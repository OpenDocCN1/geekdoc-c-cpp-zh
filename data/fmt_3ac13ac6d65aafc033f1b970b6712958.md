## 使用 Windows Installer 安装 Windows 服务

在本节中，你将学习如何在 Windows 服务应用程序中添加 Windows Installer 项目。让我们继续使用 `MyWindowsService` 应用程序并向其中添加一个名为 `ServiceDeployment` 的安装项目。

执行以下步骤向 Windows 服务应用程序添加安装项目：

1. 在解决方案资源管理器中右键单击 `MyWindowsService` 解决方案并从上下文菜单中选择 Add→New Project 选项。Add New Project 对话框出现。
2. 从 Installed Templates 窗格中选择 Other Projects Types→Setup and Deployment→Visual Studio Installer 并在 Add New Project 对话框中选择 Setup Project 模板，如图 20.10 所示。

![](img/e073a4882197be4ab61103cbe0bcb394_1055_0.png)

**图 20.10：选择安装项目**

3. 在 Name 文本框和 Location 下拉组合框中分别输入项目名称和位置。在我们的例子中，项目名称为 `ServiceDeployment`，项目位置为 `D:\Black Books\C# 2010\Chapter 20\MyWindowsService`。
4. 在 Add New Project 对话框中单击 OK 按钮。`ServiceDeployment` 安装项目已添加到 `MyWindowsService` 服务。
5. 在解决方案资源管理器中右键单击 `ServiceDeployment` 项目并从上下文菜单中选择 Add→Project Output 选项，如图 20.11 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1055_1.png)

**图 20.11：将项目输出添加到部署项目**

Add Project Output Group 对话框出现。

6. 在 Project 下拉菜单中选择 `MyWindowsService` 并在项目列表中选择 Primary output。单击 Add Project Output Group 对话框中的 OK 按钮，如图 20.12 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1056_0.png)

**图 20.12：显示 Add Project Output Group 对话框**

项目的 primary output 设置已添加到 `MyWindowsService` 解决方案中。

7. 在解决方案资源管理器中右键单击 `ServiceDeployment` 项目并从上下文菜单中选择 View→Custom Actions。Custom Actions 视图在 `ServiceDeployment` 项目中出现。
8. 右键单击 Custom Actions 图标并从上下文菜单中选择 Add Custom Action 选项，如图 20.13 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1056_1.png)

**图 20.13：选择 Add Custom Action 选项**

Select Item in Project 对话框出现（图 20.14）。

9. 在 Look in 组合框中选择 Application Folder 选项并在项目列表中选择 Primary output from `MyWindowsService` (Active) 选项，如图 20.14 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1057_0.png)

**图 20.14：添加自定义操作**

10. 单击“在项目中选择项”对话框中的“确定”按钮。`myWindowsService`（活动）对象的主输出被添加到“安装”、“提交”、“回滚”和“卸载”操作中，如图 20.15 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1057_1.png)

**图 20.15：在自定义操作中添加 `myWindowsService`（活动）对象的主输出**

11. 在 Visual Studio 2010 IDE 中选择“生成”→“配置管理器”菜单项。此时将显示“配置管理器”对话框。
12. 选中 `ServiceDeployment` 项目的“生成”复选框，并单击“配置管理器”对话框中的“关闭”按钮，如图 20.16 所示。

![](img/e073a4882197be4ab61103cbe0bcb394_1057_2.png)

**图 20.16：为 `ServiceDeployment` 选择“生成”复选框**

13. 选择“生成”→“生成解决方案”菜单项以生成 `MyWindowsService` 应用程序。图 20.17 显示了生成 `MyWindowsService` 应用程序后的输出：

![](img/e073a4882197be4ab61103cbe0bcb394_1058_0.png)

**图 20.17：显示生成 `MyWindowsService` 解决方案后的输出**

当您生成 `MyWindowsService` 解决方案时，Visual Studio 2010 会在 `ServiceDeployment` 项目的 `Debug` 文件夹中创建 `ServiceDeployment.msi` 和 `setup.exe` 文件。

现在，请执行以下步骤在 Windows 操作系统上安装 `MyWindowsService` 服务：

1. 将 `ServiceDeployment.msi` 文件复制到 Windows 操作系统上。
2. 双击 `ServiceDeployment.msi` 文件。此时将显示 `ServiceDeployment` 向导，如图 20.18 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1058_1.png)

**图 20.18：显示 `ServiceDeployment` 向导**

3. 在 `ServiceDeployment` 向导中单击“下一步”按钮。此时将显示“选择安装文件夹”页面。
4. 在“选择安装文件夹”页面中单击“浏览”按钮，以选择您要安装服务的文件夹，如图 20.19 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1058_2.png)

**图 20.19：显示“选择安装文件夹”页面**

5. 在“选择安装文件夹”页面中单击“下一步”按钮。此时将显示“确认安装”页面，如图 20.20 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1059_0.png)

**图 20.20：显示“确认安装”页面**

6. 在“确认安装”页面中单击“下一步”按钮。`ServiceDeployment` 将显示 `MyWindowsService` 服务的安装进度，如图 20.21 所示：

![](img/e073a4882197be4ab61103cbe0bcb394_1059_1.png)

**图 20.21：正在安装 Windows 服务**

此时将显示“安装完成”页面，通知您服务已成功安装。

7. 单击“关闭”按钮以关闭 `ServiceDeployment` 安装向导。

服务现已安装完成，接下来让我们学习如何使用 SCM 管理 Windows 服务。

## 使用 SCM 管理 Windows 服务

您可以使用 SCM 管理器来控制 Windows 服务的行为。SCM 管理器用于启动、停止、暂停、继续或重启特定服务。要在不同版本的 Windows 中启动 SCM 管理器，完整步骤见表 20.11：

**表 20.11：不同 Windows 版本中 SCM 的打开方式**

| Windows 版本 | SCM 管理器的打开方式 |
|---|---|
| Windows 7 | 依次单击“开始”→“控制面板”→“系统和维护”→“管理工具”→“服务”。 |
| Windows Vista | 依次单击“开始”→“控制面板”→“系统和维护”→“管理工具”→“服务”。 |
| Windows 2000 Professional | 右键单击桌面上的“我的电脑”，然后从上下文菜单中选择“管理”选项以打开“计算机管理”窗口。展开“服务和应用程序”节点，然后选择“服务”条目。 |
| Windows 2000 Server | 依次单击“开始”→“程序”→“管理工具”→“服务”。 |
| Windows XP Professional | 依次单击“开始”→“控制面板”→“管理工具”→“服务”。 |

若要停止服务，请在 SCM 管理器中右键单击 `MyService`，然后从上下文菜单中选择“停止”。现在，您可以检查我们服务的条目是否已写入其事件日志（从事件查看器中查看），如图 20.25 所示：

现在让我们学习如何卸载 Windows 服务。

## 使用 `Installutil.exe` 和 Windows Installer 卸载 Windows 服务

如果 Windows 服务未运行或未执行所需操作，您可能需要卸载该服务。您可以在 Visual Studio 2010 的命令提示符中使用以下命令卸载服务：

```
installutil.exe MyWindowsService.exe /u
```
