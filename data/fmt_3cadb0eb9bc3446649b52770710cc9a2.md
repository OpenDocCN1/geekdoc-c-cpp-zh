
# 第 11 章 更多运算符重载

## 11.1. 重载 `operator[]`

传统上访问元素可以通过三种方式实现：

- 重载的下标运算符 `operator[]` 可以返回一个非 `const` `IntArray` 对象的引用。该重载运算符的原型允许我们使用像 `x[10]` 这样的表达式作为右值或字面量。对于非 `const` `IntArray`，`operator[]` 可用于检索和赋值值。非 `const` `operator[]` 成员函数的返回值是一个 `int&`，允许在作为左值使用时修改元素；而 `const` `operator[]` 的返回值允许将返回值例如一个二进制文件写入到以下位置中：

```cpp
void writeValue(IntArray const &iarr, size_t idx){
    cout.write(reinterpret_cast<char *>(iarr[idx]));
}
```

如果没有无可赋值的内容，这种方案就会失效。考虑一下我们定义了 `IntArray const stable(5)` 的情况。这样的对象是一个 `const` 对象。编译器检测到这一点，如果存在非 `const` 版本，它将拒绝编译此定义。第二个重载的下标运算符会被编译器自动用于 `const` 对象。它用于检索而非值赋值。这当然正是我们使用 `const` 对象时所希望的。在这种情况下，成员仅根据其 `const` 属性进行重载。这种形式的函数重载早早在 C++ 标准中引入第 2.5 节和 7.7 节。

- 由于只有一个指针数据成员 `data`，由对象分配的内存的析构是一个简单的 `delete[]` 操作。

现在，成员函数的实现省略 `swap` 的简单实现，请参见第 9 章如下：

```cpp
#include "intarray.h"

IntArray::IntArray(size_t size)
: d_size(size)
{
  if (d_size < 1)
    throw "IntArray: size of array must be >= 1";
  d_data = new int[d_size];
}

IntArray::IntArray(IntArray const &other)
: d_size(other.d_size),
  d_data(new int[d_size])
{
  memcpy(d_data, other.d_data, d_size * sizeof(int));
}

IntArray::~IntArray()
{
  delete[] d_data;
}

IntArray &IntArray::operator=(IntArray const &other)
{
  IntArray tmp(other);
  swap(tmp);
  return *this;
}

int &IntArray::operatorIndex(size_t index)
{
  boundary(index);
  return d_data[index];
}

int &IntArray::operator[](size_t index)
{
  return operatorIndex(index);
}

int const &IntArray::operator[](size_t index) const
{
  return operatorIndex(index);
}
```

```cpp
void IntArray::swap(IntArray &other)
{
    // 交换 *this 和 other 的 d_size 和 d_data 成员
}
```

```cpp
void IntArray::boundary(size_t index) const
{
    if (index < d_size)
        return;
    ostream out;
    out << "IntArray: boundary overflow, index = " <<
        index << ", should be < " << d_size << '\n';
    throw out.str();
}
```

注意 `operator()` 成员的实现：由于非 `const` 成员可以拥有 `const` 函数，且 `const` 函数的实现与非 `const` 成员函数的实现相同，因此 `operator()` 成员可以使用 `operatorIndex(size_t index) const` 进行内联定义。成员函数可以返回一个非 `const` 引用或指针值，引用对象的一个数据成员。当然，这是一个潜在的危险后门，可能会破坏数据隐藏性。然而，公共接口中的成员防止了这一点，因此两个公共 `operator()` 成员本身会安全地调用同一个 `operatorIndex() const` 成员，该成员定义了一个私有后门。

## 11.11 多参数 `operator[]()`

考虑一个标准的二维数组。它有 `nRows` 行和 `nCols` 列。这样的数组是一维数组的推广：每行都由一个包含 `nCols` 个元素的数组组成。定义了一个类型 `DoubleArray`，类似于上一节的 `IntArray`，但包含的是 `double` 值而非 `int` 值，设计该类可以如下：

```cpp
class Matrix
{
    size_t nRows;
    size_t nCols;
    double **d_data;
public:
    Matrix(size_t nRows, size_t nCols);
};
```

并且它的构造函数分配 `DoubleArrays`，每个都有 `nCols` 个元素并初始化为 0：

```cpp
Matrix::Matrix(size_t nRows, size_t nCols)
: nRows(nRows), nCols(nCols)
{
    d_data = new double*[nRows];
    for (size_t i = 0; i < nRows; ++i)
        d_data[i] = new double[nCols];
        memset(d_data[i], 0, nCols * sizeof(double));
}
```
