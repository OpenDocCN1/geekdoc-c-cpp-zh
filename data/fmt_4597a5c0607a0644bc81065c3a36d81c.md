## 注释

带有双斜杠的行是注释。这意味着它们不会在代码中执行，并会被编译器忽略。注释旨在帮助你，或者查看你代码的另一个程序员解释正在发生什么。注释有两种类型：// 覆盖多行（注：原文如此），以双斜杠开头的注释。这意味着它们不会被编译器忽略。

<< 这里使用的尖括号是插入运算符。这意味着尖括号后的任何内容都将被插入到 `std::cout` 语句中。在这种情况下它们是 'Hello, world'。

```cpp
#include <iostream>
int main() {
    std::cout << "Hello, world!";
    return 0;
}
```
