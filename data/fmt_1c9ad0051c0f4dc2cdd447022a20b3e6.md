# 插入 DOCTYPE 声明

要指定 XML 文档使用的 DTD，可以在 XML 引导程序之后直接添加 DOCTYPE 声明

```
<!DOCTYPE type id="url">
```

其中 root 是文档的根元素，type 指定 DTD 的类型（PUBLIC 或 SYSTEM），id 是与 DTD 关联的 ID，url 是包含 DTD 规则的外部文件位置。对于 XHTML 文档，将 root 值设置为空（null），并将 type 值设置为 PUBLIC。
