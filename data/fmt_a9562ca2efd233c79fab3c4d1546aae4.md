(泡排序) 编写一个使用泡排序算法的排序函数。该算法对数组进行多次遍历。在每次遍历中，比较相邻的元素。如果一对是倒序的，则交换它们的值；否则值保持不变。这种技术称为泡排序，较小的值“泡”到顶部，较大的值到底部。

该算法描述如下：

```cpp
bool changed = true;
do {
  changed = false;
  for (int j = 0; j < listSize; j++)
    if (list[j] > list[j + 1])
    {
      swap(list[j], list[j + 1]);
      changed = true;
    }
} while (changed);
```

显然，循环结束时列表是有序的。循环最多执行 `listSize - 1` 次。
