
`par`参数是初始化递归的起始值，`fn`是要最小化的函数，`lower`和`upper`是定义整个实线的边界。方法`L-BFGS-B`是一种有限内存牛顿算法，使用Broyden方案进行二阶近似，并允许边界形式约束（参见Byrd等，1995和Zhu等，1997）。有限内存方面对于我们的一维设置并不特别相关。通常，`optim`函数可以用于此类问题变得重要的高维优化。

# 8.5 似然

极大似然估计技术引了一个统计学特有的优化问题。首先，令$X_1, \dots, X_n$为一组随机变量，其具有联合密度（或概率质量函数）$g(\theta^*)$，其中$\theta^*$是集合$\Theta$（实线的子集）的固定未知成员。现在假设$X_i$已观测，意味着我们有$X_1 = x_1, \dots, X_n = x_n$，下标观测值现在是固定的而不是随机的。问题是如何从观测数据中“最佳地”提取关于参数$\theta$的信息。

样本似然定义为

$$L(\theta) = g(x_1, \dots, x_n).$$

它是$\theta$的函数，因为$x_1, \dots, x_n$现在是固定的。$\theta$的极大似然估计（mle）给出：

$$\hat{\theta} = \argmax_{\theta \in \Theta} L(\theta).$$

使用mle作为估计器的动机是可能的$X$的组件为离散的情况。在那种情况下

$$L(\theta) = Prob(X_1 = x_1, \dots, X_n = x_n).$$

即$L(\theta)$是在给定$\theta$值下看到观测值$x_1, \dots, x_n$的概率。这为$\theta$的选择提供了解释：为实际收集的数据分配了最高概率。

我们对极大似然的处理将详细说明$X_1, \dots, X_n$代表定义4.1意义上的样本的特殊情况。令$f(\theta)$为某个$\theta$值的共同（一元）密度或概率质量函数，使得$g(x_1, \dots, x_n) = \prod_{i=1}^n f(x_i;\theta)$更容易处理似然的负对数：

$$\ell(\theta) = -\sum_{i=1}^n \ln f(x_i;\theta).$$

`epsilon`的值可以作为`optim`的参数指定，否则默认认为$10^{-7}$。目标函数的导数也可以作为参数提供给`optim`。

```cpp
//functorIn.h
#ifndef FUNCTIONOR_H
#define FUNCTIONOR_H

struct FunctorIn{
    double (*PF)(double x, double theta);
    double (*PF1)(double x, double theta);
    double (*PF2)(double x, double theta);

    FunctorIn() {}
    FunctorIn(double (*pf)(double x, double theta),
```

## 数值优化

`Like`类有三个成员：样本量`n`、一个`Functor`对象以及一个指向存储数据值的`double`指针。类构造函数接受样本量和`Functor`对象作为参数，以及一个C风格的字符串（即以空字符结尾的`"\0"`字符数组或`char`指针），该字符串包含存储数据的文件名。`mle`方法管理优化工作，需要指定参数空间间隔的上下界`a`和`b`，以及一个用于初始化牛顿法的起始值。剩余的两个参数`itMax`和`delta`设置了牛顿迭代的停止准则；记住，一旦某个参数被赋予了默认值，函数签名中的所有后续参数也具有默认值。这就是为什么`itMax`和`delta`出现在`mle`方法的参数列表的末尾。

列表8.15: `like.cpp`

```cpp
//like.cpp
#include "like.h"
#include "functorIn.h"
#include "optim.h"
#include "fileIn.h"

Like::Like(int N, char* fname, FunctorIn& F) {
    n = N; f = F;
    px0 = new double[n];
    fileIn<double> inObj(fname);
    inObj.read(n, px0);
}

double Like::l(double theta) const {
    double logL = 0;
    for(int i = 0; i < n; i++)
        logL += f(px0[i], theta, 0);
    return (-logL);
}

double Like::lp(double theta) const {
    double logL = 0;
    for(int i = 0; i < n; i++)
        logL += f(px0[i], theta, 1);
    return (-logL);
}

double Like::lpp(double theta) const {
    double logLpp = 0;
    for(int i = 0; i < n; i++)
        logLpp += f(px0[i], theta, 2);
    return (-logLpp);
}

double Like::mle(double a, double b, double start, int itMax,
                 double delta) const {
    int ier = 0;
    Functor<const Like> logL(this, &Like::l, &Like::lp, &Like::lpp);
    Optim<const Like> Opt(itMax, delta);
    double thetaHat = Opt::newton(logL, b, start, ier);
    return thetaHat;
}
```
