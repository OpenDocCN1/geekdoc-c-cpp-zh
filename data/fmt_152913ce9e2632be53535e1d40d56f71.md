data EuropeQ1;

### 子集 IF 语句的位置

通常，放置子集语句的最有效位置是在评估条件所需的所有变量都已赋值后立即放置。

```sas
data EuropeQ;
infile "path\sales.dat";
input @6 Location $3. @;
if Location = 'EUR';
input @1 SaleID $4.
@10 SaleDate date9.
@20 Amount commax7;
run;
```
