
这个 `try` 块包含了基本算法代码，告诉计算机在一切顺利进行时该做什么。它之所以被称为 `try` 块，是因为你并不 100% 确定一切都会进展顺利，但你想“尝试一下”。

如果真的发生了问题，你想要“抛出”一个异常，这是指示发生某些问题的方法。当我们添加 `throw` 时，基本轮廓如下：

```
try

(

  Code_To_Try

  Possibly_Throw_An_Exception

  More_Code

)
```

以下是一个包含 `throw` 语句的 `try` 块示例：

```
try {
  cout << "Enter number of donuts:\n";
  cin >> donuts;
  cout << "Enter number of glasses of milk:\n";
  cin >> milk;
  if (milk <= 0)
    throw donuts;
  dpg = donuts/static_cast<double>(milk);
  cout << donuts << " donuts.\n"
       << milk << " glasses of milk.\n"
       << "You have " << dpg
       << " donuts for each glass of milk.\n";
}
```

以下语句抛出了 `int` 类型的值 `donuts`：

```
throw donuts;
```

抛出的值在此例中为 `donuts`，有时被称为“异常”，而 `throw` 语句的执行被称为“抛出异常”。你可以抛出任何类型的值。在此例中，抛出的是一个 `int` 值。

### throw 语句

语法
`throw Expression_for_Value_to_Be_Thrown;`

当执行 `throw` 语句时，封装的 `try` 块的执行将停止。如果 `try` 块后面跟着一个合适的 `catch` 块，则控制流将转移到 `catch` 块。`throw` 语句几乎总是嵌入分支语句中，例如 `if` 语句。抛出的值可以是任何类型。

示例

```
if (milk <= 0)
  throw donuts;
```

顾如名称，当某物被“抛出”时，它会从一个地方到另一个地方。在 C++ 中，从一个地方到另一个地方的是控制流以及抛出的值。当异常发生时，周围 `try` 块中的代码停止执行，另一部分代码作为 `catch` 块开始执行。这种 `catch` 块的执行就是捕获异常或处理异常。当异常发生时，理想情况下它应该被某个 `catch` 块处理。在显示 16.2 中，相应的 `catch` 块紧随 `try` 块之后。我们在这里重复该 `catch` 块：

```
catch(int e)
{
    cout << e << " donuts, and No Milk!\n"
    << "Go buy some milk.\n";
}
```

这个 `catch` 块看起来非常像一个具有 `int` 类型参数的函数。它不是函数定义，但在某些方面，`catch` 块就像函数。它是一段独立的代码，当你的程序遇到并执行以下内容在之前的 `try` 块内时就会执行：

```
throw Some_int;
```

所以，这个 `throw` 语句类似于函数调用，但它不是调用函数，而是调用 `catch` 块并指示执行 `catch` 块中的代码。`catch` 块通常被称为“异常处理器”，这个术语暗示 `catch` 块具有类似函数的性质。

在 `catch` 块的以下行中，标识符 `e` 是什么？

```
catch(int e)
```

该标识符 `e` 看起来像一个参数，行为也很像参数。因此，我们将其称为 catch 块参数。但请记住，这并不意味着 `catch` 块是一个函数。catch 块参数有两个作用：
1. catch 块参数之前是一个类型名称，该类型指定了 `catch` 块可以捕获的抛出值的种类。
2. catch 块参数为被捕获的异常值提供了一个名称，以便你可以在 `catch` 块中编写代码来处理这个被捕获的值。

我们将相反的顺序来讨论 catch 块参数的这两个功能。在这个例子中，这种分离并没有带来很多好处，但在我们的实际情况下，它将被证明是非常有用的。让我们来看细节。

## 第16 章 / 异常处理

### catch-块参数

`catch`-块参数是 `catch` 块标题中的一个标识符，用作可能抛出的异常一个值的占位符。当在之前的 `try` 块中抛出一个合适的 值时，该值将填充到 `catch`-块的参数中。你可以使用任何合法的非保留字标识符作为 `catch`-块的参数。

### 示例

```
catch(int e) {
    cout << e << " donuts, and No Milk!\n"
    << "Go buy some milk.\n";
}
// e 是 catch-块参数。
```

当用户输入一个非正数时，`try` 块停止并执行 `catch` 块。目前，我们假设每个 `try` 块后面都有一个相应的 `catch` 块。我们稍后将讨论如果没有相应的 `catch` 块时会发生什么。

接下来，我们总结一下当 `try` 块没有抛出异常时发生的情况。如果 `try` 块中没有抛出异常没有值，那么在 `try` 块完成后，程序执行将继续执行 `catch` 块之后的代码。换句话说，如果没有抛出异常，`catch` 块将被忽略。在程序执行的大部分时间内，`throw` 语句不会执行，在大多数情况下，`try` 块中的代码将运行完成，而 `catch` 块中的代码将被完全忽略。

### try-throw-catch

这是抛出和捕获异常的基本机制。`throw` 语句抛出异常一个值。`catch` 块捕获异常该值。当异常被抛出时，`try` 块结束并执行 `catch` 块中的代码。在 `catch` 块完成后，将执行 `catch` 块之后的代码前提是 `catch` 块没有结束程序或执行了其他特殊操作。

如果 `try` 块中没有抛出异常，那么在 `try` 块完成后，程序执行将继续执行 `catch` 块之后的代码。换句话说，如果没有抛出异常，则 `catch` 块将被忽略。

语法
```
try
{
    某些语句
    < 可能是带有 throw 语句的代码或
    可能会抛出异常的函数调用>
    更多语句
}
catch(Type_Name e)
{
    < 如果在 try 块中抛出了与
    catch-块参数类型的值，则要执行的代码>
}
```

### 多次抛出和捕获

`try` 块可能会抛出任意数量的异常值，并且它们可以是不同类型。在 `try` 块的任何一次执行中，只会抛出一个异常因为抛出异常会结束 `try` 块的执行，但 在执行 `try` 块的不同时机，可以抛出不同类型的异常值。每个 `catch` 块只能捕获一种类型的值，但你通过在并在 `try` 块之后放置多个 `catch` 块，可以捕获不同类型的异常值。例如，显示 16.4 中的程序在它的 `try` 块之后有两个 `catch 块`。

#include <iostream>
using namespace std;
class NoMilk
{
public:
    NoMilk();
    NoMilk(int howMany);
    int getuts();
private:
    int count;
};
int main()
{
    int donuts, milk;
    double dpg;
    try
    {
        cout << "Enter number of donuts:\n";
        cin >> donuts;
        if (donuts <= 0)
            throw NoMilk(donuts);
        cout << "Enter number of milk:\n";
        cin >> milk;

            throw NoMilk(milk);

catch(NoMilk e)
{
    cout << e.getuts() << " donuts, and No Milk!\n";
    << "Go buy some milk.\n";
}
    cout << "After catch block." << endl;
    return 0;
}

{}

{}

}

## 陷阱 优先捕获更具体的异常

在捕获多个异常时，catch 块的顺序可能是非常重要的。当 try 块中抛出异常时，程序将按照顺序尝试后续 catch 块，并执行第一个与抛出的异常类型相匹配的 catch 块。

例如，这是一种特殊的 catch 块，它可以捕获任何类型的抛出值：

```cpp
catch(...)
{
<在此处放置任何你想要的内容>
}
```

这三个点并不代表某些省略的内容。你实际上是在程序中输入了这三个点。这使其成为一个存放在所有其他 catch 块之后的良好默认 catch 块。例如，我们可以按照如下方式将其添加到显示 16.4 的 catch 块中：

```cpp
catch(NegativeNumber e)
{
    cout << "Cannot have a negative number of " << e.getMessage() << endl;
}
```

```cpp
catch(DivideByZero)
{
    cout << "Send for help.\n";
}
catch(...)
{
    cout << "Unexplained exception.\n";
}
```

然而，只有将此默认 catch 块放在 catch 块列表的末尾才有意义。例如，假设我们使用了：

```cpp
catch(NegativeNumber e)
{
    cout << "Cannot have a negative number of " << e.getMessage() << endl;
}
catch(...)
{
    cout << "Unexplained exception.\n";
}
catch(DivideByZero)
{
    cout << "Send for help.\n";
}
```
