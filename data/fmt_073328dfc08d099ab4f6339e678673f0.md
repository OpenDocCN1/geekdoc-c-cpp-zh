## 使用 Path 和 PathGeometry 类

在 WPF 中，`Path` 类使你能够绘制复杂的曲线和形状。要使用 `Path` 类，首先创建 `Geometry` 类的对象并使用它来设置 `Path` 类对象的 `Data` 属性。`FillRule` 属性指定如何组合相交区域，它与 `PathGeometry` 或 `GeometryGroup` 对象一起工作。`FillRule` 属性有两个值，`EvenOdd` 和 `NonZero`。如果指定 `EvenOdd` 值，则交替区域会被填充。`NonZero` 值会用指定颜色填充 `GeometryGroup` 或 `PathGeometry` 对象中指定的整个区域。`PathGeometry` 对象由一个或多个图形组成，由 `PathFigure` 类表示。每个图形由一个或多个段组成，由 `PathSegment` 类定义。让我们使用 `Path` 和 `PathGeometry` 类来查看 `FillRule` 属性的应用。为此，创建一个名为 `UsingPath` 的 WPF 应用程序（也在 CD 上提供）并将 `Listing 12.7` 中的代码添加到 `MainWindow.xaml` 文件中：

### Listing 12.7: Using the Path Class

```xml
<Window x:Class="UsingPath.MainWindow"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
Title="MainWindow" Height="300" Width="300">
<Grid>
<Path Stroke="Black" StrokeThickness="2" Fill="LightBlue">
<Path.Data>
<GeometryGroup FillRule="Evenodd">
<PathGeometry>
<PathGeometry.Figures>
<PathFigure StartPoint="150,150">
<PathFigure.Segments>
<PathSegmentCollection>
<ArcSegment Size="50,50" IsLargeArc="True" SweepDirection="CounterClockwise" Point="25,120" />
</PathSegmentCollection>
</PathFigure.Segments>
</PathFigure>
<PathFigure StartPoint="150,150">
<PathFigure.Segments>
<PathSegmentCollection>
<ArcSegment Size="70,70" IsLargeArc="True" SweepDirection="CounterClockwise" Point="25,100" />
</PathSegmentCollection>
</PathFigure.Segments>
</PathFigure>
</PathGeometry.Figures>
</PathGeometry>
</GeometryGroup>
</Path.Data>
</Path>
```

### LinearGradientBrush 和 RadialGradientBrush

`LinearGradientBrush` 类用于使用线性渐变绘制区域；而 `RadialGradientBrush` 类用于使用径向渐变绘制区域。你可以使用 `GradientStop` 对象来指定渐变中的颜色及其位置。

让我们将 `LinearGradientBrush` 和 `RadialGradientBrush` 类添加到应用程序中。为此，创建一个名为 `Linear_RadialBrush` 的 WPF 应用程序（也可在 CD 中找到），并将清单 12.8 中给出的代码添加到 `MainWindow.xaml` 文件中：

**清单 12.8：使用 LinearGradientBrush 和 RadialGradientBrush 类**

```xml
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MainWindow" Height="300" Width="300">
<Grid>
<Ellipse Name="ellipse1" Stroke="OrangeRed" HorizontalAlignment="Right" Width="96" Height="96" VerticalAlignment="Top" Margin="0,8,19,0">
```
