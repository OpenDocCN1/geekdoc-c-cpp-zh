# 案例研究：数值积分与微分

本章的目的是将第六部分讨论的数值积分和微分方法应用于实际工程问题。通常会遇到两种情况。第一种情况是研究函数可以用解析形式表示，但过于复杂，无法直接使用微积分方法进行评价。这类情况通过使用解析表达式生成变量和函数值的表格应用数值方法。第二种情况是待评价的函数本质上是表格形式。这类函数通常代表一组测量、观测或其他收集的信息，因为这两种情况都与书中此处讨论的方案直接兼容。

第 24.1 节处理化学工程的热量计算，涉及方程。在这一应用中，对解析函数进行数值积分，以确定提高材料温度所需的热量。第 24.2 节取自土木工程，使用数值积分确定作用在帆船桅上的风力。第 24.3 节确定电路的均方值电流。该示例用于证明 Romberg 积分和高斯求积法的效用。

第 24.4 节侧重于分析表格信息，以确定移动物体所需的功。虽然这一应用与化学工程有直接联系，但对所有其他工程领域都是通用的。

## 24.1 积分以确定总热量（化学/生物工程）

背景。热量计算在化学工程、生物工程以及许多其他工程领域被经常使用。这一应用提供了此类计算的一个简单但实用的示例。

执行该计算所需的特征是热容，$c$。该参数代表将单位质量升高单位温度所需的热量。如果 $c$ 在所研究的温度范围内为常数，则所需的热量 $\Delta H$（单位为卡路）可以通过下式计算：

```
$\Delta H = mc\Delta T$
```

(24.1)

其中 $c$ 的单位为 cal/(g °C)，$m$ 是质量 (g)，$\Delta T$ 是温度变化 (°C)。例如，将 20 g 水从 5°C 升高到 100°C 所需的热量等于

```
$\Delta H = 20(100 - 5) = 100\text{ cal}$
```

水的热容约为 1 cal/(g °C)。当 $\Delta T$ 较小时，这种计算是足够的。然而，对于较大的温度范围，热容不是恒定的，实际上它是随温度变化的函数。例如，某种材料的热容可能会根据如下关系增加：

```
$c(T) = 0.132 + 1.56 \times 10^{-7}T + 2.64 \times 10^{-12}T^2$
```

(24.2)

现在要求计算将 1000 g 这种材料从 -100°C 升高到 200°C 所需的热量。

解。方程 (24.1) 提供了一种计算 $c(T)$ 平均值的方法：

```
$\overline{c} = \frac{\int_{T_1}^{T_2} c(T)dT}{T_2 - T_1}$
```

(24.3)

代入方程 (24.1) 可得到：

```
$\Delta H = m \int_{T_1}^{T_2} c(T)dT$
```

(24.4)

其中 $\Delta T = T_2 - T_1$。现在，在本例中，$c(T)$ 是一个简单的二次函数，$\Delta H$ 可以通过解析确定。将方程 (24.2) 代入方程 (24.4) 并对结果进行积分，得到 $\Delta H = 42732$ cal 的精确值。将此结果与第 21 章开发的数值方法进行比较是非常有用且具有启发性的。为了实现这一点，有必要生成一个不同 $T$ 值对应的 $c$ 值表：

| °C | cal/(g °C) |
|---|---|
| -100 | 0.11904 |
| -50 | 0.12486 |
| 0 | 0.13200 |
| 50 | 0.14046 |
| 100 | 0.15024 |
| 150 | 0.16134 |
| 200 | 0.17376 |

这些点可以结合六段辛普森 1/3 规则来计算出 42732 的积分。将此结果代入方程 (24.4) 得到 $\Delta H = 42732$ cal，这与解析解完全一致。无论使用多少分段，这种精确一致都会发生，因为 $c$ 是一个二次函数，而辛普森规则对于三次及以下的多项式是精确的（见第 21.2 节）。
