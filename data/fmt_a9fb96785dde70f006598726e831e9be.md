## 2.2 十进制转二进制、八进制、十六进制

十进制数字分为整数部分和分数部分。例如，`23` 是整数部分，`.07` 是分数部分。在本节中我们将把十进制整数转换为其他进制。

### 2.2.1 整数转二进制、八进制、十六进制

十进制整数通过除法运算转换为其他进制。让我们通过一些例子来理解这种转换。在除法过程中，每次除法后将余数写在右侧，将商写在下一行。继续除法直到商为 0。

**十进制 25 转二进制：**

| 进制 | 被除数/商 | 余数 |
| :---: | :---: | :---: |
| 2 | 25 | |
| 2 | 12 | 1 |
| 2 | 6 | 0 |
| 2 | 3 | 0 |
| 2 | 1 | 1 |
| | 0 | 1 |

十进制 25 的二进制是 `11001`。

**十进制 25 转八进制：**

| 进制 | 被除数/商 | 余数 |
| :---: | :---: | :---: |
| 8 | 25 | |
| 8 | 3 | 1 |
| | 0 | 3 |

十进制 25 的八进制是 `31`。

**十进制 25 转十六进制：**

| 进制 | 被除数/商 | 余数 |
| :---: | :---: | :---: |
| 16 | 25 | |
| 16 | 1 | 9 |
| | 0 | 1 |

十进制 25 的十六进制是 `19`。

### 2.2.2 小数转二进制、八进制、十六进制

小数是小于 1 的数字。它可能是 `.5`、`.00453`、`.564` 等。我们使用乘法运算将十进制小数转换为其他任何进制。

将小数转换为：
1. **二进制**：乘以 `2`，
2. **八进制**：乘以 `8`，
3. **十六进制**：乘以 `16`。

使用 `toBase` 转换小数以获得结果数字的步骤为：
1. 将小数乘以 `toBase`，
2. 结果由两部分组成：整数部分和小数部分。
3. 记录结果的整数部分。
4. 重复上述步骤至少四次。
5. 从上到下写入整数部分的数字。

| 2 | 0.2345 | 0 | 0.4690 |
| 2 | 0.4690 | 0 | 0.9380 |
| 2 | 0.9380 | 1 | 0.8760 |
| 2 | 0.8760 | 1 | 0.7520 |
| 2 | 0.7520 | 1 | 0.5040 |
| 2 | 0.5040 | 1 | 0.0080 |

十进制 `0.2345` 的二进制是 `(0.001111)₂`。

| 值 | ×2 | ×8 | ×16 |
| :--- | :--- | :--- | :--- |
| 0.865 | 1.730 | 6.920 | 13.84 |
| | 1.460 | 7.360 | 8.64 |
| | 0.920 | 2.880 | 13.84 |
| | 1.840 | 7.040 | 10.24 |
| | 1.680 | | 1.44 |
| | 1.360 | | 2.40 |
| | | | 4.40 |
| | | | 7.040 |

`(0.865)₁₀` 的二进制等值是 `(.110111)₂`。
十六进制中的数字 13 是 `D`。
`(0.865)₁₀` 的十六进制等值是 `(.DD7)₁₆`。
`(0.865)₁₀` 的八进制等值是 `(.6727)₈`。

### 2.2.3 将十进制整数.小数转换为二进制、八进制、十六进制

十进制整数.小数同时包含整数部分和小数部分。将十进制整数.小数转换为任何其他进制的步骤为：
1. 按照 2.2.1 节所示的步骤将十进制整数部分转换为目标进制。
2. 按照 2.2.2 节所示的步骤将十进制小数部分转换为目标进制。
3. 将目标进制中的整数部分和小数部分结合得到整数.小数。

## 2.3 二进制、八进制、十六进制转换为十进制

二进制、八进制或十六进制数包含两个部分——整数部分和小数部分。例如，二进制可以是 `1001`、`00110001` 或 `00110011`。数字 `45`、`.362` 或 `245.362` 是八进制。十六进制数可以是 `A2`、`C2` 或 `A14`。

二进制、八进制或十六进制数的整数和小数部分的转换方法相同；使用乘法运算进行转换。转换机制利用数字的面值和位置值。转换步骤如下：

1. 计算数字中每个数字的 `面值 × (基数)^位置` 之和。
   a. 在整数中，最右侧的数字位置为 0，向左递增。
   b. 在小数中，小数点左侧的数字位置为 0，向左递增；小数点右侧的第一个数字位置为 -1，向右递减（-2, -3 等）。

### 2.3.1 整数部分转换示例

| 二进制转十进制 | 八进制转十进制 | 十六进制转十进制 |
| :--- | :--- | :--- |
| `1011 = 1×2³ + 0×2² + 1×2¹ + 1×2⁰` | `62 = 6×8¹ + 2×8⁰` | `C15 = C×16¹ + 1×16⁰ + 5×16⁻¹` |
| `= 8 + 0 + 2 + 1` | `= 48 + 2` | `= 192 + 16 + 0.3125` |
| `= 11` | `= 50` | `= 208.3125` |

> **示例 2.9** | 将 `1011` 从 2 进制转换为 10 进制。将 `62` 从 8 进制转换为 10 进制。将 `C15` 从 16 进制转换为 10 进制。

### 2.3.2 小数部分转换示例

| 二进制转十进制 | 八进制转十进制 | 十六进制转十进制 |
| :--- | :--- | :--- |
| `.1101 = 1×2⁻¹ + 1×2⁻² + 0×2⁻³ + 1×2⁻⁴` | `.345 = 3×8⁻¹ + 4×8⁻² + 5×8⁻³` | `.15 = 1×16⁻¹ + 5×16⁻²` |
| `= 1/2 + 1/4 + 0 + 1/16` | `= 3/8 + 4/64 + 5/512` | `= 1/16 + 5/256` |
| `= 13/16` | `= 229/512` | `= 21/256` |
| `= .8125` | `= .447` | `= .082` |

`(.1101)₂` 的十进制等值是 `.8125`。
`(.345)₈` 的十进制等值是 `.447`。
`(.15)₁₆` 的十进制等值是 `.082`。

> **示例 2.10** | 将 `.1101` 从 2 进制转换为 10 进制。将 `.345` 从 8 进制转换为 10 进制。将 `.15` 从 16 进制转换为 10 进制。

## 2.4 十六进制与八进制转二进制

### 示例 2.14 | 将十六进制数 2BA3 转换为二进制

1. 给定数字为 `2BA3`。
2. 将每个十六进制位转换为四位二进制数。
   ```text
   2    B    A    3
   0010 1011 1010 0011
   ```
3. 将所有位组合起来得到结果 `0010101110100011`。

### 示例 2.15 | 将八进制数 473 转换为二进制

1. 给定数字为 `473`。
2. 将每个八进制位转换为三位二进制数。
   ```text
   4   7   3
   100 111 011
   ```
3. 将所有位组合起来得到结果 `100111011`。

## 2.5 二进制算术

在二进制数上进行的算术运算——加、减、乘、除称为**二进制算术**。在计算机中，在二进制数上执行的基本算术运算是：
1. 二进制加法
2. 二进制减法

在接下来的章节中，我们将讨论二进制加法和二进制减法操作。

### 2.5.1 二进制加法

二进制加法涉及两个或多个二进制数的相加。执行二进制加法时使用**二进制加法规则**。表 2.3 显示了二进制加法规则。

**表 2.3 二进制加法规则**

| 输入 1 | 输入 2 | 和 | 进位 |
| :---: | :---: | :---: | :---: |
| 0 | 0 | 0 | 无 |
| 0 | 1 | 1 | 无 |
| 1 | 0 | 1 | 无 |
| 1 | 1 | 0 | 1 |

三个输入的二进制加法遵循表 2.4 所示的规则。

**表 2.4 三输入二进制加法**

| 输入 1 | 输入 2 | 输入 3 | 和 | 进位 |
| :---: | :---: | :---: | :---: | :---: |
| 0 | 0 | 0 | 0 | 无 |
| 0 | 0 | 1 | 1 | 无 |
| 0 | 1 | 0 | 1 | 无 |
| 0 | 1 | 1 | 0 | 1 |
| 1 | 0 | 0 | 1 | 无 |
| 1 | 0 | 1 | 0 | 1 |
| 1 | 1 | 0 | 0 | 1 |
| 1 | 1 | 1 | 1 | 1 |

二进制数的加法涉及以下步骤：
1. 从个位（最右侧的一列）的位开始加法。使用二进制加法规则。
2. 一列位相加的结果是一个带或不带**进位**的**和**。
3. 将该**和**写在该列的结果中。
4. 如果存在**进位**，则将**进位**加到左侧下一列的加法中。
5. 对每一列重复步骤 2–4，即十位、百位等此类推。

让我们通过一些示例来理解二进制加法。

> 当我们在个位上加 0 和 1 时，和为 1 且没有进位。和 1 写在结果的个位上。在十位上，我们加 1 和 0 得到和 1。没有进位。和 1 写在结果的十位上。

### 2.5.2 二进制减法

二进制减法涉及两个二进制数的相减。执行二进制减法时使用**二进制减法规则**。二进制减法规则见表 2.5。

**表 2.5 二进制减法规则**

| 输入 1 | 输入 2 | 差 | 借位 |
| :---: | :---: | :---: | :---: |
| 0 | 0 | 0 | 无 |
| 0 | 1 | 1 | 1 |
| 1 | 0 | 1 | 无 |
| 1 | 1 | 0 | 无 |

二进制数的减法步骤如下：
1. 从个位开始减去下行的位。
2. 使用二进制减法规则。如果上行的位小于下行，则从下一列（左侧）借 1。
3. 将差写在该列的结果中。
4. 对每一列重复步骤 2 和 3，即十位、百位等。

让我们通过一些示例来理解二进制减法。

**示例 2.21 | 从 11 减 01。通过十进制减法验证答案。**

| :--- | :--- |
| ` 11` | 3 |
| `- 01` | 1 |
| ` 10` | 2 |
| `10₂ = 2₁₀` | |

| :--- | :--- |
