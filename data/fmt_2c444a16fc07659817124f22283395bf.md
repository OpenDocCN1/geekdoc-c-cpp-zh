您可以在 WPF 中使用`Blocks`和`Inlines`属性以编程方式向文档中添加元素。`Blocks`属性用于向`BlockCollection`添加和删除项。`Inlines`属性用于向`InlineCollection`添加和删除项。`Blocks`属性支持的流内容元素有：`Figure`、`Floater`、`ListItem`、`Section`和`TableCell`。`Inlines`属性支持的流内容元素有：`Bold`、`Hyperlink`、`Italic`、`Paragraph`、`Span`和`Underline`。让我们创建一个名为`Blocks_and_Inlines_Property`的 WPF 应用程序（也可在 CD-ROM 上获得）来学习如何使用`Blocks`和`Inlines`属性。将列表 11.18 中给出的代码添加到`Blocks_and_Inlines_Property`应用程序的`MainWindow.xaml`文件中：

```csharp
using System;

using System.Linq;

namespace Blocks_and_Inlines_Property
{

    /// Interaction logic for MainWindow.xaml
    /// </summary>

    {
        public MainWindow()
        {
            InitializeComponent();
            Run First = new Run();
            First.Text = "Hello! ";
            Bold bold = new Bold();
            Run runBold = new Run();
```
