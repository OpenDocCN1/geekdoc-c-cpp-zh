## 使用 WCF 数据服务在 WPF 中进行数据绑定

WCF 数据服务允许你为 Web 应用程序创建和消费 OData 服务。OData 服务基于开放数据协议，该协议是一种新的数据共享标准。WCF 数据服务提供客户端库，这些库由各种技术支持，例如 `.NET`、Silverlight、异步 JavaScript 和 XML（AJAX）、超文本预处理器（PHP）和 Java。此外，这些服务支持 SQL Server 2008、Windows Azure Storage、Excel 2010 和 SharePoint 2010 中的 OData。数据服务框架使你能够创建灵活的 WCF 数据服务，这些服务可以轻松地与 Web 应用程序集成。这些 WCF 数据服务使用统一服务标识符（URI）以各种格式显示数据，例如 JavaScript 对象表示法（JSON）和表述性状态转移（REST）。
