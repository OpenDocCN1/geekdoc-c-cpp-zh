## 9.6 函数与结构

在第 8 章中，你学习了函数。你已经看到通过向函数传递参数可以增加函数的灵活性。在之前的章节中，你学习了如何向函数传递变量、数组和指针。在本节中，我将告诉你如何将结构传递给函数。

### 传递结构的三种方式

1. 将结构体对象的每个成员作为单独参数传递
2. 按值传递整个结构体对象
3. 通过地址/引用传递结构体对象

## 9.6.1 将结构体对象的每个成员作为单独传递

可以通过传递结构体对象的每个成员将结构体对象传递给函数。结构体对象的成员可以按值传递，也可以通过地址/引用传递。程序 9-20 中的代码说明了通过按值和地址/引用传递其每个成员来传递结构体的方法。

> **程序 9-20** - 一个演示通过传递成员来传递结构体对象的程序

**观察点：**

1. 如果要传递的结构体对象成员较多，这种向函数传递结构体对象的方法效率极低、难以管理且不可行。
2. 如果结构体只包含少数成员，则这种传递结构体的方法是合适的。此外，成员必须是基本类型或派生类型，而不能是结构类型（即嵌套结构）。
3. 结构体对象的成员可以按值传递，也可以通过地址/引用传递。

## 9.6.2 按值传递结构体对象

赋值运算符在应用于结构体时逐成员复制的行为，使得按值将结构体对象传递给函数并从函数返回结构体对象成为可能。程序 9-21 中的代码说明了按值传递结构体对象。

### 程序 9-21：按值传递和返回结构体对象

```c
//按值传递和返回结构体对象
#include<stdio.h>
struct complex
{
    int re;
    int im;
};
struct complex add_complex(struct complex, struct complex);
main()
{
    struct complex no1, no2;
    printf("Enter the real and imaginary parts of 1st number: %d\n");
    scanf("%d%d",&no1.re,&no1.im);
    printf("Enter the real and imaginary parts of 2nd number: %d\n");
    scanf("%d%d",&no2.re,&no2.im);
    no3=add_complex(no1,no2);
    if(no3.im!=0)
    {
        printf("The result of their addition is %d+%di\n",no3.re,no3.im);
    }
    else
    {
        printf("The result of their addition is %d+%di\n",no3.re,no3.im);
    }
}
struct complex add_complex(struct complex a, struct complex b)
{
    struct complex temp;
    temp.re=a.re+b.re;
    temp.im=a.im+b.im;
    //写成 temp=a+b 是无效的
    return temp;
}
```

> **程序 9-21** - 一个演示按值向函数传递结构体对象的程序

**关于按值向函数传递结构体对象的观察点：**

1. 这种向函数传递结构体对象的方法比之前将每个成员逐个单独传递的方法更好（即更易管理）。
2. 在这种方法中，结构体对象的所有成员被一起传递，而不是逐个传递。
3. 如果结构体的成员非常多，这种方法涉及大量的数据移动。在这种情况下，通过指针传递结构体对象的方法（如 9.6.3 节所述）将更高效。
4. 由于结构体对象按值传递，在调用函数的形式参数中做的更改不会反映回调用函数。程序 9-22 中的代码说明了这一事实。

### 程序 9-22：按值传递结构体对象（坐标反射演示）

```c
//点关于 x 轴倾斜 45° 直线的反射
#include<stdio.h>
struct point
{
    int x;
    int y;
};
reflectpoint(struct point);
main()
{
    struct point pt;
    printf("Enter the x and y coordinates of the point:\t");
    scanf("%d %d", &pt.x, &pt.y);
    reflectpoint(pt);
    printf("The x and y coordinates of the reflected point: %d,%d\n",pt.x,pt.y);
}
reflectpoint(struct point pt)
{
    int temp;
    temp=pt.x;
    pt.x=pt.y;
    pt.y=temp;
}
```
