## 10.1 错误与异常

编程世界中的异常是运行时异常条件，导致程序终止或错误执行。错误是程序员可能在程序中使用的非法语句或功能。错误无法修复，但异常可以处理。

![](img/4d9a4ae4efedabe01be6e6c44bad2dc1_231_0.png)

C++中的异常大致分为两种类型：

- 1. `同步异常`：此类异常只能由抛出语句产生。例如，访问数组不存在的索引元素，会引发数组索引越界异常。

- 2. `异步异常`：此类异常包括程序执行过程中出现的键盘或输入中断，并扰乱C++代码的自然流程。这些异常不直接处理，而是通过信号概念来管理。

## 10.2 异常处理

在C++中，异常使用`try-catch`块处理，我们可以抛出认为代码可能会遇到的特定异常，并在块中处理它。现在让我们熟悉在异常处理机制中将要使用的重要关键字。

- `Try`：此块用于抛出异常。我们可以测试条件，如果条件满足（为真），就抛出一个异常。`try`块后面总是跟着`catch`块。

- `Catch`：此块在抛出异常时使用。它给出了捕获异常后会发生什么，以及如何使用异常处理器进行管理。一个`try`块后面可以跟多个`catch`。

- `Throw`：这个关键字只是抛出一个异常，除此之外不做其他事。处理异常是`try-catch`块的责任。

`try-catch`块的语法如下：

```cpp
try {
    // code
    throw exceptionName;
}
catch () {
    // code
}
```
