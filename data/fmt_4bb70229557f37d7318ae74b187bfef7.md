
关于表达式最重要的一点是利用运算符将其合并为复合表达式和语句的方法。通过这种方式，我们将查看用于将表达式转换为更复杂的表达式和语句的运算符。

最简单的表达式类型是字面量（`literal`）或变量。字面量评估为其本身。

字面量的示例包括数字、字符串和常量。变量评估为分配给它的值。

尽管字面量或变量可能是合法的表达式，但它们本身不执行任何操作。你需要通过运算符将它们连接起来让表达式执行操作，例如数学运算或任务。运算符通过在可以评估的基础表达式之间建立连接，将表达式组合成更复杂的表达式。例如，如果你需要建立的连接是两个数值属性的总和，你将编写 `3 + 4`。数字 `3` 和 `4` 分别是实质表达式。包含 `3 + 4` 也是一个合法的表达式，在这种情况下，它的值恰好是 `7`。加号（`+`）是运算符。它两边的数字是它的参数，或操作数（`operands`）。参数或操作数是运算符作用的对象；例如，一个参数或操作数可能是妻子要求去洗洗碗机的指令，而丈夫执行了洗洗碗机。不同的运算符具有不同类型和数量的操作数。运算符也可以被重载，这意味着它们在不同的语境下执行不同的事情。

你可能会从此推推出通过运算符关联的两个或多个表达式被称为一个表达式。你是的，因为运算符构成了复杂的表达式。你拥有的子表达式和运算符越多，表达式就越详细越复杂。无论如何，只要它的长度可以赋予一个值，它仍然是一个表达式。

当表达式和运算符汇在一起交付一段真正执行操作的代码时，你就有一个语句。

运算符记录在 `http://www.php.net/manual/en/language.operators.php` 上。我们将讨论一些运算符，以便你尽可能快地开始使用 PHP。目前我们只浅浅地过一下。除了其主要功能外，每个运算符都有四个基本属性：

- 运算符结合性（`associativity`）
- 操作数数量
- 优先级（Order of precedence）
- 操作数类型

关于表达式，真的没有更多可以看到的，除了如何使用运算符将它们汇成复合表达式和语句。接下来我们将讨论用于将表达式转换为更复杂的表达式和语句的运算符。

## 6.2 运算符概念

PHP 有许多运算符，包括：

- 算术运算符（Arithmetic）
- 数组运算符（Array）
- 赋值运算符（Assignment）
- 位运算符（Bitwise）
- 比较运算符（Comparison）
- 递增递减运算符（Incrementing/decrementing）
- 逻辑运算符（Logical）
- 字符串运算符（String）

运算符记录在 `http://www.php.net/manual/en/language.operators.php` 上。我们将讨论一些运算符，以便你尽可能快地开始使用 PHP。目前我们只浅浅地过一下。最简单的选择是从操作数开始。

### 1. 操作数数量

运算符具有不同数量的操作数。许多运算符用于将两个表达式连接成更复杂的表达式；这些被称为二元运算符。运算符包括乘法、减法、加法和除法。

某些运算符一个操作数；这些被称为一元运算符。考虑负运算符（`-`）将数值乘以 `-1`。第 3 章描述的递增和递减运算符也是一元运算符。

三元运算符接受三个操作数。稍后讨论条件判断时的简写语句接受三个操作数。

### 2. 操作数类型

你应该意识到运算符工作时期的操作数类型，因为某些运算符预期其操作数是特定的数据类型。

PHP 试图通过将操作数转换为运算符预期的数据类型来简化你的工作。然而，某些情况下，自动转换是不可能的。

算术运算符是你应该留心类型的一个例子。它们只接受数字作为操作数。例如，当你尝试乘以两个字符串时，PHP 可以将字符串转换为数字。虽然 `"Becker" * "Furniture"` 不是合法的表达式，但它返回 `0`。然而，一个没有错误的转换表达式是 `"70" * "80"`。这导致了 `5600`。

`(float)`, `(twofold)`, `(genuine)`

转换为浮点数，即可能包含小数部分的数字。

`(string)`

转换为字符串。

`(array)`

转换为数组。

`(object)`

转换为对象。

要使用强制类型转换（cast），请将其放置在需要转换的变量之前。如示例 6.2 所示，`$test_string` 变量具有字符串 `1234`。

# 示例 6.2. 抛出变量

```php
$test=1234;
$test_string = (string)$test;
```

请记住，在特定类型之间进行强制转换时，会发生什么可能显而易见。如果你在控制变量类型的时刻不加留心，你可能会反复遇到困难。

某些二元运算符（例如赋值运算符）对左侧操作数有进一步的限制。由于赋值运算符正在给左侧操作数分配值，它必须是一个可以接收值的类型，例如一个变量。

# 示例 6.3. 左值表达式

```php
3 = $locations;/ // 糟糕 - 无法向精确的 3 分配值
$a + $b = $c; // 糟糕 - 左侧的表达式不是一个变量
$c = $a + $b; // OK
```

有一种更简单的方法可以记住这一点。赋值操作中的左侧表达式被称为左值（L-value）。PHP 中的左值是变量、数组组件和对象属性。

## 优先级

运算符的优先级决定了表达式中哪个运算符先被处理。例如，乘法和除法在加法和减法之前被处理。你可以在 `http://www.zendend.com/manual/language.operators.php#language.operators.pr` 查看一个简化的表格。

如果多个运算符的优先级相同，它们将按照它们在表达式中出现的顺序进行处理。例如，由于乘法和除法的优先级相同，它们按照在表达式中出现的顺序进行准备。相同优先级的运算符可以在任何顺序上出现而不影响结果。

另一方面，大多数表达式没有超过一个相同优先级的运算符，而且它们处理的顺序不会改变结果。如示例 6.4 所示，在对连续的数字进行加减运算时，先加还是先减是没有区别的——结果仍然是 `1`。

PHP 的优先级级别很少，少到如果不查阅参考资料就很难掌握它们。表 4-2 是按优先级从高到低排序的 PHP 运算符列表。相同级别的运算符优先级完全相同。

# 示例 6.4. 优先级

```php
2 + 4 - 5 == 1;
4 - 5 + 2 == 1;
4 * 5/2 == 10;
5/2 * 4 == 10;
2 + 4 - 5 == 1;
4 - 5 + 2 == 1;
```

当使用包含不同优先级级别运算符的表达式时，顺序可能会改变表达式的值。你可以利用括号 `(` 和 `)` 来覆盖优先级，或者仅仅是为了让表达式更易读。

图 6.5 展示了如何更改默认优先级。

### 图 6.5. 使用括号更改默认优先级

```php
echo 2 * 3 + 4 + 1;
echo 2 * (3 + 4 + 1);
```

结果为：
11
16

在第二个表达式中，由于括号覆盖了默认优先级，乘法最后执行。

PHP 有几个优先级级别，少到如果不查阅参考资料就很难记录。

# 结合性

所有运算符都按照特定的方向处理其运算符。这种方向被称为结合性（`associativity`），它依赖于运算符的类型。结合性决定了处理顺序，，取决于运算符的优先级。

如果多个运算符的优先级相同，它们将按照它们在表达式中出现的顺序进行处理。例如，由于它们的优先级相同，乘法和除法按照它们在表达式中出现的顺序进行准备。相同优先级的运算符可以在任何顺序上出现而不影响结果。

大多数表达式没有超过一个相同优先级的运算符，另一方面它们处理的顺序不会改变结果。如示例 6.4 所示，在对连续的数字进行加减运算时，先加还是先减是没有区别的——结果仍然是 `1`。

PHP 的优先级级别很少，少到如果不查阅参考资料就很难掌握它们。表 4-2 是按优先级从高到低排序的 PHP 运算符列表。相同级别的运算符优先级完全相同。

## 逻辑运算符

逻辑运算符通过逻辑运算符的布尔结果构建更复杂的逻辑表达式；四个逻辑运算符。

## 关系运算符

关系运算符用于比较两个值。我们在上一个章节中讨论过这些运算符。

## 相等

相等运算符，双等号 `==` 经常使用。如果两个操作数相等，则返回 TRUE；否则返回 FALSE。如果你不需要相等运算符自动转换类型，可以使用恒等运算符，三等号 `===`，它会检查类型是否相同。例如，`"1" === 1` 为假，因为类型不同。

你可能需要验证两个事物是否不同。不等运算符，感叹号等号 `!=` 检查相等的反面。

```
“1” != “A” // 真
“1” != “1” // 假
```

## 比较运算符

比较运算符测试值之间的关系。你可能在中学数学中见过它们。它们包括小于 (`<`)、小于等于 (`<=`)、大于 (`>`) 和大于等于 (`>=`)。

例如，`3<4` 是真，而`3<3` 是假，`3<=3` 是真。

比较运算符经常用于检查是否达到了某个点。例如，如果你购买五个或更多商品，在线商店可能会提供免费配送。因此，代码必须将商品数量与数字五进行比较。

## 逻辑运算符

逻辑运算符通过逻辑运算符的布尔结果构建更复杂的逻辑表达式；四个逻辑运算符。

要测试两个操作数是否为真，使用与运算符，也写为双与符号 `&&`。双与符号和 AND 都是逻辑运算符；主要区别是双与符号在 AND 运算符之前被处理。`||` 与 OR 遵循相同的原理。

要测试其中一个操作数是否为真，使用或运算符，它也写为双竖线 `||`。如果一个或两个操作数为真，则返回 TRUE。

使用或运算符可能会导致棘手的程序问题。如果 PHP 发现第一个操作数为真，它就不会评估第二个操作数。虽然这节省了执行时间，但你应该确保第二个运算符中不包含程序正常运行所需的代码。

## 条件语句

条件语句与变量一样，都是构建 PHP 开发体系的基础组件。

它们根据代码中设置的依据来改变脚本的执行流程。PHP 中有三种基本的条件语句：

- `if`
- `? :` (`if` 语句的简写)
- `switch`

当你有许多需要执行的操作，并且需要根据变量的内容采取不同的活动时，`switch` 语句非常有帮助。在本节的稍后部分，将详细介绍 `switch` 语句。

## if 语句

该语句允许在提供的条件为 **TRUE (真)** 时执行一段代码；通常情况下，该代码块不会执行。条件可以是任何表达式，包括对非零、相等性、空值、变量以及函数返回属性的测试。

无论如何，你编写的每一个条件语句都包含一个限制子。如果条件为 **TRUE**，则执行大括号 `{}` 中的代码块。如果不是，PHP 将忽略它并移动到第二个条件，继续执行所有组合的语句，直到 PHP 遇到 `else`。此时，只有当 IF 条件结果为 **FALSE (假)** 时，才会执行该块；否则，如果块中只有一行代码需要执行，则不需要大括号。`else` 解释并不总是需要的。

`else` 块必须可靠地放在最后，并被视为默认活动处理。这类似于分号 (`;`)。常见的真条件包括：

- `$var`，如果 `$var` 具有除空集 (`0`)、空字符串或 NULL 以外的属性
- `isset($var)`，如果 `$var` 具有除 NULL 以外的属性，包括空集或空字符串
- TRUE 或任何变体

我们还没有讨论第二个项目点。`isset()` 是一个检查变量是否设置过的函数。已设置的变量具有 NULL 以外的值。

`if` 语句的语法如下：

```php
if (conditional expression){
  piece of code;
}
```

如果条件块中的表达式评估结果为 **TRUE**，则执行其随后的代码块。在这种情况下，如果变量 `$username` 被设置为 `'Administrator'`，则会打印欢迎消息。如果不是，则什么都不会发生。

```php
if ($username == "Administrator") {
  echo ('Welcome to the administrator page.');
}
```

如果你只需要执行一条语句，则不需要大括号，但始终使用它们是一个良好的习惯，因为这使得代码更易读且更难被修改。

## else 语句

可选的 `else` 语句在返回条件为 **FALSE (假)** 时提供一段执行的默认代码。在没有 `if` 语句的情况下无法使用 `else`，因为它本身不接受条件。因此，在代码中，`else` 和 `if` 需要始终成对出现。

当你使用属性开始编写代码段时，请记住完成 `if` 条件判断的代码块。和 `if` 块一样，`else` 块也应该使用大括号来开始和结束代码。

## elseif 语句

上述的大部分内容都非常棒，但当你需要同时测试几个条件时例外。

要做到这一点，你可以利用 `elseif` 语句。它考虑测试额外的条件，直到发现其中一个为真或直到遇到 `else` 块。每个 `elseif` 都有其特定的代码块，专门紧跟在 `if` 条件之后。`elseif` 必须位于 `if` 语句之后，以及 `else` 语句（如果存在）之前。

```php
if ($username == "Admin"){
  echo('Welcome to the administrator page.');
} elseif ($username == "Guest"){
  echo('Please investigate around.');
} else {
  echo("Welcome back, $username.");
}
```

在这里，你可以检查两个条件，并根据 `$username` 的属性采取不同的活动。此时，你还有另一种选择，如果 `$username` 不是前两个之一，则执行其他操作。

下一个结构扩展了 `if/else` 语句的思想，但它允许你有效地检查一个表达式的多个可能结果，而无需为每个值编写一个不同的 `if/else`。

## ? 运算符

`?` 运算符是一个三元运算符，这意味着它接受三个操作数。它像语句一样工作，但从两个表达式中返回一个值。条件表达式决定了表达式的值。使用冒号 (`:`) 来分隔这些表达式，如下所示：
`{expression} ? return_when_expression_true : return_when_expression_false`

### Case 4.8. 利用 ? 运算符制作消息

```php
<?php
$logged_in = TRUE;
$user = "Administrator";
$banner = ($logged_in==TRUE)?"Welcome back, $user!":"Please login.";
echo "$banner";
?>
```

上面的示例 4.8 产生：

Welcome back, Admin!

这对于检查错误非常有帮助。然而，我们应该看看一种语句，它允许你将表达式与可能值的列表进行比较，以选择执行的代码。

## switch 语句

`switch` 语句将表达式与多个值进行比较。拥有一个表达式（如变量）是非常常见的，你需要为变量存储的每个值执行不同的代码。例如，你可能有一个名为 `$action` 的变量，它可能有 adds、modify 和 delete 等值。`switch` 语句使得根据这些值中的每一个来描述要执行的代码块变得简单。为了展示使用 `if` 语句和 `switch` 语句测试变量几个属性的差异，我们将向你展示 `if` 语句的代码（在图 6.9 中）和 `switch` 语句。

### 图 6.9. 利用 switch 测试属性

```php
if ($action == "Include") {
  echo "Perform activities for including.";
} elseif ($action == "MODIFY") {
  echo "Perform activities for modifying.";
} else ($action == "Erase") {
  echo "Perform activities for erasing.";
}
```

### Case 6.10. 利用 switch 测试属性

```php
switch ($action) {
  case "Include":
    echo "Perform activities for including.";
    echo "The greatest number of statements as you like can in.";
    break;
  case "MODIFY":
    echo "Perform activities for modifying.";
    break;
  case "Erase":
    echo "Perform activities for erasing.";
    break;
}
```

`switch` 语句通过将 `switch` 之后的值与按顺序的 `case` 进行比较来符合预期。如果没有匹配，则不执行代码。当匹配成功时，会执行代码。随后的 `case` 继续执行直到遇到 `switch` 语句或遇到 `break` 关键字。这对于具有时间顺序的步骤非常有帮助。如果客户完成了几个步骤，他可以从离开的地方继续。

`switch` 语句之后的表达式必须评估为简单类型，例如整数、字符串或数字。如果引用数组中的特定元素，则可以使用数组。

有多种方法可以引导 PHP 不执行匹配 `case` 之外。

## 6.3 跳出

如果你只需要执行匹配块的代码，请在该块的末尾放置 `break` 关键字。当 PHP 跳过 `break` 关键字时，处理将跳转到 `switch` 语句之后的行。Case 6.11 概述了没有 `break` 语句时处理是如何工作的。

### Case 6.11. 没有 break 关键字时的情况

```php
$action = "ASSEMBLE ORDER";
switch ($action) {
  case "ASSEMBLE ORDER":
    echo "Perform activities for order assembly.<br/>";
  case "PACKAGE":
    echo "Perform activities for packing.<br/>";
  case "SHIP":
    echo "Perform activities for shipping.<br/>";
}
```
