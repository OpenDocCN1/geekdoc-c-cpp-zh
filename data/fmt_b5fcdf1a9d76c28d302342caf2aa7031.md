
14 标识符列表仅声明函数参数的标识符。作为函数定义一部分的函数声明符中的空列表表示该函数没有参数。不属于函数定义一部分的函数声明符中的空列表表示不提供任何关于参数数量或类型的信息。¹

15 要使两个函数类型兼容，两者都必须指定兼容的返回类型。此外，如果两者都存在，则参数类型列表在参数数量和省略号终止符的使用上应当保持一致；相应的参数应具有兼容的类型。如果一个类型具有参数类型列表，而另一个类型由不属于函数定义、且包含空标识符列表的函数声明符指定，则参数列表不应有省略号终止符，且每个参数的类型应与应用默认参数提升后得到的类型兼容。如果一个类型具有参数类型列表，而另一个类型由一个包含（可能为空）标识符列表的函数定义指定，则两者在参数数量上应当一致，且每个原型参数的类型应与对相应标识符类型应用默认参数提升后得到的类型兼容。在确定类型兼容性和复合类型时，每个用函数类型或数组类型声明的参数都应视为调整后的类型，而每个用限定类型声明的参数都应视为其声明类型的未限定版本。

16 示例 1 如下声明

```
int f(void), *fip(), (*pfi);
```

声明了一个没有参数且返回 `int` 的函数 `f`，以及一个指向无参数说明且返回 `int` 指针的指针 `pfi`。比较两者特别有用。`*fip` 的绑定是 `*(f())`，因此该声明暗示（表达式中的相同构造要求）调用函数 `fip`，然后通过指针间接得到一个 `int`。在声明符 `(*pfi)()` 中，额外的括号是必要的，用以指示指向指针的间接操作得到一个函数；返回 `int`。参见“未来语言”（6.1.6）。如果两个函数类型都是“旧式”，则不比较参数类型。如果声明符出现在任何函数之外，则标识符具有文件作用域和外部链接。如果声明发生在函数内部，则 `f` 和 `fip` 的标识符具有文件作用域或外部链接，取决于这些标识符的文件作用域声明，而 `pfi` 的标识符具有文件作用域且没有链接。

示例 2 如下声明

```
int (*pfi[3]) (int *x, int *y);
```

声明了一个包含三个返回 `int` 函数指针的数组 `pfi`。每个函数有两个指向 `int` 指针的参数。标识符 `x` 和 `y` 仅用于描述性声明，并在 `pfi` 声明结束时离开作用域。

示例 3 如下声明

```
int (*pfi) (*long), int), ...);
```

声明了一个函数 `fpfi`，它返回一个指向返回 `int` 的函数的指针。`fpfi` 有两个参数：一个指向返回 `int` 的函数的指针（带有一个类型为 `long` 的参数），以及一个 `int`。`fpfi` 返回的指针指向一个有一个参数并接受零或多个任意类型参数的函数。

示例 4 下原型具有一个变修改参数。

```
void addscalar(int n, int m, double a[n][m], double x);

int main() {
    double b[4][3];
    addscalar(4, 2, b);
    return 0;
}

void addscalar(int n, int m, double a[n][m], double x) {
    for (int i = 0; i < n; i++) {
        for (int j = 0, k = n*m; j < k; j++) {
            // a 是指向大小为 n*m 的 VLA 的指针
            a[i][j] += x;
        }
    }
}
```

示例 5 以下所有都是兼容的原型声明符。

```
double maximum(int n, int m, double a[n][m]);
double maximum(int n, int m, double a[*][*]);
double maximum(int n, int m, double a[][]);
double maximum(int n, int m, double a[ ][m]);
```

同样还有：

```
void f(double (*restrict a)[5]);
void f(double a[restrict][5]);
void f(double a[restrict] static[5]);
```

（注意，最后一个声明还规定了 `f` 的任何调用中对应 `a` 的参数必须是指向至少三个大小为 5 的数组的非空指针，而其他的并非。）

## 6.7.7 类型名

### 语法

```
type-name:
  specifier-qualifier-list abstract-declarator-declarator_opt
abstract-declarator:
  pointer
    pointer_opt direct-abstract-declarator
direct-declarator:
  ( abstract-declarator )
  direct-abstract-declarator_opt [ type-qualifier-list_opt
    assignment-expression_opt ]
  direct-abstract-declarator_opt [ static type-qualifier-list_opt
    assignment-expression ]
  direct-abstract-declarator_opt [ type-qualifier-list static
    assignment-expression ]
  direct-abstract-declarator_opt [ * ] ( parameter-type-list_opt )
```

### 语义

在几种上下文中，有必要指定类型。这是通过使用类型名来实现的，类型名在语法上是该类型函数或对象的一个省略了标识符的空声明。¹

### 示例 构造构造

- (a) `int`
- (b) `int *`
- (c) `int *[3]`
- (d) `int (*) [3]`
- (e) `int (*) [*]`
- (f) `int *`
- (g) `int (*) (void)`
- (h) `int (*const [1]) (unsigned int, ...)`

对应的类型分别为 (a) `int`，(b) 指向 `int` 的指针，(c) 三个 `int` 指针数组，(d) 指向三个 `int` 数组的指针，(e) 指向不数量 `int` 的指针，(f) 返回 `int` 的无参数说明函数。(g) 指向返回 `int` 的函数的指针，以及不数量的常量指针数组，每个指针有一个类型为 `unsigned int` 的参数和不数量的其它参数，返回 `int`。

## 6.7.8 类型定义

### 语法

```
typedef-name:
    identifier
```

### 约束

如果类型名指定变修改类型，则应具有块作用域。

### 语义

在存储类型类说明符为 `typedef` 的声明中，每个声明符定义一个标识符为类型名，按照 6.7.6 述的方式指定该标识符的类型。变长声明相关的数组大小表达式在每次遇到类型名时都会求值。类型定义不引入新类型，仅是指定类型的别名。也就是说，在以下声明中：

```
typedef T type_ident;
type_ident D;
```

`type_ident` 被定义为类型名，其类型由 `T` 中的声明说明符指定（称为 `T`），而 `D` 中的标识符具有类型“派生声明符类型列表”，其中派生声明符类型列表由 `D` 的声明符指定。

示例 1 声明后

```
typedef struct s1 { int x; } t1, *tp1;
typedef struct s2 { int x; } t2, *tp2;
```

类型 `t1` 和 `t1` 指向的类型与 `struct s1` 类型兼容。

`s1`，与类型 `struct s2`, `t2` 不兼容，指向的类型是 `tp2`，或 `int`。

## 示例 3 以下晦涩的构造

```c
typedef signed int t;
typedef int plain;
struct {
    unsigned t:4;
    const t:5;
    plain r:5;
};
```

声明一个类型为 `signed int` 的类型定义名 `t`，类型定义名 `t` 包含 [0, 15] 范围内的值，一个无名的 `const` 限定的位域（如果可以访问）将包含 [-15, +15] 或 [-16, +15] 范围内的值，而命名的 `r` 包含 [0, 31] 或 [-15, +15] 范围之一的值（范围的选择由实现定义）。前两个位域声明的区别在于，`unsigned` 是一个类型限定符（强制使 `t` 成为结构体成员的名字），而 `const` 是一个类型限定符（被修改的 `t` 仍然作为类型定义名可见）。如果在内部作用域中紧接着这些声明

```c
t f(t (t));
long t;
```

则声明了一个函数 `f`，其类型为“返回 `signed int` 的函数，带有一个类型为指向返回 `signed int` 且带有一个类型为 `signed int` 的无名参数指针”，以及一个类型为 `long int` 的标识符 `t`。

## 示例 4 另一方面，类型定义名可以用于提高代码的可读性。以下三个 `signal` 函数的声明指定了完全相同的类型，第一个没有使用任何类型定义名。

```c
typedef void fv(int), (*pfv) (int);
void (*signal(int, void (*)) (int);
f *signal(int, f *);
pfv signal(int, pfv);
```

## 示例 5 如果类型定义名表示变长数组类型，则数组的长度在定义类型定义名时固定，而不是每次使用它时固定：

```c
void copyopt(int n)
{
    typedef int B[n]; // B 是 n 个 int，n 在此时求值
    n += 1;
    B a; // a 是 n 个 int，n 未经过 += 1
    int b[n]; // a 和 b 的大小不同
    for (int i = 1; i < n; i++)
        a[i-1] = b[i];
}
```

## 6.7.9 初始化

### 语法

```c
initializer:
    assignment-expression
    { initializer-list }
    { initializer-list , }
ninitializer-list:
    designation_opt initializer
    initializer-list , designation_opt initializer
designation:
    designator-list =
designator-list:
    designator
    designator-list designator
designator:
    [ constant-expression ]
    . identifier
```

### 约束

任何初始化器均不应为被初始化实体之外包含的对象提供值。

被初始化对象的类型应为未知大小的数组，或不是变长数组类型的完整对象类型。

对于具有静态或线程存储期的的对象，初始化器中的所有表达式应为常量表达式或字符串字面量。

如果标识符的声明具有块作用域，且该标识符具有外部或内部链接，则该声明不应有标识符的初始化器。

如果指示符具有形式

```
[ constant-expression ]
```

则当前对象（下文定义）应为数组类型，且该表达式应为整数常量表达式。如果数组大小未知，则任何非负值都是有效的。

如果指示符具有形式

```
. identifier
```

则当前对象（下文定义）应为结构体或联合类型，且标识符应为该类型成员的名字。

### 语义

8 初始化器指定了存储在对象中的初始值。

9 除另有明确说明外，出于本子句的目的，结构体和联合中的无名成员不参与初始化。

10 如果具有自动存储期的对象未显式初始化，其值是不确定的。如果具有静态或线程期的对象未显式初始化，则：

- 如果它是指针类型，则初始化为空指针；
- 如果它是算术类型，则初始化为（符号零）；
- 如果它是聚合体，则每个成员根据这些规则递归初始化，任何填充初始化为零；
- 如果它是联合体，则第一个成员根据这些规则递归初始化，任何填充初始化为零；

11 标量的初始化器应为单个表达式，可选地包含在大括号中。对象的初始值为表达式的值（经过转换后）；标量的类型约束与简单赋值相同，取其类型为声明的限定版本。

12 本子句的其余部分处理聚合体或联合体对象的初始化。

13 对于具有自动存储期的结构或联合体对象，初始化器应为下述的初始化列表或兼容结构或联合类型的单一表达式。在后者的情况下，对象的值（包括无名成员）为表达式的值。

14 字符类型的数组可以使用字符字面量或 UTF-8 字面量初始化，可选地包含在大括号中。字面量的连续字节（如果有空间或数组大小未知，则包含终止字符）初始化数组元素。

15 与 `char_t`、`char16_t` 或 `char32_t` 匹配数组可以使用带有相应前缀（L、u 或 U）的宽字面量初始化，可选地包含在大括号中。字面量的连续字符（如果有空间或数组大小未知，则包含终止字符）初始化数组元素。

16 否则，聚合体或联合体对象的初始化器应为初始化器的花括号列表。

每个花括号初始化列表都有一个关联的当前对象。当存在指示符时，当前对象的成员根据当前对象的类型初始化：数组元素按下标顺序、结构体成员按声明顺序、以及联合体的第一个成员。相比之下，指示符会导致后续初始化器从指示符描述的子对象开始初始化。初始化随后按顺序继续，从指示符描述的下一个子对象开始。

每个指示符与其关联的花括号对开始其描述。指示符列表中的每项（按顺序）指定其当前对象的特定成员，并将下一个指示符（如果有）的当前对象变为该成员。指示符列表结束时的当前对象是被后续初始化的子对象。

初始化应按初始化列表顺序进行，为特定对象提供的每个初始化器都会覆盖之前列出的同一对象的初始化器。所有未初始化的主体均应隐式地按具有静态存储期的对象初始化。

如果花括号列表中的初始化器少于聚合体的元素或成员，或者用于初始化数组的字符串字面量字符少于数组元素，则聚合体的剩余部分应隐式地按具有静态存储期的对象初始化。

如果初始化了一个大小未知的数组，其大小由具有显式初始化器的最大索引元素决定。数组类型在它的初始化列表结束时完成。

初始化列表中的表达式的求值顺序彼此之间是不确定顺序（indeterminately sequenced），因此任何副作用发生的顺序是未指定的。¹152)

示例 1 假设已包含 `<complex.h>`，以下声明：

```c
int i = 3.5;
double complex c = 5 + 3 * I;
```

定义了 `i` 并将其初始化为值 `c` 以及值 `5.0 + i`。

示例 2 声明：

```c
int x[] = { 1, 3, 5 };
```

定义并初始化 `x` 为一个具有三个元素的一维数组对象，因为没有指定大小，且有三个初始化器。

示例 3 声明：

```c
int y[4][3] = {
{ 1, 3, 5 },
{ 2, 4, 6 },
{ 3, 5, 7 },
};
```

这是一个带有全括号初始化的定义：1, 3 和 5 分初始化了 `y` 的第一行（数组对象 `y[0]`），即 `y[0][0]`、`y[0][1]` 和 `y[0][2]`。同样地，接下来的两行 `y[1]` 和 `y[2]`。初始化器提前结束，`y[3]` 被初始化为零。也可以达到完全相同的效果：

```c
int y[4][3] = {
{ 1, 3, 5, 2, 4, 6, 3, 5, 0 },
};
```

`y[0]` 的初始化器没有以左括号开头，因此使用了列表中的三个元素。同样，接下来的三个元素依次用于 `y[1]` 和 `y[2]`。

示例 4 声明：

```c
int z[4][3] = {
{ 1 }, { 2 }, { 3 }, { 4 },
};
```

按指定初始化了 `z` 的第一列，并将其余部分初始化为零。

示例 5 声明：

```c
struct { int a[3], b; } w[] = { 1 }, { 2 };
```

这是一个带有不一致括号初始化的定义。它定义了一个包含两个结构的数组：`w[0].a[0]` 为 1，`w[1].a[0]` 为 2；所有其他元素均为 0。

152) 特别地，求值顺序不需要与子对象初始化的顺序一致。

```c
short q[4][3][2] = {
 { 1 },
  { 2, 3 },
  { 4, 5, 6 }
};
```

包含一个不完整但括号一致的初始化。它定义了一个三维数组对象：`q[0][0][0]` 为 1，`q[1][0][0]` 为 2，`q[1][0][1]` 为 3，而 4, 5 和 6 分别初始化了 `q[2][0][0]`。`q[2][0][1]` 为 1，`q[2][1][0]` 为 2；其余部分均为零。`q[0][0][0]` 的初始化器没有以左括号开头，因此可以使用当前列表中的最多六项。由于这里只有一个，所以其余五个元素的值被初始化为零。同样，`q[1][0]` 和 `q[2][0]` 的初始化器没有以左括号开头，因此每个都使用了最多六项，初始化了它们各自的二维子聚合。如果任何列表中的项目多于六项，则会发出诊断信息。
