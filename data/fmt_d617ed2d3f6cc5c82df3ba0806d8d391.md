# iPad 编程

这本快速上手指南将让你迅速编写 iPad 应用程序。你将结合熟悉的 iPhone API 以及新的 API 和专为创建 iPad 应用程序设计的额外模板。你将学习关于以下的所有内容：

- 从 iPhone 迁移到 iPad
- 使用新的分屏视图
- 使用手势在大屏幕上进行有效交互
- 与弹出框和模态对话框交互
- 创建和使用自定义键盘
