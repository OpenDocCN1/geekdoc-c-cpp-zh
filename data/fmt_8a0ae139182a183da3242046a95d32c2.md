### 设计策略

面向对象的系统可能会使用抽象基类来为所有外部应用程序提供一个通用且标准化的接口。然后，通过继承该抽象基类，形成以类似方式操作的派生类。

外部应用程序提供的功能（即公共函数）在抽象基类中作为纯虚函数提供。这些纯虚函数的实现则在对应于应用程序特定类型的派生类中提供。

这种架构还允许在系统定义之后轻松地向系统添加新的应用程序。

## 32. 动态内存

充分理解 C++ 中动态内存的实际工作原理，是成为一名优秀 C++ 程序员的关键。你的 C++ 程序中的内存分为两部分：

- **栈：** 函数内声明的所有变量都将占用栈中的内存。
- **堆：** 这是程序中未使用的内存，可以在程序运行时动态地分配内存。

很多时候，你事先并不知道需要在定义的变量中存储特定信息所需的内存量，所需内存的大小可以在运行时确定。

你可以使用 C++ 中的一个特殊运算符，在运行时为给定类型的变量在堆中分配内存，该运算符会返回所分配空间的地址。这个运算符称为 `new` 运算符。

如果你不再需要动态分配的内存，可以使用 `delete` 运算符，它会释放之前由 `new` 运算符分配的内存。

### new 和 delete 运算符

下面是为任意数据类型动态分配内存时，使用 `new` 运算符的通用语法。

```cpp

new data-type;

```

这里，`data-type` 可以是任何内置数据类型，包括数组，也可以是任何用户定义的数据类型，包括类或结构体。让我们从内置数据类型开始。例如，我们可以定义一个指向 `double` 类型的指针，然后请求在执行时分配内存。我们可以使用 `new` 运算符通过以下语句实现：

```cpp

double* pvalue  = NULL;  // 指针初始化为 null

pvalue  = new double;    // 为变量请求内存

```

如果空闲存储区已被用完，内存可能分配失败。因此，检查 `new` 运算符是否返回 `NULL` 指针并采取适当措施是一个好习惯，如下所示：

```cpp

double* pvalue = NULL;

if( !(pvalue = new double ))

{

    cout << "Error: out of memory." << endl;

    exit(1);

}

```

C 语言中的 `malloc()` 函数在 C++ 中仍然存在，但建议避免使用 `malloc()` 函数。`new` 相对于 `malloc()` 的主要优势在于，`new` 不仅仅分配内存，它还会构造对象，而这正是 C++ 的首要目的。

在任何时候，当你觉得一个已动态分配的变量不再需要时，可以使用 `delete` 运算符释放它在空闲存储区中占用的内存，如下所示：

```cpp

delete pvalue;        // 释放 pvalue 指向的内存

```

让我们将上述概念整合起来，形成以下示例，以展示 `new` 和 `delete` 是如何工作的：

```cpp

#include <iostream>

using namespace std;

int main ()

{

    double* pvalue = NULL;  // 指针初始化为 null

    pvalue = new double;    // 为变量请求内存

    *pvalue = 29494.99;     // 在分配的地址处存储值

    cout << "Value of pvalue : " << *pvalue << endl;

    delete pvalue;          // 释放内存。

    return 0;

}

```

如果我们编译并运行上述代码，将产生以下结果：

```text

Value of pvalue : 29495

```

### 数组的动态内存分配

假设你想为一个字符数组分配内存，即一个包含 20 个字符的字符串。使用我们上面用过的相同语法，我们可以如下所示动态分配内存。

```cpp

char* pvalue  = NULL;   // 指针初始化为 null

pvalue = new char[20]; // 为变量请求内存

```

要删除我们刚刚创建的数组，语句应如下所示：

```cpp

delete [] pvalue;        // 删除 pvalue 指向的数组

```

以下是 `new` 运算符用于多维数组的语法：

```cpp

int ROW = 2;

int COL = 3;

double **pvalue  = new double* [ROW]; // 为行分配内存

// 现在为列分配内存

for(int i = 0; i < COL; i++) {

    pvalue[i] = new double[COL];

}

```

释放多维数组内存的语法如下：

```cpp

for(int i = 0; i < COL; i++) {

    delete[] pvalue[i];

}

delete [] pvalue;

```
