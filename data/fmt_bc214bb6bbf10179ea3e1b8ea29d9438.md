
# 第 6 章 IO-STREAM 库

## 6.4 输出

流缺乏诸如 `printf` 和 `vprintf` 函数那样的格式化输出设施。虽然在流的世界中实现这些设施并不困难，但 C++ 程序几乎很少需要类似 `printf` 的功能。此外，它在潜在上是不类型安全的；完全避免这种功能可能更好。

在写入文件时，通常不使用或不需要格式化：一个 `int` 值应该作为一系列原始字节写入，而不是作为一系列从 0 到 9 的 ASCII 数字字符写入。可以使用 `ostream` 的以下成员函数来写入“二进制文件”：

- `ostream::put(char c)`：向输出流写入单个字符。由于字符是一个字节，此成员函数也可以用于将流写入到文本文件。
- `ostream::write(char const *buffer, int length)`：将存储在 `char *buffer` 中的至多 `length` 个字节写入 `ostream` 对象。字节按其在缓冲区中的存储方式写入，完全没有任何格式化。注意第一个参数是 `char const *`；写入任何其他类型都需要进行类型转换。例如，可以将一个 `int` 作为一个未格式化的字节值序列写入：

```cpp
int x;
out.write(reinterpret_cast<char const *>(&x), sizeof(int));
```

上述 `write` 写入字节到 `ostream` 的顺序取决于硬件的字节序（endian-ness）。大端字节先写入多字节值的最高位字节，小端字节先写入最低位字节。

### 6.4.1 基础输出：`ostream` 类

`ostream` 类定义了基本的输出设施。`cout`、`clog` 和 `cerr` 对象都是 `ostream` 对象。由 `ios` 类定义的所有与输出相关的设施在 `ostream` 对象中也可用。

我们使用以下 `ostream` 构造函数来定义 `ostream` 对象：

- `std::ostream object(std::streambuf* sb);`
  此构造函数创建一个 `ostream` 对象，它是现有 `std::streambuf` 对象的封装。无法定义一个纯粹的 `ostream` 对象（例如使用 `std::cout << out`）；当使用 `cout` 或其友元对象时，我们实际上在使用一个预定义的 `ostream` 对象，该对象是为标准输出定义的，并使用一个控制实际缓冲的预定义 `ostream` 对象。然而，通过传递一个空指针来定义对象是可能的。这样的对象不能用于插入（即当被插入其中时它会抛出 `ios::bad` 标志），但之后可以给它一个 `streambuf`。这种构造函数会挂起直到合适的 `streambuf` 可用（见第 14.8.3 节）。

在 C++ 源码中定义 `ostream` 类必须包含 `<iostream>` 头文件。要使用预定义的 `ostream` 对象（`std::cerr`、`std::cout` 等），必须使用 `<iostream>` 头文件。

#### 6.4.1.1 向 `ostream` 对象写入

`ostream` 类支持格式化输出和二进制输出。

插入运算符（`<<`）用于安全地将值插入到 `ostream` 对象中。这是格式化输出，因为存储在计算机内存中的二进制值会根据格式规则转换为人类可读的 ASCII 字符。

插入运算符指向接收信息的 `ostream` 对象。`<<` 的正常结合性保持不变，因此当遇到语句：

```cpp
cout << "hello " << "world";
```

时，左侧的操作数首先求值（`cout << "hello "`），并返回一个 `ostream` 对象引用（实际上是同一个 `cout` 对象）。现在，语句被简化为：

```cpp
cout << "world";
```

第二个字符串被插入到 `cout` 中。

`<<` 运算符有很多（重载的）变体，因此许多类型的变量可以插入到 `ostream` 对象中。存在期望 `int`、`double`、指针等的重载 `<<` 运算符。每个运算符都返回目前为止已插入信息的那个 `ostream` 对象，然后可以紧接着进行下次插入。

#### 6.4.1.2 定位

虽然并不是每个 `ostream` 对象都支持定位，但它们通常都支持。这意味着可以回溯已写入的流部分。定位经常用于数据库应用程序，在这些程序中可以随机访问数据库信息。

可以使用以下成员获取和修改当前位置：

- `ios::pos_type tellp()`：返回下一次写入操作将发生在文件中的当前（绝对）位置。
- `ostream::seekg(ios::off_type seek, ios::seekdir org)`：修改流的实际位置。函数期望一个 `off_type`，表示相对于 `org` 移动的字节数。步值可以是负、零或正。

步起点 `org` 是 `ios::seekdir` 枚举中的一个值。其值为：

- `ios::beg`：相对于流的开始计算。这是默认值。
- `ios::cur`：相对于流的当前位置（由 `tellp` 返回）计算。
- `ios::end`：相对于流的位置的位置。

在流之外查找或写入是允许的。超出范围写入将填充。超出末尾查找将抛出 `ios::fail` 标志。

#### 6.4.1.3 `ostream` 对象

除非在调用 `open` 之前设置了 `ios::fail` 标志且打开成功，否则标志将被清除。打开已打开的流会失败。要重新关联一个流，必须先关闭。

### 6.4.2 打开流对象的模式

在构造或打开 `ofstream`（或 `istream`，见第 6.5.2 节）对象时，可以使用以下模式或文件标志。这些值的类型为 `ios::openmode`。标志可以使用位或运算符组合。

- `ios::app`：在每次输出命令前将流重新定位到末尾（另见下文的 `ios::ate`）。如果文件不存在，则创建文件。在此模式下打开流时，文件的任何现有内容都将保留。
- `ios::ate`：初始位置位于文件末尾。请注意，*只有*当其他标志指示对象执行操作时，任何现有内容才会被保留。例如，`ofstream("zone", ios::ate)` 会重写文件，因为实现的 `ios::out` 导致了重写。如果需要防止重写现有文件，则必须指定 `ios::in` 模式。`ate` 模式仅将文件指针定位在末尾。之后，可以使用 `seekp` 在文件的中间写入信息。当使用 `app` 模式时，信息*仅*写入文件末尾（实际上忽略了 `seekp` 操作）。
- `ios::binary`：以二进制模式打开文件（用于区分文本和二进制文件的系统，如 MS-Windows）。
- `ios::in`：以只读模式打开文件。文件必须存在。
- `ios::out`：以只写模式打开文件。如果不存在则创建它。如果已存在，则重写文件。
- `ios::trunc`：初始从空文件开始。文件的任何现有内容将丢失。

以下标志组合具有特殊含义：

| in | out | 含义 |
| :--- | :--- | :--- |
| in | out | 流可以读可写。然而，文件必须存在。 |
| in | out | trunc | 流可以读可写。它会首先被（重）创建一个为空的文件。 |

一个有趣的微妙之处是，`ifstream`、`ofstream` 和 `fstream` 类的 `open` 成员有一个类型为 `ios::openmode` 的第二个参数。此相反，位或运算符（bitor operator）返回的是转换为枚举值的 `int`。关于位或运算符是否仍可以使用此处，将在后面的章节中回答（参见第 11.13 节）。

### 6.4.3 输出到内存：`ostringstream` 类

要使用设施向内存写入信息，应使用 `std::ostringstream` 对象。由于 `ostringstream` 类派生自 `iostream` 类，`ostringstream` 对象也可以使用 `iostream` 的设施。要使用和定义这些对象，必须包含头文件 `<sstream>`。此外，`ostringstream` 类提供了以下构造函数和方法：

- `ostringstream ostr(string const &init, ios::openmode mode = ios::out)`：当指定 `openmode` 为 `ios::ate` 时，`ostringstream` 对象由字符串 `init` 初始化，并进行的插入将追加到 `ostringstream` 对象的内容之后。
- `ostringstream ostr(ios::openmode mode = ios::out)`：此构造函数可以作为默认构造函数。或者，它允许使用 `ios::app` 在对象目前为止存储的信息的末尾进行强制添加。示例：

```cpp
std::ostringstream out;
```

- `std::string str() const`：返回存储在 `ostringstream` 对象内部的字符串的副本。
- `void str(std::string const &str)`：用新的初始内容重新初始化对象。

以下示例说明了 `ostringstream` 类的用法：向对象中插入了多个值。然后，将 `ostringstream` 对象包含的文本存储在 `std::string` 中，并打印其长度和内容。此类 `ostringstream` 对象通常用于进行“类型”到“字符串”的转换，例如将整数值转换为文本。由于它们是 `ostream` 类的一部分，也可以在 `ostringstream` 中使用格式标志。

这里是一个显示使用 `ostringstream` 对象的示例：

```cpp
#include <iostream>
#include <sstream>
using namespace std;

int main()
{
    ostringstream ostr("hello ", ios::ate);
    cout << ostr.str() << '\n';

    ostr.setf(ios::showbase);
    ostr.setf(ios::hex, ios::basefield);
    ostr << 12345;
    cout << ostr.str() << '\n';

    ostr << " ";
    ostr.unsetf(ios::hex);
    ostr << 12;
    cout << ostr.str() << '\n';

    ostr.str("new text");
    cout << ostr.str() << '\n';

    ostr.seekp(4, ios::beg);
    ostr << "world";
}
/*
此程序的输出：
hello 
0x3039
hello 0xfc
12
new text
world
*/
```

### 6.4.4 `put_time` 操纵符

操纵符 `std::put_time(std::tm *specs, char const *fmt)` 可将时间规范插入 `std::ostream` 对象中。时间规范由 `std::tm` 对象提供，时间的定义方式由格式字符串指定。从 `chrono::time_point` 开始，必须执行以下步骤将时间插入 `std::ostream`：

- 获取一个 `time_point`（例如 `system_clock::now()`）；
- 将时间点传递给时钟 `to_time_t` 函数，保存返回的 `time_t` 值：

```cpp
time_t secs = system_clock::to_time_t(system_clock::now());
```

- 将 `secs` 的地址传递给 `localtime` 或 `gmtime`。这些函数返回包含所需时间组件的 `std::tm` 结构体，分别表示计算机的本地时间或 GMT；
- 将 `localtime` 或 `gmtime` 的返回值与格式字符串（例如 `"%c"`）一起传递给 `put_time`，插入到 `std::ostream` 中：

```cpp
time_t secs = system_clock::to_time_t(system_clock::now());
cout << put_time(localtime(&secs), "%c") << '\n';
// 显示，例如 Mon 4 21:34:59 2019
```

一个返回 `put_time` 的值并期望 `time_point` 和格式字符串的简单函数可以处理这两个参数。例如（为了简洁省略了 `chrono::`）：

```cpp
auto localTime(time_point<system_clock> const tp, char const fmt) {
    time_t secs = system_clock::to_time_t(tp);
    return put_time(localtime(&secs), fmt);
}
// 使用方法：
cout << localTime(system_clock::now(), "%c") << '\n';
```

## 6.5 输入

`std::ws` 操纵符移除当前文件位置的所有空白字符（空格、制表符、换行符等）。即使设置了 `ios::skipws` 标志，如果存在空格字符也会移除。示例（假设输入包含 4 个空格后后跟字符 `x`）：

```cpp
cin >> ws; // 跳过空白
cin.get(); // 返回 'x'
```

`ofstream` 类允许我们写文件（类似于 C 语言的 `fopen(filename, "w")`）；`ostringstream` 类允许我们向内存写入信息（类似于 C 语言的 `sprintf`）。
