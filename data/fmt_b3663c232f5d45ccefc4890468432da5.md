
程序 D.1 的可执行版本名为 `PGMD-1.exe`，命令行 `C:\>PGMD-1 three mice` 的示例输出为：

```cpp
// 显示命令行参数的程序

#include <iostream>

using namespace std;

int main(int argc, char *argv[])

{

    int i;

    cout << "\nThe arguments were passed to main():";

    for (i = 0; i < argc; i++)

        cout << argv[i] << " ";

    cout << endl;

    return 0;

}
```
