
# 描述

## 7.29.6 扩展多字节/宽字符转换工具

头文件 `<wchar.h>` 声明了一组扩展的函数，用于在多字节字符和宽字符之间进行转换。

大多数函数——即列为“可重入的”的函数（见 7.29.6.3 和 7.29.6.4）——最后一个参数接受一个指向 `mbstate_t` 类型对象的指针，该对象用于描述在当前 `locale`（区域）的 `LC_CTYPE` 类别特定规则下，从特定多字节序列到（反之）的当前转换状态。

在输入时，每个函数都将描述的转换状态（内部的或通过参数指向）作为参数。引用对象描述的转换状态将根据需要进行修改，以跟踪关联多字节字符序列的移位状态以及在多字节字符内部的位置。

> 348 因此，一个特定的 `mbstate_t` 对象可以同时用于 `mbrtowc` 和 `mbrtowcs` 函数，只要它们被用于顺序步进同一个多字节字符字符串即可。

描述

### 7.29.6.3 多字节/宽字符函数

这些函数与 7.2.27 中对应的多字节字符函数（`mblen`、`mbtowc` 和 `wctom`）的区别在于，它们有一个额外的参数 `ps`，类型为指向 `mbstate_t` 对象的指针，该对象可以完全描述关联多字节序列的当前转换状态。如果 `ps` 为空指针，每个函数将使用其内部的 `mbstate_t` 对象，该对象在程序启动时初始化为初始转换状态；在这种情况下，函数不需要避免与其他对同一函数的其他调用产生数据竞态。其实现行为类似于没有库函数用空指针 `ps` 调用了同一个函数。

此外，与其对应的函数不同，其返回值不表示编码是否依赖状态。

### 7.29.6.3.1 `mbrlen` 函数

概要
```c
#include <wchar.h>

size_t mbrlen(const char * restrict s,
size_t n,
mbstate_t * restrict ps);
```

描述
`mbrlen` 函数等同于调用：
`brtowc(NULL, s, n, ps != NULL ? ps : &internal)`
其中 `internal` 是 `mbrlen` 函数的 `mbstate_t` 对象，但 `ps` 指定的表达式仅被求值一次。

返回值
`mbrlen` 函数返回零到 `n`（包含）之间的值、`(size_t)-2` 或 `(size_t)(-1)`。

前向引用：`mbtowc` 函数（7.29.6.3.2）。

### 7.29.6.3.2 `mbrtowc` 函数

概要
```c
#include <char.h>

size_t mbrtowc(wchar_t * restrict pwc,
const char * restrict s,
size_t n,
mbstate_t * restrict ps);
```

描述
如果 `s` 为空指针，`mbrtowc` 函数等同于调用：
`mbrtowc(NULL, "", 1, ps)`
在这种情况下，忽略 `pwc` 和 `n` 的值。

如果 `s` 不是空指针，`mbrtowc` 函数检查 `s` 开始的最多 `n` 个字节以确定完成多字节字符所需的字节数。如果函数判断多字节字符完整且有效，它将该值存储在 `pwc` 指向的对象中。结果状态为初始转换状态。

返回值
`mbrtowc` 函数根据当前状态返回第一个适用值：
- `0`：`n` 或更少字节完成空字符
- `1` 到 `n` 之间：`n` 或更少字节完成多字节字符（即已存储的值）
- `(size_t)-2`：字节贡献于不完整但可能有效的多字节字符，且所有 `n` 个字节已处理
- `(size_t)(-1)`：发生编码错误：函数将宏 `EILSEQ` 的值存储在 `errno` 中

### 7.29.6.3.3 `wcertomb` 函数

概要
```c
#include <wchar.h>

size_t wcertomb(char * restrict s,
wchar_t wc,
mbstate_t * restrict ps);
```

描述
如果 `s` 为空指针，`wcertomb` 函数等同于调用：
`wcertomb(buf, L'\0', ps)`
其中 `buf` 是内部缓冲区。

如果 `s` 不是空指针，`wcertomb` 函数确定表示 `wc` 多字节字符所需的字节数（包括任何移位），并将多字节字符表示存储在 `s` 指向的首元素的数组中。最多存储 `MB_CUR_MAX` 字节。如果 `wc` 是空宽字符，则存储一个空字节，任何移位序列恢复内部状态；结果状态为初始转换状态。

返回值
`wcertomb` 函数返回存储在数组中的字节数（包括任何移位序列）。当 `wc` 不是有效的宽字符时，发生编码错误：函数将宏 `EILSEQ` 的值存储在 `errno` 中并返回 `((size_t) -1)`;

### 7.29.6.4 可重入多字节/宽字符串函数

这些函数与 7.2.8 中对应的多字节字符串函数（`mbstowcs` 和 `wcstombs`）的区别在于，它们有一个额外的参数 `ps`，类型为指向 `mbstate_t` 的指针，指向一个可以完全描述多字节序列当前转换状态的对象。如果 `s` 为空指针，每个函数将使用其内部的 `mbstate_t` 对象，该对象在程序启动时初始化为初始转换状态；在这种情况下，函数不需要避免与其他对同一函数的调用产生竞态。

此外，与其对应的函数不同，转换源参数 `src` 具有指针指针类型。当函数存储转换结果时（即 `dst` 不是空指针），该参数所指向的指针对象将进行更新，以反映本次调用处理的源量。

## 7.29.6.4.1 `mbsrtowcs` 函数

### 摘要
```c
#include <wchar.h>

size_t mbsrtowcs(wchar_t * restrict dst,
const char ** restrict src,
size_t len,
mbstate_t * restrict ps);
```

## 描述
`mbsrtowcs` 函数将由 `src` 间接指向的数组中的多字节字符序列（从 `ps` 指向的对象所描述的转换状态开始）转换为相应的宽字符序列。如果 `dst` 不是空指针，则转换后的字符将存储在 `dst` 指向的数组中。转换将持续到包含终止空字符，该空字符也会被存储。在以下两种情况下，转换会提前停止：遇到无法构成有效多字节字符的字节序列，或者（如果 `dst` 不是空指针）已经将 `len` 个字符存储到 `dst` 指向的数组中。3350 每次转换的发生都如同调用了 `mbrtowc` 函数。

如果 `dst` 不是空指针，则 `src` 指向的指针对象将被赋值为空指针（如果转换是因为达到长度限制而停止）或最后一个转换的多字节字符之后的下一个地址（如果有的话）。如果转换是因为遇到终止空字符而停止，且 `dst` 不是空指针，则描述的最终状态为初始转换状态。

### 返回
如果输入转换遇到无法构成有效多字节字符的字节序列，则会发生编码错误：`mbsrtowcs` 函数将宏 `EILSEQ` 的值存入 `errno` 并返回 `(size_t) (-1)`；转换状态未定义。否则，它返回成功转换的多字节字符数，不包括终止空字符（如果有）。

> 350) 因此，如果 `dst` 是空指针，则 `len` 的值被忽略。

## 7.29.6.4.2 `wcsrtombs` 函数

### 摘要
