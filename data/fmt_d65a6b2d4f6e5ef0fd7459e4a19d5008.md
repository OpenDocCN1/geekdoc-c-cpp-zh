
假设 `$c(x^e) = 0$`，我们寻求当 `$k \rightarrow \infty$` 时 `$x(k) \rightarrow x^e$` 的条件，因此希望 `J` 是取有限值的。对于巡航控制问题，代价函数的设计设计使得：当状态 `x` 对应于远离期望的状态时，`c(x)` 的值很大。

## 为什么控制领域对总成本感到如此兴奋？

这种性能指标并不直观，但在控制设计中使用它作为性能指标有令人信服的理由：

- (i) “前瞻性”。有人可能会认为 `(2.24)` 看得太远了（谁在乎无穷？），但对于良好的策略，我们隐含对未来的“折扣”，即当 `$k \rightarrow \infty$` 时 `$c(k) \rightarrow 0$`。

- (ii) 总成本最优控制理论通常与平均最优控制密切相关——见本书第二部分。

- (iii) 如果 `J` 是有限值，则稳定性通常是有保证。

益处是该性能指标最抽象但最有价值的方面。第 2.4.2 节专门介绍稳定性及其与值函数的关系。该理论的一部分基于（固定策略）动态规划方程$^4$

```
$J(x) = c(x) + J(F(x)). \qquad (2.25)$
```

这可以从定义 `(2.21)` 推导出，其中：

```
$J(x) = c(x) + \sum_{k=0}^{\infty} c(x^+).$
```

其中 `x^+` 是 `(2.21)` 的解，起始于 `x^+(0) = F(x)`。

我们在这里概述了非线性状态空间模型稳定性的常用定义。第一个最基础的是平衡点 `x^e` 附近的连续性形式。令 `X(k; x_0)` 表示在初始条件 `x_0` 下时刻 `k` 时的状态；这简单就是 `x(k)`，通过 `(2.21)` 递归获得，起始于 `x(0) = x_0`。特别是，平衡属性 `(2.23)` 意味着对于所有 `k`，`X(k; x^e) = x^e`。

$^4$ 动态规划方程和贝尔曼方程交替使用，以致敬 [35]

### 李雅普夫意义上的稳定

如果对于 `ε > 0`，存在 `δ > 0` 使得 `||x_0 - x^s|| < δ`，则

> `|x(k;x_0) - x(k;x^s)|| ≤ ε` 对于所有 `k ≥ 0`.

如果初始条件接近平衡点，对于任何 `r > 0`，`B(r) = {x ∈ R^n : ||x - x^s|| < r}`。图 2.3 提供了一个说明。

这是一种弱稳定性概念，因为无法保证状态会趋于期望平衡点。后续定义增加了收敛性：

### 渐近稳定

平衡点 `x^s` 是渐近稳定的如果 `x^s` 在李雅普夫意义上稳定的，且对于某些 `δ > 0`，`||x_0 - x^s|| < δ_0`，

> `lim_{k→∞} X(k;x_0) = x^s.`

使得上述极限成立的 `x_0` 集合称为 `x^s` 的**吸引域**。

如果吸引域是整个 `X`，则平衡点是**全局渐近稳定**的：即 `δ_0 = ∞`，因此从任何初始条件开始 `x(k) → x^s`。

通常说状态模型是全局渐近稳定的。也就是说，通常强调这是系统 `(2.21)` 的属性，而不是平衡点 `x^s ∈ X` 的属性。

有时我们获得快速的收敛速率：状态模型被称为**全局指数渐近稳定**的，如果存在常数 `α_0 > 0` 和 `B_0 < ∞`，使得对于每个初始条件和 `k ≥ 0`

> `|X(k;x_0) - x^s| ≤ B_0 ||x_0 - x^s|| e^{-α_0 k}`.

构造李雅普夫函数 `V` 是建立渐近稳定性以及值函数界（以及状态过程的更通用的界）的最常用方法。通常来说，`V` 是 `X` 上的取非负值的函数，使其成为李雅普夫函数的关键属性是当 `x(k)` 很大时它是递减的：这被称为*漂移不等式*。李雅普夫函数 `V` 通常被视为到“中心”的粗略距离。

对于任何标量 `r`，令 `S_V(r)` 表示**水平集**：

> `S_V(r) = {x ∈ X : V(x) ≤ r}`.

除了 `V` 的非负性外，我们经常假设它是下紧的（inf-compact）：

- (ii) 此外，`J` 是连续的、下紧的，且仅在 `x^c` 处零。那么对于每个初始条件，`lim(k) = x^c`。

证明推至 2.4.4 节，但我们在这里注意第一步：动态规划方程 `(2.25)` 意味着对于每个 `k ≥ 0`，

```
$J(k+1) = J(k) - c(k) ≤ J(k).$
```

也就是说，`J(k)` 是递减的，因此对于每个 `k ≥ 0，x(k) ∈ S_J(r`，其中 `r = J(0)`。下紧假设意味着状态轨迹“密封”在有集 `S_J(r)` 中。

在总成本最优的背景下，书中基本的漂移不等式是*泊松不等式*：对于非负函数 `V, c: X → R_+` 以及常数 `η ≥ 0`，

```
$V(Fx) ≤ V(x) - c(x) + η.$
```

注释中解释了对法国数学学家的引用。泊松不等式是通过引入 `η` 以及不等式对动态规划方程 `(2.25)` 的松弛。

泊松不等式的定义考虑了动力学：通过结合 `(2.31)` 和 `(2.21)`，我们得到（类似于 2.30）：

```
$V(k+1) ≤ V(k) - c(k) + η, \quad k ≥ 0.$
```

**命题 2.2** 假设 `(2.31)` 且 `overline{γ} = 0`。此外假设 `V` 是连续的、下紧的，并在 `x^e` 处有唯一的最小值。平衡点在李雅普夫意义上是稳定的。

**命题 2.4** 假设 `(2.33)` 成立，并满足以下假设：
