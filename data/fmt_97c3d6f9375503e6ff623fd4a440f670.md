# 在 .NET Framework 中压缩文件

在 `.NET` 中，`System.IO.Compression` 命名空间提供了各种类，例如 `DeflateStream` 和 `GZipStream`，用于压缩文件。`DeflateStream` 类使用 `Deflate` 算法并提供各种方法和属性来压缩和解压缩文件。`GZipStream` 类也使用 `Deflate` 算法来压缩文件；然而，它可以扩展以使用其他数据压缩格式。要使用这些类，您需要使用现有流（如 `FileStream` 对象和 `StreamReader` 类）对其进行初始化。默认流大多是 `FileStream` 对象。此外，您需要指定流是用于压缩还是解压缩。
