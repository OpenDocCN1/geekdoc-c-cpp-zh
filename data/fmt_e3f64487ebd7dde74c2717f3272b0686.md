
## 6.9 一般马尔可夫链的遍历理论

那么存在一个唯一的不变概率测度 `π`。它满足 `π(f) < ∞`，并且对于满足条件的函数 `c: X → ℝ` 以下附加结论：

$$\sup_x \frac{|c(x)|}{f(x)} < \infty.$$

(i) 泊松方程 (6.23) 有解，使得 `η = π(c)` 且 

$$\sup_x \frac{|h(x)|}{V(x)+1} < \infty.$$

(ii) 假设对于每个 `r`，下水平集 `S_c(r)` 都是小集或空集，其中

$$S_c(r) = \{x \in X : c(x) \le r\}.$$

则可以选取 (i) 中的函数 `h`，使得对于每个 `x` 都有 `h(x) ≥ 0`。

在 `(V3)` 条件下也有可用的遍历定理——详情请参阅 [257]。在大多数情况下，可以获得更强的漂移条件，并从此我们几何遍历性的强形式。将李雅普夫函数解释为权重函数在随后的定义中特别有用。为此，我们假设对于每个 `x` 都有 `V(x) ≥ 1`，并对于 `c: X → ℝ` 定义：

$$\|c\| = \sup_x \frac{|c(x)|}{V(x)}$$

令 `L_V` 为该值有限的波雷尔可测函数集。我们称马尔可夫链是 `V`-均匀遍历的，如果存在一个不变测度 `π`，以及对于任意 `c ∈ L^∞_V`，存在 `ρ < 1, B < ∞`：

$$|E_x[c(X(k))] - π(c)| ≤ B^k \|c\|V(x), \quad k ≥ 0, x ∈ X.$$

或者，用算子理论的表示法，记 `~c = c - π(c)`：

$$\|P^k c\|_V ≤ Bρ^k \|c\|_V, \quad k ≥ 0.$$

**定理 6.13 (V-均匀遍历的李雅普夫条件)** 假设马尔可夫链是 `V`-不可约且非周期的，对于函数 `V: X → [1, ∞)` 符合漂移条件；对于常量 `ε > 0, b < ∞` 以及小集 `S ∈ ℬ(X)`：

$$PV(x) ≤ (1 - ε)V(x) + b 1_S(x), \quad x ∈ X.$$

则该马尔可夫链是 `V`-均匀遍历的。

我们可以确定边界 (6.59) 中的状态依赖性，这是一个极好的消息。遗憾的是，获得 `B` 或 `ρ` 的界限并不容易 [232, 256, 302, 303]。

*随机控制*意味着显式地考虑了随机扰动和噪声。马尔可夫决策过程（MDP）是一个非常特殊的用例。虽然本书的部分将专门关注 MDP，但标题旨在强调确定性控制与随机控制之间的相似性。MDP 研究的对象是取值为状态空间 `X` 的过程 `X={X(k) : k ≥ 0}`，`X` 的演化受扰动影响，控制序列 `U={U(k) : k ≥ 0}` 取值为输入（动作）空间 `U`。

### 7.1 MDP：快速介绍

在这个简短介绍中，我们假设状态和输入空间是有限或可计的。这极大简化了确定性设置下的定义。MDP 的第一个要素是转移矩阵：根据后文定义的“容许性”（admissibility）假设，`(X(k), U(k))` 是以下充分统计量：

`P{X(k+1) = x' | X(0), …, X(k), U(0), …, U(k); X(k) = x, U(k) = u} = P_u(x').`

其中右侧是在三元组 `(u, x, x')` 处的转移矩阵。更一般地，对于任何 `m, k ≥ 0` 和函数 `g: X^{m+1} → ℝ`：

`E[g(X(k), X(k+1), …, X(k+m)) | X(0), …, X(k), U(0), …, U(k)] = E[g(X(k), X(k+1), …, X(k+m)) | X(k), U(k)].`

当我们有控制马尔可夫模型的实现时，定义要少抽象得多：

```
X(k+1) = F(X(k), U(k), N(k+1)), (7.1)
```

其中 `𝒩` 是 i.i.d. 序列。转移矩阵具有显式形式：

`P_u(x, x') = P{F(x, u, N(1)) = x'}, u ∈ U, x' ∈ X.`

**马尔可夫决策过程（MDP）。** 定义需要三个要素：

- (i) 转移矩阵，对于 `x, x' ∈ X, u ∈ U`，记为 `P_u(x, x')`。
- (ii) 代价函数 `c: X × U → ℝ`，以及对于 `x ∈ X` 受集合 `U ⊆ C` 限制的输入约束。
- (iii) 目标，例如总代价：`h(x) = Σ_{k=0}^{∞} E_x[c(X(k), U(k)]`，或者平均代价：

`lim_{n → ∞} 1/n Σ_{k=0}^{n-1} E_x[c(X(k), U(k))]. (7.2)`

与确定性设置一样，策略策略很重要。对于任何策略 `φ: X → U`，如果对于每个 `k` `U = φ(X)`，则控制过程 `X` 是马尔可夫链，转移矩阵记为 `Φ_φ`：

`Φ_φ(x, x') = P_u(x, x')|_{u=φ(x)}, x, x' ∈ X. (7.3)`

对于总代价准则，对于每个 `x`，我们有：

`h^*(x) = min_{u ∈ U} c(x, u) + Σ_{x'} P_u(x, x') h^*(x')}. (7.4)`

且最优策略是状态反馈 `φ^*`，其中 `φ^*(x)` 是 (7.4) 的任何最小化值。

与确定性控制类似，规划（DP）方程的作用。在宽的假设下，最小平均代价 `η^*` 不取决于初始条件，且平均代价最优方程（ACOE）有解：

`h^*(x) + η^* = min_{u ∈ U} c(x, u) + Σ_{x'} P_u(x, x') h^*(x')$. (7.5)`

函数 `h^*` 被称为相对价值函数，最优策略再次是最小化值：

`φ^*(x) = arg min_{u ∈ U} c(x, u) + Σ_{x'} P_u(x, x') h^*(x') , x ∈ X. (7.6)`

Q-learning 的“Q-函数”是括号内的函数：

`Q^*(x, u) \overset{def}{=} c(x, u) + Σ_{x'} P_u(x, x') h^*(x'), x ∈ X, u ∈ U. (7.7)`

## 平均成本与瞬态性能界。第 6.6.2 节的观点在这里值得重复：最小化平均成本 (7.2)并不意味着我们不关心现在。

定理 6.12 告诉我们，对于一般的状态空间，我们可以预期为 `h^*` 的非负值找到 `U(k)` 的解。命题 6.4 应用于 `V = h^*` 时，在最优策略下得到以下结论：

`Σ_{k=0}^{n-1} 𝔼[c^*(X^*), U^*(k)) | X(0)=x] ≤ η^* + h^*(x)/n, n ≥ 1 x ∈ 𝕏.`

对于有限状态，几何遍历性源于非周期性，由此我们得到 `𝔼[c^*(X^*), U^*(k))] = η^* + ε_k`，其中 `ε_k` 快速收敛于 0。

`P(X(k+1) = x', ε_k = w' | X(0), …, X(k), U(0), …, U(k); X(k) = x, U(k) = u) = P_u(x, x') ν(w') 对于所有 u ∈ 𝕌, x' ∈ 𝕏, w' ∈ Ω. (7.9)`

我们本质上扩大了状态空间到 `𝕏 × Ω`，新的状态过程为 `𝒳`。对于任何准入输入，

## 符号与约定

标准的 MDP 术语在平稳策略的定义使用了“马尔可夫”（Markov）：

- 马尔可夫策略：对于映射序列 `φ_k: X → U, k ≥ 0`，`U(k) = φ_k(X(k))`。
- 平稳马尔可夫策略：`U(k) = Φ(X(k))`。

我们通常为 `φ` 选择简单的“平稳策略”甚至“策略”，这与第 2 章引入的术语“反馈律”也是同义。

这些定义通过用 `X'` 替换 `X` 扩展到随机策略。然而，每当我们需要随机化时，引入 `φ` 就很麻烦。相反，我们让 `φ` 表示随机策略，它被定义为条件概率：对于每个 `u` 和 `x`，
`P{U(k) = u | X(0), …, X(k-1), U(0), …, X(k-1)} = φ(u | x)}. (7.11)$`

命题 7.1 随后从这些定义得出：

**命题 7.1** *当输入序列 U 由平稳的（可能是随机的）策略 `φ` 定义时，可知状态过程 `X` 是一个马尔可夫链，其转移矩阵为* `P_φ(x,x') = Σ_u φ(u | x) P_u(x,x'), x,x' ∈ X. (7.12)$`

对于函数 `h: X → ℝ`，我们使用以下紧凑符号表示期望：

`P_u h(x) = Σ_{x'} φ(u | x) P_u(x,x') h(x') = E[h(X(k+1)) | X(k) = x, U(k) = u]`,
`P_u h(x) = Σ_{x'} φ(u | x) P_u(x,x') h(x') = E[h(X(k+1)) | X(k) = x]`, (13)

其中 `X` 是通过策略控制的。

*对于熟悉随机过程的人*
表达式 (7.9) 是一个要求精简符号的方程示例。通常做法是引入一个递增的 `σ`-代数序列（*滤波*）来处理该方程中的历史：

`ℱ_k = σ{X(0), …, X(k), U(0), …, U(k)}. (7.14)$`

如果“`σ`”对你来说陌生，只需将 `ℱ_k` 取为约定。在准入输入下我们有

对于任何函数 `h: X → ℝ`，

`P_u h(x) = Σ_{x'} P_u(x,x').$ (7.15c)$`

## 确定性与随机控制没有区别

此的一个证明在命题 9.6 中提出，但需要书中尚未提供的背景知识。在这里通过对比随机和确定性模型的 DP 方程提供证明。假设状态和动作空间是欧几里得空间的凸集，并考虑梯度 `∇J` 连续的函数 `J: X → ℝ`。中值定理（MVT）告诉我们，对于任意的 `x,x' ∈ X`，存在 `ϱ ∈ [0,1]` 使得
`J(x') = J(x) + ∇J(\bar{x}) · (x' - x), \bar{x} = ϱ x + (1-ϱ)x. (7.20)$`

在本节的剩余部分，我们将展示如何解释当 `J = J^*` 等于确定性流模型的总成本函数时的 MVT。对梯度施加 Lipschitz 限制是有有用的：对于 Lipschitz 约束 `L > 0`，
`|\nabla J(x') - \nabla J(x)| ≤ L|x' - x|, x,x' ∈ X. (7.21)$`

## 离散时间流模型

让我们首先考虑与（确定性）流模型 (7.17) 相关的总成本函数 `J^*`。它满足 DP 方程：
`J^*(x) = min{c(x,u) + J^*(\bar{F}(x,u))}, (7.22)$`

使用以下条件应用 MVT (7.20)：
`x' = X(k+1) 且 x = \bar{F}(x,u) \overset{=}{=} E[X(k+1) | X(k)=x, U(k)=u].`

这对于任何连续可微函数 `J` 得：
`J(X(k+1)) = J(\bar{F}(x,u)) + ∇J(\bar{F}(x,u)) · \bar{X}(k+1) (7.23)$`
`\bar{X}(k+1) \overset{=}{=} X(k+1) - \bar{F}(x,u),`
其中 `\bar{X} = qX(k+1) + (1-q)\bar{F}(x,u)`，`q` 是取值区间为 [0,1] 的随机变量。

引理 7.2 提供了确定性和随机规划方程之间的联系。令
`η(k+1) = {∇J(\bar{X}) - ∇J(\bar{F}(x,u)) · \bar{X}(k+1).`

我们有 `X - \bar{F}(x,u) = q\bar{X}(k+1)`，以证明 (7.21) 蕴含 (7.24a) 给出的 `η` 的界。

**引理 7.2** `J: X → ℝ` 是可微的，其梯度满足 Lipschitz 边界 (7.21)。对于每个 `k`，以下近似成立：令 `η = X(k)` `u = U(k)`，
`J(X(k+1)) = J(\bar{F}(x,u)) + ∇J(\bar{F}(x,u)) · \bar{X}(k+1) + η(k+1),`
`|η(k+1)| ≤ L|\bar{X}(k)||^2. (7.24a)$`

因此，对于任意的 `x,u` 和 `k`，在 (7.15) 的符号中：
`P_u J(x) = J(\bar{F}(x,u)) | X(k)=x, U(k)=u`
`η(x,u) = E[η(k+1) | X(k)=x] = E[J(X(k+1)) | X(k)=x, U(k)=u] - \bar{F}(x,u)]. (7.24b)$`

假设函数 `J` 是凸函数。詹森不等式给出了下界：

> `E[J(X(k+1)) | X(k) = x, U(k) = u] ≥ J(E[X(k+1) | X(k) = x, U(k) = u]) J(\bar{F}(x,u)).`

由 (7.24b) 可知，在这种特殊情况下，`η` 是 `(x,u)` 的非负函数。
考虑当 `J = J^*` 时应用引理。值函数满足该引理的假设，流体模型的 DP 方程 (7.22) 推导出了 MDP 模型的 DP 方程：

`J^*(x) = min_u c(x,u) - η(x) + P_u J^*(x), x ∈ X. (7.25)$`

在许多示例中，我们发现 `η` 相较于 `c` 足够小，使得 `c^*` 近似求解 ACOE。事实上，在跨度范数下，这个值要小得多：

`|\eta||_{\infty} \triangleq max_{x,u} |\eta(x,u) - g|.`

令 `q^o` 表示最小化器，`c^*(x,u) = c(x,u) - η(x,u) - q^o`，(7.22) 变为

`q^o + J^*(x) = min_u {c^*(x,u) + P_u J^*(x)}. (7.26)$`

因此，`J^*` 求解该代价函数和平均代价 `q^o` 的 ACOE。

# 连续时间流体模型

连续时间总成本的值函数 `J^*` 满足 HJB 方程：

`0 = min_u c(x,u) + f(x,u) · J^*(x)}. (7.27)$`

连续时间模型的合理性需要不同的应用 MVT (7.20)。我们像之前一样取 `x' = X(k+1)`，但现在取 `x = X(k)` 以得到：

`J(X(k+1)) = J(X(k)) + ∇J(X) · {X(k+1) - X(k)},`

`\bar{X}` 位于端点为 `X(k)` 和 `X(k+1)` 的线段上。令

`η(k+1) = {∇J(X) - ∇J(X(k)) · {X(k+1) - X(k)}}.`

**引理 7.3** 假设 `J: X → ℝ` 是可微的，且其梯度满足 Lipschitz 边界 (7.21)。对于每个 `k`，以下近似关系成立：

`J(X(k+1)) = J(X(k)) + ∇J(X) · {X(k+1) - X(k)} + η(k+1),`
`|η(k+1)| ≤ L ||X(k+1) - X(k)||^2. (7.28a)$`

因此，对于任何 `x,u`，以及：

`P_u J(x) - J(x) = ∇J(x) · \tilde{f}(x,u) + η(x/u),`

`η(x,u) = E[η(k+1) | X(k) = x, U(k) = u].`

## 7.4 频率扩展

- (iii) 离散时间流体模型的处理稍微复杂：
- (a) 流体模型变为 `x(k+1) = \bar{F}(x(k), u(k)) = x(k) - μ u(k) + α`。
- (b) 最优策略在对于每个 `k, x(k) ≥ 0` 的约束下是最大的，`Φ^*(x) = min{1, (x+α)/μ}`。这导致当 `x(k) ≤ μ - α` 时，`x(k+1) = 0`。
- (c) 总成本由 `J^*(x) = { x x ≤ μ-α x^2/(μ-α) + 1/2 x otherwise }` 给出。这通过直接计算或验证该函数求解 DP 方程 `J^*(x) = min_u{c(x,u) + J^*(\bar{F}(x,u))}`，边界条件为 `J^*(0) = 0`。

处理器中的**动态频率扩展**使用响应环境调整处理速度的算法。虽然最初是为处理器设计的 [25]，但这些思想影响了无线通信等其他应用领域。

动态频率扩展被建模为离散时间下的 MDP，使用 CRW 队列模型的变体。对于每个 `k=0,1,2,…`，`A(k)` 表示该时隙的到达，`X(k)` 是队列中等待服务的作业数，`U(k)` 是服务率。状态的演化为：

`X(k+1) = X(k) - U(k) + A(k+1), k ≥ 0. (7.32)$`

假设到达过程 `A` 是同分布的，因此形成了 MDP 模型的动态系统。一个复杂性来源是状态和输入的整数约束：每个 `k` 演变于非负整数 `X = U = ℤ_+ = {0,1,2,3...}`，并且加了约束 `U(k) ≤ x`，因此 `U(x) ∈ ℤ_+ : u ≤ x`。
