
由 (9.18b) 通过归纳法得出第 $j$ 次迭代近似之差有上界：

```
$$y_j(x)-y_{j-1}(x) \leq \frac{k^{j-1}}{j!}B|x-x_0|, \quad (9.19)$$
```

```

```
$$|y_j(x)| \leq |y_0| + \sum_{q=1}^{j} |y_q(x)-y_{q-1}(x)| \leq |y_0| + B \sum_{q=1}^{j} \frac{k^{q-1}h^q}{q!}, \quad (9.21a, b)$$
