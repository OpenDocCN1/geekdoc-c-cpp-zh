C# 中的 `while` 循环用于在指定条件变为 `true` 之前重复一个过程。让我们创建一个名为 `MyWhileLoop` 的控制台应用程序（也在 CD 上提供）来展示如何使用 `while` 循环。清单 3.5 显示了 `MyWhileLoop` 应用程序的代码：

### 清单 3.5：显示 MyWhileLoop 应用程序的代码

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MywhileLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            // Example 1
            // An example of a simple while loop
            Console.WriteLine("Loop 1:");
            int i = 0;
            while (i < 5)
            {
                Console.WriteLine("I = {0}", i);
                i++;
            }
            // Example 2
            // A while loop with a boolean
            bool flag = false;
            i = 0;

            }

        }
    }
}
```

## 使用 do...while 循环

`do...while` 循环的工作方式与 `for` 循环和 `while` 循环非常相似。`do...while` 循环不包含任何初始化语句，也不自动递增。与 `while` 循环不同，`do...while` 循环在循环末尾检查条件而不是在开头。因此，无论给定的条件是 `true` 还是 `false`，`do...while` 循环总是至少执行一次。让我们创建一个名为 `MyDoWhileLoop` 的控制台应用程序（也在 CD 上提供）来展示 `do...while` 循环的使用。

### 清单 3.6：显示 MyDoWhileLoop 应用程序的代码

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MyDoWhileLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            // First, a simple do loop that
            // increments a counter
            int i = 0;
            Console.WriteLine("Loop 1:");
            do
            {
                Console.WriteLine("I = {0}", i);
                i++;
            }
            while (i < 5);
            // Next, the same case, but using a
            // boolean rather than an index
            i = 0;
            Boolean done = false;
            Console.WriteLine("\nLoop 2:");
            do
            {
                Console.WriteLine("I = {0}", i);
                i++;
                if (i > 5)
                    done = true;
            }
            while (!done);
            // Finally, a conditional that is true before
            // You get into the loop
            do
            {
                Console.WriteLine("Into Loop 3");
            }
            while (!done);
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
```

清单 3.6 包含三个示例来展示 `do...while` 循环的使用。在第一个示例中，`do...while` 循环在 `while` 语句中指定的条件为 `true` 时显示 `i` 变量的值。第二个示例包含一个检查布尔标志的 `do...while` 循环。在第三个示例中，`while` 语句中指定的条件为 `false`，但 `while` 循环仍然执行一次。

## 使用 for 循环

`for` 循环允许你创建一个初始化、递增/递减并验证循环计数器的循环。`for` 循环可用于简单的索引或涉及数组和元素的复杂循环。C# 有几种 `for` 循环的变体，已在清单 3.7 中说明。

### 清单 3.7：显示 MyForLoop 应用程序的代码

```csharp

namespace MyForLoop
{
    class Program
```

```csharp
{
    static void Main(string[] args)
    {
        // Illustrate a simple for loop that counts from 1 to 5
        for (int i = 0; i < 5; ++i)
            Console.WriteLine("I = {0}", i);
        // Illustrate two loops to first find a letter in a string
        // and then to print it out until a space is encountered.
        // This shows you how to skip initialization in the second
        // loop
        int nPos = 0;
        string s = "this is a test of the emergency broadcast system";

        for (nPos = 0; nPos < s.Length; ++nPos)
            if (s[nPos] == 'b')
                break;
        for (; nPos < s.Length; ++nPos)
        {
            if (s[nPos] == ' ')
                break;
            Console.Write(s[nPos]);
        }
        Console.WriteLine("\n");

        // Finally, illustrate how to use the for loop
        // for something
        // other than an integer and how to change the increment
        int state = 0;
        for (double d = 0.0; d < 5.0; )
        {
            Console.WriteLine("D = {0}", d);
            switch (state)
            {
                case 0:
                    d += 0.1;
                    break;
                case 1:
                    d += 0.2;
                    break;
                case 2:
                    d += 0.5;
                    break;
            }
            state++;
            if (state > 2)
                state = 0;
        }

        Console.Write("\nPress ENTER to quit...");
        Console.ReadLine();
    }
}
```
