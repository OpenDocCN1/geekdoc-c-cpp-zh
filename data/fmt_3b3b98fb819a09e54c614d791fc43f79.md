
> ${\omega \in \Omega : \lim_{T \to \infty} \frac{1}{T} \sum_{i=0}^{T-1} c(\omega_i) = \eta\}$

其中 $c: X \to \mathbb{R}$ 是任意函数，$\eta \in \mathbb{R}$ 是任意常数。

# A.2 概率与马尔可夫背景

## A.2.2 马尔可夫链基础

我们将保持简单，假设马尔可夫链的状态空间 `X` 是有限的或计数无限的。转移矩阵记为 `P`。对于 `X` 上的每个 `μ`，在 `F` 上有一个概率测度 `P_μ`，使得 `μ` 是链的初始分布。与第 6 章中的定义一致：

> $P_{\mu}[X_0 = x] = \mu(x)$

> $P_{\mu}[X_k = x] = \sum_{x' \in X} \mu(x') P^k(x',x), \quad x \in X$，

> $E_{\mu}[g(X_k)] = \sum_{x} P_{\mu}\{X_k = x\}g(x) \quad$ 对于任意 $g: X \to \mathbb{R}$。

当 `μ` 是退化的时（即对于某个 `x` 使得 `μ(x)=1`），我们写作 `P_μ` 和 `E_x`。*移位算子*是 `Ω` 上的映射，为复杂概念提供了紧凑的语言。对于每个 `k`，移位算子 `θ^k` 将元素 `ω = {x_0, x_1, …, x_n, …} ∈ Ω` 映射到新值，通过：

> `θ^k ω = {x_k, x_{k+1}, …, x_{n+k}, …}`。

它通过如下定义随机变量 `H` 的变换：

> `(θ^k H)(ω) = H(θ^k ω)`。

因此，如果随机变量 `H` 的形式为对于函数 `h` 的 `h = h(X_0, X_1, …)`，那么

> `θ^k H = h(X_k, X_{k+1}, …, …)`。

对于某些 `n` 和 `h: X → ℝ` 特化为 `H = h(X_n)` 得：

> `θ^k H = h(X_{n+k})`

因此

> $E_{\mu}[\theta^kH | \mathcal{F}_k] = E_{\mu}[h(X_{n+k}) | \mathcal{F}_k]$

> $E_{\mu}[h(X_{n+k}) | X_k]$

> $\sum_{x'} P^n(x', x)h(x')_{x=X_k}$

根据转移矩阵的马尔可夫性质定义。

这可以被推广：对于任意初始分布 `X_0 ~ μ`，任意有界随机变量 `H`，以及固定的 `k, n ∈ ℤ_+`。

```
$E_{\mu}[\theta^k H | \mathcal{F}_k] = E_x[H]_{x=X_k} \quad \text{a.s.}[P_{\mu}]. \quad (A.4)$
```

这简洁地描述了（时间齐次的）*马尔可夫*性质。因此，注意我们将 `E_x[H]` 视为状态空间上的一个实值函数。在这里我们替换以下内容：

```
$E_x[H] = E_x[H]_{x=X_k}.$
```

## A.2.3 强马尔可夫性质

强马尔可夫性质通过公式 `(A.4)` 的显著扩展来描述。该性质的定义需要这三个要素：

- (i) 函数 `τ : Ω → ℤ_+ ∪{∞}` 是 **X** 的*停止时间*，如果对于每个 `n ∈ ℤ_+`，事件 `{τ = n}` 属于 `F_n`。也就是说，对于每个 `n`，存在一个函数 `f_n` 使得 `{τ = n} = f_n(X_0, …, X_n)`。

- (ii) 相关的移位算子 `θ^τ` 的定义与之前相同：`θ^τ H = h(X_τ, X_{τ+1}, …)`。

- (iii) 相关的 `σ` 域也定义为：`F_τ \stackrel{\text{def}}{=} {A ∈ F :{τ = n} ∩ A \text{ 对于每个 } n ∈ ℤ_+}`  `(A.5)`

这被解释为“在时间 `τ` 之前”发生的事件。

两个重要的停止时间例子，对于任意集合 `A ⊂ X`：

`τ_A \stackrel{\text{def}}{=} \min\{n ≥ 1 : X_n ∈ A\}`

`σ_A \stackrel{\text{def}}{=} \min\{n ≥ 0 : X_n ∈ A\}`

分别被称为进入 `A` 的首次时间和击中时间。

**命题 A.1** 对于任意集合 `A ⊂ X`，变量 `τ_A` 和 `σ_A` 是 **X** 的停止时间。

*证明* 随机变量 `τ_A` 和 `σ_A` 具有如下表示，对于任意 `n ≥ 1`：

```
${\tau_A = n} = f_n(X_0, \dots, X_n) \stackrel{\text{def}}{=} \mathbb{1}\{X_n \in A\} \prod_{i=1}^{n-1} \mathbb{1}\{X_i \notin A\}$,
```

```
${\sigma_A = n} = g_n(X_0, \dots, X_n) \stackrel{\text{def}}{=} \mathbb{1}\{X_n \in A\} \prod_{i=0}^{n-1} \mathbb{1}\{X_i \notin A\}$,
```

其中 `∏_{i=1}^{0} = 1`（处理 `n=1` 的情况）。对于 `n=0`，我们有 `{τ_A = 0} = f_0(X_0) = 0` 且 `{σ_A = 0} = g_0(X_0) 𝟙{X_0 ∈ A}`。□

# 数学背景

一个 `F_t`-可测的有限值随机变量 `H` 可以表示为无穷和：

```
$H = \sum_{n=0}^{\infty} h_n(X_0, \dots, X_n) \mathbb{1}\{\tau = n\}$
```

对于函数序列 `{h_n}`；这对于什么性质成立？

一个例子是随机变量 `X_τ`，其通过设置 `X_τ = X_n` 定义：

```
$X_{\tau} = X_n \mathbb{1}\{\tau = n\}$
```
