
在 C# 中，小数值有多种数据类型，取决于你想要使用的精度点数量。最小的数值值是 `float` 数据类型。最大的是 `decimal` 数据类型。小数点允许你在变量中存储多达 128 位的数字。

我们使用 `int` 数据类型定义了名为 `myNumber` 的变量。它是整数指定器的缩写。整数存储一个 32 位的数字，但你可以使用 `long` 数据类型将整数存储空间扩展到 64 位。让我们来看 `long` 变量声明。

我们在上面的语句中使用了了一个较长的整数值，以说明当你使用 `long` 数据类型时可以使用更长的数字。

再次，使用了相同的语法模板来定义变量。这次我们使用了一个小数。我们也可以使用 0 作为小数占位符。例如，以下代码也是有效的语法。

如果我们需要更长的小数值，可以使用 `double` 数据类型或 `decimal` 数据类型。`double` 数据类型允许 64 位的小数值。以下代码展示了如何声明一个 `double` 变量。

再次，我们使用了较长的小数值值，说明 `double` 数据类型可以持有多达 32 位的小数值。

接下来，我们有 `decimal` 数据类型。除非你需要高精度（例如科学计算），否则 `decimal` 数据类型很少使用。以下是小数值声明语句的示例。

### 自定义数据类型

当你使用类（classes）时，你就创建了一个自定义数据类型。你也可以使用结构体（structs）和枚举（enums）创建自定义数据类型。我们将在后续章节中介绍这些数据类型，但在创建程序时，你仍然需要理解如何定义这些变量。

### 常数

你并不总是需要为变量动态赋值。有时你只需要知道 pi 的值始终是 3.14。你不需要动态地分配这个值，因此你可以创建一个常数。常数持有永不改变的静态值。

```cs

乘法变量的工作原理相同。乘法运算符的语法与我们看过的其他运算符相同。下面的代码是乘法运算符的示例。

```
int myNumber = 3;
addedNumber = myNumber * 4;
```

我们对代码唯一的更改是星号符号 `*`，它用于指定你想将一个变量乘以另一个变量。我们将 `myNumber` 乘以 4，因此结果是 12，存储在 `addedNumber` 变量中。

我们可以使用的最后一个简单运算符是除法运算符。除法运算符的工作方式与其他运算符相同。让我们来看除法运算符的示例。

```
int myNumber = 3;
float addedNumber = myNumber / 4;
```

同样，我们做的更改是除法运算符。我们将 3 除以 4，结果是 .75。请注意，我们需要将 `addedNumber` 改为 `float` 数据类型，因为除法计算的结果是一个小数值。当你进行除法计算时，你通常希望使用 `float` 数据类型以避免代码中的错误，即使你确定每个结果都将整数。

现在我们已经看了简单运算符，可以转向那些较不为人知的运算符了。第一个是取模运算符（模运算）。取模运算符执行除法计算，但它返回的不是减去余数的结果，而是余数。让我们来看一个示例。

int myNumber = 4;

在上面的示例中，除法计算是 4 除以 3。结果是 3 进 4 一，余数为 1。因此，`addedNumber` 变量包含值 1。在使用取模运算符时记住这一点，否则你可能会得到不同的结果。

下一个运算符是递增操作。你会经常使用这个运算符，特别是在循环中——我们将在后面的章节中介绍。递增运算符将变量加 1。该运算符是变量加 1 的简写。让我们来看一个示例。

```
int j = 0;
j++;
```

上面的代码与下面的代码相同。

```
int j = 0;
j = j + 1;
```

注意，之前的版本的代码要短得多且更容易阅读。结果只是给变量 `j` 加上了 1。在这个示例中，结果是 `j` 等于 1。

你也可以以相同的方式递减变量。让我们来看递减运算符。

```
int j = 0;

```

注意，我们只是把加号替换成了减号。结果是变量 `j` 递减了 1。上面的代码与下面的代码相同。

int j = 0;

```

结果是变量 `j` 包含值 -1。

### 关系运算符

关系运算符用于我们将在后续章节中讨论的循环和条件。关系运算符在两个值（静态或动态变量）之间进行比较。在本节中，我们将介绍不同的运算符。

在许多情况下，你需要确保两个变量彼此相等。关系运算符用于 `if` 条件中，我们将使用 `if` 语法——但请知道，此操作的完整覆盖将在后面的章节中介绍。

让我们先来看相等运算符。

```
int myNumber1 = 1;
 myNumber2 = 2;
if ( myNumber1 == myNumber2)
{
  //如果条件成立，则执行这些操作
}
```

在上面的代码中，我们创建了名为 `myNumber1` 和 `myNumber2` 的两个变量，并将它们初始化为 1 和 2。显然，这两个值不相等，`if` 条件中的关系运算符返回 `false`。由于结果为 `false`，`if` 条件内部的语句不会执行。记住，如果关系运算符的结果为 `false`，则 `if` 语句括号内的任何内容都不会执行，代码执行将跳转到条件下方的任何代码。

就像相等运算符一样，你也可以识别两个变量是否不相等。使用相同的语法，让我们来看示例。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 != myNumber2)
{
//如果条件成立，则执行这些操作
}
```

我们将关系运算符更改为 `!=` 或“不等于”。在这个条件中，计算结果为 `false`，所以这次 `if` 条件内的任何语句都将被执行。

你还需要确定一个值是否大于或小于另一个变量。C# 也有这些关系运算符来为你提供这两个条件。让我们来看大于关系运算符。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 > myNumber2)
{
//如果条件成立，则执行这些操作
}
```

我们使用了相同的语法，只需将关系运算符切换为大于符号即可。在这个示例中，计算结果为 `false`，所以没有任何 `if` 语句被执行。

与大于运算符类似，让我们来看小于语句。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 < myNumber2)
{
//如果条件成立，则执行这些操作
}
```

在上面的语句中，`myNumber1` 确实小于 `myNumber2`，因此计算结果为 `true`。在这个示例中，`if` 语句括号内的语句将执行。

在之前的操作中，变量要么大于要么小于，但如果你想知道该值是否相等呢？你可以将大于和小于运算符与相等运算符结合，以检查两种条件。让我们来看大于等于运算符。

```
int myNumber1 = 1;

在上面的语句中，没有任何条件是真实的。两个变量不相等，且 `myNumber1` 不大于 `myNumber2`。因此，没有任何 `if` 语句将执行。现在让我们来看小于等于语句。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 <= myNumber2)
{
//如果条件成立，则执行这些操作
```

### 逻辑运算符

逻辑运算符允许你在语句中组合条件。你可以通过评估两个条件来控制执行流。有三个逻辑运算符：`&&`（与）、`||`（或）和 `!`（非）。

让我们首先使用上一节中使用的 `if` 条件来看 `&&` 运算符。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 < myNumber2 && myNumber1 == 2)
{
//如果条件成立，则执行这些操作
}
```

在上面的语句中，我们首先评估 `myNumber1` 是否小于 `myNumber2`。在这个示例中，结果为 `true`，但我们添加了 `&&` 逻辑运算符，所以语句在确定执行流之前必须评估第二个条件。第二个条件评估 `myNumber1` 是否等于 2。这个条件的结果为 `false`。因为我们使用了“与”，两个条件都为真时语句才会执行。由于其中之一为 `false`，`if` 语句不执行。

让我们使用相同的值但将逻辑运算符更改为或（`||`）。

```
int myNumber1 = 1;
int myNumber2 = 2;
if (myNumber1 < myNumber2 || myNumber1 == 2)
{
//如果条件成立，则执行这些操作
}
```

最后一个逻辑运算符是非（`!` 操作。非运算符改变条件的逻辑。让我们来看一些代码。

```
int myNumber1 = 1;
int myNumber2 = 2;
if (!myNumber1 == 2)
{
//如果条件成立，则执行这些操作
}
```

在上面的代码中，我们不是在评估条件是否为真，而是识别条件是否为假。因为有非运算符，你知道我们正在评估为 `false`。这个运算符有点让人困惑，但由于表达式计算结果为 `true`，非运算符将条件更改为 `false`。由于条件为 `false`，`if` 语句执行。

### 赋值运算符

你已经见过赋值运算符了。等号是赋值运算符的一个简单示例。

赋值运算符。它将一个值赋予变量。让我们再次查看一遍赋值运算符。

```
int myNumber1 = 1;
```

赋值运算符用于将值 1 赋值给 `myNumber1`。

你也可以对变量进行数学计算，并用一行代码将结果赋值给它。这是将赋值运算符与数学计算结合的一种简写代码形式。你使用我们在第一节中使用相同的数学运算符，并将它们与赋值运算符结合。

让我们来看这个例子。

```
int myNumber1 = 1;

```

在这个例子中，`myNumber1` 首先被赋值为值 1。下一条语句在变量上加 2，然后给它赋予新值。第二条语句的结果为 3 并将其赋值给 `myNumber1`。

你可以对任何其他数学操作执行相同的操作。让我们再看另一个使用乘法运算符的例子。

```
int myNumber1 = 1;
myNumber1 *= 2;
```

注意，使用的语法是相同的，只是我们使用了乘法字符。在这个例子中，`myNumber1` 乘以 2，并将该值赋值给 `myNumber1`。结果是 `myNumber1` 现在包含值 2。

运算符是任何编程语言的重要部分，包括 C#。这些运算符存在于每个主要的应用程序中，因此你需要熟悉它们，以便在任何编程语言中工作。

## 循环和 If 语句

目标：循环和 `if` 语句控制代码的执行方式。我们在上一节中看到了 `if` 语句，现在我们将结合对循环的复习深入探讨它们。

在每个程序中，你都需要根据语句的计算方式来评估语句并执行代码。循环遍历语句直到达到停止条件，而 `if` 语句评估两个条件并根据结果执行语句。在本章中，我们将向你展示如何使用这两种结构来控制代码的执行方式。

### For 循环

`for` 循环是所有循环结构中最受欢迎的。循环遍历一系列条件，直到满足停止条件。如果停止条件从不被满足，你就会创建一个无限循环，因此你总是需要记住包含停止条件。`for` 循环最受欢迎，是因为很难达到停止条件。

让我们来看你用于 `for` 循环的通用语法模板。

```
for ( init; condition; increment )
{
// 在此处执行
}
```

`for` 循环初始化一个变量，设置停止条件，然后递增初始化的变量。这三条语句用分号隔开。每次迭代时，初始化的变量都会递增，直到满足条件并退出循环。让我们来看一个例子。

```
for ( int j = 0; j < 5; j++)
{
// 在此处执行
}
```

在上面的 `for` 循环中，变量 `j` 被初始化并设为 0。你可以将变量设置为任何值，但标准是将其设置为 0，因为循环通常用于遍历数组，而这些结构从索引 0 开始。下一条语句是条件。只要 `j` 小于 5，循环就会继续。一旦 `j` 等于 5 或大于 5，循环就会执行。递增语句在每次循环后给 `j` 加 1。让我们为循环期间发生的情况增加一些细节。

```
for ( int j = 0; j < 5; j++)
{
    Console.WriteLine(j.ToString());
}
```

上述循环的输出如下。

- 0

- 1

- 2

- 3

- 4

注意值 5 没有打印，因为当 `j` 达到值 5 时，循环退出了。

当我们处理数组时，你会再次看到循环。

### While 循环

`while` 循环与 `for` 循环相似，因为它具有相同的停止条件设置。然而，`while` 循环不初始化变量，且在每次迭代后不递增。当你使用 `while` 循环时，你更有可能导致无限循环，因为没有自动递增的值，但当你有一个无法使用数值条件的可用条件时，你需要 `while` 循环。

让我们来看 `while` 循环模板。

```
while (condition)
{
    // 在此处执行
}
```

注意 `while` 循环与 `for` 循环的区别在于它只有一个条件。让我们来看一个例子。

```
while (condition)
{
    // 在此处执行
}
```

int j = 0;

{

    {

        loop = false;

    }

    j++;

}
```
