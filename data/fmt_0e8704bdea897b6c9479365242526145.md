
# 化学信息学算法手册

## 5.1 相似性与距离度量

当我们考虑距离时，较大的自然比较小的重要。在许多应用中，接近性比距离更相关。当用于描述空间的变量弱不一致时，特别是在考虑“第四维度”时：两个人在同一时间处于同一地点时会见面，但如果时间非常不同，无论差异大并不重要。相似度量（值越高表示越接近）比差异度量更有用。概念上的区别是微妙的，但它具有巨大的数学和实际影响。距离度量通常是无界的，而相似性度量的上限为 1（相同），下限为 -1（完全对立）或 0（完全无共同）。

### 5.1.1 实值向量之间的相似性

化学信息学应用中常见的成对相似性指标都始于两个比较结构的描述符值向量（`x_1` 和 `x_2`）之间的点积。最基础的是余弦系数，其点积通过单个向量幅的几何平均值进行缩放：

```
$S_{cos} = \frac{\sum(x_{1j}x_{2j})}{\sqrt{\sum x_{1j}^2 \times \sum x_{2j}^2}} \quad (5.4a)
```

余弦系数的值在 -1 到 1 之间，如果允许的描述值为非负，则在 0 到 1 之间。它源于该值等于从原点到两个向量定义的射线之间角的余弦。

另一种，点积可以通过算术平均值进行缩放得到 Dice 相似性：

```
$S_{Dice} = \frac{\sum(x_{1j}x_{2j})}{(1/2) (\sum x_{1j}^2 + \sum x_{2j}^2)} \quad (5.5a)
```

然而，化学信息学中最常用的相似性度量是 Tanimoto 系数。修正系数与 Dice 系数非常相似，但区别在于其重新缩放包含了对点积大小的修正，而不是简单地取平均值。这种改变的主要影响是扩大范围高端相似性之间的分辨率。

```
$S_{Tan} = \frac{\sum x_{1i}x_{2j}}{\sum x_{1i}^2 + \sum x_{2j}^2 - \sum x_{1i}x_{2j}} \quad (5.6a)
```

请注意，“Tan”下标并不表示与三角函数的正切函数有任何联系。

### 5.1.2 位集之间的相似性

如上文在使用曼哈顿距离时提到的，`x_1` 和 `x_2` 的元素在许多化学信息学应用中是二进制的，即它们只取 0 或 1。这类向量可以被视为位集，其中 `x_{ij} = 1` 表示 `x_i` 是集合 `j` 的成员，`x_{ij} = 0` 表示 `x_i` 不是集合 `j` 的成员。这是相似性搜索应用最大的化学信息学领域。对于结构指纹，`K` 个集合被定义为包含片段 `f_j` 作为其子结构的结构。在这种情况下，余弦系数可以重写为：

```
$S_{cos} = \frac{|x_1 \cap x_2|}{\sqrt{|x_1|^2 \times |x_2|^2}} \quad (5.6b)
```

基数始终是非负的，因此当应用于位集时，`S_{Dice}` 被下限于 0。同样，Dice 系数的二进制等效形式为：

```
$S_{Dice} = 2 \times \frac{|x_1 \cap x_2|}{|x_1| + |x_2|} \quad (5.5b)
```

最后，Tanimoto 系数的二进制等效形式（更准确地称为 Jaccard 指数 [3]）给于：

```
$S_J = \frac{|x_1 \cap x_2|}{|x_1| + |x_2| - |x_1 \cap x_2|} \quad (5.6b)
```

Tversky [4] 指出 Dice 和 Jaccard（二进制 Tanimoto）相似性可以被视为更广义相似性度量的特例。

```
$S_{Tversky} = \frac{|x_1 \cap x_2|}{|x_1 \cap x_2| + \alpha \times |x_1 - x_2| + \beta \times |x_2 - x_1|} \quad (5.7)
```

注意等方程 5.8a 中的减法 `x_1 - x_2` 代表集合差，即在 `x_1` 中被设置为 1 但在 `x_2` 中不是 1 的位集合；它不代表两个集合之间基数的差异。设置 `α = β = 1` 得到 Jaccard 相似性，而设置 `α = β = 0.5` 得到 Dice 系数。在生物信息学领域，Tversky 的泛化已用于评估非对称或模态相似性，其中 `α = 1` 且 `β = 0`（或反之）。这对于执行子结构的部分匹配变异或部分形状相似性搜索非常有用 [5–7]。

### 5.1.3 总体相似性

余弦系数实际上最遇到的是皮尔逊相关系数 `r`，在这种特殊情况下，向量 `x_1` 和 `x_2` 的元素 `x_{ij}` 本身是两个不同变量相对于平均值的观测离差（`⟨x_{1j}⟩` 和 `⟨x_{2j}⟩`）。方程 5.5a 中的定义变为：

```
$r = \frac{\sum x_{ij}y_{ij}}{\sqrt{\sum x_{ij}^2} \sqrt{\sum y_{ij}^2}} \quad (5.8)
```

其中 `x = x_1` 且 `y = x_2`。索引格式不同，但底层度量具有相同的属性。对于模型，可以证明 `r` 的绝对值等于 `y` 与 `ŷ` 之间的相关性，`ŷ` 是通过向量 `x` 的普通最小二乘 (OLS) 回归预测的 `y` 值向量。这可以推广到多元线性回归预测，其中 `y` 是基于包含若干描述符的矩阵 `X` 的预测值集合。多元相关系数 `R` 给于：

```
$R = \frac{\sum y_{ij}ŷ_{ij}}{\sqrt{\sum y_{ij}^2} \sqrt{\sum ŷ_{ij}^2}}
```

其中 `ŷ_j` 是基于向量 `[x_{1j}, x_{2j}, ..., x_{kj}]` 对离差 `y_j` 的预测值。

总体抽样的影响对于涉及全柔药效团多聚体的相似性搜索可能很重要 [5,8]。这些位图（压缩位集）代表了来自可及构象随机样本的位图并集。即使尺寸很大，对于柔性分子得到的并集位图也存在相当差异，使用上述讨论的相似性系数计算出的相似性可能是误导性的。更糟糕的是，结构自身的预期相似性小于 1，而且通常小得多。此外，该相似性的期望值取决于考虑的构象数量。可以使用随机余弦来比较位图以解决这些问题：

```
$s_{SCos} = \frac{(|x_1 \cap x_2|)}{\sqrt{|x_1 \cap x_1|^2} \times |x_2 \cap x_2|^2}} \quad (5.9)
```

* 注意 `(x_1 - x_2) + (x_1 \cap x_2) = x_1`。

其中角括号 `(( ))` 表示期望，带撇的向量基于独立取的构象样本。在实践中，总体期望通过为每个结构创建两个位图来估计。自交集的基数对每对获取，而交叉集则对所有组合取平均。

根据方程 5.8b 计算的两个相似结构之间的随机相似性可能大于 1，结构自身的相似性也是如此。然而，在实践中这些值通常很小，且随机相似性的期望上限为 1，这也是与分子自身比较时的预期相似性。

其他非确定相似性系数的随机类似物可以类似考虑。

## 5.1.4 应用

已发表的相似性搜索应用的综述超出了本文的范围。下面引用的特定论文旨在说明如何有效使用距离和相似性度量。

### 5.1.4.1 距离应用

数值描述符向量之间的距离，特别是基于从分子结构计算的属性（尺寸、极性、极化率、脂溶性等）的距离，通常用欧几里得距离 [9] 表示。历史上这类分析更多地涉及聚类分析而非相似性搜索 [10]，但在 BCUT 描述符上的虚拟搜索 [11] 成了这种泛化的显著例外。

预过滤和后过滤操作可以被视为曼哈顿距离的相似性搜索应用，只要代表存在（1）或缺失（0）的位符合，候选结构就可以“通过”。

对于足够大或复杂的、足以设置哈希指纹中大多数位点的分子，欧几里距离等测量方法可能更为合适 [28,29]。这种效应最好的理解方式是注意到：不在任一指纹中的位会减小欧几里距离，而不会影响 Tanimoto 系数或余弦系数。任何单个位被设置的概率为 `p`，某个位不在其中一个指纹中的概率为 `q = 1 - p`，而在两个指纹中均未被设置的概率为 `q^2`。如果认为指纹是相对稀疏的，则 `p` 较小且 `q^2` 接近 1。因此，在一个或两个指纹中找到某个位点是常见的且不含信息的，而特征可以通过修改描述符来更好地处理，然而可以通过尝试调整相似性度量将 `p` 保持在 0.1 以下。

这些考虑强调了任何相似性度量计算出的精确值在不同语境下意义不同，任何距离量的值也是如此。这种语境包括描述符以及其所应用的化学范围。在使用可能表现出相似生物活性的类药分子的结构指纹时，“0.85”的 Jaccard 阈值是有用的 [30]。这不能意味着在使用余弦系数对肽药效团多聚进行相似性搜索时，“0.85”是一个有用的截止值。在大多数情况下，只有相似性的顺序——即相似性排名——是有意义的，并且任何新应用都需要确定基准。幸运的是，当对原始相似性应用简单的排名变换时，许多此类尺度差异就消失了 [31]。

## 5.1.5 结合相似性

尽管 Tanimoto 系数在大多数应用中效果良好，但将其与互补的测量方法结合通常能提高性能。共识评分现在被广泛用于改进基于结构的（对接）系统的评分，类似的方法——分层数据融合 [13,32,33]——已显示出改进基于配体的相似性搜索的潜力。然而，由于不同的相似性测量值之间不可直接比较，因此通常结合的是排名，通常对每个目标使用最小排名或排名之和。中位数排名在共识评分中显示出前景 [34]，当涉及三个或更多相似性度量时，它可能作为替代技术值得探索。

关于如何结合“命中列表”（hit lists）的最佳方法已有相关工作——即优化单个目标与多个查询结构之间的相似性 [35,36]。从逻辑上讲，人们可能会认为与两个或多个查询特别相似的“命中者”本身更有可能活性，因此取相似性的平均值或排名的平均值会提高性能。然而，对于子结构指纹，发现的情况并非如此 [33]。

尽管如此，将数据融合模型扩展到多个“活性分子”的相当极端的方法有时是有效的。“涡轮搜索”（Turbo search）涉及检索与查询相似的化合物（即本身未知的活性的活性分子的近邻），至少在某些情况下提高了了性能 [37]。

### 5.2.1 引言

药物发现的第一步是识别具有新结构并能结合靶受体的先导化合物。最初这主要通过偶然发现发生，需要大量精力寻找和筛选天然产物。虚拟筛选方法为先导化合物识别提供了一种合理的替代方案，在计算机中对化合物（现有的或在组合库中易合成的）进行大规模筛选，并减少了需要实验筛选的化合物数量。得益于过去十年蛋白质晶体学的飞速发展和计算能力的提高，基于结构的虚拟筛选已被证明是加速发现过程的有用工具和行业标准 [38]。 基于结构的筛选树根据小分子对靶受体的预测亲和力对小分子数据库进行排名。起点是蛋白质的 3D（通常是晶体）结构和一个含有小分子配体的数据库。起点是蛋白质的 3D 结构和建模的小分子配体数据库。每个配体被“对接”到靶受体的结合位点，并计算一个代表亲和力的得分。这种计算通常被称为对接。

对接问题可以分解为三个部分：(1) 取向搜索，或相对于另一个分子的 3D 搜索；(2) 构象搜索，或通过扭转的搜索；以及 (3) 评分，通过评估姿态和取向/组合。原始的对接程序是 UCSF DOCK [39]，它仅处理配体/受体系统的取向搜索和评分。在原始实现中，使用球体来表示配体和通过在受体外部生成球体表示“负图像”。对于小分子，使用原子代替球体。这提供了配体和受体的相同描述，用于识别两者之间的几何拟合。取向问题简化为配体与受体球体的匹配。匹配使用图论算法进行，查看配体-球体之间的距离（图 5.1）。受体球体内配体球之间的连接距离集是一个团（clique）。大小为 4 的团足以定义配体的唯一取向。然后将配体变换，使其重叠到受体的球体上进行最终放置。

对接程序的下一个发展是将配体柔性（即构象搜索）引入该过程。处理柔性的第一种方法是将配体拆分为两个部分，分别对其进行对接，并识别可以重新连接的片段 [40]。AutoDock [41] 开发了一种完全不同的策略，通过采用退火法将构象和取向搜索合并到一个步骤中。AutoDock 的后期版本包含了进化算法 [42]，这在其他几个程序中也很流行。

蒙特卡洛方法也已成功应用 [46–50]。其他程序按取向搜索的顺序执行构象搜索，通过对接“锚点”或基础片段并逐步构建配体构象 [51,52]。这种方法在柔性单元与蛋白质具有分段作用的情况下很好地重建对接结构。在其他情况下，例如柔性单元之间存在相互间隙时，增量构建不会将柔性单元放置在间隙位置，而是放置在与受体相互作用最大的位置。最后，受体柔性也被添加到对接程序中。与配体柔性一样，构象可以预先计算或在对接过程中动态生成。第一种方法计算一系列蛋白质构象（例如来自分子动力学模拟的快照或正模式分析），然后将配体对接到蛋白质系综中 [56–59]。优势

这种集成方法的能力在于能够搜索包含骨架和侧链变化的构象空间。即时方法可能包括蛋白质侧链异构体 [45,60]、侧链和用户定义的环路 [49,61]，或者使用蛋白质结构预测的诱导拟合 [62]。后者方法虽然准确，但目前对于虚拟筛选来说还不够。

在计算出配体后，对接的最后一步是使用某种评分函数对其进行评估。后来引入了来自 UCSF DOCK 的原始评分函数——基于形状接触评分。这些函数使用了来自 AMBER [63] 或 CHARMM [64,65] 等力场中的 Lennard-Jones 和静电参数。为了通过将 `O(N^2)` 计算转换为 `O(N)` 来节省计算时间，针对每个阶段的受体电势之和预计算了网格。为了生成该网格，对力场的范德华力进行了几何近似 `A_i = √(A_{ij})`。许多基于力场的评分函数还添加了评估和排序项，通常使用 DELPHI [67] 或 ZAP [68] 进行溶液求解 [69,70]。已知许多对配体结合效率很重要的因素，许多评分程序选择使用几个直观的参数（如疏水性、溶剂化、金属结合或可旋转键数量）结合范德华能和静电能项来推导出经验评分。经验函数是通过对具有已知晶体结构和已知结合能的配体-蛋白质系统参数进行最小二乘拟合得出的 [42,45,52,71–73]。同样，为了计算速度，这些评分函数通常在网格上计算。从力场方法开始的优点是它适用于广泛的配体。当配体和受体与训练集相似时，经验方案效果良好。另一种方法是使用基于知识的函数，该函数源于结构数据库中配体-蛋白质接触频率和距离的统计分析 [74–76]。由于这些评分方法均被证明在不同情况下效果良好，许多程序开始创建结合不同评分方案的“共识”函数，事实证明这些比任何单一方案都更有预测性。对于初级评分，几种方法会对顶部命中点进行“重新评分”。例如，PostDock 过滤器 [78] 源于对蛋白质数据库 [79] 中蛋白质/配体结构的监督学习研究，结果证明其富集率提高了 9 倍。使用隐式水的通过 MM-PBSA（用于 Poisson–Boltzmann 溶剂化）或 MM-GBSA（广义 Born）短分子动力学运行也被证明可以提高富集 [80,81]。许多其他提高基于结构的亲和预测质量的因素已解决，包括水、金属和受体的质子化状态（详细综述参见参考文献 [82,83]）。已开发出额外的筛选以识别对靶具有强亲和力且具有良好药学特性的先导化合物。Lipinski 五规则 [84] 使用了一组启发式方法（如分子量、氢键等匹配大多数口服药物范围），已成为筛选标准。已开发出过滤器以去除已知的多毒性结合剂（即假阳性）[85,86]，或与 hERG 通道相互作用的化合物 [87]。基于结构的筛选已与 3D 药效团搜索和 3D 相似性搜索成功结合，为该过程增加了补充信息。基于结构的虚拟筛选仍然是先导化合物开发库中非常有用的工具。

### 5.2.2 DOCK 算法

#### 5.2.2.1 定向搜索：团检测算法

许多对接算法将定向搜索和团检测算法分开来。寻找配体-球体距离之间连接集（图 5.1）的定向搜索仍然是最常用的方法之一。该算法的后续版本使用配体原子而不是球体来对接分子。虽然在所有配体的所有团中寻找最大团（clique）是一个 NP 完全性问题，但原始算法使用了二分图，其中配体和受体节点被分配到不同的图中。在 DOCK 4.0 [51] 中，算法被改为单个对接图，每个节点代表一个配体/受体配对。该对接图以及 Bron 和 Kerbosch [89] 首次讨论的穷举搜索。

算法从（见图 5.2 和算法 5.1）一组 `T` 个总节点开始，其中 `T` 等于配体原子数乘以受体球体数。它预计算了节点之间所有的“边”。如果配体原子之间的距离在受体球体距离的残差（`distanceTol`）范围内，则两个节点之间存在边。所有边都存储在大小为 `T × T` 的 `EdgeMatrix` 中。如果不存在边，则存入 null。两个数组存储增长中的团，每个大小为 `N`。第一个是 `Clique[N]`，包含当前团的所有节点。第二个是 `NodeSearchGraph[N]`，包含所有与当前团长度一致的新节点集（每个 Index 处可以存储多达 `T` 个节点）。搜索通过从 `NodeSearchGraph[N]` 中添加一个新分支 `j` 到当前 `clique[N+1]` 中开始。`NodeSearchGraph[N+1]` 的计算方法是 `NodeSearchGraph[N]` 中剩余所有 `k` 个节点与所有与 `j` 有边的节点的交集，其测试方法是在预计算的 `EdgeMatrix` 中测试所有 `k` 个节点与 `j` 是否有边。如果存在边，则将 `k` 添加到 `NodeSearchGraph[N+1]` 中。当一个团完成时，由于无法找到更多节点或 `N` 达到 `NODESMAX` 大小，`pop_node()` 会移除团中的第 `N` 个节点，并在该位置尝试下一个节点。如果找到了，`pop_node()` 会移除第 `N-1` 个节点。回溯可以持续到位置 0，直到所有节点都经过穷举搜索。在实践中，使用 `MAXCLIQUES` 来限制找到的团的总数。
