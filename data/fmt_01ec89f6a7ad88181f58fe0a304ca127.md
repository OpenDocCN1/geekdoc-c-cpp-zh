基类初始化：在 C++ 中，基类成员数据是通过成员初始化列表初始化的。在 Java 中，使用 `super` 关键字来实现这一目标。参见列表 C.10。

## 列表 C.10 从派生类构造函数初始化基类成员

```
class A
{
    private int x;
    public A(int p)
    {
        x=p;
    }
}
class B extends A
{
    int y;
    public B(int p, int q)
    {
        super(p); //调用基类构造函数
        y=q;
    }
}
```
