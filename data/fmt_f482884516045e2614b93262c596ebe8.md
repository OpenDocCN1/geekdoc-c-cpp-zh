搜索有序列表的另一种流行且高效的算法是二分查找。二分查找有时被称为分治算法，因为它从列表的中间开始，并将搜索空间减半，直到找到值。以下是实现二分查找的函数：

### 二分查找

```c
int bSearch(const int list[], int n, int value)
{
    int top = 0, bottom = n-1, mid;
    while(top <= bottom)
    {
        mid = (top + bottom) / 2;
        if(list[mid] == value)
            return mid;
        if(list[mid] < value)
            top = mid + 1;
        else
            bottom = mid - 1;
    }
    return -1;
}
```
