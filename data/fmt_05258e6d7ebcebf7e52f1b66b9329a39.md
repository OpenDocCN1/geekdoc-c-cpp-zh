
### RETFIE 从中断返回

`PCLATU`, `PCLATH` 保持不变

**受影响的状态位：**

`GIE`/`GIEH`, `PIE`/`GIEL`

**编码：**

`0000 0000 0001 000s`

**描述：**

从中断返回。弹出栈并将栈顶 (`TOS`) 加载到 `PC` 中。通过设置高优先级或低优先级全局中断使能位来启用中断。如果 `s = 1`，则阴影寄存器 `WS`、`STATUS` 和 `BSRs` 的内容被加载到其对应的寄存器 `W`、`STATUS` 和 `BSR` 中。如果 `s = 0`，则不更新这些寄存器（默认）。

**字数：**

`1`

**周期数：**

`2`

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 无操作 | 无操作 | 从栈中弹出 PC，设置 `GIEH` 或 `GIEL` |
| 无操作 | 无操作 | 无操作 | 无操作 |

**示例：**

```
RETFIE 1

中断返回后
PC = TOS
W = WS
BSR = BSRs
STATUS = STATUS
GIE/GIEH, PIE/GIEL = 1
```

### RETLW 返回字面量到 W

**语法：**

`RETLW k`

**操作数：**

`0 ≤ k ≤ 255`

**操作：**

`k → W`,

`(TOS) → PC`,

`PCLATU`, `PCLATH` 保持不变

**受影响的状态位：**

无

**编码：**

`1100 kkkk kkkk`

**描述：**

将八位字面量 `'k'` 加载到 `W` 中。程序计数器从栈顶（返回地址）加载。高位地址锁存器 (`PCLATH`) 保持不变。

**字数：**

`1`

**周期数：**

`2`

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| :--- | :--- | :--- | :--- |
| 解码 | 读取字面量 'k' | 处理数据 | 从栈中弹出 PC，写入 W |
| 无操作 | 无操作 | 无操作 | 无操作 |

**示例：**

```
CALL TABLE ; W 包含表偏移值
              ; 表值
:
TABLE
ADWF PCL ; W = 偏移量
RETLW k0 ; 表开始
RETLW k1
:
:
RETLW kn ; 表结束

指令执行前 W = 07h
指令执行后 W = kn 的值
```

### RLCF 携带进位左移 *f*

**语法：**

`RLCF (f,{d},{a})`

**操作数：**

`0≤f≤255`

`d ∈ [0,1]`

`a ∈ [0,1]`

**操作：**

`(f<->n) → dest<n + 1>`,

`(f<0>) → C`,

`(C) → dest<0>`

**受影响的状态位：**

`C`, `N`, `Z`

**编码：**

| `0011` | `01da` | `ffff` | `ffff` |

**描述：**

寄存器 `'f'` 的内容通过进位标志位向左旋转一位。如果 `'d'` 为 `'0'`，结果放置在 `W` 中；如果 `'d'` 为 `'1'`，结果存储回寄存器 `'f'` 中（默认）。

如果 `'a'` 为 `'0'`，选择访问银行。如果 `'a'` 为 `'1'`，使用 `BSR` 选择 `GPR` 银行（默认）。如果 `'a'` 为 `'1'` 且启用了扩展指令集，则只要 `f = 95 (5Fh)`，该指令即以索引字面量偏移寻址模式操作。详情请参见 *第 24.2.3 节 “索引字面量偏移模式下的字节导向和位导向指令”*。

**字数：**

`1`

**周期数：**

`1`

**Q 周期活动：**

| Q1 | Q2 | Q3 | Q4 |
| --- | --- | --- | --- |
| 解码 | 读取寄存器 'f' | 处理数据 | 写入目标 |

**示例：**

```
RLCF REG, 0, 0

指令执行前
REG = 1110 0110
C = 0

指令执行后
REG = 1110 0110
W = 1100 1100
C = 1
```
