# 程序 6 | 冒泡排序：给定一个包含 n 个元素的列表。将它们按升序排列。

原理：

冒泡排序基于以下观察：“泡泡（或较轻的元素）在水中上升，而较重的元素下沉”。

未排序的列表最初分为两个列表——不包含元素的有序列表和包含所有元素的未排序列表。例如，未排序的列表可以分为两个部分：

| 12 | 1 | 8 | 10 | 5 | 3 |
| 12 | 1 | 8 | 10 | 5 | 3 |
| 未排序列表 | 有序列表 |

冒泡排序从左到右扫描未排序列表，当发现相邻元素顺序不对时交换它们。在完成一次迭代（也称为通过），最重的元素（即最大的）位于未排序列表的末尾，但前面的元素可能仍然无序的。未排序列表的大小减一，有序列表的大小加一。重复此过程，直到未排序列表消失且整个列表完成排序。排序如下所示：

| 未排序列表 | 未排序列表 | 有序列表 |
| :--- | :--- | :--- |
| 通过 1 | 通过 2 | |
| 通过 3 | | |
| 未排序列表 | 有序列表 | |
| 通过 4 | 通过 5 | |
