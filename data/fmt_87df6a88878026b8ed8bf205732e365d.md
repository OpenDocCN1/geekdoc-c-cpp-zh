
# `GridView` 数据控件

`GridView` 数据控件具有内置的排序、分页、更新和删除数据的功能。你还可以通过 `AutoGenerate` 属性设置列字段，以指示是否针对数据源中的每个字段自动创建绑定字段。表 26.1 列出了 `GridView` 类的不同列字段类型：

## 表 26.1：`GridView` 类的列字段类型

| Field | Description |
| --- | --- |
| `BoundField` | 显示数据源中字段的值。它是 `GridView` 控件的默认列类型。 |
| `ButtonField` | 为 `GridView` 控件中的每个项目显示一个命令按钮。它允许我们创建自定义按钮控件的列，例如 `Add` 或 `Remove` 按钮。 |
| `CheckBoxField` | 为 `GridView` 控件中的每个项目显示一个 `CheckBox` 控件。此列字段类型通常用于显示布尔值字段。 |
| `CommandField` | 显示预定义的命令按钮以执行操作，例如 `select`、`edit` 或 `delete`。 |
| `HyperLinkField` | 以超链接形式显示数据源中字段的值。此列字段类型允许你将第二个字段绑定到超链接的 URL。 |
| `ImageField` | 为 `GridView` 控件中的每个项目显示一个图像。 |
| `TemplateField` | 根据指定的模板为 `GridView` 控件中的每个项目显示用户定义的内容。此列字段类型使我们能够创建自定义列字段。 |

你还可以通过设置样式属性来自定义 `GridView` 控件的外观。不同的样式属性在表 26.2 中列出：

## 表 26.2：`GridView` 类的样式属性

| Style Property | Description |
| --- | --- |
| `EditRowStyle` | 对 `GridView` 控件中正在编辑的行执行样式设置 |
| `EmptyDataRowStyle` | 对 `GridView` 控件中在数据源不包含任何记录时显示的空数据行执行样式设置 |
| `FooterStyle` | 对 `GridView` 控件的页脚行执行样式设置 |
| `HeaderStyle` | 对 `GridView` 控件的标题行执行样式设置 |
| `PagerStyle` | 对 `GridView` 控件的分页行执行样式设置 |
| `SelectedRowStyle` | 对 `GridView` 控件中选定的行执行样式设置 |

# `DataList` 控件

现在，让我们来了解 `DataList` 控件。

`DataList` 控件是一种数据绑定控件，它使用模板来显示数据。这些模板定义了要为项显示的控件和 HTML 元素。`DataList` 控件存在于 `System.Web.UI.WebControls` 命名空间中。`DataList` 控件的继承层次结构如下：

```
System.Object

    System.Web.UI.Control

        System.Web.UI.WebControls.WebControl

            System.Web.UI.WebControls.BaseDataList

                System.Web.UI.WebControls.DataList
```
