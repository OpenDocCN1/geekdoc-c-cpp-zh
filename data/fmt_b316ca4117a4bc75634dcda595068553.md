
> 注意
> `TreeView` 控件支持 `AutoFormat` 功能，允许你从已有的格式中进行选择。`AutoFormat` 选项可以从 `TreeView` 控件的 `Smart Tag` 中选择。

`TreeView` 控件是一个功能强大的服务器控件，用于渲染树视图 UI。它具有许多属性，例如 `CheckedNodes`、`DataBindings`、`NodeIndent`、`Nodes` 和 `NodeStyle`，这些属性由 `TreeView` 类提供。有关 `TreeView` 控件类的更多信息，请参阅本章的 Immediate Solutions 部分。`TreeView` 控件的内容可以通过以下方式添加：

- 以编程方式在运行时添加
- 从外部数据源动态加载，例如 XML 文件

`TreeView` 控件也可以在设计应用程序时添加。

## 动态向 TreeView 控件添加节点

`TreeView` 控件可以在运行时动态加载数据。为此，你需要动态设置 `TreeView` 节点的属性。`TreeView` 控件有一个名为 `TreeView.Nodes` 的 `Nodes` 属性。你可以使用 `TreeView.Nodes` 属性的 `add` 方法向 `TreeView` 控件添加节点。有关 `TreeView` 类的更多信息，请参阅本章的 Immediate Solutions 部分。

## 使用 DataSource 属性向 TreeView 控件添加节点

你也可以使用 `DataSource` 属性向 `TreeView` 控件添加数据。事实上，这是一种更灵活、更易于使用的属性，用于绑定数据。通过将 `TreeView` 控件的 `DataSourceID` 属性设置为所需的文件，你可以从指定文件中加载 `TreeView` 控件的内容。目标文件可以是 XML 文件、站点地图，甚至可以从数据库中填充树视图，例如 SQL（结构化查询语言）服务器的数据库或 MS（Microsoft）-Access 的数据库。

为 `TreeView` 控件设置适当的数据源后，`TreeView` 控件会以树结构显示信息。使用 `DataSource` 属性是 `TreeView` 控件的一种灵活方法，因为你可以通过更改底层文件的内容轻松更改任何节点的文本。

## The Menu Control

`Menu` 控件是另一个 Navigation 控件，也用于显示站点导航信息。`Menu` 控件可以水平显示站点结构，也可以垂直显示。它可以用作数据绑定控件，例如将菜单控件绑定到 `SiteMapDataSource` 控件。它也可以从在运行时添加到 `Menu` 控件的 `Items` 集合中的项目中检索要显示的数据。`Menu` 控件支持使用分层数据源（如 XML 文件）进行数据绑定。您也可以使用 `Menu` 控件的 `Items` 集合在运行时向 `Menu` 控件添加数据项。`Menu` 控件由一个或多个在不同层级显示的 `MenuItem` 对象组成。每个 `MenuItem` 反过来包含用于设置单个 `MenuItem` 样式的属性。`Menu` 控件包含两种类型的菜单：

- Static menu – 指的是完全在屏幕上显示所有菜单选项的类型菜单。静态菜单的整个结构，包括父菜单项及其子菜单，都是可见的。
- Dynamic menu – 指的是包含静态部分和动态部分的菜单类型，静态部分显示在屏幕上，动态部分在用户将鼠标指针移过菜单的静态部分时出现。

### Menu Display Properties

您可以通过设置以下属性来更改 `Menu` 控件的外观：

- `Orientation` – 表示您可以将此属性设置为 horizontal 以在页面顶部或底部显示菜单。默认方向值为 Vertical。
- `StaticItemFormatString` – 表示您可以设置此属性以显示静态菜单的值。
- `DynamicItemFormatString` – 表示您可以设置此属性以显示动态菜单的值。
- `StaticPopOutImageUrl` – 表示您可以设置 `StaticPopOutImage` 的替换图像。这意味着菜单项可以悬停以显示其所有子项。默认图像将动态出现并继续用于菜单项。

### Menu Styles

`Menu` 控件在不同级别支持各种样式，例如在单个菜单项和菜单子级别上。您可以为所有菜单级别和在 Web 页面上静态和动态显示的菜单项设置样式。以下是不同的样式属性：

- `Static/DynamicMenuStyle` – 控制所有 `MenuItem` 属性的属性。它还控制诸如 `HorizontalPadding` 和 `VerticalPadding` 之类的属性。
- `DynamicMenuItemStyle` – 控制单个 `MenuItem` 属性的样式。它还包括诸如 `ItemSpacing`、`VerticalPadding` 和 `HorizontalPadding` 之类的样式属性。
- `DynamicSelectedStyle` – 设置 `TreeView` 控件中当前选中的各个节点的样式。换句话说，它可以描述为所选菜单项的样式属性集合。它还包括诸如 `HorizontalPadding`、`VerticalPadding` 和 `ItemSpacing` 之类的样式属性。
- `DynamicHoverStyle` – 设置当前选中的各个 `MenuItem` 属性的样式属性。换句话说，它可以在您将鼠标悬停在 `MenuItem` 上时为所选 `MenuItem` 设置。它还包括诸如 `ItemSpacing`、`HorizontalPadding` 和 `VerticalPadding` 之类的属性。
