# 图 15.8：生成一个简单的 TreeView 控件

使用 `TreeView` 节点编辑器对话框创建 `TreeView` 节点是借助代码帮助可以生成的最简单的 `TreeView` 形式。你也可以基于 XML 文件、`SiteMapDataSource`，甚至 SQL Server 等数据库生成 `TreeView`。

现在是时候扩展示例以基于 XML 数据生成 `TreeView` 了。为此，我们现在向解决方案中添加一个名为 `TreeViewXMLData.aspx` 的新 Web 表单。要从 XML 数据生成 `TreeView`，我们需要将 `TreeView` 控件绑定到 `XmlDataSource` 控件。首先，按如下方式向 Web 表单添加一个 `XmlDataSource` 控件：

```
<asp:XmlDataSource ID="XmlDataSource1" runat="server" DataFile="~/Navigation.xml"></asp:XmlDataSource>
```

#### 注意

你将在本书第 26 章 ASP.NET 应用程序中的数据绑定 中详细了解 `XmlDataSource` 控件。

在前面的代码中，我们使用一个名为 `Navigation.xml` 的 XML 文件作为 `XmlDataSource` 控件的数据文件。按如下方式添加 `Navigation.xml` 文件中的代码：
