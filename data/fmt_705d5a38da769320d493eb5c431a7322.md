# §13. 相位估计问题

**¶46.** 相位估计问题是量子算法中的另一项基本任务。假设 `U` 是一个酉算符 `U`，以黑盒形式给出。这仅意味着我们可以作为量子电路中的基本门来使用。此外，我们有一个 `U` 的特征向量 `|v⟩`。如果对应的特征值为 `ω = e^{i2πφ}`，则：

```
U|v⟩ = ω|v⟩.
```

将 `φ` 称为相位，我们假设 `0 ≤ φ < 1`。**相位估计**问题是：给定 `U` 和 `|v⟩`，以及 `n ∈ ℕ` 和 `ε > 0`，计算 `φ` 的 `n` 位精度的近似值，失败概率为 `ε`。如果 `|φ - φ̂| ≤ 2^{-n}`，则近似值 `φ̂` 具有 `n` 位精度。但注意，这并不意味着 `φ̂` 由尾数后 `n` 位的二进制理数表示；我们将使用额外的 `log(1+ε^{-1})` 位。

# §14. 整数因分解问题

我们的目标是整数分解。到目前为止，我们已经开发了一些量子算法工具：QFT 和相位估计。现在我们来处理整数分解的数论背景。

分解问题很容易表述：给定一个整数 `N > 2`，找到不同的质数 `pᵢ` 和幂指数 `eᵢ ≥ 1`（`i=1, ..., m`），使得

```
N = ∏_{i=1}^m pᵢ^{eᵢ},
```

正如算术基本定理保证的那样（见下文）。这可以在 `N` 的多项式时间内求解（见练习），但这不认为是多项式时间算法，因为输入的大小为 `n = ⌊log(1+N)⌋`（`N` 的二进制表示法中的位数）。目前整数分解的记录使用复杂的数域筛法方法需要 `O(exp(√n))`。我们的目标是设计一种复杂度为 `O(nᵏ)`（对于某个 `k`）的量子算法。

**51. 数论基础。** 当说“数 `n`”时，指的是一个自然数 `n ∈ ℕ`。数论的起点是整除关系：如果对于某个 `a ∈ ℤ` 使得 `n = ma`，我们说 `m` **整除** `n` 并写作 `m|n`。同样，令 `|n|` 表示因数的个数。我们说 `n ∈ ℤ⁺` 是质数，如果它恰好被两个因数（1 和 `n`）整除。这里 2 是最小的质数，它还有唯一的偶质数的特殊性。算术基本定理说，每个数 `n ≥ 2` 都有唯一的的形式表示

```
n = ∏_{i=1}^m pᵢ^{eᵢ},  m ≥ 1
```

其中 `p₁ < p₂ < ... < pₘ` 是不同的质数，且 `eᵢ ≥ 1`。如果 `n|(x-y)`，我们假设 `x ≡ y (mod n)`。我们假设学生熟悉模 `n` 的：我们可以进行加法并模 `n`。例如，`5+6 ≡ 2 (mod 9)`。因此，集合 `ℤₙ = {0, 1, ..., n-1}` 是模 `n` 的环。对于 `ℤₙ` 中的唯一值 `x`，我们将写为 `x (mod n)`。因此 mod 是一种符号。

# §14. 整数因分解问题 第 XXII 第34 页

`m, n` 的最大公约数 (GCD) 记为 `GCD(m, n)`，它是同时整除 `m` 和 `n` 的最大数。当 `n=0` 时，定义 `GCD(m,n)=0`；否则，显然 `GCD(m,n)≥1`。如果 `GCD(m,n)=1`，我们说 `m` 和 `n` 是**互质**的（或 `m` 与 `n` 相同）。我们可以在多项式时间内使用欧几里得算法计算。欧几里得算法描述简单：如果 `n₀ > n₁` 是整数，通过以下“欧几里得序列”计算 `GCD(n₀, n₁)`：

```
n₀, n₁, n₂, ..., n_{k-1}, nₖ;  k ≥ 1
n_{i+1} = n_{i-1} (mod nᵢ),  i = 1, ..., k-1
nₖ = 0 (mod n_{k-1})
```

序列的终止条件由 `nₖ ≡ 0 (mod n_{k-1})` 给出。从 (41) 可以看出

```
GCD(nᵢ, n_{i+1}) = GCD(n_{i-1}, nᵢ)
```

但根据终止条件 (42)， `n = GCD(n₀, n₁)`。这证明了欧几里得算法的正确性。例如，`GCD(15, 8) = 1` 源于序列 `15, 8, 7, 1, 0`。

我们可以从欧几里得算法中提取信息：通过序列 (40)很容易验证存在 `sᵢ, tᵢ` 使得

```
n_{i-1} = sᵢ nᵢ + tᵢ nᵢ
```

特别是，`s, t ∈ ℤ` 使得 `GCD(m,n) = sm + tn`。因此 `sm ≡ GCD(m,n) (mod n)`。当 `m, n` 互质时，我们得出 `sm ≡ 1 (mod n)` 且 `tn ≡ 0 (mod n)`。因此 `s` 是 `m` 模 `n` 的**逆**，`t` 是 `n` 模 `m` 的逆。我们写为 `s = m^{-1} (mod n)`。总结每个与 `n` 互质的元素 `m` 模 `n` 都有逆。使用欧几里得算法计算 `sᵢ` 很容易的。因此我们可以计算逆。

由于 `Zₙ*` 中的每个元素都有模 `n` 的逆，且 1 是模 `n` 的乘法单位，我们将 `Zₙ*` 构建为模 `n` 法的群。函数 `φ(n)` 是 `Zₙ` 中与 `n` 互质值的个数。例如，如果 `n=pᵏ`，则 `φ(pᵏ)=pᵏ-p^{k-1}`，因为 `Z_{pᵏ}` 中的元素正是那些 `p` 的倍数。事实上，对于每个 `i ∈ {1, ..., p^{k-1}-1}`，`ip` 是 `p` 的倍数。（练习：`x^{φ(n)} ≡ 1 (mod n)`）。如果 `m, n` 互质，我们可以通过中国剩余定理证明 `x^{φ(n)} ≡ 1 (mod m)` 且 `x^{φ(n)} ≡ 1 (mod n)`。因此，`φ(mn) = φ(m)φ(n)`。这是 `φ` 具有积性的性质。定理规定对于任意 `x ∈ Zₙ`，`x^{φ(n)} ≡ 1 (mod n)`。幂是一个形式为 `mᵉ` 的数，对于某些 `m, e ∈ ℤ`。

**52. 归约分解。** 然而，我们可以将“整数分解”称为“分解”。我们将分解问题归约到计算“核心”。在这里，我们说问题 P 可归约为问题 Q。

1. **归约为分解：** 首先我们可以将问题归约为寻找 `n` 的任何非平凡因子 `M`。也就是说，我们要声明 `n` 为质数，要么找到一个使得 `1 < M < n` 的 `M`。将此称为**完全分解问题**，与我们用 (39) 表示的原始版本相比。此外，如果 `A_P` 来自任何多项式算法 `A_Q`，则该归约是随机的。一般，由 (39)，我们有 `n = ∏_{i=1}^c pᵢ^{eᵢ}`，其中 `c = Σ eᵢ ≤ n`。

2. **归约为奇幂：** 给定 `N`，我们想要检测它是否为幂，如果是，`N = Mᶜ`。这可以在多项式时间内完成（练习）。我们可以进一步假设 `N` 是奇数，但读者会好奇这只是一个临时的决策：为什么只排除 2 的倍数？我们也可以排除 3 或 5 的任何倍数。我们的决策遵循下一个归约。

3. **寻找模 `N` 的平方根：** 令 `x` 为模 `N` 的平方根，如果 `x² ≡ 1 (mod N)`。显然，`x=1` 和 `x=N-1`（通常记为 `-1`）是 1 的平方根。但是平凡的；我们想要非平凡的平方根 `1 < x < N-1`。配备 `x` 使得 `x²-1 = (x-1)(x+1) ≡ 0 (mod N)`，我们可以找到 `N` 的因子 `p`。也就是说，当 `N` 是合数时，有很多 1 的平方根。

4. **归约为阶：** 我们可以通过阶找到非平凡的平方根。对于 `x ∈ Zₙ*`，`x` 模 `n` 的阶（`ord(x)`）是使得 `xʳ ≡ 1 (mod n)` 的最小 `r`。阶问题是在给定 `n` 时寻找 `r`。根据欧拉定理，`x^{φ(n)} ≡ 1 (mod n)`，且 `r ≤ φ(n)`。如果 `φ(n) = ar+b` 且 `0 ≤ b < r`，则 `x^{φ(n)} = xᵇ ≡ 1 (mod n)`，除非 `b=0`。阶问题已知多项式时间内求解。归约为阶将来进行。
