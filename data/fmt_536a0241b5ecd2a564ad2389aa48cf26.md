## 纠缠

假设我们有两个量子比特，第一个处于态 `α0|0⟩ + α1|1⟩`，第二个处于态 `β0|0⟩ + β1|1⟩`。这两个比特的联合态是什么？答案是它们的（张量）积：`α0β0|0⟩ + α0β1|1⟩ + α1β0|1⟩ + α1β1|1⟩`。

对于任意的双比特态，我们可以通过这种方式指定每个比特的态吗？不，通常情况下这两个比特是*纠缠*的且无法分解为单个比特的态。例如，考虑态 `1/√2|00⟩+1/√2|11⟩`，这是贝尔态之一（见练习 10.1）。纠缠是量子力学中最神秘的方面之一，并最终是量子计算能力的来源。

这里出现了一个有趣的问题：如果我们进行*部分测量*会怎样？例如，如果我们测量第一个量子比特，结果为 0 的概率是多少？这很简单。这和我们测量两个量子比特的结果是一样的，`Pr[bit=0]+Pr[bit=1]=|α00|²+|α01|²`。那么，这种部分测量对态的影响有多大？

答案是优雅的。如果测量第一个量子比特的结果是 0，那么新的叠加态是通过去掉所有 `|α⟩` 中与该结果不符的项（即第一个比特为1的项）得到的。由于振幅的和必须重新归一化。在我们的例子中，这个新态将是：

```
|α_new⟩ = α00/√(|α00|²+|α01|²)|00⟩+α01/√(|α00|²+|α01|²)|01⟩
```

最后，让我们考虑 `n` 个氢原子的一般情况。将 `n` 看作较小的原子数量，例如 `n=500`。在经典情况下，500个比特的状态可以用显而易见的方式存储500个比特的信息。但在量子物理中，叠加原理告诉我们，量子比特的量子态是经典态的线性叠加：

```
∑_{x∈{0,1}^n} α_x |x⟩
```

这就像自然在旁边有 `2^500` 张纸条，每张上写着一个复数，仅仅为了追踪这个500个氢原子组成的系统的态！此外，在每一个时刻，系统的态随时间演化，就像自然擦掉每张纸条上的复数并将其替换为新值一样。

让我们考虑完成这一切所需的精力。`2^500` 这个数字远大于宇宙中基本粒子数量的估计值。自然在哪里存储这些信息？几百个原子的微观量子系统是否可能包含比整个经典宇宙所能存储的信息更多？这无疑关于自然为了让一个微小系统随时间演化而付出的精力最奢慨的理论了。

这种现象包含了量子计算的根本动力。毕竟，如果自然在量子层面如此奢慨，我们为什么要把计算机建立在经典物理之上？为什么不利用在量子层面投入的巨大精力呢？

但存在一个根本性问题：这个指数级的叠加态是比特的私人世界。测量系统揭示了 n 个比特的信息。和之前一样，结果为特定的500位字符串 `x` 的概率是 `|α_x|²`。而测量后的新态就是 `|x⟩`。

### 10.3 量子傅里叶变换

回想第 2 章中的快速傅里叶变换（FFT）。它的输入是一个 `M` 维复数向量 `α`（其中 M 是 2 的幂，因此 `M=2^m`），输出是一个 `M` 维复数向量 `β`：

![](img/3dd1f1364df8f87b80683fc32a15b999_313_0.png)

其中 `ω` 是复数 `M` 次单位根（额外的因子 `√M` 的是确保如果 `|α_i|²` 之和为 1，那么 `|β_i|²` 之和也是 1）。前面的方程暗示了一个 `O(M²)` 的算法，经典 FFT 能够以快多的速度完成，并具有使数字信号处理在实践上行的深远影响。我们现在将看到量子计算机可以指数级地实现 FFT，仅需 `O(log M)` 时间！

等一下，任何算法的耗时可以是输入的长度 `M` 吗？关键在于我们可以将输入编码到 `m = log M` 个量子比特的叠加态中：毕竟，这个叠加态包含了 `2^m` 个振幅值。在我们之前引入的符号中，我们将叠加态写为 `α = ∑_{j=0}^{M-1} α_j |j⟩`，其中 `α_j` 是自然地对应于数字 `j` 的 `m` 位二进制字符串的振幅。这给了我们一个重要的点：`|j⟩` 只是向量的另一种表示方法，每个条目的索引被显式地写在特殊的括号符号中。

到为止，我们只考虑了 QFT 的好消息：它惊人的速度。现在是时候读第一部分了。经典 FFT 算法实际上输出 M 个复数 `β0, …, β_{m-1}`。相比之下，QFT 只准备了一个叠加态 `|β⟩ = ∑_{j=0}^{m-1} β_j |j⟩`。而且，正如我们之前看到的，这些振幅是这个量子系统的“私有世界”。

### 10.4 周期性

假设 QFT 的输入 `|α⟩ = (α0, …, α_{M-1})` 是周期性的，每当 `i ≡ j (mod k)` 时 `α_i = α_j`，其中 `k` 是整除 `M` 的一个特定整数。此外，假设 `k` 个数 `α_j` 中恰好有一个是非零的，因此说 `|α⟩` 是周期为 `k` 且偏移（offset）为 `j` 的周期态（图 10.5）。

事实证明，如果输入是周期性的，可以使用量子傅里叶采样来计算其周期！这基于以下事实：

> 假设量子采样的输入是周期为 `k` 的，对于某个整除 `M` 的 `k`，那么输出将是 `M/k` 的倍数，且等概率可能是 `k` 个倍数中的任何一个。

思考告诉我们，通过重复采样（重复准备周期叠加态并进行傅里叶采样），然后取所有返回索引的公约数，将极高概率得到数字 `M/k`——取决于输入的周期 `k`！

## 设置周期叠加态

让我们现在来看看如何使用我们的周期函数 `f(a) = x^a mod N` 来设置一个周期叠加态。步骤如下：

- 我们从两个量子寄存器开始，它们的初始状态都为 0。
- 计算第一个寄存器 `M0` 的量子傅里叶变换，得到一个关于 0 到 `M-1` 之间所有数的叠加态：`1/√M ∑_{a=0}^{M-1} |a, 0⟩`。这是因为初始叠加态可以被看作周期为 `M` 的周期，因此变换是周期为 1 的周期。
- 我们现在计算函数 `f(a) = x^a mod N`。执行此操作的量子电路将第一个寄存器的内容 `a` 视为 `f` 的输入，并将第二个寄存器（初始为 0）视为结果寄存器。在应用该量子电路后，两个寄存器的状态为：`∑_{a=0}^{N-1}|a, f(a)⟩`。
- 在第一个寄存器上测量第二个寄存器，周期为 `r`，即 `f` 的周期。原因如下：

由于 `f` 是周期为 `r` 的周期函数，对于第一个寄存器中的每隔 `r` 个值，第二个寄存器的内容都是相同的。对第二个寄存器的测量产生 `f(b)`，其中 `k` 是 0 到 `r-1` 之间的随机数。在这次测量后，第一个寄存器的状态是什么？为了回答这个问题，回想第一个寄存器仅包含与第二个寄存器测量结果兼容的数值 `a` 的叠加态。但这些 `a` 值恰好是 `k, k+r, k+2r,…,k+M-r`。第一个寄存器的最终状态是一个周期为 `r` 的周期叠加态 `|α⟩`，这正是我们想要寻找的 `x` 的阶！

- 在范围 `1 ≤ x ≤ N-1` 内均匀地选择 `x`。
- 令 `M` 为接近 `N` 的 2 的幂次（由于某些无法详述的原因，最好选择 `M ≈ N²`）。
- 重复 `L=log N` 次：
    (a) 从两个量子寄存器开始，初始状态都为 0，第一个寄存器足够大以存储数字 `M`，第二个寄存器取模 `N`。
    (b) 使用函数 `f(a) = x^a mod N` 创建一个长度为 `M` 的周期叠加态 `|α⟩`，如下（详情见框）：
        i. 对第一个寄存器应用 QFT，得到叠加态 `1/√M ∑_{a=0}^{M-1}|a, 0⟩`。
        ii. 使用量子电路计算 `f(a) = x^a mod N`，得到叠加态 `1/√M ∑_{a=0}^{M-1}|a, x^a mod N⟩`。
        iii. 测量寄存器。现在第一个寄存器包含周期叠加态 `|α⟩ = ∑_{j=0}^{M/r-1} √(r/M) |jr+k⟩`，其中 `k` 是 0 到 `r-1` 之间的随机偏移（回想 `r` 是 `x mod N` 的阶）。
        i. 对叠加态 `|α⟩` 进行傅里叶采样，得到一个 0 到 `M-1` 之间的索引。
        令 `g` 为所得索引 `j1, …, js` 的最大公约数。
        l. 如果 `M/g` 是偶数，计算 `gcd(N, x^{M/g}+1)`如果它是 `N` 的非平凡因子则输出它；否则返回步骤 1。

根据先前的引理，我们知道这种方法至少适用于一半的 `x` 情况，并且在找到因子之前，必须重复整个过程几次。

但该算法有一个与数字 `M` 有关的仍然相当模糊：`M`，即我们 FFT 的大小，必须是 2 的幂。为了让我们的周期检测想法生效，周期必须整除 `M`——因此它也应该是 2 的幂。但在我们的案例中，周期是 `x` 的阶，显然不是 2 的幂！

所有这一切之所以仍然有效，原因如下：如果量子傅里叶变换的周期不能整除 `M`，它仍然可以检测周期向量的周期。但除法不像周期整除 `M` 时那样整除，因此我们不再深入探讨这一点。

令 `n` 为输入 `N` 的比特数。算法运行时间由步骤 3 的 `2 log N = O(n)` 次重复决定。由于模幂需要 `O(n³)` 步（如我们在第 1.2.2 节所示），量子傅里叶变换需要 `O(n²)` 步，分解算法的总运行时间为 `O(n³ log n)`。
