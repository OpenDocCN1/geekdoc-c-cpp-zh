## 挂起线程

与使线程暂停指定时间的 `Sleep()` 方法不同，`Suspend()` 方法会永久暂停线程，直到用户恢复它为止。这意味着 `Suspend()` 方法会导致线程无限期地休眠。`ThreadSuspend` 应用程序（也可在光盘上获得），如清单 31.3 所示，说明了如何挂起线程：

### 清单 31.3：显示 `ThreadSuspend` 应用程序的代码

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading;
namespace ThreadSuspend
{
class Program
{
    static Thread FirstThread;
    static void Main(string[] args)
    {
        FirstThread = new Thread(FirstFunction);
        FirstThread.Name = "First Thread";
        FirstThread.Start();
        Console.WriteLine("Thread Started...\n");
        Thread.Sleep(200);

        //Suspending the FirstThread thread
        FirstThread.Suspend();
        Console.WriteLine("\nThread Suspended...");
    }
    public static void FirstFunction()
    {
        int number = 1;
        for (; number <= 25; number++)
        {
            int time = new Random().Next(25, 50);
            Console.WriteLine("{0} Slept for: {1} milliseconds", FirstThread.Name, time.ToString());
            Thread.Sleep(time);
        }
    }
}
}
```

在清单 31.3 中，你可以看到 `FirstThread` 线程开始执行，并且 `FirstFunction()` 方法在每次迭代时生成一个随机数，该随机数被视为线程的休眠时间。当 `FirstThread` 线程达到总休眠时间 200 毫秒时，程序控制转移到 `Suspend()` 方法，导致线程无限期挂起。

## 恢复线程

要恢复已挂起的线程，`Thread` 类提供了一个名为 `Resume()` 的方法。清单 31.4 显示了 `ThreadResume` 应用程序的代码（也可在光盘上获得），描述了如何恢复已挂起的线程：

### 清单 31.4：显示 `ThreadResume` 应用程序的代码

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading;
namespace ThreadResume
{
class Program
{
    static Thread FirstThread;
    static void Main(string[] args)
    {
        FirstThread = new Thread(FirstFunction);
        FirstThread.Name = "First Thread";
        FirstThread.Start();
        Console.WriteLine("Thread Started...\n");
        Thread.Sleep(200);
        FirstThread.Suspend();
        Console.WriteLine("\n Thread Suspended...");
        Thread.Sleep(200);

        //Code to resume a thread
        FirstThread.Resume();
        Console.WriteLine("\n Thread Resumed...\n");
    }
    public static void FirstFunction()
    {
        int number = 1;
        try
        {
            for (; number <= 25; number++)
            {
                int time = new Random().Next(25, 50);
                Console.WriteLine("{0} Slept for: {1} milliseconds", FirstThread.Name, time.ToString());
                Thread.Sleep(time);
            }
        }
        finally
        {
            Console.Write("\n Press ENTER to quit...");
            Console.ReadLine();
        }
    }
}
}
```

## 停止线程

停止线程意味着终止其执行的进程。`Abort()` 方法用于停止线程。你不应将 `Suspend()` 方法与 `Abort()` 方法混淆，因为被挂起的线程稍后可以恢复；然而，一旦使用 `Abort()` 方法终止的线程就无法稍后恢复。`ThreadAbort` 应用程序的代码（也可在 CD 上获得），如清单 31.5 所示，描述了如何在完成前中止线程：

### 清单 31.5：显示 `ThreadAbort` 应用程序的代码

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading;
namespace ThreadAbort
{
class Program
{
    static Thread FirstThread;
    static void Main(string[] args) {
        FirstThread = new Thread(FirstFunction);
        FirstThread.Name = "First Thread";
        FirstThread.Start();
        Console.WriteLine("Thread Started...\n");
        Thread.Sleep(200);
        FirstThread.Suspend();
        Console.WriteLine("\nThread Suspended...");
        Thread.Sleep(200);
        FirstThread.Resume();
        Console.WriteLine("\nThread Resumed...\n");
        Thread.Sleep(200);
        Console.WriteLine("\nThread Aborted...\n");

        //Code to stop the execution of a thread
        FirstThread.Abort();
    }
    public static void FirstFunction()
    {
        int number = 1;
        try
        {
            for (; number <= 25; number++)
            {
                int time = new Random().Next(25, 50);
                Console.WriteLine("{0} Slept for: {1} milliseconds", FirstThread.Name, time.ToString());
                Thread.Sleep(time);
            }
        }
        catch (ThreadAbortException ex)
        {
            Console.WriteLine("{0} Aborted after {1} iterations", FirstThread.Name, number);
            Console.Write("\nPress ENTER to quit...");
            Console.ReadLine();
        }
    }
}
}
```

在清单 31.5 中，我们以 200 毫秒的恒定间隔启动、挂起、恢复并中止了 `FirstThread` 线程。你应该记住，当线程被中止时，运行时会在线程方法中抛出 `ThreadAbortException` 异常，例如 `FirstFunction()` 方法。此异常允许我们的线程在终止前执行一些清理工作，例如关闭已打开的数据库、网络或文件连接。

## 创建多线程应用程序

.NET Framework 4.0 为在单个程序中执行多个线程提供了完整支持。你可以通过创建 `Thread` 类的多个实例在程序中创建多个线程。`Multithreading` 应用程序（也可在 CD 上获得）如清单 31.6 所示，描述了如何创建多线程应用程序

### 清单 31.6：显示 `Multithreading` 应用程序的代码

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading;
namespace Multithreading
{
class Program
{
    static void Main(string[] args)
    {
        // creating more than one thread in the application
        Thread FirstThread = new Thread(FirstFunction);
        Thread SecondThread = new Thread(SecondFunction);
        Thread ThirdThread = new Thread(ThirdFunction);
        Console.WriteLine("\nThreading Starts...\n");

        //Starting more than one thread in the application
        FirstThread.Start();
        SecondThread.Start();
        ThirdThread.Start();
    }
    public static void FirstFunction() {
        for (int number = 1; number <= 5; number++)
        {
            Console.WriteLine("First Thread Displays: " + number);
            Thread.Sleep(200);
        }
    }
    public static void SecondFunction() {
        for (int number = 1; number <= 5; number++)
        {
            Console.WriteLine("Second Thread  Displays: " + number);
            Thread.Sleep(500);
        }
    }
    public static void ThirdFunction()
    {
        for (int number = 1; number <= 5; number++)
        {
            Console.WriteLine("Third  Thread  Displays: " + number);
            Thread.Sleep(700);
        }
        Console.Write("\nPress ENTER to quit...");
        Console.ReadLine();
    }
}
}
```

在清单 31.6 中，你可以看到我们创建了 `Thread` 类的三个实例——`FirstThread`、`SecondThread` 和 `ThirdThread`。`FirstThread` 线程的 `Start()` 方法被调用，这反过来调用 `FirstFunction()` 方法。`FirstThread` 线程的执行会一直停止到 `FirstFunction()` 方法完成；然而，程序的执行会继续进行下一条语句，这也启动了 `SecondFunction()` 方法的执行。同样，`ThirdThread` 线程不会等待 `SecondFunction()` 方法完成并开始执行 `ThirdFunction()` 方法。
