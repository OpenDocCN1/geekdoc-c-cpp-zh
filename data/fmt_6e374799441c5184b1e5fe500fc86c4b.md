
观察发现，大多数自然问题似乎并不具有非平凡的 a.e. 下界。例如，读者在检查一些类后可以很容易发现，所有 NP 完全类都存在不具有此特性的无限子集。其中一个问题是，非确定性类对于素性判定没有下界：未知是否存在一个素数的无限子集可以在确定性多项式时间内被识别。更准确地说，存在一个语言 `L ∈ P`，使得 `L ∩ Primes` 是无限的。

Meyer [20] 显示，对于任何空间可构造函数 `s(n) ≥ n`，存在一个语言，其空间复杂度受限于 `s(n)`（a.e.）。以下定理改纳了针对接受空间复杂度的证明，并避免了 `s(n) ≥ n` 的假设。

设 `s` 是一个单调不减、无界的空间可构造函数。那么在 `DSPACE(s)` 中存在一个无限语言 `L₀`，使得如果 `N` 是 `L₀` 的任意：

`AcceptSpace_X(n) = Ω(s(n))`。

这可以被视为特征类的确定性空间层级定理的强版本。在 Rabin [4, 31] 和 Blumm [1] 的早期工作基础上已经获得了类似的结果。

**证明。** 语言 `L₀` 将通过描述一个它的机器 `M` 来定义。设 `U = {U₀, U₁, …}` 是类 `RE[0]` 的通用机器。基本思想是对每个具有空间 `cs(n)`（对于 `c > 0`）的 `Uᵢ` 进行对角化。更具体地说，假设 `M` 的输入是二进制字符串 `i`（视为方便的整数）。我们首先在它的每个工作带上标记出 `s(i)` 个单元格。在随后的实现中，计算永远不会超过这些标记的格子。因此，`L(M)` 显然在 `DSPACE(s)` 中。

在下面的描述中，我们展示 `M` 在输入上将计算出一个索引 `δ(i) ≥ 0`，使得：

> *最近 Goldwasser 和 Nisan 显示，存在一个可以在期望时间内识别的无限子集。期望复杂度类将在后面的章节中讨论。*

`δ(i) = 奇数 ⇒ M` 接受且 `U_(δ(i)/2)` 拒绝 `i`。

`δ(i) = 偶数 ⇒ M` 拒绝且 `U_(δ(i)/2)` 接受 `i`。

我们说索引 `j ≥ 0` 被输入 `i` “抵消”，如果 `j = δ(i)/2`；因此如果 `j` 被抵消，那么 `L(U_j) ≠ L(M)`。注意我们可以抵消 `j` 两次，但当然，如果 `L(U_j)` 是平凡语言，这将是不可能的。二进制字符串 `δ(i)` 将在计算 `i` 结束时写入带 1（为了该目的）。机器在计算 `i` 结束时在带 1 上写入二进制字符串 `δ(i)`（为了该目的）。

## 6.8 不可分结果

显然 `L ≤_m L'`，很容易设计一个针对 `L'` 的接受器，它对所有奇长度的输入都不使用空间。Lynch [17] 证明，如果问题 `L` 不在 `P` 中，则 `L` 包含一个子集，其时间复杂度对于每个 `k ≥ 1` 的下界为 `n^k`（几乎处处）；关于此类结果的推广，请参见 Elman 和 Yacobi [9]。Schneider 和 Klein [26] 在自然语境下提供了一个类似于 Lynch 的结果：SAT 语言中存在一个困难的子集。这些结果应该让读者想起第 4 章中的 Ladner 定理。

为了补充分离结果，我们现在展示一些揭示了我们分离复杂度类尝试之局限性的结果。这些结果并不意外，因为它们仅依赖于时间、空间等典型复杂度度量中某些简单属性。Blum [1] 将此类复杂度度量的属性形式化了。

令 `Σ = {0,1}`，`U` 是对于类 `K = KΣ` 的通用机器，`R` 是关于字母表 `Σ ∪ {#}` 的任意语言。如果满足以下条件，我们称对 `(U, R)` 为一个 *Blum 度量*：

- (B1) 如果存在 `m` 使得 `i#m ∈ R`，则 `x ∈ L(U_i)`
- (B2) `R` 是二元的并定义了一个函数 `r(i, x)`，即：如果 `r(i, x) ↓`（即 `r(i, x)` 定义），则存在一个 `m ∈ Σ*` 使得 `i#m ∈ R`；如果 `r(i, x) ↑`（即未定义），则对于所有 `m ∈ Σ*`，`i#m ∉ R`。

我们用 `R(i)` 表示 `r(i, x)`。注意，如果 `x ∈ L(U)`，符合我们对 `m` 单位某种抽象资源的使用习惯。读者可以验证，我们可以将这种资源解释为时间、空间或其他组合（例如乘积）。对于空间资源有一个注意：我们现在必须证明，除非机器循环（在有限空间内），否则空间使用是无限或未定义的。

层级定理给出了这种形式的一般定理：存在全递归函数 `g(n)`，使得对于所有递归函数 `t(n)`，对

```
$DTIME(g \circ t), DTIME(tt)$
```

是可以分离的：`DTIME(gt(t)) ~ DTIME(tt) ≠ ∅`。遗憾的是，我们现在证明了在没有 `t(n)` 限制的情况下，这种定理是不可能的。这由 Boroddin 定理 [3, 18-45] 导出。

**定理 23（间隙引理）。** 令 `(U, R)` 是所有递归可枚举语言的固定 Blum 度量。对于任何全递归函数 `g(n) > n`，存在一个全递归函数 `t(n)`，使得对于所有 `i`，只有许多 `n` 满足 `t(n) < R_i(n) < g(n)`。

**证明。** 我们定义 `t(n)` 为满足谓词的最小 `m`：

```
$P(n, m) \equiv \exists i (m \geq R_i(n) < g(n) \Rightarrow n \leq i$
```

按照习惯，当整数 `n` 出现在期望强度的位置（例如 `R_i(n)`）时，我们将其识别为其二进制表示。注意这个 `t(n, m)` 的定义是全的且递归的，我们将为度量获得所需的属性。我们首先证明谓词 `P(n, m)` 是原初的。`P(n, m)` 可以重写为 `(P(n, m) ≤ n)` 或 `(i < m < R_i(n) < g(n))`：

```
$i(n) < m \geq R_i(n) \vee g(n)$
```

显然，`P(n, m)` 是可判定的，因此通过搜索 `m` 的连续值，我们得到了 `t(n)` 的递归过程。为了证明该过程是全的，我们证明对于任何 `n`，至少存在一个 `m` 满足条件。定义 `m₀ = 0`，对于每个 `i ≥ 1`，定义 `mᵢ = mᵢ₋₁ + mᵢ`。考虑序列 `m₀, m₁, …, mₙ₊₁`：存在 `n+1` 个间隙，使得 `[mⱼ, mⱼ₊₁]`（`j = 0, …, n`）中至少一个不包含 `Rᵢ(n)` 的值，`i = 0 … n-1`。那么 `P(n, m)` 成立。证明完毕。

例如，存在复杂度函数 `tᵢ`（`1, 2, 3`）使得：

```
$DTIME(t_1) = DTIME(2^1)$
$DTIME(t_2) = NTIME(t_2)$
$DSPACE(t_3) = NSPACE(t_3)$
```

因此，此类类是不可分的，正如第 6 节提到的那样。还有许多此类结果。

## 6.9 结论

本章展示了一些分离结果，并使用了翻译引理来进一步的概念。这些结果大多适用于空间和时间：我们还证明了如果不限制函数，分离是有限的。

## 习题

- [6.1] 令 `t'` 为任何时间可构造函数，使得 `NTIME(t') - NTIME(t) ≠ ∅`。
- [6.2] 改进空间层级定理。定理陈述相同，但不假设 `s` 是可构造的。
- [6.3] 对于 `DSPACE(t, log n)` 类证明层级定理。
- [6.4]（分布式计数器）重构第 2 节所述的结果。我们希望在 `t(n)` 步内模拟 `tᵢ(n)` 界的机器。在输入 `w` 上，我们希望模拟机器 `M_w` 直到 `i`。为了做到这一点，我们使用一个初始化为 `tᵢ(w)` 值的“减计数器”，并在模拟的每一步尝试减少该计数器。问题在于由于我们限制 `k=2`（定理的版本），我们必须使用磁带之一作为工作带（用于 `M_w` 的实际模拟）。想法是使用数字的分布式表示，使得位分布在整个表示中，必要时传播到高位。我们使用用 `0` 到 `B-1` 的数字标记的二叉树（对我们来说 `B=4` 足够）。高度为 `h ≥ 0` 的节点（叶子）具有表示值 `d^h` 的 `d` 位数字。表示的是所有节点值的和。显然存在冗余和低位。我们以中序方式存储树的节点，使得根位于树中间。我们希望到达任何叶子位置。如果到路径只有零，则这种表示是单映的，我们必须利用旋转。证明如果总共执行 `m` 次减少（只要树未耗尽），图灵机上的时间为 `O(m)`。将其应用于我们的定理，证明树没有过度耗尽且我们必须重建树。
- (a)（Hong）证明变换 `w ↦ tally(w)`（其中 `w ∈ {1, …, k}` 且 `tally(w) ∈ {1}*`）可以在空间旋转 `O(log n)` 内计算，也可以在空间旋转 `O(log n, n)` 内计算。
- (b) 通过给出空间与旋转之间的权衡推广这一结果。
- [6.6] 证明对于任何时间可构造函数，存在一个确定性单带接受器 `M`，它时间构造了某些 `t'`，使得 `L(M) ∈ DTIME(t') - Σⱼ₌₀^∞ NTIME((t+j))`。
- [6.7] 分离以下类对：
  - (a) `DTIME(2^n)` 和 `DTIME(3^n)`
  - (b) `SPACE(2^n)` 和 `SPACE(3^n)`
  - (c) `SPACE(2^n)` 和 `DSPACE(2^n)`
- [6.8] 证明引理 5 的资源翻译引理。结论如果 `NP ⊂ P`，则 `NEXPT ⊂ DEXPT`。

## 6.9. 结论

- [6.9]（I. Simon）此题假设使用单向查询机（第 4 章第 3 节）。证明 Savitch 的向上空间翻译可以实现于任何查询机。具体而言，对于任何查询机 `A` 和由增长函数 `s` 空间可构造的空间，`NSPACE^A ⊆ DSPACE^A`。
- [6.10] 证明如果 `NSPACE^A ⊆ DSPACE^A`，则 `s(n)`。
- [6.11] 证明 `NTIME(t) ≠ NTIME(t')`，其中 `t` 是时间构造的。使用第 4 章的方法。
- [6.12]（递归定理）令 `Σ = {0,1}`，`U` 是 RE 的通用机器。对于每个递归函数 `F`，存在一个索引 `j`，使得对于所有 `x`，`U_j(x) = F(j)`。
- [6.13]（Zák）如果 `f` 是时间构造的，则 `NTIME(f) ≠ NTIME(f')`。
- [6.14]（书籍）证明空间异常：如果 `f(n) ≥ 2` 则 `EXTIME(f(n)) = EXIME(f(n))`。
- [6.15]（Wilson）证明如果 `NP ∩ coNP` 属于 `NP`，则 `DEXP ⊆ EXP`。
- [6.16]（书籍）如果 `L` 在 `≤_m` 下是 `DTIME(n)` 完全的，则 `L ⊆ DLOG`。
- [6.17] 为节末图表的条目提供证明。
- [6.18]（书籍）证明如果 `NP ⊆ P`，则 `NEXP ⊆ DEXP`。
- [6.19]（书籍）证明 `NP(log n) ≠ DSPACE(log² n)`。考虑在确定性对数时间内计算的变换。如果 `Φ` 是 4 的一部分。
  - (i) 如果 `L ∈ DSPACE(n², log n)` 且 `L' ≤_m L`，则 `L' ∈ DSPACE(n, log n)`
  - (ii) `NTIME(n²)` 在 `≤_m` 下有一个完全语言
  - (iii) `NTIME(n^n) ≠ DLOG`。使用习题 6.3。
- [6.21]（Loui）尝试证明定理 20 以证明 `P ≠ EXP`。证明在何处崩溃了？
- [6.22]（开放）分离 `NTIME(2^n)`。
- [6.23] 通过将 Seifer-Fischer-Meyer 的非确定性时间层级定理的陈述从 `o(t(n-1))` 更改为 `o(t^n)` 来改进该定理。
- [6.26]（Stockmeyer）假设 `L` 通过一个线性界的阶项式时间变换 `t` Karp 归约为 `L'`。如果 `L` 的接受时间有一个 `t(n)`（a.e.）下界，则在 `L'` 上存在一个相应的 a.e. 下界。
- [6.27] 定义一种更强的分离概念：如果特征类 `DTIME(t')` 和 `DTIME(t)` 被认为是*极强分离的*（strongly separated），如果在 `DTIME(t') - DTIME(t)` 中存在一个无限语言 `L`，使得对于 `L` 的任何接受器 `M`，对于几乎每个输入 `x ∈ L(M)` 都有 `AcceptTime_M(x) > t(|x|)`。（换句话说，对于 a.e. `x'`）。将定理 21 的证明扩展到这种极强分离的情况。
- [6.28]（Even, Lang, Yacobi）如果对于所有接受 `L'` 的 `N`，均满足以下条件，则说 `L` 比 `L'` *容易*（easier than）：
  - 1. 对于所有输入 `x`，`AcceptTime_M(x) = |x|^{O(1)} + AcceptTime_N(x)`。
  - 2. 对于某些 `k > 0`，`(AcceptTime_{M'}(x))^k ≤ AcceptTime_{M'}(x)` 对于无限多个 `x`。
  
  如果仅满足 (1)，则我们说 `L` 不比 `L'` 困难（not harder than）。如果存在语言 `L₀ ∈ NP - co-NP`，则：
  - (a) 存在一个递归语言 `L₁ ∉ NP ∪ co-NP`，使得 `L₀` 不比 `L₁` 困难且 `L₁` 不比 `L₀` 困难。
  - (b) 存在一个递归语言 `L₂ ∉ NP ∪ co-NP`，使得 `L₁` 比 `L₀` 容易。
- [6.29]（Ming Li）证明对于所有 `j > 1`，`NTIME(n^j) - DTIMPSPACE(n³, o(n))` 是非空的。
- [6.30]（Ming Li）证明在 `NTIME(n)` 中存在一种语言，任何确定性图灵机无法在 `O(n^{1.366})` 时间内接受它。
