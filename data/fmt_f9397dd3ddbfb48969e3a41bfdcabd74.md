# Linux 下的 C 语言 IoT

# 基础 C 语言：接近机器

ISBN: 978187192604

在入门阶段，本书从底层编程的角度探索了 C，并保持与硬件的距离。它涵盖了地址、指针以及如何用二进制表示，并强调了这是一个重要概念。对于学者，书中介绍了如何安装 IDE 和 `GCC`，并编写了 Hello World 程序，然后介绍了程序的基本构建块——变量、赋值和表达式、通过条件和循环实现的控制流。
