## A.2.2 马尔可夫链基础

我们将保持简单，假设马尔可夫链的状态空间 `X` 是有限的或计数无限的。转移矩阵记为 `P`。对于 `X` 上的每个 `μ`，在 `F` 上有一个概率测度 `P_μ`，使得 `μ` 是链的初始分布。与第 6 章中的定义一致：

> `P_μ[X_0 = x] = μ(x)`

> `P_μ[X_k = x] = ∑_{x' ∈ X} μ(x') P^k(x',x), x ∈ X`

> `E_μ[g(X_k)] = ∑_{x} P_μ{X_k = x} g(x)` 对于任意 `g: X → ℝ`。

当 `μ` 是退化的时，即对于某个 `x` 使得 `μ(x)=1`，我们写作 `P_μ` 和 `E_x`。*移位算子*是 `Ω` 上的映射，为复杂概念提供了紧凑的语言。对于每个 `k`，移位算子 `θ^k` 将元素 `ω = {x0, x1, …, xn, …} ∈ Ω` 映射到新值，通过：

> `θ^k ω = {x_k, x_{k+1}, …, x_{n+k}, …}`。

它通过如下定义随机变量 `H` 的变换：

> `(θ^k H)(ω) = H(θ^k ω)`。

因此，如果随机变量 `H` 的形式为对于函数 `h` 的 `h = h(X0, X1, …)`，那么

> `θ^k H = h(X_k, X_{k+1}, …, …)`。

对于某些 `n` 和 `h: X → ℝ` 特化为 `H = h(X_n)` 得到：

> `θ^k H = h(X_{n+k})`

因此

> `E_μ[θ^k H | F_k] = E_μ[h(X_{n+k}) | F_k]`

> `E_μ[h(X_{n+k}) | X_k]`

> `∑_{x'} P^n(x', x) h(x')_{x=X_k}`

根据转移矩阵的马尔可夫性质定义。

## A.2 概率与马尔可夫背景

这可以被推广：对于任意初始分布 `X0 ~ μ`，任意有界随机变量 `H`，以及固定的 `k, n ∈ ℤ_+`。

```
E_μ[θ^k H | F_k] = E_x[H]_{x=X_k} a.s.[P_μ]. (A.4)
```

这简洁地描述了时间齐次的*马尔可夫*性质。因此，注意我们将 `E_x[H]` 视为状态空间上的一个实值函数。在这里我们替换以下内容：

```
E_x[H] = E_x[H]_{x=X_k}.
```

## A.2.3 强马尔可夫性质

强马尔可夫性质通过公式 `(A.4)` 的显著扩展来描述。该性质的定义需要这三个要素：

- (i) 函数 `τ : Ω → ℤ_+ ∪{∞}` 是 `X` 的*停止时间*，如果对于每个 `n ∈ ℤ_+`，事件 `{τ = n}` 属于 `F_n`。也就是说，对于每个 `n`，存在一个函数 `f_n` 使得 `{τ = n} = f_n(X0, …, Xn)`。

- (ii) 相关的移位算子 `θ^τ` 的定义与之前相同：`θ^τ H = h(X_τ, X_{τ+1}, …)`。

- (iii) 相关的 `σ` 域也定义为：`F_τ def= {A ∈ F : {τ = n} ∩ A 对于每个 n ∈ ℤ_+}` `(A.5)`

这被解释为“在时间 `τ` 之前”发生的事件。

两个重要的停止时间例子，对于任意集合 `A ⊂ X`：

`τ_A def= min{n ≥ 1 : X_n ∈ A}`

`σ_A def= min{n ≥ 0 : X_n ∈ A}`

分别被称为进入 `A` 的首次时间和击中时间。

**命题 A.1** 对于任意集合 `A ⊂ X`，变量 `τ_A` 和 `σ_A` 是 `X` 的停止时间。

*证明* 随机变量 `τ_A` 和 `σ_A` 具有如下表示，对于任意 `n ≥ 1`：

```
{τ_A = n} = f_n(X0, …, Xn) def= 1{X_n ∈ A} ∏_{i=1}^{n-1} 1{X_i ∉ A}
```

```
{σ_A = n} = g_n(X0, …, Xn) def= 1{X_n ∈ A} ∏_{i=0}^{n-1} 1{X_i ∉ A}
```

其中 `∏_{i=1}^{0} = 1`。对于 `n=0`，我们有 `{τ_A = 0} = f0(X0) = 0` 且 `{σ_A = 0} = g0(X0) 1{X0 ∈ A}`。□

一个 `F_t`-可测的有限值随机变量 `H` 可以表示为无穷和：

```
H = ∑_{n=0}^{∞} h_n(X0, …, Xn) 1{τ = n}
```

对于函数序列 `{h_n}`。

一个例子是随机变量 `X_τ`，其通过设置 `X_τ = X_n` 定义：

```
X_τ = X_n 1{τ = n}
```

最后，通过如下定义：**强马尔可夫性质**对于任意初始分布 `μ`，任意有界随机变量 `H` 和停止时间 `τ`，满足：

```
E_μ[θ^τ H | F_τ] = E_x[H]_{x=X_τ} a.s.[P_μ]. (A.5)
```

## B.2 MDP 的计算方面

在当 `S = {x*}` 为单元素集时，这是定理 6.3 中使用的首次返回时间：

```
τ = min{k ≥ 1 : X_k = x*}.
```

如果 `π*(x*) > 0`，其中 `π*` 是最优策略下的不变分布，则 `h*` 满足平均成本最优性方程 `ACOE`：

```
min_u{c(x,u) + P_u h*(x)} = h*(x) + η*.
```

函数 `h*` 是相对价值函数，而最小化器是一个实现最优平均成本的静态策略：

```
φ*(x) = argmin_u{c(x,u) + P_u h*(x)}.
```

本节回顾值迭代算法和策略迭代算法，并介绍与第 3.5 节引入的 LPS 相关的线性规划方法。

本节专门介绍 `ACOE (B.6)`。相对价值函数 `h*` 不是唯一的——我们总是可以给它加上一个常数。这里引入额外的约束 `h*(x*) = η*` 是方便的。

```
min_u{c(x,u) + P_u h*(x)} = h*(x) + h*(x*).
```

算法设计始于将 `(B.7)` 表示为固定点方程：令 `T` 表示映射 `h : X → ℝ` 的泛函，并通过以下方式创建一个新函数：

```
T(h) = min_u{c(x,u) + P_u h(x)} - h(x), x ∈ X.
```

`ACOE` 可以表示为固定点方程：

```
h* = T(h*).
```

### B.2.1 值迭代与迭代逼近

在迭代逼近中，我们初始化一个函数 `h0 : X → ℝ`，然后对于 `n ≥ 0`，

```
h_{n+1}(x) = T(h_n)(x) = min_u{c(x,u) + P_u h_n(x)} - h_n(x*), x ∈ X.
```

值迭代算法通过忽略 `h_n(x*)` 得到。

#### 值迭代算法 VIA

`VIA` 使用函数 `V0 : X → ℝ` 初始化。然后，对于每个 `n ≥ 0`，

```
V_{n+1}(x) = min_u {c(x,u) + P_u V_n(x)}.
```

第 `n` 阶段的策略定义为最小化器：

```
φ_n(x) = arg_u {c(x,u) + P_u V_n(x)}.
```

**命题 B.1** 在第 `n` 阶段，我们有一个策略序列 `(Φ0, ..., Φ_{n-1})`。函数 `V_n` 可以表示为：

```
V_n(x) = min E[∑_{k=0}^{n-1} c(X_k, U_k) + V0(X_n)],
```

其中对所有输入进行最小化。存在一个马尔可夫最小化器，但不一定是静态的。

```
U_k* = Φ_{n-k}(X_k*), 0 ≤ k ≤ n.
```

假设 `{V_n}` 使用 `VIA` 得到，`{h_n}` 使用迭代逼近得到，且初始化为 `h0 ≡ V0`。通过对 `n` 进行归纳可以证明：

```
h_n(x) - h_n(x*) = V_n(x) - V_n(x*) 对于每个 x 且 n ≥ 0.
```

因此，在温和假设下具有收敛性：

```
lim_{n→∞} |V_n(x) - V_n(x*)| = h*(x*).
```

### B.2.2 策略改进与牛顿法

#### 策略改进算法 PIA

给定初始策略 `Φ0`，序列 `(φ_n, h_n)` 构建如下：在第 `n` 阶段，给定 `φ_n`，

- (i) 求解泊松方程：

```
P_n h_n = h_n - c_n
```

- (ii) 构建策略：

```
φ_{n+1}(x) = argmin {c(x,u) + P_u h_n(x)}, x ∈ X.
```

`PIA` 是牛顿-拉夫逊法的特例，其中 `(B.8)` 中的函数 `T` 被其线性化 `T̂_n` 替换以获得 `h*` 的近似序列。给定某些 `h_n`，映射 `T̂_n` 定义为一阶泰勒展开：

```
T̂_n(h_n) ≈ T(h_n) + D_n(h - h_n). (B.15)
```

当 `X` 包含 `d` 个元素时，`D_n = ∇ T(h_n)` 是一个 `d × d` 矩阵。牛顿-拉夫逊方法定义 `h_{n+1}` 为方程的解：

```
h_n = T(h_n) + D_n(h - n). (B.16)
```

**引理 B.2** 对于任何函数 `h: X → ℝ`，令 `φ+` 表示满足

```
φ+(x) = argmin {c(x,u) + P_u h(x)}, x ∈ X.
```

令 `P+ = P_{φ+}`，令 `S` 为任何函数 `g: X → ℝ` 的替换算子：

```
S(x)=g(x*), x ∈ X.
```
