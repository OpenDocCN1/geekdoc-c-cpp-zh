void richTextBox_ContextMenuOpening(object sender, ContextMenuEventArgs e)
{
    RichTextBox rtb = sender as RichTextBox;
    if (rtb == null) return;
    ContextMenu contextMenu = rtb.ContextMenu;
    contextMenu.PlacementTarget = rtb;
    TextPointer position = rtb.Selection.Start;
    if (position == null) return;

    contextMenu.HorizontalOffset = positionRect.Right;
    contextMenu.VerticalOffset = positionRect.Left;
    contextMenu.IsOpen = true;
    e.Handled = true;
}
}

## In Depth

图形在字面意义上是指设计、形状、绘图和文本的视觉呈现，通常用于查看特定信息。动画是将排列顺序的图形快速显示以创造运动错觉。多媒体包括文本、音频、视频、动画和图形内容的组合。`Windows Presentation Foundation`（`WPF`）包括对高质量二维（2-D）和三维（3-D）图形、动画和媒体功能的支持，使您能够向应用程序添加图形、过渡效果、声音和视频。`WPF` 提供了以前仅对专门库（如图形设备接口（`GDI`）和 `GDI+`）可用的高级绘图和动画功能。

`Visual Studio 2005` 之前的版本提供了有限的功能来在 `Windows Forms` 中集成图形。例如，在 `Visual Studio` 的早期版本中，仅使用原色与不同的形状和图形对象。随着 `Visual Studio` 的每次后续发布，微软一直试图成功克服这一缺点。图形在 `Windows Forms` 中的集成现已扩展到包括在 `WPF` 中集成多媒体、图形和动画的支持。这种集成使得构建图形丰富且视觉上吸引人的用户界面（`UI`）和内容变得更容易。

## Graphics in Windows Forms Applications

在 `Windows Forms` 应用程序中，您可能需要创建简单的形状和其他图形对象。在这种情况下，您可以使用 `Windows Forms` 的图形元素，这有助于创建视觉上吸引人的应用程序。在 `Windows Forms` 应用程序中，`GDI+` 用于创建图形、绘制文本和操作图形图像。`GDI` 负责在 `Windows Forms` 中集成图形，而 `GDI+` 是 `GDI` 的高级实现。`GDI+` 的基本用途是在窗体上渲染图形图像。

您还可以通过使用 `Image` Web 服务器控件显示图形图像在 Web 窗体上使用 `GDI+`。请注意，您不能直接在 Web 窗体上使用 `GDI+`。在本节中，您将学习：

- `GDI+` 托管类接口
- 基本 `GDI+` 托管类

### GDI+ Managed Class Interface

`GDI+` 功能的核心是 `Graphics` 类。`GDI+` 由一组基类组成，可用于控制屏幕上的自定义绘图。它通过部署为托管代码的一组类公开。这组类统称为 `GDI+` 托管类接口。

`GDI+` 托管类接口是 `.NET Framework` 的一部分。它提供了一个用于构建、部署和运行 `XML` Web 服务和其他应用程序的环境。它允许访问提供 2-D 矢量图形、成像和排版的底层操作系统功能。`GDI+` 托管类接口包含约 60 个类、50 个枚举和 8 个结构。您可以在构成 `GDI+` 托管类接口的命名空间中对类进行分组。`GDI+` 的命名空间在表 12.1 中列出：

## 基本GDI+托管类

许多类与 `Graphics` 类协同工作以获得渲染效果。例如，`DrawLine()` 方法接收一个 `Pen` 对象，该对象包含要绘制线条的属性。重要的 `GDI+` 托管类包括 `Graphics` 类、`Pen` 类和 `Brush` 类。除了这些类，`Windows Forms` 应用程序还定义了颜色结构，帮助您设计图形。让我们在以下章节中详细讨论所有这些内容。

## Graphics类
