# 第 2 章

## C# 编程语言

你可能会奇怪为什么要使用 C#。这一章涵盖了为什么 C# 是一门非常棒的学习语言的原因，以及它能为你做什么。

C# 是一种后端编程语言。它处理 Web 和桌面应用程序的输入和输出。有很多语言可以选择，所以你可能会奇怪为什么选择 C# 而不是其他编程语言。这一章为你提供了关于 C# 语言的一些背景以及它在编程行业中的用途。

### 为什么要用 C#

没有开发者是绑定在任何语言上的。你可以使用任何基于语言的应用程序来完成开发。当你想要开发纯 Windows 环境的应用程序时，你需要学习 `.NET` 框架的语言之一，包括 `C#` 和 `VB.NET`。当 `.NET` 最初推出时，`VB.NET` 是最流行的语言。这是因为旧版的 Classic VB 很有基础。这一章将为你提供关于 `C#` 语言的一些背景以及它在编程行业中的用途。

### C# 是用来做什么的？

有几个理由你想要使用 `C#`。`C#` 让你处理桌面和 Web 应用程序。为了运行 `C#`，服务器需要 `.NET` 框架。`.NET` 框架只兼容 Windows，所以你需要运行 Windows。

`C#` 常用于 Web 应用程序。具体来说，`C#` 语言用于处理动态代码。例如，当用户通过 Web 表单发送信息时，`C#` 语言进行处理、存储并发送响应。`C# MVC` 仍然处理前端，你使用 `HTML`、`CSS` 和 `JavaScript` 进行前端。`C#` 也用于桌面应用程序，但你可能不再看到桌面应用程序作为主要的软件。编程世界正在转向云应用，这对 `C#` 程序员是有益的。`C#` 程序员可以创建 API 和处理云应用的后端代码。

`C# API` 也称为 `WCF` 应用程序。这些 API 允许开发者集成与内部工作的外部功能。例如，你可以使用 Facebook API 集成到你的应用程序中。`C# API` 也可以这样做。发布 API 的好处是，第三方开发者使用什么语言并不重要。他们可以使用 `PHP`、`Java`、`JavaScript` 和 `Python` 与你的 API 交互。只要应用程序支持 `XML` 或 `JSON` 输入输出，第三方开发者就可以处理你的 `C# API`。

`C#` 还用于数据库应用程序。它与 `SQL Server` 工作，存储并从数据库服务器请求数据。`C#` 可以使用 `Entity Framework` 和 `MSSQL`，这样开发者可以使用 `LINQ` 查询和 `POCO` 类来处理数据。这意味着你不需要在数据库存储过程之间来回切换。相反，开发者可以直接与数据库结构和数据进行工作。

最后，`C#` 用于 Windows 服务。这些是在计算机（通常是服务器）后台运行的程序。它们被用于自动化，以确保某些过程在一天中的特定时间自动发生。

微软提供了 `Visual Studio Express`，这是一个免费版本，它为你提供了创建 `C#` 应用程序所需的所有内容。你也可以使用 `Visual Studio` 创建 `VB.NET` 应用程序。微软将其桌面版和网页版分开了，因此请确保为你的项目下载了正确的版本。例如，如果你想创建一个 Web 应用程序但你使用的是桌面版 `Visual Studio`，那么你将无法创建该程序。在创建应用之前，你需要下载网页版的 `Visual Studio` 应用程序。

要创建具有数据库存储功能的应用程序，你需要 Microsoft `SQL Server`。你不需要完整版或企业版，你只需要 Express 版本来配合你不断增长的应用程序。你可以创建一个功能完整的 `SQL Server` 数据库，它可以与你的应用程序配合，然后你可以将 Express 版本的数据库迁移到功能完整的网站或应用程序版本中。

在安装 `Visual Studio` 时，你可以选择下载与自己的应用程序集成的第三方应用程序。`Visual Studio` 使用 `NuGet`，它允许你下载文件并自动将它们添加到你的项目中。一旦你安装并配置了 `Visual Studio`，就可以下载任何所需的库来开始工作。

如果你决定创建一个 Web 应用程序，需要的最后一个项目是 `IIS`。`IIS`（Internet信息服务）是允许你托管和运行网站的 Web 软件。如果你有一台 Windows 电脑，你已经拥有了 `IIS`。某些版本的 Windows 如果你不升级到专业版，则不允许运行完整版的网站。所有服务器操作系统都运行完整版本的 `IIS`，而桌面版有时需要专业版来运行你的测试网站。如果你不确定，请检查控制面板中的设置，查看你是否有能力在桌面上运行 `IIS`。

#### 一些基础最佳实践

一旦你安装了 `Visual Studio` 并设置好了整个环境，在开始编程之前，有一些最佳实践需要遵循。这些是大多数使用 `C#` 的开发者在工作时遵循的微小标准。如果你决定在行业内工作，你应该了解这些标准，以保持一致性，并在你需要接手另一位编码员的工作时理解其代码。

在构建大型字符串时，使用 `StringBuilder` 代替 `string`。`StringBuilder` 是一个我们将在后续章节中学习的类。它的性能比原始字符串变量更好。你可能会倾向于直接使用原始字符串而不是 `StringBuilder`，但在处理动态字符串时，请务必使用 `StringBuilder`。

使用动词来创建方法。我们将在后续章节中讨论类和方法，但在创建你的类及其方法时，命名方案是非常重要的。方法赋予动词名称，是因为它们执行了存储数据或操作数据的动作。它们还接收用户的输入并为你的用户提供输出。

类属性应该始终是名词。再次，我们将在后续章节中介绍类和属性，但请记住属性应该用名词命名。例如，如果一个属性持有用户的名称，它应该命名为 `m_name`、`m_fullname` 或 `_fullname`。注意，类成员属性应该有某种前缀。它应该是 `m_` 或 `_` 作为前缀。这是命名方案中的标准做法。

经常对你的代码进行注释。记住，必须有人跟在你后面并编辑你的代码。这意味着你需要对代码进行注释，以便他人能够接手你未完成的工作。注释帮助其他编码员理解你的代码应该做什么，它应该期望什么类型的输入，以及编码员是否应该注意系统中的任何异常。

`C#` 是一门非常棒的学习语言。如果你想在 Windows 环境下工作并想在行业内赚钱，`C#` 是学习的完美语言。它是企业中非常流行的语言，薪水也很高。它也是使用 Microsoft `SQL Server` 进行存储的编码员的首选语言。当服务器运行 Windows 操作系统时，它也被用于自动化。事实是，如果你使用 `C#` 和 `Visual Studio`，是不会出错的。它是任何 Web 或桌面开发者都应该学习的流行语言。

# 第 3 章

## 数据类型

**目标：** 数据类型决定了你可以在变量中存储的数据。`C#` 有多种数据类型，本章将帮助你理解它们以及你对这些变量可以做的事情。

当你编写程序时，你需要告诉操作系统它对系统中设置的每个变量可以期待什么。你需要定义变量数据类型的原因是，操作系统根据数据类型分配内存。数据类型告诉操作系统你将在变量中存储什么，并且对于你定义的每个变量都是必不可的。

### 基础数据类型语法

在进入特定的数据类型之前，我们应该看一眼基础语法。以下是定义变量的基本模板。

```
<data type><variable name>;
```

我们将涵盖程序中将使用的几种数据类型，但仅就本节而言，请记住**数据类型指定符**始终是你变量声明语句中的第一个项。

你变量声明语句中的下一个项目是变量名。你可以给变量起任何名称，但通常编码标准定义了你命名变量的方式。例如，大多数开发者要求在变量名中使用“驼峰命名法”`camelCase`。你用小写字母开头，然后变量中的任何后续单词都大写。例如，你将变量命名为 "`camelCase`" 而不是 "`CamelCase`" 或 "`camelcase`"。然而，你可以为变量起任何你喜欢的名称。

注意，`C#` 中不同的大小写代表不同的变量。在 `camelCase` 示例中，`camelCase`、`camelcase` 和 `CamelCase` 都是不同的变量。这遵循了 C 语言的变量命名约定。你会发现 `C#` 遵循了许多标准的 C 风格。

语句的最后一个要求是分号。分号告诉编译器语句已结束。

变量的最后一个规则是，你可以在声明变量的同时为它赋值。让我们看看这种赋值语法。

```
datatype variable name = value;
```

再次，赋值是可选的，但上面的语法是你在声明的同时赋予值的方式。记住，值必须与数据类型匹配。例如，如果你尝试将字符串字符赋值给整数数据类型，编译器将给出错误。

### 字符串数据类型

在任何程序中，你都会处理字符串。字符串是包含单词的变量。这些单词可以是任何字母数字字符，甚至是特殊字符。大多数用户输入都是字符串形式的，但然后你可以将其转换为其他数据类型。例如，你可能会要求用户输入数字，然后将其转换为整数以进行某种计算。

让我们看一个字符串变量的示例。

```
string myName = "John";
```

注意，`string` 数据类型首先用于定义字符串变量。这是一个原始字符串数据类型。数据类型 "`String`" 是一个类，只有当你对变量执行复杂的字符串函数时才使用它。大多数情况下，你在设置变量时使用原始字符串定义。

语句中的下一个项是变量名。我们使用了驼峰命名法，变量名中的第一个字母为小写。接下来的名称使用大写字母。

在这个语句中，我们为定义赋值。我们将 "`John`" 赋值给 `myName`。注意，语句以分号结束。分号告诉编译器语句已结束。如果我们忘记了语句中的分号，下一个语句将导致语法错误。

你也可以声明一个没有值的字符串变量。我们可以使用相同的语句来说明如何定义没有值的变量。

```
string myName;
```

此时，该字符串为空（null）。你也可以使用一个特殊的字符串属性 `Empty` 将字符串初始化为空值。

```cs
string symbolName = string.Empty;
```

上述语句将字符串初始化为空值。这通常用于程序员还不知道字符串的值，且不想将字符串值设置为 `null` 的情况。

### C# 中的数值数据类型

`C#` 提供了多种数据类型，你可以用它们来存储和计算数值。两种主要的数值类型是小数 `decimals` 和整数 `integers`。整数是不带小数点的数值。它们可以是带符号的或无符号的。带符号整数可以是负值，这意味着符号部分是负号，而数字是数值本身。无符号整数是不带加号的正值。它被自动假认为正值。
