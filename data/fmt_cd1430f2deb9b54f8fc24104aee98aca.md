# 章节总结

理解类、对象和封装的概念。

- 类描述了一组具有相同行为的对象。
- 每个类都有一个公共接口：一组方法，通过这些方法可以对该类的对象进行操作。
- 封装是提供公共接口并隐藏实现细节的行为。
- 封装允许在实现发生改变，而不影响类的用户。

![](img/6a52d1dde3a219cfa39d548e31d0e6ce_438_0.png)

![](img/6a52d1dde3a219cfa39d548e31d0e6ce_438_1.png)

理解简单类的实例变量和方法实现。

- 对象的实例变量存储了执行其方法所需的数据。
- 类的每个实例都有自己的一组实例变量。
- 实例方法可以访问其所作用的对象的实例变量。
- 私有实例变量只能由其所属类的方法访问。

编写描述类公共接口的方法头。

- 你可以使用方法头和方法注释来指定类的公共接口。
- 修改器（mutator）会改变其操作的对象。
- 访问器方法（accessor method）不会改变其操作的对象。

![](img/6a52d1dde3a219cfa39d548e31d0e6ce_438_2.png)

为类选择合适的数据表示。

- 对于每个访问器方法，对象必须存储存储或计算结果。
- 通常，表示对象数据的方法不止于一种；你必须做出选择。
- 确保你的数据表示支持以任何顺序调用方法。

![](img/6a52d1dde3a219cfa39d548e31d0e6ce_438_3.png)

为类提供实例方法的实现。

- 应用于方法的对象是隐式参数。
- 方法的显式参数列在方法列表中。

![](img/6a52d1dde3a219cfa39d548e31d0e6ce_438_4.png)

设计并实现构造函数。

- 构造函数初始化对象的实例变量。
- 当使用 `new` 运算符创建对象时会调用构造函数。
- 构造函数的名称与类名相同。
- 一个类可以有多个构造函数。
- 编译器选择匹配构造参数的构造函数。

使用对象追踪技术来可视化对象行为。

- 将卡片的正面写上方法，背面写上实例变量。
- 当调用修改器方法时，更新实例变量的值。

使用模式来设计类的数据表示。

- 总计的实例变量在增加或减少数量的方法中更新。
- 计数事件的计数在对应事件的方法中递增。
- 对象可以在数组或列表（ArrayList）中收集其他对象。
- 对象属性可以通过获取方法（getter method）访问，通过设置方法（setter method）更改。
- 如果你的对象可以有几种影响行为的状态之一，请为当前状态提供一个实例变量。
- 为了模拟移动对象，使用变量来存储和更新它的位置。

![](img/6a52d1dde3a219cfa39d548e31d0e6ce_439_1.png)

描述对象引用的行为。

- 对象引用指定对象的位置。
- 多个对象变量可以包含同一个对象的引用。
- 基本类型变量存储值。对象变量存储引用。
- 当复制对象引用时，你拥有两个指向同一个对象的引用。
- null 引用指向没有任何对象。
- 在方法中，此引用指的是隐式参数。

![](img/6a52d1dde3a219cfa39d548e31d0e6ce_439_2.png)

理解静态变量和静态方法的行为。

- 静态变量属于类，而不属于类的任何对象。
- 静态方法不会在对象上调用。
