| $S_1$ | 0 | 7 | 1 | 0 | 0 | 0 | | 77 |

| $S_3$ | 0 | 1 | 0 | 0 | 0 | 1 | | 9 |
| $S_4$ | 0 | 0 | 1 | 0 | 0 | 0 | | 6 |

| -0 | (-150) | (-120) | -0 | (-15) | 0 | 0 | (-1200) |

## 15.2 非线性优化

在存在约束的情况下，处理非线性优化的方法有很多。这些通常分为间接方法和直接方法（Rao 1996）。典型的直接方法使用惩罚函数，这些表达式在解接近约束时降低目标函数。因此，尽管此类方法在某些问题上有效，当问题涉及许多约束时会变得困难。广义梯度（GRG）方法是最流行的直接方法之一（见 Flystra 等 1998；London 1978；Smith 1992）。事实上，Excel 求解器内部使用的非线性优化引擎通过求解一组非线性方程，将问题还原关于基础变量的优化问题。然后，选择一个搜索方向以寻找目标函数。默认选择是拟牛顿法（BFGS）；该方法在大多数情况下表现良好。共轭梯度法也是大规模问题的有效替代方案。Excel 求解器具有根据可用性自动切换到共轭梯度法的功能。一旦确定了搜索方向，将使用可变尺寸方法沿方向进行一维搜索。

## 15.3.3 使用 MATLAB 进行一维优化

### 示例 15.5 使用 MATLAB 进行一维优化

问题描述。使用 MATLAB 的 `fminbnd` 函数找到以下函数的最大值：

```
f(x) = 2 sin x - \frac{x^2}{2}
```

在 $x = 0$ 和 $x = 4$ 的区间内。回想在第 13 章中，我们使用了多种方法求解了 $x = 1.4276$ 且 $f(x) = 1.7757$ 的问题。

解答。首先，我们必须创建一个 M-文件来存储该函数。

```matlab
function fmfx(x)
f = -(sin(x)-x^2/10)
```

由于我们感兴趣的是最大化，因此我们输入函数的负值。我们通过以下命令调用 `fminbnd`：

```matlab
>> fminbnd('fx',0,4)
```

结果为：

```
f =
-1.7757
x =
1.4275
```

注意，可以包含额外的参数。一个有用的补充是设置选项，例如误差容差或最大迭代次数。这是通过 `optimset` 函数实现的，之前在示例 7.6 中用过，其通用格式为：

```matlab
optimset('param',value,'param',value,...)
```

其中 `param` 是指定选项类型的参数，`value` 是分配给它的值。例如，如果你想将容差设置为 $1 \times 10^{-2}$：

```matlab
optimset('TolX',1e-2)
```

因此，以 $1 \times 10^{-2}$ 的容差求解当前问题可以生成：

```matlab
>> fminbnd('fx',0,4,optimset('TolX',1e-2))
```

结果为：

```
f =
-1.7757
ans =
1.4270
```

可以通过如下方式调用 `Help` 找到完整的参数集：

```matlab
>> help optimset
```
