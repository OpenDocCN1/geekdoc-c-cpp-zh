# 静态队列模板

之前显示的队列类仅适用于整数。队列模板可以很容易地处理任何数据类型，如下例所示：

# `Queue.h` 的内容

```cpp
#ifndef QUEUE_H
#define QUEUE_H

#include <iostream>

using namespace std;

// 队列模板

template <class T>
class Queue {
private:
    T *queueArray;      // 指向队列数组
    int queueSize;      // 队列大小
    int front;          // 队列头的下标
    int rear;           // 队列尾部的下标
    int numItems;       // 队列中的项数
public:
    // 构造函数
    Queue(int);
    // 拷贝构造函数
    Queue(const Queue &);
    // 析构函数
    ~Queue();
    // 队列操作
    void enqueue(T);
    void dequeue(T &);
    bool isEmpty() const;
    bool isFull() const;
    void clear();
};

/***********************************************************/
// 此构造函数创建一个指定大小的空队列.
/***********************************************************/

template <class T>
Queue<T>::Queue(int s) {
    queueArray = new T[s];
    queueSize = s;
    front = -1;
    rear = -1;
    numItems = 0;
}
```

## 19.5 动态队列

概念：队列可以实现为链表，并随着每次入队（`enqueue`）或出队（`dequeue`）操作扩展或缩小。

基于链表构建的动态队列比静态队列更直观。动态队列起始于一个空链表。第一次入队操作会添加一个节点，该节点由头指针（`front`）和尾指针（`rear`）指向。当每个新项目添加到队列中时，新节点被添加到列表的尾部，并更新尾指针指向新节点。当每个项目被出队时，头指针指向的节点被删除，并将头指针指向列表中的下一个节点。图 19-14 显示了动态队列的结构。

### `DynIntQueue.h` 的内容

```cpp
#ifndef DINTQUEUE_H
#define DINTQUEUE_H

class DynIntQueue {
private:
    // 队列节点的结构
    struct ListNode {
        int value;        // 节点中的值
        ListNode *next;   // 指向下一个节点的指针
    };
    ListNode *front;      // 队列的头部
    ListNode *rear;       // 队列的尾部
    int numItems;         // 队列中的项目数量
public:
    // 构造函数
    DynIntQueue();
    // 析构函数
    ~DynIntQueue();
    // 队列操作
    void enqueue(int);
    void dequeue(int &);
    bool isEmpty() const;
    bool isFull() const;
    void clear();
};
#endif
```

### `DynIntQueue.cpp` 的内容

```cpp
#include <iostream>
#include "DynIntQueue.h"
using namespace std;

/********************************************************
/* 构造函数创建一个空队列。
/********************************************************

DynIntQueue::DynIntQueue()
{
    front = nullptr;
    rear = nullptr;
    numItems = 0;
}

/********************************************************
/* 析构函数
/********************************************************

DynIntQueue::~DynIntQueue()
{
    clear();
}

/********************************************************
/* 函数 enqueue 将 num 插入到
* 队列的尾部。
/********************************************************

void DynIntQueue::enqueue(int num)
{
    ListNode *newNode = nullptr;

    // 创建一个新节点并在其中存储 num。
    newNode = new ListNode;
    newNode->value = num;
    newNode->next = nullptr;

    // 根据需要调整头和尾。
    if (isEmpty())
    {
        front = newNode;
        rear = newNode;
    }
    else
    {
        rear->next = newNode;
        rear = newNode;
    }

    // 更新 numItems。
    numItems++;
}

/********************************************************
/* 函数 dequeue 移除队列
* 头部的值，并将其复制到 num。
/********************************************************

void DynIntQueue::dequeue(int &num)
{
    ListNode *temp = nullptr;

    if (isEmpty()) {
        cout << "The queue is empty.\n";
    } else {
        // 将头节点的值保存在 num 中。
        num = front->value;
        // 保存头节点并删除它。
        temp = front;
        front = front->next;
        delete temp;
    }

    // 更新 numItems.
    numItems--;
}
```
