### 三元地址代码中的表达式翻译

生成三元地址代码（Three-Address Code）涉及将从源代码系统地翻译为中间表示中的等效形式。考虑表达式 `a = b + c * d`。对应的三元地址代码可能是：

```
// 表达式的三元地址代码
t1 = c * d
t2 = b + t1
a = t2
```

在这里，`c` 和 `d` 的乘法结果被赋值给临时变量 `t1`，然后与 `b` 相加产生 `t2`，最后将 `t2` 赋值给变量 `a`。

### 三元地址代码中的控制流结构

除了表达式外，三元地址代码还支持条件语句和循环等控制流结构。例如，考虑一个简单 if 语句的源代码：

```
// 带有 if 语句的高级代码示例
if (x > 0) {
 y = 10;
}
```

对应的三元地址代码将条件和赋值翻译如下：

```
// if 语句的三元地址代码
if x > 0 goto L1
goto L2
L1: y = 10
L2:
```

在这里，条件分支（`if x > 0 goto L1`）在条件为真时控制流引导至标签 `L1`，随后的 `goto L2` 确保执行 if 语句之后的代码。标签 `L1` 代表赋值语句 `y = 10`，而 `L2` 作为 if 语句后无条件跳转的目标。
