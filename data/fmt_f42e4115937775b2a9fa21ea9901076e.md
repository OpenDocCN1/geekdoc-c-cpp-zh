## 指定描述性统计量关键字

`MEANS` 过程的默认统计量是 `N` 计数（非缺失值数量）、标准差以及数据集中每个数值变量的最小值和最大值。然而，你可能需要计算不同的统计量，例如中位数或范围。使用 `PROC MEANS` 语句中的统计关键字选项来指定在输出中显示的一个或多个统计量。

以下是 `PROC` 语句中可用的关键字：

**表 15.1** 描述性统计量关键字

| 关键字 | 说明 |
| --- | --- |
| CLM | 平均值的双侧置信限。 |
| CSS | 均值修正平方和。 |
| CV | 变异系数百分比。 |
| KURTOSIS | KURT 测量尾部厚度。 |
| LCLM | 平均值下单侧置信限。 |
| MAX | 最大值。 |
| MEAN | 所有数值的算术平均值。 |
| MIN | 最小值。 |
| MODE | 出现频率最高值。 |
| N | 非缺失观测数量。 |
| NMISS | 缺失观测数量。 |
| RANGE | 最大值与最小值之间的差。 |
| SKEWNESS | SKEW 测量偏离向某一方向更大的倾向。 |
| STDDEV / STD | 标准差，计算为方差的平方根。 |
| STDERR / STDMEAN | 平均值的标准误。 |
| SUM | 总和。 |
| SUMGT | 权重之和。 |
| USS | 未修正的平方和值。 |
| VAR | 方差。 |

**表 15.2** 分位数统计量

| 关键字 | 说明 |
| --- | --- |
| MEDIAN / P50 | 中位数或第50百分位数。 |
| P1 | 第1百分位数。 |
| P5 | 第5百分位数。 |
| P10 | 第10百分位数。 |
| Q1 / P25 | 下四分位数或第25百分位数。 |
| Q3 / P75 | 上四分位数或第75百分位数。 |
| P90 | 第90百分位数。 |
| P95 | 第95百分位数。 |

```sas
proc means data=cert.survey median range;
run;
```

## 使用 MAXDEC= 选项限制小数

默认情况下，`PROC MEANS` 使用 `BESTw.` 格式在报告中显示数值值。在没有指定的情况下，SAS 会根据可用字段宽度提供关于数值信息最多的格式。有时这会导致产生不必要的小数，使输出难以阅读。要限制小数，请在 `PROC MEANS` 语句中使用 `MAXDEC=` 选项，并设置为你偏好的长度。

语法，带有 `MAXDEC=` 的 `PROC MEANS` 语句：
`PROC MEANS <data=SAS数据集> <statistic(s)> MAXDEC=n;`
`n` 指定最大位数。

## 使用 VAR 语句指定变量

默认情况下，`MEANS` 过程为数据集中的每个数值变量生成统计量。通常只关注少数变量，特别是数据集很大时。排除某些类型的变量是有意义的。例如，标识变量 `ID` 的值不太可能产生有用的统计量。

要指定 `PROC MEANS` 分析的变量，请添加 `VAR` 语句并列出变量名。

语法，`VAR` 语句：
```sas
VAR variable(s);
```
`variable(s)` 列出要计算统计量的数值变量。

```sas
proc means data=cert.diabetes min max maxdec=0;
  var height weight;
run;
```

## 使用 CLASS 语句

你通常需要分组的统计量，而不是整个数据集。例如，按区域分组观测数量更有用。要对分组进行分析，请添加 `CLASS` 语句。

语法，`CLASS` 语句：
`CLASS variable(s);`
`variable(s)` 指定分类变量。`CLASS` 变量可以是字符或数值。`CLASS` 语句决定输出的顺序。以下输出是按性别分组的。

```sas
proc means data=cert.survey max maxdec=1;
  var urinary;
  class sex;
run;
```

## 使用 BY 语句进行分组

与 `CLASS` 语句一样，`BY` 语句指定用于对观测值分类的变量。但 `BY` 和 `CLASS` 在两个方面不同：

- 与 `CLASS` 处理不同，`BY` 分组处理要求数据已经按照 `BY` 变量的顺序进行了排序或索引。除非数据集已经过排序，否则在运行带有任何 `BY` 分组的 `PROC MEANS` 之前，你必须运行 `SORT` 过程。

> **注意**：如果不使用 `OUT=` 选项指定输出数据集，`PROC SORT` 将用新排序的观测值覆盖初始数据集。

- `BY` 分组统计结果的布局与 `CLASS` 分组的布局不同。注意，下面过程中的 `BY` 语句会创建四个小表；而 `CLASS` 语句会生成一个大表。

```sas
proc sort data=work.heart out=work.heartsort;
  by survey sex;
run;

proc means data=work.heart maxdec=1;
  var heart cardiac urinary;
  by survey sex;
run;
```

## 使用 OUTPUT 语句创建汇总数据集

要将统计量写入新数据集，请在 `MEANS` 过程中使用 `OUTPUT` 语句。

语法，`OUTPUT` 语句：
`OUTPUT OUT=sas-data-set <statistic=variable(s)>;`

- `OUT=` 指定输出数据集。
- `statistic` 指定要存储在输出数据集中的统计量。
- `variable(s)` 指定了要创建的变量名称。这些变量用于 `VAR` 语句中列出的分析变量。

> **提示**：你可以使用多个 `OUTPUT` 语句指定 `out=` 数据集。

`OUTPUT` 语句将统计量写入新的 SAS 数据集。默认情况下，会对所有数值变量或 `VAR` 语句中指定的变量生成汇总统计数据。要指定在新的 SAS 数据集中生成特定的统计量，请在 `OUTPUT` 语句中指定 `statistic=variable-name`。

示例创建了一个 `PROC MEANS` 报告。

```sas
proc means data=cert.diabetes;
  var age height weight;
  class sex;
  output out=work.diabetes_by_gender
    mean=AvgAge AvgHeight AvgWeight;
run;
```

```sas
proc means data=work.heart maxdec=1;
  var heart cardiac urinary;
  by survey sex;
run;
```
