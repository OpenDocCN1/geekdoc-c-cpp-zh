## 显示 11.9 使用 Money 对象数组的程序（部分 2，共 2）

<成员函数和重载运算符的定义位于此处。>

```cpp
// 读取 5 个金额并显示每个
// 金额与最大金额之间的差异。
int main() {
    Money amount[5], max;
    int i;
    cout << "Enter 5 amounts of money:\n";
    cin >> amount[0];
    max = amount[0];
    for (i = 1; i < 5; i++) {
        cin >> amount[i];
        if (max < amount[i])
            max = amount[i];
        //max 是 amount[0] 到 amount[i] 中的最大值。
    }
    Money difference[5];
    for (i = 0; i < 5; i++) {
        difference[i] = max - amount[i];
    }
    cout << "The highest amount is " << max << endl;
    cout << "The amounts and their\n";
    for (i = 0; i < 5; i++) {
        cout << amount[i] << " off by " << difference[i] << endl;
    }
    return 0;
}
```

输入 5 个金额：

$5.00 $10.00 $19.99 $20.00 $12.79

最高金额是 $20.00

$5.00 差 $15.00

$10.00 差 $10.00

$19.99 差 $0.01

$20.00 差 $0.00
