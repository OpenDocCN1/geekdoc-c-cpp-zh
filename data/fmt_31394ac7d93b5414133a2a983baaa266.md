## 为 Web 服务声明方法

您需要声明定义 Web 服务功能的方法来实现 Web 服务。Web 服务的方法应该能够通过 Internet 向 Web 应用程序发送数据以及从 Web 应用程序接收数据，以便 Web 应用程序可以访问 Web 服务。您可以通过将方法声明为 `Public` 并将 `WebMethod` 特性应用于这些方法，从而使 Web 服务方法能够与 Web 应用程序进行通信。

`WebMethod` 属性使 Web 服务方法能够与位于本地或远程位置的 Web 应用程序进行通信。将 `WebMethod` 属性与 Web 服务方法一起使用的语法如下：

`[ WebMethod ]`

`public returntype functionname()`

## 使用 WebService 类

假设您想在 Web 服务中使用常见的 ASP.NET 对象，例如 `Application`、`User`、`Session` 和 `Context`。在这种情况下您会怎么做？您会在 Web 服务中定义这些对象，然后再使用它们吗？在 Web 服务中使用这些对象的更好方式是让实现 Web 服务的类继承自 `WebService` 类。

`WebService` 类允许 Web 服务访问所有常见的 ASP.NET 对象，就如同这些对象是实现 Web 服务的类的成员一样。`WebService` 类位于 `System.Web.Services` 命名空间和 `System.Web.Services` 程序集中。现在，让我们创建一个使用 `WebService` 类的 Web 服务。

假设您希望 Web 服务确定运行该 Web 服务的服务器名称。您可以使用 `Server` 对象（它是 `WebService` 类的成员）来确定服务器名称。因此，您应该从 `WebService` 类派生实现 Web 服务的类来创建您的 Web 服务。
