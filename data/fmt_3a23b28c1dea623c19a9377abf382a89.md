3. 在 `FindGCDStein` 方法中，添加下方示例中的代码，它使用 Stein 算法计算并返回参数 `u` 和 `v` 指定值的最大公约数（GCD）。你可以手动输入这些代码，也可以使用 Mod0 代码片段。

> 注意：出于本次练习的考虑，你不需要理解这些代码。如果你有时间，可能会将此方法与练习场景中描述的算法进行比较。注意，此代码使用左移 (`<<`) 和右移 (`>>`) 运算符来执行快速的乘 2 和除 2 操作。如果你将一个整数左移一位，结果等同于将该整数乘以 2。同样，如果你将一个整数右移一位，结果等同于将该整数除以 2。此外，`|` 运算符在两个整数值之间执行位按或运算。因此，如果 `u` 或 `v` 其中之一为 0，表达式 `u | v` 是快速返回非零变量值的方法（如果两者都为 0）。同样，`&` 运算符执行位按与运算，因此表达式 `u & 1` 是快速判断 `u` 的值是奇数还是偶数的方法。

```csharp
public static int FindGCDStein(int u, int v)
{
    int k;
    // 步骤 1。
    // gcd(0, v) = v，因为任何数都能除尽 0，
    // 而 v 是除 v 的最大数。
    // 同样，gcd(u, 0) = u。gcd(0, 0) 通常没有
    // 定义，但将 gcd(0, 0) 设置为 0 是很方便的。
    // (u == 0 || v == 0)
    return u | v;

    // // 如果 u 和 v 均为偶数，那么 gcd(u, v) = 2*gcd(u/2, v/2)，
    // 因为 2 是一个公因数。
    for (k = 0; ((u | v) & 1) == 0; ++k) {
        u >>= 1;
        v >>= 1;
    }

    // 如果 u 是偶数而 v 是奇数，那么 gcd(u, v) = gcd(u/2, v)，
    // 因为 2 不是公因数。
    // 同样，如果 u 是奇数而 v 是偶数，
    // gcd(u, v) = gcd(u, v/2)。
    while (u & 1) u >>= 1;

    // 如果 u 和 v 均为奇数且 u >= v，
    // 那么 gcd(u, v) = gcd((u - v)/2, v)。
    // 如果两者均为奇数且 u < v，则 gcd(u, v) = gcd((v - u)/2, u)。
    // 这些是简单欧几里得算法一步的组合，
    // 该算法在每一步中都使用减法，以及上述步骤 3 的应用。
    // 除以 2 的结果是一个整数，因为
    // 奇数的差是偶数。
    while ((v & 1) == 0) // 循环 x
        v >>= 1;

    // 现在 u 和 v 均为奇数，所以 diff(u, v) 是偶数。
    // 设 u = min(u, v), v = diff(u, v)/2。
    if (u < v) {
        v -= u;
    } else {
        int diff = u - v;
        u = v;
    }

    v = diff;
    v >>= 1;
    // 重复步骤 3-4 直到 u = v，或者（再过一步）
    // 直到 u = 0；
    // 在任何情况下，结果都是 (2^k) * v，其中 k 是
    // 在步骤 2 中找到的 2 的公因数。
    while (v != 0) {
        u <<= k;
        return u;
    }
}
```
