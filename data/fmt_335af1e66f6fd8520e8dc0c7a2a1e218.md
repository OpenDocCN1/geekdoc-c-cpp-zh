## 程序 1：输入一个字符串并找到字符串中出现的元音数量

**输出窗口**

输入字符串：
世界上没有比健康的老人更美了 - 语堂
字符串中存在 25 个元音

```c
// 字符串中元音的数量
#include<stdio.h>
main()
{
    char string[200];
    int count=0, i=0;
    printf("Enter a string:\n");
    gets(string);
    while(string[i]!='\0')
    {
        switch(string[i])
        {
            case 'A':
            case 'E':
            case 'I':
            case 'O':
            case 'U':
            case 'a':
            case 'e':
            case 'i':
            case 'o':
            case 'u':
                count++;
        }
        i++;
    }
    if(count==1)
        printf("One vowel is present in the string");
    else
        printf("%d vowels are present in the string", count);
}
```

## 程序 4：从用户输入两个长度相同的字符串，并确定两个字符串对应位置上完全相同的字符次数

**输出窗口**

第一次执行
输入两个长度
输入第一个字符串：choice
输入第二个字符串：chance
对应位置相同字符 4 次

第二次执行
输入相等长度
输入第一个字符串：very
输入第二个字符串：much
对应位置相同字符 0 次

第三次执行
输入相等长度
输入第一个字符串：life
输入第二个字符串：lovely
输入的字符串长度不同

// 两个字符串对应位置相同字符的数量
