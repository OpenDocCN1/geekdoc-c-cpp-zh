**Listing 22.3: Showing the Code for the Code-Behind File for the Default.aspx Page**

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Web;
using System.Web.UI;
using System.Web.UI.WebControls;
using NewPublisherModel;
public partial class _Default : System.Web.UI.Page
{
    private NewPublisherEntities2 PublisherContext;
    protected void Page_Load(object sender, EventArgs e)
    {
        PublisherContext = new NewPublisherEntities2();
    }
    protected void DropDownList1_SelectedIndexChanged(object sender, EventArgs e)
    {
        Int32 AuthorID = Convert.ToInt32(DropDownList1.SelectedValue);
        var BookDetails = from bookD in PublisherContext.Books
                          where bookD.Author.AuthorID == AuthorID
                          select new
                          {
                              BookName = bookD.Title,
                              Pages = bookD.Pages,
                              ISBN = bookD.BookISBN
                          };
        GridView1.DataSource = BookDetails;
        GridView1.DataBind();
    }
}
```

在前面的代码中，`DropDownList1_SelectedIndexChanged` 事件包含将 `GridView1` 控件绑定到 `DropDownList1` 控件的代码。`Page_PreRenderComplete` 事件包含在页面预渲染时调用 `DropDownList1_SelectedIndexChanged` 事件的代码。预渲染事件在页面加载时将 GridView 控件与 Author Name 旁边的下拉列表绑定。

## 深入探讨

通用语言运行时（CLR）为 .NET Framework 代码提供执行环境。在 Visual Studio 中，在 CLR 上运行的代码称为托管代码。CLR 提供执行程序所需的各种函数和服务。这些服务的示例包括即时（JIT）编译、内存管理、线程管理、类型安全和异常处理。此 CLR 运行时功能也集成在 SQL Server 2008 中，这为开发人员提供了更大的灵活性来开发代码。SQL Server 2008 中集成的 CLR 功能允许您使用 C# 等托管语言在 .NET Framework 中创建 CLR 对象，例如存储过程和触发器，并通过在 SQL Server 2008 中创建程序集来在外部使用这些对象。您可以通过导入 `Microsoft.SqlServer.Server` 命名空间在 .NET Framework 中创建 CLR 对象。

在本章中，您将了解 CLR 在 SQL Server 2008 中的集成。本章首先介绍 SQL Server 2008 中的 CLR 主机。接下来，您将了解 `Microsoft.SqlServer.Server` 命名空间以及该命名空间中可用的类、接口和枚举。您还将了解各种 CLR 对象，例如存储过程、触发器、聚合函数、用户定义函数（UDF）和用户定义类型（UDT）。然后，您将了解如何在 SQL Server 2008 中处理可扩展标记语言（XML）数据。在本章的即时解决方案部分，您将学习如何在 .NET Framework 中创建和使用不同的 CLR 对象及其在结构化查询语言（SQL）中的使用。

让我们从 .NET 运行时在 SQL 中的托管开始。

### .NET 运行时托管

SQL Server 2008 提供了一个 CLR 集成功能，根据该功能，它可以托管 .NET Framework 4.0 的 CLR。CLR 集成功能使您能够以托管代码创建存储过程、触发器、UDF、UDT 和用户定义聚合，这提供了内存管理、线程同步和管理、异常处理、类型安全和调试服务的优势。

默认情况下，SQL Server 2008 中的 CLR 集成功能处于禁用状态，您可以使用 `sp_configure` 存储过程的 `clr enabled` 选项启用它。使用以下查询在 SQL Server Management Studio 中启用 CLR 集成功能：

```
sp_configure 'clr enabled', 1
GO
RECONFIGURE
GO
```
