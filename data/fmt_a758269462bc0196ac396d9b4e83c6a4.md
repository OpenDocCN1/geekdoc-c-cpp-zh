所有以 `vcomp` 为头的函数都是与 OpenMP 相关的，并存储在 `vcomp*.dll` 文件中。在这里启动了一组线程。

来看 `_mainomp$1`：

> 列表 3.126: MSVC 2012

```assembly
$T1 = -8          ; size = 4
$T2 = -4          ; size = 4

_mainomp$1 PROC
    push   ebp
    mov    ebp, esp
    push   ecx
    push   ecx
    push   esi
    lea    eax, DWORD PTR $T2[ebp]
    push   eax
    lea    eax, DWORD PTR $T1[ebp]
    push   eax
    push   eax
    push   1
    push   1
    push   2147483647
    push   0
    call    __vcomp_for_simple_init
    mov     esi, DWORD PTR T1[ebp]
    add     esi, 24
    jmp     _mainomp$1

_mainomp$1:
    push    esi
    call    check_nonce
    inc     esi

_mainomp$1:
    cmp     esi, DWORD PTR T2[ebp]
    je      _mainomp$1
    call    __vcomp_for_simple_init
    pop     esi
    leave
    ret
END
```

该函数是并行启动的，“n” 是 CPU 核心数。`vcomp_for_simple_init()` 根据当前线程计算当前线程的循环间隔。循环的起始值和结束值存储在 `T1` 和 `T2` 中。你可能还会注意到 `0xffffffff`（或 2147483647），`2147483647` 是 `vcomp_for_simple_init` 的一个参数。

注意：这是一个故意编写的最简单示例，但在实践中，OpenMP 的用法可能会更加困难和复杂。`sha512.c` 和 `sha64.h` 文件可以从 OpenSSL 库获取：http://www.openssl.org/source/
