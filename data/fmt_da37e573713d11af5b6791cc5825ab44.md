## 11.3 双目视觉

双目视觉（Stereovision）是一组图像分析技术，旨在从不同视角（视差）获取的两张（或多张）图像中检索有关真实世界的 3D 结构和深度信息。我们并未涵盖所有内容，而是处理了两个经典问题：两幅图像之间匹配点的搜索以及物体深度的估计。

### 11.3.1 极线几何

极线几何（图 11.10）对从不同观测点拍摄的同一场景的不同图像进行几何建模。它允许描述对应像素之间的依赖关系，即由在每幅图像上观测到的 3D 场景中的单个点形成的像素。

设 `I1` 和 `I2` 为两个透视相机 `C1` 和 `C2` 观测同一场景的两幅图像。设 `P1` 和 `P2` 为对应这两幅图像的投影矩阵。3D 场景中的点 `m ∈ ℝ³` 投影到 `I1` 上的 `m1 = P1m` 和 `I2` 上的 `m2 = P2m`，其中 `m1` 和 `m2` 用齐次坐标表示。在下文中，我们关注 `m1` 和 `m2` 之间的联系。这些联系由极线几何刻画，它源于极线约束。

#### 极线约束

极线约束描述了这样一个事实：点 `m1` 的对应点 `m2` 位于 `l2` 中的直线 `ℓm1` 上。事实上，`m2` 属于由 `C1` 和 `C2` 定义的平面。直线 `ℓm1` 点 `m1` 在 `l2` 中的极线。该约束是对称的。图像中所有的极线都交于一点 `e`，称为极点（epipole），它对应于另一幅图像投影中心的投影。因此 `e1 = P1C2` 且 `e2 = P2C1`。

#### 基础矩阵

该约束可以通过基础矩阵以代数形式表示，验证极线关系：

`m2^T F m1 = 0`

则 `ℓm1 = F m1`，对称地 `ℓm2 = F^T m2`。这个秩为 2 的矩阵（`Fe1 = 0`）刻画了两图像之间所有的几何关系，除了相机的内部参数（焦距、尺度因子、光轴）。它在尺度因子内定义。

![](img/6b7de6c7ce31f7bb2927e7184da0492f_282_0.png)

图 11.10 – 极线几何。

矩阵 `F` 可以从图像 `I1` 和 `I2` 之间至少 8 个点匹配中估计出来。这些点可以自动获得（例如使用感兴趣点检测器，见第 6.1 节），或由用户点击。

我们提供了一个简单的交互程序（实现在代码 11.16 中），它允许在两幅图像上交替点击 `n` 对点，并返回一个大小为 `n × 2×3` 的 `CIMgList`，其中列表的每个元素都是图像，其列是点击点 `m^k` 的坐标。

设 `F = (fij)≤ i,j≤3` 且 `f = (f11 f12 f13 f21 f22 f23 f31 f32 f33)^T`。对于 `I1` 和 `I2` 中的 `n` 对对应点 `(m^k,m'^k),k∈[1,n]`，关系 `mk^T F m'^k = 0` 成立的。如果 `m^k = (x^k, y^k)^T∈[1,2]`，则 `mk^T F m'^k = 0`。

```cpp
CImg> FundamentalMatrix(CImgList<>& m, int n) {
  CImg> F(3,3);
  A(9,n);
  // 矩阵 A.
  for (int i = 0; i<n; ++i) {
    A(0,i) = m(i,1,0)*m(i,0,0);
    A(1,i) = m(i,1,0)*m(i,0,1);
    A(2,i) = m(i,1,0);
    A(3,i) = m(i,1,1)*m(i,0,0);
    A(4,i) = m(i,1,1)*m(i,0,1);
    A(5,i) = m(i,1,1);
    A(6,i) = m(i,0,0);
    A(7,i) = m(i,0,1);
    A(8,i) = 1;
  }

  // SVD.
  CImg> U, S, V;
  A.SVD(U,S,V);

  // F = V 的最后一列.
  CImg> f = V.get_column(8);
  F(0,0) = f(0); F(1,0) = f(1); F(2,0) = f(2);
  F(0,1) = f(3); F(1,1) = f(4); F(2,1) = f(5);
  F(0,2) = f(6); F(1,2) = f(7); F(2,2) = f(8);

  return F;
}
```

**F** 通常不是秩为 2 的矩阵（如果没有测量或计算误差，它将是秩 2 的）。为了强制执行秩，我们再次通过奇异分解。设 **F** 为之前计算的矩阵。我们寻找最接近 **F** 的秩为 2 的矩阵 `F̂`，通过计算 `U Σ` 直到最小奇异值为零，并重构 `F̂ = U Σ' Vᵀ`，其中 `Σ'` 与 `Σ` 的区别在于最后一列。

实现非常简单

```cpp
CImg> U, S, V;
F.SVD(U,S,V);
S(2) = 0;
F = U*S.diagonal()*V.transpose();
```

> 知道 `F` 后，很容易找到极点：从分解 `F=U^T e1`（或 `e2`）得到的是 `U`（或 `V`）中对应于零奇异值的列。

## MATCHING

A possible use of the epipolar line is the matching of points detected on images `I1` and `I2`.

Let's suppose that we have `ni` points of interest detected on the image `Ii`, `1 ≤ i ≤ 2` by a dedicated algorithm (Harris and Stephens detector type, see Section 6.1). Among these points we assume to know at least eight correspondences, that the fundamental matrix `F` can be estimated. The question that arises is the following: for a point of interest `Pi^1` detected on `I1`, is it possible to find its corresponding point on `I2`, if it indeed exists?

A simple solution to this matching problem is to look for the point on the epipolar line associated with `Pi^1` with maximum correlation. For this purpose, we define around `Pi^1` a window of size `t`, and we look for the window of the same size, centered at a point on the epipolar line, having a maximum correlation. This technique, similar to motion estimation by correlation, is very simple to implement and robust to errors in the estimation of `F`. It assumes a conservation of luminance, and no geometrical deformation of the two images.

Other methods, not discussed here, such as the `RANSAC` algorithm, the phase shift approach or methods based on dynamic programming.

> Epipolar lines have no reason to be parallel. But this makes it easier to find the corresponding image and to estimate the depth. If we rectify the images, i.e., have parallel epipars, we know how to compute the images corresponding to the scene with parallel image planes. For this, we can generate an image of the scene by rotation around the optical center without knowing the scene. It is a question of projecting the images on a plane parallel to the baseline (the line passing through `C1` and `C2`) in order to have rectified views.

## 11.3.2 Depth estimation

Once the `m1 - m2` matching is done, it is possible to retrieve the depth information using the disparity `d` of the two points. We assume in the following, for simplicity, that the images are rectified, so the epipolar lines are parallel. The depth information of a point `m` can be calculated by a simple geometrical consideration (Fig. 11.12).

If `b` is the distance between the two cameras and `f` the focal length (assumed equal) of the two sensors, the depth `z` of the point `m` in the scene can be estimated by

```
$z = \frac{x}{f} = \frac{x-b}{x_2} = \frac{y}{y_2}$ thus $z = \frac{bf}{d}$ with $d = x-b$
```

The matching can be done by epipolar matching, as we have seen it. It is also possible to generate dense disparity maps, by computing the disparity of each pixel using its neighborhood.
