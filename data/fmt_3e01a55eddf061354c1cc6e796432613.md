
在涉及数字的计算问题中（通常在计算几何中），我们有两种自然的复杂度模型。一种是图灵机模型，所有数字必须编码为位流；另一种是将每个数字视为基本对象，我们计算代数运算的次数。在简单情况下，唯一的代数运算是四种算术运算 `+,-,*/`。这些复杂度模型分别称为位数模型和算术模型。然而，我们指出这些模型在复杂度上是相关的。具体来说，某些问题在一个模型中需要非多项式时间，而在另一个模型中是多项式的。例如，线性规划问题在位数模型下是多项式的，但在代数模型下未知。另一方面，多边形障碍之间的最短路径在代数模型中是多项式的，但在位数模型中不是。

## 1. 命题逻辑

*布尔变量*是一个假设符号为“1”或“0”（或者为“true”或“false”）的变量。如果 `x` 是一个布尔变量，则其否定表示为 `x̄` 或 `¬x`。*文字*（literal）是一个布尔变量或该变量的否定。

一个（布尔）公式是一个变量，或者递归地具有以下三种形式之一：

- 合取：`φ ∧ ψ`

- 析取：`φ ∨ ψ`

- 否定：`¬φ`

`(x_1 ∧ x_2) ∨ ((x̄_1 ∨ x_2) ∧ (x̄_2 ∨ x̄_3))` (1)

其中每个 `x_i` 都由符号 `x_i*` 编码，其中 `b_0, …, b_n ∈ {0,1}` 是二进制下的整数。

使用这种约定，并假设除非使用了 `x_i`，否则就不会使用变量 `x_{i+1}`，很容易看出公式 `φ` 的大小为 `O(k+m)`，其中 `k` 是布尔算符的数量，`m` 是出现的次数。

如果 `x` 或其否定出现在公式 `F` 中，则变量 `x` 在公式 `F` 中*出现*。出现在 `F` 中的所有变量都是 `x_1, x_2, …, x_n`；我们将其记为 `F(x_1, …, x_n)`。在这种表示法中，（可能所有的）`x` 不出现在 `F` 中。对变量集 `X` 的*赋值*是一个函数 `I : X → {0,1}`。如果 `X` 包含 `F` 的所有变量，且 `I` 是 `X` 的赋值，那么 `F`（通过对 `F` 的大小进行归纳）赋予一个值 `I(F)=I(φ)`；否则：

- 如果 `F` 是否定 `(¬φ)`，则 `I(F) = 1 - I(φ)`；

- 如果 `F` 是合取 `(φ ∧ ψ)`，则 `I(F) = min(I(φ), I(ψ))`；

- 如果 `F` 是析取 `(φ ∨ ψ)`，则 `I(F) = max(I(φ), I(ψ))`。

我们说如果 `I(F)=1`，则 `F` 是*可满足的*。如果不存在能满足它的赋值，则公式 `F` 是*不可满足的*。因此，方程 (1) 中的公式被 `I(x_i)=1` 的 `I` 满足。

两个公式 `φ` 和 `ψ` 是*等价的*，如果对于这两个公式变量的任意赋值 `I`，都有 `I(φ)=I(ψ)`。如果公式都是可满足的或都是不可满足的，则它们是*共同满足的*。

如示例 (1) 所示，括号用于合取和析取的属性分组，即：

`φ_1 ∧ φ_2 ≡ (φ_1 ∧ φ_2) ∧ φ_3`；`φ_1 ∨ φ_2 ≡ (φ_1 ∨ φ_2) ∨ φ_3`，

交换律的，即：

`φ_1 ∧ φ_2 ≡ φ_2 ∧ φ_1`；`φ_1 ∨ φ_2 ≡ φ_2 ∨ φ_1`，

并利用 `φ ∨ φ ≡ φ; φ ∧ φ ≡ φ` 的事实。

因此 (A.1) 可以简单地写为

```
$(x_1 ∨ x_2 ∨ x_3) ∧ (x̄_1 ∨ x_2 ∨ x̄_3) ∧ (x̄_1 ∨ x̄_2 ∨ x_3).
```

如果 `S = {u_1, …, u_n}` 是文字集，我们也写成

```
$\bigwedge_{u \in S} u \quad \text{或} \quad \bigvee_{i=1}^n u_i$
```

表示 `S` 中文字的合取。我们以类似的方式使用 `∧` 表示合取。一个由文字的析取的合取组成的公式称为*合取范式* (CNF)。示例 (A.2) 就是这样一个公式。*析取范式* (DNF) 的定义类似。

根据上述性质，CNF 公式可以给出一个方便的替代形式：一个处于*子句形式*的 CNF 公式是一组子句，其中每个*子句*是一个文字集。将普通形式的公式转换为子句形式的方法是显而易见的；例如，子句形式的公式 (A.2) 为：

```
{{x_1, x_2, x_3},{x̄_1, x̄_2},{x̄_2, x̄_3}}
```

注意，由于子句被定义为集合，重复的文字会被删除，如上述第二个子句所示。子句形式 CNF 公式的可满足性特别为简单：令 `X` 为 CNF 公式 `F` 中出现的变量集，令 `I` 为 `X` 的赋值。`X`*满足*子句 `C`，当且仅当对于 `C` 中的某个文字 `u`，我们有 `I(u) = 1`。`I` *满足* `F`，当且仅当它满足 `F` 中的每个子句。例如，以下 CNF 公式

```
{{x_1, x_2},{x̄_1, x̄_2},{x_1},{x̄_2}}
```

是不可满足的。
