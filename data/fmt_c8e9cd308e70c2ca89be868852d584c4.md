
## 7.3.6 双曲函数

### 7.3.6.1 cacosh 函数

概要

```
#include <complex.h>
double complex cacosh(double complex z);
float complex acosh(float complex z);
long double complex achl(long double complex z);
```

描述

`cacosh` 函数计算 `z` 的复数双曲余弦，在实轴上小于 1 的处有支割。

返回值

`cacosh` 函数返回复数双曲余弦值，其范围在实轴上的非负值带内，并在虚轴上处于 $[-i\pi, +i\pi]$ 区间。

### 7.3.6.2 casinh 函数

概要

```
#include <complex.h>
double complex casinh(double complex z);
float complex casinhf(float complex z);
long double casinl(long double complex z);
```

描述

`casinh` 函数计算 `z` 的复数双曲反正弦，其支割沿虚轴位于区间 $[-i, +i]$ 之外。

返回值

`casinh` 函数返回复数双曲反正弦值，其范围在一个沿实轴方向数学上无界的带内，并在虚轴上处于 $[-i\pi/2, +i\pi/2]$ 区间。

返回值

`catanh` 函数返回复数双曲反切正值，其范围在一个沿实轴方向数学上无界的带内，并在虚轴上处于 $[-i\pi/2, +i\pi/2]$ 区间。

## 7.4.2 大小写映射函数

### 7.4.2.1 tollower 函数

概要

```
#include <ctype.h>
int tollower(int c);
```

描述

`tollower` 函数将大写字母转换为对应的小写字母。

返回值

如果参数是一个 `isupper` 为真的字符，且根据当前区域指定存在一个或多个对应的 `islower` 为真的字符，则 `tollower` 函数返回其中一个对应字符（对于任何给定的区域，返回的总是同一个）；否则，返回参数本身。

### 7.4.2.2 toupper 函数

概要

```
#include <ctype.h>
int toupper(int c);
```

描述

`toupper` 函数将小写字母转换为对应的大写字母。

返回值

如果参数是一个 `islower` 为真的字符，且根据当前区域指定存在一个或多个对应的 `isupper` 为真的字符，则 `toupper` 函数返回其中一个对应字符（对于任何给定的区域，返回的总是同一个）；否则，返回参数。
