**¶68. 平滑凸起函数。** 考虑“sigmoid”函数

```
h(x) := { e^{-1/x^2} 若 x > 0; 0 若 x <= 0. }
```

注意 `0 <= h(x) <= 1` 且对于 `x > 0`，`h'(x) = e^{-1/x^2}(2x^{-3})`。那么

```
h'(x) := 2/x^3 * 1/(1+x^{-2}+x^{-4}+x^{-6}+...) = 2/(x^3+x^1+x^{-1}+x^{-3}+...)
```

因此，当 `x -> 0^+` 时，`h'(x) -> 0`。故对于所有 `n >= 2`，`h^{(n)}(0) = 0`。

图 3：Sigmoid 函数

该函数如图3 所示。我们将 `h(x)` 修改为 `H(x)` 以创建一个更明显的阶梯函数：

```
H(x) := h(x)/(h(1-x)+h(x))
```

观察到

```
H(x) := { 0 若 x <= 1; 1 若 x >= 1; 1/2 若 x = 1/2; 严格递增 若 0 < x < 1. }
```

最后，我们创建了一个“凸起函数”

```
B(x) := { H(2x) 若 x <= 1/2; H(2-2x) 若 x >= 1/2. }
```

观察到

```
B(x) := { 0 若 x <= 0 或 x >= 1; 1 若 x = 1/2; 严格递增 若 0 < x < 1/2; 严格递减 若 1/2 < x < 1. }
```

对于所有 `n >= 1`，`H^{(n)}(0) = H^{(n)}(1) = 0`。

72. 孤立根的复杂度。虽然孤立根是可计算的，但它们可能有任意高的复杂度：引理 33。`x_0` 属于 `[0,1]` 是可计算实数。那么存在一个递增函数 `f_0 : [0,1] -> R`，使得 `ZERO(f_0) = {x_0}`。

证明。假设 `F : N -> D` 是 `x_0` 的近似。不失一般性，假设 `a,b` 属于 `D` 使得 `0 < a < b`。我们构造线性近似 `F : N x D[0,1] -> D` 对于 `f_0` 如下：对于每个 `n` 属于 `N` 和 `d` 属于 `D[0,1]`,

```
x_n(max) = max{a, |x - 2^{-i}| : i = 0, ..., n}
```

和

```
x^*(min) = min{b, |x + 2^{-i}| : i = 0, ..., n}
```

因此，对于所有 `n`，我们定义 `g_n : [0,1] -> R` 为在 `x_*(n)` 和 `x^*(n)` 处的分段线性函数。对于 `d` 属于 `{0, 1, x_*(n), x^*(n)}`，我们有

```
g_n(d) := { -2^{-n} 若 d = 0; 0 若 d = x_*(n) 或 d = x^*(n); +2^{-n} 若 d = 1. }
```

查看展示 `g_n` 的插图

注意对于每个 `t`，对于足够大的 `(i > i(t))`，我们有

```
g_i(t) := { 0 若 t = x_0; <0 若 t < x_0; >0 若 t > x_0. }
```

现在定义函数 `F_n`，使得 `F_n(t) = sum_{i=0}^{n} g_i(t)`。注意当 `n -> 无穷` 时，`F_n` 收敛于

```
f_0(t) = sum_{i=0}^{无穷} g_i(t) := { 0 若 t = x_0; <0 若 t < x_0; >0 若 t > x_0. }
```

因此 `ZERO(f_0) = {x_0}`。很容易看出每个 `g_n` 都是递增的，因此 `F_n(d) = F(n,d) : n 属于 N)` 快速收敛于 `f_0`，对于所有 `t` 属于 `[0,1]`。

```
|F_n(t) - f_0(t)| <= sum_{i=n+1}^{无穷} 2^{-i} <= 2^{-n}.
```

显然，一致近似函数 `F(n,d) := F_n(d)` 显然是递归的。最后，为了证明 `g_n` 是递归的，只需记住 `f_0` 有一个递归模。

### 第31 页

一个 `S` 属于 `R^k` 是**正可识别的**，如果其特征函数 `chi_S` 是正可近似的。如果 `f` 是集合 `S` 的特征函数，那么 `f` 也是 `S` 的**正近似**。因此，(24) 变为

```
chi_S(d[p]) = f(d[p]) = { 1 若 B(d,p) 交 S != 空集; 0 若 B(d,p-1) 交 S = 空集 }
```

与之前一样，这两个句是不完整的。为了满足“完全形式”的要求，我们要求：

```
chi_S(d[p]) = 1 => B(d,p) 交 S != 空集
chi_S(d[p]) = 0 => B(d,p-1) 交 S = 空集
```

对于**负可识别性**有一个类似的定义：

```
chi_S(d[p]) = f(d[p]) = { 0 若 B(d,p) 交 S != 空集; 1 若 B(d,p-1) 交 S = 空集 }
```

主要来说，如果 `S` 既是正可识别又是负可识别的，我们说 `S` 是**可识别的**。

**75. 距离函数。** 我们通过距离函数研究识别性。**`S` 的距离函数** `d_S: R^k -> R 并 {无穷}`，`d_S(x) = inf{||x-y|| : y 属于 S}`。在 `S = 空集` 的情况下，对于所有 `x`，`d_S(x) = 无穷`。然而，为了避免这种平凡情况，从现在起我们假设 `S` 非空。下一个引理显示 `d_S` 在非常强的意义下是连续的

**引理 36。** 距离函数 `d_S` 对于所有 `x, y` 属于 `R^k` 具有 Lipschitz 常数 1。

证明。不失一般性，假设 `d_S(x) >= d_S(y)` 且对于某些 `z` 属于 `S`，`d_S(y) >= ||y-z||`。那么下式是正确的：

```
|d_S(x) - d_S(y)| = d_S(x) - d_S(y) <= ||x-z|| - ||y-z|| <= ||x-y||.
```

Q.E.D.

**推论 37。** 如果 `d_S` 是可近似，则 `d_S` 是可计算的。

证明。`d_S` 的 Lipschitz 常数 1 意味着 `d_S` 有一个递归模，`m(n)=n`。该结果遵循可计算函数的刻画，定理 15。

Q.E.D.
