### 9
`*restrict*` 限定符的好处是它们允许翻译器在不检查程序中任何 `f` 调用的情况下对 `f` 进行有效的依赖分析。代价是程序员必须检查所有的调用以确保没有给定的未定义行为。例如，`f` `g` 的第二次调用具有未定义行为，因为 `d[1]` 到 `d[49]` 的每个元素都被通过 `p` 和 `q` 访问。

## 6.7.4 函数限定符

### 语法

```c
function-specifier:
inline
_Noreturn
```

### 约束

函数限定符应仅用于函数标识符的声明。

具有外部链接的函数的内联 `inline` 定义不应包含具有静态或线程存储持续期的可修改对象的定义，且不应包含对具有内部链接标识符的引用。

在托管 `hosted` 环境中，`main` 的声明中不应出现函数限定符。

### 语义

函数限定符可以出现多次；其行为与出现一次相同。

用 `inline` 函数限定符声明的函数是内联函数。将函数标记为内联建议对该函数的调用将尽可能快。

此类建议的有效程度取决于实现 `implementation-defined`。¹³⁹

任何具有外部链接的函数可以是内联函数。对于具有外部链接的函数，适用以下限制：如果使用 `inline` 函数限定符声明一个函数，则它也必须在同一个翻译单元中定义。如果一个翻译单元中某个函数的所有文件声明都包含 `inline` 函数限定符且没有 `extern`，则该翻译单元中的定义是*内联*的。内联定义不为函数提供外部定义，也不禁止在另一个翻译单元中进行外部定义。内联定义提供了外部定义的替代方案，翻译器可以使用它来实现同一翻译单元内对该函数的任何调用。对函数的调用是使用内联定义还是外部定义是未指定的。¹⁴⁰

用 `_noreturn` 函数限定符声明的函数不应返回其调用者。

## 推荐做法

对于一个用 `_Noreturn` 函数限定符声明、且似乎能够返回其调用者的函数，实现应对其产生一个诊断消息。

示例 1 具有外部链接的内联函数的声明可以导致外部定义，也可以导致仅在翻译单元内可用的定义。带有 `extern` 的文件范围声明创建一个外部定义。此示例显示了整个翻译单元。

```c
inline double f(double t)
{
    return (9.0 * t) / 5.0 + 32.0;
}
inline double cells(double t)
{
    return (5.0 * (t - 32.0)) / 9.0;
}
extern double jahr(double); // 创建外部定义
```

138) 通过使用（例如）通常函数调用机制的替代方案，例如“内联替换”。内联替换不是文本上的，也不会创建一个新函数。因此，例如，在函数体内部使用的宏的扩展使用的是该函数体出现时具有的定义，而不是调用函数时的定义；且标识符指的是函数体发生处作用域内的声明。无论除外部定义外发生了多少次内联定义，该函数都有唯一的地址。

139) 例如，某种实现可能永远不执行内联替换，或者可能只对 `inline` 声明的作用域执行内联替换。

140) 由于内联定义区别于相应的外部定义并区别于其他翻译单元中的任何其他内联定义，所有具有静态存储持续期的对应对象在每个定义中也是不同的。

```c
double convert (int is_fahr, double temp)
{
    /* 翻译器执行内联替换 */
    return is_fahr ? cels(temp) : fahr(temp);
}
```

注意 `fahr` 的定义是一个外部定义，因为 `fahr` 是用 `extern` 声明的，但 `cels` 的定义是内联定义。由于 `cels` 具有外部链接并被引用，必须在另一个翻译单元中出现外部定义（见 6.9）；内联定义和外部定义是不同的，并可用于调用。

## 6.7.6 声明符

### 语法

```c
declarator:
    pointer_opt
direct-declarator:
    identifier
    ( declarator )
    direct-declarator [ expression-opt ]
    direct-declarator [ static ]
    direct-declarator ( parameter-type-list )
pointer:
    * type-qualifier-list_opt
type-qualifier-list:
    type-qualifier
    type-qualifier type-qualifier
parameter-type-list:
    parameter-list
    parameter-list , ...
-list:

identifier
identifier-list , identifier
```

### 语义

每个声明符声明一个标识符，并断言当与声明符相同的操作数出现在表达式中时，它指定由限定符指示的作用、存储持续期和类型。

声明符是不属于另一个声明符的声明符。完整声明符的结束是一个序列点。如果在完整声明符的嵌套声明符序列中存在一个指定变长度类型的声明符，则完整声明符指定的类型被称为是*变修改的*。此外，任何通过声明符从变修改类型派生的类型本身也是变修改的。

在以下子句中，考虑声明

```c
T D1
```

其中 `T` 包含指定类型（如 `int`）的限定符，且 `D1` 是包含标识符 `ident` 的声明符。在各种声明符形式中标识符指定的类型通过这种归纳方式描述。

如果，在声明 `T D1` 中，`D1` 的形式为

```c
ident
```

则 `ident` 指定的类型为 `T`。

如果，在声明 `T D1` 中，`D1` 的形式为

```c
( D )
```

则 `ident` 的类型由声明 `T D` 指定。因此，括号中的声明符与无括号的声明符相同，但复杂声明符的绑定可能会被括号改变。

## 实现限制

如 5.2.4.1 所示，实现可能会限制修改算术、结构、联合或 `void` 类型的指针、数组和函数声明符的数量，无论是直接还是通过一个或多个 `typedef`。

### 6.7.6.1 指针声明符 (Pointer declarators)

### 语义

如果在声明 `TD1` 中，`D1` 的形式为：

+   * type-qualifier-listopt D

并且声明 `TD` 中为 `ident` 指定的类型为`derived-declarator-type-list T`，那么为 `ident` 指定的类型为`derived-declarator-type-list type-qualifier-list pointer to T`。对于列表中的每个类型限定符，`ident` 都是具有该限定符的指针。

两个指针类型要兼容，两者都应具有相同的限定符，且两者都指向兼容的类型。

示例 下述的成对声明演示了“指向常量值的变量指针”与“指向变量值的常量指针”之间的区别。

```
const int *ptr_to_constant;
int *constant_ptr;
```

`ptr_to_constant` 指向的任何对象的内容不能通过指针修改，但 `ptr_to_constant` 本身可以更改以指向另一个对象。同样，`constant_ptr` 指向的 `int` 内容可以修改，但 `constant_ptr` 本身应始终指向同一个位置。

通过包含对类型`pointer to int`的定义，可以明确常量指针 `constant_ptr` 的声明。

```
typedef int *int_ptr;
const int constant_ptr;
```

将 `constant_ptr` 声明为类型`const-qualified pointer to int`的对象。

### 6.7.6.2 数组声明符 (Array declarators)

### 约束

除了可选的类型限定符和关键字 `static` 外，`[ ]` 可以界定一个表达式或 `*`。如果它们界定一个表达式（指定数组的大小），该表达式应具有整数类型。如果该表达式是常量表达式，其值应大于零。元素类型不应是不完全类型或函数类型。可选的类型限定符和关键字 `static` 应仅出现在具有数组类型的函数参数声明中，且仅出现在最外层的数组类型推文中。

如果一个标识符被声明为具有变体类型（variably modified type），它应该是一个普通标识符（如 6.2.3 定义）、没有链接，且具有块作用域或函数原型作用域。如果一个标识符被声明为具有静态或线程存储持续期的对象，它不应具有变长数组类型。

### 语义

如果在声明 `T D1` 中，`D1` 具有以下形式之一：

**D[ type-qualifier-list_opt assignment-expression_opt ]**

**D[ static type-qualifier-list_opt assignment-expression ]**

**D[ type-qualifier-list_opt static assignment-expression * ]**

并且声明 `T D` 中为 `ident` 指定的类型为`derived-declarator-type-list array of T`¹⁴²（参见 6.7.6.3 关于可选类型限定符和关键字 `static` 的含义）。

如果没有设置大小，则数组是不完全类型。如果大小不是表达式，则该数组类型为未指定大小的变长数组，它只能在具有函数原型作用域的声明或类型名中使用¹⁴³；此类数组仍然完整类型。如果大小是整数常量表达式且元素类型具有已知的常量大小，则数组类型不是变长数组类型；否则，数组类型为变长数组类型。（变长数组是一种条件性特性，实现不一定支持；参见 6.10.8.3。）

如果大小是一个不是整数常量表达式的表达式：如果它出现在函数原型作用域的声明中，则被视为被 _ 替换；否则，每次求值时其值都应大于零。变长数组类型实例的大小在其生命周期内不会发生变化。当大小表达式是 `sizeof` 运算符的操作数的一部分，且更改大小表达式的值不会影响运算符的结果，则大小表达式是否求值是不确定的。

两个数组类型要兼容，两者都应具有兼容的元素类型，如果两个大小都存在且为常量表达式，则两个大小指定应具有相同的常量值。如果两个数组使用在需要它们兼容的语文中，且两个大小指定求出的值不相等，则将是未定义行为。
