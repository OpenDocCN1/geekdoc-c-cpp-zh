
## PROC SGPLOT 过程语法

```
PROC SGPLOT < DATA= data-set > < options >;
plot-statement(s) required-parameters < / options >;
axis-statement(s);
legend-statement(s);
inset-statement(s);
RUN;
```

图 2.6 显示了 `SGPLOT` 过程的典型用法。在这个示例中，我们为 `Horsepower`（马力）变量创建分布语句。使用了三个独立的绘图语句，每个对应一个数据元素。这些语句按照图 2.7 所示的顺序渲染。

```
proc sgplot data=sashelp.cars;
histogram horsepower;
density horsepower;
density horsepower / type=kernel;
keylegend / location=inside

position=topright across=1;
xaxis;
run;
```

如上所述，支持的绘图语句分为四类。每个类别中的绘图语句可以在过程步骤中组合。来自 `Basic Plots` 组和 `Fit and Confidence Plots` 组的绘图也可以组合。

根据需要可以使用 `INSET`、`REFLINE` 和 `KEYLEGEND` 语句将这些内容添加到图表中。

轴语句可用于自定义四个轴中的任意一个：

- `XAXIS` 位于图表的底部。
- `YAXIS` 位于图表的左侧。
- `XAXIS` 位于图表的顶部。
- `YAXIS` 位于图表的右侧。

## 2.3 SGPANE 过程

`SGPANE` 过程将 `SGPLOT` 过程的功能扩展到分类面板，使用一个或多个分类变量。图 1.12 和图 1.13 中之前的示例是使用 `SGPANE` 过程创建的分类面板。

`SGPANE` 过程的语法如下：

```
1. PROC SGPANE DATA=data-set < options >;
2. PANELBY classvar < classvar2 < classvarN > / options >;
3. < plot-statement (s) >;
4. < refine-statement (s) >;
< inset-statement (s) >;
< axis-statement (s) >;
< keylegend-statement (s) >;
RUN;
```

- 1. 过程语句支持多个选项，这些选项将在后续章节的示例中演示。
- 2. `PANELBY` 语句是必需的，必须放置在任何绘图、精炼、插入、轴或图例语句之前。该语句用于设置布局类型和其他控制单元格整体分面板的选项。
- 3. 使用一个或多个绘图语句来表示数据。每个绘图语句都有自己的一套数据角色和选项，将在后续章节中详细说明。该过程支持与 `SGPLOT` 过程的大多数绘图语句。
- 4. 支持的语句可自定义图表：
    a. 参考线 `Reference Lines`
    b. 轴 `Axes`
    c. 图例 `Legends`

`PANELBY` 语句是必需的，必须位于任何绘图、轴、参考线或图例语句之前。

`PANELBY` 语句必须提供一个或多个分类变量。过程根据分类变量唯一值的所有交叉自动将图表区域划分为多个单元格。在图 2.10 中，我们指定了分类变量 `Origin`（产地）和 `Type`（类型），每个有两个唯一值。因此，我们得到了一个具有四个单元格的图，如图 2.11 所示。每个单元格有两个标题。

每个单元格的数据是基于该单元格的分类值的子集。在图 2.11 中，标题为 `Asia` 的单元格显示 `Origin='Asia'` 的数据子集。

`ROWAXIS` 和 `COLAXIS` 等非绘图语句用于自定义公共轴。根据语法检查自动创建图例。

由此过程创建的所有图具有共同的外部轴：

- 所有列的 x 轴是统一的。
- 所有行的 y 轴是统一的。
- 在行或列中可以设置 `Uniform` 选项。
