
# 电子邮件基础

## 撰写电子邮件

在撰写电子邮件时，你必须输入收件人、主题和正文。你可以选择性包含附件。在写邮件时，“收件人”用于主要收件人，“抄送”用于接收副本的人，“密送”用于那些将接收不公开副本的人。你可以选择地从 Outlook 中的联系人列表（或你电子邮件应用程序中的等效列表）中选择收件人。

## 联系人列表

大多数电子邮件客户端都允许你保存与你通信的人的电子邮件地址，并在写邮件时使用它们。在 Outlook 中，这就是联系人列表。

## 回复选项

你可以通过点击“回复”按钮回复收到的消息；其他选项包括“回复全部”和“转发”。

## 离开自动回复

离开回复会向在你离开期间给你发邮件的人发送自动回复。只有当你拥有 Exchange 服务器时，你才能在 Outlook 中设置此项。否则，你可能可以通过提供商为你的电子邮件账户提供的网页界面进行配置。

## 签名

签名是自动附加到输出邮件末的文本。你可以在你的邮件客户端中设置此项。

## 存档邮件

为了避免邮件文件过大，你可以定期存档消息，这意味着根据你指定的标准将消息传输到辅助存储文件夹中。

## 垃圾邮件过滤

欢迎的垃圾邮件（也称为垃圾邮件）可以使用邮件过滤软件降至最低，该软件可能包括黑名单和白名单。

## Web 的工作原理

在短短一代人的范围内，互联网和万维网彻底改变了我们的生活。通过这些技术，我们可以比以往任何时候都更容易与他人建立联系——无论他们是在隔壁还是在地球的另一端。互联网还让电子商务成为可能，并扩展了我们对广泛话题的认知。

但这项技术是如何工作的呢？哪些组件和技术是实现这种通信必要的？如何在网上找到信息？这些主题是本章的重点。

### 核心概念

**互联网**：由多家公司、政府和标准组织合作创建的全球分组交换网络。互联网是一个由数百万台计算机组成的全球网络，它们之间可以相互通信。只要两台计算机连接到互联网，它们就可以相互共享信息。

**万维网 (WWW)**：存储在公共访问服务器上的互联信息页面网络，是互联网的一部分；这些页面使用一致的页面布局和格式语言。

### Web 浏览组件

Web 浏览涉及以下三个组件：

- **Web 服务器**：存储并提供网站的访问，接收网页数据请求并通过互联网发送数据提供数据的服务器。
- **Web 浏览器**：向个人请求并显示信息，用于访问网站并检索或上传信息的应用程序。
- **Web 页面**：Web 服务器存储以及 Web 浏览器请求的单个文档。

> Web 浏览器与 Web 服务器之间的关系是无缝的，这意味着它们各自使用的硬件和操作系统是相互无关的（平台无关）。它们使用 HTML 等标准语言进行通信，因此运行 Web 浏览器的 Windows、Mac 和 Linux 计算机都可以与运行 UNIX、Linux 或 Windows Server 的 Web 服务器进行同样良好的通信。

### Web 服务器

当有人连接到互联网时，他通常会使用带有桌面操作系统的计算机，例如 Windows 7。然而，该人员访问的信息存储在另一种类型的计算机上，称为 Web 服务器。服务器是一种强大的计算机，其目的是为其他计算机提供数据或服务。Web 服务器是存储 Web 页面并供公众使用的服务器。

### Web 设计师

Web 设计师为企业、学校、组织和个人创建网站。Web 设计师不仅在 HTML、Java 和 ASP 等编程工具方面具有深厚的背景，而且对如何使页面不仅具有功能而且美观且易用有独特的眼光。如果你对成为 Web 设计师感兴趣，你将学习计算机技术、编程、用户界面设计和计算机图形。

### Web 浏览器

Web 浏览器（通常简称为浏览器）是一种用于访问网站并检索或上传信息的应用程序。浏览器运行在个人的计算机上，并为 Web 服务器提供通信接口。

### 超链接与页面类型

网页上另一个点的指针，你通过点击超链接访问它。一个网站上的每个页面都可能有许多指向存储在站点其他地方或完全另一个站点上的内容的链接。当鼠标光标从箭头变为手形时，这表示存在超链接。

某些页面是静态的——也就是说，除非所有者更新它，否则其内容不会改变。其他页面是动态的，经常更新信息，例如当前的股票价格。如图 15.2 所示 news.google，如果你打开它并保持开启，你会发现页面每隔几分钟就会重新加载更新后的标题。

## 理解 URL 和 IP 地址

### URL

**URL**（统一资源定位符，有时称为网络地址或资源标识符 URI），是你输入浏览器地址栏的字符，以导航到特定的网页。标识网站资源位置的字符串。URL 的示例是 `http://www.microsoft.com`。

一个完整的 URL 由三个部分组成：

- **协议**：管理设备间数据传输的规则集。在互联网上，超文本传输协议 (HTTP) 常用于此——因此在大多数 URL 中存在 `http://`。
- **目标服务器（域名）**：由域名指示的字符（如 `www`），它们指向拥有域名的公司或组织。对于只有一个服务器的公司，习惯上使用 `www` 作为子域名。然而，拥有多个服务器的公司通过在域名之前使用不同的字母指向它们。例如，Google 使用 `news.google.com`、`maps.google.com`、`images.google.com` 等。
- **路径**：你在服务器上请求的文件位置。例如，文档可能存储在名为 news 的文件夹中。路径也可以包含特定的文件名，例如 `news/story.htm`。如果路径中没有包含文件名，将加载指定文件夹的默认页面。

一个完整的 URL 将是 `http://www.bbc.co.uk/news/story.htm`。图 15.3 标识 URL 的每个部分。

| 协议 | 域名 | 路径（包括文件名） |
|---|---|---|
| http://www.bbc.co.uk/news/story.htm | 顶级域名 | 文件名 |

**图 15.3 解释 URL。**

使用斜杠 (`/`) 作为分隔符。这与 Windows 中描述文件路径使用的反斜杠 (`\`) 形成对比。

### 域名

**域名**：标识互联网上实体的名称。它是 URL 的关键部分。公司或个人可以注册域名。该名称可以作为该公司或个人的标识符。

在基本形式下，域名由标识符加扩展名组成，例如 `microsoft.com`。扩展名指示组织的类型，其中 `.com` 留给商业。表 15.1 显示了常见的顶级域名。

| 身份 | 描述 |
|---|---|
| .com | 商业企业 |
| .mil | 为美国军方保留 |
| .gov | 政府组织 |
| .edu | 教育机构、学院、学校 |
| .org | 非营利组织 |
| .net | 通常由互联网服务提供商使用 |

某些域名还包含两个字母的国家代码——例如，英国为 `uk`，加拿大的为 `ca`，沙特阿拉伯为 `sa`。域名还可以包含子域名——例如 `training.microsoft.com` 或 `marketing.microsoft.com`。

具有全球属性的公司应该在多个国家注册域名。例如，如果你输入 `www.microsoft.se`，你将收到瑞典语的 Microsoft 主页。

#### 注册域名

对于任何想要在互联网上开展业务或仅仅拥有在线形象的公司来说，选择正确的域名是至关重要的。理想情况下，域名将与公司名称尽可能匹配。精确匹配可能不可能，因为该名称可能已被占用。如果你需要一个已被占用的特定名称，你可能从当前所有者那里购买该权利，或者可以使用不同的顶级域名注册该名称。例如，而不是 `.com` 地址，你可能获得 `.net` 或 `.biz` 版本。

任何人都可以注册域名，只要它不属于现有的公司或组织。你可以通过 GoDaddy 或 1&1 等域名注册公司注册域名。具体费用因注册商而异，但通常在每年 10 到 30 美元之间。

名称注册必须每年续订，但你可以一次性支付多年的费用。当域名的所有者未能续订时，它将供其他人认领和注册。

### IP 地址

**IP 地址**：每台直接连接到互联网的计算机都有其自身的数字地址，IP 代表“网际协议”（Internet Protocol），它是 TCP/IP 协议族中的一种协议。协议是一种约定的规则或标准；互联网是基于 TCP/IP 规则的。今天的大多数网络（包括互联网）都使用 IP 地址来识别计算机。如果你通过服务提供商（ISP）连接到互联网，它会自动为你分配一个 IP 地址。根据 ISP 的不同，该地址可能是静态 IP 地址（即永久分配给你的调制调制解调器）或动态 IP 地址（即在调制调制解调器连接到 ISP 时临时分配给它的）。

![IP 地址示意图](img/218567e51e5dac8e3e89ffff9d77da01_544_0.png)

### 网络地址转换 (NAT)

假设你的家庭在 ISP 有一个小型账户，但有几台都需要共享的计算机。你的 ISP 为你分配了一个单一的 IP 地址。当你连接家里连接调制调制解调器的路由器时，你的路由器会为每台计算机分配自己的私有 IP 地址，以便它们相互通信，并将互联网连接设置为网关。当请求发送到互联网并到达路由器时，路由器使用网络地址转换（NAT）更改传出消息上的 IP 地址，使其看起来是来自分配给调制调制解调器的 IP 地址。当回复从互联网返回时，路由器会将 IP 地址改回本地 PC 的地址。这就是许多计算机如何共享单个互联网 IP 地址的原理。

![NAT 工作原理](img/218567e51e5dac8e3e89ffff9d77da01_544_1.png)

目前正在使用的是两种 IP 地址。它们的功能相似，但地址看起来完全不同。

- **IPv4 地址**：一种由 32 位（二进制数字）组成的二进制数字。它以点分十进制法表示。也就是说，这 32 位分成四组，每组 8 位，每组 8 位转换为一个十进制数字并用点隔开，例如：`131.107.23.100`。IPv4 地址有超过 40 亿种可能的组合。尽管这个数字在 1969 年互联网首次出现时被认为是绰绰有余的，但它已经不再足够了。

- **IPv6 地址**：由 128 个二进制位组成，其最大空间拥有 340,282,366,920,938,463,474,607,168,211,456 个地址——比 IPv4 的 40 亿大得多。希望通过这种方案，我们不会再次用尽地址。IPv6 地址的大小使其以点分十进制格式编写变得不切实际。相反，IPv6 地址显示为八组四位十六进制数，用冒号（:）隔开，例如：`2001:0db8:65a3:7b62:1ab:34c2:1038`。（十六进制数是以 16 为底数的数字）。

### 识别计算机的 IP 地址

要发现你计算机的 IP 地址，请遵循以下步骤：

1. 点击“开始”按钮，在搜索程序和文件框中输入 `cmd` 并按回车。打开一个命令提示符窗口。
2. 在命令提示符处输入 `ipconfig` 并按回车。

![ipconfig 命令示例](img/218567e51e5dac8e3e89ffff9d77da01_545_0.png)

3. 查找包含“局域网连接”（Local Area Connection）的行。你应该看到分配给你计算机的两个地址——IPv6，后面是 IPv4。

![IP 地址显示示例](img/218567e51e5dac8e3e89ffff9d77da01_545_1.png)

### 域名如何解析

运行 `ipconfig` 命令显示你计算机的 IP 地址，这是分配给路由器的私有地址。如果你想查看计算机的公共地址——即它在互联网上使用的地址——请访问 `http://whatyipaddress.com`。主页将显示你计算机的公共 IP 地址。还有一张显示你的互联网服务提供商地理位置的地图。

假设你想访问互联网上的某个网站。这个网站——和所有网站一样——可以通过其 IP 地址访问。例如，假设你想访问微软网站。为此，你输入它的 IP 地址——如果你恰好知道的话。不过你可能并不知道。相反，你可能知道微软站点名为 `www.microsoft.com`，这是它的域名。

**域名系统 (DNS)**：允许用户使用域名或 URL 而不是 IP 地址访问网站的命名系统。

**名称解析**——将域名转换为数值 IP 地址的过程。使用 DNS 服务器来将名称解析为地址。

如果你在网络浏览器中输入 IP 地址，浏览器将直接去到该地址。如果你输入域名，它将联系 DNS 服务器并找到对应的 IP 地址。然后它会为你打开网页。

互联网包含成千上万互连的服务器。DNS 服务器只持有其中的一部分。当你向浏览器中输入 URL 时，你的浏览器会联系 DNS 服务器并找到对应的 IP 地址。

### 访问网站
