
## 描述

`fprintf` 函数向 `stream` 指向的流写入输出，由 `format` 指向的宽字符串控制哪些后续参数被转换为输出。如果格式所需的参数不足，则行为未定义。如果格式耗尽而仍有参数，则多余参数会被求值（始终），但会被忽略。当遇到格式字符串结束时，`fprintf` 返回。

格式由零或多个指令组成：普通宽字符（非 `%`），它们被原样复制到输出流；以及转换规范，每个规范都会获取零或多个后续参数，根据转换说明符对其进行转换，然后将结果写入输出流。`fprintf` 函数为 `%n` 说明符执行内存写入。

每个转换规范由宽字符 `%` 引入。在 `%` 之后，按顺序出现：

- 零或多个标志（任意顺序），修改转换规范的含义。
- 可选的最小字段宽。如果转换值的宽字符少于字段宽，则在左侧（默认）或右侧（如果给出了后文描述左对齐标志）填充空格以达到字段宽。字段宽的形式为星号 `*`（见后文）或非负整数。
- 可选的精度，对于 `d`、`i`、`o`、`u`、`x` 和 `X` 转换给出最小数字个数；对于 `a`、`A`、`e`、`f` 和 `F` 转换给出小数点宽字符后的数字个数；对于 `g` 和 `G` 转换给出最大有效位数；对于 `s` 转换给出写入的最大宽字符数。精度的形式为点 `.`，后跟星号 `*`（见后文）或可选整数；如果指定了点，则精度视为零。如果精度与任何其他转换说明符一起出现，行为未定义。
- 可选的长度修饰，指定参数的大小。
- 转换说明符宽字符，指定应用的转换类型。

如上述，字段宽、精度或两者可能由星号指示。在这种情况下，一个 `int` 类型参数提供字段宽或精度。指定字段宽、精度或两者的参数应（按此顺序）出现在要转换的参数（如果有）之前。负的字段宽参数被视为标志，后跟一个正字段宽。负的精度参数被视为省略了精度。

宽标志字符及其含义为：

- 转换结果在字段内左对齐。（如果未指定此标志，则右对齐。）
- 有符号转换的结果始终以加号或减号开头。（如果未指定此标志，仅在转换负值时显示符号。）

符号转换的第一个宽字符不是符号位，或者如果符号转换的结果没有宽字符，则在结果前缀加一个空格。如果空格和标志（flags）同时出现，则忽略空格标志。

结果被转换为“备用形式”。对于 `o` 转换，当且仅当必要时会增加精度，以强制结果的第一位数字为零（如果值和精度均为 0，则打印单个 0）。对于 `x`（或 `X`）转换，非零结果将前缀加上 `0x`（或 `0X`）。对于 `a`、`E`、`e`、`F`、`G` 和 `G` 转换，浮点数转换的结果始终包含一个小数点宽字符，即使后面没有数字。（通常情况下，这些转换的结果只有在后面有数字时才会出现小数点宽字符。）对于 `g` 和 `G` 转换，不会移除结果中的末尾零。对于其他转换，其行为未定义。

对于 `d`、`i`、`o`、`u`、`x`、`A`、`a`、`E`、`e`、`F`、`g` 和 `G` 转换，在转换无穷大或 NaN 时，前导零（跟随任何符号或基数的指示之后）用于填充字段宽度，而不是执行空格填充。如果 0 和标志同时出现，则忽略 0 标志。对于 `d`、`i`、`o`、`u`、`x` 转换，如果指定了精度，则忽略 0 标志。对于其他转换，其行为未定义。

长度修及其含义为：

- `hh` 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于符号字符（signed char）或无符号字符（unsigned char）参数（该参数已根据整数提升进行了提升，但在打印之前其值应转换为符号字符或无符号字符）；或者指定后续的 `n` 转换符适用于指向符号字符参数的指针。
- `h` 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于短整数（short int）或无符号短整数（unsigned short int）参数（该参数已根据整数提升进行了提升，但在打印之前其值应转换为短整数或无符号短整数）；或者后续的 `n` 转换符适用于指向短整数参数的指针。
- `(ll)` 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于长整数（long int）或无符号长整数（unsigned long int）参数；且 `n` 转换符适用于指向长整数参数的指针；后续转换符适用于 `wint_t` 参数；后续转换符适用于指向 `wchar_t` 参数的指针；或者对 `a`、`A`、`e`、`E`、`f`、`F`、`g` 或 `G` 转换符没有影响。
- `ll` 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于长整数或无符号长整数参数；或者后续的转换符适用于指向长长整数（long long int）参数的指针。
- `j` 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于 `intmax_t` 或 `uintmax_t` 参数；或者后续的 `n` 转换符适用于指向 `intmax_t` 参数的指针。
- `z` 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于 `size_t` 或对应的符号整数类型参数；或者后续转换符适用于指向与 `size_t` 参数对应的符号整数类型的指针。
- `t` 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于 `ptrdiff_t` 或对应的无符号整数类型参数；或者后续转换符适用于指向 `ptrdiff_t` 参数的指针。
- `L` 指定后续的 `a`、`A`、`e`、`E`、`f`、`F`、`g` 或 `G` 转换符对应长双 参数。

如果长度修饰符出现在上述指定的任何转换符之外，其行为未定义。

转换符及其含义为：

- `d`, `i`: `int` 参数被转换为 `[-]dddd` 风格的符号十进制。精度指定了出现的最小位数；如果转换的值可以用较少的数字表示，则用前导零进行扩展。默认精度为 1。精度为 0 时转换零值的结果没有宽字符。
- `o`, `u`, `x`, `X`: `unsigned int` 参数被转换为 `ddddd` 风格的八进制（`o`）、无符号十进制（`u`）或十六进制表示法（`x` 或 `U`）；`x` 转换使用字母 `abcdef`，`X` 转换使用字母 `ABCDEF`。精度指定了出现的最小位数；如果被转换的值可以用较少的数字表示，则用前导零进行扩展。默认精度为 1。精度为 0 时转换零值的结果没有宽字符。
- `f`, `F`: 代表浮点数的 `double` 参数转换为十进制表示法，其中小数点宽字符后的数字数等于精度指定。如果缺少精度，则默认为 6；如果精度为 0 且未指定 `#` 标志，则不出现小数点宽字符。如果出现了小数点宽字符，则其前面至少有一个数字。该值将舍入到相应的位数。
- `e`, `E`: 代表浮点数的 `double` 参数转换为科学计数法表示，其中小数点宽字符后的数字数等于精度指定。如果缺少精度，则默认为 6；如果精度为 0 且未指定 `#` 标志，则不出现小数点宽字符。如果出现了小数点宽字符，则其前面至少有一个数字。该值将舍入到相应的位数。
- `g`, `G`: 代表浮点数的 `double` 参数转换为十进制或科学计数法表示，以产生较短者为准。如果缺少精度，则默认为 6；如果精度为 0 且未指定 `#` 标志，则移除小数点宽字符。如果出现了小数点宽字符，则其前面至少有一个数字。该值将舍入到相应的位数。
- `a`, `A`: 代表浮点数的 `double` 参数转换为十六进制表示法，其中小数点宽字符后的数字数等于精度指定。如果缺少精度，则默认为 6；如果精度为 0 且未指定 `#` 标志，则不出现小数点宽字符。如果出现了小数点宽字符，则其前面至少有一个数字。该值将舍入到相应的位数。

终止空零宽字符。如果指定了精度，则写入的宽字符数不超过该精度。如果未指定精度或精度大于转换数组的大小，则转换后的数组应包含一个空零宽字符。

如果存在 `l1` 长度修饰符，则参数应为指向 `wchar_t` 类型数组起始元素的指针。从数组中写入宽字符，直到（但不包括）终止空零字符。如果指定了精度，则写入的宽字符数不超过该精度。如果未指定精度或精度大于数组的大小，则数组应包含一个空零宽字符。

参数应为指向 `void` 的指针。指针的值以实现定义的方式转换为一组打印的宽字符序列。

参数应为指向符号整数的指针，该整数表示到此调用 `fprintf` 为止已向输出流写入的宽字符数。不对参数进行转换，但会消耗一个参数。如果转换规范包含任何标志、字段宽度或精度，则行为是未定义的。

写入一个 `%` 宽字符。不进行任何参数转换。整个转换规范应为 `%%`。

如果转换规范无效，行为是未定义的。³³⁵) 如果任何参数的类型与相应的转换规范不匹配，行为是未定义的。

在不存在或较小的字段宽度导致字段被截断的情况下；如果转换结果比字段宽度宽，则该字段将扩展以包含转换结果。

对于 `a` 和 `A` 转换，`FLT_RADIX` 是 2 的幂，该值被正确舍入为具有给定精度的十六进制浮点数。

## 推荐实践

对于 `a` 和 `A` 转换，如果 `FLT_RADIX` 不是 2 的幂且结果在给定位置上无法精确表示，则结果应为给定精度下两个相邻的十六进制浮点格式之一，额外规定是误差对于当前的舍入方向应具有正确的符号。

对于 `e`、`f`、`g` 和 `G` 转换，如果有效数字位数最多为 `DECIMAL_DIG`，则结果应被正确舍入。³³⁶) 如果有效位数多于 `DECIMAL_DIG` 但源值可以用 `DECIMAL_DIG` 位数字精确表示，则结果应为带有尾随零的精确表示。否则，源值被限制在具有 `DECIMAL_DIG` 位有效数字的两个相邻十进制 `L < U` 之间；生成的十进制字符串 `D` 的值应满足 `L ≤ D ≤ U`，额外规定是误差对于当前的运行方向应具有正确的符号。

## 返回

`fprintf` 函数返回传输的宽字符数，如果发生输出或编码错误，则返回负值。

## 环境限制

任何单个转换可以产生的宽字符数至少为 4095 个。

示例 打印格式为“Sunday, July 3, 10:02”的日期时间，后跟五位小数：

```
#include <math.h>

#include <stdio.h>

#include <wchar.h>

/* ... */

wchar_t *weekday, *month; // 指向宽字符串的指针

int day, hour, min;

fwprintf(stdout, "L%ls, %ls %d, %.2d:%2d\n", weekday, day, hour, min);

wprintf(stdout, "Lpi = %.5f\n", 4 * atan(1.0));
```

前引用：`btowc` 函数（7.29.6.1.1），`mbrtowc` 函数（7.29.6.3.2）。
