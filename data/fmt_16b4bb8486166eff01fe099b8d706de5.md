
再次，列表 5.17 的输出可以解释为由于类 `B` 构造函数的定义修改，语句


被转换为

根据列表 5.17 中派生类构造函数的定义，传递给它的第一个参数转而传递给了基类构造函数。但这不是必要的。传递给派生类构造函数的任何参数都可以传递给基类构造函数。

## 5.5 保护访问修符

除了 `public`（公共）和 `private`（私有）访问修符外，C++ 中还有第三种访问修符称为 `protected`（保护）。保护成员对成员函数不可用。然而，它们所属类的成员函数以及派生类的成员函数是可以访问的。列表 5.18 及其注释说明了这一切。

- 列表 5.18 访问保护成员

```cpp
/*Beginning of A.h*/
class A
{
private:
int x;
protected:
int y;
public:
int z;
};
/*End of A.h*/
```

```cpp
/*Beginning of B.h*/
#include "A.h"
class B : public A                               //派生类
{
public:
void xyz();
}
/*End of B.h*/
/*Beginning of B.cpp*/
#include "B.h"
void B::xyz()                                     //派生类的成员函数
```

```cpp

  x=1; //错误：基类的私有成员
  y=2; // 正常：基类的保护成员
  z=3; // 正常：基类的公共成员
}
```

```cpp
/*Beginning of protected.cpp*/
#include "A.h"
void main() {
  A * Aptr;
  Aptr->x=10; //错误：私有成员
  Aptr->y=20; //错误：保护成员
  Aptr->z=30; // 正常：公共成员
}
/*End of protected.cpp*/
```

## 5.6 通过不同的访问修符派生

### 5.6.1 通过公共访问修符派生

通过 `public` 访问修符派生保留了基类成员的访问级别。

**私有成员：** 派生类的成员函数无法访问。后续派生类的成员函数无法访问它们。成员函数无法访问它们。
