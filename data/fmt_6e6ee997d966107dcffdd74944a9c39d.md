
现在您已经回顾了程序集和清单，让我们继续看看如何在应用程序中使用反射。C# 反射需要`System.Reflection`命名空间，其中包含所有反射相关类，如`Type`、`MemberInfo`等。这些类用于从 .NET Framework 下的任何其他类中检索信息。`System.Type`类是`System.Reflection`的基类，是访问元数据的主要方式。`System.Type`类是一个抽象类，表示公共类型系统（CLS）中的一种类型。

我们之前提到，反射可以动态创建任何类型的实例，将类型绑定到现有对象，或从现有对象获取类型。类型包括构造函数、方法、字段、属性、事件、类和程序集。创建实例后，可以调用适当的方法，并访问字段和属性。这可以通过仅指定对象类型或同时指定需要创建的对象的程序集和类型来完成。此外，反射还使您能够找出与新创建的对象关联的各种方法以及在 C# 中使用这些对象的方式。您可以使用`MemberInfo`抽象类来找出与对象关联的属性和方法。

反射使用`System.Reflection`命名空间下的以下类来获取各种类型的信息：

- `Assembly`类 – 检索和操作关于程序集的信息。此类允许您执行各种功能，例如定义和加载程序集、加载程序集清单中列出的模块，以及从该程序集中定位类型以创建实例。`Assembly`类

使用其中一种方法——`Assembly.GetType`或`Assembly.GetTypes`——来获取尚未加载的程序集中`Type`对象。

- `Module`类——检索有关父程序集、模块中的类以及类中所有全局方法的信息。

- `ConstructorInfo`类——检索有关构造函数的信息，例如构造函数名称、参数、访问修饰符以及各种实现细节。`ConstructorInfo`类使用`Type`对象的`GetConstructor`或`GetConstructors`方法来检索构造函数信息。

- `MethodInfo`类——检索有关类、模块或程序集中的方法的信息，例如方法名称、返回类型、参数、访问修饰符和实现细节。`MethodInfo`类使用类型的`GetMethod`或`GetMethods`方法来检索信息。

- `FieldInfo`类——检索有关字段的信息，例如名称、访问修饰符和实现细节。此外，您还可以使用此类来获取或设置类的字段值。

- `EventInfo`类——检索有关事件的信息，例如名称、事件处理程序数据类型、自定义属性、声明类型和反射类型。

- `PropertyInfo`类——检索有关属性的信息，例如属性名称、数据类型、声明类型、反射类型以及属性的只读或可写状态。此外，此类还获取或设置属性值。

- `ParameterInfo`类——检索有关参数的信息，例如其名称、数据类型、它是输入参数还是输出参数，以及它在方法签名中的位置。此类使用`GetParameters`方法返回`ParameterInfo`对象数组，表示方法参数。

用于反射的另一个命名空间是`System.Reflection.Emit`。此命名空间在运行时创建类型并在需要时调用该类型。`System.Reflection.Emit`命名空间通常将信息写入适当的类型。此命名空间包含可由编译器或工具用来发出元数据和 Microsoft 中间语言（MSIL）的类。

接下来，您将了解使用反射动态加载程序集。

## 使用反射进行程序集的动态加载

让我们来看反射的最简单形式——在运行时加载程序集并调查您可以从程序集中找到哪些信息。为此，您需要使用`Reflection`命名空间。以下导入语句用于在您的应用程序中了解此功能：

```
using System.Reflection;
```

在反射库功能已加载到您的应用程序后，可以从外部世界加载单个程序集。您可以使用`Reflection`库中`Assembly`类的`LoadFrom`静态方法来加载单个程序集。现在，如果您想加载的程序集名称存储在名为`assemblyName`的变量中，则使用以下代码片段：

```
Assembly assembly = Assembly.LoadFrom(assemblyName);
```

在您获得对程序集对象的访问权限后，您可以对其进行询问。询问程序集对象最简单的方法是使用`GetTypes`方法。此方法返回`Type`对象数组，其中包含有关此程序集中定义的各种类型的信息。您可以从以下给定类型的`Type`对象中查出类名、命名空间、访问级别等：

```
Type[] types = assembly.GetTypes()
```

在您获得程序集中可用类型的列表后，您可以从中获取各种信息。`Type`类中可用的第一个函数组确定您处理的类型的种类。表 34.1 描述了`Type`对象的属性：

## 表 34.1：Type 对象中可用的属性

| Property | Purpose |
|---|---|
| IsClass | Indicates that the type is a class if this property is true. |
| IsEnum | Indicates that the type is an enumeration if this property is true |
| IsInterface | Indicates that the type is an interface if this property is true |
| IsValueType | Indicates that the type is a Value Type (a struct) if this property is true |

您可以使用上述四个简单属性来确定类型并适当处理它。在您确定属性的类型后，您可以确定它是否可公开用于应用程序。

有两个属性可用于确定类型的访问范围——`IsPublic`和`IsNotPublic`属性。`IsPublic`属性确定公共方法，而`IsNotPublic`属性确定私有或受保护方法，或实际上是非公共方法。例如，以下代码片段显示程序集中的所有公共类型：

```
Type[] types = assembly.GetTypes();
foreach ( Type t in types )
{
if ( t.IsPublic )
Console.WriteLine("Class {0} is public!", t.FullName );
}
```

此外，反射使您能够探索类的实现以及类中使用的参数和方法；但是，反射不允许您获取方法的代码转储。如果这样做，不法分子很容易从 C# 程序集中复制算法和代码供自己使用。

允许您获取类中定义的类型的信息的所有方法都有共同的功能。表 34.2 列出了最常用的用于检索有关类型的一般信息以及存储在这些类型中的信息的方法：

## 表 34.2：用于检索类型信息的常用方法

| Value Type | What it Represents |
|---|---|
| GetTypes | Retrieves all types for a given assembly |
| GetMethods | Retrieves all methods for a given current Type |
| GetConstructors | Retrieves all constructors for a given current Type |
| GetProperties | Retrieves all properties for a given current Type |
| GetEvents | Retrieves all events for a given current Type |
| GetInterfaces | Retrieves all interfaces supported by a given current Type |

您首先使用`GetTypes`方法从程序集中检索类型，然后使用这些常用方法。这些方法返回程序集的类型数组，其中包括类、结构、枚举和事件。如果您检查`Type`对象的适当类型并验证它是否为类或结构，则可以应用其他方法，例如`GetMethods`和`GetConstructors`方法，以检索您感兴趣的信息。有关此过程的更多信息，请查看本章 Immediate Solutions 部分中 Dumping the Methods and Their Parameters for a Class 部分中的示例。

### Listing 34.1: Showing the Code for Obtaining Class and Type Information

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Reflection;
namespace ObtainClassInformation
{
    class Program
    {
        public static void ShowInterfaces(Type t)
        {
            Type[] interfaces = t.GetInterfaces();
            Console.WriteLine("Implemented Interfaces");
            foreach (Type type in interfaces)
            {
                Console.WriteLine("Interface : {0}", type.FullName);
                if (type.IsPublic)
                    Console.WriteLine("Scope: Public");
                else
                    Console.WriteLine("Scope: Private");
            }
        }
        public static void ShowEvents(Type t)
        {
            EventInfo[] events = t.GetEvents();
            Console.WriteLine("Implemented Events");
            foreach (EventInfo e in events)
            {
                Console.WriteLine("Event name: {0}", e.Name);
                Console.WriteLine("Multicast: {0}", e.IsMulticast ? "Yes" : "No");
                Console.WriteLine("Member Type {0}", e.MemberType.ToString());
            }
        }
        public static void ShowTypes(string name, Assembly assembly)
        {
            Type[] typeArray = assembly.GetTypes();
            Console.WriteLine("Assembly Name: {0}", name);
            foreach (Type type in typeArray)
            {
                if (type.IsClass) {
                    Console.WriteLine("\nNamespace : {0}",
                        type.Namespace);
                    Console.WriteLine("Class : {0}",
                        type.FullName);
                    if (type.BaseType != null)
                        Console.WriteLine("Base Class : {0}",
                            type.BaseType.FullName);
                    else
                        Console.WriteLine("Class not derived from anything");
                    // check if abstract
                    if (type.IsAbstract)
                        Console.WriteLine("Abstract base class");
                    else
                        Console.WriteLine("Instantiable class");
                    if (type.IsPublic)
                        Console.WriteLine("Scope: Public");
                    else
                        Console.WriteLine("Scope: Private");
                    ShowInterfaces(type);
                    ShowEvents(type);
                }
                else
                    if (type.IsInterface)
                {
                    Console.WriteLine("\nNamespace : {0}",
                        type.Namespace);
                    Console.WriteLine("Interface : {0}",
                        type.FullName);
                    if (type.IsPublic)
                        Console.WriteLine("Scope: Public");
                    else
                        Console.WriteLine("Scope: Private");
                }
                else
                    if (type.IsEnum)
                {
                    Console.WriteLine("\nEnumeration: {0}",
                        type.FullName);
                }
                else
                    Console.WriteLine("\nType: {0}", type.FullName);
            }
        }
        static void Main(string[] args)
        {
            for (int i = 0; i < args.Length; ++i)
            {
                // Get the assemble object (from System.Reflection)
                Assembly assembly = Assembly.LoadFrom(args[0]);
                ShowTypes(args[0], assembly);
            }
        }
    }
}
```
