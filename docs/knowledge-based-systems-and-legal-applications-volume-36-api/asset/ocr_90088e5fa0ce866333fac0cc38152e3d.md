It is less clear, that we want to do this for the advice system. Firstly, it may be the case that there are practical difficulties in making these data available to the public. Alternatively, given that this sort of information is readily available to the claimant, we may prefer simply to ask the claimant for the information rather than accessing the remote database. If either is the case then the assessment system will need this part of the KB representing knowledge about how to use the database and the advice system will not.
