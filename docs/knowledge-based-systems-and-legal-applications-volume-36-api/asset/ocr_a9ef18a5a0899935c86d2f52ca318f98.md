It is interesting to note that whatever response the system gives to the user’s ‘OK?’ acts to reassure users. A ‘Turn’ user statement was provided as a method for users to give back the initiative to the system without actually saying anything. Several users manoeuvred themselves into a position in the conversation from which they gracefully escaped with this option. This usually involved holding or taking the initiative from the system to make an utterance which subsequently could not be found among the question or statement options.
