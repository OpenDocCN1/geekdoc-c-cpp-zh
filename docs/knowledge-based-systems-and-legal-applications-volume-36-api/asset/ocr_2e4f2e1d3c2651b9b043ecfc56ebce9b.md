#  13.1. INTRODUCTION

There are a number of important ingredients to the success of any knowledge based system. Many of these have been discussed in other chapters of this book. For example, the function of the system should be fitted to the requirements of some target user group (Chapter 3). Its knowledge representation and inference capabilities allow it to fulfill this function accurately and efficiently (Chapter 12). Its knowledge-base should be coherent and scrutable (Chapter 11). Communication at the human-computer interface should be based around some clear metaphor-for interaction (Chapter 5), and the cost of developing and maintaining the system should be outighed by the benefits of operating it (Chapter 10).

However, there is another ingredient which is rather difficult to characterize but is equally important in making the system useful and usable. This is the dynamic property of the interaction which the system supports. In many ways the dynamics of the interactional dynamics of a knowledge based system is the engine which binds all other ingredients together. Ultimately, users interact with a 'virtual system' whose behaviour is more than the sum of its constituent parts; behaviour which is unfolded bit by bit, in an on-going interaction sequence.
