# Starting

The user started the system by pressing the Start button. In response
sysystem recommended a first question for the user to answer by moving
cursor into the region of the answer.

# Overall mixture of initiative

The user did not have a question once it was recommended.
He or could use their turn to divert from it, perhaps to look at an
answer to a previous question or to answer another, different question.
This was a way for allowing users to take the overall initiative from
system. Once a question was answered, the system would recommend
tnext relevant question to answer. The choice of question depended on
answers given by the user, so it was possible for the user to be
routed a long way on the form. By recommending questions, the system
led the user through the form. The user could divert the recom-
dations, but once the user had answered a question the system would
lead and recommend another.

# Local mixture of initiative

Users would be given the initiative by moving the cursor into
tnext answer area. Now the user would be in control until he or she
completed an answer. That meant that users were free to do anything in
t turn. They could view or answer any other question on the form by
 the section panel or page turner. They could start typing an
answer, decide to look another question and start answering this
new question. The system would only have the initiative when it
given, by the user typing a special key. It was not intended that the
system should take the initiative during the user's turn nor, for that
matter, the user should take the initiative during the system's.
