Though this context is useful, it leads people to ‘capture’ questions that are not relevant to them. Often by ignoring instructions, they see questions that they think they should answer and try to answer them. The design of the first version of the Forms Helper intended that, by displaying all the questions on the form and skipping the irrelevant ones, the user would be given context but discouraged from giving unnecessary answers. Unfortunately, the system skipping questions disrupted the interaction, especially as this meant going into a new page. Users tended to use their turn to see what had just happened in the system’s. Luckily, as the system would only recommend relevant questions it was hard to answer a series of irrelevant ones. The system kept taking the user away. This is illustrated in the following example.
