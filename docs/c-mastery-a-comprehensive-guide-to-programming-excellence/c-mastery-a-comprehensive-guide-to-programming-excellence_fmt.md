### 使用 cout 显示结果

在 `C++` 中，你可以利用来自 `<iostream>` 库的 `cout` 对象向控制台显示结果。`<<` 运算符用于将信息嵌入到输出流中。例如：

```cpp
#include <iostream>

    std::cout << "Hi, world!" << std::endl; //显示 "Hi, world!" 后后续换行
    return 0;
}
```

在此模型中，`std::cout` 指向标准输出流，而 "Hi, world!" 是正在显示的信息。`<< std::endl` 部分嵌入了一个换行符，在显示文本后移动到下一行。

### 使用 cin 获取输入

要从客户端获取输入，你可以利用 `<iostream>` 库中的 `cin` 对象。`>>` 运算符用于从输入流中提取信息。例如：

```cpp
#include <iostream>

int main() {
    int age;
    std::cout << "Enter your age: ";
    std::cin >> age;
    std::cout << "You entered: " << age << std::endl;
    return 0;
}
```

在此模型中，`std::cin` 被用于从客户端获取输入，并存储在变量 `age` 中。随后，`<< age << std::endl` 部分将输入的数值回显显示给客户端。

### 构建直观的项目

通过整合输入和输出任务，你可以创建能够响应客户端输入的直观项目。例如：

```cpp

int main() {
    int num1, num2, aggregate;
    std::cout << "Enter two numbers: ";
    std::cin >> num1 >> num2;

    std::cout << "The amount of " << num1 << " and " << num2 << " will be " << aggregate << std::endl;
    return 0;
}
```

该程序提示客户端输入两个数字，将它们相加，然后显示结果。

### 条件语句

条件语句允许你的程序根据明确条件做出决策。`C++` 中最常见的条件语句是 `if` 语句。其结构如下：

```cpp
#include <iostream>

int main() {
    int x = 10;
    if (x > 0) {
        std::cout << "x is positive" << std::endl;
    }
    return 0;
}
```

在此模型中，如果条件 `(x > 0)` 为真（它是确定的，因为 `x` 是 10），将显示消息 "x is positive"。

你同样可以使用 `else if` 和 `else` 语句来管理不同的条件：

```cpp
#include <iostream>

int main() {
    int x = 10;
    if (x > 0) {
        std::cout << "x is positive" << std::endl;
    } else if (x < 0) {
        std::cout << "x is negative" << std::endl;
    } else {
        std::cout << "x is zero" << std::endl;
    }
    return 0;
}
```

在此模型中，如果 `x` 为正数，将执行主代码块。如果 `x` 为负数，将执行相应的代码块。相反，将执行第三个块。

### 循环

循环允许你在各种情况下重复执行一段代码块。`C++` 中有三种主要的循环：`for`、`while` 和 `do-while`。

`for` 循环：

- 该循环会在多次执行其内部的代码块，`I` 从 0 开始并每次增加 1。

`while` 循环：

```cpp
int I = 0;
while (I < 5) {
    i++;
}
```

只要条件 `I < 5` 为真，该循环就会执行其内部的代码块。

`do-while` 循环：

```cpp
int I = 0;
do {
  i++;
} while (I < 5);
```

该循环类似于某些时间循环，但它通常至少会执行一次内部代码块。

### 封装和信息隐藏

封装是将信息（属性）和处理这些信息的技术（方法）封装在单一单元（类）内部。它允许通过将特定属性或策略设置为私有来控制对信息的访问，从而从其他世界隐藏实现细节。

```cpp

private:
    double balance; // 私有属性

    }
```

在此模型中，`balance` 是 `BankAccount` 类的私有属性，而 `deposit()` 策略是一个允许向记录中存储现金的公共技术。`getBalance()` 技术是一个公共 getter 策略，允许你获取记录余额。

## 第 10 节：处理记录

在本节中，我们将研究如何在 C++ 中处理记录。文件输入/输出任务允许你从外部文档读取信息并向其写入信息，使你的项目能够与持久化存储进行通信。

### 从记录读取

要在 C++ 中从记录中读取信息，你需要执行以下步骤：
- 使用输入文件流 `ifstream` 打开记录。
- 从文档中读取信息。
- 关闭文档。

这是一个从文本文档中读取信息的实例：

```cpp
#include <iostream>
#include <fstream>
#include <string>

int main() {
    std::ifstream inputFile("input.txt"); // 打开文档
    if (inputFile.is_open()) { // 检查假设记录已打开
        std::string line;
        while (std::getline(inputFile, line)) { // 从文档读取每行
            std::cout << line << std::endl; // 打印该行
        }
        inputFile.close(); // 关闭记录
    } else {
        std::cerr << "Unable to open document!" << std::endl;
    }
    return 0;
}
```
在这个模型中，我们利用输入记录流打开了一个名为 `"input.txt"` 的文档。然后，我们利用 `std::getline()` 从记录中读取每行，并将其打印到控制中心。最后，我们利用 `close()` 技巧关闭记录。

### 向文档写入

要在 C++ 中向记录中写入信息，你确实需要执行以下步骤：
- 使用结果记录流 `ofstream` 打开文档。
- 向文档中写入信息。
- 关闭记录。

这是一个向文本记录中组合信息的实例：

```cpp
#include <iostream>
#include <fstream>

int main() {
  std::ofstream outputFile("output.txt"); // 打开文档
  if (outputFile.is_open()) { // 检查假设记录已打开
    outputFile << "Hi, world!" << std::endl; // 向文档写入信息
    outputFile.close(); // 关闭文档
    std::cout << "Information written to record effectively." << std::endl;
  } else {
    std::cerr << "Unable to open document!" << std::endl;
  }
  return 0;
}
```
在这个模型中，我们利用结果记录流打开了一个名为 `"output.txt"` 的文档。然后，我们在此处利用插入运算符 `<<` 向文档写入 `"Hi, world!"`。最后，我们利用 `close()` 技巧关闭记录。

# 结束

## 第 11 节：排查与调试

在本节中，我们将深入研究 C++ 中的排查和调试策略。排查是识别和修复代码错误（bug）的最常见方法，而调试包含了诊断并解决可能出现的问题。

### 错误及其修复方法

理解 C++ 中的常见错误可以帮助你更有效地分析和修复错误。一些常见错误包括：
- 语法错误：当代码违反 C++ 规则时发生。示例包括缺少分号、括号不匹配和拼写错误。编译器通常会指出这些符号错误并提供错误消息。
- 逻辑错误：当代码由于逻辑缺陷产生错误结果时发生。排查逻辑错误通常包括使用打印语句、调试设备以及逐行检查代码以识别逻辑缺陷。
- 运行时错误：当程序在执行期间遇到错误时发生，例如除以零或访问越界数组元素。运行时错误可能难以排查，因为它们并不总是发生。利用调试工具或添加错误检查代码可以帮助修复运行时错误。

### 排查策略

以下是你有效排查 C++ 程序的一些策略：
- 打印语句：在代码中嵌入打印语句以显示因子值或执行过程，可以帮你了解程序各个位置的情况。
- 排查工具：集成开发环境 `IDE` 如 `Visual Studio`、`Code::Blocks` 或 `CLion` 提供了内置调查工具，允许你设置断点、评估因子并逐行执行代码。
- 编译器警告：关注编译器警告，因为它们经常会显示代码中可能导致运行时错误的预期问题。
- 代码审查：让他人审核你的代码可以提供新的视角，并协助识别你可能忽略的错误或改进区域。

# 结束

### 泛型 Templates

C++ 中的泛型允许你编写可以与任何数据类型工作的非特定代码。它们对于创建独立于显式数据类型的数据设计和计算特别有用。

```cpp
template<typename T>
T maximum(T a, T b) {
    return (a > b) ? a : b;
}
```

### STL 标准模板库

标准模板库（STL）是一组强大的类和函数，提供了 C++ 中通用的数据结构和算法。它包含了向量、记录和指南等容器，以及用于排序、查找和控制信息的算法。

```cpp
#include <vector>
#include <algorithm>

std::vector<int> numbers = {3, 1, 4, 1, 5, 9, 2, 6};
std::sort(numbers.begin(), numbers.end());
```

### Lambda 表达式

Lambda 表达式允许你内联定义匿名函数，使得编写短小的、一次性的功能更加简单，而不需要独立的函数声明。

```cpp
auto total = [](int a, int b) { return a + b; };
std::cout << total(3, 5) << std::endl; //结果: 8
```

### 并发性

C++ 通过 `<thread>` 和 `<future>` 等库提供了多线程和异步编程的支持。这些特性允许你创建可以同时执行多个任务的程序，进一步提高执行和响应速度。

```cpp
#include <iostream>
#include <thread>

void welcome() {
    std::cout << "Hello!" << std::endl;
}

int main() {
    std::thread t(welcome);
    t.join();
    return 0;
}
```

### 智能指针

智能指针是像指针一样的对象，但提供了内存管理等额外功能。它们有助于防止内存泄漏。

```cpp
#include <memory>
std::shared_ptr<int> ptr = std::make_shared<int>(10);
```

## 第 14 部分：C++ 最佳实践与改进

在这一部分，我们深入探讨了编写高效 C++ 代码的最佳实践和改进方法。遵循这些实践将帮助你创建清晰、可维护且健壮的代码。

### 1. 使用有意义的变量名

为变量、函数和类选择描述性的名称。



### 2. 遵循编码规范

坚持一致的代码风格和组织模式。

### 3. 限制全局变量

限制全局变量的使用，因为它们会创建隐藏依赖并增加测试难度。

### 4. 避免魔数

用命名常量或规范替换数字字面量，以提高代码的可读性。

### 5. 错误处理

使用适当的错误处理（例如异常或错误代码），以灵活处理意外情况并防止崩溃。

### 6. 使用智能指针

使用智能指针（如 `std::unique_ptr` 和 `std::shared_ptr`）管理内存，避免内存泄漏。

### 7. 避免过早优化

优先编写清晰高效的代码。仅在通过性能分析并识别瓶颈后再对代码执行部分进行优化。

### 8. 使用标准库

在情况允许的情况下使用 C++ 标准库（STL）提供的功能和算法。它是经过充分测试、高效且紧凑的。

### 9. 性能分析与基准测试

通过性能分析识别执行瓶颈，并使用基准测试量化改进的效果。

### 10. 代码注释

编写清晰的注释来记录代码，包括逻辑、行为以及任何非明显设计选择的说明。

### 11. 测试驱动开发 (TDD)

采用测试驱动开发方法，确保代码在更改后仍然符合预期。

### 12. 代码模块化

将代码拆分为更小的、可重用的模块（函数、类或库），以提高代码的可重用性和活力。

### 13. 持续集成与持续部署 (CI/CD)

自动化构建、测试和部署周期，确保代码库的更改经过测试并以受控的方式交付。

### 14. 从他人学习

关注经验 C++ 设计师的代码，参与代码审查并贡献开源项目，以学习新的方法和最佳实践。

通过遵循这些规定的流程和进阶策略，你可以编写出更整洁、更高效且更实行的 C++ 代码。不断努力提升你的编码能力，并关注 C++ 社区的最新进展，以成为一名胜任且高产的软件工程师。
