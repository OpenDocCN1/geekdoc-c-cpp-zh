### 什么是数组？

数组是具有相同评估类型的部分的固定大小集合，分配在连续的内存位置。包中的每个部分都通过索引访问，索引负责记录其在数组中的详细信息。

### 获取数组以拥有索引进行显示

在 C++ 中，你可以通过声明部分的类型选择和集合的大小来设置数组。这是一个带有两个部分初始化的示例：

cpp

复制代码

```cpp
#include <iostream>

int main() {
    // 创建一个大小为 5 的整数数据数组
    int numbers[5] = {10, 20, 30, 40, 50};

    // 访问数组部分

    std::cout << "Introductory piece: " << numbers[0] << std::endl;

    std::cout << "later part: " << numbers[1] << std::endl;

    return 0;
}
``` 在此模型中，我们创建了一个包含五个部分的集合 `numbers`，并在稍后通过它们特定的记录访问并打印第一部分和后续。

### C++ 中的向量

向量是 C++ 标准模板库（STL）提供的重要类数组数据结构。与数组完全不同，向量可以逻辑地调整自己的大小以适应添加的部分。

# 面向对象编程 (OOP)

面向对象编程（OOP）是一种基于“对象”概念的范式。在本节中，我们将探索 OOP 的基础，包括类和对象。

### 类和对象

类是创建对象的蓝图。它定义了对象将拥有的属性（特征）和行为（方法）。这是一个声明示例：

```cpp
#include <iostream>

// 类声明
class Vehicle {

public:
    // 属性
    std::string brand;

    int year;

    // 显示数据的方法
    void displayInfo() {
        std::cout << "Brand: " << brand << ", Year: " << year << std::endl;
    }
};
```

```cpp
int main() {
    // 创建 Vehicle 类的对象
    Vehicle myCar;

    // 设置属性
    myCar.brand = "Toyota";

    myCar.year = 2022;

    // 调用方法
    myCar.displayInfo();

    return 0;
}
``` 在此模型中，`Vehicle` 是一个带有 `brand` 和 `year` 的类，以及一个显示数据的 `displayInfo()` 方法。

# 封装和信息隐藏

封装是将信息（属性）和处理这些信息的技术（方法）封装在单一单元（类）内部。它允许通过将特定属性或策略设置为私有来控制对信息的访问，从而从其他世界隐藏实现细节。

```cpp
class BankAccount {

private:
double balance;// 私有属性

public:
// 存储现金的公共策略
void deposit(double sum) {
if (sum > 0) {
balance += sum;
}
}

// 获取余额的公共策略 (getter)
double getBalance() {
    return balance;
}
};
``` 在此模型中，`balance` 是 `BankAccount` 类的私有属性，而 `deposit()` 策略是一个允许向记录中存储现金的公共技术。`getBalance()` 技术是一个公共 getter 策略，允许你获取记录余额。
