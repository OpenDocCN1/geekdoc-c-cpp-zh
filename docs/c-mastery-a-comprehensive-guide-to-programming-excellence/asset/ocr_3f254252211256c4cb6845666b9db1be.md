```
int head() {
    int x = 10;

    if (x > 0) {
        std::cout << "x is positive" << std::endl;
    } else if (x < 0) {
        std::cout << "x is negative" << std::endl;
    } else {
        std::cout << "x is zero" << std::endl;
    }

    return 0;
}
```

In this model, in case x is positive, the chief block will be executed. If x is negative, the resulting block will be executed. Differently, the third block will be executed.
