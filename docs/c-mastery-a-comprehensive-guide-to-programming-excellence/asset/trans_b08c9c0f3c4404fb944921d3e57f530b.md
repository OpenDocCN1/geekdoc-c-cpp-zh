

# 第 12 部分：总装一切：比常规模更小的任务

在这一部分，我们将应用贯穿全书的思想，在 C++ 中完成一些比常规模更小的任务。这些任务将帮助你建立对编程基础知识的理解，并允许你以一种既有趣又智能的方式练习批判性思维能力。

# 编写基础游戏

猜数字游戏：编写一个程序，在 1 到 100 之间随机生成一个数字，并要求用户猜出该数字。给用户提供反馈（例如，“太高了”或“太低了”），并记录尝试的次数。如果用户需要，允许他们再次游戏。

剪刀石头石头布：执行一个经典的剪刀石头石头布游戏回合。让用户从三个选项中选择一个，然后为电脑生成一个随机决定。根据游戏规则判断胜负并显示结果。

# 直观项目

每日计划规划器：开发一个允许用户处理每日计划的程序。用户应该能够添加任务、标记任务为已完成、删除任务以及显示正在进行的任务列表。实现一个基于菜单的界面来与计划进行交互。

简易微型计算机：构建一个基础的数字处理程序，可以执行加、减、乘、除等数学任务。允许用户输入两个数字并选择一个要执行的操作。向用户显示结果。

# 用 C++ 解决趣味问题

斐波那契数列：编写一个程序，生成到指定项数的斐波那契数列。向用户显示该序列并计算该数列的总和。

回文检查器：编写一个程序检查给定字符串是否为回文（正读反读都相同）。在判断字符串是否为回文时，忽略空格、标点和大小写。

结束

在这一节中，我们研究了一些你可以执行以练习 C++ 编程能力的小型项目。这些活动涵盖了从简单的游戏到智能项目以及批判性思维挑战。通过完成这些任务，你将加强对编程概念的理解，并积极参与构建可靠的 C++ 应用程序。祝编码愉快！

# 第 13 部分：C++ 高级主题

在这一部分，我们将探讨一些超越书中之前讨论的基础知识的 C++ 高级主题。这些点将提升你对语言的理解，并让你熟悉更先进的概念和技术。

# 泛型 (Templates)

C++ 中的泛型允许你编写可以与任何数据类型工作的非特定代码。它们对于创建独立于显式数据类型的数据设计和计算特别有用。

重复代码

```cpp
template<typename T>
T maximum(T a, T b) {
    return (a > b) ? a : b;
}
```

# STL (标准模板库)

标准模板库（STL）是一组强大的类和函数，提供了 C++ 中通用的数据结构和算法。它包含了向量、记录和指南等容器，以及用于排序、查找和控制信息的算法。

重复代码

```cpp
#include <vector>
#include <algorithm>

std::vector<int> numbers = {3, 1, 4, 1, 5, 9, 2, 6};

std::sort(numbers.begin(), numbers.end());
```

# Lambda 表达式

Lambda 表达式允许你内联定义匿名函数，使得编写短小的、一次性的功能更加简单，而不需要独立的函数声明。

重复代码

```cpp
auto total = [](int a, int b) { return a + b; };

std::cout << total(3, 5) << std::endl; //结果: 8
```

# 并发性

C++ 通过 `<thread>` 和 `<future>` 等库提供了多线程和异步编程的支持。这些特性允许你创建可以同时执行多个任务的程序，进一步提高执行和响应速度。

重复代码

```cpp
#include <iostream>
#include <thread>

void welcome() {
    std::cout << "Hello!" << std::endl;
}

int main() {
    std::thread t(welcome);
    t.join();
    return 0;
}
```

# 智能指针

智能指针是像指针一样的对象，但提供了内存管理等额外功能。它们有助于防止内存泄漏。

```cpp
#include <memory>

std::shared_ptr<int> ptr = std::make_shared<int>(10);
```

结束

在这一部分，我们研究了几个 C++ 高级主题，包括泛型、标准模板库 (STL)、Lambda 表达式、并发和智能指针。这些点将提升你对语言的理解和测试能力。当你继续 C++ 之之旅时，请确保探索更先进的概念和技术。

# 第 14 部分：C++ 最佳实践与改进

在这一部分，我们深入探讨了编写高效 C++ 代码的最佳实践和改进方法。遵循这些实践将帮助你创建清晰、可维护且健壮的代码。

# 1. 使用有意义的变量名

为变量、函数和类选择描述性的名称。

# 2. 遵循编码规范

坚持一致的代码风格和组织模式。

# 3. 限制全局变量

限制全局变量的使用，因为它们会创建隐藏依赖并增加测试难度。

# 4. 避免魔数

用命名常量或规范替换数字字面量，以提高代码的可读性。

# 5. 错误处理

使用适当的错误处理（例如异常或错误代码），以灵活处理意外情况并防止崩溃。

# 6. 使用智能指针

使用智能指针（如 `std::unique_ptr` 和 `std::shared_ptr`）管理内存，避免内存泄漏。

# 7. 避免过早优化

优先编写清晰高效的代码。仅在通过性能分析并识别瓶颈后再对代码执行部分进行优化。

# 8. 使用标准库

在情况允许的情况下使用 C++ 标准库（STL）提供的功能和算法。它是经过充分测试、高效且紧凑的。

# 9. 性能分析与基准测试

通过性能分析识别执行瓶颈，并使用基准测试量化改进的效果。

# 10. 代码注释

编写清晰的注释来记录代码，包括逻辑、行为以及任何非明显设计选择的说明。

# 11. 测试驱动开发 (TDD)

采用测试驱动开发方法，确保代码在更改后仍然符合预期。

# 12. 代码模块化

将代码拆分为更小的、可重用的模块（函数、类或库），以提高代码的可重用性和活力。

# 13. 持续集成与持续部署 (CI/CD)

自动化构建、测试和部署周期，确保代码库的更改经过测试并以受控的方式交付。

# 14. 从他人学习

关注经验 C++ 设计师的代码，参与代码审查并贡献开源项目，以学习新的方法和最佳实践。
