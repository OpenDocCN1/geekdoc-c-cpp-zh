## Segment 2: Elements and Data Types

In this segment, we'll explore elements and data types in C++. Understanding how to store and manipulate data is crucial for any programmer.

## What are Variables?

A variable is a named region in the PC's memory, used to store data that can change during execution. Think of a variable a container that holds information.

In C++, you can declare a variable by deciding its type followed by its name. For example:

```cpp
int age = 25;
```

## Data Types in C++

C++ maintains a couple of native data types, each expected to store different kinds of data. The following are a couple of common types:

- int: Used to store integer numbers (e.g., 10, -5, 1000).

- double: Used to store floating point numbers with decimal places (e.g., 3.14, -0.5, 100.0).

- char: Used to store single characters (e.g., 'A', 'b', '$').

- bool: Used to store Boolean characteristics (either true or false).

- string: Used to store sequences of characters (e.g., "Hello").

## Using Elements to Store Data

At the point you've declared a variable, you can give a value to it using the assignment operator =. For example:

```cpp
int age; // Declare a variable named 'age'
age = 10; // Assign the value 10 to the variable 'age'
```

You can also instantiate a variable at the time of declaration:

```cpp
int score = 100; // Declare and instantiate a variable named 'score' with the value 100
```
