# Setting Up the View:

Use QTableView to display the items in the model.

```
```cpp
int main(int argc, char *argv[]) {
    QApplication app(argc, argv);
    ItemModel *model = new ItemModel();
    QTableView *tableView = new QTableView();
    tableView->setModel(model);
    tableView->show();
    return app.exec();
}
```
