+   
+      A. *Partitioning Step:* Take the first element of the unsorted `array` and determine its final location in the sorted `array` (i.e., all values to the left of the element in the `array` are less than the element’s value, and all values to the right of the element in the `array` are greater than the element’s value—we show how to do this below). We now have one value in its proper location and two unsorted sub-`array`s.
+   
+      B. *Recursion Step:* Perform the *Partitioning Step* on each unsorted sub-`array`.
