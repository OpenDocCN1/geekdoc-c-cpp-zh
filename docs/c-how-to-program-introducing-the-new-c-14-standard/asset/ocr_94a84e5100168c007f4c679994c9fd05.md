# Fig. 5.21 Rules for forming structured programs.

| Rules for forming structured programs |
|---|
| 1. Begin with the simplest activity diagram ([Fig. 5.22](#)).<br>2. Any action state can be replaced by two action states in sequence.<br>3. Any action state can be replaced by any control statement (sequence of action states, `if`, `if...else`, `switch`, `while`, `do...while` or `for`).<br>4. Rules 2 and 3 can be applied as often as you like and in any order. |
