# Performance Tip 5.1

*In loops, avoid calculations for which the result never changes—such calculations should typically be placed before the loop. Many of today’s sophisticated optimizing compilers will place such calculations before loops in the compiled code.*

# *Floating-Point Number Precision and Memory Requirements*

Variables of type `float` represent **single-precision floating-point numbers** and have approximately seven significant digits on most of today’s systems. Variables of type `double` represent **double-precision floating-point numbers**. These require twice as much memory as `float` variables and provide approximately 15 significant digits on most of today’s systems—approximately double the precision of `float` variables.
