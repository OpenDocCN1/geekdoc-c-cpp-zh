# Fig. 22.29 String-conversion function `atoi`.

Function `atoi` (Fig. 22.30, line 8) converts its argument—a string of digits representing a long integer—to a `long` value. The function returns the `long` value. If the string cannot be converted, function `atoi` returns zero. If `int` and `long` are both stored in four bytes, function `atoi` and function `atol` work identically.

```
// Fig. 22.30: fig22_30.cpp
// Using atol.
#include <iostream>
#include <cstdlib> // atol prototype
using namespace std;

int main() {
    long x = atol("1000000"); // convert string to long

    cout << "The string \"1000000\" converted to long is " << x
         << "\nThe converted value divided by 2 is " << x / 2 << endl;
}
```

```
The string "1000000" converted to long int is 1000000
The converted value divided by 2 is 500000
```
