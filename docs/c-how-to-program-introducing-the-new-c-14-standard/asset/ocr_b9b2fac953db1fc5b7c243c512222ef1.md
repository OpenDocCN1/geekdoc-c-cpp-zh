This *hiding of implementation details* promotes good software engineering. **Figure 6.1** shows the `boss` function communicating with several worker functions. The `boss` function divides the responsibilities among the `worker` functions, and `worker1` acts as a “boss function” to `worker4` and `worker5`. The relationship does not need to be hierarchical, but often it is, which makes it easier to test, debug, update and maintain programs.
