Pointers, like any other variables, must be declared **before** they can be used. For example, for the pointer `countPtr` in **Fig. 8.1**, the declaration

```
```c
int* countPtr, count;
```
```

declares the variable `countPtr` to be of type `int*` (i.e., a pointer to an `int` value) and is read *(right to left)*, “`countPtr` is a pointer to `int`.” Variable `count` in the preceding declaration is declared to be an `int`, but **not** a pointer to an `int`. The `*` in the declaration applies only to the first variable. Each variable being declared as a pointer **must** be preceded by an asterisk (`*`). When `*` appears in a declaration, it’s **not** an operator; rather, it indicates that the variable being declared is a pointer. Pointers can be declared to point to objects of **any** data type.

# Common Programming Error 8.1

> Assuming that the `*` used to declare a pointer distributes to all names in a declaration’s comma-separated list of variables can lead to errors. Each pointer must be declared with the `*` prefixed to the name (with or without spaces in between). Declaring only one variable per declaration helps avoid these types of errors and improves program readability.
