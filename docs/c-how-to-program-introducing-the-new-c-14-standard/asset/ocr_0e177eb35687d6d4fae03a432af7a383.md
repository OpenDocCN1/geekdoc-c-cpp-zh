# 8.4 Pass-by-Reference with
Pointers

There are three ways in C++ to pass arguments to a function:

+   - pass-by-value
+   - pass-by-reference with a reference argument
+   - **pass-by-reference with a pointer argument.**

**Chapter 6** compared and contrasted the first two. Here, we explain
pass-by-reference with a pointer argument.

**Chapter 6** showed that `return` can return one value from a called
function or simply return control. You also learned that arguments can
be passed to a function using reference parameters, which enable the
called function to modify the original values of the arguments in the
caller. Reference parameters also enable programs to pass large data
objects to a function without the overhead of pass-by-value which, of
course, copies the object. Pointers, like references, also can be used
to modify variables in the caller or to pass large data objects by
reference to avoid the overhead of copying the objects.
