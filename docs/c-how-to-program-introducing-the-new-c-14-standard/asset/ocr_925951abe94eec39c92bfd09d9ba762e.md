# Recursive Implementation

Our merge sort implementation is *recursive*. The base case is an `array` with one element. Such an `array` is, of course, sorted, so merge sort immediately returns when it’s called with a one-element `array`. The *recursion* step splits an `array` of two or more elements into two equal-sized sub-`array`s, recursively sorts each sub-`array`, then merges them into one larger, sorted `array`. [Again, if there is an odd number of elements, one sub-`array` is one element larger than the other.]
