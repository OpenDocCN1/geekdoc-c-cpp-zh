**pointer/offset notation.** The parentheses are necessary, because the precedence of `*` is higher than that of `+`. Without the parentheses, the preceding expression would add `3` to a copy of `*bPtr`’s value (i.e., `3` would be added to `b[0]`, assuming that `bPtr` points to the beginning of the built-in array).

```
