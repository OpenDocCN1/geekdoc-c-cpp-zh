# 19.1.1 Always Prefer the Standard
Library’s Containers, Iterators and
Algorithms, if Possible

The C++ Standard Library’s *containers*, *iterators* for traversing those
containers and *algorithms* for processing the containers’ elements
meet the needs of most C++ programmers. The Standard Library
code is carefully written to be correct, portable, efficient and
extensible. Understanding how to build custom templatized data
structures will also help you use the Standard Library containers,
iterators and algorithms, more effectively.
