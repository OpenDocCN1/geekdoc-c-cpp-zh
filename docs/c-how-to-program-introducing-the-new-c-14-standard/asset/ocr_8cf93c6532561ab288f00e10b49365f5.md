```
```cpp
bPtr = &b[0]; // also assigns address of built-in array b to bPtr
```
```

The expression

```
```cpp
b += 3
```
```

causes a compilation error, because it attempts to *modify* the value of the built-in array’s name with pointer arithmetic.
