# Fig. 22.37 String-search function `strpbrk`.

Function `strchr` searches for the last occurrence of the specified character in a string. If the character is found, `strchr` returns a pointer to the character in the string; otherwise, `strchr` returns `0`. Line 14 of Fig. 22.38 searches for the last occurrence of the character `'z'` in the string `"A zoo has many animals including zebras"`.
