**Figure 12.19** uses the `Employee` hierarchy from **Section 12.7** and increases by 10 percent each `BasePlusCommissionEmployee`’s base salary. Lines 20–24 create and initialize the three-element `vector` named `employees` that stores pointers to `Employee` objects. The elements are initialized with the addresses of *dynamically allocated* objects of classes `SalariedEmployee` (**Figs. 12.11–12.12**), `CommissionEmployee` (**Figs. 12.13–12.14**) and `BasePlusCommissionEmployee` (**Figs. 12.15–12.16**). Lines 27–44 of **Fig. 12.19** iterate through the `employees` vector and display each `Employee`’s information by invoking member function `toString` (line 28). Recall that because `toString` is declared `virtual` in *base class* `Employee`, the system invokes the appropriate *derived-class* object’s `toString` function.
