Each arrow in the hierarchy (**Fig. 11.2**) represents an *is-a* relationship.\nFor example, as we follow the arrows in this class hierarchy, we can state “an `Employee` is a `Community-Member`” and “a `Teacher` is a `Faculty member.” `CommunityMember` is the **direct base class** of `Employee`, `Student` and `Alumnus. In addition, `CommunityMember` is an **indirect base class** of all the other classes in the diagram. An indirect base class is inherited from two or more levels up the class hierarchy.

Starting from the bottom of the diagram, you can follow the arrows upward and apply the *is-a* relationship to the topmost base class. For example, an `AdministratorTeacher` *is an* `Administrator`, *is a* `Faculty member, is an* `Employee` and *is a* `CommunityMember`.
