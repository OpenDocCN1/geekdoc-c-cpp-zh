# Big O: Linear Runtime

An algorithm that tests whether the first element of an `array` is equal to any of the other elements of the `array` requires at most *n* − 1 comparisons, where *n* is the number of elements in the `array`. If the `array` has 10 elements, the algorithm requires up to nine comparisons. If the `array` has 1000 elements, the algorithm requires up to 999 comparisons. As *n* grows larger, the *n* part of the expression *n* − 1 “dominates,” and subtracting one becomes inconsequential. Big O is designed to highlight these dominant terms and ignore terms that become unimportant as *n* grows. For this reason, an algorithm that requires a total of *n* − 1 comparisons (such as the one we described in this paragraph) is said to be **O(n)** and is referred to as having a **linear runtime**. *O(n)* is often pronounced “on the order of *n*” or more simply “order *n*.”
