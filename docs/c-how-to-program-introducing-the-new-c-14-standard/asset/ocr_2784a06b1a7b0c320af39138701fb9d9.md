# 13.7.3 Padding (`fill`, `setfill`)

The `fill` member function specifies the *fill character* to be used with justified fields; *spaces* are used for padding by default. The function returns the prior padding character. The `setfill` manipulator also sets the *padding character*. **Figure 13.14** demonstrates function `fill` (line 29) and stream manipulator `setfill` (lines 33 and 36) to set the fill character.
