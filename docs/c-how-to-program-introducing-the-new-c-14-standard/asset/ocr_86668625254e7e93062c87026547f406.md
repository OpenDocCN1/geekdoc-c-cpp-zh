# 18.3 Function Template to Manipulate a Class-Template Specialization Object

The code in function `main` of **Fig. 18.3** is *almost identical* for both the `doubleStack` manipulations in lines 8–29 and the `intStack` manipulations in lines 31–51. This presents another opportunity to use a function template. **Figure 18.4** defines function template `testStack` (lines 10–36) to perform the same tasks as `main` in **Fig. 18.3**—*push* a series of values onto a `Stack<T>` and *pop* the values of a `Stack<T>`.
