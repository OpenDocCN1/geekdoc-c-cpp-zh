# Fig. 22.45 Memory-handling function `memchr`.

Function `memset` copies the value of the byte in its second argument into a specified number of bytes of the object pointed to by its first argument. Line 12 in Fig. 22.46 uses `memset` to copy `'b'` into the first 7 bytes of `string1`.
