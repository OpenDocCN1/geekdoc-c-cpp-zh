# *The `std` Namespace*

The `std::` before `cout` is required when we use names that we’ve brought into the program by the preprocessing directive `#include <iostream>`. The notation `std::cout` specifies that we are using a name, in this case `cout`, that belongs to namespace `std`. The names `cin` (the standard input stream) and `err` (the standard error stream)—introduced in [Chapter 1]—also belong to namespace `std`.
