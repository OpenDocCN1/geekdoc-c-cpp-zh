As you’ll see, various algorithms can receive a *function pointer* as an argument—recall that a function’s name is implicitly convertible to a pointer to that function’s code. Such algorithms use the pointer to call the function, typically with one or two container elements as arguments. For most of the examples in this chapter, rather than function pointers we’ll use *lambda expressions*—C++11’s convenient shorthand notation for creating *anonymous functions* (that is, functions that do not have names).
