# 7.4.1 Declaring an `array` and
Using a Loop to Initialize the
`array`’s Elements

The program in **Fig. 7.3** declares five-element integer `array` **n** (line 9). Line 5 includes the `<array>` header, which contains the definition of class template `array`. Lines 12–14 use a `for` statement to initialize the `array` elements to zeros. Like other non-`static` local variables, `array`s are *not* implicitly initialized to zero (`static` `array`s are). The first output statement (line 16) displays the column headings for the columns printed in the subsequent `for` statement (lines 19–21), which prints the `array` in tabular format. Remember that `setw` specifies the field width in which only the *next* value is to be output.
