# 15.7.3 `priority_queue` Adapter

Class `priority_queue` (from header `<queue>`) provides functionality that enables *insertions* in sorted order into the underlying data structure and deletions from the *front* of the underlying data structure. By default, a `priority_queue`’s elements are stored in a `vector`. When elements are added to a `priority_queue`, they’re inserted in *priority order*, such that the highest-priority element (i.e., the *largest* value) will be the first element removed from the `priority_queue`. This is usually accomplished by arranging the elements in a data structure called a **heap** (not to be confused with the heap for dynamically allocated memory) that always maintains the largest value (i.e., highest-priority element) at the front of the data structure. The comparison of elements is performed with *comparator function object* `less<T>` by default, but you can supply a different comparator.

There are several common `priority_queue` operations. Function `push` inserts an element at the appropriate location based on *priority order* of the `priority_queue`, which then reorders the elements in priority order.
