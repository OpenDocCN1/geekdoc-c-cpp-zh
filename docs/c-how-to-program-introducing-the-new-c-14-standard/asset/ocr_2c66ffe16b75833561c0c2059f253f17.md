In this program, the `catch` handler specifies that it catches `DivideByZeroException` objects—this type matches the object type thrown in function `quotient`. Actually, the `catch` handler catches a *reference* to the `DivideByZeroException` object created by function `quotient`’s `throw` statement (line 13), so that the `catch` handler does *not* make a copy of the exception object.

The `catch`’s body (lines 35–36) prints the error message returned by function `what` of base-class `runtime_error`—i.e., the string that the `DivideByZeroException` constructor (lines 10–11 in *Fig. 17.1*) passed to the `runtime_error` base-class constructor.
