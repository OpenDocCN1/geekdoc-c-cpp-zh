# *Even `int64_t` Is Limited*

Though class `DollarAmount` can represent extremely large monetary values, the range of values supported by `int64_t` is still limited. Through C++'s class mechanism, you'll see that you can define a class that you might call `BigInteger` or `HugeInteger` (as you'll do in **Exercise 10.9**), which could store and manipulate integers of *any* size. By doing so, you will have truly crafted another valuable class.
