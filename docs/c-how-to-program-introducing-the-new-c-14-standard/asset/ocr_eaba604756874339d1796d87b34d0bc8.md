The expression

```
```cpp
b.count()
```
```

returns the number of bits that are set (`true`) in `bitset b`.

The expression

```
```cpp
b.any()
```
```

returns `true` if any bit is set in `bitset b`.

The expression

```
```cpp
b.all()
```
```

11

(added in C++11) returns `true` if all of the bits are set (`true`) in `bitset b`.
