# ## C++14 Digit Separators for Numeric Literals

Prior to C++14, you’d represent the integer value 60,000,000 as `60000000` in a program. Typing numeric literals with many digits can be error prone. To make numeric literals more readable, C++14 allows you to insert between groups of digits in numeric literals the **digit separator** `'` (a single-quote character)—for example, `60'000'000` (line 18) represents the integer value 60,000,000. You might wonder why single-quote characters are used rather than commas. If we use `60,000,000` in line 18, C++ treats the commas as *comma operators* and the value of `60,000,000` would be the *rightmost* expression (`000`). The loop-continuation condition would immediately be *false*—a logic error in this program.
