# *Using an Element’s Subscript*

The range-based `for` statement can be used in place of the counter-controlled `for` statement whenever code looping through an `array` does *not* require access to the element’s subscript. For example, totaling the integers in an `array` (as in Fig. 7.6) requires access only to the element values—the elements’ subscripts are irrelevant. However, if a program must use subscripts for some reason other than simply to loop through an `array` (e.g., to print a subscript number next to each `array` element value, as in the examples earlier in this chapter), you should use the counter-controlled `for` statement.
