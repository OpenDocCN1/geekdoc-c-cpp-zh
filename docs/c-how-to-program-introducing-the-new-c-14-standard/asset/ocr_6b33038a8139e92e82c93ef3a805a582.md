Many of the applications you develop will have more than one function
of the same name. This technique, called function overloading, is used
to implement functions that perform similar tasks for arguments of
different types or different numbers of arguments. We consider
function templates—a mechanism for concisely defining a family of
overl oaded functions. The chapter concludes with a discussion of
functions that call themselves, either directly, or indirectly (through
another function)—a topic called recursion.
