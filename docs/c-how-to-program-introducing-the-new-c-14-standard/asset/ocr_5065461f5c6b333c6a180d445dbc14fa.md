# Section 19.6 Trees

+   - Binary trees (p. 823) are trees whose nodes all contain two links (none, one or both of which may have the value `nullptr`).
+   - The **root node** (p. 823) is the first node in a tree.
+   - Each link in the root node refers to a child. The left child is the root node of the **left subtree** (p. 823), and the right child is the root node of the **right subtree** (p. 823).
+   - The children of a single node are called **siblings** (p. 823). A node with no children is called a **leaf node** (p. 823).
+   - A **binary search tree** (p. 824) (with no duplicate node values) has the characteristic that the values in any left subtree are less than the value in its **parent node** (p. 824), and the values in any right subtree are greater than the value in its parent node.
+   - A node can only be inserted as a leaf node in a binary search tree.
+   - An **inorder traversal** (p. 824) of a binary tree traverses the left subtree, processes the value in the root node then traverses the right subtree. The value in a node is not processed until the values in its left subtree are processed. An inorder traversal of a binary search tree processes the nodes in sorted order.
+   - A **preorder traversal** (p. 824) processes the value in the root node, traverses the left subtree, then traverses the right subtree. The value in each node is processed as the node is encountered.
+   - A **postorder traversal** (p. 824) traverses the left subtree, traverses the right subtree, then processes the root node’s value. The value in each node is not processed until the values in both subtrees are processed.
