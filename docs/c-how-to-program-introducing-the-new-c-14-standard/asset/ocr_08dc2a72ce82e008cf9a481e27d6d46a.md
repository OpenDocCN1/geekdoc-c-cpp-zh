# 5.3 `for` Iteration Statement

**Section 5.2** presented the essentials of counter-controlled iteration. The `while` statement can be used to implement any counter-controlled loop. C++ also provides the **`for` iteration statement**, which specifies the counter-controlled-iteration details in a single line of code. **Figure 5.2** implements the application of **Fig. 5.1** using `for`.

When the `for` statement (lines 9–11) begins executing, the control variable `counter` is *declared and initialized* to `1`. (Recall from **Section 5.2** that the first two elements of counter-controlled iteration are the *control variable* and its *initial value*.) Next, the program checks the *loop-continuation condition*, `counter <= 10`, which is between the two

```
```cpp
// Fig. 5.2: ForCounter.cpp
// Counter-controlled iteration with the for iteration statement.
#include <iostream>
using namespace std;

int main() {
   // for statement header includes initialization,
   // loop-continuation condition and increment
   for (unsigned int counter{1}; counter <= 10; ++counter) {
      cout << counter << " ";
   }

   cout << endl;
}
