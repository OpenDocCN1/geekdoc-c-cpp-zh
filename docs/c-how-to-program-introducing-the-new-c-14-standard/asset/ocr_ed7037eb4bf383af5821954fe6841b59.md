Represent the set internally as a `vector` of `bool` values.  
Element `a[i]` is `true` if integer *i* is in the set. Element `a[j]` is `false` if integer *j* is not in the set. The default constructor initializes a set to the so-called “empty set,” i.e., a set for which all elements contain `false`.
