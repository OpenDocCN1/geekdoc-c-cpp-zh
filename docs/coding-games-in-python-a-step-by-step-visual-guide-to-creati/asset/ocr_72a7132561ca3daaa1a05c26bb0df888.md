# # How to build
## Big Quiz

Put your coding skills to the test and create a quiz game to challenge your friends. You’re the quizmaster, so you can make the questions about any topic you like.

# ## What happens

When the game begins, the first question is shown on the screen along with four possible answers. The player then has ten seconds to click on an answer box. If they get the right answer, the game moves on to the next question. If the player chooses a wrong answer, or if the time runs out, the game ends and the final score is displayed on the screen.
