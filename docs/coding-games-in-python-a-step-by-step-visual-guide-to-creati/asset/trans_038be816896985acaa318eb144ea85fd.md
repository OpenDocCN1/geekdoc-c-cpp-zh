### 22 停止动画

现在需要定义 `stop_animations()` 函数。这个函数会遍历列表，并对每个正在运行的动画调用 `stop()`，从而让星星停止移动。

```python
animations = []

def stop_animations(animations_to_stop):
    for animation in animations_to_stop:
        if animation.running:
            animation.stop()
```
