△ **A longer dance**

You can make the game more challenging. Each time you complete three sequences, increase the `dance_length` by one. To find out how many rounds have been completed, divide the number of sequences danced by three. If the remainder is zero, then three sequences have been successfully completed since the last check, so add 1 to `dance_length`. You can use Python’s modulo operator to work out the remainder. Modulo is written using the `%` symbol, so 4 % 3 will give you the remainder on dividing 4 by 3.
