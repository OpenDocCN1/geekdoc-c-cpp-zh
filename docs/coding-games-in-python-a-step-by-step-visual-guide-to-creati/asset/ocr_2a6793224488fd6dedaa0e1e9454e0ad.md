# Keeping score

Imagine the current high scores are 12, 10, 8, and a player scores 11. If your code just replaced each score you’ve beaten with the new score, you’d end up with 12, 11, 11, which wouldn’t be right. To avoid this, your code needs to compare the player’s score with the top score first. 11 is less than 12, so it doesn’t replace it. It then needs to move on to the second-highest score. The next one, 11 is greater than 10, so it replaces it. Now that 11 is on the scoreboard, the code needs to check if the score that was just replaced, is greater than the score currently in third place. Because 10 is greater than 8, it replaces it, and 8 is removed altogether.

high_scores = line.split()

This sets score to the high score that was just beaten.
