# 24 Unhappy garden!

Next you need to check if any of the flowers have been wilted for more than ten seconds. If one has, the garden’s unhappy, and it’s game over! Copy the `check_wilt_times()` in Step 13 and replace `pass` with the code shown here.

def check_wilt_times():
    global wilted_list, game_over, garden_happy
    if wilted_list:
        for wilted_since in wilted_list:
            if (not wilted_since == "happy"):
                time_wilted = int(time.time() - wilted_since)
                if (time_wilted > 10.0):
                    garden_happy = False
                    game_over = True
                    break
    return
