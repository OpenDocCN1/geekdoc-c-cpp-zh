# ## 1. Get started

Open IDLE and create an empty file by clicking on the **File** menu and choosing **New File**.

![](bbox=[0.028, 0.259, 0.313, 0.468])

# ## 2. Save the game

Go to your python-games folder and create another folder called **happy-garden**. From the **File** menu, choose **Save As...** and save the program as *garden.py* inside the happy-garden folder.

![](bbox=[0.505, 0.294, 0.955, 0.457])

# ## 3. Set up an image folder

Within the happy-garden folder, create another folder by right-clicking and choosing **New Folder**. Name it *images*. It will be used to store all the images you need for this game.

![](bbox=[0.025, 0.594, 0.482, 0.777])

# ## 4. Put the images into the folder

Find the images for Happy Garden in the Python Games Resource Pack (dkl.com/computercoding) and copy them into the images folder. Your folders should look like this now.

![](bbox=[0.504, 0.594, 0.955, 0.776])
