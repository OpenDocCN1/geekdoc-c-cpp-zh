## 12 导入 randint()

## 13 放置金币

接下来修改 `place_coin()` 函数中的代码。这个函数会将金币放在屏幕上的随机位置。删除 `pass`，然后输入这些命令。

```python
def place_coin():
    coin.x = randint(20, (WIDTH - 20))
    coin.y = randint(20, (HEIGHT - 20))
```

金币将被放置在距离屏幕边缘至少 20 个像素的位置。

## 15. 时间到！

现在让我们填充 `time_up()` 函数的代码。在这个函数中，将 `game_over` 布尔变量设置为 `True`，这会在函数被调用时告诉程序退出游戏。输入以下代码。

```python
def time_up():
    global game_over
    game_over = True
```

记得删除 `pass` 关键字，然后添加这些行。

## 16. 设置计时器

既然 `time_up()` 已经定义好了，程序需要运行它。但它需要在游戏开始七秒后运行。你可以使用 Pygame Zero 的内置工具 `clock` 来实现这一点。这个工具让你可以编程在指定时间后调用一个函数。如图所示，在代码中添加这一行。

```python
clock.schedule(time_up, 7.0)
place_coin()
```

这行代码会在游戏开始七秒后运行 `time_up()` 函数。

## 17. 结束游戏

游戏开始，七秒后 `clock.schedule` 将运行 `time_up()` 函数，从而结束游戏。但游戏还需要显示玩家的最终得分。为此，你需要在 `draw()` 函数中再添加一小段代码。

![](img/3188b147f991a51de14dcd2bb4b4c42e_66_0.png)

```python
def draw():
    screen.fill("green")
    fox.draw()
    coin.draw()
    screen.draw.text("Score: " + str(score), color="black", topleft=(10, 10))

    if game_over:
        screen.fill("pink")
        screen.draw.text("Final Score: " + str(score), topleft=(10, 10), fontsize=60)
```

如果变量 `game_over` 为 `True`，屏幕将会变成粉红色。

最终得分会显示在屏幕上。

这条命令设置了屏幕上显示文字的大小。

## 18. 使用 update()

你需要定义的最后一个函数是 `update()`。这是 Pygame Zero 的内置函数，这意味着与其他函数不同，你不用担心何时运行它。一旦你定义好它，Pygame Zero 就会自动运行它——每秒钟 60 次！删除 `def update()` 下的 `pass`，并添加这段代码。如果你按下键盘上的左箭头键，狐狸就会向左移动。

```python
def update():
    if keyboard.left:
        fox.x = fox.x - 2
```

按左箭头键时，狐狸会向左移动两个像素。

## 19 单向移动

现在测试你的代码。你应该能够向左移动狐狸了。但狐狸还需要能够向其他方向移动，所以添加这段代码来实现。

![](img/3188b147f991a51de14dcd2bb4b4c42e_67_0.png)

```python
def update():
    if keyboard.left:
        fox.x = fox.x - 2
    elif keyboard.right:
        fox.x = fox.x + 2
    elif keyboard.up:
        fox.y = fox.y - 2
    elif keyboard.down:
        fox.y = fox.y + 2
```

这些 else-if 分支用于根据按下的方向键来移动狐狸。

## 20 收集金币

最后，你需要添加一些代码，以便在狐狸触碰到金币时更新得分。将这段代码添加到 `update()` 函数中。

确保你将这一行添加到代码的最顶部。

如果狐狸触碰到金币，这个变量将为 `True`。

```python
def update():
    global score

    if keyboard.left:
        fox.x = fox.x - 2
    elif keyboard.right:
        fox.x = fox.x + 2
    elif keyboard.up:
        fox.y = fox.y - 2
    elif keyboard.down:
        fox.y = fox.y + 2

    coin_collected = fox.colliderect(coin)

    if coin_collected:
        score = score + 10
        place_coin()

clock.schedule(time_up, 7.0)
place_coin()
```

这样会使得分增加十分。
