# Smooth animations

In Python, the update() function is automatically called 60 times every second. If you change the image of the bird each time this function is called, it would just be a blur on the screen. To make the animation smoother, add a block of code that will change the image every tenth time the function is called. You can change this interval if you want. But if the gap between the updates is too big, the bird will appear to move very slowly.
