# File handling

In Balloon Flight, you've used a .txt file to store the high scores. A file like this can be opened and assigned to a variable. The main functions that you need to handle the file are open(), read(), and write().

![](bbox=[0.544, 0.127, 0.941, 0.263])

▷ open() takes two parameters, the file name and the “mode,” which tells Python what you want to do with the file. There are four modes in Python: r for reading, w for writing, a for adding to the end of a file, and r+ for reading and writing.

```
file = open("names.txt", "r")
```

Name of the file
Mode

▽ Use the read() function to read an entire file.

```
names = file.read()
```

▽ You can also just read a single line, rather than the whole file.

```
name = file.readline()
```

▽ You can even add all the lines to a list.

```
lines = []
for line in file:
    lines.append(line)
```

▽ Now use the write() function to write to a file.

```
file = open("names.txt", "w")
file.write("Martin")
```

▽ When you’re finished with a file, you should close it to tell the program you are done with it.

```
file.close()
```

▽ If you forget to close a file after using it, some of the data may not get written to it. Use the with statement to stop this from happening. This statement opens the file and automatically closes it when it has finished running the body of the with statement.

```
with open("names.txt", "r") as file:
    name = file.readline()
```
