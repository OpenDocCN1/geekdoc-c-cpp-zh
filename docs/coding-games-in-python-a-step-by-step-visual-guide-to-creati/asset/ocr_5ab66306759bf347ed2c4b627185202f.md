# ### 3. Return a value

Rather than printing out the score, you might want to use it elsewhere in your code. You can ask to get a value out of a function to use later. This is called “returning” a value. Type in the keyword `return` before the value you want it to return in each case. Try switching your `print` statements to `return` statements.

```
```python
def fruit_score(fruit):
    if fruit == "apple":
        return 10
    elif fruit == "orange":
        return 5
```
```

Don’t use parentheses with `return` statements.

The values are returned for use later in the code. They will not appear in the shell.

# ## Indentation Errors

Python uses indentation to understand where a block of code starts and stops. An “IndentationError” appears when something is wrong with the way you’ve structured the code. Remember that if a line of code ends with a colon (:), the next line needs to be indented. If Python does not add them automatically, use the **Space bar** to manually insert four spaces.
