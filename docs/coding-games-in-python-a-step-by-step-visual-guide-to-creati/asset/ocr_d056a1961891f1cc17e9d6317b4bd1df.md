# ### 18 Move the hero

With everything set up, it’s time to add some code that will make the hero move on the screen. You’ll use the `update()` function to do this. If the player presses an arrow key, this code will make the hero move in that direction by the number of pixels assigned to `MOVE_DISTANCE`. You also need to add a call to the `check_for_collisions()` function, which you’ll define later. Type this code after the lines from Step 17.

```
```python
def update():
    if keyboard.right:
        hero.x += MOVE_DISTANCE
        if hero.x > WIDTH:
            hero.x = WIDTH
    elif keyboard.left:
        hero.x -= MOVE_DISTANCE
        if hero.x < 0:
            hero.x = 0
    elif keyboard.down:
        hero.y += MOVE_DISTANCE
        if hero.y > HEIGHT:
            hero.y = HEIGHT
    elif keyboard.up:
        hero.y -= MOVE_DISTANCE
        if hero.y < 0:
            hero.y = 0
    check_for_collisions()
