### EXPERT TIPS

**Event handling**

Dance Challenge uses an event handler function called on_key_up() to react to a player pressing an arrow key. You shouldn't put the code to deal with key presses inside the built-in update() function in this case because it will run too frequently. If you pressed a key down just for a second, update() would tell the game you had pressed it hundreds of times. This probably wouldn't match the dance sequence, so the game would finish right away.
