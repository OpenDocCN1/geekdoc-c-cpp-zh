# # How to build
## Dance Challenge

Get your groove on with this fast-paced game. Watch the dancer move to the music and then put your memory skills to the test by repeating those moves. How long can you keep going without making a mistake?

# ## What happens

In this game, the dancer performs a sequence of moves. You need to remember this sequence and make him repeat it using the four arrow keys on the keyboard.

![](bbox=[0.547, 0.205, 1.0, 0.962])

Each correct move will earn you a point.
