# ## Keep count

Change your code so that it can keep count of the number of times you click successfully. Here are some hints to help you out.

+   - Store the count in a variable.
+   - Start by setting the variable to 0.
+   - Increase the count by 1 each time you click on the apple.
+   - Use print() to show the score in the Command Prompt or Terminal window each time the apple is drawn on the screen.
