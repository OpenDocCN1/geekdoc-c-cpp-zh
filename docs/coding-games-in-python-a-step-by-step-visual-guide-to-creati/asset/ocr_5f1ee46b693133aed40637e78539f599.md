# ### Hello flowchart

When building a game, programmers use diagrams called flowcharts to plan their game and show how it works. Each step is shown in a box, with an arrow leading to the next step. More complicated games might have steps with questions and more than one arrow leading to different boxes, depending on the answer to the question.
