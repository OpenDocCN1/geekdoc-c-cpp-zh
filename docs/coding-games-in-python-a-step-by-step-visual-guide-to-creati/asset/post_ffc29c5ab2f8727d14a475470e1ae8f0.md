### Modulo operator

When Python performs division, it ignores the remainder. But sometimes it’s useful to know if there is a remainder and what it is. For example, if you want to test if the number is even, you can do so by dividing it by 2 and checking if there is a remainder. To do this, you can use the modulo operator %.

```python
>>> print(2 % 2)
0
```

> This is 0 because there is no remainder when 2 is divided by 2.

```python
>>> print(3 % 2)
1
```

> This is the remainder when 3 is divided by 2.

In Balloon Flight, you can use the modulo operator to know if the score is a multiple of 10, and therefore whether the player should move to the next level.

```python
score % 10
```

> This would return the remainder when the score is divided by 10.
