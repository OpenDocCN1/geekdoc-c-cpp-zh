The previous analysis included a continuous predictor variable (body weight) and a qualitative predictor variable (dinosaur). In the analysis, a common linear relationship between log(brain weight) and log(body weight) in both dinosaurs and non-dinosaurs was assumed. But, the relationship could differ between groups (in this case, between dinosaurs and non-dinosaurs). This type of analysis is sometimes called an analysis of covariance (ANCOVA), in which the response (log(brain weight)) is compared between groups after adjusting for an important covariate (log(body weight)).
