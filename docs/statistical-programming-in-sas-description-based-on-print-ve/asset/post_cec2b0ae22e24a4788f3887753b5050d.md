## 4.1 Introducing PROC TABULATE

More powerful than PROC FREQ for summaries...incredibly more convoluted than PROC MEANS...able to present the most complicated table structures...it’s PROC TABULATE. Tables specified with PROC TABULATE have dimensions corresponding to pages, rows, and columns. In a page, row, or column, classification variables can be crossed or nested. And, numeric analysis variables can be summarized with a variety of descriptive statistics. Remember the nitrofen data from the previous chapter? (Nitrofen, a rice herbicide, exhibited reproductive toxicity in an experiment where Ceriodaphnia dubia were exposed to nitrofen.¹ The number of young produced in three broods was recorded.) In the following code, PROC TABULATE is used to produce a descriptive summary of the nitrofen data.

## Display 4.1 PROC TABULATE and nitrofen data

```
%let DATA_DIR=C:\Users\baileraj\BAILERAJ\Classes\Web-Classes\STA402\FALL-2007\data;

data nitrofen;
  infile "&DATA_DIR\ch2-dat.txt" firstobs=16 expandtabs missover pad;
  input @9 animal 2.    @17 conc 3.    @25 brood1 2.
        @33 brood2 2.  @41 brood3 2.  @49 total 2.;
run;

ods rtf BODYTITLE file="&DATA_DIR\Display-4.1.rtf";
proc tabulate data=nitrofen format=3.;  * include default format for;
  class conc;                         *   numeric summaries;
  var brood1 brood2 brood3 total;
  table (brood1 brood2 brood3 total)*conc,
        n min q1 median*f=4.1 q3 max;
run;
ods rtf close;
```

The table in Display 4.2 presents a five-number summary for each brood and the total number of young for each concentration condition.

This table includes the summaries of four different variables on the row dimension (BROOD1, BROOD2, BROOD3, and TOTAL) with the summary of each variable stratified by the value of another variable (CONC). The columns include the sample size and the five-number summary (min, first quartile, median, third quartile, max) associated with the brood, and the TOTAL variable stratified by the nitrofen concentrations. For example, entries in the first row (BROOD1 and CONC=0) correspond to the summary statistics of the number of young produced in the first brood in organisms exposed to control conditions. Here, the median number of young produced in the first brood by the control organisms is 5.5. Let’s explore the statements that generated this table.

```
proc tabulate data=nitrofen format=3.;
  class conc;
  var brood1 brood2 brood3 total;
  table (brood1 brood2 brood3 total)*conc,
        n min q1 median*f=4.1 q3 max;
run;
```

The class conc statement identifies the concentration variable as a categorical variable for the table to be constructed. The var brood1 brood2 brood3 total statement identifies the four variables as numeric variables to be summarized. Here is the general form of the table statement:

```
table page dimension, row dimension, column dimension;
```

Page, row, and column dimensions are separated by commas. Not all page, row, and column dimensions are required. (In the previous code example, only row and column specifications are given.) In the TABLE statement generating this output, the rows are nested between the four numeric variables and the categorical variable CONC. The columns include the sample size and five descriptive statistics (minimum, 25th percentile, median, 75th percentile, and maximum). There is a specification for formatting one of the table entries (median*f=4.1). The other entries (e.g., n, min, q1, q3, and max) are formatted based on the default format set in the proc tabulate data=nitrofen format=3. statement.
