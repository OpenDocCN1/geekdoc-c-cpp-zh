Most, if not all, of the graphics in earlier chapters used the new ODS Statistical Graphics (ODS Graphics). In these graphics, an output destination (e.g., ODS RTF) is specified before the procedure is invoked (e.g., PROC SGPLOT) or before the graphics are requested (e.g., ODS graphics for regression analyses requested by PROC REG). This is not the only way to produce graphics. In fact, you can also produce graphics using traditional SAS graphics, which is discussed in Chapter 7.

# 6.2 ODS Statistical Graphics

The power and utility of ODS was discussed in Chapter 4. Most of the output in this book is based on using the ODS RTF destination to package output from various procedures. ODS RTF invocations should include the FILE= specification to explicitly identify a file for permanently storing output. SAS recommends this in two SAS Notes— http://support.sas.com/kb/32/474.html and http://support.sas.com/kb/35/957.html.

One aspect of ODS that has not been addressed in detail is the special use of ODS Graphics to produce automatically contextually relevant graphs for statistical procedures. Here, contextually relevant means that the statistical graphics associated with regression are not necessarily the same graphics for an ANOVA model or for a survival analysis. In this section, the graphics that can be produced using the ODS GRAPHICS statement and statistical procedures are explored. Essentially, ODS Graphics refers to the new functionality in SAS 9.2 for creating graphics. This functionality is broadly used by numerous statistical procedures in SAS/STAT software, SAS/ETS software, SAS/QC software, and Base SAS software, which automatically produce graphs as part of their output. It is also used by new procedures in SAS/GRAPH software that create stand-alone graphs. All of these products share the general features of ODS Graphics, such as styles for consistency of appearance, image formats, point-and-click editing with the ODS Graphics Editor, and so on.
