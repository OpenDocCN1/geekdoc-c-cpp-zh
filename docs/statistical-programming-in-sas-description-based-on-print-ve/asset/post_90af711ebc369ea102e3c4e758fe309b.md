## 11.9.3 Case Study 3: SAS/IML matrix manipulations and invocations of SAS/STAT procedures

SAS/IML Studio enables you to interact with SAS/STAT. In Display 11.25, a data object containing the SMSA data is created. A subset of the variables is written to the SAS server for use with PROC REG, which then creates a data set with residuals. The residuals are copied back to the SAS/IML Studio client data object, and a scatter plot of Residuals versus the predictor variable Education is produced. A horizontal reference line is added at zero. The submit and endsubmit pair (also known as a submit block) in IMLPlus is required to process SAS/STAT commands on the SAS server.

## Display 11.25 Exporting a data object, fitting a regression, adding residuals, and generating a plot

```
declare DataObject dobj;
dobj=DataObject.CreateFromFile("C:\Users\baileraj.IT\DASL_SMSA.sas7bdat");
DataTable.Create(dobj);

/* follows Ch 4-6 in SAS/IML Studio 3.2 for SAS/Stat Users */
dobj.WriteVarsToServerDataSet({"Education", "Mortality"},
"work", "SMSA", true);

submit;
proc reg data=SMSA;
  model Mortality = Education;
  output out=resout r=residuals;
run;
endsubmit;

ok = CopyServerDataToDataObject( "work", "resout", dobj,
("residuals"),  /* name on SAS server */
{"residuals"},  /* name in DataObject */
("Residuals"),  /* label in DataObject */
true            /* replace if existing variable has this name */
);

declare ScatterPlot resplot;
resplot = ScatterPlot.Create(dobj, "Education", "Residuals");
resplot.DrawUseDataCoordinates();
resplot.DrawLine(0, 0, 1, 0);
```

In Display 11.26, PROC REG output is displayed in SAS/IML Studio. Selecting points with relatively large or small residuals identifies New Orleans as having a mortality rate appreciably higher than what a linear prediction based on education would suggest (i.e., a large positive residual). Lancaster, PA, and York, PA, have mortality rates appreciably lower than what a linear prediction based on education would suggest. Dynamically linking the residual plot with the data table enables you to quickly and easily evaluate

city-specific mortality rates that are underestimated or overestimated by a simple linear regression model.

## 11.9.4 Case Study 4: Generating bootstrap CIs for mean AGE using R

SAS/IML Studio supports the ability to call R functions. This section does not cover all of the nuances of R, much less the data exchange options in SAS/IML Studio. If you are interested in learning more about R, see www.r-project.org.

In this case study, you are working with the AGE variable from the FITNESS data from Chapter 8. In Display 11.27, familiar SAS/IML commands are used to define a matrix. The matrix is transposed before it is exported to R. ExportMatrixToR makes the matrix myAGEmat available for use in R as the data frame age.df. The commands between submit / R and endsubmit contain the R statements to perform the following functions:

- 1. Echo the contents of the matrix exported to R.
- 2. Define a mean function.
- 3. Request the loading of the boot bootstrap package (Canty and Ripley, 2008).
- 4. Set the seed for the random number generator.
- 5. Construct 90% and 95% CIs. Construct percentile and bias-corrected and accelerated bootstrap CIs (Davison and Hinkley, 1997).
- 6. Produce a histogram of the bootstrap means with superimposed 90% interval endpoints.

## Display 11.27 Calling R functions to generate bootstrap CIs for mean AGE

```
* define SAS/IML matrix with AGE data from Chapter 8;
myAGEmat = {
44 40 44 42 38 47 40 43 44 38 44 45 45 47 54 49 51 51 48 49 57 54 52 50
51 54 51 57 49 48 52
};
myAGEmat = t(myAGEmat);
matrib myAGEmat colname={AGE};
print myAGEmat;

* Export matrix to R;
run ExportMatrixToR(myAGEmat, "age.df");

submit / R;
age.df
mymean <- function(x,ii) mean(x[ii])

library(boot)

set.seed(9035768)
myboots.mean <- boot(age.df, mymean, R=4000)
myboots.mean.ci <- boot.ci(myboots.mean, type = c("perc","bca"),
    conf=c(0.90, 0.95))
names(myboots.mean)
names(myboots.mean.ci)
myboots.mean.ci

hist(myboots.mean$t,xlab="Means",
    main="Histogram of means from bootstrap samples")
abline(v=myboots.mean.ci$percent[1,4:5])  # percentile limits
abline(v=myboots.mean.ci$bca[1,4:5],lty=2) # bca limits
endsubmit;
```
