# 7.4 Case Study: Comparing Distributions of Responses

In this section, many of the ideas described previously are applied to graphics to help you understand the differences in the distribution of responses between experimental conditions. You will use the nitrophen data set, which contains nitrophen-concentration-reproductive response data on water fleas Ceriodaphnia dubia-exposed to varying concentrations of nitrophen.² (Hey, you might be sick of these data, but you should now be familiar enough with the data that you can focus on the code!) This data set includes 10 observations at each of the five concentrations. You want to construct graphs to display how the distribution of responses changes across concentration conditions. You want to present the data values and the appropriate summary statistics. In the first figure, you produce a scatter plot of the responses versus the concentration variable with reference segments at the mean responses. In the second figure, you produce a scatter plot with superimposed box plots for the responses at each concentration.

Some of the key actions in the code in Display 7.11 that apply to both of the scatter plots include the following:

+   1. Define a jitter so that all of the observations can be observed.
+   2. Rotate the y-axis label using the AXIS statement.
+   3. Define the label for the x-axis and the range of the values on the x-axis (the LABEL and ORDER parts of the AXIS2 statement).
+   4. Suppress the tick marks and scale values on the x-axis (MINOR=NONE, MAJOR=NONE, and V=NONE in the AXIS2 statement).

In the first scatter plot, an annotate data set is used to label concentration values above the x-axis, and to draw and superimpose segments at the mean response values. In the second scatter plot, SYMBOL1 selects the plotting character for the scatter plot, and SYMBOL2 selects a box plot interpolation and specifies the width of the boxes (bwidth=8). Again, an annotate data set is used to label the concentration values above the x-axis. Because jittering is used to modify values, annotate data sets are used to define the x-axis values in these two scatter plots. Try this at home: Can AXIS statements produce these scatter plots?
