The PLOTS option in the following PROC REG statement requests a panel of DFBETAS plots. The following code selects only DFBETAS for this regression. If only was omitted, then the three default graphics and the DFBETAS plots would be produced.

```
ods rtf bodytitle file="C:\Users\baileraj.IT\Desktop\fig6p1.rtf";
ods graphics on;
proc reg data=cubic plots(only)=DFBETAS;
  model response = x;
run;
ods graphics off;
ods rtf close;
```
