Time needs to be stored as an elapsed number relative to a reference time. In SAS, time is recorded as the number of seconds that have elapsed since midnight. Display 8.14 includes code to define three variables using time and date constants (the t and d in the character expressions define these variables as times and dates). The code displays internal storage values and formatting of values.

# Display 8.14 Time and date formats

```
Data NULL;
 time_date_origin = 0;
 nowtime = '09:00't;
 today = '17jun2008'd;
 put time_date_origin @20 time_date_origin datetime13.;
 put nowtime @20 nowtime time9.;
 put today @20 today date9.;
 run;
```

In Display 8.15, 9:00:00 corresponds to 9*60*60=32400 seconds since midnight. And, 17JUN2008 corresponds to 17700 days since January 1, 1960.
