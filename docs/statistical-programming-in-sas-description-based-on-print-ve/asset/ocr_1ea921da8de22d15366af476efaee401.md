A *template* is a program that contains the instructions for creating a graph. These instructions are written in the Graph Template Language (GTL) and are compiled with PROC TEMPLATE. For more information, see the *SAS/GRAPH: Graph Template Language User’s Guide, Second Edition*, and Kuhfeld (2009). In addition, Kuhfeld (2010) has a more recent book that addresses the richness of GTL and statistical graphics procedures. A description of the extensive changes that can be made to a template is beyond the scope of a statistical programming text. However, this example should give you a taste.

The first step is to locate the template that was used to produce the graph. You can use the ODS TRACE statement as follows:

```
ods rtf bodytitle file="C:\Users\baileraj.IT\Desktop\fig6p2.rtf";
ods trace on;
ods graphics on;
proc reg data=cubic plots(only)=RESIDUALHISTOGRAM;
    model response = x;
run;
ods graphics off;
ods trace off;
ods rtf close;
```

The output of this statement identifies the template for this residual histogram.

```
Output Added:
------------
Name:        ResidualHistogram
Label:       Residual Histogram
Template:    Stat.REG.Graphics.ResidualHistogram
Path:        Reg.MODEL1.ObswiseStats.response.DiagnosticPlots.ResidualHistogram
------------
357 ods graphics off;
358 ods trace off;
359 ods rtf close;
```

This edited portion of the output in the SAS log indicates that **Stat.REG.Graphics.ResidualHistogram** is the template.

The contents of this template can be displayed using the following code:

```
proc template;
    source Stat.REG.Graphics.ResidualHistogram;
run;
```
