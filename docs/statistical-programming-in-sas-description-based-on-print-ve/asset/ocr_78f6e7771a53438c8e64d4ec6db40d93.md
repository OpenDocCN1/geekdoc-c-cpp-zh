# 6.3 Modifying Graphics Using the ODS Graphics Editor

To complete tasks in this section, you should download and install the ODS Graphics Editor. Installation information can be found in the SAS/GRAPH ODS Graphics Editor: User’s Guide. You need to request editable graphs, and then invoke the ODS Graphics Editor. To use the ODS Graphics Editor, the LISTING destination must be active, and you should be in the SAS windowing environment. There are three ways to request editable graphs:

+   1. Submit the following statement:

```
ods listing sge=on;
```

This enables the creation of editable graphs within a session.

+   2. Select the Results window. On the command line, enter:

```
sgedit on
```

+   3. Set a default in the SAS Registry. For more information, see Rodriguez (2009).

Editable graphs can be opened with the ODS Graphics Editor by double-clicking the icon for the editable graph in the Results window. Two icons are displayed for each graph when you request an editable graph. One icon is for the usual (non-editable) graph, and one icon is for the editable graph.

Let’s look at how to modify a graphic. Two main features associated with the ODS Graphics Editor are customizing elements of the graph (such as titles, footnotes, marker shapes, etc.) and annotating the graph. Let’s begin with the plot in Display 6.2B. If you drill down in the Results window, you can double-click the graph to launch the ODS Graphics Editor.
