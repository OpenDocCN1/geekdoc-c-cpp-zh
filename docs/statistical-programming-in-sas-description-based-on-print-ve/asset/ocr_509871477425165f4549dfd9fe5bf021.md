In this section, a short summary of one of the most useful SAS tools—the Output Delivery System (ODS)—for customizing output from procedures is provided. ODS is required for some of the slick statistical graphics procedures (e.g., PROC SGPLOT) or for generating the graphical displays associated with statistical procedures. (For more information, see Chapter 6.)

SAS evolved at a time when line printer plots were cool and dot-matrix printers were simply a glimmer in an engineer’s eye. Many of the options in SAS directly addressed line printer output (e.g., OPTIONS LS=80 restricts the number of printed characters on a line). The need to generate output that could be easily included in documents or displayed on Web pages led to the development of ODS. All of the output produced by PROC TABULATE in the previous section is processed using ODS. SAS online documentation is an excellent resource for learning more about ODS. (For more information, see Base SAS software documentation at http://support.sas.com.)

# 4.4.1 Basic ideas

So, what is ODS? Why should you bother learning more about it? ODS is a system for writing SAS output to alternate destinations. You can direct SAS to present output in formats and destinations such as the following:

+   - document (RTF, which stands for rich text format)
+   - Web page (HTML)
+   - high-resolution format for printing or sharing with others (e.g., PDF)
+   - SAS data set for additional manipulation (OUTPUT destination)

Most SAS procedures produce tables (also known as output objects) that are directed to the destination specified by ODS. For example, a simple invocation of PROC REG produces a set of output objects including an observations object, an ANOVA table object, a fit statistics object, and a parameter estimates object. The parameter estimates object includes estimates of the regression coefficients, standard errors, test statistics, and p-values. Various attributes of the graphical displays of these objects can be specified as styles. An alternate style (JOURNAL) is used in Display 3.27. In Chapter 6, a variety of styles for presenting these same graphical displays is provided. For a more detailed discussion about this topic, see the SAS documentation or other ODS-specific books. For example, see books by Haworth, Zender, and Burlew (2009), Haworth (2001), and Gupta (2003).
