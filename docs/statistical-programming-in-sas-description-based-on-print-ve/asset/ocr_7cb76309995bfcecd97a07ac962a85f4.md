Being multilingual in computer software and data analysis and display applications is useful. There will be times that you want to take data from one system and use it in a different system. This is what happened when Excel data sheets were imported into SAS data sets. Suppose you wanted to create a text file with the contents of a SAS data set, either space delimited or comma separated. You can use PUT statements with FILE specifications to do this. In Display 2.18, three different files are created: a text file with the nitrogen data values separated by spaces, a text file with the nitrogen data values separated by commas, and a text file with the nitrogen data values separated by commas where the first row contains the names of the columns in the file.
