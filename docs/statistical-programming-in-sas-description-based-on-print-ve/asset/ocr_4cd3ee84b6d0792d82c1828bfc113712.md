Additional modifications would make this scatter plot even more publication ready. Because publications often reduce figure sizes, you might want to make the plotted line wider so that it can be reduced successfully. The color (black), type of line (line=1 requests a solid line), and width of line (width=2 requests a thicker line than the default thickness) can be modified by the SYMBOL statement. The following SYMBOL statement was used in the previous code to produce Display 7.5:

```
symbol interpol=join color=black line=1 width=2;
```
