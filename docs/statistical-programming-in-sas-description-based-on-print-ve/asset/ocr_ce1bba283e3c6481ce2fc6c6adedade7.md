Bar charts with limits are often disparagingly described as dynamite plots or dynamite plots with plungers. The dot plot or the scatter plot is arguably preferred for displaying data. (For more information, see the next section.) These plots are emphasized throughout the remainder of this book.

A dot plot of the total number of young produced by each animal and grouped by nitrofen concentration is produced by the DOT statement in the second PROC SGPLOT in Display 3.15. Display 3.17 shows this dot plot. This display clearly demonstrates that the total number of young shifts to lower values as the nitrofen concentration increases.
