## 8.11 Generating Variables Using Random Number Generators

It’s time for a confession. In this book, random number generators were used before they were formally discussed. Arrays were used before they were defined, and other concepts were probably slipped in here and there without appropriate explanation. However, patience will be rewarded. Most of these concepts eventually will be discussed.

The case studies in this chapter include random normal deviates and random uniform deviates that are invoked by RAND ('Normal') or RAND ('Uniform'). These deviates have the equivalent functions RANNOR/NORMAL and RANUNI/UNIFORM, respectively. There are a number of random number functions and routines that take the form RAN####, where #### denotes a distribution such as binomial (BIN), Cauchy (CAU), exponential (EXP), Poisson (POI), and triangular (TRI), to name a few. In addition, a random deviate can be generated from a probability distribution specified as a table (RANTBL).

SAS includes CDF and QUANTILE for obtaining cumulative probabilities and quantiles from specified distributional arguments. You can use an analogous function for random number generation. Here is the syntax of this function:

```
RAND('distribution-name', parameter-list-sep-commas)
```

The parameter list varies with the distribution. The seed for the RAND invocation is set using the STREAMINIT routine. In Display 8.59, a random deviate is generated from a triangular distribution.

Another common (perhaps, painfully common) example used in introductory statistics is rolling two dice. In Display 8.61, the roll of two dice is simulated 6000 times. When the sum of pips on the face of the dice is 7 or greater, the value is recorded. The random die roll is implemented by generating an integer of 1 to 6. Each roll has a probability of 1/6 using RAND('Table',...) with p(1)=p(2)=...=p(5)=1/6 specified. The probability of rolling a 6 is implicit from the specification of the other five probabilities (i.e., p(6)=1-[p(1)+...+p(5)].

# Display 8.61 Simulating rolling a pair of dice

```
data diceroll;    * rolling two six-sided balanced dice;
    call streaminit(34567);
    do inum = 1 to 6000;
        die1 = RAND('Table', 1/6, 1/6, 1/6, 1/6, 1/6);
        die2 = RAND('Table', 1/6, 1/6, 1/6, 1/6, 1/6);
        sum7plus = (die1+die2)>=7;
        output;
    end;
run;

ods rtf bodytitle file="C:\Users\baileraj.IT\Desktop\Display-8-62.rtf";
proc freq data=diceroll;
    table die1 / nocum testf=(1000,1000,1000,1000,1000,1000);
    table sum7plus;
run;
ods rtf close;
```

Display 8.62 contains the relative frequency of each die face and the result of the X² goodness of fit test. These results suggest that the data are consistent with die1 being fair (X²=0.6020, df=5, p-value=0.9879).
