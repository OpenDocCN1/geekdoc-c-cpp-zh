
# Display 7.2 Scatter plot of relative frequency of heads

![](img/26474180ee55914c13fb9156a7678157_254_0.png)

The scatter plot illustrates that the long-term relative frequency of heads when tossing a fair digital coin is 0.5. This scatter plot can be enhanced with a few simple changes. The defaults in this graph include using variable names as the axis labels, using the plus sign as a plotting character, placing tick marks on the x-axis every 100 tosses, and placing tick marks on the y-axis every 0.10. The extremes of the y-axis are defined as 0.3 and 1.0. Simple changes that could enhance the scatter plot include:

- 1. Provide more informative axis labels.
- 2. Rotate the y-axis label so that you have more space for the plotting region.
- 3. Restrict the range of values plotted on the y-axis and x-axis.
- 4. Remove the minor axis tick marks.
- 5. Connect the relative frequencies associated with the different number of tosses.

This section addresses items 1 through 4 using the AXIS statement, and item 5 using the SYMBOL statement.

Many of these simple changes can be implemented with ODS Graphics and PROC SGPLOT. For example, items 1 and 2 can be addressed in the XAXIS and YAXIS statements in PROC SGPLOT using the LABEL option. You can create irregular intervals in PROC SGPLOT and PROC SGPANEL. In PROC GPLOT, to create irregular intervals, you need an annotate data set. (For more information, see page 13 in “Secrets of the SG Procedures,” at http://support.sas.com/resources/papers/proceedings09/324-2009.pdf. The MIN, MAX, VALUES, and VALUESHINT options in the PROC SGPLOT AXIS and SERIES statements might also be useful.)

The AXIS statement enables you to specify tick mark values and labels. It enables you to rotate the axis label and much more. The following statement defines a restricted range for the relative frequencies (MIN=0.35, MAX=0.65), defines the spacing of the values (by 0.05), defines a more expansive label for the axis, and rotates that axis by 90 degrees.

```
axis1 order=0.35 to 0.65 by 0.05
    label=(angle=90 "Estimated Pr(HEADS)");
```

The SYMBOL statement and AXIS statements are placed before the invocation of PROC GPLOT. The PLOT statement associated with PROC GPLOT identifies which axis in the plot (vertical axis=VAXIS or horizontal axis=HAXIS) is associated with each AXIS statement. The SYMBOL statement requests an interpolation between points—here, adjacent relative frequencies are connected with the JOIN option. Other interpolation options include options that are useful for displaying stock market data (HILOC for high-low-close data), for smoothing data (L1P, L3P, L5P, SM, and SPLINE), for displaying polynomial regression fits (RL, RQ, and RC with confidence intervals for mean responses CLM; or with prediction intervals for new responses CLI), for plotting means ±1, 2, or 3 standard deviations (STD), or for displaying step function patterns (STEP).

The revisions to the previous scatter plot with axis, symbol, and label changes are provided in the code in Display 7.3. This code produces the new scatter plot in Display 7.4. This scatter plot is much better than its first incarnation. This is a common experience in producing statistical graphics. You will rarely, if ever, be satisfied with the first graphic that you produce. The norm is to iterate and tune a graphic until you are happy with the results.

## Display 7.3 Toss a digital coin–relative frequency of heads (for a better scatter plot)

```
data cointoss;
    retain num_heads 0;
    call streaminit(1234567);
    do itoss = 1 to 1200;
        outcome = RAND('Bernoulli', 0.50);
        num_heads = num_heads + (outcome=1);
        probability_heads = num_heads / itoss;
        output;
    end;
run;

goptions reset=global;
symbol interpol=join;
axis1 order=0.35 to 0.65 by 0.05
    minor=NONE
    label=(angle=90 "Estimated Pr(HEADS)");
axis2 order=0 to 500 by 50
    minor=NONE
    label=("Number of simulated data points");

ods rtf bodytitle file="C:\Users\baileraj.IT\Desktop\cointoss-figs.rtf";
proc gplot data=cointoss;
    plot probability_heads*itoss / vaxis=axis1 haxis=axis2;
run;
quit;

/* SGPLOT alternatives suggested by Dan Heath  */

proc sgplot data=cointoss;
    xaxis label="Number of simulated data points"
        values=(0 to 500 by 50);
    yaxis label="Estimated Pr(HEADS)"
        values=(0.35 to 0.65 by 0.05);
    series x=itoss y=probability_heads;
run;

proc sgplot data=cointoss;
    xaxis label="Number of simulated data points"
        values=(0 to 500 by 50);
    yaxis label="Estimated Pr(HEADS)"
        values=(0.35 to 0.65 by 0.05);
    series x=itoss y=probability_heads /
        lineattrs=(color=black thickness=2);
run;
ods rtf close;
```

Additional modifications would make this scatter plot even more publication ready. Because publications often reduce figure sizes, you might want to make the plotted line wider so that it can be reduced successfully. The color (black), type of line (line=1 requests a solid line), and width of line (width=2 requests a thicker line than the default thickness) can be modified by the SYMBOL statement. The following SYMBOL statement was used in the previous code to produce Display 7.5:

```
symbol interpol=join color=black line=1 width=2;
```

The SYMBOL statement can explicitly specify what plotting character should be used in a scatter plot. For example, if you want a dot as the plotting character, specify:

```
symbol1 value=dot cv=black;
```

An analogous specification of the marker is in the MARKERCHAR option in PROC SGPLOT or PROC SGPANEL. The MARKERCHAR option references a column, and the value of that column (string or numeric) is used as a marker. You might have noticed the frequent use of GOPTIONS in the previous code.

```
goptions reset=global;
```

Resetting graphics options is a good idea. Once graphics options are set, they stay set until you reset them. As a result, the options set for one plot can unintentionally affect later plots. You might be surprised to know that SAS can cycle through particular options before recognizing other options. If you have graphics code that is not varying a particular SYMBOL option that you have set (e.g., plotting character), but another option is varying (e.g., color), you might try defining the features to be the same in each SYMBOL statement (e.g., set CV=BLACK in each SYMBOL statement).

## 7.3 Why You Need to Learn about Annotate Data Sets

> ...they took twenty seven eight-by-ten color glossy photographs with circles and arrows and a paragraph on the back of each one explaining what each one was to be used as evidence against us.

You might be interested in adding circles, arrows, and text to explain a figure. This is where annotate data sets enter the picture. At this point, you have constructed a figure with modifications to the SYMBOL and AXIS statements. Now, you want to add text, segments, and arrows to your figure. The method is to define a data set (the annotate data set) containing instructions for augmenting the figure. Then, you request the annotation of a traditional SAS graphic by pointing to this data set.

Annotate data sets can be used to enhance graphs produced by procedures that use traditional SAS graphics. These include procedures that are not in SAS/GRAPH software. Annotate data sets consist of observations that each request an action on an existing graph. SAS/GRAPH documentation (2009) describes these as commands to “draw a graphic element or to perform an action.” In particular, you define a FUNCTION variable that has specific values that are associated with an action to the figure. The annotate data set has variables associated with positioning in the figure—X and Y. These variables can possibly be in reference to a system definition—XSYS and YSYS. Annotate data sets are essentially a series of graphics primitives that can be easily applied to an existing graph.

Let’s start with a simple annotation of the coin toss figure in Display 7.4. (The code is in Display 7.3.) Suppose you want to add a horizontal reference line at PROBABILITY=0.5, and text noting that the long-term relative frequency of heads should be 0.5. It helps to break these actions into steps. A horizontal reference line at 0.5 is equivalent to drawing a line from (0, 0.50) to (500, 0.50) on this plot. Or it is equivalent to moving the cursor to the point (0, 0.50), and then drawing a segment to (500, 0.50). Adding text requires positioning text (say, just below the horizontal reference line at (350, 0.48)), and then defining the text to be added. The ANNOTATE functions MOVE, DRAW, and LABEL accomplish this in Display 7.6.
