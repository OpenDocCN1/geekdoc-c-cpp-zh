# 8.8 Case Study 2: Monte Carlo Integration to Estimate an Integral

Another really cool thing to do is estimate integrals using stochastic methods. The area (volume) under a curve (surface) can be estimated from the proportion of points randomly generated in some space that lie beneath the curve (surface) multiplied by the area (volume) of the space. To make this concrete, consider the problem of estimating the area under a standard normal density function between 0 and 1.645. You probably already know the answer—you can read the table. But, let’s see how to implement a stochastic solution. The rough idea of a stochastic solution is described in Display 8.41.

You need to consider the dimensions of the rectangle over which you are generating the data. The interval for the x-axis is easy, it is [0, 1.645]. The interval for the y-axis is not hard to configure, but you need to think a little. The standard normal density takes the following form:

f(x) = 1/√(2π) exp( -1/2 x² )

The maximum of this function occurs at x=0, so the interval for the y-axis should have the following range:

0 to 1/√(2π) = 0.399

So, you generate an (x,y) point in the rectangle with a lower left corner [0, 0] and an upper right corner [1.645, 0.400]. (Yeah, I rounded up.)
