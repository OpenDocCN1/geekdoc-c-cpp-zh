Two required statements for a one-way ANOVA model follow the PROC GLM statement. The CLASS statement identifies the variable containing the levels of the group variable. The GLM MODEL statement is similar to the REG MODEL statement (in particular, the statement is of the form: response variable = predictor variable or group variable).
