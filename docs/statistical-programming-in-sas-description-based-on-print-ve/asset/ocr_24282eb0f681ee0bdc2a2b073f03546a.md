# Display 7.2 Scatter plot of relative frequency of heads

![](bbox=[0.11, 0.19, 0.92, 0.65])

The scatter plot illustrates that the long-term relative frequency of heads when tossing a fair digital coin is 0.5. This scatter plot can be enhanced with a few simple changes. The defaults in this graph include using variable names as the axis labels, using the plus sign as a plotting character, placing tick marks on the x-axis every 100 tosses, and placing tick marks on the y-axis every 0.10. The extremes of the y-axis are defined as 0.3 and 1.0. Simple changes that could enhance the scatter plot include:

+   1. Provide more informative axis labels.
+   2. Rotate the y-axis label so that you have more space for the plotting region.
+   3. Restrict the range of values plotted on the y-axis and x-axis.
+   4. Remove the minor axis tick marks.
+   5. Connect the relative frequencies associated with the different number of tosses.

This section addresses items 1 through 4 using the AXIS statement, and item 5 using the SYMBOL statement.
