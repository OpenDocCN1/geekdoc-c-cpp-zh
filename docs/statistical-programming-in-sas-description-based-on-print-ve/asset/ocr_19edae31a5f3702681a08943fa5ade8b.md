# Display 6.18 Producing separate dot plots of the number of young for each concentration

```
data nitrofen;
    infile 'C:\Users\baileraj.IT\Desktop\ch2-dat.txt' firstobs=16 expandtabs missover pad;
    input @9 animal 2. @17 conc 3. @25 brood1 2. @33 brood2 2. @41 brood3 2. @49 total 2.;
run;

ods rtf bodytitle file="C:\Users\baileraj.IT\Desktop\nitrofen-dotplots.rtf";
proc sgpanel data=nitrofen;
title "dot plots";
panelby conc / layout=panel novarname columns=5;
dot total;
run;

ods rtf close;
```

The SGPANEL procedure includes statements that identify the classification variable for each panel (panelby conc) with five columns specified. Using the LATTICE option in PROC SGPANEL is more relevant if you have two classification variables. With the LATTICE option, the values of the first classification variable define the rows, and the values of the second classification variable define the columns.
