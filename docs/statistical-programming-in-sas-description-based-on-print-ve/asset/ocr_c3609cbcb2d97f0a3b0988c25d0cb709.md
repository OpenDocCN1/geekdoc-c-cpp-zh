# 3.4 Selecting or Stratifying an Analysis by Values of a Variable

The BY statement is used to specify an analysis of a data set stratified by levels of a variable. It is often used with the SORT procedure. For example, the following code sorts the nitrofen data set (nitro_tox) and produces an output data set (nitro_tox2) with the observations sorted:

```
proc sort data=nitro_tox out=nitro_tox2;
    by conc;
run;
proc print data=nitro_tox2;
    by conc;
run;
```

You can sort by more than one variable. For example, suppose you want to sort by total within conc. The following code performs the sort and prints the result in Display 3.11:

```
proc sort data=nitro_tox;
    by conc total;
run;
proc print data=nitro_tox;
    id animal;
    var conc total;
run;
```
