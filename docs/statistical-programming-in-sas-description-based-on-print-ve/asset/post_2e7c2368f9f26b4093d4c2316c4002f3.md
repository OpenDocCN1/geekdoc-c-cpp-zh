
The following example is not a matrix:

B = [ 17  George  11
 15  Jungle  15
 18  June  17 ]

Matrices have properties including dimension. Dimension corresponds to the number of rows and the number of columns. Dimensions can be extracted using the NROW and NCOL functions in SAS/IML. In the previous example of a matrix, A has 3 rows and 3 columns, which means it has the dimension 3×3. An element of a matrix is referenced by its row and column position. For example, 11 is the (1,3) element of A, or A[1,3]=11. A matrix with one dimension equal to 1 is called a vector. Here is a 3×1 matrix, which is called a column vector:

X = [ 17
 15
 18 ]

Here is a 1×3 matrix, which is called a row vector:

Y = [17  15  18]

A 1×1 matrix with Z=[12] is called a scalar. A matrix name in SAS/IML is a valid SAS name. This means that it is 1 to 32 characters in length, can begin with a letter or underscore, and can contain letters, numbers, or underscores. In the next example, matrices are defined in PROC IML and some basic manipulations are performed (e.g., extracting a row or column and summing rows or columns).

In Display 11.1, a 2×3 matrix is defined.

C = [ 1  2  3
 4  5  6 ]

The second row is extracted:

C_r2 = [4 5 6]

The third column is extracted:

C_c3 = [3
6]

The (2,3) element of C is C23=[6]. Matrix C is defined by the first row [1 2 3], followed by the second row [4 5 6], with a comma separating the definition of the rows. The general form of referencing matrices or parts of matrices in SAS/IML is the following:

matrix-name[row, column]

Rows and columns are extracted from a matrix by specifying the row or column of interest, and then leaving the other index blank. For example, C[2,] selects the second row of C. Placing a + in a row or column sums the entries in that row or column, which produces a vector containing the sums. If a matrix has columns that are distinct variables and rows that are observations, then a column’s sum divided by the number of rows produces the arithmetic mean for that column or variable. You can select ranges of rows or columns using a : operator. For example, C[,2:3] selects columns 2 and 3 of matrix C.

Let’s look closely at the statements in Display 11.1. The first statement defines matrix C with 2 rows and 3 columns. The entries of each row are separated by a comma.

```
C = {1 2 3,4 5 6};
```

The second statement defines matrix C_r2 with 1 row and 3 columns containing the second row from matrix C.

```
C_r2 = C[2,];
```

A matrix is referenced by two arguments separated by a comma and within brackets following the matrix name. The first argument represents a row index. The second argument represents a column index. A reference to a matrix with only one index such as C[2,] selects the second row and all columns. To select the third column of a matrix, the following statement is issued:

```
C_c3 = C[,3];
```

You can select ranges of indices using a : operator. For example, the fourth statement selects columns 2 and 3 from matrix C.

```
Col23 = C[,2:3];
```

An element of a matrix can be selected by specifying its row and column indices. For example:

```
C23 = C[2,3];
```

The row 2, column 3 element of matrix C is assigned to C23. The next two statements illustrate that operations can be specified on the row or column dimension of a matrix.

```
C_csum=C[+,];
C_rsum=C[,+];
```

These two statements form a 1×3 matrix C_csum by summing the rows in each column of matrix C. They form a 2×1 matrix C_rsum by summing the columns in each row of matrix C. The final two statements in Display 11.1 scale the row and column sums by the number of columns and rows, respectively. The sums are used to yield row and column means.

```
C_row_mean = C[,+]/ncol(C);
C_col_mean = C[+,]/nrow(C);
```

The + sign sums a particular index. The NCOL and NROW functions extract the number of columns or number of rows in matrix C.

An alternative for yielding row and column means uses a different subscript reduction operator. The + operator is used in the previous mean row and column statements. The : operator takes on a different meaning when used without numbers preceding or following it. In particular, the : subscript reduction operation can be used to find the mean of rows, columns, or matrices using the following statements:

```
C_row_mean2 = C[, :];
C_col_mean = C[:, ];
C_mean = C[:];
```

Other subscript reduction operators can be used to extract the minimum (<), maximum (>), indices of maximum (<:>), indices of minimum (>: <), and sum of squares (##). For example, the sample variance of all of the entries of C can be calculated with the following statements. First, you construct the mean of all entries.

```
cmean = C[:];
```

Then, you subtract this value from all of the entries, calculate the sum of squared differences, and divide by the number of observations, minus one.

```
cdiff = C-cmean;
cvar2 = cdiff[##]/5;
```

Or, you can use a single statement instead of three statements.

```
cvar = (C-C[:])[##]/(nrow(C)*ncol(C)-1);
```

Additional functions for extracting matrix properties or manipulating matrices are introduced in later displays.

The final statement assigns a 3×3 identity matrix to I3.

```
I3 = I(3);
```

This statement produces an identity matrix, which is a diagonal matrix with all diagonal elements equal to 1, and all off-diagonal elements equal to 0, using the I() function in SAS/IML.

As a final observation, in Display 11.1, quit is used to terminate PROC IML. The run command in SAS/IML is associated with executing a module (as you will see in Section 11.8). The IML procedure also ends if a procedure or DATA step is encountered. The use

of a quit to indicate the end of PROC IML is a good habit, analogous to the use of run to indicate the end of a procedure or DATA step.

There are many special types of matrices. For example, a square matrix has the same number of rows and columns. A diagonal matrix is a square matrix with all diagonal elements equal to nonzero, and all off-diagonal elements equal to 0. The identity matrix I3 is an example of a square, diagonal matrix. The SAS/IML function DIAG can be used to construct a diagonal matrix from a vector. The SAS/IML function VECDIAG can be used to extract the diagonal elements from a matrix into a vector. You might want to combine matrices. You might want to stack matrices vertically, producing a matrix with the same number of columns, but with additional rows. (This is like using the SET option with data sets.) You might want to combine matrices horizontally, producing a matrix with the same number of rows, but with additional columns. (This is like using the MERGE option with data sets.) All of these manipulations assume that the matrices conform. For example, you can stack matrices vertically only if they have the same number of columns. The SAS/IML special symbols // and || produce the vertical and horizontal stacking, respectively.
