## Display 6.10 Stat.REG.Graphics.ResidualHistogram template

```
define statgraph Stat.REG.Graphics.ResidualHistogram;
    notes "Residual Histogram";
    dynamic _DEPName _MODELlabel;
    BeginGraph;
        entrytitle halign=left textattrs=GRAPHVALUETEXT _MODELlabel
            halign=center textattrs=GRAPHTITLETEXT
            "Distribution of Residuals" " for " _DEPName;
        layout overlay /
            xaxisopts=(label="Residual")
            yaxisopts=(label="Percent");
            histogram RESIDUAL / primary=true;
            densityplot RESIDUAL / name="Normal" legendlabel="Normal"
                lineattrs=GRAPHFIT;
            densityplot RESIDUAL / kernel () name="Kernel"
                legendlabel="Kernel"
                lineattrs=GRAPHFIT2;
            discretelegend "Normal" "Kernel" / across=1 location=inside
                autoalign=(topright topleft top);
        endlayout;
    EndGraph;
end;
```

The x-axis and y-axis changes involve changing xaxisopts and yaxisopts, which are options of the layout overlay statement. Using this template, modify the xaxisopts label. Add a range of x-axis values (viewmin and viewmax) with three tick values specified (tickvaluelist) and two variables to add some space on each end of the x-axis (offsetmin and offsetmax). After you modify a template, you need to compile it with PROC TEMPLATE as shown in Display 6.11. Then, you can produce the new graph by rerunning your original program. The modified template is saved in Sasuser, and it is accessed each time you run your program. For more information about managing templates, see Chapter 21 of the SAS/STAT User's Guide. This example is simple to describe, but hardcoding the axis tick values is not realistic in practice because tick values are data-dependent in nature. More realistic examples of persistent modifications include changing the title or removing the normal curve. Try this at home: Change the template to remove the normal density curve and update the title.

## 6.5 Statistical Graphics—Entering the Land of SG Procedures

SAS/GRAPH software in SAS 9.2 includes a set of new SG procedures including SGPLOT, SGPANEL, and SGSCATTER. With these new procedures, complex displays can be produced with a small number of statements. SG procedures require that the ODS destination be specified before you invoke the procedure. While you do not need to specify ODS GRAPHICS ON when you use SG procedures, there are options in the ODS GRAPHICS ON statement that do apply to SG procedures. These options are described in Chapter 21 of the SAS/STAT User’s Guide. SAS documentation provides a fundamental reference for using SG procedures. Rodriguez (2009) and Schwartz (2009) provide nice overviews of these procedures and kick-start their use.

The SGPLOT procedure enables you to construct one or more plots displayed on the same axis. As you might have inferred from previous chapters, the SGPLOT procedure is used for graphic displays of univariate and bivariate data. Displays include scatter plots with superimposed smooth fits (e.g., with LOESS), histograms with a superimposed density curve, time series plots, bar charts, box plots, and so on. Display 6.13 provides an analysis related to fitting a linear regression model to predict manatee deaths as a function of motorboats registered in Florida.¹ Display 6.13 uses one PROC SGPLOT invocation to produce a scatter plot of manatee deaths versus number of motorboats registered with superimposed linear regression and LOESS fits. It uses a second PROC SGPLOT invocation to produce a scatter plot of the residuals versus the predictor variable with a superimposed LOESS smooth.
