# 9.4 Case Study 2: Randomization Test for the Equality of Two Populations

Randomization tests (Edgington 1995 and Good 2001) can also be used to obtain p-values. Suppose you want to test for the equality of two normal distributions, assuming each distribution has the same unknown variance. In this case, the pooled variance t-test is commonly used. If you have n1 (n2) observations from the first (second) population, then the test statistic can be written as the following:

t^* = \frac{\bar{Y}_1 - \bar{Y}_2}{s_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}

The pooled variance estimate is denoted as the following:

s_p^2 = \frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}

The test statistic is compared to a t-distribution with n1 + n2 - 2 degrees of freedom.

Randomization tests provide an alternative for obtaining a p-value. If the two distributions are the same, then the label of group membership (i.e., group 1 versus group 2) can be thought of as being randomly assigned to each observation.
