
# Display 6.13 Using PROC SGPLOT to analyze the residuals from fitting linear regression model

```
data manatee_deaths;
    input year nboats manatees @@;
    datalines;
77 447 13  78 460 21   79 481 24   80 498 16
81 513 24  82 512 20   83 526 15   84 559 34
85 585 33  86 614 33   87 645 39   88 675 43
89 711 50  90 719 47
;

ods rtf bodytitle file="C:\Users\baileraj.IT\Desktop\manatee-plots.rtf";
proc reg data=manatee_deaths;
    title '# Manatees killed regressed on the number of boats registered (FL)';
    model manatees = nboats;
    output out=regress r=resid;
run;

proc sgplot data=manatee_deaths;
    title2 "residual plot from the linear model fit";
    regression x=nboats y=manatees;
    loess x=nboats y=manatees;
run;

proc sgplot data=regress;
    title2 "plot residuals vs. predictor variable (loess fit)";
    loess x=nboats y=resid;
run;
ods rtf close;
```

In Display 6.14, the linear regression fit and LOESS fit are very similar. Another key element of PROC SGPLOT is in this display—the statements in PROC SGPLOT each produce a layer that is combined in a single graph.

The SGPANEL procedure can be used to produce a panel of plots where the panel entries are defined by one or more classification variables. This panel includes scatter plots, bar charts, dot plots, box plots, etc. Display 6.16 uses the SGPANEL procedure to produce separate brood-specific scatter plots of young versus concentration with superimposed LOESS smooth.

## Display 6.16 Brood-specific scatter plots of young versus concentration with superimposed LOESS smooth

```
data nitrophen;

title "Brood-specific LOESS fits";
panelby brood;
  loess x=conc y=young;
run;

Using the LATTICE option in PROC SGPANEL is more relevant if you have two classification variables. With the LATTICE option, the values of the first classification variable define the rows, and the values of the second classification variable define the columns.

## 6.6 Case Study: Using the SG Procedures

Because these new SG procedures are sufficiently important to statistical programmers and data analysts, it is a worthwhile practice for you to produce graphs to explore a data set. In this section, you will conduct a quick graphical exploration of a subset of the variables in the SMSA data set from Chapter 2. An extensive code example is shown in Display 6.22 in which formats, labels, and SG procedures are used to examine key features of the data.

## Display 6.22 SMSA data formatted, labeled, and graphically explored

```
options formdlim='~' nodate;

data SMSA_from_txt;  * from Display 2.8;
  infile "C:\Users\balleraj.T\Desktop\SMSA-DASL-2space-sep.txt" firstobs=2;
  length city $ 39;
  input city & JanTemp JulyTemp RelHum Rain Mortality Education PopDensity
        pct_NonWhite pct_WC pop pop_per_house income HCPot NOxRot SO2Pot NOx;
run;

/* extract and save the 5 number summary for Jan. Temps */
proc univariate data=SMSA_from_txt;
  var JanTemp;
  output out=JanSumOut min=Jmin Q1=JQ1 Median=JQ2 Q3=JQ3 max=Jmax;
run;

/* assign the 5 number summaries (min,Q1,M,Q3,max) to macro variables */
/* (see Ch. 10 for more on Macro magic) */
data _null_;
  set JanSumOut;
  call symputx('M_Jmin', Jmin);
  call symputx('M_JQ1', JQ1);
  call symputx('M_JQ2', JQ2);
  call symputx('M_JQ3', JQ3);
  call symputx('M_Jmax', Jmax);
  %put _user_;
run;

/* create informative formats for later displays */
proc format;
  value gt32F 0="below freezing"
              1="above freezing";
  value JTemp 1 = "&M_Jmin <= Jan. Temp. (F) <= &M_JQ1"
              2 = "&M_JQ1 < Jan. Temp. (F) <= &M_JQ2"
              3 = "&M_JQ2 < Jan. Temp. (F) <= &M_JQ3"
              4 = "&M_JQ3 < Jan. Temp. (F) <= &M_Jmax";
run;

/* define and add a variable indicating Jan. temps > 32 deg F and a variable */
/* containing the Jan. temp quartile category */
data SMSA_from_txt;
  set SMSA_from_txt;

  freezing = (JanTemp>32);
  label freezing="Temp. in January";
  format freezing gt32F.;
```
