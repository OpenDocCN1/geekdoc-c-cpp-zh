The data set myanno contains the commands for displaying the annotation. The length declaration of 8 ensures that the function label will not be truncated to four characters because the first value of function is the four-character value move, while the declaration of the text length allows for a longer text string to be displayed. (A length of 8 accommodates any of the possible function arguments.) The retain statement does double-duty. It keeps the values of xsys and ysys in place for all of the observations that are defined in subsequent lines. And, it assigns the value 2 to these variables. The xsys and ysys variables define the coordinate axis definition that is used by coordinate (x,y) pairs in the annotate data set. A value of 2 is an absolute scale that corresponds to the data value scale. The XSYS and YSYS values 1 through 6 correspond to an absolute scale, while {7, 8, 9, A, B, C} correspond to a relative scale. You might find 2 to be the most useful value for the annotation of statistical figures or for the annotation of scales related to the percentage of the data area (1, 7) or to the percentage of the graphics output area (3, 9). The first observation moves the cursor to the (0, 0.50) position:

```
function="move"; x=0; y=0.50; output;
```

The second observation draws from the current location (0, 0.50) to the target location (500, 0.50):

```
function="draw"; x=500; y=0.50; output;
```

The third observation adds text centered at (350, 0.48):

```
function="label"; x=350; y=0.48;
    text="Long-term relative frequency of HEADS=0.50"; output;
```
