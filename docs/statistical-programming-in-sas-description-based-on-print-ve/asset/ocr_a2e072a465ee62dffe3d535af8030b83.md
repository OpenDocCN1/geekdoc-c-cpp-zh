# Display 6.5 DFBETAS plots for the intercept and slope

![](bbox=[0.04, 0.2, 0.94, 0.62])

Two separate graphs with DFBETAS are produced if the plots are unpacked:

```
ods rtf bodytitle file="C:\Users\baileraj.IT\Desktop\fig6p1.rtf";
ods graphics on;
proc reg data=cubic plots(only)=DFBETAS(unpack);
  model response = x;
run;
ods graphics off;
ods rtf close;
```

You can specify the name of an ODS graph in ODS SELECT and ODS EXCLUDE statements. (See Display 6.4.) Use the PLOTS= option to determine which plots you want to create. Use the ODS SELECT and ODS EXCLUDE statements to control which plots go to your ODS destination. The ODS SELECT and ODS EXCLUDE statements can be used to select output tables and graphics.
