Let’s look at numeric summaries of January temperature data from the SMSA² city data using PROC UNIVARIATE. (For more background, see Section 2.2.) Display 3.29 includes the request for univariate statistics for the JANTEMP variable and for the identification of cities associated with extreme low or high temperatures. (This is a great way to check for outliers in a data set.)

# Display 3.29 Request for univariate statistics describing the distribution of January temperatures in the SMSA data set

```
options nodate nocenter nonumber;
%let DATA_DIR = C:\Users\baileraj.IT\Desktop;
data SMSA_from_txt;
  infile "C:\Users\baileraj.IT\Desktop\SMSA-DASL-2space-sep.txt"
  firstobs=2;
  length city $ 39;
  input city & JanTemp JulyTemp RelHum Rain Mortality Education PopDensity pct_NonWhite pct_WC pop pop_per_house income HCPot NOxPot SO2Pot NOx;
run;
ods rtf bodytitle file="&DATA_DIR\Display-3.29.rtf";
proc univariate data=SMSA_from_txt;
  var JanTemp;
  id city;
run;
ods rtf close;
```

The output in Display 3.30 gives information about the number of observations, central values, and dispersion measures. It includes a statistical test of whether the mean temperature is zero. It shows quantiles of the January temperature data and extreme observations (five lowest January temperatures and five highest January temperatures).
