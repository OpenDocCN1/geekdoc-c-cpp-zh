You can restrict output using the WHERE statement. For example, suppose you want to print only observations in which the total young in all three broods is less than 10. The following partial code generates the output in Display 3.12:

```
proc sort data=nitro_tox;
  by conc total;
run;

proc print data=nitro_tox;
  id animal;
  var conc total brood1 brood2 brood3;
  where total<10;
run;
```
