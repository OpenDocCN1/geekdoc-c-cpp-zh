There are a variety of buttons around the plot. For example, the ellipse button enables you to add, position, rotate, and reshape an ellipse on a figure. The arrow button enables you to add an arrow with a text label at its end. Double-clicking the plotting symbols, axis labels, and titles enables you to change them. Changes made with the ODS Graphics Editor are not reflected in the SAS code. Therefore, you should use the ODS Graphics Editor for one-time changes to a graph.

In Display 6.6, the original plot is shown in the top left. With the ODS Graphics Editor, ellipses are added and rotated (top right and bottom left). An axis label is changed (top right), and plotting symbols are changed (top right). A reference line is widened (top right). Text and arrows are added (bottom left), and a title and final text arrows are added (bottom right).
