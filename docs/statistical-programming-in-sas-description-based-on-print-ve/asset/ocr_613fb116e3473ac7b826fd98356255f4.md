# 4.4.3 What's produced and how to select it

There are going to be times when you want to grab only part of the results produced by a procedure. In this section, you learn how to determine what output objects are produced by a procedure, and how to select particular tables or output objects. In the following example, a data set with 20 observations is generated, with two observations at values of X=1, 2, ..., 10, where Y = 3 + 1.5 X + 2*ε, where ε ~ N(0,1). The pseudorandom normal deviate generator RAND is used with a seed specified using call streaminit (54321). (The specification of the seed enables you to run the same code and replicate the results. If SEED=0 was used, then a seed based on time since midnight would be the result, and each run of the code would generate a different set of data.)

```
call streaminit (54321)
```
