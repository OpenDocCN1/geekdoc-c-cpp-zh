## 4.4 Using the Output Delivery System

In the previous examples, PROC TABULATE invocations are bracketed by the commands ODS RTF BODYTITLE and ODS RTF CLOSE. (Actually, if you have been paying attention, then you have seen this convention used with regularity.) The BODYTITLE option is useful if TITLE or FOOTNOTE is specified because the default ODS RTF behavior is to put titles and footnotes in the header and footer parts of a document. In this book, the Output Delivery System (ODS) is frequently used to produce attractive displays of the output from procedures. And, in a more specialized example in this book, ODS is used to produce a comma-separated values data file containing the observations in a SAS data set. (See Display 2.20.)

In this section, a short summary of one of the most useful SAS tools—the Output Delivery System (ODS)—for customizing output from procedures is provided. ODS is required for some of the slick statistical graphics procedures (e.g., PROC SGPLOT) or for generating the graphical displays associated with statistical procedures. (For more information, see Chapter 6.)

SAS evolved at a time when line printer plots were cool and dot-matrix printers were simply a glimmer in an engineer’s eye. Many of the options in SAS directly addressed line printer output (e.g., OPTIONS LS=80 restricts the number of printed characters on a line). The need to generate output that could be easily included in documents or displayed on Web pages led to the development of ODS. All of the output produced by PROC TABULATE in the previous section is processed using ODS. SAS online documentation is an excellent resource for learning more about ODS. (For more information, see Base SAS software documentation at http://support.sas.com.)

### 4.4.1 Basic ideas

So, what is ODS? Why should you bother learning more about it? ODS is a system for writing SAS output to alternate destinations. You can direct SAS to present output in formats and destinations such as the following:

- document (RTF, which stands for rich text format)
- Web page (HTML)
- high-resolution format for printing or sharing with others (e.g., PDF)
- SAS data set for additional manipulation (OUTPUT destination)

Most SAS procedures produce tables (also known as output objects) that are directed to the destination specified by ODS. For example, a simple invocation of PROC REG produces a set of output objects including an observations object, an ANOVA table object, a fit statistics object, and a parameter estimates object. The parameter estimates object includes estimates of the regression coefficients, standard errors, test statistics, and p-values. Various attributes of the graphical displays of these objects can be specified as styles. An alternate style (JOURNAL) is used in Display 3.27. In Chapter 6, a variety of styles for presenting these same graphical displays is provided. For a more detailed discussion about this topic, see the SAS documentation or other ODS-specific books. For example, see books by Haworth, Zender, and Burlew (2009), Haworth (2001), and Gupta (2003).

### 4.4.2 Destinations—RTF, HTML, PDF, and more!

The ODS destination that I use most frequently is RTF, both in this book and in everyday analyses using SAS. The RTF destination produces a series of tables that can be easily imported into your favorite word processor. The ODS RTF statement specifies the RTF destination. Including the FILE= specification with the ODS RTF statement is good programming practice even though the statement might work just fine on some systems if this specification is omitted. If you are keen on writing documents using TeX, you might prefer to generate output objects that are in LaTeX, PostScript, or PDF, which would entail the use of the ODS LATEX, ODS PS, or ODS PDF statement. Generating HTML files for displaying output objects might be of interest to you if you want a Web-based outlet for displaying results. PDF files are also great for the Web. The following program produces three different versions of the same PROC TABULATE table using RTF, PDF, and HTML destinations, respectively.

## Display 4.9 Illustrating three different ODS destinations with the country data set

```
/* using the COUNTRY data set constructed in DISPLAY 4.6 */

/* set up formats for the density categories */
proc format;
    value dfmt 1="Least Dense 25%"
                2="Middle 50%"
                3="Most Dense 25%";
run;

options nodate nonumber;
%let outdir = C:\Users\baileraj\Desktop;
ODS RTF file="&outdir\tab.rtf";
ODS PDF file="&outdir\tab.pdf";
ODS HTML file="tab.html" path="&outdir";

proc tabulate data=country format=4.1;
    class density_cat;
    var lifemen lifewom liter loggnp;
    format density_cat dfmt.;
    table (lifemen="Life Expectancy (Men)"
           lifewom="Life Expectancy (Women)"
           liter="% Literate" loggnp="Log10 GNP")*
          (n="# countries"*f=2. mean="Mean"
           median="Median" stddev="Std. Dev."),
          density_cat="Population Density";
run;

ODS RTF CLOSE;
ODS PDF CLOSE;
ODS HTML CLOSE;
```
