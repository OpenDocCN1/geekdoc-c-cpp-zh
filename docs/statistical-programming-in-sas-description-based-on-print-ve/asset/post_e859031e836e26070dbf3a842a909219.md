Four output objects are produced—NObs, ANOVA, FitStatistics, and ParameterEstimates. You can select a particular output object (say, ParameterEstimates) from PROC REG using the ODS SELECT statement.

```
ods select ParameterEstimates;
ods rtf bodytitle file="reg-est.rtf";
proc reg;
  model y = x;
run;
ods rtf close;
```

The output is shown in Display 4.20.

# 4.4.4 Another destination that stat programmers should visit—OUTPUT

The OUTPUT destination enables you to construct SAS data sets based on output objects from a SAS procedure. The following program generates a set of simulated linear regression data, extracts the intercept and slope estimates, generates summary statistics of these estimates, and produces a scatter plot of the estimates.

# Display 4.21 Generating a set of regression data, fitting the model, and extracting and plotting coefficients

```
data simreg;
    beta0 = 3;  * Simulate Y ~ N(3 + 1.5 X, sigma = 2);
    beta1 = 1.5;
    sigma = 2;
    call streaminit(54321);
    do iexpt = 1 to 2000;  * generate 2000 samples/experiments with 20 (x,y) observations;
        do nobs = 1 to 2;  * with 2 replicates at x=1 to 10 by 1;
            do x = 1 to 10;
                y = beta0 + beta1*x + sigma* RAND('Normal');
                output;
            end;
        end;
    end;
run;

proc print data=simreg;
title "first 2 experiments from the SIMREG data set";
    where iexpt<=2;
run;

ods output ParameterEstimates=ParmEst;
proc sort data=simreg;
    by iexpt;
run;
proc reg data=simreg;
    by iexpt;
    model y = x;
run;
ods output close;

proc print data=ParmEst;
title "first 2 experiments from the PARMEST data set";
    where iexpt<=2;
    var iexpt Variable Estimate;
run;
```

Let’s look at the code and some of the intermediate steps in this analysis. First, glance at the SAS log:

```
NOTE: The data set WORK.SIMREG has 40000 observations and 7 variables.
NOTE: DATA statement used (Total process time):
  real time          0.20 seconds
  cpu time           0.04 seconds
```

Two thousand sets of 20 (X,Y) observations are generated, so the resulting data set SIMREG should contain 40000 observations. In addition, BETA0, BETA1, SIGMA, IEXPT, and NOBS are included in each simulated data set with the X and Y variable of primary interest. A significantly smaller data set is produced if a KEEP or DROP statement is added to eliminate all variables except for the X and Y variables.

Print the first 20 observations and two simulated samples from SIMREG to examine whether the structure matches what you expect. The following code generates output that

confirms that two observations at each of the 10 values of predictor variable X are produced:

```
proc print data=simreg;
title " first 2 experiments from the SIMREG data set";
where iexpt<=2;
run;
```

The ODS OUTPUT selection extracts parameter estimates from the fitting of the 2000 regression data sets using PROC REG. The fits from the first two simulated samples that are output to the PARMEST data set are displayed using the following code:

```
proc print data=ParmEst;
title "first 2 experiments from the PARMEST data set";
where iexpt<=2;
var iexpt Variable Estimate;
run;
```

This code produces the following output:

Each simulated sample leads to a model fit based on the two lines of the PARMEST data set that show the estimate associated with VARIABLE='INTERCEPT' as b0, and the estimate associated with VARIABLE=X as b1. This SAS log reports that 4000 lines of output are associated with the 2000 model fits.

```
NOTE: The data set WORK.PARMEST has 4000 observations and 9 variables.
```

DATA step programming is needed to extract the intercept estimate from one line and pair it with the slope estimate from the next line for each model fit. This is accomplished using the following code:

```
data ParmEst2; set ParmEst;
retain b0;
if variable="Intercept" then b0 = estimate;
else do;
b1 = estimate;
keep iexpt b0 b1;
output;
end;
run;
```

The 4000 lines of PARMEST are processed in groups of two lines. The first line corresponds to the intercept based on the IF check (if variable="Intercept" then b0 = estimate;). This estimate is not immediately written to the data set because the b0 and b1 estimates need to be paired. The RETAIN statement holds the value of the intercept while the next line is processed. (For more information about the RETAIN statement, see Chapter 9.) The first five lines and last five lines of the data set produced are output by the following code:

```
proc print data=ParmEst2;  * a nice debugging check;
    title "first 5/last 5 lines from the PARMEST2 data set";
    where iexpt <= 5 or iexpt > 1995;
run;
```

The output matches the data structure that is needed for later analysis.

At this point, you can feel confident that the code is correct, and you can now focus on the analysis of primary interest—exploring the sampling distribution of the intercept and slope estimates from simple linear regression. The sampling distribution of the intercept and slope estimates is centered at the values of the underlying parameters that were set as part of generating the regression data. (See Display 4.22.) This is not a surprise because you know that these estimates are unbiased. By the way, what do you see when you compare the observed standard deviation of b1 over the 2000 simulated data sets to the value of s(b1)? Is it what you expected?
