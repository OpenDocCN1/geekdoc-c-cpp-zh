# **** Comment 1

The contents of the original data set test are copied into a new data set test2 by the variable id. This creates two internal variables FIRST.id and LAST.id. FIRST.ID=1 if the record corresponds to the first record for a particular ID. FIRST.ID=0 for all other records. LAST.ID=1 if the record corresponds to the last record for a particular ID. LAST.ID=0 for all other records. For the first individual (id=1). FIRST.ID=1 and LAST.ID=1 because there is only one record for this individual. For the third individual (id=3). FIRST.ID=1 and LAST.ID=0 for the data line 3 6 12. FIRST.ID=0 and LAST.ID=0 for the data line 3 14 15. and FIRST.ID=0 and LAST.ID=1 for the data line 3 17 23.

# **** Comment 2

The two lines starting with retain define the counter for the number of enrollments for an individual, and for the array elements for enrollment (start), disenrollment (stop), and time spent in an enrollment (times). The RETAIN statement ensures that these values do not get reset to missing while data lines for the same individual are being processed. The arrays are set up to have at most nine separate enrollment times.

# **** Comment 3

When it is the first record for an individual, the counter and the array elements are initialized. The array elements are initially set to missing because most individuals are expected to have fewer than the maximum.
