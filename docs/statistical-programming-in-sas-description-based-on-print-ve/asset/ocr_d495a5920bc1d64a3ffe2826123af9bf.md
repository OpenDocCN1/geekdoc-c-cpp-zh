# 10.10 Summary

To repeatedly use code, you should generalize it. Macro programming is a natural way to generalize code. This chapter starts with a trapezoidal rule example that is generalized by replacing hardcoded values with macro variables. The code is then nested in a macro so that it can be easily invoked. Parameters are passed to the macro. Looping and conditionally executing code as a result of these parameters are discussed. Macro functions are introduced and illustrated. The chapter closes with a final example illustrating the automatic processing of a large number of data sets and showcasing functions.
