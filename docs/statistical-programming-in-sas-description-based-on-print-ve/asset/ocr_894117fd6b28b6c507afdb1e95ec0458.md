# Display 6.12 Residual histogram based on the modified template

![](bbox=[0.1, 0.16, 0.9, 0.65])

This modified template is applied until it is altered. To restore the template to its original settings, delete the template with PROC TEMPLATE.

```
proc template;
    delete Stat.REG.Graphics.ResidualHistogram;
run;
```
