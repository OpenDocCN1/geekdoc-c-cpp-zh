The PUT statement can be used to create simple customized reports. In the program in Display 2.16, the nitrofen data are read from an external source and written to a text file with an annotation. The nitrofen data are first sorted by concentration, and then added to the `_NULL_` data set by concentration. From the previous example, `BY CONC` creates internal SAS variables `FIRST.CONC` and `LAST.CONC`, which are true when an observation is the first or last observation, respectively, within a group. Thus, the statements in the `DO-END` block are executed when `FIRST.CONC` is TRUE:

```sas
put 6*'+-----' '+';
put 'Conc = ' conc /
    @1 'Brood 1'  @10 'Brood 2'  @20 'Brood 3' @30 'TOTAL' /
    @1 '-------'  @10 '-------'  @20 '-------' @30 '-------';
```

In the program, the condition is true if the observation being processed corresponds to the first animal in a concentration group. In this case, a divider of the form +-----+-----+-----+... +-----+ is written, along with variable labels and underlines for the labels. Where values are written is controlled by the `@n` specification, which moves the output pointer to the nth column before writing. The values of the variables are written following the specified format:

```sas
put @5 brood1 3. @14 brood2 3. @24 brood3 3. @32 total 3.;
```

The value of `BROOD1` is written starting at column 5 with a fixed formatted width of 3 columns. Other output locations and formats are similarly specified. A second `DATA _NULL_` block is specified to write a note at the bottom of the file. The `FILE` specification in this block includes the `MOD` option, which declares that any `PUT` activity will be appended to the end of the text file. If the `MOD` option had been omitted, then the entire text file would have been overwritten with the last line.

## Display 2.16 Producing a formatted report with an annotated printout of the nitrofen data

```sas
libname myfiles "C:\Users\baileraj.IT\BAILERAJ\Classes\Web-CLASSES\sta402\data";

proc sort data=myfiles.nitrofen;
    by conc;
run;

data _NULL_;
    set myfiles.nitrofen;
    by conc;
    file 'C:\Users\baileraj.IT\Desktop\nitrofen-put.txt';

    /* Write out header text information for the first observation in each conc */
    if FIRST.conc then do;
        put 6*'+-----' '+';
        put 'Conc = ' conc
            @1 'Brood 1' @10 'Brood 2' @20 'Brood 3' @30 'TOTAL'
            @1 '-------' @10 '-------' @20 '-------' @30 '-------';
    end;

    /* Write out the data for all records */
    put @5 brood1 3. @14 brood2 3. @24 brood3 3. @32 total 3.;
run;

data _NULL_;       /* add last line to the output file */
    file 'C:\Users\baileraj.IT\Desktop\nitrofen-put.txt' MOD;
    put 6*'+-----' '+' /
        'Data from C. dubia Nitrofen exposure data [Bailer & Oris 1993]';
run;
```

Being multilingual in computer software and data analysis and display applications is useful. There will be times that you want to take data from one system and use it in a different system. This is what happened when Excel data sheets were imported into SAS data sets. Suppose you wanted to create a text file with the contents of a SAS data set, either space delimited or comma separated. You can use `PUT` statements with `FILE` specifications to do this. In Display 2.18, three different files are created: a text file with the nitrofen data values separated by spaces, a text file with the nitrofen data values separated by commas, and a text file with the nitrofen data values separated by commas where the first row contains the names of the columns in the file.

## Display 2.18 Creating external data files containing the contents of a SAS data set

```sas
libname myfiles "C:\Users\baileraj.IT\BAILERAJ\Classes\Web-CLASSES\sta402\data";

/* create a TEXT file with the nitrofen data */
data _NULL_; set myfiles.nitrofen;
    file 'C:\Users\baileraj.IT\Desktop\nitrofen-TEXT.txt';
    put @1 conc @10 animal @15 brood1 @20 brood2 @25 brood3 @30 total;
run;

/* create a CSV file with the nitrofen data */
data _NULL_; set myfiles.nitrofen;
    file 'C:\Users\baileraj.IT\Desktop\nitrofen-CSV.csv' dsd;
    put conc animal brood1 brood2 brood3 total;
run;

/* create a CSV file with the nitrofen data and a row with variable names */
data _NULL_; * write variable names to first line of file;
    file 'C:\Users\baileraj.IT\Desktop\nitrofen-CSV2.csv' dsd;
    put "conc,animal,brood1,brood2,brood3,total";
run;

data _NULL_; set myfiles.nitrofen; * add data values below var names;
    file 'C:\Users\baileraj.IT\Desktop\nitrofen-CSV2.csv' dsd MOD;
    put conc animal brood1 brood2 brood3 total;
run;
```

## Display 2.20 Alternatives for producing *.csv data files containing SAS data sets

```sas
libname myfiles "C:\Users\baileraj.IT\BAILERAJ\Classes\Web-CLASSES\sta402\data";

/*
  nitrofen = SAS data set in this library
*/

proc contents data=myfiles.nitrofen;

/* Using ODS with CSV + PROC PRINT to produce *.csv file
   Thanks to Kathy Roggenkamp for suggesting this alternative!
*/
ods csv file="C:\Users\baileraj.IT\Desktop\nitrofen.csv";
proc print data=myfiles.nitrofen;
  var conc total;
  id animal;
run;
ods csv close;

/*
  Using File > Export Data ... can be used to construct a
  *.csv file AND save the associated SAS PROC EXPORT code
  (see below)
*/
PROC EXPORT DATA= MYFILES.NITROFEN
  OUTFILE= "C:\Users\baileraj.IT\Desktop\nitrofen2.csv"
  DBMS=CSV REPLACE;
  PUTNAMES=YES;
RUN;
```
