Numeric variables are read using informats and are displayed using formats. The specification of numeric informats and formats involves stating the name of the format, the width of the display, and the number of decimals to the right of the decimal point. For example, here is a specification:

```
format-namew.d
```

w is the total width including the decimal point and the number of decimals to the right of the decimal point). d is the number of decimals to the right of the decimal point.

SAS uses an arguably best format when the BESTw. format is specified. Other numeric formats include Ew. for scientific notation, COMMAw.d for comma-separated values after each consecutive set of three digits, DOLLARw.d for currency (to add a $ to the left of a numeric value), and w.d for the most common and default numeric format. Display 8.3 contains a simple program exploring some of these numeric formats.

# # Display 8.3 DATA step displaying numeric formats

```
```sas
data numeric_format_show;
/* character formatting illustrated first */
test_num = 1277695.384;
put 'BEST6. / BEST9. / BEST12.' ;
put test_num BEST6.;
put test_num BEST9.;
put test_num BEST12.;
put '-------------------------------';
put 'COMMA7. / COMMA10.1 / COMMA11.3';
put test_num COMMA7.;
put test_num COMMA10.1;
put test_num COMMA11.3;
put '-------------------------------';
put 'E7.';
put test_num E7.;
put '-------- -- -- --------';
put '7. / 10.1 / 11.3';
put test_num 7.;
put test_num 10.1;
put test_num 11.3;
put '-------------------------------';
put 'DOLLAR9. / DOLLAR12.2';
put test_num DOLLAR9.;
put test_num DOLLAR12.2;
run;
```
```

The output in Display 8.4 is right on target. A number such as 1277695.384 needs w=11 and d=3 to fully display. If w=11 is specified, then rounding the value is necessary. It is interesting that the BEST format displays in scientific notation when w=6.
