# 7.3 Why You Need to Learn about Annotate Data Sets

> ...they took twenty seven eight-by-ten color glossy photographs with circles and arrows and a paragraph on the back of each one explaining what each one was to be used as evidence against us.

You might be interested in adding circles, arrows, and text to explain a figure. This is where annotate data sets enter the picture. At this point, you have constructed a figure with modifications to the SYMBOL and AXIS statements. Now, you want to add text, segments, and arrows to your figure. The method is to define a data set (the annotate data set) containing instructions for augmenting the figure. Then, you request the annotation of a traditional SAS graphic by pointing to this data set.

Annotate data sets can be used to enhance graphs produced by procedures that use traditional SAS graphics. These include procedures that are not in SAS/GRAPH software. Annotate data sets consist of observations that each request an action on an existing graph. SAS/GRAPH documentation (2009) describes these as commands to “draw a graphic element or to perform an action.” In particular, you define a FUNCTION variable that has specific values that are associated with an action to the figure. The annotate data set has variables associated with positioning in the figure—X and Y. These variables can possibly be in reference to a system definition—XSYS and YSYS. Annotate data sets are essentially a series of graphics primitives that can be easily applied to an existing graph.

Let’s start with a simple annotation of the coin toss figure in Display 7.4. (The code is in Display 7.3.) Suppose you want to add a horizontal reference line at PROBABILITY=0.5, and text noting that the long-term relative frequency of heads should be 0.5. It helps to break these actions into steps. A horizontal reference line at 0.5 is equivalent to drawing a line from (0, 0.50) to (500, 0.50) on this plot. Or it is equivalent to moving the cursor to the point (0, 0.50), and then drawing a segment to (500, 0.50). Adding text requires positioning text (say, just below the horizontal reference line at (350, 0.48)), and then defining the text to be added. The ANNOTATE functions MOVE, DRAW, and LABEL accomplish this in Display 7.6.
