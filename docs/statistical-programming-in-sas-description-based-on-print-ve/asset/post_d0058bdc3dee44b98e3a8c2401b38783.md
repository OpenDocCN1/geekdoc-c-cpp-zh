This draft has captured the essence of the table. However, all concentration groups are pooled in this display and the number of decimal places is unnecessary. In the next iteration of code, stratify the analysis for each concentration group. Identify the concentration with a CLASS statement, and then construct a separate table for each concentration by specifying CONC as the page specification or first argument in the TABLE statement:

```
proc tabulate data=nitrofen;
  class conc;
  var brood1 brood2 brood3 total;
  table conc, brood1 brood2 brood3 total, n min q1 median q3 max;
run;
```

This code produces five tables, one for each concentration group as shown in Display 4.5.

The following code moves the classification variable CONC into the row dimension (nesting it (brood1 brood2 brood3 total)*conc with the four analysis variables so that the four variables are summarized separately for each concentration). The table entries are formatted as well.

```
proc tabulate data=nitrofen format=3.;
class conc;
var brood1 brood2 brood3 total;
table (brood1 brood2 brood3 total)*conc,
n min q1 median*f=4.1 q3 max;
run;
```

## 4.3 Enhancing PROC TABULATE Output

At this point, you have probably had enough of the nitrophen data set. The life expectancy data for different countries is used for the next example. A table of sample sizes, means, and standard deviations for the life expectancy of men and women is requested. In addition, the literacy percentage and LOG10(GNP) are requested. The data represents countries that are sparsely populated (in the first quartile of population density), moderately populated (in the middle 50% of population density), and densely populated (in the top 25% of population density). This program is shown in Display 4.6.

## Display 4.6 Constructing numeric statistical summaries of life expectancy, GNP, and literacy percentage separately for the different quartiles of population density

```
%let topdir = C:\Users\baileraj.IT\BAILERAJ;      * go ahead and check out;
%let subdir = Classes\Web-Classes\sta402\data\;  * macro variables in Ch 10;
data country;
title 'country data analysis';
infile "&topdir.&subdir.country.data";
input name $ area popnsize pcturban lang $ liter lifemen
      lifewom pcGNP;
logarca = log10(area);
logpopn = log10(popnsize);
loggnp  = log10(pcGNP);
density = popnsize/area;      * construct density variable;
ienglish = (lang="English");
drop area popnsize pcGNP;
run;

proc univariate data=country;  * calculate %tiles of density;
var density;
id name;
output out=cstats Q1=P_25 Q3=P_75;  * output to data set - cstats;
* output out=cstats2 pctlpts=25 75 pctlpre=P ;  * equivalent;
run;

proc print data=cstats;  * check of summary stat data;
run;
/* the CSTATS data set . . .
Obs      P_75      P_25
1   0.40881   0.046858
*/

data country;      * adding Q1 and Q3 to each line of the country data set;
retain P_25 P_75;      * keep values of Q1 and Q3 around to be assigned;
if _n =1 then set cstats;  * read and process CSTATS data set first;
  set cstats;
  set country;
run;

* you need to be somewhat careful in defining categories if any missing;
*   values are present (see Section 8.3) - not a problem in this example;
data country; set country;    * define density categorical var;
if density <= P_25 then density_cat=1;      * [min, Q1];
else if density <= P_75 then density_cat=2;      * [Q1, Q3];
else density_cat=3;                         * (Q3, max];
run;
* aside: could hard code Q1/Q3 but the solution above is a bit slicker and
        avoids the possibility of transcription error, is robust to
        underlying data changes when program is rerun;

proc freq data=country;  * check construction of density category variable;
table density_cat;
run;

* additional check suggested by Kathy Roggenkamp;
proc means data=country n nmiss min max;
class density_cat / missing;
var density;
run;

ods rtf BODYTITLE file="&topdir\Display-4.6.rtf";
proc tabulate data=country;
class density_cat;
var lifemen lifewom liter loggnp;
table (lifemen lifewom liter loggnp)*(n nmiss mean median stddev), density_cat;
run;
ods rtf close;
```

The program first reads the country data set, and then defines additional variables including LOGGNP and population density. The quartiles of DENSITY are determined using PROC UNIVARIATE, and then a categorical variable is created that indicates whether a country falls in the lowest 25%, middle 50%, or upper 25% of population density in this collection of countries. The assignment of these categories is checked using PROC FREQ. (Here, one fourth of the countries should be in the first category, and one fourth should be in the third category. One half should be in the middle category). A (not very attractive) table is produced and shown in Display 4.7.
