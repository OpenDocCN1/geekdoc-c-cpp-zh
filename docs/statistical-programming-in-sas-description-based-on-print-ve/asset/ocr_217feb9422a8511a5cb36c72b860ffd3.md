When both the intercept and slope are positive, a negative correlation exists between the intercept and slope estimates in simple linear regression. (This is a nice opportunity to dig out the old regression book and confirm.)

# 4.5 Summary

In this chapter, a powerful procedure—PROC TABULATE—was reviewed for constructing summary tables. ODS was used to process output from procedures for easy incorporation into documents or for display on Web pages. Data sets were produced using the OUTPUT destination in ODS. While PROC TABULATE and ODS are incredibly important tools for producing summaries in SAS, SAS has many other tools for preparing reports, including PROC REPORT. If you have a job that requires you to produce reports frequently, then you might want to explore PROC REPORT in more detail.
