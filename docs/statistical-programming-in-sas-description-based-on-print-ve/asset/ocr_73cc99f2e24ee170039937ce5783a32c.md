# 2.3 Writing Out a File or Making a Simple Report

This chapter started with an emphasis on getting data into SAS. The next section discusses producing an analysis data set and changing it by adding observations (concatenating data sets or adding rows to a data set) and adding variables (merging data sets or adding columns to a data set). This section talks about how some of the ideas used for creating a SAS data set from an external file can be inverted to write or create a data set for analysis by other programs or to construct a simple report.

The PUT statement can be thought of as the output analog of the INPUT statement. It specifies how the values of variables, text, etc. should be written. If a filename is specified, then the PUT statement writes to this location. If it is not, then the PUT statement writes to the SAS log. The PUT statement is used to echo the values of all of the variables in a SAS data set. The _NULL_ data set is used to allow for DATA step programming without storing a data set. The _ALL_ specification selects all variables for display. Alternative specifications such as _NUMERIC_ or _CHARACTER_ select all variables corresponding to the data type. The following statement writes the text string - 50 times:

```
put 50*'-';
```
