
The MODEL statement includes the main effects (A B C), the two-way interactions (A*B A*C B*C), and the three-way interaction (A*B*C). An alternative for requesting this model using a shorthand expression in SAS follows:

```
model Y = A|B|C
```

Simpler models can be fit using a variation of this shorthand. For example, suppose you want to fit a model without the three-way interaction. One of the following two model statements works:

```
model Y = A B C A*B A*C B*C;
```

```
model Y = (A|B|C)@2;
```

The fitting of factorial models (or any model with multiple factors, including blocking and Latin square designs) might result in Type I tests and Type III tests that differ. This difference reflects an issue related to sequential versus partial tests when the data are non-orthogonal. (Data that are non-orthogonal typically result from unbalanced cells.) See design texts for more information.

The specification of a two-factor model and the differences between MEANS and LSMEANS are illustrated with a toy example. Suppose you have an experiment with a response variable, RESPONSE, that is measured in combination with two two-level factors, FACTOR1 and FACTOR2. There are 11 observations in this 2x2 factorial experiment. There are three replicate observations in each factor-level combination, except the (1,1) combination, in which two replicate observations are evaluated. These data are given in the following table:

Factor 2

| Factor 1 | 1 | 2 |
|---|---|---|
| 1 | 5, 7 | 10, 11, 12 |
| 2 | 8, 9, 10 | 13, 14, 15 |

Summary statistics for each factor-level combination are produced by PROC MEANS. The tests of interactions and main effects are produced by PROC GLM. The statements to enter these data and conduct these analyses are shown in Display 5.24.

## 5.5 Summary

The purpose of this chapter is to describe the specification of regression and ANOVA models in SAS. The emphasis is on the specification of linear and multiple regression models and one-way and factorial ANOVA models. This discussion is intended to supplement your study of linear models (say, like an introductory course in regression or experimental design methods). In addition, this information gives you a sense of how the MODEL statement is used in SAS, and how categorical factors (using CLASS statements) and numeric predictor variables enter regression models.
