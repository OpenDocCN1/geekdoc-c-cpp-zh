The variables in this array are defined as ADL1 through ADL7. You can define an array based on a collection of variable names. For example:

```
data D3;
ARRAY ADL{*} t1 t2 t3 t4 t5 time6 time_7;
input t1 t2 t3 t4 t5 time6 time_7;
datalines;
6 6 5 5 5 4 3
;
run;
```

Arrays are often used to process a list of variables. Perhaps the most common use for an array is to reassign missing value codes to the SAS internal representation. To process all of the elements of an array, use a looping construction with a DO-END statement pair and an index. The example in the next section illustrates this strategy.

# 9.1.3 Reassign missing value codes for numeric variables “.”

Data sets are often inherited from data collectors, or from part of a secondary data analysis following the primary data collection for some other purpose. Suppose -999 is used as a missing value code in the ADL study. You want to replace all occurrences of -999 with . before doing further any further analyses. The following code does this by looping over an array.

# Display 9.2 Recoding missing values in numeric variables

```
data D4;
ARRAY ADL{*} t1 t2 t3 t4 t5 time6 time_7;
input t1 t2 t3 t4 t5 time6 time 7;
DO ielement = 1 to /;
    if ADL{ielement}=-999 then ADL{ielement}=.;
END;
datalines;
6 6 5 5 5 4 3
7 -999 4 4 3 -999 2
;
run;
proc print data=D4;
title "Recoding missing values using arrays and DO loop";
run;
```
