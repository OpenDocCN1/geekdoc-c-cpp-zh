# 3.8.1 Comparing distributions of responses between multiple groups

The bar chart in Display 3.16, the dot plot in Display 3.17, and the scatter plot in Display 3.19 give a sense of how the distribution of total young changes when the nitrofen concentration increases. Box plots might be easier to understand and are easy to construct. The minimum, first quartile (25th percentile), median, third quartile (75th percentile), and maximum (the so-called five-number summary) are graphically displayed in a box plot.
