This information describes the levels of the group variable. This is a great place to see typographical errors in an input data set. A typo in the entry of levels would lead to more than g=4 levels. For example, if C02 (C-zero-two) was entered for one observation, and two cases of Co2 (C-oh-two) were also entered, then there would be g=5 levels in the table. The total number of observations is noted. A table of CONDITION levels from PROC FREQ can be used to check this as well.

PROC GLM includes two options: an option identifying the input data set and the option order=data. Packaging was entered in the order of plastic, vacuum, mixed, and CO₂. Without the ORDER option, SAS does an internal alphabetical sort in PROC GLM that would have implications for statements such as CONTRAST. In particular, the internal alphabetical sort would have CO₂ (coded as Co2) assigned as the first level, Mixed as the second level, Plastic as the third level, and Vacuum as the fourth level.

Display 5.20 shows the test of mean equality for the g=4 groups. In the analysis, the null hypothesis for the mean log-bacterial counts is the same for the four packaging conditions and is rejected for any commonly selected level of significance (F(3,8)=94.58, P<0.0001). This test and its associated p-value are presented, along with an ANOVA table, descriptive statistics (overall mean, coefficient of variation), and two additional tables of tests. The Type I and Type III tables are more meaningful in the context of multiple factor ANOVA models with unbalanced data.
