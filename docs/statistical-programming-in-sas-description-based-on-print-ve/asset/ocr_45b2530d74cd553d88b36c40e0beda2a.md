# Display 11.23 Creating a data object, two scatter plots, and a histogram

```
declare DataObject dobj;
dobj=DataObject.CreateFromFile("C:\Users\baileraj.IT\DASL_SMSA.sas7bdat");

DataTable.Create(dobj);

declare ScatterPlot plot;
plot = ScatterPlot.Create( dobj, "Education", "Mortality");
declare Histogram hist;
hist = Histogram.Create( dobj, "JanTemp");
hist.SetWindowPosition(50, 50, 50, 50);

declare ScatterPlot plot2;
plot2 = ScatterPlot.Create( dobj, "income", "Mortality");
plot2.SetWindowPosition(0,50,50,50);
```

The linked windows (the data table, the two scatter plots, and the histogram) are shown in Display 11.24. Clicking the two lowest (leftmost) temperature bars in the histogram selects 23 cities. (Cities are associated with the numbers labeling the shaded bars.) These points are highlighted on the scatter plots. None of the cold cities has an average income more than $37,500. Only one of the cold cities has an average education level exceeding 11.5 years. It does not appear that the relationships between mortality and education and between mortality and income differ dramatically between cold cities and non-cold cities.
