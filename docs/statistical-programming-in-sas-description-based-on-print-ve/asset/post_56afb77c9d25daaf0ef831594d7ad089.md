## 2.3 Writing Out a File or Making a Simple Report

This chapter started with an emphasis on getting data into SAS. The next section discusses producing an analysis data set and changing it by adding observations (concatenating data sets or adding rows to a data set) and adding variables (merging data sets or adding columns to a data set). This section talks about how some of the ideas used for creating a SAS data set from an external file can be inverted to write or create a data set for analysis by other programs or to construct a simple report.

The PUT statement can be thought of as the output analog of the INPUT statement. It specifies how the values of variables, text, etc. should be written. If a filename is specified, then the PUT statement writes to this location. If it is not, then the PUT statement writes to the SAS log. The PUT statement is used to echo the values of all of the variables in a SAS data set. The _NULL_ data set is used to allow for DATA step programming without storing a data set. The _ALL_ specification selects all variables for display. Alternative specifications such as _NUMERIC_ or _CHARACTER_ select all variables corresponding to the data type. The following statement writes the text string `'-'` 50 times:

```
put 50*'-';
```

**Display 2.14 Echoing the values of variables in a data set using a PUT statement**

```
libname myfiles "C:\Users\baileraj.IT\BAILERAJ\Classes\Web-CLASSES\sta402\data";

proc sort data=myfiles.nitrofen;
  by conc;
run;

data _null_; set myfiles.nitrofen; by conc;
  if FIRST.CONC then do; * first observation in concentration group;
    put 50*"-";           * add separator line of 50 dashes + column headings;
    put "Animal" @10 "Conc" @20 "Total" @30 "First?" @40 "Last?";
  end;
  put animal @10 conc @20 total @30 FIRST.CONC @40 LAST.CONC;

* put _all_;  /* useful to check values during input */
run;
```

In addition to producing a report, Display 2.14 introduces two indicator variables that are useful when manipulating sorted data sets—FIRST.VARNAME and LAST.VARNAME, where VARNAME is the name of a SAS variable that is used to sort a data set. These two indicator variables were defined when the contents of the nitrofen data set were added to the _NULL_ data set using BY CONC (FIRST.CONC and LAST.CONC). These variables indicate whether the current observation is the first or last observation for each level of the BY variable CONC. As you can see in Display 2.15, the first observation in the CONC=0 condition—animal 1—has FIRST.CONC=1 (TRUE) and LAST.CONC=0 (FALSE). Animals 2 through 9 have FIRST.CONC=0 and LAST.CONC=0. The last observation in the CONC=0 condition—animal 10—has FIRST.CONC=0 and LAST.CONC=1. This program writes a separation line of dashes and column headings if it is the first animal in a concentration group (i.e., when FIRST.CONC=1). The @# specifies that the variable value or column heading is to be printed starting at column #.
