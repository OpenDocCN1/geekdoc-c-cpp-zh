# Display 6.2B Plot of residuals versus the predictor variable

![](bbox=[0.12, 0.17, 0.9, 0.58])

This display shows a pattern where the linear regression model under-predicts the responses (positive residuals) for small values of x (x≤3) and large values of x (x≥10). It shows that the model over-predicts responses (negative residuals) for x values between 4 and 8. This suggests an inadequacy in using a linear regression model. This is not a surprise because a cubic polynomial relationship was simulated.
