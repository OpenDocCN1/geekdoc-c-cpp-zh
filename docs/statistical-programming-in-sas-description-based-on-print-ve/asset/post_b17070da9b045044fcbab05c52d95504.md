## 8.1 Internal Representations and Output Displays

Let’s start by discussing how to get data with formatted values into a SAS data set using informats, and how to display this data using formats. Data can be crudely classified into four types: character, numeric, date, and time. (Someone might argue that there are only two types because date and time are essentially numeric. However, it is necessary to make these distinctions when discussing formats.) Informats tell SAS how to read data and store an input variable. Formats tell SAS how to display the values of a variable.

The most common informat for reading or storing character variables is $w. In this informat, w equals the number of columns, characters, or total width of the variable. The default informat for reading character variables is $8. (i.e., $w, where the default length is 8 bytes). In Chapter 5, a brain weight and body weight data set¹ is used to discuss multiple regression. This data set includes a character variable SPECIES. In this chapter, this variable is identified in the construction of the first data set using the $ following the variable name in the INPUT statement. (See Display 8.1.) In the second data set, SPECIES is declared to be a character variable with a length of 15 before it is specified in the INPUT statement.
