# 6.5 Statistical Graphics—Entering the Land of SG Procedures

SAS/GRAPH software in SAS 9.2 includes a set of new SG procedures including SGPLOT, SGPANEL, and SGSCATTER. With these new procedures, complex displays can be produced with a small number of statements. SG procedures require that the ODS destination be specified before you invoke the procedure. While you do not need to specify ODS GRAPHICS ON when you use SG procedures, there are options in the ODS GRAPHICS ON statement that do apply to SG procedures. These options are described in Chapter 21 of the SAS/STAT User’s Guide. SAS documentation provides a fundamental reference for using SG procedures. Rodriguez (2009) and Schwartz (2009) provide nice overviews of these procedures and kick-start their use.

The SGPLOT procedure enables you to construct one or more plots displayed on the same axis. As you might have inferred from previous chapters, the SGPLOT procedure is used for graphic displays of univariate and bivariate data. Displays include scatter plots with superimposed smooth fits (e.g., with LOESS), histograms with a superimposed density curve, time series plots, bar charts, box plots, and so on.
