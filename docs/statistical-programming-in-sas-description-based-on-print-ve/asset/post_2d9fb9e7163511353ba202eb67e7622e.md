The use of RAND functions is discussed in more detail in Section 8.11, “Generating Variables Using Random Number Generators.” It might seem that the following two statements would produce identical values of X1 and X2:

```
X1 = RAND('normal',mu_1,sig_1);
X2 = RAND('normal',mu_1,sig_1);
```

They don’t because these numbers are generated from a sequence that is initiated once in each DATA step. This function is started with a single seed, which can be set once per DATA step using a STREAMINIT call. Then, a stream of pseudorandom numbers is produced.

While this code generates the two samples of interest (specifically with a sample size of 10 in each group), this task might be better implemented using objects for storing the generated data. This current code is too difficult to generalize for other conditions. (How would you like to modify the code for sample sizes of 50, or even 25?) A better option is to use a data storage object called an array. If you want to read ahead, Section 9.1, “Storage Bins for Collections of Values,” defines, describes, and illustrates many uses for arrays in SAS. For this case study, arrays are used as simple and well-defined storage bins. Functions defined over these arrays calculate intermediate statistics for constructing the pooled variance t-test. A revised array-laden program is shown in Display 8.38.

# Display 8.38 Storing simulated data in arrays

```
data simulate_2group_t;

array x{10} x1-x10;    * storage for sample from population 1;
array y{10} y1-y10;    * storage for sample from population 2;

Nsims = 4000;      * number of simulated experiments;
Myseed = 65432;   * specify seed for random number sequence;
call streaminit(Myseed);

N1 = 10;           * sample sizes from populations 1 and 2;
N2 = 10;

Mu_1 = 0;          * mean/sd of population 1;
Sig_1 = 1;

Mu_2 = 0;          * mean/sd of population 2;
Sig_2 = 1;

do iexpt = 1 to Nsims;

    * generate N1=10 observations ~ N(mu_1, sig_1^2);
    do isample1 = 1 to N1;
        x{isample1} = RAND('normal',mu_1,sig_1);
    end;

    * generate N2=10 observations ~ N(mu_2, sig_2^2);
    do isample2 = 1 to N2;
        y{isample2} = RAND('normal',mu_2,sig_2);
    end;

output;

/* calculate the test statistic */

end;
run;
```
