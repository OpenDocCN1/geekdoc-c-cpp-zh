
## 11.12 Exercises

- 1. Use SAS/IML to perform a randomization test on the packaging and log-bacterial growth data.³ In this problem, you have n₁=n₂=n₃=n₄=3. Use a statistic that measures the difference in the four group means. For example:
  
  $$CSS = \sum_{i=1}^{4} (\bar{Y}_i - \bar{Y})^2$$
  
  $\bar{Y}_i$ is the arithmetic mean of the iᵗʰ group. $\bar{Y}$ is the mean of all of the observations. Note: This is a redo of a Chapter 9 exercise.

- 2. Write a SAS/IML module to conduct a small Monte Carlo simulation that shows how the CI for the mean performs (e.g. coverage probability properties) when estimating the mean of an exponential distribution. Recall that the formula for a confidence interval for a population mean is
  
  $$\bar{Y} \pm t(1-\alpha/2,\,n-1)\, s/\sqrt{n}$$
  
  Select at least three values of n for this illustration (say, n=15, 30, and 50).
  
  Hint: You can generate exponential random variables a few different ways in SAS/IML. You can use randgen with exponential to specify a standard exponential (mean=1), and then multiply these deviates by lambda to get a random exponential (mean=lambda). The following code generates 20 random deviates from an exponential distribution with mean=6:
  
  ```sas
  proc iml;
      lambda = 6;
      mydevs = J(20,1,0);  * initialize vector to contain deviates;
      call randseed(9753);
      call randgen(mydevs,'exponential');
      mydevs = 6*mydevs;

      mean_dev = sum(mydevs)/nrow(mydevs);

      print mean_dev;
  quit;
  ```
  
  How might you use a uniform random deviate along with a manipulation of the exponential cumulative distribution function to generate a random exponential deviate?

- 3. Place the code from “Case Study 2: Bisection Root Finder” into a SAS/IML module. This module should solve the square root of an arbitrary value x where the initial interval endpoints (lo and hi) and the convergence criterion delta are input to this module. How would you build in checks to determine whether the lo and hi values are properly specified?

- 4. Write a numerical integration module (e.g., trapezoidal rule or Simpson’s rule) to estimate π by finding the area under f(x)=4√(1−x²) in the first quadrant.

- 5. Use SAS/IML to merge three different files into one matrix. Output this matrix to a SAS data set. Note: This is a redo of a homework exercise in Chapter 2. Enter each column of the data table into a separate SAS data set, and then import each data set into SAS/IML for processing. Print the resulting SAS data set.
