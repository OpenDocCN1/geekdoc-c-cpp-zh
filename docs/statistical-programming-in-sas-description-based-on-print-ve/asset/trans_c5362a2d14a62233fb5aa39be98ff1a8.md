
# 使用SAS®解决您的数据分析问题！

在《SAS®中的统计编程》一书中，作者A. John Bailer将SAS工具与有趣的统计应用相结合，并以SAS 9.2为平台，介绍用于统计分析、数据管理、数据显示和模拟的编程思想。本书采用通俗易懂的叙述风格，包含大量示例和案例研究，以结构清晰的方式介绍编程问题。

本书分为两部分。第一部分讲解编程的基本要素，包括培养良好的编程习惯、将外部数据集导入SAS以构建分析数据集、生成基本的描述性统计汇总、制作自定义表格、生成更美观的输出以及制作高质量的图形显示。第二部分重点介绍DATA步、宏和SAS/IML®软件中的编程。

书中使用了一些在基础统计课程中不常遇到的统计方法和概念（例如自助法、随机化检验和抖动法）来说明编程思想。本书还广泛展示了SAS中新的ODS统计图形过程，介绍了新的ODS图形编辑器，并简要介绍了SAS/IML® Studio的一些功能，例如生成动态链接的数据显示以及从SAS调用R。
