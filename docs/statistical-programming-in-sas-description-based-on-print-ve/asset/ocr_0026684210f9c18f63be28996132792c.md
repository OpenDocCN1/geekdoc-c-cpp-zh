There are many graphics tasks accomplished by other functions (e.g., POLY, POINT, BAR, SYMBOL, DRAW2TXT, PIE, and FRAME).

Let’s consider an example that is more complicated. The odds ratio (OR) is a common summary reported in logistic regression and for epidemiological investigations. It is not uncommon to see an approximate confidence interval (CI) produced by exponentiating a symmetric CI that is constructed for the log[OR]. Suppose an estimate OR=2 is observed with an estimated SE{log[OR]}=0.2. The approximate 95% CI for OR would be exp[log(2) ± 1.96*0.2]. Wouldn’t it be neat to construct a figure showing this? This figure would do the following:

+   - Illustrate the (OR, log[OR]) relationship.
+   - Map OR=2 to its corresponding log[OR] value.
+   - Move ± 1.96 SE{log[OR]} from this value.
+   - Move back to the OR-log[OR] trace.
+   - Project back to the OR axis for the CI.
