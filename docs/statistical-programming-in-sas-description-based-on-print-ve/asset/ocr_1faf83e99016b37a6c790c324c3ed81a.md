As you conduct a study of the impact of heterogeneous variances on the pooled variance t-test, think about some of the tasks that need to be implemented, such as:

+   - Specify the conditions to be generated.
+   - Generate data sets reflecting these conditions.
+   - Calculate the test statistic.
+   - Accumulate the results over numerous simulated data sets.

Thus, the program might input parameters (conditions), produce output (results), generate data, and calculate a test statistic.
