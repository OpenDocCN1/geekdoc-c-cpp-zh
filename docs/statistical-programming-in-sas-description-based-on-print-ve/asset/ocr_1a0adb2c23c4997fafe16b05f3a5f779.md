The following code moves the classification variable CONC into the row dimension (nesting it (brood1 brood2 brood3 total)*conc with the four analysis variables so that the four variables are summarized separately for each concentration). The table entries are formatted as well.

```
proc tabulate data=nitrofen format=3.;
class conc;
var brood1 brood2 brood3 total;
table (brood1 brood2 brood3 total)*conc,
n min q1 median*f=4.1 q3 max;
run;
```
