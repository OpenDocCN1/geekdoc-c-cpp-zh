The SGSCATTER procedure produces a panel of scatter plots of various combinations of variables. However, these panels can include independently specified variables. Display 6.20 shows the code for requesting separate scatter plots for the three brood counts and total count versus concentrations.

# Display 6.20 Requesting a panel of scatter plots of brood counts versus concentrations

```
data nitrof en;
  infile 'C:\Users\baileraj.IT\Desktop\ch2-dat.txt' firstobs=16 expandtabs missover pad;
  input @9 animal 2. @17 conc 3. @25 brood1 2. @33 brood2 2. @41 brood3 2. @49 total 2.;
run;

title;

ods rtf bodytitle file="C:\Users\baileraj.IT\Desktop\nitrofen-plots2.rtf";
proc sgscatter data=nitrofen;
  plot (brood1 brood2 brood3 total)*conc / loess uniscale=ALL;
  * UNISCALE option ensures axis scales are uniform for better comparison;
run;

ods rtf close;
```

In addition, a LOESS smooth is added to each scatter plot as shown in Display 6.21.
