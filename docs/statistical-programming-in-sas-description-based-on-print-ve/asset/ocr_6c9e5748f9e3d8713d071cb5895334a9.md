# 4.4 Using the Output Delivery System

In the previous examples, PROC TABULATE invocations are bracketed by the commands ODS RTF BODYTITLE and ODS RTF CLOSE. (Actually, if you have been paying attention, then you have seen this convention used with regularity.) The BODYTITLE option is useful if TITLE or FOOTNOTE is specified because the default ODS RTF behavior is to put titles and footnotes in the header and footer parts of a document. In this book, the Output Delivery System (ODS) is frequently used to produce attractive displays of the output from procedures. And, in a more specialized example in this book, ODS is used to produce a comma-separated values data file containing the observations in a SAS data set. (See Display 2.20.)
