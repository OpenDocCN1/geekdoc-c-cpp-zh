The spatial distribution of a quantity of interest might be clustered or regularly spaced. Clustered observations tend to have less distance between observations than completely spatially random (CSR) observations. Regularly spaced observations tend to have more distance between observations than CSR observations. While more complicated test statistics should be considered in this context (Ripley 1981, Waller and Gotway 2004), a very simple statistic—average nearest-neighbor distance—is selected. Define the nearest-neighbor distance for observation i as the following:

d(i)=min(d_i1, d_i2, ..., d_i(i-1), d_i(i+1), ..., d_in) where d_ij=Euclidean distance between observation i and observation j (i≠j).

Assume that there are n observations in the data set. The average nearest-neighbor distance is Σd(i)/n.

Let’s see what happens when there is a square plot of n=4 trees that are located at coordinate points (.25, .65), (.25, .75), (.35, .65), and (.35, .75). (Without giving away the punch line, you can see that these coordinate points are clustered in the unit square. The punch line was just given away! Determine whether the analysis confirms the interocular trauma test.)

Here is the strategy for this analysis:

+   1. Determine nearest-neighbor distances for the observed data.
+   2. Calculate the average nearest-neighbor distance for the observed data.
+   3. Assuming the null hypothesis of CSR observations is true, generate a sample of observations that are randomly distributed in the region of interest.
+   4. Calculate the average nearest-neighbor distance for this simulated data.
+   5. Repeat steps 3 and 4 many times.
+   6. The Monte Carlo p-value is the proportion of generated samples that are more extreme than the observed data. To test for clustering, determine whether the average nearest-neighbor distance from the simulated data is less than the average nearest-neighbor distance from the observed data.

These six steps can be thought of as pseudo-code for the program to calculate the Monte Carlo p-value for detecting clustering.
