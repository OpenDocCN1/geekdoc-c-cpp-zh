PROC GLM requests the test of mean equality between the four groups, and also requests a series of related analyses. GLM is short for general linear model, which includes the regression analysis previously described and the ANOVA model. General linear models are often referred to as simply linear models. GLM might be a confusing procedure name if you are expecting a generalized linear model, which is implemented in SAS using PROC GENMOD.
