A natural extension to regression is to consider the relationship between two or more predictor variables and a response variable. A model with one Y (response) variable and more than one X (predictor) variable is called a multiple regression model. (A source of possible confusion is that this model is sometimes referred to as a multivariate model. However, this is not an appropriate description. Multivariate better describes a situation where more than one Y variable is simultaneously analyzed. A better description for multiple regression is multivariable model.) Here is the formula for a multiple regression problem with five predictor variables:

```
Y_i = β_0 + β_1 X_i1 + β_2 X_i2 + β_3 X_i3 + β_4 X_i4 + β_5 X_i5 + ε_i
```

This formula is often written with the observation index i suppressed. For example:

```
Y = β₀ + β₁ X₁ + β₂ X₂ + β₃ X₃ + β₄ X₄ + β₅ X₅ + ε
```

The usual error assumptions (for example, independent and normally distributed with constant variance) are made for this model. In a natural generalization from simple linear regression, the intercept reflects the expected response when all predictor variables are simultaneously zero. In addition, the coefficients (β₁, β₂, β₃, β₄, β₅) associated with each of the predictor variables (X₁, X₂, X₃, X₄, X₅) represent the partial effects of a variable on the response assuming that all other variables are held constant.

Now that you have a quick overview of multiple regression, let’s look at specifying a multiple regression model for a problem relating brain weight to body weight. Lunneborg (1994) includes a data set with average brain weights and average body weights for a variety of species, including a number of extinct species (in this case, dinosaurs).² Because the relationship between organ size and body size often follows a power law, Y = αX^β, a linearizing transformation might be considered. For example, log(Y) = log(α) + β log(X) or Y* = β₀ + β₁ X* + ε, where β₀ = log(α), β₁ = β. Y*=log(Y), and X*=log(X). Implicitly, an additive error on the log scale implies a multiplicative error on the original scale.

At this point, the model is a simple linear regression model. In the data set you are analyzing, Y = log₁₀(brain weight) and X = log₁₀(body weight). You shouldn’t be surprised that dinosaurs are often characterized by big bodies with small brains. Thus, you might want to allow for dinosaurs to have a different model than other species in this data. For the analysis program shown in Display 5.8, you fit a model that assumes a common intercept and slope for mammals and dinosaurs. You fit a second model that allows the relationship between log₁₀(brain weight) and log₁₀(body weight) in dinosaurs to have a different intercept but the same slope as other species. This second model can be written with the following formula:

```
log₁₀(brain weight)ᵢ = β₀ + β₁ log₁₀(body weight)ᵢ + β₂ I_dinoᵢ + εᵢ
```

Or, if you really like writing models in terms of Xs and Ys, the second model can be written with the following formula:

```
Yᵢ = β₀ + β₁ X₁ᵢ + β₂ X₂ᵢ + εᵢ
```

I_dino = 1 for diplodocus, triceratops, or brachiosaurus (the three species of dinosaurs in this data set). I_dino = 0 for all other species. In the first model, common intercept and common slope, assume β₂=0. In the program shown in Display 5.8, the data are read as part of the program. The variable names are specified in the INPUT statement, and the DATALINES statement is used as a demarcation between the DATA step programming statements and the data. In the DATA step, variables are constructed that correspond to log₁₀ transformations of the brain weight and body weight. An indicator variable IDINO (in memory of the Flintstone’s beloved pet) is defined and indicates that the species is dinosaur. A new variable IDINOBOD is defined and is the product of IDINO and LOGBODY. PROC PRINT provides a chance to see whether the indicator variable is defined correctly and whether the transformed weights are constructed. PROC UNIVARIATE enables you to look at the univariate distributions of each of the weights. Two PROC REG steps fit a model with a common intercept and another model with a unique intercept for dinosaurs. ODS is used to construct an RTF version of the output from this program. Each of the sections of output is a distinct table that can be manipulated in a report (or even a book chapter).
