
## Display 3.15 Producing a horizontal bar chart using PROC SGPLOT

```
%let DATA_DIR = C:\Users\baileraj.IT\Desktop;
%let OLD_DIR = M:\public.www\classes\sta402\SAS-programs;

data nitro_tox;
    infile "&DATA_DIR\ch2-dat.txt"
          firstobs=16 expandtabs missover pad ;
    input @9 animal 2. @17 conc 3. @25 brood1 2.
          @33 brood2 2. @41 brood3 2. @49 total 2.;
run;

* ods rtf bodytitle file="&DATA_DIR\Display-3.15.rtf";
ods listing image dpi=300;
ods graphics / width=4.5in;
proc sgplot data=nitro_tox;  * Display 3.16;
    hbar conc / response=total stat=mean limits=both limitstat=stddev
                numstd=2;
run;

proc sgplot data=nitro_tox; * Display 3.17;
    dot animal / response=total group=conc;
run;

ods graphics off;
* ods rtf close;
```

The bar lengths in Display 3.16 correspond to the mean number of young produced (stat=mean) for each concentration (hbar conc). The limits extend to reflect a multiple of the standard deviation from the mean in each concentration (limitstat=stddev numstd=2). The limits could be modified to reflect a confidence interval for each unknown mean (limitstat=clm) if you wanted that information. So, when would you prefer which display? Hint: Do you want to describe the distribution of responses in a sample? Or do you want to reflect the uncertainty when estimating an unknown population parameter?

## 3.8 Using Scatter Plots to Display Relationships between Numeric Variables

Scatter plots are preferred when looking at the relationship between two numeric variables. The SGPLOT procedure is the tool for this display. Are you seeing a pattern at this point? PROC SGPLOT is the statistical graphics procedure that accommodates most of the basic displays that you construct in a data analysis. More details about PROC SGPLOT and other statistical graphics procedures are provided in Chapter 6. Go ahead and jump to Chapter 6 if you are feeling a bit impatient. These procedures are a very cool addition to SAS 9.2 and it is well worth your time to explore their use.

The simple example in Display 3.18 produces three plots. The first plot shows the total number of young produced in three broods (total) versus nitrofen concentration (conc) where the value of the cbrood variable is used as a group variable that yields a different plotting symbol. (See Display 3.19.) The second plot shows the brood-specific counts as a function of nitrofen concentration. (See Display 3.20.) The third plot will be discussed in a moment.

## Display 3.18 Generating the three scatter plots

```
%let DATA_DIR = C:\Users\baileraj.IT\Desktop;
proc format;
value totfmt    0='none'
                1-HIGH='some';
run;

data nitro_tox;
    infile "&DATA_DIR\ch2-dat.txt"
        firstobs=16 expandtabs missover pad ;
    input @9 animal 2. @17 conc 3. @25 brood1 2.
          @33 brood2 2. @41 brood3 2. @49 total 2.;
    cbrood3 = brood3;
    format cbrood3 totfmt.;
run;

* ods rtf bodytitle file="&DATA_DIR\Display-3.18.rtf";
ods listing image dpi=300;
ods graphics / width=4.5in;

proc sgplot data=nitro_tox;    * Display 3.19;
    scatter y=total x=conc  / group=cbrood3;
run;

proc sgplot data=nitro_tox;    * Display 3.20;
    scatter y=brood1 x=conc;
    scatter y=brood2 x=conc;
    scatter y=brood3 x=conc;
run;

* add JITTER to concentration to separate points in the plot;
data nitro_tox3; set nitro_tox;
    jconc = conc + 20*RAND('uniform')- 10;
                        * add jitter to the concentration for plotting;
run;

proc sgplot data=nitro_tox3;    * Display 3.21;
xaxis label = "Nitrofen concentration (jittered)";
yaxis label = "Number of young";
    scatter y=brood1 x=jconc;
    scatter y=brood2 x=jconc;
    scatter y=brood3 x=jconc;
run;

ods graphics off;
* ods rtf close;
```

Display 3.19 shows that there is a reduction in the number of young when there is an increase in nitrofen concentration. In addition, there is an increase in animals with no young produced in the third brood.

There should be 150 observations (50 animals each with three broods) in this plot. Obviously, some observations are not in this display. Can you do anything about this? The observations are hidden because more than one observation is at a coordinate plotting location. One trick is to add a little noise to the plotting location. For example, the last data set in Display 3.18—nitro_tox3—constructs a jittered concentration (JCONC) by generating a random uniform quantity—UNIF(−10, 10)—that is added to each concentration measurement. This is accomplished by first generating a random uniform variate—U(0,1)—and then multiplying by 20 to yield U(0, 20). Then, 10 is subtracted from this quantity, yielding a uniform deviate over the domain −10 to 10 (i.e., U(−10, 10)). This uniform deviate is added to each concentration measurement to produce a jittered concentration and is graphed in Display 3.21. Two statements are included with the final SGPLOT, XAXIS, and YAXIS to further customize the graph. (For more information about customizing graphs, see Chapter 6.)

### 3.8.1 Comparing distributions of responses between multiple groups

The bar chart in Display 3.16, the dot plot in Display 3.17, and the scatter plot in Display 3.19 give a sense of how the distribution of total young changes when the nitrofen concentration increases. Box plots might be easier to understand and are easy to construct. The minimum, first quartile (25th percentile), median, third quartile (75th percentile), and maximum (the so-called five-number summary) are graphically displayed in a box plot. To produce box plots using PROC SGPLOT, VBOX or HBOX statements can be used. To construct side-by-side box plots for the nitrofen data set, the following code is used:

```
proc sgplot data=nitro_tox;
 ybox total / category=conc;
 xaxis label = "Nitrofen concentration";
 yaxis label = "Number of young (3 broods)";
 run;
```

The results of this code are shown in Display 3.22. The box is defined by the first quartile (25th percentile), median, and third quartile (75th percentile) with whiskers extending from the third quartile to the maximum value, and from the first quartile to the minimum value. (Variations of this construction are available. See the Help documentation.) The diamond in the center of the box indicates the location of the mean total number of young for each nitrofen concentration.
