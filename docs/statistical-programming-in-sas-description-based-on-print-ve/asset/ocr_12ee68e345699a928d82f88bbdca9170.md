# Display 8.58 Q-Q plot of t4 versus standard normal

![](bbox=[0.05, 0.18, 0.95, 0.78])

The curvature in this display indicates the heavier tails in the t4 versus standard normal distribution (e.g., P(Z≤-2) ≈ P(t4≤-3). Previous and new releases of SAS include functions to calculate quantiles such as PROBIT (for standard normal distribution) and TINV (for t distribution). However, with the advent of QUANTILE, these other distributional functions are unnecessary.

Other SAS functions associated with distributions include survival functions (SDF) and functions that return the log of the CDF, PDF, or SDF - namely, LOGCDF, LOGPDF, or LOGSDF, respectively.
