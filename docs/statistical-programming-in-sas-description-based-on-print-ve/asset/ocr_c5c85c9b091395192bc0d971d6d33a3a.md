This draft has captured the essence of the table. However, all concentration groups are pooled in this display and the number of decimal places is unnecessary. In the next iteration of code, stratify the analysis for each concentration group. Identify the concentration with a CLASS statement, and then construct a separate table for each concentration by specifying CONC as the page specification or first argument in the TABLE statement:

```
proc tabulate data=nitrofen;
  class conc;
  var brood1 brood2 brood3 total;
  table conc, brood1 brood2 brood3 total, n min q1 median q3 max;
run;
```

This code produces five tables, one for each concentration group as shown in Display 4.5.
