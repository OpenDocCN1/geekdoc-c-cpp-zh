Chapter 3 presented SAS procedures for generating summaries for categorical and numeric variables. Chapter 4 addressed customizing output and creating fancy tables. In this chapter, you learn how to specify and fit models for the relationship between variables. SAS procedures that study the relationship between a single continuous variable and other variables are described in this chapter. SAS procedures for linear regression are introduced for predicting a continuous response variable as a linear function of one or more predictor variables. SAS procedures for ANOVA models are described. Basic descriptions of these statistical methods are presented.
