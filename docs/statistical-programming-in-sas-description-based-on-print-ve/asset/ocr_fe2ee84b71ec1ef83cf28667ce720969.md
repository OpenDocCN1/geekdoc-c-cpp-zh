In contrast, the appearance of ODS Graphics is controlled by templates and options in the ODS GRAPHICS statement. ODS Graphics are displayed in ODS destinations and can be saved in a variety of file formats. Annotate data sets are used for customizing graphs produced by traditional SAS graphics. The ODS Graphics Editor is used for customizing graphs produced by ODS Graphics, and the GTL can be used for permanent modifications.
