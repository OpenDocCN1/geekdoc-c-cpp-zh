Before you begin exploring ways to read data into SAS, let’s take a short digression into the topic of functions in SAS and how functions can be used to add variables to a data set.

In Chapter 1, the LOG10 function was introduced in Display 1.1 to generate new variables that contain the common logarithm values of certain variables. In Display 1.2, you saw the use of the function RAND in a DATA step to generate a pseudorandom number. Many functions related to statistical distributions including RAND are presented in Chapter 8. While the focus of this chapter is on creating an analysis data set, you should keep in mind that after a data set is created, new variables can be created from variables in the data set. A good place to see an overview of the power and variety of functions in SAS is in Base SAS Help. (Review functions and CALL routines by category.) You will see descriptive statistics functions (e.g., MIN (minimum), CV (coefficient of variation), GEOMEAN (geometric mean), and STD (standard deviation)). You will see mathematical functions (e.g., ABS (absolute value), EXP (exponential functions), LOG (logarithm relative to base e), LOG10 (logarithm relative to 10), LOG2 (logarithm relative to 2), and SQRT (logarithm relative to square root)). Other classes of functions that might be of interest to a statistical programmer include trigonometric, truncation, state and ZIP code, variable, date and time, combinatorial, array, and character functions.

# 2.1 Temporary versus Permanent Status of Data Sets

Data sets in SAS have two-part names. However, if you want them to exist only for the duration of a particular session of SAS, then they can have single-part names (kind of like the luminaries of Brazilian soccer). As discussed in Section 1.4, “What Is a SAS Data Set,” SAS data sets are rectangular objects where rows are different observations and columns are different variables. Think of permanent SAS data sets as residing in collections known as SAS libraries. A two-part name includes a library name and a data set name, separated by a period. For example, myfiles.nitrofen has the library name myfiles that points to a subdirectory containing my SAS data sets. The second part of the name is nitrofen, which is a specific data set. The nitrofen data set probably includes catalogs for graphics and formats.
