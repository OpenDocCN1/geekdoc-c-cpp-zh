# 3.9 Summarizing Categorical Variables

Categorical data are often summarized by frequency or relative frequency of responses for levels of each categorical variable, or for combinations of levels of categorical variables. A table of the frequency of one variable can be used to check the integrity of data entry. For example, there should be 10 animals in the five concentration groups. The following code to check data integrity uses PROC FREQ, which produces the table in Display 3.23:

```
proc freq data=nitro_tox;
    table conc;
run;
```

You can see that the five levels of nitrofen concentration were entered correctly (i.e., CONC=0, 80, 160, 235, and 310, as expected). There are 10 observations recorded for each concentration.
