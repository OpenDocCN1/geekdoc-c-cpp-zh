Four output objects are produced—NObs, ANOVA, FitStatistics, and ParameterEstimates. You can select a particular output object (say, ParameterEstimates) from PROC REG using the ODS SELECT statement.

```
ods select ParameterEstimates;
ods rtf bodytitle file="reg-est.rtf";
proc reg;
  model y = x;
run;
ods rtf close;
```

The output is shown in Display 4.20.
