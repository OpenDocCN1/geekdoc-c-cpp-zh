# Display 8.10 Assigning date formats to numeric variables

```
data tester2;
    input @1 indate1 date7. @9 indate2 date9.
          @19 indate3 mmddyy. @26 indate4 ddmmyy8.;
    format numeric_date9.;
datalines;
30jun10 30jun2010 063010 30.06.10
;
run;

ods rtf file="C:\Users\baileraj.IT\Desktop\Display-8-10.rtf";
proc print data=tester2;
run;
ods rtf close;
```

The informats—date7, date9, mmddyy, and ddmmyy8—are used to read the dates in the data set in Display 8.10. The date9 format is assigned to all numeric variables in the tester2 data set.

In addition to displaying dates in a useful format, you might be interested in displaying dates in different formats, or displaying parts of the date such as the day or month. Display 8.12 illustrates some of these options.

# Display 8.12 Various date formats

```
data date_format_show;
    start = 0;
    put start date9.;
    today = 17700;  * days since Jan 1, 1960;
    put '----------------------------';
    put 'DATE7. / DATE9.';
    put today date7.;
    put today date9.;
    put '----------------------------';
    put 'DAY?. / DAY?.';
    put today day?.;
    put today day7.;
    put '----------------------------';
    put 'EURDFDD8.';
    put today eurdfdd8.;
    put '----------------------------';
```
