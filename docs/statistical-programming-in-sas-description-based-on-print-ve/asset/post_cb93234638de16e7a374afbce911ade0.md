
In this chapter, you are presented with a data structure (the array) that is available in DATA steps. The array can store a collection of similar type elements. Manipulations involving these data structures are provided. A series of examples illustrate the power and flexibility of arrays. By default, SAS processes data one record at a time, forgetting the values of variables from previous records. (Sorry for anthropomorphizing SAS. I know it doesn’t really forget values, but it is a useful image, nonetheless.) However, it is often important to keep the values for processing future records. The RETAIN statement addresses this need. The descriptions and basic illustrations of ARRAY and RETAIN are supplemented with case studies that emphasize their power.

## 9.1 Storage Bins for Collections of Values

An array is a temporary data structure that contains a collection of variables or values. Arrays are often used to store lists of variables. An array can be conceptualized as a box that has been partitioned into many chambers, and each chamber contains information. There are many ways to define the variables and the values of these variables in an array. So, how do you tell SAS that you want to set up an array for storing values? Here is the basic syntax:

```
ARRAY arrayname{number of array elements} variable-list;
```

(The symbols { }, [ ], and ( ) can all be used in an array definition.) If you want to define the values of the variables directly, you can define them following the variable list.

### 9.1.1 Defining values in the variable list

In this example, one array (tempF) is initialized with four Fahrenheit temperatures. This array is looped over an array of Celsius temperatures (tempC) to calculate the values corresponding to the Fahrenheit values.

# Display 9.1 Converting temperature scales using arrays

```
data temps;
  array tempF(4) tempF1-tempF4 (32,50,68,86);
  array tempC(4) tempC1-tempC4;

  do itemp = 1 to 4;
    tempC(itemp) = 5/9*(tempF(itemp)-32);
  end;
  drop itemp;
end;
run;

proc print data=temps;
run;
```

The printout from Display 9.1 includes the following output lines:

| Obs | temp F1 | temp F2 | temp F3 | temp F4 | temp C1 | temp C2 | temp C3 | temp C4 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 32 | 50 | 68 | 86 | 0 | 10 | 20 | 30 |

### 9.1.2 Inputting values in the variable list

You can read variable values into an array from data lines or from an external file. Suppose the number of activities of daily living (ADL) that each resident of a nursing home could conduct is measured during seven consecutive quarters. It makes sense to consider each resident’s data as being naturally grouped. In the following figure, a seven-element array contains the data from a resident whose first two ADL measurements are 6, followed by three ADL measurements of 5, followed by an ADL measurement of 4, and a final ADL measurement of 3.

| ADL[1] | ADL[2] | ADL[3] | ADL[4] | ADL[5] | ADL[6] | ADL[7] |
| --- | --- | --- | --- | --- | --- | --- |
| 6 | 6 | 5 | 5 | 5 | 4 | 3 |

For this example, the following code can be used to read these data into an array:

```
data D1;
ARRAY ADL{7} ADL1-ADL7;
    input ADL1-ADL7;
    datalines;
6 6 5 5 5 4 3
;
run;
```

In this portion of code, the array is named ADL, and the elements are named ADL1 through ADL7. The size of the array is explicitly declared to be 7 elements long by the use of {7} following the declaration of the array name ADL. You can define the size of the array without counting the elements in the array by using an asterisk, as in {*}. This is illustrated in the next portion of code:

```
data D2;
ARRAY ADL{*} ADL1-ADL7;
    input ADL1-ADL7;
    datalines;
6 6 5 5 5 4 3
;
run;
```

The variables in this array are defined as ADL1 through ADL7. You can define an array based on a collection of variable names. For example:

```
data D3;
ARRAY ADL{*} t1 t2 t3 t4 t5 time6 time_7;
input t1 t2 t3 t4 t5 time6 time_7;
datalines;
6 6 5 5 5 4 3
;
run;
```

Arrays are often used to process a list of variables. Perhaps the most common use for an array is to reassign missing value codes to the SAS internal representation. To process all of the elements of an array, use a looping construction with a DO-END statement pair and an index. The example in the next section illustrates this strategy.

### 9.1.3 Reassign missing value codes for numeric variables “.”

Data sets are often inherited from data collectors, or from part of a secondary data analysis following the primary data collection for some other purpose. Suppose -999 is used as a missing value code in the ADL study. You want to replace all occurrences of -999 with . before doing further analyses. The following code does this by looping over an array.

# Display 9.2 Recoding missing values in numeric variables

```
data D4;
ARRAY ADL{*} t1 t2 t3 t4 t5 time6 time_7;
input t1 t2 t3 t4 t5 time6 time_7;
DO ielement = 1 to dim(ADL);
    if ADL{ielement}=-999 then ADL{ielement}=.;
END;
datalines;
6 6 5 5 5 4 3
7 -999 4 4 3 -999 2
;
run;
proc print data=D4;
title "Recoding missing values using arrays and DO loop";
run;
```

The printout from Display 9.2 includes the following output lines:

```
Recoding missing values using arrays and DO loop
Obs    t1    t2    t3    t4    t5    time6    time_7    ielement
1      6     6     5     5     5     4        3         8
2      7     .     4     4     3     .        2         8
```

Notice the index variable ielement in the output data set. The value of this index, 8, is beyond the looping range, which is when the looping stops for each observation. You can eliminate the index variable from an output data set by using a DROP statement. (For example, insert a drop ielement statement before the datalines statement in the previous code). The list of variables included in an array can be implicitly defined as all numeric variables, all character variables, or all variables using the _NUMERIC_, _CHARACTER_, and _ALL_ options, respectively. The following example illustrates the power of this construction.

### 9.1.4 Recoding missing values for all numeric and character variables

Suppose the ADL data set included character variables for the name and sex of the resident and the seven ADL measurements recorded over time. The following program groups all of the numeric variables into an array named num_array. It groups all of the character variables into an array named char_array. The program loops over each array to change all missing values to . for the numeric variables, and to change all missing values to a blank space for the character variables. The dim function determines the number of elements in each array for the looping. The program is shown in Display 9.3.

# Display 9.3 Recoding missing values in numeric and character variables

```
data D5;
    input name $ sex $ t1 t2 t3 t4 t5 time6 time_7;

ARRAY num_array{*} _NUMERIC_;
ARRAY char_array{*} _CHARACTER_;

/* recode the numeric variables */
DO inum = 1 to dim(num_array);
    if num_array{inum}==-999 then num_array{inum}=.;
END;

/* recode the character variables */
Do ichar = 1 to dim(char_array);
```

# Display 9.3 (continued)

```
if char_array{ichar}="-999" then char_array{ichar}=" ";
END;

drop inum ichar;
datalines;
MrSmith -999 6   6 5 5 5    4 3
-999      F 7 -999 4 4 3 -999 2
;
run;

proc print data=D5;
title "Recoding missing values using arrays and DO loop";
run;
```

The printout from Display 9.3 includes the following output lines:

```
Recoding missing values using arrays and DO loop
Obs    name    sex    t1    t2    t3    t4    t5    time6    time_7
1      MrSmith         6     6     5     5     5     4        3
2                   F     7     .     4     4     3     .        2
```

### 9.1.5 Creating multiple observations from a single record

Different procedures in SAS might expect data to have different structures. For example, some of the multivariate procedures expect all of the variables to be defined in a single record. In other cases, such as in mixed models applied to longitudinal data, different measurements are expected to be defined in different records. It is important to be able to program the expansion of a single record to multiple records, or to be able to condense multiple records into a single record. Suppose you have data in the following form:

| Name | Sex | t1 | t2 | t3 | t4 | t5 | time6 | time_7 |
|------|-----|----|----|----|----|----|-------|--------|
| Smith | M | 6 | 6 | 5 | 5 | 5 | 4 | 3 |
| Jones | F | 7 | 5 | 4 | 4 | 3 | 2 | 1 |
| Fisher | M | 5 | 5 | 5 | 3 | 2 | 2 | 1 |
