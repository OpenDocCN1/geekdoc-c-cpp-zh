The PUT statement can be used to create simple customized reports. In the program in Display 2.16, the nitrofen data are read from an external source and written to a text file with an annotation. The nitrofen data are first sorted by concentration, and then added to the _NULL_ data set by concentration. From the previous example, BY CONC creates internal SAS variables FIRST.CONC and LAST.CONC, which are true when an observation is the first or last observation, respectively, within a group. Thus, the statements in the DO-END block are executed when FIRST.CONC is TRUE:

```
put 6*' +-----' '+';
put 'Conc = ' conc /
    @1 'Brood 1'  @10 'Brood 2'  @20 'Brood 3' @30 'TOTAL' /
    @1 '-------'  @10 '-------'  @20 '-------' @30 '------';
```

In the program, the condition is true if the observation being processed corresponds to the first animal in a concentration group. In this case, a divider of the form +-----+-----+-----+... +-----+ is written, along with variable labels and underlines for the labels. Where values are written is controlled by the @n specification, which moves the output pointer to the nth column before writing. The values of the variables are written following the specified format:

```
put @5 brood1 3. @14 brood2 3. @24 brood3 3. @32 total 3.;
```

The value of BROOD1 is written starting at column 5 with a fixed formatted width of 3 columns. Other output locations and formats are similarly specified. A second DATA _NULL_ block is specified to write a note at the bottom of the file. The FILE specification in this block includes the MOD option, which declares that any PUT activity will be appended to the end of the text file. If the MOD option had been omitted, then the entire text file would have been overwritten with the last line.
