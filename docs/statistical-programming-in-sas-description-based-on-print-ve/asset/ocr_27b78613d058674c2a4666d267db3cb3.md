# 2.2.2 Reading data sets saved as text—INFILE can be your friend

It’s OK to use a DATALINES statement for so-called instream data entry when you have relatively small data sets. In fact, you might want to use a subset of a large data set as a test data set for making sure that you have your INPUT statement correctly specified. The code in the previous section accomplishes this, and the previous INPUT statement is used again in this section. When you get to larger data sets, it would make for large and ugly programs if you had to slog through hundreds of lines of data before getting to analysis statements or PROCs. Thus, an alternative for specifying an external file for data entry is needed. If the external file is a text file, data can be read using an INFILE statement in which the data file is identified. You might discover that some preprocessing of the data is needed before reading it into a SAS data set. For example, as shown in the comments before the program in Display 2.8, tabs are replaced with two spaces and missing values for two Fort Worth variables are assigned the SAS missing code for numeric variables (a period).

# Display 2.8 Reading an external text file into a SAS data set using an INFILE statement

```
/*
Notes:
1) Two spaces separate each entry in the input data file. A global replace of tabs with two spaces was performed before saving the text file.
2) The first line contains the names of the variables, and the data begins on the 2nd line of the file.
3) Fort Worth had missing values for POP and INCOME and "." were entered in the data file.
4) Increased LENGTH to 39 to accommodate GREENSBORO-WINSTON-SALEM...
*/
options nodate nocenter;
data SMSA_from_txt;
infile "C:\Users\baileraj.IT\Desktop\DT-Book 3\SMSA-DASL-2space-sep.txt";
firstobs=2;
length city $ 39;
input city & JanTemp JulyTemp RelHum Rain Mortality Education PopDensity pct_NonWhite pct_WC pop pop_per_house income HCPot NOxPot SO2Pot NOx;
run;
ods rtf bodytitle file='C:\Users\baileraj.IT\Desktop\ch2-fig2.8.rtf';
proc print data=SMSA from txt;
var city JanTemp JulyTemp RelHum NOxPot SO2Pot NOx;
run;
ods rtf close;
```
