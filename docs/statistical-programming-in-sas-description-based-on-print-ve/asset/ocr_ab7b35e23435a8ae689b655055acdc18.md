The list of graphs produced by each statistical procedure that uses ODS Graphics is provided in the Details section of the documentation for that procedure. For example, the graphs produced by PROC REG are listed by selecting SAS Products→SAS/STAT→SAS/STAT 9.2 User’s Guide→The REG Procedure→Details: REG Procedure→ODS Graphics in SAS Help. A table that lists the graphs is shown. (See Display 6.4 for an example.) Display 6.2A shows the graph of the DiagnosticsPanel object.
