
## 8.8 Case Study 2: Monte Carlo Integration to Estimate an Integral

Another really cool thing to do is estimate integrals using stochastic methods. The area (volume) under a curve (surface) can be estimated from the proportion of points randomly generated in some space that lie beneath the curve (surface) multiplied by the area (volume) of the space. To make this concrete, consider the problem of estimating the area under a standard normal density function between 0 and 1.645. You probably already know the answer—you can read the table. But, let’s see how to implement a stochastic solution. The rough idea of a stochastic solution is described in Display 8.41.

### Display 8.41 Pseudocode for stochastic solution (the Monte Carlo integration)

```
/* generate data [x, f(x)] in a rectangle containing f(x) = density for N(0,1) */

/* determine proportion of points that lie below f(x) */

/* derive the area estimate and place a bound on the error of estimation */
```

You need to consider the dimensions of the rectangle over which you are generating the data. The interval for the x-axis is easy, it is [0, 1.645]. The interval for the y-axis is not hard to configure, but you need to think a little. The standard normal density takes the following form:

f(x) = 1/√(2π) exp( -1/2 x² )

The maximum of this function occurs at x=0, so the interval for the y-axis should have the following range:

0 to 1/√(2π) = 0.399

So, you generate an (x,y) point in the rectangle with a lower left corner [0, 0] and an upper right corner [1.645, 0.400]. (Yeah, I rounded up.)

### Display 8.43 Generating a Monte Carlo estimate of P(0<Z<1.645)

```
data area_est;
retain n_under 0;                * initialize counter - aside: n_under=0 - also works;
seed1 = 98765;                  * seed specified;
call streaminit(seed1);

const = 1/sqrt(2*arcos(-1));    * bring constant calc. outside loop;
n_pts = 4000;
zmult = 1.96;                  * 95% Confidence interval requested;
Area_rectangle = 1.645*.400;

do ii = 1 to n_pts;             * REPEAT { . . . ;
/* generate data [x, f(x)] in a rectangle containing the
                                   f(x) = density for N(0,1) */
x = 1.645*RAND('uniform');
y = 0.400*RAND('uniform');

/* determine proportion of points that lie below f(x) */
iunder = (y<= const*exp(-x*x/2) );
n_under = n_under + iunder;
p_est = n_under/ii;

/* derive the area estimate, SE and CI  */
AUC_hat = Area_Rectangle * p_est;
SE_AUC_hat = Area_Rectangle * sqrt(p_est * (1-p_est) / n_pts);
LCL = AUC_hat - zmult * SE_AUC_hat;
UCL = AUC_hat + zmult * SE_AUC_hat;

output;
end;                            * . . . };

/* write out the results */
put "Area est. = " AUC_hat;
put "(SE = " SE_AUC_hat ")";
put "CI: [" LCL "," UCL "]";
run;
```

The estimated integral and associated pointwise CIs are extracted from the SAS log and reproduced:

```
Area est. = 0.4522105
(SE = 0.004823385 )
CI: [0.4427566653 ,0.4616643347 ]
```

The estimate of P(0<Z<1.645) is 0.452 (95% CI: 0.442, 0.462). You knew the answer was 0.45. It is interesting to see how the estimated integral and associated pointwise CIs changed as the number of randomly generated points increased.

## 8.9 Case Study 3: Simple Percentile-Based Bootstrap

The bootstrap (see, e.g., Efron and Tibshirani 1994) is one of the most important tools to be added to the data analyst’s toolkit in recent memory. The key idea in a bootstrap is that if the sample distribution is a reasonable approximation of the population distribution, then you can approximate the sampling distribution of a statistic by sampling from the sample distribution. For each resample, you calculate the test statistic of interest. The distribution of this test statistic over bootstrap resamples can be used to construct quantities including standard error estimates and CIs. The simplest form of CI construction is to use appropriate quantiles of the bootstrap distribution to serve as the CI. For example, a 90% percentile-based CI is constructed from the 5th and 95th percentiles of the bootstrap distribution. (Other more complicated constructions of the bootstrap CI might be preferred. For example, a BCa (bias-corrected and accelerated) bootstrap can be constructed. You are encouraged to learn more about this.)

The general flow of the program to construct a percentile-based bootstrap CI is described in Display 8.47.
