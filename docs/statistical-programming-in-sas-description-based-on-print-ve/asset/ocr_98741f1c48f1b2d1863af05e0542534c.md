# 11.7 Case Study 3: Randomization Test Using Matrices Imported from PROC PLAN

In Display 11.13, the two-group randomization test example from Chapter 9 is revisited. (You might want to look back at the Chapter 9 illustration to remind yourself about randomization test ideas and see the SAS code for generating permutations.) In this example, PROC PLAN is used to generate permutations of the indices 1:20 (i.e., the labels 1 to n1+n2). The permutations are imported into SAS/IML to calculate the permutation test statistic. The actual data are imported into SAS/IML as the matrix nitro. The indices are in the matrix perm_index. The matrix perm_resp is the data in nitro rearranged based on the rows of indices in perm_index. The permutation test statistic is presented in the PERM_RESULTS matrix. The difference in sample means (which is equal to the difference in sample sums because the two groups have equal sample sizes (n1=n2=10)) is presented in the PERM_RESULTS matrix. And, an indicator of whether this difference is larger than the observed value of the test statistic is presented in the PERM_RESULTS matrix. The proportion of 1s in the second column of the PERM_RESULTS matrix defines the p-value.
