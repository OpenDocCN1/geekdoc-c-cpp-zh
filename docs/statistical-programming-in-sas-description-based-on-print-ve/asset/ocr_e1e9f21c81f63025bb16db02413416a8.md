Let’s look closely at the statements in Display 11.1. The first statement defines matrix C with 2 rows and 3 columns. The entries of each row are separated by a comma.

```
C = {1 2 3,4 5 6};
```

The second statement defines matrix C_r2 with 1 row and 3 columns containing the second row from matrix C.

```
C_r2 = C[2,];
```

A matrix is referenced by two arguments separated by a comma and within brackets following the matrix name. The first argument represents a row index. The second argument represents a column index. A reference to a matrix with only one index such as C[2,] selects the second row and all columns. To select the third column of a matrix, the following statement is issued:

```
C_c3 = C[,3];
```

You can select ranges of indices using a : operator. For example, the fourth statement selects columns 2 and 3 from matrix C.

```
Col23 = C[,2:3];
```

An element of a matrix can be selected by specifying its row and column indices. For example:

```
C23 = C[2,3];
```

The row 2, column 3 element of matrix C is assigned to C23. The next two statements illustrate that operations can be specified on the row or column dimension of a matrix.

```
C_csum=C[+,];
C_rsum=C[,+];
```

These two statements form a 1×3 matrix C_csum by summing the rows in each column of matrix C. They form a 2×1 matrix C_rsum by summing the columns in each row of matrix C. The final two statements in Display 11.1 scale the row and column sums by the number of columns and rows, respectively. The sums are used to yield row and column means.

```
C_row_mean = C[,+]/ncol(C);
C_col_mean = C[+,]/nrow(C);
```
