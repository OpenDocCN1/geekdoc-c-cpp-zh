
## 3.9 Summarizing Categorical Variables

Categorical data are often summarized by frequency or relative frequency of responses for levels of each categorical variable, or for combinations of levels of categorical variables. A table of the frequency of one variable can be used to check the integrity of data entry. For example, there should be 10 animals in the five concentration groups. The following code to check data integrity uses PROC FREQ, which produces the table in Display 3.23:

```
proc freq data=nitro_tox;
    table conc;
run;
```

You can see that the five levels of nitrofen concentration were entered correctly (i.e., CONC=0, 80, 160, 235, and 310, as expected). There are 10 observations recorded for each concentration.

The responses of individuals to two or more categorical variables are often displayed in contingency tables. In the case of two categorical variables, one variable labels the rows. The other variable labels the columns. The contingency table displays the counts of observations at each combination of row and column values. The following code requests a contingency table in which nitrofen levels are displayed as rows (CONC) and the presence of young in a third brood (CBROOD3) are displayed as columns (a two-level categorical variable). Table output is modified to display only row percentages. (The NOCOL and NOPCT options suppress the printing of column and joint percentages, respectively.) Statistical tests are requested to see whether the probability of young being produced in the third brood is the same for the other broods (CHISQ and EXACT options), and whether a concentration-related trend exists in the probability (TREND option). The following partial code produces the output in Display 3.24:

```
```sas
proc freq data=nitro_tox;
  table conc*cbrood3 / noperct nocol chisq trend exact;
run;
```

## 3.10 Summarizing Numeric Variables

If you were stuck on a desert island with access to only one SAS procedure, PROC UNIVARIATE might be your choice (assuming you have an interest in characterizing a numeric variable while stranded on a desert island). This procedure can generate descriptive statistics of location (means, medians, percentiles) and spread (standard deviation, variance, range, interquartile range). It can identify extreme values in the data set. In addition, it can produce simple graphics including histograms, normal quantile plots, stemplots, box plots, etc. The following programming statements produce a

histogram of the total number of young with a nonparametric density estimate (Display 3.25). The statements also produce a plot of the quantiles of the data versus normal quantiles (Display 3.26):

```
proc univariate data=nitro_tox;
    var total;
    histogram / kernel;  * histogram with nonpar. Density est.;
    qqplot;             * quantile-quantile plot vs. normal;
run;
```

The following programming statements generate separate numeric summaries for each of the concentrations:

```
proc univariate data=nitro_tox;
  by conc;
  var total;
run;
```

The histogram in Display 3.25 can be produced by the SGPLOT procedure as shown in the code in Display 3.27 and in the output in Display 3.28. Let’s look at numeric summaries of January temperature data from the SMSA² city data using PROC UNIVARIATE. (For more background, see Section 2.2.) Display 3.29 includes the request for univariate statistics for the JANTEMP variable and for the identification of cities associated with extreme low or high temperatures. (This is a great way to check for outliers in a data set.)

### Display 3.29 Request for univariate statistics describing the distribution of January temperatures in the SMSA data set

```
options nodate nocenter nonumber;
%let DATA_DIR = C:\Users\baileraj.IT\Desktop;
data SMSA_from_txt;
  infile "C:\Users\baileraj.IT\Desktop\SMSA-DASL-2space-sep.txt"
  firstobs=2;
  length city $ 39;
  input city & JanTemp JulyTemp RelHum Rain Mortality Education PopDensity pct_NonWhite pct_WC pop pop_per_house income HCPot NOxPot SO2Pot NOx;
run;
ods rtf bodytitle file="&DATA_DIR\Display-3.29.rtf";
proc univariate data=SMSA_from_txt;
  var JanTemp;
  id city;
run;
ods rtf close;
```

The output in Display 3.30 gives information about the number of observations, central values, and dispersion measures. It includes a statistical test of whether the mean temperature is zero.
