# 11.9.3 Case Study 3: SAS/IML matrix manipulations and invocations of SAS/STAT procedures

SAS/IML Studio enables you to interact with SAS/STAT. In Display 11.25, a data object containing the SMSA data is created. A subset of the variables is written to the SAS server for use with PROC REG, which then creates a data set with residuals. The residuals are copied back to the SAS/IML Studio client data object, and a scatter plot of Residuals versus the predictor variable Education is produced. A horizontal reference line is added at zero. The submit and endsubmit pair (also known as a submit block) in IMLPlus is required to process SAS/STAT commands on the SAS server.

# Display 11.25 Exporting a data object, fitting a regression, adding residuals, and generating a plot

```
declare DataObject dobj;
dobj=DataObject.CreateFromFile("C:\Users\baileraj.IT\DASL_SMSA.sas7bdat");
DataTable.Create(dobj);

/* follows Ch 4-6 in SAS/IML Studio 3.2 for SAS/Stat Users */
dobj.WriteVarsToServerDataSet({"Education", "Mortality"},
"work", "SMSA", true);

submit;
proc reg data=SMSA;
  model Mortality = Education;
  output out=resout r=residuals;
run;
endsubmit;

ok = CopyServerDataToDataObject( "work", "resout", dobj,
("residuals"),  /* name on SAS server */
{"residuals"),  /* name in DataObject */
("Residuals"),  /* label in DataObject */
true            /* replace if existing variable has this name */
);

declare ScatterPlot resplot;
resplot = ScatterPlot.Create(dobj, "Education", "Residuals");
resplot.DrawUseDataCoordinates();
resplot.DrawLine(0, 0, 1, 0);
```

In Display 11.26, PROC REG output is displayed in SAS/IML Studio. Selecting points with relatively large or small residuals identifies New Orleans as having a mortality rate appreciably higher than what a linear prediction based on education would suggest (i.e., a large positive residual). Lancaster, PA, and York, PA, have mortality rates appreciably lower than what a linear prediction based on education would suggest.
