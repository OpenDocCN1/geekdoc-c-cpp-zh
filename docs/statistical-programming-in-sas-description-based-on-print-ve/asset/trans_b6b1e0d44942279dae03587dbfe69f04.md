## 2.1 数据集的临时与永久状态

SAS中的数据集具有两部分名称。然而，如果你希望它们仅在SAS的特定会话期间存在，那么它们可以具有单部分名称（有点像巴西足球的巨星）。如第1.4节“什么是SAS数据集”中所讨论的，SAS数据集是矩形对象，其中行是不同的观测值，列是不同的变量。将永久SAS数据集视为驻留在称为SAS库的集合中。两部分名称包括库名和数据集名，以句点分隔。例如，myfiles.nitrofen具有指向包含我的SAS数据集的子目录的库名myfiles。第二部分名称是nitrofen，即特定的数据集。nitrofen数据集可能包括图形和格式的目录。提示：最好为图形、格式等有单独的位置。 （为提供一点背景，nitrofen是一种除草剂。该数据集包含水蚤Ceriodaphnia dubia暴露于不同浓度的nitrofen的nitrofen浓度-生殖反应数据。¹）

¹ Nitrofen数据集来自Bailer, A. John., and James T. Oris. 1994. “Assessing Toxicity of Pollutants in Aquatic Systems.” Chapter 2 in Case Studies in Biometry. Nicholas Lange, Louise Ryan, Lynne Billard, David Brillinger, Loveday Conquest, Joel Greenhouse, eds. New Jersey: John Wiley & Sons, Inc. Reprinted with permission of John Wiley & Sons, Inc.

假设你有一个名为nitrofen.sas7bdat的SAS数据集。 （记住，.sas7bdat是Windows中SAS数据集的常见扩展名。）nitrofen.sas7bdat数据集存储在一个指向服务器上位置的路径规范的文件夹中。例如：

如果不想永久保存数据集，而只想在当前SAS会话中使用它怎么办？其他章节中有大量临时文件存储的示例。例如，Display 1.2中模拟简单线性回归数据集的代码（在Display 2.3中以最小修改重现）生成一个名为WORK.lin_reg_data的数据集（其两部分名称），或更简单地lin_reg_data（其单部分名称）。

### Display 2.3 生成临时数据集的示例代码

```
data lin_reg_data;
  call streaminit(32123);
  do x = 0 to 10 by 1;
    y = 3 + 2*x + 2*RAND('NORMAL');
    output;
  end;
run;

ods rtf bodytitle file='C:\Users\baileraj.IT\Desktop\ch2-fig2.3.rtf';
proc sgplot data=lin_reg_data;   * or equivalently, data=work.lin_reg_data;
  scatter y=y x=x;
run;

proc reg data=lin_reg_data;
  model y=x;
run;
ods rtf close;
```

Display 2.3代码中生成的数据集包含11个观测值和两个变量（X，Y）。SAS日志的一瞥证实了这一点，并显示以下消息：

```
NOTE: The data set WORK.LIN_REG_DATA has 11 observations and 2 variables.
```

WORK库是SAS在SAS会话执行期间分配的临时存储。lin_reg_data是在本次SAS会话期间存储在此临时库中的数据集。关闭SAS后，lin_reg_data数据集就会消失到虚拟蒸汽中，或者如果你愿意的话，消失到电子以太中。
