# 11.10 Summary

In this chapter, a matrix definition and basic manipulations are provided. Importing SAS data sets for processing in SAS/IML is discussed. SAS/IML solutions for familiar problems are reviewed. This chapter closes by introducing one of the most incredibly powerful enhancements to SAS. SAS/IML Studio enables you to dynamically explore data and provides a tool to tap into the resources and packages of R.

This chapter does not comprehensively cover matrix manipulation, SAS/IML, or SAS/IML Studio. If you are interested in learning more, dig into SAS/IML documentation. In addition, SAS conference proceedings have many of these topics included in papers and presentations.
