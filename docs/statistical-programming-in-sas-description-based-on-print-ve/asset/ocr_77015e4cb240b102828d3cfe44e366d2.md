+   2. Write a SAS/IML module to conduct a small Monte Carlo simulation that shows how the CI for the mean performs (e.g. coverage probability properties) when estimating the mean of an exponential distribution. Recall that the formula for a confidence interval for a population mean is
+   
+   $$\bar{Y} \pm t(1-\alpha/2,\,n-1)\, s/\sqrt{n}$$
+   
+   Select at least three values of n for this illustration (say, n=15, 30, and 50).
+   
+   Hint: You can generate exponential random variables a few different ways in SAS/IML. You can use randgen with exponential to specify a standard exponential (mean=1), and then multiply these deviates by lambda to get a random exponential (mean=lambda). The following code generates 20 random deviates from an exponential distribution with mean=6:

```
proc iml;
    lambda = 6;
    mydevs = J(20,1,0);  * initialize vector to contain deviates;
    call randseed(9753);
    call randgen(mydevs,'exponential');
    mydevs = 6*mydevs;

    mean_dev = sum(mydevs)/nrow(mydevs);

    print mean_dev;
quit;
```
