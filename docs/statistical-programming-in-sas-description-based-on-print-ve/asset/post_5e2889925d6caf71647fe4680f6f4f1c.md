You might want to consider how to perform a test of equal slopes. If you have a data set named DSN, which includes a response variable named RESPONSE, a classification variable named GROUP, and a covariate named X, then the test of equal slopes can be constructed using PROC GLM. The following statements conduct this test:

```
proc glm data=DSN;
    class GROUP;
    model RESPONSE = X GROUP  X*GROUP;
run;
```

## 5.3 ANOVA Models—PROC GLM for a One-Way ANOVA

In experimental studies, comparing average responses between different treatments or different populations is often the focus. Data analyzed in these models stem from random samples from g distinct populations or from randomly assigning one of the g treatments to experimental units in a sample. Assuming comparable variability in the different groups, a test of the null hypothesis of equal means in the g groups (i.e., H₀: μ₁ = ... = μ_g) can be tested using an F test, which tests the ratio of variation between groups relative to variability within groups. (See Kutner et al. (2004) for a discussion of ANOVA model tests and related topics.) (Recall that g=2 corresponds to the familiar t-test, which, in this case, is the pooled variance version.) A model for the response of the jth observation in the ith group (i=1,2,...,g (treatments or populations), j=1,2,...,n_i (replications), and Y_ij) is the cell means model (Y_ij = μ_i + ε_ij). This model can be written in the form of an effects coding model as Y_ij = μ + α_i + ε_ij, where the interpretation of μ can depend on the coding of α_i. For example, if α_g =0, then μ corresponds to the mean in the gth group (reference cell coding). If Σ α_i=0, then μ corresponds to an overall mean. (For more information, see problem 3 in Section 5.7 “Exercises.”) As with regression models, ε_ij ~ independent N(0, σ²).

### 5.3.1 Comparing bacterial growth under different packaging conditions using a one-way ANOVA model

It is easy to get consensus that bacterial growth should be inhibited in packaged meats. It might be that different packaging conditions provide different degrees of inhibiting bacterial growth. In the example shown in Display 5.16, the data described and analyzed by Kuehl (1994) are examined.¹ The mean log-bacterial growth for g=4 is described for different packaging (plastic, vacuum, mixed, and CO₂), with nᵢ=3 replicates for each type of packaging.

## Display 5.16 Fitting a one-way ANOVA model

```
/* Bacteria in meat under 4 different conditions */
options ls = 75;
data meat;
    input condition $ logcount @@;
datalines;
Plastic    7.66    Plastic    6.98    Plastic    7.80
Vacuum     5.26    Vacuum     5.44    Vacuum     5.80
Mixed      7.41    Mixed      7.33    Mixed      7.04
Co2        3.51    Co2        2.91    Co2        3.66
;
run;

title "bacteria growth under 4 packaging conditions";

ODS RTF file='C:\Users\baileraj.IT\Desktop\oneway-output.rtf';
ods listing image dpi=300;
ods graphics on / width=4.5in;
proc sgplot data=meat;          * graphical comparisons;
    vbox logcount / category=condition;
run;

proc glm data=meat order=data plot(unpack)=diagnostics;
    title2 "fitting the one-way anova model via GLM";
    class condition;
    model logcount = condition;
    means condition / bon tukey scheffe cldiff lines;
    lsmeans condition / cl pdiff;
    lsmeans condition / cl pdiff adjust=Tukey;
    contrast 'plastic vs. rest' condition 3 -1 -1 -1;
    output out=new p=yhat r=resid stdr=eresid;
run;

proc sgplot data=new;          * plots for model checking;
    title2 "residual analyses";
    scatter x=yhat y=resid;
    refline 0 / axis=y;
run;

proc univariate data=new noprint;
    histogram resid / normal;
    qqplot resid / normal;
run;
ods graphics off;

ODS RTF CLOSE;
```
