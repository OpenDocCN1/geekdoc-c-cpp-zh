# 6.4 Graphing with Styles and Templates

ODS styles are used to “control the colors and general appearance of all graphs and tables” (Kuhfeld 2009). Default ODS styles can be used for most applications. The default styles produce a graph with varying colors, which might not be acceptable for some journal applications.
