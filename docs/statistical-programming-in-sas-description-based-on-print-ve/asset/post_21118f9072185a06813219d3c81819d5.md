The data set myanno contains the commands for displaying the annotation. The length declaration of 8 ensures that the function label will not be truncated to four characters because the first value of function is the four-character value move, while the declaration of the text length allows for a longer text string to be displayed. (A length of 8 accommodates any of the possible function arguments.) The retain statement does double-duty. It keeps the values of xsys and ysys in place for all of the observations that are defined in subsequent lines. And, it assigns the value 2 to these variables. The xsys and ysys variables define the coordinate axis definition that is used by coordinate (x,y) pairs in the annotate data set. A value of 2 is an absolute scale that corresponds to the data value scale. The XSYS and YSYS values 1 through 6 correspond to an absolute scale, while {7, 8, 9, A, B, C} correspond to a relative scale. You might find 2 to be the most useful value for the annotation of statistical figures or for the annotation of scales related to the percentage of the data area (1, 7) or to the percentage of the graphics output area (3, 9). There are many graphics tasks accomplished by other functions (e.g., POLY, POINT, BAR, SYMBOL, DRAW2TXT, PIE, and FRAME).

Let’s consider an example that is more complicated. The odds ratio (OR) is a common summary reported in logistic regression and for epidemiological investigations. It is not uncommon to see an approximate confidence interval (CI) produced by exponentiating a symmetric CI that is constructed for the log[OR]. Suppose an estimate OR=2 is observed with an estimated SE{log[OR]}=0.2. The approximate 95% CI for OR would be exp[log(2) ± 1.96*0.2]. Wouldn’t it be neat to construct a figure showing this? This figure would do the following:

- Illustrate the (OR, log[OR]) relationship.
- Map OR=2 to its corresponding log[OR] value.
- Move ± 1.96 SE{log[OR]} from this value.
- Move back to the OR-log[OR] trace.
- Project back to the OR axis for the CI.

Display 7.9 provides the code to construct this figure. The figure is shown in Display 7.10.

## Display 7.9 Constructing a CI for an OR based on exponentiating a symmetric CI

```
/* generate a profile of [OR, log(OR)] values */
data or_stuff;
   do or=0.01 to 5 by .01;
      logor = log(or);
      output;
   end;
run;

goptions reset=global; * often a good idea, especially if doing a lot of graphs;

/* interpolate btwn [OR, log(OR)] values and set up axes */
symbol interpol=join c=black; * always specify color in symbol stmt;
axis1 label=("Odds Ratio");
axis2 label=(angle=90 "Log(Odds Ratio)");

/* set up annotate data set with arrows and text to illustrate the CI idea */
data myanno;
length function $ 8 text $ 7; * good habit b/c max fcn length=8;
retain xsys "2" ysys "2" function SE;
SE = .2;
function="move"; x=2; y=-5; output;
function="arrow"; x=2; y=log(2); output; * from OR to logOR;
function="arrow"; x=.01; y=log(2); output; * back to y-axis;

function="draw"; x=.01; y=log(2) + 1.96*SE; line=2; output; * upper CI;
function="arrow"; x=exp(log(2) + 1.96*SE); y=log(2) + 1.96*SE; output;
function="arrow"; x=exp(log(2) + 1.96*SE); y=-4.5; output;

function="move"; x=.01; y=log(2); output; * lower CI;
function="draw"; x=.01; y=log(2) - 1.96*SE; output;
function="arrow"; x=exp(log(2) - 1.96*SE); y=log(2) - 1.96*SE; output;
function="arrow"; x=exp(log(2) - 1.96*SE); y=-4.5; output;
function="label";
        x=exp(log(2) - 1.96*SE); y=-4.75; text="LCL OR"; output;
        x=exp(log(2) + 1.96*SE); y=-4.5; text="UCL OR"; output;
        x=2.2; y=-2; text="Step 1"; output;
        x=1; y=log(2) + .25; text="Step 2"; output;
        x=0.5; y=log(2) - 1.96*SE; text="Step 3a"; output;
        x=0.5; y=log(2) + 1.96*SE + .25; text="Step 3b"; output;
        x=3.2; y=-2; text="Step 4a"; output;
        x=1.2; y=-2; text="Step 4b"; position="<"; output; * right justify text;
run;

/* produce the graph with annotation */
ods rtf bodytitle file="C:\Users\baileraj.IT\Desktop\fig7p9.rtf";
proc gplot data=or_stuff;
   plot logor * or / annotate=myanno haxis=axis1 vaxis=axis2;
run;
quit;
ods rtf close;
```

New elements of the annotate data set include:

- Use of the `arrow` function.
- Use of `line=2` to request a dashed line in the `draw` function.
- Use of `position="<"` to request that the text be right-justified in the label.
- Use of `retain` to assign the `label` function to all annotate observations that follow.

## 7.4 Case Study: Comparing Distributions of Responses

In this section, many of the ideas described previously are applied to graphics to help you understand the differences in the distribution of responses between experimental conditions. You will use the nitrophen data set, which contains nitrophen-concentration-reproductive response data on water fleas (Ceriodaphnia dubia) exposed to varying concentrations of nitrophen.² (Hey, you might be sick of these data, but you should now be familiar enough with the data that you can focus on the code!) This data set includes 10 observations at each of the five concentrations. You want to construct graphs to display how the distribution of responses changes across concentration conditions. You want to present the data values and the appropriate summary statistics. In the first figure, you produce a scatter plot of the responses versus the concentration variable with reference segments at the mean responses. In the second figure, you produce a scatter plot with superimposed box plots for the responses at each concentration.

Some of the key actions in the code in Display 7.11 that apply to both of the scatter plots include the following:

- Define a jitter so that all of the observations can be observed.
- Rotate the y-axis label using the AXIS statement.
- Define the label for the x-axis and the range of the values on the x-axis (the LABEL and ORDER parts of the AXIS2 statement).
- Suppress the tick marks and scale values on the x-axis (MINOR=NONE, MAJOR=NONE, and V=NONE in the AXIS2 statement).

In the first scatter plot, an annotate data set is used to label concentration values above the x-axis, and to draw and superimpose segments at the mean response values. In the second scatter plot, SYMBOL1 selects the plotting character for the scatter plot, and SYMBOL2 selects a box plot interpolation and specifies the width of the boxes (bwidth=8). Again, an annotate data set is used to label the concentration values above the x-axis. Because jittering is used to modify values, annotate data sets are used to define the x-axis values in these two scatter plots. Try this at home: Can AXIS statements produce these scatter plots?
