The SYMBOL statement can explicitly specify what plotting character should be used in a scatter plot. For example, if you want a dot as the plotting character, specify:

```
symbol1 value=dot cv=black;
```

An analogous specification of the marker is in the MARKERCHAR option in PROC SGPLOT or PROC SGPANEL. The MARKERCHAR option references a column, and the value of that column (string or numeric) is used as a marker. You might have noticed the frequent use of GOPTIONS in the previous code.

```
goptions reset=global;
```

Resetting graphics options is a good idea. Once graphics options are set, they stay set until you reset them. As a result, the options set for one plot can unintentionally affect later plots. You might be surprised to know that SAS can cycle through particular options before recognizing other options. If you have graphics code that is not varying a particular SYMBOL option that you have set (e.g., plotting character), but another option is varying (e.g., color), you might try defining the features to be the same in each SYMBOL statement (e.g., set CV=BLACK in each SYMBOL statement).
