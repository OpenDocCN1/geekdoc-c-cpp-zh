## 9.2 Case Study 1: Monte Carlo p-Value for Test of Spatial Randomness

A p-value, the probability of observing a test statistic at least as extreme as the observed value of the test statistic when the null hypothesis is true, is commonly reported in statistical inference. When the sampling distribution of a test statistic has a familiar form, standard statistical distributions (e.g., t or F) can be used to calculate the p-value. In other cases, it might be very difficult to calculate a p-value if the test statistic does not have a familiar form. In the following example, arrays are used in a Monte Carlo calculation of a p-value based on an average nearest-neighbor test statistic.

The spatial distribution of a quantity of interest might be clustered or regularly spaced. Clustered observations tend to have less distance between observations than completely spatially random (CSR) observations. Regularly spaced observations tend to have more distance between observations than CSR observations. While more complicated test statistics should be considered in this context (Ripley 1981, Waller and Gotway 2004), a very simple statistic—average nearest-neighbor distance—is selected. Define the nearest-neighbor distance for observation i as the following:

d(i)=min(d_i1, d_i2, ..., d_i(i-1), d_i(i+1), ..., d_in) where d_ij=Euclidean distance between observation i and observation j (i≠j).

Assume that there are n observations in the data set. The average nearest-neighbor distance is Σd(i)/n.

Let’s see what happens when there is a square plot of n=4 trees that are located at coordinate points (.25, .65), (.25, .75), (.35, .65), and (.35, .75). (Without giving away the punch line, you can see that these coordinate points are clustered in the unit square. The punch line was just given away! Determine whether the analysis confirms the interocular trauma test.)

Here is the strategy for this analysis:

- 1. Determine nearest-neighbor distances for the observed data.
- 2. Calculate the average nearest-neighbor distance for the observed data.
- 3. Assuming the null hypothesis of CSR observations is true, generate a sample of observations that are randomly distributed in the region of interest.
- 4. Calculate the average nearest-neighbor distance for this simulated data.
- 5. Repeat steps 3 and 4 many times.
- 6. The Monte Carlo p-value is the proportion of generated samples that are more extreme than the observed data. To test for clustering, determine whether the average nearest-neighbor distance from the simulated data is less than the average nearest-neighbor distance from the observed data.

These six steps can be thought of as pseudo-code for the program to calculate the Monte Carlo p-value for detecting clustering. The recommendation in the previous chapter is to flesh out the pseudo-code. In Display 9.5, these six steps are identified with comments in the program implementing this analysis.

## Display 9.5 Calculating a Monte Carlo p-value to detect clustering

```
/* enter the observed data into data arrays  */
data plot_obs;
    array xobs(4) xobs1-xobs4;
    array yobs(4) yobs1-yobs4;
    do idat = 1 to 4;
        input xobs(idat) yobs(idat) @@;
    end;
datalines;
.25 .65 .25 .75 .35 .65 .35 .75
;
run;

/* STEP 1: Determine nearest-neighbor distances for observed data  */
data plot1;  set plot_obs;
    array xobs(4) xobs1-xobs4;
    array yobs(4) yobs1-yobs4;
    array nnobs(4) nnobs1-nnobs4;

/* Determine nearest-neighbor distance for each point  */
sumnnobs = 0;
do i=1 to 4;      * find nearest-neighbor distance for each point;
    nnobs(i) = 100;  * initialize distances to be large;

/* calculate the Euclidean distance between the ith tree and
   all others - save the smallest value as the distance to its
   nearest neighbor and compare the ith point to all others.
*/
    do j=1 to 4;
        d=sqrt( (xobs(i)-xobs(j))**2 + (yobs(i)-yobs(j))**2 );
        if (d<nnobs(i)) and (d>0) then nnobs(i)=d;
    end;
/* Note: Each point is also compared to itself - thus, d=0
       omitted from updated of nearest neighbor distance. */
    sumnnobs=sumnnobs+nnobs(i);
end;

/* STEP 2: Calculate average nearest-neighbor distance for observed data  */
avgnnobs = sumnnobs/4;
run;

/* Simulate plots under CSR  */
data mccsr1; set plot1;
    array xobs xobs1-xobs4; * observed data;
    array yobs yobs1-yobs4;
    array xsim xsim1-xsim4; * CSR simulated data;
    array ysim ysim1-ysim4;
```

## Display 9.5 (continued)

```
array nnobs nnobs1-nnobs4; * observed NN distances;
array nncsr nncsr1-nncsr4; * simulated NN distances;

/* STEP 3: Generate many CSR plots with four trees */

* initialize counters of nn avg dist le or ge than observed;
numle = 0;
* numge = 0; * commented out since focus on clustering here;

nsim = 4000;      * user-specified option;
seed1 = 12345;    * if =0, then uses time since midnight;
call streaminit(seed1);

do isim = 1 to nsim;

/* STEP 5: Repeat steps 3 and 4 many times */
do ii = 1 to 4;
    xsim(ii) = RAND('uniform');
    ysim(ii) = RAND('uniform');
end;

/* STEP 4: Calculate average nearest-neighbor distance for simulated data */

sumnncsr = 0;
do i=1 to 4;
    nncsr(i) = 100;  * initialize;

    do j=1 to 4;
        d=sqrt( (xsim(i)-xsim(j))**2 + (ysim(i)-ysim(j))**2 );
        if (d<nncsr(i)) and (d>0) then nncsr(i)=d;
    end;

    sumnncsr=sumnncsr+nncsr(i);
end;
avgnncsr = sumnncsr/4;

/* Accumulate counts of patterns consistent with clustering */
ile = (avgnncsr <= avgnnobs);
numle = numle + ile;

* ige = (avgnncsr >= avgnnobs);
* numge = numge + ige;

drop i j ii xobs1-xobs4 yobs1-yobs4 nnobs1-nnobs4
      sumnnobs sumnncsr;
output;
end;      * of the isim - simulation loop;
```

## 9.3 Remembering Variable Values across Observations

It is usually straightforward to manipulate variables within a record. What is tricky is manipulating variables across records. SAS initializes each variable in a data set to missing when it starts to process a new observation. However, you might want SAS to remember a variable’s value when it starts to process a new observation. The RETAIN statement achieves this objective. It is easier to understand the RETAIN statement when you see it in action.
