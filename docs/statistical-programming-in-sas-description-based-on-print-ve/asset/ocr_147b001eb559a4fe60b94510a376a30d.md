ODS commands exist to enumerate all of the tables and output objects produced by a procedure. And, ODS commands exist to select output objects. A list of ODS table names is included as part of PROC REG in the SAS online documentation. For example, in the SAS online documentation for PROC REG, the ODS tables produced by PROC REG are listed with short descriptions and options.

The ODS TRACE statement enables you to see all of the names of the output objects produced. ODS SELECT and ODS EXCLUDE enable you to select output objects. ODS TRACE lists all of the output objects produced by statements in a particular program. By default, this information is listed in the SAS log. Or, you can list output objects in the SAS Output Window using ODS TRACE with the ON /LISTING option.

```
ods trace on /listing;
proc reg;
  model y = x;
run;
ods trace off;
```
