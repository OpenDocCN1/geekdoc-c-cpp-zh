# 2.2.5 Reading Excel spreadsheets directly

While you can save an Excel file as a comma-separated values file, and read it in using the methods in the previous section, it is always easier to read data in without having to perform data-manipulation gymnastics. If you have SAS/ACCESS software licensed on your computer, then the engines for reading Excel files and other files such as relational databases are available for use in LIBNAME statements. In addition, the Import Wizard enables you to select an Excel file and read it into a SAS data set. Code for both methods of reading in an Excel file is shown in Display 2.12.

# Display 2.12 Importing an Excel spreadsheet using PROC IMPORT or a LIBNAME statement with the EXCEL engine specified

```
/* Assumes SAS/ACCESS engines are available */
/* IMPORT code produced by the IMPORT WIZARD */

PROC IMPORT OUT= WORK.DASL_FROM_EXCEL2
    DATAFILE= "C:\Documents and Settings\baileraj\Desktop\DASL-SMSA.xls"
    DBMS=EXCEL REPLACE;
    SHEET="Sheet15";
    GETNAMES=YES;
    MIXED=NO;
    SCANTEXT=YES;
    USEDATE=YES;
    SCANTIME=YES;
RUN;

/* ... via EXCEL engine with LIBNAME */
options nodate;
title ;
```
