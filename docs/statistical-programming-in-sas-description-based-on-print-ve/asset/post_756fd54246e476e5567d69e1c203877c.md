## 8.3 Recoding and Transforming Variables in a DATA Step

The DATA step is the hub of a lot of action defining, redefining, and transforming variables for later analyses. Common transformation examples include a variance-stabilizing or linearizing transformation of a response variable, the definition of higher order terms for a polynomial regression, and the construction of indicator variables. Two of these tasks are highlighted using the nitrofen data³ as coded in Display 8.18.

## Display 8.18 Data transformations before fitting a polynomial regression model

```
data nitrofen;
infile 'C:\Users\baileraJ.IT\Desktop\ch2-dat.txt' firstobs=16 expandtabs;
input 017 conc 3. 049 total 2.;
sqrt_total = sqrt(total); * transformed response variable;
cconc = conc - 157; * construct mean-centered concentration;
cconc2 = cconc*cconc; * quadratic term;
run;
ods rtf BODYTITLE file="C:\Users\baileraJ.IT\Desktop\Display-8-18.rtf";
ods graphics on;
proc reg data=nitrofen;
model sqrt_total = cconc cconc2; * fit the polynomial reg. model;
run;
ods graphics off;
ods rtf close;
```

The mean-centered concentration was determined in a different program and hard coded here. (It would be slick to use PROC STANDARD to construct a variable containing the mean-centered version of the concentration variable, which you then output to a new data set. Can you figure out how to do this at home?) Even more interesting alternatives to the DATA step programming of the transformation include the following:

- PROC GLM with MODEL SQRT_TOTAL=CONC | CONC;
- PROC TRANSREG with MODEL POWER(TOTAL / PARAMETER=0.5)=PSPLINE(CONC / CENTER DEGREE=2);

ODS graphics associated with this fitted polynomial regression model are shown in Display 8.19.

In this model, the count response is square-root transformed. Another common transformation involves constructing indicator variables based on the values of a variable. One of the easiest ways to define these indicator variables is to conduct a Boolean comparison whose results are coerced into numeric values. Here, if the statement is true, then the value 1 is assigned. If the statement is false, then the value 0 is assigned. In Chapter 5, an indicator variable was constructed to allow dinosaurs to have a body weight and brain weight relationship that differed from other animals in the data set. The following statements were used to construct the indicator variable:

```
idino = 0;                * define the indicator of dinosaurs;
if (species="diplodoc" or species="tricerat" or
    species="brachios") then
idino=1;
```

The indicator idino is initialized to 0 for all observations, and reassigned to 1 if the condition (species="diplodoc" or species="tricerat" or species="brachios") is true. Here is an alternative statement that avoids the initialization and condition checking:

```
idino = (species="diplodoc" or species="tricerat" or
    species="brachios");
```

This statement assigns idino to 0 when the condition is false, and idino to 1 when the condition is true. It is important to recognize that case matters in these comparisons. If Diplodoc is the value of species, then idino is 0 because Diplodoc differs from diplodoc.

For the next indicator variable example, the packaging and log-bacterial growth data⁴ is used. Suppose you want to use linear regression with indicator variables as an alternative to a one-way ANOVA model. In the data, there are four different packaging conditions. An indicator variable is defined for each condition in the code in Display 8.20. The CLASS statement in PROC GLM automatically produces indicator variables for an ANOVA model.

## Display 8.20 Defining indicator variables for different conditions to fit an ANOVA model

```
options nodate formdlim="-";
data meat;
    input condition $ logcount @@;
    iPlastic = (condition ="Plastic");
    iVacuum = (condition="Vacuum");
    iMixed  = (condition="Mixed");
    iCO2    = (condition="Co2");
    datalines;
Plastic    7.66  Plastic    6.98  Plastic    7.80
Vacuum     5.26  Vacuum     5.44  Vacuum     5.80
Mixed      7.41  Mixed      7.33  Mixed      7.04
Co2        3.51  Co2        2.91  Co2        3.66
;
run;

title "bacteria growth under 4 packaging conditions";

ODS RTF bodytitle file="C:\Users\baileraj.IT\Desktop\Display-8-20.rtf";

proc print data=meat;
title "Print to check indicator variable construction";
run;

proc reg data=meat;
title "Regression with indicator variables: alt. to one-way anova model";
    model logcount = iPlastic iVacuum iMixed;
run;

proc glm data=meat;
title "One-way ANOVA model";
    class condition;
    model logcount = condition;
run;

ods rtf close;
```
