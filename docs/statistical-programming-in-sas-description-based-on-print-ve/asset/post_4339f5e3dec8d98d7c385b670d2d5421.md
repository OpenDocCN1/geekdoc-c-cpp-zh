## 5.1 Overview of Modeling

SAS provides many regression procedures. These include procedures for constructing linear models for normally distributed responses (e.g., REG, GLM, and MIXED), non-normal regression models (e.g., GENMOD, LOGISTIC, COUNTREG, and GLIMMIX), nonlinear regression models (e.g., NLIN and NLMIXED), failure time models (e.g., LIFEREG and PHREG), and other regression methods (e.g., LOESS, ROBUSTREG, QUANTREG, and TRANSREG). Other procedures address problems in the analysis of time series data (e.g., TSCSREG or ARIMA) or structural equations (e.g., CALIS). Some general modeling procedures enable you to fit models defined by a set of differential equations (MODEL). Discussing the statistical methods in these procedures is beyond the scope of this chapter. (It is beyond the scope of a single statistics course, for that matter.) As a result, this chapter emphasizes linear models for responses that are assumed to be normally distributed. A little statistical background is given for linear regression and basic ANOVA models. Then, SAS procedures for addressing these tasks are introduced. Examples illustrate the features of PROC REG and PROC GLM. This chapter is not intended to be a substitute for a modeling introduction in a regression course. However, some basic statistical ideas are introduced as a context for describing model specification in SAS. A good regression or linear model book such as Kutner et al. (2004) is a great companion to this chapter. In addition, this chapter provides a flavor for how models are specified. You should be able to generalize when working with other procedures. Muller and Fetterman (2002) provide an extensive introduction to fitting linear models using SAS.

## 5.2 Linear Regression Models

One of the best graphical methods for displaying the relationship between two numeric variables is the scatter plot. (For illustrations of the scatter plot, see Chapter 3.) While a picture is worth a thousand words, you might need more than a picture if you want to generate predictions and do inference. So, what is the simplest relationship that might exist between two variables? A line is the answer. While the simple equation Y = m X + b is often used to introduce linear relationships in algebra, a simple equation isn't readily available in statistical modeling, especially when you have more than one X variable. As a result, the linear model is rewritten Y = β0 + β1 X with the slope as β1 instead of m, and the y-intercept as β0 instead of b. To further complicate the statistical modeling of relationships, the Y value at each X value is not expected to be the same. In other words, responses are expected to be random instead of fixed. So, a term to allow for responses with the same X value to vary is added to the equation, Y = β0 + β1 X + ε. In this equation, ε represents the random error term. Y is the response variable (or dependent variable). X is the predictor variable (or independent variable or covariate).
