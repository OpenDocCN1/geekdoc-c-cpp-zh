The proportion of test statistics from the randomization test that exceed (are at least as extreme as) the observed test statistic is the randomization p-value. As an alternative to complete randomization, you can take a sample from the (n₁ + n₂ choose n₁) possible assignments of labels to observations. You calculate a p-value from this sample. The code to accomplish this task is shown in the following example.

Data are read from the member NITROFEN of an external permanent SAS library. These data are the number of young produced by Ceriodaphnia dubia (water fleas) exposed to varying concentrations of nitrofen.¹ The control condition and 160 µg per l condition are selected for analysis.

```
libname class 'C:\Users\baileraj.IT\Desktop';

data test; set class.nitrofen;
    if conc 0 | conc=160;
run;

proc print data=test;
    title "NITROFEN: print of (0, 160) concentrations";
    var conc total;
run;
```
