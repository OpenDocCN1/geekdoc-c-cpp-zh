## 3.2 Statements That Can Modify the Output of Most Procedures

Many statements can appear throughout a SAS program. These statements enable you to annotate output (e.g., TITLE and FOOTNOTE) or expand variable names or values of variables (e.g., LABEL and FORMAT). Examples illustrate formats defined in a DATA step versus formats applied as part of a PROC step along with TITLE.

The program presented in Display 3.7 sets up system options so that the output does not have a date stamp (NODATE), is not centered (NOCENTER), has a width of 64 (LS=64), starts renumbering output at page number 1 (PAGENO=1), and uses an equal sign as a page separator (FORMDLIM='='). The data block enters three observations from DATALINES. (By the way, the data set name d1 isn't a very exciting data set name, and after I preached about this in Chapter 1 I feel guilty. Oh well, this is a toy example for an illustration.) The @@ in the INPUT statement tells SAS to continue reading a data line even after values for the new variables X and Y are found. This allows multiple observations to be entered on each line.

You might be interested in attaching formats to the values of variables. Assigning formats is discussed in detail in Chapter 8, but a few basic uses of formats are discussed in this chapter. Formats can be attached to variables using an assignment in a DATA step. Or, they can be temporarily attached to a variable using a statement in a PROC. Attaching formats to variables is shown in Display 3.7.

The variable Y is defined with a FORMAT statement as part of the data block. The assigned format —dollar6.2— displays the values of Y as currency with a $ sign attached. The 6.2 in the format says that six total spaces are allocated for the output (including the $ sign and decimal point) with two digits to the right of the decimal point. (More discussion about formats follows in later chapters. However, this chapter gives you a taste of using formats.) This assigned format affects any procedure that references Y in this data set. In contrast, an assigned format is defined for variable X in the second PROC PRINT. When the format is assigned in the procedure, it operates for the duration of that procedure and not beyond. Titles are placed in the output using the TITLE and TITLE2 statements. Titles appear on every output page until they are reset. Up to 10 titles can appear on an output page. While TITLE specifies the first title line for the output, the statement TITLEn specifies the nth title line (n=2,...,10). More than three title lines (give or take) might limit the actual output on a page. Lines can be added to the bottom of each page of output by using the FOOTNOTEn option. This parallels TITLEn, with the exception that you are specifying text to include at the foot of each page.

# Display 3.7 Code with a few formatting options

```
options formdlim='=' pageno=1 ls=64 nocenter nodate;
data dl;
  input x y @@;
  format y dollar6.2;
  datalines;
1 2 4 3 5 6 12345 123456
;
run;

proc print data=dl;
  title "Y formatted in DATA";
run;

proc print data=dl;
  title2 "X now formatted in the 2nd PROC PRINT";
  format x dollar12.2;
run;

proc print data=dl;
  title2;
run;
```

The output reflects the options requested in the OPTIONS statement. The second title as requested by TITLE2 in the second PROC is in the output. The TITLE requested in the first PROC PRINT applies to the next two PROCs. The format defined for Y in the DATA step applies to all PROCs, while the format defined for X in the second PROC applies to only the second PROC. Question: “What happened to the format of Y in the fourth observation?” The problem is that the width of the format—6 for Y—does not accommodate the value of the variable. In this case, the output displays the value of the variable without the $ sign and decimals.

## 3.3 Defining Your Own Formats for Variable Values

In the previous example, some of the formats that are internally defined within SAS (e.g., the DOLLARW.D format) are used. Many other formats are internally defined within SAS, including formats for processing and displaying dates and times. There are times when you want to define your own formats to display variable values. In these cases, the FORMAT procedure provides this flexibility.

An example data set from the StatLib server is used in the next example (and throughout the rest of the book). The data set describes the results of an experiment examining the toxicity of nitrofen. Nitrofen is an herbicide used on rice, and the data examines the impact of nitrofen on *Ceriodaphnia dubia*, which are water fleas.

The URL for the data set on the StatLib server—http://lib.stat.cmu.edu/datasets/csb—contains a file describing the variables in the data set (ch2.txt), a file with the data (ch2.dat), and a file with a SAS program for reading the data. The variables include an animal ID, nitrofen concentration, the number of young produced in each of the three broods, and a total number of young produced in the three broods. Toxicity is suggested if reproductive output decreases with increasing herbicide concentration. A discussion and analysis of these data can be found in Bailer and Oris (1994). OK, enough background. The data set from the StatLib server was saved to my desktop and renamed ch2-dat.txt.

In the program in Display 3.9, a format is defined to map the values of a numeric variable to **NONE** if the variable has VALUE=0, and to **SOME** if the variable has a value of 1 or larger. The range of the variable, 1—HIGH, uses a keyword HIGH, indicating the maximum value in a data set. This user-defined format TOTFMT is then applied to a newly defined variable CBROOD3 in the DATA step. The data for the conc=235 condition are displayed.

# Display 3.9 User-defined format using PROC FORMAT

```
```sas
proc format;
    value totfmt       0='none'
                   1-HIGH='some';
run;

data nitro tox;
    infile 'C:\Users\bailera\JT\desktop\DT-Book 3\ch2-dat.txt'
        firstobs=16 expandtabs missover pad;
    input @9 animal 2. @17 conc 3. @25 brood1 2.
          @33 brood2 2. @41 brood3 2. @49 total 2.;

    cbrood3 = brood3;
    format cbrood3 totfmt.;
    label animal = 'animal ID number';
    label conc   = 'Nitrofen concentration';
    label brood1 = 'number of young in first brood';
    label brood2 = 'number of young in 2nd brood';
    label brood3 = 'number of young in 3rd brood';
    label total  = 'total young produced in three broods';
run;

proc print data=nitro; tox;
    where conc=235;
run;
```
