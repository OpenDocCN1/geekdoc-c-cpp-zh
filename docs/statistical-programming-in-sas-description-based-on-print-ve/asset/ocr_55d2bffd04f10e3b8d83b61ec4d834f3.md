# Display 4.12 Table of numeric statistical summaries routed to the HTML destination

![](bbox=[0.143, 0.123, 0.977, 0.754])

A really cool use of the HTML destination is to display output objects in a Web page within a frame that includes a table of contents or index of the output objects. In Display 4.13, the specification of FRAME, CONTENTS, and BODY creates a Web page with the results of three procedures (UNIVARIATE, TABULATE, and SGPlot) run against the country data set. Note: RTF and PDF destinations can also create a table of contents.
