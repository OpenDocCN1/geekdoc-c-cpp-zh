(10.73)

(10.74)
\(^n E^z_{i,j} = ^{n-1}E^z_{i,j} + \frac{\Delta t}{\mu} \left[ \frac{1}{\Delta y} (U_{H_{Ex1} n-1} E^x_{i,j} + U_{H_{Ex2} n-1} E^x_{i,j+1}) - \frac{1}{\Delta x} (U_{H_{Ey1} n-1} E^y_{i,j} + U_{H_{Ey2} n-1} E^y_{i+1,j}) \right]\)

These equations are written in a matrix form similar to [57], where, for example, each \(^n E^x_{i,j}\) is the vector of the scaling and wavelet coefficients that represent the electric field in the i, j cell at time step n. The U matrices are the results of the inner products from the method of moments. Equations (10.72)-(10.74) form an explicit set of equations which can be used in a time marching scheme similar to the FDTD method [70].
