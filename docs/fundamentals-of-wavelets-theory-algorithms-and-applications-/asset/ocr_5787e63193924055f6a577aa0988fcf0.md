energy of the signal can be computed by a two-dimensional integration of the Wigner-Ville distribution over the entire time-frequency plane.

```
E = \int_{-\infty}^{\infty} |f(t)|^2 dt = \int_{-\infty}^{\infty} |\hat{f}(\omega)|^2 d\omega
= \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} W_f(t, \omega) d\omega dt = 1.
```

# 4.10.3 Correlation Function

We can compute the correlation functions in the time or frequency domains easily from the marginals:

```
(4.74) \gamma_f(\tau') = \int_{-\infty}^{\infty} f(\tau) \overline{f(\tau + \tau')} d\tau = W_f(\tau', 0)
```

```
(4.75) \gamma_\omega(\omega') = \int_{-\infty}^{\infty} f(\omega) \overline{f(\omega + \omega')} d\omega = W_f(0, \omega').
```
