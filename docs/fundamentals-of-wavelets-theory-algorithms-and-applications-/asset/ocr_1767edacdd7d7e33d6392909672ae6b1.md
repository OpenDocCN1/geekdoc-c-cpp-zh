# 7.4 RECONSTRUCTION ALGORITHM

It is important for any transform to have a unique inverse
such that the original data can be recovered perfectly. For
random signals, some transforms have their unique
inverses in theory, but cannot be implemented in reality.
There exists a unique inverse discrete wavelet transform
(or the synthesis transform) such that the original function
can be recovered perfectly from its components at different
scales. The reconstruction algorithm is based on the
two-scale relations of the scaling function and the wavelet.
We consider a sum of these components at the sth
resolution

```
(7.37)
x_s(t) + y_s(t) = \sum_k a_{k,s}\phi_{k,s}(t) + \sum_k w_{k,s}\psi_{k,s}(t) = x_{s+1}(t).
```

By a substitution of the two-scale relations into (7.37) one
obtains

```
(7.38)
\sum_k a_{k,s} \sum_\ell g_0[\ell]\phi[2^{s+1}t - 2k - \ell] + \sum_k w_{k,s} \sum_\ell g_1[\ell]\phi[2^{s+1}t - 2k - \ell]
= \sum_\ell a_{\ell,s+1}\phi[2^{s+1}t - \ell].
```
