The important issue of this algorithm is to retain all pertinent information so that the user may recover the original signal (if needed). The algorithm is based on the decomposition relation in MRA discussed in Chapter 5. We rewrite several of these relations here for easy reference.

Let

```
x_{s+1}(t) \in A_{s+1}, \Rightarrow x_{s+1}(t) = \sum_k a_{k,s+1} \phi_{k,s+1}(t)
x_s(t) \in A_s, \Rightarrow x_s(t) = \sum_k a_{k,s} \phi_{k,s}(t)
y_s(t) \in W_s, \Rightarrow y_s(t) = \sum_k w_{k,s} \psi_{k,s}(t).
```

Since the MRA requires that

```
A_{s+1} = A_s + W_s,
```

we have

```
x_{s+1}(t) = x_s(t) + y_s(t)
\sum_k a_{k,s+1} \phi_{k,s+1}(t) = \sum_k a_{k,s} \phi_{k,s}(t) + \sum_k w_{k,s} \psi_{k,s}(t).
```
