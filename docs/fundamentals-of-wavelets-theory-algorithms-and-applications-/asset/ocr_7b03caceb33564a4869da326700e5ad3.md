Let $g(t) \in L^2$ be expanded into a series with basis functions $\{\phi_k(t)\}_{k \in \mathbb{Z}}$:

```
(2.29) 
\( g(t) = \sum_k c_k \phi_k(t). \)
```

The basis set $\{\phi_k(t)\}_{k \in \mathbb{Z}}$ is called a Riesz basis if it satisfies the following inequality:

```
(2.30) 
\( R_1 \|c_k\|_{l^2}^2 \le \|g(t)\|^2 \le R_2 \|c_k\|_{l^2}^2 \)
```

```
(2.31) 
\( R_1 \|c_k\|_{l^2}^2 \le \left\| \sum_k c_k \phi_k(t) \right\|^2 \le R_2 \|c_k\|_{l^2}^2. \)
```

where $0 < R_1 \le R_2 < \infty$ are called Riesz bounds. The space $l^2$ is the counter part of $L^2$ for discrete sequences with the norm defined as

```
(2.32) 
\( \|c_k\|_{l^2} = \left( \sum_k |c_k|^2 \right)^{\frac{1}{2}} < \infty. \)
```
