MSE $\|e_c(t)\|^2$ is minimum. To show this, let us assume that there is another sequence $\{d_j : j = 0, \cdots, N-1\}$ that is obtained in a way other than orthogonal projection and also minimizes the error. Then we will show that $c_j = d_j, j = 0, \cdots, N-1$, thus completing our proof.

With the sequence $\{d_j\}$, we have

```
g(t) = g_d(t) = \sum_{j=0}^{N-1} d_j \phi_j(t),
(2.50)
```

and

```
\|e_d(t)\|^2 = \left\| g(t) - \sum_{j=0}^{N-1} d_j \phi_j(t) \right\|^2 = \left\langle g(t) - \sum_{j=0}^{N-1} d_j \phi_j(t), g(t) - \sum_{j=0}^{N-1} d_j \phi_j(t) \right\rangle
= \langle g, g \rangle - \sum_{j=0}^{N-1} d_j \langle \phi_j(t), g \rangle - \sum_{j=0}^{N-1} \overline{d_j} \langle g, \phi_j(t) \rangle + \sum_{j=0}^{N-1} |d_j|^2
= \langle g, g \rangle - \sum_{j=0}^{N-1} d_j \overline{c_j} - \sum_{j=0}^{N-1} \overline{d_j} c_j + \sum_{j=0}^{N-1} |d_j|^2.
(2.51)
```

To complete the square of the last three terms in (2.51), we add and subtract $\sum_{j=0}^{N-1} |c_j|^2$ to yield

```
\|e_d(t)\|^2 = \left\| g(t) - \sum_{j=0}^{N-1} d_j \phi_j(t) \right\|^2 = \left\| g(t) - \sum_{j=0}^{N-1} c_j \phi_j(t) \right\|^2 + \sum_{j=0}^{N-1} |d_j - c_j|^2
(2.52)
```
