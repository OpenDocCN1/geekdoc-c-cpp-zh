# Find the Fourier series representation of

+   (a) \( f(n) = \cos \frac{n\pi}{5}, \text{and} \)

+   (b) \( f(n) = \{1, 1, 0, 0\} \).

Solution: (a) Instead of directly computing the coefficients using (3.96), we may represent the cosine function in its exponential form

```
(3.97) 
\( f(n) = \frac{1}{2} \left\{ e^{j \frac{2\pi n}{10}} + e^{-j \frac{2\pi n}{10}} \right\} \).
```

The periodicity of this sequence is seen as \( N = 10 \). Since (3.97) is already in the form of an exponential series as in (3.95), we conclude that

```
(3.98) 
\( \alpha_k = \begin{cases} \frac{1}{2} & k=1, \\ \frac{1}{2} & k=9, \\ 0, & \text{otherwise.} \end{cases} \)
```

(b) We compute the Fourier coefficients using (3.96) to obtain

```
\( \alpha_k = \frac{1}{4} \left( 1 + e^{-j \frac{2\pi k}{4}} \right), \quad k=0, 1, 2, 3. \)
```
