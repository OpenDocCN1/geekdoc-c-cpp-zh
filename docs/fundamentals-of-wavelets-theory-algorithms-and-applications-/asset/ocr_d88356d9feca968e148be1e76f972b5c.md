# 10.9 EXPRESSIONS FOR SPLINES AND WAVELETS

We provide formulas for the scaling functions \(B_{m,0,k}(x)\) and the wavelets \(\psi_{m,k,0}(x)\) for \(k = -m + 1, ..., 0\) and \(m = 2, 4\). Formulas at the scale \(s_0\) can be obtained by replacing \(x\) by \(2^{s_0} x\) and scaling the intervals accordingly.

```
(10.81)
\(B_{m,-m+1,0}(x) = \begin{cases} (1-x)^{m-1}, & x \in [0,1) \\ 0, & \text{otherwise.} \end{cases}\)
```

```
(10.82)
\(B_{2,0,0}(x) = \begin{cases} x, & x \in [0,1) \\ 2-x & x \in [1,2) \\ 0 & \text{otherwise.} \end{cases}\)
```
