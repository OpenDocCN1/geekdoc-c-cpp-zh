\(\sum_{n=1}^N c_n L_K \Lambda_n = g.\)

For the present discussion we will assume N to be large enough so that the above representation is exact. Now by taking the inner product of (10.16) with a set of weighting functions or testing functions {\(\xi_m : m = 1, ..., M\)} we get a set of linear equations

(10.17) 
\(\sum_{n=1}^N c_n \langle \xi_m, L_K \Lambda_n \rangle = \langle \xi_m, g \rangle ; m = 1, ..., M\)

which can be written in the matrix form as

(10.18) 
\([A_{mn}][c_n] = [b_m]\)

where

\(A_{mn} = \langle \xi_m, L_K \Lambda_n \rangle ; m = 1, ..., M; n = 1, ..., N\)

\(b_m = \langle \xi_m, g \rangle ; m = 1, ... , M.\)
