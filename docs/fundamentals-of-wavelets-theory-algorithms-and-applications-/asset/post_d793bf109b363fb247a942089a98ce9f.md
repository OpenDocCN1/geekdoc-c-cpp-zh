### 2.7.2 Eigenmatrix

A linear transformation is a mapping such that when a vector \(\mathbf{x} \in V\) (a vector space) is transformed, the result of the transformation is another vector \(\mathbf{y} = A\mathbf{x} \in V\). The vector \(\mathbf{y}\), in general, is a scaled, rotated, and translated version of \(\mathbf{x}\). In particular, if the output vector \(\mathbf{y}\) is only a scalar multiple of the input vector, we call this scalar the eigenvalue and the system an *eigensystem*. Mathematically, we write

```
(2.55) \(\mathbf{y} = A\mathbf{x} = \mu \mathbf{x}\)
```

where \(A\) is an \(N \times N\) matrix, \(\mathbf{x}\) is an \(N \times 1\) vector and \(\mu\) is a scalar eigenvalue. We determine the eigenvalues from the solution of the characteristic equation

```
(2.56) \(\det(A - \mu I) = 0\).
```

If \(\mathbf{x}\) is an \(N \times 1\) column matrix, there are \(N\) eigenvalues in this system. These eigenvalues may or may not be all distinct. Associated with each eigenvalue, there is an eigenvector. The interpretations of the eigenvectors and eigenvalues depend on the nature of the problem at hand. For each eigenvalue \(\mu_j\), we substitute it into (2.56) to solve for the eigenvector \(\mathbf{x}_j\). We use the following example to illustrate this procedure. Let

```
A = \begin{bmatrix} 3 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 3 \end{bmatrix}
```

be the transformation matrix. The characteristic equation from (2.56) is

```
\det(A - \mu I) = \det \begin{bmatrix} 3-\mu & -1 & 0 \\ -1 & 2-\mu & -1 \\ 0 & -1 & 3-\mu \end{bmatrix} = (3-\mu)[(2-\mu)(3-\mu)-1] - (3-\mu) = (3-\mu)(\mu-1)(\mu-4) = 0
```

and the eigenvalues are \(\mu = 4, 1, \text{and } 3\). We substitute \(\mu = 4\) into (2.55)

```
\begin{bmatrix} 3 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 3 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} = 4 \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix}
```

and obtain the following set of linear equations

```
-x_1 - x_2 + 0 = 0 \\ -x_1 - 2x_2 - x_3 = 0 \\ 0 - x_2 - x_3 = 0. \\ (2.57)
```

This is a linearly dependent set of algebraic equations. We assume \(x_1 = \alpha\) and obtain the eigenvector \(e_3\) corresponding to \(\mu = 4\) as

$$
\alpha \begin{bmatrix} 1 \\ -1 \\ 1 \end{bmatrix}; \alpha \neq 0.
$$

(2.58)

The reader can compute the other two eigenvectors as an exercise.

### 2.7.3 Linear Transformation

Using the example on the eigensystem in the previous section, we have

$$
\mathbf{A} = \begin{bmatrix} 3 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 3 \end{bmatrix}
$$

$$
\mu_j = 1, 3, 4 \text{ for } j = 1, 2, 3,
$$

and the eigenvectors corresponding to the eigenvalues are

$$
\mathbf{e}_1 = \begin{bmatrix} 1 \\ 2 \\ 1 \end{bmatrix}, \mathbf{e}_2 = \begin{bmatrix} 1 \\ 0 \\ -1 \end{bmatrix}, \mathbf{e}_3 = \begin{bmatrix} 1 \\ -1 \\ 1 \end{bmatrix}.
$$

(2.59)

From the definitions of eigenvalue and eigenvector, we have

$$
\mathbf{A}\mathbf{e}_j = \mu_j\mathbf{e}_j, \text{ for } j = 1, 2, 3.
$$

(2.60)

We may rearrange this equation as

(2.61) \( A[\boldsymbol{e}_1 \ \boldsymbol{e}_2 \ \boldsymbol{e}_3] = [\mu_1\boldsymbol{e}_1 \ \mu_2\boldsymbol{e}_2 \ \mu_3\boldsymbol{e}_3] \).

To be more concise, we put equation (2.61) into a compact matrix form,

\( AE = E \begin{bmatrix} \mu_1 & 0 & 0 \\ 0 & \mu_2 & 0 \\ 0 & 0 & \mu_3 \end{bmatrix} = E\mu \) (2.62)

where \(\mu\) is a diagonal matrix and \(E\) is the eigen matrix. If the matrix \(E\) is nonsingular, we diagonalize the matrix \(A\) by premultiplying (2.62) by \(E^{-1}\):

(2.63) \( E^{-1}AE = \mu \).

Therefore, we have used the eigenmatrix \(E\) in a linear transformation to diagonalize the matrix \(A\).

### 2.7.4 Change of Basis

One may view the matrix \(A\) in the previous example as a matrix that defines a linear system

\(\boldsymbol{y} = \begin{bmatrix} y_1 \\ y_2 \\ y_3 \end{bmatrix} = A\boldsymbol{x} = A \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix}.\) (2.64).

The matrix \(A\) is a transformation that maps \(\boldsymbol{x} \in \mathbb{R}^3\) to \(\boldsymbol{y} \in \mathbb{R}^3\). The components of \(\boldsymbol{y}\) are related to that of \(\boldsymbol{x}\) via the linear transformation defined by (2.64). Since e1, e2, and e3 are linearly independent vectors, they may be used as a basis for R^3. Therefore, we may expand the vector x on this basis

```
x = x_1e_1 + x_2e_2 + x_3e_3
= Ex',
```

and the coefficient vector x' is computed by

```
x' = E^{-1}x.
```

The new coordinates for the vector y with respect to this new basis become

```
y' = E^{-1}y
= E^{-1}Ax
= E^{-1}AEx'
= \mu x'.
```

Equation (2.67) states that we have modified the linear system y = Ax by a change of basis to another system y' = \mu x' in which the matrix \mu is a diagonal matrix. We call this linear transformation via the eigenmatrix the similarity transformation.

### 2.7.5 Hermitian Matrix, Unitary Matrix, and Orthogonal Transformation

Given a complex-valued matrix $H$, we can obtain its Hermitian, $H^h$, by taking the conjugate of the transpose of $H$, namely

```
(2.68) $H^h := \overline{H^T}$.
```

The two identities

```
$(H^h)^h = H$
```

```
$(GH)^h = H^h G^h$
```

obviously follow from the definition.

Let the basis vectors of an $N$-dimensional vector space be $b_i, i = 1, \cdots, N$, where $b_i$ is itself a vector of length $N$. An orthogonal basis means that the inner product of any two different basis vectors vanishes:

```
(2.69) $\langle b_j, b_i \rangle = [b_j]^t [b_i] = \delta_{i,j}, \forall i, j \in \mathbb{Z}$.
```

For complex-valued basis vectors, the inner product is expressed by

```
$\langle b_j, b_i \rangle = [b_j]^h [b_i]$.
```

If the norm of $b_i$ is one, this basis is called an *orthonormal basis*. We form an $N \times N$ matrix of transformation $P$ by putting the orthonormal vectors in a row as

(2.70) \( P = [b_1, b_2, ... b_N] \).

Since

(2.71) \( [b_j]^h [b_i] = \delta_{i,j} \).

it follows that

(2.72) \( P^h P = I \).

and

(2.73) \( P^h = P^{-1} \).

In addition to the column-wise orthonormality, if \( P \) also satisfies the row-wise orthonormality, \( PP^h = I \), matrix \( P \) is called a *unitary* (or *orthonormal*) matrix.

## 2.8 DIGITAL SIGNALS

In this section we provide some basic notations and operations pertinent to the signal processing techniques. Details may be found in [3].

### 2.8.1 Sampling of Signal

Let \( x(t) \) be an energy-limited continuous-time (analog) signal. If we measure the signal amplitude and record the result at a regular interval \( h \), we have a discrete-time signal

(2.74) \( x(n) := x(t_n), n=0, 1, ..., N-1 \).

where

$t_n = nh$.

For simplicity in writing and convenience of computation, we use x(n) with the sampling period h understood. These discretized sample values constitute a signal, called a digital signal.

To have a good approximation to a continuous band-limited function x(t) from its samples {x(n)}, the sampling interval h must be chosen such that

$h \le \frac{\pi}{\Omega}$.

where $2\Omega$ is the bandwidth of the function x(t), i.e., $\hat{x}(\omega) = 0$ for all $|\omega| > \Omega$. The choice of h is the Nyquist sampling rate, and the Shannon recovery formula

$x(t) = \sum_{n \in \mathbb{Z}} x(nh) \frac{\sin \pi(t - nh)}{\pi(t - nh)}$

**(2.75)**

enables us to recover the original analog function x(t). The proof of this theorem is most easily carried out using the Fourier transform and the Poisson sum of Fourier series. We shall defer this proof until Chapter 3.

### 2.8.2 Linear Shift-Invariant Systems
