Hence the function $f(t)$ is reconstructed through interpolation of its sampled values with the sinc function as the interpolation kernel.

$p_M(t) = \sum_{k=-M}^{M} \alpha_k e^{jk\omega_0 t}, \quad \text{(3.87)}$

$\alpha_k = \frac{1}{T} \int_{-T/2}^{T/2} p(t) e^{-jk\omega_0 t} dt. \quad \text{(3.88)}$
