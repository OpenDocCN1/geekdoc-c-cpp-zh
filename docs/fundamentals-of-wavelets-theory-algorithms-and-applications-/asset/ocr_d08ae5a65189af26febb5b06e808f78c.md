3. The U-step updates the even value based on the difference obtained in the P-step to compute the approximation coefficients of the next lower resolution.
$a_{k,l} = a_{2k,l+1} + w_{k,l} / 2$.

From here on, the next level of signal decomposition starts with $a_{k,l}$ and repeats the prediction and updating procedures with the same predictor and updator. It is important to note that the design of the predictor and updator must keep the average value of the signal level to be the same to preserve the zeroth order moment:

(8.62)
$$ \frac{1}{2} \sum_{k=0}^{2^n-1} a_{k,l} = \sum_{k=0}^{2^{n-1}-1} a_{k,n-1} $$

This condition is shown to be true as

(8.63)
$$ \sum_{k=0}^{2^{n-1}-1} a_{k,n-1} = \sum_{k=0}^{2^{n-1}-1} [a_{2k,n} + w_{k,n-1}/2] = \sum_{k=0}^{2^{n-1}-1} (a_{2k,n} + a_{2k+1,n})/2 = \frac{1}{2} \sum_{k=0}^{2^{n-1}-1} a_{k,n} $$

The reconstruction phase of the DWT is carried out by simply running the decomposition algorithm backward! That is, we apply (8.61) in the reverse direction:

(8.64)
$a_{2k,l+1} = a_{k,l} - w_{k,l} / 2,$

(8.65)
$a_{2k+1,l+1} = w_{k,l} + a_{2k,l}.$
