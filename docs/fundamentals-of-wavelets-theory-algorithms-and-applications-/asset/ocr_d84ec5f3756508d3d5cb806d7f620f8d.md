Let us consider a system characterized by its impulse response h(n). We say the system is linearly shift invariant if the input x(n) and the output y(n) satisfy the following system relations:

# Shift invariance:

```
\begin{cases}
x(n) \Rightarrow y(n) \\
x(n-n') \Rightarrow y(n-n').
\end{cases}
(2.76)
```

# Linearity:

```
\begin{cases}
x_1(n) \Rightarrow y_1(n) \text{ and } x_2(n) \Rightarrow y_2(n), \\
x_1(n) + m x_2(n) \Rightarrow y_1(n) + m y_2(n).
\end{cases}
(2.77)
```

In general, a linear shift-invariant system is characterized by

```
x_1(n - n') + m x_2(n - n') \Rightarrow y_1(n - n') + m y_2(n - n').
(2.78)
```
