# 6.4.2 Meyer Scaling Function

The Shannon scaling function \(\phi_{SH}(t)\) has poor time localization (\(\Delta \phi_{SH} = \infty\)). The reason for this is that in the frequency domain, \(\hat{\phi}_{SH}(\omega)\) has a discontinuity at \(-\pi\) and \(\pi\).
