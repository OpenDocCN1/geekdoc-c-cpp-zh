If the coefficients are not processed, the original data can be recovered exactly through the reconstruction algorithm. The procedure is simply the reverse of the decomposition except that the sequences are {g0[k], g1[k]} instead of {h0[k], h1[k]}. Care should be taken to remember upsampling before convolution with the input sequences. The perfectly reconstructed image is identical to the original image in Figure 9.20.
