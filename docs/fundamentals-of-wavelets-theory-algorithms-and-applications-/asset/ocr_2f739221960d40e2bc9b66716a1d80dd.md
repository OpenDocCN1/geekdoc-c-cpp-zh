= \|\epsilon_c(t)\|^2 + \sum_{j=0}^{N-1} |d_j - c_j|^2.

(2.53)

It is clear that to have minimum MSE, we must have \( d_j = c_j; j = 0, \cdots, N-1 \), and hence the proof.
