Each subband contains a total of 128 wavelet packet coefficients.

+   2. From each subband at the fifth level of resolution, compute the average energy content in the wavelet packet coefficients such that

(9.23) \(v_i^{wp} = \frac{1}{n_i} \sum_{j=1}^{n_i} p_{i,j}^2, \quad i = 1, 2, ..., 32, \text{and } n_i = 128, \quad \forall i,\)

where \(v_i^{wp}\) is the \(i\)th feature in a wavelet packet feature vector; \(n_i\) is the number of sample in each subband; and \(p_{i,j}\) is the \(j\)th wavelet packet coefficient in the \(i\)th subband. The WP feature vector is represented as follows:

(9.24) \(v^{wp} = \{v_1^{wp}, v_2^{wp}, ..., v_{13}^{wp}\}^t\)
