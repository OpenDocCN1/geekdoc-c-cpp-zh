# 9.10 MULTICARRIER COMMUNICATION SYSTEMS (MCCS)

Multicarrier modulation is the principle of transmitting data by dividing the data stream into several parallel bitstreams, each of which has a much lower bit rate. Each of these substreams modulates an individual carrier. Figure 9.33 shows the block diagram of the transmitter of a multicarrier communication system. A serial-to-parallel buffer segments the information sequences into frames of \(N_f\) bits. The \(N_f\) bits in each frame are parsed into \(M\) groups, where the \(i\)th group is assigned \(n_i\) bits so that

```
$$\sum_{i=0}^{M-1} n_i = N_f.$$
(9.48)
```
