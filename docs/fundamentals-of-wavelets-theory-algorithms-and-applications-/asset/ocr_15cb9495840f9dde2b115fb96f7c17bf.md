If \(\omega^*\) is the center and \(\Delta_{\hat{\phi}}\) is the radius of the window function \(\hat{\phi}(\omega)\), then (4.15) gives us information about the function \(\hat{f}(\omega)\) in the interval

(4.17) \([\omega^* + \xi - \Delta_{\hat{\phi}}, \omega^* + \xi + \Delta_{\hat{\phi}}]\).

Because of the similarity of representations in (4.7) and (4.15), the STFT gives the information about the function \(f(t)\) in the time-frequency window:

(4.18) \([t^* + b - \Delta_{\hat{\phi}}, t^* + b + \Delta_{\hat{\phi}}] \times [\omega^* + \xi - \Delta_{\hat{\phi}}, \omega^* + \xi + \Delta_{\hat{\phi}}]\).
