or

```
[y] = [DEC_{1/2}][x]
```

The shift-variant property of the decimator is evident when we shift the input column either up or down by a given number of position. In addition, the decimation matrix is an orthogonal matrix since

```
[DEC_{1/2}]^{-1} = [DEC_{1/2}]^t.
```

Consequently, decimation is an orthogonal transformation.

# 7.1.2 Interpolation

Interpolation of data means inserting additional data points into the sequence to increase the sampling rate. Let y(n) be the input to an interpolator. If we wish to increase the number of sample by M-fold, we insert M - 1 zeros in between any two adjacent samples so that the interpolator output gives

```
x'(n) = \begin{cases} y(\frac{n}{M}), & \text{for } n = kM, k \in \mathbb{Z} \\ 0, & \text{otherwise.} \end{cases} (7.11)
```
