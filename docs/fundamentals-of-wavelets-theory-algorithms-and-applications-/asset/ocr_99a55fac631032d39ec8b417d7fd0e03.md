Furthermore, o.n. scaling functions and wavelets have poor time-scale localization.

In some applications to be discussed in later chapters, we need to interchange the roles of the analysis and synthesis pairs, \(\{\phi, \psi\}, \{\tilde{\phi}, \tilde{\psi}\}\), respectively. In b.o. decomposition, we cannot do so easily since \(\phi\) and \(\tilde{\phi}\) generate two different MRAs, \(A\) and \(\tilde{A}\), respectively. For such an interchange, we need to map the given function \(x \mapsto \tilde{x}_M \in \tilde{A}_M\), and then we can use \(\psi\) as analyzing and \(\tilde{\psi}\) as synthesizing wavelets.

In addition to b.o.o. and o.n. decomposition, there is another class of decomposition called *semiorthogonal decomposition*, for which \(A_s \perp W_s\). Since in this system, the scaling function and wavelets are nonorthogonal, we still need their duals, \(\tilde{\phi}\) and \(\tilde{\psi}\). However, unlike the b.o. case, there is no dual space. That is, \(\phi, \tilde{\phi} \in A_s\) and \(\psi, \tilde{\psi} \in W_s\), for some appropriate scale \(s\). In this system it is very easy to interchange the roles of \(\phi, \psi\) with those of \(\tilde{\phi}, \tilde{\psi}\) .
