After a single 3D level wavelet transform, the volume data would be decomposed into eight blocks, as shown in Figure 9.39. The 3D volume can be approximated by using

```
$$a^{j+1}(x, y, z) = \sum_{n,m,l} a^j_{n,m,l} \phi(2^j x - n, 2^j y - m, 2^j z - l)$$
```
