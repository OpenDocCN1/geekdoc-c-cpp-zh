We note in passing that a best basis is usually obtained between the third layer and the fourth layer, since deeper layers may yield some adverse effects due to the amplitude increase in their spectral sidelobes.

Once we have chosen a best basis, the signal is readily expressed as

```
s(t) = \sum_{j=1}^{\infty} \sum_{m=0}^{2^k-1} \sum_{n=-\infty}^{\infty} d_n^{j,k,m} \mu_{s^k+m}(2^{j-k}t-n)
= \sum_{j,m} s'_{j,m}(t),
(9.18)
```

where

```
d_n^{j,m} = \langle s(t), \mu_{z^k+m}(2^{j-k}t-n) \rangle \text{ and }
s'_{j,m}(t) = \sum_n d_n^{j,k,m} \mu_{2^k+m}(2^{j-k}t-n).
(9.19)
```

The WPCDR with a best basis selection is given by

```
WPCDR_s(t, f) = \sum_{j,m} WVD_{s'_{j,m}}(t, f).
(9.20)
```
