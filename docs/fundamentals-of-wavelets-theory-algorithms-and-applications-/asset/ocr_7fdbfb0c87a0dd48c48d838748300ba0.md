# Note

+   * A function \(f \in L^2(\mathbb{R})\) has linear phase if

```
\tilde{f}(\omega) = \pm |\hat{f}(\omega)| e^{-j a \omega}
```

where \(a\) is some real constant. The function \(f\) has generalized linear phase if

```
\tilde{f}(\omega) = \tilde{g}(\omega)e^{-j a \omega + b}
```

where \(\tilde{g}(\omega)\) is a real-valued function and constants \(a\) and \(b\) are also real valued. To avoid distortion in signal reconstruction, a filter must have linear or generalized linear phase.
