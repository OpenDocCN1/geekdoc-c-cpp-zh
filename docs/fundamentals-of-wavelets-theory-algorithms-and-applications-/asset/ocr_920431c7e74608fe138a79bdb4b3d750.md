```
(8.12) \n \left\{ \begin{array}{l} \boldsymbol{a}_{M-1} = (\boldsymbol{\sigma}^0 \tilde{\boldsymbol{g}}_0) * \boldsymbol{a}_M, \\ \boldsymbol{w}_{M-1} = (\boldsymbol{\sigma}^0 \tilde{\boldsymbol{g}}_1) * \boldsymbol{a}_M. \end{array} \right.
```

To extend this to other lower levels, we rely on the method given in [3], yielding the algorithm

```
(8.13) \n \left\{ \begin{array}{l} \boldsymbol{a}_{s-1} = (\boldsymbol{\sigma}^{M-s} \tilde{\boldsymbol{g}}_0) * \boldsymbol{a}_s, \\ \boldsymbol{w}_{s-1} = (\boldsymbol{\sigma}^{M-s} \tilde{\boldsymbol{g}}_1) * \boldsymbol{w}_s, \\ \text{with } s = M, M-1, \dots, M-M'+1. \end{array} \right.
```
