# Special Cases:

+   1. If \(a=1\) and \(\omega_0=0\), we have
+   
+   \(U(z) = \frac{1-z^{-1}}{1-2z^{-1}+z^{-2}} = \frac{1}{1-z^{-1}}, ROC: |z| > 1.\)

+   2. If \(a=1\), we have
+   
+   \(X(z) = \frac{1-\cos(\omega_0)z^{-1}}{1-2\cos(\omega_0)z^{-1}+z^{-2}}, ROC: |z| > 1.\)

+   3. If \(\omega_0=0\), we have
+   
+   \(X(z) = \frac{1-az^{-1}}{1-2az^{-1}+a^2z^{-2}} = \frac{1}{1-az^{-1}} ROC: |z| > |a|.\)

# 2.8.6 Inverse z-Transform

The formula for recovering the original sequence from its \(z\)-transform involves complex integration of the form

\(x(n) = \frac{1}{2\pi j} \oint_c X(z)z^{n-1}dz\)
