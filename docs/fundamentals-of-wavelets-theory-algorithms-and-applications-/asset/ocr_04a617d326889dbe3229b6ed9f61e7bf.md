The passes are repeated by cutting the threshold by half each time. If all the coefficients are coded, we have a lossless code. The compression ratio achieved in this manner is limited. The user may stop coding at any time or when the bit budget is exhausted. We have a lossy compression scheme wherein the user may control the bit budget, but he or she cannot control the compression ratio.
