# 9.3.3 Percentage Thresholding

In certain applications such as image compression where a bit quota has been assigned to the compressed file, it is more advantageous to set a certain percentage of wavelet coefficients to zero to satisfy the quota requirement. In this case, the setting of the threshold value \(\sigma\) is based on the histogram of the coefficient set and the total number of coefficients. The thresholding rule is the same as hard thresholding once we have determined the threshold \(\sigma\).

# 9.3.4 Implementation

Implementations of the hard, soft, and percentage thresholding methods are quite simple. One simply subtracts the threshold value from the magnitude of each coefficient.
