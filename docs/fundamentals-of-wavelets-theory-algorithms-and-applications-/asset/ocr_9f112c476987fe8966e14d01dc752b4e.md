The $m$th order cardinal B-spline $N_m(t)$ has the knot sequence $\{..., -1, 0, 1, ...\}$ and consists of polynomials of order $m$ (degree $m - 1$) between the knots. Let $N_1(t) = \chi_{[0,1)}(t)$ be the characteristic function of $[0, 1)$. Then for each integer $m \ge 2$, the $m$th order cardinal B-spline is defined, inductively, by

```
(5.36) $$N_m(t) := (N_{m-1} * N_1)(t)$$
```

```
$$:= \int_{-\infty}^{\infty} N_{m-1}(t-x) N_1(x) dx$$
```

```
(5.37) $$= \int_{0}^{1} N_{m-1}(t-x) dx.$$
```
