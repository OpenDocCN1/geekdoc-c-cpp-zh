We set the initial threshold value $T_0 = 32 = 2^5$. We then use this threshold and compare with all of the coefficients in a dominant pass (to be described below).

In wavelet-tree coding, not only do the values of the coefficients need to be coded but the location of the coefficients must also be known to the decoder. The EZW makes use of the parent-children relationship between coefficients in adjacent coefficient maps to record the location of a given coefficient.
