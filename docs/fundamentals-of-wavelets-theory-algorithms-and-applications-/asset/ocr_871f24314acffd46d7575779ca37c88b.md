# 3.9.2 Discrete-Time Fourier Transform (DTFT)

If a discrete signal is aperiodic, we may consider it to be a periodic signal with period \( N = \infty \). In this case, we extend the discrete Fourier series analysis to DTFT similar to the extension in the analog domain. In DTFT, the time variable \( (n) \) is discretized while the frequency variable \( (\omega) \) is continuous since

```
\(\Delta\omega = \lim_{N \to \infty} \frac{2\pi}{N} \to \omega.\)
```

The DTFT pair is explicitly given by

```
(3.100) \(\hat{f}(\omega) = \sum_{n=-\infty}^{\infty} f(n)e^{-jn\omega},\)
```

```
(3.101) \(f(n) = \frac{1}{2\pi} \int_{-\pi}^{\pi} \hat{f}(\omega)e^{jn\omega} d\omega.\)
```
