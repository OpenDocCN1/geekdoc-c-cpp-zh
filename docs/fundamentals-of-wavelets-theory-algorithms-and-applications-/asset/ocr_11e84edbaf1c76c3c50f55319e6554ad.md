\sum_k \hat{f}(\omega + 2\pi k) = \sum_k f(k) e^{-jk\omega}

\frac{1}{a} \sum_k \hat{f}\left(\frac{\omega + 2\pi k}{a}\right) = \sum_k f(ak) e^{-jk\omega}

Note

1 This is not a function in the classical sense. It is called a generalized function or distribution. However, in this book, we will refer to this as a delta function.
