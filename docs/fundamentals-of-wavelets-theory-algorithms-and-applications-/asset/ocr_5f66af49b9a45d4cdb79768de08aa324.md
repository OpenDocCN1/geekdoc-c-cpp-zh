Let us recall the formulation of the multiresolution analysis, in which we have the approximation subspace as an orthogonal sum of the wavelet subspaces

```
(7.40)
\[\mathbf{A}_M = \oplus_{s=-M+1}^{M'} \mathbf{W}_s + \mathbf{A}_{-M'}
= \mathbf{W}_{M-1} \oplus \mathbf{W}_{M-2} \oplus \dots \oplus \mathbf{W}_{-M'+1} \oplus \mathbf{A}_{-M'}\]
```

for any positive integer \( M' \). Consequently, any good approximant \( x_M \in \mathcal{A}_M \) of a given function \( x \in L^2 \) (for sufficiently large \( M \)) has a unique (orthogonal) decomposition

```
(7.41)
\[x_M = \sum_{n=1}^{M'} y_{M-n} + x_{-M+M'},\)
```

where \( x_s \in \mathcal{A}_s \) and \( y_s \in \mathcal{W}_s \). Since \( \phi_m \) and \( \tilde{\phi}_m \) generate the same MRA while \( \psi_m \) and \( \tilde{\psi}_m \) generate the same wavelet subspace (a property not possessed by biorthogonal scaling functions and wavelets that are not semiorthogonal), we write

```
(7.42)
\[\begin{cases}
x_s(t) = \sum_k a_{k,s} \phi(2^s t - k) = \sum_k \tilde{a}_{k,s} \tilde{\phi}(2^s t - k); \\
y_s(t) = \sum_k w_{k,s} \psi(2^s t - k) = \sum_k \tilde{w}_{k,s} \tilde{\psi}(2^s t - k),
\end{cases}\]
```

for each \( s \in \mathbb{Z} \). We have not included the normalization factor \( 2^{s/2} \) in order to simplify the implementation.
