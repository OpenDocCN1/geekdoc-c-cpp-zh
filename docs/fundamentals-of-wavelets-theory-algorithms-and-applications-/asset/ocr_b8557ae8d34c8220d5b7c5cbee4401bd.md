A slightly more complicated one will be using a quadratic polynomial. We need to define a quadratic polynomial q(x) such that

\begin{cases} a_{k-1,j} = \int_{2l(k-1)}^{2l(k)} q(x) dx \\ a_{k,j} = \int_{2l(k)}^{2l(k+1)} q(x) dx \\ a_{k+1,j} = \int_{2l(k+1)}^{2l(k+1)} q(x) dx \end{cases} (8.76)

The resulting quadratic polynomial will be used to compute the unknown values at 2^{j+1} level so that

\begin{cases} a_{2k,j+1} = 2 \int_{2l(k)}^{2l(k+1/2)} q(x) dx \\ a_{k+1,j} = 2 \int_{2l(k+1/2)}^{2l(k+1)} q(x) dx \end{cases} (8.77)

For two-interval average, the coefficients are {1/2, 1/2} ,while the quadratic polynomial results in {-1/8, 1/8, 1, 1/8, -1/8}. The graphs for these two scalingfunctions are shown in Figure 8.29.
