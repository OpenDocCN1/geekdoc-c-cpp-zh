for some sequence \(\{r_k\}\). We observe that this change-of-bases sequence is a finite sequence, if the scaling function has compact support. Indeed, by the definition of the dual, we have

(7.47) \(r_k = \int_{-\infty}^{\infty} \phi(t) \phi(t-k) dt.\)

Therefore, at the original scale of approximation, with \(s = M\), an application of (7.46) yields

(7.48) \(\tilde{a}_{k,M} = \sum_l r_{k-l} a_{l,M}.\)

which is an FIR operation. Observe that if we take splines as scaling functions—that is, \(\phi(t) = N_m(t)\), then \(r_k = N_{2m}(m - k); k = 0, \pm 1, ..., \pm m - 1\) [1]. As we have seen in previous discussions, the sequences \(\{g_0[k]\}\) and \(\{g_1[k]\}\) in the decomposition algorithm are finite sequences.
