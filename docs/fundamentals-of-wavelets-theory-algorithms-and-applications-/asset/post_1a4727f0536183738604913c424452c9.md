
compute the difference (odd-even) first and then the average:

```
\begin{cases} w_{k,\ell} = a_{2k+1,l+1} - a_{2k,l+1} \\ a_{k,\ell} = a_{2k,l+1} + \frac{w_{k,\ell}}{2} \end{cases}
```

This is the lifting approach for the Haar wavelet transform of a one-dimensional signal. The process can be summarized in three simple steps:

- 1. The S-step splits (or unzips) the signal into an even and an odd sample paths.

```
x(k) = a_{m,n} \rightarrow \begin{cases} Even path \rightarrow a_{2k,n} \\ Odd path \rightarrow a_{2k+1,n} \end{cases}
```

Notice that each path carries only half of the total number of samples in the original signal.

- 2. The P-step predicts the odd samples based on the even samples. At certain $(l+1)^{th}$ resolution of the Haar wavelet analysis, the lifting scheme assumes the predicted odd value to be the same as its preceding even value.

```
\tilde{a}_{2k+1,l+1} = a_{2k,l+1}.
```

At this point, the wavelet coefficients (difference) of the next lower resolution is computed by

```
w_{k,l} = a_{2k+1,l+1} - \tilde{a}_{2k+1,l+1} = a_{2k+1,l+1} - a_{2k,l+1}.
```

- 3. The U-step updates the even value based on the difference obtained in the P-step to compute the approximation coefficients of the next lower resolution.
$a_{k,l} = a_{2k,l+1} + w_{k,l} / 2$.

From here on, the next level of signal decomposition starts with $a_{k,l}$ and repeats the prediction and updating procedures with the same predictor and updator. It is important to note that the design of the predictor and updator must keep the average value of the signal level to be the same to preserve the zeroth order moment:

(8.62)
$$ \frac{1}{2} \sum_{k=0}^{2^n-1} a_{k,l} = \sum_{k=0}^{2^{n-1}-1} a_{k,n-1} $$

This condition is shown to be true as

(8.63)
$$ \sum_{k=0}^{2^{n-1}-1} a_{k,n-1} = \sum_{k=0}^{2^{n-1}-1} [a_{2k,n} + w_{k,n-1}/2] = \sum_{k=0}^{2^{n-1}-1} (a_{2k,n} + a_{2k+1,n})/2 = \frac{1}{2} \sum_{k=0}^{2^{n-1}-1} a_{k,n} $$

The reconstruction phase of the DWT is carried out by simply running the decomposition algorithm backward! That is, we apply (8.61) in the reverse direction:

(8.64)
$a_{2k,l+1} = a_{k,l} - w_{k,l} / 2,$

(8.65)
$a_{2k+1,l+1} = w_{k,l} + a_{2k,l}.$

The coefficients are merged (zipped) together to form the next higher resolution signal.

```
a_{2k, l+1}
a_{2k+1, l+1} \xrightarrow{merge} a_{k, l+1}
```

This process is repeated for every level of resolution until all the wavelet coefficients at each level have been used in the reconstruction process and the final sequence of samples will be the original signal x(k). ## 8.5.1 Linear Spline Wavelet

The complexity of the lifting scheme is increased slightly when we use the linear prediction for the odd samples of the signal. The predictor (P) uses the average of the two adjacent even samples to predict the in-between odd sample

```
(8.66)
\(\tilde{a}_{2k+1,\ell+1} = \frac{1}{2}(a_{2k,\ell+1} + a_{2k+2,\ell+1}).\)
```

The prediction error (difference) forms the wavelet coefficient

```
(8.67)
\(w_{k,\ell} = a_{2k+1,\ell+1} - \tilde{a}_{2k+1,\ell+1} = \frac{1}{2}(2a_{2k+1,\ell+1} - a_{2k,\ell+1} - a_{2k+2,\ell+1}).\)
```

To preserve the zeroth and first order moments for all resolution, we have

```
(8.68)
\(\sum_{k=0}^{2^{n-1}-1} a_{k,n-1} = \frac{1}{2} \sum_{k=0}^{2^{n-1}} a_{k,n}.\)
```

(8.69)
\(\sum_{k=0}^{2^{n-1}-1} k a_{k,n-1} = \frac{1}{2} \sum_{k=0}^{2^{n-1}-1} k a_{k,n}.\)

The updator (U) is found to be

(8.70)
\(a_{k,\ell} = a_{2k,\ell+1} + \frac{1}{4}(w_{k-1,\ell} + w_{k,\ell}).\)

The inverse transform is computed in a reverse manner by

(8.71)
\(a_{2k,\ell+1} = a_{k,\ell} - \frac{1}{4}(w_{k-1,\ell} + w_{k,\ell})\)

(8.72)
\(a_{2k+1,\ell+1} = w_{k,\ell} + \frac{1}{2}(a_{2k,\ell+1} + a_{2k+2,\ell+1}).\)

These coefficients are zipped back together by the merger to form the signal at the next higher resolution.

## 8.5.2 Construction of Scaling Function and Wavelet from Lifting Scheme

Thus far we have described the lifting algorithm as a means to obtain the average and the difference from a given set of data. From the DWT point of view, these data streams correspond to the approximation coefficients and the wavelet coefficients for the next lower level of resolution. However, the predicting and updating schemes are user designed, and therefore, there are no known scaling function and wavelet bases associated with the schemes. They will have to be constructed based on the schemes. Unlike the classical wavelet construction where the Fourier analysis is used extensively, in lifting schemes, subdivision algorithms are often used in the literature. These are important techniques in computer-aided curve and surface designs. A detail exposition on the topic is beyond the scope of this section. We will use only the elementary ones to demonstrate the procedure of wavelet construction from lifting.

## 8.5.3 Linear Interpolative Subdivision

Subdivision is a method of refining a set of original data (i.e., to increase the number of data points by suitably inserting data in between two original data points). Interpolative subdivision means that the original data points are not changed by running the algorithm. One simple way to subdivide data is by using the average of the adjacent value as the new (inserted) data value. Let $\{a_{k,0}\}$ be the original data set. We compute the expanded set by

```
(8.73) \(a_{2k, j+1} = a_{k, j}\)
```

```
(8.74) \(a_{2k+1, j+1} = \frac{1}{2}(a_{k, j} + a_{k+1, j}).\)
```

The new data points are inserted halfway between two adjacent old data points. Its value is the linear interpolation of the two adjacent old values. If the original data values are samples from linear functions, this linear subdivision algorithm will reproduce the linear functions.

More sophisticated algorithms are available for interpolative subdivision. One can use more known values (original data values) adjacent to the desirable data point location to compute its value. If we use four-point values ($a_{k-1,j}, a_{k,j}, a_{k+1,j}, a_{k+2,j}$) and use a cubic interpolation to compute the value of $a_{2k+1,j+1}$, the resulting value is a weighting of the 4 original values

```
(8.75)

a_{2k+1,j+1} = \frac{-1}{16}a_{k-1,j} + \frac{9}{16}a_{k,j} + \frac{9}{16}a_{k+1,j} + \frac{-1}{16}a_{k+2,j}.
```

This is known as the four-point scheme in computer graphics.

The interpolative subdivision is a very simple yet powerful algorithm to refine a set of data. A new sample value at a given location is computed via an interpolating polynomial constructed by using nearby sample values. If the samples are equidistant, the weights for the polynomial need to be computed only once. Since equidistant sample is not a requirement for subdivision, it can be used for defining approximation basis and wavelet basis on irregular grid points.

Another scheme for subdivision is the interpolating average algorithm. The simplest algorithm for the new value at the higher resolution is

```
$a_{2k,j+1} = a_{k,j}$
$a_{2k+1,j+1} = a_{k,j}$
```

A slightly more complicated one will be using a quadratic polynomial. We need to define a quadratic polynomial q(x) such that

\begin{cases} a_{k-1,j} = \int_{2l(k-1)}^{2l(k)} q(x) dx \\ a_{k,j} = \int_{2l(k)}^{2l(k+1)} q(x) dx \\ a_{k+1,j} = \int_{2l(k+1)}^{2l(k+2)} q(x) dx \end{cases} (8.76)

The resulting quadratic polynomial will be used to compute the unknown values at 2^{j+1} level so that

\begin{cases} a_{2k,j+1} = 2 \int_{2l(k)}^{2l(k+1/2)} q(x) dx \\ a_{2k+1,j+1} = 2 \int_{2l(k+1/2)}^{2l(k+1)} q(x) dx \end{cases} (8.77)

For two-interval average, the coefficients are {1/2, 1/2} ,while the quadratic polynomial results in {-1/8, 1/8, 1, 1/8, -1/8}. The graphs for these two scaling functions are shown in Figure 8.29.
