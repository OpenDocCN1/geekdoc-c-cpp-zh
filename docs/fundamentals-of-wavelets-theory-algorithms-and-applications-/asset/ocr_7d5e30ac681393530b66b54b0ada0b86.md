(7.97) S(z) = z^{-m}C_0(z)

where S(z) is a noncausal filter symmetric with respect to the origin. The PR condition becomes

(7.98) S(z) + S(-z) = 2

since S(-z) = (-z)^{-m}C_0(-z) = -z^{-m}C_0(-z) for odd m. All even-indexed coefficients in S(z) are zero except s(0) = 1. S(z) is a half-band filter satisfying the following conditions:

+   1. s(n) = 0 for all even n except n = 0.
+   2. s(0) = constant.
+   3. s(n) = s(-n).
+   4. S(e^{j\omega}) + S(-e^{-j\omega}) = constant.

This half-band filter is capable to be spectral-factorized into a product of two filters. We will have discussions on the HBF with examples.
