There are many algorithms for detecting edges [7–10] in a digital image. However, they can be largely classified into two categories: the gradient (first derivative of the signal) approach and the Laplacian (second derivative of the signal) approach. We will consider some representative algorithms of these two classes as well as wavelet- and curvelet-based approaches.

An ideal edge should be like a step function, but in practice, edges are blurred and are closely modeled as ramp functions (Figure 9.23). A blurred edge can be modeled mathematically at x = 0 by an error function given by

(9.33) \( f(x) = \frac{I_{x>0} - I_{x<0}}{2} \left[ \text{erf}\left( \frac{x}{\sqrt{2}\sigma} \right) + 1 \right] + I_{x<0} \)

where the error function \(\text{erf}(y) = (2/\pi) \int_0^y e^{-u^2} du\) is bounded by \(\pm 1\) as the variable \(y \to \pm \infty\). Another model for an edge is

(9.34) \( f(x) = 1 + \tanh(\beta x) \)
