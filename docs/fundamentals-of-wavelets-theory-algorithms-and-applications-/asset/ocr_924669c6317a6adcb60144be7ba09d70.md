As we can see in the transformed domain, most of the information is contained in y0. We can remove half the data — that is, set y1 = 0 — and still be able to recover the original sequence with little distortion. Transform coding steps can be summarized as follows.

+   1. Divide input sequence {xi} in blocks of size N and transform them to sequence {yi}.
+   
+   2. Quantize the transformed sequence {yi}.
+   
+   3. Encode the quantized data.
