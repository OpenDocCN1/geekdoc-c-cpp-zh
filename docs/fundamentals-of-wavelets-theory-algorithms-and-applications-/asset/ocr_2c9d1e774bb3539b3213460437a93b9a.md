where $h(t)$ is the system response function. Hence if $i(t)$ is a delta function, the output function $O(t)$ is the same as $h(t)$. For an arbitrary input function $f(t)$ the convolution integral

```
(3.39) \( O(t) = \int_{-\infty}^{\infty} h(t) i(t - \tau) d\tau \)
```

represents a superposition of the output due to a series of input delta functions whose amplitudes are modulated by the input signal. It is easy to show that the spectral domain representation of the convolution integral of (3.36) is given by

```
\( \hat{f}(\omega) = \hat{f}_1(\omega) \hat{f}_2(\omega) \)
```
