# Pricing Microsoft Azure

How would you price Microsoft's cloud service called Azure?

Things to Consider

+   * What are the strategic objectives? Maximize profits or share?
* Does pricing high, low or in-line with competitor's help Microsoft do so?
* What kind of creative pricing models can Microsoft invent?

Common Mistakes

+   * Not asking about costs.
* Not inquiring about Azure's unique value vs. the competition.
* Oversimplifying the situation by telling interviewer to just price below the competition.

# Answer

CANDIDATE: This is a really complex problem. There are many services to Azure. Are there certain services you meant to work with?

INTERVIEWER: That won't be necessary, just give me your thoughts on it.

CANDIDATE: Well, to be honest, I think Azure is doing good. Because it has so many services, it's really easy to add and subtract methods basically as you go. This goes for bandwidth or usage as well. If you use a lot of queries this month, for example, you just pay that for month. If we try to slip a price on everything, it would get complicated it actually turn the users off.

INTERVIEWER: Well, do you think it can be improved in any way?

CANDIDATE: I supposed it could offer bundle packages. For example, if you use A and B not C, we can offer a deal or bundle package that has A, B, and C. It would serve as a way to attract users to C. But I think this will run the trouble of being too complicated for the user I mentioned above. I propose actually offer monthly deals. We offer one or two, and how we gauge users are reacting to them. For example, let say month I am offering a deal for service A, B and C. I can gauge how many users made the switch to C, and how many stopped using C after the deal was over. That way it allows me to better price C.

We are doing this monthly because it's piecemeal. They only see one or two deals means they only need to decide on those just. If it doesn't apply, they don't think about it. If we continue to test prices like this, we can eventually reach a good point on pricing for each service.

INTERVIEWER: That is an interesting thought. Why do you think Microsoft isn't doing this?

CANDIDATE: Microsoft might be concerned with the confusion this brings, and also how customer service and business representatives would have to deal with extra inquiries. We might have some people whose deal ended they don't know and they are complaining we are charging them more, and we might have people asking for deals on their particular service because they are used to seeing deals now.
