# Improving the Help Center

Can you make suggestions how to improve the Help Center for Facebook?

Things to Consider

+   - Approach this as a product design.
- Use the CIRCLES Method.
- Think hard about pain points and frustrations with key metrics that the help team would like to optimize such as satisfaction and decreases in support tickets.

Common Mistakes

+   - Suggesting magical solutions, like the omnipotent support chat bot or the mindreading recommendation algorithm, without explaining the details

# Answer

CANDIDATE: Are we talking about the desktop version or the mobile version?

INTERVIEWER: Let say the desktop version.

CANDIDATE: The Help Center is when users come to Facebook for help. The whole point is to allow the user to be able to find help in the fastest way and not feel helpless. Just thinking about the Help Center, I can see three points of improvements:

+   - No Live Chat or Email. While we do want users to use the FAQ and self-help sections first, we want to provide live chat as a last ditch effort. Both of these connect the user with an actual person, which could cause a lot of the frustrations of feeling helpless.
- Too Many Sections. The first page shows 10+ sections on the left and a bunch of more on the bottom. This is a lot for a user to take in. When someone comes for help, they are already feeling helpless. When we make this harder by listing these sections, we are telling them this is complicated and you'll have to find it.
- Language Selection. The language selection right now doesn't feel like a selection. It would be better to add a down arrow or some other sort of symbol to make it like selectable. Facebook serves a lot of users in different countries and thus languages. I am sure it shows your language browser as default, but this should still be visible.

INTERVIEWER: Wouldn't adding live chat or cause most users to use those instead of reading of the FAQ and finding help on their own? That would add a lot of pressure to us in terms of customer service.

CANDIDATE: I would use testing on this, and I have a feeling Facebook might already have. But to me, I feel like people who are already here on the Help Center are already trying to self-help. They are more willing to search for an answer on their own first they give up and try another route. So I don't think the impact will be exactly 1:1. I am sure it'll add some pressure, but I'll need to see data to make sure that is true or not.
