# Method 2

It's 80 units per hour. This means we generate many error units per hour:

$80 \times 0.015 = 1.2\ error units per hour$

\frac{1.2\ error units}{20\ error units per hour} = 0.06\ hours

\frac{80\ units stowed per hour}}{(1\ hour of stowing + 0.06\ hours of find and fixing)} = \\sim75.47\ units per hour
