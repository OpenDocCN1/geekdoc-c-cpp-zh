## Weighing Eight Balls

You have eight balls all of the same size. 7 of them weigh the same, and one of them weighs slightly more. How can you find the ball that is heavier by using a balance and weighing it only twice?

 Things to Consider

- Work out an example.
- Consider different edge cases.

### Common Mistakes

- Assuming that it's a digital scale, not a balance.
- Solving for the best case with the balance, which is one weighing.
- Incorrectly assuming that the heavier ball can be determined without using the balance and simply identifying the heavier ball by hand.

Show your work below. Make any assumptions as necessary. Answer on the next page.

## Answer

CANDIDATE: I would weigh 3 vs. 3. We have two possibilities:

- The heavier ball is not in here. It's in one of the 2 balls I didn't weigh. I then weigh 1 vs. 1 on the remaining 2 balls to find it. I only weighed twice.
- The heavier ball is in one of the 3 balls. I eliminate the other 5 balls. I then weigh 1 vs. 1 out of 3 balls. The heavier ball is in either of these 2, in which case I would know, or the heavier ball is not, which then it must be the 3rd ball that I didn't weigh. I only weighed twice.

## Chapter 10 Product Design: Putting it Together

## Amazon Mayday in Gmail

Let's say we wanted to implement an Mayday-like feature in Gmail. How would that work?

 Things to Consider

- Distill the key features of Amazon Mayday and map to Gmail.
- Be prepared to defend design decisions including features left in features out.

### Common Mistakes

- Making incorrect assumptions on how the feature works, especially for those who never used it.

## Answer

CANDIDATE: Just so we are on the same page, Amazon Mayday is a feature that is on the Fire tablet that is essentially a panic button that lets you connect with a support. You can draw on your screen where you want to go, do it for you, or give you instructions on how to do it.

INTERVIEWER: That is correct.

CANDIDATE: Okay. Can I get some time to brainstorm?

CANDIDATE: Okay, I have a few ideas, but first me point out some things. This needs to be displayed prominently over the Gmail page. It needs to be ever present no matter which page you are on. I would say somewhere in the top would be nice. Whenever the user hovers over it, it should display a description for what it is.

When the user presses it, it should automatically connect with a support. First though, it would detect which language you need it in. Since Gmail definitely tracks language, this makes it easier. The user gets connected through Google Hangouts or Gmail (email thread). He has then three options:

- Remote Desktop: The customer service representative can remote desktop to fix the problem. The user is warned that the customer will be able to see his email, which may be sensitive.
- Audio/Text: The representative can use voice (if the user agrees and has a microphone and this is through Hangouts) or message the user through Hangouts or email. Instructions can be given this way for the user to follow.
- Video: Hangouts can do calling or upload videos. The user can follow through that.

The biggest concern here is that the user must be the one that chooses option to use. If we offer too many it could confuse the users, so we need to be selective. Looking back, I went into too much breadth.
