# # Interview Evaluation Sheet: Estimation

Downloadable copy for printing: http://bit.ly/InscyfEvalEstimation

| Interviewer's Explanation | Rating 1-5 |
|---|---|
| | 1 = Not like the candidate at all<br>5 = Very much like the candidate |
| **Problem Solving Skills**
Did the candidate take an an unfamiliar problem and
develop a plan to solve it confidently? | |
| **Communication Skills**
Did the candidate clearly communicate his or her action
plan to the interviewer? Easy to follow? Or did the
interviewer have to ask an excessive number of clarifying
questions to unravel the candidate's thoughts? | |
| **Comfort with Numbers**
Did the candidate confidently calculate numbers by
hand? Did the candidate rely on using a calculator or computer to crunch
numbers? Or did the candidate needlessly round
numbers to oversimplify calculations? | |
| **Judgment**
Did the candidate choose reasonable assumptions,
backed by logical thinking? Or was the candidate sloppy
in choosing assumptions, believing that reasonable
assumptions don't matter? | |
