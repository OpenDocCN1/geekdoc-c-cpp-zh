# Yahoo’s Revenue Streams

How does Yahoo! make money? Name 4 ways.

Things to Consider

+   - If you think this is a trick question, clarify with the interviewer. E.g. "Do you want me to list 4 ways literally? Or are you asking me to analyze and optimize Yahoo’s money making potential?

Common Mistakes

+   - Giving up because the candidate is not familiar with Yahoo’s business model.
- Pretending to know, but getting the facts wrong, hurting credibility in the process.

# Answer

CANDIDATE: I can think of these:

+   - Ads. Yahoo has a lot of services that can sell ads to the user. These include things like Yahoo Search, Yahoo News, and Yahoo Map.
- Enterprise. Yahoo has certain products that are free for consumers and can be purchased as an enterprise solution. An example of this is Yahoo Mail.
- Sales. Yahoo sells some products for money. Examples of this include Yahoo’s TV service and Yahoo Music.
- Royalty and Cuts. Yahoo has some portals that sell products owned by others for a cut. Examples of this include Yahoo Shopping and Yahoo Travel.
