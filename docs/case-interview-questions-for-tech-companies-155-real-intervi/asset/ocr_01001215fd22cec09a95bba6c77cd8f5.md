# Google Offline Search

Brainstorm at least 10 solutions to allow those who don’t have Internet access to perform a Google search.

# Answer

+   1. Store local Google index on user’s computers for the most common queries such as weather, restaurants, etc. Refresh index when user connects to Internet café.
2. Allow access to a bigger Google index using a peer-to-peer networking technology, even without always-on Internet access.
3. Compress Google index onto a USB key; deliver a fresh USB key every morning la newspaper delivery.
4. Deliver Google search results via automated voice call.
5. Deliver Google search results via manual voice call.
6. Deliver Google search results via text message.
7. Deliver Google search results via mail.
8. Deliver Google search results via courier.
9. Perform Google search via a publicly available Internet-connected kiosk.
10. Sponsor or subsidize Internet cafes, allowing users to perform Google searches.
