# Quick Test

As usual, let's test everything in the scene. Open your **scene.h** header file, and register the rigid body system in the constructor, and add an entity with a rigid body component, as shown in the code snippet below.

```
engine/src/ecs/scene.h

FUSE_INLINE void start() {
    // load sprite
    auto sp = _assets.load_texture("assets/obj1.png", "", _renderer);

    // add tilenmap entity
    auto entity = add_entity("rigid body");
    entity.add_component<sprite_component>().sprite = sp->id;
    auto& rb = entity.add_component<rigid_body_component>();
    rb.body.gravity_scale = 1.0f;

    // start systems
    for (auto& sys : _systems) { sys->start(); }
}
```

If you run your code right now, nothing will happen because of the delta time. There is one thing I said earlier about making all motions and animations in our engine time-based. The reason nothing is happening is that the delta time so far has been zero. We will add a timer to compute the delta time for us but for now, we are going to apply a quick solution to test our rigid body system.

# Quick Fix

If you open your **application.cpp** you will see that the scene's update function is called with zero as delta time value. To quickly test the rigid body system, we can simply pass a constant delta time value like shown in the following code snippet.

```
engine/src/core/application.cpp

while (is_running) {
    inputs::dispatch_events();
    SDL_RenderClear(renderer);
    scene->update(0.016666666);
    SDL_RenderPresent(renderer);
}
```

The number 0.016666666 is the value of the delta time you would get if you had a game running at around sixty frames per second (60 FPS). If you compile your code and run, you will see your game object falling due to gravity. You can play around with the gravity scale to see how it affects the simulation of the rigid body.
