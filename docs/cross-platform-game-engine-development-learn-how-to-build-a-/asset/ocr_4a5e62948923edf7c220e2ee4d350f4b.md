# # Adding Score

The score is also going to be an entity with a text component. Below is the code to add the score entity to the scene.

```
engine/src/ecs/scene.h
FUSE_INLINE void d start() {
    // ...

    // score text
    auto score = add_entity("score");
    auto& s_tr = score.get_component<transform_component>();
    s_tr.translate = vec2f(120, 20);
    auto& tx = score.add_component<text_component>();
    tx.text = "Score: 0";
    tx.font = font->id;

    // start systems
    for (auto& sys : _systems) { sys->start(); }
}
```
