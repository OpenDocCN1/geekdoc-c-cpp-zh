# Why was this book written?

This book has held a particular place in my heart for a long time. I am confident that it is a long-awaited answer for many people who, like myself, have been seeking resources to learn how to design and develop a gaming engine by themselves. I was reluctant whether what I knew suited the supposed "industry standard." It took me many years to get to the point where I could author a book about this topic, and I'm glad to know I didn't hold myself back.

# Who is this book for?

This book is not intended for complete beginners in C++ or any other programming language. You need to know some fundamental coding concepts like object-oriented programming, inheritance, template functions, pointers, and so on. If you have programming experience with other object-oriented programming languages such as C#, Java, or Python, you will be able to find your way through. No prior knowledge of SDL2 is required. It is recommended that you have a basic understanding of linear algebra and physics.

# What this book covers

This book will take you through the entire process of designing and implementing a cross-platform Entity-Component-System-based game engine. It begins by describing how to set up a multiplatform development environment. It then goes over how to add custom features to the engine before concluding with a demonstration of how to utilize the game engine to make a simple Flappy Bird game.
