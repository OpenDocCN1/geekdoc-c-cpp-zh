# # Audio Asset

A game without audio is just flat-out dead and not fun to play. We'll keep the same pattern for the audio assets as well. The SDL mixer library provides two types of audio data. Mix_Music and Mix_Chunk. The difference is that you only play one piece of music at a time, but you can play as many chunks as your computer can handle. Each new chunk will be assigned to a dedicated channel, whereas there is only one channel for all music. That is the reason we are using Mix_Chunk instead of Mix_Music. Feel free to make more research online if you wish.

engine/src/assets/audio.h

```
#pragma once
#include "asset.h"

namespace fuse {
struct audio_clip {
    Mix_Chunk* data = NULL;
    std::string filename;
};

struct audio_asset : asset {
    FUSE_INLINE audio_asset() = default;

    FUSE_INLINE ~audio_asset() {
        Mix_FreeChunk(instance.data);
    }

    audio_clip instance;
};
}
```
