# Getting Started

The first thing we want to do is to change the game configuration. So, make sure to update your application's configuration like shown below.

```
↘ game/src/game.cpp

#nclude <core/entry.h>
fuse :: app_config fuse :: create_application() {
    fuse :: app_config config;
    config.title = "Flappy Plane";
    config.version = "0.0.1";
    config.width = 380;
    config.height = 720;
    return config;
}
```

As you can see, we have changed the width, the height, and the title of the application's window.
