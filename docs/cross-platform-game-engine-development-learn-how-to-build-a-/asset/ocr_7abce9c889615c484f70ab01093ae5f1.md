# Roadmap

This book will teach you how to use SDL2 to design and implement a multiplatform 2D game engine using C++ from the ground up. Below is a diagram (Figure 4) that shows what our roadmap will look like.

![](bbox=[0.13, 0.18, 0.87, 0.32])

We'll start by configuring our cross-platform development environment and build system, and then we'll add some core features like logging, assertions, inputs, and event handling. After that, features such as entity component systems, renderers, animation, physics, etc. will be implemented. The last step is to merge all the features mentioned above to create a flappy plane game.
