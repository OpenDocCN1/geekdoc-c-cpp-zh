# Background Music

It is quite common to have background music while playing. It adds life and fun to the game. We need a function that we will be able to call to play any sound effect available in the asset registry. So, add the following function to the “script_instance”.

```
engine/src/scripts/script_instance.h

// . . .

FUSE_INLINE void play_audio(std::string name, int channel = -1,
    int loops = 0, int vol = 50) {
    auto& chunk = assets->get<audio_asset>(name)->instance.data;
    Mix_VolumeChunk(chunk, vol);
    Mix_PlayChannel(channel, chunk, loops);
}

// . . .
```

The function takes four arguments. The first argument is the name of the audio asset we wish to play. The second argument is the channel where we want to play the song. If you pass "-1", SDL will choose the next free channel for you. But you can also give a specific channel where you want the sound to be played. The third argument is to tell SDL how many times the sound should be played. "-1" means repeat forever. The last parameter is the volume at which you wish the sound to be played.
