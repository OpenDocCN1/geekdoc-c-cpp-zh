## Initializing SDL libraries

Now that we have VS-Code and all SDL libraries set up, let’s start writing some code to test if everything is successfully installed by creating a simple application. I will be using the project folder tree (Figure 17) from earlier as a reference to create and address files and directories.

Add the code snippet below in your **pch.h** header file. As previously said, any header file or code included in this file will be compiled once to generate the precompiled headers. It’s also worth noting that you shouldn’t include header files that will be changed often, as this will force the precompiled headers to be compiled all over again resulting to a much slower compilation process.

The **pragma once** on top is used to ensure that this header file is not included more than once the final code generated by the compiler. If that ever happens, the compilation will fail because some functions or classes are being defined more than once.

As stated in the introduction, the engine is intended to be a shared library that will be linked to the game executable at runtime.

**dllexport** and **dllimport** are Microsoft-specific extensions to the C and C++ programming languages. They can be used to export or import functions, data, and objects into a DLL or from another DLL.

The equivalent for GNU compiler is **__attribute__((visibility("default")))**.
**_MSC_VER** is defined as a literal whole number, which encodes the digits of the compiler’s main and secondary versions. This symbol is used to detect if the Microsoft C/C++ Compiler is available and in use.

**FUSE EXPORT** was defined as a symbol in the **engine/CMakeLists.txt** file. As a result, any method, or class defined in a cpp-file that has the symbol **FUSE API** in front of it will be exported to the compiled library.

### engine/src/core/application.cpp

```cpp
#include "pch.h"
#include "application.h"

namespace fuse {
FUSE_API void run_application(const app_config& config) {
    if(SDL_Init(SDL_INIT_EVERYTHING) == 0) {
        std::cout << "sdl initialized!" << std::endl;
    }
    if(IMG_Init(IMG_INIT_PNG) > 0) {
        std::cout << "sdl image initialized!" << std::endl;
    }
    if(TTF_Init() == 0) {
        std::cout << "sdl ttf initialized!" << std::endl;
    }
    if(Mix_Init(MIX_INIT_MP3) > 0) {
        std::cout << "sdl mixer initialized!" << std::endl;
    }
    SDL_Quit();
    IMG_Quit();
    TTF_Quit();
    Mix_Quit();
}
}
```

To determine whether all the libraries were successfully installed or not, we simply try to initialize each one.

### SDL_Init(Uint32 flags) returns 0 on success or a negative code on failure.

We didn't want to be specific about which system to initialize, so we used the SDL_INIT_EVERYTHING flag to initialize all systems. However, if for instance we only want to initialize audio and video, we can use the OR-operator to combine flags: SDL_Init(SDL_INIT_AUDIO | SDL_INIT_VIDEO).

Note : You can make use of IntelliSense to find out all possible flags.

### IMG_Init(int flags) loads dynamic libraries and prepares them for use. Flags should be one or more flags from IMG_InitFlags OR'd together. It returns the flags successfully initialized, or 0 on failure.

### TTF_Init() Initialize the SDL_ttf engine. Returns 0 if successful, -1 on error.

### Mix_Init(int flags) loads dynamic libraries and prepares them for use. Flags should be one or more flags from MIX_InitFlags OR'd together. It returns the flags successfully initialized, or 0 on failure.
