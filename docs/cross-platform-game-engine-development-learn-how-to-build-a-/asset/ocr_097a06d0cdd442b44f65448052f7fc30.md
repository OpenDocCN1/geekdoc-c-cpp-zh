# Step 1 Navigate to yaml-cpp directory

Use the command below to navigate into the directory of yaml-cpp.

```
cd <path to yaml-cpp directory>
```

# Step 2 Build with CMake

```
rem create output directory
mkdir build
rem generate make file
cmake -O . -B ./build -DBUI LD_SHARED_LI BS=ON
rem compile library
cmake --build ./build
```

These commands will create a folder to store the build files, use CMake to generate and build the source code of yaml-cpp. Since we want to build yaml-cpp as a shared library, we use "BUILD_SHARED_LIBS" to instruct CMake about that.

After the compilation is done, you will find the library files generated in the directory visualized in the folder tree below.

![](bbox=[0.08, 0.45, 0.9, 0.61])

Similar to all SDL libraries, yaml-cpp also has include header files, a ".dll" and a ".lib" file that are the only files we need to link yaml-cpp to our project.

# Linking yaml-cpp

We are going to use the same technique we used for SDL to link yaml-cpp.

# Step 1 Copy Header files

Go ahead and copy the header files folder found under yaml-cpp/include into Project/windows/includes.

# Step 2 Copy Library Files

Copy the “yaml-cppd.lib” file into Project/windows/lib and copy the second library file “yaml-cppd.dll” into Project/windows/bin.
