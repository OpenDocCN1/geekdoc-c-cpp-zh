### Loading Font Asset

Add the following function to your asset registry. This function will be used to load font files into our engine.

```
engine/src/assets/registry.h

// ...

FUSE_INLINE font_asset* load_font(const std::string& src, const std::string& name, int size) {
    font font;
    font.data = TTF_OpenFont(src.c_str(), size);
    font.filename = src;
    font.size = size;

    if (!font.data) {
        FUSE_ERROR("%s", IMG_GetError());
        return NULL;
    }

    auto asset = new font_asset();
    asset->instance = font;
    asset->name = name;

    _data[type_id<font_asset>()].push_back(asset);
    return asset;
}

// ...
```

This is one of the reasons why using external libraries in a project is important: it abstracts all the complexity for us, so we only have to focus on what matters to us. As you can see, all we have to do is call TTF_OpenFont() to load the font file. This function takes the path to the font file and the target size for that font.

### Text Component

Text rendering is also part of the category “graphics”. That’s why the text component is also going to be created inside of the same file that the sprite component was created in. There are three essential components required to render text on the screen: A font, the text value (string), and the color. Of course, there are other elements that are also necessary to render text, like the background color, the alignment, and the space between characters, but that’s up to you to figure out how to do it.

```
engine/src/ecs/components/graphics.h
struct text_component {
FUSE_INLINE text_component(const text_component &) = default;
FUSE_INLINE text_component() = default;

SDL_RendererFlip flip = SDL_FLIP_NONE;
SDL_Color color = { 0, 0, 0, 255 };
asset_id font = INVALID_ID;
std::string text;
};
```

Update the code inside your graphics.h by adding the code snippet above. Similar to the sprite component, we are also using an asset_id for the font because it will be retrieved in the text renderer system for the time being. We set the default color of the text to black and added a string to store the current value of the text. SDL_Color is a structure that holds the value of a color in the RGBA standard. The color value is an 8-bit unsigned integer, in other words, a number between 0 and 255.

### Text Renderer System

There are many functions available in SDL_ttf for rendering text. There is one called TTF_RenderText_Shaded(). This function gives us the ability to render text with a background color, hence the shaded in the name. TTF_RenderText_Blended(), on the other hand, renders text without a background or with a blend mode. More functions, such as TTF_SetFontStyle(font, TTF_STYLE_BOLD), are available to experiment with the font's style. Check the documentation [17] of SDL_ttf to learn more about all the functions available for you to use.

The way text is rendered with SDL is similar to the way textures are rendered, because all we do is create a texture from the text and render it. Next is a code snippet that shows how the text renderer system is defined. As you can see, TTF_RenderText_Blended() takes a pointer to the font, the text value, and a color as parameters, and it returns a pointer to an SDL_Surface which is just a structure that contains a collection of pixels used in software blitting. That surface is then used to create a texture using the SDL_CreateTextureFromSurface(). We query the size of that texture using SDL_QueryTexture(). The queried size is then used to create the target viewport "rect" of the texture, and finally, the texture is rendered using the function from the last chapter.

It is vital to destroy the texture and its surface before moving to the next stage because this could be a cause of our game getting slow over time.

```
engine/src/ecs/systems/text_renderer_system.h
#pragma once
#include "ecs/system.h"

namespace fuse::ecs {
struct text_renderer_system : system {
    FUSE_NN_INLINE void update(float) {
        for (auto& e : view<text_component>()) {
            // get components
            auto& tr = e.get_component<transform_component>();
            auto& tx = e.get_component<text_component>();

            // get texture from asset registry
            auto& font = _assets->get<font_asset>(tx.font)->instance;

            // create text surface
            SDL_Surface* surface = NULL;
            surface = TTF_RenderText_Blended(font.data,
                                             tx.text.c_str(), tx.color);
            if (!surface) {
                FUSE_ERROR("%s", TTF_GetError());
                continue;
            }

            // create texture from surface
            SDL_Texture* texture = SDL_CreateTextureFromSurface(_renderer, surface);
            SDL_FreeSurface(surface);
            if (!texture) {
                FUSE_ERROR("%s", SDL_GetError());
                continue;
            }

            // query texture size
            int width, height;
            SDL_QueryTexture(texture, NULL, NULL, &width, &height);

            // define target viewport
            SDL_FRect dst {
                tr.translate.x, tr.translate.y,
                width * tr.scale.x, height * tr.scale.y
            };

            // render text
            SDL_RenderCopyExF(_renderer, texture, NULL, &dst, tr.rotation, NULL, tx.flip);
            // destroy texture
            SDL_DestroyTexture(texture);
        }
    }
};
}
```

```
#pragma once
#include "ecs/systems/text_renderer_system.h"
#include "ecs/systems/sprite_renderer_system.h"

struct scene {

        register_systems<ecs::sprite_renderer_system>();
        register_systems<ecs::text_renderer_system>();
    }

    FUSE_INLINE void update(float dt) {
        SDL_SetRenderDrawColor(_renderer, 255, 255, 255, 255);
        for (auto& sys : _systems) { sys->update(dt); }
    }

        // load texture asset

        auto& tx = entity.add_component<ecs::text_component>();
        tx.text = "This is a text!";
        tx.font = font->id;

        // start systems
        for (auto& sys : _systems) { sys->start(); }
    }
}
```
