# Delta Time

In game programming and computer graphics, delta time describes a concept that ensures a hardware-independent speed of processes in a game loop. Delta Time describes the time difference between the previous frame and the currently rendered frame. The concept of delta time was introduced to solve a problem in early computer games in which games delivered at different speeds depending on the speed of the processor and were therefore sometimes no longer playable on faster processors than intended by the game developer. # Frame Rate Based Games

These types of games are not based on time but on the frame rate of the computer used. Moving an object using a 30 FPS machine will progress with half the speed when using a 60 FPS machine. Framerate dependent games can severely affect gameplay, since the flow of the game will depend on the device's frame rate used to play the game.

# Time Based Games

Games that are time-based have similar behaviour (motions, animation, and physics) on different machines, regardless of the framerate. That means, an object moving in a "time-based" game will move at the same rate regardless of the computer speed.

This technique is used when the goal is to design multi-platform games. That is also the reason we want to use that in our engine.
