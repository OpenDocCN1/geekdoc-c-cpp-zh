```
#!/bin/bash

# check build dir
if [ ! -d build ]
then
    mkdir build
fi

# generate cmake files
cmake -O. -B ./build -DCMAKE_BUILD_TYPE=Debug -
DBUILD_SHARED_LIBS=ON

# copy assets files to output dir
cp -R "./resource" "./build/bin/assets"

# compile project
cd build && cmake --build .
echo compilation finished!
```

A shell script is a computer program that a system shell interprets and executes. In the end, it is an executable text file that can execute any command that a user can type into a command line interface, such as Windows' Command Prompt. The shell is a programming language in and of itself, with variables, loops, and decision-making.
