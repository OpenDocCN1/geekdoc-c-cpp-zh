Just like that, we have a system in place to simulate rigid bodies. But we still have a problem. The value of the delta time used should not be constant because the delta time is strongly dependent on the performance of the computer in use. The value we are using right now will not be the same on a play station or an old computer. That’s why we have to solve that problem by adding a proper delta time calculation to our engine.
