an SDL_FRect, which is the source viewport of the texture. It defines which part of the texture should be copied and rendered. We are passing NULL because we want to render the entire sprite, not just a specific part of it.

The next argument, which is also related to the previous one, is the destination viewport. It defines the box or viewport in which the sprite will be rendered on the screen.

The fifth parameter is the angle or rotation of the sprite on the screen. We also have the ability to change the center of the object we are currently rendering by passing a pointer to an SDL_Point, which is just a point in 2D space that specifies the point around which the sprite should be rotated. We are passing NULL because we want to keep the SDL's default origin which is the top left corner of the sprite.

**Note :** Remember to include your component categories in `system.h` so that every system can access all the components to perform its task.
