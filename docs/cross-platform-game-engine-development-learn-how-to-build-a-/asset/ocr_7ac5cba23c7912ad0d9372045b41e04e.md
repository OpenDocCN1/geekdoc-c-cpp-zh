Following is the code for our font asset.

```
engine/src/assets/font.h
#pragma once
#include "asset.h"

namespace fuse {
struct font {
    TTF_Font* data = NULL;
    std::string filename;
    int size = 20;
};

struct font_asset : asset {
    FUSE_NON_NE font_asset() = default;
    FUSE_NON_NE ~font_asset() {
        TTF_CloseFont(instance.data);
    }

    font instance;
};
}
```

SDL_ttf has a specific type for fonts called TTF_Font. TTF stands for TrueType Font. It is a standard for fonts used to display text on screens and printers. It is built into the Windows and Mac OS operating systems, and is also available on Unix-like operating systems via FreeType [25].

Note : After a font has been loaded, there is no possibility to adjust its size in SDL. As a result, the only way to change font sizes is to reload the same font file with new font sizes. Later, we'll talk about font loading.
