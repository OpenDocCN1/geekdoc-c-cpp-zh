# Pipe Spawner

The pipe spawner is also an entity. It will generate the pipes within a specific interval of time so that the player will avoid them. Since the pipes will be generated at runtime, we need to have a script attached to the spawner to continuously generate pipes and also make sure they are destroyed outside of the screen.
