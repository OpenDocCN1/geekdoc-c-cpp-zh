# Tile Map Asset

Tile maps are highly common in 2D games. They consist of constructing the game world using regular-shaped images called tiles. Some popular games like Super Mario, Pacman or even Zelda use this technique to build their levels. Tile maps can also be mapped to a logical grid in addition to performance improvements, and can be used in many ways within the game logic (e.g., handling collisions, implementing AI) or to construct a level editor.
