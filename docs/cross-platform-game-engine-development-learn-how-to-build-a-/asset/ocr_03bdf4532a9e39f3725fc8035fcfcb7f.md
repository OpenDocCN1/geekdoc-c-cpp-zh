The collider component is just a rectangle defined using SDL_FRect. It also has a Boolean to tell if the collide is active or not.

# Collision System

The collision system compared to another system will implement the start function because we need to make sure that the position of the box collider is aligned with the entity's initial position.
The next code snippet shows how the collision system is implemented. The start function retrieves all entities with a collider component and sets their position to the transform position of the entity to which they belong.
In the update function, we repeat that process every frame while checking if any collision occurred. To detect the collision, we simply check if there is an intersection between two rectangular shapes. You can see that in the function check_collision().
For now, we are just printing a message in the console to when two entities collide. To prevent objects from colliding with themself, we always check if the entities involved in the current collision are not equal.
