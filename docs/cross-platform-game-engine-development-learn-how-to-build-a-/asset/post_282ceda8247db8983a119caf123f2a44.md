
## Setting up SDL2 Libraries

Simple DirectMedia Layer (SDL) is a cross-platform development library designed to supply low level access to audio, keyboard, mouse, joystick, and graphics hardware via OpenGL and Direct3D. It is used by video playback software, emulators, and popular games including Valve's award-winning catalogue and many Humble Bundle games.

SDL officially supports Windows, Mac OS X, Linux, iOS, and Android. Support for other platforms may be found in the source code. SDL is written in C, works natively with C++, and there are bindings available for several other languages, including C# and Python. SDL 2.0 is distributed under the zlib license. This license allows you to use SDL freely in any software. [18]

## Installing SDL on Windows

SDL installation on Windows is as simple as copying and pasting files into the proper locations. However, we must exercise caution because this is often the basis of our project's failure to compile successfully.

- Step 1: Download

https://www.libsdl.org/download-2.0.php is the link to the official download page of SDL. We could download SDL's source code and compile it ourselves, but we don't want to make things any more complicated. We'll just download and link the built binaries to our project.

![](img/2763810ed0a1572c2bec59ee52dd75be_40_0.png)

Based on the compiler used, there are two versions of the development libraries available for Windows. There is a Visual C++ Compiler version and a MinGW-Compiler version. We previously installed the Microsoft Visual C++ Compiler Toolset. That's why we will download the Visual C++ version.

- Step 2: Unpack

Unpack the downloaded package using WinRAR, Zip, or any other package manager of your choice. Within the unpacked directory, there are two primary subdirectories: “include” and “lib”. All header files are in the include folder and the library’s binaries are found in the lib folder. The SDL comes in 32-bit and 64-bit versions under the x86 and x64 folders, respectively. Using the 32-bit or 64-bit version has no effect on our coding experience; only the final product is altered. Using 32-bit allows you to run the final piece of software on both 32-bit and 64-bit systems, but the opposite is not true. The 64-bit version will be used in this book.

```
SDL2-2.x.x
|--- lib
|    |--- x86 <--- 32-bit binaries
|    |--- x64 <--- 64-bit binaries
|--- include
```

- Step 3: Copy

Copy all header files found in SDL2-2.x.x/include/ into the folder Project/windows/includes/SDL2/ of your project.

Copy the following .lib files SDL2.lib, SDL2main.lib from SDL2-2.x.x/lib/x64 into your Project/windows/libs folder.

Also make sure to copy the SDL2.dll file from SDL2-2.x.x/lib/x64 in the folder: Project/windows/bin.

We now officially have SDL2 installed and ready to use, but we still have to link it to our project. But before we get to that, we will first install all of the extension libraries for SDL as well.

- Step 4: Installing SDL_image, SDL_ttf, SDL_mixer

SDL2 alone is not enough for us to implement all the features mentioned earlier in our game engine. That’s why we will also use other extension libraries of SDL: SDL_image, SDL_mixer, and SDL_ttf.

- SDL_image

SDL_image [12] is an image file loading library. It loads images as SDL surfaces and textures, and supports the following formats: BMP, GIF, JPEG, LBM, PCX, PNG, PNM, SVG, TGA, TIFF, WEBP, XCF, XPM, XV. Download it here: https://www.libsdl.org/projects/SDL_image/ .

![](img/2763810ed0a1572c2bec59ee52dd75be_41_0.png)

- SDL_mixer

SDL_mixer [13] is a simple multi-channel audio mixer library. It supports any number of simultaneously playing channels of 16-bit stereo audio, plus a single channel of music, mixed by the popular FLAC, MikMod Mod MOD, Timidity MIDI, Ogg Vorbis, and SMPEG MP3 libraries: https://www.libsdl.org/projects/SDL_mixer/.

### Windows
SDL2_mixer-devel-2.0.4-VC.zip (Visual C++ 32/64-bit)
SDL2_mixer-devel-2.0.4-mingw.tar.gz (MinGW 32/64-bit)

- SDL_ttf

SDL_ttf [14] is a sample library that allows you to use TrueType fonts in your SDL applications. It comes with an example program "showfont" which displays an example string for a given TrueType font file. Download it using the following link: https://www.libsdl.org/projects/SDL_ttf/.

### Windows
SDL2_ttf-devel-2.0.15-VC.zip (Visual C++ 32/64-bit)
SDL2_ttf-devel-2.0.15-mingw.tar.gz (MinGW 32/64-bit)

Make sure you copy the header files for each extension library into the project/windows/includes/SDL2 directory as we did previously for SDL. You need to repeat the same process for all .lib and .dll files for each library, respectively.

- Step 5: Link to Project

Now that all files are downloaded and copied in their proper directories, all we must do is to link them to our project.

Update the engine's CMakeLists.txt file as shown in the following code.

- Project/engine/CMakeLists.txt

```
# . . .

# windows platform
if ( WIN32)
    target_link_libraries(${PROJECT_NAME} SDL2 SDL2main SDL2_image
SDL2_ttf SDL2_mixer)
    target_include_directories(${PROJECT_NAME} PUBLIC C
${CMAKE_SOURCE_DIR}/windows/includes)
    target_link_directories(${PROJECT_NAME} PUBLIC C
${CMAKE_SOURCE_DIR}/windows/libs)
endif ( WIN32)

# . . .
```

As you can see, we use the function “target_link_libraries” to specify which library we want to link to our project. SDL2, SDL2main, SDL2_image, SDL2_ttf, and SDL2_mixer is all linked to our engine.
That’s all there is to linking SDL libraries to our project on Windows. Now let’s do the same thing with Linux.

## Installing SDL on Linux

The following installation instructions are only for Debian/Ubuntu 64-bit based distributions.

Note: You’ll need root rights to install all the packages in this section.

- Step 1: Update Package Manager

An old version of the package manager may not support the current version of SDL2, make sure you’ve upgraded to the latest version using the next command.
sudo apt-get update

- Step 2: Find current Version of SDL

The following command will search the apt-get cache of the current SDL2 version we want to install.
sudo apt-cache search libsdl2

- Step 3: Download Development Version of SDL2

libsdl2-dev is the development package for SDL2. You can use the following command to install the package on your system.
sudo apt-get install libsdl2-dev

You can see where it is installed on your system by navigating to the following directories: “/usr/include/SDL2” for header files and “/usr/lib/x86_64-linux-gnu” for binaries.

Just like that we have SDL2 installed on our system and all we need to do is to link it to our project. But we also want to repeat the process for SDL_image, SDL_ttf and SDL_mixer as well.

- Step 4: Installing SDL_image, SDL_ttf, and SDL_mixer

This part is a little bit tricky as we need to manually create some files to instruct CMake about where to find each extension library. Use the following commands to install each library on your system. These commands will also install these libraries in the same locations as SDL2.

```
sudo apt-get install libsdl2-image-dev
sudo apt-get install libsdl2-mixer-dev
sudo apt-get install libsdl2-ttf-dev
```

After you've completed the installation, we'll need to create a “.cmake” config file for each library installed above. These files will be used by CMake to locate the library files. In some cases, the commands above will automatically create all “.cmake” config files for each library, but we want to consider the worst-case scenario. So, let's see how that can be done.

- SDL_image (sdl2_image-config.cmake)

Use this command to create and open a new “.cmake” file for SDL_image.

```
cd /usr/x86_64-linux-gnu/cmake/
mkdir sdl2_image
cd sdl2_image
sudo nano sdl2_image-config.cmake
```

Copy the following code in the file created above and save it with Ctrl-X.

```
set(prefix "/usr")
set(exec_prefix "${prefix}")
set(libdir "${prefix}/lib/x86_64-linux-gnu")
set(SDL2_IMAGE_PREFIX_I "/usr")
set(SDL2_IMAGE_EXEC_PREFIX_I "/usr")
set(SDL2_IMAGE_INCLUDE_DIRS "${prefix}/include/SDL2")
set(SDL2_IMAGE_LIBRARIES "-lSDL2_image")
```
