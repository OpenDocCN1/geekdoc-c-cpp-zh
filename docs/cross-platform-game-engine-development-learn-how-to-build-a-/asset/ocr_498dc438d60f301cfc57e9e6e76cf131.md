# Adding Sound Effects

Our engine should be able to play sounds when ask to, without interfering with other processes. That's possible only if the audio files are loaded beforehand in the engine's memory.

Having to load the audio file when asked to play is quite inefficient because loading the audio file can take some time depending on the format and also the size. That's why we have created the audio asset in the chapter about asset management.

We also need to implement a function to load audio files as we did for textures and fonts. The following code snippet shows the definition of the asset registry's member function to load audio files.

# Loading Audio File

The process remains the same. We load the audio data from a source file, and we check if the loading was successful then we create an asset.

```
engine/src/assets/registry.h

// ...

FUSE_INLINE audio_o_asset* load_audio(const std::string& src, const std::string& name) {
    audio_o_clip audio_o;
    audio_o.data = Mix_LoadWAV(src.c_str());
    audio_o.filename = src;

    if (!audio_o.data) {
        FUSE_ERROR("%s", IMG_GetError());
        return NULL;
    }

    auto asset = new audio_o_asset();
    asset->instance = audio_o;
    asset->name = name;

    _data[type_id<audio_o_asset>()].push_back(asset);
    return asset;
}

// ...
```
