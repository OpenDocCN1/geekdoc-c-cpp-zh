# Setting up SDL2 Libraries

Simple Direct Media Layer (SDL) is a cross-platform development library designed to supply low level access to audio, keyboard, mouse, joystick, and graphics hardware via OpenGL and Direct3D. It is used by video playback software, emulators, and popular games including Valve's award-winning catalogue and many Humble Bundle games.

SDL officially supports Windows, Mac OS X, Linux, iOS, and Android. Support for other platforms may be found in the source code. SDL is written in C, works natively with C++, and there are bindings available for several other languages, including C# and Python. SDL 2.0 is distributed under the zlib license. This license allows you to use SDL freely in any software. [18]

# Installing SDL on Windows

SDL installation on Windows is as simple as copying and pasting files into the proper locations. However, we must exercise caution because this is often the basis of our project's failure to compile successfully.

+   Step 1: Download

https://www.libsdl.org/download-2.0.php is the link to the official download page of SDL. We could download SDL's source code and compile it ourselves, but we don't want to make things any more complicated. We'll just download and link the built binaries to our project.

![](bbox=[0.08, 0.55, 0.92, 0.67])

Based on the compiler used, there are two versions of the development libraries available for Windows. There is a Visual C++ Compiler version and a MinGW-Compiler version. We previously installed the Microsoft Visual C++ Compiler Toolset. That's why we will download the Visual C++ version.

+   Step 2: Unpack

Unpack the downloaded package using WinRAR, Zip, or any other package manager on your choice. Within the unpacked directory, there are two primary subdirectories: “include” and “lib”. All header files are in the include folder and the library’s binaries are found in the lib folder. The SDL comes in 32-bit and 64-bit versions under the x86 and x64 folders, respectively.
