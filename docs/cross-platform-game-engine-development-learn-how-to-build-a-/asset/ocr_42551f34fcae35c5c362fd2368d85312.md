# # Linux Platform

Now that our Windows environment is ready, let’s do the same for Linux. The Ubuntu 21.10 is used in this book. Keep in mind that you need to have root access to install the tools described in this section.

# # Installing Visual Studio Code

https://code.visualstudio.com/docs/setup/linux is the link to the Visual Studio Code’s official documentation website. You will find a step-by-step description of how to install VS-Code in all major Linux distributions. Please refer to it if you run into any problems when installing it on your PC or if you are using a different distribution of Linux because the following installation instructions are only for Debian/Ubuntu-based distributions. Get the VS-Code package here: https://code.visualstudio.com/download.

![](bbox=[0.078, 0.36, 0.92, 0.555])

Figure 11 VS-Code Linux:

Install the .deb package using the following command:

```
sudo apt install ./<path/to/package>.deb
# If you're on an older Linux distribution, you will need to
# run this instead:
# sudo dpkg -i <path/to/package>.deb
# sudo apt-get install -f # Install dependencies
```

This will automatically install the apt repository and signing key, allowing you to use the system’s package manager to enable auto-updating.

> Note : You can’t also install VS-Code in Linux using the built installer.
