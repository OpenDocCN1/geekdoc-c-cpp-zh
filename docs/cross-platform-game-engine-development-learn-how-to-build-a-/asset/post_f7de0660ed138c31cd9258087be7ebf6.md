## Asset Management

an asset manager oversees loading, storing, converting, and destroying assets in a game (engine).

There is no specific design of how an asset manager should be implemented, but there are some fundamental concepts that we can apply to achieve our goal(s).

Each asset should have a unique universal identifier (UUID) and a name because that information will be used to search the asset in the registry. We also want each asset type to have a specific type identifier that will be used to save each asset in the specific memory block of the registry. ### Audio Asset

A game without audio is just flat-out dead and not fun to play. We'll keep the same pattern for the audio assets as well. The SDL mixer library provides two types of audio data. Each new chunk will be assigned to a dedicated channel, whereas there is only one channel for all music. That is the reason we are using Mix_Chunk instead of Mix_Music.
