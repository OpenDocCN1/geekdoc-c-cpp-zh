and then plays that sound using the SDL function "Mix_PlayChannel". This function takes the channel, the audio data, and the loop count, respectively to play the sound.

We want the background music to be played directly at the start of the game. So, we can simply add that in the pipe spawner script's start function. Add the following code to your pipe spawner.

```
```cpp
// ...
engine/src/scripts/pipe_spawner.h

// ...
FUSE_INLINE void d_on_start() {
  // play music on channel "1" infinite loop
  play_audio("music", 1, -1);
}

// ...
```
```

We are playing the sound asset called "music" on channel number "1" as long as the program is running. However, we want to be able to stop the background music when the player dies. To do so, simply call SDL_HaltChannel(channel) to stop that specific channel.

We can do that in the pipe spawner script or the player controller script. But because we played it in the spawner script, we will also stop there when the plane crashes.

# Plane Crash Sound Effect

We want to have a sound effect played when the plane crashes. We can do that in the "on_collision" function of the player controller script. Whenever a collision is triggered, we will simply play the sound.

```
```cpp
// ...
engine/src/scripts/player_controller.h

// ...
FUSE_INLINE void d_on_collision(ecs::entity e) {
  play_audio("boom");
  auto& sp = get_component<ecs::sprite_component>();
  sp.sprite = get_asset<texture_asset>("dead")->d;
  get_component<ecs::collider_component>().disabled = true;
  get_component<ecs::rigidbody_component>().disabled = true;
}
