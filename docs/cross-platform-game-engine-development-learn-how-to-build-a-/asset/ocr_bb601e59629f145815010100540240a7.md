# # Rigid Body Component

Now that we have a basic understanding of what rigid bodies are, we want to use that knowledge to implement our rigid body component. We will first create a rigid body instance and then use that instance to define our component.
Create a new directory in the folder tree of the engine called "physics" and add
the file described below.

```
engine/src/physics/rigidbody2.h
```

The gravity scale defines how an object is affected by gravity. We are assuming
that all objects have a mass of 1 kg, and we will use the gravity scale to simulate
the difference of mass.
We are not defining the acceleration here because we will simplify the equation
from the table by directly embedding the equation of the acceleration in the
velocity's equation.
We have implemented some functions that can be used to apply diverse types of
forces to the rigid body.
