Both scripts will check if a build folder exists in the project's root directory and create one if not. Then CMake will produce all the files required for building the project for the current platform.

Because we will be using assets like audios, textures, and fonts, we want to copy the contents of the resource folder into the output folder of the built project.

Additionally, the win-build.bat will make sure all libraries .dll files required are copied from the folder windows/bin to the output folder. CMake will go on to compile the project using the platform-specific compiler that was installed earlier in the previous chapter.

CMake needs to know where to find the root CMakeLists.txt file to generate the project files for the current platform. That's why we need to pass that information to CMake as an argument using [-O <path to file>].

The [-B <output dir>] is used to tell CMake where to store all the build files generated.

The symbol BUILD_SHARED_LIBS is required to force the compiler to build all the libraries in our project as a shared library instead of a static library..
