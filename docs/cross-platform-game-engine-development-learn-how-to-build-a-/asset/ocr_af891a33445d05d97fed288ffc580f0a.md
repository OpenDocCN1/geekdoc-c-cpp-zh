You must also make sure to update the scene's register_system() function so that when registering a new system, the prepare() function of that system will be called with the right arguments list (See code below).

```
engine/src/scene/scene.h

template <typename T>
FUSE_INLINE void register_system() {
    FUSE_STATIC CASSERT(std::is_base_of<ecs::system<T>>::value);
    auto new_system = new T();
    new_system->prepare(&registry, &renderer, &assets);
    this->_systems.push_back(new_system);
}
```
