# Static Linking vs Dynamic Linking

A computer program, in general, is a sequence of instructions written in a programming language to instruct the computer to perform certain actions. Those actions often require the use of other external libraries to function properly. Linking is the act of connecting an external library with an executable. There are primarily two types of linking techniques: static and dynamic linking.

Static linking combines the libraries and the program into a single executable file. This is done by the linker, which is the last step in the compilation process. To resolve external references, the linker mixes the required libraries with the program code. The linker creates an executable file that may be loaded into memory after that. The statically linked file contains both the library modules and the executable. This will generally result in a heavyweight output file.

Dynamic linking is handled by the operating system. The shared library is only loaded in memory when the executable starts its execution. As a result, the size of the executable file is reduced. External libraries can be updated and recompiled. The load time is also reduced if the shared library code is already in memory.
