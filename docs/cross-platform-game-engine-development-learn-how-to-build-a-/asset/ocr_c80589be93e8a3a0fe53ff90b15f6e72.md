# Conclusion

We can all agree that rendering a texture with SDL is quite simple, however, this is due in part to the way our engine is constructed. The system is exclusively focused on a specific group of entities.

Keep in mind that you can play around with the transform and sprite to see how they affect the rendering of the sprite. For example, you could increase the scale, change the rotation value, or even change the value of the flip in the sprite component to something else.
