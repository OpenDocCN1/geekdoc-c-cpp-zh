If you open the file .vscode/tasks.json, you will see the build task that we have defined with the label “build everything”.
If you click on “build everything”, the build-win.bat shell-script will be executed if you are on Windows or the build-linux-sh if you are on Linux. The result will be store in build/bin/Debug/ if you are on Windows or build/bin/ if you are on Linux.

# Execution

Similar to the compilation, we have two ways to execute our compiled project. The first method is by just pushing the key F5. The second method is to use the VS-Code Debug-View.

![](bbox=[0.085, 0.43, 0.915, 0.59])

Figure 19 Run Program

If you open the .vscode/launch.json file, you will see that we have two launch configurations defined, one for Windows and another one for Linux. Before you try to execute your application, make sure you have the correct configuration for your operating system selected.
This will also copy all the .dll files in the windows/bin into the output folder. Click on the small play button near the "Windows" or "Linux" configuration.
