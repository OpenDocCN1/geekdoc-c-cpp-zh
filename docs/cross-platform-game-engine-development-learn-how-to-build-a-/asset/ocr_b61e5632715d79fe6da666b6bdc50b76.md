# Step 3 Update CMakeLists.txt File

Now that all files are placed in their location, we want to finalize by telling CMake to link the library when we try to compile our project.

# Project/engine/CMakeLists.txt

```
# . . .
if ( W NB2)
    target_link_libraries(${PRJ ECT_NAME} SDL2 SDL2main SDL2_image
    SDL2_ttf SDL2_mixer yaml-cppd)
    target_include_directories(${PRJ ECT_NAME} PUBLIC C
    ${CMAKE_SOURCE_DIR}/windows/includes)
    target_link_directories(${PRJ ECT_NAME} PUBLIC C
    ${CMAKE_SOURCE_DIR}/windows/libs)
endif ( W NB2)
# . . .
```

The small part highlighted in yellow is the only thing you need to add to this file to link yaml-cpp. Check if everything is working by just trying to compile your project. If the compilation succeeds, then all is well.

Note : If you encountered any problem while compiling the library, then check the official instructions found on the GitHub repository.
