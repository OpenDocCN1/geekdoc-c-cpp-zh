# Installing yaml-cpp (Linux)

The installation of yaml-cpp on Linux is quite simple. We are going to do that using the system package manager, as we did for SDL. The good news is that we don’t have to manually setup the CMake config files as we did for the extension libraries of SDL.

+   Step 1 Installing the Package

Install yaml-cpp on your Linux system by running the command below. We’re updating our package management to guarantee that the version of yaml-cpp we’re trying to install is compatible. We don’t have to copy any header or library file here. Everything is managed by the package manager.

```
sudo apt update
sudo apt install libyaml-cpp-dev
```
