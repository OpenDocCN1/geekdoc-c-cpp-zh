# Figure 24 Data Oriented Design

Each game object is represented by a number. That number is used to know which component belongs to that entity. You can see that all components of the same type for all entities are stored together in a contiguous manner. This will have a positive impact on the CPU cache. Many game engines use this design because it offers reliable performance and maintaining it is also not difficult.
