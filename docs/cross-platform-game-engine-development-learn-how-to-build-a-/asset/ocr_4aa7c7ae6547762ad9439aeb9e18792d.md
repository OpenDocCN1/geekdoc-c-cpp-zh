# Rigid Body System

The rigid body system code comes next. It works in a loop across all entities with a rigid body component.
Before we begin any physics simulation, we must ensure that the rigid body is not disabled.

```
engine/src/ecs/systems/rigidbody_system.h
#pragma once
#include "ecs/system.h"
namespace fuse::ecs {
struct rigid_body_system: system {
FUSE_INLINE void update(float dt) {
for (auto& e : view<rigid_body_component>()) {
auto& bd = e.get_component<rigid_body_component>();
if (bd.disabled) { continue; }

auto& tr = e.get_component<transform_component>();
vec2f f_g = vec2f(0.0f, bd.body.gravity_scale * 9.8f);
bd.body.velocity += (bd.body.force + f_g) * dt;
tr.translate += bd.body.velocity * dt;
}
}
};
}
```

As you can see, we simply check if the rigid body is enabled, and we then proceed
to calculate its current position based on the force and gravity.
