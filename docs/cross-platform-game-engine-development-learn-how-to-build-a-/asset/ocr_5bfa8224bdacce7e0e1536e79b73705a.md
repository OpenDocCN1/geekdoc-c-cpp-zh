Finally, we ensure that each system that we initialized is also closed properly. This step is critical because we want to make sure we release the memory allocated by each system before quitting.

```
engine/src/core/entry.h

#pragma once
#include "application.h"

extern fuse::app_config fuse::create_application();

int main(int argc, char** argv) {
    auto config = fuse::create_application();
    fuse::run_application(config);
    return 0;
}
```

The “main” function can be defined in the game executable, but we chose to declare it in the engine library to hide the game loop from the outside. The only access to the engine right now is done via the create_application().
