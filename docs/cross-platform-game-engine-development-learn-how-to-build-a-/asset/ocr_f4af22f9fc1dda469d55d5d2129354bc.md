# What is YAML?

YAML is a human-friendly data serialization language [29], [19]. YAML originally stood for "Yet Another Markup Language", but since 2002 it has been replaced with the recursive acronym "YAML Ain't Markup Language". As a result, YAML is defined as an encoding language that isn't one.

Markup languages like: XML, HTML are primarily used to store data in a human-readable format. YAML differs from XML in that it uses a simple approach. The main justification for YAML is its simplicity, which includes constraints that arise from XML's broad application spectrum. However, YAML's main competitor is JSON, rather than XML.

# How does YAML work?

YAML turns data from a program's internal format into a text file. Because this is possible even for complex data types like two- or multidimensional arrays, the elements are serialized and sent one after the other.

If we were to serialize the following data structure using YAML, the result will look like shown below.

```
struct transform_component {
    vec2f translate = vec2f( 0.0f );
    vec2f scale = vec2f( 1.0f );
    float rotation = 0.0f ;
};
```
