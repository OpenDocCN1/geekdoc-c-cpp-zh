# # Sprite Renderer

You'll see how simple it is to add new features to our engine from now on.
This chapter will go through how to render textures. We will create a sprite component that takes the asset_id of a texture asset. That component will be attached to an entity and will be drawn to the screen via a sprite renderer system.
Before we get to render the texture or even create the component, we want to see how to load them from source files.
