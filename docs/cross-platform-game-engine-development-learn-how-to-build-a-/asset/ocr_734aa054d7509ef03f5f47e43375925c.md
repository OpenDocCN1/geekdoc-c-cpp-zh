# engine/src/core/application.h

```
#pragma once

namespace fuse {
struct app_config {
    int width = 0;
    int height = 0;
    std::string title;
    std::string version;
};

// will be defined in game.exe
app_config create_application();
FUSE_API void run_application(const app_config&);
}
```

The function create_application() must be implemented in the game executable to initialize the configurations of the application we want to create. The app_config definition so far is straightforward. The function run_application() will be in charge of handling events, updating and rendering the scene as well as compute the time of our engine.
