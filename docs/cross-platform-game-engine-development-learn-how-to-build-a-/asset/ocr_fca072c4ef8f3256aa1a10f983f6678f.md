# Installation for Windows Platform

If you already have Visual Studio 2017 or later installed on your system and you don't plan to use Linux at any point in time, then you can simply skip this section. But if you want to learn how to set up an environment for multiplatform development, then you must follow the following steps.

# Installing Visual Studio Code

https://code.visualstudio.com/download can be used to download Vs-Code. It's available in 32-bit and 64-bit. Download the version for your operating system (Figure 5). Execute the .exe file and keep all the configurations to default and make sure to enable the "Add to PATH" option. Note that the default color theme is dark, but you can easily change that in the settings with CTRL+K, CTRL+T.
