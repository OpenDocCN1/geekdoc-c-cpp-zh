# Animation Component

Again, you must update the code inside of the header file **graphics.h** by adding the code snippet below, which shows how the animation component is defined. This component is similar to the sprite component in that it also only takes an **asset_id** for the animation we want to play.

```
engine/src/ecs/components/graphics.h

struct animation_component {
    FUSE_INLINE animation_component(const animation_component&) = default;
    FUSE_INLINE animation_component() = default;
    SDL_RendererFlip flip = SDL_FLIP_NONE;
    asset_id animation = INVALID_ID;
};
```
