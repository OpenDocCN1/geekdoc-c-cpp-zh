# Step4: Installing SDL_image, SDL_ttf, and SDL_mixer

This part is a little bit tricky as we need to manually create some files to instruct CMake about where to find each extension library. Use the following commands to install each library on your system. These commands will also install these libraries in the same locations as SDL2.

```
sudo apt-get install libsdl2-image-dev
sudo apt-get install libsdl2-mixer-dev
sudo apt-get install libsdl2-ttf-dev
```

After you've completed the installation, we'll need to create a “.cmake” config file for each library installed above. These files will be used by CMake to locate the library files. In some cases, the commands above will automatically create all “.cmake” config files for each library, but we want to consider the worst-case scenario. So, let's see how that can be done.

+   SDL_image (sdl2_image-config.cmake)

Use this command to create and open a new “.cmake” file for SDL_image.

```
cd /usr/i386_64-linux-gnu/cmake/
mkdir sdl2_image
cd sdl2_image
sudo nano sdl2_image-config.cmake
```

Copy the following code in the file created above and save it with Ctrl-X.

```
set(prefix "/usr")
set(exec_prefix "${prefix}")
set(libdir "${prefix}/lib/x86_64-linux-gnu")
set(SDL2_IMAGE_PREFIX_I "/usr")
set(SDL2_IMAGE_EXEC_PREFIX_I "/usr")
set(SDL2_IMAGE_INCLUDE_DIRS "${prefix}/include/SDL2")
set(SDL2_IMAGE_LIBRARIES "-lSDL2_image")
```
