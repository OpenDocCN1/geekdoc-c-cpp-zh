Asset types are serialized in groups. Since we have access to the data map of the asset registry, we can loop through each asset type array to serialize their content. Because the assets are all stored as pointers to the "asset_instance", we have to make sure to cast them to their proper type so that we will be able to access their member variables.

The deserialize function simply calls for each asset type the custom deserialize function.
