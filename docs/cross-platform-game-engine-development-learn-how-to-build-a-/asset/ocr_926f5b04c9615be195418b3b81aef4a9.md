# Assets Definition

![](bbox=[0.07, 0.1, 0.9, 0.345])

Update your project folder tree as shown above by creating the folder and files highlighted in red. We are now going to create each asset type step by step, starting with the base asset, which is going to contain some common information about all kinds of assets.

```
#pragma once

namespace fuse {
using asset_typeid = uint32_t;
using asset_id = uuid64;

struct asset {
FUSE_NONIE virtual ~asset() = default;
asset_id id = generate_uuid();
std::string name;
};
}
```

Each asset should have a unique universal identifier (UUID) and a name because that information will be used to search the asset in the registry. We also want each asset type to have a specific type identifier that will be used to save each asset in the specific memory block of the registry. That’s why we’ve created the typedef asset_typeid which is simply a 32-bit integer similar to what we did for events and components.
