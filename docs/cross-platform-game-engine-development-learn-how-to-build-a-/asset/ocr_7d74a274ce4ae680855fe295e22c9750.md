# Sprite Renderer System

Now that we can load the texture, and that we have our sprite component ready, let's create a system that will target all entities with a sprite component and render their sprites to the screen.

```
engine/src/ecs/systems/sprite_renderer_system.h

#pragma once
#include "ecs/system.h"

namespace fuse::ecs {
struct sprite_renderer_system : system {
    FUSE_INLINE void update(float) {
        for (auto& e : view<sprite_component>()) {
            // get components
            auto& tr = e.get_component<transform_component>();
            auto& sp = e.get_component<sprite_component>();

            // get texture from asset registry
            auto& sprite = _assets->get<texture_asset>(sp.sprite)->instance;

            // define target viewport
            SDL_FRect dst{
                tr.translate.x, tr.translate.y,
                sprite.width * tr.scale.x, sprite.height * tr.scale.y
            };

            // render sprite
            SDL_RenderCopyExF(_renderer, sprite.data, NULL, &dst,
                tr.rotation, NULL, sp.flip);
        }
    }
};
}
```

We are retrieving the list of entities with a sprite component, and we loop through the list and render each entity's sprite. We start by getting the transform component because we want to know where and how the sprite will be rendered to the screen. We then proceed to get the sprite component, which gives us the asset_id of the sprite to render. We then retrieve the texture asset from the asset registry.

To render the sprite, we use the function SDL_RenderCopyExF(). This function takes a pointer to the target renderer as its first argument. The renderer was created alongside the window and was passed to the scene's constructor as an argument, which also passed to the system::prepare() function.
