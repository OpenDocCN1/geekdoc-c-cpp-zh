bit version has no effect on our coding experience; only the final product is altered. Using 32-bit allows you to run the final piece of software on both 32-bit and 64-bit systems, but the opposite is not true. The 64-bit version will be used in this book.

SDL2.2.x.

# Step 3: Copy

Copy all header files found in SDL2-2.x.x/include/ into the folder Project/windows/includes/SDL2/ of your project.

Copy the following .lib files SDL2.lib, SDL2main.lib from SDL2-2.x.x/lib/x64 into your Project/windows/libs folder.

Also make sure to copy the SDL2.dll file from SDL2-2.x.x/lib/x64 in the folder: Project/windows/bin.

We now officially have SDL2 installed and ready to use, but we still have to link it to our project. But before we get to that, we will first install all of the extension libraries for SDL as well.
