# # Platform and Tools

The code presented in this book should run on Windows, Linux, and MacOS. However, the code has only been tested on Linux and Windows. We couldn't do any testing on a Mac computer because we didn't have one on hand. This is also why we'll only discuss Windows and Linux implementations in this book.

The following is a description of the computer and operating systems that were used to produce the code in this book:

# ## Tools

Visual-studio-code (VS-code) will be used for code editing, while CMake will manage the build process. Both Vs-code and CMake can run on all the platforms mentioned above.
