# Asset Registry

Now that we've defined all our asset types, we'll need to create an asset registry to keep track of all of the assets we add to the game engine. Next is a code snippet that shows how the asset registry is defined.

The get() function is used to retrieve a specific asset from the registry using its asset_id and its type. All assets are stored in the member variable _data, which is a map of std::vector of asset pointers.

To retrieve an asset, we first check if there is an array for that specific asset's type available. We do that by checking if the typeid of asset is available on the map. If there is no array available, we simply return NULL. But if the array is found, we will proceed to search for the asset with the id passed as an argument. The next function is get_id(), which takes the name of the asset as an argument and its type name as a template parameter. This function will search for the asset and return its asset_id.

We also want to have the ability to add assets to our registry because some assets, like the tile map, and the animation, are not initially loaded from a source file, like textures, fonts, and audios. That's why we have the add() function.

If you take a closer look at all the asset types we have defined, you will see that they all have a default constructor. It's to make sure that the add() function can create a default version of that asset.
