# Installing SDL on Linux

The following installation instructions are only for Debian/Ubuntu 64-bit based
distributions.

Note : You’ll need root rights to install all the packages in this section.

+   ↘ Step1: Update Package Manager
+   
+   An old version of the package manager may not support the current version of
+   SDL2, make sure you’ve upgraded to the latest version using the next command.
+   sudo apt-get update

+   ↘ Step2: Find current Version of SDL
+   
+   The following command will search the apt-get cache of the current SDL2
+   version we want to install.
+   sudo apt-cache search libsdl 2
