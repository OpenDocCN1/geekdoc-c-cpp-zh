represented here by a small array of 8-bit unsigned integers in which each index stores the state of a key. SDL has predefined macros to distinguish between event types. For example, when a key is pressed, the `SDL_KEYDOWN` event is triggered, or `SDL_MOUSEDOWN` when a mouse button is pressed. The `is_key(int)` function will simply return the state of the key code past as argument.

You can test the setup in your main loop using the following code snippet.

```
// engine/src/core/application.cpp
// ...
inputs::initialize(window);

while (is_running) {
    inputs::dispatch_events();
    if (inputs::is_key(SDL_SCANCODE_A)) {
        FUSE_INFO("key 'a' pressed!");
    }
    SDL_RenderClear(renderer);
    SDL_RenderPresent(renderer);
}
```

The following result will be printed in your console as you press the key ‘A’.

> [info] key 'a' pressed!
> [info] key 'a' pressed!

We now have a basic concept in place. But we still can't close the windows or event notify our application about the event that just occurred.

# Identification of Events

We want to create a system in which each event triggered can also be broadcast to the entire application via a sort of notification system. That way, we will be able to implement callback functions anywhere in our program and make it respond to a specific event occurrence. Now, one major problem with a notification system is recognizing what type of message or event is being sent. As a result, we will create a type system in which each event's type will be assigned a unique number. That number will be used to recognize that event and call the proper callback when it occurs. Create the following header file in your project:

+   engine/src/core/typeid.h
