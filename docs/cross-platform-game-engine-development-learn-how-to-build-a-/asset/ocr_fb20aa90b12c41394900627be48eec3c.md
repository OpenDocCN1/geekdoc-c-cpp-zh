The update() function of the scene will simply loop through all available systems and call their update functions accordingly. The function add_entity() is used to add an entity with a transform- and an info component. Because all entities in our engine will at least have those two components, we want to quickly do that by just calling this function.

If you take a close look at the start() function, you will see that we are adding one entity using the add_entity() function and also make sure the start function of all systems is also called to make sure all registered system is also started.
