# # Events Handling

Events can occur in various places in a program, e.g., when a user clicks a button or moves the mouse. The event system's job is to recognize the event and execute a specific callback action. We now want to give our window the ability to respond to events like resizing, mouse motion, key down, and more. Create two files in your project, **inputs.h** and **inputs.cpp**.

```
```cpp
#pragma once

namespace fuse::inputs {
FUSE_API void initialize(SDL_Window*);
FUSE_API void dispatch_events();
FUSE_API bool is_key(int);
}
```
```

```
```cpp
#include "pch.h"
#include "inputs.h"

namespace fuse::inputs {
static const uint8_t* keyboard = NULL;

bool is_key(int key) { return keyboard[key]; }

void initialize(SDL_Window* window) {
    keyboard = SDL_GetKeyboardState(NULL);
}

void dispatch_events() {
    static SDL_Event event;
    while (SDL_PollEvent(&event)) {
        switch (event.type) {
        case SDL_KEYDOWN
            keyboard = SDL_GetKeyboardState(NULL); break;
        case SDL_KEYUP:
            keyboard = SDL_GetKeyboardState(NULL); break;
        }
    }
}
}
