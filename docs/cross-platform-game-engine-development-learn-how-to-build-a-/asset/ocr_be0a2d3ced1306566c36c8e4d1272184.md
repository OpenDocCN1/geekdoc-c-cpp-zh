The **callback_function** is a function type definition that takes a pointer to an **event_instance** and returns a Boolean to tell if the event system should continue managing that event or stop.

We then use that **callback_function** type we just created to define our final **event_callback** structure, which must also be templated to make sure its callback function member variable also has a specific type. The function "execute" is a virtual function that the **event_callback** structure must implement to make sure the callback function can be executed by the dispatcher.

**callback_list** is simply a typedef of an array of callbacks. It will make our code more readable.
