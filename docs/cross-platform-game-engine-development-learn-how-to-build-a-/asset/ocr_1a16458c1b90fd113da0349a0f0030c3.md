# Installing C/C++ and CMake Extensions

You can add an extension to VS-Code by opening the Extensions-View using the side-menu (Figure 14) or the key combination Ctrl+Shift+X. These extensions must be installed on both Windows and Linux.

![](bbox=[0.08, 0.18, 0.92, 0.32])

Figure 14 Extensions View

# C/C++ Extension

This extension adds language support for C/C++ to VS-Code including features such as IntelliSense, syntax highlighting, error checking, and debugging. Install it by searching for 'C/C++' like shown below (Figure 15).

![](bbox=[0.08, 0.48, 0.92, 0.63])

Figure 15 C/C++ extension

# CMake Tools Extension

The CMake Tools extension combines VS-Code and CMake to make configuring, building, and debugging our C++ project simple. You can install it by searching for CMake Tools in the extensions view (Figure 16).
