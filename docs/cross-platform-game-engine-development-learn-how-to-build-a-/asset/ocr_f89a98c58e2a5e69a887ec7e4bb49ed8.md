# Entity Serializer

We are going to create a custom serializer to serialize all entities and their components. We will also create a serializer for our assets later.

# Basic Serialization Example

```
void d serialize_info(YAML::Emitter& em, ecs::entity& e) {
    auto& i = e.get_component<ecs::info_component>();
    em << YAML::Key << "i_info_component";
    em << YAML::BeginMap;
    em << YAML::Key << "uuid" << YAML::Value << i.uuid;
    em << YAML::Key << "name" << YAML::Value << i.name;
    em << YAML::Key << "tag" << YAML::Value << i.tag;
    em << YAML::EndMap;
}
```

The code snippet above shows how the "info_component" can be serialized using yaml-cpp. It takes a YAML::Emitter as a parameter and the entity we want to retrieve the component from. The emitter is just a handle that can be used to push data to the buffer allocated for the current serialization process. Each file of the component is stored using a key. The key will be used to retrieve the data by deserialization. The component itself is a map which content data fields.

# Basic Deserialization Example

```
void d deserialize_info(YAML::Node node, ecs::entity& e) {
    if (auto data = node["i_info_component"]) {
        auto& i = e.add_component<ecs::info_component>();
        i.name = data["name"].as<std::string>();
        i.tag = data["tag"].as<std::string>();
        i.uuid = data["uuid"].as<u64>();
    }
}
```

To deserialize an object, you need the YAML::Node that represents the object in the YAML file you are trying to deserialize from. That's why this function takes a YAML::Node as a parameter and the target entity that will have the component attached to. All nodes in a YAML document (including the root) are represented by YAML::Node. We have the ability to access any data in the node using its key. The template function "as<T>()" is used to convert the value to its correct type.
