# Suffering through trigonometry

I won't bother to explain trigonometry to you. If your code needs a trig function, you know why. But what you probably don't yet know is that trigonometric functions in C — and, indeed, in all programming languages — use radians, not degrees.

# What's a radian?

Glad you asked. A radian is a measurement of a circle or, specifically, an arc. It uses the value π (pi) instead of degrees, where π is a handy circle measurement. So instead of a circle having 360 degrees, it has 2π radians. That works out to 6.2831 (which is 2 × 3.1415) radians in a circle. Figure 11-1 illustrates this concept.
