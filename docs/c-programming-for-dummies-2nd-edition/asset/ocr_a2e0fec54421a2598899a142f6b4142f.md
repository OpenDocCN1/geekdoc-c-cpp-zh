The solution I would use is to devise a function that returns the first character in the stream and then swallows the rest of the characters until the \n is encountered. This function appears in Listing 13-10:

# LISTING 13-10: A Single-Character Input Function, getch()

```
int getch(void)
{
    int ch;

    ch = getchar();
    while(getchar()!='\n')
    ;
    return(ch);
}
```
