Here is the output I see:

Grid forward:
0:0 0:1 0:2
1:0 1:1 1:2
2:0 2:1 2:2

Grid backwards:
2:2 2:1 2:0
1:2 1:1 1:0
0:2 0:1 0:0

Both functions rely upon the defined constant GRID to set their size. The forward() function outputs the grid from low numbers to high; the backwards() function does the opposite.

Note how the for loops are constructed in the backwards() function:

```
for(x=GRID-1; x>=0; x--)
```

Variable x is initialized to the ending value for statement in the forward() function. The loop continues as long as the value of variable x is greater than or equal to zero. This is how both loops generate similar values in their grid output.
