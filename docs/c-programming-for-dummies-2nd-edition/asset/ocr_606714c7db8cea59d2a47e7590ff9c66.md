# SEE ANYTHING FAMILIAR?

Arrays of pointers should be somewhat familiar to you. If you've worked through Chapter 15, you may remember this thing:

```
```c
int main(int argc, char *argv[])
```
```

The full declaration of the main() function includes an array of pointers as the second argument. In Chapter 15, you treat each item as its own string, which is exactly how the construction works. But secretly, what's being passed to the main() function is an array of pointers.

By the way, the full declaration of the main() function can also be written like this:

```
```c
int main(int argc, char **argv)
```
```

![](bbox=[0.15, 0.58, 0.22, 0.7])

Just to keep you from understanding this topic too well, accept that the *array[] notation can also be written as **array. Effectively, the ** declaration refers to a pointer to a pointer.
