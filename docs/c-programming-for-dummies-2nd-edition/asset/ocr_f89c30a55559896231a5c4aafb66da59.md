| Expression | Address p | Value *p |
|---|---|---|
| p | Yes | No |
| *p | No | Yes |
| *p++ | Incremented after value is read | Unchanged |
| *(p++) | Incremented after value is read | Unchanged |
| (*p)++ | Unchanged | Incremented after it's read |
| *++p | Incremented before value is read | Unchanged |
| *(++p) | Incremented before value is read | Unchanged |
| ++*p | Unchanged | Incremented before it's read |
| ++(*p) | Unchanged | Incremented before it's read |
