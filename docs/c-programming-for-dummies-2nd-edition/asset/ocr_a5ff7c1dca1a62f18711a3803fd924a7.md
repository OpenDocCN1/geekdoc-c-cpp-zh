# Creating string storage

The malloc() function is commonly used to create a text input buffer. This technique avoids declaring and sizing an empty array. For example, the notation

```
char input[64];
```

can be replaced by this statement:

```
char *input;
```

The size of the buffer is set in the code by using the malloc() function. In Listing 20-2, malloc() at Line 8 declares a char array — a storage buffer — for about 1,024 bytes. Okay, it's a kilobyte (KB). I remember when they were a big deal.
