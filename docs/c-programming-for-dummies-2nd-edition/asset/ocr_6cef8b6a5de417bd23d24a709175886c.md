The enum keyword is handy for declaring a clutch of sequential constants. In Listing 16-8, it declares false and true, assigning zero to the value of false and 1 to true. The keyword saves time over making multiple constant declarations. For example.

```
const int zero = 0;
const int one = 1;
const int two = 2;
const int three = 3;
```

These four statements can be expressed by using a single enum statement:

```
enum { zero, one, two, three };
```

The enum keyword is followed by a set of curly brackets. They contain the constant declarations, separated by commas, as just shown. The first constant is assigned a value of zero, with each subsequent constant's value incremented by one. This statement can appear in a function, as shown in Listing 16-8, or it can be declared externally.
