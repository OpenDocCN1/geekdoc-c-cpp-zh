# Escape Sequences

| Characters | What It Represents or Displays |
|---|---|
| \a | Bell ("beep!") |
| \b | Backspace, non-erasing |
| \f | Form feed or clear the screen |
| \n | Newline |
| \r | Carriage return |
| \t | Tab |
| \v | Vertical tab |
| \\ | Backslash character |
| \? | Question mark |
| \' | Single quote |
| \" | Double quote |
| \xnn | Hexadecimal character code nn |
| \onn | Octal character code nn |
| \nn | Octal character code nn |
