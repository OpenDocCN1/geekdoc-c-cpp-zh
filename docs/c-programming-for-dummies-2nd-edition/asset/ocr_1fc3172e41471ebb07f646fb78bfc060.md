You can refine the error messages further, if you like. I kept the messages short in Listing 25-3 so that the text wouldn't wrap in this book. For example, a better message than “Permission denied” is “The permission settings for ‘blorfts’ do not allow renaming. Consider resetting the file’s permissions and trying again.” This message is descriptive and informative, which is what users appreciate: It explains the problem and also offers a solution.
