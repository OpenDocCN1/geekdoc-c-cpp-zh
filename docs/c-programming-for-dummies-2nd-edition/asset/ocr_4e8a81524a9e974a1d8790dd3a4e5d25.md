# Watching variables

Sometimes, you must get down-and-dirty in memory and look at a variable's value while the code runs. The Code::Block's debugger allows you to watch any variable in a program, showing you that variable's contents as the program runs. Listing 25-2 assists in this process:

# LISTING 25-2: Where Variables Lurk

```
```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    int x;
    int *px;

    px=&x;
    for(x=0;x<10;x++)
        printf("%d\n",*px);
    return 0;
}
```
```
