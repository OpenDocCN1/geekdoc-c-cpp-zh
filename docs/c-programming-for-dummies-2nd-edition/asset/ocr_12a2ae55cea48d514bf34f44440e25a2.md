# LISTING 10-7: Exiting a Function with return

```
#include <stdio.h>

void limit(int stop);

int main()
{
    int s;

    printf("Enter a stopping value (0-100): ");
    scanf("%d",&s);
    limit(s);
    return(0);
}

void limit(int stop)
{
    int x;

    for(x=0;x<=100;x=x+1)
    {
        printf("%d ",x);
        if(x==stop)
        {
            puts("You won!");
            return;
        }
    }
    puts("I won!");
}
```

The silly source code shown in Listing 10-7 calls a function, limit(), with the value read in Line 10. A loop in the function spews out numbers. If a match is made with the function's argument, a return statement (refer to Line 25) bails out of the function. Otherwise, execution continues and the function ends when the loop is done. No return function is required at the end of the function because no value is returned.
