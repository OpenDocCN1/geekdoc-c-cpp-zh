Okay, I'll explain: The compiler appends the null character (\0) to any string literal, such as the one declared at Line 5 in Listing 18-2. This extra byte of storage is accounted for by the sizeof operator. The extra storage is not counted by the strlen() function, which returns a character count in the string itself. The terminating null character is a delimiter, not a character in the string.
