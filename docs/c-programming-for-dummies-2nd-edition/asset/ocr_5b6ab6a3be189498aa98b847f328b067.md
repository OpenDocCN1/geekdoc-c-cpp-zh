# LISTING 5-4: Where Integers Dare

```
#include <stdio.h>

int main()
{
    printf("%d/%d=%d\n",2,5,2/5);
    return(0);
}
```

Three %d (integer) placeholders are used in the print() statement. Each corresponds to an integer value argument in the function: 2, 5, and then the expression 2/5. The placeholders in the format string must match the argument count and the type of value each argument represents, as illustrated in Figure 5-1.
