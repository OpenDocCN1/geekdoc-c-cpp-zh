# What Are the
Parts of an Ozobot?

# Outside Ozobot

+   - Main board: The main board is a tiny computer. It is the Ozobot’s brain.
+   - Sensors: Ozobot’s **optical** sensors are like its eyes. They see light and follow your paths.
+   - Power button: This button turns Ozobot on and off.

# Inside Ozobot

+   - Battery: The battery powers Ozobot.
+   - Motors: Motors make Ozobot’s wheels turn.
