# Glossary

**calibrate** (KAL-uh-brayt) to adjust a device so it works correctly in different situations

**code** (KODE) ideas written using computer language

**optical** (AHP-ti-kuhl) having to do with sight

**OzoCodes** (OH-zoh-kohdz) special codes that Ozobot can read and understand

**programs** (PROH-gramz) sets of instructions for computers to follow

**sensors** (SEN-surz) electronic devices that can detect things such as light, color, or sound
