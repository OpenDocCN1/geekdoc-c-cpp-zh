# Types of Ozobots

There are two kinds of Ozobots. The first is called Ozobot 1.0. Ozobot 1.0 can follow the lines you draw for it. It can also read special codes called **OzoCodes**. The second kind of Ozobot is the Ozobot Bit. This Ozobot can do everything Ozobot 1.0 does. It can also be controlled using a computer or tablet.
