# # What Is an Ozobot?

Ozobot is a robot. It moves on two wheels. It can also spin and flash its lights. The most special thing about Ozobot is that it can see. Ozobot uses its **sensors** to see the colors red, green, blue, and black. This lets Ozobot follow paths drawn in these colors.

# ## What Can I Do with Ozobot?

You can control Ozobot by drawing paths for it on paper. You can also control Ozobot with a computer. Ozobot can help you learn more about how computers work by using **code**.
