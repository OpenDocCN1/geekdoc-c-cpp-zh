# # Modules

Modules are bundles of code that help you deal with common coding challenges. Modules provide the less exciting bits of code, letting you focus on the fun stuff. Also, because modules are used by a lot of people, they are likely to work well and be free of bugs.

# ## Built-in modules

There are lots of useful modules included with Python. This collection of modules is known as the Standard Library. Here are some interesting modules from the library that you might want to experiment with.

![](bbox=[0.538, 0.309, 0.978, 0.441])

![](bbox=[0.058, 0.471, 0.34, 0.589])

+   ▷ **statistics**
+   
+   Use `statistics` to calculate averages or find the most common value in a list of numbers. It's handy if you need to work out an average score in a game.

+   ▷ **datetime**
+   
+   This module lets you work with dates. You can get today’s date, or work out how long it is until a special day.

![](bbox=[0.647, 0.487, 0.949, 0.612])

+   ▷ **random**
+   
+   You used this module to make random selections in Password Picker. It's great for adding an element of chance to a game or program.

![](bbox=[0.253, 0.756, 0.371, 0.865])

+   ▷ **webbrowser**
+   
+   You can control the computer’s web browser with this module, allowing you to open web pages directly from your code.

![](bbox=[0.616, 0.642, 0.805, 0.863])

+   ▷ **socket**
+   
+   The socket module allows programs to communicate across networks and the Internet. It could be used to create an online game.
