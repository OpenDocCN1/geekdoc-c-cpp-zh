# Escape character (\\)

The backslash in `Emma\'s Room` tells Python to ignore the apostrophe so that it doesn’t treat it as the quotation mark that closes the whole string. A backslash used like this is called an escape character. It tells Python not to count the next character when working out if the line makes sense or contains errors.

# While loops

What happens if you don’t know how many times you want to repeat a code? Do you need a crystal ball or some other way of seeing into the future? No, it’s okay! You can use a **while** loop.

# ▷ Loop condition

A while loop doesn’t have a loop variable that’s set to a range of values. Instead it has a loop condition. This is a Boolean expression that can be either True or False. It’s a bit like a bouncer at a disco asking you if you’ve got a ticket. If you have one (True), head straight for the dance floor; if you don’t (False), the bouncer won’t let you in. In programming, if the loop condition isn’t True, you won’t get into the loop!
