
## 18 Is it a snap?

To complete the game, create your last function: snap(). This function will check which player has hit their key and whether the snap is valid (correct). It will then update the scores and show a message. Add this code beneath the next_shape() function.

![](img/6b18a113f7aa9338e32f3ac1fa217987_177_0.png)

Don’t forget to save your work.

```python
def snap(event):
    global shape
    global player1_score
    global player2_score
    valid = False

    c.delete(shape)

    if previous_color == current_color:
        valid = True

        if valid:
            if event.char == 'q':
                player1_score = player1_score + 1
            else:
                player2_score = player2_score + 1
            shape = c.create_text(200, 200, text='SNAP! You score 1 point!')
        else:
            if event.char == 'q':
                player1_score = player1_score - 1
            else:
                player2_score = player2_score - 1
            shape = c.create_text(200, 200, text='WRONG! You lose 1 point!')
    c.pack()
    root.update_idletasks()
    time.sleep(1)
```

Label these variables as global so the function can change them.

Check if it’s a valid snap (if the color of the previous shape matches the color of the current shape).

If the snap is valid, check which player snapped and add 1 to their score.

This line shows a message when a player makes a valid snap.

Otherwise (else), take away one point from the player that snapped.

This line shows a message when a player snaps at the wrong time.

### Stop players cheating

Right now, if a shape is called and both players hit the shape key at the same time, they each get a point. In fact, they will still be able to score points up until the next shape is shown, since the previous and current will still be the same. Try this hack to stop the players from cheating.

### 1. Go global

Now we need to set the previous_color and current_color variables on the snap() function because these are not accessible from inside the function unless we make them global variables.

```python
global previous_color
```

### 2. Block a multiple snap

Next add the following line to the `snap()` function to set the value of `previous_color` to the empty string (`''`) after a correct snap. Now if a player presses their key again before the next shape is shown, they will lose a point. This is because `''` will never be equal to the current color, except before the first shape is shown.

```python
shape = c.create_text(200, 200, text='SNAP!')  # scored 1 point!
previous_color = ''
```

![](img/6b18a113f7aa9338e32f3ac1fa217987_180_0.png)

> There's nothing I don't know about multiple snaps!

### 3. Prevent early snaps

Since `previous_color` and `current_color` are equal at the beginning of the game, players can still cheat by pressing their key before the first shape appears. To solve this, set the two variables to different strings at the start. Change their values to “a” and “b”.

```python
previous_color = 'a'
current_color = 'b'
```

> Starting with different strings means that a snap can't be made until the shapes appear on the screen.

### 4. Change the messages

If both players press their keys at almost the same time, it might be confusing as to who has scored or lost a point. To fix this, you can change the messages that are displayed when players attempt a snap.

## Matchmaker

### What happens

When you run the program, it opens a window showing a grid of buttons. Click on them in pairs to reveal the hidden symbols. Try to remember the location of each hidden symbol to quickly find all the pairs.
