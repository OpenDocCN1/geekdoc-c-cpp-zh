#### 术语表

- **密码：** 一组用于改变消息以隐藏其含义的指令。
- **加密：** 隐藏秘密消息。
- **解密：** 揭示秘密消息。
- **密文：** 加密后的消息。
- **明文：** 加密前的消息。
