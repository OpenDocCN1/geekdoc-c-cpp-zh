The program uses Tkinter to draw and move shapes, and the random module to place them on the screen.

New eggs appear at the top of the screen, in random positions.

> Let's catch some eggs!

Lives: 2

This counter shows you how many lives you have left.

You can add static shapes, such as grass, to the screen to create background scenery.

If an egg touches the bottom of the screen, you lose a life.

# Arcade-style game

This last project brings all your coding skills together to create an impressive arcade-style game. The code is quite complex, so check your code carefully for bugs at each stage and don't be discouraged if you make a few mistakes along the way. Once you've cracked Egg Catcher, you'll be all set to start making your own games.
