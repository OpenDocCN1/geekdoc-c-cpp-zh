# 2. Edit function

Next change the update_clue() function as shown below. Each time the player guesses a letter, the program will now take away the number of times that letter appears in the secret word from unknown_letters.

![](bbox=[0.53, 0.48, 0.98, 0.67])

At first all the letters are unknown.

```
```python
def update_clue(guessed_letter, secret_word, clue, unknown_letters):
    index = 0
    while index < len(secret_word):
        if guessed_letter == secret_word[index]:
            clue[index] = guessed_letter
            unknown_letters = unknown_letters - 1
        index = index + 1

    return unknown_letters
```
