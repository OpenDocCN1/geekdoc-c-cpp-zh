# Configuring Canvas items

You can alter things that appear on the Canvas by using Canvas’s `itemconfigure()` function. In this game, for instance, you use `itemconfigure()` to change shapes from hidden to visible, but you could also use it to change other characteristics. To use `itemconfigure()`, put the name of the item you want to change in brackets, followed by a comma and then the characteristic and its new value.

```
c.itemconfigure(shape, state=NORMAL)
```
