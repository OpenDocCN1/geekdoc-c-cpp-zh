def get_line_width():
    choice = input('Enter line width (superthick, thick, thin): ')
    if choice == 'superthick':
        line_width = 40
    elif choice == 'thick':
        line_width = 25
    else:
        line_width = 10
    return line_width
```
```

This asks the user to choose how thick the line is.

If short lines are chosen, this sets `line_width` to 10.
