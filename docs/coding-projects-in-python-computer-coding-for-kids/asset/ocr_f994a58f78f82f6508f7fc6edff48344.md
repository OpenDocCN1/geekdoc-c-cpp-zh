# How it works

You use an actor to represent the catcher. An arc is one part of a whole circle. Tkinter draws circles inside an invisible box. The first two `catcher_start` coordinates (x1 and y1) plot where one corner of the box should be. The second two coordinates (x2 and y2) plot the position of the box’s opposite corner. The `create_arc()` function has two parameters, both given in degrees (°), that say where in the circle to draw the arc: `start` says where to start drawing, while `extent` is how many degrees to draw before stopping.

![](bbox=[0.044, 0.069, 0.317, 0.322])

A whole circle is 360°. The code starts drawing the arc just over half way around the circle, at 200°.
