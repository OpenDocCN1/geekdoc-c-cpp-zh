# ## How it works

The code for this project draws star shapes and places them at random locations in a Turtle Graphics window. You can use the code to create a function that can draw a star. Then you'll make a loop that repeats it, drawing lots of different stars all over the sky.

# ▽ Starry Night flowchart

The flowchart is quite simple, with no questions to be asked or decisions to be made. Once the turtle has drawn the first star, the program loops back and repeats the star-drawing steps nonstop until you quit.

+   1. START
+   2. Draw the sky
+   3. Choose a random number of points for the star
+   4. Choose a random color
+   5. Choose a random position in the sky
