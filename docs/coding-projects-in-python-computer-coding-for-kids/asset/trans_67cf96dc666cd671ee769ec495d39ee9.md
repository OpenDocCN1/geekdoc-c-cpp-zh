### 一体化手臂

分几部分绘制手臂会让重新定位或添加额外手臂变得麻烦。在这个技巧中，你将编写一个一次性绘制整条手臂的函数。

### 创建手臂函数

首先添加这个新函数，它绘制手臂形状并为其着色。

![](img/6b18a113f7aa9338e32f3ac1fa217987_81_1.png)

```python
t.penup()

def arm(color):
    t.pendown()
    t.begin_fill()
    t.color(color)
    t.forward(60)
    t.right(90)
    t.forward(50)
    t.right(90)
    t.forward(10)
    t.right(90)
    t.forward(40)
    t.left(90)
    t.forward(50)
    t.right(90)
    t.forward(10)
    t.end_fill()
    t.penup()
    t.setheading(0)
```

这一行会填充后续移动所形成形状的颜色。

设置颜色。

海龟按照这些命令绘制手臂。

停止填充形状颜色。

重置海龟，使其再次面向右侧。
