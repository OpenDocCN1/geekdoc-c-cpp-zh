# 1.2 PERMUTATION-BASED INDEXING

# 1.2.1 Indexing Model

# Definition 1

Given a set of N objects o_i, D = {o_1,...,o_N} in m-dimensional space, a set of reference objects R = {r_1,...,r_n} ⊂ D, and a distance function that follows the metric space postulates, we define the ordered list of R relative to o ∈ D, L(o,R), as the ordering of elements in R with respect to their increasing distance from o:

L(o,R) = {r_{π1},...,r_{πn}} such that d(o,r_{πj}) ≤ d(o,r_{πj+1}) ∀j = 1,...,n-1

Then, for any r ∈ R, L(o,R)_r indicates the position of r in L(o,R). In other words, L(o,R)_r = j such that r_{πj} = r. Further, given ñ > 0, L̃(o,R) is the pruned ordered list of the ñ first elements of L(o,R).

Figure 1.1b and c gives the ordered lists L(o_i,R) (ñ = 4) and the pruned ordered lists L̃(o_i,R) (ñ = 2) for D and R illustrated in Figure 1.1a.

In K-nearest neighbor (K-NN) similarity queries, we are interested in ranking objects (to extract the K first elements) and not in the actual interobject distance values. PBI relaxes distance calculations by assuming that they will be approximated in terms of their ordering when comparing the ordered lists of objects. Spearman footrule distance (d_SFD) is considered to define the similarity between ordered lists. Formally,

d(q,o_i) ≈ d_SFD(q,o_i) = Σ_{r=1}^n | L̃(q,R)_r - L̃(o_i,R)_r | . (1.1)
