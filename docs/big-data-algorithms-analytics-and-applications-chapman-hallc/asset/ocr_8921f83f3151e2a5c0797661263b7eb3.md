# ABSTRACT

The purpose of this project is to present a set of algorithms and their efficiency for Multiple Sequence Alignment (MSA) and clustering problems, including also solutions in distributive environments with Hadoop. The strength, the adaptability, and the effectiveness of the genetic algorithms (GAs) for both problems are pointed out. MSA is among the most important tasks in computational biology.
