We use Amazon CloudWatch [13] to monitor the status of Hadoop jobs and tasks and EC2 instances. For EC2 instances, CloudWatch provides a free service named Basic Monitoring, which includes metrics for CPU utilization, data transfer, and disk usage at a 5 min frequency. For the EMR service, CloudWatch has metrics about HDFS, S3, nodes, and map/reduce tasks. All these built-in EC2 and EMR metrics are automatically collected and reported. AWS users can access these metrics in real time on the CloudWatch website or through the CloudWatch application programming interfaces (APIs).
