E_I^U(Q_k) can be extended to the whole query workload QWL by considering the average relative inference error \bar{E}_i(QWL) that takes into account the contributions of relative inference errors E_i(Q_k) of all the queries Q_k in QWL. Similarly to what was done for the average relative query error \bar{E}_Q(QWL), we model \bar{E}_i(QWL) as follows: \bar{E}_i(QWL)= \sum_{k=0}^{|QWL|-1} \frac{|Q_k|}{|QWL|} \cdot E_i(Q_k),

that is, \bar{E}_i(QWL)= \sum_{k=0}^{|QWL|-1} \frac{|Q_k|}{\sum_{j=0}^{|QWL|-1}|Q_j|} \cdot \frac{|I(Q_k)-\tilde{I}_v(Q_k)|}{\max\{I(Q_k),1\}}, under the constraint \sum_{k=0}^{|QWL|-1} \frac{|Q_k|}{|QWL|}=1.

Note that, \bar{E}_i(QWL) is defined in dependence on \tilde{I}_v(Q_k) rather than \tilde{I}(Q_k). For the sake of simplicity, here and in the remaining part of the chapter, we assume E_i(Q_k) \equiv E_i^U(Q_k).

The concepts and definitions allow us to introduce the singleton aggregation privacy-preserving model \mathcal{X}=\langle I(\cdot),\tilde{I}(\cdot),\tilde{I}_v(\cdot)\rangle, which is a fundamental component of the privacy-preserving OLAP framework we propose. \mathcal{X} properly realizes our privacy OLAP notion.

Given a query Q_k \in QWL against the target data cube A, in order to preserve the privacy of Q_k under our privacy OLAP notion, we must maximize the inference error E_i(Q_k) while minimizing the query error E_Q(Q_k). While the definition of E_i(Q_k) can be reasonably considered as an invariant of our theoretical model, the definition of E_i(Q_k) strictly depends on \mathcal{X}. Therefore, given a particular class of OLAP queries \mathcal{C}, in order to preserve the privacy of queries of kind \mathcal{C}, we only need to appropriately define \mathcal{X}. This nice amenity states that the privacy-preserving OLAP framework we propose is orthogonal to the particular class of queries considered and can be straightforwardly adapted to a large family of OLAP query classes.
