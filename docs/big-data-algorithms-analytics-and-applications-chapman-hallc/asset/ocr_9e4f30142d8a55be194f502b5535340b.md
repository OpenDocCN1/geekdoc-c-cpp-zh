# 2.6 SCALABILITY AND COST EVALUATION

The evaluation includes scenarios to emulate the incremental updates of data sets, in terms of data sizes. We consider scalability as to what extent a platform can utilize computing resources to handle increasing data sizes or data rates before a platform scales out on more computing resources. We also observe the cost incurred as the data sizes and update rates grow. To this end, we collect the following metrics to observe the performance of the Hadoop platform (Table 2.2).

The system status metrics help to identify any bottleneck that limits performance. We explore the metrics of the platform status to observe factors at the application level that link to a bottleneck and affect performance most. The MapReduce task status provided by CloudWatch includes *remaining map tasks, remaining map tasks per slot, remaining reduce tasks, running map tasks, and running reduce tasks*.
