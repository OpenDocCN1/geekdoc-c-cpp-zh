# 2.9 CONCLUSION

In this chapter, we evaluate the scalability and cost of the Amazon Hadoop service through a movie recommendation scenario, which requires frequent updates on continuous input data streams. We implement this sample application with the MapReduce programming model and deploy it on the Amazon EMR service. We present the monitoring techniques to collect both system- and platform-level metrics to observe the performance and scalability status. Our evaluation experiments help to identify the minimal time interval or the highest frequency of data processing, which is an indicator on the autoscaling settings of optimal resource provisioning.
