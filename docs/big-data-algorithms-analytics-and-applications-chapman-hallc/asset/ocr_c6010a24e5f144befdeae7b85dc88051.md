# 16.3  FUNDAMENTAL DEFINITIONS AND FORMAL TOOLS

A data cube A defined over a relational data source S is a tuple A = (D, F, H, M), such that (1) D is the data domain of A containing (OLAP) data cells, which are the basic aggregations of A computed over relational tuples stored in S; (2) F is the set of dimensions of A, that is, the functional attributes with respect to which the underlying OLAP analysis is defined (in other words, F is the set of attributes along which tuples in S are aggregated); (3) H is the set of hierarchies related to the dimensions of A, that is, hierarchical representations of the functional attributes shaped in the form of general trees; (4) M is the set of measures of A, that is, the attributes of interest for the underlying OLAP analysis (in other words, M is the set of attributes taken as argument of SQL aggregation whose results are stored in data cells of A). Given these definitions, (1) |F| denotes the number of dimensions of A, (2) d ∈ F a generic dimension of A, (3) |d| the cardinality of d, and (4) H(d) ∈ H the hierarchy related to d. Finally, for the sake of simplicity, we assume that we are dealing with data cubes having a single measure (i.e., |M| = 1). However, extending schemes, models, and algorithms proposed in this chapter to deal with data cubes having multiple measures (i.e., |M| > 1) is straightforward.

Given an |F|-dimensional data cube A, an m-dimensional *range query* Q against A, with m ≤ |F|, is a tuple Q = (R<sub>k<sub>0</sub></sub>, R<sub>k<sub>1</sub></sub>, …, R<sub>k<sub>m−1</sub></sub>, A), such that (1) R<sub>k<sub>i</sub></sub> denotes a *contiguous range* defined on the dimension d<sub>k</sub> of A, with k<sub>i</sub> belonging to the range [0, |F| − 1], and (2) A is an SQL aggregation operator. The evaluation of Q over A returns the A-based aggregation computed over the set of data cells in A contained within the multidimensional subdomain of A bounded by the ranges R<sub>k<sub>0</sub></sub>, R<sub>k<sub>1</sub></sub>, …, R<sub>k<sub>m−1</sub></sub> of Q. Range-SUM queries, which return the SUM of the involved data cells, are treated as examples of range queries.
