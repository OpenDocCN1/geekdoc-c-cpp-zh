# # Practice Problems

+   1. Write a program that generates two random numbers between 0 and 10. The program calculates their sum and product. It prints out the sum and product on the screen and asks the user to guess the 2 numbers. The user inputs his guesses through a form and it is checked against the initial two numbers. If he gets it right, then he gets a congratulatory message. If he gets it wrong, the program lets him know the correct answers. At the end, there is the option to restart the program and try again.
+   2. Write a program that generates a random number between 0 and 20. It squares the number and prints the square on the screen. Then, it asks the user to guess what the number is. The user inputs the number via a form and the program checks whether it is correct or not.
+   3. Write a program that allows the user to input 3 numbers via a form. These 3 numbers are supposed to be the 3 sides of a triangle. The program then checks if this is a right-angled triangle. The program lets the user know if it is a right-angled triangle (Hint: Use Pythagros theorem to check).
