## Example 6 – Guess a country name

In this example, we make a game similar to hangman where we ask the user to guess the name of the country. We have a tuple of various country names. The user is allowed to guess a few times incorrectly before losing. We make a list of correctly guessed characters where correct guesses are appended to. The user wins when the guessed list length is equal to country name length. Note that we used a list data structure for guessed characters since it is continuously updated while countries are in tuple since it is never mutated.

```python
# guess a random country

import random

# list of countries
countries = ('france', 'usa', 'spain', 'india', 'brazil', 'norway', 'germany')

# Choose random country from countries
country = random.choice(countries)

# number of turns
turns = 4

# a list to store the guessed characters
guessed = []
while turns > 0:

    # print guessed characters
    for char in country:
        if char in guessed:
            print(char, end='')
        else:
            print('_', end='')

    print()
    print(f"You have {turns} left.")

    # user input
    guess = input("I guess a character:")

    # make sure guess is lowercase
    guess.lower()

    # if guess already made
    if guess in guessed:
        print("You have already made this guess\n")

    # check input with the character in word
    if guess not in country:
        turns -= 1
    else:
        # character is in word, append character
        # the number of times it appear in word
        count = country.count(guess)
        for i in range(count):
            guessed.append(guess)

    # if guessed length match country length then user wins
    # else if ran out of turns user loses
    if len(guessed) == len(country):
        print("Congratulation you guessed correctly!!")
        break
    elif turns == 0:
        print("Good luck next time")
```

### Example 2: Dice Game

This is a game of dice between 2 players where dice is flipped 1000 times. If dice flip result in an even number player 1 wins one point, if it is odd player 2 wins 1 point. The dice flip is implemented using random number function.

```python
# dice game if it is even player 1 point
# odd player 2 gets 1 point
# import random library
import random

# create class player with score initialize to zero
class player:
    score = 0

# if number is even return True else return False
def is_even(n):
    even = None
    if n % 2 == 0:
        even = True
    else:
        even = False

    return even

# create players
player1 = player()
player2 = player()


# run loop for 1000 times
for i in range(1000):
    # dice flip, return random number between 1 and 6 inclusive
    dice = random.randint(1, 6)

    if is_even(dice):
        player1.score += 1
    else:
        player2.score += 1

print("Player 1 score is: ", player1.score)
print("Player 2 score is: ", player2.score)
```

`randint` which generate numbers between 1 and 6 inclusive. Class `player` creates player objects with score initialized to zero. Each time one player wins we access `player.score` and increment it by one.

```text
Player 1 score is: 518
Player 2 score is: 482
```

We can see that players' scores are close, which is expected since each player's win probability is 50% as the ratio of odd:even of dice output is 1:1.
