# Remainder

In order to get the remainder of a division use the modulo operator which is represented by the symbol %.

![](bbox=[0.126, 0.215, 0.805, 0.564])

```
```cpp
#include<iostream>
using namespace std;

int main(){
    int x = 3;
    int y = 2;
    int remainder = x % y;
    cout << remainder ;
    return 0;
}
```
```

The output of the code will be **1**, which is the reminder when x is divided by y.
