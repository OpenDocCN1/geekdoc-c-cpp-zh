## Substrings and String Index

There are a couple of other string manipulation techniques that I would like to discuss before we move on. These are string index and substring.

String Index gives you the position within a certain string that another string occurs. For example, the string index of boy in the string “The boy climbed the tree” is 4, because boy starts at the 4th character of the overall string.

A substring lets you extract a section of an existing string. For example, in the same string “The boy climbed the tree”; if we do a substring from 6 to 10 we get “oy cl” because those are the characters between 6 and 10.

Now, let’s look at an example below:

```html
<html>
<head><title>Substrings and String Index</title></head>
<body>
<form id="form">
What is your day like? <textarea name="sentence" cols="20" rows="5" id="sentence"></textarea><br><br>
What string would you like to find the String Index Of? <input name="text" type="text" size="20"><br><br>
</form>

<button onclick="strindex()">Find Index</button>

<script>

function strindex()
{
var daydesc=document.getElementById("sentence").value;
var str = document.getElementById("text").value;
var ind=daydesc.indexOf(str);
document.write('The String Index is '+ind);
}
</script>
</body>
</html>
```

In the above example, daydesc is the large string and str is the string we need to find the string index for. The variable ind stores the value of the string index and then we print the answer using document.write. Now, let’s run the program:

Find Index

## Introduction to CSS

### What is CSS?

CSS stands for cascading style sheets. CSS is used to set up the design and style of your website – including the fonts, colors, layouts, shading and schemes. They work great in partnership with html and JavaScript.

### How to Use CSS in a html website

The best way to use CSS is to create a separate css file and refer to it in the html header file.

Now, let’s create a css file.

- 1. Open a blank Notepad++ document.
- 2. Click ‘Save As’ and choose file type as ‘CSS’. Let’s name this file as style

![](img/443990a0ec620659ce8be783c0758bc6_204_0.png)

![](img/443990a0ec620659ce8be783c0758bc6_205_0.png)

- 3. Click ‘Save’
- 4. Go to the relevant html and include the line below in the header file.

```html
<link rel="stylesheet" href="style.css" />
```

- 5. (Optional) If you want to include any button css elements, you need to define a button class as below:

```html
<button class="btn str" onclick="substr()">Find
SubString</button>
```

Now, let’s insert the style sheet in the example from last chapter.


## CSS Terms

- **html{}**: The above term is used to define css for the entire html file. Anything that is within the bracket will be used in the html code.
- **body{}**: Defines the style for the body of the html code.
- **.btn{}**: Sets the style for any buttons in the web page. You have to define a class called ‘btn’ in your html code for the button. See code above for example of that.
- **.btn:hover{}**: Sets the style for the button when you hover the mouse over the button in the web page.
- **background-color**: Background color of the website.
- **text-decoration**: Used to add decoration to the text such as wavy, dotted, curved etc.
- **text-transform**: Used to capitalize and un-capitalize entire words or parts of a word.
- **text-align**: Can align the text at the left, right or center of the page.
- **color**: Sets the color of the text on the page.
- **padding**: Sets the gap between the edge of the page and the text/button elements.
- **line-height**: Sets the height of the line for the text.
- **font-family**: Sets the type of font that you want to use for the text.
- **font-size**: Sets the size of the font.
- **font-weight**: Can set the font as bold when needed.
