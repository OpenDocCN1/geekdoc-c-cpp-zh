# exp() Function

The exp() function can be used to calculate the power of e.

```
```python
>>> math.exp(10)
22026.465794806718
>>> math.exp(5)
148.4131591025766
>>>
```
```

# log() Function

This function returns the logarithm of the specified number. The natural logarithm is computed with respect to the base e. The following example demonstrates the usage of this function:

```
```python
>>> math.log(10)
2.302585092994046
>>> math.log(1)
0.0
>>>
```
```

It can also be used as log(x,y) where y is base.

```
```python
>>> math.log(100,10)
2.0
>>> math.log(10,3)
2.095903274289385
>>>
```
