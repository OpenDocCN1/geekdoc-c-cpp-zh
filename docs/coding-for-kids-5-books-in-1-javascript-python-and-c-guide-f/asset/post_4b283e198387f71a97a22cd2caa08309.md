### CSS Example

```css
html, body {
    text-decoration: none;
    text-transform: capitalize;
    text-align: center;
    margin: 0;
    padding-top: 100px;
    min-height: 100%;
    color: black;
    background-color: cyan;
    line-height: 1;
    font-family:serif;
    font-size: 20px;
    font-weight: bold;
}
.btn {
    background-color: Crimson;
    border: none;
    color: black;
    padding: 10px 24px;
    text-align: center;
    text-decoration: none;
    display: inline-block;
    font-size: 16px;
}
.btn:hover {
    background-color: MidnightBlue;
    color: white;
}
```

In the html and body of the css code, the text is set to center of the page and capitalized. It is 100 px from the top and black in color with a line height of 1. It is bold in color with font size of 20px. The background of the page is cyan (light blue).

There is a separate css set up for the button. It is Crimson (Red) in color with black text. The text is 10 px from the top and 24 px from the sides. It is center aligned with a 16px font size.

When we hover the button with the mouse, the background of the button changes to MidnightBlue (Blue) and the text changes to White.

## Linking Multiple Web Pages

Now, you have a web page set up with CSS linked up. But you may notice that the web page switches back to the original design when you click the Find Substring button. This is because the JavaScript section is not linked to the webpage yet.

To refresh your memory, the code we are talking about takes in a string and prints a substring based on the preference of the user. The user specifies the start and end of the substring. Here's the code below:

```html
<html>
<head>
<title>Substrings and String Index</title>
<link rel="stylesheet" href="style.css" />
</head>
<body>
<form id="form1">
What was your day like?: <textarea name="sentence" cols="20" rows="5" id="sentence"></textarea><br><br>
Substring From?:<input name="txtstr1" type="number" id="txtstr1" size="20"><br><br>
Substring To?:<input name="txtstr2" type="number" id="txtstr2" size="20"><br><br>
</form>

<button class ="btn str" onclick="substr()">Find Substring</button>

<script>
function substr()
{
var daydesc=document.getElementById("sentence").value;
var strnum1 = document.getElementById("txtstr1").value;
var strnum2 = document.getElementById("txtstr2").value;

var str=daydesc.substring(strnum1,strnum2);
document.write("The Substring is "+str);
}
</script>
</body>
</html>
```

As you can see the code is linked to the style.css sheet to get the current design. So, we get an output below:

This code basically writes the stylesheet onto the JavaScript function.
