# 6) Accessing multiple elements in the list

We can access multiple elements in a list using the ‘:’ operator.

+   list[0] returns the first element
+   
+   list[0:4] returns the elements from index 0 to index 3, Note index 4 is not included
+   
+   list[0:] returns the elements from index 0 till the end of the list
+   
+   list[2:] return the elements from index 2 till the end of the list

The index -1 refers to the last element of the list , -2 refers to the second last element and so on.
