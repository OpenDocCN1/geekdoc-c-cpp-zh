## Intro to HTML

### What is HTML?

HTML stands for HyperText Markup Language. HTML is the language that humans use to connect with web browsers like Chrome, Internet Explorer, Firefox, etc. Sometimes, it is assisted by CSS and JavaScript; but the basic structure of a web page is defined by HTML. It is pretty simple and easy to grasp for even beginners to programming and young kids. HTML is done using simple tags that look like the ends of an arrow.

### Example of an HTML tag

Here’s what an HTML tag looks like:

```
<p> - Example of a tag
```

Every HTML tag has an extra tag that signals the end of the tag. The ending of a tag has a slash in it in addition to the two ends of a tag. See below for a simple example.

```html
<p> - Tag starts
</p> - Tag ends
```

## Basic HTML Tags and What They’re Used For

- `<html>` — This is the tag that starts every piece of HTML code.
- `<head>` — This is the code that is executed first before anything else.
- `<title>` — This is the code written in the top ribbon of the browser.
- `<body>` — Includes the information that appears on the page.
- `<p>` — This is used for a paragraph of text that appears on the body.
- `<h1>, <h2>, <h3>, <h4>, <h5>, <h6>` — These are used for headings on text in descending order of size. `<h1>` is the largest size heading, and `<h6>` is the smallest.
- `<strong>` — This is used to bold text.
- `<ul>` — This is used for unordered lists such as bulleted items.
- `<li>` — Used to add a bullet icon before a line of text.
- `<ol>` — This is used for ordered lists such as items numbered 1, 2, 3…
- `<div>` — These are larger sections of content that generally contain several paragraphs, headings, etc.
- `<a>` — This is used to hyperlink text. Hyperlink is what happens when you click on a piece of underlined text and it links to another page.
- `<img>` — This is used for adding images to a web page.

Now, you might be wondering that it’s a lot to learn. Don’t worry. You don’t need to memorize any of it for now. Just use it as a reference for when you code. We’re going to go through an example that will explain everything better.
