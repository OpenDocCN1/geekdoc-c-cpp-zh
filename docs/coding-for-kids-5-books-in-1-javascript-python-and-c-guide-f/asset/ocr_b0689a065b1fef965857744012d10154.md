# Nested Conditional

What if we want to create branches inside other branches? We can nest if conditional inside other if conditional. This is called nested conditional. Keep in mind that too many nested conditionals generally make the program difficult to read so use them only when you can’t capture you program logic using combination of logical operators.

```
If expression:
    If expression1:
        statement1
    else:
        statement2
else:
    statement3
```

In this snippet, nested conditional was reduced into a flat if conditional using “and” logical operators. Observe that the second if conditional is easier to read.
