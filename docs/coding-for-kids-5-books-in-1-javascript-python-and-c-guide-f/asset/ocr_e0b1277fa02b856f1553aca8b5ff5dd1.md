# # JavaScript Example

# ## What is JavaScript?

JavaScript is a high-level programming language. It is most commonly used
to perform user actions on a html page.
It also helps to enhance interactions of users on a web page.

# ## How to Use JavaScript in html

There are two ways to use JavaScript on a html page:
The first way is to just include JavaScript code within <script> tags. It
would be like below:

```
```html
<html>
<head>
<title> </title>
</head>
<body>
<script>
</script>
</body>
</html>
```
```

The JavaScript code would be within the two script tags shown in red
above.
