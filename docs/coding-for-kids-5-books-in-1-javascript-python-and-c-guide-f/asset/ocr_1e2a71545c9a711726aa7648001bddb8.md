The next thing to avoid is to search for the latest textbook on JavaScript; and read it out for your kid. These are as useful for learning programming; as a dictionary is for learning a language. They are expensive, and more useful as a reference tool for existing programmers. I also recommend against coding camps. These can work for a minority of students; but most students get lost in the large group of kids that are learning. One to one attention is the best way to get going.

# First Steps to Get Started

This book is the best way to get started. I’ve broken down programming into a series of basic chapters; and relate it to the real world. The first chapter will help you set up your JavaScript and html files for you to get started.

I also have code for every chapter that you can copy and paste to get working. Every aspect of the code is well explained; and I have exercises that you can complete yourself with the concepts in the chapter.

I also have a recommended one on one tutor at the end of the book; and additional books you can use to build on your knowledge.
