# Having Fun with Strings

# Strings and String Variables

We’ve touched on this in the previous chapters. A string is any piece of text that is used in a program. As an example, “abcd” is a string; while the number 7 is not a string. It is an integer.

A string variable is a place to store a string. As an example, st is a string variable below that stores the value of “abcd”.

```
var st=”abcd”;
```

Now, let’s have some fun with strings using our knowledge of JavaScript and loops.
