
## parseInt()

parseInt() changes the number to a whole number, whether it is a decimal or not. For example, parseInt(2.8) would equal 3. parseInt(2) would just be 2.

## parseFloat()

parseFloat() does the opposite of parseInt(). It changes the number to decimal. For example, parseFloat(2) would equal 2.0. parseFloat(3.1) would just be 3.1.

## JavaScript Example 1

The code below creates a html form that accepts name, age and hobby of a person. There is a html button that produces JavaScript code when clicked. The JavaScript code prints out the name, age and hobby of the person when clicked. The JavaScript code is within the <script> tags. The code is shown below with the output; and then a few of the lines are explained later as well.

```html
<html>
<head>
<title>Print Name and Age......</title>
</head>
<body>
<form id="form1">
Enter Name: <input name="Enter Name" type="text" id="name" size="20"><br>
Enter Favorite Hobby: <input type="text" id="hobby" size="20"><br>
Enter Age: <input type="number" id="age" size="20"><br>
</form>
<button onclick="writename()">Print Intro</button>
<script>
function writename()
{
    var nameValue=document.getElementById("name").value;
    var hobbyValue=document.getElementById("hobby").value;
    var ageValue=document.getElementById("age").value;

    document.write("This is "+nameValue+"! I am "+ageValue+" years old. My favorite hobby is "+hobbyValue);
}
</script>
</body>
</html>
```

## JavaScript Example 2

The code below creates a html form that accepts two numbers and then creates 4 html buttons.

There are 4 Javascript function that add, subtract, multiply or divide the two numbers. A particular JavaScript code is selected based on which buttons are clicked.

The code is shown below with the output; and then a few of the lines are explained later as well.

```html
<html>
<head>
<title>Mini Calculator......</title>
</head>
<body>
<form id="form1">
Enter Number 1: <input type="number" id="num1" size="20"><br>
Enter Number 2: <input type="number" id="num2" size="20"><br>
</form>
<button onclick="sum()">+</button>
<button onclick="subtract()">-</button>
<button onclick="multiply()">*</button>
<button onclick="divide()">/</button>

function sum()
{
    var number1=parseFloat(document.getElementById('num1').value);
    var number2=parseFloat(document.getElementById('num2').value);
    var total=number1+number2;
    document.write("The sum is "+total);

{
    var number1=parseFloat(document.getElementById('num1').value);
    var number2=parseFloat(document.getElementById('num2').value);
    var diff=number1-number2;

{
    var number1=parseFloat(document.getElementById('num1').value);
    var number2=parseFloat(document.getElementById('num2').value);
    var multi=number1*number2;
    document.write("The product is "+multi);
}
function divide()
{
    var number1=parseFloat(document.getElementById('num1').value);
    var number2=parseFloat(document.getElementById('num2').value);
    var div=number1/number2;
    document.write("The quotient is "+div);
}
</script>
</body>
</html>
```

## Conditional Statement

### What is the conditional statement?

It is a statement that checks if a certain condition is true. It can be as simple as checking if a number is less than 10 to something as checking medical samples from patients for certain medical conditions.
In Javascript, the conditional statement is done using IF ELSE statements. So, it basically checks that if something is true, then perform an action. If it’s not true, then do something else. As an example,

```
IF (George=="Hungry")
{
    document.write("Give George a Snack");
}
ELSE
{
    document.write("No snack for George");
}
```

In the above example, the code checks if George is hungry and performs one of two actions. If George is hungry then it prints ‘Give George a snack’. If not, then print ‘No snack for George’.
This is a simple example of a conditional in JavaScript using IF ELSE statement.

### IF ELSE Loop – Example 1

```html
<html>
<head>

function check10()
{
var num1=parseFloat(document.getElementById("num1").value);
var num2=parseFloat(document.getElementById("num2").value);
    if ((num1+num2)<15)
    {
        document.write('Sum of two numbers is less than 15');
    }
    else
    {
        document.write('Sum of two numbers is greater than or equal to 15');
    }
}

</script>
</body>
</html>
```
