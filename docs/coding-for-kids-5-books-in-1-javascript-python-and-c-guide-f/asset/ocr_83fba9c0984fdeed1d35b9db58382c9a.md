In this example, we are going to take a 4 digit year as an input and check if it is a leap year. Now, this is a little more complicated than we think.
We know that every 4 years is a leap year. So that is our first check. So a year like 1996 would be a leap year.
But, every 100 years, there is no leap year. So, 1800 and 1900 are not leap years.
Also, there is another exception. Every 400 years, it is not a leap year. So 1600 and 2000 are not leap years. So there are 3 checks.
