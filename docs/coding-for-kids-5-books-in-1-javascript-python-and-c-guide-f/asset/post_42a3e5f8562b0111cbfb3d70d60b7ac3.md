## Game 3 – Math Quiz with Random Numbers

In this program below, there are 5 math questions generated by 10 random numbers. The 10 random numbers are variables **n1** through **n10**. The answers to the questions are calculated and are stored in variables **ans1** through **ans5**. These 15 variables are called global variables as they are outside any functions. These answers (**answer1-answer5**) are checked against user answers (**user_ans1- user_ans5**) using 5 different if conditionals in **check_ans** function. ## Lists, tuples and dictionaries

### Introduction to data structure

Data structures are structures used to store and group data so they can easily access and manipulate data efficiently. Each type of data structure has its advantages and disadvantages. A specific data structure is selected based on what you want to optimize. There are different aspects to optimize, for example, access speed or storage size or data modification speed. Each of these aspects will require different types of data structure optimized for this aspect.

In this chapter, we will explore three fundamental built-in Python data structures: Lists, tuples and dictionaries. These data structures are immensely useful. They make your program easier to write and more efficient and you don't have to implement your own data structures from scratch. Note that these data structures are also called containers since they hold/contain other objects.

### Lists

Lists are sequences that store collections of items. List is one of the containers most commonly used due to its versatility. Lists can hold different types of data. They are heterogeneous meaning they don't have to store similar data types. Lists are mutable so you can modify a list after its creation.

To create a list, put comma separated value in square brackets.

```
my_list = []  or
my_list = list()
```

The code below creates lists of numbers, strings and a heterogeneous list of both numbers and strings.

```python
# create list either by square brackets or list()
my_list = []
my_list = list()

# Define list L1, L2, L3
# list1 sequence of numbers
list1 = [1, 2, 3]

# list2 sequence of strings
list2 = ["Nick", "Tom", "Jane"]

# list3 sequence of numbers and strings
list3 = ["Nick", 10, "Python", 50]

# list4 a list containing other lists
list4 = [list1, list2, list3]

print("list1 is:", list1)
print("list2 is:", list2)
print("list3 is:", list3)
print("list4 is:", list4)

list1 is: [1, 2, 3]
list2 is: ['Nick', 'Tom', 'Jane']
list3 is: ['Nick', 10, 'Python', 50]
list4 is: [[1, 2, 3], ['Nick', 'Tom', 'Jane'], ['Nick', 10, 'Python', 50]]
```

### Basic list operations

This table summarizes basic list operations.

| Expression | Name | Output |
|---|---|---|
| `len(['a', 'b', 'c'])` | Length | `3` |
| `['a', 'b', 'c'] + ['d', 'e', 'f']` | List concatenation | `['a', 'b', 'c', 'd', 'e', 'f']` |
| `['Hi!'] * 4` | Repetition | `['Hi!', 'Hi!', 'Hi!', 'Hi!']` |
| `'a' in ['a', 'b', 'c']` | Membership | `True` |
| `for num in [1, 2, 3]:<br>    print(num)` | List iteration | `1<br>2<br>3` |
| `n = ['a', 'b', 'c']<br>n[0] = 'z'<br>print(n)` | List element assignment | `['z', 'b', 'c']` |

- **list[index]** – Indexing operator, selects a single value from a list. The number inside the brackets is called index, it is an integer value. Indexing in python starts at zero. Similar to strings you can also have negative index where it starts indexing backward.

```
list1 = ['Python', 'C++', 'C', 'Java Script']
list1[0] value is 'Python'
list1[2] value is 'C'
list1[-1] value is 'Java Script'
list1[-2] value is 'C'
```

- **list[starting_index: ending_index]** – slicing operator, slices the list at starting index and ends at one element before ending index.

```
list1 = ['Python', 'C++', 'C', 'Java Script']
list1[0:2] = ['Python', 'C++']
list1[0:-1] = ['Python', 'C++', 'C']
```

- **list.append(elem)** – *Append element to list.*

```
list1 = [1, 2, 3]
list1.append(4)
list1 value is [1, 2, 3, 4]
```

- **list.clear()** – Clears list values.

```
list1 = [1,2,3]
list1.clear()
list1 value is []
```

- **list.count(elem)** – Count how many times element elem is on list.

```
list1 = [1,2,2,2,3,4]
list1.count(2) outputs 3
```

- **list.extend(list2)** — Adds list2 elements to list. This method performs same job as lists concatenation using '+' operator.

```
list1 = [1, 2, 3]
list2 = [4, 5]
list1.extend(list2)
list1 is [1,2,3,4,5]
```

- **list.insert(elem_index, elem)** — Insert element elem into list at index elem_index.

```
list1 = [1, 2, 3]
list1.insert(3, 4)
list1 is [1,2,3,4]
```

- **list.pop()** — Removes list last element.

```
list1 = [1, 2, 3, 4]
list1.pop() removes 4
list1 is [1,2,3]
```

- **list.index(elem)** — Returns index of first occurrence of elem.

```
list1 = [1, 2, 3, 4]
list1.index(2) returns 3
```
