# return statement

In the previous script, we ran print function inside hello function, but what if we need to return just a value instead to the caller?
In this snippet, hello function returns a string. hello function is called first and the returned value is stored in the assigned variable.

```
```python
# function example
my_name = 'Jame'

# return hello to name
def hello(name):
    return "Hello !" + name

# function call
retruned_name = hello(my_name)
print(retruned_name)
```
```

Hello !Jame
