There is another way to link web pages; which is used when you create two separate web pages. Let’s say you want to add a link from Page A on Page B.

So, in Page B you would add the link using:

```
`<a href="PageB.html">`
```

We can also link any external web pages using the same html code:

```
`<a href=www.google.com>`
```
