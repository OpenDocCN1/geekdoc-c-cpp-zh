# Introduction to CSS

# What is CSS?

CSS stands for cascading style sheets. CSS is used to set up the design and style of your website – including the fonts, colors, layouts, shading and schemes. They work great in partnership with html and JavaScript.

# How to Use CSS in a html website

The best way to use CSS is to create a separate css file and refer to it in the html header file.

Now, let’s create a css file.

+   1. Open a blank Notepad++ document.
+   2. Click ‘Save As’ and choose file type as ‘CSS’. Let’s name this file as style
