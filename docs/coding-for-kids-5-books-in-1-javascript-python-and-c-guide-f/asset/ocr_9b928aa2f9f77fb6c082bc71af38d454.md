# Example : Moving Square by Mouse .

In this example we let the square follow the mouse by updating the square position with the mouse cursor position. We access mouse cursor position pygame.MOUSEMOTION, mouse x position is event.pos[0] and y position is event.pos[y]. We also change the color of square if mouse left button is clicked using pygame.MOUSEBUTTONUP.
