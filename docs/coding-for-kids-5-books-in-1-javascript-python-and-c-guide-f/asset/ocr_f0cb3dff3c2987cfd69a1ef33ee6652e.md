# ## Running the code

To run the code, we have to compile it first.

In Code::Blocks, we use the term *build* instead of compile. This is because a project usually consists of multiple C++ files and we call the process of compiling all of them building.

There are three buttons on top of the editor that enable us to build and run our project.
