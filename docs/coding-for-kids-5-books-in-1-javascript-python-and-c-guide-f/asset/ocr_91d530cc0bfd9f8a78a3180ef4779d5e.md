# Install Python on your computer

+   1. Go to [https://www.python.org/downloads/](https://www.python.org/downloads/) and click on the “Download Python 3.x.x”. In my case, the latest version is 3.8.4, and since I am on Windows, I will be downloading Python for windows. Make sure you download the latest version of Python for your Operating System.

![](bbox=[0.202, 0.495, 0.794, 0.684])

+   2. Launch the installer and wait for it to load. Check the “Install launcher for all users”. Make sure the “Add Python 3.8 to PATH” is also checked. After you have checked the boxes, click on “Install Now” and wait for the installation to be complete.
