# # char

char stands for character. char is a variable that can hold only one value. The value is a string of length 1. In below example, **excellent** is a char variable that holds the grade of a student in Mathematics.

```
```cpp
#include<iostream>
using namespace std;

int main(){
    char excellent = 'A';
    cout << "Congratulations you got an " << excellent << " in maths" << endl;
    return 0;
}
