Let's say you want to print to the screen the string ‘x is greater than 5’ if x is indeed greater than 5 else you print ‘x is less than or equal to 5’

```
```cpp
#include<iostream>
using namespace std;

int main(){
    int x = 3;

    if(x > 5){
        cout << "x is greater than 5" << endl;
    }else{
        cout << "x is less than or equal to 5" << endl;
    }
    return 0;
}

# Building Boolean Expressions

A **Boolean expression** is any expression that has one of two values. It is either true or false. It is basically an expression that compares two values and returns true/false.
