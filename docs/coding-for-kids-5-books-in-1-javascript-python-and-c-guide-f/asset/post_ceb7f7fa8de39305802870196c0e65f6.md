## Colors basics – RGB color model

Before starting to code games, we got to learn about colors. After all, we are not in the business of creating boring games in black and white shades! We should be able to create colorful interesting games full of life, full of colors.

There are millions and millions of colors but how can we determine color in a computer? The answer is the RGB color model.

RGB stands for Red, Green and Blue, using 3 corresponding numbers, one for each color. We can create any color we want. Each color has a number ranging from 0 to 255, where 0 is null intensity and 255 is the maximum intensity of color. Here are some typical color values.

| (R, G, B) | Color name |
| --- | --- |
| (255, 255, 255) | White |
| (255, 0, 0) | Red |
| (0, 255, 0) | Green |
| (0, 0, 255) | Blue |
| (0, 0, 0) | Black |

## Basic shape creation methods

Let’s start learning basic methods to create shapes.

`pygame.init()` – Initialize pygame and give permissions. This line is essential to start a pygame session.

`pygame.display.set_mode((X, Y))` – Creates a display window surface with dimensions (x,y) where x is width and y is height. This acts as our background.

`pygame.display.set_caption(‘name’)` – Sets display caption name.

`display_surface.fill(color)` – Fills display surface with a particular color. Color is an RGB tuple.

`pygame.draw.polygon(surface, color, points_list)` – Takes display_surface and draws a polygon with color color and points in points_list. points_list is a list of Cartesian sets such as [(3, 5), (5, 9)].

`pygame.draw.line(surface, color, start_point, end_point, thickness)` – Draws a line with color col, with starting point start_point and ending point end_point with optional thickness thickness.

`pygame.draw.circle(surface, color, center, radius, thickness)` - Draws a circle with color color, center center, radius radius and thickness thickness.

`pygame.draw.ellipse(surface, color, bounding_rectangle, thickness)` – Draws an ellipse bounded and centered by rectangle bounding_rectangle with optional thickness thickness. bounding_rectangle is given by (x, y, width, height) where x and y are upper left corner coordinates, width is rectangle width and height is rectangle height.

`pygame.draw.rect(surface, col, (x, y, width, height), thickness)` – Draws a rectangle with color col and coordinates in rectangle_tuple and thickness thickness. (x, y, width, height) is same as bounding_rectangle discussed above.

To read and learn more methods, use pygame documentation. Coders read much more than they write. They read others’ codes, documentations and manuals. This is a good practice in reading documentation.

https://www.pygame.org/docs/ref/draw.html

## Example 1 Implementing basic drawing methods

```python
# Import pygame module
import pygame

# activate a pygame library init
pygame.init()

# define the RGB value for colors
white = (255, 255, 255)
black = (0, 0, 0)
yellow = (255, 255, 0)
red = (255, 0, 0)
green = (0, 255, 0)
random_color = (120, 38, 58)


# assigning width 600, height 600 to background
dimensions = (600, 600)

# create the display surface object
# of specific dimension..(x, y).
display = pygame.display.set_mode(dimensions)

# pygame window name
pygame.display.set_caption('Basic shapes')

# Fill display surface with white
# with white colour
display.fill(white)

# draw a polygon using draw.polygon()
# pygame.draw.polygon(surface, color, points_list)
pygame.draw.polygon(display, yellow,
                    [(460, 300), (591, 400),
                     (530, 577), (350, 577), (300, 400)])

# draw horizontal line
# pygame.draw.line(surface, color, start_point, end_point, thickness)
pygame.draw.line(display, random_color,
                 (0, 300), (600, 300), 4)
# draw vertical line
pygame.draw.line(display, random_color,
                 (300, 0), (300, 600), 4)

# draw a circle
# pygame.draw.circle(surface, color, center_point, radius, thickness)
pygame.draw.circle(display, red, (150, 150), 50, 0)

# draw a ellipse pygame.draw.ellipse(surface, color, bounding_rectangle, thickness)
pygame.draw.ellipse(display, green, (400, 100, 100, 150), 0)

# draw a rectangle
# pygame.draw.rect(surface, col, (x,y,width,height), thickness)
pygame.draw.rect(display, black, (100, 400, 100, 100))


# infinite loop to keep session on
while True:

    # iterate over the list of Event objects
    # that was returned by pygame.event.get() method.
    for event in pygame.event.get():

        # if event object type is QUIT when corner exit button is clicked
        # then quitting pygame and program
        if event.type == pygame.QUIT:

            # kill pygame session
            pygame.quit()
            # quit the program.
            quit()

    # Draws the objects screen.
    pygame.display.update()
```

In this example we implement the basic pygame drawing methods we discussed in this chapter. We create a circle, ellipse, polygon, square and lines. Each shape is created with its own color, position and size. Try to read and understand this program. It is well commented to facilitate easy reading.

### Infinite loop (game loop)

Why do we have an infinite loop at line 57? Pygame library is used to create video games. Video is nothing but a continuous stream of pictures viewed in a short amount of time so human eyes can’t detect the difference. The loop will keep updating the screen with any newly drawn shapes on it and keeps the session on. Without this infinite loop, Pygame will display the shapes momentarily and cease running. This infinite loop is called the game loop since it is the loop that contains the main logic of a game and is also responsible for updating the screen with any new status.

## Example 2 Frowny face

In this script we create an angry frowny face. This program is very similar to the last example. Except that we draw different shapes. Frowny face basically consists of 1 circle for face, 2 circles for eyes and an arc for mouth. To understand the arc method, read **pygame** documentation. Try to understand how arc gets oriented, you will need it in the practice problems.

```python
# import pygame module
import pygame
import math

# activate a pygame library init.
pygame.init()

# define the RGB values for some colors
white = (255, 255, 255)
yellow = (255, 255, 0)
red = (255, 0, 0)

# assigning width 300, height 300 to background
dimensions = (300, 300)

# create the display surface object
display = pygame.display.set_mode(dimensions)

# naming window name
pygame.display.set_caption("Frowny face!")

# Display color is white
display.fill(white)

# Draw face
pygame.draw.circle(display, yellow, (150, 150), 50, 0)

# Draw left eye
pygame.draw.circle(display, red, (130, 140), 10, 0)

# Draw right eye
pygame.draw.circle(display, red, (170, 140), 10, 0)
```
