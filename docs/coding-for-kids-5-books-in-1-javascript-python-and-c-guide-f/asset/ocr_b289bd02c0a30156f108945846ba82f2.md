# Truth Tables

The following are known as truth tables. It indicates all the possibilities that a combination of each expression can be and the resulting boolean value.

# AND

| expression1 | expression2 | expression1 && expression2 |
|---|---|---|
| true | True | True |
| true | False | False |
| false | True | False |
| false | False | False |

# OR

| expression1 | expression2 | expression1 \|\| expression2 |
|---|---|---|
| true | True | True |
| true | False | True |
| false | True | True |
| false | False | False |
