# # Introduction to CSS

# ## What is CSS?

CSS is an acronym for Cascading Style Sheets. It allows the user to set and modify the style of your html website. ‘Style’ is a term used for font type, font color, background color, shading etc. CSS elements can be accessed through html and JavaScript.
