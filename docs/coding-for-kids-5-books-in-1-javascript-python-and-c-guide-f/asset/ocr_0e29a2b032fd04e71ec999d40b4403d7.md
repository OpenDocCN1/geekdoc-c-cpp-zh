# Example of Boolean expressions

Let’s say that you only buy food when you are hungry, and you have money. To represent this in code it will be something like this.

# Example

```
```cpp
#include<iostream>
using namespace std;

int main(){
    bool isHungry = true;
    bool hasMoney = true;

    if( isHungry && hasMoney){
        cout << "I will buy food" << endl;
    }else{
        cout << "I can't buy food" << endl;
    }

    return 0;
}
```
