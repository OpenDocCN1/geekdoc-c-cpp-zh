# Nested Conditional Statements

These are basically conditional statements within conditional statements.
These are also called nested loops.
Let’s say that you want to check if two conditions are true in Javascript,
before you take an action; then you put two if loops within each other.
Let’s take the example from the previous chapter. We want to check if
George is hungry and has money to give him a snack.
not true, then do something else. As an example,

```
```javascript
IF (George==”Hungry”)
{
    IF (George==”Has Money”)
    {
        Document.write(“Buy George a Snack);
    }
    ELSE
    {
        Document.write(‘Make George a Snack’);
    }
}
ELSE
{
    Document.write(‘No snack for George’);
}
```
```

In the above example, the code checks if George is hungry first. If George
is hungry then it performs a 2nd check. It checks if George has money. If
George has money, it prints ‘Buy George a snack’. If he’s hungry but
doesn’t have money, then print ‘Make George a snack’).
If he’s not hungry, then print ‘No snack for George’).
This is a simple example of a nested IF ELSE statement in JavaScript.
