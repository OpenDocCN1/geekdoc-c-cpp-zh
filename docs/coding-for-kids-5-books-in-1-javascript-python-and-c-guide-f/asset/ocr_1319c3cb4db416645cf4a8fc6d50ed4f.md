The program above has an extra textbox and extra button. The textbox is for accepting the length of the `starloop` and the button links to a function called `looplengthstar()` that prints the star loop. `Looplengthstar()` is a nested FOR loop, which means that it has 1 loop within the other. The variable `looplength` stores the value of the star loop length that you entered. The first FOR loop goes from 1 to `looplength`. So, in the example above, the first loop is from 1 to 20. So, within that, there is another FOR loop. The second loop basically prints `*` in one line. The number of times it prints `*` depends on the counter in the first loop. For example, if the first loop counter is 5 (i==5); then the second loop prints star 5 times. Something like this `_*****`. So, the second loop does this each time the first loop is increased and moves to the next line.
