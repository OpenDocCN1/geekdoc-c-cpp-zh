# Add a record in array

We have declared two arrays for student names and student registration numbers. The two arrays are called *registrationNum* and *nam*.

If the user enters the number ‘1’ then program will ask user to enter student name and registration number. The user then enters the name and registration number. It is stored in their respective array. There is count variable called *index* which counts the number of students which are created. The index is increased by 1 each time a student is added. The process of adding the record is shown in the part of the code below.
