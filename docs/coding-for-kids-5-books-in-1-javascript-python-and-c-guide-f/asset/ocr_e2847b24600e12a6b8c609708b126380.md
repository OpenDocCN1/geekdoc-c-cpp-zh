# Example Using Counter Inside Loop

We can use our declared integer inside the associated block of code, for example, we could print the value 1 to 10 with the code below.

```
```cpp
#include<iostream>
using namespace std;

int main(){

    for(int i = 1 ; i <= 10; i++){
        cout << i << endl;
    }

    return 0;
}
