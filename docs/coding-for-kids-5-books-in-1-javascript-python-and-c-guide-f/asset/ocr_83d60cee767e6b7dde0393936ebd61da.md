math.random() returns a random number between 0 and 1. If we want to get a random between 0 and 10, we multiply by 10 and round the answer (using math.round()). Let's look at a few examples.

In the above example, n1 is a random number between 0 and 1. n2 and n3 are two different random numbers between 0 and 50. You should probably see that n2 and n3 are different because both numbers are randomized. n4 returns a random number between 0 and 1000. We can see the results in the output below.
