A function can take in variables as input known as parameters, do something with the variable such as increasing it by 20, multiplying it with 4 etc. and return the result. The ‘return’ keyword is used to return a result. In the above case, the name of the function is ‘my_function’. A function doesn’t necessarily take parameters and return an output all the time, e.g.:

```
def new_function():
........ piece of code ........
```

The above is also a valid definition of a function. Python comes with a broad set of pre-defined or built-in functions which are available for us to use, eg: print(), min(), max() etc.

When we want to use a function, we simply invoke it like this:

```
my_function(input variables)
```
