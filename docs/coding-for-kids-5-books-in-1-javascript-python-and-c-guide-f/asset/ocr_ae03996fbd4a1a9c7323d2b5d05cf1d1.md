The code below lets you input your name through a textbox. When you click the button, it runs the function `namereverse()` that reverses your name. Name2 stores the value you entered for your name len stores the number of letters in your name. Then we create a loop than runs from len-1 to 0. The reason we use 0 is because name2 is an array of letters. The first index of the array is 0 in JavaScript. So the first character is name2[0].
