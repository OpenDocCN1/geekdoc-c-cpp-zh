# Division

Division is done using the / operator, this returns the quotient of the division

# Division Example code

```
```cpp
#include<iostream>
using namespace std;

int main(){

    int x = 3;
    int y = 2;
    int quotient = x / y;
    cout << quotient;
    return 0;
}
```
```

The output of above code will be 1.5
