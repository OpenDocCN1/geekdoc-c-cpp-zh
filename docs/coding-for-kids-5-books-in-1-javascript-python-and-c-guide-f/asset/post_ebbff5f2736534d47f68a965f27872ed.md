## Nested Conditional Statements

These are basically conditional statements within conditional statements. These are also called nested loops. Let’s say that you want to check if two conditions are true in Javascript, before you take an action; then you put two if loops within each other. Let’s take the example from the previous chapter. We want to check if George is hungry and has money to give him a snack. If not true, then do something else. As an example,

```javascript
IF (George=="Hungry")
{
    IF (George=="Has Money")
    {
        Document.write("Buy George a Snack");
    }
    ELSE
    {
        Document.write('Make George a Snack');
    }
}
ELSE
{
    Document.write('No snack for George');
}
```

In the above example, the code checks if George is hungry first. If George is hungry then it performs a 2nd check. It checks if George has money. If George has money, it prints ‘Buy George a snack’. If he’s hungry but doesn’t have money, then print ‘Make George a snack’. If he’s not hungry, then print ‘No snack for George’.

This is a simple example of a nested IF ELSE statement in JavaScript.

### Nested IF ELSE Loop Example

In this example, we are going to take a 4 digit year as an input and check if it is a leap year. Now, this is a little more complicated than we think. We know that every 4 years is a leap year. So that is our first check. So a year like 1996 would be a leap year. But, every 100 years, there is no leap year. So, 1800 and 1900 are not leap years. Also, there is another exception. Every 400 years, it is not a leap year. So 1600 and 2000 are not leap years. So there are 3 checks.

```html
<html>
<head><title>Leap Year Check</title></head>
<body>
<form id="form1">
Enter Year: <input type="number" id="year" size="20"><br>

</form>
<button onclick="leapyear()">Leap Year?</button>

<script>

function leapyear()
{
var yr=parseInt(document.getElementById("year").value);
var leapyear=0;
    if ((yr%4)==0)//First loop that checks if the year is divisible by 4
    {
        lpyear=1;
        if((yr%100)==0)//Second loop that checks if the year is divisible by 4
        {
            lpyear=0;
            if(yr%400==0)//Third loop that checks if the year is divisible by 4
            {
                lpyear=1;
            }
        }
    }
if (lpyear==1)
{
    document.write(yr+" is a leap year");
}
else
{
    document.write(yr+" is not a leap year");
}
}
</script>
</html>
```

Leap Year?

Leap Year?

Leap Year?

### Output

### Run #4

Leap Year?

### Output

As you can see from the above code and results, it properly calculates the leap year through the use of 3 nested if loops.
1992 is a leap year since it is divisible by 4.
1995 is not a leap year since it is not divisible by 4.
1900 is not a leap year since it is divisible by 100.
2000 is a leap year since it is divisible by 400.

## Loops

A loop is a set of instructions that is repeated a certain amount of times. In most cases, a certain process is done and there is a count of the process that increases by 1. At the end of the process, we check if the count is over the number of times we need the process done. If it has reached the number of times we need, then we stop the loop.

For example, let’s say you want to print the numbers 1 to 10 on the screen. Then use a loop which counts from 1 to 10. It prints the count on the screen each time.

In JavaScript, we use a function called **FOR** to implement this loop. We’ll go through a simple example below.
