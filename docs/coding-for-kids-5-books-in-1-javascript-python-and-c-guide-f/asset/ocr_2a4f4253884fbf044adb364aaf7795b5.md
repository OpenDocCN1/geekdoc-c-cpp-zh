# Modulus operation

The modulus operation returns the remainder between two numbers. It looks like the percentage sign %. Here’s an example below:

```
```python
n1 = float(input('num1: '))
n2 = float(input('num2: '))

remainder = n1 % n2
print()
print(f"Remainder is {remainder}")
```
```

The above code takes in two numbers via an input and finds the remainder between the two; as shown in output below.

# Output:

```
```
num1: 9
num2: 2

Remainder is 1.0
```
```

The remainder when 9 is divided be 2 is indeed 1.
