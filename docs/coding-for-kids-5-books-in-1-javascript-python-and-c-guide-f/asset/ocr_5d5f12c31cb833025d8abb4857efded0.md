# Basic dictionary methods

To access a dictionary value, use its key.

```
num_dict = {'one':1, 'two':2, 'three':3}
num_dict['one'] is 1
```

Membership is similar to tuple and lists except that it checks for key.

```
num_dict = {'one':1, 'two':2, 'three':3}
‘one’ in num_dict returns True
```

To add new key value pair use assignment operator.

```
num_dict = {'one':1, 'two':2, 'three':3}
num_dict['four'] = 4
num_dict now is {'one':1, 'two':2, 'three':3, 'four':4}
```

dict.clear – clears the dictionary.

```
num_dict = {'one':1, 'two':2, 'three':3}
num_dict.clear()
num_dict now is {}
```

dict.get(key) – retrieve a dictionary value by a key and returns None if no such key exists.

```
num_dict = {'one':1, 'two':2, 'three':3}
num_dict.get(‘one’) returns 1
```
