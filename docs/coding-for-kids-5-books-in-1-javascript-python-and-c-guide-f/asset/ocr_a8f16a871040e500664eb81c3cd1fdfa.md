In this example when func is called it only execute line 4 because it terminates when it reaches return statement at line 5. Also, note that it returns None

```python
# None return

def func():
    print("Before return nothing")
    return
    print("After return nothing")

m = func()
print()
print("func returned ", m)

# Output:
# before return nothing
#
# func returned  None
