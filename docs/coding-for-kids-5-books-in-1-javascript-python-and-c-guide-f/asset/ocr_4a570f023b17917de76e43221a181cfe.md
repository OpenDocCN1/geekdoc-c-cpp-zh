# Example 4 – Random Jokes

This program prints a random joke out a random joke picked from a list of jokes. The one button runs the **writejoke()** function. In the function, we declare an array that contains all the jokes. You can get the values for all below:

[https://drive.google.com/file/d/1xDN9dt2Gvj-mdPmi5ATCnP1tv0ZtZ5/view?usp=sharing](https://drive.google.com/file/d/1xDN9dt2Gvj-mdPmi5ATCnP1tv0ZtZ5/view?usp=sharing)

We then chose a random number between 0 and x, x is the length of the array. This random number picks a random country. We do this using **Math.random()** and **Math.floor()**.

We then print out the joke using the **document.write()** function.

Then, the user has the chance to restart the program with the **Home** button that runs the **redirect()** function.
