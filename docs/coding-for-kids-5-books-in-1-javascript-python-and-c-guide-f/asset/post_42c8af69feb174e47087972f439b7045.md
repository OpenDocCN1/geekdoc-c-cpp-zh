## The Bulb Example - HTML

### What This Project Does

This is a simple html project that creates a button that can switch a light bulb on the page on/off. We are going to use two bulb images to make this happen. The button will switch between the two images.

### Concepts to Understand for this Chapter

We’ll need to understand button tags and image tags for this example.

### Button Tag

```html
<button onclick=Action >Button text</button>
```

The button element has two elements. An Action and Button Text. The Button Text is the text that shows on the button; and the Action is what happens when the user clicks on the button.

### Image Tag

```html
<img id=ImageId src=ImageUrl style=ImageSize>
```

The Image Tag has three elements.

The ImageId is the name you assign to the image. This name is used to reference the image in the code.

ImageUrl is the URL of the image that the tag is referencing. If the image is in the same folder as the html file, then you can use the file name only instead of the entire URL.

ImageSize sets the width and height of the Image.

## HTML Forms

### What are HTML forms?

HTML forms are empty boxes on the web page that you can enter information in. It’s those forms that you see online where you enter your name, age, password etc.

Here’s what a form looks like:

![](img/443990a0ec620659ce8be783c0758bc6_139_0.png)

### Form HTML Tag format

Below is an example of a form html tag that takes in name, occupation and gender.

```html
<form id="form1">
Name: <input name="Enter Name" type="text" id="name" size="20"><br>
Occupation: <input type="text" id="occupation" size="20"><br>
Age: <input type="number" id="gender" size="20"><br>
</form>
```

Once you run the program, the output looks like below. You can type anything in the empty boxes in the output. The empty boxes are also called textboxes.

![](img/443990a0ec620659ce8be783c0758bc6_140_0.png)

### Different parts of form HTML tag

`<form id="form1">`

The form id tag is the name of the form that will be used as a reference in the rest of the code.

- `Name:`
- `Occupation:`
- `Age:`

This is the text that’s written at the left of the box. It is used to describe to the user what to put in the box.

`input type="text"`

This means that what you type in the box is a type of text or string. For example, name and occupation uses text because you type letters in the box.

`input type="number"`

This means that what you type in the box is a number. For example, age and phone would use number because they are entirely numbers.

```
id="name"
id="occupation"
id="gender"
```

The id is what the box is called in the rest of the program. We will use the id in the rest of the program to reference the box.

```
size="20"
```

This means that the length of the box is 20 pixels. To change this, change the value of size. For example, if you want to double the length of the box, change the size to 40.

## JavaScript Example

### What is JavaScript?

JavaScript is a high-level programming language. It is most commonly used to perform user actions on a html page. It also helps to enhance interactions of users on a web page.

### How to Use JavaScript in HTML

There are two ways to use JavaScript on a html page:

The first way is to just include JavaScript code within <script> tags. It would be like below:

```html
<html>
<head>
<title> </title>
</head>
<body>
<script>
</script>
</body>
</html>
```

The JavaScript code would be within the two script tags shown in red above.

The second way is to create a JavaScript file and save it as a .js file. Then you would reference the JavaScript file in the html code. This is shown below.

```html
<html>
<head>
<title> </title>
</head>
<body>
<script src="newfile.js"></script>
</body>
</html>
```

You would include all the JavaScript code in the **newfile.js** file.

## JavaScript Terms You Need to Know

We are going through a couple of JavaScript html code examples next. We need to know the following terms to understand the code.

### function

A JavaScript function is any set of lines of code that performs a task. A function is normally made to execute tasks that need to happen when you click on a html button. Every function has a name and is referenced in the html code. An example is below:

```
function abcd()
```

abcd is the name of the function that performs a specific task. It will be referenced in html code as abcd.

### Variable

A variable is used to store names or numbers in JavaScript. Think of it as a box that can store one value. That box is referenced each time you need that value. It is defined as below:

```
var flag=1;
```

`flag` is the name of the variable and it stores the value of 1. So anytime `flag` is referenced in the JavaScript program; it has a value of 1 (unless you change the value of flag). This value of flag can be used to define other variables. For example:

```
var king=flag*2;
```

king now has a value of 1*2=2. So variables are a good way of dealing with unknown quantities.

### document.getElementById().value

This JavaScript term is used to get the value of an item in a html form textbox. So, if you fill out a form textbox with your name and click on a button, the document.getElementById() gets the value of what you typed in the box. As an example:

```
var yname=document.getElementById("name").value;
```

“name” is the id of the form textbox that is defined in html. To see how this is done in html, check out the section on html tags in the previous chapter. Whatever is typed in the textbox is stored in a variable called `yname`. It will be referenced in JavaScript from now on as yname.

### Document.write()

This function is used to print anything on the web browser.
For example,

```
document.write("xyz");
```

Prints **xyz** on the screen

You can also add two different terms by using the “+” button.

```
document.write("xyz"+"123");
```

Prints **xyz123** on the screen.
This is useful when you want to add text to a variable. For example.

```
var yname=document.getElementById("name").value;
document.write("My name is "+yname);
```

If you typed in “Matt” in the textbox, it prints out **“My name is Matt”** on the screen.
