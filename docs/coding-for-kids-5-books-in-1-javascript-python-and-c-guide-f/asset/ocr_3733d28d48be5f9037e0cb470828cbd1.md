# Example 1

Below is a function that takes an input from the user and prints it. This keeps on being repeated till the user inputs the word ‘exit’.

```
```python
def func():
    status = True
    while status:
        word = input("Enter the word? ")
        if word == 'exit':
            status = False

func()
```
```

We define a function func to take input from the user and print it to the console repeatedly. We stop once the user inputs ‘exit’. First we declare a boolean variable ‘status’ and set it to True. The while loop keeps on running as long as the boolean variable has a value True
