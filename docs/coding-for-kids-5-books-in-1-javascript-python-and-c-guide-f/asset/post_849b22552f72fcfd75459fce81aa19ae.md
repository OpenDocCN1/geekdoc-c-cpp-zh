
## Example #1

```html
<html>
<head><title>Print 1 to 20</title></head>
<body>

<button onclick="printtotwenty()">Print To 20</button>

<script>

function printtotwenty()
{

for (i=1;i<=20;i++)
{
    document.write(i+"<br>");
}

}

</script>

</body>
</html>
```

In this function we create a function `printtotwenty` that prints the numbers from 1 to 20. The button titled ‘Print To 20’ activates the function.
In the function there is a for loop:

`for (i=1; i<=20; i++)`

The line above means that the loop runs from 1 to 20; and it increases by a value of 1 each time.
The `document.write` prints the value of `i` each time.

## Example #3

Now, we’re going to do something even cooler with loops. We’re going to print a star pattern based on the loop length.

```html
<html>
<head><title>JavaScript Greetings......</title></head>
<body>
<form id="form1">
Loop Length: <input type="number" id="loop" size="20"><br>
Star Loop Length: <input type="number" id="starloop" size="20"><br>
</form>

<button onclick="printtwenty()">Print To 100</button>
<button onclick="printlooplength()">Print Loop Length</button>
<button onclick="looplengthstar()">Print Star Loop</button>

<script>

function printtwenty()
{
for (i=1;i<=20;i++)
{
document.write(i+"<br>");
}
}

function printlooplength()
{
var looplength=parseInt(document.getElementById("loop").value);

var j=1;
for (i=1;i<=looplength;i++)
{
document.write(i+"<br>");
}
}
function looplengthstar()
{
var looplength=parseInt(document.getElementById("starloop").value);

for (i=1;i<=looplength;i++) {
    for (j=1;j<=i;j++)
    {
        document.write("*");
    }
    document.write("<br>");
}
}

</script>

</body>
</html>
```

The output below:

![](img/443990a0ec620659ce8be783c0758bc6_183_0.png)

After entering 20, and clicking ‘Print Star Loop’ we get:

```
*
**
***
****
*****
******
*******
********
*********
**********
***********
************
*************
**************
***************
****************
*****************
******************
*******************
********************
```

The program above has an extra textbox and extra button. The textbox is for accepting the length of the `starloop` and the button links to a function called `looplengthstar()` that prints the star loop. `Looplengthstar()` is a nested FOR loop, which means that it has 1 loop within the other. The variable `looplength` stores the value of the star loop length that you entered. The first FOR loop goes from 1 to `looplength`. So, in the example above, the first loop is from 1 to 20. So, within that, there is another FOR loop. The second loop basically prints `*` in one line. The number of times it prints `*` depends on the counter in the first loop. For example, if the first loop counter is 5 (i==5); then the second loop prints star 5 times. Something like this `*****`. So, the second loop does this each time the first loop is increased and moves to the next line.

## Arrays

### What is An Array?

An array is basically a group of items that are stored in a single name. They are accessed using different indexes of the name. For example, in JavaScript:

`var name[5]` is an array of size 5. The first element is `name[0]`, the second element is `name[1]` and so on.

So, if we want to assign values to the array:

```javascript
var name[5]=["Abhi", "Bob", "Aaron", "Steve", "Mark"]
```

The above creates an array of size 5. To print the first element in JavaScript, we do:

```javascript
document.write(name[0]);
```

This prints out Abhi, which is the first element of the array.

If we do:

```javascript
document.write(name[4]);
```

This prints out Mark, which is the last element of the array.

If we want to add an element to the array use the push function as below:

```javascript
name.push("Carl");
```

```javascript
document.write(name[5]);
```

This prints out Carl, which is the new element of the array.

Now, let’s go through a couple of examples:

### Example 1

In this example, we create 3 arrays and assign them values in JavaScript, and then print them on the screen.

```html
<html>
<head><title>Arrays 1</title></head>
<body>

<button onclick="createarray()">Create Array</button>

<script>

function createarray()
{
var name = ["Bob","Peter","Nick"];
var age=[32,10,11];
var loc=new Array("New York","Rockford","Kansas");// 2nd way to start array
document.write(name[0]+' lives in '+loc[0]+' and age is '+age[0]+'<br>');
document.write(name[1]+' lives in '+loc[1]+' and age is '+age[1]+'<br>');
document.write(name[2]+' lives in '+loc[2]+' and age is '+age[2]+'<br>');
name.push("Steve");
age.push(20);
loc.push("Miami");
document.write(name[3]+' lives in '+loc[3]+' and age is '+age[3]+'<br>');
}

</script>

</body>
</html>
```

The above example, `createarray()` creates 3 arrays `name`, `age` and `loc`. Each array has three elements assigned. They are printed on the screen using `document.write()`.

After that we add a 4<sup>th</sup> element using `push` for all 3 arrays and then that is printed out as well.
