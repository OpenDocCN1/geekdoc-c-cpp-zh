# Concepts to Understand for this Chapter

We’ll need to understand button tags and image tags for this example.

# Button Tag

```
<button onclick=Action >Button text</button>
```

The button element has two elements. An Action and Button Text. The Button Text is the text that shows on the button; and the Action is what happens when the user clicks on the button

# Image Tag

```
<img id=ImageId src=ImageUrl style=ImageSize>
```

The Image Tag has three elements.
The ImageId is the name you assign to the image. This name is used to reference the image in the code.
Imageurl is the url of the image that the tag is referencing. If the image is in the same folder as the html file, then you can use the file name only instead of the entire url.
ImageSize sets the width and height of the Image.
