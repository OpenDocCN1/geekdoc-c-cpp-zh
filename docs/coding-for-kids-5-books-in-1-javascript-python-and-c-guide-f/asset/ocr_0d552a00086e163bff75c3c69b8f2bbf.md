# Example 3: is divisible:

In this example, is_divisible function checks if a is divisible by b, if so, it prints a message and set div to true. If a is not divisible by b, else statement will handle this case where it prints message and set div to false.

```
```python
# is_divisible
# checks if a is divisible by b, print a message
# return true if else false

def is_divisible(a, b):
    div = None
    if a % b == 0:
        print(f"{a} is divisible by {b}")
        div = True
    else:
        print(f"{a} is not divisible by {b}")
        div = False

    return div

n1 = is_divisible(8, 2)
n2 = is_divisible(8, 3)

print(n1)
print(n2)
```
