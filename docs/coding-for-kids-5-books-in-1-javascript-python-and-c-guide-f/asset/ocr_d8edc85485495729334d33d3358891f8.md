# Practice Problems

+   1. Write a program that creates an object for a restaurant menu. The properties are the dish name, time to cook and price of dish. And then access the object values to print out all the dishes that cost below $20 and cook below 20 minutes.
+   
+   2. Write a program that simulates shooting practice for a basketball game. The name of the player is the property and the points scored is the value assigned to the property. The program checks the name of the player and whether the shot is outside the 3-point circle. Based on the answer, it adds 2 or 3 points to the relevant player.
