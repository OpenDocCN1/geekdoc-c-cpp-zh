# float

Represent numbers with decimals places. See example below. pi is a float variable with a value of 3.142 and areaofcircle is another float variable.

```
```cpp
#include<iostream>
using namespace std;

int main(){
    float pi = 3.142;
    int radius = 3;
    float areaOfCircle = pi * radius * radius;
    cout << areaOfCircle;
    return 0;
}
