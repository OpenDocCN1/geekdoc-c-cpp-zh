The function **searchRecord()** takes in an array of names (**name[]**) and an array of registration numbers (**regnum[]**) as arguments. It also takes in two variables for registration number **reg** and index **in**.
**reg** is the registration number we are using to search for the student record, while **in** is the number of records.
The function search the array **regnum[]** using a for loop for the registration number **reg**.
If **reg** is found, the function prints out the student registration number and name.
If **reg** is not found, the function prints out “Record is not found”

```
```cpp
// search record function to search the record of the student if it is exist and then print record
void searchRecord(string name[], string regnum[], int reg, int in) {
    // is found variable to check whether a record is exist or not in the array if exist set it true
    bool isfound = false;

    // loop till array to check whether a record exist or not
    for(int index = 0; index < in; index = index + 1) {
        // check every record in array if match then
        if (regnum[index] == reg) {
            // record is found
            isfound = true;

            // printing the record
            cout << "Student Registration Number : " << regnum[index] << "\t\t" << "Student Name : " << name[index] << endl;
            cout << endl;

            // terminating from loop
            break;
        }
    }

    // if a particular record is not exist then
    if (isfound == false) {
        // display that record is not exist
        cout << "Record is not found : " << endl;
        cout << endl;
    }
}
