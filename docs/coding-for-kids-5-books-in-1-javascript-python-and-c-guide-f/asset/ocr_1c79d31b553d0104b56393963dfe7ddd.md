# Growing square

We make a square that grows in size until it fills the entire lower right screen quadrant. The logic is very similar to how we made various shapes in the previous example except for 2 main differences. We make pygame clock instance `clock=pygame.time.Clock()`, this is a pygame method to keep track of time. We use it in the program to control how many frames per seconds (fps) we want using `clock.tick(fps)`. Faster fps updates the shape more frequently which makes the square grows faster.
