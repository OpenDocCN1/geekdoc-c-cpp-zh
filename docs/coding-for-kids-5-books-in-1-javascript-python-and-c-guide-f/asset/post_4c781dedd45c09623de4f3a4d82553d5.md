```html
function namereverse()
{
var name2=document.getElementById("name").value;
len=name2.length;
for (i=len-1;i>=0;i--)
{
document.write(name2[i]);
}
}

</script>

</body>
</html>
```

The code below lets you input your name through a textbox. When you click the button, it runs the function `namereverse()` that reverses your name. Name2 stores the value you entered for your name. len stores the number of letters in your name. Then we create a loop that runs from len-1 to 0. The reason we use 0 is because name2 is an array of letters. The first index of the array is 0 in JavaScript. So the first character is name2[0]. In the loop, we go backwards and decrease the count by 1 each time. And, within the loop, we print the value of the character that is indexed by the count. Now, let’s run the program:

### Splitting Strings

Now, did you know that you can split a string into an array of elements. You can achieve this using the split function. Now, let’s try an example. In the code below, you take a list of 3 animals as input into a textbox which are separated by commas.

The split function separates this into an array of 3 elements and you can print out each element using document.write function.

```html
<html>
<head><title>Splitting Strings</title></head>
<body>
<form id="form1">
Enter List of 3 Animals separated by commas:<input name="name" type="text" id="ani" size="20"><br>

</form>
<button onclick="strsplit()">Get Animals</button>

<script>

function strsplit()
{
var animal=document.getElementById("ani").value;
anarray=animal.split(","); // Split on commas
document.write("The first animal is "+anarray[0]+"<br>");
document.write("The second animal is "+anarray[1]+"<br>");
document.write("The third animal is "+anarray[2]+"<br>");
}

</script>
</body>
</html>
```

Now, let’s check out the output:

Enter List of 3 Animals separated by commas: `tiger, lion, wolf`

Get Animals

After clicking the button **Get Animals** we have:

The first animal is tiger  
The second animal is lion  
The third animal is wolf

The above code works if you have 3 animals as input. You might ask if there’s a code that can work for more than 3 animals. Yes, it can. You need to find the length of the string array using length function and then use a FOR loop when printing the animals. In the **for loop**, we use **aninumber** to keep track of the animal count; and **aniarray[i]** to keep track of the actual animals to print.

Note that **aninumber** is always 1 more than i, because i starts from 0 in a JavaScript array.

Here’s the code below:

```html
<html>
<head><title>Splitting Strings</title></head>
<body>
<form id="form1">
Enter list of 3 Animals separated by commas:<input name="name" type="text" id="ani" size="20"><br>
</form>

<button onclick="strsplit()">Get Animals</button>

<script>

function strsplit()
{
var animal=document.getElementById("ani").value;
aniarray=animal.split(",");       // Split on commas
var len=aniarray.length;
var aninumber;
for (i=0; i<=len-1;i++)
{
aninumber=i+1;
document.write("Animal "+aninumber+" is "+aniarray[i]+"<br>");
}
}

</script>
</body>
</html>
```
