# # Exercises to Practice:

You can copy the above examples and once you are able to run them and understand the code; you can try a few of the problems below.

+   1. The Fibonacci series is a set of numbers like this 0,1,1,2,3,5,8,13.... Every number is the sum of the previous two numbers. Using a FOR loop, print the first 20 numbers of the sequence.
+   2. Write a program that takes in a number in a textbox and prints a reverse star loop.
+   3. Write a program that takes in a number in a textbox and prints the sum of its digits.
