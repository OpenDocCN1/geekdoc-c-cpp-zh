A C++ variable name must start with either a letter or an underscore and all the rest of the characters must be letters, digits or an underscore.

Examples of valid variable names are:

+   x
+   x1
+   x_1_abc
+   RATE
+   bigBonus_

Examples of invalid variable names:

+   12
+   3x
+   %change data
+   -1 PROG.CPP

The first three, 12 3x %change, are not allowed because they do not start with a letter or an underscore.

C++ is also case sensitive, meaning that the following are three distinct variable names:

+   Rate
+   RATE
+   Rate

# Camel Case

Camel case is a programming practice where multiple words are written without spaces and the first letter of each word is capitalized (except for the first word)
