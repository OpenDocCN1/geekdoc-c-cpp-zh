The program above has an extra textbox and extra button. The textbox is for accepting the length of the `loop` and the button links to a function called `printlooplength()` that prints the star loop. The variable `looplength` stores the value that you put in the textbox. The FOR loop runs from 1 to `looplength`. In the above example, `looplength` is 50; so it runs from 1 to 50.
