```
```html
<html>
<head><title>Print 1 to 20</title></head>
<body>

<button onclick="printtotwenty()">Print To 20</button>

<script>

function printtotwenty()
{

for (i=1;i<=20;i++)
{
    document.write(i+"<br>");
}

}

</script>

</body>
</html>
```
```

In this function we create a function printtowenty that prints the numbers from 1 to 20. The button titled ‘Print To 20’ activates the function.
In the function there is a for loop:
For (i=1;i<=20; i++)
The line above means that the loop runs from 1 to 20; and it increases by a value of 1 each time.
The Document.write prints the value of i each time.
