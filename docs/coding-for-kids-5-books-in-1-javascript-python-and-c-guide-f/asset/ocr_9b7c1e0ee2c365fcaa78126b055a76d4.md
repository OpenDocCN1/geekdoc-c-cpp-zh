The replace function is used to replace a string with another string as can be seen in the example below

```
```python
>>> "Hello World".replace("o" , "2")
'Hello W2rld'
>>> "Hello World".replace("Hello" , "*")
'* World'
>>> |
```
```

In the first instance we replace all occurrence of letter O with “2” and in the second instance we replace “Hello” with “*”
