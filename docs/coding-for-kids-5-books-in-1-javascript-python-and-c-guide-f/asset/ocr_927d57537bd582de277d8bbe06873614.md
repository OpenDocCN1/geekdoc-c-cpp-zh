# Arithmetic Functions

Arithmetic functions are used to perform mathematical operations. Some of the most common arithmetic functions are discussed below:

+   - ceil(a): returns the ceiling value of the specified number.
+   - fabs(a): returns the absolute value of the specified number.
+   - floor(a): returns the floor value of the specified number.
+   - gcd(a, b): returns the greatest common divisor of a and b.
+   - pow(a,b): returns result of first number raised to the second number
+   - sqrt(a): returns the square root of the specified number.
