# double

A double variable can hold numbers that contain decimals places with higher precision and can hold more decimal places (up to 15 decimal places).

In below example, acceleration, mass and force are three double variables that can each hold numbers that contain up to 15 decimal places.

```
```cpp
#include<iostream>
using namespace std;

int main(){
    double acceleration = 9.91;
    double mass = 30.03;
    double force = acceleration * mass;
    cout << force;
    return 0;
}
