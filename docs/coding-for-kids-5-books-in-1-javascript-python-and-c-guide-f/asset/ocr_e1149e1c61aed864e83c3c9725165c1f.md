# Breaking Down the Code

```
```html
<form id="form1">
Enter Number 1: <input type="number" id="num1" size="20"><br>
Enter Number 2: <input type="number" id="num2" size="20"><br>
</form>
```
```

The above code creates a form that accepts two numbers, with ids of num1 and num2.

```
```html
<button onclick="sum()">+</button>
<button onclick="subtract()">-</button>
<button onclick="multiply()">*</button>
<button onclick="divide()">/</button>
```
```

The above code creates 4 buttons. Each of the 4 buttons activates the functions sum(), subtract(), multiply() and divide().

```
```javascript
function sum()
{
        var
number1=parseFloat(document.getElementById('num1').value);
        var number2=parseFloat(document.getElementById('num2').value);
        var total=number1+number2;
        document.write("The sum is "+total);
}
```
```

number1 and number2 store the numbers that were entered in the form using ids of num1 and num2

Total stores the sum of the two numbers

document.write writes the total on the screen.
