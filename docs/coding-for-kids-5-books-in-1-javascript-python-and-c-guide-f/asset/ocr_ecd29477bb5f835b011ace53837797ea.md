A text editor is just a program that enables you to write and save code as a file.

Files usually have extensions to their file names to indicate the kind of file it is. When writing C++ files, the files will have the extension .cpp , example main.cpp

We are going to use an application known as Code::Blocks to write, compile and run our programs. Code::Blocks is what is known as an IDE , integrated development environment.

An IDE has everything you need to write, compile and run a program in one place.
