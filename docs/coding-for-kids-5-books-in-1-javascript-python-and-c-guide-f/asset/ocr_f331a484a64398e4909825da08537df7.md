This time we will write a function which takes in an array and
returns the maximum value in the array.

```
```python
def find_max(inputs):
    max_value = inputs[0]
    for item in inputs:
        if item > max_value:
            max_value = item

    return max_value

maximum = find_max([1, 3, 9, 200, 6, -10])
print("Max in array is: ", maximum)
```
```

First we set max_value to the first element in the array. This is temporary. Next we iterate through each element in the array and check if that element is greater than the max we set, if so it will set that value as the new max. Once it has iterated through the entire array, max_value should contain the absolute max in the array.

For the given array [1, 3, 9, 200, 6, -10], output is:

```
```
Max in array is:  200
