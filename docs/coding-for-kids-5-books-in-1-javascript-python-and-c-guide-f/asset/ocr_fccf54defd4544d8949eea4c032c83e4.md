# Practice Problems

+   1. Write a program that takes in a string and prints out every 2<sup>nd</sup> character in the string. For example “wfwfwkfnf wbej” would print out “ffkbwj”.
+   2. Write a program that takes in a long sentence and replaces all instances of the word “red” with “yellow”.
+   3. Write a program that takes in an address and checks if the zip code contains 5 characters. If it contains more or less, or there is no zip code, print out “Invalid Address”.
