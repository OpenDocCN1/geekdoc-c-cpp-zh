# Run #4:

Enter Year: 2000

Leap Year?

**Output:**

2000 is a leap year

As you can see from the above code and results, it properly calculates the leap year through the use of 3 nested if loops.
1992 is a leap year since it is divisible by 4.
1995 is not a leap year since it is not divisible by 4.
1900 is not a leap year since it is divisible by 100.
2000 is a leap year since it is divisible by 400.
