# # Loops

A loop is a set of instructions that is repeated a certain amount of times. In most cases, a certain process is done and there is a count of the process that increases by 1. At the end of the process, we check if the count is over the number of times we need the process done. If it has reached the number of times we need, then we stop the loop.

For example, let’s say you want to print the numbers 1 to 10 on the screen. Then use a loop which counts from 1 to 10. It prints the count on the screen each time.
