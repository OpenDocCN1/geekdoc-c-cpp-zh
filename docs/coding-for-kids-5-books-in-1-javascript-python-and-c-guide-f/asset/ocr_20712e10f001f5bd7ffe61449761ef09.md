# # Timer and Animations

# ## What is a Timer?

A timer in Javascript is used to time Javascript code. It allows the user to execute different portions of the code at different time intervals. **setTimeOut()** and **setTimeInterval()** functions are used to set the timer. **setTimeOut()** allows a fixed break before executing a code; **settimeinterval()** allows the code to be executed multiple times with a fixed interval between each execution. For example: **setTimeOut(a, 1000)** executes the function **a** after **1000 ms (1 second)**. **setTimeInterval(a, 1000)** keeps executing the function with a break of **1000 ms (1 second)** between runs. These functions are the key to running JavaScript animations.
