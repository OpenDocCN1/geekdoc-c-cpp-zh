# # Loops

Loops enable us to repeat a set of instructions a fixed number of times. It can also be repeated forever if we want to.

There are usually two types of loops, *finite loops* and *infinite loops*.

Finite loops repeat the set of instructions a countable number of times while infinite loops repeat a set of instructions forever.

# ## How we specify loops

In C++ there are two ways of declaring loops.
One way is to use the **for** keyword and the other is to use the **while** keyword.

# ## For loops

Let's say you want to print out your name 10 times to the console, you might think of writing out the instruction *'cout << "My name"<< endl;'* 10 times.

Using For loops is a good way to prevent repetition of the same statement and shorten the code.
