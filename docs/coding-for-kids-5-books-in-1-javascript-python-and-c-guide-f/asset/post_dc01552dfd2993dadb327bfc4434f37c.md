## Conditional statements

### If conditional

Conditional statement is what makes programs smart. A computer is able to make decisions that enable program to change its behavior according to some Boolean expression that evaluates to either True or False. The if conditional in its simplest form is:

```python
if expression:
    statement
```

Where it executes statement if expression evaluates to True only. Note that statements must be indented below the if statement. The indented space is called a block.

### If else conditional

If else is very similar to if conditional except that we have an else block that executes if expression is False.

```python
if expression:
    statement1
else:
    statement2
```

Now we have 2 branches, first branch is statement 1 and second branch is statement 2. The program will execute the branch that corresponds to the logical expression evaluation. Think of branches as a road that forks into different roads.

### if elif else conditional

What if we want to have multiple branches instead of only two? if elif else conditional is also called chained conditionals. In a chained conditional only one branch is executed. elif stands for else if. We can have any number of elif statements as the program logic needs.

First, if expression is evaluated. If it evaluates to False, then the program proceeds to evaluating expression2 belonging to the first elif. The program keeps evaluating each expression until it evaluates to True and executes the corresponding statement/block. If all expressions evaluate to False, then it executes the else block.

```python
if expression:
    statement1
elif expression2:
    statement2
elif expression2:
    statement3
else:
```

### Nested Conditional

What if we want to create branches inside other branches? We can nest if conditional inside other if conditional. This is called nested conditional. Keep in mind that too many nested conditionals generally make the program difficult to read, so use them only when you can’t capture your program logic using a combination of logical operators.

```python
if expression:
    if expression1:
        statement1
    else:
        statement2
else:
    statement3
```

In this snippet, nested conditional was reduced into a flat if conditional using “and” logical operators. Observe that the second if conditional is easier to read.

```python
x = -1
y = 5

# nested conditional
if x < 0:
    if y < 10:
        print("nested conditional: x < 0 and y < 10")

print()
# Equivalent version using and
if x < 0 and y < 10:
    print("and version conditional: x < 0 and y < 10")
```

nested conditional: x < 0 and y < 10

and version conditional: x < 0 and y < 10

## Functions

A function is a block of reusable code that performs a specific task when called. Think of them as a machine/black box which takes inputs and transforms them into outputs. This black box is run every time it’s called. Functions help in breaking the code into simple easily maintainable reusable modules. In fact, you have been using functions all the way through this book without noticing. For example, print() is a function that takes string input and displays it on screen. Also, the string methods you learnt in the past chapter are functions that operate on strings.

### Functions definition

Functions are defined in python using the def keyword.

```python
def function_name(input_parameters):
    statements
```

To call a function, type the function name with inputs.

```python
function_name(input_parameters)
```

In the code below, we define a function that greets a user by name. It takes one input, a name, and prints hello to the user name.

```python
# function example
my_name = 'Jame'

# say hello to name
def hello(name):
    print("Hello !", name)

# function call
hello(my_name)
```

Hello ! Jame

### return statement

In the previous script, we ran the print function inside the hello function, but what if we need to return just a value to the caller instead?

In this snippet, the hello function returns a string. The hello function is called first and the returned value is stored in the assigned variable.

```python
# function example
my_name = 'Jame'

# return hello to name
def hello(name):
    return "Hello !" + name

# function call
returned_name = hello(my_name)
print(returned_name)
```

Hello !Jame

### Empty return

When a function's return statement is empty, it terminates the function run and returns None.

In this example when func is called it only executes line 4 because it terminates when it reaches the return statement at line 5. Also, note that it returns None.

```python
# None return

def func():
    print("Before return nothing")
    return
    print("After return nothing")

m = func()
print()
print("func returned ", m)

# Output:
# before return nothing
#
# func returned  None
```

## Example 3: is divisible

In this example, the is_divisible function checks if a is divisible by b, if so, it prints a message and sets div to true. If a is not divisible by b, the else statement will handle this case where it prints a message and sets div to false.

```python
# is_divisible
# checks if a is divisible by b, print a message
# return true else false

def is_divisible(a, b):
    div = None
    if a % b == 0:
        print(f"{a} is divisible by {b}")
        div = True
    else:
        print(f"{a} is not divisible by {b}")
        div = False

    return div

n1 = is_divisible(8, 2)
n2 = is_divisible(8, 3)

print(n1)
print(n2)
```

```
8 is divisible by 2
8 is not divisible by 3
True
False
```

## Loops

Loops in coding are a sequence of instructions that are repeated a certain number of times. Think of a loop like a repeating operation that keeps repeating until a condition is met. There are mainly 2 types of loops based on the conditions of execution. They are:

- a. **FOR Loops:** FOR loops contain a sequence of instructions that are executed for a certain number of times. For example, a FOR loop from 1 to 10 executes the code inside the loop 10 times.
- b. **WHILE Loops:** WHILE loops are a sequence of instructions that are executed till a certain condition is met.

Now, if we want to do 1000 executions of execute function; we use a FOR loop. The FOR loop below starts at 0 and ends at 999, thus running execute function 1000 times.

```python
for i in range(1000):
```
