# Why Python is Great for Beginners

Python is a great programming language to learn. It’s easy to learn and it is a good entry point into the world of programming. Python was invented by a person named Guido van Rossum, he was working on an educational project to build a language for new coders called ABC. As a result of this project he created the Python programming language. Guido made Python with four main goals in mind. These goals are to be intuitive, open source, easy to understand and to be versatile to allow for shorter development time. Python continues developing and maturing till today. Many enthusiasts and developers use it every day for a variety of tasks. Python is used for many tasks like web development, scripting, web scraping, data analysis and automation.
