# Form Html Tag format

Below is an example of a form html tag that takes in name, occupation and gender.

```
<form id="form1">
Name: <input name="Enter Name" type="text" id="name" size="20"><br>
Occupation: <input type="text" id="occupation" size="20"><br>
Age: <input type="number" id="gender" size="20"><br>
</form>
```

Once you run the program, the output looks like below. You can type anything in the empty boxes in the output. The empty boxes are also called textboxes.

![](bbox=[0.259, 0.405, 0.728, 0.505])

# Different parts of form html tag

`<form id="form1">`

The form id tag is the name of the form that will used as a reference in the rest of the code.

+   - `Name:`
+   - `Occupation:`
+   - `Age:`

This is the text that’s written at the left of the box. It is used to describe to the user what to put in the box.

`input type="text"`

This means that what you type in the box is a type of text or string. For example, name and occupation uses text because you type letters in the box.

`input type="number"`
