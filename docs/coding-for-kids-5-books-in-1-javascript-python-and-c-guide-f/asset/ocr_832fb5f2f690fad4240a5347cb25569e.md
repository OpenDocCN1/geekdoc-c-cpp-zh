# Substrings and String Index

There are a couple of other string manipulation techniques that I would like to discuss before we move on. These are string index and substring.

String Index gives you the position within a certain string that another string occurs. For example, the string index of boy in the string “The boy climbed the tree” is 4, because boy starts at the 4th character of the overall string.

A substring lets you extract a section of an existing string. For example, in the same string “The boy climbed the tree”; if we do a substring from 6 to 10 we get “oy cl” because those are the characters between 6 and 10.
