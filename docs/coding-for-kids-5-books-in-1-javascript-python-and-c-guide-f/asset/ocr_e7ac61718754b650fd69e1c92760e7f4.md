A while loop runs while a certain condition is met. If the condition is no longer met, it breaks out of the loop. In the below example, the program executes a while loop that takes in a user input via the input function. The while loop keeps running and printing the user text. The loop stops when the user inputs the word ‘STOP’. Once the word is input, that’s the end of the while loops and the program stops.

```
```python
text = ''

while(text != 'stop'):
    text = input("What do you want to do now ? ")
    print("Activity is : ", text)
```
```
