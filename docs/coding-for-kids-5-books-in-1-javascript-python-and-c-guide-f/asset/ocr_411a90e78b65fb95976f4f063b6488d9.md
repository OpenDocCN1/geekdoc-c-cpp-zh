# Example 4 – Guess World Capitals

In this example we use both list and dictionary. A dictionary capital_dict is used to make country:capital key pairs. Then we get the dictionary keys using keys() method and store them in countries list. This is essential so we can use random.choice() function which takes a list and return a value from list randomly. Then inside an infinite while loop, user is asked for a capital using input function and the answer is compared to actual capitals.

```
```python
# World capital game
import random

# World capitals dictionary
capital_dict={
    'spain':'madrid',
    'france':'paris',
    'germany':'berlin',
    'norway':'oslo',
    'india':'new delhi',
    'egypt':'cairo'
}

# get countries and convert it to list so we can use random function
countries = list(capital_dict.keys())
print ("Let's learn World Capitals. Enter quit to quit the game.")

while True:
    # pick a random country
    country = random.choice(countries)
    capital = capital_dict[country]

    guess = input(f'What is the capital of {country}.')
    # if user type quit, quit
    if guess.lower() == "quit":
        break
    elif guess.lower() == capital:
        print(f'Correct !')
        break
    else:
        print(f'Incorrect. The capital of {country} is {capital}.')
