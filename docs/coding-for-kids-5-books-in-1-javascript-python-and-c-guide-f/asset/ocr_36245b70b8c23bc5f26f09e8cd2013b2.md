# # Exercises to Practice:

You can copy the above examples and once you are able to run them and
understand the code; you can try a few of the problems below.

+   1. Write a program that find how many times a particular string occurs within a bigger string that is input in a textbox?
+   2. Write a program that takes in a string that includes a name, math mark, English mark, physics mark and geography mark. Use the split function to separate the string and find the average score for the person. For example, “Mark, 90, 34, 56, 65” would find the average of 90, 34, 56, 65 for Mark.
+      Hint: You can use parseInt() to convert the scores into numbers.
