This still doesn’t solve the problem of typing multiple print statements. Notice how the index always increments by one, we can use a for loop and set the index as a variable.

```
```python
carNames = [ 'Toyota', 'Ford', 'BMW', 'Ferrari', 'Porsche']

for i in range (0,5):
    print("Car number", i+1, "is ", carNames[0])
```
```

Variable ‘i’ is initially 0 and the loop executes as long as ‘i’ is less than 5, i.e ‘i’ takes the values between 0 and 5 excluding 5.The output for the above code will be similar to the previous output. There is another way to access all the elements in the list using a for loop.
