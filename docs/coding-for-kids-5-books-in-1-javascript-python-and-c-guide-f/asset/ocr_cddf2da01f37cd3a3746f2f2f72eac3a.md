str.isalpha() – returns True if all string characters are letters.

a = ‘door1’

a.isalpha() returns False

str.isdigit() – returns True if str contains digits only.

n = ‘324235’
m = ‘d4ds’

n.isdigit(), returns True
m.isdigit(), returns False

str.islower()- returns True if string characters are all lowercase.

s=“People”
s.islower() return False

S = “ALL”
