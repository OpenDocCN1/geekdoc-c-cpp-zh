# Example 2

Below is a function that takes in a number (n) and adds all integer numbers from 1,2 …. N.

```
```python
def add_numbers(n):
    n = int(n)
    total = 0
    counter = 1
    while counter <= n:
        total = total + counter
        counter = counter + 1
    return total

n = input("Please enter value of n: ")
print("Total sum is",add_numbers(n))
```
```

Counter is the current number being added, starting from 1. Total is the summation of the numbers so far. We increment counter by 1 every iteration to change the number being added, so counter goes 1,2,3… n. When the counter reaches n + 1 the while loop will break, and we return the total at the end.
