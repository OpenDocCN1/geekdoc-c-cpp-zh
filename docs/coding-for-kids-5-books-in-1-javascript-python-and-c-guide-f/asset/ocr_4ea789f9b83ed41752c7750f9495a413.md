# **document.getElementById().value**

Document.getElementById().value is used to get html elements into JavaScript variables. So, we need to use the id of the html element and put it in between brackets. Let’s look at an example.

Let’s look at below html element:

```
`Enter number: <input name=”x” type=”number” id=”test” size=”20”><br>`
```

JavaScript code:

```
`var testv=document.getElementById("test").value;`
```

The html element is a form textbox that extracts a number from the user. In Javascript, the number that the user assigns is set to the variable testv.

# How to add Comments

Comments are items that you add to the code to document or explain the code. Comments cannot be executed and do not effect the program. Comments in JavaScript are added using two double backslash in front of the comment (“//”)
