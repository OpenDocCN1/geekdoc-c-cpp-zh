int const, int[7], and int(int) parameters have decayed to int, int*, and int(*)(int), respectively.

We can implement a trait that produces the same type conversion of passing by value. To match to the C++ standard library trait std::decay, we name it DecayT.⁹ Its implementation combines several of the techniques described above First, we define the nonarray, nonfunction case, which simply deletes any const and volatile qualifiers: Click here to view code image

```

struct DecayT : RemoveCVT<T> {
};
```

};
```

```

};
```

};
```
