# 15.10.5 Structured Bindings

C++17 added a new feature known as structured bindings.¹⁴ It is most easily introduced with a small example: Click here to view code image

```
struct MaybeInt { bool valid; int value; };
MaybeInt g();
auto const&& [b, N] = g(); // binds b and N to the members of the result of g()
```

The call to g( ) produces a value (in this case a simple class aggregate of type MaybeInt) that can be decomposed into “elements” (in this case, the data members of MaybeInt). The value of that call is produced as if the bracketed list of identifiers [b, N] were replaced by a distinct variable name. If that name were e, the initialization would be equivalent to: auto const&& e = g(); The bracketed identifiers are then bound to the elements of e. Thus, you can think of [b, N] as introducing names for the pieces of e (we will discuss some details of that binding below).

Syntactically, a structured binding must always have an auto type optionally extended by const and/or volatile qualifiers and/or &and/or && declarator operators (but not a * pointer declarator or some other declarator construct). It is followed by a bracketed list containing at least one identifier (reminiscent of the “capture” list of lambdas). That in turn has to be followed by an initializer.
