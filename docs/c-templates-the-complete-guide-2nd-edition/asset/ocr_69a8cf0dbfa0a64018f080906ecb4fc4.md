```
template<typename T1, typename T2>
struct PlusResultT {
using Type = decltype(T1() + T2());
};
```

```
template<typename T1, typename T2>
using PlusResult = typename PlusResultT<T1, T2>::Type; This trait template uses decltype to compute the type of the expression T1() + T2(), leaving the hard work of determining the result type (including handling promotion rules and overloaded operators) to the compiler.
```

However, for the purpose of our motivating example, decltype actually preserves too much information (see Section 15.10.2 on page 298 for a description of decltype’s behavior). For example, our formulation of PlusResultT may produce a reference type, but most likely our Array class template is not designed to handle reference types.
