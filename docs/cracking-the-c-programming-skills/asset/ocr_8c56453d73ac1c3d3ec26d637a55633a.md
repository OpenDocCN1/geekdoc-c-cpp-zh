5. What is the output of the code? (L3)

```
#include<iostream>
using namespace std;
class cons
{ public:
 int m;
 void cons()
 { m=9; }
}S;
int main()
{ cout<< “S.m”;}
```

(a) 9        (b) 0
(c) Unpredictable        (d) Error
Answer: (d) Here the function ‘fun()’ is treated as a normal member function as the function has a return type. The compiler finds that it is a constructor with return type and throws “return type specification for constructor ‘void cons’”.
