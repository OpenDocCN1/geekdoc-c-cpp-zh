### 11. 代码的输出是什么？(L3)


- (c) 错误
- (d) 以上都不是

答案：(a) 'static' 存储类意味着即使代码块执行完毕，变量仍会存储在内存中。只有整个程序执行完毕后，该变量才会被释放。如果下次调用该变量，它会保留旧值。
