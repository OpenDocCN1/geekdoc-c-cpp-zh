

## 8 函数重载与重写

函数重载是面向对象编程最有用的特性之一，它允许在不损失可读性的情况下增加程序的功能。本章详细讨论函数重载的方方面面，并引导你进入重写。

### 1. 以下代码使用了哪种面向对象概念？(L2)

```cpp
#include <iostream>
using namespace std;
class function_echo
{
public:
void echo(int x) {
cout << "Output: " << x << endl;
}
void echo(double y) {
cout << "Output: " << y << endl;
}
void echo(char* z) {
cout << "Output: " << z << endl;
}
};
int main(void)
{
function_echo foo;
foo.echo(76);
foo.echo(7878.099);
foo.echo("Hello, Welcome to Polymorphism");
return 0;
}
```

- (a) 运算符重载
- (b) 函数重载
- (c) 函数重写
- (d) 以上都不是

**答案：** (b) 代码中使用了函数重载。函数名 echo 被用于打印所有数据类型。

### 2. 以下代码的输出是什么？(L2)

```cpp
#include <iostream>
using namespace std;
class function_echo
{
public:
void echo() {
cout << "I have nothing passed as an argument" << endl;
}
void echo(double y) {
cout << "Output: " << y << endl;
}
void echo(char* z) {
cout << "Output: " << z << endl;
}
};
int main(void)
{
function_echo foo;
foo.echo();
foo.echo(780.23);
foo.echo("Hello, This is a tough question");
return 0;
}
```

- (a) 无输出
- (b) 语法错误
- (c) 我没有传入任何参数  
  输出：780.23  
  输出：你好，这是一个棘手的问题
- (d) 编译错误

**答案：** (c) 这段代码可以正常运行，函数将根据参数数量被识别；由于第一次调用没有参数，它会搜索合适的无参函数并调用它。所以答案是 C。

### 3. 以下代码的输出是什么？(L3)

```cpp
#include <iostream>
using namespace std;
class function_echo
{
public:
void echo() {
cout << "I have nothing passed as an argument" << endl;
}
void echo() {
cout << "I too have nothing with me: " << endl;
}
void echo(char* z) {
cout << "Output: " << z << endl;
}
};
int main(void)
{
function_echo foo;
foo.echo();
foo.echo();
foo.echo("Hello, This is a tough question");
return 0;
}
```

- (a) 代码将出现编译错误
- (b) 代码将顺利运行
- (c) 代码将出现语法错误
- (d) 以上都不是

**答案：** (a) 代码将出现编译错误，因为 echo 两次无参数导致有歧义。编译器无法选择其中一个，因为两者相同。

### 4. 以下代码的输出是什么？(L3)

```cpp
#include <iostream>
using namespace std;
class function_add
{
public:
void add(int x, int y) {
cout<<x+y<<" ";
}
void add(double x, double y) {
cout<<x+y<<" ";
}
};
int main(void)
{
function_add foo;
foo.add(76, 45);
foo.add(1.0000, 2.0000);
return 0;
}
```

- (a) 编译故障
- (b) 语法错误
- (c) 121 3
- (d) 3 121

**答案：** (c) 这是正确的函数重载，函数 add 已被重载以处理 double 参数。

### 5. 以下代码的输出是什么？(L3)

```cpp
#include <iostream>
using namespace std;
class function_add
{
public:
void add(int x, int y) {
cout<<x+y<< " ";
}
void add(double x, double y, int z) {
cout<<x+y+z<<" ";
}
};
int main(void)
{
function_add foo;
foo.add(76, 45);
foo.add(1.0000, 2.000, 2);
return 0;
}
```

- (a) 编译故障
- (b) 语法错误
- (c) 121 5
- (d) 5.0 121

**答案：** (c) 这是使用函数重载的正确方式，会正常工作。两个函数的参数数量不同，因此将根据参数数量进行调用。前者 2 个参数，后者 3 个。

### 6. 以下关于函数重载的说法哪项正确？(L2)

- (a) 函数的参数数量可以相同。
- (b) 所有函数的参数数量必须不同。
- (c) 参数数量或参数类型应不同。
- (d) 对数据类型或参数数量没有要求。

**答案：** (c) 要执行重载，参数数量或参数类型应不同。

### 7. 以下代码的输出是什么？(L3)

```cpp
#include <iostream>
using namespace std;
class function_add
{
public:
void add(int x, int y, int z) {
cout<<x+y+z<<" ";
}
void add(int a, int b, int c) {
cout<<a+b+c<<" ";
}
};
int main(void)
{
function_add foo;
foo.add(1, 2, 3);
foo.add(4, 5, 6);
return 0;
}
```

- (a) 6 15
- (b) 15 6
- (c) 编译错误（无法重载）
- (d) 以上都不是

**答案：** (c) 两个函数的参数数量和类型相同，而函数名也相同。这有歧义，编译将失败并提示无法重载。

### 9. 以下关于 C++ 函数重载的说法哪些是不正确的？(L2)

- (a) 函数重载是不可能的。
- (b) 运算符重载是不可能的。
- (c) 构造函数重载是不可能的。
- (d) 析构函数重载是不可能的。

**答案：** a、b 和 c 是可能的，而题目中却声称它们不可能。只有析构函数不能重载。

### 10. 以下代码片段的输出是什么？(L3)

```cpp
#include <iostream>
using namespace std;
void add(int);
void add(int, int);
void add(int, int, int);
int main()
{
    int x = 1;
    int y = 2;
    int z = 3;
    add(x);
    add(x, y);
    add (x, y, z);
    return 0;
}
void add (int a)
{
    cout << a << endl;
}
void add (int a, int b)
{
    cout << a + b << endl;
}
void add (int a, int b, int c)
{
    cout << a + b + c << endl;
}
```

- (a) 语法错误
- (b) 1, 3, 6
- (c) 编译故障
- (d) 以上都不是

**答案：** (b) 是答案。三个函数的参数数量都不同，因此调用将很精确。输出将是 1、1 + 2 和 1 + 2 + 3，得到 1、3 和 6。

### 11. 为什么有人会重载构造函数？从以下选项中选择可能的原因。(L2)

- (a) 为了获得更大的灵活性
- (b) 因为这是强制性的
- (c) 为了支持拷贝构造函数的概念
- (d) 为了避免编译故障

**答案：** (a) 和 (c) 重载构造函数不是强制性的，如果不重载也不会导致任何编译故障。

### 12. 以下代码的输出是什么？(L3)

```cpp
#include <iostream>
using namespace std;
class constructor_overloading
{
    public:
    int a;
    constructor_overloading (int b)
    {
        cout << "\n" << "single parameter"<< endl;
        a = b;
    }
    constructor_overloading ()
    {
        cout << "\n" << "No Argument"<< endl;
    }
};
int main()
{
    constructor_overloading obj1(2);
    cout << obj1.a << endl;
    constructor_overloading obj2;
    return 0;
}
```

- (a) 语法错误
- (b) 构造函数不能被重载
- (c) 单参数  
  2  
  无参数
- (d) 由于代码中没有析构函数，它将失败。

**答案：** (c) 是正确答案，因为构造函数可以被重载，第一个将调用带一个参数的构造函数，第二个将调用无参构造函数。如果代码中添加了析构函数会更好，但不是强制性的。
