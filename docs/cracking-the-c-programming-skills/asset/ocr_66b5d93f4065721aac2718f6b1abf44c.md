# **155. Give a brief note on near and far pointer.**

All the terms as near and far pointers were used in the olden programming days where the memory available was not suffice. Now, it is not being used at most of the places and in very few embedded systems it is being used. Near pointers are 16 bits long and have capacity to address 64 KB range whereas far pointers are 32 bits long and have capacity to address 1 MB range.
