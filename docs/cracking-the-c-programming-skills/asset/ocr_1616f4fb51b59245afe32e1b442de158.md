46. What is the output of the code? (L3)

```
~~~cpp
#include<iostream>
using namespace std;
struct tea
{ int rate;
  struct bun
  { int temp; };
}t;
int main()
{ t.rate=9;
  struct bun b;
  b.temp = 98;
  cout<<b.temp; }
~~~
```

+   (a) 98    (b) Error
+   (c) Unpredictable   (d) None of the above

Answer: (b) structures inside another structure do not get global scope in C++.
