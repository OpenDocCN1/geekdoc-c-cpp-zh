```cpp
#include<iostream>
using namespace std;
    class dev1 : public base
{ };
class base
{  public:
       static int fun; };
class dev2 : public dev1
    { };
int dev2::base::fun = 3;
    int main()
{ cout<<dev2::base::fun; }
```

- (a) 3
- (b) 不打印任何内容
- (c) 错误
- (d) 以上都不是

**答案：(c)** 基类必须在派生类之前定义。它会抛出错误“class-name before ‘{’ token”。

### 90. 代码的输出是什么？(L3)

```cpp

using namespace std;
class base
{ public:
    void fun()
    { cout<< "fun"; }
};
class dev1 : public base
{ public:
    int b;
    void fun()
    { cout<<b<< " "; } }S;

    int b; }D;
```

### 93. 以下哪一项会是代码抛出的错误之一？(L4)

```cpp
#include<iostream>
using namespace std;
class base
{
public:
    static int b;
    static void fun()
    { cout<< b; }
};

class dev1 : public base
{ }S;
class dev2 : public base
{ }D;

{ base::dev1::b = 9;
  base::dev2::b = 3;
  dev1::fun();

```

- (a) 无效的类层级`base::dev2`
- (b) `base::dev2`尚未声明
- (c) `dev2`未被`base`继承。无效的类层级`base::dev2`

**答案：(b)** 编译器查找了继承了`dev2`的`base`。由于它未定义，因此抛出未声明。类似地，它也会抛出“`base::dev1` has not been declared”。

### 94. 代码的输出是什么？(L4)

```cpp
#include<iostream>
using namespace std;
class base
{
public:
    int b;
    void fun()
    { cout<< b<< " "; }
};

class dev1 : public base
{ public:
    int b;
}S;

class dev2 : public base
{ }D;

class dev3 : public base
{ }E;

int main()
{ S.b = 3;
  D.b = 2;
  E.b = 5;
  S.fun();
  D.fun();
  E.fun(); }
```

- (a) 3 2 5
- (b) 不打印任何内容
- (c) 错误
- (d) 以上都不是

**答案：(d)** 它打印“0 2 5”。这里“dev1”中的“3”进入其原始成员。但“base”中的“fun”指向其成员“b”。因此“dev1”继承的成员“b”没有获得值。因此它得到0。
