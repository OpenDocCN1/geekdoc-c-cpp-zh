# 156. What is a namespace and how are they useful?

Entities like classes, objects and functions can all be grouped under a name and it is referred to be as namespace.

# 157. What is a macro?

A macro is a statement that defines an expression for an identifier. Before compilation, the pre-processor replaces all the macros with their definitions.

# 158. What is '#' called?

It is called pre-processor directive. It indicates a command to pre-processor to be done before compiling.

# 159. What is exception handling?

Exception handling is the art of handling errors and by-passing errors to continue compilation.

# 161. What is multi catch?

A single try block with multiple `catch` block is called multi catch. Each catch block differs by the arguments it takes. It acts like a switch case and a exception enters into the best match. Finally, the `catch()` without any arguments is treated as default catch. If there is no match for the exception it enters into the default catch block.
