- **8.** 预测以下代码的输出。

  ```cpp
  #include <stdio.h>
  #define SQ(p) p*p
  void main() {
      int val=4;
      printf("\nSQ(val+4)=%i",SQ(val+4));
  }
  ```

  - (a) 64
  - (b) 256
  - (c) 24
  - (d) 以上都不是

  **答案**：(c) 24。编译器一看到 SQ(something)，就会将其替换为 SQ(something)*SQ(something)。因此，SQ(val+4) 变成 val+4*val+4，即 4+4*4+4，然后计算为 4+16+4，等于 24。
