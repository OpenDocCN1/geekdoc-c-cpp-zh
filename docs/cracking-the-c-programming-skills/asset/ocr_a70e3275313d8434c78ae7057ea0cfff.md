+   11. Say true or False. If we open a file using text stream, the data will undergo conversion to and from ASCII, whereas if we open a file using binary stream, there will not be any conversion. (L2)
+       (a) True        (b) False
+       **Answer:** (a) True. When text mode is used, the data we insert to the file will be saved in ASCII equivalent. For instance, if 0 is in the file, it will be stored as 48 (ASCII equivalent). If it is in binary mode, the value 0 will be saved as 0000000 (binary equivalent of 0). While reading the data back from file, it will be converted from ASCII.
