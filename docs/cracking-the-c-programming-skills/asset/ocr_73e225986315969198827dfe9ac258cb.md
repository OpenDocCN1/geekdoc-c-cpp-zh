24. What is the output of the code? (L3)

```
```cpp
#include<iostream>
using namespace std;
class cons
{ public:
    int m;
    cons()
    { int d=8; }
};
int main()
{ cons S;
    cout<< S.d; }
```
```

+   - (a) 8
+   - (b) 0
+   - (c) Prints nothing
+   - (d) Error

Answer: (d) 'd' has the scope of the constructor. It is deleted after the execution of the constructor. So it is not accessible from the object.

25. What is the output of the code? (L3)

```
```cpp
#include<iostream>
using namespace std;
class cons
{ public:
    int m;
    cons()
    { cout<< "basic constructor"; }
    cons(int d)
    { cout<< "constructor with parameters"; }
};
    int main()
    { cons S(3); }
```
```

+   - (a) constructor with parameters
+   - (b) basic constructor
+   - (c) Prints nothing
+   - (d) Error

Answer: (a) This is a form of overloaded constructor. It accepts objects with parameters.
