## 2 类

本章带你了解类的方方面面。这个概念是面向对象编程的首要必要条件。学习完本章后，你将能够轻松处理类、对象以及任何相关概念。

- **1.** 代码的输出是什么？(L1)

  ```cpp
  #include<iostream>
  using namespace std;
  class student
  { public:
    int marks;
    void percent()
    { cout<< marks*10; }
  }S;
  int main()
  { S.marks=9;
    S.percent(); }
  ```

  |  |  |
  |---|---|
  | (a) 90 | (b) 9 |
  | (c) 错误 | (d) 不可预测 |

  **答案：** (a) ‘S’是类的对象/实例。它可以访问类的‘public’成员。‘public’是访问说明符。类还有两个说明符‘private’和‘protected’。变量称为‘数据成员’，函数称为‘成员函数’。

- **2.** 代码的输出是什么？(L1)

  ```cpp
  #include<iostream>
  using namespace std;
  class student
  { private:
    int marks;
    void percent()
    { cout<< marks*10; }
  }S;
  int main()
  { S.marks=9;
    S.percent(); }
  ```

  - (a) 90
  - (b) 9
  - (c) 错误
  - (d) 不可预测

  **答案：** (c) ‘private’访问说明符意味着该数据需要对其他无关信息和用户隐藏。尝试访问‘private’数据和成员函数会抛出错误。它只能由类的成员访问，甚至对象也不能访问。

- **3.** 代码会抛出什么错误？(L3)

  ```cpp
  #include<iostream>
  using namespace std;
  class student
  { private:
    int marks;
    void percent()
    { cout<< marks*10; }
  }S;
  int main()
  { S.marks=9; }
  ```

  - (a) ‘int student::marks’是私有的
  - (b) 在此上下文中 S.marks=9;
  - (c) ‘student::marks’未定义
  - (d) ‘a’和‘b’都正确
  - (e) ‘d’和‘b’都正确

|  |  |
|---|---|
| (a) 4 | (b) 0 |
| (c) 不可预测 | (d) 以上都不是 |

**答案：(a)** 尽管成员不能由对象访问，但每个对象都会有一个特定的变量值。因此会为它分配内存。
