+   - ✓ 5 + 3 = 8
+   - ✓ Shri + ram = Shriram

Here + is the operator used to add two numbers and in the second case, it is used as a concatenation operator. This is the purpose of the operator overloading and function overloading will let two different functions to have same function name.

# 127. Define single inheritance with appropriate pseudocode.

When one derived class is inherited from one base class, it is referred to be single inheritance.

Pseudocode:

```
~~~cpp
class base_class // This is base class.
{
public:
    ---------- // Code goes here.
};
class derived_class: public base_class
//Deriving class from the base and single inheritance is achieved here.
{
public:
    ---------- // Code goes here.
}
~~~
```

# 128. Explain multiple inheritance with an example.

When one derived class is derived (inherited) from multiple base classes it is referred to multiple inheritance.

```
~~~cpp
class base_class_1 // Base class 1. One of the base classes.
{
public:
    ----- // Code goes here.
};
class base_class_2 // Base class 2. Second base class.
{
public:
    ----- // Code goes here.
};
class derived_class: public base_class_1, public base_class_2
// base classes are now derived classes and it is called multiple inheritance.
{
public:
    ----- // Code goes here.
}
~~~
```

# 129. Explain multilevel inheritance with an example.

A class will be used to create the derived class. For example A -> B -> C -> D, where A is the base class, B being the first derived class, C being the second derived class, but derived from B and so on. This is called multi-level inheritance.

```
~~~cpp
class base_class_1 // Base class_1. It is to be inherited.
{
public:
    int x, y;
};
class derived_class: public base_class // deriving from base class.
{
public:
    int z;
}
~~~
```
