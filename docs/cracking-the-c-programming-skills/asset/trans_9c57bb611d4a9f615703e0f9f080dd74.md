## 6 继承

本章讲解一个非常重要的面向对象概念“继承”。它阐明了继承的所有形式和技术。在本章结束时，你将能够在编程技能中高效运用这一概念。继承是从一个类获取特征到另一个类的概念。数据成员和成员函数都可以被继承。

1. 以下代码的输出是什么？(L1)

```cpp
#include<iostream>
using namespace std;
class base
{ public:
    int b; };
class dev : public base
{ };
int main()
{ dev S;
    S.b = 9;
    cout<<S.b; }
```

- (a) 9
- (b) 0
- (c) 不可预测
- (d) 错误

**答案：(a)** 这里类‘dev’以‘public’模式继承类‘base’的功能。冒号是继承运算符。‘public’继承方式意味着基类的所有‘public’成员成为派生类的‘public’成员，基类的‘protected’成员成为派生类的‘protected’成员。这是简单继承。

2. 以下代码的输出是什么？(L3)

```cpp
#include<iostream>
using namespace std;
class base
{ protected:
    int b; };
class dev : public base
{ };
int main()
{ dev S;
    S.b = 9;
    cout<<S.b; }
```

- (a) 9
- (b) 0
- (c) 不可预测
- (d) 错误

**答案：(d)** 在‘public’继承中，基类的‘protected’成员将作为派生类的‘protected’成员被继承。‘protected’成员不能由对象直接访问。

3. 以下代码的输出是什么？(L1)

```cpp
#include<iostream>
using namespace std;
class base
{ protected:
    int b; };
class dev : public base

      cout<<b; }
}S;

int main()
{ S.play(); }
```

- (a) 4
- (b) 0
- (c) 不可预测
- (d) 错误

**答案：** (a) ‘protected’成员可以被‘public’成员调用。
