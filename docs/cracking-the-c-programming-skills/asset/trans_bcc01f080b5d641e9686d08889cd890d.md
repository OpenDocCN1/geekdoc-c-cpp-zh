
### 29. 代码的输出是什么？（L4）

```cpp
#include<iostream>
using namespace std;
int main()
{ cin>>9;
cout<< 9; }
```

- (a) 9
- (b) 不可预测
- (c) 错误
- (d) 以上都不是

答案：(c) 这会产生相同的错误。提示“`operator>>` 的重载有歧义”以及相关说明。它只是说明操作数的用法错误，并给出多种可能的方式。

### 33. 代码的输出是什么？（L3）

```cpp
#include<iostream>
using namespace std;
int main()
{ int a=9;
int& b=a;
cout<< a<< " "<<b; }
```

- (a) 9 9
- (b) 9 0
- (c) 错误
- (d) 以上都不是

答案：(a) 变量‘b’称为引用变量，这是 C++ 特有的。它类似于指针，但仍有一些主要区别。因此 C++ 中同时存在引用变量和指针。这里‘b’指向‘a’的值。引用变量意味着为同一内存位置提供多个名称。

### 39. 代码的输出是什么？（L3）

```cpp
#include<iostream>
using namespace std;
int main()
{ int a=9;
 int b=a<<2;
 cout<<b; }
```

- (a) 2
- (b) 162
- (c) 36
- (d) 错误

答案：(c) “<<”是数字的左移。‘a<<n’表示将‘a’的位向左移 n 位。这等于乘以 2 的 n 次方。因此，这里结果是 36（9 x 4）。

### 40. 代码的输出是什么？（L3）

```cpp
#include<iostream>
using namespace std;
int main()
{ int a=9;
 int b=a>>2;
 cout<<b; }
```

- (a) 2
- (b) 2.5
- (c) 2.25
- (d) 错误

答案：(a) `">>"` 是数字的右移。`'a>>n'` 表示将 'a' 的位向右移 n 位。这等价于除以 2 的 n 次方。这里，9/2 = 4，而 4/2 得到最终输出 2。
