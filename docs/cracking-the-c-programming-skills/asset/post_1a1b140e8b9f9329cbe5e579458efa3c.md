### 33. What is the output of the code? (L3)

### 39. What is the output of the code? (L3)

```cpp
#include<iostream>
using namespace std;
int main()
{ int a=9;
 int b=a<<2;
 cout<<b; }
```

- (a) 2
- (b) 162
- (c) 36
- (d) Error

Answer: (c) “<<” is shift left for numbers. ‘a<<n’ means shift the bits of ‘a’ to left by n bits. This is equal to multiplication by 2 power n. Hence, here it is 36 (9 x 4).
