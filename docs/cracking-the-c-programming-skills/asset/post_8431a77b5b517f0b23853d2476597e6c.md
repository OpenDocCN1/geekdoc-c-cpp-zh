### 3. Predict the output of the following code snippet, given val1=10, val2=20 (L2)

```cpp
#include <iostream>
#include <exception>
using namespace std;
struct UserDefinedException : public exception
{
    const char * what () const throw ()
    {
        return "Value 2 cannot be greater than value 1";
    }
};
int main()
{
    int val1,val2;
    std::cout<<"Please enter value1";
    std::cin>>val1;
    std::cout<<"Please enter value2";
    std::cin>>val2;
    try
    {
        if (val2>val1)
            throw UserDefinedException();
        else
            std::cout<<val1/val2;
    }
    catch(UserDefinedException& e)
    {
        std::cout << e.what() << std::endl;
    }
}
```

- (a) No output
- (b) Value 2 cannot be greater than value 1
- (c) 0
- (d) Compile error

**Answer:** (b) Value 2 cannot be greater than value 1. Try block compares value1 with value2. When value2 is greater than value1, we are throwing user defined exception. When we call `what()` method present in user defined exception class, it prints the output statement, Value 2 cannot be greater than value 1.
