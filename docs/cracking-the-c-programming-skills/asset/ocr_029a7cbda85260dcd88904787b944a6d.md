75. What is the output of the following code snippet? (L3)

```
    # include <iostream>
    using namespace std;
    int main (){
        register int i = 10;
        cout <<i <<"\n";
        getchar ();
        return 0;
    }
```

+   (a) 1
+   (b) 10
+   (c) Usage of register is wrong
+   (d) None of the above

**Answer:** (b) It is very much legal to use the register as storage qualifier. But, programmers prefer when faster access is required.

78. Identify the error in the following code. (L4)

```
    # include <iostream>
    using namespace std;
    global int sum = 0;
    int auto_verify ()
    {
        sum = sum + 1;
        cout <<"\n" << sum;
    }
    int main ()
    {
        int i, ret;
        for (i=1;i<=5;i++)
        {
            ret = auto_verify();
        }
        getchar ();
        return 0;
    }
```

**Answer:** There is no explicit keyword called global supported in C or CPP. If declared above main, it naturally gets qualified as global storage qualifier.
