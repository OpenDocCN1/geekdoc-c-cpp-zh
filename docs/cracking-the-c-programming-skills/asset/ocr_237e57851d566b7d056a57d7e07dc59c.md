31. What is the output of the code? (L1)

```
    #include<iostream>
    using namespace std;
    class base
    { public:
        int b; };
    class dev : private base
    { public:
        void fun()
        { b = 2;
            cout<< b; }
    }D;
    int main()
    { D.fun(); }
```

+   - (a) 2
+   - (b) Unpredictable
+   - (c) Error
+   - (d) None of the above

Answer: (a) 'private' mode of inheritance makes both 'public' and 'protected' members of base class into 'private' members of derived class. So it is accessible from a function.

32. What is the output of the code? (L3)

```
    #include<iostream>
    using namespace std;
    class base
    { public:
        int b; };
    class dev : private base
    { }D;
    int main()
    { D.b = 2;
        cout<<D.b; }
```

+   - (a) 2
+   - (b) Unpredictable
+   - (c) Error
+   - (d) None of the above

Answer: (c) As said above, 'b' will be inherited as 'private' variable.
