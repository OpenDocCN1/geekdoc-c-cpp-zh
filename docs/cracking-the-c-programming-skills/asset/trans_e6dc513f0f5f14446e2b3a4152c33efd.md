## 13. 以下代码的输出是什么？(L4)
（假设地址分配从 1000 开始）

```cpp
# include <iostream>
using namespace std;
int main ()
{
    int n=10;
    int *pointer;
    pointer = new (nothrow) int;
    cout<<pointer<< " ,";
    *pointer =n;
    cout<<* pointer<<endl;
    getchar ();
    return 0;
}
```

- (a) 1000, 10
- (b) 语法错误，因为没有叫作 nothrow 的东西可用。
- (c) 10, 1000
- (d) 编译错误

**答案：(a)** 是正确答案。这里，程序使用 nothrow 来避免抛出异常。它不会抛出异常，而是将分配的地址作为返回值；如果地址分配失败，则返回零。
