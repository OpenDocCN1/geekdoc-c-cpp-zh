```cpp

    {
        cout << "class initiated";
        main();
    }
};
int main()

    cons S;
}
```
```

+   (a) Prints `class initiated` repeatedly till stack overflows
+   (b) Prints `class initiated` once
+   (c) Prints nothing
+   (d) Error

**Answer:** (d) Constructor cannot call function that are out of scope. So it cannot call `main`. Throws “`main` was not declared in this scope”.
