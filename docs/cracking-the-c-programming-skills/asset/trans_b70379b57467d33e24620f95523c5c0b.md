## 17. 代码将抛出什么错误？(L4)

```cpp
#include<iostream>
using namespace std;
class base
{ public:
      static int b; };
class dev : public base
{ }D;
D.base::b = 3;
int main()
{ cout<<D.base::b; }
```

- (a) 在 'D.base::b = 3' 中的 'base' 前期望未限定标识符
- (b) 在 'D.base::b = 3' 中的 '.' 记号前期望初始化器
- (c) ISO C++ 不允许将静态 'base' 变量初始化为 'D.base::b = 3'
- (d) 以上都不是

**答案：** (b) 这不是对基类静态变量的恰当初始化。
