## 1 C 与 C++

本章将列举 C 与 C++ 之间最重要的区别。还需注意，“C”语言是自顶向下语言，而“C++”是自底向上语言。在本章结束时，你将了解从 C 语言转向 C++ 时需要谨慎处理的重要而基本的转变。

- **1.** 代码的输出是什么？(L2)

```cpp
#include<iostream.h>
void main()
{ cout<< "hello world";}
```

- (a) hello world
- (b) hello
- (c) 不可预测
- (d) 取决于编译器

**答案：** (d) 在“C++”中，“cout”是用于打印输出的函数。运算符“<<”称为提取运算符。它用于从右侧提取值，并将其输出到控制台。在“g++”中会报错。而在其他编译器和一些较旧版本中，它可能输出“hello world”。

- **2.** 这段代码将抛出什么错误？(L4)

```cpp
#include<iostream.h>
void main()
{ cout<< "hello world";}
```

- (a) 致命错误：iostream.h：没有那个文件或目录
- (b) “::main()”必须返回“int”
- (c) “cout”在此作用域中未声明
- (d) 以上全部

**答案：** (a) 致命错误会终止编译。之后不会再抛出其他错误。这是因为“g++”不支持这种编译方式。

- **3.** 这段代码将抛出什么错误？(L3)

```cpp
#include<iostream>
using namespace std;
void main()
{ cout<< "hello world";}
```

- (a) 致命错误：iostream.h：没有那个文件或目录
- (b) “::main()”必须返回“int”
- (c) “cout”在此作用域中未声明
- (d) 无错误

**答案：** (b) “using namespace std”用于处理命名冲突以及添加外部文件和定义。这在“C”中不存在。它用于在命名内存空间时防止冲突。最初，它仅用于具有多用户和共享内存的系统，但现在它已被采纳为“G++”中的强制语法。此外，在“G++”中，默认的“main”必须是“int”类型，而不是“void”。因此会报错。但也应注意，即使“main”末尾没有给出 return 语句，编译器也不会抛出任何错误或警告。

- **4.** 这段代码将抛出什么错误？(L4)

```cpp
#include<iostream>
int main()
{ std::cout<< "hello world";}
```

- (c) 不可预测
- (d) 段错误

**答案：** (b) 在“int”之前应有“;”。与“C”一样，每条语句中“;”都是必需的。

- **12.** 代码的输出是什么？(L2)

```cpp
#include<iostream>
using namespace std
int main()
{ std::cout<< "hi"; }
```

- (a) hi
- (b) 错误
- (c) 不可预测
- (d) 以上都不是

**答案：** (b) 额外的“std”并不能弥补声明中缺失的“;”。

- **13.** 代码的输出是什么？(L1)

```cpp
#include<iostream>
using namespace std;
int main()
{ int a=9;
    cout<< "hi " <<a; }
```

- (a) hi 9
- (b) hi
- (c) 错误
- (d) 以上都不是

**答案：** (a) “cout”可以同时打印不同类型的多个值。

- **14.** 代码的输出是什么？(L1)

```cpp
#include<iostream>
using namespace std;
int main()
{ cout<< "hi " <<9; }
```

- (a) hi 9
- (b) hi
- (c) 错误
- (d) 以上都不是

**答案：** (a) 这也能正常工作。

- **15.** 代码的输出是什么？(L3)

```cpp
#include<iostream>
using namespace std;
int main()
{ int a=9;
    cout<< "hi " << "%d",a; }
```

- (a) hi 9
- (b) hi
- (c) 错误
- (d) 以上都不是

**答案：** (d) “%d”被当作字符串处理。因此输出将是“hi  %d”。格式说明符的概念在 C++ 中被完全舍弃。默认的“cout”运算符可以处理任何数据类型的变量和值。

- **16.** 代码的输出是什么？(L3)

```cpp
#include<iostream>
using namespace std;
int main()
{ int a=9;
    cout<< "hi " << ("%d",a); }
```

- (a) hi %d
- (b) hi
- (c) 错误
- (d) 以上都不是

**答案：** (d) 输出将是“hi 9”。在这里，中间的“,”用“a”覆盖了“%d”。这与“C”中相同。

- **17.** 代码的输出是什么？(L2)

```cpp
#include<iostream>
using namespace std;
int main()
{ cout<< 9,8,7,6; }
```

- (a) 9
- (b) 9876
- (c) 6
- (d) 错误

**答案：** (a) 每个变量和值都需要提取运算符。这称为级联运算符。

- **18.** 代码的输出是什么？(L2)

```cpp
#include<iostream>
using namespace std;
int main()
{ int a=9;
    cout<< a++<<a++<<a++; }
```

- (a) 91011
- (b) 11109
- (c) 999
- (d) 111111

**答案：** (b) 该运算符的结合性是从右到左。

- (a) 234
- (b) 230
- (c) 不可预测
- (d) 以上都不是

**答案：** (a) 当给出不同类型的数据时，它会在内部将其转换为所需类型并保存。

- **25.** 代码的输出是什么？（假设给定的值为 2,2,3,4,34）(L3)

```cpp
#include<iostream>
using namespace std;
int main()
{ int a,b,c;
  cin>>a>>b>>c;
  cout<< a;
  cout<< b;
  cout<< c;  }
```

- (a) 234
- (b) 230
- (c) 不可预测
- (d) 以上都不是

**答案：** (d) 输出为 200。当“cin”遇到类型不匹配时，它会停止读取该值。

- **26.** 代码的输出是什么？（假设给定的值为 2,2,3,4,34）(L3)

```cpp
#include<iostream>
using namespace std;
int main()
{ int a,b,c;

     cout<< b;
```

**答案：** (a) 这也以相同方式工作。当一个“cin”失败时，所有其他“cin”都会被跳过。

- **27.** 代码的输出是什么？（假设给定的值为 2,2,3,4,34）(L3)

- **28.** 代码的输出是什么？（假设给定的值为 2,2,3,4,34）(L4)

```cpp
#include<iostream>
using namespace std;
int main()
{ int a,b,c;
  cin>>int(a);
  cin>>b;
  cin>>int(c);
      cout<< a;
      cout<< b;
      cout<< c;  }
```

- (a) 200
- (b) 234
- (c) 不可预测
- (d) 以上都不是

**答案：** (d) 这会报错。“‘operator>>’的重载有歧义”。它会给出关于该运算符内部定义及其可能重载的长篇描述。重载是面向对象编程的一个概念，意味着根据用法为运算符提供多个定义。
