12. What is the output of the code? (L3)

```
```cpp
#include<iostream>
using namespace std;
class base
{ public:
    static int b; };
class dev : public base
{ };
int dev::b = 3;
int main()
{ cout<<dev::b; }
```
```

(a) 3        (b) 0
(c) Unpredictable    (d) Error

Answer: (d) 'static' variables will not be inherited as 'static'.

{ };

```
```
