## 第一章：编程导论

在开始学习特定语言之前，你应该对编程有一个良好的理解。编程的绝对基础是必不可少的。这将有助于你更好地理解任何语言的基础。

### 二进制数字

计算机和几乎所有基于计算机的设备在运行时都使用二进制系统。该系统只包含两个数字：`1` 和 `0`。每一个数字被称为一个位（bit）。所有的计算机程序都可以简化为这个系统。事实上，二进制系统在计算机存储各种信息和数据方面起着关键作用。

在基础层面上，计算机的所有功能简单地在 `1` 和 `0` 之间切换，无论简单还是复杂。任何数据（包括文本和图像）都以一系列 `1` 和 `0` 的形式存储在计算机中。你看，计算机是电路。在电路中，电流要么流动要么不流动。因此，状态可以被定义为 `1` 或 `0`。换句话说，这是一个二进制状态。

一旦你理解了这个概念，你就会意识到为什么二进制系统对计算机如此基础。在所有的计算机程序和情况下，问题总是可以简化为一个二选择。因此，所有的计算机都使用二进制系统处理信息。

### 什么是程序？

让我们先分析计算机的功能。它的首要功能是解决问题。现在，它是如何解决问题的呢？通过程序的帮助来实现。计算机程序是指令序列，当它们被计算机执行时会执行特定的任务。

无论计算机是什么，如果没有程序，它将完全毫无用处。如果你在基于计算机的设备上阅读这些内容，那是因为它有一组程序允许它这样做。

### 什么是编程语言？

顾其名，编程语言是一种用于编程的特殊语言。遗憾的是，机器码对于人类来说极其难以理解。除其他因素外，机器码几乎用二进制系统表示。此外，机器码是特定架构所有的。

因此，我们需要某种与计算机通信的方法。这就是编程语言存在的原因。它们是人与计算机之间的接口。通过它们，程序可以用人们易于理解的语言表达。同时，这种语言在不同架构之间是通用的。更重要的是，程序可以被翻译成机器码。

为了确保这种情况发生，计算机必须解释或编译用编程语言编写的程序，以便执行程序。对于编译型程序，必须使用编译器，以便程序可以翻译成计算机使用的机器码。然而，在解释型程序的情况下，计算机不会直接运行源代码。相反，解释器会在程序运行时读取程序的每一行并将其修改为机器码。修改后，计算机就会执行该行。

这些方法都有其自身的优点。通常，编译型程序的开发时间可能更长，但运行速度更快。毕竟，计算机执行的是已经翻译过的程序。解释型程序运行速度较慢，因为它们每次执行时都需要翻译。但它们编写起来可能更快，因为语言通常更简单。同时，在每次修改或错误测试后，不需要重新编译整个程序。

学习编程时，你必须准备好投入大量的时间。

另一方面，你需要确保你的程序能够在时间内被理解、改进和修复。

- 在开始编写程序之前，查看一下与你想创建的程序类似的程序。理解这些程序并找出它们的优缺点。你应该思考可以改进程序的方法。
- 在开始编写程序之前，你需要计划你希望你的程序具备的功能。你可以预先为程序的功能和特性创建一个流程图。
- 如果可能，尝试寻找一些与你的程序类似的优质源代码。确保代码的质量。
- 在编写程序时，你需要在最大化功能的同时降低复杂性。这是你创建一个真正有效程序的方法。
- 你应该这样开发程序，使得仅仅通过查看源代码就能理解正在发生什么。
- 每当你尝试程序的复杂部分时，都应该添加注释。从长远来看，这对你有帮助。
- 定义变量时，你必须使用易于理解且简单的名称。这有助于你跟踪它们以及它们将被使用的函数。

你现在应该对编程是什么样的大有体会。现在，是时候选择你应该尝试哪种编程语言了。

## 第 2 章：用 C 和 C++ 回归传统

C 和 C++ 作为编程语言都拥有悠久的历史。C 开发于 20 世纪 70 年代初，它不断发展；而 C++ 则出现在后来的 20 世纪 80 年代。

你需要记住，这两种语言在计算机编程的早期就已经存在了。因此，它们被认为是世界上最基础的编程语言之一。因此，即使你以后不使用它们，学习它们也将让你受益匪浅。事实上，学习它们就像获得了对计算机编程初期的无价洞见。

每种语言显然有其优缺点。尽管如此，你将对通用编程有更深入的理解。事实上，你可能会发现学习其他编程语言（如 Java）会变得更容易。毕竟，C 和 C++ 的特性已经为许多语言提供了灵感。

当然，在 C 和 C++ 之间存在一个选择的问题。现在，C 是两者中较老的，而 C++ 被认为是较早语言的子集。许多程序员也认为 C++ 是两者中更容易学习的。另一方面，如果你希望成为一名专业程序员，C 的知识被证明是有帮助的。尽管如此，在学习 C++ 之后再学习 C 或反之亦然也是可能的。

### C 的设计

C 是一种过程化编程语言，它的设计初衷是可以使用相对简单的编译器进行编译。它的设计还提供了可以高效映射到机器指令的语言结构。它所需的运行时支持也是最小的。这些特性使得 C 能够应用于各种程序，而这些应用以前必须用汇编语言编写。

尽管 C 具有低级处理能力，但这种编程语言旨在鼓励跨平台级别的编程。只要程序写得具有移植性且符合标准，就可以为各种操作系统和计算机平台编译 C 程序。

### C 语言中的一个简单程序

为了说明 C 编程语言，有一个示例可以参考将非常有帮助。这里有一个用这种语言编写的简单“Hello World!”程序。

```c
#include <stdio.h>

int main ()
{
    printf("Hello world\n");
    return 0;
}
```

为了更好地理解程序中发生了什么，最好将其拆分为不同的部分并逐一处理。

#### #include <stdio.h>

这段代码告诉我们要包含名为 `stdio.h` 的文件，它代表标准输入/输出头文件。有了它，可以在程序中使用特定的命令进行输入或输出。在这个示例中，它允许我们输出消息并将其打印在屏幕上。

#### int main ()

`int` 被称为返回值，在这个例子中它是整数类型。接下来的部分是 `main()`，它是主函数。C 中的每个程序都必须有且主函数，它也是所有程序的起点。

#### printf("Hello World\n");

当需要在屏幕上打印内容时，使用 `printf` 命令，在这个程序中内容是“Hello World”。要打印的数据必须放在括号内。在这种情况下，“Hello World”被放在双引号内，因为它是一个字符串，而字符串必须放在双引号内。命令的最后部分是 `\n`，它被称为转义序列。`\n` 代表换行符，它允许下一次输出在下一行打印。在 C 编程过程中将学到其他类型的转义序列。

#### return 0;

在程序的第二行，写了 `int main ()` 表示主函数必须返回一个整数。通过使用 `return 0` 命令，空值将返回给操作系统。通过返回 `0`，你只是在告诉操作系统运行程序时没有发生错误。

根据这个示例，关于这种语言的编程，你应该了解以下几点。

- 所有编写的程序都应该有一个主函数。
- 程序的执行总是从主函数开始。

## 第 3 章：享受 Java 的多功能

Java 是世界上最有影响力的编程语言之一。它在计算领域仍然保持着流行和无处不在。你可以发现 Java 被应用于各种平台，从 Web 到操作系统，甚至是设备。你会发现 Java 充满了各种特性。作为一种编程语言，它是基于类且面向对象的。它的设计初衷是具有可移植性的，因此你可以在各种平台上对其进行开发。这就是为什么在在最初发布二十年后，它在世界范围内依然如此广受欢迎。

另一方面，Java 有时可能难以理解，并且难以高效、有效地进行编程。然而，它的流行性意味着作为一名程序员，你不缺乏资源来帮助你理解，也不会缺乏探索的途径。学习 Java 的另一个益处是，它迫使你进行分析性和逻辑性的思考。换句话说，你将开始像程序员一样思考。你也可以很好地理解计算机如何处理信息。你在 Java 中学的核心概念和基础，在你开始学习其他编程语言时将证明自己是有用的。

### Java 的特性

Java 最初由 Sun Microsystems 公司于 1991 年开发。现在，它由 Oracle 公司维护，Oracle 在 2009 年收购了 Sun Microsystems。它的流行依赖于其卓越的特性。

- **平台无关性**：与某些其他编程语言不同，Java 是平台无关的。因此，无论你在什么平台上编译它们，你都可以在所有平台上运行 Java 程序。
- **面向对象**：虽然 Java 是一种面向对象的编程语言，但它缺乏一些复杂的特性，如多重继承、运算符重载和显式内存分配。因此，它是一门易学习的语言。
- **强语言**：处理不当的错误和内存管理是导致程序失败的两个主要问题。在 Java 中，这些问题可以得到高效处理。异常处理程序可以解决处理不当的错误，而垃圾回收可以处理内存管理错误。
- **安全性**：编写 Java 程序时，所有代码都将限制在 Java 运行环境中。因此，不会授予对系统资源的未经授权访问。
- **多线程**：由于对多线程的支持，Java 允许你的程序同时执行不同的任务。

### Java 中的一个简单程序

为了更好地了解 Java 是什么样的，下面的示例将会有帮助。

这是 "Hello World" 程序，这是一个经常用于说明编程语言基础的简单程序。你已经在 C 和 C++ 的章节中遇到过这样的示例。

```java
public class Main {
    public static void main (String [] args) {
        System.out.println("Hello, World!");
    }
}
```

现在，让我们检查程序的每个部分，以理解函数和关键字是什么以及它们的作用。

#### Public class Main

这是程序的第一行，它定义了一个名为 `Main` 的类。如果你想让一行代码在 Java 程序中运行，你必须将其放在类内部。在这里声明了 `Main` 类。它被定义为 `public`。因此，其他类可以访问它。你还应该记住，`public` 类必须声明在一个具有同名的文件中。在这种情况下，文件名应该是 `Main.java`。如果你不这样做，将在编译期间得到错误。

#### Public static void main (String [] args) {

这是 Java 程序的起点。`main` 方法必须具有精确的签名，程序才能运行。这里有几个你需要查看的关键字。你已经熟悉了 `public`，其他的将在稍后讨论。当然，`Main` 是方法名。

#### System.out.println("Hello, World!");

`System` 是 Java 中的一个预定义类，它包含了一些在编程时非常有用的变量和方法。下一个关键字是 `out`，它是 `System` 的一个静态变量。它代表程序的输出。`println` 是在 `out` 内部的方法，用于打印一行。

### Java 中的数据类型和变量

在 Java 中，有三种变量和多种数据类型。当你想要用这种语言编写程序时，理解它们至关重要。

#### 数据类型

Java 中有两种数据类型：基本类型和非基本类型。基本数据类型是 Java 预定义并提供的。Java 中这些类型的示例包括 `boolean`、`char`、`int`、`long`、`short` 和 `float`。另一方面，非基本数据类型不是 Java 定义的。相反，它们将由你，程序员创建。它们引用内存位置，因此它们有时被称为引用变量。`String` 和数组是一些非基本数据类型。

#### 变量

在 Java 中，你有三种可以用于程序的变量类型。类型取决于你如何声明变量。局部变量是在方法内部声明的变量。另一方面，实例变量定义在方法之外但类之内。静态变量简单来说就是用 `static` 关键字声明的变量，它们不能是局部变量。当你开始认真学习 Java 编程时，将学到这些用法。

与其他编程语言一样，你需要在使用变量之前声明它。Java 中声明变量的基本语法如下：

`数据类型 变量 [= 值];`

你可以在一个语句中声明多个相同数据类型的变量。你只需要用逗号将它们分隔。

在 Java 中，声明变量时需要小心，因为那里有相应的规则。变量名是区分大小写的。因此，‘Hi’和‘hi’被认为是不同的。

### 循环和条件语句

在程序中，语句和代码行是按顺序执行的。然而，可以通过创建复杂的执行路径来实现某些程序。这是通过条件语句和循环等不同的控制结构实现的。

循环语句用于一段代码需要执行多次的情况。Java 中提供了不同类型的循环语句。列举如下：

- **While 循环**：只要给定条件为真，它就会重复一组语句。一旦条件变为假，循环将不再执行。在执行循环之前测试条件。
- **Do-While 循环**：这种循环的工作方式与 while 循环相似。然而，它在执行代码后检查条件。
- **For 循环**：在这里，代码块将执行固定的次数。它允许缩短管理循环变量的代码。

#### 条件语句

这些实际上是伴随一个或多个条件的结构。这些条件由程序评估，并根据评估结果执行语句。如果条件为真，将执行特定的语句或一组语句。如果为假，将执行另一组语句。换句话说，这些结构允许程序做出决策。Java 提供了几种类型的条件结构。

- **If 语句**：它包含一个布尔表达式以及在条件为真时执行的语句。
- **If else 语句**：这是配合 else 语句一起使用的普通 if 语句。如果条件为假，将执行 else 语句列出的语句。if 语句下的代码在返回真时执行。
- **嵌套 if 语句**：这是 if 语句的一种特殊用法。可以将 if 语句嵌套彼此内部。它也适用于 if 语句。
- **Switch 语句**：该语句用于测试变量与指定值列表的相等性。每个值将对应一个当变量值与之匹配时执行的语句或代码块。

这些是在学习如何使用 Java 语言开发程序时应该熟悉的某些知识。正如之前提到的，Java 是进入编程世界的绝佳跳板。一旦学会，你会发现学习其他语言会变得容易。

## 第 4 章：使用 JavaScript 构建 Web

首先，你不应该将 JavaScript 与 Java 混淆。它们是完全独立的编程语言，彼此之间没有任何联系。它最初开发于 90 年代。JavaScript 是当今 Web 开发中必不可少的技术之一。然而，这种编程语言也用于网络浏览器之外的地方，作为连接的服务应用程序。

作为一种编程语言，JavaScript 是动态的。因此，你可以灵活地利用面向对象的编程方法或命令式和函数式方法，尽管该语言主要是面向对象的。如果你已经熟悉 C 语言，你会发现 JavaScript 更容易，因为大部分语法都源自这种早期的语言。事实上，学习这种语言非常容易。同时，JavaScript 的知识可以让你学习 Java 和 C 变得更加容易。

此外，它现在非常流行。如果你计划成为一名专业代码人员或为互联网构建内容，JavaScript 是入门的最好语言之一。通过学习这种语言，你能够快速开始构建 Web 程序。

### JavaScript 的特性

JavaScript 能够为网页添加各种精美的效果等。当你学习这种编程语言时，了解它的特性是什么是有帮助的。以下是一些最重要的特性。

#### 浏览器支持

JavaScript 已被所有浏览器接受为标准脚本语言。因此，与 Flash 不同，你不需要安装任何插件即可在浏览器中使用 JavaScript。更重要的是，浏览器对这种语言提供了集成的支持。

#### 客户端与服务器端的结合

JavaScript 可以访问浏览器的文档对象模型（DOM）。因此，可以在运行时修改网页的结构。因此，你可以使用这种语言为网页添加各种效果。同时，也可以在服务器端使用它。其中之一就是创建 Web 脚本。

#### 脚本与 JavaScript 编程

JavaScript 经常被称为脚本语言，因为事实确实如此。它本身并不确切是某种意义上的编程语言。毕竟，浏览器在程序中执行了大量工作。由于浏览器执行了实际工作，可以通过编写几行代码来更改内容，这相对容易。这就是为什么 JavaScript 被认为是一种初学者的简单语言。

尽管如此，这种语言也有一些复杂的方面。尽管被用作脚本语言，但 JavaScript 是一门完善的编程语言。你可以用它创建复杂的程序。当然，当你创建网页时，很少需要这样做。

### 在 JavaScript 中编写一个简单的程序

为了更好地了解 JavaScript 这种语言，你应该开始编写你的第一个程序。在这种情况下，也将使用经典的“Hello World”示例。好的一点是，用 JavaScript 编写这个程序非常简单。

在开始之前，你需要满足一些基本要求。JavaScript 的一个优点是它可以很容易被浏览器本身解释。因此，你不需要任何额外的软件或编译器来用这种语言编写程序。你只需要下面提供的内容。

- **文本编辑器**：你可以使用记事本编写程序。但是，你应该考虑使用 Notepad++，它对程序员来说是一个无价的文本编辑器。你可以免费获取此应用程序。

## Ruby 编程中的语法

在任何编程语言中，你都需要注意代码的语法。不正确的语法可能会在运行时导致错误，甚至破坏程序并产生与预期不符的结果。在 Ruby 中，语法概念非常简单且易于理解。以下是在使用这种语言进行编程时需要了解的一些语法概念。

### 空格符

在 Ruby 中，制表符和空格等空白字符通常会被程序忽略。然而，当这些字符出现在字符串中时，它们将会在考虑在内。尽管如此，在某些情况下，空格被用于解释歧义的语句。如果启用了 `-w` 选项，这些解释可能会产生警告。

### 换行符

在 Ruby 中，换行符和分号被视为语句的结束。然而，如果将反斜杠 `\` 和 `+` 等运算符放在行尾，Ruby 将其视为语句将继续执行的标识。

### 标识符

标识符是赋予方法、常量和变量的名字。在 Ruby 中，标识符始终区分大小写。因此，'Hi'、'HI' 和 'hi' 在 Ruby 中会被视为不同的标识符。另一方面，你可以在创建标识符时使用字母、数字以及下划线字符。

### Ruby 中的 BEGIN 和 END 语句

这是 Ruby 中两个重要的语句。在使用这种语言进行编程时，你一定会遇到需要使用这些语句的情况。

### BEGIN 语句

该语句允许在实际程序执行之前声明其方的代码。因此，BEGIN 语句中的代码将首先被执行。你可以使用多个 BEGIN 语句，它们将按照它们在程序中出现的顺序被执行。该语句的基本语法如下：

```ruby
BEGIN {
#code
}
```

### END 语句

这与 BEGIN 语句相反，因为它所声明的代码将在程序结束时执行。该语句的语法如下：

```ruby
END {
#code
}
```

### Ruby 中的变量

Ruby 中有四种不同的变量。理解它们对编程至关重要。以下是对这些变量的简要介绍。

**实例变量（Instance Variables）：** 这些变量对于特定对象或实例的不同方法是可用的。因此，实例变量对于不同的对象是不同的。如果未初始化，实例变量的值为 `nil`，并且在启用了 `-w` 选项时会导致警告。

**局部变量（Local Variables）：** 这些变量的作用范围从代码块的开始到结束。换句话说，它们存在于大括号之间。它们在方法外部不可用。如果你引用了一个未初始化的局部变量，Ruby 将认为它是对一个无参数方法的调用。可以通过给未初始化的局部变量赋值来声明局部变量。所有的局部变量必须以下划线或小写字母开头。

**全局变量（Global Variables）：** 当你需要一个可以存在于所有类的变量时，就会使用它们。通过给全局变量赋值，你可以更改全局状态。因此，除非绝对必要，否则不建议使用它们。它们可能会使程序复杂。未初始化的全局变量的值为 `nil`。带有 `-w` 选项，它们会导致警告。所有全局变量都需要以 `$` 字符开头。

### Ruby 中的条件结构

Ruby 中提供了许多条件结构，其中大多数与其他编程语言是通用的。因此，如果你熟悉其他语言，学习它们不会遇到问题。即使你不熟悉，对你来说学习并不困难。

- **If 语句**：该语句用于在条件被确定为真时执行代码块。当条件返回假时，将跳过代码的执行。

- **Else 语句**：Else 语句与 if 语句配合使用。它在条件评估为假时提供一个备用的执行代码块。

- **Elsif 语句**：Elsif 语句与 if 和 else 语句配合使用，并放在两者之间。根据需要添加任意数量的 elsif 语句。当你需要检查多个条件时使用此语句。对于返回 true 的条件，其对应的代码块将被执行。

- **Unless 语句**：unless 语句是 if 语句的相反。当你想在条件返回假时执行代码块时使用。

- **Case when 语句**：当你需要评估许多选项时，使用 if-elsif-else 条件结构可能会变得非常复杂。在这种情况下，你可以应用 case when 语句。当条件返回正确的值时，将执行 when 语句下的代码。一个 case 语句可以应用于多个语句。在这个条件结构中，也可以使用 else 语句。当条件没有返回任何 when 语句接受的值时，else 语句将提供一个待执行的代码块。

### Ruby 中的循环语句

Ruby 也提供了循环。正如你所知道的，循环允许你多次执行某个代码块。以下是对 Ruby 中可用循环的简要介绍。

- **While 循环**：while 循环允许只要条件为真就执行代码。一旦它变为假，执行就会停止，程序跳转到下一个语句。

- **Until 循环**：这是 while 循环的相反。只要条件为假，until 循环就会一直执行。当条件变为真时，它将停止。

- **For 循环**：虽然 Ruby 提供了 for 循环，但它与其他语言中的 for 循环不同。相反，Ruby 中的 for 循环更像其他语言中的 for 循环。结果是，只要表达式中有待考虑元素，它就会执行代码。
