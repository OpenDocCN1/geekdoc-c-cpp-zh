# 29.8 Converting from a Pre-Test Loop Structure to a Counted Loop Structure

In PHP, the conversion from a pre-test loop structure to a counted loop structure can be done very easily for any form of the while statement. However, you will need to be aware that in computer programming languages other than PHP, such as Visual Basic, Pascal, and Delphi (to name a few) you can do this type of conversion, but only under certain circumstances. Throughout the rest of this chapter, you will encounter situations in which conversion should not always be carried out.

Following is the general form of the pre-test loop structure, in which conversion can actually be carried out in the majority of the programming languages.
