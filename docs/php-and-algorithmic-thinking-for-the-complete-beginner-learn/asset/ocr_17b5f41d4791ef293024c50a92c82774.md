# Solution

The PHP script is as follows.

```
```php
<?php
    $p = 1;

    $a = trim(fgets(STDIN));
    do {
        $p = $p * $a;
        $a = trim(fgets(STDIN));
    } while ($a != -1);

    echo $p;
?>
```
```

Now let’s create a trace table to determine if the script operates properly.

| Step | Statement | Notes | $a | $p |
|---:|---|---|---:|---:|
| 1 | `$p = 1` |  | ? | **1** |
| 2 | `$a = trim(fgets(STDIN))` |  | **2** | 1 |
| 3 | `$p = $p * $a` |  | 2 | **2** |
| 4 | `$a = trim(fgets(STDIN))` |  | **4** | 2 |
| 5 | `while ($a != -1)` | This evaluates to true |  |  |
| 6 | `$p = $p * $a` |  | 4 | **8** |
| 7 | `$a = trim(fgets(STDIN))` |  | **5** | 8 |
| 8 | `while ($a != -1)` | This evaluates to true |  |  |
| 9 | `$p = $p * $a` |  | 5 | **40** |
| 10 | `$a = trim(fgets(STDIN))` |  | **-1** | 40 |
| 11 | `while ($a != -1)` | This evaluates to false |  |  |
| 12 | `echo $p` | The value 40 is displayed |  |  |

As you can see, in the end, variable $p contains the value 40, which is, indeed, the product of the values 2 × 4 × 5. Moreover, the final given value -1 does not participate in the final sum.
