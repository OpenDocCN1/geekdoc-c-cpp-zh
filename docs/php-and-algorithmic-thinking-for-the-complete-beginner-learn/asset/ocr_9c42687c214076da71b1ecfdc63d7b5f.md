# 9.1 Creating a New PHP Project

So far, you have learned some really good basics about PHP scripts. Now it’s time to learn how to enter scripts into the computer, execute them, see how they perform, and see how they display the results.

The first thing you must do is create a new PHP project. The NetBeans IDE provides a wizard to help you do that. Start the NetBeans IDE, and from its main menu select “File→New Project...” as shown in **Figure 9–1**.

![](bbox=[0.044, 0.223, 0.965, 0.489])

**Figure 9–1** Starting a new PHP project from NetBeans IDE

> **Notice:** A PHP project can contain many PHP scripts.

The “New Project” wizard will appear, and it will guide you through the steps that follow.

+   1. On the “New Project” screen of the wizard, under “Choose Project,” select “PHP Application” as shown in **Figure 9–2**. Then, click on the “Next” button.
