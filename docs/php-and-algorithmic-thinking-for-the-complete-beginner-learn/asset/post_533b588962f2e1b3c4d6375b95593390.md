# Solution

This exercise is quite simple. A post-test loop structure is nested within a pre-test loop structure (or in a counted loop structure, if you prefer). The only obstacle you must overcome is that the true and false paths of the inner post-test loop structure are not quite in the right positions since the true path, and not the false path, must go upwards. As you have already learned, it is possible to switch the two paths, but you also need to negate the corresponding Boolean expression. The code fragment is as follows.

```php
for ($i = 0; $i <= CITIES - 1; $i++) {
    do {
        $b[$i] = trim(fgets(STDIN));
    } while ($b[$i] >= 0);
}
```

In this exercise, a dual-alternative decision structure is nested within a post-test loop structure. The corresponding PHP script is as follows.

```php
<?php
$i = 1;
$m = 0;
$n = 0;
$pos = array();
$neg = array();
do {
    $b = trim(fgets(STDIN));
    if ($b < 0) {
        $pos[$m] = $b;
        $m++;
    } else {
        $neg[$n] = $b;
        $n++;
    }
    $i++;
} while ($i < 90);
echo "The End";
?>
```

# Exercise 37.1-2 Creating an Array with the Greatest Values

Design a flowchart and write the corresponding PHP script that lets the user enter numerical values into arrays $a and $b of 20 elements each. Then the algorithm, and consequently the script, should create a new array $new of 20 elements. The new array should contain in each position the greatest value of arrays $a and $b of the corresponding position.

# Solution

Nothing new here! You need four counted loop structures: two counted loop structures to read the values for arrays $a and $b, one for creating the array $new, and one to display array $new on the screen. The flowchart is presented next.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_670_0.png)

![](img/4d9a992abc5da7946ac44f9e6bf1d032_671_0.png)

The corresponding PHP script is shown here.

# file_37.1-2.php

```php
<?php
define("ELEMENTS", 20);

//Read arrays $a and $b
$a = array();
for ($i = 0; $i <= ELEMENTS - 1; $i++) {
    $a[$i] = trim(fgets(STDIN));
}
$b = array();
for ($i = 0; $i <= ELEMENTS - 1; $i++) {
    $b[$i] = trim(fgets(STDIN));
}
//Create array $new
$new = array();
for ($i = 0; $i <= ELEMENTS - 1; $i++) {
    if ($a[$i] > $b[$i]) {
        $new[$i] = $a[$i];
    } else {
        $new[$i] = $b[$i];
    }
}
//Display array $new
for ($i = 0; $i <= ELEMENTS - 1; $i++) {
    echo $new[$i], "\n";
}
?>
```

# Exercise 37.1-3 Merging One-Dimensional Arrays

Write a PHP script that lets the user enter numerical values into arrays $a and $b of 20 and 30 elements correspondingly. Then, the script should create a new array $new of 50 elements. This new array should contain in the first 20 positions the elements of array $a, and in the next 30 positions the elements of array $b.

# Solution

As you can see in the example presented next, there is a one-to-one match between the index positions of the elements of array $a and those of array $new. The element from position 0 of array $a is stored in position 0 of array $new, the element from position 1 of array $a is stored in position 1 of array $new, and so on. However, there is no one-to-one match between the index positions of the elements of array $b and those of array $new. The element from position 0 of array $a should be stored in position 20 of array $new, the element from position 1 of array $a should be stored in position 21 of array $new, and so on.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_673_0.png)

In order to assign the values of array `$a` to array `$new` you can use the following code fragment.

```php
for ($i = 0; $i <= ELEMENTS_OF_A - 1; $i++) {
    $new[$i] = $a[$i];
}
```

However, to assign the values of array `$b` to array `$new` your code fragment should be quite different.

```php
for ($i = 0; $i <= ELEMENTS_OF_B - 1; $i++) {
    $new[ELEMENTS_OF_A + $i] = $a[$i];
}
```

The final PHP script is as follows.

```php
// file_37.1-3.php
<?php
define("ELEMENTS_OF_A", 20);
define("ELEMENTS_OF_B", 30);
define("ELEMENTS_OF_NEW", ELEMENTS_OF_A + ELEMENTS_OF_B);

//Read arrays $a and $b
$a = array();
for ($i = 0; $i <= ELEMENTS_OF_A - 1; $i++) {
    $a[$i] = trim(fgets(STDIN));
}
$b = array();
for ($i = 0; $i <= ELEMENTS_OF_B - 1; $i++) {
    $b[$i] = trim(fgets(STDIN));
}

//Create array $new
$new = array();
for ($i = 0; $i <= ELEMENTS_OF_A - 1; $i++) {
    $new[$i] = $a[$i];
}
```
