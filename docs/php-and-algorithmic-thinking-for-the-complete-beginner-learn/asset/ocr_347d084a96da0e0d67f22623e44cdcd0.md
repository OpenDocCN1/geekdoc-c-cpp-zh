This PHP script works fine, but assume that the user enters a very large sentence that is not a palindrome. Let's say, for example, that the second letter is not the same as the last but one. Unfortunately, in this script the counted loop structure continues to iterate until the middle of the sentence despite the fact that variable $palindrome has been set to false, even from the second iteration. So, let's try to make this script even better.

What you need here is a way to break out of the loop when something goes wrong. There are two approaches, actually.

# First Approach – Using the break statement

The first approach uses the break statement. In the initial PHP script, the statements marked with a dashed rectangle can be replaced with the following code fragment.

```
$palindrome = true;
for ($i = 0; $i <= $middle_pos; $i++) {
    if ($message_clean[$i] != $message_clean[$j]) {
        $palindrome = false;
        break;
    }
    $j--;
}
```
