```
```php
$values[5] = 7;

11. The following code fragment adds the name “Sally” to index position 3.

```
```php
$names = array();
$names[] = "John";
$names[] = "George";
$names[] = "Sally";
```
```

12. The following statement adds the name “Sally” to index position 2.

```
```php
$names = array("John", "George", "Sally");
```
```

13. The following code fragment displays the name “Sally” on the screen.

```
```php
$names = array();
$k = 0;
$names[$k] = "John";
$k++;
$names[$k] = "George";
$k++;
$names[$k] = "Sally";
$k--;
echo $names[$k];
```
```

14. The following code fragment is syntactically correct.

```
```php
$names = array();
$names[] = "John";
$names[] = "George";
$names[] = "Sally";
echo $names[];
```
```

15. The following code fragment displays the name “Maria” on the screen.

```
```php
$names = array("John", "George", "Sally", "Maria");
echo $names[intval(pi())];
```
```

16. The following code fragment satisfies the property of definiteness.

```
```php
$grades = array("B+", "A+", "A", "C-");
