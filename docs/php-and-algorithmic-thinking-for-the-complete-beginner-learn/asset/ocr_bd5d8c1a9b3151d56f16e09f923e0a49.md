+   - **where**
+     - `counter` must always be a variable.
+     - `initial value`, `final value1`, `final value2` and `offset` can be a constant value or even a variable or an expression. In case of a variable or an expression, however, the content or the result correspondingly must be invariable inside the loop.
+     - `OP1` must be `<=` when `counter` increments and `>=` when `counter` decrements.
+     - `OP2` must be `+` when `counter` increments and `-` when `counter` decrements.
+     - `OP3` can be any comparison operator (`<`, `>`, `<=`, `>=`, `==`, `!=`).
+     - Inside statement or block of statements 2 (those being inside the loop), any existing `counter` variable must be replaced by the expression `counter OP2 offset`.
