To further help you, there is also a general purpose PHP script that can be used to split any given integer. Since the length of your script depends on the number of digits, N, all you have to do is write N−1 pairs of statements.

```
```php
<?php
    echo "Enter an N-digit integer: ";
    $number = trim(fgets(STDIN));

    $digit1 = intval($number / 10^(N-1));
    $r = $number % 10^(N-1);

    $digit2 = intval($r / 10^(N-2));
    $r = $r % 10^(N-2);

    .
    .
    .

    $digit(N-2) = intval($r / 100);
    $r = $r % 100;

    $digit(N-1) = intval($r / 10);
    $digitN = $r % 10;
```
