# Solution

In this exercise you need to write a procedure that accepts a value from the caller (this is the main code) and then calculates and displays its absolute value. The solution is shown here.

```
```php
<?php

function display_abs($n) {
    if ($n < 0) {
        $n = (-1) * $n;
    }

    echo $n;
}

$a = trim(fgets(STDIN));
display_abs($a);       //This displays the absolute value of given number.
echo $a;              //This displays the initial number given.
?>
```
