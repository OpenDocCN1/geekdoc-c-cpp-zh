Now, it’s easy to write the corresponding PHP script.

```
```php
<?php
    $i = 1;
    $S = 0;

    $a = trim(fgets(STDIN));
    $i++;

    while ($i < 90) {
        $S = $S + $a * $i;

        $a = trim(fgets(STDIN));
        $i++;
    }
    echo $S;
?>
