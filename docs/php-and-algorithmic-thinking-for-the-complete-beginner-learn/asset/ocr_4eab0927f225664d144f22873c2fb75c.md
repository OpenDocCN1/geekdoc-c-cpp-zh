# Exercise 31.1-9    *Finding the Sum of Integers*

Write a PHP script that prompts the user to enter integer values repeatedly until a real one is entered. At the end, the script should display the total number of positive integers entered.

# *Solution*

Once again, you don’t know the exact number of iterations, so you cannot use a counted loop structure.

According to the “Ultimate” rule, the pre-test loop structure should always be as follows, given in general form.

```
```php
$x = trim(fgets(STDIN));              //Initialization of $x
while ( intval($x) == $x) {
    A statement or block of statements
    $x = trim(fgets(STDIN));          //Update/alteration of $x
}
```
```

> **Notice:** In this case, using a pre-test loop structure rather than a post-test loop structure is a better option. Why? Because if the first number given is real, the pre-test loop structure ensures that the flow of execution never enters the loop!

The final PHP script is as follows.

```
```php
<?php
    $count = 0;

    echo "Enter a number: ";
    $x = trim(fgets(STDIN));
    while (intval($x) == $x) {
        if ($x > 0) {
            $count++;
        }
        echo "Enter a number: ";
        $x = trim(fgets(STDIN));
    }

    echo $count;
?>
```
