```
# ## Second approach – Finding the absolute value using a user-defined procedure.

If you want to use a procedure, things become complicated. Since procedures return no values, you must pass an argument by reference, giving the procedure the ability to return the result indirectly. But there is one little problem! As already stated, only variables can be passed by reference.

One solution that overcomes this problem is to use auxiliary variables, as shown here.

# ### file_41.3-2b.php

```
```php
<?php
function my_abs(&$n) {
    if ($n < 0) {
        $n = (-1) * $n;
    }
}

$x = trim(fgets(STDIN));

my_abs($aux1);
$aux2 = $x + 9;
my_abs($aux2);
$y = $aux1 / 9 + $aux2 / 8;
echo $y;
?>
```
