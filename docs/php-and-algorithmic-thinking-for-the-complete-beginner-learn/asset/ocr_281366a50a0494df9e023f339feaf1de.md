# # Exercise 31.6-3 Just a Poll

A public opinion polling company asks 1000 citizens if they eat breakfast in the morning. Write a PHP script that prompts the citizens to enter their sex (M for Male, F for Female) and their answer to the question (Y for Yes, N for No, S for Sometimes), and then calculates and displays the number of citizens that gave “Yes” as an answer, as well as the percentage of women among the citizens that gave “No” as an answer. Moreover, the script should validate data input and accept only values M or F for sex and Y, N, or S for answer.

# # Solution

The PHP script is as follows.

```
```php
<?php
define("CITIZENS", 1000);

$total_yes = 0;
$female_no = 0;
for ($i = 1; $i <= CITIZENS; $i++) {
    do {
        echo "Enter Sex: ";
        $sex = trim(fgets(STDIN));
        $sex = strtolower($sex);
    } while ($sex != "m" && $sex != "f");

    do {
        echo "Do you eat breakfast in the morning? ";
        $answer = trim(fgets(STDIN));
        $answer = strtolower($answer);
    } while ($answer != "y" && $answer != "n" && $answer != "s");

    if ($answer == "y") {
        $total_yes++;
    }

    if ($sex == "f" && $answer == "n") {
        $female_no++;
    }
}
echo $total_yes, " ", $female_no * 100 / CITIZENS;
?>
