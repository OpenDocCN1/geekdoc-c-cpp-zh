
## Post-Test Loop Structure

```php
if (Boolean_Expression) {
    do {
        A statement or block of statements
    } while (Boolean_Expression);
}
```

## Exercise 29.10-1 Converting the PHP Script

Rewrite the following PHP script using the post-test loop structure.

```php
<?php
$a = trim(fgets(STDIN));
$b = trim(fgets(STDIN));

    $a *= 2;
    $b = $b * 3;
}
```

## Solution

Following the conversion rule, the PHP script using the post-test loop structure becomes

```php
<?php
$a = trim(fgets(STDIN));
$b = trim(fgets(STDIN));

if ($b <= $a) {
    do {
        $a *= 2;
        $b = $b * 3;
    } while ($b <= $a);
}

echo $a, $b;
?>
```

```php
$x = $x * 2;
$y = $y + 1;
}
echo $x;
?>
```

## Solution

Following the conversion rule, the PHP script using the post-test loop structure becomes

```php
<?php
$x = 0;
$y = 1;
if ($y < 10) {
    do {
        $x = $x * 2;
        $y = $y + 1;
    } while ($y < 10);
}
echo $x;
?>
```

As you can see, variable $y does not depend on user input (it is assigned the constant value 1). This means that, whenever this script is executed, the Boolean expression ($y < 10) definitely evaluates to true and therefore the flow of execution enters the loop. Thus, in this case, you can actually omit the decision control structure. It is not wrong to leave it there, but it is without doubt redundant.

```php
<?php
$y = 1;
$x = 0;
do {
    $x = $x * 2;
    $y = $y + 1;
} while ($y < 10);
echo $x;
?>
```

# 29.11 Converting from a Counted Loop Structure to a Post-Test Loop Structure

This conversion doesn’t have its own rules but you can use the rules you have already learned, that is, you can convert from a counted loop structure to an intermediate pre-test loop structure, and finally to a post-test loop structure, as shown in the next diagram.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_468_0.png)

For your convenience, everything you have learned so far is presented once again.

# Counted Loop Structure

```
for (counter = initial_value; counter OP1 final_value; counter = counter OP2 offset) {
    A statement or block of statements
}
```

![](img/4d9a992abc5da7946ac44f9e6bf1d032_468_1.png)

# Pre-Test Loop Structure

```
counter = initial_value;
while (counter OP1 final_value) {
    A statement or block of statements
    counter = counter OP2 offset;
}
```

![](img/4d9a992abc5da7946ac44f9e6bf1d032_468_2.png)

# Post-Test Loop Structure

```
counter = initial_value;
if (counter OP1 final_value) {
    do {
        A statement or block of statements
        counter = counter OP2 offset;
    } while (counter OP1 final_value);
}
```

where

+   - counter must always be a variable.

# Exercise 29.11-1 Converting the PHP Script

Rewrite the following PHP script using the post-test loop structure.

```php
<?php
    $start = trim(fgets(STDIN));
    $end = trim(fgets(STDIN));

    for ($i = $start; $i <= $end; $i++) {
        $x = pow($x, 1.5);
```

The intermediate pre-test loop structure is as follows.

```php
<?php
    $start = trim(fgets(STDIN));

    while ($i <= $end) {
        $x = pow($x, 1.5);
        $i++;
    }
    echo $x;
?>
```

and the final post-test loop structure is

```php
<?php
    $start = trim(fgets(STDIN));
    $end = trim(fgets(STDIN));

$x = 5;

$i = $start;
if ($i <= $end) {
    do {
        $x = pow($x, 1.5);
        $i++;
    } while ($i <= $end);
}
echo $x;
?>
```

# 29.12 Converting from a Post-Test Loop Structure to a Counted Loop Structure

This conversion doesn’t have its own rules but you can use the rules you have already learned, that is, you can convert from a post-test loop structure to an intermediate pre-test loop structure, and finally to a counted loop structure, as shown in next diagram.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_471_0.png)

Keep in mind that in computer programming languages other than PHP, such as Visual Basic, Pascal, and Delphi (to name a few), you can do this type of conversion, but only under certain circumstances. The general form of the post-test loop structure, in which conversion can actually be carried out in the majority of the programming languages, is given next.

# Post-Test Loop Structure

```
counter = initial_value;
do {
    A statement or block of statements 1
    counter = counter OP2 offset;
    A statement or block of statements 2
} while (counter OP3 final_valuel);
```

# Pre-Test Loop Structure

```
counter = initial_value;
A statement or block of statements 1
counter = counter OP2 offset;
A statement or block of statements 2
while (counter OP3 final_valuel) {
    A statement or block of statements 1
    counter = counter OP2 offset;
    A statement or block of statements 2
}
```

# Counted Loop Structure

```
counter = initial_value;
A statement or block of statements 1
counter = counter OP2 offset;
A statement or block of statements 2
for (counter = initial_value OP2 offset;
    counter OP1 final_value2;
    counter = counter OP2 offset) {
    A statement or block of statements 1
    A statement or block of statements 2
}
```

+   - **where**
+     - `counter` must always be a variable.
+     - `initial value`, `final value1`, `final value2` and `offset` can be a constant value or even a variable or an expression. In case of a variable or an expression, however, the content or the result correspondingly must be invariable inside the loop.
+     - `OP1` must be `<=` when `counter` increments and `>=` when `counter` decrements.
+     - `OP2` must be `+` when `counter` increments and `-` when `counter` decrements.
+     - `OP3` can be any comparison operator (`<`, `>`, `<=`, `>=`, `==`, `!=`).
+     - Inside statement or block of statements 2 (those being inside the loop), any existing `counter` variable must be replaced by the expression `counter OP2 offset`.
