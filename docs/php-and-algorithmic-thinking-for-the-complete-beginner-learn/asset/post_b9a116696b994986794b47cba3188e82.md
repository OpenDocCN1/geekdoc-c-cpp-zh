## 34.2 How to Get Values from Two-Dimensional Arrays

A two-dimensional array consists of rows and columns. The following example shows a two-dimensional array with three rows and four columns.

|  | Column 0 | Column 1 | Column 2 | Column 3 |
|---|---|---|---|---|
| Row 0 |  |  |  |  |
| Row 1 |  |  |  |  |
| Row 2 |  |  |  |  |

Each element of a two-dimensional array can be uniquely identified using a pair of indexes: a row index, and a column index, as shown next.

```text
$array_name[row_index][column_index]
```

The following PHP script creates the two-dimensional array `$grades` having three rows and four columns, and then displays some of its elements.

```php
<?php
$grades = array();
$grades[0] = array("B+", "A+", "A", "C-");
$grades[1] = array("B", "A", "C", "A+");
$grades[2] = array("B", "B", "B-", "B+");

echo $grades[1][2];  //This displays C on the screen
echo $grades[2][2];  //This displays B- on the screen
echo $grades[0][0];  //This displays B+ on the screen
```

## 34.4 How to Iterate Through a Two-Dimensional Array

Since a two-dimensional array consists of rows and columns, a script can iterate either through rows or through columns.

### Iterating through rows

Iterating through rows means that row 0 is processed first, row 1 is processed next, row 2 afterwards, and so on. Next there is an example of a 3 × 4 array. The arrows show the “path” that is followed when iteration through rows is performed or in other words, they show the order in which the elements are processed.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_610_0.png)

> **Remember!** A 3 × 4 array is a two-dimensional array that has 3 rows and 4 columns. In the notation Y × X, the first number (Y) always represents the total number of rows and the second number (X) always represents the total number of columns.

When iterating through rows, the elements of the array are processed as follows:

- the elements of row 0 are processed in the following order  
  `$a[0][0]` → `$a[0][1]` → `$a[0][2]` → `$a[0][3]`
- the elements of row 1 are processed in the following order  
  `$a[1][0]` → `$a[1][1]` → `$a[1][2]` → `$a[1][3]`
- the elements of row 2 are processed in the following order  
  `$a[2][0]` → `$a[2][1]` → `$a[2][2]` → `$a[2][3]`

Using PHP statements, let’s try to process all elements of a 3 × 4 array (3 rows × 4 columns) iterating through rows.

```php
$i = 0;                         //Variable $i refers to Row 0.
for ($j = 0; $j <= 3; $j++) {   //This loop control structure processes all
    process $a[$i][$j];          //elements of Row 0
}

$i = 1;                         //Variable $i refers to Row 1.
for ($j = 0; $j <= 3; $j++) {   //This loop control structure processes all
    process $a[$i][$j];          //elements of Row 1
}

$i = 2;                         //Variable $i refers to Row 2.
for ($j = 0; $j <= 3; $j++) {   //This loop control structure processes all
    process $a[$i][$j];          //elements of Row 2
}
```

Of course, the same results can be achieved using a nested loop control structure as shown next.

```php
for ($i = 0; $i <= 2; $i++) {
    for ($j = 0; $j <= 3; $j++) {
        process $a[$i][$j];
    }
}
```

Let’s see some examples. The following code fragment lets the user enter 10 × 10 = 100 values to array $a.

```php
for ($i = 0; $i <= 9; $i++) {
    for ($j = 0; $j <= 9; $j++) {
        $a[$i][$j] = trim(fgets(STDIN));
    }
}
```

The following code fragment decreases all values of array $a by one.

```php
for ($i = 0; $i <= 9; $i++) {
    for ($j = 0; $j <= 9; $j++) {
        $a[$i][$j] = $a[$i][$j] - 1;
    }
}
```

The following code fragment displays the values of array $a.

```php
for ($i = 0; $i <= 9; $i++) {
    for ($j = 0; $j <= 9; $j++) {
        echo $a[$i][$j], "\t";
    }
    echo "\n";
}
```

### Exercise 34.4-2 Displaying Odd Columns Only

Write a PHP script that prompts the user to enter numeric values in a 5 × 7 array and then displays the elements of the columns with odd-numbered indexes (that is, column indexes 1, 3, and 5).

### Solution

The PHP script is presented next.

```php
<?php
define("ROWS", 5);
define("COLUMNS", 7);

$a = array(array());
for ($i = 0; $i <= ROWS - 1; $i++) {
    for ($j = 0; $j <= COLUMNS - 1; $j++) {
        echo "Enter a value for element ", $i , ",", $j, ": ";
        $a[$i][$j] = trim(fgets(STDIN));
    }
}

//Iterate through columns
for ($j = 1; $j <= COLUMNS - 1; $j += 2) {   //Start from 1 and
    //increment by 2
    for ($i = 0; $i <= ROWS - 1; $i++) {
        echo $a[$i][$j], " ";
    }
}
```
