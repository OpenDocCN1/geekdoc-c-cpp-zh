Now the flowchart contains known decision control structures and it can become a PHP script. But don’t be in a hurry! This flowchart, as is, can be written in PHP only by using nested if statements. However, there is something better that you can do! If you negate all Boolean expressions and also switch their true/false paths, you can have a multiple-alternative decision structure, which is more convenient in PHP than nested control structures.
