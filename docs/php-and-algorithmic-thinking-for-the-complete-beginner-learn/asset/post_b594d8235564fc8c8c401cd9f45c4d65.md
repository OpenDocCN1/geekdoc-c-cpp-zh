- For N = 1, M = 2 the criteria equals to |1/2 − 0.333| = 0.1670

- For N = 100, M = 100 the criteria equals to |100/100 − 0.333| = 0.6670

As you can see, the value 0.0003 is the minimum value among all possible results. Thus, the combination N = 1 and M = 3 (which corresponds to the fraction 1/3) is considered the best approximation for the value 0.333.

And now the PHP script:

```php
<?php
do {
    echo "Enter a real number between 0 and 100: ";
    $x = trim(fgets(STDIN));
} while (is_numeric($x) != true || $x < 0 || $x > 100);

$best_n = 1;
$best_m = 1;
for ($n = 0; $n <= 100; $n++) {
    for ($m = 1; $m <= 100; $m++) {
        if (abs($n / $m - $x) < abs($best_n / $best_m - $x)) {
            $best_n = $n;
            $best_m = $m;
        }
    }
}

echo "The corresponding fraction is: ", $best_n, "/", $best_m;
?>
```

### 31.5 Finding Minimum and Maximum Values with Loop Control Structures

In Chapter 23 you learned how to find the minimum and maximum values among four values using single-alternative decision structures. Now, the following code fragment does pretty much the same but uses only one variable `$w` to hold all of the user’s given values.

```php
$w = trim(fgets(STDIN));             //User enters 1st value
$max = $w;

$w = trim(fgets(STDIN));             //User enters 2nd value
if ($w > $max) {
    $max = $w;
}

$w = trim(fgets(STDIN));             //User enters 3rd value
if ($w > $max) {
    $max = $w;
}

$w = trim(fgets(STDIN));             //User enters 4th value
if ($w > $max) {
    $max = $w;
}
```

Except for the first pair of statements, all other blocks of statements are identical; therefore, only one of those can be enclosed within a loop control structure and be executed three times, as follows.

```php
$w = trim(fgets(STDIN));             //User enters 1st value
$max = $w;

for ($i = 1; $i <= 3; $i++) {
    $w = trim(fgets(STDIN));         //User enters 2nd, 3rd and 4th value
    if ($w > $max) {
        $max = $w;
    }
}
```

Of course, if you want to allow the user to enter more values, you can simply increase the `final_value` of the counted loop structure.

Accordingly, if you want a script that finds and displays the heaviest person among 10 people, the solution is presented next.

```php
<?php
echo "Enter a weight: ";
$w = trim(fgets(STDIN));
$max = $w;

for ($i = 1; $i <= 9; $i++) {
    echo "Enter a weight: ";
    $w = trim(fgets(STDIN));
    if ($w > $max) {
        $max = $w;
    }
}
echo $max;
?>
```

> **Notice:** Please note that the counted loop structure iterates one time less than the total number of values given.

Even though this PHP script operates perfectly well, let's do something different. Instead of prompting the user to enter one value before the loop and nine values inside the loop, let's prompt him or her to enter all values inside the loop.

The problem that arises here is that no matter what, before the loop starts iterating, an initial value must be assigned to variable `$max`. You can actually assign an “almost arbitrary” initial value but this value should be chosen carefully since a wrong one may lead to incorrect results.

In this exercise, all given values have to do with people’s weight. Since there is no chance of finding any person with a negative weight (at least not on planet Earth), you can safely assign the initial value -1 to variable `$max`, as follows.

```php
<?php
$max = -1;
for ($i = 1; $i <= 10; $i++) {
    echo "Enter a weight: ";
    $w = trim(fgets(STDIN));
    if ($w > $max) {
        $max = $w;
    }
}
echo $max;
?>
```

As soon as the flow of execution enters the loop, the user enters the first value and the decision control structure validates to true. The value -1 in variable `$max` is overwritten by that first given value and after that, flow of execution proceeds normally.

#### Exercise 31.5-1 Validating and Finding the Minimum and the Maximum Value

Write a PHP script that prompts the user to enter the weight of 10 people and then finds the heaviest and the lightest one. Moreover, the script should validate data input and display an error message when the user enters any non-numeric, negative, zero value, or any values greater than 1500.

#### Solution

Using the previous exercise as a guide, you should now be able to do this with your eyes closed!

To validate data input, all you have to do is replace the following two lines of code of the previous exercise,

```php
echo "Enter a weight: ";
$w = trim(fgets(STDIN));
```

with the following code fragment:

```php
echo "Enter a weight: ";
$w = trim(fgets(STDIN));
while (is_numeric($w) != true || $w < 1 || $w > 1500) {
    echo "Invalid value! Please enter a weight between 1 and 1500! \n";
    $w = trim(fgets(STDIN));
}
```

The final script is as follows.

**file_31.5-1.php**

```php
<?php
$max = -1;
$min = 1500;
for ($i = 1; $i <= 10; $i++) {
    echo "Enter a weight: ";
    $w = trim(fgets(STDIN));
    while (is_numeric($w) != true || $w < 1 || $w > 1500) {
        echo "Invalid value! Please enter a weight between 1 and 1500! \n";
        $w = trim(fgets(STDIN));
    }
    if ($w > $max) {
        $max = $w;
    }
    if ($w < $min) {
        $min = $w;
    }
}
echo $min, $max;
?>
```

**Notice:** Please note that this method cannot be used in every case. If an exercise needs to prompt the user to enter any number (not only a positive one) this method cannot be applied since the user could potentially enter only negative values. If this were to occur, the initial value -1 would never be overwritten by any of the given values. You can use this method to find the maximum value only when you know the lower limit of given values or to find the minimum value only when you know the upper limit of given values. For example, if the exercise needs to find the lightest person, you can assign the initial value +1500 to variable `$min`, since there is no human on Earth that can be so heavy! For the record, Jon Brower Minnoch was an American who, at his peak weight, was the heaviest human being ever recorded, weighing approximately 1,400 lb!!!!

#### Exercise 31.5-2 Validating and Finding the Maximum Temperature

Write a PHP script that prompts the user to repeatedly enter the names and the average temperatures of planets from space, until the word "STOP" (used as a name) is entered. In the end, the script should display the name of the hottest planet. Moreover, since -459.67° (on the Fahrenheit scale) is the lowest temperature possible (it is called absolute zero), the script should validate data input and display an error message when the user enters non-numeric values or values lower than absolute zero.

#### Solution

First, let’s write the PHP script without using data validation. According to the “Ultimate” rule, the pre-test loop structure should be as follows, given in general form:

```php
echo "Enter the name of a planet: ";
$name = trim(fgets(STDIN));    //Initialization of $name
while (strtoupper($name) != "STOP") {
    A statement or block of statements

    echo "Enter the name of a planet: ";
    $name = trim(fgets(STDIN));    //Update/alteration of $name
}
```

Now, let’s add the rest of the statements, still without data input validation. Keep in mind that, since value -459.67° is the lower limit of the temperature scale, you can use a value lower than this as the initial value of variable `$max`.

```php
<?php
$max = -460;
$m_name = "";
echo "Enter the name of a planet: ";
$name = trim(fgets(STDIN));
while (strtoupper($name) != "STOP") {
    echo "Enter its average temperature: ";
    $t = trim(fgets(STDIN));
    if ($t > $max) {
        $max = $t;
        $m_name = $name;
    }
    echo "Enter the name of a planet: ";
    $name = trim(fgets(STDIN));
}
if ($m_name != "") {
    echo "The hottest planet is: ", $m_name;
} else {
    echo "Nothing Entered!";
}
?>
```

> **Notice:** The `if ($m_name != "")` statement is required because there is a possibility that the user could enter the word “STOP” right from the beginning.

To validate the data input, all you have to do is replace the following two lines of code:

```php
echo "Enter its average temperature: ";
$t = trim(fgets(STDIN));
```

with the following code fragment:

```php
echo "Enter its average temperature: ";
$t = trim(fgets(STDIN));
while (is_numeric($t) != true || $t < -459.67) {
    echo "Invalid value!\n";
    echo "Enter an average temperature greater than -459.67 degrees!\n";
    $t = trim(fgets(STDIN));
}
```
