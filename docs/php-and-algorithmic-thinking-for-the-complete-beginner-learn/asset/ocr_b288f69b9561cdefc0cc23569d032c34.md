function, a function that calls another function, or even a function that calls one of the built-in functions of PHP.

The next example presents exactly this situation. The main code calls the procedure `display_sum()`, which in turn calls the function `add()`.

```
```php
<?php

function add($number1, $number2) {
    $result = $number1 + $number2;
    return $result;
}

function display_sum($num1, $num2) {
    echo add($num1, $num2);
}

$a = trim(fgets(STDIN));
$b = trim(fgets(STDIN));

display_sum($a, $b);
?>
```
```

> **Notice:** Please note that there is no restriction on the order in which the two subprograms should be written. It would have been exactly the same if the procedure `display_sum()` had been written before the function `add()`.
