6. The following code fragment

```
if ($a == 1) {
    echo "Hello Dionysus!";
}
else {
    $a = $a * $x;
    if ($a == 5) {
        echo "Hello Hera!";
    }
    else {
        echo "It's all Greek to me!";
    }
}
```

+   a. cannot be converted to a multiple-alternative decision structure because it evaluates the same variable for all paths.
+   
+   b. can be converted to a multiple-alternative decision structure.
+   
+   c. cannot be converted to a multiple-alternative decision structure because of the `$a = $a * $x` statement.
+   
+   d. none of the above
