# More Exercises with Arrays

The main idea is to break out of the loop when the given value is **not** found in one column.

> **Notice:** You can use a pre-test loop structure as well, but you need to initially assign the value `true` to the variable `$found`.

The final PHP script is as follows.

```
```php
<?php
define("ROWS", 20);
define("COLUMNS", 30);

$haystack = array(array());
for ($i = 0; $i <= ROWS - 1; $i++) {
    for ($j = 0; $j <= COLUMNS - 1; $j++) {
        $haystack[$i][$j] = trim(fgets(STDIN));
    }
}

echo "Enter a value to search: ";
$needle = trim(fgets(STDIN));

$count = 0;
$j = 0;
do {
    $found = false;
    $i = 0;
    while ($i <= ROWS - 1 && $found == false) {
        if ($haystack[$i][$j] == $needle) {
            $found = true;
        }
        $i++;
    }

    if ($found == true) {
        $count++;
    }

    $j++;
} while ($j <= COLUMNS - 1 && $found == true);
```
