# Solution

The conversion rule states that, in order to make a post-test loop structure produce the same result(s) as a pre-test loop structure, the statement or block of statements of the post-test loop structure must be written twice, once before and once inside the pre-test loop structure!

The next PHP script operates exactly the same way as the initial post-test loop!

```
```php
<?php
$a = trim(fgets(STDIN));
$b = trim(fgets(STDIN));

$a += 2;
echo $a, ", ", $b;
$b = $b + 5;

while ($b <= $a) {
    $a += 2;
    echo $a, ", ", $b;
    $b = $b + 5;
}
?>
