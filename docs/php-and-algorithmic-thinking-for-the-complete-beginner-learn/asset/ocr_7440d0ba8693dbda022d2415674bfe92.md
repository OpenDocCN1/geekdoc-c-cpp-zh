# Tips and Tricks with Loop Control Structures

Following is the script of the exercise, written again, with some notes on it.

```
```php
<?php
    $s = 0;
    $y = 0;

    while ($y != -3) {
        $s = $s + 2 * $y;
        $y = $y - 2;
    }

    echo $s;
?>
```
```

![](bbox=[0.012, 0.107, 0.874, 0.408])

Some extra notes:

+   - Since `counter` decrements, `OP1` must be >=.
+   - Since `offset` is 2 and variable `$y` decrements, and since the loop’s Boolean expression is `$y != -3`, it becomes clear that the last value of `$y` for which the pre-test loop structure performs an iteration is the value -1. Thus, `final_value2` must be -1.
+   - Inside statement or block of statements 1, variable `counter` must remain as is.

Now, with everything clarified, the PHP script can be rewritten using the counted loop structure.

```
```php
<?php
    $s = 0;
    for ($y = 5; $y >= -1; $y = $y - 2) {
        $s = $s + 2 * $y;
    }
    echo $s;
?>
```
