# 29.11 Converting from a Counted Loop Structure to a Post-Test Loop Structure

This conversion doesn’t have its own rules but you can use the rules you have already learned, that is, you can convert from a counted loop structure to an intermediate pre-test loop structure, and finally to a post-test loop structure, as shown in the next diagram.

![](bbox=[0.058, 0.198, 0.969, 0.287])

For your convenience, everything you have learned so far is presented once again.

# Counted Loop Structure

```
for (counter = initial_value; counter OP1 final_value; counter = counter OP2 offset) {
    A statement or block of statements
}
```

![](bbox=[0.447, 0.437, 0.558, 0.493])

# Pre-Test Loop Structure

```
counter = initial_value;
while (counter OP1 final_value) {
    A statement or block of statements
    counter = counter OP2 offset;
}
```

![](bbox=[0.447, 0.652, 0.558, 0.708])

# Post-Test Loop Structure

```
counter = initial_value;
if (counter OP1 final_value) {
    do {
        A statement or block of statements
        counter = counter OP2 offset;
    } while (counter OP1 final_value);
}
```

where

+   - counter must always be a variable.
