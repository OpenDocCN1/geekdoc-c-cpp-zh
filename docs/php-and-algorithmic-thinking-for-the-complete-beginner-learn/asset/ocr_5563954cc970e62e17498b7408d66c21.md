```
$a[$n] = $a[$n - 1];
$n--;
}
//insert the previously "removed" element at index position $n
$a[$n] = $element;
}
```

Notice: Please note that the element at index position $m is not actually removed from
the array but is in fact overwritten when shifting to the right is performed. This is why
its value is kept in variable $element before shifting the elements.

Notice: If you wish to sort an array in descending order, all you need to do is alter the
Boolean expression of the while statement to $n > 0 && $a[$n - 1] < $element.

Remember! As in previous sort algorithms, in order to sort alphanumeric data, you
don’t have to change anything in the algorithm!
