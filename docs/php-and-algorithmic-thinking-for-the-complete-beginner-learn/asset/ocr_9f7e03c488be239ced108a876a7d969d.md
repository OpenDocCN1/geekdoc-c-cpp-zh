# Exercise 33.2-1    *Creating the Trace Table*

Create the trace table for the next code fragment. At the end, the array should contain four elements.

```
```php
$a = array();
$a[3] = 9;
$x = 0;
$a[$x] = $a[3] + 4;
$a[$x + 1] = $a[$x] * 3;
$x++;
$a[$x + 2] = $a[$x - 1];
$a[2] = $a[1] + 5;
$a[3] = $a[3] + 1;
```
```

# Solution

Don’t forget that you can manipulate each element of an array as if it were a variable. Thus, when you create a trace table for a PHP script that uses an array, you can have one column for each element as follows.

| Step | Statement | Notes | $x | $a[0] | $a[1] | $a[2] | $a[3] |
|---:|---|---|---:|---:|---:|---:|---:|
| 1 | `$a = array()` | This creates array `$a` with no values in it | ? | ? | ? | ? | ? |
| 2 | `$a[3] = 9` |  | ? | ? | ? | ? | **9** |
| 3 | `$x = 0` |  | **0** | ? | ? | ? | 9 |
| 4 | `$a[$x] = $a[3] + 4` |  | 0 | **13** | ? | ? | 9 |
| 5 | `$a[$x + 1] = $a[$x] * 3` |  | 0 | 13 | **39** | ? | 9 |
| 6 | `$x++` |  | **1** | 13 | 39 | ? | 9 |
| 7 | `$a[$x + 2] = $a[$x - 1]` |  | 1 | 13 | 39 | ? | **13** |
| 8 | `$a[2] = $a[1] + 5` |  | 1 | 13 | 39 | **44** | 13 |
| 9 | `$a[3] = $a[3] + 1` |  | 1 | 13 | 39 | 44 | **14** |
