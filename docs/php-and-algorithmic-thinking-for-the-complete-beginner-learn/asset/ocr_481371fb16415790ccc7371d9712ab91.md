# Solution

This PHP script contains a counted loop structure that nests a multiple-alternative decision structure. The corresponding flowchart is as follows.

```
elseif ($hour >= 12 && $hour < 20) {
    echo "Good Afternoon\n";
}
elseif ($hour >= 20 && $hour < 24) {
    echo "Good Evening\n";
}
elseif ($hour <= 24) {
    echo "Good Night\n";
}
}
?>
```
