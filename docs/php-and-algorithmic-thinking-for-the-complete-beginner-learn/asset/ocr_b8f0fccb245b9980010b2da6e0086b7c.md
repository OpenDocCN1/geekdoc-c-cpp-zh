One possible solution would be to write a function in which the array is passed by
value (not by reference) and the function would return a smaller array that contains
only the three lowest values. The proposed solution is shown here.

define("ELEMENTS", 10);
function get_array($a) {
for ($m = 1; $m <= ELEMENTS - 1; $m++) {
$element = $a[$m];
$n = $m;
while ($n > 0 && $a[$n - 1] > $element) {
$a[$n] = $a[$n - 1];
$n--;
}
$a[$n] = $element;
}
