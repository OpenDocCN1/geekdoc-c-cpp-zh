15. Write the following PHP script using correct indentation and then rewrite it using nested decision control structures.

```
```php
<?php
$a = trim(fgets(STDIN));

if ($a < 1) {
    $y = 5 + $a;
    echo $y;
}
elseif ($a < 5) {
    $y = 23 / $a;
    echo $y;
}
elseif ($a < 10) {
    $y = 5 * $a;
    echo $y;
}
else {
    echo "Error!";
}
?>
