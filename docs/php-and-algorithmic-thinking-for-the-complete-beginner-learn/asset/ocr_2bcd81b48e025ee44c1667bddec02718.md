Of course, if you pass an array by reference to a subprogram, and that subprogram changes the value of one or more elements of the array, these changes are also reflected outside the subprogram. In the next example, the PHP script must find the three lowest values of array $t. To do so, the script calls and passes the array to the procedure get_array() through its formal argument $a, which in turn sorts array $a using the insertion sort algorithm. When the flow of execution returns to the main code, array $t also gets sorted. So what the main code finally does is just display the elements of the first three positions of the array.

```
```php
<?php
define("ELEMENTS", 10);
function get_array(&$a) {
for ($m = 1; $m <= ELEMENTS - 1; $m++) {
$element = $a[$m];
$n = $m;
while ($n > 0 && $a[$n - 1] > $element) {
$a[$n] = $a[$n - 1];
$n--;
}
$a[$n] = $element;
}
}
$t = array(75, 73, 78, 70, 71, 74, 72, 69, 79, 77);
get_array($t);
echo "Three lowest values are: ", $t[0], " ", $t[1], " ", $t[2], "\n";
//In this step, array $t is now sorted
for ($i = 0; $i <= ELEMENTS - 1; $i++) {
echo $t[$i], "\t";
}
?>
```
