> **Notice:** Please note that for each succeeding term of the Fibonacci series, the number of calls increments exponentially. For example, the calculation of the 40ᵗʰ or the 50ᵗʰ term of the Fibonacci series using this function can prove tragically slow!

Recursion helps you write more creative and more elegant scripts, but keep in mind that it is not always the best option. The main disadvantage of recursion is that it is hard for a programmer to think through the logic, and therefore it is difficult to debug a code that contains a recursive subprogram. Furthermore, a recursive algorithm may prove worse than a non-recursive algorithm because it may consume too much CPU time or too much main memory (RAM). So, there are times where it would be better to follow the KISS principle and, instead of using a recursion, solve the algorithm using loop control structures.

> **Notice:** For you who don’t know what the KISS principle is, it is an acronym for “Keep It Simple, Stupid!” It states that most systems work best if they are kept simple, avoiding any unnecessary complexity!
