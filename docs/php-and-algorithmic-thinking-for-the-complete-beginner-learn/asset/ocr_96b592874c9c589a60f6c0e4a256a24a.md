```
<?php
function is_odd($number, &$return_value) {
	$return_value = true;
	if ($number % 2 == 0) {
		$return_value = false;
	}
}

echo "Enter an integer: ";
$x = trim(fgets(STDIN));

is_odd(3 * $x, $return_value);
if ($return_value == true) {
	echo "3 x ", $number , " is odd";
}
else {
	echo "3 x ", $number , " is not odd";
}
?>
```

# ## 41.4 Passing and/or Returning an Array

Passing an array to a subprogram as an argument is as easy as passing a simple variable. The next example passes array $a to the procedure display(), and the latter displays the array.

```
<?php
define("ELEMENTS", 10);

function display($b) {
	for ($i = 0; $i <= ELEMENTS - 1; $i++) {
		echo $b[$i], "\t";
	}
}

$a = array();
for ($i = 0; $i <= ELEMENTS - 1; $i++) {
	$a[$i] = trim(fgets(STDIN));
}
```
