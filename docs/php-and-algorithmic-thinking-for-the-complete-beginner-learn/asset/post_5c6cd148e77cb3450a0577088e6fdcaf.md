# Exercise 37.4-8 The Selection Sort Algorithm – Sorting One-Dimensional Arrays

Write a code fragment that sorts the elements of an array in ascending order using the selection sort algorithm.

# Solution

The selection sort algorithm is inefficient for large scale data, as is the bubble sort algorithm, but it generally performs better than the latter. It is the simplest of all the sorting algorithms and performs well on computer systems in which limited main memory (RAM) comes into play.

The algorithm finds the smallest (or largest, depending on sorting order) element of the array and swaps its content with that at position 0. Then the process is repeated for the remainder of the array; the next smallest (or largest) element is found and put into the next position, until all elements are examined.

For example, let’s try to sort the following array in ascending order.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_719_0.png)

The lowest value is the value 4 at position 4. According to the selection sort algorithm, this element swaps its content with that at position 0. The array A becomes

![](img/4d9a992abc5da7946ac44f9e6bf1d032_719_1.png)

The lowest value in the remainder of the array is the value 9 at position 5. This element swaps its content with that at position 1. The array A becomes

![](img/4d9a992abc5da7946ac44f9e6bf1d032_719_2.png)

The lowest value in the remainder of the array is the value 18 at position 4. This element swaps its content with that at position 2. The array A becomes

| A = | 4 | 9 | 18 | 36 | 41 | 19 |
|---|---:|---:|---:|---:|---:|---:|
| Position | 0 | 1 | 2 | 3 | 4 | 5 |

Proceeding the same way, the next lowest value is the value 19 at position 5. The array A becomes

| A = | 4 | 9 | 18 | 19 | 41 | 36 |
|---|---:|---:|---:|---:|---:|---:|
| Position | 0 | 1 | 2 | 3 | 4 | 5 |

Finally, the next lowest value is the value 36 at position 5. The array A becomes finally sorted in ascending order!

| A = | 4 | 9 | 18 | 19 | 36 | 41 |
|---|---:|---:|---:|---:|---:|---:|
| Position | 0 | 1 | 2 | 3 | 4 | 5 |

Now, let’s write the corresponding PHP script. The “from inner to outer” method is used in order to help you better understand the whole process. The next code fragment finds the smallest element and then swaps its content with that at position 0. Please note that this is the inner (nested) loop control structure. Assume variable $m contains the value 0.

```php
$min = $a[$m];
$index_of_min = $m;
for ($n = $m; $n <= ELEMENTS - 1; $n++) {
    if ($a[$n] < $min) {
        $min = $a[$n];
        $index_of_min = $n;
    }
}
//Minimum found! Now, swap values.
$temp = $a[$m];
$a[$m] = $a[$index_of_min];
$a[$index_of_min] = $temp;
```

Now, in order to repeat the process for all elements of the array, you can nest this code fragment within a counted loop structure that iterates for all elements.

The final selection sort algorithm that sorts an array in ascending order is as follows.

```php
for ($m = 0; $m <= ELEMENTS - 1; $m++) {
    $min = $a[$m];
    $index_of_min = $m;
    for ($n = $m; $n <= ELEMENTS - 1; $n++) {
        if ($a[$n] < $min) {
            $min = $a[$n];
            $index_of_min = $n;
        }
    }
    //Swap values
    $temp = $a[$m];
    $a[$m] = $a[$index_of_min];
    $a[$index_of_min] = $temp;
}
```

**Notice:** If you wish to sort an array in descending order, all you need to do is search for maximum instead of minimum values.

**Remember!** As in a bubble sort algorithm, in order to sort alphanumeric data, you can do one simple thing: leave the algorithm as is!
