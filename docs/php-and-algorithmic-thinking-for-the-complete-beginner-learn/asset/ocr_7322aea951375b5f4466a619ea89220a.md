# Tips and Tricks with Loop Control Structures

$$S=\frac{1}{1\cdot2\cdot3\cdots100}+\frac{2}{1\cdot2\cdot3\cdots100}+\cdots+\frac{100}{1\cdot2\cdot3\cdots100}$$

is solved using the following PHP script.

```
```php
<?php
    $s = 0;

    for ($i = 1; $i <= 100; $i++) {
        $denom = 1;

        for ($j = 1; $j <= 100; $j++) {
            $denom *= $j;
        }

        $s += $i / $denom;
    }
    echo $s;
?>
```
```
