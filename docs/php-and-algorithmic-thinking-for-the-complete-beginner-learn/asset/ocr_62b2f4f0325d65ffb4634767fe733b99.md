# Case Decision Structure

```
```php
switch (var_expr) {
    case value-1:
        block of statements 1
        break;
    case value-2:
        block of statements 2
        break;
    case value-3:
        block of statements 3
        break;
    .
    .
    .
    case value-N:
        block of statements N
        break;
    default:
        block of statements N+1
}
```

# Multiple-Alternative Decision Structure

```
```php
if (var_expr == value-1) {
    block of statements 1
}
elseif (var_expr == value-2) {
    block of statements 2
}
elseif (var_expr == value-3) {
    block of statements 3
}
.
.
.
elseif (var_expr == value-N) {
    block of statements N
}
else {
    block of statements N+1
}
```
```

> **Notice:** The opposite conversion (from multiple-alternative decision structure to case decision structure) is possible as long as the same variable or expression is evaluated for all paths. Moreover, this variable or expression should be tested in each path to determine if it is equal to the constant values `value-1`, `value-2`, and `value-N` respectively.
> 
> **Notice:** Although there is an alternative form of the `switch` statement in PHP, it is beyond the scope of this book and so is purposely not mentioned.
