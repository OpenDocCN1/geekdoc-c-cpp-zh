# # Exercise 31.5-1 Validating and Finding the Minimum and the Maximum Value

Write a PHP script that prompts the user to enter the weight of 10 people and then finds the heaviest and the lightest one. Moreover, the script should validate data input and display an error message when the user enters any non-numeric, negative, zero value, or any values greater than 1500.

# ## Solution

Using the previous exercise as a guide, you should now be able to do this with your eyes closed!

To validate data input, all you have to do is replace the following two lines of code of the previous exercise,

```
```php
echo "Enter a weight: ";
$w = trim(fgets(STDIN));
```
```

with the following code fragment:

```
```php
echo "Enter a weight: ";
$w = trim(fgets(STDIN));
while (is_numeric($w) != true || $w < 1 || $w > 1500) {
    echo "Invalid value! Please enter a weight between 1 and 1500! \n";
    $w = trim(fgets(STDIN));
}
```
