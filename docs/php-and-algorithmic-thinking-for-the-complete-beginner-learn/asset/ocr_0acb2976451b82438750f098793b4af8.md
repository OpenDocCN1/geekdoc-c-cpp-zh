# 40.4 How Does a Procedure Execute?

When the main code calls a procedure, the following steps are performed:

+   - The execution of the statements of the main code is interrupted.
+   - The values of the variables or the result of the expressions that exist in the actual argument list are passed (assigned) to the corresponding arguments (variables) in the formal argument list and the flow of execution goes to where the procedure is written.
+   - The statements of the procedure are executed.
+   - When the flow of execution reaches the end of the procedure, the flow of execution continues from where it was before calling the procedure.

In the next PHP script, the procedure `minimum()` accepts three arguments (numeric values) through its formal argument list and displays the lowest value.

```
```php
<?php

function minimum($val1, $val2, $val3) {
    $min = $val1;
    if ($val2 < $min) {
        $min = $val2;
    }
    if ($val3 < $min) {
        $min = $val3;
    }
    echo $min;
}

$a = trim(fgets(STDIN));
$b = trim(fgets(STDIN));
$c = trim(fgets(STDIN));

minimum($a, $b, $c);

echo "The end";
?>
```
```

When the PHP script starts running, the first statement executed is the statement `$a = trim(fgets(STDIN))` (this is considered the first statement of the script). Suppose the user enters the values 9, 6, and 8.

| Step | Statements of Main Code | $a | $b | $c |
|---:|---|---:|---:|---:|
| 1 | `$a = trim(fgets(STDIN))` | 9 | ? | ? |
| 2 | `$b = trim(fgets(STDIN))` | 9 | 6 | ? |
