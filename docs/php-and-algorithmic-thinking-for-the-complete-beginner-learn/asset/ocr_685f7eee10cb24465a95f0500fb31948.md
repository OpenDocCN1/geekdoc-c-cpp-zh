# First Approach – Using a case decision structure

This PHP script can be written using either a case decision structure or a multiple-alternative decision structure. Let’s try them both!

```
```php
<?php
echo "Enter a number between 1 and 7: ";
$day = trim(fgets(STDIN));

switch ($day) {
    case 1:
        echo "Sunday";
        break;
    case 2:
        echo "Monday";
        break;
    case 3:
        echo "Tuesday";
        break;
    case 4:
        echo "Wednesday";
        break;
    case 5:
        echo "Thursday";
        break;
    case 6:
        echo "Friday";
        break;
    case 7:
        echo "Saturday";
        break;
    default:
        echo "Invalid Number";
}
?>
```
