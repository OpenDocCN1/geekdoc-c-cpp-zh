# Exercise 23.5-4 Checking for Proper Capitalization and Punctuation

Write a PHP script that prompts the user to enter a sentence and then checks it for proper capitalization and punctuation. The script should determine if the string begins with an uppercase letter and ends with a punctuation mark (check only for periods, question marks, and exclamation marks).

# Solution

# Chapter 23 More Exercises with Decision Control Structures

In this exercise you need to isolate the first and the last character of the string. As you already know, you can access any individual character of a string using substring notation. You can use index 0 to access the first character, index 1 to access the second character, and so on.

Thus, you can isolate the first character of a string using the following PHP statement.

```php
$first_char = $sentence[0];
```

On the other hand, the index of the last character is 1 less than the length of the string. But, how long is that string?

You can find the length of any string using the `strlen()` function. The following code fragment isolates the last character of a string.

```php
$length = strlen($sentence);
$last_char = $sentence[$length - 1];
```

or you can even write it with one single statement.

```php
$last_char = $sentence[strlen($sentence) - 1];
```

The PHP script is shown here.

```php
<?php
echo "Enter a sentence: ";
$sentence = trim(fgets(STDIN));

$first_char = $sentence[0];
$last_char = $sentence[strlen($sentence) - 1];

$sentence_is_okay = true;

if ($first_char != strtoupper($first_char)) {
    $sentence_is_okay = false;
}
elseif ($last_char != "." && $last_char != "?" && $last_char != "!") {
    $sentence_is_okay = false;
}

if ($sentence_is_okay == true) {
    echo "Sentence is okay!";
}
?>
```

In the beginning, the script assumes that the sentence is okay (`$sentence_is_okay = true`). Then, it checks for proper capitalization and proper punctuation and if something goes wrong, it assigns the value `false` to the variable `$sentence_is_okay`.
