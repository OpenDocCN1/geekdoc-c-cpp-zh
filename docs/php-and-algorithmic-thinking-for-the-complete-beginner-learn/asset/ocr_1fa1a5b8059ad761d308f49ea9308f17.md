# Exercise 8.1-3    *Swapping Values of Variables – A Second Approach*

Write a PHP script that lets the user enter two numeric values, in variables $a and $b. In the end, the two variables should swap their values.

# Solution

Since the variables contain only numeric values, you can use the following PHP script.

```
```php
<?php

$a = trim(fgets(STDIN));
$b = trim(fgets(STDIN));

$a = $a + $b;
$b = $a - $b;
$a = $a - $b;

echo $a, " ", $b;

?>
```
```

> **Notice:** Compared to previous exercise, the only major disadvantage of this method is that it cannot swap the contents of alphanumeric variables (strings).
