# 39.6 Review Exercises

Complete the following exercises.

+   1. The following function contains a logic error. Can you spot it?

```
function find_max($a, $b) {
    if ($a > $b) {
        $max = $a;
    }
    else {
        $max = $b;
    }
}
```

+   2. Create a trace table to determine the values of the variables in each step of the following PHP script.

```
<?php

function sum_digits($a) {
    $d1 = $a % 10;
    $d2 = intval($a / 10);

    return $d1 + $d2;
}

$s = 0;
for ($i = 25; $i <= 27; $i++) {
    $s += sum_digits($i);
}
echo $s;
?>
```
