#### 练习 36.2-1 设计流程图

设计与以下 PHP 脚本对应的流程图。

```php
<?php
define("ELEMENTS", 100);

$values = array();
for ($i = 0; $i <= ELEMENTS - 1; $i++) {
    $values[$i] = trim(fgets(STDIN));
}

for ($i = 0; $i <= ELEMENTS - 1; $i++) {
    if ($values[$i] < 0) {
        echo $values[$i];
    }
}
?>
```

#### 练习 36.2-3 设计流程图

设计与以下 PHP 脚本对应的流程图。

```php
<?php
define("ROWS", 20);
define("COLUMNS", 10);

$a = array(array());
for ($i = 0; $i <= ROWS - 1; $i++) {
    for ($j = 0; $j <= COLUMNS - 1; $j++) {
        $a[$i][$j] = trim(fgets(STDIN));
    }
}

$max = $a[0][0];
```
