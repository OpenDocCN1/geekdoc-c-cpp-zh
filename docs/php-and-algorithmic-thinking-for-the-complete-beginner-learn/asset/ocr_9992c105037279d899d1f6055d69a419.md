# 29.5 Cleaning Out Your Loops

As you already know, loops can consume too much CPU time, so you must be very careful and use them sparingly. Although a large number of iterations is sometimes inevitable, there are always things that you can do to make your loops perform better.

The next PHP script calculates the average value of the numbers 1, 2, 3, 4, 5, ... 10000.

        $i++;
