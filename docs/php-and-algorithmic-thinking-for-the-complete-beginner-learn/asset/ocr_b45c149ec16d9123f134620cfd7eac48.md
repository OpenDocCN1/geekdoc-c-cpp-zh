# Exercise 29.5-2  *Cleaning Out the Loop*

*The next formula*

$$S=\frac{1}{1+2^2+3^3+\cdots+N^N}+\frac{2}{1+2^2+3^3+\cdots+N^N}+\cdots+\frac{N}{1+2^2+3^3+\cdots+N^N}$$

is solved using the following PHP script, where $N$ is given by the user.

```
```php
<?php
echo "Enter N: ";

$n = trim(fgets(STDIN));

$s = 0;

for ($i = 1; $i <= $n; $i++) {
    $denom = 0;
    for ($j = 1; $j <= $n; $j++) {
        $denom += pow($j, $j);
    }
    $s += $i / $denom;
}
echo $s;
?>
```
```

*Try to move as many statements as possible outside the loop to make the script more efficient.*

# Solution

As you can see from the formula, the denominator is common for all fractions. Thus, it is pointless to calculate it again and again for every fraction. You can calculate the denominator just once and use the result many times, as follows.

```
```php
<?php
echo "Enter N: ";

$n = trim(fgets(STDIN));

$denom = 0;
for ($j = 1; $j <= $n; $j++) {
    $denom += pow($j, $j);
}

$s = 0;
for ($i = 1; $i <= $n; $i++) {
    $s += $i / $denom;
}
echo $s;
```
