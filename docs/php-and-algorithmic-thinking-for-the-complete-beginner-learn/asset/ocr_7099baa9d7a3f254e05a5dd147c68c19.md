# Chapter 39 User-Defined Functions

8. A function cannot return an array.

9. The statement

`return $x + 1;`

is a valid PHP statement.

10. A formal argument can be an expression.

11. An actual argument can be an expression.

12. A function can have no arguments in the actual argument list.

13. The next statement calls the function `cube_root()` three times.

`$cb = cube_root($x) + cube_root($x) / 2 + cube_root($x) / 3;`

14. The following code fragment

`$cb = cube_root($x);`
`$y = $cb + 5;`
`echo $y;`

displays exactly the same value as the statement `echo cube_root($x) + 5.`

15. A function must always include a `return` statement.

16. The name `play-the-guitar` can be a valid function name.

17. You can place your functions either above or below your main code.

18. When the main code calls a function, the execution of the statements of the main code is interrupted.

19. Generally speaking, it is possible for a function to return no values to the caller.

20. The function `strpos()` is a built-in function of PHP.

21. The following code fragment

`function add($a, $b) {`
`return $a / $b;`
`}`

`$a = 10;`
`$b = 5;`
`echo add($b, $a);`

displays the value 0.5.

22. The following code fragment

`$y = cube_root($x);`
`$y += 5;`

is equivalent to the statement `$y = 5 + cube_root($x);`
