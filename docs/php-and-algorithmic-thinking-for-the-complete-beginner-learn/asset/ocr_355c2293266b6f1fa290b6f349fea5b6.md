5. Design the flowchart that corresponds to the following PHP script.

```
```php
<?php
    $i = -20;
    do {
        $x = trim(fgets(STDIN));
        if ($x == 0)
            echo "Zero";
        elseif ($x % 2 == 0)
            echo 2 * $i;
        else
            echo 3 * $i;
        $i++;
    } while ($i <= 20);
?>
