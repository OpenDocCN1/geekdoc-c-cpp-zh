
## Chapter 33: One-Dimensional Arrays

### 33.1 Creating One-Dimensional Arrays in PHP

There are several approaches that can be used to create and add values (elements) to an array in PHP. Which one to use is up to you, depending on the given problem.

Let’s try to create the following array, `$grades`, using all approaches.

| 0 | 1 | 2 | 3 |
|---|---|---|---|
| B+ | A+ | A | C- |

**First Approach**

You can create an array in PHP using the following statement given in general form:

```php
$array_name = array();
```

and then you can add a value (an element) to it using the following statement, given in general form:

```php
$array_name[index] = value;
```

where `index` is the index position of the element in the array.

The next code fragment creates the array `$grades` and adds some values (elements) to it.

```php
$grades = array();
$grades[0] = "B+";
$grades[1] = "A+";
$grades[2] = "A";
$grades[3] = "C-";
```

> **Notice:** In Chapter 5 you learned about the rules that must be followed when assigning names to PHP variables. Assigning names to PHP arrays follows exactly the same rules!

Of course, instead of using constant values for `index`, you can also use variables or expressions, as follows.

```php
$grades = array();
$k = 0;
$grades[$k] = "B+";
$grades[$k + 1] = "A+";
$grades[$k + 2] = "A";
$grades[$k + 3] = "C-";
```

**Second Approach**

The same result can be achieved without using an `index`, as follows.

```php
$grades = array();
$grades[] = "B+";
$grades[] = "A+";
$grades[] = "A";
$grades[] = "C-";
```

> **Notice:** Please note that in this approach, *index* numbering starts at zero by default. This means that grade B+ is added to index position 0.

**Third Approach**

Another way to create an array and directly add values to it is shown in the next PHP statement, given in general form.

```php
$array_name = array(value0, value1, value2, ..., valueM);
```

Using this approach, the array `$grades` can be created using the following statement:

```php
$grades = array("B+", "A+", "A", "C-");
```

> **Notice:** Please note that in this approach as well, *index* numbering starts at zero by default.

**Fourth Approach**

Last but not least, if you wish to create an array and directly add some elements to certain positions you can use the next PHP statement, given in general form.

```php
$array_name = array(index0 => value0, index1 => value1, ..., indexM => valueM);
```

Thus, the array `$grades` can be created using the following statement:

```php
$grades = array(0 => "B+", 1 => "A+", 2 => "A", 3 => "C-");
```

In this approach, elements can also be in random order.

```php
$grades = array(3 => "C-", 1 => "A+", 0 => "B+", 2 => "A");
```

As previously shown, instead of using constant values for *index*, you can also use variables or expressions as shown next.

```php
$k = 0;
$grades = array($k + 3 => "C-", $k + 1 => "A+", $k => "B+", $k + 2 => "A");
```

### 33.2 How to Get Values from One-Dimensional Arrays

Getting values from arrays is just a matter of pointing to a specific position. Each element of a one-dimensional array can be uniquely identified using the array index. The following code fragment

```php
$grades = array("B+", "A+", "A", "C-");
echo $grades[1];
```

displays A+ on the screen.

Of course, instead of using constant values for *index*, you can also use variables or expressions. The following example

```php
$grades = array("B+", "A+", "A", "C-");
$k = 3;
echo $grades[$k], " and ", $grades[$k - 1];
```

displays C- and A on the screen.

**Exercise 33.2-2 — Using a Non-Existing Index**

Which properties of an algorithm are not satisfied by the following PHP script?

```php
<?php
$grades = array("B+", "A+", "A", "C-");
```

### 33.3 How to Add Values Entered by the User to a One-Dimensional Array

There is nothing new here. Instead of reading a value from the keyboard and assigning that value to a variable, you can directly assign that value to a specific position of an array. The next code fragment lets the user enter three values, and then adds these values to positions 0, 1, and 2 of the array `$test`.

```php
$test = array();
$test[0] = trim(fgets(STDIN));
$test[1] = trim(fgets(STDIN));
$test[2] = trim(fgets(STDIN));
```

### 33.4 How to Iterate Through a One-Dimensional Array

Now comes the interesting part. A script can iterate through the elements of an array using a loop control structure (usually a counted loop structure) in which the counter variable is used as the index to the array. Following is a code fragment, written in general form

```php
for ($i = 0; $i <= size_of_the_array - 1; $i++) {
    process array_name[$i];
}
```

in which *size_of_the_array* is the number of elements the array contains, and *process* is any PHP statement or block of statements that processes one element of the array at each iteration.

> **Notice:** The name of the variable `$i` is not binding. You can use any variable name you wish, such as `$index`, `$ind`, `$j`, and many more.

The following PHP script,

```php
<?php
$grades = array("B+", "A+", "A", "C-");
for ($i = 0; $i <= 3; $i++) {
    process $grades[$i];
}
?>
```

“processes” all elements of the array `$grades`, one at each iteration.

If you are really satisfied with this programming style, go ahead. However, what if the wording of this exercise asked the user to enter 1000 instead of 10 words? Think about it!

Arrays are especially perfect for problems like this one. The following is an appropriate solution.

```php
<?php
$words = array();

for ($i = 0; $i <= 9; $i++) {
    $words[$i] = trim(fgets(STDIN));
}

for ($i = 9; $i >= 0; $i--) {
    echo $words[$i];
}
?>
```

> **Remember!** Since index numbering starts at zero, the index of the last element of an array is 1 less than the total number of elements in the array.
>
