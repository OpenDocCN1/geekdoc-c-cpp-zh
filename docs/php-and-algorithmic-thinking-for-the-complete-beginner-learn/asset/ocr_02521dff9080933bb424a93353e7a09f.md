# Chapter 39
User-Defined Functions

In this exercise you need to write a function that accepts two values from the caller (this is the main code) and then calculates and returns their sum. The solution is shown here.

```
```php
<?php

    function sum($a, $b) {
        $s = $a + $b;
        return $s;
    }

    $num1 = trim(fgets(STDIN));
    $num2 = trim(fgets(STDIN));

    $result = sum($num1, $num2);
    echo "The sum of ", $num1, " + ", $num2, " is ", $result;
?>
```
