# 31.1  Simple Exercises with Loop Control Structures

# Exercise 31.1-1  *Finding the Sum of 1 + 2 + 3 + ... + 100*

Write a PHP script that calculates and displays the following sum:

$S = 1 + 2 + 3 + ... + 100$

# Solution

Let’s study this exercise using a sequence control structure.

```
```php
$S = 0;
$i = 1;

$S = $S + $i;
$i = $i + 1;

$S = $S + $i;
$i = $i + 1;

...

...

$S = $S + $i;
$i = $i + 1;
```
```

> Since the PHP script must calculate the sum of 1 + 2 + 3 + ... + 100, this pair of statements should be written 100 times.

Let’s use a trace table to better understand it.

| Step | Statement | Notes | $i$ | $S$ |
|---|---|---|---:|---:|
| 1 | `$S = 0` | 0 | ? | **0** |
| 2 | `$i = 1` |  | **1** | 0 |
| 3 | `$S = $S + $i` | **0 + 1 = 1** | 1 | **1** |
| 4 | `$i = $i + 1` |  | **2** | 1 |
| 5 | `$S = $S + $i` | **0 + 1 + 2 = 3** | 2 | **3** |
| 6 | `$i = $i + 1` |  | **3** | 3 |
| 7 | `$S = $S + $i` | **0 + 1 + 2 + 3 = 6** | 3 | **6** |
| 8 | `$i = $i + 1` |  | **4** | 6 |
| ... | ... |  | ... | ... |
| ... | ... |  | ... | ... |
| Last but one iteration | `$S = $S + $i` |  | 99 | **4950** |
|  | `$i = $i + 1` |  | **100** | 4950 |
