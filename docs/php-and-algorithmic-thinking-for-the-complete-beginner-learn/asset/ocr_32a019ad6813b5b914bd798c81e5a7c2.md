```
echo "Sum = ", $sum;

```

Notice: Please note that the script iterates through rows and checks if the row index is equal to the column index. Alternatively, the same result can be achieved by iterating through columns.

# Second Approach – Iterating directly through the main diagonal

In this approach, one single loop control structure iterates directly through the main diagonal. The solution is as follows.

```
<?php
define("N", 10);

$a = array(array());
for ($i = 0; $i <= N - 1; $i++) {
    for ($j = 0; $j <= N - 1; $j++) {
        $a[$i][$j] = trim(fgets(STDIN));
    }
}

//Calculate Sum
$sum = 0;
for ($k = 0; $k <= N - 1; $k++) {
    $sum = $sum + $a[$k][$k];
}

echo "Sum = ", $sum;
?>
```

Notice: This approach is much more efficient than the first one since the total number of iterations performed by the counted loop structure that is responsible for calculating the sum is just 10.
