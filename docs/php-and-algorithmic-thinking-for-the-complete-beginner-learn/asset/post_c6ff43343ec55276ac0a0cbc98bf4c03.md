### Exercise 43.1-1 Finding the Average Values of Positive Integers

Do the following:

- i. Write a subprogram named `test_integer()` that accepts a number through its formal argument list and returns `true` when the passed number is an integer; it must return `false` otherwise.

- ii. Using the subprogram `test_integer()` cited above, write a PHP script that lets the user enter integer values repeatedly until a real one is entered. In the end, the script should display the average value of positive integers entered.

#### Solution

Since the subprogram `test_integer()` returns one value (`true` or `false`), it can be written as a function. The solution is presented next.

```php
<?php
function test_integer($number) {
    $return_value = false;
    if ($number == intval($number)) {
        $return_value = true;
    }
    return $return_value;
}

$sum = 0;
$count = 0;
$x = trim(fgets(STDIN));
while(test_integer($x) == true) {
    if ($x > 0) {
        $sum += $x;
        $count++;
    }
    $x = trim(fgets(STDIN));
}

if ($count > 0) {
    echo $sum / $count;
}
?>
```

### Exercise 43.1-2 Finding the Sum of Odd Positive Integers

Do the following:

- ii. Write a subprogram named `test_odd` that accepts a number through its formal argument list and returns `true` when the passed number is odd; it must return `false` otherwise.

- iii. Write a subprogram named `test_positive` that accepts a number through its formal argument list and returns `true` when the passed number is positive; it must return `false` otherwise.

- iv. Using the three subprograms cited above, write a PHP script that lets the user enter numeric values repeatedly until a negative one is entered. In the end, the script should display the sum of odd positive integers entered.

#### Solution

This exercise is pretty much the same as the previous one. Each subprogram returns one value (which can be `true` or `false`) thus, all subprograms can be written as functions. The solution is presented here.

```php
<?php

function test_integer($number) {
    $return_value = false;
    if ($number == intval($number)) {
        $return_value = true;
    }
    return $return_value;
}

function test_odd($number) {
    $return_value = false;
    if ($number % 2 != 0) {
        $return_value = true;
    }
    return $return_value;
}

function test_positive($number) {
    $return_value = false;
    if ($number > 0) {
        $return_value = true;
    }
    return $return_value;
}

$sum = 0;
$x = trim(fgets(STDIN));
while(test_positive($x) == true) {
    if (test_integer($x) == true && test_odd($x) == true) {

    }
```
