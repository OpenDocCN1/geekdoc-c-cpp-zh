# # 34.1 Creating Two-Dimensional Arrays in PHP

An array that can hold the grades of four lessons for three students is as follows.

![](bbox=[0.209, 0.121, 0.834, 0.319])

**Notice**: A two-dimensional array has rows and columns. In this particular example, array grades has 3 rows and 4 columns.

Actually, PHP supports only one-dimensional arrays. But there is a trick that you can use to overcome this problem and create multidimensional arrays. You can create an array of arrays! Just imagine the array `$grades` as a one-column array with three positions, each of which contains a whole new array of four elements, as follows.

![](bbox=[0.184, 0.506, 0.859, 0.812])

**Notice!** In PHP, a multidimensional array is actually an array of arrays! A two-dimensional array is an array of arrays, a three-dimensional array is an array of arrays of arrays, and so on.

**Remember!** In Chapter 5 you learned about the rules that must be followed when assigning names to PHP variables. Assigning names to PHP arrays follows exactly the same rules!
