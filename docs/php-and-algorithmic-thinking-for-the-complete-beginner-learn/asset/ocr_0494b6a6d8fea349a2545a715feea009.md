22. Design the flowchart fragment of the linear search algorithm that searches array `$a` of N elements for the value `$needle` and displays the position(s) at which `$needle` is found. If `$needle` is not found, the message “Not found” should be displayed.

23. Design the flowchart fragment of the binary search algorithm that searches array `$a` of N elements for the value `$needle` and displays the position at which `$needle` is found. If `$needle` is not found, the message “Not found” should be displayed.

24. Ten teams participate in a football tournament, and each team plays 16 games, one game each week. Write a PHP script that prompts the user to enter the name of each team, the number of goals the team scored, and the number of goals the team let in for each match. A win receives 3 points and a tie receives 1 point. The PHP script should prompt the user for a team name and then it finds and displays the total number of points for this team. If the given team name is not found, the message “This team does not exist” should be displayed.

Assume that no two teams have the same name. Moreover, the script should validate data input and display an error message when the user enters any non-numeric or negative number of goals.

25. In a high school, there are two classes, with 20 and 25 students respectively. Write a PHP script that prompts the user to enter the names of the students in two separate arrays. The script then displays the names of each class independently in ascending order. Afterwards, the script prompts the user to enter a name and it searches for that given name in both arrays. If the student’s name is found, the script should display the message “Student found in class No...”; otherwise the message “Student not found in either class” should be displayed. Assume that both arrays contain unique names.

Hint: Since the arrays are sorted and the names are unique, you can use the binary search algorithm.
