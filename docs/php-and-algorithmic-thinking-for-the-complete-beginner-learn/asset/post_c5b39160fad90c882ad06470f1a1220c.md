## Exercise 41.3-1 Finding the Logic Error

The following PHP script is supposed to prompt the user to enter an integer and then display the product of that integer multiplied by its number of digits. For example, if the user enters the value 401, the script should display a result of 401 × 3 = 1203. Unfortunately, the PHP script displays 0. Can you find out why?

### file_41.3-1.php

```php
<?php
function get_num_of_digits(&$x) {
    $count = 0;
    while ($x != 0) {
        $count++;
        $x = intval($x / 10);
    }
    return $count;
}

$val = trim(fgets(STDIN));

echo get_num_of_digits($val) * $val;
?>
```

### Solution

The function `get_num_of_digits()` counts the number of digits of the argument `$x` using an already known method proposed in Chapter 31. But before you read the answer below, can you try to find the logic error by yourself?

No? Come on, it isn't that difficult!

Still No? Do you want to give up?

So, let it be!

The problem is that, within the function `get_num_of_digits()`, variable `$x` eventually becomes `0`, and since the variable `$val` is passed to the function by reference, that `0` also reflects back to the main code. So, when the flow of execution returns to the main code, the value of variable `$val` is zeroed!

To resolve this issue, all you have to do is remove the ampersand (`&`) sign at the beginning of the argument `$x`. If you do so, the variable `$val` is passed to the function by value, so that no matter what happens to variable `$x` within the function, nothing can affect the value of the variable `$val` of the main code.

## 41.4 Passing and/or Returning an Array

Passing an array to a subprogram as an argument is as easy as passing a simple variable. The next example passes array `$a` to the procedure `display()`, and the latter displays the array.

```php
<?php
define("ELEMENTS", 10);

function display($b) {
    for ($i = 0; $i <= ELEMENTS - 1; $i++) {
        echo $b[$i], "\t";
    }
}

$a = array();
for ($i = 0; $i <= ELEMENTS - 1; $i++) {
    $a[$i] = trim(fgets(STDIN));
}
?>
```

Of course, if you pass an array by reference to a subprogram, and that subprogram changes the value of one or more elements of the array, these changes are also reflected outside the subprogram. In the next example, the PHP script must find the three lowest values of array `$t`. To do so, the script calls and passes the array to the procedure `get_array()` through its formal argument `$a`, which in turn sorts array `$a` using the insertion sort algorithm. When the flow of execution returns to the main code, array `$t` also gets sorted. So what the main code finally does is just display the elements of the first three positions of the array.

```php
<?php
define("ELEMENTS", 10);
function get_array(&$a) {
for ($m = 1; $m <= ELEMENTS - 1; $m++) {
$element = $a[$m];
$n = $m;
while ($n > 0 && $a[$n - 1] > $element) {
$a[$n] = $a[$n - 1];
$n--;
}
$a[$n] = $element;
}
}
$t = array(75, 73, 78, 70, 71, 74, 72, 69, 79, 77);
get_array($t);
echo "Three lowest values are: ", $t[0], " ", $t[1], " ", $t[2], "\n";
//In this step, array $t is now sorted
for ($i = 0; $i <= ELEMENTS - 1; $i++) {
echo $t[$i], "\t";
}
?>
```

> **Notice:** Please note that, since the array `$t` of the main code is passed to the procedure by reference, when the flow of execution returns to the main code, array `$t` also gets sorted.

So, one way in which a subprogram can indirectly return an array is by passing the array by reference. But there are many times when passing an array by reference can be completely disastrous. Suppose you have the following two arrays. Array `$names` contains the names of 10 cities, and array `$t` contains their corresponding temperatures recorded at 12:00 p.m. on a specific day.

Now, suppose that for array `$t` you wish to display the three lowest temperatures. If you call procedure `get_array()` of the previous PHP script, you have a problem. Although the three lowest temperatures can be displayed as required, the array `$t` becomes sorted; therefore the relationship between its elements and the elements of array `$names` is lost forever!

One possible solution would be to write a function in which the array is passed by value (not by reference) and the function would return a smaller array that contains only the three lowest values. The proposed solution is shown here.

### file_41_4c.php

```php
<?php
define("ELEMENTS", 10);
function get_array($a) {
for ($m = 1; $m <= ELEMENTS - 1; $m++) {
$element = $a[$m];
$n = $m;
while ($n > 0 && $a[$n - 1] > $element) {
$a[$n] = $a[$n - 1];
$n--;
}
$a[$n] = $element;
}
$ret_array = array($a[0], $a[1], $a[2]);
return $ret_array;
}
$names = array("City1", "City2", "City3", "City4", "City5",
"City6", "City7", "City8", "City9", "City10");
$t = array(75, 73, 78, 70, 71, 74, 72, 69, 79, 77);
$low = get_array($t);

echo "Three lowest values are: " . $low[0] . ", " . $low[1] . ", " . $low[2] . "\n";

//In this step, array $t is NOT sorted
for ($i = 0; $i <= ELEMENTS - 1; $i++) {
    echo $t[$i], "\t", $names[$i], "\n";
}
?>
```

> **Notice:** Returning an array from a subprogram is as easy as returning a simple variable.

## 41.5 Default Argument Values (Optional Arguments)

If you assign a default value to an argument within the formal argument list, it means that if no value is passed for that argument, the default value is used. In the next example, the function `prepend_title()` prepends a title before the name. However, if no value for argument `$title` is passed, the function uses the default value “Mr.”

```php
<?php
function prepend_title($name, $title = "Mr") {
    return $title . " " . $name;
}

echo prepend_title("John King");        //It displays Mr John King
echo prepend_title("Maria Miller", "Ms"); //It displays Ms Maria Miller
?>
```

> **Notice:** When a default value is assigned to an argument within the formal argument list, this argument is called an optional argument.

Within the formal argument list, any optional arguments should be on the right side of any non-optional arguments; to do the opposite of this would be incorrect. Consider the following example, in which the optional argument `$title` is written before the non-optional argument `$name` in the formal argument list.

```php
<?php
function prepend_title($title = "Mr", $name) {
    return $title . " " . $name;
}

echo prepend_title("Vassilis Bouras");
?>
```
