$names = array(array());

$names[1][0] = "Sally";
$names[1][1] = "Angelina";

11. The following statement adds the name “Sally” to the row with index 1.

$names = array(array("John", "George"),

12. The following code fragment displays the name “Sally” on the screen.

$names = array();
$k = 0;
$names[0][$k] = "John";
$k++;
$names[0][$k] = "George";
$names[1][$k] = "Sally";
$k--;
$names[1][$k] = "Angelina";

$grades = array(array("B+", "A+"),
array("A", "C-"));

$values = array(array(1, 0),
