# Exercise 29.9-3    *Converting the PHP Script*

Rewrite the following PHP script using the pre-test loop structure.

```
```php
<?php
$a = 0;

do {
    echo $a;
    $b = trim(fgets(STDIN));
    $a = $a + $b;
} while ($a < 1000);
?>
```
```

# Solution

Following the conversion rule, the PHP script using the pre-test loop structure becomes

```
```php
<?php
$a = 0;

echo $a;
$b = trim(fgets(STDIN));
$a = $a + $b;
while ($a < 1000) {
    echo $a;
    $b = trim(fgets(STDIN));
    $a = $a + $b;
}
