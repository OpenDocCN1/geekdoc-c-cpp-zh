# Chapter 9
Using NetBeans IDE

```
```php
<?php
echo "Enter your name: ";
$name = trim(fgets(STDIN));
echo "Hello " . $name . "\n";
echo "How do you do?";
?>
```
```

> **Remember!** You can execute a file by selecting “Run → Run File” from the main menu, or by hitting the SHIFT+F6 key combination.

Once you execute the script, the message “Enter your name:” is displayed in the “Output” window. The script waits for you to enter your name, as shown in **Figure 9–9**.

![](bbox=[0.045, 0.356, 0.982, 0.661])

**Figure 9–9** Viewing a prompt in the Output window

To enter your name, however, you must place the cursor inside the “Output” window. Then you can type your name and hit the “Enter ↵” key. Once you do that, PHP interpreter continues executing the rest of the statements. When execution finishes, the final output is as shown in **Figure 9–10**.
