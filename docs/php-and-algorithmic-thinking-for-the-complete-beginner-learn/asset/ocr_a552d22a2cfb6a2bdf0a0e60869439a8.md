# Solution

In this case, you don’t know the exact number of iterations, so you cannot use a counted loop structure. Let’s use a post-test loop structure instead, but, in order to make your script free of logic errors you should follow the “Ultimate” rule discussed in Chapter 29. According to this rule, the post-test loop structure should always be as follows, given in general form.

```
initialize $sum
do {
    A statement or block of statements
    Update/alter $sum
} while ( Boolean_Expression($sum) )
```
