# Solution

The formula has two different results.

+   1. When x is greater than or equal to zero, the value of y in $\dfrac{7+x}{x-3}+\dfrac{3-x}{x}$ can be found following the method shown in the previous exercise.
+   
+   2. However, for an x less than zero, a small detail can save you some lines of PHP code. If you look carefully, you can see that there are no restrictions on the fraction $\dfrac{40x}{x-5}$ because x can never be +5.
