> **Notice:** The program counter shows you, at any time, which statement is the next to be executed.

Click on the “Step into” icon on the toolbar. This action tells the PHP interpreter to execute the statement `$s = 0`, and the program counter moves to the second PHP statement, which is the next to be executed.

From the main menu, select “Window→Debugging→Variables”. In the window that appears, you can watch all the variables declared in main memory (RAM) and the value they contain during each step of execution. Until now, the only variable declared and assigned a value is the variable `$s` as shown in **Figure 9–15**.
