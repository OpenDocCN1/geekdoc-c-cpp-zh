## Exercise 39.4-1 Back to Basics – Calculating the Sum of Two Numbers

Do the following:

i. Write a function named `sum()` that accepts two numeric values through its formal argument list and then calculates and returns their sum.

ii. Using the function `sum()` cited above, write a PHP script that lets the user enter two numbers and then displays their sum. Next, create a trace table to determine the values of the variables in each step of the PHP script for two different executions.

The input values for the two executions are: (i) 2, 4; and (ii) 10, 20.

## Solution

In this exercise you need to write a function that accepts two values from the caller (this is the main code) and then calculates and returns their sum. The solution is shown here.

```php
<?php

    function sum($a, $b) {
        $s = $a + $b;
        return $s;
    }

    $num1 = trim(fgets(STDIN));
    $num2 = trim(fgets(STDIN));

    $result = sum($num1, $num2);
    echo "The sum of ", $num1, " + ", $num2, " is ", $result;
?>
```

Now, let’s create the corresponding trace tables. Since you have become more experienced with them, the column “Notes” has been removed.

## Exercise 39.4-2 Calculating the Sum of Two Numbers Using Fewer Lines of Code!

Rewrite the PHP script of the previous exercise using fewer lines of code.

### Solution

The solution is shown here.

```php
<?php
function sum($a, $b) {
    return $a + $b;
}

$num1 = trim(fgets(STDIN));
$num2 = trim(fgets(STDIN));

echo "The sum of ", $num1, " + ", $num2, " is ", sum($num1, $num2);
?>
```

Contrary to the solution of the previous exercise, in this function `sum()` the sum is not assigned to variable `$s` but it is directly calculated and returned. Furthermore, this main code doesn't assign the returned value to a variable but directly displays it.

> Notice: User-defined functions can be called just like the built-in functions of PHP.
