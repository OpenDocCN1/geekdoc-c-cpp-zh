
## Exercise 29.5-1 Cleaning Out the Loop

The following code fragment calculates the average value of numbers 1, 2, 3, 4, ... 10000. Try to move as many statements as possible outside the loop to make the script more efficient.

```php
$s = 0;
for ($i = 1; $i <= 10000; $i++) {
    $s = $s + $i;
    $average = $s / 10000;
}
echo $average;
```

## Solution

One very common mistake that novice programmers make when calculating average values is to put the statement that calculates the average inside the loop. Think about it! Imagine that you want to calculate your average grade in school. Your first step would be to calculate the sum of the grades for all of the courses that you’re taking. Then, when all your grades have been summed up, you would divide that sum by the number of courses that you’re taking.

> **Notice:** Calculating an average is a two-step process.

Therefore, it is pointless to calculate the average value inside the loop. You can move this statement outside and right after the loop, and leave the loop just to sum up the numbers as follows.

```php
$s = 0;
for ($i = 1; $i <= 10000; $i++) {
    $s = $s + $i;
}
$average = $s / 10000;
echo $average;
```

## 29.7 Converting from a Counted Loop Structure to a Pre-Test Loop Structure

The conversion from a counted loop structure to a pre-test loop structure is quite easy. All you need to do is get the `counter` variable of the `for` statement and use it within the `while` statement, as follows.

### Counted Loop Structure

```
for (counter = initial_value; counter OP1 final_value; counter = counter OP2 offset) {
    A statement or block of statements
}
```

![](img/4d9a992abc5da7946ac44f9e6bf1d032_449_0.png)

### Pre-Test Loop Structure

```
counter = initial_value;
while (counter OP1 final_value) {
    A statement or block of statements
    counter = counter OP2 offset;
}
```

where

- `counter` must always be a variable.
- `initial_value`, `final_value`, and `offset` can be a constant value or even a variable or an expression.
- `OP1` must be `<=` when counter increments and `>=` when counter decrements.
- `OP2` must be `+` when counter increments and `−` when counter decrements.

> **Remember!** Be careful not to forget to include the statement that increments or decrements the `counter` variable at the end of the pre-test loop structure, because otherwise the loop will iterate endlessly!

## 29.8 Converting from a Pre-Test Loop Structure to a Counted Loop Structure

In PHP, the conversion from a pre-test loop structure to a counted loop structure can be done very easily for any form of the while statement. However, you will need to be aware that in computer programming languages other than PHP, such as Visual Basic, Pascal, and Delphi (to name a few) you can do this type of conversion, but only under certain circumstances. Throughout the rest of this chapter, you will encounter situations in which conversion should not always be carried out.

Following is the general form of the pre-test loop structure, in which conversion can actually be carried out in the majority of the programming languages.

### Pre-Test Loop Structure

```
counter = initial_value;
while (counter OP3 final_value1) {
    A statement or block of statements 1
    counter = counter OP2 offset;
    A statement or block of statements 2
}
```

![](img/4d9a992abc5da7946ac44f9e6bf1d032_452_0.png)

### Counted Loop Structure

```
for (counter = initial_value; counter OP1 final_value2; counter = counter OP2 offset)
{
    A statement or block of statements 1
    A statement or block of statements 2
}
```

where

- `counter` must always be a variable.
- `initial_value`, `final_value1`, `final_value2`, and `offset` can be a constant value or even a variable or an expression. In the case of a variable or an expression, however, the content or the result correspondingly must be invariable inside the loop.
- **OP1** must be `<=` when *counter* increments and `>=` when *counter* decrements.
- **OP2** must be `+` when *counter* increments and `−` when *counter* decrements.
- **OP3** can be any comparison operator (<, >, <=, >=, ==, !=).
- any existing *counter* variable inside statement or block of statements 2 must be replaced by the expression *counter OP2 offset*.

Surely you are a little bit confused right now. Don’t be! The next examples will help you put things in order.

## Tips and Tricks with Loop Control Structures

Following is the script of the exercise, written again, with some notes on it.

```php
<?php
    $s = 0;
    $y = 0;

    while ($y != -3) {
        $s = $s + 2 * $y;
        $y = $y - 2;
    }

    echo $s;
?>
```

![](img/4d9a992abc5da7946ac44f9e6bf1d032_455_0.png)

Some extra notes:

- Since `counter` decrements, `OP1` must be `>=`.
- Since `offset` is 2 and variable `$y` decrements, and since the loop’s Boolean expression is `$y != -3`, it becomes clear that the last value of `$y` for which the pre-test loop structure performs an iteration is the value -1. Thus, `final_value2` must be -1.
- Inside statement or block of statements 1, variable `counter` must remain as is.

Now, with everything clarified, the PHP script can be rewritten using the counted loop structure.

```php
<?php
    $s = 0;
    for ($y = 5; $y >= -1; $y = $y - 2) {
        $s = $s + 2 * $y;
    }
    echo $s;
?>
```
