# Trace Tables

i. For the input value of 0.3, the trace table looks like this.

| Step | Statement | Notes | $a | $b | $c |
|---:|---|---|---:|---:|---:|
| 1 | `$b = trim(fgets(STDIN))` | User enters value 0.3 | ? | **0.3** | ? |
| 2 | `$c = 3` |  | ? | 0.3 | **3** |
| 3 | `$c = $c * $b` |  | ? | 0.3 | **0.9** |
| 4 | `$a = 10 * $c % 10` |  | **9** | 0.3 | 0.9 |
| 5 | `echo $a` | The value 9 is displayed |  |  |  |
