# 3.4 How to Set Up NetBeans IDE

In order to install NetBeans IDE, you must download it, free of charge, from the following address:

https://netbeans.org/downloads/index.html

On the NetBeans web page, there is a dropdown list that lets you choose the required platform (Windows, Linux, or Mac OS X). Choose the platform that matches yours. This book shows the process of installing NetBeans IDE on a Windows platform.

From all the “download bundles” available on netbeans.org, select and download the one called “All.” When the download is complete, run the corresponding installer.

If you receive the message shown in Figure 3-3, it means that the Java SE Development Kit (JDK) was not found on your system. Please visit the displayed address to download and install the JDK before proceeding with the NetBeans IDE installation.
