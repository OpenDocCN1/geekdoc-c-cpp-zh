# 20.1 What are Nested Decision Control Structures?

Nested decision control structures are decision control structures that are “nested” (enclosed) within a path of another decision control structure. This means that one if statement can nest (enclose) another if statement, and the nested if statement can nest (enclose) another if statement, and so on. There are no practical limitations to how deep this nesting can go. As long as the syntax rules are not violated, you can nest as many decision control structures as you wish. For practical reasons however, as you move to three or four levels of nesting, the entire decision structure becomes very complex and difficult to understand. So, try to keep your code as simple as possible by breaking large nested decision control structures into multiple smaller ones, or by using other types of decision control structures.

An example of a nested decision control structure is shown here.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_237_0.png)

This can be rearranged to become

![](img/4d9a992abc5da7946ac44f9e6bf1d032_237_1.png)

and the PHP script is shown here.

```
if ($x < 30) {
    if ($x < 15) {
        $y = $y + 2;
    }
    else {
        $y--;
    }
}
else {
    $y++;
}
```

You can even nest case decision structures inside dual-alternative decision structures.

```php
<?php
echo "Enter a number: ";
$x = trim(fgets(STDIN));

if ($x < 1 || $x > 3) {
    echo "Invalid Number";
}
else {
    switch ($x) {
        case 1:
            echo "1st choice selected";
            break;
        case 2:
            echo "2nd choice selected";
            break;
        case 3:
            echo "3rd choice selected";
            break;
    }
}
?>
```

This is a nested case decision structure

*Notice:* Please note that keyword default is missing from the switch statement.

In general, you can nest any control structure inside any other control structure as long as you keep them syntactically and logically correct. However, you should always try to keep your script as simple as possible because complex code may lead to invalid results.

# Exercise 20.1-1 Trace Tables and Nested Decision Control Structures

Create a trace table to determine the values of the variables in each step of the next PHP script for three different executions.
The input values for the three executions are (i) 13, (ii) 18, and (iii) 30.

```php
<?php
    $x = trim(fgets(STDIN));
    $y = 10;

    if ($x < 30) {
        if ($x < 15) {
            $y = $y + 2;
        }
        else {
            $y--;
        }
    }
    else {
        $y++;
    }

    echo $y;
?>
```

# Solution

i. For the input value of 13, the trace table looks like this.

| Step | Statement | Notes | $x | $y |
|---:|---|---|---:|---:|
| 1 | `$x = trim(fgets(STDIN));` | User enters the value 13 | **13** | ? |
| 2 | `$y = 10;` |  | 13 | **10** |
| 3 | `if ($x < 30)` | This evaluates to true |  |  |
| 4 | `if ($x < 15)` | This evaluates to true |  |  |
| 5 | `$y = $y + 2;` |  | 13 | **12** |
| 6 | `echo $y;` | The value 12 is displayed |  |  |

ii. For the input value of 18, the trace table looks like this.

| Step | Statement | Notes | $x | $y |
|---:|---|---|---:|---:|
| 1 | `$x = trim(fgets(STDIN));` | User enters the value 18 | **18** | ? |
| 2 | `$y = 10;` |  | 18 | **10** |
| 3 | `if ($x < 30)` | This evaluates to true |  |  |
| 4 | `if ($x < 15)` | This evaluates to false |  |  |
| 5 | `$y--;` |  | 18 | 9 |
| 6 | `echo $y;` | The value 9 is displayed |  |  |

iii. For the input value of 30, the trace table looks like this.

| Step | Statement | Notes | $x | $y |
|---|---|---|---|---|
| 1 | `$x = trim(fgets(STDIN));` | User enters the value 30 | 30 | ? |
| 2 | `$y = 10;` |  | 30 | 10 |
| 3 | `if ($x < 30)` | This evaluates to false |  |  |
| 4 | `$y++;` |  | 30 | 11 |
| 5 | `echo $y;` | The value 11 is displayed |  |  |

# Exercise 20.1-2 Positive, Negative or Zero?

Design a flowchart and write the corresponding PHP script that lets the user enter a number from the keyboard and then displays the messages “Positive”, “Negative”, or “Zero” depending on whether the given value is greater than, less than, or equal to zero.

# Solution

The flowchart is shown here.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_240_0.png)

This PHP script can be written using either a nested decision control structure or a multiple-alternative decision structure. Let’s try them both!

# First approach – Using a nested decision control structure

file_20.1-2a.php

```php
<?php
$a = trim(fgets(STDIN));

if ($a > 0) {
    echo "Positive";
}
else {
    if ($a < 0) {
        echo "Negative";
    }
    else {
        echo "Zero";
    }
}
?>
```

# Second approach – Using a multiple-alternative decision structure

file_20.1-2b.php

```php
<?php
$a = trim(fgets(STDIN));

if ($a > 0) {
    echo "Positive";
}
elseif ($a < 0) {
    echo "Negative";
}
else {
    echo "Zero";
}
?>
```
