# Nested Loop Control Structures

![](bbox=[0.052, 0.042, 0.899, 0.427])

If you try to follow the flow of execution in this flowchart fragment, you can see that when the inner loop completes all of its four iterations, variable i contains the value 0. Then, variable i increments by 1 and the outer loop repeats again. This process can continue forever since variable i can never exceed the value 3 that the Boolean expression of the outer loop requires. Therefore, the message “Hello” is displayed an infinite number of times.
