# 18.1 The Multiple-Alternative Decision Structure

The multiple-alternative decision structure is used to expand the number of alternatives, as shown in the following flowchart fragment.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_218_0.png)

When a multiple-alternative decision structure is executed, *Boolean Expression 1* is evaluated. If *Boolean Expression 1* evaluates to true, the corresponding statement or block of statements that immediately follows it is executed and the rest of the structure is skipped. In other words, the flow of execution continues to any remaining statements that may exist after the multiple-alternative decision structure. However, if *Boolean Expression 1* evaluates to false, the flow of execution evaluates *Boolean Expression 2*. If it evaluates to true, the corresponding statement or block of statements that immediately follows it is executed and the rest of the structure is skipped. This process continues until one Boolean expression evaluates to true or until no more Boolean expressions are left.

The last statement or block of statements N+1 is executed when none of the previous Boolean expressions has evaluated to true. Moreover, this last statement or block of statements N+1 is optional and can be omitted. It depends on the algorithm you are trying to solve.

The general form of the PHP statement is

```php
if (Boolean_Expression 1) {
    A statement or block of statements 1
}
elseif (Boolean_Expression 2) {
    A statement or block of statements 2
}
```

```text
}
elseif (Boolean_Expression 3) {
    A statement or block of statements 3
}
.
.
.
elseif (Boolean_Expression N) {
    A statement or block of statements N
}
else {
    A statement or block of statements N+1
}
```

As you already know, single statements can be written without being enclosed in braces {}. Thus, the if-elseif statement would become as shown here.

```text

    One Single Statement N
else
    One Single Statement N+1
```

Create a trace table to determine the values of the variables in each step for three different executions of the next PHP script. The input values for the three executions are (i) 5, 8; (ii) -13, 0; and (iii) 1, -1.

```php
<?php
$a = trim(fgets(STDIN));
$b = trim(fgets(STDIN));
```

```php
if ($a > 3)
    echo "Variable A greater than 3";
elseif ($a > 4 && $b <= 10) {
    echo "Variable A greater than 4 ";
    echo "and B less than or equal to 10";
}
elseif ($a * 2 == -26) {
    echo "Variable A times 2 is equal to -26";
    $b++;
}
elseif ($b == 1)
    echo "Variable B is equal to 1";
else
    echo "Display this when none of the above evaluates to true";

echo "The end!";
?>
```

> **Notice:** Please note that you can use braces `{ }` only when necessary.

| Step | Statement | Notes | $a | $b |
|---:|---|---|---:|---:|
| 1 | `$a = trim(fgets(STDIN))` | User enters the value 5 | **5** | ? |
| 2 | `$b = trim(fgets(STDIN))` | User enters the value 8 | 5 | **8** |
| 3 | `if ($a > 3)` | This evaluates to true |  |  |
| 4 | `echo "Variable A greater ...` | The message "Variable A greater than 3" is displayed |  |  |
| 5 | `echo "The end!"` | The message "The end!" is displayed |  |  |

> **Notice:** Please note that even though the second Boolean expression `($a > 4 && $b <= 10)` could also have evaluated to true, it was not checked.

- ii. For the input values of -13 and 0, the trace table looks like this.

| Step | Statement | Notes | $a | $b |
|---:|---|---|---:|---:|
| 1 | `$a = trim(fgets(STDIN))` | User enters the value -13 | **-13** | ? |
| 2 | `$b = trim(fgets(STDIN))` | User enters the value 0 | -13 | **0** |
| 3 | `if ($a > 3)` | This evaluates to false |  |  |

> Notice: Please note that after step 7 the fourth Boolean expression ($b == 1) could also have evaluated to true, but it was not checked.
