# # Exercise 36.2-3 Designing the Flowchart

Design the flowchart that corresponds to the following PHP script.

```
```php
<?php
define("ROWS", 20);
define("COLUMNS", 10);

$a = array(array());
for ($i = 0; $i <= ROWS - 1; $i++) {
    for ($j = 0; $j <= COLUMNS - 1; $j++) {
        $a[$i][$j] = trim(fgets(STDIN));
    }
}

$max = $a[0][0];
```
