# # Exercise 30.2-5 Designing the Flowchart

Design the flowchart that corresponds to the following PHP script.

```
<?php
$a = trim(fgets(STDIN));

switch ($a) {
case 1:
for ($i = 1; $i <= 9; $i += 2) {
echo $i;
}
break;
case 2:
for ($i = 9; $i >= 1; $i -= 2) {
echo $i;
}
break;
default:
echo "Nothing to do!";
}
echo "The End!";
?>
```
