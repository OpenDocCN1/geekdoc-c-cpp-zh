# # 40.3 Formal and Actual Procedure Arguments

Each procedure contains an argument list called a formal argument list. As already stated, arguments in this list are optional. The formal argument list may contain no arguments, one argument, or more than one argument.

When the procedure is called, an argument list is passed to the procedure. This list is called the actual argument list.

In the next example, the variables `$number1`, `$number2`, `$number3`, and `$number4` constitute the formal argument list whereas variables `$a`, `$b`, `$c`, and `$d` constitute the actual argument list.

```
```php
<?php
function add_and_display( [$number1, $number2, $number3, $number4] ) {
    $result = $number1 + $number2 + $number3 + $number4;
    echo $result;
}

$a = trim(fgets(STDIN));
$b = trim(fgets(STDIN));
$c = trim(fgets(STDIN));
$d = trim(fgets(STDIN));

add_and_display( [$a, $b, $c, $d] );
?>
```
```

> > **Remember!** There is a one-to-one match between the formal and the actual arguments. The value of argument `$a` is passed to argument `$number1`, the value of argument `$b` is passed to argument `$number2`, and so on.
