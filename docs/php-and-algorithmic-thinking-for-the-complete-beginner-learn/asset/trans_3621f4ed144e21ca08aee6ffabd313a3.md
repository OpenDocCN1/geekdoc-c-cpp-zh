# 28.2 适用于嵌套循环的规则

除了适用于计数循环结构的四条规则之外，编写带有嵌套循环的脚本时，还应始终遵循两条额外规则，因为它们可以帮助你避免不良的副作用。

+   ➢ **规则 1：** 内层循环必须完全位于外层循环的开始和结束之内，这意味着循环不能重叠。
+   ➢ **规则 2：** 外层循环和内层（嵌套）循环不能使用相同的 *计数器* 变量。

本章致力于教你一些有用的技巧和窍门，可以帮助你编写“更好”的代码。当你设计自己的算法，甚至自己的 PHP 脚本时，应始终牢记这些内容。
