## Exercise 40.4-2 A Simple Currency Converter

Do the following:

- i. Write a procedure named `display_menu()` that displays the following menu.

  1. Convert USD to Euro (EUR)
  2. Convert Euro (EUR) to USD
  3. Exit

- ii. Using the procedure `display_menu()` cited above, write a PHP script that displays the previously mentioned menu and prompts the user to enter a choice (of 1, 2, or 3) and an amount of money. The script should then calculate and display the required value. The process should repeat as many times as the user wishes. It is given that $1 = 0.72 EUR (€).

### Solution

The solution is very simple and needs no further explanation.

```php
<?php
function display_menu() {
    echo "1. Convert USD to Euro (EUR)\n";
    echo "2. Convert Euro (EUR) to USD\n";
    echo "3. Exit\n";
    echo "----------------------------------\n";
    echo "Enter a choice: ";
}

do {
    display_menu();
    $choice = trim(fgets(STDIN));
    if ($choice == 3) {
        echo "Bye!";
    }
    else {
        echo "Enter an amount: ";
        $amount = trim(fgets(STDIN));
        if ($choice == 1) {
            echo $amount, " USD = ", $amount * 0.72, " Euro\n";
        }
        else {
            echo $amount, " Euro = ", $amount / 0.72, " USD\n";
        }
    }
} while ($choice != 3);
?>
```

## 41.1 Can Two Subprograms use Variables of the Same Name?

You should realize something: each subprogram uses its own memory space to hold the values of its variables. Even the main code has its own memory space! This means that you can have a variable named `$test` in main code, another variable named `$test` in a subprogram, and yet another variable named `$test` in another subprogram. Pay attention! Those three variables are three completely different variables, in different memory locations, and they can hold completely different values.

The trace table in the following example can help you understand what really goes on.

```php
<?php
function f1() {
    $test = 22;
    echo $test;
    return true;
}
function f2($test) {
    echo $test;
}

$test = 5;
echo $test;
$ret = f1();
f2(10);
echo $test;
?>
```

The trace table is shown here.

| Step | Statement | Notes | Main Code | | Function f1() | Procedure f2() |
|---|---|---|---|---|---|---|
| | | | $test | $ret | $test | $test |
| 1 | $test = 5 | | 5 | ? | | |
| 2 | echo $test | Value 5 is displayed | 5 | ? | | |
| 3 | $ret = f1() | f1() is called | | | ? | |
| 4 | $test = 22 | | | | 22 | |
| 5 | echo $test | Value 22 is displayed | | | 22 | |
| 6 | return true | It returns to the main code | 5 | true | | |
