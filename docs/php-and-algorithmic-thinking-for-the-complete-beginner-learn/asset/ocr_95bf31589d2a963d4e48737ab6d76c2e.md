Assume that the user enters a country to search for, and the binary search algorithm finds that country, for example, at index position 2 of array `$country_names`. The script can then use this value of 2 as a column index for the array `$event_descriptions`, and it will display all the event descriptions of column 2.

The PHP script is as follows.

```
```php
<?php
define("EVENTS", 20);
define("COUNTRIES", 10);

$country_names = array();
$event_descriptions = array(array());
for ($j = 0; $j <= COUNTRIES - 1; $j++) {
    echo "Enter Country No. ", $j + 1, ": ";
    $country_names[$j] = trim(fgets(STDIN));
    for ($i = 0; $i <= EVENTS - 1; $i++) {
        echo "Enter description for event No. ", $i + 1, ": ";
        $event_descriptions[$i][$j] = trim(fgets(STDIN));
    }
}

echo "Enter a country to search: ";
$needle = strtolower(trim(fgets(STDIN)));

$left = 0;
$right = EVENTS - 1;
