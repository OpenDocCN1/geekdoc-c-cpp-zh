# More Exercises with Decision Control Structures

The PHP script is shown here.

```
```php
<?php
echo "Enter a value for x: ";
$x = trim(fgets(STDIN));

if ($x > -5 && $x <= 0) {
    if ($x != -1) {
        $y = $x / ($x - 3) + (0 + $x) / ($x + 1);
        echo $y;
    }
    else {
        echo "Invalid value";
    }
}
elseif ($x > 0 && $x <= 6) {
    $y = 40 * $x / ($x - 8);
    echo $y;
}
elseif ($x > 6 && $x <= 20) {
    if ($x != 9) {
        $y = 3 * $x / ($x - 9);
        echo $y;
    }
    else {
        echo "Invalid value";
    }
}
else {
    $y = abs($x);
    echo $y;
}
?>
```
