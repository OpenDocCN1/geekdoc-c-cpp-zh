```php
<?php
define("PEOPLE", 20);

$first_names = array();
$last_names = array();
for ($i = 0; $i <= PEOPLE - 1; $i++) {
    echo "Enter first name: ";
    $first_names[$i] = trim(fgets(STDIN));
    echo "Enter last name: ";
    $last_names[$i] = trim(fgets(STDIN));
}

echo "Enter a first name to search: ";
$needle = trim(fgets(STDIN));

$found = false;
for ($i = 0; $i <= PEOPLE - 1; $i++) {
    if (strtoupper($first_names[$i]) == strtoupper($needle)) {
        echo $last_names[$i], "\n";
        $found = true;
    }
}

if ($found == false) {
    echo "No one found!";
}
?>

> **Notice:** Even though it is not very clear in the wording of the exercise, it is true that the array `$first_names` may contain a value multiple times. How rare is it to meet two people named “John,” for example?

> **Notice:** Since the script works with alphanumeric data, the `strtoupper()` function is required so that the script can operate correctly for any given value. For example, if the value “John” exists in the array `$first_names` and the user wants to search for the value “JOHN,” the `strtoupper()` function ensures that the script finds all Johns.
