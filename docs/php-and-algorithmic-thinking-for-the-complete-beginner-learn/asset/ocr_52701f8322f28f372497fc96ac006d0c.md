# Solution

For the input value of 3, the trace table looks like this.

| Step | Statement | Notes | $a | $b | $c | $d |
|---|---|---|---|---|---|---|
| 1 | $a = trim(fgets(STDIN)) | User enters value 3 | 3 | ? | ? | ? |
| 2 | $b = a + 10 |  | 3 | 13 | ? | ? |
| 3 | $a = $b * ($a - 3) |  | 0 | 13 | ? | ? |
| 4 | $c = 3 * $b / 6 |  | 0 | 13 | 6.5 | ? |
| 5 | $d = $c * $c |  | 0 | 13 | 6.5 | 42.25 |
| 6 | $d-- |  | 0 | 13 | 6.5 | 41.25 |
| 7 | echo $d | The value 41.25 is displayed |  |  |  |  |
