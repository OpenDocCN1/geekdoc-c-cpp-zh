## 40.2 How Do You Call a Procedure?

You can call a procedure by just writing its name. The next example creates the procedure `display_line()` and the main code calls the procedure whenever it needs to display a horizontal line.

```php
<?php
function display_line() {
    echo "--------------------------------";
}

echo "Hello there!\n";
display_line();
echo "How do you do?\n";
display_line();
echo "What is your name?\n";
display_line();
?>
```

You can also pass (send) values to a procedure, as long as at least one argument exists in procedure’s parenthesis. In the next example, the procedure `display_line()` is called three times but each time a different value is passed through the variable `$length`, resulting in three printed lines of different length.

```php
<?php
function display_line($length) {
    for ($i = 1; $i <= $length; $i++) {
        echo "-";
    }
    echo "\n";
}

echo "Hello there!\n";
display_line(12);
echo "How do you do?\n";
display_line(14);
echo "What is your name?\n";
display_line(18);
?>
```

## 40.3 Formal and Actual Procedure Arguments

Each procedure contains an argument list called a formal argument list. As already stated, arguments in this list are optional. The formal argument list may contain no arguments, one argument, or more than one argument.

When the procedure is called, an argument list is passed to the procedure. This list is called the actual argument list.

In the next example, the variables `$number1`, `$number2`, `$number3`, and `$number4` constitute the formal argument list whereas variables `$a`, `$b`, `$c`, and `$d` constitute the actual argument list.

```php
<?php
function add_and_display( [$number1, $number2, $number3, $number4] ) {
    $result = $number1 + $number2 + $number3 + $number4;
    echo $result;
}

$a = trim(fgets(STDIN));
$b = trim(fgets(STDIN));
$c = trim(fgets(STDIN));
$d = trim(fgets(STDIN));

add_and_display( [$a, $b, $c, $d] );
?>
```

> **Remember!** There is a one-to-one match between the formal and the actual arguments. The value of argument `$a` is passed to argument `$number1`, the value of argument `$b` is passed to argument `$number2`, and so on.

## 40.4 How Does a Procedure Execute?

When the main code calls a procedure, the following steps are performed:

+   - The execution of the statements of the main code is interrupted.
+   - The values of the variables or the result of the expressions that exist in the actual argument list are passed (assigned) to the corresponding arguments (variables) in the formal argument list and the flow of execution goes to where the procedure is written.
+   - The statements of the procedure are executed.
+   - When the flow of execution reaches the end of the procedure, the flow of execution continues from where it was before calling the procedure.

In the next PHP script, the procedure `minimum()` accepts three arguments (numeric values) through its formal argument list and displays the lowest value.

```php
<?php

function minimum($val1, $val2, $val3) {
    $min = $val1;
    if ($val2 < $min) {
        $min = $val2;
    }
    if ($val3 < $min) {
        $min = $val3;
    }
    echo $min;
}

$a = trim(fgets(STDIN));
$b = trim(fgets(STDIN));
$c = trim(fgets(STDIN));

minimum($a, $b, $c);

echo "The end";
?>
```

When the PHP script starts running, the first statement executed is the statement `$a = trim(fgets(STDIN))` (this is considered the first statement of the script). Suppose the user enters the values 9, 6, and 8.

| Step | Statements of Main Code | $a | $b | $c |
|---:|---|---:|---:|---:|
| 1 | `$a = trim(fgets(STDIN))` | 9 | ? | ? |
| 2 | `$b = trim(fgets(STDIN))` | 9 | 6 | ? |
| 3 | `$c = trim(fgets(STDIN))` | 9 | 6 | 8 |

When a call to the procedure `minimum()` is made, the execution of the statements of the main code is interrupted and the values of the variables `$a`, `$b`, and `$c` are copied (assigned) to the corresponding arguments (variables) `$val1`, `$val2`, and `$val3`, and the flow of execution goes to where the procedure is written. Then the statements of the procedure are executed.

| Step | Statements of Procedure minimum() | $val1 | $val2 | $val3 | $min |
|---|---|---:|---:|---:|---:|
| 5 | `$min = $val1` | 9 | 6 | 8 | 9 |
| 6 | `if ($val2 < $min)` | This evaluates to true |  |  |  |
| 7 | `$min = $val2` | 9 | 6 | 8 | 6 |
| 8 | `if ($val3 < $min)` | This evaluates to false |  |  |  |
| 9 | `echo $min` | Value 6 is displayed |  |  |  |

When the flow of execution reaches the end of the procedure the flow of execution simply continues from where it was before calling the procedure.

| Step | Statements of Main Code | $a | $b | $c |
|---|---|---:|---:|---:|
| 10 | `echo "The end"` | The message “The end” is displayed. |  |  |

> **Notice:** Please note that at step 10 no values are returned from the procedure to the main code.
> 
> **Remember!** In PHP there are no real procedures. There are only functions that can behave like procedures and return no result. This type of function, in some computer languages like C, C++, C#, and Java are known as void functions.

# Solution

In this exercise you need to write a procedure that accepts a value from the caller (this is the main code) and then calculates and displays its absolute value. The solution is shown here.

```php
<?php

function display_abs($n) {
    if ($n < 0) {
        $n = (-1) * $n;
    }

    echo $n;
}

$a = trim(fgets(STDIN));
display_abs($a);       //This displays the absolute value of given number.
echo $a;              //This displays the initial number given.
?>
```
