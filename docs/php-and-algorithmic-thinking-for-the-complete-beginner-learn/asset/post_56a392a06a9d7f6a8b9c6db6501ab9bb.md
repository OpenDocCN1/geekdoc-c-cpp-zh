# 34.1 Creating Two-Dimensional Arrays in PHP

An array that can hold the grades of four lessons for three students is as follows.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_604_0.png)

**Notice**: A two-dimensional array has rows and columns. In this particular example, array grades has 3 rows and 4 columns.

Actually, PHP supports only one-dimensional arrays. But there is a trick that you can use to overcome this problem and create multidimensional arrays. You can create an array of arrays! Just imagine the array `$grades` as a one-column array with three positions, each of which contains a whole new array of four elements, as follows.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_604_1.png)

**Notice!** In PHP, a multidimensional array is actually an array of arrays! A two-dimensional array is an array of arrays, a three-dimensional array is an array of arrays of arrays, and so on.

**Remember!** In Chapter 5 you learned about the rules that must be followed when assigning names to PHP variables. Assigning names to PHP arrays follows exactly the same rules!

# Chapter 34 Two-Dimensional Arrays

As in one-dimensional arrays, there are several approaches to creating and adding values (elements) to a two-dimensional array. Let's try to create the array $grades using each of these approaches.

## First Approach

You can create an array in PHP using the following statement, given in general form,

```php
$array_name = array();
```

and then you can add a whole new array to one of its positions using the following statement, given in general form

```php
$array_name[index] = array(value0, value1, value2, ..., valueM);
```

where index is the index position in the array.

The following code fragment creates the array $grades and adds values to it.

```php
$grades = array();
$grades[0] = array("B+", "A+", "A", "C-");
$grades[1] = array("B", "A", "C", "A+");
$grades[2] = array("B", "B", "B-", "B+");
```

## Second Approach

You can create an array and add new arrays to its positions without using index, as shown in the following code fragment, given in general form.

```php
$array_name = array();
$array_name[] = array(value0-0, value0-1, value0-2, ..., value0-M);
$array_name[] = array(value1-0, value1-1, value1-2, ..., value1-M);
$array_name[] = array(value2-0, value2-1, value2-2, ..., value2-M);
...
$array_name[] = array(valueN-0, valueN-1, valueN-2, ..., valueN-M);
```

The next code fragment creates the array $grades and adds values to it.

```php
$grades = array();
$grades[] = array("B+", "A+", "A", "C-");
$grades[] = array("B", "A", "C", "A+");
$grades[] = array("B", "B", "B-", "B+");
```

> Notice: Please note that in this approach, index numbering starts at zero by default.

## Third Approach

Another way to create an array and directly add values to it is shown in the following PHP statement, given in general form.

```php
$array_name = array( array(value0-0, value0-1, value0-2, ..., value0-M),
                     array(value1-0, value1-1, value1-2, ..., value1-M),
                     array(value2-0, value2-1, value2-2, ..., value2-M),
                     ...
                     array(valueN-0, valueN-1, valueN-2, ..., valueN-M)
                   );
```

Thus, the array $grades can be created using the following statement.

```php
$grades = array( array("B+", "A+", "A", "C-"),
                 array("B", "A", "C", "A+"),
                 array("B", "B", "B-", "B+")
               );
```

## Fourth Approach

If you wish to create an array and directly add values to certain positions you can use
the following PHP statement, given in general form.

```php
$array_name = array( index0 => array(value0-0, value0-1, ..., value0-M),
                     index1 => array(value1-0, value1-1, ..., value1-M),
                     index2 => array(value2-0, value2-1, ..., value2-M),
                     ...
                     indexN => array(valueN-0, valueN-1, ..., valueN-M)
                   );
```

Thus, the array $grades can be created using the following statement.

```php
$grades = array( 0 => array("B+", "A+", "A", "C-"),
                 1 => array("B", "A", "C", "A+"),
                 2 => array("B", "B", "B-", "B+")
               );
```

In this approach, elements can also be in random order.

```php
$grades = array( 2 => array("B", "B", "B-", "B+"),
                 1 => array("B", "A", "C", "A+"),
                 0 => array("B+", "A+", "A", "C-")
               );
```

## Fifth Approach

Last but not least, if you wish to create an array and add values using one statement
for each, you can use the following PHP statement, given in general form.

```php
$array_name = array(array());
$array_name[0][0] = value0-0;
$array_name[0][1] = value0-1;
$array_name[0][2] = value0-2;
...
$array_name[0][M] = value0-M;
$array_name[1][0] = value1-0;
$array_name[1][1] = value1-1;
```
