+   27. Suppose there are two arrays, `$names` and `$SSNs`, that contain the names and the SSNs (Social Security Numbers) of 1000 U.S. citizens. Write a code fragment that prompts the user to enter a value (it can be either a name or an SSN) and then searches for and displays the names of all the people that have this name or this SSN.
