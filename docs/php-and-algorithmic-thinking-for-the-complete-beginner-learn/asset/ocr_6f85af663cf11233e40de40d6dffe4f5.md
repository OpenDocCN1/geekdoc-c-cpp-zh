```
<?php
$s = 0;
$count = 0;
for ($i = 1; $i <= 100; $i++) {
    $x = trim(fgets(STDIN));
    if ($x > 0) {
        $s = $s + $x;
        $count++;
    }
}
if ($count != 0) {
    echo $s / $count;
} else {
    echo "No numbers entered!";
}
?>
```

Notice: The if ($count != 0) statement is necessary, because there is a possibility that the user may enter negative values only. By including this check, the script prevents any division-by-zero errors and thereby satisfies the property of definiteness.
