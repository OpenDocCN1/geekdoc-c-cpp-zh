# Solution

The $y++ statement is executed when **either** variable $a is greater than 10 **or** variable $b is greater than 20. Therefore, you can rewrite the PHP script using an OR (||) logical operator.

```
<?php
$a = trim(fgets(STDIN));
$b = trim(fgets(STDIN));

$y = 0;

if ($a > 10 || $b > 20) {
    $y++;
}
else {
    $y--;
}

echo $y;
?>
```
