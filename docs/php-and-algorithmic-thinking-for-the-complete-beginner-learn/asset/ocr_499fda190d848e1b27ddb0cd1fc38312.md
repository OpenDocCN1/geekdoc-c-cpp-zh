# # 40.2 How Do You Call a Procedure?

You can call a procedure by just writing its name. The next example creates the procedure `display_line()` and the main code calls the procedure whenever it needs to display a horizontal line.

```
```php
<?php
function display_line() {
    echo "--------------------------------";
}

echo "Hello there!\n";
display_line();
echo "How do you do?\n";
display_line();
echo "What is your name?\n";
display_line();
?>
```
```

You can also pass (send) values to a procedure, as long as at least one argument exists in procedure’s parenthesis. In the next example, the procedure `display_line()` is called three times but each time a different value is passed through the variable `$length`, resulting in three printed lines of different length.

```
```php
<?php
function display_line($length) {
    for ($i = 1; $i <= $length; $i++) {
        echo "-";
    }
    echo "\n";
}

echo "Hello there!\n";
display_line(12);
echo "How do you do?\n";
display_line(14);
echo "What is your name?\n";
display_line(18);
?>
```
