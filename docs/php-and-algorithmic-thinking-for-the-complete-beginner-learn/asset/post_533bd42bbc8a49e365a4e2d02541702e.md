#### Exercise 23.1-1 Both Odds or Both Evens?

Write a PHP script that prompts the user to enter two integers and then displays a message indicating whether both numbers are odd or both are even; otherwise a message “Nothing special” is displayed.

# Solution

The PHP script is shown here.

```php
<?php
echo "Enter an integer: ";
$n1 = trim(fgets(STDIN));
echo "Enter a second integer: ";
$n2 = trim(fgets(STDIN));

if ($n1 % 2 == 0 && $n2 % 2 == 0) {
    echo "Both integers are evens";
}
elseif ($n1 % 2 != 0 && $n2 % 2 != 0) {
    echo "Both integers are odds";
}
else {
    echo "Nothing special!";
}
?>
```

In PHP, you can use the `is_numeric()` function to test whether or not a variable contains a numeric value. The PHP script is shown here.

```php
<?php

echo "Enter an integer: ";
$x = trim(fgets(STDIN));

if (is_numeric($x) == true) {
    if ($x % 5 == 0 && $x % 8 == 0) {
        echo $x, " is exactly divisible by 5 and by 8";
    }
    else {
        echo $x, " is not what you are looking for!";
    }
}
else {
    echo "Invalid Number";
}
?>
```

#### Exercise 23.1-3 Is it an Integer?

Write a PHP script that prompts the user to enter a number and then displays a message indicating whether the data type of this number is integer or real. Moreover, if the user enters a non-numeric character, an error message should be displayed.

(This exercise gives you some more practice in working with data validation.)

# Solution

It is well known that a number is considered an integer when it contains no fractional part. In PHP, you can use the function intval() to return the integer value of any real number. If the number given is equal to its integer value, then the number is considered an integer.

For example, if the user enters the integer 7, this number and its integer value, intval(7), are equal.

On the other hand, if the user enters the real number 7.3, this number and its integer value, intval(7.3), are not equal.

Now, suppose that variable $x contains a value entered by the user. The code fragment, without data validation, would look like this.

```php
if ($x == intval($x)) {
    echo $x, " is integer";
}
else {
    echo $x, " is real";
}
```

And now it’s time to handle data validation. All you must do is combine the previous PHP script with the following one.

```php
<?php
echo "Enter a number: ";
$x = trim(fgets(STDIN));

if (is_numeric($x) == true) {
    //Here goes the previous code fragment
}
else {
    echo "Invalid number";
}
?>
```

Thus, the final script looks like this.

file_23.1-3.php
```php
<?php
echo "Enter a number: ";
$x = trim(fgets(STDIN));

if (is_numeric($x) == true) {
    if ($x == intval($x)) {
        echo $x, " is integer";
    }
    else {
        echo $x, " is real";
    }
}
else {
    echo "Invalid Number";
}
?>
```

#### Exercise 23.1-4 Converting Gallons to Liters, and Vice Versa

Write a PHP script that displays the following menu:

+   1. Convert gallons to liters
+   2. Convert liters to gallons

The script prompts the user to enter a choice (1 or 2) and a quantity. Then, it calculates and displays the required value. It is given that

1 gallon = 3.785 liters

# Solution

The PHP script is shown here.

file_23.1-4.php
```php
<?php
define("COEFFICIENT", 3.785);

echo "1: Gallons to liters\n";
echo "2: Liters to gallons\n";
echo "Enter choice: ";
$choice = trim(fgets(STDIN));

echo "Enter quantity: ";
$quantity = trim(fgets(STDIN));

if ($choice == 1) {
    $result = $quantity * COEFFICIENT;
    echo $quantity, " gallons equal to ", $result, " liters";
}
else {
    $result = $quantity / COEFFICIENT;
    echo $quantity, " liters equal to ", $result, " gallons";
}
```

#### Exercise 23.1-6 Where is the Tollkeeper?

In a toll gate, there is an automatic system that recognizes whether the passing vehicle is a motorcycle, a car, or a truck. Write a PHP script that lets the user enter the type of the vehicle (M for motorcycle, C for car, and T for truck) and then displays the corresponding amount of money the driver must pay according to the following table.

| Vehicle Type | Amount to Pay |
|---|---|
| Motorcycle | $1 |
| Car | $2 |
| Track | $4 |

The only thing that you need to take care of in this exercise is the possibility that the user could enter zero for the divisor (the second number), and as you know from mathematics, division by zero is undefined.

The following PHP script uses the case decision structure to check the type of operation.

```php
<?php
echo "Enter 1st number: ";
$a = trim(fgets(STDIN));
echo "Enter type of operation: ";
$op = trim(fgets(STDIN));
echo "Enter 2nd number: ";
$b = trim(fgets(STDIN));

switch ($op) {
    case "+":
        echo $a + $b;
        break;
    case "-":
        echo $a - $b;
        break;
    case "*":
        echo $a * $b;
        break;
    case "/":
        if ($b == 0) {
            echo "Error: Division by zero";
        }
        else {
            echo $a / $b;
        }
        break;
}
?>
```
