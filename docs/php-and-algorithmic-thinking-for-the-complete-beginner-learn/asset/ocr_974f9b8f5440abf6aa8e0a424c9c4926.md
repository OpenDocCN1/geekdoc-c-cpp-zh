As you can see, since the initial value 5 of variable i is less than 10, the flow of execution enters the loop. Inside the loop, however, the statement i ← i − 1 eliminates the statement i ← i + 1 and this results in a non-incrementing variable i, which can never reach final_value 10. Thus, the loop performs an infinite number of iterations.

> **Remember!** You should never alter the value of counter variable inside the loop. The same applies to initial_value, final_value, and offset (in case they are variables and not constant values).
