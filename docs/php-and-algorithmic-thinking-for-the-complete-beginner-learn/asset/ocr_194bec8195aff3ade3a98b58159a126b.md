Now, let’s write the corresponding code fragment. To more easily understand the process, the “from inner to outer” method is used again. The following code fragment calculates the sum of the first column (column index 0) and stores the result in position 0 of the auxiliary array. Assume variable `$j` contains the value 0.

```
```php
$s = 0;
for ($i = 0; $i <= ROWS - 1; $i++) {
    $s += $a[$i][$j];
}
$sum[$j] = $s;
```
```

This script can equivalently be written as

```
```php
$sum[$j] = 0;
for ($i = 0; $i <= ROWS - 1; $i++) {
    $sum[$j] += $a[$i][$j];
}
```
```

Now, nesting this code fragment in a counted loop structure that iterates for all columns results in the following.

```
```php
$sum = array();
for ($j = 0; $j <= COLUMNS - 1; $j++) {
    $sum[$j] = 0;
    for ($i = 0; $i <= ROWS - 1; $i++) {
        $sum[$j] += $a[$i][$j];
    }
}
```
