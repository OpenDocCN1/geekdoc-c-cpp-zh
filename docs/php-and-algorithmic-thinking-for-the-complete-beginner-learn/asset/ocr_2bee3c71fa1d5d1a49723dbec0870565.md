The only thing that you need to take care of in this exercise is the possibility that the user could enter zero for the divisor (the second number), and as you know from mathematics, division by zero is undefined.

The following PHP script uses the case decision structure to check the type of operation.

```
```php
<?php
echo "Enter 1st number: ";
$a = trim(fgets(STDIN));
echo "Enter type of operation: ";
$op = trim(fgets(STDIN));
echo "Enter 2nd number: ";
$b = trim(fgets(STDIN));

switch ($op) {
    case "+":
        echo $a + $b;
        break;
    case "-":
        echo $a - $b;
        break;
    case "*":
        echo $a * $b;
        break;
    case "/":
        if ($b == 0) {
            echo "Error: Division by zero";
        }
        else {
            echo $a / $b;
        }
        break;
}
?>
