## 35.3  Processing Each Column Individually

Processing each column individually means that every column is processed separately and the result of each column (which can be the sum, the average value, and so on) can be used individually for further processing. Suppose you have the following 4 × 5 array.

|   | 0 | 1 | 2 | 3 | 4 |
|---|---:|---:|---:|---:|---:|
| 0 | 2 | 3 | 5 | 2 | 9 |
| 1 | 9 | 8 | 3 | 14 | 12 |
| 2 | 5 | 2 | 15 | 20 | 9 |
| 3 | 7 | 8 | 3 | 5 | 6 |

As before, let’s try to find the sum of each column individually. Yet again, there are two approaches that you can use. Both of these approaches iterate through columns.

### First Approach – Creating an auxiliary array

In this approach, the script processes each column individually and creates an auxiliary array in which each position stores the sum of one column. This approach gives you much flexibility since you can use this new array later in your script for further processing.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_637_0.png)

> **Notice:** The auxiliary array is shown at the bottom.

Now, let’s write the corresponding code fragment. To more easily understand the process, the “from inner to outer” method is used again. The following code fragment calculates the sum of the first column (column index 0) and stores the result in position 0 of the auxiliary array. Assume variable `$j` contains the value 0.

```php
$s = 0;
for ($i = 0; $i <= ROWS - 1; $i++) {
    $s += $a[$i][$j];
}
$sum[$j] = $s;
```

This script can equivalently be written as

```php
$sum[$j] = 0;
for ($i = 0; $i <= ROWS - 1; $i++) {
    $sum[$j] += $a[$i][$j];
}
```

Now, nesting this code fragment in a counted loop structure that iterates for all columns results in the following.

```php
$sum = array();
for ($j = 0; $j <= COLUMNS - 1; $j++) {
    $sum[$j] = 0;
    for ($i = 0; $i <= ROWS - 1; $i++) {
        $sum[$j] += $a[$i][$j];
    }
}
```

### Second Approach - Just find it and process it!

This approach, as previously shown, uses no auxiliary array; it just calculates and directly processes the sum. The code fragment is as follows.

```
for ($j = 0; $j <= COLUMNS - 1; $j++) {
    $sum = 0;
    for ($i = 0; $i <= ROWS - 1; $i++) {
        $sum += $a[$i][$j];
    }
    process $sum;
}
```

Accordingly, the following code fragment calculates and displays the average value of each column.

```
for ($j = 0; $j <= COLUMNS - 1; $j++) {
    $sum = 0;
    for ($i = 0; $i <= ROWS - 1; $i++) {
        $sum += $a[$i][$j];
    }
    echo $sum / ROWS;
}
```
