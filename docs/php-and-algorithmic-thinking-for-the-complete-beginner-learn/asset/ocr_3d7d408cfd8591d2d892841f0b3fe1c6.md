# 28.2  Rules that Apply to Nested Loops

Beyond the four rules that apply to counted loop structures, there are two extra rules that you should always follow when writing scripts with nested loops, since they can save you from undesirable side effects.

+   ➢ **Rule 1:** The inner loop must begin and end entirely within the outer loop, which means that the loops must not overlap.
+   
+   ➢ **Rule 2:** An outer loop and the inner (nested) loop must not use the same *counter* variable.
