# 4.12  Your First PHP Script

Converting a flowchart to a computer language such as PHP results in a PHP script. A PHP script is nothing more than a text file including PHP statements. PHP scripts can even be written in your text editor application! Keep in mind, though, that using NetBeans IDE to write PHP scripts is a much better solution due to all of its included features that can make your life easier.

A PHP script always begins and ends with the delimiters `<?php` and `?>`, respectively, as shown here.

```
```php
<?php

// PHP code goes here

?>
```
```

A PHP script is saved on your hard disk with the default .php file extension. Here is a very simple PHP script that displays just three messages on the screen.

```
```php
<?php
echo "Hello World!";
echo "Hallo Welt!";
echo "The End";
?>
```
```

> **Notice:** Please note that PHP requires that all statements be terminated with a semicolon.
