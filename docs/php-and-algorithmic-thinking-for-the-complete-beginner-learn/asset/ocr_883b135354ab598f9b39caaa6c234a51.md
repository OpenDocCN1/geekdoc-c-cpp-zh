# Exercise 29.7-2    *Converting the PHP Script*

Rewrite the following PHP script using the pre-test loop structure.

```
```php
<?php
    $f = trim(fgets(STDIN));
    $x = 3;

    for ($j = 20; $j >= $f; $j -= 5) {
        $x = $x / 2;
    }

    echo $x;
?>
```
```

# *Solution*

Here is the script of the exercise, written again, with some notes on it.

```
```php
<?php
    $final = trim(fgets(STDIN));
    $x = 3;

    for ($j = 20;       $j >= $f;       $j -= 5) {
        $x = $x / 2;
    }

    echo $x;
?>
```
