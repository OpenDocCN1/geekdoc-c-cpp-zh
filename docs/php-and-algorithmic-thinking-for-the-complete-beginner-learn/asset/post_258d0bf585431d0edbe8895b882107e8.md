## 21.8 Converting a Case Decision Structure to a Multiple-Alternative Decision Structure, and Vice Versa

Converting a case decision structure to a multiple-alternative decision structure is quite easy. All you need to do is get the variable or the expression that the switch statement evaluates and use it in the multiple-alternative decision structure for all cases.

### Case Decision Structure

```php
switch (var_expr) {
    case value-1:
        block of statements 1
        break;
    case value-2:
        block of statements 2
        break;
    case value-3:
        block of statements 3
        break;
    .
    .
    .
    case value-N:
        block of statements N
        break;
    default:
        block of statements N+1
}
```

![](img/4d9a992abc5da7946ac44f9e6bf1d032_269_0.png)

### Multiple-Alternative Decision Structure

```php
if (var_expr == value-1) {
    block of statements 1
}
elseif (var_expr == value-2) {
    block of statements 2
}
elseif (var_expr == value-3) {
    block of statements 3
}
.
.
.
elseif (var_expr == value-N) {
    block of statements N
}
else {
    block of statements N+1
}
```

> **Notice:** The opposite conversion (from multiple-alternative decision structure to case decision structure) is possible as long as the same variable or expression is evaluated for all paths. Moreover, this variable or expression should be tested in each path to determine if it is equal to the constant values `value-1`, `value-2`, and `value-N` respectively.
>
> **Notice:** Although there is an alternative form of the `switch` statement in PHP, it is beyond the scope of this book and so is purposely not mentioned.

## 21.9 Converting a Multiple-Alternative Decision Structure to Nested Decision Control Structures, and Vice Versa

The next PHP statements, given in general form, can help you easily convert from a multiple-alternative decision structure to nested decision control structures, and vice versa.

### Multiple-Alternative Decision Structure

```php
if (Boolean Expr 1) {
    block of statements 1
}
elseif (Boolean Expr 2) {
    block of statements 2
}
elseif (Boolean Expr 3) {
    block of statements 3
}
.
.
.
elseif (Boolean Expr N) {
    block of statements N
}
else {
    block of statements N+1
}
```

### Nested Decision Control Structures

```php
if (Boolean Expr 1) {
    block of statements 1
}
else {
    if (Boolean Expr 2) {
        block of statements 2
    }
    else {
        if (Boolean Expr 3) {
            block of statements 3
        }
        .
        .
        .
        else {
            if (Boolean Expr N) {
                block of statements N
            }
            else {
                block of statements N+1
            }
        }
    }
}
```

> **Notice:** The opposite conversion (from nested decision control structures to a multiple-alternative decision structure) is possible as long as the else keyword and the succeeding if statement (in the nested decision control structures) are side by side without any statements existing between them.
