# ### Solution

This exercise is quite simple. Without further explanation, the code fragment is shown here.

```
```php
function f1($n) {
    $s = 0;
    for ($i = 1; $i <= $n; $i++) {
        if ($i < $n / 2) {
            $s += pow($n, 2);
        } else {
            $s += pow($n, 3);
        }
    }
    return $s;
}
