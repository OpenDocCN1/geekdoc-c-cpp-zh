```php
<?php
$max = -460;
$m_name = "";
echo "Enter the name of a planet: ";
$name = trim(fgets(STDIN));
while (strtoupper($name) != "STOP") {
    echo "Enter its average temperature: ";
    $t = trim(fgets(STDIN));
    if ($t > $max) {
        $max = $t;
        $m_name = $name;
    }
echo "Enter the name of a planet: ";
$name = trim(fgets(STDIN));
}
if ($m_name != "") {
    echo "The hottest planet is: ", $m_name;
} else {
    echo "Nothing Entered!";
}
?>
```
```

> > Notice: The if ($m_name != "") statement is required because there is a possibility that the user could enter the word “STOP” right from the beginning.
```

```php
echo "Enter its average temperature: ";
```

    echo "Enter an average temperature greater than -459.67 degrees!\n";
    $t = trim(fgets(STDIN));
}
