```php
function div_mod($a, $b, &$int_quotient, &$int_remainder, &$ret_value) {
    $ret_value = true;
    if ($b == 0) {
        $ret_value = false;
    } else {
```

### Solution

This exercise is quite simple. Without further explanation, the code fragment is shown here.

```php
function f1($n) {
    $s = 0;
    for ($i = 1; $i <= $n; $i++) {
        if ($i < $n / 2) {
            $s += pow($n, 2);
        } else {
            $s += pow($n, 3);
        }
    }
    return $s;
}
```

# Solution

In this flowchart there is a function named `read_values()` and a procedure named `find_min_max()`. As you can see, the latter returns the values of variables `$max_i` and `$min_i` indirectly (they are passed by reference). The PHP script is as follows.

```php
<?php

define("ELEMENTS", 100);

function read_values() {
    for ($i = 0; $i <= ELEMENTS - 1; $i++) {
        $values[$i] = trim(fgets(STDIN));
    }
    return $values;
}

function find_min_max($values, &$min_i, &$max_i) {
    $min_i = 0;
    $max_i = 0;
    for ($i = 1; $i <= ELEMENTS - 1; $i++) {
        if ($values[$i] < $values[$min_i]) {
            $min_i = $i;
        }
        if ($values[$i] > $values[$max_i]) {
            $max_i = $i;
        }
    }
}

$v = read_values();
find_min_max($v, $min_i, $max_i);
echo $v[$min_i], $v[$max_i];
?>
```

> **Notice:** Please study the way the procedure `find_min_max()` finds the index positions of the minimum and the maximum values of the array `$values`. This method is not the same as the one you learned in Chapter 37; however, it can be used as an alternative.
