4. To force a user to enter only positive numbers, without displaying any error messages, you can use the following code fragment.

```
do {
echo "Enter a positive number: ";
$x = trim(fgets(STDIN));
} while (is_numeric($x) != true || $x <= 0);
```

5. To force a user to enter numbers between 1 and 10, you can use the following code fragment.

```
echo "Enter a number between 1 and 10: ";
$x = trim(fgets(STDIN));
while (is_numeric($x) == true && $x >= 1 && $x <= 10) {
echo "Wrong number \n";
echo "Enter a number between 1 and 10: ";
$x = trim(fgets(STDIN));
}
```

6. When a PHP script is used to find the maximum value among 10 given values, the loop control structure that is used must always iterate 9 times.

7. In order to find the lowest number among 10 numbers given, you can use the following code fragment.

```
$min = 0;
for ($i = 1; $i <= 10; $i++) {
$w = trim(fgets(STDIN));
if ($w < $min)
$min = $w;
}
```

8. In order to find the highest number among 10 positive numbers given, you can use the following code fragment.

```
$max = 0;
for ($i = 1; $i <= 10; $i++) {
$w = trim(fgets(STDIN));
if ($w > $max) {
$max = $w;
}
}
```
