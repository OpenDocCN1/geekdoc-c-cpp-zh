# 15.7 如何否定布尔表达式

否定是反转布尔表达式含义的过程。有两种方法可用于否定布尔表达式。

## 第一种方法

第一种方法是最简单的一种。只需在原始布尔表达式前使用 NOT 运算符 (`!`)，你的否定布尔表达式就准备好了！例如，

如果原始布尔表达式是 `$x > 5 && $y == 3`，
则否定的布尔表达式变为 `!($x > 5 && $y == 3)`。

> **注意：** 请注意，整个表达式必须用括号括起来。如果你没有使用括号而写成 `!$x > 5 && $y == 3`，那就完全错误了。在这种情况下，NOT 运算符 (`!`) 只会否定第一个布尔表达式 `$x > 5`。

## 第二种方法

第二种方法稍微复杂一些，但不难学习。你只需根据以下表格否定每个运算符即可。

| 原始运算符 | 否定运算符 |
|---|---|
| `==` | `!=` |
| `!=` | `==` |
| `>` | `<=` |
| `<` | `>=` |
| `<=` | `>` |
| `>=` | `<` |
| `&&` | `||` |
| `||` | `&&` |
| `!` | `!` |

> **注意：** 请注意，NOT 运算符 (`!`) 保持不变。

例如，
如果原始布尔表达式是 `$x > 5 && $y == 3`，
则否定的布尔表达式变为 `$x <= 5 || $y != 3`。

# Exercise 15.7-1 — *否定布尔表达式*

*使用两种方法否定以下布尔表达式。*

+   i. `$b != 4`
+   ii. `$a * 3 + 2 > 0`
+   iii. `!($a == 5 && $b >= 7)`
+   iv. `$a == true`
+   v. `$b > 7 && !($x > 4)`
+   vi. `$a == 4 || $b != 2`

# 解答

## 第一种方法

+   i. `!($b != 4)`
+   ii. `!($a * 3 + 2 > 0)`
+   iii. `!(!($a == 5 && $b >= 7))`，或者等价的 `$a == 5 && $b >= 7`
+   iv. `!($a == true)`
+   v. `!($b > 7 && !($x > 4))`
+   vi. `!($a == 4 || $b != 2)`

> **注意：** 两次否定会得到肯定。也就是说，连续两个 NOT (`!`) 运算符会相互抵消。

## 第二种方法

+   i. `$b == 4`
+   ii. `$a * 3 + 2 <= 0`
+   iii. `!($a != 5 || $b < 7)`
+   iv. `$a != true`
+   v. `$b <= 7 || !($x <= 4)`
+   vi. `$a != 4 && $b == 2`

> **注意：** 请注意，算术运算符**不**被否定。千万不要*胆敢*将加号 (`+`) 替换为减号 (`-`) 运算符！

> **注意：** 请注意，NOT 运算符 (`!`) 保持不变。
