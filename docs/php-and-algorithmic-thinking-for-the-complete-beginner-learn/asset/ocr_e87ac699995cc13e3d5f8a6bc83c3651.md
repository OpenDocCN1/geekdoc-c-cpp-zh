# Exercise 22.2-4    *Designing the Flowchart*

*Design the flowchart that corresponds to the following PHP script.*

```
```php
<?php
    $a = trim(fgets(STDIN));
    if ($a < 0)
        $y = $a * 2;
    elseif ($a < 10)
        $y = $a / 2;
    elseif ($a < 100)
        $y = $a + 2;
    else {
        $b = trim(fgets(STDIN));
        $y = $a * $b;
        if ($y > 0)
            $y--;
        else
            $y++;
    }
    echo $y;
