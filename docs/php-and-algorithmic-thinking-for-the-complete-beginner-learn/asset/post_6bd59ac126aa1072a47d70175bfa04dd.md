# Second Approach – Rows for lessons, columns for students

In this approach, the two dimensional array should have 5 rows, one for every lesson
and 10 columns, one for every student. All other arrays can be placed in relation to
this two-dimensional array, as shown next.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_643_0.png)

Notice: The auxiliary array $count is created by the script and contains the number of
grades for each lesson that are greater than 89.

The solution is as follows.

```php
file_35.4-1b.php

<?php
define("STUDENTS", 10);
define("LESSONS", 5);

//Read names and grades together
$names = array();
$grades = array(array());
for ($j = 0; $j <= STUDENTS - 1; $j++) {
echo "Enter name for student No. ", $j + 1, ": ";
$names[$j] = trim(fgets(STDIN));
```

```php
for ($i = 0; $i <= LESSONS - 1; $i++) {
    echo "Enter grade No. ", $i + 1, " for ", $names[$j], ": ";
    $grades[$i][$j] = trim(fgets(STDIN));
}
}
//Create array $count
$count = array();
for ($j = 0; $j <= STUDENTS - 1; $j++) {
    $count[$j] = 0;
    for ($i = 0; $i <= LESSONS - 1; $i++) {
        if ($grades[$i][$j] > 89) {
            $count[$j]++;
        }
    }
}
//Displays the names of the students who have
//more than one grades greater than 89
for ($j = 0; $j <= STUDENTS - 1; $j++) {
    if ($count[$j] > 1) {
        echo $names[$j], "\n";
    }
}
?>
```

## 35.5 Creating a One-Dimensional Array from a Two-Dimensional Array

To more easily understand how to create a one-dimensional array from a two-dimensional array, let’s use an example.

Write a script that creates a one-dimensional array of 12 elements from a two-dimensional array of 3 × 4 as follows: The elements of the first column of the two-dimensional array should be placed in the first three positions in the one-dimensional array, the elements of the second column should be placed in the next three positions, and so on.

An example of a 3 × 4 array is as follows.

Accordingly, the new one-dimensional array will be as follows.

When the user enters data, the script can iterate, as usual, through rows but to create the new one-dimensional array, iterating through columns is more convenient. The PHP script is presented next.

# file_35.5.php

```php
<?php
define("ROWS", 3);
define("COLUMNS", 4);
define("ELEMENTS", ROWS * COLUMNS);

$a = array(array());
for ($i = 0; $i <= ROWS - 1; $i++) {
    for ($j = 0; $j <= COLUMNS - 1; $j++) {
        echo "Enter a value for element ", $i , ",", $j, ": ";
        $a[$i][$j] = trim(fgets(STDIN));
    }
}

$b = array();
$k = 0; //This is the index of the new array.
for ($j = 0; $j <= COLUMNS - 1; $j++) { //Iterate through columns
    for ($i = 0; $i <= ROWS - 1; $i++) {
        $b[$k] = $a[$i][$j];
        $k++;
    }
}

for ($k = 0; $k <= ELEMENTS - 1; $k++) {
    echo $b[$k], " ";
}
```

## 35.6 Creating a Two-Dimensional Array from a One-Dimensional Array

To more easily understand how to create a two-dimensional array from a one-dimensional array, let’s use an example.

Write a PHP script that creates a two-dimensional array of \(3 \times 4\) from a one-dimensional array of 12 elements as follow: The first three elements of the one-dimensional array should be placed in the first column of the two-dimensional array, the next three elements of the one-dimensional array should be placed in the next column of the two-dimensional array and so on.

An example of a \(3 \times 4\) array is as follows.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_646_0.png)

Accordingly, the new two-dimensional array will be as follows.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_646_1.png)

When the user enters data, the script can iterate, as usual, through rows but to create the new one-dimensional array, iterating through columns is more convenient. The PHP script is presented next.

```php
<?php
define("ROWS", 3);
define("COLUMNS", 4);
define("ELEMENTS", ROWS * COLUMNS);

$a = array();
for ($k = 0; $k <= ELEMENTS - 1; $k++) {
    echo "Enter a value for element ", $k, ": ";
    $a[$k] = trim(fgets(STDIN));
}

$b = array(array());
```

```php
$k = 0; //This is the index of array $a.
for ($j = 0; $j <= COLUMNS - 1; $j++) { //Iterate through columns
for ($i = 0; $i <= ROWS - 1; $i++) {
$b[$i][$j] = $a[$k];
$k++;
}
}
for ($i = 0; $i <= ROWS - 1; $i++) { //Iterate through rows
```
