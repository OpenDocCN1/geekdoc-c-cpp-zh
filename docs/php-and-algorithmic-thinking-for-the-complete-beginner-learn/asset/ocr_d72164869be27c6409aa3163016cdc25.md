# Exercise 28.2-2  *Counting the Total Number of Iterations*

*Find the number of times message “Hello” is displayed.*

```
for ($i = 1; $i <= 3; $i++) {
    for ($i = 5; $i >= 1; $i--) {
        echo "Hello";
    }
}
```

# Solution

This script breaks the second rule of nested loops, which states, “An outer loop and the inner (nested) loop must not use the same counter variable.”
