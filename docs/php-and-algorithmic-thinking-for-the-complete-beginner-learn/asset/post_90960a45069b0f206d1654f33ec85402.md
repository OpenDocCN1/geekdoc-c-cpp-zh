## Section 5

### Loop Control Structures

#### 24.1 What is a Loop Control Structure?

A loop control structure is a control structure that allows the execution of a statement or block of statements multiple times until a specified condition is met.

#### 24.2 From Sequence Control to Loop Control Structures

The next example lets the user enter four numbers and it then calculates and displays their sum. As you can see, there is no loop control structure yet, just the familiar sequence control structure.

```php
<?php

    $a = trim(fgets(STDIN));
    $b = trim(fgets(STDIN));
    $c = trim(fgets(STDIN));
    $d = trim(fgets(STDIN));

    $sum = $a + $b + $c + $d;

    echo $sum;
?>
```

This script is quite short—very short actually! However, think of an analogous script that lets the user enter 1000 numbers instead of four! Can you imagine copying and pasting the statement `trim(fgets(STDIN))` 1000 times? Wouldn’t it be much easier if you could write this statement only once but “tell” the computer to execute it 1000 times? Of course it would be! But for this you need a loop control structure!

However, if you want to use a loop control structure in this example, you need to modify this script a little. To do so, you have a riddle to solve: you are allowed to use only two variables, `$a` and `$sum`. Yes, you heard it! This script should prompt the user to enter four numbers and then it will calculate and display their sum, **but** it must do it with only two variables! Can you find a way? Hmmm... it’s obvious what you are thinking right now: “*The only thing that I can do with two variables is to read one single value in `$a` and then assign that value to `$sum`.*” Your thinking is quite correct, and it is presented here.

```php
$a = trim(fgets(STDIN));
$sum = $a;
```

which can equivalently be written as

```php
$sum = 0;

$a = trim(fgets(STDIN));
$sum = $sum + $a;
```

And now what? Now, there are three things that you can actually do, and these are: think, think, and of course, think!

The first number has been stored in variable `$sum`, so variable `$a` is now free for further use! Thus, you can reuse variable `$a` to read a second value which will also be accumulated in variable `$sum`, as follows.

```php
$sum = 0;

$a = trim(fgets(STDIN));
$sum = $sum + $a;

$a = trim(fgets(STDIN));
$sum = $sum + $a;
```

> **Notice:** Statement `$sum = $sum + $a` accumulates the value of `$a` to `$sum`. For example, if variable `$sum` contains the value 5 and variable `$a` contains the value 3, the statement `$sum = $sum + $a` assigns the **value 8** to variable `$sum`.

Since the second number has been accumulated in variable `$sum`, variable `$a` can be re-used! Of course, this process can go on again and again until all four numbers are read and accumulated in variable `$sum`. The final PHP script is as follows. Please note that this script does not use any loop control structure yet!

```php
<?php
    $sum = 0;

    $a = trim(fgets(STDIN));
    $sum = $sum + $a;

    $a = trim(fgets(STDIN));
    $sum = $sum + $a;

    $a = trim(fgets(STDIN));
    $sum = $sum + $a;

    $a = trim(fgets(STDIN));
    $sum = $sum + $a;

    echo $sum;
?>
```

![](img/4d9a992abc5da7946ac44f9e6bf1d032_367_0.png)

> **Notice:** The main difference between this script and the initial one is that this one has four identical pairs of statements.

Of course, this example can be expanded to read and find the sum of more than four numbers. However, as it becomes clear, you can’t write that pair of statements over and over again because soon you will realize how painful this is. Moreover, if you

## Chapter 25: The Pre-Test Loop Structure

> **Remember!** Many programmers prefer to always use braces, even when the `while` statement encloses just one statement.

The following example displays the numbers 1 to 10.

```php
<?php

$i = 1;

while ($i <= 10) {
    echo $i, "\n";
    $i++;
}
?>
```

> **Notice:** Please note that the statements inside the structure are indented. Just as in decision control structures, this indentation makes scripts easier to read and understand. By using indentation, you visually set those statements apart from the rest of the structure.

#### Exercise 25.1-1 Designing the Flowchart and Counting the Total Number of Iterations

Design the corresponding flowchart for the following PHP script. How many iterations does this PHP script perform?

```php
<?php

$i = 4;

while ($i > 0) {
    $i--;
}
echo "The end";
?>
```

#### Solution

The corresponding flowchart is as follows.

![](img/4d9a992abc5da7946ac44f9e6bf1d032_373_0.png)

Next, a trace table can help you observe the flow of execution.

| Step | Statement | Notes | $i$ |
|---:|---|---|---:|
| 1 | `$i = 4` |  | 4 |
| 2 | `while ($i > 0)` | This evaluates to true |  |
| 3 | `$i--` |  | 3 |
| 4 | `while ($i > 0)` | This evaluates to true |  |
| 5 | `$i--` |  | 2 |
| 6 | `while ($i > 0)` | This evaluates to true |  |
| 7 | `$i--` |  | 1 |
| 8 | `while ($i > 0)` | This evaluates to true |  |
| 9 | `$i--` |  | 0 |
| 10 | `while ($i > 0)` | This evaluates to false |  |
| 11 | `echo "The end"` | The message “The end” is displayed |  |

As you can see from the trace table, the total number of iterations is four.

Now, let’s draw some conclusions!

- If you want to find the total number of iterations, you need to count the number of times the statement or block of statements of the structure is executed and not the number of times the Boolean expression is evaluated.
- In a pre-test loop structure, when the statement or block of statements of the structure is executed N times, the Boolean expression is evaluated N+1 times.

#### Exercise 25.1-2 Counting the Total Number of Iterations

*How many iterations does this PHP script perform?*

```php
<?php
    $i = 4;
    while ($i >= 0) {
        $i--;
    }
    echo "The end";
?>
```

#### Solution

*This exercise is almost identical to the previous one. The only difference is that the Boolean expression here remains `true`, even for `$i = 0`. Therefore, it performs an additional iteration, that is, five iterations.*
