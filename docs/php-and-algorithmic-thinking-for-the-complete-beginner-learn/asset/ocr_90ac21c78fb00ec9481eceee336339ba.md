# # Second Approach - Just find it and process it!

This approach, as previously shown, uses no auxiliary array; it just calculates and
directly processes the sum. The code fragment is as follows.

```
for ($j = 0; $j <= COLUMNS - 1; $j++) {
    $sum = 0;
    for ($i = 0; $i <= ROWS - 1; $i++) {
        $sum += $a[$i][$j];
    }
    process $sum;
}
```
