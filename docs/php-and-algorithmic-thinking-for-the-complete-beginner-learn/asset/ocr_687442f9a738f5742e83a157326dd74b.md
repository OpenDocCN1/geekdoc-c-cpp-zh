# Example

```
```php
<?php

$a = 5.312;
$b = 5.315;

echo round($a, 2), "\n";        // outputs: 5.31
echo round($b, 2), "\n";        // outputs: 5.32
echo round(2.3447, 3), "\n";   // outputs: 2.345
?>

# Sine

`sin (number)`

This returns the sine of *number*. The value of *number* must be expressed in radians.

# Example

```
```php
<?php

$a = sin(3 * pi() / 2);
echo $a;                         // outputs: -1
?>
```
```

# Square root

`sqrt (number)`

This returns the square root of *number*.

# Example

```
```php
<?php

echo sqrt(2), "\n";             // outputs: 1.4142135623731
echo sqrt(9), "\n";             // outputs: 3
?>
```
```

# Tangent

`tan (number)`

This returns the tangent of *number*. The value of *number* must be expressed in radians.

# Example

```
```php
<?php

$a = tan(10);
echo $a;                         // outputs: 0.64836082745909
?>
```
