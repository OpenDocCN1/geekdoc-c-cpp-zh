## Introduction to Sequence Control Structures

### 10.1 What is the Sequence Control Structure?

“Sequence control structure” refers to the line-by-line execution by which statements are executed sequentially, in the same order in which they appear in the script. They might, for example, carry out a series of read or write operations, arithmetic operations, or assignments to variables.

The sequence control structure is the simplest of the three fundamental control structures that you learned about in Chapter 4. The following script shows an example of PHP statements that are executed sequentially.

```php
<?php
	echo "Enter a number: ";
	$a = trim(fgets(STDIN));

	$b = $a * $a;

	echo "The square of ", $a, " is ", $b;
?>
```

### Exercise 10.1-1 Calculating the Area of a Parallelogram

Write a PHP script that calculates and displays the area of a parallelogram.

#### Solution

The area of a parallelogram can be calculated using the following formula:

*Area = Base × Height*

In this exercise, the user enters values for *Base* and *Height* and the script calculates and displays the area of the parallelogram. The solution to this problem is shown here.

```php
<?php
	echo "Enter the length of Base: ";
	$base = trim(fgets(STDIN));
	echo "Enter the length of Height: ";
	$height = trim(fgets(STDIN));

	$area = $base * $height;

	echo "The area of the parallelogram is ", $area;
?>
```

### Exercise 10.1-2 Calculating the Area of a Circle

Write a PHP script that calculates and displays the area of a circle.

#### Solution

The area of a circle can be calculated using the following formula:

Area = π · Radius²

The value of π is a known quantity, which is 3.14159. Therefore, the only value the user has to enter is a value for Radius. The solution to this problem is shown here.

```php
<?php
echo "Enter the length of Radius: ";
$radius = trim(fgets(STDIN));

$area = 3.14159 * $radius * $radius;

echo "The area of the circle is ", $area;
?>
```

A much better approach would be with to use a constant, PI.

```php
<?php
define("PI", 3.14159);

echo "Enter the length of Radius: ";
$radius = trim(fgets(STDIN));
$area = PI * $radius * $radius;
echo "The area of the circle is ", $area;
?>
```

### Exercise 10.1-3 Calculating Fuel Economy

In the United States, a car's fuel economy is measured in miles per gallon, or MPG. A car's MPG can be calculated using the following formula:

MPG = miles driven / gallons of gas used

Write a PHP script that prompts the user to enter the total number of miles he or she has driven and the gallons of gas used. Then the script should calculate and display the car's MPG.

#### Solution

This is quite a simple case. The user enters the total number of miles he or she has driven and the gallons of gas used, and then the script should calculate and display the car’s MPG.

```php
<?php
echo "Enter miles driven: ";
$miles_driven = trim(fgets(STDIN));
echo "Enter gallons of gas used: ";
$gallons = trim(fgets(STDIN));

$mpg = $miles_driven / $gallons;

echo "Your car's MPG is: ", $mpg;
?>
```

### Exercise 10.1-4 Where is the Car? Calculating Distance Traveled

A car starts from rest and moves with a constant acceleration along a straight horizontal road for a given time. Write a PHP script that prompts the user to enter the acceleration and the time the car traveled, and then calculates and displays the distance traveled. The required formula is

$$S = u_0 + \frac{1}{2}at^2$$

where

- **S** is the distance the car traveled, in meters (m)
- **u₀** is the initial velocity (speed) of the car, in meters per second (m/sec)
- **t** is the time the car traveled, in seconds (sec)
- **a** is the acceleration, in meters per second² (m/sec²)

#### Solution

Since the car starts from rest, the initial velocity (speed) $u_0$ is zero. Thus, the formula becomes

$$S = \frac{1}{2}at^2$$

and the PHP script is

```php
<?php
echo "Enter acceleration: ";
$a = trim(fgets(STDIN));
echo "Enter time traveled: ";
$t = trim(fgets(STDIN));
```
