# 33.1 Creating One-Dimensional Arrays in PHP

There are several approaches that can be used to create and add values (elements) to an array in PHP. Which one to use is up to you, depending on the given problem.

Let’s try to create the following array, `$grades`, using all approaches.

| 0 | 1 | 2 | 3 |
|---|---|---|---|
| B+ | A+ | A | C- |

# First Approach

You can create an array in PHP using the following statement given in general form:

```
```php
$array_name = array();
```
```

and then you can add a value (an element) to it using the following statement, given in general form:

```
```php
$array_name[index] = value;
```
```

where `index` is the index position of the element in the array.

The next code fragment creates the array `$grades` and adds some values (elements) to it.

```
```php
$grades = array();
$grades[0] = "B+";
$grades[1] = "A+";
$grades[2] = "A";
$grades[3] = "C-";
```
```

> **Notice:** In Chapter 5 you learned about the rules that must be followed when assigning names to PHP variables. Assigning names to PHP arrays follows exactly the same rules!

Of course, instead of using constant values for `index`, you can also use variables or expressions, as follows.

```
```php
$grades = array();
$k = 0;
$grades[$k] = "B+";
$grades[$k + 1] = "A+";
$grades[$k + 2] = "A";
$grades[$k + 3] = "C-";
```
```

# Second Approach

The same result can be achieved without using an `index`, as follows.

```
```php
$grades = array();
$grades[] = "B+";
$grades[] = "A+";
$grades[] = "A";
```
```
