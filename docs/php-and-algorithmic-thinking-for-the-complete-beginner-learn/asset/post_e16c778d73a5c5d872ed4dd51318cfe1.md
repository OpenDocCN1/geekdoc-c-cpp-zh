## Exercise 10.1-5 Kelvin to Fahrenheit

Write a PHP script that converts a temperature value from degrees Fahrenheit¹ to its degrees Kelvin² equivalent. The required formula is

1.8 × Kelvin = Fahrenheit + 459.67

### Solution

The formula given cannot be used in your script as is. In a computer language such as PHP, it is not permitted to write

```
1.8 * $kelvin = $fahrenheit + 459.67
```

Remember! In the position on the left side of the ( = ) sign, only one single variable may exist. This variable is actually a region in RAM where a value can be stored.

The script converts degrees Fahrenheit to degrees Kelvin. The value for degrees Fahrenheit is a known value and it is given by the user, whereas the value for degrees Kelvin is what the PHP script should calculate. So, you need to solve for Kelvin. After a bit of work, the formula becomes

Kelvin = (Fahrenheit + 459.67) / 1.8

and the PHP script is shown here.

### file_10.1-5.php

```php
<?php
echo "Enter a temperature in Fahrenheit: ";
$fahrenheit = trim(fgets(STDIN));

$kelvin = ($fahrenheit + 459.67) / 1.8;
```

### Power

`pow (number, exp)`

This returns the result of number raised to the power of exp.

### Example

```php
<?php
$a = 2;
$b = 3;
echo pow($a, $b), "\n";       // outputs: 8

$c = pow(3,2);
echo $c, "\n";                // outputs: 9
?>
```

> **Notice:** Function `pow()` can be used to calculate the square root of a number as well. It is known from mathematics that \(\sqrt[z]{X}=X^{1/z}\). So, you can write `$y = pow($x, 1/2)` to calculate the square root of `$x`, or you can even write `$y = pow($x, 1/3)` to calculate the cube root of `$x`, and so on!

### Random

`rand (minimum_value, maximum_value)`

This returns a pseudo-random integer between minimum_value and maximum_value.

### Example

```php
<?php
echo rand(2, 10), "\n";       // outputs: 8
echo rand(0, 10)/10, "\n";    // outputs: 0.5
echo rand(20, 25), "\n";       // outputs: 22
?>
```

> **Notice:** Random numbers are widely used in computer games. For example, an “enemy” may show up at a random time or move in random directions. Moreover, random numbers are used in simulation programs, in statistical programs, in computer security to encrypt data, and so on.

### Round

`round (number, [ precision ])`

This returns the rounded value of number to a specified precision.

### Example

```php
<?php

$a = 5.312;
$b = 5.315;

echo round($a, 2), "\n";        // outputs: 5.31
echo round($b, 2), "\n";        // outputs: 5.32
echo round(2.3447, 3), "\n";   // outputs: 2.345
?>
```

### Sine

`sin (number)`

This returns the sine of *number*. The value of *number* must be expressed in radians.

### Tangent
