# Exercise 21.8-3 Converting the PHP Script

Rewrite the following PHP script using the case decision structure.

```
<?php
echo "Enter a number: ";
$x = trim(fgets(STDIN));
echo "Enter a second number: ";
$y = trim(fgets(STDIN));

if ($x < 5) {
    echo "Variable x is less than 5";
}
elseif ($y == 3) {
    echo "Variable y equals to 3";
}
elseif ($x + $y == 24) {
    echo "The sum of x + y equals to 24";
}
elseif (sqrt($x) == 4) {
    echo "The square root of x equals to 4";
}
else {
    echo "None of the above";
}
?>
```

# Solution

As you already know, the conversion from a multiple-alternative decision structure to a case decision structure is possible as long as the same variable or expression is evaluated for all paths. In this exercise, however, each path evaluates a different variable or expression. For that reason, the conversion to the classical form of the switch statement is not possible.
