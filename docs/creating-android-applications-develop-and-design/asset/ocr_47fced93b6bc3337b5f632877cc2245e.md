# A NOTE ON LOADERS

Android, in version 3.0, added the Loader class to its arsenal of helpers. A loader is essentially a simplified version of the AsyncTask class. It processes or acquires a piece of data off the main thread and then calls your listener on the main thread when the data is ready. In this chapter, I’m giving it a query string that, if the user has a lot of media, could take a very long time. This is an excellent time to deploy one of Android’s loader subclasses: the CursorLoader. You can use this library on versions of Android older than 3.0 by including the Android compatibility library in your project. To add it, right-click your project and select Android Tools > Add Compatibility Library.
