# APPENDIX C: RESOURCES

As we discussed in the Introduction, this book avoids getting into the fundamentals of individual user research methods. This appendix compiles some of the best resources that you can use to learn more about these methods, as well as professional organizations that you may find helpful in your role as a user researcher.

Please check our website (http://www.modssvivalguide.org/resources) for additional and updated resources.
