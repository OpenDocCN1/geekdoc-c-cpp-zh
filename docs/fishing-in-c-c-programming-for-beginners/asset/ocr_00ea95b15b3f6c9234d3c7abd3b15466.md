# Else if ladder

In addition to above formats, if...else ladder can also be used as in following program

```
#include<iostream>
using namespace std;
int main()
{
    cout<<"Enter a number\n";
    int num1;
    cin>>num1;
    cout<<"Enter another number\n";
    int num2;
    cin>>num2;
    if(num1<5)
    cout<<"First number is less than 5";
    else if (num2>5)
    cout<<"Second number is greater than 5";
    else
    cout<<"Both cases are false";
}
```

Output

Enter a number

5

Enter another number

7
