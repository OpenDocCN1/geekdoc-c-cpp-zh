# Multidimensional array

An array can be one dimensional or multidimensional. e.g. int array[3][4][2];

Consider the following program

```
#include<iostream>
using namespace std;
int main()
{
    int num[3][2][5],i,j,k;
    for(i=0;i<3;i++)
        for(j=0;j<2;j++)
            for(k=0;k<5;k++)
                num[i][j][k]=i+j+k;
}
```

In this program, we have declared a three dimensional array and assigned values to it.

A 2D array can also be initialized as follows

```
int num[4][2] = {{ 1214, 86 },{ 1612, 53 },{ 24, 8 },{ 22,8 }};
```
