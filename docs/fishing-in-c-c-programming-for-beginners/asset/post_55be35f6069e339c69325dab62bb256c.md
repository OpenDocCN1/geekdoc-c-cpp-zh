## Variable constraint: Limitations of variables

Now, consider a question, Can a variable store a number to any number of digits after the decimal point if it lies within its range? Let us see:

```
#include<iostream>
using namespace std;
int main()
{
    float a=2.523456789;
    float b=2123456.789;
    cout<<a;
    cout<<endl<<b<<endl;
    cout<<a*b<<endl;
    cout<<2.523456789*2123456.789<<endl;
    cout<<(a*b-5358450);
}
```

Output

```
2.52346
2.12346e+006
5.35845e+006
5.35845e+006
1.5
```

Well, if you are not accustomed to e+ symbol then you will be pleased to know that this is the way to represent the scientific notation into computer. E.g. 3e-004 means 3*10^-4.

The product 2.523456789*2123456.789=5358451.45. While it displays 5358450 but this does not mean it has stored this result as our last line of output shows, where we told the compiler to subtract the displayed result from the original result and the answer is non zero. This experiment proves an amazing fact about the compiler that, a compiler can display something other than whatever it has stored. This experiment confirms the fact that a variable cannot show any number of digits after the decimal point rather it has a limit. The limit is:

A variable shows only six digits of any number assigned to it excluding the decimal point and exponential symbols; if the number of digits increases after the decimal point then the compiler starts rounding the number and if the number of digits increases before decimal point then the compiler round the first six digits and expresses it in scientific form, but the compiler performs any mathematical calculations from the original digits assigned to it without rounding each number and as soon as the final result is obtained, it rounds the final number to six digits while displaying it but may not round it in memory.

I call this rule as Variable constraint. We have to keep this rule in mind for various calculations. This rule is applicable to all the input and output operations even including calculations.

## Difference between declarations and definitions:

Now, time has come where we should learn the difference between a declaration and a definition.

### Declarations

A declaration is any statement which occupies the memory but it has not been assigned any value. E.g. following statements are declarations:

```
int num;
char ch1,ch2,ch3;
void fact();
```

Here, the function has been declared only, not defined. If you will try to use this function, it will give an error “undefined reference to fact()”

e.g. following program will not run and give the above error:

```
#include<iostream>
using namespace std;
void fact();
int main()
{
    fact();
}
```

### Definitions

A definition is any declared statement and which assign a value to the variable or make a function usable. E.g. following statements are definitions:

```
int num=5;
char ch1='t',ch2='u';
int fact(){}
```

Here, in all of the statements cited above, either we have assigned a value to a variable so that now we can use the variable or we have defined a function. Now, if we can call this function.
