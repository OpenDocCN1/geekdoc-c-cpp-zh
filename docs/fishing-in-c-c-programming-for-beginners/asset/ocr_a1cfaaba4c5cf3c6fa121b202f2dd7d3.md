# Left shift operator

<< is Left shift operator. This is a very amazing operator. It shifts the binary equivalent of a number to the number of bits. e.g. 5<<2 means shifting the number 5 by 2 bits.

```
e.g. 5<<2=101<<2
=00101<<2
=10100
=20
```

Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    int a=5;
    int c=a<<2;
    cout<<c;
}
```

Here, the output will be 20
