- It is called the pre-processor. It is used for special purposes, out of which the most common are three:
  - To include a file
  - To define a Macro
  - To use conditions

Here, it has been used to tell the compiler that, we are going to use any one of these three tasks.

include – It is a keyword i.e. those words which are reserved for special purposes and used for them. This keyword is used to include a file in the program, this does not mean only a header file rather it may be a text file or even a C program or C++ program file or even some other files as per requirement.

<...> - It is a format to include a file. However, you are free to use one more format, i.e. “...”, so we can also write #include “iostream” instead of #include<iostream>

iostream – It is a predefined source code called header file. It includes the definition of the object cout (pronounced C out). Other important function included in iostream is cin (pronounced C in) which is used to scan the input given by the standard input device, which is by default keyboard.

Note: Remember, if you are using turbo C++, instead of writing iostream, you will have to write iostream.h, similarly with fstream which is used for file processing.

using namespace std; - Borland C++ support multiple namespaces which are used in long programs. Even we can also define our own namespace. Turbo C++ does not support multiple namespaces. So, using namespace std; does not make sense there. So, you will have to remove this line in Turbo C++.

int main() – Here, main () is a function. The parenthesis is used to pass the arguments to the function. Here int is a return type of the variable returned by the function. It is more understandable, if we try it for a summation program. Suppose we want to add two numbers and want the result to be returned. So, we declare a function int add(int a,int b). Here, we provide two numbers a and b, which will be added and the result will be returned. Remember, main() is the first function which is compiled by the compiler, no matter how many functions are defined above or below it.

{...} – All the statements are declared and defined within it. These curly brackets can be said to bind all the statements inside it, as a single entity. Other functions are also called within it. We also use it in various loops and conditions as required.

cout – This is an object with ‘<<’ to display a character, a string or a number. Not only one but many of them can be displayed using cout. E.g. cout<<1<<“Hello”<<“z”;

return 0 – It is used to return a value back to a function which has called this function in which this return statement is used. E.g. in following function, return is used to return the summation of two numbers.

```
int add(int a, int b)
{
    return a+b;
}
```

## Comments

Comments are those lines which are neglected by the compiler, but make the program easier to read. E.g. consider the program

```
#include<iostream>
```

```
using namespace std;
```

```
int main()
{
 //This is a comment.
}
```

There are two types of comments supported in a C++ program:

- Single line comment: For single line comment // is used. e.g.

```
#include<iostream>
using namespace std;
int main()
{
 //This is a single line comment.
}
```

- Multiple line comment: For multiple line comments, we generally use the following structure:
  - /* This is a comment*/
  e.g. consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
 /*This is a
 multiple line
 comment*/
}
```

We can also use multiple line comment symbols for single line comment e.g.

```
#include<iostream>
using namespace std;
int main()
{
 /*This is a single line comment designed by multiple line comment symbol*/
}
```

We can also repeat single line comment symbol to design multiple line comments, e.g.

```
#include<iostream>
using namespace std;
int main()
{
    //This is a
    //multiple line
    //comments designed by
    //using single line comment symbol
    //multiple times.
}
```

## Variables, constants and Keywords

The golden rule of computer is that nothing can be used without storing it. It does not mean that compiler will always show you that value has been stored. Many of the programming languages even including C++ and python do not always show that the value they are using are being stored. Constants are those data types which cannot be modified, once it is defined. On the contrary, variables are those data types which can be modified, again and again. Suppose we want to operate a number whose initial value is 5 and final value depends on the intermediate operations, then we store it in a variable and then operate that variable according to our desire. In variable section, we shall learn how to store and use the numbers, characters and strings in a variable.

### Character sets

Following character set can be used in a C++ program

- **Alphabets:** A,B,...,Z,a,b,...,z,
- **Digits:** 0,1,...,9
- **Special characters:** ~!@#$%^&*()-+=[]{}|;':",<>?/_

### Variables

A variable is the alias for a memory location, where some data can be stored. E.g.

```
int num=5;
```

In this assignment, the value 5 is assigned to the variable num which is an int type variable. Now, a basic question arises. Can we store any number in integer type variable? The answer is no. Following is the range of the data types we can use:

| Data type | 32 bit compiler | 64 bit compiler |
|---|---|---|
| char | 1 | 1 |
| unsigned char | 1 | 1 |
| signed char | 1 | 1 |
| short | 2 | 2 |
| unsigned short | 2 | 2 |
| signed short | 2 | 2 |
| int | 2 | 4 |
| unsigned int | 2 | 4 |
| signed int | 2 | 4 |
| long | 4 | 4 |
| unsigned long | 4 | 4 |
| signed long | 4 | 4 |
| float | 4 | 4 |
| unsigned float | DOES NOT EXIST | |
| signed float | DOES NOT EXIST | |
| double | 8 | 8 |
| unsigned double | DOES NOT EXIST | |
| signed double | DOES NOT EXIST | |
| long double | 10 | 16 |
| unsigned long double | DOES NOT EXIST | |
| signed long double | DOES NOT EXIST | |

| Memory Allocated (in bytes) | Range |

Here, float, double and long double support decimal numbers too. While int and long do not. But, the amazing fact is, if you will write int num=5.7; it will not show you an error, rather it will just cut decimal part off and store the integral part in num i.e. 5 will be stored in num.

C++ also supports multiple definitions at a time i.e. following definitions are valid:

```
int a=5,b=3,c;
```

Here, three variables a, b, c are defined. Similarly, following definitions are also valid:

```
char c='r',d='e';
```

```
float f=1.6*3.22+4;
```

