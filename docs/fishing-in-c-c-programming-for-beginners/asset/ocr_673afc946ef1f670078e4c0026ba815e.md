# # Structures

Structure is a user defined collection of different data types into single entity.

e.g.

```
struct student
{
char*name;
char section;
int roll;
};
```

A semicolon should be present after closing the curly braces. Structure is a user defined data type, so at first we have to declare a variable of this data type to store the data.

e.g. struct student s1;

To access the elements of the structure, we use dot operator. e.g.

cout<<s1.roll;

