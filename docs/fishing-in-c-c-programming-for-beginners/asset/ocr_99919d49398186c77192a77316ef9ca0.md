Consider the following program:

```
#include<iostream>
using namespace std;
namespace ns1
{
    int a=1;
}
namespace ns2=ns1;
int main()
{
    using namespace ns1;
    cout<<a<<endl;
    using namespace ns2;
    cout<<a;
}
```

# Output

1
1

This time the variable a is not ambiguous.
