# Definitions

A definition is any declared statement and which assign a value to the variable or make a function usable. E.g. following statements are definitions:

```
int num=5;
char ch1='t',ch2='u';
int fact(){}
```

Here, in all of the statements cited above, either we have assigned a value to a variable so that now we can use the variable or we have defined a function. Now, if we can call this function.

# scope resolution operator(::)

