We can also save the value which has been returned by a function, in a variable.
E.g. Consider the following program:

```
#include<iostream>
int power(int,int);
using namespace std;
int main()
{
    int x=5,y=6;
    int c=power(x,y);
    cout<<c;
}
int power(int a,int b)
{
    int temp=1;
    for(int i=0;i<b;i++)
        temp*=a;
    return temp;
}
```

Output
15625

This program simply calculates the value of 5 raised to the power 6.
