# # Class

You can imagine the importance of this chapter from the fact that C++ was initially named “C with classes”. Up to now whatever we have learnt is a part of both the types of languages i.e. structural programming languages and object oriented programming languages. Now, we shall start that part which specifically belong to an object.

+   1. Data encapsulation: The data members can be bind into one capsule called class.
+   2. Polymorphism: This is the ability to process different functions in different ways depending on the arguments passed to them.
+   3. Data hiding: This gives us the right to hide the data from outside the class. private is a keyword used for data hiding.
+   4. Code Reuse and Recycle: The same code can be reused and put into a header file for further reuse.

A class is declared using the keyword class. An example of a class:

```
class rectangle {
int x, y;
public:
void assign_values (int,int);
int area (void);
};
```

Here, class is a keyword used to tell the compiler that we are going to define a class. rectangle is class name, you can type any name here. public: is access specifier or permission controller. It controls the permissions. See, we have not decided any permission level for int x, y; in this case the compiler assigns private: automatically. So, private: is the default permission level. There are three types of permissions available for a class:

+   1. private
+   2. protected
+   3. public
