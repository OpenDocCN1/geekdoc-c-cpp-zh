## eofbit and eof()

The eofbit is automatically set for an input stream when EOF is encountered. When EOF is encountered on cin, the call cin.eof returns true. Here “encountering” means that there is no more bytes to read from the input stream. Returns true if a file open for reading has reached the end. We have already seen its example.

## goodbit and good()

It is the most generic state flag: The goodbit is set and good method returns false in the same cases in which calling any of the previous functions would return true.

## is_open()

Returns true if the file is found to be open.

Consider the following program:

```
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin("example.txt",ios::out);
    if(fin.is_open())
    {
        fin<<"Hello World";
        fin.close();
        return 0;
    }
    else
    {
        cout<<"Can't open file";
        return -1;
    }
}
```

Another alternative use of this function which is very popular in C++ is displayed in the following program:

```
#include<iostream>

{
    fstream fin("example.txt",ios::out);
    if(!fin.is_open())

    fin.close();
    return 0;
}
```

## clear()

In order to reset the state flags checked by any of these member functions we have just seen we can use the member function clear(). The clear method is normally used to restore a stream’s state to “good” so that IO may proceed on that stream. Any error state bit listed above which becomes the argument is set. The default argument of clear method is ios::goodbit, so the statement “cin.clear” clears cin and sets goodbit for the statement, and “cin.clear(ios::failbit)” actually sets the failbit.

Consider the following program:

```
#include<iostream>
#include<fstream>
using namespace std;

int main()
{
    fstream fin("example.txt",ios::out);
    if(!fin.is_open())
    {
        cout<<"Can't open file";
        return -1;
    }

    fin<<"Hello World";
    if(fin.good())
    {
        cout<<"File written successfully";
        fin.clear();
    }

    fin.close();
    return 0;
}
```

### Output

File written successfully

## Operating multiple files simultaneous

We can operate multiple files simultaneously. Following is a file copy program to illustrate this:

```
#include<iostream>
#include<fstream>
using namespace std;

int main()
{
    char ch1[100];
    cout<<"Enter file name to copy from: \n";
    cin>>ch1;
    char ch2[100];
    cout<<"\nEnter file name to copy to: \n";
    cin>>ch2;
    fstream fin,fout;
    fin.open(ch1,ios::in);
    fout.open(ch2,ios::out);
    if(!fin.is_open())
    {
        cout<<"Can't open "<<ch1;
        return -1;
    }
    if(!fout.is_open())
    {
        cout<<"Can't open "<<ch2;
        return -2;
    }
    char ch;
    fin.seekg(0,ios::end);
    int file_length=fin.tellg();
    fin.seekg(0,ios::beg);
    int count=0;
    while(!fin.eof())
    {
        ch=fin.get();
        fout<<ch;
        cout<<(count++*100)/file_length<<"% completed"<<'\r';
    }
    cout<<"File copied";
    fout.close();
    fin.close();
}
```

### Output

Enter the file name to copy from
example.txt
Enter the file name to copy to
b.txt
100% completed
File copied

In the above program, we take the file name as input from user. To obtain the length of the file at first we placed the handle to the end of file using the code snippet fin.seekg(0,ios::end); then we stored the offset of the last character using the code snippet int file_length=fin.tellg();. At last we returned the handle to the beginning of file using snippet fin.seekg(0,ios::beg);
