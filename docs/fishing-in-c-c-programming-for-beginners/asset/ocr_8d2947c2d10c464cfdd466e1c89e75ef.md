# cout.put()

This function places a character on the screen, opposite to puts(), it does not insert any line feed. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    cout.put('a');
    cout.put('k');
}
```

Output :

ak

Now, consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    cout.put('a').put('k');
}
```

Output:

ak

This program tells that .put() can be cascaded multiple times.
