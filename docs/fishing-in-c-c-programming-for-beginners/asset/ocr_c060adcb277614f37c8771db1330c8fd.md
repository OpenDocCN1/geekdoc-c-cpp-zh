# Limiting exceptions types for functions

While declaring a function we can limit the exception type it might directly or indirectly throw by appending a throw suffix to the function declaration. So the function can be declared in any of the following three ways:

+   return_type func_name(arg1,arg2,...) throw(int); //Only integral exceptions allowed
+   return_type func_name(arg1,arg2,...) throw(char); //only char exceptions allowed
+   return_type func_name(arg1,arg2,...) throw(); // No exceptions allowed
+   return_type func_name(arg1,arg2,...); //All exceptions allowed

Here see, if throw function is passed no arguments, then no exceptions will be thrown to catch. If we do not write throw() then all types of exceptions are allowed.

An example is:

```
#include<iostream>
using namespace std;
void allocate_memory()throw();
void allocate_memory()throw()
{
    long double*array=new long double[10000000000000000];
}
```
