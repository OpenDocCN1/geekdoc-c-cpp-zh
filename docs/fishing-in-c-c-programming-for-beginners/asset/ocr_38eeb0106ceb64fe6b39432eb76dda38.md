# #define

This macro is used for various purposes. It can be used to name any constants, variables, functions and even statements. We can also generate a function using this term!

Consider the following program:

```
#include<iostream>
using namespace std;
#define a 50
int main()
{
    cout<<a;
    return 0;
}
```

Here, the output will be 50. So, instead of 50,you can use a everywhere in your program.

Consider the following program:

```
#include<iostream>
using namespace std;
#define a 50*2+3
int main()
{
    cout<<a;
    return 0;
}
```

Here, output will be 103
