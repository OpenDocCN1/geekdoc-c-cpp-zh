# To display the value stored in a variable

To display a variable, we just place the variable name next to left shift symbol (<). E.g.

```
#include<iostream>
using namespace std;
int main()
{
    int num=8;
    cout<<num;
    char ch='s';
    cout<<ch;
    char*ch1="Aman";
    cout<<ch1;
}
```

Output:

8sAman
