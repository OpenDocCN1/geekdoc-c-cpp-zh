```
{
int i,j;
for(i=1;i<3;i++)
{
for(j=6;j<9;j++)
{
cout<<"j";
if(j==7)
break;
}
cout<<"i";
}
return 0;
}
```

The output of the above program will be jijii. Since at first i is initialized with 1 and j with 6. Now, j will be printed. Now value of j is increased to 7 and again j is printed. But now j is 7,so break statement will be executed and the handle comes out of innermost for loop and cout<<"i"; is executed. Now value of i will be incremented. And again inner for loop is executed. This process continues until the statement i<3 becomes false.

Consider the following program

```
#include<iostream>
using namespace std;
int main()
{
int i;
for(i=1;i<3;i++)
{
cout<<i;
continue;
cout<<"i";
}
```
