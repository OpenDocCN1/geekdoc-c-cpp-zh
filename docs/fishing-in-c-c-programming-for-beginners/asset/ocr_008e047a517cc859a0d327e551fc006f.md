# Reading entire file: Character by character

In the following program, we have used get() function to read each and every character from the file.

Consider the following program:

```
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::in);
    if(fin==NULL)
    {
        cout<<<"Can't open the file");
        return -1;
    }
    char ch;
    while(!fin.eof())
    {
        fin.get(ch);
        cout<<ch;
    }
    fin.close();
    return 0;
}
```
