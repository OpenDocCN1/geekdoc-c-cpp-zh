Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
     char ch[]="Aman";
     char*ch1=ch;
     puts(ch1);
}
```

This program will print Aman. This program also illustrates the fact that we cannot assign a string to a character but we can assign a string to a character pointer.

Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
     char ch[]="aman";
     int i=0;
     while(ch[i]!='\0')
     {
          cout<<ch[i];
          i++;
     }
}
```

Output of the above program will be aman, this program illustrates the fact that every string and even a character of array end with a null character. The second fact it illustrates is that strlen() neglect null character.
