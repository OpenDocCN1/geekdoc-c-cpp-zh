# setw()

This function allows us to display a fixed number of digits after the decimal point with rounding. E.g. Consider the following program

```
#include<iostream>
#include<iomanip>
using namespace std;
int add(int,int);
int main()
{
    float a=21.23456789;
    cout<<setw(4)<<a;
}
```

Output
21.2346
