```
struct student s1;
s1.name="Aman";
s1.roll=12;
s1.section='D';
return 0;
}
```

We can also declare a variable while defining a structure. e.g

```
struct student
{
int roll;
char section;
char*name;
}s1,s2;
```

# Input//output in structure

```

using namespace std;
struct student
{
     char name[50];
     char section;
     int roll;
};
```
