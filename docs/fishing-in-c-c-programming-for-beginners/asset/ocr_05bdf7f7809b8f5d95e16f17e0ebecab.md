At first download and install DEV C++ latest release from http://bloodshed.net . Now, open it, it will ask for some more settings, keep everything on default and go further. I have used TDM-GCC++ 4.8.1 release, Dev C++ 5.8.3 in this whole book.

C++ compilers are mainly of two types:

+   1. Borland C++ compiler
+   2. Turbo C++ compiler

The difference is that Turbo C++ compilers are no more significantly maintained, while Borland compilers are significantly updated. However, remember that Turbo C++ does not support typename keyword and namespaces. If you are using Turbo C++ then various programs implemented in this book may not work accurately. You should immediately leave that and switch to a compiler of Borland C++. You can switch to Dev C++, Code block and various other popular compilers. All of these are free and easy to use.
