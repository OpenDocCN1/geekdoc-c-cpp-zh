Now, consider the following program:

```
#include<iostream>
using namespace std;
#include<math.h>
/*#define a*/
int main()
{
#ifdef a
    cout<<("5+2=8\n");
    cout<<("\"Make Fool\" process was ON\n");
#endif
    cout<<("5+2=7");
}
```

Since here, define statement has been comented, which is ignored by the compiler. So, compiler will understand that a has not been defined and hence output will be 5+2=7

We can also use #ifdef...#elif...#else...#endif condition here.
