# Returning a pointer

A pointer can also be used as a return type.

Consider the following program:

```
#include<iostream>
using namespace std;
int*change();
int main()
{
    int*b;
    b=change();
    cout<<*b;
}
int*change()
{
    int a=5;
    return(&a);
}
```

This program will display 5.
