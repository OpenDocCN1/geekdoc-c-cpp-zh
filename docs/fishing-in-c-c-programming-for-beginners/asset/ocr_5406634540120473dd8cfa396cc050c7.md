In this program, we have used a shorthand notation.

Consider the following program

```
#include<iostream>
using namespace std;
int main()
{
    int marks[10],sum=0,average,i;
    for(i=0;i<10;i++)
    {
        cout<<"\nEnter the marks of "<<i+1<<"th student\n";
        cin>>marks[i];
        sum+=marks[i];
    }
    average=sum/10;
    cout<<"\nAverage of marks of 10 students is "<<average;
}
```

Here, you can see the value in marks[i] is taken in same manner as it was taken without array.

# Bound checking

Suppose you declare an array int a[32]; then you may use a statement a[95]=0; because C++ does not check the boundary. But, this should not be practiced, as it may crash the program.

E.g. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    int a[32];
    a[90]=0;
}
```
