# # Array

Array is a sequence of variables stored at consecutive memory location of same data type. It is a method to store large number of variables. Suppose we want to work on 500 numbers, then it is not feasible to declare or define 500 different variables. So we can define an array like int num[500]; Here, num has been indexed from 0 to 499. So, we can now use num[0] to num[499].

# ## Array declaration and initialization

Array can be declared and initialized in following way:

```
int a[2]={45,43};
int a[2]={43};
int a[]={34,54,65};
int a[]={43};
int a[23];
```

An uninitialized array contains garbage value.

e.g. suppose, we want to calculate sum of 10 numbers as in the following program

```
#include<iostream>
using namespace std;
int main()
{
    int num[10]={5,7,8,3,2,1,2,4,3,15};
    int sum=0,i;
    for(i=0;i<10;i++)
    sum+=num[i];
    cout<<sum;
}
```

Output

50

Here, you can see, a method of assigning the values to num[i]. To assign the value to a number say num[3], we can directly use num[3]=5; In the above program, I have used linear assignment i.e. 5 is assigned to num[0],7 to num[1],...,15 to num[9].
