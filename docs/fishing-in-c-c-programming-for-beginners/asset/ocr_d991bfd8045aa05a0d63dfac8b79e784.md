Consider the following program

```
#include<iostream>
using namespace std;
#define a cout<<"It's amazing";
int main()
{
    a
    return 0;
}
```

Here, there is no error in the program and we have not used semicolon as it has already been included in cout statement. Its output will be **Its amazing**
