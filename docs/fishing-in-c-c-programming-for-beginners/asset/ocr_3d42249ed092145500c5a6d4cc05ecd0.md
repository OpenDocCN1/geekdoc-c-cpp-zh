# Friend class

Many a times we want to access the private and protected members of a class from the other class. Suppose a class rectangle and other one is square. Instead of declaring a new area function, we want to use the area function declared in the class rectangle. To use the function, we shall have to access the private elements length and breadth of the class rectangle. At that time the friend class is very useful. The code snippet to declare the friend class in a pre-existing class is as follows:

```
class square
{
    int side;
    public:
        void set_side (int s);
        friend class rectangle;
};
class rectangle
{
    int length, breadth;
    public:
        int area ();
        void set_square(square a);
};
```

Here, you can see that we have passed entire class to the function set_square. Following program illustrates the friend class
