# \r Carriage return

This is not like \n. The problem with the people is that they are generally never explained where to use \r. So they ask a lot of questions about its use on forums. Well, \r moves the cursor to the beginning of the current line which is being displayed, for example, consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    cout<<"Hello world\rBlack";
}
```

Output:

Black world

See, here after printing Hello World, the cursor moves to beginning of the line and then since it has to write Black, so it overwrites it with Black. Now, you have understood that \r is something like \b but not like \n at all. You can also say this is equivalent to Home button of our keyboard.
