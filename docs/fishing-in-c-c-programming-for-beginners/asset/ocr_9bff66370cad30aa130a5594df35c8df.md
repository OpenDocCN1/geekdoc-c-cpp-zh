# Exceptions

Exceptions give us a way to detect to and react to various runtime errors. When an error is encountered, the error is thrown to special handlers. Most useful part of this chapter is try...catch block. To catch an error, we place the code inside the try block, catch is defined just after the try block. Catch receives the error and reacts correspondingly.As soon as an exception is caught, it is thrown.

The syntax of using try...catch is:

```
try
{
//statements
throw exception;
}
catch(argument)
{
//statements
}
```

Where argument is the thrown value, it may be of integer type, char type. If you do not know the type, you should use three dots (...) called ellipsis as an argument as it accepts all types of arguments. So, you can say it the default argument.
