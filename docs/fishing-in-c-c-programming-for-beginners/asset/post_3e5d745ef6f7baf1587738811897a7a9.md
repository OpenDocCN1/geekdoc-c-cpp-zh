## Structures

Structure is a user defined collection of different data types into single entity.

e.g.

```
struct student
{
char*name;
char section;
int roll;
};
```

A semicolon should be present after closing the curly braces. Structure is a user defined data type, so at first we have to declare a variable of this data type to store the data.

e.g. struct student s1;

To access the elements of the structure, we use dot operator. e.g.

cout<<s1.roll;

Following program illustrates it:

```
#include<iostream>
using namespace std;
struct student
{
    char*name;
    char section;
    int roll;
};
int main()
{
    struct student s1;
    s1.name="Aman";
    s1.roll=12;
    s1.section='D';
    return 0;
}
```

We can also declare a variable while defining a structure. e.g

```
struct student
{
int roll;
char section;
char*name;
}s1,s2;
```

## Input//output in structure

Structure variables can be used like normal variables for input and output. All the functions which we have used till now can be used with structures. E.g. consider the following program.

```
#include<iostream>
using namespace std;
struct student
{
     char name[50];
     char section;
     int roll;
};
int main()
{
    struct student s1;
    cout<<"Enter the name of student\n";
    gets(s1.name);
    cout<<"Enter the section of student\n";
    cin>>s1.section;
    cout<<("Enter the roll number of the student\n");
    cin>>s1.roll;
    cout<<("\nThe name of student is: ");
    puts(s1.name);
    cout<<"\nThe section of the student is:"<<s1.section;
    cout<<"\nRoll number of the student is: "<<s1.roll;
    return 0;
}
```

## Array of structures

Like other data types we can use the array of structures. Following program illustrates this:

```
#include<iostream>
using namespace std;
struct student
{
    char name[50];
    char section;
    int roll;
};
int main()
{
    struct student s1[5];
    int i;
    for(i=0;i<5;i++)
    {
        cout<<("Enter the name of student\n");
        gets(s1[i].name);
        cout<<("Enter the section of student\n");
        cin>>s1[i].section;
        cout<<("Enter the roll number of the student\n");
        cin>>s1[i].roll;
        fflush(stdin);
    }
    for(i=0;i<5;i++)
    {
        cout<<("\nThe name of student is: ");
        puts(s1[i].name);
        cout<<("\nThe section of the student is: "<<s1[i].section);
        cout<<("\nRoll number of the student is: "<<s1[i].roll);
    }
    return 0;
}
```

Here, you can see that we have used a new function fflush(stdin), why? The fact is as soon as the roll number is entered and Enter is pressed then roll number is taken by s1[i].roll and 'Enter' is kept in buffer for next input. Now, a query for name is displayed and it requires an input, since 'Enter' is in buffer for next input. So, it is now received as the name and the query for the section is appeared immediately. So, user understands that the program skipped the input. fflush(stdin), flushes the input buffer and so, program asks for name and user can give the input. Just abolish fflush(stdin); statement and see what happens.
