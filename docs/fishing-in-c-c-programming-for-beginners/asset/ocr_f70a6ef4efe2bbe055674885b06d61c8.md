# Nested if...else

if...else branch used under another if...else branch is called nested if...else.E.g.

```
#include<iostream>
using namespace std;
int main()
{
    int num=50;
    if(num%5==0)
    {
        cout<<"The number is divisible by 5";
        if(num%10==0)
            cout<<"\\nThe number is also divisible by 10";
    }
    else
        cout<<"The number is not divisible by 5";
}
```
