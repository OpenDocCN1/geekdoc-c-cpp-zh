# cin.get()

This function is used to take a character as input from screen. E.g. consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    char ch;
    cout<<"Enter a character\n";
    cin.get(ch);
    cout<<"Entered character is "<<ch;
}
```

# Output

Enter a character

5

Entered character is 5

# cin.getline(char*,int l,char f)

This function is used to take a line as input from screen.

It is a overloaded function, means it can be used with two arguments as well as three arguments. First argument is the char pointer to which the line is stored. Second argument is the number of characters to store. Third argument is optional, it is called delim character. Suppose you want to input the characters until a particular character strikes. That particular character can be used as a delimit character. If the delimitative character is used then second argument and third argument both should be responsible for terminating the input
