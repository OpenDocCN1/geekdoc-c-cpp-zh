
Typecasting can also be done manually. To convert a variable say num to integer, we can write int(num);

So, the above program can also be written as:

```
#include<iostream>
using namespace std;
int main()
{
    int a=255;
    float b=182;
    cout<<char(a-b);
}
```

Both will give the same output. This is called manual typecasting. But, remember, you cannot write

```
#include<iostream>
using namespace std;
int main()
{
    int a=255;
    float b=182;
    cout<<(char)a-b;
}
```

Output

-183

Well, (char)a will also convert the variable to character but (char)a-b; will not convert the variable a-b to character, rather it will convert variable a to character and then subtract b from it. So, to remove the confusion, it is good to practice expressions like char(a) not like (char)a.

To convert a variable say num to float, just use float(num); and so on.

## Constants

Well, just adding a word const, just before the variable declaration, converts the variable to a constant. A constant is that whose value can be altered inside a program. E.g. const int num=5; E.g. consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    const int num=5;
    const char ch='c';
    cout<<num<<" "<<ch;
}
```

Output:

5 c

Now, if we want to assign any value to num again somewhere in the program, the compiler displays the error “Assignment of read-only variable”.

E.g. consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    const int num=5;
    const char ch='c';
    cout<<num<<" "<<ch;
    num=7;
}
```

This program will display the above error. Once we add the word const to the variable declaration; the variable becomes constant and read only type, so is the above error.

## Shorthand notation

Many a times it happens that we work on a variable and store the value obtained to the same variable. E.g. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    int a=5;
    int b=7;
    a=a+b;
    cout<<a;
}
```

Output

12

These types of programs can also be written using various shorthand notations. C++ supports many shorthand expressions like:

- a=a+b; is equivalent to a+=b;
- a=a-b; is equivalent to a-=b;
- a=a*b; is equivalent to a*=b;
- a=a/b; is equivalent to a/=b;

E.g. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    int a=5;
    int b=7;
    a+=b;
    cout<<a<<endl;
}
```

Output
12

Now, consider the following amazing program:

```
#include<iostream>
using namespace std;
int main()
{
    int a=5;
    int b=7;
    a+=b;
    cout<<a<<endl;
    a-=b;
    cout<<a<<endl;
    a*=b;
    cout<<a<<endl;
    a/=b;
    cout<<a<<endl;
}
```

Output
12
5
35
5

Amazing, isn't it? Initially a=5 and b=7, so a+b=12 and now a=12 and b=7, so a-b=5, now a=5 and b=7, so a*b=35 and then a=35 and b=7, so a/b is 5.

## Decision control

### if...else

Decisions can be controlled using if...else. Consider the following code:

```
#include<iostream>
using namespace std;
int main()
{
    int num=53;
    if(num%5==0)
        cout<<"The number is divisible by 5";
    else
        cout<<"The number is not divisible by 5";
    return 0;
}
```

Here, % is the modulus operator, which stores the remainder. E.g. in declaration int b=a%5; a is divided by 5 and the remainder is stored in b. So, in above program, num is divided by 5 and the remainder is compared with 0. If the remainder is equal to zero, then the program displays that the number is divisible by 5 else it displays the contrary.

Also note that we have used two signs of equality (==) not one (=) for comparison as we have already used single equality for assigning the value to a variable like in int num=5;.

For comparisons of not equal, we use (!=). For example consider the following code:

```
#include<iostream>
using namespace std;
int main()
{
    int i=5;
    if(i!=7)
        cout<<"i is not 7";
    else
        cout<<"i is 7";
}
```

Output

i is not 7

If you want to use more than one statement in if...else then you will have to use {...} otherwise the compiler will consider only one statement which is next to if...else under if and else. E.g. consider the following code

```
#include<iostream>
using namespace std;
int main()
{
    int num=53;
    if(num%5==0)
        cout<<"The number is divisible by 5";
        cout<<"The number is also divisible by 1";
    else
        cout<<"The number is not divisible by 5";
}
```

This program will give a compile error, “else without a previous if”. So, the correct one will be

```
#include<iostream>
using namespace std;
int main()
{
    int num=53;
    if(num%5==0)
    {
        cout<<"The number is divisible by 5";
        cout<<"The number is also divisible by 1";
    }
    else
        cout<<"The number is not divisible by 5";
}
```

Output

The number is not divisible by 5

We have used only one statement inside else branch, so we have not used curly bracket there, otherwise we must have to use a curly bracket there too.

#include<iostream>

## Logical operators

There are various logical operators which can be used inside a program

&& This is AND operator and compares various statements, if all of the statements are true then the whole expression is assumed to be true and the statement inside the corresponding branch will be executed.

Consider the following program

```
#include<iostream>
using namespace std;
int main()
{
    int num=5,num2=7;
    if(num==5&&num2-1==6)
        cout<<"4 is just before "<<num;
    else
        cout<<"Either the num is not 5 or num2-1 is not equal to 6";
}
```

Here the output will be “4 is just before 5”. As both are true statements.

|| This is OR operator which compares two statements, if anyone of all the statements is true then the entire expression is assumed to be true and then statement inside the corresponding branch will be executed.

E.g. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    int num=5,num2=7;
    if(num==5 || num2-2==6)
        cout<<"4 is just before "<<num;
    else
        cout<<"Either the num is not 5 or num2-1 is not equal to 6";
}
```

This time only one of the statements is correct still the output will be 4 is just before 5.
