## Friend class

Many a times we want to access the private and protected members of a class from the other class. Suppose a class rectangle and other one is square. Instead of declaring a new area function, we want to use the area function declared in the class rectangle. To use the function, we shall have to access the private elements length and breadth of the class rectangle. At that time the friend class is very useful. The code snippet to declare the friend class in a pre-existing class is as follows:

```
class square
{
    int side;
    public:
        void set_side (int s);
        friend class rectangle;
};
class rectangle
{
    int length, breadth;
    public:
        int area ();
        void set_square(square a);
};
```

Here, you can see that we have passed entire class to the function set_square. Following program illustrates the friend class

## this pointer

Many a times, we want to create an object of a class inside the function definition of the same class , so that we can calculate and return the object to store it in another object. For example, suppose we define a class rectangle. Now, we want to calculate the area from one object say obj1 and we want to return the entire object and store in another object say obj2. This time this pointer becomes very useful.

Consider the following program:

```
#include<iostream>
using namespace std;
class rectangle
{
int length,breadth,area;
public:
void set_values(int a,int b){length=a;breadth=b;}
rectangle calc_area();
void display_area(){cout<<area;}
};
rectangle rectangle::calc_area()
{
area=length*breadth;
return *this;
}
int main()
{
    rectangle obj1,obj2;
    obj1.set_values(4,5);
    obj1.calc_area();
    obj2=obj1;
    obj2.display_area();
}
```

Output
20

Here return*this; returns the entire object. Remember this behaves as an object pointer.

## Inheritance

This is an amazing feature of object oriented programming. This feature allows us to inherit a class from an existing class. This feature saves us from writing a lot of codes and we can inherit using permissions so that we control inheriting feature for future.

**Base class:** A pre existing class from which another class is to be derived

**Derived class:** A class which is derived from a base class

Syntax of inheriting a class from an existing class is:

```
class derived_class_name: permission_level base_class_name
{
//Statements
}
```

Permission level can be private,protected or public.

Consider the following program:

```
#include<iostream>
using namespace std;
class cuboid
{
    public:
    int length,breadth,height;
    int volume(int,int,int);
};
int cuboid::volume(int x,int y,int z)
{
    length=x;
    breadth=y;
    height=z;
    return length*breadth*height;
}

class base_area:public cuboid
{
public:
int calculate_base_area();
};

int base_area::calculate_base_area()
{
return length*breadth;
}

int main()
{
class base_area b1;
cout<<"Volume of cuboid is: "<<b1.volume(5,2,3)<<endl;
cout<<"Base area of cuboid is: "<<b1.calculate_base_area()<<endl;
}
```

Volume of cuboid is: 30
Base area of cuboid is: 6
