## Default arguments

A function can have default arguments. These arguments are used automatically, if no argument is passed for them. A default argument is declared inside the function declaration. E.g. Consider the following program:

#include<iostream>
using namespace std;
int add(int x=1,int y=2);
int main()
{
    cout<<add()<<endl;
    cout<<add(5)<<endl;
    cout<<add(5,6);
}
int add(int x,int y)
{
 return x+y;
}

Output
3
7
11

See here, In the first call to the function since we have not passed any value, so automatically 1 and 2 which was used in function declaration was taken. In the second calling we have passed a value, so this value was considered as first argument and so 5 and 2 was added to give 7. Then in third calling we passed both the arguments to the function, So the result 11 was returned.

See the function declaration contains the default arguments, not the function definition.

## Function overloading

C++ has the capacity to differentiate different functions on the basis of type of arguments being passed to them. This gives us the power to use many functions with the same name.

Consider the following program:

#include<iostream>
using namespace std;
void disp();
void disp(int);
void disp(char);
void disp(int,char);
int main()
{
    int i=5;
    char ch='c';
    disp(i,ch);
    disp(i);
    disp();
    disp(ch);
}
void disp()
{
    cout<<"In 1"<<endl;
}
void disp(int x)
{
    cout<<"In 2"<<endl;
}
void disp(char c)
{
    cout<<"In 3"<<endl;
}
void disp(int x,char c)
{
    cout<<"In 4"<<endl;
}

Output
In 4
In 2
In 1
In 3

See, how efficiently the compiler automatically decided the correct function to use. It just matches the type of argument with the function to be called. This is called function overloading.

## Inline Functions

While calling a function, the handle jumps to the function, execute the statement inside it and then returns to the main() function. Again, when the function is called, the same process is repeated again. This process has two disadvantages:

- 1. It is slightly more time consuming than the program without a function
- 2. It breaks continuity

To solve these problems, we use an arrangement called inline functions. If we declare a function inline, then we are in fact suggesting the compiler to copy the statements written in functions in the calling function itself instead of calling the function. It is not necessary that function will be inlined but most of the very small functions got inlined whenever they are declared so.

Syntax of an inline function:

inline return_type func_name(data_type1 arg1,data_type2 arg2,...)
{
/*Statements*/
}

Following program illustrates to use inline functions:

#include<iostream>
using namespace std;
inline int add(int a,int b);
int main()
{
for(int i=0;i<1000;i++)
cout<<add(5,6);
return 0;
}
inline int add(int a,int b)
{
    return a+b;
}

## Pointers

This part includes two special symbols & and *

& - It is called address of variable.

Consider the following program:

#include<iostream>
using namespace std;
int main()
{
    int a=5;

Here, it will display the memory address of variable stored. Output depends on compilers, in my compiler it displayed 0x22fe4c. In yours, it may be different.

* Asterisk, also called value at the address of is used to access the value stored at the address of a variable.

A pointer may be declared as

int *a;

Consider the following program:

#include<iostream>
using namespace std;
int main()
{
    int *a;
    cout<<*a;
    return 0;
}

In this program, we have not assigned any address to a, but we are trying to access the value stored at that address. This simply crashes the program with the following output:

Consider the following program

#include<iostream>
using namespace std;
int main()
{
    int b=5;
    int *a=&b;
    cout<<*a;
    return 0;
}

This program will assign the address of b to a not to *a as it looks. So, output will be shown as 5

To remove the confusion int *a = &b; can also be written as:

int *a;
a=&b;

Now, if you change the value stored at a as in the following program, then the value will be changed at the address.

#include<iostream>
using namespace std;
int main()
{
    int b=5;
    int *a=&b;
    cout<<*a;
    *a=7;
    cout<<endl<<b;
    cout<<endl<<*a;
}

Output:
5
7
7

This program illustrates the fact that; whatever the change we carry out through a pointer, the changes occur at the memory address.

Consider the following program:

#include<iostream>

{
    int a=5;
    cout<<a;
    display1(&a);
    cout<<a;

*x = 6;

The output of the above program will be 56. As since we passed the address using ampersand operator to the function display1(). And there, we used a pointer, so that it can receive the address. Then using asterisk operator, we changed the value at address of a to 6. And when we printed the same value in main() function. We can see that the value in main() function has also been changed.

## Call by value and call by reference

A function can be called in two ways

- 1. Call by value
- 2. Call by reference

Again calling by reference can be subdivided into two parts

- i. Calling using pointers
- ii. Calling without using pointers

## Call by value

When we call a function by value, then a copy of the local variables which are being passed to the function is created and passed to the function. So, after the function execution the original value of the local variable does not change.

E.g. Consider the following program

#include<iostream>
using namespace std;
int display1(int);
int main()
{
    int a=5;
    display1(a);
    cout<<a;
}
int display1(int a)
{
a = 6;
}

In this program, output will be 5, instead of the fact that we have changed the value of a to 6, in display1() function. This is called the function call by value. Here, one copy of the value of a is passed to display1() function. So, the value in the main() function remains unchanged because the value stored at the original address has not been changed rather the copy of value in the display1() function has been changed and this change will survive until and unless the function display1() function returns the handle to main().

If the above said is true then if we try to access the memory location of num in the following program, it should give two different values, which can be viewed easily.

## Call by reference using pointers

When we call the function by reference either by using pointer or by using address, then the address of the variables are passed to the function. So, whatever the change we make in the function, the same changes occur at original memory location of the local variable.

Consider the following program:

#include<iostream>
using namespace std;
int display1(int*);
int main()
{
    int a=5;
    cout<<a;
    display1(&a);
    cout<<a;
}
int display1(int *x)
{
*x = 6;
}

The output of the above program will be 56. As since we passed the address using ampersand operator to the function display1(). So, this is called function call by reference
