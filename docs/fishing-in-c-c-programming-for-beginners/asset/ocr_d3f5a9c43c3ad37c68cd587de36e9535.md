# Call by reference without using pointers

We can also call a function using call by reference without using address.

E.g. Consider the following program:

```
#include<iostream>
using namespace std;
int display1(int&);
int main()
{
int a=5;
cout<<a;
display1(a);
cout<<a;
}
int display1(int&x)
{
x=6;
}
```
