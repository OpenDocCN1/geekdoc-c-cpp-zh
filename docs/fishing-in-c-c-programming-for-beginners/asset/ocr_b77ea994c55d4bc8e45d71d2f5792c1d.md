There are two types of comments supported in a C++ program:

+   1. Single line comment: For single line comment // is used. e.g.

```
#include<iostream>
using namespace std;
int main()
{
 //This is a single line comment.
}
```

+   2. Multiple line comment: For multiple line comments, we generally use the following structure:
+   /* This is a comment*/
+   e.g. consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
 /*This is a
 multiple line
 comment*/
}
```

We can also use multiple line comment symbols for single line comment e.g.

```
#include<iostream>
using namespace std;
int main()
{
 /*This is a single line comment designed by multiple line comment symbol*/
}
```
