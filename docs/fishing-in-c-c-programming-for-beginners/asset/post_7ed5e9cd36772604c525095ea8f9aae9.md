
else
cout<<"It should be obvious";
}

In this program, output will be "It is strange, isn't it?". This is because whenever C++ assigns the value successfully to a variable then since it is a success, so by default true and so the condition inside the if() statement is true and hence you will have to be careful while using (==) and (=).

## Switch statement

As per its name, switch statement is used to switch between various cases. Consider the following program

```
#include<iostream>
using namespace std;
int main()
{
    int num=5;
    switch (num)
    {
        case 1: cout<<"1";
        case 5: cout<<"5";
        case 6: cout<<"6";
        case 7: cout<<"7";
            break;
        case 8: cout<<"8";
        default:
            cout<<"None of the cases matches";
    }
}
```

In the above program, switch statement compares the variable num with each of the cases, since num matches with 5 so, the statements in the corresponding case will be executed, in addition, there is no one to stop it from executing the further cases until either it strikes either the break statement or get out of it. So, output will be 567

**default** is also a keyword and the corresponding statement is executed automatically when none of the cases matches. It is optional to introduce the **default** keyword.

## Loops

Loop is a method to do a task again and again, need not to be a finite number of times.
Following loops are used in C

- 1. for loop
- 2. while loop
- 3. do...while loop

In addition of these three, a jumper goto is also used as a loop in C.

## for loop

It is the most popular loop. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    int i=5;
    for(i=7;i<10;i++)
    cout<<i;
}
```

The above program will print 789, this means the first statement in for loop is initialization,
and the second statement is a condition. The statement block under for loop will be
executed until this statement is true. As soon as this condition becomes false, the control
comes out of the loop. The third statement is executed after each and every execution of
statement within the for loop. The amazing fact about third statement is that each time, it
is executed before the second statement. Otherwise the result would have been 78910

Consider the following program

```
#include<iostream>
using namespace std;
int main()
{
    int i=5;
    for(i=11;i<10;i++)
    cout<<i;
}
```

This program will print nothing as first statement is always executed first, then before going inside the statements within the loop, the condition is checked. So, the condition is false, so nothing will be printed.

Other valid for loop formats include

```
for(i=0,j=5;i<5&&j>3;i++,j=j-5)
{
/*Statements*/
}
```

See carefully, we cannot use more than one statement in the second statement and if we want to, then they have to be joined by the logical operators.

Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
     int i=5;
     for(i=1;i<10&&i=11;i++)
     cout<<i;
}
```

Here, we have used logical operators, but it will be read by the compiler as (i<10&&i)=11, which is a wrong expression. So, it will generate an error: "value required as left operand of assignment"

Now consider the following program

```
#include<iostream>
using namespace std;
int main()
{
     int i=5;
     for(i=5;i<10&&(i=11);i++)
     cout<<i;
}
```

Guess its output. Well, its output will be 11, amazing isn't it? I have already said that it will execute first assignment inside for loop which is i=5. Now, it will check the condition, which is i<10&&(i=11), in which both the conditions cannot be true at a time, so it must be false. You are wrong; this is a demo of the power of modern computers. Our computers are multitasking, it does not mean that they are performing multiple tasks in a program simultaneously; rather, they jump from one task to another too rapidly to be realized by us. But, the consequence is on the result. Here, at first i is compared with 10 and the statement i<10 becomes true as i is initially 5. Now, 11 is assigned to i and it is a true statement as it is an assignment. Hence, both the statements are true. So, the statement following for loop which is cout<<i; is executed. But, now since value in i is 11, so 11 is displayed. Now, value of i is increased and its value becomes 12, now the statement i=11 is executed and then i<10 which becomes false now. So, program exits.

This will become clearer and even more interesting from the following program:

```
#include<iostream>
using namespace std;
int main()
{
    int i=5;
    for(i=1;i<10&&(i=3);i++)
    cout<<i;
}
```

Guess its output, well, its output will be :

![](img/5340985153962870d4e4a3b9453b9146_68_0.png)

i.e. an infinite loop. So, now you have understood that initially first assignment is executed, in the condition statement at first the first statement is executed, then second statement is executed then the result from both the statements are compared. If the final result is true, then the statement blocks within for loop is executed. Then third statement of for loop which is i++, is executed. Then, program takes a U turn and instead of executing the first statement of the condition, it executes the second statement of the condition which is i=3, now first statement of the condition which is i<10 is executed, which is obviously true. So, now again the statement blocks within for loop which is cout<<i; is executed and this process starts repeating and instead of using i=1; i<10 and i++ and && operator, the loop runs infinitely.

## while loop

While loop is used when we want to test the condition even before executing the first statement in the loop.

Consider the following program

```
#include<iostream>
using namespace std;
int main()
{
    int i=1;
    while(i<5)
    {
    cout<<i;
    i++;
    }
}
```

Output of the program will be 1234

## Do...while loop

The prominence of this loop lies in the fact that the first statement is executed before testing the first case and before each next execution condition is tested. Consider the following program.

```
#include<iostream>
using namespace std;
int main()
{
int i=1;
do
{
cout<<i;
i++;
}while(i>5);
}
```

Its output will be 1. Also note that a semicolon is required just after do...while loop, otherwise it will show a compile error “Expected ‘;’ before ‘}’ token”

## goto keyword

goto is a keyword which is used for a sudden jump from one part of the program to another. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
int i=5;
start:
cout<<i;
i++;
goto start;
}
```

In this program start is a label where we want the cursor to jump to. A colon is required after the label name. Whenever we want to jump to any label, we just use the syntax goto label_name; So, this program will jump infinitely many times to start and it is an infinite process. So, you will see an output like as follows

Remember goto is not a loop, it is just a jumper. So, we cannot use break and continue inside start...goto start;

## Break and Continue

These are two keywords which are used to control the loops in an effective way. Break is used to get out from the innermost loop, while continue is used to jump to the top of the loop.

Consider the following program

```
#include<iostream>
using namespace std;
int main()
{
int i,j;
for(i=1;i<3;i++)
{
for(j=6;j<9;j++)
{
cout<<"j";
if(j==7)
break;
}
cout<<"i";
}
return 0;
}
```

The output of the above program will be jijii. Since at first i is initialized with 1 and j with 6. Now, j will be printed. Now value of j is increased to 7 and again j is printed. But now j is 7, so break statement will be executed and the control comes out of innermost for loop and cout<<"i"; is executed. Now value of i will be incremented. And again inner for loop is executed. This process continues until the statement i<3 becomes false.

Consider the following program

```
#include<iostream>
using namespace std;
int main()
{
int i;
for(i=1;i<3;i++)
{
cout<<i;
continue;
cout<<"i";
}
