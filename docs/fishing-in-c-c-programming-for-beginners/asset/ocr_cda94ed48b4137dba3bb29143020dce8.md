# Abstract base classes and pure virtual methods

Consider the function declaration void call_me()=0; If declared outside the class then it will display an error "[Error] function 'void call_me()' is initialized like a variable".

But this declaration is fully valid inside the class if we add the keyword virtual before it i.e.

virtual void call_me()=0; This function is now called pure virtual function and it is equivalent to the function definition virtual void call_me() { return 0;} . You see how beautifully we have encapsulated the entire function definition into a function declaration. The class containing such types of functions are called abstract base classes. Remember this function declaration is possible inside a class only not outside it.

Consider the following program:

```
#include <iostream>

protected:
int length, breadth;
public:

virtual int area ()=0;
```
