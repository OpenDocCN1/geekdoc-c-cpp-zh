# Hacking: Exploiting computer security with Aman

See Here, logically you can think that I am passing an address to a function; at that address I am changing the value. So, the value in the main function should also change, but output of this program clearly shows that this is not happening. It means our logic is wrong somewhere. Suppose ch1 is stored at an address starting at 243145.Now, “Fishing in C” is an array of constant character. So, this is being assign to a variable, so according to the golden rule of computer, this will be stored before the assignment begins. So, it gets stored at an address say starting at 343233. Now, the value at the address 343233 which is Fishing in C is trying to replace the address of ch[] through the assignment ch=“Fishing in C” ! Since this assignment is not possible, so to fulfill your wish compiler puts the cursor of ch to the beginning of the string “Fishing in C” i.e.at 343233, but... we did not want that, our desire was to change the value at the address of ch1 and there we had to put the value of ch.
