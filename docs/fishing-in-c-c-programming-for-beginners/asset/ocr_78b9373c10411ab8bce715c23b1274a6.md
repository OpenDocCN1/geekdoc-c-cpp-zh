```
using namespace std;
int main()
{
    cout<<x;
}
int x=5;
```

This program will generate an error " x was not declared in this scope"
Now, let us modify the code a little bit as under:

```
#include<iostream>
using namespace std;
int main()
{
    extern int x;
    cout<<x;
}
int x=5;
```

Now, this program will execute successfully, giving the output 5.

# Default arguments

A function can have default arguments. These arguments are used automatically, if no argument is passed for them. A default argument is declared inside the function declaration. E.g. Consider the following program:

```
#include<iostream>
using namespace std;
int add(int x=1,int y=2);
int main()
{
    cout<<add()<<endl;
    cout<<add(5)<<endl;
}
```
