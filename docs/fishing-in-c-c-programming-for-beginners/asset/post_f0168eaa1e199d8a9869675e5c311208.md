## Stricmp

This function is similar to the previous one but it ignores the case while comparing and returns 0 if two strings are identical.

```cpp
#include<iostream>
#include<string.h>
using namespace std;
int main()
{
    char ch[50],ch1[50];
    cout<<"Enter a string\n";
    gets(ch);
    cout<<"Enter second string\n";
    gets(ch1);
    if(!strcmp(ch,ch1))
        cout<<"Strings are equal";
    else
        cout<<"Strings are unequal";
}
```

### Output

Enter a string
Forex.com teaches you to use it
Enter second string
Forex.COM teAches yOu to uSe it
Strings are equal

See, when the strings are equal, strcmp will return 0. So, (!strcmp) will return non zero values and hence the condition inside if() will be true. So, it will display "Strings are equal"

## Union and Enumeration

### Enumeration

It is a named data type. It continuously assigns consecutive whole numbers to its element starting from zero. If you assign another number to one of its element then for the next elements onwards, it automatically assigns the next consecutive whole numbers.

E.g. In the following program:

```cpp
#include<iostream>
using namespace std;
enum
{
    Red,Blue,Green,White=5,Yellow,Purple
};
int main()
{
    cout<<Red<<Blue<<Green<<White<<Yellow<<Purple;
    return 0;
}
```

Output will be 012567. So, we can use this name say Green everywhere in our program, and in our program, everywhere its value will be treated as 2.

Enumeration is used as a data type. Its object can be declared. Consider the following program:

```cpp
#include<iostream>
using namespace std;
enum color{red,blue,green,white};
int main()
{
    enum color c1,c2;
    c1=blue;
    c2=red;
    cout<<"Even color is "<<c2;
    return 0;
}
```

Amazingly, its output will be zero.

### Passing enum to the function

Enum can also be passed to the function. It can be passed in two ways:

- Calling by value
- Calling by reference

Again calling by reference can be subdivided into two parts

- Calling using pointers
- Calling without using pointers

### Call by value

Consider the following program:

```cpp
#include<iostream>
using namespace std;
enum color{red,blue,green,white};
void modify_enum(enum color x);
int main()
{
    enum color c1;
    c1=blue;
    modify_enum(c1);
    cout<<c1;
    return 0;
}
void modify_enum(enum color x)
{
    x=green;
    cout<<x;
}
```

Output
21

See here, value has not been modified at the actual address.

### Call by reference using pointers

Enumeration can also be modified using call by reference using pointers.

```cpp
#include<iostream>
using namespace std;
enum color{red,blue,green,white};
void modify_enum(enum color *x);
int main()
{
    enum color c1=blue;
    modify_enum(&c1);
    cout<<c1;
    return 0;
}
void modify_enum(enum color *x)
{
    *x=green;
}
```

Output
2

See here, 2 corresponds to green means value has been modified.

### Call by reference without using pointers

Following program illustrate to modify enum by calling without using pointers:

### Union

Union is a derived data type, which resembles structure in look but is not. Consider the following union

```
union un
{
int a;
char b[4];
};
```

Here, since I am using a 64 bit compiler, so I used char b[4]. If you are using a 32 bit compiler, then you should write char b[2]. So, the amazing thing about union is that it divides the memory among its element, i.e its size is 4 bytes only, not 8 bytes.

Consider the following program in 64 bit compiler:

```cpp
#include<iostream>
using namespace std;
union un
{
    int a;
    char b[4];
};
int main()
{
    union un un1;
    un1.a=204800001;
    cout<<un1.a<<"\n";
    cout<<int(un1.b[0])<<endl;
    cout<<int(un1.b[1])<<endl;
    cout<<int(un1.b[2])<<endl;
    cout<<int(un1.b[3])<<endl;
}
```

Output will be

```
204800001
1
0
53
12
```

Why? Because binary of 204800001 is 00001100 00110101 00000000 00000001

So, 00001100=12, 00110101=53, 00000000=0,00000001=1. So, we can see that the same memory which is for int has been divided to char b[4]; too.
