# # Introduction

C++ is an object oriented programming language. It consists of following features:

+   1. Data encapsulation: The data members can be bind into one capsule called class.
+   2. Data hiding: Using this feature we can hide the data members and member functions from outside the class.
+   3. Code Reuse and Recycle: The same code can be reused again and again.
+   4. Inheritance: It is the ability to derive a class from a base class.
+   5. Polymorphism: It is the ability to process different variables, functions, operators or objects in different ways.

When, we shall move forward, you will see how these are automatically implemented while programming.

C++ was developed by Bjarne Stroustrup in 1979 at AT & T's Bell laboratory Initially it was named C++ with classes but later it was renamed to C++ in 1983.
