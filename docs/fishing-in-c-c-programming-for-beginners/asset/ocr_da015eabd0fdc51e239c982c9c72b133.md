# Constructor overloading

Constructor can be overloaded like functions, we can define multiple constructors, but while declaring the constructor it should be noted that we can create only those objects which has exactly the same number of arguments as in the constructor.

```
#include<iostream>
using namespace std;
class area {
int x, y;
public:
area();
area (int,int);
int calculate_area (void);
};
int main()
{
    class area rectangle;
    class area parallelogram(4,2);

    cout<<"Area of rectangle is "<<rectangle.calculate_area()<<endl;
    cout<<"Area of parallelogram is "<<parallelogram.calculate_area());
    return 0;
}
area::area()
{
    x=y=1;
}
area::area(int a,int b)
```
