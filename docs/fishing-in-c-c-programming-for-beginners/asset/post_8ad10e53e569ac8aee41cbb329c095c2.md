
## Reading characters from a file

Suppose we want to read only a single character from a file, then we have to open it using ios::in. Following program illustrates to read a character from a file.

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::in);
    if(fin==NULL)
    {
        cout<<("Can't open the file");
        return -1;
    }
    char ch;
    fin>>ch;
    cout<<ch;
    fin.close();
    return 0;
}
```

### Output

b

Now, consider the following program:

```cpp
#include<iostream>
#include<fstream>

int main()

    while(!(fin.eof()))
    {
        fin>>ch;
        cout<<ch;
    }
    fin.close();

```

### Output

See here, we have used fin.eof() to detect the end of file. Output is not formatted. One more thing missing in the output is special characters like newline and spaces. It means like cin>>, file pointer is also unable to detect whitespaces. So, now time has come to search for a more reliable method for reading characters, which can give us a more correct result.

## Reading entire file: Character by character

In the following program, we have used get() function to read each and every character from the file.

Consider the following program:

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::in);
    if(fin==NULL)
    {
        cout<<"Can't open the file");
        return -1;
    }
    char ch;
    while(!fin.eof())
    {
        fin.get(ch);
        cout<<ch;
    }
    fin.close();
    return 0;
}
```

### Output

b
5
I am Aman

See here, each and every character and whitespaces have been displayed exactly as it is.

## Reading a string from a file

We can also read a string from file. For this purpose we use a function getline()

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::in);
    if(fin==NULL)
    {
        cout<<"Can't open the file");
        return -1;
    }
    char ch[10];
    while(!fin.eof())
    {
        fin.getline(ch,10);
        cout<<ch;
    }
    fin.close();
    return 0;
}
```

### Output

b5I am Aman

See here, the getline() function recognizes the blank spaces but it cannot recognizes the newline character.

## File position pointer

Using file position pointer, we can travel in a file from one point to other.

seekg(offset,whence) – This function places the 'get' cursor to the place offset, counted from whence. This function is used when we want to read something from file. Here whence may have three values.

- ios::beg – This is used to start counting offset position from beginning of file.
- ios::cur – This is used to start counting offset the position from current position.
- ios::end – This is used to start counting offset the position from end of file.

Consider the following program:

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::out);
    if(fin==NULL)
    {
        cout<<("Can't open the file");
        return -1;
    }
    fin<<"Hacking: Exploiting computer security with Aman";
    fin.close();
    fin.open("example.txt",ios::in);
    char ch;
    fin.seekg(3,ios::beg);
    ch=fin.get();
    cout<<ch;
    fin.close();
    return 0;
}
```

### Output

k

From the output, you can easily see that first character is set the offset value zero. This program places the cursor inside the file to fourth place i.e. offset number three, from the beginning of the file. Here, you can see that we have opened the file with read and write mode. While opening the file in both read and write mode, we have to take care that since the file has been opened in read mode too, so there must be an existing file with the same name at the corresponding location. If there is no any existing file with the same name then an error will be displayed because the file will not be automatically created. In that case the above program will display an error “Can’t open the file”. In that case, you can open the file in output mode then close it and reopens it in read mode. Following program displays an example program to perform this task:

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::out);
    if(fin==NULL)
    {
        cout<<"Can't open the file");
        return -1;
    }
    fin<<"Hacking: Exploiting computer security with Aman";
    fin.close();
    fin.open("example.txt",ios::in);
    char ch;
    fin.seekg(3,ios::beg);
    ch=fin.get();
    cout<<ch;
    fin.close();
    return 0;
}
```

The above program will display no error. Since, if the file “example.txt” does not exist then it will be created.Here, we have to read some data from the file,so we used seekg().

seekg() is an overloaded function. So, it has one more prototype:

```
seekg(offset);
```

This function always assumes offset from the beginning of the file. So, it is an alternative of seekg(offset,ios::beg);

seekp(offset,whence) - This function places the ‘put’ cursor to the place offset, counted from whence. This function is used when we want to put something to the file.

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;

    fin.open("example.txt",ios::in | ios::out);

    if(fin==NULL)
    {
        cout<<("Can't open the file");
        return -1;
    }

    fin<<"I am Aman";
    fin.seekp(4,ios::beg);

    fin<<"Hacking: Exploiting computer security with Aman";

    char ch;

    fin.seekg(0,ios::beg);

    while(!fin.eof())
    {
        ch=fin.get();
        cout<<ch;
    }

    fin.close();

    return 0;
}
```

### tellg()

tellg() – This function returns the position of ‘get’ cursor in a file in terms of offset

Consider the following program:

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::in | ios::out);
    if(fin==NULL)
    {
        cout<<("Can't open the file");
        return -1;
    }
    fin<<"Hacking: Exploiting computer security with Aman";
    fin.seekg(5,ios::beg);
    int i=fin.tellg();
    cout<<i;
    fin.close();
    return 0;
}
```

### Output

5

This program places the cursor at fifth offset then it returns its position.

## Using state flags

In addition to eof(), which checks if the end of file has been reached, other member functions exist to check the state of a stream (all of them return a bool value):

### badbit and bad()

The badbit is set and bad method returns true if a reading or writing operation fails. For example in the case that we try to write to a file that is not open for writing.

Consider the following program:

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin("example.txt",ios::in);
    if(fin==NULL)
    {
        cout<<"Can't open file";
        return -1;
    }
    fin<<"Hello";
    if(fin.bad())
    {
        cout<<"Can't write";
    }
    fin.close();
}
```

### Output

Can't write

### failbit and fail()

The failbit is set and fail method returns true in the same cases as bad(), but also in the case that a format error happens, like when an alphabetical character is extracted when we are trying to read an integer number.
