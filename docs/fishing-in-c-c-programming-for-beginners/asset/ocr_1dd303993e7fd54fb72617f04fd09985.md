| Accessible to | private | protected | public |
|---|---|---|---|
| members of the same class | yes | yes | yes |
| members of derived classes | no | yes | yes |
| not members | no | no | yes |

Where not members is any type of access tried from other class which has not been derived from it, or any access from other functions including main, which is not a member of the class.

Consider the following program:

```
#include<iostream>
using namespace std;
class area {
int x, y;
public:
void assign_values (int,int);
int calculate_area (void);
};
int main()
{
class area rectangle;
rectangle.assign_values(3,5);
cout<<"Area of rectangle is "<<rectangle.calculate_area();
return 0;
}
void area::assign_values(int a,int b)
{
x=a;
y=b;
}
```
