Here, we have used a function add((int,int); See, we have defined a function above the main() function. Many a times , it is required to define the function below the main function, so there at first we declare the function and the corresponding expression is known as function prototype.

A function prototype can be declared in two ways:

First method is:

```
```
return_type function_name(data_type1,data_type2,...);
```
```

The other one is:

```
```
return_type function_name(data_type1 arg1,data_type2 arg2,...);
```
```

E.g. the above program, that we used can also be written in the following way:

```
```cpp
#include<iostream>
int add(int,int); //This is a function prototype
using namespace std;
int main()
{
    int x=5,y=6;
    cout<<add(x,y);
}
```
