# NOT operator

! is NOT operator

| x | !(x) |
|---|---|
| 0 | 1 |
| 1 | 0 |

Now, consider the following amazing program

```
#include<iostream>
using namespace std;
int main()
{
    int a=13;
    int c=(!a);
    cout<<c;
    return 0;
}
```

Here, output is 0, while it should be !(13)=!(1101)=0010=2. The reason is that NOT operator considers everything other than zero to be true. Hence 13 is non zero. So, it is true, hence its negation will be false. So, output is zero. In the above program, if we replace 13 by (-13) then again the output will be zero. While if we replace 13 by 0 then the output will be 1.
