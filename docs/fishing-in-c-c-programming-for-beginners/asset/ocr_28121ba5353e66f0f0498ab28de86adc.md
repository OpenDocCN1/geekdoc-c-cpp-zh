See, we amazingly abbreviated a thirty lines program into a seventeen lines program. So, you can imagine the labour saved in a multi-file program.

Many a times we do not require the type to determine, the result is independent of type and there we do not pass the type while calling the function.

Consider the following program:

```
#include<iostream>
using namespace std;
template <class T>
T return_max(T x, T y)
{
return (x > y? x : y);
};
int main()
{
cout<<"Enter first number: ";
int a;
cin>>a;
cout<<"Enter second number: ";
int b;
cin>>b;
cout<<"Maximum is: "<<return_max(a,b);
}
```
