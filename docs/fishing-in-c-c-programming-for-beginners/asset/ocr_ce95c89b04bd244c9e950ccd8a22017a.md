```
struct student s1[5];
int i;
for(i=0;i<5;i++)
{
    cout<<("Enter the name of student\n");
    gets(s1[i].name);
    cout<<("Enter the section of student\n");
    cin>>s1[i].section;
    cout<<("Enter the roll number of the student\n");
    cin>>s1[i].roll;
    fflush(stdin);
}
for(i=0;i<5;i++)
{
    cout<<("\nThe name of student is: ");
    puts(s1[i].name);
    cout<<("\nThe section of the student is: "<<s1[i].section;
    cout<<("\nRoll number of the student is: "<<s1[i].roll;
}
return 0;
}
```

Here, you can see that we have used a new function fflush(stdin), why? The fact is as soon as the roll number is entered and enter is pressed then roll number is taken by s1[i].roll and ‘enter’ is kept in buffer for next input. Now, a query for name is displayed and it requires an input, since ‘enter’ is in buffer for next input. So, it is now received as the name and the query for the section is appeared immediately. So, user understand that the program skipped the input. fflush(stdin), flushes the input buffer and so, program asks for name and user can give the input. Just, abolish fflush(stdin); statement and see what happens.
