# Nested try...catch

Try...catch can be nested into each other. Following program illustrates this fact:

```
#include<iostream>
using namespace std;
int main()
{
    try
    {
    int*arr=new int;
    try
    {
    long double*array=new long double[100000000000000000];
    }
    catch(...)
    {
    cout<<"Internal error occurred";
    }
}
```
