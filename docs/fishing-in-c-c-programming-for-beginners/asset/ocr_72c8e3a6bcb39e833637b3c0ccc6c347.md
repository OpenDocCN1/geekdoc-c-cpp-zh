Consider the following program

```
#include<iostream>
using namespace std;
int main()
{
    int b=5;
    int *a=&b;
    cout<<*a;
    return 0;
}
```

This program will assign the address of b to a not to *a as it looks. So, output will be shown as 5

To remove the confusion int*a=&b; can also be written as:

```
int *a;
a=&b;
```

Now, if you change the value stored at a as in the following program, then the value will be changed at the address.

