```
using namespace std;
int main()
{
    int b=5;
    int*a=&b;
    cout<<*a;
    *a=7;
    cout<<endl<<b;
    cout<<endl<<*a;
}
```

Output:
5
7
7

This program illustrates the fact that; whatever the change we carry out through a pointer, the changes occur at the memory address.

Consider the following program:

```
#include<iostream>
using namespace std;
int display1(int*x);
int main()
{
    int a=5;
    cout<<a;
    display1(&a);
    cout<<a;
}
int display1(int*x)
```
