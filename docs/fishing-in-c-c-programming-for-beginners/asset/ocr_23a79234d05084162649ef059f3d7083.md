# eofbit and eof()

The eofbit is automatically set for an input stream when EOF is encountered. When EOF is encountered on cin, the call cin.eof returns true. Here “encounterer” means that there is no more bytes to read from the input stream. Returns true if a file open for reading has reached the end. We have already seen its example.
