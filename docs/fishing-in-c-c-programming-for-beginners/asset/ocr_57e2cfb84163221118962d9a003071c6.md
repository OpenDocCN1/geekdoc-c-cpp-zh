}
Output
\b
,
"

See here, to print single apostrophe, double apostrophe and backslash, we have to use backslash before them.

# puts() function

puts() is a function used to print the string output and then place a line feed. This function is defined in stdio.h. So, if at compiler time the compiler gives you an error puts() should have a prototype or puts() undeclared, then just use one more sentence #include<stdio.h> at the beginning of the program. All latest compilers, include this function in iostream too.

E.g. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    puts("Aman");
    puts("Kumar");
}
```

Output:

Aman
Kumar

Here, Aman and Kumar will be printed in separate lines instead of using no newline character. This is one of the features of puts()
