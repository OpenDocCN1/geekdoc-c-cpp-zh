Here, first argument is the address of buffer we the data is stored. Suppose the data is stored at array[11] then out first argument will be array. Since it is of char type, so it is better to typecast it using (char*) buffer. So, our first argument will be (char*)buffer. Suppose, you want to write a structure say s1 into the file, in that scenario our first argument will be (char*)&s1.Second argument is the total number of elements to write into the file. Suppose the variable char array[11], so second argument will 11. Suppose we are going to write a structure say s1 into the file,so second argument will be sizeof(s1).
