# Returning a string

Strings can be returned also, as in the following program:

```
#include<iostream>
using namespace std;
char*modify_string();
int main()
{
     char *ch1=modify_string();
     puts(ch1);
     return 0;
}
char*modify_string()
{
     char *ch="Fishing in C++";
     return ch;
}
```

Output

Fishing in C++
