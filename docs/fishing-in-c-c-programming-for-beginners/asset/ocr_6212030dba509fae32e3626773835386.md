```
class area
{
    int x, y;
public:
    area();
    area(area&);
    int calculate_area (void);
};
int main()
{
    class area rectangle;
    class area parallelogram(rectangle);
    cout<<""\nArea of rectangle is "<rectangle.calculate_area()<endl;
    cout<<"Area of parallelogram is "<parallelogram.calculate_area();
    return 0;
}
area::area()
{
    x=y=1;
}
area::area(area& s)
{
    x=5;
    y=s.y;
    cout<<"Calling copy constructor";
}
int area::calculate_area()
{
    return x*y;
}
```

Output
Calling copy constructor
Area of rectangle is 1
Area of parallelogram is 5

# Destructor

Just like we called a constructor to create an object, similarly we can destroy an object using a destructor. It also has same name as the class. So, how to separate it from constructor? To separate it from constructor, we use a tilde sign (~) preceding it. Like constructor, it also returns nothing. The use of destructors is especially suitable when an object assigns dynamic memory during its lifetime and at the moment of being destroyed we want to release the memory that the object was allocated. It is also automatically called like constructors.
