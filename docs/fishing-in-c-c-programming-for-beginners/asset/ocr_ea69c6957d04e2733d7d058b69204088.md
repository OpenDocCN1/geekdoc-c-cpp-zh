process. In that case, whichever strikes earlier out of second and third argument, is used to terminate the input process.

E.g, consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    char ch[50];
    cout<<"Enter a line\n";
    cin.getline(ch,50);
    cout<<"Entered line is: "<<ch;
}
```

Output

Enter a line

I am Aman

Entered line is: I am Aman

Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    char ch[50];
    cout<<"Enter a line\n";
    cin.getline(ch,50,*);
    cout<<"Entered line is: "<<ch;
}
```
