# Helloc World

See, here \b moves the cursor right to character ‘o ’ then we overwrite w by c. We can also overwrite any character by space.

# Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    cout<<"Helloc\b World";
}
```

# Output

Hello World

Here, we have left a space just after \b and so w is overwritten with space and we get our desired output Hello World.

# \f Formfeed

This character is negligibly used in programs but it is widely used if printer or word file is included. Well this character signals the OS that the current form has been ended and it is the time to start a new form. But, in program output it only displays the character which play this role for printer or file. So, if we want to insert a new page in word file through program then we use \f there.
