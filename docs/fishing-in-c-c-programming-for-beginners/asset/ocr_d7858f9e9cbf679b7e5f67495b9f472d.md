# Call by reference using pointers

Enumeration can also be modified using call by reference using pointers.

```
#include<iostream>
using namespace std;
enum color{red,blue,green,white};
void modify_enum(enum color *x);
int main()
{
    enum color c1=blue;
    modify_enum(&c1);
    cout<<c1;
    return 0;
}
void modify_enum(enum color *x)
{
    *x=green;
}
```

Output
2
See here, 2 corresponds to green means value has been modified.
