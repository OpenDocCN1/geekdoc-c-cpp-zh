This program will show no error due to no bound checking. So be careful about boundary while using array. However, if you cross the boundary while initializing then the compiler detects it and give an error.

E.g. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    int a[3]={1,2,4,5};
}
```

This program will give an error “Too many initializers for int[3]”
