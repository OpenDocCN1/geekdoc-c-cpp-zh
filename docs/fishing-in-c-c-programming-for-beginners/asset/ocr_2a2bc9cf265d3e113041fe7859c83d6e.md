#define can be used to test the conditions also. Let us see how.

Consider the following program:

```
#include<iostream>
using namespace std;
#include<math.h>
#define a
int main()
{
#ifdef a
    cout<<("5+2=8\n");
    cout<<("\"Make Fool\" process was ON\n");
#endif
    cout<<("5+2=7");
}
```

Since a has been defined, so output will be

5+2=8
“Make Fool” process was ON
5+2=7

Here, \’ is used, it is because if we want to display, we cannot directly put “ as program will understand that string is being finished, and when we shall give “ again to finish the string it will give an error saying “[Error] expected ’) before ’Make”. So, we use \ to avoid the confusion for the program. Remember, here, #endif is must, else it will show an error saying “Unterminated #ifdef”. Also, see here that a has been defined with nothing. You can define it with some value if you want.
