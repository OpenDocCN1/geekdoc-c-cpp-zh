# setprecision()

It is used to set the precision points. Suppose, you have a value say 21.23456789 and you want to display this number upto five digits then the program will be.

```
#include<iostream>
#include<iomanip>
using namespace std;
int add(int,int);
int main()
{
    float a=21.23456789;
    cout<<setprecision(5)<<a;
}
```
