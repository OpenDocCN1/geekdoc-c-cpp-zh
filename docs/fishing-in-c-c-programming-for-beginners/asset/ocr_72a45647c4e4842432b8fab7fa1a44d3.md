```
{
int a=7,*b=&a;
cout<<b;
b++;
cout<<endl<<b;
}
```

Output (yours may be different)

0x22fe44

0x22fe48

Note here that, we have increased b by 1 ,so, this will increased by one memory block of the corresponding data type which is int. So, in 64 bit compiler an increase of 4bytes will be observed, while in 32 bit compiler an increase of 2 bytes will be observed.

Direct multiplication or division between two pointers is not possible.
