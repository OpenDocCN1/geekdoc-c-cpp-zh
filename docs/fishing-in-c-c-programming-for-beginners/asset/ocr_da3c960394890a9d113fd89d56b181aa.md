# Switch statement

As per its name, switch statement is used to switch between various cases. Consider the following program

```
#include<iostream>
using namespace std;
int main()
{
    int num=5;
    switch (num)
    {
        case 1: cout<<"1";
        case 5: cout<<"5";
        case 6: cout<<"6";
        case 7: cout<<"7";
            break;
        case 8: cout<<"8";
        default:
            cout<<"None of the cases matches";
    }
}
```

In the above program, switch statement compares the variable num with each of the cases, since num matches with 5 so, the statements in the corresponding case will be executed, in addition, there is no one to stop it from executing the further cases until either it strikes either the break statement or get out of it.
