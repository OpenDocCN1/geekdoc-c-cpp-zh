## Functions

Function is a block of statements used to perform a specific task. One of the burning fact is “Except main() function, no function is required at all to perform tasks”. Main() function is only required because the program execution searches for this function and shows a compile error, if not defined.

Still, we use various functions, due to following reasons:

- 1. It makes our task simpler by dividing it into various parts.
- 2. The program is easy to read and understandable.
- 3. It is easier to correct errors
- 4. Error in one function, does not affect the other.
- 5. It is independent of the numerical value of the input given

There are two types of functions:

- 1. Library function: These are predefined in a header file.
- 2. User defined function: These are those functions which are defined by the programmer.

Syntax of a function definition is:

```cpp
return_type func_name(data_type1 arg1,data_type2 arg2,....)
{

/*Statements*/

}
```

where arg1,arg2 etc are called the arguments. These are the parameters passed to the function for further processing.

One of the functions we have used till now is :


A function prototype can be declared in two ways:

First method is:

The other one is:

## Recursion

Recursion is a method of calling function in which a function is called from itself and within itself. It makes the program elegant, attractive and compact. But, it makes the program slow to a little extent as C++ maintains a stack while calling the functions.

Consider the following program:

```cpp
#include<iostream>
using namespace std;
int factorial(int);
int main()
{
    int a=5;
    cout<<factorial(a);
}
int factorial(int x)
{
    if(x==1 || x==0)
        return 1;
    else
        return x*factorial(x-1);
}
```

Output will be 120. Here, see inside the definition of factorial function, we have again called the factorial of (x-1). This program will be executed in the following sequence:

- 5*(5-1)
- 5*((5-1)*(5-2))
- 5*((5-1)*((5-2)*(5-3)))
- 5*((5-1)*((5-2)*((5-3)*(5-4))))
- 5*((5-1)*((5-2)*((5-3)*1)))
- =120

## Variables Revisited

Initially, we talked of variables there we did not talk about the type of variables on the basis of accessibility. Well, On the basis of accessibility variables are of four types:

- 1. Automatic storage class
- 2. Static storage class
- 3. Register storage class
- 4. Extern storage class

Auto – It is the default data type for all the variables used inside a function, hence we did not write auto anywhere.

e.g. auto int a=5;

Default initial value – An unpredictable value, which is often called a garbage value.
Life – Till the control remains within the block in which the variable is defined.
Scope – Local to the block in which the variable is defined.
Storage – Memory.

Static – The peculiarity of static variable is that it remembers the last value stored.

Consider the following program

```cpp
#include<iostream>
using namespace std;
void change();
int main()
{
    change();
    change();
}
void change()
{
    static int a=0;
    a++;
    cout<<a;
}
```

This program will display 12. This displays the fact that initially value of a was increased to 1 from 0. Now, when the function was called second time, its value was increased from 1 to 2.

Register – Register is a type of variable which gives a request to the compiler to store the variable in a CPU register, if possible; else it is declared auto. A Register gives faster read and write access to the variables.

To declare a variable in C++ as register, just add register keyword before the declaration.

E.g.

```cpp
register int a=5;
```

- Default initial value . Garbage value.
- Life . Till the control remains within the block in which the variable is defined.
- Scope . Local to the block in which the variable is defined.
- Storage . CPU registers.

Extern – This variable is defined outside of the main() and all other functions. Its value can be modified by any of the functions.

Consider the following program

```cpp
#include<iostream>
using namespace std;
int a=5;
int display1();
int main()
{
    cout<<a;
    display1();
    cout<<a;
}
int display1()
{
    a=6;
}
```

Its output will be 56 as initially it was assigned 5 then display1() function is called which modifies its value and assigns 6 to it. Now, just after function calling, the handle is returned to the main function. Now, when value is displayed there, it shows 6. Here, a is called a global variable and accessible to all the functions inside the program.

```cpp
#include<iostream>
```
