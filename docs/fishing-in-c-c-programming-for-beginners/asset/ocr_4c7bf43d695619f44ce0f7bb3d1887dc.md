It is important to remember that while initializing a 2-D array it is necessary to mention the second dimension, whereas the first dimension is optional.

So the declarations:

```
int num[2][3] = { 1, 3, 2, 4, 98, 78 };
int num[][3] = { 2, 4, 2, 4, 6, 5 };
```

are acceptable,whereas,

```
int num[2][] = { 12, 34, 23, 45, 56, 45 };
int num[] [] = { 12, 34, 23, 45, 56, 45 };
```

would give the error “Array type has incomplete element type”

Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    int num[2][3]={{0,1,5},{6,7,8}};
    int i;
    for(i=0;i<2;i++)
    {
        cout<<"\nAddress of num["<<i<<"] is "<<num[i];
    }
}
```

When you will run this program,you will see that the difference between address of num[0] and num[1] is of 12 bytes. It means that num[0] contains three memory block num[0][0],num[0][1] and num[0][2], then the memory block of num[1] starts. More amazingly this program shows that each array whose dimension is one less than the actual array represents the address of the actual array. It means we can access the elements of multidimensional array by efficient use of pointers.
