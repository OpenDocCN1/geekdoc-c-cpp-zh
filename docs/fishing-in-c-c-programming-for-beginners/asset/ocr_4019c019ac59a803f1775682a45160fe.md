Click on File->New->Source File

Or just press Ctrl+N. Now, you will see a blank space where you can write the program. So let us start, just type:

```
#include<iostream>
using namespace std;
int main()
{
    cout<<"Hello World";
    return 0;
}
```

Now press F11 to compile and run the program or from the menu bar find run ,compile and run, build and run and select anyone of these to compile and run program. Now, you will be asked to save your program
