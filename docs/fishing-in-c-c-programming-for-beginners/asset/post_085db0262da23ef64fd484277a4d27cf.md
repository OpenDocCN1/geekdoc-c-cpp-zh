Consider a function max(x,y) that returns the larger of its two arguments. x and y can be of any type that has the ability to be ordered. Because C++ is a strongly typed language, it expects the types of the parameters x and y to be declared at compile time. Without using templates, many overloaded versions of max() are required (one for each data type to be supported), even though the code for each version is essentially identical. Each version compares the arguments and returns the larger.

By using a template, you can define a pattern for a family of related overloaded functions by letting the data type be a parameter:

```
template <class T>

T max(T x, T y)
{
    return (x > y) ? x : y;
};
```

The data type is represented by the template argument <class T>. When you use this template in an application, the compiler generates the appropriate function according to the data type actually used in the call:

```
int i;
```

```
Myclass a, b;
```

```
int j = max(i,0); // arguments are integers
Myclass m = max(a,b); // arguments are type Myclass
```

Any data type even including classes and objects can be compared as you can see above snippet. The compiler takes care of calling the appropriate operator>(), so you can use max with arguments of any type for which operator>() is defined.

So, our program can be rewritten as:

```
#include<iostream>
using namespace std;
template <typename T>
T random(T a, T b);
int main()
{
    short p=random<short>(5,6);
    int q=random<int>(5,6);
    double r=random<double>(5,6);
    long double s=random<long double>(5,6);
    cout<<p<<endl<<q<<endl<<r<<endl<<s;
}
template <typename T>
T random(T a, T b)
{
    return a+b+sizeof(T);
}

## Class Templates

You use a class template (also called a generic class or class generator) to define a pattern for class definitions. Generic container classes are good examples. Whether you have a list of integers or any other type, the basic operations are the same (insert, delete, index, etc.). You can define the class structure with generic operations once, and let the system generate class definitions on the fly:

```
template <class T>
class List
{
T *v;
int size;
public:
List(int);
T& operator[](int i) { return v[i];}
};
```

// Out-of-class definitions require a special syntax:

```
template <class T> List<T>::List(int n)
{
v = new T[n];
size = n;
}
```

Given the preceding class definitions, you can instantiate a list of any
type:

x[3] = 7;

We also have the possibility to write class templates, so that a class can have members that
use template parameters as types. For example:

```
template <class T>

class pairs

{

    T values [2];

    public:

    pairs (T first, T second)

    {

        values[0]=first;

        values[1]=second;

    }

};
```

This class stores two elements of any valid type. For example, if we want to declare an
object of this class to store two integer values of type int with the values 4 and 5 we would
write:

```
pairs<int> myint (4,5);
```

This class can also be used to create an object to store any other type:

```
pairs<double> mydouble (2.0, 4.25);
```

The only member function in the previous class template has been defined inline within the class declaration itself.

In case that we define a function member outside the declaration of the class template, we precede that definition with the template <> prefix:

```
#include <iostream>

using namespace std;

template <class T>
class pairs
{
    T x, y;

public:
    pairs (T first, T second){x=first; y=second;}
    T getmax ();

};

template <class T>
T pairs<T>::getmax ()
{
    T retval;
    retval = x>y? x : y;

    return retval;
}

int main ()
{
    pairs <int> myobject (34, 43);
    cout << "The Maximum value is: "<< myobject.getmax();

    return 0;
}
```

## Template specialization

If we want to define a different implementation for a template when a specific type is passed as template parameter, we can declare a specialization of that template.

For example, let's suppose that we have a very simple class called size_return that returns the sum of size of the data type and the value passed for all data types except integers. For integers we want to return the value only. So, it would be more convenient to have a completely different implementation with a function member int, so we decide to declare a class template specialization for that type.

The syntax used in the class template specialization is:

```
template <>
class size_return <int>
{
//Statements
};
```

First of all, notice that we precede the class template name with an empty template<> parameter list. This is to explicitly declare it as a template specialization. Another thing is the <int> specialization parameter after the class template name. This parameter itself identifies the type for which we are going to declare a template class specialization. Notice the differences between the generic template class and the specialization:

```
template <class T> class size_return{ //Statements };
```

```
template <> class size_return <int> { //Statements};
```

The first line is the generic template, and the second one is the specialization. When we declare specializations for a template class, we must also define all its members, even those exactly equal to the generic template class, because there is no "inheritance" of members from the generic template to the specialization.

Now, consider the following program:

```
#include <iostream>
using namespace std;
// class template:
template <class T>
class size_return
{
  T element;
public:
  size_return (T arg) {element=arg;}
  T operate () {return element+sizeof(T);}
};
// class template specialization:
template <>
class size_return <int>
{
  int element;
public:
  size_return (int arg) {element=arg;}
  int return_value() {return element;}
};

int main ()
{
  size_return<float> myfloat (23.3);
  size_return<double> mydouble (233);
  size_return<int> myint (23);
  cout << myfloat.operate()<< endl;
  cout << mydouble.operate()<< endl;
  cout << myint.return_value();
  return 0;
}
```

Output
27.3
241
23
