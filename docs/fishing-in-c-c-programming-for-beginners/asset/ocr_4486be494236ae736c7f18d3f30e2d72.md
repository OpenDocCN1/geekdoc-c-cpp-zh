# Decision control

# if...else

Decisions can be controlled using if...else. Consider the following code:

```
#include<iostream>
using namespace std;
int main()
{
    int num=53;
    if(num%5==0)
        cout<<"The number is divisible by 5";
    else
        cout<<"The number is not divisible by 5";
    return 0;
}
```

Here, % is the modulus operator, which stores the remainder. E.g. in declaration int b=a%5; a is divided by the 5 and the remainder is stored in b. So, in above program, num is divided by 5 and the remainder is compared with 0. If the remainder is equal to zero, then the program displays that the number is divisible by 5 else it displays the contrary.

Also note that we have used two signs of equality (==) not one (=) for comparison as we have already used single equality for assigning the value to a variable like in int num=5;.
