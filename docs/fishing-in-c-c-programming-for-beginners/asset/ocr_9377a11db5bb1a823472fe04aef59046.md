# ## Introduction

cout is used to print all the three types of data numbers, characters, strings. This is one of the benefits over C language; there we had to be very careful about what type of data we are going to print.

# ## To display a character

Following is an example of displaying a character say 's':

```
#include<iostream>
using namespace std;
int main()
{
    cout<<'s';
}
```

Output

s

# ## To display a string

```
#include<iostream>
using namespace std;
int main()
{
    cout<<"This is a string";
}
```

Output

This is a string

# ## To display a number

To display a number we directly put the name of variable just after left shift operator (<<)
