```
int main ()
{
    square sqr;
    rectangle rect;
    sqr.set_side(5);
    rect.set_square(sqr);
    cout<<rect.area());
    return 0;
}
```

This program is just a simple manipulation of the previous program. Here, we have tried to pass the class square in a function set_square in the class rectangle, but before that we have nowhere defined the class square. So, this program will display multiples error, including “[Error] 'square' has not been declared”. So, we have to declare the class before its use.

The syntax of declaring the class is very simple, just add following statement at the top:

```
class class_name;
```
