# oct, dec, hex

These are some of the macros used to display the octal value and hexadecimal value of a variable or constant, e.g. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    cout<<17<<endl;
    cout<<oct<<17<<endl;
    cout<<hex<<17<<endl;
    cout<<dec<<17;
}
```

Output

+   17
+   21
+   11
+   17
