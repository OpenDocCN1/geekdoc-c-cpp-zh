

## 从文件读取字符

假设我们想从文件中只读取一个字符，那么必须使用 `ios::in` 打开它。下面的程序演示了如何从文件读取一个字符。

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::in);
    if(fin==NULL)
    {
        cout<<("Can't open the file");
        return -1;
    }
    char ch;
    fin>>ch;
    cout<<ch;
    fin.close();
    return 0;
}
```

### 输出

b

现在，考虑以下程序：

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt", ios::in);
    if(fin==NULL)
    {
        cout<<("Can't open the file");
        return -1;
    }
    char ch;
    while(!(fin.eof()))
    {
        fin>>ch;
        cout<<ch;
    }
    fin.close();
    return 0;
}
```

### 输出

b5IamAman

请看，我们使用了 `fin.eof()` 来检测文件末尾。输出未格式化。输出中还缺少换行符和空格等特殊字符。这意味着就像 `cin>>` 一样，文件指针也无法检测空白字符。所以，现在是时候寻找一种更可靠的读取字符的方法，它可以给我们一个更正确的结果。

## 逐字符读取整个文件

在下面的程序中，我们使用了 `get()` 函数来读取文件中的每一个字符。

考虑以下程序：

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::in);
    if(fin==NULL)
    {
        cout<<"Can't open the file");
        return -1;
    }
    char ch;
    while(!fin.eof())
    {
        fin.get(ch);
        cout<<ch;
    }
    fin.close();
    return 0;
}
```

### 输出

b
5
I am Aman

请看，每一个字符和空白字符都已按原样显示。

## 从文件读取字符串

我们也可以从文件读取字符串。为此，我们使用 `getline()` 函数

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::in);
    if(fin==NULL)
    {
        cout<<"Can't open the file");
        return -1;
    }
    char ch[10];
    while(!fin.eof())
    {
        fin.getline(ch,10);
        cout<<ch;
    }
    fin.close();
    return 0;
}
```

### 输出

b5I am Aman

请看，`getline()` 函数识别空格，但不能识别换行符。

## 文件位置指针

使用文件位置指针，我们可以在文件中从一个位置移动到另一个位置。

`seekg(offset,whence)` – 此函数将“获取”光标放置在从 `whence` 开始计数的 `offset` 位置。当我们想要从文件读取内容时使用此函数。这里 `whence` 可能有三个值。

- `ios::beg` – 用于从文件开头开始计算偏移位置。
- `ios::cur` – 用从当前位置开始计算偏移位置。
- `ios::end` – 用从文件末尾开始计算偏移位置。

考虑以下程序：

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::out);
    if(fin==NULL)
    {
        cout<<("Can't open the file");
        return -1;
    }
    fin<<"Hacking: Exploiting computer security with Aman";
    fin.close();
    fin.open("example.txt",ios::in);
    char ch;
    fin.seekg(3,ios::beg);
    ch=fin.get();
    cout<<ch;
    fin.close();
    return 0;
}
```

### 输出

k

从输出中，您可以轻松看出第一个字符的偏移值设为零。该程序将文件内的光标放置在从文件开头算起的第四个位置，即偏移量为三。在这里，您可以看到我们以读写模式打开了文件。以读写模式打开文件时，必须注意，由于文件也以读取模式打开，因此相应位置必须存在同名的现有文件。如果不存在同名的现有文件，将显示错误，因为文件不会自动创建。在这种情况下，上述程序将显示错误“Can't open the file”。在这种情况下，您可以先以输出模式打开文件，然后关闭它，再以读取模式重新打开。以下程序展示了执行此任务的示例程序：

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::out);
    if(fin==NULL)
    {
        cout<<"Can't open the file");
        return -1;
    }
    fin<<"Hacking: Exploiting computer security with Aman";
    fin.close();
    fin.open("example.txt",ios::in);
    char ch;
    fin.seekg(3,ios::beg);
    ch=fin.get();
    cout<<ch;
    fin.close();
    return 0;
}
```

上述程序不会显示错误。因为，如果文件“example.txt”不存在，则会创建它。在这里，我们需要从文件读取一些数据，因此使用了 `seekg()`。

`seekg()` 是一个重载函数。因此，它还有一个原型：

```
seekg(offset);
```

此函数始终假设偏移量从文件开头开始。因此，它是 `seekg(offset,ios::beg)` 的替代方案。

`seekp(offset,whence)` – 此函数将“放置”光标放置在从 `whence` 开始计数的 `offset` 位置。当我们想要向文件写入内容时使用此函数。

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;

    fin.open("example.txt",ios::in | ios::out);

    if(fin==NULL)
    {
        cout<<("Can't open the file");
        return -1;
    }

    fin<<"I am Aman";
    fin.seekp(4,ios::beg);

    fin<<"Hacking: Exploiting computer security with Aman";

    char ch;

    fin.seekg(0,ios::beg);

    while(!fin.eof())
    {
        ch=fin.get();
        cout<<ch;
    }

    fin.close();

    return 0;
}
```

### 输出

I amHacking: Exploiting computer security with Aman

```
seekp(offset);
```

此函数始终假设偏移量从文件开头开始。因此，它是 `seekp(offset,ios::beg)` 的替代方案。

### tellg()

`tellg()` – 此函数以偏移量的形式返回文件中“获取”光标的位置

考虑以下程序：

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::in | ios::out);
    if(fin==NULL)
    {
        cout<<("Can't open the file");
        return -1;
    }
    fin<<"Hacking: Exploiting computer security with Aman";
    fin.seekg(5,ios::beg);
    int i=fin.tellg();
    cout<<i;
    fin.close();
    return 0;
}
```

### 输出

5

该程序将光标放置在第五个偏移量，然后返回其位置。

### tellp()

`tellp()` – 此函数以偏移量的形式返回文件中“放置”光标的位置

考虑以下程序：

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin;
    fin.open("example.txt",ios::in | ios::out);
    if(fin==NULL)
    {
        cout<<("Can't open the file");
        return -1;
    }
    fin<<"Hacking: Exploiting computer security with Aman";
    fin.seekp(3,ios::beg);
    int i=fin.tellp();
    cout<<i;
    fin.close();
    return 0;
}
```

### 输出

3

该程序将光标放置在第五个偏移量，然后返回其位置。请看，使用 `tellp` 时我们以写入模式打开文件。

- 请记住，偏移值可以是负整数、零或正整数。

## 使用状态标志

除了检查是否到达文件末尾的 `eof()` 之外，还有其他成员函数用于检查流的状态（它们都返回 `bool` 值）：

### badbit 和 bad()

如果读取或写入操作失败，则会设置 `badbit`，且 `bad` 方法返回 `true`。例如，当我们尝试向未打开写入模式的文件写入时。

考虑以下程序：

```cpp
#include<iostream>
#include<fstream>
using namespace std;
int main()
{
    fstream fin("example.txt",ios::in);
    if(fin==NULL)
    {
        cout<<"Can't open file";
        return -1;
    }
    fin<<"Hello";
    if(fin.bad())
    {
        cout<<"Can't write";
    }
    fin.close();
}
```

### 输出

Can't write

### failbit 和 fail()

如果读取或写入操作失败，则会设置 `failbit`，且 `fail` 方法返回 `true`，其情况与 `bad()` 相同，但也会在发生格式错误时设置，例如当我们尝试读取整数时却提取了一个字母字符。
