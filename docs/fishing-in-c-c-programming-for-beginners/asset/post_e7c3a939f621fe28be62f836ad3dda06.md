
Here, also the function display() grabs the address of the local variables not its value. So, the changes in the value are permanent.

## Returning a pointer

A pointer can also be used as a return type.

Consider the following program:

```cpp
#include<iostream>
using namespace std;
int*change();
int main()
{
    int*b;
    b=change();
    cout<<*b;
}
int*change()
{
    int a=5;
    return(&a);

```

This program will display 5.

## Pointer Arithmetic

A pointer obeys addition and subtraction, i.e. an address can be increased, decreased, added or even subtracted.

Consider the following program:

```cpp
#include<iostream>
using namespace std;
int main()
{
int a=7,*b=&a;
cout<<b;
b++;
cout<<endl<<b;
}
```

Output (yours may be different)

0x22fe44

0x22fe48

Note here that, we have increased b by 1, so, this will increase by one memory block of the corresponding data type which is int. So, in 64-bit compiler an increase of 4 bytes will be observed, while in 32-bit compiler an increase of 2 bytes will be observed.

Direct multiplication or division between two pointers is not possible.

## Array

Array is a sequence of variables stored at consecutive memory locations of same data type. It is a method to store large number of variables. Suppose we want to work on 500 numbers, then it is not feasible to declare or define 500 different variables. So we can define an array like int num[500]; Here, num has been indexed from 0 to 499. So, we can now use num[0] to num[499].

### Array declaration and initialization

Array can be declared and initialized in following way:

```cpp
int a[2]={45,43};
int a[2]={43};
int a[]={34,54,65};
int a[]={43};
int a[23];
```

An uninitialized array contains garbage value.

e.g. suppose, we want to calculate sum of 10 numbers as in the following program

```cpp
#include<iostream>
using namespace std;
int main()
{
    int num[10]={5,7,8,3,2,1,2,4,3,15};
    int sum=0,i;
    for(i=0;i<10;i++)
    sum+=num[i];
    cout<<sum;
}
```

Output

50

Here, you can see, a method of assigning the values to num[i]. To assign the value to a number say num[3], we can directly use num[3]=5; In the above program, I have used linear assignment i.e. 5 is assigned to num[0], 7 to num[1], ..., 15 to num[9].

## Bound checking

Suppose you declare an array int a[32]; then you may use a statement a[95]=0; because C++ does not check the boundary. But, this should not be practiced, as it may crash the program.

E.g. Consider the following program:

```cpp
#include<iostream>
using namespace std;
int main()
{
    int a[32];
    a[90]=0;
}
```

This program will show no error due to no bound checking. So be careful about boundary while using array. However, if you cross the boundary while initializing then the compiler detects it and gives an error.

E.g. Consider the following program:

```cpp
#include<iostream>
using namespace std;
int main()
{
    int a[3]={1,2,4,5};
}
```

This program will give an error "Too many initializers for int[3]"

## Multidimensional array

An array can be one dimensional or multidimensional. e.g. int array[3][4][2];

Consider the following program

```cpp
#include<iostream>
using namespace std;
int main()
{
    int num[3][2][5],i,j,k;
    for(i=0;i<3;i++)
        for(j=0;j<2;j++)
            for(k=0;k<5;k++)
                num[i][j][k]=i+j+k;
}
```

In this program, we have declared a three-dimensional array and assigned values to it.

A 2D array can also be initialized as follows

```cpp
int num[4][2] = {{ 1214, 86 },{ 1612, 53 },{ 24, 8 },{ 22,8 }};
```

It is important to remember that while initializing a 2-D array it is necessary to mention the second dimension, whereas the first dimension is optional.

So the declarations:

```cpp
int num[2][3] = { 1, 3, 2, 4, 98, 78 };
int num[][3] = { 2, 4, 2, 4, 6, 5 };
```

are acceptable, whereas,

```cpp
int num[2][] = { 12, 34, 23, 45, 56, 45 };
int num[] [] = { 12, 34, 23, 45, 56, 45 };
```

would give the error "Array type has incomplete element type"

Consider the following program:

```cpp
#include<iostream>
using namespace std;
int main()
{
    int num[2][3]={{0,1,5},{6,7,8}};
    int i;
    for(i=0;i<2;i++)
    {
        cout<<"\nAddress of num["<<i<<"] is "<<num[i];
    }
}
```

When you will run this program, you will see that the difference between address of num[0] and num[1] is of 12 bytes. It means that num[0] contains three memory blocks num[0][0], num[0][1] and num[0][2], then the memory block of num[1] starts. More amazingly this program shows that each array whose dimension is one less than the actual array represents the address of the actual array. It means we can access the elements of multidimensional array by efficient use of pointers.

## Returning an array

An array can be returned also. We can return an array either by using pointers or by reference.

### Method1: Returning the array using pointers

Entire array can be returned using pointers. Following program illustrates this:

```cpp
#include<iostream>
using namespace std;
int*arr();
int main()
{
    int*a=arr();
    cout<<*a<<*(a+1)<<"\n";
}
int*arr()
{
    int num[2]={1,2};
    return num;
}
```

Output

12

### Method2: Returning an array using reference

Array can be returned using reference. Following program illustrates this method:

```cpp
#include<iostream>
using namespace std;
int&arr();
int main()
{
    int a=arr();
    cout<<a<<(a+1)<<"\n";
}
int&arr()
{
    int num[2]={1,2};
    return num[0];
}
```

Output

12
