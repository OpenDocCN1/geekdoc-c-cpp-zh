In this program start is a label where we want the cursor to jump to. A colon is must after the label name. Whenever we want to jump to any label, we just use the syntax goto label_name; So, this program will jump infinitely many times to start and it is an infinite process. So, you will see an output like as follows

![](bbox=[0.11, 0.34, 0.94, 0.64])

Remember goto is not a loop, it is just a jumper. So, we cannot use break and continue inside start....goto start;
