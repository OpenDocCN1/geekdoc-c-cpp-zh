
## Strings

String is the very important part of our life. C++ facilitates various library functions to handle the strings. These function use the header file string.h. Some of them are:

- strcpy - Copies a string into another
- strncpy - Copies first n characters of one string into another
- strcmp - Compares two strings
- strncmp - Compares first n characters of two strings
- stricmp - Compares two strings without regard to case ("i" denotes that this function ignores case)
- strnicmp - Compares first n characters of two strings without regard to case
- strdup - Duplicates a string
- strchr - Finds first occurrence of a given character in a string
- strrchr - Finds last occurrence of a given character in a string
- strstr - Finds first occurrence of a given string in another string
- strrev - Reverses string
- strlen - Finds length of a string
- strlwr - Converts a string to lowercase
- strupr - Converts a string to uppercase
- strcat - Appends one string at the end of another
- strncat - Appends first n characters of a string at the end of another

Many a people think that string is an array of characters. The fact is slight different, string is an array of char with `\0` (null) character. This character is used to identify the end of string. There are some special functions predefined to make the easy input/output of the strings, namely gets() and puts(), as the name suggests gets() is used to input string and puts() is used to display the string.

These have been illustrated in the following program:

```cpp
#include<iostream>
using namespace std;
int main()
{
    char ch[50];
    cout<<"Enter a string\n";
    gets(ch);
    puts(ch);
}
```

The amazing thing about this program is that we have not placed a newline between gets() function and puts() function, but line is automatically changed in the output.

Now, consider the following program

```cpp
#include<iostream>
using namespace std;
int main()
{
     char ch[]={'a','m','a','n','\n'};
     puts(ch);
}
```

Output:
aman

This is a method of initializing strings. Well, you can initialize a string simply as

```cpp
char ch[]="Aman";
```

Consider the following program:

```cpp
#include<iostream>
using namespace std;
int main()
{
     char ch[]="Aman";
     char*ch1=ch;
     puts(ch1);
}
```

This program will print Aman. This program also illustrates the fact that we cannot assign a string to a character but we can assign a string to a character pointer.

Consider the following program:

```cpp
#include<iostream>
using namespace std;
int main()
{
     char ch[]="aman";
     int i=0;
     while(ch[i]!='\0')
     {
          cout<<ch[i];
          i++;
     }
}
```

Output of the above program will be aman, this program illustrates the fact that every string and even a character of array end with a null character. The second fact it illustrates is that strlen() neglect null character.

You can also use pointers to display or access the characters of the string as in the following program:

```cpp
#include<iostream>
using namespace std;
int main()
{
    char ch[]="Aman kumar jha";
    int i=0;
    while(ch[i]!='\0')
    {
        cout<<*(ch+i);
        i++;
    }
}
```

Output
Aman kumar jha

## Array of strings

Like other data types, its array can also be declared, in spite of the fact that it is not a data type. We achieve this task using multidimensional array. Consider the following program:

```cpp
#include<iostream>
using namespace std;
int main()
{
    char ch[][20]={};
    int i,j;
    for(i=1;i<7;i++)
    for(j=0;j<20;j++)
    {
        if(j%5!=0)
        ch[i][j]=i+65+j;
        else
        ch[i][j]=' ';
    }
    for(i=1;i<7;i++)
    {
        for(j=0;j<20;j++)
        {
            cout<<ch[i][j];
            if(i==6)
                exit(0);
        }
        cout<<" \n";
    }
    return 0;
}
```

FGHI KLMN PQRS UVWX

This function sometimes requires process.h header file. So, if your compiler shows an error exit() does not have a prototype or exit() undeclared then just include one extra line in your program #include<process.h>

## Passing string to the function

Strings can also be passed to the function. It can be passed in two ways:

- i. Calling by value
- ii. Calling by reference

Consider the following program:

```cpp
#include<iostream>

void modify_string(char *ch);

{
    char ch[50]="Hacking: Exploiting computer security with Aman";

    return 0;

void modify_string(char *ch)
{
    ch="Fishing in C";
    puts(ch);
}
```

Output

## Strcpy

This function accepts two arguments, it copies the string from second argument to first argument. Consider the following program:

```cpp
#include<iostream>
#include<string.h>
using namespace std;
int main()
{
    char ch[]="Aman";
    char ch1[10];
    strcpy(ch1,ch);
    puts(ch1);
}
```

Output

Aman
