# Do...while loop

The prominence of this loop lies in the fact that the first statement is executed before testing the first case and before each next execution condition is tested. Consider the following program.

```
#include<iostream>
using namespace std;
int main()
{
int i=1;
do
{
cout<<i;
i++;
}while(i>5);
}
```

Its output will be 1. Also note that a semicolon is must just after do...while loop, otherwise it will show a compile error “Expected ‘;’ before ‘}’ token”
