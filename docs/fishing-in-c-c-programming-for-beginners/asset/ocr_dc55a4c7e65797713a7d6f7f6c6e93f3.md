```
using namespace std;
int main()
{
    char ch[50],ch1[50];
    cout<<"Enter a string\n";
    gets(ch);
    cout<<"Enter second string\n";
    gets(ch1);
    if(!strcmp(ch,ch1))
        cout<<"Strings are equal";
    else
        cout<<"Strings are unequal";
}
```

See, when the strings are equal, strcmp will return 0. So, (!strcmp) will return non zero values and hence the condition inside if() will be true. So, it will display "Strings are equal"
