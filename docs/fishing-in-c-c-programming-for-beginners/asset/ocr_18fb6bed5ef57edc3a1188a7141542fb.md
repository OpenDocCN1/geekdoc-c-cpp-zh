# Second number is greater than 5

We can also use else if multiple times. E.g. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    cout<<"Enter a number\n";
    int num1;
    cin>>num1;
    cout<<"Enter another number\n";
    int num2;
    cin>>num2;
    if(num1<5)
        cout<<"First number is less than 5";
    else if (num2>5)
        cout<<"Second number is greater than 5";
    else if(num1%5==0)
        cout<<"First number is divisible by 5";
    else if(num2%10==0)
        cout<<"Second number is divisible by 10";
    else
        cout<<"Both cases are false";
}
```

# Output

Enter a number

5
