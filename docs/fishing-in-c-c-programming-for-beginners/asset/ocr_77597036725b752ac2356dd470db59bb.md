# Call by value

Consider the following program:

```
#include<iostream>
using namespace std;
union un
{
int a;
char b[4];
};
void modify_union(union un x);
int main()
{
union un u1;
u1.a=4;
modify_union(u1);
cout<<u1.a;
return 0;
}
void modify_union(union un x)
{
x.a=3;
cout<<x.a;
}
```

# Output

34

See here, value has not been modified at the actual address.
