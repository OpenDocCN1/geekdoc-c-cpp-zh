## Stricmp

此函数与前一个函数类似，但在比较时忽略大小写，如果两个字符串相同则返回 0。

```cpp
#include<iostream>
#include<string.h>
using namespace std;
int main()
{
    char ch[50],ch1[50];
    cout<<"Enter a string\n";
    gets(ch);
    cout<<"Enter second string\n";
    gets(ch1);
    if(!strcmp(ch,ch1))
        cout<<"Strings are equal";
    else
        cout<<"Strings are unequal";
}
```

### 输出

输入一个字符串
Forex.com 教你如何使用它
输入第二个字符串
Forex.COM teAches yOu to uSe it
字符串相等

你看，当字符串相等时，strcmp 将返回 0。因此，(!strcmp) 将返回非零值，因此 if() 内部的条件将为真。因此，它将显示 "字符串相等"

## 联合体和枚举

### 枚举

它是一个命名数据类型。它从零开始，为其元素连续分配连续的整数。如果为其中一个元素分配另一个数字，那么从下一个元素开始，它会自动分配下一个连续的整数。

例如，在以下程序中：

```cpp
#include<iostream>
using namespace std;
enum
{
    Red,Blue,Green,White=5,Yellow,Purple
};
int main()
{
    cout<<Red<<Blue<<Green<<White<<Yellow<<Purple;
    return 0;
}
```

输出将是 012567。因此，我们可以在程序中到处使用此名称（如 Green），在程序中，其值到处都将被视为 2。

枚举可用作数据类型。可以声明其对象。请考虑以下程序：

```cpp
#include<iostream>
using namespace std;
enum color{red,blue,green,white};
int main()
{
    enum color c1,c2;
    c1=blue;
    c2=red;
    cout<<"Even color is "<<c2;
    return 0;
}
```

惊人的是，其输出将为零。

### 将枚举传递给函数

枚举也可以传递给函数。它可以以两种方式传递：

- 按值传递
- 按引用传递

同样，按引用传递可以细分为两部分

- 使用指针调用
- 不使用指针调用

### 按值传递

请考虑以下程序：

```cpp
#include<iostream>
using namespace std;
enum color{red,blue,green,white};
void modify_enum(enum color x);
int main()
{
    enum color c1;
    c1=blue;
    modify_enum(c1);
    cout<<c1;
    return 0;
}
void modify_enum(enum color x)
{
    x=green;
    cout<<x;
}
```

输出
21

请看，实际地址处的值未被修改。

### 使用指针按引用传递

枚举也可以使用指针按引用传递来修改。

```cpp
#include<iostream>
using namespace std;
enum color{red,blue,green,white};
void modify_enum(enum color *x);
int main()
{
    enum color c1=blue;
    modify_enum(&c1);
    cout<<c1;
    return 0;
}
void modify_enum(enum color *x)
{
    *x=green;
}
```

输出
2

请看，2 对应 green，表示值已被修改。

### 不使用指针按引用传递

以下程序演示如何通过不使用指针的调用来修改枚举：

```cpp
#include<iostream>
using namespace std;
enum color{red,blue,green,white};
void modify_enum(enum color &x);
int main()
{
    enum color c1=blue;
    modify_enum(c1);
    cout<<c1;
    return 0;
}
void modify_enum(enum color &x)
{
    x=green;
}
```

输出
2

### 返回枚举

枚举也可以返回，如以下程序所示：

```cpp
#include<iostream>
using namespace std;
enum color{red,blue,green,white};
enum color modify_enum();
int main()
{
    enum color c1;
    c1=modify_enum();
    cout<<c1;
    return 0;
}

{

}
```

输出

### 联合体

联合体是一种派生数据类型，外观类似结构体但并非如此。请考虑以下联合体

```
union un
{
int a;
char b[4];
};
```

这里，由于我使用的是 64 位编译器，所以我使用了 char b[4]。如果你使用的是 32 位编译器，则应该写 char b[2]。联合体的神奇之处在于它在其元素之间划分内存，即其大小仅为 4 字节，而不是 8 字节。

请考虑在 64 位编译器中的以下程序：

```cpp
#include<iostream>
using namespace std;
union un
{
    int a;
    char b[4];
};
int main()
{
    union un un1;
    un1.a=204800001;
    cout<<un1.a<<"\n";
    cout<<int(un1.b[0])<<endl;
    cout<<int(un1.b[1])<<endl;
    cout<<int(un1.b[2])<<endl;
    cout<<int(un1.b[3])<<endl;
}
```

输出将是

```
204800001
1
0
53
12
```

为什么？因为 204800001 的二进制是 00001100 00110101 00000000 00000001

因此，00001100=12，00110101=53，00000000=0，00000001=1。我们可以看到，用于 int 的同一内存也被划分给了 char b[4]。

### 联合体数组

与其他数据类型一样，也可以声明其数组。请考虑以下程序：

```cpp
#include<iostream>
using namespace std;
union un
{
    int a;
    char b[4];
};
int main()
{
    union un u1[30];
    int i;
    for(i=0;i<30;i+=4)

    }
    for(i=0;i<30;i++)
    {
        cout<<int(u1[i].b[i%4]);
    }
    return 0;
}
```

输出

