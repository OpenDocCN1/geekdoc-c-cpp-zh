# oct, dec, hex

Like as in cout, these macros are used in input too but even more amazingly. E.g. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    int num;
    cout<<"Enter a number\n";
    cin>>hex>>num;
    cout<<"Entered number is "<<num;
}
```

Output
Enter a number
