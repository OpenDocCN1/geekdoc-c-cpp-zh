# # Inheritance

This is an amazing feature of object oriented programming. This feature allows us to inherit a class from an existing class. This feature saves us from writing a lot of codes and we can inherit using permissions so that we control inheriting feature for future.

**Base class:** A pre existing class from which another class is to be derived

**Derived class:** A class which is derived from a base class

Syntax of inheriting a class from an existing class is:

```
class derived_class_name: permission_level base_class_name
{
//Statements
}
```

Permission level can be private,protected or public.
