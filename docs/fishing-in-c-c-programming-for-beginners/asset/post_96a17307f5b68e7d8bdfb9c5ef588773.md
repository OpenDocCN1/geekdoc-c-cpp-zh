## Introduction

C++ is an object oriented programming language. It consists of following features:

- 1. Data encapsulation: The data members can be bind into one capsule called class.
- 2. Data hiding: Using this feature we can hide the data members and member functions from outside the class.
- 3. Code Reuse and Recycle: The same code can be reused again and again.
- 4. Inheritance: It is the ability to derive a class from a base class.
- 5. Polymorphism: It is the ability to process different variables, functions, operators or objects in different ways.

When we shall move forward, you will see how these are automatically implemented while programming.

C++ was developed by Bjarne Stroustrup in 1979 at AT&T's Bell laboratory. Initially it was named C++ with classes but later it was renamed to C++ in 1983.

We shall start from very basic, so don't worry, if you do not know any programming language before. But, I shall convince you for one thing that anything that computer is very much user friendly; whatever we want, it does without displaying the complex background process. So, whenever you see a long and complex program, do not fret, do not give up, just think that output is going to be very much simpler and amazing.

## First C++ Program: Hello World

At first download and install DEV C++ latest release from http://bloodshed.net. Now, open it, it will ask for some more settings, keep everything on default and go further. I have used TDM-GCC++ 4.8.1 release, Dev C++ 5.8.3 in this whole book.

C++ compilers are mainly of two types:

- 1. Borland C++ compiler
- 2. Turbo C++ compiler

The difference is that Turbo C++ compilers are no more significantly maintained, while Borland compilers are significantly updated. However, remember that Turbo C++ does not support typename keyword and namespaces. If you are using Turbo C++ then various programs implemented in this book may not work accurately. You should immediately leave that and switch to a compiler of Borland C++. You can switch to Dev C++, Code block and various other popular compilers. All of these are free and easy to use.

So let us start.
