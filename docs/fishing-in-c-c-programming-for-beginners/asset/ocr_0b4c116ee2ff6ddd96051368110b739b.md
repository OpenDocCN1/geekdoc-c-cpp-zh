# # Polymorphism

This is the ability to process the variable, functions, operators, objects and class in multiple ways. Function overloading, function overriding, constructor overloading, operator overloading, pointer to base class, virtual members etc. are various ways to introduce polymorphism in our program.

# ## Function overriding

The difference between function overloading and function overriding is that in overloading the arguments are of different data types in different functions with same name, while in overriding even the arguments are of same data types but in different levels of classes. Here, different level means that one function is defined in a base class, while the other one in the derived class.

Consider the following program:

```
#include <iostream>
using namespace std;
class polygon
{
    protected:
        int length, breadth;
    public:
        void assign_values (int a, int b){length=a; breadth=b;}
        int area () {return 0;}
};

class triangle: public polygon
{
    public:
        int area() {return (length * breadth / 2); }
}
```
