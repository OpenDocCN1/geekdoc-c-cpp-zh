# Call by reference using pointers

Enumeration can also be modified using call by reference using pointers.

```
#include<iostream>
using namespace std;
union un
{
int a;
char b[4];
};
void modify_union(union un *x);
int main()
{
    union un u1;
    u1.a=4;
    modify_union(&u1);
    cout<<u1.a;
    return 0;
}
```

```
void modify_union(union un *x)
{
    x->a=3;
}
```

Output

3
