# Cascading nature of cout

Cout is cascading in nature. E.g. Consider the following program:

```
#include<iostream>
using namespace std;
int main()
{
    int num=8;
    char ch='s';
    char*ch1="Aman";
    cout<<num<<ch<<ch1;
}
```

This program will have same output as from previous program.
