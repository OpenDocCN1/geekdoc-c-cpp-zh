# Listing 12.6 `printf1/Printf1.c`

```
```c
/**
 * @version 1.10 1997-07-01
 * @author Cay Horstmann
 */

#include "Printf1.h"
#include <stdio.h>

JNIEXPORT jint JNICALL Java_Printf1_print(JNIEnv* env, jclass cl,
        jint width, jint precision, jdouble x)
{
   char fmt[30];
   jint ret;
   sprintf(fmt, "%%%d.%df", width, precision);
   ret = printf(fmt, x);
   fflush(stdout);
   return ret;
}
```
```

The function simply assembles a format string "%.pf" in the variable fmt, then calls printf. It returns the number of characters printed.
