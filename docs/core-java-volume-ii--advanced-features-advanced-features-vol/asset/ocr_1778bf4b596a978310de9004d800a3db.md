# ### Executing Java Methods (Continued)

```
~~~c
typedef union jvalue
{
    jboolean z;
    jbyte b;
    jchar c;
    jshort s;
    jint i;
    jlong j;
    jfloat f;
    jdouble d;
    jobject l;
} jvalue;
~~~
```

The third function receives the method parameters in a va_list, as defined in the C header stdarg.h.

+   - Xxx CallNonvirtualXxxMethod(JNIEnv *env, jobject obj, jclass cl, jmethodID id, args)
+   - Xxx CallNonvirtualXxxMethodA(JNIEnv *env, jobject obj, jclass cl, jmethodID id, jvalue args[])
+   - Xxx CallNonvirtualXxxMethodV(JNIEnv *env, jobject obj, jclass cl, jmethodID id, va_list args)

calls a method, bypassing dynamic dispatch. The return type Xxx is one of jObject, jBoolean, jByte, jChar, jShort, jInt, jLong, jFloat, or jDouble. The first function has a variable number of arguments—simply append the method parameters after the method ID. The second function receives the method arguments in an array of jvalue. The third function receives the method parameters in a va_list, as defined in the C header stdarg.h.
