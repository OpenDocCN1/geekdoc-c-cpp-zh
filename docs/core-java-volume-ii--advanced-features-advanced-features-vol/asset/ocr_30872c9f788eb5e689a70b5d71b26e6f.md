When code in a consuming module calls ServiceLoader.load(ServiceInterface.class), the matching provider classes will be loaded, even though they may not be in accessible packages.

In our code example, we provide implementations for a German and French greeter in the package com.horstmann.greetvs.internal. The service module exports the com.horstmann.greetvs package, but not the package with the implementations. The provides statement declares the service and its implementing classes in the unexported package:
