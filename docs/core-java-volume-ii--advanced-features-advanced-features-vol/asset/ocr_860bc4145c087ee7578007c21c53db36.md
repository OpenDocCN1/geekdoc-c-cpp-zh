> **NOTE:** Since the `rt.jar` and `tools.jar` files are no longer included with Java 9, you need to update any references to them. For example, if you referred to `tools.jar` in a security policy file, change it to a reference to the module:
> 
> The `jrt:` syntax denotes the Java runtime file.

```
grant codeBase "jrt:/jdk.compiler"

    permission java.security.AllPermission;
```
