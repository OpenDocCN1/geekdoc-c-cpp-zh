The left panel of Xcode shows the groupings in the project. You can expand on each group to reveal the files contained in each group (and folders). The right panel of Xcode shows the files contained within the group (or folder) you have selected on the left panel. To edit a particular file, select that file, and the editor at the bottom of the right panel opens the file for editing. If you want a separate window for editing, simply double-click a file to edit it in a new window.
