# Size Inspector window

The Size Inspector window (see Figure C-8) is where you configure the size and positioning of views in Interface Builder.

The Size Inspector window can be invoked by choosing Tools ⇨ Size Inspector.

# Identity Inspector window

The Identity Inspector window (see Figure C-9) is where you configure the outlets and actions of your view controller. You add actions and outlets by clicking the plus sign (+) button and remove them using the minus sign button(-). The last section in this appendix discusses in more detail how to create outlets and actions in Interface Builder.
