# How It Works

In this example, you added a Tab Bar Item view to the Tab Bar view and connected it to an XIB file and its corresponding View Controller class.

Adding new Tab Bar Item views is straightforward: Simply drag the Tab Bar item from the Library and drop it into the Tab Bar view. Alternatively, you can add it through the Attributes Inspector window for the Tab Bar Controller item in the `MainWindow.xib` window (see Figure 8-15). Click the + (plus) button to add new View Controllers, and the Tab Bar view automatically inserts a new Tab Bar Item view for you.
