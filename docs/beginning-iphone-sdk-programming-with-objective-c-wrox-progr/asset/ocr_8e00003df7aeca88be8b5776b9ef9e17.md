# WHAT YOU HAVE LEARNED IN THIS CHAPTER

| TOPIC | KEY CONCEPTS |
|---|---|
| Xcode | Create your iPhone application project and write code that manipulates your application. |
| Interface Builder | Build your iPhone UI using the various views located in the Library. |
| Repositioning views | Use the Autosizing feature in Interface Builder to ensure that the views resize even when there is an orientation change. |
| Adding application icon | Add an image to the project and then specify the image name in Icon file property of the `info.plist` file. |
| Creating icons for your iPhone applications | Icon size is 57 x 57 pixels (Home screen) and 29 x 29 pixels (Settings). For AppStore hosting, size is 512 x 512 pixels. |
