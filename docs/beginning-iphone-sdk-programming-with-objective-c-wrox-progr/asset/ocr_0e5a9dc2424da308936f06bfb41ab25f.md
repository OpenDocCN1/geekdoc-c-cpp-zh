When a runtime exception occurs, the best way to troubleshoot the error is to open the Debugger Console window by pressing Shift-Command-R. The Debugger Console window displays all the debugging information that is printed when Xcode debugs your application. This window usually contains the clue that helps you determine exactly what went wrong behind the scenes. Figure B-14 shows the content of the Debugger Console window when the exception occurs. To find out the cause of the crash, scroll to the bottom of the window and look for the section displayed in bold. In this case, note the reason stated.
