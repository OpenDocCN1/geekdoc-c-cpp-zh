# How It Works

To pass data from one view to another, the easiest way is expose a property on the receiving view and set the property value on the calling end.

The second view exposes the property named selectedDatePicker:

```
@interface SecondViewController : UIViewController {
    //--object of type UIDatePicker---
    UIDatePicker *selectedDatePicker;
}

//--expose the object as a property---
@property (nonatomic, retain) UIDatePicker *selectedDatePicker;
```

To pass a value from the first view to the second view, you simply set the property that you have defined:

```
//--set the property of the second view with the DatePicker view in
// the current view--
secondViewController.selectedDatePicker = datePicker;
```
