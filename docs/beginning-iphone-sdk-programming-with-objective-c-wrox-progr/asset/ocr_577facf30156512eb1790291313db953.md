# 论文排版格式说明

本文档用于说明本课程论文的排版格式要求，包括字体、字号、行距、页边距以及各级标题的样式规范。请各位同学严格按照以下要求进行排版。

# 一、总体要求

+   - 正文字数要求：不少于 5000 字。
+   - 论文须包含题目、摘要、关键词、正文、参考文献等部分。
+   - 全文需保持格式统一，行文流畅，逻辑清晰。

# 二、字体与字号

| 项目 | 字体 | 字号 | 行距 |
| --- | --- | --- | --- |
| 正文 | 宋体 | 小四 | 1.5 倍 |
| 一级标题 | 黑体 | 四号 | 1.5 倍 |
| 二级标题 | 黑体 | 小四 | 1.5 倍 |
| 图表标题 | 宋体 | 五号 | 单倍 |

注：表格内容一律使用五号宋体，表头使用黑体五号。
