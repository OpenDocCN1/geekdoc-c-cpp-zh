> **NOTE** The code for validating an email address using regular expression is adapted from http://cocoawithlove.com/2009/06/verifying-that-string-is-email-address.html.

You can then test for the validity of an email address using the newly added method:

```
NSString *email = @"weimenglee@gmail.com";
if ([email isEmail])
    NSLog(@"Valid email");
else
    NSLog(@"Invalid email");
```
