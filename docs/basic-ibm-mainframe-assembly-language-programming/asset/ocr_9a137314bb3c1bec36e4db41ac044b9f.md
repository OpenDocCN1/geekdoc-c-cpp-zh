# 23.4 Convert Infix to Suffix

In the example in Figure 86 we use a simplified algorithm to convert fully parenthesized infix notation to suffix notation. In infix notation, the operators appear between the operands. In suffix notation, the operands appear after the operands.

The algorithm uses a stack. When we place a new item on a stack, the existing items are pushed down. When we remove an item, the remaining items pop up. Stacks are very useful in many algorithms and are an example of a last in, first out data structure.

A simplified infix-to-suffix procedure is as follows:

+   1. Examine the next character in the input.
+   2. If it is an open parenthesis, ignore it and go to step 1.
+   3. If it is a dollar sign (terminator character), done. Check results.
+   4. if it is an operand, copy it to the output string.
+   5. If it is an operator, push it on the stack.
+   6. If it is a close parenthesis, pop the top element on the stack to the output string.
