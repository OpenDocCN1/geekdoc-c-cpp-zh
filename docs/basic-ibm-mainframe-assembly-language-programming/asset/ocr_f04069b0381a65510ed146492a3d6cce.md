Next we need to add each of the values into R2. To do this, we could use five Add (A) instructions as shown in Figure 44. The Add instruction is an RX instruction that adds a full word aligned signed binary value from memory at the address specified as the second operand to the value in the register specified as the first operand and leaves the result in the first operand. The easiest way to specify a memory operand is with a label so that the assembler calculates the base/displacement. Thus, we use five Add instructions, each referencing a separate label.
