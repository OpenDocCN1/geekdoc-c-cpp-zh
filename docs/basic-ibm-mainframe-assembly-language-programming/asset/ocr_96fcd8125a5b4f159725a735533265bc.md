Figure 83 gives an example of printing a bit strings for the powers of two from 0 to 20. It also illustrates calling a subroutine and passing arguments.

The main body of the program is the CSECT BIN (recall that the SUBENTRY macro includes a CSECT statement whose label is the same as that placed on the SUBENTRY itself) that extends from lines 4 through 21. The main program BIN operates as follows:

+   2. Lines 8 through 16 are the main loop.
+   3. The decimal value of the power of two contained in R6 is written to the output field at OUT.
+   4. The address of the parameter list of loaded into R1 on line 9. The parameter list consists of one item: the address of the output field OUT. The value to be converted is passed in R6.
