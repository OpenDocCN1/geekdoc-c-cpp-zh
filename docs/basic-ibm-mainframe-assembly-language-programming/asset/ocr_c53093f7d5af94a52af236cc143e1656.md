The program in Figure 70 function is very similar to that in Figure 69 except that all intermediate and final results are stored in registers, not memory. Thus, the program is reentrant. Because of the usage of the system stack, it is also recursive.

The number whose factorial is to be calculated (5) is loaded into R5 in line 8 and the FACT subroutine is called in lines 10 and 11. Upon return, the value is R1, the answer, is printed. FACT receives its argument in R5 and returns its result in R1.

On entry, FACT performs a Branch and Stack Register thereby storing the calling programs registers. It establishes a base register and tests if the value passed in R5 is one. If not, it branches to RECURS. If yes, the contents of R5 (1) are copied to R1 and the Program Return (PR) instruction is performed. Note that PR does not alter R1.
