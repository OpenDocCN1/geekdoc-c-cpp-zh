# To define bold in a CSS rule:

+   1. Add the font weight property to your CSS. Type the property name **font-weight (Code 5.7)**, followed by a colon (:).

```
font-weight:
```

+   2. Define the weight.

bold;

Type the value for the **font-weight property**, using one of the following:

+   **bold**, which sets the font to boldface

+   **bold** or **lighter**, which sets the font's weight to be bolder or lighter relative to its parent element's weight

+   A value from **100 to 900**, in increments of 100, which increases the weight, based on alternate versions of the font that available

+   **normal1**, which overrides other weight specifications

# Font-Weight Numbers

Most fonts do not have nine weights, if you specify a **font-weight value** that is not available, another weight is used, based on the system:

+   100 to 300 uses the next lighter weight, if available, or the next darker weight.

+   400 and 500 may be used interchangeably.

+   600 to 900 uses the next darker weight, if available, or the lighter weight.
