> TIP The font shorthand property is a real time-saver, and I try to use it as often as possible. It not takes less time to type and edit, but can reduce the size of your code and speed up your load time.

> TIP Code editing software, such as Coda and Dreamweaver, tend to default to the individual properties rather than the shorthand.

> TIP If you don't want to set a particular style, variant, or weight value in the list, just leave it out. The browser will use its default value instead. However, you do have to include at least one value, even if it's normal.

> TIP If you need to override a value set by the font shorthand property, it's generally best to use the full property (such as font-style, font-variant, font-weight, and font-family).
