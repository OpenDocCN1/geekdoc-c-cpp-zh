Adding space between lines of text—especially with large amounts of text. Generally, a line height of 1.5 to 2 times the font size is appropriate.

To double-space text, set the line-height value to 2 or 200%. Likewise, a value of 3 or 300 results in triple-spaced text.

You can use a percentage value lower than 100% or line values smaller than the font size to smash lines together. Although this effect may look neat in moderation, it won't ever integrate with your readers if they can't actually read the text.

Line height can also be defined at the same time as the font size using the shorthand property. (See “Setting Multiple Font Values” in Chapter 5.)

+   A length value, such as 24px. The space for each line of text is set to this size regardless of designated font size. If the font size is set to 12px and the line height is set to 24px, the text will be double-spaced. See “Values and Units Used in This Book” in the Introduction.

+   A percentage, which sets the line height proportionate to the font size used for the text.

+   normal, which overrides inherited spacing values.
