# # CSS Quick Reference

Throughout this book, wherever new properties were introduced, I included a table showing the values for property and the specific browser version in which support first appeared. But for quick reference, all you really care about is "does it work now?" or at least "does it work in browsers with major market share?" also need to know in what the default value is, which types of elements the property applies to, and whether its child elements will inherit the values. Well, look no further.
