# Specifying the Quote Style

Although most writers will use the keyboard to add quotation marks to text, HTML includes the quotation tag: <q>...</q>. This tag browser-default quotation marks around the indicated text. With CSS, you can find the exact characters to be used as quotation marks using the quotes property (Table 9.6). Although English uses single ('...') or double ("...") quotation marks, this by no means the norm for all languages.

| TABLE 9.6 Quotes Values |
| Value | Compatibility |
| '<string>' | IE8, FF1, S1, C1, O4, CSS2 |
| none | IE8, FF1, S1, C1, O4, CSS2 |
| inherit | IE8, FF1, S1, C1, O4, CSS2 |
