# 6.7 text-properties.css—The .byline class has been right justified A, whereas the chapter title in the level 2 heading has been centered, the copy has been fully justified.

Text is left justified by default.

Fully justifying text may produce some strange results on the screen because words must be added to make each line the same. In addition, opinions differ as to whether full justification helps or hinders readability.

```
*** CSS3 VOS | Chapter 6 | text-properties.

body {
  line-height: 1.5;
}

h1 {
  letter-spacing: -.05em;
  word-spacing: -.1em;
  line-height: .9em;
  text-shadow: rgba(51,51,51,.9) -1px -1px 3px,
  rgba(203,203,203,.9) 1px 1px 3px;
}

  letter-spacing: 2px;
  word-spacing: 3px;
  line-height: 1em;

}

  text-shadow: none;
}

  line-height: 24px;

}
```
