# Transformation and Transition Properties

Although the use of transform and transition properties is still somewhat controversial, the ability to apply these changes to elements without using JavaScript will be a boon for Web designers and developers. Think of these as temporal styles that not only change the appearance of an element—as do other styles—but also change that element's appearance over time and space.

The styles presented in this chapter are extremely new, at least by Web standards. Although Webkit has had them in one form or another for a while and Firefox and Opera have started adapting them, it is only in the last year or so that work has started making part of the standard CSS3 canon. Approach these with some caution making sure they degrade gracefully in older browsers, but I can't wait to see how you use them.
