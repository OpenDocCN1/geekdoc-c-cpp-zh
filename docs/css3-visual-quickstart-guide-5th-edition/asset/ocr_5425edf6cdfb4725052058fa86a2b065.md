# RGB(100%, 100%, 100%)

RGB can be expressed as whole percentages from 0% (no color) to 100% (full color) to represent the levels of red, green, and blue (in that order) present in the desired color

RGB percentage color values range from 0–100 indicate the amount of red, green, and blue that is combined to create the color.

# New in CSS3: HSL values

Although their notations are different, decimal, and percentage values are just different ways to define the levels of red, green, and blue in a color. CSS3 adds a completely different method for defining color by its hue, saturation, and lightness

HSL color values represent hue as the angle on a standard color wheel (0–360), saturation as a percentage, and lightness as a percentage.

# rgba(255,255,255,.5)

+   - A degree value from 0 to 360, although the degree symbol is not included. The position is based on a color's position in the standard color wheel where red is typically at 0°, green at 120°, cyan at 180°, blue at 240°, and magenta at 300.

# hsla(0,0,100,.5)

+   - Saturation—A percentage from 0% (no color) to 100% (full color).
- Lightness—A percentage from 0% (black) to 100% (white).

RGBA and HSLA add an alpha value as a decimal (0–1) to represent the opacity of a color with 0 completely transparent and 1 completely opaque.

# New in CSS3: Color alpha values

Although the opacity property allows you to make elements transparent, this is applied to the entire element. CSS3 now allows you to make colors transparent. An alpha value is generally a fourth value in a color, but rather than representing a hue or brightness, it sets the opacity of the color—a value from 0 (transparent) to 1 (opaque). So, an alpha of .5 is the equivalent of 50% opacity
