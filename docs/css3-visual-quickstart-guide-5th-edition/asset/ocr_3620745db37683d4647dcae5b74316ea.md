# # Using Background Shorthand

The background shorthand property (Table 7.14) allows you to define the background image and color for an entire page or individual element, rolling many of the background properties into a single quick and compressed declaration. From a coding standpoint, this is preferable because it uses less space, but it requires that you remember the purpose of each of the values in the list.

# To define the background:

+   1. Add the background property to your CSS rule declarations list. Start your declaration by typing background, followed by a colon (:): Then define a background value (Code 7.5).

```
header.page {
  display: block;
  background: url(../images/bg-spine-
    title.png) no-repeat center top,
  rgb(102,0,0) url(../images/bg-spine.jpg)
    repeat-x o 0;
}
```
