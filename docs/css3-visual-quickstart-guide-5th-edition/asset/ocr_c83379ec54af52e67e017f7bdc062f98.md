This step sets the element's z-index in relation to its siblings, where 0 is on the same level.

```
*** CSS3 VOS | Chapter 11 |
*** visualformatting-properties.css ***

aside {
  position: absolute;
  right: 1%;
  top: 120px;
}

strong {
  position: relative;
  top: -15em;
}

footer {
  position: fixed;
  bottom: 0;
  left: 0;
  z-index: 99;
}

ul {
  position: relative;
  top: 10px;
}

div.gallery {
  position: relative;
}

div.gallery figure {
  position: absolute;
}

div.gallery figure.f1 {
  left: 0;
  top: 0;
  z-index: 3;
}

div.gallery figure.f2 {
  left: 150px;
  top: 50px;
  z-index: 2;
}

div.gallery figure.f3 {
  left: 300px;
  top: 100px;
  z-index: 1; 
}
```

Alternatively, you can use auto to allow the browser to determine the z-index order.

Using a negative number for the z-index causes an element to be stacked that many levels below others.
