5. Define the source of the WOFF, TrueType or OpenType, and SVG format font file. Now add the location of your WOFF, TTF/OTF, or SVG font files. Each browser will use the one suited for it.

```
url('Little-Trouble-Girl/
  littletroublegirl-webfont.woff')n  format('woff'),

url('Little-Trouble-Girl/
  littletroublegirl-webfont.ttf)
  format('truetype'),

url('Little-Trouble-Girl/
  littletroublegirl-webfont.
  svg#webfont') format('svg');
```

6. Optionally add weight, style, and variants associated with this font. This will mean the font is only used if these properties are also applied with the specific value. These are still buggy in many browsers, so I would avoid them for now.

```
font-weight: normal;
font-style: normal;
font-variant: normal
```

7. Add the Web-safe font name to your font stack. To leverage one of the Webafe fonts, place it as the first typeface in your font stack.

```
font-family: Corbel, Helvetica,
  Arial, Sans-serif;
```

8. Add the Webfont name to your your font stack. To leverage a downloaded Webfont and trigger its download, place the name you gave it at the first value of the font stack.

```
font-family: 'Title Font',
  Constantia, Georgia, Times,
  "Times New Roman", Serif;
```
