# A Universal Transition

I added default transitions to the universal selector, applying these styles to every element on the screen. This ensures a consistent transition across my design and cuts down on the amount of code needed, since I apply it only once. You can override the transitions, as necessary.

> This example uses the transition shorthand, but each of these properties can be set separately, using the transition-property, transition-duration, transition-delay properties. Of course, you will need to set all of this independently for all three browser extensions as well as the standard CSS version, which can lead to a lot of code. Still, using these can be useful to override a particular value.

The concern with using the universal selector in this way is that applying a style like this to every element might slow down rendering, but my own experiments have shown that it has little or no impact, even on large and complex pages.
