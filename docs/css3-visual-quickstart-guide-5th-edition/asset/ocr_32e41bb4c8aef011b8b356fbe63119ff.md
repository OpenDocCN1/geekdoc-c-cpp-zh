# # Why You Should Never Use Inline Styles in Your Final Web Site

Because inline styles are the last line of styling, you cannot override them using embedded or external style sheets. As a result, you are stuck with this style permanently or you have to change it manually, which may not always be possible. If you are working on a large scale Web site, the HTML code is often set independently of the styles, and designers may not be able to access that or easily change it.

I once spent three days trying to rewrite a widget for a major Internet company, only to realize the link style wouldn't change because the developer had an inline style. Because I couldn't edit the HTML code, I was stuck.

Inline styles can be useful for quickly testing styles. But to retain maximum flexibility, I recommend placing your final styles into external style sheets, as discussed later in this chapter.

That said, it is likely that you will encounter places where a developer added inline styles to ensure design control. This is especially common in a content management system (CMS) such as WordPress or Drupal.
