# 4.14 default.css—These styles are applied regardless of the media type and include sans-serif fonts, a dark background, and light text.

# Using media queries to specify styles:

+   1. Create your style sheets. Create a default style sheet that captures all the general styles for your design and save it. I like to call mine default. css (Code 4.14).

Create style sheets for the various media or specific devices for you will be designing. Print is generally good to include (Code 4.15). You can call the sheet print.css, but you might also want to create style sheets specifically for popular mobile devices such as the iPhone (Code 4.16), which you could use iphone.phone.

```
*** Default Styles ***
body {
  background: black url('../images/AAIW-illos/
  -alice2a.gif') no-repeat 0;
  margin: 0;
  padding: 200px 0 175px;
h1 {
  color: white;
  font-style: italic;
h2 {
  color: rgb(153,153,153);
pp {
  font: normal 100%1/5 Corbethel,
  Arial, Sans-serif;
  color: rgb(204,204,204);
}
```

Code 4.15 print.css—These styles are tailored for the printed page, changing the background to white (using white paper), serif fonts, black text, and a different background image to match.

Code 4.16 iphone.css—These styles are specific for use on an iPhone and are loosely based based on that device's look and feel.
