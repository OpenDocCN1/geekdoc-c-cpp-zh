+   - From—The value of the initial color in the gradient (7.1). Same as color-stop(0.0, <color>). For example, fromrgb(255,255,255).

+   - To—The value of the final color in the gradient (7.1). Same as color-stop(1.0, <color>). For example, torgb(0,0,0).

+   - Stop—A length, percentage (0–100%), or decimal value (0–1.0) to indicate where the color should be positioned along the gradient, followed by the comma (,), and then the value of a particular point along the gradient (7.1). For example, color-stop(60%, orange).

Gradients can be defined using the from() and to() values, color-stops (), or any combination of these values separated by commas.
