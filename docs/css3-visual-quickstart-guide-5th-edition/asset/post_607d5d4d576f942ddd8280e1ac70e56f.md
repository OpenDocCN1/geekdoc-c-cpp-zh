## Downloadable Webfonts

For years it has been technically feasible to download a font just as you would and use it in your design. However, the browser developers have only recently added this feature. The good news is that you can now download fonts (called Webfonts) to the vast majority of users. The bad news is that different browsers use different file formats (Table 5.3).

Here is a list of the file formats:

- TTF/OTF. TrueType and OpenType fonts are the type you are most likely to have on your computer. They are commonly used today and represent the majority of fonts sold. That said, they have no built-in security to prevent their unlicensed use.
- EOT. Embedded OpenType is a format developed by Microsoft in the late 1990s to allow secure downloadable fonts for the Web. However, because the technology was proprietary for many years and EOT fonts were hard to create, the format didn't catch on. Because it is the only format supported by IE and has been supported since IE4, it has gained new life for implanting Webfonts for IE.

* Not available on Safari Mobile. SVG can be used.

- SVG. A separate W3 standard from CSS, Scalable Vector Graphics can include font information. Some browsers, such as Safari mobile, support only this format.

- WOFF. Web Open Font Format may be the new kid on the block, developed in mid-2009, but it is already becoming the frontman by the default Web font format. This format includes some protection for the font—such as licensing—but is not nearly as cumbersome as EOT.

Code 5.3 font-properties.css - I've added the Web-safe fonts Corbel and Constantia to the body and header texts, respectively, and then downloaded the Webfont "Little Trouble" for use in the h2 page.

To deploy Webfonts in your design, the trick is to include links to multiple font files; the browser will use the format that works for it. The good news is that, with a bit of clever coding, this can easily be accomplished by "Setting a Better Fontstack." Next to learn how to download or convert fonts to these multiple font formats (using Font Squirrel to Convert Font Files" in this chapter).

```css
/* CSS 5 - font-properties.css */
@font-face {
  font-family: 'Title Font';
  src: url('../fonts/little-Trouble-Girl/little-trouble-girl.woff');
  src: local('../fonts/little-Trouble-Girl/little-trouble-girl.woff'),
  format('woff'), url('../fonts/little-Trouble-Girl/little-trouble-girl.ttf') format('truetype'),
  url('../fonts/little-Trouble-Girl.svg#webfont') format('svg');
  font-weight: normal;
  font-style: normal;
  font-variant: normal;
}
```

## Setting a better font stack

Let's look again at the font stack and how to leverage Web-safe fonts and Webfonts to create a design that rises above the visual monotony that we commonly see on the Web.

```css
body {
  font-family: Corbel, Helvetica, Arial, Sans-serif;
}
```

```css
h1, h2, h3, h4, h5, h6, .byline {
  font-family: Constantia, Georgia, Times, "Times New Roman", Serif;
}
```

```css
h3 {
  font-family: Constantia, Georgia, Times, "Times New Roman", Serif;
}
```

To deploy Webfonts in your design, the trick is to include links to multiple font files; the browser will use the format that works for it. The good news is that, with a bit of clever coding, this can easily be accomplished by "Setting a Better Fontstack."
