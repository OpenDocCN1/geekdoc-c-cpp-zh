
# Specifying the Quote Style

Although most writers will use the keyboard to add quotation marks to text, HTML includes the quotation tag: <q>...</q>. This tag provides browser-default quotation marks around the indicated text. With CSS, you can find the exact characters to be used as quotation marks using the quotes property (Table 9.6). Although English uses single ('...') or double ("...") quotation marks, this by no means the norm for all languages.

| TABLE 9.6 Quotes Values |

# Box Properties

In the physical world, atoms are the building blocks of all larger objects. Every type of atom, or element, has unique properties, but when bonded with other atoms, they create molecules—larger structures with properties different from the parts.

Likewise, HTML tags are the building blocks of your Web page. Each tag, or element, has its own capabilities. Tags can be combined to create a Web page that is greater than the sum of its parts. Whether a tag is itself or nested within other tags, it can be treated as a discrete element on the page.

This chapter uses the concept of the box to show what you can do to an element—including margins, borders, padding, width, and height—that can be influenced by CSS.
