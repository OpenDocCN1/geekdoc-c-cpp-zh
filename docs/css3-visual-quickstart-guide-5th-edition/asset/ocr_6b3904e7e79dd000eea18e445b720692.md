# To set up list descendants universally:

# Chapter 2. The Pool of Tears

+   1. Set up a list of descendant selectors including a universal selector. Type the HTML selector of the parent tag, followed by a space, and then asterisk (*) or other selectors (Code 4.2).
   article.copy * {...}

ALICE'S RIGHT FOOT, ESO.

Results of Code 4.2. The text in red matches the selective criteria with the universal selector. In this case, all emphasis tags match.

+   2. Styles will be used if the pattern matches. The universal selector is used at an end of a list of selectors so that the style is applied to all of a parent's children.

Like grouped selectors, contextual selectors can include class selectors (dependent or independent), ID selectors in the list, and HTML selectors.

```
<article class="copy">
  <h1>Alice's Adventures in
  <em>Wonderland</em></h1>
  <h2>Chapter 2.</em> The Pool
  of Tears</em></h2>
  <p>...<em>...</em>...</p>
</article>
```

# Code 4.2 The style is for emphasis with any parent that's in an article using the class D.

```
<!-- HTML -->
<!DOCTYPE type>
<html lang="en">
<head>
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />
<title>Alice's Adventures in Wonderland</title>
<style type="text/css" media="all">
article.copy * em {
  color: red;
  font-weight: bold;
}
</style>
</head>
<body>
<article class="copy">
<h1>Alice's Adventures in <em>Wonderland</em></h1>
<h2>Chapter 2.</em> The Pool of Tears</h2>
<p>Curious and curious!<em>cried</em> Alice...</p>
<p>And she went on <em>planning</em>...</p>
<p>Poor <em>Alice!</em></p>
<blockquote>ALICE'S RIGHT FOOT, ESO.<em>/blockquote</em></blockquote>
<p>Oh dear, what <em>nonsense</em> I'm talking!...</p>
</article>
</body>
</html>
```
