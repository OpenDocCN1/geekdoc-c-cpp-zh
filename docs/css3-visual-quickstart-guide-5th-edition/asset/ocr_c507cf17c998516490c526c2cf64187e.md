# YUI2: Reset CSS

Yahoo! developed YUI2: Reset CSS to remove and neutralize inconsistencies in the default styling of HTML elements, to create a level playing field across browsers, and according to their documentation, to provide a sound foundation upon which you can explicitly declare your intentions.

This CSS Reset (Code 13.6) addresses the styles of many specific HTML tags, zeroing them out, as well as resolving some problems with font sizes, weights, and the use of quotation marks.
developyahoo.com/yui/reset/

Code 13.6 cssreset-YUI2.css—Developed by Yahoo, the YUI2 reset does a more thorough job of overriding specific browser styles.
