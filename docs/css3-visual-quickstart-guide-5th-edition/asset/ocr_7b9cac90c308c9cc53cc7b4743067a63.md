Code 5.6 font-properties.css—The h1 and h2 tags both have italic for them this being overridden the strong tag with an h2 ⓔ We also need to change the font-style in the @font-face rule. This does not actually italicize the downloaded font, it tells the browser to use this in place of italicized version.

```
*** VQS - Chapter 5 - font-properties.css ***
@font-face {
  font-family: 'Title Font';
  src: url('./fonts/little-Trouble-Girl/littletoublegirl-webfont.eot');
  src: local('Open Sans'), url('./fonts/little-Trouble-Girl/littletoublegirl-webfont.woff') format('woff'),
  url: url('./fonts/little-Trouble-Girl/littletoublegirl-webfont.ttf') format('truetype');
  url: url('./fonts/little-Trouble-Girl/littletoublegirl-webfont.svg#svg') format('svg');
  font-weight: normal;
  font-style: italic;
  font-variant: normal;
}

body {
  font-family: Corbel, Helvetica, Arial, Sans-serif;
  font-size: 100%;
  font-size-adjust: .5;
}

h1, h2, h3, h4, h5, h6, .byeline {
  font-family: Constantia, Georgia, Times, "Times New Roman", Serif;
  font-size-adjust: .46;
}

h1 {
  font-family: 'Title Font', Constantia, Georgia, Times, "Times New Roman", Serif;
  font-size: 3em;
  font-style: italic;
}

h2 {
  font-size: 2em;
  font-style: normal;
}

h2 strong {
  font-size: .5em;
  font-style: italic;
}

p {
  font-size: .85em;
}

strong {
  font-size: 1.25em;
}

.byeline {
  font-size: 1.25em;
  font-style: italic;
}

.byeline .author {
  font-style: normal;
}
```
