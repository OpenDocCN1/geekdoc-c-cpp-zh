# Using HTML5 Structure Now

```
<!DOCTYPE html>
<html lang="en-US">
<head>
<meta charset="UTF-8">
<title>HTML5</title>
</head>
<body>
<header>
<nav></nav>
</header>
<section>
<article>
<header></header>
<figure>
<footer></footer>
</article>
<dialog></dialog>
</section>
<aside></aside>
<footer></footer>
</body>
</html>
```

HTML5 is not implemented on most current browsers (and it may be some time before it is), but you can follow some steps now to prepare for the future.

Although CSS can be applied to any version of HTML in use today—including XHTML 1 and HTML 4.01–I’ll be using HTML5 throughout this book. This book is by no means an exhaustive resource of HTML 5. However, I want to show you how to set up the Web document that I'll reference in future chapters.

# Setting up a basic HTML5 document:

+   1. Add the HTML5 doctype (Table 2.4). Notice the new !DOCTYPE HTML is much simpler than the complex and hard-to-decipher HTML and XHTML doctypes in use today (Code 2.1). It simply tells the browser to use HTML.

```
<!DOCTYPE html>
```
