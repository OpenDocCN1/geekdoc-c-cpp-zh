### 2. Specify the vertical alignment.

Type a value for the vertical alignment using one of these options:

- superscripts the text above the baseline.
- subscripts the text below the baseline.
- baseline places the text on the baseline (its default).
- A relative value from Table 6.8 that sets the element's alignment relative to its parent's. To align the top of your text with the top of the parent element's text, you would use **text-top**.
- A percentage value, which raises or lowers the element proportionate to the parent element's font size (25%, for example).

#### TABLE 6.8 Setting an Element's Position Relative to the Parent

| Type | To align the element |
| --- | --- |
| top | highest element in line |
| middle | Middle of parent |
| bottom | lowest element in line |
| text-top | Top to parent's text |
| text-bottom | Bottom of parent element's text |

### Math and Science

Superscript and subscript are used for scientific notation. To express the Pythagorean theorem, for example, you would use superscripts:

```
a² + b² = c²
```

A water molecule might be expressed with subscripts:

H₂O

However, keep in mind that neither subscript nor superscript will reduce the text size, so you may also want to include **font-size** in your definition to achieve a true scientific notation. (See "Setting the Font Size" in Chapter 5).

> TIP Superscript is great for footnotes, which can be hyperlinked to notes at the bottom of the current page or to another page.

> TIP The `sup` and `sub` tags can also be used as superscript and subscript, but should not be used for design (as in this case) for footnotes or mathematical notation.

> TIP If you are creating a column layout, you might encounter problems with vertical alignment when it doesn't appear where it should. In those cases, a good fallback is to use relative positioning, as explained in Chapter 10.

### Indenting Paragraphs

Indenting the first word of a paragraph several spaces (five spaces, traditionally) is the time-honored method of introducing a new paragraph.

On the Web, indented paragraphs haven't worked because browsers compress multiple spaces into a single space. Instead, paragraphs have been separated by an extra line break.

Using the `text-indent` property (Table 6.9), you can specify either horizontal space at the beginning of the first line of text and restore the traditional style.

#### TABLE 6.9 Text-Indent Values

| Value | Compatibility |
| --- | --- |
| <length> | IE3, FF1, S1, C1, O3, CSS1 |
| <percentage> | IE3, FF1, S1, O3.5, CSS1 |
| inherit | IE3, FF1, S1, C1, CSS1 |

### To define indent indentation

1. Add the indent property to your CSS `text-indent` in the CSS declaration list, followed by a colon (: (Code 6.9).

```css
text-indent:
```

2. Specify the amount of indentation.

Type a value for the indent, using one of the following options:

- A length value such as `em` creates a nice, clear indent. (see "Values and Units Used in This Book" in the Introduction.)
- A percentage value indents the text proportional to the parent's (paragraph) width (10%), for example.

> TIP If you are using indent to indicate paragraphs, you should set the margin and padding of paragraphs to 0 to override the `<p>` tag's natural tendency to add space between paragraphs. You'll learn more about margins and padding in Chapter 8.

> TIP Because indent is more common in the print world than the online, you may want to consider using indents for only the printer-friendly versions of your page.

### Controlling White Space

As you've learned, browsers traditionally collapsed multiple spaces into a single space unless a `<pre>` tag was used. CSS lets you allow or disqualify space collapsing, as well as designate whether text break at a space (similar to the `<wbr>`) using the **white-space** property (Table 6.10).

An excellent example of this is the mouse tail poem from Chapter 3 of *Alice in Wonderland*. This poem is shaped like a curvy mouse tail. If the **white-space property value is assigned pre for the poem class**, all spaces collapse. However, if it's assigned a value of **nowrap**, the spaces and line breaks are ignored, and the text stretches as far to the right on the page as necessary.

![](img/9cd61ac1d4015ed5688d0c411434a660_192_0.png)

> A The pre value keeps all spaces so the poem retains its distinctive mouse tail shape than collapsing.

![](img/9cd61ac1d4015ed5688d0c411434a660_192_1.png)

> B Without the pre value, the spaces collapse along with the mouse tail.

![](img/9cd61ac1d4015ed5688d0c411434a660_192_2.png)

> C With the no-wrap value, the poem stretches vertically across the window, forcing a horizontal scroll to accommodate its width.

### To define white space:

1. Add the white space property to your CSS rule. Type white-space in the CSS declaration list, followed by a colon (: Code 6.10).

```css
white-space:
```

2. Specify how you want white space treated.

Type one of the following options:

- pre preserves multiple spaces.
- nowrap prevents line wrapping without a `<br>` tag.
- normal allows the browser to determine how spaces are treated. This setting usually forces spaces to collapse into a single space.

![](img/9cd61ac1d4015ed5688d0c411434a660_193_0.png)

Code 6.10 applied to code 6.1: The note has been set along diagonal by adding spaces. These would collapse if not for the `pre` value applied to it.

> TIP Do not confuse the `<br>` and `<pre>` tags with the white-space property of nowrap and pre. Although they basically do the same thing, the no break tag is being phased out (deprecated) and should not be used.

> TIP The content of any tag that receives the nowrap value runs horizontally as far as necessary regardless of the browser window width. The user may be forced to scroll horizontally to read all the text, so this setting is usually avoided.

> TIP nowrap is great for preventing content from wrapping in table data cells.
