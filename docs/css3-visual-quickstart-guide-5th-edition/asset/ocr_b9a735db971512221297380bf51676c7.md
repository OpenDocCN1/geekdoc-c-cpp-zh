# 14.3 .css-Styles links in the Code 14.1, with a default style applied to all link (a) elements, and applies special styles for links in paragraphs and links used for navigation

```
*** CSS3 | Chapter 14 | links.css ***/

/* Default Link Styles */
na {
  text-decoration: none;
  a:link {
    color: rgb(204,0,0);
    a:visited {
      color: rgb(153,0,0);
      a:hover {
        color: rgb(255,0,0);
        a:active {
          color: rgb(0,255,255);
        }
      }
    }
  }

/* Contextual Link Styles */
pa {
  font-style: italic;
  font-size: 1.2em;
}
p a:link, p:visited {
  border-bottom: 1px dotted rgb(255,153,153);
}
p a:hover, p:active {
  background-color: rgb(255,235,235);
  border-bottom: 1px solid rgb(255,102,102);
}

/* Navigation Link Styles */
nav.toc .menu a {
  display: block;
  text-decoration: none;
  padding: 10px;
  width: 100%;
  height:100%;
}

nav.toc .menu a:link, nav.toc .menu a:visited {
  color: rgb(153,0,0);
}

av.toc .menu a:hover {
  -webkit-transition: color .25s ease;
  -moz-transition: color .25s ease;
```
