# Setting a Font-Stack

The font-family property lets you determine the visual effect of your message by choosing the font for displaying your text (Table 5.2). The typeface you use to display your text can make a powerful difference in how readers perceive your message. Whether you use a serif, sans-serif, monospace, or fantasy typeface can speak volumes before your visitor reads the first line of text.

# To define the font family for an element:

+   1. Add the font-family property to your CSS rule. Type the property font-family, followed by a colon. In this example, font-family is applied to the body tag, which will set the font for the entire page (Code 5.2).

+   2. Define the name of the primary font you want to use, followed by a comma. This name is not sensitive. Fonts that contain a space in their names must be enclosed in quotation marks, either single or double ("Times New Roman" will work).
