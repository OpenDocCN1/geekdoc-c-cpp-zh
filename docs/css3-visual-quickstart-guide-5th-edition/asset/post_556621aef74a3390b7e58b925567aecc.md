
# Styling links

Although a link is a tag, its individual states are not. To set properties for these states, you must use the pseudo-classes associated with each state that a link can have (in this order):

- :link lets you declare the appearance of hypertext links that have not yet selected.
- :visited lets you set the appearance of links that the visitor selected previously—that is, the URL of the href attribute in the tag is part of the browser's history.
- :hover lets you set the appearance of the element when the visitor's pointer is over it.
- :active sets the style of the element when it is clicked or selected by the visitor.

For ideas on styles to use with links, see the sidebar "Picking Link Styles."

2. Style the default link state. Type the selector (anchor tag, class, or ID) of the element you want to style, followed by a colon (:), and then link.

```
a:link {......}
```

You can override styles set for the anchor tag, but this rule should always come before the :visited pseudo-class.

3. Style the visited link state. Type the selector (anchor tag, class, or ID) of the element you want to style, followed by a colon (:), and then visited.

```
a:visited {...}
```

4. Style the hover link state. Type the selector (anchor, class, or ID) of the element you want to style, followed by a colon (:), and then hover.

```
a:hover {...}
```

5. Style the active link state. Type the selector (anchor, class, or ID) of the element you want to style, followed by a colon (:), and then active.

```
a:active {...}
```

6. Style is applied to the link state as needed.

```html
<a href="chapter1.html">...</a>
```

All links on the page will obey the rules you lay down when styling the various states. You can use selective styling to differentiate link types.

# Picking Link Styles

Most browsers default to blue for unvisited links and red for visited links. The problem with using different colors for visited and unvisited links is that visitors may not remember which is which. I recommend using a color for unvisited links that contrasts with both the page's background and the text. Then, for visited links, use a darker or lighter version of the same color that contrasts with the background but dimmer than the unvisited link. Brighter unvisited links will then stand out dramatically. For example, on a page with white background and black text, I might use bright red (rgb(255,0,0)) and pale red (rgb(255,153,153)) for visited links. The paler version is less distinctive, but obviously a link.

> TIP In this example, pseudo-classes are applied directly to the anchor tag, but class or ID could have been used as long as it was applied to any element, not just links.

> TIP The general anchor link styles will be inherited by the different states. The font you use for the :link appearance, :active, and :hover states, will be inherited by the document.

> TIP The Web is a hypertext medium, so it is important that users are able to distinguish them.

> TIP If you use too many colors, your visitors may not be able to tell which are links and which are not.

> TIP The link styles are set for the entire page in this example, but links can be used for a variety of purposes. To that end, it's a good idea to style links depending on their usage:

```
nav {...}
nav:link {...}
nav:visited {...}
```

The preceding styles will be applied only to links in the navigation element.

# Styling for interaction

Once loaded, Web pages are far from static. Users will start interacting with their pointers right away, moving their pointers across the screen and clicking. The dynamic pseudo-classes allow you to style elements as the user interacts with them, providing visual feedback: input elements to change style when the user interacts with them by hovering, focusing, or clicking.

- :hover—Same as for links, but sets the appearance of the element when the pointer is hovering over.
- :focus—Applied to elements that can receive focus, such as text fields.
- :active—Same as for links, but sets the style of the element when it is clicked or selected.

Code 4.7 To define a dynamic pseudo-class:

```html
<!-- HTML -->
<!DOCTYPE html>
<html lang="en">
<head>
  <meta http-equiv="Content-Type" content="text/html;charset=UTF-8" />
  <title>Alice's Adventures in Wonderland</title>
  <style type="text/css" media="all">
    input {
      border: 3px solid rgb(153,153,153);
      background-color: rgb(204,204,204);
      color: rgb(153,153,153);
      padding: 0px;
      font-size: 2em;
    }
    input:hover {
    border-color: rgb(204,153,153);
    color: rgb(102,102,102);
  }
  input:focus {
    border-color: rgb(255,0,0);
    background-color: rgb(255,255,255);
    color: rgb(0,0,0);
    outline: none;
  }
  input:active {
    border-color: rgb(255,0,0);
    background-color: rgb(0,0,0);
  }
  </style>
</head>
<body>
  <input type="text" value="First Name">
  <input type="text" class="hover" value="Last Name">
  <input type="text" class="focus" value="Email">
  <input type="button" class="active" value="Search">
</form>
</body>
</html>
```

# To define a dynamic pseudo-class:

1. Style the default element.
```css
input {...}
```

Although optional, it's generally a good idea to set the default, non-dynamic style for the elements receiving dynamic styles (Code 4.7).

2. Style the hover state of the element.
Type the selector (HTML, class, or ID), a colon (:), and then hover.
```css
input:hover {...}
```

As the pointer enters the element's box (see Chapter 10 for details about the box model), the style change will occur.
