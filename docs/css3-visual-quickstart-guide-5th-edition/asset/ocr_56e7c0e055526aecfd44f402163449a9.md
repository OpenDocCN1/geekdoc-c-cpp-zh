# Defining Reusable Classes

| Class selector | Declaration |
|---|---|
| .authorName { font-size: 1em; } | |

A class selector allows you to set up an independent style that you can apply to any HTML tag. Unlike an HTML selector, which automatically targets a specific tag, a class selector is given a unique name that is then specified using the style attribute in the HTML tag or in any tags you want to use. However, you can also specify styles to apply using a class applied to a specific HTML tag, making it a dependent class.

To define a class selector:

+   1. Give your class name. Type a period (.) and a class name you give it; then open and close your declaration block with curly brackets ({}) (Code 3.9).

```
.author {...}}
```

CSS classes can be defined in the head of your document within the style tags or in an external CSS file that is imported or linked to the HTML document.
