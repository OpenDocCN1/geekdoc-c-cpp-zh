2. Specify the color value. Type a value for a space. This value can be the name of the color or an RGB, HSL, or keyword value (Table 7.1) Use **transparent** if you do not want a background color to appear. rgb(85,85,85)

3. Specify the URL for the background image. Type `url()` in the parentheses, add an absolute or relative path to the background image (Table 7.7), followed by a space. This location is the image file (GIF, JPEG, or PNG file) that you want to use as the background and is either a complete Web address or a local filename.

```
url('./images/dark-victorian.jpg")
```

Alternatively, you could use **none** instead of a URL, which would instruct the browser not to use a background image.

4. If you included a background image, specify how it should tile. Type a value for the way you want your background to repeat, followed by a space.

repeat
Use one of the following options (Table 7.8):

+   repeat instructs the browser to tile the graphic background of the element, both horizontally and vertically.

+   repeat-x instructs the browser to tile the graphic background horizontally. In other words, the graphic repeats in one straight horizontal line along the top of the element.
