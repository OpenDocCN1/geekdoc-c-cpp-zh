4. Specify the opacity. Enter an alpha value for the opacity of the element, which can range between 0.0 (completely transparent) and 1.0 (completely opaque).

You could also use inherit, to set the element's opacity to the same value as its parent. So, if the parent has an opacity of 0.75, inherit will cause the child element to reduce its opacity in addition to the 75 percent already set for the parent.

> Opacity is applied to the entire element and all of its children, with no way to override in child elements. However, you can independently set the opacity of two siblings and then one on top of the other.

> Opacities are cumulative, so if an element with .5 opacity is within an element with .5 opacity, it will have a cumulative opacity of .25.
