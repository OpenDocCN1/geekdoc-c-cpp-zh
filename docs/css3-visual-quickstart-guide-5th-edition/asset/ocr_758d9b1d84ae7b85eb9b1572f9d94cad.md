# 11.3 visual-formatting-properties.css

When applied to Code 11.1, this CSS positions the footer at the bottom of the viewport (keeps it there); positions in a convenient location in the top-right corner of the screen; and offsets our gallery images slightly. It pulls up the strong text, so that its baseline matches the surrounding text. It looks much better A

```
*** CSS VQS | Chapter 11 |
  visual-formatting-properties.css ***

aside {
  position: absolute;
  left: 1%;
  top: 120px;
}

strong {
  position: relative;
  top: -15em;
}

footer {
  position: fixed;
  bottom: 0;
  left: 0;
}

ul {
  position: relative;
  top: 10px;
}

div.gallery {
  position: relative;
}

div.gallery figure {
  position: absolute;
}

div.gallery figure.f1 {
  left: 0;
  top: 0;
}

div.gallery figure.f2 {
  left: 150px;
  top: 50px;
}

div.gallery figure.f3 {
  left: 300px;
  top: 100px;\}
```

![](bbox=[0.515, 0.195, 0.902, 0.335])

> TIP You can use negative values to move the content up and to the left instead of down and the right.

> TIP Child elements that are not absolutely positioned aligned with their parent element.

> TIP What happens if you set the top/left and bottom/right positions for the same element? The answer depends on the browser. Internet Explorer always defaults to the top and left positions. But most others stretch elements that do not have a definite width or height to accommodate the values that are set.
