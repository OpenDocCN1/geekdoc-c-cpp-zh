# Putting It All Together

+   1. Using the HTML you set up in Chapter 6, set the foreground (text) color for your Web page. Make sure the colors are readable against whatever background color you set.

+   2. Add a background image to the page.
Use something with some contrast.

+   3. Add a second background image, and position it over the main background.
Use a transparent PNG image and set repeating so that it's not completely covering the fist background image.

+   4. Set a transparent background color behind paragraphs. Play around with the opacity level until your text is readable against the background you chose in step 1.

+   5. Combine background properties into a single declaration. You may not be able to do this with all of your background properties, but see how many you can combine.
