# New in CSS3:
Color Gradients in
Backgrounds ★

Although not yet part of the CSS standard, the ability to fill an element's background with a gradient has been introduced as both Webkit and Mozilla extensions, which means you can add linear and radial gradients compatible with Safari, Chrome, and Firefox ★ Surprisingly, Internet Explorer also includes its own system for adding background linear gradients, leaving only out in IE (for now).

All though three browsers can display gradients, the syntax has not standardized by the W3C, but all three have a unique way to define the style.

# Internet Explorer gradients

+   Linear gradients can be added for Internet Explorer, browsers (including Chrome and Safari), and Mozilla-based browsers (including Firefox). Radial gradients are available only in Webkit and Mozilla browsers.

Internet Explorer uses its filter property, which does duty for multiple purposes; gradients is just one of them.

The syntax for Internet Explorer gradients is simple and clear-cut, requiring you to define only a starting color, ending color, and orientation ② However rather than using a straightforward RGB value, the colors are defined using a completely nonstandard ARGB color value. You guessed it: the first couple is the alpha value from 00 (transparent) to ff (opaque). You can also set the orientation of the gradient (gradientType) as either horizontal (1) or vertical (0).

```
filter: prodig;
DXImageTransform.Microsoft.gradient
(startColor='#ff000000',
endColor='#7ff00000',
gradientType='1');
```

There is no radial gradient for Internet Explorer.

+   Internet Explorer uses the proprietary filter property to add simple linear gradients. Colors are set using a nonstandard color format that adds an alpha value to the hex code.
