# Setting an Element’s Outline

The outline (Table 10.9) surrounds the border and even uses the same values as the border; unlike the border, it does not increase the apparent dimensions (width or height) of the box and does not actually occupy any space on the screen. Instead, it appears within any margin or out the page under surrounding content.

An outline can be very useful for link-rollovers, allowing you to highlight them without displacing the surrounding content.

Code 10.8 ui-box-properties.css—Applied to Code 10.1, the outline style can be used to highlight links being hovered over disturbing the surrounding elements 1.

```
*** CSS VOS | Chapter 10 |

  float: left;
  margin: 0 10px 10px 0;
}

figcaption {
  display: block;
}
\aside {
  display: block;
}
```
