# Putting It All Together

+   1. Using the three boxes you built in Chapter 10, set their position types. Set the first to absolute, the second to relative, and the third to fixed.

+   2. Set the position of each box. Use the same values on each and note how the different position types affect how the values are used.

+   3. Set the z-index. Set up the boxes to overlap each other, and then set the z-index to change which box is on top.

+   4. Set the opacity of each box. Notice how the colors combine.

+   5. Add a box shadow to each box. Try multiple shadows and continue and inset shadows. Can you create a glow effect?
