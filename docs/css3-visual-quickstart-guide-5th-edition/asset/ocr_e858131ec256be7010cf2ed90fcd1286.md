# Fixed positioning

Fixing an element's position in the window is similar to absolute positioning except that it is in a locked position relative to the viewport edge (rather than its parent). When a document scrolls in the viewport, fixed elements stay in their initial positions and do not scroll with the rest of document. This allows you to establish constant elements in the screen that do not scroll with the rest of the content D.
