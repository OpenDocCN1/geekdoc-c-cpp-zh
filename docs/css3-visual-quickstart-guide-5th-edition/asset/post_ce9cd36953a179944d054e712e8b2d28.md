
# Adjusting space between words

Just as tracking and word spacing adjustments can both help and hinder readability, adding a little space between words on the screen using the word-spacing property (Table 6.2) can make your text easier to read. But too much space interrupts the path of the reader's eye across the screen and interferes with reading.

text-properties.css—When applied to 6.1. The words in the level 1 heading are spaced almost on top of each other, but this works because the words are visually separated by the capital letters. The words in the chapter title class are spaced out. The copy (body text) is slightly spaced out, which has the overall effect of lightening the page by creating more white space.

```css
*** CSS3 V5 | Chapter 6 | text-properties.
***

h1 {
letter-spacing: -.05em;
word-spacing: -1em;
}
h2 {
letter-spacing: 2px;
word-spacing: 3px;
}
h2 strong {
letter-spacing: 0; 
}
p {
word-spacing: .075em;
}
header p:first-letter {
letter-spacing: -.05em;
}
.byline {
word-spacing: -.3em;
}
.byline .author {
word-spacing: 0;
}
```

# To define word spacing:

- 1. Add the word-spacing property to your declaration list. Type word-spacing in the CSS declaration list, followed by a colon (:) (Code 6.3).

word-spacing:

- 2. Specify the amount of space between words.

.1em

Set the value for word-spacing, using one of the following:

- A positive or negative length value, representing the amount of space between words (-1em, for example). For more information, see "Values and Units in This Book" in Introduction.
- normal, which overrides inherited values.

> Like word-spacing very sparingly. Generally, the natural word spacing has been optimized for readability. Changing that space often does more harm than good.

# Adjusting space between lines of text (leading)

Anyone who has typed a term paper knows that they are usually double-spaced to make reading easier and allow space for comments. The leading between lines also can be increased for a dramatic effect by creating negative space between the text. The line-height property (Table 6.3) adds space between the text baselines (the bottoms most letters).

# TABLE 6.3 Line-Height Values

| Value | Compatibility |
|---||---|
| normal | IE3, FF1, C1, O3, CSS1 |
| <number> | IE4, FF1, S1, C1, O3, CSS1 |
| <length> | IE3, FF1, S1, C1, O3, CSS1 |
| <percentage> | IE3, FF1, S1, C1, O3, CSS1 |

# To define leading:

- 1. Add the line-height property to your rule. Type line-height in the CSS declaration list, followed by a colon (:) (Code 6.4).
- 2. Specify the space between lines of text.
.9;
Type a value for line-height, using one of the following options:
- A number to be multiplied by the font size to get the spacing value (2.0) for double-spacing, for example). Although a value of 2 works, it will not validate properly, so always include the decimal.

Code 6.4 text-properties.css—the default line-height has been set in the body to be 1.5 spaces, but paragraph copy has been set to 24px. Assuming that the font size is 12px, that will double-space the text. The book title spacing has tightened until by 6.

```css
line-height: 24px; }
byline {
word-spacing: -.3em; }
.byline .author {
word-spacing: 0; }
```

Adding space between lines of text—especially with large amounts of text. Generally, a line height of 1.5 to 2 times the font size is appropriate. To double-space text, set the line-height value to 2 or 200%. Likewise, a value of 3 or 300 results in triple-spaced text. You can use a percentage value lower than 100% or line values smaller than the font size to smash lines together. Although this effect may look neat, it't ever integrate with your readers if they can't actually read the text. Line height can also be defined at the same time as the font size using shorthand (See “Setting Font Values” in Chapter 5.)

- A length value, such as 24px. The space for each line of text is set to this size regardless of designated font size. If the font size is set to 12px and the line height is set to 24px, the text will be double-spaced. See “Values and Units in This Book”.
- A percentage, which sets the line height proportionate to the font size.
- normal, which overrides inherited values.

# Setting Text Case

When you're dealing with dynamically generated output, such as from a database, you can never quite sure whether the text will appear in uppercase, lowercase, or a combination of the two. With the text-transform property (Table 6.4), you can control the case of the text no matter it enters.

TABLE 6.4 Text-Transform Values
| Value | Compatibility |
| --- | --- |
| capitalize | IE4, FF1, S1, C1, O3, CSS1 |
| uppercase | IE4, FF1, S1, C1, O3, CSS1 |
| lowercase | IE4, FF1, S1, C1, O3, CSS1 |
| none | IE4, FF1, S1, C1, O3, CSS1 |

To define the text case:

- 1. Add the text-transform property to your CSS. Type `text-transform` in the CSS declaration list, followed by a colon (Code 6.4).
- 2. Specify the text case.
   uppercase:
   Type one of the following text-transform values to specify how you want the text to be:
   **capitalize** sets the first letter of each word to uppercase.
   **uppercase** forces all letters to uppercase.
   **lowercase** forces all letters to lowercase.
   **none** overrides inherited text-case values and leaves the text unaltered.

**Code 6.5** text-properties.css—The text-transform property lets you take control of the case of the text. The author is forced to capitalize as the class `.asis`.

```css
*** CSS3 V5 | Chapter 6 | text-properties.
/ css ***/

body {
line-height: 1.5;
}

h1 {
letter-spacing: -0em;
word-spacing: -1em;
line-height: .9em;
}

h2 {
letter-spacing: 2px;
word-spacing: 3px;
}

h2 strong {
letter-spacing: 0;
}

p {
word-spacing: .07em;
line-height: 24px;
}

header + p:first-letter {
letter-spacing: -0em;
line-height: 24px;
}

byline {
word-spacing: -.3em;
}

.byline .author {
word-spacing: 0;
text-transform: uppercase;
}

.asis {
  text-transform: uppercase;
}
```
