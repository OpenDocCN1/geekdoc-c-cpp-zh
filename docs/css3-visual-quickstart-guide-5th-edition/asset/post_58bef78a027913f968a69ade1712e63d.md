
## User Interface and Generated Content Properties

The user interface cannot, for the most part, be controlled by CSS. It is dependent on the specific operating system and browser in use. Objects such as the scroll bars are out of your control. However, CSS provides some control over the appearance of the mouse pointer and style of quotes.

Additionally, CSS includes several properties that let you specify content to be placed on the page (generated) for specific instances. For example, you might want all chapter titles to include the word "Chapter" before them. Although you'll usually want to place all of your page content directly into the HTML code, on occasion you'll find it useful to have some redundant content generated for you or have it tailored to specific language.

## Changing the Mouse Pointer Appearance

### TABLE 9.1 Cursor Values

Normally, the browser determines the appearance of the mouse pointer according to the current content under it. If the pointer is over text, for example, the pointer becomes a text selector. Or, if the browser is working and the visitor can't do anything, the pointer becomes a timer, indicating that the visitor needs to wait.

| Value | Compatibility |
| --- | --- |
| <cursor type name> | IE4, FF1, S1, S0, C1, CSS2 |
| <URL> | IE6, FF1.5, S3, C3, CSS2 |
| auto | IE4, FF1, S0, C1, CSS2 |
| none | IE4, FF1, S1, C1, CSS2 |

Sometimes, it's useful to override the browser's behavior and set the appearance of the mouse pointer yourself, using the cursor property (Table 9.1). This can be applied to any element on the screen, not just links. Also, do not have to associate it with the dynamic state for it to work; just apply it directly to the CSS rule. I've set up different pointer types that depend on the type of object over which the pointer is hovering

```css
.toc {
  margin: 0;
  width: 90%;
  text-align: center;
  font-size: .5em;
}

a {
  cursor: help;
}
```

### To set the mouse pointer appearance:

1. Add the cursor property to your CSS declarations. Type cursor in the CSS block, followed by a colon (:).
2. Specify the mouse pointer. Type one of the mouse pointer names listed in Table 9.2 to specify the appearance.
3. Add a graphic mouse pointer. You can also create your own pointer by adding the URL reference to an image file (generally in PNG format) to use as a custom cursor. You can specify the complete Web address or the local filename of the image

```css
cursor: url(../images/cursor-02.png) 20 20, crosshair;
```

CSS3 adds the ability to define the pointer's hotspot (the point at which the active click will happen) as determined from the upper-left corner of the image. Always include a backup pointer. Firefox, Safari, and Chrome allow you to use CUR, ANI, PNG, or JPEG as a custom pointer. Unfortunately, Internet Explorer supports only CUR and ANI file formats for custom pointers.

TIP CUR and ANI are not standard image formats and can only be created using specialized software.

TIP Remember that the exact appearance of the pointer depends on the operating system and the browser in use.

TIP Although it's fun to play around with the mouse pointers, I have tested this feature on my own site and have received several emails asking me to cut it out. Most Web users have learned to recognize the common functions of specific pointers and when they should appear. Breaking these conventions tends to confuse users.

| crosshair | + |
| e-resize | → |
| help | ❓ |
| move | ╋ |
| n-resize | ↑ |

## Adding Content Using CSS

For the purposes of search engine optimization and accessibility, it is usually best to keep all content within the `<body>` element of your Web page. If it is dynamically generated, then it will not be seen by web crawler and many screen readers. However, at times you may have repetitive content that will not help (or even hinder) your placement in a search index.

To add content, you can use the **content** property (Table 9.3), which allows you to specify a text string, image or file URL, quote, or even an attribute value that should be displayed on the page.

### TABLE 9.3 Compatibility

| Value | Compatibility |
| --- | --- |
| normal | IE8, FF1, S1, O4, CSS2 |
| none | IE8, FF1, S1, O4, CSS2 |
| <string> | IE8, FF1, S1, O4, CSS2 |
| <url> | IE8, FF1, S1, O7, CSS2 |
| <counter> | IE8, FF1, S1, O4, CSS2 |
| attr(<selector>) | IE8, FF1, S1, O4, CSS2 |
| open-quote | IE8, FF1, S1, O4, CSS2 |
| close-quote | IE8, FF1, S1, O4, CSS2 |
| no-quote | IE8, FF1, S1, O4, CSS2 |
| inherit | |

### To define generated content:

1. Specify whether the content should go before or after the element. Type a selector with the `:before` or `:after` pseudo-class (see *Setting the Content Before and After and Element* in Chapter 4) to define where the content will be positioned in relation to the selector.
2. Add the content property to your CSS. In your declaration block, type the **content** property name, followed by a colon (:) and one of the values listed in step 3.

```css
.toc h2:before {
  content: url('../images/bullet-01.png');
  'Chapter ' counter(counterNumber) . '.';
}

toc h2:after {
  content: url('../images/bullet-02.png');
}
```
