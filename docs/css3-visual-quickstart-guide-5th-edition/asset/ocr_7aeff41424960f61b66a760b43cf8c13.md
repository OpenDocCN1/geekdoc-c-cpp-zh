TIP The text-transform property is best reserved for formatting dynamically generated text. If the names in a database are all uppercase, for example, you can use text-transform to make them more legible.

TIP Keep in mind that capitalize all letters in the text, even word such as "of" and "the" that should remain lowercase. In reality, capitalize is primarily useful for names.

TIP DON'T TYPE TEXT IN ALL CAPS. When HTML text is in caps, it makes it a lot harder to control in CSS. Plus, anyone using an assistive device for reading will hear this as shouting. It's better to use normal text plus text transform to style text as uppercase.
