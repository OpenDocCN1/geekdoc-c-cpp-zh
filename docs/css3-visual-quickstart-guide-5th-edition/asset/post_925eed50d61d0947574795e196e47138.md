## Collapsing Borders Between Table Cells

Every table data cell defined by the `<td>` tag has four borders: top, right, bottom, and left. The **border-collapse** property (Table 8.8) allows you to set a table so that each table data cell share its borders with an adjacent table data cell rather than creating a separate border for each.

Code 8.8 `list-table-properties.css`—The border-collapse property lets you remove any space between the table data cells, giving each a single border (on the following page), but border spacing being ignored. Use **separate** to allow **border-spacing** to work (on the following page):

## To collapse the borders in a table:

```css
*** CSS3 | Chapter 8 |
list-table-properties.css ***

ul {
  list-style: url(../images/bullet01.png) inside;
}

nav.global {
  list-style: none;
}

table {
  table-layout: auto;
  border-spacing: 8px;
  border-collapse: separate;
  width: 75%;
  margin: 40px auto;
}

caption, table caption {
  font: italic 1.25em Georgia, 'Times New Roman', Serif;
}

t {
  font-size: 1.25em;
}

td {
  vertical-align: top;
  padding: .5em;
  background-color: rgba(200, 200, 180, .25);
  border: 1px solid rgb(200, 200, 180);
}
```

- 1. Add the border-collapse property to a table element. Type `border-collapse`, followed by a colon (: (Code 8.8).
- 2. Specify how borders should collapse. Type one of the following to how you want to display the borders:
  - collapse will make adjacent table data cells share a common border; however, you won't be able to set border-spacing if borders are collapsed.
  - separate will maintain borders for each data cell. The displayed results can vary between browsers unless you set the border thickness. If borders have the same thickness but different styles, the border style for the data cell to the left is used. By using collapse, the border between data cells has been reduced to a single, thin line.

## Dealing with Empty Cells

Code 8.9 `list-table-properties.css`—The empty-cells property lets you show (default) or hide table cells. If a table cell has no data (not even non-breaking spaces), it appears as a blank at the default width and height of the column and row. The **empty-cells property (Table 8.9)** allows you to specify how empty cell (and, most importantly, its border) is present.

```css
*** CSS3 | Chapter 8 |
list-table-properties.css ***

ul {
  list-style: url(../images/bullet01.png) inside;
}

nav.global ul {
  list-style: none;
}

table {
  table-layout: auto;
  border-spacing: 8px;
  border-collapse: separate;
  empty-cells: hide;
  width: 75%;
  margin: 40px auto;
}
```

### To hide empty table cells:

- 1. Add the empty-cells property to a table elements rule. Type `empty-cells`, followed by a colon (: (Code 8.9)).
- 2. Specify how empty table cells should be treated. Type one of the following to specify how the cells will be treated:
  - **show** will force the empty data cell to display its background and border.
  - **hide** will leave a visual gap in place of the data cell.

```css
table caption, table head {
  font: 1.25em Georgia, *Times New Roman*, Serif;
}
td {
  font-size: 1.25em;
  vertical-align: top;
  padding: .5em;
  background-color: rgba(200, 200, 180, 25);
  border: 1px solid rgb(200, 200, 180);
}
```
