# 6.6 text-properties.css — The drop-shadow

property allows the x/y offset and the blur radius. The book title has dual shadows, creating a subtle embossed effect, whereas the chapter title has a strong shadow slightly offset to the left off the page.

# 4. Specify the color. Type a space and then a color value for the shadow.

rgba(0,0,0,.5);

For more information on color values, see "Choosing Color Values" in Chapter 7.

5. You can add multiple shadows (as many as you want) to any block of text. To do so, you can add another text-shadow declaration to the rule, or a comma followed by another definition.

```
*** CSS VS | Chapter 6 | text-properties. ***
- css
```

```
body {
  line-height: 1.5;
}

h1 {
  letter-spacing: -.05em;
  word-spacing: -1em;
  line-height: .9em;
  text-shadow: rgba(51,51,51,9) -1px -1px 3px, rgba(203,203,203,9) 1px 1px 3px;
}
```

```
text-shadow: rgba(51,51,51,9)
  -1px -1px 3px, rgba(203,203,203,9)
  1px 1px 3px;
```

```
h2 {
  letter-spacing: 2px;
  word-spacing: 3px;
  line-height: 1em;
  text-shadow: rgba(0,0,0,.5) 2px 2px 2px;
}
```

> TIP You can set the value to none to override a shadow that was previously set in the CSS.

> TIP Using RGBA works best for shadows. Anything under that shadow will realistically show through.

```
h2 {
  letter-spacing: 0;
  text-shadow: none;
}
```

> TIP Although this is a "shadow", you can use any color for it. Therefore, if your text is on a dark background, you could use a light color to create a drop "glow".

```
p {
  word-spacing: .07em;
  line-height: 24px;
}
```

> TIP In Chapter 11, you'll learn how to set a box-shadow that works like the text-shadow property but applied to the element's box.

```
p {
  text-transform: uppercase;
}

header + p:first-letter {
  letter-spacing: -.05em;
  line-height: 24px;
  text-shadow: rgba(51,51,51,9) -1px -1px 3px;
  + rgba(203,203,203,9) 1px 1px 3px;
}
```

> TIP Shadows do not affect the position of the text they are placed behind.

```
.byline {
  word-spacing: -3em;
}

byline .author {
  word-spacing: 0;
  text-transform: uppercase;
}

.asis {
  text-transform: uppercase;
}
```

> TIP Text shadows are great to make links pop off the page when used with the :hover pseudo class.
