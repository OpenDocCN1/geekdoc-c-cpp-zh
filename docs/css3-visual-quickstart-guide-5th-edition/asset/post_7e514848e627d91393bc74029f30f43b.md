## Clipping an Element's Visible Area

Unlike setting the width and the height of an element, which controls the element's dimensions (Chapter 10), clipping an absolute-fixed-position element designates how much of that element's content will be visible (**Table 11.6**). The part that is not designated as visible will still be present, but viewers won't be able to see it, and the browser will treat it as empty space.

**To define the clip area of an element:**

- 1. Specify a position type. For details, see “Setting the positioning Type” earlier in this chapter.
- 2. Add the clip property to your declaration list. Type the `clip` property name, followed by a colon (:) as shown in **Code 11.6.**

```css
clip:
```
- 3. Specify the rectangular clipping region. Type `rect` to define the shape of the clip as a rectangle, opening parenthesis (), four values separated by spaces, a closing parenthesis ()), and a semicolon (;).

`rect(50px 250px 250px 50px);` The numbers define the top, right, bottom, and left lengths of the clip area, respectively. All these values are distances from the element's origin (top-left corner), not from the indicated side.

Each value can be a length value or `auto`, which allows the browser to determine the clip size (usually, 100 percent).

| TABLE 11.6 Clip Values |
| Value | Compatibility |
| :--- | :--- |
| rect <top> <right> <bottom> <left> | IE5,5, FF1, S1, C7, CSS2 |
| auto | IE5,5, FF1, S1, C7, CSS2 |
| inherit | IE5,5, FF1, S1, C7, CSS2 |

![](img/9cd61ac1d4015ed5688d0c411434a660_319_0.png)

> A The center is clipped based on the top, right, bottom, and left values provided to the clip property. The transparent area will not be visible.

## NEW CSS3: Setting an Element’s Opacity

One of the earliest, widely implemented CSS3 features was the ability to set opacity, which let you transform an element from opaque to transparent. However, different browsers implement opacity in different ways. For example, rather implementing W3C CSS syntax, Internet Explorer builds on its existing filter function, whereas other W3C compliant browsers simply add the opacity property. Because Internet Explorer ignores the other browsers code, you can place both declarations in the rule to control its opacity.

![](img/9cd61ac1d4015ed5688d0c411434a660_321_0.png)

> Changing opacity allows you to see through the element underneath.

### Table 11.7 Opacity Values

| Value | Compatibility |
| :--- | :--- |
| alpha value | FF1, S1.3, C1, CSS2 |
| inherit | FF1, S1.3, C1, CSS2 |

### To set the opacity of an element:

- 1. Add the IE filter property to your declaration list. To control opacity of an element displayed in Internet Explorer for Windows, type the filter name in the declaration block, followed by a colon (:) (Code 11.7).

```css
filter:
```
- 2. Specify the opacity for Internet Explorer. `alpha(opacity=75);` Add the alpha() code to define the filter value used. You do not want to change this code except for the alpha value, which can range between 0 (completely transparent) and 100 (completely opaque). End the declaration with a semicolon (;).
- 3. Add the opacity property to your CSS. To control the opacity of an element, type opacity followed by a colon (:).

```css
opacity:
```
