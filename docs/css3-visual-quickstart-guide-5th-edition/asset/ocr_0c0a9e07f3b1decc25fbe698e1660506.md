# 7.4 color-background-properties

Background-images are added over the background colors A. Notice that you can have multiple backgrounds in a single element, and they stack on top of each other B.

# To define a background image:

+   1. Add the background image property to your CSS code with the image file source. Type background–image, followed by a colon (:), url(), and a URL in the parenthesis for the location of the image file (GIF, JPEG, or PNG) that you want to use as the background. It can be either a complete Web address or a relative path (Code 7.4).
background-image: url(alice0.gif);
Alternatively, you could type none instead of url() with a path to instruct the browser to use a background-image (Table 7.7).
