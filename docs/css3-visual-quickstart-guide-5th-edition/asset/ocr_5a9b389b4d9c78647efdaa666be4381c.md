# Minifying Your CSS

Although creating readable CSS is great for editing and maintaining your code, of those comments, spaces, and returns end up adding a lot of overhead to your file size. Additionally, I'm sure you are a fine coder, there is always more room to sort and merge selectors for optimization.

If you want to cut down on your file size, before you deploy your site to the Web, create a minified version of your CSS code. Depending on the size of your CSS file, this can go far to reduce size.

Don't delete the readable version. You need to keep that version around to make changes.

Minifying your own code is possible but can lead to numerous errors. Fortunately, several online tools are available to help you. My favorite is Minify's CSS Compressor & Minifier
