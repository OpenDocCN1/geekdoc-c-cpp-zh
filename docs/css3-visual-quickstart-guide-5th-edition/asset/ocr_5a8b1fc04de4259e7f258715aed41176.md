# Floating Elements in the Window

10.5 ui-box-properties.css—Applied to Code 101, the float properties will cause the text to wrap around the figure and the article and aside elements to float side by side if wide enough to accommodate them

In addition to precisely positioning elements within the document, CSS also allows you to set how an element interacts with other elements by floating.

*** CSS3 V0 | Chapter 10 | - box-properties.css ***

Using the CSS float property, you flow text content or float block elements next to each other to create columns.

```

```

float: left;}
