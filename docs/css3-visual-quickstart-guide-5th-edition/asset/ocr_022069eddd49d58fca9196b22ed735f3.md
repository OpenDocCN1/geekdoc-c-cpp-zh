# # Inheriting Properties from a Parent

No, this book hasn't suddenly become the Visual QuickStart Guide to Real Estate. Child and descendent HTML tags generally assume the styles of their parents—inherit them—whether the style is using CSS or is inherited from a browser style. This is called inheritance of styles.

For example, if you use an ID copy and give it a font-family value of Times, all of its descendants would inherit the Times font style. If you set a **bold** tag to red with CSS, all of its descendants will inherit both the applied bold style A.

# ## CSS

```
b { color : red; }
.copy { font-family: times; }
```
