# 11.6 visualformatting-properties.css— When applied to Code 11.1, this CSS hides the edges of the figures in the gallery, creating consistently sized thumbnails 9

```
*** CSS3 Flex | chapter 11 |
* visualformatting-properties.css* ***

header navigation {
  visibility: hidden; 
}

aside {
  position: absolute;
  right: 1%;
  top: 120px;
}

strong {
  position: relative;
  top: -15em;
}

footer {
  position: fixed;
  bottom: 0;
  left: 0;
  z-index: 99;
}

uul {
  position: relative;
  top: 10px;
}

div.gallery {
  position: relative;
}

div.gallery figure {
  position: absolute;
  clip: rect(50px 250px 250px 50px);
}

div.gallery figure.f1 {
  left: 0;
  top: 0;
  z-index: 3;
}

div.gallery figure.f2 {
  left: 150px;
  top: 50px;
  z-index: 2;
}

div.gallery figure.f3 {
  left: 300px;
  top: 100px;
  z-index: 1;}
```

> TIP The element's borders and padding, but not the margin, are clipped along with the content of the element.

> TIP Auto should restore an element to its unchanged original state. However, Safari and Chrome will only restore the clip to the edges of the border while stripping the outline or box shadow.
