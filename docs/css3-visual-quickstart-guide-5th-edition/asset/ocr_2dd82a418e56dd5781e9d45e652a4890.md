# Eric Meyer reset

Partially in response to Yahoo!, noted Webit Eric Meyer developed his own CSS reset script. According to his blog, he felt that the Yahoo! code went too far and not far enough in others. script (Code 13.7) is useful for resetting typographic styles.meyer.com/eric/tools/css/

Code 13.7 cssreset-ericmeyer.css—Developed by Eric Meyer, this reset is simpler than the Yahoo Reset.

Applying styles globally to every tag puts a burden on the browser's rendering engine. This is mostly an argument against using the universal selector (*), which applies the styles to every tag. However, I have not seen any data showing exactly how this lag is and haven't found any noticeable degradation in my tests, even on complex pages.
