Cons—Similar to the Divide and Conquer method but worse. This used to be a very popular CSS strategy until someone discovered that using @import often prevents external style sheets from loading simultaneously. Instead, they must load one after another, which slows down. Additionally, since the linked parent style sheet has to load before the imported style sheets are seen by the browser, this method can lead to the page rerendering as new styles become available.

# The Dynamic method

The Dynamic method relies on your skills as a CSS coder, but on your skills server-side code. It is possible to write server scripts that take aggregated CSS file full of @imports and combine them on the server into a single file for deployment D.

Pros—Combines the ease of use and lean file size of the Aggregate method with the speed of the One For All method.

Cons—Requires server-side coding that is beyond the scope of this book. Talk to your server admin or developer for more details.
