# Controlling White Space

As you've learned, browsers traditionally collapsed multiple spaces into a single space unless a `<pre>` tag was used. CSS lets you allow or disqualify space collapsing, as well as designate whether text break at a space (similar to the `<wbr>`) using the **white-space** property (Table 6.10).

An excellent example of this is the mouse tail poem from Chapter 3 of *Alice in Wonderland*. This poem is shaped like a curvy mouse tail A. If the **white-space property value is assigned pre for the poem class**, all spaces collapse B. However, if it's assigned a value of **nowrap**, the spaces and line breaks are ignored, and the text stretches as far to the right on the page as necessary C.
