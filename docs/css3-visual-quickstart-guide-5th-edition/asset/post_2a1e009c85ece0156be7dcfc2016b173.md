## 3. Specify the content to be added.

```css
url('../images/bullet-01.png')

```

To define the content that is added, type one or more of the following values, separating each with a space:

- A string value, such as Chapter, within single or double quotes. Anything within the quotes will be displayed just as you typed it, including HTML code, although spaces are collapsed (that is, more than two spaces are collapsed into a single space when displayed).

- url(), with an absolute or relative url within the parentheses pointing to an external file, such as an image or sound file. For example, url(bg_flourish.png) will load an image.

- counter(), with a counter name in parentheses. For example, counter(chapterNum) adds the counter number for the chapterNum. (Counters are explained in the next section.)

- open-quote or close-quote to add a quotation mark using the current quotation style. (See "Specifying the Quote Style" later in this chapter.)

- no-open-quote or no-close-quote to increase the level of quoting by one level.

- attr(), to display the value of the cited attribute. For example, attr(alt) will display the value for the alt attribute of the element being styled.

- inherit, which will use the content defined for the parent element.

- normal or none, which will not add any content or apply any other values.

> Because the content property is not supported until Internet Explorer 8, it is best not to rely on this property for critical information.

> Information rendered using the content property will not be searchable by search engines, never use it to insert information that defines your page.

> Content added this way is also invisible to screen readers, so don't include anything that they will.

> One idea is to use content to add figure captions pulled from the images tag. Since this is visible to screenreaders and search engines, it's a good way to repeat content.

## Teaching the Browser to Count

Browsers can automatically create sequentially listed lists, starting at 1 and counting by ones. You will explore this later in the chapter. However, if you need to start numbering from 6 instead of 1! Or, if you need to create two sequential lists that are nested inside each other? CSS allows you to set up multiple counter lists using the content property (previous section). The counter-reset property (Table 9.4) is used to set the initial value for the count, and the counter-increment property (Table 9.5) is used to increase the counter by a specific value.

| TABLE 9.4 Counter-Reset Values | Value | Compatibility |
| :--- | :--- |
| <counterName> | IE8, FF, CSS2 |
| <num> | IE8, FF, CSS2 |
| none | IE8, FF, CSS2 |
| inherit | IE8, FF, CSS2 |

| TABLE 9.5 Counter-Increment Values | Value | Compatibility |
| :--- | :--- |
| <counterName> | IE8, FF, CSS2 |
| <num> | IE8, FF, CSS2 |
| none | IE8, FF, CSS2 |
| inherit | IE8, FF, CSS2 |

To use a counter:

1. Set up the parent element. Set up a CSS rule for the selector that will be the parent element for your numbered list (Code 9.4).
2. Add the counter-reset property to your declaration block. counter-reset: counterName: 0;
3. Type counter-increment: (:), and then the name of the counter you are defining (which can be any name). Then insert a space and the number you want to start the list.

```css
/* Code 9.4 ui-generated-properties.css */
/* The table of contents shows chapters before after, so the list needs to skip 0. */
.toc {
  margin: 0 auto;
  width: 90%;
  text-align: center;
  font-size: 5em;
}
.toc h2:before {
  content: url(../images/bullet01.png) counter(counterName);
  counter-increment: counterName 1;
}
.toc h2:after {
  content: url(../images/bullet02.png);
}
```
