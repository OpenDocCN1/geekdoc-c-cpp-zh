# # What Is HTML?

The HyperText Markup Language is simply a system of tags that define elements on the page, which create the structure of a document for use on the Web. For example, you take a block of text and add HTML tags, as follows:

```
<h1>Alice In Wonderland</h1>
```

Here, you've used the `<h1>` tag to create the most important header for the page: the level 1 header. Different tags are used to tag different kinds of elements, and tags can be placed within other tags. For example:

```
<p>I wonder if I shall fall right <em>through the earth</em></p>
```

These tags tell the browser that the text is a paragraph, and the word “through” should be presented with emphasis, probably by displaying it in italics.
