# 2. Define the name of your font family.
type name of the font family you want to import. This can be anything you choose, as long as you reference it in your font stack

font-family: 'Title Font';

Many developers choose to use the name of the font, but I recommend creating a name that indicates how the font is used in the design. Then, if the typeface is changed, you don't have to change the font name everywhere it is referenced.

Remember: if you want to use a name with two or more words separated by a space, put the whole name in quotes.

# 3. Define the source of the EOT format of the font file. Add your font sources. Always begin with the EOT file for use in Internet Explorer, but not add a format attribute.

```
src: url('Little-Trouble-Girl/littletroublegirl-webfont.eot');
```

# 4. Add a local source decay. for a little trick. Because Internet Explorer ignores the local source attribute, you can place it before your other font sources, and IE will just skip this, which would otherwise cause an error. You can insert anything you want for the name of the font. But because some browsers will trigger an alert if your CSS tries to access a local font file, it's best to use a random character (such as a smiley face).

```
src: local('o');
```
