# Adjusting space between
lines of text (leading)

Anyone who has typed a term paper
nows that they are usually double-spaced
to make reading easier and allow space for
comments. The leading between lines also
be increased for a dramatic effect by
creating negative space between the text.
The line-height property (Table 6.3) adds
space between the text baselines (the bot-
toms most letters).

# TABLE 6.3 Line-Height Values

| Value | Compatibility |
|---|---|
| normal | IE3, FF1, C1, O3, CSS1 |
| <number> | IE4, FF1, S1, C1, O3, CSS1 |
| <length> | IE3, FF1, S1, C1, O3, CSS1 |
| <percentage> | IE3, FF1, S1, C1, O3, CSS1 |

# To define leading:

+   1. Add the line-height property to your
rule. Type line-height in the CSS
declaration list, followed by a colon (:)
(Code 6.4).
2. Specify the space between lines of
text.
.9;
Type a value for line-height, using
one of the following options:
 A number to be multiplied by the font
size to get the spacing value (2.0)
for double-spacing, for example).
Although a value of 2 works, it will not
validate properly, so always include
the decimal.

Code 6.4 text-properties.css—the default
line-height has been set in the body to be
1.5 spaces, but paragraph copy has been set to
24px. Assuming that the font size is 12px, that will
double-space the text. The book title spacing has
tightened until by 6.

```
*** CSS VQ | Chapter 6 | text-properties.
***

body {
line-height: 1.5; }

h1 {
letter-spacing: -.05em;
word-spacing: -.1em;
line-height: .9; }

h2 {
letter-spacing: 2px;
word-spacing: 3px; }

h2 strong {
letter-spacing: 0; }

p {
word-spacing: .075em;
line-height: 24px; }

header + p:first-letter {
letter-spacing: -.05em;
line-height: 24px; }

byline {
word-spacing: -.3em; }

byline .author {
word-spacing: 0; }
```
