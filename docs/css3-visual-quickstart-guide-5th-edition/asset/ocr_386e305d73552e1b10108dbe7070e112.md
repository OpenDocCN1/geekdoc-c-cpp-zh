To affect only the first paragraph in an article, you can add the :first-of-type pseudo-class, as in this example.

3. Style the first line of the element's text if it is the first of its type. Use the selector (article p) for which you want to style the first letter, a colon (:), and then first-line.

article p:first-of-type:
  first-line {...}

In this example, the first-of-type pseudo-class is added so that the first paragraph in an article is styled.
