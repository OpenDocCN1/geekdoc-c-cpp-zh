# Code 15.1 An example of an introduction and TOC for an externai CSS file. Notice that the hierarchy of the TOC is based on page structure.

```
/*...
# Default Stylesheet

Filename: default.css
Site: speakinginstyles.com
Version: 1.1
Last change: 09/11/10 [added gallery view, jct]
Author: Jason Cranford Teague (jct)
Description: Default styles to be applied to all pages in the site

```
