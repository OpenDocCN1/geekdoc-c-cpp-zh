# Webfont Service Bureaus

Another up-and-coming option for adding specific fonts to a Web design is Webfont service bureaus, which provide licensed fonts for your use (generally at a cost) but retain the actual files on their own servers while allowing you to reference them in your code. Some enable this with a straightforward CSS link; others use their own proprietary methods, generally incorporating JavaScript.

The advantages of using Webfont service bureaus include:

- Fonts are licensed, so you don't have to worry about violating EULA and getting sued.
- Fonts are hosted on the bureaus' servers, which means you are taking less bandwidth on your own servers.
- Browser support is handled by the bureau, as are potential updates and upgrades.

However, there are disadvantages as well:

- Since the fonts are on a third-party server, you are depending on someone else's system to always be fast and reliable.
- If you do not have a copy of the font on your own computer, you will not be able to create graphical comps to show clients.
- Price scales vary from service to service. Some charge a one-time fee; others require a yearly subscription. If you forget to pay, your font goes bye-bye.

Webfont service bureaus are coming online all the time, but the top ones currently include:

- Typekit (www.typekit.com)
- Kernest (www.kernest.com)
- Typotheque (www.typotheque.com)
- Ascender (www.ascender.com)
- Fontdeck (www.fontdeck.com)
- Google Font API (code.google.com/apis/webfonts/)

# Setting the Font Size

With CSS, you can specify the size of the text on the screen using several notations or methods, including the traditional print-based point-size notation, percentage, absolute size, and even a relative size to the surrounding text (Table 5.4).

Fonts can be set as either absolute sizes, which define the font size based on a standard length measurement, or relative sizes, which are in relation to defaults set for the browser.

To define the font size for an element:

- Add the font size property to your CSS. Type the property name **font-size**, followed by a colon.
- Define the font size, which could be any of the following:
- A relative or absolute length unit (often in pixels or ems). See "Values and Units in This Book" for detail.
- An absolute size keyword relative to the default size: *xx-small, small, medium, large, and xx-large*.
- A relative size keyword of *smaller* or *larger* to describe the font size in relation to its parent element. I defined the default size of text on the page as 100% (the default size the user has set) and then set font sizes on the page relative to that size.

```css
@font-face {
  font-family: 'Title Font';
  src: url('./fonts/Little-Trouble.woff') format('woff'),
       url('./fonts/Little-Trouble.ttf') format('truetype'),
       url('./fonts/Little-Trouble.svg') format('svg');
  font-weight: normal;
  font-style: normal;
  font-variant: normal;
}

body {
  font-family: Corbel, Arial, Sans-serif;
  font-size: 100%;
}

h1, h2, h3, h4, h5, h6, .byline {
  font-family: Georgia, Georgia, "Times New Roman", Serif;
}

h1 {
  font-family: 'Title Font', Georgia, Georgia, "Times New Roman", Serif;
  font-size: 3em;
}

h2 {
  font-size: 2em;
}

h2 strong {
  font-size: .5em;
}

p {
  font-size: .85em;
}

strong {
  font-size: 1.25em;
}

.byline {
  font-size: 1em;
}

byline .author {
  font-size: 1.25em;
}
```

### Choosing Font Size Type for Screen or Print

Although you may more exact control, absolute font values (as points) are unreliable for the screen and can limit how the visitor's browser displays your work.

The only reason you would need to increase or decrease it compared to the size set in the body is if you are using ems to set the font size, which I recommend; then remember that this is relative to the size of the parent. So a size of 2em would be twice as large as the parent, whereas a size of .5em would be half the size.

The point (abbreviated pt) is one way to refer to a font's absolute size. A 12-point font is an average size for print use and is comfortable for most readers. The size of a point onscreen, varies slightly between operating systems, so on a Windows computer appears larger than the same font as displayed on a Mac. Although using point sizes is an acceptable choice in CSS for print (see "Quarrying the Media" in Chapter 4), it is a poor choice for screen display.

> TIP Avoid defining media font sizes using points or other absolute font sizes because these tend to render inconsistently across platforms. However, they're fine to use for print style sheets.

> TIP When setting font sizes, your strategy is to set a relative-length size for the <body> (such as 100%), and then absolute font sizes (such as small) or relative font sizes (such as larger) to adjust the size. Doing so ensures the most consistent and versatile page viewing regardless of the actual media used (computer screen, printed page, handheld, and so on.)

I recommend sticking with relative value types (especially em) for screen and absolute value types for print.
