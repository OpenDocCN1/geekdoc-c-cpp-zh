# CSS3 and the Promise of Internet Explorer 9

Currently Internet Explorer accounts for around 70 percent of browser usage. Most of this represents IE8 users; slightly fewer IE7 users; and a small but significant number of IE6 users.

None of these browsers support CSS3.

You can use some workarounds. Occasionally, an IE-specific code performs a similar function to the CSS3 code, and in a few (rare) cases a CSS3 property that has been around for awhile has made it into IE8. For the most part, however, the segment of your audience that uses Internet Explorer will be left out in the cold if you use CSS3.

But wait, what is this appearing on the horizon? It's IE9, which Microsoft has double-secret-pink sworn will completely and fully support every last detail in the CSS3 specification, or at least the important ones. This is great news, but as of writing, IE9 is still in Beta, with no clear release date. And even after its release it will be sometime before IE6, 7, and 8 disappear.

For now, I suggest that you use CSS3 only as a design enhancement, unless you know your audience will not be using Internet Explorer—example, if you are developing iPhone apps. The design enhancement a concept is explained in more detail in Chapter 12.
