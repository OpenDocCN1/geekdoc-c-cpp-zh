# Mozilla gradients

In Firefox or other browsers use -moz extensions, you can use the -moz-linear-gradient or -moz-repeating-linear-gradient property to create a straight gradient or use -moz-radial-gradient or -moz-repeating-radial-gradient to create circular gradients. The repeating gradients just will tile based on their size.

-moz gradient extensions use the following values:

+   * Point-One or two keyword values separated by a space defining the side or corner where the gradient should start. Values can include top, right, bottom, and/or left. If two values are used (separated by a space), specify a corner, such as top left.

+   * Position-A background position, which is the same as setting background images shown later in this chapter (Table 7.10) for the center point of a radial gradient, such as center.

+   * Angle-The angle of the gradient in degrees (deg), grads (grad), or radians (rad), such as 45deg.

+   * Shape-Shape of a radial gradient, either circle or ellipse.
