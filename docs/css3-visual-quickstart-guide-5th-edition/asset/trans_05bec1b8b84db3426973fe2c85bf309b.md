> CSS 精灵图（CSS sprites）的理念（以及名称的最后部分）源于视频游戏的早期，当时内存和速度都是极其珍贵的资源。为了克服速度限制，视频游戏制作人员会将创建游戏所需的数千个微小图形排列成网格，然后根据需要显示每个精灵图，遮住大图像中除所需部分以外的所有部分。
