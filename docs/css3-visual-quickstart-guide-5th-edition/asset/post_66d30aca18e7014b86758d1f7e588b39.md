A new feature in CSS3 is the ability to use a rectangular image that can be applied to the box's border, overriding the line style. Mozilla and Webkit have implemented almost identical systems, and CSS3 has (thankfully) followed their lead. Although some differences exist, setting a basic image border background is identical among the three systems.

![](img/9cd61ac1d4015ed5688d0c411434a660_294_0.png)

The background image system (the border-image takes a rectangular image and slices it into nine parts. The eight parts around the edges are used as the side and corner images, and the center is hidden to allow the content within the element to show through. The corners are applied to the corners of the offset set based on the size you set. Then the middle of the sides of the image are stretched or tiled to fill the width and height.

border-02.png—The border image is used to fill in the corners and sides of the border. I've constructed this one using a grid with each square 27px on a side.

To set the border background image:

- 1. Create your background image and save it, preferably as a transparent PNG, although any format will work. For this example I divided the image into a grid of 27px squares, fitting the corners and edges of my background into each of these. This will make the math easier.

- 2. Add the Webkit, Mozilla, standard CSS3 border-image properties:

```
-webkit-border-image:
```

```
-moz-border-image:
```

Although the order doesn't matter, it's generally preferred to have the CSS3 version last because it's the version that should be used (Code 10.11).

- 3. Add the URL that indicates the path to the image you created in step 1.

```
url(../images/border-02.png)
```

- 4. You can include up to four values to specify the image offset—basically how far into the image background should extend (how wide the border slices should be)—separated by a space.

If you set up your image as a grid, this will be the size of a square in your grid:

- One value sets all four sides.
- Two values set the offset for the top/bottom and left/right, respectively.
- Three values set the offset for the top, left/right, and bottom, respectively.
- Four values set the offset for each side in order: top, right, bottom, and left.

## 5. Set one or two values to dictate how the images in the middle of a side should be tiled or stretched.

round;
Choose from the following values:

- stretch (default value) scales images to fit the width or height of the box.
- repeat tiles images to the width and height of the element.
- round is similar to repeat. It tiles the images but scales them exactly within the width or height.

> TIP More properties and values for setting the border image are in the CSS2 specification, but they are not yet supported in most browsers.

> TIP Opera 10.5 supports the CSS3 version of the border image property.

## Setting an Element's Padding

At first glance, **padding (Table 10.18)** seems to have an effect identical to margins: It adds space around the element. The difference is that **padding** sets the space between the border of the element and its content rather than between the element and the other elements in the window. Padding is useful when you're using borders and background colors and don't want the content but right up to the edges.

Table 10.18 Padding Values

| Value | Compatibility |
| --- | --- |
| <length> | IE4, FF1, S1, C3, CSS3 |
| <percentage> | IE4, FF1, S1, C3, CSS3 |
| inherit | IE4, FF1, S1, C3, CSS3 |

To setting padding:

- 1. Start your padding declaration by typing the padding name followed by a colon (:).
- 2. Type a value for the element using one of the following values:
    * Length, which creates padding exact size
    * A percentage, which creates padding proportional to the width
    * inherit to use the parent's padding.
- 3. As with margins, padding can also be set on all four sides (top, right, bottom, and left).
