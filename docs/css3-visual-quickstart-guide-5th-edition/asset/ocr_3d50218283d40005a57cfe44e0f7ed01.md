# To set a style for a specific language:

+   1. Style an element based on its language code. Type the selector (HTML, class, or ID) of the element you style, a colon (:), .lang, and enter the code for the language you are defining within parentheses (Code 4.9).

```
p:lang(fr)
```

+   2. The element is styled if it has a matching language code. Set up your tag with the language attributes as necessary.

```
<p lang="fr">...</p>
```

If the indicated style has its language attribute to the same value that indicated in parentheses in step 1, the style is applied.

Code 4.9 Styles are set to turn paragraphs red if they are in French (fr).

```
<!-- HTML5 -->
<!DOCTYPE html>
<html lang="en">
<head>
  <meta http-equiv="content" charset="UTF-8" />
  <title>Alice's Adventure in Wonderland</title>
  <style type="text/css" media="all">
    p:lang(fr) {
      color: red;
      font-style: italic;
    }
  </style>
</head>
<body>
  <p>It sounded an excellent plan...</p>
  <p lang="fr">On aurait dit un excellent plan,.../</p>
</body>
</html>
```

> TIP You can use any string as the language code, as long as it matches the value in the HTML. However, the W3C recommends using the codes from RFC 3066 or its successor. For more on language tags, visit w3.org/International/articles/language-tags.

> TIP Language styles can go beyond simple colors and fonts. Many languages have specific symbols for quotes and punctuation, which CSS can add. In Chapter 9, you will find information on how to style quotes for a particular language.
