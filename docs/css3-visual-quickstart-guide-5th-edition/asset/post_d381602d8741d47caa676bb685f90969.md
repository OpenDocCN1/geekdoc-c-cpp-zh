
# NEW IN CSS3: Setting an Element’s Shadows ★

Just as with text shadows (Chapter 6), you can add one element or drop shadows to the box of any element on the screen—positioned or not. The term “shadow” is a bit misleading, though, since you can make the color anything you like—including light colors—to create a glow effect.

## To set an element shadow:

1. Add the box shadow property to your CSS rule. Type the box-shadow property names, including Mozilla and Webkit browser extensions, followed by a colon (;); (Code 11.8).
```css
-webkit-box-shadow:
-moz-box-shadow:
box-shadow:
```
2. Specify the shadow offset, blur, choke, and inset.

```
1px 1px 5px 1px rgba(0,0,0,.25)
. inset
```

Type the following keywords or values (Table 11.8) to specify how you want this element’s shadow to be treated (from right to left):

- x and y offset values set the position of the shadow relative to the box. Positive values offset the shadow and down to the right, whereas negative values move the shadow up and to the left. These are required.

- A blur length is a positive value that increases the fuzziness of the shadow and spreads it out. The higher the value, the bigger and lighter the shadow. This is optional but defaults to 0 when left unset.

- A spread length—called choke—is a positive value used to specify the break point for the shadows. It has the effect of increasing the darker area of the shadow before it begins to fade. This is optional but defaults to 0 when left unset.

- A color is any of the standard color in Chapter 7. This is optional but defaults to transparent when left unset, rendering the shadow invisible.

- inset causes the shadow to appear within the element's edges, creating an inner shadow. This is optional.

## Transformation and Transition Properties

Although the use of transform and transition properties is still controversial, ability to apply these changes without using JavaScript will be a boon for Web designers and developers. Think of these as temporal styles that not only change the appearance of an element—as do other styles—but also change that element's appearance over time and space.

The styles presented in this chapter are extremely new, at least by Web standards. Although Webkit has had them in one form or another for a while and Firefox and Opera have started adapting them, it is only in the last year or so that work has started making part of the standard CSS3 canon. Approach these with caution caution sure they degrade gracefully in older browsers, but I can wait to see how you use them.
