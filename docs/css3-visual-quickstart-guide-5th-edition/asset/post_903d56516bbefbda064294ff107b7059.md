
# The underscore hack

A hack is code that is used because it is not supposed to work but does work under certain circumstances and can be exploited to fix a specific problem. Although several hacks allow us to include CSS that will work only in Internet Explorer, the hack I find easiest to use and most reliable is the underscore hack.

# Designing with Progressive Enhancements

It's clear that not all browsers are created equal, so why should we expect all sites to treat them? For years Web designers have tried to design to the lowest common denominator (IE), ignoring the new features available to them in the belief that they had to create the exact experience in all browsers. As long as the site functions effectively and is as good as it can be, why not advantage of new features? This is a question that has been debated back and forth by Web designers for several years. The best reason for using progressive enhancement comes down to your client's expectations:

- 1. faster to develop—Rather than spending time kludging together bunch of images for rounded corners, shadows, and other effects, a few lines of code takes care of it.
- 2. cheaper to maintain—Changing code is much more effective than reworking, re-cutting, and redeploying images.
- 3. better looking—Since styles are native to the browser, they will display more precisely than images that are shoehorned in.

If these arguments don't sway your client, show them that working with progressive enhancements is compared to. Usually this is enough to convince even the most stubborn client. The underscore hack is the simplest way to include CSS for Internet Explorer browsers, exploiting a mistake in the way the beginning of CSS declaration should be treated. According to standards, any declaration that starts with underscore should be ignored, as if commented out. However, when Microsoft created earlier versions of Internet Explorer apparently didn't get that memo, and any version of Internet Explorer in quirks mode will pay attention to this declaration We can use this to fix it.

# Underscore

A general syntax for underscore hack. Any CSS placed on the same line as underscore is ignored by browsers other than Internet Explorer. Standards-compliant browsers will use the range from 640 to 980px depending on browser, whereas IE will always use 800px because it does not support max/min width This can be applied in any situation where you need a different property or value.

# To use the IE underscore hack:

- 1. Add standards-compliant declarations to the CSS rule.
- 2. Add IE-specific declaration with underscore (_) in front. This value will override previous values for that property for any browsers.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Alice's Adventures in Wonderland</title>
  <style type="css">
    {
      padding: 10px;
      margin: 10px auto;
      max-width: 980px;
      min-width: 640px;
      width: 100%;
      _width: 800px;
      outline: 1px solid red;
      border: 1px solid red;
    }
  </style>
</head>
<body>
  <p>Suddenly she came,...</p>
  <p>Alice opened the door,...</p>
  <p>There seemed to...</</p>
</body>
</html>
```

# IE conditional CSS

Internet Explorer (and only Internet Explorer) has the ability to interpret conditional statements (if this...then that) that are ignored by other browsers. This allows you to insert links to style sheets that can tailor your CSS for any version. To set up conditional styles for Internet Explorer:

- 1. Add your standards-compliant CSS. This can be embedded in the head of your document in a <style> tag or imported using the <link> tag or @import rule (Code 13.2):
- 2. Add a conditional comment, specifying the version of IE you want to target.

```html
<!-- Version of IE -->
<!--[if IE]>
<link href="ie.css" rel="stylesheet">
<!--[endif]-->
```

TABLE 13.1 IE Conditionals

| IE | Any version of IE |
|---|---|
| IE <version> | Versions less than version |
| lte IE <version> | Versions less than equal to version |
| IE <version> | Specific version |
| gte IE <version> | Versions greater or equal to version |
| gt IE <version> | Versions greater than version |

Using just IE will be used in any version of Internet Explorer. Adding a space followed by a number will specify the version number. For example, IE 6 allows CSS to be used only in Internet Explorer 6 regardless of the doctype.
