# Displaying an Element

In Chapter 1 you learned that all elements can be classified according to the way they are displayed—inline or block ("Kinds of HTML Tags" in Chapter 2). By default, every tag has a display style that defines how will fit with the surrounding tags.

You can use the **display** property to define whether an element line breaks above and below (block), is included with other elements without hard line breaks (inline), is treated as part of a list (list), or is displayed at all (none). **Table 10.1** shows the values available for the **display** property.
