```
    x = 5;
    y = ++x;   // Prefix form
               // x is incremented first, then
               // the value of x is assigned to y.
               // Value of y is 6.
               // Value of x is 6.
```

You might understand the postfix form better if you think of the statement y = x++; as
being the same as the following:

```
    x = 5;
    y = x;
    x = x + 1;
```

To understand the prefix form better, think of y = ++x; as being the same as the following:

```
    x = 5;
    x = x + 1;
    y = x;
```
