The * symbol also serves as the **indirection operator**, which means that it can be used to indirectly access the value to which a pointer points. Because the * symbol is used in many ways in C++, C++ must use context to determine the appropriate meaning. The C++ code that follows shows the use of the * symbol to carry out multiplication, to declare a pointer variable, and to function as the indirection operator.

```
int y = 5;
int x;
int* ptr_x;       // Pointer variable
x = y * 10;       // Multiplication; x is assigned the value 50
ptr_x = &x;       // ptr_x is assigned the memory address of x
cout << *ptr_x;   // Indirection operator; prints 50
```
