> KEEP THE CONTROLS

Unlike the case for the image brush and drawing brush, you must not delete the controls that define a visual brush. WPF uses those controls at run to build the image that the brush uses; thus, if you delete those controls, it cannot make the brush's image.
If you don't want the visual brush's controls to be visible, you can hide them behind another control.
