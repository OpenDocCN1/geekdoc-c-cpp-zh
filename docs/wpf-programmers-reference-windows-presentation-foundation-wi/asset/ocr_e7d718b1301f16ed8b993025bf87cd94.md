# SUMMARY

By using Pages, you can add a web-like navigation model to an application. The web browser, NavigationWindow, or Frame that holds the Pages automatically allows the user to move backward and forward through the navigation history.

This style of navigation doesn't replace other methods of opening new such as menus and buttons. It just gives the a new option for returning to places previously visited.

All of the chapters (and almost all of the examples) so far in this book have worked only in two dimensions. Careful use of graphical techniques such as BevelbitmapEffect and overlaid highlights can give objects a three-dimensional (3D) appearance, but they are still two-dimensional (2D) objects.

The next chapter explains how to display 3D objects. It shows how you can make 3D shapes with colored and textured surfaces and multiple light sources. It even shows how you can place controls such as TextBoxes and MediaElements on 3D objects.
