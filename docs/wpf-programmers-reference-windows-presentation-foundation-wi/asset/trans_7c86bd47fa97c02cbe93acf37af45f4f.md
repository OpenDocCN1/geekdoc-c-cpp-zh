

# 引言

几十年来，优秀的开发者一直将 UI 构建与用户界面背后的代码（code behind）分开。保持这种分离有利于在不同的开发者之间分配工作，并更便于独立地构建每个部分。WPF 延续了这一哲学，它让用户界面与后台代码之间的分离比以往任何时候都更加清晰。

事实上，微软最初的愿景是：由专业的图形设计师构建用户界面，而程序员则完全负责添加后台代码。

虽然许多开发项目无法负担同时雇佣独立图形设计师和程序员的费用，但将这两项任务分开仍然很有价值。本书专门为负责其中任一任务的人士而编写。

本书提供了对 WPF 的介绍，不需要你具备任何相关经验。事实上，它甚至不需要你具备任何先前的编程或 UI 设计经验。

> 我不想收到一大堆抱怨某些内容太基础的“喷火式”邮件，所以我现在就警告你！如果你对入门级材料感到受到了极大的冒犯，欢迎跳过前几章，直接阅读更高级的内容。

尽管本书不需要先前的编程经验，但它涵盖了大量内容，并涉及了一些高级主题。当你读完这本书时，无论你开始时的经验如何，都应该学到很多。

# 本书涵盖的内容（以及未涵盖的内容）

本书解释了 WPF 开发。它解释了如何使用微软的 Expression Blend 工具、Visual Studio 和 XAML 语言来构建用户界面。它还解释了如何使用 Visual Studio 将代码附加到界面。

WPF 是一个非常灵活的工具，你可以用它制作出惊叹的用户界面。遗憾的是，它通常也很复杂，有时令人困惑，有时又令人生畏。你可以利用它完成非凡的 UI 幻术，但这样做可能是一场充满实验和浏览的英雄式冒险。

这种开发行为违背了微软的愿景——即由专业图形设计师构建用户界面，然后由程序员将其附加到代码中。我可能混错了圈子，但我遇到的设计师并没有技能或兴趣花费时间去构建复杂的 UI 界面。相反，他们更关注界面的外观和易用性。

本书的哲学是：用户界面是应用程序的前端，而不是应用程序本身。构建一个数据输入表单不需要多年的经验和 WPF 博士学位。

如果需要大量的花哨技巧才能让程序执行某些奇特的动作，那么本书并不涵盖这些内容。对于更复杂的情况，本书会在用户界面和其后台代码之间自由切换。例如，如果某个动画用纯 WPF 很难控制，但使用后台代码很容易控制，我每次都会选择后者。

本书也不涵盖界面的编程。它展示了一些代码，以便你学习如何编写自己的代码，但它没有详细介绍 C#、Visual Basic 或任何其他编程语言。

# 本书的结构

本书的章节通常从开始的最基础到结尾的高级内容进行排列。它们从基础知识开始，如向窗口添加控件以及选择要使用的控件类型。后面的章节涵盖了更高级的技术，如动画、变换和 3D 图形。附录提供了控件和其他对象以及 XAML 语法的方便参考。

如果你按顺序阅读章节，可能会最有意义，然后如果你需要特定主题的信息，也可以来跳着读。例如，在读完前几章并学会如何构建简单的 WPF 应用后，你可能想跳过去多读一些关于样式或变换的内容。

如果你有开发经验，特别是使用 Expression Blend 或 Visual Studio，你可能想跳过前面的章节。

如果你知道自己不会使用 Expression Blend 或 Visual Studio，你可能想跳过相应的章节。例如，如果你知道自己将使用 Visual Studio 而不是 Expression Blend，那么你可能想跳过第 3 章。

- 第 1 章：WPF 概述 —— 第一章介绍了基本的 WPF 概念。它解释了 WPF 的优势、WPF 如何构建在 DirectX 之上，以及 WPF 如何将 UI 设计与后台代码分离。它还描述了不同类型的 WPF 项目（独立、XAP、库），并泛泛解释了 Page、Frame 和 PageFunction 项目。

- 第 2 章：Visual Studio 中的 WPF —— 第2章解释了如何使用 Visual Studio 构建 WPF 项目。它告诉你如何构建简单的用户界面以及如何将界面与后台代码连接。本章解释了如何控制属性以及如何在 Visual Studio 中编辑 XAML 代码。它没有深入解释 WPF 控件，因为它们在后文中会介绍。

- 第 3 章：Expression Blend —— 第3章解释了如何使用 Expression Blend 构建 WPF 项目。它告诉你如何在 Expression Blend 中编辑 XAML 代码，以及如何链接到 Visual Studio 添加后台代码。

- 第 4 章：通用属性 —— 第4章描述了许多 WPF 控件共有的某些属性。这些属性定义了基本的控件特征，如颜色、大小和位置。

- 第 5 章：内容控件 —— 第5章描述了 WPF 中用于显示内容的控件（与后续章节描述的控件不同）。这些包括 Label、GroupBox、ListBox 和 Image 等控件。本章描述了每个控件的作用，并总结了它们最重要的属性和行为。

- 第 6 章：布局控件 —— 第6章描述了用于排列其他控件的 WPF 控件。这些包括 Grid、DockPanel、StackPanel 和 WrapPanel 等。本章描述了每个控件的作用，并总结了它们最重要的属性和行为。

- 第 7 章：用户交互 —— 第7章描述了允许用户控制应用程序的 WPF 控件。这些包括 Button、RadioButton、TextBox 和 Slider。本章描述了每个控件的作用，并总结了它们最重要的属性和行为。

- 第 8 章：二维绘制控件 —— 第8章描述了执行二维（2D）绘制的 WPF 对象。这些包括 Line、Ellipse、Rectangle、Polygon、Polyline 和 Path。本章还解释了 Path 语言和几何形状，它们可以创建多个图形。

- 第 9 章：属性 —— 第9章详细解释了 WPF 属性。之前的章节使用属性提供简单示例，而本章更深入地描述了属性。它解释了作为简单文本的属性、多值属性、对象属性、依赖属性和附加属性。

- 第 10 章：笔与画笔 —— 第10章描述了用于确定 WPF 对象外观的笔和画笔对象。除了简单的颜色笔和画笔，本章描述了更复杂的对象，如虚线、渐变和图像画笔。

- 第 11 章：事件与后台代码 —— 第11章解释了路由事件、隧道（预览）、冒泡事件和附加事件。这些不同类型的事件允许你使用用 WPF 创建的用户界面来更改后台代码。

- 第 12 章：资源 —— 第12章解释了 WPF 资源。它告诉了如何在 XAML 代码中使用静态资源和动态资源。

- 第 13 章：样式与属性触发器 —— 第13章解释了样式和属性触发器。它告诉了如何使用通常存储在资源中的样式来赋予对象一致的外观（例如，参见图 0-4）。它还解释了属性触发器（通常定义在样式中），用于属性值变化时更改控件的外观。

- 第 14 章：事件触发器与动画 —— 第14章解释了事件触发器及其可以运行的动画。它解释了 WPF 应用程序轻松完成的故事线和时间线。

- 第 15 章：模板 —— 第15章描述了控件模板。它解释了你如何使用模板来更改预定义控件的外观和行为。它还告诉了如何使用 ItemsPresenter 和 ContentPresenter 对象来更改列表和菜单的工作方式。
