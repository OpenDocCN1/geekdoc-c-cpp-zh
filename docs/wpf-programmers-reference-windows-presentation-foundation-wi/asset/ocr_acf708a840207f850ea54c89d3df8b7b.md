# CONTROL TOOLBOX

The Control Toolbox shown in Figure 3-30 lets you controls on a window. Double-click on a control in the Objects and Timeline area to select it for children. Then you can double-click a control in the Toolbox to put a new instance of that control in the selected control.

The Toolbox only shows a few controls at a time. If you do not see the control you want, you need to take action to make it appear.

If the control is one of the more common controls, you can find it in the Toolbox's control groups. For example, the third control from the top in Figure 3-30 represents the Grid control. If you want some other control, you can right-click this one and select Canvas, StackPanel, WrapPanel or some other control from a dropdown list. That replaces the Grid with the control you selected so you can use it.

If the control you aren't in any of the control groups or you just can't find it, click on the double arrow at the bottom of the Toolbox to open the Asset Library, shown in Figure 3-31.
