
# FILLRULE DETAILS

To better understand how FillRule works and what its values mean, pick a point somewhere on Figure 10-12 and mentally draw a ray from that point infinitely far to the right (off the page is far enough in this example).

For the EvenOdd rule, count the number of times the ray intersects one of the shape's segments. If the number of intersections is odd, then the point is "inside the shape and is colored." If the number of intersections is even, then the point is "outside" of the shape and is not colored.

For the Nonzero rule, you need to consider the orientation of the shape's segments where they cross the ray. Each time a segment crosses the ray from left to right (as seen by the ray), add 1 to the counter. Each time a segment crosses the ray from right to left, subtract 1 from the counter. When you're done, if the counter is nonzero, then the point is "inside" of the shape and is colored. If the counter is zero, then the point is "outside" of the shape and is not colored.

Experiment with next points inside and outside of the shapes in Figure 10-12 and see what happens.

# SolidColorBrush

The SolidBrush class represents a single solid color. In XAML, you can specify the brush's color by name (e.g., Red or HotPink) or by hexadecimal value (e.g., #FFF0000 or #FFF69B4).

It's usually easier to use a color's name, or you can explicitly build a SolidColorBrush object if you like.

The UseColorBrush example uses the following XAML code to demonstrate both methods. First, it uses the color Margin to draw a blue ellipse. Then it draws a second ellipse, filling it with an explicitly created SolidColorBrush.

```xml
<Ellipse Margin="10,20" StrokeThickness="5" Stroke="Black"
  Fill="Blue"/>
<Ellipse Margin="75,0" StrokeThickness="5" Stroke="Black"
  Fill="SolidColorBrush Color="Red"/>
</Ellipse>
```

# LinearGradientBrush

A LinearGradientBrush fills an area with a sequence of colors that blend smoothly from one to another in a linear direction. For example, the brush might start blue on the left and gradually turn to white on the right.

The LinearGradientBrush's StartPoint and EndPoint properties determine how the gradient starts and ends. The coordinates of these points use a scale, where (0, 0) is the brush's upper-left corner and (1, 1) is its lower-right corner.

The brush contains a collection of GradientStop objects that determine how it fills its area. The GradientStop's Color property defines the color that the brush should use at a particular point. Its Offset property determines how far through the brush from its StartPoint to its EndPoint the color is positioned (0 to 1 scale).

The brush can contain many GradientStop objects to define intermediate colors within the gradient.

The LinearGradientBrush example program shown in Figure 10-14 uses the following code to draw its rectangles:

```xml
<Rectangle Margin="5" Width="100" Height="100" Stroke="Black">
  <Rectangle.Fill>
    <LinearGradientBrush EndPoint="0.5,1" StartPoint="0.5,0">
      <GradientStop Color="White" Offset="0" />
      <GradientStop Color="Blue" Offset="1" />
    </LinearGradientBrush>
  </Rectangle.Fill>
</Rectangle>
<Rectangle Margin="5" Width="100" Height="100" Stroke="Black">
  <Rectangle.Fill>
    <LinearGradientBrush EndPoint="0.5,1" StartPoint="0.5,0">
      <GradientStop Color="White" Offset="0" />
      <GradientStop Color="White" Offset="0.5" />
      <GradientStop Color="Blue" Offset="1" />
    </LinearGradientBrush>
  </Rectangle.Fill>
</Rectangle>
<Rectangle Margin="5" Width="100" Height="100" Stroke="Black">
  <Rectangle.Fill>
    <LinearGradientBrush EndPoint="1,1" StartPoint="0,0">
      <GradientStop Color="Blue" Offset="0" />
      <GradientStop Color="White" Offset="0.5" />
      <GradientStop Color="Red" Offset="1" />
    </LinearGradientBrush>
  </Rectangle.Fill>
</Rectangle>
```

<Rectangle.Fill>

The first rectangle shades vertically from the top point (0.5, 0) to blue to the bottom point (0.5, 1).

The second rectangle adds an additional GradientStop object to make the gradient remain white until halfway through the brush before it starts shading to blue.

The third rectangle's brush uses different StartPoint and Endpoint values to make the gradient move from the upper-left corner (0, 0) to the lower-right corner (1, 1). It uses GradientStop objects to make the colors blend from blue to lime.

The final rectangle's brush has Endpoint (0.25, 0.5), so the brush only covers a quarter of the rectangle. The brush's SpreadMethod is set to Reflect, so the brush reflects to cover the rest of the rectangle.

# RadialGradientBrush

The RadialGradientBrush fills an area with colors radiating from a central point. Instead of using StartPoint and Endpoint the brush uses GradientOrigin, RadiusX, and RadiusY.

GradientOrigin determines the point from which the colors radiate. By default, this is (0.5, 0.5), so the colors radiate from the center of the brush (0, 0) to (1, 1).

RadiusX and RadiusY determine how far the brush extends horizontally and vertically from the center, using the (0, 0) to (1, 1) coordinate system.

REMEMBER THE RADIUS

Remember that the rectangle is half the width of a circle, so RadiusX and RadiusY values of 0.5 make the gradient fill the brush. Note also that values of 0.5 make the gradient only reach the sides of the brush. That means, for example, the corners of a rectangle are not covered by the gradient, so how they are filled depends on the SpreadMethod property.

The RadialGradientBrush example shown in Figure 10-15 draws several rectangles filled with RadialGradientBrushes. From left-to-right and top-to-bottom, these brushes have the following properties:

- A default brush shading from white to red
- RadiusX = 0.25 and RadiusY = 0.25
- RadiusX = 0.5 and RadiusY = 0.25
- An extra GradientStop object that makes the brush remain white until it is halfway through the brush- GradientOrigin = 0.25, 0.25
- An extra GradientStop object that makes the brush shade from red to white
- RadiusX = 0.1, RadiusY = 0.1, and SpreadMethod = Reflect
- SpreadMethod = Repeat (so you can see that the gradient doesn't reach the rectangle's corners)

# DrawingBrush

The DrawingBrush class fills an area with a drawing. The drawing may contain labels, lines, polygons, or others. Unfortunately, drawing a DrawingBrush in XAML code is rather difficult. The brush should contain a Drawing element that defines the drawing. The Drawing element can contain a drawing object such as a GeometryDrawing, a GlyphRunDrawing, or an ImageDrawing. Those objects define properties for the objects they contain. For example, the GeometryBrush and Pen properties apply to any objects you draw.

If you want to include more than one object, you can draw the DrawingGroup child, which can contain other drawing objects such as a GeometryDrawing, a GlyphRunDrawing, or an ImageDrawing.

Creating a complex picture within a DrawingBrush is quite a chore. In fact, it's so difficult that you might wonder why you don't use an ImageBrush, which is much simpler. But the advantage of the DrawingBrush is that it defines its commands so if you zoom in on a DrawingBrush you will still see smooth curves. In contrast, if you zoom in on an ImageBrush, the brush becomes pixelated and blurry.
