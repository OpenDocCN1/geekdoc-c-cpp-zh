The code starts an Ellipse object and creates the Brush in the Ellipse.Fill element attribute. The Brush uses TileMode = Tile so it will repeat as needed.

The property Viewbox = 0,0,1,1 makes the Brush use the entire drawing area for its content. (By default, ViewboxUnits = RelativeToBoundingBox.)

The code sets Viewport = 0,0,0.3,5 and ViewportUnits = RelativeToBoundingBox the first tile fills are a third of the Ellipse's width and half of its height.

Next, the code defines the Drawing's property. That element contains a GeometryDrawing. The GeometryDrawing's Geometry attribute contains a GeometryGroup that holds a PathGeometry and an EllipseGeometry.

The PathGeometry contains a PathFigure that draws a polyline (series of connected lines). The figure is closed (the endpoints connect to the start point) and starts at the points (10,0). The points defined by the PolySegment draw a diamond shape.

The EllipseGeometry draws an object of radius 2 centered at (20, 20), which is also the center of the diamond.

After finishing the GeometryGroup, the code defines the GeometryDrawing object's Pen. This is a Pen of thickness 2 drawn with a LinearGradientBrush that shades from black to white and back to black.
