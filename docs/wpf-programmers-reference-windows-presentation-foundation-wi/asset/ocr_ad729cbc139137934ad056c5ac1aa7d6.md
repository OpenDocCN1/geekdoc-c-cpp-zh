```
<Storyboard x:Key="sbMoveButton" RepeatBehavior="Forever">
  <DoubleAnimationUsingPath Duration="0:0:0:4">
    Storyboard.TargetName="btnMover"
    Storyboard.TargetProperty="Canvas.Left"
    Source="X"
    <PathGeometry x="StaticResource pathMove"/>
  </DoubleAnimationUsingPath>
  <DoubleAnimationUsingPath Duration="0:0:0:4">
    Storyboard.TargetName="btnMover"
    Storyboard.TargetProperty="Canvas.Top"
    Source="Y"
    <PathGeometry x="StaticResource pathMove"/>
  </DoubleAnimationUsingPath>
  <DoubleAnimationUsingPath Duration="0:0:0:4">
    Storyboard.TargetName="btnMover"
    Storyboard.TargetProperty="RenderTransform.Angle"
    Source="Angle"
    <PathGeometry x="StaticResource pathMove"/>
  </DoubleAnimationUsingPath>
</Storyboard>
```

RovingButtonWithPath

The code creates a PathGeometry object to define the path. Then that object in the sbMoveButton Storyboard.
The Storyboard's first DoubleAnimationUsingPath changes the Button's Canvas.Left property. The property should be set to the path's x coordinate as the animation progresses over the path.
Similarly, the second DoubleAnimationUsingPath object matches the Button's Canvas.Top property matches the path's Y coordinate as the animation progresses.
The Button's definition includes a RenderTransform object that initially rotates the Button by -90 degrees. The final animation object makes the Button's Transform.Angle property match the path's Angle during the animation.

# Mix and Match Key Frames

Each of the previous key frame examples uses a single type of key frame, but you can mix and match them. For example, a single storyboard might include linear key frames and discrete key frames. The storyboard can even include path animations.
The RovingButtonMixedKeyFrames example program shown in Figure 14-9 demonstrates a mix of linear and discrete key frames, and path animation. When you click on the Start button, the Button follows the route drawn in black.
