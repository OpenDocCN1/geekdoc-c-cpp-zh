# 200 | CHAPTER 12 RESOURCES

Now the following code defines two resources with the Double data type. Notice how the code uses the sys namespace prefix to indicate where the Double data type is defined.

```
<Window.Resources>
<sys:Double x:Key="dblRadX*5\></sys:Double>
<sys:Double x:Key="dblRadY">20</sys:Double>
</Window.>
```

The following code shows a Rectangle might use these resources to its RadiusX and RadiusY properties:

```
<Rectangle Margin="5" Width="175" Height="60"
Fill="Red" Stroke="Black" StrokeThickness="5"
RadiusX={StaticResource dblRadX}
RadiusY={StaticResource dblRadY}"n
/>
```

These simple data types let you place specific values in resources. For example, you can build a resource dictionary containing all of the strings that your application will use for labels, buttons, menu items, and other controls. You probably won't have to use the same text for several different buttons (although you might want a button and a menu item that have the same purpose to use the same text), placing these values in resources makes it easier to change them in a central location.
