# Pens

Brushes determine how an area such the interior of a rectangle is filled. They also determine how lines as the borders of a rectangle or polygon are filled.

Pens determine the style of lines such as the edges of rectangles and polygons. For example, they determine the line's thickness, pattern, and corner style.

The WPF properties that define a pen brush with the word Stroke and include StrokeThickness, StrokeDashArray, StrokeDashCap, and StrokeMiterLimit. You can find these properties in the Properties window's Appearance area, mostly in the advanced properties.

> In fact, the brush used to fill a line is stored in the line's property, so all of the properties that define a line's appearance are stroke properties.

Figure 3-21 shows a program that demonstrates three of the stroke properties. Its StrokeThickness property is set to 20, so the polygon's lines are very thick; its StrokeMiterLimit property is set to 1, so the extra corners on the right edge of the polygon are chopped off; and its Stroke is a brush that shades from red to yellow.

![](bbox=[0.685, 0.631, 0.87, 0.765])

Figure 3-21

The following XAML code defines the polygon's:

```
<Polygon StrokeThickness="20"
  Points="20,110 20,60 90,200 200,330 110,160 110,100 180,130 60,150"
  StrokeMiterLimit="2" >
  <LinearGradient EndPoint="0.5,0.1" StartPoint="0.5,0.0">
    <GradientStop Color="#FFFF0000" Offset="0"/>
    <GradientStop Color="#FFFF00FF" Offset="1"/>
  </LinearGradientBrush>
  </Polygon.Stroke>
</Polygon>
```
