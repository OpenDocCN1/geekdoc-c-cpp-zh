
In some ways, UniformGrid acts like a WrapPanel. Both arrange their children in a row until they run out of room, and then they begin a new row. However, there are two big differences between the controls.

First, the WrapPanel gives each item in a row the same height, but the items in different rows may have different widths so they don't necessarily line up in columns. In contrast, the UniformGrid gives every item the same size the area relatively vertically and horizontally.

Second, the WrapPanel has an Orientation property that determines how it arranges its children in rows or columns. The UniformGrid always arranges its children in row-first order.

# VIEWBOX

The Viewbox control controls its contents in various ways. That not only lets you stretch images (the Image control can do that by itself anyway), but it also lets you stretch other controls.

The Viewbox can contain only a single child, but that can be a container such as a Grid or StackPanel, so you can put anything you want in the child.

The Viewbox's Stretch property determines how it stretches its child. The Stretch property can take one of the following values:

- None — The child is not stretched.
- Fill — The child is stretched to fill the Viewbox even if that causes distortion.
- Uniform — The child is stretched uniformly (by the same amount vertically and horizontally) until it is as big as possible while still fitting within the Viewbox.
- UniformToFill — The child is stretched uniformly until it fills the Viewbox even if parts of the child stick out or are clipped.

# WRAPPANEL

The WrapPanel control works much like a StackPanel, arranging controls in a row. The difference between two is that the WrapPanel starts a new row when the current row runs out of it. It keeps its children in rows, starting new rows when necessary, until it has positioned all of its children.

Like the StackPanel, the WrapPanel has an Orientation property that can take the values Horizontal or Vertical. If you set Orientation to Vertical, the control arranges its children in columns of rows.

# SUMMARY

This chapter describes WPF's most useful layout controls. These are the controls that a program uses to arrange other controls in various ways.

This chapter provides a brief overview of the controls and gives enough detail to get started using them. However, some of the controls are fairly complex. In particular, the Grid control provides a lot of features for arranging its children, and you may need a bit of practice with it before fully mastering its capabilities.

The following chapter describes another group of controls: user interaction controls. These are controls such as TextBox, Button, and Menu that the user enter data, execute code, and otherwise control the application.
