## COMBINING TRANSFORMATIONS

You can transform any object using any combination of rotation, scaling, skewing, and translation transformations. To make a combined transformation, use a TransformGroup instead of a single transformation object. Inside the group, you can place any other order of transformations.

For example, the following code shows a TransformGroup for a Grid control that contains a translation followed by a rotation:

```
<Grid.RenderTransform>
<TransformGroup>
<TranslateTransform X="150" Y="0"/>
<RotateTransform Angle="60"/>
</TransformGroup>
</Grid.RenderTransform>
```

## LAYOUT AND RENDER TRANSFORMS

WPF controls have two transformation properties: LayoutTransform and RenderTransform.

WPF applies a control's LayoutTransform before it arranges that control and the others on the window. It then uses the transformed control's new width and height to calculate placement. For example, if you rotate a square 45 degrees, the result is a diamond that is wider and taller than the original. If the square is placed inside a StackPanel, the StackPanel will allow enough room for the rotated square to fit.

WPF applies a RenderTransform after the controls have been arranged and before they are drawn. This can produce some strange results in arranging controls such as StackPanel and WrapPanel, with controls sticking past the edges of the areas allocated by them.

RenderTransforms work well, however, if a control's container doesn't use control sizes to arrange its children. For example, a Canvas doesn't use control sizes to arrange controls, so RenderTransforms work there.

> TRANSLATION TRICKNESS
> Depending on a control's container, transformations sometimes produce unexpected results or may have no noticeable effect.

For example, suppose you place a Label inside a Grid and give the Label a transformation. WPF translates the Label but centers it inside the Grid so it appears in the same place it would have been if you hadn't bothered with the translation.

In situations like this, it is easier to get the result if you use a RenderTransform instead of a LayoutTransform, or if you move the control into a Canvas.

The LayoutVsRender example program shown in Figure 20-3 demonstrates the difference between the LayoutTransform and RenderTransform properties.

## EFFECTS

As transformations modify an object's geometry, bitmap effects modify the way in which an object is drawn.

To add an effect to an object, give it a BitmapEffect property element that contains an effect object. For example, the following code defines a Canvas that holds an Ellipse and a Path.

```
<Canvas Width="100" Height="100">
<Canvas.BitmapEffect>
  <DropShadowBitmapEffect />
</Canvas.BitmapEffect>
  <Ellipse Stroke="Blue" Fill="Yellow" Width="100" Height="100"/>
  <Path Data="M 20,50 A 30,30 0 0,1 80,50" Stroke="Blue" StrokeThickness="2"/>
</Canvas>
```

![](img/c9b2d394f4fc2f7e276f6a0a6fa9c2f6_400_1.png)

The following list summarizes WPF's bitmap effect classes:

- BevelEdges adds edges to the object. This effect has several important properties. BorderWidth determines how the beveled edges are. LightAngle determines the direction that light hits the beveled edges. Relief determines how the contrast is between the shadowed and lighted edges. Smoothness determines how much shadows are. EdgeProfile is discussed in the following paragraphs.
- Blur blurs the object. Radius determines how large the blurring is.
- DropShadowBitmapEffect — Adds a drop shadow behind the object. This effect's most useful properties are Color (which determines the shadow's color) and Direction (which gives the direction in degrees from the object to its shadow). ShadowDepth determines how far “behind” the shadow appears.
- EmbossBitmapEffect — Adds a glow around the object.
- OuterGlowBitmapEffect — Adds a aura around the object. GlowSize determines the aura's size. GlowColor determines the aura.

If you want to use more than one effect at the same time, use a BitmapEffect element that contains a BitmapGroup. Inside the BitmapGroup, place the effects that you want to use. For example, the following makes a Canvas using an EmbossBitmapEffect followed by a BevelBitmapEffect.

```
<Canvas.BitmapEffect>
  <BitmapGroup>
    <EmbossBitmapEffect />
    <BevelBitmapEffect BevelWidth="10"/>
  </BitmapGroup>
</Canvas.BitmapEffect>
```
