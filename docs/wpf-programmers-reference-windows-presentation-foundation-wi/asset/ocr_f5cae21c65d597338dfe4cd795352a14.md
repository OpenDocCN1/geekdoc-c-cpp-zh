When the canField Canvas control is resized, the following SizeChanged event handler executes. This happens when the control is first created and if the user resizes the control by resizing the browser.

```
private DateTime LastUpdate;
private List<Ball> Balls;
private DispatcherTimer Clock;

// Get ready to run.
private void canField_SizeChanged(object sender, SizeChangedEventArgs e)
{
    GetReady();
}

// Delete all balls. Necessary if the user resizes.
canField.Children.Clear();

// Make some balls.
Balls = new List<Ball>();
Random rand = new Random();
Rect bounds = new Rect(0, 0, canField.ActualWidth, canField.ActualHeight);
for (int i = 1; i <= 5; i++)
{
    Balls.Add(new RandomBall(rand, bounds));
}

// Prepare the timer.
LastUpdate = DateTime.Now;
Clock = new DispatcherTimer();
Clock.Interval = TimeSpan.FromSeconds(0.1);
Clock.Tick += Tick;
Clock.Start();n
```

BouncingBalls

The program declares class-level variables that hold the time when the balls were last updated, the references to a DispatchTimer object that provides Tick events.

The SizeChanged event handler simply calls GetReady(). That function removes Ellipses that are currently in the Canvas. (Try commenting this step to see an interesting result.)

Next, the code uses the Random function to create five Ball objects, storing them in the Balls list. The Ball class keeps track of the size, position, and velocity of balls moving on the screen and is described shortly.

The RandomBall function simply creates a new Ball and initializes its properties randomly. It is straightforward so it isn't shown here now.

The GetReady function finishes by preparing the Clock DispatchTimer. It creates the timer, sets its Interval property so it ticks every tenth of a second, gives it a new Tick event handler, and starts it.
