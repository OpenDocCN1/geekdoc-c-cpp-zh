The DepartmentPanel Style then defines its MouseOver Trigger. When MouseOver is True, the Trigger sets the StackPanel's Opacity to 1, so the Controls are fully opaque, and the LayoutTransform property to the previously defined ScaleTransform resource, so the StackPanel is enlarged.

# # IsActiveAndFocused Triggers

Several of the previous triggers take action when the MouseOver property is True. The MouseOver property is a natural choice for examples because it provides nice, graphical feedback that's easy to see, but you can write triggers for values in just any property.

The ActiveTrigger example program shown in Figure 13-11 demonstrates two triggers that watch the Window's IsActive property and the TextBox's IsFocused property.

These triggers provide two effects:

+   1. First, when the program is inactive because another application has the focus, the program changes its Title to Inactive.
2. Second, the TextBox that contains the insertion cursor displays a red glow.

![](bbox=[0.638, 0.276, 0.929, 0.413])

After the window opening <Window> tag, the Style element defines the Window's Style. This example defines the Style directly rather than in a resource that it later references for demonstration purposes and partly there will be only one Window object in the file.

The following code shows the Window's Style element that changes the Window's Title to Inactive when some other program has the focus:

```
<Style>
  <Style TargetType="Window">
    <Setter Property="Title" Value="ActiveTrigger"/>
    <Triggers>
      <Trigger Property="IsActive" Value="False">
        <Setter Property="Title" Value="Inactive"/>
      </Trigger>
    </Triggers>
  </Style>
</Style>
```

![](bbox=[0.093, 0.574, 0.149, 0.656])

![](bbox=[0.833, 0.733, 0.929, 0.755])

The only trick to this Style is that it sets the Window's Title property. When the IsActive property is False, the Trigger tries to set the Title property to Inactive. If the Window element explicitly sets a value for Title in an attribute, then the Trigger won't be able to override that value.

To allow the Trigger to do its job, the Window element must not have a Title attribute. To display a title when it is active, the Style sets the Window's initial Title in its first Setter.
