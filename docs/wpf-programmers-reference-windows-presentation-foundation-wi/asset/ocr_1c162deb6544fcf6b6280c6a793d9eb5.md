The ListView property (the ListView View element in the code describes how the control's data should be displayed. The GridView property produces the gridlike arrangement shown in Figure 5-17.

The GridView element contains a series of GridViewColumns that define the view's columns. The Width and Header attributes set the text displayed at the top of a column and the column's initial width.

The GridViewColumn's DisplayMemberBinding attribute tells the column to find the data it should display in that column. The Path of the binding tells what part of the data to display. # ProgressBar

The ProgressBar displays information to the user. As your program performs some consuming task, it can use a ProgressBar to let the user know that the program is still working and to indicate how much it has done.

The control's Minimum, Maximum, and Value properties determine the control's appearance. For example, suppose your program needs 17 large text files. You could set the ProgressBar's Minimum property to 0 and its Maximum property to 17. After processing each file, the program could set the control's Value property to the number of files processed so far. As the program worked through its way, the ProgressBar would fill in a corresponding percentage of itself.
