# CHAPTER 5 CONTENT CONTROLS

The following table describes properties that determine the pop-up appears when it is visible:

| PROPERTY | PURPOSE |
| --- | --- |
| PlacementTarget | The object relative to the Popup is positioned. Typically, this is a control, and the Popup is placed next to it. In XAML code, this might look like: `PlacementTarget="Binding ElementName=image"`. If you omit this property, then the Popup is positioned relative to its container. |
| Placement | Determines how the Popup is positioned relative to the PlacementTarget object. See the following text for information. |
| PlacementRectangle | If you include this, it determines a rectangle within the PlacementTarget relative to which the Popup should be positioned. |
| HorizontalOffset | Sets a horizontal offset for the Popup's placement. |
| VerticalOffset | Sets a vertical offset for the Popup's placement. |

The Use example program shown in Figure 5-9 demonstrates the PlacementTarget and IsOpen properties. When the mouse enters a sample picture, the program's code-behind uses those properties to display the larger picture in a Popup.

The following XAML code shows how the program creates its interface:

```
<StackPanel Orientation="Horizontal" Height="35" Margin="4">
  <Label Width="200" Content="George Washington"/>
  <Image Name="img" Stretch="Uniform"
    Source="GeorgeWashington.jpg"
    MouseEnter="img_MouseEnter"
    MouseLeave="img_MouseLeave" />
</StackPanel>

.. Other rows omitted
<Popup Name="popFullScale" Placement="Right"
  HorizontalOffset="5" VerticalOffset="5">
    <Image Name="imgFullScale" Stretch="None"/>
  </Popup>
</StackPanel>
```
