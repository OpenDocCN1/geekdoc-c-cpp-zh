# BUTTON

Many applications customize Buttons extensively to give them new shapes, highlights, translucency, and graphical effects. To keep this code simple, the following template makes it Button from a simple rectangle and changes the Rectangle's color to show different Button states:

    <Style x:Key="styDefault" TargetType="Rectangle">
      <Setter Property="Fill" Value="DarkGreen/"
    </Style>
    <Style x:Key="styDisabled" TargetType="Rectangle">
