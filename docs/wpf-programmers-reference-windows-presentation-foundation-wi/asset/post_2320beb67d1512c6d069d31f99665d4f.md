# HYPERLINK NAVIGATION

One simple way to navigate in a Page is to document it that it contains hyperlinks. The hyperlinks automatically navigate from the application's Pages and even to external locations on the Web.

The PageDocument example program shown in Figure 2-2 contains two Pages. Each Page displays a FlowDocument that contains a series of hyperlinks that let you to navigate between sites. The bottom link on each Page leads to the other Page.

Figure 22-2 shows the navigation dropdown open and displaying the program's navigation history. When I started the program, it displayed its Writing Links. I used the hyperlinks to navigate to the Map Links page (displayed as "Current Page" in the dropdown) and then to the Google Maps. Next, I clicked on the Back button to move back to the Map Links page and opened the dropdown. The mouse is over the Writing Links page so it is highlighted and displays a left arrow. Figure 22-2. ("Future" pages such as Google Maps in this case display a right arrow). The second page is similar.

The following code shows the body of the program's first.

```
<FlowDocument>
<Paragraph FontSize="20" FontWeight="Bold" TextAlignment="Center">
  Writing Links
</Paragraph>
<List>
  <ListItem>
    <Paragraph>
      <Hyperlink NavigateUri="http://www.rhymezone.com/">RhymeZone</Hyperlink>
    </Paragraph>
  </ListItem>
  <ListItem>
    <Paragraph>
      <Hyperlink>
    </Paragraph>
  </ListItem>
```

# RECYCLING OLD OBJECTS

> It is important to note that navigating to a new instance of a Page rather than reusing any existing Page objects. In contrast, if you click the Back or Next to move to a previously viewed Page, the program redraws the object it previously showed.

For example, a program's first Page contains a TextBox. You enter text into it and click on a hyperlink to move to a second Page. Now, if you click the Back-button, you will see the text on the first Page. However, if you click on another hyperlink to move to the first Page, you'll see a new object with a blank textbox.

If you want to allow this sort of navigation but the hyperlink to lead to the original Page object, you'll need to use some code-behind rather than letting the hyperlink navigate for you automatically.

# NAVATIONSSERVICE

In addition to using hyperlinks, an application's code-behind can use a NavigationService to navigate. A NavigationService object lets an application code-behind to control how the container navigates.

The PageApp example program shown in Figure 22-3 uses a NavigationService to move between its pages.

When you click on one of the buttons shown in Figure 22-3, the program uses the NavigationService’s Navigate method to open the new page. The following code shows how the program moves to the “Add Customer” page shown in Figure 22-4:

```
private void btnAddCustomer_click(object sender, RoutedEventArgs e)
{
    NavigationService.Navigate(new pagAddCustomer());
```

This code calls the NavigationService’s Navigate method, passing it new pagAddCustomer Page object.
In addition to displaying a Page object, the Navigate method can display a web page. The following code executes if you click the Help icon in the lower-right corner of Figure 22-3. This code navigates to the web page www.vb-helper.com/wpf.htm.

```
// Go to the help web site.
private void btnHelp_Click(object sender, RoutedEventArgs e)
{
    NavigationService.Navigate(new Uri("http://www.vb-helper.com/wpf.htm"));
}
```

The NavigationService object provides other useful properties and methods in addition to Navigate. The following code shows how the program PageApp returns from the "Add Customer" page shown in Figure 22-4 when you click on the checkmark in the lower right:

```
// Prepend we did something and return to the main page.
private void void btnnOk_Click(object sender, MouseButtonEventArgs e)
{
    MessageBox.Show("Customer created.", "Customer created",
    MessageBoxButtons.OK, MessageBox.Information);
    if (NavigationService.CanGoBack())
    {
        NavigationService.GoBack();
    }
    else
    {
        NavigationService.Navigate(new pageMain());
    }
}
```

PageApp

This code first displays a message box. It then checks the NavigationService’s CanGoBack property to see if the user can go back to a previous page — in this case, the program’s ideal state. If CanGoBack is True, the code calls the NavigationService’s GoBack method. If CanGoBack is False, then the code calls the NavigationService’s Navigate method, passing a new pageMain Page object.

The following list summarizes the NavigationService’s most useful properties and methods:

- AddBackEntry — Adds a navigation entry that contains a custom state object.
- CanGoBack — True if the NavigationService can move back to a previous object.
- CanGoForward — True if the NavigationService can move forward to a following object.
- GoBack — Goes to the previous page if one exists.
- GoForward — Goes to the next page if one exists.
- Navigate — Displays a Page or URI.
- RemoveBackEntry — Removes the most recent navigation entry.
- Source — Gets or sets the URI of the display. Normally in code-behind, you would use the Navigate method to open a source, but you can set this property in XAML to make the Page open.

# FRAME

The previous example display Page objects. The result is a form containing navigation buttons, the Page object, and nothing else.

Sometimes you may want a Page to appear as only part of a form that contains other elements. You can achieve this by placing a Page inside a Frame.

You cannot write XAML code that places a Page inside a Frame, but you can set the Frame's Source property to the name of the Page that it show.

The FrameApp program shown in Figure 22-5 uses this to display the Pages used by the PageApp inside a Frame. In Figure 22-5, the top and bottom labels and the green background are part of a Window. Everything else is inside the Frame.

The following XAML fragment shows how the Frame displays its Labels and Frame. An unnamed style targeted at Label controls the Labels and gives them drop shadows.

```
<StackPanel>
  <Label FontSize="30" FontWeight="Bold" Content="FrameApp"/>
  <Frame Name="main" Source="PageMain.xml" Height="420" Margin="10"/>
  <Label BorderBrush="Black" BorderThickness="1" FontSize="16"
    Content="Use the buttons inside the Page to navigate within the frame."/>
</StackPanel>
```
