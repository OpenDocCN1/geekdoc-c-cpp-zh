# BulletDecorator

The BulletDecorator displays an item and bullet in bulleted list. The control can have only a single child (other than the bullet), but that can be a container such as a Grid or StackPanel, so this isn't really of a restriction.

The BulletDecorator's most important property is Bullet, which should contain the object to be used as the item's bullet. Normally this should be something that looks like a bullet such as a small image or character, but in theory it can be something else like a label or border.

The following XAML code creates the first item in the bulleted list shown in Figure 5-15. The three BulletDecorator controls are contained in a StackPanel to make the list.

![](bbox=[0.715, 0.196, 0.931, 0.303])

```
<BulletDecorator>
  <BulletDecorator.Bullet>
    <Image Width="20" Height="20"
      Source="Bullet.bmp" Stretch="None"
      HorizontalAlignment="Left" VerticalAlignment="Center">
      <Image.BitmapEffect>
        <GroupShadowBitmapEffect/>
      </Image.BitmapEffect>
    </Image>
  </BulletDecorator.Bullet>
  <Label Content="Choice 1" Foreground="Red"/>
</BulletDecorator>
```

# GroupBox

A GroupBox displays a header and a border around a single child. Like the Border, the GroupBox is useful for creating distinct areas in a window.

The GroupBox's Foreground property determines the brush used to draw the header text, with its BorderBrush property determines the brush used to draw the border. The Background property determines the GroupBox is filled.

| BROKEN BORDERS |
| For some reason, the GroupBox's border is partially obscured if the control's BorderThickness property is larger than 2.
| Note also that you can hide the border by setting BorderThickness = 0. |
