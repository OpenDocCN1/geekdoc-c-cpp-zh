private void ShowSample() {
  if (borSample == null) return;

  byte r, g, b;
  try {
    r = byte.Parse(txtRed.Text);
  } catch {
    r = 0;
  }
  try {
    g = byte.Parse(txtGreen.Text);
  } catch {
    g = 0;
  }
  try {
    b = byte.Parse(txtBlue.Text);
  } catch {
    b = 0;
  }
  borSample.Background = new SolidColorBrush(Color.FromRgb(r, g, b));
}

EventNameAttributes

When the scrollbar value changes, the ValueChanged event handler converts the new value into integer (to throw any fractional part) and displays the result in the red component's textbox. It then calls ShowSample to display a sample of the new color.

When the textbox's value changes, the TextChanged event handler converts the new value into an integer. It makes sure the result is between 0 and 255, the allowed values for a color component, and renders the result. It then sets the corresponding scrollbar's value to this new value and calls ShowSample to display a sample of the color.

The ShowSample method gets the values in the red, green, and blue textboxes; uses them to create a color; and displays it in the Background property of the Border control borSample.
