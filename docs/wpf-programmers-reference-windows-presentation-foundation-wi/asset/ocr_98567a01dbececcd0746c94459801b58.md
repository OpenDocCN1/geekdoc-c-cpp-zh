OrderTracking

The program begins by defining Window attributes. Setting the SizeToContent attribute to WidthHeight makes the window automatically resize to fit its content so the window is an appropriate size when it is skin. The code also sets the ResizeMode attribute to NoResize, so the window stays that size.

Next, the code loads its resource dictionaries. The first one, resBasics.xml, contains values that are the same for every day. It defines the window's fonts properties and an unnamed Button style that sets the Button sizes and margins.

After that, the code loads the resource dictionary for the skin we display. The preview code includes the resource file for managers, resManager.xml, and the other resource files are commented out.
