The code first gathers geometry information. It then gives the ball a random position on the Canvas. (Notice how the program uses the Canvas's SetLeft and SetTop methods to set the values of the ball's Canvas.Left and Canvas.Top attached properties.)

Next the program creates a DoubleUsingKeyframes object to manage the ball's X coordinate and its RepeatBehavior to Forever. It will calculate the time spent moving to the left and right of its initial position. The code creates LinearDoubleKeyframe objects to move the ball to the right edge, back to the left edge, and back to its starting position. (Note that the key times are cumulative, e.g., the key times might be 0:0:0.25, 0:0:1.25, and 0:0:2).

The code repeats these steps to make an animation for the ball's Y coordinate.

Finally, the code calls the ball's EllipseAnimation method, passing the properties it should animate and the corresponding animation objects. Notice how the code uses the Canvas's LeftProperty and TopProperty values to identify the Ellipse's attached Canvas.Left and Canvas.Top properties.

Using animation, storyboard, game frame, and others, your code-behind can build any animation that you can make using XAML.

# EASY ANIMATIONS

Building animations can be a tedious business. The code is long and deeply nested for even simple animations. For example, the JumpingButton example program uses the following code to build one of the simplest animations, modifying a single property to make the Button move up and back to its starting position.

```
<Button Contents="Jump!" Width="100" Height="40">
  <Canvas.Top="65" Canvas.Left="95">
    <Button.Triggers>
      <EventTrigger Routed="Button.Click">
        <EventTrigger.Actions>
          <Storyboard>
            <DoubleAnimation To="0:0:0.25" Duration="0:0:0.25" AutoReverse="True"/>
            <Storyboard.TargetProperty="Canvas.Top"/>
          </Storyboard>
        </EventTrigger.Actions>
      </EventTrigger>
    </Button.Triggers>
  </Canvas.Top>
</Button>
```
