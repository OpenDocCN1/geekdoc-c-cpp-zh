SelectedValuePath — This gives the path in the ItemsSource to the value that is stored and manipulated by the control. In this program, the Students DataTable stores each student's state abbreviation, not its full name, so SelectedValuePath is the field that gives the abbreviation: State.

SelectedValue — This gives the value the control displays and modifies. In this case, the ComboBox displays the value for the current StudentsTable's value.

To understand how this works, you select a student who has State = AZ. The ComboBox's SelectedValue binding gets the value of Tables[Student].State, which is AZ. The control then looks in its ItemsSource (which is Tables[Students]) for the field referred to by SelectedValuePath (which is State). The value that matches AZ looks up the corresponding DisplayMemberPath (Arizona), and displays it.

If you select a new value from the ComboBox, the process reverses. The control gets the value selected and looks it up in the ItemsSource's DisplayMemberPath field. It gets the corresponding SelectedValue and saves it as the SelectedValue.
