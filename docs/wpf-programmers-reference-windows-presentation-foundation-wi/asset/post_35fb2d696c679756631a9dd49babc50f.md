
## ANIMATION CLASSES

WPF provides many animation classes that you can use in Storyboards. For each data type that these classes animate, there are three possible kinds of animation.

A basic animation moves a property from one value to another in a straightforward way. These animation classes have names ending with Animation. For example, the class that animates the Double data type is DoubleAnimation.

A frame animation uses key frames to define points along the animation. These classes have names ending with AnimationUsingKeyFrames, in DoubleAnimationUsingKeyFrames.

A path animation uses a PathGeometry to specify values during the animation. These classes have names ending with AnimationUsingPath, in DoubleAnimationUsingPath.

Key frame animations use a collection of key frames to define the values that the animation should visit and the way in which the values change from one to another. For example, a LinearKeyFrame object makes a Double property vary linearly from its previous value to the one defined by the key frame object.

Table O-3 lists the key frame classes. The name of a particular key frame class starts with the value shown in this table, followed by the data type, followed by KeyFrame, as in LinearDoubleFrame.

## TABLE O-3: Key Frame Classes

| KEY FRAME TYPE | PURPOSE |
|---|---|
| Discrete | Makes the property jump to its new value discretely |
| Linear | Makes the property move linearly to its new value |
| Spline | Makes the property move smoothly between values using a spline to control the movement's speed. For example, you can use a spline to make the property's change start slowly, speed up in the middle, and then slow to a stop. |
