# Properties Window

You can use the Solution Explorer to find other project files as code-behind files. For example, to open the code-behind for Window1.xaml, click on the hollow triangle to the left of that file in the Solution Explorer if necessary, and double-click on the MainWindow.xaml.cs (for C#) or MainWindow.xaml.vb (for Visual Basic) that lies beneath. (Figure 2-9 shows the file expanded to the code-behind file.)

If you add resource files to the project as images, video, or audio files, you can change the files' properties. Click on a file in the Solution Explorer to select it and then use the Properties window to set properties as “Build Action” and “Copy to Output Directory.”

# EDITORS EVERYWHERE

Visual Studio includes a lot of kinds of editors. It can edit C#, Visual Basic, XAML, images, icons, and cursors.

In fact, you have relatively easy way to create and edit images and icons. Open the Project menu and select “Add New Item.” Select the type of file that you want to add, give it a good name and click Add. Initially Visual Studio opens the new file for editing. You can double-click on the file in Solution Explorer to edit it.

The editors include all of useful tools such as color palettes, drawing tools (pens, brushes, spray, flood), and specialized tools for different file types. For example, the Cursor Editor lets you set the cursor's hotspot, and the Icon Editor lets you add new sizes and colors to the file. (Icons look best on different systems if you provide lots of different sizes and depths.) The tools may not be as powerful as commercial editors that you can buy, but they are functional and handy.

# PROPERTIES WINDOW

The Properties window lets you view and edit the properties for the currently selected control in the Window Designer. Figure 2-10 shows the Properties window with a Grid control selected.

The Properties window can only set relatively simple kinds of properties. For example, you can set a control's Background, Fill, or Stroke to solid colors such as Red, Light Blue, or #FFFF800 (a dark orange). You can even set these properties to gradient brush but cannot set them to more complex objects as visual brushes.

To set more complex property values in Visual Studio, you need to type the brush's code in the XAML Editor. For example, the code fills a Rectangle with a VisualBrush:

```
<Rectangle>
  <Rectangle.Fill>
```
