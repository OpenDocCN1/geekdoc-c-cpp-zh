# VisualBrush

The VisualBrush class fills an area with a control of user interface element. That element can contain other controls such as Lines, Labels, TextBoxes, Polygons, and just anything else that you want to add.

In fact, if you fill an area with a VisualBrush defined by a control and that control changes at run time, then the Brush automatically updates to match the control's appearance.

Unfortunately, when you choose to define the Brush cannot be invisible because the Brush needs to use its drawing, and image does not exist if the Visibility property is not set to Visible. That means you cannot make the control completely hidden and then use it only to fill area on the screen.

You can, place the control before another control or move it if it is off the program's run.

The MagnifiedVisualBrush example program uses a VisualBrush to perform exactly as result as the MagnifiedDrawingBrush program uses a VisualBrush instead of a DrawingBrush.

The following XAML code shows how the MagnifiedVisualBrush program builds the control that defines its VisualBrush. Note how the code sets the Canvas's Margin property to move the left edge of the control which is invisible at run time "-120,0,0,0".

```
<Canvas HorizontalAlignment="Left" Margin="-120,0,0,0">
  <Rectangle Name="Face" Width="100" Height="100" Background="Yellow">
    <Canvas Left="0" Canvas.Right="100" Width="100" Height="100">
      <!-- left -->
      <Ellipse Left="15" Canvas.Top="5" Width="20" Height="40"
        Stroke="Black" Fill="White"/>
      <!-- left -->
      <Ellipse Left="25" Canvas.Top="20" Width="10" Height="20"
        Fill="Blue"/>
      <!-- right -->
      <Ellipse Left="63" Canvas.Top="10" Width="24" Height="36"
        Stroke="Black" Fill="White"/>
      <!-- right -->
      <Ellipse Left="63" Canvas.Top="15" Width="10" Height="20"
        Fill="Blue"/>
      <!-- nose -->
      <Ellipse Left="43" Canvas.Top="35" Width="14" Height="30"
        Stroke="Green" Fill="Lime"/>
      <Line X1="35" Y1="80" X2="80" Y2="80" Stroke="Red" Thickness="5"/>
    </Canvas>
  </Rectangle>
</Canvas>
```
