# EXAMPLE Using Button

The following code creates two Buttons. The first uses a simple text caption. The second contains a StackPanel that has a Label and an Image.

```
<Button Content="Click Me" Click="btnClickMe"/>

<Button Click="btnSmile_Click">
  <StackPanel>
    <Image Source="smiley.jpg" Height="50"/>
    <Label Content="Smile!" HorizontalAlignment="Center"/>
  </StackPanel>
</Button>
```

The previous code's Click attributes gives the name of each Button's event handler in the code-behind. The following C# code shows Click event handlers for these Buttons. This code just displays a message box that you the Buttons have done something.

```
private void btnClickMe_Click(object sender, RoutedEventArgs e)
{
  MessageBox.Show("Click me clicked");
}

private void btnSmile_Click(object sender, RoutedEventArgs e)
{
  MessageBox.Show("Smile clicked");
}
```

# CHECKBOX

The CheckBox lets the user check or unchecked an option. The user can check and unchecked any number of CheckBoxes in any combination. (Contrast this with the RadioButton, where only one in a group is selected at a time.) Table D-2 gives the key properties of CheckBox, and Table D-3 gives the keys event.

# TABLE D-2: Key Properties of CheckBox

| PROPERTY | PURPOSE |
| --- | --- |
| IsChecked | Determines whether the control is currently checked. |
| IsThreeState | Determines whether the control cycles through three values — checked (IsChecked = True), unchecked (IsChecked = False), and indeterminate (IsChecked = null). |
