# Flow Documents | 377

The Table's content includes TableRow objects that hold TableGroup objects. Each TableRow contains a series of TableCells that hold block elements such as Paragraphs and BlockContainers.

The following code shows how the ShowFlowDocument program defines the content for the Table shown in Figure 21-6. Since the code contains lists of repeating elements (rows for each planet and five cells in each), many of them are omitted to save space

![](bbox=[0.075, 0.213, 0.138, 0.283])

```
<TableRow>
  <!-- Title -->
  <TableCell Background="#FF0A0FF">
    <TableCell ColumnSpan="5" TextAlignment="Center">
      <Paragraph FontSize="16" FontWeight="Bold">Planets</Paragraph>
    </TableCell>
  </TableCell>
</TableRow>
```
