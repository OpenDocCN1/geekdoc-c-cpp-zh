department might have Managers and Projects properties that return lists of Manager and Project objects, respectively.

To build the hierarchical data, create instances of the classes. Initialize their collection properties so that they properly represent the hierarchy.

To tell the TextView how to display data and how to follow the hierarchy, place one or more HierarchicalDataTemplate elements inside the Resources section. The DataType attribute tells which of the object template handles. The ItemsSource attribute tells which property the TextView should use to descend further into the data hierarchy after it is done with the current item. The HierarchicalDataTemplate's content should define the values that the control should display for the current object. Typically, this includes Label, TextBlock, and other controls with content bound to the current hierarchical object.

The following code snippet shows a HierarchicalDataTemplate that handles Department objects. The TextBlock displays the current Department object's Name property. The ItemsSource attribute refers the Department's Managers property next.

```
<HierarchicalDataTemplate DataType="x:local:Department"
ItemsSource="{Binding Path=Managers}">
<TextBlock Text="{Binding Path=Name}" Foreground="Blue"/>
</HierarchicalDataTemplate>
```

There are a couple you can attach the TextView to the hierarchical data. First, you can make the control's ItemsSource refer to a property defined by the form. That property can return a collection holding the top-level data items.

The following XAML code attaches the TextView to the MainWindow object's TopLevelData property. For more information on binding properties to the Window, see the section, "Collections in Code-Bind," earlier in this appendix.

```
<TreeView ItemsSource="{Binding ElementName=MainWindow, Path=TopLevelData}">
```

A second approach is to make the code-bind behind the TextView to the data. The following code snippet shows the TextView named trvParts to the listed parts:

```
trvParts.ItemsSource = parts;
```

For more information on binding TextView controls to data, see the section, "TreeView Templates," in Chapter 18.
