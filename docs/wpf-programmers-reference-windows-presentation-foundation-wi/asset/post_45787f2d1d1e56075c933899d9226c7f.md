To create a style for a group of buttons, make one button with the properties you want in the style. Then select the button, open the Object menu, expand the Edit Style submenu, and select "Edit a Copy."

Note that Expression Blend will only apply a style to an object that is compatible with the one you used to define the style. For example, if you define a Button style, you cannot apply it to a Label.

## OBJECTS AND TIMELINE

The Objects and Timeline area shown in Figure 27 lets you edit objects and storyboards. Usually you use this area to select controls so you can change their properties in the Properties window.

When it is displaying the window's controls, this area shows the hierarchical arrangement of controls. For example, Figure 27 shows the window contains a Grid named OuterGrid, which contains two Grids named InnerGrid and InnerGrid. Those controls contain others (the squares around a control mean it has no children).

One of the most confusing uses of this area is how you select controls. If you click on a control, it turns gray and is selected for property editing, so you can apply the properties to the control. In Figure 27, the Label is selected for property editing.

If the control you click is a container, it is also highlighted with a blue box. If the control is not a container, then its container is highlighted. In Figure 27 the StackPanel containing the Label is highlighted.

If you double-click on a control in the Toolbox, a new instance of that control is highlighted. In Figure 27, if you double-click the Button, a new Button is added to the StackPanel.

The Objects and Timeline area has two useful icons to the right of each. The first, which looks like an eye, lets you make the control visible or invisible. Even if you want a control to be visible, it's sometimes useful to hide it at design time to reduce clutter so you can see the controls easier.

The second icon looks like a padlock depending on whether you have clicked it. When the padlock is visible, the control's properties are locked so you cannot accidentally change them by dragging the control on the Window Designer.

The Objects and Timeline area has several other features. You can click-and-drag controls to new positions. For example, that would reorder the controls in the StackPanel.

One final trick is worth mention. If you select a group of controls, right-click on them, and select "Group Into," then Expression Blend lets you select a container such as a Grid or StackPanel. When you pick container, Expression Blend moves the controls into a new instance of the container.

## SUSPEND TIME

While you are editing a storyboard, the Window Designer is outlined in red and displays a label at the top that says “Timeline recording is on.” Click the red dot beside this label to turn recording off. Then you can modify control properties without the changes becoming part of the storyboard.

Figure 28 shows the timeline for the SpinButton storyboard in the Spinning program. The storyboard sets a button's angle of rotation to 0 degrees at 0 seconds and sets the angle of rotation to 360 degrees at 0.5 second. This makes the button rotate through one complete revolution in a half second.

## TRIGGERS

After you design a storyboard, you can determine which events trigger it. Expression Blend hooks the storyboard to the window's Loaded event so the storyboard events execute when the program starts.

You can change this behavior by using the Triggers area in Figure 29.

Click on the dropdown to the right of the word “When” and select the control that should trigger the storyboard. In Figure 29, this is set to the Button named btnSpinMe.

## CONTROL TOOLBOX

The Control Toolbox shown in Figure 30 lets you control the window. Double-click a control in the Objects and Timeline area to select it. Then you can double-click a control in the Toolbox to put a new instance of that control in the selected control.

The Toolbox only shows a few controls at a time. If you do not see the control you want, you need to take action to make it appear.

If the control is one of the more common controls, you can find it in the Toolbox's groups. For example, the third control from the top in Figure 30 represents the Grid control. If you want some other control, you can right-click this one and select Canvas, StackPanel, or some other control from a dropdown list. That replaces the Grid with the control you selected so you can use it.

If the control isn't in any of the control groups or you just can't find it, click on the double arrow at the bottom of the Toolbox to open the Asset Library, shown in Figure 31.
