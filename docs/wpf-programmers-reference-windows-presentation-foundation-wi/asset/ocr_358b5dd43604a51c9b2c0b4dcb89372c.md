# SimpleClock

The first Label displays the TimeNow as a static resource using hard-coded brushes.

The second Label displays the TimeNow dynamically. It also uses the DynamicResource keyword to set its Foreground and Background properties from its own resources.

The third Label displays the TimeNow dynamically. In addition, it the DynamicResource keyword to get its background and Foreground Brushes from the system resources.

The Label gets its Brush from the system's active caption color. The static resource ActiveCaptionKey gives the name of the Brush in the system resource dictionary. The code that uses value in a DynamicResource statement to look up the corresponding value.

The Label builds its Background Brush so it matches the system's desktop color. Because the system resources do not define a desktop brush color, the code builds a SolidBrush that uses the desktop color.

The SimpleClock program follows the code-behind to update the TimeNow resource every second:

```
public Window()
{
    this.InitializeComponent();

    // Insert code required on object creation below this point.
    tmClock = new System.Timers.Timer(1000.0);
    tmClock.Elapsed += new System.Timers.EventHandler(tmClock_Elapsed);
    tmClock.Enabled = true;
    SetTimeResource();
}
```

```
// Update the TimeNow resource every second.
private void Update(Object sender, System.Timers.ElapsedEventArgs e)
{
    this.Dispatcher.Invoke(new Action(SetTimeResource));
}
```

```
// Update the TimeNow resource.
private void SetTimeResource()
{
    this.Resources.Remove("TimeNow");
    this.Resources.Add("TimeNow", DateTime.Now.ToString("T"));
}
```
