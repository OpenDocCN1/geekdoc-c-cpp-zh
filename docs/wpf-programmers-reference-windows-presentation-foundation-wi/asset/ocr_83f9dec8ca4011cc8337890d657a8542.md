| PROPERTY | PURPOSE |
| --- | --- |
| Content | The control's content, usually simple text |
| FontFamily | The name of the font family as Times New Roman, Arial, or Segoe (pronounced see-go) |
| FontSize | The text's size. Append cm, in, px, or pt to specify centimeters, inches, pixels (the default), or points (1/72 inch) as in "0.25in" or "12pt". |
| TextStyle | Can be Normal, Italic, or Oblique (simulates italic for fonts without an italic style) |
| FontWeight | The text's **boldness**. This can be Thin, ExtraLight, Light, Normal, Medium, SemiBold, Bold, ExtraBold, Black, and ExtraBlack. |
| Foreground | The color used to draw the text |

> **CLEVER COPYING**
If you want the user to be able to copy text to the clipboard, consider using a readonly **Text** instead of a *Label*.
