## 背面移除 (BACKFACE REMOVAL)

移除背向相机的三角形称为背面移除（backface removal）。有时它也被称为*剔除*（culling），尽管它也可以指任何快速从考虑范围中移除三角形的方法。例如，如果你能识别出相机背后的三角形，它们也可以被剔除。
