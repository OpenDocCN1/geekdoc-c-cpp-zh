## TABCONTROL

The TabControl displays a series of tabs where you can place different sets of information. The control should contain a series of TabItems, each of which holds a single item (which is often a container such as a Grid). The properties of TabControl are given in Tab C-11.

**TABLE C-11: Key Properties of TabControl**

| PROPERTY | PURPOSE |
| --- | --- |
| Background | The color used to fill the interior of the tab contents. This color does not fill the header area. |
| BorderBrush | The color of the edge of the tab contents. This does not include the header area. |

#### TABLE C-11 (continued)

| PROPERTY | PURPOSE |
|---|---|
| BorderThickness | The contents' border thickness. This does not include the header area. |
| FlowDirection | Determines whether the tabs are arranged right-to-left or left-to-right. |
| FontFamily | The name of the font family as in Times New Roman, Arial, or Segoe |
| FontSize | The text's font size. Append cm, in, px, or pt to specify centimeters, inches (the default), or points (1/72 inch) as in "0.25inch" or "12". |
| FontStyle | Can be Normal, Italic, or Oblique (simulates italic for fonts without an italic style) |
| FontWeight | The text's boldness. This can be Thin, ExtraLight, Light, Normal, Medium, Semibold, Bold, ExtraBold, Black, and although many fonts look the same for many of these values. |
| Padding | The extra space added between the control's edges and the tab contents. This does not include the header area. |
| SelectedIndex | The zero-based index of the currently selected tab. |
| TabStripPlacement | Determines where the strip is positioned. This can be Bottom, Left, Right, or Top. |
