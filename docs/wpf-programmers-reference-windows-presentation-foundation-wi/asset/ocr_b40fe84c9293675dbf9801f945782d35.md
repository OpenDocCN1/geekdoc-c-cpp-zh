# PROPERTY ELEMENT SYNTAX

Unfortunately, XAML does not provide type converters for other, complicated properties. For example, it's easy to describe a single-color Brush with a string such as Yellow, LightGreen, or #FF00CC0 (a sort of dark turquoise). But if you want to fill a Grid with the brush shown in Figure 9-2? It would be difficult to represent this complex object as a simple string.

To use more complex objects in XAML code, you need to build the actual objects instead of describing them in a simple string. You can do that with property element syntax.

Property element syntax lets XAML code represent a property as a separate element with its own start and end tags nested inside the object it will use. In example, the Grid that will use the background contains a new element that defines the background.

The property name consists of the control's type (Grid), followed by a dot (.), followed by the property's name (Background); thus, in this case, the element's name is Grid.Background.

Inside this property element, the XAML code defines how the ComplexBrush object displays the background shown in Figure 9-2:

```
<Grid>
  <Grid.Background>
    <GradientBrush>
      <GradientStop Color="#FFFFFF" Offset="0.00//>
      <GradientStop Color="#FFFF00" Offset="0.25//>
      <GradientStop Color="#FFFFFF" Offset="0.50//>
      <GradientStop Color="#FF00FF0" Offset="0.75//>
      <GradientStop Color="#FF0000FF" Offset="1.00//>
    </GradientBrush>
  </Grid.Background>
</Grid>
```

The Grid.Background element is the Grid's background property. It contains a GradientBrush object. That object contains five stops that indicate the colors that the brush should use at various positions. The GradientStop objects' Color and Offset properties are relatively simple values (simple colors) and they are represented as attributes that XAML's type converters can handle.

```
GradientBrush br = new RadialGradientBrush();
br.GradientStops.Add(new GradientStop(Colors.White, 0.00));
br.GradientStops.Add(new GradientStop(Colors.Red, 0.25));
br.GradientStops.Add(new GradientStop(Colors.Yellow, 0.50));
```
