# Better Multimedia Support

DirectX includes routines that play multimedia files efficiently. WPF has taken advantage of some of those routines to make media files quick and easy.

For example, the following XAML snippet makes all of the buttons in a window play the sound file speech_on.wav when clicked:

```
<RoutedTrigger RoutedEvent="ButtonBase.Click">
  <SoundPlayerAction Source="speech_on.wav"/>
</RoutedTrigger>
```

The MediaElement control plays video files almost easily. In the XAML code, you can set the Source property to the file that you want to play. At run, the control provides methods and properties as Play, Pause, Stop, and Position to control the video playback.

Figure 1-6 shows a small application playing three video files simultaneously. The buttons use MediaElement methods and properties to control the video. The program also uses the previous XAML snippet to play a sound whenever you click a button.

# Transformations

DirectX provides methods that make it easy to move, stretch, skew, and rotate graphics. WPF gives you access to those methods so you can easily transform any graphics you draw. In fact, you can also apply those transformations to objects that WPF draws including such as Labels, TextBoxes, and Buttons.

Figure 1-7 shows a program that displays Labels 90 degrees on the left.

You can transform a MediaElement, and it will display video, stretched, skewed, and rotated! Figure 1-8 shows a program displaying three videos in MediaElements that have been rotated, skewed, and stretched, respectively. The three Buttons at the top are also skewed.
