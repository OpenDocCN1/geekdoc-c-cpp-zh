
Next, the code places a Viewbox centered inside the Grid. Recall that a Viewbox's purpose is to stretch its single child in various ways.

If the routine's margin parameter is null, the code should display the window at its normal scale; it sets the Viewbox's Stretch property to None.

If the routine's margin parameter is not null, the code should enlarge the window. It sets the Viewbox's Margin property to the margin parameter the Viewbox expands to fill the Grid except for the margin. It also sets the Viewbox's Stretch property to Uniform so it enlarges its child control as much as possible without changing its aspect ratio (ratio of width to height).

Next, the code makes a VisualBrush that contains an image of the window that it should print.
It makes a Rectangle with the same size as the window, fills the Rectangle with the VisualBrush, and places the Rectangle inside the Viewbox. The Viewbox stretches the Rectangle if appropriate.

Next, the code calls the Grid's Arrange method. The Grid recursively arranges its child and renders them. If you omit this call, the code runs, but the printout is blank.

Finally, the code calls the PrintDialog's PrintVisual method to print the Grid and its contents.
If the user clicks on the dialog's Preferences button and changes the printer's orientation to landscape, the PrintDialog's PrintableAreaWidth and PrintableAreaHeight automatically switch so the controls are arranged properly.

# PRINTING CODE-GENERATED OUTPUT

The PrintDialog object's PrintVisual method is easy to use, and can produce nicely scaled and centered results. It assumes that you are only printing one page at a time, however. If you want to print a longer document, you'll need to call PrintVisual once for each page, and it will produce one print job for each page. This isn't an ideal solution. Frequently there's a better way to produce multiple-page printouts.

The PrintDialog object's PrintDocument method takes a DocumentPaginator object as a parameter.

That object generates the pages of a printout, and the PrintDocument places them in a single print job.

# PRINTING DOCUMENTS

By using the PrintDialog method, you could draw a series of pictures as the PrintShapes program does. You could also print tables across several pages of program or simple blocks of text.

To produce relatively complicated output, however, you would need to write a complicated DocumentPaginator class. For example, suppose you want to print a multi-page newsletter that has paginators flowing around embedded pictures and tables. Building a paginator that could handle these complex layouts would be quite a chore.

However, displaying complex output like this is much easier using the FlowDocument and FixedDocument controls. A FlowDocument arranges its paragraphs, tables, lists, and other contents to make use of the available space. A FixedDocument displays items at specific positions that never change.

The following sections explain how to print FlowDocuments and FixedDocuments.

# Printing FlowDocuments

Instead of building a complicated paginator to produce complex output, you can build a FlowDocument and place paragraphs, tables, lists, and other elements inside it. The FlowDocument automatically arranges its contents to fill the available space.

Unfortunately, the FlowDocument class does not inherit from Visual class, so you cannot simply pass it into the PrintDialog's PrintVisual method. You could pass the Window containing the FlowDocument into PrintVisual, but then the printout would only include whatever is visible on the screen at the time.

Printing a FlowDocument correctly is simple but confusing. The basic idea is to create an XpsDocumentWriter with a print queue. That object's Write method can create a paginator in the print job. To make all work, you just need to figure out how to build a paginator for the FlowDocument.

Fortunately, the FlowDocument class implements the IDocumentaginatorSource interface, and defines a DocumentPaginator property which returns a paginator for the document.

The following code shows how the PrintDocument example program prints its FlowDocument when you open its menu and select Print:

```csharp
// Print the FlowDocument.
private void mnFilePrint_Click(object sender, RoutedEventArgs e)
{
    PrintDialog pd = new PrintDialog();
    if (pd.ShowDialog() == true)
    {
        // Make an Xps document writer for the print queue.
        XpsDocumentWriter xps_writer = 
            PrintQueue.CreateXpsDocumentWriter(pd.PrintQueue);

        // Turn the FlowDocument into an IDocumentaginatorSource.
        IDocumentaginatorSource paginator_source = 
            (IDocumentaginatorSource)fdContents;

        // Use the IDocumentaginatorSource's
        // property to get a paginator.
        xps_writer.Write(paginator_source.DocumentPaginator);
    }
}
```
