# PAGE

A Page object is somewhat similar to a Window object in the sense that it is the top-level container that you use to build its style of application. Unlike a Window, however, a Page must be contained in a navigation host such as a web browser, NavigationWindow, or Frame. Those hosts support for the back/next style navigation to the Page. Your program moves through Page objects, either by code or by using hyperlinks within the Page, and the navigation host takes care of the rest.

Because it as a top-level container for a program, a Page includes namespace and declarations similar to those used by a Window.

In some ways, a Page is also similar to a Border control. Like a Border, it can contain a single child.

If you create a Style with TargetType = Border in the Page's Resources source, that style also modifies the appearance of the Page.

The Border example program shown in Figure 22-1 uses a Style that modifies Border controls display a title, with red bordered rounded corners.

The following code shows how the PageBorder program works:

```
<Page
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
x:Class="PageBorder"
x:Name="PageBorder"
WindowTitle="WindowTitle"
Title="Title"
FlowDirection="LeftToRight"
Width="300" Height="200"
MinWidth="400" WindowHeight="300"
Background="LightBlue">
<Page.Resources>
  <Style TargetType="Border">
    <Setter Property="BorderBrush" Value="Red"/>
    <Setter Property="BorderThickness" Value="10"/>
    <Setter Property="CornerRadius" Value="20"/>
  </Style>
</Page.Resources>
<Label Content="This is a Page"
FontSize="30" FontWeight="Bold" Foreground="Blue"/>
</Page>
```
