# XAML EDITOR

The XAML Editor lets you manually edit the window's XAML code. Usually it's easier to use the Window Designer to place controls on the window and let the designer generate the XAML for you, but there are occasions when you'll need to edit the XAML code directly. The Window Designer can't claim to do everything, and it does a poor job of doing others.
