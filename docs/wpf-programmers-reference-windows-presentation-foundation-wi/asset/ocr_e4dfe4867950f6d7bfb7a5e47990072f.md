Note that the main Window element also specifies the Window's name by a Name or x:Name attribute. The XAML code can use element name to refer to the window that is running the code. It can refer to Window's property that returns the array of Person objects.

# USING LISTBOX AND COMBOBOX TEMPLATES

The previous sections explain how to create items and give each items that bind data to ListBoxes. Binding ComBoxes is similar. See those sections for more information on basic binding.

These controls also use a DataTemplate that determines how the controls display each item.

Create an ItemTemplate element. Inside that, place a DataTemplate element containing the controls that you use to display each data item. Bind the controls to the ListBox's (or ComboBox's) data context.

The following code binds ListBox to the array named People described in the previous section. The DataTemplate makes the control display item in two TextBlocks by a third sandbox.

```
<ListBox ItemsSource={Binding ElementName=TheWindow, Path=ThePeople}>
<ListBox.ItemTemplate>
<DataTemplate>
<StackPanel Orientation="Horizontal">
<TextBlock Text={Binding FirstName} FontWeight="Normal" />
<TextBlock Text="*" />
<TextBlock Text={Binding LastName} FontWeight="Bold" />
</StackPanel>
</DataTemplate>
</ListBox.ItemTemplate>
</ListBox>
```

The code for ComboBox is similar.
