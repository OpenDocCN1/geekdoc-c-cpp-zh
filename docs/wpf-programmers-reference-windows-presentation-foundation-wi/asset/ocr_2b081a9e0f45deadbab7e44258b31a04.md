After the horizontal entries, the main StackPanel holds a Popup control that contains an Image.

The program uses the following code to show and hide its Popup control:

```
// The mouse has entered an image. Display the popup.
private void imgMouseEnter(object sender, MouseEventArgs e)
{
    Image img = (Image)sender;
    imgFullScale.Scale = img.Source;

    popFullScale.PlacementTarget = img;
    popFullScale.IsOpen = true;
}

// The mouse has left an image. Hide the popup.
private void imgMouseLeave(object sender, MouseEventArgs e)
{
    popFullScale.IsOpen = false;
}
```

When the mouse enters an Image control, the img_MouseEnter event handler finds which Image raised the event. It sets the Popup's Image control to display the same image as the small preview control but at full scale. It sets the Popup's PlacementTarget to the control that raised the event and sets IsOpen to True.

When the mouse leaves an image, the img_MouseLeave event handler simply sets the Popup's IsOpen property to False.

The following table describes the values that the Placement property can take:

| VALUE | POSITION RELATIVE TO |
| --- | --- |
| Absolute | Upper-left of the screen. If the popup won't fit, it is moved to the edge of the screen. |
| Relative | Upper-left corner of PlacementTarget |
| Bottom | Lower edge of PlacementTarget |
| Center | Center of PlacementTarget |
| Right | Right edge of PlacementTarget |
| AbsolutePoint | Upper-left of the screen. If the popup won't fit, it is extended from an axis defined by HorizontalOffset or VerticalOffset. |
| RelativePoint | Upper-left corner of PlacementTarget. If the popup won't fit, it is extended by an axis defined by HorizontalOffset or VerticalOffset. |
| Mouse | The mouse's position |
