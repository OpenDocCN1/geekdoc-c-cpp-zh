# MediaElement

The MediaElement control plays an audio or video file. At design time, the control's most important property is Source, which gives the name of the file to play.

By default, the MediaControl loads, it begins playing its media. Unless you want it to play some sort of startup or video, which is probably not what you want. Instead, you probably want the program to control the media.

To let the program control the media, set the control's LoadedBehavior property to Manual. That prevents the control from playing when it loads and lets the program take charge.

Next, write code to control the methods of the media.

The following XAML defines two MediaElement controls, one that plays a .wmv video file and one that plays a wav file. Notice that LoadBehavior is to Manual.

```
<MediaElement x:Name="Julia" Source="EvolvingJulia.wmv"
LoadedBehavior="Manual"
Margin="283.5,24.0,0" HorizontalAlignment="Left"
VerticalAlignment="Top" Height="88" />
```

```
<MediaElement x:Name="audio" Source="Windows XP Startup.wav"
LoadedBehavior="Manual"
Margin="0.116,106.444.28" HorizontalAlignment="Right"
Width="114" />
```

# STRANGE SIZES

While working on one program, I shrank an Image control's Stretch property to None, and the (fairly large) picture shrunk to postage-stamp size. I reassigned the picture and got the same result. I opened the file in Microsoft Paint, and it was at its normal size, but when I opened it in an Image control, it was tiny.

It turned out that I had taken that picture with a digital camera. The imaging software that came with expected me to print the image on a printer so it set the image's resolution to 480 dpi (dots per inch), which is much higher than the resolution of the screen. The Image control was smart enough (or stupid enough, depending on how you look at it) to realize that the image was intended to display more pixels per inch, so it resized the image accordingly.

I solved the problem by opening the file in Microsoft Paint, selecting all of the pixels, copying and pasting them into a new image. Fancier image processing applications as Paint Shop Pro can also set an image's dpi settings.
