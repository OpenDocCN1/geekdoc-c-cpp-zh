# PERFECT PADDING

Some controls such as Border, Button, and TextBox provide a Padding property. This property has a syntax similar to that of Margin, but it specifies padding to add inside the control around its contents. For example, setting Padding = "10" adds 10 pixels of extra space around the text inside a TextBox.

Other properties that influence a control's size are MaxWidth, MaxHeight, MinWidth, and MinHeight. As you can guess from their names, they determine how big and how small a control can be when the content is resized and its properties make it resize too.

The MaxMinSizes example program shown in Figure 4-4 displays two rectangles with rounded corners. Labels show the MinHeight and MaxHeight values.

The first rectangle's Height is set to 75, so it always has that height.

The second rectangle's MaxHeight value is set to 100. The window is big enough for the rectangle to be taller than this, but its Max:Height value limits it.

The third rectangle's MinHeight value is 150. That's too tall to fit completely in the window, so this rectangle is clipped.

The final rectangle does not have any MinHeight or MaxHeight values, so it grows and shrinks to fit its part of the window.

You might take a few minutes to download the MaxMinSizes example program from the book's site and run it to see what happens to the rectangles when you change the window's size at run time.

# FONT

It makes sense that displaying controls like Label and TextBox would provide properties that let you determine the text's appearance. It's less obvious that some controls that don't display text provide the same properties.

For example, the Menu, ListBox, and Window classes provide these properties even when they don't directly display text. These objects generally contain controls that display text. (Menus-generally contain MenuItems, ListBoxes generally contain ListBoxItems, and Windows can contain anything.) These Font properties allow the controls they contain inherit their values, making it easier to give all of those controls the same fonts.

The following summarizes the most useful font properties:

+   * FontFamily — Determines the text's font face. Some common values like Segoe (pronounced see-go), this is Microsoft's preferred font for Windows Vista, Times New Roman, Courier New, Arial. Its also Comic Sans MS for many of the figures in this book.
