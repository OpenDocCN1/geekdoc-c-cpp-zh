RectanglesAndBoxes

The code starts by checking whether its MeshGeometry3d group is missing. If so, then the routine makes a new one. Allowing you to pass an existing mesh into the routine lets the same mesh for MakeRectangle or any of the other object creation routines. (Remember that any mesh contains many triangles is more efficient than many meshes containing one triangle each, so it's better to use the same mesh if the objects can use all material.)

Next, the code adds the rectangle's corner points to the mesh and sets their texture coordinates. Finally, the code adds the two triangles needed to build the rectangle.

The other object-building routines used by the RectanglesAndBoxes program follow the same basic approach: Create a mesh if, create points and set texture coordinates, and create triangles. The big differences are in how the code generates the points and sets its texture coordinates.

Unfortunately, some of these routines are fairly long and complicated (drawing a sphere and mapping a texture onto it takes some work), so they are not shown here. Download the example from the book's web page to see the details.
