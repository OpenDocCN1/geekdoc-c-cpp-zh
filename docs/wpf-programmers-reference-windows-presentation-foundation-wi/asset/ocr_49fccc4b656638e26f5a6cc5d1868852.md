Creating complex data structures like one in code-bind is common, but it is not the only approach. One alternative is to build the objects in XAML code.

To do this, by using a namespace declaration similar to how one defines your project's namespace in XAML. This statement means that you can use the prefix local to refer to classes in your code-bind.

```
xmlns:local=clr-namespace:OrgChartTreeView
```

Now the XAML code can use the code-bind classes as data types to define the data you need. For example, the OrgChart example demonstrates this approach. For example, the XAML code shows a Manager object:

<Manager FirstName="Mindy" LastName="Most" Extension="0001"

</Manager>
