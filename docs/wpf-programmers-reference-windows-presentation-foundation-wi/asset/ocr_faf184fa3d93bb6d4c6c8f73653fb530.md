In some ways, UniformGrid acts like a WrapPanel. Both arrange their children in a row until they run out of room, and then they begin a new row. However, there are two big differences between the controls.

First, the WrapPanel gives each item in a row the same height, but the items in different rows may have different widths so they don't necessarily line up in columns. In contrast, the UniformGrid gives every item the same size the area relatively vertically and horizontally.

Second, the WrapPanel has an Orientation property that determines how it arranges its children in rows or columns. The UniformGrid always arranges its children in row-first order.

Figure 6-3 shows the UseUniformGrid example displaying three rows and four columns. The buttons stretch to fit their cells, all have the same size, but the control would work just well as if all children had different sizes.

The following XAML code fragment shows the key pieces of the UseUniformGrid program. I omitted the UniformGrid's background definition to save space:

```
<UniformGrid Columns="4" Rows="3">
-UniformGrid.Background=""
<!-- Omitted to save space -->
<Button Content="Button 1" Margin="5"/>

<Button Content="Button 4" Margin="5"/>
<Button Content="Button 5" Margin="5"/>
<Button Content="Button 6" Margin="5"/>
<Button Content="Button 7" Margin="5"/>
```

# VIEWBOX

The Viewbox control controls its contents in various ways. That not only lets you stretch images (the Image control can do that by itself anyway), but it also lets you stretch other controls.

The Viewbox can contain only a single child, but that can be a container such as a Grid or StackPanel, so you can put anything you want in the child.
