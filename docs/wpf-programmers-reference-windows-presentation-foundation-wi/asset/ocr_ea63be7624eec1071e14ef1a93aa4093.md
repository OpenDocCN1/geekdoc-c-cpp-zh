# Polyline

The Polyline object draws lines that connect a series of points. Unlike the Polygon object, it does not finish by connecting the first point to the last point.

In fact, even if you repeat the point at the end so the Polyline finishes at the first point, you don't exactly get the same result as you would get from the Polygon object.

A Polygon considers the join between the last and first lines as a corner in the shape. In contrast, the Polyline considers the first and last lines as separate lines, even if they happen to end at the same point.

The PolygonPolylineDifference example program in Figure 8-6 draws a Polygon and a Polyline that connects the same points. The first and last lines are the same for the Polyline, so it closes the shape.

![](bbox=[0.703, 0.296, 0.927, 0.413])

If you look at Figure 8-6, you will see that the top point on the left triangle (drawn with Polygon) isn't quite the same as the top point on the right triangle (drawn with Polyline). The Polyline treats this join as a corner, so it gets a nice point. The Polyline treats this as the first and last line segments happen to, so it draws to their ends.

The following XAML code shows how the PolylinePolylineDifference program draws its Polygon and Polyline:

```
<StackPanel Orientation="Horizontal">
  <Polygon Margin="15,5,0,0"
           HorizontalAlignment="Center" VerticalAlignment="Top"
           Fill="Yellow" Stroke="Black" StrokeThickness="10"
           Points="50,100 100,100 100,100"/>
  <Label HorizontalAlignment="Center" Content="Polygon"/>
</StackPanel>
<StackPanel>
  <Polyline Margin="25,5,0,0"
           HorizontalAlignment="Center" VerticalAlignment="Top"
           Fill="Yellow" Stroke="Black" StrokeThickness="10"
           Points="50,100 100,100 150,100"/>
  <Label HorizontalAlignment="Center" Content="Polyline"/>
</StackPanel>
```

# RECTANGLE

The Rectangle control draws a simple rectangle that cannot contain any children. The control's location and position are much like those of an Ellipse. The Rectangle's size is determined by its Width and Height properties, and its location is determined by its container and its Margin, HorizontalAlignment, and VerticalAlignment properties.
