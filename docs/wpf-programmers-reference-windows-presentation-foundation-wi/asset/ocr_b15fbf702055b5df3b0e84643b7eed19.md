# ANOTHER EXAMPLE

The DockPanelView example program uses a Style with TargetType = Label to make Labels contained in a DockPanel display their DockPanel.Dock attached property values.

+   - If a value provides an index, include the index in square brackets. For instance, the ColumnWidths example described earlier in this chapter uses paths of the form ColumnDefinitions[2].Width to describe a Grid of column widths.

+   - If the binding's source is a collection, you can refer to the collector' current item with the slash (/).

The ColorList example program shown in Figure 18-7 demonstrates bindings with Source = /, the List on the left, the Label on the right displays the name of the color selected and its Background to match.

The ColorList program uses the following code to define its List and Label:

```
<Grid Margin="10">
<Grid.DataContext>
<x:Array Type="sys:String">
<sys:String>Red</sys:String>
<sys:String>Yellow</sys:String>
<sys:String>Lime</sys:String>
<sys:String>Cyan</sys:String>
<sys:String>Blue</sys:String>
<sys:String>Magenta</sys:String>
</x:Array>
</Grid.DataContext>
<Grid.ColumnDefinitions>
<ColumnDefinition Width="*/>
<ColumnDefinition Width="*/>
</Grid.ColumnDefinitions>
```

```
<ListBox Name="colorList" Grid.Column="0" Background="Transparent"
IsSynchronizedWithCurrentItem="True"
ItemsSource="Binding Path" />
```

```
<Label Grid.Column="1" BorderBrush="Black" BorderThickness="1"
HorizontalAlignment="Center" VerticalAlignment="Center"
Content="Binding Path/" />
</Grid>
```
