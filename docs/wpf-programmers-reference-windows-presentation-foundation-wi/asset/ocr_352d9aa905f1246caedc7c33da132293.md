# TextBlock

The TextBlock displays read-only text such as a Label does but with greater flexibility. The TextBlock has additional features that let you:

+   - Change some text's appearance inline by making it bold, italic, or underlined.
- Add line breaks.
- Change line spacing.
- Expand or condense the text.
- Truncate text with an ellipsis.
- Apply text decorations as strikethrough, baseline, underline, and outline.
- Use superscripts and subscripts*

The following table summarizes some of the more useful properties that the TextBlock class provides.

| PROPERTY | PURPOSE |
|---|---|
| LineHeight | Determines the spacing between lines. |
| LineStackingStrategy | Can be BlockLineHeight (line height is determined by Line) or maxHeight (each line's height is set to fit its contents) |
| TextTrimming | Determines how the TextBlock handles words that don't fit. Can be None (words are truncated), WordEllipse (text is broken at a word boundary and replaced with an ellipsis), or CharacterEllipse (text is broken at a character boundary and replaced with an ellipsis). See Figure 5-11. |
| TextWrapping | Determines how text is wrapped at the end of the TextBox. Can be No, Wrap, or WrapOverflow. If the text contains a long word and the character cannot figure out how to break the text into lines, WrapWithOverflow may make part of the word string extend beyond the edge of the TextBlock (and get chopped off), whereas Wrap will break the word and continue on the next line. |

Each row in Figure 5-11 demonstrates a different TextTrimming value. The Text on the right contain the text CProgramFiles\CoolApplications and have their Wrapping properties set to Wrap. When TextTrimming is CharacterEllipse, the control ends at the last character that can fit and finishes with an ellipsis. When TextTrimming is WordEllipse, the control ends at the last break that can and finishes with an ellipsis. When TextTrimming is None, the control simply truncates the text.
