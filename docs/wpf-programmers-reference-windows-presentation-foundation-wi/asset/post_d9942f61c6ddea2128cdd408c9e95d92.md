
# PROPERTIES WINDOW

The Properties Window lets you view and modify the properties that determine the appearance and behavior of a window's controls. Figure 3-4 shows the Properties for the Rectangle rectContent.

This window groups the controls' properties into categories that vary largely depending on the type of control selected. The following lists the categories shown in Figure 3-4:

- Brushes — Sets the control's fill and outline colors.
- Appearance — Sets the control's opacity, visibility (visible or hidden), and some aspects of geometry (the radius of the angle's curves in this example). Advanced properties set style and bitmap effects.
- Layout — Sets the control's width, height, and alignment. If the control is inside a Grid, it shows the row and column.
- Common Properties — Sets properties that are common to many controls such as Cursor, IsEnabled, and Tooltip.
- Transform — Sets transformations that can move, scale, rotate, and skew the control.
- Miscellaneous — Holds advanced properties such as ContextMenu that doesn't fit anywhere else.

Another common category, Text, is used by controls that contain text to specify font properties.

Click on the right-pointing triangle (▷) next to a category. In Figure 3-4, the Layout, Common Properties, Transform, and Miscellaneous categories are collapsed to show them this.

Click on the downward-pointing triangle (▽) next to a category to collapse it. In Figure 3-4, the Brushes and Appearance categories are expanded to show them this.

Note that some categories have advanced properties that are hidden by default. In Figure 3-4, the Appearance category has advanced properties that are hidden. Click with a dot in it (⊞) at the bottom of the category to see the downward pointing arrow to see the advanced properties.

Unfortunately these categories and their sections are fairly confusing. If you are a beginner and sort of know what you want to do but don't really know what property to look for, the sections can help. For example, if you want to change a grid's fill color but don't know the name of the property that does, you can look in the Brushes and Appearance categories until you figure out that the property is Background.

# Properties Window

However, if you know that you want to change a control's MinWidth to 100, you may need to wander around until you discover that MinWidth is in the advanced properties of the Layout category.

To make finding properties easier, the Properties window provides a search box over the property categories. In Figure 3-4, it contains italicized text Search. Click in this box, enter the name of the property you want (or part of it), and the Properties window will display the matching properties.

The following sections say a bit about making and editing brushes and using property resources.

# Brushes

In WPF, a brush defines how an object is filled. WPF also uses brushes to "fill" items that seem thin to fill such as the lines that make up a polygon or the edges of a rectangle.

Figure 3-5 shows a rectangle that is filled with a pale yellow brush. Its Stroke, which is used to draw its edges, is a gradient brush that shades from yellow at the top to orange at the bottom. The star-shaped Polygon has no fill color (the Rectangle shows through), and its Stroke is a gradient brush that shades from blue to white.

# Making Brushes

To make a brush, select the object it should use on the Window Designer. In the Properties window, expand the Brush categories. Figure 3-6 shows the Brush properties for the rectangle shape in Figure 3-5.

The bars across the top of the Brush area show the different kinds of brushes the control can use. For the Rectangle in Figure 3-5, this Fill (the Brush used to fill the Rectangle), Stroke (the Brush used to draw the Rectangle's outline), and OpacityMask (the Brush used to determine how opaque or transparent the Rectangle is at different points).

Click on one of these bars to select the brush that you want to modify. In Figure 3-6, the brush is selected.

Now you use the Brush definition area below to define the brush. The small images across the top of this area are tabs that select different styles of brushes. The following list summarizes these tabs in left-to-right order:

- No Brush — The control is not filled so whatever lies below shows through.
- Solid Brush — The control is filled with a single solid color. (The rectangle in Figure 3-5 is filled with this type of brush.)

![](img/c9b2d394f4fc2f7e276f6a0a6fa9c2f6_80_1.png)

- Gradient Brush — The control is filled with a gradient brush that shades between colors. The following sections say more about gradient brushes.
- Tile Brush — The control is filled with a repeating image. The section “Tile Brushes” later in this chapter says more about tile brushes.
- Brush Resources — This tab lists predefined brush resources. They include system-brush colors such as ControlBrushKey and HighlightBrushKey, in addition to any brush resources.

# Gradient Brushes

A gradient brush fills an area with colors smoothly. To create a brush, select the gradient type you want from the Brush area. The following sections say more about gradient brushes.

A gradient brush is a brush that shades from one color to another. There are several types of gradient brushes:

- Linear Gradient Brush — This brush shades along a line.
- Radial Gradient Brush — This brush shades from a central point outward.
- Angular Gradient Brush — This brush shades around a central point.
- Path Gradient Brush — This brush shades along a defined path.

Depending on the type of gradient brush, you can use different color stops. For example, a linear gradient brush can shade from one color to another or across multiple colors, as shown in Figure 3-7.

# Transformed Gradient Brushes

More advanced options let you change the appearance of gradient brushes. Particularly useful tool is the Transform tool. This tool looks like an arrow in the Toolbox and is shown in Figure 3-9.

If you select this tool and click on a control that uses a brush, the Window Designer displays an arrow that lets you change its geometry.
