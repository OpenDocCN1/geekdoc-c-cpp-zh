FlowDocument

A FlowDocument can contain:
* Paragraph Contains elements grouped in a paragraph.
* List An ordered or bulleted list of items.
* Section A high-level section group.
* Table of rows and columns.

You can use Figures and Floaters to contain content around which text should flow.

Figures | Floaters
Can be positioned explicitly. | Cannot be positioned explicitly. It floats to a spot.
You can size it to fit more than one page or columns. | Sizes to fit one column.
Does content doesn't fit on the page, the figure is clipped. | Paginates. If its content won't fit, it continues on the next column or page.
