# TOOLTIP

As you can probably guess, the ToolTip displays a tooltip (see Figure B-13). Usually it's easier to simply set the control's ToolTip property than it is to create a ToolTip object. One in which you might want to make the ToolTip a separate object is if you want to change its properties.

# CONSISTENT TIPS

If you change the ToolTip's properties, you will make it look different from other applications' tooltips. While that will make your program less consistent with the rest of the system, it won't distract the user too much as long as you don't go overboard (e.g., by displaying tooltips in a 60-point font).

# TABLE B-13:

| PROPERTY | PURPOSE |
| --- | --- |
| Background | The color used to fill the control's interior |
| Foreground | The color used to draw the text |
| BorderBrush | The color of the control's edge |
| BorderThickness | The control's thickness |
| FontFamily | The name of the font family as Times New Roman, Arial, or Segoe |
| FontSize | The text's size. Append cm, in, px, or pt to specify centimeters, inches, pixels (the defaults), or points (1/72 inch) as "0.25in" or "12pt" |
| FontStyle | Can be Normal, *Italic*, or *Oblique* (simulates italic for fonts without an italic style) |
| FontWeight | The text's boldness. This can be *Thin*, *ExtraLight*, *Light*, *Normal*, *Medium*, *SemiBold*, *Bold*, *ExtraBold*, *Black*, and *ExtraBlack*, although many fonts look for the many of these values. |

# EXAMPLE Using ToolTips

The following code creates two ToolTips. The first uses element syntax to define a ToolTip and sets all of its property values. The second uses the simpler ToolTip property syntax and uses default property values.

```
<Button Content="New">
  <ToolTip>
    <ToolTip Content="Make a new file"
      Background="Yellow" Foregrounds="Red" BorderBrush="Blue" BorderThickness="5"
      FontWeight="Bold" FontSize="16" StyleStyle="Italic"/>
  </ToolTip>
</Button>
```

# TREEVIEW

The TreeView displays hierarchical data in a tree-like format similar to the one used by Windows Explorer to show directory structure. It should contain TreeButtonItem objects that represent the entries.

See Chapter 18 for information on binding TreeView controls to data sources. Key properties of TreeView are given in table B-14.

# TABLE B-14:

| PROPERTY | PURPOSE |
| --- | --- |
| Background | The color used to fill the control's interior |
| BorderBrush | The color of the control's edge |
| BorderThickness | The control edge's thickness |
| FontFamily | The name of the font family as in Times New Roman, Arial, and Segoe |
| FontSize | The text's font size. Append cm, in px, or pt to specify centimeters, inches, pixels (the default), or points (1/7 inch) as "0.25in" or "12pt." |
| FontStyle | Can be Normal, Italic, or Oblique (simulates italic for fonts without any italic style) |
| FontWeight | The text's boldness. It can be Thin, ExtraLight, Light, Normal, Medium, SemiBold, ExtraBold, and ExtraBlack, although many fonts look like same for many of these values |
| Padding | The extra space added between the control's edges and its contents |

The TreeButtonItem provides the same key properties as the TreeView control.

> ITEM INHERITANCE
Note that a TreeItem's subitems inherit font properties. For example, if you make an item bold, then all of its descendants in the tree are also bold.

EXAMPLE Using TreeView
The following code builds a TreeView listing the Major League Baseball teams. The two topmost nodes for the American League and National League use property element syntax to display baseball teams in addition to text. The division and team items display only text.         <Label Content="American League" VerticalAlignment="Center"/>
```
      </StackPanel>
    </TreeWidgetItem.Header>
    <TreeWidgetItem Header="East" IsExpanded="True">
      <TreeWidgetItem Header="Baltimore Orioles" />
      <TreeWidgetItem Header="Boston red Sox" />
      <TreeWidgetItem Header="New York Yankees" />
    </TreeWidgetItem>
</TreeView>
```
