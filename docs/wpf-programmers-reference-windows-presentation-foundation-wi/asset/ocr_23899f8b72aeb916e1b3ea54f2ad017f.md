Use the Toolbox (described shortly) to select a control type. Then click and draw on the Window Designer to place the control on it. Alternatively, you can double-click a tool in the Toolbox to place the control on the window at a default size and location.

After you place a control on the Designer, you can click on it and drag it into a new position. If you create or drag a control on top of a container control such as StackPanel, or Frame, the control will be placed inside the container.

# CONTENT INTENT

Be careful when you position controls on the window. It's easy to accidentally drag a control inside a container.

In doubt, look at the XAML code to see which control contains other controls. You can also use the XAML Editor to move controls into other containers if you have trouble dragging them where you want them to be.

When you select a control, the Designer highlights it as shown in Figure 2-3.

In Figure 2-3 the upper left, top, and right edges are attached to the edges of its container. This indicates that the control's corresponding edges will remain a fixed distance from the container's edges, which means if the container is made wider, then the button grows wider, too.

![](bbox=[0.618, 0.471, 0.863, 0.63])

The following code shows the XAML generated by the Window Designer for the top button. The Margin attribute sets the distance between the control's and the left edge, top, and right edges. The VerticalAlignment="Top" keeps the button's bottom edge attachment to the container.

```
<Button Height="23" Margin="46,30,157,0" Name="button1" VerticalAlignment="Top"/>
```

If you hover over the attachment of the arrow or over any unattached side, the cursor changes to a pointing hand, as shown in Figure 2-3. If you click while a control is displayed, the control toggles whether the edge is attached to its container's edges. This is an easy way to turn edge attachment on and off.
