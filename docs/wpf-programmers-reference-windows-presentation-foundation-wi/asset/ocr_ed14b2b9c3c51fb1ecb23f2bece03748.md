Visual Basic supports Relaxed Delegates. These let replace the data types of a routine's parameters with other data types that are consistent with whatever is actually passed to the routine. That lets you make an event handler's parameters either more or less specific than those that Visual Studio creates by default, and can sometimes simplify the code.

For example, consider the empty Button Click event handler generated by Visual Basic:

```
Private Sub btnApplyClick(ByVal sender As System.Object, _\nByVal e As System.Windows.RoutedEventArgs)

End Sub
```

Now suppose that this event handler is only attached to Button Click events. Then you know that the sender parameter always be a Button, so you can change its data type to Button in the event handler's declaration.

Meanwhile, you may not use the parameter e. That parameter contains information about the event such as a RoutedEventArgs object representing the event, and a Handled flag that you can set to True from further processing. Even handlers have no need for this information. In that case, you can change the parameter's data type to the general and simple Object instead of the more cumbersome System.Windows.RoutedEventArgs.

The following code shows the modified event handler. The new line of code in the event handler displays the Button's content converted into a string. If the Button displays a simple caption, the code displays the caption.

```
Private Sub btnApplyClick(ByVal sender As Button, _\nByVal e As Object)
MessageBox.Show(sender.Content.ToString())
End Sub
```

When sender is declared as a System.Object, there's not a lot you can do with it. To access its properties, you need to convert it to a Control, Button, or some other more specific class.

Declaring the sender parameter to be of type Button allows the code to convert that conversion and treat it as a Button right away. In this case it means you can look at the control's Content property.

Relaxed Delegates also allow you to omit the parameter list entirely if you don't need to use the parameters. The following code shows the simplest form of the btnApply_Click event handler:

```
Private Sub btnApply_Click()\n\nEnd Sub
```
