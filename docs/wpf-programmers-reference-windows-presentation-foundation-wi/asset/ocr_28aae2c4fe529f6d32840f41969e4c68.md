The TextBoxToLabel example program in Figure 18-1 demonstrates this concept of simple binding. When you type in the text, the two labels enable whatever you type.

The following XAML code shows how the program works:

```
<StackPanel Margin="5">
  <TextBox Name="txtType" Margin="5" Height="30" VerticalAlignment="Top" Type="here!"/>
  <Label Margin="5" Brush="Yellow" BorderThickness="1">
    <Binding ElementName="txtType" Path="Text"/>
  </Label>
  <Label Margin="5" Brush="Yellow" BorderThickness="1">
    <Content><Binding ElementName="txtType" Path="Text"></Content>
  </Label>
</StackPanel>
```

The code defines a TextBox named txtTypeHere.

Next, the code defines a Label. Its start and end tag enclose its content, in this case, a Binding object. The object's ElementName property defines the control — the TextBox. Its Path property defines the location of the data in the source control — the Text property.

In this binding, the four keys are:

+   - Target — The Label that contains the binding

+   - Target Property — The Content property that is equal to the binding

+   - Source — Given by the ElementName attribute

+   - Path — The name of the source control's property

Finally, the code defines a second Label that uses a binding similar to the first one, except time it defines the binding with the strangely string (Binding ElementName=txtTypeHere, Path=Text).

The following sections describe the four pieces of binding in greater detail and explain how to set their values.
