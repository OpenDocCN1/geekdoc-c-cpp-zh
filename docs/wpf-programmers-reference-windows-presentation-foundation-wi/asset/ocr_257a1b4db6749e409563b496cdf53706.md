The code starts with a hack to save any edit that is in progress.

Suppose you are typing a new Street in your TextBox when you invoke the Data menu’s “Save Changes” command. At that point WPF has not yet notified the DataSet of your edit in progress, so that change isn't saved into the database. To force WPF to make notification, the program saves a reference to the control that currently has focus, moves focus that control, and moves it back.

Next, the code creates a command builder to generate any changes that the data adapter might need to update the database. Finally, the code calls the data adapter Update method to save the changes.

It’s for the code-behind. The rest of the program is in XAML code. Naturally, the most interesting pieces are the bindings.

# Binding the Student Name ListBox

The following code shows how the program binds the student name ListBox on the left in Figure 18-14 to the Students data:

```
<ListBox Grid.Row="0" Grid.Column="0" Margin="10" Name="Students"
  IsSynchronizedWithItem="True"
  DataContext={Binding Tables[Students]}"
  ItemsSource={Binding Binding}"
  <ItemTemplate>
    <Grid>
      <StackPanel Orientation="Horizontal" Margin="3,0,3,0">
        <TextBlock Text="Binding Path=FirstName}" />
        <TextBlock Text=" /" />
        <TextBlock Text="Binding Path=LastName}" />
      </StackPanel>
    </Grid>
  </ItemTemplate>
</ListBox>
```

The code sets the control’s DataContext attribute to the Entries named Students. Remember that at this point the window’s DataContext property points to the DataSet. The DataSet has a Tables property that contains references to the DataTable objects contains. The syntax Tables[Students] shows here a reference to the DataTable named Students.

> WHAT’S IN A NAME?

The name Students used here is the name of the DataSet, not the name of the table in the database. To make things easier to understand, database code typically gives a DataTable the same name as the table it represents, but that’s not required. The DataTables are set in the calls to the data adapters Fill methods.
