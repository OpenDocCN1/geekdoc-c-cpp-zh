You can include a unit indicator after a number to use a unit other than pixels. The following table lists the unit indicators that you can use:

| INDICATOR | MEANING | EQUIVALENT |
|---|---|---|
| px | pixels | 1 pixel |
| in | inches | 96 pixels |
| cm | centimeters | 96/2.54 * 37 pixels |
| pt | points | 1/72 inch |

To use a proportional width or height, assign the property a number followed by an asterisk (*). (The value * is equivalent to 1*) The Grid calculates the amount of space it has that is not used by absolute values and divides it among the rows or columns with proportional sizing, weighting them according their numeric values.

For example, the following XAML code defines a grid with three columns and two rows.

```
<Grid Margin="5">
  <Grid.ColumnDefinitions>
    <ColumnDefinition Width="0.75 in" />
    <ColumnDefinition Width="2*" />
    <ColumnDefinition Width="1*" />
  </Grid.ColumnDefinitions>
  <Grid.RowDefinitions>
    <RowDefinition Height="*30" />
    <RowDefinition Height="*2" />
  </Grid.RowDefinitions>
</Grid>
```

The first column has a width of 0.75 in = 72 pixels, so it takes up the leftmost 72 pixels in the Grid. The second and third columns' are set to 2* and 1*, so the second column is twice as wide as the last. In other words, the second column gets 2/(2+1) = 2/3 of the remaining width in the Grid, and the last column gets 1/(2+1) = 1/3 of the remaining width.

The first row has a height of 30 pixels. The second row has height set to *, so it gets all of the remaining height in the Grid.

By convention, developers set proportional values so that they add up to 100 or 1. That lets you think of these as percentages of the remaining space. For example, in the following XAML code, the first two columns each use 25 percent of the Grid's width and the third column uses the remaining 50 percent of the Grid's width.

```
<Grid Margin="5">
  <Grid.ColumnDefinitions>
    <ColumnDefinition Width="25*" />
    <ColumnDefinition Width="25*" />
    <ColumnDefinition Width="50*" />
  </Grid.ColumnDefinitions>
</Grid> **
```
