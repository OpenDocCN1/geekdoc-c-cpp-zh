Finally, you can make a WPF application display an XPS file inside a DocumentViewer control. To do that, first add a reference to the ReachFramework library.

In Expression Blend, use the Project menu and select "Add Reference." Browse to the ReachFramework DLL (on your system, it is@\Program Files\Reach Assemblies\Microsoft\Frameworkw3.0\ReachFramework.dll) and click OK.

In Visual Studio, open the Project and select "Add Reference." on the Add Reference dialog, select the .NET tab, check the ReachFramework, and click OK.

Now you can code-behind to load an XPS document into a DocumentViewer control. To make using the necessary classes easier, you can add the following statement to the program:

```
using System.Windows.Xps.Packaging;
```

The following code loads file "Fixed Document.xps" when your program's window loads:

```
// Load the XPS document.
private void WindowLoaded(object sender, EventArgs e)
n    // Note: Mark the file as "Copy if newer"
    // to make a copy to the output directory.
    XpsDocument xps_doc = new XpsDocument("Fixed Document.xps",
    System.IO.FileAccess.Read);
    docViewer.Document = xps_doc.GetFixedDocumentSequence();
```
