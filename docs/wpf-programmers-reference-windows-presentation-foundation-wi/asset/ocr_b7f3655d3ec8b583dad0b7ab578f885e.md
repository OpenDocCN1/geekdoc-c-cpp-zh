# STATUSBAR

The StatusBar control creates an area at the bottom of the window where you can display status information to the user. Ideally, a StatusBar should contain relatively simple read-only information as labels, icons, and progress bars, although some buttons, combo boxes, menus, and all sorts of other content in them.

Figure 6-8 shows the UseStatusBar displaying a StatusBar. In the code-behind updates the status icon, progress, and color.

A StatusBar should contain StatusBarItem objects to hold the status items. StatusBarItem can contain only a single child, but that can be a container such as a Grid or StackPanel, so you can display just anything you like.
