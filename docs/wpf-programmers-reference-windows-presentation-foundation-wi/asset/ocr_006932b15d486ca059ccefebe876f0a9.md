# Pens

This appendix summarizes Pens. A Pen defines the colors and geometry of linear features such as lines, paths, and the edges of drawn shapes like Rectangles.

Typically Pen properties are provided by some other object than the Pen itself and determine how the object defines its border. The following draws an ellipse with a StrokeThickness properties

For example, the Ellipse control's Stroke and StrokeThickness determine how the control draws its border. The following code draws an ellipse with a red border that's 10 pixels wide:

```
<Ellipse Width="200" Height="100" Stroke="Red" StrokeThickness="10">
```

Table F-1 summarizes Pen's properties.

**Table F-1**: Key Properties of Pen

| PROPERTY | PURPOSE |
| --- | --- |
| Stroke | Determines the Pen's Brush. This can be a solid color red or an element attribute that specifies a more complicated brush such as LinearGradientBrush. |
| StrokeDashArray | Determines the Pen's pattern of draw and skipped segments in units of the pen thickness. For example, the pattern 3,1 means "draw three pens, skip one pen width, and repeat.". |
| StrokeDashCap | Determines the shape of ends of each dash. This can be Flat, Round, Square, or Triangle. |
| StrokeDashOffset | Determines how far into the first dash the line starts. |
| StrokeEndLineCap | Determines the shape of the Pen's ending finish. This can be Flat, Round, Square, or Triangle. |
| StrokeLineJoin | Determines how the Pen draws corners. This can be Bevel, Miter, or Round. |
