# CHAPTER 3 EXPRESSION BLEND

Figure 3-28 shows the Objects and Timeline area while it is editing the storyboard named SpinButton.

To edit a storyboard, drag the timeline indicator to a time. In Figure 3-28, the indicator is set at 0.5 second. Now change the controls of the properties that you want to animate. Expression Blend creates a storyboard that sets those properties to the desired values at the selected time.

You can use the video-control buttons at the top of the timeline area to test the animation. For example, click the Play button (►) to run the animation.

# SUSPEND TIME

While you are editing a storyboard, the Window Designer is outlined in red and displays a label at the top that says “Timeline recording is on.” Click the red dot beside this label to turn recording off. Then you can modify control properties without the changes becoming part of the storyboard.

Figure 3-28 shows the timeline for the SpinButton storyboard in the Spinning example program. The storyboard sets a button's angle of rotation to 0 degrees at 0 seconds and sets the angle of rotation to 359, 90 degrees at 0.5 second. This makes the button rotate through one complete revolution in a half second.

# TRIGGERS

After you design a storyboard, you can determine which events trigger it. Expression Blend hooks the storyboard to the window's Loaded event so the storyboard events execute when the program starts.

You can change this behavior by using the Triggers area in Figure 3-29.

Click on the doorway next to the right of the word “When” and select the control that should trigger the storyboard. In Figure 3-29, this is set to the Button named btnSpinMe.

# CONTROL CONFUSION

The control dropdown only lists the control that is currently attached to the storyboard and the control that is currently selected in the Objects and Timeline area. The dropdown doesn't show the control that you want, be sure it is selected in the Objects and Timeline area.
