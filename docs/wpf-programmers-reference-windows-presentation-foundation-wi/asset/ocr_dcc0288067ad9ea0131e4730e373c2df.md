```
      </Button>
      <Button ToolBar.OverflowMode="Never">
        <Image Source="search_reference.ico" Height="24" Width="24" />
      </Button>
      <Button ToolBar.OverflowMode="Never">
        <Image Source="search4doc.ico" Height="24" Width="24" />
      </Button>
      <!-- Other Buttons omitted -->
    </ToolBar>
  <ToolBar Band="1" BandIndex="1">-- Search -->
  <!-- Other ToolBars omitted -->
</ToolBarTray>
```

The ToolBar control has one property worth mentioning here: Orientation. You can set this property to Horizontal or Vertical to determine whether the tray arranges its ToolBars vertically or horizontally.
