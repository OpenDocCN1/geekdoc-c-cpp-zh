When you design an animation, particularly one that changes control positions and sizes, try to minimize the effects of those changes on other controls. You can fix this by moving the Button into a Grid so that changes to its size don't affect other controls.

Specific kinds of animation handles properties of different data types such as Double, Color, String, Thickness, and many others.

The following code shows a simple Storyboard containing five DoubleAnimation objects. This is the Storyboard that the CentralizedTriggers program in Figure 14-2 uses to move the first thumbnail into the viewing area.

```
<Storyboard x:Key="img">
<DoubleAnimation Duration="0:0:0.5" To="120">
  Storyboard TargetName="img"
  Storyboard TargetProperty="(Canvas.Left)"/>
<DoubleAnimation Duration="0:0:0.5" To="0">
  Storyboard TargetName="img"
  Storyboard TargetProperty="(Canvas.Top)"/>
<DoubleAnimation Duration="0:0:0.5" To="485">
  Storyboard TargetName="img"
  Storyboard TargetProperty="Width"/>
<DoubleAnimation Duration="0:0:0.5" To="400">
  Storyboard TargetName="img"
  Storyboard TargetProperty="Height"/>
<DoubleAnimation Duration="0:0:0.5" To="1">
  Storyboard TargetName="img"
  Storyboard TargetProperty="Opacity"/>
</Storyboard>
```

The first animation makes the Canvas.Left property of the control img1 from its current value (whatever it is) to 120 over a 0.5-second interval. The second animation similarly changes the control's Canvas.Top property to 0 over the same 0.5 second.

The third and fourth animations change the img1's Width and Height properties to 485 and 400, respectively. The final animation changes the control's Opacity to 1 so it is completely opaque.
