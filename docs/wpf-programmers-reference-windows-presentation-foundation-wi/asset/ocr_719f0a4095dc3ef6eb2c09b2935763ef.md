# Index of Example Programs

# CHAPTER 1

Chapter 1 contains the following example programs:

+   - Clutter — A cluttered interface with garish colors, too much animation, and annoying sound effects. [Page 2, 3].
- Clutter_FakeRotation — A static version of Clutter to simulate rotation. Figure 1-1. [Page 2].
- Critics — A simple demonstration of properly nested XAML elements, in this case, a horizontal StackPanel holding a vertical StackPanel. Figure 1-4. [Page 6].
- FlowDocument — Demonstrates many FlowDocument elements including tables, controls, shapes, lists, and even a rotating three-dimensional shape. Figure 1-14. [Page 19].
- Gasket3D — Uses codebehind to build a complex rotating three-dimensional object. Figure 1-9. [Page 12].
- GrowingButtons — Makes buttons grow and shrink when the mouse moves on and off them. Figure 1-12. [Page 14].
- Multimedia — Plays video and audio. Figure 1-6. [Page 11].
- SetBackgrounds — Sets background linear gradient brushes in code.
- SimpleCritters — A simple demonstration of properly nested XAML elements, in this case, a horizontal StackPanel holding a vertical StackPanel. Figures 1-2 and 1-3. [Page 6].
- StackPanelButton — Displays buttons that contain StackPanels. Figure 1-13. [Page 16].
