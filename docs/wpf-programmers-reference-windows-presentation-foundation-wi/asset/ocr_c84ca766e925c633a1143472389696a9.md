# CLEVER CLASSES

The classes used in the Setters'property attributes must support their properties,
but the style doesn't actually require the controls using them be from that class.

For example, the previous style sets the FrameworkElement.Width and
FrameworkElement.Height properties. The FrameworkElement class has the
Width and Height properties, so WPF can use its definitions to understand how to
set their values. If you changed the Width property to Red, WPF would complain
ecause FrameworkElement.Width cannot be a color.

While the class defines the properties, the style doesn't require the controls using
it have those classes. In this example, if you were to change FrameworkElement to
Button, the style would still work. The Button class also has Width and Height prop-
ers, so it could define them, the Label and Rectangle can still use those property
e though they are not descendants of Button.

In fact, if you look back at the style's definition and the result in Figure 13-4, you'll
se the Rectangle uses the same Margin value as the Button and Rectangle
even that property is specified with the Control class and Rectangle isn't a
descendant of Control.

The moral of the story is that it doesn't matter much which classes you use --
as long as they define the properties.

The UnnamedStyles program shown in Figure 13-5 defines four unnamed styles. The fol-
lowing list describes those styles they set for their classes:

+   - Width = 100, Height = 100, Stretch = Uniform, BitmapFactory = drop shadow
- Label - FontFamily = Comic Sans MS, FontSize = 18, FontWeight = bold,
HorizontalAlignment = center, BitmapFactory = light blue outer
- Button - FontFamily = Arial, FontSize = 12, Height = 20, Background = blue and white
linear gradient
- StackPanel — Margin = S

The following code shows how the program defines its Style for Images. You can download the
example from the web site to see how other Styles are defined.

```
<Style TargetType="Image">
  <Setter Property="Width" Value="100" />
  <Setter Property="Height" Value="100" />
  <Setter Property="Stretch" Value="Uniform" />
  <Setter Property="BitmapEffect">
    <Setter.Value>
      <DropShadowBitmapEffect/>
    </Setter.Value>
  </Setter>
</Style>
```
