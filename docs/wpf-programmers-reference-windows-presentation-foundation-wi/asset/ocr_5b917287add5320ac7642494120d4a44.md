# SPLIT WINDOWS

You can drag the slider between the Window Designer and the XAML Editor to make one bigger and the other smaller. When you're initially placing controls on a window, you may want a large Window Designer and a small XAML Editor. Later, when you're fine-tuning the XAML code, you may want a big XAML Editor.

You can also click on the up/down arrow ( between the two panes to switch which is on top and which is at bottom. If you keep the top window large and the bottom one small, this makes it easy to switch between the two.

# TOOLBOX

The Toolbox holds controls that you can place on the window. Many of the controls, as Label and TextBox, are self-explanatory, and you should have little trouble figuring out how to use them. Many of the controls are also similar to Forms controls, so using them will be easy if you experience with Windows Forms controls. Chapters 5 through 8 describe individual controls in more detail.

To use the Toolbox, click on a control to select. Move to the Window Designer and click-and-drag to place an instance of the control on the window. You can also control the control and use handles to resize it.

If you [Ctrl]-click on a control in the Toolbox, then control remains selected after you click-and-drag to place an instance on the window. This lets you make several controls quickly and be useful, for example, if you need to make a forming of labels and controls.

Click on the Pointer tool to select any previously selected control (including if you [Ctrl]-clicked). One can then click on controls in the Window Designer to select them.

If you double-click on a control on the Toolbox, Visual Studio adds an instance of the control to the window at a default size and location. You can then drag it to position and resize it as needed.

The Toolbox contains tabs that group related controls. In Figure 2-2, the Controls tab is open to display all of the available controls. Figure 2-8 shows the Toolbox with the Common tab expanded. This tab contains only the most frequently used controls, which include (on my system at) Border, Button, CheckBox, ComboBox, Grid, Image, Label, ListBox, RadioButton, Rectangle, StackPanel, TabControl and TextBox.
