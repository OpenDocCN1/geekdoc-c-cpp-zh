# TABCONTROL

The TabControl displays a series of tabs that the user can click to select the control's children.

CONTROL CONTROLS
Yes, this is called TabControl, not just Tab, TabContainer, or some other appealing name. This can lead to awkward phrases such as "Insert a TabControl control here."
For some reason, it seems that one or two controls always slip through that that have the word control in their names, perhaps for historical reasons.

The TabControl object contains TabItem objects that hold the control's content. A TabItem can contain only a single child, but that can be a container such as a Grid or Panel, so you can put anything you want inside the TabItem.

The following table summarizes the TabControl's most useful properties:

| PROPERTY | PURPOSE |
| BorderBrush | Sets the color for the control's border (red in Figure 6-9). |
| BorderThickness | Sets the thickness of the border (3 pixels in Figure 6-9). |
| Selectedindex | The index of the currently selected tab (0 in Figure 6-9) |
| SelectedItem | The selected object (normally a TabItem object) |
| TabStripPlacement | Determines where the control places its tabs. Tab can take the values Left, Right, Top (the default), or Bottom. |

Figure 6-9

The TabItem's Foreground and Background property determine the colors used to draw the item's tab. In Figure 6-9, these are yellow and blue, respectively. The light-to-dark blue shaded area is the Grid contained inside the TabItem.

Usually the TabItem's Header property is a simple string, but if you want to place something complicated in the tab, you can do so by using property element syntax.
