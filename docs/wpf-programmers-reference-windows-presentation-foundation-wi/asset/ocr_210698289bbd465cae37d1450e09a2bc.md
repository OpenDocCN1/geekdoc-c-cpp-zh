# Building Fixed Documents in XAML

Building an XPS document is easy with Microsoft Word, WordPad, or some other external program, but sometimes it's more convenient to build a fixed document in XAML or code-behind. For example, you might want a program to generate a report at runtime and display it as a fixed document.

Building a fixed document in XAML is not too complicated, although it is a lot of work because it's a fairly verbose format.

Starting by creating a Document to hold the document. Give it any properties and resources it needs (such as a background), and place a FixedDocument inside it.

The FixedDocument object should contain one or more PageContent objects that define its pages.

# PAINLESS PAGES

> If you don't want to build a page within the code, you can set a PageContent object's Source property to the Uniform Resource Identifier (URI) of the page it should display.

You can set each PageContent object's Width and Height properties to determine the size of the page.

Inside the PageContent, you place a FixedDocument to define the page's contents.

Inside the FixedPage, you can control controls such as StackPanel, Grid, TextBlock, and Border to create the page's contents.

# CONTESTED INHERITANCE

> FixedPage objects don't seem to inherit unnamed styles, so, for example, you can't set Label properties in an unnamed style defined in the Window.Resources. You need to either define the style inside the FixedPage or use a named style.

The SimpleFixedDocument example program shows in Figure 21-2 draws four pages that contain simple shapes and labels.

The SimpleFixedDocument program uses the following code to draw its pages:

```
<DocumentViewer Background="Pink">
  <FixedDocument>
    <PageContent Width="850" Height="1100">
      <FixedPage>
        <Grid Margin="100" Width="650" Height="900" Background="LightBlue">
          <Ellipse Stroke="Green" Fill="Orange" StrokeThickness="10" />
          <Label Content="Ellipse" Style="StaticResource styleLabel"/>
        </Grid>
      </FixedPage>
    </PageContent>
  </FixedDocument>
</DocumentViewer>
```
