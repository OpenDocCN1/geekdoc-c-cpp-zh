# TRUE TILING

The technique shown in the lower of [Figure 3-16](_3-16) is very useful for tiling areas. Set the brush's Viewbox to 0, 0, 1. Set ViewportUnits to Absolute so the Viewport values are specified in pixels and then set the Viewport values to match the image's size in pixels.

The following snippets show the brushes used by the UseImageBrushes example program shown in Figure 3-16. Note that it only shows the brushes, not the rest of the XAML code.

```
<ImageBrush ImageSource="Smiley.bmp" />

<ImageBrush Stretch="Uniform" TileMode="Tile"
ImageSource="Smiley.bmp"
Viewbox="0,0,1,1" Viewport="0,0,0.5,0.5">

<ImageBrush Stretch="Uniform" TileMode="Tile"
ImageSource="Smiley.bmp"
Viewbox="0,0,1,1"
Viewport="0,0,50,50" ViewportUnits="Absolute"/>

<ImageBrush Stretch="Uniform" TileMode="Tile"
ImageSource="Smiley.bmp"
Viewbox="0,0,0.5,0.5" Viewport="0,0,50,50" ViewportUnits="Absolute"/>
```

# Drawing Brush

A drawing brush fills an area with a drawing that may contain shapes, labels, video, and other controls.

To make a brush, add some sort of container control to the window such as a Grid, Canvas, or StackPanel. Add the controls to it you want to be part of the brush.

Next, select the container control, open the Tools menu, expand the "Make Brush Resource" sub-menu, and select "Make Drawing Brush Resource." On the Create Drawing Brush dialog, give the brush a good name and click OK.

Now you can modify the brush as explained in the previous section for image brushes. For example, you can open the Resources window in Expression Blend's right panel and click on the brush's drop-down to set its TileMode and Stretch properties.

Review the previous section "Image Brush" for more information on modifying the brush. In particular, you may review how to set the brush's viewbox and viewport.
