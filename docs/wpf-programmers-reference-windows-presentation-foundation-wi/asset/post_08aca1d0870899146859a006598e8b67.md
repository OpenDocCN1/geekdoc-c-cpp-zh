The following table describes properties that determine the pop-up appears when it is visible:

| PROPERTY | PURPOSE |
| --- | --- |
| PlacementTarget | The object relative to the Popup is positioned. Typically, this is a control, and the Popup is placed next to it. In XAML code, this might look like: `PlacementTarget="Binding ElementName=image"`. If you omit this property, then the Popup is positioned relative to its container. |
| Placement | Determines how the Popup is positioned relative to the PlacementTarget object. See the following text for information. |
| PlacementRectangle | If you include this, it determines a rectangle within the PlacementTarget relative to which the Popup should be positioned. |
| HorizontalOffset | Sets a horizontal offset for the Popup's placement. |
| VerticalOffset | Sets a vertical offset for the Popup's placement. |

After the horizontal entries, the main StackPanel holds a Popup control that contains an Image.

The program uses the following code to show and hide its Popup control:

```
// The mouse has entered an image. Display the popup.
private void imgMouseEnter(object sender, MouseEventArgs e)
{
    Image img = (Image)sender;
    imgFullScale.Scale = img.Source;

    popFullScale.PlacementTarget = img;
    popFullScale.IsOpen = true;
}

// The mouse has left an image. Hide the popup.
private void imgMouseLeave(object sender, MouseEventArgs e)
{
    popFullScale.IsOpen = false;
}
```

When the mouse enters an Image control, the img_MouseEnter event handler finds which Image raised the event. It sets the Popup's Image control to display the same image as the small preview control but at full scale. It sets the Popup's PlacementTarget to the control that raised the event and sets IsOpen to True.

When the mouse leaves an image, the img_MouseLeave event handler simply sets the Popup's IsOpen property to False.

> PUSHY POP-UPS
> Pop-ups float over the application. If you move the application, they remain where they were originally positioned and do not move with the application.
> In fact, pop-ups tend to float above all other applications, too. If you switch to another program, the pop-ups remain visible floating over the new program.

By default, a pop-up remains invisible until its IsOpen property is set to False. If you set the control's StayOpen property to False, the Popup automatically captures the mouse and hides when a mouse event occurs outside the Popup.

The final Popup property mentioned here is PopupAnimation. You can set this property to None (the pop-up simply appears), Fade (the pop-up fades in and out), Scroll (the pop-up scrolls from its upper-left corner), and Slide (the pop-up slides down from the top or from the bottom if it won't fit sliding down). To use any of these values other than None, you must set the control's AllowsTransparency property to True.

## TextBlock

The TextBlock displays read-only text such as a Label does but with greater flexibility. The TextBlock has additional features that let you:

- Change some text's appearance inline by making it bold, italic, or underlined.
- Add line breaks.
- Change line spacing.
- Expand or condense the text.
- Truncate text with an ellipsis.
- Apply text decorations as strikethrough, baseline, underline, and outline.
- Use superscripts and subscripts*

The following table summarizes some of the more useful properties that the TextBlock class provides.

| PROPERTY | PURPOSE |
|---|---|
| LineHeight | Determines the spacing between lines. |
| LineStackingStrategy | Can be BlockLineHeight (line height is determined by Line) or maxHeight (each line's height is set to fit its contents) |
| TextTrimming | Determines how the TextBlock handles words that don't fit. Can be None (words are truncated), WordEllipse (text is broken at a word boundary and replaced with an ellipsis), or CharacterEllipse (text is broken at a character boundary and replaced with an ellipsis). See Figure 5-11. |
| TextWrapping | Determines how text is wrapped at the end of the TextBox. Can be No, Wrap, or WrapOverflow. If the text contains a long word and the character cannot figure out how to break the text into lines, WrapWithOverflow may make part of the word string extend beyond the edge of the TextBlock (and get chopped off), whereas Wrap will break the word and continue on the next line. |

Each row in Figure 5-11 demonstrates a different TextTrimming value. The Text on the right contain the text CProgramFiles\CoolApplications and have their Wrapping properties set to Wrap. When TextTrimming is CharacterEllipse, the control ends at the last character that can fit and finishes with an ellipsis. When TextTrimming is WordEllipse, the control ends at the last break that can and finishes with an ellipsis. When TextTrimming is None, the control simply truncates the text.

![](img/c9b2d394f4fc2f7e276f6a0a6fa9c2f6_124_0.png)

In addition to ordinary text, the TextBlock can contain inlines, objects that change the text's appearance for a while. The following table summarizes the most useful inlines.

| INLINE | PURPOSE |
|---|---|
| Bold | Makes the enclosed text bold. |
| Hyperlink | Displays text as a hyperlink. Can raise Click events and automatically navigate if contained in a navigation host such as a NavigationWindow

For example, the following XAML code italicizes the word:

```
<TextBlock>
  A TextBlock gives <Italic></Italic> greater control
  <Label>
</TextBlock>
```

A TextBlock can directly contain some controls, which it includes within the flow of the text.

The following XAML code demonstrates many TextBlock features. The result is shown in Figure 5-12.

```
<TextBlock HorizontalAlignment="Stretch" VerticalAlignment="Stretch"
FontSize="16" Margin="0,0,0,0"
TextWrapping="Wrap" TextTrimming="WordEllipsis"
LineStackingStrategy="BlockHeight">
  The text in a TextBlock can include <Italic>inlines</Italic>
  that make the text <bold>bold</bold>, <Italic>italic</Italic>
  or <Underline>underline</Underline>.
  They can also provide
  <Hyperlink>hyperlinks</Hyperlink>
  <LineBreak/>
  line breaks and even controls such as
  <Button Content="Buttons"/>
</TextBlock>
```
