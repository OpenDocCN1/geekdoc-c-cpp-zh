# SIZE WIDTH

Note how the Labels on the right in Figure 20-3 stretch to match the width of the StackPanel, while those ones on the left size themselves to fit their contents.

Normally a StackPanel stretches its Labels to fit its width. However, the Layout Transforms when using the Labels on the left in Figure 20-3 are applied before the Labels are stretched so the Labels get their desired fit-to-content sizes. In contrast, the StackPanel on the right of Figure 20-3 arranges the Labels first, stretching them, and then, only returns the results.

# EFFECTS

As transformations modify an object's geometry, bitmap effects modify the way in which an object is drawn.

To add an effect to an object, give it a BitmapEffect property element that contains an effect object. For example, the following code defines a Canvas that holds an Ellipse and a Path. The Canvas.BitmapEffect element holds a DropShadowBitmapEffect to give the result a drop shadow.

```
<Canvas Width="100" Height="100">
<Canvas.BitmapEffect>
  <DropShadowBitmapEffect />
</Canvas.BitmapEffect>
  <Ellipse Stroke="Blue" Fill="Yellow" Width="100" Height="100"/>
  <Path Data="M 20,50 A 30,30 0 0,1 80,50" Stroke="Blue" StrokeThickness="2"/>
</Canvas>
```

The following list summarizes WPF's bitmap effect classes:

+   - BevelEdges adds edges to the object. This effect has several important properties. BorderWidth determines how the beveled edges are. LightAngle determines the direction that light hits the beveled edges. Relief determines how the contrast is between the shadowed and lighted edges. Smoothness determines how much shadows are. EdgeProfile is discussed in the following paragraphs.
- Blur blurs the object. Radius determines how large the blurring is.
- DropShadowBitmapEffect — Adds a drop shadow behind the object. This effect's most useful properties are Color (which determines the shadow's color) and Direction (which gives the direction in degrees from the object to its shadow). ShadowDepth determines how far “behind” the shadow appears.
