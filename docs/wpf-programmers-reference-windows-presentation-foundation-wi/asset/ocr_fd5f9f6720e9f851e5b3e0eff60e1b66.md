The Storyboard contains two ParallelTimelines that run independently. The first lasts 1 second until the ball is touching the "ground" and uses a MediaTimeline object to play the sound effect.

The second ParallelTimeline contains two DoubleAnimationUsingKeyframes objects, one to control the ball's Canvas.Top property and one to control the shadow's Opacity. As the animation moves the ball downward, the shadow's animation makes the shadow more opaque. When the animations end, the ball is touching the "ground," and the shadow is fully opaque.

Both animations use spline keyframes with control points set so that the controlled property value starts changing slowly and speeds up at the end of the animation.

The ParallelTimeline containing the two animations has its AutoReverse property set to True, after the ball reaches the "ground," it bounces back up to its starting position.
