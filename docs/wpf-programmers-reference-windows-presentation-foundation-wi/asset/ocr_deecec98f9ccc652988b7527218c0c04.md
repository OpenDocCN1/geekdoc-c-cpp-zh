+   - Italic — Makes its italic

+   - LineBreak — Makes text start a new line. This does not add extra vertical space between the lines.

+   - Run — Contains a run of text, with a different appearance from the rest of the paragraph. You can use the Run's properties to change the text's background color, text color, font, size, style, and so forth.

+   - Span — Similar to a Run except it can also contain inline elements (e.g., Bold, Italic) and UI elements (e.g., Button, Ellipse, Polygon)

+   - Underline — Makes its text underlined.
