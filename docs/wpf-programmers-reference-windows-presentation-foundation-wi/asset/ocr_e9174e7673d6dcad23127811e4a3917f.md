# A CLOSER LOOK

Many of the stroke properties do not make a huge difference to appearance unless the linear feature you are drawing is thick. For example, `StrokeDashCap` determines whether the dashes are drawn as square, rounded, or triangular. If a line is only 1 pixel wide, you won't be able to tell the difference.

Remember, that WPF can draw objects that are scaled, so if your program allows it, the user zoom on linear features until these properties make a big difference. The MagnifiedLines example shown in Figure 10-2 draws the same line at five different scales. In the thickest lines you can tell that the dash caps are triangular.

![](bbox=[0.518, 0.23, 0.802, 0.375])

The following code shows how the MagnifiedLine draws its thickest line. Because the line is not as wide as the ViewBox that contains it, the ViewBox enlarges it to fit:

```
<Line Stretch="Uniform" Height="20" Width="300" Margin="10,10,10,10">
<Line X1="0" Y1="0" X2="18.75" Y2="0" Stroke="Blue
StrokeDashArray="3" StrokeDashCap="Triangle"/>
</Line>
```

# Stroke

The `Stroke` property determines the color of a linear feature. You can specify the color in a couple of ways. WPF understands include Red, Chartreuse, LavenderBlush, and about 150 others.

The following XAML shows how the PensAndBrushes example draws the ellipse shown in Figure 10-1. The `Stroke` property makes the ellipse's border purple.

```
<Ellipse Fill="Red" Stroke="Purple"
Margin="0" StrokeThickness="10" StrokeDashArray="2,"/>
```

The second way to specify a solid color is by giving its `color components`. In both cases, the RR, GG, and BB parts include two hexadecimal decimal digits giving the color, red, green, and blue color components between 00 and FF (255). For example, the value `#FF0000` is red, and the value `#FFF00` is yellow (equal parts red and green).
