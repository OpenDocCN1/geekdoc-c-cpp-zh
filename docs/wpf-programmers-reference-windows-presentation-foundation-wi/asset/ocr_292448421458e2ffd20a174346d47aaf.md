# Using XAML IntelliSense

The third way to make an event handler in Visual Studio is to use the XAML Editor's IntelliSense in the XAML Editor. Start typing the event attribute name when you type the equals sign, IntelliSense displays a list of all existing event handlers that could catch the event. At the top of the list is the special entry <Event Handler>. If you select this entry, Visual Studio inserts an event handler name and creates an event handler stub.
