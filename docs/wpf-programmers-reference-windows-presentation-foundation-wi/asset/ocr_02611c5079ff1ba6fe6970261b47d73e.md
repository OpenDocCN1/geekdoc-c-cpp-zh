You can also play a sound inside a Storyboard. To do that, add a MediaElement control to the window. Then, inside the Storyboard, add a MediaTimeline object, setting its Storyboard.TargetName property to the MediaElement and its Source property to the name of the sound you want to play.

The RepeatingSound example program uses the following Storyboard to play a sound every time a button passes in an animation. The MediaTimeline object plays the sound in the file WindowsDefault.wav using the MediaElement named medBinding.

```
<Storyboard x:Key="mdnButton RepeatBehavior="Forever">
<DoubleAnimation Duration="0:0:2">
<Storyboard.TargetName="btnMore"
<Storyboard.TargetProperty="Canvas.Left">
<Source="X">
<PathGeometry="StaticResource pathMove"/>
</DoubleAnimation>
<DoubleAnimation Duration="0:0:2">
<Storyboard.TargetName="btnMore"
<Storyboard.TargetProperty="Canvas.Top">
<Source="Y">
<PathGeometry="StaticResource pathMove"/>
</DoubleAnimation>
<MediaTimeline BeginTime="0:0:1" Source="WindowsDefault.wav">
<Storyboard.TargetName="medBinding"/>
</Storyboard>
```

# MULTIPLE SOUNDS

I've had luck trying to play more than one sound in the storyboard. Multiple MediaTimelines seem to interfere with each other. It's a problem with the media layer. If you get working, e-mail me at RodStephens@vb-helper.com and let me know the secret.

Unfortunately, we cannot play media files in a Storyboard that has its AutoReverse set to True. (Presumably, WPF doesn't want to reverse the media file.)

One way around this is to build a storyboard that explicitly reverses the actions it takes so it can reverse animations without trying to reverse the media file.

A second approach is to make two storyboards or two timelines within the same storyboard. Multiple timelines let different parts of the storyboard run independently, overlapping each other.

The BouncingBall example program shown in Figure 14-1 uses the following Storyboard to make its red ball bounce up and down playing a sound effect when it hits the ball "ground."

```
<-- One storyboard to rule them all --
<Storyboard x:Key="mdnButton RepeatBehavior="Forever">
<!-- Play the sound after 1 second. --
<ParallelTimeline BeginTime="0:0:0">
<MediaTimeline BeginTime="0:0:1" Source="boing.wav">
<Storyboard.TargetName="medBinding"/>
```
