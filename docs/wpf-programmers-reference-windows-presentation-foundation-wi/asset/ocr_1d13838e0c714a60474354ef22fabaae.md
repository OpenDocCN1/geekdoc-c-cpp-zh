SimpleRichEditor

The code first gets the FontFamily property value. It sets the font
ComboBox's text to a blank string. Otherwise, it sets the ComboBox's text to the family name.

Next, the code gets the selection's font size, converts it into a string, and displays the value in the size
ComboBox. There's one trick here: If the current selection contains different pieces of text that have different
font sizes, the call to GetPropertyValue doesn't return a size. Instead it returns a NamedObject
which has the special value UnsetValue. The call to ToString returns "DependencyPropertyValue"\and the code tries to make the size ComboBox display that value. Because ComboBox doesn't have a
it, it displays nothing.

Having the font name and color, the code gets the ForegroundBrush. The Brush ToString returns a hexadecimal
value representing the red, green, and blue components. The code uses a switch statement to
determine which color it is and displays the corresponding result.

Finally, the code displays the selection's weight and style property values.

The FlowDocument contained in a RichTextBox can provide more features than those demonstrated

that the RichTextBox is not particularly suited to edit. To create and edit more complex documents,
