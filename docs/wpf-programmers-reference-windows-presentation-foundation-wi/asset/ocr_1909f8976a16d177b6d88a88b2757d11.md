MultiWindowResources

The MultiWindowResources example uses similar code to include the resource dictionary and refer to it in all four of its Windows. Because every form refers to the same resources, they all have a common appearance. If you decide to change the appearance, you can simply modify the resource dictionary, and all of the forms will pick up the changes automatically.
