The following code builds a DockPanel that displays a Menu on the top, a StatusBar on the bottom, and a Grid in the middle:

```
<DockPanel>
  <Menu DockPanel.Dock="Top">
    <!-- Menu items omitted. -->
  </Menu>

  <StatusBar DockPanel.Dock="Bottom">
    <StatusItem>
      <Label Content="Status:"/>
    </StatusItem>
    <Label Content="Normal" Background="White" Padding="10,6,10,6">
      <BitmapEffect>
        <BevelItBitmapEffect EdgeProfile="BulgedUp"/>
      </BitmapEffect>
    </Label>
  </StatusItem>
  <StatusItem HorizontalAlignment="Right">
    <Button Content="Disconnect"/>
  </StatusItem>
</StatusBar>

  <Grid>
    <!-- Other controls omitted. -->
  </Grid>
</DockPanel>
```

The StatusBar contains a pair of StatusItems holding Labels. The third StatusBarItem has HorizontalAlignment = Right, so that item is moved to the StatusBar’s right edge.

# # TABCONTROL

The TabControl displays a series of tabs where you can place different sets of information. The control should contain a series of TabItems, each of which holds a single item (which is often a container such as a Grid). The properties of TabControl are given in Tab C-11.

**TABLE C-11:** Key Properties of TabControl

| PROPERTY | PURPOSE |
| --- | --- |
| Background | The color used to fill the interior of the tab contents. This color does not fill the header area. |
| BorderBrush | The color of the edge of the tab contents. This does not include the header area. |
