For the example, the following code shows an extremely simple Label template:

```
<Window.Resources>
  <ControlTemplate x:Key="temSimpleLabel" TargetType="Label">
    <Border Brush="Red" BorderThickness="1">
      <ContentPresenter/>
    </Border>
  </ControlTemplate>
</Window.Resources>
```

SimpleLabelTemplate

The template's name is temSimpleLabel, and it applies to Label controls. The template contains a Border control that displays a red border and holds the ContentPresenter.

The following code shows how to program this template: This code creates a Label. Its last attribute sets the Control's Template property to the previously created template.

```
<Label Margin="5" Content="No Template"
HorizontalContentAlignment="Right"
VerticalAlignment="Center"
BorderBrush="Yellow" BorderThickness="2"
Foreground="StaticResource brForeground"
Background="StaticResource brBackground"
Template="StaticResource temBorderLabel"/>
```

# TEMPLATE BINDING

If you compare the Labels in Figure 15-2, you will see that this example has some potential problems. The template's Border control includes explicit values for its BorderBrush and BorderThickness properties, which overrides any values set in the code that creates the Label. The Border control also does not set a Background, so it uses its default transparent background.

This means the templated control does not display the corner or border. It also doesn't honor the requested HorizontalContentAlignment and VerticalContentAlignment values.

Fortunately, you can learn about some of the properties on the client control by using a template binding. For example, the following code fragment sets the Background property for a piece of the template to the value set for the control's Background property:

```
Background={TemplateBinding Background}"
```
