TextBoxCommands

The code sets each MenuItem’s Command property to the name of a predefined application command.

# SHORTER NAMES

The text ApplicationCommands.before the command name is optional, for example, you could call the Copy command Copy instead of ApplicationCommands.Copy. Writing the full name makes it obvious that these are application commands but you can use whichever style you think is easier to read.

The MenuItems rest the automatically. They automatically display the appropriate text and shortcut combinations. When you invoke one of the menu items, it activates the command object and that object makes the TextBox with the focus perform the appropriate action.

# THE EASY WAY

This is the easiest commanding scenario. It uses a predefined command, a control that has built-in support for the command (TextBox), and a control that has built-in support for representing and invoking commands (MenuItem).

The following code shows how the program makes its toolbar:

```
<ToolBarTray Dock.Dock="Top" Background="Transparent">
  <ToolBar Band="1" BandIndex="1" Background="Transparent">
    <Button Command="Copy" Content="
{Binding RelativeSource={RelativeSource}, Path=Command.Text}/>
    <Button Command="Cut" Content="
{Binding RelativeSource={RelativeSource}, Path=Command.Text}/>
    <Button Command="Paste" Content="
{Binding RelativeSource={RelativeSource}, Path=Command.Text}/>
    <Separator/>
    <Button Command="Undo" Content="
{Binding RelativeSource={RelativeSource}, Path=Command.Text}/>
    <Button Command="Redo" Content="
{Binding RelativeSource={RelativeSource}, Path=Command.Text}/>
  </ToolBar>
</ToolBarTray>
```
