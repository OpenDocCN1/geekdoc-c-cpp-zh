To let you place child controls in rows and columns, the Grid control defines Row and Column attached properties. For example, the following XAML code creates a Label and places it in row 0 column 2 of a Grid.

```
<Grid Row="0" Grid.Column="2" Content="Hello!"/>
```

The Grid also defines RowSpan and ColumnSpan attached properties, so you can make a child more than one row or column. For example, set RowSpan = 2 to make a child span 2 rows.

# SCROLLVIEWER

The ScrollViewer control displays a single child inside a scrollable region. Its most important properties are HorizontalVisibility and VerticalScrollBarVisibility. These take one of the following values:

+   - Auto — The scrollbar is displayed when needed and hidden otherwise.
- Visible — The scrollbar is displayed when it isn't needed.
- Disabled — The scroll does not appear even when it is needed. The child control's size is set to the available size of the ScrollViewer. For example, a Grid may be resized to fit.
- Hidden — The scrollbar does not appear even when it is needed. The child's size is not set to the available size of the ScrollViewer. For example, a Grid would keep its original size if it sticks out the bounds of the ScrollViewer (where it is clipped).

Figure 6-5 illustrates the difference between the Disabled and Hidden values. The program contains a StackPanel holding nearly two items.
