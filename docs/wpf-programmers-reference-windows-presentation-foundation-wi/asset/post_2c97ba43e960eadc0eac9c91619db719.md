## View Templates

The `TreeView` control works a bit differently than the `ListBox` and `ComboBox` because it displays hierarchical data instead of items in a simple list.

In a `TreeView`, you must specify two things at each node in the tree — the data to display for the items and node and the path to follow deeper into the tree.

For example, consider an organizational chart that lists corporate regions that contain departments, which, in turn, contain employees. When the `TreeView` reaches a department node, your program must tell it what to display (e.g., the department's name) and how to move deeper into the tree (by listing the department's employees).

The OrgTreeView example program in Figure 18-12 displays a company organizational chart with departments displayed either by managers or by projects. To understand the items easier, region names are red, department names are blue and end in the word department, manager names are in blue boxes, project names are in goldenrod boxes, and employee names are plain black text.

The `TreeView` on the left shows regions, each region's departments, each department's managers, and each manager's direct report employees. The `TreeView` on the right shows regions, each region's departments, projects, and each project's team members.

The HierarchicalDataTemplate has three key keys:

- First, its DataType attribute tells what this template holds. The preceding template springs into life when the TreeView encounters a Region object in its data.
- Second, the template's ItemsSource attribute tells the TreeView should look for children of this item. The previous code indicates that a Region object has children that are Departments. You can use the ItemsSource attribute to make the Tree follow paths through the data hierarchy.
- Third, the HierarchicalDataTemplate provides the template to display the data at each node. This example displays the Region's RegionName property in a TextBlock.

The TreeView on the left in Figure 18-2 uses the following HierarchicalDataTemplate to display data for a department object:

```
<HierarchicalDataTemplate

ItemsSource="Binding Path=Managers">
  <TextBlock Text="(Binding Path=Name)" Foreground="Blue"/>
</HierarchicalDataTemplate>
```
