# FlowDocument

The FlowDocument control contains objects that make up a document. These objects may include:

+   - Paragraphs
- Tables
- Lists
- Floaters
- Figures
- Three-dimensional (3D) objects

For more information on building FlowDocuments, see Chapter 21.
The following three sections describe controls that display FlowDocuments in different styles. If you place a FlowDocument directly in a Window, then the control acts as if it were a FlowDocumentReader. See the section describing control for information about how it behaves.

# FlowDocumentPageView

FlowDocumentPageView displays a FlowDocument in page viewing mode. In this mode, the user can see a single page at a time, and controls at the bottom of the viewer allow the user to move to other pages.
The size of the page and the amount displayed by the viewer are determined by the FlowDocument's PageHeight and PageWidth properties, and by the viewer's size.
By default, the control scales to the viewer's width. When a page is defined by how much of the document can fit vertically in the viewer at that width. If you set the document's PageHeight and PageWidth properties, the viewer may control the document into more or fewer values.

Figure 5-5 shows a FlowDocument displaying a FlowDocument. The arrows in the viewer's bottom center let you scroll through the document's pages. The plus and minus buttons on the bottom right let you zoom in and out.

# FlowDocumentReader

FlowDocumentReader displays a FlowDocument in one of three modes: Page, Scroll, or TwoPage.
In Page mode, the control works like a FlowDocumentPageView. See the preceding section for information about that control.
