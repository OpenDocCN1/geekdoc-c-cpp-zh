# 408 | CHAPTER 24 SILVERLIGHT

Because Silverlight applications are intended to run in a user's browser

While there are some differences between WPF and Silverlight applications, the majority of what you know about applies to Silverlight. In particular, you can build a user interface with Expression Blend or Visual Studio using familiar controls. Silverlight does not provide all of the controls that WPF does, but it includes the basics such as Button, TextBox, StackPanel, Grid, and so on.

# COLOR SELECTION EXAMPLE

As a quick introduction to Silverlight, this section shows how to use Visual Studio to build a simple example program.

Start Visual Studio, open the File menu, and select "New Project" to display the dialog shown in Figure 24-1.

![](bbox=[0.095, 0.417, 0.513, 0.616])

FIGURE 24-1

Expand the template tree on the left to find the Silverlight category for your language (C# or Visual Basic). Select the Silverlight application, enter a project name, and click OK to display the dialog shown in Figure 24-2.

Leave the checkbox checked if you want Silver Studio to create a web site for the application. Otherwise, uncheck the checkbox to create an application without a web site.

When you click OK, Visual Studio builds a Silverlight project as it builds any other kind of project.
