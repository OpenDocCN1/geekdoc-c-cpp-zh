The Click attribute is the only connection between the XAML code and the code-behind. If you need to detach the button from the code, simply remove that attribute. You don't need to remove the event-handler code, although leaving it in will clutter the code.

# # Non-Default Event Handlers

If you want to attach to an event other than a control's default event (e.g., a Button's MouseOver event), select the control in the Window Designer. At the top of the Properties window, click on the Events button to view the control's events.

2-13 shows the Properties window displaying the events for btnGreen. Notice that the Click event is already filled in with the btnGreen_Click route.

If you select an event, a dropdown appears to the right that will let you pick an appropriate event handler for that event.

If you want to create a new event handler, simply double-click on the event, and Visual Studio will create an appropriate handler and open it in the Code Editor.

# # Handmade Event Handlers

Double-clicking on a control and using the Properties window are the easiest ways to build event handlers, but there's nothing stopping you from doing it by yourself.

Add an attribute to the control's XAML code. For example, to add a ValueChanged event to a Slider, add an attribute to ValueChanged="slider_ValueChanged".

Then add the event handler to your code. You'll need to give the appropriate parameters for the type of event you are creating. For C#, the Slider's ValueChanged event handler would look similar to the following:

```
private void slider_ValueChanged(object sender,
    RoutedPropertyChangedEventArgs<double> e)
{
n}
```

In Visual Basic, the code would be similar to the following:

```
Private Sub Slider_ValueChanged(ByVal sender As System.Object,
    ByVal As System.Windows.RoutedPropertyChangedArgs(
    Of System.Double)) _
    Handles Slider1.ValueChanged
```

```
End Sub
```

The trick to building event handlers by hand lies in knowing what parameters they need. Because they are often complicated, it's usually easier to double-click on the control or use the Properties window.
