# COMMANDS IN XAML

To use a command in XAML, simply set a control's Command property to the appropriate object. For example, the following code defines several items in an Edit menu and sets their Command properties:

```
<MenuItem Header="Edit">
<!-- Menu items that invoke default commands. -->
  <MenuItem Command="ApplicationCommands.Copy"/>
  <MenuItem Command="ApplicationCommands.Cut"/>
  <MenuItem Command="ApplicationCommands.Paste"/>
  <Separator/>
  <MenuItem Command="ApplicationCommands.Undo"/>
  <MenuItem Command="ApplicationCommands.Redo"/>
</MenuItem>
```

Use the CommandTarget property to make a command apply to a specific code. The following makes a Button that applies the ApplicationCommands.Cut command to the TextBox named txtTop:

```
<Button Row="0" Column="1" Margin="2"
Content="Binding RelativeSource={RelativeSource}, Command=Text}"
Command="ApplicationCommands.Cut"
CommandTarget="{Binding ElementName=txtTop}"/>
```

# COMMANDS IN-BEHIND

Some commands, such as the Edit command, have predefined behaviors. For other commands, you need to define behaviors.

The following code shows how a program can define command bindings. These tie commands like New to the code event handlers that the command needs to determine when it is available and what action it should perform.

```
<Window.CommandBindings>
<CommandBinding Command="New"
CanExecute="DocumentNewAllowed" Exec="DocumentNew"/>
<CommandBinding Command="Open"
CanExecute="DocumentOpenAllowed" Exec="DocumentOpen"/>
<CommandBinding Command="Save"
CanExecute="DocumentSaveAllowed" Exec="DocumentSave"/>
<CommandBinding Command="SaveAs"
CanExecute="DocumentSaveAsAllowed" Exec="DocumentSaveAs"/>
<!-- The Close binding is defined in code
    just to show how it's done. -->
<CommandBinding Command="Close"
CanExecute="DocumentCloseAllowed" Exec="DocumentClose"/>
-->
</Window.CommandBindings>
```

The following C# code shows the code-behind for the New command:

```sharp
// Return true if we can perform the New action.
private void DocumentNewAllowed(Object sender, ExecuteRoutedEventArgs e)
{
    e.CanExecute = (!m_IsDirty);
}
// Perform the New action.
private void DocumentNew(Object sender, ExecutedRoutedEventArgs e)
{
    // Remove any existing controls on the Canvas.
    canvasDrawing.Children.Clear();
    // Display the canvas.
    drawing.Visibility = Visibility.Visible;
    m_FileName = null;
}
```

# Styles

A Style lets you define a package of properties that you can share among many controls. Typically, a Style contains Setter objects that define specific values. You can make two kinds of Styles: named and unnamed.

# NAMED STYLES

To make a named Style, give it an x:Name attribute. Later you can refer to the Style as a StaticResource. The following XAML code defines and uses a Style named stubButton:

```xml
<StackPanel Orientation="Horizontal">
  <StackPanel.Resources>
    <Style Key="stubButton" TargetType="Button">
      <Setter Property="Width" Value="100"/>
      <Setter Property="Height" Value="30"/>
      <Setter Property="Margin" Value="5"/>
      <Setter Property="FontSize" Value="14"/>
      <Setter Property="FontWeight" Value="Bold"/>
      <EventSetter Event="Click" Handler="Button_Clicked"/>
    </Style>
  </StackPanel.Resources>
  <Button Content="Customers" Style="{StaticResource stubButton}" Width="150"/>
  <Button Content="Orders" Style="{StaticResource stubButton}"/>
  <Button Content="Inventory" Style="{StaticResource stubButton}"/>
</StackPanel>
```

# UNNAMED STYLES

To make an unnamed Style, simplify the x:Name attribute. Unnamed Styles apply to all objects of the appropriate type within scope. For example, if you define a Button Style in a StackPanel's Resources section, then any Button within the StackPanel uses it.

The following code defines an unnamed Style similar to the one described in the previous section:

```xml
<StackPanel Orientation="Horizontal">
  <StackPanel.Resources>
    <Style TargetType="Button">
      <Setter Property="Width" Value="100"/>
      <Setter Property="Height" Value="30"/>
      <Setter Property="Margin" Value="5"/>
      <Setter Property="FontSize" Value="14"/>
      <Setter Property="FontWeight" Value="Bold"/>
      <EventSetter Event="Click" Handler="Button_Clicked"/>
    </Style>
  </StackPanel.Resources>
  <Button Content="Customers" Width="150"/>
  <Button Content="Orders"/>
  <Button Content="Inventory"/>
  <Button Content="Maintenance" Style="(x:Null)" Width="75" Height="25" Click="Maintenance_Clicked"/>
</StackPanel>
```
