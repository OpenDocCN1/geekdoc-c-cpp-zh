+   - FlipXY — The image is flipped both horizontally and vertically to create new copies of the image.

+   - Tile — The image is repeated as needed without any flipping.

The stretch determines how the image is scaled or stretched when needed and can take the following values:

+   - None — The image is not stretched.

+   - Fill — The image is stretched to fill the area.

+   - Uniform — The image is stretched to be as large as possible in the area but not distorted. For example, if the image is relatively tall and thin compared to it fills the area vertically, and parts of the area to the sides may remain unfilled.

+   - UniformToFill — The image is stretched uniformly until it completes the area. If parts of the image extend beyond the edges of the filled area, they are clipped off.

To use the brush resource, place a control such as a Rectangle on the window. Use the Properties window, find the Brushes category, and select the brush type you want to set (Fill for a Rectangle). Among the tabs for different kinds of brushes (none, solid, gradient, etc.), select the rightmost Brushes tab.

A brush's viewBox determines the part of the image is used by the brush. The viewport determines the part of the filled area that should correspond to a single copy of the viewbox image.
