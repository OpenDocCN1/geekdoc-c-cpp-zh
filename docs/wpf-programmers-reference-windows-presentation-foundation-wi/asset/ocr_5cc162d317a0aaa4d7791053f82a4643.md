# # RADIOBUTTON

The RadioButton control lets user select one of an exclusive set of options. If the user selects a RadioButton, all RadioButtons in the same container automatically deselect.

(In contrast, any number of CheckBoxes in a group can be selected at one time. If the user needs able to select more than one option at a time, use CheckBoxes instead of RadioButtons)
