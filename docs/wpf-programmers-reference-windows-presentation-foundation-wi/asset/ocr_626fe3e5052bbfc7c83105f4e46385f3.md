The EditingCommands also makes these editing commands available through code. For the C# code toggles whether the current selection in the RichTextBox named rchBody is of a numbered list:

```
// Toggle the selection's number state.
private void mParaNumber_Click(Object sender, RoutedEventArgs e)
{
    EditingCommands.ToggleNumbering.Execute(null, rchBody);
}
```

Instead of executing an editing command in code-behind, you can indicate that a button or menu item should execute it in the XAML code.

For example, the Command attribute in the following XAML code makes the MenuItem execute the AlignLeft command when it is selected:

```
<MenuItem Name="mnuParaAlignLeft" Header="_Left"
Command="EditingCommands.AlignLeft/>
```
