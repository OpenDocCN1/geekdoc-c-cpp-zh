# ANIMATION ADVICE

Motion is one of the most attention-grabbing effects you can add to a program, but it can also be the most distracting and annoying. A button that flashes bright colors or continually changes size while the mouse is over would really annoy users. The moving highlight that the EllipseButton program displays is subtle so the effect isn't too bad, but careful. Keep animations like this one subtle or make them only once — for example, when the mouse first enters the button, so don't drive your users crazy. In extreme cases, rapidly flashing lights can induce seizures in some people particularly at frequencies between 2 and 55 Hz. Better still, give users a way to disable these sorts of animations. Also note that users with special needs such as color vision deficiency or impairment may not see subtle animations well or at all. Don't rely solely on subtle animations to give the user information.
