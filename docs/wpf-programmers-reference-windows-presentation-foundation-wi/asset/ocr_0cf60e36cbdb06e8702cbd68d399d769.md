# EXAMPLE Using a Frame Bound to a ComboBox

The more interesting XAML code creates a Grid that contains a ComboBox and a Frame. The Frame's Source property is bound to the ComboBox's SelectedItem.Tag value when you pick a new entry from the ComboBox, the Frame displays the corresponding web page.

```
<Grid>
  <RowDefinition Height="35"/>
  <RowDefinition Height="*"/>
  <Grid.Definitions>
    <ComboBox Grid.Row="0" SelectedIndex="0" Name="cSites" Margin="5"/>
    <ComboBox Content="Beginning Database Solutions"
      Tag="http://vb-helper.com/db_design.html"/>
    <ComboBox Content="VB Helper"
      Tag="http://www.vb-helper.com/"/>
    <ComboBox Content="VB Helper Bookstore"
      Tag="http://store.amazon.com/vbhelper/about/"/>
    <ComboBox Content="Books To Keep"
      Tag="http://www.BooksToKeep.com/"/>
    <ComboBox Content="Astronomy Picture of the Day"
      Tag="http://antwerp.grasc.nasa.gov/apod/"/>
  </ComboBox>
</Grid>
<Frame Name="fraGo" Grid.Row="1" HorizontalAlignment="Stretch"
      VerticalAlignment="Stretch" Margin="5"
      Source="{Binding ElementName=cSites, Path=SelectedItem.Tag}">
</Frame>
</Grid>
```

The following C# code makes the Frame named fraGo navigate to the URL http://astore.amazon.com/vbhelper/about:
fraGo.Navigate(new Uri("http://astore.amazon.com/vbhelper/about*\));

# GRIDSPLITTER

The GridSplit lets users resize two adjacent rows or columns in a Grid control (see Table D-12). To use a vertical GridSplit, add a cell to the Grid's first row and set its Grid.RowSpan property so it spans all of the Grid's rows. Next, set its HorizontalAlignment property to Left or Right. That makes the GridSplit stick to the side of its alignment and determines which column it will add. Finally, set the control's Width to something big enough for the user to grab and drag, perhaps 3 or 5.

To make a horizontal GridSplit, switch the roles of the Grid's rows and columns, use the GridSplitter's VerticalAlignment property, and set its Height to a reasonable value.
