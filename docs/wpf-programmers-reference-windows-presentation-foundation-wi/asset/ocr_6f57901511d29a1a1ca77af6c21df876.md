In this bare-framework-and-browser environment, you can create XAML files in a text editor and then look at them in your browser.

If you want to attach program code to your WPF user interfaces, or if you want to build complex applications or XAML Browser Applications (XBAP — pronounced ex-bay), you'll need a programming environment that can write that code. The easiest solution is to install Visual Studio and write code in C# or Visual Basic.

> The programming code examples show how they are written in C# and Visual Basic; versions of the programs are available for download on the book's web site.

Visual Studio attaching code to the WPF user interface practically trivial. The interactive Window Designer is missing lot of functionality, so you often need to write XAML code to get the job done, but the Visual Studio Express Editions come at the unbeatable price of $0. The C# or Visual Basic Express Editions at www.microsoft.com/express.

If you want a more graphic designer-oriented development tool, you can install Expression Blend. It won't help you build code to attach to the interface, but it has some nice features that are missing from Visual Studio. Its support for interactively manipulating WPF objects is more complete than that provided by Visual Studio, and it provides fairly simple editors that let you build simple triggers and animations.

Unfortunately, Expression Blend is far from free. At the time of writing, it costs $499, although you can get a 30-day free trial. You can learn more about Expression Blend at www.microsoft.com/expression/products/Overview.aspx?key=blend.

Of course, the configuration for building WPF applications includes both Visual Studio and Expression Blend. Neither of these tools is perfect, but they cover some of the other's shortcomings.
