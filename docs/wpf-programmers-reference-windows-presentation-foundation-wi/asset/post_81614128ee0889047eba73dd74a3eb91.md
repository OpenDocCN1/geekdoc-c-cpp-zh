# Brushes

This appendix summarizes brushes. A Brush defines the colors used to fill an area such as a Rectangle or Ellipse. Brushes also define the colors used by many controls' Foreground and Background properties.

The following section briefly describes each of the types of Brushes available. The sections that describe each of the Brush types in greater detail.

## BRUSH CLASSES

Table G-1 summarizes the Brush classes.

| BRUSH CLASS | PURPOSE |
| --- | --- |
| DrawingBrush | Fills areas with a drawing. |
| ImageBrush | Fills areas with one or more copies of an image. |
| LinearGradientBrush | Fills areas with a color gradient that shades between two or more colors in a linear direction. |
| RadialGradientBrush | Fills areas with a color gradient that shades between two or more colors radially. |
| SolidColorBrush | Fills areas with a solid color. |
| VisualBrush | Fills areas with a visual. (Loosely speaking, a visual is an object that provides rendering support for WPF. It's basically something that can draw itself such as a control.) |

The Brushes example program shown in Figure G-1 demonstrates these kinds of brushes. The SolidColorBrush fills its Ellipse with dark gray, the LinearGradientBrush shades from white to the top to the bottom, and the RadialGradientBrush shades from white at the middle to black at the edges.

# DRAWINGBRUSH

A DrawingBrush fills areas with a Drawing object.

Table G-2 summarizes the DrawingBrush's most important properties.

TABLE G-2:

| PROPERTY | PURPOSE |
| --- | --- |
| AlignmentX | Determines how the Brush is aligned if the Stretch property is set to None so it doesn't stretch to fill the area |
| AlignmentY | Determines how the Brush is aligned if the Stretch property is set to None so it doesn't stretch to fill the area |
| Drawing | The Brush's content |
| Stretch | Determines how the Brush is stretched to fill its tiles. This can be None (the drawing is used at its original size), Uniform (the drawing is stretched to be as large as possible within the tile), UniformToFill (the drawing is uniformly stretched to fill the tile), and Fill (the drawing is stretched to fill the tile if it distorts the drawing |
| TileMode | Determines how the tile is repeated if necessary to fill the area. This can be None (the rest of the area is unfilled), Tile (the tile is repeated), FlipX (the tile is repeated with every other tile in the X direction flipped horizontally), FlipY (the tile is repeated with every other tile in the Y direction vertically), and FlipXY (both FlipX and FlipY). This only has an effect if Viewport is smaller than the filled area. |
| Viewbox | Defines the part of the content used for the Brush. |
| ViewboxUnits | Defines the units used by Viewbox. This can be Absolute (pixels) or RelativeToBoundingBox [where (0, 0) is the upper-left corner and (1, 1) is the lower right corner]. |
| Viewport | Defines the part of the filled area that is covered by a single tile. |
| ViewportUnits | Defines the units used by Viewport. This can be Absolute (pixels) or RelativeToBoundingBox [where (0, 0) is the upper-left corner and (1, 1) is the lower right corner]. |

# Drawing Types

Table G-3 lists the kinds of Drawing objects you can use to make a DrawingBrush.

| DRAWING TYPE | PURPOSE |
| --- | --- |
| DrawingGroup | Contains a group of other Drawing objects. |
| GeometryDrawing | Draws shapes. |
| GlyphDrawing | Draws text. |
| ImageDrawing | Draws an image. |
| VideoDrawing | Draws a video file. |

> EXAMPLE Using DrawingBrushes

The following code shows how the Brushes program in Figure G-1 creates its DrawingBrush:

```xml
<Ellipse Grid.Row="0" Grid.Column="0" Stroke="Black">
  <Fill>
    <DrawingBrush TileMode="Tile" Viewbox="0,0,1,1" Viewport="0,0,0.3,0.5" ViewportUnits="RelativeToBoundingBox">
      <DrawingBrush.Drawing>
        <GeometryDrawing.Geometry>
          <GeometryGroup>
            <PathGeometry>
              <PathFigure IsClosed="True" StartPoint="10,0">
                <PolyLineSegment Points="20,10 10,20 0,10"/>
              </PathFigure>
            </PathGeometry>
          </GeometryGroup>
        </GeometryDrawing.Geometry>
        <GeometryDrawing.Pen>
          <Pen Thickness="2">
            <LinearGradientBrush StartPoint="0,0" EndPoint="0,1">
              <GradientStop Offset="0.0" Color="Black" />
              <GradientStop Offset="0.5" Color="White" />
              <GradientStop Offset="1.0" Color="Black" />
            </LinearGradientBrush>
          </Pen>
        </GeometryDrawing.Pen>
      </GeometryDrawing>
      </DrawingBrush.Drawing>
    </DrawingBrush>
  </Fill>
</Ellipse>
```

The code starts an Ellipse object and creates the Brush in the Ellipse.Fill element attribute. The Brush uses TileMode = Tile so it will repeat as needed.

The property Viewbox = 0,0,1,1 makes the Brush use the entire drawing area for its content. (By default, ViewboxUnits = RelativeToBoundingBox.)

The code sets Viewport = 0,0,0.3,5 and ViewportUnits = RelativeToBoundingBox the first tile fills are a third of the Ellipse's area.
