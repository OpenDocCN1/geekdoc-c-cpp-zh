The example program shown in 23-7 demonstrates the different kinds of lights. Each scene shows a yellow square (the corners cropped by the edges of the viewport) made up of lots of little triangles.

The ambient light shines on every surface with the same intensity every triangle appears yellow. This light is bright because it could produce an brightly result if it were gray. Usually ambient light is even darker than this and is only intended to display surfaces that are not illuminated by any other light. The following code shows how the program makes AmbientLight:

```
<AmbientLight Color="LightGray"/>
```

The directional light shines at an angle to the square. Because all of the square's triangles lie in the same plane, they all make the same angle with respect to the directional light, so they all show the same color. The light shines at an angle to the square, so square isn't as bright as light. The following code shows how the program makes its DirectionalLight:

```
<DirectionalLight Color="White" Direction="-1, -1, -1"/>
```

The point light is located just above the middle of the square. The light is shining directly on the triangles sitting below it, so they are the brightest. Light shining on triangles to the sides those triangles at an angle, so those triangles are not lit as brightly. The following code shows how the program makes its PointLight:

```
<PointLight Color="White" Position="0.0, 0.5, 0.0"/>
```

If you look closely at Figure 23-7, you will see that there is an area of uniform brightness directly below the spot. This area is the light's inner cone and is defined by the light's InnerConeProperty. Outside the inner cone, the light intensity drops off until it reaches the edge of the light's outer cone, which is defined by the OuterConeProperty. The following code shows how the program makes its SpotLight:

```
<SpotLight Color="White" Position="0, 2.0, 0" Direction="0, -1, 0" InnerConeAngle="10" OuterConeAngle="40" Range="10"/>
```

Usually a scene includes ambient light so the user can see all of the objects.

Often you will need to use additional lights, particularly if multiple objects in the scene have the same color. If you don't use multiple lights, objects with the same color will tend to blend together, so you can't tell where one ends and the next begins.
