In fact, there's a kernel of truth in each of these attitudes. WPF does include a new set of controls largely replace the Windows Forms controls. The libraries you need to run WPF applications are installed by Vista and Windows 7, so it is sort of a thing, although you can run WPF applications in Windows XP and certainly in future versions of WPF (and even UNIX some day). WPF applications can use XAML to build interfaces, and XAML is all you really need to write loose web pages; but there's more to WPF than just XAML.

Again, the truth lies between these two extremes. You can abuse WPF to build completely unusable interfaces full of bouncing buttons, skewed video, stretched labels, garish colors, and rotating three-dimensional (3D) graphics. You can add animation to the controls until the interface like a video game than a business application.

This program demonstrates some interesting techniques but goes overboard with gratuitous animation, displaying a spinning invoice area, animated buttons, and sound effects. If you think it's ugly in this book, you should see how annoying it is when you run it!
