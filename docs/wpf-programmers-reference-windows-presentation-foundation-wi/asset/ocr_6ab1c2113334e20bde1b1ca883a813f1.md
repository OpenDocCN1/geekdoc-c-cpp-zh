# NEW PROJECTS

Starting a WPF project in Visual Studio is easy. Open the File menu and select New Project to display the New Project dialog shown in Figure 2-1.

![](bbox=[0.095, 0.191, 0.595, 0.452])

FIGURE 2-1

Select the type of project that you want to build. If you want to use C# to build a stand-alone application, select “WPF Application” as shown in Figure 2-1. If you want to build a XAML Browser Application (XBAP), select “WPF Browser Application."

Note that Expression Blend 3 cannot open projects created for .NET Framework version 4, at least as of this writing. If you want to edit the project with Expression 3, a .NET Framework version that it can understand as 3.5. In Figure 2-1, the Framework version is circled in red.

> ALL MAY NOT BE AS IT APPEARS

The exact appearance of the New Project dialog shown in Figure 2-1 and where menus appear depend on how you have Visual Studio configured. For example, in Figure 2-1 it is assumed that Visual Studio is configured for C# development. If it is configured for Visual Basic, then Visual Basic will be listed as the first category, and C# will appear in the “Other Languages” category.

Also depending on the version of Visual Basic you have and how it is configured, your development environment may not look exactly the same as mine. Windows may be moved to new locations or hidden, and even menus may be rearranged. You may need to spend a little time searching through Visual Studio to find something, but it should all be there somewhere.
