# Transformed Gradient Brushes

More advanced options let you change the appearance of gradient brushes. Particularly useful brush tool is the Transform tool. This tool looks like a arrow in the Control Toolbox and is shown in the model of Figure 3-9.

If you select this tool and click on a control that uses a brush, the Window Designer displays an arrow that lets the brush's geometry.

In Figure 3-10, the rectangle on the left is filled with a linear gradient brush. The arrow shows the brush's direction.

![](bbox=[0.653, 0.301, 0.936, 0.439])

FIGURE 3-9

When the Brush Transform is active for a linear gradient brush, you can use the mouse to:

+   - Grab the middle dot and move the whole arrow without rotating it.
- Grab the arrow's head or tail and move it.
- Hover beyond either end of the arrow to get a rotation pointer. Then click-and-drag to rotate the arrow without moving it.

When the Brush Transform is active for a radial gradient brush, you can use the mouse to:

+   - Drag the arrow's tail to change where the first color begins.
- Drag the small white grab handles to resize the brush. (For example, you could make it shorter and wider).
- Drag the brush's edge to move the whole brush without otherwise changing it.
- Hover beyond a side's grab handle to get a rotation pointer. Then click-and-drag to rotate the brush without moving it.
