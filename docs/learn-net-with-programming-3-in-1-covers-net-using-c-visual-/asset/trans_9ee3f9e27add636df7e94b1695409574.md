## WSDL 文档

Web 服务是自描述的，这意味着 ASP.Net 本身以 WSDL 文档的形式向客户端提供使用 Web 服务所需的全部信息。WSDL 文档告诉客户端 Web 服务中存在哪些方法，以及方法使用的参数和返回值，以及客户端应用程序如何与它们通信。WSDL 是一种 XML 标准。
