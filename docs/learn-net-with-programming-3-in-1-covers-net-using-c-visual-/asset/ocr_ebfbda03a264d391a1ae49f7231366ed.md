Example:

```
Class Car
{
    Private string model = "Mustang";
    Static void Main(string[] args)
    {
        Car myobj = new Car();
        Console.writeline(myobj.model);
    }
}
```

The output will be:

Mustang

# Public Modifier

If you declare a field with a public access modifier, it is accessible for all classes:

# Example:

```
Class Car
{
    Public string model = "Mustang";
```
