# 2.20 Parameters and Arguments

Information can be passed to methods as parameter. Parameters act as variables inside the method. They are specified after the method name, inside the parentheses. You can add as many parameters as you want, just separate them with a comma.

The following Example: has a method that takes a string called fname as parameter. When the method is called, we pass along a first name, which is used inside the method to print the full name:

# Example:

```
Static void mymethod(string fname)
{
    Console.writeline(fname + " Refsnes");
}
```

```
Static void Main(string[] args)
{
    Mymethod("Liam");
    Mymethod("Jenny");
    Mymethod("Anja");
}
```
