## Implementation of Web Services in ASP.NET Applications.

### Create Web Service

A simple .asmx page is known as Web Service. For the creation of the Web Service, we will use Visual Studio 2017, which uses the .NET Framework 4.8. For creating the Web Service, we will follow the following steps:

**Step 1:** Firstly, we will create a Web Application for creating the Web Service.

For that, we will click on the File -> New -> Project as shown in the below screenshot:

![](img/e7ca4af023a4148a909dd82c11f81893_345_0.png)

After that the new window will open as shown in the below screenshot:

![](img/e7ca4af023a4148a909dd82c11f81893_346_0.png)

After this a new window will be shown to us as shown below:

![](img/e7ca4af023a4148a909dd82c11f81893_346_1.png)

For creating the Web Service, we will right-click on the project **Name -> Click on Add -> Add New Item**. As shown in the below screenshot:

![](img/e7ca4af023a4148a909dd82c11f81893_347_0.png)

After this, a new window will appear. From there, we have to click on Web -> Select Web Service (.asmx page) -> Give a name to the Web Service as shown in the below screenshot:

![](img/e7ca4af023a4148a909dd82c11f81893_348_0.png)

After adding the Web Service to the application, a new window will appear, which is shown below:

![](img/e7ca4af023a4148a909dd82c11f81893_348_1.png)

Direct method overloading is not supported by the Web Service. To allow method overloading in the Web Service, we have to add the MessageName property to differentiate one method used in the Web Service from the other method, which has the same name and uses parameters.

`[WebServiceBinding(ConformsTo = WsiProfiles.BasicProfile1_1)]` to `[WebServiceBinding(ConformsTo = WsiProfiles.None)]`

```csharp
[WebMethod]
public int sumofnums(int firstnumber, int secondnumber)
{
    return firstnumber + secondnumber;
}

// Here we will use MessageName property to do the differentiation between both of the methods.
[WebMethod(MessageName = "sumoffloats")]
public float sumofnums(float firstnumber, float secondnumber)
{
    return firstnumber + secondnumber;
}
```

If we want to call the Web service from the Script, we will use ASP.NET AJAX and uncomment the below line.

```csharp
[System.Web.Script.Services.ScriptService]
[WebMethod]
```

This attribute is always used at the top of the method. We write this attribute in the Web Service. The [WebMethod] attribute is used to define that the method using this attribute is exposed to the user/client access.

If we remove this attribute, in that case, the client will not be able to see the details of the method; hence they cannot implement it.

### Markup

In the Service1.asmx, we will see that the Service uses the WebService directive with the attribute. From here, this shows us that the application invokes the Service, not the end-user. Hence the asmx page has no markup.

### Service1.asmx

```aspx
<%@ WebService Language="C#" CodeBehind="Service1.asmx.cs" Class="webapplication7.Service1" %>
```

Here are some points about the Service1.asmx.

- **"Web Service" directive:** This directive shows that the asmx page is a web service.
- **"Language"="C#":** This indicates that the C# language is used for the Service.
- **"codebehind":** This property has no role with the ASP.NET or web service. CodeBehind is a property of Visual Studio. This property is used to map the asmx page with the code-behind page.
- **"Class" property:** It contains the qualified name of the class. This is the entry point of the Service, just like the `main()` in C language.
