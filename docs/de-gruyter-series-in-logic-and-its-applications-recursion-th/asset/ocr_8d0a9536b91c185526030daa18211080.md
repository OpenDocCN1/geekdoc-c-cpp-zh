Theorem 13.1.3 is useful as a basic tool for hyperarithmetic measure theory.

# 13.1.2 Measure-theoretic uniformity

# **Theorem 13.1.4** (Sacks [120]). $\{x \mid \omega_1^{\text{CK}, x} = \omega_1^{\text{CK}}\}$ has measure 1.

Proof. By Theorem 5.15, it is sufficient to prove that the set

$\{x \mid \mathfrak{A}(\omega_1^{\text{CK}, x}) = \Delta_1^1\text{-comprehension}\}$

has measure 1. Let $(\langle \varphi_i, \psi_i \rangle)_{i < \omega}$ be a recursive enumeration of arithmetical formulas.

For each $i$, define the $\Pi_1^1$-set

$A_i = \{x \mid \mathfrak{A}(\omega_1^{\text{CK}, x}) \ni x = (\forall n) \exists y (\varphi_i(n, y) \lor \neg \psi_i(n, y)) \}$.

Let

$A_{i, \beta} = \{x \mid \mathfrak{A}(\omega_1^{\text{CK}, x}) \ni x = (\forall n)(\exists \beta') (\varphi_i(n, y^\beta) \lor \neg \psi_i(n, y^\beta)) \}$.

Then $A_{i, \beta} \subseteq A_i$ for all $i < \omega$ and $\beta < \omega_1^{\text{CK}}$. By Corollary 13.1.2, for any $i, j < \omega$, there is a $\beta_{i, j} < \omega_1^{\text{CK}}$ such that $\mu(A_i \setminus A_{i, \beta_{i, j}}) < 2^{-i-j}$. Moreover, for any $j < \omega$ and $x \notin \bigcup_{i < \omega} (A_i \setminus A_{i, \beta_{i, j}})$, we have $\mathfrak{A}(\omega_1^{\text{CK}, x}) = A_i - \text{comprehension}$. Then for any $j$,

$\mu(\{x \mid \mathfrak{A}(\omega_1^{\text{CK}, x}) = \Delta_1^1\text{-comprehension}\}) \ge 1 - \sum_{i < \omega} 2^{-i+j} \ge 1 - 2^{-j+1}$.

Thus

$\mu(\{x \mid \mathfrak{A}(\omega_1^{\text{CK}, x}) = \Delta_1^1\text{-comprehension}\}) = 1$.

Theorem 13.1.4 is somewhat counterintuitive since it is much easier to construct a real hyperarithmetically computing the hyperjump. The theorem may also be viewed as one more piece of evidence to support the randomness thesis since the set of reals hyperarithmetically computing 0 has measure 0.
