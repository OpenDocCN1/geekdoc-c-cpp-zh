The following basic facts follow immediately from the definition of forcing.

# **Proposition 5.4.3.** For $p \Vdash \text{sentence } \varphi$,

+   (i) $(\forall p)(p \Vdash \varphi \lor \psi \Vdash \neg \varphi)$;
+   (ii) $(\forall p)(\exists q \leq p)(q \Vdash \varphi \lor q \Vdash \neg \phi)$;
+   (iii) $(\forall p)(\forall q \leq p)(p \Vdash \varphi \Rightarrow q \Vdash \varphi)$.

Analyzing the complexity of $\Vdash$ defined above is not a straightforward matter. The difficulty is that Steel forcing, unlike Cohen forcing, is essentially a form of "class forcing". Because of tagging, the forcing conditions range over the entire $L_a$. This makes the complexity of the statement "$p \Vdash \neg \varphi$" harder to determine. Our major effort is then to handle this problem.

# **Definition 5.4.4.** Suppose that $p, q$ are conditions and $\gamma < \alpha$. Then $\text{Ret}(\gamma, p, q)$, a retagging of $q$ by $p$, holds if and only if

+   - $t_p = t_q$;
+   - $(\forall o)((h_p(o) < \gamma \lor h_q(o) = 0 \lor h_q(o) = 0) \rightarrow h_p(o) = h_q(o))$, and
+   - $(\forall o)(h_p(o) \geq \gamma \rightarrow h_q(o) \geq \gamma)$.

We will use retagging to reduce a complex condition with a simpler condition while preserving the forcing relation.

# **Lemma 5.4.5.** If $\gamma_0 < \gamma_1 < \alpha$ and $\text{Ret}(\gamma_1, p, q)$, then

$(\forall p_1 \leq p)(\exists q_1 \leq q)\text{Ret}(\gamma_0, p_1, q_1)$.

# **Proof.**

The reason for working $\gamma_0$ and $\gamma_1$ is to set aside some space to do the retagging. Assume that $\gamma_0 < \gamma_1 < \alpha$ and $\text{Ret}(\omega \gamma_1, p, q)$. Let $p_1 \leq p$. Define $q_1$ as follows:

+   Set $t_q = t_p$, and
+   Case (1) $\sigma \in t_q$ and $h_q(\sigma) < \omega \gamma_0$. Let $h_{q_1}(\sigma) = h_q(\sigma)$;
+   Case (2) otherwise. Let $h_{q_1}(\sigma) = \omega \gamma_0 + t_{q_1 \alpha, \sigma}$ where $t_{q_1 \alpha, \sigma} = \{ \tau \geq \sigma \mid \tau \restriction t_{q_1 \alpha} \}$.
+   We leave it to the reader to verify that $q_1$ is as required.

It is not difficult to see that there is a one-one $\Delta_1(L_a)$-function $f : \{ \varphi \mid \varphi \text{ is ranked} \} \to \alpha$ such that if the rank of $\varphi$ is less than that of $\psi$, then $f(\varphi) < f(\psi)$.

# **Lemma 5.4.6.** Iff($\varphi$) = $\gamma$ and $\text{Ret}(\gamma, p, q)$, then $p \Vdash \varphi \leftrightarrow q \Vdash \varphi$.

# **Proof.**

We prove the lemma by induction on ordinals. The only nontrivial case is when $\varphi$ is of the form $\neg \psi$ and $f(\psi) < f(\varphi)$. Suppose $\text{Ret}(\alpha \gamma, p, q)$ where $f(\varphi) = \gamma$. If $p \Vdash \neg \varphi$ but $q \not\Vdash \neg \varphi$, then $(\exists p_1 \leq p)(p_1 \Vdash \varphi)$ but $(\exists q_1 \leq q)(q_1 \Vdash \neg \varphi)$. By Lemma 5.4.5, there is a $p_2 \leq p$ such that $\text{Ret}(\omega p_1, p_2, q_1)$ where $f(\psi) = \gamma_1 < \gamma$. By induction, $p_2 \Vdash \varphi$, a contradiction. Hence $p \Vdash \neg \varphi \leftrightarrow q \Vdash \neg \varphi$. A similar argument shows that $q \Vdash \varphi \to p \Vdash \varphi$.

# **Theorem 5.4.7.** The set $(\{p, \ulcorner \varphi \urcorner \} \mid p \Vdash \varphi \land \varphi \text{ is ranked})$ is $\Delta_1(L_a)$.
