For every real s, choose \(x_s \in A\) such that \(x_s \ge_T s\). Then for the \(<_T\)-least real \(y \in A\) above \(x_s\), there is a \(z\) coding \(\{x \mid x <_L y \wedge x \in A\} = \{x \mid x <_T y \wedge x \in A\}\) so that \(P(z, y)\) holds. Obviously \(x'_s \le_T z \le_T O^y\). By the definition of P,

\(O^{x'} \le_T O^{y'} \le_T \Sigma y,\)

and \((y)_1 = z\). Thus

\(\{(y)_1)_n \mid n \in \omega\} = \{r \mid r \le_T x \wedge r \in A\}.\)

Since \(x'_s \le_T r\) for all \(r \in A\) with \(r \le_T x'_s\), we have \(x'_s \le_T (y)_1)_n\) for all \(n \in \omega\). Hence

\(F(x'_s) = y.\)

Thus the function \(F\) is \(M\)-incomparable with the function \(G\) where \(G(x) \equiv_T x'\) for every \(x\).

Assume ZF + DC + AD. By Lemma 7.14, if \(F\) is uniformly degree invariant and nonincreasing on a cone, then \(F(x) <_T x\) on a cone \(C = \{x \mid x \ge_T z_0\}\) for some \(z_0\). We show that this also fails for \(\Pi_1^1\)-functions under \(V = L\).

# **Theorem 8.4.2.** Assume \(V = L\). There is a uniform degree invariant, nonincreasing \(\Pi_1^1\)-function \(F\) such that \(F(x)|_T x\) on a cone. In particular, \(F\) is not constant on a cone.

**Proof.** Let \(A\) be the \(\Pi_1^1\)-set as constructed in Theorem 8.4.1. Define \(F(x) = y\) if and only if there is a real \(z \equiv_T y'\) such that

+   (1) \(z \in A\);
+   (2) the degree of \(y\) is minimal;
+   (3) \(y = O_e^x\) for some \(e\) such that for all \(i < e\), if the degree of \(\Phi_i^x\) is minimal then \((\Phi_i^x)' \# z\), and
+   (4) \(x >_T 0 \Rightarrow (\forall n)(x \le_T (z)_1)_n)\).

We leave it to the reader to verify that \(F\) is the desired counterexample.

By Lemma 7.2.4, ZF + AD + DC implies that \(\le_M\) is a well-ordering on the set of increasing uniform degree invariant functions. This again fails under the assumption \(V = L\).

# **Theorem 8.4.3.** Assume \(V = L\). There is a sequence of uniform degree invariant, increasing, \(\Pi_1^1\)-functions \(\{f_n\}_{n < \omega}\) such that \(F_{n+1} <_M F_n\) for all \(n\). Thus \(<_M\) is not a prewellordering.

**Proof.** Define \(P(x, y)\) by

\(y \in L_{\omega_1^y}(y) \omega = x \wedge (y)_1 \text{ is the } <_L \text{-least such that}\)
\((y)_1 \le_T (y)_0 \wedge y \equiv_T (y)_0 (\omega \oplus (y)_1 \oplus (y)_2)'.\)

Clearly \(P(x, y)\) is a \(\Pi_1^1\)-cofinally progressive relation. By Theorem 8.2.4, there is a \(\Pi_1^1\)-set \(A\) with the property prescribed by P.

By the definition of P, every real is Turing below some element of \(A\) and \(<_T\) is a well-ordering consistent with \(<_L\) on \(A\).
