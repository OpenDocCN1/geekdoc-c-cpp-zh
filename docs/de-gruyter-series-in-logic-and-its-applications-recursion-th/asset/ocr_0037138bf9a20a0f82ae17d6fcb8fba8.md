Proof. Suppose that \( T \subseteq \omega^{<\omega} \) is a recursive tree with an infinite path. Note that the set \( S = \{ \sigma \in T \mid (\exists y > \sigma)(\forall n)(y \mid n \in T) \} \subseteq T \) is a nonempty \(\Sigma^1_1\) tree without dead ends and so recursive in \( 0 \). Since \( T \) has an infinite path, so does \( S \). Hence, the leftmost infinite path \( x \) in \( S \) is recursive in \( 0 \).

Thus the collection of reals recursive in \( 0 \) is a basis for recursive trees in \(\omega^{<\omega}\), while the set of hyperarithmetic reals is not:

# **Proposition 2.5.2.** There is a recursive tree \( S \subseteq \omega^{<\omega} \) with uncountably many infinite paths but without a hyperarithmetic infinite path.

Proof. By Corollary 2.2.2, the set \( A \) of non-hyperarithmetic reals is \(\Sigma^1_1\). Then there is a recursive tree \( T \subseteq 2^{<\omega} \times \omega^{<\omega} \) such that for any \( x \in 2^\omega \), \( x \in A \) if and only if there exists a \( y \) satisfying \( (\forall n)((x \mid n, y \mid n) \in T) \). Let \( S \subseteq \omega^{<\omega} \) be a recursive tree such that \( \sigma \in S \) if and only if \( (\sigma_0, \sigma_1) \in T \) where \( \sigma_0(n) = \sigma(2n) \) and \( \sigma_1(n) = \sigma(2n + 1) \) for all \( n \) which makes sense for the \( \sigma \)’s. Then for any infinite path \( x \in [S] \), \( x = x_0 \oplus x_1 \) so that \( x_0 \in A \). In other words, every infinite path in \( S \) Turing computes a nonhyperarithmetic real. Moreover, by the definition of \( A \), every nonhyperarithmetic real is recursive in an infinite path in \( S \). Hence \( S \) contains uncountably many infinite paths.

# **Theorem 2.5.3 (Gandy [33]).** If \( A \) is \(\Sigma^1_1\) and nonempty, then \( A \) contains a real \( x \) such that \( \omega^x_1 = \omega^{CK}_1 \) and \( x \le_T 0 \).

Proof. By Corollary 2.2.2, the set \( B = \{ x \oplus y \mid y \not\le_h x \wedge x \in A \} \) is also a \(\Sigma^1_1\) nonempty set. By Lemma 2.5.1, there is a real \( x \oplus y \in B \) and \( x \oplus y \le_T 0 \). Hence \( x \in A \) is recursive in \( 0 \). Since \( y \not\le_h x \), we have \( x \not\ge_h 0 \). By Theorem 2.4.7, \( \omega^x_1 = \omega^{CK}_1 \).

Theorem 2.5.3 is known as the Gandy Basis Theorem.

# 2.5.2 Incomparable hyperdegrees

We apply the Gandy Basis Theorem to construct a pair of incomparable hyperdegrees.

# **Lemma 2.5.4.** If \( A \) is a \(\Sigma^1_1\)-set containing a nonhyperarithmetic real, then \( A \) is uncountable.

Proof. Suppose that \( A \) is a countable \(\Sigma^1_1\)-set containing a nonhyperarithmetic real. Then the set \( B = \{ x \in A \mid x \not\le_h 0 \} \) is a nonempty \(\Sigma^1_1\)-subset of \( A \). Hence there is a recursive tree \( T \) such that \( x \in B \) if and only if there exists a \( y \) satisfying for every \( n \), \( (x \mid n, y \mid n) \in T \). Let \( T' = \{ (\sigma, \tau) \mid (\exists x \supset \sigma)(\exists y \supset \tau)(\forall n)((x \mid n, y \mid n) \in T) \} \) be a subtree of \( T \). Obviously \( T' \) is \(\Sigma^1_1\)-tree. Moreover, for any \( (\sigma, \tau) \in T' \), there are \( \sigma_0, \sigma_1 > \sigma \) and \( \tau_0, \tau_1 > \tau \) with \( (\sigma_0, \sigma_1) \in T' \) for \( i \le 1 \). Otherwise, the \(\Sigma^1_1\)-set \( \{ x \mid (\exists y)((\forall n)(x \supset \sigma \wedge y \supset \tau, y \in T)) \} \subseteq B \) contains a unique real which must be hyperarithmetic, contradicting the definition of \( B \). Thus imitating the proof of Theorem 11.10, one shows that \( B \) contains a perfect subset.
