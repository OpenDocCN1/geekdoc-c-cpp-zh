# Theorem 8.3.2 (Chong and Yu [15]). Assume \((\omega_1)^L = \omega_1\). There is a \(\Pi^1_1\)-maximal chain in the Turing degrees.

Proof. By Lemma 8.3.1, P is a \(\Delta^1_1\)-cofinally progressive relation. Hence by Theorem 8.2.4, there is a \(\Pi^1_1\)-set A as prescribed. J(ii) implies that A is a maximal chain.

# 8.3.2 Antichains in the Turing degrees

Given a partial ordering \((P, <_P)\), a set \(A \subseteq P\) is an *antichain* if any distinct \(x, y \in A\) are \(<_P\)-incomparable. A is *maximal* if it is not a proper subset of an antichain.

Define a binary relation P(x, y) to hold if either (1) or (2) below is satisfied:

+   1. There exist \(n \neq m\) such that \((x)_n \neq (x)_m\) but \((x)_n\) is Turing comparable with \((x)_m\);
+   2. \(|(x)_n \in e \cup y|\) is an antichain such that
+      (2a) \(x \oplus y) \in L_{\omega_1^{x,y}}\),
+      (2b) \(|(x)_n \in e \cup y| (y)_0)\) is an antichain, and
+      (2c) for every \(r <_L y\), \((x)_n \mid n \in \omega) \cup \{r\}\) is not an antichain.

# Lemma 8.3.3. If \(2^\omega = (2^\omega)^L\), then P is a cofinally progressive relation.

Proof. Fix \(y_0\). Given x, let \(X = \{(x)_n \mid n \in \omega\}\). Assume that the set \(X \cup \{y_0\}\) is an antichain of Turing degrees. We show that for any \(y_1 \ge_T (x \oplus y_0)''\), there is a z such that

+   1. \(z'' \ge_T y_1\),
+   2. \(y_0 \le_T z \le_T y_1\),
+   3. \(X \cup \{z\}\) is an antichain.

Then given a constructible \(y_{-1}\) and a countable antichain \(X \cup \{y_0\}\) such that for every \(r <_L y_0\), \(X \cup \{r\}\) is not an antichain, by Proposition 4.3.4, there is a \(y_1 \ge_T (y_{-1} \oplus X \oplus y_0)''\) such that \(y_1 \in L_{\omega_1^{y_1}}\). Then by (1)-(3) above, there is a z such that \(z \equiv_T y_1\) (and hence \(y_0 \notin z \in L_{\omega_1^{y_0,x}}\)) and \(X \cup \{z\}\) is an antichain. Thus \(|z \mid P(x, y_0 \oplus z)|\) is cofinally progressive.

We construct a real z such that \((z \oplus x)_0'' \ge_T y_1\) and the following requirements are satisfied:

```
\(N_{e,i} : \Phi_e^{z \oplus y_0}_i \text{ is total} \Rightarrow \Phi_e^{z \oplus y_0}_i \neq \langle x \rangle_i.\)
```

Then \(X \cup \{z \oplus y_0\}\) is an antichain. The real z is obtained as the union of a sequence of finite strings \(\sigma_0 < \sigma_1 < \cdots\).
