# 2.2.3 Parametrization of \(\Delta^1_1\)-sets

As a first application of the results above, we demonstrate a parametrization of \(\Delta^1_1\)-reals.

# Proposition 2.2.11. There is a partial function \(D : \omega \times \omega \rightarrow \omega\) with a \(\Pi^1_1\)-graph \(G^D\) such that for all x, \(x \in \Delta^1_1 \Leftrightarrow (\exists m)(\forall i)(\forall j)(x(i) = j \mapsto (m, i, j) \in D)\).

Proof. Define \(D = \{\langle n, e, i, j \rangle | n \in O \wedge \Phi^{H^x}_e \text{ is total} \wedge \Phi^{H^x}_e(i) = j\}\). By Theorem 2.2.6, for all x, \(x \in \Delta^1_1 \Leftrightarrow (\exists m)(\forall i)(\forall j)(x(i) = j \mapsto (m, i, j) \in D)\). Moreover, \(\langle n, e, i, j \rangle \in D \Rightarrow n \in O \wedge (\forall z)(H(n, z) \wedge \Phi^z_e \text{ is total} \rightarrow \Phi^z_e(i) = j)\), where H is as defined in § 2.1.2. Hence \(G^D\) is \(\Pi^1_1\).

Proposition 2.2.11 may be applied to reduce certain \(\Sigma^1_2\)-predicates to \(\Pi^1_1\).

# Corollary 2.2.12. For any \(\Pi^1_1\)-predicate P(x, y), the predicate Q(y) \(\Leftrightarrow (\exists x \in \Delta^1_1)P(x, y))\) is \(\Pi^1_1\).

Proof. By Proposition 2.2.11, Q(y) \(\Leftrightarrow (\exists x \in \Delta^1_1)P(x, y)\) is equivalent to

```
\((\exists m)(\forall i)[\exists j((m, i, j) \in D) \land (\forall x)(\forall i)(\forall j)(\chi(i) = j \mapsto (m, i, j) \in D) \rightarrow P(x, y))].\)
```

Note that for each m, if \((\forall i)(\exists j)((m, i, j) \in D)\), then the predicate \((m, i, j) \in D\) is \(\Delta^1_1\). Hence Q is \(\Pi^1_1\).
