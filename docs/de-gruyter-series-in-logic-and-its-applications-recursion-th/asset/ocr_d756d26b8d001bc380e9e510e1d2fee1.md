By the \(\Pi_1^1\)-Uniformization Theorem (4.2.1), there is a total \(\Pi_1^1\) and so \(\Delta_1^1\)-function \(f : \{q \mid q \le p\} \times \omega \to \omega\) such that \(f(q, n) = m\) if and only if \(m \in O_1\), and there is an \(r \le q\) with \(r \Vdash (\exists z^{[\omega]})(\varphi(n, z^{[n]}) \lor \psi(n, z^{[n]})).\) Let \(S\) be the range of \(f\).

By Theorem 5.2.2, \(f\) is a well-defined \(\Pi_1^1\)-function. Since \(f\) is total on its domain, it is \(\Delta_1^1\). By Corollary 1.5.2, there is an \(n_0 \in O_1\) such that for any \(m \in S, m <_O n_0\). Then

\((\forall q \le p)(\forall n)(\exists r \le q)(r \Vdash (\exists z^{[\omega]})(\varphi(n, z^{[n_0]}) \lor \neg \psi(n, z^{[n_0]})).\)

Hence

\((\forall n)(\forall q \le p)(q \Vdash \neg (\exists z^{[n_0]})(\varphi(n, z^{[n_0]}) \lor \neg \psi(n, z^{[n_0]})).\)

and so

\((\forall n)p \Vdash \neg (\exists z^{[n_0]})(\varphi(n, z^{[n_0]}) \lor \neg \psi(n, z^{[n_0]})).\)

Since \(x > p\), by Theorem 5.2.4,

\(\mathfrak{A}(\omega_1^{\text{CK}}, x) \Vdash (\forall n)(\exists z^{[n_0]})(\varphi(n, z^{[n_0]}) \lor \neg \psi(n, z^{[n_0]})).\)

Let \(y\) be such that \(n \in y\) if and only if \(\mathfrak{A}(\omega_1^{\text{CK}}, x) \Vdash (\exists z^{[n_0]})(\varphi(n, z^{[n_0]}).\) Then \(y \in \mathfrak{A}(\omega_1^{\text{CK}}, x).\) Now if \(n \in y,\) then \(\mathfrak{A}(\omega_1^{\text{CK}}, x) \Vdash (\exists z)(\varphi(n, z).\) If \(n \notin y,\) then \(\mathfrak{A}(\omega_1^{\text{CK}}, x) \Vdash (\exists z^{[n_0]})(\neg \psi(n, z^{[n_0]}).\) Then by assumption, \(\mathfrak{A}(\omega_1^{\text{CK}}, x) \Vdash (\forall z) \neg \varphi(n, z).\) Thus \(\mathfrak{A}(\omega_1^{\text{CK}}, x)\) satisfies \(\Delta_1^1\)-comprehension.

# Corollary 5.2.6. If \(x\) is Cohen generic, then

+   (i) \(\omega_1^x = \omega_1^{\text{CK}}.\)

+   (ii) For any real \(y \le_{sh} x,\) there is an \(n \in O\) such that \(y \le_T x \oplus H_n.\)

Proof. Theorem 5.2.5 and Theorem 5.1.5 give (i) as an immediate consequence.

For (ii), suppose \(y \le_{sh} x.\) Then by Corollary 5.1.4 and (i), \(y \in \mathfrak{A}(\omega_1^{\text{CK}}, x).\) By Theorem 5.24, there is a ranked formula \(\varphi\) such that for any \(k, y(k) = 1 \Leftrightarrow (\exists m)(x \mid m \Vdash \varphi(k))\) and \(y(k) = 0 \Leftrightarrow (\exists m)(x \mid m \Vdash \neg \varphi(k)).\) By Theorem 5.2.2,

\(R(p, k, i) \equiv (i \wedge 1 \wedge p \Vdash \varphi(k)) \vee (i = 0 \wedge p \Vdash \neg \varphi(k))\)

is \(\Pi_1^1\). Since \(O\) is \(\Pi_1^1\) complete (Theorem 1.5.1), there is a recursive function \(f : 2^{<\omega} \times \omega \times 2 \to \omega\) such that \(f(p, k, i) \in O\) if and only if \(R(p, k, i)\) holds.

Define \(R^* \subseteq \omega \times 2 \times \omega\) so that \(R^*(k, i, n)\) if and only if \(n \in O\) and there is an \(m\) with \(f(x \mid m, k, i) = n.\) Then \(R^*\) is \(\Pi_1^1(x).\) By Theorem 4.2.1, there is a total \(\Pi_1^1(x),\) hence \(\Delta_1^1(x),\) function \(h : \omega \to 2 \times \omega\) uniformizing \(R^*.\) Thus Range(\(h\)) is a \(\Delta_1^1(x)\)-set. By (i) and Corollary 1.5.2, there is an \(n_0 \in O\) such that Range(\(h\)) \(\subseteq 2 \times O_{n_0}.\) Hence for any \(k, y(k) = 1 \Leftrightarrow (\exists m)(f(x \mid m, k, 1) \in O_{n_0}),\) and \(y(k) = 0 \Leftrightarrow (\exists m)(f(x \mid m, k, 0) \in O_{n_0}).\) It follows that \(y \le_T x \oplus O_{n_0},\) and hence there is an \(n \in O\) such that \(y \le_T x \oplus H_n.\)

From the topological point of view, a Cohen generic real is one which meets all definable dense open sets. Thus the set of such reals is co-meager. In Chapter 14, we will develop a parallel notion of forcing based on the co-null property.
