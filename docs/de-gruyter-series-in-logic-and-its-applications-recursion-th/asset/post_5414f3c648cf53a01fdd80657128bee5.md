
## Definition 10.3.5.
The degree structure $(\mathscr{P}_h, \le)$ is *biinterpretable* with second order arithmetic if $R^*$ is definable in $(\mathscr{P}_h, \le)$.

The intuition is as follows: It is immediate that $(\mathscr{P}_h, \le)$ can be “interpreted” in the standard model of second order arithmetic $\mathcal{M} = (\omega, \mathscr{P}(\omega), <, +, \cdot, 0, 1, \in)$. In other words, any $(\mathscr{P}_h, \le)$-definable relation is definable in $\mathcal{M}$. The converse is not obvious. Slaman and Woodin [144] showed that the biinterpretability of $(\mathscr{P}_h, \le)$ would enable one to interpret $\mathcal{M}$ in $(\mathscr{P}_h, \le)$. In other words, any $\mathcal{M}$-definable degree relation is definable in $(\mathscr{P}_h, \le)$. This is the content of the following theorem. We say that a set of hyperdegrees is analytical if it is the set of hyperdegrees of an analytical set.

## Proposition 10.3.6.
*If* $(\mathscr{P}_h, \le)$ *is biinterpretable with second order arithmetic, then every analytical set of hyperdegrees is definable in* $(\mathscr{P}_h, \le)$.

**Proof.** Suppose that $A$ is analytical. Let $\tilde{A} = \{ \mathbf{x} \mid \exists \mathbf{y} \in A \, \mathbf{x} \in \mathbf{y} \}$. We show that $\tilde{A}$ is definable in $(\mathscr{P}_h, \le)$. Let $\psi$ be a formula in the language of second order arithmetic such that
\( x \in A \Leftrightarrow (\omega, \mathscr{P}(\omega), <, +, \cdot, 0, 1, \in) \models \psi(x) \).

Since quantifying over countable sets of hyperdegrees can be expressed in $(\mathscr{P}_h, \le)$ through the codes, the second order quantifiers over $\omega$ are also interpretable in $(\mathscr{P}_h, \le)$ via first order quantifiers over codes of subsets of $\omega$. Then $\mathbf{x} \in A$ if and only if there is a finite sequence $\tilde{\mathbf{p}}$ such that $R^*(\tilde{\mathbf{p}}, \mathbf{x})$ and $\psi(x)$ is satisfied in the model with $\mathbf{x}$ coded by $\tilde{\mathbf{p}}$ and $\omega$.

Thus $\tilde{A}$ is definable in $(\mathscr{P}_h, \le)$.

The rigidity of the hyperdegrees proved in Theorem 10.2.4 allows one to show the biinterpretability of this structure with second order arithmetic:

## Theorem 10.3.7 (Slaman and Woodin [141], Shore [133]).
*The structure* $(\mathscr{P}_h, \le)$ *is bi-interpretable with second order arithmetic.*

**Proof.** Let $\psi(\tilde{\mathbf{p}}, \mathbf{x})$ be defined as follows:

- $\tilde{\mathbf{p}}$ codes a real $\mathbf{x}$;
- For any coded real $y \le_\alpha x$, there exist degrees $\mathbf{y}_0, \mathbf{y}_1 > \mathbf{x}$ such that
- $\mathbf{y}_0 \cap \mathbf{y}_1 = \mathbf{x}$, and
- $e_\gamma$ can be embedded into both $[\mathbf{x}, \mathbf{y}_0]$ and $[\mathbf{x}, \mathbf{y}_1]$ with least element $\mathbf{x}$.

By Theorem 10.3.1, $\psi$ may be viewed as a first order formula in the language of partial ordering for $\langle \mathscr{P}_h, \le \rangle$. If $R^*(\tilde{\mathbf{p}}, \mathbf{x})$ holds, then by Lemma 10.2.3 $\langle \mathscr{P}_h, \le \rangle \models \psi(\tilde{\mathbf{p}}, \mathbf{x})$.

If $\langle \mathscr{P}_h, \le \rangle \cong \langle \psi(\mathbf{p}), \in \rangle$ then by Lemma 10.2.3, the real $x$ stated must have hyperdegree $\mathbf{x}$. So $R^*(\tilde{\mathbf{p}}, \mathbf{x})$ is true.

In summary, the structure $(\mathscr{P}_h, \le)$ is biinterpretable with second order arithmetic.

## 11 Basis theorems

In earlier chapters we have seen examples of uncountable sets of reals (e.g. \(\Sigma^1_1\) and certain \(\Pi^1_1\)-sets) that contain perfect subsets. In this chapter we study basis theorems for uncountable sets of reals as well as basis properties of perfect sets.

## 11.1 A basis theorem for \(\Delta^1_1\)-sets of reals

### 11.1.1 Friedman's conjecture

Friedman [29] conjectured that every uncountable $\Delta^1_1$-set of reals has a member in each hyperdegree greater than or equal to the hyperdegree of $\emptyset$. This conjecture was settled by Martin [94] and Friedman independently.

**Theorem 11.1.1** (Martin [94] and Friedman). If \(A \subseteq \omega^\omega\) is an uncountable \(\Delta^1_1\)-set, then there is a perfect tree \(T \subseteq \omega^{<\omega}\) such that \([T] \equiv A\) and for any \(x \ge_h \emptyset\), there is a \(z \in [T]\) with \(z \equiv_h x\).

Suppose that \(A \subseteq \omega^\omega\) is an uncountable \(\Delta^1_1\)-set. By Corollary 2.2.14, there is a recursive function \(h : \omega^\omega \to \omega^\omega\) and a \(\Pi^0_1\)-set \(B \subseteq \omega^\omega\) such that \(h\) maps \(B\) onto \(A\) and is injective on \(B\). Then for every \(x \in B\), \(h(x) \equiv_h x\) and for every \(y \in A\), there exists an \(x \in B\) such that \(x \equiv_h h(x) = y\). Hence it suffices to show that every \(x \ge_h \emptyset\) satisfies \(z \equiv_h x\) for some \(z \in B\). Since \(B\) is a \(\Pi^0_1\)-class, there is a recursive tree \(T \subseteq \omega^{<\omega}\) so that \(B = [T] = \{x \mid (\forall n)(x \upharpoonright n \in T)\}\). We shall prove in the next section a slightly stronger result:

**Theorem 11.1.2.** Every \(\Sigma^1_1\)-tree \(T_1\) with uncountably many infinite paths has a member in each hyperdegree greater than or equal to that of \(\emptyset\).

### 11.1.2 Proof of Friedman's conjecture

We prove Theorem 11.1.2 following [172]. Let \(T_1 \subseteq \omega^{<\omega}\) be a \(\Sigma^1_1\)-tree with a nonhyperarithmetic path. Then there is a \(\Sigma_1(L_{\omega_1^{CK}})\)-enumeration of the nodes of \(\omega^\omega \setminus T_1\). We use \(T_1[\beta]\) to denote the collection of nodes not yet enumerated up to stage \(\beta\). Then \(T_1 = \cap_{\beta < \omega_1^{CK}} T_1[\beta]\). Fix a nonempty recursive tree \(T_0 \subseteq \omega^{<\omega}\) having an infinite path and without a hyperarithmetic infinite path. Let \(f\) be the leftmost path of \(T_0\). Then \(f \equiv_h \emptyset\).

**Lemma 11.1.3.** If \(T_1 \cap [v] = \{ \tau \in T_1 \mid \tau \supseteq v \}\) has no nonhyperarithmetic infinite path, then there is a stage \(\beta < \omega_1^{CK}\) witnessing it. In other words, there is a \(\Sigma_1(L_{\omega_1^{CK}})\) partial function \(H : \omega^{<\omega} \to \{0\}\) such that \(H(\sigma)\) is undefined if and only if \(T_1 \cap [\sigma]\) contains a nonhyperarithmetic infinite path.

Proof. Suppose that \(\sigma \in T_1\) and \(T_1 \cap [\sigma]\) has no nonhyperarithmetic infinite path. We perform a Cantor-Bendixson type operation on \(T_1 \cap [\sigma]\) as follows: Let \(\le_{KB}\) be the Kleene-Brouwer ordering on \(\omega^{<\omega}\). At stage \(\beta < \omega_1^{CK}\), define a subtree \(T_1^\beta\). \(T_1^0\) is in fact \(T_1[\sigma]\) except for the removal of those strings \(\sigma'\) where \([\sigma]\) is seen at stage \(\beta\) not to contain a nonhyperarithmetic path in \(T_1\).

Stage 0. Let \(T_1^0 = T_1[\sigma]\).

Stage \(\beta + 1\). Given \(\sigma \in T_1^\beta\) and \(\tau > \sigma\), if either (1) there exists a \(<_{KB}\) order-preserving function \(h : T_1^\beta \cap [\tau] \to \beta\) in \(L_\beta\) (hence there is no infinite path in \(T_1^\beta \cap [\tau]\), or (2) there exists a function \(h \in L_\beta\) that enumerates \(T_1^\beta \cap [\tau]\) as a unique hyperarithmetic path.

Then let \(T_1^{\beta+1} = T_1^\beta \setminus [\tau]\) and declare that \(\tau\) is removed from \(T_1^\beta\) at stage \(\beta + 1\).

By the usual Cantor-Bendixson proof as in Proposition 3.6.10, if \(T_1 \cap [\sigma]\) has no nonhyperarithmetic infinite path, then every \(\tau > \sigma\) is removed at some stage \(\beta\). Then by the admissibility of \(\omega_1^{CK}\), there is a stage \(\beta_\sigma < \omega_1^{CK}\) such that every \(\tau > \sigma\) is removed at \(\beta_\sigma\). At stage \(\beta_\sigma\), define \(H(\sigma) = 0\).

Thus \(H\) may be viewed as a \(\Sigma_1(L_{\omega_1^{CK}})\)-partial enumeration function. A node \(\sigma \in \omega^{<\omega}\) is a splitting node in the tree \(T_1\) if there exist \(j \neq j'\) such that both \(H(\sigma^\frown j)\) and \(H(\sigma^\frown j')\) are undefined. For \(\beta < \omega_1^{CK}\), a node \(\sigma \in \omega^{<\omega}\) is a splitting node in the tree \(T_1[\beta]\) if there exist \(i \neq j\) such that both \(H(\sigma^\frown i)\) and \(H(\sigma^\frown j)\) are undefined at stage \(\beta\). By a similar argument, there is a \(\Sigma_1(L_{\omega_1^{CK}})\)-partial function \(K : \omega^{<\omega} \to \{0\}\) such that \(K(\sigma)\) is undefined if and only if there exists an infinite path in \(T_0 \cap [\sigma]\). Note that \(K\) is different from \(H\).

We call a node \(\sigma \in \omega^{<\omega}\) a terminal node in \(T_0\) if \(K(\sigma)\) is defined. For \(\beta < \omega_1^{CK}\), \(\sigma \in \omega^{<\omega}\) is a terminal node in \(T_0[\beta]\) if \(K(\sigma)\) is defined at stage \(\beta\).

Now for any \(x \in \omega^\omega\), we build a \(z \in [T_1]\) such that \(x \equiv_B z\): Stage 0. Let \(\sigma_0 = 0\).

Stage \(s + 1\). Let \(\sigma' > \sigma_s\) be the leftmost splitting node of \(T_1\) extending \(\sigma_s\) so that there are \(f(s)\) many splitting nodes between \(\sigma_s\) and \(\sigma'\). Let \(\sigma'' > \sigma'\) be the second leftmost splitting node extending \(\sigma'\) in \(T_1\). Set \(\sigma_{s+1} > \sigma''\) to be the \(x(s) + 1\)-th leftmost splitting node extending \(\sigma''\) in \(T_1\).

Let \(z = \bigcup_{s \in \omega} \sigma_s\).

We prove that \(x \in L_{\omega_1}[z]\). In fact we show that there is a \(\Sigma_1(L_{\omega_1}[z])\) (and hence \(\Delta_1(L_{\omega_1}[z])\)) definable increasing sequence of ordinals \(\{\alpha_s\}_{s \in \omega}\) below \(\omega_1^{CK}\) such that \(x \in L_{\bigcup \{ \alpha_s, \alpha_{s+1} \}}[z]\). Then \(\bigcup_s \alpha_s + 1 < \omega_1^{CK}\), proving \(x \in L_{\omega_1}[z]\).

The idea is to decode the construction of \(z\) in \(L_{\omega_1}[z]\). For each \(n < \omega\) we use \(z\) to identify the value of \(f(n)\), where \(f\) is the leftmost path of \(T_0\). As an example, consider the case \(n = 0\). Given \(\beta < \omega_1^{CK}\), we compute, beginning at the root of \(T_1[\beta]\), the number \(l_\beta\) of times \(z\) 'turns left' in \(T_1[\beta]\). Then \(l_\beta\) is a possible value of \(f(0)\). Of course this guess may be wrong. As an aid to making a better guess, we also determine if \(l_\beta\) is \(f(0)\) by asking if \(0^\frown l_\beta\) is not a terminal node in \(T_0[\beta]\) but \(0^\frown l'\) is terminal for every \(l' < l_\beta\).
