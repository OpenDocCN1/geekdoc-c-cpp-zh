### Definition 6.5.2. The Axiom of Determinacy (AD) states that for any A \in ^\omega \omega, either I or II has a winning strategy for G_A.

It is not difficult to see that AC contradicts AD. However, G_A is determined whenever A is simply defined.

### Proposition 6.5.3. If A is a closed set, then G_A is determined.

Proof. Since A is closed, there is a tree T \subseteq ^{<\omega} \omega such that A = [T]. Suppose that II has no winning strategy. We define a I-winning strategy \tilde{\sigma} as follows:

Let \tilde{\sigma}(0) be an n_0 such that II has no winning strategy on G_{T[(n_0)]} where T_{(n_0)} = \{ \tau \in T | n_0 \le \tau \}, where n_0 is the string of length 1 whose value at 0 is n_0. Note that n_0 exists by the assumption that II has no winning strategy.

By induction assume that \tilde{\sigma} is defined for sequences of length up to i - 1, and II has no winning strategy on G_{T[(n_0, m_0, ..., n_{i-1})]} where

T_{(n_0, m_0, ..., n_{i-1})} = \{ \tau \in T | (n_0, m_0, ..., n_{i-1}) \le \tau \},

for the sequence (n_0, m_0, ..., m_i) played by I following \tilde{\sigma}. Then there is an n_i such that II has no winning strategy on G_{T[(n_0, m_0, ..., m_i)]} where

T_{(n_0, m_0, ..., m_i, n_i)} = \{ \tau \in T | (n_0, m_0, ..., m_{i-1}, n_i) \le \tau \}.

Let

\tilde{\sigma}((n_0, m_0, ..., m_{i-1})) = n_i.

Then for any g \in ^\omega \omega and number k, \tilde{\sigma} * g \upharpoonright k \in T. Hence \tilde{\sigma} * g \notin A since A is closed.

It is not always true that if G_A is determined, then so is G_{^\omega \omega \setminus A} (see Exercise 6.5.1). However, the next proposition implies that this complementation property holds when A is closed.

### Proposition 6.5.4. Suppose that \Gamma \subseteq \mathscr{P}(^\omega \omega) so that for any A \in \Gamma and string \sigma \in ^{<\omega} \omega, the set A_\sigma = \{ x | ^\sigma x \in A \} \in \Gamma. If G_A is determined for every A \in \Gamma, then so is G_{^\omega \omega \setminus A} for every A \in \Gamma.

Proof. Suppose that A \in \Gamma. Note that for any n, A_n = \{ x | ^n x \in A \} \in \Gamma and so G_{A_n} is determined.

Case (1) There exists an n_0 such that player II has a winning strategy \tilde{\tau} for G_{A_{n_0}}. Let \tilde{\sigma}(0) = n_0. For any string (n_0, m_0, ..., m_i), let \tilde{\sigma}((n_0, m_0, ..., m_i)) be \tilde{\tau}(m_0, ..., m_i). Then \tilde{\sigma} is a winning strategy for player I for G_{^\omega \omega \setminus A}.

Case (2) Otherwise. Then for every n, player I has a winning strategy \tilde{\sigma}_n for G_{A_n}. Define \tilde{\tau} so that for each n, \tilde{\tau}(n) = \tilde{\sigma}_n(0) and for any string (n_0, m_0, ..., n_i), \tilde{\tau}(n_0, m_0, ..., n_i) = \tilde{\sigma}_{n_i}(m_0, ..., n_j). Then \tilde{\tau} is a winning strategy for II for the game G_{\omega^\omega \setminus A}.

The optimal result on determinacy provable in ZF is due to Martin. Optimality here means that any stronger version is essentially a large cardinal axiom. Let DC denote the Axiom of Dependent Choice:

### Theorem 6.5.5 (Martin [93]). ZF + DC “Every Borel set is determined”.

### Theorem 6.5.6 (Martin [92] and Harrington [45]). \( \Pi^1_1 \)-determinacy is equivalent to the existence of \( 0^\sharp \).

The status concerning AD is more complex. A detailed discussion would involve the notion of a Woodin cardinal which we will not define. Nonetheless, Woodin, Martin and Steel have shown that ZF + AD is equiconsistent with ZFC+ “There exist infinitely many Woodin cardinals”. Woodin also showed the following:

- **Theorem 6.5.7** (Woodin). The following are equivalent:
- (i) ZF + DC + \( \Delta_2^1 \)-Determinacy is consistent;
- (ii) ZF + DC + Analytical Determinacy is consistent;
- (iii) ZFC + “There exists a Woodin cardinal” is consistent.

Woodin as well as Martin and Steel [95] have also provided a level-by-level analysis of determinacy in the projective hierarchy (known as Projective Determinacy).

## 6.6 Recursion-theoretic aspects of determinacy

The investigation of determinacy from the perspective of recursion theory was initiated by Martin. A natural starting point is to analyze the complexity of winning strategies.

### 6.6.1 Basis theorems for winning strategies

If \( A \) is \( \Pi^1_1 \), then both the sets \( \{\hat{\sigma} \mid (\forall g)((\hat{\sigma} * g \in A))\} \) and \( \{\hat{\tau} \mid (\forall f)(f * \hat{\tau} \in A)\} \) are \( \Pi^1_1 \). By Corollary 4.2.7, there is a \( \Delta^1_1 \)-winning strategy for either I or II. However, even for \( \Pi^1_2 \)-sets, it is not possible to improve the upper bound significantly.

### Theorem 6.6.1 (Blass [7]). Suppose that \( A \) is \( \Pi^1_1 \). If I has a winning strategy for \( G_A \), then I has a winning strategy recursive in \( O \); if II has a winning strategy for \( G_A \), then II has a hyperarithmetic winning strategy.

Proof. Since \( A \) is \( \Pi^1_1 \), there is a recursive tree \( T \subseteq \omega^{<\omega} \) such that \( A = [T] \). Suppose that I has a winning strategy. Then the set

\( B = \{\hat{\sigma} \mid (\forall i)(\forall \sigma \in \omega^i)((\hat{\sigma} \text{ is a play at step } i \text{ by I following } \hat{\sigma}) \to (\exists x)(\sigma \frown x \in A))\} \)

is a nonempty \( \Sigma^1_1 \)-set. By Gandy's Basis Theorem (2.5.3), there is a \( \hat{\sigma}_0 \le_T O \) in B. Obviously \( \hat{\sigma}_0 \) is a winning strategy for player I.

Now suppose that I has no winning strategy. Let \( n \in \omega^* \setminus 0 \). Then \( \Omega^1_n = \{m \mid m \le_{\sigma^*} n\} \) is an r.e. set with an initial segment of order type \( \sigma^1_{CK} \) under the r.e. linear ordering relation \( <_{\sigma^*} \). Define an arithmetical set C of functions from \( \omega^{<\omega} \) into \( \Omega^1_n \) as follows: \( f \in C \) if and only if for any \( \sigma \),

(i) If \( |\sigma| \le |T| \), then \( f(\sigma) \) is undefined;
(ii) if \( |\sigma| \cap |T| = \emptyset \), then \( f(\sigma) = 1 \);
(iii) suppose that \( \sigma \) satisfies neither (i) nor (ii). (a) If \( |\sigma| \) is even, then \( f(\sigma) = 2^i \) if \( i = \sup\{k \mid k = f(\sigma^i)\} \) exists where sup is in the sense of \( <_{\sigma^*} \); otherwise, \( f(\sigma) \) is undefined. (b) If \( |\sigma| \) is odd, then \( f(\sigma) = 2^i \) if \( i = \inf\{k \mid k = f(\sigma^m)\} \) exists where inf is in the sense of \( <_{\sigma^*} \); otherwise, \( f(\sigma) \) is undefined.

Since \( \Omega \cap O^1_\alpha \) is the largest well-ordered segment of \( \Omega^1_n \), for any \( f \in C \) and \( \sigma \), if \( f(\sigma) \) is defined then \( f(\sigma) \in O \).

**Claim 1.** Suppose \( \sigma \) satisfies (iii)(a). If for any m, there is a hyperarithmetic partial function \( f_m \in C \) such that \( f_m(\sigma^m) \) is defined, then there is a hyperarithmetic partial function \( f \in C \) such that \( f(\sigma) \) is defined.

Proof of Claim 1. Define a \( \Pi^1_1 \)-relation \( R \subseteq \omega \times (\omega \times \omega) \) as follows: \( (m, (e, i)) \in R \) if and only if \( i \in O \) and \( \emptyset_e^O \in C \) so that \( \emptyset_e^O(\sigma^m) \) is defined. By Theorem 4.21, there is a \( \Pi^1_1 \)-function \( g : \omega \to \omega \times \omega \) uniformizing R. By the assumption, g is total and hence hyperarithmetic.

Define f to be a hyperarithmetic function such that for any m and \( r \ge \sigma^m \), \( f(r) = \Phi_{g(m)}^{H_{r_1}}(r) \) where \( g(m) = (m_0, m_1) \). Obviously \( f \in C \). Moreover, since f is hyperarithmetic, \( \sup\{k \mid k = f(\sigma^m)\} \) exists and so \( f(\sigma) \) is defined.
