
We now define a notion of Cohen forcing over $\Sigma^0_b$-predicates for $b <_0 a$. If $P(x, n)$ is a $\Sigma^0_1$-predicate, then there is a partial recursive function $\Phi^b(n)$ such that $P(x, n) \Leftrightarrow \Phi^b(n) \downarrow$. Define $\sigma \Vdash P(x, n)$ if and only if $\Phi^b(n) \downarrow$.

If $b = 2^c \in O, b <_0 a$, and $P(x, n)$ is $\Sigma^0_b$, then $P(x, n) \Leftrightarrow (\exists m)\neg Q(x, \langle n, m \rangle)$. Define $\sigma \Vdash P(x, n) \Leftrightarrow (\exists m)(\forall \tau \sqsupset \sigma)(Q(x, \langle n, m \rangle))$.

If $b = 3 \cdot 5^e \in O, b <_0 a$, and $P(x, n)$ is a $\Sigma^0_b$ predicate, then $P(x, n) \Leftrightarrow P_{\Phi^b(\Phi(e)(n))}(x, n)$ for some $i$. Define $\sigma \Vdash P(x, n) \Leftrightarrow \sigma \Vdash P_{\Phi^b(\Phi(e)(n))}(x, n)$.

Given $b <_0 a$, if $P(x, n)$ is a $\Sigma^0_b$ predicate, then $\sigma \Vdash \neg P(x, n) \Leftrightarrow (\forall \tau \sqsupset \sigma)(\tau \nVdash P(x, n))$.

The verification of the following lemma is also left to the reader.

### Lemma 7.3.4. There is a partial recursive function $h : a^2 \times 2 \to \omega$ such that for any $b <_0 a$,

- (i) if $b = 1$ or $2^c$, then $(\forall n)(\forall m)((\sigma \Vdash P_{\Phi(b,n)}(x, m) \implies \Phi^h_{\langle b,n \rangle}(\sigma, m) = 1) \wedge (\sigma \nVdash P_{\Phi(b,n)}(x, m) \implies \Phi^h_{\langle b,n \rangle}(\sigma, m) = 0))$;
- (ii) if $b = 3 \cdot 5^e$, then $(\forall n)(\forall m)((\sigma \Vdash P_{\Phi(b,n)}(x, m) \implies \Phi^h_{\langle b,n \rangle}(\sigma, m) = 1) \wedge (\sigma \nVdash P_{\Phi(b,n)}(x, m) \implies \Phi^h_{\langle b,n \rangle}(\sigma, m) = 0))$.

A real $g$ is $a$-generic if for any $b <_0 a$ and $\Sigma^0_b$-predicate $P(x, n)$ there is an $m$ such that either $g \mid m \Vdash P(x, n)$ or $g \mid m \Vdash \neg P(x, n)$. This yields the following truth lemma:

### Lemma 7.3.5. Suppose that $g$ is $a$-generic. For any $m$, $n$ and $b <_0 a$, $P_{\Phi(b,n)}(g, m)$ if and only if there is a $k$ such that $g \mid k \Vdash P_{\Phi(b,n)}(x, m)$, and $\neg P_{\Phi(b,n)}(g, m)$ if and only if there is a $k$ such that $g \mid k \Vdash \neg P_{\Phi(b,n)}(x, m)$.

### Lemma 7.3.6. If $g$ is $a$-generic, then there is a partial recursive function $r$ such that for any $b <_0 a$

- if $b = 1$ or $2^c$, then $H^g_b = \Phi^{g_{H(b)}}_{r(b)}$;
- if $b = 3 \cdot 5^e$, then $H^g_b = \Phi^{g_{H(b)}}_{r(b)}$.

**Proof.** We give the proof for the case when the notation of $b$ is a successor, and leave the limit case to the reader.

If $b = 1$, then by Lemma 7.3.3, $n \in H^g_b$ if and only if $P_{\Phi(1,n)}(g, n)$. By Lemma 7.3.5, there exists a $k$ such that either $g \mid k \Vdash P_{\Phi(1,n)}(g, n)$ or $g \mid k \Vdash \neg P_{\Phi(1,n)}(g, n)$. By Lemma 7.3.4, this is decidable by $\Phi^{H_g}_{\langle 1,n \rangle}(g \mid k, n)$. Hence $H^g_1 = \Phi^{g_{H(1)}}_{r(1)}$ for some $i$. Let $r(1) = i$.

If $b = 2^c$, then by Lemma 7.3.3, $n \in H^g_b$ if and only if $P_{\Phi(b,n)}(g, n)$. By Lemma 7.3.5, there exists a $k$ such that either $g \mid k \Vdash P_{\Phi(b,n)}(g, n)$ or $g \mid k \Vdash \neg P_{\Phi(b,n)}(g, n)$. Since $P_{\Phi(b,n)}(g, n) \Leftrightarrow (\exists m)P_{\Phi(c,n)}(g, n, m)$, we have

$(\exists m)(g \mid k \Vdash P_{\Phi(c,n)}(g, n, m)) \vee (\forall \tau \sqsupset g \mid k)(\forall m)(\tau \nVdash P_{\Phi(c,n)}(g, n, m))$.

By Lemma 7.3.4, this is decidable by either $g \mid H^g_c = g \mid H_{2^c} (= c 2^d$ for some $d)$ or $g \mid H^g_c \le_T g \mid H_{2^c} (= c \cdot 3 \cdot 5^e$ for some $e)$. Hence $H^g_b = \Phi^{g_{H(b)}}_{r(b)}$ for some $i$, a number which may be effectively computed from $b$. Let $r(b) = i$.

We are now ready to prove Theorem 7.3.2. We establish the case where \(\beta\) is a successor ordinal and leave the limit case to the reader.

Let \(a \in \omega\) so that \(a = \beta\). Fix \(z > \tau_H\) for all \(b <_0 a\). We may assume that \(z\) is not r.e. in \(H_b\) for any \(b <_0 a\). Given \(b <_0 a\) and \(i, j < \omega\), consider the following statement:

\((\forall \sigma \in 2^{<\omega})(\exists n)[(n \notin z \land \sigma^\frown 0 1^n \Vdash \neg P_{\Phi(b,i)}(x,j)) \lor (n \notin z \land (\exists \tau \supseteq \sigma^\frown 0 1^n)(\tau \Vdash P_{\Phi(b,j)}(x,i)))]\). \((\sharp_{b,(i,j)})\)

Since \(z\) is not r.e. in \(H_b\) for \(b <_0 a\), by Lemma 7.3.4, \((\sharp_{b,(i,j)})\) is true for every \(b <_0 a\) and \(n < \omega\). We construct \(g\) in stages as the union of the sequence \(\{g_s\}_{1 \le s < \omega} \subset 2^{<\omega}\) with \(g_0 < g_1 < g_2 < \cdots\).

Let \(\langle \langle b_s, \langle i_s, j_s \rangle \rangle \rangle_{s < \omega}\) be an enumeration of \(\{b \mid b <_0 a\} \times \omega^2\).

- Stage 0: Let \(g_0 = \emptyset\).
- Stage s + 1:
- Substage 1. Define \(g(s, 1) = g_s \frown z^*(s) \frown H_a(s)\).
- Substage 2. Define \(g(s, 2) = g(s, 1) \frown 0^{\langle b_s, \langle i_s, j_s \rangle \rangle} 1\).
- Substage 3.
- Case (1): \(2^{b_s} \# a\). Define \(g(s, 3) = g(s, 2) \frown 0^{e_s} 1\) where \(e_s\) is an index so that \(\Phi_{e_s}^z = \Phi_{H_a(b_s)}^{H_a}\) \((b_s = 2^c\) for some \(c)\) or \(\Phi_{e_s}^z = \Phi_{H_a(b_s)}^{H_a} (b_s = 3 \cdot 5^e\) for some \(e)\).
- Case (ii): \(2^{b_s} = a\). Let \(g(s, 3) = g(s, 2) \frown 0^{e_s} 1\) where \(e_s\) is an index such that \(\Phi_{e_s}^z = \Phi_{H_a(b_s)}^{H_a} (b_s = 2^c\) for some \(c)\) or \(\Phi_{e_s}^z = \Phi_{H_a(b_s)}^{H_a} (b_s = 3 \cdot 5^e\) for some \(e)\).
- Substage 4. Find the least \(n\) such that either

  \(n \notin z \land g(s, 3) \frown 0^n 1 \Vdash \neg P_{\Phi(b,i_s)}(x, j_s)\)

  or

  \(n \notin z \land (\exists \tau \supseteq g(s, 3) \frown 0^n 1)(\tau \Vdash P_{\Phi(b,j_s)}(x, j_s))\).

  By \((\sharp_{b,(i_s,j_s)})\), such a number \(n\) exists. If it satisfies the first half of the disjunction, define \(g_{s+1} = g(s, 3) \frown 0^n 1\). Otherwise, select the lexicographically least \(\tau\) such that \(\tau \supseteq g(s, 3) \frown 0^n 1\) and \(\tau \Vdash P_{\Phi(b,i_s)}(x, j_s)\). Define \(g_{s+1} = g(s, 3) \frown \tau\).

Let \(g = \bigcup_{s < \omega} g_s\).

It is clear that \(g\) is a-generic. By Lemma 7.3.6, \(\hat{H}_g^z \equiv_T g \oplus H_a\). By Lemma 7.3.4, the construction can be decoded by \(g\) in \(H_a\). So \(z \oplus g \le_T g \oplus H_a \equiv_T \hat{H}_g^z\).

To prove that \(z \oplus g \ge_T \hat{H}_g^z\), it is sufficient to decode the construction by \(z \oplus g\) and compute \(H_a\). To do this, we go through the same steps as in the proof of Theorem 7.3.1. Suppose we know \(g_s\). Then \(z(s+1) = g(|g_s|+1)\) and \(H_a(s) = g(|g_s|_2)\). Then one obtains \((b_s, i_s, j_s)\) by calculating \(g(s, 2)\). By calculating \(g(s, 3)\), we find an \(e_s\) such that \(\Phi_{e_s}^z\) computes the set \(\{(\sigma, i_s, j_s) \mid \sigma \Vdash P_{\Phi(b,i_s)}(x, j_s)\}\). To compute \(g_{s+1}\), search for the unique number \(n\) such that \((g \mid |g(s, 3)|) \frown 0^n 1 \prec g\). By the construction, either

- (1) \(n \notin z\) or
- (2) \(n \notin z\) and there is a \(\tau \supseteq g(s, 3) \frown 0^u 1\) such that \(\tau \Vdash P_{\Phi(b_s)}(x, j_s)\).

We may use \(\Phi_e^\tau\) to find the \(\tau\). Then \(g_{s+1} = \tau\) and we conclude that \(z \oplus g \ge_T H_a\).

## 7.3.3 Further generalizations

Another generalization of the Posner–Robinson Theorem (7.3.1) into the transfinite is as follows:

### Theorem 7.3.7 (Shore and Slaman [134]). For any recursive ordinal \(\beta\), if \(x \not\le_T 0^{(\gamma)}\) for \(\gamma < \beta\), then there is a \(g\) such that \(x \oplus g \equiv_T g^{(\beta)}\).

Theorem 7.3.7 is proved by a forcing argument (Kumabe–Slaman forcing) different from Cohen forcing, and is used to show the definability of the complete Turing degree \(0'\) (see Exercise 7.3.3). On the other hand, it is possible to extend Theorem 7.3.7 beyond recursive ordinals. This was shown by Woodin using a set-theoretic argument:

### Theorem 7.3.8 (Woodin [169]). If \(z\) is not hyperarithmetic, then there is a \(g\) such that \(z \oplus g \equiv_T 0^{(\delta)}\).
