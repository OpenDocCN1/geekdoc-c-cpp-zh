Observe that (1)-(4) are \(\Sigma_1\)-statements. By (4), one verifies that (5) is a \(\Delta_1\)-statement. Hence there is a \(\Sigma_0\)-formula \(\varphi(a, X, z, s)\) such that
\(F(a, X) = z \Leftrightarrow L_{\omega_1^X}[X, z] \models (\exists s)\varphi(a, X, z, s).\)

Thus we may perform transfinite induction on \(\alpha\) to define a sequence \(\{z_\alpha \mid \alpha < \omega_1\}\) using \(F\). However, the resulting sequence yields in general a set of reals that is \(\Sigma_1\) over \(L_{\omega_1}\), i.e. \(\Sigma_1^1\) but not necessarily \(\Pi_1^1\) over second order arithmetic. To ensure that \(\Pi_1^1\)-ness is achieved, we refine the approach as follows.

Define \(G(a) = z\) if and only if \(a < \omega_1^X\) and there is a function \(f : a + 1 \to 2^\omega\) with \(f \in L_{\omega_1}[z]\) so that for all \(\beta \le a, f(\beta) = F(\beta, \{\langle \gamma, n \rangle \in f(\gamma) \mid \gamma < \beta\})\) and \(f(a) = z\). Since \(L_{\omega_1}[z]\) is admissible, \(f(\gamma) \mid y \le \alpha \in L_{\omega_1}[z]\). Hence \(G(a) = z\) if and only if there is a function \(f : a + 1 \to 2^\omega\) with \(f \in L_{\omega_1}[z]\) such that
\(\langle L_{\omega_1^\gamma}[z], \in \rangle \models (\forall \beta \le a)(\exists s \in \rho)(\beta, \langle \gamma, n \rangle \in f(\gamma) \land \gamma < \beta \land s, f(\beta)) \land f(a) = z.\)

Since \(L_{\omega_1^\gamma}[z]\) is admissible, \(G\) is \(\Sigma_1\)-definable. In other words, \(G(a) = z\) if and only if there is a function \(f : a + 1 \to 2^\omega\) with \(f \in L_{\omega_1}[z]\) such that
\(\langle L_{\omega_1^\gamma}[z], \in \rangle \models ((\exists \beta)(\forall \beta \le a)(\exists s \in \rho)(\beta, \langle \gamma, n \rangle \in f(\gamma) \land n \in f(\gamma) \land \gamma < \beta \land s, f(\beta))) \land f(a) = z.\)

Let \(A\) be the range of \(G\). Then \(z \in A\) if and only if there exists an ordinal \(a < \omega_1^Y\) and a function \(f : a + 1 \to 2^\omega\) with \(f \in L_{\omega_1}[z]\) such that
\(\langle L_{\omega_1^\gamma}[z], \in \rangle \models ((\exists \beta)(\forall \beta \le a)(\exists s \in \rho)(\beta, \langle \gamma, n \rangle \in f(\gamma) \land n \in f(\gamma) \land \gamma < \beta \land s, f(\beta))) \land f(a) = z.\)

Hence \(A\) is \(\Pi_1^1\).

All that remains is to use an argument as that for Theorem 3.1.8 to show that \(G\) is a well-defined total function on \(\omega_1\). The only nontrivial part is to prove that the function \(f\) defined above exists. This can be done by induction. Let \(a < \omega_1\) be given and suppose that \(\{f_\beta\}_{\beta < a}\) is a uniformly \(\Sigma_1\) and increasing (i.e. \(f_\beta \subset f_\gamma\) for \(\beta > \gamma\)) sequence such that each \(f_\beta\) is an \(f\) at stage \(\beta < a\) as required. Let \(f_a\) be such that \(f_a \in L_{\omega_1}[z]\) and for all \(\beta \le a, f_a(\beta) = F(\beta, \{\langle \gamma, n \rangle \mid n \in f_\beta(\gamma) \land \gamma < \beta\})\) and \(f_a(a) = z\), where \(F(a, X) = z\) and \(X = \{\langle \gamma, n \rangle \mid \exists \beta(\gamma < \beta \land a \in n \in f_\beta(\gamma))\}\). Note that \(X = \{\langle \gamma, n \rangle \mid \gamma \le a \land n \in f_\gamma(\gamma)\}\) by absoluteness. Then \(f_a \supset f_\beta\) for all \(\beta < a\) and satisfies the requirement of such an \(f\) at stage \(a\).

By (1) and (2) above, \((x, z) \in L_Y\) and \(L_Y \in L_{\omega_1}\). So \(A \subset C\). Since P is cofinally progressive, (i) of the definition of I is satisfied.

For (ii), if \(y \in A\) then \(y = G(a)\) for some \(a < \omega_1\). By the definition of \(G\), there is a real \(x \in L_{\omega_1^{G(a)}}\) such that \(x\) codes the set \(\{G(\beta) \mid \beta < a\}\) and \(P(x, G(a))\) holds. Clearly \(\beta < a\) if and only if \(G(\beta) <_L G(a)\). Hence (ii) holds.

It turns out that the \(\Pi_1^1\)-inductive principle \(\mathcal{I}\) is equivalent to the set-theoretic assumption \((\omega_1)^L = \omega_1\), as we now show.
