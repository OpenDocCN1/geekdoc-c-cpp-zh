Thus (i) implies that \(x\) is nonempty; (ii) says that \(x\) is “closed under successor”, and (iii) that it is “closed under limit”; (iv) asserts that \(x\) defines a transitive relation. We introduce the following notations.

**Definition 1.2.1.** \(<_\alpha = \bigcup_{\beta < \alpha} x\). \(\mathcal{O} = \{n \mid (\exists m)(n <_\alpha m)\}\).

By Proposition 1.1.5, \(<_\alpha\) is a \(\Pi^1_1\)-relation and \(\mathcal{O}\) is \(\Pi^1_1\). We define a set \(a\) by induction:

+   Stage 0. Put (1, 2) into \(a_0\).
+   Stage \(\beta + 1\). Put \((n, 2^n)\) and \((m, 2^n)\) into \(a_{\beta+1}\) if \((m, n) \in a_\beta\) at stage \(\beta\).
+   Stage \(\lambda\). For \(\lambda\) a limit ordinal. For each \(e\) such that \(\Phi_e\) is total and \((\forall n)(\exists \beta < \lambda)((\Phi_e(n), \Phi_e(n+1)) \in a_\beta)\), put \((\Phi_e(n), 3 \cdot 5^e)\) into \(a_\lambda\) for each \(n\). Furthermore, if \((m, \Phi_e(n)) \in a_\beta\) for some \(\beta < \lambda\), then \((m, 3 \cdot 5^e) \in a_\lambda\).

Let \(a = \bigcup_\beta a_\beta\).

It is straightforward to verify that \(a \in P\) and for each \(x \in P\), \(a \subseteq x\). Hence \(a = <_\mathcal{O}\).

Define a function \(|\cdot| : \mathcal{O} \mapsto \omega_1\) such that \(|1|=0\) and \(|n|\) is the least ordinal \(\beta\) for which there is a number \(m\) with \((m, n) \in a_\beta\). If \(\alpha \in \mathcal{O}\), then \(n\) is said to be a notation for the ordinal \(|n|\). An ordinal \(\beta\) is constructive if \(\beta = |n|\) for some \(n \in \mathcal{O}\). Obviously \(m <_\mathcal{O} n\) implies \(|m| < |n|\). Hence \(<_\mathcal{O}\) is a wellfounded partial ordering.

**Definition 1.2.2.** \(\omega_1^{CK} =\) the least ordinal \(\alpha\) greater than \(|n|\) for every \(n \in \mathcal{O}\).

By induction on ordinals \(\beta < \omega_1^{CK}\), it is easy to see that for each \(n \in \mathcal{O}\), \(\{m \mid m <_\alpha n\}\) is a linear ordering under \(<_\mathcal{O}\).

**Remark 1.2.3.**

+   (i) A path \(x \subseteq \mathcal{O}\) is a set such that

\((\forall m, n \in x)(n <_\alpha m \lor m <_\alpha n \lor m = n) \land\)
\((\forall m)(\forall n \in x)(m <_\alpha n \to m \in x)\).

An interesting question is whether every path can be extended to one whose ordinal height is \(\omega_1^{CK}\). Such a path is necessary for carrying out effective transfinite induction. However, this is in general not true. Note that there are many possible choices of notations at a limit stage \(\beta\) below \(\omega_1^{CK}\). If every path up to \(\beta\) were extendible to one of ordinal height \(\omega_1^{CK}\), then there would be \(2^{\aleph_0}\) many sets of notations. Hence to obtain a path through \(<_\mathcal{O}\), one must choose the notations judiciously. We will show that there exists a “well-behaved” \(\Pi^1_1\)-path through \(<_\mathcal{O}\).

+   (ii) It is not difficult to see that the set of constructive ordinals forms an initial segment, and hence is equal to \(\omega_1^{CK}\).
