# Lemma 2.7.1. $y \in 	ext{BC}$ if and only if $T^y$ is a wellfounded tree. Hence $	ext{BC}$ is $\Pi^1_1$. Moreover $y \in \Sigma^y_eta$ if and only if $|T^y| \le eta + 1$.

Proof. If $T^y$ is wellfounded, then one may show by induction on the rank of $\sigma$, for $\sigma \in T^y$, that $(y)_\sigma$ belongs to BC.

If $y \in 	ext{BC}$, then for any $	au > \sigma$ in $T^y$ there exists a $y < eta$ such that $(y)_	au \in \Sigma_y$ and $(y)_\sigma \ge \Sigma_y$. Thus $T^y$ is a wellfounded tree.

Since $T^y \le_T y$ uniformly and $y \in 	ext{BC}$ if and only if $T^y$ is wellfounded, we conclude that $	ext{BC}$ is $\Pi^1_1$. We leave the verification of the last statement of the lemma to the reader.

# 2.7.2 Hyperarithmetic codes

A hyperarithmetic code is a real in $	ext{HYP} \cap 	ext{BC}$. Let $	ext{BC}(	ext{HYP})$ denote the collection of hyperarithmetic codes. By Corollary 2.2.2 and Lemma 2.7.1, $	ext{BC}(	ext{HYP})$ is $\Pi^1_1$.
