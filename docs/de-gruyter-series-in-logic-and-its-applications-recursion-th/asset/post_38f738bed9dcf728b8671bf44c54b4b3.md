
Theorem 12.1.13 has an interesting consequence. By the Low Basis Theorem (Exercise 1.5.3), there is a real x which is 2-DNR and x' ≡_T 0'. By Proposition 12.1.5, there is a nonempty Π^0_1 set which contains only Martin-Löf random reals. Then there is a Martin-Löf random real z ≤_T x since every 2-DNR real Turing computes a member of any given nonempty Π^0_1-set. By Theorem 12.1.13, there is no random real Turing equivalent to x. Thus we have the following:

**Theorem 12.1.14** (Kučera [76]). The collection of Turing degrees of Martin-Löf random reals is not upward closed.

On the other hand, the Turing degrees of Martin-Löf random reals may be downward closed, as implied by the following.

**Theorem 12.1.15** (Demuth [20]). Any y >_T 0 that is truth-table reducible to a Martin-Löf random real is Turing equivalent to a Martin-Löf random real.

Clearly every real Turing reducible to any recursively dominated x is tt-reducible to x. Hence the collection of Turing degrees of Martin-Löf random reals is downward closed for random reals that are recursively dominated. The following result gives another piece of evidence for the randomness thesis.

**Theorem 12.1.16** (Miller and Yu [103]). For any z, if x ≤_T y are Martin-Löf random and y is z-Martin-Löf random, then so is x.

## 12.2 Randomness via complexity theory

Intuitively, a random real is not predicated by any partial information about itself, and no information about its content is compressible. This is the basis for defining randomness in terms of complexity.

### 12.2.1 Plain Kolmogorov complexity

**Definition 12.2.1** (Solomonoff [146] and Kolmogorov [73]). Given a Turing machine $M$ and a finite string $\sigma \in 2^{<\omega}$, the $M$-Kolmogorov complexity of $\sigma$, $C_M(\sigma)$, is $\min\{|\tau| \mid M(\tau) = \sigma\}$.

If $U$ is a universal Turing machine, then for any Turing machine $M$, there is a constant $c_M$ such that \((\forall \sigma)(C_U(\sigma) \le C_M(\sigma) + c_M)\).

In other words, $C_U$ is optimal up to a constant. We drop the subscript $U$ and use $C$ to denote the plain Kolmogorov complexity function $C_U$. Then one may define a real x to be random if there is a constant $c$, such that \((\forall n)(C(x \mid n) \ge n - c)\). However, for any x and n, $x \mid \text{Code}(x \mid n)$ (where Code(x) is the natural number that codes a string $\sigma$) may be obtained from a final segment (say $\sigma$) of $x \mid \text{Code}(x \mid n)$ of length Code(x | n) - n via U. This is because once $\sigma$ is known, one may find a unique string $\tau$ such that $\tau$ codes $\tau$, i.e., $|\tau^\frown \sigma| = \text{Code}(\tau)$. Then $|\tau| = n$ and $\tau^\frown \sigma = x \mid \text{Code}(x \mid n)$. Thus we have $|\tau^\frown \sigma|$ following.

**Proposition 12.2.2** (Martin-Löf). For any real x, $\lim_{n} n - C(x \mid n) = +\infty$.

Proposition 12.2.2 says that there is no random real in the sense of plain Kolmogorov complexity leading to the next definition introduced by Levin and Chaitin.

**Definition 12.2.3.** (i) A set $A \in 2^{<\omega}$ is *prefix-free* if for any $\sigma \prec \tau \in 2^{<\omega}$, either $\sigma \notin A$ or $\tau \notin A$. (ii) A Turing machine $M$ is *prefix-free* if its domain is a prefix-free set.

**Definition 12.2.4** (Levin [83] and Chaitin [9]). Given a prefix-free Turing machine $M$ and a string $\sigma \in 2^{<\omega}$, the $M$-Kolmogorov complexity of $\sigma$, $K_M(\sigma)$, is $\min\{|\tau| \mid M(\tau) = \sigma\}$.

It is not difficult to see that there is a universal prefix-free Turing machine U and we use $K(\sigma)$ to denote $K_U(\sigma)$. The following technical theorem points a way to constructing a prefix-free machine.

**Theorem 12.2.5** (Levin [83] and Chaitin [9] and Schnorr [126]). Let $\{\langle d_i, \tau_i \rangle\}_{i < \omega} \subseteq \omega \times 2^{<\omega}$ be a recursive sequence such that $\sum_{i < \omega} 2^{-d_i} \le 1$. There exist a prefix-free machine M and strings $\sigma_i$ of length $d_i$ such that $M(\sigma_i) = \tau_i$ for all i and $\text{Dom}(M) = \{\sigma_i \mid i < \omega\}$. Furthermore, an index for M may be obtained effectively from an index for the sequence.

The following result summarizes some basic properties of K.

**Theorem 12.2.6** (Chaitin). (i) $\sum_{\sigma} 2^{-K(\sigma)} \le 1$; (ii) $(\exists c)(\forall \sigma)(K(\sigma) \le |\sigma| + K(|\sigma|) + c)$; (iii) $(\exists c)(\forall n)(\forall k)(|\{\sigma \in 2^n \mid K(\sigma) \le n + K(n) - k\}| \le 2^{n-k+c})$.

### 12.2.2 Characterizing randomness via complexity

The equivalence between Martin-Löf randomness and Kolmogorov complexity is given by the following:

**Theorem 12.2.7** (Schnorr). A real x is Martin-Löf random if and only if

```
(∃c)(∀n)(K(x ↾ n) ≥ n - c).
```

Chaitin [9] gave a “concrete” example of a Martin-Löf random real:

```
\Omega = \sum_{U(\sigma)\downarrow} 2^{-|\sigma|},
```

and several randomness notions have been characterized in terms of Kolmogorov complexity. The next two theorems characterize Martin-Löf randomness and 2-randomness respectively in terms of plain Kolmogorov complexity.

**Theorem 12.2.8** (Miller and Yu [103]). A real x is Martin-Löf random if and only if for every recursive function g with \sum_{n<\omega} 2^{-g(n)} < \infty,

```
(∃c)(∀n)(C(x ↾ n) ≥ n - g(n) - c).
```

**Theorem 12.2.9** (Miller [101] and Nies, Stephan, Terwijn [112]). A real x is 2-random if and only if

```
(∃c)(∀n)(∃m ≥ n)(C(x ↾ m) ≥ m - c).
```

2-randomness may also be characterized via prefix-free Kolmogorov complexity as follows:

**Theorem 12.2.10** (Ding, Downey, and Yu [173] and Miller [102]). A real x is 2-random if and only if

```
(∃c)(∀n)(∃m ≥ n)(K(x ↾ m) ≥ m + K(m) - c).
```

A connection between Martin-Löf randomness and the two notions of complexity is given by the following theorem:

**Theorem 12.2.11** (Miller and Yu [103]). x ∨ y is Martin-Löf random if and only if

```
(∃c)(∀n)(K(x ↾ n) + C(y ↾ n) ≥ 2n - c).
```

There is a natural way of comparing two reals in terms of plain and prefix-free complexities:

**Definition 12.2.12.** Write x ≤_K y (resp. x ≤_C y) if and only if

```
(∃c)(∀n)(K(x ↾ n) ≤ K(y ↾ n) + c)
```

(resp. (∃c)(∀n)(C(x ↾ n) ≤ C(y ↾ n) + c)).

By combining van Lambalgen's Theorem 12.1.7 and Theorem 12.2.11, we have the following conclusion.

**Corollary 12.2.13** (Miller and Yu [103]). Suppose that $x, y, z$ are Martin-Löf random. If $x \le_K y$ or $x \le_C y$ and $x$ is $z$-Martin-Löf random, then so is $y$.

It is not known whether strong Martin-Löf randomness is $\le_K$-upward closed. By Theorem 12.11.0, Corollary 12.2.13 says that higher complexity entails stronger randomness in a set. However, the following two results hint at a more subtle picture.

**Theorem 12.2.14** (Miller [102]). If $x$ is $2$-random, then $|\{y \mid x \le_K y\}| = \aleph_0$ and $|\{y \mid x \le_C y\}| = \aleph_0$.

**Theorem 12.2.15** (Miller and Yu [104]). There are two Martin-Löf random reals $x$ and $y$ such that $|\{z \mid x \le_K z \le_K y\}| = 2^{\aleph_0}$.

### 12.2.3 K-triviality

**Definition 12.2.16.** A real $x$ is $K$-trivial if $(\exists c)(\forall n)(K(x \mid n) \le K(n) + c)$.

Thus a $K$-trivial real is one that is far from being random. It is immediate that every recursive real is $K$-trivial. However, the class of $K$-trivial reals includes nonrecursive members all of which are recursive in a fixed real.

**Theorem 12.2.17** (Solovay [151]). There is a nonrecursive $K$-trivial real.

**Theorem 12.2.18** (Nies [110]). If $x$ is $K$-trivial, then $x' \le_T \emptyset'$.

**Theorem 12.2.19** (Kučera and Slaman [77]). There is an $x$ with $x' \equiv_T \emptyset'$ which computes every $K$-trivial real.
