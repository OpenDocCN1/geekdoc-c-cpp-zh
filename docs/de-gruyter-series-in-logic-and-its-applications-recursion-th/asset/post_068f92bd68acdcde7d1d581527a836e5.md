
### Substep 2 (Coding $x_n$). For each $k$, define

```
$T_{n+1,1,k} = \mathcal{T}(R_1(T_{n+1,0}^{L_k(x_n)}), x_n, T_{n+1,0}).$
```

By the discussion above, there are recursive functions $f, g$ so that $\Phi_{f(k)}^y = x_n$ and $\Phi_{g(k)}^y = T_{n+1,1,k}$ for all $y \in [T_{n+1,k}]$. By the Recursion Theorem, there is a $k_1$ such that $\Phi_{k_1}^y = \Phi_{g(k_1)}^y = T_{n+1,1,k_1}$ for all $y \in [T_{n+1,1,k_1}]$. Define $\sigma_{n+1,1} = R_1(T_{n+1,0}^{L_{k_1}(x_n)})$ and $T_{n+1,1} = T_{n+1,1,k_1}$.

### Substep 3 (Forcing a minimal cover). This is the only place where $z''$ is used.

Case 1. There exists $\alpha \in T_{n+1}$ and a number $l_k$ such that for all $m > l_k, T_1 \supseteq \sigma, (t_1, t_2) \subset T_{n+1,1} \supset \Phi_{k_1}^{t_1}(m) \downarrow \wedge \Phi_{k_2}^{t_2}(m) \downarrow$ implies $\Phi_{k_1}^{t_1}(m) = \Phi_{k_2}^{t_2}(m)$. Choose the least such $\sigma \in T_{n+1,1}$ in the sense of the coding of strings. Define $S = T_0^{l_k}$. For each $k$, define $S_k = S^R(S^{(l_k)})$. By the Recursion Theorem again, there is a $k_2$ so that $\Phi_{k_2}^y = S^R(S^{(l_k)})$ for all $y \in [S^R(S^{(l_k)})]$. Define $\sigma_{n+1} = R_1(S_k^{(l_k)})$ and $T_{n+1} = S^{n+1}$.

Case 2. Otherwise, for each $k$ define $S_k = T_{n+1,1}^{k-1}$. Then we can $S_1$-recursively find a perfect tree $P_k$ of $S_k$ such that for all $y \in [P_k]$, $\Phi_k^y$ is total and for all $\tau_0, \tau_1 \in P_k$ for $\tau_0 \sqsubset \tau_1$ then there is an $i$ such that for all reals $z_0 \supset \tau_0$ and $z_1 \supset \tau_1$, $\Phi_k^i(i) \downarrow \neq \Phi_k^i(i) \downarrow$. By the Recursion Theorem, there is a $k_2$ such that $\Phi_{k_2}^y = P_k$ for all $y \in [P_k]$. Let $T_{n+1} = P_{k_3}$ and $\sigma_{n+1} = R_1(T_{n+1,1}^{L_{k_3}(x_n)}) \in T_{n+1}$.

Let $e_{n+1} = k_3$. Then $\Phi_{e_{n+1}}^z = T_{n+1}$ for all $y \in [T_{n+1}]$. This completes the construction at step $n+1$.

Note that by induction on $n, T_n \le_T \oplus_{i<n} X_i$.

Finally, let $z = \bigcup_n \sigma_n$.

By the construction, $T_{n+1} \nleq_T \oplus_{i<n+1} X_i$ for every $n \in \omega$. If $\sigma_n^z$ is total and $\Phi_{e_{n+1}}^z \nleq \oplus_{i<n+1} X_i$, then we have Case (2) at Substep 3 of Step $n+1$. Then it is obvious that $z \le_T \Phi_{e_{n+1}}^z$. Hence $z$ is a minimal cover of $A$.

We show that $z'' \ge_T x$. This is proved by induction on $n$ that $x(n)$ may be $z''$-uniformly computed. To do this, we argue that the index $e_n$ is uniformly computed from $z''$.

Suppose we are at step $n+1$. By inductive hypothesis, assume that $z''$ recursively computes the index $e_n$. By the construction, we have $\Phi_{e_n}^z = T_n$ for all $y \in [T_n]$. Use $z$ to recursively find an initial segment of $z$ which is $R_1(T_n^{L_n(x_n)})$ or $L_1(T_n^{L_n(x_n)})$ for some $k_0$. In the first case, $x(n) = 0$. In the second case, $x(n) = 1$. Note that $\Phi_{k_0}^z$ is the perfect tree in Substep 1 of the construction. Now $z$-recursively find $k_1$ such that $R_1((\Phi_{k_0}^z)^{L_{k_1}(x_n)}) \supset z$. Then $\Phi_{k_1}^z = \mathcal{T}(R_1((\Phi_{k_0}^z)^{L_{k_1}(x_n)}), x_n, T_{n+1,0}) = T_{n+1,1}$. Use $z''$ to decide which case $\Phi_{k_1}^z$ is in. In Case 1, we $z''$-recursively find the least $\sigma \in T_{n+1,1}$ with the required property. Let $S = T_0^{l_k}$. Then use $z$ to compute the $k_2$ such that $\Phi_{k_2}^z = S^R(S^{(l_k)})$. Then $e_{n+1} = k_2$ and $T_{n+1} = \Phi_{k_2}^z$. In Case 2, use $z$ to compute the $k_2$ such that $R_1(T_{n+1,1}^{L_{k_2}(x_n)}) \le z$. Then by the construction, $e_{n+1} = k_2$ and $T_{n+1} = \Phi_{k_2}^z$. Thus $z'' \ge_T x$.

### Theorem 8.3.2 (Chong and Yu [15]). Assume \((\omega_1)^L = \omega_1\). There is a \(\Pi^1_1\)-maximal chain in the Turing degrees.

Proof. By Lemma 8.3.1, P is a \(\Delta^1_1\)-cofinally progressive relation. Hence by Theorem 8.2.4, there is a \(\Pi^1_1\)-set A as prescribed. J(ii) implies that A is a maximal chain.

## 8.3.2 Antichains in the Turing degrees

Given a partial ordering \((P, <_P)\), a set \(A \subseteq P\) is an *antichain* if any distinct \(x, y \in A\) are \(<_P\)-incomparable. A is *maximal* if it is not a proper subset of an antichain.

Define a binary relation P(x, y) to hold if either (1) or (2) below is satisfied:

- 1. There exist \(n \neq m\) such that \((x)_n \neq (x)_m\) but \((x)_n\) is Turing comparable with \((x)_m\);
- 2. \(\{(x)_n \mid n \in \omega\} \cup \{y\}\) is an antichain such that
  - (2a) \(x \oplus y \in L_{\omega_1^{x,y}}\),
  - (2b) \(\{(x)_n \mid n \in \omega\} \cup \{(y)_0\}\) is an antichain, and
  - (2c) for every \(r <_L y\), \(\{(x)_n \mid n \in \omega\} \cup \{r\}\) is not an antichain.

### Lemma 8.3.3. If \(2^\omega = (2^\omega)^L\), then P is a cofinally progressive relation.

Proof. Fix \(y_0\). Given x, let \(X = \{(x)_n \mid n \in \omega\}\). Assume that the set \(X \cup \{y_0\}\) is an antichain of Turing degrees. We show that for any \(y_1 \ge_T (x \oplus y_0)''\), there is a z such that

- 1. \(z'' \ge_T y_1\),
- 2. \(y_0 \le_T z \le_T y_1\),
- 3. \(X \cup \{z\}\) is an antichain.

Then given a constructible \(y_{-1}\) and a countable antichain \(X \cup \{y_0\}\) such that for every \(r <_L y_0\), \(X \cup \{r\}\) is not an antichain, by Proposition 4.3.4, there is a \(y_1 \ge_T (y_{-1} \oplus X \oplus y_0)''\) such that \(y_1 \in L_{\omega_1^{y_1}}\). Then by (1)-(3) above, there is a z such that \(z \equiv_T y_1\) (and hence \(y_0 \notin z \in L_{\omega_1^{y_0,x}}\)) and \(X \cup \{z\}\) is an antichain. Thus \(P(x, y_0 \oplus z)\) is cofinally progressive.

We construct a real z such that \((z \oplus x)_0'' \ge_T y_1\) and the following requirements are satisfied:

```
\(N_{e,i} : \Phi_e^{z \oplus y_0}_i \text{ is total} \Rightarrow \Phi_e^{z \oplus y_0}_i \neq \langle x \rangle_i.\)
```

Then \(X \cup \{z \oplus y_0\}\) is an antichain. The real z is obtained as the union of a sequence of finite strings \(\sigma_0 < \sigma_1 < \cdots\).

### Construction

- Step 0. Let \(\sigma_0 = \emptyset\).
- Step n + 1 = (e, i).

### Substep 1 (Satisfying \(N_{e,i}\)). Consider the following statement:

```
\((\exists \tau \supseteq \sigma_n)(\forall \tau_0, \tau_1 \supseteq \tau)(\forall m)(\Phi^{\tau_0 \oplus y_0}(m) \downarrow \land \Phi^{\tau_1 \oplus y_0}(m) \downarrow \rightarrow \Phi^{\tau_0 \oplus y_0}(m) = \Phi^{\tau_1 \oplus y_0}(m)).\)
```

If the statement is true, then find the (lexicographically) least such \(\tau\) and define \(\sigma_{n+1}^0 = \tau\). Then for every real \(z \supset \sigma_{n+1}^0\), \(\Phi_e^{z \oplus y_0}\) is total implies \(\Phi_e^{z \oplus y_0} \le_T y_0\). Thus \(\Phi_e^{z \oplus y_0} \neq (x)_i\) since \(X \cup \{y_0\}\) is an antichain. If the statement is false, then find the least \(\tau_0 \supseteq \sigma_n\) for which there exists a (least) \(\tau_1 \supseteq \sigma_n\) such that \(\Phi^{\tau_0 \oplus y_0}(m) \downarrow \neq \Phi^{\tau_1 \oplus y_0}(m) \downarrow\) for some \(m\). Define \(\sigma_{n+1}^0 = \tau_1\) where \(\Phi^{\tau_1 \oplus y_0}(m) \neq (x)_i(m)\).

### Substep 2 (Coding \(y_1\)). Define \(\sigma_{n+1} = (\sigma_{n+1}^0)^\frown \langle y_1(n) \rangle\).

Finally, let \(z = \bigcup_n \sigma_n\).

Since \(y_0 \not\le_T (x)_i\) for all \(i\), the same conclusion holds for \(z \oplus y_0\). By the construction, \(z \oplus y_0 \not\le_T (x)_i\) for all \(i\), and so \(X \cup \{z \oplus y_0\}\) is an antichain.

To see that \((z \oplus y_0)'' \ge_T y_1\), consider the statement in Substep 1. The statement is decidable by \(y_0''\). If it is true, then we \(y_0''\)-recursively find the least such \(\tau\). Then \(\tau = \sigma_{n+1}^0\). Otherwise, we can \(y_0''\)-recursively find both \(\tau_0\) and \(\tau_1\). In this case we use \(z\) to decide which string is the \(\sigma_{n+1}\). Thus \(y_1(n) = 0\) if and only if \(z(\sigma_{n+1}^0 + 1) = 0\). Moreover, \(\sigma_{n+1} = z \upharpoonright [\sigma_{n+1}^0 + 1)\). Hence the sequence \((\sigma_n)_n\) can be computed from \(z \oplus y_0''\). Therefore \((z \oplus y_0)'' \ge_T z \oplus y_0'' \ge_T y_1\).

Clearly the entire construction can be decoded by \(y_1\). Thus \(y_1 \ge_T z\).

### THEOREM 8.3.4 (Chong and Yu [16]). Assume \((2^\omega)^L = 2^\omega\). There exists a \(\Pi^1_1\)-thin maximal antichain in the Turing degrees.

Proof. By Lemma 8.3.3, P is a cofinally progressive relation. Note that (2c) is equivalent to

```
\(L_{u^{[\kappa,n]}}(x, y) \models (\exists \beta)((y)_0 \in L_\beta \land (\forall z \in L_\beta)(z <_L (y)_0 \rightarrow (\exists n)((x)_n \ge_T y \lor y \succ_T (x)_n))).\)
```

Thus P is \(\Pi^1_1\). Hence by Theorem 8.2.4, there is a \(\Pi^1_1\) set A with the prescribed properties. Using (3ii), we show by induction on \(<_L\) that A is an antichain.

Suppose \(x \in A\) and \(\{y \mid y \in A \land y <_L x\}\) is an antichain. By (i), there is a \(z\) coding \(\{y \mid y \in A \land y <_L x\}\) so that \(P(z, y)\) holds. Then by (2), \(\{(z)_n \mid n \in \omega\} \cup \{y\}\) is an antichain. So A is an antichain. Note that \(A \in c\). This together with Lemma 4.3.1 implies that A is a thin set. By (2b) above, A is maximal.
