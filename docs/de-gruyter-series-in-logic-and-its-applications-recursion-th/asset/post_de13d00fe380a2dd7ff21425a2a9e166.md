
Now suppose that there is a \(\le_M\)-sequence \(\langle F_n \rangle_{n<\omega}\) such that for each \(n\), (a) \(F_n\) is uniformly degree invariant via \(t_n\), and (b) \(F_{n+1} \le_M F_n\) on the cone \(\{x \mid x \ge_T z_n\}\).

Let \(z = \Phi_{n<\omega} z_n\) and \(\langle t_n, e_0, e_1 \rangle = t_\infty(e_0, e_1)\). For each \(n\), we define sets \(A_n\) and \(B_n\) for the pair \((F_{n+1}, F_n)\) to be the corresponding set \(A\) in Lemma 7.2.1 and Lemma 7.2.2 respectively. Then for every \(n\), I has a winning strategy \(\delta_n\) for \(G_n\) for \(y = z \oplus t \oplus (\Phi_{n<\omega} \delta_n) \oplus (\Phi_{n<\omega} \bar{\delta}_n)\). Then as in the proof of Lemma 7.2.1, there is a y-arithmetical relation \(P(x_0, x_1)\) such that for any \(n\), \(F_{n+1}(y)\) is the unique real \(x\) for which \(P(x, F_n(y))\) holds. Note that by Lemma 7.2.2, \(F_{n+1}(y) \le_T F_n(y)\) for every \(n\).

## Proposition 7.2.3 (Steel [157])

Let \(R \subseteq 2^\omega \times 2^\omega\) be an arithmetical relation. If \(\langle x_n \rangle_{n<\omega}\) is a sequence of reals such that \(x_{n+1}\) is the unique \(y\) satisfying \(R(y, x_n)\), then for some \(n\), \(x'_{n+1} \le_T x_n\).

Proof. Suppose for the sake of contradiction that \(x'_{n+1} \le_T x_n\) for each \(n\). Define

\(P(x, i, j) \Leftrightarrow (\exists k > j + 1)(\exists \sigma \in \omega^{<\omega})(|\sigma| = j + 1 \wedge \Phi_e^{(x)}(i) = x \wedge (\forall k' < k)R(\Phi_{\sigma(k')}^{\sigma(k+1)}, \Phi_{\sigma(k)}^{\sigma(k)}) \wedge (\exists e)(\Phi_e^x(i) = 0 \wedge \Phi_e^x = (\Phi_{\sigma(k)}^{\sigma(j+1)})).\)

By assumption on the sequence \(\langle x_n \rangle_{n<\omega}\), for any \(n\) we have

\((\forall i)(\forall j)(P(x_n, i, j) \Leftrightarrow (\exists k > j + 1)(i \notin (x_{n+k})^{(j+1)})).\)

Since \(P\) is arithmetical, there exist \(m\) and \(e\) such that

\(P(x, i, j) \Leftrightarrow \Phi_e^{(m)}(i, j) = 1.\)

Then for any \(n, i, j\),

\(\Phi_e^{(x_n)}(i, j) = 1 \Leftrightarrow (\exists k > j + 1)(i \notin (x_{n+k})^{(j+1)}).\)

Setting \(j = m\), there is an \(e_0\) such that for every \(i\),

\(\Phi_{e_0}^{(x_n)}(i) = 1 \Leftrightarrow \Phi_e^{(x_n)}(i, m) = 1 \Leftrightarrow (\exists k > m + 1)(i \notin (x_{n+k})^{(m+1)}).\)

When \(i = e_0\), we have for any \(n\),

\(e_0 \in (x_n)^{(m+1)} \Leftrightarrow (\exists k > m + 1)(e_0 \notin (x_{n+k})^{(m+1)}).\)

Thus \(e_0 \in (x_0)^{(m+1)}\) if and only if \((\exists k > m + 1)(e_0 \notin (x_k)^{(m+1)})\), and \(e_0 \in (x_{k_0})^{(m+1)}\) if and only if \((\exists k > m + 1)(e_0 \notin (x_{k_0+k})^{(m+1)})\). Then \(e_0 \in (x_0)^{(m+1)}\) if and only if \(e_0 \in (x_{k_0+k})^{(m+1)}\). By the equivalence above again, \(e_0 \in (x_0)^{(m+1)}\) if and only if \(e_0 \notin (x_0)^{(m+1)}\), a contradiction.

Relativizing Proposition 7.2.3 to \(y\), there is an \(n\) such that \(F_{n+1}(y)' \not\le_T F_n(y)\), which contradicts our assumption on the sequence \(\langle F_n \rangle_{n<\omega}\) and Lemma 7.2.2. We therefore have:

## Lemma 7.2.4

Assume ZF + AD + DC, the partial order \(\le_M\) on increasing uniformly degree invariant functions is well-ordering.

In conclusion, we have the following theorem.

## Theorem 7.2.5 (Steel [159], Slaman and Steel [142])

Assume ZF + AD + DC, Martin's conjecture (6.6.9) holds for uniformly degree invariant functions.

## Remark 7.2.6

H. Friedman [30] proved that there is a hyperarithmetic predicate R and a sequence \(\{x_n\}_{n<\omega}\) such that \(x'_{n+1} \le_T x_n\) and \(x_{n+1}\) is the unique y satisfying \(R(y, x_n)\).

## 7.3 The Posner–Robinson Theorem

### 7.3.1 The original Posner–Robinson Theorem

## Theorem 7.3.1 (Posner and Robinson [114])

For any nonrecursive \(x \le_T 0'\), there is a g such that \(x \oplus g \equiv_T g' \equiv_T 0'\).

Thus given a nonrecursive \(\Delta^0_2\)-real x, Theorem 7.3.1 says that there is a g relative to which x is its Turing jump.

Proof. To prove this, we use a method due to Jockusch and Shore [57]. Fix \(x >_T 0\) to be \(\Delta^0_2\). We may assume that x is not r.e.. For every e, consider the following statement:

\((\forall \alpha \in 2^\omega)(\exists n)(n \in x \wedge (\forall \tau \supseteq \sigma \supseteq 0^n1)(\Phi_e^\tau(e)[s] \uparrow) \vee (n \notin x \wedge (\exists \tau \supseteq \sigma \supseteq 0^n1)(\Phi_e^\tau(e)[s] \downarrow)).\)

Since x is not r.e., \((\sharp_e)\) is true for every e. We construct g by induction.

Step 0: Define \(g_0 = \emptyset\).

Step s + 1:

- Substep 1. Define \(g(s, 1) = g_s^\frown 0'(s)\).

- Substep 2. Find the least n such that either

  \((n \in x \wedge \forall \tau \supseteq g(s, 1)^\frown 0^n 1)(\Phi_s^\tau(s)[s] \uparrow)\)

  or

  \((n \notin x \wedge (\exists \tau \supseteq g(s, 1)^\frown 0^n 1)(\Phi_s^\tau(s)[s] \downarrow)).\)

By \((t_s)\), such an n exists. In the first case, define \(g_{s+1} = g(s, 1) \ulcorner 0^s 1 \urcorner\). In the second case, select the lexicographically least \(\tau\) such that \(\tau \supseteq g(s, 1) \ulcorner 0^s 1 \urcorner (\Phi_s^\tau(s)[|\tau|] \downarrow)\). Define \(g_{s+1} = \tau \ulcorner 1 \urcorner\).

Let \(g = \bigcup_{s < \omega} g_s\). Note that the construction is uniformly \(x \oplus \emptyset'\)-recursive. Hence \(\emptyset' \geqslant_T x \oplus \emptyset'\). We show that \(0'(s)\) and \(g_s\) are uniformly \(g \oplus x\)-recursive. Suppose we have computed \(g_s\), and \(0'(s)\). Then \(0'(s + 1) = g(|g_s| + 1)\). To compute \(g_{s+1}\), search for the unique \(n\) such that \((g \upharpoonright |g_s| + 1) \ulcorner 0^s 1 \urcorner < g\). By the construction, either

- (1) \(n < s\) or
- (2) \(n \notin x\) and there is a \(\tau \supseteq (g \upharpoonright |g_s| + 1) \ulcorner 0^s 1 \urcorner\) such that \(\tau < g\) and \(\Phi_s^\tau(s)[|\tau|] \downarrow\).

If (1) holds, then \(g(s+1) = \langle g \upharpoonright |g_s| + 1 \rangle \ulcorner 0^s 1 \urcorner\). If (2) holds, then there is a unique \(\tau \supseteq (g \upharpoonright |g_s| + 1) \ulcorner 0^s 1 \urcorner\) such that \(\tau < g\) and \(\Phi_s^\tau(s)[|\tau|] \downarrow\). It follows that \(g_{s+1} = \tau\). Thus \(\emptyset' \geqslant_T g \oplus x\).

To prove \(g' \leq_T g \oplus \emptyset'\), observe that for every \(e\) there is an \(n\) such that either \(\Phi_e^{g \oplus \emptyset'}(e) \downarrow\) or \(\Phi_e^\tau(e) \downarrow\) for any \(\tau > g \upharpoonright n\). Using this, one verifies immediately that \(g' \leq_T g \oplus \emptyset'\). \(\square\)

### 7.3.2 A transfinite Posner-Robinson Theorem

Theorem 7.3.1 may be iterated into the transfinite in several different ways. Here is the first version.

## Theorem 7.3.2 (Slaman and Steel [142])

Let \(0 < b < \omega_1^{CK}\) and let \(z\) be a real such that \(0^{(y)} <_T z\) for each \(y < b\). Then there is a \(g\) such that \(g \oplus z \equiv_T g^{(b)}\).

The rest of the section is devoted to a proof of Theorem 7.3.2.

Let \(a \in \mathcal{O}\). The first step is to introduce an enumeration of arithmetical predicates indexed by \(|a|\). By Theorem 1.3.4, the set \(\{b \mid b <_O a\}\) is r.e. Applying the Recursion Theorem, we may assume that there is a partial recursive function \(\Phi : a^2 \to \omega\) such that for each \(b <_O a\), \(\{\Phi(b, i)\}_{i < \omega}\) is an enumeration of the set of Gödel numbers of "\(\Sigma_b^0\)-predicates". To simplify notations, we identify a predicate with its Gödel number.

We introduce an enumeration of \(\Sigma_b^0\) predicates by induction. The enumeration of \(\Sigma_1^0\)-predicates is standard. If \(b = 2^e \in \mathcal{O}\) and \(b <_O a\), then a predicate \(P(x, n)\) is the \(i\)-th \(\Sigma_b^0\)-predicate, or \(P(x, n) = P_{\Phi(b, i)}(x, n)\), if \(P(x, n) \leftrightarrow (\exists m)\neg Q(x, n, m)\) where \(Q(x, n, m)\) is the \(i\)-th \(\Sigma_b^0\)-predicate.

If \(b = 3 \cdot 5^e \in \mathcal{O}\) and \(b <_O a\), then a predicate \(P(x, n)\) is the \(i\)-th \(\Sigma_b^0\)-predicate, or \(P(x, n) = P_{\Phi(b, i)}(x, n)\), if \(P(x, n) \leftrightarrow P_{\Phi(i, \Phi(b, n))}(x, n)\), where \(P(i, \Phi(b, n)) = (i_0(n), i_1(n))\) so that \(i_0(n) <_O b\) for every \(n\). The next lemma is proved by induction on the notation of \(b\) and is left to the reader.

## Lemma 7.3.3

There exist recursive functions \(f : \omega \to \omega\) and \(g : \omega \to \omega^2\) such that for any \(b <_O a\),

- (i) if \(b = 1\) or \(2^e\), then \(P_{\Phi(b, f(b))} \equiv_T H_{f(b)}^2\) via \(g(b)\);
- (ii) if \(b = 3 \cdot 5^e <_O a\), then \(P_{\Phi(b, f(b))} \equiv_T H_{f(b)}^2\) via \(g(b)\).
