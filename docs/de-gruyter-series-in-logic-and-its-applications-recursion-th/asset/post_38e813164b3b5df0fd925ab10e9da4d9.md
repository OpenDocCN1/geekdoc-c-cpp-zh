## 3.2 Admissible sets

The universe of sets $V$ is defined inductively on ordinals:

```
\( V_0 = \emptyset, \)
\( V_{\beta+1} = \mathscr{P}(V_\beta), \)
\( V_\lambda = \bigcup_{\alpha < \lambda} V_\alpha \text{ when } \lambda \text{ is a limit ordinal, and} \)
\( V = \bigcup_\alpha V_\alpha. \)
```

**Definition 3.2.1.** An *admissible structure* (or an admissible set) is a model \(\mathfrak{M}\) of KP of the form \(\mathfrak{M} = \langle M, \in_M \rangle\) where \(M\) is a transitive set in \(V\) and \(\in_M\) is the restriction of \(\in\) to \(M\). We will often write \(\in_M\) simply as \(\in\) if the context is clear.

**Definition 3.2.2.** The *ordinal* of a transitive structure \(\mathfrak{M}\), denoted \(o(\mathfrak{M})\), is the least ordinal not in \(M\). An ordinal \(\alpha\) is *admissible* if \(\alpha = o(\mathfrak{M})\) for some admissible structure \(\mathfrak{M}\).

A relation \(S \subseteq M^n\) on \(\mathfrak{M}\) is \(\Sigma_n\) if there is a \(\Sigma_n\)-formula \(\varphi\) such that

```
\( S(a_1, a_2, \dots, a_n) \Leftrightarrow \mathfrak{M} \vDash \varphi(a_1, a_2, \dots, a_n). \)
```

We allow parameters in the above definition. Clearly both \(a\) and \(\{a\}\) are \(\Sigma_1\) for any \(a \in M\). Moreover, it follows from Theorem 3.1.5 that for \(\mathfrak{M}\) admissible, \(\Sigma_1\)-relations are closed under \(\vee, \wedge, \exists x \in a, \forall x \in a\) and \(\exists x\).

### 3.2.1 The smallest admissible set

**Definition 3.2.3.** A set \(a \in V\) is *hereditarily finite*, written \(a \in \text{HF}\), if \(\text{TC}(a)\) is finite.

HF can be redefined by induction as follows:

```
HF(0) = 0,
HF(n + 1) = {a | a ⊆ HF(n)},
HF = ∪_{n<ω} HF(n).
```

Thus HF = V_ω. We leave the following theorem as an exercise.

### Theorem 3.2.4. HF is the smallest admissible set.

(HF, ε) is the first natural example of an admissible set we encounter. There is a natural and standard way of identifying n as a natural number (in arithmetic) and n as a finite ordinal (in set theory). We will follow the convention of identifying these two objects. The following theorem highlights an important connection between recursion theory and admissibility theory, and explains the reason for introducing admissible sets in the study of generalized recursion theory.

### Theorem 3.2.5. Let S be a relation on the natural numbers. Then S is r.e. if and only if S is Σ1 over (HF, ε).

Proof. It is sufficient to assume that S is infinite. The class of r.e. relations is the class of relations which are Σ1-definable over (ω, +, ·, 0, 1, <) in the language of first order arithmetic. Thus for the "only if" part, it is sufficient to show that if S ⊆ ω is Σ1 over (ω, +, ·, 0, 1, <), then it is Σ1 over (HF, ε) in the language of set theory. It is obvious that the set of ordinals in HF, i.e. ω, is Δ1-definable over (HF, ε). Now it is routine to show that if S is defined by an open formula φ involving +, ·, then it is defined over (HF, ε) by a Δ1-formula φ* in the language of set theory. Also "u < v" is definable over (HF, ε) by "u ∈ v". Hence any open formula defining S involving +, ·, < is definable by a corresponding Δ1-formula over (HF, ε) in the language of set theory.

For S defined by a bounded formula φ in the language of set theory (∃i < n) ψ where ψ is open, let φ* be (∃u ∈ n) ψ*(u), where ψ* is the Δ1-formula corresponding to ψ (note that the "n" in φ* denotes the finite ordinal n). Define φ* for φ of the form (∀i < n) ψ and ψ open, in the obvious way. By induction on the complexity of formulas, any S ⊆ ω defined by a bounded formula in the language of first order arithmetic has a corresponding definition via a Δ1-formula in the language of set theory over (HF, ε).

Now assume that S = (m|(∃i)ψ(i, m)) where ψ is a bounded formula in arithmetic. By induction, let ψ* be Δ1 such that (ω, +, ·, 0, 1, <) ⊨ ψ(n, m) if and only if (HF, ε) ⊨ ψ*(n, m). Then n ∈ S if and only if

```
(HF, ε) ⊨ (∃u)(u is an ordinal ∧ ψ*(u, m)).
```

Hence S is Σ1 over (HF, ε).

For the other direction, we first define a function \( f : \omega \to \text{HF} \) as follows:

```
f(0) = 0,
f(1) = {0},
f(2^{n_1} + 2^{n_2} + \dots + 2^{n_k}) = {f(n_1), f(n_2), \dots, f(n_k)}.
```

It is straightforward to verify that \( f \) is a bijection. Furthermore,

- \( f \) is \(\Delta_1\) over \((\text{HF}, \in)\).
- Define \( f^*(n) = m \) if and only if \( m \) as an ordinal is the set \( f(n) \). Then the relation "\( f(n) = m' \) is recursive.
- The set \( T_\varphi = \{(n_1, n_2, \dots, n_k) \mid (\text{HF}, \in) \models \varphi(f(n_1), f(n_2), \dots, f(n_k))\} \) is recursive for each \(\Delta_0\)-formula \(\varphi\).

Now if \( S \) is \(\Sigma_1\) over \((\text{HF}, \in)\), then there is a \(\Delta_0\)-formula \(\varphi\) such that \( S(m) \) if and only if there is a \( u \in \text{HF} \) with \((\text{HF}, \in) \models \varphi(u, m)\). Thus \( S(m) \) if and only if \((\exists i)(\exists j)(f^*(i) = m \land (i, j) \in T_\varphi)\). We conclude that \( S \) is an r.e. relation.

By the proof of Theorem 3.2.5, we have the following result.

**Proposition 3.2.6.** For any \( S \subseteq \text{HF} \), there is an \( x_S \subseteq \omega \) such that \( S \) is \(\Delta_1\)-definable in \((\text{HF}, \in, x_S)\) and \( x_S \) is \(\Delta_1\)-definable in \((\text{HF}, \in, S)\).

_Proof._ By the proof of Theorem 3.2.5, there is a bijection \( f : \omega \to \text{HF} \) which is \(\Delta_1\)-definable in \((\text{HF}, \in)\). Define \( n \in x_S \) if and only if \( f(n) \in S \).

Model-theoretically, Theorem 3.2.5 may be viewed as a biinterpretation of \(\Sigma_1\)-formulas between \((\text{HF}, \in)\) and \((\omega, \in)\) (see [52]).

## 3.3 Constructibility

The constructible universe \( L \) was introduced by Gödel [37] to prove the consistency of the Generalized Continuum Hypothesis and the Axiom of Choice. Jensen [55] developed the fine structure theory of \( L \) and the theory has had a deep impact on higher recursion theory.

### 3.3.1 The constructible universe

Expand the language of set theory \(\mathscr{L}\) with a unary relation symbol \(\dot{A}\) and denote it as \(\mathscr{L}^{\dot{A}}\).

**Definition 3.3.1.** Let \(A\) be a set. Given a set \(X\), we say that \(Y\) is *definable relative to \(A\) over the structure* \((X, \in, A \cap X)\), written \(Y \in Def^A(X)\), if there is a formula \(\varphi(\mathbf{v})\) in \(\mathscr{L}^{\dot{A}}\) such that upon interpreting \(\dot{A}\) to be \(A \cap X\), we have \(Y = \{y \mid (X, \in, A \cap X) \models \varphi(y)\}\).

By recursion on ordinals, define

\(L_0[A] = 0,\)
\(L_{\beta+1}[A] = Def^A(L_\beta[A]),\)
\(L_\lambda[A] = \bigcup_{\beta<\lambda} L_\beta[A], \text{if } \lambda \text{ is a limit ordinal.}\)

Define \(L[A] = \bigcup_\beta L_\beta[A]\), and \(L = L[\emptyset]\). Obviously \(L[A]\) is a proper class.

If \(x \in L[A]\), then \(x\) is said to be \(A\)-constructible. In particular, \(x\) is constructible if \(A = 0\). The construction of \(L\) is uniformly \(\Sigma_1\)-definable over any admissible structure \(\mathcal{M}\), in the sense of the following theorem whose proof we omit. It involves a tedious coding device that is \(\Sigma_1\)-definable by appealing to Theorem 3.1.8. For details, see [22].

**Theorem 3.3.2.** There exists a \(\Sigma_1\)-formula \(\varphi(u, v)\) such that for any admissible structure \(\mathcal{M}\) and ordinal \(\beta \in M\), \(\mathcal{M} \models \varphi(\beta, x)\) if and only if \(x = L_\beta\). Moreover, \(L_\beta\) is the unique set such that \(\mathcal{M} \models \varphi(\beta, x)\). Hence \(L_\beta\) is uniformly \(\Delta_1\)-definable over \(\mathcal{M}\).

There is a recursion-theoretic way of generating \(L\) via the following set of primitive recursive operators introduced by Gödel:

- (i) \(F_0(x, y) = \{x, y\}.\)
- (ii) \(F_1(x, y) = x \setminus y.\)
- (iii) \(F_2(x, y) = x \times y = \{x, y\}.\)
- (iv) \(F_3(x, y) = \{(u, z, v) \mid z \in x \wedge (u, v) \in y\}.\)
- (v) \(F_4(x, y) = \{(u, v, z) \mid z \in x \wedge (u, v) \in y\}.\)
- (vi) \(F_5(x, y) = \bigcup x.\)
- (vii) \(F_6(x, y) = \{y \mid \exists z(z, y) \in x\}.\)
- (viii) \(F_7(x, y) = \in \cap x \times x.\)
- (ix) \(F_8(x, y) = \{z_1 \mid \exists z_0((z_0, z_1) \in x \wedge z_0 \in y)\}.\)
- (x) \(F_9(x) = A \cap x.\)

Let

\(\mathcal{S}^A(U) = U \cup \{U\} \cup \bigcup_{i \le 9} \{z \mid (\exists x \in U \cup \{U\})(\exists y \in U \cup \{U\})(z = F_i(x, y))\}\)

and

\(\mathcal{R}^A(U) = \bigcup_{n < \omega} (\mathcal{S}^A)^n(U).\)
