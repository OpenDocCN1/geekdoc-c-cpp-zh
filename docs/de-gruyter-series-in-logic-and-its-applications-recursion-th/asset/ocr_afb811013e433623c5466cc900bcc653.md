By Theorem 1.3.4, there is a recursive function $h$ such that for $n \in O_1$, $W_{h(n)}$ is the set of Gödel numbers of ranked formulas of rank at most $|n|$.

We now define the structure $\mathcal{A}(\omega_1^{CK}, x) = \bigcup_{\beta < \omega_1^{CK}} \mathcal{A}(\beta, x)$, where $x$ is a real that interprets $x$. $\mathcal{A}(\omega_1^{CK}, x)$ is a collection of reals defined in an analogous way as Gödel's $L$. The construction is completed in $\omega_1^{CK}$-many stages. Any ranked set variable $x^\rho$ is to be interpreted by a real in $\bigcup_{y \subseteq \beta} \mathcal{A}(y, x)$. With this as our convention, the satisfaction relation $\bigcup_{y \subseteq \beta} \mathcal{A}(y, x) \models \varphi$ is well defined for a ranked formula $\varphi$ of rank at most $\beta$. We define $\mathcal{A}(\omega_1^{CK}, x)$ by induction on the recursive ordinals, as follows:

$\mathcal{A}(O, x) = \{x\} \cup \omega$.

Suppose $\beta > 0$ and $\mathcal{A}(y, x)$ is defined for all $y < \beta$. Given a ranked formula $\varphi(n)$ with rank at most $\beta$ and whose only free variable is $n$, let

$i \in Z_\varphi \Leftrightarrow \bigcup_{y < \beta} \mathcal{A}(y, x) \models \varphi(i)$.

Let $B$ be the collection of reals $z_\varphi$ for such $\varphi$'s. Set

$\mathcal{A}(\beta, x) = \bigcup_{y < \beta} \mathcal{A}(y, x) \cup B$.

Thus the reals constructed at stage $\beta$ are precisely those arithmetically defined by the reals constructed at earlier stages.

For a formula $\varphi$, the satisfaction relation $\mathcal{A}(\omega_1^{CK}, x) \models \varphi$ is defined by induction:

+   - if $\varphi$ is ranked with rank at most $\beta$, then $\mathcal{A}(\omega_1^{CK}, x) \models \varphi$ if and only if $\bigcup_{y \subseteq \beta} \mathcal{A}(y, x) \models \varphi$;

+   - if $\varphi$ is $(\exists z)\varphi(z)$, then $\mathcal{A}(\omega_1^{CK}, x) \models \varphi$ if and only if there is a $\beta < \omega_1^{CK}$ and a $z^\beta$ such that $z^\beta \in \mathcal{A}(\omega_1^{CK}, x)$ and $\mathcal{A}(\omega_1^{CK}, x) \models \varphi(z^\beta)$;

+   - if $\varphi$ is $\neg \psi$, then $\mathcal{A}(\omega_1^{CK}, x) \models \varphi$ if and only if $\mathcal{A}(\omega_1^{CK}, x) \not\models \psi$.

A sentence $\varphi$ in $\mathcal{L}(\omega_1^{CK}, x)$ is $\Sigma_1^1$ if it is ranked, or of the form $(\exists x_1)\cdots(\exists x_n)\psi$ for some formula $\psi$ with no unranked set variables bounded by a quantifier. It is not difficult to see that the set of Gödel numbers of $\Sigma_1^1$-sentences is $\Pi_1^1$. Let “$\varphi$” be the code of the formula $\varphi$.

# Theorem 5.1.1. The set $\{(x, \text{“}\varphi\text{”}) \mid \varphi \text{ is } \Sigma_1^1 \land \mathcal{A}(\omega_1^{CK}, x) \models \varphi\}$ is $\Pi_1^1$.

Proof. By $\Sigma$-induction (Theorem 3.1.8) and the definition of $\mathcal{A}(\omega_1^{CK}, x)$, there is a $\Sigma_1$-formula $\psi(u)$ such that $(L_\omega[x], x) \models \psi(u^{\text{“}\varphi\text{”}})$ if and only if $\varphi$ is ranked $\land \mathcal{A}(\omega_1^{CK}, x) \models \varphi$. Hence by the Spector-Gandy Theorem (3.2.2), the set $\{(x, \text{“}\varphi\text{”}) \mid \varphi \text{ is ranked} \land \mathcal{A}(\omega_1^{CK}, x) \models \varphi\}$ is $\Pi_1^1$. Now if $\varphi$ is of the form $(\exists z)\varphi(z)$, then $\mathcal{A}(\omega_1^{CK}, x) \models (\exists z)\varphi(z)$ if and only if there is an $n \in O_1$ such that $\mathcal{A}(\omega_1^{CK}, x) \models (\exists z|n)\varphi(z^{\omega[n]})$. It follows that the set $\{(x, \text{“}\varphi\text{”}) \mid \varphi \text{ is } \Sigma_1^1 \land \mathcal{A}(\omega_1^{CK}, x) \models \varphi\}$ is $\Pi_1^1$.

# Corollary 5.1.2. For $\beta < \omega_1^{CK}$, the set $\{(x, \text{“}\varphi\text{”}) \mid \text{rank}(\varphi) \text{ is at most } \beta \land \mathcal{A}(\omega_1^{CK}, x) \models \varphi\}$ is $\Delta_1^1$.
