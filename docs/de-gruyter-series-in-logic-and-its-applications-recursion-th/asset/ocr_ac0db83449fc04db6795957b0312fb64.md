# 5.3 Sacks forcing

The notion of forcing with perfect sets over the ramified analytical hierarchy was introduced by Gandy and Sacks [36] in their construction of a set with minimal hyperdegree. The origin of perfect set forcing, however, traces back to Spector's proof of the existence of a minimal Turing degree [154]. As will be seen, the construction of a minimal hyperdegree is much more intricate as it requires a detailed analysis of the complexity of the forcing relation \(\Vdash\).

# 5.3.1 Perfect set forcing over the ramified analytical hierarchy

Let \(\mathscr{S}\) be the collection of hyperarithmetic perfect sets. Each \(S \in \mathscr{S}\) is a condition for Sacks forcing. Given two conditions \(S, T \in \mathscr{S}\), we say that \(S \le T\) if \(S \subseteq T\).

Let \(\varphi\) be a sentence in the language of ramified analytical hierarchy \(\mathscr{L}(\omega_1^{CK}, x)\).

Define \(T \Vdash \varphi\) as follows.

+   - If \(\varphi\) is ranked, then \(T \Vdash \varphi\) if \((\forall x \in T)(\exists \alpha(\omega_1^{CK}, x) = \varphi)\);
+   - If \(\varphi(y)\) is unranked and \(T \Vdash \varphi(y \mid \varphi)\) for some \(\varphi\) of rank at most \(\beta\), then \(T \Vdash (\exists y^\beta)\varphi(y)\);
+   - \(T \Vdash (\exists y)\varphi(y)\) if and only if \(T \Vdash (\exists y^\beta)\varphi(y^\beta)\) for some \(\beta < \omega_1^{CK}\);
+   - if \(\varphi(n)\) is unranked and \(T \Vdash \varphi(\bar{n})\) for some number \(m\), then \(T \Vdash (\exists n)\varphi(n)\);
+   - if \(\varphi\) and \(\psi\) are unranked, \(T \Vdash \varphi\) and \(T \Vdash \psi\), then \(T \Vdash \varphi \land \psi\);
+   - if \(\varphi\) is unranked and \((\forall S)(S \le T \rightarrow \neg S \Vdash \varphi)\), then \(T \Vdash \neg \varphi\).

Note that while the definition of Cohen forcing for ranked sentences is by induction on the complexity of the sentence, that of Sacks forcing is given directly. This immediately implies the following.

**Lemma 5.3.1.** If \(T \Vdash \varphi\) and \(S \le T\), then \(S \Vdash \varphi\).

By Theorem 5.1.1 and the definition of forcing, we have

**Lemma 5.3.2.** The set \(\{(T, \ulcorner \varphi \urcorner) \mid \varphi \text{ is } \Sigma_1^1 \wedge T \Vdash \varphi\}\)

is \(\Pi_1^1\).

**Lemma 5.3.3.** (Fusion Lemma) Let \(T\) be a condition and \(((i, \varphi_i))_{i < \omega}\) be a hyperarithmetic set of \(\Sigma_1^1\) formulas. Assume that \((\forall i)(\forall y \in T)(\exists S \le P)(S \Vdash \varphi_i)\).

Then \((\exists S \le T)(\forall i)(S \Vdash \varphi_i)\).

Proof. Using the notation \(P \Vdash n = \{ \tau \in 2^{<\omega} \mid \tau \in P \}\), define \(\mathfrak{R}\) by

\(\mathfrak{R}(i, \alpha, R, P) \Leftrightarrow \alpha \in R \wedge P \subseteq R \wedge P \Vdash |\alpha| = \{ \tau \mid \tau < \alpha \} \wedge P \Vdash \varphi_i \}.\)
