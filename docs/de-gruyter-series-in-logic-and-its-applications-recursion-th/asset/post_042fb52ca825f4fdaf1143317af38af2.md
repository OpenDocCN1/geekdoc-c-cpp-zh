
Thus \(O_1^s \subseteq O\) is a \(\Pi_1^1\)-path through \(O\), yielding the following theorem.

### THEOREM 2.6.4 (Feferman and Spector [26]). There is a \(\Pi_1^1\)-set \(O_1 \subseteq O\) such that \(<_O\) restricted to \(O_1\) is a well-ordering of order type \(\omega_1^{CK}\).

The proof of Theorem 2.6.4 is essentially model-theoretic. A purely recursion-theoretic proof can be found in Sacks [123]. The results in this section may also be uniformly relativized. Namely, there is a \(\Sigma_1^1\)-set \(\{ (x, O^{x+*}) \mid x \in 2^\omega \}\) such that for each x, \(O^{x+*}\) is a proper end extension of \(O^x\) (a nonstandard \(O^x\)).

## 2.6.3 A regular path through O

Despite the apparent complexity of the partial ordering on O, there is a \(\Pi_1^1\)-path through it in which every proper initial segment is recursive. This indicates that there exists certain regularity hidden within \(<_O\).

### THEOREM 2.6.5 (Jockusch [56]). There is a set \(O \subseteq O\) such that

- \(<_O\) (Definition 1.2.1) is a well-ordering of order type \(\omega_1^{CK}\) on O;
- O is \(<_O\)-downward closed, and
- for any \(n \in O\), \(\{ m \mid m <_O n \}\) is recursive.

Proof. First, observe that by the Padding Lemma in classical recursion theory, we may assume that

```
\((\forall m \in O)(\forall n \in O)(n +_O m > \max\{m, n\}).\)
```

By the s-m-n Theorem, there is a recursive function \(g_0\) such that for every m,

```
\(\varphi_{g_0(e, m, 0)} = \varphi_e(\varphi_m(0)) \land (\forall n)(\varphi_{g_0(e, m)(n+1)} = \varphi_{g_0(e, m)}(n) +_O \varphi_e(\varphi_m(n+1)).\)
```

Define a recursive function \(h_0\) as follows:

```
\(\varphi_{h_0(e)}(n) = \left\{ \begin{array}{ll} 1 & n = 1, \\ 2^{\varphi_e(k)} & n = 2^k, \\ 3 \cdot 5^{\varphi_e(k)} & n = 3 \cdot 5^k, \\ \uparrow & \text{Otherwise.} \end{array} \right.\)
```

By the Recursion Theorem, there is a constant c such that \(\varphi_{h_0(c)} = \varphi_c\). Then \(\varphi_c\) is total on O. Note that \(\varphi_c(1) = 1\), \(\varphi_c(2^n) = 2^{\varphi_c(n)}\), and if \(n = 3 \cdot 5^k\), then \(\varphi_c(n) = 3 \cdot 5^w\) where \(\varphi_w(n) = \varphi_c(\varphi_c(n))\) and \(\varphi_w(j+1) = \varphi_w(j) +_O \varphi_c(\varphi_c(j+1))\). \(\varphi_c\) follows the format set in (i)-(iv) of § 1.2.1 with the additional property that for \(n = 3 \cdot 5^k\), \(\varphi_c(n)\) gives an index w of a recursive function that is recursively defined from \(\varphi_c\). Thus intuitively one may view this as a version of O on the range of \(\varphi_c\). Let \(i \in O^* \setminus O\). We claim that the set

```
\(O = \{ m \mid (\exists n \in O)(m <_O \varphi_c(n) \land n <_{O^*} i) \}\)
```

is as required. We first leave it as an exercise to verify that

- (1) \(\Phi_e\) is strictly increasing in the sense of \(<_O\);
- (2) for each \(j_0\) and \(m\), if \(\Phi_\omega(j_0) \le_O n <_O \Phi_\omega(j_0 + 1)\), then there is a \(j_1 \in \Theta\) such that \(m = \Phi_e(j_0) \vdash_O j_1\).

Since \(n <_O m\) implies \(\Phi_e(n) <_O \Phi_e(m)\), \(<_O\) is a well-ordering on \(O\). Note that for any \(n \in O, |n| \le |\Phi_e(n)|\). Hence \(\Phi_e : \{n \in O \mid n <_O \cdot\} \to O\) is an embedding and hence \(<_O\) is a well-ordering of order type \(\omega_1^{CK}\) on \(O\). By performing induction over the standard ordinal notations \(<_O\) below \(i\), one easily sees that \(O\) is \(<_O\)-downward closed.

By Theorem 1.3.4, there is a recursive function \(g_1\) such that \(W_{g_1(n)} = \{j \mid j <_O n\}\) for any \(n \in O\). We claim that \(W_{g_1(n)}\) is a recursive set when restricted to \(n \in O\). It will then follow that the set \(\{(j, k) \mid j <_k n <_O n\}\) is recursive as well.

By an effective transfinite induction together with an application of the Recursion Theorem, we will define a partial recursive function \(q\) such that \(W_{q(n)} = \omega \setminus W_{g_1(n)}\) for \(n \in O\). The case \(n = 2^k\) and \(\Phi_e(n) = 2^{\Phi_e(k)}\) is left to the reader as an exercise (Exercise 2.6.1). Suppose \(n = 3 \cdot 5^k\) and \(\Phi_e(3 \cdot 5^k) = 3 \cdot 5^w\), where \(w\) is as defined earlier, and \(e\) is given such that \(\Phi_e(\Phi_e(j))\) is defined for each \(j < \omega\). First note that an induction on \(j\) shows that \(\Phi_\omega(j) \ge j\). If for each \(j\), \(W_{\Phi_e(\Phi_e(j))} = \omega \setminus W_{g_1(\Phi_e(j))}\), then we claim

\(m \in \bigcup_{j < \omega} W_{g_1(\Phi_e(j))} \iff (\exists j_0 \le m)(m \in W_{g_1(\Phi_e(j_0+1))}).\)

The proof of the claim from right to left is immediate. For the other direction, let \(j_0\) be such that \(\Phi_\omega(j_0) \le_O m < \Phi_\omega(j_0 + 1)\). Then by (2) there is a \(j_1 \in \Theta\) such that \(\Phi_\omega(j_0) \vdash_O j_1 = m\). This implies that \(j_0 \le \Phi_\omega(j_0) \le m\). Since \(m \le_O \Phi_\omega(j_0 + 1)\), we have proved the Claim.

Hence \(\bigcup_{j < \omega} W_{g_1(\Phi_e(j))} = \omega \setminus \bigcap_{j < \omega} \Phi_\omega(\Phi_e(j))\) is recursive. Now this calculation is uniform, and hence there is a recursive function \(g_2\) such that if \(W_{\Phi_e(\Phi_e(j))} = \omega \setminus W_{g_1(\Phi_e(j))}\) for every \(j\), then \(W_{g_2(e,w)} = \bigcap_{j < \omega} W_{\Phi_e(\Phi_e(j))}\). Let \(g_3\) be a recursive function such that \(W_{g_1(e,w)} = W_e \setminus \{w\}\). Recall that if \(\Phi_e(3 \cdot 5^k) = 3 \cdot 5^w \in O\), then \(\Phi_\omega(j + 1) = \Phi_\omega(j) \vdash_O \Phi_e(j + 1)\). Let \(W_{c_1} = \omega\).

Define a recursive function \(h_1\) as follows:

\(\Phi_{h_1(e)}(n) = \begin{cases} c_1 & n=1, \\ g_3(\Phi_e(m), m) & n=2^m, \\ g_2(e, w) & n=3 \cdot 5^w, \\ \uparrow & \text{Otherwise.} \end{cases}\)

By the Recursion Theorem, there is a \(d\) such that \(\Phi_{h_1(d)} = \Phi_d\). Let \(q = \Phi_d\). Then \(q\) is as required.

## 2.7 Codes for sets

In § 2.2.3, a method of coding \(\Delta^1_1\)-sets was introduced. However, the method does not provide an effective way of tracking the construction of \(\Delta^1_1\)-sets. Here we discuss the method of hyperarithmetic coding which serves as a useful tool for performing inductive analysis of \(\Delta^1_1\) sets of reals.

### 2.7.1 Borel codes

*Throughout this section, fix an effective enumeration* \(\{\sigma_i\}_{i < \omega}\) *of* \(\omega^{<\omega}\)*.*

For each \(x \in 2^\omega\), define \((x)_n = \{m \mid 2^n \cdot 3^m \in x\}\). Define a sequence \(\{\Sigma_\beta\}_{\beta < \omega_1}\) of sets of reals as follows:

- \(\beta = 0\): Let \(\Sigma_0 = \{x \in 2^\omega \mid 0\}\).

- \(\beta > 0\): Let \(\Sigma_\beta = \{x \in 2^\omega \mid (\forall n)(\exists \gamma < \beta)((x)_n \in \Sigma_\gamma)\}\).

Let BC = \(\bigcup_{\beta < \omega_1} \Sigma_\beta\) be the set of Borel codes. For each \(x \in\) BC, define \(A_x\) to be:

\(x \in \Sigma_0\): \(A_x = \bigcup_{i \in x} \{ \sigma_i \}\).

\(\beta > 0\) and \(x \in \Sigma_\beta\): \(A_x = \bigcup_n (2^\omega \setminus A_{(x)_n})\).

If \(\sigma\) is the empty string, let \((y)_\sigma = y\). For each \(\sigma \in \omega^{<\omega}\), define

\((y)_\sigma = (\dots ((y)_{\sigma(1)})_{\sigma(2)}) \dots )_{\sigma(|\sigma|)}\).

Given a real \(y\), we define a tree \(T' \le_T y\) over \(\omega^{<\omega}\) as follows:

\(\emptyset \in T';\)

For any \(\sigma \in T'\), if \((y)_\sigma \in \Sigma_0\) then \(\sigma\) will have no extension in \(T'\). Otherwise, \(\sigma^\frown n \in T'\) for every \(n\).
