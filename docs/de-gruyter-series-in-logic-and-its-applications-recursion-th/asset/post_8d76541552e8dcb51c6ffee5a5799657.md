
Proof. By Theorem 1.3.4, define a \(\Sigma^1_1\)-predicate \(P(x, y)\) to be the conjunction of the following three sentences:

\(x^{[1]} = 0,\)

\((\forall e)(3 \cdot 5^e \in O^y \to x^{[3 \cdot 5^e]} = \bigcup_x x^{[\Phi_e^x(0)]}),\)

and

\((\forall n)(2^n \in O^y \to x^{[2^n]} = \{1\} \cup \{k \mid (\exists j)(k = 2^j \wedge j \in x^{[1]})\} \cup \{k \mid (\exists e)(k = 3 \cdot 5^e \land (\forall j)(\Phi_e^x(j) <_O \Phi_e^x(j+1) \in x^{[1]}))\}).\)

Define a \(\Pi^1_1\)-set \(A = \{(m, n, y) \mid (\forall z)(P(z, y) \to \langle m, n, z \rangle \in z)\}\). It is easy to see that

\(n \in O^y \land m \in O^y_n \Leftrightarrow \langle m, n, y \rangle \in A.\)

The argument for (ii) is similar and is left as an exercise.

### Lemma 2.2.4. There is a recursive function g such that for all \(n \in O^y\), \(O^y_n = \Phi^{H^y_{g(n)}}_{g(n)}\).

Proof. We prove the unrelativized version. By the Recursion Theorem, we may assume that \(O_m = \Phi^{H_m}_{g(m)}\) for all m <_O n.

If n = 2^m, define

\(E = \{e \mid (\forall n)(\Phi_e(n) \downarrow \land \Phi_e(n) \in W_{f(\Phi_e(n+1))})\}\)

where f is the function in (i) of Theorem 1.3.4. Note \(E \le_T O^y\). If m \(\neq\) 1 and m \(\in\) O, then

\(k \in O_{2^m} \Leftrightarrow k = 1 \lor (\exists j)(k = 2^j \wedge j \in O_m) \lor (\exists e)(k = 3 \cdot 5^e \land e \in E \land (\forall j)(\Phi_e(j) \in O_m)).\)

Thus \(O_{2^m}\) may be computed by \(H_{2^m}\) via an oracle Turing machine whose index can be effectively obtained from g(m). Set the index to be g(n). Then \(O_n = \Phi^{H_{g(n)}}_{g(n)}\).

If n = 3 \(\cdot\) 5^e, then

\(i \in O_n \Leftrightarrow (\exists k)(i \in O_{\Phi_e(k)}) \Leftrightarrow (\exists k)(i \in \Phi^{H_{g(\Phi_e(k))}}_{\Phi_e(k)}).\)

By Lemma 2.1.2, \(H_{2^e \oplus 0}\) may be computed by \(H_n\), and hence by \(H_{2^e}\). uniformly. Thus \(O_n\) is \(\Sigma^1_1\) over \(H_n\) and so recursive in \(H_{2^e}\). Moreover, the computation from \(H_{2^e}\) is uniform. Hence the index i of the oracle Turing machine computing \(O_n\) from \(H_{2^e}\) can be obtained effectively. Set g(n) = i. Then \(O_n = \Phi^{H_{g(n)}}_{g(n)}\).

### Corollary 2.2.5. If x is \(\Delta^1_1(y)\), then x is hyperarithmetic in y.

Proof. If x is \(\Delta^1_1(y)\), then there is recursive function f such that \(n \in x \leftrightarrow f(n) \in O^y\). The set \(A = \{f(n) \mid n \in x\}\) is \(\Delta^1_1(y)\). By Spector's Boundedness Theorem (1.5.5), there is a number \(m \in O^y\) such that \(A \subseteq O^y_m\). Then \(n \in x \leftrightarrow f(n) \in O^y_m\). Hence \(x \le_T H^y_{2^m}\) by Lemma 2.2.4.

We have as a consequence the following characterization due to Kleene.

### Theorem 2.2.6 (Kleene [69]). A real $x$ is $\Delta_1^1(y)$ if and only if it is hyperarithmetic in $y$.

The following corollary says that $\Delta_1^1$-sets are strongly reducible to $H$-sets.

### Corollary 2.2.7. Every $\Delta_1^1$-real is many-one reducible to an $H$-set.

**Proof.** By Theorem 2.2.6, if $x$ is $\Delta_1^1$ then it is Turing reducible to $H_n$ for some $n \in \mathcal{O}$. Then $x$ is many-one reducible to $H_{2^n} = (H_n)'$.

## 2.2.2 $\Delta_1^1$-sets of reals

There is a subtle point regarding uniformity when it comes to defining the notion of hyperarithmetic sets of reals. For this, we define $\tilde{H}^x$-sets by induction on $\mathcal{O}$ rather than on $\mathcal{O}^x$:

$$\tilde{H}_1^x = x,$$

$$\tilde{H}_{2^x}^x = (\tilde{H}^x)'$$

and

$$\tilde{H}_{3 \cdot 5^e}^x = \langle \langle m, i \rangle \mid m \in \tilde{H}_{\phi_e(i)}^x \rangle.$$

### Definition 2.2.8. A set of reals $A$ is *hyperarithmetic* if there is a number $n \in \mathcal{O}$ and an index $e$ such that for all $x, x \in A \Leftrightarrow \phi_e^{\tilde{H}_n^x}(0) \downarrow$.

Hence if $A$ is hyperarithmetic, then there exist $n$ and $e$ such that

$$x \in A \Leftrightarrow (\exists \sigma)(\sigma < \tilde{H}_n^x \land \phi_e^\sigma(0) \downarrow)$$

and

$$x \notin A \Leftrightarrow (\forall \sigma)(\sigma < \tilde{H}_n^x \rightarrow \phi_e^\sigma(0) \uparrow).$$

It follows that Lemma 2.2.1 remains true for such $\tilde{H}^x$-sets and so $A$ is $\Delta_1^1$.

Conversely, assume $A$ is $\Delta_1^1$. According to the discussion in §1.5.1, there are two numbers $k_0$ and $k_1$ such that $x \in A \Rightarrow k_0 \in \mathcal{O}^x \Rightarrow k_1 \in \mathcal{O}^x$. By relativizing Corollary 1.5.4, there is a recursive function $p$ such that $\min\{|k_0|_x, |k_1|_x\} \le |p(k_0, k_1)|_x$ for all $x$. Let $n = 2^{p(k_0, k_1)}$. Note that $n \in \mathcal{O}^x$ for all $x$ and so $0 \in \mathcal{O}^x = 0$. Since Lemma 2.2.4 remains true, $\mathcal{O}_n^x = \tilde{H}_{\phi(n)}^x$ for all $x$. Hence there is a recursive function $h$ such that $k_0 \in \mathcal{O}_n^x \Leftrightarrow 0 \in W_{\tilde{H}_{\phi(n)}^x}$ for all $x$, giving $x \in A \Leftrightarrow \phi_{h(n)}^{\tilde{H}_n^x}(0) \downarrow$. Thus we arrive at the following conclusion.

### Theorem 2.2.9. A set of reals is hyperarithmetic if and only if it is $\Delta_1^1$.

Hyperarithmeticity also provides a scheme for inductive analysis of $\Delta_1^1$-sets of reals. We will show how this is implemented after introducing the ramified analytical hierarchy in §3.8. The notion of a hyperarithmetic code, to be introduced in §2.7, will also provide a powerful tool for the study of \(\Delta^1_1\)-sets of reals. The next proposition sets an effective bound on \(|n|_x\) if \(n \in O^x\) for all x.

### Proposition 2.2.10. If \(n \in O^x\) for all x, then there is a recursive ordinal \(\beta\) such that \(|n|_x < \beta\) for all x.

Proof. If not, \(m \in \text{WF}_0 \Leftrightarrow (\exists j)(\exists x)(\forall i)(\forall j)R_m(i, j) \rightarrow \langle f(i), f(j) \rangle \in W^{g(x)}_m)\) where g is the recursive function in (ii) of Theorem 1.3.4. So \(\text{WF}_0\) is \(\Sigma^1_1\), a contradiction.

It also follows from the discussion above that \(\omega^x_1 = \omega^{CK}_1\) if and only if every \(y \le_h x\) is recursive in \(H^x_n\) for some \(n \in O\).

## 2.2.3 Parametrization of \(\Delta_1^1\)-sets

As a first application of the results above, we demonstrate a parametrization of \(\Delta_1^1\)-reals.

### Proposition 2.2.11. There is a partial function \(D : \omega \times \omega \rightarrow \omega\) with a \(\Pi^1_1\)-graph \(G^D\) such that for all x, \(x \in \Delta^1_1 \Leftrightarrow (\exists m)(\forall i)(\forall j)(x(i) = j \leftrightarrow (m, i, j) \in D)\).

Proof. Define \(D = \{\langle n, e, i, j \rangle | n \in O \wedge \Phi^{H}_e \text{ is total} \wedge \Phi^{H}_e(i) = j\}\). By Theorem 2.2.6, for all x, \(x \in \Delta^1_1 \Leftrightarrow (\exists m)(\forall i)(\forall j)(x(i) = j \leftrightarrow (m, i, j) \in D)\). Moreover, \(\langle n, e, i, j \rangle \in D \Rightarrow n \in O \wedge (\forall z)(H(n, z) \wedge \Phi^z_e \text{ is total} \rightarrow \Phi^z_e(i) = j)\), where H is as defined in § 2.1.2. Hence \(G^D\) is \(\Pi^1_1\).

Proposition 2.2.11 may be applied to reduce certain \(\Sigma^1_2\)-predicates to \(\Pi^1_1\).

### Corollary 2.2.12. For any \(\Pi^1_1\)-predicate P(x, y), the predicate Q(y) \(\Leftrightarrow (\exists x \in \Delta^1_1)P(x, y)\) is \(\Pi^1_1\).

Proof. By Proposition 2.2.11, Q(y) \(\Leftrightarrow (\exists x \in \Delta^1_1)P(x, y)\) is equivalent to

\((\exists m)(\forall i)[\exists j((m, i, j) \in D) \land (\forall x)(\forall i)(\forall j)(x(i) = j \leftrightarrow (m, i, j) \in D) \rightarrow P(x, y)].\)

Note that for each m, if \((\forall i)(\exists j)((m, i, j) \in D)\), then the predicate \((m, i, j) \in D\) is \(\Delta^1_1\). Hence Q is \(\Pi^1_1\).
