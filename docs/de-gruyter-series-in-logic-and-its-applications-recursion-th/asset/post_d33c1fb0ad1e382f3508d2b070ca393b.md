Let \(\beta_1\) be the first such stage. One is not able to conclude that \(l_\beta\) is indeed the real value of \(f(0)\). Both \(l_\beta\), and the computed value of \(f(0)\) (as seen in \(T_0[\beta_1]\)) may change at a later stage. However, this situation does not occur infinitely often since otherwise either \(l_\beta\) goes to infinity or \(l_\beta = l\) infinitely often for some finite limit \(l\). In either case, since "\(\sigma\) is a terminal node in \(T_1\)" is a \(\Sigma_1\)-statement, \(z\) would be the leftmost path in \(T_1\), a contradiction. Hence incorrect guesses occur at most finitely many times and \(l_\beta\) reaches a limit after finitely many changes.

In general, to compute \(f(n)\) from \(z\) one imitates the guessing procedure for \(f(0)\). This will involve a finite injury argument. Thus once the finite sequence \((0, l_\beta^0)^\frown (1, l_\beta^1)^\frown \dots (n, l_\beta^n)\) matches the computed values of \(f \lceil n\) at stage \(s\), we set \(\beta_s\) to be \(\beta''\). The sequence and values of \(f \lceil n\) computed at a later stage may change, but changes happen at most finitely often. Hence \(l_\beta^n\) will reach a limit. Let \(y\) be the least upper bound of \(\{\beta_s\}_{s<\omega}\). Clearly \(y < \omega_1^{CK}\) and the limit of \(l_\beta|_{s<y}\) is an infinite path in \(T_0[y]\). Since \([T_0] = [T_0[y]]\), it is also an infinite path in \(T_0\). Moreover, it is the leftmost path. Hence \(z\) hyperarithmetically computes the leftmost path of \(T_0\). Using this, one shows by a decoding method that \(z \equiv_T x\).

We now proceed with the formal proof.

Define \(\alpha_s, \sigma_s^0, f_s(n)\) as follows. The aim is to ensure that \(\lim_{s \to \omega} f_s(n) = f(n)\).

Stage 0. Let \(\sigma_0^0 = 0\) and \(\beta_0 = f_0(n) = 0\) for every \(n\). We say that 0 receives attention. Assume that at stage \(s \ge 0\), \(\beta_s\) is defined and that if \(j \le s\) receives attention, then \(f_s(j)\) and \(\sigma_s^j\) are defined. Then \(z\) is said to be *correct up to j at \(\beta\)* if for every \(i \le j\), if \(0 < i\) then

- (1) \(f_s \lceil (i + 1)\) is the leftmost nonterminal node in \(T_0[\beta]\);
- (2) there exists a \(\sigma' < \sigma_s^i\) which is the leftmost splitting node of \(T_1[\beta]\) so that \(\sigma'\) has \(f_s(i)\)-many splitting nodes extending \(\sigma_s^{i-1}\) in \(T_1[\beta]\), and
- (3) for the \(\sigma'\) above, there is a node \(\sigma'' < \sigma'\), extending \(\sigma'\) which is the second leftmost splitting node extending \(\sigma'\) on \(T_1[\beta]\) so that \(\sigma_s^i\) is the next splitting node extending \(\sigma''\) in \(T_1[\beta]\).

Stage s + 1. Let \(j_{s+1}\) be the minimum of \(j \le s\) such that \(z\) is not correct up to \(j\) at \(\beta_s + 1\) if such a \(j\) exists, and let it be \(s + 1\) otherwise. Initialize each \(j > j_{s+1}\), and let \(f_{s+1}(j) = f_s(j)\) and \(\sigma_{s+1}^j = \sigma_s^j\) for \(j < j_{s+1}\). For \(j = j_{s+1}\), there are two cases:

Case 1. \(j_{s+1} = 1\) has not received any attention since its last initialization, if any. Let \(\beta_{s+1} = \beta_s + 1\), \(\sigma_{s+1}^{j_{s+1}} > \sigma_s^{j_{s+1}-1}\) be the next splitting node in \(T_1[\beta_{s+1}]\) and \(f_{s+1}(j_{s+1}) = 0\) and declare that \(j_{s+1}\) receives attention at stage \(s + 1\).

Case 2. Otherwise. Search for a \(\beta > \beta_s\) less than \(\omega_1^{CK}\) such that \(z\) is correct up to \(j_{s+1} - 1\) at \(\beta\), and there exists a \(\sigma < z\) extending \(\sigma_s^{j_{s+1}-1}\) for which there is an \(l\) satisfying

- (i) \(f_s \lceil j_{s+1} \lceil (j_{s+1}, l)\) is the leftmost nonterminal node in \(T_0[\beta]\);
- (ii) there exists a \(\sigma' < \sigma\) which is the leftmost splitting node of \(T_1[\beta]\) such that \(\sigma'\) has \(l\)-many splitting nodes extending \(\sigma'_{s-1}^{-1}\) in \(T_1[\beta]\), and
- (iii) for the \(\sigma'\) above, there is a node \(\sigma'' < \sigma\) extending \(\sigma'\) which is the second leftmost splitting node extending \(\sigma'\) in \(T_1[\beta]\) so that \(\sigma\) is the next splitting node extending \(\sigma''\) in \(T_1[\beta]\).

Suppose that during the search in Case 2, \(z\) is always correct up to \(j_{s+1} - 1\). By the definition of \(z\), \(\beta\) as stipulated exists. Then let \(\beta_{s+1} = \beta\), \(f_{s+1}(j_{s+1}) = l\) and \(\sigma'_{s+1}^{-1} = \sigma\). Declare that \(j_{s+1}\) receives attention at stage \(s + 1\). Otherwise, \(z\) is not correct up to \(j_{s+1} - 1\) at \(\beta\), and we replace \(j_{s+1}\) by \(j_{s+1} - 1\) to do the search. However, this process of replacement occurs only finitely many times since \(z\) is always correct up to 0 at any \(\beta\). This completes the construction.

Let \(\gamma = \bigcup_{s \in \omega} \beta_s\). Then \(\{\beta_s\}_{s \in \omega}\) is a \(\Delta_1(L_{\omega_1}[z])\)-sequence and hence \(\gamma < \omega_1^z\).

### **Lemma 11.1.4.** For every \(j\), there exists a stage \(s_j\) such that if \(s \ge s_j\) then \(z\) is correct up to \(j\) at \(\beta_s\).

Proof. Suppose otherwise. Let \(j^*\) be the least \(j\) such that for infinitely many \(s\), \(z\) is not correct up to \(j^*\) at \(\beta_s\). Then Case 2 in the construction applies to \(j^*\). Let \(s_{j^*-1}\) be the least stage such that for every \(s \ge s_{j^*-1}\), \(z\) is correct up to \(j^* - 1\) at \(\beta_s\). For \(s > s_{j^*-1}\), let \(\sigma_s^0\) be the \(\sigma^0\) defined in the construction for \(j^*\) at stage \(s\). In other words, for some initial segment \(\sigma\) of \(z\), \(\sigma_s^0 < \sigma\) is the leftmost splitting node of \(T_1[\beta_s]\) such that \(\sigma_s^0\) has \(f_s(j^*)\)-many splitting nodes extending \(\sigma_s^{0-1}\) in \(T_1[\beta_s]\). Note that for any \(s \ge s_{j^*-1}\), \(f_{s+1}(j^*) \ge f_s(j^*)\). Hence \(|\sigma_{s+1}^0| \ge |\sigma_s^0|\) whenever \(s > s_{j^*-1}\). Since for any \(r\), \(z\) is not the leftmost path of \(T_1[\gamma \cap r]\), \(\sigma^0 = \lim_s \sigma_s^0\) exists. Let \(s_1 > s_{j^*-1}\) be chosen such that \(\sigma_s^0 = \sigma^0\) for \(s \ge s_1\). By the construction, \(f_{s+1}(j^*) = f_s(j^*)\) for \(s \ge s_2\). It follows that there exists an \(s_{j^*} \ge s_1\) such that for all \(s \ge s_{j^*}\), \(\sigma_s^0 = \sigma_{s_{j^*}}^0 = \sigma^0\). Then for any \(s \ge s_{j^*}\), \(z\) is correct up to \(j^*\) at \(\beta_s\).

By Lemma 11.1.4, we may let \(f(j) = \lim_{s \to \omega} f_s(j)\). Obviously, \(\hat{f} \in L_{\omega+1}[z]\). Note that for any \(j\), \(T_0 \supseteq \sigma \langle \forall k \le j \rangle (\sigma(k) = \hat{f}(k))\). So \(\hat{f}\) is an infinite path in \(T_0\). By the construction, \(\hat{f} = f\) and hence \(f \in L_{\omega+1}[z]\). Since \(\hat{f} \notin \emptyset\), we have \(\emptyset \notin z\) and \(\omega_1^{CK} < \omega_1^z\). Then the construction may be decoded from \(z\). Thus \(z \not\ge_h x\). If \(x \not\ge_h \emptyset\), then \(x\) may also decode the construction so that \(x \not\ge_h z\).

The construction in the proof above yields a perfect tree \(T \le_T \emptyset\) with \([T] \subseteq A\) in which every infinite path \(x\) is hyperarithmetically above \(\emptyset\). This completes the proof of Theorem 11.1.2.

## 11.2 An antibasis theorem for \(\Pi^0_1\)-sets

### 11.2.1 An analysis of Theorem 11.1.1

A natural question arising from Theorem 11.1.1 is whether the condition \(x \ge_h \emptyset\) in the statement may be weakened to \(x^{(\beta)} \ge_T \emptyset\) or even \(x^{(\beta)} \ge_T 0^{(\beta+1)}\) for some \(\beta < \omega_1^{CK}\). The proof of the theorem requires at least \(\omega_1^{CK}\)-many iterates of the Turing jump. A negative answer is given by Harrington:

**Theorem 11.2.1 (Harrington [43]).** For any ordinal \(\beta < \omega_1^{CK}\), there is an uncountable \(\Pi^0_1\)-set \(A \subseteq \omega^\omega\) such that for each \(x \in A\), \(x^{(\beta)} \not\ge_T 0^{(\beta+1)}\).

We begin our discussion with the finite version of Theorem 11.2.1.

**Theorem 11.2.2.** There is an uncountable \(\Pi^0_1\)-set \(A \subseteq \omega^\omega\) such that for any \(x \in A\) and \(n < \omega\), \(x^{(n)} \not\ge_T 0^{(n+1)}\).

Harrington's proof uses an ingenious reverse induction construction. The following proof is more complicated than necessary, but the argument is applicable to a more general situation. By Theorem 2.1.4, the set \(H = \{(i, (0)^i) \mid i < \omega\} \subseteq \omega \times 2^\omega\) is \(\Pi^0_2\). Hence there is a recursive predicate \(P(i, \sigma, m)\) such that \((i, x) \in H \Leftrightarrow (\forall m)(\exists k)P(i, x \unknown k, m)\). Let \(T^\omega \subseteq \omega \times \omega^{<\omega}\) be a recursive tree such that

\((i, \sigma) \in T^\omega \Rightarrow (\exists m)(\exists s_m)(\sigma = \sigma_0 \oplus \sigma_1 \dots \sigma_s \mid \sigma_0 = s_m \wedge |\sigma_0| = 2^m \cdot 3^{s_m} \wedge s_m = \min\{|s| \mid (\forall l \le m)(\exists k \le s)P(i, \sigma_0 \unknown k, l)\})\).

It is easy to verify that for each \(i < \omega\), there is a unique \(z_i\) such that \((i, z_i) \in [T^\omega]\) and \(z_i = (0)^i \oplus y_i\) for some \(y_i \in \omega^\omega\). Hence uniformly each \(\emptyset^{(i)}\) is a \(\Pi^0_1\)-singleton (in \(\omega^\omega\)).
