# ## 8.4 Martin's conjecture for \(\Pi^1_1\)-functions

# ### 8.4.1 \(\Pi^1_1\)-Martin's conjecture in \(L\)

Since Borel determinacy is a theorem of ZF + DC [93], the results in Chapter 7 hold under ZF + DC for \(\Delta^1_1\)-functions. Since Chapter 7 is concerned with total functions, by Proposition 11.8 (v) the results apply to total \(\Pi^1_1\)-functions as well. However, the situation changes when it comes to partial \(\Pi^1_1\)-functions. Throughout this section, a function \(F\) is said to be \(\Pi^1_1\) if its graph \(G^F\) is \(\Pi^1_1\). We prove that Martin's conjecture fails for certain \(\Pi^1_1\)-functions under the assumption \(V = L\). For a start, Lemma 7.2.1 says (under ZF + AD + DC) that \(\le_M\) is a linear ordering for increasing uniformly degree invariant functions. The conclusion fails if one assumes \(V = L\).

**Theorem 8.4.1.** Assume \(V = L\). There is a \(\Pi^1_1\)-uniformly degree invariant function \(F\) that is increasing and order preserving on a cone such that for all \(y\), there exist reals \(x_0, x_1 \ge_T y\) satisfying \(F(x_0) \equiv_T x_0\) and \(F(x_1) \ge_T 0^{(\omega)}\).

Proof. Assume \(V = L\). Define \(P(x, y)\) as

\(y \in L_{\omega_1^y} \wedge 0^{O^y} = (y)_0 \wedge (y)_1 = x \wedge (y)_2 \text{ is the } <_L\text{-least real such that } (y)_2 \not<_T (y)_0.\)

Since "\(0^{O^y} = (y)_0\)" is \(\Pi^1_1\), \(P\) is a \(\Pi^1_1\)-cofinally progressive relation. By Theorem 8.2.4, there is a \(\Pi^1_1\)-set \(A\) satisfying the prescribed properties in J.

By the definition of P, every real is Turing below some real in A. Moreover, P ensures that \(<_T\) is a well ordering and consistent with \(<_L\) on A.

Define \(F(x) = y\) if

+   (1) \(y \in A\);
+   (2) \(x \le_T y\);
+   (3) \(x \not\ge_T 0 \Rightarrow (\forall n) x \not<_T ((y)_1)_n\).

Roughly speaking, \(y\) is the \(<_T\)-least real in \(A\) such that \(x \le_T y\).

By (3) and the property of \(A\), \(F\) is well defined. Furthermore, it is \(\Pi^1_1\), increasing, order persevering and uniformly degree invariant (\(x \equiv_T y\) implies \(F(x) = F(y)\)). Moreover, since \(F(x) = x\) for every \(x \in A\), we have \(F(x) \equiv_T x\) cofinally.
