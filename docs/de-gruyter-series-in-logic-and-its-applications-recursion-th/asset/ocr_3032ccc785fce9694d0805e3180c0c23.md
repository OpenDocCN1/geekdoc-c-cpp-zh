We now describe the construction of $x_0$ and $x_1$, and the associated strings in detail. For $1 \le i \le s$ and $\sigma, \tau \in T_i$, let $T_i(\sigma, \tau)$ be the set of strings in $T_i$ compatible with $\sigma$ and $\tau$), i.e.

$$T_i(\sigma, \tau) = \langle \sigma', \tau' \rangle \in T_i \mid \exists (\sigma'', \tau'') \in T_i (\sigma' \preceq \sigma'' \wedge \tau' \preceq \tau'' \wedge \sigma \preceq \sigma'' \wedge \tau \preceq \tau'') \rangle.$$

Note that it is unnecessary that $|\sigma| = |\tau|$ in the definition above.

We say that a string (or node) $\sigma^* \in 2^{<\omega}$ is splitting over $(\sigma, \tau)$ in $T_i$ if $\sigma^* \succeq \sigma$ and for $j \le 1$,

$$T_{i, \sigma^* \frown j}(\sigma, \tau) = \{ \langle \sigma', \tau' \rangle \mid \sigma' \succeq \sigma^* \frown j \wedge \tau' \succeq \tau \wedge \langle \sigma', \tau' \rangle \in T_i \}$$

contains an infinite path. Note that $\sigma^*$ does not lie on $T_i$ but some pair $(\sigma^*, \tau^*)$ does and we call $(\sigma^*, \tau^*)$ a splitting node on $T_i$.

For each $i \le 1$, we construct a sequence $(\sigma_{1,i,s}, \tau_{0,i,s}) < (\sigma_{1,i,1}, \tau_{1,i,1}) < \cdots$ on $T_i$ and let $x_i = \bigcup_j \sigma_{1,i,j}$. Again, the idea is to apply a “mutual coding” technique so that $x_0$ codes the leftmost witness function $f_1 = \cup_s r_{1,s}$ (in the $\Sigma^1_1$-definition) for $x_1$ and $x_1$ codes the leftmost witness function $f_0 = \cup_s r_{0,s}$ for $x_0$. In addition, we also assign $x_0$ the responsibility of coding $z$ as well as $f_0$. More precisely, for each $s \in \omega$ we use $\sigma_{0,s}$ to code $z(s)$, $f_0(s)$ and $\tau_{1,s-1}$, and use $\sigma_{1,s}$ to code $\tau_{0,s}$.

At stage 0, let $(\sigma_{1,i,0}, \tau_{1,i,0}) = (\emptyset, 0)$ for $i \le 1$. Without loss of generality, assume that $(\emptyset, \emptyset)$ is a splitting node in both $T_0$ and $T_1$.
