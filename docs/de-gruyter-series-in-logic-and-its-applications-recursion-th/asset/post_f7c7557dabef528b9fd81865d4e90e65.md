
By (2),

\(\mu(U_{n_0, <\beta_0} \cap [\sigma_0]) > \frac{1}{2} \cdot 2^{-|\sigma_0|}.\)

By (1) and (4),

\(\mu(\bigcap_{n>n_0} U_{n, <\beta_0} \cap [\sigma_0]) > \frac{1}{4} \cdot 2^{-|\sigma_0|}.\)

Hence there is a \(\sigma_1 > \sigma_0\) such that

\(\mu(\bigcap_{n>n_0} U_{n, <\alpha} \cap [\sigma_1]) > \frac{3}{4} \cdot 2^{-|\sigma_1|}.\)

Let \(n_1 = |\sigma_1| + 2\). There is a \(\beta_1 < \beta_0\) such that

\(\mu(U_{n_1, <\beta_0} \cap [\sigma_1]) > \frac{3}{4} \cdot 2^{-|\sigma_1|}.\)

Repeating the process, one obtains an infinite descending sequence \(\beta_0 > \beta_1 > \cdots\) of ordinals which is a contradiction. It follows that \(\{U_n\}_{n<\omega}\) is a generalized \(\Pi^1_1\)-ML test and \(x \in \bigcap_{n<\omega} U_n\).

**Theorem 14.2.13** (Chong, Nies and Yu). _There is a real which is_ \(\Pi^1_1\)_-ML random but not strongly_ \(\Pi^1_1\)_-ML random._

_Proof._ By Corollary 14.4.26, there is \(\Sigma^1_1\)-closed set _P_ of positive measure consisting only of \(\Pi^1_1\)-ML random reals. By Lemma 14.2.12, there is an \(x \in P\) which is not strongly \(\Pi^1_1\)-ML random.

## 14.3 \(\Pi^1_1\)-randomness

### 14.3.1 The largest \(\Pi^1_1\)-nullset

The notion of \(\Pi^1_1\)-randomness was introduced in Hjorth and Nies [51] and is unique to the study of higher randomness. There is no analog of this notion in the subject of classical randomness theory.

**Theorem 14.3.1** (Kechris [64]; Stern [161]; Hjorth and Nies [51]). _There is a largest_ \(\Pi^1_1\)_-nullset._

_Proof._ Define

\(\mathcal{P} = \{(\ulcorner \varphi \urcorner, x) \mid \varphi \text{ is a ranked formula} \land \Omega(\mathfrak{A}_1^{\text{CK}}, x) \vDash \varphi(x) \land \mu(\{x \mid \Omega(\mathfrak{A}_1^{\text{CK}}, x) \vDash \neg \varphi(x)\}) \ge 1\}\)

and

\(\Omega_{\ulcorner \varphi \urcorner} = \{x \mid (\ulcorner \varphi \urcorner, x) \in \mathcal{P}\}.\)

Define

\(\Omega = \bigcup_{n < \omega} \Omega_n \cup \{x \mid \omega_1^x > \omega_1^{\text{CK}}\}.\)

We show that \(\Omega\) is the largest \(\Pi^1_1\)-nullset. By Theorem 13.11.1, \(\Omega\) is \(\Pi^1_1\). Moreover, \(\mu(\Omega_n) = 0\) for all \(n < \omega\). By Theorem 13.1.4, \(\mu(\Omega) = 0\).

If \(A\) is a \(\Pi^1_1\)-nullset, then, by Corollary 3.74, there is an arithmetic formula \(\varphi(x, z)\) such that if \(\omega_1^x = \omega_1^{\text{CK}}\), then \(x \in A \Leftrightarrow \mathfrak{A}(\omega_1^x, x) \vDash (\exists y)\varphi(x, y)\). Hence if \(\omega_1^x = \omega_1^{\text{CK}}\), then \(x \in A \Leftrightarrow \mathfrak{A}(\omega_1^{\text{CK}}, x) \vDash (\exists y)\beta(\varphi, y^\beta)\) for some \(\beta < \omega_1^{\text{CK}}\). Since \(A\) is null, we have

\(A \cap \{z \mid \omega_1^z = \omega_1^{\text{CK}}\} \subseteq \bigcup_{\beta < \omega_1^{\text{CK}}} \Omega_{\ulcorner (\exists y)\beta(\varphi, y^\beta) \urcorner}.\)

Thus \(A \subseteq \Omega\).

**Corollary 14.3.2.** _For any_ \(x \in 2^\omega\)_, the following are equivalent:_

- (i) \(x\) is \(\Pi^1_1\)-random;
- (ii) \(x\) is strongly \(\Pi^1_1\)-ML random and \(\omega_1^x = \omega_1^{\text{CK}}\);
- (iii) \(x\) is \(\Pi^1_1\)-ML random and \(\omega_1^x = \omega_1^{\text{CK}}\).
- (iv) \(x\) is \(\Delta^1_1\)-random and \(\omega_1^x = \omega_1^{\text{CK}}\).

_Proof._ Suppose that \(x\) is \(\Pi^1_1\)-random. Since \(\{z \mid \omega_1^z > \omega_1^{\text{CK}}\}\) is a \(\Pi^1_1\)-nullset, we have \(\omega_1^x = \omega_1^{\text{CK}}\) and hence (i) \(\Rightarrow\) (ii) \(\Rightarrow\) (iii).

By Theorem 14.2.10, (iii) implies (iv). We now show (iv) \(\Rightarrow\) (i). By the proof of Theorem 4.31, if \(\omega_1^x = \omega_1^{\text{CK}}\) and \(x \in \Omega\), then \(x \in \Omega_n\) for some \(n\). Since \(\Omega_n\) is a \(\Delta^1_1\)-nullset, if \(\omega_1^x = \omega_1^{\text{CK}}\) and \(x\) is \(\Delta^1_1\)-random, then it is \(\Pi^1_1\)-random.

The equivalence between (i) and (iv) was also obtained by Stern [161].

### 14.3.2 Domination and \(\Pi^1_1\)-randomness

**Lemma 14.3.3.** If \(x\) is \(\Pi^1_1\)-random, then it is \(\Delta^1_1\)-dominated.

Proof. By the proof of Theorem 13.3.2, for each \(e \in \omega\) and \(n \in \omega\), the set \(A_{e,n} = \{x \mid (\exists f \in HYP)(\Phi_e^{f(x)} \text{ is total} \rightarrow \Phi_e^{f(x)} < f)\}\) has measure 1. Note that \(A_{e,n} \in \Pi^1_1\). By Corollary 13.11.1, there is a \(\Delta^1_1\)-set \(\hat{A}_{e,n} \subseteq A_{e,n}\) such that \(\mu(A_{e,n}) = 1\). Hence if \(x\) is \(\Pi^1_1\)-random, then \(x \in \hat{A}_{e,n}\). By Corollary 14.3.2, \(\omega_1^{CK} = \omega_1^x\). Thus if \(g \le_T x\), then \(g = \Phi_e^{f(x)}\) for some \(e\) and \(n \in \omega\), proving the lemma.

**Proposition 14.3.4** (Kjos-Hanssen, Nies, Stephan and Yu [68]). For any \(x \in 2^\omega\), the following are equivalent:

- (i) \(x\) is \(\Pi^1_1\)-random;
- (ii) \(x\) is strongly \(\Pi^1_1\)-ML random and \(\Delta^1_1\)-dominated;
- (iii) \(x\) is \(\Pi^1_1\)-ML random and \(\Delta^1_1\)-dominated;
- (iv) \(x\) is \(\Delta^1_1\)-random and \(\Delta^1_1\)-dominated;
- (v) \(x\) is \(\Pi^1_1\)-Kurtz random and \(\Delta^1_1\)-dominated.
- (vi) \(x\) is \(\Delta^1_1\)-Kurtz random and \(\Delta^1_1\)-dominated.

Proof. By Corollary 14.3.2 and Lemma 14.3.3, we have (i) \(\Rightarrow\) (ii) \(\Rightarrow\) (iii) \(\Rightarrow\) (iv) \(\Rightarrow\) (v) \(\Rightarrow\) (vi).

To prove (vi) \(\Rightarrow\) (i), it is sufficient to prove (vi) \(\Rightarrow\) (iv) according to Corollary 14.3.2. Suppose \(x\) is \(\Delta^1_1\)-dominated and \(\Delta^1_1\)-Kurtz random. Let \((U_n)_{n < \omega}\) be a \(\Delta^1_1\) ML test. Then there is a recursive function \(f : \omega \times 2^{<\omega} \rightarrow \omega\) such that for any pair \((n, \sigma)\), \(\sigma \in U_n\) if and only if \(f(n, \sigma) \in \omega\). Since \(x\) is \(\Delta^1_1\)-dominated, \(\omega_1^x = \omega_1^{CK}\). Define a \(\Pi^1_1(x)\) relation \(R \subseteq \omega \times \omega\) such that

\(R(n, m) \equiv (\exists \sigma)(m \equiv \sigma \wedge f(n, \sigma) \in O_m \wedge \sigma \prec x),\)

where \(O_m = \{i \in \omega \mid i < |m|\}\). By the \(\Pi^1_1\)-Uniformization Theorem (4.2.1), there is a partial function \(p\) uniformizing \(R\). Since \(x \in \cap_n U_n\), \(p\) is a total function and so \(\Delta^1_1(x)\). Since \(\omega_1^x = \omega_1^{CK}\), there is an \(m_0 \in \omega\) such that \(p(n) \in O_{m_0}\) for every \(n\). Define a \(\Delta^1_1\)-Martin-Löf test \((\hat{U}_n)_{n < \omega}\) so that \(\sigma \in \hat{U}_n\) if and only if \(f(n, \sigma) \in O_{m_0}\). Then \(x \in \cap_n \hat{U}_n\). Let

\(\hat{f}(n) = \min\{l \mid (\exists \sigma \in 2^{<\omega})(\sigma \in \hat{U}_n \wedge x \prec [\sigma])\}\)

be a \(\Delta^1_1(x)\)-function. Then there is a \(\Delta^1_1\)-function \(f\) dominating \(\hat{f}\). For \(n < \omega\), define

\(V_n = \{\sigma \mid \sigma \in 2^{\le f(n)} \wedge \sigma \in \hat{U}_n\}.\)

Then \(P = \cap_{n \in \omega} V_n\) is a \(\Delta^1_1\)-closed set and \(x \in P\). Hence \(x\) is not \(\Delta^1_1\)-Kurtz random, a contradiction.
