Suppose \(\pi : \mathscr{D}_h \to \mathscr{D}_h\) is an automorphism such that \(\pi(\mathbf{x}) \neq \mathbf{x}\). Then the coding scheme (see Remark 10.2.2) ensures that \(\mathbf{x} \le \pi f(1_{\bar{c}_e})\) and \(\mathbf{x} \le \pi f(1_{\bar{c}_e})\). Since \(\mathbf{x} = f(0_{\bar{c}_e}) = f(1_{\bar{c}_e}) \cap f(1_{\bar{c}_e})\), we have \(\pi(\mathbf{x}) = \pi(f(1_{\bar{c}_e}) \cap f(1_{\bar{c}_e})) = \pi(f(1_{\bar{c}_e})) \cap \pi(f(1_{\bar{c}_e}))\) so that \(\mathbf{x} \le \pi(\mathbf{x})\). A similar argument with \(\pi^{-1}\) shows that \(\pi(\mathbf{x}) \le \mathbf{x}\) so that \(\pi(\mathbf{x}) = \mathbf{x}\), a contradiction.

# 10.3 Biinterpretability

Biinterpretability in the Turing degrees says essentially that a relation on \(\mathscr{D}\) is definable if and only if it is definable in second order arithmetic.

While the biinterpretability of \((\mathscr{D}, \le)\) has yet to be established, we show in this section that it holds for the hyperdegrees.

# 10.3.1 Slaman–Woodin Coding

Slaman and Woodin [14] showed the definability (with parameters) of any countable relation on the Turing degrees. This was achieved using a technique of what is now called the Slaman–Woodin coding. The technique is applicable to an array of degree structures, including the hyperdegrees, and is key to proving the biinterpretability of \((\mathscr{D}_h, \le)\) with second order arithmetic.

Theorem 10.3.1 (Slaman and Woodin [143]). For each \(n < \omega\) there is a formula \(\varphi_n\) in the language of hyperdegrees such that for any countable \(n\)-ary relation \(R \subseteq \mathscr{D}_h\), there exist \(\mathbf{g}_1, \dots, \mathbf{g}_m\) and \((\mathbf{a}_1, \dots, \mathbf{a}_n) \in R \leftrightarrow (\mathscr{D}_h, \le) \models \varphi_n(\mathbf{a}_1, \dots, \mathbf{a}_n; \mathbf{g}_1, \dots, \mathbf{g}_m)\).

We establish this theorem by first showing that any countable antichain of hyperdegrees is definable in \((\mathscr{D}_h, \le)\). Here is the setup: Let \(A = \{\mathbf{a}_i \mid i < \omega\}\) be an antichain and let \(a_i\) be a real of hyperdegree \(\mathbf{a}_i\) such that \(a_i\) is recursive in each of its infinite subsets (note that every infinite set is Turing equivalent to the set of (codes of) its finite initial segments). Let \(a \in \mathbf{a}\) be an upper bound of \(A\).
