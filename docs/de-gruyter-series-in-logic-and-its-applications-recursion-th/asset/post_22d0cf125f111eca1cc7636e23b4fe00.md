
- 1. Every degree invariant function that is not increasing on a cone is a constant on a cone;
- 2. \(\le_M\) wellorders the degree invariant functions which are increasing on a cone. Furthermore, if the \(\le_M\)-rank of \(F\) is \(\alpha\), then \(F'\) has \(\le_M\)-rank \(\alpha + 1\), where \(F'(x) = (F(x))'\), the Turing jump of \(F(x)\).

Martin's conjecture is one of the deepest conjectures in recursion theory. Essentially it says that the only "natural unsolvable problem" is the halting problem. We will take up this topic in detail in Chapter 7.

## 7 Classification of jump operators

The Turing jump operator \(x \mapsto x'\) is degree invariant, i.e. if \(x \equiv_T y\) then \(x' \equiv_T y'\). The property of degree invariance is a fundamental property of the operator that motivated the introduction of Martin's conjecture (§ 6.6.5). In this chapter we discuss a stronger one called _uniform degree invariance_ and give a classification of functions that satisfy this property.

### 7.1 Uniformly degree invariant functions

**Definition 7.1.1.**
- If \(e = (e_0, e_1)\), we say that \(x \equiv_T y\) via \(e\) if \(x = \Phi_{e_0}^y\) and \(y = \Phi_{e_1}^x\);
- a function \(F : 2^\omega \to 2^\omega\) is _uniformly degree invariant_ on a cone \(C = \{x \mid x \ge_T z\}\) with base \(z\) if there is a function \(t : \omega \to \omega\) such that for any \(x, y \ge_T z\) with \(x \equiv_T y\) via \(e\), we have \(F(x) \equiv_T F(y)\) via \(t(e)\).

Note that in the definition above, the value of \(t(e)\) is independent of the reals \(x, y\).

In 1967, Sacks made a conjecture on the existence of a degree invariant function \(x \mapsto W^x\) for a general solution of Post's problem. This conjecture contradicts Martin's conjecture since the latter asserts that any such function must be at least as strong as the jump operator:

**Conjecture 7.1.2 (Sacks [119]).** _There is a_ \(\Sigma^1_1\)_-predicate_ \(W \subseteq 2^\omega \times \omega\) _such that, if_ \(W^x = \{n \mid W(x, n)\}\)_, then_ \(x <_T W^x < x'\) _and for any_ \(y \equiv_T x\)_,_ \(W^x \equiv_T W^y\)_._

In 1975, Lachlan [80] proved that this conjecture failed for uniformly degree invariant \(W\).

### 7.1.1 Nonincreasing uniformly degree invariant functions

Uniformly degree invariant functions are well-behaved under ZF + DC + AD. The following theorem says that a uniformly degree invariant function is either a constant or increasing on a cone.

**Theorem 7.1.3 (Slaman and Steel [142]).** _Assume_ ZF + DC + AD_. If F is uniformly degree invariant and not increasing on a cone, then F is a constant on a cone._

We decompose the proof of Theorem 7.1.3 into a series of lemmas. Let \(F\) be uniformly degree invariant via \(\leq a\) and not increasing on a cone.

**Lemma 7.1.4.** _Assume_ ZF+DC+AD_. If F is uniformly degree invariant and nonincreasing on a cone, then \(F(x) <_T x\) on a cone._

Proof. Suppose that \(F\) is uniformly degree invariant and not increasing on a cone. Then the set \(\{x \mid F(x) \not\ge_T x\}\) is cofinal in the Turing degrees. By Proposition 6.6.5, there is a pointed tree \(T\) such that \(F\) is uniformly degree invariant on \(T\) via a function \(\iota : \omega \to \omega\) and \(F(x) \not\ge_T x\) for any \(x \in [T]\).

Given \(x\), let \(x^\iota(i) = 2(x_i + 1)\) for \(i < \omega\). Let \(A \subseteq \omega^\omega\) be such that \(x = x_0 \oplus x_1 \in A\) if and only if either \(x_1^\iota \not\ge_T 2^\omega\) or

- \(x_0^\iota \in 2^\omega\);
- \(x_0(i) = \langle e, n \rangle\) for some \(e, n < \omega\);
- either \(x_0 \not\le_T x_1\) or \(F(x_0^\iota)(n) = 0 \leftrightarrow x_1(x_1(0)) \neq 0\) and
- \(x_0^\iota \in [T] \wedge \Phi_e^{x_0^\iota} = x_1\).

Consider a two person game \(\mathcal{G}_A\) played by I and II, choosing numbers alternately as usual. By AD, either I or II has a winning strategy for \(\mathcal{G}_A\). Suppose that I has a winning strategy \(\delta\). We show that \(x \le_T F(x)\) on the cone above \(T \oplus \delta\), which will give a contradiction.

Let \(z_0 \ge_T T \oplus \delta\) and \(x_1^m = m \frown z_0\) for \(m < \omega\). Let \(x_0^m\) be the real in \([T]\) played by I in response to II playing \(x_1^m\), i.e. \(\delta(x_1^m) = \langle e_0, n_0 \rangle \frown x_0^m\), where \(\langle e_0, n_0 \rangle\) codes the pair of numbers \(e_0, n_0\) and \(\delta(0) = \langle e_0, n_0 \rangle\) is the first move dictated by \(\delta\). Since I wins, \(x^m = x_0^m \oplus x_1^m \in A\) for every \(m\). As \(x_1^m \ge_T \delta\), we have \(x_1^m \ge_T x_0^m\). Then for every \(m\),

\(F(x_0^m)^+(n_0) = 0 \leftrightarrow x_1^m(m) = 1.\)

Since \(\Phi_{e_0}^{(x_0^m)^+} = x_1^m\) and \(x_1^m = m \frown z_0\), there is an \(i\) such that \(\Phi_i^{(x_0^m)^+} = (x_0^{m+1})^+\) for every \(m\). Similarly, there is a \(j\) such that \(\Phi_j^{(x_0^m)^+} = (x_0^m)^+\) for every \(m\). Hence \((x_0^m)^+ \equiv_T (x_0^{m+1})^+\) via \(\langle i, j \rangle\), and so \(F((x_0^m)^+) \equiv_T F((x_0^{m+1})^+)\) via \(t(i, j) = \langle i', j' \rangle\). Since \(F\) is degree invariant and \(z_0 \equiv_T x_0^m \equiv_T (x_0^m)^+\), we have \(\Phi_k^{(x_0^m)} = F((x_0^m)^+)\) for some \(k\). Let \(l_m = F((x_0^m)^+)(n_0)\). Note that \(F((x_0^m)^+) = \Phi_k^{F(z_0)}\) and \(F((x_0^{m+1})^+) = \Phi_k^{F((x_0^m)^+)}\). So \(\{l_m\}_{m \in \omega}\) is \(F(z_0)\)-recursive. Note that \(z_0(m) = x_1^{m+1}(m+1) = 1 - l_{m+1}\). Thus \(z_0 \le_T F(z_0)\), a contradiction.

Hence II has a winning strategy \(\tilde{\tau}\). We show that \(F(x) <_T x\) on the cone above \(T \oplus \tilde{\tau}\). Fix a real \(x_0 \in [T]\) so that \(x_0 \ge_T T \oplus \tilde{\tau}\). By the Recursion Theorem relativized to \(x_0\), there is an \(e_0\) such that \(\tilde{\tau}((e_0, n)^\frown x_0)(m) = \Phi_{e_0}^{e_0}(\langle n, m \rangle)\) for every \(n, m\). For each \(n\), let \(x_1^n = \tilde{\tau}((e_0, n)^\frown x_0)\). Since II wins, it must be the case that \(x_0 \le_T x_1^n\) and \(F(x_0^n)(n) = x_1^n(x_1^n(0))\). Then

\(F(x_0^n)(n) = x_1^n(x_1^n(0)) = \Phi_{e_0}^{e_0}(\langle n, x_0^n(e_0(n, 0)) \rangle)\)

and so \(F(x_0) \le_T x_0\). Since \(F\) is degree invariant, we conclude that \(F(x) <_T x\) on a cone.

By Lemma 7.1.4, fix \(x_0\) such that \(F(x) <_T x\) on the cone \(\{x \mid x \ge_T x_0\}\). Then there is an \(e_0\) such that the set \(C = \{x \mid \Phi_{e_0}^x = F(x) \wedge x \ge_T x_0\}\) is cofinal. By Proposition 6.6.5, there is a perfect tree \(T_0\) and a number \(i\) such that \([T_0] \subseteq C\) and \(T_0 = \Phi_i^x\) for every \(x \in [T_0]\).
