# 1 An introduction to higher recursion theory

# 1.1 Projective predicates

# 1.1.1 Recursive and arithmetical predicates

A recursive predicate R on \(\omega\) is a total recursive function \(\Phi : \omega \to 2\) such that \(R(n) \Leftrightarrow \Phi(n) = 1\). With a standard coding of \(\omega^{<\omega}\) in \(\omega\), one may define recursive predicates on \(\omega^{<\omega}\). Similarly one may code \(\omega^n\) in \(\omega\) to obtain recursive n-ary predicates on \(\omega\), as well as recursive predicates on \((\omega^{<\omega})^m \times \omega^k\). The class of arithmetical predicates on \(\omega^\omega \times \omega\) is now defined as follows:

**Definition 1.1.1.** A predicate \(R(x, n)\) on \(\omega^\omega \times \omega\) is *partial recursive* if there is a partial recursive function \(\Phi(\sigma, n)\) on \(\omega^{<\omega} \times \omega\) such that

+   (i) \((\forall \sigma)(\forall n)(\Phi(\sigma, n) \downarrow \Rightarrow \sigma \prec \tau \rightarrow (\Phi(\tau, n) \downarrow \land \Phi(\sigma, n) = \Phi(\tau, n))]\).

+   (ii) For any \(x \in \omega^\omega\) and \(n \in \omega\), \(R(x, n)\) if and only if \((\exists m)(\Phi(x \mid m, n) \downarrow = 0)\).

A predicate \(R(x, n)\) on \(\omega^\omega \times \omega\) is *recursive* if the partial recursive function \(\Phi\) above also satisfies the following property:

+   (iii) \((\forall y)(\forall n)(\exists m)(\Phi(x \mid m, n) \downarrow]\).

**Remark 1.1.2.** We may similarly define recursive predicates on \((\omega^\omega)^k \times (\omega^{<\omega})^m \times \omega^k\). In general, there is no effective enumeration of recursive predicates on \(\omega^\omega \times \omega\).

The hierarchy \(\Sigma^0_n\) of arithmetical predicates is defined by induction on \(n < \omega\).

**Definition 1.1.3.**

+   (i) \(\Sigma^0_1 = P\) (P is a partial recursive predicate).

+   (ii) \(P\) is \(\Pi^0_1\) if \(\{(x, m) \mid \neg P(x, m)\}\) is \(\Sigma^0_n\).

+   (iii) P is \(\Sigma^0_{n+1}\), if there is a \(\Pi^0_n\) predicate \(R(x, (m, k))\) such that

\(P(x, m) \Leftrightarrow (\exists k)R(x, (m, k)) \).

+   (iv) P is \(\Delta^0_2\) if it is \(\Sigma^0_n\) and \(\Pi^0_n\).

We say that a predicate P is *arithmetical* if \(P \in \Sigma^0_n\) for some n.

It follows from results in classical recursion theory that a predicate \(P(x, m)\) is \(\Sigma^0_1\) if and only if there is a recursive predicate \(R(x, m, n)\) such that \(P(x, m) \Leftrightarrow (\exists n)R(x, m, n)\).

Fix an effective enumeration of partial recursive functions \(\{\Phi_e(\sigma, n)\}_{e \in \omega}\) which satisfies property (i) in Definition 1.1.1. For each real x, \(\Phi_e(x \mid m, n)\) denotes \(\Phi_e(x \mid m, n)\) for the least m such that \(\Phi_e(x \mid m, n) \downarrow\) at stage m. If no such m exists, then \(\Phi_e(x, n)\) is undefined. We say that \(\Phi_e(x, n)\) is an x-partial recursive function. Hence there is a uniform enumeration of partial recursive functions \(\{\Phi_e(x, n)\}_{e \in \omega}\) with oracle x. In other words, the predicate \(P(e, x, n, m) \Leftrightarrow \Phi_e(x, n) \downarrow = m\) is \(\Sigma^0_1\).
