# 14 The theory of higher randomness

Higher randomness theory studies algorithmic complexity problems of randomness using techniques and ideas from hyperarithmetic theory and set theory. Since second order arithmetic provides a broader, though sometimes coarser, view of the reals, the picture one gets of randomness is quite different from that for first order theory.

# 14.1 Higher Kurtz randomness

# 14.1.1 \(\Delta^1_1\) and \(\Pi^1_1\)-Kurtz randomness

**Definition 14.11.** Let \(x \in 2^\omega\). Given a class \(\Gamma\) of sets of reals, \(x\) is \(\Gamma\)-Kurtz random if it is not a member of any closed nullset in \(\Gamma\).

We focus on \(\Delta^1_1\), \(\Sigma^1_1\) and \(\Pi^1_1\)-Kurtz randomness. Recall (§ 2.7.1) that BC denotes the set of Borel codes and \(\{A_z \mid z \in \text{BC}\}\) is the set of reals generated by the codes.

# Proposition 14.12.

+   (i) \(x\) is \(\Delta^1_1\)-Kurtz random if and only if \(x\) does not belong to any \(\Pi^1_1(\text{HYP})\)-nullset.

+   (ii) The set of \(\Delta^1_1\)-Kurtz random reals is \(\Sigma^1_1\) but not \(\Delta^1_1\).

Proof. Note that (i) follows immediately from Theorem 2.7.4. We give a self-contained proof here.

By Theorem 2.7.2, every \(\Pi^1_1(\text{HYP})\)-set is a \(\Delta^1_1\)-set. Hence no \(\Delta^1_1\)-Kurtz random real belongs to a \(\Pi^1_1(\text{HYP})\)-nullset. Conversely, let \(P\) be a \(\Delta^1_1\)-nullset. Then \(U = \{\sigma \mid (\forall z)(\forall x \in P \to z \neq \sigma) \text{ is } \Pi^1_1\}\). Since \(P\) is closed and the set of hyperarithmetic reals is dense, we have

\(\sigma \in U \iff (\forall z \in \text{HYP})(z > \sigma \to z \notin P)\).

By Corollary 2.2.12, \(U\) is also \(\Sigma^1_1\) and hence \(\Delta^1_1\). Thus \(P \in \Pi^1_1(\text{HYP})\). It follows that \(x\) does not belong to a \(\Pi^1_1(\text{HYP})\)-nullset, and hence \(x\) is \(\Delta^1_1\)-Kurtz random.

To prove (ii), observe that the set

\(C = \{(\langle n, e \rangle, y) \mid n \in \theta \land \Delta^{B_n}_e \in \Pi_1 \cap \text{HYP} \land y \in A_{\varrho^{B_n}_e}\}\)

is \(\Pi^1_1\), where \(A_z\) is as defined in § 2.7.1. By Proposition 13.1.6, the set

\(D = \{(\langle n, e \rangle, y) \mid \mu(y \mid ((\langle n, e \rangle, y) \in C)) = 0\}\)

is \(\Pi^1_1\). Hence the set

\(E = \{y \mid (\exists m)((m, y) \in D)\}\)

is a \(\Pi^1_1\)-nullset. Moreover by (i),

\((\forall x)(x \in E \mapsto x \text{ is not } \Delta^1_1\text{-Kurtz random}).\)
