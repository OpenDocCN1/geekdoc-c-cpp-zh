One may view \(\sum_{\sigma \in 2^{<\omega}} \lambda \mu[\text{ext}(\sigma) \oplus \emptyset^{(\beta)}[f(|\sigma|)]]_{r(\sigma)} 2^{-|\sigma|}\) as a “measure” for \(\tau\). For each \(n\), let

\(l_n = l(y \upharpoonright n)\), and \(r_n = r(y \upharpoonright n)\).

Then \(l_n \le l_{n+1} \le r_{n+1} \le r_n\). Since \(y\) is not hyperarithmetic, it is not difficult to see that \(\lim_{n \to \infty} r_n = 0\). Hence there is a unique

\(z = \bigcap_{n<\omega} (l_n, r_n)\).

Clearly \(z \le_T y \oplus \emptyset^{(\beta)}\). We leave it to the reader to verify that \(y \le_T z \oplus \emptyset^{(\beta)}\). Thus \(z \equiv_T y\).

Suppose that \(z\) is not \(\Delta^1_1\)-random. Then there is a recursive ordinal \(\gamma < \beta\) and a \(\emptyset^{(\gamma)}\)-ML-test \(\{V_n\}_{n \in \omega}\) such that \(z \in \bigcap_{n<\omega} V_n\). Let

\(\tilde{V}_n = \{u \mid (\exists v)(v \text{ is the } k\text{-th string in } V_n \wedge\)
\((\exists p \in \mathbb{Q})(\exists q \in \mathbb{Q})(p < l(u) < r(u) < q \forall [\sigma \sqsubseteq (p, q) \land q - p < 2^{-|v|} - 2^{-n-k-2}]).\)

Intuitively, \(\{\tilde{V}_n\}_{n<\omega}\) is a \(\Delta^1_1\)-Martin-Löf test relative to the measure \(\lambda\), where \(\lambda(\sigma) = \sum_{\tau \in C(\sigma)} 2^{-|\tau|}\) for any \(\sigma \in 2^{<\omega}\).

Since \(z \in V_n\), we have \(y \in \tilde{V}_n\) for every \(n\). Note that \(\{\tilde{V}_n\}_{n<\omega}\) is \(\emptyset^{(\gamma+1+\beta)}\)-r.e. Let

\(U_n = \{\sigma \mid (\exists \tau \in \tilde{V}_n)(|\sigma| = f(|\tau|) \land \tau \oplus \emptyset^{(\gamma)}[f(|\tau|)][f(|\tau|)] \ge \tau)\} = \bigcup_{u \in \tilde{V}_n} C(u)\).

Then \(\{U_n\}_{n<\omega}\) is \(\emptyset^{(\gamma+1+\beta)}\)-r.e and \(x \in \bigcap_{n<\omega} U_n\). Note that for every \(n\),

\(\mu(U_n) \le \mu(V_n) + \sum_{k<\omega} 2^{-n-k-2+1} < 2^{-n} + 2^{-n} = 2^{-n+1}\).

Then \(\{U_{n+1}\}_{n<\omega}\) is a \(\emptyset^{(\gamma+1+\beta)}\)-ML-test. Hence \(x\) is not a \(\Delta^1_1\)-random, a contradiction.
