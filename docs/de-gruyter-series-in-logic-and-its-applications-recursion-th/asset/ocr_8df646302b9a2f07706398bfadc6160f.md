Thus let \(q^m, r^m\) be chosen as in the Claim. Note that \(m \mapsto (q^m, r^m)\) is hyperarithmetic in \(x\).

We start with (the least) \(i < |Q|\) such that \(q_1^m\) and \(r_1^m\) disagree at \(i\) (if any). Define a condition \(s(0) = (s_1(0), s_2(0), s_5(0))\) by first changing the value of \(q_i^m\) at the point \(i\) to agree with that of \(r_1^i\), \(s_2(0) \mid [q_1^m]^2 = q_2^m\) and \(s_5(0) = q_5^m\), and then extending it to decide the value of \(\varphi_{x \oplus g_i}(m)\). Then extend the domains of \(q_1^m, q_2^m\) and \(r_1^m, r_2^m\) to that of \(s_1(0)\) so that the new points in these domains agree with \(s_1(0)\) in their values. Call the resulting conditions \(q^m(0)\) and \(r^m(0)\). Either \(s_1(0)\) and \(q_1^m(0)\) disagree at exactly one point, \(s_2(0) = q_2^m(0)\), and \(s(0)\) and \(q^m(0)\) force incompatible values for \(\varphi_{x \oplus g_i}(m)\), or \(s(0)\) and \(r^m(0)\) force incompatible values and have fewer points of disagreement between them than that between \(q^m\) and \(r^m\). For \(q_i^m\) and \(r_i^m\), we carry out the same construction. By induction, one defines successively \(s(0), s(1), \dots\) and concludes that there is a \(j\) so that \(s(j)\) and \(s(j+1)\) with exactly one point of disagreement in the first two components forcing incompatible values for \(\varphi_{x \oplus g_i}(m)\).

Thus we may assume that \(q^m\) and \(r^m\) differ exactly at one point \((k, l)\) so that \(q_1^m((k, l)) \neq r_1^m((k, l))\). If either \(k > p_3\) or \(l \notin a_k\), then let \(s = (s_1^m, r_2^m, q_3 + r_3)\). Then \(s \le p\). This implies that we can extend \(p\) to a generic \(g\) having the same values for \(g_1\) and \(g_2\) as those for \(q^m\) and \(r^m\) respectively at their common points. This, however, contradicts the assumption on \(p\).

It follows that there exist infinitely many pairs of conditions extending \(p\) which differ at exactly one \((k, l)\) with \(k \le p_3\) and \(l \in a_k\), forcing different values as described above. In particular there is a \(k \le p_3\) for infinitely many such \(l\)'s to satisfy this requirement. Now as noted earlier the forcing relation for sentences of fixed rank considered here is hyperarithmetic in the parameter \(x\), and so one can hyperarithmetically in \(x\) enumerate an infinite set of \(l\)'s contained in \(a_k\). Since \(a_k\) is recursive in each of its infinite subsets, this set computes \(a_k\).

Thus \(x \ge_h a_k\), proving the lemma.

One may now convert an arbitrary countable relation on the degrees into an antichain so that the original relation is definable from the antichain using parameters.

# Proof of Theorem 10.31.

Let \(R\) be an \(n\)-ary relation on the hyperdegrees. Let \(\{\mathbf{a}_j \mid j < \omega\}\) be a list of all the hyperdegrees \(\le \mathbf{a}\), with \(a_j \in \mathbf{a}_j\) and \(a \in \mathbf{a}\). Let \(\{g_{i,j} \mid 1 \le i \le n \text{ and } j < \omega\}\) be reals which are mutually Cohen generic over \(a\).
