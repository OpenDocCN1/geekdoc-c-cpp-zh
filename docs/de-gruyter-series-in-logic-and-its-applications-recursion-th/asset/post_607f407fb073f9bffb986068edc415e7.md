
$f(A) \Leftrightarrow (\exists x \in \Delta_1^1(y))(y \in A \wedge (x, y) \in G') \Leftrightarrow (\exists x)(x \in A \wedge (x, y) \in G')$. By relativizing Corollary 2.2.12 to $y$, one concludes that $f(A)$ is $\Delta_1^1$.

Thus we obtain a characterization of $\Delta_1^1$-sets of reals:

### Corollary 2.2.14. A set of reals $A$ is $\Delta_1^1$ if and only if there is a $\Pi_1^0$-set $B$ and a recursive function $f : \omega^\omega \to \omega^\omega$ such that $f(B) = A$ and $f$ is one-one on $B$.

Proof. If there is a $\Pi_1^0$-set $B$ and a one-one recursive function $f : \omega^\omega \to \omega^\omega$ such that $f(B) = A$, then, by Corollary 2.2.13, one easily verifies that $A$ is $\Delta_1^1$. If $A = \omega^\omega$ is $\Delta_1^1$, then there is a recursive function $g$ such that $x \in A \Leftrightarrow g(x) \in \text{WO}_1$, and, by the discussion in §1.5.2, there is a recursive well-ordering $z$ such that $x \in A \Leftrightarrow |g(x)| \le |z|$. Define $P(x, y)$ if and only if $y$ is an isomorphism from $\le_{g(x)}$ to an initial segment of $\le_z$. Since $z$ is recursive, $P(x, y)$ is $\Pi_1^0$ and $x \in A \Leftrightarrow (\exists y)P(x, y)$. Hence there is a recursive predicate $R$ such that $P(x, y) \Leftrightarrow (\forall n)(\exists m)R(x, y, n, m)$. Uniformize $P$ by defining a $\Pi_1^0$-set $B = \{x_0 \oplus x_1 \oplus x_2 \mid (\forall n)(R(x_1, x_2, n, x_0(n)) \wedge (\forall m < x_0(n))(\neg R(x_1, x_2, n, m)))\}$. Define a recursive function $f$ such that $f(x) = x_1$ if $x = x_0 \oplus x_1 \oplus x_2$. Obviously $f$ is one-one on $B$.

In certain situations, Corollary 2.2.14 enables one to reduce a construction over a $\Delta_1^1$-set to one that is over a $\Pi_1^0$-set. Additionally, Theorem 2.2.9 provides a parametrization of $\Delta_1^1$-sets of reals.

### Proposition 2.2.15. There is a $\Pi_1^1$-set $A \subseteq \omega \times \omega^\omega$ with the property that for any set $B$ of reals, $B$ is $\Delta_1^1$ if and only if there is an $n$ such that $B = A_n = \{x \mid (n, x) \in A\}$.

Proof. Define $A = \{(\langle e, m \rangle, x) \mid m \in \omega \wedge \Phi_e^{B_n(0)} \downarrow \}$. By Theorem 2.2.9, $A$ is as required.

## 2.3 Spector's Uniqueness Theorem

Since the $H$-sets are generated by a $\Pi_2^0$-singleton process (cf. Theorem 2.1.4), they provide a way of carrying out transfinite induction over hyperarithmetic sets. We make this observation precise by noting Corollary 2.3.2, the Spector Uniqueness Theorem, which implies that induction over H-sets is degree-theoretic invariant.

### Theorem 2.3.1 (Spector [153]). There is a recursive function h such that
$n, m \in O \land |n| \le |m| \implies H_n = \Phi_{h(n,m)}^{H_m}$.

Proof. We prove this by induction on the well-ordering $<_O^2$:
$(n_1, m_1) < (n_2, m_2) \Rightarrow |n_1| < |n_2| \lor (|n_1| = |n_2| \land |m_1| < |m_2|)$.

There are four cases to consider.

- (1) $n = 1$. Set $h(1, m) = c_1$ so that $\Phi_{c_1}^x = H_1 = \emptyset$ for all x.
- (2) $n = 2^{|x|} \land n = 2^i$. Fix a recursive function g so that for any e, x and y, $x = \Phi_e^y$ implies $x' = \Phi^{g(e)}$. Set $h(n, m) = g(h(i, j))$.
- (3) $n = 3 \cdot 5^k$. Set $h(n, m) = c_3$ so that $\Phi_{c_3}^{H_m}$ is the characteristic function of $\{(i, j) \mid i \in H_m^{(h(\phi(i),0),m)}\}$.
- (4) $n = 2^a \land m = 3 \cdot 5^i$. This is the most difficult case. By Lemma 2.2.4, we may $H_m$-recursively search for an i such that $n \in O_{\phi(i,0)}$ and $O_{\phi(i,0)} = \Phi_{g(h(\phi(i),0))}^{H_m}$. By Lemma 2.1.2, there is a recursive function f so that $H_{2^{\phi(i,0)}} = \Phi_{f(2^{\phi(i,0)},m)}^{H_m}$. By induction, $H_n = \Phi_{h(n, 2^{\phi(i,0)})}^{H_m}$. Then there exists a $c_4$ with $H_n = \Phi_{h(n, 2^{\phi(i,0)})}^{H_m} = \Phi_{c_4}^{H_m}$. Set $h(n, m) = c_4$.

Note that these cases can be identified recursively. Hence h is a recursive function.

Thus we have the following uniqueness theorem.

### Corollary 2.3.2 (Spector). If $n, m \in O$, then $|n| = |m|$ implies $H_n \equiv_T H_m$.

In particular, for any recursive ordinal $\beta$, the “$\beta$-th Turing jump”, denoted $\emptyset^{(\beta)}$, may be taken to be $H_n$ for any $n \in O$ with $|n| = \beta$. There is a parallel result for $\tilde{H}^r$-sets with exactly the same proof as that of Theorem 2.3.1. We leave it to the reader as an exercise.

### Theorem 2.3.3. There is a recursive function h such that for any real x,
$n \in O^x \land m \in O \land |n| \le |m| \implies H_n^x = \Phi_{h(n,m)}^{H_m}$.

## 2.4 Hyperarithmetic reducibility

### 2.4.1 \( A_1^1 \)-reducibility

Definition 2.4.1. \( x \le_{A_1^1} y \) if \( x \) is \( \Delta_1^1(y) \). In particular, \( x \le_h y \) if \( x \le_{A_1^1} y \).

Proposition 2.4.2 (Shoenfield). If \( x \le_{A_1^1} y \) and \( y \le_{A_1^1} z \), then \( x \le_{A_1^1} z \).

Proof. If \( x \le_{A_1^1} y \), then there is a \( A_1^1 \)-predicate \( R \) such that \( n \in x \Leftrightarrow R(n, y) \).
If \( y \le_{A_1^1} z \), then there is a \( A_1^1 \)-predicate \( S \) such that \( n \in y \Leftrightarrow S(n, z) \).
Then
\( n \in x \Leftrightarrow (\exists r)(R(n, r) \land (\forall m)(m \in r \leftrightarrow S(m, z))) \)
\( \leftrightarrow (\forall r)(\forall m)((m \in r \leftrightarrow S(m, z)) \rightarrow R(n, r)) \).
Thus \( x \le_{A_1^1} z \).

Reals \( x, y \) are said to have the same \( A_n^1 \)-degree if \( x \le_{A_1^1} y \) and \( y \le_{A_1^1} x \). If \( n = 1 \), then we also say that they have the same hyperdegree. By Theorem 2.2.6, \( x \le_h y \) if and only if there is an \( n \in O^y \) and an \( e \) such that \( x = \Phi_e^{y_n} \). The hyperjump of \( x \) is defined to be the set \( O^x \).

The \( h \)-reduction relation \( x \le_h y \) suggests another reason for introducing the \( \dot{H}^x \)-sets. One of the problems with \( h \)-reducibility is that, unlike the case of Turing reducibility where one examines a fixed recursive list of possible reduction algorithms (independently of the sets \( x \) and \( y \) being considered), there is no uniform procedure to search for an algorithm that \( h \)-reduces \( x \) to \( y \). The reduction depends on what can be Turing computed by the \( H^x \)-sets and this involves ordinal notations for \( y \). Different reals \( y \) have different ordinal notations. In certain cases the notations may be markedly different since \( \{ \omega_1^y \mid y \in 2^\omega \} \) is unbounded in \( \omega_1 \). The use of \( \dot{H}^x \)-sets circumvents this difficulty. If \( \omega_1^y = \omega_1^{y, \text{CK}} \), then the sets Turing computable by the \( \dot{H}^x \)-sets are precisely the \( A_1^1(y) \)-sets. Hence while it is not true in general, for reals \( y \) with \( \omega_1^y = \omega_1^{y, \text{CK}} \), one does have a uniform reduction.

### 2.4.2 The partial order of hyperdegrees

The Turing jump operator is order preserving on the Turing degrees. This remains true for the hyperjump operator which preserves order on the hyperdegrees.

Proposition 2.4.3. \( x \le_h y \iff O^x \le_m O^y \).

Proof. First of all \( O^x \) is \( \Pi_1^1(x) \). If \( x \le_h y \), then as in the proof of Proposition 2.4.2 \( O^x \) is \( \Pi_1^1(y) \). By Theorem 1.5.1, \( O^x \le_m O^y \).
If \( O^x \le_m O^y \), then \( x \le_m O^y \) and \( \omega \setminus x \le_m O^y \). Since \( \omega \setminus x \) is \( \Pi_1^1(x) \), \( \omega \setminus x \le_m O^x \). Then \( \omega \setminus x \) is \( \Pi_1^1(y) \) and this implies that \( x \le_h y \).
