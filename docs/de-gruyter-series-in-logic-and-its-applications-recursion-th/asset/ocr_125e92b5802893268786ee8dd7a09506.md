We now define a notion of Cohen forcing over $\Sigma^0_b$-predicates for $b <_0 a$. If $P(x, n)$ is a $\Sigma^0_1$-predicate, then there is a partial recursive function $\Phi^b(n)$ such that $P(x, n) \Leftrightarrow \Phi^b(n) \downarrow$. Define $\sigma \Vdash P(x, n)$ if and only if $\Phi^b(n) \downarrow$.

If $b = 2^c \in O, b <_0 a$, and $P(x, n)$ is $\Sigma^0_b$, then $P(x, n) \Leftrightarrow (\exists m)\neg Q(x, \langle n, m \rangle)$. Define $\sigma \Vdash P(x, n) \Leftrightarrow (\exists m)(\forall \tau \sqsupset \sigma Q(x, \langle n, m \rangle))$.

If $b = 3 \cdot 5^e \in O, b <_0 a$, and $P(x, n)$ is a $\Sigma^0_b$ predicate, then $P(x, n) \Leftrightarrow P_{\Phi^b(\Phi(e)(n))}(x, n)$ for some $i$. Define $\sigma \Vdash P(x, n) \Leftrightarrow \sigma \Vdash P_{\Phi^b(\Phi(e)(n))}(x, n)$.

Given $b <_0 a$, if $P(x, n)$ is a $\Sigma^0_b$ predicate, then $\sigma \Vdash \neg P(x, n) \Leftrightarrow (\forall \tau \sqsupset \sigma)(\tau \nVdash P(x, n))$.

The verification of the following lemma is also left to the reader.

# Lemma 7.3.4. There is a partial recursive function $h : a^2 \times 2 \to \omega$ such that for any $b <_0 a$,

+   (i) if $b = 1$ or $2^c$, then $(\forall n)(\forall m)((\sigma \Vdash P_{\Phi(b,n)}(x, m) \mapsto \Phi^h_{\langle b,n \rangle}(\sigma, m) = 1) \wedge (\sigma \nVdash P_{\Phi(b,n)}(x, m) \mapsto \Phi^h_{\langle b,n \rangle}(\sigma, m) = 0))$;

+   (ii) if $b = 3 \cdot 5^e$, then $(\forall n)(\forall m)((\sigma \Vdash P_{\Phi(b,n)}(x, m) \mapsto \Phi^h_{\langle b,n \rangle}(\sigma, m) = 1) \wedge (\sigma \nVdash P_{\Phi(b,n)}(x, m) \mapsto \Phi^h_{\langle b,n \rangle}(\sigma, m) = 0))$.

A real $g$ is $a$-generic if for any $b <_0 a$ and $\Sigma^0_b$-predicate $P(x, n)$ there is an $m$ such that either $g \mid m \Vdash P(x, n)$ or $g \mid m \Vdash \neg P(x, n)$. This yields the following truth lemma:

# Lemma 7.3.5. Suppose that $g$ is $a$-generic. For any $m$, $n$ and $b <_0 a$, $P_{\Phi(b,n)}(g, m)$ if and only if there is a $k$ such that $g \mid k \Vdash P_{\Phi(b,n)}(x, m)$, and $\neg P_{\Phi(b,n)}(g, m)$ if and only if there is a $k$ such that $g \mid k \Vdash \neg P_{\Phi(b,n)}(x, m)$.

# Lemma 7.3.6. If $g$ is $a$-generic, then there is a partial recursive function $r$ such that for any $b <_0 a$

+   - if $b = 1$ or $2^c$, then $H^g_b = \Phi^{g_{H(b)}}_{r(b)}$ ;

+   - if $b = 3 \cdot 5^e$, then $H^g_b = \Phi^{g_{H(b)}}_{r(b)}$ .

Proof. We give the proof for the case when the notation of $b$ is a successor, and leave the limit case to the reader.

If $b = 1$, then by Lemma 7.3.3, $n \in H^g_b$ if and only if $P_{\Phi(1,n)}(g, n)$. By Lemma 7.3.5, there exists a $k$ such that either $g \mid k \Vdash P_{\Phi(1,n)}(g, n)$ or $g \mid k \Vdash \neg P_{\Phi(1,n)}(g, n)$. By Lemma 7.3.4, this is decidable by $\Phi^{H_g}_{\langle 1,n \rangle}(g \mid k, n)$. Hence $H^g_1 = \Phi^{g_{H(1)}}_{r(1)}$ for some $i$. Let $r(1) = i$.

If $b = 2^c$, then by Lemma 7.3.3, $n \in H^g_b$ if and only if $P_{\Phi(b,n)}(g, n)$. By Lemma 7.3.5, there exists a $k$ such that either $g \mid k \Vdash P_{\Phi(b,n)}(g, n)$ or $g \mid k \Vdash \neg P_{\Phi(b,n)}(g, n)$. Since $P_{\Phi(b,n)}(g, n) \Leftrightarrow (\exists m)P_{\Phi(c,n)}(g, n, m)$, we have

$(\exists m)(g \mid k \Vdash P_{\Phi(c,n)}(g, n, m)) \vee (\forall \tau \sqsupset g \mid k)(\forall m)(\tau \nVdash P_{\Phi(c,n)}(g, n, m))$ .

By Lemma 7.3.4, this is decidable by either $g \mid H^g_c = g \mid H_{2^c} (= c 2^d$ for some $d)$ or $g \mid H^g_c \le_T g \mid H_{2^c} (= c \cdot 3 \cdot 5^e$ for some $e)$. Hence $H^g_b = \Phi^{g_{H(b)}}_{r(b)}$ for some $i$, a number which may be effectively computed from $b$. Let $r(b) = i$.
