
### Theorem 8.2.4.
$(\omega_1)^L = \omega_1$ if and only if the $\Pi^1_1$-inductive principle $\mathfrak{I}$ holds.

Proof. The "if" direction is immediate: Choose $P(x, y)$ to express $x \le_T y$. Then $P$ is cofinally progressive. Let $A$ be a $\Pi^1_1$-set satisfying $\mathfrak{I}$ for $P$, of $<_1$-height $\omega_1$. Then $(\omega_1)^L = \omega_1$.

For the other direction, suppose $P$ is $\Pi^1_1$ and cofinally progressive. Then for any pair of reals $x, z \in L$, the set $U_{x,z} = \{y \mid y \ge_T z \ge P(x, y)\}$ is a nonempty $\Pi^1_1(x, z)$-set. By Theorem 4.12, there is a $y \in U_{x,z} \cap L$. By Theorem 4.1.2 again, $(L, \in) \models P$ is cofinally progressive.

By Theorem 8.2.3, there is a $\Pi^1_1$-set $A$ such that $(A)^L$ witnesses the correctness of the inductive principle $\mathfrak{I}$ in $L$.

Since $(\omega_1)^L = \omega_1$, $\mathfrak{I}$ is true in $V$. Since the statement "$x \in L^A_{\omega_1}$" is $\Pi^1_1$ and $(L, \in) \models (\forall x)(x \in A \to x \in L^A_{\omega_1})$,

by the Shoenfield Absoluteness Lemma (Corollary 4.2.9), $(V, \in) \models (\forall x)(x \in A \to x \in L^A_{\omega_1})$. Hence $A \subset L$.

Let $y \in A$. Since $A \subseteq L$, $y \in L$. Then there exists an $x \in L^A_{\omega_1}$ such that $(L, \in) \models x$ codes the set $\{z \mid z \in A \wedge z <_L y\} \wedge P(x, y)$.

Since $A \subset L$, $x$ codes the set $\{z \mid z \in A \wedge z <_L y\}$. Since the relation $P$ is $\Pi^1_1$ and $x, y \in L$, by the Shoenfield Absoluteness Lemma (Corollary 4.2.9) again, $P(x, y)$ holds. Hence (ii) follows.

One may relativize the $\Pi^1_1$-inductive principle $\mathfrak{I}$ to admit real parameters and obtain its boldface version $\underline{\mathfrak{I}}$. Then Theorem 8.2.4 may be generalized to state: Boldface $\Pi^1_1$-inductive principle $\underline{\mathfrak{I}}$ fails if and only if there is no real $x$ such that $(\omega_1)^{L[x]} = \omega_1$. This leads to the following conclusion.

### Corollary 8.2.5.
The statement "ZFC + $\Pi^1_1$-inductive principle $\mathfrak{I}$ is false" is consistent if and only if "ZFC + There exists an inaccessible cardinal" is consistent.

Proof. If $\mathfrak{I}$ fails, then $(\omega_1)^{L[x]} < \omega_1$ for all $x$, so that the latter is inaccessible in $L$. Conversely, suppose ZFC + "There is an inaccessible cardinal" is consistent. Then by Proposition 6.2.9 (the Levy collapsing map), ZFC + "$\omega_1$ is inaccessible in $L^r$" is consistent.

Now in a model $M$ with such a property, $\omega_1 > (\omega_1)^{L[x]}$ for all $x$. Hence $\mathfrak{I}$ fails in $M$.

## 8.3 \(\Pi^1_1\)-maximal chains and antichains of Turing degrees

We now apply the \(\Pi^1_1\)-inductive principle \(\mathfrak{I}\) to construct some special \(\Pi^1_1\)-sets of Turing degrees.

### 8.3.1 Chains in the Turing degrees

Given a partial ordering \((P, \le_P)\), \(p \in P\) is a minimal cover of \(A \subseteq P\) if \(q <_P p\) for all \(q \in A\) and if there is no \(r \in P\) such that \(r <_P p\) having the same property. A set \(A \subseteq P\) is a *chain* if for any \(x, y \in A\), either \(x \le_P y\) or \(y \le_P x\). A chain \(A\) is *maximal* if there is no chain \(B \supset A\). Define \(P(x, y)\) if and only if

\(y\) is a minimal cover of \(\{\chi(n) \mid n \in \omega\}\) under \(\le_T\).

Lemma 8.3.1. $P(x, y)$ is a cofinally progressive relation.

Proof. We prove that for any countable set \(A = \{x_i\}_{i < \omega}\) and any real \(x\), there is a minimal cover \(z\) of \(A\) such that \(z'' \ge_T x\).

Fix an effective enumeration of partial recursive functions \(\{\Phi_e\}_{e < \omega}\).

Given a perfect tree \(T\), define the \(n\)-th level \(Lev_n(T)\) of \(T\) to be

\(\{\sigma \notin Lev_{n-1}(T) \mid (\exists \tau)(\tau \in T \land \sigma \preceq \tau \land \tau \text{ is an } n\text{-th splitting node on } T)\}.\)

Let \(\{p_n\}_{n < \omega}\) be a recursive one-one enumeration of prime numbers. Allowing ambiguity, we will also use \(p_\sigma\) to denote the prime number which codes the string \(\sigma\). Given a recursive oracle function \(\Phi\), we use \(\Phi^v = T\) to express the following:

- (1) \(\Phi^v\) is total;
- (2) \((\forall n)(\Phi^v(n) = \prod_{\sigma \in Lev_n(T)} p_\sigma)\).

Given a tree \(T\) and a string \(v \in T\), let \(T^v\) be the subtree of \(T\) consisting of all \(v' \in T\) extending \(v\). Define \(L_n(T)\) to be the leftmost \(n+1\)-th splitting node and \(R_n(T)\) to be the rightmost \(n+1\)-th splitting node on \(T\).

For each finite string \(\sigma^*\), real \(x\) and perfect tree \(T \subseteq 2^{<\omega}\) with \(\sigma^* \in T\), define \(T(\sigma^*, x, T)\) to be the perfect tree that is the intersection of a sequence of perfect trees \(T_n\) given as follows:

\(T_0 = T^{\sigma^*}\).

\(T_{n+1} = \{\tau \mid (\exists \sigma \in Lev_n(T_n))(\sigma \preceq \tau \land \tau \in S_{n+1})\}\).

where \(S_{n+1}\) is defined as:

Case 1. \(x(n) = 0\): \(\sigma \in S_{n+1}\) if and only if there exists \(\tau \in Lev_{n+1}(T_n)\) so that \(\sigma \succeq \tau\) and \(\sigma = L_1(T_n^\tau)\) for some \(v\) which is an \(n\)-th splitting node of \(T_n\).

Case 2. \(x(n) = 1\): \(\sigma \in S_{n+1}\) if and only if there exists \(\tau \in Lev_{n+1}(T_n)\) so that \(\sigma \succeq \tau\) and \(\sigma = R_1(T_n^\tau)\) for some \(v\) which is an \(n\)-th splitting node of \(T_n\).

\(\mathcal{T}(\sigma^*, x, T) = \bigcap_n T_n\).

In other words, $\mathcal{T}(\sigma^*, x, T)$ is a subtree which, roughly speaking, codes $x(n)$ at a $2n$-th splitting node of $T^*$. Note that $\mathcal{T}(\sigma^*, x, T) \oplus_T T \ge_T x$. Moreover, suppose for some recursive oracle function $\Phi$, we have $\Phi^y = T$ for all $y \in [T]$. Then there is a recursive oracle function $\Psi$ such that $\Psi^y = x$ for all $y \in \mathcal{T}(\sigma^*, x, T)$. Furthermore, given an index of the oracle function $\Phi$, an index of the recursive function $\Psi$ may be effectively obtained from $\sigma^*$. In other words, there is a recursive function $f$ such that $\Phi_{f(\sigma^*)}^y = x$ for all $y \in [\mathcal{T}(\sigma^*, x, T)]$. Since $\Phi^y = T$ for all $y \in [\mathcal{T}(\sigma^*, x, T)] \subseteq [T]$ and $x \ge_T \mathcal{T}(\sigma^*, x, T)$, there is a recursive function $g$ so that $\Phi_{g(\sigma^*)}^y = \mathcal{T}(\sigma^*, x, T)$ for all $y \in [\mathcal{T}(\sigma^*, x, T)]$.

We give a sketch of the idea behind the construction. To obtain a minimal cover of a countable set $A = \{x_i\}_{i<\omega}$, one makes appropriate modifications of the construction of a minimal degree (see [82]). To make the minimal degree relatively high (i.e. to make it compute a given x through jumps), one needs to code the indices of the perfect trees in the course of the construction. Were the construction uniform, one could use the Recursion Theorem to code the index of the next perfect tree being defined during the step by step construction. This technique could be applied to code x and $x_i$ into z for each $i < \omega$. However, the construction to achieve minimality is nonuniform (one needs to decide whether the next tree will be an "s-splitting tree" or a "full tree", which in general is a "double jump" question). Although it is highly nonuniform, the construction does become uniform once it is decided which situation one is in (see Substep 3 of the construction below). This is the reason for using $z''$ to "get up" to x.

We now turn to the construction.

Fix a real x and an enumeration $(x_i)_{i \in \omega}$ of A. Suppose the recursive oracle functional $\Phi_0$ satisfies $\Phi_0^y = 2^{<\omega}$ for all reals y. We construct a sequence of perfect trees step by step. At step n, we construct a perfect tree $T_n \le_T \Phi_{<e(x_i)}$ and a finite string $\sigma_n$ so that $T_n \upharpoonright |\sigma_n| = \{\tau \mid \tau \le \sigma_n\}$, $|\sigma_n| > n$ and there is a recursive oracle functional $\Phi_{e_n}$ such that for each $y \in [T_n]$, $\Phi_{e_n}^y = T_n$.

### Construction

- Step 0. Define $T_0 = 2^{<\omega}$ and $\sigma_0 = \emptyset$.
- Step n + 1. There are three substeps:
  - Substep 1 (Coding x). For each k, if x(n) = 0 then define $\sigma^k_{n+1,0} = R_1(T^{L_k}_n(T_x))$. Otherwise, let $\sigma^k_{n+1,0} = L_1(T^{R_k}_n(T_x))$. Define $T_{n+1,0,k} = T^{n_{k+1,0}}_{n,k}$. Hence there is a recursive oracle functional $\Phi_{k_i}$ such that for each $y \in T_{n+1,0,k}$, $\Phi_{e_k}^y = T_{n+1,0,k}$. Note that the function $k \mapsto i_k$ is recursive. It follows from the Recursion Theorem that there is a number $k_0$ such that $\Phi_{k_0}^y = \Phi_{i_{k_0}}^y$ for all $y \in [T^{n_{k_0+1,0}}_{n}]$. Fix this $k_0$ and define $\sigma^0_{n+1} = \sigma^{k_0}_{n+1,0}$ and $T_{n+1,0} = T_{n+1,0,k_0}$.
