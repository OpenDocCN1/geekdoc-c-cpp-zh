Note that $\mathcal{P}$ is a $\Pi^0_1$-relation. Then $\mathcal{X}$ may be uniformized by a partial $\Pi^0_1$-function $F : \omega 2^{<\omega} \times \mathscr{S} \to \mathscr{S}$. By assumption, for any $R \le T$, $\sigma \in R$ and $i \in \omega$, $F(R, i, \sigma)$ is defined. Using $F$, a hyperarithmetic family $\{P_\sigma \mid \sigma \in 2^{<\omega}\}$ is defined by recursion on $\sigma$:

$P_0 \vDash T.$

If $\sigma \notin P_\sigma$, let $P_{\sigma 0} = P_{\sigma 1} = \emptyset$. Otherwise let $P_{\sigma 0}$ and $P_{\sigma 1}$ be disjoint conditions stronger than (i.e. contained in) $P_\sigma$ and $P_{\sigma 0} \vDash [0]$, $P_{\sigma 1} \vDash [1] = [\sigma] = \{\tau \mid \tau \prec \sigma\}$ so that $P_{\sigma 0}, P_{\sigma 1} \vDash \lambda_{\sigma \sqcup \rho} \varphi_\rho$.

Let $Q = \bigcup_{\sigma \in P_\sigma} P_\sigma$. Then $Q \in \mathscr{S}$.

For each $i$ and $\sigma \in 2^{i+1}$, we have either $P_\sigma = \emptyset$ or $P_\sigma \Vdash \varphi_i$. Suppose that $\varphi_i$ is of the form $(\exists \beta^i)(z)$ for some ranked $\psi(z)$. Then $P_\sigma \Vdash (\exists \beta^i)\psi(z^{\beta_\sigma})$ for some $\beta_\sigma$ whenever $P_\sigma \neq \emptyset$. Let $\beta = \bigcup_{\sigma \in 2^{i+1}} \beta_\sigma$. By the definition of the forcing relation, we have $Q \Vdash (\exists \beta^i)\psi(z^\beta)$.

$\text{Hence } (\exists \beta^i)(\varphi_i(z^\beta)).$

Hence for every $i, Q \Vdash \varphi_i.$

# Lemma 5.3.4. For any sentence $\varphi$ and condition $T$, there is an $S \le T$ such that either $S \Vdash \varphi$ or $S \Vdash \neg \varphi$.

Proof. If $\varphi$ is unranked, then the lemma follows immediately from the definition. For $\varphi$ of rank $\beta$, we prove the lemma by induction on $\beta$. Without loss of generality, assume that $\varphi$ is of the form $(\exists \beta^i)\psi(x^\beta)$ for some $\psi$ with rank less than $\beta$. Let $\{\dot{\varphi}_i(n)\}_{i < \omega}$ be a hyperarithmetic enumeration of all the formulas for rank at most $\beta$ whose only free variable is $n$. If there is an $i$ and $S \le T$ such that $S \Vdash \psi(x^\beta \mid \dot{\varphi}_i)$, then we are done. Otherwise, by Lemma 5.3.3 and the inductive hypothesis, there is an $S \le T$ such that $S \Vdash \neg \psi(x^\beta \mid \dot{\varphi}_i)$ for every $i$. Then $S \Vdash \neg \varphi$.

# 5.3.2 Sacks generic reals

A set $D \subseteq \mathscr{S}$ is dense if for any condition $T$, there is an $S \in D$ such that $S \le T$. A real $x$ is Sacks generic if for any dense set $D \subseteq \mathscr{S}$ arithmetical in $\emptyset$, there is a condition $T \in \mathscr{S}$ such that $x \in [T]$. Note that by Lemma 5.3.2 and Lemma 5.3.4, for any sentence $\varphi$ the set $D_p = \{T \in T \mid p \Vdash T \Vdash \neg p\}$ is dense and arithmetical in $\emptyset$.

# Lemma 5.3.5. Let $x$ be Sacks generic and $x \in [T_0] \cap [T_1]$. Then there is a $T \le T_0 \cap T_1$ such that $x \in [T]$.

Proof. Let $i \in \{0, 1\}$. Since $T_i$ is hyperarithmetic, there is a ranked formula $\varphi_i$ such that

$(\forall \sigma)(\sigma \in T_i \leftrightarrow \exists \alpha(\alpha_1^{\text{CK}}, z) \models \varphi_i(\sigma)).$

Hence for $i < 2$,

$(\forall i < 2)(z \in [T_i] \leftrightarrow \exists \alpha(\alpha_1^{\text{CK}}, z) \equiv (\forall n)p_i(z \nmid n)).$
