# 2.2 $\Delta^1_1$-ness and hyperarithmeticity

In this section we prove the fundamental result that a set is $A^1_1$ if and only if it is hyperarithmetic.

# 2.2.1 $A^1_1$-subsets of $\omega$

Lemma 2.2.1. The following two predicates are $\Pi^1_1$: (i) $n \in O^\vee \land k \in H^y_n$, (ii) $n \in O^\vee \land k \notin H^y_n$.

Proof. Note that $n \in O^\vee \land k \in H^y_n$ if and only if $n \in O^\vee \land (\forall z)(H(n, z, y) \rightarrow k \in z)$, and $n \in O^\vee \land k \notin H^y_n$ if and only if $n \in O^\vee \land (\forall z)(H(n, z, y) \rightarrow k \notin z)$. By Proposition 1.2.5 and Theorem 2.14, both are $\Pi^1_1$.

Corollary 2.2.2 (Kleene [69]). (i) If $x$ is hyperarithmetic in $y$, then $x$ is $\Delta^1_1(y)$. (ii) The Set $\{(x, y) \mid x \in \text{HYP}^y\}$ is $\Pi^1_1$.

Proof. If $x$ is hyperarithmetic in $y$, then there is an $H^y$-set $H^y_n$ such that $x \le_T H^y_n$ for some $n \in O^\vee$. Hence $x = \Phi^{H^y}_e$ for some $e$. Then both the predicates

```
$k \in x \leftrightarrow (\exists \sigma)(\Phi^e_\sigma(k) = 1 \land \sigma \prec H^y_n)$
```

and

```
$k \notin x \leftrightarrow (\exists \sigma)(\Phi^e_\sigma(k) = 0 \land \sigma \prec H^y_n)$
```

are $\Pi^1_1(y)$ by Lemma 2.2.1.

Now $x \in \text{HYP}^y \leftrightarrow (\exists n)(\exists e)(n \in O^\vee \land x = \Phi^{H^y}_e) \leftrightarrow (\exists n)(\exists e)(\forall m)(\forall z)(n \in O^\vee \land (H(n, z, y) \rightarrow x = \Phi^z_e))$ where $H$ is as in Theorem 2.14. Thus the set $\{(x, y) \mid x \in \text{HYP}^y\}$ is $\Pi^1_1$.
