
Proposition 3.3.11. There is a \(\Sigma_1\)-formula \(\varphi(x, y, i, z)\) such that for any ordinal \(\alpha\), the function

\(h_\alpha(i, x) = y \leftrightarrow \langle J_\alpha, \in \rangle \models (\exists z)\varphi(x, y, i, z)\)

is a \(\Sigma_1\)-Skolem function for \(\langle J_\alpha, \in \rangle\).

Proof. By Proposition 3.3.3, there is a \(\Sigma_1\)-formula \(\varphi(u, v)\) defining a well-ordering \(<_J\) of \(J_\alpha\) for any admissible \(\alpha\). Clearly there is a \(\Sigma_1\)-enumeration \(\langle \varphi_i(u, v, w) \rangle\) of all \(\Sigma_0\)-formulas. In other words, there is a \(\Sigma_1\)-formula \(\varphi(x, y, i, z)\) so that \(\langle J_\alpha, \in \rangle \models \varphi(x, y, i, z) \leftrightarrow \langle J_\alpha, \in \rangle \models \varphi_i(x, y, z)\). Define \(h_\alpha(i, x)\) to be \(y\) so that \(\langle y_0, y_1 \rangle\) is the \(<_J\)-least pair with \(\langle J_\alpha, \in \rangle \models \varphi_i(y_0, y_1, x)\). By Proposition 3.3.3, \(h_\alpha(i, x)\) is \(\Sigma_1\)-definable.

By the admissibility of \(\alpha\), using some tedious coding argument which may be found in [22], one can show that the relation \(h_\alpha(i, x) = y\) is uniformly \(\Sigma_1\). Let \(h_\alpha(i, x) = y\) if and only if there exist \(y_0, y_1\) such that \(\langle J_\alpha, \in \rangle \models \varphi(y_0, y_1, x)\) and there exists \(z = \langle z_0, z_1 \rangle\) such that \(\langle z_0, z_1 \rangle <_J \langle y_0, y_1 \rangle\) such that for any pair \(\langle z_0, z_1 \rangle \in J_\alpha\), \(\langle J_\alpha, \in \rangle \models \neg \varphi(z_0, z_1, x)\). Since \(z\) is uniformly \(\Delta_1\)-definable for any admissible \(\alpha\), we have \(h_\alpha(i, x)\) to be uniformly \(\Sigma_1\)-definable for any admissible \(\alpha\).

If \(\alpha\) is admissible, we call the \(\Sigma_1\)-Skolem function \(h_\alpha\) the canonical \(\Sigma_1\)-Skolem function for \(\alpha\).

Proposition 3.3.12. If \(\alpha > \omega\) is admissible, then \(\alpha \ge \omega_1^{CK}\).

Proof. Suppose \(\alpha\) is admissible and \(\omega < \alpha < \omega_1^{CK}\). By Theorem 3.3.6, \(L_\alpha\) is admissible. By Theorem 13.4, there is a recursive function \(f\) such that for each \(n \in \omega\), \(f(n) = \langle \{i, j\} | i <_J j < n \rangle\). Fix a number \(n \in \omega\) with \(|n| = \alpha\). Then the order type of \(W_{f(n)}\) is \(\alpha\) and \(W_{f(n)} \in L_{\omega+1} \subseteq L_\alpha\) by Theorem 3.2.5. By \(\Sigma\)-induction there is a \(\Sigma_1\) order-preserving bijection \(g : W_{f(n)} \to \alpha\). Since \(W_{f(n)} \in L_\alpha\), \(\alpha \in L_\alpha\) by the admissibility of \(\alpha\). This is a contradiction.

## 3.4 Projecta and master codes

In the interest of keeping the chapter within reasonable length and the proofs simpler, we present weaker versions of results in Jensen [55]. Nevertheless, the key ideas are extracted from [55] and the results are sufficient for recursion-theoretic applications.

### 3.4.1 Projecta

**Definition 3.4.1.** Let \(\alpha > 0\) and \(n \ge 1\). The \(\Sigma_n\)-projectum \(\rho_\alpha^n\) of \(\alpha\) is the least ordinal \(\rho\) for which there is a \(\Sigma_1(J_\alpha)\)-definable function \(f\) mapping a subset of \(J_\rho\) onto \(J_\alpha\).

Clearly \(\rho_\alpha^n\) exists for any \(n \ge 1\). One may replace \(J_\rho\) with \(\omega\rho\) in the above definition. To prove this, we need the following lemma whose proof is left to the reader:

**Lemma 3.4.2.** Let \(\alpha > 0\). For each \(1 \le \gamma \le \omega\alpha\), there is a \(\Sigma_1(J_\alpha)\)-definable bijection between \(\omega\alpha\) and \(\gamma \times \omega\alpha\).

**Proposition 3.4.3.** Let \(\alpha > 0\). There is a \(\Sigma_1(J_\alpha)\)-definable function from \(\omega\alpha\) onto \(J_\alpha\).

**Proof.** Let \(f_0 = (f^0, f^1)\) be a bijection between \(\omega\alpha\) and \((\omega\alpha)^2\) guaranteed by Lemma 3.4.2 (setting \(\gamma = \omega\alpha\)) defined via the \(<_{J_\alpha}\)-least parameter \(p \in J_\alpha\). Define \(f_{n+1}(\gamma) = (f^0(\gamma), f_n(f^1(\gamma)))\) for \(\gamma < \omega\alpha\). It is easy to verify that \(f_n\) is \(\Sigma_1(J_\alpha)\)-definable with parameter \(p\) and is a bijection between \(\omega\alpha\) and \((\omega\alpha)^{n+2}\). Let \(h_\alpha\) be the canonical \(\Sigma_1\)-Skolem function for \(J_\alpha\). Set \(X = h_\alpha(\omega \times (\omega\alpha \times p))\). Note that for each \(n < \omega\) and \(y < \omega\alpha\), there is an \(i_n\) such that \(f_p(y) = h_\alpha(i_n, \langle p, y \rangle)\). Thus \(\chi \in X\) for every \(\chi < \omega\alpha\). By Proposition 3.3.10, \((X, \in) \prec_{\Sigma_1} (J_\alpha, \in)\). By Theorem 3.3.7, there is a \(\beta \le \alpha\) and an isomorphism \(\pi : (X, \in) \cong (J_\beta, \in)\). Moreover, \(\pi(p) \le_{J_\alpha} p\). Since \(\chi \in X\) for every \(\chi < \omega\alpha\), we have \(\pi\beta = \alpha\) and \(\pi(\gamma) = \gamma\) for every \(\gamma < \omega\alpha\). Hence \(\pi^{-1} : (J_\alpha, \in) \xrightarrow{\Sigma_1} (J_\alpha, \in)\) and \(\pi^{-1}(f_0) = f_0\). Thus \(f_0\) is also defined by \(\pi(p)\) in \((J_\alpha, \in)\). By the assumption on \(p\), \(p \le_{J_\alpha} \pi(p)\) and so \(p = \pi(p)\). Then for any \(x \in X\), there are \(i < \omega\) and \(\gamma < \omega\alpha\) such that \(x = h_\alpha(i, \langle \gamma, p \rangle) = h_\alpha(\pi(i), \langle \pi(\gamma), \pi(p) \rangle) = \pi(x)\), implying that \(X = J_\alpha\). Note that \(h_\alpha\) is not necessarily total. Let \(\varphi(u, i, v, w, s)\) be a \(\Sigma_0\)-formula such that \(h_\alpha(i, \gamma, p) = x\) if and only if \((J_\alpha, \in) \models (\exists y)\varphi(i, \gamma, p, x, y)\). Then by the proof of Proposition 3.3.11, there is a total \(\Sigma_1\)-function \(h'(i, \gamma_1, \gamma_2) = \begin{cases} x & (J_\alpha, \in) \models (\exists n \in \omega)(\exists y \in J_\omega \cup S^{(\alpha)}(J_\rho))\varphi(i, \gamma_1, p, \gamma_2, y), \\ 0 & \text{Otherwise.} \end{cases}\) Let \(h(\gamma) = h'(f_1(\gamma))\) for \(\gamma < \omega\alpha\).

Applying Proposition 3.4.3, we have:

**Proposition 3.4.4.** \(\alpha\) is admissible if and only if there is no \(\Sigma_1(J_\alpha)\)-definable function mapping \(\alpha\) onto \(\omega\alpha\).

The next lemma is a characterization of \(\rho_\alpha^1\).

**Lemma 3.4.5.** Suppose that \(\alpha > 0\) and \(\rho = \rho_\alpha^1\). Then \(A \in J_\rho\) for any \(\gamma < \rho\) and any \(\Sigma_1(J_\alpha)\)-definable \(A \subseteq J_\gamma\).

Proof. If \(\rho = 1\) then the conclusion is immediate. Suppose \(\rho > 1\). Then \(\rho\) is a limit ordinal. Let \(\gamma < \rho\) and \(A \subseteq J_\gamma\). Let \(h_\alpha\) be the canonical \(\Sigma_1\)-Skolem function for \(J_\alpha\). Fix \(p \in J_\alpha\) such that \(A\) is \(\Sigma_1(J_\alpha)\)-definable with parameter \(p\). Let \(X = h_\alpha(\omega \times \{p\})\). Then \((X, \in) \prec_\Sigma (J_\alpha, \in)\). By Theorem 3.3.7, there is a \(\beta \le \rho\) such that \(\pi : (X, \in) \cong (J_\beta, \in)\) is an isomorphism. Note that \(\pi(x) = x\) for all \(x \in J_\gamma\) since \(\gamma\) is transitive. Hence \(\pi(x) = x\) for all \(x \in A\). Thus \(A\) is also \(\Sigma_1\)-definable in \(J_\rho\) with parameter \(\pi(p) \in J_\beta\). We claim that \(\beta < \rho\). Otherwise, let \(f\) be \(\Sigma_1(J_\alpha)\) mapping a subset of \(J_\rho\) onto \(J_\alpha\). Then \(f \circ \pi \circ h_\alpha\) is \(\Sigma_1(J_\alpha)\) and maps a subset of \(\omega \times (J_\gamma \times \{p\})\) onto \(J_\alpha\). But \(\omega \times J_\gamma \times \{p\} \in J_{\gamma+2} \subseteq J_\rho\), and so it maps a subset of \(J_{\gamma+2}\) onto \(J_\alpha\), contradicting the choice of \(\rho\).

**Lemma 3.4.6.** Let \(\alpha > 0\) and \(\rho = \rho_\alpha^+\). Then there is an \(A \subseteq J_\rho\) which is \(\Sigma_1(J_\alpha)\)-definable and \(A \notin J_\alpha\).

**Proof.** Let \(f\) be \(\Sigma_1(J_\alpha)\)-definable mapping a subset of \(J_\rho\) onto \(J_\alpha\). Then the domain of \(f\) restricted to \(J_\rho\) is \(\Sigma_1(J_\alpha)\) and not an element of \(J_\alpha\) by admissibility.

Lemma 3.4.5 and Lemma 3.4.6 yield the following characterization of \(\rho_\alpha^+\):

**Theorem 3.4.7.** Let \(\alpha > 0\). Then \(\rho_\alpha^+\) is the least ordinal \(\rho\) for which there is a \(\Sigma_1(J_\alpha)\) set \(A \subseteq J_\rho\) not in \(J_\alpha\).

Now suppose that \(x \subseteq \omega\) is \(\Sigma_1(J_\alpha)\)-definable with parameter \(p\) and \(x \notin J_\alpha\). Let \(X = h_\alpha(\omega \times \{p\})\). We may identify \(\omega \times J_1\) with \(J_1\). Hence \(X = H(1 \times \{p\})\) for some \(\Sigma_1\)-function \(H\). Then \((X, \in) \prec_\Sigma (J_\alpha, \in)\). By transitive collapse there is a \(\beta \le \alpha\) such that \(\pi : (X, \in) \cong (J_\beta, \in)\). Since \(x \subseteq J_1\), \(\pi(n) = n\) for all \(n \in \omega\). Thus \(x\) is \(\Sigma_1(J_\beta)\)-definable with parameter \(\pi(p)\). If \(\beta < \alpha\), then \(x \in J_\alpha\) which is a contradiction. Thus \(\beta = \alpha\). Now \(\pi\) is \(\Sigma_1(J_\alpha)\)-definable and so \(\pi \circ h\) is \(\Sigma_1(J_\alpha)\)-definable and maps a set \(y \subseteq J_1\) onto \(J_\alpha\). Since \(J_1 \simeq \text{HF}\), by Proposition 3.2.6, we may assume that \(y\) is a real. Hence for any admissible \(\alpha\), if \(J_{\alpha+1} \backslash J_\alpha\) contains a \(\Sigma_1(J_\alpha)\)-definable real, then it contains a real "coding \(J_\alpha\)".

**Remark 3.4.8.** Theorem 3.4.7 remains valid for \(n \ge 1\). However, the proof requires more than a straightforward generalization of what was presented above. The major difficulty is that there is no canonical \(\Sigma_n\)-Skolem function for \(n \ge 2\). To overcome this difficulty, a finer analysis of \(J_\alpha\) is introduced. See Jensen [55] for details.

### 3.4.2 Master codes

**Definition 3.4.9.** Given an ordinal \(\alpha\) and \(n \ge 0\), a \(\Sigma_n\)-master code for \(J_\alpha\) is a \(\Sigma_n(J_\alpha)\)-definable set \(A \subseteq J_\rho\) such that for any \(m \ge 1\), any set \(B \subseteq J_\rho\) that is \(\Sigma_{n+m}(J_\alpha)\)-definable is \(\Sigma_m\)-definable in \((J_\rho, \in, A)\).
