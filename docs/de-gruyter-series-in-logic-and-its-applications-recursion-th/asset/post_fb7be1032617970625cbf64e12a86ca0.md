
By (iii) of Proposition 3.6.4, if $f$ is recursive, then every real in $\mathfrak{M}$ is recursive in $E$. If such a recursive $f$ exists, we say that $\langle \omega, E \rangle$ is a nicely coded $\omega$-model.

**Proposition 3.6.5.** If $\langle \omega, E \rangle$ codes an $\omega$-model, then there is a nicely coded $\omega$-model $\langle \omega, E_0 \rangle \equiv \langle \omega, E \rangle$. Moreover, the set $E \mid \{ \langle \alpha, E \rangle \text{ is a nicely coded } \omega\text{-model} \}$ is $\Delta^1_1$.

Proof. Suppose that $\langle \omega, E \rangle$ codes an $\omega$-model and $m$ codes $\omega$ in $\langle \omega, E \rangle$. Without loss of generality, we may assume that $\{ k \mid \langle k, E \rangle \in K m \}$ is infinite. Let $f : \omega \to \{ k \mid \langle \omega, E \rangle \equiv k E m \}$ be an order-preserving bijection. Let $g : \omega \to \omega$ be any bijection such that $g(2n) = f(n)$ for every $n$. Now define $j E_0 i$ if and only if $g(i) E g(j)$. Then $g : \langle \omega, E \rangle \equiv \langle \omega, E_0 \rangle$. Obviously $n E_0^{CK} 1(m)$ if and only if $n$ is an even number. Let $h(n) = 2n$. Then $h$ is recursive and $h : \omega \to \{ i \mid \langle \omega, E_0 \rangle \equiv i E_0^{CK} 1(m) \}$ is an order-preserving bijection. Thus $\langle \omega, E_0 \rangle$ is a nicely coded $\omega$-model.

We leave the proof of the second part of Proposition 3.6.5 to the reader.

From the above it is harmless to assume that an $\omega$-model $\langle \omega, E \rangle$ is always nicely coded.

## 3.6.4 The second least admissible ordinal

An application of the previous results yields

**Lemma 3.6.6.** $\omega_1^{CK}$ is the second least admissible ordinal.

Proof. Let $\alpha$ be the second least admissible ordinal. By Proposition 3.3.12, $\alpha \ge \omega_1^{CK}$. Let $\mathscr{X} = \{ E \mid \langle \omega, E \rangle \text{ nicely codes an } \omega\text{-model of KP} \}$. By Proposition 3.6.5, $\mathscr{X}$ is a $\Delta^1_1$-set. By Gandy's Basis Theorem (2.5.3), there is an $E \in \mathscr{X}$ such that $\omega_1^E = \omega_1^{CK}$. Let $\langle M_1, \in \rangle$ be the $\omega$-model coded by $\langle \omega, E \rangle$ and $M_1$ its standard part. By Lemma 3.5.4, $\langle M_1, \in \rangle \models \text{KP}$. We claim that $\beta < \omega_1^{CK}$ for any $\beta \in M_1$. Assume this is false. Let $m \in \omega$ be a real which codes $\omega_1^{CK}$ in $\langle \omega, E \rangle$. Then the set

$\{ \langle i, j \rangle \mid \langle \omega, E \rangle \models i E j \land j E m \}$

is an $E$-recursive well-ordering of order type $\omega_1^{CK}$, contradicting $\omega_1^E = \omega_1^{CK}$. Thus $o(M_1) = \omega_1^{CK}$ and hence $\alpha = \omega_1^{CK}$. Hence $\omega_1^{CK}$ is the second least admissible ordinal.

By Theorem 3.3.6 and Lemma 3.6.6, we have

**Corollary 3.6.7.** $L_{\omega_1^{CK}}$ is admissible.

**Theorem 3.6.8.** A real $x$ is hyperarithmetic real if and only if $x \in L_{\omega_1^{CK}}$.

Proof. To prove that every hyperarithmetic real belongs to $L_{\omega_1^{CK}}$, it suffices to prove $H_n \in L_{\omega_1^{CK}}$ for any $n \in \omega$. By Proposition 2.1.5, $H_n$ is Turing reducible to some $\Pi^0_1$-singleton $f_n \in \omega^\omega$. So it is sufficient to prove that $f_n \in L_{\omega_1^{CK}}$.

Since $f_n$ is a $\Pi^0_1$-singleton, there is a recursive tree $T_n$ such that $f_n$ is the unique infinite path in $T$. Then for every $m \in \omega$ and $\sigma \in \omega^{<\omega} \setminus \{ f_n \mid m \}$, $T_\sigma = \{ \tau \in T_n \mid \tau > \sigma \}$ is wellfounded. Since $L^K_{\omega_1^{CK}}$ is admissible, there is an $h_\sigma : T_\sigma \to \omega_1^{CK}$ in $L^K_{\omega_1^{CK}}$ such that for any $r_1 >_T r_0$ in $T_\sigma$, $h_\sigma(r_1) < h_\sigma(r_0)$. Hence there is a $\beta_\sigma \in \omega_1^{CK}$ such that $h_\sigma \in L_{\beta_\sigma}$. Since $\omega_1^{CK} \setminus f_n \mid m \in L_{\alpha_\beta}$, by Theorem 3.3.2 and the $\Sigma$-Collection Theorem (3.1.6), there is a $\beta^m < \omega_1^{CK}$ such that $\beta_\sigma < \beta_m$ for all $\sigma \in \omega^m \setminus f_n \mid m$. By Theorem 3.1.6 again, there is a $\beta < \omega_1^{CK}$ which is an upper bound of all the $\beta_m$'s. Then $\sigma < f_n$ if and only if

$\langle L_\beta, \in \rangle \models (\forall \tau \in \omega^{<\omega})(\exists \beta)(\exists \gamma)(\forall r_1, r_2 \in T_\sigma)(h : T_\tau \to \gamma \wedge r_2 >_T r_1 \to h(r_2) < h(r_1)).$

Thus $f_n \in L_{\beta+1} \subset L^K_{\omega_1^{CK}}$.

Suppose that $x \in L^K_{\omega_1^{CK}}$. Since $L^K_{\omega_1^{CK}}$ is admissible, we have $\omega_1^x = \omega_1^{CK}$. Assume that $x$ is not hyperarithmetic. Define

$\mathscr{X} = \{E \mid \langle \omega, E \rangle \text{ nicely codes an } \omega\text{-model of KP}\}.$

By Proposition 3.6.5, $\mathscr{X}$ is a $\Delta^1_1$-set. By the Kreisel Basis Theorem (2.5.6), there is an $E_0 \in \mathscr{X}$ with $\omega_1^{E_0} = \omega_1^{CK}$ and $x \notin E_0$. Let $\langle M, \in \rangle$ be the $\omega$-model coded by $\langle \omega, E_0 \rangle$ and let $M_1$ be the standard part of $M$. Then every real $z \in M_1$ is recursive in $E_0$. Hence $x \notin M_1$. By Proposition 3.5.5, $L^K_{\omega_1^x} \subset M_1$. Thus $x \notin L^K_{\omega_1^x}$.

This gives a model-theoretic characterization of the set of hyperarithmetic reals:

**Corollary 3.6.9.** A real $x$ is hyperarithmetic if and only if it belongs to every $\omega$-model of KP.

**Proof.** By Theorem 3.6.8, $x$ is hyperarithmetic if and only if $x \in L^K_{\omega_1^x}$. By Theorem 3.5.5 and Corollary 3.6.7, $x \in L^K_{\omega_1^x}$ if and only if $x$ belongs to every $\omega$-model of KP.

## 3.6.5 The Cantor-Bendixson construction revisited

We now return to the recursion-theoretic proof of Theorem 1.1.10 and calculate the least ordinal $\gamma$ for which $T_{\gamma+1} = T_\gamma$.

**Proposition 3.6.10.** Suppose $T \subset \omega^{<\omega}$ is a recursive tree with uncountably many infinite paths. Then there is a $\Sigma_1(L_{\omega_1^{CK}})$-function $f : \omega_1^{CK} \to L_{\omega_1^{CK}}$ such that for any $\gamma_1 < \gamma_2 < \omega_1^{CK}$, $f(\gamma_2) = T_{\gamma_2} \subseteq f(\gamma_1) = T_{\gamma_1} \subseteq T$ and $\cap_{\gamma < \omega_1^{CK}} T_\gamma$ is a perfect subtree of $T$.

Proof. Since $T$ is recursive, we have $T \in L_{\omega+1}$. By Theorem 3.1.8, there is a $\Sigma_1(L_{\omega_1^{CK}})$-function $f : \omega_1^{CK} \to L^K_{\omega_1^{CK}}$ such that

- $f(0) = T$;
- for any $\gamma < \omega_1^{CK}$, $f(\gamma + 1) = T_{\gamma+1} = \{\sigma \in T_\gamma \mid (\exists \tau_0, \tau_1 > \sigma)(\tau_0, \tau_1 \in T_\gamma \wedge \tau_0 \perp_T \tau_1)\} \subseteq f(\gamma)$;
- if $\gamma$ is a limit ordinal, then $f(\gamma) = T_\gamma = \cap_{\beta < \gamma} T_\beta$.

First note that $|[T_\gamma] \setminus [T_{\gamma+1}]| \le \aleph_0$ for each $\gamma < \omega_1^{CK}$, and hence $[T_{\omega_1^{CK}}] \neq \emptyset$. We claim that $T_{\omega_1^{CK}} = \cap_{\gamma < \omega_1^{CK}} T_\gamma \subseteq T$ is a perfect tree. First note that given $\sigma \in T_{\omega_1^{CK}}$, there is a $\tau > \sigma$ such that $\tau \in T_{\omega_1^{CK}}$. Otherwise, let $g_0(n)$ be the least ordinal $\gamma < \omega_1^{CK}$ for which $\sigma^\frown n \notin T_\gamma$. Then $g_0$ is a total function and $\Sigma_1$ in $L_{\omega_1^{CK}}$. By the admissibility of $\omega_1^{CK}$ (Corollary 3.6.7), there is an ordinal $\beta < \omega_1^{CK}$ so that $g_0(n) < \beta$ for all $n$. Then $\sigma \notin T_{\beta+1}$, a contradiction.

Now suppose that $\sigma \in T_{\omega_1^{CK}}$ is an isolated path, i.e. $[\sigma] \cap [T_{\omega_1^{CK}}]$ contains exactly one path. Let $h_0(n)$ be the least ordinal $\gamma < \omega_1^{CK}$ such that $[\{\tau \in T \mid T_\gamma \wedge \tau \supset \sigma \mid [\sigma] = [\sigma] \mid n\}] = 1$. Then $h_0$ is a total function and $\Sigma_1$ in $L_{\omega_1^{CK}}$. By Corollary 3.6.7 again, there is an ordinal $\beta < \omega_1^{CK}$ such that $h_0(n) < \beta$ for all $n$. Then for any $\tau_0, \tau_1 > \sigma$, if $\tau_0, \tau_1 \in T_\beta$, then $\tau_0$ and $\tau_1$ are compatible. So $\sigma \notin T_{\beta+1}$, a contradiction.
