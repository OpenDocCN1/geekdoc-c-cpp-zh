Proposition 6.1.13. Let \(a\) be an infinite ordinal. Assume that \(\mathcal{M} \vDash \text{ZFC} \wedge \text{``}\kappa > \omega \text{ is regular''}\), \(I = \{s \mid s \subseteq a \wedge |s| < \aleph_0\}\) and let \(\mathbb{P}_a = (\mathbf{P}_a, \le_{\mathbb{P}_a}, \Vdash \le a, I)\). If for each \(p\) and \(\beta \le a\), \(p \Vdash \beta\) ``\(\dot{Q}_\beta\) satisfies c.c.c.'', then for each \(\beta \le a\), \(\mathbb{P}_\beta\) satisfies c.c.c. in \(\mathcal{M}\).

Remark 6.1.14. A similar statement holds for proper forcing in the case when \(I\) is countably supported. The proofs can be found in [53].

# 6.1.6 Embeddings and isomorphisms

Definition 6.1.15. A function \(f\) from \((\mathbf{P}, \le)\) into \((\mathbf{Q}, \le)\) is a dense embedding if
- \((\forall p_0)(\forall p_1)(p_0 \le p_1 \rightarrow f(p_0) \le f(p_1))\);
- \((\forall p_0)(\forall p_1)(p_0 \| p_1 \rightarrow f(p_0) \| f(p_1))\);
- Range(\(f\)) is a dense subset of \(\mathbf{Q}\).

A function \(f\) from \((\mathbf{P}, \le)\) into \((\mathbf{Q}, \le)\) is an isomorphism if \(f\) is a bijection such that \((\forall p_0)(\forall p_1)(p_0 \le p_1 \leftrightarrow f(p_0) \le f(p_1))\). Clearly every isomorphism is a dense embedding.

Definition 6.1.16. Suppose that \(f : \mathbf{P} \to \mathbf{Q}\). For any \(\tau \in M^{\mathbf{P}}\), recursively define the corresponding \(\mathbb{Q}\)-name \(\tau\) of \(\tau\) induced by \(f\) as
\(f_*(\tau) = \{(f_*(\sigma), f(p)) \mid (\sigma, p) \in \tau\}\).

This allows one to prove the following proposition.

Proposition 6.1.17. Let \(\mathcal{M} \vDash \text{ZFC}\) and let \(f : \mathbf{P} = (\mathbf{P}, \le) \to \mathbf{Q} = (\mathbf{Q}, \le)\) be a dense embedding.
(i) If \(H\) is \(\mathbb{Q}\)-generic over \(\mathcal{M}\), then \(f^{-1}(H)\) is \(\mathbb{P}\)-generic over \(\mathcal{M}\) and \(M[f^{-1}(H)] \subseteq M[H]\).
(ii) For any formula \(\varphi(v_0, \dots, v_n)\),
\(p \Vdash \varphi(\tau_0, \dots, \tau_n) \leftrightarrow f(p) \Vdash \varphi(f_*(\tau_0), \dots, f_*(\tau_n))\).
