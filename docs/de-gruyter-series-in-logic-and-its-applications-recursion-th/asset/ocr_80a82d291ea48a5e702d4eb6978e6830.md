and only if G = G1 x G2 where G1 <= P is generic over M and G2 is generic over M[G1]. Moreover, M[G] = M[G1][G2].

In general, the c.c.c. property is not preserved under product forcing. This limitation is addressed by the following stronger property.

Definition 6.1.10. A forcing notion has property (K) if every uncountable set of conditions has an uncountable subset of mutually compatible elements.

The next theorem is in Jech [53].

# Theorem 6.1.11.

+   (i) Let gamma >= 0 be an ordinal and assume that for each alpha < gamma, P_alpha has property (K). Then the product forcing P = Pi_{alpha < gamma} P_alpha with finite support has property (K);
+   (ii) Suppose that kappa >= aleph_1, kappa^omega = kappa and |P_i| <= kappa for each i in I. Then the product forcing Pi_{i in I} P_i with countable support satisfies kappa^+-c.c.

# 6.1.5 Iterated forcing

Product forcing is less amenable to fine tuning the construction of a model. The notion of iterated forcing, introduced by Solovay and Tennenbaum [147], offers more “flexibility” in this respect. Given an ordinal alpha, let I subset P(alpha) be an ideal such that {0} in I. We define iterated forcing P_beta = (P_beta, Q_gamma, gamma <= beta, I) on ordinals beta <= alpha with support I by induction on beta.

Definition 6.1.12. For beta = 0, P_0 = (P_0, Q_0, 0, I) satisfies

+   - Q_0 is a notion of forcing;
+   - p in P_0 if and only if p is a function such that Dom(p) = {0} and p(0) in Q_0.

For beta = xi + 1, a forcing condition p in P_beta is a partial function whose domain belongs to I so that

+   - p | xi = ((eta, r) | xi < eta ^ lambda p(r) = r) in P_xi;
+   - Q_beta is a P_xi-name;
+   - if beta in Dom(p), then p | xi ^ p(beta) in Q_beta.

If q in P_beta, define p <=_beta q if p | xi <= q | xi and p | xi ^ p(beta) <= q(beta).

If P_beta is a limit ordinal, then a forcing condition p in P_beta is a partial function whose domain belongs to I so that

+   - for every xi < beta, p | xi = ((eta, r) | xi < eta ^ lambda p(r) = r) in P_xi;
+   - {xi < beta | Dom(p) in I}.

If q in P_beta, define p <=_beta q if and only if p | xi <= q | xi for every xi < beta.

The two most useful notions of iterated forcing are those defined in terms of finite and countable support.
