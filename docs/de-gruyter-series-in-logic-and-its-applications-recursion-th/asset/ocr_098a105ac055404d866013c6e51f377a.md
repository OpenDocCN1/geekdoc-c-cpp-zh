Then $S_i, T_i$ and $U$ are definable in $(\mathscr{P}_n, \le)$. For any $\mathbf{x}_1, \dots, \mathbf{x}_n \le \mathbf{a}$, $R(\mathbf{x}_1, \dots, \mathbf{x}_n)$ holds if and only if for each $i \in [1, n]$, there is a $\mathbf{y}_i \in S_i$ and $\mathbf{z}_i \in T_i$ such that $\mathbf{y}_1 \cup \cdots \cup \mathbf{y}_n \in U$ and $\mathbf{x}_i \cup \mathbf{y}_i = \mathbf{z}_i$. Hence $R$ restricted to the hyperdegrees below $\mathbf{a}$ is definable, completing the proof of Theorem 10.3.1.

# 10.3.2 Coding an expanded standard model of PA

Consider the standard model $\langle \omega, x, <, +, \cdot, 0, 1 angle$ of Peano arithmetic expanded by a unary predicate $x$. We may represent it as a relation on degrees. Let $\langle \mathbf{d}_n angle_{n < \omega}$ be a countable sequence of hyperdegrees. We interpret $\mathbf{d}_n$ as the number $n$ and define arithmetical relations and functions on finite subsets of $\langle \mathbf{d}_n angle_{n < \omega}$ in the obvious way. From these one may define a countable relation $R^*$ on $\langle \mathbf{d}_n angle_{n < \omega}$ turning it into (a copy of) the standard model of arithmetic with a unary predicate representing the real $x$. By Theorem 10.3.1, there is a finite sequence of degrees $ar{\mathbf{p}}$ and a formula $\varphi$ in the language of partial ordering which together define $R^*$. Fix the formula $\varphi$ throughout this section. Note that not every $ar{\mathbf{p}}$ together with $\varphi$ necessarily code a standard model of arithmetic.

**Definition 10.3.4.** Given a finite sequence $ar{\mathbf{p}}$ of hyperdegrees and a real $x$, we say that $ar{\mathbf{p}}$ codes a standard model with $x$ (as a second order element) if $ar{\mathbf{p}}$ and $\varphi$ together define a relation $R^* = (R_\omega, R_<, R_+, R_\cdot, R_0, R_1)$ which represents the standard model of arithmetic $\mathcal{M} = \langle \omega, x, <, +, \cdot, 0, 1 angle$.

If one removes the unary predicate $x$, then $ar{\mathbf{p}}$ codes a standard model if $ar{\mathbf{p}}$ and $\varphi$ define a relation $R = (R_\omega, R_<, R_+, R_\cdot, R_0, R_1)$ which represents $\mathcal{M} = \langle \omega, <, +, \cdot, 0, 1 angle$. Then the relation "$ar{\mathbf{p}}$ and $\varphi$ code a standard model" is definable in $(\mathscr{P}_n, \le)$. To see this, we make the following observations:

+   - (i) The model $\mathcal{M}$ represented by $R$ satisfies the system of Robinson arithmetic $Q$. Since $Q$ is a finite collection of axioms, it can be expressed in one sentence;
+   - (ii) $\mathcal{M}$ is wellfounded. In other words, there is no infinite descending $R_<$-sequence. By Theorem 10.3.1, there is a formula $\psi(ar{U}, \mathbf{v})$ so that $\mathcal{M}$ is wellfounded if and only if for any finite sequence $ar{\mathbf{q}}$, the set $\{ \mathbf{d} \mid (\mathscr{P}_n, \le) \vDash \psi(ar{\mathbf{q}}, \mathbf{d}) \}$ is not an infinite descending $R_<$-sequence.

Thus the statement that $ar{\mathbf{p}}$ and $\varphi$ code a standard model is definable.
