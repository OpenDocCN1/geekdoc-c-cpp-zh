
$\mathbb{P}_{\ge \aleph_0}$ preserve cardinals. Moreover, $\mathcal{M}[G_{\ge \aleph_0}] \vDash \text{GCH}$. Thus without loss of generality, we may assume that $\mathcal{M}[G_{\ge \aleph_0}] = \mathcal{M}$. In other words, for any $\alpha \le \omega_1$, there is a real $x_\alpha \in M$ such that $p_0 \Vdash \dot{f}(\alpha) = x_\alpha$.

Now for $\alpha < \omega_1 < \beta < \omega_2$, we have
$p_0 \Vdash \text{``}\dot{x}_{\omega_1} \le_T \dot{f}(\beta) \oplus x_\alpha\text{''} \Leftrightarrow \alpha \in X_\beta$.

By Proposition 6.11.7 and a rearrangement of $p_0$ (if necessary), we may assume that $p_0 \in \mathbb{P}_{<\omega_1}$. Let $a_{p_0} = \min\{n \mid (\forall \beta < \alpha)(p_0(\beta) \text{ is undefined})\}$. Then $a_{p_0}$ is a countable ordinal. Since only at most countably many ordinals occur in $\dot{f}(\beta)$, for $\beta > \omega_1$, if $\dot{f}(\beta)$ is not a $\mathbb{P}_{<\omega_0}$-name then there is a permutation $\iota_g$ switching ordinals in $\dot{f}(\beta)$ to countable ordinals greater than $a_{p_0}$. In other words, $\iota_g$ induces an automorphism of $\mathbb{P}$ so that $\iota_g(p_0) = p_0$ but $\iota_g(\dot{f}(\beta)) \in \mathbb{P}_{<\omega_0}$. By Proposition 6.11.7 again,
$p_0 \Vdash \text{``}\dot{x}_{\omega_1} \le_T \iota_g(\dot{f}(\beta)) \oplus x_\alpha\text{''} \Leftrightarrow \alpha \in X_\beta$.

Now in $\mathcal{M}$, there are at most $2^{\aleph_0} = \aleph_1$ many $\mathbb{P}_{<\omega_0}$-names for reals. Thus there exist $\beta_0 \neq \beta_1$ such that $\iota_g(\dot{f}(\beta_0)) = \iota_g(\dot{f}(\beta_1))$. Hence $X_{\beta_0} = X_{\beta_1}$, contradicting the assumption.
Let $N = M[G]$. Then $N \models$ "U is not embeddable into $(\mathscr{D}, \le, U)$". This completes the proof of Theorem 9.2.3.

**Remark 9.2.6.** Both the conclusions of Theorem 9.1.4 (see [4]) and Theorem 9.2.2 (see [167]) are provable under ZFC + MA + $\neg$CH.

## 9.3 Cofinal chains in $\mathscr{D}$

### 9.3.1 Existence of a cofinal maximal chain of order type $\omega_1$

**Definition 9.3.1.** Given a partial ordering $(P, <_P)$, a set $A \subseteq P$ is a _cofinal chain_ if the members of $A$ are linearly ordered under $P$ and for any $z \in P$, there is an $x \in A$ such that $z \le_P x$.

It is not difficult to see that under ZFC, there is a cofinal chain of Turing degrees if and only if CH holds. A natural question is whether there exists a cofinal maximal chain of order type $\omega_1$ in $(\mathscr{D}, \le)$ assuming ZFC + CH. The question is considered in this section.

The following fact is immediate.

**Lemma 9.3.2.** Assume ZF. There exist $x_0$ and $x_1$ of minimal degree such that $\mathbf{0}'' \equiv_T x_0 \oplus x_1 \equiv_T x_0'' \equiv_T x_1''$.

**Lemma 9.3.3.** Assume ZF. There is a maximal chain $\mathbf{0} = c_0 < c_1 < \dots < c_\omega = \mathbf{0}''$ in $[\mathbf{0}, \mathbf{0}']$.

**Proof.** Fix an enumeration $\langle d_n : n \in \omega \rangle$ of degrees below $\mathbf{0}''$. Let $c_0 = \mathbf{0}$.

Suppose that $c_n$ is defined with $c_n'' = \mathbf{0}''$. Relativize Lemma 9.3.2 to obtain degrees $x_0$ and $x_1$ minimal over $c_n$ such that $x_0 \oplus x_1 = c_n'' = \mathbf{0}'' = x_0'' = x_1''$. If $d_n < \mathbf{0}''$ then there is an $i < 2$ with $x_i \not\le d_n$, and let $c_{n+1} = x_i$. If $d_n = \mathbf{0}''$, let $c_{n+1} = x_0$.

Finally let $c_\omega = \mathbf{0}''$.

**Theorem 9.3.4** (Wang, Wu and Yu [168]). Assume ZFC. Then CH holds if and only if there is a cofinal maximal chain in $\mathscr{D}$ of order type $\omega_1$.

**Proof.** ($\Rightarrow$) Assume CH and let $\langle d_\alpha \mid \alpha < \omega_1 \rangle$ be an enumeration of the Turing degrees.

We construct inductively a sequence $\{C_\alpha\}_{\alpha < \omega_1}$ of chains such that

- (1) For each $\beta < \alpha$ there is a $c \in C_\alpha$ with $c \ge d_\beta$;
- (2) $C_\alpha$ has order type $\alpha + \omega$ if $\alpha = 0$ or is a successor ordinal;
- (3) $C_\alpha$ has order type $\alpha \times \omega$ if it is a limit ordinal, and
- (4) $C_\beta \subset C_\alpha$ if $\beta < \alpha$.

Let $C_0 = \{\mathbf{0}\}$. Suppose that $\alpha = \beta + 1$ and $C_\beta$ is defined. Given $d_\beta$, we apply Lemma 8.3.1 to obtain a minimal cover $a$ of $C_\beta$ with $a'' \ge d_\beta$. Relativizing Lemma 9.3.3 yields a maximal chain $\mathbf{a} = \mathbf{a}_0 < \mathbf{a}_1 < \dots < \mathbf{a}_\omega = \mathbf{a}''$ in $[\mathbf{a}, \mathbf{a}'']$. Let $C_\alpha = C_\beta \cup \{\mathbf{a}_\gamma : \gamma \le \omega\}$. For $\alpha$ a limit ordinal, let $C_\alpha = \bigcup_{\gamma < \alpha} C_\gamma$. Let $C = \bigcup_{\alpha < \omega_1} C_\alpha$. It is straightforward to verify that the order type of $C$ is $\omega_1$, $C$ is a maximal chain, and that for each $\alpha < \omega_1$ $(\alpha \times \omega + \omega + 1)$-th element of $C$ bounds $d_\alpha$.

($\Leftarrow$) Since every degree bounds at most countably many degrees, CH follows immediately if there is a maximal chain as described.

## 9.3.2 CH without AC

To continue our tour of the ordering of Turing degrees, we recall some set-theoretic facts. CH is the statement that there is no set $X$ with $|\omega| < |X| < |2^\omega|$, where "$|X| \le |Y|$" means the existence of a surjective map from $Y$ onto $X$. Hence ZF + CH does not obviously imply the existence of a well-ordering of reals. The same is true of GCH with regard to AC. It turns out that there is a link between these two hypotheses.

**Theorem 9.3.5** (Sierpinski [136]). ZF + GCH $\to$ AC.

A question along this line is whether Theorem 9.3.5 holds level by level. For example, does CH imply the existence of a well-ordering of $2^\omega$?

**Theorem 9.3.6** (Kanamori and Pincus [62]). ZFC + “There exists an inaccessible cardinal” is consistent if and only if ZF + CH + “There is no well-ordering of $2^\omega$” is consistent.

Proof. Assume that ZFC + “There exists an inaccessible cardinal” is consistent. By Solovay [150], there is a model $M$ of ZF in which every uncountable set of reals contains a perfect subset. In other words, $M \models$ ZF + CH. Furthermore, there is no well-ordering of the set of reals in $M$.

Conversely, suppose that ZF + CH + “There is no well-ordering of $2^\omega$” is consistent and let $M$ be a transitive model of this theory. We claim that $(\omega_1)^M$ is inaccessible in L. Clearly $(\omega_1)^M$ is regular in L. It is sufficient to prove that for any $\alpha < (\omega_1)^M$, $|(2^\omega)^L| < \omega_1$. If not, there exists a countable $\alpha$ such that $|(2^\omega)^L| = (\omega_1)^M$. Then $(2^\omega)^L \in M$ and there is a well-ordering of $(2^\omega)^L$ in $M$. Since $|\omega| < |(2^\omega)^L| \le |2^\omega|$, we have $|(2^\omega)^L| = |2^\omega|$. In other words, there is a bijection between $(2^\omega)^L$ and $2^\omega$ in $M$. It follows that there is a well-ordering of $2^\omega$ in $M$, which is a contradiction.

Theorem 9.3.6 says that “ZF + CH + There is no well-ordering of $2^\omega$” is such a strong theory that an inaccessible cardinal is required to guarantee its consistency. However, for forcing extensions, one has the following:

**Proposition 9.3.7.** Let $M \models$ ZFC. If $N$ is an extension of $M$ preserving $(\omega_1)^M$ such that $N \models$ ZF+“There is a cofinal chain of Turing degrees”, then $N \models$ $\neg$CH if and only if $N \models$ “There is no well-ordering of $2^\omega$”.

Proof. If $N \models$ “There is a well-ordering of $2^\omega$”, then $N \models$ CH since $N \models$ ZF+“There is a cofinal chain of Turing degrees”.

Now suppose that $N \models$ “There is no well-ordering of $2^\omega$”. Take $C \in M$ to be a subset of $(2^\omega)^M$ such that $<_T$ is a well-ordering of $C$ of order type $(\omega_1)^M$. Since $N$ is an extension of $M$ preserving $(\omega_1)^M$, $N \models |\omega| < |C|$. Since there is no well-ordering of $2^\omega$ in $N$, we have $N \models |C| < |2^\omega|$. So $N \models \neg$CH.

## 9.3.3 Cofinal chains versus CH

Pursuing further the link between CH and Turing degrees, one asks if, under ZF, CH is equivalent to the existence of a cofinal maximal chain of Turing degrees of order type $\omega_1$. The answer is negative: By Solovay [150], there exists a model $M$ of ZF in which every uncountable set of reals contains a perfect subset. Since it is a theorem of ZF that every perfect set contains two reals with incomparable Turing degrees, there is no chain of Turing degrees of order type $\omega_1$.

It is not known if ZF + “There exists a cofinal maximal chain of Turing degrees of order type $\omega_1$” implies CH. However, there is a partial answer:

**Theorem 9.3.8** (Wang, Wu and Yu [168]). If ZFC is consistent, then so is ZF + $\neg$CH + “There exists a cofinal chain in the Turing degrees of order type $\omega_1$”.
