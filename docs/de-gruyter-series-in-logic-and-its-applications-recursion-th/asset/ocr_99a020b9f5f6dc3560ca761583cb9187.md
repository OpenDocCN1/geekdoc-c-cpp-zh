# 11 Basis theorems

In earlier chapters we have seen examples of uncountable sets of reals (e.g. \(\Sigma^1_1\) and certain \(\Pi^1_1\)-sets) that contain perfect subsets. In this chapter we study basis theorems for uncountable sets of reals as well as basis properties of perfect sets.

# 11.1 A basis theorem for \(\Delta^1_1\)-sets of reals

# 11.1.1 Friedman's conjecture

Friedman [29] conjectured that every uncountable \(\Delta^1_1\)-set of reals has a member in each hyperdegree greater than or equal to the hyperdegree of \(\emptyset\). This conjecture was settled by Martin [94] and Friedman independently.

**Theorem 11.1.1** (Martin [94] and Friedman). If \(A \subseteq \omega^\omega\) is an uncountable \(\Delta^1_1\)-set, then there is a perfect tree \(T \subseteq T\) such that \([T] \equiv A\) and for any \(x \ge_h \emptyset\), there is a \(z \in [T]\) with \(z \equiv_h x\).

Suppose that \(A \subseteq \omega^\omega\) is an uncountable \(\Delta^1_1\)-set. By Corollary 2.2.14, there is a recursive function \(h : \omega^\omega \to \omega^\omega\) and a \(\Pi^0_1\)-set \(B \subseteq \omega^\omega\) such that \(h\) maps \(B\) onto \(A\) and is injective on \(B\). Then for every \(x \in B\), \(h(x) \equiv_h x\) and for every \(y \in A\), there exists an \(x \in B\) such that \(x \equiv_h h(x) = y\). Hence it suffices to show that every \(x \ge_h \emptyset\) satisfies \(z \equiv_h x\) for some \(z \in B\). Since \(B\) is a \(\Pi^0_1\)-class, there is a recursive tree \(T \subseteq \omega^{<\omega}\) so that \(B = [T] = \{x \mid (\forall n)(x \upharpoonright n \in T)\}\). We shall prove in the next section a slightly stronger result:

**Theorem 11.1.2.** Every \(\Sigma^1_1\)-tree \(T_1\) with uncountably many infinite paths has a member in each hyperdegree greater than or equal to that of \(\emptyset\).

# 11.1.2 Proof of Friedman's conjecture

We prove Theorem 11.1.2 following [172]. Let \(T_1 \subseteq \omega^{<\omega}\) be a \(\Sigma^1_1\)-tree with a nonhyperarithmetic path. Then there is a \(\Sigma_1(L_{\omega_1^{CK}})\)-enumeration of the nodes of \(\omega^\omega \setminus T_1\). We use \(T_1[\beta]\) to denote the collection of nodes not yet enumerated up to stage \(\beta\). Then \(T_1 = \cap_{\beta < \omega_1^{CK}} T_1[\beta]\). Fix a nonempty recursive tree \(T_0 \subseteq \omega^{<\omega}\) having an infinite path and without a hyperarithmetic infinite path. Let \(f\) be the leftmost path of \(T_0\). Then \(f \equiv_h \emptyset\).

**Lemma 11.1.3.** If \(T_1 \cap [v] = \{ \tau \in T_1 \mid \tau \supseteq v \}\) has no nonhyperarithmetic infinite path, then there is a stage \(\beta < \omega_1^{CK}\) witnessing it. In other words, there is a \(\Sigma_1(L_{\omega_1^{CK}})\) partial function \(H : \omega^{<\omega} \to \{0\}\) such that \(H(\sigma)\) is undefined if and only if \(T_1 \cap [\sigma]\) contains a nonhyperarithmetic infinite path.
