
By the proof of Corollary 4.2.7, we have the following characterization of \(\Delta^1_2\)-reals.

**Corollary 4.2.8.** _A real x is_ \(\Delta^1_2\) _if and only if x is recursive in a_ \(\Pi^1_1\)_-singleton. Hence the set of_ \(\Delta^1_2\)_-reals is_ \(\Sigma^1_2\)_._

**Corollary 4.2.9** (Shoenfield [129])**.** (i) _If_ \(A \subseteq 2^\omega\) _is nonempty and_ \(\Sigma^1_2\)_, then there is an_ \(x \in A \cap L\) _recursive in a_ \(\Pi^1_1\)_-singleton._
(ii) _Every_ \(\Delta^1_2\)_-real is constructible._

_Proof._ (i) If \(A \subseteq 2^\omega\) is a nonempty \(\Sigma^1_2\)-set, then there is a \(\Pi^1_1\)-set \(B \subseteq 2^\omega \times 2^\omega\) such that \(x \in A\) if and only if there exists a _y_ such that _B_(_x_, _y_). By Proposition 4.2.25, there is a \(\Pi^1_1\)-singleton _B_(_x_<sub>0</sub>, _y_<sub>0</sub>). By Corollary 4.1.3, \((x_0, y_0) \in L\). Thus \(x_0 \in A\) is a constructible real recursive in the \(\Pi^1_1\)-singleton \(x_0 \oplus y_0\).
(ii) Immediate from (i), since every \(\Delta^1_2\)-real is a \(\Sigma^1_2\)-singleton. \(\square\)

Corollary 4.2.9 (i) is known in the literature as the _Shoenfield Absoluteness Lemma_. There are many applications of this in set theory. For example, given a \(\Sigma^1_2\)-predicate _P_, one has \((L, \varepsilon) \models P\) if and only if \(\langle V, \varepsilon \rangle \models P\).

## 4.3 Characterizing thin \(\Pi^1_1\)-sets

A set is _thin_ if it contains no perfect subset. There is a beautiful characterization of \(\Pi^1_1\)-thin sets in terms of constructibility.

### 4.3.1 The largest thin \(\Pi^1_1\)-set

Let \(\mathbb{C} = \{x \mid x \in L_{\omega_1}\}\).

**Lemma 4.3.1.** \(\mathbb{C}\) _is a thin_ \(\Pi^1_1\)_-set._

_Proof._ \(x \in L_{\omega_1}\) if and only if \((L_{\omega_1}[x], \in) \models (\exists \beta)(x \in L_\beta)\). By Theorem 3.3.2 and Corollary 3.7.2, C is \(\Pi^1_1\). Suppose \(\mathcal{C}\) is not thin. Let

\(B = \{T \in 2^{<\omega} \mid T \text{ is a perfect tree in which every infinite path belongs to } \mathcal{C}\}.\)

Then \(B\) is a \(\Pi^1_1\)-set. By Theorem 4.1.2, there is a \(T \in B\) with \(T \in L_{\omega_1}\). By relativizing the Gandy Basis Theorem (2.5.3) to \(T\), there is a real \(x \in [T] \subseteq \mathcal{C}\) such that \(x \not\le_h T\) and \(\omega_1^x \le \omega_1^{x \oplus T} = \omega_1^T\). Hence \(x \notin L_{\omega_1}\), a contradiction.

**Lemma 4.3.2** (Mansfield [87], Solovay [149]). Let \(A \subseteq 2^\omega\) be \(\Pi^1_1\). If there is an \(x \in A\) such that \(x \notin L_{\omega_1}\), then there is a perfect tree \(T \in L\) all of whose infinite paths belong to \(A\).

**Proof.** Let \(\mathcal{C}\) be defined as before. Suppose \(A \subseteq 2^\omega\) is \(\Pi^1_1\) and there is an \(x \in A \setminus \mathcal{C}\). Let \(\alpha_0\) be the least ordinal \(\alpha\) such that \(\alpha = \alpha_1^x\) for some \(x \in A \setminus \mathcal{C}\).

Let \(T_0\) be a tree presentation of \(A\) and \(T_0^\alpha\) be defined as in the proof of Theorem 4.1.2. Since \(\mathcal{C}\) is a \(\Pi^1_1\)-set, there is a recursive tree \(T_1 \subseteq 2^{<\omega} \times \omega^{<\omega}\) such that \(x \notin \mathcal{C}\) if and only if \((\exists y)((x, y) \in [T_1])\). Now let \(T_2 \subseteq 2^{<\omega} \times \omega^{<\omega} \times 2^{<\omega}\) be a tree defined as follows: \((\sigma, p, \tau) \in T_2\) if and only if \((\sigma, p) \in T_0^\alpha\) and \((\sigma, \tau) \in T_1\). By assumption, there is an infinite path \((x, f, y)\) in \(T_2\).

We claim that for any \((\sigma, p, \tau) \in T_2\), if there is an infinite path in \(T_{2, (\sigma, p, \tau)} = \{(\sigma', p', \tau') \in T_2 \mid (\sigma', p', \tau') \succ (\sigma, p, \tau)\}\), then there are \((\sigma_0, p_0, \tau_0)\) and \((\sigma_1, p_1, \tau_1)\) in \(T_{2, (\sigma, p, \tau)}\), with \(\sigma_0\) and \(\sigma_1\) incompatible, such that both \(T_{2, (\sigma_0, p_0, \tau_0)}\) and \(T_{2, (\sigma_1, p_1, \tau_1)}\) have infinite paths. Otherwise, fix a \((\sigma, p, \tau) \in T_2\) for which this is false. Then there is an infinite path \((x, f, y)\) in \(T_{2, (\sigma, p, \tau)}\). Note that \(\omega_1^x \ge \alpha_0\). By assumption, for any \(\sigma' \succ \sigma\) that is not an initial segment of \(x\), the tree

\(T_{2, \sigma'} = \{(\sigma'', p'', \tau'') \in T_{2, (\sigma, p, \tau)} \mid \sigma' \succ \sigma\}\)

is wellfounded. Then by the same proof as that of Theorem 4.1.2, there is a \(\gamma < \omega_1^x\) such that the set \(\{\sigma' \mid (\exists \sigma'', p'', \tau'') \in T_{2, (\sigma, p, \tau)}\, \sigma' \subseteq \sigma''\}\) belongs to \(L_\gamma\). Then \(x \in L_{\gamma+1} \subseteq L_{\omega_1}\), contradicting the fact that \(x \notin \mathcal{C}\).

By the claim, one may carry out the first construction of Theorem 1.1.10 to obtain a perfect tree all of whose paths belong to \(A\). Thus the set \(\{T \mid T \text{ is perfect and } [T] \subseteq A\}\) is a nonempty \(\Pi^1_1\)-set. By Theorem 4.1.2, there is a perfect tree \(T \in L\) such that \([T] \subseteq A\).

By Lemma 4.3.1 and Lemma 4.3.2, we have the following characterization of the largest thin \(\Pi^1_1\)-set.

**Theorem 4.3.3.** \(\mathcal{C}\) is the largest thin \(\Pi^1_1\)-set.

### 4.3.2 Some properties of \(\mathcal{C}\)

Since every \(\Pi^1_1\)-set of reals contains an \(x \in \mathcal{C}\) that is also a \(\Pi^1_1\)-singleton, one may ask if every real in \(\mathcal{C}\) is a \(\Pi^1_1\)-singleton. This is false since \(\mathcal{C}\) is uncountable in \(L\).

**Proposition 4.3.4.** For any real \(x \in L\), there is a \(z \in \mathbb{C}\) such that \(z \geq_T x\).

Proof. Let \(x \in L\). By Corollary 3.3.8, \(x \in L_{a+1} \setminus L_a\) for some \(a < (\omega_1)^L\). Then \(x\) is \(\Sigma_n(L_{a+1})\) for some \(n\). By Theorem 3.4.11, there is a real \(z \in L_{a+1} \setminus L_a\) which is a \(\Sigma_n\)-master code. Thus \(\rho_a^L = \omega\). By the definition of \(\Sigma_n\)-master code, there is a \(z\)-recursive well-ordering of \(a\). In other words, \(\omega_1^x > a\). Thus \(z \in L_{\omega_1^x}\) and \(x \leq_T z\).

**Proposition 4.3.5.** There is an \(x \in \mathbb{C}\) in which every \(\Pi^1_1\)-singleton is recursive.

Proof. By Proposition 4.1.3, every \(\Pi^1_1\)-singleton is in \(L\). Since \((L, \in) \vDash \text{ZFC}\), the statement "there are only countably many \(\Pi^1_1\)-singletons" is true in \(L\). Hence there is a real \(y \in L\) in which every \(\Pi^1_1\)-singleton in \(L\) is recursive. By Proposition 4.3.4, \(y \leq_T z\) for some \(z \in \mathbb{C}\).

**Corollary 4.3.6.** (i) \(\mathbb{C}\) is the largest countable \(\Pi^1_1\)-set of reals if and only if \((\omega_1)^L < \omega_1\). (ii) There is an uncountable thin \(\Pi^1_1\)-set if and only if \((\omega_1)^L = \omega_1\).

Proof. (i) By Proposition 4.3.4, if \(\mathbb{C}\) is countable, then \(L \cap 2^\omega\) is countable. So \((\omega_1)^L\) is countable. Suppose that \((\omega_1)^L\) is countable. Then by Proposition 4.3.2, every \(\Pi^1_1\)-countable set of reals is a subset of \(\mathbb{C}\). By Corollary 3.3.8, \(\mathbb{C}\) is countable. (ii) follows from (i).

## 4.4 \(\Sigma^1_2\)-sets

\(\Sigma^1_2\)-sets and \(\Pi^1_2\)-sets of reals are similar in several respects. We list some of them here.

**Corollary 4.4.1.** \(2^\omega \cap L\) is \(\Sigma^1_2\).

Proof. By Proposition 4.3.4, \(x \in L\) if and only if there is a \(y \in \mathbb{C}\) such that \(y \geq_T x\).

**Proposition 4.4.2.** \(x \leq_L y\) is a \(\Sigma^1_2\)-relation.

Proof. \(x \leq_L y\) if and only if \(x, y \in L\) and there is a binary relation \(E \subseteq \omega\) such that

- \((\omega, E)\) is wellfounded;
- \((\omega, E) \models V = L + \text{KP}\);
- \((\omega, E) \models x \leq_L y\).

Thus the relation \(x \leq_L y\) is \(\Sigma^1_2\).
