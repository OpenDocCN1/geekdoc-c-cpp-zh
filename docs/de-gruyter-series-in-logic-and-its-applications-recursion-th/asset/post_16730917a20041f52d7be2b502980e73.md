
The following is an analog of the Spector–Gandy Theorem for \(\Sigma^1_2\)-sets.

### Proposition 4.4.3.
A set \(A \subseteq 2^\omega\) is \(\Sigma^1_2\) if and only if there is a \(\Sigma_1\)-formula \(\varphi\) such that

\[
x \in A \Leftrightarrow \langle L[x], \in \rangle \vDash \varphi \Leftrightarrow \langle L_{(\omega_1)^x}[x], \in \rangle \vDash \varphi.
\]

Proof. Suppose that \(A \subseteq 2^\omega\) is \(\Sigma^1_2\). Then there is a \(\Pi^1_1\)-relation \(B \subseteq 2^\omega \times 2^\omega\) such that

\[
x \in A \Leftrightarrow (\exists y) B(x, y).
\]

By Corollary 3.7.2, there is a \(\Sigma_1\)-formula \(\psi\) such that

\[
B(x, y) \Leftrightarrow \langle L_{(\omega_1)^x}[x, y], \in \rangle \vDash \psi.
\]

Since for every \(x\), \(B_x = \{y \mid B(x, y)\}\) is \(\Pi^1_1(x)\), by relativizing Theorem 4.1.2 there is a \(y \in B_x\) such that \(y \in L_{(\omega_1)^x}[x]\).

Hence

\[
x \in A \Leftrightarrow (\exists y)(y \in L_{(\omega_1)^x}[x] \land \langle L_{(\omega_1)^x}[x], \in \rangle \vDash \psi).
\]

Now let \(\varphi\) be

\[
(\exists \beta)(\exists \alpha > \omega)(\alpha \text{ is the least admissible ordinal such that}
\]

\[
y \in L_\alpha[x] \land \langle L_\alpha[x], \in \rangle \vDash \psi).
\]

By Theorem 3.3.2, \(\varphi\) is \(\Sigma_1\). By the discussion above, \(x \in A\) if and only if \(\langle L[x], \in \rangle \vDash \varphi\) if and only if \(\langle L_{(\omega_1)^x}[x], \in \rangle \vDash \varphi\).

For the other direction, suppose there is a \(\Sigma_1\)-formula \(\varphi\) such that \(x \in A \Leftrightarrow \langle L[x], \in \rangle \vDash \varphi\). Then for each \(x\), there is a cardinal \(\alpha\) such that \(x \in A \Leftrightarrow \langle L_\alpha[x], \in \rangle \vDash \varphi\).

By the Condensation Theorem (3.3.7), there is a countable admissible ordinal \(\alpha\) such that \(x \in A \Leftrightarrow \langle L_\alpha[x], \in \rangle \vDash \varphi\). Since \(\varphi\) is \(\Sigma_1\), we have \(x \in A \Leftrightarrow \langle L[x], \in \rangle \vDash \varphi \Leftrightarrow \langle L_{(\omega_1)^x}[x], \in \rangle \vDash \varphi\).

By Theorem 3.3.4, \(\langle L_{(\omega_1)^x}[x], \in \rangle \vDash \varphi\) if and only if there is a countable transitive wellfounded model \(\langle M, \in \rangle \vDash \text{KP} + \text{“}V = L[x]\text{”} + \varphi\). Hence \(\langle L_{(\omega_1)^x}[x], \in \rangle \vDash \varphi\) if and only if

\[
(\exists E)(\langle \omega, E \rangle \text{ codes a wellfounded transitive model } \land \langle \omega, E \rangle \vDash \text{KP} + \text{“}V = L[x]\text{”} + \varphi).
\]

By Proposition 3.6.2, the set \(\{x \mid \langle L_{(\omega_1)^x}[x], \in \rangle \vDash \varphi\} = \{x \mid \langle L[x], \in \rangle \vDash \varphi\}\) is \(\Sigma^1_2\).

Thus one may regard \(L_{\omega_1}\) as the structure where \(\Sigma^1_2\)-sets are based. In a way, \(\Sigma^1_2\)-ness draws the boundary between recursion theory and set theory. Within ZFC, it is not possible to generalize results in the previous sections to a level beyond \(\Sigma^1_2\). One needs additional set-theoretic assumptions for this. How this is to be implemented is a major subject in descriptive set theory. From this perspective, higher recursion theory serves as a launch pad for the study of descriptive set theory beyond the level of \(\Sigma^1_2\). Let

\[
\delta^1_2 = \text{supremum of the } \Delta^1_2 \text{ well-orderings of } \omega,
\]

and

\[
\delta = \min\{\alpha \mid L \setminus L_\alpha \text{ contains no } \Pi^1_1\text{-singleton}\}.
\]

### Proposition 4.4.4. \(\delta = \delta^1_2\).

Proof. If \(\alpha < \delta\), then there is a \(\Pi^1_1\)-singleton \(x \in L_\delta \setminus L_\alpha\). Since \(x \in L_{\omega_1^x}\) and \(\omega_1^x\) is a \(\Pi^1_1(x)\) well-ordering, \(\alpha < \omega_1^x < \delta^1_2\). Hence \(\delta \le \delta^1_2\).

If \(\alpha < \delta^1_2\), then there is a \(\Delta^1_2\) well-ordering relation \(R \subseteq \omega \times \omega\) of order type \(\alpha\). Then there exist arithmetical relations \(S, T \subseteq (\omega^\omega)^2 \times \omega^2\) such that

\[
R(n, m) \Leftrightarrow (\exists f)(\forall g)S(f, g, n, m),
\]

and

\[
\neg R(n, m) \Leftrightarrow (\exists f)(\forall g)T(f, g, n, m).
\]

Define \(\Pi^1_1\)-sets

\[
R_0 = \{\langle h, (n, m) \rangle \mid h(0) = 0 \land (\exists f)(\forall g)(S(f, g, n, m) \land (\forall n)(f(n) = h(n+1)))\}.
\]

and

\[
R_1 = \{\langle h, (n, m) \rangle \mid h(0) = 1 \land (\exists f)(\forall g)(T(f, g, n, m) \land (\forall n)(f(n) = h(n+1)))\}.
\]

By the \(\Pi^1_1\)-Uniformization Theorem (4.2.1), the two relations may be unified by partial \(\Pi^1_1\)-functions \(p_{R_0}\) and \(p_{R_1} : \omega \to \omega^\omega\). Let \(p = p_{R_0} \cup p_{R_1}\). Then \(p\) is a total \(\Pi^1_1\)-function and may be viewed as a \(\Pi^1_1\)-singleton. Then \(R\) is arithmetical in \(p\) and hence \(\alpha < \omega_1^p < \delta\). Thus \(\delta^1_2 = \delta\).

This gives a finer version of the Spector–Gandy Theorem for \(\Sigma^1_2\)-sets:

### Proposition 4.4.5. A real \(x\) is \(\Sigma^1_2\) if and only if \(x\) is \(\Sigma_1\)-definable over \(\langle L_{\delta^1_2}, \in \rangle\).

Proof. Suppose that \(x\) is \(\Sigma^1_2\). Then there is a \(\Sigma_0\)-formula \(\varphi(n, y)\) such that

\[
n \in x \Leftrightarrow (\exists y)(\langle L_{\delta^1_2}[y], \in \rangle \vDash \varphi(n, s, y)).
\]

By Corollary 4.2.9 and Proposition 4.4.4, we have

\[
n \in x \Leftrightarrow \langle L_{\delta^1_2}, \in \rangle \vDash (\exists s)(\exists y)[s \in L_{\omega_1^y}[y] \land \varphi(n, s, y)].
\]

Assume \(\langle L_{\delta^1_2}, \in \rangle \vDash (\exists s)(\exists y)[s \in L_{\omega_1^y}[y] \land \varphi(n, s, y)]\) and fix such a real \(y\). Then \(\langle L_{\omega_1^y}[y], \in \rangle \vDash (\exists s)\varphi(n, s, y)\). Hence \(n \in x\). Thus \(x\) is \(\Sigma_1\)-definable over \(\langle L_{\delta^1_2}, \in \rangle\).

Conversely, suppose that \(x\) is \(\Sigma_1\)-definable over \(\langle L_{\delta^1_2}, \in \rangle\) via the formula \(\varphi(n)\). By Proposition 4.4.4, we have \(n \in x\) if and only if there exists a \(z \in L_{\omega_1^x}\) such that \(\langle L_{\omega_1^x}[x], \in \rangle \vDash \varphi(n)\). Thus \(x\) is \(\Sigma^1_2\).

It is possible to relativize "$\Delta^1_2$-ness" in the obvious way and define the relation "$x$ is $\Delta^1_2$" in $y$ and thereby introduce the notion of a $\Delta^1_2$-degree. Let \(\delta^{1,x}_2\) be the supremum of all well-orderings of \(\omega\) that are \(\Delta^1_2\) in \(x\). The following result says in a strong way that Post's problem has a negative solution for the \(\Delta^1_2\)-degrees.

### Proposition 4.4.6.

- (i) If \(x\) is constructible and not \(\Delta^1_2\), then \(\delta^{1,x}_2 > \delta^1_2\).
- (ii) Assume \(V = L\). Then \(\le_{\Delta^1_2}\) is a well-ordering of the \(\Delta^1_2\)-degrees and its order type is \(\omega_1\). Moreover, if \(x <_{\Delta^1_2} y\), then \(\delta^{1,x}_2 < \delta^{1,y}_2\).

Proof. (i) Let \(A = \{r \mid r \text{ codes a well-ordering of } \omega \land x \in L_{|r|}\}\), where \(|r|\) denotes the order type of \(r\) as a well-ordering. Then \(A\) is \(\Delta^1_2(x)\). Let \(r \in A\). Since \(x\) is not \(\Delta^1_2\) we must have \(|r| > \delta^1_2\). Hence \(\delta^{1,x}_2 > \delta^1_2\).

(ii) If \(V = L\), then by Proposition 4.4.2, \(\le_L\) is a \(\Delta^1_2\) well-ordering of the reals. Suppose that \(x \le_L y\). Then by the proof of (i), there is a \(\Delta^1_2(y)\)-real \(r\) coding a well-ordering of \(\omega\) such that \(y \in L_{|r|}\) and so \(x \in L_{|r|}\). Then \(x \in L_{\omega_1^x}\) and hence \(x \le_{\Delta^1_2} y\). Thus \(x \le_{\Delta^1_2} y\). So \(\le_{\Delta^1_2}\) is a well-ordering of \(\Delta^1_2\)-degrees and its order type is \(\omega_1\). If \(x <_{\Delta^1_2} y\), then by the same argument as that in (i) but relativized to \(y\), we have \(\delta^{1,x}_2 < \delta^{1,y}_2\).

Proposition 4.4.6 indicates that while \(L\) is an appropriate ground model for hyperarithmetic theory, it is less so for a \(\Delta^1_2\)-theory as the well-ordering of the \(\le_{\Delta^1_2}\) relation makes the structure of the corresponding degrees relatively simple and hence less interesting.
