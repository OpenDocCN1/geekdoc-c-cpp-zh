# 4.2 $\Pi^1_1$-uniformization

# 4.2.1 Uniformizing $\Pi^1_1$-relations

Given a relation $R \subseteq 2^\omega \times 2^\omega$, a relation $R_0$ is a uniformization of $R$ if for any x and y, $R_0(x, y)$ implies $R(x, y)$ and for any x, if there is a y such that $R(x, y)$, then there is a unique y such that $R_0(x, y)$. Uniformization of R is in effect a choice function for R.

THEOREM 4.2.1 (Kondo [74] and Addison [1]). Suppose that $R \subseteq 2^\omega \times 2^\omega$ is $\Pi^1_1$. Then there is a $\Pi^1_1$-relation $R_0$ that uniformizes R.

Proof. Suppose that $R \subseteq 2^\omega \times 2^\omega$ is $\Pi^1_1$. By Corollary 3.7.2, there is a $\Sigma_0$-formula $\varphi(u, v, w)$ such that

$(x, y) \in R \leftrightarrow (L_{\omega_1^{xy}}[x \oplus y], \in) \models (\exists w)\varphi(x, y, w).$

+   Define $R_0 \subseteq 2^\omega \times 2^\omega$ so that $(x, y) \in R_0$ if and only if
+   (i) $y \in L_{\omega_1^{xy}}[x]$;
+   (ii) $(\exists w \in L_{\omega_1^{xy}}[x])((L_{\omega_1^{xy}}[x], \in) \models \varphi(x, y, w))$; and
+   (iii) $(\forall w'_{\omega_1^{xy}}[x], \in) \models (\forall z \forall w')(w' <_{L[x]} (y, w) \rightarrow \neg\varphi(x, z, w'))$.

By Theorem 4.1.2, if there is a y such that $(x, y) \in R$, then there is one such that $R_0(x, y)$. By the definition of $R_0$, $R_0$ uniformizes R. Note that both (i) and (ii) above are $\Sigma_1$-statements. By Proposition 3.3.3, (iii) is also a $\Sigma_1$-statement. By Corollary 3.7.2, $R_0$ is a $\Pi^1_1$-relation.

There are a number of interesting applications of the $\Pi^1_1$ Uniformization Theorem (4.2.1) which we now discuss:

PROPOSITION 4.2.2. Given $\Pi^1_1$-sets $A_0$ and $B_0$, there exist disjoint $\Pi^1_1$-sets $A_1 \subseteq A_0, B_1 \subseteq B_0$ such that $A_0 \cup B_0 = A_1 \cup B_1$.

Proof. Let $R \subseteq 2^\omega \times 2^\omega$ be a $\Pi^1_1$-relation such that $(x, i) \in R$ if and only if either $i = 0$ and $x \in A_0$ or $i = 1$ and $x \in B_0$. By Theorem 4.2.1, there is a $\Pi^1_1$-relation $R_0$ uniformizing R. Define $x \in A_1$ if and only if $(x, 0) \in R_0$ and $x \in B_1$ if and only if $(x, 1) \in R_0$. Then $A_1, B_1$ are as required.

COROLLARY 4.2.3. Given disjoint $\Sigma^1_1$-sets $A_0, B_0$, there exist disjoint $\Delta^1_1$-sets $A_1, B_1$ such that $A_0 \subseteq A_1, B_0 \subseteq B_1$ and $A_1 \cup B_1 = 2^\omega$.

Proof. The hypothesis implies that $2^\omega \setminus A_0$ and $2^\omega \setminus B_0$ are $\Pi^1_1$. By Proposition 4.2.2, there exist two $\Pi^1_1$-sets $A_1 \supseteq B_0, B_1 \supseteq A_0$ such that $A_1$ and $B_1$ are disjoint and $A_1 \cup B_1 = 2^\omega$. Hence these sets are $\Delta^1_1$.
