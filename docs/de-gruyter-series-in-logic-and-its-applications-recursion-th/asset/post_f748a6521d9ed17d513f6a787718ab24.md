We now describe the construction of $x_0$ and $x_1$, and the associated strings in detail. For $i \le 1$ and $\sigma, \tau \in T_i$, let $T_i(\sigma, \tau)$ be the set of strings in $T_i$ compatible with $\sigma$ and $\tau$, i.e.

$$T_i(\sigma, \tau) = \{ \langle \sigma', \tau' \rangle \in T_i \mid \exists (\sigma'', \tau'') \in T_i (\sigma' \preceq \sigma'' \wedge \tau' \preceq \tau'' \wedge \sigma \preceq \sigma'' \wedge \tau \preceq \tau'') \}.$$

Note that it is unnecessary that $|\sigma| = |\tau|$ in the definition above.

We say that a string (or node) $\sigma^* \in 2^{<\omega}$ is splitting over $(\sigma, \tau)$ in $T_i$ if $\sigma^* \succeq \sigma$ and for $j \le 1$,

$$T_{i, \sigma^* \frown j}(\sigma, \tau) = \{ \langle \sigma', \tau' \rangle \mid \sigma' \succeq \sigma^* \frown j \wedge \tau' \succeq \tau \wedge \langle \sigma', \tau' \rangle \in T_i \}$$

contains an infinite path. Note that $\sigma^*$ does not lie on $T_i$ but some pair $(\sigma^*, \tau^*)$ does and we call $(\sigma^*, \tau^*)$ a splitting node on $T_i$.

For each $i \le 1$, we construct a sequence $(\sigma_{i,0}, \tau_{i,0}) < (\sigma_{i,1}, \tau_{i,1}) < \cdots$ on $T_i$ and let $x_i = \bigcup_j \sigma_{i,j}$. Again, the idea is to apply a “mutual coding” technique so that $x_0$ codes the leftmost witness function $f_1 = \cup_s r_{1,s}$ (in the $\Sigma^1_1$-definition) for $x_1$ and $x_1$ codes the leftmost witness function $f_0 = \cup_s r_{0,s}$ for $x_0$. In addition, we also assign $x_0$ the responsibility of coding $z$ as well as $f_0$. More precisely, for each $s \in \omega$ we use $\sigma_{0,s}$ to code $z(s)$, $f_0(s)$ and $\tau_{1,s-1}$, and use $\sigma_{1,s}$ to code $\tau_{0,s}$.

At stage 0, let $(\sigma_{i,0}, \tau_{i,0}) = (\emptyset, 0)$ for $i \le 1$. Without loss of generality, assume that $(\emptyset, \emptyset)$ is a splitting node in both $T_0$ and $T_1$.

The construction at stage $s+1$ proceeds as follows:

### Substage (i)

First let $\sigma^*$ be the shortest splitting node over $(\sigma_{0,s}, \tau_{0,s})$ in $T_0$. Thus $T_{0, \sigma^* \frown j}(\sigma_{0,s}, \tau_{0,s})$ contains an infinite path for $j \le 1$. Let $\sigma^0_{0,s+1}$ be the leftmost splitting node over $(\sigma_{0,s}, \tau_{0,s})$ extending $\sigma^* \frown z(s)$ in $T_0$. Thus $z(s)$ is coded here. Next we code $r_{1,s}$. Let $n^*_{s+1} = |\text{Dom}(r_{1,s})|$ (let $|\text{Dom}(r_{1,s-1})| = 0$ if $s=0$). Inductively, for any $k \in \{1, n^*_{s+1}\}$, let $\sigma^k_{0,s+1}$ be the leftmost splitting node over $(\sigma_{0,s}, \tau_{0,s})$ extending $(\sigma^{k-1}_{0,s+1}) \frown 1$ in $T_0$ so that there are $r_{1,s}(k + |\text{Dom}(r_{1,s-1})|)$-many splitting nodes over $(\sigma_{0,s}, \tau_{0,s})$ in $T_0$ between $\sigma^{k-1}_{0,s+1}$ and $\sigma^k_{0,s+1}$. This completes the coding of $r_{1,s}$. To code $f_0(s)$, let $\sigma^{n^*_{s+1}+1}_{0,s+1}$ be the leftmost splitting node extending $(\sigma^{n^*_{s+1}}_{0,s+1}) \frown 1$ over $(\sigma_{0,s}, \tau_{0,s})$ in $T_0$ so that there are $f_0(s)$-many splitting nodes in $T_0$ over $(\sigma_{0,s}, \tau_{0,s})$ between $\sigma^{n^*_{s+1}}_{0,s+1}$ and $\sigma^{n^*_{s+1}+1}_{0,s+1}$. For $j \le 1$, let $\sigma^{n^*_{s+1}+j+1}_{0,s+1}$ be the next splitting node in $T_0$ over $(\sigma_{0,s}, \tau_{0,s})$ extending $(\sigma^{n^*_{s+1}+j}_{0,s+1}) \frown 1$. This coding tells us that the action at this substage for the “$x_0$ side” is completed. Define $\sigma_{0,s+1} = \sigma^{n^*_{s+1}+3}_{0,s+1}$. Let $\tau_{0,s+1}$ extend $\tau_{0,s}$ so that $|\text{Dom}(\tau_{0,s+1})| = |\sigma_{0,s+1}|$ and $\tau_{0,s+1}$ is the leftmost node such that the tree $T_0(\sigma_{0,s+1}, \tau_{0,s+1})$ has an infinite path.

### Remark

At stage $s+1$, the coding of $x_0$ in $T_0$ by way of $\sigma_{0,s+1}$ applies the method of the proof of 11.11, treating the $\Sigma^1_1$-set $A_0$ as a “closed set”. This means that one first ignores the second component (the “r side”) and applies the coding construction in the proof of Theorem 11.1.1 to the closed set $X_{\sigma_{0,s}, \tau_{0,s}} = \{x \supset \sigma_{0,s} \mid \forall n > |\tau_{0,s}| \exists y \supset \tau_{0,s} (x \upharpoonright n = y \upharpoonright n \forall f \in T([0]))\}$. Once the coding of $\sigma_{0,s+1}$ (an initial segment of $x_0$) is completed, one pair fits with a finite string $\tau$ which has an infinite extension to guarantee that $x_0$ belongs to $A_0$. Since $x_0$ does not know the right $\tau$ to select, $x_1$ is designed to help decode the correct $\tau$. The mutual coding strategy is crucial for this purpose.

### Substage (ii)

Let $\sigma^0_{1,s+1} = \sigma_{1,s}$ and $n^1_{s+1} = |\text{Dom}(\tau_{0,s+1})| - |\text{Dom}(\tau_{0,s})|$. Inductively for any $k \in [1, n^1_{s+1}]$, let $\sigma^k_{1,s+1}$ be the leftmost splitting node over $(\sigma_{1,s}, \tau_{1,s})$ extending $(\sigma^{k-1}_{1,s+1}) \frown 1$ so that in $T_1$ there are $\sigma_{0,s+1}(k + |\text{Dom}(\tau_{0,s})|)$-many splitting nodes over $(\sigma_{1,s}, \tau_{1,s})$ between $\sigma^{k-1}_{1,s+1}$ and $\sigma^k_{1,s+1}$. Hence $\sigma_{0,s+1}$ is coded. For $j \le 1$, let $\sigma^{n^1_{s+1}+j+1}_{1,s+1}$ be the next splitting node over $(\sigma_{1,s}, \tau_{1,s})$ in $T_1$ extending $(\sigma^{n^1_{s+1}+j}_{1,s+1}) \frown 1$. This coding tells us that the action of coding $\tau_{0,s+1}$ at this substage for the “$x_1$ side” is completed. Define $\sigma_{1,s+1} = \sigma^{n^2_{1,s+1}}_{1,s+1}$. Thus we have coded $\tau_{0,s+1}$ into $\sigma_{1,s+1}$. Let $\tau_{1,s+1}$ extend $\tau_{1,s}$ so that $|\text{Dom}(\tau_{1,s+1})| = |\sigma_{1,s+1}|$ and $\tau_{1,s+1}$ is the leftmost finite string such that the tree $T_1(\sigma_{1,s+1}, \tau_{1,s+1})$ has an infinite path.

This ends the construction at stage $s+1$.

Let $x_i = \bigcup_{s<\omega} \sigma_{i,s}$ for $i \le 1$. Note that the construction is carried out over $L_{\omega_1^{CK}-1}[z]$ since $\emptyset \in L_{\omega_1^{CK}+1}$, and whether $(\sigma, \tau) \in T_i$ has an infinite path extension in $T_i$ is decided by stage $L_{\omega_1^{CK}+1}^z$. As $z \ge_h \emptyset$ we have $a_i^X > \omega_1^{CK}$ and so $z \ge_h x_0 \bowtie x_1$.

We now use $x_0$ and $x_1$ to decode the coding construction and hence hyperarithmetically recover $\emptyset$ and $z$ from $x_0 \bowtie x_1$. The decoding is achieved via a finite injury method similar to that used in the proof of Theorem 11.1.1. However, a correct decoding requires use of the witness functions $f_0$ and $f_1$. Without these witness functions, $x_0$ would still code $z$ and would belong to the closure of $A_0$. The entire construction is then reduced to that in the proof of Martin’s theorem 11.1.1. However, in this case one cannot conclude that $x_0$ belongs to $A_0$. This difficulty is resolved by a procedure of mutual coding, in which $x_0$ also codes $f_1$ and $x_1$ codes $f_0$. The coding of $z$ is woven into the mutual coding strategy in the course of the construction.

We now point out the key decoding steps and leave the details to the reader. As in the proof of Theorem 11.1.1, we may fix a $\Sigma_1$-enumeration $\{T_i[a]\}_{i \le 2, a \in \omega_1^{CK}}$ over $L_{\omega_1^{CK}}$ such that for $i \le 2$,

- $T_i[0] = T_i$
- $T_i[a] \le T_i[\beta]$ if $a \le \beta$
- $T_i[\langle \omega^a \rangle] = \langle \text{acc}_\omega^{X_i} T_i[a] \rangle$
- $T_i[\omega_1^{CK}]$ has no dead end nodes, and
- $A_i = \{x \mid \exists \forall n (x \upharpoonright n, f \upharpoonright n) \in T_i[\omega_1^{CK}]\}$.

Since $[T_i]$ does not contain a hyperarithmetic infinite path, we have $[T_i[\omega_1^{CK}]] = [T_i]$ to be a perfect tree (which as noted earlier enabled the coding procedure to be implemented). Clearly $(x_i, f_i)$ is an infinite path in $T_i[a]$ for each $a$. As was the case for $T_i, i \le 1$, for each $a < \omega_1^{CK}$ one may define the notion of a string $\sigma'$ being a splitting node over $(\sigma, \tau)$ in $T_i[a]$. In particular, for $(\sigma, \tau) \in T_i[a]$ such that $\sigma \prec x_i$, it makes sense to say that $x_i \upharpoonright n$ splits over $(\sigma, \tau)$ in $T_i[a]$. This means that there are strings $\tau'_0, \tau'_1 \supseteq \tau$ such that $(x_i \upharpoonright n \frown 0, \tau'_0), (x_i \upharpoonright n \frown 1, \tau'_1) \in T_i[a]$. In this case we also say that $x_i \upharpoonright n$ is a *locally splitting node* over $(\sigma, \tau)$ in $T_i[a]$. Here “locally” refers to the fact that there is no guarantee that $(x_i \upharpoonright n \frown j, \tau'_j)$ has an infinite extension in $T_i[a]$ for $j=0, 1$.

Since for each $i \le 1$ and $a < \omega_1^{CK}$, $(x_i, f_i)$ is a path on $T_i[a]$, one may use $x_0 \oplus x_1$ to approximate the values of $f_0(s)$ and $f_1(s)$ by simulating in $T_i[a]$ the construction of $x_i$. This is achieved by attempting to retrieve the sequences $\langle \langle \sigma_{i,s}, \tau_{i,s} \rangle \rangle_{s \le \omega}$, $i \le 1$, using $x_0 \oplus x_1$. Of course, since it is yet to be established that $z$ and $f_0$ are hyperarithmetic in $x_0 \oplus x_1$, the retrieval is only by way of approximating the original construction. Using $x_0 \oplus x_1$, one may mimic the construction of $\langle \langle \sigma_{i,s}, \tau_{i,s} \rangle \rangle_{s \le \omega}$ to define $\langle \langle \sigma_{i,s+1}[a], \tau_{i,s}[a] \rangle \rangle_{s \le \omega}$ for $i \le 1$, so that $\sigma_{i,s+1}[a]$ is an initial segment of $x_i$ (in ascending order of length) and a local splitting node over $\langle \sigma_{i,s}[a], \tau_{i,s}[a] \rangle$ in $T_i[a]$. Furthermore, for each $i$, $\tau_{i,s+1}[a]$ is an approximation of $f_i \upharpoonright s$ at stage $a$. In other words, $\tau_{i,s+1}[a]$ is the leftmost finite string so that $\langle \sigma_{i,s+1}[a], \tau_{i,s+1}[a] \rangle \in T_i[a]((\sigma_{i,s}, \tau_{i,s}))$.

Note that for each $n$ and $a < a' < \omega_1^{CK}$, the number of splitting nodes along $(x_i \upharpoonright n, f_i \upharpoonright n)$ in $T_i[a]$ is greater than or equal to that in $T_i[a']$.

One may use $T_2[a]$ to define a $\Sigma_1(L_{\omega_1^{CK}})$-approximation $f_0^a$ of $f_0$ “from the left”: $f_0^a(0)[a] \frown \cdots \frown f_0^a(n)[a]$ is the leftmost string in $T_2[a]$ (it is possible that there exist only finitely many such $n$’s). Then for $a < \omega_1^{CK}$, $f_0^a(0)[a] = f_0(0)$. Suppose $n > 0$ and $f_0^a(m)[a] = f_0(m)$ for all $m < n$. Then $f_0^a(n)[a] \le f_0(n)$, and $\lim_{a \to \omega_1^{CK}} f_0^a(n)[a] = f_0(n)$. The algorithm we adopt for decoding proceeds as follows. Construct a sequence of ordinals $\langle \alpha_s \rangle_{s \le \omega}$ which is $\Delta_1$-definable in $L_{\omega_1^{CK}}[x_0 \oplus x_1]$ so that $\lim_{s \to \omega} \alpha_s = \omega_1^{CK}$, and use it as a parameter to decode the real $z$, and thereby conclude that $x_0 \oplus x_1 \cong_h z$.
