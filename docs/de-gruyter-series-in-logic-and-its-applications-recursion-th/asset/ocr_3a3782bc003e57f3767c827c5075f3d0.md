Obviously MA$_{\aleph_0}$ is a theorem of ZFC. It is known that if ZFC is consistent then so is ZFC + MA. The $\kappa$-chain condition is also used to compute the cardinality of a power set.

# **Lemma 6.1.6.** Suppose that $\kappa > \aleph_0$ is a regular cardinal and $\mathbb{P} = (\mathbf{P}, \le)$ satisfies $\kappa$-c.c. in $\mathcal{M}$ with $|\mathcal{P}| = \lambda$. Then for any regular cardinal $\eta \in M$ and generic set $G$, $\mathcal{M}[G] \models 2^\lambda \le ((\lambda^\kappa)^\eta)^M$.

**Proof (Sketch).** Every $x \in M[G] \cap 2^\lambda$ corresponds to a $\mathbb{P}$-name $\dot{x} \in \eta \times \mathscr{P}(\mathbf{P})$. Moreover, we may assume that for any $\gamma < \eta$, $| \{ p : (\dot{\gamma}, p) \in \dot{x} \} |$ is an antichain. There are $\lambda^\kappa$-many antichains in $\mathcal{M}$. Hence there are at most $(\lambda^\kappa)^\eta$-many such $\mathbb{P}$-names. In other words, $\mathcal{M}[G] \models 2^\lambda \le ((\lambda^\kappa)^\eta)^M$ (see [78] for a detailed proof).

# **6.1.3** $\kappa$**-closedness**

Two conditions $p$ and $q$ in $\mathbb{P}$ are compatible if $p \le q$ or $q \le p$. Given a cardinal $\kappa$, $\mathbb{P}$ has the $\kappa$-closed property (in $\mathcal{M}$) if for any sequence $\langle p_\alpha \rangle_{\alpha < \nu}$ of compatible conditions of length $\nu < \kappa$, there is a $q$ such that $q \le p_\alpha$ for each $\alpha < \nu$. Satisfying the $\kappa$-closed property is another basic tool for preserving cardinals.

# **Lemma 6.1.7.** If $\mathbb{P}$ has the $\kappa$-closed property and $A \in M$ with $|A| < \kappa$, then any function $f$ in a generic extension $\mathcal{M}[G]$ with domain $A$ belongs to $\mathcal{M}$. 

It follows that $\kappa$-closed property preserves all cardinals not greater than $\kappa$.

# **6.1.4 Product forcing**

# **Definition 6.1.18.** Let $I$ be an index set and let $\mathbb{P}_i = (\mathbf{P}_i, \le_i)$ be a notion of forcing for $i \in I$. Let $C \subseteq \mathscr{P}(I)$. The $C$-product forcing $\mathbb{P} = (\mathbf{P}, \le)$ is a partial ordering satisfying the following for each $p \in \mathbf{P}$:

+   - there is a $J \in C$ such that $p(i)$ is defined if and only if $i \in J$ and $p(i) \in \mathbf{P}_i$;
+   - $q \le p$ in $\mathbf{P}$ if and only if for any $i \in I$, $p(i)$ is defined implies $q(i)$ is defined and $q(i) \le_i p(i)$.

If $C$ is the collection of all finite subsets of $I$, then $\mathbb{P}$ is known as product forcing with finite support. If $C$ is the collection of all countable subsets of $I$, then $\mathbb{P}$ is product forcing with countable support. $I$ is often taken to be an ordinal.

Let $I$ be an ordinal $\gamma$. If $C = I$, we call $\mathbb{P}$ simply the product of $\langle \mathbb{P}_\alpha \rangle_{\alpha < \gamma}$. Then the $C$-product forcing $\mathbb{P} = \Pi_{\alpha < \gamma} \mathbb{P}_\alpha$ may be decomposed into $\Pi_{\alpha < \beta} \mathbb{P}_\alpha \times \Pi_{\beta \le \alpha < \gamma} \mathbb{P}_\alpha$. In other words, $\mathbb{P} \cong \Pi_{\alpha < \beta} \mathbb{P}_\alpha \times \Pi_{\beta \le \alpha < \gamma} \mathbb{P}_\alpha$.
