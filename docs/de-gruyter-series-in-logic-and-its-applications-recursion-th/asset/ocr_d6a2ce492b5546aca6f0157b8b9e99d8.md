**Theorem 2.2.6** (Kleene [69]). A real $x$ is $\Delta_1^1(y)$ if and only if it is hyperarithmetic in $y$.

The following corollary says that $\Delta_1^1$-sets are strongly reducible to $H$-sets.

**Corollary 2.2.7.** Every $\Delta_1^1$-real is many-one reducible to an $H$-set.

**Proof.** By Theorem 2.2.6, if $x$ is $\Delta_1^1$ then it is Turing reducible to $H_n$ for some $n \in \mathcal{O}$. Then $x$ is many-one reducible to $H_{2x} = (H_n)'$.

# ## 2.2.2 $\Delta_1^1$-sets of reals

There is a subtle point regarding uniformity when it comes to defining the notion of hyperarithmetic sets of reals. For this, we define $\tilde{H}^x$-sets by induction on $\mathcal{O}$ rather than on $\mathcal{O}^x$:

$$\tilde{H}_1^x = x,$$

$$\tilde{H}_{2^x}^x = (\tilde{H}^x)'$$

and

$$\tilde{H}_{3 \cdot 5^e}^x = \langle \langle m, i \rangle \mid m \in \tilde{H}_{\phi_e(i)}^x \rangle.$$

**Definition 2.2.8.** A set of reals $A$ is *hyperarithmetic* if there is a number $n \in \mathcal{O}$ and an index $e$ such that for all $x, x \in A \Leftrightarrow \phi_e^{\tilde{H}_n^x}(0) \downarrow$.

Hence if $A$ is hyperarithmetic, then there exist $n$ and $e$ such that

$$x \in A \Leftrightarrow (\exists \sigma)(\sigma < \tilde{H}_n^x \land \phi_e^\sigma(0) \downarrow)$$

and

$$x \notin A \Leftrightarrow (\forall \sigma)(\sigma < \tilde{H}_n^x \rightarrow \phi_e^\sigma(0) \uparrow).$$

It follows that Lemma 2.2.1 remains true for such $\tilde{H}^x$-sets and so $A$ is $\Delta_1^1$.

Conversely, assume $A$ is $\Delta_1^1$. According to the discussion in §1.5.1, there are two numbers $k_0$ and $k_1$ such that $x \in A \Rightarrow k_0 \in \mathcal{O}^x \Rightarrow k_1 \in \mathcal{O}^x$. By relativizing Corollary 1.5.4, there is a recursive function $p$ such that $\min\{|k_0|_x, |k_1|_x\} \le |p(k_0, k_1)|_x$ for all $x$. Let $n = 2^{p(k_0, k_1)}$. Note that $n \in \mathcal{O}^x$ for all $x$ and so $0 \in \mathcal{O}^x = 0$. Since Lemma 2.2.4 remains true, $\mathcal{O}_n^x = \tilde{H}_{\phi(n)}^x$ for all $x$. Hence there is a recursive function $h$ such that $k_0 \in \mathcal{O}_n^x \Leftrightarrow 0 \in W_{\tilde{H}_{\phi(n)}^x}$ for all $n$, giving $x \in A \Leftrightarrow \phi_{h(n)}^{\tilde{H}_n^x}(0) \downarrow$. Thus we arrive at the following conclusion.

**Theorem 2.2.9.** A set of reals is hyperarithmetic if and only if it is $\Delta_1^1$.
