
Theorem 13.1.3 is useful as a basic tool for hyperarithmetic measure theory.

## 13.1.2 Measure-theoretic uniformity

### **Theorem 13.1.4** (Sacks [120]). $\{x \mid \omega_1^{\text{CK}, x} = \omega_1^{\text{CK}}\}$ has measure 1.

Proof. By Theorem 5.15, it is sufficient to prove that the set
$\{x \mid \mathfrak{A}(\omega_1^{\text{CK}, x}) = \Delta_1^1\text{-comprehension}\}$
has measure 1. Let $(\langle \varphi_i, \psi_i \rangle)_{i < \omega}$ be a recursive enumeration of arithmetical formulas.

For each $i$, define the $\Pi_1^1$-set
$A_i = \{x \mid \mathfrak{A}(\omega_1^{\text{CK}, x}) \models (\forall n) \exists y (\varphi_i(n, y) \lor \neg \psi_i(n, y)) \}$.

Let
$A_{i, \beta} = \{x \mid \mathfrak{A}(\omega_1^{\text{CK}, x}) \models (\forall n)(\exists \beta') (\varphi_i(n, y^\beta) \lor \neg \psi_i(n, y^\beta)) \}$.

Then $A_{i, \beta} \subseteq A_i$ for all $i < \omega$ and $\beta < \omega_1^{\text{CK}}$. By Corollary 13.1.2, for any $i, j < \omega$, there is a $\beta_{i, j} < \omega_1^{\text{CK}}$ such that $\mu(A_i \setminus A_{i, \beta_{i, j}}) < 2^{-i-j}$. Moreover, for any $j < \omega$ and $x \notin \bigcup_{i < \omega} (A_i \setminus A_{i, \beta_{i, j}})$, we have $\mathfrak{A}(\omega_1^{\text{CK}, x}) = \Delta_1^1\text{-comprehension}$. Then for any $j$,
$\mu(\{x \mid \mathfrak{A}(\omega_1^{\text{CK}, x}) = \Delta_1^1\text{-comprehension}\}) \ge 1 - \sum_{i < \omega} 2^{-i+j} \ge 1 - 2^{-j+1}$.

Thus
$\mu(\{x \mid \mathfrak{A}(\omega_1^{\text{CK}, x}) = \Delta_1^1\text{-comprehension}\}) = 1$.

Theorem 13.1.4 is somewhat counterintuitive since it is much easier to construct a real hyperarithmetically computing the hyperjump. The theorem may also be viewed as one more piece of evidence to support the randomness thesis since the set of reals hyperarithmetically computing 0 has measure 0.

It is known (see Sacks [117] and Leeuw, Moore, Shannon, and Shapiro [19]) that for any nonrecursive x, the set $\{y \mid y \ge_T x\}$ is null. The following theorem is a hyperarithmetic analog.

### **Theorem 13.1.5** (Sacks [123]). If $x$ is not hyperarithmetic, then $\mu(\{y \mid y \ge_h x\}) = 0$.

Proof. For any x, the set $\{y \mid y \ge_h x\}$ is $\Pi_1^1(x)$ and hence measurable by Corollary 3.7.10.

Now suppose that $\mu(\{y \mid y \ge_h x\}) > 0$. By Theorem 13.1.4, $\omega_1^x = \omega_1^{\text{CK}}$. Moreover, $\mu(\{y \mid \omega_1^y = \omega_1^{\text{CK}} \land y \ge_h x\}) > 0$. By Theorem 5.14, there is a ranked formula $\varphi(n)$ such that $\mu(\{y \mid n \in x \iff \mathfrak{A}(\omega_1^{\text{CK}, y}) \models \varphi(n)\}) > 0$. By the Lebesgue Density Theorem, there is a string $\sigma \in 2^{<\omega}$ such that $\mu(\{y \mid y > \sigma \land n \in x \iff \mathfrak{A}(\omega_1^{\text{CK}, y}) \models \varphi(n)\}) > \frac{1}{2} \cdot 2^{-|\sigma|}$. Then
$n \in x \iff \mu(\{y > \sigma \mid \mathfrak{A}(\omega_1^{\text{CK}, y}) \models \varphi(n)\}) > \frac{1}{2} \cdot 2^{-|\sigma|}$
and
$n \notin x \Rightarrow \mu(\{y > \sigma \mid \mathfrak{A}(\omega_1^{\text{CK}, y}) \models \neg \varphi(n)\}) > \frac{1}{2} \cdot 2^{-|\sigma|}$.

By Lemma 13.1.1, x is hyperarithmetic, which is a contradiction.

It is also known that the statement "\(\mu(A) > p\)" is r.e. if A is an r.e. set of reals and p is rational. The following corresponding result holds in hyperarithmetic theory.

### **Proposition 13.1.6** (Sacks [123]). Let \(A \subseteq \omega \times 2^\omega\) be \(\Pi_1^1\) and \(A_n = \{x \mid (n, x) \in A\}\). Then \(\{(n, p) \mid p \text{ is rational} \land \mu(A_n) > p\}\) is \(\Pi_1^1\).

Proof. Since A is \(\Pi_1^1\), by Corollary 3.7.4 there is an arithmetical formula \(\varphi(n, x, z)\) such that
\((n, x) \in A \Leftrightarrow (\exists z \leqslant_{\text{h}} x) \varphi(n, x, z)\).

Let \(B = \{(n, x) \mid \mathfrak{A}(\omega_1^x, x) \models (\exists i)(\varphi(n, x, z) \leqslant i)\}\). By Theorem 13.1.4 for every n, \(\mu(B_n) = \mu(\{x \mid (n, x) \in B\}) = \mu(A_n)\). By Corollary 13.1.2, \(\mu(B_n) > p\) if and only if
\((\exists i)(\mu(B_n) \ge p + 2^{-i})\)
if and only if
\((\exists i)(\exists m)(m \in \omega_1 \land \mu(\{x \mid \mathfrak{A}(\omega_1^{\text{CK}}, x) \models (\exists z^{\le m}) \varphi(n, x, z^{\le m})\}) \ge p + 2^{-i})\).

By Lemma 13.1.1, it follows that the set \(\{(n, p) \mid \mu(A_n) > p \land p \text{ is rational}\}\) is \(\Pi_1^1\).

The following result was proved by Kechris in [63] under the assumption of PD. It turns out that the additional assumption can be weakened.

### **Corollary 13.1.7** (Kechris [63]). Assume that \(\omega_1^x < \omega_1\). Given a \(\Sigma_2^1\)-set \(A \subseteq 2^\omega\), both \(\{p \in \mathbb{Q} \mid \mu(A) > p\}\) and \(\{p \in \mathbb{Q} \mid \mu(A) \ge p\}\) are \(\Sigma_2^1\).

Proof. By assumption, almost every real is R-generic over L (see § 6.2.2). Note that for any x that is R-generic over L, \(L_1^{\omega_1^x} = \omega_1^x\). Since A is \(\Sigma_2^1\), there is a \(\Pi_1^1\) relation R such that
\(x \in A \Leftrightarrow (\exists y \in L_{\omega_1^x}[x]) R(x, y)\).

Then \(\mu(A) > p\) if and only if there is an ordinal \(\beta < \omega_1^x\) such that \(\mu(\{x \mid (\exists y \in L_\beta[x]) R(x, y)\}) > p\). Thus \(\mu(A) > p\) if and only if there is a real \(r \in L\) coding a well-ordering of order type \(\beta\) such that \(\mu(\{x \mid (\exists y \in L_\beta[x]) R(x, y)\}) > p\). By Proposition 13.1.6, the latter is a \(\Sigma_2^1\) statement.

The second part of the corollary follows immediately from the first.

By the proof of Corollary 13.1.7, we have the following conclusion.

### **Corollary 13.1.8.** If \(\omega_1^x < \omega_1\), then every \(\Sigma_2^1\)-set is measurable.

### **Proposition 13.1.9** (Kechris [63]). Suppose that \(\omega_1^x < \omega_1\). For any x, if \(\{y \mid x \leqslant_{\Delta_1^1} y\}\) is not null, then x is \(\Delta_2^1\).

Proof. By the \(\Pi^1_1\)-Uniformization Theorem (4.2.1), there is a \(\Pi^1_1\)-partial function \(F : \omega \times 2^\omega \to 2^\omega\) such that for any \(y\) and \(\Pi^1_1(y)\)-singleton \(z\), there is an \(n\) such that \(F(n, y) = z\). By Corollary 4.2.8, \(x \le_{\Delta^1_1} y\) if and only if there exist \(n\) and \(e\) such that \(x = \Phi_e^{F(n, y)}\). Note that for any pair \((n, e)\) and numbers \(m\) and \(i\), the set \(D_{n,e,m,i} = \{y \mid \Phi_e^{F(n,y)}(m) = i\}\) is \(\Sigma^1_1\) and hence, by Corollary 13.1.8, is measurable. Note also that for any \(n\) and \(e\), the set \(D_{n,e} = \{y \mid \Phi_e^{F(n,y)}(m) = x(m)\} = \bigcap_{m \in \omega} D_{n,e,m,x(m)}\) is measurable. Hence \(E = \{y \mid x \le_{\Delta^1_1} y\}\) is measurable. Now suppose that \(E\) is not null. Then there is a pair \((n, e)\) that has \(D_{n,e}\) positive measure. Let \(\sigma \in 2^{<\omega}\) such that \(\mu(D_{n,e} \cap [\sigma]) > 2^{-|\sigma|} \cdot \frac{3}{4}\). Then \(m \in x \iff \mu(D_{n,e,m,1} \cap [\sigma]) > 2^{-|\sigma|} \cdot \frac{3}{4}\). By Corollary 13.1.7, \(x\) is \(\Sigma^1_1\). By the same argument, \(\omega \backslash x\) is also \(\Sigma^1_1\) and hence \(x\) is \(\Delta^1_1\). \(\square\) It should be pointed out that the assumption "\(\omega_1^{\text{CK}} < \omega_1\)" in Proposition 13.1.9 is not provable under ZFC.

## 13.1.3 A measure-theoretic basis theorem

In measure theory, every measurable set of reals is approximated by closed sets. There is an effective version of this in hyperarithmetic theory.

### **Lemma 13.1.10.** There is a \(\Pi^1_1\)-function \(f : \omega \times \omega \to \omega\) such that for any Gödel number \(n\) of a ranked formula,
- (i) \(f(n, m)\) is the Gödel number of a ranked formula whose only free variable is \(x\);
- (ii) the set \(\{x \mid \mathfrak{A}(\omega_1^{\text{CK}}, x) \vDash \phi_{f(n,m)}\}\) is a closed subset of \(\{x \mid \mathfrak{A}(\omega_1^{\text{CK}}, x) \vDash \phi_n\}\);
- (iii) \(\mu(\{x \mid \mathfrak{A}(\omega_1^{\text{CK}}, x) \vDash \phi_n\} \setminus \{x \mid \mathfrak{A}(\omega_1^{\text{CK}}, x) \vDash \phi_{f(n,m)}\}) < 2^{-m}\).

Proof. We construct the function \(f\) by induction on the rank of formulas. Let \(\beta < \omega_1^{\text{CK}}\) and assume by induction that \(f\) is defined for every formula with rank less than \(\beta\). In \(\langle L_{\omega_1^{\text{CK}}}, \in \rangle\), there is a uniform enumeration \(\{\psi_{(n)}\}_{i < \omega}\) of the set of formulas of rank \(< \beta\) with \(n\) as the only free variable.

Let \(\varphi(x^E)\) be a formula of rank \(\le \beta\) whose only free ranked variable is \(x^E\). For the formula \((\exists x^E)\varphi(x^E)\), \(\mathfrak{A}(\omega_1^{\text{CK}}, x) \vDash (\exists x^E)\varphi(x^E)\) if and only if there is a \(j\) such that \(\mathfrak{A}(\omega_1^{\text{CK}}, x) \vDash \forall^j \varphi(\Psi b)\). By Theorem 13.1.3, there is a hyperarithmetic function taking each \(m\) to a large enough \(j\) such that
\(\mu(\{x \mid \mathfrak{A}(\omega_1^{\text{CK}}, x) \vDash (\exists x^E)\varphi(x^E)\}) - \mu(\{x \mid \mathfrak{A}(\omega_1^{\text{CK}}, x) \vDash (\exists i \le j)(\varphi(\Psi_i))\}) < 2^{-m-1}\).
