This shows that $S_0$ is a pointed tree. Then there exists an $x_1 \in [S_0]$ such that $T_0 \oplus S_0 \le_T x_1$. Since $\Phi_{e_0}$ is a homeomorphism from $T_0$ to $S_0$, it is not difficult to see that the unique real $y \in [T_0]$ such that $\Phi_{e_0}^y = x_1$ is recursive in $x_1$. In other words, $F(y) = x_1 \ge_T y$, a contradiction.

# 7.2 Martin's conjecture for uniformly degree invariant functions

The results discussed in this section are due to Steel [159].

Lemma 7.2.1. Assume ZF + AD + DC. Then $\le_M$ is a linear ordering on the collection of functions which are increasing and uniformly degree invariant.

Proof. Suppose that $F$ and $G$ are increasing uniformly degree invariant functions via $t$ on a cone $\{x \mid x \ge_T z_0\}$. Define a set $A \subseteq \omega^\omega$ so that $x_0 \oplus x_1 \in A$ if and only if either $x_1^i \notin 2^\omega$ or

+   - $x_0^i \in 2^\omega$;
+   - $\Phi_{e_0}^{x_0^i} = x_1^i$ where $x_0(0) = \langle e_0, n_0 \rangle$, and
+   - either $\Phi_{e_1}^{x_1^i} \notin x_0^i$ or $n_0 \in F(x_0^i) \leftrightarrow n_1 \notin G(x_1^i)$ where $x_1(0) = \langle e_1, n_1 \rangle$.

Consider a two person game $\mathcal{G}_A$ played by I and II on $A$, with I playing $\langle e_0, n_0 \rangle$ as the first move. Suppose that I has a winning strategy $\hat{\sigma}$ for $\mathcal{G}_A$. Fix a real $y \ge_T \hat{\sigma} \oplus z_0 \oplus t$. By the Recursion Theorem relativized to $y$, for any number $m$, there is an $e_1^m$ such that $\Phi_{e_1^m} = (\delta(\overline{x_1^m}))$ where $x_1^i = (\langle e_1^m, m \rangle)^\frown y$. Note that the function $m \mapsto e_1^m$ is recursive. Let $x_0^m = \delta(\overline{x_1^m})$ and $x_0^m(0) = \langle e_0^m, n_0^m \rangle$. Note that the function $m \mapsto \langle e_0^m, n_0^m \rangle$ is $y$-recursive (actually a constant function). Since $\hat{\sigma}$ is a winning strategy for I, $\Phi_{e_0^m}^{n_0^m} = y$ and

$n_0^m \in F((x_0^m)^\frown) \leftrightarrow m \notin G(x_1^m) = G(y)$.

Note that $(x_1^m)^\frown \equiv_T y$ via $\langle e_0^m, e_1^m \rangle$, and so we have $F((x_0^m)^\frown) \equiv_T F(y)$ via $\langle e_0^m, e_1^m \rangle = (i_0^m, i_1^m)$. Since $F(y) \ge_T y$, $t \le_T y$ and $m \mapsto \langle e_0^m, e_1^m \rangle$ is $y$-recursive, the function $m \mapsto (i_0^m, i_1^m)$ is $F(y)$-recursive. Then for any $m$, we may $F(y)$-recursively find $n_0^m$ and $i_1^m$ such that $\Phi_{i_1^m}^{F(y)}(n_0^m) = F((x_0^m)^\frown)(n_0^m) = 1 - G(y)(m)$. Hence $G(y) \le_T F(y)$ and so $G \le_M F$.

If II has a winning strategy, then by a similar argument one shows that $F \le_M G$.
