Proof. Suppose that \(\sigma \in T_1\) and \(T_1 \cap [\sigma]\) has no nonhyperarithmetic infinite path. We perform a Cantor-Bendixson type operation on \(T_1 \cap [\sigma]\) as follows: Let \(\le_{KB}\) be the Kleene-Brouwer ordering on \(\omega^{<\omega}\). At stage \(\beta < \omega_1^{CK}\), define a subtree \(T_1^\beta\). \(T_1^0\) is in fact \(T_1[\beta]\) except for the removal of those strings \(\sigma'\) where \([\sigma]\) is seen at stage \(\beta\) not to contain a nonhyperarithmetic path in \(T_1\).

Stage 0. Let \(T_1^0 = T_1[\sigma]\).

Stage \(\beta + 1\). Given \(\sigma \in T_1^\beta\) and \(\tau > \sigma\), if either (1) there exists a \(<_{KB}\) order-preserving function \(h : T_1^\beta \cap [\tau] \to \beta\) in \(L_\beta\) (hence there is no infinite path in \(T_1^\beta \cap [\tau]\), or (2) there exists a function \(h \in L_\beta\) that enumerates \(T_1^\beta \cap [\tau]\) as a unique hyperarithmetic path.

Then let \(T_1^{\beta+1} = T_1^\beta \setminus [\tau]\) and declare that \(\tau\) is removed from \(T_1^\beta\) at stage \(\beta + 1\).

By the usual Cantor-Bendixson proof as in Proposition 3.6.10, if \(T_1 \cap [\sigma]\) has no nonhyperarithmetic infinite path, then every \(\tau > \sigma\) is removed at some stage \(\beta\). Then by the admissibility of \(\omega_1^{CK}\), there is a stage \(\beta_\sigma < \omega_1^{CK}\) such that every \(\tau > \sigma\) is removed at \(\beta_\sigma\). At stage \(\beta_\sigma\), define \(H(\sigma) = 0\).

Thus \(H\) may be viewed as a \(\Sigma_1(L_{\omega_1^{CK}})\)-partial enumeration function. A node \(\sigma \in \omega^{<\omega}\) is a splitting node in the tree \(T_1\) if there exist \(j \supset \sigma\) such that both \(H(\sigma^\frown j)\) and \(H(\sigma^\frown j')\) are undefined. For \(\beta < \omega_1^{CK}\), a node \(\sigma \in \omega^{<\omega}\) is a splitting node in the tree \(T_1[\beta]\) if there exist \(i \neq j\) such that both \(H(\sigma^\frown i)\) and \(H(\sigma^\frown j)\) are undefined at stage \(\beta\). By a similar argument, there is a \(\Sigma_1(L_{\omega_1^{CK}})\)-partial function \(K : \omega^{<\omega} \to \{0\}\) such that \(K(\sigma)\) is undefined if and only if there exists an infinite path in \(T_0 \cap [\sigma]\). Note that \(K\) is different from \(H\).

We call a node \(\sigma \in \omega^{<\omega}\) a terminal node in \(T_0\) if \(K(\sigma)\) is defined. For \(\beta < \omega_1^{CK}\), \(\sigma \in \omega^{<\omega}\) is a terminal node in \(T_0[\beta]\) if \(K(\sigma)\) is defined at stage \(\beta\).

Now for any \(x \supset \sigma \supset 2^\omega\), we build a \(z \in [T_1]\) such that \(x \equiv_B z\): Stage 0. Let \(\sigma_0 = 0\).

Stage \(s + 1\). Let \(\sigma' > \sigma_s\) be the leftmost splitting node of \(T_1\) extending \(\sigma_s\) so that there are \(f(s)\) many splitting nodes between \(\sigma_s\) and \(\sigma'\). Let \(\sigma'' > \sigma'\) be the second leftmost splitting node extending \(\sigma'\) in \(T_1\). Set \(\sigma_{s+1} > \sigma''\) to be the \(x(s) + 1\)-th leftmost splitting node extending \(\sigma''\) in \(T_1\).

Let \(z = \bigcup_{s \in \omega} \sigma_s\).

We prove that \(x \in L_{\omega_1}[z]\). In fact we show that there is a \(\Sigma_1(L_{\omega_1}[z])\) (and hence \(\Delta_1(L_{\omega_1}[z])\)) definable increasing sequence of ordinals \(\{\alpha_s\}_{s \in \omega}\) below \(\omega_1^{CK}\) such that \(x \in L_{\bigcup \{ \alpha_s, \alpha_{s+1} \}}[z]\). Then \(\bigcup_s \alpha_s + 1 < \omega_1^K\), proving \(x \in L_{\omega_1}[z]\).

The idea is to decode the construction of \(z\) in \(L_{\omega_1}[z]\). For each \(n < \omega\) we use \(z\) to identify the value of \(f(n)\), where \(f\) is the leftmost path of \(T_0\). As an example, consider the case \(n = 0\). Given \(\beta < \omega_1^{CK}\), we compute, beginning at the root of \(T_1[\beta]\), the number \(l_\beta\) of times \(z\) 'turns left' in \(T_1[\beta]\). Then \(l_\beta\) is a possible value of \(f(0)\). Of course this guess may be wrong. As an aid to making a better guess, we also determine if \(l_\beta\) is \(f(0)\) by asking if \(0^\frown l_\beta\) is not a terminal node in \(T_0[\beta]\) but \(0^\frown l'\) is terminal for every \(l' < l_\beta\).
