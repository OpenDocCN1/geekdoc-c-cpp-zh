Proof. If \(\rho = 1\) then the conclusion is immediate. Suppose \(\rho > 1\). Then \(\rho\) is a limit ordinal. Let \(\gamma < \rho\) and \(A \subseteq J_\rho\). Let \(h_\alpha\) be the canonical \(\Sigma_1\)-Skolem function for \(J_\alpha\). Fix \(p \in J_\alpha\) such that \(A\) is \(\Sigma_1(J_\alpha)\)-definable with parameter \(p\). Let \(H = h_\alpha(\omega \times \{p\})\). Then \((X, \in) \prec_\Sigma (J_\alpha, \in)\). By Theorem 3.3.7, there is a \(\beta \le \rho\) such that \(\pi : (X, \in) \cong (J_\beta, \in)\) is an isomorphism. Note that \(\pi(x) = x\) for all \(x \in J_\gamma\) since \(\gamma\) is transitive. Hence \(\pi(\alpha) = x\) for \(x \in A\). Thus \(A\) is also \(\Sigma_1\)-definable in \(J_\rho\) with parameter \(\pi(p) \in J_\beta\). We claim that \(\beta < \rho\). Otherwise, let \(f\) be \(\Sigma_1(J_\alpha)\) mapping a subset of \(J_\rho\) onto \(J_\alpha\). Then \(f \circ \pi \circ h_\alpha\) is \(\Sigma_1(J_\alpha)\) and maps a subset of \(\omega \times (J_\gamma \times \{p\})\) onto \(J_\alpha\). But \(\omega \times J_\gamma \times \{p\} \in J_{\gamma+2} \subseteq J_\rho\), and so it maps a subset of \(J_{\gamma+2}\) onto \(J_\alpha\), contradicting the choice of \(\rho\).

**Lemma 3.4.6.** Let \(\alpha > 0\) and \(\rho = \rho_\alpha^+\). Then there is an \(A \subseteq J_\rho\) which is \(\Sigma_1(J_\alpha)\)-definable and \(A \notin J_\alpha\).

**Proof.** Let \(f\) be \(\Sigma_1(J_\alpha)\)-definable mapping a subset of \(J_\rho\) onto \(J_\alpha\). Then the domain of \(f\) restricted to \(J_\rho\) is \(\Sigma_1(J_\alpha)\) and not an element of \(J_\alpha\) by admissibility.

Lemma 3.4.5 and Lemma 3.4.6 yield the following characterization of \(\rho_\alpha^+\):

**Theorem 3.4.7.** Let \(\alpha > 0\). Then \(\rho_\alpha^+\) is the least ordinal \(\rho\) for which there is a \(\Sigma_1(J_\alpha)\) set \(A \subseteq J_\rho\) not in \(J_\alpha\).

Now suppose that \(x \subseteq \omega\) is \(\Sigma_1(J_\alpha)\)-definable with parameter \(p\) and \(x \notin J_\alpha\). Let \(X = h_\alpha(\omega \times \{J_1 \times \{p\}\})\). We may identify \(\omega \times J_1\) with \(J_1\). Hence \(X = h_1(1 \times \{p\})\) for some \(\Sigma_1\)-function \(H\). Then \((X, \in) \prec_\Sigma (J_\alpha, \in)\). By transitive collapse there is a \(\beta \le \alpha\) such that \(\pi : (X, \in) \cong (J_\beta, \in)\). Since \(x \subseteq J_1\), \(\pi(n) = n\) for all \(n \in \omega\). Thus \(x\) is \(\Sigma_1(J_\beta)\)-definable with parameter \(\pi(p)\). If \(\beta < \alpha\), then \(x \in J_\alpha\) which is a contradiction. Thus \(\beta = \alpha\). Now \(\pi\) is \(\Sigma_1(J_\alpha)\)-definable and so \(\pi \circ h\) is \(\Sigma_1(J_\alpha)\)-definable and maps a set \(y \subseteq J_1\) onto \(J_\alpha\). Since \(J_1 \simeq \text{HF}\), by Proposition 3.2.6, we may assume that \(y\) is a real. Hence for any admissible \(\alpha\), if \(J_{\alpha+1} \backslash J_\alpha\) contains a \(\Sigma_1(J_\alpha)\)-definable real, then it contains a real "coding \(J_\alpha\)".

**Remark 3.4.8.** Theorem 3.4.7 remains valid for \(n \ge 1\). However, the proof requires more than a straightforward generalization of what was presented above. The major difficulty is that there is no canonical \(\Sigma_n\)-Skolem function for \(n \ge 2\). To overcome this difficulty, a finer analysis of \(J_\alpha\) is introduced. See Jensen [55] for details.
