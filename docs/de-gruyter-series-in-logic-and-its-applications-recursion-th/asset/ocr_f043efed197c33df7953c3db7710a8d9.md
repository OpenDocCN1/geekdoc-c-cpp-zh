In this section, we study the key properties of $\Delta^1_1$-randomness.

Proposition 14.2.2. Suppose that $A$ is a $\Delta^1_1$-nullset. There is a $\Delta^1_1$-set $V \subseteq \omega \times 2^{<\omega}$ such that $(\forall n)(\nu(V_n) = 2^{-n})$ and $A \subseteq \bigcap_{n<\omega} V_n$, where $V_n = \{\sigma \mid (n, \sigma) \in V\}$ is a $\Delta^1_1$-open set.

Proof. As before, $\{A_s\}$ is the collection of sets of reals generated by Borel codes $z$ (§2.7.1). Since $A$ is a $\Delta^1_1$-nullset, by Lemma 13.11.10 there is a $\Delta^1_1$-function $f : \omega \to \Sigma_1 \cap \text{HYP}$ such that for every $n < \omega$,

+   - $\mu(A(f(n)) < 2^{-n}$, and
+   - $A \subseteq A_{f(n)}$

Then $A_{f(n)} = [U_n]$ for some $\Delta^1_1$-set $U_n \subseteq 2^{<\omega}$. It now suffices to show that $\{U_n\}_{n<\omega}$ may be expanded to a $\Delta^1_1$-collection $\{V_n\}_{n<\omega}$ such that $U_n \subseteq V_n$ and $\mu(V_n) = 2^{-n}$. Since the set $U = \{(n, \sigma) \mid \sigma \in U_n\}$ is $\Delta^1_1$, there is an $m \in \Theta$ such that $U \le_T H_m$. Note that the set $\{(x, e, p) \in 2^\omega \times \omega \times \mathbf{Q} \mid \mu(\{o\} \mid (\exists i)(\Phi_e^i(i) = o\})) > p\}$ is r.e. Then by a standard technique in classical randomness theory relativized to $H_{2^m}$, there is a $V \subseteq \omega \times 2^{<\omega}$ recursive in $H_{2^m}$ such that for every $n$, $\mu(V_n) = 2^{-n}$ and $U_n \subseteq V_n$. Then $A \subseteq \bigcap_{n<\omega} V_n$.

By Proposition 14.2.2, $\Delta^1_1$-randomness may be viewed as a higher analog of Schnorr randomness.

Proposition 14.2.3 (Martin-Löf [97]). The set of $\Delta^1_1$-random reals is $\Sigma^1_1$ but not $\Delta^1_1$.

Proof. Define a $\Sigma^1_1$-set

```
$A = \{x \mid (\forall e)(\forall n)((m \in \Theta)(\nu m[\{i(\{o\} \mid \exists i)(\Phi_e^{H_n}(\langle m, i \rangle) = o\})) \le 2^{-m}) \to (\exists m)(\forall i)(x \not\prec \Phi_e^{H_n}(\langle m, i \rangle))).$
```

By Proposition 14.2.2, $A$ is precisely the set of $\Delta^1_1$-random reals. Since $A$ does not contain a hyperarithmetic member, by Theorem 13.13.13, it is not $\Delta^1_1$.

# 14.2.2 $\Pi^1_1$-Martin-Löf randomness

A sequence of open sets $\{U_n\}_{n<\omega}$ is a Martin-Löf test (ML test) if $\mu(U_n) < 2^{-n}$ for all $n$. Given a class $\Gamma$ of sets of reals (e.g., $\Pi^1_1$), $\{U_n\}_{n<\omega}$ is a $\Gamma$-ML test if $\{(n, \sigma) \mid \sigma \in 2^{<\omega} \wedge [\sigma] \in U_n\} \in \Gamma$.

Definition 14.2.4. Let $\Gamma$ be a class of sets of reals. Then $x$ is $\Gamma$-ML random if $x \notin \bigcap_{n<\omega} U_n$ for any $\Gamma$ ML test $\{U_n\}_{n<\omega}$.

Proposition 14.2.5 (Jorhth and Nies [51]). There is a universal $\Pi^1_1$-ML test $\{U_n\}_{n<\omega}$, i.e., for every $\Pi^1_1$-ML test $\{V_n\}_{n<\omega} \bigcap_{n<\omega} V_n \subseteq \bigcap_{n<\omega} U_n$.
