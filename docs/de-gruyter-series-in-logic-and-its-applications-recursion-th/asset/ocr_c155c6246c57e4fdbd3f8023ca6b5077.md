Proposition 3.3.11. There is a \(\Sigma_1\)-formula \(\varphi(x, y, i, z)\) such that for any ordinal \(a\), the function

\(h_a(i, x) = y \leftrightarrow \langle J_a, \in \rangle \models (\exists z)\varphi(x, y, i, z)\)

is a \(\Sigma_1\)-Skolem function for \(\langle J_a, \in \rangle\).

Proof. By Proposition 3.3.3, there is a \(\Sigma_1\)-formula \(\varphi(u, v)\) defining a well-ordering \(<_J\) of \(J_a\) for any admissible \(a\). Clearly there is a \(\Sigma_1\)-enumeration \(\langle \varphi_i(u, v, w) \rangle\) of all \(\Sigma_0\)-formulas. In other words, there is a \(\Sigma_1\)-formula \(\varphi(x, y, i, z)\) so that \(\langle J_a, \in \rangle \models \varphi(x, y, i, z) \leftrightarrow \langle J_a, \in \rangle \models \varphi_i(x, y, z)\). Define \(h_a(i, x)\) to be \(y\) so that \(\langle J_0, y \rangle\) is the \(<_J\)-least pair with \(\langle J_a, \in \rangle \models \varphi_i(y_0, y_1, x)\). By Proposition 3.3.3, \(h_a(i, x)\) is \(\Sigma_1\)-definable.

By the admissibility of \(a\), using some tedious coding argument which may be found in [22], one can show that the relation \(\text{\textit{h}}_a(i) \in \varphi(y_0, y_1, x)^x\) is uniformly \(\Sigma_1\). Let \(h_a(i, x) = y\) if and only if there exists \(y_1\) such that \(\langle J_a, \in \rangle \models \varphi(y_0, y_1, x)\) and there exists \(z = \langle z_0, z_1 \rangle | \langle z_0, z_1 \rangle <_J \langle y_0, y_1 \rangle\) such that for any pair \(\langle z_0, z_1 \rangle \in J_a\), \(\langle z_0, z_1 \rangle \models \neg \varphi(y_0, y_1, x)\). Since \(z\) is uniformly \(\Delta_1\)-definable for any admissible \(a\), we have \(h_a(i, x)\) to be uniformly \(\Sigma_1\)-definable for any admissible \(a\).

If \(\alpha\) is admissible, we call the \(\Sigma_1\)-Skolem function \(h_\alpha\) the canonical \(\Sigma_1\)-Skolem function for \(\alpha\).

Proposition 3.3.12. If \(a > \omega\) is admissible, then \(a \ge \omega_1^{CK}\).

Proof. Suppose \(\alpha\) is admissible and \(\omega < \alpha < \omega_1^{KT}\). By Theorem 3.3.6, \(L_\alpha\) is admissible. By Theorem 13.4, there is a recursive function \(f\) such that for each \(n \in \omega\), \(f(n) = \langle \{i, j\} | i <_J j < n \rangle\). Fix a number \(n \in \omega\) with \(|n| = \alpha\). Then the order type of \(W_{f(n)}\) is \(\alpha\) and \(W_{f(n)} \in L_{\omega+1} \subseteq L_\alpha\) by Theorem 3.2.5. By \(\Sigma\)-induction there is a \(\Sigma_1\) order-preserving bijection \(g : W_{f(n)} \to \alpha\). Since \(W_{f(n)} \in L_\alpha\), \(\alpha \in L_\alpha\) by the admissibility of \(\alpha\). This is a contradiction.
