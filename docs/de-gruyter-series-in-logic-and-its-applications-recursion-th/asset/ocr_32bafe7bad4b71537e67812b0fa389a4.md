\(\sigma \in T_1 \cap 2^A\) and a stage \(s \ge T\) such that \(\psi_s(\alpha) = \psi(\alpha) < x\). Then \(\Phi_i^x(t)\) is convergent if and only if \(\Phi_i^{\psi(\alpha)}(t)[s]\). Thus \(x' \le_T x \oplus \emptyset'\).

Now if \(i < \alpha\) and \(\sigma \in 2^1\), let \(\hat{T}_{i+1,l,\alpha}\) be a \(\emptyset^{(i)}\)-recursive tree as in Lemma 11.2.5 by setting \(T\) as \(\{\tau \mid \sigma^\frown \tau \in T_{i+1}^0\}\) and \(x\) as \(\emptyset^{(i)}\). Realizing Lemma 11.2.6 to \(\emptyset^{(i)}\) by replacing \(T_0\) with \(\hat{T}_{i+1,l,\alpha}\), we have a \(\emptyset^{(i)}\)-recursive homeomorphism \(\psi_i : \hat{T}_{i+1,l,\alpha} \to T_{l,\alpha}\) where \(T_{l,\alpha}\) is \(T_1\) in Lemma 11.2.6. Define \(T_i^0\) to be a \(\emptyset^{(i)}\)-recursive tree so that \(\tau \in T_i^0\) if and only if either

+   - \(|\tau| \le 1\), or

+   - \(\tau = (\tau \uparrow \gamma)^\frown \tau'\) for some \(\tau' \in T_{1, \uparrow \gamma}\).

Define \(\psi_i \le_T \theta^{(i+1)} : T_{i+1}^0 \to T_i^0\) such that

+   - if \(\tau \in 2^{\le \omega}\), then \(\psi_i(\tau) = \tau\);

+   - otherwise, let \(\tau = (\tau \uparrow \gamma)^\frown \tau'\). Define \(\psi_i(\tau) = \tau \uparrow \gamma \psi_i(\tau' \oplus (h_{00} \uparrow |\tau'|))\).

Hence for any path \(x \in [T_i^0]\),

\((x \oplus \theta^{(i)})^y \equiv_T x \oplus \theta^{(i+1)} \equiv_T \psi_i^{-1}(x) \oplus \theta^{(i+1)}\).

Since the construction is uniform, it is straightforward to verify that (1)-(7) are satisfied. This completes the proof of Theorem 11.2.2.

# 11.2.2 The proof of Harrington's Theorem

We follow the presentation of Hjorth [50]. By Theorem 2.6.5, for any recursive ordinal \(\beta \ge \omega\), there is an \(n \in \omega\) such that \([n] = \beta\) and the set \(\{m \mid m <_n n\}\) is recursive. We choose such an ordinal \(\beta\) and the corresponding \(n\).

For each \(m = 3 \cdot 5^k < \alpha_0\), let \(\{i_{j,m}\}_{j<\omega}\) be a sequence of numbers such that

\(i_{0,m} = \Phi_k(m)\)

and

\(i_{j+1,m} = \Phi_k(m+j+1)\).

By the proof of Theorem 2.6.5, we may assume that \(m \le i_{l,m} < i_{l+1,m}\) for all \(j\). Clearly the set \(\{(i_{l,m,j}, m) \mid (\exists k)(m = 3 \cdot 5^k \land \alpha_0 < n \land j \in \omega)\}\) is recursive.
