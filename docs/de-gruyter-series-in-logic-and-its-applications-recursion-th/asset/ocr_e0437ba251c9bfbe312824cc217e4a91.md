# 9 Independence results in recursion theory

# 9.1 Independent sets of Turing degrees

# 9.1.1 Locally countable partial ordering

**Definition 9.1.1.** A partially ordered set $(\mathbf{P}, \le_P)$ is locally countable if for any $p \in \mathbf{P}$, $|\{q \mid q \le_P p\}| \le \aleph_0$.

**Definition 9.1.2.** A function $f : (\mathbf{P}, \le_P) \to (\mathbf{Q}, \le_Q)$ is an embedding if $(\forall p_0, p_1 \in \mathbf{P}) (p_0 \le_P p_1 \Leftrightarrow f(p_0) \le_Q f(p_1))$.

Obviously $(\mathscr{D}, \le_T)$, the partial ordering of the Turing degrees, is locally countable. Sacks made the following conjecture.

**Conjecture 9.1.3** (Sacks [117]). Every locally countable partial ordering on $2^{\aleph_0}$ is embeddable into $(\mathscr{D}, \le_T)$. 

A positive solution is known assuming the Continuum Hypothesis:

**Theorem 9.1.4** (Sacks [117]). Assuming ZFC + CH. Every locally countable partially ordered set $(2^{\aleph_0}, \le_P)$ is embeddable into $(\mathscr{D}, \le_T)$. 

# 9.1.2 Independent sets of Turing degrees

As a "test question" for Conjecture 9.1.3, Sacks introduced the notion of independent sets and conjectured that every maximal independent set of Turing degrees has size $2^{\aleph_0}$. 

**Definition 9.1.5.** Let $(\mathbf{P}, \le_P)$ be a partial ordering. $X \subseteq \mathbf{P}$ is independent if for any finite subset $Y$ of $X$ and any $p \in X \backslash Y$, there is a $q \in \mathbf{P}$ such that $p \le_P q \wedge (\forall r \in Y)(r \le_P q)$. 

**Theorem 9.1.6** (Sacks [117]). Assume ZFC + CH. Every maximal independent set of Turing degrees has size $2^{\aleph_0}$. 

However, the conclusion of Theorem 9.1.6 is independent of ZFC:

**Theorem 9.1.7** (Groszek and Slaman [40]). There is a model $\mathbb{N} \vDash \text{ZFC} + \neg\text{CH}$ with a maximal independent set of Turing degrees of size $\aleph_1$. 

The rest of this section is devoted to a proof of Theorem 9.1.7. We begin with a ground model $\mathbb{M} \vDash \text{ZFC} + \text{GCH}$. Let $\mathbb{P} = (P, \le) = \Pi_{\alpha < \omega_1} \mathbb{S}_\alpha$ be product Sacks forcing with countable support, where $\mathbb{S}_\alpha$ is Sacks forcing for $\alpha < \omega_1$. Every P-generic set $G$ may be viewed as an $(\omega_1)^\mathbb{M}$-sequence of reals $\langle G_\alpha \rangle_{\alpha \in (\omega_1)^\mathbb{M}}$ where $G_\alpha = \{i \mid (\alpha, i) \in G\}$. It is not difficult to see that the Turing degrees of $\langle G_\alpha \rangle_{\alpha \in (\omega_1)^\mathbb{M}}$ form an independent set.
