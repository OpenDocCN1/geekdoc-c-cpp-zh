
## 14.3.3 Hyperdegrees of random reals

By Corollary 14.2.6, we know that the hyperdegrees of the set of $\Delta_1^1$-random reals include the cone of hyperdegrees with base 0. This raises the natural question of whether the hyperdegrees of $\Delta_1^1$-random reals are closed upwards.

Proposition 14.3.5. If $x$ is $\Delta_1^1$-random and $\omega_1^x = \omega_1^{CK}$, then there is a $y \ge_h x$ such that no $z \equiv_h y$ is $\Delta_1^1$-random.

Proof. Suppose that $x$ is $\Delta_1^1$-random and $\omega_1^x = \omega_1^{CK}$. Let

$F(x) = \{ y \mid y \ge_T x \land (\forall f \le_T y)(\forall g \le_h x)(g < f) \}.$

Then $F(x)$ is $\Sigma_1^x(x)$. Since $\emptyset^x \in F(x)$, $F(x)$ is not empty. By Gandy's Basis Theorem and relativized to $x$, there is a $y \in F(x)$ with $\omega_1^y = \omega_1^x = \omega_1^{CK}$. By Corollary 14.3.2 and Proposition 14.3.4, no $z \equiv_h y$ is $\Delta_1^1$-random.

On the other hand, the hyperdegrees of $\Pi_1^1$-random reals are closed downwards.

Lemma 14.3.6. If $x$ is $\Pi_1^1$-random and $y \le_h x$, then there is a recursive ordinal $\gamma$ such that $y \le_T x \oplus \emptyset^{(\gamma)}$.

Proof. Since $x$ is $\Pi_1^1$-random, we have $\omega_1^x = \omega_1^{CK}$. Let $y \le_h x$. Then there is a formula $\varphi(\dot{n}, \dot{x})$ with rank at most $\beta_0 < \omega_1^{CK}$ such that

$n \in y \Leftrightarrow \mathfrak{A}(\omega_1^{CK}, x) \vDash \varphi(\dot{n}, \dot{x})$.

By Lemma 13.1.11, there is a recursive ordinal $\beta > \beta_0$ such that

$A_{\beta_0} = \{ \ulcorner \varphi \urcorner \mid \varphi \text{ has rank at most } \beta_0 \land \mu(\{ z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \varphi \}) > 0 \}$

is recursive in $\emptyset^{(\beta)}$. By Lemma 13.1.10, there is a recursive ordinal $\beta_1 \ge \beta$ such that for any number $i$ and formula $\psi$ with rank $\beta$, there is a formula $\psi'$ with rank at most $\beta_1$ such that $\{ z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \psi' \}$ is a $\Pi_1^0(\emptyset^{(\beta)})$-subset of $\{ z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \psi \}$ with difference in measure less than $2^{-i}$. Note that the search procedure for $\beta_1$ from $\beta_0$ is effective in $L_{\omega_1^x}$. In this way one obtains a $\Delta_1$-sequence of ordinals $\beta_0 < \beta_1 < \cdots$ in $L_{\omega_1^x}$. Let $\gamma = \bigcup_{i < \omega} \beta_i$. Then for any $\beta < \gamma$,

- (i) $A_\beta = \{ \ulcorner \varphi \urcorner \mid \varphi \text{ has rank at most } \beta \land \mu(\{ z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \varphi \}) > 0 \}$

is recursive in $\emptyset^{(\beta)}$, and

- (ii) for any number $i$ and formula $\psi$ with rank $\beta$, there is a formula $\psi'$ with rank less than $\gamma$ so that $\{ z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \psi' \}$ is a $\Pi_1^0(\emptyset^{(\beta)})$-subset of $\{ z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \psi \}$ for some $\beta' < \gamma$ with difference in measure less than $2^{-i}$.

Note that for any ranked formula $\psi$, if $x \in P_\psi = \{ z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \psi \}$, then $P_\psi$ has positive measure.

Since \( x \) is \( \Delta^1_1 \)-dominated, there is a hyperarithmetic function \( f : \omega \to \omega \) such that for any \( e \) and \( n \in \omega \) with \( |n| < \gamma \) such that \( \Phi_e^{H_e} \) computes a tree \( T_{e,n} \), if \( x \notin [T_{e,n}] \) then \( f(n,e) \notin T_{e,n} \).

Now recursively in \( x \oplus 0^{(\beta)} \oplus f \), search for a formula \( \psi_0 \) with rank less than \( \gamma \) such that \( S_0 = \{z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \psi_0\} \) contains \( x \), and is a closed subset of either \( \{z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \varphi(z, 0)\} \) or \( \{z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \neg \varphi(z, 0)\} \).

Since \( x \) is \( \Pi^1_1 \)-random, by (ii) there is such a \( \psi_0 \). Note that one needs \( x \oplus 0^{(\beta)} \oplus f \) to decide if \( x \in S_0 \). Inductively, for each \( n \), search recursively in \( x \oplus 0^{(\beta)} \oplus f \) for a formula \( \psi_{n+1} \) with rank less than \( \gamma \) such that \( S_{n+1} = \{z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \psi_{n+1}\} \) contains \( x \), has positive measure, and is a closed subset of either \( S_n \cap \{z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \varphi(z, n+1)\} \) or \( S_n \cap \{z \mid \mathfrak{A}(\omega_1^{CK}, z) \vDash \neg \varphi(z, n+1)\} \).

Since \( x \) is \( \Pi^1_1 \)-random, by (ii), such a \( \psi_{n+1} \) exists. This implies that \( y \not\le_T x \oplus 0^{(\beta)} \oplus f \).

Since \( f \) is hyperarithmetic, there is a \( \gamma_0 < \omega_1^{CK} \) such that \( f \le_T 0^{(\gamma_0)} \). Without loss of generality, assume \( \gamma_0 \le \gamma \) (replacing \( \gamma \) with \( \gamma_0 + \gamma \) if necessary). Then \( y \not\le_T x \oplus 0^{(\gamma)} \). \(\square\)

## **Corollary 14.3.7.** If \( x \) is \( \Pi^1_1 \)-random and \( y \le_h x \), then there is a recursive ordinal \( \beta \), a function \( f \le_T 0^{(\beta)} \) and a recursive functional \( \Psi \) such that for every \( n, y(n) = \Psi^{x \oplus 0^{(\beta)}(n)}(n)[f(n)] \).

**Proof.** Suppose that \( x \) is \( \Pi^1_1 \)-random and \( y \le_h x \). By Lemma 14.3.6, there is a recursive ordinal \( \gamma \) and a recursive function \( \Phi \) such that for every \( n, y(n) = \Phi^{x \oplus 0^{(\gamma)}(n)}(n)[g(n)] \). Since \( x \) is \( \Pi^1_1 \)-dominated, there is a function \( g \le_h x \) such that for every \( n, y(n) = \Phi^{x \oplus 0^{(\gamma)}(n)}(n)[g(n)] \). Since \( x \) is \( \Pi^1_1 \)-dominated, there is a hyperarithmetic function \( h \) so that for all \( n, h(n) > g(n) \).

Hence there is a sufficiently large recursive ordinal \( \beta \) such that both \( x \) and \( h \) are many-one reducible to \( 0^{(\beta)} \). It is not difficult to define a function \( f \le_T 0^{(\beta)} \) and a recursive function \( \Psi \) so that for every \( n, y(n) = \Psi^{x \oplus 0^{(\beta)}(n)}(n)[f(n)] \). \(\square\)

## **Theorem 14.3.8.** If \( x \) is \( \Pi^1_1 \)-random and \( y \le_h x \) is not hyperarithmetic, then there is a \( \Pi^1_1 \)-random \( z \equiv_h y \).

**Proof.** Suppose \( x \) is \( \Pi^1_1 \)-random and \( y \le_h x \) is not hyperarithmetic. By Corollary 14.3.7, there is a recursive ordinal \( \beta \), a nondecreasing function \( f \le_T 0^{(\beta)} \) and a recursive function \( \Psi \) such that \( \lim_{n \to \infty} f(n) = \infty \) and for every \( n \),

\( y(n) = \Psi^{x \oplus 0^{(\beta)}(n)}(n)[f(n)] \).

For each \( u \in 2^{<\omega} \), let

\( l(u) = \sum_{\tau \in 2^{|\tau|} \cap \text{Cl}} \left( \sum_{g \in 2^{|\tau|} \wedge \forall \rho \prec u \exists \rho' \in [u] [f(|\rho|)] \|\tau\| = \tau} 2^{-|\sigma|} \right) \)

and

\( r(u) = l(u) + \sum_{\sigma \in 2^{|\tau|} \wedge \forall \rho \prec u \exists \rho' \in [u] [f(|\rho|)] \|\tau\| = u} 2^{-|\sigma|} \),

where \( \tau < u \) means, as strings, \( \tau \) is to the left of \( u \).

One may view \(\sum_{\sigma \in 2^{<\omega}} \lambda \mu[\text{ext}(\sigma) \oplus \emptyset^{(\beta)}[f(|\sigma|)]]_{r(\sigma)} 2^{-|\sigma|}\) as a “measure” for \(\tau\). For each \(n\), let

\(l_n = l(y \upharpoonright n)\), and \(r_n = r(y \upharpoonright n)\).

Then \(l_n \le l_{n+1} \le r_{n+1} \le r_n\). Since \(y\) is not hyperarithmetic, it is not difficult to see that \(\lim_{n \to \infty} r_n = 0\). Hence there is a unique

\(z = \bigcap_{n<\omega} (l_n, r_n)\).

Clearly \(z \le_T y \oplus \emptyset^{(\beta)}\). We leave it to the reader to verify that \(y \le_T z \oplus \emptyset^{(\beta)}\). Thus \(z \equiv_T y\).

Suppose that \(z\) is not \(\Delta^1_1\)-random. Then there is a recursive ordinal \(\gamma < \beta\) and a \(\emptyset^{(\gamma)}\)-ML-test \(\{V_n\}_{n \in \omega}\) such that \(z \in \bigcap_{n<\omega} V_n\). Let

\(\tilde{V}_n = \{u \mid (\exists v)(v \text{ is the } k\text{-th string in } V_n \wedge (\exists p \in \mathbb{Q})(\exists q \in \mathbb{Q})(p < l(u) < r(u) < q \land \forall \sigma \sqsubseteq u (q - p < 2^{-|v|} - 2^{-n-k-2}))\}\).

Intuitively, \(\{\tilde{V}_n\}_{n<\omega}\) is a \(\Delta^1_1\)-Martin-Löf test relative to the measure \(\lambda\), where \(\lambda(\sigma) = \sum_{\tau \in C(\sigma)} 2^{-|\tau|}\) for any \(\sigma \in 2^{<\omega}\).

Since \(z \in V_n\), we have \(y \in \tilde{V}_n\) for every \(n\). Note that \(\{\tilde{V}_n\}_{n<\omega}\) is \(\emptyset^{(\gamma+1+\beta)}\)-r.e. Let

\(U_n = \{\sigma \mid (\exists \tau \in \tilde{V}_n)(|\sigma| = f(|\tau|) \land \tau \oplus \emptyset^{(\gamma)}[f(|\tau|)][f(|\tau|)] \ge \tau)\} = \bigcup_{u \in \tilde{V}_n} C(u)\).

Then \(\{U_n\}_{n<\omega}\) is \(\emptyset^{(\gamma+1+\beta)}\)-r.e and \(x \in \bigcap_{n<\omega} U_n\). Note that for every \(n\),

\(\mu(U_n) \le \mu(V_n) + \sum_{k<\omega} 2^{-n-k-2+1} < 2^{-n} + 2^{-n} = 2^{-n+1}\).

Then \(\{U_{n+1}\}_{n<\omega}\) is a \(\emptyset^{(\gamma+1+\beta)}\)-ML-test. Hence \(x\) is not a \(\Delta^1_1\)-random, a contradiction.

## 14.3.4 Exercises

**Exercise 14.3.1** (Jorhth and Nies [51]). Prove that \(x \oplus y\) is \(\Pi^1_1\)-random if and only if \(x\) is \(\Pi^1_1\)-random and \(y\) is \(\Pi^1_1(x)\)-random.

**Exercise 14.3.2** (Yu [171]). For any \(z \ge_h \emptyset\), there is a \(\Delta^1_1\)-random \(x \equiv_h z\) which is not \(\Pi^1_1\)-ML random.

**Exercise 14.3.3.** Prove that if \(x\) is \(\Pi^1_1\)-random, then for any \(\Sigma^1_1\)-set \(A\) of reals containing \(x\),

\(\lim_{n \to \infty} \frac{\mu(A \cap [x \upharpoonright n])}{2^{-n}} = 1\).
