
- (i) Range($h_p$) $\supseteq y_0 \cup \{\infty\}$;
- (ii) for any $m, f((\exists z^{>n})(\varphi(n, z^{>n}) \lor \neg \psi(n, z^{>n})) < \gamma_{m+1}$ and for any $n$ and $p_n \le p$ in $L_{\gamma_{m+1}}$, there exists a $q_n \le p_n$ with $q_n \in L_{\gamma_{m+1}}$ such that $q_n \Vdash (\exists z^{>n+1})(\varphi(n, z^{>n+1}) \lor \neg \psi(n, z^{>n+1}))$, and
- (iii) for each $m$, $\gamma_{m+1} = \omega \gamma_{m+1}$.

Let $\beta = \bigcup_{m < \omega} \gamma_m = \omega \beta$. Then $\beta < \alpha$. We claim that

$p \Vdash (\forall n)((\exists z^\beta)(\varphi(n, z^\beta) \lor \neg \psi(n, z^\beta))$.

The forcing relation is equivalent to

$(\forall n)(\forall q \le p)(\exists r \le q)(q \Vdash (\exists z^\beta)(\varphi(n, z^\beta) \lor \neg \psi(n, z^\beta))).$

Given $n$ and $q \le p$, let $q'$ be a condition such that $t'_{q'} = t_q$ and $h_{q'}(\alpha) = h_q(\alpha)$ for $h_q(\alpha) < \beta$ and $h_{q'}(\alpha) = \infty$ otherwise. By (i), $q' \le p$ and $q' \in L_{\gamma_m}$ for some $m$. By (ii), there is a condition $r' \in L_p$ such that $r' \le q'$ and

$r' \Vdash (\exists z^{\gamma_m})(\varphi(n, z^{\gamma_m}) \lor \neg \psi(n, z^{\gamma_m})).$

By (iii), Ret$(\omega\beta, q, q')$ holds and

$\omega \cdot f((\exists z^{\gamma_m})(\varphi(n, z^{\gamma_m}) \lor \neg \psi(n, z^{\gamma_m}))) < \beta.$

By Lemma 5.4.5 and Lemma 5.4.6, there is a condition $r \le q$ such that

$r \Vdash (\exists z^\beta)(\varphi(n, z^{\gamma_m}) \lor \neg \psi(n, z^{\gamma_m})).$

Hence

$r \Vdash (\exists z^\beta)(\varphi(n, z^\beta) \lor \neg \psi(n, z^\beta)).$

By Lemma 5.4.10,

$\mathfrak{A}(\alpha, T) \Vdash (\forall n)(\exists z^\beta)(\varphi(n, z^\beta) \lor \neg \psi(n, z^\beta)).$

Let $y$ be defined such that $y \in \dot{y}$ if and only if $\mathfrak{A}(\alpha, T) \Vdash (\exists z^\beta)\varphi(n, z^\beta)$. Then $y \in \mathfrak{A}(\alpha, T)$ and thus $\mathfrak{A}(\alpha^{<\omega}, T)$ satisfies $\Delta_1^\xi$-comprehension. $\square$

In summary, we have the following:

## **Theorem 5.4.12** (Sacks [122]). For any countable admissible ordinal $\alpha > \omega$, there is a real $x$ such that $\omega_1^x = \alpha$.

## **Remark 5.4.13.** In the literature, there are several proofs of Theorem 5.4.12. Sacks's original proof was by the method of perfect set forcing and provided a stronger conclusion. The second proof, due to Friedman and Jensen [31], was by an application of the Barwise Compactness Theorem [3]. The third proof, which remains unpublished, was due to Jensen [54] and uses a class of Levy collapse operations which may be viewed as a variant of Steel forcing.

## 6 Set theory

This chapter reviews results in set theory that have recursion-theoretic applications. Some of these will be stated without proof for future reference.

### 6.1 Set-theoretic forcing

The technique of forcing was discussed in the context of recursion theory in Chapter 5. The original version of the method as presented in Cohen [18] was very similar to that developed in § 5.2. Here we follow the approach of unramified forcing introduced by Shoenfield [130] (see Kunen [78] for an excellent exposition of the subject).

### 6.1.1 Forcing and genericity

Let M = (M, ∈) be a countable transitive model of ZFC and let P = (P, ≤) be a partial ordering in M. An element p ∈ P is called a condition. Given two conditions p, q ∈ P, we say that q is stronger than p if p ≤ q. D ⊆ P is dense if for any p ∈ P, there is a q ∈ D such that q ≤ p.

A filter F ⊆ P is a nonempty set such that

- (∀p)(∀q)(q ≤ p ∈ P → p ∈ F);
- (∀p)(∀q)((∃r) ∈ F ∧ q ≤ r → r ∈ F ∧ r ≤ p ∧ r ≤ q).

A generic set G ⊆ P is a filter that meets every dense set. In general, a generic set does not belong to M except for very special partial orderings. If G ∉ M, then there is a model M[G] = (M[G], ∈) of ZFC such that M ∪ {G} ⊆ M[G] and o(M) = o(M[G]). This is defined as follows.

First, a P-name in M is defined by induction:

- ∅ is a P-name;
- if τ ⊆ the set of P-names × P, then τ is a P-name.

We use M^P to denote the class of P-names. Note that M^P ⊂ M and is not a member of M. Suppose G is generic. Define val(τ, G) by induction:

- if τ is not a P-name, then val(τ, G) = τ;
- otherwise, val(τ, G) = {val(σ, G) | (σ, p) ∈ τ ∧ p ∈ G}.

Let

```
M[G] = {val(τ, G) | τ ∈ M}.
```

Thus every element x ∈ M[G] has a corresponding P-name. We use ẋ to denote the P-name of x. We use ȧ to denote ⟨⟨ḃ, p⟩ | b ∈ a ∧ p ∈ P⟩ for any a ∈ M by induction on the rank of \(a\). Since for any \(a \in M\), \(\text{val}(\tilde{a}, G) = a\), we have \(M \subseteq M[G]\). Moreover \(\tilde{G} = \{(\check{p}, p) \mid p \in \mathbf{P}\}\) is a \(\mathbf{P}\)-name and \(\text{val}(\tilde{G}, G) = G\). Hence \(G \in M[G]\). \(\langle M[G], \in \rangle\) is a transitive model of ZFC and \(o(M) = o(M[G])\).

**Definition 6.1.11.** Given a condition \(p \in \mathbf{P}\) and a formula \(\varphi(\tau_0, \dots, \tau_n)\) with \(\tau_0, \dots, \tau_n \in M^\mathbf{P}\), we say that \(p\) *forces* \(\varphi(\tau_0, \dots, \tau_n)\), or \(p \Vdash \varphi(\tau_0, \dots, \tau_n)\), if and only if for any generic set \(G\) with \(p \in G\), \(\langle M[G], \in \rangle \models \varphi(\text{val}(\tau_0, G), \dots, \text{val}(\tau_n, G))\).

**Theorem 6.1.2.** (i) The class \(\langle p, \varphi, (\tau_0, \dots, \tau_n) \rangle \mid p \Vdash \varphi(\tau_0, \dots, \tau_n)\rangle\) is definable in \(\mathfrak{M}\); (ii) for every generic \(G\) and formula \(\varphi(\tau_0, \dots, \tau_n)\) with \(\tau_0, \dots, \tau_n \in M^\mathbf{P}\), \(\langle M[G], \in \rangle \models \varphi(\text{val}(\tau_0, G), \dots, \text{val}(\tau_n, G)) \Leftrightarrow (\exists p \in G)(p \Vdash \varphi(\tau_0, \dots, \tau_n))\).

Theorem 6.1.2 is not surprising when taken together with the definition of \(\Vdash\) in §5.2 (see [78]). The following facts about the forcing relation are standard.

**Proposition 6.1.3.** For any formula \(\varphi\), condition \(p\) and \(\mathbf{P}\)-names \(\tau_0, \dots, \tau_n\), (i) \(q \le p \land p \Vdash \varphi \implies q \Vdash \varphi\); (ii) \(p \Vdash \varphi \land \psi\) if and only if \(p \Vdash \varphi\) and \(p \Vdash \psi\); (iii) \(p \Vdash \neg \varphi\) if and only if \((\forall q \le p) q \not\Vdash \varphi\); (iv) the set \(\{p \mid p \Vdash \neg \varphi \lor p \Vdash \varphi\}\) is dense; (v) \(p \Vdash (\exists x)\varphi(x)\) if and only if the set \(\{q \mid q \le p \text{ and } \exists \tau (q \Vdash \varphi(\tau))\}\) is dense; (vi) \(p \Vdash (\exists x)\varphi(x)\) if and only if there is a \(\mathbf{P}\)-name \(\tau \in M^\mathbf{P}\) such that \(p \Vdash \varphi(\tau)\).

### 6.1.2 \(\kappa\)-chain condition and Martin's Axiom

Given a partial ordering \(\mathbf{P} = (\mathbf{P}, \le)\), a set \(A \subseteq \mathbf{P}\) is an *antichain* if for \(p \neq q\) in \(A\), there is no \(r\) satisfying \(r \le p\) and \(r \le q\). \(\mathbf{P}\) has the \(\kappa\)-*chain condition*, or \(\kappa\)-c.c., if in \(\mathfrak{M}\) every antichain of \(\mathbf{P}\) has cardinality less than \(\kappa\). In particular, \(\omega_1\)-c.c. is known as the countable chain condition, or c.c.c. A chain condition restricts the possible values of a function in a generic extension. In fact, chain conditions are used as basic tools for the preservation of cardinals in a generic extension. For example, if \(\mathbf{P} = (\mathbf{P}, \le)\) satisfies c.c.c. and \(f : \omega \to (\omega_1)^{\mathbf{M}}\) is a function in \(\mathbf{M}[G]\) for some generic \(G\), then for every \(n < \omega\), the set \(A_n = \{(\alpha, \omega_1)^{\mathbf{M}} \mid (\exists p)(p \Vdash f(\check{n}) = \check{\alpha})\} \in \mathbf{M}\) is countable in \(\mathfrak{M}\) so that \(\bigcup_n A_n \in \mathbf{M}\) is also countable in \(\mathfrak{M}\). Thus \(\mathbf{P}\) does not collapse \((\omega_1)^{\mathbf{M}}\).

**Lemma 6.1.14.** If \(\mathbf{P}\) *has the* \(\kappa\)*-chain condition*, then for any generic set \(G\), \((\kappa)^{\mathbf{M}} = (\kappa)^{\mathbf{M}[G]}\).

**Definition 6.1.5** (Martin's Axiom [90]). Let \(\kappa\) be a cardinal. \(\text{MA}_\kappa\) states that for any c.c.c. partial ordering \(\mathbf{P} = (\mathbf{P}, \le)\) and any \(\kappa\)-sequence of dense sets \(\{D_\alpha\}_{\alpha < \kappa}\), there is a filter \(G \subseteq \mathbf{P}\) that meets every \(D_\alpha\). We use \(\text{MA}\) to denote \((\forall \kappa < 2^{\aleph_0})\text{MA}_\kappa\).
