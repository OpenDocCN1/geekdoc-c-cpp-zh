Proof. (i) is immediate. (ii) is true since for any number $l$, there are only finitely many $m \le l$ such that $l <_o m <_o n$. (iii) is true since $<_o$ is a recursive relation over the recursive set $\{i \mid i <_o n\}$.

We prove (iv). If $m = 3 \cdot 5^k <_o n$ and $|m| = \lim_{i \to \infty} \beta_i$ where $\{\beta_i\}$ is an increasing sequence of limit ordinals, then for any $i$ there is an $m' = 3 \cdot 5^{k'} <_o m$ with $|m'| > \beta_i$ such that whenever $m' = 3 \cdot 5^{k'} <_o m$ with $|m'| > |m''|$, we have $m' > m''$. Hence $|i_{0,m'}| > |m''|$.

The main difficulty when extending Theorem 11.2.2 to arbitrary levels of recursive ordinals concerns coding at limit ordinal stage. Here, as in the proof of Theorem 11.2.2, at each successor stage one attempts to carry out a stepdown construction that codes information computed at a limit level. There is no difficulty dealing with only one limit ordinal. With more than one limit ordinal, one of them has to be chosen for coding. Lemma 11.2.7 allows the use of nice sequences in the approximation of limit ordinals to facilitate the choice.

For convenience, in the rest of this section let $[n] = \beta_{\infty}$ and identify each natural number $\le_o n$ with the ordinal $\beta < \beta_{\infty}$ of which it is an ordinal notation. In particular, we use $\lambda$ for natural numbers which are ordinal notations of limit ordinals. Also $\beta_{j,\lambda} = |i_{j,m}|$ for $\lambda = |m|$. We write $\theta^{(\beta)}$ and $x^{(\beta)}$ for $H_i$ and $H_i^X$ where $|i| = \beta$. Finally, $\beta^+$ is identified with $2^k$ where $|k| = \beta$.

For $\beta \le_o n$, let

$$
\Lambda(\beta) = \{\lambda \mid \beta <_o \lambda \land (\exists j \in \omega)(\beta_{j,\lambda} \le_o \beta)\}.
$$

Note that by Lemma 11.2.7, $\Lambda(\beta)$ is finite for any $\beta \le_o n$. Hence the following is well defined:

$$
j(\beta) = \max(\{0\} \cup \{j \mid (\exists \lambda \in \Lambda(\beta))(\beta_{j,\lambda} \le_o \beta)\}).
$$

For each $a \in \omega$, define the following function “specialized” to $\omega \setminus a$:

$$
p_a(\sigma) = \tau \Leftrightarrow (\forall i, j, k)(\tau(\langle j, i \rangle) = k > 0 \leftrightarrow j \notin a \land \sigma(\langle j, i \rangle) = k > 0).
$$

Then

$$
p_a(T) = \{p_a(\sigma) \mid \sigma \in T\},
$$

and

$$
p_a(\dot{X}) = x \Leftrightarrow (\forall i, j, k)(x(\langle j, i \rangle) = k > 0 \leftrightarrow j \notin a \land \dot{X}(\langle j, i \rangle) = k > 0).
$$
