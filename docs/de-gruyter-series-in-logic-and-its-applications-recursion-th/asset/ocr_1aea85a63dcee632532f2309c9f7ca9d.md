Proposition 4.3.4. For any real $x \in L$, there is a $z \in \mathbb{C}$ such that $z \geq_T x$.

Proof. Let $x \in L$. By Corollary 3.3.8, $x \in L_{a+1} \setminus L_a$ for some $a < (\omega_1)^L$. Then $x$ is $\Sigma_n(L_{a+1})$ for some $n$. By Theorem 3.4.11, there is a real $z \in L_{a+1} \setminus L_a$ which is a $\Sigma_n$-master code. Thus $ho_a^L = \omega$. By the definition of $\Sigma_n$-master code, there is a $z$-recursive well-ordering of $a$. In other words, $w_1^x > a$. Thus $z \in L_{w_1^x}$ and $x \leq_T z$.

Proposition 4.3.5. There is an $x \in \mathbb{C}$ in which every $\Pi^1_1$-singleton is recursive.

Proof. By Proposition 4.1.3, every $\Pi^1_1$-singleton is in $L$. Since $(L, \in) \vDash 	ext{ZFC}$, the statement "there are only countably many $\Pi^1_1$-singletons" is true in $L$. Hence there is a real $y \in L$ in which every $\Pi^1_1$-singleton in $L$ is recursive. By Proposition 4.3.4, $y \leq_T z$ for some $z \in \mathbb{C}$. 

Corollary 4.3.6. (i) $\mathbb{C}$ is the largest countable $\Pi^1_1$-set of reals if and only if $(\omega_1)^L < \omega_1$. (ii) There is an uncountable thin $\Pi^1_1$-set if and only if $(\omega_1)^L = \omega_1$.

Proof. (i) By Proposition 4.3.4, if $\mathbb{C}$ is countable, then $L \cap 2^\omega$ is countable. So $(\omega_1)^L$ is countable. Suppose that $(\omega_1)^L$ is countable. Then by Proposition 4.3.2, every $\Pi^1_1$-countable set of reals is a subset of $\mathbb{C}$. By Corollary 3.3.8, $\mathbb{C}$ is countable. (ii) follows from (i).

# 4.4 $\Sigma^1_2$-sets

$\Sigma^1_2$-sets and $\Pi^1_2$-sets of reals are similar in several respects. We list some of them here.

Corollary 4.4.1. $2^\omega \cap L$ is $\Sigma^1_2$.

Proof. By Proposition 4.3.4, $x \in L$ if and only if there is a $y \in \mathbb{C}$ such that $y \geq_T x$.

Proposition 4.4.2. $x \leq_L y$ is a $\Sigma^1_2$-relation.

Proof. $x \leq_L y$ if and only if $x, y \in L$ and there is a binary relation $E \subseteq \omega$ such that

+   - $(\omega, E)$ is wellfounded;
+   - $(\omega, E) \models V = L + 	ext{KP}$;
+   - $(\omega, E) \models x \leq_L y$.

Thus the relation $x \leq_L y$ is $\Sigma^1_2$.
