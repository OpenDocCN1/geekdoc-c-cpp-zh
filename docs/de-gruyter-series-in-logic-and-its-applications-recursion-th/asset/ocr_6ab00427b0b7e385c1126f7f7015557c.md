Given a standard enumeration \(\Phi_e(n, m, y)\) of partial recursive functions, there is an enumeration \(\{x_e\}_{e < \omega}\) of \(\Sigma^1_1\)-reals such that \(n \in x_e \leftrightarrow (\exists y)(\forall m)(\Phi_e(n, m, y) \downarrow \rightarrow \Phi_e(n, m, y) \neq 0)\). We have the following effective version of Spector's \(\Sigma^1_1\) boundedness principle.

# Theorem 1.5.5 (Sacks). There is a recursive function \(\hat{g}\) such that

\((\forall n)(x_n \subseteq \mathbb{O} \rightarrow \hat{g}(n) \in \mathbb{O} \wedge x_n \subseteq \mathbb{O}_{\hat{g}(n)})\),

where \(\mathbb{O}_{\hat{g}(n)} = \{m \in \mathbb{O} \mid |m| < |\hat{g}(n)|\}\).

Proof. Since the set \(\{m \mid m \notin \Pi^1_1\}\) is in \(\Pi^1_1\), there is a recursive function \(h\) such that \(m \in x_n \leftrightarrow h(m, n) \notin \mathbb{O}\). Let \(p\) be the function in Corollary 1.5.4. Define a recursive function \(f\) such that \(W_{f(n)} = \{p(h(m, n), m) \mid m \in \omega\}\). If \(x_n \subseteq \mathbb{O}\), then \(W_{f(n)} \subseteq \mathbb{O}\). Let \(\hat{g}(n) = 20^{\overline{f(n)}}\) where \(\overline{g}\) is the function in Lemma 1.3.5. By Lemma 1.3.5, \(X_n \subseteq \mathbb{O} \implies \hat{g}(n) \in \mathbb{O}\). If \(\hat{g}(n) \in \mathbb{O}\), then by Lemma 1.3.5 again, \(W_{f(n)} \subseteq \mathbb{O}\). But \(h(m, n) \in \mathbb{O}\) for all \(m \in x_n\). Then by Corollary 1.5.4, \(m \in \mathbb{O}\) for all \(m \in x_n\) and hence \(x_n \subseteq \mathbb{O}\). Moreover, if \(x_n \subseteq \mathbb{O}\), then \(m \in x_n \implies h(m, n) \notin \mathbb{O} \implies |m| \le |p(h(m, n), m)|\).

By Theorem 1.5.1, every \(\Pi^1_1\)-set is many-one reducible to \(\mathbb{O}\). Hence we may view \(\mathbb{O}\) as providing the stages for enumerating a \(\Pi^1_1\)-set (this view will become clearer after the set \(\mathbb{O}_1\) is introduced). Hence it is natural to think of a \(\Pi^1_1\)-set as analog of a \(\Sigma^0_1\) (i.e. recursively enumerable) set. Now if one considers a "finite set" to be one whose members are all enumerated by some stage \(\beta < \omega_1^{CK}\), then Spector's boundedness principle says that any \(\Delta^1_1\)-set is "finite". We shall make this precise with the introduction of admissible set theory.

In terms of definability, one would expect a big gap between possible order types of a recursive ordering and a \(\Sigma^1_1\)-ordering. The following observation says otherwise.

# Proposition 1.5.6. Suppose \(R\) is a \(\Sigma^1_1\) well-ordering relation on \(\omega\). Then \(|R| < \omega_1^{CK}\).

Proof. Suppose \(|R| \ge \omega_1^{CK}\). Then \(n \in W\mathbf{f}_0 \leftrightarrow (\exists \beta)(\forall i)(\forall j)(R_\alpha(i, j) \rightarrow R(h(i), h(j)))\). This implies that \(W\mathbf{f}_0\) is \(\Sigma^1_1\) which is a contradiction.

# Remark 1.5.7. For sets of reals, there is a boundedness principle for \(\Delta^1_1\)-sets. As discussed in §1.1.4, for each \(\Pi^1_1\)-set \(A\) of reals, there is a recursive function \(f : \omega^\omega \rightarrow \omega^\omega\) such that \(x \in A \Rightarrow f(x) \in \mathbf{wO}\). Then if \(A\) is \(\Delta^1_1\), by the same argument as in the proof of Proposition 1.5.6, the supremum \(\beta = \sup\{f(x) \mid x \in A\}\) of \(f(A)\) is less than \(\omega_1^{CK}\).

For \(\Sigma^1_1\) well-orderings of reals, by the same argument as in the proof of Corollary 1.5.2, each such well-ordering has order type less than \(\omega_1^{CK}\).
