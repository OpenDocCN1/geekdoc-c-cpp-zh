# **Question 11.3.2.** Suppose that there is a nonconstructible real. Is $L \cap \mathbb{R} \Sigma^1_1$-set?

By Theorem 11.1.10, a positive answer to Question 11.3.1 would imply a negative solution to Question 11.3.2. The latter was given a negative solution by Velickovic and Woodin:

# **Theorem 11.3.1** (Velickovic and Woodin ([66]). If the set of constructible reals is $\Sigma^1_1$, then either $\omega_1^{ck}$ is countable or every real is constructible.

On the other hand, Question 11.3.1 was answered positively by Groszek and Slaman [41] and the solution is discussed in the next section.

# **Theorem 11.3.4.** If there is a perfect set $A \subseteq (2^\omega)^L$, then every real is constructible.

# ## 11.3.2 The proof of Theorem 11.3.4

Given a tree $T \subseteq 2^{<\omega}$, a set $A \subseteq 2^\omega$ is dense in $T$ if for any $\sigma \in T$, $[\sigma] \cap T \cap A \neq \emptyset$. A real $x \in [T]$ is eventually constant in $T$ if there is an $n$ such that $x$ is the leftmost or rightmost infinite path in $[x \restriction n] \cap T$.

# **Lemma 11.3.5.** Let $T$ be a perfect tree. Suppose that $\{g_i\}_{i<\omega} \in L$ contains a dense subset of $T$ no member of which is eventually constant in $T$. Then for any $z$, there exist $x, y \in [T]$ such that $x \oplus y \oplus (\oplus_{i<\omega} g_i) \ge_T z$.

Assume Lemma 11.3.5. Let $T$ be a perfect tree such that $[T] \subseteq L$. Then $(\omega_1)^L = \omega_1$. Select a countable sequence $\{x_i\}_{i<\omega}$ from $[T]$ which is dense and such that no $x_i$ is eventually constant. Since $(\omega_1)^L = \omega_1$, there is an $x^* \in L$ such that $x_i <_L x^*$ for each $i < \omega$. Let $\{g_i\}_{i<\omega}$ be an enumeration of the set $\{x \mid x <_L x^*\}$. Note that $\{g_i\}_{i<\omega}$ belongs to $L$. By Lemma 11.3.5, for each $z$ there exist $x, y \in [T]$, and hence in $L$, such that $x \oplus y \oplus (\oplus_{i<\omega} g_i) \ge_T z$ such $z \in L$.

The idea of the proof is as follows. Suppose $z$ is a given real, $T$ is perfect and $\{g_i\}_{i<\omega} \in L$ is a sequence with a subset dense in $T$ no element of which is eventually constant in $T$. We define $x \in [T]$ and an index function $h_x : \omega \to \omega$ such that for each $i$, $h_x(i)$ is a path through $T$ that is not eventually constant in $T$. The set $x$ agrees with $g_{h_x(i)}$ on longer and longer initial segments as $i$ increases, and $z$ is coded into $x$ and $\{g_{h_x(i)}\}_{i<\omega}$ so that $z(i)$ is the value of $x$ at the first place where $x$ differs from $g_{h_x(i)}$. It is easy to see that $z \le_T x \oplus h_x \oplus (\oplus_{i<\omega} g_i)$. There is no problem to recursively define such an $x$ and $h_x$.

The challenge is to decode $h_x$. This is handled by defining another real $y \in [T]$ such that $h_x \le_T x \oplus y \oplus (\oplus_{i<\omega} g_i)$. To achieve this, we define an additional index function $h_y : \omega \to \omega$ with the same properties (except that $z$ is not coded here), in such a way that $h_x$ and $h_y$ can be computed from $x$, $y$ and $\oplus_{i<\omega} g_i$.

# **Proof of Lemma 11.3.5.** We now describe the construction of the sets $x$, $y$ and functions $h_x, h_y$.
