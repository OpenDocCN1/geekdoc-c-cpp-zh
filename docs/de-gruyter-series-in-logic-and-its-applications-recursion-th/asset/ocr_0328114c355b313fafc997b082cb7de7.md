# 12.3.6 Exercises

**Exercise 12.3.1.** Prove that there are $2^{\aleph_0}$-many recursively dominated and non-DNR reals.

**Exercise 12.3.2.** Prove that there is a recursively traceable $x$ for which $x' \le_T x \oplus \emptyset'$.

**Exercise 12.3.3.** Let $\mathcal{M}$ be a model of ZFC and let $x$ be Sacks generic over $\mathcal{M}$. Prove that if $y$ is random in $\mathcal{M}$, then $y$ is random in $\mathcal{M}[x]$.
