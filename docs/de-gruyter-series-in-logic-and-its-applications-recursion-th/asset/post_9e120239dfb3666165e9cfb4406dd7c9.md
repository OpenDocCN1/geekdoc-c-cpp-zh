## 8.2 Inductively defining \(\Pi^1_1\)-sets of reals

There is a parallel way of defining \(\Pi^1_1\)-sets of reals inductively. In [164], Engelen, Miller and Steel constructed a number of \(\Pi^1_1\)-sets of reals not based on the method of inductive definition.1 We prove some of the results here via inductive definition (see Chong and Yu [17]).

### 8.2.1 A \(\Pi^1_1\)-induction principle for reals

**Definition 8.2.1.** A binary relation \(P(x, y) \subseteq 2^\omega \times 2^\omega\) is cofinally progressive if for every real x, the set \(\{y \mid P(x, y)\}\) is cofinal in the hyperdegrees, i.e. for each z, there is a \(y \ge_h z\) such that \(P(x, y)\) holds.

Let \(\mathbb{C} = \{y \mid y \in L_{\omega_1^y}\}\).

**Lemma 8.2.2.** Assume \((2^\omega)^L = 2^\omega\). If P is \(\Pi^1_1\) and cofinally progressive, then for every x and z there is a \(y \ge_h z\) such that \(y \in \mathbb{C}\) and \(P(x, y)\).

**Proof.** Suppose \((2^\omega)^L = 2^\omega\) and P is cofinally progressive. Then for any reals x, z, the set \(A = \{y \mid x \oplus z \in L_{\omega_1^y}, A(x, y)\}\) is a nonempty \(\Pi^1_1(\{x \oplus z\})\)-set. By Theorem 4.1.2 there is a \(y \in A\) such that \(y \in L_{\omega_1^{y[x]}}[x \oplus z]\). Since \(x \oplus z \in L_{\omega_1^y}\), we have \(x \oplus z \le_h y\) and so \(\omega_1^{x \oplus z} = \omega_1^y\). Then \(y \in L_{\omega_1^{y[x]}}[x \oplus z] = L_{\omega_1^y}\) and \(P(x, y)\) holds.

Given a countable set A of reals and a real x, we say that x codes A if \(\{(y)_n \mid n < \omega\} = A\) where \((x)_n = \{m \mid m < \omega \wedge (n, m) \in x\}\).

A cofinally progressive relation generates a progressive relation as follows: Let \(P(x, y)\) be cofinally progressive. For each \(X \in 2^\omega\), let \(Q(X) = X \cup \{y \mid (\exists x \in X)P(x, y)\}\). Then it is immediate that \(Q(X) \supseteq X\) for all X. However, an operation such as Q may be too general to be useful and that motivates a refinement of Q to one that is similar to a uniformization function for well-defined sets. Now if \(P(x, y)\) is \(\Pi^1_1\), then Theorem 4.2.1 guarantees the existence of a uniformization function for P. However, our interest is in strong uniformization, i.e. a function that uniformizes “initial segments of reals” that does roughly the following: if X codes a set of reals in \(\epsilon\) such that any two elements \(w <_L z\) in x satisfy P(w, z), then there is a “least” \(y \in \epsilon\) such that \(x \le y\) and P(x, y) holds. This strong uniformization property enables one to implement an inductive construction which is made precise by the \(\Pi^1_1\)-inductive principle \(\exists\) defined as follows:

\(\Pi^1_1\)-inductive principle 3. If P(x, y) is \(\Pi^1_1\) and cofinally progressive, then there is a \(\Pi^1_1\)-set \(A \subseteq \epsilon\) such that:

- (i) \(|\le_L| A\), the height of \(\le_L\) restricted to A, is \(\omega_1\);
- (ii) \((\forall y)(y \in A \to (\exists x)(x \in L_{\omega_1^y} \wedge x \text{ codes the set } \{z \mid z \in A \wedge z <_L y\} \wedge P(x, y)))\).

**Theorem 8.2.3** (Chong and Yu [17]). V = L implies \(\exists\).

**Proof.** Suppose V = L, and P is \(\Pi^1_1\) and cofinally progressive. Recall that for each constructibly countable \(\beta\), there is an \(\alpha > \beta\) such that \((L_{\alpha+1} \setminus L_\alpha) \cap 2^\omega \neq \emptyset\). Given ordinals \(\beta < \alpha\) and \(X \subseteq \alpha \omega\), denote by \(X[\beta]\) the real \(n \mapsto (\beta, n) \in X\). We may regard X as a sequence of reals of length \(\alpha\).

Since P is \(\Pi^1_1\), by the Spector–Gandy Theorem (3.71) there is a \(\Sigma_0\)-formula \(\psi(x, y, s)\) such that

\(P(x, y) \Leftrightarrow (L_{\omega^{xy}}[x, y], \in) \models (\exists s)\psi(x, y, s).\)

Assume V = L. We define a partial function F which we will show to be total on \(\omega_1 \times \bigcup_{\alpha < \omega_1} 2^{\alpha \omega}\). For \(\alpha < \omega_1\), \(z \in 2^\omega\) and \(X \subseteq \alpha \omega\), let \(\omega_1^{X,z}\) be the least ordinal \(\gamma\) such that \(L_\gamma[X, z]\) is admissible. We define \(F(\alpha, X)\) to be the real z such that \(L_{\omega_1^{X,z}}[X, z]\) satisfies the following properties:

- (1) there is a \(\beta \ge \alpha\) such that \(z \in L_{\beta+1} \setminus L_\beta\);
- (2) there is an \(x \in L_{\omega_1^{X,z}}\) which codes X;
- (3) there is a limit ordinal \(\gamma\) and an element \(s \in L_\gamma\) such that \(L_\gamma[X, z] \models \psi(x, z, s)\);
- (4) if \((t, y) \prec_L (s, z, y)\), then \((L_\mu[X, y], \in) \models \psi(x, y, t)\) implies \(\omega_1^{(X,y)} < \beta\);
- (5) if \((t, y) \prec_L (s, z, y)\) and \((L_\mu[X, y], \in) \models \psi(x, y, t)\), then either no real \(t \in L_{\omega_1^{X,y}}\) codes X or \(y \in L_{\omega_1^{(t,y)}}\).

Since \(L_{\omega_1^{X,z}}[X, z] = L_{\omega_1^{X,z}} \prec_L\) is uniformly \(\Delta_1\) in \(L_{\omega_1^{X,z}}[X, z]\). Moreover, (4) implies that (5) is \(\Sigma_1\) in \(L_{\omega_1^{X,z}}[X, z]\). We show that \(F(\alpha, X)\) is defined for \(\alpha < \omega_1\) if X is countable.

Fix (a, X). Since V = L, there is a countable \(\gamma' > \alpha\) with a real \(x \in L_{\gamma'}\) coding X. Since P is cofinally progressive, by Lemma 8.2.2 there is a \(\beta > \gamma'\) such that \((L_{\beta+1} \setminus L_\beta) \cap 2^\omega \neq \emptyset\), and a real \(z \in L_{\beta+1} \setminus L_\beta\) such that \(x \in z \prec \omega_1^{X,z} \models \psi(x, z, s)\) for some limit ordinal \(\gamma < \omega_1^z\) and \(s \in L_\gamma\). Note that \(L_{\omega_1^z} = L_{\omega_1^{X,z}}[X, z]\) and \(\gamma' = L_\gamma[X, z]\) for all sufficiently large \(\gamma' < \omega_1^z\). Hence (1)–(3) are satisfied. Clearly we can assume that \((s, z, y)\) is the \(<_L\)-least satisfying these properties. Thus (4) and (5) are satisfied as well. By the absoluteness of \(<_L\), one concludes that F is a well-defined function on each \((\alpha, X)\), where \(\alpha < \omega_1\) and X is countable.

Observe that (1)-(4) are \(\Sigma_1\)-statements. By (4), one verifies that (5) is a \(\Delta_1\)-statement. Hence there is a \(\Sigma_0\)-formula \(\varphi(a, X, z, s)\) such that
\(F(a, X) = z \Leftrightarrow L_{\omega_1^X}[X, z] \models (\exists s)\varphi(a, X, z, s).\)

Thus we may perform transfinite induction on \(\alpha\) to define a sequence \(\{z_\alpha \mid \alpha < \omega_1\}\) using \(F\). However, the resulting sequence yields in general a set of reals that is \(\Sigma_1\) over \(L_{\omega_1}\), i.e. \(\Sigma_1^1\) but not necessarily \(\Pi^1_1\) over second order arithmetic. To ensure that \(\Pi^1_1\)-ness is achieved, we refine the approach as follows.

Define \(G(a) = z\) if and only if \(a < \omega_1^X\) and there is a function \(f : a + 1 \to 2^\omega\) with \(f \in L_{\omega_1}[z]\) so that for all \(\beta \le a, f(\beta) = F(\beta, \{\langle \gamma, n \rangle \in f(\gamma) \mid \gamma < \beta\})\) and \(f(a) = z\). Since \(L_{\omega_1}[z]\) is admissible, \(f(\gamma) \mid y \le \alpha \in L_{\omega_1}[z]\). Hence \(G(a) = z\) if and only if there is a function \(f : a + 1 \to 2^\omega\) with \(f \in L_{\omega_1}[z]\) such that
\(\langle L_{\omega_1^\gamma}[z], \in \rangle \models (\forall \beta \le a)(\exists s \in \rho)(\beta, \langle \gamma, n \rangle \in f(\gamma) \land \gamma < \beta \land s, f(\beta)) \land f(a) = z.\)

Since \(L_{\omega_1^\gamma}[z]\) is admissible, \(G\) is \(\Sigma_1\)-definable. In other words, \(G(a) = z\) if and only if there is a function \(f : a + 1 \to 2^\omega\) with \(f \in L_{\omega_1}[z]\) such that
\(\langle L_{\omega_1^\gamma}[z], \in \rangle \models ((\exists \beta)(\forall \beta \le a)(\exists s \in \rho)(\beta, \langle \gamma, n \rangle \in f(\gamma) \land n \in f(\gamma) \land \gamma < \beta \land s, f(\beta))) \land f(a) = z.\)

Let \(A\) be the range of \(G\). Then \(z \in A\) if and only if there exists an ordinal \(a < \omega_1^Y\) and a function \(f : a + 1 \to 2^\omega\) with \(f \in L_{\omega_1}[z]\) such that
\(\langle L_{\omega_1^\gamma}[z], \in \rangle \models ((\exists \beta)(\forall \beta \le a)(\exists s \in \rho)(\beta, \langle \gamma, n \rangle \in f(\gamma) \land n \in f(\gamma) \land \gamma < \beta \land s, f(\beta))) \land f(a) = z.\)

Hence \(A\) is \(\Pi^1_1\).

All that remains is to use an argument as that for Theorem 3.1.8 to show that \(G\) is a well-defined total function on \(\omega_1\). The only nontrivial part is to prove that the function \(f\) defined above exists. This can be done by induction. Let \(a < \omega_1\) be given and suppose that \(\{f_\beta\}_{\beta < a}\) is a uniformly \(\Sigma_1\) and increasing (i.e. \(f_\beta \subset f_\gamma\) for \(\beta > \gamma\)) sequence such that each \(f_\beta\) is an \(f\) at stage \(\beta < a\) as required. Let \(f_a\) be such that \(f_a \in L_{\omega_1}[z]\) and for all \(\beta \le a, f_a(\beta) = F(\beta, \{\langle \gamma, n \rangle \mid n \in f_\beta(\gamma) \land \gamma < \beta\})\) and \(f_a(a) = z\), where \(F(a, X) = z\) and \(X = \{\langle \gamma, n \rangle \mid \exists \beta(\gamma < \beta \land a \in n \in f_\beta(\gamma))\}\). Note that \(X = \{\langle \gamma, n \rangle \mid \gamma \le a \land n \in f_\gamma(\gamma)\}\) by absoluteness. Then \(f_a \supset f_\beta\) for all \(\beta < a\) and satisfies the requirement of such an \(f\) at stage \(a\).

By (1) and (2) above, \((x, z) \in L_Y\) and \(L_Y \in L_{\omega_1}\). So \(A \subset C\). Since P is cofinally progressive, (i) of the definition of I is satisfied.

For (ii), if \(y \in A\) then \(y = G(a)\) for some \(a < \omega_1\). By the definition of \(G\), there is a real \(x \in L_{\omega_1^{G(a)}}\) such that \(x\) codes the set \(\{G(\beta) \mid \beta < a\}\) and \(P(x, G(a))\) holds. Clearly \(\beta < a\) if and only if \(G(\beta) <_L G(a)\). Hence (ii) holds.

It turns out that the \(\Pi^1_1\)-inductive principle \(\mathcal{I}\) is equivalent to the set-theoretic assumption \((\omega_1)^L = \omega_1\), as we now show.
