At stage $s + 1$, suppose that $l_{	au_i}(m_2 + s)$ is defined and $|	au_i^s| = l_{	au_i}(m_2 + s)$ (hence $l_{	au_i}(m_2 + s + 1)$ is undefined) for $i = 0, 1$.

Case 1. $x(s) = 0$. Then by the assumption on $u$ and Lemma 7.5.3, let $r_{	au_{s+1}}^0 > r_{	au_s}^0$ so that $l_{	au_i}(m_2 + s + 1)$ is defined and $|	au_i^s| = l_{	au_i}(m_2 + s)$. Let $	au = (	au_{s+1}^0)^\frown (l_{	au_i}(m_2 + s + 1) + 1)$. By the assumption on $u$ and Lemma 7.5.3 again, let $r_{	au_{s+1}} > 	au$ so that $l_{	au_{s+1}}^r(m_2 + s + 1)$ is defined and $|	au_i^r| = l_{	au_i}(m_2 + s + 1)$. Note that by the assumption on $u$, there is an $h > r_{	au_{s+1}}^1$ in $H_{e_1, m_1}$. Hence by Lemma 7.5.3,

$l_{	au_{s+1}}^r(m_2 + s + 1) = l_0(m_2 + s + 1) \ge h(m_2 + s + 1) = l_{	au_{s+1}}^0(m_2 + s + 1) + 1 > l_{	au_{s+1}}^0(m_2 + s + 1)$.

Case 2. $x(s) = 1$. Do the same construction as in Case 1 but replace 0 by 1. We have

$l_{	au_{s+1}}^1(m_2 + s + 1) < l_{	au_{s+1}}^0(m_2 + s + 1)$.

Let $h_i = igcup_s 	au_i^s$ and $x_i = \pi(h_i) \in [T]$ for $i \le 1$. Then $x_0 \equiv_T x_1 \equiv_T T$. Let $l_i$ be $l^{	au_i}$ for $x_i$ as defined in Lemma 7.5.2. Then $l_i \le_T \Phi_{e_0}^{x_i}$ for $i \le 1$. Moreover,

(vii)($(l_i(m+i+1) > l_0(m+i+1)) \Leftrightarrow x(i) = 0$) $\wedge$ ($(l_i(m+i+1) < l_0(m+i+1)) \Leftrightarrow x(i) = 1$)).

Hence $T \equiv_T x \le_T \Phi_{e_0}^{x_0} \oplus \Phi_{e_0}^{x_1}$.

The completes the proof of Theorem 75.1.
