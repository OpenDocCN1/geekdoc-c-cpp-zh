# 8 The construction of $\Pi^1_1$-sets

As seen in the previous chapters, inductive definition plays a key role in hyperarithmetic theory. In fact Gandy (see [106]) held the view that inductive definition rather than computation constituted the core characteristic of any generalized recursion theory. Admissible set theory (Chapter 3) reinforces the line of thought. Here we discuss inductive definition in greater detail and present some applications of this notion to the construction of $\Pi^1_1$-sets. The reader is referred to [47] and [106] for more on this subject.

# 8.1 An introduction to inductive definition

# 8.1.1 Inductive definability

Definition 8.1.1. Let $\Gamma : 2^\omega \to 2^\omega$ be a function.

+   - $\Gamma$ is progressive if $x \in \Gamma(x)$ for every $x \in 2^\omega$;
+   - $\Gamma$ is monotonic if $\Gamma(y) \subseteq \Gamma(x)$ if $y \subseteq x$.

Given a function $\Gamma : 2^\omega \to 2^\omega$, let

```
$\Gamma_0 = \emptyset;$
$\Gamma_{\alpha+1} = \bigcup \Gamma(\Gamma_\alpha) \cup \Gamma_\alpha;$
$\Gamma_\lambda = \bigcup_{\beta < \lambda} \Gamma_\beta$ if $\lambda$ is a limit ordinal;
$\Gamma_\infty = \bigcup_\alpha \Gamma_\alpha.$
```

A real $x \in 2^\omega$ is inductively defined by $\Gamma$ if $x = \Gamma_\infty$. We use $|\Gamma|$ to denote the least ordinal $\alpha$ such that $\Gamma_\alpha = \Gamma_\infty$. Note that $|\Gamma| < (2^{\aleph_0})^+$. It is not difficult to see that for any real $x$, there is a function $\Gamma : 2^\omega \to 2^\omega$ such that $x$ is inductively defined by $\Gamma$ (Exercise 8.1.1).

Theorem 8.1.2 (Gandy). Suppose that $\Gamma$ is a progressive function such that the set $\{(n, x) \in \omega \times 2^\omega \mid n \in \Gamma(x)\}$ is $\Pi^1_1$. Then $|\Gamma| \le \omega_1^{CK}$ and $\Gamma_\infty$ is $\Pi^1_1$.

Proof. By Theorem 3.1.8, there is a $\Sigma_1(L_{\omega_1^{CK}})$-definable function $f : \omega_1^{CK} \to L_{\omega_1^{CK}}$ such that $f(\beta) = \Gamma_\beta$ for $\beta < \omega_1^{CK}$. Let $x$ be a real such that

```
$n \in x \leftrightarrow (\exists \beta < \omega_1^{CK})(n \in f(\beta))$.
```

Note that $x = \Gamma_{\omega_1^{CK}}$. Moreover $x$ is $\Sigma_1$-definable in $(L_{\omega_1^{CK}}, \in)$ and hence $\Pi^1_1$. Let $R$ be a recursive predicate such that for any $i$,

```
$i \in \Gamma(x) \leftrightarrow (\forall j) R(i, x \mid j)$.
```
