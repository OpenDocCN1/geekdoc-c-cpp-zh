# ## 8.2 Inductively defining \(\Pi^1_1\)-sets of reals

There is a parallel way of defining \(\Pi^1_1\)-sets of reals inductively. In [164], Engelen, Miller and Steel constructed a number of \(\Pi^1_1\)-sets of reals not based on the method of inductive definition.1 We prove some of the results here via inductive definition (see Chong and Yu [17]).

# ### 8.2.1 A \(\Pi^1_1\)-induction principle for reals

**Definition 8.2.1.** A binary relation \(P(x, y) \subseteq 2^\omega \times 2^\omega\) is cofinally progressive if for every real x, the set \(\{y \mid P(x, y)\}\) is cofinal in the hyperdegrees, i.e. for each z, there is a \(y \ge_h z\) such that \(P(x, y)\) holds.

Let \(\mathbb{C} = \{y \mid y \in L_{\omega_1^y}\}\).

**Lemma 8.2.2.** Assume \((2^\omega)^L = 2^\omega\). If P is \(\Pi^1_1\) and cofinally progressive, then for every x and z there is a \(y \ge_h z\) such that \(y \in \mathbb{C}\) and \(P(x, y)\).

**Proof.** Suppose \((2^\omega)^L = 2^\omega\) and P is cofinally progressive. Then for any reals x, z, the set \(A = \{y \mid x \oplus z \in L_{\omega_1^y}, A(x, y)\}\) is a nonempty \(\Pi^1_1(\{x \oplus z\})\)-set. By Theorem 4.1.2 there is a \(y \in A\) such that \(y \in L_{\omega_1^{y[x]}}[x \oplus z]\). Since \(x \oplus z \in L_{\omega_1^y}\), we have \(x \oplus z \le_h y\) and so \(\omega_1^{x \oplus z} = \omega_1^y\). Then \(y \in L_{\omega_1^{y[x]}}[x \oplus z] = L_{\omega_1^y}\) and \(P(x, y)\) holds.
