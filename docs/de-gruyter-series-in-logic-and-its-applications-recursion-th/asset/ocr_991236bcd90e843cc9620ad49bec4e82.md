Given \(x\) and \(y\), we say that \(x \equiv_M y\) via \((e_0, e_1)\) if there are two recursive functions \(\Phi_{e_0}\) and \(\Phi_{e_1}\) such that for any \(n\),

+   - \(n \in y \Leftrightarrow \Phi_{e_0}(n) \downarrow \in x\); and
+   - \(n \in x \Leftrightarrow \Phi_{e_1}(n) \downarrow \in y\).

# **Lemma 7.2.2.** Assume ZF+AD+DC. If \(F\) and \(G\) are increasing uniformly degree invariant functions via \(t\) such that \(F <_M G\), then \(F' \le_M G\).

Proof. Suppose that \(F <_M G\) on the cone \([x \mid x \ge_T z_0]\) but \(F' \not\le_M G\). Let \(p : 2^{<\omega} \to \omega\) be a recursive bijection and for any \(x\), let \(G_1(x) = y\) where

\(y = \{n \mid (\forall m)(p(G(x) \mid m) \neq n)\}.\)

Then for each \(x\), \(G_1(x) \equiv_T G(x)\). Moreover, since \(G\) is uniformly degree invariant, so is \(G_1\).

We apply the same method as that in Lemma 7.2.1. Define \(A \subseteq \omega^\omega\) such that \(x_0 \oplus x_1 \in A\) if and only if either \(x_1^t \notin 2^\omega\) or

+   - \(x_0^t \in 2^\omega\);
+   - \(\Phi_{e_1}^{x_0^t} = x_1^t\) where \(x_0(0) = (e_0, n_0)\), and
+   - either \(\Phi_{e_1}^{x_1^t} \neq x_0^t\) or \(n \in F'(x_0^t) \Leftrightarrow n_1 \notin G_1(x_1^t)\), where \(x_1(0) = (e_1, n_1)\).

A game \(\mathcal{G}_A\) is played by the two players I and II. As in Lemma 7.2.1, if II has a winning strategy for \(\mathcal{G}_A\), then \(F' \le_M G_1\) which is a contradiction.

Hence I has a winning strategy \(\vartheta\) for \(\mathcal{G}_A\). Fix \(y \ge_T \vartheta \oplus z_0 \oplus t\). By the Recursion Theorem relativized to \(y\), for each \(m\) there is an \(e_m^t\) such that \(\Phi_{e_m^t} = (\partial(x_1^m))'\) where \(x_1^m = (e_m^m, m) \cdot y\). Note that the function \(m \mapsto e_1^m\) is recursive. Let \(x_0^m = \partial(x_1^m)\) and \(x_0^m(0) = (e_0^m, n_0^m)\). The function \(m \mapsto (e_0^m, n_0^m)\) is \(y\)-recursive. Since \(\vartheta\) is a winning strategy for I, \(\Phi_{e_0^m}^{x_1^m} = y\) and

\(n_0^m \in F'((x_0^m)^t) \Leftrightarrow m \notin G_1(x_1^t) = G_1(y).\)

Note that \((x_0^m)^t \equiv_T y\) via \((e_0^m, e_0^m)\). We then have \(F((x_0^m)^t) \equiv_T F(y)\) via \(t(e_0^m, e_1^m) = (i_0^m, i_1^m)\). Since \(t \le_T y\) and \(m \mapsto (e_0^m, e_0^m)\) is \(y\)-recursive, the function \(m \mapsto (i_0^m, i_1^m)\) is \(y\)-recursive as well. Hence there is a \(y\)-recursive function \(m \mapsto (j_0^m, j_1^m)\) such that \(F'((x_0^m)^t) \equiv_m F(y)\) via \((j_0^m, j_1^m)\). Thus for any \(m\), one may \(y\)-recursively find \(x_0^m\) and an \(j_1^t\) such that

\(F'(y)(\Phi_{j_1^t}(n_0^m)) = F'((x_0^m)^t)(n_0^m) = 1 - G_1(y)(m).\)

Since \(F(y) \ge_T y\), the set \(E_1 = \{m \mid F'(y)(\Phi_{j_1^t}(n_0^m)) = 1\}\) is infinite and \(F(y)\cdot\) r.e. Let \(E_2 \subseteq E_1\) be infinite \(F(y)\)-recursive. Then for any \(m \in E_2\), there is an \(n_m\) such that \(p^{-1}(m) = G_1(y) \downarrow n_m\). Thus \(G(y) \le_T F(y)\) and so \(G \le_M F\), contradicting the hypothesis.

We conclude that \(F' \le_M G\).
