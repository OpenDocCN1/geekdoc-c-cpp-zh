Since for each \(i \le 1\) and \(\alpha < \omega_1^{CK}\), \((x_i, f_i)\) is a path on \(T_i[a]\), one may use \(x_0 \oplus x_1\) to approximate the values of \(f_0(s)\) and \(f_1(s)\) by simulating in \(T_i[a]\) the construction of \(x_i\). Using \(x_0 \oplus x_1\), one may mimic the construction of \(\langle \langle 0_{i,s}, \tau_{i,s} \rangle \rangle_{s \le \omega}\) to define \(\langle \langle \alpha_{i,s+1}[a], \tau_{i,s}[a] \rangle \rangle_{s \le \omega}\) for \(i \le 1\), so that \(\alpha_{i,s+1}[a]\) is an initial segment of \(x_i\) (in ascending order of length) and a local splitting node over \(\langle \alpha_{i,s}[a], \tau_{i,s}[a] \rangle\) in \(T_i[a]\).
