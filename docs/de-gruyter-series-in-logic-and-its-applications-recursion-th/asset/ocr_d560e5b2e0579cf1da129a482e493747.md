+   (1) \(\Phi_\epsilon\) is strictly increasing in the sense of \(<_\epsilon\);
+   (2) for each \(j_0\) and \(m\), if \(\Phi_\omega(j_0) \le_m n <_\epsilon \Phi_\omega(j_0 + 1)\), then there is a \(j_1 \in \Theta\) such that \(m = \Phi_\epsilon(j_0) \vdash_\epsilon j_1\).

Since \(n <_o m\) implies \(\Phi_\epsilon(n) <_o \Phi_\epsilon(m)\), \(<_o\) is a well-ordering on \(O\). Note that for any \(n \in O, |n| \le |\Phi_\epsilon(n)|\). Hence \(\Phi_\epsilon : \{n \in O \mid n <_\epsilon \cdot\} \to O\) is an embedding and hence \(<_\epsilon\) is a well-ordering of order type \(\omega_1^{CK}\) on \(O\). By performing induction over the standard ordinal notations \(<_\epsilon\) below \(i\), one easily sees that \(O\) is \(<_\epsilon\)-downward closed.

By Theorem 1.3.4, there is a recursive function \(g_1\) such that \(W_{g_1(n)} = \{j \mid j <_o n\}\) for any \(n \in O\). We claim that \(W_{g_1(n)}\) is a recursive set when restricted to \(n \in O\). It will then follow that the set \(\{(j, k) \mid j <_k n <_o n\}\) is recursive as well.

By an effective transfinite induction together with an application of the Recursion Theorem, we will define a partial recursive function \(q\) such that \(W_{q(n)} = \omega \setminus W_{g_1(n)}\) for \(n \in O\). The case \(n = 2^k\) and \(\Phi_\epsilon(n) = 2^{\Phi_\epsilon(k)}\) is left to the reader as an exercise (Exercise 2.6.1). Suppose \(n = 3 \cdot 5^k\) and \(\Phi_\epsilon(k - 5^k) = 3 \cdot 5^w\), where \(w\) is as defined earlier, and \(e\) is given such that \(\Phi_e(\Phi_\epsilon(j))\) is defined for each \(j < \omega\). First note that an induction on \(j\) shows that \(\Phi_\omega(j) \ge j\). If for each \(j\), \(W_{\Phi_\epsilon(\Phi_\epsilon(j))} = \omega \setminus W_{g_1(\Phi_\epsilon(j))}\), then we claim

\(m \in \bigcup_{j < \omega} W_{g_1(\Phi_\epsilon(j))} \iff (\exists j_0 \le m)(m \in W_{g_1(\Phi_\epsilon(j_0+1))}).\)

The proof of the claim from right to left is immediate. For the other direction, let \(j_0\) be such that \(\Phi_\omega(j_0) \le_0 m < \Phi_\omega(j_0 + 1)\). Then by (2) there is a \(j_1 \in \Theta\) such that \(\Phi_\omega(j_0) \vdash_0 j_1 = m\). This implies that \(j_0 \le \Phi_\omega(j_0) \le m\). Since \(m \le_o \Phi_\omega(j_0 + 1)\), we have proved the Claim.

Hence \(\bigcup_{j < \omega} W_{g_1(\Phi_\epsilon(j))} = \omega \setminus \bigcap_{j < \omega} \Phi_\omega(\Phi_\epsilon(j))\) is recursive. Now this calculation is uniform, and hence there is a recursive function \(g_2\) such that if \(W_{\Phi_\epsilon(\Phi_\epsilon(j))} = \omega \setminus W_{g_1(\Phi_\epsilon(j))}\) for every \(j\), then \(W_{g_2(e,w)} = \bigcap_{j < \omega} W_{\Phi_\epsilon(\Phi_\epsilon(j))}\). Let \(g_3\) be a recursive function such that \(W_{g_1(e,w)} = W_e \setminus \{w\}\). Recall that if \(\Phi_\epsilon(3 \cdot 5^k) = 3 \cdot 5^w \in O\), then \(\Phi_\omega(j + 1) = \Phi_\omega(j) \vdash_o \Phi_\epsilon(j + 1)\). Let \(W_{c_1} = \omega\).

Define a recursive function \(h_1\) as follows:

\(\Phi_{h_1(e)}(n) = \begin{cases} c_1 & n=1, \\ g_3(\Phi_e(m), m) & n=2^m, \\ g_2(e, w) & n=3 \cdot 5^w, \\ \uparrow & \text{Otherwise.} \end{cases}\)

By the Recursion Theorem, there is a \(d\) such that \(\Phi_{h_1(d)} = \Phi_d\). Let \(q = \Phi_d\). Then \(q\) is as required.
