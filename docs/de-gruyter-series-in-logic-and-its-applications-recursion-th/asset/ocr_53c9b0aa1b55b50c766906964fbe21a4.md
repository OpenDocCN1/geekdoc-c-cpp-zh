The rest of this section is devoted to a proof Theorem 9.3.8. We begin with the ground model \(\langle L, \in \rangle\). Let \(\mathbb{P}\) be the collection of Cohen forcing conditions. \(\mathbb{P}_{N_1}\) is the resulting product forcing with finite support of length \(N_1\).

For \(\alpha < \omega_1\), let \(\mathbb{P}_{<\alpha} = (\mathbb{P}_{<\alpha}, \le)\), where \(p \in \mathbb{P}_{<\alpha}\) if and only if \(p \in \mathbb{P}_{N_1}\) and \(\text{dom}(p) \subseteq \alpha\). The partial order on \(\mathbb{P}_{<\alpha}\) is the restriction of that on \(\mathbb{P}_{N_1}\) to \(\mathbb{P}_{<\alpha}\). Thus \(\mathbb{P}_{N_1} = \mathbb{P}_{<N_1}\). Let \(E\) be the set of limit ordinals less than \(\omega_1\). For \(\alpha < \omega_1\), let \(\omega_1^\alpha\) be the least admissible ordinal greater than \(\alpha\). Then \(\mathbb{P}_{<\alpha} \in L_{\omega_1^\alpha}\).

+   Lemma 9.3.9. There exist an uncountable set \(E_1 \subseteq E\) in \(L\) and a sequence of binary relations \(\{R_\alpha\}_{\alpha \in E_1} \in L\) such that for each \(\alpha \in E_1\),
+   - \(R_\alpha \in L\) is a binary relation on \([2^n \mid n < \omega)\) that is a well-ordering of order type \(\alpha\);
+   - for each \(\beta < \alpha\), there is a function \(f_\beta \le_T R_\alpha\) which is an isomorphism between \(R_\beta\) and an initial segment of \(R_\alpha\).

Proof. We define \(E_1\) and \(\{R_\alpha\}_{\alpha \in E_1}\) by induction on \(\alpha < \omega_1\). Let \(E_{1,0} = \emptyset\). At stage \(\alpha + 1\), suppose that \(E_{1,\alpha}\) and \(\{R_\gamma\}_{\gamma \in E_{1,\alpha}}\) have been defined. Let \(R \in L\) be a well-ordering of \(\{2^n \mid n < \omega\}\) of order type a limit ordinal greater than that of \(R_\gamma\) for \(\gamma \in E_{1,\alpha}\). Then for every \(\gamma \in E_{1,\alpha}\), there is a function \(f_\gamma\) which maps \(R_\gamma\) isomorphically onto an initial segment of \(R\). Let \(x \in L\) be a real that computes all the \(f_\gamma\)’s. Let \(E_{1,\alpha+1} = E_{1,\alpha} \cup \{\gamma_1\}\) where \(\gamma_1 = \alpha + \omega \cdot \alpha\). Let \(R^1\) be a binary relation on \(\{2^{n+1} \mid n < \omega\}\) such that for any \(n \neq m\), \((2^{n+1}, 2^{m+1}) \in R^1\) if and only if either \(n \in x\) and \(m \notin x\) or \(n \notin x \mapsto m \in x\) and \(n < m\). So \(R^1 \supseteq_T x\) in \(L\) and is a well-ordering of order type \(\omega + \omega\) on \(\{2^{n+1} \mid n < \omega\}\). Let

```
\(R_{\alpha+1} = R \cup R^1 \cup \langle (2^{2n}, 2^{2m+1}) \mid n, m \in \omega \rangle.\)
```

If \(\alpha\) is a limit ordinal, let \(E_{1,<\alpha} = \bigcup_{\gamma < \alpha} E_{1,\gamma}\) and repeat the above upon replacing \(E_{1,\alpha}\) by \(E_{1,<\alpha}\).
Let \(E_1 = \bigcup_{\beta < \omega_1} E_{1,\beta}\). Then \(E_1\) and \(\{R_\alpha\}_{\alpha \in E_1}\) are as required.

From now on, let \(E_1\) and \(\{R_\alpha\}_{\alpha \in E_1}\) in \(L\) be as above. Let \(G\) be a \(\mathbb{P}_{N_1}\)-generic set over \(L\). Then \(G\) may be viewed as an \(\omega_1\)-sequence \(\langle G_\alpha \mid \alpha < \omega_1 \rangle\) such that for every \(\alpha < \omega_1\), \(G_\alpha = \bigcup_{p \in G} p(\alpha)\) is a real. Let \(G_\alpha = \langle \langle \beta, G_\beta \rangle \mid \beta < \alpha \rangle\).

Definition 9.3.10. For any \(\gamma < \alpha \in E_1\) and any sequence \(\langle z_\beta \rangle_{\beta < \alpha}\) of reals, define the join of \(\langle z_\beta \rangle_{\beta < \gamma}\) along \(R_\alpha\) to be the set

```
\(\bigoplus_{R_\alpha} \langle z_\beta \rangle_{\beta < \gamma} = R_\alpha \nmid \{2^n \cdot 3^j \mid (\exists \beta < \gamma)(j \in z_\beta \land \beta = \text{order type of } (R_\alpha \nmid n))\}.\)
```

The following lemma says that the join operator is order preserving.

Lemma 9.3.11. For any \(\beta_1 \le \beta_2 \le \alpha_1 \le \alpha_2 \in E_1\),

```
\(\bigoplus_{R_{\beta_2}} \langle G_\gamma \rangle_{\gamma < \beta_1} \le_T \bigoplus_{R_{\alpha_2}} \langle G_\gamma \rangle_{\gamma < \alpha_1}.\)
```
