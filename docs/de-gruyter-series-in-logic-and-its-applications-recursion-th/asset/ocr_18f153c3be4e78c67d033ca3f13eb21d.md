The following is an analog of the Spector–Gandy Theorem for \(\Sigma^1_2\)-sets.

**Proposition 4.4.3.** A set \(A \subseteq 2^\omega\) is \(\Sigma^1_2\) if and only if there is a \(\Sigma_1\)-formula \(\varphi\) such that

\(x \in A \Leftrightarrow \langle L[x], \in \rangle \vDash \varphi \Leftrightarrow \langle L_{(\omega_1)^{x[x]}}[x], \in \rangle \vDash \varphi\).

Proof. Suppose that \(A \subseteq 2^\omega\) is \(\Sigma^1_2\). Then there is a \(\Pi^1_1\)-relation \(B \subseteq 2^\omega \times 2^\omega\) such that

\(x \in A \Leftrightarrow (\exists y) B(x, y)\).

By Corollary 3.7.2, there is a \(\Sigma_1\)-formula \(\psi\) such that

\(B(x, y) \Leftrightarrow \langle L_{a^\omega}[x, y], \in \rangle \vDash \psi\).

Since for every \(x\), \(B_x = \{y \mid B(x, y)\}\) is \(\Pi^1_1(x)\), by relativizing Theorem 4.1.2 there is a \(y \in B_x\) such that \(y \in L_{a^\omega}[x]\).

Hence

\(x \in A \Leftrightarrow (\exists y)(y \in L_{a^\omega}[x] \land \langle L_{a^\omega}[x], \in \rangle \vDash \psi)\).

Now let \(\varphi\) be

\((\exists \beta)(\exists \alpha > \omega)(\alpha \text{ is the least admissible ordinal such that}\)

\(y \in L_\alpha[x] \land \langle L_\alpha[x], \in \rangle \vDash \psi)\).

By Theorem 3.3.2, \(\varphi\) is \(\Sigma_1\). By the discussion above, \(x \in A\) if and only if \(\langle L[x], \in \rangle \vDash \varphi\) if and only if \(\langle L_{(\omega_1)^{x[x]}}[x], \in \rangle \vDash \varphi\).

For the other direction, suppose there is a \(\Sigma_1\)-formula \(\varphi\) such that \(x \in A \Leftrightarrow \langle L[x], \in \rangle \vDash \varphi\). Then for each \(x\), there is a cardinal \(x\) such that \(x \in A \Leftrightarrow \langle L_\alpha[x], \in \rangle \vDash \varphi\).

By the Condensation Theorem (3.3.7), there is a countable admissible ordinal \(\alpha\) such that \(x \in A \Leftrightarrow \langle L_\alpha[x], \in \rangle \vDash \varphi\). Since \(\varphi\) is \(\Sigma_1\), we have \(x \in A \Leftrightarrow \langle L[x], \in \rangle \vDash \varphi \Leftrightarrow \langle L_{(\omega_1)^{x[x]}}[x], \in \rangle \vDash \varphi\).

By Theorem 3.3.4, \(\langle L_{(\omega_1)^{x[x]}}[x], \in \rangle \vDash \varphi\) if and only if there is a countable transitive wellfounded model \(\langle M, \in \rangle \vDash \text{KP} + \text{“}V = L[x]\text{”} + \varphi\). Hence \(\langle L_{(\omega_1)^{x[x]}}[x], \in \rangle \vDash \varphi\) if and only if

\((\exists E)(\langle \omega, E \rangle \text{ codes a wellfounded transitive model } \land \langle \omega, E \rangle \vDash \text{KP} + \text{“}V = L[x]\text{”} + \varphi)\).

By Proposition 3.6.2, the set \(\{x \mid \langle L_{(\omega_1)^{x[x]}}[x], \in \rangle \vDash \varphi\} = \{x \mid \langle L[x], \in \rangle \vDash \varphi\}\) is \(\Sigma^1_2\).

Thus one may regard \(L_{\omega_1}\) as the structure where \(\Sigma^1_2\)-sets are based. In a way, \(\Sigma^1_2\)-ness draws the boundary between recursion theory and set theory. Within ZFC, it is not possible to generalize results in the previous sections to a level beyond \(\Sigma^1_2\). One needs additional set-theoretic assumptions for this. How this is to be implemented is a major subject in descriptive set theory. From this perspective, higher recursion theory serves as a launch pad for the study of descriptive set theory beyond the level of \(\Sigma^1_2\). Let

\(\delta^1_2 = \text{supremum of the } \Delta^1_2 \text{ well-orderings of } \omega\),

and

\(\delta = \min\{\alpha \mid L \setminus L_\alpha \text{ contains no } \Pi^1_1\text{-singleton}\}\).
