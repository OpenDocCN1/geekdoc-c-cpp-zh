We now show (iii) \(\Rightarrow\) (i). Suppose that \(A\) is \(\Delta^1_1\). Then both \(A\) and \(B = \omega^\omega \\ A\) are \(\Sigma^1_1\). So there are two recursive trees \(S\) and \(T\) such that

\(x \in A \iff (\exists y)(\forall n)(x [ n, y [ n ) \in S\)

and

\(x \in B \iff (\exists y)(\forall n)(x [ n, y [ n ) \in T.\)

Define \(R = S \otimes T\) as follows:

\((\sigma, \tau, v) \in R \iff (\sigma, \tau) \in S \wedge (\sigma, v) \in T.\)

Define \((\sigma, \tau, v) < (\sigma', \tau', v')\) if \(\sigma > \sigma'\), \(\tau > \tau'\) and \(v > v'\). Since \(A \cap B = \emptyset\), \(R\) is a wellfounded tree under \(<\). We construct a hyperarithmetic code \(z\) so that \(B \subseteq A_z\) and \(A_z \cap A = \emptyset\). Then \(A_z = B\).

We define a recursive function \(h : \omega \to \omega\) such that for some \(c\), \(\Phi_{h(e)}(n, \emptyset, \emptyset, 0)\) is a hyperarithmetic code for \(A\).

For \((\sigma, \tau, v)\) such that \(|\sigma| = |\tau| = |v|\), there are three cases to consider:

(1) \((\sigma, \tau, v) \notin R\) and \((\sigma, v) \in T\). Define \(\Phi_{h(e)}(0, \sigma, \tau, v) = 0\) and \(\Phi_{h(e)}(n, \sigma, \tau, v) = 1\) for all \(n > 0\).

(2) \((\sigma, \tau, v) \notin R\) and \((\sigma, v) \notin T\). Define \(\Phi_{h(e)}(n, \sigma, \tau, v) = 0\) for all \(n\).

(3) \((\sigma, \tau, v) \in R\). For \((i, j, k, l)\), we define a recursive function \(g\) determined by the following four subcases:

3(i) \(i = k\) and \((\sigma' \uparrow i, \tau' \uparrow j, v' \uparrow l) \in R\). Define \(g(e, i, j, k, l, n) = \Phi_e(n, \sigma' \uparrow i, \tau' \uparrow j, v' \uparrow l)\).

3(ii) \(i \neq k\). Define \(g(e, i, j, k, l, n) = m\) for all \(n > 0\) and \(g(e, i, j, k, l, 0) = 0\), where \(m\) is a code such that \(0_m = 0^k\).

3(iii) \(i = k\) and \((\sigma' \uparrow i, \tau' \uparrow j) \notin S\). Define \(g(e, i, j, k, l, n) = 1\) for all \(n > 0\) and \(g(e, i, j, k, l, 0) = 0\).

3(iv) \(i = k\) and \((\sigma' \uparrow i, \tau' \uparrow j) \in S\) but \((\sigma' \uparrow i, v' \uparrow l) \notin T\). Define \(g(e, i, j, k, l, n) = 0\) for all \(n\).

Intuitively, \(g\) is a hyperarithmetic code for a set \(A_{i,j,k,l}\) disjoint from \([S_{(\sigma \uparrow i, \tau \uparrow j)}]\) but covers \([T_{(\sigma \uparrow i, v \uparrow l)}]\), where

\([S_{(\sigma \uparrow i, \tau \uparrow j)}] = \{x > \sigma \uparrow i \mid (\exists y)(y > \tau \uparrow j \wedge (\forall n)((x [ n, y [ n ) \in S)\}\)

and

\([T_{(\sigma \uparrow k, v \uparrow l)}] = \{x > \sigma \uparrow k \mid (\exists y)(y > v \uparrow l \wedge (\forall n)((x [ n, y [ n ) \in T)\}.\)

The plan is to define \(\Phi_{h(e)}(n, \sigma, \tau, v)\) to code the set \(C = \bigcup_{k,l} [\bigcup_{i,j} A_{i,j,k,l}]\). Then \(C \supseteq [T_{(\sigma, v)}]\) and \(C \cap [S_{(\sigma, \tau)}] = \emptyset\). Define a recursive function \(p^1_k\) such that \(p^1_k(0) = 1\) and \(p^1_k((2^{i,j} \cdot 3^n) \cdot 3^m) = 1\) if and only if \(g(e, i, j, k, l, n) = 1\). Then \(p^1_k\) will code the set \(\bigcup_{i,j} (\omega^2 \\ A_{i,j,k,l})\).

Define a recursive function \(p^2\) so that \(p^2(0) = 1\) and \(p^2((2^{k,l} \cdot 3^n) \cdot 3^m) = 1\) if and only if \(p^1_k(n) = 1\). Then \(p^2\) is a code for \(\bigcup_k (\omega^\omega \\ \bigcup_j (\omega^\omega \\ A_{i,j,k,l})) = \bigcup_k (\bigcap_l A_{i,j,k,l})\).

Let \(\Phi_{h(e)}(n, \tau, v_0, v_1) = 1\) if and only if \(p^2(n) = 1\). By the Recursion Theorem, there is a fixed point \(c\) such that \(\Phi_{h(c)} = \Phi_c\).
