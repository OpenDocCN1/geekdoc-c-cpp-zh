
## 4.1.2 A constructible basis theorem

Theorem 4.1.2 (Gupasari [42]). If \( A \subseteq 2^\omega \) is a nonempty \( \Pi^1_1 \)-set, then there is an \( x \in A \) such that \( x \in L_{\omega_1^x} \).

Proof. Let T be the tree presentation for A and (x, f) its leftmost path. We claim that \( x \in L_{\omega_1^x} \). By Lemma 4.1.1, \( f \in L_{\omega_1^x}[x] \). Hence there is an ordinal \( \alpha_0 < \omega_1^x \) such that Rang(f) = \( \alpha_0 \). We define tree \( T^{\alpha_0} \) by replacing \( \omega_1 \) with \( \alpha_0 \) in T everywhere. Obviously \( T^{\alpha_0} \in L_{\omega_1}[x] \) for some \( \gamma_0 < \omega_1^x \) and (x, f) is an infinite path in \( T^{\alpha_0} \). Moreover, for any \( (\sigma, p) < (x \upharpoonright |\sigma|, f \upharpoonright \text{Dom}(p)) \), there is no infinite path in \( T^{\alpha_0}_{(\sigma, p)} = \{\sigma', \tau' \in T^{\alpha_0} \mid (\sigma', p') > (\sigma, p)\} \). Otherwise, any such infinite path would also be in T and to the left of (x, f), which contradicts the choice of (x, f) in T. Then for any \( (\sigma, p) < (x \upharpoonright |\sigma|, f \upharpoonright \text{Dom}(p)) \), there exist ordinals \( \alpha_{(\sigma, p)} < \omega_1^x \), \( \beta_{(\sigma, p)} < \alpha_{(\sigma, p)} \) and a function \( g_{(\sigma, p)} \in L_{\alpha_{(\sigma, p)}} \) such that \( g_{(\sigma, p)} \) is an order-preserving function from \( T^{\alpha_0}_{(\sigma, p)} \) to \( \beta_{(\sigma, p)} \). Moreover, the function from \( (\sigma, p) < (x \upharpoonright |\sigma|, f \upharpoonright \text{Dom}(p)) \) to \( \alpha_{(\sigma, p)} < \omega_1^x \) is \( \Sigma_1 \) in \( L_{\omega_1^x}[x] \). Since the set \( \{(\sigma, p), T^{\alpha_0}_{(\sigma, p)} \mid (\sigma, p) < (x \upharpoonright |\sigma|, f \upharpoonright \text{Dom}(p))\} \) is an element of \( L_{\omega_1^x}[x] \), there is a \( \gamma < \omega_1^x \) that bounds any \( \alpha_{(\sigma, p)} \) where \( (\sigma, p) < (x \upharpoonright |\sigma|, f \upharpoonright \text{Dom}(p)) \). We may assume that \( \gamma > \alpha_0 \). Now working in \( L_\gamma \), we define an infinite path as follows: \( (o_0, p_0) = 0 \). \( (o_{i+1}, p_{i+1}) > (o_i, p_i) \) in \( T^{\alpha_0} \) is of length i + 1 so that (1) for all \( (\sigma, p) < (o_{i+1}, p_{i+1}) \) not extending \( (o_{i+1}, p_{i+1}) \), there is an order-preserving function \( g_{(\sigma, p)} \in L_\gamma \) from \( T^{\alpha_0}_{(\sigma, p)} \) into an ordinal \( \beta_{(\sigma, p)} < \gamma \), and (2) there is no order-preserving function \( g \in L_\gamma \) from \( T^{\alpha_0}_{(o_{i+1}, p_{i+1})} \) into any ordinal \( \beta < \gamma \). By the assumption of \( \gamma \), we have \( \bigcup_{i < \omega} (o_i, p_i) = (x, f) \). Clearly the sequence \( \{(o_i, p_i)\}_{i < \omega} \) is an element of \( L_{\gamma + \omega} \). Hence \( (x, f) \in L_{\gamma + \omega} \subseteq L_{\omega_1^x} \), and so \( x \in L_{\omega_1^x} \).

We have as an immediate consequence of Theorem 4.1.2,

Corollary 4.1.3. If x is a \( \Pi^1_1 \)-singleton, then \( x \in L_{\omega_1^x} \).

## 4.2 $\Pi^1_1$-uniformization

### 4.2.1 Uniformizing $\Pi^1_1$-relations

Given a relation $R \subseteq 2^\omega \times 2^\omega$, a relation $R_0$ is a uniformization of $R$ if for any x and y, $R_0(x, y)$ implies $R(x, y)$ and for any x, if there is a y such that $R(x, y)$, then there is a unique y such that $R_0(x, y)$. Uniformization of R is in effect a choice function for R.

THEOREM 4.2.1 (Kondo [74] and Addison [1]). Suppose that $R \subseteq 2^\omega \times 2^\omega$ is $\Pi^1_1$. Then there is a $\Pi^1_1$-relation $R_0$ that uniformizes R.

Proof. Suppose that $R \subseteq 2^\omega \times 2^\omega$ is $\Pi^1_1$. By Corollary 3.7.2, there is a $\Sigma_0$-formula $\varphi(u, v, w)$ such that

$(x, y) \in R \leftrightarrow (L_{\omega_1^{xy}}[x \oplus y], \in) \models (\exists w)\varphi(x, y, w).$

Define $R_0 \subseteq 2^\omega \times 2^\omega$ so that $(x, y) \in R_0$ if and only if
- (i) $y \in L_{\omega_1^{xy}}[x]$;
- (ii) $(\exists w \in L_{\omega_1^{xy}}[x])((L_{\omega_1^{xy}}[x], \in) \models \varphi(x, y, w))$; and
- (iii) $(L_{\omega_1^{xy}}[x], \in) \models (\forall z \forall w')(w' <_{L[x]} (y, w) \rightarrow \neg\varphi(x, z, w'))$.

By Theorem 4.1.2, if there is a y such that $(x, y) \in R$, then there is one such that $R_0(x, y)$. By the definition of $R_0$, $R_0$ uniformizes R. Note that both (i) and (ii) above are $\Sigma_1$-statements. By Proposition 3.3.3, (iii) is also a $\Sigma_1$-statement. By Corollary 3.7.2, $R_0$ is a $\Pi^1_1$-relation.

There are a number of interesting applications of the $\Pi^1_1$ Uniformization Theorem (4.2.1) which we now discuss:

PROPOSITION 4.2.2. Given $\Pi^1_1$-sets $A_0$ and $B_0$, there exist disjoint $\Pi^1_1$-sets $A_1 \subseteq A_0, B_1 \subseteq B_0$ such that $A_0 \cup B_0 = A_1 \cup B_1$.

Proof. Let $R \subseteq 2^\omega \times 2^\omega$ be a $\Pi^1_1$-relation such that $(x, i) \in R$ if and only if either $i = 0$ and $x \in A_0$ or $i = 1$ and $x \in B_0$. By Theorem 4.2.1, there is a $\Pi^1_1$-relation $R_0$ uniformizing R. Define $x \in A_1$ if and only if $(x, 0) \in R_0$ and $x \in B_1$ if and only if $(x, 1) \in R_0$. Then $A_1, B_1$ are as required.

COROLLARY 4.2.3. Given disjoint $\Sigma^1_1$-sets $A_0, B_0$, there exist disjoint $\Delta^1_1$-sets $A_1, B_1$ such that $A_0 \subseteq A_1, B_0 \subseteq B_1$ and $A_1 \cup B_1 = 2^\omega$.

Proof. The hypothesis implies that $2^\omega \setminus A_0$ and $2^\omega \setminus B_0$ are $\Pi^1_1$. By Proposition 4.2.2, there exist two $\Pi^1_1$-sets $A_1 \supseteq B_0, B_1 \supseteq A_0$ such that $A_1$ and $B_1$ are disjoint and $A_1 \cup B_1 = 2^\omega$. Hence these sets are $\Delta^1_1$.

### 4.2.2 Kreisel compactness

Kreisel's Compactness Theorem is a generalization of the Compactness Theorem in model theory to \(L_{\omega_1\omega}\)-logic. In this setting, "recursively enumerable" is \(\Pi^1_1\), and "finite" is \(\Delta^1_1\). It is a striking application of the \(\Pi^1_1\)-Uniformization Theorem.

**Theorem 4.2.4** (Kreisel). Let \(A \subseteq \omega^2\) be a \(\Pi^1_1\)-set such that for each \(n, A_n = \{x \mid (n, x) \in A\}\) is \(\Delta^1_1\). Let \(z \in \Pi^1_1\). If \(\bigcap_{n \in \omega} A_n \neq \emptyset\) for every hyperarithmetic \(y \subseteq z\), then \(\bigcap_{n \in \omega} A_n \neq \emptyset\).

Proof. Suppose not. Then \(z\) is properly \(\Pi^1_1\) and \(\bigcap_{n \in \omega} A_n = \emptyset\). Then for each \(x\), there is an \(n\) such that \(x \notin A_n\). Define a \(\Pi^1_1\)-relation \(R \subseteq 2^{<\omega} \times \omega\) such that \(R(x, n) \Leftrightarrow n \in 2^\omega \times A_n\). By the Uniformization Theorem (4.2.1), there is a total \(\Pi^1_1\)-function \(f\) uniformizing \(R\). Then the set \(y = \{n \mid (\exists x)(f(x) = n)\}\) is contained in \(z\) and is \(\Sigma^1_1\). If \(x \in \bigcap_{n \in \omega} A_n\), then \(f(x) \in \omega \setminus y\). But no \(m \in \omega \setminus y\) belongs to \(f[2^\omega]\). Thus \(\bigcap_{n \in \omega} A_n = \emptyset\). By Corollary 4.2.3 restricted to \(\omega\), there is a \(\Delta^1_1\)-real \(y_0\) with \(y \subseteq y_0 \subseteq z\). Then \(\bigcap_{n \in \omega} A_n = \emptyset\), which is a contradiction.

Theorem 4.2.4 was further generalized by Barwise [3] to countable admissible sets as a compactness theorem for infinitary logic.

### 4.2.3 \(\Pi^1_1\)-singletons

**Proposition 4.2.5.** Every nonempty \(\Pi^1_1\)-set of reals contains a \(\Pi^1_1\)-singleton.

Proof. Suppose that \(A \subseteq 2^\omega\) is \(\Pi^1_1\) and nonempty. Let \((n, x) \in R\) if and only if \(x \in A\). Then \(R\) is a \(\Pi^1_1\)-relation. By Theorem 4.2.1, there is a \(\Pi^1_1\)-relation \(R_0\) uniformizing \(R\). Then the unique real \(x\) such that \((0, x) \in R_0\) is a \(\Pi^1_1\)-singleton.

By Proposition 4.2.5, we know that every nonempty \(\Pi^1_1\)-set contains a \(\Pi^1_1\)-singleton.

**Proposition 4.2.6.** The set \(\{x \mid x \text{ is a } \Pi^1_1\text{-singleton}\}\) is \(\Pi^1_1\).

Proof. Let \(P \subseteq \omega \times 2^\omega\) be a universal \(\Pi^1_1\)-set. By Proposition 4.2.5, there is \(\Pi^1_1\)-set \(P_0 \subseteq P\) uniformizing \(P\). Let \(A = \{x \mid (\exists n)(n, x) \in P_0\}\). Then \(A\) is a \(\Pi^1_1\) set which contains precisely all the \(\Pi^1_1\)-singletons.

Since there are only countably many \(\Pi^1_1\)-singletons, there is a countable \(\Pi^1_1\)-set which is a basis for \(\Pi^1_1\)-sets of reals. This gives the following basis result for \(\Sigma^1_2\)-sets.

**Corollary 4.2.7.** Every nonempty \(\Sigma^1_2\)-set of reals contains a \(\Delta^1_2\)-member.

Proof. Suppose \(A\) is a nonempty \(\Sigma^1_2\)-set of reals. Then \(x \in A\) if and only if \((\exists y)B(x, y)\) for some \(\Pi^1_1\)-relation \(B\). By Proposition 4.2.5, there is a \(\Pi^1_1\)-singleton, and hence a \(\Delta^1_2\)-real, \((x_0, y_0)\) such that \(B(x_0, y_0)\). Then \(x_0 \in A\) is \(\Delta^1_2\).
