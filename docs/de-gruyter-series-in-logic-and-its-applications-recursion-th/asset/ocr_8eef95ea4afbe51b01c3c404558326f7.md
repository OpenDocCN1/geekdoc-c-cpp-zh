Proof. By the \(\Pi^1_1\)-Uniformization Theorem (4.2.1), there is a \(\Pi^1_1\)-partial function \(F : \omega \times 2^\omega \to 2^\omega\) such that for any \(y\) and \(\Pi^1_1(y)\)-singleton \(z\), there is an \(n\) such that \(F(n, y) = z\). By Corollary 4.2.8, \(x \le_{\Delta^1_1} y\) if and only if there exist \(n\) and \(e\) such that \(x = \Phi_e^{F(n, y)}\). Note that for any pair \((n, e)\) and numbers \(m\) and \(i\), the set \(D_{n,e,m,i} = \{y \mid \Phi_e^{F(n,y)}(m) = i\}\) is \(\Sigma^1_1\) and hence, by Corollary 13.1.8, is measurable. Note also that for any \(n\) and \(e\), the set \(D_{n,e} = \{y \mid \Phi_e^{F(n,y)}(m) = x(m)\} = \bigcap_{m \in \omega} D_{n,e,m,x(m)}\) is measurable. Hence \(E = \{y \mid x \le_{\Delta^1_1} y\}\) is measurable. Now suppose that \(E\) is not null. Then there is a pair \((n, e)\) that has \(D_{n,e}\) positive measure. Let \(\sigma \in 2^{<\omega}\) such that \(\mu(D_{n,e} \cap [\sigma]) > 2^{-|\sigma|} \cdot \frac{3}{4}\). Then \(m \in x \iff \mu(D_{n,e,m,1} \cap [\sigma]) > 2^{-|\sigma|} \cdot \frac{3}{4}\). By Corollary 13.1.7, \(x\) is \(\Sigma^1_1\). By the same argument, \(\omega \backslash x\) is also \(\Sigma^1_1\) and hence \(x\) is \(\Delta^1_1\). \(\square\) It should be pointed out that the assumption "\(\omega_1^{ck} < \omega_1\)" in Proposition 13.1.9 is not provable under ZFC.

# 13.1.3 A measure-theoretic basis theorem

In measure theory, every measurable set of reals is approximated by closed sets. There is an effective version of this in hyperarithmetic theory.

+   Lemma 13.1.10. There is a \(\Pi^1_1\)-function \(f : \omega \times \omega \to \omega\) such that for any Gödel number \(n\) of a ranked formula,
+   (i) \(f(n, m)\) is the Gödel number of a ranked formula whose only free variable is \(x\);
+   (ii) the set \(\{x|\mathfrak{I}(\omega_1^{CK}, x) \vDash \phi_{f(n,m)}\}\) is a closed subset of \(\{x|\mathfrak{I}(\omega_1^{CK}, x) \vDash \phi_n\}\);
+   (iii) \(\mu(\{x|\mathfrak{I}(\omega_1^{CK}, x) \vDash \phi_n\} \\setminus \{x|\mathfrak{I}(\omega_1^{CK}, x) \vDash \phi_{f(n,m)}\}) < 2^{-m}\).

Proof. We construct the function \(f\) by induction on the rank of formulas. Let \(\beta < \omega_1^{CK}\) and assume by induction that \(f\) is defined for every formula with rank less than \(\beta\). In \(\langle L_{\omega_1^{CK}}, \in \rangle\), there is a uniform enumeration \(\{\psi_{(n)}\}_{i < \omega}\) of the set of formulas of rank \(< \beta\) with \(n\) as the only free variable.

Let \(\varphi(x^E)\) be a formula of rank \(\le \beta\) whose only free ranked variable is \(x^E\). For the formula \((\exists x^E)\varphi(x^E)\), \(\mathfrak{I}(\omega_1^{CK}, x) \vDash (\exists x^E)\varphi(x^E)\) if and only if there is a \(j\) such that \(\mathfrak{I}(\omega_1^{CK}, x) \vDash \forall^j \varphi(\Psi b)\). By Theorem 13.1.3, there is a hyperarithmetic function taking each \(m\) to a large enough \(j\) such that

\(\mu(\{x | (\exists \mathfrak{I}(\omega_1^{CK}, x) \vDash (\exists x^E)\varphi(x^E)\} - \mu(\{x | (\exists \mathfrak{I}(\omega_1^{CK}, x) \vDash (\exists i \le j)(\varphi(\Psi_i))\} < 2^{-m-1}.\)
