with

$(y, x, y, e, i)(x = \Phi_e^{y'} \rightarrow \Phi_i^x = \Phi_{s(i)}^y)$.

Suppose that $x = 0_e^\omega$. Then

+   (1) $(G(y))_0 = (G(y))_{i+2}$,
+   (2) $(G(y))_1 = 0_{(h(e))}^{(G(y))}$, and
+   (3) $(G(y))_{i+2} = (G(y))_{s(i)+2}$.

Hence G is as desired.

# 8.4.3 Exercises

**Exercise 8.4.1.** Use Theorem 6.5.6 to prove that if $0^\sharp$ exists, then Martin's conjecture for $\Pi^1_1$-uniformly degree invariant functions is true.

**Exercise 8.4.2.** Prove that there is a sentence $\varphi$ in the language of partial ordering of the Turing degrees such that $\{ \mathbf{x} \mid (\mathscr{D} \ge \mathbf{x}), \mathbf{s} \} \models \varphi$ is cofinal and if it contains a cone, then $0^\sharp$ exists.

**Exercise 8.4.3.** Suppose that $\alpha > \beta > \omega$ are countable admissible ordinals and $g$ is a generic real produced by Steel forcing over $L_\alpha$. Then for any ordinal $\gamma < \beta$ and any set $A \subseteq \gamma$, if $A \in L_\alpha \cap L_\beta[g]$, then $A \in L_\beta$.

**Exercise 8.4.4.** Suppose that the Friedman set $F^*$ contains a cone of Turing degrees. Then there is a real $x$ such that for any $y \ge_T x$, any $\alpha < \omega_1^x$ and any $A \subseteq \alpha$, if $A \in L$ then $A \in L_\alpha[y]$.

**Exercise 8.4.5.** Assume that the Friedman set $F^*$ contains a cone of Turing degrees. Show that there is a real $x$ such that for any $y \ge_T x$ and countable ordinal $\alpha$, if $L_\alpha[y]$ is admissible then $\alpha$ is a cardinal in $L$.

**Exercise 8.4.6.** Assume that the Friedman set $F^*$ contains a cone of Turing degrees. Show that there is a real $x$ such that for any $y \ge_T x$ and ordinal $\alpha$, if $L_\alpha[y]$ is admissible then $\alpha$ is a cardinal in $L$.

**Exercise 8.4.7.** Suppose that $x$ is a real such that for any ordinal $\alpha$, if $L_\alpha[x]$ is admissible then $\alpha$ is a cardinal in $L$. Furthermore, assume that $V = L[x]$. Then there is an ordinal $\alpha < \aleph_2$ and an elementary embedding $\pi : L_\alpha[x] \to L_{\aleph_1}[x]$ such that
- $\aleph_2 \in \text{Range}(\pi)$,
- there is an ordinal $\beta < \alpha$ such that $\pi(\beta) > \beta$, and
- $(\text{Range}(\pi))^\omega \subseteq \text{Range}(\pi)$.

**Exercise 8.4.8.** As in Exercise 8.4.7, let $\beta$ be the least ordinal such that $\pi(\beta) > \beta$. Then the set $\{ X \in L \mid X \subseteq \beta \land \beta \notin \pi(X) \}$ is an $\omega$-complete nonprincipal ultrafilter over $L \cap \mathscr{P}(\beta)$. Thus there is a nontrivial elementary embedding of $L$ into $L$.
