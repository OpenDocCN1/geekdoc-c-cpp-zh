# 3.4.1 Projecta

**Definition 3.4.1.** Let $\alpha > 0$ and $n \ge 1$. The $\Sigma_n$-projectum $\rho_\alpha^n$ of $\alpha$ is the least ordinal $\rho$ for which there is a $\Sigma_1(J_\alpha)$-definable function $f$ mapping a subset of $J_\rho$ onto $J_\alpha$.

Clearly $\rho_\alpha^n$ exists for any $n \ge 1$. One may replace $J_\rho$ with $\omega\rho$ in the above definition. To prove this, we need the following lemma whose proof is left to the reader:

**Lemma 3.4.2.** Let $\alpha > 0$. For each $1 \le y \le \omega\alpha$, there is a $\Sigma_1(J_\alpha)$-definable bijection between $\omega\alpha$ and $y \times \omega\alpha$.

**Proposition 3.4.3.** Let $\alpha > 0$. There is a $\Sigma_1(J_\alpha)$-definable function from $\omega\alpha$ onto $J_\alpha$.

**Proof.** Let $f_0 = (f^0, f^1)$ be a bijection between $\omega\alpha$ and $(\omega\alpha)^2$ guaranteed by Lemma 3.4.2 (setting $\gamma = \omega\alpha$) defined via the $<_{J_\alpha}$-least parameter $p \in J_\alpha$. Define $f_{n+1}(\gamma) = (f^0(\gamma), f_n(f^1(\gamma)))$ for $\gamma < \omega\alpha$. It is easy to verify that $f_n$ is $\Sigma_1(J_\alpha)$-definable with parameter $p$ and is a bijection between $\omega\alpha$ and $(\omega\alpha)^{n+2}$. Let $h_\alpha$ be the canonical $\Sigma_1$-Skolem function for $J_\alpha$. Set $X = h_\alpha(\omega \times (\omega\alpha \times p))$. Note that for each $n < \omega$ and $y < \omega\alpha$, there is an $i_n$ such that $f_p(y) = h_\alpha(i_n, \langle p, y \rangle)$. Thus $\chi \in X$ for every $\chi < \omega\alpha$. By Proposition 3.3.10, $(X, \in) \prec_{\Sigma_1} (J_\alpha, \in)$. By Theorem 3.3.7, there is a $\beta \le \alpha$ and an isomorphism $\pi : (X, \in) \cong (J_\beta, \in)$. Moreover, $\pi(p) \le_{J_\alpha} p$. Since $\chi \in X$ for every $\chi < \omega\alpha$, we have $\pi\beta = \alpha$ and $\pi(\gamma) = \gamma$ for every $\gamma < \omega\alpha$. Hence $\pi^{-1} : (J_\alpha, \in) \xrightarrow{\Sigma_1} (J_\alpha, \in)$ and $\pi^{-1}(f_0) = f_0$. Thus $f_0$ is also defined by $\pi(p)$ in $(J_\alpha, \in)$. By the assumption on $p$, $p \le_{J_\alpha} \pi(p)$ and so $p = \pi(p)$. Then for any $x \in X$, there are $i < \omega$ and $\gamma < \omega\alpha$ such that $x = h_\alpha(i, \langle \gamma, p \rangle) = h_\alpha(\pi(i), \langle \pi(\gamma), \pi(p) \rangle) = \pi(x)$, implying that $X = J_\alpha$. Note that $h_\alpha$ is not necessarily total. Let $\varphi(u, i, v, w, s)$ be a $\Sigma_0$-formula such that $h_\alpha(i, \gamma, p) = x$ if and only if $(J_\alpha, \in) \models (\exists y)\varphi(i, \gamma, p, x, y)$. Then by the proof of Proposition 3.3.11, there is a total $\Sigma_1$-function $h'(i, \gamma_1, \gamma_2) = \begin{cases} x & (J_\alpha, \in) \models (\exists n \in \omega)(\exists y \in J_\omega \cup S^{(\alpha)}(J_\rho))\varphi(i, \gamma_1, p, \gamma_2, y), \\ 0 & \text{Otherwise.} \end{cases}$ Let $h(\gamma) = h'(f_1(\gamma))$ for $\gamma < \omega\alpha$.

Applying Proposition 3.4.3, we have:

**Proposition 3.4.4.** $\alpha$ is admissible if and only if there is no $\Sigma_1(J_\alpha)$-definable function mapping $\alpha \prec \omega\alpha$ onto $\omega\alpha$.
