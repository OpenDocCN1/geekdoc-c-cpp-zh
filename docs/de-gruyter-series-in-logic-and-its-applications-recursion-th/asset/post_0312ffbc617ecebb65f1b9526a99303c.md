
We say that a function $f : 2^\omega \to 2^\omega$ presents an automorphism $\pi : (\mathscr{P}, \le) \to (\mathscr{P}, \le)$ if for every Turing degree $\mathbf{x}$ and real $x \in \mathbf{x}$, $f(x) \in \pi(\mathbf{x})$. The next two results are needed for Theorem 9.4.2 and are stated without proof.

### Theorem 9.4.3.
Every automorphism $\pi : (\mathscr{P}, \le) \to (\mathscr{P}, \le)$ is presented by an arithmetical function $f : 2^\omega \to 2^\omega$.

If $R$ is a degree invariant relation over $(2^\omega)^{n+1}$ for some $n$, then it induces a relation $\bar{R}$ on degrees such that $(x_0, \dots, x_n) \in \bar{R} \Leftrightarrow (\exists x_0) \dots (\exists x_n)(x_0 \in x_0 \land \dots \land x_n \in x_n \land (x_0, \dots, x_n) \in R)$. We identify $\bar{R}$ with $R$ for simplicity.

### Theorem 9.4.4.
For any relation $R$ over $\mathscr{P}$ which is induced by a degree invariant analytical relation over $2^\omega$, if $R$ is invariant under any automorphism of $\mathscr{P}$, then $R$ is definable in $(\mathscr{P}, \le)$.

We now prove Theorem 9.4.2.

### Lemma 9.4.5.
If $V = L$, then $(\mathscr{P}, \le)$ is $\omega$-homogeneous.

Proof. By Proposition 4.4.2, $<_1$ is a $\Delta^1_2$ well-ordering of $2^\omega$. The lexicographic ordering of $n + 1$-tuples induced by $<_1$ implies that for each $n$ there is a $\Delta^1_2$ well-ordering $<_{n+1}$ of $(2^\omega)^{n+1}$.

For $m < \omega$ and $k \le n$, let $R_{m,k} \subseteq (2^\omega)^{n+1}$ be such that
\[
(x_0, \dots, x_n) \in R_{m,k} \Leftrightarrow k \le n \land \\
(\exists y_0) \dots (\exists y_n)((y_0, \dots, y_n) \text{ is the } <_{n+1}\text{-least so that} \\
(\exists \pi)(\forall i \le n)(\pi : (\mathscr{P}, \le) \to (\mathscr{P}, \le) \text{ is an automorphism } \land \pi(y_i) = x_i \land m \in y_k)).
\]

It is straightforward to verify that $R_{m,k}$ is degree invariant and hence induces a relation on $\mathscr{P}$ invariant under any automorphism. By Theorem 9.4.3, $R_{m,k}$ is also analytical. Hence by Theorem 9.4.4, $R_{m,k}$ is definable in $(\mathscr{P}, \le)$.

Suppose that $(\mathscr{P}, \le, a_0, \dots, a_n) \equiv (\mathscr{P}, \le, b_0, \dots, b_n)$. Then $R_{m,k}(a_0, \dots, a_n) \Leftrightarrow R_{m,k}(b_0, \dots, b_n)$ for every $m$ and $k \le n$. For such a $k$, define $y_k$ so that $m \in y_k$ if and only if $R_{m,k}(a_0, \dots, a_n)$. By the definition of $R_{m,k}$, there are automorphisms $\pi_0$ and $\pi_1$ such that for every $k \le n$, $\pi_0(y_k) = x_k$ and $\pi_1(y_k) = b_k$. Then $\pi_1 \circ \pi_0^{-1}$ is an automorphism between $(\mathscr{P}, \le)$ and $(\mathscr{P}, \le)$, and $\pi_1 \pi_0^{-1}(a_k) = b_k$, implying that $(\mathscr{P}, \le)$ is $\omega$-homogeneous.

We complete the proof of Theorem 9.4.2 with the following lemma.

### Lemma 9.4.6.
If $V = L[g]$ where $g$ is a Cohen generic real, then $(\mathscr{P}, \le)$ is not $\omega$-homogeneous.

Proof. Let $g = g_0 \oplus g_1$. We leave it to the reader to verify that $(g_0, g_1)$ is a pair of generic reals over a product Cohen forcing $\mathbb{C} \times \mathbb{C}$. Then by Theorem 9.4.3, there is no automorphism of $(\mathscr{P}, \le)$ sending $g_0$ to $g_1$.

Now let \(\varphi\) be a formula such that \((L[\mathbf{g}], \in) \models (L[\langle g_0, g_1 \rangle], \in) \models (\langle \mathscr{D}, \le \rangle \equiv \varphi(\mathbf{g}_0))^\wedge\). Then there is a condition \((p_0, p_1) \in 2^{<\omega} \times 2^{<\omega}\) such that \([p_0] = [p_1]\), \((p_0, p_1) < (\mathbf{g}_0, \mathbf{g}_1)\) and \((p_0, p_1) \Vdash (\langle \mathscr{D}, \le \rangle \equiv \varphi(\mathbf{g}_0))^\wedge\). Obviously there is an automorphism \(\tau : \mathbb{C} \times \mathbb{C} \to \mathbb{C} \times \mathbb{C}\) so that \(\tau((p_0, p_1)) = (p_1, p_0)\) and \(\tau(\mathbf{g}_0) = \mathbf{g}_1\). By Proposition 6.1.17, \((p_1, p_0) \Vdash (\langle \mathscr{D}, \le \rangle \equiv \varphi(\mathbf{g}_1))^\wedge\). Then \((L[\langle \mathbf{g}_1, \mathbf{g}_0 \rangle], \in) \models (\langle \mathscr{D}, \le \rangle \equiv \varphi(\mathbf{g}_1))^\wedge\). However, \(L[\langle \mathbf{g}_1, \mathbf{g}_0 \rangle] = L[\langle \mathbf{g}_0, \mathbf{g}_1 \rangle] = L[\mathbf{g}]\) and thus \((L[\mathbf{g}], \in) \models (\langle \mathscr{D}, \le \rangle \equiv \varphi(\mathbf{g}_1))^\wedge\). Hence \((\mathscr{D}, \le)\) is not homogeneous.

## 9.5 Some general independence results

For a general reference on the subject of Turing degrees, see Lerman [82]. Let \(\mathcal{L}(\le)\) be the language of partial ordering. \(\mathcal{L}(\le)\) is a set definable in the language of set theory. Furthermore, both \((\mathscr{D}, \le)\) and the relation "\((\mathscr{D}, \le) \models \varphi\)" may be viewed as definable sets in the language of set theory. We code each formula \(\varphi\) in \(\mathcal{L}(\le)\) by a number "\(\ulcorner \varphi \urcorner\)".

Let

\(\text{Th}_{\exists_1}(\mathscr{D}, \le) = \{ \ulcorner \varphi \urcorner \mid \varphi \text{ is a } \Sigma_2\text{-sentence in } \mathcal{L}(\le) \wedge (\mathscr{D}, \le) \models \varphi \}\).

Lerman and Shore [131] proved:

### Theorem 9.5.1.
The set \(\text{Th}_{\exists_1}(\mathscr{D}, \le)\) is recursive.

Hence the set \(\text{Th}_{\exists_1}(\mathscr{D}, \le)\) is definable by a \(\Sigma^0_1\)-formula \(\psi_0\) and a \(\Pi^0_1\)-formula \(\psi_1\). It follows that for any \(\Sigma_2\)-sentence \(\varphi\),

\(\text{ZFC} \vdash (\mathscr{D}, \le) \models \varphi \leftrightarrow \psi_0(\ulcorner \varphi \urcorner)\)

and

\(\text{ZFC} \vdash (\mathscr{D}, \le) \models \neg \varphi \leftrightarrow \neg \psi_1(\ulcorner \varphi \urcorner)\).

Since for any \(\Sigma^0_1\)-formula \(\psi(u)\) and natural number \(n\),

\(\text{ZFC} \vdash \psi(n) \leftrightarrow (\omega, \le, +, \cdot, 0, 1) \models \psi(n)\),

(see [145]), for any \(\Sigma_2\)-sentence \(\varphi\) either

\(\text{ZFC} \vdash (\mathscr{D}, \le) \models \varphi\)

or

\(\text{ZFC} \vdash (\mathscr{D}, \le) \models \neg \varphi\).

Hence we have the following conclusion.

### Corollary 9.5.2.
For any \(\Sigma_2\)-sentence \(\varphi\) in \(\mathcal{L}(\le)\), either "\((\mathscr{D}, \le) \models \varphi\)" or "\((\mathscr{D}, \le) \models \neg \varphi\)" is provable in ZFC.

Clearly the set \(\text{Pr} = \{ \ulcorner \varphi \urcorner \mid \text{ZFC} \vdash (\mathscr{D}, \le) \models \varphi \}\) is r.e. The complexity of the theory of the Turing degrees was established by Simpson [139]:

### Theorem 9.5.3.
ZFC proves that there is a recursive bijection $f : \omega \to \omega$ such that for any $n, n \in \ulcorner \varphi \urcorner \langle \mathscr{D}, \le \rangle \vDash \varphi$ if and only if $f(n) \in \ulcorner \varphi \urcorner \langle \omega, 2^\omega, +, \cdot, \subseteq \rangle \vDash \psi \rangle$, where $\psi$ is a formula in the language of second order arithmetic.

Thus ZFC proves that the set $\ulcorner \varphi \urcorner \langle \mathscr{D}, \le \rangle \vDash \varphi$ is not analytical. It follows that for any $\mathsf{M} \vDash \mathsf{ZFC}$, we have $\mathsf{Pr} \vdash \ulcorner \varphi \urcorner \vdash \mathsf{M} \vDash \ulcorner \langle \mathscr{D}, \le \rangle \vDash \varphi \urcorner$. This leads to the following conclusion.

### Corollary 9.5.4.
For any $\mathsf{M} \vDash \mathsf{ZFC}$, there is a sentence $\varphi$ such that $\ulcorner \varphi \urcorner \in \ulcorner \psi \urcorner \vdash \mathsf{M} \vDash \ulcorner \langle \mathscr{D}, \le \rangle \vDash \psi \urcorner \vdash \mathsf{Pr}$.

Let $\mathsf{M} \vDash \mathsf{ZFC}$ and $\varphi$ be as above. Since $\mathsf{ZFC} \vdash \ulcorner \langle \mathscr{D}, \le \rangle \vDash \varphi \urcorner$, there exists a model $\mathsf{N} \vDash \mathsf{ZFC}$ such that $\mathsf{N} \vDash \ulcorner \langle \mathscr{D}, \le \rangle \vDash \neg \varphi \urcorner$. Hence the statement $\ulcorner \langle \mathscr{D}, \le \rangle \vDash \varphi \urcorner$ is independent of ZFC. This argument implies the existence of a sentence $\varphi$ not provable in ZFC, but does not provide any information about $\varphi$. The following offers more information: By Corollary 4.4.1, the statement “every real is constructible” is $\Pi_2^1$. Hence there is a sentence $\varphi$ in $\mathcal{L}(\in)$ such that $\ulcorner \langle \mathscr{D}, \le \rangle \vDash \varphi \urcorner$ if and only if every real is constructible. Thus the statement $\ulcorner \langle \mathscr{D}, \le \rangle \vDash \varphi \urcorner$ is independent of ZFC. However, a weakness in the argument is that the sentence $\varphi$ is highly complicated, not necessarily considered “natural”, and heavily dependent on the coding scheme. It is not known if there is a “natural” sentence in $\mathcal{L}(\in)$ that is independent of ZFC.
