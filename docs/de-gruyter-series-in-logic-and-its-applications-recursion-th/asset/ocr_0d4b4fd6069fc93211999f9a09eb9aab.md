# **Theorem 9.5.3.** ZFC proves that there is a recursive bijection $f : \omega 	o \omega$ such that for any $n, n \in \ulcorner \varphi \urcorner \langle \mathscr{D}, \le angle \vDash \varphi$ if and only if $f(n) \in \ulcorner \varphi \urcorner \langle \omega, 2^\omega, +, \cdot, \subseteq angle \vDash \psi angle$, where $\psi$ is a formula in the language of second order arithmetic.

Thus ZFC proves that the set $\ulcorner \varphi \urcorner \langle \mathscr{D}, \le angle \vDash \varphi$ is not analytical. It follows that for any $\mathsf{M} \vDash \mathsf{ZFC}$, we have $\mathsf{Pr} \vdash \ulcorner \varphi \urcorner \vdash \mathsf{M} \vDash \ulcorner \langle \mathscr{D}, \le angle \vDash \varphi \urcorner$. This leads to the following conclusion.

# **Corollary 9.5.4.** For any $\mathsf{M} \vDash \mathsf{ZFC}$, there is a sentence $\varphi$ such that $\ulcorner \varphi \urcorner \in \ulcorner \psi \urcorner \vdash \mathsf{M} \vDash \ulcorner \langle \mathscr{D}, \le angle \vDash \psi \urcorner \vdash \mathsf{Pr}$.

Let $\mathsf{M} \vDash \mathsf{ZFC}$ and $\varphi$ be as above. Since $\mathsf{ZFC} 
vdash \ulcorner \langle \mathscr{D}, \le angle \vDash \varphi \urcorner$, there exists a model $\mathsf{N} \vDash \mathsf{ZFC}$ such that $\mathsf{N} \vDash \ulcorner \langle \mathscr{D}, \le angle \vDash 
eg \varphi \urcorner$. Hence the statement $\ulcorner \langle \mathscr{D}, \le angle \vDash \varphi \urcorner$ is independent of ZFC. This argument implies the existence of a sentence $\varphi$ not provable in ZFC, but does not provide any information about $\varphi$. The following offers more information: By Corollary 4.4.1, the statement “every real is constructible” is $\Pi_2^1$. Hence there is a sentence $\varphi$ in $\mathcal{L}(\in)$ such that $\ulcorner \mathscr{D}, \le angle \vDash \varphi \urcorner$ if and only if every real is constructible. Thus the statement $\ulcorner \langle \mathscr{D}, \le angle \vDash \varphi \urcorner$ is independent of ZFC. However, a weakness in the argument is that the sentence $\varphi$ is highly complicated, not necessarily considered “natural”, and heavily dependent on the coding scheme. It is not known if there is a “natural” sentence in $\mathcal{L}(\in)$ that is independent of ZFC.
