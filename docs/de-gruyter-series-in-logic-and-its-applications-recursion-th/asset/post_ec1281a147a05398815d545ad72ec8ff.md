
\(\psi_{\beta, \Lambda}(\sigma_m) = \psi_{\beta_{<m}, \Lambda}(\psi_{\beta, \beta_{<m}}(\sigma_m)) = \psi_{\beta_{<m}, \Lambda}(\sigma_m) = x \mid m\). Thus \(\psi_{\Lambda, \beta}(z) = x\). In other words, \(\psi\) is onto.

Now suppose that \(x_0, x_1 \in [T^0_\beta]\), \(x_0 \mid n_0 = x_1 \mid n_0 = \sigma_0\), \(x_0 \succ \sigma' k_0\), \(x_1 \succ \sigma' k_1\) for some \(k_0 \neq k_1\). Let \(j > |\sigma| + 1\) be such that \(\beta_{j, \Lambda} > \beta\). Then \(\psi_{\beta, \beta_{j, \Lambda}}(x_0 \mid [\sigma] + 1) = x_0 \mid [\sigma] + 1 \uparrow x_0 \mid [\sigma] + 1 = \psi_{\beta, \beta_{j, \Lambda}}(x_1 \mid [\sigma] + 1)\). By induction, \(\psi_{\beta, \beta_{j, \Lambda}}(y_0) \neq \psi_{\beta, \beta_{j, \Lambda}}(y_1)\) for any \(y_0 \succ x_0 \mid [\sigma] + 1\) and \(y_1 \succ x_1 \mid [\sigma] + 1\). By Lemma 11.2.9 (ii), \(\psi_{\Lambda, \beta}(x_0) \neq \psi_{\Lambda, \beta}(x_1)\).

Hence for \(\gamma = \Lambda\), \(\psi_{\gamma, \beta}\) is a bijection between \([T^0_\gamma]\) and \([T^0_\beta]\). Clearly both \(\psi_{\gamma, \beta}\) and \(\psi^{-1}_{\gamma, \beta}\) are continuous. Hence \(\psi_{\gamma, \beta}\) is a homeomorphism.

By (3), \(T^0_\beta\) is a recursive tree. By the Recursion Theorem, one may assume that there is already a system satisfying (1)-(6). We define \(T_\beta\) from \(T_{\beta^*}\). Let \(T^1_\beta = P_{\beta, \beta_{<\Lambda}}(T^{0\beta\sigma})\) be a recursive tree. Recursively compute \(f(\beta)\).

For \(\sigma \in \omega^{<\beta}\), let \(T^{0\beta}_\sigma\) be a \(\theta^{(\beta)}\)-recursive tree obtained from Lemma 11.2.5 upon replacing \(T\) with \(\{\tau \mid \sigma' \tau \in T^{0\beta}_\sigma\}\) and \(x\) with \(\theta^{(\beta)}\). Relativizing Lemma 11.2.6 to \(\theta^{(\beta)}\) (replacing \(T_0\) with \(T^{0\beta}_{\sigma, \sigma}\)), we have a \(\theta^{(\beta)}\)-recursive homeomorphism \(\psi_\sigma : T^{0\beta}_{\sigma, \sigma} \to T^{0\beta}_{\sigma, \sigma}\) where \(T^{0\beta}_{\sigma, \sigma}\) is \(T_1\) in Lemma 11.2.6. Define \(T^0_\beta\) to be a \(\theta^{(\beta)}\)-recursive tree such that \(\tau \in T^0_\beta\) if and only if either

- \((\tau, P^0_{\beta^*, \Lambda}(\forall \beta' \langle j[\beta']\rangle) \in T_\alpha \cap \alpha \omega^{S(\beta)} \times \alpha \omega^{S(\beta)}\) for some \(\lambda \in \Lambda(\beta)\), or
- \(\tau = (\tau \uparrow j[\langle \beta' \rangle] \uparrow \tau' \text{ for some } \tau' \in T^0_{\beta, \tau \uparrow j[\langle \beta' \rangle]}\).

Define \(\psi_{\beta^*, \beta} \le_T \theta^{(\beta)} : T^0_{\beta^*} \to T^0_\beta\) such that

- if \((\tau, P^0_{\beta^*, \Lambda}(\forall \beta' \langle j[\beta']\rangle)) \in T_\alpha \cap \alpha \omega^{S(\beta)} \times \alpha \omega^{S(\beta)}\) and \(\lambda \in \Lambda(\beta)\), then \(\psi_{\beta^*, \beta}(\tau) = \tau\);
- otherwise, let \(\tau = (\tau \uparrow j[\langle \beta' \rangle] \uparrow \tau'\). Define \(\psi_{\beta^*, \beta}(\tau) = \tau \uparrow j[\langle \beta' \rangle] \uparrow \psi_{\theta(\beta)}(\tau' \uparrow (\oplus_{\beta \in \beta^*} \uparrow \tau' \uparrow))\).

Hence for any \(x \in T^0_\beta\),
\((x \oplus \theta(\beta))' \equiv_T x \oplus \theta(\beta') \equiv_T \psi^{-1}_{\beta^*, \beta}(x) \oplus \theta(\beta')\).

Note that \(T^0_\beta = T^0_{\beta^d}\) (see (3)) for some \(d\) which is independent of \(\beta\). Define \(T_\beta\) such that \((\sigma, \tau) \in T_\beta\) if and only if either

- there exists a \((\sigma, \tau) \in T_\alpha \cap \alpha \omega^{S(\beta)} \times \alpha \omega^{S(\beta)}\) for some \(\lambda \in \Lambda(\beta)\) such that \(\tau = p_{\beta, \Lambda}(\tau)\), or
- or there is a \(\tau' \succeq \tau\) so that \(\tau' \in T^1_\beta, \forall^0_{\beta^*}(\sigma)(\uparrow \tau' \uparrow) = 1\) and \((\sigma \uparrow j[\langle \beta' \rangle], \tau' \uparrow j[\langle \beta' \rangle]) \in T_\alpha\) for some \(\lambda \in \Lambda(\beta)\) and \(\tau' \text{ such that } \tau' = p_{\beta, \Lambda}(\tau' \uparrow)\).

Then the tree \(T_\beta\) is as required. Since the construction is uniform, the rest of (1)-(6) follow. This completes the proof of Theorem 11.2.2.

By \(\Sigma^1_1\)-boundedness, we have the following generalization:

### Corollary 11.2.11 (Harrington). There is an uncountable $\Pi^1_2$-set $A$ such that for any recursive ordinal $\beta$ and $x \in A$, $x^{(\beta)} \not\ge_T 0^{(\beta+1)}$.

Proof. Suppose not. Let $B = \omega \times \omega^{<\omega}$ be arithmetical such that $[\{B_e\}]_{e < \omega}$, where $B_e = \{ \alpha \in \omega^{<\omega} \mid (e, \alpha) \in B \}\), is a recursive list of all $\Pi^1_1$-subsets of $\omega^{<\omega}$. Let $O \subseteq \Theta\) be as defined in Theorem 2.6.5.

Recall that the system satisfying (1)–(6) was obtained by fixing an ordinal notation $n$ with $|n| \ge \omega$. Let $e_0$ be such that $3 \cdot 5^{e_0} = \omega$. Define a $\Pi^1_1$-relation $R \subseteq \omega \times \omega$ such that

$R(e, n) \Leftrightarrow 3 \cdot 5^{e_0} \le_\Theta n \wedge n \in \Theta \wedge$

there is no system satisfying (1)–(6) for $n$ and $B_e = T_0^0$.

Then by Theorem 4.2.1 and the assumption, there is a total $\Pi^1_1$, hence $\Delta^1_1$, uniformizing function $f : \omega \to O$ for $R$. Let $I = \{ e \mid [B_e] > \aleph_0 \}$. By Theorem 11.10, $I$ is $\Sigma^1_1$. By Corollary 11.5.2, there is an $n \in O$ such that for all $m \in I, f(e) \in e \mid I$, we have $m <_\Theta n$ and that contradicts the proof above.

Hence there is an $e \in I$ such that $B_e = T_0^0$ and a system satisfying (1)–(6) exists for each $n \in O$ where $|n| \ge \omega$. By the proof above, $H_n^1 \not\ge_T H_{2n}$.

## 11.3 Perfect sets in L

### 11.3.1 A question of Prikry

In [98], Prikry posed the following question.

### Question 11.3.1. Suppose that there is a nonconstructible real. Does every perfect set contain a nonconstructible real?

Friedman [29] also raised a question related to Question 11.3.1:

### Question 11.3.2. Suppose that there is a nonconstructible real. Is $L \cap \mathbb{R} \Sigma^1_1$-set?

By Theorem 11.1.10, a positive answer to Question 11.3.1 would imply a negative solution to Question 11.3.2. The latter was given a negative solution by Velickovic and Woodin:

### Theorem 11.3.1 (Velickovic and Woodin ([66]). If the set of constructible reals is $\Sigma^1_1$, then either $\omega_1^{ck}$ is countable or every real is constructible.

On the other hand, Question 11.3.1 was answered positively by Groszek and Slaman [41] and the solution is discussed in the next section.

### Theorem 11.3.4. If there is a perfect set $A \subseteq (2^\omega)^L$, then every real is constructible.

### 11.3.2 The proof of Theorem 11.3.4

Given a tree $T \subseteq 2^{<\omega}$, a set $A \subseteq 2^\omega$ is dense in $T$ if for any $\sigma \in T$, $[\sigma] \cap T \cap A \neq \emptyset$. A real $x \in [T]$ is eventually constant in $T$ if there is an $n$ such that $x$ is the leftmost or rightmost infinite path in $[x \restriction n] \cap T$.

### Lemma 11.3.5. Let $T$ be a perfect tree. Suppose that $\{g_i\}_{i<\omega} \in L$ contains a dense subset of $T$ no member of which is eventually constant in $T$. Then for any $z$, there exist $x, y \in [T]$ such that $x \oplus y \oplus (\oplus_{i<\omega} g_i) \ge_T z$.

Assume Lemma 11.3.5. Let $T$ be a perfect tree such that $[T] \subseteq L$. Then $(\omega_1)^L = \omega_1$. Select a countable sequence $\{x_i\}_{i<\omega}$ from $[T]$ which is dense and such that no $x_i$ is eventually constant. Since $(\omega_1)^L = \omega_1$, there is an $x^* \in L$ such that $x_i <_L x^*$ for each $i < \omega$. Let $\{g_i\}_{i<\omega}$ be an enumeration of the set $\{x \mid x <_L x^*\}$. Note that $\{g_i\}_{i<\omega}$ belongs to $L$. By Lemma 11.3.5, for each $z$ there exist $x, y \in [T]$, and hence in $L$, such that $x \oplus y \oplus (\oplus_{i<\omega} g_i) \ge_T z$ such that $z \in L$.

The idea of the proof is as follows. Suppose $z$ is a given real, $T$ is perfect and $\{g_i\}_{i<\omega} \in L$ is a sequence with a subset dense in $T$ no element of which is eventually constant in $T$. We define $x \in [T]$ and an index function $h_x : \omega \to \omega$ such that for each $i$, $h_x(i)$ is a path through $T$ that is not eventually constant in $T$. The set $x$ agrees with $g_{h_x(i)}$ on longer and longer initial segments as $i$ increases, and $z$ is coded into $x$ and $\{g_{h_x(i)}\}_{i<\omega}$ so that $z(i)$ is the value of $x$ at the first place where $x$ differs from $g_{h_x(i)}$. It is easy to see that $z \le_T x \oplus h_x \oplus (\oplus_{i<\omega} g_i)$. There is no problem to recursively define such an $x$ and $h_x$.

The challenge is to decode $h_x$. This is handled by defining another real $y \in [T]$ such that $h_x \le_T x \oplus y \oplus (\oplus_{i<\omega} g_i)$. To achieve this, we define an additional index function $h_y : \omega \to \omega$ with the same properties (except that $z$ is not coded here), in such a way that $h_x$ and $h_y$ can be computed from $x$, $y$ and $\oplus_{i<\omega} g_i$.

### Proof of Lemma 11.3.5. We now describe the construction of the sets $x$, $y$ and functions $h_x, h_y$.
