
Stage 0. Let \(\sigma_0\) and \(\tau_0\) be the first splitting node of \(T\) extending its root, i.e. a splitting node of \(T\) such that every node in \(T\) extends either \(\sigma_0\) or \(\tau_0\). Let \(h_x(0)\) be the least \(i\) such that \(T_i \models [z^\frown \sigma] \cap [T]\), and let \(h_y(0)\) be the least \(j\) such that \(g_j \models [\tau_0] \cap T\).

Stage \(n + 1\). Assume by induction hypothesis that \(\sigma_n\) and \(\tau_n\) are splitting nodes in \(T\), and that \(\sigma_n z^n(n)\) and \(\tau_n h_n(n)\).

Substage (a). Define \(j_0\) to be the least index \(j\) so that \(g_j \in [\sigma_n (1 - z(n))] \cap [T]\) is not eventually constant. Let \(m_0\) be the least \(m > |\tau_n|\) so that \(g_i \models m_i \neq g_{j_0} \models m\) for every \(i < j_0\). Let \(m_1\) be the least \(m > m_0\) such that \(g_{h_n(n)} \models m\) is a splitting node in \(T\). Let \(t' = g_{h_n(n)} \models m_i \models (1 - g_{h_n(n)}(m_i))\). Then \(g_i \models m_i \neq g_{j_0} \models m\) for \(i < j_0\) and node \(m_1\) is the least \(m\) such that \(t' \models m \neq g_{h_n(n)}(m)\).

Substage (b). Let \(j_1\) be the least \(j\) such that \(g_j \in [t'] \cap [T]\). Let \(m_2\) be the least \(m\) such that for any \(i < j_1\), \(g_i \models m \neq g_{j_1} \models m\). Since \(g_{j_0}\) is not eventually constant, we may choose \(m_3\) to be the least \(m > m_2\) such that \(g_{j_0} \models m\) is a splitting node in \(T\) and \(g_{j_0} > g_{j_0} \models m_i (n + 1)\). Then \(g_i \models m_i \neq g_{j_1} \models m_3\) for \(i < j_1\). Let \(\sigma_{n+1} = g_{j_0} \models m_3\), \(\tau_{n+1} = g_{j_1} \models m_3\), \(h_x(n + 1) = j_0\) and \(h_y(n + 1) = j_1\).

Let \(x = \bigcup_{n < \omega} \sigma_n\) and \(y = \bigcup_{n < \omega} \tau_n\). This completes the construction.

The construction ensures that for every \(n\), \(h_x(n + 1)\) is the least \(i\) such that \(g_i \models m_i = x \models m_1\) where \(m_1\) is the least \(m\) satisfying \(y(m) \neq g_{h_n(n)}(m)\). Also, \(h_y(n + 1)\) is the least \(i\) such that \(g_i \models m_3 = y \models m_3\) where \(m_3\) is the least \(m\) such that \(x(m) \neq g_{h_n(n+1)}(m)\). Hence \(h_x \leq_T y \leq_T x \oplus y \oplus (\exists_{i < \omega} g_i)\), giving \(z \leq_T x \oplus y \oplus (\exists_{i < \omega} g_i)\).

## 12 Review of classical algorithmic randomness

We assume familiarity with the classical theory of algorithmic randomness and give a review of the subject in this chapter. For details see [111] and [24].

### 12.1 Randomness via measure theory

Intuitively, a random real should pass every feasible statistical test. This is the motivation for using measure theory to define randomness. In the language of measure theory, a test is associated with a null set. The following is a summary of the key notions of measure theoretic-randomness.

#### 12.1.1 Kurtz and Schnorr randomness

The notion of (now called) Kurtz randomness was introduced in Kurtz [79].

**Definition 12.1.1.** (i) A set \(A \subseteq 2^\omega\) is a *Kurtz test* if it is \(\Pi^0_1\) and \(\mu(A) = 0\); (ii) a real \(x\) is *Kurtz random* if \(x \notin A\) for every Kurtz test \(A\).

**Definition 12.1.2** (Schnorr [125] and [127]). (i) A sequence of open sets \(\{U_n\}_{n<\omega}\) is a *Schnorr test* if \(\{(n, \sigma) \mid \sigma \in U_n\}\) is r.e. and \(\mu(U_n) = 2^{-n}\) for every \(n < \omega\); (ii) a real \(x\) is *Schnorr random* if \(x \notin \bigcap_{n<\omega} U_n\) for every Schnorr test \(\{U_n\}_{n<\omega}\).

**Proposition 12.1.3** (Terwijn and Zambella [163]). A real \(x\) is Schnorr random if and only if \(x \notin \bigcap_{n<\omega} V_n\) for every sequence of open sets \(\{V_n\}_{n<\omega}\) such that \(\{(n, \sigma) \mid \sigma \in V_n\}\) is r.e. and \(\mu(V_n) = 2^{-f(n)}\) for some recursive function \(f\).

#### 12.1.2 Martin-Löf randomness

The notions of Kurtz and Schnorr randomness both turn out to be somewhat restrictive and unsatisfactory. The next notion, due to Martin-Löf, is perhaps the most widely studied to-date.

**Definition 12.1.4** (Martin-Löf [96]). (i) A sequence of open sets \(\{U_n\}_{n<\omega}\) is a *Martin-Löf test* if \(\{(n, \sigma) \mid \sigma \in U_n\}\) is r.e. and \(\mu(U_n) < 2^{-n}\) for every \(n < \omega\); (ii) a real \(x\) is *Martin-Löf random* if \(x \notin \bigcap_{n<\omega} U_n\) for every Martin-Löf test \(\{U_n\}_{n<\omega}\).

The next result says that Martin-Löf randomness is decided by a single test.

**Proposition 12.1.5** (Martin-Löf [96]). *There exists a universal Martin-Löf test. Namely, there is a Martin-Löf test* \(\{U_n\}_{n<\omega}\) *such that* \(\bigcap_{n<\omega} V_n \subseteq \bigcap_{n<\omega} U_n\) *for every Martin-Löf test* \(\{V_n\}_{n<\omega}\).

#### 12.1.3 Strong Martin-Löf randomness

**Definition 12.1.6** (Kurtz [79]).
(i) A sequence of open sets \(\{U_n\}_{n<\omega}\) is a generalized Martin-Löf test if \(\{(n, \sigma) \mid \sigma \in U_n\}\) is r.e. and \(\lim_{n \to \infty} \mu(U_n) = 0\);
(ii) a real x is strongly Martin-Löf random if \(x \notin \bigcap_{n<\omega} U_n\) for any generalized Martin-Löf test \(\{U_n\}_{n<\omega}\).

Strong Martin-Löf randomness has a number of regularity properties not shared by Martin-Löf randomness.

#### 12.1.4 Relativized randomness

Each of the notions above may be relativized to an arbitrary real x. For example, an x-Martin-Löf test is a sequence of open sets \(\{U_n\}_{n<\omega}\) such that \(\{(n, \sigma) \mid \sigma \in U_n\}\) is x-r.e. and \(\mu(U_n) < 2^{-n}\) for every \(n \in \omega\). Then z is x-Martin-Löf random if \(z \notin \bigcap_{n<\omega} U_n\) for any x-Martin-Löf test \(\{U_n\}_{n<\omega}\). In particular, z is n-random if z is \(0^{(n-1)}\)-Martin-Löf random.

The following is known as van Lambalgen's Theorem.

**Theorem 12.1.7** (van Lambalgen [165]). \(x \oplus y\) is Martin-Löf random if and only if x is Martin-Löf random and y is x-Martin-Löf random, and also if and only if y is Martin-Löf random and x is y-Martin-Löf random.

Martin-Löf randomness seems to be the only randomness notion for which van Lambalgen's Theorem holds.

#### 12.1.5 Relative strengths of randomness notions

The relative strengths of the notions of randomness introduced above may be summarized as follows. Note that the implications do not reverse:

- Strong Martin-Löf randomness \(\Rightarrow\) Martin-Löf randomness
- \(\Rightarrow\) Schnorr randomness
- \(\Rightarrow\) Kurtz randomness

A real \( x \) is *recursively dominated* if every function \( f \le_T x \) is dominated by a recursive function. The following result gives a characterization of strong Martin-Löf randomness for recursively dominated reals.

**Proposition 12.1.8 (Yu).** If \( x \) is recursively dominated, then \( x \) is strongly Martin-Löf random if and only if it is Kurtz random.

Next is a characterization of Martin-Löf randomness in terms of Schnorr randomness.

**Theorem 12.1.9 (Nies, Terwijn and Stephan [112]).** For any real \( x \),
(i) if \( x \) is Schnorr random and \( x' \not\ge_T 0'' \), then \( x \) is Martin-Löf random;
(ii) if \( x' \ge_T 0'' \), then there is a Schnorr random real \( y \equiv_T x \) such that \( y \) is not Martin-Löf random.

#### 12.1.6 The computational power of random reals

The following theorem says that random reals may have very strong computational power:

**Theorem 12.1.10 (Kučera [76]).** *For any real* \( x \ge_T 0' \)*, there is a Martin-Löf random real* \( z \equiv_T x \).

Rather unexpectedly, strong Martin-Löf randomness does not yield the same conclusion:

**Theorem 12.1.11 (Downey, Nies, Weber, Yu [23] and Hirschfeldt, Miller).** *A real* \( x \) *is strongly Martin-Löf random if and only if* \( x \) *is Martin-Löf random and Turing computes no nonrecursive* \( \Delta_2^0 \)*-real.*

In algorithmic randomness theory, there is a thesis which states that *more randomness means less computational power*. Although a random real \( x \) contains much information, the information may be computationally useless in the sense that it cannot be used to predicate any set except the set \( x \) itself. There is much evidence in the literature to support this thesis. We give some examples.

**Definition 12.1.12.** Let \( h \) be a function. A real \( x \) is \( h \)-diagonally nonrecursive, abbreviated \( h \)-DNR, if there is a function \( f \le_T x \) such that \( f(e) \neq \Phi_e(e) \) and \( f(e) < h(e) \) for every \( e < \omega \). We say that \( x \) is DNR if there is a function \( f \le_T x \) such that \( f(e) \neq \Phi_e(e) \) for \( e < \omega \).

The next theorem implies that no incomplete Martin-Löf random real is 2-DNR.

**Theorem 12.1.13 (Stephan).** *Suppose that* \( x \in 2^\omega \) *is Martin-Löf random. Then* \( x \) *is* 2*-DNR if and only if* \( x \ge_T 0' \).
