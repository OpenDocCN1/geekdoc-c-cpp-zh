\(\psi_{\beta, \Lambda}(\sigma_m) = \psi_{\beta_{<m}, \Lambda}(\psi_{\beta, \beta_{<m}}(\sigma_m)) = \psi_{\beta_{<m}, \Lambda}(\sigma_m) = x \mid m\). Thus \(\psi_{\Lambda, \beta}(z) = x\). In other words, \(\psi\) is onto.

Now suppose that \(x_0, X_1 \in [T^0_\beta]\), \(x_0 \mid n_0 = x_1 \mid n_0 = \sigma_0\), \(x_0 \succ \sigma' k_0\), \(x_1 \succ \sigma' k_1\) for some \(k_0 \neq k_1\). Let \(j > |\sigma| + 1\) be such that \(\beta_{j, \Lambda} > \beta\). Then \(\psi_{\beta, \beta_{j, \Lambda}}(x_0 \mid [\sigma] + 1) = x_0 \mid [\sigma] + 1 \uparrow x_0 \mid [\sigma] + 1 = \psi_{\beta, \beta_{j, \Lambda}}(x_1 \mid [\sigma] + 1)\). By induction, \(\psi_{\beta, \beta_{j, \Lambda}}(y_0) \neq \psi_{\beta, \beta_{j, \Lambda}}(y_1)\) for any \(y_0 \succ x_0 \mid [\sigma] + 1\) and \(y_1 \succ x_1 \mid [\sigma] + 1\). By Lemma 11.2.9 (ii), \(\psi_{\Lambda, \beta}(x_0) \neq \psi_{\Lambda, \beta}(x_1)\).

Hence for \(\gamma = \Lambda\), \(\psi_{\gamma, \beta}\) is a bijection between \([T^0_\gamma]\) and \([T^0_\beta]\). Clearly both \(\psi_{\gamma, \beta}\) and \(\psi^{-1}_{\gamma, \beta}\) are continuous. Hence \(\psi_{\gamma, \beta}\) is a homeomorphism.

By (3), \(T^0_\beta\) is a recursive tree. By the Recursion Theorem, one may assume that there is already a system satisfying (1)-(6). We define \(T_\beta\) from \(T_{\beta^*}\). Let.
\(T^1_\beta = P_{\beta, \beta_{<\Lambda}}(T^{0\beta\sigma})\)
be a recursive tree. Recursively compute \(f(\beta)\).

For \(\sigma \in \omega^{<\beta}\), let \(T^{0\beta}_\sigma\) be a \(\theta^{(\beta)}\)-recursive tree obtained from Lemma 11.2.5 upon replacing \(T\) with \(\{\tau \mid \sigma' \tau \in T^{0\beta}_\sigma\}\) and \(x\) with \(\theta^{(\beta)}\). Relativizing Lemma 11.2.6 to \(\theta^{(\beta)}\) (replacing \(T_0\) with \(T^{0\beta}_{\sigma, \sigma}\)), we have a \(\theta^{(\beta)}\)-recursive homeomorphism \(\psi_\sigma : T^{0\beta}_{\sigma, \sigma} \to T^{0\beta}_{\sigma, \sigma}\) where \(T^{0\beta}_{\sigma, \sigma}\) is \(T_1\) in Lemma 11.2.6. Define \(T^0_\beta\) to be a \(\theta^{(\beta)}\)-recursive tree such that \(\tau \in T^0_\beta\) if and only if either

+   - \((\tau, P^0_{\beta^*, \Lambda}(\forall \beta' \langle j[\beta']\rangle) \in T_\alpha \cap \alpha \omega^{S(\beta)} \times \alpha \omega^{S(\beta)}\) for some \(\lambda \in \Lambda(\beta)\), or

+   - \(\tau = (\tau \uparrow j[\langle \beta' \rangle] \uparrow \tau' \text{ for some } \tau' \in T^0_{\beta, \tau \uparrow j[\langle \beta' \rangle]}\).

Define \(\psi_{\beta^*, \beta} \le_T \theta^{(\beta)} : T^0_{\beta^*} \to T^0_\beta\) such that

+   - if \((\tau, P^0_{\beta^*, \Lambda}(\forall \beta' \langle j[\beta']\rangle)) \in T_\alpha \cap \alpha \omega^{S(\beta)} \times \alpha \omega^{S(\beta)}\) and \(\lambda \in \Lambda(\beta)\), then \(\psi_{\beta^*, \beta}(\tau) = \tau\);

+   - otherwise, let \(\tau = (\tau \uparrow j[\langle \beta' \rangle] \uparrow \tau'\). Define \(\psi_{\beta^*, \beta}(\tau) = \tau \uparrow j[\langle \beta' \rangle] \uparrow \psi_{\theta(\beta)}(\tau' \uparrow (\oplus_{\beta \in \beta^*} \uparrow \tau' \uparrow))\).

Hence for any \(x \in T^0_\beta\),
\((x \oplus \theta(\beta))' \equiv_T x \oplus \theta(\beta') \equiv_T \psi^{-1}_{\beta^*, \beta}(x) \oplus \theta(\beta')\).

Note that \(T^0_\beta = T^0_{\beta^d}\) (see (3)) for some \(d\) which is independent of \(\beta\). Define \(T_\beta\) such that \((\sigma, \tau) \in T_\beta\) if and only if either

+   - there exists a \((\sigma, \tau) \in T_\alpha \cap \alpha \omega^{S(\beta)} \times \alpha \omega^{S(\beta)}\) for some \(\lambda \in \Lambda(\beta)\) such that \(\tau = p_{\beta, \Lambda}(\tau)\), or

+   - or there is a \(\tau' \succeq \tau\) so that \(\tau' \in T^1_\beta, \forall^0_{\beta^*}(\sigma)(\uparrow \tau' \uparrow) = 1\) and \((\sigma \uparrow j[\langle \beta' \rangle], \tau' \uparrow j[\langle \beta' \rangle]) \in T_\alpha\) for some \(\lambda \in \Lambda(\beta)\) and \(\tau' \text{ such that } \tau' = p_{\beta, \Lambda}(\tau' \uparrow)\).

Then the tree \(T_\beta\) is as required. Since the construction is uniform, the rest of (1)-(6) follow. This completes the proof of Theorem 11.2.2.
