Suppose $\mathcal{C}$ is not thin. Let

$B = \{T \in 2^{<\omega} \mid T \text{ is a perfect tree in which every infinite path belongs to } \mathcal{C}\}.$

Then $B$ is a $\Pi^1_1$-set. By Theorem 4.1.2, there is a $T \in B$ with $T \in L_\omega$. By relativizing the Gandy Basis Theorem (2.5.3) to $T$, there is a real $x \in [T] \subseteq \mathcal{C}$ such that $x \not\le_h T$ and $\omega_1^x \le \omega_1^{x \oplus T} = \omega_1^T$. Hence $x \notin L_\omega$, a contradiction.

**Lemma 4.3.2** (Mansfield [87], Solovay [149]). Let $A \subseteq 2^\omega$ be $\Pi^1_1$. If there is an $x \in A$ such that $x \notin L_\omega$, then there is a perfect tree $T \in L$ all of whose infinite paths belong to $A$.

**Proof.** Let $\mathcal{C}$ be defined as before. Suppose $A \subseteq 2^\omega$ is $\Pi^1_1$ and there is an $x \in A \setminus \mathcal{C}$. Let $\alpha_0$ be the least ordinal $\alpha$ such that $\alpha = \alpha_1^x$ for some $x \in A \setminus \mathcal{C}$.

Let $T_0$ be a tree presentation of $A$ and $T_0^\alpha$ be defined as in the proof of Theorem 4.1.2. Since $\mathcal{C}$ is a $\Pi^1_1$-set, there is a recursive tree $T_1 \subseteq 2^{<\omega} \times \omega^{<\omega}$ such that $x \notin \mathcal{C}$ if and only if $(\exists y)((\exists x, y) \in [T_1])$. Now let $T_2 \subseteq 2^{<\omega} \times \omega^{<\omega} \times 2^{<\omega}$ be a tree defined as follows: $(\sigma, p, \tau) \in T_2$ if and only if $(\sigma, p) \in T_0^\alpha$ and $(\sigma, \tau) \in T_1$. By assumption, there is an infinite path $(x, f, y)$ in $T_2$.

We claim that for any $(\sigma, p, \tau) \in T_2$, if there is an infinite path in $T_{2, (\sigma, p, \tau)} = \{(\sigma', p', \tau') \in T_2 \mid (\sigma', p', \tau') \succ (\sigma, p, \tau)\}$, then there are $(\sigma_0, p_0, \tau_0)$ and $(\sigma_1, p_1, \tau_1)$ in $T_{2, (\sigma, p, \tau)}$, with $\sigma_0$ and $\sigma_1$ incompatible, such that both $T_{2, (\sigma_0, p_0, \tau_0)}$ and $T_{2, (\sigma_1, p_1, \tau_1)}$ have infinite paths. Otherwise, fix a $(\sigma, p, \tau) \in T_2$ for which this is false. Then there is an infinite path $(x, f, y)$ in $T_{2, (\sigma, p, \tau)}$. Note that $\omega_1^x \ge \alpha_0$. By assumption, for any $\sigma' \succ \sigma$ that is not an initial segment of $x$, the tree

$T_{2, \sigma'} = \{(\sigma'', p'', \tau'') \in T_{2, (\sigma, p, \tau)} \mid \sigma' > \sigma\}$

is wellfounded. Then by the same proof as that of Theorem 4.1.2, there is a $\gamma < \omega_1^x$ such that the set $\{\sigma' \mid \sigma' \times \kappa \times \kappa \times \kappa \times \kappa (\exists \sigma'', p'', \tau'') \in T_{2, (\sigma, p, \tau)}\}$ belongs to $L_\gamma$. Then $x \in L_{\gamma+1} \subseteq L_\omega$, contradicting the fact that $x \notin \mathcal{C}$.

By the claim, one may carry out the first construction of Theorem 1.1.10 to obtain a perfect tree all of whose paths belong to $A$. Thus the set $\{T \mid T \text{ is perfect } \cap [T] \subseteq A\}$ is a nonempty $\Pi^1_1$-set. By Theorem 4.1.2, there is a perfect tree $T \in L$ such that $[T] \subseteq A$.

By Lemma 4.3.1 and Lemma 4.3.2, we have the following characterization of the largest thin $\Pi^1_1$-set.

**Theorem 4.3.3.** $\mathcal{C}$ is the largest thin $\Pi^1_1$-set.

# 4.3.2 Some properties of $\mathcal{C}$

Since every $\Pi^1_1$-set of reals contains an $x \in \mathcal{C}$ that is also a $\Pi^1_1$-singleton, one may ask if every real in $\mathcal{C}$ is a $\Pi^1_1$-singleton. This is false since $\mathcal{C}$ is uncountable in $L$.
