$L_{\omega_1^{CK}}^x$ is admissible. Hence by Theorem 3.1.8, there is an ordinal $\gamma < \omega_1^{CK}$ and an order-preserving function $g : T_{[n]} \to \gamma$.

Let $\varphi(n)$ be the statement

$(\exists y)(\exists g)(y \text{ is an ordinal } \wedge g \text{ is an order-preserving function from } T_{[n]} \text{ into } y)$.

In other words, $n \in x \Rightarrow (L_{\omega_1^{CK}}^x, \in) \models \varphi(n)$. On the other hand, if $(L_{\omega_1^{CK}}^x, \in) \models \varphi(n)$, then $T_{[n]}$ is wellfounded. Thus $n \in x$.

For the other direction, suppose that there is a $\Sigma_1$-formula $\varphi(u)$ such that $n \in x \Leftrightarrow (L_{\omega_1^{CK}}^x, \in) \models \varphi(n)$. Since $\varphi(u)$ is $\Sigma_1$, by Proposition 3.5.5, $(L_{\omega_1^{CK}}^x, \in) \models \varphi(n)$ if and only if for any $E$, if $(\omega, E)$ codes an $\omega$-model of KP, then $(\omega, E) \models \varphi[n_E]$ where $n_E$ denotes the number in $(\omega, E)$ which codes $n$. By Proposition 3.6.3, $x \in \Pi_1^1$.

Notwithstanding the remark in [107] that "the Spector–Gandy Theorem does not have many applications but it is undoubtedly one of the jewels of the effective theory", it is a major result and has seen important applications in higher recursion theory. For example, the theorem allows one to develop a robust computation theory for the structure $(L_{\omega_1^{CK}}^x, \in)$, including implementation of the priority method to study the metadegrees of $\Pi_1^1$-sets.

A generalization of Theorem 3.7.1 that lifts the result to sets of reals is the following.

**Corollary 3.7.2.** For any real $y$, a set $A \subseteq 2^\omega$ is $\Pi_1^1(y)$ if and only if there is a $\Sigma_1$-formula $\varphi(u, v)$ such that $x \in A \Leftrightarrow (L_{\omega_1^{CK}}[x \oplus y], \in) \models \varphi(x, y)$.

It should be pointed out that the statement in the corollary remains valid if one replaces $2^\omega$ with $\omega^\omega$ in Corollary 3.7.2.

# 3.7.2 Second version

Let $0^*$ be as defined in § 2.6. Fix a number $i \in 0^* \setminus 0$. Then by the results in the same section, the set $0_i^* = \{j \mid j <_{0^*} i\}$ is an r.e. set such that $0_i^* \cap 0$ is an initial segment of $0^*$ of order type $\omega_1^{CK}$. By Lemma 2.2.4, there is a recursive function $g$ such that if $n \in 0$, then $0_n = \Phi_{g(n)}^{0_i^*}$.

For any real $z$ and $n \in \omega$, let $(z)_n = \{m \mid 2^n 3^m \in z\}$. Let $A(n, z)$ be an arithmetical predicate defined as follows: There is an $m <_{0^*} i$ such that

+   (1) $(z)_i = \emptyset$;
+   (2) $(\forall j)((j \prec_{0^*} 2^n) \to (z)_j = ((z)_j)')$;
+   (3) $(\forall y)(3^{x+5} \prec_{0^*} 2^n \to (\forall k)((z)_{y,3} s^* = (z)_{\varphi(x, k)});
+   (4) n \in \Phi_{g(m)}^{(2)_m}$, and
+   (5) $(\forall j)((j \prec_{0^*} 2^n) \to (z)_j \le_T (z)_{2^n})$.

Roughly speaking, $A(n, z)$ says that there is an $m <_{0^*} i$ such that $z$ codes an iteration of Turing jumps along the set $\{j \mid j \prec_{0^*} m\}$ and $n \in 0_m = \Phi_{g(m)}^{(2)_m}$. Then for any $n \in 0_i^* \cap 0$, $(z)_n = H_n$.
