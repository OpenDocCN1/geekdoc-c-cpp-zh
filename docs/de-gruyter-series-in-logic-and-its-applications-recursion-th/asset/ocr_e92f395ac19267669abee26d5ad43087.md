Proof of Claim 2. Suppose not. We obtain a winning strategy $\tilde{\sigma}$ for I playing $G_A$ as follows:

By Claim 1, there is an $m$ such that no hyperarithmetic function $f \in C$ exists for which $f(m)$ is defined. Let $\tilde{\sigma}(0) = m$. Note that by (iii), for any hyperarithmetic $f \in C$ and number $j$, $f(m^j)$ is undefined.

By induction on $k$, for any play $(i_0, j_0, \dots, i_k)$ at step $k$ by I following $\tilde{\sigma}$, there is no hyperarithmetic $f \in C$ such that $f((i_0, j_0, \dots, i_k))$ is defined. Then for any $j_k$ and any hyperarithmetic $f \in C$, $f((i_0, j_0, \dots, i_k, j_k))$ is undefined. By Claim 1, there is a $i_{k+1}$ for which there is no hyperarithmetic function $f_{i_{k+1}} \in C$ so that $f_{i_{k+1}}((i_0, j_0, \dots, i_k, j_k, i_{k+1}))$ is defined. Let $\tilde{\sigma}((i_0, j_0, \dots, i_k, j_k)) = i_{k+1}$. Then $\tilde{\sigma}$ is a winning strategy for I, contradicting the assumption.

Thus there is a hyperarithmetic function $g \in C$ such that $g(0) \in \mathcal{O}$. We define a hyperarithmetic strategy $\tilde{\tau}_g$ for II as follows: For each $n$, let $\tilde{\tau}_g(n) = m$ where $g(m) <_{\mathcal{O}} g(0)$. For each $k$ and $a \in \omega^{<\omega}$ with even length, let $\tilde{\tau}_g(a * k) = m$ where $(a * k * m) <_{\mathcal{O}} g(a)$ (if it exists).

We claim that $\tilde{\tau}_g$ is II's winning strategy. To see this, for any $h \in \omega^\omega, g(h * \tilde{\tau}_g \upharpoonright 2k + 2) <_{\mathcal{O}} g(h * \tilde{\tau}_g \upharpoonright 2k)$ for any $k$ with $g(h * \tilde{\tau}_g \upharpoonright 2k) > 1$. Since $g(0) \in \mathcal{O}$, there is a $k$ such that $g(h * \tilde{\tau}_g \upharpoonright 2k) = 1$. Thus $h * \tilde{\tau}_g \in \omega^\omega \setminus A$.

A general basis theorem for the analytical hierarchy is the following Third Periodicity Theorem due to Moschovakis.

# Theorem 6.6.2 (Moschovakis [107]).

+   (i) Suppose that every $\Sigma^1_{2n}$-set is determined. If I has a winning strategy for $G_A$ where $A$ is $\Sigma^1_{2n}$, then I has a $A^1_{2n+1}$-winning strategy.

+   (ii) Suppose that every $A^1_{2n}$-set is determined. If I has a winning strategy for $G_A$ where $A$ is $\Pi^1_{2n+1}$, then I has a $\Delta^1_{2n+2}$-winning strategy.

# 6.6.2 Cones of Turing degrees

A set $\mathbf{A}$ of Turing degrees is a cone if there exists a $\mathbf{z}$ such that $\mathbf{A} = \{\mathbf{x} \mid \mathbf{x} \ge \mathbf{z}\}$. We say that $\mathbf{z}$ is the base of $\mathbf{A}$. 

Proposition 6.6.3. Assume ZF + AD. For any set $\mathbf{A}$ of Turing degrees, either $\mathbf{A}$ or its complement contains a cone of Turing degrees.

Proof. Let $A = (\mathbf{x} \mid \mathbf{x} \in \mathbf{A})$. Suppose that I has a winning strategy $\tilde{\sigma}$ for $G_A$. Then for any $g \ge_T \tilde{\sigma}, h * g \equiv_T g$. Thus $g \in A$. Hence $\mathbf{A}$ contains a cone of Turing degrees.

If II has a winning strategy $\tilde{\tau}$ for $G_A$, then by the same argument, the complement of $\mathbf{A}$ contains a cone of Turing degrees.
