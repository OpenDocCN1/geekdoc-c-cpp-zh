## 6.2.2 Random forcing

Random forcing was introduced by Solovay [150] to construct a model of ZF + DC in which every set of reals is Lebesgue measurable.

### Definition 6.2.5. Let \(\mu\) denote the Lebesgue measure. Random forcing \(\mathbb{R} = (\mathbf{T}, \le)\) is a notion of forcing where

- every \(T \in \mathbf{T}\) is a subtree of \(2^{<\omega}\) such that \(\mu([T]) > 0\);
- \(T_1 \le T_2\) if and only if \(T_1 \subseteq T_2\).

### Proposition 6.2.6. Random forcing satisfies c.c.c.

Proof. Suppose that there is an uncountable antichain \(\{T_\alpha\}_{\alpha < \omega_1}\). Then for \(\alpha \neq \beta < \omega_1\), \(\mu([T_\alpha] \cap [T_\beta]) = 0\). Let \(S_\alpha = [T_\alpha] \setminus \bigcup_{\beta < \alpha} [T_\beta]\). Then \(\{S_\alpha\}_{\alpha < \omega_1}\) is an uncountable sequence of pairwise disjoint Borel sets with \(\mu(S_\alpha) > 0\) for each \(\alpha < \omega_1\). Let \(n\) be such that the set \(R_n = \{S_\alpha \mid \mu(S_\alpha) > \frac{1}{n}\}\) is uncountable. Then \(1 = \mu(2^\omega) \ge \mu(\bigcup_{S \in R_n} S_\alpha) = \infty\), a contradiction.

A real \(x\) is random if it is \(\mathbb{R}\)-generic.

## 6.2.3 Collapsing cardinals

Let \(\kappa\) be a cardinal. There is a notion of forcing that collapses all cardinals below \(\kappa\) while preserving \(\kappa\): Let \(\mathbb{P}(\kappa) = (\kappa^{<\omega}, \le)\) and for \(p, q \in \kappa^{<\omega}\), define \(q \le p\) if and only if \(q \supseteq p\). Then \(\mathbb{P}(\kappa)\) satisfies \(\kappa^+\)-c.c. Moreover, for any generic filter \(G\), the function \(g = \bigcup_{p \in G} p\) maps \(\omega\) onto \(\kappa\). Thus we have

### Proposition 6.2.7. Suppose that \(\kappa \ge \omega_1\) is a cardinal. Then

- (i) \(\mathbb{P}(\kappa)\) satisfies \(\kappa^+\)-c.c.;
- (ii) If \(G\) is generic, then \(\kappa^+ = (\omega_1)^{M[G]}\).

Note that \(\mathbb{P}(\kappa)\) only preserves the successor cardinal \(\kappa^+\). The next notion of forcing allows one to preserve limit cardinals which are regular.

### Definition 6.2.8. Let \(\kappa \ge \omega\) be a cardinal. Define Lévy forcing for \(\kappa\), \(\mathbb{L}(\kappa) = (\mathbb{L}_\kappa, \le)\), as follows:

- \(p \in \mathbb{L}_\kappa\) if and only if \(p\) is a finite function mapping a subset of \(\kappa \times \omega\) into \(\kappa\) such that for any \(\alpha < \kappa\) and \(n < \omega\), if \(p(\alpha, n)\) is defined, then \(p(\alpha, n) < \alpha\).
- For any \(p, q \in \mathbb{L}_\kappa\), \(q \le p\) if and only if \(q \supseteq p\).

\(\mathbb{L}(\kappa)\) may be considered as product forcing with finite support of length \(\kappa\), where at each \(\alpha < \kappa\) the forcing action collapses \(\alpha\) onto \(\omega\).

### Proposition 6.2.9. Let \(\kappa \ge \omega\) be a regular cardinal and let \(G\) be \(\mathbb{L}(\kappa)\)-generic. Then \(\kappa = (\omega_1)^{M[G]}\).

Proof. It is clear that for any \(\alpha < \kappa\), \(G(\alpha) = \bigcup_{n \le p \in G} p(\alpha, n)\) maps \(\omega\) onto \(\alpha\). Hence \(M[G] \models \kappa \le \omega_1\). We prove that \(\mathbb{L}(\kappa)\) satisfies c.c.c.

Suppose that \(A \subseteq \mathbb{L}_\kappa\) is an antichain of cardinality \(\kappa\). Without loss of generality, we may assume that there is an \(n^*\) such that \(|\text{Dom}(p)| = n^*\) for every \(p \in A\). We claim that there is an \(\alpha < \kappa\) such that \(A_\alpha = \{p \in A \mid (\exists n)(\alpha, n) \in \text{Dom}(p)\}\) has cardinality \(\kappa\). Otherwise, there exist \(p, q \in A\) with disjoint domains such that \(p\) and \(q\) are compatible, which is a contradiction. Hence let \(\alpha_0\) be the least \(\alpha\) such that \(A_\alpha\) has cardinality \(\kappa\). Let \(B_{\alpha_0} = \{p \in A_{\alpha_0} \mid (\forall \beta < \alpha_0)(\forall n)(\beta, n) \in \text{Dom}(p)\}\). By the assumption on \(\alpha_0\), \(|B_{\alpha_0}| = \kappa\).

Since \(|B_{\alpha_0}| = \kappa\) and \(|\alpha_0| < \kappa\), we may assume that for any \(p, q \in B_{\alpha_0}\), \(\{(\alpha_0, n) \mid (\alpha_0, n) \in \text{Dom}(p)\} = \{(\alpha_0, n) \mid (\alpha_0, n) \in \text{Dom}(q)\}\). Furthermore since \(p(\alpha, n) < \alpha\) in general, we may even assume that for any \(p, q \in B_{\alpha_0}\), \((\alpha_0, n) \in \text{Dom}(p)\) implies \(p(\alpha_0, n) = q(\alpha_0, n)\).

Then by the same argument as that for \(\alpha_0\), there is an \(\alpha_1 > \alpha_0\) which is the least ordinal \(> \alpha_0\) such that \(B_{\alpha_0} \ge A_{\alpha_1}\) and the latter has size \(\kappa\). Let \(B_{\alpha_1} = A_{\alpha_1} \cap \{p \mid (\forall \beta)(\forall n)(\alpha_0 < \beta < \alpha_1 \rightarrow (\beta, n) \notin \text{Dom}(p))\}\). Then \(|B_{\alpha_1}| = \kappa\).

Thus as before we may define a sequence of ordinals \(\alpha_0 < \alpha_1 < \dots < \alpha_\kappa\) and a sequence of sets \(B_{\alpha_0} \ge B_{\alpha_1} \ge \dots \ge B_{\alpha_\kappa}\) such that \(|B_{\alpha_\kappa}| = \kappa\) and for all \(p \in B_{\alpha_\kappa}\), \(\text{Dom}(p) = \{\alpha_0, \dots, \alpha_\kappa\}\). Then \(|B_{\alpha_\kappa}| \le |\alpha_\kappa|^\omega < \kappa\), a contradiction.

## 6.2.4 Sacks forcing

Forcing with perfect sets was introduced by Spector [154] in his construction of a set of minimal Turing degree. This method was generalized by Sacks and applied to the hyperarithmetic and set-theoretic setting to produce sets of minimal hyperdegree and minimal degree of constructibility [121] respectively.

### Definition 6.2.10. Sacks forcing is a notion of forcing \(\mathbb{S} = (\mathbf{T}, \le)\), such that

- \(\mathbf{T}\) is the collection of perfect trees \(\subseteq 2^{<\omega}\);
- for any \(T_1, T_2 \in \mathbf{T}\), \(T_1 \le T_2\) if and only if \(T_1 \subseteq T_2\).

A Sacks generic real is one which meets every dense collection of perfect sets. The following theorem says that such a real has the “minimality property”.

### Theorem 6.2.11 (Sacks [121]). Suppose that \(g\) is Sacks generic over a model \(\mathcal{M}\) of ZFC and \(x \in \mathbf{M}[g] \setminus \mathbf{M}\) is a real. Then there are reals \(z_0, z_1 \in \mathbf{M}\) such that \(x \oplus z_0 \ge_T g\) and \(x \le_T z_1 \oplus g\).

Proof. Suppose that \(g\) is Sacks generic produced by a generic filter \(G\) and let \(x \in \mathbf{M}[g] \setminus \mathbf{M}\). By Theorem 6.1.2, there is a condition \(T^0\) such that \(T^0 \in G\) (i.e. \(g \in [T^0]\)) and

```
$T^0 \Vdash \dot{x} \notin \check{\mathbf{M}} \wedge \dot{x} \in 2^\omega$.
```

Let \(T^1 \le T^0\). Define a function \(T : 2^{<\omega} \to T^1\) and a sequence of conditions \(\{T_\sigma\}_{\sigma \in 2^{<\omega}}\) and numbers \(n_\sigma\) by induction as follows:

Let \(T(0) = 0\) and \(T_0 = T^1\).

Suppose \(\sigma \in 2^{<\omega}\), \(T(\sigma)\) is defined and \(T_\sigma \subseteq T^1\). Then \(T_\sigma \Vdash \dot{x} \notin \check{\mathbf{M}} \wedge \dot{x} \in 2^{n_\sigma}\), and there exist an \(n_\sigma > |\sigma|\) as well as conditions \(T_0, T_1 \subseteq T_\sigma \cap [T(\sigma)]\) such that \(T_0 \Vdash \dot{x}(\dot{n}_\sigma) = 0\) and \(T_1 \Vdash \dot{x}(\dot{n}_\sigma) = 1\), where \([T(\sigma)]\) is the set of strings extending \(T(\sigma)\).

Then there is a \(\tau > T(\sigma)\) and an \(i \in \{0, 1\}\) such that \(\tau \in T_\sigma\), \([\tau'] \cap [T_0] \neq \emptyset\) and \([\tau' \cap (1-i)] \cap [T_1] \neq \emptyset\). Let \(T(\sigma') = \tau'\), \(T_{\sigma'} = \tau' \cap [T_i] \cap T_i\) for \(i \in \{0, 1\}\). Then \(T_{\sigma'} \Vdash \dot{x}(\dot{n}_\sigma) = 0\) and \(T_{\sigma' \cap (1-i)} \Vdash \dot{x}(\dot{n}_\sigma) = 1\).

Let \(T^2 = \{\tau \mid (\exists \sigma)(T(\sigma) > \tau)\} \subseteq T^1\). Then for any \(\sigma\), \(T^2 \cap [T(\sigma)] \le T_\sigma\). Thus

```
$(\forall \sigma)(\forall i < 2)(T^2 \cap [T(\sigma' \cap i)] \Vdash \dot{x}(\dot{n}_\sigma) = i)$.
```

Let

```
D = \{T^2 \mid (T(\sigma) \Vdash_T T^2 \Vdash_T T \notin [T^0] \lor
(\exists(n_\sigma)_{\sigma \in 2^{<\omega}})(\exists \forall)(T : 2^{<\omega} \to 2^{<\omega}(\forall \sigma)(\forall \tau)(i < 2)(\exists j < 2)
(T^2 = \{\tau \mid (\exists \sigma)(\tau < T(\sigma))\} \land
(\sigma < \tau \mapsto T_\sigma \le T_\tau) \land (n_\sigma > |\sigma|) \land
(T^2 \cap [T(\sigma' \cap i)] \Vdash \dot{x}(\dot{n}_\sigma) = \dot{j} \wedge T^2 \cap [T(\sigma' \cap (1-i))] \Vdash \dot{x}(\dot{n}_\sigma) = \dot{1-\dot{j}})\}.
```

It is clear that \(D\) is a dense set. Hence there is a \(T^2 \in D \cap G\). Furthermore, there exist a sequence \(\{n_\sigma\}_{\sigma \in 2^{<\omega}}\) and an order-preserving map \(T : 2^{<\omega} \to 2^{<\omega}\) such that

- \(T^2 = \{\tau \mid (\exists \sigma)(\tau < T(\sigma))\}\);
- \((\forall \sigma)(n_\sigma > |\sigma|)\);
- \((\forall \sigma)(\forall i < 2)(\exists j < 2)(T^2 \cap [T(\sigma' \cap i)] \Vdash \dot{x}(\dot{n}_\sigma) = \dot{j} \wedge T^2 \cap [T(\sigma' \cap (1-i))] \Vdash \dot{x}(\dot{n}_\sigma) = \dot{1-\dot{j}})\).

Let

```
$z_0 = \{(\sigma, T(\sigma' \cap i), n_\sigma, j) \mid \sigma \in 2^{<\omega} \wedge i \in 2 \wedge j \in 2 \wedge T^2 \cap [T(\sigma' \cap i)] \Vdash \dot{x}(\dot{n}_\sigma) = \dot{j}\}$.
```
