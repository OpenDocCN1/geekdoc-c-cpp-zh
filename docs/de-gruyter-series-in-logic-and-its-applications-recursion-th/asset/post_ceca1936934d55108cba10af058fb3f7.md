
By the \(\Pi_1^1\)-Uniformization Theorem (4.2.1), there is a total \(\Pi_1^1\) and so \(\Delta_1^1\)-function \(f : \{q \mid q \le p\} \times \omega \to \omega\) such that \(f(q, n) = m\) if and only if \(m \in O_1\), and there is an \(r \le q\) with \(r \Vdash (\exists z^{[\omega]})(\varphi(n, z^{[n]}) \lor \psi(n, z^{[n]})).\) Let \(S\) be the range of \(f\).

By Theorem 5.2.2, \(f\) is a well-defined \(\Pi_1^1\)-function. Since \(f\) is total on its domain, it is \(\Delta_1^1\). By Corollary 1.5.2, there is an \(n_0 \in O_1\) such that for any \(m \in S, m <_O n_0\). Then

\((\forall q \le p)(\forall n)(\exists r \le q)(r \Vdash (\exists z^{[\omega]})(\varphi(n, z^{[n_0]}) \lor \neg \psi(n, z^{[n_0]})).\)

Hence

\((\forall n)(\forall q \le p)(q \Vdash \neg (\exists z^{[n_0]})(\varphi(n, z^{[n_0]}) \lor \neg \psi(n, z^{[n_0]})).\)

and so

\((\forall n)p \Vdash \neg (\exists z^{[n_0]})(\varphi(n, z^{[n_0]}) \lor \neg \psi(n, z^{[n_0]})).\)

Since \(x > p\), by Theorem 5.2.4,

\(\mathfrak{A}(\omega_1^{\text{CK}}, x) \Vdash (\forall n)(\exists z^{[n_0]})(\varphi(n, z^{[n_0]}) \lor \neg \psi(n, z^{[n_0]})).\)

Let \(y\) be such that \(n \in y\) if and only if \(\mathfrak{A}(\omega_1^{\text{CK}}, x) \Vdash (\exists z^{[n_0]})(\varphi(n, z^{[n_0]}).\) Then \(y \in \mathfrak{A}(\omega_1^{\text{CK}}, x).\) Now if \(n \in y,\) then \(\mathfrak{A}(\omega_1^{\text{CK}}, x) \Vdash (\exists z)(\varphi(n, z).\) If \(n \notin y,\) then \(\mathfrak{A}(\omega_1^{\text{CK}}, x) \Vdash (\exists z^{[n_0]})(\neg \psi(n, z^{[n_0]}).\) Then by assumption, \(\mathfrak{A}(\omega_1^{\text{CK}}, x) \Vdash (\forall z) \neg \varphi(n, z).\) Thus \(\mathfrak{A}(\omega_1^{\text{CK}}, x)\) satisfies \(\Delta_1^1\)-comprehension.

Corollary 5.2.6. If \(x\) is Cohen generic, then

- (i) \(\omega_1^x = \omega_1^{\text{CK}}.\)
- (ii) For any real \(y \le_{sh} x,\) there is an \(n \in O\) such that \(y \le_T x \oplus H_n.\)

Proof. Theorem 5.2.5 and Theorem 5.1.5 give (i) as an immediate consequence.

For (ii), suppose \(y \le_{sh} x.\) Then by Corollary 5.1.4 and (i), \(y \in \mathfrak{A}(\omega_1^{\text{CK}}, x).\) By Theorem 5.2.4, there is a ranked formula \(\varphi\) such that for any \(k, y(k) = 1 \Leftrightarrow (\exists m)(x \mid m \Vdash \varphi(k))\) and \(y(k) = 0 \Leftrightarrow (\exists m)(x \mid m \Vdash \neg \varphi(k)).\) By Theorem 5.2.2,

\(R(p, k, i) \equiv (i \wedge 1 \wedge p \Vdash \varphi(k)) \vee (i = 0 \wedge p \Vdash \neg \varphi(k))\)

is \(\Pi_1^1\). Since \(O\) is \(\Pi_1^1\) complete (Theorem 1.5.1), there is a recursive function \(f : 2^{<\omega} \times \omega \times 2 \to \omega\) such that \(f(p, k, i) \in O\) if and only if \(R(p, k, i)\) holds.

Define \(R^* \subseteq \omega \times 2 \times \omega\) so that \(R^*(k, i, n)\) if and only if \(n \in O\) and there is an \(m\) with \(f(x \mid m, k, i) = n.\) Then \(R^*\) is \(\Pi_1^1(x).\) By Theorem 4.2.1, there is a total \(\Pi_1^1(x),\) hence \(\Delta_1^1(x),\) function \(h : \omega \to 2 \times \omega\) uniformizing \(R^*.\) Thus Range(\(h\)) is a \(\Delta_1^1(x)\)-set. By (i) and Corollary 1.5.2, there is an \(n_0 \in O\) such that Range(\(h\)) \(\subseteq 2 \times O_{n_0}.\) Hence for any \(k, y(k) = 1 \Leftrightarrow (\exists m)(f(x \mid m, k, 1) \in O_{n_0}),\) and \(y(k) = 0 \Leftrightarrow (\exists m)(f(x \mid m, k, 0) \in O_{n_0}).\) It follows that \(y \le_T x \oplus O_{n_0},\) and hence there is an \(n \in O\) such that \(y \le_T x \oplus H_n.\)

From the topological point of view, a Cohen generic real is one which meets all definable dense open sets. Thus the set of such reals is co-meager. In Chapter 14, we will develop a parallel notion of forcing based on the co-null property.

### 5.2.2 Applications to hyperdegrees

We now use Cohen forcing to study the structure of hyperdegrees.

**Proposition 5.2.7.** If _z_ is not hyperarithmetic, then there exists an _x_ such that \(x \not\le_h z\) and \(x \not\ge_h z\).

**Proof.** Assume that _z_ is not hyperarithmetic. Fix an enumeration \(\{z_i\}_{i<\omega}\) of reals hyperarithmetic in _z_ and an enumeration \(\{\varphi_i\}_{i<\omega}\) of all formulas.

We define a sequence \(\emptyset = p_0 \ge p_1 \ge \cdots\) of conditions as follows:

Suppose that _p<sub>i</sub>_ is defined. At stage _i_ + 1, first let \(q_i^1 \le p_i\) so that there exists a _j_ with \(q_i^1(j) \neq z(i)\). Then let \(q_i^1 \le q_i^0\) so that \(q_i^1 \in D_{\varphi_i}\). This is possible according to Lemma 5.2.3.

See if \(\varphi_i(n, k)\) is ranked and whether for all _n_, there exists an \(r \le q_i^1\) and _k_ such that \(r \Vdash \varphi_i(n, k)\). If not, let _p_<sub>_i_+1</sub> = \(q_i^1\) and go to next stage. Otherwise, see if for all _n_ and \(r \le q_i^1\), if \(r \Vdash \varphi_i(n, k)\) then _k_ is unique. If this is so, let _p_<sub>_i_+1</sub> = \(q_i^1\) and go to next stage. If not, let \(p_{i+1} \le q_i^1\) so that there exists an _n_ with \(p_{i+1} \Vdash \varphi_i(n, k)\) for some \(k \neq z(n)\).

Let \(x = \bigcup_{i<\omega} p_i\). Then _x_ is Cohen generic and \(x \not\le_h z\). By Corollary 5.2.6, \(\omega_1^x = \omega_1^{CK}\). If \(x \ge_h z\), then by Corollary 5.1.4, there is a ranked formula \(\varphi_i(n, k)\) in the enumeration list such that _z_(_n_) = _k_ if and only if \(\mathfrak{A}(\omega_1^{CK}, x) \Vdash \varphi_i(n, k)\). By Theorem 5.2.4, for each _n_, there exist _k_ and _m_ such that \(x \mid m \Vdash \varphi_i(n, k)\). Then by the construction at stage _i_ + 1, it must be the case that for every _n_ and \(r \le q_i^1\), there is a unique _k_ satisfying \(r \Vdash \varphi_i(n, k)\). Define _z_(_n_) = _k_ if and only if there is an \(r \le q_i^1\) with \(r \Vdash \varphi_i(n, k)\). By Theorem 5.2.2, _z_ is \(\Pi_1^1\) and hence hyperarithmetic. But \(z = \hat{z}\), a contradiction.

Thus \(x \not\le_h z\) and \(x \not\ge_h z\).

## 5.3 Sacks forcing

The notion of forcing with perfect sets over the ramified analytical hierarchy was introduced by Gandy and Sacks [36] in their construction of a set with minimal hyperdegree. The origin of perfect set forcing, however, traces back to Spector's proof of the existence of a minimal Turing degree [154]. As will be seen, the construction of a minimal hyperdegree is much more intricate as it requires a detailed analysis of the complexity of the forcing relation \(\Vdash\).

### 5.3.1 Perfect set forcing over the ramified analytical hierarchy

Let \(\mathscr{S}\) be the collection of hyperarithmetic perfect sets. Each \(S \in \mathscr{S}\) is a condition for Sacks forcing. Given two conditions \(S, T \in \mathscr{S}\), we say that \(S \le T\) if \(S \subseteq T\).

Let \(\varphi\) be a sentence in the language of ramified analytical hierarchy \(\mathscr{L}(\omega_1^{CK}, x)\).

Define \(T \Vdash \varphi\) as follows.

- If \(\varphi\) is ranked, then \(T \Vdash \varphi\) if \((\forall x \in T)(\exists \alpha(\omega_1^{CK}, x) = \varphi)\);
- If \(\varphi(y)\) is unranked and \(T \Vdash \varphi(y \mid \beta)\) for some \(\beta\), then \(T \Vdash (\exists y^\beta)\varphi(y)\);
- \(T \Vdash (\exists y)\varphi(y)\) if and only if \(T \Vdash (\exists y^\beta)\varphi(y^\beta)\) for some \(\beta < \omega_1^{CK}\);
- if \(\varphi(n)\) is unranked and \(T \Vdash \varphi(\bar{n})\) for some number \(m\), then \(T \Vdash (\exists n)\varphi(n)\);
- if \(\varphi\) and \(\psi\) are unranked, \(T \Vdash \varphi\) and \(T \Vdash \psi\), then \(T \Vdash \varphi \land \psi\);
- if \(\varphi\) is unranked and \((\forall S)(S \le T \rightarrow \neg S \Vdash \varphi)\), then \(T \Vdash \neg \varphi\).

Note that while the definition of Cohen forcing for ranked sentences is by induction on the complexity of the sentence, that of Sacks forcing is given directly. This immediately implies the following.

**Lemma 5.3.1.** If \(T \Vdash \varphi\) and \(S \le T\), then \(S \Vdash \varphi\).

By Theorem 5.1.1 and the definition of forcing, we have

**Lemma 5.3.2.** The set \(\{(T, \ulcorner \varphi \urcorner) \mid \varphi \text{ is } \Sigma_1^1 \wedge T \Vdash \varphi\}\)

is \(\Pi_1^1\).

**Lemma 5.3.3.** (Fusion Lemma) Let \(T\) be a condition and \(((i, \varphi_i))_{i < \omega}\) be a hyperarithmetic set of \(\Sigma_1^1\) formulas. Assume that \((\forall i)(\forall y \in T)(\exists S \le T)(S \Vdash \varphi_i)\).

Then \((\exists S \le T)(\forall i)(S \Vdash \varphi_i)\).

Proof. Using the notation \(P \Vdash n = \{ \tau \in 2^{<\omega} \mid \tau \in P \}\), define \(\mathfrak{R}\) by

\(\mathfrak{R}(i, \alpha, R, P) \Leftrightarrow \alpha \in R \wedge P \subseteq R \wedge P \Vdash |\alpha| = \{ \tau \mid \tau < \alpha \} \wedge P \Vdash \varphi_i.\)
