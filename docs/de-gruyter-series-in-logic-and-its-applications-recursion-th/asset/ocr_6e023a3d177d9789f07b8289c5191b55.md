(ii) If \( x \le_h y \), then \( x \le_T H_e^y \) for some \( e \in \mathcal{O}^y \). Let \( f \) be as in Lemma 2.4.8. Since \( \omega_1^x < \omega_1^y \), by Proposition 2.4.6, \( \omega_1^x < \omega_1^{H_e^y} \). Hence there is a number \( m \in \mathcal{O}^{H_e^y} \) such that for all \( i \), \( i \in \mathcal{O}^x \leftrightarrow (i) \in \mathcal{O}_m^{H_e^y} \). Thus \( x \le_h^{CK} H_e^y \le_h y \).

Proof of Theorem 2.4.7. If \( \omega_1^x > \omega_1^{CK} \), then by (ii) of Lemma 2.4.9, \( \mathcal{O} \le_h x \). If \( \mathcal{O} \le_h x \), then by (i) by Lemma 2.4.9, \( \omega_1^x < \omega_1^{CK} < \omega_1^y \).

The following corollary says that each \( h \)-degree not above the hyperjump is \(\text{GL}_1\). This is in sharp contrast to Turing reducibility where there exist reals \( x \not\le_T \emptyset' \) such that \( x' \not\le_T x \oplus \emptyset' \).

**Corollary 2.4.10.** \( x \not\le_h \emptyset \leftrightarrow \mathcal{O}^x \le_h x \not\le_h \emptyset \).

Proof. If \( \mathcal{O}^x \not\le_h x \not\le_h \emptyset \), then \( x <_h \emptyset' \not\le_h x \not\le_h \emptyset \). Conversely, if \( x \not\le_h \emptyset \), then by Theorem 2.4.7, \( \omega_1^x = \omega_1^{CK} < \omega_1^{\mathcal{O}^x} \). By (i) of Lemma 2.4.9, \( \mathcal{O}^x \le_h x \not\le_h \emptyset \).

**Corollary 2.4.11.** The set \(\{x \mid \omega_1^x = \omega_1^{CK}\}\) is \(\Sigma_1^1\).

Proof. By Proposition 1.2.5, \(\mathcal{O}\) is a \(\Pi_1^1\)-singleton. Then \( x \ge_h \emptyset \) if and only if \( (\exists n \in \mathcal{O}^x)(\exists e)(\Theta_e^{H_e^x} \in \{\emptyset\}) \), which is a \(\Pi_1^1\)-statement. By Theorem 2.4.7, the set \(\{x \mid \omega_1^x = \omega_1^{CK}\}\) is \(\Sigma_1^1\).

# 2.5 Some basis theorems and their applications

# 2.5.1 Gandy's Basis Theorem

A set of reals \( A \) is a *basis* for a collection of sets \(\mathbf{P}\) of reals if for any nonempty \( P \in \mathbf{P} \), \( P \cap A \neq \emptyset \). Basis theorems are very important in recursion theory. They are used against another things to pin down the complexity of predicates. For example, let \(\{T_i\}_{i \in \omega}\) be an effective enumeration of recursive trees in \( 2^{<\omega} \). The index set \( N = \{i \mid T_i \text{ contains an infinite path}\} \) appears to be \(\Sigma_1^1\). But one can show that every recursive tree in \( 2^{<\omega} \) containing an infinite path must contain an infinite path recursive in \( \emptyset' \) (see Exercise 1.5.3). So \( N \) is an arithmetical set.
