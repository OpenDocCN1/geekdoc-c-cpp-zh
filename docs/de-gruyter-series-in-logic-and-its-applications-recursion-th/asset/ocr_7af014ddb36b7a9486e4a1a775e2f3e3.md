Substep 1 (Satisfying \(N_{e,i}\)). Consider the following statement:

```
\((\exists \tau \supseteq \sigma_n)(\forall \tau_0, \tau_1 \supseteq \tau)(\forall m)(\Phi^{\tau_0 \oplus y_0}(m) \downarrow \land \Phi^{\tau_1 \oplus y_0}(m) \downarrow \rightarrow \Phi^{\tau_0 \oplus y_0}(m) = \Phi^{\tau_1 \oplus y_0}(m)).\)
```

If the statement is true, then find the (lexicographically) least such \(\tau\) and define \(\sigma_{n+1}^0 = \tau\). Then for every real \(z \supset \sigma_{n+1}^0\), \(\Phi_e^{z \oplus y_0}\) is total implies \(\Phi_e^{z \oplus y_0} \le_T y_0\). Thus \(\sigma_e^{z \oplus y_0} \neq (x)_1\) since \(X \upharpoonright \langle y_0 \rangle\) is an antichain. If the statement is false, then find the least \(\tau_0 \supseteq \sigma_n\) for which there exists a (least) \(\tau_1 \supseteq \sigma_n\) such that \(\Phi^{\tau_0 \oplus y_0}(m) \downarrow \neq \Phi^{\tau_1 \oplus y_0}(m) \downarrow\) for some \(m\). Define \(\sigma_{n+1}^0 = \tau_1\) for the \(k \ge 2\) where \(\Phi^{\tau_e \oplus y_0}(m) \neq (x)(m)\).

Substep 2 (Coding \(y_1\)). Define \(\sigma_{n+1} = (\sigma_{n+1}^0)^\frown \langle y_1(n) \rangle\).

Finally, let \(z = \bigcup_n \sigma_n\).

Since \(y_0 \not\prec_T x\) for all \(i\), the same conclusion holds for \(z \forall y_0\). By the construction, \(z \not\prec_T y_0 \upharpoonright \langle x \rangle_i\) for all \(i\), and so \(X \cup \{z \oplus y_0\}\) is an antichain.

To see that \((z \oplus y_0)'' \ge_T y_1\), consider the statement in Substep 1. The statement is decidable by \(y_0''\). If it is true, then we find \(y_0''\)-recursively find the least such \(\tau\). Then \(\tau = \sigma_{n+1}^0\). Otherwise, we can \(y_0''\)-recursively find both \(\tau_0\) and \(\tau_1\). In this case we use \(z\) to decide which string is the \(\sigma_{n+1}\). Thus \(y_1(n) = 0\) if and only if \(z(\sigma_{n+1}^0 + 1) = 0\). Moreover, \(\sigma_{n+1} = z \upharpoonright [\sigma_{n+1}^0 + 1)\). Hence the sequence \((\sigma_n)_n\) can be computed from \(z \oplus y_0''\). Therefore \((z \oplus y_0)'' \ge_T z \oplus y_0'' \ge_T y_1\).

Clearly the entire construction can be decoded by \(y_1\). Thus \(y_1 \ge_T z\).

# THEOREM 8.3.4 (Chong and Yu [16]). Assume \((2^\omega)^L = 2^\omega\). There exists a \(\Pi^1_1\)-thin maximal antichain in the Turing degrees.

Proof. By Lemma 8.3.3, P is a cofinally progressive relation. Note that (2c) is equivalent to

```
\(L_{u^{[\kappa,n]}}(x, y) \models (\exists \beta)((y)_0 \in L_\beta \land (\forall z \in L_\beta)(z <_L (y)_0 \rightarrow (\exists n)((x)_n \ge_T y \lor y \succ_T (x)_n))).\)
```

Thus P is \(\Pi^1_1\). Hence by Theorem 8.2.4, there is a \(\Pi^1_1\) set A with the prescribed properties. Using (3ii), we show by induction on \(<_L\) that A is an antichain.

Suppose \(x \in A\) and \(|y| y \in A \land y <_L x\) is an antichain. By \(\forall(i)\), there is a \(z\) coding \(|y| y \in A \land y <_L x\) so that \(P(z, y)\) holds. Then by (2), \((z)_n \notin n \in \omega \cup \{y\}\) is an antichain. So A is an antichain. Note that \(A \in c\). This together with Lemma 4.3.1 implies that A is a thin set. By (2b) above, A is maximal.
