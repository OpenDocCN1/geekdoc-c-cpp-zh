Proof. First set $\varphi_0(u)$ to be $u = d_0$. Recursively define $\varphi_{2n+1}(u)$ to be

$(\exists w)(\varphi_{2n}(w) \land u \subseteq w \cup e_0 \land u \lesssim f_1 \land c \cup u \supseteq c')$

and let $\varphi_{2n+2}(u)$ to be

$(\exists w)(\varphi_{2n+1}(w) \land u \subseteq w \cup e_1 \land u \lesssim f_0 \land c \cup u \supseteq c')$

Suppose that $\varphi_{2n+1}(u)$ holds for u. Then there is a w as described such that, by induction, $0 < w \le d_{2n}$. Thus $w \cup e_0 \subseteq d_{2n} \cup e_0$ and so $d_{2n} \cup e_0 \subseteq f_1$. As $d_{2n+1} = (d_{2n} \cup e_0) \cap f_1$, $u \subseteq d_{2n+1}$. Furthermore, $c' \subseteq c \cup u$ ensures that $u > 0$ as well and so (i) holds for $\varphi_{2n+1}$. The argument for $\varphi_{2n+2}$ is similar.

We leave the verification of (ii) and (iii) to the reader. Finally, (iv) follows from Corollary 3.7.4.

Remark 10.2.2. Theorem 10.1.2 may be relativized to any real x. The partial lattice $c_x$ is defined recursively in x from the parameters $d_0, e_0, e_1, f_0, f_1, c_x, c_+, c_-, c'$ using $\le, \cup, \cap$ as partial functions. Then any embedding of $c_x$ into the hyperdegrees maps the 0 of $c_x$ to x.

Now fix a real x. By Theorem 10.1.2 relativized to x, there is an embedding $f : c_x \to \mathscr{D}_h$ preserving $\le, \cup, \cap$ and $\neg$ so that $f(0_{c_x}) = x$. By Lemma 10.2.1, both x and $\omega \setminus x$ are $\Pi^0_1$-definable relative to a representation of

$f(d_0) \cup f(e_0) \cup f(e_1) \cup f(f_0) \cup f(f_1) \cup f(c_x) \cup f(c) \cup f(c') \le f(1_{c_x})$.

Hence $x \le f(1_{c_x})$.

The following result will be used in the proof of the biinterpretability of $(\mathscr{D}_h, \le)$ with second order arithmetic.

Lemma 10.2.3. For any x and y, $y \le_R x$ if and only if there exist $y_0, y_1 > x$ such that $y_0 \cap y_1 = x$ and $c_y$ is embeddable into both $[x, y_0]$ and $[x, y_1]$ with minimal element x.

Proof. Let g0 and g1 be Cohen generic reals relative to x so that $(x \cup g_0) \cap (x \cup g_1) = x$. Then the 'only if' direction follows immediately from Theorem 10.1.2 relativized to x by letting $y_0 = x \cup g_0$ and $y_1 = x \cup g_1$.

For the other direction, note that by Lemma 10.2.1 $y \le y_0$ and $y \le y_1$. So $y \le x$.

We are now ready to prove the main theorem of this section.

Theorem 10.2.4 (Slaman and Woodin [141], Shore [133]). If $\pi : \mathscr{D}_h \to \mathscr{D}_h$ is an automorphism, then $\pi$ is the identity map.

Proof. Let x be a hyperdegree containing x as an element. Let $c_x$ be the lattice generated by $d_0, e_0, e_1, f_0, f_1$ as described above. Let $\hat{c}_x$ be a disjoint copy of $c_x$ and define a partial lattice $\mathscr{P}_x$ which is the union of $c_x$ and $\hat{c}_x$ such that $0_{\mathscr{P}_x} = 1_{c_x} \cap 1_{\hat{c}_x}$ and $1_{\mathscr{P}_x} = 1_{c_x} \cup 1_{\hat{c}_x}$. By Theorem 10.1.2 relativized to x, there is an embedding f of $\mathscr{P}_x$ into the hyperdegrees such that $f(0_{\mathscr{P}_x}) = x$.
