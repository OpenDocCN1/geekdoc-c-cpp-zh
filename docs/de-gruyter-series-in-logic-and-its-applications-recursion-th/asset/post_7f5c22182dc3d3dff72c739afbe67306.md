
Obviously $\mathrm{MA}_{\aleph_0}$ is a theorem of ZFC. It is known that if ZFC is consistent then so is ZFC + MA. The $\kappa$-chain condition is also used to compute the cardinality of a power set.

## 6.1.3 $\kappa$-closedness

### Lemma 6.1.6.
Suppose that $\kappa > \aleph_0$ is a regular cardinal and $\mathbb{P} = (\mathbf{P}, \le)$ satisfies $\kappa$-c.c. in $\mathcal{M}$ with $|\mathcal{P}| = \lambda$. Then for any regular cardinal $\eta \in M$ and generic set $G$, $\mathcal{M}[G] \models 2^\lambda \le ((\lambda^\kappa)^\eta)^M$.

**Proof (Sketch).** Every $x \in M[G] \cap 2^\lambda$ corresponds to a $\mathbb{P}$-name $\dot{x} \in \eta \times \mathscr{P}(\mathbf{P})$. Moreover, we may assume that for any $\gamma < \eta$, $|\{p : (\dot{\gamma}, p) \in \dot{x}\}|$ is an antichain. There are $\lambda^\kappa$-many antichains in $\mathcal{M}$. Hence there are at most $(\lambda^\kappa)^\eta$-many such $\mathbb{P}$-names. In other words, $\mathcal{M}[G] \models 2^\lambda \le ((\lambda^\kappa)^\eta)^M$ (see [78] for a detailed proof).

Two conditions $p$ and $q$ in $\mathbb{P}$ are compatible if $p \le q$ or $q \le p$. Given a cardinal $\kappa$, $\mathbb{P}$ has the $\kappa$-closed property (in $\mathcal{M}$) if for any sequence $\langle p_\alpha \rangle_{\alpha < \nu}$ of compatible conditions of length $\nu < \kappa$, there is a $q$ such that $q \le p_\alpha$ for each $\alpha < \nu$. Satisfying the $\kappa$-closed property is another basic tool for preserving cardinals.

### Lemma 6.1.7.
If $\mathbb{P}$ has the $\kappa$-closed property and $A \in M$ with $|A| < \kappa$, then any function $f$ in a generic extension $\mathcal{M}[G]$ with domain $A$ belongs to $\mathcal{M}$.

It follows that $\kappa$-closed property preserves all cardinals not greater than $\kappa$.

## 6.1.4 Product forcing

### Definition 6.1.18.
Let $I$ be an index set and let $\mathbb{P}_i = (\mathbf{P}_i, \le_i)$ be a notion of forcing for $i \in I$. Let $C \subseteq \mathscr{P}(I)$. The $C$-product forcing $\mathbb{P} = (\mathbf{P}, \le)$ is a partial ordering satisfying the following for each $p \in \mathbf{P}$:

- there is a $J \in C$ such that $p(i)$ is defined if and only if $i \in J$ and $p(i) \in \mathbf{P}_i$;
- $q \le p$ in $\mathbf{P}$ if and only if for any $i \in I$, $p(i)$ is defined implies $q(i)$ is defined and $q(i) \le_i p(i)$.

If $C$ is the collection of all finite subsets of $I$, then $\mathbb{P}$ is known as product forcing with finite support. If $C$ is the collection of all countable subsets of $I$, then $\mathbb{P}$ is product forcing with countable support. $I$ is often taken to be an ordinal.

Let $I$ be an ordinal $\gamma$. If $C = I$, we call $\mathbb{P}$ simply the product of $\langle \mathbb{P}_\alpha \rangle_{\alpha < \gamma}$. Then the $C$-product forcing $\mathbb{P} = \Pi_{\alpha < \gamma} \mathbb{P}_\alpha$ may be decomposed into $\Pi_{\alpha < \beta} \mathbb{P}_\alpha \times \Pi_{\beta \le \alpha < \gamma} \mathbb{P}_\alpha$. In other words, $\mathbb{P} \cong \Pi_{\alpha < \beta} \mathbb{P}_\alpha \times \Pi_{\beta \le \alpha < \gamma} \mathbb{P}_\alpha$.

### Theorem 6.1.19.
Suppose that $\mathbb{P} = (\mathbf{P}, \le_P)$ and $\mathbb{Q} = (\mathbf{Q}, \le_Q)$ are two notions of forcing. Let $\mathbb{P} \times \mathbb{Q}$ be the product of $\mathbb{P}$ and $\mathbb{Q}$. Then for any set $G \subseteq \mathbf{P} \times \mathbf{Q}$, $G$ is generic over $\mathcal{M}$ if and only if $G = G_1 \times G_2$ where $G_1 \subseteq \mathbf{P}$ is generic over $\mathcal{M}$ and $G_2$ is generic over $\mathcal{M}[G_1]$. Moreover, $\mathcal{M}[G] = \mathcal{M}[G_1][G_2]$.

In general, the c.c.c. property is not preserved under product forcing. This limitation is addressed by the following stronger property.

### Definition 6.1.10.
A forcing notion has property (K) if every uncountable set of conditions has an uncountable subset of mutually compatible elements.

The next theorem is in Jech [53].

### Theorem 6.1.11.
- (i) Let $\gamma \ge 0$ be an ordinal and assume that for each $\alpha < \gamma$, $\mathbb{P}_\alpha$ has property (K). Then the product forcing $\mathbb{P} = \Pi_{\alpha < \gamma} \mathbb{P}_\alpha$ with finite support has property (K);
- (ii) Suppose that $\kappa \ge \aleph_1$, $\kappa^\omega = \kappa$ and $|\mathbf{P}_i| \le \kappa$ for each $i \in I$. Then the product forcing $\Pi_{i \in I} \mathbf{P}_i$ with countable support satisfies $\kappa^+$-c.c.

## 6.1.5 Iterated forcing

Product forcing is less amenable to fine tuning the construction of a model. The notion of iterated forcing, introduced by Solovay and Tennenbaum [147], offers more “flexibility” in this respect. Given an ordinal $\alpha$, let $I \subseteq \mathscr{P}(\alpha)$ be an ideal such that $\{0\} \in I$. We define iterated forcing $\mathbb{P}_\beta = (\mathbf{P}_\beta, \dot{\mathbb{Q}}_\gamma, \gamma \le \beta, I)$ on ordinals $\beta \le \alpha$ with support $I$ by induction on $\beta$.

### Definition 6.1.12.
For $\beta = 0$, $\mathbb{P}_0 = (\mathbf{P}_0, \dot{\mathbb{Q}}_0, 0, I)$ satisfies

- $\dot{\mathbb{Q}}_0$ is a notion of forcing;
- $p \in \mathbf{P}_0$ if and only if $p$ is a function such that $\mathrm{Dom}(p) = \{0\}$ and $p(0) \in \dot{\mathbb{Q}}_0$.

For $\beta = \xi + 1$, a forcing condition $p \in \mathbf{P}_\beta$ is a partial function whose domain belongs to $I$ so that

- $p \restriction \xi \in \mathbf{P}_\xi$;
- $\dot{\mathbb{Q}}_\beta$ is a $\mathbf{P}_\xi$-name;
- if $\beta \in \mathrm{Dom}(p)$, then $p \restriction \xi \Vdash p(\beta) \in \dot{\mathbb{Q}}_\beta$.

If $q \in \mathbf{P}_\beta$, define $p \le_\beta q$ if $p \restriction \xi \le q \restriction \xi$ and $p \restriction \xi \Vdash p(\beta) \le q(\beta)$.

If $\beta$ is a limit ordinal, then a forcing condition $p \in \mathbf{P}_\beta$ is a partial function whose domain belongs to $I$ so that

- for every $\xi < \beta$, $p \restriction \xi \in \mathbf{P}_\xi$;
- $\{\xi < \beta \mid \xi \in \mathrm{Dom}(p)\} \in I$.

If $q \in \mathbf{P}_\beta$, define $p \le_\beta q$ if and only if $p \restriction \xi \le q \restriction \xi$ for every $\xi < \beta$.

The two most useful notions of iterated forcing are those defined in terms of finite and countable support.

### Proposition 6.1.13.
Let $\alpha$ be an infinite ordinal. Assume that $\mathcal{M} \vDash \text{ZFC} \wedge \text{``}\kappa > \omega \text{ is regular''}$, $I = \{s \mid s \subseteq \alpha \wedge |s| < \aleph_0\}$ and let $\mathbb{P}_\alpha = (\mathbf{P}_\alpha, \le_{\mathbb{P}_\alpha}, I)$. If for each $p$ and $\beta \le \alpha$, $p \Vdash \text{``}\dot{\mathbb{Q}}_\beta \text{ satisfies c.c.c.''}$, then for each $\beta \le \alpha$, $\mathbb{P}_\beta$ satisfies c.c.c. in $\mathcal{M}$.

### Remark 6.1.14.
A similar statement holds for proper forcing in the case when $I$ is countably supported. The proofs can be found in [53].

## 6.1.6 Embeddings and isomorphisms

### Definition 6.1.15.
A function $f$ from $(\mathbf{P}, \le)$ into $(\mathbf{Q}, \le)$ is a dense embedding if
- $(\forall p_0)(\forall p_1)(p_0 \le p_1 \rightarrow f(p_0) \le f(p_1))$;
- $(\forall p_0)(\forall p_1)(p_0 \parallel p_1 \rightarrow f(p_0) \parallel f(p_1))$;
- Range($f$) is a dense subset of $\mathbf{Q}$.

A function $f$ from $(\mathbf{P}, \le)$ into $(\mathbf{Q}, \le)$ is an isomorphism if $f$ is a bijection such that $(\forall p_0)(\forall p_1)(p_0 \le p_1 \leftrightarrow f(p_0) \le f(p_1))$. Clearly every isomorphism is a dense embedding.

### Definition 6.1.16.
Suppose that $f : \mathbf{P} \to \mathbf{Q}$. For any $\tau \in M^{\mathbf{P}}$, recursively define the corresponding $\mathbb{Q}$-name $f_*(\tau)$ of $\tau$ induced by $f$ as
$f_*(\tau) = \{(f_*(\sigma), f(p)) \mid (\sigma, p) \in \tau\}$.

This allows one to prove the following proposition.

### Proposition 6.1.17.
Let $\mathcal{M} \vDash \text{ZFC}$ and let $f : \mathbf{P} = (\mathbf{P}, \le) \to \mathbf{Q} = (\mathbf{Q}, \le)$ be a dense embedding.
- (i) If $H$ is $\mathbb{Q}$-generic over $\mathcal{M}$, then $f^{-1}(H)$ is $\mathbb{P}$-generic over $\mathcal{M}$ and $M[f^{-1}(H)] \subseteq M[H]$.
- (ii) For any formula $\varphi(v_0, \dots, v_n)$,
  $p \Vdash \varphi(\tau_0, \dots, \tau_n) \leftrightarrow f(p) \Vdash \varphi(f_*(\tau_0), \dots, f_*(\tau_n))$.
