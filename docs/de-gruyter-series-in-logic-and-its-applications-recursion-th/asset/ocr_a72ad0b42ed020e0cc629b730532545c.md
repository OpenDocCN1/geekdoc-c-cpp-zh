A set \(D \subseteq 2^{<\omega}\) is dense if for any \(p \in 2^{<\omega}\), there is a \(q \in D\) such that \(q \le p\). Given a sentence \(\varphi\), let \(D_p = \{p \mid p \Vdash \varphi \lor p \Vdash \neg \varphi\}\). The next lemma follows from (ii) of Proposition 5.2.1.

# Lemma 5.2.3. Given a formula \(\varphi\), \(D_p\) is dense.

A real \(x\) is Cohen generic if for any sentence \(\varphi\) there is an \(n\) such that \(x \Vdash n \Vdash \varphi\) or \(x \Vdash n \Vdash \neg \varphi\). By Lemma 5.2.3 and induction on the set of Gödel numbers of formulas, it is an easy exercise to show that a Cohen generic real exists. The following theorem states that for a generic real, forcing equals truth.

# Theorem 5.2.4. Suppose that \(x\) is Cohen generic. Then for any sentence \(\varphi\), \(\mathfrak{A}(\omega_1^{CK}, x) \models \varphi\) if and only if there is an \(n\) such that \(x \Vdash n \Vdash \varphi\).

Proof. Either direction of the theorem may be proved by induction on the complexity of formulas. We show the nontrivial case when \(\varphi\) is of the form \(\neg \psi\).

Suppose that there is an \(n\) such that \(x \Vdash n \Vdash \neg \psi\). We claim that \(\mathfrak{A}(\omega_1^{CK}, x) \models \neg \psi\). Otherwise, by induction, there is an \(m\) such that \(x \Vdash m \Vdash \psi\). By Lemma 5.2.1, \(x \Vdash (m+n) \Vdash \psi \land \neg \psi\), contradicting Lemma 5.2.1. Hence \(\mathfrak{A}(\omega_1^{CK}, x) \models \neg \psi\), i.e. \(\mathfrak{A}(\omega_1^{CK}, x) \models \varphi\).

Assume that \(\mathfrak{A}(\omega_1^{CK}, x) \models \neg \psi\). By induction, \(x \Vdash n \Vdash \psi\) for any \(n\). Since \(x\) is Cohen generic, there exists an \(m\) such that \(x \Vdash m \Vdash \psi\) or \(x \Vdash m \Vdash \neg \psi\). Hence \(x \Vdash m \Vdash \neg \psi\).

# Theorem 5.2.5. If \(x\) is Cohen generic, then \(\mathfrak{A}(\omega_1^{CK}, x)\) satisfies \(\Delta_1^1\)-comprehension.

Proof. Suppose that \(x\) is Cohen generic and

\(\mathfrak{A}(\omega_1^{CK}, x) \models (\forall n)(\exists z)\varphi(n, z) \leftrightarrow (\forall z)(\psi(n, z)).\)

where both \(\varphi(n, z)\) and \(\psi(n, z)\) are arithmetical. Then

\(\mathfrak{A}(\omega_1^{CK}, x) \models (\forall n)(\exists z)(\varphi(n, z) \lor \neg \psi(n, z)).\)

By Theorem 5.2.4, there exists a \(p < x\) such that

\(p \Vdash (\forall n)(\exists z)(\varphi(n, z) \lor \neg \psi(n, z)).\)

By the definition of forcing,

\((\forall q \le p)(q \Vdash (\forall n)(\exists z)(\varphi(n, z) \lor \neg \psi(n, z))).\)

Hence

\((\forall q \le p)(\forall n)(q \Vdash (\exists z)(\varphi(n, z) \lor \neg \psi(n, z))).\)

Therefore

\((\forall q \le p)(\forall n)(\exists r \le q)(r \Vdash (\exists z)(\varphi(n, z) \lor \neg \psi(n, z))).\)
