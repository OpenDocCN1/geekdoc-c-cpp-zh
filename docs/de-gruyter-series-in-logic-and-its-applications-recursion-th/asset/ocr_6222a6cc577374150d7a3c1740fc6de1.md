# Theorem 9.3.6 (Kanamori and Pincus [62]). ZFC + “There exists an inaccessible cardinal” is consistent if and only if ZF + CH + “There is no well-ordering of $2^\omega$” is consistent.

Proof. Assume that ZFC + “There exists an inaccessible cardinal” is consistent. By Solovay [150], there is a model M of ZF in which every uncountable set of reals contains a perfect subset. In other words, M $\models$ ZF + CH. Furthermore, there is no well-ordering of the set of reals in M.

Conversely, suppose that ZF + CH + “There is no well-ordering of $2^\omega$” is consistent and let M be a transitive model of this theory. We claim that $(\omega_1)^M$ is inaccessible in L. Clearly $(\omega_1)^M$ is regular in L. It is sufficient to prove that for any $\alpha < (\omega_1)^M$, $|(2^\omega)^L| < \omega_1$. If not, there exists a countable $\alpha$ such that $|(2^\omega)^L| = (\omega_1)^M$. Then $(2^\omega)^L \in M$ and there is a well-ordering of $(2^\omega)^L$ in M. Since $|\omega| < |(2^\omega)^L| \le |2^\omega|$, we have $|(2^\omega)^L| = |2^\omega|$. In other words, there is a bijection between $(2^\omega)^L$ and $2^\omega$ in M. It follows that there is a well-ordering of $2^\omega$ in M, which is a contradiction.

Theorem 9.3.6 says that “ZF + CH + There is no well-ordering of $2^\omega$” is such a strong theory that an inaccessible cardinal is required to guarantee its consistency. However, for forcing extensions, one has the following:

# Proposition 9.3.7. Let M $\models$ ZFC. If N is an extension of M preserving $(\omega_1)^M$ such that N $\models$ ZF+“There is a cofinal chain of Turing degrees”, then N $\models$ –CH if and only if N $\models$ “There is no well-ordering of $2^\omega$”.

Proof. If N $\models$ “There is a well-ordering of $2^\omega$”, then N $\models$ CH since N $\models$ ZF+“There is a cofinal chain of Turing degrees”.

Now suppose that N $\models$ “There is no well-ordering of $2^\omega$”. Take $C \in M$ to be a subset of $(2^\omega)^M$ such that $<_T$ is a well-ordering of C of order type $(\omega_1)^M$. Since N is an extension of M preserving $(\omega_1)^M$, $N \models |\omega| < |C|$. Since there is no well-ordering of $2^\omega$ in N, we have $N \models |C| < |2^\omega|$. So $N \models \neg$CH.

# 9.3.3 Cofinal chains versus CH

Pursuing further the link between CH and Turing degrees, one asks if, under ZF, CH is equivalent to the existence of a cofinal maximal chain of Turing degrees of order type $\omega_1$. The answer is negative: By Solovay [150], there exists a model M of ZF in which every uncountable set of reals contains a perfect subset. Since it is a theorem of ZF that every perfect set contains two reals with incomparable Turing degrees, there is no chain of Turing degrees of order type $\omega_1$.

It is not known if ZF + “There exists a cofinal maximal chain of Turing degrees of order type $\omega_1$” implies CH. However, there is a partial answer:

# Theorem 9.3.8 (Wang, Wu and Yu [168]). If ZFC is consistent, then so is ZF + $\neg$CH + “There exists a cofinal chain in the Turing degrees of order type $\omega_1$”.
