
Let B be the collection of such z_p's. Set

```
\mathfrak{A}(\gamma, x) = \bigcup_{\beta < \gamma} \mathfrak{A}(\beta, x) \cup B.
```

The satisfaction relation \(\mathfrak{A}(\alpha, x) \vDash \varphi\) is defined inductively:

- if \(\varphi\) is ranked with rank at most \(\gamma\), then \(\mathfrak{A}(\alpha, x) \vDash \varphi\) if and only if \(\bigcup_{\beta < \gamma} \mathfrak{A}(\beta, x) \vDash \varphi\);
- if \(\varphi\) is \((\exists z)\varphi(z)\), then \(\mathfrak{A}(\alpha, x) \vDash \varphi\) if and only if there is a \(\gamma < \alpha\) and a \(z^\gamma\) such that \(z^\gamma \in \mathfrak{A}(\alpha, x)\) and \(\mathfrak{A}(\alpha, x) \vDash \varphi(z^\gamma)\);
- if \(\varphi\) is \(\neg \psi\), then \(\mathfrak{A}(\alpha, x) \vDash \varphi\) if and only if \(\mathfrak{A}(\alpha, x) \not\vDash \psi\).

We leave the proof of the following results to the reader.

### THEOREM 5.4.1. If \(\omega_1^x \ge \alpha\), then the set \(\{ (x, \varphi) \mid \varphi \text{ is ranked } \land \mathfrak{A}(\alpha, x) \vDash \varphi \}\) is \(\Delta_1\) in \(L_{\omega_1^x}[x]\).

### THEOREM 5.4.2. Assume that \(\omega_1^x \ge \alpha\). Then \(\omega_1^x = \alpha\) if and only if \(\mathfrak{A}(\alpha, x)\) satisfies the \(\Delta_1^1\)-comprehension axiom.

## 5.4.2 Steel forcing

Steel forcing is a notion of forcing whose conditions are finite tagged trees \(p\) with the following properties:

- \(p = (t, h)\) where \(t \subseteq \omega^{<\omega}\) and \(h : \tilde{t} \to \alpha \cup \{\infty\}\) is a function such that \(h(t) = \infty\) and \((\forall \sigma, \tau \in \text{Dom}(h))(\sigma \to_T \tau \Rightarrow h(\sigma) < h(\tau))\). We adopt the convention that \(\infty > \beta\) for all \(\beta < \alpha\);
- \(p = (\tilde{t}_p, h_p) < q = (\tilde{t}_q, h_q)\) if and only if \(\tilde{t}_q\) is a subtree of \(\tilde{t}_p\) and \(h_p \restriction \tilde{t}_q = h_q\).

Fix a recursive coding of \(\omega^{<\omega}\) so that a string in \(\omega^{<\omega}\) is identified with a natural number. Since the generic real is intended to be a tree, we also use T in place of \(\dot{x}\).
Given a sentence \(\varphi \in \mathcal{L}(\alpha, \mathcal{T})\), define \(p = (t_p, h_p) \Vdash \varphi\) by induction on the complexity of \(\varphi\):

- \(p \Vdash \sigma \in \dot{T}\) if and only if \(\sigma = \emptyset \lor (\sigma \restriction |\sigma| - 1) \in \tilde{t}_p \land h_p(\sigma \restriction (|\sigma| - 1)) > 0\);
- \(p \Vdash t_1 = t_2\) if and only if \(\mathfrak{A}(\alpha, 0) \vDash t_1 = t_2\), where \(t_1, t_2\) are number-theoretic terms;
- \(p \Vdash t \in \dot{T}\) if and only if \(\mathfrak{A}(\alpha, 0) \vDash t = \sigma\) for some \(\sigma\) and \(p \Vdash \dot{\sigma} \in \dot{T}\), where \(t\) is a number-theoretic term;
- \(p \Vdash (\exists n)\varphi(n)\) if and only if \(p \Vdash \varphi(\bar{n})\) for some \(n \in \omega\);
- \(p \Vdash (\exists z^\gamma)\varphi(z^\gamma)\) if and only if \(p \Vdash \varphi(\bar{\eta})\) for some ranked formula \(\psi(\bar{\eta})\) of rank at most \(\gamma\);
- \(p \Vdash (\exists z)\varphi(z)\) if and only if \(p \Vdash (\exists z^\gamma)\varphi(z^\gamma)\) for some \(\gamma < \alpha\);
- \(p \Vdash \varphi \land \psi\) if and only if \(p \Vdash \varphi\) and \(p \Vdash \psi\);
- \(p \Vdash \neg \varphi\) if and only if \((\forall q \le p)(\neg q \Vdash \varphi)\).

The following basic facts follow immediately from the definition of forcing.

### Proposition 5.4.3. For $p \Vdash \text{sentence } \varphi$,

- (i) $(\forall p)(p \Vdash \varphi \lor \psi \Vdash \neg \varphi)$;
- (ii) $(\forall p)(\exists q \leq p)(q \Vdash \varphi \lor q \Vdash \neg \phi)$;
- (iii) $(\forall p)(\forall q \leq p)(p \Vdash \varphi \Rightarrow q \Vdash \varphi)$.

Analyzing the complexity of $\Vdash$ defined above is not a straightforward matter. The difficulty is that Steel forcing, unlike Cohen forcing, is essentially a form of "class forcing". Because of tagging, the forcing conditions range over the entire $L_\alpha$. This makes the complexity of the statement "$p \Vdash \neg \varphi$" harder to determine. Our major effort is then to handle this problem.

### Definition 5.4.4. Suppose that $p, q$ are conditions and $\gamma < \alpha$. Then $\text{Ret}(\gamma, p, q)$, a retagging of $q$ by $p$, holds if and only if

- $t_p = t_q$;
- $(\forall o)((h_p(o) < \gamma \lor h_q(o) = 0 \lor h_q(o) = 0) \rightarrow h_p(o) = h_q(o))$, and
- $(\forall o)(h_p(o) \geq \gamma \rightarrow h_q(o) \geq \gamma)$.

We will use retagging to reduce a complex condition with a simpler condition while preserving the forcing relation.

### Lemma 5.4.5. If $\gamma_0 < \gamma_1 < \alpha$ and $\text{Ret}(\gamma_1, p, q)$, then

$(\forall p_1 \leq p)(\exists q_1 \leq q)\text{Ret}(\gamma_0, p_1, q_1)$.

### Proof.

The reason for working $\gamma_0$ and $\gamma_1$ is to set aside some space to do the retagging. Assume that $\gamma_0 < \gamma_1 < \alpha$ and $\text{Ret}(\gamma_1, p, q)$. Let $p_1 \leq p$. Define $q_1$ as follows:

- Set $t_{q_1} = t_p$, and
- Case (1) $\sigma \in t_q$ and $h_q(\sigma) < \omega \gamma_0$. Let $h_{q_1}(\sigma) = h_q(\sigma)$;
- Case (2) otherwise. Let $h_{q_1}(\sigma) = \omega \gamma_0 + t_{q_1, \sigma}$ where $t_{q_1, \sigma} = \{ \tau \geq \sigma \mid \tau \restriction t_{q_1} \}$.
- We leave it to the reader to verify that $q_1$ is as required.

It is not difficult to see that there is a one-one $\Delta_1(L_\alpha)$-function $f : \{ \varphi \mid \varphi \text{ is ranked} \} \to \alpha$ such that if the rank of $\varphi$ is less than that of $\psi$, then $f(\varphi) < f(\psi)$.

### Lemma 5.4.6. If $f(\varphi) = \gamma$ and $\text{Ret}(\gamma, p, q)$, then $p \Vdash \varphi \leftrightarrow q \Vdash \varphi$.

### Proof.

We prove the lemma by induction on ordinals. The only nontrivial case is when $\varphi$ is of the form $\neg \psi$ and $f(\psi) < f(\varphi)$. Suppose $\text{Ret}(\gamma, p, q)$ where $f(\varphi) = \gamma$. If $p \Vdash \neg \varphi$ but $q \not\Vdash \neg \varphi$, then $(\exists p_1 \leq p)(p_1 \Vdash \varphi)$ but $(\exists q_1 \leq q)(q_1 \Vdash \neg \varphi)$. By Lemma 5.4.5, there is a $p_2 \leq p$ such that $\text{Ret}(\gamma_1, p_2, q_1)$ where $f(\psi) = \gamma_1 < \gamma$. By induction, $p_2 \Vdash \varphi$, a contradiction. Hence $p \Vdash \neg \varphi \leftrightarrow q \Vdash \neg \varphi$. A similar argument shows that $q \Vdash \varphi \to p \Vdash \varphi$.

### Theorem 5.4.7. The set $(\{p, \ulcorner \varphi \urcorner \} \mid p \Vdash \varphi \land \varphi \text{ is ranked})$ is $\Delta_1(L_\alpha)$.

Proof. Suppose that \(f(\psi) = \gamma\). For any condition \(p\), \(p \Vdash \neg \phi\) if and only if \((\forall q \le p)(q \not\Vdash \phi)\). Fix a condition \(q \le p\) and define \(q'\) so that \(t_{q'} = t_q\) and Case (1) \(t \in t_p\) or \(h_q(\sigma) > \omega_\gamma\). Let \(h_{q'}(\sigma) = h_q(\sigma)\); Case (2) otherwise. Let \(h_{q'}(\sigma) = \omega_\gamma + t_{q,\sigma}\) where \(t_{q,\sigma} = \{\tau \ge \sigma \mid \tau \in t_q\}\). Hence \(\text{Ret}(\omega_\gamma, q, q')\) holds. By Lemma 5.4.6, \(q \Vdash \phi \Leftrightarrow q' \Vdash \phi\). Thus

\((\forall q \le p)(\text{Range}(h_q) \subseteq \cup_{\sigma \in t_q} h_p(\sigma) + \omega \cdot (\gamma + 1)) \to q \Vdash \phi\).

The theorem now follows from this by applying the \(\Sigma\)-Induction Theorem (3.1.8).

Let \(\{D_i\}_{i<\omega}\) be an enumeration of all dense sets of conditions definable over \((L_\alpha, \in)\). Then there is a sequence \(\{p_i\}_{i<\omega}\) such that \(p_0 \ge p_1 \ge \cdots\) and \(p_i \in D_i\) for each \(i\). Let \(T = \bigcup_{i<\omega} p_i\), and \(h = \bigcup_{i<\omega} h_{p_i}\). The following lemma is immediate.

### Lemma 5.4.8. For any \(\gamma < \alpha\),

- The set \(D_0^\gamma = \{p \mid (\exists \sigma)(\sigma \in t_p \land h_p(\sigma) = \gamma)\}\) is dense.
- The set \(D_1^\gamma = \{p \mid (\forall \sigma)(\sigma \in t_p \land h_p(\sigma) > \gamma \to (\exists \tau > \sigma)(\tau \in t_p \land h_p(\tau) = \gamma))\}\) is dense.

### Lemma 5.4.9. \(\omega_1^T \ge \alpha\).

Proof. By Lemma 5.4.8, for any \(\gamma < \alpha\), there is a \(\sigma \in T\) such that \(h(\sigma) = \gamma\). By induction on \(\gamma\), it is straightforward to verify that the subtree \(T_\sigma = \{\tau \in T \mid \tau \ge \sigma\}\) is well ordered under the Kleene-Brouwer ordering with order type at least \(\gamma\). Hence \(\omega_1^T \ge \alpha\).

The following forcing lemma is proved by a routine argument and is left to the reader.

### Lemma 5.4.10. For any sentence \(\phi\), \(\mathfrak{A}(\alpha, T) \models \phi\) if and only if there is a \(p\) with \(t_p \subseteq T\) such that \(p \Vdash \phi\).

### Lemma 5.4.11. \(\mathfrak{A}(\alpha, T)\) satisfies the \(\Delta_1^1\)-comprehension axiom.

Proof. Let \(\phi\) and \(\psi\) be arithmetical such that

\(\mathfrak{A}(\alpha, T) \models (\forall n)((\exists z)\phi(n, z) \to (\forall z)\psi(n, z))\).

Then

\(\mathfrak{A}(\alpha, T) \models (\forall n)(\exists z)(\phi(n, z) \lor \neg \psi(n, z))\).

As in the proof of Theorem 5.2.5, there is a \(p\) with \(t_p \subseteq T\) such that

\((\forall q \le p)(\forall n)((\exists r \le q)(r \Vdash (\exists z)\phi(n, z) \lor \neg \psi(n, z)))\).

Hence

\((\forall q \le p)(\forall n)((\exists r \le q)(\exists r')(r \Vdash (\exists z)\phi(n, z') \lor \neg \psi(n, z')))\).
