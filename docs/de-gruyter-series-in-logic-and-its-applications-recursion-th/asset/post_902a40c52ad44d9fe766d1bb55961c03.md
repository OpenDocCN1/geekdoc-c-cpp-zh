## 2 Hyperarithmetic theory

In this chapter, we introduce the hyperarithmetical hierarchy and prove that the class of hyperarithmetic sets is precisely that of the \(\Delta^1_1\)-sets. Hence the hyperarithmetic hierarchy provides the right framework for analyzing \(\Delta^1_1\)-sets and \(\Pi^1_1\)-sets. This equivalence also allows one to perform transfinite induction over \(\Delta^1_1\)-sets.

### 2.1 H-sets and \(\Pi^0_2\)-singletons

#### 2.1.1 H-sets

**Definition 2.1.1.**

- The sequence \(\{H_n\}_{n \in O}\) is defined by transfinite induction over \(O\) as follows.

```
H_1 = \emptyset,
H_{2^n} = (H_n)', \text{the Turing jump of } H_n
H_{3 \cdot 5^e} = \{\langle m, i \rangle \mid m \in H_{|e|_O(i)}\}.
```

- A member of \(\{H_n\}_{n \in O}\) is called an H-set. A real \(y\) is hyperarithmetic if \(y \le_T H_n\) for some \(n \in O\). We use HYP to denote the collection of all hyperarithmetic sets.

- Similarly, for any real \(x\), the set \(H_n^x\) is defined for all \(n \in O^x\):

```
H_1 = x,
H_{2^n} = (H_n^x)',
H_{3 \cdot 5^e} = \{\langle m, i \rangle \mid m \in H_{|e|_O^x(i)}\}.
```

Clearly \(n <_O m\) implies \(H_n <_T H_m\). In fact,

**Lemma 2.1.2 (Kleene).** There is a recursive function \(f\) such that for all \(m, n <_O m\) implies \(H_n = \Phi^0_{f(n,m)}\).

Proof. Let \(e_0\) be an index such that \(x = \Phi^{e_0}_x\) and let \(p, q\) be recursive functions such that \(x = \Phi^{e_0}_x \wedge y = \Phi^{e_0}_m\) implies \(x = \Phi^{p(n,m)}_x\) and \(\Phi^{q(m)}(x) = m\) where \(\langle m, n \rangle \in x\). Fix a function \(g\) as in (i) of Theorem 1.3.4.

If \(m = 2^{m'}\) for some \(m' \in O\), then \(\Phi^{f(n,m)}_{f(n,m)} = \Phi^{f(n,m')}_{f(n,m')}\). #### 2.1.2 $\Pi^0_2$-singletons

Let x be the unique real satisfying a predicate in the class $\Gamma$. Then x is said to be a $\Gamma$-singleton. We have seen that every $\Sigma^1_1$-singleton is $\Delta^1_1$ and $\emptyset$ is a $\Pi^1_1$-singleton. In this section we will show that every H-set is a $\Pi^0_2$-singleton.

**Lemma 2.1.3.** If x is a $\Pi^0_2$-singleton, then x' and any $y \equiv_T x$ is a $\Pi^0_2$ singleton.

Proof. Let x be a $\Pi^0_2$-singleton for the predicate R. Note that the set \(\{y \mid R(\Phi^y_e)\}\) is \(\Pi^0_2\) for each e. Let \(e_0\) be an index such that \(\Phi^{y}_{e_0} = y\) for all y. Then the predicate Q(y) \(\Leftrightarrow\) R($\Phi^{e_0}_y$) \(\wedge\) (\(\forall e\))(e \(\in\) y \(\rightarrow\) (\(\exists s\))(\(\exists \sigma\))(\(\sigma\) < y \(\wedge\) \(\Phi^{e_0}_{e_0}[s](e)[s] \downarrow\))) is \(\Pi^0_2\). Note that x' is the unique y such that Q(y) holds. If x = \(\Phi^{e_0}_y\) and y = \(\Phi^{e_0}_x\) then the predicate S(y) \(\Leftrightarrow\) R($\Phi^{y}_{e_0}$) \(\wedge\) (\(\forall e\))(e \(\in\) y \(\rightarrow\) (\(\exists s\))(\(\exists \sigma\))(\(\sigma\) < y \(\wedge\) \(\Phi^{e_0}_{e_0}[s](e)[s] \downarrow\) = 1)) is \(\Pi^0_2\) and witnesses the uniqueness of y.

**Theorem 2.1.4.** There exists a \(\Pi^0_2\)-predicate H such that for all reals y and \(n \in O^y\), \((\exists x)(H(x,n,y)) \wedge H(n,H^y_n,n)\).

Hence every \(H^y\)-set is a \(\Pi^0_2(y)\)-singleton.

Proof. By the Recursion Theorem, we may assume that there exists a \(\Pi^0_2\)-predicate H(n, x, y) such that for each \(m' < \omega\), \(m \in O^y\), \((H(m', H^m_n, x))\) is defined and \(H^m_n\) is the unique real satisfying \(H(m', y, x)\). If \(m = 2 \cdot 5^k\) for some k, then define \(H(m, H^m_n, x)\) if and only if \((H^m_n)' = H^m_n \wedge H(m', H^m_n, x)\). If \(m = 3 \cdot 5^k\) for some k, then define \(H(m, H^m_n, x)\) if and only if \((\forall n)(H(k,n,x))\).

We remark that the condition \(\Pi^0_2\) in Theorem 2.1.4 cannot be replaced by \(\Sigma^0_2\). It is not difficult to show that every \(\Sigma^0_2\)-singleton in \(2^\omega\) is recursive. On the other hand, every \(\Pi^0_2\)-singleton in \(2^\omega\) is Turing equivalent to a \(\Pi^0_1\)-singleton in \(\omega^\omega\).

**Proposition 2.1.15.** If \(x \in 2^\omega\) is a \(\Pi^0_2\)-singleton, then there is a \(\Pi^0_1\)-singleton \(T \subseteq \omega^\omega\) whose unique member y is Turing equivalent to x.

Proof. Suppose that \(x \in 2^\omega\) is a \(\Pi^0_2\) singleton. Then there is a recursive predicate R(n, \(\sigma\)) such that x is the unique real z satisfying \((\forall n)(\exists m)(R(n, z \mid m))\). We may assume that \((\forall n)(\forall \sigma)(R(n, \sigma) \rightarrow |\sigma| \ge n)\). Let T be the set of y's such that

- If y(n) = \(\sigma\) then R(n, \(\sigma\));
- (\(\forall \tau < y(n)\))(\(\neg\)R(n, \(\tau\))), and
- (\(\forall k \le n\))(y(k) \(\le\) y(n) \(\vee\) y(n) \(\le\) y(k)).

Then T is a \(\Pi^0_1\) set. Furthermore, if \(y \in T\) then for each n, y(n) is the shortest initial segment \(\sigma\) of x satisfying R(n, \(\sigma\)). Hence if \(y \in T\), then \(\bigcup_{n \in \omega} y(n) = x\). It follows that y is the unique real in T. Clearly \(y \equiv_T x\).

### 2.2 \(\Delta^1_1\)-ness and hyperarithmeticity

In this section we prove the fundamental result that a set is \(\Delta^1_1\) if and only if it is hyperarithmetic.

#### 2.2.1 \(\Delta^1_1\)-subsets of \(\omega\)

**Lemma 2.2.1.** The following two predicates are \(\Pi^1_1\): (i) \(n \in O^\vee \land k \in H^y_n\), (ii) \(n \in O^\vee \land k \notin H^y_n\).

Proof. Note that \(n \in O^\vee \land k \in H^y_n\) if and only if \(n \in O^\vee \land (\forall z)(H(n, z, y) \rightarrow k \in z)\), and \(n \in O^\vee \land k \notin H^y_n\) if and only if \(n \in O^\vee \land (\forall z)(H(n, z, y) \rightarrow k \notin z)\). By Proposition 1.2.5 and Theorem 2.1.4, both are \(\Pi^1_1\).

**Corollary 2.2.2 (Kleene [69]).** (i) If \(x\) is hyperarithmetic in \(y\), then \(x\) is \(\Delta^1_1(y)\). (ii) The set \(\{(x, y) \mid x \in \text{HYP}^y\}\) is \(\Pi^1_1\).

Proof. If \(x\) is hyperarithmetic in \(y\), then there is an \(H^y\)-set \(H^y_n\) such that \(x \le_T H^y_n\) for some \(n \in O^\vee\). Hence \(x = \Phi^{H^y}_e\) for some \(e\). Then both the predicates

```
$k \in x \leftrightarrow (\exists \sigma)(\Phi^e_\sigma(k) = 1 \land \sigma \prec H^y_n)$
```

and

```
$k \notin x \leftrightarrow (\exists \sigma)(\Phi^e_\sigma(k) = 0 \land \sigma \prec H^y_n)$
```

are \(\Pi^1_1(y)\) by Lemma 2.2.1.

Now \(x \in \text{HYP}^y \leftrightarrow (\exists n)(\exists e)(n \in O^\vee \land x = \Phi^{H^y}_e) \leftrightarrow (\exists n)(\exists e)(\forall m)(\forall z)(n \in O^\vee \land (H(n, z, y) \rightarrow x = \Phi^z_e))\) where \(H\) is as in Theorem 2.1.4. Thus the set \(\{(x, y) \mid x \in \text{HYP}^y\}\) is \(\Pi^1_1\).

For each \(n \in O^\vee\), define \(O^\vee_n = \{m \mid m \in O^\vee \land |m| < |n|\}\).
