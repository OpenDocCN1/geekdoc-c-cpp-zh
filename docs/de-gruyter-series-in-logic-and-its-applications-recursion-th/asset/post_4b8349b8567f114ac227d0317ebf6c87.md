
$L_{\omega_1^{CK}}^x$ is admissible. Hence by Theorem 3.1.8, there is an ordinal $\gamma < \omega_1^{CK}$ and an order-preserving function $g : T_{[n]} \to \gamma$.

Let $\varphi(n)$ be the statement

$(\exists y)(\exists g)(y \text{ is an ordinal } \wedge g \text{ is an order-preserving function from } T_{[n]} \text{ into } y)$.

In other words, $n \in x \Rightarrow (L_{\omega_1^{CK}}^x, \in) \models \varphi(n)$. On the other hand, if $(L_{\omega_1^{CK}}^x, \in) \models \varphi(n)$, then $T_{[n]}$ is wellfounded. Thus $n \in x$.

For the other direction, suppose that there is a $\Sigma_1$-formula $\varphi(u)$ such that $n \in x \Leftrightarrow (L_{\omega_1^{CK}}^x, \in) \models \varphi(n)$. Since $\varphi(u)$ is $\Sigma_1$, by Proposition 3.5.5, $(L_{\omega_1^{CK}}^x, \in) \models \varphi(n)$ if and only if for any $E$, if $(\omega, E)$ codes an $\omega$-model of KP, then $(\omega, E) \models \varphi[n_E]$ where $n_E$ denotes the number in $(\omega, E)$ which codes $n$. By Proposition 3.6.3, $x \in \Pi_1^1$.

Notwithstanding the remark in [107] that "the Spector–Gandy Theorem does not have many applications but it is undoubtedly one of the jewels of the effective theory", it is a major result and has seen important applications in higher recursion theory. For example, the theorem allows one to develop a robust computation theory for the structure $(L_{\omega_1^{CK}}^x, \in)$, including implementation of the priority method to study the metadegrees of $\Pi_1^1$-sets.

A generalization of Theorem 3.7.1 that lifts the result to sets of reals is the following.

### Corollary 3.7.2. For any real $y$, a set $A \subseteq 2^\omega$ is $\Pi_1^1(y)$ if and only if there is a $\Sigma_1$-formula $\varphi(u, v)$ such that $x \in A \Leftrightarrow (L_{\omega_1^{CK}}[x \oplus y], \in) \models \varphi(x, y)$.

It should be pointed out that the statement in the corollary remains valid if one replaces $2^\omega$ with $\omega^\omega$ in Corollary 3.7.2.

## 3.7.2 Second version

Let $0^*$ be as defined in § 2.6. Fix a number $i \in 0^* \setminus 0$. Then by the results in the same section, the set $0_i^* = \{j \mid j <_{0^*} i\}$ is an r.e. set such that $0_i^* \cap 0$ is an initial segment of $0^*$ of order type $\omega_1^{CK}$. By Lemma 2.2.4, there is a recursive function $g$ such that if $n \in 0$, then $0_n = \Phi_{g(n)}^{0_i^*}$.

For any real $z$ and $n \in \omega$, let $(z)_n = \{m \mid 2^n 3^m \in z\}$. Let $A(n, z)$ be an arithmetical predicate defined as follows: There is an $m <_{0^*} i$ such that

- (1) $(z)_i = \emptyset$;
- (2) $(\forall j)((j \prec_{0^*} 2^n) \to (z)_j = ((z)_j)')$;
- (3) $(\forall y)(3^{x+5} \prec_{0^*} 2^n \to (\forall k)((z)_{y,3} s^* = (z)_{\varphi(x, k)})$;
- (4) $n \in \Phi_{g(m)}^{(2)_m}$, and
- (5) $(\forall j)((j \prec_{0^*} 2^n) \to (z)_j \le_T (z)_{2^n})$.

Roughly speaking, $A(n, z)$ says that there is an $m <_{0^*} i$ such that $z$ codes an iteration of Turing jumps along the set $\{j \mid j \prec_{0^*} m\}$ and $n \in 0_m = \Phi_{g(m)}^{(2)_m}$. Then for any $n \in 0_i^* \cap 0$, $(z)_n = H_n$.

### Theorem 3.7.3 (Spector [156], Gandy [34]). $x \in 2^\omega$ is $\Pi_1^1$ if and only if there is an arithmetical predicate $B(n, z)$ such that $n \in x \leftrightarrow (\exists z \in A_1^x)(B(n, z))$.

Proof. By Corollary 2.2.12, if there is an arithmetical predicate $B(n, z)$ such that $n \in x \leftrightarrow (\exists z \in A_1^x)(B(n, z))$, then $x$ is in $\Pi_1^1$.

Suppose that $x$ is $\Pi_1^1$. Then there is a recursive function $f$ such that $n \in x \leftrightarrow f(n) \in \emptyset$. Let $A(n, z)$ be as defined earlier. If $n \in x$, then $f(n) \in \emptyset_{(m)}$. Let $m <_{0^*} i$ be in $\emptyset$ so that $|m| > f(n)$. Let $z$ be a real such that for any $j \le \omega^2$, $\langle z \rangle_j = H_j$ and $\langle z \rangle_0 = \emptyset$ for the other $j$'s. Then $f(n) \in \emptyset_m = \varphi_{(m)}^{(\omega^2)m}$. Clearly $z$ is hyperarithmetic. Thus $n \in x$ implies that there exists a hyperarithmetic real $z$ satisfying $A(f(n), z)$.

Now suppose that $z$ is hyperarithmetic and $A(f(n), z)$. Then there is an $m <_{0^*} i$ with properties (1)–(5). We claim that $m \in \emptyset$. Otherwise, for any $k \in \emptyset$, $H_k \le_T (z)_{2^{k+m}}$, contradicting the fact that $z$ is hyperarithmetic. Thus $f(n) \in \emptyset_m = \varphi_{(m)}^{(\omega^2)m}$ and so $n \in x$. Let $B(n, z)$ be $A(f(n), z)$. Then $n \in x$ if and only if there is a hyperarithmetic real $z$ such that $B(n, z)$.

We leave it to the reader to prove the following generalization of Theorem 3.7.3 to sets of reals:

### Corollary 3.7.4. $A \subseteq 2^\omega$ is $\Pi_1^1(y)$ if and only if there is an arithmetical predicate $B$ such that $x \in A \leftrightarrow (\exists z \le_h x \oplus y)(B(x, z, y))$.

Theorem 3.7.3 says that if we consider $\Pi_1^1$-sets to be r.e. sets, then hyperarithmetic reals are analogs of finite sets. In particular, there are infinite sets of natural numbers which are “finite”. This is a departure from the classical notion where infinite sets are never “finite”.

As mentioned in § 3.7.1, the Gandy–Specter Theorem presents an effective – hence recursion-theoretic – way to enumerate members of a $\Pi_1^1$-set. The enumeration is carried out in $L_{\omega_1^x}$ through ordinals less than $\omega_1^{CK}$.

The situation is more problematic with $\Pi_1^1$-sets of reals. Corollary 3.7.2 says that a set $A \subseteq 2^\omega$ is $\Pi_1^1$ if and only if there is a $\Sigma_1^1$-formula $\varphi(u)$ such that $x \in A \leftrightarrow (L_{\omega_1^x}[x], \in) \models \varphi(x)$ (rather than $(L_{\omega_1}, \in) \models \varphi(x)$). This makes analyzing $\Pi_1^1$-sets of reals a more delicate proposition. For each real $x$, one has to work within $L_{\omega_1^x}[x]$ to search for a solution to the $\Sigma_1^1$-formula $\varphi(u)$. This lack of uniformity is an issue when one wishes to choose the $x$ enumerated at the least stage satisfying $\varphi$. In the case of the second version of the Gandy–Specter Theorem (3.7.3), the corresponding procedure for “enumerating” a $\Pi_1^1$-set of reals is to “enumerate” the $H^x$-sets in order to compute a witness $z$. Here we face a problem similar to that for version one, in that there is no uniform way to execute this procedure. We give below an example to illustrate how such a difficulty may be addressed.

### Definition 3.7.5. A norm on a set $A \subseteq 2^\omega$ is a function $\varphi : A \to \alpha$ for some ordinal $\alpha$.

Norms are among the most important objects in descriptive set theory. A norm on a set $A$ acts as an “enumerating function” for $A$.

### Proposition 3.7.6. Let \( A \subseteq 2^\omega \) be \( \Pi_1^1 \). There is a norm \( \phi \) on \( A \), a \( \Pi_1^1 \)-relation \( P(x, y) \) and a \( \Sigma_1^1 \)-relation \( Q(x, y) \) such that for any \( y \in A \), \( (\forall x)(x \in A \land \phi(x) \le \phi(y) \rightarrow (P(x, y) \rightarrow Q(x, y))) \).

*Proof.* Since \( A \) is \( \Pi_1^1 \), by Corollary 3.7.4 there is an arithmetical predicate \( B(x, z) \) such that \( x \in A \Leftrightarrow (\exists z \in O^\times) B(x, z) \). If \( x \in A \), choose \( n \in O^\times \) so that \( |n|_x \) is minimal and \( B(x, \phi_{n_1}^H) \) holds for some \( e \). Let \( p(x) \) be as follows:

- 1. \( (\exists n_0 \in O^\times)(\exists e)(B(x, \phi_{n_0}^H) \land (\forall m \in O_{n_0}^y)(\neg e)(B(x, \phi_{m_1}^H)) \);
- 2. \( (\exists n_1 \in O^\times)(\exists e)(B(y, \phi_{n_1}^H) \land (\forall m \in O_{n_1}^y)(\neg e)(B(y, \phi_{m_1}^H)) \), and
- 3. there exists an isomorphism from \( \{m \mid m <_{O^\times} n_0\} \) onto an initial segment of \( \{m \mid m <_{O^\times} n_1\} \).

Clause (3) is \( \Pi_1^1 \) since the isomorphism (if there is one) must be hyperarithmetic in \( x \oplus y \).

By relativizing the results in §2.6, there is a \( \Sigma_1^1 \)-set \( \{(x, O^{+,*}) \mid x \in 2^\omega\} \subseteq 2^\omega \times \omega \) so that \( <_{O^\times} \) is a binary relation on \( O^{+,*} \) with the following properties:

- (i) \( O^\times \subseteq O^{+,*} \);
- (ii) \( <_{O^\times} \) is the restriction of \( <_{O^\times} \) to \( O^\times \);
- (iii) for any $n$, $n \in O^\times$ if and only if $<_{O^\times}$ restricted to $\{m \mid m <_{O^\times} n\}$ is a well-ordering.

Let \( Q(x, y) \) be the formula

```
\( (\forall n \in O^\times)(\exists e_0)(B(y, \phi_{n_0}^H) \rightarrow (\exists m \in O^{+,*})(\exists f)(\exists e_1) \)
\( (f : \{j \mid j <_{O^\times} m\} \rightarrow \{j \mid j \in O_{n_1}^y\} \text{ is order preserving } \land B(x, \phi_{e_1}^H)) \).
```

Now it is easy to see that if \( y \in A \), then \( (\forall x)(x \in A \land \phi(x) \le \phi(y)) \) if and only if \( P(x, y) \), and if and only if \( Q(x, y) \).

Proposition 3.7.6 essentially says that if \( y \) belongs to \( A \), then the collection of reals enumerated into \( A \) "before \( y \) is enumerated" is \( \Delta_1^1(y) \).

## 3.7.3 An application

We apply the Spector-Gandy Theorem to study \( \Sigma_1^1 \)-sets of reals. For each ordinal \( \alpha < \omega_1 \), let \( r_\alpha \) be a real coding a well-ordering of \( \omega \) of order type \( \alpha \). In the next two lemmas, let \( R_\alpha = \emptyset \) if \( \alpha \) is not a countable admissible ordinal (since \( \omega_1^x \) is admissible for any \( x \in \omega \)).

### Lemma 3.7.7. For any \( \alpha < \omega_1 \), the set \( R_\alpha = \{x \mid \omega_1^x = \alpha\} \) is \( \Delta_1^1(r_\alpha) \).

*Proof.* For any \( n \), let \( |n|_{r_\alpha} \) be the order of $n$ under the ordering $r_\alpha$. Then $x \in R_\alpha$ if and only if

- \( (\forall n \in O^\times)(\exists f) \text{ is an embedding of } \{m \mid m <_{O^\times} n\} \text{ into } r_\alpha) \land \)
- \( (\exists g)(\exists i \in O^{+,*})(g \text{ is an isomorphic map from } r_\alpha \text{ onto an initial segment of } O_i^{+,*}) \).
