By Lemma 5.3.3,

\((\exists S \le T)(\forall n)(S \Vdash \exists z(\varphi(n, z) \lor \neg \psi(n, z))).\)

By Lemma 5.3.2, define a \(\Pi^1_1\)-relation \(R \subseteq \omega \times \omega\) such that \(R(n, m)\) if and only if
\(m \in O_1 \land S \Vdash (\exists z^{|m|})(\varphi(n, z^{|m|}) \lor \neg \psi(n, z^{|m|})).\)

By Theorem 4.2.1, there is a total \(\Pi^1_1\) and hence \(\Delta^1_1\) function \(f\) uniformizing \(R\). By Corollary 1.5.2, there is an \(m_0 \in O_1\) such that for any \(n\), \(f(n) \mathrel{\text{o}} m_0\), so that
\((\forall n)(S \Vdash (\exists z^{|m_0|})(\varphi(n, z^{|m_0|}) \lor \neg \psi(n, z^{|m_0|}))).\)

Hence for any condition \(T\) with \(T \Vdash (\forall n)(\exists z)(\varphi(n, z) \lor \neg \psi(n, z))\), there is an \(S \le T\) and \(\beta < \omega_1^{CK}\) such that
\((\forall n)(S \Vdash (\exists z^\beta)(\varphi(n, z^\beta) \lor \neg \psi(n, z^\beta))).\)

Let

\(\mathcal{D} = \{S \mid S \Vdash \neg(\forall n)(\exists z)(\varphi(n, z) \lor \neg \psi(n, z)) \lor (\exists \beta < \omega_1^{CK})(S \Vdash (\forall n)(\exists z^\beta)(\varphi(n, z^\beta) \lor \neg \psi(n, z^\beta)))\}.\)

Then \(\mathcal{D}\) is a dense set of conditions arithmetical in \(\mathcal{O}\). By the genericity of \(x\) there is a \(T \in \mathcal{D}\) such that \(x \in [T]\). By Lemma 5.3.6 and the assumption, \(T \Vdash \neg(\forall n)(\exists z)(\varphi(n, z) \lor \neg \psi(n, z))\). Thus
\(T \Vdash (\exists \beta < \omega_1^{CK})(\varphi(n, z^\beta) \lor \neg \psi(n, z^\beta))\)
for some \(\beta < \omega_1^{CK}\). By the definition of forcing,
\(\mathfrak{A}(\omega_1^{CK}, x) \Vdash (\forall n)(\exists z^\beta)(\varphi(n, z^\beta) \lor \neg \psi(n, z^\beta)).\)

Thus as in the proof of Theorem 5.2.5, \(\mathfrak{A}(\omega_1^{CK}, x)\) satisfies \(\Delta^1_1\) comprehension.

**Theorem 5.3.8 (Gandy and Sacks [36]).** Suppose that \(x\) is Sacks generic and \(y \le_h x\) is nonhyperarithmetic. Then \(x \le_h y\), i.e. \(x\) is a set of minimal hyperdegree.

**Proof.** Suppose that \(y \le_h x\) is nonhyperarithmetic. By Corollary 5.1.4 and Lemma 5.3.7, there is a ranked formula \(\varphi\) such that
\((\forall n)(y(n) = i \Rightarrow \mathfrak{A}(\omega_1^{CK}, x) \Vdash \varphi(n, i)).\)
By Lemma 5.3.6, let \(T\) be a condition such that \(x \in [T]\) and
\(T \Vdash (\forall n)(\exists i)(i < 2 \land \varphi(n, i)).\)

**Claim.** For any \(S \le T\), there exist \(Q_i \le S\), \(i < 2\), and an \(n\) such that \(Q_i \Vdash \varphi(\bar{n}, i)\). Otherwise, fix \(S\) such that for all \(Q_i\) and all \(n\), it is not the case that \(Q_0 \Vdash \varphi(\bar{n}, 0)\) and \(Q_1 \Vdash \varphi(\bar{n}, 1)\). Then
\(n \in y \Leftrightarrow (\exists Q \le S)Q \Vdash \varphi(\bar{n}, 0)\)
and
\(n \notin y \Leftrightarrow (\exists Q \le S)Q \Vdash \varphi(\bar{n}, 1),\)
implying by Lemma 5.3.2 that \(y\) is hyperarithmetic, which is a contradiction.
