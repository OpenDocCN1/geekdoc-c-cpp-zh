Let B be the collection of such z_p's. Set

```
\mathfrak{A}(\gamma, x) = \bigcup_{\beta < \gamma} \mathfrak{A}(\beta, x) \cup B.
```

The satisfaction relation \(\mathfrak{A}(\alpha, x) \vDash \varphi\) is defined inductively:

+   - if \(\varphi\) is ranked with rank at most \(\gamma\), then \(\mathfrak{A}(\alpha, x) \vDash \varphi\) if and only if \(\bigcup_{\beta < \gamma} \mathfrak{A}(\beta, x) \vDash \varphi\);
+   - if \(\varphi\) is \((\exists z)\varphi(z)\), then \(\mathfrak{A}(\alpha, x) \vDash \varphi\) if and only if there is a \(\gamma < \alpha\) and a \(z^\gamma\) such that \(z^\gamma \in \mathfrak{A}(\alpha, x)\) and \(\mathfrak{A}(\alpha, x) \vDash \varphi(z^\gamma)\);
+   - if \(\varphi\) is \(\neg \psi\), then \(\mathfrak{A}(\alpha, x) \vDash \varphi\) if and only if \(\mathfrak{A}(\alpha, x) \not\vDash \psi\).

We leave the proof of the following results to the reader.

# **THEOREM 5.4.1.** If \(\omega_1^x \ge \alpha\), then the set \(\{ (x, \varphi) \mid \varphi \text{ is ranked } \land \mathfrak{A}(\alpha, x) \vDash \varphi \}\) is \(\Delta_1\) in \(L_{\omega_1^x}[x]\).

# **THEOREM 5.4.2.** Assume that \(\omega_1^x \ge \alpha\). Then \(\omega_1^x = \alpha\) if and only if \(\mathfrak{A}(\alpha, x)\) satisfies the \(\Delta_1^1\)-comprehension axiom.

# ## 5.4.2 Steel forcing

Steel forcing is a notion of forcing whose conditions are finite tagged trees \(p\) with the following properties:

+   - \(p = (t, h)\) where \(t \subseteq \omega^{<\omega}\) and \(h : \tilde{t} \to \alpha \cup \{\infty\}\) is a function such that \(h(t) = \infty\) and \((\forall \sigma, \tau \in \text{Dom}(h))(\sigma \to_T \tau \Rightarrow h(\sigma) < h(\tau))\). We adopt the convention that \(\infty > \beta\) for all \(\beta < \alpha\);
+   - \(p = (\tilde{t}_p, h_p) < q = (\tilde{t}_q, h_q)\) if and only if \(\tilde{t}_q\) is a subtree of \(\tilde{t}_p\) and \(h_p \restriction \tilde{t}_q = h_q\).

Fix a recursive coding of \(\omega^{<\omega}\) so that a string in \(\omega^{<\omega}\) is identified with a natural number. Since the generic real is intended to be a tree, we also use T in place of \(\dot{x}\).
Given a sentence \(\varphi \in \mathcal{L}(\alpha, \mathcal{T})\), define \(p = (t_p, h_p) \Vdash \varphi\) by induction on the complexity of \(\varphi\):

+   - \(p \Vdash \sigma \in \dot{T}\) if and only if \(\sigma = \emptyset \lor (\sigma \restriction |\sigma| - 1) \in \tilde{t}_p \land h_p(\sigma \restriction (|\sigma| - 1)) > 0\);
+   - \(p \Vdash t_1 = t_2\) if and only if \(\mathfrak{A}(\alpha, 0) \vDash t_1 = t_2\), where \(t_1, t_2\) are number-theoretic terms;
+   - \(p \Vdash t \in \dot{T}\) if and only if \(\mathfrak{A}(\alpha, 0) \vDash t = \sigma\) for some \(\sigma\) and \(p \Vdash \dot{\sigma} \in \dot{T}\), where \(t\) is a number-theoretic term;
+   - \(p \Vdash (\exists n)\varphi(n)\) if and only if \(p \Vdash \varphi(\bar{n})\) for some \(n \in \omega\);
+   - \(p \Vdash (\exists z^\gamma)\varphi(z^\gamma)\) if and only if \(p \Vdash \varphi(\bar{\eta})\) for some ranked formula \(\psi(\bar{\eta})\) of rank at most \(\gamma\);
+   - \(p \Vdash (\exists z)\varphi(z)\) if and only if \(p \Vdash (\exists z^\gamma)\varphi(z^\gamma)\) for some \(\gamma < \alpha\);
+   - \(p \Vdash \varphi \land \psi\) if and only if \(p \Vdash \varphi\) and \(p \Vdash \psi\);
+   - \(p \Vdash \neg \varphi\) if and only if \((\forall q \le p)(\neg q \Vdash \varphi)\).
