# Proposition 14.6.17. If V = L, then

Lowness for \(\Sigma^1_2\)-ML randomness = Lowness for \(\Delta^1_2\)-randomness.

In the case of lowness for \(\Sigma^1_2\)-randomness, one may apply Theorem 14.4.7 to obtain a characterization. Finally, it is possible to introduce the notion of constructive traceability in the obvious way and use it to study lowness property for \(\Sigma^1_2\)-randomness under additional set-theoretic assumptions. This will involve the use of some sophisticated techniques in set theory. The interested reader may consult [2].

# 14.6.6 Exercises

Exercise 14.6.1. Prove Lemma 14.6.3.

Exercise 14.6.2. Prove that x is \(\Delta^1_1\)-semirecceable if and only if every \(\Pi^1_1\)-ML random real is \(\Delta^1_1(x)\)-Kurtz random.

Exercise 14.6.3. Prove that there exist two uncountable \(\Sigma^1_1\)-sets A, B such that for any x \in A, y \in B and recursive ordinal \(\beta\), (x \oplus y)^\beta \not<_T O.

Exercise 14.6.4 (Bienvenu, Greenberg and Monin). Let \((G_i)_{i \in \omega}\) be as defined before. Prove that a \(\Delta^1_1\)-random x is \(\Pi^1_1\)-random if and only if for any i, either x \notin G_i or x \in \bigcup \{P \in \mathbf{P} \mid P \subseteq G_i\}.

Exercise 14.6.5 (Monin [105]). Prove that the set of \(\Pi^1_1\)-random reals is \(\Pi^1_3\) but not \(\Sigma^1_3\).

Exercise 14.6.6 (Greenberg and Monin). Prove that if x is low for \(\Delta^1_1\)-random but not hyperarithmetic, then x is \(\Pi^1_1\)-random cuppable.
