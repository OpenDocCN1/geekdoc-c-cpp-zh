
## Lemma 2.7.1. $y \in \text{BC}$ if and only if $T^y$ is a wellfounded tree. Hence $\text{BC}$ is $\Pi^1_1$. Moreover $y \in \Sigma^y_\beta$ if and only if $|T^y| \le \beta + 1$.

Proof. If $T^y$ is wellfounded, then one may show by induction on the rank of $\sigma$, for $\sigma \in T^y$, that $(y)_\sigma$ belongs to BC.

If $y \in \text{BC}$, then for any $\tau > \sigma$ in $T^y$ there exists a $y < \beta$ such that $(y)_\tau \in \Sigma_y$ and $(y)_\sigma \ge \Sigma_y$. Thus $T^y$ is a wellfounded tree.

Since $T^y \le_T y$ uniformly and $y \in \text{BC}$ if and only if $T^y$ is wellfounded, we conclude that $\text{BC}$ is $\Pi^1_1$. We leave the verification of the last statement of the lemma to the reader.

## 2.7.2 Hyperarithmetic codes

A hyperarithmetic code is a real in $\text{HYP} \cap \text{BC}$. Let $\text{BC}(\text{HYP})$ denote the collection of hyperarithmetic codes. By Corollary 2.2.2 and Lemma 2.7.1, $\text{BC}(\text{HYP})$ is $\Pi^1_1$.

Since $T^x \le_T x$, if $x \in \text{BC}(\text{HYP})$ then by Lemma 2.7.1 and the discussion above, $|T^x| < \omega^{ck}_1$. Thus $\text{BC}(\text{HYP}) \subseteq \Sigma_{\omega^{ck}_1} = \bigcup_{\beta < \omega^{ck}_1} \Sigma_\beta$.

## Theorem 2.7.2 (Kleene [70]). The following statements are equivalent:

- (i) $A = A_z$ for some $z \in \text{BC} \cap \Delta^1_1$.
- (ii) $A = A_z$ for some $z \in \text{BC}(\text{HYP})$.
- (iii) $A$ is $\Delta^1_1$.

Proof. Obviously, (i) $\Rightarrow$ (ii). For (ii) $\Rightarrow$ (iii), suppose $A = A_z$ for some $z \in \text{BC}(\text{HYP})$. We define a $\Pi^1_1$-relation $R_z \le \omega^{<\omega} \times \omega^\omega$ as follows. $R_z$ will decode $A_z$ from $T^z$, and retraces the steps that constructed $T^z$ from $A_z$:

- (1) $(\forall \tau \notin T^z)(\forall y) \neg R_z(\tau, y)$;
- (2) $(\forall \tau \in T^z)(\forall y)(\tau \text{ has no extensions} \to (R_z(\tau, y) \leftrightarrow (\exists m)(y \supset \sigma_n \wedge (z)_\tau(n) = 1)));$
- (3) $(\forall \tau \in T^z)((\exists m)(\tau * m \in T^z) \to (\forall y)(R_z(\tau, y) \leftrightarrow (\exists m) \neg R_z(\tau * m, y))).$

It is obvious that $R_z$ is unique and well defined. Moreover, for any $z \in \text{BC}, m \in \omega$, and $y \in \omega^\omega, R_z(\emptyset, m, y)$ if and only if $R_{(z)_m}(\emptyset, y)$. We make the following claim.

### Claim. $R_z(\emptyset, y)$ if and only if $y \in A_z$.

Proof of Claim. We prove this by induction. First assume that $z \in \Sigma_0$. Then $T^z$ consists only of the empty string and so by (2) $R_z(\emptyset, y)$ if and only if $y \in A_z$. Suppose the Claim holds for all $\Sigma$-codes where $y < \beta$. Let $z \in \Sigma_\beta$. If $R_z(\emptyset, y)$ then by (3) for some $m, \neg R_{(z)_m}(\emptyset, y)$. Then by induction $y \notin A_{(z)_m}$, hence $y \in A_z$. Conversely, if $y \in A_z$ then there is an $m$ such that $y \notin A_{(z)_m}$. Now $(z)_m \in \Sigma_\gamma$ for some $\gamma < \beta$. By induction, $\neg R_{(z)_m}(\emptyset, y)$. Thus $R_z(\emptyset, y)$ by (3), proving the Claim.

The Claim implies that $A_z$ is $\Pi^1_1(z)$. By a similar argument, one shows that the complement of $A_z$ is also $\Pi^1_1(z)$. Hence $A_z$ is $\Delta^1_1(z)$. Since $z \in \text{HYP}$, $A_z$ is $\Delta^1_1$.

We now show (iii) \(\Rightarrow\) (i). Suppose that \(A\) is \(\Delta^1_1\). Then both \(A\) and \(B = \omega^\omega \setminus A\) are \(\Sigma^1_1\). So there are two recursive trees \(S\) and \(T\) such that

\(x \in A \iff (\exists y)(\forall n)(x \upharpoonright n, y \upharpoonright n) \in S\)

and

\(x \in B \iff (\exists y)(\forall n)(x \upharpoonright n, y \upharpoonright n) \in T.\)

Define \(R = S \otimes T\) as follows:

\((\sigma, \tau, v) \in R \iff (\sigma, \tau) \in S \wedge (\sigma, v) \in T.\)

Define \((\sigma, \tau, v) < (\sigma', \tau', v')\) if \(\sigma > \sigma'\), \(\tau > \tau'\) and \(v > v'\). Since \(A \cap B = \emptyset\), \(R\) is a wellfounded tree under \(<\). We construct a hyperarithmetic code \(z\) so that \(B \subseteq A_z\) and \(A_z \cap A = \emptyset\). Then \(A_z = B\).

We define a recursive function \(h : \omega \to \omega\) such that for some \(c\), \(\Phi_{h(e)}(n, \emptyset, \emptyset, 0)\) is a hyperarithmetic code for \(A\).

For \((\sigma, \tau, v)\) such that \(|\sigma| = |\tau| = |v|\), there are three cases to consider:

- (1) \((\sigma, \tau, v) \notin R\) and \((\sigma, v) \in T\). Define \(\Phi_{h(e)}(0, \sigma, \tau, v) = 0\) and \(\Phi_{h(e)}(n, \sigma, \tau, v) = 1\) for all \(n > 0\).
- (2) \((\sigma, \tau, v) \notin R\) and \((\sigma, v) \notin T\). Define \(\Phi_{h(e)}(n, \sigma, \tau, v) = 0\) for all \(n\).
- (3) \((\sigma, \tau, v) \in R\). For \((i, j, k, l)\), we define a recursive function \(g\) determined by the following four subcases:

  - 3(i) \(i = k\) and \((\sigma' \uparrow i, \tau' \uparrow j, v' \uparrow l) \in R\). Define \(g(e, i, j, k, l, n) = \Phi_e(n, \sigma' \uparrow i, \tau' \uparrow j, v' \uparrow l)\).
  - 3(ii) \(i \neq k\). Define \(g(e, i, j, k, l, n) = m\) for all \(n > 0\) and \(g(e, i, j, k, l, 0) = 0\), where \(m\) is a code such that \(0_m = 0^k\).
  - 3(iii) \(i = k\) and \((\sigma' \uparrow i, \tau' \uparrow j) \notin S\). Define \(g(e, i, j, k, l, n) = 1\) for all \(n > 0\) and \(g(e, i, j, k, l, 0) = 0\).
  - 3(iv) \(i = k\) and \((\sigma' \uparrow i, \tau' \uparrow j) \in S\) but \((\sigma' \uparrow i, v' \uparrow l) \notin T\). Define \(g(e, i, j, k, l, n) = 0\) for all \(n\).

Intuitively, \(g\) is a hyperarithmetic code for a set \(A_{i,j,k,l}\) disjoint from \([S_{(\sigma \uparrow i, \tau \uparrow j)}]\) but covers \([T_{(\sigma \uparrow i, v \uparrow l)}]\), where

\([S_{(\sigma \uparrow i, \tau \uparrow j)}] = \{x \supset \sigma \uparrow i \mid (\exists y)(y \supset \tau \uparrow j \wedge (\forall n)((x \upharpoonright n, y \upharpoonright n) \in S)\}\)

and

\([T_{(\sigma \uparrow k, v \uparrow l)}] = \{x \supset \sigma \uparrow k \mid (\exists y)(y \supset v \uparrow l \wedge (\forall n)((x \upharpoonright n, y \upharpoonright n) \in T)\}.\)

The plan is to define \(\Phi_{h(e)}(n, \sigma, \tau, v)\) to code the set \(C = \bigcup_{k,l} [\bigcup_{i,j} A_{i,j,k,l}]\). Then \(C \supseteq [T_{(\sigma, v)}]\) and \(C \cap [S_{(\sigma, \tau)}] = \emptyset\). Define a recursive function \(p^1_k\) such that \(p^1_k(0) = 1\) and \(p^1_k((2^{i,j} \cdot 3^n) \cdot 3^m) = 1\) if and only if \(g(e, i, j, k, l, n) = 1\). Then \(p^1_k\) will code the set \(\bigcup_{i,j} (\omega^2 \setminus A_{i,j,k,l})\).

Define a recursive function \(p^2\) so that \(p^2(0) = 1\) and \(p^2((2^{k,l} \cdot 3^n) \cdot 3^m) = 1\) if and only if \(p^1_k(n) = 1\). Then \(p^2\) is a code for \(\bigcup_k (\omega^\omega \setminus \bigcup_j (\omega^\omega \setminus A_{i,j,k,l})) = \bigcup_k (\bigcap_l A_{i,j,k,l})\).

Let \(\Phi_{h(e)}(n, \tau, v_0, v_1) = 1\) if and only if \(p^2(n) = 1\). By the Recursion Theorem, there is a fixed point \(c\) such that \(\Phi_{h(c)} = \Phi_c\).

Let \( z(n) = 1 \iff \Phi_c(n, 0, 0, 0) = 1 \). By an easy transfinite induction along \( < \) on \( R \), one shows that for any \( (\sigma, \tau, v) \in R \), \( z_{(\sigma, \tau, v)} = \{n \mid \Phi_c(n, \sigma, \tau, v) = 1\} \) is a recursive Borel code such that \( A_{z_{(\sigma, \tau, v)}} \cong [T_{(\sigma, v)}] \) and \( A_{z_{(\sigma, \tau, v)}} \cap [S_{(\sigma, \tau)}] = \emptyset \). In particular, \( z^* = z_{(0, \emptyset, \emptyset)} \) is a recursive Borel code such that \( A \cap A_{z^*} = A \cap [S_{0,0}] = \emptyset \) and \( [T_{(0,0)}] = B \subseteq A_{z^*} \). Thus \( z^* \) is a recursive Borel code for \( B \).

Note that more was proved in the theorem above. Recall (see § 1.5.1) that there is a \( \Pi^1_1 \)-set \( A \subseteq \omega \times \omega^\omega \) such that every \( \Sigma^1_1 \)-set \( B \) is of the form \( B = \neg A_n = \{x \mid (n, x) \notin A\} \) for some \( n \). These \( n \)’s are called \( \Sigma^1_1 \)-codes. Then Theorem 2.7.2 may be strengthened to: There is a recursive function \( f : \omega \times \omega \to \omega^\omega \) such that if \( m, n \) are \( \Sigma^1_1 \)-codes and \( (2^\omega \setminus A_n) \cap (2^\omega \setminus A_m) = \emptyset \), then \( f(n, m) \in \text{BC} \cap \Delta^1_1 \), \( (2^\omega \setminus A_{f(n,m)}) \cap (2^\omega \setminus A_n) = \emptyset \), and \( (2^\omega \setminus A_m) \subseteq (2^\omega \setminus A_{f(n,m)}) \). This is an effective separation theorem which is a central result in effective descriptive set theory. We will discuss related facts in the sequel.

## Remark 2.7.3. One may wonder how recursive codes are able to code the same sets as those coded hyperarithmetically. The answer is that there is a trade-off in the number of induction steps used. For example, a hyperarithmetic open set can be coded by a hyperarithmetic code in one step but any recursive code for it will be in some \( \Sigma_\beta \) where \( \beta \) is a possibly large recursive ordinal.

We say that \( A \le \omega^\omega \) is \( \Sigma^1_1(\text{HYP}) \) if \( A = A_x \) for some hyperarithmetic \( x \in \Sigma_\beta \). Louveau [85], using Gandy forcing, proved the following result.

## Theorem 2.7.4 (Louveau [85]). If \( A, B \) are \( \Sigma^1_1 \) and separated by \( A_x \) for some \( x \in \Sigma_\beta \), then \( A \) is separable from \( B \) by \( A_y \) for some \( y \in \Sigma_\beta \cap \Delta^1_1 \). Hence if \( A \) is \( \Delta^1_1 \) and \( \Sigma_\beta \), then \( A \) is \( \Sigma_\beta(\text{HYP}) \).

Theorem 2.7.2 yields another parameterization of \( \Delta^1_1 \)-sets of reals.

## Corollary 2.7.5. There is a \( \Pi^1_1 \)-set \( A \subseteq \omega \times \omega^\omega \) such that

- \( (\forall n)(A_n = \{y \mid (n, y) \in A\} \in \Delta^1_1) \).
- \( (\forall C)(\exists n)(C \in \Delta^1_1 \to C = A_n) \).

**Proof.** By Proposition 2.2.11, there is a partial function \( D : \omega \times \omega \to \omega \) with a \( \Pi^1_1 \)-graph parameterizing \( \Delta^1_1 \)-reals. Define \( (n, y) \in A \) if and only if

\( (\forall i)(\exists j)(n, i, j) \in D \land (\forall x)((\forall i)(\forall j)(x(i) = j \leftrightarrow (n, i, j) \in D) \to x \in \text{BC}(\text{HYP}) \land x \in A_x) \).

Note that if \( (\forall i)(\exists j)(n, i, j) \in D \) is \( \Delta^1_1 \). So \( A \) is \( \Pi^1_1 \). Obviously each \( A_n^1 \)-set \( C \) is \( A_n \) for some \( n \), and \( A_n \) codes a real in \( \text{BC}(\text{HYP}) \). For each \( n \), either \( A_n = \emptyset \) or \( A_n = A_x \) for some \( x \in \text{BC}(\text{HYP}) \). Hence \( A \) is as required.
