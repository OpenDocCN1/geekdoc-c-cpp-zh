Recursion-theoretic proof. As above, we have a recursive tree \( T \subseteq \omega^{<\omega} \times \omega^{<\omega} \) such that \( x \in P \) if and only if \( (\exists y)(\forall n)(\langle x \mid n, y \mid n \rangle \in T \). We perform a Cantor–Bendixson style operation on the tree as follows:

At stage 0, let \( T_0 = T \).
At limit stage \( \alpha \), let \( T_\alpha = \bigcap_{\beta < \alpha} T_\beta \).
At successor stage \( \alpha + 1 \), let
\( T_{\alpha+1} = \langle (\sigma, \tau) \in T_\alpha \mid (\exists \sigma_0 > \sigma)(\exists \tau_0 > \tau)(\exists \sigma_1 > \sigma)(\exists \tau_1 > \tau)((\sigma_0, \tau_0) \in T_\alpha \land (\sigma_1, \tau_1) \in T_\alpha \land \sigma_0|\sigma_1) \rangle \).

Observe that \( T_\alpha \subseteq T_\beta \) for all \( \alpha \ge \beta \). Moreover, for any successor ordinal \( \alpha + 1 \), if \( T_{\alpha+1} \neq T_\alpha \), then there is a \( (\sigma_\alpha, \tau_\alpha) \in T_\alpha \setminus T_{\alpha+1} \). Note that \( (\sigma_\alpha, \tau_\alpha) \neq (\sigma_\beta, \tau_\beta) \) for any \( \alpha \neq \beta \) if these are defined. Since the set \( \omega^{<\omega} \times \omega^{<\omega} \) is countable, there is a least countable ordinal \( \gamma \) such that \( (\sigma_\gamma, \tau_\gamma) \) does not exist. Then \( T_\gamma = T_{\gamma+1} \) and so \( T_\gamma = T_\alpha \) for any \( \alpha \ge \gamma \). By replacing \( T' \) in the set-theoretic proof above with \( T_\gamma \), we conclude that \( P \) contains a perfect subset.

# Remark 1.1.11.

+   (i) The proofs above raise two interesting questions. First, what is the complexity of the perfect subset obtained? Since the statement, “\( P \) is uncountable” is not second-order definable in arithmetic, the perfect subset defined is generally neither \( \Sigma^1_1 \) nor \( \Pi^1_1 \). However, we will show later by a more powerful recursion-theoretic argument that its complexity can be controlled (see Exercise 1.5.5). Second, what is the least ordinal \( \gamma \) for which \( T_\gamma = T_{\gamma+1} \)? We will give a calculation of this ordinal later (see Proposition 3.6.10).

+   (ii) In general, not every uncountable set has the perfect set property. In fact, “\( \Sigma^1_1 \)-ness” is the best possible since it is not provable in ZFC that every \( \Pi^1_1 \)-set has the perfect set property (see Corollary 4.3.6).
