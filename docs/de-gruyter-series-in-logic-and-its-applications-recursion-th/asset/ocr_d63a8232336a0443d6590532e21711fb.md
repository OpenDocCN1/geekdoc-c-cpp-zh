Then by assumption there are corresponding $\Delta^1_1$-functions $f_n$ and $F_n$. For every $n$ and $m \in [2^n, 2^{n+1})$, let $g(m) = \text{the } (m - 2^n)\text{-th entry of the } (m - 2^n)\text{-th element in } F_h(n) \text{ if such an } m \text{ exists, and let } g(m) = 1 \text{ otherwise. Then } g \text{ is a } \Delta^1_1\text{-function semitracing } g.$

To separate $\Delta^1_1$-traceability from the conjunction of $\Delta^1_1$-semitraceability and $\Delta^1_1$-domination, one applies a modified Sacks forcing construction.

# **Definition 13.3.14.**

+   (i) A $\Delta^1_1$-perfect tree $T \subseteq 2^{<\omega}$ *fully splits at n* if for every $\sigma \in T$ with $|\sigma| \in [2^n, 2^{n+1})$, both $\sigma 0$ and $\sigma 1$ are in $T$. Then $n$ is said to be a *fully splitting level* of $T$.
+   (ii) A $\Delta^1_1$-perfect tree $T \subseteq 2^{<\omega}$ is *clumpy* if there are infinitely many $n$'s where $T$ fully splits at $n$.

Let $\mathbb{F} = \langle F, \le \rangle$ be the partial order of clumpy trees ordered under inclusion. Given a formula $\varphi$ in the language $\mathscr{L}(\omega_1^{ck}, X)$ of ramified analytical hierarchy (§ 5.1.1), define the forcing relation $T \Vdash \varphi$ as in Sacks forcing:

+   - If $\varphi$ is a ranked sentence and $(\forall x \in T)(\exists(\alpha \in O^{ck}, x) \Vdash \varphi)$, then $T \Vdash \varphi$;
+   - If $\varphi(y)$ is unranked and $T \Vdash \varphi(y \mid \psi)$ for some $\psi$ of rank at most $\beta$, then $T \Vdash (\exists y)^\beta \varphi(y^\alpha)$;
+   - If $T \Vdash (\exists y)^\beta \varphi(y^\alpha)$, then $T \Vdash (\exists y)\varphi(y)$;
+   - If $\varphi(n)$ is unranked and $T \Vdash \varphi(\bar{m})$ for some numeral $\bar{m}$, then $T \Vdash (\exists n)\varphi(n)$;
+   - If $\varphi$ and $\psi$ are unranked, $T \Vdash \varphi$ and $T \Vdash \psi$, then $T \Vdash \varphi \land \psi$;
+   - If $\varphi$ is unranked and $(\forall p)(P \subseteq T \rightarrow P \Vdash \varphi)$, then $T \Vdash \neg \varphi$.

By Theorem 5.1.1, we have the following.

# **Lemma 13.3.15.**

The set
\(\{ (T, \ulcorner \varphi \urcorner) \mid T \text{ is a condition } \land \varphi \text{ is } \Sigma_1^1 \land T \Vdash \varphi \}\)

is $\Pi_1^1$.

# **Lemma 13.3.16.**

+   (i) Let $\langle \varphi_i \rangle_{i < \omega}$ be a hyperarithmetic sequence of $\Sigma_1^1$-sentences. Suppose that for every $i$ and $Q \le T$, there exists an $R \le Q$ such that $R \Vdash \varphi_i$. Then there exists an $R \le T$ such that $R \Vdash \varphi_i$ for every $i$.
+   (ii) $(\forall \psi)(\forall T)(\exists Q \le T)(Q \Vdash \psi \lor Q \Vdash \neg \psi)$.

Proof. Using the notation $P \Vdash n = \{ \tau \in 2^{<\omega} \mid \tau \in P \}$, define a $\Pi_1^1$-relation $\mathcal{R}$ by

\(\mathcal{R}(R, i, \sigma, P) \leftrightarrow (\sigma R \wedge P \subseteq R \wedge P \Vdash \varphi_i \wedge P \Vdash [\sigma] = \{ \tau \mid \tau < \sigma \} \wedge \log |\sigma| - 1 \text{ is the } i\text{-th fully splitting level of } R).\)

Then $\mathcal{R}$ is uniformized by a partial $\Pi_1^1$-function $F : F \times \omega \times 2^{<\omega} \rightarrow \mathbf{F}$. Using $F$, a hyperarithmetic family $\langle P_\sigma \mid \sigma \in 2^{<\omega} \rangle$ may be defined by recursion on $\sigma$.
