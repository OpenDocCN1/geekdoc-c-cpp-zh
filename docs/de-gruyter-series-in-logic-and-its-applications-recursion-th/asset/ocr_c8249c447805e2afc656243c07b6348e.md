Let \(\varphi(x, x^\beta)\) be a formula of rank at most \(\beta\) so that the only free variables are \(x\) and \(x^\beta\). Then \(\mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv (\exists x^\beta)\varphi(x, x^\beta)\) if and only if \(\mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv \varphi(x, x^\beta \mid \psi)\) for some formula \(\eta(n)\) with rank less than \(\beta\), where \(n\) is the only free variable of \(\psi\).

For simplicity, write \(\varphi(x, x^\beta \mid \psi)\) as \(\varphi(x, \psi)\). Then

\(\{(\lnot(\exists x^\beta)\varphi(x, x^\beta), p) \mid \mu(|x| \mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv (\exists x^\beta)\varphi(x, x^\beta)) \ge p \wedge p \text{ is rational} \} = \{(\lnot(\exists x^\beta)\varphi(x, x^\beta), p) \mid (\exists n \text{ of rank} < \beta) (n \text{ is the only free variable of } \psi) \wedge p \text{ is rational} \wedge \mu(|x| (\mathfrak{A}_1^{CK}, x) \equiv \varphi(x, \psi))) \ge p \}.\)

Note that the set of formulas \(\varphi\) of rank \(< \beta\) where \(n\) is the only free variable belongs to \(L_{\omega_1^{CK}}\). Hence the set \(\{(\lnot(\exists x^\beta)\varphi(x, x^\beta), p) \mid p \text{ is rational} \wedge \mu(|x| \mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv (\exists x^\beta)\varphi(x, x^\beta)) \ge p \}\) is \(\Sigma_1\) over \((L_{\omega_1^{CK}}, \in)\).

For formulas of the form \((\forall x^\beta)\varphi(x, x^\beta)\) where \(n\) is the only free variable, note that uniformly in \((L_{\omega_1^{CK}}, \epsilon)\) there is an \(\omega\)-enumeration of the set of such formulas. Fix such an enumeration \(\{\psi_i(n)\}_{i < \omega}\). Then

\(\mu(|x| \mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv (\forall x^\beta)\varphi(x, x^\beta)) \ge p\)

if and only if

\(\mu(|x| \mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv (\forall i)\varphi(x, \psi_i)) \ge p\)

if and only if

\((\forall j)\mu(|x| \mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv \wedge_{i \le j} \varphi(x, \psi_i)) \ge p.\)

Hence \(\{(\forall x^\beta)\varphi(x, x^\beta), p\} \mid p \text{ is rational} \land \mu(|x| \mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv (\forall x^\beta)\varphi(x, x^\beta)) \ge p\}\) is \(\Sigma_1\) over \((L_{\omega_1^{CK}}, \in)\).

We leave it to the reader to verify the other cases. Note that the induction is uniform and hence the lemma follows.

**Corollary 13.1.2.** Let \(p > 0\) be rational. Suppose that \(\varphi(n, y)\) is a ranked formula whose only free unbounded set variable is \(y\). If for any \(n < \omega\), \(\mu(|x| \mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv (\exists y)\varphi(n, y)) \ge p\), then there is a \(\beta < \omega_1^{CK}\) such that \((\forall n)\mu(|x| (\mathfrak{A}_1^{CK}, x) \equiv (\exists y^\beta)\varphi(n, y^\beta)) \ge p\).

**Proof.** Let \(m_0\) be fixed so that \(p > 2^{-m_0}\). By Lemma 13.1.1 and the assumption, there is a function \(f : \omega \times (\omega \setminus \{m_0\}) \to \omega_1^{CK}\) such that for every \(n\) and \(m > m_0\),

\(\mu(|x| \mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv (\exists y^{<m_0})\varphi(n, y^{<m_0})) \ge p \ge 2^{-m}.\)

Let \(g(n) = \bigcup_{m < \omega} f(n, m)\). By the admissibility of \(L_{\omega_1^{CK}}\), \(g\) is total in \(L_{\omega_1^{CK}}\). Hence for all \(n\), \(\mu(|x| \mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv (\exists y^{<g(n)})\varphi(n, y^{<g(n)})) \ge p\). Let \(\beta = \bigcup_{n < \omega} g(n)\). By admissibility again, \(\beta < \omega_1^{CK}\). Moreover, \((\forall n)\mu(|x| \mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv (\exists y^\beta)\varphi(n, y^\beta)) \ge p\).

**Theorem 13.13.** (Sacks [120]). Let \(p\) be rational. The set \(\{(\ulcorner \varphi \urcorner, p) \mid p \text{ is rational.} \}\) is \(\Sigma_1^1 \wedge \varphi\)’s only free variable is \(x\) if \(\mu(|x| \mathfrak{A}(\mathfrak{A}_1^{CK}, x) \equiv \varphi) \ge p\}\) is \(\Pi_1^1\).

**Proof.** This follows immediately from Lemma 13.1.1 and Corollary 13.1.2.
