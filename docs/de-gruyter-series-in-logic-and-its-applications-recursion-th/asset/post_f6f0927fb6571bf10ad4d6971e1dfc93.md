
## 6.3.2 Martin–Solovay's characterization

### Lemma 6.3.4.

(i) For each \(i \in I\), \(D_{0,i} = \{p \in \mathbf{P} \mid x_i \subseteq \text{Dom}(p)\}\) is dense. (ii) For each \(i \in X\) and \(i \in \omega\), \(D_{1,i} = \{p \in \mathbf{P} \mid |\{n \in x_i \mid p(n) = 1\}| > i\}\) is dense.

**Proof.** (i) is obvious. To see (ii), given any condition \(p\), we have \(|\text{Dom}(p) \cap x_i| < \infty\). Then simply extend \(p\) to a condition \(q\) such that \(|\{n \in x_i \mid q(n) = 1\}| > i\).

### Theorem 6.3.5.

If \(G\) is a generic set meeting all \(D_{0,i}\)’s and \(D_{1,i}\)’s for all \(i \in I\), then the generic set \(g = \bigcup_{p \in G} p\) is a real such that for any \(i \in I, x \in X\) and only if \(g \cap x_i\) is infinite.

**Proof.** Let \(G\) be a generic meeting all \(D_{0,i}\)’s and \(D_{1,i}\)’s for all \(i \in I\). If \(i \in X\), then by (ii) of Lemma 6.3.4, \(x_i \cap g\) is infinite. If \(i \notin X\), then by (i) of Lemma 6.3.4, \(x_i \subseteq \text{Dom}(p)\) for some \(p \in G\). But \(|\{n \mid p(n) = 1\}| < \infty\), and so \(x_i \cap g\) is finite.

Hence almost disjoint forcing produces a real \(g\) which codes a large set \(X\) via an almost disjoint set \(A\).

### Lemma 6.3.6.

Assume \(\text{MA}_{\aleph_1}\) and suppose that \((\omega_1)^{L[x]} = \omega_1\) for some \(x \in 2^\omega\). If \(B \subseteq 2^\omega\) has cardinality \(\aleph_1\), then \(B\) is \(\Pi^1_1\).

**Proof.** We assume that \(x(0) = 1\) for any \(x \in B\).

Since \((\omega_1)^{L[x]} = \omega_1\), let \(C = \{z \mid z(0) = 0 \wedge z \in L_{\omega_1^{L[x]}}[z \oplus x]\}\). Then \(C\) is a \(\Pi^1_1\)-set of cardinality \(\aleph_1\).

Let \(f : \omega \to 2^\omega\) be a recursive bijection. Define

\(T = \{t \in 2^{<\omega} \mid (\exists \tau \in 2^{<\omega})(\forall n < |t|)(t(n) = 1 \mapsto f(n) \prec \tau)\}.\)

Note that \(T\) is an almost disjoint set tree. Moreover \(T\) is a recursive perfect tree and there is a recursive homomorphism \(h : 2^\omega \to [T]\). Also note that any \(x \in [T]\) is recursive in each of its infinite subsets. Let \(C_0 = \{y \mid (\exists x \in C)(h(x) = y)\}\) and \(B_0 = \{y \mid (\exists x \in B)(h(x) = y)\}\). Suppose \(p_0, p_1, \dots\) is a recursive enumeration of the prime numbers. Let

- \(B_0 = \{x_a\}_{a < \aleph_1},\)
- \(C_0 = \{y_a\}_{a < \aleph_1},\)
- \(B_1 = \{x_{a,n} \mid (\forall i \in \omega)(x_{a,n}(i) = 1 \leftrightarrow (\exists j)(i \text{ is the } p_n^j\text{-th element of } x_a))\}\)

and

\(C_1 = \{y_{a,n} \mid (\forall i \in \omega)(y_{a,n}(i) = 1 \leftrightarrow (\exists j)(i \text{ is the } p_n^j\text{-th element of } y_a))\}.\)

Set \(B = B_0 \cup C_0\). Then \(A\) is almost disjoint, and \(x \in C_1\) if and only if

- (i) there is a \(z \le_T x\) and an \(n \in \omega\) such that \(z \in C_0\), and
- (ii) \((\forall i \in \omega)(x(i) = 1 \leftrightarrow (\exists j)(i \text{ is the } p_n^j\text{-th element of } z))\).

Then \(C_1\) is \(\Pi_1^1\). By \(\text{MA}_{\aleph_1}\), Lemma 6.3.3 and Theorem 6.3.5, there is a real \(g\) such that for any \(\alpha < \aleph_1\) and \(n \in \omega\),

- 1. \(g \cap \chi_{\alpha, 2n+1}\) is infinite if and only if \(n \notin \chi_\alpha\); and
- 2. \(g \cap \chi_{\alpha, 2n+2}\) is infinite if and only if \(n \in \chi_\alpha\).

Let \(h_0\) be a function so that \(h_0(x, n) = i\) (if \((\exists j)(i\) is the \(p_j^i\)-th element of \(x)\)). Note that \(h_0(x_\alpha, n) = \chi_{\alpha, n}\) and \(h_0(y_\alpha, n) = y_{\alpha, n}\).

Set \(h_1(x) = \{n \mid h_0(x, 2n + 1) \cap g\} = \text{co}\infty\) and \(h_2(x) = \{n \mid h_0(x, 2n + 2) \cap g\} = \text{co}\infty\).

Then for any \(x \in 2^\omega\), \(x \in B_0 \leftrightarrow h_1(x) \in C_0 \land h_2(h_1(x)) = x\),

showing that \(B\) is \(\Pi_1^1\).

### Theorem 6.3.7 (Martin and Solovay [90]).

Assume \(\text{MA}_{\aleph_1}\). Then \((\omega_1)^{[L[x]]} = \omega_1\) for some \(x \in 2^\omega\) if and only if every subset of \(2^\omega\) with cardinality \(\aleph_1\) is \(\Pi_1^1\).

**Proof.**

Suppose that \((\omega_1)^{[L[x]]} < \omega_1\) for all \(x \in 2^\omega\). Let \(A = \{x_\alpha\}_{\alpha < \omega_1}\) be a maximal chain of Turing degrees. Then \(A\) has cardinality \(\aleph_1\) and contains no perfect subset. It follows that for any real \(x\), \(A\) must contain a real not constructible in \(L[x]\). If \(A\) is \(\Pi_1^1(x_0)\) for some \(x_0\), then by Lemma 4.3.2, \(A\) contains a perfect subset which is a contradiction.

Conversely suppose that \((\omega_1)^{[L[x]]} = \omega_1\) for some \(x \in 2^\omega\). By Lemma 6.3.6, every subset of \(2^\omega\) of cardinality \(\aleph_1\) is \(\Pi_1^1\).

### Remark 6.3.8.

Theorem 6.3.7 may be viewed as a result that goes "beyond the limits" of recursion theory, in which typically a lightface version of a theorem is proved and then relativized to a boldface version. However, in this case there is no lightface version for Theorem 6.3.7.

An immediate consequence of Theorem 6.3.7 (see Exercise 6.3.3) is that if \(\text{MA}_{\aleph_1}\) holds, then \((\omega_1)^{[L[x]]} = \omega_1\) for some \(x \in 2^\omega\) if and only if every union of \(\aleph_1\)-many Borel sets is \(\Sigma_2^1\). In contrast to this, Harrington [44] proved that for any cardinal \(\kappa < 2^{\aleph_0}\), there is a model of ZFC in which any union of \(\kappa\)-many Borel sets is \(\Pi_2^1\).

## 6.4 Large cardinals

Despite a fairly comprehensive set of axioms for a theory of sets, a considerable number of important mathematical problems are known to be independent of ZF. Additional assumptions have been introduced to study such problems, and among the assumptions are those involving the notion of a large cardinal. We discuss some of them here.

### 6.4.1 Inaccessible cardinals

### Definition 6.4.1.

- A cardinal \(\kappa\) is *inaccessible* if \(\kappa\) is regular and for every cardinal \(\nu < \kappa, 2^\nu < \kappa\);
- A cardinal \(\kappa\) is *weakly inaccessible* if \(\kappa\) is a regular limit cardinal.

We only consider \(\kappa > \omega\) here. The assumption that there is an inaccessible cardinal is the weakest large cardinal axiom. If \(\kappa\) is inaccessible, then ZFC \(\vdash\) "\((V_\kappa, \in) \vDash\) ZFC". In other words, ZFC + "\(\exists \kappa (\kappa \text{ is inaccessible})\)" implies that ZFC is consistent. By Gödel's second Incompleteness Theorem, ZFC + "ZFC is consistent" does not imply the consistency of "ZFC + \(\exists \kappa (\kappa \text{ is inaccessible})\)". This means that one is not able to construct a model of "ZFC + \(\exists \kappa (\kappa \text{ is inaccessible})\)" by assuming that there is a model of ZFC.

At first sight, the notion of an inaccessible cardinal appears to be disconnected from the structure of the set of reals. Rather surprisingly, the two are closely linked, as illustrated by the following example.

### Proposition 6.4.2 (Solovay [149]).

If there is no uncountable \(\Pi^1_1\)-thin set, then \(\omega_1\) is inaccessible in \(L\).

**Proof.** Clearly \(\omega_1\) is regular in \(L\). Since \((L, \epsilon) \vDash\) GCH, it is sufficient to show that \(\omega_1\) is a limit cardinal in \(L\).

Suppose not. Then there is a countable ordinal \(\gamma < \omega_1\) such that \((L, \epsilon) \vDash \omega_1 = \gamma^+ = 2^\gamma\). Since \(\gamma\) is countable, there is an \(x\) which computes a well-ordering of \(\omega\) of order type \(\gamma\). Then \((L[x], \epsilon) \vDash 2^\omega = \omega_1\). Relativizing the proof of Corollary 4.3.6 to \(x\), we have \(\{z \mid z \in L_{\omega_1^{CK}}[x]\}\) to be an uncountable \(\Pi^1_1(x)\)-thin set, a contradiction.

Proposition 6.4.2 is concerned with the classical topic in descriptive set theory of existence of perfect subsets of an uncountable definable set of reals. It says that to require all \(\Pi^1_1\)-sets to be "well-behaved", one would have to appeal at least to the existence of an inaccessible cardinal. This situation may be viewed from the perspective of reverse mathematics, a program which investigates set existence axioms that are necessary and sufficient to prove theorems in "ordinary mathematics".
