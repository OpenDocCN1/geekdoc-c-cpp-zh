$f(A) \Leftrightarrow (\exists x \in \Delta_1^1(y))(y \in A \wedge (x, y) \in G') \Leftrightarrow (\exists x)(x \in A \wedge (x, y) \in G')$. By relativizing Corollary 2.2.12 to $y$, one concludes that $f(A)$ is $\Delta_1^1$.

Thus we obtain a characterization of $\Delta_1^1$-sets of reals:

# Corollary 2.2.14. A set of reals $A$ is $\Delta_1^1$ if and only if there is a $\Pi_1^0$-set $B$ and a recursive function $f : \omega^\omega \to \omega^\omega$ such that $f(B) = A$ and $f$ is one-one on $B$.

Proof. If there is a $\Pi_1^0$-set $B$ and a one-one recursive function $f : \omega^\omega \to \omega^\omega$ such that $f(B) = A$, then, by Corollary 2.2.13, one easily verifies that $A$ is $\Delta_1^1$. If $A = \omega^\omega$ is $\Delta_1^1$, then there is a recursive function $g$ such that $x \in A \Leftrightarrow g(x) \in \text{WO}_1$, and, by the discussion in §1.5.2, there is a recursive well-ordering $z$ such that $x \in A \Leftrightarrow |g(x)| \le |z|$. Define $P(x, y)$ if and only if $y$ is an isomorphism from $\le_{g(x)}$ to an initial segment of $\le_z$. Since $z$ is recursive, $P(x, y)$ is $\Pi_1^0$ and $x \in A \Leftrightarrow (\exists y)P(x, y)$. Hence there is a recursive predicate $R$ such that $P(x, y) \Leftrightarrow (\forall n)(\exists m)R(x, y, n, m)$. Uniformize $P$ by defining a $\Pi_1^0$-set $B = \{x_0 \oplus x_1 \oplus x_2 \mid (\forall n)(R(x_1, x_2, n, x_0(n)) \wedge (\forall m < x_0(n))(\neg R(x_1, x_2, n, m)))\}$. Define a recursive function $f$ such that $f(x) = x_1$ if $x = x_0 \oplus x_1 \oplus x_2$. Obviously $f$ is one-one on $B$.

In certain situations, Corollary 2.2.14 enables one to reduce a construction over a $\Delta_1^1$-set to one that is over a $\Pi_1^0$-set. Additionally, Theorem 2.2.9 provides a parametrization of $\Delta_1^1$-sets of reals.
