
Now for every \(x \in B\), if \(\Phi_e^{H_s}\) is total, then \(\Phi_e^{H_s} < f\). Thus we may construct an \(\omega\)-sequence of \(\Delta_1^1\)-sets \(\{B^{(e,n)}\}_{e<n,e \in \Omega}\) such that

- (1) if \((e, n) > (e', n')\), then \(B^{(e,n)} \subseteq B^{(e',n')}\);
- (2) \(\mu(B^{(e,n)}) > p\).

Define

\(D = \{x \mid \omega_1^x = \omega_1^{CK}\} \cap (\bigcap_{e < \omega \wedge e \in \Omega} B^{(e,n)})\).

By Theorem 13.1.4, \(D \subseteq [x \text{ is } \Delta_1^1\text{-dominated}]\) and \(\mu(D) \ge p\). \(\square\)

It is obvious that if \(x\) is \(\Delta_1^1\)-dominated, then \(\omega_1^x = \omega_1^{CK}\). The converse is however false.

**Proposition 13.3.3.** *There is an uncountable* \(\Sigma_1^1\)*-set A in which every x hyperarithmetically computes an f such that f > g for every hyperarithmetic function g.*

*Proof.* It is immediate that there is a Turing oracle function \(\Phi\) such that \(\Phi^\Omega\) dominates all the hyperarithmetic function. Let

\(A = \{x \mid \Phi^x \text{ is total } \wedge (\forall f (f \in \text{HYP} \rightarrow f < \Phi^x))\}\).

By Corollary 2.2.12, \(A\) is \(\Sigma_1^1\). Since \(\Omega \in A\), by Lemma 2.5.4, \(A\) is uncountable. \(\square\)

Hence by the Gandy Basis Theorem (2.5.3), we have the following conclusion.

**Corollary 13.3.4.** *There is an x with* \(\omega_1^x = \omega_1^{CK}\) *which is not* \(\Delta_1^1\)*-dominated.*

## 13.3.2 Traceability

**Definition 13.3.5.**

- (i) Let \(h\) be a nondecreasing unbounded and hyperarithmetic function. A \(\Pi_1^1\)-trace/\(\Delta_1^1\)-trace with bound \(h\) is a \(\Pi_1^1/\Delta_1^1\)-set \(T \subseteq \omega \times \omega\) such that \(|T_e| \le h(e)\) for each \(e\) where \(T_e = \{k \mid (e, k) \in T\}\).
- (ii) \(x\) is \(\Pi_1^1\)-traceable/\(\Delta_1^1\)-traceable if there is an \(h \in \Delta_1^1\) such that, for each \(f \le_h x\), there is a \(\Pi_1^1\)-trace/\(\Delta_1^1\)-trace \(T\) with bound \(h\) satisfying \(f(e) \in T_e\) for each \(e\).

It is not difficult to see that the bounding function \(h\) may be chosen to be any hyperarithmetic function, for example \(h(e) = e\) for every \(e\).

**Proposition 13.3.6** (Chong, Nies and Yu [12]). *If x is* \(\Pi_1^1\)*-traceable, then x is* \(\Delta_1^1\)*-traceable.*

*Proof.* Firstly we show that \(\omega_1^x = \omega_1^{CK}\). It is sufficient to show that \(\Omega\) is not \(\Pi_1^1\)-traceable. Since each \(\Pi_1^1\)-set is many-one reducible to \(\Omega\), there is a uniformly \(\emptyset\)-recursive list \((T^e)_{e \in \omega}\) of all \(\Pi_1^1\)-traces for the bound \(h(e) = e\). Define \(f \le_h \Omega\) by

\(f(e) = \mu n [n \notin T_e^e]\).

Then $f$ does not have a \(\Pi^1_1\)-trace. Now given $f \le_T x$, there is a \(\Pi^1_1\)-trace \((T_e)_{e < \omega}\) such that \(f(e) \in T_e\) for each \(e\). Then there is a recursive function \(h : \omega^2 \to \omega\) such that \(k \in T_e\) if and only if \(h(k, e) \in \Pi^1(x)\)-relation \(R \subseteq \omega \times \Omega\) by

\((e, n) \in R \Rightarrow h(f(e)) \in \Theta_n\).

Note that for each \(e\), there is a notation \(n \in \Theta\) such that \((e, n) \in R\). By the \(\Pi^1_1\)-Uniformization Theorem (4.2.1), there is a total \(\Pi^1_1(x)\) (and hence \(\Delta^1_1(x)\)) function \(g\) uniformizing \(R\). Since \(\omega_1^{CK} = \omega_1^x\), there exists a notation \(n_0 \in \Theta\) so that \(|g(e)| < |n_0|\) for every \(e\). Define a set \(\tilde{T}_e \subseteq T_e\) as follows:

\(k \in \tilde{T}_e \Rightarrow h(k, e) \in \Theta_{n_0}\).

By the definition of \(n_0\), \(f(e) \in \tilde{T}_e\) for all \(e \in \omega\). Note that the relation \(n \in \tilde{T}_e\) is \(\Delta^1_1\). Hence \((T_e)_{e < \omega}\) is a \(\Delta^1_1\)-trace for \(f\). It follows that \(f\) is \(\Delta^1_1\)-traceable.

There is also a plentiful supply of \(\Delta^1_1\)-traceable reals. In fact every Sacks generic real is \(\Delta^1_1\)-traceable.

### Proposition 13.3.7. Every Sacks generic real is \(\Delta^1_1\)-traceable.

**Proof.** Suppose $x$ in Sacks generic. Then \(\omega_1^x = \omega_1^{CK}\). If $f \le_T x$, then there is an $e$ and a notation $n \in \Theta$ such that $\Phi_e^{\tilde{H}_e} = f$. Note that the ranked formula

$(\exists z^{[n]})(H(n, z^{[n]}, y) \wedge \Phi_e^{\tilde{H}_e^{[n]}}(i) = j)$

defines the set $A = \{(y, n, i, j)|\Phi_e^{\tilde{H}_e}(i) = j\}$. For simplicity, we may view $\Phi_e^{\tilde{H}_e}$ as a ranked formula. Since $\Phi_e^{\tilde{H}_e}$ is total, by Lemma 5.3.6, there is a condition $T \Vdash \text{``}\Phi_e^{\tilde{H}_e} \text{ is total''}$. We show that for each condition $S \le T$, there is a condition $Q \le S$ such that

$Q \models (\exists f)(f \in \Delta^1_1 \wedge (\forall i)(\Phi_e^{\tilde{H}_e^{[i]}}(i) \in D_{f(i)} \wedge |D_{f(i)}| \le 2^{i+1}))$.

Then by the definition of forcing, there is a $\Delta^1_1$ function $f$ such that for all $i$, $\Phi_e^{\tilde{H}_e}(i) \in D_{f(i)} \wedge |D_{f(i)}| \le 2^{i+1}$. Since $T \Vdash \text{``}\Phi_e^{\tilde{H}_e} \text{ is total''}$, $S$ also forces the same sentence. We consider two cases.

Case 1. There is a condition $R \le S$ such that for all $i, j_0, j_1$ and for all conditions $P_0, P_1 \le R$, if $P_0 \Vdash \Phi_e^{\tilde{H}_e}(i) = j_0$ and $P_1 \Vdash \Phi_e^{\tilde{H}_e}(i) = j_1$ then $j_0 = j_1$. In this case define $f(i) = j$ if and only if there exists a condition $P \le R$ such that $P \Vdash \Phi_e^{\tilde{H}_e}(i) = j$. Then $f$ is a total \(\Pi^1_1\)-function and hence \(\Delta^1_1\). This implies that \(R \Vdash f = \Phi_e^{\tilde{H}_e}\).

Case 2. Otherwise. Define a \(\Pi^1_1\)-relation \(\mathfrak{R}(P, \sigma, i, j_0, Q_0, Q_1)\) as

\(i \ge |\sigma| \wedge \sigma_0 \neq j_1 \wedge \Lambda \cap \sigma_0 \cap Q_1 = \emptyset \wedge (\forall k \le Q_1)(\exists k \supseteq \sigma Q_k \models \Phi_e^{\tilde{H}_e^{[k]}}(i) = j_k)\).

By the \(\Pi^1_1\)-Uniformization Theorem (4.2.1), there is a \(\Pi^1_1\)-function \(F : 2^\omega \times 2^{<\omega} \to (\omega)^3 \times (2^\omega)^\omega\) such that \(\mathfrak{R}(P, \sigma, i, j_0, j_1, Q_0, Q_1)\) holds if and only if \(\mathfrak{R}(P, \sigma, F(P, \sigma))\).

Without loss of generality, we assume that if $P \Vdash \Phi_e^{G(i)} = j_i$ then for all \(k \le i\), \(P \Vdash \Phi_e^{G(i)}(k) = j_k\) for some \(j_k\). Define by induction on \(\omega\) a \(\Pi^1_1\)-sequence of conditions \(\{P_\sigma\}_{\sigma \in 2^{<\omega}}\) as follows:

- Step 0. Let \(P_\emptyset = S\).
- Step \(n + 1\). For each \(\sigma \in 2^n\), define \(P_{\sigma^\frown 0} = Q_0\), \(P_{\sigma^\frown 1} = Q_1\) if \(F(P_\sigma, \sigma) = (i, j_0, j_1, Q_0, Q_1)\).

Let \(G(\sigma) = P_\sigma\). Then \(G\) is a total \(\Pi^1_1\)-function and so \(\Delta^1_1\). Note that for each \(\sigma\), \(G(\sigma^\frown 0) \cap G(\sigma^\frown 1) = \emptyset\) and if \(\sigma \subseteq \tau\) then \(G(\sigma) \supseteq G(\tau)\). Let

\(Q = \bigcup_n \bigcap_{\sigma \in 2^{\geq n}} G(\sigma)\).

Then \(Q\) is a \(\Delta^1_1\) perfect set.

Define \(g : \bigcup_{k \in \omega} 2^{2k+1} \to \omega\) such that \(g(i, \sigma) = k\) if \(\sigma \in 2^{i+1}\) and \(G(\sigma) \Vdash \Phi_e^{G(i)} = k\). Hence \(g\) is a total \(\Pi^1_1\) and therefore \(\Delta^1_1\)-function. Define \(f(i) = j\) if \(j\) is the least number such that \(D_j = \{g(i, \sigma) \mid \sigma \in 2^{i+1}\}\). Then \(f\) is a \(\Delta^1_1\)-function and \(|D_{f(i)}| \le 2^{i+1}\) for all \(i\). Since for all \(i\), \(Q \subseteq \bigcup_{\sigma \in 2^i} G(\sigma)\), it is easy to see that \(Q \Vdash \Phi_e^{G(i)} \in D_{f(i)}\). It follows that \(x\) is \(\Delta^1_1\)-traceable.

We will see later (Theorem 14.6.8) that the collection of \(\Delta^1_1\)-traceable reals is null.

By Theorem 5.3.12, there is an uncountable \(\Sigma^1_1\)-set of weakly-Sacks-generic reals in which every real \(x\) has the property \(\omega_1^x = \omega_1^{CK}\). By the proof of Proposition 13.3.7, it is easy to derive the following conclusion.

### Corollary 13.3.38. There is an uncountable \(\Sigma^1_1\)-set of \(\Delta^1_1\)-traceable reals.

## 13.3.3 Semitraceability

### Definition 13.3.9.

- (i) \(x \in 2^\omega\) is \(\Delta^1_1\)-semitraceable if for each \(f \le_{tt} x\), there is a \(\Delta^1_1\)-function \(g\) such that, for infinitely many \(n\), \(f(n) = g(n)\). We say that \(g\) semitraces \(f\).
- (ii) \(x \in 2^\omega\) is \(\Pi^1_1\)-semitraceable if for each \(f \le_h x\), there is a partial \(\Pi^1_1\)-function \(p\) such that for infinitely many \(n\) we have \(f(n) = p(n)\).

### Lemma 13.3.10. \(x\) is \(\Pi^1_1\)-semitraceable if and only if \(x\) is \(\Delta^1_1\)-semitraceable.

**Proof.**

It is not difficult to see that if \(x\) is \(\Pi^1_1\)-semitraceable, then \(\omega_1^x = \omega_1^{CK}\). Since \(x \ge_h \emptyset\) otherwise. Hence it suffices to show that \(\emptyset\) is not \(\Pi^1_1\)-semitraceable. Let \(\{\Phi_i\}_{i \in \omega}\) be an effective enumeration of partial recursive functions. Let \(m_i^j\) be the least \(k\) such that \(p_i(j, k) \in \emptyset\) if it exists, and let it be 0 otherwise. Define a function \(g \le_T \emptyset'\) such that \(g(i) = \bigcup_{j \le i} m_i^j + 1\). Note that for any \(\Pi^1_1\)-partial function \(p\), there is a partial recursive function \(p_i\) such that for every pair \(n, m\), \(p(n) = m\) if and only if \(p_i(n, m) \in \emptyset\). Then by the definition of \(g\), for any \(i > j\), \(g(k) \neq p(i)\). Hence \(g\) is not traced by \(p\).
