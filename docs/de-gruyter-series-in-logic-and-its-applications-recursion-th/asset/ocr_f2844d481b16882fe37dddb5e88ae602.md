# 4.2.2 Kreisel compactness

Kreisel's Compactness Theorem is a generalization of the Compactness Theorem in model theory to \(L_{\omega_1\omega}\)-logic. In this setting, "recursively enumerable" is \(\Pi^1_1\), and "finite" is \(\Delta^1_1\). It is a striking application of the \(\Pi^1_1\)-Uniformization Theorem.

**Theorem 4.2.4** (Kreisel). Let \(A \subseteq \omega^2\) be a \(\Pi^1_1\)-set such that for each \(n, A_n = \{x \mid (n, x) \in A\}\) is \(\Delta^1_1\). Let \(z \in \Pi^1_1\). If \(\bigcap_{n \in \omega} A_n \neq \emptyset\) for every hyperarithmetic \(y \subseteq z\), then \(\bigcap_{n \in \omega} A_n \neq \emptyset\).

Proof. Suppose not. Then \(z\) is properly \(\Pi^1_1\) and \(\bigcap_{n \in \omega} A_n = \emptyset\). Then for each \(x\), there is an \(n\) such that \(x \notin A_n\). Define a \(\Pi^1_1\)-relation \(R \subseteq 2^{<\omega} \times \omega\) such that \(R(x, n) \Leftrightarrow n \in 2^\omega \times A_n\). By the Uniformization Theorem (4.2.1), there is a total \(\Pi^1_1\)-function \(f\) uniformizing \(R\). Then the set \(y = \{n \mid (\exists x)(f(x) = n)\}\) is contained in \(z\) and is \(\Sigma^1_1\). If \(x \in \bigcap_{n \in \omega} A_n\), then \(f(x) \in \omega \setminus y\). But no \(m \in \omega \setminus y\) belongs to \(f[2^\omega]\). Thus \(\bigcap_{n \in \omega} A_n = \emptyset\). By Corollary 4.2.3 restricted to \(\omega\), there is a \(\Delta^1_1\)-real \(y_0\) with \(y \subseteq y_0 \subseteq z\). Then \(\bigcap_{n \in \omega} A_n = \emptyset\), which is a contradiction.

Theorem 4.2.4 was further generalized by Barwise [3] to countable admissible sets as a compactness theorem for infinitary logic.

# 4.2.3 \(\Pi^1_1\)-singletons

**Proposition 4.2.5.** Every nonempty \(\Pi^1_1\)-set of reals contains a \(\Pi^1_1\)-singleton.

Proof. Suppose that \(A \subseteq 2^\omega\) is \(\Pi^1_1\) and nonempty. Let \((n, x) \in R\) if and only if \(x \in A\). Then \(R\) is a \(\Pi^1_1\)-relation. By Theorem 4.2.1, there is a \(\Pi^1_1\)-relation \(R_0\) uniformizing \(R\). Then the unique real \(x\) such that \((0, x) \in R_0\) is a \(\Pi^1_1\)-singleton.

By Proposition 4.2.5, we know that every nonempty \(\Pi^1_1\)-set contains a \(\Pi^1_1\)-singleton.

**Proposition 4.2.6.** The set \(\{x \mid x \text{ is a } \Pi^1_1\text{-singleton}\}\) is \(\Pi^1_1\).

Proof. Let \(P \subseteq \omega \times 2^\omega\) be a universal \(\Pi^1_1\)-set. By Proposition 4.2.5, there is \(\Pi^1_1\)-set \(P_0 \subseteq P\) uniformizing \(P\). Let \(A = \{x \mid (\exists n)(n, x) \in P_0\}\). Then \(A\) is a \(\Pi^1_1\) set which contains precisely all the \(\Pi^1_1\)-singletons.

Since there are only countably many \(\Pi^1_1\)-singletons, there is a countable \(\Pi^1_1\)-set which is a basis for \(\Pi^1_1\)-sets of reals. This gives the following basis result for \(\Sigma^1_2\)-sets.

**Corollary 4.2.7.** Every nonempty \(\Sigma^1_2\)-set of reals contains a \(\Delta^1_2\)-member.

Proof. Suppose \(A\) is a nonempty \(\Sigma^1_2\)-set of reals. Then \(x \in A\) if and only if \((\exists y)B(x, y)\) for some \(\Pi^1_1\)-relation \(B\). By Proposition 4.2.5, there is a \(\Pi^1_1\)-singleton, and hence a \(\Delta^1_2\)-real, \((x_0, y_0)\) such that \(B(x_0, y_0)\). Then \(x_0 \in A\) is \(\Delta^1_2\).
