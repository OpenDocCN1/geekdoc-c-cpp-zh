
Since \(\omega_1^{CK} \le M_1\), we have \(\pi(\beta) = \beta\) for any \(\beta < \omega_1^{CK}\). Thus \(\pi(x) = x\) for \(x \in J_1\). Since \((N, \in) \models \phi(1, x)\) if and only if \(x = f_1\), we have \((M_1, E) \models \phi(1, x)\) if and only if \(x = f_1\). So \(\pi^{-1}(J_1) = J_1\).

For a successor ordinal \(\beta + 1\), \(\pi\) clearly preserves the Gödel primitive recursive operators. Hence \(\text{Rang}(\pi^{-1} J_{\beta+1}) = J_{\beta+1}\). Since \((N, \in) \models \phi(\beta + 1, x)\) if and only if \(x = J_{\beta+1}\), we have \((M_1, E) \models \phi(\beta + 1, x)\) if and only if \(x = J_{\beta+1}\). So \(\pi^{-1}(J_{\beta+1}) = J_{\beta+1}\).

Now suppose \(\beta < \omega_1^{CK}\) is a limit ordinal. By induction, if \(\gamma < \beta\) then \((M_1, E) \models \phi(\gamma, x)\) if and only if \(x = J_\gamma\). Let \(z = \pi^{-1}(J_\beta)\). Since \(\pi^{-1}(\beta) = \beta\), we have

\((M_1, E) \models \phi(\beta, z) \wedge (\forall x Ez)(\exists y Ey)(\exists y Xy) \wedge \phi(\gamma, y).\)

Thus \(z = J_\beta\). By the transitivity of \(J_{\omega_1^{CK}}\), we conclude that \(\pi^{-1} \restriction L_{\omega_1^{CK}}\) is the identity map so that \(L_{\omega_1^{CK}} \in M\).

## 3.6 Coding structures

### 3.6.1 Coding a language

Given a countable language \(\mathscr{L}\), there are many ways of coding it by a set of numbers. What we want is a "nice" coding scheme. In many cases, one may code a language \(\mathscr{L}\) by a recursive set \(\mathscr{L}' \subseteq \omega\). A language that may be thus coded is called a recursive language. For example, both the first order language of arithmetic and the language of Zermelo–Fraenkel set theory are recursive. Moreover, in a recursive language, the set of well-formed formulas and the set of sentences are recursive. We may effectively associate each formula \(\varphi\) with its Gödel number \(\ulcorner \varphi \urcorner\). We say that a theory \(T\) is recursive if its corresponding set of Gödel numbers \(T' = \{ \ulcorner \varphi \urcorner | \varphi \in T \}\) is recursive. The theories considered in this book, such as KP, ZFC, are recursive. Under coding with Gödel numbers, a proof sequence is identified with a finite sequence of numbers, and may therefore be considered as a finite subset of \(\omega\). Moreover, if both \(\mathscr{L}\) and \(T\) are recursive, then so is the set of proofs in \(T\). It follows that the set of sentences which are theorems of \(T\) is r.e.

### 3.6.2 Coding a structure

Given a recursive language \(\mathscr{L}\), one may associate with it a recursive set \(\dot{\mathscr{L}}\) and code a countable structure in \(\mathscr{L}\) by the set of natural numbers \(\omega\) with relations in \(\dot{\mathscr{L}}\) defined over \(\omega\), so that the resulting structure is isomorphic to the original structure. If \(\mathfrak{M} = (M, R_0, \dots, R_n)\) is countable, a coding \(\ulcorner M \urcorner = (\omega, \dot{R}_0, \dots, \dot{R}_n)\) of \(\mathfrak{M}\) is a structure such that \(\mathfrak{M} \cong \dot{\mathfrak{M}}\). If all the relations \(R_0, \dots, R_n\) are recursive, then the structure \(\ulcorner M \urcorner\) is said to be recursive. However, very few structures are recursive.

Let \(\mathscr{L}\) be a recursive language and \(\mathfrak{M}\) a structure coded by \(\ulcorner \mathfrak{M} \urcorner\). For a formula \(\dot{\varphi}(u)\) in \(\dot{\mathscr{L}}\) corresponding to the formula \(\varphi(u)\) in \(\mathscr{L}\), we may compute the complexity of the set of the set \(A = \{m \in \omega \mid \ulcorner m \urcorner \vDash \dot{\varphi}(m)\}\). The procedure to calculate the complexity goes as follows: Recursively decode \(\dot{\varphi}(u)\) to obtain the formula \(\varphi(u)\). Then the complexity of \(A\) is the complexity of \(\varphi(u)\). For example, suppose \(\mathscr{L}\) is the language of set theory and \(\dot{\varphi}(u)\) corresponds to the formula \(\varphi(w): (\forall u)(\forall v)(u \in v \land v \in w \rightarrow u \in w)\) ("$w$ is transitive"). Then the set

\(\{m \mid (\omega, \dot{\in}) \vDash (\forall i)(\forall j)(i \dot{\in} j \land j \dot{\in} m \rightarrow i \dot{\in} m)\}\)

is \(\Pi_1(\dot{\in})\).

In general, given a language \(\mathscr{L}\) with relation symbols \(R_0, \dots, R_n\), a structure and a formula \(\varphi \in \mathscr{L}\), the set \(\{m \in \omega \mid \ulcorner M \urcorner \vDash \varphi(m)\}\) is arithmetical in \(\dot{R}_0 \oplus \cdots \oplus \dot{R}_n\). Moreover, this coding is uniform. Hence if \(\{\varphi_i\}_{i < \omega}\) is recursive, then the set \(\{(i, m) \mid \ulcorner M \urcorner \vDash \dot{\varphi}_i(m)\}\) is Turing computable in \((\dot{R}_0 \oplus \cdots \oplus \dot{R}_n)^{(\omega)}\) via an algorithm with index \(e\). In particular, there is an \(e\) such that if \(\{\varphi_i\}_{i < \omega}\) is a recursive set of sentences, then \(\ulcorner M \urcorner \vDash \dot{\varphi}_i\) if and only if \(\dot{\varphi}_e^{(R_0 \oplus \cdots \oplus R_n)^{(i)}}(i) = 1\). As a consequence, we have the following:

### **Proposition 3.6.1.**

Given a recursive theory \(T\), the set \(\{\ulcorner M \urcorner \mid \forall \varphi(\varphi \in T \rightarrow \ulcorner M \urcorner \vDash \varphi)\}\) is \(\Delta_1^1\).

For example, \(\{\ulcorner M \urcorner \mid \ulcorner M \urcorner \vDash \text{KP} + \text{"V = L"}\}\) is \(\Delta_1^1\) (where for simplicity we make no distinction between KP+V = L" and the corresponding sentences interpreted in \(\ulcorner M \urcorner\)).

### 3.6.3 Coding \(\omega\)- and wellfounded models

We now work in the language of set theory and use "\(E\)" in place of the symbol \(\dot{\in}\). The best models of set theory are of course those that are wellfounded.

### **Proposition 3.6.2.**

\(\langle E \mid (\omega, E) \text{ codes a wellfounded model} \rangle\) is \(\Pi_1^1\).

Proof. \((\omega, E)\) codes a wellfounded model if and only if there is no function \(f : \omega \to \omega\) such that for any pair \((i, j)\), \(i < j\) if and only if \((\omega, E) \models f(j)Ef(i)\).\(\square\)

Coding wellfounded models is a complicated matter, though such models are the 'bona fide models' of set theory. The next best thing is to code \(\omega\)-models. The reason for studying \(\omega\)-models is that in considering reals or sets of reals in such models, one is assured that the 'natural numbers' involved are standard numbers.

### **Proposition 3.6.3.**

\(\{E \mid (\omega, E) \text{ codes an } \omega\text{-model}\}\) is \(\Delta^1_1\).

Proof. \((\omega, E)\) codes an \(\omega\)-model if and only if there is an \(m \in \omega\) and an injection \(f : \omega \to \omega\) such that

- (i) \((\omega, E) \models \text{‘}m \text{ is an infinite ordinal’}\);
- (ii) \(f\) is a bijection between \(\omega\) and \([k \mid kEm]\), and
- (iii) for any pair \((i, j)\), \(i < j\) if and only if \((\omega, E) \models f(i)Ef(j) \land f(j)Em\).

Hence the set \(\{E \mid (\omega, E) \text{ is an } \omega\text{-model}\}\) is \(\Sigma^1_1\).

On the other hand, \((\omega, E)\) codes an \(\omega\)-model if and only if there is an \(m \in \omega\) such that

- (iv) \((\omega, E) \models \text{‘}m \text{ is an infinite ordinal’}\);
- (v) for every injection \(f\) from \(\omega\) into \([k \mid kEm]\), there is a pair \((i, j)\) such that \(i < j\) and \((\omega, E) \models f(i)Ef(j)\), and
- (vi) for every order-preserving function \(f\) from \(\omega\) into \([k \mid kEm]\) and for any \(k\) with \((\omega, E) \models kEm\), there is a \(j\) such that \((\omega, E) \models kEf(j)\).

Thus \(\{E \mid (\omega, E) \text{ is an } \omega\text{-model}\}\) is also \(\Pi^1_1\) and hence \(\Delta^1_1\).\(\square\)

### **Proposition 3.6.4.**

- (i) The set \(\langle \omega, \omega_E, \emptyset \rangle = \langle \langle n, n_E \rangle \mid n_E \text{ codes } n \text{ in } \ulcorner \mathcal{M} \urcorner \rangle\) is arithmetical;
- (ii) Suppose that \(\ulcorner \mathcal{M} \urcorner = \langle \omega, E \rangle\) codes an \(\omega\)-model M. Then for any real \(x \in \mathcal{M}\), \(x\) is arithmetical in E;
- (iii) If \(m\) codes \(w\) in \(\ulcorner \mathcal{M} \urcorner\) and \(f : \omega \to [k \mid k \in \ulcorner \mathcal{M} \urcorner]\) is an order-preserving bijection, then every real \(x \in \mathcal{M}\) is recursive in \(f \oplus E\).

Proof. (i) \(\langle n, m, E \rangle \in \langle \omega, \omega_E, \emptyset \rangle\) if and only if there is a finite sequence \(\langle k_j \rangle_{j \in \mathbb{Z}^n}\) such that

- \(k_n = m \cap \ulcorner \mathcal{M} \urcorner\);
- for any \(j < n\), \(\ulcorner \mathcal{M} \urcorner \models k_j E k_{j+1} \land (\forall k) (k E k_{j+1} \to k E k_j \lor k = k_j)\), and
- for all \(j < n\), \(\ulcorner \mathcal{M} \urcorner \models k E k_j\).

Hence \((\omega, \omega_E, E)\) is arithmetical.

(ii) Given \(x \in \mathcal{M}\), let code \(x\) in \(\ulcorner \mathcal{M} \urcorner\). Then for any \(n\), \(n \in x\) if and only if \((n, n_E) \in \langle \omega, \omega_E, \emptyset \rangle\) and \(\ulcorner \mathcal{M} \urcorner \models n_E E m\). Thus \(x\) is arithmetical in E.

(iii) For \(x \in \mathcal{M}\), let \(n\) code \(x\) in \(\ulcorner \mathcal{M} \urcorner\). Then for any \(i\), \(i \in x\) if and only if \(\ulcorner \mathcal{M} \urcorner \models f(i) E n\), so that \(x \le_T E \oplus f\).
