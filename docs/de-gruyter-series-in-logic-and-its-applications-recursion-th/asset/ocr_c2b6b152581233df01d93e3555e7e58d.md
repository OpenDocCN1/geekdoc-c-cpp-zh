Proof. Let g be P-generic. It is sufficient to prove that $\mathfrak{A}(\omega_1^{CK}, g) = \Delta^1_1$-comprehension. Let P be a condition such that $g \in P$. If $P \cap G_i = \emptyset$, then $P \cap A_i = \emptyset$. It follows that there is a k such that $\mathfrak{M}(\omega_1^{CK}, g) = (\forall y)(\neg \varphi_i(k, y) \land \varphi_i(k, y))$. Otherwise $P \subseteq G_i$. By topological compactness, for any j and l there is an n such that $P \subseteq U_{i,j,l,n}$. It follows that there is a total $I_1^1$ - hence $\Delta^1_1$ - function $f : \omega^2 \to \omega$ such that for any i, j, l, $f(i, l) \in \emptyset$ and $P \subseteq U_{i,l,f(i,l)}$. Hence there is an $m \in \emptyset$ such that $f([f_i, l)) < |m|$ for any j, l. Then $C_i = \bigcup_{l < \omega} \bigcap_{n < \omega} (U_{i,l,f(i,l),n} \setminus A_{i,f(i,l),n})$ is a $\Delta^1_1$-nullset. Since g is $\Pi^1_1$-ML-random, $g \in C_i$. Then for any j, there is an l such that $g \in A_{i,l,f(i,l),n}$. Thus $\mathfrak{A}(\omega_1^{CK}, g) \models (\forall k)(\exists^{III}(m))(\varphi_i(k, y^{III}) \lor \neg \varphi_i(k, y^{III}))$ and so $\mathfrak{A}(\omega_1^{CK}, g) \models \Delta^1_1$-comprehension.

# Theorem 14.6.15 (Greenberg and Monin). Every low for $\Pi^1_1$-random real is hyperarithmetic.

Proof. Suppose that x is not hyperarithmetic. By Theorem 14.6.9, x is not low for $\Pi^1_1$-ML randomness. Let $\{U_n\}_{n<\omega}$ be a universal $I_1^1(x)$-ML test. We claim that for any n and $P \in \mathbf{P}$, $U_n^P \cap P \neq \emptyset$. Otherwise, $P \cap U_n^P = \emptyset$ for some n. Then every real $z \in P$ is $I_1^1(x)$-ML random. However, for any $\Pi^1_1$-ML random y, by Proposition 14.2.7, there is a $z \in P$ such that $y =^* z$. Hence y is also $I_1^1(x)$-ML random. In other words, x is low for $I_1^1$-ML random, a contradiction.

Since P contains only $I_1^1$-ML random reals, $P \cap U_n^P \neq \emptyset$ implies that there is a condition $Q \subseteq P \cap U_n^P$.

Let $\mathscr{D}^n = \{P \in \mathbf{P} \mid P \subseteq U_n^P\}$. Then $\mathscr{D}^n$ is dense for each n. If g is P-generic meeting each $\mathscr{D}_i$ and $\mathscr{D}^n$, then g is $I_1^1$-random and $g \in \bigcap_{n<\omega} U_n^P$. In other words, g is not $I_1^1(x)$-ML random and hence not $I_1^1(x)$-random.

By the proof of Theorem 14.6.15, for any x if every $\Pi^1_1$-random real is $I_1^1(x)$-ML random, then x must be hyperarithmetic.

# Corollary 14.6.16. A real x is low for strongly $\Pi^1_1$-ML random if and only if it is hyperarithmetic.

Proof. Obviously every hyperarithmetic real is low for strongly $\Pi^1_1$-ML random. Now suppose that x is low for strongly $\Pi^1_1$-ML random. Then every $\Pi^1_1$-random real is strongly $I_1^1(x)$-ML random and so $I_1^1(x)$-ML random. So x must be hyperarithmetic.
