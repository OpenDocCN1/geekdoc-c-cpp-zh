
## 5 Recursion-theoretic forcing

Although historically Cohen introduced forcing for set-theoretic considerations, the method was adapted to study problems in recursion theory soon after by Feferman [25] (indeed, one detects a hint of Cohen forcing in the theorems of Post and Kleene on the structure of the Turing degrees proved in the 1950s). Here we study three classic examples of forcing (due to Cohen, Sacks and Steel respectively) and their applications in recursion theory. It turns out that the ramified analytical hierarchy provides an ideal platform for this purpose.

### 5.1 Ramified analytical hierarchy

#### 5.1.1 The structure $\mathfrak{A}(\omega_1^{CK}, x)$

The ramified analytical hierarchy was introduced by Kleene [72] and forcing constructions over it goes back to Cohen [18] and continued in Feferman [25]. It may be viewed as an analog of the constructible hierarchy defined in the language of second order arithmetic, for the study of hyperarithmetic theory.

- The language for the hierarchy, denoted $\mathscr{L}(\omega_1^{CK}, x)$, consists of the following:
  - number variables: $i, j, k, m, n, \dots$
  - numerals: $0, 1, 2, \dots$
  - set constants: $\dot{x}, \dot{y}, \dots$
  - ranked set variables: $x^\beta, y^\beta, \dots$ for $\beta < \omega_1^{CK}$
  - unranked set variables: $x, y, \dots$
  - function and relation symbols: $+, \dots$ (times), $'$ (successor) and $\epsilon$.

Formulas in this language are defined by induction in the usual way. As one might expect, the presence of ranked set variables implies that there is no recursive coding of $\mathscr{L}(\omega_1^{CK}, x)$. Instead, coding is carried out in the countable admissible set $L_{\omega_1^{CK}}$. First choose a $\Pi^1_1$-path $\mathsf{O}_1$ through $\mathsf{O}$ which exists according to Theorem 2.6.4. Code the ranked set variable $x^\beta$ by the number $(2, n)$ where $n \in \mathsf{O}_1$ and $|n| = \beta$. Other symbols are coded recursively. With this, formulas are coded in $L_{\omega_1^{CK}}$. A formula is *ranked* if all of its set variables are ranked. A ranked formula $\varphi$ has rank at most $\beta$ if

- for any $\gamma_i$ if $x^i$ is a free variable occurring in $\varphi$, then $\gamma \le \beta$;
- for any $\gamma_i$ if $x^i$ is a bounded variable occurring in $\varphi$, then $\gamma < \beta$.

Note that

- the set of Gödel numbers of formulas is $\Pi^1_1$;
- the set of Gödel numbers of ranked formulas of rank at most $\beta$ is r.e. uniformly in the unique notation for $\beta$ in $\mathsf{O}_1$.

By Theorem 1.3.4, there is a recursive function $h$ such that for $n \in O_1$, $W_{h(n)}$ is the set of Gödel numbers of ranked formulas of rank at most $|n|$.

We now define the structure $\mathcal{A}(\omega_1^{CK}, x) = \bigcup_{\beta < \omega_1^{CK}} \mathcal{A}(\beta, x)$, where $x$ is a real that interprets $x$. $\mathcal{A}(\omega_1^{CK}, x)$ is a collection of reals defined in an analogous way as Gödel's $L$. The construction is completed in $\omega_1^{CK}$-many stages. Any ranked set variable $x^\rho$ is to be interpreted by a real in $\bigcup_{y < \beta} \mathcal{A}(y, x)$. With this as our convention, the satisfaction relation $\bigcup_{y < \beta} \mathcal{A}(y, x) \models \varphi$ is well defined for a ranked formula $\varphi$ of rank at most $\beta$. We define $\mathcal{A}(\omega_1^{CK}, x)$ by induction on the recursive ordinals, as follows:

$\mathcal{A}(0, x) = \{x\} \cup \omega$.

Suppose $\beta > 0$ and $\mathcal{A}(y, x)$ is defined for all $y < \beta$. Given a ranked formula $\varphi(n)$ with rank at most $\beta$ and whose only free variable is $n$, let

$i \in Z_\varphi \Leftrightarrow \bigcup_{y < \beta} \mathcal{A}(y, x) \models \varphi(i)$.

Let $B$ be the collection of reals $z_\varphi$ for such $\varphi$'s. Set

$\mathcal{A}(\beta, x) = \bigcup_{y < \beta} \mathcal{A}(y, x) \cup B$.

Thus the reals constructed at stage $\beta$ are precisely those arithmetically defined by the reals constructed at earlier stages.

For a formula $\varphi$, the satisfaction relation $\mathcal{A}(\omega_1^{CK}, x) \models \varphi$ is defined by induction:

- if $\varphi$ is ranked with rank at most $\beta$, then $\mathcal{A}(\omega_1^{CK}, x) \models \varphi$ if and only if $\bigcup_{y < \beta} \mathcal{A}(y, x) \models \varphi$;
- if $\varphi$ is $(\exists z)\varphi(z)$, then $\mathcal{A}(\omega_1^{CK}, x) \models \varphi$ if and only if there is a $\beta < \omega_1^{CK}$ and a $z^\beta$ such that $z^\beta \in \mathcal{A}(\omega_1^{CK}, x)$ and $\mathcal{A}(\omega_1^{CK}, x) \models \varphi(z^\beta)$;
- if $\varphi$ is $\neg \psi$, then $\mathcal{A}(\omega_1^{CK}, x) \models \varphi$ if and only if $\mathcal{A}(\omega_1^{CK}, x) \not\models \psi$.

A sentence $\varphi$ in $\mathcal{L}(\omega_1^{CK}, x)$ is $\Sigma_1^1$ if it is ranked, or of the form $(\exists x_1)\cdots(\exists x_n)\psi$ for some formula $\psi$ with no unranked set variables bounded by a quantifier. It is not difficult to see that the set of Gödel numbers of $\Sigma_1^1$-sentences is $\Pi_1^1$. Let “$\varphi$” be the code of the formula $\varphi$.

**Theorem 5.1.1.** The set $\{(x, \text{“}\varphi\text{”}) \mid \varphi \text{ is } \Sigma_1^1 \land \mathcal{A}(\omega_1^{CK}, x) \models \varphi\}$ is $\Pi_1^1$.

*Proof.* By $\Sigma$-induction (Theorem 3.1.8) and the definition of $\mathcal{A}(\omega_1^{CK}, x)$, there is a $\Sigma_1$-formula $\psi(u)$ such that $(L_\omega[x], x) \models \psi(u^{\text{“}\varphi\text{”}})$ if and only if $\varphi$ is ranked $\land \mathcal{A}(\omega_1^{CK}, x) \models \varphi$. Hence by the Spector-Gandy Theorem (3.2.2), the set $\{(x, \text{“}\varphi\text{”}) \mid \varphi \text{ is ranked} \land \mathcal{A}(\omega_1^{CK}, x) \models \varphi\}$ is $\Pi_1^1$. Now if $\varphi$ is of the form $(\exists z)\varphi(z)$, then $\mathcal{A}(\omega_1^{CK}, x) \models (\exists z)\varphi(z)$ if and only if there is an $n \in O_1$ such that $\mathcal{A}(\omega_1^{CK}, x) \models (\exists z|n)\varphi(z^{\omega[n]})$. It follows that the set $\{(x, \text{“}\varphi\text{”}) \mid \varphi \text{ is } \Sigma_1^1 \land \mathcal{A}(\omega_1^{CK}, x) \models \varphi\}$ is $\Pi_1^1$.

**Corollary 5.1.2.** For $\beta < \omega_1^{CK}$, the set $\{(x, \text{“}\varphi\text{”}) \mid \text{rank}(\varphi) \text{ is at most } \beta \land \mathcal{A}(\omega_1^{CK}, x) \models \varphi\}$ is $\Delta_1^1$.

*Proof.* Note that the set $\{\ulcorner \varphi \urcorner \mid \text{rank}(\varphi) \text{ is at most } \beta\}$ is r.e. and hence $\Delta_1^1$. By Theorem 5.1.1, both the sets $\{(x, \ulcorner \varphi \urcorner) \mid \text{rank}(\varphi) \text{ is at most } \beta \land \mathfrak{A}(\omega_1^{CK}, \mathbf{x}) \models \varphi\}$ and $\{(x, \ulcorner \varphi \urcorner) \mid \text{rank}(\varphi) \text{ is at most } \beta \land \mathfrak{A}(\omega_1^{CK}, \mathbf{x}) \models \neg \varphi\}$ are $\Pi_1^1$ and hence $\Delta_1^1$.

#### 5.1.2 Characterizing $\mathfrak{A}(\omega_1^{CK}, \mathbf{x})$

**Proposition 5.1.3.** For any real $z, z \in \mathfrak{A}(\omega_1^{CK}, \mathbf{x})$ if and only if there is an $m \in \mathbb{O}$ such that $z \le_T H_m^x$.

*Proof.* Suppose that $z \in \mathfrak{A}(\omega_1^{CK}, \mathbf{x})$. Then there is a ranked formula $\varphi(n)$ such that \( n \in z \Leftrightarrow \mathfrak{A}(\omega_1^{CK}, \mathbf{x}) \models \varphi(n) \).

By Corollary 5.1.2, the set \( C = \{\langle x, n \rangle \mid \mathfrak{A}(\omega_1^{CK}, \mathbf{x}) \models \varphi(n)\} \) is $\Delta_1^1$. By the $\Pi_1^1$-Uniformization Theorem (4.2.1), there is a total $\Pi_1^1$ and hence $\Delta_1^1$ function \( f : 2^\omega \to \omega \) such that \( f(x) = m \) if and only if \( m \in O^x \) and \( (\exists \beta)(\forall n)(n, x \in C \leftrightarrow \mathfrak{A}_m^{f(x)}(n) = 1) \). By relativized $\Sigma_1^1$-boundedness (Corollary 1.5.2), there is an ordinal \( \beta < \omega_1^{CK} \) such that \( f(x)|_x \le \beta \) for all \( x \). Thus if \( z \in \mathfrak{A}(\omega_1^{CK}, \mathbf{x}) \), then there is an \( m \in \mathbb{O} \) such that \( z \le_T H_m^x \).

For the other direction, suppose there is an \( m \in \mathbb{O} \) such that $z \le_T H_m^x$. It suffices to prove that \( H_m^x \in \mathfrak{A}(m|1+2, \mathbf{x}) \). We show this by induction on \( |m| \).

Suppose that \( m = 2^n \). Then \( H_m \in \mathfrak{A}(m|1+x) \). So \( H_m^x \in \mathfrak{A}(m|1+2, \mathbf{x}) \).

Suppose that \( m = 3 \cdot 5^n \) and \( H_n^x \in \mathfrak{A}(\omega_1^{CK}, \mathbf{x}) \) for all \( n < m \). Then \( i \in H_m^x \) if and only if

\(\mathfrak{A}(m|1+x) \equiv (\exists m'(\exists \beta)[\exists \beta](\hat{H}(f_C(\mathbf{l}), z^{m'|\mathbf{l}}, \mathbf{x}) \wedge \mathbf{l} = \langle j, l \rangle \wedge j \ge z^{m'}])\).

Thus \( H_m^x \in \mathfrak{A}(m|1+2, \mathbf{x}) \).

Theorem 2.3.3 and Proposition 5.1.3 immediately give the following

**Corollary 5.1.4.** Suppose that \( \omega_1^x = \omega_1^{CK} \). Then for any \( z, z \in \mathfrak{A}(\omega_1^{CK}, \mathbf{x}) \) if and only if \( z \le_h x \). In particular, \( z \) is hyperarithmetic if and only if $z \in \mathfrak{A}(\omega_1^{CK}, \emptyset)$.

#### 5.1.3 $\Delta_1^1$-comprehension

The $\Delta_1^1$-comprehension scheme states:

\( (\forall n)((\exists z)\varphi(n, z) \to (\forall z)\psi(n, z)) \to (\exists y)(\forall n)(n \in y \leftrightarrow (\exists z)\varphi(n, z)) \).

where both \(\varphi(n, z)\) and \(\psi(n, z)\) are arithmetical. In forcing constructions, satisfying $\Delta_1^1$-comprehension in $\mathfrak{A}(\omega_1^{CK}, \mathbf{x})$ is used to guarantee \(\omega_1^x = \omega_1^{CK}\), as shown by the following theorem.

**Theorem 5.1.5.** \(\omega_1^x = \omega_1^{CK}\) if and only if $\mathfrak{A}(\omega_1^{CK}, \mathbf{x})$ satisfies the $\Delta_1^1$-comprehension axiom.
