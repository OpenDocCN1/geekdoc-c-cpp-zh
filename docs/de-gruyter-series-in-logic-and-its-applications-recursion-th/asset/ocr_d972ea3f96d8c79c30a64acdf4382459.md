Since \( x \) is \( \Delta^1_1 \)-dominated, there is a hyperarithmetic function \( f : \omega \to \omega \) such that for any \( e \) and \( n \in \omega \) with \( |n| < \gamma \) such that \( \Phi_e^{H_e} \) computes a tree \( T_{e,n} \), if \( x \notin [T_{e,n}] \) then \( x \notin f(n,e)) \notin T_{e,n} \).

Now recursively in \( x \oplus 0^{(\beta)} \oplus f \), search for a formula \( \psi_0 \) with rank less than \( \gamma \) such that \( S_0 = \{z \mid \mathfrak{A}(\omega^{CK}, z) = \psi_0\} \) contains \( x \), and is a closed subset of either \( \{z \mid \mathfrak{A}(\omega^{CK}, z) = \varphi(z, 0)\} \) or \( \{z \mid \mathfrak{A}(\omega^{CK}, z) = \neg \varphi(z, 0)\} \).

Since \( x \) is \( \Pi^1_1 \)-random, by (ii) there is such a \( \psi_0 \). Note that one needs \( x \oplus 0^{(\beta)} \oplus f \) to decide if \( x \in S_0 \). Inductively, for each \( n \), search recursively in \( x \oplus 0^{(\beta)} \oplus f \) for a formula \( \psi_{n+1} \) with rank less than \( \gamma \) such that \( S_{n+1} = \{z \mid \mathfrak{A}(\omega^{CK}, z) = \psi_{n+1}\} \) contains \( x \), has positive measure, and is a closed subset of either \( S_n \cap \{z \mid \mathfrak{A}(\omega^{CK}, z) = \varphi(z, n+1)\} \) or \( S_n \cap \{z \mid \mathfrak{A}(\omega^{CK}, z) = \neg \varphi(z, n+1)\} \).

Since \( x \) is \( \Pi^1_1 \)-random, by (ii), such a \( \psi_{n+1} \) exists. This implies that \( y \not\le_T x \oplus 0^{(\beta)} \oplus f \).

Since \( f \) is hyperarithmetic, there is a \( \gamma_0 < \omega_1^{CK} \) such that \( f \le_T 0^{(\gamma_0)} \). Without loss of generality, assume \( \gamma_0 \le \gamma \) (replacing \( \gamma \) with \( \gamma_0 + \gamma \) if necessary). Then \( y \not\le_T x \oplus 0^{(\gamma)} \). \(\square\)

# **Corollary 14.3.7.** If \( x \) is \( \Pi^1_1 \)-random and \( y \le_h x \), then there is a recursive ordinal \( \beta \), a function \( f \le_T 0^{(\beta)} \) and a recursive functional \( \Psi \) such that for every \( n, y(n) = \Psi^{x \oplus 0^{(\beta)}(n)}(n)[f(n)] \).

**Proof.** Suppose that \( x \) is \( \Pi^1_1 \)-random and \( y \le_h x \). By Lemma 14.3.6, there is a recursive ordinal \( \gamma \) and a recursive function \( \Phi \) such that for every \( n, y(n) = \Phi^{x \oplus 0^{(\gamma)}(n)}(n)[g(n)] \). Since \( x \) is \( \Pi^1_1 \)-dominated, \( g \le_h x \) be a function such that for every \( n, y(n) = \Phi^{x \oplus 0^{(\beta)}(n)}(n)[g(n)] \). Since \( x \) is \( \Pi^1_1 \)-dominated, there is a hyperarithmetic function \( h \) so that for all \( n, h(n) > g(n) \).

Hence there is a sufficiently large recursive ordinal \( \beta \) such that both \( x \) and \( h \) are many-one reducible to \( 0^{(\beta)} \). It is not difficult to define a function \( f \le_T 0^{(\beta)} \) and a recursive function \( \Psi \) so that for every \( n, y(n) = \Psi^{x \oplus 0^{(\beta)}(n)}(n)[f(n)] \). \(\square\)

\( y(n) = \Psi^{f(n)[x \oplus 0^{(\beta)}(n)]}(n)[f(n)] \).
