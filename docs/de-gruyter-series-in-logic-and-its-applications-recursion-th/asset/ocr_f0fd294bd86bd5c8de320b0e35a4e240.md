# 1.2.2 Relativized O

As in § 1.2.1, one may relativize the notion of ordinal notations to any real x ∈ ω^ω. Let {Φ_e(x, n)}_{e<ω} be an effective enumeration of partial recursive functions with oracle x (cf. § 1.1.1). Define an arithmetical set P ⊆ ω^ω × 2^ω such that (x, y) ∈ P if and only if y satisfies the following conditions:

+   (i) (1, 2) ∈ y;
+   (ii) {∀m(∀n(m, n) ∈ y → (n, 2^n) ∈ y};
+   (iii) {∀e(⟨Φ_e(x, ·)⟩ is total ∧ (∀n)(Φ_e(x, n), Φ_e(x, n + 1)) ∈ y) → (∀n)(⟨Φ_e(x, n), 3 · 5^e⟩) ∈ y}, and
+   (iv) (∀n)(∀m)(∀k)(n, m) ∈ y ∧ (n, k) ∈ y → (n, k) ∈ y).

# Definition 1.2.4. <_O^P = ⋂_{(x,y)∈P} y. O^P = {n | (∃m)(n <_O^P m)}.

One may also let relativized α^P = ⋃_β α_β^P. Then α^X <_O^P and the function |·|_x : O^x ↦ ω_1 is a well-defined rank function so that [1]_x=0 and [n]_x is the least ordinal β for which there is a number m with (m, n) ∈ α_β^P.

Note that there is a subtle difference between O and O^P: An enumeration of oracle functionals is used to define O^P. Hence the set of indices used in the definition of O^P may be different from that of O, resulting in possibly different notations at limit stage. However, such a difference does not affect the overall properties of O. Indeed, one may redefine O as O^P if desired.

By the relativized version of Proposition 1.1.15, both <_O^P and O^P are Π_1^1(x). The following proposition is immediate.

# Proposition 2.5.

+   (i) The sets {(n, x) | n ∈ O^x} and {((m, n), x) | m <_O^x n} are Π_1^1.
+   (ii) The sets {(x, y) | y = <_O^x} and {(x, y) | y = O^x} are Π_1^1.

Proof. Let P be the set of reals defined before Definition 1.2.4. For (i), n ∈ O^x if and only if (∃m)(m, n) ∈ <_O^P if and only if (∃m)(∀y)((x, y) ∈ P → (n, m) ∈ y).

For (ii), note that y = <_O^x if and only if (x, y) ∈ P and (∀z)((x, z) ∈ P → (∀n)(n ∈ y → n ∈ z)) which is Π_1^1. We leave the other part of (ii) as an exercise.

Proposition 1.2.5 has some interesting consequences. Consider for example the set O = {0}. Then x ∈ O if and only if (0, x) ∈ {(x, y) | y = O^x}. Hence O is a Π_1^1-singleton whose unique member is only Π_1^1.

As in § 1.2.1, one may define the notion of an x-constructive ordinal and denote the least non x-constructive ordinal as α_1^x. Note that at limit stage, different oracle sets x may use different indices e for the notation. Hence O^x may be different for different x's. Moreover, for x's with "sufficient computational power", one may have α_1^x > ω_1^{CK}. We will present a characterization of this property in due course.
