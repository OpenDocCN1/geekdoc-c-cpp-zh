theory, is there a large cardinal axiom \(\psi\) such that ZFC \(+\varphi\) (or ZF \(+\varphi\)) is consistent if and only if ZFC \(+\psi\) is consistent? When this holds, we say that \(\varphi\) is equiconsistent with \(\psi\). The next result due to Solovay exemplifies this point.

# **Proposition 6.4.3** (Solovay [149]). The statement that every uncountable \(\Pi^1_1\)-set has a perfect subset is equiconsistent with the existence of an inaccessible cardinal.

Proof. By Proposition 6.4.2, the statement that every uncountable \(\Pi^1_1\)-set has a perfect subset implies \(\omega_1\) is inaccessible in L. Hence over ZFC, the consistency of the statement implies the consistency of the existence of an inaccessible cardinal.

Now suppose that there exists an inaccessible cardinal \(\kappa\) in a transitive model \(\mathfrak{M}\) of ZFC. Fix an L(\(\kappa\))-generic set \(G\) over \(\mathfrak{M}\). By Proposition 6.2.9, \(\kappa = (\omega_1)^{\mathfrak{M}[G]}\). Let \(x \in \mathfrak{M}[G]\). Then there is a sequence of conditions \(\cdots \le p_n \le \cdots \le p_0\) such that for any \(n\), \(p_n \in G\) forces the value of \(x(n)\). Since \(\kappa = (\omega_1)^{\mathfrak{M}[G]}\), there is a regular cardinal \(\eta < \kappa\) such that \(p_n \in \mathbf{L}(\eta)\) for every \(n\) and hence \(x \in \mathfrak{M}[G \cap \mathbf{L}(\eta)]\). Thus \((\omega_1)^{L[x]} \le (\omega_1)^{\mathfrak{M}[G \cap \mathbf{L}(\eta)]} < \kappa < \omega_1\). In other words,

\(\mathfrak{M}[G] \models \text{"}(\omega_1)^{L[x]} < \omega_1\text{"}. \)

Relativizing the proof of Corollary 4.3.6 to x, we conclude that the largest \(\Pi^1_1(x)\)-thin set \(\{z \mid z \in L_{\omega_1^{x+}}[x]\}\) is countable. Then

\(\mathfrak{M}[G] \models \text{"Every uncountable } \Pi^1_1\text{-set has a perfect subset".}\)

# **6.4.2 Measurable cardinals**

For a given infinite cardinal \(\kappa\), consider \(\mathscr{P}(\kappa)\) as a partially ordered set under \(\subseteq\).

# **Definition 6.4.4.**

+   - A set \(A \subseteq \mathscr{P}(\kappa)\) is an ultrafilter over \(\kappa\) if it is a filter and for any \(a \subseteq \kappa\), either \(a \in A\) or \(\kappa \setminus a \in A\);

+   - a filter \(A\) is nonprincipal if for any \(a \in A\), there exists a \(b \in A\) such that \(a \not\subseteq b\);

+   - let \(\eta \le \kappa\) be a cardinal. A Filter \(A\) is \(\eta\)-complete if for any \(\beta < \eta\) and any sequence \(\{a_\alpha\}_{\alpha < \beta}\) in \(A\), \(\cap_{\alpha < \beta} a_\alpha \in A\).

A \(\kappa\)-complete nonprincipal ultrafilter \(A\) over \(\kappa\) induces a \(\kappa\)-additive zero-one measure \(\mu\) on \(\mathscr{P}(\kappa)\) defined so that for any \(a \subseteq \kappa\), \(\mu(a) = 1\) if and only if \(a \in A\). It is not difficult to construct under ZFC an \(\omega\)-complete nonprincipal ultrafilter \(A\) over \(\omega\). For \(\kappa > \omega\), however, no \(\kappa\)-complete nonprincipal ultrafilter \(A\) over \(\kappa\) can be proved to exist within the same axiom system.

# **Definition 6.4.5.** We say that \(\kappa > \omega\) is measurable if there exists a \(\kappa\)-complete non-principal ultrafilter \(A\) over \(\kappa\).
