# 5.2.2 Applications to hyperdegrees

We now use Cohen forcing to study the structure of hyperdegrees.

**Proposition 5.2.7.** If _z_ is not hyperarithmetic, then there exists an _x_ such that \(x \not\le_h z\) and \(x \not\ge_h z\).

**Proof.** Assume that _z_ is not hyperarithmetic. Fix an enumeration \(\{z_i\}_{i<\omega}\) of reals hyperarithmetic in _z_ and an enumeration \(\{\varphi_i\}_{i<\omega}\) of all formulas.

We define a sequence \(\emptyset = p_0 \ge p_1 \ge \cdots\) of conditions as follows:

Suppose that _p<sub>i</sub>_ is defined. At stage _i_ + 1, first let \(q_i^1 \le p_i\) so that there exists a _j_ with \(q_i^1(j) \neq z(i)\). Then let \(q_i^1 \le q_i^0\) so that \(q_i^1 \in D_{\varphi_i}\). This is possible according to Lemma 5.2.3.

See if \(\varphi_i(n, k)\) is ranked and whether for all _n_, there exists an \(r \le q_i^1\) and _k_ such that \(r \Vdash \varphi_i(n, k)\). If not, let _p_<sub>_i_+1</sub> = \(q_i^1\) and go to next stage. Otherwise, see if for all _n_ and \(r \le q_i^1\), if \(r \Vdash \varphi_i(n, k)\) then _k_ is unique. If this is so, let _p_<sub>_i_+1</sub> = \(q_i^1\) and go to next stage. If not, let \(p_{i+1} \le q_i^1\) so that there exists an _n_ with \(p_{i+1} \Vdash \varphi(n, k)\) for some \(k \neq z(n)\).

Let \(x = \bigcup_{i<\omega} p_i\). Then _x_ is Cohen generic and \(x \not\le_h z\). By Corollary 5.2.6, \(\omega_1^x = \omega_1^{CK}\). If \(x \ge_h z\), then by Corollary 5.1.4, there is a ranked formula \(\varphi_i(n, k)\) in the enumeration list such that _z_(_n_) = _k_ if and only if \(\exists(\omega_1^{CK}, x) \Vdash \varphi_i(n, k)\). By Theorem 5.2.4, for each _n_, there exist _k_ and _m_ such that \(x \Vdash m \Vdash \varphi_i(n, k)\). Then by the construction at stage _i_ + 1, it must be the case that for every _n_ and \(r \le q_i^1\), there is a unique _k_ satisfying \(r \Vdash \varphi_i(n, k)\). Define _z_(_n_) = _k_ if and only if there is an \(r \le q_i^1\) with \(r \Vdash \varphi_i(n, k)\). By Theorem 5.2.2, _z_ is \(\Pi_1^1\) and hence hyperarithmetic. But \(z = \hat{z}\), a contradiction.

Thus \(x \not\le_h z\) and \(x \not\ge_h z\).
