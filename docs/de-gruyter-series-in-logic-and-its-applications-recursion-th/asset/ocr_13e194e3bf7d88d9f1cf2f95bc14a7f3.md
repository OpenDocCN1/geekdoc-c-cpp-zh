# ## 11.2 An antibasis theorem for \(\Pi^0_1\)-sets

# ### 11.2.1 An analysis of Theorem 11.1.1

A natural question arising from Theorem 11.1.1 is whether the condition \(x \ge_h \emptyset\) in the statement may be weakened to \(x^{(\beta)} \ge_T \emptyset\) or even \(x^{(\beta)} \ge_T 0^{(\beta+1)}\) for some \(\beta < \omega^{CK}_1\). The proof of the theorem requires at least \(\omega^{CK}_1\)-many iterates of the Turing jump. A negative answer is given by Harrington:

**Theorem 11.2.1 (Harrington [43]).** For any ordinal \(\beta < \omega^{CK}_1\), there is an uncountable \(\Pi^0_1\)-set \(A \subseteq \omega^\omega\) such that for each \(x \in A\), \(x^{(\beta)} \not\ge_T 0^{(\beta+1)}\).

We begin our discussion with the finite version of Theorem 11.2.1.

**Theorem 11.2.2.** There is an uncountable \(\Pi^0_1\)-set \(A \subseteq \omega^\omega\) such that for any \(x \in A\) and \(n < \omega\), \(x^{(n)} \not\ge_T 0^{(n+1)}\).

Harrington's proof uses an ingenious reverse induction construction. The following proof is more complicated than necessary, but the argument is applicable to a more general situation. By Theorem 2.1.4, the set \(H = \{(i, (0)^i) \mid i < \omega\} \subseteq \omega \times 2^\omega\) is \(\Pi^0_2\). Hence there is a recursive predicate \(P(i, \sigma, m)\) such that \((i, x) \in H \Leftrightarrow (\forall m)(\exists k)P(i, x \unknown k, m)\). \((i, \sigma) \in T^\omega \Rightarrow (\exists m)(\exists s_m)(\sigma = \sigma_0 \oplus \sigma_1 \dots \sigma_s \mid \sigma_0 = s_m \wedge |\sigma_0| = 2^m \cdot 3^{s_m} \wedge s_m = \min\{|s| \mid (\forall l \le m)(\exists k \le s)P(i, \sigma_0 \unknown k, l)\})\).
