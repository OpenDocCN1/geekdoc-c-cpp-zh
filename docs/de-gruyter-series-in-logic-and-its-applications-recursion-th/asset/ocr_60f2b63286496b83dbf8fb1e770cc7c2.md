The main result of this section states:

# Theorem 1.4.4 (Kleene [71], Markwald [89]). An ordinal is recursive if and only if it is constructive.

Proof. Suppose $R$ is a recursive well-ordering with $|R| = \beta$. By Lemma 1.4.2, there is a constructive ordinal $\gamma \ge \beta$. Hence $\beta$ is constructive. Conversely, if $\beta$ is constructive, then by Theorem 1.3.4, there is a partial recursive well-ordering $R$ with $|R| = \beta$. By Lemma 1.4.3, $\beta$ is recursive.

# 1.5 $\Pi^1_1$-completeness and $\Sigma^1_1$-boundedness

# 1.5.1 $\Pi^1_1$-completeness

# Theorem 1.5.1. $O \in \Pi^1_1$-complete. Hence $O$ is not $\Sigma^1_1$.

Proof. By Lemma 1.4.2, Wf is many-one reducible to $O$. As discussed in §1.1.4, Wf$_0$ is $\Pi^1_1$-complete, hence $O$ as well.

We now consider sets of reals. Suppose $P(x, n)$ is $\Pi^1_1$. By relativizing Theorem 1.5.1, there is a recursive function $f_P$ such that $P(x, n) \Leftrightarrow f_P(n) \in O^x$ for all $n$ and $x$. In particular, a $\Pi^1_1$-predicate $Q(x)$ is $P(x, 0)$ for some $\Pi^1_1$-predicate $P$. Hence $Q(x)$ if and only if $f_Q(0) \in O^x$ for some recursive function $f_Q$. It follows that the set $C = \{(x, n) \mid n \in O^x\}$ is $\Pi^1_1$-universal. In other words, for each $\Pi^1_1$-set $Q$, there is a number $n$ such that $Q = \{x \mid (x, n) \in C\}$. It is not difficult to see that $C$ is not $\Sigma^1_1$. We may also code $C$ into a subset of $2^\omega$ by defining $D = \{0^n1^x \mid n \in O^x\}$. Then $D$ is a $\Pi^1_1$-complete set.
