
## 10.2 The rigidity of hyperdegrees

Let $x \le \omega$. The next step in the proof of rigidity is to define a partial lattice $\mathcal{C}_x$ with a finite set of parameters that generates a copy of $\omega$. In addition, $x$ will be coded in $\mathcal{C}_x$. For the intended application, the coding of membership and nonmembership in $x$ will be in terms of positive formulas involving only $\le$ and $u$, i.e. the negation symbol $-$ and the meet symbol $\wedge$ do not appear in the formula defining an $n$ in $x$ or $n \notin x$. This is a key device to ensure that in any embedding $f$ of $\mathcal{C}_x$ into $\mathcal{D}_h$ preserving $\le$ and $u$, one always has $x$ hyperarithmetic in the parameters defining the partial lattice (a consequence of Lemma 10.2.1 (iv) below).

Firstly, let $d_0, e_0, e_1, f_0, f_1$ be elements of $\mathcal{C}_x$ which will be the generators of $\{d_n \mid n < \omega\}$ intended as a copy of $\omega$. For each $n < \omega$, let:

- $(d_{2n} \cup e_0) \cap f_1 = d_{2n+1}$
- $(d_{2n+1} \cup e_1) \cap f_0 = d_{2n+2}$

These conditions guarantee that the $d_n$'s are enumerated recursively. Given $x \le \omega$, we add two additional parameters $c_x$ and $c_x'$, and require $d_n \le c_x$ for $n \in x$, $d_n \cap c_x = 0$ for $n \notin x$. We also set $d_{2n+1} \le (d_{2n} \cup e_0)$, $d_{2n+1} \le f_1$ and $d_{2n+1} \neq 0$. To avoid the use of $-$, the last inequality may be satisfied by introducing two further parameters $c$ and $c'$ and requiring that in the partial lattice $c' \neq 0$ and $c \cup d_n \ge c'$ for each $n$. If $u = d_n$ for some $n$, then $u \neq 0$ is expressed as $c \cup u \ge c'$.

### Lemma 10.2.1. Let $x \le \omega$. There is a recursive set $\{p_n \mid n \in \omega\}$ of positive existential formulas involving only $\le$, $u$ and parameters $c_x, c_x', c, c', d_0, e_0, e_1, f_0, f_1$ such that in any partial lattice $\mathcal{C}_x$ defined as above,

- (i) $p_n(u) \leftrightarrow 0 \le u \le d_n$;
- (ii) $n \in x \leftrightarrow (\exists u)(p_n(u) \wedge u \le c_x)$;
- (iii) $n \notin x \leftrightarrow (\exists u)(p_n(u) \wedge u \le c_x)$;
- (iv) In any embedding of $\mathcal{C}_x$ into $\mathcal{D}_h$ preserving $\cap, \cup$ and $\le$, the formulas are equivalent to $\Pi_1^1$-formulas (with the relevant parameters).

Proof. First set $\varphi_0(u)$ to be $u = d_0$. Recursively define $\varphi_{2n+1}(u)$ to be

$(\exists w)(\varphi_{2n}(w) \land u \subseteq w \cup e_0 \land u \lesssim f_1 \land c \cup u \supseteq c')$

and let $\varphi_{2n+2}(u)$ to be

$(\exists w)(\varphi_{2n+1}(w) \land u \subseteq w \cup e_1 \land u \lesssim f_0 \land c \cup u \supseteq c')$

Suppose that $\varphi_{2n+1}(u)$ holds for u. Then there is a w as described such that, by induction, $0 < w \le d_{2n}$. Thus $w \cup e_0 \subseteq d_{2n} \cup e_0$ and so $d_{2n} \cup e_0 \subseteq f_1$. As $d_{2n+1} = (d_{2n} \cup e_0) \cap f_1$, $u \subseteq d_{2n+1}$. Furthermore, $c' \subseteq c \cup u$ ensures that $u > 0$ as well and so (i) holds for $\varphi_{2n+1}$. The argument for $\varphi_{2n+2}$ is similar.

We leave the verification of (ii) and (iii) to the reader. Finally, (iv) follows from Corollary 3.7.4.

### Remark 10.2.2. Theorem 10.1.2 may be relativized to any real x. The partial lattice $c_x$ is defined recursively in x from the parameters $d_0, e_0, e_1, f_0, f_1, c_x, c_+, c_-, c'$ using $\le, \cup, \cap$ as partial functions. Then any embedding of $c_x$ into the hyperdegrees maps the 0 of $c_x$ to x.

Now fix a real x. By Theorem 10.1.2 relativized to x, there is an embedding $f : c_x \to \mathscr{D}_h$ preserving $\le, \cup, \cap$ and $\neg$ so that $f(0_{c_x}) = x$. By Lemma 10.2.1, both x and $\omega \setminus x$ are $\Pi^0_1$-definable relative to a representation of

$f(d_0) \cup f(e_0) \cup f(e_1) \cup f(f_0) \cup f(f_1) \cup f(c_x) \cup f(c) \cup f(c') \le f(1_{c_x})$.

Hence $x \le f(1_{c_x})$.

The following result will be used in the proof of the biinterpretability of $(\mathscr{D}_h, \le)$ with second order arithmetic.

### Lemma 10.2.3. For any x and y, $y \le_R x$ if and only if there exist $y_0, y_1 > x$ such that $y_0 \cap y_1 = x$ and $c_y$ is embeddable into both $[x, y_0]$ and $[x, y_1]$ with minimal element x.

Proof. Let $g_0$ and $g_1$ be Cohen generic reals relative to x so that $(x \cup g_0) \cap (x \cup g_1) = x$. Then the 'only if' direction follows immediately from Theorem 10.1.2 relativized to x by letting $y_0 = x \cup g_0$ and $y_1 = x \cup g_1$.

For the other direction, note that by Lemma 10.2.1 $y \le y_0$ and $y \le y_1$. So $y \le x$.

We are now ready to prove the main theorem of this section.

### Theorem 10.2.4 (Slaman and Woodin [141], Shore [133]). If $\pi : \mathscr{D}_h \to \mathscr{D}_h$ is an automorphism, then $\pi$ is the identity map.

Proof. Let x be a hyperdegree containing x as an element. Let $c_x$ be the lattice generated by $d_0, e_0, e_1, f_0, f_1$ as described above. Let $\hat{c}_x$ be a disjoint copy of $c_x$ and define a partial lattice $\mathscr{P}_x$ which is the union of $c_x$ and $\hat{c}_x$ such that $0_{\mathscr{P}_x} = 1_{c_x} \cap 1_{\hat{c}_x}$ and $1_{\mathscr{P}_x} = 1_{c_x} \cup 1_{\hat{c}_x}$. By Theorem 10.1.2 relativized to x, there is an embedding f of $\mathscr{P}_x$ into the hyperdegrees such that $f(0_{\mathscr{P}_x}) = x$.

Suppose \(\pi : \mathscr{D}_h \to \mathscr{D}_h\) is an automorphism such that \(\pi(\mathbf{x}) \neq \mathbf{x}\). Then the coding scheme (see Remark 10.2.2) ensures that \(\mathbf{x} \le \pi f(1_{\hat{c}_x})\) and \(\mathbf{x} \le \pi f(1_{\hat{c}_x})\). Since \(\mathbf{x} = f(0_{\hat{c}_x}) = f(1_{\hat{c}_x}) \cap f(1_{\hat{c}_x})\), we have \(\pi(\mathbf{x}) = \pi(f(1_{\hat{c}_x}) \cap f(1_{\hat{c}_x})) = \pi(f(1_{\hat{c}_x})) \cap \pi(f(1_{\hat{c}_x}))\) so that \(\mathbf{x} \le \pi(\mathbf{x})\). A similar argument with \(\pi^{-1}\) shows that \(\pi(\mathbf{x}) \le \mathbf{x}\) so that \(\pi(\mathbf{x}) = \mathbf{x}\), a contradiction.

## 10.3 Biinterpretability

Biinterpretability in the Turing degrees says essentially that a relation on \(\mathscr{D}\) is definable if and only if it is definable in second order arithmetic.

While the biinterpretability of \((\mathscr{D}, \le)$ has yet to be established, we show in this section that it holds for the hyperdegrees.

### 10.3.1 Slaman–Woodin Coding

Slaman and Woodin [14] showed the definability (with parameters) of any countable relation on the Turing degrees. This was achieved using a technique of what is now called the Slaman–Woodin coding. The technique is applicable to an array of degree structures, including the hyperdegrees, and is key to proving the biinterpretability of \((\mathscr{D}_h, \le)$ with second order arithmetic.

### Theorem 10.3.1 (Slaman and Woodin [143]). For each \(n < \omega\) there is a formula \(\varphi_n\) in the language of hyperdegrees such that for any countable \(n\)-ary relation \(R \subseteq \mathscr{D}_h\), there exist \(\mathbf{g}_1, \dots, \mathbf{g}_m\) and \((\mathbf{a}_1, \dots, \mathbf{a}_n) \in R \leftrightarrow (\mathscr{D}_h, \le) \models \varphi_n(\mathbf{a}_1, \dots, \mathbf{a}_n; \mathbf{g}_1, \dots, \mathbf{g}_m)$.

We establish this theorem by first showing that any countable antichain of hyperdegrees is definable in \((\mathscr{D}_h, \le)$. Here is the setup: Let \(A = \{\mathbf{a}_i \mid i < \omega\}\) be an antichain and let \(a_i\) be a real of hyperdegree \(\mathbf{a}_i\) such that \(a_i\) is recursive in each of its infinite subsets (note that every infinite set is Turing equivalent to the set of (codes of) its finite initial segments). Let \(a \in \mathbf{a}\) be an upper bound of \(A\).
