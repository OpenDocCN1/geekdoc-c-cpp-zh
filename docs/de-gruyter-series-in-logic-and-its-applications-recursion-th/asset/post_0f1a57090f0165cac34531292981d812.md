## Lemma 9.1.18. If (p, q) ≤ (p₀, q₀), then there exist an n and a condition (p′, q′) ≤ (p, q) such that for any (p′′, q′′) ≤ (p′, q′), (p′′, q′′) ⊩ ẋ(n) = i for some i < 2.

Proof. Suppose not. Then there is a (p₁, q₁) ≤ (p₀, q₀) such that for any n and (p′, q′) ≤ (p₁, q₁), there exist a (p′′, q′′) ≤ (p′, q′) and an i_n < 2 satisfying (p′′, q′′) ⊩ ẋ(n) = i_n. Then the set

D_n = {p | p \not\perp p₁ ∨ (∃i)(p ≤ p₁ ∧ (p, q̇₁) ⊩ ẋ(n) = i_n)}

is an element of M and is dense in P. Fix a generic set (G′, H′) such that p₁ ∈ G′. Then val(ẋ, (G′, H′))(n) = i_n if and only if there exists a p ∈ D_n ∩ G′ such that (p, q̇₁) ⊩ ẋ(n) = i_n. Thus val(ẋ, (G′, H′)) ∈ M[G′], a contradiction.
