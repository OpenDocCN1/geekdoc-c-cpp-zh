# ## 1.3.2 Operators on ordinal notations

We now define an operator $+_o$ on $\mathcal{O}$. In addition to requiring it to be closed in $\mathcal{O}$ (i.e. \(m \in \mathcal{O}\) and \(n \in \mathcal{O}\) implies \(m +_o n \in \mathcal{O}\)), we also require \(|m| + |n| = |m +_o n|\).

Let \(g\) be a recursive function such that

\(\Phi_{g(e,m,n)}(k) = \Phi_e(m, \Phi_n(k))\)

for all \(e, k, m, n\). Intuitively, \(g\) is a function to be used to handle induction at limit stage.

By the s-\(m\)-n Theorem, there is a recursive function \(h\) such that

\(\Phi_{h(e)}(m, n) = \begin{cases} m & n = 1, \\ 2^{\Phi_e(m,k)} & n = 2^k, \\ 3 \cdot 5^{g(e,m,k)} & n = 3 \cdot 5^k, \\ 7 & \text{Otherwise.} \end{cases}\)

By the Recursion Theorem, there is a \(c\) such that \(\Phi_{h(c)} = \Phi_c\). Define

\(m +_o n = \Phi_c(m, n)\).

It is straightforward to verify that

\(m +_o n = \begin{cases} m & n = 1, \\ 2^{m+k} & n = 2^k, \\ 3 \cdot 5^{c(m,k)} & n = 3 \cdot 5^k, \\ 7 & \text{Otherwise.} \end{cases}\)

Note that

\(\Phi_{g(e,m,k)}(n) = \Phi_e(m, \Phi_k(n)) = m +_o \Phi_k(n)\)

for all \(n\). Obviously \(+_o\) is a recursive function on \(\omega \times \omega\). The following is proved by induction on \(<_o\).

# ### Proposition 1.3.3. The function \(+_o\) satisfies the following properties: For all \(m, n\),

+   (i) \(m, n \in \mathcal{O} \Leftrightarrow m +_o n \in \mathcal{O}\).
+   (ii) \(m, n \in \mathcal{O} \Longrightarrow |m +_o n| = |m| + |n|\).
+   (iii) \(m, n \in \mathcal{O} \text{ and } n \neq 1 \Longrightarrow m <_o m +_o n\).
+   (iv) \(m \in \mathcal{O} \text{ and } k <_o n \Leftrightarrow m +_o k <_o m +_o n\).
+   (v) \(m \in \mathcal{O} \land n = k \in \mathcal{O} \Leftrightarrow m +_o n = m +_o k \in \mathcal{O}\).
