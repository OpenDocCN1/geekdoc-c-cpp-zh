Proof. Suppose \(x\) is \(\Delta^1_1\)-dominated and \(\Delta^1_1\)-semitraceable. Let \(U\) be a \(\Delta^1_1(x)\) open set with measure 1. Then there is a \(y \le_h x\) such that \(U\) is \(\Delta^1_1(y)\). Let \(\Phi\) be a Turing reduction so that the domain of \(\Phi^y\) is \(U\). Write \(U'\) for the domain of \(\Phi^x\) for any \(z\). Note that \(U = U'\).

Define a \(\Delta^1_1(x)\) function \(\hat{f}\) by: \(\hat{f}(n)\) is the shortest string \(\sigma < y\) with \(\mu(U'[\sigma]) > 1 - 2^{-n}\). By the hypothesis of the theorem, there is an increasing \(\Delta^1_1\)-function \(g\) and a \(\Delta^1_1\)-function \(f\) such that for every \(n\), there is an \(m \in [g(n), g(n+1)]\) with \(f(m) = f(m)\). Without loss of generality, we may assume that \(\mu(U'[f(m)]) > 1 - 2^{-m}\) for every \(m\).

Define a \(\Delta^1_1\)-open set \(V\) such that \(\sigma \in V\) if and only if there exists an \(n\) such that \([\sigma] \subseteq \bigcap_{g(n) \le m \le g(n+1)} U'[f(m)]\). By the property of \(f\) and \(g\), \(V \subseteq U' = U\). But for every \(n\),

\(\mu\left(\bigcap_{g(n) \le m \le g(n+1)} U'[f(m)]\right) > 1 - \sum_{g(n) \le m \le g(n+1)} 2^{-m} \ge 1 - 2^{-g(n)+1}.\)

Hence

\(\mu(V) \ge \lim_n \mu\left(\bigcap_{g(n) \le m \le g(n+1)} U'[f(m)]\right) = 1.\)

This implies that \(x\) is low for \(\Delta^1_1\)-Kurtz tests.

# Lemma 14.6.2. If \(x\) is low for \(\Delta^1_1\)-Kurtz randomness, then \(x\) is \(\Delta^1_1\)-dominated.

Proof. We first show that if \(x\) is low for \(\Delta^1_1\)-Kurtz tests, then \(x\) is \(\Delta^1_1\)-dominated.

Suppose \(f \le_h x\) is an increasing function. Let \(S_f = \{z \mid (\forall n)(z(f(n)) = 0)\}\). Obviously \(S_f\) is a \(\Delta^1_1(x)\)-closed nullset. Hence there is a \(\Delta^1_1\)-closed nullset \([T] \supseteq S_f\) where \(T \subseteq 2^{<\omega}\) is a \(\Delta^1_1\)-tree. Define

\(g(n) = \min\{m \mid |\{\sigma \in 2^m \mid [\sigma] \subseteq T\}| < 2^{-n}\} + 1.\)

Since \(\mu([T]) = 0\), \(g\) is \(\Delta^1_1\). We claim that \(g\) dominates \(f\).

For every \(n\), \(S_{f(n)} = \{\sigma \in 2^{f(n)} \mid (\forall i < n)(\sigma(f(i)) = 0)\}\) has cardinality \(2^{f(n)-n}\). However, if \(g(n) \le f(n)\) then applying \(S \subseteq [T]\) one has

\(|S_{f(n)}| \le 2^{f(n)-g(n)} \cdot |\{\sigma \in 2^{g(n)} \mid \sigma \in T\}| < 2^{f(n)-g(n)} \cdot 2^{g(n)-n} = 2^{f(n)-n}.\)

This is a contradiction. Hence \(x\) is \(\Delta^1_1\)-dominated.

Now suppose \(x\) is not \(\Delta^1_1\)-dominated witnessed by an \(f \le_h x\). Then \(S_f\) is not contained in any \(\Delta^1_1\)-closed nullset. Indeed it is not difficult to see that for any \(\sigma\) oracle with \([\sigma] \cap S_f \neq \emptyset\), \([\sigma] \cap S_f\) is not contained in any \(\Delta^1_1\)-closed nullset (otherwise, as proved above, one shows that \(f\) is dominated by a \(\Delta^1_1\)-function). Then by induction, one constructs a \(\Delta^1_1\)-Kurtz random \(z \in S_f\) as follows:

Let \(P_0, P_1, \dots\) be an enumeration of the \(\Delta^1_1\)-closed nullsets. First choose the least \(\tau\) such that \([\tau] \cap S_f \neq \emptyset\) but \([\tau] \cap S_f \cap P_0 = \emptyset\). Let \(l_0 = |\tau|\) and \(Z_0 = \tau\). Suppose that at stage \(n+1\), \(Z_n \in l_n\) is defined so that \([Z_n \cap l_n] \cap S_f \neq \emptyset\). Then there is a \(\tau > Z_n \cap l_n\) such that \([\tau] \cap S_f \neq \emptyset\) but \([\tau] \cap S_f \cap P_n = \emptyset\). Choose the least such \(\tau\) and let \(l_{n+1} = |\tau|\) and \(z \cap l_{n+1} = \tau\). Then \(z \in S_f\) is \(\Delta^1_1\)-Kurtz random. Thus \(x\) is not low for \(\Delta^1_1\)-Kurtz randomness.
