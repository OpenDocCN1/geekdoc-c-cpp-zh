
At stage $s + 1$, suppose that $l_{\tau_i}(m_2 + s)$ is defined and $|\tau_i^s| = l_{\tau_i}(m_2 + s)$ (hence $l_{\tau_i}(m_2 + s + 1)$ is undefined) for $i = 0, 1$.

Case 1. $x(s) = 0$. Then by the assumption on $u$ and Lemma 7.5.3, let $r_{\tau_{s+1}}^0 > r_{\tau_s}^0$ so that $l_{\tau_i}(m_2 + s + 1)$ is defined and $|\tau_i^s| = l_{\tau_i}(m_2 + s)$. Let $\tau = (\tau_{s+1}^0)^\frown (l_{\tau_i}(m_2 + s + 1) + 1)$. By the assumption on $u$ and Lemma 7.5.3 again, let $r_{\tau_{s+1}} > \tau$ so that $l_{\tau_{s+1}}^r(m_2 + s + 1)$ is defined and $|\tau_i^r| = l_{\tau_i}(m_2 + s + 1)$. Note that by the assumption on $u$, there is an $h > r_{\tau_{s+1}}^1$ in $H_{e_1, m_1}$. Hence by Lemma 7.5.3,

$l_{\tau_{s+1}}^r(m_2 + s + 1) = l_0(m_2 + s + 1) \ge h(m_2 + s + 1) = l_{\tau_{s+1}}^0(m_2 + s + 1) + 1 > l_{\tau_{s+1}}^0(m_2 + s + 1)$.

Case 2. $x(s) = 1$. Do the same construction as in Case 1 but replace 0 by 1. We have

$l_{\tau_{s+1}}^1(m_2 + s + 1) < l_{\tau_{s+1}}^0(m_2 + s + 1)$.

Let $h_i = \bigcup_s \tau_i^s$ and $x_i = \pi(h_i) \in [T]$ for $i \le 1$. Then $x_0 \equiv_T x_1 \equiv_T T$. Let $l_i$ be $l^{\tau_i}$ for $x_i$ as defined in Lemma 7.5.2. Then $l_i \le_T \Phi_{e_0}^{x_i}$ for $i \le 1$. Moreover,

(vii)($(l_i(m+i+1) > l_0(m+i+1)) \Leftrightarrow x(i) = 0$) $\wedge$ ($(l_i(m+i+1) < l_0(m+i+1)) \Leftrightarrow x(i) = 1$)).

Hence $T \equiv_T x \le_T \Phi_{e_0}^{x_0} \oplus \Phi_{e_0}^{x_1}$.

This completes the proof of Theorem 7.5.1.

## 8 The construction of $\Pi^1_1$-sets

As seen in the previous chapters, inductive definition plays a key role in hyperarithmetic theory. In fact Gandy (see [106]) held the view that inductive definition rather than computation constituted the core characteristic of any generalized recursion theory. Admissible set theory (Chapter 3) reinforces the line of thought. Here we discuss inductive definition in greater detail and present some applications of this notion to the construction of $\Pi^1_1$-sets. The reader is referred to [47] and [106] for more on this subject.

### 8.1 An introduction to inductive definition

#### 8.1.1 Inductive definability

Definition 8.1.1. Let $\Gamma : 2^\omega \to 2^\omega$ be a function.

- $\Gamma$ is progressive if $x \in \Gamma(x)$ for every $x \in 2^\omega$;
- $\Gamma$ is monotonic if $\Gamma(y) \subseteq \Gamma(x)$ if $y \subseteq x$.

Given a function $\Gamma : 2^\omega \to 2^\omega$, let

$$
\begin{aligned}
\Gamma_0 &= \emptyset; \\
\Gamma_{\alpha+1} &= \bigcup \Gamma(\Gamma_\alpha) \cup \Gamma_\alpha; \\
\Gamma_\lambda &= \bigcup_{\beta < \lambda} \Gamma_\beta \quad \text{if $\lambda$ is a limit ordinal;} \\
\Gamma_\infty &= \bigcup_\alpha \Gamma_\alpha.
\end{aligned}
$$

A real $x \in 2^\omega$ is inductively defined by $\Gamma$ if $x = \Gamma_\infty$. We use $|\Gamma|$ to denote the least ordinal $\alpha$ such that $\Gamma_\alpha = \Gamma_\infty$. Note that $|\Gamma| < (2^{\aleph_0})^+$. It is not difficult to see that for any real $x$, there is a function $\Gamma : 2^\omega \to 2^\omega$ such that $x$ is inductively defined by $\Gamma$ (Exercise 8.1.1).

Theorem 8.1.2 (Gandy). Suppose that $\Gamma$ is a progressive function such that the set $\{(n, x) \in \omega \times 2^\omega \mid n \in \Gamma(x)\}$ is $\Pi^1_1$. Then $|\Gamma| \le \omega_1^{CK}$ and $\Gamma_\infty$ is $\Pi^1_1$.

Proof. By Theorem 3.1.8, there is a $\Sigma_1(L_{\omega_1^{CK}})$-definable function $f : \omega_1^{CK} \to L_{\omega_1^{CK}}$ such that $f(\beta) = \Gamma_\beta$ for $\beta < \omega_1^{CK}$. Let $x$ be a real such that

$n \in x \leftrightarrow (\exists \beta < \omega_1^{CK})(n \in f(\beta))$.

Note that $x = \Gamma_{\omega_1^{CK}}$. Moreover $x$ is $\Sigma_1$-definable in $(L_{\omega_1^{CK}}, \in)$ and hence $\Pi^1_1$. Let $R$ be a recursive predicate such that for any $i$,

$i \in \Gamma(x) \leftrightarrow (\forall j) R(i, x \mid j)$.

Fix an $i \in \Gamma(x)$. Then $(\forall j)R(i, x \upharpoonright j)$. Now for each $j \in \omega$, there is an ordinal $\beta < \omega_1^{CK}$ such that $\Gamma_\beta \upharpoonright j = x \upharpoonright j$ and hence $R(i, \Gamma_\beta \upharpoonright k)$ for every $k \le j$. Since $R$ is recursive, we have

$(L_{\omega_1^{CK}}, \in) \equiv (\forall j)(\exists R(i, \Gamma_\beta \upharpoonright j))$.

By induction, let $\beta_j$ be the least ordinal $\beta > \beta_{j-1}$ such that $(L_{\omega_1^{CK}}, \in) = R(i, \Gamma_\beta \upharpoonright k)$ for every $k \le j$. Then the function $p : j \mapsto \beta_j$ is $\Sigma^1_1(L_{\omega_1^x})$-definable and hence belongs to $L_{\omega_1^x}$ by the admissibility of $L_{\omega_1^x}$. It follows that the ordinal $\beta(i) = \bigcup_{j < \omega} \beta_j$ is a limit ordinal less than $\omega_1^{CK}$. Note that $\Gamma_\beta \subseteq \Gamma_{\beta+1}$ for $j < \omega$. Then for each $k$, there is a $j \ge k$ such that $\Gamma_{\beta(j)} \upharpoonright k = \Gamma_\beta \upharpoonright k$. Thus

$(L_{\omega_1^{CK}}, \in) = R(i, \Gamma_{\beta(i)} \upharpoonright k)$.

In other words,

$(L_{\omega_1^{CK}}, \in) \equiv (\forall k)R(i, \Gamma_{\beta(i)} \upharpoonright k)$.

Hence if $i \in \Gamma(x)$, then $i \in \Gamma_{\beta(i)}$ and so $i \in x$. Thus $\Gamma(x) \subseteq x$, i.e. $\Gamma(x) = x$. We conclude that $x = \Gamma_{co}$.

#### 8.1.2 Monotonic inductive definability of $\Pi^1_1$-reals

**Proposition 8.1.3.** Let $k > 0$. Suppose that $\Gamma$ is progressive and monotonic, and the set $\{(n, x) \mid n \in \Gamma(x)\}$ is $\Pi^1_k$. Then $\Gamma_{co}$ is $\Pi^1_k$.

Proof. Since $\Gamma$ is progressive and monotonic, $\Gamma_{co}$ is the least real (in the sense of inclusion) $x$ such that $\Gamma(x) \subseteq x$. Then $n \in \Gamma_{co}$ if and only if

$(\forall x)(\Gamma(x) \subseteq x \rightarrow n \in \Gamma(x))$.

If the set $\{(n, x) \mid n \in \Gamma(x)\}$ is $\Pi^1_k$, then $\Gamma_{co}$ is $\Pi^1_k$.

The following strengthens Theorem 8.1.2 for monotonic functions.

**Theorem 8.1.4** (Specter [153]). Suppose that $\Gamma$ is progressive and monotonic such that $\{(n, x) \in \omega \times 2^\omega \mid n \in \Gamma(x)\}$ is $\Pi^1_1$. Then $|\Gamma| \le \omega_1^{CK}$.

Proof. We prove that $\Gamma(\Gamma_{\omega_1^{CK}}) = \Gamma_{\omega_1^{CK}}$ and $|\Gamma| \le \omega_1^{CK}$.

- Let $C \subseteq \mathscr{B}(\omega \times \omega)$ be a $\Sigma^1_1$-set such that $x \in C$ if and only if
  - $\{n \mid (1, n) \in x\} = \emptyset$
  - $(\forall j)(\Gamma(n \upharpoonright j, n, x) \subseteq \{n \mid \langle 2', n \rangle \in x\})$, and
  - $(\forall e)(e \in \omega \rightarrow (\bigcup_{j \in \omega} n \mid (\Phi_e(j), n) \in x) = \{n \mid \langle 3 \cdot 5^e, n \rangle \in x\})$.

Let
$$z = \bigcap_{x \in C} x.$$

Then $z$ is $\Pi_1^1$. We leave it to the reader to verify that

$(\forall j \in \mathcal{O})((n \mid (j, n) \in z) = \Gamma(j))$.

Hence $\Gamma_{\omega^{CK}} = \{n \mid (\exists j \in \mathcal{O})((j, n) \in z)\}$ is a $\Pi_1^1$-real.

Let $i \in \mathcal{O}^* \setminus 0$. Define $D \subseteq \mathcal{O}^* \times 2^\omega$ to be a $\Sigma_1^1$-set such that $x \in D$ if and only if

$(\forall n)(\forall j)(j \in \mathcal{O} \cap 2^\omega \to ((j, n) \in z \leftrightarrow ((j, n) \in x)))$.

By Gandy's Basis Theorem (2.5.3), there is a $z^* \in D$ such that $\omega_1^{z^*} = \omega_1^{CK}$.

For $j \in \mathcal{O}^*$, let

$z_j^* = \{n \mid (\exists k)(k <_\mathcal{O} j \land (k, n) \in z^*)\}$.

Clearly $\Gamma_{\omega^{CK}} = \bigcup_{j \in \mathcal{O} \cap \mathcal{O}^*} z_j^*$. Moreover, for any $j_0 <_\mathcal{O} j_1 <_\mathcal{O} \dots, z_{j_n}^* \subseteq z_j^*$.

Suppose that $n \in \Gamma(\omega^{CK})$. We claim that there is a $j \in \mathcal{O} \cap \mathcal{O}_1^*$ such that $n \in \Gamma(z_j^*) = \Gamma(\Gamma(j))$. Otherwise, since $\Gamma$ is monotonic, it must be the case that $n \notin \Gamma(z_j^*)$ for any $j \in \mathcal{O}_1^* \setminus 0$. Let

$j \in y_n \leftrightarrow n \in \Gamma(z_j^*)$.

Note that $z_j^* <_{h^*} z^*$ for every $j \in \mathcal{O}^*$. By Corollary 2.2.12, $y_n$ is $\Pi_1^1\{z^*\}$. By the assumption, $y_n = \mathcal{O}_1^* \cap \mathcal{O}$. Thus $y_n$ is also $\Sigma_1^1\{z^*\}$ and hence $\Delta_1^1\{z^*\}$. Obviously $\omega_1^{\mathcal{O}_1^* \cap \mathcal{O}} > \omega_1^{CK}$ and hence $\omega_1^{y_n} > \omega_1^{CK}$, contradicting the choice of $z^*$. We conclude that $\Gamma(\Gamma_{\omega^{CK}}) \subseteq \bigcup_{j \in \mathcal{O} \cap \mathcal{O}^*} \Gamma(j) = \bigcup_{j \in \mathcal{O} \cap \mathcal{O}^*} \Gamma[j] = \Gamma_{\omega^{CK}}$. $\square$

#### 8.1.1 Inductively defining $\mathcal{O}$

As an illustration, we show how $\mathcal{O}$ may be defined inductively. Let $\Gamma$ be a function such that for any $x$,

$$
\Gamma(x)(n) = \begin{cases} 1 & n \in x \\ 1 & n = 1 \\ 1 & (\exists m \in x)(n = 2^m), \\ 1 & (\exists e)(\forall i)(n = 3 \cdot 5^e \cdot \Phi_i(e) \in x), \\ 0 & \text{Otherwise.} \end{cases}
$$

We leave the proof of the other proposition to the reader.

**Proposition 8.1.5.** Let $\Gamma$ be as defined above. Then $\Gamma_\infty = \Gamma_{\omega^{CK}} = \emptyset$.

Thus $\mathcal{O}$ is inductively defined by the arithmetical function $\Gamma$. Indeed, every $\Pi_1^1$-real is "generated" by a simple monotonic function $\Gamma$ (Exercise 8.1.3).
