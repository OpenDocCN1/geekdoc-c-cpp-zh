(ii) if \(\mathfrak{M}\) is a collection of structures and \(A_M \subseteq M\) for \(\mathfrak{M} \in \mathfrak{M}\), then \(\{A_M\}_{\mathfrak{M} \in \mathfrak{M}}\) is \(\mathfrak{F}\)-uniformly definable in \(\mathfrak{M}\) if there is a formula \(\varphi(u)\) in \(\mathfrak{F}\) without parameters such that for any \(\mathfrak{M} \in \mathfrak{M}\), \(x \in A_{\mathfrak{M}}\) if and only if \(\mathfrak{M} \models \varphi(x)\).

Note that for a collection of structures to be uniformly definable, there should be no parameters in the formula defining it.

# 3.1.5 Absoluteness

**Definition 3.1.14.** Given a set of sentences \(\mathfrak{F}\) in \(\mathscr{L}\), we say that two \(\mathscr{L}\)-structures \(\mathfrak{M}\) and \(\mathfrak{N}\) are \(\mathfrak{F}\)-elementarily equivalent, written \(\mathfrak{M} \equiv_{\mathfrak{F}} \mathfrak{N}\), if for every \(\varphi \in \mathfrak{F}\), \(\mathfrak{M} \models \varphi \Leftrightarrow \mathfrak{N} \models \varphi\).

If \(\mathfrak{F}\) is the set of all sentences, then we say that \(\mathfrak{M}\) and \(\mathfrak{N}\) are *elementarily equivalent* and write \(\mathfrak{M} \equiv \mathfrak{N}\).

**Definition 3.1.15.** Given a set of sentences \(\mathfrak{F}\), we say that an embedding \(j\) from \(\mathfrak{M}\) into \(\mathfrak{N}\) is \(\mathfrak{F}\)-elementary and write \(\mathfrak{M} \prec_j^{\mathfrak{F}} \mathfrak{N}\) if for every \(\varphi(\bar{v}) \in \mathfrak{F}\) and finite sequence \(\bar{a} \in M^{<\omega}\), \(\mathfrak{M} \models \varphi(\bar{a}) \Leftrightarrow \mathfrak{N} \models \varphi(j(\bar{a}))\).

If \(\mathfrak{F}\) is the set of all formulas, then we write \(\mathfrak{M} \prec^j \mathfrak{N}\). If \(j\) is the inclusion map, then we write \(\mathfrak{M} < \mathfrak{N}\) and say that \(\mathfrak{M}\) is an *elementary substructure* of \(\mathfrak{N}\), and \(\mathfrak{N}\) is an *elementary extension* of \(\mathfrak{M}\).

**Definition 3.1.16.** Given a class \(\mathfrak{M}\) of structures and a formula \(\varphi(\bar{v})\), (i) \(\varphi\) is \(\mathfrak{M}\)-upward absolute if for every pair \(\mathfrak{M} \subseteq \mathfrak{N}\) in \(\mathfrak{M}\) and any finite sequence \(\bar{a} \in M^{<\omega}\), \(\mathfrak{M} \models \varphi(\bar{a})\) implies \(\mathfrak{N} \models \varphi(\bar{a})\); (ii) \(\varphi(\bar{v})\) is \(\mathfrak{M}\)-downward absolute if for every pair \(\mathfrak{M} \subseteq \mathfrak{N}\) in \(\mathfrak{M}\) and any finite sequence \(\bar{a} \in M^{<\omega}\), \(\mathfrak{N} \models \varphi(\bar{a})\) implies \(\mathfrak{M} \models \varphi(\bar{a})\); (iii) \(\varphi(\bar{v})\) is \(\mathfrak{M}\)-absolute if it is both \(\mathfrak{M}\)-upward and downward absolute.

**Proposition 3.1.17.** Let \(\mathfrak{M}\) be a class of transitive structures. (i) Every \(\Sigma_0\)-formula is \(\mathfrak{M}\)-absolute; (ii) every \(\Sigma_1\)-formula is \(\mathfrak{M}\)-upward absolute; (iii) every \(\Pi_1\)-formula is \(\mathfrak{M}\)-downward absolute. Hence every \(\Delta_1\)-formula is \(\mathfrak{M}\)-absolute.

**Proof.** We prove (i) by induction on the complexity of \(\Sigma_0\)-formulas and leave (ii) and (iii) to the reader. Suppose \(\mathfrak{M} \subseteq \mathfrak{N}\) and \(\varphi(a)\) has the form \((\exists u \in a)\psi(u, a)\) for some \(\Sigma_0\)-formula \(\psi(u, a)\) with \(a \in M\). If \(\mathfrak{M} \models \varphi(a)\), then there exists an \(a' \in M\) such that \(\mathfrak{M} \models \psi(a', a)\). Since \(\mathfrak{M} \subseteq \mathfrak{N}\), by induction \(\mathfrak{N} \models \psi(a', a)\). If \(\mathfrak{N} \models \varphi(a)\), then there exists an \(a' \in N\) such that \(\mathfrak{N} \models \psi(a', a)\). Since \(a' \in a\) and \(a \in M\), by transitivity we have \(a' \in M\). Then by induction, \(\mathfrak{M} \models \psi(a', a)\).
