
- (i) $R_e$ is wellfounded if and only if $f(e) \in \mathcal{O}$.
- (ii) If $R_e$ is wellfounded, then $|R_e| \le |f(e)|$, where $|R_e|$ is the height of $R_e$.

Proof. By the s-m-n Theorem, there is a recursive function $h$ such that

$R_{h(e,k)}(m,n) \Leftrightarrow R_e(m,n) \land R_e(k,m) \land R_e(n,k)$

for all $e, k, m$ and $n$. $R_{h(e,k)}$ is the initial segment of $R_e$ preceding $k$. The idea is to define a one-one, order-preserving map from the field of $R_e$ into $\mathcal{O}$. Fix the recursive function $g$ in Lemma 1.3.5. If $k$ is a minimal element of $R_e$, then $k$ is mapped to an element in $\mathcal{O}$ determined by applying $W_{h(e,k)} = \emptyset$ in Lemma 1.3.5. Otherwise, by induction $R_{h(e,k)}$ is mapped to an r.e. set $W \subset \mathcal{O}$ with index $e'$. By Lemma 1.3.5, $g(e') \in \mathcal{O}$ and $|n| < g(e')$ for all $n \in W$. Hence we may define $f(k) = g(e')$.

We now turn to the formal proof. First of all, there is a recursive function $p$ such that

$W_{p(e)} = \begin{cases} \emptyset & R_e = \emptyset \\ \{ \Phi_c(h(e,k)) \mid k \in \omega \} & \text{Otherwise.} \end{cases}$

Hence there is a recursive function $q$ such that $\Phi_{q(e)}(e) = g(p(e))$. By the Recursion Theorem, there is a fixed point $c$ such that $\Phi_{q(c)} = \Phi_c$. Define

$f(e) = \Phi_c(e)$

and

$p(e) = p(c, e)$.

Then

$W_{p(e)} \text{ wellfounded} = \begin{cases} \emptyset & R_e = \emptyset \\ \{ \Phi_c(h(e,k)) \mid k \in \omega \} = \{ f(h(e,k)) \mid k \in \omega \} & \text{Otherwise.} \end{cases}$

Note that $f(e) = \Phi_c(e) = \Phi_{g(e)}(e) = g(p(c,e)) = g(p(e))$.

Now suppose $R_e$ is wellfounded. If $R_e$ is empty, then by Lemma 1.3.5, $W_{p(e)} = \emptyset \subset \mathcal{O}$ and $f(e) \in \mathcal{O}$. Assume for all wellfounded relations $R_e$ with $|R_e| < \alpha$, (i) and (ii) hold. Fix a wellfounded relation $R_e$ with $|R_e| = \alpha$. Then for each $k$ in the field of $R_e$, $|R_{h(e,k)}| < \alpha$. Hence $W_{h(e,k)} \subset \mathcal{O}$ and $f(h(e,k)) \in \mathcal{O}$. Thus $W_{p(e)} = \{ f(h(e,k)) \mid k \in \omega \} \subset \mathcal{O}$. By Lemma 1.3.5, $f(e) = g(p(e)) \in \mathcal{O}$ and $f(e) > |n|$ for all $n \in W_{p(e)}$. Thus $|f(e)| \ge |R_e|$.

Suppose $f(e) \in \mathcal{O}$. By Lemma 1.3.5, $W_{p(e)} \subset \mathcal{O}$ and $|f(e)| > |f(h(e,n))|$ for all $n$. By induction on $<_{\mathcal{O}}$, $R_{h(e,n)}$ is wellfounded for all $n$. Hence

$R_e = \bigcup_n (R_{h(e,n)} \cup \{ (m,n) \mid R_e(m,n) \land m \in \omega \})$

is wellfounded.

We leave the proof of the next lemma to the reader (Exercise 1.5.1):

### **Lemma 1.4.3.** Every partial recursive well-ordering $R$ is isomorphic to a recursive well-ordering.

The main result of this section states:

### Theorem 1.4.4 (Kleene [71], Markwald [89]). An ordinal is recursive if and only if it is constructive.

Proof. Suppose $R$ is a recursive well-ordering with $|R| = \beta$. By Lemma 1.4.2, there is a constructive ordinal $\gamma \ge \beta$. Hence $\beta$ is constructive. Conversely, if $\beta$ is constructive, then by Theorem 1.3.4, there is a partial recursive well-ordering $R$ with $|R| = \beta$. By Lemma 1.4.3, $\beta$ is recursive.

## 1.5 $\Pi^1_1$-completeness and $\Sigma^1_1$-boundedness

### 1.5.1 $\Pi^1_1$-completeness

### Theorem 1.5.1. $O \in \Pi^1_1$-complete. Hence $O$ is not $\Sigma^1_1$.

Proof. By Lemma 1.4.2, Wf is many-one reducible to $O$. As discussed in §1.1.4, Wf$_0$ is $\Pi^1_1$-complete, hence $O$ as well.

We now consider sets of reals. Suppose $P(x, n)$ is $\Pi^1_1$. By relativizing Theorem 1.5.1, there is a recursive function $f_P$ such that $P(x, n) \Leftrightarrow f_P(n) \in O^x$ for all $n$ and $x$. In particular, a $\Pi^1_1$-predicate $Q(x)$ is $P(x, 0)$ for some $\Pi^1_1$-predicate $P$. Hence $Q(x)$ if and only if $f_Q(0) \in O^x$ for some recursive function $f_Q$. It follows that the set $C = \{(x, n) \mid n \in O^x\}$ is $\Pi^1_1$-universal. In other words, for each $\Pi^1_1$-set $Q$, there is a number $n$ such that $Q = \{x \mid (x, n) \in C\}$. It is not difficult to see that $C$ is not $\Sigma^1_1$. We may also code $C$ into a subset of $2^\omega$ by defining $D = \{0^n1^x \mid n \in O^x\}$. Then $D$ is a $\Pi^1_1$-complete set.

### 1.5.2 $\Sigma^1_1$-boundedness

The next corollary is known as the $\Sigma^1_1$-bounding principle. We will see a number of applications of this principle later.

### Corollary 1.5.2 (Spector [153]). Suppose $x \subseteq O$ and $x \in \Sigma^1_1$. Then there exists an $n \in O$ such that $|m| \le |n|$ for all $m \in x$.

Proof. Otherwise, for each \(\beta < \omega_1^{CK}\) there is an element \(n \in x\) with \(|n| > \beta\).

Since \(\mathbb{O}\) is \(\Pi^1_1\), there is a recursive function \(f\) such that \(n \in \mathbb{O}\) implies \(f(n) \in \text{WF}_0\).

Then \(n \in \mathbb{O}\) if and only if

\((\exists m)(m \in x \land (\exists h \in \omega^\omega)(\forall i)(R_j(f_{i0}(n), j) \rightarrow \langle h(i), h(j) \rangle \in W_{g(m)}))\),

where g is as defined in Theorem 1.3.4. So \(\mathbb{O}\) is \(\Sigma^1_1\), a contradiction.

We now turn to Theorem 1.5.5. This may be viewed as an effective version of Corollary 1.5.2.

### Lemma 1.5.3. There is a recursive function \(f\) such that \(n \in \mathbb{O} \Leftrightarrow f(n) \in \text{WF}_0 \land |n| < |R_{f(n)}|\).

Proof. Since \(\mathbb{O}\) is \(\Pi^1_1\), there is a recursive function \(g\) such that

$n \in \mathbb{O} \Leftrightarrow g(n) \in \text{WF}_0$.

By Theorem 1.3.4, there is a function \(h\) such that \(n \in \mathbb{O}\) implies \(R_{s(n)} = (\langle i, j \rangle | \langle i, j \rangle \in W_{k(n)}), h(n) \in \text{WF}_0\) and \(|n| = |R_{h(n)}|\), where \(k(n)\) is the second function in Theorem 1.3.4. Define a recursive function \(s\) such that \(R_{s(m,n)} =\)

$R_m \oplus R_n = \{\langle i, j \rangle | (i, j \in \text{Even} \land (\frac{i}{2}, \frac{j}{2}) \in R_m) \lor (i, j \in \text{Odd} \land (\frac{i-1}{2}, \frac{j-1}{2}) \in R_n)\}$.

Then

$(m \in \text{WF}_0 \land n \in \text{WF}_0) \Leftrightarrow (s(m, n) \in \text{WF}_0 \land \max\{|R_m|, |R_n|\} \le |R_{s(m,n)}|)$.

So $n \in \mathbb{O} \Leftrightarrow (g(n) \in \text{WF}_0 \land h(n) \in \text{WF}_0) \Leftrightarrow s(g(n), h(n)) \in \text{WF}_0$ and $|n| \le |R_{s(g(n), h(n))}|$. Now let $f(n) = s(g(n), h(n))$.

Given two binary r.e. relations $R_i, R_j$ on $\omega$, define a recursive function $t$ such that $R_{t(i,j)} = R_i \otimes R_j$ where

$R_i \otimes R_j = \{(\langle n_1, m_1 \rangle, \langle n_2, m_2 \rangle) | (n_1, n_2) \in R_i \land (m_1, m_2) \in R_j\}$.

It is easy to verify that $\langle i, j \rangle \in \text{WF}_0 \Leftrightarrow i \in \text{WF}_0 \lor j \in \text{WF}_0$ and that $\min\{|R_i|, |R_j|\} \le |R_{t(i,j)}|$. We have the following corollary.

### Corollary 1.5.4. There is a recursive function \(p\) such that

$(\forall n)(\forall m)(n \in \mathbb{O} \lor m \in \mathbb{O}) \Leftrightarrow p(m, n) \in \mathbb{O}$,

and if $p(m, n) \in \mathbb{O}$ then

$\min\{|n|, |m|\} \le |p(m, n)|$,

where $|m| = \infty$ for $m \notin \mathbb{O}$.

Proof. Let $f_0$ be the recursive function $f$ in Lemma 1.4.2, $f_1$ be the recursive function $f$ in Lemma 1.5.3 and let $t$ be as above. Then the function $p(i, j) = f_0(\langle t(f_1i, f_1j) \rangle)$ is exactly what is required.

Given a standard enumeration $\Phi_e(n, m, y)$ of partial recursive functions, there is an enumeration $\{x_e\}_{e < \omega}$ of $\Sigma^1_1$-reals such that $n \in x_e \leftrightarrow (\exists y)(\forall m)(\Phi_e(n, m, y) \downarrow \rightarrow \Phi_e(n, m, y) \neq 0)$. We have the following effective version of Spector's $\Sigma^1_1$ boundedness principle.

### Theorem 1.5.5 (Sacks). There is a recursive function \(\hat{g}\) such that

$(\forall n)(x_n \subseteq \mathbb{O} \rightarrow \hat{g}(n) \in \mathbb{O} \wedge x_n \subseteq \mathbb{O}_{\hat{g}(n)})$,

where $\mathbb{O}_{\hat{g}(n)} = \{m \in \mathbb{O} \mid |m| < |\hat{g}(n)|\}$.

Proof. Since the set $\{m \mid m \notin \Pi^1_1\}$ is in $\Pi^1_1$, there is a recursive function $h$ such that $m \in x_n \leftrightarrow h(m, n) \notin \mathbb{O}$. Let $p$ be the function in Corollary 1.5.4. Define a recursive function $f$ such that $W_{f(n)} = \{p(h(m, n), m) \mid m \in \omega\}$. If $x_n \subseteq \mathbb{O}$, then $W_{f(n)} \subseteq \mathbb{O}$. Let $\hat{g}(n) = 20^{\overline{f(n)}}$ where $\overline{g}$ is the function in Lemma 1.3.5. By Lemma 1.3.5, $x_n \subseteq \mathbb{O} \implies \hat{g}(n) \in \mathbb{O}$. If $\hat{g}(n) \in \mathbb{O}$, then by Lemma 1.3.5 again, $W_{f(n)} \subseteq \mathbb{O}$. But $h(m, n) \notin \mathbb{O}$ for all $m \in x_n$. Then by Corollary 1.5.4, $m \in \mathbb{O}$ for all $m \in x_n$ and hence $x_n \subseteq \mathbb{O}$. Moreover, if $x_n \subseteq \mathbb{O}$, then $m \in x_n \implies h(m, n) \notin \mathbb{O} \implies |m| \le |p(h(m, n), m)|$.

By Theorem 1.5.1, every $\Pi^1_1$-set is many-one reducible to $\mathbb{O}$. Hence we may view $\mathbb{O}$ as providing the stages for enumerating a $\Pi^1_1$-set (this view will become clearer after the set $\mathbb{O}_1$ is introduced). Hence it is natural to think of a $\Pi^1_1$-set as analog of a $\Sigma^0_1$ (i.e. recursively enumerable) set. Now if one considers a "finite set" to be one whose members are all enumerated by some stage \(\beta < \omega_1^{CK}\), then Spector's boundedness principle says that any \(\Delta^1_1\)-set is "finite". We shall make this precise with the introduction of admissible set theory.

In terms of definability, one would expect a big gap between possible order types of a recursive ordering and a \(\Sigma^1_1\)-ordering. The following observation says otherwise.

### Proposition 1.5.6. Suppose \(R\) is a \(\Sigma^1_1\) well-ordering relation on \(\omega\). Then \(|R| < \omega_1^{CK}\).

Proof. Suppose \(|R| \ge \omega_1^{CK}\). Then $n \in W\mathbf{f}_0 \leftrightarrow (\exists \beta)(\forall i)(\forall j)(R_\alpha(i, j) \rightarrow R(h(i), h(j)))$. This implies that $W\mathbf{f}_0$ is \(\Sigma^1_1\) which is a contradiction.

### Remark 1.5.7. For sets of reals, there is a boundedness principle for \(\Delta^1_1\)-sets. As discussed in §1.1.4, for each \(\Pi^1_1\)-set \(A\) of reals, there is a recursive function \(f : \omega^\omega \rightarrow \omega^\omega\) such that \(x \in A \Rightarrow f(x) \in \mathbf{wO}\). Then if \(A\) is \(\Delta^1_1\), by the same argument as in the proof of Proposition 1.5.6, the supremum \(\beta = \sup\{f(x) \mid x \in A\}\) of \(f(A)\) is less than \(\omega_1^{CK}\).

For \(\Sigma^1_1\) well-orderings of reals, by the same argument as in the proof of Corollary 1.5.2, each such well-ordering has order type less than \(\omega_1^{CK}\).
