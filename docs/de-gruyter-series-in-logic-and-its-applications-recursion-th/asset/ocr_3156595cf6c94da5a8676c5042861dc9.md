# 12.2.1 Plain Kolmogorov complexity

**Definition 12.2.1** (Solomonoff [146] and Kolmogorov [73]). Given a Turing machine $M$ and a finite string $\sigma \in 2^{<\omega}$, the $M$-Kolmogorov complexity of $\sigma$, $C_M(\sigma)$, is $\min\{|\tau| \mid M(\tau) = \sigma\}$.

If $U$ is a universal Turing machine, then for any Turing machine $M$, there is a constant $c_M$ such that \((\forall \sigma)(C_U(\sigma) \le C_M(\sigma) + c_M)\).

In other words, $C_U$ is optimal up to a constant. We drop the subscript $U$ and use $C$ to denote the plain Kolmogorov complexity function $C_U$. Then one may define a real x to be random if there is a constant $c$, such that \((\forall n)(C(x \mid n) \ge n - c)\). However, for any x and n, $x \mid \text{Code}(x \mid n)$ (where Code(x) is the natural number that codes a string $\sigma$) may be obtained from a final segment (say $\sigma$) of $x \mid \text{Code}(x \mid n)$ of length Code(x | n) - n via U. This is because once $\sigma$ is known, one may find a unique string $\tau$ such that $\tau$ codes $\tau$, i.e., $|\tau^\frown \sigma| = \text{Code}(\tau)$. Then $|\tau| = n$ and $\tau^\frown \sigma = x \mid \text{Code}(x \mid n)$. Thus we have $|\tau^\frown \sigma|$ following.

**Proposition 12.2.2** (Martin-Löf). For any real x, $\lim_{n} n - C(x \mid n) = +\infty$.

Proposition 12.2.2 says that there is no random real in the sense of plain Kolmogorov complexity leading to the next definition introduced by Levin and Chaitin.

**Definition 12.2.3.** (i) A set $A \in 2^{<\omega}$ is *prefix-free* if for any $\sigma \prec \tau \in 2^{<\omega}$, either $\sigma \notin A$ or $\tau \notin A$. (ii) A Turing machine $M$ is *prefix-free* if its domain is a prefix-free set.

**Definition 12.2.4** (Levin[83] and Chaitin [9]). Given a prefix-free Turing machine $M$ and a string $\sigma \in 2^{<\omega}$, the $M$-Kolmogorov complexity of $\sigma$, $K_M(\sigma)$, is $\min\{|\tau| \mid M(\tau) = \sigma\}$.

It is not difficult to see that there is a universal prefix-free Turing machine U and we use $K(\sigma)$ to denote $K_U(\sigma)$. The following technical theorem points a way to constructing a prefix-free machine.

**Theorem 12.2.5** (Levin[83] and Chaitin [9] and Schnorr [126]). Let $\{\langle d_i, \tau_i \rangle\}_{i < \omega} \subseteq \omega \times 2^{<\omega}$ be a recursive sequence such that $\sum_{i < \omega} 2^{-d_i} \le 1$. There exist a prefix-free machine M and strings $\sigma_i$ of length $d_i$ such that $M(\sigma_i) = \tau_i$ for all i and $\text{Dom}(M) = \{\sigma_i \mid i < \omega\}$. Furthermore, an index for M may be obtained effectively from an index for the sequence.

The following result summarizes some basic properties of K.

**Theorem 12.2.6** (Chaitin). (i) $\sum_{\sigma \ge \omega} 2^{-K(\sigma)} \le 1$; (ii) $|\exists \sigma (\forall \sigma)(K(\sigma) \le |\sigma| + K(|\sigma|) + c)$; (iii) $(\exists c)(\forall n)(\forall k)(|\{\sigma \in 2^n \mid K(\sigma) \le n + K(n) - k\}| \le 2^{n-k+c})$.
