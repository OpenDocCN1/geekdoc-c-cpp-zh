such a pair \((x, y)\). Define \(\sigma_{i+1} = x \uparrow (|\sigma_i| + 1)\) and \(\tau_{i+1} = y \uparrow (|\tau_i| + 1)\). Let

```
\(G_{i+1} = \{x \in F_{i+1} \mid x > \sigma_{i+1} \land (\exists y > \tau_{i+1})(\forall n)((x \upharpoonright n, y \upharpoonright n) \in T)\}.\)
```

Then \(G_{i+1}\) is a nonempty \(\Sigma_1^1\)-subset of \(F_{i+1}\) and hence of \(P_{i+1}\). Let \(x(i) = m\) if and only if \(\sigma_{i+1}(i) = m\) and \(y(i) = m\) if and only if \(\tau_{i+1}(i) = m\). Then for all \(i, x \in G_i\) and for all \(n, (x \upharpoonright n, y \upharpoonright n) \in T\). Hence \(x \in P \cap \bigcap_{n < \omega} P_i\).

As a consequence of Proposition 1.11.2, we may define the Gandy topology as follows.

**Definition 1.11.13.** The Gandy topology on \(\omega^\omega\) is the topology generated by taking all \(\Sigma_1^1\)-sets as basic open sets.

Proposition 1.1.12 implies that the Gandy topology satisfies the Baire category theorem: The intersection of a countable collection of dense open sets is dense.

# 1.1.4 \(\Pi_1^1\)-sets of reals

By Proposition 1.1.9, we have the following:

**Proposition 1.1.14.** A predicate \(P(x, m)\) is \(\Pi_1^1\) if and only if there is a recursive sequence of recursive trees \(T_m \in \omega^{<\omega} \times \omega^{<\omega}\) such that \(P(x, m) \leftrightarrow (\forall y)(\exists n)((x \upharpoonright n, y \upharpoonright n) \notin T_m)\).

For each real \(x\), define a binary relation \(\le_x\) on \(\omega\) such that \(m \le_x n\) if and only if \(x(<m, n>) = 1\). Define

```
\(WF_1 = \{x \in \omega^\omega \mid \le_x \text{ is a wellfounded relation}\}.\)
```

Then \(x \in WF_1\) if and only if

```
\((\forall f \in \omega^\omega)[(\forall n)(\forall m)(n \ge m \rightarrow f(n) \le f(m)) \rightarrow (\exists m)(\forall n)(\forall k)(n > m \land k > m \rightarrow f(n) = f(k))],\)
```

so that \(WF_1\) is a \(\Pi_1^1\)-set of reals. Fix a standard effective enumeration \(\{\sigma_n\}_{n < \omega}\) of \(\omega^{<\omega}\). We say that \(x\) codes a tree relation if

```
\(m \le_x n \leftrightarrow \sigma_m \succeq \sigma_n.\)
```

Now let \(P\) be a \(\Pi_1^1\)-set of reals and let \(T\) be a recursive tree such that \(x \in P \leftrightarrow (\forall y)(\exists n)((x \upharpoonright n, y \upharpoonright n) \notin T)\). Define \(T_x = \{\sigma \mid (|\sigma|, |\sigma|) \in T\}\). Then \(x \in P\) if and only if \(T_x\) is wellfounded. Define the Kleene-Brouwer ordering \(<_{KB}\) on strings so that for any \(\sigma, \tau \in \omega^{<\omega}\), \(\sigma <_{KB} \tau\) if and only if

```
\(\sigma \succ \tau (\exists i \le \min[|\sigma|, |\tau|])(\sigma \upharpoonright i = \tau \upharpoonright i \land \sigma \upharpoonright i \prec \tau(i)).\)
```

In other words, \(\sigma \prec_{KB} \tau\) whenever either \(\sigma\) extends \(\tau\) or \(\sigma\) is "to the left" of \(\tau\). Then for each \(x\), \(x\) codes a wellfounded tree if and only if \(x\) codes a well-ordering under \(<_{KB}\).
