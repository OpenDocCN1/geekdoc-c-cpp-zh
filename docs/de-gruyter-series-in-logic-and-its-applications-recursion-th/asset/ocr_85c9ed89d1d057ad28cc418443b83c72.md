The collection P of forcing conditions we consider here are relatively simple, such as finite binary strings or hyperarithmetically encoded perfect sets. A forcing relation ⊩ is a binary relation that is a subset of P × {φ | φ is a formula in L(ω1CK, x)}. The objective is to make ⊩ as simply defined as possible. For example, to be hyperarithmetic when the formula φ being forced is ranked, or Π11 when φ is Σ11. The generic set x will be a real that is obtained from a collection of pairwise compatible conditions through a union or intersection operation. The model A(ω1CK, x) is then a generic extension of A(ω1CK, ω). We always make A(ω1CK, x) satisfy Δ11-comprehension so that ω1x = ω1CK. With this, one can construct generic x’s with a prescribed property.

# 5.2.1 Cohen forcing

A Cohen condition p is a finite string σ ∈ 2<ω which may be identified with the basic open set [σ]. Define a partial ordering ≤ such that p ≤ q if and only if p ⊇ q.

Given formulas φ(x) and ψ(n), denote by φ(x | ψ) the formula obtained upon replacing every occurrence of n ∈ x in φ with ψ(n) and every occurrence of n ∉ x in φ with ¬ψ(n).

For a sentence φ ∈ L(ωCK, x), define p ⊩ φ by induction on the complexity of φ:

+   - p ⊩ ň ∈ x if and only if p(n) = 1;
+   - p ⊩ t1 = t2 if and only if A(ω1CK, 0) ⊨ t1 = t2, where t1, t2 are terms involving only numerals and arithmetic operations;
+   - p ⊩ t ∈ x if and only if A(ω1CK, 0) ⊨ t = ň for some n and p ⊩ ň ∈ x, where t is a term involving only numerals and arithmetic operations;
+   - p ⊩ (∃n)ψ(n) if and only if p ⊩ ψ(ň) for some n ∈ ω;
+   - p ⊩ (∃β < ω2^CK)φ̇ if and only if p ⊩ φ(ω̇β | ψ) for some ranked formula ψ(ň) with rank at most β;
+   - p ⊩ (∃β)ω(p) if and only if p ⊩ (∃β < ω2^CK)φ(ω̇β) for some β < ω1CK;
+   - p ⊩ φ ∨ ψ if and only if p ⊩ φ and p ⊩ ψ;
+   - p ⊩ ¬φ if and only if ∀q ≤ p(q ∥ φ ∨ p).
