n \notin x \Rightarrow \mu(y > \sigma | \mathfrak{A}(\omega_1^{CK}, y) \equiv \neg \varphi(n))) > \frac{1}{2} \cdot 2^{-|n|}.

By Lemma 13.1.1, x is hyperarithmetic, which is a contradiction.

It is also known that the statement “\(\mu(A) > p\)” is r.e. if A is an r.e. set of reals and p is rational. The following corresponding result holds in hyperarithmetic theory.

**Proposition 13.1.6** (Sacks [123]). Let \(A \subseteq \omega \times 2^\omega\) be \(\Pi_1^1\) and \(A_n = \{x | (n, x) \in A\}\). Then \(\{(n, p) \mid p \text{ is rational} \land \mu(A_n) > p\}\) is \(\Pi_1^1\).

Proof. Since A is \(\Pi_1^1\), by Corollary 3.7.4 there is an arithmetical formula \(\varphi(n, x, z)\) such that

\((n, x) \in A \Leftrightarrow (\exists z \leqslant_{\text{h}} x) \varphi(n, x, z).\)

Let \(B = \{(n, x) | \mathfrak{A}(\omega_1^x, x) \equiv (\exists i)(\varphi(n, x, z) \leqslant i\}\). By Theorem 13.1.4 for every n, \(\mu(B_n) = \mu(\{x | (n, x) \in B\}) = \mu(A_n)\). By Corollary 13.1.2, \(\mu(B_n) > p\) if and only if

\((\exists i)(\mu(B_n) \ge p + 2^{-i})\)

if and only if

\((\exists i)(\exists m)(m \in \omega_1 \land \mu(\{x | \mathfrak{A}(\omega_1^{CK}, x) \equiv (\exists z^{\le m}) \varphi(n, x, z^{\le m})\}) \ge p + 2^{-i}).\)

By Lemma 13.1.1, it follows that the set \(\{(n, p) | \mu(A_n) > p \land p \text{ is rational}\}\) is \(\Pi_1^1\).

The following result was proved by Kechris in [63] under the assumption of PD. It turns out that the additional assumption can be weakened.

**Corollary 13.1.7** (Kechris [63]). Assume that \(\omega_1^x < \omega_1\). Given a \(\Sigma_2^1\)-set \(A \subseteq 2^\omega\), both \(\{p \in \mathbb{Q} | \mu(A) > p\}\) and \(\{p \in \mathbb{Q} | \mu(A) \ge p\}\) are \(\Sigma_2^1\).

Proof. By assumption, almost every real is R-generic over L (see § 6.2.2). Note that for any x that is R-generic over L, \(L_1^{\omega_1^x} = \omega_1^x\). Since A is \(\Sigma_2^1\), there is a \(\Pi_1^1\) relation R such that

\(x \in A \Leftrightarrow (\exists y \in L_{\omega_1^x}[x]) R(x, y).\)

Then \(\mu(A) > p\) if and only if there is an ordinal \(\beta < \omega_1^x\) such that \(\mu(\{x | (\exists y \in L_\beta[x]) R(x, y)\}) > p\). Thus \(\mu(A) > p\) if and only if there is a real \(r \in L\) coding a well-ordering of order type \(\beta\) such that \(\mu(\{x | (\exists y \in L_\beta[x]) R(x, y)\}) > p\). By Proposition 13.1.6, the latter is a \(\Sigma_2^1\) statement.

The second part of the corollary follows immediately from the first.

By the proof of Corollary 13.1.7, we have the following conclusion.

**Corollary 13.1.8.** If \(\omega_1^x < \omega_1\), then every \(\Sigma_2^1\)-set is measurable.

**Proposition 13.1.9** (Kechris [63]). Suppose that \(\omega_1^x < \omega_1\). For any x, if \(\{y | x \leqslant_{\Delta_1^1} y\}\) is not null, then x is \(\Delta_2^1\).
