There is no difficulty dealing with only one limit ordinal. With more than one limit ordinal, one of them has to be chosen for coding. For convenience, in the rest of this section let $[n] = \beta_{\infty}$ and identify each natural number $\le_o n$ with the ordinal $\beta < \beta_{\infty}$ of which it is an ordinal notation. ## Lemma 11.2.8.

Suppose that $\lambda \in \Lambda(\beta)$ with $\beta_{j, \lambda} \le_o \beta$ for some $j$. Then $(\sigma, \tau) \in T_\beta \cap \omega^{S(j)} \times \omega^{S(j)}$ if and only if there exists a $(\sigma, \bar{\tau}) \in T_\lambda$ such that $p_{\beta, \lambda}(\bar{\tau}) = \tau$.

$$
p_{\beta, \lambda}(p_{\lambda, \lambda_1}(\bar{\tau}_1)) = p_{\beta, \lambda_1}(\bar{\tau}_1) = \tau,

## Lemma 11.2.9.

Let $\delta \le_o \beta_{c, o}$.

- (i) If $\beta \le_o \delta$, then $\psi_{\delta, \beta}$ is well defined.
- (ii) For $\beta \le_o \beta_1 \le_o \delta$, $\psi_{\delta, \beta} = \psi_{\beta_1, \beta} \circ \psi_{\delta, \beta_1}$.
- (iii) For $\beta \le_o \delta$ and $\sigma, \tau \in T_\beta^\infty$, $\sigma \le_T \psi_{\delta, \beta}(\sigma) \succeq \psi_{\delta, \beta}(\tau)$. Moreover, $|\psi_{\delta, \beta}(\sigma)| \ge |\sigma|$.
- (iv) There is a recursive function $g$ such that for each $\beta \le_o \delta$, $\psi_{\delta, \beta} = g^{\psi_{\delta, \beta}(\beta)}$.

Proof. We prove (i) and (ii) simultaneously by induction on $\delta$. By the definition of $\psi_{\delta, \beta}$, the only nontrivial case is when $\delta = \lambda$ for some limit ordinal $\lambda$.

For (i), fix $\alpha <_o \lambda$ and $\beta \le_o \beta_{j_0, \lambda} <_o \beta_{j_1, \lambda} <_o \lambda$ for $j_0 < j_1$. Suppose that $\sigma \in T_\lambda^\infty \cap \omega^{<j_0}$ and $j_0$ is used to define $\psi_{\lambda, \beta}(\alpha)$. By (2) and Lemma 11.2.8, $\sigma \in T_{\beta_{j_0, \lambda}}^\infty \cap T_{\beta_{j_1, \lambda}}^\infty$. Note that for any $\gamma$ with $\beta_{j_0, \lambda} <_o \gamma \le_o \lambda$, we have $\lambda \in \Lambda(\gamma)$ and $j(\gamma) \ge j_0$. By (6) and an induction on $\gamma$ in $(\beta_{j_0, \lambda}, \lambda]$, $\psi_{\gamma, \beta_{j_0, \lambda}}(\sigma) = \sigma$. By the same argument, for $\gamma$ in $(\beta_{j_1, \lambda}, \lambda]$, we have $\psi_{\gamma, \beta_{j_1, \lambda}}(\sigma) = \sigma$. Hence by induction on $\beta$, $\psi_{\lambda, \beta}(\sigma) = \psi_{\beta_{j_0, \lambda}, \beta}(\psi_{\lambda, \beta_{j_0, \lambda}}(\sigma)) = \psi_{\beta_{j_0, \lambda}, \beta}(\psi_{\beta_{j_1, \lambda}, \beta_{j_0, \lambda}}(\sigma)) = \psi_{\beta_{j_1, \lambda}, \beta}(\psi_{\lambda, \beta_{j_1, \lambda}}(\sigma)) = \psi_{\beta_{j_1, \lambda}, \beta}(\sigma)$. Thus $\psi_{\delta, \beta}$ is well defined.

For (ii), given let $j$ be such that $|d| < j$ and $\beta \le_o \beta_1 <_o \beta_{j, \lambda} \le_o \lambda$. Then $\psi_{\lambda, \beta_1}(\sigma) = \sigma$. By the definition of $\psi_{\lambda, \beta_1}$, $\psi_{\lambda, \beta}(\sigma) = \psi_{\beta_1, \beta}(\sigma)$. Then by induction, $\psi_{\beta_1, \beta}(\sigma) = \psi_{\beta_1, \beta}(\psi_{\lambda, \beta_1}(\sigma))$.

We obtain (iii) by using (5i) and (5ii) and an induction on $\beta$. Finally, (iv) follows from (3).

If $x \in [T_\beta^\infty]$, let $\psi_{\beta, \delta}(x) = \cup_{m < \omega} \psi_{\beta, \delta}(x \upharpoonright m)$. By Lemma 11.2.9 (iii), $\psi_{\delta, \beta}$ is well defined.
