# Theorem 1.3.4 (Kleene [71]). There are two recursive functions f and g such that for all $n \in \omega$,

+   (i) $W_{f(n)} = \{m \mid m <_\omega n\}$,

+   (ii) $W_{g(n)} = \{(i, j) \mid i <_\omega j <_\omega n\}$.

Proof. (i) By the s-m-n Theorem, there are two recursive functions p, q such that

```
$$W_{p(e, m)} = \{m\} \cup W_{\phi_e(m)},$$
$$W_{q(e, m)} = \bigcup \{W_{\phi_i(\phi_e(n))} \mid n \in \omega\}.$$
```

Fix $e_0$ such that $W_{e_0} = \emptyset$. Define a recursive function h as follows:

```
$$\Phi_{h(e)}(n) = \begin{cases} e_0 & n = 1, \\ p(e, k) & n = 2^k, \\ q(e, k) & n = 3 \cdot 5^k, \\ 0 & \text{Otherwise.} \end{cases}$$
```

By the Recursion Theorem, there is a constant c such that $\Phi_{h(c)} = \Phi_c$. Set $f = \Phi_c$.

Then

```
$$f(n) = \begin{cases} e_0 & n = 1, \\ p(c, k) & n = 2^k, \\ q(c, k) & n = 3 \cdot 5^k, \\ 0 & \text{Otherwise.} \end{cases}$$
```

Obviously f is total since both p and q are total. Then

```
$$W_{f(n)} = \begin{cases} \emptyset & n = 1, \\ \{k\} \cup W_{f(k)} & n = 2^k, \\ \bigcup \{W_{\phi_i(\phi_e(n))} \mid m \in \omega\} & n = 3 \cdot 5^k, \\ 0 & \text{Otherwise.} \end{cases}$$
```

An easy induction shows that $W_{f(n)} = \{m \mid m <_\omega n\}$ for each $n \in \omega$.

(ii) By the s-m-n Theorem, there are two functions p and q such that

```
$$W_{p(e, m)} = \{(i, j) \mid i \in W_{f(m)}\} \cup W_{\phi_e(m)},$$
$$W_{q(e, m)} = \bigcup \{W_{\phi_i(\phi_e(n))} \mid n \in \omega\},$$
```

where f was defined in (i). Fix $e_0$ so that $W_{e_0} = \emptyset$. Let

```
$$\Phi_{h(e)}(n) = \begin{cases} e_0 & n = 1, \\ p(e, k) & n = 2^k, \\ q(e, k) & n = 3 \cdot 5^k, \\ 0 & \text{Otherwise.} \end{cases}$$
```

By the Recursion Theorem, there is a constant c such that $\Phi_{h(c)} = \Phi_c$. Set $g = \Phi_c$.

Hence

```
$$g(n) = \begin{cases} e_0 & n = 1, \\ p(c, k) & n = 2^k, \\ q(c, k) & n = 3 \cdot 5^k, \\ 0 & \text{Otherwise.} \end{cases}$$
```
