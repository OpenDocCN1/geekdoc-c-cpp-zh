Note that "/" is used to divide two integers, its result is the integral part of the quotient, and the fractional part is automatically discarded. Therefore, the result of the expression 1/2 is 0.

In addition, ++ (increment) and -- (decrement) are two operators that are easy to use and efficient in C++. They both are unary operators and have two forms: pre- and postfix. For example: i++, --i, and so on. Both forms will (subtract) 1 to the operand, and then rewrite the location of the operand in memory. For example, if the original value of i is 1, after computing the expression i++ it is 2 and the value of i will also change to 2. If the original value of j is 2, then computing the expression --j, the result of the expression is 1 and the value of j will change to 1. However, when the result of increment and decrement are used to continue participating in other operations, the preposition and postfix are totally different. For example, if the value of i is 1, the result of the following two are not the same:

```
cout++; // First output the value of i (which is 1), then do
// the increment, the value of i changes into 2
cout++; // First increase i to 2, then output the value of i
// (which is now 2)
```

# 2. Assignment Operators and Assignment Expressions

C++ provides several assignment operators, in which the simplest is "=". Expressions with assignment operators are called assignment expressions. For example, n=n+5 is an assignment expression. An assignment expression assigns the value of the expression on the right side to the left side. The type of the assignment expression is the same as the type of the object on the left side, and its result is the object's value after the assignment. The assignment operators associate from right to left. See the following assignment expressions:

+   a=5 Expression value is 5.
a=b=c5 Expression value is 5; a, b, c are 5. The expression operates from right to left: after c was updated to 5, the value of expression c=5, then b is updated to 5, and a is assigned to last.
a=5+(c=6) Expression value is 11, a is 11, c is 6.
a=(b+4)+(c=6) Expression value is 10, a is 10, b is 4, c is 6.
a=(b+10)/(c=2) Expression value is 5, a is 5, b is 10, c is 2.

Besides "=", C++ provides 10 kind of compound assignment operators: +=, -=, *= /=, %, <<, >>, &=, ^, and |=. The first five are compound assignment operators and arithmetic operators, while the rest are compounded by assignment operators and bitwise logical operators.
