# Chapter 11: I/O Stream Library and Input/Output

This chapter introduces the concept of stream, as well as the structure and usage of the stream library. Like C, there is no Input/Output statement in C++. However, the compiler of C++ is an object-oriented I/O software packet, which is the I/O stream library.

# Chapter 12: Exception Handling

This chapter focuses on the exception handling. Exception is a kind of program-defined error. In C++, exception handling refers to a set of implementation mechanisms that handles predicted errors in the runtime of programs. *Try, throw and catch* are the mechanisms in C++ to implement exception handling. With the exception handling of C++, programs can deliver unexpected events to exception contexts at higher levels, and thus better recover from these exceptions.
