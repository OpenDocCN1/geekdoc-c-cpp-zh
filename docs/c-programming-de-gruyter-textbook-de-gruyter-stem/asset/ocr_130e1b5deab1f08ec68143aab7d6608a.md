Example 3.6: Game of casting dice.
Game rules: Dice has six faces — counting by the points, they are 1, 2, 3, 4, 5, and 6. The player inputs an unsigned integer, and the seed is what is used to generate a random number at the beginning of the program.

In each turn the dice is cast twice, and we can get the total number of points. In the first turn, if the total number of points is 7 or 11, the player wins and the game is over; if the point is 2, 3, 12, the player loses and the game is over; otherwise the player records the total point as his. In the following turns, if the total number is equal to the player's point, the player wins and the game is over; if the point total is 7, the player loses and the game is over; otherwise, it goes to the next round.

The function roledice to simulate rolling the dice, getting the total point, and outputting it.

> Note: The system function rand(void) generates a pseudorandom number. The pseudorandom number is not really random. When we call this function continuously in a program that it will generate a sequence of random numbers, we discover that it will generate the same sequence each time we run the program. This sequence is called a pseudorandom number sequence. It is because rand needs an initial seed called "seed", and different seeds will generate different sequences. Thus, if we give the program a different seed in each run, continuously calling rand will generate a different random number sequence. If the seed is not set, rand will use the default value 1 as the seed. Note that the method for setting the seed is somewhat special: it is not through the parameters of rand, but by calling another function srand(unsigned int seed) to set the seed before calling rand, and the parameter seed in the function rand is the seed of rand.
