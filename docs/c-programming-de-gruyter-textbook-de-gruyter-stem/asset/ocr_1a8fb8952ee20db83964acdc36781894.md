**Example 2.9:** Write a program that can output the following pattern:

```
*
***
*****
******
*****
***
*
```

Source code:

```
//2_9.cpp
#include<iostream>
using namespace std;
int main()
{
    int i,j,n=4;
    for(i=1;i<=n;i++) //output the first 4 rows of pattern
        for(j=1;j<=30;j++) //set the 30 columns on the left of the
            cout<<' '; //pattern as empty

    for(j=1;j<=8*i-1 ;j++)
        cout<<'*';
    cout<<endl;
}
```
