# ### 9.3.3 Exchange Sort

The idea of exchange sort is to pair elements in the collections and exchange if they are disordered. Bubble sort is a good example.
The Following is the algorithm of bubble sort for operating on an array with n elements:

+   - Check the first and the second element, exchange them if they are not in the right order. Do this similarly for the second and the third one, and so on until the last one is reached. The whole procedure is called the first stage of bubble sort. After the procedure, the maximum is at the $n$-th position.
- Repeat the first step with the $n-1$ elements. After the procedure, the maximum of these $n-1$ elements is at $n-1$ position.
- Repeat the second step until no element appears in a stage of bubbling sort. For an $n$-element collection, bubbling sort requires $n-1$ stages at most.
