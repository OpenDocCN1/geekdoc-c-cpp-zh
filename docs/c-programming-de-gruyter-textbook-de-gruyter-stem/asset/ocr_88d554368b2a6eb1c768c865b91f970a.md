# 3. switch Statement

In some problems, though there need to be multiple selections, each judgment evaluates the same expression, and thus it is not necessary to calculate the value of the expression in each nested if statement. The switch statement is designed to solve this problem in C++. The syntax is:

```
switch (expression)
  case constant expression 1: statement 1
    case constant expression 2: statement 2
    ...
    case constant expression n: statement n
  default : statement n+1
}
```
