# 9.2.2 Direct Accessible Linear Collection – Array

Static arrays were discussed in Chapter 6. The static array has a fixed number of elements, which can be accessed directly by subscripts. It is impossible to modify the size of a static array and there is no built-in mechanism to deal with the out-of-bound problem.

Now we propose a class template Array to deal with these problems. Array contains a number of consecutive elements of the same type, and its size can be changed on demand.
