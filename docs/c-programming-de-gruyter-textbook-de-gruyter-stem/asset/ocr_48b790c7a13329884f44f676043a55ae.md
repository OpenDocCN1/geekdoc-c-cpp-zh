# 7.6.2 Analysis of the Program Design

We can see from the above analysis that the main task in this example is the matrix calculation. We can define a class Matrix as the base class, and then derive a linear equation class Lineq from Matrix. The class Matrix only deals with n × n square matrices and stores matrix using a one-dimensional array. The data members of class Matrix include the starting address of the one-dimensional array and the variable n. The functions of class Matrix include setMatrix() for setting the matrix value, printMatrix() for displaying the matrix, and so on.

According to the analysis, besides the coefficient matrix A inherited from class Matrix, the linear equation class Lineq should also include the starting address of solution vector x and vector b. The primary functions of class Lineq include setLine() for setting equations, printLine() for displaying equations, Solve() for solving equations, and showX() for outputting the solution. We define new members in class Lineq to implement these functions for solving equations.

The composition of classes Matrix and Lineq and their relations are shown in Figure 79.

The member function Solve of class Lineq needs to access the data members of base class Matrix when solving the equations. We use public derivation and set the access attributes of the data members in class Matrix as protected. Thus, after the public derivation, protected members in the base class are still protected members in the derived class and can be accessed by derived-class functions.
