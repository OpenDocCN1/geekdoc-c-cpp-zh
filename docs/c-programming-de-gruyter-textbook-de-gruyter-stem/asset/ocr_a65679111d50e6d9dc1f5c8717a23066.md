# 6.3 Dynamic Memory Allocation 239

In the main() function

Using the new operator can also create multidimensional arrays, and the format is follows:

```
new type name[subscript expression 1][subscript expression 2]...
```

"Subscript expression 1" can be any expression so long as its result is a positive, while other subscript expressions must be constant expressions whose results are positive integers. If the memory allocation is successful, the new operation will return a pointer to points to the starting address of the newly allocated memory space. Note that this pointer is not a T-type pointer, but rather a T-type array. The number of array elements is the product of all subscript expressions besides the first. For example,

```
float *fp;
fp = new float[10][25][10];
```

will in an error. This is because the new operation generates a pointer that points to a 25x10 two-dimensional array of float type, but fp is a pointer that to a data variable of the float type. The correct form is

```
float (*cp)[25][10];ncp = new float[10][25][10];
```

The pointer cp can be used as a pointer or a three-dimensional array name. Please see the following program.
