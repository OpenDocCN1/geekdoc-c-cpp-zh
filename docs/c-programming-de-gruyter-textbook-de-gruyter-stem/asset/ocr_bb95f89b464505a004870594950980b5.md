# Example 6.5: Declaration, assignment, and use of pointers.

```
///6_5.cpp
#include <iostream>
using namespace std;
int main()
{
    int *i_pointer;      //declare pointer i_pointer of int type
    int i;               //declare variable i of int type
    i_pointer=&i;       //assign the address of i to i_pointer
    i=10;                //initialize the variable of i of int type
    cout<<"Output i="<<i<<endl; //Output the value of the int-type
                         //variable

    cout<<"Output pointer i="<<*i_pointer<<endl;
    //Output the content of the address that the pointer of int type
    //points to
}
```

The result of the program is:

| Output i=10 |
| Output int pointer i10 |

Let us analyze the running process of the program. In the program, it first declares a pointer i_pointer of int type; then it declares an int variable i and uses address-of operator to get the address of i. Next it assigns this address to the pointer i_pointer and assigns 10 to i. The states of related variables at this time can be simply described in Figure 6.7. Here, we suppose the memory addresses of i and i_pointer are 3000 and 2000 respectively.
