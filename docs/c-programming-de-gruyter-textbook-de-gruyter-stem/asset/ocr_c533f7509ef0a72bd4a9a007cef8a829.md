# 6.1.2 Storage and Initialization of Arrays

+   1. Storage of Arrays

Array elements are stored ordered and continuously in memory. They occupy a group of consecutive storage locations in memory. Elements that are logically adjacent are physically adjacent. The array name represents the starting address of array elements. The elements of a one-dimensional array are simply stored ordered and continuously according to their subscripts. Elements of a multidimensional array are also stored ordered and continuously, and the rule of the storage order is very important.

The issue of the storage order of array elements is related to what kind of order we operate the array elements when processing the array as an entity. Many operations in C++ are related to the storage order of array elements, such as array initialization and data transfer between units.

A one-dimensional array can be viewed as a column vector in mathematics, and each element is stored in memory according to their subscripts. For example, the following array declaration statement

```
int ay[5];
```

declares a one-dimensional array of int with five elements. This array can be viewed as a column vector [ay[0], ay[1], ay[2], ay[3], ay[4]]T. The storage order of array elements is demonstrated in Figure 6.1.

A two-dimensional array can be viewed as a matrix in mathematics; the first subscript of each array element is called the row subscript of the element, and the second subscript is called the column subscript. For example, the array declaration statement

```
M[2][3];
```

declares a two-dimensional array, which equals a matrix with two rows and three columns

```
M = [[M(1,1) M(1,2) M(1,3)], [M(2,1) M(2,2) M(2,3)]]
```
