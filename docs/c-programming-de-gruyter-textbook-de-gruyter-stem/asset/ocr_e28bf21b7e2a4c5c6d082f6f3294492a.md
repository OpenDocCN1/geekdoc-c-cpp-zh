# 8.5 Program Instance: Variable Stepwise Trapezoid Method — 337

We can get the recursive formula by exploiting the integral result before halving (8.2):

```
$T_{2n} = \frac{1}{2}T_n + \frac{1}{2}\sum_{k=0}^{n-1} f(x_k+\frac{1}{2}) \quad (8.5)$
```

For practical problems, we often take the following steps:

+   First, let $n=1$, apply formula (8.2) to calculate the integral value.

+   Second, halve and apply recursive formula (8.5) to calculate the new integral value.

+   Third, judge if the difference between the two integral values is within the given error tolerance, and if so, the integral value after halving is the expected result and we can stop the integration. Otherwise, go back to the second step and continue execution.

Note that this integral method has certain restrictions on the integrand. If a function happens to be 0 on the boundaries and center, but not between these points, then the results of the first and the second step are both 0. In this case, the procedure is concluded with 0 as the final result, which is obviously wrong.

# 8.5.2 Analysis of Program Design

From the above analysis, it is obvious that the two problems we face are: the calculation of the integral values at every step, and we need to evaluate the function over a very small interval at step size of a trapezoidal integral, and the implementation of the variable step trapezoid method.

Two abstract classes are defined: class F and integral class Inte. They have virtual functions:

```
virtual double operator ()(double x)=0;
//pure virtual function overload operator()
virtual double operator ()(double a, double b, double eps)=0;
```

They are both overload operators (). The former calculates the function at point x while the latter calculates the integral with an error less than eps in interval [a,b]. The specific implementations are by their derived classes. The advantage of doing so that when the derived class offers different implementations, it can calculate late different integrals using different methods (we only use the variable step trapezoid method, but we can also use new methods by deriving classes).
