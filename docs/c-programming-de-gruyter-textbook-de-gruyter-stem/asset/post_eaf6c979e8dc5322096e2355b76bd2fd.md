# 9.2.4 Stack

As mentioned in 9.2.1, a stack is a special linear collection with restricted access. It is possible to implement stacks in arrays or linked lists. However, the access pattern of a stack is a restricted one, so we need a different interface for the stack class.

In order to represent the states of a stack, the stack class should contain data elements and the pointer to the top of the stack. There are two types of implementation: one is based on arrays (either static or dynamic) and the other is based on linked lists.

> **There are three states of a stack: normal, empty and full.** A stack is full when the number of elements reaches the number in the declaration. In the implementation based on dynamic arrays or linked lists, it is possible to set the number as unlimited.

- - Stack should provide interfaces of these operations:
- Initialization
- Push data into the stack
- Pop data out of the stack
- Clear the stack
- Access the top of the stack
- State detection

# Example 9.8: Implementation of stack.

```cpp
//9_8.h
#ifndef STACK_CLASS
#define STACK_CLASS
#include <iostream>
#include <cstdlib>
using namespace std;

const int MaxMaxSize = 50; //Size of the stack, the maximum
//number of elements in the stack
//Definition of class
template <class T>
class Stack {
private:
    T stacklist[MaxMaxSize]; //The array used to store elements
//of the stack
    int top; //Position of stack top(index)
public:
    Stack(void); //Constructor, initialize the stack
    void Push(const T& item); //Push the element item
    T Pop(void); //Pop the element on stack top
    void ClearStack(void); //Clear the stack
    T Peek(void) const; //Access the element on stack top

    int StackEmpty(void) const; //Test whether the stack is empty
    int StackFull(void) const; //Test whether the stack is full
};
```

```cpp
//Implementation of class
template <class T>
Stack<T>::Stack(void) : top(-1) //Constructor, stack top is
                    //initialized to -1
```

```cpp
template <class T>
void Stack<T>::Push(const T& item)
                            //Push the element item in the stack
{
    if (top == MaxSize-1) //Terminate the program if the
                        //stack is full
    {
        std::cerr << "Stack overflow! << endl;
        exit(1);
    }
    top++; //Increase the pointer of stack top by 1
    stacklist[top] = item; //Push the new element to stack top
}
```

```cpp
template <class T>
TStack<T>::Pop(void)                            //Pop the element on stack
{
    T temp;
    if (top == -1) //Terminate the program if the stack is empty
    {
        std::cerr << "Attempt to pop an empty stack! << endl;
        exit(1);
    }
    temp = stacklist[top]; //Get the element on stack top
    top--; //Decrease the pointer of stack top
    return temp; //Return the element on stack top
}
```

```cpp
template <class T>
TStack<T>::Peek(void) const                    //Access the element on stack top
{
    if (top == -1) //Terminate the program if the empty
    {
        std::cerr << "Attempt to peek at an empty stack! << endl;
        exit(1);
    }
    return stacklist[top]; //Return the element on stack top
}
```

```cpp
template <class T>
int Stack<T>::StackEmpty() const //Test whether the stack is empty
{ return top == -1; } //return TRUE if stack is empty,
                             //otherwise return FALSE

template <class T>
int Stack<T>::StackFull() const //Test whether the stack is full
{ return top == MaxMaxSize-1; } //return TRUE if stack is full,
                                   //otherwise return FALSE
```

```cpp
template <class T>
void Stack<T>::ClearStack(void) //Clear the stack
{ top = -1; }
```
