# 7 Inheritance and Derivation

The type compatible rule is about the use scope of derived-class objects. After public derivation, a derived class has all the functionalities of its base class. We can use a derived class to substitute for the base class wherever the latter is needed. This characteristic lays the foundation for polymorphism, which will be discussed in the next chapter.
