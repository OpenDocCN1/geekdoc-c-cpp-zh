```
int array2[2][3]={{11,12,13},{21,22,23}};
```

We can understand it as:

```
array2[0] --- array[00] array[01] array[02]
array2[1] --- array[10] array[11] array[12]
```

This two-dimensional array has two rows and three columns. It equals a one-dimensional pointer int-type array. The number of elements of the pointer array is the number of rows of the two-dimensional array. Elements of the pointer array, array2[0] and array2[1], denote the starting addresses of the first and second row of the two-dimensional array. Each row of the two-dimensional array equals a one-dimensional int-type array, which has three elements.
