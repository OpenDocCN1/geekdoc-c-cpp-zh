The function seekg can be used to achieve an object-oriented management system. The position of the last byte of the file can be determined by multiplying the fixed-length record size by the number of records. With this number, the record can be read using get.

Member function tellg returns the position of the current reading pointer; the value is of streampos type.

Example 11.10: Read a file and display the position of the blanks inside.

```
//11_10.cpp
#include <iostream>
#include <fstream>
using namespace std;
int main()
{
    char ch;
    ifstream tfile("payroll",ios_base::binary);
    if (tfile)
    {
        while (tfile.good())
        {
            streampos here = tfile.tellg();
            tfile.get(ch);
            if (ch== ' ')
                cout << "Position " << here << " " is a space\n";
        }
    }
    else
    {
        cout << "ERROR: Cannot open file 'payroll'." << endl;
    }
    tfile.close();
}
```
