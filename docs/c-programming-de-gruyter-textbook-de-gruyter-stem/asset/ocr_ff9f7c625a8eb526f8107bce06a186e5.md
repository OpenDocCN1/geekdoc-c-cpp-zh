# Example 11.1: Use function width to control output width.

```
//11_1.cpp
#include <iostream>
using namespace std;
int main() {
    double values[] = {1.23,35.36,653.7,4358.24};
    for (int i=0;i<4; i++) {
        cout.width(10);
        cout << values[i] << '\n';
    }
}
```

The result of the program is as follows:

| 1.23 |
| 35.36 |
| 653.7 |
| 4358.24 |

From the results we can see that the program added leading space before values that are less than 10 characters wide.
Blank the default filler. When the output data cannot satisfy the specified width, the system will fill it with blanks automatically. By using the member function fill, other characters can be set as the filler to fill. To use an asterisk to fill the row, for example, we changed the for loop in Example 11.1 to the following:

```
for (int i=0; i<4; i++) {
    cout.width(10);
    cout.fill('*');
    cout << values[i] endl;
}
```

The result of the program is as follows:

```
******1.23
*****35.36
*****653.7
***4358.24
```
