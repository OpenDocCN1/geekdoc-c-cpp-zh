# External Variable

If we want a variable to be used by other files than the source file that defines it, we can declare it as an external variable by using the keyword extern in its declaration.

An external variable has scope, and is defined outside any function. When declaring an external variable, we can give its definition, or just refer to an external variable that is declared elsewhere. Let's see the following example:

```
//source file 1
int i = 3;
void next( void );
int main()
{
    i++;
    next();
}
void next( void )
{
    i++;
    other();
}
```
