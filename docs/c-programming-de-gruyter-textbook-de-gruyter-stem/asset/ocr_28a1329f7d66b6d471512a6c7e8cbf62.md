# 6.3 Dynamic Memory Allocation

Although large amounts of data and objects can be managed effectively by arrays, in many cases we cannot know the exact number of elements in an array before the program runs. Take linear regression as an example: if the number of data pairs obtained by experiment varies a lot, it would be a headache problem to determine the size of the object array of the Point class. If we declare the array too large, for example, declaring it with 200 elements while we only process 10 points, it would be very wasteful. If the array were too small, it would affect processing large amounts of data. In C++, the technique of dynamic memory allocation can ensure that the program applies for moderate memory according to actual needs during the execution, and the memory can be released after the use. This kind of storage locations applied for and released during runtime is called a heap object. The processes of applying for memory and releasing memory are called creating and deleting respectively.

# 6.3.1 new Operation and delete Operation

In C++, the program creates and deletes heap objects using two operators: new and delete.
The function of the new operator is to allocate dynamic memory, or to create heap objects dynamically. The grammar is
