# 6.2.8 Using Pointers as Function Parameters

When we need to transfer a large amount of data between different functions, the cost of calling functions during the program execution will be large. In this case, if the data needs transferring is stored continuously in memory, we can only pass the starting address of the data rather than passing values, which will decrease cost and increase efficiency. The grammar of C++ provides support for this: parameters of functions can not be variables of basic types, object names, arrays, or function names, but also be pointers. If we use pointers as formalparameters, the actual parameters will be transferred to the formal parameters when the function is called. This is, the actual and formal pointer variables point to the same memory address. In this way, we can change data through formal parameters in the subfunction, which also affect the data values that the actual parameters point to.

Pointers in C++ are inherited from C. In C, there are three functions for usingpointers as formal parameters of functions: first, it can make actual parameters and formal parameter pointers point to the same memory space to realize bidirectional passing. With this, we can process the data of the calling function in the code directly and return the result to the calling function. This use has been realized in C++ by references, which have been detailed in the introduction ofusing references as function parameters in Chapter 3; secondly can decrease the cost of data transfer when calling functions. This use can also be realized by reference in C++ times, while in some cases pointers are still needed; the third use is to pass the starting address of code by the pointer which it points to. This will be introduced later.

When designing a program, using pointers and using references as formalparameters can achieve the same thing, so we can use references that can make the program more readable.
