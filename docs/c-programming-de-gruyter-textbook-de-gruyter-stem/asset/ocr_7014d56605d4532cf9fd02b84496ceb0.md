Let's analyze the structure of the whole program. It is made up of three separate files, whose relationship as well as the process of compiling and including are illustrated in Figure 5.8.

We can see that the two .cpp files in the multile structure both have added a new include statement. When we input/output operations, we need to use the statement #include <iostream> to include the standard header file iostream by the system in the source program. We also need to use the statement #include "point.h" to include the user-defined header file. The #include instruction in C++ is used to embed the specified file can be either into the current file or an .h or a .cpp file.

There are two forms for writing an include instruction. The form "#include <file name>" indicates for the compiler to search for the file that needs to be embedded in the standard way, and that the file is embedded in the subdirectory of the C++ system directory. This form is usually used to embed standard files provided by the system, as standard header file iostream. The other form is "#include "file name"", which indicates for the current directory; if the file cannot be found, the compiler will use the current directory, and then search by the standard searching method. This form is usually used if the files are written by the user, such as the class definition file point.h in this example.

#include is a compilation preprocessing directive, which will be detailed later.
