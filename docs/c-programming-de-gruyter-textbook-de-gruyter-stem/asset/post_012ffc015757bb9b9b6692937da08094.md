## 9.3 Organizing Data in Linear Collections

### 9.3.1 Insertion Sort

The basic idea of insertion sort is to insert unsorted element at a time into the correct position (in the sorted subcollection) until the collection is completely sorted. For example, if we need to sort an n-element array a, we can consider a[0] a sorted subcollection and a[1..n-1] as the subcollection to be sorted. The procedure is shown in Figure 9.119. There are some variants of the algorithm using different ways to find the position in which to insert the element. Here we only introduce the simplest one, the direct insertion sort.

```cpp
void InsertionSort(T A[], int n)
{
    int i, j;
    T temp;

    //Insert the elements with index 1-n-1 to the appropriate position
    //in the sorted sequence
    for (i = 1; i < n; i++)
    {
        //Scan elements from A[i-1] to A[0], find the appropriate
        //position to insert A[i]
        j = i;
        temp = A[i];
        while (j > 0 && temp < A[j-1])
            //Compare them one by one until temp=A[j-1], j is the
            // position to insert
            // If j==0, 0 is the appropriate position
            A[j] = A[j-1]; //Move elements forward one by one, make it
            //possible to insert immediately when the
            //appropriate is found
            j--;
        }
        //The position is found, insert immediately
        A[j] = temp;
    }
}
```

### 9.3.3 Exchange Sort

The idea of exchange sort is to pair elements in the collections and exchange if they are disordered. Bubble sort is a good example.
The Following is the algorithm of bubble sort for operating on an array with n elements:

- Check the first and second element, exchange them if they are not in order. Do this similarly for the second and third one, and so on until the last one is reached. The whole procedure is called the first stage of bubble sort. After the procedure, the maximum is at the n-th position.
- Repeat the first step with n-1 elements. After the procedure, the maximum of these n-1 elements is at n-1 position.
- Repeat the second step until no element appears in a stage of bubble sort. For an n-element collection, bubble sort requires n-1 stages.

Figure 9.21 shows the procedure of bubble sort.

```cpp
{
    int i, j;
    int lastExchangeIndex; //Record the index of smaller elements
                             //in the last pair of elements
                             //every swap
    //i is the largest index of
                             //elements will take place in
                             //next turn
    i = n - 1;
    while (i > 0) { //Keep sorting, until no swap occurred
                    //in the last turn or n-1 turn has
                    been done
        lastExchangeIndex = 0; //Set swap 0 before every
                               //turn(no swap)
        for (j = 0; j < i; j++) { //Compare and swap between A[0]..A[i]
                                   in every turn
            if (A[j+1] < A[j]) { //If element A[j+1] < A[j], swap them
                Swap(A[j], A[j+1]);
                lastExchangeIndex = j; //Record the smaller index in the swap
            }
        }
        i = lastExchangeIndex; //Set i to the smaller index in
                               //last swap
    }
}
```

### 9.3.4 Sequential Search

Sequential search is a basic search method. It scans through the array, and compares each element with the desired one until it finds the match. The search is unsuccessful if there is no element that matches the desired one.

Example 9.14: Sequential search.

```cpp

//search
//Return the index of the element if found, otherwise return -1
template <class T>
int SeqSearch(T list[], int n, T key)
{
    for(int i=0; i < n; i++)
        if (list[i] == key)
            return i;
    return -1;
}
```

```cpp
//Use binary search to find the element with key as value in a
//ascending array list
template<class T>
int BinSearch(T list[], int n, T key)
{
    int mid, low, high;
    T midvalue;
    low=0;
    high=n-1;
    while (low <= high) {
        //low <= high indicates the array
        //haven't been searched through
        mid=(low+high)/2;
        //Get the index of the element at
        //the center
        midvalue = list[mid];
        //Get the value of the element
        if (key == midvalue) {
            //If found, return the index
            return mid;
        } else if (key < midvalue) {
            high = mid - 1;
        } else {
            low = mid + 1;
        }
    }
    return -1;
}
```
