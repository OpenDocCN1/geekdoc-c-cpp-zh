# 2.5.4 Union

Sometimes several different types of data need to share the same storage area. In this case we can declare a union type. The syntax form of a union declaration is:

```
union type name
{
    data type identifier 1 member name 1;
    data type identifier 2 member name 2;
    :
    data type identifier n member name n;
};
```

Syntax form of union-type variable declaration:

| union type name union-type variable name; |

Syntax form of referencing a member of a union-type variable:

| Union-type variable name.member name |
