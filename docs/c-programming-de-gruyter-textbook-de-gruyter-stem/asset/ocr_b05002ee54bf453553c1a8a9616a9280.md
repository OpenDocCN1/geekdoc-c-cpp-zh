# 6.2.3 Operations Related to Addresses – '*' and '&'

C++ provides two operations related to addresses – '*' and '&'. '*' is called an indirection operator (also called dereferencing operator), and is used to access the variable that a pointer points to. It is a unary operator. i_pointer denotes the value of the int type that i_pointer points to. '&' is called an address-of-operator, which is also a unary operator. '&' is used to get the address of an object. For example, we can get the address of the storage location of variable i by using &.

Note that '*' and '&', when appearing in declaration statements and in execution statements, have different meanings. Also, when acting as unary operators and binary operators, '*' and '&' have different meanings. When the unary operator '*' appears in a declaration statement and is before the name of the declared variable, it indicates a pointer. For example,

```
int *p; //declare p is a pointer of int type
```

When '*' appears as a unary operator in an execution statement or the initial expression of a declaration statement, it means for it to access the content of the object that a pointer points to. For example,

```
cout<<*p; //output the content of the object that pointer points to
```

```
int &rf; //declare a reference rf of int type
```
