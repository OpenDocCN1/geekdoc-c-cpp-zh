In the small interval $[X_{k-1}, X_k]$, we take an approximate value of $I_k$ and calculate the approximate value of $I$.
In the interval $[X_{k-1}, X_k]$, let $I_k = (f(X_{k-1}) + f(X_k)) \times h/2$ for the trapezoidal integral. An easy way to understand the trapezoid integral is to see that the original integral is divided into a series of small intervals and in each small interval, we approximate the integral of the original function by the area of a trapezoid. If the integral is small enough, a close approximation of the value of the original integral can be achieved. Here, the integral can be approximated by:

```
$T_n = \sum_{k=0}^{n-1}\frac{h}{2}[f(x_k) + f(x_{k+1})] \quad (8.2)$
```

After applying the integral formula, an appropriate step length must be given. If the step is too big, the precision cannot be guaranteed. Therefore, we often use a variable step size method. We apply the integral formula repeatedly and in each integration, the step size is halved. This procedure is applied until the integral result meets the precision requirement.
Dividing the interval $[a, b]$ into $n$ equal intervals, we get $n+1$ points of division. According the integral is halved, the number of points division reaches $2n+1$. We use the recursive relation between these two integrals as follows:

After halving, each subinterval $[x_k, x_{k+1}]$ has one more point of division $x_{k+1/2} = (x_k + x_{k+1})/2$.

```
$$\frac{h}{4}[f(x_k) + 2f(x_{k+1/2}) + f(x_{k+1})] \quad (8.3)$
```

Note that here $h = (b-a)/n$ is still the step before halving. Adding each interval's integral together, we get the result:

```
$T_{2n} = \frac{h}{4}\sum_{k=0}^{n-1}[f(x_k) + f(x_{k+1})] + \frac{h}{2}\sum_{k=0}^{n-1}f(x_{k+1/2}) \quad (8.4)$
```
