# 5.4.2 Friend Class

With the friend function, one class can declare another class as its friend. If class A is the friend class of class B, then all the member functions of class A are friend functions of class B, and they can access class B's private and protected members. The syntax of a friend class declaration is:

```
class B
{
  ...
  //member declaration of class B
  friend class A; //declare A as B's friend class
  ...
};
```

Declaring a friend class is a method to correlate classes and achieve data sharing among classes. UML language uses the <<friend>> stereotype to represent friendship between classes.
