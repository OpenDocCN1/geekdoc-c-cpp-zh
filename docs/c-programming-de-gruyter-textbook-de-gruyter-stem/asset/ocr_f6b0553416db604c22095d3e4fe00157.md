Exceptions of the C++ standard library are always derived from the logic_error logic class. It denotes errors in the program or violations of the invariance of the class, which can be avoided by writing correct codes. C++ standard library provides the following types of logic errors: invalid_argument passing invalid arguments to functions. Length_error denotes that the length exceeds the maximum allowable length of the operational block. Out_of_range denotes the value of the array subscript exceeds the defined range. Domain_error denotes invalid preprocessing errors. In addition, the class library of the standard library provides a special exception named IOS_base::failure. When the state of the data stream changes because of error or reaching the end of file, it will be thrown.

Exception classes derived from runtime_error are base classes of several other exception classes that denote errors occur only in the program execution. Range_error denotes the interval error in internal computation, overflow_error denotes errors in computation, and underflow_error denotes underflow error in computation.

To use exception classes, the corresponding header files should be included. Exception and bad_exception are defined in <exception>. Bad_alloc is defined in <new>. Bad_cast and bad_type are defined in <typeinfo>. Io_base::failure is defined in <ios>. Other exception classes are defined in <stdexcept>.

C++ standard library guarantees that exceptions will not cause resource leak and the integrity of containers is maintained.
