# ## 1. Background of Writing This Book

C++ is an object-oriented programming language, which is evolved from C. C++ has two main characteristics: one is its full compatibility with C and the other is that it supports object-oriented methods.

The object-oriented program design encapsulates both data and related operations to form an interdependent and invisible whole – an object. By abstract features of the same category, we can get a class. Most data in a class can only be processed by the methods encapsulated in the class. A class communicates with the outside through a simple external interface, and objects communicate with each other through messages. In this way, we can have simple relationships between program modules, and module independence and data security can be ensured. Meanwhile, through inheritance and polymorphism, codes can be reused, which facilitates both the development and maintenance of software.

Because of the outstanding qualities of object-oriented methods, they have now become the major ways to develop large-scale software, and C++ is one of the most widely used object-oriented programming languages.

C++ has been considered hard to, and is seldom used as an introductory language for teaching. Are C++ and object-oriented program design deined hard to learn? The answer is no. In fact, when C was first created, it was only used by a few professional developers. However, along with the development of computer science, computer technologies have permeated research and applications of different subjects. Now C has been used by various engineers and technicians, and it has also been as the introduction programming language in many schools. C++ is fully compatible with C, although it provides a stricter and more secure grammar. In this sense, C++ is primarily a C.

C++ is an Object-Oriented Programming (OOP) language. OOP has once been considered a previously advanced technology. This is before the theories of Object-Oriented Analysis (OOA) and Object-Oriented Design (OOD) were developed, in order to write a good object-oriented program, programmers would first learn to use object-oriented methods to understand and describe problems. Now, since the work of understanding problem domains and designing system components, the work of OOP becomes much easier – it is just to write every component of an OOD model with an object-oriented programming language.
