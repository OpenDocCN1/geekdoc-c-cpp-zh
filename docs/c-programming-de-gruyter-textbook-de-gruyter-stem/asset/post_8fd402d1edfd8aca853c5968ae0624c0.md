# 6.5 Strings

We introduced in Chapter 2 that a string constant is a sequence enclosed in pair of double quotes. For example, "abcd", "China", and "This is a string" are all string constants. In memory, string constants are stored according to the order of characters in the string, and each character occupies a byte; at the end '\0' is added as the ending tag.

However, in C, a string variable is not a basic data type of C++. Then how does one store and process string? C uses character arrays to store strings, and C++ can still use this method. In addition, the standard C++ library defines the string class. We will introduce these two methods in this section.
