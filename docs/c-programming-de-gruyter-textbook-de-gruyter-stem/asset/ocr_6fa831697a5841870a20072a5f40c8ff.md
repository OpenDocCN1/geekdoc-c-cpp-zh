# 5.2 Lifetime of Object — 163

```
void Clock::ShowTime()
{
    cout<<Hour<<":"<<Minute<<":"<<Second<<endl;
}
```

Clock globClock; //declare object globClock, which has static
//lifetime, file scope
//use default constructor to initialize it to 0:0:0

```
int main()
{
    cout<<"First time output:"<<endl;
    //quote object globClock that has file scope
    globClock.ShowTime();
    //the member function of object has
    //class scope
    //display 0:0:0
    globClock.SetTime(8,30,30); //set the time to 8:30:30
    Clock myClock(globClock); //declare object myClock that has
    //local scope
    //call copy constructor, initialize
    //it by globClock
    cout<<"Second time output:"<<endl;
    myClock.ShowTime(); //reference object myClock that has
    //local scope
    //output 8:30:30
}
```

Result:

```
First time output:
0:0:0
First time output:
8:30:30
```

This program includes variables and objects of all kinds scopes: in the definition of class Clock, the three parameters of function member SetTime have prototype scope; object myClock has local scope; data members and function members of class Clock have class scope; and object globClock has file scope. These variables, objects, and public members are all visible in the main function. As for lifetime, apart from object globClock with file scope having a static lifetime, which is the same as the running period of the program, all the others have a dynamic lifetime.
