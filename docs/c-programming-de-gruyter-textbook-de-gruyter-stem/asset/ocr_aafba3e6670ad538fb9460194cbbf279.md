# 5 Data Sharing and Protecting

```
class Point                        //definition of class Point
{
    public:
        //external interface
        Point(int xx=0, int yy=0){ X=xx; Y=yy; countP++; } //constructor
        Point(Point &p);                    //copy constructor
        ~Point(Point &p){ countP--; }
        int getX() { return X; }
        int getY() { return Y; }
        void getC(){ cout<<countP<<endl; } //output static
        //data member
    private:
        //private data members
        int X,Y;
        static int countP;                 //referential declaration of static data
        //member, used to record the number of points
};

Point::Point(Point &p) {
    X=p.X;
    Y=p.Y; //accumulate countP in constructor, all the objects
    //maintain the same countP
}
int Point::countP=0;                //definitional declaration and initialization
//of static data member, qualified with class
//name

int main() {
    //the main function
    Point A(4,5);                       //define object A, its constructor will make
    //countP add 1
    cout<<"A:"<<A.getX()<<","<<A.getY()();
    A.getC();                          //output the number of objects
    Point B(A);                        //define object B, its constructor will make
    //countP add 1
    cout<<"B:"<<B.getX()<<","<<B.getY()();
    B.getC();                          //output the number of objects
}
```

In the example above, data member countP in class Point is declared, and used to count the number of objects in class Point; every time a new object is defined, the value of countP increases by 1. The definition and initialization of static data member countP are done outside the class. Pay attention to the reference method when initializing the static data member.
