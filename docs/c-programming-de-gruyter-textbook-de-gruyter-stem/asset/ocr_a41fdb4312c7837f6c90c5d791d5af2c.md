**Example 3.9:** Calculate the number of possible combinations (i.e., the combinatorial number) of selecting $k$ person(s) out of $n$ person(s) to form a committee.
Analysis: The combinatorial number of selecting $k$ person(s) out of $n-1$ person(s)
= The combinatorial number of selecting $k-1$ person(s) out of $n-1$ person(s)
Since the formula is recursive, it is easy to write a recursive function to implement the calculation. The ending condition of the recursion is $n=k||k=0$, at which the combinatorial number is 1. Then the regression may start.
