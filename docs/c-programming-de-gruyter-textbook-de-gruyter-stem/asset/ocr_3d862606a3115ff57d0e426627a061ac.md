Through public derivation, class Linequ inherits all the members of class Matrix except for the constructor and the destructor. Because all the base-class members are public or protected, they are accessible in the function members of the derived class. The protected members of the base class, are not accessible in the module creating objects of class Linequ. By using the protected access attributes and public derivation, we realize efficient sharing and reliable protection of data of the base Matrix. In the program, we store the coefficient matrix, the solution vector, and the vector on the right side of the equations all through dynamic memory allocation, which are implemented in the constructors of the base class and the derived class. The cleanup work is done in destructors.
