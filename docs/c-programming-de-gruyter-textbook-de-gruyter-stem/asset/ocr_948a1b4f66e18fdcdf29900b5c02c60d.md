After public derivation, class Fun has all members of class F except the constructor and destructor. Because the base class has a pure virtual function, it is an abstract class. The so member function in the derived-class is a specific implementation of the pure virtual function in the base class. The integrand is shown in expression 8.6.

f(x) = \frac{\log(1+x)}{1+x^2} (8.7)

Because the member function has the same name, and return value as that of the base class, the system recognizes it as a virtual function. There is no need to declare it explicitly. If we calculate the integral of another function, we only need to derive a new class from base class F, e.g., Fun1, and implement the function as a pure virtual function of class Fun1.
