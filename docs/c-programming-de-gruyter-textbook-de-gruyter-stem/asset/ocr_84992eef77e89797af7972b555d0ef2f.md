# 290 7 Inheritance and Derivation

```
int main() {
    D1 d1;
    d1.B1::nV=2;
    d1.B1::fun();
    d1.B2::nV=3;
    d1.B2::fun();
}
//main()
//declare object d1 of class D1
// use a direct base class
// use a direct base class
```

In main(), an object d1 of the derived class D1 is created. The system cannot uniquely identify which member is be accessed only through the object name. In this case, the scope qualifier should be used. Using the name of the direct base class to qualify a member determine which member inherited from the base class is to be accessed. The result of execution is:

| Member of B0 |
| Member of B0 |

In this case, there are two copies of member nV and member fun with the same names in the memory of the derived-class. The two nV can be initialized by the constructor of B0 by B1 and B2 respectively, and the two nV can store different values. Each can be separately accessed using the direct base class name to qualify the member nV. However, in most cases we only need one copy of the base-class members. Multiple copies will only result in more memory cost. The problem can be solved by the virtual class mechanism provided by C++.

# 7.5.2 Virtual Base Class

If some or all of a derived class's direct base classes are derived from the upper base class, then the members of the direct base classes share the same name. The data members declared in the indirect base class will have multiple copies in memory for a derived class object and each function declared in the indirect base class will have multiple mappings. We can utilize the scope qualifier to access them separately, or we can also set the common base class as a virtual base class. In the latter case, there will be only one copy in memory for data members with the same name inherited from different paths and only one map for each function name. This solves the unique identification problem for the members with the same name.

Virtual base class is declared during the definition of the derived class. Its syntax is:

```
class derived-class name: virtual inheritance mode base-class name
```
