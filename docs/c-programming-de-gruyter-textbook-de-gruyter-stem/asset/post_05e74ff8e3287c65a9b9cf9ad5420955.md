## 10.4.5 Numerical Algorithms

There are four generic numerical algorithms; Table 10.7 lists numerical algorithms in STL.

Here is an example of numerical algorithms in STL.

Example 10.12: An example of numerical algorithms.

```cpp
//10_12.cpp
#include <iostream>
#include <numeric>
#include <functional>
#include <vector>
using namespace std;

int main() {
    int iarray[]={1,2,3,4,5};
    vector<int> ivector(iarray,iarray+sizeof(iarray)/sizeof(iarray));

    // Accumulation
    cout<<accumulate(ivector.begin(),ivector.end(),0)<<endl;

    // Inner product
    cout<<inner_product(ivector.begin(),ivector.end(),ivector.begin(),0)<<endl;

// Difference
    adjacent_difference(ivector.begin(),ivector.end(), ostream_iterator<int>(cout, " "));

// Adjacent sum
    cout << partial_sum(ivector.begin(),ivector.end()) << endl;
}
```

Table 10.7: Numerical Algorithms

| Name | Description |
| :--- | :--- |
| accumulate | Calculates the sum of elements in a range |
| inner_product | Calculates the sum of products of corresponding elements |
| difference | Calculates the difference between consecutive elements |
| adjacent_sum | Returns a sequence of the sums of adjacent elements |
