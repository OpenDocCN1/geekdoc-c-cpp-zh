# 5.5.2 Constant Object

A constant object is an object whose value of its data member cannot be changed during the whole lifetime of the object. That is to say, constant objects must be initialized, but cannot be updated. The syntax form of declaring a constant object is:

```
class name const object name;
```

For example:

```
class A
{
    public:
    A(int i, int j) {x=i; y=j;}
    ...
    private:
    int x,y;
};
```

A const(3,4); //a is a constant object, and cannot be updated
