Implement the whole assignment between objects*/
template<class T>
Array<T>& Array<T>::operator=(const Array<T>& rhs)
{
    int n = rhs.size; //Get the size of array in rhs
    /*If the size of array in current object is different from the one
   rhs, free the existing memory and reallocate it */
    if (size != n)
    {
        delete[] alist; //Free the existing memory of array
        alist = new T[n]; //Reallocate the memory of n elements
        if (alist == NULL) //Output error if the
            Error(memoryAllocationError); //allocation failed
        }
        size = n; //Save the size of array in current
        //object
    }
    //Copy elements from object rhs to current object
    T* destptr = alist;
    T* srcptr = rhs.alist;
    while (n--)
        *destptr++ = *srcptr++;
    return *this; //Return the reference of current
    //object
}

# 9.2 Linear Collection 367

Array does an out-of-bound check before accessing an element, and its size can be changed during the runtime. Programmers use Array as the common array, since the subscript operator performs bounds checking during runtime. There are three issues in Array: 1) Why is the constructor so complicated, 2) Why does some assignment return a reference instead of the value, 3) Why does Array overload the cast operator?

The following section addresses these problems:

## Shallow Copy vs Deep Copy

As discussed in Section 6.4, shallow copy only copies the references and not the contents. Here is an example of shallow:

```cpp
template <class T>
Array<T>::Array(const Array<T>& X)
{
  int n = X.size;
  size = n;
  alist = new T[n];
  if (alist == NULL)
    Error(memoryAllocationError);
  T* srcptr = X.alist;
  T* destptr = alist;
  while (n--)
    *destptr++ = *srcptr++;
}
```

Consider the following function:

```cpp
int main()
{
    Array<int> A(10);
    Array<int> B = A;
    ...
}
```

The result of the assignment will share the same memory, which for A and B will generate a serious error. At the end of the program, the destructor will free the existing memory of array, once for A and B will generate a runtime error. The correct way of doing it is:

```cpp
template <class T>
Array<T>::operator=(const Array<T>& rhs)
{
    int n = rhs.size;
    if (size != n)
    {
        delete[] alist;
        alist = new T[n];
        if (alist == NULL)
            Error(memoryAllocationError);
        }
        size = n;
    }
    ...
}
```
