The second example concerns the abstraction of human beings. Based on the generalization and abstraction of human beings, we extract the common characteristics and have abstract descriptions as below:

Common attributes: name, sex, and age, which form the data abstraction of human beings. Using C++ variables to represent them, they can be:

char *name; char *sexe; int age;

Common function: biological behaviors like eating and walking, and social behaviors like working and studying. They make the function abstraction of human beings. We can also use C++ functions to represent them:

Eat(); Walk(); Work(); Study();

If we need to develop the personnel management software for a company, the human characteristics mentioned above may not be enough, and we also need to worry concerns, working age, department, operational capability, subordination, and so on.

From these two examples we can see that focusing on different aspects of the same object can lead to different abstraction results. Even for the same problem, different requirements of problem solving may lead to different abstraction results.

# 4.1.2 Encapsulation

Encapsulation means combining abstracted data and behaviors (or functions) to form an organic whole. In other words, encapsulation means to combine data and the functions operating on the data together to form a "class", and the functions are both members of the class. For example, based on abstraction, we can encapsulate the data and the functions of a clock to make a class of that clock. According to C++ grammar, the class Clock be defined as follows:

```
class Clock //class keyword, class name
{
public:
    void SetTime(int NewH, int NewM, int New S); //function, code member

    //exterior interface
    void ShowTime(); //function, code member
```
