4. Notation
dec, oct, and hex manipulators set the default notation of input and output. For example, if the manipulator hex is inserted into the output stream, the output will be in a hexadecimal format. If ios_base::uppercase (default) label is cleared, the hex numbers through f are displayed in lowercase; otherwise they are displayed in uppercase. The default notation is dec (decimal).

# 11.2.3 Output Stream Member Function

There are three types of member functions in the output stream classes:

+   1. Member functions equivalent to manipulators;
2. Member functions executing unformatted write operations;
3. Other member functions that modify stream state and are not equal to manipulators or inserters.

Inserters and manipulators can be used in ordinal formatted outputs. For random binary outputs, other member functions should be used.

# 1. Function open of output stream

To use an output file (ostream), the stream should be related to a specified disk file in the constructor or function open. In both cases, the parameters of the described files are the same.
When a file related to an output stream is opened, an open mode label is often needed as shown. These labels can be combined by using a bitwise or () operator. They are defined as enumeration constant in class ios_base.

# 2. Function close of output stream

Member function close closes a disk file related to an output file stream. To complete the disk output, the file must be closed after being used. Although an ostream destructor will finish closing it automatically, if we want to open another file by the same stream object, we have to use the function close.
