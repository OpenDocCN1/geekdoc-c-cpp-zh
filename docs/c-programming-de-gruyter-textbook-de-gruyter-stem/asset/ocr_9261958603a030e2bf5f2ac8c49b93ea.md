When the compiler detects the mismatch between the type of formal parameter and actual parameter, it will try to perform a type cast, i.e., converting *a* into a variable with type int*. However, we need to override the type-cast operator to help the compiler to cast *a* into an int* variable.

Some reader might find that the type-cast operator does not declare the type of return value. It is in fact a C++ syntax, which requires that the type of return value should not be declared (including void) for overloading a type-cast operator.
