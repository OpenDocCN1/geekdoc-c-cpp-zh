Then an exception occurs in the runtime, i.e., there is a running error. What is the reason? First, let us see the output above. In the program, pointsArray2 is copied from pointsArray1, and its initial states are the same as. But when the first group of points in pointsArray1 is moved by the move function, the second group of points in pointsArray2 has the same movements. This means that there is some connection between the two groups of points, which is not expected. Maybe this is the root cause of errors in the program.

Here, we create the object pointsArray2 by calling the default copy constructor to realize the direct copy of corresponding data items. This process is shown in Figure-6.10.

We can see from the figure that after the default copy constructor has simply copied the corresponding data items of the two objects, the member points of pointsArray1 and member points of pointsArray2 have the same value.
