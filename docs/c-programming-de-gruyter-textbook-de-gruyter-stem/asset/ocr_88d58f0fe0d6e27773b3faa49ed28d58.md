# 6.1.4 Object Arrays

The type of array not only be basic data types, but can also be user-defined types. For example, if we want to store and process the information of all employees of a corporation, we can construct an object array for an employee class. The elements of an object array are objects that have data members as well as function members. Therefore, compared with arrays of basic data types, object arrays have some special characteristics.

The form for declaring a one-dimensional object array is:

```
Class Array name[Subscript expression];
```
