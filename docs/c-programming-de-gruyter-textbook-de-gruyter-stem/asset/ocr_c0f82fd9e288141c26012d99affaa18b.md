# **1. Simple Analysis**

A linear fit of points is the most common way to process experimental data in general. Let us consider a problem of fitting a line by $N$ data points. The linear model is

```
y(x) = y(x; a, b) = ax + b
```

This problem is called regression. Suppose that variable $y$ varies along the independent variable $x$. Given $n$ observed data $(x_i, y_i)$, we want to use a line to fit these points. Here, $a$ and $b$ are the slope and intercept of the line, which are called regression coefficients.

In order to determine the regression coefficients, we generally use the least squares method, that is, to minimize the regression coefficient:

```
Q = \sum_{i=0}^{n-1} [y_i - (ax_i + b)]^2 \quad (6.1)
```

According to the extremum principle, $a$ and $b$ satisfy the equations below,

```
\frac{\partial Q}{\partial a} = 2 \sum_{i=0}^{n-1} [y_i - (ax_i + b)](-x_i) = 0 \quad (6.2)
```

```
\frac{\partial Q}{\partial b} = 2 \sum_{i=0}^{n-1} [y_i - (ax_i + b)](-1) = 0 \quad (6.3)
```

Then we get,

```
a = \frac{L_{xy}}{L_{xx}} = \frac{\sum_{i=0}^{n-1} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=0}^{n-1} (x_i - \bar{x})^2} \quad (6.4)
```

```
b = \bar{y} - a\bar{x} \quad (6.5)
```

```
\bar{x} = \frac{\sum_{i=0}^{n-1} x_i}{n}, \quad \bar{y} = \frac{\sum_{i=0}^{n-1} y_i}{n} \quad (6.6)
```

Finally, we can have the linear equation $y(x)=ax+b$.
