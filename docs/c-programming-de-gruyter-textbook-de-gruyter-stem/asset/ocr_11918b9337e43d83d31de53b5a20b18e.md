# 2. do-while Statement

Syntax form:

do statement
while (expression)

The execution order is: execute loop body statement, first, and then evaluate the ex-ression (loop condition). If the expression is true, continue the execution-evaluation cycle; otherwise end the loop. Figure 2.8 is the flow chart of a do-while statement.

Like in while statements, generally there should be statements in the loop body that can change the value of expression; otherwise it will be a dead loop.
