Programmers often write statements like: "a[3] = 5", in which the result of operator [] is placed on the left of the assignment operator. We call it a left value (lvalue) by convention.

As discussed above, the result of arithmetic operators should be a constant that it cannot be used as an lvalue, the situation differs in operator [] – it is desirable that we can write statements like "a[3]=5". That is why the operator [] returns a reference rather than a constant value.

The operator = is just a convention for compatibility. As a convention, the result of assignment operator can be used as an lvalue. The following statements are valid in C++:

```
int a, b=5;
(a=b)++;
```

The value of A is 6 after running these statements.
