```cpp
//employee.h
class employee
{
protected:
    int individualEmpNo;        //individual number
    int grade;                  //grade
    float accumPay();           //monthly pay
    static int employeeNo;     //currently maximum employee number
public:
    employee();                  //constructor
    ~employee();                 //destructor
    void promote(int);          //promotion function
    void SetAccumPay(float pa); //setting monthly pay function
    int GetIndividualEmpNo();   //getting number function
    int GetGrade();             //getting grade function
    float GetAccumPay();        //getting monthly pay function
};
```

## 5.8 Summary

Data sharing and data protection mechanisms are very important features in C++. They include scope, visibility and lifetime of identifiers, achieving data sharing and operation sharing between different objects of a same class using static members of the class, and using constant members to set the protection attributes of members.
