# 3.3 Default Formal Parameters in Functions

```
cout << "Some box data is ";ncout << get_volume(x) << endl;
cout << "Some box data is ";ncout << get_volume(x, 7) << endl;
cout << "Some box data is ";ncout << get_volume(5, 5, 5) << endl;

```

```
int get_volume(int length, int width, int height) {
    cout<<setw(5)<<length<<setw(width)<<setw(5)<<height<<' ';
    return length * width * height;
}
```

Running result:

| Some box data is 10 12 15 1800 |
| Some box data is 10 12 3 360 |
| Some box data is 10 2 3 60 |
| Some box data is 10 7 210 |
| Some box data is 5 5 5 125 |

Since the first parameter of the function get_volume has no default value, every function call on get_volume must provide the first actual parameter to initialize the formal parameter length. The parameters width and height have default values. So all three formal parameters will be initialized by actual parameters; the last formal parameter height will use the default value if the function call provides two actual parameters; the last two formal parameters width and height
 height will use the default values if the function call provides only one actual parameter.

When overloading functions that have default values, we should avoid ambiguity. For example, the following two prototypes will cause ambiguity that they cannot be recognized as different overloaded forms by the compiler:

```
void fun(int length, int width = 2, int height = 3);
void fun(int length);
```

In other words, when the function fun is called in the following form, the compiler is unable to decide which overloaded function should be executed:

```
fun(1);
```

The compiler will count this as a compiling error.
