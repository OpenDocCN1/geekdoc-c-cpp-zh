There are greater drawbacks in shallow copy. Before the end of the program, destructors of pointsArray1 and pointsArray2 will be called automatically, and the memory space formerly allocated will be released. Since the two objects share the same memory space, the space will be released twice, which leads to running errors. The solution to this problem is writing copy constructors to realize “deep copy”.
