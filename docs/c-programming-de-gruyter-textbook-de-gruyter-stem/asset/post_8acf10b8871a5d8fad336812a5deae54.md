
## 6 Arrays, Pointers, and Strings

X=xx;
YY=yy;

Each time the two statements are executed, the system needs to differentiate which object the assigned data member belongs to, and it uses this pointer to achieve this. Each time the system executes the above two statements, it executes:

```
this->X=xx;
this->Y=yy;
```

The pointer explicitly indicates which object the data member that the member function operates on belongs to. The actual process is as follows: when calling a member by an object, the system first assigns the object address to this pointer, and then calls the member function. When member function operates on some data member, this pointer is used implicitly.

In general designs, we usually don't use the pointer to refer to object members. This pointer is a pointer variable, so in a member function, we can use *this* to identify the object through which the function is called.

## 3. Pointers to Nonstatic Members of a Class

Members of a class are variables, functions, objects, etc., so we can also store their addresses in pointer variables. In this way, we can make pointers to members of objects and access these members using pointers.

Pointers that point to members of objects should also be declared and assigned values before being used. We should first specify which class the member pointed belongs during the declaration of the pointer. Note that using pointers we can only access public members. The syntax for forming a pointer that points to a class member is

```cpp
type specify class name::*pointer name;
//declare a pointer which points to a public data member
type specify (class name::*pointer name)(parameter list);
//declare a pointer which points to a public function member
```

After declaring a pointer that points to a class member, we need to assign it the member of the class that pointer is going to. The general syntax of assigning a pointer that points to a data member is:

```
Pointer name=class name::data member name;
```

For a common variable, we can use &operator to get its address. After assigning such an address to a pointer, we can access the variable by the pointer directly. However, things are a little complicated as class members. The definition of a class only notes the type and occupied memory size of each data member and their relative positions, while the specific memory addresses are not allocated for data members when defining the class.

## 6.2 Pointers

So the assignment introduced above only denotes which data member the pointer points to and stores it in the pointer's relative position in the class (offset from the starting address of the class), while we can access any through such a pointer at a time.

Because classes are instantiated through objects, memory spaces will be allocated to objects when we declare objects of classes. After declaring an object, we can access a data member of the object by combining the starting address of the object and the relative offset stored in the pointer that points to the data member. When accessing data members, this combination can be realized by either of the following syntax forms:

```
Object name.* class member pointer name
or: object pointer->*class member pointer name
```

Pointers to member functions of classes should be assigned values after their declarations through the following form.

```
Pointer name=class name::function member name;
```

The name of a common function denotes its starting address. By assigning the function's starting address to a pointer, we can call the function through this pointer. Although member functions of a class do not have a copy of it, grammatically, nonstatic member functions should be called through objects. Thus, assigning a pointer to a member function through the form introduced above, rather than using the pointer to call the member function, we must first declare an object of the class and then use the member pointer to call the member function using the statements below:

```
(object name.* class member pointer name)(parameter list)
or: (pointer name->*class member pointer name)(parameter list)
```

Note that the type of the return value and the parameter list of functions must match during the declaration, as well as the assignment and the use of a member function pointer.

**Example 6.13:** Different ways to access public member functions of objects.

```cpp
int main()
{
    Point A(4,5); //declare object A
    Point *p1=&A; //declare object pointer and initialize it
    int (Point::*p_GetX)()=Point::GetX;
    //declare member function pointer and initialize it

    cout<<(A.*p_GetX)()<<endl;
    ///(1) use member function pointer to access member function

    cout<<(p1)->GetX()<<endl;
    //(2)use object pointer to access member function
    cout<<A.GetX()<<endl;
    //(3)use object name to access member function
}
```

Accessing static members of a class does not depend on specific objects, so we can use common pointers to point to and access static class members. Now, we make a few modifications on Example 5.4 in Chapter 5 and get two programs in Example 6.14 and Example 6.15, to explain how to use common pointers to access static class members.

**Example 6.14:** Using pointers to access static members.

```cpp
//6_14.cpp
#include <iostream>
using namespace std;
class Point
{
    static int count;
    int X, Y;
public:
    Point(int x, int y) : X(x), Y(y) {}
    int GetX() { return X; }
    int GetY() { return Y; }
    static void getC() { cout << "count: " << count << endl; }
};
int Point::count = 0;
int main()
{
    Point A(4,5);
    A::getC();
    Point B(1,2);
    B::getC();
}
```

**Example 6.15:** Using pointers through static members.

```cpp
//6_15.cpp
#include <iostream>
using namespace std;
class Point
{
    static int count;
    int X, Y;
public:
    Point(int x, int y) : X(x), Y(y) { count++; }
    int GetX() { return X; }
    int GetY() { return Y; }
    static void getC() { cout << "count: " << count << endl; }
};
int Point::count = 0;
int main()
{
    Point A(4,5);
    Point *p1 = &A;
    Point::getC();
    (p1)->getC();
}
```
