### 7.5.2 Virtual Base Class

If some or all of a derived class's direct base classes are derived from the upper base class, then the members of the direct base classes share the same name. The data members declared in the indirect base class will have multiple copies in memory for a derived class object and each function declared in the indirect base class will have multiple mappings. We can utilize the scope qualifier to access them separately, or we can also set the common base class as a virtual base class. In the latter case, there will be only one copy in memory for data members with the same name inherited from different paths and only one map for each function name. This solves the unique identification problem for the members with the same name.

Virtual base class is declared during the definition of the derived class. Its syntax is:

```cpp
class derived-class name: virtual inheritance mode base-class name
```
