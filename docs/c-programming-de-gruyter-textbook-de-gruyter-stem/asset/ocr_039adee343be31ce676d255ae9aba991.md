# 11.3 Input Stream

An input stream object is the source of a data flow. The three most important input streams are stream, ifstream, and stringstream.

Class stream is most suitable for ordered text mode input. All the functions of the basic class ios are included in stream. We rarely need to construct objects from class ist. We usually use predefined cin object, which is actually an object of class ist_withassign.

Ifstream supports disk file input. For an input-only disk file, one can construct a ifstream object, and set its mode to text or binary. If a file name is specified in the constructor, the file will be opened automatically when constructing this object or the member function open can be used to open the file after the default constructor. Many format options and member functions of ifstream objects can be used, using all the functions in the basic classes ios and istream.

# 11.3.1 Construct Input Stream Object

It is unnecessary to construct an input stream object only if the predefined cin is used. If a file stream is needed to read information from it, a constructor should be used to establish a stream object. Two commonly used methods for constructing input file streams are shown below:

+   1. Use the default constructor, and then call member function open to open the file as shown in the following example:
```cpp
ifstream myFile;                   //define a file stream object
myFile.open("filename",iosmode);  //open file "filename"

ifstream* pmyFile = new ifstream; //new a file stream object
myFile->open("filename",iosmode);  //use object pointer to call
                                     //function open to open the file
```
