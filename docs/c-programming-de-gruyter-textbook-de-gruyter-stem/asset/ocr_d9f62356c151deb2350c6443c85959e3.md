An input i stream object is the origin of data flow. The three most important streams are istream, ifstream, and stringstream.

An iostream object is the origin or destination of the data. The two important I/O classes fstream and stringstream are derived from iostream.

We only introduced the concept and simple applications of stream class library. Readers should refer to a class library reference manual or online help for more details.
