
Note there are no assignment statements and function call statements in C++, and we have to use expressions to achieve assignment and function call. We have already introduced assignment expressions in Chapter 2.2.5, and we will introduce function calls in Chapter 3.

Adding a semicolon at the end of an assignment expression will make it a statement. For example:

```
a=a+3;
```

It is an expression statement, and it achieves the same function as an assignment statement.

The difference between an expression and expression statement is: an expression can be a part of another compound expression and continue to participate in operations, while a statement does not have this function.

## 2.3 Data Input and Output

### 2.3.1 I/O Stream

C++, the movement of data from one object to another using it, is abstracted as a “stream”. One should establish a stream before using it, and delete it after use. To get data out from a stream is called an extract operation, and to put data into a stream is called an insert operation. I/O stream is used to achieve data input and output, and **cin** deals with standard inputs, i.e., input from terminal. **cout** deals with standard outputs, i.e., output directed to terminal.

### 2.3.2 Predefined Input and Output Operator

“<<” is the predefined output operator. Using it on the stream-type object **cout** can achieve most general outputs. The format is:

```
cout<< expression...
```

You can use successive output operators in one statement to output several data items. You can write any compound expression after the output operator, and it will calculate its value and deliver it to the output operator. For example:

```
cout<<"Hello!\n";
```

It outputs the character string “Hello!” to the screen and then jumps to a new line.

```
cout<<"a+b="<<a+b;
```

The most general input is to use the input operator on stream-type object. The format is:

```
cin>>expression...
```

In an input statement, one can write several input contiguously, each followed by an expression that stores the variable. For example:

```
int a,b;
cin>>a>>b;
```

To input two int-type numbers from the keyboard, we can use space to separate the two numbers. If one enters:

```
5 6
```

Then the value of variable a is 5 and the value of variable b is 6.

### 2.3.3 Simple I/O Format Control

When using cin and cout for input and output, computers can process any type of data according to default format. But this is not enough. we often need special formats. There are many ways to set a format, and we will detail them in detail. In this section we only include simplest format control.

C++ I/O-stream library provides some operators that can be directly embedded into input/output statements to achieve I/O format control. To use these operators, one should first include iomanip header file at the beginning of the source program. The commonly used I/O-stream operators are listed in Table 2.6.

For example, if you want to output floating number 3.1415 to the screen and jump to a new line, you can set the field width to five characters and keep significant digits the decimal point. The output would be:

For example: the following piecewise function calculates the value of y when entering a value of x.

y = { -1 (x < 0)

### 2.4.1 Case Structure Using if Statement

if statements are designed to achieve case structure. Their syntax form is:

```
if (expression) statement 1
else statement 2
```

The execution order is: firstly evaluate the expression; if the expression is true, execute statement 1; otherwise execute statement 2. The flow chart of an if statement is shown in Figure 2.5.

Statement 1 and 2 can also be several statements enclosed in brackets (known as a compound statement). For example:

```
if (x>y) cout<<x;
else cout<<y;
```

The above statements output the larger number between x and y.

Statement 2 can be empty. When statement 2 is empty, we can ignore else, and the syntax form becomes the following:

```
if (expression) statement
```

For example:
if (x>y) cout<<x

Example 2.2: Input a certain year and determine whether it is a leap year.
Analysis: a year is divisible by 4 but not by 100, or is divisible by 400. Therefore, we can first store the value of the input into the variable, and then evaluate the expression. If the expression is true, then the input is a leap year; otherwise it is not.

Source code:

```cpp
//2_2.cpp
#include <iostream>
using namespace std;
int main()
{
    int year;
    bool IsLeapYear;

    cout << "Enter the year: ";
    cin >> year;
    IsLeapYear = ((year % 4 == 0 && year % 100 != 0) ||
                 (year % 400 == 0));

    if (IsLeapYear)
        cout << " is a leap year" << endl;
    else
        cout << " is not a leap year" << endl;
}
```

The result (the underlined part is the input content, the rest is output content. All the examples afterwards are the same):

```
Enter the year: 2000
2000 is a leap year
```
