## Inheritance and Derivation

The rule of inheritance in C++ is about the use of derived-class objects. After public derivation, a derived class has all functionalities of the base class. We can use a derived class to substitute the base class wherever needed. This lays the foundation for polymorphism, which will be discussed in the next chapter.

# 8 Polymorphism

The power of object-oriented programming lies not only in inheritance but also in its ability to treat derived-class objects like base-class objects. This mechanism supports dynamic binding.

## 8.1 Overview of Polymorphism

Polymorphism means that different objects behave differently when given the same message. The call by member functions is due to different implementations. Polymorphism is quite often used in programming. The most common example is the operator. We use the same sign '+' to implement addition operation over integers, floats, and double-precision floats. The same message is accepted by different objects or variables, which carry out the addition operation in different ways. If the addition operation is performed on variables of different types, e.g., float and integer, the first will be converted to floating point before addition. This is a typical polymorphism.

### 8.1.1 Types of Polymorphism

Object-oriented programming can be divided into four types: overload polymorphism, coercion polymorphism, inclusion polymorphism, and argument polymorphism. The former two fall into the category of special polymorphism, while the latter two are general polymorphism. Overloading of ordinary functions and class member functions are both overload polymorphism. We will learn operator overloading. The example of addition between floating numbers and integers is an example of overload. Coercion polymorphism is converting the type of a variable to meet the requirement of the function or operation. When adding a float and an integer, we should first do coercion to convert the integer to float. This is an example of coercion polymorphism.

Inclusion polymorphism is the behavior of member functions with the same name in different classes within a class family. It is implemented using virtual functions. Argument polymorphism and class templates (to be introduced in Chapter 9) are related to each other. This polymorphism must be assigned an actual type before realization. So, all classes instantiated from the class template have the same operations, but the types of operands are different.

This chapter mainly introduces overloading and inclusion polymorphism. Function overloading has been elaborated in Chapters 3 and 4. Here we mainly introduce operator overloading. Virtual function is the main issue of polymorphism.

## 8.1.2 Implementation of Polymorphism

Polymorphism can be divided into two groups in terms of implementation: **compiling polymorphism and executing polymorphism**. For the former group, the operands in the same operation are determined during compilation, while for the latter group, they are determined dynamically during execution. The process of determining the operands is binding. Binding is a procedure in which computer programs relate themselves. It also means the identifier and memory address. In object-oriented programming, **binding is the process of connecting a message with a function**. According to the different stages of binding, there are two ways of binding: static binding and dynamic binding, corresponding to two methods of polymorphism implementation.

**A static binding is a binding during the compiling and linking processes.** Because binding is done before the execution, it is also called early binding. During compiling and linking, the system can determine the relation between the operation and the code for the operation according to features such as type matching. In other words, it determines the proper code for a certain identifier. The operands with the same operation name can be decided during compiling and linking for polymorphism types. It is done by static binding, such as overloading, coercion, and argument polymorphism.

**If binding is performed during execution, it is called dynamic binding.** In some cases, binding cannot be performed during compiling or linking, such as operator overloading. The operations are performed during the execution.

## 8.2 Operator Overload

The question is how to perform the addition operation between $a$ and $b$. Naturally, we would like to use the operator “+” and write the expression $a+b$.

```cpp
complex a(10,20), b(5,8);
``` such expression will render an error during compilation because the compiler does not know how to perform the addition operation. In this, we must write a program to clearly specify the operator when it operates on complex number objects. This is called operator overload. Operator overload makes existing operators more versatile and, with overload, an operator can act on different types of data.

Operator overload is essentially function overload. We should first convert the expression to the call of an operator function. The operands are converted to actual arguments. And then the function to be called is determined according to the type of actual arguments, which is completed in the compilation process.

### 8.2.1 Rules of operator overload

The rules of operator overload are as follows:

*   All operators in C++ can be overloaded except a few exceptions and only those existing operators in C++ can be overloaded. own*   After overloading, the priority and associativity are still the same.
*   Operator overload meets the actual needs of new types of data and makes appropriate modifications to the original operator. Generally speaking, an overloaded function should be similar with the original operator. The number of operands cannot be changed and at least one operand should be a user-defined type.
