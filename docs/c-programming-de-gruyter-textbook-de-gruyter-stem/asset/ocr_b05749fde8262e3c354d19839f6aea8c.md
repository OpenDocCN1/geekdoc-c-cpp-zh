# 2. Using Character Arrays to Store Strings

In Example 6.22 and Example 6.23, we process array elements by one one, and characters in the array are independent. There is no '\0' at the end, so this doesn't comprise a C++ string. If we put '\0' at the end of a character array in its initialization, we will get a string of C++. Here we should note that the size of the array used to store a string must be no less than the length of the string (the number of characters) plus 1. When we initialize a character array, the form of initial values are ASCII characters or character constants separated by commas, or a whole string constant ('0' in the end is hidden). So the following statements are all correct:

```
static char str[8]={112,114,111,103,114,97,109,0};
static char str[8]={'p','r','o','g','r','a','m','\0'};
static char str[8]="program";
static char str[]="program";
```
