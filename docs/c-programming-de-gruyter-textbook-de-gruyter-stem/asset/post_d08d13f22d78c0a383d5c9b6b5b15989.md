```cpp
class Matrix //define base class Matrix
public:
    Matrix(int dims=2); //constructor

    void setMatrix(double* rmat); //set initial value for matrix
    void printM(); //display matrix

    Linequ(int dims=2); //constructor
    ~Linequ(); //destructor
```

Through public derivation, class Linequ inherits all the members of class Matrix except for the constructor and the destructor. Because all the base-class members are public or protected, they are accessible in the function members of the derived class. The protected members of the base class, are not accessible in the module creating objects of class Linequ. By using the protected access attributes and public derivation, we realize efficient sharing and reliable protection of data of the base Matrix. In the program, we store the coefficient matrix, the solution vector, and the vector on the right side of the equations all through dynamic memory allocation, which are implemented in the constructors of the base class and the derived class. The cleanup work is done in destructors.

```cpp

    *(MatrixA+i)=rmat[i]; //set initial value of the matrix

Matrix::Matrix(int dims)
{
    index=dims; //protected data assignment
    MatrixA=new double[index*index]; //dynamic memory allocation
```

## 318 7.6 Program Example: Solving Linear Equations using Gaussian Elimination Method — 301

```cpp
//Public Function member No.6 Constructor
int Linequ::Solve()//use complete pivoting elimination
//method to solve linear equations
{
    int js,l,k,i,j,is,p,q;
    double d,t;
    js=new int[index];
    l=1;
    for(k=0;k<=index-2;k++) //elimination
        d=0.0;
        for(i=k;i<=index-1;i++) {
            for(j=k;j<=index-1;j++) {
                t=fabs(MatrixA[i*index+j]);
                if(t>d)
                    d=t;js[k]=j;is=i;
            }
        }
        if(d+1.0==1.0) l=0;
        else
            if(js[k]!=k)
                for(i=0;i<=index-1;i++) {
                    p=index+k; q=index+js[k];
                    MatrixA[p]=MatrixA[q]; MatrixA[q]=t;
                }
                if(!is)
                    for(j=k;j<=index-1;j++) {
                        p=k*index+j; q=is*index+j;
                        MatrixA[p]=MatrixA[q]; MatrixA[q]=t;
                    }
                t=sums[k]; sums[k]=sums[is]; sums[is]=t;
            }
    }
    if (l==0) delete[] js; cout<<"fail"<<endl;
```

In the process of implementing class functions, the constructor of the derived class also calls the constructor of the base class to pass arguments and it dynamically allocates memory space for the matrix. The destructor of the derived class also calls the destructor of the base class. Every calling procedure is completed with the system automatically. After public derivation, protected base-class members remain as protected members in the derived class, which can be accessed by the member functions of the derived class.
