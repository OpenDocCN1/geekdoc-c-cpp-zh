### L 类旋转

当从 A 的左子树删除一个节点时，向上路径到根节点的第一个祖先节点导致 bf(A) 变为 -2。然后为重新平衡不平衡的 AVL 搜索树，使用 L 类旋转。根据 A 的右子树根节点的平衡因子，这些旋转可进一步分类为：当其平衡因子为 0 时为 L0，为 +1 时为 L1，为 -1 时为 L-1。L0、L1 和 L-1 旋转的一般表示如图 12.26 所示。此处 $B'_L$ 为删除后 B 的左子树。
