**Path:** In an undirected graph G, a sequence P of zero or more edges of the form {v,v1}, {v1,v2}, ..., {vn-1,vn} or v0-v1-...-vn is called a path from v0 to vn where v0 is the initial vertex and vn is the terminal vertex of the path P.
In the definition of path, vertices and edges may be repeated.
If v0=vn, then P is called a closed path.
If v0 != vn, then P is called an open path.

**Circuit:** A path of length ≥ 1 with no other repeated vertices or edges except its starting and ending vertices is called a circuit.

**Length of the path:** The number of edges appearing in the sequence of the path P is called the length of the path.
If the length of the path P is zero, i.e. path P has no edges at all, it contains only a single vertex and is called a trivial path.

**Isomorphism:** Two graphs G and G' are said to be isomorphic, there is a one-to-one correspondence between their vertices and between their edges such that the incident relationship is preserved.
In other words, if vi and vj are the vertices in graph G, v'i and v'j are the corresponding vertices in graph G', then for an edge having vi and vj as the end vertices in G, there is a corresponding edge in G' with v'i and v'j as the end vertices. Then G and G' are said to be isomorphic.

+   Conditions for isomorphism:
+   1. Both graphs should have the same number of vertices.
+   2. Both graphs should have same number of edges.
+   3. Both graphs should have an equal number of vertices with the same degree.
+   4. Both graphs should have the same cycle vector (c1, c2, ..., ck), where ci = number of cycles of length i.
