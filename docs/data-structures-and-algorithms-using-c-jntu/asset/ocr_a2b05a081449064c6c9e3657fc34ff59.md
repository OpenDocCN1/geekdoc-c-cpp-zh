# **Figure 11.13** Insertion using swapping

To insert element 16, a new node is created in the next available heap location (Figure 11.13(a)). Insert 16 in the new node. Element 16 in this location would violate min heap property. Hence, move 16 up by swapping with its parent. Since 33 parents of the new node is greater than 16, swap 33 and 16; 16 is moved up and is indicated by a dashed line: Figure 11.13(b). At this stage (Figure 11.13(b)), heap does not min heap property. Hence, 16 needs to be moved up further. Since 23 which is a parent of 16 is greater, swap 23 with 16 (Figure 11.13(c)) which is shown by a dashed line. In Figure 11.13(c), further swapping is not required since min heap property is achieved. The time for inserting an element into priority queue could be as much as O(log N) if the element is moved all the way to the root.
