## 10.5 GRAPH TRAVERSALS

Similar to the case of trees, traversal visits elements of the nodes in a particular manner. Graphs can be traversed in two ways. They are:

- Breadth first traversal
- Depth first traversal

### 10.5.1 BREADTH FIRST TRAVERSAL

An arbitrary vertex V is selected to begin the traversal, visit the vertex. All the adjacent vertices of V, a, are visited. Now, the unvisited adjacent vertices of each a1,b1 are visited. This process continues till all the vertices of the graph are visited. The vertices whose adjacent vertices are to be visited are kept in queue.

### Algorithm 10.8

```
breadthfirsttraversal(G)
```

This algorithm performs breadth first traversal starting from the vertex V of graph G /*QUEUE is a queue, keeping track of vertices whose adjacency nodes are to be visited. Vertices which are visited are set to 1 Initially all the vertices in a graph are set to 0*/

- 1. Initialize queue QUE
- 2. Set Visit(V) to 1
- 3. Insert the vertex V into QUE
- 4. Loop till the QUE is empty then perform deletion from QUE
- 5. Display the visited vertex
- 6. Loop for all adjacent vertices A of V
- 7. Check whether visit (A) is zero then insert vertices into QUE
- 8. Set VISIT(A) to 1
- 9. End loop
- 10. End loop
- 11. End

Dequeue 'c' to visit its two adjacent vertices 'f', 'g' and then enqueue the traversal output at this stage is abc. Now, dequeue 'd' to visit its adjacent vertex 'h' and enqueue it. The traversal output at this stage is abcd. Dequeue 'e' to visit its adjacent vertex 'i', enqueue 'i'. The traversal output at this stage is abcde. Dequeue 'f', its only adjacent vertex 'i' is already visited. The traversal output at this stage is abcdf. So, proceed to dequeue 'g' to visit its adjacent vertex 'j', enqueue it. Now the traversal output is abcdefg. Dequeue 'h', its only adjacent node 'j' is also already visited. So, no enqueue is required. The traversal at this stage is abcdefgh. Dequeue 'i', it does not have any unvisited vertices, so no enqueue is required. The traversal at this stage is abcdefghi. Dequeue 'j' the queue is empty as all its adjacent vertices are already visited, no further enqueuing is required. The final traversal output is abcdefghij.
