Let A[1:R, 1:C] be a two-dimensional array with R and C data elements where R is the number of rows and c is the number of columns in the array A. Each element in array is represented by a pair of integers called subscripts such as A[i] [j], where i range from 1 to R and j range from 1 to C. Two-dimensional arrays are also called matrix arrays. # 4.2.3 N-dimensional ARRAY

An N-dimensional m1 x m2 x ... x mn array A is a collection of m1, m2, m3 ... mn data elements, where each element is referred by a list of n integer such as j1, j2, ..., jn called subscripts where 1<=j1<=m1, 1<=j2<=m2, 1<=j3<=m3, ..., 1<=jn<=mn.
