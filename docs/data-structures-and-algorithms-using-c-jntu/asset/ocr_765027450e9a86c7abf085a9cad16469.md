**L category rotations:** When a node is deleted from the left subtree of A, the first ancestor node in the path to the root in upward direction leads bf(A) to -2. Then to rebalance an unbalanced AVL search tree, L category rotations are used. With respect to balance factor of the root of the right subtree of A these rotations can be further classified as L0 when its balance factor is 0, L1 when its right factor is +1 and L-1 when its balance factor is -1.
