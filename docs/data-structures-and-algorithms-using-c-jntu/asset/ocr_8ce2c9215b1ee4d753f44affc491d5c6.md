# Incidence matrix representation:

For a graph G=(V,E) of n vertices and e edges the incidence matrix, is an n×e matrix, and every entry of this matrix is defined as

```
a_{ij} = 1, if an edge e_j is incident on vertex v_i
a_{ij} = 0, otherwise
```

| | e1 | e2 | e3 | e4 | e5 | e6 | e7 |
|---|---|---|---|---|---|---|---|
| v1 | 1 | 1 | 0 | 0 | 0 | 0 | 0 |
| v2 | 1 | 0 | 1 | 1 | 0 | 0 | 0 |
| v3 | 0 | 1 | 1 | 0 | 1 | 0 | 0 |
| v4 | 0 | 0 | 0 | 1 | 1 | 1 | 0 |
| v5 | 0 | 0 | 0 | 0 | 0 | 1 | 1 |
| v6 | 0 | 0 | 0 | 0 | 0 | 0 | 1 |
