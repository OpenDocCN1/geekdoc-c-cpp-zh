+   2. Set PTR to RLINK of PTR
+   3. End Loop
+   4. Call GETNODE(N) //get the new node
+   5. Set N PTR to RLINK of PTR //N PTR is the pointer to next node after /node with VALUE
+   6. Set LLINK of N to PTR
+   7. Set RLINK of N to NPTR
+   8. Set RLINK of PTR to N
+   9. Set LLINK of NPTR to N
+   10. Set PTR to N
+   11. Assign ITEM to DATA of N
+   12. End

# 5.5.2.2 Deletion

Like insertion, the deletion operation can also be performed in three ways:

+   1. Deletion of the first node
+   2. Deletion of the last node
+   3. Deletion at a specified position

**Deletion of the first node:** Deleting the first node, that is, deleting the link between the HEAD node and the first node and LLINK of the node after the deleted node is updated to point to the HEAD node and then it becomes the first node (Figure 5.21; Algorithm 5.13).
