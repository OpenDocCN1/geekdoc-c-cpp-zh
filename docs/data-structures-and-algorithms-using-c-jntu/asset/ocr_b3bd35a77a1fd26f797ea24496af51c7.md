# Algorithm 5.4: SL-INSERT-E

+   1. call GETNODE(N) to allocate memory for N and return the points of N.
+   2. Set PTR to HEAD. //HEAD is pointer to head node.
+   3. Loop to move to the end of the list and insert.
+   4. Set PTR to LINK of PTR.
+   5. End loop.
+   6. Set LINK of PTR to N.
+   7. Set DATA of N to ITEM.
+   8. End.
