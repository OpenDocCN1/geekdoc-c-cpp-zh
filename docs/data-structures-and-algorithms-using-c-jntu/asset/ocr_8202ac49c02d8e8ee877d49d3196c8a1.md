# Algorithm 10.8

```
breadthfirsttraversal(G)
```

This algorithm performs breadth first traversal starting from the vertex V of graph G /*QUEUE is a queue, keeping track of vertices whose adjacency nodes are to be visited. Vertices which are visited are set to 1 Initially all the vertices in a graph are set to 0*/

+   1. Initialize queue QUE
+   2. Set Visit(V) to 1
+   3. Insert the vertex V into QUE
+   4. Loop till the QUE is empty then perform deletion from QUE
+   5. Display the visited vertex
+   6. Loop for all adjacent vertices A of V
+   7. Check whether visit (A) is zero then insert vertices into QUE
+   8. Set VISIT(A) to 1
+   9. End loop
+   10. End loop
+   11. End
