

## 练习

### 填空题

- 1. _______ 算法的复杂度与 O(n²) 相同
- 2. 归并排序和快速排序遵循 _______ 原则。
- 3. 归并排序的时间复杂度是________
- 4. 希尔排序通过________对数组进行排序。
- 5. 基数排序使用 _______ 来对元素进行排序。

### 选择题

- 1. 以下哪种排序算法属于分治类型？
  - a. 冒泡排序
  - b. 插入排序
  - c. 快速排序
  - d. 以上都是

- 2. 冒泡排序算法的复杂度是
  - a. O(n)
  - b. O(log n)
  - c. O(n²)
  - d. O(n log n)

- 3. 归并排序算法的复杂度是_______
  - a. O(n)
  - b. O(log n)
  - c. O(n²)
  - d. O(n log n)

- 4. 在堆树中
  - a. 节点中的值大于左子树中的每个值且小于右子树中的每个值
  - b. 节点中的值大于其每个子节点的值
  - c. a 和 b 都是
  - d. 都不是

- 5. 查找给定值元素的位置是_______。
  - a. 遍历
  - b. 查找
  - c. 排序
  - d. 都不是

- 6. 线性查找算法的最坏情况发生在_______。
  - a. 项目在数组中间的某个位置
  - b. 项目根本不在数组中
  - c. 项目是数组中的最后一个元素
  - d. 项目是数组中的最后一个元素或根本不在其中

- 7. 线性查找算法的复杂度是
  - a. O(n)
  - b. O(log n)
  - c. O(n²)
  - d. O(n log n)

- 8. 二分查找算法的复杂度是
  - a. O(n)
  - b. O(log n)
  - c. O(n²)
  - d. O(n log n)

- 9. 以下哪项不是二分查找算法的必需条件？
  - a. 列表必须已排序
  - b. 需要直接访问任何子列表中的中间元素
  - c. 需要在列表中插入和/或删除元素
  - d. 都不是

### 简答题

- 1. 定义各种排序算法。
- 2. 证明任何基于比较的对 4 个元素进行排序的算法至少需要 5 次比较。
- 3. 两个总大小为 N 的已排序数组有多少种合并方式？
- 4. 堆的属性有哪些？
- 5. 对长度为 n 且已按递增顺序排序的数组 A 进行堆排序的运行时间是多少？按递减顺序排序的情况又如何？
- 6. 定义线性查找并给出其复杂度。
- 7. 解释二分查找和斐波那契查找的时间复杂度。

### 论述题

- 1. 对以下内容进行说明：
  - a. 冒泡排序
  - b. 插入排序
  - c. 选择排序

- 2. 详细解释
  - a. 快速排序
  - b. 归并排序

- 3. 写简短笔记
  - a. 希尔排序
  - b. 基数排序

- 4. 对以下列表追踪堆排序算法：
  [25, 44, 55, 99, 30, 37, 15, 10, 2, 4]。

- 5. 修改 BUILD-HEAP 算法以创建最小堆，并用示例说明。
- 6. 比较各种排序算法的复杂度。
- 7. 讨论（i）线性查找和（ii）二分查找。
- 8. 对斐波那契查找进行说明。
