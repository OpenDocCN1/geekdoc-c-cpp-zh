# 3.7.1.1 Finding g(x), c and n_o Values

# Example 1

Let f(n) = 3n+2 for an algorithm. Computation of c, n_o, and g(n) can be performed as f(n) = 3n+2. The function can be written in terms of g(n) as

```
f(n) <= c*g(n)
3n+2 <= c*g(n) because the function value is more than 3n, consider c=4, then
3n+2 <= 4*g(n) define g(x)=n
3n+2 <= 4n find n_o.
Put n=1      3.1+2 <= 4.1 (condition failed)
So put n=2   3*2+2 <= 4*2 (true)
Put n=3      3*3+2 <= 4*3 (true)
Put n=4      3*4+2 <= 4*4 (true)
```

So, as per the mathematical induction, the function f(x) can be written in terms of g(x), and is true from n_o=2 to all positive integers. The function f(x) can be defined as f(x)<=4n where n>=2

# 3.7.2 Omega Notation (Ω)

Definition: f(n) = Ω(g(n)) if there exists positive constants c and n_o, such that f(n)>=c*g(n) or all n>=n_o. In this case, the maximum possible lower bound will be selected.
