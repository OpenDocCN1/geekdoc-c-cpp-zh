```
  (%make-property name
    (get-predicate-property plist)
    (get-default-supplier plist)))
```

A property is implemented as a Scheme record [65], which is a data
structure that consists of a set of named fields. It is defined by
elaborate syntax that specifies a constructor, a type predicate, and an
accessor for each field:

```
(define-record-type <property>
  (%make-property name predicate default-supplier)
    property?)
  (name-property)
  (predicate-property)
  (default-supplier property-default-supplier))
```

We choose to give the primitive record constructor %make-
property a name with an initial percent sign (%). We often use the
initial sign to indicate a low-level procedure that will not be
 except to support a higher-level abstraction. The %make-
property procedure is used only in make-property, which in
turn is used by other parts of the system.

Given a set of properties, we can construct a type predicate:

```
(define (make-type name properties)
  (guarantee-list-of-properties properties)
  (let ((type
    (simple-abstract-predicate name instance-data?))
    (%set-type-properties! type properties))
  type))
```
