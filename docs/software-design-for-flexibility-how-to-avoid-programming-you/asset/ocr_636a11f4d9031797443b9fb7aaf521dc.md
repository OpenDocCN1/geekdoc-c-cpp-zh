Here are some example patterns:

(r:seq (r:quote "a") (r:dot) (r:quote "c")
matches any three-character string beginning with a and ending with c. For example, it will match abc and aac and acc.

(r:alt (r:quote "foo") (r:quote "bar") (r:quote
"baz")
matches each foo, bar, or baz.

(r:repeat 3 5 (r:alt (r:quote "cat") (r:quote
"dog")) matches catdogcat and catcatdog and
dogdogcatdogdog but not catcatcatdogdog.

We will implement patterns as Scheme expressions. Thus we can
freely mix them with any Scheme code, giving us all the power of the
programming language.
