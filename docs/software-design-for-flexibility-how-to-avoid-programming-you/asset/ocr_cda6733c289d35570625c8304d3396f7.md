```
(define a-list (list 6 946 8 356 12 620))

a-list
(6 946 8 356 12 620)

(list? a-list)
#t

(list? 3)
#f
```

 #t and #f are the printed representations of the boolean values true and false.6

Lists are built from pairs. A *pair* is made using the constructor cons. The selectors for the two components of the pair are car and cdr (pronounced “coud-er”).7

```
(define a-pair (cons 1 2))
```

```
a-pair
(1 . 2)
```

```
(car a-pair)
1
```

```
(cdr a-pair)
2
```

```
(car a-list)
6
```

```
(cdr a-list)
(946 8 356 12 620)
```

```
(car (cdr a-list))
946
```

```
(define another-list)
(cons 32 (cdr a-list)))
```
