For assigning to the elements of a data structure, such as a pair,
list, or a vector, Scheme provides:

```
(set-car) pair new-value)
(set-cdr) pair new-value)
```

```
(list-set) list index new-value)
(vector-set) vector index new-value)
```

A record may be defined to allow assignments to its fields
(compare page 388):

```
(define p (make-point 1 2))
```

```
(point-x p)
1
(point-y p)
2
```

```
(set-x! p 3)
3
(point-x p)
(point-y p)
2
```

In general, it is good practice to avoid assignments when possible,
but if you need them they are available.12
