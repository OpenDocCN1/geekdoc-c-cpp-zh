# a-trie

![](bbox=[0.198, 0.093, 0.802, 0.315])

**Figure 3.1** A trie can be used to classify sequences of features. A Trie is a directed graph in which each edge has a predicate. Starting from the root, the first feature is tested by an edge proceeding from the root. If a predicate is satisfied, the process moves to the node at the end of that edge and the next feature is tested. This is repeated with successive features. The classification of sequence is the set of terminal nodes arrived at.

```
define a-trie (make-trie)
```

We can add an edge to this trie

```
define s (add-edge-to-trie a-trie symbol?))
```

where add-edge-to-trie from the root returns the new node that is at the target end of the new edge. This node is reached by being matched against a symbol.

We can make chains of edges, which are referenced by lists of the corresponding edge predicates

```
define sn (add-edge-to-trie s number?))
```

**The node sn** is reached from the root via the path (list symbol number?). Using a path, there is a simpler way to make a chain of edges than repeatedly calling add-edge-to-trie:

```
(define ss (intern-path a-trie list symbol? symbol)))
```
