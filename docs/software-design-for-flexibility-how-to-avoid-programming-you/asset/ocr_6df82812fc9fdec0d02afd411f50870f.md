# 4.5.6 Implementing graph matching

The entry point for using a graph pattern is:

```
(define (graph-match path dict object)
  (gmatch:compile-path path) object dict
  (lambda* object* dict*)
  dict*))
```

We compile the pattern into a match procedure that takes the graph object to start, an initial dictionary, and a success continuation. If the pattern successfully matches a sequence of edges starting with node, it calls the success continuation, which takes the node (object*) at the end of the matched path and a dictionary of bindings accumulated in the match, as described in section 4.3.18 If the pattern fails to match the given object the match procedure returns #f.
