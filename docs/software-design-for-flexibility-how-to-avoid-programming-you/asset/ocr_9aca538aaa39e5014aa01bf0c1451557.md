The name the-composition is not defined outside the scope of the definition of compose, so there is no obvious advantage to this way of writing the compose procedure. We often use anonymous procedures defined by lambda expressions in our programs, as in the first version of compose above. The choice of how to write the program is mostly a matter of style.^3

Even with just this compose combinator we can write some elegant code. Consider the problem of computing the nth iterate of a function f(x)=f⁻¹(x). We can write this elegantly as a program:

```
(define ((iterate n) f)
  (if (= n 0)
    identity
    (compose f ((iterate (- n 1) f))))
```

The result of ((iterate n) f) is a new function, of the same type as f. It can be used wherever f can be used. So (iterate n) is itself a combinator. Now we can use this to determine the result of repeatedly squaring a number:

```
((iterate 3) square) 5
390625
```

Notice the analogy: function composition is like multiplication, so function iteration is like exponentiation.
