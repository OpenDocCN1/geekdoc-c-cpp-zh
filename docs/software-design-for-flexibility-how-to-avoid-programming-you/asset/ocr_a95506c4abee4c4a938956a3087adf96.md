To make it easy to experiment with different dispatch stores, we gave generic-procedure-constructor and make-generic-arithmetic the dispatch store maker. For example, we can build a full generic arithmetic as on page 95 but using make-trie-dispatch-store as follows:

```
(define trie-full-arithmetic
(let ((g (make-generic-arithmetic make-trie-dispatch-store))
  (add-to-generic-arithmetic! g numeric-arithmetic)
  (extend-generic-arithmetic! g function-extender)
  (add-to-generic-arithmetic! g)
  (symbolic-extender numeric-arithmetic))
 g))
```

We have provided a crude tool to measure the effectiveness of our dispatch strategy. By wrapping any computation with with-predicate-counts we find out how many times each dispatch predicate is called in an execution. For example, evaluating fib 20 in a generic arithmetic with a trie-based dispatch store may yield something like this:29

(define fib n)
(if (< n 2)
 n
  (+ fib (- n 1)) (fib (- n 2))))
