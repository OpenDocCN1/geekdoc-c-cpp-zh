# Exercise 7.1: Making writing propagator networks easier

In our propagator system it is pretty painful to write the code to build even a simple network, because all internal nodes must be named. For example, a constraint propagator that converts Celsius and Fahrenheit temperatures looks like:

```
(define-c:prop (celsius fahrenheit)
(let-cells (u (nine 9) (five 5) (thirty-two u))
  (c:* celsius u)
  (c:* five u)
  (c:* thirty-two fahrenheit))
```

It would be much nicer to be able to use expression syntax for some propagators, so we could write:

```
(define-c:prop (celsius fahrenheit)
(c:+ (ce:* (ce:/ constant 9) (constant 5))
  celsius))
```
