Knight moves are special in chess, in that a knight can move over\squares occupied by a friend or an opponent to get to
target square. Rooks, bishops, and queens may not pass through
unoccupied squares on their way to a target square. We need a way to specify
such a repeated traversal. Use (* . . .) to specify a repeated
tversal.

```
(define basic-queen-move
'(? source-node ,occupied-by 'queen')
(* north (*?, ,unoccupied))
north (? target-node ,maybe-opponent))
```

The queen may move north through any number of unoccupied
squares to the target square. The notation (* . . .) is a new kind
of pattern variable that can be used only inside a (* . .) pattern.
Like a simple pattern variable, it matches one element, but instead of
saving just a single matched value, it collects a list of all elements
matched in the repeat. All of the queen's possible moves are:

```
(define all-queen-moves
(symmetrize-move basic-queen-move
rotate-45 rotate-90 rotate-180))
```
