each unary procedure we have to make the finite part of the result and the infinitesimal part of the result, and we have to put the results together, as expressed in equation 3.5. So the handler for a unary primitive arithmetic procedure that computes function f is constructed by diff:unary-proc from the procedure f for f and the procedure df for its derivative Df. These are glued together special addition and multiplication procedures d:+ and d:* for differential objects, to be explained in section 3.3.3.

```
(define diff:unary-proc f df)
(define uop x) ; x is a differential object
(let (xf (finite-part x))
  (dx (infinitesimal-part x))
  (d+: (f x) (d*: (df dx)))))
nuop)
```

For example, the sqrt handler for differential objects is just:

```
(define diff:sqrt
diff:unary-proc sqrt (lambda (x) (/ 1 (* 2 (sqrt x)))))
```

The first argument of diff:unary-proc is the sqrt procedure and the second argument is a procedure that computes the derivative of sqrt.

We add the new handler to the generic sqrt procedure using

```
(assign-handler! sqrt diff:sqrt differential?)
```

where differential? is a predicate that is true only of differential objects. The procedure assign-handler! is shorthand for a useful pattern:

```
(define (assign-handler! procedure handler preds)
(define-generic-procedure-handler procedure
  (apply match-args preds))
```

And the procedure match-args makes an applicability specification from a sequence of predicates.
