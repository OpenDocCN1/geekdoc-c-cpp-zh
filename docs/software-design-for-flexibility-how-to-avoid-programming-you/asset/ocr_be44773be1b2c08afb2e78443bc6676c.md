Ex or we want to compute a second derivative we must take a derivative of a derivative function. The evaluation of such a function will have two infinitesimals in play. To enable the computation of multiple derivatives and derivatives of functions of several variables we define an algebra of differential objects in “infinitesimal space.” The objects are multivariate power series in no infinitesimal increment exponent greater than one.23

A differential object is represented by a tagged list of the terms of the power series. Each term has a coefficient and a list of infinitesimal incremental factors. The terms are kept sorted, in descending order. (Order is the number of incrementals. So $\delta dx$ is higher than $\delta x$ or $\delta y$.) Here is a quick and dirty implementation:24

```
(define differential-tag 'differential')

(define (differential? x)
  (and (pair? x) (eq? (car x) differential-tag)))

(define (diff-h)
  (if (differential? h)
    (cdr h)
    (list (make-diff-term h ')))))
```

The list is just the cdr of the differential object. However, if we are given an object that is not explicitly a differential object, for example a number, we coerce it to a differential object with a single term and no incremental factors. When we make a differential object from a (presorted) list of terms, we always try to return a simplified version, which may be just a number, which is not explicitly a differential object:

```
(define (make-differential terms) ; Nonzero terms
  (let ((terms
    (filter
      (lambda (term)
        (let ((coeff (diff-coefficient term))
          (not (number? coeff) (= coeff 0))))
    terms)) 0))
    (cond ((null? terms)
      (and (null? (cdr terms)))
            ;; Finite part only:
            (null? (diff-factors (car terms))))
    (diff-coefficient (car terms))))
```
