```
(define-syntax amb
  (syntax-rules ()
    (amb exp ...)
    (amb-list (list (lambda () exp) ...))))
```

# For example:

```
(pp (syntax '(amb a b c) user-initial-environment)
  amb-list (list (lambda () a) (lambda () b) (lambda () c)))
```

The search maintains a search schedule, an agenda of thanks that can be called when it is necessary for an expression to return with a new alternative value. The procedure amb-list first adds the thanks for its alternative values to the search schedule and then yields control to the first pending thunk on the schedule. If there are no alternatives (the expression was just amb) then the amb-list yields control without adding anything to the search schedule and increments a global counter for auditing the search.

```
(define amb-list alternatives
  (if (null alternatives)
    (set! *number-of-calls-to-fail*
      (* *number-of-calls-to-fail* 1))))
```

```
(call/cc
  (lambda k
    ((add-to-search-schedule
      map (lambda alternative)
      (lambda ()
        (with-continuation k alternative))
     alternatives))
     (yield))))
```

For a particular amb expression the thanks for the alternatives are constructed so as to return from amb expression, using the continuation, k, captured at the entrance to their enclosing list.

The way to yield control is to retrieve a thunk specifying an alternative, if any, from the search schedule and execute it. The search schedule is both a stack and a queue; we will see it shortly.

```
(define (yield)
  (if deque-empty? (*search-schedule*)
    ((*top-level*) 'no-more-alternatives)
    ((pop! (*search-schedule*))))
```
