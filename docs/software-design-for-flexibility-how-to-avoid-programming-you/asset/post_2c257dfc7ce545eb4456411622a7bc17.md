## 5.2 Procedures with non-strict arguments

In this section we will investigate adding declarations to the formal parameters of a procedure to allow deferred evaluation of the corresponding operands.

In Scheme, procedures are *strict*. Strict procedures require evaluating all the operands of the calling expression and binding the resulting arguments to the formal parameters before the body of the procedure is evaluated. But for an *if* expression, the predicate part must be evaluated to determine whether to evaluate the consequent part or the alternative part; they won't be evaluated. This is why *if* must be a special form, not a procedure. A *non-strict* procedure is one that defers the evaluation of some operands. How can we make it possible for a programmer to define non-strict procedures as needed, rather than just using a few special forms, such as *if*, that are specified in the language definition?

For example, suppose we want to make a procedure *unless* that works like the special form *if* in that does not evaluate the alternatives that are not needed.¹³ Using *unless* we could write:

```
(define (unless condition consequent alternative)
  (if condition
      alternative
      consequent))
```

If we want a procedure to be non-strict, we must delay the evaluation of its arguments until they are needed. We can do this by wrapping the arguments in a special structure, often called a promise, and then providing a mechanism to evaluate the promise.

```
(define (promise expression)
  (list 'promise expression))

(define (force p)
  (if (equal? (car p) 'promise)
      (let ((val (eval (cdr p))))
        (set! (car p) val)
        val)
      p))
```

Now we can redefine *unless* to be non-strict:

```scheme
(define (unless-ns condition consequent alternative)
  (let ((cond (force condition)))
    (if cond
        (force alternative)
        (force consequent))))
```

This way, the `consequent` and `alternative` are only evaluated if they are actually needed. This is the power of non-strict arguments, and they can be used to implement many powerful control structures.
