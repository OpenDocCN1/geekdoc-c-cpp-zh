```
$x(t+h)-2x(t)+x(t-h)\nh^{2}=\sum_{j=0}^{k}A(j)F(t-jh,x(t-jh)\quad(3.2)$
```

with $h$ is the step size and $A$ is the array of magic coefficients.
For example, Stormer's integrator of order 2 is

```
$x(t+h)-2x(t)+x(t-h)\nh^{2}(13F(t,x(t))-2F(t-h,x(t-h))+F(t-2h,x(t-2h))\quad(3.3)$
```

With this to compute the future of $x$ we write a program. The procedure returned by $stormer-2$ is an integrator for a given function and step size, given a history of values of $x$, produces an estimate of the value of $x$ at the next time, $x(t+h)$. The procedures $t$ and $x$ extract precise times and values from the history: ($x$ 0 history) returns $x(t)$, ($x$ 1 history) returns $x(t-h)$, and ($x$ 2 history) returns $x(t-2h)$. We access the time of a step from the history similarly: ($t$ 1 history) returns $t-h$.

```
define (stormer-2 F h)
(lambda (history))
  (+ 2 (x 0 history))
  (* -1 (x 1 history))
  (* / (expt h2 12))
    (* 13 (F 0 history) (x 0 history))
      (* -2 (F 1 history) (x 1 history))
      (F 2 history) (x 2 history))))))
```

The procedure returned $stepper$ takes a history and returns a new history advanced by $h$ for the given integrator.

```
define (stepper h integrator)
(lambda (history))
  (extend-history (+ t 0 history)
    (integrator history)
    history)))
```

The procedure $stepper$ is used in the procedure evolver to produce a procedure $step$ that will advance a history by one step.
