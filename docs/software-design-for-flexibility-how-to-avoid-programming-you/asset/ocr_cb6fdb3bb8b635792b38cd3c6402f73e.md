conditional propagators controlled by cells whose true or false values are modulated by binary-amb propagators, but this is very inefficient and introduces lots of extra machinery. So we provide a native n-ary choice mechanism with p:amb. The procedure p:amb is analogous to binary-amb. For binary-amb there are exactly two choices, #t or #f, for the value in the cell, and each is supported by a hypothetical premise. When p:amb is applied to a cell and a list of possible values, the procedure make-hypotheticals adds values to the cell, each supported by a new hypothetical premise.

When the propagator constructed by p:amb is activated, the procedure amb-choose is called. It first tries to find a hypothetical premise, among its hypotheticals, that is not ruled out by its premise-nogoods. If there is one, it marks premise in and marks all of the other premises out, thus choosing the value associated with that premise of the cell. If none of the hypothetical premises can be believed, it marks all of its out and makes a new set of nogoods to pass to process-contradictions, which will retract a hypothetical premise from one of those nogoods, possible. The generalization of the procedure pairwise-union takes more than two setsis cross-product-union. As before, this is a resolution step.

(define (p:amb cell values)
(let ((premises make-hypotheticals cell values))
  (define amb-choose
    (let ((to-choose
      (find (lambda premise)
        (not any all-premises-in?
          (premise-nogoods premise))))
      premises)))
    (for-each (lambda premise)
      (if eq7 to-choose
        (mark-premise-in! premise)
        (mark-premise-out! premise)))))
    premises))

  (cross-product-union
