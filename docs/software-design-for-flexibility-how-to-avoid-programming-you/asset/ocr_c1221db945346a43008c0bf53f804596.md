In the embedded interpreter version of amb in section 5.4.2 we showed how to use two kinds of assignment: the usual permanent assignment, indicated by set!, and the undoable assignment, indicated by `may-set!`, which gets undone by backtracking. We can implement a general wrapper for undoable effects in the native-code implementation of this section:

(define (effect-wrapper doer undoer)
