## Repository repository form

As applications grow in size and the tasks required of them are varied, a way to organize work within the application is needed. In fact, there are many models supported by Xamarin for this purpose, such as the MVVM model that is used effectively within Xamarin to organize and separate the parts responsible for the interfaces for the parts responsible for the business logic from those responsible for dealing with remote or local data servers of various types.

One of my models that I personally prefer is the Repository which I use extensively in all kinds of applications I am working on. It is a beautiful and rational method that allows the application to develop smoothly and quickly to work in various types of environments, and it is compatible to work with the MVVM model.

The repository model allows isolating the code responsible for handling data from business logic. There are several benefits in this matter, the most important of which are:

- Organizing the program, and making it more understandable and development.
- Development of the data-handling method, without making any changes to the program's logic.
- The ability to radically change the type of service we use to store data without negligible change in business logic.

I will go directly to how this model is adopted in our app. Where we will need to use a single interface with a single class achieved. To refresh your memory around the facades, see this lesson. Let's start building this app now in the next paragraph.

}

Interfaces are generally used when we want to strip Abstraction and make it public, which is a huge benefit in making software code more understandable and reusable. This is why this interface has been added to the Abstract folder. The interfaces do not contain any software code as we know, all that it contains are permits for dependencies that must be achieved within any category that wishes to achieve this interface. This interface briefly contains the basic processes our application needs to accomplish its tasks: obtaining contacts by name and nickname GetContactsAsync, adding a new contact AddContactAsync, updating a pre-existing contact UpdateContactAsync, and deleting a DeleteContactAsync contact. The reason for the presence of the word Async in each of these functions is to indicate that it is assumed that you will use the Asynchronous Programming technology that we talked about in this lesson.
