
Each application contains a main page (which will be in the category NavigationPage), which is the main node from which all other pages, whatever their number and level, can be accessed. Xamarin also distinguishes two types of content pages that are used within this navigation structure: Modal Pages and Modeless Pages. The difference between these two types for Android apps is simple. That is, in Modal pages, the title of the page will not be displayed at the top as we will see in the example shortly. In a Modeless page, the title of the page will be at the top if it is specified using the Title property of the content page. To preview the difference between these types, let's create a simple, practical application that illustrates this.
