# Follow the UpdateContactAsync

The UpdateContactAsync function, which requires only one Contact type argument and returns a Task <bool> object to indicate the success of the deletion:

```
public async Task <bool> UpdateContactAsync (Contact contactToUpdate)
{
    return await Task.Factory.StartNew (() =>
    {
        Contact result = (from contact in contacts
                          where contact.Id == contactToUpdate.Id
                          select contact) .FirstOrDefault ();
        if (result! = null)
        {
            contactToUpdate.FirstName = result.FirstName;
            contactToUpdate.LastName = result.LastName;
            contactToUpdate.EMail = result.EMail;
            contactToUpdate.Tel = result.Tel;
            contactToUpdate.Hobbies = result.Hobbies;
            return true;
        }
        else
        {
            return false;
        }
    });
}
```

This code is subject to the same principle: The LINQ to Objects query searches for the required contact within the contacts within the contacts variable according to the value of the contact's Id property, and after obtaining it, the values of the other properties are updated as is clear.
