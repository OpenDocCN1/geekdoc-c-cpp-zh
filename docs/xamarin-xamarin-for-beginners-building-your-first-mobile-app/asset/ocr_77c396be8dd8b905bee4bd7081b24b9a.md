# The main interface of ContactsPage

Initially, we will need to add a new folder, which we will call Pages, in which we will place any new page for the application.
From the Solution Explorer window, right-click on the ContactsApp (Portal) project name, then choose from the list that appears the Add option. From the submenu, choose New Folder and name it Pages.
Right-click on the folder you just added, which is Pages, and choose from the Add menu, then choose from the New Item submenu, for a window to appear that allows you to choose the new item you want to add. Choose a code-based content page as we have already done in this lesson. Name this page ContactsPage.
Now go to the ContactsPage.xaml file and make sure its contents are as follows:

```
<? xml version = "1.0" encoding = "utf-8"?>
<ContentPage xmlns = "http://xamarin.com/schemas/2014/forms" xmlns: x = "http://schemas.microsoft.com/winfx/2009/xaml" x: Class = "ContactsApp.Pages.ContactsPage" Appearing = "ContactsPage_Appearing">

<StackLayout>
    <StackLayout Padding = "5,25,5,5">
        <StackLayout Orientation = "Horizontal">
            <Label Text = "First Name" />
            <Editor x: Name = "txtFirstName" HorizontalOptions = "FillAndExpand" TextChanged = "Editor_TextChanged" />
        </StackLayout>

        <StackLayout Orientation = "Horizontal">
            <Label Text = "Last Name" />
            <Editor x: Name = "txtLastName" HorizontalOptions = "FillAndExpand" TextChanged = "Editor_TextChanged" />
```
