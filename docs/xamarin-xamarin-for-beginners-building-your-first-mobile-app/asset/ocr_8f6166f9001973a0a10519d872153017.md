The Contact category as it appears from the previous figure contains the basic data that any contact needs, in addition to the hobby feature that may seem a little strange for a contact.
Right-click again on the ContactsApp project, then choose from the list that appears, add, and from the submenu the New Folder option to add a new folder. Name this folder Abstract, and after it appears in the Solution Explore window, right-click on it and choose Add and from the submenu choose New Item. A window will appear allowing you to specify the type of item to be added. Choose the Interface and assign it the name IContactsRepository.
Make sure the contents of the IContactsRepository.cs file are as follows:

```
using System.Threading.Tasks;
using System.Collections.ObjectModel;
using ContactsApp.Entities;

namespace ContactsApp.Abstract
{
    public interface IContactsRepository
    {
        Task<ObservableCollection<Contact>> GetContactsAsync (string firstName, string lastName);

        Task<bool> AddContactAsync (Contact contactToAdd);

        Task<bool> UpdateContactAsync (Contact contactToUpdate);

        Task<bool> DeleteContactAsync (Contact contactToDelete);
    }
}
```

Interfaces are generally used when we want to strip Abstraction and make it public, which is a huge benefit in making software code more understandable and reusable.
