# Continue with DeleteContactAsync

The DeleteContactAsync function requires only one Contact argument and returns a Task <bool> object to indicate the success of the deletion:

```
```csharp
public async Task <bool> DeleteContactAsync (Contact contactToDelete)
{
 return await Task.Factory.StartNew (() =>
 {
 var result = (from contact in contacts where contact.Id! = contactToDelete.Id select contact);
 if (result! = null)
 {
 contacts = new ObservableCollection <Contact> (result);
 contactToDelete = null;
 return true;
 }
 else
 {
 return false;
 }
 });
}
```
```

The preceding code actually filters the contact to be deleted, which simply means that the LINQ to Objects query will return all contacts except those whose Id value has a value of Id for the contact we want to delete. Then the result is attributed to the contacts variable, which means that we have actually deleted this contact from memory.
