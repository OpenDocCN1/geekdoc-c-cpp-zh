1, we will reduce the size. When any value greater than 1 is used, we will enlarge the volume. For example, a value of 3 means we will magnify the volume 3 times, and so on. A value of 0 for the Scale property is allowed but will cause the element to disappear. Negative values of Scale can be used, but this will overturn the element while the previous concept remains the same. That is, a value of -1 will overturn the element but the volume remains the same.
