# Build the app

Start by creating a new Blank App (Xamarin.Forms Portable) project named ContactsApp then just keep the ContactsApp (Portable) and ContactsApp.Droid projects just as we did in this lesson.

From the Solution Explorer window, right-click on the ContactsApp project and choose from the menu that appears the Add option, then from the submenu the New Folder option to add a new folder. Name this folder Entity, and after it appears in the Solution Explore window, right-click on it and choose Add and from the submenu choose Class. A window will appear allowing you to assign a name to this item. Choose the name, Contact. This category is the main building block for this program and represents the logic of working in it. Be sure to make the contents of the Contact.cs file as follows:

```
namespace ContactsApp.Entities
{
    public class Contact
    {
        public int Id {get; set;}
        public string FirstName {get; set;}
        public string LastName {get; set;}
        public string Tel {get; set;}
        public string EMail {get; set;}
        public string Hobbies {get; set;}

        public override string ToString ()
        {
            return string.Concat (FirstName, "" " , LastName);
        }
    }
}
```
