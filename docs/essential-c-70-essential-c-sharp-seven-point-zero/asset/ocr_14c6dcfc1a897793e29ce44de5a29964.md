class Program
{
    static void Main()
    {
        Employee employee = new Employee();

        // Call the FirstName property's setter
        employee.FirstName = "Inigo";

        // Call the FirstName property's getter
        System.Console.WriteLine(employee.FirstName);
    }
}


class Employee
{
    // FirstName property
    public string FirstName
    {
        get
        {
            return _FirstName;
        }
        set
        {
            _FirstName = value;
        }
    }
    private string _FirstName;
    // ... 
}

The first thing to notice in Listing 6.17 is not the property code itself, but rather the code within the Program class. Although you no longer have the fields with the FirstName and LastName identifiers, you cannot see this by looking at the Program class. The API for accessing an employee's first and last names has not changed at all. It is still possible to assign the parts of the name using a simple assignment operator, for example (employee.FirstName = "Inigo").
