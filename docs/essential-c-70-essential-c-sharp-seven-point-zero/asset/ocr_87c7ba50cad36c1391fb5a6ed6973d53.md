# **Accessing the Member of a Referent Type**

Dereferencing a pointer produces a variable of the pointer's underlying type. You can then access the members of the underlying type using the member access dot operator in the usual way. However, the rules of operator precedence require that `*x.y` means `*(x.y)`, which is probably not what you intended. If `x` is a pointer, the correct code is `(*x).y`, which is an unpleasant syntax. To make it easier to access members of a dereferenced pointer, C# provides a special member access operator: `x->y` is a shorthand for `(*x).y, as shown in Listing 21.19.`

```
**LISTING 21.19: Directly Accessing a Referent Type's Members**

```csharp
unsafe
{
    Angle angle = new Angle(30, 18, 0);
    Angle* pAngle = @angle;
    System.Console.WriteLine("{0}' {1}' {2}",
        pAngle->Hours, pAngle->Minutes, pAngle->Seconds);
}
```
```

The results of Listing 21.19 appear in Output 21.5.

```
**OUTPUT 21.5**

`30° 18' 0`
```
