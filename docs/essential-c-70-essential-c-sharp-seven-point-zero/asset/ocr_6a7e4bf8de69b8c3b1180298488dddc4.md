The null-coalescing operator was added to C# in version 2.0, along with nullable value types. This operator works on both operands of nullable value types and reference types.

# Null-Conditional Operator (?,)

Whenever you invoke a method on a value that is null, the runtime will throw a System.NullReferenceException, which almost always indicates an error in the programming logic. In recognition of the frequency of this pattern (i.e., checking for null before invoking a member), C# 6.0 introduces the ? . operator, known as the null-conditional operator, as shown in Listing 4.37.
