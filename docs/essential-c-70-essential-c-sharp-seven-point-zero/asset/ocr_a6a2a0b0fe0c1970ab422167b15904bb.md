| :--- | :--- |

| Shift | << >> |

| Equality | == != |
| Logical AND | & |

| Logical OR | | |
| Conditional AND | && |
| Conditional OR | \|\| |
| Null coalescing | ?? |
| Conditional | ?: |

* Rows appear in order of precedence from highest to lowest.
