# ## Generating an XML Documentation File

The compiler checks that the XML comments are well formed and issues a warning if they are not. To generate the XML file, add a DocumentationFile subelement to the ProjectProperties element:

```
"<DocumentationFile>$(OutputPath)\\$(TargetFramework)\\$(AssemblyName).\r\n xml</DocumentationFile>"
```

This subelement causes an XML file to be generated during build into the output directory using the <assemblyname>.xml as the filename. Using the CommentSamples class listed earlier and the compiler options listed here, the resultant CommentSamples.XML file appears as shown in Listing 10.18.

# **LISTING 10.18: Comments.xml**

```
"<?xml version=\"1.0\"?>\r\n<doc>\r\n<assembly>\r\n<name>\r\nDataStorage</name>\r\n</assembly>\r\n<members>\r\n<member name=\"T:DataStorage\">\r\n<summary>\r\nDataStorage is used to persist and retrieve\r\n employee data from the files.\r\n</summary>\r\n</member>\r\n<member name=\"M:DataStorage.Store(Employee)\">\r\n<summary>\r\nSave an employee object to a file\r\n named with the Employee name.\r\n</summary>\r\n<remarks>\r\nThis method uses\r\n<seealso cref=\"T:System.IO.FileStream\"/>\r\n in addition to\r\n<seealso cref=\"T:System.IO.StreamWriter\"/>\r\n</remarks>\r\n<param name=\"employee\">\r\nThe employee to persist to a file</param>\r\n<date>\r\nJanuary 1, 2000</date>\r\n</member>\r\n<member name=\"M:DataStorage.Load(\r\n System.String,System.String)\">\r\n<summary>"
```
