| Escape Sequence | Character Name | Unicode Encoding |

You can represent any character using Unicode encoding. To do so, pre-fix the Unicode value with \u. You represent Unicode characters in hexadecimal notation. The letter A, for example, is the hexadecimal value 0x41. Listing 2.12 uses Unicode characters to display a smiley face ( : ), and Output 2.8 shows the results.

# LISTING 2.12: Using Unicode Encoding to Display a Smiley Face

```
System.Console.Write('\u003A');
System.Console.WriteLine('\u0029');
```
