# **Newline**

When writing out a newline, the exact characters for the newline will depend on the operating system on which you are executing. On Microsoft Windows operating systems, the newline is the combination of both the carriage return (\r) and line feed (\n) characters, while a single line feed is used on UNIX. One way to overcome the discrepancy between operating systems is simply to use `System.Console.WriteLine()` to output a blank line. Another approach, which is almost essential for working with newlines from the same code base on multiple operating systems, is to use `System.Environment.NewLine`. In other words, `System.Console.WriteLine("Hello World")` and `System.Console.Write($"Hello World{System.Environment.NewLine}")` are equivalent. However, on Windows, `System.WriteLine()` and `System.Console.Write(System.Environment.NewLine)` are equivalent to `System.Console.Write("\r\n")`—not `System.Console.Write("\n")`. In summary, rely on `System.WriteLine()` and `System.Environment.NewLine` rather than `\n` to accommodate Windows-specific operating system idiosyncrasies with the same code that runs on Linux and iOS.

> **Guidelines**

DO rely on `System.WriteLine()` and `System.Environment.NewLine` rather than `\n` to accommodate Windows-specific operating system idiosyncrasies with the same code that runs on Linux and iOS.
