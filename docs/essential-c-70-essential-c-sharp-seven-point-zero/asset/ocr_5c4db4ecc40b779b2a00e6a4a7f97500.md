# **LISTING 13.3: BubbleSort() with Delegate Parameter**

```csharp
class DelegateSample
{
// ...
public static void BubbleSort(
int[] items, Func<int, int, bool> compare)
{
int i;
int j;
int temp;

if (compare == null)
{
throw new ArgumentNullException(nameof (compare));
}

if (items == null)
{
return;
}

for (i = items.Length - 1; i >= 0; i--)
{
for (j = 1; j <= i; j++)
{
if (compare (items[j - 1], items[j]))
{
temp = items[j - 1];
items[j - 1] = items[j];
items[j] = temp;
}
}
}
// ...
}

Within the BubbleSort() method, you then use the instance of the Func<int, int, bool>, referred to by the compare parameter, to determine which integer is greater.
