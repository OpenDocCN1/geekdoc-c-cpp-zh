Note that Longitude and Latitude will also require implementations of the + operator because they are called by source.Longitude + arc.LongitudeDifference and source.Latitude + arc.LatitudeDifference.

# **LISTING 10.8: Calling the – and + Binary Operators**

```
public class Program
{
    public static void Main()
    {
        Coordinate coordinate1,coordinate2;
        coordinate1 = new Coordinate(
                    new Longitude(48, 52), new Latitude(-2, -20));
        Arc arc = new Arc(new Longitude(3), new Latitude(1));

        coordinate2 = coordinate1 + arc;
        Console.WriteLine(coordinate2);

        coordinate2 = coordinate2 - arc;
        Console.WriteLine(coordinate2);

        coordinate2 += arc;
        Console.WriteLine(coordinate2);
    }
}
```

The results of Listing 10.8 appear in Output 10.3.

# **OUTPUT 10.3**

```
51°  52' 0 E  -1°  -20' 0 N
48°  52' 0 E  -2°  -20' 0 N
51°  52' 0 E  -1°  -20' 0 N
```

For Coordinate, you implement the – and + operators to return coordinate locations after adding/subtracting Arc. This allows you to string multiple operators and operands together, as in result = ((coordinate1 + arc1) + arc2) + arc3.Moreover, by supporting the same operators (+/-) on Arc (see Listing 10.9) you could eliminate the parentheses. This approach works because the result of the first operand (arc1 + arc2) is another Arc, which you can then add to the next operand of type Arc or Coordinate.
