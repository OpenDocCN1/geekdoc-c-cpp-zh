# **LISTING 17.3: Using the Bitwise Complement of the BinarySearch() Result**

```
```
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        List<string> list = new List<string>();
        int search;

        list.Add("public");
        list.Add("protected");
        list.Add("private");

        list.Sort();

        search = list.BinarySearch("protected internal");
        if (search < 0)
        {
            list.Insert(~search, "protected internal");
        }

        foreach (string accessModifier in list)
        {
            Console.WriteLine(accessModifier);
        }
    }
}
```
```

Beware that if the list is not first sorted, an element will not necessarily be found with this code, even if it is in the list. The results of Listing 17.3 appear in Output 17.2.

# **OUTPUT 17.2**

private
protected
protected internal
public
