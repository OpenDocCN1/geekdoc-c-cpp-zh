# Error Handling

Error handling makes awareness of the sequential notification critical. If one subscriber throws an exception, later subscribers in the chain do not receive the notification. Consider, for example, what would happen if you changed Heater’s OnTemperatureChanged() method so that it throw an exception, as shown in Listing 14.9.
