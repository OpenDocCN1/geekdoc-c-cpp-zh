# Determining String Lengths

Function strlen takes a string as an argument and returns the number of characters in the string—the terminating null character is not included in the length. The length is also the index of the null character. The program of Fig. 21.26 demonstrates function strlen.

```
```cpp
// Fig. 21.26: fig21_26.cpp
// Using strlen
#include <iostream>
#include <cstring> // prototype for strlen
using namespace std;

int main()
{
    char *string1 = "abcdefghijklmnopqrstuvwxyz";
    char *string2 = "four";
    char *string3 = "Boston";

    cout << "The length of \\" << string1 << "\\ is " << strlen( string1 )
         << "\\nThe length of \\" << string2 << "\\ is " << strlen( string2 )
         << "\\nThe length of \\" << string3 << "\\ is " << strlen( string3 )
         << endl;
} // end main
```
```

```
The length of "abcdefghijklmnopqrstuvwxyz" is 26
The length of "four" is 4
The length of "Boston" is 6
```
