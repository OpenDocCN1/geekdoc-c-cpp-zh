
基类析构函数。如果层次结构中的某个对象通过将 `delete` 运算符应用于派生类对象而被显式销毁，则会调用相应类的析构函数。派生类析构函数运行后，该类的所有基类的析构函数会沿着层次结构一路向上运行。
