Rule 3 is the **nesting rule**. Repeatedly applying Rule 3 to the simplest activity diagram results in one nicely nested control statement. For example, in Fig. 5.24, the action state in the simplest activity diagram is replaced with a double-selection (if…else) statement. Then Rule 3 is applied again to the action states in the double-selection statement, replacing each with a double-selection statement. The dashed action-state symbols around each of the double-selection statements represent an action state that was replaced in the preceding activity diagram.
