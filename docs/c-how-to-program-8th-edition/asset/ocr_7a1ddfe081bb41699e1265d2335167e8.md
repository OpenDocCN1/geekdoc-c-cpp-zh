+   - Interaction overview diagrams, new in UML 2, provide a summary of control flow in the system by combining elements of several types of behavioral diagrams (e.g., activity diagrams).
+   - Timing diagrams, also new in UML 2, model the timing constraints imposed on state changes and interactions between objects in a system.
