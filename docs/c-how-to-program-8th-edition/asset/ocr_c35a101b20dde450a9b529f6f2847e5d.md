Function shuffle implements the high-performance shuffling algorithm. The function loops through all 52 cards (subscripts 0 to 51). For each card, a number between 0 and 51 is picked randomly. Next, the current Card and the randomly selected Card are swapped in the vector. A total of 52 swaps are made in a single pass of the entire vector, and the vector is shuffled.
