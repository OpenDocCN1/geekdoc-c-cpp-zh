+   - A so-called serialized object (p. 686) is an object represented as a sequence of bytes that includes the object’s data as well as information about the object’s type and the types of data stored in the object. A serialized object can be read from the file and deserialized (p. 686).
+   - The open source Boost Libraries provide support for serializing objects (p. 686) in text, binary and extensible markup language (XML) formats.
