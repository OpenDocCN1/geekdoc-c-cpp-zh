The addResourceLocation function (Figure 27.5, lines 79–80) takes three Ogre::String arguments. The first is the location of the resources. We placed all the resources in a folder called resources within the example’s directory. Normally you’d organize the resources in different folders by type, e.g. materials, models and overlays. But for simplicity we maintain one folder to hold all the resources we’ll need for the game. The second argument is the type of file the resources are in. The third is the resource group those files belong to. We’ll put these files in the "Pong" group. Now we load the resources in the location we just added (line 81).
