# 13.6.2 Creating Concrete Derived Class SalariedEmployee

Class SalariedEmployee (Figs. 13.11–13.12) derives from class Employee (line 8 of Fig. 13.11). The public member functions include a constructor that takes a first name, a last name, a social security number and a weekly salary as arguments (lines 11–12); a set function to assign a new nonnegative value to data member weeklySalary (line 14); a get function to return weeklySalary’s value (line 15); a virtual function that calculates a SalariedEmployee’s earnings (line 18) and a virtual function print (line 19) that outputs the employee’s type, namely, "salaried employee," followed by employee-specific information produced by base class Employee’s print function and SalariedEmployee’s getWeeklySalary function.
