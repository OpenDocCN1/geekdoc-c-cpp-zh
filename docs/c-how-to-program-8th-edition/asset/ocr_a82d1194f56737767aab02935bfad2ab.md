# ### 实验6 基于单片机的AD转换实验

一、实验目的

+   1. 了解A/D转换的基本原理。
+   2. 掌握ADC0809芯片的使用方法。
+   3. 掌握单片机与ADC0809的接口电路设计方法。

二、实验设备

+   1. 计算机
+   2. Keil C51 单片机开发套件
+   3. 单片机实验箱

三、实验原理

ADC0809是8位逐次逼近型A/D转换芯片，具有8路模拟量输入，转换时间约为100μs。其内部包含一个8位A/D转换器、8通道多路选择器、三态输出锁存器等电路。工作时，通过地址锁存信号ALE选通某一通道，将模拟量输入到转换器进行转换，转换结束后由EOC信号指示，通过OE信号控制输出转换结果。
