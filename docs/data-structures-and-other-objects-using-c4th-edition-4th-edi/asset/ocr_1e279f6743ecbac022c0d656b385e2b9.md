Because of the parentheses problem, C++ offers an alternative way to select a member of a class, shown here:

### The -> Operator

If p is a pointer to a class, and m is a member of the class, then p->m means the same as (*p).m.

Example: head_ptr->data() is the syntax for activating the data function of the node pointed to by head_ptr.

The symbol "->" is considered a single operator (rather than two separate symbols "-" and ">"). It is called the **member selection operator** or **component selection operator**. Visually, the p->m operator reminds you of an arrow, leading from the pointer p to the object that contains the member m. Using the member selection operator, we can print the data from the first node of the list in Figure 3.3, as shown here: cout << head_ptr->data();
