The array of labels has been changed to an ordinary dynamic array. But what is the meaning of the declaration `bool * *edges`? This declaration says that `edges` is more than a pointer to a boolean value; in fact, it is a “pointer to a pointer” to a boolean. A “pointer to a pointer” can be made to act like a two-dimensional array. For example, suppose that we want edges to act like an array with `n` rows and `n` columns. Using a `size_t` variable `i`, we could write this code to allocate the needed memory:

```
```cpp
edges = new bool*[n];
for (i = 0; i < n; ++i)
    edges[i] = new bool[n];
```
```

In this code, the first statement has an interesting effect. The statement `edges = new (bool*)[n]` makes edges point to an array of `n` pointers. The for loop then makes each of these pointers point to a dynamic array of `n` boolean values. After the for-loop, we can use `edges` just as if it was an `n` by `n` two-dimensional array of boolean values. For example, we could fill the entire “array” with `false` us-

ing the loop shown here (`i` and `j` are both `size_t` variables):

```
```cpp
for (i = 0; i < n; ++i)
    for (j = 0; j < n; ++j)
        edges[i][j] = false;
```
```
