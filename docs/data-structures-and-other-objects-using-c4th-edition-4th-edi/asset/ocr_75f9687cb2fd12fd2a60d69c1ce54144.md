Low Precedence

This table gives the precedence of C++ operators. Operators in higher boxes have higher precedence than operators in lower boxes. Unary operators and the assignment operator are done in right-to-left order when operators have the same precedence. For example, x = y = z means x = (y = z). Other operators that have the same precedence are done in left-to-right order. For example, x - y - z means (x - y) - z.
