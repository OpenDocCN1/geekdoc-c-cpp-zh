# ## LEARNING OBJECTIVES

When you complete Chapter 13, you will be able to...

+   - do a simulation by hand of selectionsort, insertionsort, mergesort, quicksort, and heapsort.
+   - implement each of these sorting algorithms to sort an array of numbers or to sort any collection of objects that provides a random access iterator.
+   - explain the run-time advantage of insertionsort for the situation in which an array is nearly sorted to begin with.
+   - explain the advantage of mergesort for sorting a collection of data that is too large to fit in memory all at once.
+   - demonstrate situations where the poor choice of a pivot element can cause quadratic behavior for quicksort.
