# 12.2 OPEN-ADDRESS HASHING

In this section we will present another approach to storing and searching for values. The technique, called hashing, has a worst-case behavior that is linear for finding a target, but with some care, hashing can be dramatically fast in the average case. Hashing also makes it easy to add and delete elements from the collection that is being searched, providing an advantage over binary search (since binary search must ensure that the entire list stays sorted when elements are added or deleted).
