Every call of the function must eventually lead to a stopping case or else the function call will never end because of an infinite sequence of recursive calls. (In practice, a call that includes infinite recursion will terminate abnormally rather than actually running forever because the computation no longer has enough memory for the run-time stack of activation records.)
