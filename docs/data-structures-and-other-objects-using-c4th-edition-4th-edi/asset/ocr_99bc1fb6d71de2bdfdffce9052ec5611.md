# ## LEARNING OBJECTIVES

When you complete Chapter 6, you will be able to...

+   - recognize situations in which template functions and template classes are appropriate.
+   - design and implement template functions and template classes.
+   - use the standard template classes for sets, multisets, and lists.
+   - use iterators to step through all the elements of an object for any of the standard template classes.
+   - manipulate objects of the standard template classes using functions from the <algorithms> library facility.
+   - implement simple forward iterators for our own classes, such as the bag class.
