In this scheme, all the records that hash to location i are placed on the linked list, which has its head pointer stored in data[i]. To maintain the linked lists, we can use the template version of our node class (from Section 6.4). With this approach, the table class definition is shown in Figure 12.7.

In the figure we have included the file node2.h from Figure 6.4 on page 321 to provide the node class. We also have defined a static member constant called TABLE_SIZE, which determines the size of the table’s array. We used the name TABLE_SIZE rather than CAPACITY since “CAPACITY” suggests a limit to the number of entries—but in fact, the chaining hash table can hold more than TABLE_SIZE entries.
