As an example, suppose that a sequence contains four numbers, with the current item at data[2]. The member variables of the object might appear as shown here:

![](bbox=[0.3, 0.21, 0.82, 0.31])

In this example, the current item is at data[2], so the current() function would return the number 6. At this point, if we called advance(), then current_index would increase to 3, and current() would then return 9. Normally, a sequence has a “current” item, and the member variable current_index contains the location of that current item. But if there is no current item, then current_index contains the same value as used. In our example, if current_index was 4, then that would indicate that there is no current item. Notice that this value (4) is beyond the used part of the array (which stretches from data[0] to data[3]).
