# CHAPTER SUMMARY

+   • If a problem can be reduced to smaller instances of the same problem, then a recursive solution is likely to be easy to find and implement.

+   • A recursive algorithm for a function implementation contains two kinds of cases: one or more cases that include a recursive call and one or more stopping cases in which the problem is solved without the use of any recursive calls.

+   • When writing recursive functions, always check to see that the function will not produce infinite recursion. This can be done by finding an appropriate variant expression and threshold.

+   • Inductive reasoning can be used to show that a recursive function meets its precondition/postcondition contract.
