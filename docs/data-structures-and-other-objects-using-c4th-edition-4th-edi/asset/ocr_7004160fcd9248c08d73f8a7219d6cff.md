# The erase_one member function.

There are two approaches to implementing the erase_one function. The first approach uses the toolkit's removal functions—using list_head_remove if the removed item is at the head of the list, and using the ordinary list_remove to remove an item that is farther down the line. This first approach is fine, although it does require a bit of thought because List::remove requires a pointer to the node that is just *before* the item that you want to remove. We could certainly find this "before" node, but not by using the toolkit's list_search function.
