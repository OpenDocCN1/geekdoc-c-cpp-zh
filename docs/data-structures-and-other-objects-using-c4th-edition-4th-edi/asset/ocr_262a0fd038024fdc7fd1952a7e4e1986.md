# ## LEARNING OBJECTIVES

When you complete Chapter 8, you will be able to...

+   * follow and explain queue-based algorithms using the usual computer science terminology of enqueue and de-queue (or the unusual C++ queue terms of push and pop).
+   * use the STL queue class to implement queue-based algorithms such as scheduling first-come, first-served tasks.
+   * use the STL double-ended queue classes in applications
+   * implement the queue and double-ended queue classes on your own using either an array or a linked-list data structure.
