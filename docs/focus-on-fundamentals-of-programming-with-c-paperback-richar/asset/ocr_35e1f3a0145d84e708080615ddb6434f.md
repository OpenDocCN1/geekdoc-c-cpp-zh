# Macros Can Replace Function Calls

Macros are frequently used to replace function calls by in-line code that is more efficient. For example, a macro MIN() could be used in a program instead of a function min(), where the macro definition is given by:

```
// macro6.c
#define MIN(x,y) (((x) < (y)) ? (x) : (y))
```

Therefore the call:

```
m = MIN(a, b);
```

gets correctly expanded by the preprocessor to:

```
m = (((a) < (b)) ? (a) : (b));
```

Here are some additional examples of how macros can replace function calls:

```
// macro7.c
#define MAX(x,y) (((x) > (y)) ? (x) : (y))
#define ABS(x) (((x) < 0) ? -(x) : (x))
```
