See if you can calculate the output of the following C program before looking at the answers:

```
// incDecOperators.c

#include <stdio.h>

int main(void) {
    int a, b, c;

    a = 0;
    b = 0;
    c = 0;

    a = ++b + ++c;
    printf("%d %d \n", a, b, c);

    a = b++ + c++;
    printf("%d %d \n", a, b, c);

    a = ++b + c++;
    printf("%d %d \n", a, b, c);

    a = b-- + --c;
    printf("%d %d \n", a, b, c);

    return 0;
}
```

Here's the program output:

```
2 1 1
2 2 2
3 3 3
5 2 2
```

Can you see why?
