Here's another example. Suppose we need to set up a list of events that are to occur at a particular date and time. We want to associate both date and time together within a single entity.

First we define a `Date` struct and a `Time` struct:

```
// nestingStructs4.c
typedef struct {
    int month;
    int day;
    int year;
} Date;
typedef struct {
    int hour;
    int minute;
    int second;
} Time;
```

Now we can define a `DateTime` struct as follows:

```
// nestingStructs5.c
typedef struct {
    Date eventDate;
    Time eventTime;
} DateTime;
```
