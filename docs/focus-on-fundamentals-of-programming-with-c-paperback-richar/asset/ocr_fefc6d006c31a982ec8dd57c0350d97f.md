We write our own code to perform a string comparison:

```
// strcmp1.c

int strcmp(char s1[], char s2[]) {
    int i = 0;

    while (s1[i] == s2[i] && s1[i] != '\0') {
        ++i;
    }
    return s1[i] - s2[i];
}
```
