Is the cost of sorting the data is worth the increase in search speed gained with the binary search? If you are searching only once, it is probably better to do a linear search in most cases.

Once the data is sorted it can also prove very expensive to add or delete items. In a sorted array, for instance, such operations require a shift of array elements to open or close a 'hole' in the array. This is an expensive operation as it requires, in worst case, log_2 n comparisons and n data movements.
