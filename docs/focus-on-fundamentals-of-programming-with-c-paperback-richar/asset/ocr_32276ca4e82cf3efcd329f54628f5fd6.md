The modulus operator turns out to be surprisingly useful. For example, we could check whether one number is divisible by another:

```
If x % y is zero, then x is divisible by y.
```

We can also use the modulus operator to extract the rightmost digit or digits of a number:

```
x % 10 yields the rightmost digit of x
x % 100 yields the last two digits of x
```

Hand trace the value of the variables in the following two programs and see if you can match the output:

```

    int a, b, c;
```
