C guarantees no defined result if an attempt is made to left or right shift a value by an amount that is greater than or equal to the number of bits in the size of the data item (left operand). The right operand may not be negative. Below is a function to count the number of 1-bits in the integer argument.

```
// bitcount.c

int bitCount(unsigned num) {
    int count = 0;

    while(num) {
        if(num & 1) {
            count++;
        }
        num >>= 1;
    }
    return count;
}
```

Here are several portable programs that compute the number of bits in an int.

```
// numbits1.c

#include <stdio.h>

int main(void) {
    int i = 0, num = 1;

    while(num) {
        num <<= 1;
        i++;
    }
    printf("%d\n", i);
    return 0;
}
```
