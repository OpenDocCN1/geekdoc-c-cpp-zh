Note that the size in memory of the two-dimensional array is:

```
3 rows * 4 columns * sizeof(int) = 48 bytes
```

We can initialize a two-dimensional array at declaration time:

```
// 2d2.c
int num[3][4] = {
   ( 2, 4, 6, 8 ),
   ( 1, 3, 5, 7 ),
   ( 3, 6, 9, 12 )
};
```

Brace pairs are used to separate the list of initializers for one row from the next. Commas are required after each brace that closes off a row, except in the case of the last row.

Our two-dimensional array initialization looks like this:

| | Col 0 | Col 1 | Col 2 | Col 3 |
|---|---|---|---|---|
| Row 0 | 2 | 4 | 6 | 8 |
| Row 1 | 1 | 3 | 5 | 7 |
| Row 2 | 3 | 6 | 9 | 12 |

Note that the inner pair of braces is also optional:

```
// 2d3.c
int num[3][4] = ( 2, 4, 6, 8, 1, 3, 5, 7, 3, 6, 9, 12 );
```
