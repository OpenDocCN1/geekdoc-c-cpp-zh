# Object-Oriented Approach

+   ❖ Software objects would be constructed to represent:
+   
+   - the paddle       - the ball
+   - the sides        - the bricks in the wall, etc.

+   ❖ Furthermore, operations on these objects would represent problem-domain tasks such as:
+   
+   - moving the ball
+   - moving the paddle
+   - determining if the paddle has struck the ball
+   - whether the ball is lost
+   - removing bricks from the wall, etc.

❖ So our object-oriented approach to this problem is to try to identify not the functions but the objects that will be involved in the computation.
