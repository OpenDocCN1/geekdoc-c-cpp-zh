```
putc(c, fp));
```

A macro which places the character value of c in the file pointed to by fp. It returns the int value of the character written. Note that putchar(c) is a macro defined as putc(c, stdout).

```
Function prototype:
int putc(int c, FILE *fp);
```

```
c = fgetc(fp);
```

Similar to getc(fp), but is a function and not a macro.

```
Function prototype: int fgetc(FILE *fp);
```

```
fputc(c, fp);
```

Similar to putc(c, file_ptr), but is a function and not a macro.

```
Function prototype:
int fputc(int c, FILE *fp);
```

# Example: Output the contents of a file to standard output.

```
// file4.c

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int c;
    FILE *fp;

    if ((fp = fopen("infile.txt", "r"))) {
        fprintf("File could not be opened.\n");
        exit(1);
    }

    while((c = getc(fp)) != EOF) {
        putchar(c);
    }
    fclose(fp);
    return 0;
}
```
