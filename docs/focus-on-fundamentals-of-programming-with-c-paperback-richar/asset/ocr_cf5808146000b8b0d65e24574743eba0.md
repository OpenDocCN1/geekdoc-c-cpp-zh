# User-Defined Functions

A function is a subprogram that carries out a particular task. Its purpose is to group together a related set of statements that performs some well-defined step in an algorithm.

We have already seen examples of functions that are built into C such as:

```
printf()      fopen()       isdigit()
scanf()       fclose()      isupper()
              fprint()      islower()
                              toupper()
                              tolower()
```

But C also gives us the ability to create our own functions. Suppose we wanted to write a program to display different geometric shapes. We could create our own function, drawRect(), to display a rectangle:

```
// displayRectangle.c
// Displays a rectangle.
void drawRectangle() {
    printf("*************\n");
    printf("**        **\n");
    printf("**        **\n");
    printf("**        **\n");
    printf("*************\n");
}
```

We could create our own function, drawTriangle(), to display a triangle:

```
// displayTriangle.c
// Displays a triangle.
void drawTriangle() {
    printf("         *\n");
    printf("       * *\n");
    printf("     *   *\n");
    printf("   *     *\n");
    printf("*************\n");
}
```
