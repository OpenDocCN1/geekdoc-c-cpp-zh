
## Polynomial Representation

Note the following three preconditions for representing a polynomial as a linear linked list:

- Terms must be stored in order of decreasing exponent within the linear linked list.
- No two terms may have the same exponent.
- No term may have a zero coefficient.

Each node of the linear linked list will represent one term of the polynomial and is a struct containing the following information:

- coefficient
- exponent
- pointer to the next term of the polynomial

```
typedef struct poly {
    float coeff;
    int expo;
    struct poly *next;
} *POLYPTR;
```

## Adding Two Polynomials

To add two polynomials together, we only must scan through them once each:

- If we find terms with the same exponent in the two polynomials, then we add the coefficients and copy the new term to the end of the sum polynomial; otherwise we copy the term with the larger exponent into the sum polynomial and continue.
- When we reach the end of one of the polynomials, we copy the remaining part of the other to the sum polynomial.

We must be careful not to include terms with 0 coefficient in the sum. For example:

```
6X^5 + 2X^4 + 3X^3 + 2X
+
3X^5 - 2X^4 - 5X^2 - 8X + 7
9X^5 + 3X^3 - 5X^2 - 6X + 7
```

```
// poly.c

#include <stdio.h>

typedef struct poly {
    float coeff;
    int expo;
    struct poly *next;
} *POLYPTR;

POLYPTR sum(POLYPTR p, POLYPTR q) {
    float coeff;
    POLYPTR add = NULL;

    while (p != NULL && q != NULL) {
        if (p->expo == q->expo) {
            coeff = p->coeff + q->coeff;
            if (coeff) {
                makeTerm(add, coeff, p->expo);
                p = p->next;
                q = q->next;
            }
        }
        else if (p->expo > q->expo) {
            makeTerm(add, p->coeff, p->expo);
            p = p->next;
        }
        else {
            makeTerm(add, q->coeff, q->expo);
            q = q->next;
        }
    }

    while (p) {
        makeTerm(add, p->coeff, p->expo);
        p = p->next;
    }

    while (q) {
        makeTerm(add, q->coeff, q->expo);
        q = q->next;
    }

    return add;
}
```

At several places in the algorithm we must create a new term with given coefficient and exponent and place it at the end of the sum polynomial, that is, after the term pointed to by `last`. Note that pointer `add` will always point to the first term created and pointer `last` will always point to the last term of the sum polynomial.

```
void makeTerm(POLYPTR *add, float coeff, int expo) {
    POLYPTR t;
    POLYPTR last = NULL;

    t = (POLYPTR) malloc(sizeof(struct poly));
    t->coeff = coeff;
    t->expo = expo;
    t->next = NULL;
    if (*add == NULL) {
        *add = t;
    }
    else {
        last->next = t;
    }
    last = t;
}
```
