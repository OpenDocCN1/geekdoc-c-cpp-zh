The program below:

```
// power3.c

#include <stdio.h>
#include <stdlib.h>

float power(float base, int expo n);

int main(void) {
    float result = power(3.5, -6);
    printf("%f\n", result);
    return 0;
}

float power(float base, int expo n) {
    int i;
    float num = 1.0;
    if (expo n == 0) {
        return 1.0;
    }
    for (i = 0; i < abs(expo n); ++i) {
        num *= base;
        if (expo n > 0) {
            return num;
        }
        else {
            return 1/num;
        }
    }
}
```

produces the following output:

```
0.000544
```

Note the use of the abs() function that returns the absolute value of expo n is used in the for loop. The abs() function is a built-in C math function and its use requires the inclusion of the appropriate header file:

```
#include <stdlib.h>
```
