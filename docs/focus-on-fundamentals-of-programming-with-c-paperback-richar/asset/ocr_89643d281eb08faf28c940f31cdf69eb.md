The following four string functions copy string t into string s. Can you follow the pointers?

```
// strcpy3.c
void strcpy(char s[], char t[]) {
    int i;
    for (i = 0; t[i] != '\0'; i++) {
        s[i] = t[i];
    }
    s[i] = '\0';
}
```

```
// strcpy4.c
void strcpy(char *s, char *t) {
    for (; *t != '\0'; s++, t++) {
        *s = *t;
    }
    *s = '\0';
}
```

```
// strcpy5.c
void strcpy(char *s, char *t) {
    while (*t) {
        *s++ = *t++;
    }
    *s = '\0';
}
```
