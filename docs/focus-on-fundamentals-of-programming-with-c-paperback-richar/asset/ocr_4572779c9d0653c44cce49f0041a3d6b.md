+   - OOP is programming with objects
+   - OOP is programming with messages
+   - OOP is programming with classes
+   - OOP is programming with encapsulation

# # Encapsulation

Conceptually, we can characterize objects such as the ball in our example as an encapsulation of both state and operations (behavior).

Encapsulation is the ability to conceptually group together in an object both the state of the object and the allowable operations on that state.
