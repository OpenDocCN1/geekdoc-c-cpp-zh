# Increment and Decrement Operators

The increment and decrement are unary operators (i.e., require only one operand):

```
++ adds one to its operand
-- subtracts one from its operand
```

The statements:

```
++num;
num++;
```

both increment the value of num by 1 and have the same effect as the statement:

```
num = num + 1;
```

The statements:

```
--num;
num--;
```

both decrement the value of num by 1 and have the same effect as the statement:

```
num = num - 1;
```

Note that when the ++ or -- operator is used to the left of the operand:

```
++num;
--num;
```
