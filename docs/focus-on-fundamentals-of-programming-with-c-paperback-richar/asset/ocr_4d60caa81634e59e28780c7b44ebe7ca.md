To correctly read the input, we must therefore use:

```
scanf("%d %c", &i, &c);
input:
29 w
assign:
29 to i
'w' to c
```

This works since the blank space in format string causes scanf() to ignore any leading whitespace characters after 29 has been read.

Note when scanf() searches input for value to be reads, all leading whitespace characters are skipped, except when using %c, which reads the next character from input, no matter what it is.

For character strings read in with %s, any non-whitespace character is valid. For %c, any character is valid.

When a value is read that does not match a value expected by scanf(), then scanf() does not read any further items from input and returns to the calling program with the number of items that were successfully read. This value can be tested to determine if any errors occurred in the input. For example,

```
scanf("%d %f %d", &i, &f, &n);
```

will return the value 3 given the input:

```
-300, 12.34, 23
```

since the 3 values of i, f, and n would successfully get assigned.
