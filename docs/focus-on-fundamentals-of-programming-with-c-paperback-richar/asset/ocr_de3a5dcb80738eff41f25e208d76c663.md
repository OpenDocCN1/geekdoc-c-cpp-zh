# Inheritance Relationship

In this example, PERSON is the base class and STUDENT and EMPLOYEE are the derived classes.

The class PERSON might contain information common to all people:

+   - name
+   - address
+   - social security number

Using inheritance we can say STUDENT and EMPLOYEE inherits everything that is known about person (has a name, address, social security number).

But in addition there are some specializations about STUDENTS and EMPLOYEES.
