# Bitwise Operator Homework

+   1. Let b1 = b2 = 1. Which of the following does not have the same result as the others?
+   a) b1 & b2
+   b) b1 | b2
+   c) b1 ^ b2
+   d) ~(~b2)

+   2. Evaluate the expression: (00001000 & 11000101) ^ (11110000)
+   a) 00111101
+   b) 11000000
+   c) 00111101
+   d) 11110000

+   3. For any 8-bit integer x, which of the following does not result in zero?
+   a) x &= (~x)
+   b) x ^= x
+   c) x <<= 8
+   d) x |= x

+   4. Which of the following is true?
+   a) Any bit "ANDed" with 0 yields 0.
+   b) Any bit "ANDed" with 1 yields 1.
+   c) Any bit "ANDed" with 0 yields 1.
+   d) Any bit "ANDed" with 1 yields 0.

5. Write a single C statement to set the middle 16 bits of a 32-bit integer num to zero but leaves the left 8 and the right 8 bits as they originally were.

6. Write a C function with the prototype:

int compare(int x, int y);

that returns the number of corresponding bits in x and y which differ. For example, if x = 9 and y = 97, the number of corresponding bits which differ is three.

x = 9 = 0000 0000 0000 0000 0000 0000 0000 1001
y = 97 = 0000 0000 0000 0000 0000 0000 0110 0001
