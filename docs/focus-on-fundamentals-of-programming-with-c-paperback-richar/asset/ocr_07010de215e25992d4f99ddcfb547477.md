If the input were:

```
-300, x, 17.8, 27
```

then 1 would be returned.

We could use this test in the calling program as follows:

```
if (scanf("%d %f %d", &I, &f, &n) == 3) {
    ;
}
```

# A Note on Microsoft C Compilers

If you are using a Microsoft compiler, the use of scanf() might produce a warning message during the build phase. Microsoft has determined that any format string of the form "%s" is dangerous because it doesn't prevent buffer overflow (a security concern). For all such functions Microsoft has introduced a secure version:

```
scanf_s()
```

Unlike scanf(), scanf_s() requires the buffer size to be specified for all input parameters of type c or s. The buffer size is passed as an additional parameter immediately following the pointer to buffer or variable. For example, if reading a string, the buffer size for that string is passed as follows:

```
char s[10];
scanf_s("%9s", s, 10);
```

The buffer size includes the terminating null. A width specification field may be used to ensure that the token read in will fit into the buffer. If no width specification field is used, and the token read is too big to fit in the buffer, nothing will be written to that buffer.
