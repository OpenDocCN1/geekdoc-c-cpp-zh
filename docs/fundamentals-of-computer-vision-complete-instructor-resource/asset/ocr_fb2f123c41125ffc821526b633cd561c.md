Substituting Eq. 10.21 into Eq. 10.19, we have

```
\(\epsilon(m) = \sum_{i=m+1}^d E\{(y_i - E\{y_i\})^2\}.\)
```

Substituting Eq. 10.11 into Eq. 10.22:

```
\(\epsilon(m) = \sum_{i=m+1}^d E\{(\mathbf{b}_i^T \mathbf{x} - E\{\mathbf{b}_i^T \mathbf{x}\})^2\}\)
```

```
\(= \sum_{i=m+1}^d E\{(\mathbf{b}_i^T \mathbf{x} - E\{\mathbf{b}_i^T \mathbf{x}\})(\mathbf{b}_i^T \mathbf{x} - E\{\mathbf{b}_i^T \mathbf{x}\})\}\)
```

```
\(= \sum_i \mathbf{b}_i^T \{E(\mathbf{x} - E(\mathbf{x}))(\mathbf{x}^T - E\{\mathbf{x}^T\})\mathbf{b}_i\}\)
```

```
\(= \sum_i \mathbf{b}_i^T \{E(\mathbf{x} - E(\mathbf{x}))(\mathbf{x} - E(\mathbf{x}))^T\}\mathbf{b}_i\)
```

and we now recognize the term between the b's in Eq. 10.26 as the covariance of x:

```
\(\epsilon(m) = \sum_{i=m+1}^d \mathbf{b}_i^T K_x \mathbf{b}_i.\)
```

We could differentiate Eq. 10.27, set the result to zero, and attempt to find the vectors \(\mathbf{b}_i\), but it wouldn't work because the \(\mathbf{b}\)'s that minimize the function are the zero vectors. We must make use of the fact that they are unit vectors. That is for every \(i\), \(\mathbf{b}_i^T \mathbf{b}_i = 1\). We make that a constraint by using Lagrange multipliers.

Recall that an objective function can be minimized subject to a constraint by adding a term that is equal to zero, multiplied by a scalar Lagrange multiplier. For our problem, the objective function becomes

```
\(\sum_i [\mathbf{b}_i^T K_x \mathbf{b}_i - \lambda_i (\mathbf{b}_i^T \mathbf{b}_i - 1)].\)
```

To avoid confusion with the index of the summation, take the derivative with respect to some arbitrary \(\mathbf{b}\), say \(\mathbf{b}_k\). Doing that, one realizes that the only terms in the summation over \(i\) that are nonzero are the terms involving \(k\), so the summation goes away, and we have

```
\(\nabla_{\mathbf{b}_k} \epsilon = 2K_x \mathbf{b}_k - 2\lambda_k \mathbf{b}_k.\)
```

Rearranging, this becomes

```
\(K_x \mathbf{b}_k = \lambda_k \mathbf{b}_k.\)
```

That is, the optimal basis vectors are the eigenvectors of \(K_x\).

The covariance of y can be easily related to \(K_x\) by:

```
\(K_y = E\{(\mathbf{y} - E\{\mathbf{y}\})(\mathbf{y} - E\{\mathbf{y}\})^T\} = B^T K_x B\)
```

where the matrix \(B\) has columns made from the basis vectors, \((\mathbf{b}_1, \mathbf{b}_2, \dots, \mathbf{b}_d)\).
