## Moving the Contour without Using Image Edges

In this subsection you will learn the concepts underlying the Chan-Vese algorithm, one of the most effective current methods for active contour-based segmentation. You will also get more exposure to the process of converting between continuous and discrete mathematics.

While most algorithms have names that describe what they do, the algorithm described here is named for the authors, Chan and Vese, probably because “Segmentation by maximizing the difference between two regions” is too hard to say. At the time of this writing, extensions of the Chan-Vese algorithm provide some of the very best segmentations, competing with some graph-based methods that will be discussed later in this chapter. The Chan-Vese algorithm uses level set approaches to find the contour that divides the image into two regions that are maximally different. It is important to realize that these regions are not required to be connected. Since the algorithm does not rely on image gradient, it can successfully detect objects whose boundaries are not necessarily defined by edges.

Here, we present the same example application that was in the original paper by Chan and Vese [8.13]. There are many papers applicable to the student that extend the Chan-Vese algorithm [8.12, 8.18, 8.1, 8.2], just to mention a few.

Philosophically, Chan-Vese segmentation chooses an objective function that describes the difference in brightness between the outside and inside of the contour. The version discussed here assumes the algorithm is finding a contour that separates two relatively homogeneous regions, denoted background and foreground. As we did in section 8.5.1 the derivation begins using continuous mathematics and concludes using finite differences. Consider the following function:

```
\( F(C) = \int_{inside C} (f(x, y) - \mu_1)^2 dxdy + \int_{outside C} (f(x, y) - \mu_2)^2 dxdy, \quad (8.47) \)
```

where \(\mu_1\) is the mean brightness inside the contour and \(\mu_2\) is the mean brightness outside the contour.

\( F(C) \) will be small if the two regions are close to homogeneous, one precisely enclosed by the contour, and the other totally outside the contour. Finding the best such contour \( C \) is the objective of the optimization.

One problem with this objective function can be identified before proceeding further: The contour that optimizes this function is not constrained to be smooth, so it may sharply curve and deform to match the two regions precisely. We modify \( F(C) \) by adding a regularizing term to encourage a smooth contour – simply minimizing the length of the contour.

```
\( F(C) = \alpha \, \text{Length}(C) + \int_{inside C} (f(x, y) - \mu_1)^2 dxdy + \int_{outside C} (f(x, y) - \mu_2)^2 dxdy, \quad (8.48) \)
```

where \(\alpha\) is a constant scaling the relative importance of the length of the contour compared to the difference in region statistics.

This problem can be readily converted to a level set problem by defining the function \(\psi(x, y)\) as we did previously. For convenience, we denote the set of points inside the contour as \(\omega\), and all the points in the image as \(\Omega\).

```
\(\omega = \{(x,y)|\psi(x,y) > 0\}\)
\(\omega^c = \{(x,y)|\psi(x,y) < 0\}.\)
\(C = \partial \omega = \{(x,y)|\psi(x,y) = 0\}\)
```

(The student should observe that this is a slightly different definition of \(\psi\) from that given at the beginning of section 8.5.2 because here, the inside is positive and the outside negative.)

To convert Eq. 8.48 into something that can be minimized, we introduce a binary function,

```
\(H(z) = \left\{ \begin{array}{ll} 1 & \text{if } z \ge 0 \\ 0 & \text{if } z < 0. \end{array} \right.\)
```

\(H(\cdot)\) is called the *Heaviside function*, and has a derivative by definition:

```
\(\delta(z) = \frac{\partial H(z)}{\partial z},\)
```

where \(\delta\) is the Dirac measure.

Now we can write the previous expressions in terms of \(H\), remembering that the contour of interest is the zero level set of \(\psi\):

```
\(Length(C) = Length(\psi = 0) = \int_\Omega |\nabla H(\psi(x,y))|dxdy\)
\(= \int_\Omega \delta(\psi(x,y))|\nabla\psi(x,y)|dxdy.\)
```

We get rid of the nonuniform regions of integration by using \(H\):

```
\(\int_{\psi > 0} (f(x,y) - \mu_1)^2 dxdy \text{ becomes } \int_\Omega (f(x,y) - \mu_1)^2 H(\psi(x,y))dxdy\)
```

and similarly

```
\(\int_{\psi < 0} (f(x,y) - \mu_2)^2 dxdy \text{ becomes } \int_\Omega (f(x,y) - \mu_2)^2 (1 - H(\psi(x,y)))dxdy.\)
```

Finally, collecting the components of \(F\), we have

```
\(F(C) = \alpha \int_\Omega \delta(\psi(x,y))|\nabla\psi(x,y)|dxdy\)
\(+ \int_\Omega (f(x,y) - \mu_1)^2 H(\psi(x,y))dxdy\)
\(+ \int_\Omega (f(x,y) - \mu_2)^2 (1 - H(\psi(x,y)))dxdy.\)
```

At this point, we have an expression for the metric function, but it depends on a Heaviside function, which is not continuous, and its derivative that, while defined, has no numerical value. We must replace \(H\) with something that can be manipulated mathematically. Such an expression is called a *regularizer*. One such regularizer for \(H\) is the one used by Chan and Vese [8.13]:

```
H_\epsilon(z) = \frac{1}{2} \left( 1 + \frac{2}{\pi} \arctan \left( \frac{z}{\epsilon} \right) \right). \tag{8.56}
```

which in the limit as \(\epsilon \to 0\) approaches \(H\).

The parameters \(\mu_1\) and \(\mu_2\) can be written in terms of \(H\) as

```
\mu_1(\psi) = \frac{\int_\Omega f(x,y) H(\psi(x,y)) dx dy}{\int_\Omega H(\psi(x,y)) dx dy} \\
\mu_2(\psi) = \frac{\int_\Omega f(x,y) (1 - H(\psi(x,y))) dx dy}{\int_\Omega (1 - H(\psi(x,y))) dx dy}. \tag{8.57}
```

Now that we have an expression for an objective function, we must derive a way to change \(\psi\) that will move the zero level set in the direction to minimize this function. This can be shown\(^6\) to result in the time step equation, Eq. 8.58 below. To conserve space, the subscripts \(i\) and \(j\) respectively are used for the column and row numbers. The superscript \(n\) denotes the iteration number.

```
\psi_{i,j}^{n+1} \leftarrow [\psi_{i,j}^n + \Delta t \delta_\epsilon(\psi_{i,j}^n)(A_{i,j}\psi_{i+1,j}^n + A_{i-1,j}\psi_{i-1,j}^{n+1} + B_{i,j}\psi_{i,j+1}^n + B_{i,j-1}\psi_{i,j-1}^{n+1} \\
- (f_{i,j} - \mu_1)^2 + (f_{i,j} - \mu_2)^2)] / [1 + \delta_\epsilon(\psi_{i,j})(A_{i,j} + A_{i-1,j} + B_{i,j} + B_{i,j-1})]. \tag{8.58}
```

Note that on the right-hand side, the term \(\psi_{i-1,j}^{n+1}\) appears. This may be confusing since if this assignment statement is computing \(\psi^{n+1}\), how can it use \(\psi^{n+1}\)? This equation describes an in-place modification of the \(\psi\) function, proceeding from left to right and top (\(j=0\)) to bottom (\(j = maxrow\)). In this way, it is possible to use \(\psi^{n+1}\) on both the right and left of the assignment statement because on the right, pixel \(\psi_{i,j}^{n+1}\) is being computed, and it depends on its already-computed neighbor \(\psi_{i-1,j}^{n+1}\).

The per-iteration time difference \(\Delta t\) is usually chosen to be 1.

The \(A\)’s and \(B\)’s may be found by

```
A_{i,j} = \frac{\alpha}{\eta + (\psi_{i+1,j}^n - \psi_{i,j}^n)^2 + ((\psi_{i+1,j}^n - \psi_{i-1,j}^{n+1})/2)^2} \\
B_{i,j} = \frac{\alpha}{\eta + ((\psi_{i+1,j}^n - \psi_{i-1,j}^{n+1})/2)^2 + (\psi_{i,j+1}^n - \psi_{i,j}^n)^2}. \tag{8.59}
```

The \(\eta\) is some small number used to avoid the possibility that the remainder of the denominator may be zero.
