A few words of explanation are in order for those students who are not familiar with constrained optimization using Lagrange multipliers. The term with the \(\lambda\) in front (\(\lambda\) is the Lagrange multiplier) is the constraint. It is formulated such that if it is exactly equal to zero, we shall find the proper \(a, b,\) and \(c\). By minimizing \(H\), we will find the parameters that minimize \(H_\lambda\) while simultaneously satisfying the constraint. To minimize \(H\), take the partial derivatives and set them equal to zero:

```
\(\frac{\partial H}{\partial a} = 4a - 4a + 2\lambda.\)
\(\frac{\partial H}{\partial b} = 4b - 4b + 2\lambda.\)
\(\frac{\partial H}{\partial c} = 2c - 2\gamma + \lambda\)
\(\frac{\partial H}{\partial \lambda} = 2a + 2b + c\)
```

Setting the partial derivatives equal to zero and simplifying, we find the following set of linear equations:

```
\(a = \alpha - \frac{\lambda}{2}\)
\(b = \beta - \frac{\lambda}{2}\)
\(c = \gamma - \frac{\lambda}{2}\)
\(2a + 2b + c = 0\)
```

which we solve to find the sets given in Table 5.1. In the case of the first derivative, 3 x 1, symmetry ensures the values always sum to zero, and therefore the integer values are just as good as the floating point ones.

We can proceed in the same way to compute the kernels to estimate the partial derivatives using Gaussians in two dimensions; one implementation of the first derivative with respect to x, assuming an isotropic Gaussian is presented in Figure 5.6.
