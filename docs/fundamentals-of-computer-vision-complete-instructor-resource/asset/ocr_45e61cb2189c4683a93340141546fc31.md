# 10.3.1 Derivation of the K-L Expansion

Let x be a d-dimensional random vector. We will describe x in terms of a set of basis vectors. That is, represent x by

```
x = \sum_{i=1}^d y_i b_i. (10.9)
```

Here, the vectors b_i are deterministic (and may in general, be specified in advance). If any random vector x may be expressed in terms of the same d vectors, b_i (i = 1, ..., d), we say the vectors b_i span the space containing x, and refer to them as a basis set for the set of all x's. To make further use of the basis set, we require:

+   1. The b_i vectors are linearly independent.
+   2. The b_i vectors are orthonormal, i.e.,

```
b_i^T b_j = \begin{cases} 1 & (i = j) \\ 0 & (i \neq j) \end{cases} (10.10)
```

Under these conditions, the y_i of Eq. 10.9, can be determined by

```
y_i = b_i^T x \quad (i = 1, \dots, d). (10.11)
```

Here, we say the scalar y_i results from projecting x onto the basis vector b_i, and we define

```
y = [y_1, \dots, y_d]^T. (10.12)
```
