Chan and Vese [8.13]:

```
H_\epsilon(z) = \frac{1}{2} \left( 1 + \frac{2}{\pi} \arctan \left( \frac{z}{\epsilon} \right) \right). \tag{8.56}
```

which in the limit as \(\epsilon \to 0\) approaches \(H\).

The parameters \(\mu_1\) and \(\mu_2\) can be written in terms of \(H\) as

```
\mu_1(\psi) = \frac{\int_\Omega f(x,y) H(\psi(x,y)) dx dy}{\int_\Omega H(\psi(x,y)) dx dy} \\
\mu_2(\psi) = \frac{\int_\Omega f(x,y) (1 - H(\psi(x,y))) dx dy}{\int_\Omega (1 - H(\psi(x,y))) dx dy}. \tag{8.57}
```

Now that we have an expression for an objective function, we must derive a way to change \(\psi\) that will move the zero level set in the direction to minimize this function. This can be shown\(^6\) to result in the time step equation, Eq. 8.58 below. To conserve space, the subscripts \(i\) and \(j\) respectively are used for the column and row numbers. The superscript \(n\) denotes the iteration number.

```
\psi_{i,j}^{n+1} \leftarrow [\psi_{i,j}^n + \Delta t \delta_\epsilon(\psi_{i,j}^n)(A_{i,j}\psi_{i+1,j}^n + A_{i-1,j}\psi_{i-1,j}^{n+1} + B_{i,j}\psi_{i,j+1}^n + B_{i,j-1}\psi_{i,j-1}^{n+1} \\
- (f_{i,j} - \mu_1)^2 + (f_{i,j} - \mu_2)^2)] / [1 + \delta_\epsilon(\psi_{i,j})(A_{i,j} + A_{i-1,j} + B_{i,j} + B_{i,j-1})]. \tag{8.58}
```

Note that on the right-hand side, the term \(\psi_{i-1,j}^{n+1}\) appears. This may be confusing since if this assignment statement is computing \(\psi^{n+1}\), how can it use \(\psi^{n+1}\)? This equation describes an in-place modification of the \(\psi\) function, proceeding from left to right and top (\(j=0\)) to bottom (\(j = maxrow\)). In this way, it is possible to use \(\psi^{n+1}\) on both the right and left of the assignment statement because on the right, pixel \(\psi_{i,j}^{n+1}\) is being computed, and it depends on its already-computed neighbor \(\psi_{i-1,j}^{n+1}\).

The per-iteration time difference \(\Delta t\) is usually chosen to be 1.

The \(A\)’s and \(B\)’s may be found by

```
A_{i,j} = \frac{\alpha}{\eta + (\psi_{i+1,j}^n - \psi_{i,j}^n)^2 + ((\psi_{i+1,j}^n - \psi_{i-1,j}^{n+1})/2)^2} \\
B_{i,j} = \frac{\alpha}{\eta + ((\psi_{i+1,j}^n - \psi_{i-1,j}^{n+1})/2)^2 + (\psi_{i,j}^n - \psi_{i,j}^n)^2}. \tag{8.59}
```

The \(\eta\) is some small number used to avoid the possibility that the remainder of the denominator may be zero.
