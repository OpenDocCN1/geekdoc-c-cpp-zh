Observe that when applied to a perfect step edge, these two operators produce a binary output. The vertical operator has only two possible outputs, and the horizontal likewise has only two. So the use of a pair of 1 x 3 differences can only distinguish four orientations – very low resolution in orientation space. Application to a blurred step edge is better, since the blurring operation spreads the information about the edge over a larger area.
