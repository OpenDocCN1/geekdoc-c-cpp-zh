+   1. Gradient descent is used to modify the current estimate of $f$, using the derivatives of the $H_i$ and $H_p$. The derivative of the noise term is trivial: on each iteration, simply change pixel $i$ by $\Delta H_a = \alpha \frac{(y_i - p_i)}{\sigma^2}$, for some small constant $\alpha$.
+   2. Three kernel operators may be used to estimate the three partial second derivatives in the quadratic variation
+   \(\Delta_{xx} = \frac{1}{6} \begin{bmatrix} 0 & 0 & 0 \\ 1 & -2 & 1 \\ 0 & 0 & 0 \end{bmatrix}, \Delta_{yy} = \frac{1}{6} \begin{bmatrix} 0 & 1 & 0 \\ 0 & -2 & 0 \\ 0 & 1 & 0 \end{bmatrix} \Delta_{xy} = 2 \begin{bmatrix} -0.25 & 0 & 0.25 \\ 0 & 0 & 0 \\ 0.25 & 0 & -0.25 \end{bmatrix}.\)
+   3. Compute three images, where the $i^{th}$ pixels of these images are $r_{ixx} = (\Delta_{xx} \otimes f)_i$, $r_{iyy} = (\Delta_{yy} \otimes f)_i$, and $r_{ixy} = (\Delta_{xy} \otimes f)_i$.
+   4. Create the image $s_{xx}$, whose elements are $\frac{\tau}{c} \exp \left( - \frac{r_{ixx}^2}{2c^2} \right)$, and similarly create $s_{yy}$ and $s_{xy}$.
+   5. For purposes of gradient descent, the change in pixel $i$ from the prior term is then $\Delta H_p = \beta ((\Delta_{xx} \otimes s_{xx}) + (\Delta_{yy} \otimes s_{yy}) + (\Delta_{xy} \otimes s_{xy}))_i$.
+   6. Following the gradient descent rule, change each element of $f$ using $f_i \leftarrow f_i - \eta \Delta H_i$, where $\Delta H_i = \Delta H_a + \Delta H_p$, for some small scalar constant $\eta$.
+   7. The learning coefficient $\eta$ can be shown to be $\eta = \frac{\nu \sqrt{\sigma}}{\sqrt{RMS(\Delta H)}}$, where $\nu$ is a small dimensionless number, like 0.04; $RMS(\Delta H)$ is the root mean square norm of the gradient $\Delta H$; and $\sigma$ can be determined as the standard deviation of the noise in the image (note that this is NOT necessarily a good estimate in synthetic images). In this form, $\eta$ changes every iteration. However, $\eta$ could also simply be chosen to be some small number like .01.
+   8. The coefficient $\beta$ is on the order of $\sigma$, and choosing $\beta = \sigma$ is usually adequate.

MFA is based on the mathematics of simulated annealing. One can show that in simulated annealing, a global minimum can be achieved by following a logarithmic annealing schedule like

```
\( r(k) = \frac{1}{\ln k} \) (6.31)
```

+   **MAP with annealing**
+   1. Begin with "large" $\tau$.
+   2. Do gradient descent to get increasingly closer to the nearest local minimum.
+   3. As the descent iterations proceed, "slowly" reduce $\tau$.
+   4. When $\tau$ reaches an application-dependent small value, stop.
