# Solution

```
{
\frac{\partial H}{\partial x_1} = 2\alpha x_1 + b = 0 \\
\frac{\partial H}{\partial x_2} = 2\alpha x_2 = 0 \\
\frac{\partial H}{\partial x_3} = 2\alpha x_3 = 0
}
```

is minimized by

```
x_3 = x_2 = 0, x_1 = \frac{-b}{2\alpha}.
```

If H is some function of order higher than two, or is transcendental, the technique of setting the derivative equal to zero may result in a set of simultaneous equations that are (usually) impractical to solve algebraically, and we must resort to numerical techniques. The first of these is gradient descent.

In one dimension, the utility of the gradient is easy to see. At a point x^(k) where k is the iteration index (Figure 3.3), the derivative points away from the minimum. That is, in one dimension, its sign will be positive on an "uphill" slope.

Thus, in pursuit of a minimum, to find a new point, x^(k+1), we let

```
x^{(k+1)} = x^{(k)} - \alpha \frac{\partial H}{\partial x}|_{x=x^{(k)}} \tag{3.40}
```

where \alpha is some "small" constant.

In a problem where x is a vector with d variables, we write

```
x^{(k+1)} = x^{(k)} - \alpha \nabla H(x)|_{x=x^{(k)}}. \tag{3.41}
```

It is not immediately obvious in Eq. 3.41 how to choose the variable \alpha that is also referred to as the learning rate. If \alpha is too small, the iteration of Eq. 3.41 will take too long to converge. If \alpha is too large, the algorithm may become unstable and never find the minimum.

We can find an estimate for \alpha by considering the well-known Newton-Raphson method for finding roots: In one dimension, we expand the function H(x) in a Taylor series about the point x^(k) and truncate, assuming all higher order terms are zero,

```
H(x^{(k+1)}) = H(x^{(k)}) + (x^{(k+1)} - x^{(k)})H'(x^{(k)}).
```
