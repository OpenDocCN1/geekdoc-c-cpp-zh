# Matching Contours using Shape Context

To match region shapes, with the shape context we will use it to find a measure that will characterize how well curve C matches some other curve, say 'C. Let P denote a point on curve C and let Q ∈ 'C. Denote the corresponding histograms as h(P, k) and h(Q, k). For any particular P and Q, we may match their shape contexts by matching individual points along the two curves. Since P and Q denote points along specific curves, they may be thought of as indices. Since P indexes curve C, and Q indexes 'C, we can construct a matrix of matching costs. Specifically, if we believe point P in curve C is the same as point Q in curve 'C, we define a cost of assigning P to correspond to Q. This "assignment cost" is

```
\(\gamma_{PQ} = \frac{1}{2} \sum_{k=1}^{K} \frac{(h(P, k) - h(Q, k))^2}{h(P, k) + h(Q, k)}.\)
(10.61)
```

All these assignment costs may be calculated and entered into a matrix.

```
\(\Gamma_{ij} = [\gamma_{PQ}] \quad P \in C, Q \in 'C.\)
(10.62)
```

The matrix \(\Gamma\) is a representation of the cost of matching shape \(i\) to shape \(j\). if \(N_i = N_j\), \(\Gamma_{ij}\) is square, if not, \(\Gamma_{ij}\) may be made square by adding "dummy" nodes with constant match cost. To extract a scalar measure of this cost, we must find the mapping \(f : C \rightarrow 'C\) that is a bijection (1:1 and onto), and that minimizes the total cost. That is, to the \(p^{th}\) element of \(C\) we must find exactly one element of \( 'C\) to which we assign it. This is referred to as the *linear assignment problem* (LAP). This problem may be stated in terms of the matrix \(\Gamma_{ij}\) by observing that, for each row, we must choose one and only one column for the match, and that column must, in turn match no other rows.

The linear assignment problem is one of a large set of linear programming problems that may be solved using the simplex algorithm (see [10.9]). The special case of the linear assignment problem may be solved in \(O(n^3)\), using several strategies, the most well-known of which is the "Hungarian algorithm" [10.23]. We used the implementation by Jonker and Volgenant [10.17].

Assuming that unknown curve \( 'C\) is being matched to a data base of models, \(B\). The solution to the LAP produces a number, \(\hat{\Gamma}_{ij} = \min(\Gamma_{ij}), 'C \in B\), which is the best assignment possible for these two curves. Thus the index of the best match \(m = \text{argmin}_j(\hat{\Gamma}_{ij})\).

# 10.6.3 Curvature Scale Space

Curvature Scale Space (CSS) is a shape representation method introduced by Mokhtarian and Mackworth [10.25]. CSS has also been adopted in the MPEG-7 standard as a contour shape descriptor [10.44]. The CSS representation is a multi-scale organization of curvature zero crossing points of a planar curve. The representation is defined in the continuous domain and sampled later. Consider a curve parametrized by arc length \(s\), and \(s\) is set to lie in the range \(0 \le s \le 1\), to provide scale invariance, then

```
\(C(s) = [x(s), y(s)]^T.\)
(10.63)
```
