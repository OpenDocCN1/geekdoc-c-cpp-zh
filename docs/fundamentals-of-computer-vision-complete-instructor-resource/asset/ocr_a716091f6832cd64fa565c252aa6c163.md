First, define some reference point. The choice of a reference point is arbitrary, but the center of gravity is convenient. Call that point O. For each point Pi on the boundary, calculate both the gradient vector at that point and the vector OPi from the boundary point to the reference. Quantize the gradient direction into, say, n values, and create a table R with n rows. Each time a point P on the boundary has a gradient direction with value theta_i (i = 1, ..., n), a new column is filled in on row i, using T[i, k] = OPi, where k is the index of the entry on row i. Thus, the fact that multiple points on the boundary may have identical gradient directions is accommodated by placing a separate column in the table for each entry.
