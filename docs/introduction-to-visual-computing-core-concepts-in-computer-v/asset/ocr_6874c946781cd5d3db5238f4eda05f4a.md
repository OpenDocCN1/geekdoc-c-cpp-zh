Z_q = Z_1 + q(Z_2 - Z_1). (14.16)

We know from Chapter 13 that if the screen space parameter for the same point is given by p, 0 ≤ q ≤ 1, then

1/Z_q = 1/Z_1 + p(1/Z_2 - 1/Z_1) (14.17)

From the above two equations we can find the relationship between p and q as

q = p Z_1 / (p Z_1 + (1 - p) Z_2) (14.18)

When interpolating the texture coordinates we would like to achieve the correct coordinate based on their correct depth. Therefore, if the mapping from the texture space to object space assigns texture coordinates T_1 and T_2 to P_1 and P_2 respectively, then the texture coordinate at P_q is given by

T_q = T_1 + q(T_2 - T_1) = (T_1/Z_1 + p(T_2/Z_2 - T_1/Z_1)) / (1/Z_q) (14.19)
