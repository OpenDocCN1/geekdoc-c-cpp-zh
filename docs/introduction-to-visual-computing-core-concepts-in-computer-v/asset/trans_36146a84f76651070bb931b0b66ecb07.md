
当它们从不同方向被照亮时，会呈现不同的方向。几个世纪以来，画家和摄影师一直在探索树木和城市区域在各种条件下的外观，积累了关于“事物看起来如何”的知识——而这正是与BRDF相关的知识。

现在，让我们正式定义表面点P处的BRDF。考虑表面上的一个点P，其法线为n，从方向k_i被照亮。这可以通过在该方向放置一个光源来实现。设入射到P点的辐照度为H。设朝向观察方向k_o出射的辐射亮度为L_s。该设置如图9.1所示。BRDF ρ定义为L_s与H之比，即

```
ρ(k_i, k_o) = L_s / H.  (9.12)
```

因此，BRDF给出了当从入射方向k_i照亮时，光线朝观察方向k_o出射的比例。注意，k_o和k_i都是三维方向，可以用球坐标中的两个角度表示。设k_i由(θ_i, φ_i)给出，k_o由(θ_o, φ_o)给出。因此，BRDF是一个四维函数ρ(θ_i, φ_i, θ_o, φ_o)。另外，注意ρ是辐射亮度与辐照度之比，因此其单位是(sr)^{-1}。

方向半球反射率 让我们考虑一个简单的问题：“入射光中有多少比例被反射？”显然，仅从能量守恒的角度来看，这个数值应该在0到1之间。现在让我们看看，使用BRDF是否能轻易回答这个问题。给定来自方向k_i的入射光，被反射的比例应该是出射辐照度（或辐射出射度）与入射辐照度之比。因此，方向半球反射率D(k_i)由辐射出射度E与辐照度H之比给出：

```
D(k_i) = E / H.  (9.13)
```

由公式9.12可知

```
L_s(k_o) = H ρ(k_i, k_o)  (9.14)
```

同样，由公式9.8中辐射亮度的定义可知

```
L_s(k_o) = ΔE / (Δσ_o cosθ_o).  (9.15)
```

因此，

```
H ρ(k_i, k_o) = ΔE / (Δσ_o cosθ_o).  (9.16)
```

整理各项，我们得到反射到k_o方向的E/h贡献为

```
ΔE / H = ρ(k_i, k_o) Δσ_o cosθ_o  (9.17)
```

因此，

$$D(\mathbf{k_i}) = \frac{E}{H} = \int_{\forall \mathbf{k_o}} \rho(\mathbf{k_i},\mathbf{k_o}) cos\theta_o d\sigma_o \tag{9.18}$$

理想的漫反射表面称为*朗伯*表面，并被认为在任何观察方向都具有恒定的BRDF。换句话说，物体的外观与观察方向无关，或说独立于观察方向。尽管这种表面实际上并不存在，但许多具有*哑光*外观的物体通常被建模为朗伯表面。让我们考虑这样一个朗伯表面，其$\rho = C$。那么这种表面的方向半球反射率由下式给出：

$$D(\mathbf{k_i}) = \int_{\forall \mathbf{k_o}} C \Delta\sigma_o cos\theta_o d\sigma_o \tag{9.19}$$ $$= \int_{\phi_o=0}^{2\pi} \int_{\theta_o=0}^{\frac{\pi}{2}} C \ cos\theta_o \ sin\theta_o \ d\theta_o \ d\phi_o \tag{9.20}$$ $$= \pi C \tag{9.21}$$

因此，如果我们考虑一个完美反射的朗伯表面，其中$D(\mathbf{k_i}) = 1$，那么它的BRDF就是$\frac{1}{\pi}$。

## 9.1.2 光传输方程

利用上述方程，我们现在可以写出一个简单的光传输方程，该方程定义了在存在来自许多不同方向的光线时，光如何通过表面或物体进行传输。如果我们考虑来自方向$\mathbf{k_i}$的辐射亮度$L_i$在一个小的立体角$\Delta\sigma_i$内，由该光引起的辐照度为$L_i cos\theta_i \Delta\sigma_i$，其中$\theta_i$是$\mathbf{k_i}$与$\mathbf{n}$之间的夹角。因此，由来自方向$\mathbf{k_i}$的辐射亮度在方向$\mathbf{k_o}$上产生的出射辐射亮度$\Delta L_o$为：

$$\Delta L_o = \rho(\mathbf{k_i},\mathbf{k_o}) L_i cos\theta_i \Delta\sigma_i \tag{9.22}$$

因此，为了考虑来自所有不同方向（$\mathbf{k_i}$的所有不同值）的辐射亮度，方向$\mathbf{k_o}$上的总辐射亮度由下式给出：

$$L_s(\mathbf{k_o}) = \int_{\forall \mathbf{k_i}} \rho(\mathbf{k_i},\mathbf{k_o}) L_f(\mathbf{k_i}) cos\theta_i d\sigma_i \tag{9.23}$$

这被称为渲染方程或光传输方程，是构建简单或复杂光照模型的基石。

## 9.2 光度学与颜色

对于每一个辐射度量属性，都有一个相应的光度学属性，后者直观地衡量“人类观察者能利用其中多少”。

图9.2 该图显示了光的可见光谱及其相对于不可见光谱的位置。

因此，光度学量具有与感知相关的方面。颜色是我们一直在使用的一种光度学量。它是我们生活中不可或缺的一部分，以至于除非我们失去颜色感知，否则我们可能无法珍惜它。I先生因一场事故失去了颜色感知，他痛苦地喊道：“我的狗看起来是灰色的，番茄汁是黑色的，彩色电视是一团大杂烩。”颜色不仅为我们的生活增添美感，还起着重要的信号功能。自然界为我们提供了许多信号来识别和分类物体。其中许多信号是以颜色形式出现的。例如，香蕉成熟时会变黄，黎明时天空会变红，等等。

颜色刺激是一种辐射度量（通常是辐射亮度），它从世界上的任何一点到达人眼。在光度学以及颜色视觉的语境中，相关的重要参数是波长λ。可见光谱的波长在400纳米到700纳米之间变化。图9.2显示了可见的颜色光谱。一种光源或一个物体分别选择性地发射或反射某些波长，这些波长的强度高于其他波长。有两个原因决定了我们的颜色视觉，并因此决定了光度学。首先是不同物体对波长的选择性反射。然而，这只是决定物体颜色的因素之一。第二个重要因素是眼睛对不同波长的选择性响应。这种响应，以及由此产生的颜色感知，在不同物种之间可能不同，并且在同种物种的个体之间也存在差异。这就是为什么颜色通常被视为一种感知，而非现实！

让我们从场景的照明开始。场景通常由

图9.3 左：荧光灯（粗线）和钨丝灯（虚线）的照明光谱（I(λ)）。右：红苹果的反射光谱（R(λ)）。

某些光源照亮。该光源在不同波长λ下发射光的方式不同。这个函数用I(λ)表示，给出了照明光谱。类似地，对于一个物体，它在不同波长下的相对反射率定义了其反射光谱R(λ)。由于物体的反射率或反射比是出射功率与入射功率之比，因此对于非光源物体，它介于0和1之间。几个光源和一个红苹果的这些光谱如图9.3所示。

当一个物体被光源照亮时，该物体在不同波长下反射的光量由I(λ)和R(λ)的乘积给出。由于这是刺激视觉的光谱，它被称为颜色刺激或颜色信号，用C(λ)表示。因此，

C(λ) = I(λ) × R(λ)  (9.24)

如图9.4所示。我们在这里处理的物理量是单位面积、单位立体角、单位波长的功率（W m⁻¹ (nm)⁻¹ (sr)⁻¹）。因此，当定义颜色刺激时，我们实质上是在考虑辐射亮度。

颜色刺激可以有不同的类型，如图9.4所示。当它只包含一种波长的光时，被称为单色光，例如激光束。当所有波长的相对光量相等时，则称为消色差光。日光在白昼期间接近消色差。最后，如果刺激包含来自不同波长的不同光量，则称为多色光。大多数时候我们处理的是多色光。大多数人造和自然的颜色刺激都是多色光的平滑光谱。
