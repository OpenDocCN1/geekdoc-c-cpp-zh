# 11.1 Histogram Processing

Histogram is defined as the probability density function of the values in an image. Let us consider a single channel of an image of size $m \times n$ providing a total of $N = m \times n$ pixels. The value at each pixel $i$ can take $p$ discrete values normalized between zero (black) to one (white). $p$ is given by the number of bits used for representing the grays. Let us consider 8-bit gray values leading to $p = 256$. Therefore, $i$ can take $k$ different values, $i_k$, $1 < k < 256$. Let the number of pixels in the image with value $i_k$ be $N_k$. Therefore, the histogram $h(i_k)$ is defined as

$$h(i_k)=\frac{N_k}{N} \qquad (11.1)$$

i.e. the probability of a pixel to have a value $i_k$. Since $h(i_k)$ is a probability, $0 \le h(i_k) \le 1$, and therefore $h$ is a probability density function.
