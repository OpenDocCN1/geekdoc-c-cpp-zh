This can be achieved by clamping the out-of-bound input to 1 or 0. Such a clamping creates a local movement of only the out-of-gamut colors retaining the appearance of all in-gamut colors. This method can yield rather effective results for GUI applications where flat colors are used for buttons and slides.

However, when dealing with natural images, multiple out-of-gamut colors can land on the same in-gamut colors creating color blotches. Another option is to scale the position of all the colors to fit the out-of-gamut colors within the gamut. This can be achieved by scaling the input by an appropriate factor to move the out-of-range value to 1. This leads to a global movement of colors yielding better result for images though vibrancy and brightness of all the colors are sacrificed.
