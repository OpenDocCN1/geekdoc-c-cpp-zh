**Figure 1.6.** This figure illustrates the effect of step size on quantization error. The blue dotted lines show the eight discrete values. Note that these can be distributed at equal intervals resulting in uniform step size throughout the range of continuous values. The intervals can also change to create non-uniform step size. The range of continuous signal values that are assigned a particular discrete value is shown on the independent axis leading to maximum quantization error of half the maximum step size. Hence, for uniform step size, the maximum error is half the uniform step size.

Similarly, a 2D digital grayscale image *I* is denoted by the 2D array *I[x,y]* where *x, y* stands for spatial coordinates. This also assumes structured data. This can be visualized as an image with a grayscale color assigned to every *(x,y)* coordinates. It can also be visualized as a *height field* in which the height (Z-value) is the grayscale value at every *(x,y)* coordinate forming a surface (Figure 1.7).

Color images also have multiple channels, typically red, green and blue.
