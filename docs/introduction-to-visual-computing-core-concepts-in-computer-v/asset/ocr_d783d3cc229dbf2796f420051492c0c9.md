# 5.3 Other Non-Linear Filters

Let us now discuss a few non-linear filters which are not used for feature detection. This will give you an idea of how such filters can be used for other domains as well.

In a box filter, the mean of all the values in the neighborhood of a pixel is used to replace the value of the pixel.
