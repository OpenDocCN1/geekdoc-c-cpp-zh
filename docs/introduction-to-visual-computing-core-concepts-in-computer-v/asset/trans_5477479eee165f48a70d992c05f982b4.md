## 图形编程

图形编程要求在使用专用图形硬件的同时，熟悉多个 API 和库。我们首先介绍现代图形处理单元（GPU）的历史和发展，从前面章节讨论的各种交互式技术的角度，介绍其现有形式和功能。接下来介绍现代图形硬件的基本特性，以及有助于对图形和通用计算进行编程的现有 API 和库。

### 15.1 图形处理单元的发展

图形处理单元（GPU）是一种专用硬件单元，旨在分担并加速中央处理单元（CPU）的 2D 或 3D 处理，以保证交互性能。如今，几乎所有的台式机、笔记本电脑和移动设备都配备了某种 GPU。近年来，GPU 经历了革命性的变革，了解 GPU 如何帮助我们在交互式图形管线中计算所渲染的各种效果非常重要。

图形硬件最早在 1980 年代投入使用，尽管它们直到很久以后才被称为 GPU。GPU 是 nVidia 于 1999 年引入的术语。不过，为了保持一致性，在本章其余部分中，我们将此类硬件统称为 GPU。早期的 GPU 本质上是集成的帧缓冲区，能够实现线条光栅化（也称为线框光栅化），从而将多边形图元边缘的渲染工作分担到 GPU 上。第一款专用于图形管线的硬件是 IBM 专业图形控制器（PGA），它使用微处理器硬件，将诸如绘制和着色填充多边形之类的简单渲染任务从 CPU 上分担出来，释放 CPU 周期用于其他通用处理，而图形处理则在 PGA 卡上并行完成。板载独立的 PGA 卡标志着独立 GPU 演进过程中的重要一步。到 1987 年，GPU 增加了更多功能，包括着色立体、顶点光照、填充多边形光栅化、深度缓冲区和 Alpha 混合。然而，仍然存在对 CPU 的巨大依赖，大多数计算过去都在 CPU 上进行，而且
