The (u, v) coordinates related to a 3D point (x, y, z) can then be mapped to texture coordinates (s, t) as

```
s = (u + 180) / 360;    (14.14)
t = (v + 90) / 180.      (14.15)
```

The mappings from the (s, t) to (x, y, z) coordinates thus achieved in the above two cases are called cylindrical and spherical mapping respectively. Once the texture coordinates have been defined as above for every 3D vertex, the vertex is colored based on the color at the mapped texture image coordinate (s, t). Note that color is defined only at integer values of (s, t), often called texels. However, after mapping, there is no guarantee that (s, t) will be integers. Therefore, if (s, t) falls between integer values, the color value can be interpolated from the nearest texels either by picking the color of the nearest texel or interpolating the colors from the a few nearest texels in the texture.

An important point to note in the context of texture mapping is that the appearance of the textured objects depends completely on the parametrization.
