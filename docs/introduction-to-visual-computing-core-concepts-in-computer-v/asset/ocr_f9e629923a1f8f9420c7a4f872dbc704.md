Hence, they are represented by a three dimensional array $I[c, x, y]$ where $c$ denotes the channel, $c \in \{R, G, B\}$. Video involves the additional dimension of time and hence is represented by a four dimensional array $V[t, c, x, y]$. Note that all of these data are structured, which assumes a uniform sampling in each dimension. All these aforementioned representations are called the time or spatial domain representation.

Let us consider a 1D signal $c(t)$ (e.g. audio). This can be represented as

$c(t) = \sum_{i=1}^{\infty} a_i Cos(f_i + p_i)$
