+   2. Step 2: Now with the center at origin, you can apply the basic transformation asked of you, i.e. scaling with factor 2 along both X and Y directions. Therefore ℬ = 𝒮(2,2).
+   3. Step 3: Now we need to apply ℱ⁻¹ = 𝒯(−1,−1)⁻¹ = 𝒯(1,1) to undo the effect of ℱ.
+   4. Step 4: Therefore the final concatenated transformation is given by 𝒯(1,1)𝒮(2,2)𝒯(−1,−1). If you write these out completely, the 3×3 matrix for this transformation is given by
