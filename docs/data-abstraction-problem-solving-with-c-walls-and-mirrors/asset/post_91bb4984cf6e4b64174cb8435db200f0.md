# 5.3.2 The Eight Queens Problem

Place eight queens on the chessboard. The most powerful piece in the game of chess is the queen, because it can attack any other piece within its row, with its column, or along diagonal. The Eight Queens problem asks you to place eight queens on the chessboard so that no queen can attack any other queen.

One strategy is to guess at a solution. However, according to Section 2.6.3 of Chapter 2, there are g(64) = 4,426,368 ways to arrange eight queens on 64 squares—so many that it would be exhausting to check all of them for a solution to this problem. Nevertheless, a simple observation eliminates all arrangements from consideration: No queen can reside in a row or a column that contains another queen. Alternatively, each row and column can contain exactly one queen. Thus, attacks along rows or columns are eliminated, only 8! = 40,320 arrangements of queens to be checked for attacks along diagonals. A solution now appears more feasible.

Place queens one column at a time

Suppose you provide some organization for the guessing by placing one queen in column i, with the first square of column 1. Figure 5-7a shows this column and its range of attack. When you consider column 2, you eliminate your first square because row 1 contains a queen, you eliminate your second square because of a diagonal attack, and you finally place a queen in the third square of column 2, as Figure 5-7b illustrates. The blue dots in the figure indicate squares that are rejected because of an attack. The blue dots also indicate the additional squares that your new queen can attack.

If you reach an impasse, backtrack to the previous column

We continue to place queens in this manner until we get to column 6, as Figure 5-7 shows. Although the five queens placed cannot attack each other, they can attack any square in column 6, and therefore, you cannot place a queen in column 6. You must back up to column 5 and move your queen to the next possible square in column 5, which is in the last row, as Figure 5-7i indicates. When you consider column 6 once again, there are still no choices for a queen in that column. Because you have exhausted the possibilities in column 5, you must back up to column 4. As Figure 5-7g shows, the next possible square in column 4 is in row 7. You then consider column 5 again and place a queen in row 2 (Figure 5-7h).

How can use recursion in the process that was just described? Consider an algorithm that places a queen in a column, given that you have placed queens correctly in the preceding columns.

First, if there are no columns to consider, you are finished; this is the base case. Otherwise, if you successfully place a queen in the current column, you need to consider the next column. That is, you need to solve the same problem with one fewer column; this is the recursive step. Thus, you begin with eight columns, consider smaller problems that decrease in size by one column at each recursive step, and reach the base case when you have a problem with no columns.

The solution appears to satisfy the criteria for a recursive solution. However, you do not know whether you successfully place a queen in the current column. If you can, recursively consider the next column. If you cannot place a queen in the current column, you need to backtrack, as has already been described.

The Eight Queens problem can be solved in a variety of ways. The solution in this chapter uses two classes: a Board class to represent the chessboard and a Queen class to represent a queen on the board. A Board object tracks of its row and column placement and contains a static pointer to the Board. It also has operations to move the queen to the next row and see whether it is subject to attack—such as placeQueens.

The following pseudocode describes the algorithm for placing queens, given that the previous columns cannot attack another:

```cpp
// placeQueens(column): void
if (column > lastColumn)
    problem is solved
else
    while (squares exist in column)
        if (such square exists)
            Place a queen in the square
            placeQueens(column + 1)
            if (no queen is possible in the next column)
                Delete the new queen
```

with backtracking

The Eight Queens problem is initiated by the method doEightQueens with a new queen in the upper-left corner of the board:

```cpp

}
```
