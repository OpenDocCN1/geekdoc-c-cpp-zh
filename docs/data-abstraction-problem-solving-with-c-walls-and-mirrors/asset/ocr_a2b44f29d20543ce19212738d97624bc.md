Analysis. As we noted earlier, the bubble sort requires most $n-1$ passes through the array. Pass 1 requires $n-1$ comparisons and at most $n-1$ exchanges; pass 2 requires $n-2$ comparisons and at most $n-2$ exchanges. In general, pass $i$ requires $n-i$ comparisons and at most $n-i$ exchanges. Therefore, in the worst case, a bubble sort will require a total of

```
$(n-1) + (n-2) + \dots + 1 = n \times (n-1)/2$
```

comparisons and the number of exchanges. Recall that each exchange requires three data moves. Unlike, there are
$2 \times n(n-1) = 2n^2 - 2n$

major operations in the worst case. Therefore, the bubble sort is $O(n^2)$ in the worst case. The best case occurs when the data is already sorted; bubble uses one pass, during which $n-1$ comparisons and no exchanges occur. Thus, the bubble sort is $O(n)$ in the best case.

# 11.3 The Insertion Sort

Imagine once again a hand of cards, but now you pick up one card at a time and insert it into its position; in this example, you are performing an **insertion sort** algorithm in the context of a list of alphabetical names. In example, we repeatedly call the method `insert` to add a string into its proper sorted order.

You can use the insertion strategy to sort items that reside in an array. This version of the insertion sort partitions the array into two regions: sorted and unsorted. Figure 11-3 depicts. Initially, the array is the unsorted region, where you sit in an unsorted pile on the table. At each step, the insertion sort takes the first item of the unsorted region and places it into its correct position in the sorted region. This is analogous to taking and inserting it into its proper position in your hand. The first step, however, is trivial: moving `theArray[0]` from the unsorted region to the sorted region does not require moving data. Therefore, you can omit this first step by `theArray[1..n-1]`. The fact that the items in the sorted region are sorted among themselves is an invariant. Because at each step the size of the sorted region grows by 1 and size of the unsorted region shrinks by 1, the array will be sorted when the algorithm terminates.
