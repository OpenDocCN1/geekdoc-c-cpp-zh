# 11.1 Basic Sorting Algorithms

Sorting is a process that organizes data into either ascending/ descending order. There is need for sorting algorithms in many situations. You may simply want to sort a collection of data before including it in a report. Often, however, you must perform a sort as an initialization step for algorithms. For example, searching for data is one of the most common tasks performed by computers—such as the binary search algorithm— However, the binary search requires the data to be sorted. Thus, sorting is the step that must precede a binary search on a collection of data that is not already sorted. Good sorting algorithms, therefore, are quite valuable.

You can organize sorting algorithms into two categories. An internal sort requires the collection of data to fit entirely in the main memory. The main sorting algorithms are internal. An external sort when the data will not fit in the computer's main memory all out but must reside in secondary storage, such as a disk. Chapter 21 examines external sorts.

The items to be sorted may be integers, strings, or even objects. It is easy to imagine the results of sorting a collection of integers or strings, but consider a collection of objects. If each object contains only one member, sorting the objects is really different from sorting a collection of integers. When each object contains several members, you must know which data determines the order of the entry within the collection. This data member is the sort key. For example, if you represent people, you may sort by their names, ages, or their zip codes. Regardless of your choice of sort key, the sorting algorithm orders entries based only on one data member.

For simplicity, the algorithms in this chapter sort quantities such as numbers and strings. All algorithms in this chapter sort the data into ascending order. Finally, each example assumes that the data resides in an array.

# 11.1 The Selection Sort

Imagine some data that you can examine all. To sort it, you could select the largest item and put it in its place, select the next and put it in its place, and so on. For a card player, this is analogous to looking at inner hand of cards or selecting cards one at a time in their proper order. The selection sort formalizes these intuitive notions. To sort an array in ascending order, first search for the largest. Because you want the largest item to be in the last position of the array, swap the last item with the largest item, even if these items have to be identified. Now, getting the last—and—item of the array, search the array for its largest item and swap it with it, which is the next-to-last in the original array. Continue until you have selected and swapped $n-1$ of the items in the array. The item now in the first position of the array is in its proper order, so it is not considered further.

Figure-11 provides an example of a selection sort. Beginning with five integers, you select the largest—37—and swap it with the last integer—5. (As the items in figure are ordered, they are shaded in blue. This convention will be used throughout the chapter.) Next you select the largest integer—29—from among the four integers in the array and swap it with the next-to-last in the array—13. Notice that the next selection—14—is already in its proper position, but the algorithm ignores this fact and performs a swap of 14 with itself. It is more efficient in occasionally perform an unnecessary swap than is to continue as. Finally, you select the 13 and swap it in the second position of the array—10. The array is now sorted into ascending order.
