# 20.1 Implementing Adjacency

Adjacency matrix

The two most common implementations of a graph are the adjacency matrix and the list. An adjacency matrix for a graph with n vertices numbered 0, 1, ..., n-1 is an n by n array matrix such that matrix[i][j] is 1 if there is an edge from vertex i to vertex j, and 0 (otherwise). Figure 20-6 shows a directed graph and its adjacency matrix. Note that the diagonal entries matrix[i][i] are 0, although can be used to set these to 1. You should choose the value that is most convenient for your application.

When the graph is weighted, you let matrix[i][j] be the label from the edge from vertex i to vertex j, instead of 1, and matrix[i][j] equal to 0 when there is no edge from vertex i to vertex j. For example, Figure 20-7 shows a weighted directed graph and its adjacency matrix. Notice that the adjacency matrix for an undirected graph is symmetric; that, matrix[i][j] equals matrix[j][i].

Our definition of an adjacency matrix does not mention the value, or in a vertex. If you need to associate values with vertices, you can use a second array, to represent the n vertices. The array values are one-dimensional, and values[i] is the value in vertex i.

Adjacency list

An adjacency list for a graph with n vertices numbered 0, 1, ..., n-1 consists of linked nodes. The P linked chain has a head for vertex i if and only if the graph contains an edge from vertex i to j. This node contains the vertex j's value, if any. If the graph has no value, the node needs to contain some indication of the vertex's identity. Figure 20-8 shows a directed graph and its adjacency list. You can see, for example, vertex 0 (P) has edges to vertex 2 (R) and vertex 5 (W). Thus, the first chain in the adjacency chain contains nodes for R and W.
