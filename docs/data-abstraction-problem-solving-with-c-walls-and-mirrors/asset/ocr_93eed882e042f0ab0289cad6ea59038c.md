A recursive definition can summarize this discussion. Let
kSmall(k, anarray, first, last) = kth smallest value in anarray[first..last]

After you select the pivot value p and partition anarray[first..last] into Si and Sn, you have that
kSmall(k, anarray, first, last) equals
* kSmall(k, anarray, first, pivotIndex) – 1 if k < pivotIndex
* pif if k = pivotIndex – first + 1
* kSmall(k, (pivotIndex – first + 1), anarray, pivotIndex + 1, last)
  if k > pivotIndex – first + 1

There is always a pivot, and because it is not part of either Si or Sn, the size of the array segment to be decreased by at least 1 each step. Thus, you will eventually reach the base case: The desired value is a pivot. A high-level pseudocode solves this

```
// Returns the kth smallest value in anarray[first..last]
kSmall(k: integer, anarray: ArrayType,
  first: integer, last: integer): ValueType
  Choose a pivot value p from anarray[first..last]
  Partition the values of anarray[first..last] about p
  if (k < pivotIndex)
    return kSmall(k, anarray, first, pivotIndex - 1)
  else if (k == pivotIndex – first + 1)
    return p
  else
    return kSmall((pivotIndex – first + 1), anarray,
      pivotIndex + 1, last)
```

> The kth smallest value in anarray [first..last].

This pseudocode is not from a C++ function. The only questions that remain are how to choose the pivot value p and how to partition the array of the chosen p. The choice of p is arbitrary. Any p in the array will work, although the sequence of choices will affect how you reach the base case. Chapter 11 gives an algorithm for partitioning the array around p. You will see how to turn the function kSmall into a sorting algorithm.
