The solution to the HAir problem in Chapter 6 involved an exhaustive search of the graph in Figure 20-a to determine a directed path from the origin vertex (city) to the destination vertex (city). The algorithm search starts at a given vertex and traverses edges to other vertices until it found the desired vertex or determined that no (directed) path existed between the two vertices.

What distinguishes search5 from a standard graph traversal is that search5 stops when it first encounters the destination vertex. A graph-traversal, on the other, will not stop until it has visited all of the vertices that it can reach. That is, a graph traversal is a tree traversal, which always starts at v and will visit all vertices in v for which there is a path between v and w. Unlike a tree traversal, it does not necessarily visit all of the vertices in the graph unless the graph is connected. A graph traversal visits every vertex in the graph if and only the graph is connected, regardless of the order of vertices. Then you can use a graph traversal to determine whether a graph is connected.

A graph traversal visits all of the vertices that it can reach and only if it is connected

If a graph is not connected, a graph-traversal begins at v will visit only a subset of the graph's vertices. This subset is called the connected component v. You can determine all of the connected components of a graph by repeating a traversal starting at an unvisited vertex.

A connected component is the subset of vertices visited by a traversal that begins at a given vertex

If a graph contains a cycle, a graph-traversal algorithm can loop indefinitely. To prevent such a misfortune, the algorithm must mark each vertex during a traversal and never visit a vertex more than once.
