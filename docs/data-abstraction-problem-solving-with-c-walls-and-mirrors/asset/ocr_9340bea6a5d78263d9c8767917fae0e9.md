+   8. You can organize an index file by using hashing or a B-tree. These schemes allow you to perform the basic dictionary operations using only a few block accesses.

+   9. Although external hashing generally performs retrievals, insertions, and removals to be performed more quickly than a B-tree, it does not support such operations as traversals or range queries. This deficiency is one motivation for multiple indexing.

If the file contains n blocks, the system can allocate it to an (n + 1)th block. When the file needs a longer block, you can deallocate it and return it to the system.
