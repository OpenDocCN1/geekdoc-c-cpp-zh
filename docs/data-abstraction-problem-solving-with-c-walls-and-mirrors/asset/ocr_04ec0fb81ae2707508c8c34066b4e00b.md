Clearly, before you access an element of an array, you must assign it a value. You must assign values to array elements one at a time by the previously described index notation. Note that, if a and b are arrays of the same type, assignment = b is illegal.

The data type of maxTemps is a derived type, which is a type that you derive from fundamental types using a declaration operator as []. Defining a type by using typedef is often useful. Thus, you can write

```
const int DAYS_PER_WEEK = 7;
typedef double Array[DAYS_PER_WEEK];nArray maxTemps;
```

and make Array available for use throughout your program.

Initialization. You can initialize the elements of an array when you declare it for the first time. For example,

```
double maxTemps[DAYS_PER_WEEK] = {82.0, 71.5, 61.8, 75.0, 88.3};
```

initializes the first five elements of maxTemps to the values listed and the last two to zero.

Passing an array to a function. If you wanted a function computed the average of the first n elements in a one-dimensional array, you could declare the function

```
double getAverageTemp(double temperatures[], int n);
```

Because the compiler does not know how many items of the array that you write, you must also pass either the size of the array or the number of array items to process. Traditionally, the array is listed as the first parameter and the number of items as the second. You can invoke the function by writing, example,

```
double avg = getAverageTemp(maxTemps, 5);
```

maxTemps is the previously defined array.\An array is never passed by value, regardless of how you write it. An array is always passed by reference. This restriction avoids the copying of many array entries. Thus, the function getAverageTemp could modify the elements of maxTemps, even though the array is an input to the function. To prevent such alteration, you can specify the array parameter as a constant reference parameter by preceding its type with, as follows:

```
double getAverageTemp(const double temperatures[], int n);
```
