# 14.1.3 An Array-Based Implementation

For applications in which a fixed-sized queue does not present a problem, you can use an array to represent a queue. A naive array-based implementation of a queue might include the following definitions, as Figure 14-7a illustrates:

A naive array-based implementation of a queue

```
const int MAX_QUEUE = maximum size of queue;
...
type items[MAX_QUEUE]; // Array of queue items
int front;             // Index to front of queue
int back;              // Index to back of queue
```

Overview of nArrayQueue

Front and back are the indices of the front and back entries, in the queue. Initially, front is 0 and back is -1. To add a new item to the queue, you increment back and place the item in items[back]. To remove an item, you simply increment front. The queue is full whenever back equals MAX_QUEUE - 1.

The problem with this strategy is rightful drift—that is, after a sequence of additions and removals, the items in the queue will drift toward the end of the array, making it appear full. In other words, back could equal MAX_QUEUE–1 when the queue contains only a few items. Figure 14-7 illustrates this situation.

Rightward drift can cause a queue-full condition though the queue contains a few items

One possible solution to this is to shift the array entries to the left, either after each removal from the queue or when back equals MAX_QUEUE–1. This solution guarantees that the queue always contains up to MAX_QUEUE items. Shifting is not really satisfactory, however, as it would increase the cost of the implementation.
