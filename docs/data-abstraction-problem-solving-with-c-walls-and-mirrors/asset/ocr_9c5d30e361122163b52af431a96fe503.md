A binary search of a dictionary

```
// Search a dictionary for a word by using a recursive binary search
if (the dictionary contains only one page)
    Scan the page for the word
else
    Open the dictionary to a point near the middle
    Determine which half of the dictionary contains the
    if (the word is in the first half of the dictionary)
        Search the first half of the dictionary for the word
    else
        Search the second half of the dictionary
```

Parts of this solution are intentionally vague: How do you scan a single page? How do you find the middle of the dictionary? Once the middle is found, how do you determine which half contains the word? The answers to these questions are not difficult, but they would obscure the solution strategy right now.
The previous search strategy reduces the problem of searching the dictionary to a problem searching half of the dictionary for the word, as Figure 2-1 illustrates. Notice two important points. Once you have divided the dictionary in half, you already know how to search the appropriate half. You can easily use the same strategy that you employed to search the original dictionary. Note, that there is a special case that is different from all the other cases: After you have divided the dictionary so many times that you are left with only a single page, the halves ceases. At this point, the problem is small enough that you can solve it directly by scanning the single page that remains for the word. This special case is called the base case (or basis or degenerate case).

This strategy is called divide and conquer. You solve the dictionary search problem by first dividing the dictionary into two halves and conquering the appropriate half. You solve the smaller problem by using the same divide-and-conquer strategy. The division continues until you reach the base case. As you will see, this strategy is inherent in many recursive solutions.
To explore the nature of the solution to the dictionary problem, consider a slightly more rigorous formulation.

A binary search uses a divide-and-conquer strategy

```
search(aDictionary: Dictionary, word: string)
if (aDictionary is one page in size)
    Scan the page for word
else
    Open aDictionary to a point near the middle
    Determine which half of aDictionary contains word
```
