# The Abstract Data Type 195

This solution calls attention to two of the operations the ADT will have to include:

+   - Add a new item to the ADT.
- Remove from the ADT the item that was added most recently.

Notice that potential trouble occurs if you type a $\leftarrow$ when the ADT is empty—that is, when the ADT contains no characters. If this situation should occur, you have three options: (1) the program terminate and write an error message, (2) throw an exception, or (3) have the program ignore the $\leftarrow$ and continue. Any of these options is reasonable, so let's suppose that you decide to ignore the $\leftarrow$ and continue. Therefore, the algorithm

Two ADT operations that are required

```
// Read the line, correcting mistakes along the way
while (not end of line)
{
  Read a new character ch
  if (ch is not a '←')
    Add ch to the ADT
  else if (the ADT is not empty)
    Remove from the ADT the item that was added most recently
  else
    Ignore the '←'
}
```

A false start at writing the line

This pseudocode is incorrect for two reasons:

+   - When you remove an item from the ADT, the item is gone, so you cannot display it. What you should have done to look at the item that was added to the ADT most recently. An accessor operation returns an item—allowing you to look at it—but does not change the ADT's data. After getting and displaying the item you remove it from the ADT.
- The last character of the input line is the most recently added to the ADT. You certainly do not want to write it. The resolution of this particular difficulty is left to you as an exercise.
