# 4.2 A Link-Based Implementation of the ADT Bag

Now that we have a class of nodes to use when defining link-based data structures, we will use it to define a link-based implementation of the ADT bag. Doing so will allow us to examine some of the best practices for creating such implementations. Subquent chapters will expand on these ideas.

Unlike array-based implementations, a link-based implementation does not impose a fixed size on the data structure—except, of course, imposed by the storage limits of the system. Additionally, data items do not move during an ADT’s insertion and removal operations.
