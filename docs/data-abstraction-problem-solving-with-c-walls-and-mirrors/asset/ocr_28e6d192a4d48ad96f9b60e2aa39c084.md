The elaboration phase refines a system's requirements and cost

Each iteration starts with an object-oriented analysis of the system requirements and input from the testing of the previous iteration. This analysis leads to a set of use case scenarios to analyze, design, implementation, and test. Those scenarios are examined for objects and attributes. UML sequence and class diagrams are drawn to clearly show the objects' capabilities, responsibilities to the system, and relations to one another. This design is then coded and tested. If this iteration is not of the first, code may need to be integrated into the existing subsystem. After final testing, end users and data experts use the system to produce feedback for subsequent iterations.

# D.2.3 Construction Phase

The construction phase begins once most of the system requirements have been formalized. Each iteration in this phase still consists of analysis, design, implementation, and testing. At this point in the development of the system, however, the analysis and design components require less attention, and increased effort is focused on implementation and testing.
