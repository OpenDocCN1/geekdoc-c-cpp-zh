# 2.6.3 Choosing out of n

A rock band wants to visit $n$ cities. Unfortunately, time will allow visits to only $k$ cities. The band agent considers the different for visiting $k$ cities out of $n$ possibilities. Because time is short, the band members are not concerned about the order in which they visit the same $k$ cities.

Let $g(n,k)$ be the number of groups of $k$ cities chosen from $n$. If we visit either $C$ or not. If we visit $C$, we have to choose $k-1$ cities to visit from the $n-1$ others. Thus the number of ways is $g(n,k)$. On the other hand, if we do not visit $C$, we have to choose $k$ cities from the remaining $n-1$ cities. The number of groups of $k$ cities that do not include $C$ is $g(n-1,k)$. We can compute $g(n,k)$ by solving two smaller problems of the type such as:

The number of ways to choose out of $n$ cities is the sum of the ways to choose out $k-1$ of $n-1$ and the number of ways to choose out $k$ of $n-1$ things

```
$g(n,k)=g(n-1,k-1)+g(n-1,k)$,
```

We need to find the base case(s) and demonstrate that each of the two smaller problems reaches a base case. First, if the band needs to visit all $n$ cities—that is $k=n$—there is one group of all the cities. Thus, the first base case

```
$g(n,k)=1$
```

If $k<n$, the second term $g(n-1,k)$ in the recursion definition will reach this base case, because each successive stage of the recursion, $n-1$ decreases until it reaches $k$. The first term, $g(n-1,k-1)$, does not reach this base case. Since $n-1$ and $k-1$ decrease at the same rate, they will never become equal. The first term does, in fact, approach another selection problem. Just as there is only one group of all the cities ($k=n$), there is only one group of zero cities ($k=0$). Thus, the base case is

```
$g(n,0)=1$
```
