# C4.2 Containment: Has-a Relationships

A ball-point pen has a ball as its point, as Figure C4-8 illustrates. Although you would want to use Ball1 in your definition of a class Pen, you should not use public inheritance, because a pen is not a ball. In fact, you do not use inheritance at all implement a has-a relationship. Instead, you can define a data member point—whose type is Ball1—within the class Pen as

```
class Pen {
    private:
        Ball point;
};
// end Pen
```

Recall that a data member can be an instance of any class other than the currently being defined—Pen. An instance of Pen has, or contains, an instance of Ball1. Thus, another name for the has-a relationship is containment.
