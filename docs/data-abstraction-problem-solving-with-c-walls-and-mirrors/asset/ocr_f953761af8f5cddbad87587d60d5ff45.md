behave reasonably. Consider two possibilities:

+   * The first integer on the input line, the function assigns to group, is not in the range
LOW_END to HIGH_END. The reference
incomeData[group - LOW_END]
is incorrect, because it accesses an array element outside the bounds. This error also
happens when the user tries to end the input by entering zeros for group and number.
* The second number on the input line, the function assigns to number, is negative.
Although a negative value for number is valid, because you cannot have a negative number of
people in an income group, the function will add to the group's array. Thus, the

After the function reads values for group and number, it must check whether group is in the
LOW_END to HIGH_END and whether number is positive. If either value is not in range, you

Suppose instead of checking the value of number before you add it to the array
incomeData[group - LOW_END], you perform the addition and see whether the sum is positive. This
approach is insufficient, you might add a negative value to an entry of incomeData without

incomeData is 10,000, a negative value for number could remain undetected
invalidates the results of the rest of the program.

and terminate. Another possibility is to set the error flag, ignore the bad input line, and con-
