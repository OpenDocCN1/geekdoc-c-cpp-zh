
* * Chapters 15 through 17: Before we begin the next chapter, C++ 5 introduces overloaded operators and friend access. We overload operators when we define classes of trees—binary, search, and general—and their possible uses. Chapter 16 considers implementations of these trees, and briefly introduces the sort. C++ 6 presents it in the context of a list. Chapter 17 introduces the ADT heap and shows how to implement it by using an array. We use a heap to implement the query and to sort an array.
* Chapter 18: This chapter covers the specification and use of the ADT dictionary (formerly called the table in the previous edition). We look at implementations of the dictionary that use an array or binary search tree. We then introduce hashing and use it as a dictionary implementation.
* Chapter 19: Chapter 19 introduces balanced search trees. Included in this chapter are 2-3-4, and red-black trees, as well as AVL trees. These are considered as implementations of the ADT dictionary.
* Chapter 20: Next, this last chapter considers data storage in external access files. Merge sort is modified to sort such data, and external hashing and B-tree indexes are used to search. Searching algorithms are generalizations of the internal hashing schemes and 2-3 trees already developed. Finally, C++ ends the main presentation by discussing the containers and algorithms available in the C++ Template Library (STL).
* Appendix A through L: The appendices provide supplemental information. As we mentioned, Appendix A reviews C++ up to not classes. Appendices B, C, D, and F contain sections that were in Chapter 1 of the previous edition, namely important aspects of programming, the Unified Modeling (UML), the software life cycle, and algorithm verification. Appendix E covers mathematical induction, and Appendix G covers input and output with external files. Appendix H provides a list of C++ header files and standard functions, and Appendix I considers the javadoc commenting style and defines the tags that we use in this book. Appendix J is a simple chart of the ASCII character codes. Finally, Appendix K and L are brief transition guides to C++ for those who know Java or Python, respectively.
