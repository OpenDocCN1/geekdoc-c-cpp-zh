This C++ Interlude discusses memory allocation for variables and arrays and introduces you to pointers to complete the discussion on polymorphism begun in the first C++ Inter. Pointers are a powerful tool for the programmer, but you must be careful to use them correctly. This interlude explains the need for pointers and shows when and how to use them. Certain aspects of pointers are not covered in this interlude, but those features are either unnecessary in this textbook or introduce unsafe practices.

We will introduce memory allocation during execution instead of compilation and show how pointers are involved with this process. We will also discuss how to create a new and larger array during execution, if an array becomes full. You will see examples of this process at the end of this interlude.

Throughout our discussion here, and throughout the book, we will stress safety and secure programming practices. To begin our discussion, let's consider how memory is allocated for local variables and parameters.
