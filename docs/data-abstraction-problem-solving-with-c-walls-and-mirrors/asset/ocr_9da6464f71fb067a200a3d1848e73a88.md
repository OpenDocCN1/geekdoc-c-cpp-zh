Graphs as ADTs 607

> Note: ADT graph operations
* Test whether a graph is empty.
* Get the number of vertices in a graph.
* Get the number of edges in a graph.
* See whether an edge exists between two vertices.
* Insert a vertex in a graph whose vertices have distinct values that differ from the vertex's value.
* Insert an edge between two vertices in a graph.
* Remove a particular vertex from a graph and any edges between the vertex and other vertices.
* Remove the edge between two vertices in a graph.
* Retrieve from a graph that contains a given value.

Several variations of this ADT are possible. For example, if the graph is directed, you can replace occurrences of "edges" in the previous operations with "directed edges". You can add traversal operations to the ADT. Graph-Traversal algorithms are discussed in Section 20.3.
Listing 20-1 contains an interface that specifies in detail the ADT operations for an undirected graph.
