The ghost function will examine all the paths that start at the square to the west of the present square as follows. If the square directly to the west is clear, it is inside the maze, and has not been visited before, move into this square and make it part of the path. (Note that you are moving from the east.) Check whether you are at the exit. If you are not, otherwise try to find a path to the exit by trying all paths leaving this square except the one you came (this would put you back in the square from which you came). Call goNorth; if it is not successful, call goWest; and if it is not successful, call goSouth. If goSouth is not successful, mark this square as visited, move back into the square to the east, and return. The functions goEast and goSouth are analogous to goNorth and goNorth.

The input represents a maze is simple. For example, the previously given maze is represented by the lines of input, which can be in a text file:

20 7 ← width and height of the maze in squares
0 18 ← row and column coordinate of maze exit
6 12 ← row and column coordinate of maze entrance
XXXXXXXXXXX
X X XXXX X
X XXXXX XX X
X XXXXXXX X X
X X XX XX X
XXXXXXXXXXXX X
XXXXXXXXXXX

After the first three lines of numeric data in the file, each next lines corresponds to a row in the maze, and each character in a line corresponds to a maze. An x indicates a blocked square (part of the wall), and a blank indicates a clear square. This notation is convenient, because you can see what the maze looks like as you design it.
