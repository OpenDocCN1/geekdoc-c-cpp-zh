# 18.2.2 A Binary Search Tree Implementation of the ADT Dictionary

Although linear implementations of the ADT are fine for specific applications, they are not suitable as general-purpose classes. The nonlinear link-based implementation uses a binary search tree to represent the items in the ADT. That is, the dictionary class will use composition and thus have a binary search tree as one of its data members. In this way, our class reuses the class BinarySearchTree from Chapter 16.
