Standard Template Library, or STL. The STL is a collection of data types you can use in your programs. These data types are not part of the official C++ language, but they have been added to the built-in data types. Section A9 discusses libraries like the STL and their usefulness.
To use a vector in your program, you must begin it with the following statements:

```
#include<vector>
using namespace std;
```

You can declare a vector in one of three:

+   - If you know how many elements you want in the vector, you can place the type of data will in brackets and the number of elements in parentheses:

```
vector<double> firstVector(10); // Vector to hold 10 doubles
vector<string> myVector(12); // Vector to hold 12 strings
```

The size you specify when declaring the vector is only its initial size. As you will see, a vector can grow size when you add more elements.

+   - You can place initial values into a vector when you declare it, by writing a second argument:

```
vector<int> intVector(5, -1); // Vector to hold 5 integers, initialized to -1
```

+   - When the elements are in the vector, they are given the value of the second argument.

+   - You can create an empty vector—a vector with no elements—by omitting the size and parentheses:

```
vector<char> letterVector; // An empty vector
```

You can store or access items in a vector using the [] operator, just as you would using an array. For an array, the subscripts that identify elements in a vector start at 0 and go to s-1, where s is the size of the vector. The following statements are examples of accessing a value and changing the value of an existing entry:

```
double x = firstVector[5]; // Places sixth entry in x
myVector[3] = "This is a string."; // Sets fourth entry’s value
```

Using stores a value in an existing element. If you are not sure how many elements the vector has, you can call the size method, as in the following:

```
cout << intVector.size() << endl; // Displays the number of elements in vector
```

By calling the size method, you can determine whether the vector is full. This is an important advantage if the vector is either full or has elements—that is, if it was created without elements, letterVector was previously—you can add new values by using the push_back method. The push_back method accepts an argument and adds the element to the end of the vector. In other cases, it pushes the value onto the back of the vector.

Earlier, we declared a ten-element firstVector that could hold data of type double. If we needed to add all additional values 2.3 and 3.4, we can use the push_back method:

```
firstVector.push_back(2.3); // Grow and store value
firstVector.push_back(3.4); // Grow and store value
```

At this point, calling the size method would return 12, since two additional elements have been added to the vector.
