# 4.1 Preliminaries

Let consider components that can be linked to one another. Each component—usually called a node—contains both a data item and a "pointer" to the next item. Because each node must contain two pieces of information—the data item and the pointer to the next node—it is natural to conclude that each node should be an object. One member of the is the data item and the other is a pointer. Typically, such pointers are C++ pointer variables.

We use arrows to represent the pointers, but what type of pointer should you use within a node, and to what it point? You might guess that the pointer should point to a string, but actually it must point to a node that contains the string. Because pointers can point to any data type except files—and nodes are objects—pointers can, in fact, point to nodes. Suppose our class of nodes has an accessor method, getItem(), which returns the value of the data item. To reference item in the node which nodePtr points, you write nodePtr->getItem(). Likewise, if our class of nodes has the method getNext to access the data member, the expression nodePtr->getNext() represents the pointer next.
