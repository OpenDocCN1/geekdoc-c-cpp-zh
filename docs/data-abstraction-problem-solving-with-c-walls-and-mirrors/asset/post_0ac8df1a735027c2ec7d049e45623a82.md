### Strip away the first character

To begin, consider a simple method of the previous pseudocode that replaces occurrence of last with first. Thus, the function writes the first character rather than the last and recursively writes the remainder of the string.

```
writeBackward1(s: string)
if (string s is empty)
    Do nothing—this is the base case
else{
    Write the first character of s
    writeBackward1(s minus its first character)
}
```

Does this solution do what you want? If you think about this function, you will realize that it writes the string in its normal left-to-right direction instead of backward. After all, the steps in pseudocode simply write the string. Naming the function writeBackward does not guarantee that it will actually write string backward—recursion is really magic!
