Given the specification of the add method, you have no reason to expect that the previous statements, in fact, produce the binary tree in Figure. Assuming that the operations are successful, you will know only that the binary tree has seven nodes containing the data. Our specification of addition is intentionally vague and the programmer implements the class BinaryTree flexibility. It also makes BinaryTree more useful as a base class, as you will see in the next chapter.
