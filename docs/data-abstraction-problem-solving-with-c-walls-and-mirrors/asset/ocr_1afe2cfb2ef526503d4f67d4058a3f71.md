Surprisingly, you can building a full binary search tree is simple, but what can you do if the tree is restored is not full—that, if it does not have n = 2^h-1 nodes for some h? The first thing that comes to mind is that the restored tree should be complete—full up to the last level, with the last level filled from left to right. Actually, because you care only about minimizing the height of the restored tree, it does not matter where the nodes on the last level go, as Figure 16-17 shows.
