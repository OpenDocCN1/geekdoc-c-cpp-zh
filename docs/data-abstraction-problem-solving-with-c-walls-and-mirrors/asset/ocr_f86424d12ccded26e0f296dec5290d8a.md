+   1. You can ignore low-order terms in an algorithm's growth-rate function. For example, if an algorithm is $O(n^3 + 4 	imes n^2 + 3 	imes n)$, it is also $O(n^3)$. By examining the table in 10-3a, you can see that $n^3$ is significantly larger than $4 	imes n^2$ or $3 	imes n$, particularly for large values of $n$. For large $n$, the growth rate of $n^3 + 4 	imes n^2 + 3 	imes n$ is the same as the growth rate of $n^3$. Even, if an algorithm is $O(n^3 + 4 	imes n^2 + 3 	imes n)$, we say that it is simply $O(n^3)$. In general, you can usually conclude that an algorithm is $O(f(n))$, where $f$ is a function similar to the ones listed in Figure 10-3.
