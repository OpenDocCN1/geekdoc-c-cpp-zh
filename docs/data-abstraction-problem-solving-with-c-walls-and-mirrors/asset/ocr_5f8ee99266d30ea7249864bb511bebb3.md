# Dynamic Allocation of Arrays 131

You just learned how to use the new operator to allocate memory dynamically—that is, during program execution. Although Section C2.3 showed how to allocate memory for a single variable object, or you can actually allocate memory for many at one. If you write

```
int gridSize = 50;
double* anArray = new double[arraySize];
```

the pointer variable anArray will point to the first item in an array of 50 items. Unlike MAX_SIZE, arraySize can change during program execution. You can assign a value to arraySize at execution time and then determine how large your array is. It's good, but how do you use this array?

Regardless of how you use an array—statistically, as in example, or dynamically, as in the second—you can use an index and the family-like array notation to access its elements. For example, anArray[0] and anArray[1] are the first two items in your anArray.

When you allocate an array dynamically, you need to return its memory to the system when you no longer need it. As described, use the delete operator to perform this task. To deallocate the array, you write

```
delete [] anArray;
```

Note that you use brackets when you want to delete an array.

Now suppose that your program needs to allocate a new and larger array, copy the old array into the new array, and finally deallocate the old array. The size of the array can change during its execution, but this is feasible. The following statements show the size of an array:

```
double* oldArray = anArray;
double* newArray = double[2 * arraySize];
```
