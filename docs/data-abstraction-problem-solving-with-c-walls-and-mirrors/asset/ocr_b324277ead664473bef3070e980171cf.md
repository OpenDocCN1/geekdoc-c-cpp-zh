# Algorithm Verification 761

**4. The loop must terminate.** That is, you must show that the loop will terminate after a finite number of iterations. In the example, j begins at 0 and increases by 1 at each execution of the loop. Thus, j eventually equals n for any n ≥ 1. This fact and the nature of the statement guarantee that the loop will terminate.

Not only can you use invariants to show that your loop is correct, but you can also use them to show that your loop is correct. For example, show that the expression in the previous while statement was j = n instead of j = k. Steps 1 and 2 of the demonstration would be true, but step 3 would differ: When the loop contained n+1, and the invariant would be true, sum of the elements item[0] through item[n]. Because this is not the desired sum, you know something is wrong with your loop.

Notice the clear connection between steps 1 through 4 and **mathematical induction.**¹ Showing the invariant to be true initially, which establishes the **base case**, is analogous to showing a property of the natural numbers for 0. Showing that each iteration of the loop preserves the invariant is the **inductive step**. This step is analogous to showing if a property is true for any natural number k, then the property is true for natural k+1. After performing the four steps described, you can conclude that the invariant is true after every iteration of the loop—just as mathematical induction allows you to conclude that a property is true for every natural number.
