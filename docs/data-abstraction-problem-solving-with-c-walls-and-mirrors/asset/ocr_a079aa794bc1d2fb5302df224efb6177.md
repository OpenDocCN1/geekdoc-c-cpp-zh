# G.2 Text Files

Text files are designed for easy communication with people. As such, these files are flexible and easy to use, but they are not as efficient with respect to computer time and storage as binary files.

One special aspect of text files is that they appear to be divided into lines. This illusion is often the source of confusion. In reality, a text file—like any other file—is a sequence of bytes, that a text file is a sequence of characters. An end-of-line character creates the illusion that a text file contains lines by making the file behave as if it were divided into lines.

When you create a text file by typing data at character, each time you press the Enter, or Return, you insert one end-of-line character into the file. When an output device, such as a printer or monitor, encounters an end-of-line character in a text file, the device moves to the beginning of the next line. In C++, this end-of-line symbol is \n.

In addition, you might find a special end-of-line character that follows the last component in a file. Such a symbol may not actually exist in the file, but C++ behaves as if one did. The defined constant EOF, for "end of file," represents this symbol within your program. This book assumes that all files—including the empty file—have both an end-of-line symbol and an end-of-file symbol. Figure G-1 depicts a text file with these special symbols.

FIGURE G-1 A text file with end-of-line and end-of-file symbols

| T | o | d | a | y | eoln | i | s | eoln | i | t | eoln | eof |
eoln is the end-of-line symbol |
eof is the end-of-file symbol |

Any program that uses files must use the standard C++ file stream library. We enable access by including the following statements in your program:

```
#include <fstream>
using namespace std;
```

The C++ file stream library provides three types: ifstream for input file streams, ofstream, and ofstream for file streams that are both input and output. You use a stream variable of one of these to access a file. Files are sometimes referred to as streams since you can think of a file as a stream of characters flowing into or out of your program.
To a file in your program, there are three simple steps:

+   1. Open the file.
2. Read data from the file or write data to the file.
3. Close the file.

# G.2.1 Opening and Closing Text Files

Opening a file. Before you read or write to a file, you need to open it. That is, you need to initialize the file and associate it with a stream variable. One way to open a file is to provide the file's name when you declare the stream variable. For example,

```
ifstream inFile("Ages.DAT"); // Input file
```
