# 编程问题 225

对于此输入，程序应该产生输出：

```
请求从 Albuquerque 到 San Diego 的飞行。
从 Albuquerque 到 Chicago 的 #178 号航班，费用：$250
从 Chicago 到 San Diego 的 #703 号航班，费用：$325
总费用 . . . $575
请求从 Albuquerque 到 Paris 的飞行。
抱歉，Air 不提供 Paris。
请求从 San Diego 到 Chicago 的飞行。
抱歉，Air 不从 San Diego 到 Chicago。
```

当非递归路径方法找到从起点到目的地的航班序列时，它的栈包含了相应的城市路径。报告此路径的障碍是城市在栈中的出现顺序是反的；也就是说，目的地在栈顶，而起点城市在栈底。例如，如果你使用程序查找图 6-6 中从城市 P 到城市 Z 的路径，栈的最终内容将是 P-W-Z 在栈顶。你想先显示起点城市 P，但它在栈的底部。如果你限制在栈操作上，按正确顺序写入路径的唯一方法是将栈弹出到一个临时栈中以反转栈，然后在从临时栈中弹出元素时写入城市。注意，这种方法需要你处理路径上的每个城市两次。

显然，栈不是按正确顺序写入城市路径问题的合适抽象数据类型；合适的抽象数据类型是可遍历栈。除了标准的栈操作 isEmpty、push、pop 和 peek 之外，可遍历栈还包含 traverse 操作。traverse 操作从栈的一端开始并访问栈中的每个元素直到到达栈的另一端。对于该项目，你希望 traverse 从栈底向栈顶移动。
