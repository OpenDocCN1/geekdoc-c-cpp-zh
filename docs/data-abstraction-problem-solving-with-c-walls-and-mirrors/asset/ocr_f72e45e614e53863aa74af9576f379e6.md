The method class. To remove all entries from a list, you can call the remove method. Because the easiest to remove is the first one, the method can invoke remove(1) repeatedly until the list is empty. This action works because, if you remove the first entry in the list, the remaining entries are renumbered. Therefore, to remove all entries, you can repeatedly remove the first entry.
