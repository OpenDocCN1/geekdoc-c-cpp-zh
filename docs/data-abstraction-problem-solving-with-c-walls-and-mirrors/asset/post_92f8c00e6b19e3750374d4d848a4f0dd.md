## 20.4.6 Some Difficult Problems

The next three applications of graphs have solutions that are beyond the scope of this book.

**The traveling salesperson problem.** A **Hamilton circuit** is a path that begins at a vertex $v$, passes through every vertex exactly once and terminates at $v$. Determining whether an arbitrary graph contains a Hamilton circuit can be difficult. A well-known variation of this problem—the traveling salesperson problem—involves a weighted graph that represents a road map. Each edge has an associated cost, such as the mileage between cities or the time required to drive from one city to the next. The salesperson must begin at an origin city, visit every other city exactly once, and return to the origin city. However, the circuit traveled must be the least expensive.

# SUMMARY

- 1. The most common implementations of a graph are the adjacency matrix and the adjacency list. Each has its relative advantages and disadvantages. The choice should depend on the needs of the given application.
- 2. Graph searching is an important application of stacks and queues. Depth-first search (DFS) is a graph-traversal algorithm that uses a stack to keep track of the sequence of vertices. It goes as deep into the graph as it can backtracking. Breadth-first search (BFS) uses a queue to keep track of the sequence of vertices. It visits all adjacent vertices before further.
- 3. Topological sorting produces a linear order of the vertices in a directed graph. A graph is an acyclic graph if it contains no cycles.
- 4. A spanning tree of a connected graph is a tree that contains all vertices.
- 5. A minimum spanning tree of a weighted graph is a spanning tree whose edge sum is minimum.
- 6. The shortest path between two vertices in a weighted graph is the path with smallest weights.
