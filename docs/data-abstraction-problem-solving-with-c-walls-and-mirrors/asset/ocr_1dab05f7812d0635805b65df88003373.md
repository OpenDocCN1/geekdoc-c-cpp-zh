We have several options to fix this function. The first is to delete the object before the function terminates. We can do this by adding the lines

```
delete someBoxPtr;
someBoxPtr = nullptr;
```

at the end of the function. If the Box object pointed to by someBoxPtr is needed only by this function, a better implementation would have been not to allocate memory from the free store, but to use a local variable as is done in the following statements:

```
ToyBox<double> someBox(); // someBox is not a pointer variable
someBox.setItem(someItem);
```

If the object created is outside the function, the function can return a pointer to it that the caller can access the object. To implement this, we would change the function's return type from void to ToyBox<double>* and return someBoxPtr, which is a pointer to the ToyBox<double> object. The resulting definition is

```
ToyBox<double>* leakyFunction(const double& someItem)
{
    ToyBox<double>* someBoxPtr = new ToyBox<double>();
    someBoxPtr->setItem(someItem);
    return someBoxPtr;
} // end leakyFunction
```
