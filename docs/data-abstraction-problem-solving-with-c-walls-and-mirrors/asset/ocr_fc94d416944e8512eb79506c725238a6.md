A syntax diagram is convenient for use, but a grammar is a starting point if you want to write a function that will recognize it. A grammar for the language C++Identifiers

```
<identifier> = <letter><identifier><letter>|<identifier><digit>
<letter> = a | b | .. | z | A | B | .. | Z |
<digit> = 0 | 1 | .. | 9
```

A grammar for the language of C++ identifiers

The definition reads as:

> An identifier is a letter, or an identifier followed by a letter, or an identifier followed by a digit.

The most striking aspect of this definition is that identifier appears in its own definition: this grammar is recursive, and as are many grammars.

Many grammars are recursive

Given a s, you can determine whether it is in the language C++Identifiers by using the grammar to construct the following recognition algorithm: If s of length 1, it is in the language if the character is a letter. If s is of length than 1, it is in the language if the last character of s is a letter or a digit, and s minus its last character is an identifier.

The pseudocode for a recursive valued function determines whether a string is in the language C++Identifiers:

```
// Returns true if s is a legal C++ identifier;
// otherwise returns false.
isid(s: string): boolean
  if (s is of length 1) // Base case
    if (s is a letter)
      return true
    else
      return false
  else if (the last character of s is a letter or a digit)
    return isid(s minus its last character) // Point X
  else
    return false
```
