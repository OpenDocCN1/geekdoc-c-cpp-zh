# G.2.2 Reading and Writing Text Files

Associated with each file in a program is a file window, which marks the current position within the file. Opening a file positions the file window over the first byte in the file, as Figure G-2 illustrates. Because each byte in a file is a character, the file window for a text file moves from character to character. The following sections describe the behavior of the file window.

Character input. Suppose that you have declared an input stream variable inputFile and associated it with the name of the text file by writing

```
ifstream inputFile(fileName);
```

where fileName is a string variable. When you use an input file, the file window is over the byte that you will read next. Then, after you open it, you are ready to read the first byte, as you saw in Figure G-2. As you read characters from a text file, the file window advances sequentially from one character to another. After reading several characters, you will see the file window in Figure G-3.
