Sometimes a derived class has more than one class. For example, as Figure C4-2 illustrates, you can derive a class of clock radios from the class of digital clocks and the class of radios. This type of relationship is known as **multiple inheritance**. Multiple inheritance must be used with care, since it is possible for the base classes to have named methods. For example, suppose that both digital clocks and digital radio implement a method `turnOn`. When you call the `turnOn` method in the digital clock radio, you have no way to know which turnOn method is called. In this textbook, if multiple inheritance is used, the derived class inherits from only one base class; any other classes should be abstract classes.

A derived class can add new members to inherit it

You can add as many members to a derived class as you like. However you cannot revise an ancestor's method to use their name, unless you **redefine** inherited methods. A a derived class redefines a nonvirtual method in the base class if the two methods have the same name and parameter declarations.
