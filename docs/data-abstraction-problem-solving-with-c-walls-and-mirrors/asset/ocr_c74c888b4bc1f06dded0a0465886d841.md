# CHAPTER 2 Recursion: The Mirrors

```
/** Searches the array anArray[first] through anArray[last]
 * for a given value using a binary search.
 * @pre 0 <= first, last <= SIZE - 1, WHERE SIZE is the
 * maximum size of the array, and anArray[first] <=
 * anArray <= ... <= anArray[last];
 * @post anArray is unchanged and either anArray[index] contains
 * the given value or index == -1.
 * @param anArray The array to search.
 * @param first The low index to start searching from.
 * @param last The high index to stop searching at.
 * @return Either index, such that anArray[index] == target, or -1.
 */
int binarySearch(const int anArray[], int first, int last, int target)
{
    int index;
    if (first > last)
        index = -1; // target not in original array
    else {
        // If target is in anArray,
        // anArray[first] <= target < anArray[last]
        int mid = first + (last - first) / 2;
        if (target == anArray[mid])
            index = mid; // target found at anArray[mid]
        else if (target < anArray[mid])
            // Point X
            index = binarySearch(anArray, first, mid - 1, target);
        else
            // Point Y
            index = binarySearch(anArray, mid + 1, last, target);
    } // end if
    return index;
}
```

Notice that if target occurs in the array, it must be in the segment of the array delineated by first and last. That is, in the following true:

anArray[first] target anArray[last]

> Note: When developing a recursive solution, you must be sure that the solutions to the smaller problems really give you a solution to the original problem. For example, binarySearch works because each smaller array is sorted and the value sought between its first and last values.

There is another implementation issue—one that deals specifically with C++. Recall that an array is never passed to a function by value and is therefore not copied.
