# 6.2.2 Recognizing Strings in a Language

Consider the problem of whether a particular string is in the language
L = {$S*}: s is a possibly string of characters other than S, s'=reverse(s)}

For the strings ASA, ABCSA, and S are in L, but ABAB and ABCB are not. (Exercise 14 in Chapter 5 introduced a similar language.) This language is like the language of palindromes that these strings have a special character.
A stack is useful in determining whether a string is in L. Suppose you traverse the first half of the string and push each character onto a stack. When you reach the S you undo the process: For each character in the second half of the string, you pop a character off the stack. However, you must match the popped character with the character in the string to ensure that the second half of the string is the reverse of the first half.
