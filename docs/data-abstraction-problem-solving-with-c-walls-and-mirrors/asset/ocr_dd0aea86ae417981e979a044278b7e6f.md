# 17.2.1 Algorithms for the Array-Based Heap Operations

Let's assume that the class of our heap has the following private data members:

+   * items: an array of heap items
* itemCount: an integer equal to the number of items in the heap
* maxItems: an integer equal to the maximum capacity of the heap

The array items represents the array-based representation of a complete binary tree, such as the array shown in Figure 17-3b. We will assume that we are working with a maxheap of integers.

**Retrieving an item from a heap.** First consider the heap's peekTop operation. Where is the largest item in the heap? Because every item in every node is greater or equal to the item in either of its children, the largest item must be in the root of the tree—that is, at the top of the heap. Thus, the peekTop operation takes only the following step:

```
// Return the item in the root
return items[0]
```

**Removing an item from a heap.** While the peekTop operation returns the largest item in the heap—which we know is in its root—the heap operation must remove it. Removing the root of the heap leaves two disjoint heaps, as shown in Figure 17-4a. Therefore, we do not want to remove the root. Instead, we remove the last node of the tree and place its item in the root, as shown in Figure 17-4b. The result of this step is not necessarily a heap. It is, however, a complete binary tree where left and right subtrees are both heaps. The only item in the root out of place is a semimaheap.

You thus need a way to transform a semimaheap into a heap. One strategy allows the item in the root to trickle down until it reaches a node in which it will not be out of place; that is, the item will be greater than or equal to each of its children. To accomplish this, you compare the item in the root of the semimaheap to its children. If the root's item is smaller than the larger of the items in its children, swap the item in the root with that larger item. For convenience, we will refer to the larger item as the *larger child*. The result of this step is shown 5 trickles down only one, in general more swaps may be necessary.
