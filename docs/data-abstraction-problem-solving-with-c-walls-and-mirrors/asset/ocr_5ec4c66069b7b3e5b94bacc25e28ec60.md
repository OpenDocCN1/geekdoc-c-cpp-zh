# 5.3.1 Searching for an Air Route

This example will introduce you to a general type of search problem. In this problem, you must find a path from one origin to some destination point. We shall solve this problem by using recursion. In the next chapter, we will solve it without recursion.

The High Plains Airline Company (HPAir) wants to process customer flights from some origin to some destination point. So that we can use recursion, we will simplify the problem: for each customer request, just indicate whether a sequence of HPAir flights from the origin to the destination exists.

Imagine three trips that specify all of the flight information for the airline as follows:

+   - The names of cities that HPAir serves
- Pairs of cities names, each pair representing the origin and destination of one of HPAir flights
- Pairs of cities names, each pair representing a request to fly from some origin to some destination

Determine whether HPAir flies from one city to another

The program should produce output as

Request is to fly from Providence to San Francisco.
HPAir Flies from Providence to San Francisco.

Request is to fly from Philadelphia to Albuquerque.
Sorry. HPAir does not fly from Philadelphia to Albuquerque.

Request is to fly from Salt Lake City to Paris.
Sorry. HPAir does not serve Paris.
