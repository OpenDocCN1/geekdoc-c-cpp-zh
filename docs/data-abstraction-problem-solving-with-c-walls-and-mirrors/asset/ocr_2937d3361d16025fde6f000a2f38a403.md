# A.8 Classes

Object-oriented programming, or OOP, views a program not as a sequence of actions but as a collection of components called objects that interact to produce a certain result. A group of objects of the same kind belongs to a class, which is a programming construct that defines the object's data type. Chapter 1 talks about OOP; here we will discuss how to write a class in C++.

An object contains data and can perform operations on or with that data. The class associated with a particular object describes its data and its operations. That is, a class is a blueprint for creating objects. An object's operations, or behaviors, are defined within the class by methods. These methods, together with the class's data are known as the class's members.

We could use a sphere as an example of an object. Because thinking of a basketball, volleyball, tennis ball, or soccer ball suggests images of the game rather than the object itself, let's abstract the notion of a ball by picturing a sphere. A sphere of a given radius has attributes such as volume and surface area, and should be able to report its radius, volume, surface area, and so on. The sphere object has methods that return such values.

In C++, a class has the following form:

```
class Sphere {
private:
    // Definitions of private data members and methods
    // Definitions of private methods

public:
    // Definitions of public methods
};
```

By default, all members in a class are private—they are not directly accessible by any program that uses the class—unless you designate them as public. However, explicitly indicating the private and public portions of a class is a good programming practice and one we will follow in this book. You should always declare a class's members as private.

Most objects are useful, but private methods—which only the class can call—can be helpful, you will see. The definition of a class's method can call any of the class's other methods or use of its data members, regardless of whether they are private or public.

Classes have special members, constructors and destructors, for creation and destruction of objects. A constructor creates and initializes objects, instances of a class. A destructor destroys an object when the class's life ends. A typical class has several constructors, but only one destructor. For many classes, you can omit the destructor. In such cases, the compiler will generate one for you. However, the compiler-generated destructor is sufficient. C++ Interlude 2 discusses how and why you would write your own destructor.

In C++, a constructor has the same name as the class. Constructors have no return type—not even void—and cannot return a value. Constructors have arguments. We discuss constructors in more detail before we look at an example of a class definition.
