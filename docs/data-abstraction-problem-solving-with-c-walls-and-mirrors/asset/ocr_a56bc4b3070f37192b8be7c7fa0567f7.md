Although you can declare arrays with more than two dimensions, generally more than three is unusual. The techniques for working with such arrays, however, are analogous to those for two-dimensional arrays.

> Programming Tip: When referencing an element of a multidimensional array

Initialization. You can initialize the elements of a two-dimensional array as you initialize a one-dimensional array. You list the rows by row. For example, the statement

```
int x[2][3] = {{1, 2, 3},
    {4, 5, 6}}; // 2 rows, 3 columns
```

initializes the two-dimensional array x so that it appears as

```
1 2 3
4 5 6
```

That is, the statement initialize the elements x[0][0], x[0][1], x[0][2], x[1][0], x[2][0], x[1][1] and
x[1][2] in order. In general, when you assign initial values to a multidimensional array, it is the
last, rightmost, index that increases the fastest.
