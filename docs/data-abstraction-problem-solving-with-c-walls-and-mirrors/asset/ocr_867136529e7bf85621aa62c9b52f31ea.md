Although the solution is conceptually sound, you must consider several details before you can implement the algorithm:

+   1. How will you pass half of anArray to the recursive calls to binarySearch? You can pass the entire array at each call but have binarySearch only anArray[first..last], that is, the portionArray[first] through anArray[last]. Then, you would also pass the integers first and to binarySearch:

```
binarySearch(anArray, first, last, target)
```

With this convention, the midpoint is given by

```
mid = (first + last) / 2
```

Then binarySearch(first half of anArray, target) becomes

```
binarySearch(anArray, first, mid - 1, target)
```

and binarySearch(second half of anArray, target) becomes

```
binarySearch(anArray, mid + 1, last, target)
```

+   2. How do you determine which half of the array contains target? One possible implementation of

```
target in the first half of anArray
```

is

```
target < anArray[mid]
```

However, there is no test for equality between target and anArray[mid]. This omission can cause the algorithm to miss target. The however halving algorithm splits anArray into halves, anArray[mid] is not in either half of the array. (In this case, two halves not make a whole!) Therefore, you must determine whether anArray[mid] is the value you seek, because later is not in the remaining half of the array. The interaction between the halting criterion and the termination condition (the base case) is subtle and often a source of error. We need to rethink the base case.

+   3. What should the base case(s) be?As binarySearch terminates when an array of size 1; this is the only case of halves, by the halving process it is possible to implement the binary search correctly so that it only this single base case. However, it could be clearer to have two distinct base cases:

+   - first = last. You will reach this base case when target is not in the original array.
- target = anArray[mid]. You will reach this base case when target is in the original array.

These base cases are different from any you have ever encountered previously. In a sense, the algorithm determines the answer to the problem by the case it reaches. Many cases have this flag.

+   4. How will binarySearch indicate the result of the search?If binarySearch successfully locates target in the array, it could return the index of the array value that is equal to target. This index would never be negative, binarySearch could return a negative value if it does not find target in the array.
