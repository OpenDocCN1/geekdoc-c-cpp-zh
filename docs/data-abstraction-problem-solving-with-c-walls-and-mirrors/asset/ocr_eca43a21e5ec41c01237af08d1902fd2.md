# SUMMARY

+   1. Each comment line in C++ begins with two slashes // and continues until the end of the line.

+   2. A C++ identifier is a sequence of letters, digits, and underscores that must begin with either a letter or an underscore.

+   3. You can use a typedef to declare new names for data types. These are simply synonyms for the data types; they are not new data types.

+   4. You define named constants by using a statement of the form

```
const identifier = value;
```

+   5. Enumeration provides another way to name integer constants and to define an integral data type, as in

```
enum Day {SUN, MON, TUE, WED, THU, FRI, SAT};
```

+   6. C++ uses short-circuit evaluation for expressions that contain the logical operators && (and) and || (or). That is, evaluation proceeds from left to right and as soon as the value of the entire expression is apparent.

+   7. The output operator << places a value into an output stream, and the input operator extracts a value from an input stream. You can imagine that these operators operate in direction of data flow. Thus, in cout << myVar, the operator operates on the variable myVar—data flows from myVar to the stream—whereas in cin >> myVar, the operator points to the variable myVar—data flows from the stream into myVar.

+   8. The general form of a function definition is

```
type name(parameter-declaration-list)
{
  body
}
```

A valued function returns a value by using the return statement. Although a void function does not return a value, it can use return to exit.
