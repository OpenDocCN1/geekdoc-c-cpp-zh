# 20.4 Shortest Paths

Consider once a map of airline routes. A weighted directed graph can represent this map: the vertices are cities, and the edges indicate existing flights between cities. The edges represent the mileage between cities (vertices); as such, the weights are not negative. For example, you could combine the weights in Figure 20-5 to get a weighted directed graph.

Often for directed graphs you need to know the shortest path between two particular vertices. **The shortest path between two given vertices in a weighted graph is the smallest sum of its edges.** Although we use the term “shortest”, the weight could be more than distance, such as the cost of each flight in dollars or the duration of each flight in hours. The sum of the weights of the directed edges is called the path's length or weight.

For example, the shortest path from vertex 0 to 1 in the graph in Figure 20-24 is not the edge between 0 and 1—it is rather the path from 0 to 2 to 1, with a cost of 7. For convenience, the starting vertex, or origin, is labeled 0 and the other vertices are labeled from 1 to $n-1$. Note the graph's adjacency matrix in Figure 20-2b.

The following algorithm, which is attributed to E. Dijkstra, determines the shortest path between any two vertices. The algorithm uses a *vertexSet* of selected vertices and an adjacency matrix, where weight[v] is the weight of the (cheapest) path from vertex 0 to $v$ that passes through *vertices*.

If $v$ is in *vertexSet*, the shortest path between vertices in *vertexSet*. If $v$ is not in *vertexSet*, then $v$ is the only vertex along the path that is not in *vertexSet*. That is, the path ends with an edge from vertex 0 to vertex $v$.

Initially, *vertexSet* contains only vertex 0, and weight contains weights of the single-edge paths from vertex 0 to all other vertices. Thus, weight[v] equals matrix[0][v] for all $v$, where matrix is the adjacency matrix. Thus, *weight* is the first row of matrix.

After this initialization, find a vertex $v$ that is not in *vertexSet* and minimizes weight[v]. You add $v$ to *vertexSet*. For all (unselected) vertices $u$ that are not in *vertexSet*, you check the values weight[u] to ensure they are minimum. That is, you can reduce weight[u]—the weight of a path from vertex 0 to vertex $u$—by passing through the newly selected vertex $v$.

To make this decision, break the path from 0 to $v$ into two pieces and find their weights as:

> weight[v] = weight of the shortest path from 0 to $v$
matrix[u][v] = weight of the edge from $u$ to $v$

Compare weight[v] with weight[u] + matrix[u][v] and weight[u] + matrix[v][u]

weight[u] = the smaller of the values weight[v] and weight[u] + matrix[v][u]
