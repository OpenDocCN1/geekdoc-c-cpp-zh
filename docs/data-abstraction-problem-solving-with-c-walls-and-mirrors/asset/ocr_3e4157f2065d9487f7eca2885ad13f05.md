From Chapter 1, recall the interface BagInterface that describes the operations of the ADT bag. Also remember that we can use this interface when developing any implementation of this ADT. The bag operations in this interface, given in UML notation, are as follows:

```
+getCurrent(): integer
+isEmpty(): boolean
+add(newEntry: ItemType): boolean
+remove(anEntry: ItemType): boolean
+clear(): void
+getFrequency(ofEntry: ItemType): integer
+contains(anEntry: ItemType): boolean
+toVector(): vector
```

These operations correspond to the public methods in our class.

# 4.2.1 The Header File

The header file in Linking 4-3 declares the class LinkedBag. The private data members are headPtr, which points to the first node in the linked chain that contains the items in the bag, and itemCount, which counts these items. The private section of class also declares a private method, constructor whose purpose is declared shortly. The public section declares a default constructor, a copy constructor whose purpose is discussed near the end of Section 4.2.2—a destructor, and the public methods declarations declarations are identical to those in class ArrayBag given in Chapter 3. As you will see, the compiler-generated constructor and destructor are not sufficient for linked-list implementations.

Recall from C++ Interface 2 that destructors should be virtual. We have tagged LinkedBag's destructor with the keyword virtual in the header file. Failure to do so will result in a warning from the compiler.

> LISTING 4-3 The header file for the class LinkedBag

```
/* ADT bag: Linked-based implementation.
 * @file LinkedBag.h " */

#ifndef LINKED_BAG
#define LINKED_BAG

#include "BagInterface.h"
#include "Node.h"

template<class ItemType>
class LinkedBag : public BagInterface<ItemType>
```
