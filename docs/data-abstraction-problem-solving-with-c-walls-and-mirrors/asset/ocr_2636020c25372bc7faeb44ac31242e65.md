Converting a recursive solution to an iterative one is even easier with the recursive call is the last action that the function takes. This situation is called tail recursion. For example, the function writeBackward exhibits tail recursion because its call is the last action that the function takes. Although its recursive call appears last in the function definition, fact last action is the multiplication. Thus, last call is not-recursive.

A tail-recursive function

Recall the definition of writeBackward:

```
void writeBackward(string s)
{
    int length = s.size();
    if (length > 0)
    {
        // Write last character
        cout << s.substr(length - 1, 1);
        writeBackward(s.substr(0, length - 1)); // Write reverse
    } // end if
} // end writeBackward
```

Because this function is tail-recursive, its recursive call can simply repeat the function with altered arguments. You can perform this recursion by using an iteration that will be straightforward and often more efficient. For the following definition of writeBackward is iterative:

Removing tail recursion is often as straightforward

```
/* Iterative version */
void writeBackward(string s)
{
    int length = s.size();
    while (length > 0)
    {
        cout << s.substr(length - 1, 1);
        length--;
    } // end while
} // end writeBackward
```

Because tail-recursive functions are often less efficient than their counterparts, and because the conversion of a recursive function to an iterative one is rather mechanical, some compilers automatically replace tail recursion with elimination. Other forms of recursion is usually more complex and a task that you would need to undertake, if necessary.
