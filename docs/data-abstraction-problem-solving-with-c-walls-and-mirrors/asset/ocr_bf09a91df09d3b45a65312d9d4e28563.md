After the move, you must transform the Heap region back into a heap because the new root may be out of place. You can accomplish this transformation using heapRebuild() to trickle the item now in the root so that the Heap region is again a heap.

The following algorithm summarizes these steps:

```
// Sort anArray[0..n-1]
heapSort(anArray: ArrayType, n: integer)
// Build initial heap
for (index = n / 2 down to 0) {
    // Assertion: The tree rooted at index is a semiheap
    heapRebuild(index, anArray, n)
    // Assertion: The tree rooted at index is a heap
}
// Assertion: anArray[0] is the largest item in heap anArray[0..n-1]
// Move the largest item in the Heap region—the root anArray[0]to the beginning
// of the region by swapping items and then adjusting the size of the regions
Swap anArray[0] and anArray[n-1]
heapSize = n - 1 // Decrease the size of the Heap region, expand the Sorted region
while (heapSize > 1) {
    // Make the Heap region heap again
    heapRebuild(0, anArray, heapSize)
    // Move the largest item in the Heap region—the root anArray[0]—to the beginning
// of the region by swapping items and then adjusting the size of the regions
Swap anArray[0] and anArray[heapSize]
heapSize-- // Decrease the size of the Heap region, expand the Sorted region
}
```

The analysis of efficiency of heap sort is similar to that of merge sort, as given in Chapter 11. Both algorithms are O(n × log n) in both worst and average cases. Heap sort has an advantage over merge sort that it does not require a second array. Quick sort is also O(n × log n) in the average case but is O(n²) in the worst case. It is generally the preferred sorting algorithm.
