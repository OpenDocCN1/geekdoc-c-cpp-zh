Although the tree 17-8b is not a semiheap, if you look at its leaves you will find semiheaps—that is, each leaf is a semiheap. In fact, each leaf is a heap, for the sake of simplicity, ignore this fact.

You first call heapRebuild1 on the leaves from left to right. You then move up the tree, knowing that by the time you reach node N, its subtrees are heaps, and thus heapRebuild will transform the semiheaped N into a heap. The following pseudocode steps transform the array items of itemCount

```
for (index = itemCount - 1 down to 0)
  // Assertion: The tree rooted at index is a semiheap
  heapRebuild1(index)
  // Assertion: The tree rooted at index is a heap
```

Actually, you can replace itemCount - 1 with itemCount / 2 in the previous for statement. Thus, our pseudocode becomes

```
for (index = itemCount / 2 down to 0)
  // Assertion: The tree rooted at index is a semiheap
  heapRebuild1(index)
  // Assertion: The tree rooted at index is a heap
```
