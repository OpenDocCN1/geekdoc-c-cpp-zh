Now form groups according to the first letter of each string: (AAC, ABC, AEO) (JBX) (KLT) (RDT, RLT) (TLJ) (XYZ)

Finally, combine the groups, maintaining the relative order within each group: AAC, ABC, BWZ, JBX, KLT, RDT, RLT, TLJ

The strings are now in order. In the previous example, all characters had the same length. If the character strings have varying lengths, you can treat them as if they were the same length by padding them on the right with blanks. To sort numeric data, the radix sort treats number as a character string. You can treat numbers as if they were padded on the left with zeros, making them all to be the same length. You then groups according to the right-most digits, combine the groups, form groups according to the next-digits, combine, and so on, just as you did in the previous example.
