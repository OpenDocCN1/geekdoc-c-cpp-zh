Although you can perform each retrieval operation by using only one of the indexes (that is, use the name index for retrieveN the soc index for retrieveS), insertion and removal operations must update both indexes. For example, the remove-by-name operation removeN(Jones) requires the following steps:

+   1. Search the name index for files and remove the index record.
2. Remove the appropriate data record from the data file, the soc index value ssn of this record.
3. Search the soc index file for ssn and remove this index record.

In general, the price paid for multiple indexing is more space and an additional overhead for each index whenever you modify the data file.
This chapter has presented at a very high level the basic principles of managing data in external storage. The details depend heavily on your specific computing system. Particular situations often mandate variations of the techniques described here or completely different approaches. In courses and work experience, you will undoubtedly learn more about these techniques.

# SUMMARY

+   1. An external file is partitioned into blocks. Each block typically contains many data records, and a block is the smallest unit of transfer between internal and external memory. That is, to access a record, you must access the block that it contains.
2. You can access the nth block of a direct access file without accessing the blocks that precede it. In this sense direct access files resemble random arrays.
3. Before you can process (for example, inspect or update) a record, you must read it from an external file into internal memory. Once you modify the record, you must write it back to the file.
