# ## 14.1 Implementations of the ADT Queue

Like stacks, queues can have an array-based or a link-based implementation. However, we may also use an implementation of the ADT list to define a class of queues. Such a class is easy to write, as most of the work is done by the class of lists. If you needed a class of queues right away, you could use this approach. The result would not be as time efficient as possible, however.
