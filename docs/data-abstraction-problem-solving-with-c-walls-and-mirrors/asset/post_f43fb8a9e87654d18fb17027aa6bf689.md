> Note: Although traversal means to visit each item in the ADT, traversal can be more difficult than you might imagine if you do more than simply display each item when you visit it. You might copy the item into another data structure or alter it. The details of traversal are quite application dependent, which makes a difficult operation to define within the framework of an ADT.

**Visiting a node.** You could have a different traversal for each desired task during a visit to a node, as preorderTraverseAndDisplay, preorderAndCopy, and so on. The traversal methods for the ADT binary tree call a function, which the client defines and passes as an argument, when it visits a node. We will take this approach, as it is more general.

For example, if the binary tree has the operation preorderTraverse, you can invoke it for the binary tree bintree:preorderTraverse:

A client-defined function, which the traversal methods calls, defines the meaning of "visit":

```
bintree.preorderTraverse(display);
```

where display is a client function that displays the data passed to it as an argument. Suppose the binary tree bintree stores objects. You define the function display to display data of type string:

```
void display(string someItem)
{
    cout << someItem << endl;
    // end display
}
```

Now the bintree.preorderTraverse(display) will call display each time it visits a node in the tree.

Despite the fact that the ADT operation preorderTraverse calls a client-supplied function, the wall between the program and the implementation of the ADT has not been violated. Because display is on the client's side of the wall, the function can access the data only by using the ADT operations. The next chapter will discuss the implementation details of the traversal operations.

## 15.2.2 Binary Tree Operations

- Get the number of nodes in a binary tree.

- Remove all nodes from a binary tree.
- Retrieve a specific entry in a binary tree.

## 15.2.3 An Interface Template for the ADT Binary Tree

We formalize our specifications for the ADT binary tree by writing the interface template given in Listing 15-1.

LIST 15-1 An interface template for the ADT binary tree
/** Interface for the ADT binary tree.
@file BinaryTreeInterface.h */
#ifndef BINARY_TREE_INTERFACE
#define BINARY_TREE_INTERFACE

template<class ItemType>
class BinaryTreeInterface
{
public:
    /** Tests whether this binary tree is empty.
    @return True if the binary tree is empty, or false if not. */
    virtual bool isEmpty() const = 0;

    /** Gets the height of this binary tree.
    @return The height of the binary tree. */
    virtual int getHeight() const = 0;

    /** Gets the number of nodes in this binary tree.
    @return The number of nodes in the binary tree. */
    virtual int getNumberNodes() const = 0;

    /** Gets the data that is in the root of this binary tree.
    @pre The binary tree is not empty.
    @post The root's data has been returned, and the binary tree is unchanged.
    @return The data in the root of the binary tree. */
    virtual ItemType getRootData() const = 0;

    /** Replaces the data item in the root of this binary tree
    with the given data, if the tree is not empty. However, if the tree is empty,
    inserts a new root node whose data into the tree.
    @param newData the data item to set.
    @post The root's data is now newData. */
    virtual void setRootData(const ItemType newData) = 0;

    /** Adds a new node containing a given data item to this binary tree.
    @param newData the data item to add.
    @return True if the addition is successful, or false if not.
    @post The binary tree contains the new node. */
    virtual bool add(const ItemType newData) = 0;

    /** Removes the node containing the given data item from this binary tree.
    @param data the data item to remove.
    @return True if the removal is successful, or false if not.
    @post The binary tree no longer contains the node with data. */
    virtual bool remove(const ItemType data) = 0;

    /** Removes all nodes from this binary tree.
    @post The binary tree is empty. */
    virtual void clear() = 0;

    /** Gets a specific entry in this binary tree.
    @param anEntry the desired item.
    @return The entry in the binary tree that matches anEntry.
    @throws an exception if the entry is not found. */
    virtual ItemType getEntry(const ItemType anEntry) const = 0;

    /** Tests whether the given item occurs in this binary tree.
    @param data the data item to test.
    @return True if the binary tree contains the given item, or false if not. */
    virtual bool contains(const ItemType data) const = 0;

    /** Traverses this binary tree in preorder and calls the function once for each node.
    @param visit a function that performs an operation on or with the data node. */
    virtual void preorderTraverse(void (*visit)(const ItemType&)) = 0;

    /** Traverses this binary tree in inorder and calls the function once for each node.
    @param visit a function that performs an operation on or with the data in each visited node. */
    virtual void inorderTraverse(void (*visit)(const ItemType&)) = 0;

    /** Traverses this binary tree in postorder and calls the function once for each node.
    @param visit a function that performs an operation on or with the data in each visited node. */
    virtual void postorderTraverse(void (*visit)(const ItemType&)) = 0;
};

#endif // BINARY_TREE_INTERFACE
