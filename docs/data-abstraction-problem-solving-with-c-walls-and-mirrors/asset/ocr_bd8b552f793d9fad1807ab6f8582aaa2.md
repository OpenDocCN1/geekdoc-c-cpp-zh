# 416 C++ INTERLUDE 5 Overloaded Operators and Friend Access

An overloaded operator has more than one meaning You said earlier that you define new types within C++ by using classes. Clients of such data types should be able to use them as the standard data types of the language. In particular, a client should be able to combine instances of a class with C++ operators in meaningful ways. To enable this you typically must define a new meaning for the operator, that is, you must overload it.

Suppose that myList and yourList are two instances of LinkedList, as given in Listing 9-2 of Chapter 9, and you write

```
if (myList == yourList)
    cout << "The lists are equal.\n";
```

You must provide LinkedList with a definition of ==, since the compiler will not provide a default interpretation. To this end, let us state that the myList is equal to the yourList if

+   * myList and yourList have the same size,
* Every item in myList is the corresponding item on yourList

Two lists are equal if they have identical lengths and items To overload an operator, you define an operator method whose name has the form

```
operator symbol
```

where symbol is the operator that you to overload. For the == operator you name the operator== and declare one argument: the object that will appear on the right-hand side of the operator. The current object represents the object on the left-hand side of the operator. For LinkedList, you would add the declaration

```
bool operator==(const LinkedList<ItemType>& rightSide) const;
```

to the class definition in the header file.
To understand this, realize that we may also have declared a client function isEqualTo that compares a member of type list with the current object to determine equality. The declaration for such a function would look like this:

```
bool isEqualTo(const LinkedList<ItemType>& rightSide) const;
```

To use isEqualTo to compare the myList and yourList, you would write

```
if (myList.isEqualTo(yourList))
    cout << "The lists are equal.\n";
```

You can treat operator== as exactly as you do isEqualTo; but so, you can write

```
if (myList.operator==(yourList))
    cout << "The lists are equal.\n";
```

because operator== is a simple method. However, you can also use the more shorthand notation myList == yourList, and the compiler will understand that you use the operator== method. The LinkedList implementation of this method is

