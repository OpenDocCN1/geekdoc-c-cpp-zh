Thus, we have the following definition for the method enqueue:

```cpp
template<class ItemType>
bool LinkedQueue<ItemType>::enqueue(const ItemType& newEntry)
{
    Node<ItemType>* newNode = new Node<ItemType>(newEntry);
    // Insert the new node
    if (isEmpty())
        frontPtr = newNodePtr;            // The queue was empty
    else
        backPtr->setNext(newNodePtr);     // The new node is at back
    return true;
} // end enqueue
```

**The method dequeue.** Removing from the queue involves deleting the first node of the chain. This is an easier operation than removing the last node, which we do not have to do. Figure 14-6 illustrates the removal of the first item from a queue that contains more than one item. Notice that you need to change only the external pointer frontPtr. Removal from a queue of one item is a special case that sets the external pointers backPtr and frontPtr to nullptr.
The definition of the method dequeue shows how to implement these two cases:

```cpp
template<class ItemType>
bool LinkedQueue<ItemType>::dequeue()
{
    bool result = false;
    if (!isEmpty())
    {
        // Queue is not empty; remove front
        Node<ItemType>* nodeToDeletePtr = frontPtr;
        if (frontPtr == backPtr)
        {
            // Special case: one node in queue
            frontPtr = nullptr;
            backPtr = nullptr;
        }
        else
            frontPtr = frontPtr->getNext();
        // Return deleted node to system
        nodeToDeletePtr->setNext(nullptr);
        delete nodeToDeletePtr;
        nodeToDeletePtr = nullptr;

        result = true;
    } // end if
    return result;
} // end dequeue
```

# 14.1.3 Array-Based Implementation

For applications in which a fixed-sized queue does not present a problem, you can use an array to represent a queue. A naive array-based implementation might include the following definitions, as Figure 14-7 illustrates:

```cpp
const int MAX_QUEUE = // maximum size of queue
type items[MAX_QUEUE]; // Array of queue
int front;             // Index to front
int back;              // Index to back
```

![](img/d0cb86b2f18b2db569968ad7c743510e_431_1.png)

The problem with this strategy is right drift—that is, after a sequence of additions and removals, the queue will drift toward the end, making it appear full. In other words, back could equal MAX_QUEUE–1 when the queue contains a few items.

One possible solution to this is to shift the array to the left, either after each removal or when back equals MAX_QUEUE–1. This solution guarantees that the queue always contains up to MAX_QUEUE items. Shifting is not satisfactory, however, as it would increase the cost of the implementation.

> Question 4 Suppose we change the array-based implementation of queue pictured in Figure 14-7 so that the back of the queue is in items[0]. Although repeated removals from the front would no longer cause right drift, what other problem would this implementation cause?

A much more elegant solution is by viewing the array as circular, as Figure 14-8 illustrates. To remove an item, you increment the queue front, and to insert an item, you increment back.

# FIGURE 14-8 A circular array as an implementation of queue

![](img/d0cb86b2f18b2db569968ad7c743510e_432_0.png)

Figure 14-9 illustrates the effect of a sequence of three queue operations on front, back, and around the array. Notice that front and back “advance” clockwise around the array.

When either front or back advances MAX_QUEUE – 1, it should wrap around to 0. This wraparound the problem of right drift, which occurs in the previous naive implementation, because here the circular array has no end. You obtain the wraparound effect of a circular queue by using modulo arithmetic (that, the C++ % operator) when incrementing front and back. You can remove newEntry to the queue by using the statements

```cpp
back = (back + 1) % MAX_QUEUE;
items[back] = newEntry;
```

Notice if back equal MAX_QUEUE – 1 before the addition of newItem, the first statement, back = (back + 1) %MAX_QUEUE, would have the effect of wrapping back around to index 0. Similarly, you can remove the item at the front of the queue by using the statement

```cpp
front = (front + 1) % MAX_QUEUE;
```

To initialize the queue, set front to 0 and back to MAX_QUEUE – 1.
