The recursive method heapRebuild closely follows the pseudocode given earlier in this chapter; let's assume that we coded it and in a method that uses it. The second constructor creates a heap from an array of entries. To do so, this constructor can call the private method heapRebuild, which will in turn call heapRebuild. Consider the details.

Notice that heapCreate has parameters, but it has access to our class's private data. In particular, heapCreate can use the array items and the counter itemCount. These two data members will serve as the input to the output from heapCreate. If the constructor places values into itemCount and the array items, it can call heapCreate to rearrange the values in an array into a heap.

Thus, we define the constructor as follows:

```cpp
template class ItemType;
ArrayMaxHeap<ItemType>::
ArrayMaxHeap(const ItemType someArray[], const int arraySize):
    ArrayMaxHeap(arraySize), maxItems(2 * arraySize)
{
    // Allocate the array
    items = new ItemType[2 * arraySize];
    // Copy values into the array
    for (int i = 0; i < itemCount; i++)
        items[i] = someArray[i];
    // Reorganize the array into a heap
    heapCreate();
}
```

We use initializers to set the initial values of itemCount and maxItems. After allocating the array items, we copy the values from the given arrayArray into items. Finally, we call heapCreate. Now heapCreate must form a heap from the values in the array items. To accomplish this transformation is to use the heap's add method to insert the items into the heap one by one. However, a more efficient technique of building a heap out of the items is as shown in Figure 17-8. transforms semiheap—a tree whose subsets are both heaps whose root may be out of place—into a heap. But are there any semiheaps for the heapRebuild to work on? Although the tree 17-8b is not a semiheap, if you look at its leaves you will find semiheaps—that is, each leaf is a semiheap. In fact, each leaf is a heap, for the sake of simplicity, ignore this fact.

You first call heapRebuild1 on the leaves from left to right. You then move up the tree, knowing that by the time you reach node N, its subtrees are heaps, and thus heapRebuild will transform the semiheaped N into a heap. The following pseudocode steps transform the array items of itemCount

```cpp
for (index = itemCount - 1 down to 0)
  // Assertion: The tree rooted at index is a semiheap
  heapRebuild1(index)
  // Assertion: The tree rooted at index is a heap
```

Actually, you can replace itemCount - 1 with itemCount / 2 in the previous for statement. Thus, our pseudocode becomes

```cpp
for (index = itemCount / 2 down to 0)
  // Assertion: The tree rooted at index is a semiheap
  heapRebuild1(index)
  // Assertion: The tree rooted at index is a heap
```
