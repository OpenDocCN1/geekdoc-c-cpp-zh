It appears that you can perform the operations getItem, add, and remove virtually instanta-
eously. You never have to search for an item; instead, you simply let the address calculator determine\where the item should be. The amount of time required to carry out the operations is O(1) and depends
on how quickly the address calculator performs this computation.

If you implement such a scheme, you must, be able to construct an address calc-
lator that, with little work, tells you a given item should be. Address calculators are
actually not as mysterious as they seem; in fact, there may exist that that approximate the ideal-ior just desired. Such an address calculator is usually referred to as a hash function. The scheme
just is an ideal description of a technique known as hashing, and the array table is
 the hash table.
