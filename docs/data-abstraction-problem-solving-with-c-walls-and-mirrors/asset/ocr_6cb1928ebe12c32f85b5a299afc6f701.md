# CHAPTER 3 Array-Based Implementations

The method remove now has the following definition:

```
template<class ItemType>
bool ArrayBag<ItemType>::remove(const ItemType& anEntry)
{
    int locatedIndex = getIndexOf(anEntry);
    bool canRemoveItem = isEmpty() && (locatedIndex > -1);
    if (canRemoveItem) {
        itemCount--;
        items[locatedIndex] = items[itemCount];
    } // end if
    return canRemoveItem;
} // end remove
```

> **Programming Tip:** Should the method getIndexOf be public or private?
You might think that the method getIndexOf, since it returns the index of an entry in the array items, would be useful to a client. While that might be true, there are important reasons why the method should be private. We declared the array private because it is detail of our array-based implementation. The client cannot access the entries in the array without invoking a public method of our class. The indices of these entries are also implementation details that are of no use to the client because it cannot access the array by name. Any method that returns an index to a private array should be declared private.

**The method clear.** The method clear can make a bag empty simply by setting itemCount to zero. Thus we have the following definition for this method:

```
template<class ItemType>
void ArrayBag<ItemType>::clear()
{
    itemCount = 0;
} // end clear
```
