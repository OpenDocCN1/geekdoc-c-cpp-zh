Now suppose you have all implementations of ListInterface, as given in Listing 8-1 of Chapter 8, to provide the overload of the operator==. You would need to add the declaration
virtual bool operator==(const List<ItemType>&rightHandSide) const = 0;

to the ListInterface. Each implementation of ListInterface would provide a definition of==, allowing you to compare any two ListInterface objects. The challenge of this comparison is that only ListInterface methods can be used for the list on the right-hand side, affecting the efficiency of the equality when comparing lists having two different implementations. For example, if we had an array-based list that we wished to convert to a linked list, we could not take advantage of the node structure of the underlying linked chain when we accessed the entries. We would need to use getEntry to access entries, but each call to getEntry would iterate through the list until it reaches the desired entry. implementation of other relational operators is completed in a similar way.

# 5.1.1 Overloading = for Assignment

Overloading the assignment operator = is similar to overloading the equality operator, but it presents additional concerns. Once again, suppose that myList and yourList are instances of Linkedlist. If you place several items in your list and then write

+   * myList = yourList;

you would expect myList to be an exact copy of your list. Without an overloaded assignment operator, however, you would get a shallow copy of your list as shown in Figure 4-8 in Chapter 4 illustrates. Although a shallow copy might be sufficient for statically allocated structure, a deep copy is necessary for a dynamically allocated one like the chain of linked nodes in the linked-based implementation Linkedlist. A shallow copy of a LinkedList object—yourList—would only copy the data members itemCount (the length of the list) and headPtr (the pointer to yourList's first item). The items in the list would not be copied.

To provide an assignment operator for the class LinkedList, you would add the declaration
LinkedList<ItemType>& operator=(const LinkedList<ItemType>&rightHandSide);
