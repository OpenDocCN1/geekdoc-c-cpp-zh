### Facts about full binary trees

- A full binary tree of height $h \ge 0$ has $2^h-1$ nodes.
- You cannot add nodes to a full binary tree without increasing its height.
- The maximum number of nodes that a binary tree of height $h$ can be $2^h-1$.

We can determine the minimum height of an $n$-node binary tree.

**Note:** The minimum height of a binary tree with $n$ nodes is $\lceil\log_2(n+1)\rceil$.

To prove the previous fact, let $h$ be the smallest integer such that $n \le 2^h-1$ and establish the following assertions:

1. *A binary tree whose height is $\le h-1$ has $< n$ nodes.*

We know that a binary tree of height $h-1$ has at most $2^{h-1}-1$ nodes. If it is possible that $n \le 2^{h-1}-1$, then $h$ is not the smallest integer such that $n \le 2^h-1$. Therefore, $n$ must be greater than $2^{h-1}-1 < n$. Because a binary tree of height $h-1$ has at most $2^{h-1}-1$ nodes, it must have fewer than $n$ nodes.

2. *An $n$-node complete binary tree whose height $h$ exists.*

Consider a full binary tree of height $h-1$. It has $2^{h-1}-1$ nodes. As you just saw, $n > 2^{h-1}-1$ because $h$ was selected so that $n \le 2^h-1$. You can then add nodes to the full tree from left to right until you have $n$ nodes, as Figure 15-10 illustrates.

¹ The ceiling of $x$, which $\lceil x\rceil$ denotes, is rounded up. For example, $\lceil 6\rceil=6, \lceil 7\rceil=7$, and $\lceil 6.8\rceil=7$.

Because $n \le 2^h - 1$ and a binary tree of height $h$ cannot have more than $2^h - 1$ nodes, you will reach $n$ nodes by the time level $h$ is filled up.

3. The *minimum height* of a binary tree with $n$ nodes is the smallest integer $h$ such that $n \le 2^h - 1$.

If $h$ is the smallest integer such that $n \le 2^h - 1$, and a binary tree has height $h-1$, then by factor 1 it has fewer than $n$ nodes. By factor 2 there is a binary tree of height $h$ that has exactly $n$ nodes, $h$ must be as small as possible.

The previous discussion implies that

$2^{h-1}-1 < n \le 2^h-1$

so the minimum height of a binary tree with $n$ nodes is the smallest integer $h$ such that $n \le 2^h - 1$.

## 15.2 The ADT Binary Tree

As an abstract data type, a binary tree has operations to add, delete, search, and retrieve nodes. The traversal of a binary tree involves visiting each node once.

### 15.2.1 Traversals

The traversal of a binary tree means visiting each node in some order. There are several common orders of traversal: preorder, inorder, and postorder.

The preorder traversal visits the root first, then the left subtree, and finally the right subtree. The recursive preorder algorithm is as follows:

```
preorder(node t)
  if t is not null
    visit(t)
    preorder(t.left)
    preorder(t.right)
```

The inorder traversal visits the left subtree, then the root, and finally the right subtree. The recursive inorder algorithm is as follows:

```
inorder(node t)
  if t is not null
    inorder(t.left)
    visit(t)
    inorder(t.right)
```

The postorder traversal visits the left subtree, then the right subtree, and finally the root. The recursive postorder algorithm is as follows:

```
postorder(node t)
  if t is not null
    postorder(t.left)
    postorder(t.right)
    visit(t)
```

The traversal of a binary tree means visiting each node in some order. For example, if the binary tree represents an algebraic expression, the preorder traversal yields the prefix notation, the inorder traversal yields the infix notation, and the postorder traversal yields the postfix notation.
