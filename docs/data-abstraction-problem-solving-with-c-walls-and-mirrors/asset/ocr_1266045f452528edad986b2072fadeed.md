# 2.6.2 Organizing a Parade

You have been asked to organize the Fourth of July parade, which will consist of bands and floats in a single line. Last year, adjacent bands tried to outlay each other. To avoid this problem, the sponsors have asked you to never place one band immediately after another. In how many ways can you organize a parade of length n?

Assume that you have at least marching bands and n floats from which to choose. When the number of ways to organize the parade, assume that the parade-float and float-band, for example, are different parades and count as two.

The parade can end with either a float or a band. The number of ways to organize the parade is simply sum the number of ways of parades of each type. That is,

```
P(n) = the number of ways to organize a parade of length n
F(n) = the number of parades of length n that end with a float
B(n) = the number of parades of length n that ends with a band
```

Then

```
P(n) = F(n) + B(n)
```

First, consider F(n). If you have a length of n ends with a float by placing a float at the end of any acceptable parade of length n-1. Hence, the number of acceptable parades of length n that ends with a float is precisely equal to the total number of acceptable parades of length n-1; that is,

```
F(n) = P(n - 1)
```

Next, consider B(n). The only way to have an end with a band is if the unit is just before the float (if it is, you will have two adjacent bands). The only way to organize an acceptable parade of length n that ends with a band is to organize a parade of length n-1 that ends with floats and then add a band to the end. Therefore, the number of acceptable parades of length n that ends with a band is precisely equal to the number of acceptable parades of length n-1 that ends with a float:

```
B(n) = F(n - 1)
```

You use the factor that F(n) = P(n - 1) to obtain

```
B(n) = P(n - 2)
```

Thus, you have F(n) and B(n) in terms of the smaller problems P(n-1) and P(n-2), respectively. You then obtain

```
P(n) = F(n) + B(n)
```

to obtain

```
P(n) = P(n - 1) + P(n - 2)
```

The form of this recurrence relation is identical to the solution for the multiplying rabbits problem.
