## A.1.3 Fundamental Data Types

The fundamental types in C++ are organized into four categories: boolean, character, integer, and floating point. Boolean, character, and integer are called **integral types**. Integral and floating-point types are called **arithmetic types**.

Most of the types are available in several forms and sizes. The size of a data type affects the range of its values. For example, a long can have a larger magnitude than a short. The sizes of—and the specific ranges for—a type depend on the particular computer and version of C++ that you use. C++, however, provides a way to determine these ranges, as you will see later. Although you will not need more than the four given previously, Figure A-2 lists the fundamental types.

A boolean value can be either true or false. Characters are represented by ASCII value. Integer values are either signed, such as -5, or unsigned. **Floating-point types** are used for numbers that have both an integer and fractional part.

## A.1.4 Variables

A variable, whose is a C++ identifier, represents a memory location that contains a value of a particular data type. You declare a variable's data type by preceding the variable name with the data type, as

```cpp
double radius; // Radius of a sphere
```

Note that you can write a comment on the line to describe the purpose of the variable. The memory, however, has no initial value and is said to be uninitialized. In Figure A-1 declares radius without an initial value and later reads its value using cin >> radius;

When, you should avoid uninitialized variables. That is, you should initialize a variable when you first declare its data type or, declare a variable's data type when you first assign it a value. For example, volume appears in the first line of 10 of Figure A-1 in the statement

```cpp
double volume = 4 * PI * radius * radius * radius / 3; own```

Because we did not declare volume's data type in the program—avoiding an uninitialized variable—we declare its data type and assign it in the same statement.
