# An Array-Based Implementation of the ADT List

The method remove. Now consider to remove an entry from a list. You could blank it out, but this strategy can lead to gaps in the array, as Figure 9-3a illustrates. An array that is full of gaps has three significant problems:

+   - itemCount — is no longer the index of the last entry in the array. You need another variable, lastPosition, to contain this.
- Because the entries are erased out, the method getEntry might have to look at every cell of the array even when only a few entries are present.
- When items[maxItems - 1] is occupied, the list could appear full, even when fewer than maxItems entries are present.

Thus, you will really need to shift entries in the array so that a deletion does not leave a gap, as shown in Figure 9-3b. This data movement is the one done by the method insert, but it occurs in the opposite direction.

The definition of class follows:

```
template<class ItemType>
bool ArrayList<ItemType>::remove(int position)
{
    bool ableToRemove = (position >= 1) && (position <= itemCount);
    if (ableToRemove)
        // remove shifting all entries after the one at
        // position toward the beginning of the array
        // (no shift if position == itemCount)
        for (int from = position; to = itemCount - 1; from < itemCount; from++, to++)
            items[to] = items[from];
    }
    itemCount--; // Decrease count of entries
    return ableToRemove;
} // end remove
```
