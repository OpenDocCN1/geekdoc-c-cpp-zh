Choose a pivot value p from anArray[first..last]
Partition the items of array[first..last] about p

Recall that this partition, which is pictured again in Figure 11-9, has the property that all items in $S_l=$ theArray[first..pivotIndex] are less or equal to the pivot $p$, and all items in $S_r=$ theArray[pivotIndex + 1..last] are greater than or equal to $p$. This property does not imply that the array is sorted, it does an extremely fast fact: the ingredients of a recursive problem remain within $S_l$, when the array is properly sorted, their positions relative to one another may change. Similarly, the items within $S_r$, will remain within $S_r$ when the array is sorted, their relative positions change. Finally, the pivot items will remain in their position, relative to the sorted array.

The quick sort partitions an array into items that are less than or equal to the pivot and that are greater than or equal to the pivot

The partition reduces increases among the items that the array generates two smaller problems—sort the left section of the array ($S_l$), and the right section of the array ($S_r$). The relationships between the pivot and the items imply that once you solve the left and right sorting problems, you will have solved the original problem. That is, partitioning the array before the recursive calls places the pivot in its correct position and ensures that the smaller array segments are sorted their items will be in the proper relation to the rest of the array. pivot is not part of either $S_l$ or $S_r$.

Partitioning places the pivot in its correct position within the array

A first draft of pseudocode for the quick sort algorithm follows:

```
// Sorts(Array[first..last])
quickSort(theArray, first: integer, last: integer): void
if (first < last)
  Choose a pivot item p from theArray[first..last]
  Partition the items of theArray[first..last] about p
  // The partition of theArray[first..last]
  quickSort(theArray, first, pivotIndex - 1) // Sort S_l
  quickSort(theArray, pivotIndex + 1, last) // Sort S_r
if first >= last, then there is nothing to do
```
