# # SUMMARY

+   1. You can implement a stack using an array. If the bottom of the stack is the first element of the array, no stack entries are moved when you add or remove entries.
2. You can implement a stack using a chain of linked nodes that has a head pointer. The first node of the chain should contain the top of the stack to provide the easiest and fastest addition and removal operations.
3. You should assert or throw an exception to enforce the precondition for the method peek.

# # EXERCISES

+   1. Discuss the advantages and disadvantages of an array-based stack implementation of the ADT stack as compared to a link-based implementation.
2. Consider the ADT bag, as described in Chapters 1, 3, and 4.
   a. Would you be able to implement the ADT stack using a bag to contain its entries? Why or why not?
   b. Would you be able to implement the ADT bag using a stack to contain its entries? Why or why not?
3. An operation that displays the contents of a stack could be useful during program debugging. Add a display method to the ADT such that
   a. The method uses only stack operations; that is, it is independent of the stack's implementation.
   b. The method uses and the link-based implementation of the ADT stack.
   c. The method uses the array-based implementation of the ADT stack.
4. Repeat the previous exercise, but define a method vector remove(n) that removes and discards the topmost n entries from a stack. Write a link-based implementation for this method.
5. To the ADT stack given in this chapter, add a method vector remove(n) for this method.
6. Repeat the previous exercise, but write an array-based implementation instead.
7. The destructor for the link-based implementation of the ADT stack calls pop. Although easy to write, this destructor can be inefficient due to repeated calls. Write another implementation for the destructor that deallocates the linked nodes without calling pop.
8. Implement a safe copy constructor for the stack. If a memory allocation fails, this constructor should release all memory that was allocated prior to the failure and throw an exception.
9. Imagine an array-based implementation of the ADT stack that stores its entries beginning at the end of an array. Describe how you could define the stack operations so that the push and pop operations do not require you to move existing entries in the array.
10. Imagine a link-based implementation of the ADT stack that stores the stack's top at the end of a chain of linked nodes. Describe how you can define the stack operations so that a traversal of the chain is not necessary.
11. Although we do not usually throw our exception when a method or constructor in LinkedStack fails to allocate a new node, do so. Define the MemoryAllocationException, and revise the constructor of LinkedStack so that it throws a MemoryAllocationException when the new operator fails to allocate memory. Throwing exceptions from constructors requires great care, so you must be sure to deallocate any memory allocated by the constructor before throwing the exception.
