# 4.3 Using Recursion in Link-Based Implementations

It is possible, and sometimes desirable, to process linked chains recursively. This section examines how to write the iterative methods given previously as recursive ones. Such recursive methods require the head pointer as an argument. Therefore, they should not be public, because the head pointer is a private data member of the class and the client does—not have access to it. Otherwise, clients could access the linked nodes directly, violating the ADT's safety.
