Graphs are an important mathematical concept with significant applications not only in computer science, but also in many other fields. A mathematical construct, a data structure, or an abstract data type. This chapter provides an introduction to graphs that allows you to view a graph in any of these three ways. It also presents the major operations and applications of graphs that are relevant to the computer scientist.
