# 6.2 Simple Uses of a Brace

Once you have satisfactorily specified the behavior of an ADT, you can design applications that access and manipulate the ADT's data in terms of its operations and without regard for its implementation. Thus, we can use the operations of the ADT stack even though we have not discussed their implementations yet. This section presents two simpler examples for which the LIFO property of stacks is appropriate.

### 6.2.1 Checking for Balanced Braces

C++ uses curly braces, ‘{' and '}', to delimit groups of statements. For example, braces begin and end a method's body. If you want to verify a C++ program as a string of characters, you can use a stack to verify that a program contains balanced braces. For the braces in the string

```
abc(defgij]{k{1}op)qr
```

are balanced, with the braces in the string

```
abc(def){ghij}k1m
```

are not located. When you check whether a string contains balanced braces by traversing it from left to right. As you move from left to right, you match successive close brace "}" with the most recently encountered unmatched brace "{"; that is, the "}" must be to the left of the current "}". The braces are balanced if:

- 1. Each time you encounter a "}", it matches an already encountered "{".
- 2. When you reach the end of the string, you have matched each "{".

The solution requires you to keep track of each unmatched "{" and discard one each time you encounter a "}". One way to perform this is to push "{" onto a stack and pop one each time you encounter a "}". Thus, a first-draft pseudocode is:

```cpp
if (each character in the string)
{
  if (the character is '{')
    aStack.push('{');
  else if (the character is '}')
    aStack.pop()
}
```

Initial draft of a solution

Although this logic correctly tracks the braces, missing from it are the checks that conditions 1 and 2 are met—that is, the braces are indeed balanced. To verify condition 1 when a "}" is encountered, you must check to see whether the stack is empty before popping from it. If it is empty,

you terminate the loop and report that the string is not balanced. To verify condition 2, you check that the stack is empty when the end of the string is reached.

Thus, the pseudocode solution to check for balanced braces in a aString becomes:

```cpp
// Check the aString to verify that braces match.
// Returns true if aString contains matching braces, false otherwise.
checkBraces(aString: string): boolean
astaStack = a new empty stack
balancedSoFar = true
i = 0
while (balancedSoFar and i < length of aString)
{
    ch = character at position i in aString
    i++
    // Push an open brace
    if (ch is '(')
        stack.push('(')
    // Close brace
    else if (ch is ')')
    {
        if (!stack.isEmpty())
            stack.pop() // Pop matching open brace
        else
            // No matching open brace
            balancedSoFar = false
    }
    // Ignore all characters other than braces
}
if (balancedSoFar and stack.isEmpty())
    aString has balanced braces
else
    aString does not have balanced braces
```

> Note: In both of the preceding examples, notice how you can focus on the task at hand without the distraction of implementation details such as arrays. With less to worry, you are less likely to recognize an error in your logic when you use the ADT's operations. Likewise, when you finally implement the ADT's operations in C++, you will not be distracted by these applications. These results assume that you do not change the specifications of the ADT's operations when you implement them. However, developing software is not a linear process. 6.2.2 Recognizing Strings

Consider the problem of whether a string is a palindrome. A palindrome is a string that reads the same forwards and backwards. To determine if a string is a palindrome, you can use a stack to push the characters of the first half of the string onto the stack, and then traverse the second half of the string, popping each character from the stack and comparing it with the character in the second half. If all characters match, the string is a palindrome.

```cpp
// Checks the aString to verify that it is a palindrome.
// Returns true if aString is a palindrome, false otherwise.
isPalindrome(aString: string): boolean
astaStack = a new empty stack
i = 0
n = length of aString
while (i < n / 2)
{
    astaStack.push(character at position i in aString)
    i++
}
// start at the second half
if (n % 2 != 0)
{
    i++ // skip the middle character if length is odd
}
while (i < n)
{
    if (character at position i in aString != astaStack.pop())
        return false
    i++
}
return true
```

The reversed version of a string can be obtained by pushing all the characters of the string onto a stack and then popping them off. This is a simple use of a stack.

```cpp
// Uses stack to reverse a string.
reverseString(aString: string): string
astaStack = a new empty stack
for (each character in aString)
{
    astaStack.push(character)
}
reversedString = ""
while (!astaStack.isEmpty())
{
    reversedString = reversedString + astaStack.pop()
}
return reversedString
```

Exercise 8: Use a stack to find the matching parentheses in a string.

```cpp
// Uses a stack to find matching parentheses in a string.
// Returns true if all parentheses are matched, false otherwise.
checkParentheses(aString: string): boolean
astaStack = a new empty stack
for (each character in aString)
{
    if (character is '(')
        astaStack.push('(')
    else if (character is ')')
    {
        if (!astaStack.isEmpty())
            astaStack.pop()
        else
            return false
    }
}
return astaStack.isEmpty()
```

```cpp
// Uses a stack to evaluate expressions in postfix notation.
// Returns the result of the expression.
evaluatePostfix(aExpression: string): number
astaStack = a new empty stack
for (each character in aExpression)
{
    if (character is a digit)
        astaStack.push(number(character))
    else
    {
        val2 = astaStack.pop()
        val1 = astaStack.pop()
        if (character is '+')
            astaStack.push(val1 + val2)
        else if (character is '-')
            astaStack.push(val1 - val2)
        else if (character is '*')
            astaStack.push(val1 * val2)
        else if (character is '/')
            astaStack.push(val1 / val2)
    }
}
return astaStack.pop()
```
