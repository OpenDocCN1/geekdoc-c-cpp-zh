
## 286 CHAPTER 9 List Implementations

## SUMMARY

- 1. Using an array results in a straightforward implementation of the ADT list, but it is somewhat more involved than the implementations of either the ADT bag or the ADT stack.
- 2. An array provides direct access to any of its elements, so a method such as getEntry can quickly retrieve any entry in a list.
- 3. Adding an entry or removing an entry from an array-based list typically requires other entries to shift one position within the array. This data movement degrades the efficiency of these operations, particularly when the list is long and on the position of the addition or removal is near the beginning of the list.
- 4. Inserting or removing entries from a link-based implementation of the ADT list does not require data to shift. Thus, the methods insert and remove essentially the same effort—regardless of the length of the list or the position of the operation within the list—once the point of insertion or removal is found. Finding this point, requires a traversal, the time for which will vary depending on where the list operation occurs.
- 5. For a link-based implementation of the ADT list, adding to the beginning of the list and removing a list's first entry are treated as special cases.
- 6. Adding or removing an entry at the end of a link-based list requires a traversal of the underlying chain.
- 7. Adding or removing any entry within a link-based list requires a change of at two pointers within the underlying chain.
- 8. The array-based getEntry method is almost instantaneous regardless of which list item you access. A link-based getEntry, however, requires i steps to access the ith item in the list.

### 10.1 What Is a Good Solution?
In this chapter, we will show what constitutes a good solution. When evaluating a solution, you must consider the following criteria:

- A solution is good if the cost over all its life is minimal.

Suppose two algorithms perform the same task, the faster one is not necessarily better. This is because the cost of a solution includes the time of the people who develop, maintain, and use the program.
