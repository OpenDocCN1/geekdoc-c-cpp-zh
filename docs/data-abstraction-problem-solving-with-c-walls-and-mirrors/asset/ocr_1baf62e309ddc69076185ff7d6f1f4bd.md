+   * Chapters 15 through 17: Before we begin the next chapter, C++  5 introduces overloaded operators and friend access. * Chapter 20: Next, this last chapter considers data storage in external access files. Merge sort is modified to sort such data, and external hashing and B-tree indexes are used to search. Searching algorithms are generalizations of the internal hashing schemes and 2-3 trees already developed. Finally, C++ ends the main presentation by discussing the containers and algorithms available in the C++ Template Library (STL).
