realCube was not defined. C++ requires that each function, constant, variable, or class be defined before it can be called.

In a simple program with a few functions, it is easy to define the functions in the reverse of the order in which they are needed so the compiler sees each function definition before it is needed. In more complex programs, this is more difficult or even impossible to achieve.

The part of a function definition that the compiler needs is the header of the function and C++ provides a mechanism that allows the programmer to provide the compiler the function's header separate from the actual definition of the function. This mechanism is the **prototype** and consists of the function's header followed by a semicolon. For example, the prototype of the function realCube is

```
double realCube(double x);
```

To eliminate the chance that a function will be needed prior to its definition within a C++ file, a common practice is to list the functions' prototypes at the beginning of the file. In larger programs, function prototypes are placed in header files, as described in Section K.1. You then include the header files in your program. Prototypes are also important in the creation of classes, as you will see in the next section.

Note that you can pass a function as an argument to another function or method. This is discussed in Section 15.2.1 of Chapter 15.
