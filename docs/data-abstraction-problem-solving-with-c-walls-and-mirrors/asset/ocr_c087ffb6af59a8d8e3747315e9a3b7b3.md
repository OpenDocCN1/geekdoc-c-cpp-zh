Finding an Euler circuit is like drawing each of the diagrams in Figure 20 without lifting your pencil or redrawing a line, and ending at your starting point. No solution is possible for-Figure 20-28a, but you should be able to find one easily for Figure 20-28b. Figure 20-29 contains undirected graphs based on Figure 20-28. In Figure 20-29a, h and j each touch an odd number of edges (three), so no Euler circuit is possible. On the other hand, each vertex in Figure 20-29b touches an even number of edges, making an Euler circuit feasible. Notice that the graphs are connected. If a graph is not connected, a path through all of the vertices would not be possible.

Let's find an Euler circuit for the graph in Figure 20-29b, starting arbitrarily at vertex a. The strat-depth search that marks edges instead of vertices as they traverse. Recalled that depth-first search traverses a path from a as deeply as the graph possible. By marking edges instead of vertices, you will return to the starting vertex; that you find a cycle. In this case the cycle is a, b, c, d, a if we visit the vertices in alphabetical order, as Figure 20-30 shows. This is not the desired circuit, because we have not visited every edge. We are not finished however,

To continue, find the first vertex along the cycle a, b, c, d, a that touches an unvisited edge. In our-desired vertex is e, f, j, i, e. Apply our modified depth-first search, beginning with this vertex. The resulting cycle is e, f, j, i, e. Now you join this cycle with the one you found previously. That when you reach e in the first cycle, you travel along the second cycle before continuing in the first cycle. The resulting path is a, b, c, d, e, f, j, i, e, d, c, g, h, a.

The first vertex along the new cycle that touches an unvisited edge is i. Beginning at i, our algorithm determines the cycle i, h, d, c, g, k, l, i. Joining this with our combined circuit results in the Euler circuit, a, b, c, d, e, f, j, i, h, d, c, g, h, l, i, e, a. (See Figure 20-30c.)
