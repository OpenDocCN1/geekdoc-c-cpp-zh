# A.8.4 Inheritance

A class derived from the class Sphere

A brief description of inheritance is provided here, because it is a common way to create new classes in C++. Further discussions of inheritance occur throughout the book.
Suppose we want to give our spheres a class, knowing that we have already developed the class Sphere. Instead of writing an entirely new class of spheres that have a color, we can reuse the Sphere implementation and add color characteristics and operations using inheritance. Here is a declaration of the class SphereColor that uses inheritance:

```
#include "Sphere.h"
enum Color {RED, BLUE, GREEN, YELLOW};
class SphereColor : public Sphere
{
    private:
        Color sphereColor;

public:
        SphereColor(Color initialColor);
        SphereColor(Color initialColor, double initialRadius);
        void setColor(Color color);
        Color getColor() const;
}; // end SphereColor
```

The class Sphere is the base class or superclass, and SphereColor is called the derived class or subclass of the base class.
Any instance of the derived class is also considered to be an instance of the base class and can be used in a program anywhere that an instance of the base class can be used. Also, when the keyword precedes the name of the base class in the new class's header, any of the publicly defined methods or data members can be used with instances of the base class. The derived class also has the additional methods and data members that are publicly defined in the derived class definition.

The implementation of the methods for the class SphereColor is as follows:

```
SphereColor::SphereColor(Color initialColor) : Sphere()
{
    sphereColor = initialColor;
} // end constructor
```

```
SphereColor::SphereColor(Color initialColor, double initialRadius)
    : Sphere(initialRadius)
{
    sphereColor = initialColor;
} // end constructor
```
