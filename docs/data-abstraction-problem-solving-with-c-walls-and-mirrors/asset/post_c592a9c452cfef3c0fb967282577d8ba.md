
# 522 CHAPTER 17 Heaps

## SUMMARY

- 1. Since a heap is a complete binary tree, it has an efficient array-based implementation.
- 2. The root of a maxheap contains the heap's largest value. The root of a minheap contains the heap's smallest value.
- 3. To remove the value in the root of a heap, you first replace the value with the value in the last node of the heap. This step likely results in a minheap. After deleting the node, you convert the minheap to a maxheap by a trickle-down step.
- 4. To add an item to a heap, you insert a new leaf into the heap so that it remains a complete binary tree. You then use a trickle-up step to position the new node.
- 5. A heap that uses an array-based representation of a complete binary tree is a good implementation of a priority queue when you know the maximum number of items that will be stored at any one time.
- 6. Heap sort converts an array into a heap to locate the array's largest item. This enables the heap sort to sort an array in an efficient manner.
- 7. Heap sort, like merge sort, has good worst-case and average-case behaviors, neither algorithm is as good in the average case as quick sort. Heap sort has an advantage over merge sort in that it does not require a second array.

This chapter considers the ADT dictionary, which is appropriate for problems that manage value. ## 18.1 The ADT Dictionary

![](img/d0cb86b2f18b2db569968ad7c743510e_552_0.png)

When we begin our discussion of sorting in Chapter 11, we introduced the notion of a sort key. For example, you might want to sort a collection of data about people based on their names, their ages, or zip codes. The criterion you choose is the sort key. Similarly, you might want to search the same collection of data for a name, an address, or a phone number. The criterion you choose for this is known as a search key.

Applications that require value-oriented operations are extremely prevalent, as you imagine values instead of positions.

- Find the number of John Smith
- Delete all the information about the employee with ID 1290

We first encountered a value-oriented ADT, the sorted list, in Chapter 12. Chapter 15 presented the binary search tree, which is also a value-oriented ADT. This section describes another value-oriented ADT, the dictionary.
