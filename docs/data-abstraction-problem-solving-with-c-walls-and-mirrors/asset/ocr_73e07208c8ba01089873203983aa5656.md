Because nextCity is the primary operation that the search algorithm performs on the flight map, you should choose an implementation that efficiently determine which cities are adjacent to a given city. If there are n cities numbered 1, 2,...,n you can use chains of linked nodes to represent the flight map. You place a node on i for j and only if there is a directed path from city i to city j. Such a data structure is called an adjacency list; Figure 6-14 illustrates the adjacency list for the flight map in Figure 6-6.
