# 16.6 General Trees

This chapter ends with a brief discussion of general trees and their relationship to binary trees. Con-
sider the general tree in Figure 16-18. The three children B, C, and D of node A, for example, are sib-
lings. The leftmost B is the oldest, or first child, of A, as mentioned in Section 15.1 of
Chapter 15. One to implement this uses the Binaryobject that we used for a link-based
binary tree. That, each node has two pointers: the left pointer points to the node's oldest child and
the right pointer points to the node's sibling. Thus you can use the data structure in Figure 16-19a
to implement the tree in Figure 16-18. Notice that the structure in Figure 16-19a also represents the
binary tree pictured in Figure 16-19b.

Recall from 15-4 that an n-ary tree is a generalization of a binary tree whose nodes
can have no more than n children. The tree in Figure 16-18 could be an n-ary tree with n=3 instead of
a general tree. You can, of course, use the implementation just described for an n-ary tree. However,
because you know the maximum of children for each node, you can let each node point
direct to its tree. Figure 16-20 illustrates such a representation for the tree in Figure 16-18. This
tree is shorter than the tree in Figure 16-19b.
