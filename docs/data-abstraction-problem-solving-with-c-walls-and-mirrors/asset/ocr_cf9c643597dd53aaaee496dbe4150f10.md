Iterative BFS traversal algorithm uses a queue

```
// Traverses a graph beginning at vertex v by using a
// breadth-first search: Iterative version.
bfs(v: Vertex)
q = a new empty queue
// Add v to queue and mark it
.enqueue(v)
Mark v as visited
while (q.isEmpty()) {
    w = q.dequeue())
    // Loop invariant: there is a path from vertex w to every vertex in the queue
    for (each unvisited vertex u adjacent to w) {
        Mark u as visited
        q.enqueue(u)
    }
}
```

Figure 20-13 shows the contents of the queue as bfs visits the graph in Figure 20-11, beginning at vertex a. In general, a breadth-first search will visit the same vertices as a depth-first search, but in a different order. The BFS traversal visits all of the vertices in this order: $a, b, f, i, c, c, e, g, d, h$.

A recursive version of BFS traversal is not as simple as the recursive version of DFS traversal. Exercise 19 at the end of this chapter asks you to think about why this is so.
