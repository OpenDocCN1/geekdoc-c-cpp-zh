The emperor was obviously not a recursive thinker, but you should realize that you can solve the monk's solution by solving three times the number of disks—Towers. Let us count (count, source, destination, spare) define the problem of moving disks from pole source to destination using pole as spare. Notice that this method makes sense if there are more than count disks on pole source; in this case, concern yourself with only the top disks and ignore the others. Similarly, the destination and source have disks on them before you move them; ignore these too, except that you may place only smaller disks on top of them.
You can restate the emperor's problem as follows: Beginning with $n$ disks on pole A and zero disks on poles B and C, solve towers $(n, A, B, C)$. You can solve the monk's solution as follows:

**Step 1.** Starting in the initial state—with all the disks on pole A—solve the problem

towers $(n-1, A, C, B)
That is, ignore the bottom (largest) disk and move the top $n-1$ disks from pole A to pole C, using pole B as spare. When you are finished, the largest disk will remain on pole A, and all the other disks will be on pole C.

**Step 2.** Now, with the largest disk on pole A and all other disks on pole C, solve the problem

towers $(1, A, B, C)
That is, move the largest disk from pole A to pole B. This disk is larger than the disks already on pole C, you could not use the spare. However, fortunately—and obviously—you do not need to use the spare in this case. When you are done, the largest disk will be on pole B, and all other disks remain on pole C.

**Step 3.** Finally, with the largest disk on pole B and all the other disks on pole C, solve the problem

towers $(n-1, C, B, A)
That is, move the $n-1$ disks from pole C to pole B, using pole A as spare. Notice that the destination pole B already has the largest, which you ignore. When you are done, you will have solved the original problem: All the disks will be on pole B.
