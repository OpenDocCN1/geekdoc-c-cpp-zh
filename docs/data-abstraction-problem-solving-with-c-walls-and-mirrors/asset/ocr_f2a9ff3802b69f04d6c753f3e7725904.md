getNodeAt is a private method

The method getNodeAt is not an ADT operation, because it returns a pointer to a node; nodes are implementation detail, you would not want any client to call it. Such clients should be able to use the ADT without knowledge of the nodes that the implementation uses. It is perfectly reasonable for the implementation of an ADT to define variables and methods that the program should not access. You could think of the method getNodeAt as marked as "internal use only." Therefore, getNodeAt is a private method that implements some of the ADT's operations.

A copy constructor and a destructor are necessary for a linked-based implementation

Because we are declaring a linked-based implementation, we must provide a constructor and a destructor for its class. The declarations of the public methods are for the class Array.

# 9.2.2 The Implementation File

Overview of LinkedList

Our methods include the same as we defined for ArrayList—namely, the constructor and the methods insert, getEntry, isEmpty, and length. The latter two methods have the same body as their ArrayList versions, since they only access the data item field. However, as will become evident when we code the methods getEntry and the private method getNodeAt will be necessary.

The constructor. Because the compiler-generated default would not necessarily initialize headPtr and itemCount to values, you must provide your own default constructor. Initializers are set to the values of headPtr and itemCount, since we, not the client, choose these values. The constructor's definition follows:

```
template<class ItemType>
LinkedList<ItemType>::LinkedList() : headPtr(nullptr)
```

This is the constructor we will need.

The method getEntry. Like getEntry in ArrayList, we will have this method enforce its precondition by throwing an exception if position is out of bounds. Note the similarity of its definition to the array-based version we gave earlier in this chapter:

```
template<class ItemType>
LinkedList<ItemType>::getEntry(int position) const
    throw(PreconditionViolatedException)
{
    // Enforce precondition
bool alterToGet((position >= 1) && (position <= itemCount))
{
    Node<ItemType>* nodePtr = getNodeAt(position);
    return nodePtr->getItem();
}
else{
    string message = "getEntry() called with an empty list or ";
    message = message + " invalid position.";
    throw(PreconditionViolatedException(message));
}// end if
}
// end getEntry
```
