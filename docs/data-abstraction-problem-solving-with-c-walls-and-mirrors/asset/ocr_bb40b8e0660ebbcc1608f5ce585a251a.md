# 440 CHAPTER 15 Trees

```
clear()
```

Task: Removes all nodes from this binary tree.
Input: None.
Output: None. (The binary tree is empty.)

```
getEntry(anEntry)
```

Task: Gets a specific entry in this binary tree.
Input: anEntry is the desired item.
Output: The entry in the binary tree that matches anEntry . Throws an exception if the entry is not found.

```
contains(data)
```

Task: Tests whether the given item occurs in this binary tree.
Input: data is the data item.
Output: True if the binary tree contains the given item, or false if not.

```
preorderTraverse(visit)
```

Task: Traverses this binary tree in preorder and calls the function once for each node.
Input: visit is a client-defined function that performs an operation on or with the data node.
Output: None.

```
inorderTraverse(visit)
```

Task: Traverses this binary tree in inorder and calls the function once for each node.
Input: visit is a client-defined function that performs an operation on or with the data in each visited node.
Output: None.

```
postorderTraverse(visit)
```

Task: Traverses this binary tree in postorder and calls the function once for each node.
Input: visit is a client-defined function that performs an operation on or with the data in each visited node.
Output: None.
