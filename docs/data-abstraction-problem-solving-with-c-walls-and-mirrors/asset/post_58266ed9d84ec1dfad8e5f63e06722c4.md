bool Board::placeQueens(Queen* queenPtr)
{
    // Base case: Try to place a queen in a nonexistent column
    if (queenPtr->getCol() >= BOARD_SIZE)
    {
        delete queenPtr;
        return true;
    } // end if
    bool isQueenPlaced = false;
    while (!isQueenPlaced && queenPtr->getRow() < BOARD_SIZE)
    {
        // If the queen can be attacked, moving it
        // to the next row in the current column
        if (queenPtr->isUnderAttack())
        {
            queenPtr->nextRow();
        }
        else
        {
            // Put this queen on the board and try putting a
            // new queen in the first row of the current column
            setBoard(queenPtr);
            Queen* newQueen = new Queen(0, queenPtr->getCol() + 1);
            isQueenPlaced = placeQueens(newQueen);
        }
    }

    // If it wasn't possible to put the new queen in the next column,
    // backtrack by deleting the new queen and moving the last
    // queen placed down one row
    if (!isQueenPlaced) {
        delete newQueen;
        removeQueen();
        queenPtr->nextRow();
    } // end if
} // end if
} // while
    return isQueenPlaced;
} // end placeQueens

## 5.4 The Relationship Between Recursion and Mathematical Induction

A very strong relationship exists between recursion and mathematical induction. Recursion solves a problem by specifying a solution to one or more bases cases and demonstrating how to derive the solution to an arbitrary size from the solutions to smaller problems of the same type. Mathematical induction proves a property about the natural numbers by proving the appropriate base case—usually 0 or 1—and proving that the property must be true for any natural number $n$ if it is true for natural numbers smaller than $n$.

Given the similarities between recursion and mathematical induction, it is not surprising that induction is often employed to prove properties about recursive algorithms. What types of properties? You can, for example, prove that an algorithm actually performs the task that you intended. As an illustration, we will prove that the recursive algorithm of Chapter 2 does indeed compute the factorial of its argument. Another use of mathematical induction is to prove that a recursive algorithm performs a certain amount of work. For example, we will prove the solution to the Towers of Hanoi problem—also from Chapter 2—makes exactly $2^n-1$ moves when it starts with $n$ disks.

You can use induction to prove that a recursive algorithm either is correct or performs a certain amount of work.

### 5.4.1 The Correctness of the Recursive Factorial Function

The following pseudocode describes a recursive function that computes the factorial of a nonnegative integer $n$:

```text
fact(n: integer): integer {
    if (n is 0)
        return 1
    else
        return n * fact(n - 1)
}
```

You can prove that the fact function returns the values

factorial(0) = 0! = 1
factorial(n) = n! \times (n-1) \times (n-2) \times \dots \times 1$ if $n > 0$

The proof is by induction on $n$.

**Basis.** Show that the property is true for $n=0$. That is, show that fact(0) returns 1. But this result is simply the base case of the function: fact(0) returns 1 by its definition.

You now must establish that

property is true for an arbitrary k $\Rightarrow$ property is true for k + 1

**Inductive hypothesis.** Assume that the property is true for n = k. That is, assume that factorial(k) = $k \times (k - 1) \times (k - 2) \times ... \times 1$

**Inductive conclusion.** Show that the property is true for n = k + 1. That is, you must show that factorial(k+1) = $(k+1) \times k \times (k-1) \times ... \times 1$.

By definition of the function,

factorial(k+1) = $(k+1) \times factorial(k)

By the inductive hypothesis,

factorial(k+1) = $(k+1) \times k!$

= $(k+1)!$

which is what you needed to show to establish

property is true for an arbitrary k $\Rightarrow$ property is true for k + 1

The inductive proof is complete.

### 5.4.2 The Cost of Towers of Hanoi

In Chapter 2, you saw the following:

```
moves(1) = 1
moves(N) = 2 × moves(N-1) + 1    if N > 1
```

Thus, you have a recurrence relation for the number of moves required for N disks:

```
moves(1) = 1
moves(N) = 2 × moves(N-1) + 1    if N > 1
```

```
moves(3) = 2 × moves(2) + 1
= 2 × (2 × moves(1) + 1)
= 2 × (2 × 1 + 1) + 1
= 7
```

The solution to the previous relation is:
