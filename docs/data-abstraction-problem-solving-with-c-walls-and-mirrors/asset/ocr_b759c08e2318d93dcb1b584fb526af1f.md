# 588 CHAPTER 19 Balanced Search Trees

Split 4-nodes as they are encountered reaching a leaf, the insertion algorithm for a 2-3-4 tree splits 4-nodes as soon as it encounters them on the way down the tree from the root to a leaf. As result, when a 4-node is split and an item is moved up to the node's parent, the parent cannot possibly be a 4-node, so it can accommodate another item.

As an example of the algorithm, consider the tree in Figure 19-22a. This one-node tree is the result of inserting 60, 30, and 10 into an initially empty 2-3-4 tree. We will now insert more data into this tree.

**Insert 20.** While determining the insertion point, you begin at the root and encounter the 4-node <10 60>, you split by moving the middle value 30 up. Because the node is the root, you create a new node, move 30 into it, and attach two children, as Figure 19-22b illustrates. You then search for 20 by examining the left subtree of the root, because 20 is less than 30. The insertion results in the tree in Figure 19-22c.
