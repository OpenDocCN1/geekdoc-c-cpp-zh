Now consider a problem that is slightly more difficult: Given a string of characters, write it in reverse order. For example, write the string "cat" as "tac". To construct a recursive solution, you should ask the four questions in the Note at the end of Section 2.

You can construct a solution to the problem of writing a string of length $n$ in terms of the problem of writing a string of length $n-1$. That is, each recursive step of the solution diminishes by the length of the string to be written backward. The solution to this problem is to do nothing—a very straightforward solution indeed! (Alternatively, you could use the string of length 1 as the base case.)

Exactly how can you use the solution to the problem of writing a string of length $n-1$ to solve the problem of writing a string of length $n$ backward? This approach is analogous to the one used to construct the solution to the factorial problem, where you specified how to use $factorial(n-1)$ in the computation of $factorial(n)$. Unlike the factorial problem, the string problem does not immediately clear a way to proceed. Unless any string of length $n-1$ will do. For example, there is no relation between the string "apple" (of length 5) and writing "pear" (a string of length 4). You must choose the smaller carefully so that you can use its solution to the original problem.

How can you write an $n$-character string backward, if you can write an $(n-1)$-character string?

The string of length $n-1$ that you must choose be a substring (part) of the original string. Suppose that you write one character from the original string, leaving a substring of length $n-1$. For the recursive solution to be valid, the ability to write the string backward, combined with the ability to perform some minor task, must result in the ability to write the original string. Compare this approach with the way you computed factorial recursively: The ability to compute $factorial(n-1)$, combined with the ability to multiply this value by $n$, resulted in the ability to compute $factorial(n)$.
