- 21. Consider the problem of finding the greatest common divisor (gcd) of two positive integers $a$ and $b$. The algorithm presented here is a version of Euclid’s algorithm, which is based on the following:
**Theorem.** If $a$ and $b$ are positive integers with $a > b$ then $gcd(a, b) = gcd(b, a \bmod b)$.

This relationship between $gcd(a, b)$ and $gcd(b, a \bmod b)$ is the heart of the recursive solution. It specifies how you can solve the problem of computing $gcd(a, b)$ in terms of another problem of the same type. Also, if $b$ divides $a$, then $b = gcd(a, b)$, so appropriate choice for the base case is $(a \bmod b) = 0$.
