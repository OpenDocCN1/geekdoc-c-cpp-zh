As Figure 9-7 indicates, you can remove the node N to which `curPtr` points by altering the value of the pointer that precedes N. You need to set this pointer so that it points to the node that follows N, bypassing N on the chain. (The dashed line indicates the old pointer value) Notice this pointer change does not directly affect node N. N remains in existence, and it is the same node that it pointed to before. For example, a traversal of the chain would reach node N.

To accomplish this pointer change, notice that if you had only the curPtr pointing to N, you would have no direct way to access the node that precedes N. After all, you cannot follow the links in the chain backward. Thus, you must have the variable `prevPtr` in Figure 9-7. It points to the node that precedes N on the chain and makes it possible for you to alter that node's next pointer, thereby removing node N from the chain. The following assignment is all that you need to remove the node to which curPtr points:

Removing an interior node

```
prevPtr->setNext(curPtr->getNext());
```

Does the previous technique work for any node N, regardless of where in the linked chain it appears? No, it does not work if the node to be deleted is the first node in the chain, but it does work for the last node in the chain. Thus, deletion of the first node in a chain is a special case. Since we already know how to delete the first node, let's consider deleting the last.

Figure 9-8 shows the deletion of the node to which curPtr points, which is the last node. That pointer alone is insufficient, as we have the variable `prevPtr` to the next-to-last node. You set the pointer within the next-to-last node to `nullPtr`. The same statement that we just used to remove an interior node will make this pointer change, since the value of `curPtr->getNext()` is `nullPtr`:

```
prevPtr->setNext(curPtr->getNext());
```

To remove a chain's first node, recall that you must change the value of headPtr to point to the second node. The second node becomes the chain's new first. You may change this to headPtr by using the assignment statement

Removing the first node is a special case

```
headPtr = headPtr->getNext();
```

As was the case for the deletion of an internal node, the pointers bypass the old node, although it still exists. Also note that if the node to be deleted is the only node in the chain—and thus it is the first and last node—the previous assignment statement assigns the value nullptr. Recall that the value nullptr in headPtr indicates an empty chain, and so this assignment statement handles the removal of the only node in chain correctly.

The removed node still exists. Assuming that curPtr points to it, changing the value of curPtr will place the removed node in a state of limbo. It will still require storage space, and the program will no longer be able to access it. You would have a memory leak. Therefore, before you change the value of curPtr, you should use the statements

```
curPtr->setNext(nullptr);
delete curPtr;
curPtr = nullptr;
```

Return removed nodes to the system by using delete to delete the node and return its memory to the system. summarize, the deletion process has three high-level steps:

1. Locate the node you want to delete.
2. Disconnect this node from the linked chain by changing pointers.
3. Return the node to the system.

Three steps to delete a node from a chain

You will see these steps and the previous discussion implemented in the following definition of remove:

```
template<class ItemType>
bool linkedList<ItemType>::remove(int position)
{
  bool ableToRemove = (position >= 1) && (position <= itemCount);
  if (ableToRemove) {
    NodeItem* curPtr = nullptr;
    if (position == 1) {
      // Remove the first node that is before the one to delete
      curPtr = headPtr; // Save pointer to node
      headPtr = headPtr->getNext();
    }
    else {
      // Find the node that is before the one to delete
      Node<ItemType>* prevPtr = getNode(position - 1);
      // Point to node to connect
      curPtr = prevPtr->getNext();
      // Disconnect indicated node from chain by connecting the
      // prior node with the one after
      prevPtr->setNext(curPtr->getNext());
    }
    // Return node to system
    curPtr->setNext(nullptr);
}
```

# 9.2.3 Using Recursion in LinkedList Methods

Using recursion in the implementation of the methods in the class can be an attractive alternative to an iterative approach. Section 4.3 of Chapter 4 developed the recursive methods getPointerTo. In general, we can state that you can process a linked chain by processing its first node and then the rest of the chain. Thus, to add a new node to a chain at a given position, you use the following logic:

```
if (the insertion position is)
    Add the new node to the beginning of the chain
else
    Ignore the first node and add the new node to the rest of the chain
```

Adding to the beginning of a chain—or subchain—is the base case of recursion. Frankly, the beginning of the chain is the easiest place to make an addition.

If position is the desired position of the new node, newNodePtr points to the new, and subChainPtr initially points to the chain and later points to the rest of the chain, we can add some detail to the previous logic, as:

```
if (position == 1)
{
    newNodePtr->next(subChainPtr)
    subChainPtr = newNodePtr
    IncrementCount
}
```

The method getPointerTo in Section 4 returned a pointer to a given entry in a chain. Since that operation traversed the chain but not alter it, its recursive formulation was straightforward. However, the list's insert does not alter the chain. Getting the recursive method to add these changes the challenge.

The method insert. Let's look at the recursive implementation of the insertion operation before we describe how it works. You learned in 4.3 that you write a private method to perform the recursion and you write a public method—typically one that implements the ADT'operation—to invoke this method. Thus, we have the following method definitions:

```
// The public method:
template<class ItemType>
bool LinkedList<ItemType>::insert(int newPosition, const ItemType& newEntry)
{
bool ableToInsert = (newPosition >= 1) &&
    (newPosition <= itemCount + 1);
if (ableToInsert)
{
    // Create a new node containing the new entry
Node<ItemType>* newNodePtr = new Node<ItemType>(newEntry);
    headPtr = insertNode(newPosition, newNodePtr, headPtr);
} // end if

return ableToInsert;
} // end insert
```
