```cpp
int LinkedBag<ItemType>::getFrequencyOf(const ItemType& anEntry) const
{
    int frequency = 0;
    int counter = 0;

    while ((curPtr != nullptr) && (counter < itemCount))
    {
        if (anEntry == curPtr->getItem())
        {
            frequency++;
        } // end if

        curPtr = curPtr->getNext();
```

```cpp
// Returns a pointer to the node containing a given entry
// or nullptr if the entry is not in the bag.
template<class ItemType>
Node<ItemType>* LinkedBag<ItemType>::getPointerTo(const ItemType& target) const
{
    bool found = false;
    Node<ItemType>* curPtr = headPtr;

    while (!found && curPtr != nullptr) {
        if (target == curPtr->getItem()) {
            found = true;
        }
        else
            curPtr = curPtr->getNext();
    } // end while

    return curPtr;
} // end getPointer
```

**The remove method.** Recall that the method deletes one occurrence of a given entry and returns either true or false to indicate whether the removal was successful. By adding a new node to a linked chain at its beginning, removing the first node. But the entry that we need to remove is not always in the chain's first node.

Suppose we want to delete an entry in node n. We replace that entry with the first node, and delete the first node. Then, we can describe the logic for remove with the following pseudocode:

```text
remove(anEntry)
    Find the node that contains anEntry
    Replace anEntry with the entry that is in the first node
    Delete the first node
```

By using the method getPointerTo to locate the entry we want to delete, we can define the method as follows:

```cpp
template<class ItemType>
bool LinkedBag<ItemType>::remove(const ItemType& anEntry) {
    Node<ItemType>* entryNodePtr = getPointerTo(anEntry);
    bool canRemoveItem = !isEmpty() && (entryNodePtr != nullptr);
    if (canRemoveItem)
    {
        // Copy data from first node to located node
        entryNodePtr->setItem(headPtr->getItem());

        // Delete first node
        Node<ItemType>* nodeDeletePtr = headPtr;
        headPtr = headPtr->getNext();

        // Return the node to the system
        nodeDeletePtr->setNext(nullptr);
        delete nodeDeletePtr;
        nodeDeletePtr = nullptr;

        itemCount--;
    } // end if

    return canRemoveItem;
} // remove
```

After the method remove, a system can use this returned memory and possibly reallocate it your program as a result of the new operator. Suppose that this reallocation occurs when you ask for a node for your linked chain. Be sure that your new node does not point to your chain, because you executed the statement nodeDeletePtr->setNext(nullptr). Doing this and setting the variable nodeDeletePtr to nullptr are examples of defensive programming that can avoid devastating, subtle errors later in the program. We take these steps, even though nodeDeletePtr is a local variable that we do not use, to clarify to future programmers who revise our method.

> Tip: Remember that any time you allocate memory using new, you must eventually delete it using delete.

> Note: For a pointer p, delete p deallocates the node to which p points; it does not delete p. The pointer still exists, but it contains an undefined value. You should not reference p or any other pointer variable that points to the allocated node. To help you avoid this kind of error, you can assign nullptr to p after deleting p. However, if variables other than p point to the deleted node, the possibility of error exists.
