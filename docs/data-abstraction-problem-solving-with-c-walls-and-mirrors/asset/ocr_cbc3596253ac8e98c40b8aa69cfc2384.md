# CHAPTER 2 Recursion: The Mirrors

# SUMMARY

+   1. Recursion is a technique that solves a problem by solving a smaller problem of the same type.

+   2. When constructing a recursive solution, keep the following four questions in mind:
   a. How can you define the problem in a smaller problem of the same type?
   b. How does each recursive call diminish the size of the problem?
   c. What instance of the problem can serve as the base case?
   d. As the problem size diminishes, will you reach this base case?

+   3. When constructing a recursive solution, you should assume that a recursive call is correct if its precondition has been met.

+   4. You can use the box to trace the activations of a recursive function. These boxes resemble activation records, which many compilers use to implement recursion. Although the box is useful, it cannot replace an intuitive understanding of recursion.

+   5. Recursion allows you to solve problems—such as the Towers of Hanoi—where iterative solutions are difficult to conceptualize. Even the most complex problems have straightforward recursive solutions. Some solutions can be easier to understand, describe, and implement than iterative.

+   6. Some recursive solutions are much less efficient than a corresponding iterative solution due to their inefficient algorithms and the overhead of function calls. In such cases, the iterative solution can be preferable. You can use the recursive solution, however, to derive the iterative solution.

+   7. If you can easily, and efficiently solve a problem by using iteration, you should do so.

+   1. The following recursive function getNumberEqual returns the array of n integers that are equal to the desiredValue. For example, if x contains the integers 1, 2, 4, 5, 6, 7, 8, and 9, then getNumberEqual(x, 10, 4) returns the value 2, because 4 occurs twice in x.
```c
int getNumberEqual(const int x[], int n, int desiredValue) {
    int count = 0;
    if (n <= 0)
        return 0;
    else {
        if (x[n - 1] == desiredValue)
            count = 1;
        return getNumberEqual(x, n - 1, desiredValue) + count;
    } // end else
} // end getNumberEqual
```

Demonstrate that this function is recursive by listing the criteria of a recursive solution and stating how the function meets each criterion.
