Building a minimum-height binary search tree

```cpp
// Builds a minimum-height binary search tree from n sorted values in a file.
// Returns a pointer to the tree's root.
readTree(n: integer): BinaryNodePointer
if (n > 0) {
    // Get the root
    treePtr = pointer to new node with nullptr as its children pointer
    rootItem = next item from file
    treePtr->setItem(rootItem)
    // Construct the left subtree
    leftPtr = readTree(treePtr->getLeftChildPtr(), n / 2)
    treePtr->setLeftChild(leftPtr)
    // Construct the right subtree
    rightPtr = readTree(treePtr->getLeftChildPtr(), (n - 1) / 2)
    treePtr->setRightChild(rightPtr)
    return treePtr
} else
    return nullptr
```

You should trace this algorithm and convince yourself that it is correct for both even and odd values of n.

To summarize, you can easily restore a tree as a balanced binary search tree if the data is sorted—if it has been produced from the inorder traversal—and you know the n of nodes in the tree. You need so that you can determine the middle item and, in turn, the number of nodes in the left and right subtrees of the tree's root. Knowing this is a simple method of counting nodes as you traverse the tree and saving the value in a file that the restore operation can read.

Note readTree would be an appropriate protected method of BinarySearchTree, if you also had a public method to call it.

## SUMMARY

| | |
| --- | --- |
| 1 | The implementation of a binary tree is usually link based. However, if the binary tree is complete, an efficient array-based implementation is possible. |
| 2 | A node in a binary tree is an object that references a data entry and two child nodes. |
| 3 | Because a binary tree has a recursive nature, recursion is useful in the implementation of its operations. As typical, the recursive methods are not public, since they require parameters that are part of the underlying data structure. Those methods can be either private or protected, but as protected methods, they are available to classes derived from the class of binary trees. |
| 4 | The ADT binary tree has several methods that are the same as those in the binary search tree. However, its insertion, removal, and retrieval operations have different definitions than those for the ADT binary tree. |
| 5 | Operations on a binary search tree can be quite efficient. In the worst case, however—when the tree approaches a linear shape—the performance of it degrades and is comparable to that of a linear linked chain. If you must avoid such a situation for a given application, you should use the balancing methods presented in Chapter 19. |
| 6 | The tree sort algorithm efficiently sorts any array by using the binary search tree's insertion and traversal operations. |
| 7 | If you save a binary search tree's data in a file while performing an inorder traversal of its nodes, you can restore the tree as a binary search tree of minimum height. If you save a binary search tree's data in a file while performing a preorder traversal of its nodes, you can restore the tree to its original form. |
| 8 | You can use a binary tree to represent a general tree or an n-ary tree. However, an n-ary tree can have nodes that point to all of its children. |
