You need to be comfortable with the differences between these two functions. The recursive calls that the functions make a different sequence of values for the argument s. Despite this, both functions correctly write the string argument backward. They compensate for the difference in the sequence of values by writing different characters in the string at different relative to the recursive calls. In terms of the box traces in Figures 2-8 and 2-9, writeBackward writes a character just before generating a new box (just before a new recursive), whereas writeBackward2 a character just after crossing off a box (just after returning from a recursive call). When these are put together, the result is two functions that employ different strategies to accomplish the task.

Well-placed temporary cout statements can help you debug a recursive function

This example illustrates the value of the box trace, combined with well-placed cout statements, in debugging recursive functions. The cout statements at the beginning, interior, and end of the recursive function return the value of the argument s. In general, when debugging a recursive function, you should also report the values of local variables and the point in the function where each recursive call occurs, as in this example:

```
abc(...);
```

```
cout << "Calling function abc from point A.\\n"
abc(...); // This is this point A
```

```
cout << "Calling function abc from point B.\\n"
abc(...); // This is this point B
```

Remove cout statements after you have debugged the function

Realize that the cout statements do not belong in the final version of the function.
