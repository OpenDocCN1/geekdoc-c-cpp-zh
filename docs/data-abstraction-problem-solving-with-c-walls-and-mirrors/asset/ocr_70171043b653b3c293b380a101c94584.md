virtual methods—methods that use the keyword virtual to indicate that they can be overridden. In the example in Section C2.2, PlainBox is the base class, which we defined in List C1-3 of C++ Interlude I. The code that we wrote did not behave as we desired. To correct that problem, we must declare the virtual methods of PlainBox that we want others to override, as Listing C2-4 shows. Notice that only the header file of the class (PlainBox) needs to be revised. Declaring the methods setItem and getItem virtual makes it possible for the method code to be bound late.

# LISTING C2-4 Revised header file for the class PlainBox

```
/** @file PlainBox.h */
#ifndef PLAIN_BOX
#define PLAIN_BOX
ntemplate<class ItemType>; // Indicates this is a template
// Declaration for the class PlainBox
class PlainBox{
private:
  // Data field
  ItemType item;
public:
  // Default constructor
  PlainBox();
  // Parameterized constructor
  PlainBox(const ItemType& item);
  // Mutator method that can change the value of the data field
  virtual void setItem(const ItemType& item);
  // Accessor method to get the value of the data field
  virtual ItemType getItem() const;
};\ // end PlainBox

#include "PlainBox.cpp" // Include the implementation file
#endif
```
