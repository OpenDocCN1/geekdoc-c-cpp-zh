Each node in the array-binary tree has a data item and two array indices, one to each child. Both leftChild and rightChild within a node are the children of that node. If a node has no left child, leftChild is -1; since the index of the root of a binary tree, tree[root].get() is leftChild, the index of the left subtree of r; tree[root].getR() is rightChild, the index of the root of the right subtree of r.
