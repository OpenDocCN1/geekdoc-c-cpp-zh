The merge sort is a recursive algorithm that gives the same performance, regardless of the initial order of the array items. Suppose that you divide the array into halves, sort each half, and then merge the sorted halves into one sorted array, as Figure 11-5 illustrates. In the figure, halves <1, 4, 8> and <2, 3> are merged to form the array <1, 2, 3, 4, 8>. This step compares an item in one half with an item in the other half and moves the smaller item to a temporary array. This process continues until there are no more items to consider in. At that time, you simply move the remaining items to the temporary array. Finally, copy the temporary array back into the original.

The merge sort requires a second array as the original

Although the merge step of the merge sort produces a sorted array, how do you sort the array prior to the merge sort? The merge sort sorts the array by using a merge sort—that is, by calling itself recursively. The pseudocode for the merge sort is

```
// Sort theArray[first..last]
// Sorting the first half of the array
// Sorting the second half of the array
// Merging the two sorted halves
mergeSort(theArray, first: integer, last: integer)
if (first < last)
    mid = (first + last) / 2
    // Get midpoint
    // SortArray[first..mid]
    mergeSort(theArray, first, mid)
    // SortArray[mid-1..last]
    mergeSort(theArray, mid + 1, last)
```
