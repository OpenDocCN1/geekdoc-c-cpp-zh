
13. The specification of a set of data-management operations, together with the data values on which they operate, defines an abstract data type (ADT).

14. Only after you have defined an ADT should you think about how to implement it. The proper choice of a data structure to implement an ADT depends both on the details of the ADT operations and the context in which you will use the operations.

- 1. The price of an item you want to buy is given in dollars and cents. You pay for it in cash by giving the clerk d dollars and c cents. - 3. Write a pseudocode in terms of the ADT appointment book, described in Section 1.4.1, for each of the following tasks. You will need to add operations to the ADT to perform these tasks?

- 4. Imagine that you have just left a store with a bag of groceries. You are concerned that the fragile items will not survive the trip, so when you reach your car, you place those items into their own bag. If Bag is a class of bags, write C++ classes that remove the items from storebag and place them into one of two new bags, as follows: Place all occurrences of bread and eggs into fragilebag, and all other items into grocerybag. When you are done, storebag should be empty. Assume that groceries are represented by strings.

- 5. Suppose that a bag contains strings representing various grocery items. Write a C++ function that removes and counts occurrences of a string from such a bag. Your function should return the number. Use comments in javdoc to fully specify your function. Accommodate the possibility that the bag is empty or does not contain any occurrences of the string.

- 6. The union of two bags is a new bag containing the combined contents of the original two bags. Design and specify a method union for the ADT that returns a new bag containing the union of the bag being called to the method and the bag that is the method argument. Include sufficient comments to fully specify the method. For example, if x occurs five times in one bag and twice in another, the union of these bags contains x seven times. Suppose, that bag1 and bag2 are bags; bag1 contains the strings a, b, and c; and bag2 contains the strings b, b, d, and e. The expression bag1.union(bag2) returns a bag containing the strings a, b, b, c, d, and e. Note that union does not affect the contents of bag1 and bag2.

- 7. The intersection of two bags is a new bag containing the entries that occur in both of the original two bags. Design and specify a method intersection for the ADT bag that returns a new bag intersection of the bag receiving the call to the bag that is the method's one argument. - 8. The difference of two bags is a new bag containing the entries that would be left in one after removing those that also occur in the second. Design and specify a method difference for the ADT bag that returns a new bag the difference of the bag receiving the call to the bag that is the method's one argument. - 9. Consider the ADT polynomial in x—which operations include the following:

```
degree() // Returns the degree of a polynomial.
coefficient(power) // Returns the coefficient of the x^power term.
changeCoefficient(newCoefficient, power) // Replaces the coefficient of
// the x^power term with newCoefficient.
```

For this problem, only polynomials whose exponents are nonnegative integers. For example, p = 4x^5 + 7x^3 - x^2 + 9

The following examples demonstrate the ADT operations on this polynomial.

- .degree() is 5 (the highest power of x with a nonzero coefficient)
- .coefficient(3) is 7 (the coefficient of the x^3)
- .coefficient(4) is 0 (the coefficient of a missing term is implicitly 0)
- .changeCoefficient(-3, 7) changes the polynomial p to -3x^4 + 7x^3 - x^2 + 9

Using these ADT operations, write statements to perform the following tasks:

    a. Display the coefficient of the term that has the highest power.
    b. Increase the coefficient of the x^3 term by 8.
    c. Compute the sum of two polynomials.

- 4. A ring is a collection of items that has a reference to a current item. An operation—let's call it advance—moves the reference to the next item. Design an ADT to represent a ring of objects. Specify each operation by stating its purpose, by describing its parameters, and by writing a pseudocode version of its header. Write a C++ interface for the ring's methods. Include javadoc-style comments in your code.
