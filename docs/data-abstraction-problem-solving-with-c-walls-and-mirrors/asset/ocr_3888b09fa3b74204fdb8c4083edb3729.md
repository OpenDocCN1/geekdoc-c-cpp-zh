**Modulo arithmetic.** Module arithmetic provides a simple and effective hash function that we will use in the rest of this chapter. For example, consider the function

```
h(x) = x mod hashTable
```

where the hash table has hashTable elements. In particular, if tableSize is 101, h(x) = x mod 101 any integer x into the range 0 through 100. For example, h maps 001364825 into 12, and so on.

For H(x) = x mod tableSize, many x's map to table[0], many x's map to table[1], and so on. That collisions occur, you can distribute the dictionary items over all of table—reducing collisions—by choosing a prime number as tableSize. In instance, 101 in the previous example is prime. The choice of tableSize will be discussed in more detail later in this chapter. For example, realize that 101 is used here as a simple example of a prime table. For the typical hash table, 101 is much too small.

**Converting a string to an integer.** If your search key is a string—like name—you can convert it into an integer before applying the hash function h(x). To do this, you could first assign an integer value to each character in the string. For example, the word “NOTE” you could assign the ASCII values 78, 79, 84, and 69, to the letters N, O, T, and E. Or, if you assign the values 1 through 26 to the letters A through Z, you could assign 14 to N, 15 to O, and 20 to E.

If you simply add these numbers, you will get an integer, but it will not be unique to the character string. For example, the word “TONE” will give you the same result. Instead, you can use the numeric value for each character in binary and concatenate the results. If you assign the values 1 through 26 A through Z, you obtain the following result for the word “NOTE":

```
N is 14, or 01110 in binary
O is 15, or 01111 in binary
T is 20, or 10100 in binary
E is 5, or 00101 in binary
```

Concatenating the binary values gives you the binary integer

```
011100011110100000101
which is 764,757 in decimal. You can apply the hash function mod hashTable for x = 474,757.
```
