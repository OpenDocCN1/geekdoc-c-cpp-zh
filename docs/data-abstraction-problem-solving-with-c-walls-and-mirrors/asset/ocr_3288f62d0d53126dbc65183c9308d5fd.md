# Dictionaries and Their Implementations

Each of the methods remove, getItem, and contains is passed a search key as its only argument. Each method must search the binary search tree for an Entry object that has a particular search key. How will Dictionary's remove method, for example, call BinarySearchTree's remove method? After it, it requires an Entry object as an argument.

The methods of BinarySearchTree compare Entry objects using either of the operators == or >. These operators are the same ones as Entry overloads. Then we can control how BinarySearchTree will make these comparisons. Because we are searching for a specific search key, which overload == to examine only the search-key portion of Entry object, the definition of the overloaded operator is

```
template <class KeyType, class ItemType>
bool EntryKeyType, ItemType>::operator=(const EntryKeyType, ItemType>&rightHandItem) const {
return (searchKey == rightHandItem.GetKey());
}// end operator->
```

Now BinarySearchTree can compare Entry objects based only on their search keys, how does Dictionary's remove method call BinarySearchTree's remove method? Because BinarySearchTree's remove expects an Entry object as an argument, Dictionary creates an Entry object that has a specific search key and item type, and passes it to the invoked method. To create this entry, you can write the following expression:

```
Entry<KeyType, ItemType>(ItemType(), searchKey)
```

```
template <class KeyType, class ItemType>
bool Dictionary<KeyType, ItemType>::remove(const KeyType& searchKey)
{
return tree.remove(Entry<KeyType, ItemType>(ItemType(), searchKey));
}// end remove
```

> Note: Usually a binary search tree can support the ADT dictionary operations efficiently. In the worst case, when the tree approaches a linear shape, the performance of the dictionary operations is comparable to that of a linearlink-based implementation. If a given application cannot tolerate poor performance, you should use the dictionary implementations presented in either Section 18.4 of this chapter or in Chapter 19.
