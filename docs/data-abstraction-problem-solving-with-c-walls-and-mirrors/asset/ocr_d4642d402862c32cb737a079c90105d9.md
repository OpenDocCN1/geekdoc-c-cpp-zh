# 526 CHAPTER 18 Dictionaries and Their Implementations

His chapter considers the ADT dictionary, which is appropriate for problems that manage data by value. Several dictionary implementations—which use arrays, linked chains, binary search trees, and a new technique called hashing—will be presented, along with their advantages and disadvantages.

To make an intelligent choice among the various dictionary implementations, you must analyze the efficiency with which each of the implementations supports the dictionary operations. For example, we analyze the time-efficiency of array-based and link-based dictionary implementations and conclude that, in many applications, the implementations do not support the dictionary operations as efficiently as possible. This conclusion motivates the use of more sophisticated dictionary implementations.

# 18.1 The ADT Dictionary

When we begin our discussion of sorting data in Chapter 11, we introduced the notion of a sort key. For example, you might want to sort a collection of data about people based on their names, their ages, or their zip codes. The criterion you choose is the sort key. Similarly, you might want to search the same collection of data for a name, an address, or a phone number. The criterion you choose for this is known as a search key.

Applications that require value-oriented operations are extremely prevalent, as you might imagine values instead of positions.

+   * Find the number of John Smith
* Delete all the information about the employee with ID 12908

We first encountered a value-oriented ADT, the sorted list, in Chapter 12. Chapter 15 presented the binary search tree, which is also a value-oriented ADT. This section describes another value-oriented ADT, the dictionary.
