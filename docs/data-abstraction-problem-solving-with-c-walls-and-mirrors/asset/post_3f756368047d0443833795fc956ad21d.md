Despite this, both functions correctly write the string argument backward. They compensate for the difference in the sequence of values by writing different characters in the string at different relative to the recursive calls. ### Well-placed temporary cout statements can help you debug a recursive function

This example illustrates the value of the box trace, combined with well-placed cout statements, in debugging recursive functions. The cout statements at the beginning, interior, and end of the recursive function return the value of the argument s. In general, when debugging a recursive function, you should also report the values of local variables and the point in the function where each recursive call occurs, as in this example:

```
abc(...);
```

```
cout << "Calling function abc from point A.\n";
abc(...); // This is this point A
```

```
cout << "Calling function abc from point B.\n";
abc(...); // This is this point B
```

# 2.4 Recursion with Arrays

When you are working with an array, recursion can be a practical and powerful tool. For your first example, we write the contents of an array backward. We then look at several problems that involve searching an array.

### 2.4.1 Writing an Array's Entries in Backward Order

The solution to this problem is much like our first solution in Section 2.3.1 when we write a string backward. We can write the following pseudocode:

```
writeArrayBackward(anArray: char[])
if (the array is empty)
    Do nothing—this is the base case
else {
    Write the last character in anArray
    writeArrayBackward(anArray minus its last character)
}
```

How will we pass the array minus last to writeArrayBackward? We could pass the number of characters left in the array. At each recursive call, we would decrease this number by 1. Alternatively, we could pass the index of the last character. If this is, writeArrayBackward would act on the array[0..last], that is, the position anArray-0 through anArray[last]. The recursive call would then act on the subArray[0..last-1]. A more general variation of this also passes the index of the first character. Instead of assuming this index is 0, we would pass anArray[first..last] to writeArrayBackward.

We can write the function writeArrayBackward as follows:

```cpp
/* Writes the characters in an array backward.
@param The array contains size characters, where size >= 0.
@param anArray the array to write backward.
@param first The index of the first character in the array.
@param last The index of the last character in the array. */
void writeArrayBackward(const char anArray[], int first, int last) {
    if (first <= last) {
        // Write the last character
        cout << anArray[last];

        // Write the rest of the array backward
        writeArrayBackward(anArray, first, last - 1);
    }
    // first > last is the base case - do nothing
}
// end writeArrayBackward
```

## 2.4.2 The Binary Search

Searching is an important task that occurs frequently. Often, searches are for a particular entry in an array. We will examine a few searching problems that have recursive solutions. Our goal is to develop your understanding of recursion.

This chapter begins with an intuitive approach to a binary search algorithm by presenting—at a high level—a way to find a word in a dictionary. We now develop this algorithm fully and illustrate some important issues.

Recall the earlier solution to the dictionary problem:

```
search(dictionary: Dictionary, word: string)
if (dictionary is one page in size)
    Scan the page for word
else
    Open ADictionary to a point near the middle
    Determine which half of ADictionary contains word
if (word is in the first half of ADictionary)
    search(first half of ADictionary, word)
else
    search(second half of ADictionary, word)
```

Now alter the problem by searching anArray of integers for a given value, the dictionary must be sorted, or a binary search is not applicable. Hence, assume

```
anArray[0] anArray[1] anArray[2] ... anArray[size - 1]
```

where size is the size of the array. A high-level binary search for the array problem is

```
binarySearch(anArray: ArrayType, target: ValueType)
if (anArray is of size 1)
    Determine if anArray's value is equal to target
else
    Find the midpoint of anArray
    Determine which half of anArray contains target
    if (target is in the first half of anArray)
        binarySearch(first half of anArray, target)
else
        binarySearch(second half of anArray, target)
```
