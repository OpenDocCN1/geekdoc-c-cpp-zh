# Inheritance and the execution order of constructors and destructors

A derived class executes after the base class's constructor. For example, if you define an instance of MagicBox, its constructor executes after PlainBox's constructor. The destructor of a derived class executes before the base class's destructor. For example, MagicBox's destructor executes before PlainBox's destructor. This is true for constructors and destructors that you write as well as those generated by the compiler.

In addition to public and private sections, a class can have a protected section. By creating a protected section, a class designer can hide members from a class but make them available to a derived class.
