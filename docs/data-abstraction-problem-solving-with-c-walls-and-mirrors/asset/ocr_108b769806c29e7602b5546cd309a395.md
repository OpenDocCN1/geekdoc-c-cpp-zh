# 16.3 A Link-Based Implementation of the ADT Binary Search Tree

Since a binary search tree is a binary tree, its implementation can use the same node objects as for a binary-tree implementation. As we plan a link-based implementation, we will use the class BinaryNode, as given in Listing 16-2.

The recursive algorithm that we presented in Section 15.3.2 of Chapter 15 is the basis of the insertion, removal, and retrieval operations on a binary search tree. The algorithms that follow for the binary search tree operations assume the link-based implementation of a binary tree that was discussed in this chapter. Also keep in mind that the data items in the binary search tree are unique.
