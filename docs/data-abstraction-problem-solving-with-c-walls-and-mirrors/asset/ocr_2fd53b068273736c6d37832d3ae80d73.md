It can be proven that the height of an AVL tree with $n$ nodes always be very close to the theoretical minimum of $\lfloor\log_2(n+1)floor$. The AVL tree implementation of a dictionary is, therefore, one implementation that guarantees a binary search-efficiency. Usually, implementations that use a 2-3-4 tree or a red-black tree will be simpler.
