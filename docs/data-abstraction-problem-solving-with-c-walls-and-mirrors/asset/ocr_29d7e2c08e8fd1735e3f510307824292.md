2-3 and 2-3-4 trees are attractive because balance is easy to maintain

> Note: 2-3 trees versus 2-3-4 trees

The advantage of 2-3 and 2-3-4 trees is their easy-to-maintain balance, not their shorter height. Even if a 2-3 tree is shorter than a balanced binary search tree, the reduction in height is offset by the increased number of comparisons that the search algorithm might require. The situation for a 2-3-4 tree, its insertion and removal require only one pass through the tree and so are more efficient than for a 2-3 tree. This decrease in effort makes the 2-3-4 tree more attractive than the 2-3 tree.

We should consider whose nodes have even more than four children? Although a tree nodes can each have 100 children would be shorter than a 2-3-4 tree, its search algorithm would require more comparisons at each node to determine which subtree to search. Thus, allowing the nodes of a tree with many children is counterproductive. Such a tree is appropriate, however, when it is implemented in external storage, moving from node to node is far more expensive than comparing the values in a node. # 19.4 Red-Black Trees

A 2-3-4 tree requires more storage than a binary search tree

A 2-3 tree is appealing because it is balanced and its insertion and removal operations use only one pass from root to leaf. On the other hand, a 2-3-4 tree requires more storage than a binary search tree that contains the same data a 2-3-4 tree has nodes that must accommodate up to three data items. A typical binary search tree, however, might not be balanced.

A red black tree has the advantages of a 2-3-4 tree but less storage

You can use a binary search tree—a red-black tree—to represent a 2-3-4 tree that retains the overhead. The idea is to represent 3-node and 4-node in a 2-3-4 tree as an equivalent binary search tree. To distinguish between 2-nodes that appeared in the original 2-3-4 tree and 2-nodes that were generated from 3-nodes and 4-nodes, you use red and black pointers. Let all the child pointers in the original 2-3-4 tree be black, and use red pointers to link the 2-3-4 tree result when you split 3-nodes and 4-nodes.

> Note: In a red-black tree, red pointers link the 2-nodes that contain the values in a 3-node or a 4-node.
