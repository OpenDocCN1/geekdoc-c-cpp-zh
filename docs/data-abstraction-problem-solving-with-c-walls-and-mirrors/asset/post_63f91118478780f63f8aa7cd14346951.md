
```cpp
if ((a >= b) && (a >= c))
largest = a;
else if (b >= c) // a is not largest at this point
largest = b;
else
largest = c;
```

> > Note: An arithmetic expression whose value is zero is not treated as true; having a value of zero is false.

## A.4.2 The switch Statement

When you must choose more than two courses of action, the if statement can become unwieldy. If your choice is to be made to the value of an integral expression, you can use a switch statement.
For example, the following statement determines the number of days in a month. The variable month designates the month as an integer from 1 to 12, and the boolean variable leapYear is

```cpp
switch (month)
{
  // 30 days Sept., Apr., June, Nov.
  case 9: case 4: case 6: case 11:
    daysInMonth = 30;
    break;
  // All the rest have 31
  case 1: case 3: case 5: case 7:
  case 8: case 10: case 12:
    daysInMonth = 31;
    break;
  // Except February
  // Assume leapYear is true if a leap year, else is false
  if (leapYear)
    daysInMonth = 29;
  else
    daysInMonth = 28;
    break;
  default:
    cout << "Incorrect value for month.\n";
}
// end switch
```

Parentheses must enclose the switch expression—month, in this example. The case labels have the form
case expression:

where expression is a constant integral expression. After the switch is evaluated, execution continues at the case label whose expression has the same value as the switch expression. Subsequent statements execute until either a break or a return is encountered or the switch statement ends.
Unless you terminate a case with either a break or a return, execution of the switch statement continues. Although this action could be useful, omitting the break statements in the previous example would be incorrect.

If no case matches the current value of the switch expression, the statements that follow de the default label, if one exists, are executed. If no default exists, the switch statement exits.

## A.5 Iteration Statements

C++ has three statements—the while, for, and do statements—that provide for repetition iteration is, loops. Each statement controls the number of times that another C++ statement—the body—is executed. The body cannot be a declaration and is often a compound statement.

### A.5.1 The while Statement

A while statement
executes as long as the expression is true.

The general form of the while statement is

```cpp
while (expression)
statement
```

As long as the value of expression is true, statement is executed. Because expression is evaluated before statement is executed, it is possible that statement will not execute at all. Note that the parentheses around expression are required.

Suppose that you wanted to compute the sum of positive integers that you enter the end of. Since the integers are positive, you can use a negative value or zero to indicate the end of the list of integers. The while statement completes this task:

```cpp
int nextValue = 0;
int sum = 0;
cin >> nextValue;
while (nextValue > 0)
{
sum += nextValue;
cin >> nextValue;
} // end while
```

If zero was the first value read, the body of the while statement would not execute. Recall that the expression cin >> nextValue has the value true if the input operation was successful and false otherwise. Then, you could revise the previous statements as

```cpp
int nextValue = 0;
int sum = 0;
while ((cin >> nextValue) && (nextValue > 0 ))
sum += nextValue;
```

### A.5.2 The For Statement

A for statement
lists the initialization, testing, and dating steps in one location.

The statement provided for counted loops and has the general form

```cpp
for (initialize; test; update)
statement
```

where test, and update are expressions. Typically, initialize is an assignment expression that initializes a counter to control the loop. This initialization occurs only once. If test, which is usually logical expression, is true, statement executes. The expression update executes next, usually incrementing or decrementing the counter. This sequence of repeats, beginning with the evaluation of test, until the value of test is false.

For example, the following: counter statement displays the integers from 1 to n:

```cpp
for (int counter = 1; counter <= n; counter++)
cout << counter << "";
cout << endl; // This statement is always executed
```

If n is less than 1, the for statement does not execute at all. Thus, the previous statements are equivalent to the following counter = while loop:

```cpp
int counter = 1;
while (counter < n)
{
    cout << counter << "";
    counter++;
} // end while // This statement is always executed
```

In general, the logic of a for statement is equivalent to initialize:

```cpp
while (test)
{
    statement;
    update;
}
```

A statement is equivalent to a while statement

```cpp
for (char ch = 'z'; ch > 'a'; ch--)
// ranges from 'z' to 'a'
```

The initialize and update portions of a for statement can contain several expressions separated by commas, performing more than one action. For example, the following loop raises a floating-point value to an integer power by multiplication:

```cpp
// Floating-point power equals floating-point x raised to int n;
// assumes int expon
for (power = 1.0, exp = 1; exp <= n; exp++)
power = x;
```

Both power and exp are assigned values before the body of the loop executes for the first time. The example here is of the comma operator, which evaluates its expressions from left to right.

When compared to a while statement, the for statement may make it easier to understand how the loop is controlled because the initialization, testing, and updating steps of the loop are consolidated into one statement. C++ programmers use for statements for loops that process collections or sequences of data.

For counted loops, a for statement is usually favored over the while statement.

### A.5.3 Do the Statement

Use the statement when you want to execute a loop's body at least once. Its general form is

A statement loops at least once

```cpp
do
statement

```

Here, statement executes until the value of expression is false.

## A.6 Arrays and Vectors

An array is a container of data items of the same type. An array has a finite number of elements. You must know the size of elements before you use an array. You can refer to any of the elements by using an expression, which is called the index, or subscript, enclosed in brackets.

### A.6.1 One-Dimensional Arrays

When you decide to use an array in your program, you must declare it, and in doing so indicate the data type of its elements as well as its size. The following statements declare a one-dimensional array, maxTemp, which contain the maximum temperatures for a:

```cpp
const int DAYS_PER_WEEK = 7;
double maxTemp[DAYS_PER_WEEK];
```

The bracket notation [] declares maxTemp as an array. This array can contain at most seven floating-point values. In C++, array indices have integer values from 0 to size-1, where size is the number of elements. The indices for maxTemp range from 0 to DAYS_PER_WEEK - 1. For example, the fifth element in the array is maxTemp[4]. If k is an integer value of 4, maxTemp[k] is the fifth element in the array, and maxTemp[k++] accesses maxTemp[k] before adding 1 to k. Note that you use index to refer to an element in a one-dimensional array:

Figure-8 illustrates the maxTemp array, which at present contains only five temperatures. The last value in the array is maxTemp[4]; the values of maxTemp[5] and maxTemp[6] are not initialized and are considered unknown.

You can use enumerators as indices because they have integer values. For example, consider the following:

```cpp
enum Day {SUN, MON, TUE, WED, THU, FRI, SAT};
```

Given this definition, maxTemp[THU] has the same value as maxTemp[4]. You can also use the enumerators in a loop that processes an array, as in the following statement:

```cpp
for (Day dayIndex = SUN; dayIndex <= SAT; dayIndex++)

```
