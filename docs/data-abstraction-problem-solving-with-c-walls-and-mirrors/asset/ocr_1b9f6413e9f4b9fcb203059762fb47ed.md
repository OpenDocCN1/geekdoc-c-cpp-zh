Recall that in a postfix expression the algorithm operates the two operands that precede it. The ADT stack provides this capability, each time you enter an operand, the calculator pushes it onto a stack. When you enter an operator, the calculator performs it to the top operands on the stack, pops the operands from the stack, and pushes the result of the operation onto the stack.
