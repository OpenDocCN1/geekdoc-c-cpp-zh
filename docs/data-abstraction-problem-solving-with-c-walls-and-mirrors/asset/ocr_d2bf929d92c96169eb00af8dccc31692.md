A graph is **planar** if you can draw it in a plane in at least one way so that no edges cross. The generalization of the three utilities problem determines whether a given graph is planar. Making this determination has many applications. For example, a graph can represent an electronic circuit where the vertices represent components and the edges represent the connections between components.
