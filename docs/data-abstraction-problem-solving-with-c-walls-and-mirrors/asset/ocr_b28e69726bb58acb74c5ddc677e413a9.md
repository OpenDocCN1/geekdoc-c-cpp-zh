A box trace of a recursive function that has an array argument requires a new consideration. Because the array is neither a value argument nor a local variable, it is not part of the function's local environment, so the entire anArray should not appear within each box. There, as Figure 2-11 shows, you may represent anArray outside the boxes, and all references to anArray affect this single representation.

> Note: Notice that the C++ computation of the mid point is
int mid = first + (last - first) / 2;
instead of
int mid = (first + last) / 2;
as as the pseudocode would suggest. If you were to search an array of at least $2^{30}$, or about 1 billion, the sum of first and last could exceed the largest possible int value of $2^{30}-1$. Thus, the computation first + last would overflow to a negative integer and result in negative value for mid. If this negative value of mid was used as an array index, it would be out of bounds and cause incorrect results. The computation first + (last - first) / 2 is algebraically equivalent to (first + last) / 2 and avoids this error.
