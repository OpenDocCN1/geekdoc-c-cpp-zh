The Statement

If you insert an item into the i-th position of a list, retrieving the i-th item will result in x

is true for all lists, and so it is an axiom. You can state this axiom in terms of the ADT operations as follows:

Use axioms to determine the effect of a sequence of ADT operations

```
(aList.insert(i, x)).getEntry(i) = x
```

That is, getEntry returns the item that insert has put at position i of aList The following axioms formally define the list

A set of axioms does not make the preconditions and postconditions for an ADT's operations unnecessary. For example, the axioms do not describe insert behavior when you try to insert an item into position 50 of a list of two items. One way to handle this is to include the restriction

```
1 <= position <= getLength() + 1
```

in insert precondition. Another way—which we used in our previous specifications of the ADT list—does not restrict position, but rather has the return value false if position is outside the range. Thus, you need both a set of axioms and a set of preconditions and postconditions to define the behavior of an ADT's operations completely.
