# SUMMARY

+   1. The most common implementations of a graph are the adjacency matrix and the adjacency list. Each has its
relative advantages and disadvantages. The choice should depend on the needs of the given application.
2. Graph searching is an important application of stacks and queues. Depth-first search (DFS) is a graph-traversal
alalgorithm that uses a stack to keep track of the sequence of vertices. It goes as deep into the graph as it
can backtracking. Breadth-first search (BFS) uses a queue to keep track of the sequence of visited vert-
ices. It visits all adjacent vertices before traversing further into the
3. Topological sorting produces a linear order of the vertices in a directed graph without cycles. Vertex x precedes
vertex y if there is a directed edge from x to y in the graph.
4. Trees are connected undirected graphs without cycles. A spanning tree of a connected graph is a
subgraph that contains all of the graph’s vertices and enough of edges to form a tree. DFS and BFS traversals
produce DFS and BFS spanning trees.
5. A minimum spanning tree for a weighted undirected graph is a spanning tree whose edge-weight sum is minim-
al. Although a particular graph can have several minimum spanning trees, their edge-weight sums will be the
same.
6. The shortest path between two vertices in a weighted directed graph is the path that has the smallest sum of its
edge weights.
