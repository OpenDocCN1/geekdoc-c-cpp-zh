To create a PlainBox object in Java, you could use the following statement:

```
PlainBox myBox = new PlainBox("Jewelry");
```

C++ provides several forms for creating objects also:

```
PlainBox myBox = PlainBox("Jewelry");
PlainBox myBox("Jewelry");
```

These statements are equal in C++ and create a PlainBox object that is local to the function or method in which it is created. In these examples the C++ keyword new is not used.

The following example uses the new keyword to create a PlainBox object that exists until the program specifically deletes it:

```
PlainBox* myBoxPtr = new PlainBox("Jewelry");
```

The syntax is similar to Java, except that PlainBox is followed by the * character. The * indicates that myBoxPtr is a pointer to a PlainBox and is not the object itself. Pointers are discussed in more detail in C++ 2.

If an object in C++ is instantiated using the new operator, as shown above, it is the responsibility of the programmer to delete object from memory when it is no longer needed, because C++ does not provide garbage collection. To delete the object by someBoxPtr, the statements

```
delete someBox; // Free memory used the object.
someBox = nullptr; // A safety precaution.
```

Each time you use the new operator to create an object, you must write a corresponding delete operator to free the object's memory. Otherwise, your application will have a memory leak.

Although at system level, Java and C++ treat keyboard input and console-output similarly, the high-level constructs used to accomplish these tasks differ greatly.

For a Java application to input from the keyboard, you create a Scanner object in System, and use it to get input from the user. To output the display is by calling either the print or println method on the System.out. The following code creates a Scanner object, displays a prompt for the user, accepts a response and echoes the response back to the user:

```
Scanner scanner = new Scanner(System.in);
System.out.print("How many apples are in a box? ");
```
