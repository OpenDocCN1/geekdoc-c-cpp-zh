# 15.3 The ADT Binary Search Tree

![](bbox=[0.135, 0.773, 0.203, 0.816])

The ADT binary search tree

Searching for an item is one operation for which the ADT tree is ill suited. The binary search tree corrects this deficiency by organizing its data by value. Recall that each node n in a binary tree satisfies the following three properties:

+   * n's value is greater than all values in its left subtree $T_L$
* n's value is less than all values in its right subtree $T_R$
* Both $T_L$ and $T_R$ are binary search trees.
