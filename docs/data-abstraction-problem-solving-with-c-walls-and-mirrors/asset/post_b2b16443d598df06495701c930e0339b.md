# SUMMARY

- 1. The enqueue and dequeue operations for a queue require efficient access to both ends of the queue. Therefore, a link-based implementation of a queue uses a linear linked chain that has both a head pointer and a tail pointer. Alternatively, you can use a circular linked chain.
- 2. An array-based implementation of a queue is prone to rightward drift. This phenomenon can make a queue full when it is really not. Shifting the items in the array is only compensate for rightward drift. A more efficient solution uses a circular array.
- 3. If you use a circular array to implement a queue, you must be able to distinguish between the queue-full and queue-empty conditions. You can make this distinction by counting the number of items in the queue, using a boolean variable isFull, or leaving one array empty.
- 4. You can use an array, chain of linked nodes, or a sorted list to contain the entries in a priority queue. A more time-efficient implementation is possible by using the ADT heap, which we will consider later in this book.

# Overloaded Operators and Friend Access

The C++ provides many operators. For example, when we use integers, + is addition, = is assignment, and == is comparisons. When we use classes, we must overload them. To overload an operator, you define an operator method whose name has the form

```
operator symbol
```

where symbol is the operator that you overload. For the == operator you name the operator== and declare one argument: the object that will appear on the right side of the operator. The current object represents the object on the left side of the operator. For LinkedList, you would add the declaration

```cpp
bool operator==(const LinkedList<ItemType>& rightSide) const;
```

to the class definition in the header file.

To understand this, realize that we may also have declared a client function isEqualTo that compares a member of type list with the current object to determine equality. The declaration for such a function would look like this:

```cpp
bool isEqualTo(const LinkedList<ItemType>& rightSide) const;
```

To use isEqualTo to compare the myList and yourList, you would write

```cpp
if (myList.isEqualTo(yourList))
    cout << "The lists are equal.\n";
```

You can treat operator== as exactly as you do isEqualTo; but so, you can write

```cpp
if (myList.operator==(yourList))
    cout << "The lists are equal.\n";
```

because operator== is a simple method. However, you can also use the more shorthand notation myList == yourList, and the compiler will understand that you use the operator== method. The LinkedList implementation of this method is
