The ordering of strings is analogous to alphabetic ordering, but you use the ASCII table instead of the alphabet. The following relationships are true:

Examples of true expressions

+   - "dig" < "dog"
- "Star" < "star" (because 'S' < 's')
- "start" > "star"
- "d" > "abc"

You can concatenate two strings to form another string using the + operator. That, you place one string after another string. For example, if

```
string str1 = "Com";
```

the statements

```
string str2 = str1 + "puter";
str1 += "puter";
```

assign the string "Computer" to each of str2 and str1. Similarly, you can append a single character to a string, as

```
str1 += 's';
```

Use substr to access part of a string

You can manipulate a portion of a string using the method substr(position, length)

The first argument specifies the position of the beginning of the substring (remainder) that 0 is the position of the first character in the string). The second argument is the length of the substring. For example,

```
title.substr(2, 7);
```

is the string "Perfect".

To perform input and output with C++ strings, you must include the library iostream by writing

```
#include <iostream>
```
