Sometimes, the inductive hypothesis in Axiom-E is not sufficient. That is, you may need to assume more than $P(k)$. The following axiom is a stronger form of the principle of mathematical induction:

**Axiom E-2. The principle of mathematical induction (strong form).** A property $P(n)$ that involves an integer $n$ is true for all $n \ge 0$ if the following are true:

1. $P(0)$ is true.
2. If $P(0), P(1), \dots, P(k)$ are true for any $k \ge 0$, then $P(k+1)$ is true.

Notice that the inductive hypothesis of Axiom E-2 ("If $P(0), P(1), \dots, P(k)$ are true for any $k \ge 0$") includes the inductive hypothesis of Axiom E-1 ("If $P(k)$ is true for any $k \ge 0$").

## **Example 4**

Prove that every integer greater than 1 can be written as a product of prime integers. The inductive proof is follows:

**Basis.** The statement that you must prove is that integers greater than 1. Thus, the base case is $n = 2$. However, 2 is a prime number, and therefore trivially is a product of prime numbers.

**Inductive Hypothesis.** Assume that the property is true for all the integers $2, 3, \dots, k$, where $k \ge 2$.

**Inductive Conclusion.** Show that the property is true when $n = k + 1$, that is, show that $k+1$ can be written as a product of prime numbers.

If $k+1$ is a prime number, then there is nothing left to show. However, if $k+1$ is not a prime number, it must be divisible by an integer $x$ such that $1 < x < k+1$.

```
$k+1 = x \times y$
```

where $1 < x < k+1$. Note that $x$ and $y$ are each less than or equal to $k$, so the inductive hypothesis applies. $x$ and $y$ can each be written as a product of prime numbers. Clearly, the product $x \times y$, which is equal to $k+1$, must be a product of prime numbers. Because the formula holds for $n = k+1$, it holds for all $n \ge 2$ by the principle of mathematical induction. (**End of proof.**).

Prove that

```
$rabbit(n) = (a^n - b^n)/\sqrt{5}$
```

where $a = (1 + \sqrt{5})/2$ and $b = (1 - \sqrt{5})/2 = 1 - a$.

**Basis.** rabbit(0) is undefined, begin at $n=1$. Some algebra shows that $rabbit(1) = (a^1 - b^1)/\sqrt{5} = 1$. However, $rabbit(2)$ is also a special case. That is, you cannot compute $rabbit(2)$ from using the recurrence relationship given here. Therefore, in this inductive proof we must include $n=2$.

When $n=2$, more algebra will show that $rabbit(2) = (a^2 - b^2)/\sqrt{5} = 1$. Thus, the formula is true when $n$ is either 1 or 2.

**Inductive Hypothesis.** Assume that the formula is true for all $n$ $1 \le n \le k$, where $k$ is at least 2.

**Inductive Conclusion.** Show that the formula is true for $n=k+1$. To do so, we can proceed as:

```
$rabbit(k+1) = rabbit(k) + rabbit(k-1)
$= [(a^k - b^k) + (a^{k-1} - b^{k-1})]/\sqrt{5} \qquad$ (inductive hypothesis)
$= [(a^{k-1}(a+1) - b^{k-1}(b+1)]/\sqrt{5} \qquad$ (factorization)
$= [(a^{k-1}(a^2) - b^{k-1}(b^2)]/\sqrt{5} \qquad$ $(a+1=a^2; b+1=b^2)$
$= [a^{k+1} - b^{k+1}]/\sqrt{5}$
```

Because the formula holds for $n=k+1$, it holds for all $n>2$ by the principle of mathematical induction. **(End of proof).**

Note that the previous proof requires you to show that $a+1=a^2$ and $b+1=b^2$. Simple algebra will demonstrate the validity of these equalities, exactly how we did discover after the factorization step. Some experience with inductive proofs will give you the confidence to determine and verify the auxiliary relationships—such as $a+1=a^2$—that are necessary in a proof. Here, after we introduced the factors $(a+1)$ and $(b+1)$, we observed that these factors were equal to $a^2$ and $b^2$, respectively, we could finish the proof. Thus tried to show that $a+1=a^2$ and $b+1=b^2$; indeed, we were successful. Inductive proofs often require adventurous algebraic manipulations!

# Algorithm Verification

To prove the correctness of an iterative algorithm, we use loop invariants. A loop invariant is a condition that is true before and after each execution of an algorithm's loop.

To use a loop invariant, we must show three things:
1. The invariant is true before the loop begins (initialization).
2. If the invariant is true before an iteration of the loop, it remains true after the iteration (maintenance).
3. When the loop terminates, the invariant implies that the algorithm is correct (termination).

Consider the following algorithm to compute the sum of an array $A$:

```
sum = 0
j = 0
while j < n {
    sum = sum + A[j]
    j = j + 1
}
```

The invariant for this loop is: "sum is the sum of the first $j$ elements of $A$".

1. **Initialization:** Before the first loop execution, $sum = 0$ and $j = 0$. The sum of the first 0 elements is 0, so the invariant is true.
2. **Maintenance:** Suppose the invariant is true before an iteration: $sum = \sum_{i=0}^{j-1} A[i]$. After the loop body, $sum$ becomes $sum + A[j]$ and $j$ becomes $j+1$. The new $sum$ is $\sum_{i=0}^{j-1} A[i] + A[j] = \sum_{i=0}^{j} A[i]$, so the invariant holds for the new $j$. 
3. **Termination:** When the loop terminates, $j \ge n$. Since $j$ starts at 0 and increases by 1 each iteration, $j = n$. The invariant says $sum = \sum_{i=0}^{n-1} A[i]$, which is the correct sum of the array. Thus, the algorithm is correct.
