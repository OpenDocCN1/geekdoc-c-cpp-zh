Assuming the private method getNodeBefore that we specified in the header file, we can use the previous algorithm to define the insertSorted method, as follows:

```
template<class ItemType>
void SortedList<ItemType>::insertSorted(const ItemType& newEntry)
{
    Node<ItemType>* newNodePtr = new Node<ItemType>(newEntry);
    Node<ItemType>* prevPtr = getNodeBefore(newEntry);

    if (isEmpty() || (prevPtr == nullptr)) // Add at beginning
        newNodePtr->setNext(headPtr);
        headPtr = newNodePtr;
    else // Add after node
        Node<ItemType>* aftPtr = prevPtr->getNext();
        newNodePtr->setNext(aftPtr);
        prevPtr->setNext(newNodePtr);
}
itemCount++;

```

**The private method getNodeBefore** We still need to implement the private method getNodeBefore to locate the node that is before or should contain the given entry. We will need two pointers as traverse the list. Clearly, we need a pointer to the current node so we can compare its entry to the desired entry. We must also retain a pointer to the previous node, because it is this pointer that the method returns. In the following implementation, these pointers are curPtr and prevPtr.

```
template<class ItemType>
Node<ItemType>* SortedList<ItemType>::getNodeBefore(const ItemType& anEntry) const
{
    Node<ItemType>* curPtr = headPtr;
    Node<ItemType>* prevPtr = nullptr;
    while ((curPtr != nullptr) && (anEntry != curPtr->getItem()))
    {
        prevPtr = curPtr;
        curPtr = curPtr->getNext();
    }
    return prevPtr;
}
```
