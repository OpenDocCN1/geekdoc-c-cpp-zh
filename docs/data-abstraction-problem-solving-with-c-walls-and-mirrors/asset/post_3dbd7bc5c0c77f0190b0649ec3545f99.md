# 19 Balanced Search Trees

## 19.1 Balanced Search Trees

As you saw in the chapter, the efficiency of the binary search tree implementation is related to its height. The operations add, remove, and get follow a path from the root of the tree to the node that contains the desired item (or, in the case of the add operation, to the node that is the parent of the new item). At each node along the path, you compare a given value to the search key in the node and determine which to search next. Because the maximum number of nodes on a path is equal to the height of the tree, the maximum number of comparisons the dictionary operations require is equal to this height.

As you know, the height of a binary search tree of n nodes ranges from a minimum of $\lfloor\log_2(n)\rfloor$ to a maximum of n. As a consequence, locating a particular item in a binary search tree requires a sequential search; thus binary search tree can be as inefficient as a sequential search. Efficiency was the primary reason for developing the binary search tree: we wanted to perform a search of a linked structure as efficiently as a sorted array. Thus, we want to optimize the behavior of the binary search tree.

What affects the height of a binary search tree? As you learned in Chapters 15 and 16, the height of the tree is sensitive to the order in which you insert or remove items. For example, a binary search tree that contains the items 10, 20, 30, 40, 50, 60, and 70. If you inserted the items into the tree in ascending order, you would obtain a binary search tree of maximum height, as shown in Figure 19-1a; on the other hand, if you inserted the items in the order 40, 20, 60, 10, 30, 50, 70, you would obtain a balanced binary search tree of minimum height, as shown in Figure 19-1b.

As you can, if you use the algorithms in Chapter 16 to maintain a binary search tree, insertions and removals can cause the tree to lose its balance and approach a linear shape. A tree is no better than a linear chain of linked nodes. For this reason, it is desirable in many applications to use one of search trees which remain balanced.
