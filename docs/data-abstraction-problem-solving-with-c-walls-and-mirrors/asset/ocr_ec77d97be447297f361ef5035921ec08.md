The operations that define the ADT binary search tree are as follows:

> Note: ADT binary search tree operations
* Test whether a binary search tree is empty.
* Get the height of a binary search tree.
* Get the number of nodes in a binary search tree.
* Get the data in a binary search tree's root.
* Insert a new item into a binary search tree.
* Remove the given item from a binary search tree.
* Remove all entries from a binary search tree.
* Retrieve the item from a binary search tree.
* Test whether a binary search tree contains a specific entry.
* Traverse the items in a binary search tree in preorder, inorder, or postorder.

For simplicity, we will insist that a binary search tree contains unique data. The following contract specifies the insertion and removal operations in more detail. The UML diagram for a class of binary trees will be almost the same as the one for a class of binary trees, so we do not write one here.

| ABSTRACT DATA TYPE: BINARY SEARCH TREE |
| DATA |
| A finite number of objects in hierarchical order |
| OPERATIONS |
| PSEUDOCODE | DESCRIPTION |
| add(newEntry) | Task: Inserts newEntry into this binary search tree so that the properties of a binary search tree are maintained. Input: newEntry is the data to be inserted. Assumes the entries in the tree are distinct and different from newEntry. Output: True if the insertion is successful, or false if not. |
 remove(anEntry) | Task: Removes the given entry from this binary search tree that the properties of a binary search tree are maintained. Input: anEntry is the entry to remove. Output: True if the removal is successful, or false if not. |

The methods isEmpty, getHeight, getNumberOfNodes, getRootData, clear, contains, preorderTraverse, inorderTraverse, and postorderTraverse have the same specifications as for a binary tree.
