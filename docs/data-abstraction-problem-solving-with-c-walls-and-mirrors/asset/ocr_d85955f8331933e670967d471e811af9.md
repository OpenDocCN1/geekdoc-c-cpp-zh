# C5.1.2 Overloading + for Concatenation

As discussed in the previous section, the operator + is used for both integer and floating-point addition. In C++, + is also used as a concatenator to append strings. This ability illustrates one of the concerns some programmers have about overloading operators—a symbol can represent several different operations. These operations are not be closely related to each other, so reading code that uses overloaded operators can be difficult

Suppose you want to maintain code else went wrote and find the following statement in a method:

```
theThing = myThing + yourThing;
```

Can you quickly determine whether the + performs scalar addition—adding two integers or floating points—or concatenates two strings? Without knowing the data type of the variables myThing and yourThing, you cannot determine what operation performs. In a well-written program, most variables are declared close to their, thus helping to clarify the symbol, but this is not always the case.
When you choose to overload an operator, you should not change the meaning of the symbol. Your definition should extend the current operation for use with a new data type—when working with lists, the concatenation definition of the + symbol applies better than scalar addition, so let's see what is involved in appending one list onto another. Let's assume that theThing, myThing, and yourThing in the previous statement are list objects.

Link-based lists. If we choose to overload the + for the list-based implementation of the ADT list, we would add the following declaration to the class definition:

```

operator+(const LinkedList<Item>& rightHandSide) const;
```
