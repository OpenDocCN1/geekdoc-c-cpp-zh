Such arrows are labeled with a message expression indicating what task object needs to perform. The message expression corresponds to the name of a method for handling task. The message expression may also include parameters necessary for performing the task. Ultimately, these parameters will correspond to method arguments. When an object finishes a task, the activation associated with that task ends. If the task returns something of interest to the calling object, a dashed arrow may be pointing back to the calling object's activation bar. You can label this arrow with the name of the variable received.

In C-1, the customer asks the bank for authorization by giving its name and identifier passed as arguments. The bank processes this message—activated by the activation bar with the bank object's lifeline—and then signals whether or not the customer has been authenticated by returning a value to the variable OK within the Customer object. Note that you should write the messages in a general, language-independent fashion. A bank class could declare the authorize message as follows:

```
class Bank {
public:
    bool authorize(string name, string identifier);
}\; // end Bank
```
