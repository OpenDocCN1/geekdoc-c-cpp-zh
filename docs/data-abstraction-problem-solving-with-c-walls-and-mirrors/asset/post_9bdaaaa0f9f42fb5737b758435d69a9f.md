## 12.3.2 Public Inheritance

A list is a container of items that you reference by position. If you maintained items in sorted order, would you have a sorted list? Ignoring name differences, most operations for the ADT list are almost the same as the ADT sorted list. The insertion and removal operations differ, however the ADT sorted list has an additional operation, getPosition.

You can insert an item into a sorted list using getPosition to determine the position in the sorted list where the new item belongs. Then you use the list's insert operation to insert the item into that position in the list. You use a similar approach to remove an item from a sorted list.

It appears that a sorted list is like ours, so let's see whether we can use public inheritance. Figure 12-7 shows the class SortedList as a descendant of LinkedList. This diagram represents inheritance and implementation in C++. SortedList inherits from LinkedList, and SortedList adds methods, the getPosition and overrides the insertion and removal operations.

The class SortedList has useful operations of the ADT list, such as getEntry, clear, isEmpty, and getLength—which inherits from the List—in addition to the methods insertSorted, removeSorted, and getPosition. However, it inherits insert and setEntry from LinkedList. A client could control the order of a sorted list. To prevent this from occurring, SortedListISA must override them.
