# A.6.1 One-Dimensional Arrays

When you decide to use an array in your program, you must declare it, and in doing so, indicate the data type of its elements as well as its size. The following statements declare a one-dimensional array, maxTemps, which contain the maximum temperatures for a week:

```
const int DAYS_PER_WEEK = 7;
double maxTemp[DAYS_PER_WEEK];
```

The bracket notation [] declares maxTemp as an array. This array can contain at most seven floating-point values.

You can refer to any of the floating-point elements in maxTemp by using an expression, which is called the index, or subscript, enclosed in brackets. In C++, array indices must have integer values from 0 to size-1, where size is the number of elements in the array. The indices for maxTemp range from 0 to DAYS_PER_WEEK - 1. For example, the fifth element in the array is maxTemp[4]. If k is an integer value of 4, maxTemp[k] is the fifth element in the array, and maxTemp[k++] accesses maxTemp[k] before adding 1 to k. Note that you use index to refer to an element in a one-dimensional array:

Use an index to specify a particular element in an array

An array index has an integer value greater than or equal to 0
