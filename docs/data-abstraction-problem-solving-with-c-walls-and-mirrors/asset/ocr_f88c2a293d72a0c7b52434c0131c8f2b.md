# 348 CHAPTER 12 Sorted Lists and Their Implementations

The ADT sorted list maintains items in sorted order

The ADT sorted list maintains its entries in sorted order. The problem of maintaining sorted data involves more than simply sorting data. You often need to insert new data item into proper, sorted list. Similarly, you often need to remove some data item. For example, suppose your university maintains an alphabetical list of the students who are currently enrolled. The registrar must add names and remove names from this list because students constantly enter and leave school. These operations should preserve the sorted order of the data.

This chapter specifies the ADT sorted list and then implements it in several ways. A major goal of this chapter is to show you we can develop a class of sorted lists from an existing class of lists.

# 12.1 Specifying the ADT Sorted List

The ADT list leaves it to the client to manage the entries in a given collection. The client can maintain the entries in any order that meets its needs. Recall that you use the `insert` operation of the ADT list, you specify both the new entry and its position within the list. The ADT sorted list differs from the ADT list that it inserts and removes items by their values and not by positions. For example, the sorted list insertion operation determines the proper position for the new entry according to its value. Since a sorted list is responsible for organizing its entries, it has no operation that inserts a new entry by position. If you were allowed to specify a new entry's position, you might destroy the order of the sorted list's entries.

> Note: The ADT sorted list is a container of items that determines and maintains the order of its entries by their values. For simplicity, we will allow the sorted list to contain duplicate items. Insisting that the sorted list contain only unique items is somewhat complicated, and we will leave this variation as an exercise.

What operations do we want for this ADT? We've already mentioned that you could add an entry to the sorted list. Since the sorted list determines the position of a new entry, you could ask the ADT for its position. That is, you could ask for the position of an existing entry or for the position in which a proposed entry would occur if you added it to the list. You could also ask the ADT for an entry at a particular position. And clearly you should be able to remove a particular entry by its value, but we could also remove an entry its position in the sorted list. We will include both of these removals.

Let's item the sorted list's operations—including common ones like getting the current number of entries—and specify them more carefully. Notice that none of the operations on a sorted list involve the position of an entry destroys the list's sorted order.

> Note: ADT sorted list operations
* Test whether a sorted list is empty.
* Get the number of entries in a sorted list.
* Insert an entry into a sorted list.
* Remove a given entry from a sorted list.
* Remove the entry at a given position from a sorted list.
* Remove all entries from the sorted list.
* Look at (get) the entry at a given position in the list.
* Get the position in a sorted list of a given entry.
