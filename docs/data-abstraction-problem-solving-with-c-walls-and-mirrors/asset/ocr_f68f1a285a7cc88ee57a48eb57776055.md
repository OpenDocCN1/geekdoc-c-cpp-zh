Consider briefly the efficiency of remove. Because the tree is stored in an array, the removal of a node requires you to swap entries rather than simply change a few pointers. These swaps may concern you, but do not necessarily indicate that the algorithm is inefficient. At most, however array entries will need to swap. After copying the item in the last node of the tree into the root, heapRebuild1 trickles this item until its appropriate place is found. This item travels down a path from the root to, at least, a leaf. Therefore, the number of items that heapRebuild1 must swap is no greater than the height of the tree.
