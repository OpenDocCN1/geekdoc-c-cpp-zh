An array-based implementation requires less memory than a link-based implementation is that it does not store explicit information about where to find the next data item, requiring less memory than a link-based implementation.

Another, more important advantage of an array-based implementation is that it can provide direct access to a specified item. For example, if you use the array to implement the ADT bag, accessing each items[0] or items[49] takes the same amount of time. That is, the access time is constant for any item.

You can access array items directly with equal access time.

On the other hand, if you use a link-based implementation, you have no disadvantage in accessing the chain that contains the ith item. To get the appropriate node, you must use pointers to traverse the linked chain until you reach the ith node. That is, you must access the first node and get to the center node, the second node and get to the pointer to the third node, and so on, until you finally access the ith node. Clearly, the time it takes to access the ith node depends on i. The type of implementation chosen will affect the efficiency of the ADT's operations.

You must traverse linked chain to access its ith node.

The time to access the ith node in a linked chain depends on i.

# SUMMARY

- 1. You can link objects—nodes—to one to form a chain of linked data. Each node contains an item and a pointer to the next node in the chain. An external pointer variable—called the head pointer—points to the first node. The last node in the chain has nullptr in its pointer, so it points to no other node.
- 2. You use the new operator to dynamically allocate a new node, whereas you use the delete operator to delete a node.
- 3. Inserting a new node at the beginning of a linked chain or deleting a node of linked chain are easier to perform insertions and deletions else in the chain. The insertion requires a change to two pointers: the new node and the head pointer. The deletion requires a change to the head pointer and an application of the delete operator to the removed node.
- 4. Unlike an array, which allows direct access to any of its elements, a linked chain requires a traversal to a particular node. Therefore, the access time for an array is constant, the access time for a linked chain depends on the position of the node within the chain.
- 5. When traversing a linked chain using the pointer variable curPtr, you must be careful not to reference curPtr after it has "passed" the last node in the chain, because it has nullptr at that point. For, the example

```cpp
while (value > curPtr->getItem())
curPtr = curPtr->getNext();
```

is incorrect if value is greater than all the data in the linked chain, because curPtr becomes nullptr. You should write

```cpp
while ((curPtr != nullptr) && (value > curPtr->getItem()))
curPtr = curPtr->getNext();
```

Because C++ uses short-circuit evaluation (see Appendix A) of logical expressions, if curPtr becomes nullptr, the expression curPtr->getItem() will not be evaluated.

# Exercises 155

- 6. A class that allocates memory dynamically needs an explicit copy constructor to copy an instance of the class. The copy constructor is invoked implicitly when you pass an object to a function by value, return an object from a valued function, or define and initialize an object. If you do not define a copy constructor, the compiler will generate one for you. A compiler-generated copy constructor is sufficient for classes that use statically allocated memory.
- 7. A class that allocates memory dynamically needs an explicit destructor. The destructor should deallocate the memory associated with the object. If you do not define a destructor, the compiler will generate one for you. A compiler-generated destructor is sufficient for classes that use statically allocated memory.
- 8. Although you can use the new operator to allocate memory dynamically for an array or a linked chain, you can increase the size of a linked chain at one time more efficiently than you can increase the size of an array. When you increase the size of a dynamically allocated array, you must copy the original array entries into the new array and then deactivate the original array.
