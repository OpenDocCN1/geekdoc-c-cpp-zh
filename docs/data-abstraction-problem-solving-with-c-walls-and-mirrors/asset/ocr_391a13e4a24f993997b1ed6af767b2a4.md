# 1.4.2 ADTs That Suggest Other ADTs

Both of the previous examples you require to represent a date, the appointment book example requires you to represent the time. C++ has date-time objects specified in ctypes that you use to represent the date and time. You can also design ADTs to represent these items in a object-oriented way. It is not unusual for the design of one ADT to suggest other ADTs. In fact, you can use one ADT to implement another ADT.

You can use an ADT to implement another ADT

This final example describes an ADT that suggests other ADTs for its implementation. Suppose you want to design a database of recipes. You can think of this as an ADT. The recipes are the data items, and some typical operations on the recipes could include the following:

```
// Inserts a recipe into the database.
+insertRecipe(aRecipe: Recipe): boolean
// Deletes a recipe from the database.
+deleteRecipe(aRecipe: Recipe): boolean
// Gets the named recipe from the database.
+getRecipe(aName: string): Recipe
```

This level of design does not include such details as where insertRecipe will place a recipe into the database.
