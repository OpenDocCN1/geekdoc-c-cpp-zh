# CHAPTER 2 Recursion: The Mirrors

You can now construct a recursive solution for computing rabbit(n), the number of pairs alive in month n. You must determine how you use rabbit(n - 1) to compute rabbit(n). Observe that rabbit(n) is the sum of the number of pairs just prior to the start of month n and the number of pairs alive in month n born at the start of month n. Just prior to the start of month n, there are rabbit(n-1) pairs of rabbits. Not all of these rabbits are sexually mature at the start of month n. Only those that were alive in month n-2 are ready to produce at the start of month n. Thus, if the number of pairs born at the start of month n is rabbit(n-2), you have the recurrence relation

The number of pairs in month n

```
rabbit(n) = rabbit(n - 1) + rabbit(n - 2)
```

This recurrence relation—like some previous examples—solves a problem by solving more than one smaller problem of the same type. This does not add much conceptual difficulty, but you must be careful when selecting the base case. The temptation is to say that rabbit(1) should be the base case because its value is 1 according to the problem's statement. But what about rabbit(2)? Applying the recurrence definition to rabbit(2) would yield

```
rabbit(2) = rabbit(1) + rabbit(0)
```

Thus, the recursive definition would need to specify the number of pairs alive in month 0—under-defined quantity.

Two base cases are necessary because there are two smaller problems

One possible solution is to define rabbit(0) to be 0, which seems artificial. A slightly more attractive alternative is to treat rabbit(2) itself as a special case with the value of 1. Thus, the recursive definition has two cases, rabbit(2) and rabbit(1). The recurrence definition is

```
rabbit(n) = { 1 if n < 2 else rabbit(n - 1) + rabbit(n - 2) 
```

The series of rabbit(1), rabbit(2), and rabbit(3), is also known as the Fibonacci sequence, models many naturally occurring phenomena.

A C++ function to compute rabbit(n) is easy to write from the previous definition:

```
/* Computes a term in the Fibonacci sequence.
 * param n is a positive integer.
 * post The given integer.
 * return The nth Fibonacci number. */
```

```
int rabbit(int n) {
  if (n < 2) {
    return 1;
  } else if (n > 2, so n - 1 > 0 and n - 2 > 0) {
    return rabbit(n - 1) + rabbit(n - 2);
  }
} // end rabbit
```
