The idea is that when the end user presses the Enter (or Return) key, the URL entered in the text box will be the HTML page that is retrieved and displayed in the WebBrowser control. To accomplish this task, use the following code for your form:

```
Public Class MainForm
    Private Sub AddressField_KeyPress(ByVal sender As Object,
        ByVal e As System.Windows.Forms.KeyPressEventArgs) Handles AddressField.KeyPress
        If e.KeyChar = Chr(13) Then
            TheBrowser.Navigate(AddressField.Text)
        End If
    End Sub
End Class
```

For this simple example, you check the key presses that are made in the AddressField TextBox control, and if the key press is a specific one — the Enter key — then you use the WebBrowser control's Navigate method to navigate to the requested page. The Navigate method can take a single String value, which represents the location of the Web page to retrieve. The example shown in Figure 29-10 shows the Wrox website.
