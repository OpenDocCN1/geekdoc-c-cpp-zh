## 自定义显示遮罩

本演示的下一部分涉及根据Windows窗体中的代码更改ElementHost内容的显示。因此，下一段代码使用几何形状在所选显示内容上叠加遮罩，从而可以为整个图像圆角。遮罩的应用基于你添加到窗体的第二个ComboBox控件。

该控件被分配了三个值，当选择其中一个值时，会触发ComboBox2.SelectedIndexChanged事件，该事件已在此代码中处理。代码遵循最佳实践，调用一个私有方法，根据所选值执行相应的操作。ApplyMask方法使用Select Case语句识别选择了三个固定遮罩中的哪一个，然后禁用裁剪区域或启用相应形状的裁剪区域。

裁剪区域是WPF控件上可用的WPF属性。Clip属性使你可以使用几何形状覆盖给定控件，从而遮住目标控件的部分区域。本示例实现了两个简单的遮罩：椭圆和矩形。选择不使用遮罩会将ElementHost1控件内Child对象的Clip属性设置为Nothing。但是，选择遮罩来屏蔽显示区域的一部分时，代码会调用两个方法之一：EllipseMask和RectMask，每个方法专注于一种几何形状。

这两个方法共享大部分逻辑，首先从ElementHost1的Child属性获取可用显示区域。然后两者都使用TextBoxMargin，让用户可以更改裁剪区域周围的边距大小。请注意，在这两种情况下，边距的应用方式与在WPF中设置边距的方式不同。

在WPF中，Margin属性被定义为控件边缘与显示边缘之间四个边各自的厚度或距离。因此，左和右、上和下的值分别相同。但在裁剪区域的情况下，代码定义的是矩形的大小。因此，矩形的大小需要考虑这样一个事实：将图像顶部向下移动10像素意味着沿边的长度需要小20像素，这样顶部的10像素与底部的10个对应像素相互抵消。这就是为什么在描述高度和宽度时边距要加倍，而在定义左上角位置时并不加倍。要实现此功能，你需要创建一个事件处理程序，其实现类似于下面代码片段所示：

```vb
Private Sub ComboBox2_SelectedIndexChanged(ByVal sender As System.Object, _
    ByVal e As System.EventArgs) _
    Handles ComboBox2.SelectedIndexChanged
    ApplyMask()
End Sub
Private Sub ApplyMask()
    Select Case ComboBox2.SelectedIndex
        Case 0
            ElementHost1.Child.Clip = Nothing
            TextBoxMargin.Enabled = False
            TextBoxRounding.Enabled = False
        Case 1
            EllipseMask()
            TextBoxMargin.Enabled = True
            TextBoxRounding.Enabled = False
        Case 2
            RectMask()
            TextBoxMargin.Enabled = True
            TextBoxRounding.Enabled = True
        Case Else
            ' Can occur if the textbox controls load before the combo box.
            ' Nothing needs to be done in that case.
    End Select
End Sub
Private Sub EllipseMask()
    Dim width As Double = ElementHost1.Child.RenderSize.Width
    Dim height As Double = ElementHost1.Child.RenderSize.Height
    Dim margin As Double = Convert.ToDouble(TextBoxMargin.Text)
    If width = 0 Then
        width = ElementHost1.Width
    End If
    If height = 0 Then
        height = ElementHost1.Height
    End If
    If (margin * 2) > height Or (margin * 2) > width Then
        ElementHost1.Child.Clip = Nothing
    Else
        ElementHost1.Child.Clip = New Windows.Media.EllipseGeometry(
            New Windows.Rect(margin, margin, _
                width - (margin * 2), height - (margin * 2)))
    End If
End Sub
Private Sub RectMask()
    Dim width As Double = ElementHost1.Width
    Dim height As Double = ElementHost1.Height
    Dim margin As Double = Convert.ToDouble(TextBoxMargin.Text)
    If (margin * 2) > height Or (margin * 2) > width Then
        ElementHost1.Child.Clip = Nothing
    Else
        Dim rect As New Windows.Media.RectangleGeometry(
            New Windows.Rect(margin, margin, _
                width - (margin * 2), height - (margin * 2)))
        rect.RadiusX = Convert.ToDouble(TextBoxRounding.Text)
        rect.RadiusY = rect.RadiusX
        ElementHost1.Child.Clip = rect
    End If
End Sub
Private Sub TextBoxMargin_TextChanged(ByVal sender As System.Object, _
                                      ByVal e As System.EventArgs) _
                                      Handles TextBoxMargin.TextChanged
    Dim margin As Double
    If Double.TryParse(TextBoxMargin.Text, margin) Then
        ApplyMask()
    Else
        TextBoxMargin.Text = 0
    End If
End Sub
Private Sub TextBoxRounding_TextChanged(ByVal sender As System.Object, _
                                        ByVal e As System.EventArgs) _
                                        Handles TextBoxRounding.TextChanged
    Dim margin As Double
    If Double.TryParse(TextBoxRounding.Text, margin) Then
        ApplyMask()
    Else
        TextBoxRounding.Text = 0
    End If
End Sub
```

> *来自Form1的代码片段*

除了边距之外，请注意在RectMask函数中，代码还将TextBoxRounding控件中的值应用于矩形的RadiusX和RadiusY属性。这些属性使矩形的角变得圆润，因此当选择矩形遮罩时，用户可以输入一个值来改变圆角程度。

最后，前面的代码块还包括两个额外的事件处理程序，分别对应窗体上的两个文本框。第一个处理与边距宽度相关的事件，第二个事件与矩形遮罩的圆角半径相关。两种情况下，它们都调用同一个ApplyMask方法，该方法在你选择遮罩时被调用。

现在可以生成并运行你的应用程序了。生成并运行控件后，你应该会看到如图16-3所示的显示效果。表面上看，这个应用程序可以工作，允许你应用不同的遮罩并调整其大小。请注意，你现在是在Windows Forms应用程序中修改你的WPF控件。

然而，应用一个遮罩然后调整主窗体的大小。请注意，即使图像已调整大小，遮罩仍保持静止。你的应用程序没有识别到ElementHost1控件大小的变化，也没有重新计算遮罩大小和位置的需要。

## 使用WPF控件的映射属性

这个问题有几个可能的解决方案；然而，就本章而言，重点在于演示Windows Forms集成库的功能，这里描述的解决方案使用控件上的一个映射属性。

访问WPF控件映射属性的能力是此库的功能之一，为你提供了更大的灵活性。ElementHost1控件上可用的属性之一——PropertyMap集合——使你可以选择一个或多个ElementHost1属性，并实质性地注册自定义事件处理程序。这不是传统Windows Forms意义上的事件处理程序，而是分配一个委托，当该属性发生更改时调用该委托。

第一步是转到本章前面描述的加载事件，取消注释调用AddPropertyMapping方法的行。取消注释后，添加下面代码块中显示的函数。其中第一个函数实际上就是自定义函数AddPropertyMapping。该函数只是调用PropertyMap集合上的Add方法，以Windows.Forms.Integration库中的PropertyTranslator形式分配一个新委托，该委托将在ElementHost1控件的Size属性更改时被调用。请注意，通过在Form1_Load事件处理程序末尾分配此值，你的应用程序现在将在控件大小更改时进行此调用：

```vb
' The AddPropertyMapping method assigns a custom
' mapping for the Size property.
Private Sub AddPropertyMapping()
    ElementHost1.PropertyMap.Add( _
        "Size", _
        New Integration.PropertyTranslator(AddressOf OnEHSizeChange))
End Sub
''' <summary>
''' Called when the ElementHost control's size is changed
''' </summary>
''' <param name="h"></param>
```
