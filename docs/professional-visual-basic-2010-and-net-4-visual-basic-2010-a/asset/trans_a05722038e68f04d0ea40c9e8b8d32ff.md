## Char和Byte

Visual Basic的默认字符集是Unicode。因此，当变量被声明为Char类型时，Visual Basic会创建一个两字节的值，因为默认情况下，Unicode字符集中的所有字符都需要两个字节。Visual Basic支持以三种方式声明字符值。在字符串字面量后放置`&c`会通知编译器该值应被视为字符，也可以使用`Chr`和`ChrW`方法。下面的代码片段展示了这三种方式的工作方式相似，区别在于`Chr`和`ChrW`方法可接受的有效输入值范围不同。`ChrW`方法基于宽字符输入，允许更广泛的值范围。

```
Dim chrLtr_a As Char = "a"c
Dim chrAsc_a As Char = Chr(97)
Dim chrAsc_b as Char = ChrW(98)
```

为了将字符转换为适合ASCII接口的字符串，运行时库需要验证每个字符的值，以确保其处于有效范围内。这对于某些串行数组可能会产生性能影响。幸运的是，Visual Basic支持Byte值类型。该类型包含从0到255的值，恰好与ASCII字符集的范围匹配。当与使用ASCII的系统交互时，最好使用Byte数组。运行时知道无需对Byte数组执行Unicode到ASCII的转换，因此系统之间的接口运行速度会显著提高。

在Visual Basic中，Byte值类型期望的是数值。因此，要将字母“a”赋值给Byte，你必须使用相应的字符代码。获取字母数值的一种方法是使用`Asc`方法，如下所示：

```
Dim bytLtrA as Byte = Asc("a")
```

## DateTime

Visual Basic的Date关键字一直支持同时包含日期和时间的结构。实际上，你可以使用DateTime和Date类型来声明日期值。请注意，Visual Basic内部不再将日期值存储为Double；然而，它提供了关键的方法，可以将当前的内部日期表示转换为旧的Double类型。`ToOADate`和`FromOADate`方法在从Visual Basic早期版本迁移期间提供向后兼容性。

Visual Basic还提供了一组共享方法，用于提供一些常见日期。共享方法的概念将在下一章（讲述对象语法）中更详细地描述，但简而言之，即使你不创建类的实例，也可以使用共享方法。对于DateTime结构，`Now`方法返回包含本地日期和时间的Date值。此方法自Visual Basic 6.0以来没有变化，但新增了`Today`和`UtcNow`方法。这些方法可用于分别使用当前本地日期，或基于协调世界时（也称为格林尼治标准时间）的日期和时间来初始化Date对象。你可以使用这些共享方法来初始化你的类，如以下代码示例所示：

```
Private Sub Dates()
    Dim dtNow = Now()
    Dim dtToday = Today()
    TextBox1.Text = dtNow & Environment.NewLine
    TextBox1.Text &= dtToday.ToShortDateString & Environment.NewLine
```

```
TextBox1.Text &= DateTime.UtcNow() & Environment.NewLine
Dim dtString = #12/13/2009#
TextBox1.Text &= dtString.ToLongDateString()
End Sub
```

## 引用类型（类）

Visual Basic的许多强大功能都体现在对象中。对象由其类定义，类描述了该类实例支持的数据、方法和其他属性。.NET Framework类库中提供了数千个类。

当代码从类实例化对象时，所创建的对象是引用类型。请记住，值类型和引用类型中包含的数据存储在不同的位置，但这并不是它们之间的唯一区别。类（引用类型的典型称呼）具有额外的能力，例如支持受保护的方法和属性、增强的事件处理能力、构造函数和终结器；并且可以通过继承使用自定义基类进行扩展。类还可以用于定义诸如“=”和“+”之类的运算符如何作用于类的实例。

本节旨在向你介绍一些常用的类，并补充你已经掌握的有关常见值类型的知识。本节将探讨Object、String、DBNull和Array类的特性，以及System.Collections命名空间中的Collection类。

## Object类

如前所述，Object类是.NET中所有类型（无论是值类型还是引用类型）的基类。从根本上说，每个变量都是对象，并且可以如此对待。

由于Object类是所有类型的基础，你可以将任何变量转换为对象。引用类型保持其当前的引用和实现，但被泛化处理；而值类型则从其当前在栈上的位置取出，并放入堆中，同时与Object关联一个内存位置。这个过程称为“装箱”，因为你正在将值从一个位置运送到另一个位置。装箱将在第8章中更详细地讨论。

关于Object，你需要理解的关键补充是：如果在类定义中实现了ToString，那么即使将对象实例转换为Object类型，你的自定义方法仍将被调用。下面的片段展示了如何创建通用对象。

```
Dim objVar as Object

objVar = Me

CType(objVar, Form).Text = "New Dialog Title Text"
```

然后，该Object被赋值为当前Visual Basic窗体实例的副本。为了访问原始Form类的Text属性，必须将Object从其声明的类型Object强制转换为其实际类型（Form），后者支持Text属性。CType命令（稍后介绍）接受对象作为其第一个参数，并接受类名（不带引号）作为其第二个参数。在这种情况下，当前实例变量是Form类型；通过转换此变量，代码可以引用当前窗体的Text属性。
