The most common and preferred approach is to have a single class per file. This is because the Visual Studio 2010 Solution Explorer and the code-editing environment are tailored to make it easy to navigate from file to file to find code. For instance, if you create a single class file with all these classes, the Solution Explorer simply displays a single entry, as shown in Figure 2-13.
