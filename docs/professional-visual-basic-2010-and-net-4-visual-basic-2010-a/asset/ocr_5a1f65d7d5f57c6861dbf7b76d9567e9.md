Of course, at this point you haven’t actually added any code to your document, so switch to the Code view. By default, VSTO inserts two event handlers when your project is created. Note that as long as the .docx file is displayed, you can’t access the ThisDocument.vb file for that document. To switch the view, close the default .docx display and then right-click on the ThisDocument.vb file in the Solution Explorer and select Code View from the context menu.
