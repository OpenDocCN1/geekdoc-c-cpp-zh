The Grid control also offers proportional sizing, so you can size the grid’s rows and columns proportionally. To enable proportional sizing, you simply set the Height or Width to a value like 2*, which specifies that a given column should be twice the size of the other columns that are set to 1*. For example, you could define your grid’s rows and columns like this:
