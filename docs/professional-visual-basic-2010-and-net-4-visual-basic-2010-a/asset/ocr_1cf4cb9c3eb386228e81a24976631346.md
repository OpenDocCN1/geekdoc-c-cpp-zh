# Understanding ParallelLoopState

The instance of ParallelLoopState (loopState) offers two methods to cease the execution of a Parallel.For or Parallel.ForEach:

+   Break — Communicates that the parallel loop should cease the execution beyond the current iteration, as soon as possible

+   Stop — Communicates that the parallel loop should cease the execution as soon as possible
