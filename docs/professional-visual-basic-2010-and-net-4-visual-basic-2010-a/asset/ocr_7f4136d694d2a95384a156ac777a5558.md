In this case you should only have a single master page available in the dialog, though it is possible to have as many master pages as you wish in a single project. Select the MasterPage.master page and click OK.

</asp:Content>
<asp:Content ID="Content3" ContentPlaceHolderID="ContentPlaceHolder2" Runat="Server">

This file is quite a bit different from a typical .aspx page. First, there is none of the default HTML code, script tags, and DOCTYPE declarations. Second, note the addition of the MasterPageFile attribute in the Page directive. This new attribute makes the association to the master page that will be used for this content page. In this case, it is the MasterPage.master file created earlier.
