Change the control used to display the sales table to a DetailsView, the control for the ord_num column to a Label, and the controls for the stor_id and title_id to a ComboBox (see Figure 12-15). This enables you to create a form displaying a single record at a time, with drop-down fields for the two columns being synchronized.

9. You can now drag the sales table onto the form from the Data Sources window. This creates the DetailsView control, as well as a BindingNavigator. It also creates the connections necessary for navigating through the data. Drag the stores table from the Data Sources window onto the stor_id ComboBox. This adds a connection to the local data. It also sets the visible text of the ComboBox to the name of each store, rather than simply displaying the store's id value. Repeat this with the titles table and the title_id ComboBox. The form should now look similar to what is shown in Figure 12-16, and you should be able to run the application and navigate through the data.

| PROPERTY | VALUE |
|---|---|
| Name | SyncButton |
| DisplayStyle | Text |
| Text | Sync |
