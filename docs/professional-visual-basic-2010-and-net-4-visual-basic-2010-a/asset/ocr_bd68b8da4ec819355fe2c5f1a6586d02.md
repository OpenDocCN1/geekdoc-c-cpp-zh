# MICROSOFT AJAX (ASP.NET AJAX)

In Web development, Ajax (asynchronous JavaScript and XML) is a term that signifies the capability to build rich, interactive applications. These applications contain client-side code that responds to user interactions by making asynchronous Web service calls via the XMLHttpRequest object and then updating areas of the page using the Document Object Model (DOM). Because the Web service calls are made asynchronously, the page remains responsive to the user throughout the process.
