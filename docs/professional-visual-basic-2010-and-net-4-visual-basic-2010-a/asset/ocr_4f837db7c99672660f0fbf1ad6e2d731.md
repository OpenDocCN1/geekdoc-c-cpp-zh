The Server class from the SMO works similarly to the SqlCommand class you may have used when accessing SQL Server (and if not, you will in Chapter 10). It enables you to execute a SQL script to create database objects. As with other data access, it requires an open connection to the database: In this case, the testdata connection string is defined in an app.config file as follows:
