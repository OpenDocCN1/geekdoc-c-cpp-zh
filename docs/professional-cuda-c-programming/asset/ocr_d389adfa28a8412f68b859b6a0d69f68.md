The global array index is adjusted accordingly, as below, because you only need half as many thread blocks to process the data set. Note that this implies warp- and block-level parallelism is exposed to the device for the same data set. Figure 3-25 illustrates the data access for each thread.

```
unsigned int idx = blockIdx.x * blockDim.x * 2 + threadIdx.x;
int *idata = g_idata + blockIdx.x * blockDim.x * 2;
```
