With these insights, a next step is to implement an overlap plan. In the case of crypt, this can be accomplished by dividing the input into smaller blocks and placing one block at a time to the device in separate streams. Then, asynchronous cudaMemcpyAsync and kernel launches can be used for each block. Because these operations are placed in different CUDA streams, the CUDA runtime will execute them in any order, enabling overlap between computation and communication, and better utilization.
