Compile the source with the following command:

```
$ nvcc -O3 -arch=sm_20 sumArrayZeroCopy.cu -o sumZeroCopy
```

Compare the time for the sumArraysZeroCopy kernel to the sumArrays kernel. When processing 1024 elements, the estimated time of the kernel running from zero-copy memory is 2.31 times slower than the kernel using only device memory. Notice that the time reported to transfer data from device to host (DtoH) reports time from both kernels because both use cudaMemcpy to update the host with the results from the calculation performed on the device.
