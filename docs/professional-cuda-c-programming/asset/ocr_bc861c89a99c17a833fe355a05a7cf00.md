# Exchange Values Using Array Indices Across a Warp

In the preceding kernel, the array elements exchanged by each shuffle operation are from the same offset in each thread's local array. If you want to swap elements between two threads at different offsets in their respective arrays, you require a swap function based on the shuffle instruction.

The following function swaps pairs of values between two threads. The boolean variable pred used to identify the first calling thread in a pair of threads that are exchanging data. The data elements to be swapped are by offset firstIdx in the first thread, and secondIdx in the second. The first calling thread starts swapping the elements at firstIdx only in its local array. A butterfly exchange is performed on the local index between two threads. Finally, the thread swaps the element received in secondIdx back to firstIdx.

```
inline __device_
void swap(int *value, int laneIdx, int mask, int firstIdx, int secondIdx) {
    bool pred = (laneIdx % mask + 1) == 0;
    if (pred) {
        int tmp = value[firstIdx];
        value[firstIdx] = value[secondIdx];
        value[secondIdx] = tmp;
    }

    value[secondIdx] = __shfl_xor(value[secondIdx], mask, BDIM);
}
```
