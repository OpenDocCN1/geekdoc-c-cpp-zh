argument has been added. At each nested invocation the child size is reduced to half of its parent size, the parent block dimension must be passed to the nested grid. This allows each thread to calculate the correct global memory offset for the first of the workload. Note that in this implementation all idle threads are removed from kernel launch, compared to the first implementation where half of all threads are idling during kernel execution at each level. This will free up half of the compute resources consumed by the first kernel as to allow more threads to be active.

```
global__ void gpuRecursiveReduce2(int *gidata, int *godata, int iStride,
 const int iDim) {
 // convert global data pointer to the local pointer of this block
 int *idata = gidata + blockIdx.x*idata;
 // stop condition
 if (iStride == 1 && idata.x == 0) {
  godata[blockIdx.x] = idata[0]+idata[1];
  return;
 }
 // in place reduction
 idata[threadIdx.x] += idata[threadIdx.x + iStride];
 // nested invocation to generate child grids
 if(threadIdx.x == 0 && blockIdx.x == 0) {
  gpuRecursiveReduce2<<gridDim.x,iStride/2,2iDim>>(
  g_idata,g_godata,iStride/2,iDim);
 }
}
```
