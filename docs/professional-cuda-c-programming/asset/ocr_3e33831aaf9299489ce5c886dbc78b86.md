An example of a nine-stencil is the eighth-order centered formula for the first derivative of a function f of a real variable at a point x. While it is important to understand the application of this formula, simply recognize that it takes as input nine points described above and produces a single output. This formula will be used as an example stencil during this section.

```
f'(x) = c_4(f(x+4h) - f(x-4h)) + c_3(f(x+3h) - f(x-3h))
c_2(f(x+2h) - f(x-2h)) + c_1(f(x+h) - f(x-h))
```

Applying this formula across a 1D array is data parallel operation that maps well to CUDA. You assign a position x to each thread and have calculate f'(x). You can follow along with this code by downloading constantStencil.cu from wrxx.com.

Now, where constant memory can be used in this stencil computation? In the case of the preceding stencil formula, the coefficients c0, c1, c2 and c3 are same across all threads and are never modified. They make excellent candidates for constant memory because they are read-only and exhibit a broadcast access pattern: Every thread in a warp fetches the same constant memory at the same time.

The following kernel implements a 1D stencil calculation based on the preceding formula. Each thread takes nine points to calculate one point, you will want to use shared memory to cache data in order to reduce redundant access to global memory.

```
__shared float smem[BDIM + 2 * RADIUS];
```

RADIUS defines the number of points on each side of a point x that are used to calculate its value. For this example, RADIUS is defined as four to nine-point stencil: Four points on either side of x plus the value at point x. As illustrated in Figure 5-19, each block has a halo of RADIUS elements in its left and right boundaries.

Calculating the index to access global memory can be done:

```
int idx = blockDim.x * threadIdx.x;
```

Calculating the index for each thread to access shared memory is done as follows: 

```
int sidx = threadIdx.x + RADIUS;
```

While reading data from global memory to shared memory, the first four threads are responsible for reading data from the halo on the left and the halo on the right into shared memory, as follows:

```
if (threadIdx.x < RADIUS) {
smem[sidx - RADIUS] = in[idx - RADIUS];
smem[sidx + BDIM] = in[idx + BDIM];
}
```
