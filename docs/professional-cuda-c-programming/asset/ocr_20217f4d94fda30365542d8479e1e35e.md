Then, you create a new kernel to sum the matrix with a 2D thread block:

```
__global void sumMatrixOnGPU2(float *MatA, float *MatB, float *MatC,
    int nx, int ny) {
    unsigned int ix = threadIdx.x + blockIdx.x * blockDim.x;
    unsigned int iy = threadIdx.y + blockIdx.y * blockDim.y;
    unsigned int idx = iy*nx + ix;

    if (ix < nx && iy < ny) {
        MatC[idx] = MatA[idx] + MatB[idx];
    }
}
```

The key to this kernel is the step mapping each thread from its thread index to the global linear memory index, as illustrated in Figure 2-12.
