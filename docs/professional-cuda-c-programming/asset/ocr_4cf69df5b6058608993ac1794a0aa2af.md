# Example of Misaligned Writes

To verify the effect of misalignment on memory store efficiency, modify the vector addition kernel as follows. Two different indices are used: Index k is shifted by given offset, but i is not (and therefore result in aligned accesses). Loading from arrays A and B uses the aligned index, causing memory load efficiency. Writing to array C, likely causing misaligned writes depends

```
global void writeOffset(float *A, float *B, float *C,
const int n, int offset {
  unsigned int i = blockDim.x * blockIdx.x + threadIdx.x;
  unsigned int k = i + offset;
  if (k < n) C[k] = A[i] + B[i];
}
```

The host vector addition code needs to be modified to match these:

```
void sumArraysHost(float *A, float *B, float *C, const int n,
int offset) {
  for (int idx = offset, k = 0; idx < n; idx++, k++) {
    C[idx] = A[k] + B[k];
  }
}
```

The main function is nearly identical to the one when studying misaligned loads. You can download the full code example in writeSegment.cu from Wrox.com.

Compile the code with the following command, and run it.

```
nvcc -03 -arch=sm_20 writeSegment.cu -o writeSegment
```
