
阐述了如何通过使用 CUDA 感知 MPI 结合 GPUDirect RDMA 在 GPU 加速计算集群上扩展应用程序，以实现近线性的性能扩展性。

**第 10 章：实现考虑** 讨论了 CUDA 开发过程以及各种由分析驱动的优化策略。它演示了如何使用 CUDA 调试工具调试内核（kernel）错误和内存错误。它还提供了一个将旧 C 应用程序迁移到 CUDA 的案例研究，通过分步骤的说明帮助巩固你对该方法的理解，使该过程可视化，并演示相关工具。

# 如何使用本书

本书不需要任何 GPU 或并行编程经验。在开始之前，如果你具备 Linux 基础经验将是最好的。为了运行书中的所有示例，理想的环境是：

- 一个 Linux 系统
- 一个 C/C++ 编译器
- 安装了 CUDA 6.0 Toolkit
- NVIDIA Kepler GPU

然而，大多数示例可以在 Fermi 设备上运行，但某些使用 CUDA 6.0 特性的示例可能需要 Kepler GPU。这些示例中的大多数可以使用 CUDA 5.5 进行编译。

# CUDA TOOLKIT 下载

你可以从 https://developer.nvidia.com/cuda-toolkit 下载 CUDA 6.0 Toolkit。
CUDA Toolkit 包含用于 NVIDIA GPU 的编译器、CUDA 数学库以及用于调试和优化应用程序性能的工具。你还会找到编程指南、用户手册、API 参考以及其他文档，帮助你开始使用 GPU 加速你的应用程序。
