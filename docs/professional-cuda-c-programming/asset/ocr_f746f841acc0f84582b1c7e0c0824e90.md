For sake, most of the examples in this book have used a single GPU. In this chapter, you will gain experience in multi-GPU programming: scaling your application across multiple GPUs within a compute node, or across multiple GPU-accelerated nodes. CUDA provides a number of features to facilitate multi-GPU programming, including multi-device management from one or more processes, direct access to other devices' memory using Unified Virtual Addressing (UVA) and GPUDirect, and computation-communication overlap multiple devices using streams and asynchronous functions. In this chapter, you will learn the skills to:

+   - Manage and execute kernels on multiple GPUs.
- Overlap computation and communication across multiple GPUs.
