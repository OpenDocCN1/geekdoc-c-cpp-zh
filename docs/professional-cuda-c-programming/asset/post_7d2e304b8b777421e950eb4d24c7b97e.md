
Zero-copy memory is pinned (non-pageable) memory that is mapped to the device address space.
You can create a mapped, pinned cudaHost memory region with the following function:

```
cudaError_t cudaAlloc(void **pHost, size_t count, unsigned int flags);
```

This function allocates count bytes of host memory that is page-locked and accessible to the device.
Memory allocated by this function must be freed with cudaFreeHost. The flags parameter enables further configuration of special properties of the allocated memory:

- cudaHostAllocDefault
- cudaHostAllocPortable
- cudaHostAllocMapped

cudaHostAllocDefault makes the behavior of cudaHostAlloc identical to cudaMallocHost.
Setting cudaHostAllocPortable returns pinned memory that can be used by all CUDA contexts, not just the one that performed the allocation. The flag cudaHostAllocWriteCombined returns write-combined memory, which can be transferred over the PCI Express bus more quickly on some system configurations but cannot be read efficiently by most hosts. Therefore, write-combined memory is a good option for buffers that will be written by the host and read by the device either mapped pinned memory or host-to-device transfers. The most relevant flag to zero-copy memory is cudaHostAllocMapped, which returns memory that is mapped into the device address space.

You can obtain the device pointer memory using the following function:

```
cudaError_t cudaGetDevicePointer(void **Device, void *pHost, unsigned int flags);
```

This function returns a pointer to device memory which can be referenced by the device to access mapped, pinned memory. Flag is reserved for future use. If not, it must be set to zero.

Using zero-copy memory as a supplement to device memory with frequent read/write operations will significantly slow performance. Because every memory transaction to mapped memory must pass over the PCIe bus, a significant amount of latency is added when compared to global memory. You can confirm the performance of zero-copy memory using the sumArrays kernel that you used in Chapter 2:

```
__global void sumArraysZeroCopy(float *A, float *B, float *C, const int n) {
  int i = blockIdx.x * blockDim.x + threadIdx.x;
  if (i < n) C[i] = A[i] + B[i];
}
```

To test the performance of zero-copy read operations, you allocate A and B as zero-copy memory, and allocate C in device memory. The main function is provided in Listing 4-3. You can download the source code in sumArrayZeroCopy.cu from Wrox.com.

The main function contains two parts: In the first part, you load data from and store to device memory; and in the second part, you load data from zero-copy memory, and store to device memory. At the beginning, you also need to check if the device supports mapped pinned memory.

To allow the kernel to read from zero-copy memory, you need to allocate arrays A and B as mapped pinned memory. You can then directly initialize arrays A and B on the device, and not need to transfer them to device memory. Next, you obtain the device pointer of the mapped pinned memory for kernel use. Once the memory is allocated and initialized, you invoke the kernel.

# LISTING 4-3: Sum arrays with zero-copy memory (sumArrayZerocopy.cu)
(main function listed)

```
int main(int argc, char **argv) {
    // part 0: set up device and array
    // set up device
    int dev = 0;
    cudaSetDevice(dev);

    // get device properties
    cudaDeviceProp deviceProp;
    cudaGetDeviceProperties(&deviceProp, dev);

    // check if supported memory
    if (!deviceProp.canMapHostMemory()) {
        printf("Device %d does not support mapping CPU host memory!\n", dev);
        cudaDeviceReset(0);
        exit(EXIT_SUCCESS);
    }

    // set up size of vectors
    int ipower = 10;
    if (argc > 1) ipower = atoi(argv[1]);
    int nElem = 1<<ipower;
    size_t nbytes = nElem * sizeof(float);
    if (ipower < 18) {
        printf("Vector size %d power %d nbytes %.3f KB\n", nElem, ipower, (float)nbytes/(1024.0));
    } else {
        printf("Vector size %d power %d nbytes %.3f MB\n", nElem, ipower, (float)nbytes/(1024.0*1024.0));
    }

    // part 1: using device memory
    // malloc host memory
    float *h_A, *h_B, *hostRef, *gpuRef;
    h_A = (float *)malloc(nbytes);
    h_B = (float *)malloc(nbytes);
    hostRef = (float *)malloc(nbytes);
    gpuRef = (float *)malloc(nbytes);

    // initialize data at host side
    initialData(h_A, nElem);
    initialData(h_B, nElem);
    memset(hostRef, 0, nbytes);
    memset(gpuRef, 0, nbytes);

    // add vector at host side for result checks
    sumArraysOnHost(h_A, h_B, hostRef, nElem);

    // malloc device global memory
    float *d_A, *d_B, *d_C;
    cudaMalloc((float**)&d_A, nbytes);
    cudaMalloc((float**)&d_B, nbytes);
    cudaMalloc((float**)&d_C, nbytes);

    // transfer data from host to device
    memcpy(d_A, h_A, nbytes, cudaMemcpyToDevice);
    memcpy(d_B, h_B, nbytes, cudaMemcpyToDevice);

    // set up execution
    int ilen = 512;
    dim3 block(ilen);
    dim3 grid((nElem+block.x-1)/block.x);

    // invoke kernel at host side
    sumArrays<<<grid, block>>>(d_A, d_B, d_C);

    // copy kernel result back to host side
    memcpy(gpuRef, d_C, nbytes, cudaMemcpyDeviceToHost);

    // check device memory
    checkResult(hostRef, gpuRef, nElem);
    cudaFree(d_A);
    cudaFree(d_B);
    free(h_A);
    free(h_B);

    // part 2: using zerocopy memory for array A B
    // allocate memory
    int flags = cudaHostAllocMapped;
    cudaMalloc((void**)&h_A, nbytes, flags);
    cudaMalloc((void**)&h_B, nbytes, flags);

    // initialize data at host side
    initialData(h_A, nElem);
    initialData(h_B, nElem);
    memset(hostRef, 0, nbytes);
    memset(gpuRef, 0, nbytes);

    // pass the pointer to device
    cudaGetDevicePointer((void**)&d_A, h_A, 0);
    cudaGetDevicePointer((void**)&d_B, h_B, 0);

    // add host to host side for result checks
    sumArraysOnHost(h_A, h_B, hostRef, nElem);

    // executeZeroCopy with zero copy memory
    sumArraysZeroCopy<<<grid, block>>>(d_A, d_B, d_C);

    // copy kernel result back to host side
    memcpy(gpuRef, d_C, nbytes, cudaMemcpyDeviceToHost);

    // check device results
    checkResult(hostRef, gpuRef, nElem);

    // free memory
    cudaFree(d_C);
    cudaFreeHost(h_A);
    cudaFreeHost(h_B);
    free(hostRef);
    free(gpuRef);

    // reset device
    cudaDeviceReset();
    return EXIT_SUCCESS;
}
```
