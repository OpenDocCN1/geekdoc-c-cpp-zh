A kernel calls asynchronously with respect to the host thread. When a kernel is invoked, it returns to the host side immediately. You can call the following function to force the host application to wait for all kernels to complete.

```
cudaError_t cudaSynchronize();
```

CUDA runtime APIs perform an implicit synchronization between the host and the device. When you use cudaMemcpy to copy data between the host and device, implicit synchronization of the host is performed by the cuda to wait for the data to complete.

```
cudaError_t cudaMemcpy(void* dst, void* src, size_t count, cudaMemcpyKind kind);
```

It starts after all previous kernel calls have been completed. When the copy is finished, control returns to the host side immediately.

> ASYNCHRONOUS BEHAVIORS
Unlike a C function, all CUDA kernel launches are asynchronous. Control returns to the CPU immediately after the CUDA kernel is invoked.

# Writing Your Kernel

A kernel function is the code to be executed on the device side. In a kernel function, you define the computation for a single thread, and the data access for that thread. When the kernel is called, many different threads perform the same computation in parallel. A kernel is defined using the __global__ declaration specification as follows:
__global__ void kernel_name(argument list);
