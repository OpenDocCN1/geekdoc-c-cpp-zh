# Hands-On with CUDA-GDB

To get some-hand experience with cuda-gdb, download the example debug-segfault.cu from Wrox.com. You will use it to experiment with debugging an invalid memory access in CUDA. First, build debug-segfault.cu using the Makefile, which will set the flags -g and -G. Next, load the application into cuda-gdb:

```
$ cuda-gdb ./debug-segfault
...
(cuda-gdb)
```

Use the run command to launch debug-segfault. It does not take any command-line arguments:
(cuda-gdb) run
