You can launch a kernel in a stream only if the device associated with that stream is the current device. You can record an event in a stream only if the device associated with that stream is the current device.

A memory copy can be issued in a stream at any time, regardless of what device it is associated with what the current device is. You can also query or synchronize any event or stream, if they are not associated with the current device.
