# Implementing Inter-Node MPI Communication

The following code segment illustrates the skeleton of a single MPI program that sends and receives a single message before synchronizing across all nodes and exiting.

```
int main(int argc, char *argv[]) {
    // initialize the MPI environment
    int rank, nprocs;
    MPI_Comm_size(MPI_COMM_WORLD, &nprocs);
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);

    // transmit messages with MPI calls
    MPI_Send(sbuf, size, MPI_CHAR, 100, MPI_COMM_WORLD);
    MPI_Recv(rbuf, size, MPI_CHAR, 0, 100, MPI_COMM_WORLD, &reqstat);

    // synchronize across nodes
    MPI_Barrier(MPI_COMM_WORLD);

    // clean up the MPI environment
    MPI_Finalize();

    return EXIT_SUCCESS;
}
```

Then, bidirectional data transfer between two compute nodes can be performed using non-blocking MPI send and receive functions:

```
// If this is the first MPI process
if(rank == 0) {
    // Repeatedly
    for (int i = 0; i < nRepeat; i++) {
        // Asynchronously receive bytes from other_proc into rbind
        MPI_Recv(rbuf, size, MPI_CHAR, other_proc, 10, MPI_COMM_WORLD, &reqstat);
        // Asynchronously send bytes to other_proc from sbuf
        MPI_Send(sbuf, size, MPI_CHAR, other_proc, 100, MPI_COMM_WORLD, &reqstat);
    }
    // Wait for the send to complete
    MPI_Waitall(1, &send_request, &reqstat);
    // Wait for the receive to complete
    MPI_Waitall(1, &recv_request, &reqstat);
}
```
