# Pinned Memory

Allocated host memory is by default pageable, which is subject to page fault operations that move data in virtual host memory to different physical locations directed by the operating system. Virtual memory offers the illusion of much more memory than is physically available, just as the L1 cache offers the illusion of much more on-chip memory than is physically available.
