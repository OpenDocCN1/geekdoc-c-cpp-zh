# Compiling and Executing

You can download the file simpleMultiGPU containing the full multi-GPU vector addition from Wrox.com. Compile it with the following command:

```
$ nvcc -O3 simpleMultiGPU.cu -o simpleMultiGPU
```

A sample output of simpleMultiGPU is:

```
$ ./simpleMultiGPU
> ./simpleMultiGPU with 2 CUDA-capable devices
> total array size: 16M, 2 devices with each device handling 8M
GPU time elapsed: 35.35ms
```

You can try running with only one GPU by passing 1 as a command-line option, as follows:

```
$ ./simpleMultiGPU 1
> ./simpleMultiGPU with 2 CUDA-capable devices
> total array size: 16M, 1 devices with each device handling 16M
GPU time elapsed: 42.25ms
```

While the elapsed is reduced by half when you double the number of GPUs being used, a significant amount of performance is still gained.

You can obtain more about each device's behavior using nvprof:

```
$ nvprof --print-gpu-trace ./simpleMultiGPU
```
