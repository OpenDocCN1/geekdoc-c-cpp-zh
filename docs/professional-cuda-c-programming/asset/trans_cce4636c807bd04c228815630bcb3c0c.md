
用于主机（host）和设备（device）之间传输数据的函数是 `cudaMemcpy`，其函数签名如下：

```

cudaMemcpyKind kind )
```

该函数将字节从 `src` 指向的源内存区域拷贝到 `dst` 指向的目标区域，方向由 `kind` 指定，其中 `kind` 取自以下类型之一：

- cudaMempyHostToHost
- cudaMempyHostToDevice
- cudaMempyDeviceToHost

```

```

否则，它返回：

```

```

```

```
