spending computing, you may be able to hide the latency of peer-to-peer copies that pass through host memory by overlapping it with device computation.

With peer-to-peer access enabled, the following code snippet performs a ping-pong synchronous copy between devices one hundred times. If peer-to-peer access was success-fully enabled on all devices, the data transfers pass directly over the PCIe bus without host

```
// ping pong unidirectional gmem copy
cudaEventRecord(start, 0);
for (int i = 0; i < 100; i++) {
    if (i % 2 == 0) {
        cudaMemcpy(d_src[1], d_src[0], iBytes, cudaMemcpyDeviceToDevice);
    } else {
        cudaMemcpy(d_src[0], d_src[1], iBytes, cudaMemcpyDeviceToDevice);
    }
}
```

Note that there is no device switching before the memory because memory copies across devices do not require you to explicitly set a current device. If you specify a device before a memory copy, it will not affect its behavior.

To measure transfer performance between devices, start and stop events are recorded on the same device, wrapping the ping-pong memory copies. cudaElapsedTime is used to calculate the elapsed time between events.

```
cudaDevice(0);
cudaEventRecord(start, 0);
for (int i = 0; i < 100; i++) {
}
cudaDevice(0);
cudaEventRecord(stop, 0);
cudaEventSynchronize(stop);
```

```
float elapsed_time_ms;
cudaEventElapsedTime(elapsed_time_ms, start, stop);
```

Then, the bandwidth achieved by this ping-pong test can be estimated as follows:

```
elapsed_time_ms = 100.00;
printf("Ping-pong unidirectional cudaMemcpy: \t%.2f ms\n", elapsed_time_ms);
printf("performance: %.2f GB/s\n", iBytes / (elapsed_time_ms * 1e6));
```
