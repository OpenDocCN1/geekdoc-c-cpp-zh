The function printThreadInfo is used to print out the following information about each thread:

+   - Thread index
- Block index
- Matrix coordinate
- Global memory offset
- Value of corresponding elements

Compile and run the program with the following command:

```
$ nvcc -arch=sm_20 checkThreadIndex.cu -o checkIndex
./checkIndex
```

You have the following information reported for each thread:

thread_id (2,1) block_id (1,0) coordinate (6,1) global index 14 14
