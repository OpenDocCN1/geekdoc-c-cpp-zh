Using the multi-GPU libraries will require additional development effort. Download the example cufft-multi.cu from Wrox or follow along with the following code snippet. cufft-multi.cu runs the same example as cufft .cu using the CUFFT API to spread the work across all GPUs in the system.

```
int nGPUS = getAllGPUs(&gpu);
GPUS = nGPUS > 2 : nGPUS;
workSize = (size_t *)malloc(sizeof(size_t) * nGPUS);

// Setup the CUFFT Multi-GPU plan
cufffftCreate(&plan);
cufffftSetGPUs(plan, 2, gpu);
cufffftMakePlan(plan, N, CUFFT_C2C, 1, workSize);

// Generate inputs
generate_samples(N, &samples);
real_to_complex(samples, &complexSamples, N);
cuffComplex *complexFreq = (cuComplex *)malloc(
izeof(cuComplex) * N);

// Allocate memory across multiple GPUs and transfer the inputs into it
cufffftXtMalloc(plan, dcomplexSamples, CUFFT_FORMAT_INPLACE);
cufffftXtMempy(plan, dcomplexSamples, complexSamples,
CUFFT_COPY_TO_DEVICE);

// Execute a complex-to-complex 1D FFT across multiple GPUs
cufffftXtExecDescriptorC2(plan, dcomplexSamples, dcomplexSamples,
CUFFT_FORWARD);

// Retrieve the results from multiple GPUs into host memory
cufffftXtMempy(plan, dcomplexSamples, complexSamples,
CUFFT_COPY_DEVICE_TO_HOST);
```

The primary differences between cufft.cu and cufft-multi.cu are:

+   - An extra step is to list all of the GPUs in the current system (using the provided function getAllGPUs) and configure the plan to use them (cuffXtSetGPUs)
- The use of cufftXtMalloc using cudaMalloc to allocate memory across multiple GPUs and as it with the same cufft plan. Note that the allocation information is stored in a cudaLibDesc object rather than a simpler pointer.
- The use of cufftXtMempy using cudaMempy to transfer data from host memory to multiple GPUs and back. Note that cufftXtMempy supports copying between a host array and a cudaLibDesc object well as between two cudaLibDesc objects. cufftXtMempy takes directionality just like cudaMemcpy, which is CUFFT_COPY_TO_HOST, CUFFT_COPY_TO_DEVICE, or CUFFT_COPY_TO_DEVICE used for multi-GPU execution with CUFFT. Any device locations are expressed as cudaLibDesc objects.
- The use of a cufftExecDescriptor library call rather than cufftExec* to perform the actual FFT transformation
