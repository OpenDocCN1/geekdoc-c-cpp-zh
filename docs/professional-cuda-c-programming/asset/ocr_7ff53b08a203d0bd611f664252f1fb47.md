cudaStreamCreate creates a non-null stream. The stream returned in pStream can be used as the stream argument to cudaMemcpyAsync and any other asynchronous CUDA APIs. One common point of confusion when using asynchronous CUDA functions is that they may return error from previously launched asynchronous operations. The API call returning an error is not necessarily the call that caused the error.

When performing an asynchronous data transfer, you must pin (or non-pageable) host memory. Pinned memory can be allocated using either cudaMallocHost or cudaHostAlloc:

By pinning locations in a stream you its physical size in CPU memory to remain constant throughout the lifetime of an operation. Otherwise, the system is free to change the physical location of host virtual memory at any time. If an asynchronous CUDA transfer was performed without pinned host memory, it would be possible for the operating system to physically move an array while the CUDA runtime is transferring it to the device, resulting in undefined behavior.

```
cudaError_t cudaMallocHost(void**ptr, size_t size)
cudaError_t cudaHostAlloc(void**host, size_t size, unsigned int flags)
```

To launch a kernel in a non-default stream, you must provide a stream identifier as the fourth parameter in the kernel execution configuration:

```
kernel_name<<<grid, block, sharedMemSize, stream>>>(argument list);
```

A non-default stream is declared as follows:

```
cudaStream_t stream;
```

Non-default streams can be created using:

```
cudaStreamCreate(&stream);
```

The resources of a stream can be released using:

```
cudaError_t cudaStreamDestroy(cudaStream_t stream);
```

If there is still work in a stream when cudaStreamDestroy is called on that stream, cudaStreamDestroy returns immediately and the resources associated with the stream are released automatically when all work in the stream has completed.

Since all CUDA operations are asynchronous, the CUDA API provides two functions that allow you to check if all operations in a stream have completed:

```
cudaError_t cudaSynchronize(cudaStream_t stream)
cudaError_t cudaStreamQuery(cudaStream_t stream);
```

cudaStreamSynchronize forces the host to block until all operations in the provided stream have completed. cudaStreamQuery checks if all operations in a stream have completed, but does not block the host if they have not completed. cudaStreamQuery returns cudaSuccess if all operations are complete or cudaErrorNotReady if one or more operation is still executing or pending execution.
