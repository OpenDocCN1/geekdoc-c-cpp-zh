The Analysis view is used to conduct performance analysis. There are two analysis modes:

+   * Guided analysis
* Unguided analysis

# # Guided Analysis

In the guided mode, as shown in Figure 10-6, nvvp will guide you step-by-step thorough analysis of the entire application.

In this mode, nvvp will go through multiple stages of analysis to aid your understanding of the likely performance limiters and optimization opportunities, including:

+   * CUDA Application Analysis
* Performance-Critical Kernels
* Compute, Bandwidth, or Latency Bound
* Compute Resources
