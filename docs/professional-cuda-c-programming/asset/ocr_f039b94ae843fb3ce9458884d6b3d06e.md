# Multi-GPU Libraries

Some applications contain sufficient parallelism to justify using more GPUs to improve performance. Chapter 9, "Multi-GPU Programming," covers more details about how to use native CUDA APIs for multi-GPU acceleration. It is important to discuss the use of GPUs by CUDA libraries as it requires less advanced understanding from the programmer and can lead to performance gains and better hardware utilization.

Multi-GPU Libraries (also known as the XT Library Interfaces) were introduced in CUDA 6. They enable a single library to be automatically executed across multiple GPUs. Because executing across multiple GPUs inherently partitioning the work across devices, a multi-GPU library can operate on datasets larger than GPU memory. As a result, even if your system has only one GPU, you will be able to operate on input data sizes that overflow the limit of global memory available by swapping data partitions in and out of the GPU.

In CUDA 6, multi-GPU execution is supported for some functions in cuFF and for all Level 3 cuBLAS functions. As a performance optimization, cuBLAS Level 3 multi-GPU library calls automatically overlap memory transfers with kernel computation.
