# UNROLLING LOOPS

Loop unrolling is a technique that attempts optimize loop execution by reducing the frequency of branches and loop maintenance instructions. In loop unrolling, rather than writing the body of a loop once and using a loop to execute it repeatedly, the body is written multiple times. By enclosing this loop then its iterations are reduced or removed entirely. The number of copies made of the loop is called the loop unrolling factor. The number of iterations in the enclosing loop is divided by the loop unrolling factor. This is most effective at improving performance for sequential array loops where the number of iterations is known prior to execution. Consider the code below:

```
for (int i = 0; i < 100; i++) {
a[i] = b[i] + c[i];
}
```

If you replicate the body of the loop, the number of iterations can be reduced to half of the original loop:

```
for (int i = 0; i < 100; i += 2) {
a[i] = b[i] + c[i];na[i+1] = b[i+1] + c[i+1];
}
```
