# Atomic Floating-Point Support

One point of note with atomic functions is they are mostly declared to operate on integer types,
such as int, unsigned int, or unsigned long int. Of all the atomic functions, only
atomicch and atomicAdd have existing support for single-precision floating-point values. None of
the atomic functions support double-precision. Fortunately, if your application needs there are techniques to manage multi-
threaded access to shared floating-point variables, there implementing floating-point atomic operations. At a high level, the idea is to store the bits of a floating-point
value in a supported type and use atomic CAS operations using that supported type.
