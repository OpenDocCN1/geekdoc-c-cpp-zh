The kernel code implementing this list is listed here. Execution of the kernel by every thread starts with printing "Hello World". Then, each thread checks if it should terminate. If the count at this nested layer is greater than one, thread 0 recursively invokes a child grid with as many threads.

```
_global void nestedHelloWorld(int const iSize, int iDepth) {
int tid = threadIdx.x;
printf("%d: Hello World from thread %d\nblock %d\n", iDepth, tid, blockIdx.x);

// condition to stop recursive execution
if (iSize == 1) return;

// reduce block size to half
int nthreads = iSize>>1;

// thread 0 launches child grid recursively
if(tid == 0 && nthreads > 0) {
nestedHelloWorld<<<1, nthreads>>>(nthreads,iDepth);
printf("nested execution depth: %d\n", iDepth);
}
```

You can find the full code for this nestedHelloWorld.cu, downloadable from Wrox.com. Compile the code with the following command:

```
$ nvcc -arch=sm35 -rdc=nestedHelloWorld.cu -o nestedHelloWorld -lcudavert
```

As dynamic parallelism is supported by the device library, nestedHelloWorld must be explicitly linked with -lcudavert on the command line.

The flag --rdc=true forces the generation of relocatable device code, a requirement for dynamic parallelism. You will learn more about relocatable device code in Chapter 10 of this book.
