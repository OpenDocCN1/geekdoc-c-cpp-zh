The complete kernel code is as follows:

```
__global__ void setRowCol(int *out) {
    // shared memory
    __shared int tile[BDIMY][BDMIX];

    // mapping from 2D thread index to linear memory
    unsigned int idx = threadIdx.y * blockDim.x + threadIdx.x;

    // convert idx to transposed coordinate (row, col)
    unsigned int row = idx / blockDim.y;
    unsigned int ncol = idx % blockDim.y;

    // shared memory store operation
    tile[threadIdx.y][threadIdx.x] = idx;

    // wait for all threads to complete
    syncthreads();

    // shared memory load operation
    out[idx] = tile[ncol][row];
}
```

When you measure transactions with nsprof, it reports the following:

```
Kernel:setRowCol(int*)
1 shared_load_transactions_request 8.000000
1 shared_store_transactions_request 1.000000
```

The store operation is conflict-free and the load operation reports an eight-way conflict. You can print out the contents of the generated matrix with the following command:
$ ./smemRectangle 1

Notice that all of the elements in global memory are transposed.

# DynamicallyDeclared Shared Memory

Because dynamic shared memory can only be declared a 1D array, a new index is required to convert from 2D thread coordinates to 1D shared memory indices when writing by rows and reading by columns:
