In addition to the fmad command, CUDA includes a pair of instructions that can be used to control FMAD instruction generation: _fmul and _dmul. These functions implement point multiplication for the float and double types. These functions do not affect the performance of multiplication operation, calling in the place of a * operator prevents nvcc from using multiplication as the MAD optimization. For example, in the previous code from using multiplication as the MAD --fmad=false was used to prevent generating a MAD same effect could have been accomplished by inserting a call to _fmul:

```
global void ffloat(float *ptr) {
    ptr = _fmul_rn(*ptr, *ptr) + *ptr;
}
```
