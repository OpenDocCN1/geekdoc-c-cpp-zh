There are a few common events that cause the fixed buffer to be transferred back to the host for
displaying:

+   1. Any CUDA kernel launch

+   2. Any synchronization with the CUDA host API (e.g. cudaDeviceSynchronize,
cudaStreamSynchronize, cudaEventSynchronize, etc.)

+   3. Any synchronous memory copies, such as cudaMemcpy

Otherwise, using printf in CUDA kernels is identical to use it in host C/C++ programs:

```
global void kernel() {
    int tid = blockIdx.x * blockDim.x + threadIdx.x;
    printf("Hello from CUDA thread %d\n", tid);
}
```

This makes it a very useful and friendly way to quickly debug kernels. However, because of
excessive use of printf, you can use block indices to limit the threads that print debug
messages so to prevent thousands of threads from overloading the debug buffer.

# CUDA assert

Another common host error-checking tool is assert. assert enables you to declaratively state
conditions that must hold true for correct application execution. If an assert fails,
your application either (1) immediately aborts with information about the assert
failed, or (2) if you are running in a cuda-gdb session, control is passed to cuda-gdb so that you can
inpect application state at the point where the assert failed. Like printf, support for assert is
only provided on GPUs with compute capability of 2.0 or better. It also relies on the same header
file the host, assert.h.

The semantics for using assert from a GPU are slightly different than the host. Upon hit-
failing an assert on the device (that is, assert whose contained expression evaluates
to zero), a CUDA thread will exit immediately after storing information about the assert
failed. However, this will only be displayed to stderr on the host at the next CUDA
synchronization point (e.g., cudaDeviceSynchronize, cudaStreamSynchronize, etc). This
means that at every synchronization point, information is displayed about any thread with a fail-
ing assert since the last synchronization point. If you make any CUDA API calls after the
first assert failure is detected, your app will return the CUDA cudaErrorAssert.

Like printf, you use assert within a kernel which like the host version, as follows:

```
global void kernel(...) {
    int *ptr = NULL;

    assert(ptr != NULL);
    *ptr = ...
    ...
}
```
