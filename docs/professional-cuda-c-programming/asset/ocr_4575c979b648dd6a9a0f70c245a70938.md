You can use the intrinsic function __ldg to direct the read accesses for array through the read-
only cache:

```
__global void copyKernel(int *out, int *in) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    out[idx] = __ldg(&out[idx]);
}
```

You can also use const __restrict__ qualifiers to pointers. (that is, pointers which are used exclusively to a par-
ic array). nvcc will automatically direct reads from non-aligned pointers through the read-only
cache.

```
__global void copyKernel(int *__restrict__ out,
    const int *__restrict__ in) {
    idx = blockIdx.x * blockDim.x + threadIdx.x;
    out[idx] = in;
}
```

# Global Memory Writes

Memory stores are relatively simple. The L1 cache is not used for store operations on either
Fermi or Kepler GPUs, store operations are only cached in the L2 cache before being sent to device
memory. Stores are preserved at a 32-byte granularity. Memory transactions can be one,
or four segments at a time. For example, if two addresses fall within the same 128-byte region
but not within an aligned 64-byte region, one four-segment transaction will be issued (that is, issuing
a single four-segment transaction performs better than issuing two segment transactions).
