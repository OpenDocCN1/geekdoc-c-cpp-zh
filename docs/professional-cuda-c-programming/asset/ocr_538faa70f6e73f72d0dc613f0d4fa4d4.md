# Padding Dynamically Declared Shared Memory

Padding techniques can also be applied to dynamic shared memory kernels that use rectangular
shared memory regions. Because the padded shared memory and global memory will have different
sizes, per-thread indices must be maintained in the kernel:

+   * row_idx: a row-major index to the padded shared memory. Using this index, a warp
access a single matrix row.
* col_idx: a column-major index to the padded shared memory. Using this index, a warp can\access a single matrix column.
* g_idx: an index to linear global memory. Using this index, a warp can perform coalesced
access to global memory.

These indices are calculated using the following code snippet:

```
// mapping thread index to global memory index
unsigned int g_idx = threadIdx.y * blockDim.x + threadIdx.x;

// convert idx to transposed (row, col)
unsigned int irow = g_idx / blockDim.y;
unsigned int icol = g_idx % blockDim.y;
unsigned int row_idx = threadIdx.y * (blockDim.x + IPAD) + threadIdx.x;

// convert back to smem index to access the transposed element
unsigned int col_idx = icol * (blockDim.x + IPAD) + irow;
```
