This example can be built using:

```
$ nvcc -lcufft cufft-multi.cu -o cufft-multi
```

The CuFFT uses prior knowledge about FFT functions to distribute data between GPUs
without breaking the validity of the FFT results (and will do something similar to cuBLAS across
multiple GPUs as well)

Adding multi-GPU support requires careful attention during the porting process. If your application
exposes selfish parallelism, then using the multi-GPU CUDA XT interfaces is much straightforward than developing your own custom multi-GPU implementation. The XT Interface for
cuBLAS and cuFFT libraries is a powerful addition to the CUDA.

# A SURVEY OF CUDA LIBRARY PERFORMANCE

Implementing an application in CUDA is always motivated by performance. There, the usability
of the CUDA libraries is meaningless if it sacrifices the performance acceleration that you expect
from GPU execution. This section briefly covers existing literature on CUDA library performance
relative to standard libraries. Keep in mind, with all performance results, your experimental
mights vary from the ones listed here depending on compilers, hardware, or other environment-factors.

# cuSPARSE versus MKL

Arguably, the gold standard for performance in sparse linear algebra is the Math Kernel Library
(MKL). MKL is optimized for both dense and sparse linear algebra on multi-core
Us using vector instructions. There is a large amount of literature comparing MKL and
cuSPARSE on a variety of computational kernels.

As part of the CUDA 5.0 release, NVIDIA performed a comprehensive performance comparison
between cuSPARSE and MKL across multiple computational kernels and multiple datasets. They found that cuSPARSE
performance uplifted varied sparse-dense vector multiplication from 1.1 times to 3.1 times relative to MKL. Multiplying a sparse
by multiple datasets yielded better relative performance, ranging from a little over 3 times
speed to more than 12 times performance improvement. Finally, when comparing tridiagonal
solvers between cuSPARSE and MKL, improvements of up to 17 times were reported,
dending on dataset size and primitive types (see Figure 8-11).

For the CUDA 6.0 release, NVIDIA performed a similar performance review of the CUDA libraries.
Results improved across the board, with sparse-dense vector multiplication achieving 1.8 times to
5.4 times speedup and performance improvements to triangular solvers, Incomplete-LU, and Cholesky
pre-conditioners.

Clearly, the cuSPARSE library is highly usable, maintains the performance benefits expected of GPU
hardware, and is continually being improved.
