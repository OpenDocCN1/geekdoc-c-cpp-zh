# Stencil Calculation for 2D Wave Equation

2D wave propagation is governed by the following wave equation:

$$\frac{\partial^2u}{\partial x^2} + \frac{\partial^2u}{\partial y^2}=v^2\frac{\partial^2u}{\partial t^2}$

where u(x, y, t) is the wave field, and v(x, y) is the velocity of the medium. This is a second order partial differential equation. A typical approach to solving this kind of partial differential equation is to use a finite difference scheme on a regular Cartesian grid.

Put simply, the finite difference scheme approximates derivatives using a stencil (like the one demonstrated in Chapter 5, albeit two-dimensional one) to calculate a derivative at a single point on a regular grid by applying a function to multiple local points that surround that single point. To evaluate the derivative of the central point, the 16 nearest local points to the central point are used.
