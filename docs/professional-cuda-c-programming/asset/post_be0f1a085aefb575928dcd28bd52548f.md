The high-performance computing (HPC) landscape is always changing as new technologies and processes become commonplace. In general, it pertains to the use of multiple processors to accomplish a complex task with high throughput and efficiency. It is common to consider HPC as not only a architecture but also as a set of elements, software tools, programming platforms, and parallel paradigms.

Over the last decade, high-performance computing has evolved significantly, particularly because of the emergence of GPU-CPU heterogeneous architectures, which have led to a fundamental paradigm shift in parallel programming. # PARALLEL COMPUTING

During the past several decades, there has been ever-increasing interest in parallel computing. The primary goal of parallel computing is to improve the speed of computation.

From a pure calculation perspective, parallel computing can be defined as a form of computation in which many calculations are carried out simultaneously, operating on the principle that large problems can be divided into smaller ones, and each smaller one is solved concurrently.

From the programmer's perspective, a natural question is how to map the concurrent calculations onto computers. Suppose you have multiple computing resources, use of multiple computing resources (cores or computers) to perform the concurrent calculations. The software and hardware aspects of parallel computing are closely intertwined together. In fact, parallel computing usually involves distinct areas of computing technologies:

- Computer architecture (hardware aspect)
- Parallel programming (software aspect)
