Note that the largest relative performance gain is achieved by the reduceUnroll8, in which each thread handles 8 blocks before starting the reduce. With 8 independent memory accesses, you will better saturate memory bandwidth and hide load/store latency. You can check memory/store efficiency metrics using the following command:

```
$nvprof --metrics gid_efficiency,gat_efficiency ./reduceInteger
```
