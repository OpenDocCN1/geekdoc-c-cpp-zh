If you run any of the examples in this section, you will need an OpenACC-enabled compiler. Currently, PGI, Cray, and CAPS compilers all support OpenACC directives. The examples in this chapter will use the PGI compiler, but all source code should work across all compilers. Consult your documentation for the flags that need to be added to OpenACC.

OpenACC-enabled compilers interpret the OpenACC directives of a program and perform auto-analysis of the source code to auto-generate accelerator source code. As a result, it is possible to automatically execute an execution on the GPU by adding a few lines of directives. For example, consider the following OpenACC vector addition:

```
#pragma acc kernels
for (i = 0; i < N; i++) {
  C[i] = A[i] + B[i];
}
```

The #pragma acc kernels directive marks the following sequential block eligible for execution on an Open Accelerator (for example, a GPU). If the compiler building this source code is OpenACC-enabled, it analyzes the loop, determines a strategy for parallelizing gangs, workers, and vectors, and then automatically generates the memory copies, kernel launches, and kernel source code to execute the loop in parallel on a GPU. In contrast, hardware (without CUDA unified memory) in CUDA would require 1) converting the body of the loop into a CUDA_global kernel, 2) explicitly allocating memory with cudaMalloc, 3) copying data to the device with cudaMemcpy, 4) performing a kernel launch, and 5) copying data back to the host. OpenACC, all of this is accomplished with a single #pragma.

In addition to compiler directives, OpenACC also offers a number of library functions. These functions may implement identical functionality, complementarity functionality, or unique functionality compared to the OpenACC compiler directives.

# Using OpenACC Compute Directives

In OpenACC, compute directives are used to communicate to the compiler how a block of code should be parallelized. There are two compute directives: #pragma acc kernels and #pragma acc parallel.

# Using the kernels kernels Directive

#pragma acc kernels takes a more automated and compiler-driven approach than #pragma acc parallel. When the kernels directive is applied to a block code, the compiler automatically analyzes that block for parallelizable loops. When they are found, the compiler can schedule parallel execution using any configuration of gangs, workers, and vector width on each parallel loop.
