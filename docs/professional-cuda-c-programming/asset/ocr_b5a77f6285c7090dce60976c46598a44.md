# Example of Misaligned Reads

Because access patterns are often determined by the algorithm an application implements, it can be challenging to coalesce memory loads for some applications. However, there are techniques that can help align memory access patterns in most cases.

To illustrate the effect of misaligned accesses on kernel performance, you will modify the addition code used in Chapter 3 to specify an offset by which all memory load operations are shifted. There are two indices in the following kernel. The new index k is shifted up by a given offset, which might cause misaligned loads depending on the value of offset. Only the load for arrays a and b will use index k. The write operation to c will use the original index i, ensuring that access remain well-aligned.
