performing (for example, complex-to-complex, real-to-complex, complex-to-real). You can

+   3. Populate device memory with the input signal samples using cudaMemcpy.

+   4. Execute the plan using a cuftExec* function.

+   5. Retrieve the result from device memory using cudaMemcpy.

+   6. Release CUDA and cuFT resources using cudaFree and cuftDestroy.

This example can be built using the following command:

```
$ nvcc -lcuff cuft.cu -o cuft
```

The example provided in cuft.cu generates a sequence of input samples from the function cos (x), converts them to complex numbers, transfers the complex representation to the GPU, and executes a complex-to-complex 1D plan before copying the results. Note that the same memory location dcomplexSamples is passed to cuftExec2C for both the input and output-range, this is an in-place FFT operation. A separate output buffer could also be pre-allocated and used to store the output.
