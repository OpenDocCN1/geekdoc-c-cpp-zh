# # Using the cuFFT API

cuFFT is used to refer to two separate libraries: the core, high-performance cuFFT library and the portability library, cuFFTW. The cuFFT library is an implementation of FFTs on CUDA that provides its own API. cuFFT, on the other hand, is designed with an identical API to the standard FFTW (Fastest Fourier Transform in the West) host library. Similar to how cuBLAS shares its API with the BLAS library, cuFFT is designed to maximize portability from existing code that uses FFTW. A wide range of the functions in the FFT library are identically supported in cuFFTW. cuFFT assumes all inputs are passed as handles and manages all the allocation (cudaMalloc) and transfers (cudacpy). Although this might lead to suboptimal performance, it greatly accelerates the porting process. A full list of supported operations in cuFFTW and cuFFT, refer to the cuFFT User Guide.
