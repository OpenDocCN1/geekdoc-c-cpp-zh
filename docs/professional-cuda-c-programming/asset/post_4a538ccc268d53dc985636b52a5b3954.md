## Reducing with Unrolled Warps

__syncthreads can be added for intra-block synchronization. In reduction kernels, it is used in each round to ensure that all threads writing partial results to global memory before any thread continues to the next round. However, consider the case when there are 32 fewer threads left (that is, a single warp). Because warp execution is SIMT, it is implicit intra-warp synchronization after each instruction. The last few iterations of the reduction loop can be unrolled as follows:

```cpp
if (tid < 32) {
    volatile int *vmem = idata;
    vmem[tid] += vmem[tid + 32];
    vmem[tid] += vmem[tid + 16];
    vmem[tid] += vmem[tid + 8];
    vmem[tid] += vmem[tid + 4];
    vmem[tid] += vmem[tid + 2];
    vmem[tid] += vmem[tid + 1];
}
```

This warp avoids loop control and thread synchronization. Note that the variable vmem is declared with the volatile qualifier, which tells the compiler it must store vmem[tid] back to global memory with every assignment. If the volatile qualifier is omitted, this code will not work correctly because the compiler or cache may optimize out writes to global memory. If a variable in global or shared memory is declared volatile, the compiler assumes its value can be changed or used at any time by threads. Therefore, any reference to volatile variables forces a read or write directly to memory, and not simply copy to a cache.

Based on reduceUnroll, unrolling can be added to the reduction kernels as follows:

```cuda
__global void reduceUnroll8 (int *g_idata, int *g_odata, unsigned int n) {
    // set thread id
    unsigned int tid = threadIdx.x;
    unsigned int idx = blockIdx.x*blockDim.x + threadIdx.x;
    // convert global data pointer to the local pointer of this block
    int *idata = g_idata + blockIdx.x*blockDim.x*8;
    // unrolling 8
    if (idx + 7*blockDim.x < n) {
        int a1 = g_idata[idx];
        int a2 = g_idata[idx+1*blockDim.x];
        int a3 = g_idata[idx+2*blockDim.x];
        int a4 = g_idata[idx+3*blockDim.x];
        int b1 = g_idata[idx+4*blockDim.x];
        int b2 = g_idata[idx+5*blockDim.x];
        int b3 = g_idata[idx+6*blockDim.x];
        int b4 = g_idata[idx+7*blockDim.x];
        g_odata[idx] = a1+a2+a3+a4+b1+b2+b3+b4;
    }
    __syncthreads();

    // in-reduction in global memory
    for (int stride = blockDim.x / 2; stride > 32; stride >>= 1) {
      if (tid < stride)
        idata[tid] += idata[tid + stride];
    }

    // synchronize within threadblock
    __syncthreads();

    // unrolling warp
    if (tid < 32) {
      volatile int *vmem = idata;
      vmem[tid] += vmem[tid + 32];
      vmem[tid] += vmem[tid + 16];
      vmem[tid] += vmem[tid + 8];
      vmem[tid] += vmem[tid + 4];
      vmem[tid] += vmem[tid + 2];
      vmem[tid] += vmem[tid + 1];
    }
}
```

## Reducing with Complete Unrolling

If you know the number of iterations in a loop, you can completely unroll it. Because the maximum number of threads per block on Fermi or Kepler is limited to 1024, refer to the reduction below:
