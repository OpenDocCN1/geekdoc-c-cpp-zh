# Variants of the Warp Shuffle Instruction

There are two sets of shuffle instructions: for integer variables and another for float variables. Each set has four variants of the shuffle instruction. To exchange integer variables within a warp, the basic function is as follows:

```
int shfl(int var, int srcLane, int width=warpSize);
```

The intrinsic instruction _shfl returns the value passed to _shfl by the thread in the same warp identified by srcLane. The meaning of srcLane changes depending on the width of warp (more details below). This makes it possible for each thread in a warp to directly fetch a value from a specific thread. This operation occurs simultaneously for all active threads within a warp, moving 4 bytes of data per thread.

Optionally, the width can be set to any power-of-2 between 2 and 32, inclusive. When set to the default warpSize (that is, a shuffle instruction is performed across the entire warp and srcLane specifies the index of the source thread). However, setting width permits subdivision of a warp into segments containing threads each, with a separate shuffle operation performed in each segment. For widths of order other than 32, the lane ID of a thread and its ID in a shuffle operation are not necessarily equal. In fact, the shuffle ID of a thread in a 1D thread block can be calculated as:

```
shflID = threadIdx.x % width;
```

For example, if shfl were called from every thread in a warp with the following arguments:

```
int y = shfl(x, 3, 16);
```

Then 0 through 15 would receive the value of x from thread 3, and threads 16 through 31 would receive the value of x from thread 19 (the thread with offset 3 in the top 16 threads of this section). For simplicity, srcLane will be referred to as a index for the remainder of this section. When the lane passed to shfl is the same value for all threads in a warp, the instruction performs a warp broadcast operation from the specified lane to all threads in the warp, as illustrated in Figure 5-20.
