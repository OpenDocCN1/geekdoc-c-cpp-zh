The third variant of the shuffle instruction instead copies data from a thread with higher index index relative to the calling thread:

```
int __shfl_down(int var, unsigned int delta, int width=warpSize)
```

__shfl_down calculates a source lane adding delta to the caller's lane index. The value held by the source thread is returned. Hence, this instruction shifts __shfl_down down the warp by delta lanes. There is no wrap around when using __shfl_down, the upper delta lanes in a warp will remain unchanged, as illustrated in Figure 5-22.

![](bbox=[0.147, 0.464, 0.686, 0.52])

__shfl_down(val,2): Shift the value to the left lanes.

FIGURE 5-22

The last variant of the shuffle instruction transfers data from a lane based on a bitwise XOR of the caller's lane index:

```
int __shfl_xor(int var, int laneMask, int width=warpSize)
```

The intrinsic instruction calculates a source lane index by performing a bitwise XOR of the caller's lane index with laneMask. The value held by the source thread is returned. This instruction facilitates a butterfly addressing pattern, as illustrated in Figure 5-23.

![](bbox=[0.147, 0.748, 0.656, 0.804])

__shfl_xor(val,1): Implement a butterfly exchange.

All of the shuffle functions in this section also support single-precision floating-point values. Floating-point shuffle functions take float for the var argument, and return a float. Otherwise, their usage is identical to integer shuffle functions.
