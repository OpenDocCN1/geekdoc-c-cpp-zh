The CUDA runtime allows you to directly allocate pinned host memory using: cudaMallocHost(void **devPtr, size_t count);

```
cudaError_t cudaMallocHost(void **devPtr, size_t count);
```

This function allocates counts of host memory that is page-locked and accessible to the device. Since the pinned memory can be accessed directly by the device, it can be read and written with much higher bandwidth than pageable memory. However, allocating excessive amounts of pinned memory might degrade system performance, since it reduces the amount of pageable memory available to the host system for storing virtual memory.

The following snippet demonstrates allocating pinned host memory with error checking and elementary error handling:

```
cudaError_t status = cudaMallocHost(void **_ahPinned, bytes);
if (status != cudaSuccess) {
    fprintf(stderr, "Error returned from pinned host memory allocation\n*");
    exit(1);
}
```

Pinned host memory must be freed with:

```
cudaError_t cudaFreeHost(void *ptr);
```
