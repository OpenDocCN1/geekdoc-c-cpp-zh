From the output messages, we can see that the parent grid invoked by the host has 1 block and 8 threads. The nestedHelloWorld kernel recursively invoked three times, and at each invocation the number of threads halved. You can confirm this using `nvvp` with the following command.

```
$ nvvp ./nestedHelloWorld
```
