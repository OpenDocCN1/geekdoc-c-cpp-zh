# PORTING FROM CPU TO GPU

Using CUDA for scientific simulations, financial algorithms, and other applications that demand a high level of accuracy and fidelity generally requires two steps: Porting legacy applications from a CPU-only framework to CUDA, followed by verifying the numerical accuracy of the port by comparing results from the legacy implementation and the CUDA version.

Even when numerically stable CUDA functions, the results of computation from GPU devices can still differ from the legacy CPU-only applications they replace. Because of the inherent inaccuracies of floating-point operations on both the host and device, it can sometimes be difficult to point one output more correct than the other. Therefore, porting plans must explicitly prepare for numerical differences and, if necessary, accept certain tolerances.
