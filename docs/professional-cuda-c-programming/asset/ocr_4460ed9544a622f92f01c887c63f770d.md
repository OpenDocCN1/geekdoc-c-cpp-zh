You can download the simpleP2P_CUDA_Aware containing the full source code for this example from Wrox.com. Compile it with the following command:

```
$ mpicc -std=c99 -03 simpleP2P_CUDA_Aware.c -o simplep2p.aware
```

Before launching the MPI program, you will need to ensure CUDA support is enabled in MVAPICH2 by setting the following environment:

```
$ export MV2_USE_CUDA=1
```

You can also set this environment variable during MPI invocation:

```
$ mpirun_rsh -np 2 node01 node02 MV2_USE_CUDA=1 ./simplep2p.aware
```

# Intra-Node GPU-to-GPU Data Transfer with CUDA-Aware MPI

You can use a CUDA-aware library to perform a data transfer between two GPUs in the same node. If two GPUs are on the PCIe bus, peer-to-peer transfers are automatically used. Run the example from the previous section as follows to perform data transfer between two GPUs on the same node, assuming node=0 has at least two GPUs:

```
$ mpirun_rsh -np 2 node01 node02 MV2_USE_CUDA=1 ./simplep2p.aware
```

The results on two Fermi M2090 GPUs are as follows. When you use, transferring data between GPUs on the PCIe bus yields much better bandwidth and latency than transfers that go across the inter-node connect.
