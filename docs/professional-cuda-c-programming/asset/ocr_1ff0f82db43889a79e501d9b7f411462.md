and vector formats. However, performing matrix-vector or matrix-matrix operations in cuSPARSE requires that the inputs and outputs in CSR, BSR, BSRX, or HYB formats.

Note that converting between cuSPARSE data formats introduces overhead in computation to perform the conversion, and space to store the converted copy which is logically the same data. Therefore, for optimal performance, you should avoid frequent conversions.

Still, cuSPARSE provides a variety of format conversion functions. Table 8-4 lists the supported format conversion functions. The top row indicates the format for your input (source) data. The left column indicates the format for your output (destination) data. Empty cells indicate unsupported conversions, though you might be able to use pipel conversions to produce the same effect. For instance, dense2csr and csr2ber are not explicitly supported conversion functions.
