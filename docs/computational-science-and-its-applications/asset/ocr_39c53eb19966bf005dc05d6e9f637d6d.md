Let {$i,j$} be the pixel locations, $f$ is available and thus $W_{i,j}$, which are nonlinear weights of kernel and construction of guidance image $f^g$ need to be calculated.

$$d_i=\sum_j W_{i,j}(f,f^g)f_j$$  (8.20)

Weights can be calculated using BNLM (Bayesian Nonlocal Means) and the guidance image can be found using local region and maximum likelihood rules.

# 8.2.4.2 Nonlinear Kernel Weights

BNLM can be expressed as follows according to [29]. Let $f_j$ be speckled data at $j$th pixel, $v_i$, $v_j$ are patch vectors whose center is at $(i,j)$ and size $N\times N$. $p(v_i|v_j)$ is a measure of similarity between $v_i$ and $v_j$ patches.

$$d_i=\frac{\sum_j p(v_i|v_j)p(v_j)f_j}{\sum_j p(v_i|v_j)p(v_j)}$$  (8.21)

Let $r_i$, $r_j$ be radar reflectivity for speckled patches $v_i$, $v_j$ to deal with similar reflectivity or almost identical-looking patches. The updated equation, after taking guidance image into consideration:

$$d_i=\frac{\sum_j p(v_i|v_j,r_i=r_j,f^g)p(v_j,r_i=r_j,f^g)v_j}{\sum_j p(v_i|v_j,r_i=r_j,f^g)p(v_j,r_i=r_j,f^g)}$$  (8.22)

Now conditional probability p(.) for independent speckles can be defined as:

$$p(v_i,v_j,r_i=r_j,f^g)=\prod_n p(v_{i,n}|v_{j,n},r_{i,n}=r_{j,n},f_n^g)$$  (8.23)

Suppose $f_g^m$ is independent from set of events {$v_{i,m}|v_{j,m},r_{i,m}=r_{j,m}$} and there is no prior knowledge about $p(v_{i,m}|v_{j,m})$ we have

$$p(v_{j,m},r_{i,m}=r_{j,m},f_g^m)p(v_{i,m}|v_{j,m},r_{i,m}=r_{j,m},f_g^m)$$
$$=p(v_{i,m},v_{j,m},r_{i,m}=r_{j,m},f_g^m)$$
$$=p(r_{i,m}=r_{j,m},f_g^m)p(v_{i,m},v_{j,m}|r_{i,m}=r_{j,m},f_g^m)$$
$$\propto p(f_g^m)p(r_{i,m}=r_{j,m}|f_g^m)p(v_{i,m},v_{j,m}|r_{i,m}=r_{j,m},f_g^m)$$  (8.24)

Suppose $p_{\mathrm{llhd}}$, $p_{\mathrm{pr}}$ are probabilities of likelihood and prior and then we can assume

$$p_{\mathrm{llhd}}=p(v_{i,m},v_{j,m}|r_{i,m}=r_{j,m})$$  (8.25)

$$p_{\mathrm{pr}}=p(r_{i,m}=r_{j,m}|f_g^m)$$  (8.26)
