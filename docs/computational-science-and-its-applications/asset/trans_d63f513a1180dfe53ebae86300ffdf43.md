### 16.3.1 通过SPSS生成的模型

该模型利用天气变量以及作物生长季两个天气变量的乘积构建。农业气候模型的指数分为两类：第一类是未加权指数，即天气变量的简单总和；第二类是加权指数，即天气变量与天气变量和产量相关值的乘积和。对这两个指数进行多元线性回归，以获得合适的回归模型。共获得五个回归模型，其中第五个模型用于进一步分析。随后，对2007年和2008年的水稻产量预测模型性能进行了验证，并通过预测2009年和2010年的产量进行了测试。因此，通过图16.6中的图形比较了实际产量和预测产量。

### 16.3.3 作物产量预测

利用每周天气数据，为北方邦东部的戈勒克布尔地区建立了产量预测模型，以获得最高的R²值和最低的模型误差。该地区作物产量预测模型的显著相关性（R²）为0.926。对2009年和2010年分别提前五周和十周进行了预测。所得预测产量及误差如表16.4所示。

**表16.4** 水稻预测产量和实际产量（收获前五周和十周）及方程误差

| 周数 | 年份 | 预测产量（公担/公顷） | 实际产量（公担/公顷） | 误差（%） | 平均误差（%） |
|------|------|----------------------|----------------------|-----------|---------------|
| 收获前五周 | 2009 | 21.9983 | 21.4544 | 2.4724 | 1.2995 |
|  | 2010 | 21.0498 | 21.0231 | 0.1267 |  |
| 收获前十周 | 2009 | 22.2454 | 21.4544 | 3.5556 | 3.5291 |
|  | 2010 | 21.7862 | 21.0231 | 3.5026 |  |

第五个模型被选用于产量预测，因为它基于更多的变量和相关系数，因此预计能给出更好的结果。产量预测方程中仅使用了非标准化系数。最终产量预测模型方程使用重要的独立天气变量，如下所示：

Y = (−18.5407) * (Constant) + 0.4118 * T + 0.0339 * Z40 + 0.0003 * Z351 + (−0.00009) * Z130 + (−0.00051) * Z140

R² = 0.926（在5%概率水平下）

其中，"Y"表示预测产量，"T"表示时间，"Z40"是早晨相对湿度，"Z351"是降雨量、傍晚相对湿度及其相关值的乘积和，"Z130"是最高温度、降雨量及其相关值的乘积和，"Z140"是最高温度、傍晚相对湿度及其相关值的乘积和。这些是通过SPSS获得产量预测方程的重要参数。对戈勒克布尔地区2009年和2010年的水稻产量提前五周进行了预测。借助生成模型得到的预测产量如表16.4所示，分别为21.9983和21.0498公担/公顷，与2009年和2010年的实际产量21.4544和21.0231公担/公顷几乎一致。2009年和2010年的误差分别为2.47%和0.13%。对2009年和2010年的水稻产量提前十周进行了预测。2009年和2010年的预测产量分别为22.2454和21.7862公担/公顷，实际产量分别为21.4544和21.0231公担/公顷，误差最小，分别为3.56%和3.50%。发现这两年的预测产量和实际产量几乎相等，误差很小。鉴于上述讨论，图16.6以图形方式展示了1971年至2010年戈勒克布尔地区实际产量与预测产量的比较。该图显示了实际产量和预测产量的趋势，两者均呈上升趋势。实际产量和预测产量的趋势线彼此重合。预测产量呈上升趋势，增长率为0.420公担/公顷/年，R²值为0.820；实际产量也呈上升趋势，增长率为0.420公担/公顷/年，R²值为0.886，与预测产量完全一致。在某些年份，实际产量和预测产量相同，例如1974年（9.3097公担/公顷）、1977年（9.3502公担/公顷）、1988年（17.1621公担/公顷）、1990年（17.4416公担/公顷）、1991年（18.9435公担/公顷）、1996年（22.27公担/公顷）、2000年（22.6331公担/公顷）、2002年（21.2728公担/公顷）、2006年（20.1907公担/公顷）、2009年（21.1690公担/公顷）、2010年（21.008公担/公顷）。实际产量和预测产量的最高值分别出现在2003年（23.9971公担/公顷）和2007年（24.1053公担/公顷），而实际产量和预测产量的最低值出现在同一年，即1979年，分别为5.0494公担/公顷和6.6589公担/公顷。然而，对实际产量和预测产量进行了曼-肯德尔秩统计检验，两者均显著。因此，可以得出结论，后续年份的产量也将遵循类似趋势。从上述结果还可以得出结论，即使在收获前五周和十周，所生成的模型也能对水稻、小麦、甘蔗、谷类等各种其他作物给出更好的产量预测。
