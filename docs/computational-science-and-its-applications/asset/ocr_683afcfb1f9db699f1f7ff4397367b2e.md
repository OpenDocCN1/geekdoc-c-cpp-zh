# 2.4 Domain Decomposition for Optimal Control Problems

There are many ways to deal with the original optimal control problem in the context of domain decomposition. We outline two strategies. The first one can be seen as a Jacobi-type approach. Here we take the iteration with respect to the domain decomposition outside of the control problem and minimize just the part of the cost that is responsible for the edges which are included in the subgraphs G_k. In the second approach, we fix the integer controls s and decompose the corresponding optimality system for the entire graph into the subgraphs G_k by a another, but very similar, non-overlapping domain decomposition, as in [13]. This is the essence of a virtual control paradigm given in [12].
