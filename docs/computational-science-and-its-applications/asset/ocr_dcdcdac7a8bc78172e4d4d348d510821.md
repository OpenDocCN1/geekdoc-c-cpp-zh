# 17.1 Introduction: Cognitive Computing-Based Intelligent Systems

The basis for an artificial agent to have human-like decision-making characteristics is due to an essential element that is known as agent architecture, the blueprint for constructing an agent having reasoning skills. Wooldridge, in 1995, discussed agent architecture as a software design that is anticipated to provide human-like rational decision-making processes (Wooldridge and Jennings, 1995). Maes defined agent architecture as a design that incorporates methods and procedures to include discrete components inside a holistic system and help these elements work together (Maes, 1991). Agent architecture is the constructing wedge for making an agent, much like building an object inside a software class.
