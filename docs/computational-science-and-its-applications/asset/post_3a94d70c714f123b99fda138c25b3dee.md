We now provide the definition of random evolution system and provide its existence.

## Definition 18.5. A two parameter family of bounded linear operators U(t,s), 0 ≤ s ≤ t ≤ T̃, on X is called an evolution system if the following two conditions are satisfied:

-   (i) U(s,s)=I (identity operator), U(t,r)U(r,s)=U(t,s) for 0 ≤ s ≤ r ≤ t ≤ T̃.

-   (ii) (t,s) ↦ U(t,s) is strongly continuous for 0 ≤ s ≤ t ≤ T̃.
