# 7.5 Simulation of Conformable Fractional Derivative of Shannon Wavelet and Scaling Function

The Shannon wavelet theory [12, 13, 14] is based on the scaling function φ(x), also known as sinc function, and the wavelet function ψ(x), respectively defined as

φ(x) = sinc x = sin πx / πx

and

ψ(x) = [ sin 2π (x - 1/2) - sin π (x - 1/2) ] / [ π (x - 1/2) ]

The conformable fractional derivative of scaling function φ(x) is

d^α φ / dx^α = x^{1-α} φ'(x)

and this implies

d^α φ / dx^α = x^{1-α} ( πx cos πx - sin πx ) / πx²

The conformable fractional derivative of wavelet function ψ(x) is

d^α ψ / dx^α = x^{1-α} ψ'(x)

d^α ψ / dx^α = x^{1-α} ( π (x - 1/2) [ 2 cos 2π (x - 1/2) - cos π (x - 1/2) ] + sin π (x - 1/2) - sin 2π (x - 1/2) ) / π (x - 1/2)²
