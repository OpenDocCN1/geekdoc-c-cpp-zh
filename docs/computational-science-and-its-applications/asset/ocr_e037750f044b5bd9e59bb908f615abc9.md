{1, |x_n − y_n|}, where x = <x_n>, y = <y_n>. Then d is an invariant metric and (X, d) is a Fréchet space but X is not normable.

**Definition 21.11** A linear metric space (X, d) is said to be *convex* if for all x, y ∈ X, λ ∈ [0, 1] we have d(u, λx + (1 − λ)y) ≤ λd(u, x) + (1 − λ)d(u, y) for all u ∈ X.

Every normed linear metric space is convex linear metric space with W(x, y, λ) = λx + (1 − λ)y, and d(x, y) = ||x − y||.

# 21.3 Proximality and Remotality in Linear Metric Spaces

**Theorem 21.1** *Let (X, d) be a linear metric space and A a closed subset of X.*

+   1. The set A is proximal if and only if for every x ∈ X, x ∈ H_{d_x}, where
+   
+      H_{d_x} = A + B[0, d_x].
+   
+   2. The set A is antiproximal if and only if for every x ∈ X, x ∉ H_{d_x}.
+   
+   3. The proximal set A is Chebyshev if and only if for every x ∈ X, x ∈ H_{d_x}^{⊕} (where ⊕ means that the sum decomposition of each element x ∈ X is unique).

*Proof.* (a) Suppose A is proximal and x ∈ X / A. If we take d_x = d(x, A), then it is clear that d_x > 0 and there exists an a ∈ A such that d(x, a) = d_x. It follows that x = a + (x − a) ∈ H_{d_x}. Also, if x ∈ A, then d_x = 0 and B[0, d_x] = {0}, there x = 0 + 0 ∈ H_{d_x}. Conversely, suppose for every x ∈ X, x ∈ H_{d_x}. It follows that for some a ∈ A, x = a + x − a ∈ A + B[0, d_x] and so d(x, a) ≤ d_x ≤ d(x, a′), i.e. d(x, a) = d_x. Therefore a ∈ P_A(x) and A is proximal.

(b) Suppose A is antiproximal and x ∈ X / A. then P_A(x) = ϕ. If x ∈ H_{d_x}, then there exists an a ∈ A such that x = a + (x − a) ∈ A + B[0, d_x] and d(x, a) = d(x − a, 0) ≤ d_x ≤ d(x, a). Therefore a ∈ P_A(x), a contradiction. It follows that x ∉ H_{d_x}. Conversely, suppose for every x ∈ X, x ∉ H_{d_x}. To show A is antiproximal. Suppose it is not. Then for some x ∈ X / A there exists an a ∈ P_A(x). But then x = a + (x − a) ∈ H_{d_x}, which is a contradiction. It follows that P_A(x) = ϕ for every x ∈ X / A and hence A is antiproximal.

(c) Suppose that the set A is Chebyshev. Since A is proximal, for each x ∈ X / A, x ∈ H_{d_x}. Suppose there exist two representations of x, i.e. x = a_1 + u_1 = a_2 + u_2 where a_1, a_2 ∈ A and u_1, u_2 ∈ B[0, d_x]. Since d(x, a_i) ≤ d_x ≤ d(x, a_i) for i = 1, 2, a_i ∈ P_A(x). Since A is Chebyshev, it follows that a_1 = a_2 and u_1 = u_2. Therefore x ∈ H_{d_x}^{⊕}.

Conversely, if for some x ∈ X there exists a_1, a_2 ∈ P_A(x), then u_i = x − a_i ∈ B[0, d_x] and x = a_1 + u_1 = a_2 + u_2. Since x ∈ H_{d_x}^{⊕}, we have a_1 = a_2. Hence A is Chebyshev.

**Theorem 21.2** *Let (X, d) be a linear metric space and A a non-empty bounded subset of X.*

+   1. The set A is remotal if and only if for every x ∈ X, x ∈ K_{δ_x}, where K_{δ_x} = A + B^c[0, δ_x].
+   
+   2. The set A is antiremotal if and only if for every x ∈ X, x ∉ K_{δ_x}.
+   
+   3. The remotal set A is uniquely remotal if and only if for every x ∈ X, x ∈ K_{δ_x}^{⊕} (where ⊕ means that sum decomposition of each element x ∈ X is unique).
