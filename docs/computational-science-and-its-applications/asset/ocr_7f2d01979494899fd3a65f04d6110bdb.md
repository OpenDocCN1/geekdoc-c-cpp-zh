∫_Ω q ∇Γ_N^q(f)·∇v dx = ∫_{∂Ω} f Γ_D v ds (5.7)

for a suitable set of test functions v. The integral on the boundary should be understood in the sense of duality pairing, i.e. f ∈ H^{-1/2}(∂Ω) and Γ_D v ∈ H^{1/2}(∂Ω) yield ∫_{∂Ω} f Γ_D v ds = ⟨f, Γ_D v⟩_{H^{-1/2}×H^{1/2}}.

There are several natural choices for the spaces X, Y, and W. To this end, we introduce

X = 	ilde{H}^1(Ω) = { u ∈ L_2(Ω) | ∫_Ω q(x) |∇u(x)|^2 dx < ∞, ∫_{∂Ω} Γ_D u(s) ds = 0 }. (5.8)

Because of Equation (5.4), the following bilinear form defines a scalar product on this space

⟨u, v⟩_{	ilde{H}^1} = ∫_Ω q ∇u·∇v dx. (5.9)

We use the Dirichlet forward operator F_D^q as an extension operator and define the following space of functions on the boundary ∂Ω

Z = 	ilde{H}^{1/2}(∂Ω) = { g ∈ L_2(∂Ω) | ∫_Ω q(x) |∇F_D^q(g)(x)|^2 dx < ∞, ∫_{∂Ω} g(s) ds = 0 } (5.10)

together with its scalar product

⟨g, φ⟩_{	ilde{H}^{1/2}} = ∫_Ω q(x) ∇F_D^q(g)(x)·∇F_D^q(φ)(x) dx. (5.11)

The Dirichlet-to-Neumann (DtN) operator q ∂/∂n F_D^q is well defined on 	ilde{H}^{1/2}(∂Ω), and we introduce

W = 	ilde{H}^{-1/2}(∂Ω) = { f | f = q ∂/∂n F_D^q(g), g ∈ 	ilde{H}^{1/2}(∂Ω) } (5.12)

together with its scalar product

⟨f, ψ⟩_{	ilde{H}^{-1/2}} = ∫_Ω q ∇F_N^q(g)·∇F_N^q(ψ) dx. (5.13)

We observe that f ∈ 	ilde{H}^{-1/2}(∂Ω) is the Neumann trace for u = F_D^q(g). This implies −div(q∇u) = 0 and the integrability condition for Neumann problems yields

∫_{∂Ω} f ds = 0 and 	ilde{H}^{-1/2}(∂Ω) = { f ∈ H^{-1/2}(∂Ω) | ∫_{∂Ω} f ds = 0 }. (5.14)
