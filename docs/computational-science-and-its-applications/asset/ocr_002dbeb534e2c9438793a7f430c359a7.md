# 8.2.4.1 Guided Image Filter

A guided filter is used for preserving the edges under the assumption about the dependence between guidance I and filtered output λ as studied in [27]. Let wₙ be window with center at pixel n, (αₙ, βₙ) are derived through the filter input p, then

$$\lambda_i = \alpha_n\gamma_i + \beta_n,\ \forall i \in w_n$$  (8.13)

However, a pixel i is involved in all the overlapping windows wₙ that covers i, so the value of λᵢ in (13) is not identical when it is computed in different windows. A simple strategy is to average all the possible values of λᵢ. So, after computing (αₙ, βₙ) for all windows wₙ in the image, we compute the filtering output by

$$\lambda_i = \frac{1}{|w|}\sum_{n}(\alpha_n\gamma_i+\beta_n)$$  (8.14)

Using the least mean square idea as in [28] and letting Aₙ,ⱼ and βₙ,ⱼ be dependent upon guidance image g, we can derive:

$$\alpha_n = \sum_n A_{n,j}(g)p_j$$  (8.15)

$$\beta_n = \sum_n \beta_{n,j}(g)p_j$$  (8.16)

Thus λᵢ can be reformulated as follows:

$$\lambda_i = \frac{1}{|w|}\sum_i\sum_j[A_{n,j}(\gamma_i)\gamma_i + \beta_{n,j}(g)]p_j$$  (8.17)

Let $W_{n,j}(g)=\frac{1}{|w|}\sum_n[g\cdot A_{n,j}(\gamma_i)+\beta_{n,j}(\gamma_i)]$ be the kernel weights then

$$\lambda_i = \sum_j W_{n,j}(\gamma_i)p_j,\ \forall i \in w_n$$  (8.18)

$$\lambda_i = \sum_j W_{i,j}(\gamma_i)p_j$$  (8.19)
