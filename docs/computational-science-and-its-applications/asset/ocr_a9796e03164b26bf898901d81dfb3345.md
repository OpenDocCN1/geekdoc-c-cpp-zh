# Proposition 21.2 Let (X, d) be a metric space. If K ⊆ X is uniquely remotal and M-compact, then FarK = {k ∈ K : k is farthest point for some x ∈ X} is M-compact.

Proof. Let {kₙ} be a maximizing sequence in FarK. So there exists x ∈ X such that lim d(x, kₙ) = δ(x, FarK) = δ(x, K). Then {kₙ} is a maximizing sequence for x in K. Since K is M-compact, {kₙ} has a convergent subsequence {kₙⱼ}. As K is uniquely remotal, {kₙⱼ} → kₓ ∈ K. Now lim d(x, kₙⱼ) = d(x, kₓ) = δ(x, K) = δ(x, FarK) and kₓ ∈ FarK, so {kₙ} has a convergent subsequence in FarK. Therefore FarK is M-compact.

# Proposition 21.3 Let (X, d) be a metric space. If K ⊆ X is uniquely remotal and M-compact, then K̄ is uniquely remotal.

Proof. As δ(x, K) = δ(x, K̄), for every x ∈ X and K is uniquely remotal, we obtain that K̄ is remotal(see [Sangeeta and Narang 2014]). Suppose there exists x₀ ∈ X such that F(x₀, K̄) is not a singleton. Let k₁, k₂ ∈ K̄ be such that k₁, k₂ ∈ F(x₀, K̄). Since k₁, k₂ ∈ K̄, there exist sequences {xₙ} ⊆ K and {yₙ} ⊆ K such that {xₙ} → k₁ and {yₙ} → k₂. Clearly {xₙ} and {yₙ} are maximizing sequences of x₀ ∈ K and K is M-compact so {xₙ} and {yₙ} have convergent subsequences in K which implies k₁, k₂ ∈ K and this contradicts the fact that K is uniquely remotal. Hence K̄ is uniquely remotal.
