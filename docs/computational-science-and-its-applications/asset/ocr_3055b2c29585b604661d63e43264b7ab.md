In our work, we will use this theory as a post-segmentation operation to clean segmentation results and fill in some cavities. Morphologic operations are especially suited to binary image processing, which is the case in our study. Within the common morphological operations, we cite: dilation and erosion. In fact, dilation increases the size of small regions by adding pixels to object boundaries, while erosion reduces the size of regions by removing pixels on object boundaries. A primordial part of these morphological operations is the structuring element (SE). It consists of a matrix of 0s and 1s. The center pixel is called the origin. It represents the pixel of interest of the structuring element. All pixels containing 1s in the neighborhood of SE. The idea behind using such a geometrical set is that the value of each pixel in the input image is matched to SE and, depending on the transformation (dilation or erosion), this pixel remains as it is or changes and becomes part of the background or object pixels, and Figure 2.10 shows a diamond structuring element.
