Using the transformation $x^{\beta}=\cos t$; $D^{\beta} y = \frac{d^{\beta} y}{dx^{\beta}} = \frac{-\beta}{\sqrt{1-x^{2\beta}}} \frac{d^{\theta} t}{dx^{\beta}}$ and

$D^{\beta} D^{\beta} y = \frac{d^{\beta}}{dx^{\beta}}\left(\frac{-\beta}{\sqrt{1-x^{2\beta}}}\frac{d^{\theta} t}{dx^{\beta}}\right)=\frac{-\beta^{2}x^{\beta}}{(1-x^{2\beta})^{3/2}}\frac{d^{\beta} y}{dt^{\beta}}-\frac{\beta}{\sqrt{1-x^{2\beta}}}\frac{d^{\beta}}{dt^{\beta}}\frac{d^{\beta} y}{dt^{\beta}}$

putting all the values of the derivative we get

$\frac{d^{\beta}}{dt^{\beta}}\frac{d^{\beta} y}{dt^{\beta}}+p^{2}y=0$

having solution $y = c_{1}\cos\left(\frac{p}{\beta}\cos^{-1}x^{\beta}\right)+c_{2}\sin\left(\frac{p}{\beta}\cos^{-1}x^{\beta}\right)$ or equivalently

$y(x^{\beta}) = c_{1}U_{p}(x^{\beta})+c_{2}V_{p}(x^{\beta})$

where $U_{p}$ and $V_{p}$ are defined as Chebyshev fractional polynomials of the first and second kinds respectively in $x^{\beta}$

for $0 < x^{\beta} < 1$, $U_{p}(x^{\beta}) \pm i V_{p}(x^{\beta}) = (\cos t \pm i \sin t)^{p} = (x^{\beta} \pm i\sqrt{1-x^{2\beta}})^{p}$

So that $U_{p}(x^{\beta}) = \frac{1}{2}\left[\left(x^{\beta}+i\sqrt{1-x^{2\beta}}\right)^{p}+\left(x^{\beta}-i\sqrt{1-x^{2\beta}}\right)^{p}\right]$ and

$V_{p}(x^{\beta}) = \frac{1}{2i}\left[\left(x^{\beta}+i\sqrt{1-x^{2\beta}}\right)^{p}-i\left(x^{\beta}-i\sqrt{1-x^{2\beta}}\right)^{p}\right]$

$U_{p}(x^{\beta}) = \frac{(-2)^{p}p!}{(2p)!\beta^{p}}\sqrt{1-x^{2\beta}}\frac{d^{\beta}}{dx^{\beta}}\left(1-x^{2\beta}\right)^{p-1/2}$

The Chebyshev fractional polynomials of the first kind can be obtained by putting $p = 0,1,2,3...$ as

$U_{3}(x^{\beta}) = 4x^{3\beta} - 3x^{\beta}$
