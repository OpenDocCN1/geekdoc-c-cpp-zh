‖A(t, b₁) − A(t, b₂)‖²_{𝕃(Y,X)} ≤ L₃ ‖b₁ − b₂‖²_X

holds for every t ∈ J and b₁, b₂ ∈ Ba.

+   (H10) The nonlinear function f: J × X → X satisfies (H2) with Lipschitz constant L₂ and there exists constants C₃ > 0 such that and for all b ∈ Ba, ‖f(t, b)‖²_Y ≤ C₃.

+   (H11) The operator Φ ∈ 𝕃₂⁰(H, Y).

From (H11) we obtain ‖∫₀^τ̃ Φ dW(θ)‖²_Y is bounded a.s. by using the Markov inequality and we denote it by M₁. Let us define the sequence of stopping times τ_N by,

τ_N := inf_{t≥0} {t: M ∨ β ∨ C₂ ∨ C₃ ∨ L₂ ∨ L₃ ∨ M₁ ∨ C ≥ N}, (18.10)

where the constant C appears later in Lemma 18.1 and we assume τ_N > 0. Since x(·) is random, the constants M, β, C₂, C₃, L₂, L₃, M₁ in the assumptions depend not only on the parameters of 𝔹 but also on N, where N is from stopping time. We use the notation T̃ = T ∧ τ_N and I to denote the time interval [0, T̃] ⊂ J.

We now provide the definition of random evolution system and provide its existence.

# Definition 18.5. A two parameter family of bounded linear operators U(t,s), 0 ≤ s ≤ t ≤ T̃, on X is called an evolution system if the following two conditions are satisfied:

+   (i) U(s,s)=I (identity operator), U(t,r)U(r,s)=U(t,s) for 0 ≤ s ≤ r ≤ t ≤ T̃.

+   (ii) (t,s) ↦ U(t,s) is strongly continuous for 0 ≤ s ≤ t ≤ T̃.

# Theorem 18.2. Let τ_N be the stopping time defined in (18.10). Let Ba ⊂ X and let {A(t,b)}, (t,b) ∈ I × Ba be a family of operators satisfying (H7)–(H9). If x ∈ L²_𝔽(Ω, C(I,X)) then there is a unique random evolution system {U(t,s;x)} := {U(t,s,(x(r,ω))_{r≤t})} defined on the triangle Δ := {0 ≤ s ≤ t ≤ T̃} with the following properties satisfied pointwise on Ω.

+   (P1) sup_{t,s∈Δ} ‖U(t,s;x)‖_{𝕃(X,X)} ≤ M e^{β T̃}, where M and β are stability constants.

+   (P2) ∂/∂t U(t,s;x) y = A(s,x(s)) U(t,s;x) y for y ∈ Y, 0 ≤ s ≤ t ≤ T̃.

+   (P3) ∂/∂s U(t,s;x) y = −U(t,s;x) A(s,x(s)) y for y ∈ Y, 0 ≤ s ≤ t ≤ T̃.

Proof of the above theorem is similar to that of Theorem 2.13 in [15] and Theorem 5.3.1 in [18] and hence omitted.

The random evolution operator constructed is only ℱ_t-measurable and generally not ℱ_s-measurable. Hence the stochastic integral ∫₀^t U(t,s;x) Φ dW(s) is not defined in Itô sense.

To rectify this issue, we apply integration by parts (as in [19]) and obtain terms which do not involve the stochastic integration of non-adapted integrands as seen below.

∫₀^t U(t,s;x) Φ dW(s) = U(t,0;x) ∫₀^t Φ dW(θ) + ∫₀^t U(t,s;x) A(s,x(s)) (∫_s^t Φ dW(θ)) ds. (18.11)
