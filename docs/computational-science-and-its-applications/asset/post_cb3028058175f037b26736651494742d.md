
Proof. (a) Suppose that the set A is remotal, then for arbitrary x ∈ X, there exist a ∈ A such that d(x, a) = δₓ. It follows that x = a + (x − a) ∈ K_{δₓ}. Conversely, suppose for every x ∈ X, x ∈ K_{δₓ}. It follows that for some a ∈ A, d(x, a) ≥ δₓ ≥ d(x, a) i.e. d(x, a) = δₓ. Therefore a ∈ F_A(x) and A is remotal.

(b) Suppose A is antiremotal, then for every x ∈ X, F_A(x) = ∅. Suppose for some x ∈ X, x ∈ K_{δₓ}, then there exists an a ∈ A such that x − a ∈ B^c[0, δₓ]. But then a ∈ F_A(x), a contradiction. It follows that for every x ∈ X, x ∉ K_{δₓ}. Conversely, suppose for every x ∈ X, x ∉ K_{δₓ}. Suppose for some x ∈ X there exists an a ∈ F_A(x). Then x = a + (x − a) ∈ K_{δₓ}, a contradiction. It follows that F_A(x) = ∅ for every x ∈ X i.e. A is antiremotal.

(c) Since A is remotal and x ∈ X, then x ∈ K_{δₓ}. If there exist two representations for x i.e. x = a₁ + u₁ = a₂ + u₂, where a₁, a₂ ∈ A and u₁, u₂ ∈ B^c[0, dₓ]. But then a₁, a₂ ∈ F_A(x). Since A is uniquely remotal, it follows that a₁ = a₂ and u₁ = u₂. Therefore x ∈ K_{δₓ}^⊕. Suppose A is remotal and for some x ∈ X there exist a₁, a₂ ∈ F_A(x). Then u_i = x − a_i ∈ B*[0, dₓ] and x = a₁ + u₁ = a₂ + u₂. Since x ∈ K_{δₓ}^⊕ we have a₁ = a₂. Therefore A is uniquely remotal. ## Theorem 21.3 Every non empty compact set in a linear metric space (X, d) is proximinal and remotal.

Proof. Suppose A is a non-empty compact set in X and x ∈ X. For n ∈ ℕ, consider the set H_n(x) = { a ∈ A : d(x, a) ≤ d_x + 1/n }. From the definition of d_x, H_n(x) ≠ ∅, H_{n+1}(x) ⊆ H_n(x) and H_n(x) ⊆ A is compact. So, there exists an a ∈ A such that for all n ∈ ℕ, n ≥ 1, a ∈ H_n(x) i.e. for all n ≥ 1, d(x, a) ≤ d_x + 1/n. Therefore d(x, a) ≤ d_x and x ∈ H_{d_x}. It follows that A is proximinal.

For n ∈ ℕ, consider the set K_n(x) = { a ∈ A : d(x, a) ≥ δ_x − 1/n }. From the definition of δ_x, K_n(x) ≠ ∅, K_{n+1}(x) ⊆ K_n(x) and K_n(x) ⊆ A is compact. So there exist a ∈ A such that for all n ≥ 1, a ∈ K_n(x) i.e. for all n ≥ 1, d(x, a) ≥ δ_x − 1/n. Therefore d(x, a) ≥ δ_x and x ∈ K_{δ_x}. It follows that A is remotal.

## Theorem 21.4 Let (X, d) be a linear metric space and A a closed remotal(proximinal) subset of X, 0 ∈ A and x ∈ X. If the set K_{δ_x} (H_{d_x}) is compact, then F_A(x)(P_A(x)) is compact.

Proof. We know that the set K_{δ_x} ≠ ∅(H_{d_x} ≠ ∅). Suppose that the set K_{δ_x}(H_{d_x}) is compact. If {g_n} ⊆ F_A(x) ({g_n} ⊆ P_A(x)) then d(x, g_n) = d(x − g_n, 0) = δ_x (d(x, g_n) = d(x − g_n, 0) = d_x). Since 0 ∈ A, we have {x − g_n} ⊆ K_{δ_x} ({x − g_n} ⊆ H_{d_x}) has a convergent subsequence {x − g_{n_k}}. Therefore there exists a z_o ∈ K_{δ_x} (z_o ∈ H_{d_x}) such that x − g_{n_k} → z_o, g_{n_k} → x − z_o as k → ∞. Since g_{n_k} ⊆ A and A is closed, we have g_o = x − z_o ∈ A and d(x, g_{n_k}) = δ_x (d(x, g_{n_k}) = d_x). It follows that d(x, g_o) = δ_x (d(x, g_o) = d_x) and g_o ∈ F_A(x) (g_o ∈ P_A(x)). Therefore the set F_A(x) (P_A(x)) is compact.

## 21.4 Unique Remotality in Convex Spaces

## Theorem 21.5 Let (X, d) be a convex linear metric space and A a closed bounded remotal subset of X admitting a center c. If A is not a singleton, then for any extracted function F of F(x, A) there exists a ρ > 0 such that d(F(x), F(c)) > ρ for all x in a neighborhood of c on (c, F(c)].

Proof. Let F be any extracted function from F(., A) and x ∈ (c, F(c)] then

d(x, F(x)) = d(tc + (1 − t)F(c), F(x))
≤ t d(c, F(x)) + (1 − t) d(F(c), F(x))
≤ t d(c, F(c)) + (1 − t) d(F(c), F(x))
≤ t d(x, F(x)) + (1 − t) d(F(c), F(x)).

which implies

d(x, F(x)) − t d((x, F(x) ≤ (1 − t) d(F(c), F(x))
i.e (1 − t) d(x, F(x)) ≤ (1 − t) d(F(c), F(x))
i.e d(x, F(x)) ≤ d(F(c), F(x))

Therefore

d(F(x), F(c)) ≥ d(x, F(x)) > d(c, F(c)) ≡ r.

Thus ρ can be chosen so that ρ ≤ r, the Chebyshev radius of A.

## Theorem 21.6 Let A be a non-singleton closed and bounded subset of a convex linear metric space (X, d) admitting a center c and let ρ be as in Theorem 21.1. If the distance δ(c, A / B(F(c), ρ)) is attained, then A can not be uniquely remotal

Proof. Suppose on contrary that A is uniquely remotal and assume c = 0. Let a ∈ (0, F(0)) be such that d(F(x), F(0)) > ρ for every x ∈ (0, a]. Let xₙ ∈ (0, a] be such that xₙ → 0. By isolation result F(xₙ) ∈ A / B(F(c), ρ). Consider

δ(0, A) = lim δ(xₙ, A)
= lim δ(xₙ, A / B(F(0), ρ))
= δ(0, A / B(F(0), ρ))

Since δ(0, A / B(F(0), ρ)) is attained, there exists a₀ ∈ A / B(F(0), ρ)) such that δ(0, A) = d(0, a₀). Since a₀ ∈ A / B(F(0), ρ)), a₀ ≠ F(0), contradicting the assumption that A is uniquely remotal.

## Corollary 21.1 If a compact subset A with center c is uniquely remotal in a convex linear metric space (X, d), then A must be a singleton.

Proof. Assume that A is not a singleton and ρ is as above. Since A is compact, A / B(F(c), ρ) is compact and hence remotal i.e. δ(c, A / B(F(c), ρ)) is attained. Consequently, A is not uniquely remotal by Theorem 21.2, contradicting our assumption.

## Proposition 21.2 Let (X, d) be a metric space. If K ⊆ X is uniquely remotal and M-compact, then FarK = {k ∈ K : k is farthest point for some x ∈ X} is M-compact.

Proof. Let {kₙ} be a maximizing sequence in FarK. So there exists x ∈ X such that lim d(x, kₙ) = δ(x, FarK) = δ(x, K). Then {kₙ} is a maximizing sequence for x in K. Since K is M-compact, {kₙ} has a convergent subsequence {kₙⱼ}. As K is uniquely remotal, {kₙⱼ} → kₓ ∈ K. Now lim d(x, kₙⱼ) = d(x, kₓ) = δ(x, K) = δ(x, FarK) and kₓ ∈ FarK, so {kₙ} has a convergent subsequence in FarK. Therefore FarK is M-compact.

## Proposition 21.3 Let (X, d) be a metric space. If K ⊆ X is uniquely remotal and M-compact, then K̄ is uniquely remotal.

Proof. As δ(x, K) = δ(x, K̄), for every x ∈ X and K is uniquely remotal, we obtain that K̄ is remotal(see [Sangeeta and Narang 2014]). Suppose there exists x₀ ∈ X such that F(x₀, K̄) is not a singleton. Let k₁, k₂ ∈ K̄ be such that k₁, k₂ ∈ F(x₀, K̄). Since k₁, k₂ ∈ K̄, there exist sequences {xₙ} ⊆ K and {yₙ} ⊆ K such that {xₙ} → k₁ and {yₙ} → k₂. Clearly {xₙ} and {yₙ} are maximizing sequences of x₀ ∈ K and K is M-compact so {xₙ} and {yₙ} have convergent subsequences in K which implies k₁, k₂ ∈ K and this contradicts the fact that K is uniquely remotal. Hence K̄ is uniquely remotal.

## Theorem 21.9 Let (X, d, W) be a convex metric space. If K ⊆ X is a uniquely remotal and M-compact set and FarK ⊆ K' then K is a singleton.

Proof. As FarK ⊆ K', there exists k_o ∈ FarK / K'. As K is uniquely remotal, there exists x ∈ X such that d(x, k_o) = sup{d(x, k) : k ∈ K}. Consider the set C = {0 ≤ t ≤ 1, k_o is farthest point for y' = W(x, k_o, t) such that d(y', x) = t d(x, k_o) and d(y', k_o) = (1−t)d(x, k_o)}. Clearly C ≠ ∅ as 1 ∈ C. We claim that inf C > 0, otherwise k_o is farthest point of itself which implies that K is a singleton. Suppose inf C = t_o > 0. Consider x_o ∈ W(x, k_o, t_o) such that d(x_o, x) = t_o d(x, k_o)). We claim that there exist ε_o > 0 such that d(x_o, k) < d(x_o, k_o) − ε_o for every k ∈ K / {k_o}. If not, then there exists {k_n} ⊆ K / {k_o} such that d(x_o, k_n) → d(x_o, k_o) = δ(x_o, K). So {k_n} is maximizing sequence for x_o. Since K is M-compact, there exists {k_{n_q}} ⊆ {k_n} such that k_{n_q} → k' Since k_o is not a limit point of K, k' ≠ k_o. This contradicts the fact that K is uniquely remotal. Now, take y'' = W(k_o, x_o, t), 0 < t < 1. For k ∈ K / {k_o}, consider

d(y'', k) = d(W(x_o, k_o, t), k)
≤ (1−t)d(k_o, k) + t d(x_o, k)
< (1−t)diam K + t(d(x_o, k_o) − ε_o)
= t d(x_o, k_o) − ε_o t + (1−t)diam K
= t d(x_o, k_o) − [ε_o t − (1−t)diam K]
= d(W(k_o, x_o, t), k_o) − [ε_o t − (1−t)diam K].

## Theorem 21.10 Let (X, d, W) be a convex metric space. If K ⊆ X is uniquely remotal and M-compact, then K' is either empty or M-compact and uniquely remotal.

Proof. If FarK ⊆ K' then K is a singleton by Theorem 21.5. Suppose FarK ⊆ K'. We claim that δ(x, K) = δ(x, K'). First we show that δ(x, K) ≥ δ(x, K') for all x ∈ X. For x ∈ X, there exists {k'_n} ⊆ K' such that d(x, k'_n) → δ(x, K') as n → ∞. As k'_n ∈ K', for each n ∈ ℕ there exists k_n ∈ K such that d(k_n, k'_n) < 1/n. Now d(x, k'_n) ≤ d(x, k_n) + d(k_n, k'_n), implies d(x, k_n) ≥ d(x, k'_n) − d(k_n, k'_n) > d(x, k'_n) − 1/n. So lim d(x, k_n) ≥ δ(x, K') and therefore δ(x, K) ≥ lim d(x, k_n) ≥ δ(x, K') for all x ∈ X.

We next show that δ(x, K') ≥ δ(x, K) for all x ∈ X. Since K is uniquely remotal, there exists k_x ∈ K such that d(x, k_x) = δ(x, K). Then k_x ∈ K', since FarK ⊆ K'. So δ(x, K') ≥ d(x, k_x) = δ(x, K). Hence δ(x, K') = δ(x, K).
