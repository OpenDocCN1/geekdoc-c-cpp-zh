+   * 10.53 Consider the problem of right-justifying a paragraph. The paragraph contains a sequence of words $w_1, w_2, \dots, w_N$ of length $\alpha_1, \alpha_2, \dots, \alpha_N$, which we wish to break into lines of length $L$. Words are separated by blanks whose ideal length is $b$ (millimeters), but blanks can stretch or shrink as necessary (but must be $> 0$), so that a line $w_{i+1} \dots w_j$ has length exactly $L$. However, for each blank $b'$ we charge $|b' - b|$ ugliness points. The exception to this is the last line, for which we charge only if $b' < b$ (in other words, we charge only for shrinking), since the last line does not need to be justified. Thus, if $b_i$ is the length of the blank between $\alpha_i$ and $\alpha_{i+1}$, then the ugliness of setting any one line (but the last) $w_{i+1} \dots w_j$ for $j > i$ is $\sum_{k=i}^{j-1} |b_k - b| = (j - i)b' - b$, where $b'$ is the average size of a blank on this line. This is true of the last line only if $b' < b$, otherwise the last line is not ugly at all.
+   a. Give a dynamic programming algorithm to find the least ugly setting of $w_1, w_2, \dots, w_N$ into lines of length $L$. (Hint: For $i = N, N - 1, \dots, 1$, compute the best way to set $w_i, w_{i+1}, \dots, w_N$.)
+   b. Give the time and space complexities for your algorithm (as a function of the number of words, $N$).
+   c. Consider the special case where we are using a fixed-width font, and assume the optimal value of $b$ is 1 (space). In this case, no shrinking of blanks is allowed, since the next smallest blank space would be 0. Give a linear-time algorithm to generate the least ugly setting for this case.
