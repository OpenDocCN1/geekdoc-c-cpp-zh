The function findNewVertexOfIndegreeZero scans the array of vertices looking for a vertex with indegree 0 that has not already been assigned a topological number. It returns NOT_A_VERTEX if no such vertex exists; this indicates that the graph has a cycle.
Because findNewVertexOfIndegreeZero is a simple sequential scan of the array of vertices, each call to it takes O(|V|) time. Since there are |V| such calls, the running time of the algorithm is O(|V|^2).
