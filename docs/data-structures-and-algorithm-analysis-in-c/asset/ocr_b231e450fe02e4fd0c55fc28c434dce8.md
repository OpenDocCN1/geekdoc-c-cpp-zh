We also see that \(S_l(P) \ge S_l(X)\). Consequently, \(R_l(X) \le R_l(P)\). Making this substitution gives

\(AT_{zig-zag} \le 2 + R_l(P) + R_l(G) - 2R_l(X)\)

From Figure 11.21 we see that \(S_l(P) + S_l(G) \le S_l(X)\). If we apply Lemma 11.4, we obtain

\(\log S_l(P) + \log S_l(G) \le 2 \log S_l(X) - 2\)

By the definition of \(rank\), this becomes

\(R_l(P) + R_l(G) \le 2R_l(X) - 2\)

Substituting this, we obtain

\(AT_{zig-zag} \le 2R_l(X) - 2R_l(X)\)
\(\le 2(R_l(X) - R_l(X))\)

Since \(R_l(X) \ge R_l(X)\), we obtain

\(AT_{zig-zag} \le 3(R_l(X) - R_l(X))\)

Zig-zig step. The third case is the zig-zig. The proof of this case is very similar to the zig-zag case. The important inequalities are \(R_l(X) = R_l(G)\), \(R_l(X) \ge R_l(P)\), \(R_l(X) \le R_l(P)\), and \(S_l(X) + S_l(G) \le S_l(X)\). We leave the details as Exercise 11.8.

The amortized cost of an entire splay is the sum of the amortized costs of each splay step. Figure 11.22 shows the steps that are performed in a splay at node 2. Let \(R_1(2)\), \(R_2(2)\), \(R_3(2)\), and \(R_4(2)\) be the rank of node 2 in each of the four trees. The cost of the first step, which is a zig-zag, is at most \(3(R_1(2) - R_1(2))\). The cost of the second step, which is a zig-zig, is \(3(R_2(2) - R_2(2))\). The last step is a zig and has cost no larger than \(3(R_4(2) - R_3(2)) + 1\). The total cost thus telescopes to \(3(R_4(2) - R_1(2)) + 1\).
