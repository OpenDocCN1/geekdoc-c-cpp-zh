# 7.5.1 Analysis of Heapsort

As we saw in Chapter 6, the first phase, which constitutes the building of the heap, uses less than 2N comparisons. In the second phase, the ith deleteMax uses at most less than 2(log N - (i + 1)) comparisons, for a total of at most 2Nlog N - O(N) comparisons (assuming N >= 2). Consequently, in the worst case, at most 2Nlog N - O(N) comparisons are used by heapsort. Exercise 7.13 asks you to show that it is possible for all of the deleteMax operations to achieve their worst case simultaneously.
