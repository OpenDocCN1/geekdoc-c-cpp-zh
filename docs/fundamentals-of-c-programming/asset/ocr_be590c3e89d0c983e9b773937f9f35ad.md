Two of the operators above, + and -, serve also as unary operators. A unary operator has only one operand. The - operator expects a single numeric expression (literal number, variable, or complex numeric expression within parentheses) immediately to its right; it computes the additive inverse of its operand. If operand is positive (greater than zero), the result is a negative value of the same magnitude; if the operand is negative (less than zero), the result is a positive value of the same magnitude. Zero is unaffected. For example, the following code sequence

```
```cpp
int x = 3;
int y = -4;
int z = 0;
std::cout << -x << " " << -y << " " << -z << '\n';

-3 4 0

The following statement

std::cout << -(4 - 5) << " \n";

The unary + operator is present only for completeness: when applied to a numeric value, variable, or expression, the resulting value is no different from the original value of its operand. Omitting the unary + operator from the following statement

```
```cpp

```

All the arithmetic operators are subject to the limitations of the data types on which they operate; for example, on a system in which the largest int is 2,147,483,647, the expression

```
2147483647 + 1
```

will not evaluate to the correct answer since the correct answer falls outside the range of ints.
