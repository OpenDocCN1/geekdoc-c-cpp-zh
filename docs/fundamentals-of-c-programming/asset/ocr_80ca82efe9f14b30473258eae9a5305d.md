```
for (auto iter = vec.begin(); iter != vec.end(); iter++)
 std::cout << *iter << ' ';
 std::cout << '\n';
}
```

The std::begin and std::end functions are overloaded to work with vector objects, arrays, and other container classes found in the standard library. Listing 20.10 (iteratolooparray.cpp) is the array version of Listing 20.8 (iteratoloop.cpp):

```
Listing 20.10: iteratolooparray.cpp

#include <iostream>
#include <vector>

int main() {
 // Make a static integer array
 int arr[] = {10, 20, 30, 40, 50};
 // Print the contents of the array
 for (auto iter = std::begin(arr); iter != std::end(arr); iter++)
 std::cout << *iter << ' ';
 std::cout << '\n';
}
```

The output of Listing 20.10 (iteratolooparray.cpp) is identical to Listing 20.8 (iteratoloop.cpp):

```
10 20 30 40 50
```

Any type for which the std::begin and std::end functions have been overloaded may participate in a range-based for statement. In fact, the compiler internally transforms a range-based for construct into its equivalent std::begin/std::end form during the compilation process. The compiler will transforms the following code:

```
for (auto i : vec)
 std::cout << i << ' ';
```

into code similar to the following:

```
for (auto __i = std::begin(vec); __i != std::end(vec); __i++)
 std::cout << *__i << ' ';
```
