The last argument passed to the std::shuffle function is an object that generates a pseudorandom number on demand. The function uses this pseudorandom number generator to randomly reposition the elements within the container. Section 13.5 introduced the std::mt19937 high-quality pseudorandom number generator used in Listing 20.39 (testshuffle.cpp).

Note that the std::shuffle function applies only to containers that support random access. The std::list class, for example, has no operator[] method and does not support random access. This means you cannot permute the elements in a std::list object using std::shuffle.
