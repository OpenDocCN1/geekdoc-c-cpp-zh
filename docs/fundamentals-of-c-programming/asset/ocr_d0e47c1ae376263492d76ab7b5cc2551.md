The constructor attempts to open a file output stream to write logging information to a text file. If the constructor cannot for any reason open the text file for writing, it terminates the program's execution. The destructor closes the file stream object when the LogComparer object's life is over.

The two overidden methods, compare_impl and swap_impl, write text to the log file. Both methods use the LogComparer object's fout field rather than the std::cout console output stream object.

Notice that even though the override keyword appears after the method declarations in logcomperer.h, it does not appear after the method implementations in logcomperer.cpp.
