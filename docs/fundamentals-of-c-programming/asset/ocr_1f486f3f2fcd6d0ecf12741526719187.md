```
struct Cmp {
    bool operator()(int i1, int i2) {
        return i2 < i1;
    }
};
```

This special method, `operator()`, is the *function invocation operator*, or *function call operator*. It enables any instance of the Cmp class to be used like a function. To see how this works, consider Listing 20.3 (calloperator.cpp).

# Listing 20.3: calloperator.cpp

```
#include <iostream>

struct Cmp {
    bool operator()(int i1, int i2) {
        return i2 < i1;
    }
};

int main() {
    Cmp op;
    std::cout << std::boolalpha;
    std::cout << op(2, 3) << '\n';
    std::cout << op(3, 2) << '\n';
    std::cout << op(3, 3) << '\n';
}
```

Listing 20.3 (calloperator.cpp) prints the following:

```
false
true
false
```

The first output line indicates it is false that 3 < 2. The second line reveals that it is true that 2 < 3, and in the last line we see that it is false that 3 < 3.

The expression op(2, 3) looks like a call to the function named op, but really it is just syntactic sugar for `op.operator()(2, 3)`. We see that we really are invoking the method named `operator()` on behalf of the op object.
