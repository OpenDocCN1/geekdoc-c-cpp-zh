Listing 6.10 (timestable-1st-try.cpp) does indeed print each row in its proper place—it just does not supply the needed detail for each row. Our next step is to refine the way the program prints each row. Each row should contain size numbers. Each number within each row represents the product of the current row and current column, for example, the number in row 2, column 5 should be 2 x 5 = 10. In each row, therefore, we must vary the column number from from 1 to size. Listing 6.11 (timestable-2nd-try.cpp) contains the needed refinement.
