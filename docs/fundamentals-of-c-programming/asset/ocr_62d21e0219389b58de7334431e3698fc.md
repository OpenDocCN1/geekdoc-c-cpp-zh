steps to ensure that division by zero does not occur. Listing 5.3 (betterdivision.cpp) shows how it might be done.

# Listing 5.3: betterdivision.cpp

```
#include <iostream>

int main() {
    int dividend, divisor;

    // Get two integers from the user
    std::cout << "Please enter two integers to divide:";
    std::cin >> dividend >> divisor;

    // If possible, divide and report the result
    if (divisor != 0)
        std::cout << dividend << "/" << divisor << " = "
                  << dividend/divisor << '\n';
}
```

The second std::cout statement may not always be executed. In the following run

![](bbox=[0.17, 0.41, 0.86, 0.44])

it is executed, but if the user enters a zero as the second number:

![](bbox=[0.17, 0.475, 0.86, 0.495])

the program prints nothing after the user enters the values.

The last statement in Listing 5.3 (betterdivision.cpp) begins with the reserved word if. The if statement allows code to be optionally executed. In this case, the printing statement is executed only if the variable divisor's value is not zero.

# The Boolean expression

```
divisor != 0
```

determines if the single statement that follows the right parenthesis is executed. If divisor is not zero, the message is printed; otherwise, the program prints nothing.
