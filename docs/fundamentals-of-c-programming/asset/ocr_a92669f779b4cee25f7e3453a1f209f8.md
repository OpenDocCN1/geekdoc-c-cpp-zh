An interesting problem arises if a method in a derived class needs to use an inherited variable. If the variable is declared private in the base class, a derived class method cannot access it. The private specifier means "not available outside the class, period." We know it is unwise in general to make instance variables public, since that breaks encapsulation. Encapsulation is a desirable property, C++ provides a third level of access protection within a class—protected. A protected member, whether it be data or a method, is inaccessible to all code outside the class, except for code within a derived class. The use of protected is illustrated in the shapes code.
