```
std::cout << "The letter at index 3 is " << word[3] << '\n';
```

The expression

```
word.operator[](3)
```

is equivalent to the expression

```
word[3]
```

We see that operator[] works exactly like its namesake in the std::vector class Section 11.1.3.
