This ability to deallocate its referenced memory at the proper time is what makes a std::shared_ptr object a smart pointer.

Recall Listing 18.1 (howtodelete.cpp) that demonstrated the difficulty of managing dynamic memory manually. Listing 18.22 (smartdelete.cpp) converts the raw pointer of the return value of the get_widget function of Listing 18.1 (howtodelete.cpp) into a std::shared_ptr. The result? We no longer need to worry about who 'owns' the memory of the heap allocated objects; std::shared_ptr objects manage all those details. No deletes are necessary.
