The standard library provides an special iterator, std::ostream_iterator, that enables the std::copy function to copy the contents of a container to an output stream instead of another container. Listing 20.29 (copytostream.cpp) shows how this special iterator works.

```cpp
#include <iostream>
#include <vector>
#include <iterator>

int main() {
  std::vector<int> vec { 10, 20, 30, 35, 40, 45, 50, 55 };

  // Copy the contents of the container to std::cout, separating
  // elements with a single space
  auto strm = std::ostream_iterator<int>(std::cout, " ");
  std::copy(std::begin(vec), std::end(vec), strm);
  std::cout << "\n";
}
