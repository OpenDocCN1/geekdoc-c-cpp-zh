// Local declarations in main
#include <iostream>

int main() {
    // These function declarations are local to main

    int three_times(int);
    std::cout << two_times(5) << '\n';
    std::cout << three_times(5) << '\n';

```

The declaration for the two_times function given in main in Listing 9.23 (localfuncdef2.cpp) is not visible in the three_times function; thus, the program will not compile.

Note that while C++ allows us to declare a function within the body of another function, it does not allow us to define a function inside the body of another function. C++ does not support nested function definitions.

Some programmers prefer to declare all their functions before their use within the program (as in Listing 9.20 (organization2.cpp) or Listing 9.21 (organization3.cpp)) and define the functions after their use
