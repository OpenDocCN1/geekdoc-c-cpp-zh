## 简介

《A Byte of Python》是一本关于使用 Python 语言进行编程的书籍。它为初学者读者提供了 Python 语言的教程或指南。如果你们都了解电脑，比如如何保存文本文件，那么这本书就是为你们准备的。

本书已针对新的 Python 3.0 进行了更新。如果你正在寻找当前 Python 2.x 版本的教程，请下载该书之前的版本 [5]。同样，如果你在犹豫是学习 Python 2.x 还是 3.x，可以阅读 James Bennett 撰写的这篇文章 [6]。

## 在：导言中的 Python

### 导言

Python 是少数几个可以自称既简单又强大的语言之一。你会发现，将精力集中在问题的解决方案而不是你所编程语言的语法和结构上，这让你感到非常惊喜。

Python 的官方介绍是：

- Python 是一门易于学习、强大的编程语言。它具有高效的高级数据结构和简单但有效的面向对象编程方法。Python 优雅的语法和动态类型，加上它的解释型特性，使其成为许多平台许多领域脚本编写和快速应用程序开发的理想语言。

我将在下一节中详细讨论这些大部分特征。


- Python 语言的创造者 Guido van Rossum 以 BBC 节目《蒙蒂 Python 的飞行马戏》命名了该语言。他并不特别喜欢那些通过杀害动物来饱满长身体并将其压碎的蛇。

## Python 的特性

### 简单

Python 是一种简单且极极主义主义的语言。阅读一个良好的 Python 程序感觉几乎就像在读英语，尽管是非常严格的英语！Python 的这种伪代码性质是它最大的优势之一。它允许你专注于问题的解决方案，而不是语言本身。

### 易于学习

如你所见，Python 入门非常容易。正如前面提到的，Python 拥有极其简单的语法。

### 免费且开源

Python 是 FLOSS（自由/自由开源软件）的一个示例。简单来说，你可以自由地分发该软件的副本，阅读其源代码，对其进行修改，并在新的免费程序中使用它的部分代码。FLOSS 基于共享知识的社区概念。这是 Python 如此好的原因之一——它由一个只想使用更好 Python 的社区创建并不断改进。

### 高级语言

当你在用 Python 编写程序时，你永远不需要担心低级细节，例如管理程序使用的内存等等。

### 可移植性

由于其开源性质，Python 已经被移植到（即经过修改以便在……的平台上运行）许多平台。只要你足够小心地避免任何依赖于系统的特性，你所有的 Python 程序都可以在这些任何一个平台上运行，而无需任何更改。

你可以在 Linux、Windows、FreeBSD、Macintosh、Solaris、OS/2、Amiga、AROS/400、FreeBSD、OS/390、z/OS、Palm OS、QNX、VMS、Psion、Acorn RISC OS、VxWorks、PlayStation、Sharp Zaurik、Windows CE 和 PocketPC 上使用 Python！

### 解释型

这需要一点解释。

用 C 或 C++ 等编译型语言编写的程序，使用带有各种标志和选项的编译器，从源码（即 C 或 C++）转换为你的计算机执行的语言（二进制代码，即 0 和 1）。当你运行程序时，链接器/加载器软件将程序从硬盘复制到内存并开始运行。

相反，Python 不需要编译为二进制文件。你只需要直接从源代码运行程序。在内部，Python 将源代码转换为中间形式字节码，并将其翻译为你计算机的语言然后运行。实际上，这一切让 Python 变得容易得多，因为你不需要担心编译程序、确保链接并加载了正确的库等等。这也让你的程序具有更好的可移植性，因为你只需要将你的 Python 程序复制到另一台计算机上它就能运行！

### 面向对象

Python 支持过程化编程，也支持面向对象编程。在过程化语言中，程序围绕过程或函数构建，而这些不是可重用的程序段。在面向对象语言中，程序围绕结合数据和功能的对象构建。Python 是实现 OOP 的一种非常强大且简单的方法，特别是与 C++ 或 Java 这样的大语言相比。

### 可扩展

如果你需要某部分关键代码运行非常快，或者希望某些算法代码不公开，你可以用 C 或 C++ 编写程序的该部分，然后通过你的 Python 程序使用它。

### 可嵌入

你可以将 Python 嵌入到 C/C++ 程序中，为程序的程序的用户提供“脚本”能力。

### 丰富的库

标准库确实巨大。它可以帮助你做各种事情，包括正则表达式、文档生成、单元测试、线程、数据库、网络浏览器、CGI、FTP、电子邮件、XML、XML-RPC、HTML、WAV 文件、加密、GUI（图形用户界面）、Tk 以及其他依赖系统的东西。记住，所有这些在任何安装了 Python 的地方可用。这被称为 Python 的“内置电池”（Batteries Included）哲学。

除了标准库，还有其他高质量的库，如 wxPython (http://www.wxpython.org)、Twisted (http://www.twistedmatrix.com/products/twisted)、Python Imaging Library (http://www.pythonware.com/products/pil/index.htm) 等许多。

## 为什么不选择 Perl？

如果你还不知道，Perl 是另一种非常流行的开源解释型语言。

如果你曾经写过大型程序，你就会自己回答过这个问题了！换句话说，Perl 程序在很小时很容易，并且擅长“完成工作”的小脚本。然而，一旦你开始编写程序，它们就会变得难以处理。

与 Perl 相比，Python 程序明显简单、更容易编写，因此更易维护。我钦佩 Perl 并在编写程序时每天使用它，因为 Perl 经历了太多的黑客，以至于感觉就像一个巨大的（或半个）黑客。遗憾的是，即将 Perl 6 似乎没有在这方面做出任何改进。

Perl 的唯一且非常显著优势是它巨大的 CPAN (http://cpan.perl.org) 库——综合 Perl 归档网络。正如名称所示，这是一个巨大的 Perl 模块集合，其规模和深度简直令人震惊——你可以用这些模块做任何事情。Perl 库比 Python 多的原因之一是它出现的时间比 Python 长得多。然而，随着 Python Index (http://pypi.python.org/pypi) 的增长，这种情况正在发生。

### 转义序列

假设你想定义一个包含单引号（'''）的字符串，你该如何指定这个字符串呢？例如，字符串是 What's your name?。你不能直接指定 'What's your name?'，因为 Python 会混乱字符串从哪里开始和结束。因此，你必须指定这个单引号不表示字符串的结束。这可以通过所谓的“转义序列”来实现。你将单引号指定为 '\' —— 注意这里的反斜杠。现在，你可以将字符串指定为 'What's your name?

另一种指定此特定字符串的方法是使用 "What's your name?" ，即使用双引号。同样，如果你在双引号字符串中使用双引号本身，也必须使用转义序列。此外，你必须使用转义序列 \\ 来指定反斜杠本身。

```

等同于 "This is the first sentence. This is the second sentence.".

### format 方法

有时我们想要从其他信息构建字符串。这就是 `format()` 方法很有用的时候。

```
#!/usr/bin/python
### Filename: str_format.py
age = 25

输出：

```
### python str_format.py

Why is Swaroop playing with that python

### 工作原理：

字符串可以使用某些规范，随后可以调用 `format` 方法，用 `format` 方法的相应参数替换这些规范。


观察我们关心的第一个用法 {}，它对应变量名，即 `format` 方法的第一个参数。同样，第二个规范 {1} 对应 age，它是 `format` 方法的第二个参数。

注意，我们可以使用字符串拼接 `name + ' ' + str(age) + ' years old'` 实现相同的效果，但这样做是多么糟糕且容易出错。到字符串的转换将由 `format` 方法自动完成，而不是在此处进行显式转换。第三，当使用 `format` 方法时，我们可以更改消息而无需处理所使用的变量，反之亦然。

Python 在 `format` 方法中所做的是将每个参数的值替换到规范的位置。可以更详细的规范，例如：

```
>>> '{0.3f}'.format(1/3) # 浮点数的小数 (.) 精度为3
'0.333'
>>> '{0:_<10}'.format('hello') # 用下划线 (_)填充，文本居中 ('')，宽度为 10
_hello____
>>> '{name} wrote {book}'.format(name='Swarwoop', book='A Byte of Python')
```

这种格式化的细节在 Python 增强提案第 3101 号 (http://www.python.org/dev/) 中解释。

## 逻辑行与物理行

物理行是你编写程序时看到的内容。逻辑行是 Python 视为单个语句的内容。Python 隐式地假设每个物理行对应一个逻辑行。

逻辑行的一个示例是语句 `'Hello World!'` —— 如果它单独占一行（如果你在编辑器中看到它），那么它也对应一个物理行。

隐式地，Python 鼓励每行使用单个语句，这使得代码具有可读性。

如果你想在单行物理上指定指定行，可以使用分号（`;`），但你必须显式地使用分号来指定，分号表示逻辑行/语句的结束。例如：

```
i = 5
print(i)
```

实际上等同于

```
i = 5;
print(i);
```

也可以写成

```
i = 5; print(i);
```

或者甚至

```python
i = 5; print(i)
```

然而，我强烈建议你坚持在单个物理行中写单个逻辑行。只有当逻辑行非常长时，才对单个逻辑行使用多个物理行。这种做法的理念是尽可能使用分号，因为它能带来更可读性的代码。事实上，我从未在 Python 程序中用过甚至分号。

## 缩进

空白在 Python 中非常重要。实际上，**行首的空白是重要的**。这被称为**缩进**。逻辑行开头的前导空白（空格和制表符）用于确定逻辑行的缩进级别，反之，它被用于确定语句的分组。

这意味着组合在一起的语句**必须**具有相同的缩进。每组语句被称为一个**块（block）**。我们将在稍后的章节中看到关于块为什么很重要的示例。

你应该记住的一点是，错误的缩进会导致错误。例如：

```
i = 5
print('Value is ', i ) # 错误！注意行开头的单个空格
print('I repeat, the value is ', , i)
```

当你运行此代码时，将得到以下错误：

```
File "Whitespace.py", line 4
print('Value is ', i ) # 错误！注意行开头的单个
空格
^
entationError: unexpected indent
```

注意第二行开头有一个空格。Python 指示的错误告诉你程序的语法是无效的，即程序没有写得正确。对你来说，这意味着你**不能随意启动语句块**（当然，除了你一直在使用的主块除外）。可以使用新块的情况将在后面的章节中详细介绍，例如控制流章节。

## 如何缩进

不要混合使用制表符（tabs）和空格进行缩进，因为它们在不同平台上无法正常工作。我*强烈建议*你为每个缩进级别使用*单个制表符或四个*空格。选择这两种缩进风格中的一种。更重要的是，选择一种并**一致地**使用，即*仅*使用那种缩进风格。

你大多数语句（逻辑行）将包含**表达式**。表达式的一个简单示例是 `2 + 3`。一个表达式可以拆分为运算符和操作数。**运算符**是执行某些操作的功能，可以使用符号（如 `or`）或特殊键表示。运算符需要一些数据进行操作，这些数据被称为**操作数**。在这种情况下，`2` 和 `3` 就是操作数。

## 运算符

我们将简要查看运算符及其用法：
注意，你可以使用解释器交互评估示例中的表达式。例如，测试表达式 `2 + 3`，使用交互式解释器提示符：

### 改变求值顺序

为了让表达式更具可读性，我们可以使用括号。例如，`2 + (3 * 4)` 绝对比需要运算符优先级的 `2 + 3 * 4` 更容易理解。与其他任何事情一样，括号应该合理使用（不要过度），且不应该是冗余的（例如 `2 + (3) * 4`）。

使用括号还有一个额外优势——它可以帮助我们改变求值顺序。例如，如果你想在表达式中先计算加法再计算乘法，你可以写成类似 `(2 + 3) * 4` 的代码。

### 结合性

运算符通常从左到右结合，即优先级相同的运算符按左到右的方式评估。例如，`2 + 3 + 4` 被评估为 `(2 + 3) + 4`。某些运算符（如赋值运算符）具有从右到左的结合性。`a = b = c` 被视为 `a = (b = c)`。

## Python 中：控制流

## 引言

在我们到目前为止看到的程序中，总有一系列语句，Python 忠实地按照相同的顺序执行它们。如果你想改变它的运行流程呢？例如，你想让程序根据不同的情况做出决定并执行不同的操作，比如根据一天的时间打印“早上好”或“晚上好”？

正如你可能猜到的那样，这是通过使用控制流语句实现的。Python 中三个控制流语句：`if`、`for` 和 `while`。

## if 语句

`if` 语句用于检查条件，如果条件为真，我们运行块语句（称为 `if-block`），否则我们处理另一块语句（称为 `else-block`）。`else` 子句是可选的。

示例：

```
#!/usr/bin/python
### Filename: if.py
number = 23
guess = int(input('Enter an integer : '))
if guess == number:
    print('Congratulations, you guessed it.') # 新块在此开始
    print('but you do not win any prizes!') # 新块结束
elif guess < number:
    print('No, it is a little higher than that') # 另一个块
    # 你可以在块中做任何你想做的事...
else:
    print('No, it is a little lower than that')
    # 你必须让 guess > number 才能到达这里
```

print('Done')
### 最后一条语句在 if 语句执行后总是会被执行

输出：

```
$ python if.py
Enter an integer : 50
No, it is a little lower than that
Done

$ python if.py

```

### while 语句

`while` 语句允许你在条件为真时重复执行一个语句块。`while` 语句是所谓的循环语句的一个示例。`while` 语句可以带有一个可选的 `else` 子句。

示例：

```python
#!/usr/bin/python
### Filename: while.py

number = 23
running = True

while running:
    guess = int(input('Enter an integer : '))

    if guess == number:
        print('Congratulations, you guessed it.')
        running = False # 这会导致 while 循环停止
    elif guess < number:
        print('No, it is a little higher than that.')
    else:
        print('No, it is a little lower than that.')

print('The while loop is over.')
### 在此处进行任何你想做的其他操作
```

```bash
$ python while.py
Enter an integer : 50
No, it is a little lower than that.
Enter an integer : 22
No, it is a little higher than that.
Enter an integer : 23
Congratulations, you guessed it.
The while loop is over.
Done
```

工作原理：

在这个程序中，我们仍然在玩猜游戏，但优势是允许用户一直猜，直到猜对为止——不需要像我们在上一节中的那样为每次猜测都反复运行程序。这恰恰演示了 `while` 语句的使用。

我们将 `input` 和 `if` 语句移动到 `while` 循环内部，并在 `while` 循环之前设置变量 `running`。首先检查变量 `running` 是否为 `True`，然后执行相应的 `while` 块。在执行完该块后，再次检查条件（在本例中是变量 `running`）。如果为真，我们再次执行 `while` 块；否则继续执行可选的 `else` 块，然后继续执行下一个语句。

当 `while` 循环条件变为 `False` 时，会执行 `else` 块——这可能是第一次检查条件。如果 `while` 循环有一个 `else` 子句，除非你使用 `break` 语句跳出循环，否则它会被执行。

`True` 和 `False` 被称为布尔类型，你可以将它们分别等同于值 `1` 和 `0`。

记住你可以为 `while` 循环编写一个 `else` 子句。

### for 循环

`for..in` 语句是另一种循环语句，用于遍历对象序列，即序列中的每个项。我们将在稍后的章节中详细介绍更多序列。你现在需要知道的是序列仅仅是项的有序集合。

示例：

```python
#!/usr/bin/python
### Filename: for.py
for i in range(1, 5):
    print(i)
else:
    print('The for loop is over')
```

输出：

```bash
$ python for.py
1
2
3
4
The for loop is over
```

工作原理：

在这个程序中，我们正在打印一个数字序列。我们使用内置的 `range` 函数生成这个数字序列。

在这里我们做的是提供两个数字，`range` 返回一个从第一个数字开始到第二个数字之前的数字序列。例如，`range(1,5)` 序列 `[1, 2, 3, 4]`。默认情况下，`range` 的步长为 `1`。如果我们向 `range` 提供第三个数字，那么它将成为步长。例如，`range(1,5,2)` 给出 `[1,3]`。记住 `range` 扩展到第二个数字，即不包含第二个数字。

`for` 循环遍历这个范围——`for i in range(1,5)` 等同于 `for i in [1, 2, 3, 4]`，这会将序列中的每个数字（或对象）赋值给 `i`，然后为 `i` 的每个值执行语句块。在这种情况下，我们只是在语句块中打印该值。

记住 `else` 部分是可选的。当包含它时，在循环结束后总是执行一次，除非遇到 `break` 语句。

记住 `for..` 循环适用于任何序列。在这里，我们有一个由内置 `range` 函数生成的数字列表，但通常可以使用任何类型的序列或任何类型的对象！我们将在稍后的章节中探索这些细节。

### 给 C/C++/Java/C# 程序员的说明

Python 的 `for` 循环与 C/C++ 的循环完全不同。C# 程序员会注意到 Python 的 `for` 循环类似于 C# 中的 `foreach` 循环；Java 程序员会注意到它与 Java 1.5 中的 `for (int : IntArray)` 相似。

在 C/C++ 中，如果你想写 `for (int i = 0; i < 5; i++)`，那么在 Python 中只需写 `for i in range(0,5)`。正如你所看到的，`for` 更简单、更具表现力，且不易出错。

### break 语句

`break` 语句用于跳出循环语句，即如果循环条件尚未变为 `False` 或项序列未完全迭代，则停止循环语句的执行。

一个重要的点是，如果你跳出了 `for` 或 `while` 循环，任何相应的循环 `else` 块将不会被执行。

示例：

```python
#!/usr/bin/python
### Filename: break.py

while True:
    s = input('Enter something : ')
    if s == 'quit':
        break
    print('You entered:', s)
```

输出：

```bash
$ python break.py
Enter something : hello
You entered: hello
Enter something : world
You entered: world
Enter something : quit
```

工作原理：

在这个程序中，我们仍然在玩猜游戏，但优势是允许用户一直猜，直到猜对为止——不需要像我们在上一节中的那样为每次猜测都反复运行程序。这恰恰演示了 `break` 语句的使用。

### continue 语句

`continue` 语句用于跳过循环的剩余部分，如果循环条件尚未变为 `False` 或项序列未完全迭代。

示例：

```python
#!/usr/bin/python
### Filename: continue.py

while True:
    s = input('Enter something : ')
    if s == 'quit':
        break
    if len(s) < 3:
        print('Too small')
        continue
    print('Input is sufficient length')
```

输出：

```bash
$ python continue.py
Enter something : a
Too small
Enter something : ab
Too small
Enter something : abc
Input is sufficient length
Enter something : quit
```

工作原理：

在这个程序中，我们接受用户的输入，但只有当长度至少为 3 个字符时才进行处理。因此，我们使用内置的 `len` 函数获取长度，如果长度小于 3，我们使用 `continue` 语句跳过块中的剩余语句；否则，执行循环的其余语句，我们可以在此处进行任何你想做的其他操作。

记住 `continue` 语句适用于 `for` 循环。

## 函数参数

函数可以接受参数，参数是您提供给函数的值，以便函数利用这些值执行某些操作。这些参数就像变量，不同之处在于这些变量的值是在调用函数时定义的，并且在函数运行时已经赋值了。

参数指定在函数定义的一对括号内，并用逗号分隔。当我们调用函数时，我们以相同的方式提供值。注意所使用的术语 - 在函数定义中给出的名称称为**参数 (parameters)**，而您在函数调用中提供的值称为**参数 (arguments)**。

在 `printMax` 的第一次使用中，我们直接提供了数字，即参数。在第二次使用中，我们通过变量调用函数。`printMax(x, y)` 导致参数 `x` 的值被赋值给参数 `a`，`y` 的值被赋值给参数 `b`。`printMax` 函数在两种情况下工作原理相同。

## 局部变量

当您在函数定义内部声明变量时，它们与函数外部使用的同名变量没有任何关系，即变量名是函数**局部的**。这被称为变量的**作用域 (scope)**。所有变量的作用域都是从名称定义点开始的所在块的作用域。

示例：

```python
#!/usr/bin/python
### Filename: func_local.py
```

x = 50

```python
def func(x):
    print('x is', x)
    x = 2
    print('Changed local x to', x)
```

```python
func(x)
print('x is still', x)
```

输出：

```
$ python func_local.py
x is 50
Changed local x to 2
x is still 50
```

工作原理：

在函数内部，我们第一次使用名称 `x` 的值时，Python 使用函数中声明的的值。

接下来，我们将值 `2` 赋值给 `x`。该名称对我们的函数是局部的。因此，当我们在函数中更改 `x` 的值时，主块中定义的 `x` 不受影响。

在最后一个 `print` 调用中，我们显示了主块中 `x` 的值，并确认它实际上不受影响。

## 使用 global 语句

如果您想给在程序顶层定义的名称赋值（即不在任何种类型的作用域内，如函数或类），那么您必须告诉 Python 该名称不是局部的，而是**全局的 (global)**。我们使用 `global` 语句来实现这一点。如果不使用 `global` 语句，无法给函数外部定义的变量赋值。

您可以使用在函数外部定义的此类变量的值（假设函数内部没有同名变量）。然而，不鼓励这样做，并且应该避免，因为程序的读者来说不清楚该变量的定义在哪里。使用 `global` 语句可以清楚地表明变量定义在最外层块。

示例：

```python
#!/usr/bin/python
### Filename: func_global.py

x = 50

def func():
    global x
    print('x is', x)
    x = 2
    print('Changed global x to', x)

func()
print('Value of x is', x)
```

输出：

```
$ python func_global.py
x is 50
Changed global x to 2
Value of x is 2
```

工作原理：

`global` 语句用于声明 `x` 是一个全局变量 - 因此，当我们在函数内部为 `x` 赋值时，这个更改会在主块中使用 `x` 的值时反映。

您可以使用同一个 `global` 语句指定多个全局变量。例如，`global x, y, z`。

## 使用 nonlocal 语句

我们在上面已经了如何访问局部和全局作用域中的变量。还有另一种作用域被称为“非局部 (nonlocal)”作用域，它介于这两种作用域之间。当在函数内部定义函数时，就会观察到非局部作用域。由于 Python 中的一切都是可执行代码，您可以在任何地方定义函数。

让我们来看来看：

```python
#!/usr/bin/python
### Filename: func_nonlocal.py
```

```python
def func_outer():
    x = 2
    print('x is', x)

    def func_inner():
        nonlocal x
        x = 5

    func_inner()
    print('Changed local x to', x)
```

func_outer()

输出：

```
$ python func_nonlocal.py
x is 2
Changed local x to 5
```

工作原理：

当我们在 `func_inner` 内部时，`func_outer` 第一行定义的 'x' 既不在局部作用域也不在全局作用域内。我们通过 `nonlocal` 声明我们正在使用这个 `x`，从而获取该变量。
将非局部 `x` 改为全局 `x` 以及删除该语句本身，观察这两种情况下行为的区别。

## 默认参数值

对于函数，您可能希望将其某些参数设置为可选的，如果用户没有为这些参数提供值，则使用默认值。这是通过默认参数值来实现的。您可以通过在函数定义中的参数名后跟随赋值运算符 (`=`) 以及默认值来为参数指定默认值。

注意，默认参数值应该是常量。更准确地说，默认参数值应该是不可变的 (immutable)——将在后面的章节中详细解释。现在只需记住这一点。

示例：

```python
#!/usr/bin/python
### Filename: func_default.py
def say(message, times = 1):
    print(message * times)
```

```python
say('Hello')
say('World', 5)
```

输出：

```
$ python func_default.py
Hello
HelloWorldWorld
```

工作原理：

名为 `say` 的函数按照指定的次数打印字符串。如果我们不提供值，默认只打印一次。我们通过为参数 `times` 指定默认值 `1` 来实现这一点。

在 `say` 的第一次使用中，我们只提供了字符串，它打印一次字符串。在 `say` 的第二次使用中，我们同时提供了字符串和参数 `5`，表示我们要打印 5 次字符串。

## 重要

只有参数列表末尾的参数可以赋予默认值，即在函数参数列表顺序中，不能将具有默认值的参数放在没有默认值的参数之前。

这是因为值是通过位置赋值给参数的。例如，`def func(a, b=5)` 是有效的，但 `def func(a=5, b)` 是无效的。

## 关键字参数

如果您有一个许多许多参数的函数并且只想指定其中某些，那么您通过命名它们来为此类参数赋值——这被称为**关键字参数 (keyword arguments)**——我们使用名称（关键字）而不是一直以来使用的位置来为函数指定参数。

这有两个优点 - 第一，使用函数变得更简单，因为我们不需要担心参数的顺序。第二，只要其他参数具有默认参数值，我们就可以只为我们需要的参数赋值。

示例：

```python
#!/usr/bin/python
### Filename: func_key.py
```

```python

    print('a is', a, 'and b is', b, 'and c is', c)
```

```python
func(3, 7)
```

输出:

a is 100 and b is 5 and c is 50
```

工作原理：

名为 `func` 的函数包含一个没有默认参数值的参数，后面紧跟着两个带有默认参数值的参数。

在第一次用法 `func(3, 7)` 中，参数获取值 3，参数 `b` 获取值 7，而 `c` 获取了默认值 10。

在第二次用法 `func(25, c=24)` 中，由于参数的位置，变量获取了值 25。然后，由于命名（即关键字参数），参数 `c` 获取了值 24。变量 `b` 获取了默认值 5。

在第三次用法 `func(c=50, a=100)` 中，我们完全使用关键字参数来指定值。注意，我们在为参数 `c` 指定值之前，先指定了函数定义中在 `c` 之前的参数。

## return 语句

`return` 语句用于从函数返回，即跳出函数。我们还可以选择从函数返回一个值。

示例：

```python

    else:

工作原理：

`maximum` 函数返回参数的最大值，在本例中即传递给函数的数字。它使用一个简单的 `if..else` 语句找到较大的值，然后返回该值。

除非你写了自己的 `return` 语句，否则每个函数最后都隐式包含一个 `return None` 语句。你可以通过运行 `print(someFunction())` 看到，其中 `someFunction` 没有使用 `return` 语句：

```python

    pass

`pass` 语句在 Python 中用于表示空语句块。

## Python 模块

当 Python 执行 `import sys` 语句时，它会寻找 `sys` 模块。在这种情况下，它是内置模块之一，因此 Python 知道去哪里找到它。

如果它不是一个编译后的模块（即用 Python 编写的模块），那么 Python 解释器将在其 `sys.path` 变量列出的目录中搜索它。如果找到了该模块，将运行该模块体中的语句，然后提供该模块供你使用。请注意，初始化只会在你第一次导入模块时进行。

`sys` 模块中的 `argv` 变量通过点符号语法访问，即 `sys.argv`。这清楚地表明该名称不会与你程序中使用的任何 `argv` 变量发生冲突。这种方法的另一个优势是 `sys.argv` 变量是一个字符串列表（列表将在后面的章节中详细解释）。具体来说，`sys.argv` 包含了命令行参数列表，即通过命令行传递给程序的参数。

如果你正在使用 IDE 编写和运行这些程序，请寻找一种可以在菜单中指定命令行参数的方法。

在这里，当我们执行 `python sys.py` 时，我们使用 `python` 命令运行了 `using_sys.py` 模块，其他内容都是传递给程序的参数。Python 为我们将命令行参数存储在 `sys.argv` 变量中。

记住，运行的脚本名称是 `sys.argv` 列表中的第一个参数。在这种情况下，我们将 'using.py' 作为 `sys.argv[0]`，'we' 作为 `sys.argv[1]`，'are' 作为 `sys.argv[2]`，'arguments' 作为 `sys.argv[3]`。注意 Python 从 0 开始计数而不是 1。

`sys.path` 包含了导入模块的目录列表。注意 `sys.path` 中的第一个字符串是空的；这个字符串表示当前目录也是 `sys.path` 的一部分，这与 `PYTHONPATH` 环境变量相同。这意味着你可以直接导入当前目录下的模块。否则，你必须将你的模块放在 `sys.path` 列出的目录之一。

请注意，当前目录是启动程序时的目录。运行 `import os; print (os.getcwd())` 来查找你程序的当前目录。

## 字节编译的 .py 文件

导入模块是一项相对昂贵的操作，因此 Python 使用了一些技巧来提高运行速度。一种方法是创建带有 `.pyc` 扩展的字节编译文件，这是 Python 将程序转换的中间格式（记得关于 Python 如何运行的引言部分吗？）。当你下次从另一个程序导入该模块时，这个 `.pyc` 文件将非常有用——它会快得多，因为导入模块所需的的部分处理已经完成。此外，这些字节编译文件是平台无关的。

## 注意

`.pyc` 文件通常在与相应的 `.py` 文件相同的目录中。如果 Python 没有权限向该目录写入文件，则不会创建 `.pyc` 文件。

## The from ... import ...

如果你想直接将 `argv` 变量导入你的程序中（以避免每次都输入 `sys`），你可以使用 `from sys import argv`。如果你想导入 `sys` 模块中使用的所有名称，可以使用 `from sys import *` 语句。这适用于任何模块。

通常情况下，你应该避免使用此语句，而代之使用 `import` 语句，这样你的程序将避免名称冲突并具有更高的可读性。

## 模块的 _name_

每个模块都有一个名称，模块中的语句可以找到运行模块的名称。这在确定模块是独立运行还是被导入的特殊情况下非常有用。如之前提到的，当模块被首次导入时，该模块中的代码会被执行。我们可以利用这个概念，在程序由自己运行而不是从另一个模块导入时改变模块的行为。这可以通过模块的 `_name_` 属性来实现。

示例：

```python
#!/usr/bin/python
### Filename: using_name.py

if __name__ == '__main__':
    print('This program is being run by itself')
else:
    print('I am imported from another module')
```

输出：

```
$ python using_name.py
This program is being run by itself

$ python
>>> import using_name
I am being imported from another module
>>>
```

工作原理：

每个 Python 模块都定义了 `__name__`，如果它的值为 `'__main__'`，则意味着该模块正由用户独立运行，我们可以采取适当的操作。

### 序列

列表、元组和字符串是特殊的序列类型。它们是项目的有序集合，你可以通过索引访问每个项目。索引从 0 开始。你还可以使用切片来获取序列的一部分。

示例：

```python
#!/usr/bin/python
### Filename: seq.py
list = ['apple', 'banana', 'cherry', 'date', 'elderberry']
print(list[0])
print(list[-1])
print(list[1:3])
print(list[:2])
print(list[2:])
```

输出：

```
apple
elderberry
banana cherry
apple banana
cherry date elderberry
```

工作原理：

首先，我们看看如何使用索引来获取序列的单个项。这被称为订阅操作（subscription operation）。每当像上面所示在方括号内指定序列时，Python 将将为你获取序列中对应该位置的项。记住 Python 从 0 开始计数。因此，`list[0]` 获取第一个项，`list[3]` 获取第四个项。

索引也可以是负数，在这种情况下，位置是从序列的末尾计算的。因此，`list[-1]` 指序列中的最后一个项，`list[-2]` 获取倒数第二个项。

切片操作通过使用序列名称后跟一对可选的由冒号分隔的数字并放在方括号内来指定。注意这与你一直使用的索引操作非常相似。记住数字是可选的，但冒号不是。

切片操作中的第一个数字（冒号之前的）指的是切片开始的位置，第二个数字（冒号之后的）指示切片停止的位置。如果没有指定第一个，Python 将从序列的开头开始。如果省略第二个数字，Python 将在序列的末尾停止。注意返回的切片从开始位置开始，并在结束位置之前停止，即包含结束位置。因此，`list[1:3]` 返回从位置 1 开始的序列切片，包含位置 2，在位置 3 停止，因此返回两个项的切片。同样，`list[:]` 返回整个序列的副本。

### 字符串切片

```python
name = "Swaroop"
print(name[0:4])
print(name[2:])
print(name[:3])
```

### 针对 C++/Java/C# 程序员的说明

Python 中的 `self` 等同于 C++ 中的指针以及 Java 中的 `this` 引用。

你可能在想 Python 是如何给 `self` 赋值的，以及为什么你不需要为它赋值。当你调用一个名为 `MyClass` 的类并其实例时，当你调用该对象的方法 `myobject.method(arg, arg2)` 时，Python 会自动将其转换为 `MyClass.method(myobject, arg2)` —— 这就是 `self` 的全部。

这意味着如果你有一个不接受参数的方法，你仍然必须有一个参数 —— `self`。

## Python 之：：面向对象编程

### 对象方法

我们已经讨论过类/对象可以像函数一样拥有方法，区别在于我们多了一个 `self` 变量。现在我们来看一个示例。

```python
#!/usr/bin/python
# Filename: method.py

class Person:
    def sayHi(self):
        print('Hello, how are you?')

p = Person()
p.sayHi()

# 这个短示例也可以写成 Person().sayHi()
```

输出：

```
$ python method.py
Hello, how are you?
```

工作原理：
在这里我们看到了 `self` 的作用。注意 `sayHi` 方法没有接受参数，但在函数定义中仍然包含 `self`。

## __init__ 方法

在 Python 类中，许多方法具有特殊意义。现在我们来看 `__init__` 方法的意义。
当类的对象被实例化时，`__init__` 方法会立即执行。该方法用于对对象执行任何所需的初始化操作。注意名称开头和结尾都有双下划线。

示例：

```python
#!/usr/bin/python
# Filename: class_init.py

class Person:
    def __init__(self, name):
        self.name = name
    def sayHi(self):
        print('Hello, my name is ', self.name)

p = Person('Swaroop')
p.sayHi()

# 这个短示例也可以写成 Person('Swaroop').sayHi()
```

输出：

```python
$ python class_init.py
Hello, my name is Swaroop
```

工作原理：
在这里，我们定义的 `__init__` 方法接收一个参数 `name`（以及通常的 `self`），在这里我们只是创建了一个名为 `name` 的新字段。注意，尽管它们都叫 'name'，但是两个不同的变量。点符号符号允许我们区分它们。
最重要的是，注意我们没有显式地调用 `__init__` 方法，而是在创建类的新实例时，在括号中传递参数。这就是该方法的特殊意义。
现在，我们可以在方法中使用 `self.name` 字段，这在 `SayHi` 中得到了演示。

## 类变量和对象变量

我们已经讨论了类和对象的功能（即方法），现在让我们学习数据部分。数据部分（即字段）无非是绑定到类和对象命名空间的普通变量。这意味着这些名称在这些类和对象的上下文中是有效的。这就是为什么它们被称为命名空间。
字段有两种类型——类变量和对象变量，根据变量是归类所有还是归对象所有来进行分类。类变量只有一份副本，当任何对象对类变量进行更改时，该更改将对所有其他实例可见。对象变量由类的每个独立对象/实例拥有。在这种情况下，每个对象都有该字段的独立副本，即它们是不共享的，并且与不同实例中的同名字段没有任何关系。一个示例将使其变得易于理解：

```python
#!/usr/bin/python
# Filename: objvar.py
class Robot:
    '''代表一个机器人，有一个名字。'''

    # 类变量，统计机器人数量
    population = 0

    def __init__(self, name):
        '''初始化数据。'''
        self.name = name
        print('Initializing {}}'.format(self.name))

        # 当此人被创建时，机器人
        # 人口加1
        Robot.population += 1

    def __del__(self):
        '我正在死去。'
        print('{0} is being destroyed!'.format(self.name))

        Robot.population -= 1

        if Robot.population == 0:
            print('{0} was the last one.'.format(self.name))
        else:
            print('There are still {0:d} robots').format(Robot.population)

    def sayHi(self):
        '''机器人问候。'''
        print('Greetings, my masters call me {0}.'.format(self.name))

    @staticmethod
    def howMany():
        '''打印当前人口。'''
        print('We have {0:d} robots.'.format(Robot.population))

droid1 = Robot('R2-D2')
droid1.sayHi()
Robot.howMany()

droid2 = Robot('C-3P0')
droid2.sayHi()
Robot.howMany()

print("\Robots can do some work here.\n")

print("\Robots have finished their work. So let's destroy them.")
del droid1
del droid2

Robot.howMany()
```

输出：

```

Greetings, my masters call me R2-D2.
We have 1 robots.
(Initializing C-3P0)
Greetings, my masters call me C-3P0.
We have 2 robots.
```

## Python: 面向对象

```python
class SchoolMember:
    """代表任何学校成员."""
    def __init__(self, name, age):
        self.name = name
        self.age = age
        print('Initialized SchoolMember: {0}'.format(self.name))

    def tell(self):
        """告诉我我的详情."""
        print('Name: {0} Age: {1}'.format(self.name, self.age), end="")

class Teacher(SchoolMember):
    """代表一名老师."""
    def __init__(self, name, age, salary):
        SchoolMember.__init__(self, name, age)
        self.salary = salary
        print('Initialized Teacher: {0}'.format(self.name))

    def tell(self):
        SchoolMember.tell(self)
        print('Salary: {0}'.format(self.salary))

class Student(SchoolMember):
    """代表一名学生."""
    def __init__(self, name, age, marks):
        SchoolMember.__init__(self, name, age)
        self.marks = marks
        print('Initialized Student: {0}'.format(self.name))

    def tell(self):
        SchoolMember.tell(self)
        print('Marks: {0}'.format(self.marks))

t = Teacher('Mrs. Shrividya', 40, 30000)
s = Student('Swaroop', 25, 75)

print() # 打印空行

members = [t, s]
for member in members:
    member.tell() # 对老师和学生都有效
```

输出:
python inherit.py
(Initialized SchoolMember: Mrs. Shrividya)
(Initialized Teacher: Mrs. Shrividya)
(Initialized SchoolMember: Swaroop)
(Initialized Student: Swaroop)

Name:"Mrs. Shrividya" Age:"40" Salary: "30000"
Name:"Swaroop" Age:"25" Marks: "75"

## 工作原理

要使用继承，我们在类定义中，在类名后面紧跟一个元组来指定基类名。接下来，我们观察到使用 `self` 变量显式调用了基类的 `__init__` 方法，以便初始化对象的基类部分。记住这一点非常重要——Python不会自动调用基类的构造函数，你必须通过在方法名前加上类名来显式地调用它。

我们还观察到，可以通过在方法名前加上类名来调用基类的方法，并将任何参数传递给 `self` 变量。

注意，当我们使用 `SchoolMember` 类的 `tell` 方法时，可以将 `Teacher` 或 `Student` 的实例仅仅视为 `SchoolMember` 的实例。

此外，观察到调用的是子类的 `tell` 方法而不是 `SchoolMember` 类的 `tell` 方法。理解这一点的方法是：Python 总是从实际类型开始查找方法，在本例中确实如此。如果找不到方法，它将按照类定义中指定的顺序，逐一查找属于其基类的方法。

关于术语说明——如果继承元组中列出了多个类，则被称为多重继承。

### 总结

我们已经探索了类和对象的各个方面以及与之相关的各种术语。我们还看到了面向对象编程的优点和缺点。Python 是高度面向对象的，仔细理解这些概念对你的长远发展非常有帮助。

## Pickle

Python 提供了一个名为 `pickle` 的标准模块，你可以将任何 Python 对象存储在文件中并在以后获取它。这被称为持久化存储对象。

示例：

```python
#!/usr/bin/python
# Filename: pickling.py

import pickle

# 将存储对象的文件名
filename = 'shoplist.data'
# 购物列表
list = ['apple', 'mango', 'carrot']

# 写入文件
f = open(filename, 'wb')
pickle.dump(list, f) # 将对象转储到文件
f.close()

del list # 销毁列表变量

# 从存储中读回
```python
f = open(filename, 'rb')
list = pickle.load(f) # 从文件加载对象
print(list)
f.close()
```

## Python基础：异常

## 简介

当程序中发生某些异常情况时，就会产生异常。例如，如果你准备读取一个文件但该文件并不存在怎么办？或者在程序运行时你不小心把它删除了怎么办？这类情况可以使用异常来处理。同样，如果你的程序中有一些无效语句呢？Python 会处理这种情况，它会举起手并告诉你发生了错误。

### 错误

考虑一个简单的函数调用。如果我们把 `print` 错写成了 `Print` 会怎样？请注意大小写。在这种情况下，Python 会抛出一个语法错误。

```python
>>> Print('Hello World')
Traceback (most recent call last):
File "<pshell#>", line 1, in <module>
Print('Hello World')
NameError: name 'Print' is not defined
>>> print('Hello World')
Hello World
```

## Python基础：异常

观察到抛出了 NameError，并且打印了检测到错误的位置。这就是该错误的处理器所的作用。

### 异常

我们将尝试从用户处读取输入。按下 ctrl-d 看看会发生什么。

```python
>>> s = input('Enter something --> ')
Enter something -->
--
Traceback (most recent call last):
File "<pshell#2>", line 1, in <module>

Python 抛出了 `EOFError` 错误，这基本上意味着它在没有预料看到的情况下看到了文件结束符号（由 ctrl-d 触发）。

### 处理异常

我们可以使用 `try..except` 语句来处理异常。我们基本上是将通常的语句放在 `try` 块中，并将所有的处理器放在 `except` 块中。

```python
#!/usr/bin/python
# Filename: try_except.py
```

```python
try:
    text = input('Enter something --> ')
except EOFError:
    print('Why did you do an EOF on me?')
except KeyboardInterrupt:
    print('You cancelled the operation.')
else:
    print('You entered {0}'.format(text))
```

Output:

```
$ python try_except.py
Enter something --> # Press ctrl-d
Why did you do an EOF on me?
```

```
$ python try_except.py
Enter something --> # Press ctrl-c
You cancelled the operation.
```

```
$ python try_except.py
Enter something --> no exceptions
You entered no exceptions
```

### 工作原理：

我们将所有可能抛出异常/错误的语句放在 `try` 块中，然后在 `except` 子句/块中放置针对相应错误/异常的处理器。`except` 子句可以处理单个指定的错误或异常，也可以处理一个带括号的错误/异常列表。如果没有提供错误或异常的名称，它将处理所有的错误和异常。

注意，每个 `try` 句必须至少关联一个 `except` 子句。否则，设置 `try` 块的意义何？

如果任何错误或异常没有被处理，将调用默认的 Python 处理器，它会停止程序执行并打印错误信息。我们已经在上面的操作中看到了这一点。

你还可以与 `try..except` 块关联一个 `else` 子句。如果没有发生异常，则执行 `else` 子句。

在下一个示例中，我们还将看到如何获取异常对象，以便我们检索额外信息。

## 抛出异常

你可以使用 `raise` 语句抛出异常，通过提供错误/异常的名称以及要抛出的异常对象。你可以抛出的错误或异常可以是直接或间接继承自 `Exception` 类的派类。

```python
#!/usr/bin/python
# Filename: raising.py

class ShortIntException(Exception):
    '''一个用户定义的异常类.'''
    def __init__(self, length, atleast):
        self.length = length
        self.atleast = atleast
```

```python
try:
    text = input('Enter something -> ')
    if len(text) < 3:
        raise ShortIntException(len(text), 3)
    # 其他工作可以在这里正常进行
except EOFError:
    print('Why did you do an EOF on me?')
except ShortIntException as ex:
    print('IntException: The input was {0} long, expected at least {1}'\n
        .format(ex.length, ex.atleast))
else:
    print('No exception was raised.')
```

Output:

```
python raising.py
enter something -> a
IntException: The input was 1 long, expected at least 3
```

### 工作原理：

输出应该与之前的示例相同。这里的不同在于我们使用了带有 `with` 语句的 `open` 函数——我们将文件的关闭交给 `with` 自动完成。

## with 语句

在 `try` 块中获取资源随后在 `finally` 块中释放资源是一种常见模式。因此，还有一个 `with` 语句能够以简洁的方式完成这一点：

```python
#!/usr/bin/python
# Filename: "poem.txt"

with open("poem.txt") as f:
    for line in f:
        print(line, end='')
```

### 工作原理：

输出应该与之前的示例相同。这里的不同在于我们使用了带有 `with` 语句的 `open` 函数——我们将文件的关闭交给 `with` 自动完成。

在背后发生的是 `with` 语句使用了一种协议。它获取 `open` 语句返回的对象，在这种情况下我们称之为 "thefile"。

它在开始其下方的代码块之前调用 `thefile__enter__` 函数，并在完成代码块后始终调用 `thefile__exit__`。

因此，我们在 `finally` 块中编写的代码由 `__exit__` 方法自动处理。这帮助我们避免重复使用显式语句。

## Finally

假设你正在读取一个文件。如何确保文件对象始终关闭？使用 `finally` 块。

```python
#!/usr/bin/python
# Filename: finally.py

import time
try:
    f = open('poem.txt')
    while True:
        line = f.readline()
        if len(line) == 0:
            break
        print(line, end='')
        time.sleep(2)
except KeyboardInterrupt:
    print('You cancelled the operation.')
finally:
    f.close()
```

Output:

```
$ python finally.py
Programming is fun
You cancelled the operation.
```

### 工作原理：

通常的文件读取操作，但我们使用 `time.sleep` 函数每行人为地睡眠 2 秒，以便程序运行缓慢。当程序仍在运行时，按下 ctrl-c 中断/取消程序。观察到抛出了 `KeyboardInterrupt` 异常并且程序退出。然而，在程序退出之前，`finally` 子句会执行，文件对象会被关闭。

## sys 模块

`sys` 模块包含特定于系统的功能。我们已经看到 `sys.argv` 列表包含了命令行参数。

假设我们想检查正在使用的 Python 命令版本，例如，我们想确保至少使用的是版本 3。`sys` 模块为我们提供了这种功能。

```python
>>> import sys
>>> sys.version_info
(3, 0, 0, 'beta', 2)
>>> sys.version_info[0] >= 3
True
```

其工作原理：

`sys` 模块有一个 `version_info` 元组，它提供了版本信息。第一个条目是主版本。我们可以通过检查它来例如确保程序只在 Python 3.0 下运行。

```python
#!/usr/bin/python
# Filename: versioncheck.py
import sys, warnings
if sys.version_info[0] < 3:
    warnings.warn('Need Python 3.0 for this program to run',
    RuntimeWarning)
else:
    print('Proceed as normal')
```

输出结果：

```bash
$ python2.5 versioncheck.py
versioncheck.py:6: RuntimeWarning: Need Python 3.0 for this program
to run
RuntimeWarning

$ python3 versioncheck.py
Proceed as normal
```

其工作原理：
我们使用了标准库中的另一个名为 `warnings` 的模块，它用于向最终用户显示警告。如果 Python 版本号至少不是 3，我们就显示相应的警告。

## logging 模块

如果你想将一些调试信息或重要信息存储在某处，以便检查程序是否按照你的预期运行该怎么办？如何“存储某处”这些信息？可以使用 `logging` 模块来实现。

```python
#!/usr/bin/python
# Filename: use_logging.py
import os, platform, logging

if platform.platform().startswith('Windows'):
    logging_file = os.path.join(os.getenv('HOMEDRIVE'),('test.log'))
else:
    logging_file = os.path.join(os.getenv('HOME'), 'test.log')

logging.basicConfig(level=logging.DEBUG,
                     format='%(asctime)s : %(levelname)s : %(message)s',
                     filename=logging_file,
                     filemode='w')
```

```python
logging.debug("Start of the program")
logging.info("Doing something")
logging.warning("Dying now")
```

输出结果：

```bash
$ python use_logging.py
Logging to C:\Users\swaroop\test.log
```

如果我们检查 `test.log` 的内容，它看起来像这样：

```
2008-09-03 13:18:16,233 : DEBUG : Start of the program
2008-09-03 13:18:16,233 : INFO : Doing something
2008-09-03 13:18:16,233 : WARNING : Dying now
```

其工作原理：

我们使用了标准库中的模块 - 用于与操作系统交互的 `os` 模块，用于获取操作系统信息的 `platform` 模块，以及用于记录日志的 `logging` 模块。

首先，我们通过检查 `platform.platform()` 返回的字符串来检查我们所处的操作系统（更多信息请参阅 `import platform; help(platform)`）。如果是 Windows，我们就确定主目录、主文件夹以及我们要存储信息的文件名。将这三部分组合在一起，我们就得到了文件的完整位置。对于其他平台，我们只需要知道用户的主目录，就可以获取完整位置。

我们使用 `os.path.join()` 函数将位置的这三部分组合在一起。使用特殊函数而不是直接拼接字符串的原因是，该函数将确保完整路径符合操作系统预期的格式。

我们配置 `logging` 模块，以特定的格式将所有消息写入我们指定的表中。

## 列表推导式 (List Comprehension)

列表推导式用于从现有列表派生新列表。假设你有一个数字列表，你想在数字本身大于 2 时，获取一个所有数字乘以 2 的对应列表。列表推导式是这种情况的理想选择。

```python
#!/usr/bin/python
# Filename: list_comprehension.py
```

```python
listone = [2, 3, 4]
listtwo = [2*i for i in listone if i > 2]
print(listtwo)
```

输出：

```python
$ python list_comprehension.py
[6, 8]
```

工作原理：

在这里，通过指定满足某些条件（`if i > 2`）时要执行的操作（`2*i`）来派生新列表。注意原始列表保持不变。

使用列表推导式的优势是，当我们使用循环处理列表的每个元素并将其存储在新列表中时，它减少了样板代码量。

## 在函数中接收元组和列表 (Receiving Tuples and Lists in Functions)

有一种特殊方式通过 `*` 或 `**` 前缀分别以元组或字典接收参数。这在函数接收可变数量参数时有用。

```python
>>> def powsum(power, args):
    '''返回每个参数的指定幂的和。'''
    total = 0
    for i in args:
        total += pow(i, power)
    return total
```

```python
>>> powsum(2, 3, 4)
25
```

```python
>>> powsum(2, 10)
100
```

因为我们在 `args` 上有 `*` 前缀，传递给函数的所有额外参数都以元组的形式存储在 `args` 中。如果使用 `**`，额外参数将被字典的键值对。

## assert 语句 (The assert statement)

`assert` 语句用于断言某些内容是真实的。例如，如果你非常确定正在使用的列表中至少有一个元素，并想检查这一点，如果不真实则抛出错误，那么 `assert` 语句在这种情况下是理想的。当 `assert` 语句失败时，会抛出 `AssertionError`。

`assert` 语句应该谨慎使用。通常，捕获异常或向用户显示错误消息更好。
