Using this definition, we compute that

```
f2 = f1 + f0 = 0 + 1 = 1
f3 = f2 + f1 = 1 + 1 = 2
f4 = f3 + f2 = 2 + 1 = 3
f5 = f4 + f3 = 3 + 2 = 5
f6 = f5 + f4 = 5 + 3 = 8
f7 = f6 + f5 = 8 + 5 = 13
```

and so on. Based on this definition, we can use induction to prove facts about the Fibonacci sequence. We can prove, for example, that fn grows exponentially with n, even without finding an exact formula for fn.

**Theorem 1.17.** The Fibonacci sequence, f0, f1, f2, ..., satisfies fn > (3/2)^(n-1), for n >= 6.

Proof. We prove this by induction on n. For n = 6, we have that fn = 8 while 1.5^(n-1) = 1.5^5, which is about 7.6. So fn > 1.5^(n-1) for n = 6. Similarly, for n = 7, we have fn = 13 and 1.5^(n-1) = 1.5^6, which is about 11.4. So fn > 1.5^(n-1) for n = 7.

Now suppose that k is an arbitrary integer with k > 7. Suppose we already know that fn > 1.5^(n-1) for n = k - 1 and for n = k - 2. We want to show that the inequality then holds for n = k as well. But

```
fk = fk-1 + fk-2
> 1.5^(k-1-1) + 1.5^(k-2)-1 (by the induction hypothesis)
= 1.5^(k-2) + 1.5^(k-3)
= (1.5) * (1.5^(k-3) + (1.5^(k-3))
= (2.5) * (1.5^(k-3))
> (1.5^2) * (1.5^(k-3)) (since 1.5^2 = 2.25)
= 1.5^(k-1)
```

This string of equalities and inequalities shows that fk > 1.5^(k-1). This completes the induction and proves the theorem.
