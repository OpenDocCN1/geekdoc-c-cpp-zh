One need not construct the tree. The simplest way is that there are seven nodes, that is, six nodes for left and right subtree. For a heap, it's quite obvious that the division has to be 3-3, as a heap is a complete binary tree.

+   7. (d) 8. (d) 9. (d)

With large n, the number of comparisons required for finding the 7th smallest element becomes irrelevant of the height (logn) of the heap. It can be found out in constant time. Hence, the answer is option (d).
