Since object 3 gives the maximum profit per unit, it is selected first, and its weight is 30. Then, object 1 with weight 10 is selected. Then, object 2 with weight 20 is selected. Total weight = 30 + 10 + 20 = 60. Now, object 5 with weight 50 is selected partially. So, the fraction of object 5 selected is equal to

\frac{\text{Maximum allowed weight - Current weight}}{\text{Weight of object 5}} = \frac{100 - 60}{50} = \frac{40}{50} = \frac{4}{5}

So, the total weight = 30 + 10 + 20 + 50 x (4/5) = 100. Here, objects 3, 1, 2 are used as a whole and 4/5th of object 5 is used. So, the total profit = 66 + 20 + 30 + 60 x (4/5) = 164. Hence, the total profit is 164 if we choose objects in the order of profit per unit.

# Conclusion

If we observe the profits of three cases, Case 3 gives the maximum profit. This case actually uses the knapsack-greedy algorithm. So, the solution obtained is surely optimal.
