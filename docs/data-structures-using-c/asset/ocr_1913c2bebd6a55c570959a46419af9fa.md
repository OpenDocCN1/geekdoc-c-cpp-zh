We notice that for a polynomial of z with 10 terms, the third field of all nodes would be set to z for all term nodes. Can we avoid storing z for all terms of a polynomial? This is possible by storing it only once using the header node. For the header node, the fields Tag, nLink, and dLink are used, and the remaining two fields unused and it can be used for storing the variable.
