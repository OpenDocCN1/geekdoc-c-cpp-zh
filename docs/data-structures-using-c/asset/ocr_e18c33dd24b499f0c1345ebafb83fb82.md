Let us compute the cost of each BST.
For Fig. 10.4(a),

Cost = \sum_{1 \le i \le 3} p(i) \times level(k_i) + \sum_{0 \le i \le 3} q(i) \times level(E_i) - 1 = A + B
A = \sum_{1 \le i \le 3} p(i) \times level(k_i) = p_1 \times level(k_1) + p_2 \times level(k_2) + p_3 \times level(k_3)
= 1/7(2 + 2 + 1)
= 5/7
B = \sum_{0 \le i \le 3} q(i) \times (level(E_i) - 1) = q_0 \times level(E_0) - 1 + q_1 \times level(E_1) - 1
+ q_2 \times level(E_2) - 1 + q_3 \times level(E_3) - 1
= 1/7(2 + 2 + 2 + 2)
= 8/7

Therefore, cost = (5/7) + (8/7) = 13/7

For Fig. 10.4(b), total cost = A + B

where A = \sum_{1 \le i \le 3} p(i) \times level(k_i) = \frac{1}{7}(1 + 2 + 3)
= 6/7

B = \sum_{0 \le i \le 3} q(i) \times level(E_i) = \frac{1}{7}(3 + 3 + 2 + 1)
= 9/7

Therefore, cost = (6/7) + (9/7) = 15/7

Similarly, for Figs 10.4(c)-(e), the cost of each subtree = 15/7.

The cost of the tree in Fig. 10.4(a) is the least; hence, it is the OBST.

Practically, we cannot use such an approach to find an OBST as we will need to draw all possible BSTs and then find the cost of all BSTs.
