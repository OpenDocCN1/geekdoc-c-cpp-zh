Case 3: Node having both subtrees Consider the case when the node to be deleted has both right and left subtrees. This problem is more difficult than the earlier cases. The question is which subtree should the parent of the deleted node be linked to, what should be done with the other subtrees, and where should the remaining subtrees be linked. One of the solutions is to attach the right subtree in place of the deleted node, and then attach the left subtree onto an appropriate node of the right subtree.
