# 2.7.2 n-dimensional Arrays

An n-dimensional m1 x m2 x m3 x ... x mn array A is a collection of m1 x m2 x m3 x ... x mn elements in which each element is specified by a list of n integers such as k1, k2, ..., kn called subscripts where 0 ≤ k1 ≤ m1 - 1, 0 ≤ k2 ≤ m2 - 1, ..., 0 ≤ kn ≤ mn - 1. The element of array A with subscripts k1, k2, ..., kn is denoted by A [k1] [k2] ... [kn].
