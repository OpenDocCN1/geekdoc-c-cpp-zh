Now, let A[0][0] be stored at address X; then A[0][1] would be stored at X + 1: A[0][i] would be at X + i and so till A[0][m2 - 1] at X + (m2 - 1). Now the address of A[i][0] would be X + (i x m2).

In general, the address of A[i][j] is X + (i x m2) + j (Fig. 2.17).

![](bbox=[0.23, 0.21, 0.88, 0.34])

# Address Calculation for Three-dimensional Array

Figure 2.18 shows a three-dimensional array A[m1][m2][m3]. This array is interpreted as m1 two-dimensional arrays of dimension m2 x m3.

![](bbox=[0.23, 0.48, 0.88, 0.61])

The address of A[i][0][0] is X + (i x m2 x m3). Therefore, the address of A[i][j][k] is computed as

```
Addr of A[i][j][k] = X + i x m2 x m3 + j x m3 + k
```

By generalizing this expression, we get the address of A[i1][i2][i3]...[in] in the n-dimensional array A[m1][m2][m3]...[mn].

Considering the address of A[0][0][0]...[0] as X, then the address of A[i][0][0]...[0] = X + (i1 x m2 x m3 x ... x mn) and the address of A[i1][i2]...[0] = X + (i1 x m2 x m3 x ... x mn) + (i2 x m3 x m4 x ... x mn).

Continuing in a similar manner, the address of A[i1][i2][i3]...[in] will be

```
Address of A[i1][i2][i3]...[in]
= X + (i1 x m2 x m3 x ... x mn) + (i2 x m3 x m4 x ... x mn)
+ (i3 x m3 x m4 x ... x mn) + (i4 x m4 x m5 x ... x mn) + ... + in
```
