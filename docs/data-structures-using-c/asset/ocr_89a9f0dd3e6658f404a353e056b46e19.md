We have studied the linked list data structure as a way to store the data in the form of collection of nodes storing data and links to other nodes. Nodes can be located anywhere in the memory, not necessarily in sequential locations. The links are established by storing the addresses of other node(s) (next or previous) in the link field of each node.

Although the linked list can be implemented in a variety of ways, the most flexible implementation is by using pointers. To implement the same in C++, we can view the entire linked list as an object of class LinkList. The individual data items or links are represented by the structure of type Node.
