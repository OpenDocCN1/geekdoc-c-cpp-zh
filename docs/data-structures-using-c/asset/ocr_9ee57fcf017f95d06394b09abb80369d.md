# Fig. 2.9 Row-major arrangement

The address of the element of the i-th row and the j-th column for a matrix of size m x n can be calculated as

```
Address of (A[i][j]) = Base address + Offset
= Base address + (Number of rows placed before i-th row
x Size of row) + (Number of elements
placed before j-th element in i-th row) x Size of element
```

Here, size of a row is actually the number of columns n. The base is the address of A[0][0].

```
Address of A[i][j] = Base + (i x n x Size of element) + (j x Size of element)
```

As row indexing starts from 0, the index i indicates the number of rows before the i-th row here and similarly for j. For Size of element = 1, the address is

```
Address of A[i][j] = Base + (i x n) + j
```

In general,

```
Address of A[i][j] = ((i - LB1) x (UB2 - LB2 + 1) x size) + ((j - LB2) x size)
```

where the number of rows placed before the i-th row = (i - LB1), and LB1 is the lower bound of the first dimension.
