While inserting 6173, the address is Hash1(6173) = 6173 % 10 = 3 and 3 is not empty. Let us use double hashing. Hence the address is as follows:

```
Hash(6173) = [Hash1(6173) + Hash2(6173)] % 10
= 3 + ( R - 6173 % R ) ( let R be 7)
= 3 + (7 - 6) = 4
```

Since 4 is empty, we store 6173 at location 4.
