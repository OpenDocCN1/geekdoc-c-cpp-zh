# Table 15.5 List of containers and their characteristics

| Container | Characteristics | Advantages/disadvantages |
|---|---|---|
| C++ array (not container) | Fixed size | • Quick random access<br>• Slow insert and delete<br>• Size cannot be changed at runtime |
| Vector | Relocating, expandable array | • Quick random access<br>• Slow insert/delete in middle<br>• Quick insert/delete at ends |
| List | Doubly linked list | • Quick insert/delete<br>• Quick access at ends<br>• Slow random access |
| Deque | Like vector but can be accessed at either ends | • Quick random access<br>• Slow insert or delete in middle<br>• Quick insert or delete at the ends |
