# 8.5 SPANNING TREE

A tree is a connected graph with no cycles. A spanning tree is a sub-graph of G that has all
vertices of G and is a tree. A minimum spanning tree of a weighted graph G is the spanning
tree of G whose edges sum to minimum weight.

There can be more than one minimum spanning tree for a graph. Figure 8.19 shows a
graph, one of its spanning trees, and a minimum spanning tree.
