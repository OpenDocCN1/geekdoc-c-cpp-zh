# Fig. 16.1 Quick sort

The partition algorithm takes care of partitioning. It takes three arguments. The first argument is an array A, which contains all the elements. The second argument m and the third argument p denote the start and end positions of a partition to be rearranged, respectively. Here, the first element of the partition A[m] is being used as the pivot element v. Any element can be used as a pivot element, however, in practice, the first element is generally used. The algorithm will rearrange the elements A[m], A[m + 1], ..., A[p]
