Algorithm 9.5 depicts the logic behind bubble sort.

```
ALGORITHM 9.5
1. Let A be the array to be sorted
2. for i = 1 to n - 1
   for j = 0 to n - 1
   begin
   if A[j] > A[j+1] then
   Swap A[j] with A[j + 1] as follows
   temp = A[j]
   A[j] = A[j+1]
   A[j + 1] = temp
   end
end
3. stop
```
