| Quick sort | Picks an element, called a pivot, from the list. Reorders the list so that all elements with values less than the pivot come before the pivot, whereas all elements with values greater than the pivot come after it (equal values can go either way). After this partitioning, the pivot is in its final position. This is called the partition operation. Recursively sorts the sub-list of lesser elements and the sub-list of greater elements. | O(nlog2n) | O(n^2) | No extra space needed | No | 1. Extremely fast 2.
