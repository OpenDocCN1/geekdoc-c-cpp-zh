# 12.6.3 Representation of Binomial Heap

The node of a binomial heap can be represented by five tuples as shown in Fig. 12.30.

+   * **Parent** Points to the parent node
+   * **Key** Key value, that is, data
+   * **Degree** Degree of each node, that is, the number of children it has
+   * **Child** Points to any of its child node (mostly pointing to its leftmost child)
+   * **Siblings** Points to a sibling node, that is, used to maintain the singly-circular lists of siblings.
