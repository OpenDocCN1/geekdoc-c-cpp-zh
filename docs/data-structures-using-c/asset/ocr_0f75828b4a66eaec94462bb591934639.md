As observed in Program Code A.22, when a virtual function is not redefined by a derived class, the version defined in the base class will be used. In many situations, there could be no meaningful definition of a virtual function in a base class or all derived classes would override a virtual function.

To handle these two cases, C++ supports pure virtual functions. A pure virtual function is one that has no definition within the base class.

```
virtual type func_name(parameter_list) = 0;
```

When a virtual function is made pure, any derived class must provide its own definition; otherwise it results in a compile-time error. Program Code A.23 illustrates pure virtual functions.

```

// To draw different shapes
class shape
{
    public:
    virtual void Draw() = 0;
};
class line:public shape
```
