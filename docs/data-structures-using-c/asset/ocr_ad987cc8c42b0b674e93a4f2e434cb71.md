**EXAMPLE 10.3** Find an OBST using the dynamic programming approach for n = 4, keys = (count, float, if, while). Compute w(i, j), r(i, j), and c(i, j) for 0 <= i <= j <= 4 given that p(1) = 1/20, p(2) = 1/5, p(3) = 1/10, p(4) = 1/20, q(0) = 1/5, q(1) = 1/10, q(2) = 1/5, q(3) = 1/20, and q(4) = 1/20. Using r(i, j), construct an OBST.

# *Solution*

p(1 : 4) = \frac{1}{20} \cdot \frac{1}{5} \cdot \frac{1}{10} \cdot \frac{1}{20} = (0.05, 0.2, 0.1, 0.05)

q(0 : 4) = \frac{1}{5} \cdot \frac{1}{10} \cdot \frac{1}{5} \cdot \frac{1}{20} \cdot \frac{1}{20} = (0.2, 0.1, 0.2, 0.05, 0.05)

+   **Step 1:** c(i, i) = 0, r(i, i) = 0, and w(i, i) = q(i) for 0 <= i <= 4
+   
+   Hence, w00 = 0.2, w11 = 0.1, w22 = 0.2, w33 = 0.05, w44 = 0.05.

+   **Step 2:** w(i, j) = q(i) + p(j) + w(i, j - 1)
+   
+   c(i, j) = \min_{i < a \le j} [c(i, a - 1) + c(a, j) + w(i, j)]
+   
+   r(i, j) = value of a which minimizes c(i, j)
+   
+   Compute c(i, j) for j - i = 1.
+   w(0, 1) = p(1) + q(1) + w(0, 0)
+   = 0.05 + 0.1 + 0.2 = 0.35
+   c(0, 1) = w(0, 1) + \min[c(0, 0) + c(1, 1)]
+   = 0.35 + [0 + 0] = 0.35
+   r(0, 1) = 1
+   w(1, 2) = p(2) + q(2) + w(1, 1) = 0.2 + 0.2 + 0.1 = 0.5
+   c(1, 2) = w(1, 2) + \min[c(1, 1) + c(2, 2)] = 0.5 + [0 + 0] = 0.5
+   r(1, 2) = 2
+   w(2, 3) = p(3) + q(3) + w(2, 2) = 0.1 + 0.05 + 0.2 = 0.35
+   c(2, 3) = w(2, 3) + \min[c(2, 2) + c(3, 3)] = 0.35 + [0 + 0] = 0.35
+   r(2, 3) = 3
+   w(3, 4) = p(4) + q(4) + w(3, 3) = 0.05 + 0.05 + 0.05 = 0.15
+   c(3, 4) = w(3, 4) + \min[c(3, 3) + c(4, 4)] = 0.15 + [0 + 0] = 0.15
+   r(3, 4) = 4

+   **Step 3:** Compute c(i, j) for j - i = 2.
+   w(0, 2) = p(2) + q(2) + w(0, 1)
+   = 0.2 + 0.2 + 0.35 = 0.75
