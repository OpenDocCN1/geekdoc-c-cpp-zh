Length() is a simple list function, but it demonstrates several concepts, which will be used later in more complex list functions.

```
PROGRAM CODE 6.26
int Llist :: Length()
{
    Node *current = Head;
    int count = 0;
    while(current != Null)
    {
        count++;
        current = current->link;
    }
    return count;
}
```
