# Simple Transpose

Let A be a matrix of size m x n with T non-zero elements and let B be its transpose. One of the easiest ways is to search for each column (column = 0 to n - 1) and sequentially place each column as a row in the transposed matrix B by placing the interchanged entries as row, column, and value (refer to Fig. 2.34 on page 80).

The steps to transpose a matrix are described in Algorithm 2.3 and the corresponding program is described in Program Code 2.10.

```
ALGORITHM 2.3
1. Row = A[0][0], Col = A[0][1] and T = A[0][2]
2. B[0][0] = Col , B[0][1] = Row and B[0][2] = T
```
