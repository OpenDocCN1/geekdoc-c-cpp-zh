The following are a few examples to elucidate this concept:

+   1. P(x,y) = 9x^3y^2 + 6xy^2 + y + x^2
+   This polynomial of two variables can be rewritten as
+   P = y^2(9x^3 + 6x) + y + x^3y^0

This is represented in Figs 6.71(a) and (b).

+   2. Q = 8x^3y^3z^3 + 3x^3y^2z^3 + y^2z^3 + xy^2z^3 + 8x + 9y
+   This can be rewritten as z^3(x(8y^3 + 3y^2) + z^3(y^2(1 + x)) + 8x^0y^0 + 9x^0y^0.
