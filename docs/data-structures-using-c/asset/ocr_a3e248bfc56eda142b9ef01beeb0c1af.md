# 1.12 SOFTWARE ENGINEERING

Software engineering is the establishment and use of good engineering methods and principles to obtain reliable software that works on real machines.

A fundamental concept in software engineering is the software development life cycle (SDLC). Software, like many other products, goes through a cycle of repeating phases. The development process in the software life cycle broadly involves four phases: analysis, design, implementation, and testing. Figure 1.7 shows these phases as part of the development process.

# 1.12.1 Analysis Phase

The development process starts with the analysis phase; the systems analyst defines requirements that specify what the proposed system is to accomplish. The requirements are usually stated in terms that the user understands. There are four steps in the analysis phase: define the user, define the needs, define the requirements, and define the methods.
