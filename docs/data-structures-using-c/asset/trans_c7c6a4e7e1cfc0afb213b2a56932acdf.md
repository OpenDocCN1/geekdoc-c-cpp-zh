## 1 基本概念

### 学习目标

完成本章后，读者将能够理解以下内容：

- 程序设计的明确、清晰且简单的方法
- 算法及其特性的基本方面
- 数据、数据类型、数据对象和数据结构等基本概念
- 抽象数据类型（ADT）的威力
- 软件开发生命周期（SDLC）

编程需要将不同种类的信息存储在计算机中，并处理输入数据。信息可以使用变量以通用格式存储。原则上，一个变量允许存储单个数据实体。但是，一组单个变量可能无法高效地解决复杂问题。数据结构使用一组相关变量，可以单独访问或作为整体访问。换句话说，数据结构表示一组具有特定关系的数据项。在本章中，我们将学习与编程和数据结构相关的基本概念。
