# 12.1.1 Min-heap and Max-heap

In this section we discuss two types of heaps, the min-heap and the max-heap.

# *Min-heap*

The structure shown in Fig. 12.3 is called *min-heap*.

In min-heap, the key value of each node is lesser than or equal to the key value of its children. In addition, every path from root to leaf should be sorted in ascending order. Figure 12.4 is an example of a min-heap.
