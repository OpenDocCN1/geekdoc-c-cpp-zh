Most of the languages use the base address plus offset for addressing. This way of addressing helps in direct access to an element with bounded time O(1) for access.

In brief, the Array_A [N] is implemented as follows:

+   1. Array_A is the name of the object/structure and is associated with a base (starting) address in memory.
+   2. The [N] notation specifies the number of array elements from the beginning (offset), which starts at zero.
+   3. The address of the $i^{th}$ element is then computed as base + $i \times$ (Size of element), where Size of element depends on the data type.
