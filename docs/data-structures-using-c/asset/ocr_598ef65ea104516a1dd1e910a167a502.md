In structured programming, the problem solution is described in the form of smaller modules. This modular design breaks an algorithm into smaller units called _subalgorithms_. These units are referred by various names in programming languages such as _functions_, _subroutines_, _procedures_, _methods_, and _modules_.

The goal of modular design in algorithms is to make the complex and lengthy algorithms easy to read, write, verify, and debug. Each subalgorithm can, in turn, be divided into subalgorithms, and the process of such subdivision may continue till each step becomes effective.

# EXAMPLE 1.2 Write an algorithm to compute the following:

P = n!/((n - r)!)

_Solution_ Algorithms 1.6 computes the number of possible ways of arranging any r of n elements.

```
ALGORITHM 1.6
Pre None
Post None
Return Result
1. Read n and r
2. Let
   (a) A = FACT(n) and
   (b) B = FACT(n - r)
3. Result = A / B
```
