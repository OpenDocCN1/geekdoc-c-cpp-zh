Meaning of each reserved word in C#

+   1. Abstract – It indicates that the thing being modified has an incomplete or missing implementation. The abstract modifier can be used with methods classes, properties, events and indexers.

+   2. As – This keyword casts an object to a different type. The keyword returns null if the object was of an incompatible type.

+   3. Base – it describes that you would like to refer to the base class for the requested information, and not in the current instantiated class.

+   4. Bool – it is used in the field, property, method and variable declarations and in typeof and cast operations as an alias for the .NET framework structure System.Boolean, i.e. it represents True or False.

Methods-these are class members containing codes. They may contain a list of parameters, return value, as well as a generic type declaration. They can be static or instance

Property – these are class members that expose functionality of methods using the syntax of fields. Like methods they can be static or instance.

+   5. Break – this keyword is used to exit out of a loop or switch block.

+   6. Byte – this keyword is used in field, property, method and variable declarations and in typeof and cast operations as an alias for the .NET framework structure System.Byte, i.e. it represents 8-bit unsigned integer whose value ranges
