# C# exception classes

Exceptions in C# are represented by classes. In C#, exception classes are mainly derived indirectly or directly from System.Exception class. Few of the exception classes derived from System.Exception class are the System.SystemException and System.ApplicationException.

The class, System.SystemException is the base class for all predefined system exception, whereas the System.ApplicationException class supports exceptions generated by application programs. Therefore, the exceptions defined by the programmers should derive from this class.
