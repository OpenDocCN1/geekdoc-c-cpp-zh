The transition from C++ to C# would be fairly easy for those who have some experience in programming. However, for beginners as well C# is not a difficult language to learn. The interesting part of working with C# is working your way through the new common language runtime library, which provides a host of functionality that had to be written by hand previously. The .NET framework provides extensive support for web application development, threading, window-based application development and much more.
