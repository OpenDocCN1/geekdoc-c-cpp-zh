# Destructors in C#

Like constructors, a destructor is also a special member function of a class. However, it gets executed only when one of the objects of the class goes outside of its designated scope. The name of the destructor is the exact as that of its class, but it will have a prefixed tilde (~) with it. A destructor is incapable of returning a value or taking any parameters. Destructors can be rather beneficial as they can release memory resources before the program is exited. It is not possible for destructors to be inherited.
