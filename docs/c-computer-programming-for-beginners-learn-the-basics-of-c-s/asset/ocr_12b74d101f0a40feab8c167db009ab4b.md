# Initializing Arrays

Remember after declaring the array will not initialize it in the memory. Only after the array variable has been initialized you will be able to assign values to it? As the array is a reference type, you will have to use the new keyword in order to create an instance of the given array.

The following example shows you how.

```
double[] balance = new double[10];
```

# Assigning Values to the Array

It is possible to assign values to individual elements of the array. In order to do, the index number of the element needs to be used. The following example illustrates this.

```
double[] balance = new double[10];
```

```
balance[0] = 4500.0;
```

Values can also be assigned to the array when it is being declared.

```
double[] balance = { 2340.0, 4523.69, 3421.0 };
```
