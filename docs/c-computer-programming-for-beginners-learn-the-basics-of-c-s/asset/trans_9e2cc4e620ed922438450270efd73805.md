

29. Foreach – 它用于标识 *foreach* 循环。

30. Goto – 它将操作流返回到紧随其标签。可以通过在任何单词后加上冒号来创建标签。

31. If – 此关键字用于标识 *if* 语句。C# 中的 *if* 语句与 Java 和 C++ 类似。

```
if (condition)
```

```
{
  // Do something
}
else
{
  // Do something else
}
```

32. Implicit – 它用于类型定义哪些类型可以进行转换，而不需要显式类型转换。

33. In – 它标识 *foreach* 循环中要枚举的集合。

34. Int – 此关键字用于字段、属性、方法和变量声明，以及 `typeof` 操作，作为 .NET 框架结构 `System.Int32` 的别名，它代表 32 位整数。

35. Interface – 此关键字用于声明接口。接口为程序员提供了一种构造结构，用于创建可以声明属性、方法、索引和事件但未实现的类型。

36. Internal – 此关键字是一个*访问修饰符*，用于字段、属性和方法声明，使字段、属性或方法在其封装的程序集内部可见，即它仅在实现它的程序集内可见。

37. Is – 此关键字将对象与类型进行比较，如果它们是相似类型，则返回 true。因此，`is` 关键字用于检查兼容性，通常在将源类型转换（转换）为目标类型之前。这确保不会抛出类型转换异常。在空变量上使用 `is` 始终返回 false。

38. Lock – 它允许一段代码独占使用某个资源。此功能在多线程应用程序中非常有用。当代码段尝试锁定指定对象时，如果该对象已被锁定，除非对象可用，否则代码的线程将被阻塞。

39. Long – 它用于字段、属性、方法和变量声明，以及 `typeof` 和强制转换，作为 .NET 框架结构 `System.Int64` 的别名。

40. Namespace – 此关键字用于为类、类型和结构声明提供命名空间。

41. New – 此关键字有两个不同的含义 -

- a) 它是一个用于显式隐藏成员的修饰符
- b) 它是一个运算符，请求由参数标识的类的新实例。

42. Null – 此关键字表示引用类型变量的空值。即对于任何派自 `System.Object` 的类型的变量。`null` 在 C#2.0 中也表示可空值变量的空值。

43. Object – 此关键字用于字段、属性、方法、变量声明以及 `typeof` 和强制转换操作，作为 .NET 框架结构 `System.Object` 的别名，即它代表所有其他引用类型所派生的基类。在某些平台上，引用的大小为 32 位，而在另一些平台上为 64 位。

44. Operator – 此关键字允许类重载算术运算符和转换运算符。

45. Out – 此关键字显式指定变量应通过引用传递给方法。使用此关键字的变量在方法调用之前不能初始化，以确保程序员理解其意图效果。使用 `out` 要求开发者即使在调用代码中也指定该关键字，以确保阅读代码的开发者能够看出变量的值将在其他处被更改。这在分析程序流时非常有用。

46. Override – 它用于声明被重写的函数，该函数扩展了同名的基类函数。

47. Params – 它用于描述何时将参数组传递给方法。方法的数量并不重要，因为它们可以变化。`params` 关键字必须是方法签名中的最后一个变量，因为它不重要，这样编译器就可以处理已定义的参数。

48. Private – 它用于字段、属性和方法声明，使字段、属性或方法对其封装的类私有。这意味着它在类外部不可见。

49. Public – 它用于字段、属性和方法声明，使字段、属性或方法对其封装的类公开。这意味着它可以从任何类可见。

50. Protected – 它用于字段、属性和方法声明，使字段、属性或方法对其封装的类受保护的。这意味着它在类外部不可见。

51. Readonly – 它与 `const` 关键字密切相关，例外允许带有该修饰符的变量在构造函数中初始化，并且它与类实例而非类本身相关。

52. Ref – 它显式指定变量应通过引用而非通过值传递。

53. Return – 此关键字用于从方法或属性访问器返回执行流。如果方法或属性访问器有返回类型，则关键字后跟着要返回的值。

54. Sbyte – 此关键字用于字段、属性、方法和变量声明中的 `typeof` 和强制转换操作，作为 .NET 框架结构 `System.Sbyte` 的别名，即它代表一个范围从 -128 到 127 的 8 位整数。

55. Sealed – 此关键字用于指定类不能被继承。

56. Short – 此关键字用于字段、属性、方法和变量声明中的 `typeof` 和强制转换，作为 .NET 框架结构 `System.Int16` 的别名，即它代表 16 位整数。

57. Sizeof – 它返回存储对象需要多少字节。

58. Stackalloc – 它在不代码上下文用于在栈上分配内存块。

59. Static – 它用于字段、属性、方法和变量声明以及 `typeof` 和强制转换操作，作为 `System.String` 的别名，表示不可变的字符序列。

60. Struct – 它声明一种结构，意味着一种值类型。

61. Switch – 它是一种控制语句，通过将控制权传递到 `case` 语句之一来处理多个枚举和选择。

62. This – 它作为实例属性或实例方法使用，引用当前类实例。它引用调用包含该方法的对象。

63. Throw – 它用于抛出异常对象。

64. True – 它是一个布尔常量值。`while(true)` - 它将创建一个无限循环。

65. Try – 它用于标识语句或块作为异常处理序列的主体。异常处理序列的主体后面应接 `finally` 或 `catch` 子句。

66. Typeof – 此关键字在传递类名时返回 `System.Type` 类的实例。

67. Uint – 此关键字用于字段、属性、方法和变量声明中的 `typeof` 和强制转换操作，作为 .NET 框架结构 `System.Uint32` 的别名，即代表 32 位无符号整数。

68. Ulong – 此关键字用于字段、属性、方法和变量声明中的 `typeof` 和强制转换操作，作为 .NET 框架结构 `System.Uint64` 的别名，即代表 64 位无符号整数。

69. Unchecked – 它在进行整数算术时防止溢出检查。`unchecked` 可以用作单个表达式的运算符，也可以作为整个代码块的语句。

70. Unsafe – 它可以用于定义使用不安全代码或修改过程。如果代码使用了“地址”(&) 指针运算符，则代码是不安全的。

71. Ushort – 此关键字用于字段、属性、方法和变量声明中的 `typeof` 和强制转换，作为 .NET 框架结构 `System.Uint16` 的别名，即代表 16 位无符号整数。

72. Using – 在 C# 中，此关键字有两个不同的含义，取决于它是用作语句还是指令。

73. Var – 为了允许编译器推断变量类型，在声明变量时可以使用此关键字代替类型。此功能可缩短变量声明。

74. Virtual – 它被应用于方法声明，以指示该方法可以在子类中被重写。

75. Void – 此关键字用于方法签名，以声明一个不返回值的方法。由 void 返回类型的方法不能为其包含的返回语句提供任何参数。
