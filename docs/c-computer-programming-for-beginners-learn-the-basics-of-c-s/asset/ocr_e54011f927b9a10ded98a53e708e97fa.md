# CHAPTER 1: INTRODUCTION TO C#

C# (pronounced as See-Sharp) was created by a team of people at Microsoft led by Anders Hejlsberg. When .NET framework was originally being developed by Microsoft, and the programmers had to write the class libraries with the help of Simple Managed C, a managed code compiler system. However, there were a few issues with using C. As a result; C# was developed as a new language to overcome these problems.

It is a powerful and flexible programming language. Like other programming languages, C# can be used to create a variety of applications. The language does not place constraints on what you can do. It has been used for projects as diverse as dynamic Web sites, development tools, and compilers. (Jones, 2001)

C# has been specifically designed to be simple and modern. It is an object-oriented and general purpose programming language. If you are already familiar with programming, you will easily recognize that C# borrows a range of key concepts for a variety of other programming languages, the most notable of which is Java.

Let us now look at some important features of this language and why it should be used by programmers.

+   1. Simple – C# removes some of the pitfalls and complexities of languages such as C++ and Java. As we mentioned earlier that it is familiar in many aspects to C++ as; statements, operators, expressions, and other functions are taken directly from C and C++. But the improvements made the language simpler.

+   2. Modern – Features such as garbage collection, exception handling, extensible data types and code security makes a language modern and C# consists of all these.

+   3. Object-Oriented- The keys to object-oriented language are the inheritance, encapsulation and polymorphism. C# supports all of these.
