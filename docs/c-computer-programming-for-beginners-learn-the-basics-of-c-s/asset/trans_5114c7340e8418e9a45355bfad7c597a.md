## C# 中的自动垃圾收集

在 C 和 C++ 中，许多对象要求程序员在声明后分配其资源，才能安全地使用这些对象。一旦对象被使用，将这些资源释放回空闲内存池也是程序员的责任。如果资源没有释放，则被称为代码内存泄漏，因为会不必要地消耗越来越多的资源。另一方面，如果资源过早释放，就会发生数据丢失、内存区域损坏和空指针异常。

然而，C# 通过独立管理应用程序中使用的所有对象的生命周期来防止这些危险。在 C# 中，垃圾回收由 CLR（公共语言运行时）处理。CLR 垃圾收集器定期检查内存堆中的任何未引用的对象并释放这些对象持有的资源。换句话说，垃圾收集器充当了自动内存管理器。它让你能够在无需释放内存的情况下开发应用程序，并通过确保一个对象无法使用另一个对象的内容提供了内存安全。
