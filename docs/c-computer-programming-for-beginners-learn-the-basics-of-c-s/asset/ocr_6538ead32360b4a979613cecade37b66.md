# The Basics of the switch Statement

In a programming language, the switch statement is akin to a selection control mechanism. It is generally used to let the value of a variable modify the control flow of the program execution by means of a multiway branch. Think of the switch statement as a set of multiple statements.

The switch statement will list a number of possibilities, and each possibility will have its own action. There will also be a default action when no other possibility is returned as true. Just like the statement is accompanied by the else statement, the switch statement has a companion in the form of the case statement. However, multiple case statements have to be used with a single switch statement
