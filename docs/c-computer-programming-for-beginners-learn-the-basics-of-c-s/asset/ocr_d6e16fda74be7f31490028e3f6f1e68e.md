| C# | C++ |
|---|---|
| It is a high level language that is component oriented. | It is a low level and platform neutral programming language. |
| When compiled, the C# code is converted into intermediate language code. The intermediate code is then converted into executable code through the process called just-in compilation. | When compiled, C++ code is converted into assembly language code. |
| The memory management in C# is automatically handled by garbage collector. | The memory that is allocated in the heap dynamically has to be explicitly deleted. |
| In the Switch statement, the test variable can be a string. | In the C++ switch statement, test variable cannot be a string. |
| In the switch statement, when break statement is not given, the fall through will not happen to the next case statement if the current case statement has any code. | The switch statement in C++, when break statement is not given, the fall through will happen to the next case statement even if the current case statement has any code.
