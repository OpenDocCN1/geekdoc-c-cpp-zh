# Conditional Directives

The conditional directives are useful for testing a symbol or symbols to check if they evaluate to true. You can use #if directive to create a conditional directive .If they do evaluate to true, the compiler evaluates all code between # if and the next directive.

Syntax –

#if symbol [operator symbol]. . .

Here, symbol is the name of the symbol which you want to test. You can also prepend symbol or true and false with the negation operator. The operator symbol is used for evaluating the symbol. The operators could be either of the following –

+   * Equality (==)
* Inequality (!)
* And (&&)

Operators with parentheses can also be used to group symbols.
