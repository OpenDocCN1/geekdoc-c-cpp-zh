# Indexers

An indexer allows an object to be indexed such as an array. When you define an indexer for a class, this class behaves similar to virtual array. The instance of this class then can be accessed using the array class operator ([).

# Use of indexers –

The declaration of an indexer is to some extent similar to property. Just like in properties, you use get and set access for defining an indexer. The index returns or set a particular value from the object instance, whereas properties return or set a specific data member. In other words, an indexer breaks the instance data into smaller parts and indexers each part, sets or gets each part. Indexers are not defined with names, but with this keyword, which refers to the object instance. (Tutorials Point
