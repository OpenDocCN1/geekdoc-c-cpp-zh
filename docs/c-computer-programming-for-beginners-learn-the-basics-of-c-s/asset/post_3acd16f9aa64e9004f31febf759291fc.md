## CHAPTER 2: BASIC SYNTAX OF C#

As we know that C# is an object-oriented programming and in object-oriented programming methodology, a program consists of various objects that interact with each other by means of actions. These actions which are taken by an object are called as methods. The objects of the same kind are said to be in the same class or have the same type.

Let us now understand the basics of C# syntax -

- 1. The first statement in any C# program is using System;

This keyword is used for including the namespaces in the program. A program can include multiple using statements.

- 1. The class keyword is used for declaring a class.

- 2. The comments in C# are used for explaining code. The compilers ignore the comment entries. The multiline comments in C# programs start with /* and end with the characters */. The single line comments are indicated by '//' symbol

- 3. The member variables are data members or attributes of a class, used for storing data.

- 4. The member functions are set of statements that perform a specific task. The functions of a class are declared within the class.

- 5. Instantiating a class – the main() method instantiates a class in a C# program.

- 6. The identifier is a name used to identify a class, function, variable or any other user-defined item. Basic rules for naming classes in C# are as mentioned below:

- a) A name must begin with a letter that could be followed by a sequence of letters, underscore or digits (0-9). The first character in an identifier cannot be a digit.

- b) There should not be any embedded space or symbol such as - + ? & @ # * ( ) { } [ ]; : / ' . \ \ and “. However, an underscore can be used.

- c) Most important that it should not be a C# keyword.

## Meaning of each reserved word in C#

- 1. Abstract – It indicates that the thing being modified has an incomplete or missing implementation. The abstract modifier can be used with methods classes, properties, events and indexers.

- 2. As – This keyword casts an object to a different type. The keyword returns null if the object was of an incompatible type.

- 3. Base – it describes that you would like to refer to the base class for the requested information, and not in the current instantiated class.

- 4. Bool – it is used in the field, property, method and variable declarations and in typeof and cast operations as an alias for the .NET framework structure System.Boolean, i.e. it represents True or False.

Methods-these are class members containing codes. They may contain a list of parameters, return value, as well as a generic type declaration. They can be static or instance

Property – these are class members that expose functionality of methods using the syntax of fields. Like methods they can be static or instance.

- 5. Break – this keyword is used to exit out of a loop or switch block.

- 6. Byte – this keyword is used in field, property, method and variable declarations and in typeof and cast operations as an alias for the .NET framework structure System.Byte, i.e. it represents 8-bit unsigned integer whose value ranges between 0-255.

- 7. Case – this keyword is often used in switch statements.

- 8. Catch – it is used to identify a statement or statement block for execution. In case an exception occurs in the body of the enclosing try block then the catch clause is preceded by the try clause. Optionally it may be followed by a finally clause.

- 9. Char – this keyword is used in field, property, method and variable declarations and in typeof and cast operations as an alias for the .NET framework System.Char, i.e. it represents a Unicode character whose value range between 0 -65,535.

- 10. Checked and Unchecked – these operators are used to control the overflow checking context for integral-type arithmetic conversions and operations.

- 11. Class – this keyword is used to declare a class.

- 12. Const – this keyword is used in field and local variable declarations to make the variable constant. Therefore, it is associated with its declaring assembly or class instead of an instance of the class or with a method call.

- 13. Continue – it can be used inside any loop in a method. The purpose of this keyword is to end the current loop iteration and proceed to the next one.

- 14. Decimal – this keyword is used in field, property, method and variable declarations and in typeof and cast operations as an alias for the .NET framework System.Decimal, i.e. it represents signed 128-bit decimal number.

- 15. Default – this keyword can be used in the generic code or the switch statement.

- 16. Delegate – it is used to declare a delegate. A programming construct that is used to obtain a callable reference to a method of a class is called a delegate.

- 17. Do – this is used to identify the beginning of a do loop.

- 18. Double – it is used in field, property, method and variable declarations and in typeof and cast operations as an alias for the .NET framework System.Double.

- 19. Else – it identifies an else clause of an if statement

- 20. Enum – it identifies an enumeration. Enumeration is a data type that enumerates a set of items by assigning to each of them a name (identifier), while exposing an underlying base type for ordering the elements of the enumeration. Enumeration are declared as =

```
enum weekday { Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday }
```

- 21. Event – this keyword is used to declare an event. Events in C# are class members that expose notification to clients of the class. They are only fired and never assigned.

- 22. Explicit – this keyword is used to create type conversion operators that can only be used by specifying an explicit type cast.

- 23. Extern – this keyword indicates that the method being called exists in DLL (Dynamic-link Library)

- 24. False – this keyword is Boolean constant value. Boolean in C# is its own type and cannot be cast to any other primitive type.

- 25. Finally – it is used to identify a statement or statement of block after a try-catch block for execution. It is irrespective of whether the associated try block encountered an exception, and executes even after a return statement. To perform the clean-up activities finally block is used.

- 26. Fixed – this keyword is used to prevent the garbage collector from relocating a variable.

- 27. Float – this keyword is used in field, property, method and variable declarations and in typeof and cast operations as an alias of .NET framework structure System.Single.

- 28. For – it identifies a for loop.
