
你可以在下面的代码中看到此示例。

```
private string color;
public string Color
{
    get { return color; }
    set { color = value; }
}
```

必须使用 `get` 方法来返回变量。另一方面，必须使用 `set` 方法来为该变量赋值。当然，上面的示例只是一个涉及属性的非常简单的例子。因此，它完全可以进一步扩展。

关于属性，你还有另一一点需要理解。一个属性至少需要一个方法才能正常工作。换句话说，你可以使用 `get` 方法，也可以使用 `set` 方法。在这些情况下，另一个方法将是可选的。这种技术允许你根据需求定义只读属性或只写属性。

这里是另一个示例，它进一步说明了属性的巨大潜力。

```
public string Color
{
    get
    {
        return color.ToUpper();
    }
    set
    {
        if (value == "Red")
            color = value;
        else
            Console.WriteLine("This car can only be red!");
    }
}
```

如你所见，这是一段更复杂的代码，具有更高级的属性。现在，你会发现 `color` 变量将仅以大写字母返回。这是因为在返回变量之前对其添加了 `ToUpper()` 方法。代码的下一部分将设置 `color` 变量。然而，唯一接受的值是“Red”。

## 可见性快速指南

在本指南中，你会遇到 `public`（公共）和 `private`（私有）术语。你可能好奇它们代表什么。嗯，它们是表示相关项目可见性的关键字。

任何项目的可见性决定了该项的开放程度。可见性可以应用于类、属性、变量甚至方法。最常见的可见性类型是私有可见性和公共可见性。然而，C# 还有许多其他类型的可见性，在下文中均有所提及。当然，并不是所有项在现阶段对你都有用，但随着你 C# 学习的深入，你一定会遇到它们。

- Public（公共）：定义为 `public` 的项目可以从所有地方访问，这是所有可见性类型中限制最少的一种。默认情况下，接口（Interfaces）和枚举（Enums）具有公共可见性。

- Private（私有）：这种可见性是所有可见性类型中限制最严格的。私有项目只能由同一类的其他项目访问。默认情况下，结构体（structs）和类（classes）设置为私有可见。

- Internal（内部）：这些项目只能从同一个项目内部访问。

- Protected（保护）：标记为 `protected` 的项目只能从同一个类内部或继承自该类的类访问。

- **Protected internal（受保护内部）：这种可见性与 `internal` 可见性相似，但有一个主要区别。继承自 `protected internal` 项目的类，即使继承类位于另一个项目中，也可以访问该项目。

你现在应该能够自己创建简单的类，甚至可以创建它们的属性了。当然，这只是基础水平。通过练习和进一步的知识，你可以创建包含多个类和属性的极其复杂且精彩的程序。

## 掌握成员函数与封装

在类中，成员函数是指其原型或定义位于类定义内部函数，方式与其他变量类似。成员函数可以操作其类的任何对象。它还可以访问该对象的所属类的每一个成员。

另一方面，成员变量是对象的属性。因此，为了实现封装，它们将被保持为私有。它们只能通过公共成员函数进行访问。

下面的示例说明了类成员的使用。在这里，我们正在获取不同类成员的值。

```
using System;

namespace BoxApplication
{
    class Box
    {
        private double length; // 盒子的长度
        private double breadth; // 盒子的宽度
        private double height; // 盒子的高度

        public void setLength( double len )
        {
            length = len;
        }

        public void setBreadth( double bre )
        {
            breadth = bre;
        }

        public void setHeight(double hei )
        {
            height = hei;
        }

        public double getVolume()
        {
            return length * breadth * height;
        }
    }

    class Boxtester
    {
        static void Main(string[] args)
        {
            Box Box1 = new Box(); // 声明类型为 Box 的 Box1
            Box Box2 = new Box();
            double volume;

            // 声明类型为 Box 的 Box2
            // box 1 规格
            Box1.setLength(6.0);
            Box1.setBreadth(7.0);
            Box1.setHeight(5.0);
            // box 2 规格
            Box2.setLength(12.0);
            Box2.setBreadth(13.0);
            Box2.setHeight(10.0);
            // box 1 的体积
            volume = Box1.getVolume();
            Console.WriteLine("Volume of Box1 : {0}",volume);
            // box 2 的体积
            volume = Box2.getVolume();
            Console.WriteLine("Volume of Box2 : {0}", volume);
            Console.ReadKey();
        }
    }
}
```

执行上述代码后，将产生以下结果。

Volume of Box1 : 210
Volume of Box2 : 1560

## C# 中的类静态成员

类成员可以通过 `static` 关键字定义为静态的。在将类的特定成员声明为静态时，无论为该类创建了多少个对象，该静态成员都只有一个副本。

换句话说，`static` 关键字表示该成员该类存在一个实例。静态变量倾向于用于定义常量。这是因为可以通过调用类而无需创建实例来获取它们的值。

```csharp
using System;

namespace StaticApplication
{
    class StaticVar
    {
        public static int num;
        public static void count()
        {
            num++;
        }
        public static int getNum()
        {
            return num;
        }
    }

    class StaticTester
    {
        static void Main(string[] args)
        {
            StaticVar s1 = new StaticVar();
            StaticVar s2 = new StaticVar();
            s1.count();
            s1.count();
            s1.count();
            s2.count();
            s2.count();
            s2.count();
            Console.WriteLine("Value for s1: {0}", StaticVar.getNum());
            Console.WriteLine("Value for s2: {0}", StaticVar.getNum());
            Console.ReadKey();
        }
    }
}
```

执行上述代码后，你会发现以下结果。

Value for s1: 3
Value for s2: 6
