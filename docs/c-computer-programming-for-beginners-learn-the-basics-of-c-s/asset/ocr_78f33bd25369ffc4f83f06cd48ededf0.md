| Operator | Description | Example |
|---|---|--|
| != | It checks if the values of two operands are equal or not. In case values are not equal then condition becomes true | (A != B) is true. |
| == | It checks if the values of two operands are equal or not. If they are equal then condition becomes true. | (A == B) is not true. |
| < | It checks if the value of left operand is less than the value of right operand, if yes then condition becomes true | (A < B) is true. |
| > | It checks if the value of left operand is greater than the right operand and incase it is then condition becomes true | (A > B) is not true. |

| Operator | Description | Example |
|---|---|--|
| <= | It checks if the value of left operand is less or equal to the value of right operand, in case yes then condition becomes true | (A <= B) is true. |
| >= | It checks if value of left operand is greater than the value of right operand, in case yes then the condition becomes true. | (A >= B) is not true. |
