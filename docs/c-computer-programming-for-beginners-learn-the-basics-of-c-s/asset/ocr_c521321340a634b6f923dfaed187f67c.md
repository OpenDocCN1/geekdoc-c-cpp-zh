# The Importance of the .NET Framework

The .Net framework is a revolutionary platform that helps a programmer to write applications such as; windows applications, web applications, and web services. It has been designed in such a way that it can be used from any of the following languages: C++, C#, Jscript, COBOL, Visual Basic, etc. These languages can access the framework as well as communicate with each other.

Theoretically speaking

The .NET framework is compatible with a large range of programming languages. However, it is C# which is most commonly associated with this framework. It is even known as ‘THE .NET language’ in some circles. This is probably due to the fact that the development of the framework and the language took (IDE) took place at the same time.
