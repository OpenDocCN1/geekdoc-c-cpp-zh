+   7. System.Globalization - it defines types that define culture-related information, including country, region, language, calendars, currency, dates, numbers and sort order for strings.

+   8. System.CodeDom – this namespace contains classes that represent elements of a source code document. This supports the generation and compilation of source code in supported programming languages.

+   9. System.Security - it contains classes that represent the .Net framework security system and permissions.

+   10. System.IO – this namespace contains types that support input and output. It also includes the ability to read and write data to streams, compress data in streams, create and use isolated stores, map files to an application’s logical address space, control multiple data objects in a single container, communicate using anonymous or named pipes, implement custom logging and to handle the flow of data.

+   11. System.Threading – it defines types that enable multithreading programming. A child namespace provides types that simplify the work of writing concurrent and asynchronous code.

+   12. System.Text – it defines types that support various regular expressions, character encodings and a more efficient mechanism for manipulating strings.

+   13. System.Configuration – this namespace contains types for handling configuration data, such as data in application configuration files or machine.
