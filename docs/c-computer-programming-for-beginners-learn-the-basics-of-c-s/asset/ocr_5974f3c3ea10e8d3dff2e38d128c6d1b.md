37. Is – this keyword compares an object to a type, and if they are of similar types, it returns true. Therefore, is keyword is used to check compatibility, usually before converting (casting) a source type to a destination type. This ensures that won't cause a type-case exception to be thrown. By using is on a null variable always returns false.

38. Lock – it allows a section of code to exclusively use a resource. This feature is useful in multi-threaded applications. In case a lock to the specified object is already held when a piece of code tries to lock the object, the code’s thread gets blocked unless the object is available.

39. Long – it is used in field, property, method and variable declarations and in typeof and cast as an alias for the .NET framework structure System.Int64.

40. Namespace – this keyword is used to supply a namespace for a class, type, and structure declarations.

41. New – this keyword has two different meanings -

+   a) It is a modifier that explicitly hides a member

+   b) It is an operator that requests a new instance of the class identified by its argument.

42. Null – this keyword represents an empty value for a reference type variable. That is for a variable of any type derived from System.Object. null also represents empty value for nullable value variables in C#2.0.

43. Object– this keyword is used in field, property, method, variable declarations and in typeof and cast operations as an alias for the .NET framework structure System.Object, i.e. it represents the base class from which all other reference types derive. The size of the reference is 32 bits on some platforms, while on others is 64 bits.
