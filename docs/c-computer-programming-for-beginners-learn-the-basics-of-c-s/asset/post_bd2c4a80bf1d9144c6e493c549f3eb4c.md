## The Importance of the .NET Framework

The .NET framework is a revolutionary platform that helps a programmer to write applications such as: windows applications, web applications, and web services. It has been designed in such a way that it can be used from any of the following languages: C++, C#, Jscript, COBOL, Visual Basic, etc. These languages can access the framework as well as communicate with each other.

### Theoretically speaking

The .NET framework is compatible with a large range of programming languages. However, it is C# which is most commonly associated with this framework. It is even known as ‘THE .NET language’ in some circles. This is probably due to the fact that the development of the framework and the language took (IDE) took place at the same time.

## What Do You Need To Get Started With C# Programming?

Before you get started on writing C# programs, there are a few things that you need to take care of first. Make sure that the following programs have been installed on your computer.

- The .NET Framework Software Development Kit
- An Editor

That is all. These are the only two things you require to start programming in C#. There is a wide range of editors available. You can even use Notepad or the DOS Editor but more on that later. That as it may, it will be better for your learning curve if you install either one of the following optional programs.

- Visual C# .NET
- Visual C++ 6.0. This is included in the Microsoft Visual Studio 6.0 package.

Your first step should be to get the .NET SDK installed on your computer. You can easily download the program from the official website of Microsoft. You will also get a complete documentation of the program along with it. On installing this kit, you will be able to compile and execute your source code in C#. This is made possible by the Command Line Compiler that has been built into the kit along with the runtime Just in Time Compiler. If you have dabbled in Java previously, you can recognize them as being similar to the Java Compiler and the Java Interpreter, which is available in the Java Development Kit.

## About the Editor

The editor is a program that is used for writing the source codes. C# is versatile in this matter as it can be written with the help of nearly any text editor. Even the basic Notepad available in Windows is a good choice. For compiling, you can easily use csc.exe, the Command Line Compiler available within the .NET framework.

When it comes to developing C# programs with .NET SDK, Notepad is a popular choice. On the other hand, it is not the best editor, especially for beginners. After all, some useful features such as code numberings and syntax coloring are absent in Notepad.

That is why many developers prefer to use an Integrated Development Environment or IDE. There are quite few options available from Microsoft, the best of which is Visual Studio. This program can be used for working on all the aspects of the .NET framework. This is certainly a highly advanced program and is available in a range of editions. The complete Visual Studio does cost a bit and may be too advanced for hobbyists.

On the release of the .NET framework, Express versions of the product were introduced by Microsoft. These versions are meant for hobby programmers and those who are just starting with the .NET framework. The Express versions will only work for a single language. They may not have the most advanced features of Visual Studio, but they are free. They are also easy to use for learning the language of your choice which is C# in this case.

There are other third-party editors available in the market. However, for this book, we will be using Visual# Express for writing the code. You must remember that the codes will remain the same irrespective of the editor you are using.

The terms used in the above may sound overwhelming to some, but do not worry we have covered all the important ones so that you can begin programming in C#. C# is designed to work with .NET. The differences between C++ and C# are as below:

| C# | C++ |
|---|---|
| It is a high level language that is component oriented. | It is a low level platform neutral language. |
| When compiled, the C# code is converted into intermediate language code. The intermediate code is then converted into executable code through the process called just-in time compilation. | When compiled, C++ code is converted into assembly language code. |
| The memory management in C# is automatically handled by garbage collector. | The memory that is allocated in the heap has to be explicitly deleted. |
| In the switch statement, the test variable can be a string. | In the C++ switch statement, test variable cannot be a string. |
| In the switch statement, when break statement is not given, the fall through will not happen to the next case if the current statement has any code. | The switch statement in C++, when break statement is not given, the fall through will happen to the next case even if the current statement has any code. |
| In addition to do...while, while and for, C# has another flow control statement called foreach. | There is no foreach statement in C++. |
| C# structs can contain only value types. The structs is sealed and it cannot have a default-argument constructor. | In C++, structs behave like classes except that the default access is public instead of private. |
| In C#, events, properties and delegates can also be specified as class members. | In C++, only constructors, variables, functions, destructors and operator overloads can be class members. Delegates, events and properties cannot be specified as class members. |
| The end of the class definition has a closing brace alone. | The end of the class definition has a closing brace followed by a semicolon. |
