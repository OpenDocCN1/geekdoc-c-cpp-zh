+   76. Volatile – it is used to declare a variable that may change its value over time due to modification by an outside process, another concurrently running thread, or the system hardware.

+   77. While – it identifies the we loop.

+   78. Add and remove – these keywords allow you to execute code whenever a delegate is added or removed from an event. Their usage is similar to get set keywords with properties.

+   79. Alias – it is used to indicate an external alias. In case you need to use several versions of the same assembly or assemblies with the same full qualified typenames, you will have to use alias and extern keywords to give different alias names for each version.

+   80. Global – it is useful in some contexts to resolve the ambiguity between identifiers. This means for example, if you have a conflict between a class and namespace, you can use the keyword global to access the namespace.

+   81. Partial – it is used to allow developers to build classes from different files and have the compiler generate one class by combining all the partial classes. It is mostly useful for separating classes into separate blocks.

+   82. Set – it is used to declare write accessor for a property.

+   83. Value – it is used in a property’s write accessor to represent the value requested for assignment to property.

+   84. Where – this keyword has two meanings –
a) With LINQ, it is used to query a data source and filter or select elements to return.
b) It is used to specify one or more constraints on generic type parameters.

+   85. Yield – This keyword returns the next value from an iterator or ends iteration.
