# CHAPTER 5: C# OPERATORS

Operator is a symbol that tells the compiler to perform specific mathematical or logical manipulations. In C#, there is a rich set of built-in operators. In this chapter we will explain each one of them.

+   Arithmetic Operators

C# supports following arithmetic operators. In the below mentioned table assume value of variable A as 10 and B as 20.

| Operator | Description | Example |
| --- | --- | --- |
| + | Subtracts second operand from the first | A - B = -10 |
| / | Adds the two operands divides numerator by denominator | A + B = 30 |
| * | It multiplies operands | A * B = 200 |
| ++ | Increment operator, increases integer value by 1 | A++ = 11 |
| % | Modulus operator and remainder of after integer division | B% A = 0 |
| -- | Decrement operator decreases integer value by 1 | A-- = 9 |
