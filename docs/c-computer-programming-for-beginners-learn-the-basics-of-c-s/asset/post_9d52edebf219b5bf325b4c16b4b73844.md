
29. Foreach – it identifies a *foreach* loop.

30. Goto – it returns the flow of operations to the label which follows it. The labels can be created by putting a colon after any word.

31. If – this keyword identifies the *if* statement. The *if* statement in C# is similar to Java and C++.

```
if (condition)
```

```
{
  // Do something
}
else
{
  // Do something else
}
```

32. Implicit – it is used for a type to define what what types can be converted without the need for explicit casting.

33. In – it identifies the collection to enumerate in a *foreach* loop.

34. Int – this keyword is used in the field, property, method and variable declarations and in typeof and as an alias for .NET framework structure System.Int32, it represents 32-bit integer.

35. Interface – this keyword is used to declare an interface. The interfaces provide a construct for a programmer to create types that can have properties, methods, indexes, and events declared, but not implemented.

36. Internal – this keyword is an *access modifier* used in field, property, and method declarations to make the field, property, or method internal to its enclosing assembly, i.e. it is only visible within the assembly that implements it.

37. Is – this keyword compares an object to a type, and if they are of similar types, it returns true. Therefore, is keyword is used to check compatibility, usually before converting (casting) a source type to a destination type. This ensures that won't cause a type-case exception to be thrown. By using is on a null variable always returns false.

38. Lock – it allows a section of code to exclusively use a resource. This feature is useful in multi-threaded applications. In case a lock to the specified object is already held when a piece of code tries to lock the object, the code’s thread gets blocked unless the object is available.

39. Long – it is used in field, property, method and variable declarations and in typeof and cast as an alias for the .NET framework structure System.Int64.

40. Namespace – this keyword is used to supply a namespace for a class, type, and structure declarations.

41. New – this keyword has two different meanings -

- a) It is a modifier that explicitly hides a member
- b) It is an operator that requests a new instance of the class identified by its argument.

42. Null – this keyword represents an empty value for a reference type variable. That is for a variable of any type derived from System.Object. null also represents empty value for nullable value variables in C#2.0.

43. Object – this keyword is used in field, property, method, variable declarations and in typeof and cast operations as an alias for the .NET framework structure System.Object, i.e. it represents the base class from which all other reference types derive. The size of the reference is 32 bits on some platforms, while on others is 64 bits.

44. Operator – this keyword allows a class to overload arithmetic and cast operators.

45. Out – this keyword explicitly specifies that a variable should be passed by reference to a method. The variable that uses this keyword must not be initialized before the method call to ensure that the programmer understands its intended effects. Using out requires the developer to specify the keyword even in calling code so to ensure that it is easily visible to developers reading the code that the variable will have its value changed elsewhere. This is useful when analyzing the program flow.

46. Override – it is used in declaring an overridden function, which extends a base class function of the name.

47. Params – it is used to describe when groupings of parameters are passed to a method. The number of methods is not important as they can vary. The params keyword must be the last variable in a method signature as it is not important, so that the compiler can deal with the parameters which have been defined.

48. Private – it is used in field, property, and method declarations to make the field, property, or method private to its enclosing class. This means that it is not visible outside of its class.

49. Public – it is used in field, property, and method declarations to make the field, property, or method public to its enclosing class. This means that it is visible from any class.

50. Protected – it is used in field, property, and method declarations to make the field, property, or method protected to its enclosing class. This means that it is not visible outside of its class.

51. Readonly – it is strongly related to const keyword, with the exception of allowing a variable with its modifier to be initialized in a constructor, along with being associated with a class instance rather than the class itself.

52. Ref – it explicitly specifies that a variable should be passed by reference rather than by value.

53. Return – this keyword is used to return execution from a method or from a property accessor. In case a method or property accessor has a return type, keyword is followed by the value return.

54. Sbyte – this keyword is used in field, property, method and variable declarations in typeof and cast operations as an alias of the .NET framework structure System.Sbyte, i.e. it represents an 8-bit integer whose value ranges from -128 to 127.

55. Sealed – this keyword is used to specify that a class cannot be inherited.

56. Short – this keyword is used in field, property, method and variable declarations in typeof and cast as an alias for the .NET framework structure System.Int16, i.e. it represents 16-bit integer.

57. Sizeof – it returns how many bytes an object requires to be stored.

58. Stackalloc – it is used in unsafe code context in order to allocate a block of memory on the stack.

59. Static – it is used in field, property, method and variable declarations in typeof and cast operations as an alias for System.String, i.e. indicates immutable sequence of characters.

60. Struct – it declares a structure that means a value type.

61. Switch – it is a control statement that handles multiple enumerations and selections by passing control to one of the case statements.

62. This – it is used as an instance property or instance method to refer to the current class instance. It refers to the object through which containing method was invoked.

63. Throw – it is used to throw an exception object.

64. True – it is a Boolean constant value. while(true) - it will create an infinite loop.

65. Try – it is used to identify a statement or block as the body of an exception handling sequence. Body of the exception handling sequence should be followed by either finally or catch clause.

66. Typeof – this keyword returns an instance of the System.Type class when passed a name of a class.

67. Uint – this keyword is used in field, property, method and variable declarations in typeof and cast operations as an alias for the .NET framework structure System.Uint32, i.e. represents 32-bit unsigned integer.

68. Ulong – this keyword is used in field, property, method and variable declarations in typeof and cast operations as an alias for the .NET framework structure System.Uint64, i.e. represents 64-bit unsigned integer.

69. Unchecked – it prevents overflow-checking when doing integers arithmetic. The unchecked may be used as an operator on a single expression or as a statement on a whole block of code.

70. Unsafe – it may be used to define a block of code which uses unsafe code or modify a procedure. The code is unsafe if it uses the "address of" (&) pointer operator (*).

71. Ushort – this keyword is used in field, property, method and variable declarations in typeof and cast as an alias for the .NET framework structure System.Uint16, i.e. represents 16-bit unsigned integer.

72. Using – In C#, this keyword has two different meanings, depending on if it is used as a statement or as a directive.

73. Var – To allow the compiler to infer the type of the variable, this keyword can be used in place of a type when declaring a variable. This feature can be used to shorten variable declarations.

74. Virtual – it is applied to a method declaration to indicate that the method can be overridden in subclass.

75. Void – this keyword is used in method signatures to declare a method that does not return a value. The method declared by void return type cannot provide any arguments to any return statements they contain.
