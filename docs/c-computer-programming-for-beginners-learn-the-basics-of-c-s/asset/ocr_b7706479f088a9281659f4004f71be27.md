```
A = 0011 1100
B = 0000 1101
```

```
A & B = 0000 1100
A | B = 0011 1101
A ^ B = 0011 0001
~A = 1100 0011
```

C# supports the following bitwise operators, assuming same values of variable A and B as above –

| Operator | Description | Example |
|---|---|---|n| | | Binary OR Operator copies a bit if it exists in either operand. | (A | B) = 61, which is 0011 1101 |
| & | Binary AND operator copies a bit to the result if it exists in both operands. | (A & B) = 12, which is 0000 1100 |
| ~ | Binary ones complement operator is unary and has the effect of 'flipping' bits. | (-A) = 61, which is 1100 0011 in 2's complement due to a signed binary number. |
| ^ | Binary XOR operator copies the bit if it is set in one operand but not both. | (A ^ B) = 49, which is 0011 0001 |
| >> | Binary right shift operator. In this operator, the left operands value is moved right by the number of bits specified by the right operand. | A >> 2 = 15, which is 0000 1111 |
