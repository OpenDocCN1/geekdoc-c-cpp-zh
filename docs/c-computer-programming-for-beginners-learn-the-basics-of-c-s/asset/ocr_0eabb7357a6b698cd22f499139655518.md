After you execute the code shown in the example above, the following result will be produced.

Before method call, value of a : 100

After method call, value of a : 5

For the output parameter, the variable supplied does not require a value to be assigned to it. As such, output parameters are quite useful when you have to return the values from a method by means of the parameters without getting an initial value assigned to the parameter.

This is demonstrated in the following example.

```
using System;
namespace CalculatorApplication
{
    class NumberManipulator
    {
        public void getValues(out int x, out int y)
        {
            Console.WriteLine("Enter the first value: ");
            x = Convert.ToInt32(Console.ReadLine());
            Console.WriteLine("Enter the second value: ");
            y = Convert.ToInt32(Console.ReadLine());
        }
    }
}
```
