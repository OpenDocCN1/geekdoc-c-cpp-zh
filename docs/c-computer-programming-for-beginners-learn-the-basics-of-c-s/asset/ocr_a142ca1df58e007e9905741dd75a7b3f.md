# Easy to use generics

The C# generics allow delaying the specification of the data type of programming elements in a method or a class until it is actually used in the program. This means generics allow you to write a method or class that can work with any data type. The specifications for the method or a class are written with substitute parameters for data types. When the compiler encounters a constructor for the function call for the method or a class, it generates code to handle the specific data type.

Features of generics

Generics enrich your program in the following ways -

+   1. Generics help you to maximize reuse, performance and type safety.

+   2. It allows you to create generic collection classes. The .NET framework class library contains several new generic collection classes in the System.Collections.Generic namespace.

+   3. It allows you to create your own generic interfaces, methods, classes, delegates and events.

+   4. You may create generic classes constrained to enable access to methods on particular data types.

+   5. By means of reflection you may get information on the types used in a generic data type at run-time.
