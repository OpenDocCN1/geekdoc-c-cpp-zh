```
// This method could be executed by the Fax object unregister
// itself with the NewMail event so that it no longer receives
public void Unregister(MailManager mm) {

    // Unregister with MailManager's NewMail event
    mm.NewMail -= FaxMsg;
}
```

When the application initializes, it would construct a MailManager object and save the reference to this object in a variable. The application would construct a Fax object, passing the reference to the MailManager object as a parameter. In the Fax constructor, the Fax object registers its interest in MailManager's NewMail event using C#'s +=.

mm.NewMail += FaxMsg;

Because the C# compiler has built-in support for events, the compiler translates the use of the += operator into the following line of code to add the object's interest in the event.

```
mm.add_NewMail(new EventHandler<NewMailEventArgs>(this.FaxMsg));
```

As you can see, the C# compiler is generating code that will construct an EventHandler<NewMailEventArgs> delegate that wraps the FaxMsg method. The C# compiler calls the MailManager's add_NewMail method, passing the delegate. Of course, you can verify all of this by compiling the code and looking at the IL with a tool like ILDisasm.

Even if you're using a programming language that doesn't directly support events, you can still register a delegate by calling the add method explicitly. The effect is identical; the source code will just not look as pretty. The add method registers the delegate with the event by adding it to the event's list of delegates.

When the MailManager object raises the event, the FaxMsg method gets called. The method is passed by a reference to the MailManager object as the first parameter. Most of the time, this parameter is ignored, but it can be used if the Fax object wants to access members of the MailManager object in response to the event notification. The second parameter is a reference to the NewMailEventArgs object. This object contains any additional information the designer of Mail and NewMailEventArgs thought would be useful to the event receivers.
