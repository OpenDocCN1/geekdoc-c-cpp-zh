Unfortunately, the .NET Framework doesn't come with an asynchronous lock offering reader-writer semantics. However, I have built such a class, which I call AsyncOneManyLock. You can use it the same way that you use a SemaphoreSlim. Here is an example:

```
private static Task AccessResourceViaAsyncSynchronization(AsyncOneManyLock asyncLock) {
  // TODO: Execute whatever code you want here...

  // Pass OneMode.Exclusive or OneManyMode.Shared for wanted concurrent access
  await asyncLock.Acquire(OneManyMode.Shared); // Request shared access
  // When we get here, no threads are waiting on the resource; other threads may be reading
  // TODO: Read from the resource...

  // When done accessing resource, relinquish lock so other code can access the resource
  asyncLock.Release();

  // TODO: Execute whatever code you want here...
}

The following is the code for my AsyncOneManyLock.

```
public enum OneMode { Exclusive, Shared }

public class AsyncOneManyLock {
#region Lock code
  private SpinLock _lock = new SpinLock(true); // Don't use readonly with SpinLock
  private void lock(bool taken = false) { _lock.Enter(ref taken); }
  private void unlock() { _lock.Exit(); }
#endregion


#region Lock state and helper methods
  private Int32 _state = 0;
  private Boolean IsOwnedByWriter() { return _state == -1; }
  private Boolean IsOwnedByReaders() { return _state > 0; }
  private Int32 AddReaders(Int32 count) { return _state += count; }
  private Int32 SubtractReader(Int32 count) { return _state -= count; }
  private void MakeWriter(int _state) { _state = -1; }
  private void MakeFree() { _state = 0; }
#endregion
