Let me explain the meaning of ALEx's command-switches:

+   * /out This switch tells ALEx to create a new PE file

+   * /version This switch identifies the version of the publisher policy assembly; this version has nothing to do with the SomeClassLibrary assembly itself. You see, publisher policies can also be versioned. Today, the publisher might create a publisher policy redirecting version 1.0.0.0 of SomeClassLibrary to version 2.0.0.0. In the future, the publisher might want to direct version 1.0.0.0 of SomeClassLibrary to version 2.5.0.0. The CLR uses this version number so that it knows to pick up the latest version of the publisher policy assembly.

+   * /keyfile This switch causes ALEx to sign the publisher policy assembly by using the publisher's public/private key pair. This key pair must match the key pair used for all versions of the SomeClassLibrary assembly. After all, this is how the CLR knows that the publisher created both the assembly and this policy file.

+   * /inkresource This switch tells ALEx that the XML configuration file is to be considered a separate file of the assembly. The resulting assembly consists of two files, of which must be packed and deployed to the users along with the new version of the SomeClassLibrary assembly. By the way, you can use ALEx's /embedresource switch to embed the XML configuration file into the assembly, making a single file for assembly, because the CLR requires the XML file to be contained in its separate file.

After this publisher policy is built, it can be packed together with the new SomeClassLibrary.dll assembly file and deployed to users. The publisher policy assembly must be installed into the GAC. Although SomeClassLibrary assembly can also be installed into the GAC, it doesn't have to be. It could be deployed into an application's base directory or some other directory identified by a codeBase URL.

> > Important A publisher should create a publisher policy assembly only when deploying an update or a service pack version of an assembly. When doing a fresh install of an application, no publisher policy should be installed.
