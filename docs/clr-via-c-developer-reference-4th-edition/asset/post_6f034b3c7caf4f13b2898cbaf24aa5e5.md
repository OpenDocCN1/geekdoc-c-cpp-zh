## Explicitly Implementing an Event

In this section, I discuss how explicitly implement an event. However, there are certain scenarios where you might want to explicitly implement a type.

To efficiently store delegates, each object that exposes events will maintain a collection (usually a dictionary) with some sort of event. When a new object is constructed, this collection is empty. When interest in an event is registered, the event identifier is looked up in the collection. If the event identifier is new, the delegate is combined with the list.

When the object needs to raise an event, the event identifier is looked up in the collection. If the collection doesn't have an entry for the event, nothing has registered in the event. If the event identifier is in the collection, the delegate list associated with the event is invoked. Implementing this pattern is the responsibility of the developer who is designing the type; the developer using the type has no idea how the events are implemented.

Here is an example of how you could accomplish this pattern. First, I implemented an EventSet class that represents a collection of events and each event's delegate list as follows:

```cs
using System;
using System.Collections.Generic;
// This class exists to provide a bit more type safety and
// code maintainability when using EventSet
public sealed class EventSet {
    // The private dictionary used to maintain EventKey -> Delegate mappings
    private readonly Dictionary<EventKey, Delegate> m_events = new Dictionary<EventKey, Delegate>();

    // Adds an EventKey -> Delegate mapping if it doesn't exist or
    public void Add(EventKey eventKey, Delegate handler) {
        Monitor.Enter(m_events);
        Delegate d;
        m_events.TryGetValue(eventKey, out d);
        m_events[eventKey] = Delegate.Combine(d, handler);
        Monitor.Exit(m_events);
    }

    // Removes a delegate from an EventKey (if it exists) and
    // removes the EventKey -> Delegate mapping the last delegate is removed
    public void Remove(EventKey eventKey, Delegate handler) {
        Monitor.Enter(m_events);
        // Call TryGetValue to ensure that an exception is not thrown if
        // attempting to remove a delegate from an EventKey not in the set
        Delegate d;
        if (m_events.TryGetValue(eventKey, out d)) {
            d = Delegate.Remove(d, handler);
        }
    }
}
```
