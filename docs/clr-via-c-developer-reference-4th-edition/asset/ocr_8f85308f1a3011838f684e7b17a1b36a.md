> Note When the Compare method is not performing an ordinal comparison, it performs character expansions. A character expansion is when a character is expanded to multiple characters regardless of culture. In the above case, the German Eszet character is expanded to 'ss'. Similarly, the Æ ligature is always expanded to 'AE'. So in the code example, the second call to Compare will return true regardless of which culture I actually pass to it.

In some rare circumstances, you may need to have even more control when comparing strings for equality or sorting. This could be necessary when comparing strings consisting of Japanese characters. This additional control can be accessed via the CultureInfo object's CompareInfo property. As mentioned earlier, a CompareInfo object encapsulates a character's comparison tables, and there is just one CompareInfo object per culture.

When you call String.Compare method, if the caller specifies a culture, the specified culture is used, or if no culture is specified, the value in the current thread's Culture is used. Internally, the method obtains the reference to the CompareInfo object for the appropriate culture and calls the Compare method of the CompareInfo object, passing the appropriate options (such as case sensitivity). Naturally, you could call the Compare method of a specific Compare-Info object yourself if you need the additional control.

The method of the CompareInfo type takes as a parameter a value from the Compare-Options enumerated (as shown earlier). You can OR these flags to gain significantly greater control when performing string comparisons. For a complete list of symbols, consult the .NET Framework documentation.
