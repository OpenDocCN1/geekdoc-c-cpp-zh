## Cooperative Cancellation and Timeout

The Microsoft .NET Framework offers a standard pattern for canceling operations. This pattern is cooperative, meaning that the operation that you want to cancel has to explicitly support being canceled. In other words, the code performing the operation that you want to cancel and the code that attempts to cancel the operation must use both the types mentioned in this section. It is nice when long-running compute-bound operations perform after cancellation, so you should consider cancelling your own compute-bound operations. In this section, I'll explain how to accomplish this. But, let me explain the two main types provided in the Framework Class Library (FCL) that are part of the standard cooperative cancellation pattern.

To cancel an operation, you must first create a System.Threading.CancellationToken object. This class looks like this:

```csharp
public sealed class CancellationSource : IDisposable { // A reference type
    public CancellationSource();

    public bool IsCancellationRequested { get; }
    public CancellationToken Token { get; }

    public void Cancel() { // Internally, calls Cancel passing false
    public void Cancel(bool throwOnFirstException) {
    ...
}
}
```

This object contains all the states that have to do with managing cancellation. By constructing a CancellationSource (a reference type), one or more CancellationToken (a value type) can be obtained by querying its Token property and passed around to your operations that allow themselves to be canceled. Here are the most useful members of the CancellationToken value type.

```csharp
public struct CancellationToken { // A value type
public static CancellationToken None { get; } // Very convenient
```

```csharp
public bool IsCancellationRequested { get; } // Called by non-Task invoked operations
public void ThrowCancellationRequested(); // Called by Task-invoked operations
```

```csharp
// WaitHandle is signaled when the CancellationSource is created
public WaitHandle WaitHandle { get; }
// GetHashCode, Equals, operator == and operator!= members are not shown
```

```csharp
public bool CanBeCanceled { get; } // Rarely used
public CancellationTokenRegistration Register(Action<Object> callback, Object state,
bool useSynchronizationContext); // Simpler overloads nothing
```

A CancellationToken is a lightweight value type because it contains a single private field: a reference to its CancellationSource object. A compute-bound operation loop can periodically call Cancellation's IsCancellationRequested property to know if the loop should terminate early, thereby ending the compute-bound operation. Of course, the benefit here is at CPU time is no longer being wasted on an operation whose result you know you're not interested now. Let us put all together with some sample code.

```csharp
internal static class CancellationDemo
public static void Main()
    CancellationSource cts = new CancellationSource();
```

```csharp
// Pass the CancellationToken and the number-to-count into the operation
ThreadPool.QueueWorkItem(item => Count(cts.Token, 1000));
```

```csharp
Console.WriteLine("Press <Enter> to cancel the operation.");
Console.Cancel(); // If counted already, Cancel has no effect on it
// Cancel returns immediately, and the method continues running...
```

```csharp
private static void Count(CancellationToken token, int32 countTo) {
    for (int32 count = 0; count < countTo; count++) {
        if (token.IsCancellationRequested) {
            Console.WriteLine("Count is cancelled");
            break; // Exit the loop to stop the operation
        }
    }
}
```

```csharp
Console.WriteLine(count);
Thread.Sleep(200); // For demo, waste some time
Console.WriteLine("Count is done");
```

Finally, you can create a new CancellationTokenSource object by linking a bunch of CancellationTokenSource objects. This new CancellationTokenSource object will be canceled when any of the linked CancellationTokenSource objects are canceled. The following code demonstrates-

```csharp
// Create a CancellationTokenSource
var cts1 = new CancellationSource();
cts1.Token.Register(() => Console.WriteLine("cts1 canceled"));
```

```csharp
// Create another CancellationTokenSource
var cts2 = new CancellationSource();
cts2.Token.Register(() => Console.WriteLine("cts2 canceled"));
```

```csharp
// Create a new CancellationTokenSource that is canceled when cts1 or cts2 is canceled
var linkedCts = new CancellationTokenSource(cts1.Token, cts2.Token);
linkedCts.Token.Register(() => Console.WriteLine("linkedCts canceled"));
```
