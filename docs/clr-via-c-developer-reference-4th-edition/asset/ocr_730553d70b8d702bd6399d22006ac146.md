```
// Turn all the even-numbered bits by calling the setter antar.
for (Int32 x = 0; x < 14; x++) {
    ba[x] = (x % 2 == 0);
}
```

```
// Show the state of all the bits by calling the getter accessor.
for (Int32 x = 0; x < 14; x++) {
    Console.WriteLine("Bit " + x + " is " + (ba[x] ? "On" : "Off"));
```
