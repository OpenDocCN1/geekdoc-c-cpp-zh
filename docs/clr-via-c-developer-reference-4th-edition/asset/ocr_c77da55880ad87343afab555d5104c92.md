The following code demonstrates string interning.

```
String s1 = "Hello";
String s2 = "Hello";
Console.WriteLine(Object.ReferenceEquals(s1, s2)); // Should be 'False'

s1 = String.Intern(s1);
s2 = String.Intern(s2);
Console.WriteLine(Object.ReferenceEquals(s1, s2)); // Should be 'True'
```

In the first call to ReferenceEquals method, s1 refers to a "Hello" string object in the heap, and s2 refers to a "Hello" string object in the heap. Because the references are different, False will be displayed. However, if you run this version of 4.5 of the CLR, it will be True displayed. The reason is because this version of the CLR chooses to ignore the attribute/flag emitted by the C# compiler, and the CLR inserts the literal "Hello" string when the assembly is loaded into the AppDomain. As previously mentioned, you should never write code that relies on this behavior because that s1 and s2 refer to the single "Hello" string in the heap. However, a future version of the CLR might ignore the attribute/flag and not intern the "Hello" string. In version 4.5 of the CLR does not ignore the attribute/flag when this assembly's code has been compiled using NGen.exe utility.

Before the second call to the ReferenceEquals method, the "Hello" string has been explicitly interned, and s1 now refers to an "Hello". Then by calling again, s2 is set to refer to the same "Hello" string as s1. Now, when ReferenceEquals is called the third time, we are guaranteed to get a result of True regardless of whether the assembly was compiled with the attribute/flag.

Now, let's look at an example to see how you can use string interning to improve performance and reduce memory usage. The TimesWordAppearsEquals method takes two arguments: a word and an array of strings in each array element refers to a single word. This method determines how many specified word appears in the딨 and returns this count.

```
private static Int32 TimesWordAppearsEquals(String word, String[] wordlist) {
    Int32 count = 0;
    for (int wordnum = 0; wordnum < wordlist.Length; wordnum++) {
        if (word.Equals(wordlist[wordnum], StringComparison.Ordinal)) {
            count++;
        }
    }
    return count;
}
```
