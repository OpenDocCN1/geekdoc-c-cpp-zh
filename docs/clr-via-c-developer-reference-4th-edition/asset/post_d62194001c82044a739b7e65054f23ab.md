## Obtaining a String Representation of an Object: ToString

You frequently need to obtain a string representation of an object. Usually, this is necessary when you
to display a numeric type (such as Byte, Int32, Single) or a DateTime object to the user.
Because the .NET Framework is an object-oriented framework, every type is responsible for providing
code that converts an instance's value to a string equivalent. When designing how types should-
complish this, the designers of the FCL devised a pattern that would be consistently throughout.
In this section, I will describe this pattern.

You can obtain a string representation for any object by calling the ToString method. A public,
virtual, parameterless ToString method is defined by System.Object and is therefore callable-
in an instance of any type. Semantically, ToString returns a string representing the object's current
value, and this string should be formatted for the calling thread's culture; that is, the string
representation of a number should use the proper decimal separator, digit-grouping symbol, and
other elements associated with the culture assigned to the calling thread.

Object's implementation of ToString returns the full name of the object's type.
This value isn't particularly useful, but it is a reasonable default for the many types that can't offer
sensible string. For example, what should a string representation of a FileStream or a Hashtable
object look like?

All types that want to offer a reasonable way to obtain a string representation the current value of
the should override the ToString method. Many of the core types are built into the FCL (Byte,
Int32, UInt64, Double, and so on) override their ToString method and return a culturally aware
string. In the Visual Studio debugger, a datatip is displayed when the mouse passes over a particular
variable. The text shown in the datatip is obtained by calling the object's ToString method. So, when
yefine a class, you should always override the ToString method so that you get good debug-
ging support.
