# Conversion Operator Methods

Occasionally, you need to convert an object from one type to an object of a different type. For example, I'm sure you've had to convert a Byte to an Int32 at some point in your life. When the source type and the target type are a compiler's primitive types, the compiler knows how to emit the necessary code to convert the object.

If the source type or target type is not a primitive, the compiler emits code that the CLR performs the conversion (cast). In this case, the CLR checks if the source object's type is the same as the target type (or derived from the target type). However, it is sometimes natural to convert an object of one type to a completely different type. For example, the System.Xml.Linq class allows you to convert an Extensible Markup Language (XML) element to a Boolean, (U)Int32, (U)Int64, Single, Double, Decimal, String, DateTime, DateTime, TimeSpan, Guid, or the null equivalent of any of these types (except String). You could also imagine that the FCL included a Rational data type that might be convenient to convert an Int32 object or a Single object to a Rational object. Moreover, it might also be nice to convert a Rational object to an Int32 or a Single object.

To make these conversions, the Rational type should define public constructors that take a single parameter: an instance of the type you're converting. You should also define public instance Toxx methods that take parameters (like the very popular ToString method). Each method will convert an instance of the defining type to the Xxx type. Here's how to correctly define constructors and methods for a Rational type.

```
public sealed class Rational {
    // Constructs a Rational from an Int32
    public Rational(Int32 num) { ... }

    // Constructs a Rational from a Single
    public Rational(Single num) { ... }

    // Converts a Rational to an Int32
    public Int32 ToInt32() { ... }

    // Converts a Rational to a Single
    public Single ToSingle() { ... }
}
```

By invoking these constructors and methods, a developer using any programming language can convert an Int32 or a Single object to a Rational object and convert a Rational object to an Int32 or a Single object. The ability to do these conversions can be quite handy, and when designing a type, you should seriously consider what conversion constructors and methods make sense for your type.
