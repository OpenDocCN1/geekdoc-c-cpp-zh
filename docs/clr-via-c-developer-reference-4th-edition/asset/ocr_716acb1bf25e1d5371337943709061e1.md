Object o = null;
try {
    o = Activator.CreateInstance(t);
    Console.Write("Created instance of {0}", t.ToString());

When I compile the preceding code and run it, I get the following output:

Cannot create an instance of System.Collections.Generic.
Dictionary2[TKey,TValue] because Type.ContainsGenericParameters is true.

Cannot create an instance of DictionaryKey1[TValue] because

Created instance of DictionaryKey1[System.Guid]
Object type=DictionaryKey1[System.Guid].

As you see, Activator.CreateInstance method throws an ArgumentException when you ask to construct an instance of an type. In fact, the exception's string message indicates that the type contains some generic parameters.

In the output, you'll notice the type names ends with a backtick (`) followed by a number. The number indicates the type's arity, which indicates the number of type parameters required by type. For example, the Dictionary class has an arity of 2 because it requires types to be specified for TKey and TValue. The DictionaryString class has an arity of 1 which requires just one type to be specified for TValue.

I should also point out that the CLR allocates static fields inside the type object (discussed in Chapter 4, "Type Fundamentals"). So closed type has its own static fields. In other worlds, if List<T> defined any static, these fields are not shared between a List<DateTime> and a List<String>; each closed type has its own static fields. Also, if a generic type defines a static constructor (discussed in Chapter 8, "Methods"), that static constructor will execute once per closed type. Sometimes people define a static constructor, a generic type to ensure that the arguments meet certain criteria. For example, if you wanted to define a generic type that can be used only with enumerated types, you could do the following.

```
internal sealed class GenericTypeThatRequiresEnum<T> {
    static GenericTypeThatRequiresEnum() {
        if (!typeof(T).IsEnum)
            throw new ArgumentException("T must be an enumerated type");
    }
}
```
