Obviously, code can call this method as follows.

```
public static void Main() {
    // Displays "15"
    Console.WriteLine(Add(new Int32[] { 1, 2, 3, 4, 5 }));
}
```

It's clear that the array can easily be initialized with an arbitrary number of elements and then passed off to Add for processing. Although the preceding code would compile and work correctly, it is a little ugly. As developers, we would certainly prefer to have writing the call to Add as follows.

```
public static void Main() {
    // Displays "15"
    Console.WriteLine(Add(1, 2, 3, 4, 5));
}
```

You'll be happy to know we can do this because of the params keyword. The params keyword tells the compiler to allow an instance of the System.ParamArrayAttribute custom to the parameter.

When the C# compiler detects a call to a method, the compiler checks of all the methods with the specified name, where no parameter has the ParamArray attribute applied. If a method exists that can accept the call, the compiler generates the code has necessary to call the method. However, if the compiler can't find a match, it looks for methods that have a ParamArray attribute to see whether the call can be satisfied. If the compiler finds a match, it emits code that constructs an array and populates its elements before emitting the code calls the selected method.

In the previous example, no Add method defines that five Int32-compatible arguments; however, the compiler generates a call to Add that is passed as a list of Int32 values and there is an Add method whose array-of-Int32 parameter is marked with the Param-Array attribute. The compiler considers this and generates code that coerces the parameters into an Int32 array and then calls the Add method. The end result is that you can write the code, easily passing a bunch of parameters to Add, but the compiler generates code as though you'd written the first version that explicitly constructs and initializes the array.

Only the last parameter to a method can be marked with the params keyword (Array-Attribute). This parameter must also identify a single-dimension array of any type. It's legal to pass null or a reference to an array of 0 entries as the last parameter to the method. The following call to Add performs fine, runs and and produces a resulting sum of 0 (as expected).

```
public static void Main() {
    // Both of these lines display "0"
    Console.WriteLine(Add()); // passes new Int32[0] to Add
    Console.WriteLine(Add(null)); // passes null to Add: more efficient (no array allocated)
}
```
