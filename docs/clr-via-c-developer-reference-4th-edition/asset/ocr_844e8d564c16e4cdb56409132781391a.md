will call the MultiWebRequests::ComputeResult method. This method processes the bytes returned from the server (or any error that may have occurred) and saves the result in the dictionary collection. After storing each result, AsyncCoordinator::JustEnded method is called to let the AsyncCoordinator know that an operation completed.

If all the operations have completed, the AsyncCoordinator will invoke the AllDone method to process the results from all web servers. The code executing the AllDone method will be the thread pool that just happened to be the last server response. If timeout or cancellation occurs, then AllDone will be invoked via whatever thread notifies the AsyncCoordinator of timeout or whatever thread happened to the Cancel method. There is also a chance that the thread issuing the web server requests could invoke AllDone itself if the last request completes before AllBegun.

Note that there is a race because it is possible that all web server requests complete, AllBegun is called all at once, and Cancel is called at the exact same time. If this happens, the AsyncCoordinator will select a winner and three losers, ensuring that the AllDone method is never called more than once. The winner is identified by the status argument passed into AllDone, which can be one of the symbols defined by the CoordinationStatus type.
