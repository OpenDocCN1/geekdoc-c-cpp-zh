The GetObjectData method works just like the ISerializable interface's GetObject-Data method. The only difference is that ISerializationSurrogate's GetDataObject method takes one additional parameter: a reference to the "real" object that is to be serialized. In the GetObjectData method above, this object is cast to DateTime, the value is converted from local time to universal time, and a string (formatted using universal date/time pattern) is added to the SerializationInfo collection.

The SetDataObject method is called in order to deserialize a DateTime object. When this is called, it is passed a reference to a SerializationInfo object. SetObjectData gets the string out of the collection, parses it as a full date/time formatted string, and then converts the resulting DateTime object from universal time to the machine's local time.

The Object that is passed for SetDataObject's first parameter is a bit string. Before just calling SetDataObject, the formatter (via Formatter's static GetUninitialized-Object method) finds an instance of the type that the surrogate is. The instance's fields are all/null and no constructor has been called on the object. The code inside SetDataObject can simply initialize the fields of this instance using the values from the passed-in Serialization-Info object and then have return null. Alternatively, SetDataObject could create an entirely different object or even a different type of object and return a reference to this object, in which case the formatter ignores any changes that may or may not have happened the object passed in to SetDataObject.

In my example, myUniversalLocalSerializationSurrogate class acts as a surrogate for the DateTime type, which is a value type. And so, the obj parameter refers to a boxed instance of DateTime. There is no way to change the fields in most value types (because they are supposed to be immutable) and so, my SetDataObject method ignores the object and returns a new DateTime object with the desired value in it.

At this point, I'm sure you are wondering how the formatter knows to use this ISerializationSurrogate type when it tries to serialize/deserialize a DateTime object. The following code demonstrates how to use the UniversalLocalSerializationSurrogate class.

```
private static void SerializationSurrogateDemo() {
    using (var stream = new MemoryStream()) {
        // 1. Construct the desired formatter
        IFormatter formatter = new SoapFormatter();

        // 2. Construct a SurrogateSelector object
        SurrogateSelector ss = new SurrogateSelector();

        // 3. Tell the surrogate selector to use our surrogate for DateTime objects
        ss.AddSurrogate(typeof(DateTime), formatter.Context, new UniversalLocalSerializationSurrogate());

        // NOTE: AddSurrogate can be called multiple times to register multiple surrogates

        // 4. Tell the formatter to use our surrogate selector
        formatter.SurrogateSelector = ss;
}
```
