In the preceding code, you can tell that an async function, as I specified async on the first line after static. When you mark a method async, the compiler transforms your method's code into a task that implements a state machine (the details of which are discussed in the next section). This allows to execute some code in the state machine and then return without having the method execute all the way to completion. So, when a thread calls ClientRequestAsync, the thread constructs a NamedPipeClient-Stream, calls Connect, sets its ReadMode property, converts the passed-in message to a Byte[] and then calls WriteAsync. WriteAsync internally allocates a Task and returns it back to ClientRequestAsync. At this point, the await operator continues With the Task passing in the method that resumes the state machine, and then returns from ClientRequestAsync.

Sometimes in the future, the network device driver will write the data to the pipe and then, a thread pool will notify the Task object, which will activate the WithCallback method, causing a thread to resume the state machine. More specifically, a thread will reenter the ClientRequestAsync method but at the point of the await operator. It executes compiler-generated code that queries the status of the Task object. If the operation failed, an exception representing the failure is thrown. If the operation completes successfully, the await operator returns the result. In this case, WriteAsync returns a Task instead of a Task<Result>.

Now, our method continues by allocating a Byte[] and then calls NamedPipeClient-Stream's asynchronous ReadAsync method. Internally, ReadAsync creates a Task<Int32> object and returns it. Again, the await operator continues WithOn the Task<Int32> object and resumes the state machine. And then returns from ClientRequestAsync.

Sometimes in the future, the server will send a response back to the client manager, the network device driver gets this response, and a thread pool notifies the Task<Int32> object, which will resume the state machine. The await operator calls the compiler to generate code that queries the Task object's Result property (an Int32) and assigns the result to the bytesRead local variable or others if an exception was failed. Then, the rest of the code in ClientRequestAsync executes, returning the result string and closing the pipe. At this point, the state machine has run to completion and the garbage collector will reclaim any memory it needed.
