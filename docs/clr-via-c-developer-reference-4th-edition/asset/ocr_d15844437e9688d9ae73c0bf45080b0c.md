In addition, there are overloads of the For and Each methods that let pass three
delegates:

+   The local initialization delegate (localInit) is invoked once for each task participating in
t work. This delegate is invoked before the task is asked to process a work item.

+   The body delegate (body) is invoked once for each task being processed by the various
threads participating in the work.

+   The local finally delegate (localFinally) is invoked once for each task participating in
work. This delegate is invoked after the task has processed all the work items that wille dispatched to it. It is even invoked if the body delegate code experiences an unhandled
exception.

Here is some sample code that demonstrates the use of the three delegates by adding up the
 for files contained within a directory.

```
private static Int64 DirectoryBytes(String path, String searchPattern,
SearchOption) {
 var files = Directory.EnumerateFiles(path, searchPattern, searchOption);
Int64 masterTotal = 0;

ParallelLoopResult result = Parallel.ForEach<String, Int64>(
iles,
() => // localInit: Invoked once per task at start
 // Initialize that this task has seen 0 bytes
 return 0; // Set localTotal initial value to 0
},

(file, loopState, index, taskTotal) => { // body: Invoked once per work item
 // Get this file's size and add it to this task's running total
Int64 contentLength = 0;
FileStream fs = null;
try {
 fs = File.OpenRead(file);
 contentLength = fs.Length;
 } catch (IOException exception) { /* Ignore any files we can't access */ }
 finally { if (fs != null) fs.Dispose(); }
 return taskLocalTotal + contentLength;
},

taskLocalTotal => { // localFinally: Invoked once per task at end
 // Atomically add this task's total to the "master" total
Interlocked.Add(ref masterTotal, taskTotal);
});

return masterTotal;
```
