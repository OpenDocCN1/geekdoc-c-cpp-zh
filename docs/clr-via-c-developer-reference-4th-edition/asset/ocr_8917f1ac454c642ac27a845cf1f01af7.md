Like anonymous types, after a Tuple is created, it is immutable (all properties are read-only). I don't show it here, the Tuple classes also offer CompareTo, Equals, GetHashCode, and ToToString methods, as well as a Size property. In addition, the Tuple types implement the IStructural-Equatable, IStructuralComparable, and IComparable interfaces so that you can compare Tuple objects with each other to see how their fields compare with other. Refer to the SDK documentation to learn more about these methods and interfaces.

Here is an example of how that uses a Tuple to return two pieces of information to a caller.

```
// Returns minimum in Item1 & maximum in Item2
private static Tuple<Int32, Int32> MinMax(Int32 a, Int32 b) {
    return new Tuple<Int32, Int32>(Math.Min(a, b), Math.Max(a, b));
}
```

```
// This shows how to call the method and how the returned Tuple is
private static void TupleTypes() {
    var min = MinMax(6, 2);
    Console.WriteLine("Min={0}, Max={1}", min.Item1, min.Item2); // Min=2, Max=6
}
```

Of course, it is important that the producer and consumer of the Tuple have a clear understanding of what is returned in the Item2 properties. With anonymous types, the properties are given actual names from the source code that defines the anonymous type. With Tuple types, the properties are assigned the Item# name by Microsoft and you cannot change this at all. Unfortunately, these names have no real meaning or significance, so it is up to the producer and consumer to assign meanings to them. This also requires comments to your code explaining the producer/consumer understanding is.

The compiler can only infer generic types when calling a generic method, not when calling a constructor. For this reason, the System namespace includes a non-generic, static Tuple class containing a bunch of static methods that can infer generic types from arguments. This class acts as a factory for creating Tuple objects, and it exists to simplify your code. Here is a rewrite of the MinMax method shown earlier using the static Tuple class.

```
// Returns minimum in Item1 & maximum in Item2
private static Tuple<Int32, Int32> MinMax(Int32 a, Int32 b) {
    return Tuple.Create(Math.Min(a, b), Math.Max(a, b)); // Simpler syntax
}
```

If you want to create a Tuple with more than six elements, then you would need to pass Tuple for the rest parameter as follows:

```
var t = Tuple.Create(0, 1, 2, 3, 4, 5, 6, Tuple.Create(7, 8));
Console.WriteLine("{0}, {1}, {2}, {3}, {4}, {5}, {6}, {7}, {8}",
t.Item1, t.Item2, t.Item3, t.Item4, t.Item5, t.Item6, t.Item7,
t.Rest.Item1, t.Rest.Item1, t.Rest.Item2);
```
