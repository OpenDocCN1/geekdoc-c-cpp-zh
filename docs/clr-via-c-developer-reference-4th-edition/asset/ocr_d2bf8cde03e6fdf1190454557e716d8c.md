In addition to switches, the C# compiler supports the /t[arget]:module switch. This switch tells the compiler to produce a PE file that doesn't contain the metadata tables. The PE file produced is always a DLL file, and this file must be added to an assembly before the CLR can access types within it. When you use the /t:module switch, the C# compiler, by default, names the output file with an extension of .netmodule

> Unfortunately, the Microsoft Visual Studio integrated development environment (IDE) doesn't natively support the ability to create multifile assemblies. If you want to create multifile assemblies, you must resort to using command-line tools.

There are many ways to add a module to an assembly. If you're using the C# compiler to build a PE file with a manifest, you can use the /module switch. To understand how to build a multifile assembly, let's assume that we have two source code files:

+   - RUT.cs, which contains rarely used types
- FUT.cs, which contains frequently used types

Let's compile the rarely used into their own module so that users of the assembly won't need to deploy this module if they never access the used types.

```
csc /t:module RUT.cs
```

This line causes the C# compiler to create a RUT.netmodule file. This file is a standard DLL file, but by itself, the CLR can't load it.

Next let's compile the frequently used into their own module. We'll make this module the keeper of the assembly's manifest because the types are so often. In fact, because this module will now represent the entire assembly, I'll change the name of the output file to MultiFileLibrary.dll instead of calling RUT.dll.

```
csc /out:MultiFileLibrary.dll /t:library /addmodule:RUT.netmodule FUT.cs
```

This line tells the C# compiler to compile the FUT.cs to produce the MultiFileLibrary.dll because /t:library is specified, a DLL file containing the manifest tables is emitted into the MultiFileLibrary.dll file. The /module:RUT.netmodule switch tells the compiler that RUT.netmodule is a file that should be considered part of the assembly. Specifically, the /module switch tells the compiler to add the FileDef metadata table and to add RUT.module's exported types to the ExportedTypesDef metadata table.
