For those scenarios in which this algorithm is insufficient, MulticastDelegate class offers an instance method, GetInvocationList, which you can use to call each delegate in a chain explicitly, using any algorithm that meets your needs.

```
public abstract class MulticastDelegate : Delegate {
    // Creates a delegate array where each element refers
    // to a delegate in the chain.
    public sealed override Delegate[] GetInvocationList();
}
```

The GetInvocationList method operates on a MulticastDelegate-derived object and returns an array of delegates where each reference points to one of the chain's delegates. Internally, GetInvocationList constructs an array and initializes it with each element referring to a delegate in the chain; reference to the array is then returned. If the _invocation field is null, the returned array contains one element that references the only delegate in the chain: the delegate instance itself.
