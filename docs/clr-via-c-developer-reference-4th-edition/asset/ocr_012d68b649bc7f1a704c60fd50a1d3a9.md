```
for (Int32 a = 0, a < appointments.Length; a++) {
  // Do something with appointments[a]

```

If you design your methods to return arrays with zero element instead of null, callers of your methods will have an easier time working with them. By the way, you should do the same for fields. If your type has a field's a reference to an array, you should consider having the field refer to an array even if it has no elements in it.

# # Creating Non-Zero Bound Arrays

I mentioned that it's possible to create and work with arrays that have non-zero lower bounds. You can dynamically create your own arrays by calling Array.static CreateInstance method. Overloads of this method exist, allowing you to specify the type of elements in the array, the number of dimensions in the array, the lower bounds of each dimension, and the number of elements in each dimension. CreateInstance allocates memory for the array, saves the parameter information in the overhead portion of the array's memory block, and returns a reference to the array. If the array has two or more dimensions, you can cast the reference returned from CreateInstance to an ElementType[](where ElementType is some type), making it easier for you to access the elements in the array. If the array has one dimension, in C#, you have to use Array-GetValue and SetValue to access the elements of the array.

Here some code demonstrates how to dynamically create a two-dimensional array of System.Decimal values The first dimension represents years from 2005 to 2009 includes, and the second dimension represents quarters from 1 to 4. The code iterates over all the elements in the dynamic array. I could have hardcoded the array's bounds into the code, which would have given better performance, but I decided to use System.Array.GetLowerBound and GetUpperBound methods to demonstrate their use.

using System;

```
public static class DynamicArrays {
  public static void Main() {
    // I a two-dimensional array [2005..2009][1..4]
    Int32[] lowerBounds = { 2005, 1 };
    Int32[] lengths = { 5, 4 };
    Decimal[,] quarterlyRevenue = new Decimal[,];
    Array.CreateInstance(typeof(Decimal), lengths, lowerBounds);

    Console.WriteLine("{0,4} {1,9} {2,9} {3,9} {4,9}", "Year","Q1","Q2","Q3","Q4");
    Int32 firstYear = quarterlyRevenue.GetLowerBound(0);
    Int32 firstQuarter = quarterlyRevenue.GetLowerBound(1);
    Int32 lastQuarter = quarterlyRevenue.GetUpperBound(1);
  }
}
```
