However, there is another tool, the Code Contract Checker (CCCCheck.exe), which analyzes the C# compiler in an attempt to statically verify that no code in the method violates a contract. This tool will attempt to prove that any condition to Assert is true, but it will just assume that any condition to Assume is true and the tool will change the expression to its body of facts known to be. Usually, you will use Assert and then change an Assert to Assume if the CCCCheck.exe tool can't statically prove that the expression is true.

Let's walk through an example. Assume that I have the following type of definition.

```
internal sealed class SomeType {
    private static String s_name = "Jeffrey";
}
```

```
public static void ShowFirstLetter() {
    Console.WriteLine(s_name[0]); // warning: requires unproven: index < this.Length
}
```

When I build this code with the Perform Static Contract Checking turned on, the CCCCheck.exe tool produces the warning shown as a comment in the preceding code. This warning is notifying me that querying the first letter of s_name may fail and throw an exception because it is unproven that s_name always refers to a string consisting of at least one character.

Therefore, we might like to add an assertion to the ShowFirstLetter method.

```
public static void ShowFirstLetter() {
    Contract.Assert(s_name.Length >= 1); // warning: assert unproven
    Console.WriteLine(s_name[0]);
}
```

Unfortunately, when the CCCCheck.exe tool analyzes this code, it is still unable to validate that s_name refers to a string containing at least one letter, so the tools produce a similar warning. Sometimes the tool is unable to validate assertions due to limitations in the tool; future versions of the tool will be able to perform a more complete analysis.

To override shortcomings in the tool or to claim that something is true that the tool would never be able to prove, we can change Assert to Assume. If we know for a fact that no other code will modify s_name, we can change ShowFirstLetter to.

```
public static void ShowFirstLetter() {
    Contract.Assume(s_name.Length >= 1); // No warning at all now!
    Console.WriteLine(s_name[0]);
}
```

With this version of the code, the CCCCheck.exe tool just takes our word for it and concludes that s_name always refers to a string containing at least one letter. This version of the ShowFirstLetter method passes the code static contract checker without any warnings at all.
