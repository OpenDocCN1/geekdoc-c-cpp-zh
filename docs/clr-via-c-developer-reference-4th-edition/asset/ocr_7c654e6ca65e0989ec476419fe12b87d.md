If a Finalize method throws an unhandled exception, then the process terminates; there is no way to catch this exception.

As, as you can see, there is a lot of cates related to Finalize methods and they must be used with caution. Specifically, they are designed for releasing native resources. It is highly recommended that developers avoid overiding Object's Finalize method; in-stead, use helper classes that Microsoft now provides in the Framework Class Library (FCL). The helper classes override Finalize and some special CLR magic I'll talk about as we go. You will derive your own classes from the helper classes and inherit the CLR magic.
