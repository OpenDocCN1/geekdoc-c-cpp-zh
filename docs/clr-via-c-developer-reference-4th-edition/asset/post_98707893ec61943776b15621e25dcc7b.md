The following C# code demonstrates three techniques (safe, jagged, and unsafe), for accessing
a two-dimensional array.

```csharp
using System;
using System.Diagnostics;

public static class Program {
    private const Int32 numElements = 10000;

    public static void Main() {
    // Declare a two-dimensional array
    Int32[,] aDim = new Int32[numElements, numElements];

    // Declare a two-dimensional array as a jagged array (a vector of vectors)
    Int32[][] jagged = new Int32[numElements][];
    for (Int32 x = 0; x < numElements; x++)
        jagged[x] = new Int32[numElements];

    // 1: Access all elements of the array using the usual, safe technique
    SafeDimArrayAccess(aDim);

    // 2: Access all elements of the array using the jagged technique
    SafeJaggedArrayAccess(jagged);

    // 3: Access all elements of the array using the unsafe technique
    UnsafeDimArrayAccess(aDim);
}}

    private static Int32 SafeDimArrayAccess(Int32[,] a) {
        Int32 sum = 0;
        for (Int32 x = 0; x < numElements; x++) {
            for (Int32 y = 0; y < numElements; y++) {
                sum += a[x, y];
            }
        }
        return sum;
    }

    private static Int32 SafeJaggedArrayAccess(Int32[][] a) {
        Int32 sum = 0;
        for (Int32 x = 0; x < numElements; x++) {
            for (Int32 y = 0; y < numElements; y++) {
                sum += a[x][y];
            }
        }
        return sum;
    }

    private static unsafe Int32 UnsafeDimArrayAccess(Int32[,] a) {
        Int32 sum = 0;
        fixed (Int32* pi = a) {
            for (Int32 x = 0; x < numElements; x++) {
                Int32* baseOfDim = pi + x * numElements;
                for (Int32 y = 0; y < numElements; y++) {
                    sum += pi[baseOfDim + y];
                }
            }
        }
        return sum;
    }
```

The UnsafeDimArrayAccess method is marked with the unsafe modifier, which is required
to use C#'s fixed statement. To compile this code, you'll have to specify the /unsafe switch when
oking the C# compiler or select the Allow Unsafe Code checkbox on the Build tab of the Project
Properties pane in Visual Studio.

Obviously, the unsafe technique has a time and place when it can be used by your own code,
and there are three serious downsides to using this technique:

- The code that manipulates the unsafe array elements is more complicated to read and write when
which manipulates the elements using the other techniques because you are using C#'s fixed
statement and performing memory-address calculations.

- If you make a mistake in the calculation, you are accessing memory that is not part of the array. This can result in an incorrect calculation, corruption of memory, a type-safety violation, and a potential security hole.

- Due to the potential problems, the CLR forbids unsafe code from running in reduced-security
environments (like Microsoft Silverlight).
