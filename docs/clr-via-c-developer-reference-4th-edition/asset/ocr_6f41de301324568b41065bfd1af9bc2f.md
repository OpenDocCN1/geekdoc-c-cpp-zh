# Parameterized Properties

In the previous section, the get accessor methods for the properties accepted no parameters. For this reason, I called these parameterless properties. These properties are easy to understand because they have the feeling of accessing a field. In addition to these field-like properties, programming languages also support what I call parameterized properties, whose get accessor methods accept one or more parameters and whose setter methods accept two or more parameters. Different programming languages expose masterful properties in different ways. Also, languages use different terms to refer to them: C# calls them indexers and Visual Basic call them default properties. In this section, I will focus on C# exposes its indexes by using parameterized properties.

In C#, parameterized properties (indexers) are exposed using an array-like syntax. In other words, you can think of an indexer as a way for the C# developer to overload the [] operator.
