And the ExceptionArgs class that TExceptionArgs is constrained to is very simple and looks like this.

```
[Serializable]
public abstract class ExceptionArgs {
```

Now, with these classes defined, I can trivially define more exception classes when I need to. To define an exception type indicating the disk is full, I simply do the following.

```
[Serializable]
public sealed class DiskFullExceptionArgs : ExceptionArgs {
    private readonly String m_diskpath; // private field set at construction

    public DiskFullExceptionArgs(String diskpath) { m_diskpath = diskpath; }

    // Read-only property that returns the field
    public String DiskPath { return m_diskpath; }

    // Override the Message property to include my field (if set)
    public override String Message {
        return (m_diskpath == null) ? base.Message : "DiskPath=" + m_diskpath;
    }
}
```
