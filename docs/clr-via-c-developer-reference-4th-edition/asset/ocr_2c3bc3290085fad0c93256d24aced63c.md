Object-oriented programming allows developers to be very productive. A big part of this is com-
posability which makes it easy to write, read and maintain code. This line of code, for example:

There is a assumption being made with the preceding code: no errors occur. But, of course,

handling constructs and mechanisms are all about and why we need them as opposed to having
methods that return true/false or an HRESULT to indicate success/failure the way that Win32
COM functions do.
