# Passing Parameters by Reference to a Method

By default, the common language runtime (CLR) assumes that all method parameters are passed by value. When reference type objects are passed, the reference (or pointer) to the object is passed (by value) to the method. This means that the method can modify the object and the caller will see the change. For value instances, a copy of the instance is passed to the method. This means that the method gets its own private copy of the value type and the instance in the caller is not affected.

> **Important** In a method, you must know whether each parameter passed is a reference type or a value type because the code you write to manipulate the parameter could be markedly different.

The CLR allows you to pass parameters by reference instead of value. In C#, you can do this by using the out and ref keywords. Keywords tell the C# compiler to emit metadata indicating that the designated parameter is passed by reference, and the compiler uses this code to pass the address of the parameter rather than the parameter itself.

From the CLR's perspective, out and ref are identical—that is, the IL produced regardless of which keyword you use, and the metadata is also identical for 1 bit, which is used to record whether you specified out or ref when declaring the method. However, the C# compiler treats the two differently, and the difference is how to do with which method is responsible for initializing the object being referred to. If a method is marked with out, the caller isn't expected to initialize the object prior to calling the method. The called method can't read the value, and the called method must write to the value before returning. If a method's parameter is marked with ref, the caller must initialize the value prior to calling the method. The called method can read the value and/or write to the value.

Reference and value types behave very differently with out and ref. Let's look at using out and ref with value types.

```cs
public sealed class Program {
    public static void Main() {
        Int32 x;
        GetVal(out x); // x is initialized.
        Console.WriteLine(x); // Displays 10
}

private static void GetVal(out Int32 v) {
    v = 10; // This method must write to the value
}
```
