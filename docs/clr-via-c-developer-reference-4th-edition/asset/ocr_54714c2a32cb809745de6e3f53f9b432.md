Note If you just need to make a copy of some array elements to another array. System.Buffer's BlockCopy method executes faster than Array's Copy method. However, Buffer's BlockCopy supports only primitive types; it does not offer the same casting abilities as Array's Copy method. The Int32 parameters are expressed as byte offsets within the array, not element indices. BlockCopy is really designed for copying data that is bitwise-compatible from one array to another bitable array type, such as copying Byte[] containing Unicode characters (in the proper byte order) to Char[ This allows programmers to partially make up for the lack of the ability to treat an array as a block of memory of any type.

If you need to reliably copy a set of array elements from one array to another array, you should use System.Array.ConstrainedCopy method. This method guarantees that the copy operation will either complete or throw an exception without destroying any data within the destination array. This allows ConstrainedCopy to be used in a constrained region (CER). In order to offer this guarantee, ConstrainedCopy requires that the source array's element type be the same as derived from the destination array's element type. In addition, it will not perform any boxing, unboxing, or downcasting.

# All Arrays Are Implicitly Derived from System.Array

When you declare an array variable like this:

```
FileStream[] fsArray;
```

the CLR automatically creates a FileStream[] type for the AppDomain. This type will be derived from the System.Array type, and therefore, all of the instance methods and properties defined on the System.Array will be inherited by the FileStream[] type, allowing these methods and properties to be called using the fsArray variable. This makes working with arrays extremely convenient because there are many instance methods and properties defined by System.Array, such as Clone, CopyTo, GetLength, GetGetLength, GetLowerBound, GetUpperBound, Rank, and others.

The System.Array exposes a large number of extremely useful static methods that operate on arrays. All methods take a reference to an array as a parameter. Some of the static methods are AsReadOnly, BinarySearch, Clear, ConstrainedCopy, ConvertAll, Exists, Find, FindAll, FindIndex, FindLast, FindIndexOf, ForEach, IndexOf, LastIndexOf, Resize, Reverse, Sort, and TrueForAll. There are many overloads for each of these methods. In fact, many of the methods provide generic overloads for compile-time safety as well as good performance. I encourage you to examine the SDK documentation to get an understanding of how useful and powerful these methods are.
