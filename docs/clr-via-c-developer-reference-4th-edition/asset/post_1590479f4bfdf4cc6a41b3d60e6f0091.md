When you're building extensible applications, interfaces should be the centerpiece. You could use a base class instead of an interface, but in general, an interface is preferred because it allows add-in developers to choose their own base class. Here's the way to Host SDK assembly:

When defining the parameters and return types for the interface methods, try to use other interfaces or types defined in MSCorLib.dll.
