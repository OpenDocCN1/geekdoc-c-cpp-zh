## Optional and Named Parameters

When designing method's parameters, you can assign default values to some of or all the parameters. Then, code that calls these methods can optionally not specify some of the arguments, thereby accepting the default values. In addition, when you call a method, you can specify arguments by using the name of their parameters. Here is some code that demonstrates using both optional and named parameters.

```csharp
public static class Program {
    private static Int32 s_n = 0;

    private static void M(Int32 x = 9, String s = "A",
        DateTime dt = default(DateTime), Guid guid = new Guid()) {
        Console.WriteLine("x={0}, s={1}, dt={2}, guid={3}", x, s, dt, guid);
    }

    public static void Main() {
        // 1. Same as M(9, "A", default(DateTime), new Guid());
        M();

        // 2. Same as M(8, "X", default(DateTime), new Guid());
        M(8, "X");

        // 3. Same as M(5, "A", DateTime.Now, Guid.NewGuid());
        M(5, guid: Guid.NewGuid(), dt: DateTime.Now);

        // 4. Same as: M(o, "1", default(DateTime), new Guid());
        M(s_n++, s_n.ToString());

        // 5. Same as: t1 = "2"; Int32 t2 = 3;
        //
        M(t2, t1, default(DateTime), new Guid());
        M(s: (s_n++).ToString(), x: s_n++);
    }
}
```
