In the first example, the unboxed Point, p is cast to an IChangeBoxedPoint. This case changes the
value in p to be boxed. Change is called on the boxed value, which changes its m_x and m_y fields
to 4 and 4, but after Change returns, the boxed object is immediately ready to be garbage collected.
The fifth call to WriteLine displays (2, 2). Many developers won't expect this result.

In the last example, the boxed Point referred to by o is cast to an IChangeBoxedPoint. No-
is necessary because o is already a boxed Point. Then Change is called, which changes
the Point's m_x and m_y fields. The interface method allows me to modify the
fields in a boxed Point! Now, when WriteLine is called, it displays (5, 5) as expected. The
purpose of this example is to demonstrate how an interface method is allow to modify the fields
of a boxed type. In C#, this isn't possible without using an interface.
