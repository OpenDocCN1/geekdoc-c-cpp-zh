In this case, the StructLayout attribute is applied to the OVERSVERSION info, the MarshalAs is applied to the CSDVersion field, the DllImport attribute is applied to the GetVersionMethod, and the In and Out attributes are applied to GetVersionEx ver. Every programming language defines the syntax a developer must use in order to apply a custom attribute to a target. Microsoft Basic .NET, for example, requires angle brackets (<, >) instead of square brackets.

The CLR allows attributes to be applied to just anything that can be represented in a file metadata. Most commonly, attributes are applied to entries in the following definition tables: TypeDef(classes, enumerations, interfaces, and delegates), MethodDef(including constructors), ParamDef, FieldDef, PropertyDef, EventDef, AssembleDef, and ModuleDef. Specifically, C# allows you to apply an attribute only to source code that defines any of the following assemblies: assembly, module, type (class, struct, enum, interface, delegate), field, method (including constructors), method parameter, return value, property, and generic type parameter.

When you're applying an attribute, C# allows you to specify a prefix specifically indicating the target attribute applies to. The following code shows all of the possible prefixes. In many cases, if you leave out the prefix, the compiler can still determine the target attribute applies to, as shown in the previous example. In some cases, the prefix must be specified to make your intentions clear to the compiler. The prefixes shown italics are mandatory.

```
[assembly: SomeAttr // Applied to assembly
[module: SomeAttr] // Applied to module
```
