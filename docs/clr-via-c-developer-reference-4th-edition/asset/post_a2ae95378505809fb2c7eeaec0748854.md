
## Formatting Objects into a Single String

So far, I've explained how an individual format owns its own object. At times, however, you want to construct strings consisting of many formatted objects. For example, the following string has a date, a person's name, and an age.

```cs
String s = String.Format("On {0}, {1} is {2} years old.",
new DateTime(2012, 4, 22, 14, 35, 5), "Aidan", 9);
Console.WriteLine(s);
```

If you build and run this code "en-US" is the thread's current culture, you'll see the following line of output.

On 4/22/2012 2:35:00 PM, Aidan is 9 years old.

String's static Format method takes a string that identifies replaceable parameters by using numbers in braces. The format used in this example tells the Format method to replace {0} with the first parameter after the string (date/time), replace {1} with the second parameter after the string ("Aidan"), and replace {2} with the third parameter after the string (7).

Internally, the Format method calls each object's ToString method to obtain a string representation for the object. The returned strings are all aligned and the complete, final string is returned. It is all fine and good, but it means that all of the objects are formatted using your general formatting and calling the thread's culture information.

You can have more over formatting when you specify format information within braces. For example, the following code is identical to the previous example except that I've added formatting information to replaceable parameters 0 and 2.

```cs
String s = String.Format("On {0:D}, {1} is {2:E} years old.",
new DateTime(2012, 4, 22, 14, 35, 5), "Aidan", 9);
Console.WriteLine(s);
```

If you build and run this code "en-US" is the thread's current culture, you'll see the following line of output.

On Sunday, April 22, 2012, Aidan is 9.00000E+000 years old.

When the Format method parses the string, it sees that replaceable parameter 0 should have its IFormable object's ToString method called "D" and null for its parameters. Likewise, Format calls replaceable parameter 2's IFormable ToString method, passing "E" and null. If the type doesn't implement the IFormable interface, Format calls its IFormable ToString inherited from Object (possibly overridden), and the default format is appended to the resulting string.

The String class offers several overloads of the static Format method. One version takes an object that implements the IFormatProvider interface so that you can format all of the parameters by calling-specific culture information. Obviously, Format calls each object's IFormable.ToString method, passing whatever IFormatProvider object was passed to Format.

If you’re using StringBuilder instead of String to construct a string, you can call StringBuilder’s AppendFormat method. This method works exactly as String’s Format except that it formats a string and appends to the StringBuilder’s character array. Does String’s Format, AppendFormat takes a string, and there’s a version that takes an IFormatProvider.

System.Console offers Write and WriteLine methods that also format strings and parameters. However, there are no overloads of Console.write and WriteLine methods allow you to pass an IFormatProvider. If you want to format a string for a specific culture, you have to call String Format method, first passing the desired IFormatProvider object and then passing the resulting string to Console.Write or WriteLine. This shouldn't be a big deal because, as I said earlier, it's rare for client-side code to format a string by using a culture than the one associated with the calling thread.

## Providing Your Custom Formatter

By now it shows that the formatting capabilities in the .NET Framework were designed to offer you a deal of flexibility and control. However, we're not finished. It's possible for you to define a method that StringBuilder AppendFormat will call whenever any object is being formatted into a string. In other words, instead of calling ToString for each object, AppendFormat can call a function you define, allowing you to format any or all of the objects in any way you want. What I'm about to describe also works with String's Format method.

Let me explain this mechanism by way of example. Let's say that you're formatting HTML text that a user will view.

```cs
using System;
using System.Text;
using System.Threading;

public class Program
{
    public static void Main()
    {
        StringBuilder sb = new StringBuilder();
        sb.AppendFormat("<b>{0}</b>: {1}", "Date", DateTime.Now);
        Console.WriteLine(sb.ToString());
    }
}

internal sealed class Bold32 : IFormatProvider
{
    public string Format(string format, object arg, IFormatProvider formatProvider)
    {
        string s = null;
        if (formatProvider != null)
        {
            s = formatProvider.Format(format, arg);
        }
        if (s == null)
        {
            IFormable formable = arg as IFormable;
            if (formable != null)
            {
                s = formable.ToString(format, formatProvider);
            }
            else
            {
                if (arg != null)
                    s = arg.ToString();
                else
                    s = string.Empty;
            }
        }
        return "<b>" + s + "</b>";
    }

    public object GetFormat(Type format)
    {
        if (format == typeof(IFormatProvider))
        {
            return this;
        }
        return null;
    }
}
```
