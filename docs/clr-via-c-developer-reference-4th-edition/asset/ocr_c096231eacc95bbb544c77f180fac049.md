Although the compiler allows you to omit the explicit cast when casting dynamic to some other type, the CLR will validate the cast at run time to ensure that type is maintained. If the object's type is not compatible with the cast, the CLR will throw an InvalidCastException exception.

Note that the result of evaluating a dynamic expression is a dynamic expression. Examine this

```
dynamic d = 123;
var result = M(d); // Note: 'var result' is the same as 'dynamic result'
```

Here, the compiler allows the code to compile dynamic because it doesn't know at time which M will call. Therefore, it also not know what type of M will return. and the compiler assumes that the result is variable of dynamic type itself. You can verify this by placing your mouse over var in the Visual Studio editor; the IntelliSense window will indicate 'dynamic Represents an object whose operations will be resolved at runtime.' If the method invoked by var has a return type of void, a Microsoft.CSharp.RuntimeBinder.BinderException is thrown.

> **Important** not confuse dynamic and var. Declaring a local variable using var is just a syntactic shortcut that the compiler infer the specific data type from an expression. The var keyword can be used only for declaring local variables inside a method, whereas the dynamic keyword can be used for local variables, fields, and arguments. You cannot cast an expression to var but you can cast an expression to dynamic. You must explicitly initialize a variable declared using var, whereas you do not have to initialize a variable declared with dynamic. For more information about C#'s var, see the "Implicitly Typed Local Variables" in Chapter 9, "Parameters"

However, when converting dynamic to another static type, the result's type is, of course, the static type. Similarly, when constructing a type by passing one or more dynamic arguments to its constructor, the result is the type of object you are constructing.

```
dynamic d = 123;
var x = (Int32)d; // Conversion: 'var x' is the same as 'Int32 x'
var dt = new DateTime(d); // Construction: 'var dt' is the same as 'DateTime dt'
```

If a dynamic expression is specified as the collection in a foreach statement or as a resource in a using statement, the compiler will generate code that attempts to cast the expression to the non-generic System.IEnumerable interface or to the System.IDisposable interface, respectively. If the cast succeeds, the expression is used and the code runs just. If the cast fails, a Microsoft.CSharp.RuntimeBinder.BinderException exception is thrown.
