shown earlier. Here is what the TaskContinuationOptions looks like.

```
[Flags, Serializable]
public enum TaskContinuationOptions {
    None = 0x0000, // The default
```

```
// Hints to the TaskScheduler that you want this task to run sooner than later.
PreferFairness = 0x0001,
```

```
// Hints to the TaskScheduler that it should more agively create pool threads.
LongRunning = 0x0002,
```

```
// Always honored: Associates a Task with its parent Task (discussed shortly)
AttachedToParent = 0x0004,
```

```
// If a task attempts to attach to this parent task, an InvalidOperationException is thrown.
DenyChildAttach = 0x0008,
```

```
// Prevents completion of the continuation until the antecedent has completed.
LazyCancellation = 0x0020,
```

```
// This flag indicates you want the thread that executed the first task to also
execute the ContinueWith. If the first task has already completed, then the
thread calling ContinueWith will execute the ContinueWith.
ExecuteSynchronously = 0x80000,
```

```
// These flags indicate what circumstances to run ContinueWith
NotRanToCompletion = 0x10000,
NotFaulted = 0x20000,
NotCanceled = 0x40000,
```

```
// These flags are convenient combinations of the above three flags
OnlyCanceled = NotRanToCompletion | NotFaulted,
OnlyFaulted = NotRanToCompletion | NotCanceled,
OnlyRanToCompletion = NotFaulted,
```

When you call ContinueWith, you can indicate that want the new task to execute only if
t first task is completed by specifying the TaskContinuationOptions.OnlyCanceled flag. Similarly,
y have the new task execute only if the first task throws an unhandled exception using the Task-
inuationOptions.OnlyFaulted flag. And, of course, you can use the TaskContinuation-
Options.OnlyRanToCompletion flag to have the new task execute only if the first task runs all
the way to completion without being canceled or, then the new task will regardless of how the first task completes.
When a Task completes, any of its continue-tasks that do not run are automatically canceled.

```
// Create a task, continue with other tasks
Task-Int32 t = Task.Run(() => Sum(10000));
// Each ContinueWith returns a Task but you usually don't
```
