# Generic Types and Inheritance

A generic type is, and like that, can be derived from any other type. When you use a generic type and specify type arguments, you are defining a new type object in the CLR, and the new type object is derived from whatever the generic type was derived from. In other words, because List<T> is derived from Object, List<String> and List<Guid> are also derived from Object. Similarly, Dictionary<StringKey,Value> is derived from Dictionary<String, Value>, Dictionary<StringKey,Guid> is also derived from Dictionary<String, Guid>. Understanding that specifying type arguments doesnt nothing to do with inheritance hierarchies will help you to recognize what kind of class you can and can't

For example, if a linked-list class is defined like this:

```
internal sealed class Node<T> {
    public T m_data;
    public Node<T> m_next;

    public Node(T data) : this(data, null) {
}

    public Node(T data, Node<T> next) {
        m_data = data; m_next = next;
}

    public override String ToString() {
        return m_data.ToString() + ((m_next != null) ? m_next.ToString() : String.Empty);
    }
```

```
private static void SameDataLinkedList() {
    Node<Char> head = new Node<Char>('C');
    head = new Node<Char>('B', head);
    head = new Node<Char>('A', head);
    Console.WriteLine(head.ToString()); // Displays "ABC"
}
```
