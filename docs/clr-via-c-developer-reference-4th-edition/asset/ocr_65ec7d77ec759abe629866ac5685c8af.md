Dynamic languages, such as Python and Ruby, endow their types with DynamicMetaObject-derived types so that they can be accessed in a way appropriate for them when manipulated from other programming languages (like C#). Similarly, when accessing a COM component, the C# runtime binder is a DynamicMetaObject-derived type that knows how to communicate with a COM component. The DynamicMetaObject-derived type is defined in the System.Dynamic.dll assembly.

If the type of being used in the dynamic expression does not implement the IDynamic-MetaObjectProvider interface, then the C# compiler treats the object like instance of an ordinary C#-defined type and performs operations on the object using reflection.

One of the limitations of the dynamic variable is that you can only use it to access an object's instance members because you refer to it. But, there are occasions when it would be useful to dynamically invoke static members of a type where the type is determined at runtime. To accomplish this, I created a StaticMemberDynamicWrapper that derives from System.DynamicObject, which implements the IDynamicMetaObjectProvider interface. The class internally uses a bit of reflection (covered in Chapter 23, "Assembly Loading and Reflection"). Here is the code for my StaticMemberDynamicWrapper class.

```
internal class StaticMemberDynamicWrapper : DynamicObject {
    private readonly Type _type;
    public StaticMemberDynamicWrapper(Type type) { _type = type.GetType(); }

    public override IEnumerable<String> GetDynamicMemberNames() {
        return _type.DeclaredMembers.Select(mi => mi.Name);
    }

    public override Boolean TryGet(GetMemberBinder binder, out object result) {
        result = null;
        var field = GetField(binder.Name);
        if (field != null) { result = field.GetValue(null); } return true;

        var prop = GetProperty(binder.Name, false);
        if (prop != null) { result = prop.GetValue(null, null); } return true;
        return false;
    }

    public override Boolean TrySet(SetMemberBinder binder, object value) {
        var field = GetField(binder.Name);
        if (field != null) { field.SetValue(null, value); } return true;

        var prop = GetProperty(binder.Name, false);
        if (prop != null) { prop.SetValue(null, value, null); } return true;
        return false;
    }
```
