# # Thread Scheduling and Priorities

A preemptive operating system must use some kind of algorithm to determine which threads should be scheduled when and for how long. In this section, we'll look at the algorithm Windows uses. Earlier in this chapter, I mentioned how every kernel object contains a context structure. The context structure reflects the state of the thread's CPU registers when the thread executed. After a time-slice, Windows looks at all the kernel objects in existence. Of these objects, the threads that are not waiting for something are considered schedulable. Windows selects one of the schedulable kernel objects and context switches to it. Windows keeps a record of how many times each thread got context switched. You can see this using a tool like Microsoft Spy++. shows the properties for a thread. Notice that this thread has been scheduled 31,768 times.
