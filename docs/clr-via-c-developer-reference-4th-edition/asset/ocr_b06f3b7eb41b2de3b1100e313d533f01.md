In the BitArray example, the indexer takes one Int32 parameter, bitPos. All indexers must have at least one parameter, but they can have more. These parameters (as well as the return type) can be of any type (except void). An example of an indexer that has more than one parameter can be found in the System.Drawing.Imaging.ColorMatrix class, which ships in the System.Drawing.dll assembly.

It's quite common to create an indexer to look up values in an associative array. In fact, the System.Collections.Generic.Dictionary type offers an indexer that takes a key and returns the value associated with it. Unlike parameterless properties, a type can offer multiple, over-loaded indexers as long as their signatures differ.

Like a parameterless property's setter accessor method, an indexer's setter accessor method also contains a parameter, called value in C#. This parameter indicates the new value for the "indexed element."

The CLR doesn't differentiate parameterless properties and parameterful properties; to the CLR, each is simply a pair of methods and a pair of metadata defined within a type. As mentioned earlier, different programming languages require different syntax to use parameter properties. The fact that C requires[...] as the syntax for expressing an indexer was purely a choice made by the C# team. This choice means that C# allows indexers to be defined only on instances of objects. C# doesn't offer syntax allowing a developer to define a static index property, although the CLR does support static particular properties.

Because the CLR treats parameterful properties just as it does parameterless properties, the compiler will emit two or three of the following items into the resulting managed assembly:

+   - A method representing the parameterful property's get accessor method. This is emitted only if you define a get accessor method for the property.

+   - A method representing the parameterful property's setter accessor method. This is emitted only if you define a setter accessor method for the property.

+   - A property definition in the managed assembly's metadata, which is always emitted. There's no special parameterful property definition table, to the CLR, parameterful properties are just properties.

For the BitArray class defined earlier, the compiler compiles the indexer as though the original source code were written as:

```
public sealed class BitArray {

    // This is the indexer's get accessor method.
    public Boolean getItem(Int32 bitPos) { /* ... */ }

    // This is the indexer's setter accessor method.
    public void setItem(Int32 bitPos, Boolean value) { /* ... */ }
}
```
