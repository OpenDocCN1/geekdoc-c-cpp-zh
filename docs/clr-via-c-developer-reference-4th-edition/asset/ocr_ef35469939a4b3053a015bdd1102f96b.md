# CPU Trends

In the past, CPU speeds used to increase with time, so an application that ran slowly on one machine would typically run faster on a newer machine. However, CPU manufacturers are unable to continue the trend of making CPUs faster. When you run CPUs at high speeds, they produce a lot of heat that has to be dissipated. A few years ago, I acquired a newly released notebook computer from a respected manufacturer. This computer had a bug in its firmware that made it not turn the fan on enough; as a result, after running the computer for a while, the CPU and the motherboard melted. The hardware manufacturer replaced the machine and "improved" the firmware by making the fan run more frequently. Unfortunately, this had the effect of drawing the battery faster, fans consume a lot of power.

These are the kinds of problems that the hardware vendors face today. Because CPU manufacturers can't continuously produce higher-speed CPUs, they have instead turned their attention to making transistors so that more of them can reside on a single chip. Today, we have a single silicon chip that contains two or more cores. The result is that our software gets faster if we write our software to use the multiple cores. How do we do this? We use threads in an intelligent fashion.

Computers use three kinds of multi-CPU technologies:

+   **Multiple CPUs** Some computers have multiple CPUs in them. That is, the motherboard has multiple sockets on it, each socket connecting a CPU. Because the motherboard must be bigger, the computer case is bigger as well, and sometimes these have multiple power supplies in them due to the additional power draw. These of computers have been around for a few decades, but they are not popular today due to their increased size and cost.

+   **Hyperthreaded chips** This technology (owned by Intel) allows a single chip to look like two chips. The chip contains sets of architectural states, such as CPU registers, but the chip has only one set of execution resources. To Windows, Windows schedules two threads concurrently, this looks like two CPUs in the machine, the chip only executes one of the threads at a time. When one thread pauses due to a cache miss, branch misprediction, or data dependency, the chip switches to the other thread. All this happens in hardware, and Windows doesn't know it is happening; Windows believes that both are running concurrently. And if you have multiple hyperthreaded CPUs in a single machine, Windows will first schedule one thread on each CPU so that the threads are truly running concurrently and schedule other threads on the already-busy CPUs. Intel claims that a hyperthreaded CPU can improve performance by 10 to 30 percent.

+   **Multi-core chips** A few years ago, single chips containing multiple CPU cores have entered the scene. As I write this, chips with two, three, and four are readily available. Even my notebook computer has two cores in it; mobile phones now have multiple cores in them too. Intel has even been working on a single chip with 80 cores on it! Wow, this is a lot of computing power! And Intel even has hyperthreaded multi-core chips.
