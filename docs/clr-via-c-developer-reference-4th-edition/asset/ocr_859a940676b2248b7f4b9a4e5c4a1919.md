```
And here is code how to use it:

public static void Main() {
	using (ThreadIO.BeginBackgroundProcessing()) {
		 // Low-priority I/O requests in here (eg: calls to ReadAsync/WriteAsync)
	}
}
```

You tell that you want your thread to start low-priority I/O requests by calling ThreadIO.BeginBackgroundProcessing method. Note that this lowers the CPU scheduling priority of the thread. You can return the thread to making normal-priority I/O requests (and normal CPU scheduling priority) by calling EndBackgroundProcessing or by calling Dispose on the value returned by BeginBackgroundProcessing (as shown in the code C#'s using state). A thread can only affect its own background processing mode; Windows doesn't allow a thread to change the background processing mode of another thread.

If you want all threads to make process low-priority I/O requests and have low CPU scheduling, you can call BeginBackgroundProcessing, passing in true for the process parameter. A process can only affect its own background processing mode; Windows doesn't allow a thread to change the background processing mode of another process.
