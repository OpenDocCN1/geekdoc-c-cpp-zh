# Who This Book Is For

The purpose of this book is to explain how to develop applications and reusable classes for the .NET Framework. No book could fully explain the FCL—contains thousands of types, and now this continues to grow at an alarming rate. Therefore, I'm concentrating on the core types that every developer needs to be aware of. Now you must decide which programming language to use. This task is usually difficult because different languages offer different capabilities.
