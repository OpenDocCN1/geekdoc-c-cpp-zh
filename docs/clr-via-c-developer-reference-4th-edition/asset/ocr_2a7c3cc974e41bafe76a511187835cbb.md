allow themselves to be canceled. Here are the most useful members of the CancellationToken
value type.

```
public struct CancellationToken { // A value type
public static CancellationToken None { get; } // Very convenient
```

```
public bool IsCancellationRequested { get; } // Called by non-Task invoked operations
public void ThrowCancellationRequested(); // Called by Task-invoked operations
```

```
// WaitHandle is signaled when the CancellationSource is created
public WaitHandle WaitHandle { get; }
// GetHashCode, Equals, operator == and operator!= members are not shown
```

```
public bool CanBeCanceled { get; } // Rarely used
public CancellationTokenRegistration Register(Action<Object> callback, Object state,
bool useSynchronizationContext); // Simpler overloads nothing
```

A CancellationToken is a lightweight value type because it contains a single private
field: a reference to its CancellationSource object. A compute-bound operation loop can
periodically call Cancellation's IsCancellationRequested property to know if the loop
should terminate early, thereby ending the compute-bound operation. Of course, the benefit here is
at CPU time is no longer being wasted on an operation whose result you know you're not interested
now. Let us put all together with some sample code.

```
internal static class CancellationDemo
public static void Main()
    CancellationSource cts = new CancellationSource();
```

```
// Pass the CancellationToken and the number-to-count into the operation
ThreadPool.QueueWorkItem(item => Count(cts.Token, 1000));
```

```
Console.WriteLine("Press <Enter> to cancel the operation.");
Console.Cancel(); // If counted already, Cancel has no effect on it
// Cancel returns immediately, and the method continues running...
```

```
private static void Count(CancellationToken token, int32 countTo) {
    for (int32 count = 0; count < countTo; count++) {
        if (token.IsCancellationRequested) {
            Console.WriteLine("Count is cancelled");
            break; // Exit the loop to stop the operation
        }
    }
}
```

```
Console.WriteLine(count);
Thread.Sleep(200); // For demo, waste some time
Console.WriteLine("Count is done");
```
