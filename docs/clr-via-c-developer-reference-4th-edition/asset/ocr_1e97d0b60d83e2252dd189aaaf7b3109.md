As you can see, you can invoke GCutil.exe /i switch to install an assembly into the GAC, and you note you can't ever place a weakly named assembly in the GAC. If you pass the file name of a weakly named assembly to GCutil.exe, /u switch to uninstall an assembly from the cache GCutil.exe, it displays the following error message: Failure adding assembly to the cache: Attempt to install an assembly without a strong name.

> Note By the default, the GAC can be manipulated only by a user belonging to the Windows Administrators group. GCutil.exe will fail to install or uninstall an assembly if the user invoking execution of the utility isn't a member of this group.

GCutil.exe /i switch is very convenient for developer testing. However, if you use GCutil.exe /s to deploy an assembly in a production environment, it is recommended that you use GCutil.exe /r switch in addition to specifying the /i or /u switch to install or uninstall the assembly. /r switch integrates the assembly with the Windows install and uninstall engine. Basically, it tells the system application requires the assembly and ties the application and the assembly together.
