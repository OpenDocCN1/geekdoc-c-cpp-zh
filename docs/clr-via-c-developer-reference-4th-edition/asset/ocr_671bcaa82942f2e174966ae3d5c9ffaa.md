Space developing, the Char type also offers several static methods, as IsDigit, IsLetter, IsWhitespace, IsLower, IsPunctuation, IsLetterOrDigit, IsNumber, IsSeparator, IsSurrogate, IsLowSurrogate, IsHighSurrogate, and IsSymbol. Most of these methods getUnicodeCategory internally and simply return true or false accurately. Note that all of these methods either take a single character for a parameter or a String and the index of a character within the String parameters.

In addition, you can convert a single character to its lowercase or uppercase equivalent in a culture-agnostic way by calling the ToLowerInvariant or ToToUpper methods. Alternatively, the ToLower and ToToUpper convert the character by using the culture-association with the calling thread (which methods obtain internally by querying the staticCurrentCulture property of the System.Globalization.CultureInfo class). You can also specify a particular character by passing an instance of the CultureInfo class to these methods. ToLower and ToToUpper require culture information because letter casing is a culture-dependent operation. For example, Turkish considers the uppercase of U+0069 (LATIN LOWER LETTER I) to be U+0130 (LATIN UPPERCASE LETTER I WITH DOT ABOVE), whereas other cultures consider the result to be U+0049 (LATIN CAPITAL I).

Besides these static methods, the Char type also offers a few methods of its own. The Equals method returns true if two Char represent the same 16-bit Unicode code point. The CompareTo methods (defined by the IComparable/IComparable<Char> interfaces) return a comparison of two characters; this comparison is not culture-sensitive. The ConvertUtf32 method produces a string consisting of one or two UTF-16 characters from a single UTF-32 character. The ConvertToUtf32 method returns a UTF-32 character from a low/high surrogate pair or from a string. The ToString method returns a string consisting of a single character. The opposite of ToString/Parse, which takes a single-character String and returns its UTF-16 code point.

The last method, GetNumericValue, returns the numeric equivalent of a character. I demonstrate this method in the following code.

using System;

```
public static class Program {
    Double d;
    // \u0033 is the "digit 3"
    d = Char.GetNumericValue(\u0033); // '3' would work too
    Console.WriteLine(d.ToString()); // Displays "3"

    // \u00bc is the "vulgar fraction one quarter ('¼')"
    d = Char.GetNumericValue(\u00bc);
    Console.WriteLine(d.ToString()); // Displays "0.25"

    // 'A' is the "Latin capital letter A"
    d = Char.GetNumericValue('A');
    Console.WriteLine(d.ToString()); // Displays "-1"
}}
```
