To get the answer, you must look up ArrayList's Add method and see what type its parameter defined as. In this case, the Add method is prototyped as follows.

```
public virtual Int32 Add(Object value);
```

From this, you can plainly see that Add takes an Object as a parameter, indicating that Add requires a reference (or pointer) to an object on the managed heap as a parameter. In the preceding code, I'm passing p, a Point, which is a value type. For this code to work, the Point value type must be converted into a true heap-managed object, and a reference to this object must be obtained.

It's possible to convert a value type to a reference type by using a mechanism called boxing. Generally, it's what happens when an instance of a value type is boxed:

+   Memory is allocated from the managed heap. The amount of memory allocated is the size required by the value type's fields plus the two additional overhead members (the type pointer and the sync block index) required by all objects on the managed heap.

+   The value's fields are copied to the newly allocated heap memory.

+   The address of the object is returned. This address is now a reference to an; the value type is now a reference type.

The C# compiler automatically produces the IL code necessary to box a value type, but you still need to understand what's going on internally so you're aware of code size and performance.

In the preceding code, the C# compiler detected that I was passing a value type to a method that requires a reference, and it automatically emitted code to box the object. At run time, the fields residing in the Point value type instance p are copied into the newly allocated object. The address of the boxed Point object (now a reference) is returned and is then passed to the Add method. The Point object will remain in the heap until it is garbage collected. The value type variable (p) can be reused because the ArrayList never knows anything about it. Note that the lifetime of the boxed value type extends beyond the lifetime of the unboxed value type.
