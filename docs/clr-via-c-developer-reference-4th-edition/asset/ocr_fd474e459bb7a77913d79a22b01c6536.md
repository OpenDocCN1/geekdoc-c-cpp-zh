Figure 25-2 shows the various WinRT IAsyncCxx interfaces. The four main interfaces all derive from the IAsyncInfo interface. The two IAAsyncAction interfaces give you a way to know when the operation has completed, but they complete with no return value (GetResults methods have a void type). The two IAAsyncOperation interfaces also give you a way to know when the operation has completed and allow you to get their return value (GetResults methods have a generic TResult type).

The two IAsyncCxxThProgress interfaces allows your code to receive periodic progress updates as the asynchronous operation is progressing through its work. Most asynchronous operations do not offer progress but some (like background downloading and uploading). To receive periodic progress updates, you would define another callback method in your code, create a delegate that refers to it, and assign the delegate to the IAsyncCxxThProgress object's Progress property. When your callback is invoked, it is passed an argument type that matches your generic T type.

In the .NET Framework, we use the types in the System.Threading.Tasks namespace to simplify performing asynchronous operations. We explain these types and how to use them to perform compute operations in Chapter 27, “Compute-Bound Asynchronous Operations,” and how to use them to perform I/O operations in Chapter 28, "I/O-Bound Asynchronous Operations." In addition, C# offers the async and await keywords, which allow you to perform asynchronous operations by using a sequential programming model, thereby simplifying your code substantially.
