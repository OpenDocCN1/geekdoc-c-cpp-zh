Now ToString is called on the unboxed value type instance, and a String is returned. String objects are already reference types and can simply be passed to the Concat method without requiring boxing.

Let's look at another example that demonstrates boxing and unboxing.

```
public static void Main() {
    Int32 v = 5;           // Create an unboxed value type.
    Object o = v;               // refers to the boxed version of v.

    v = 123;
    Console.WriteLine(v);\    // Changes the unboxed value type to 123
                                 // Displays "123"

    v = (Int32)o;
    Console.WriteLine(o);\    // Unboxes and copies into v
                                 // Displays "5"
}
```

How many boxing operations do you call in this code? The answer is one. The reason there is only one boxing operation is that the System.Console defines a WriteLine method that accepts Int32 as a parameter.

```
public static void WriteLine(Int32 value);
```

In the preceding calls to WriteLine, the variable v, an Int32 unboxed value type, is passed by value. Now it will be that WriteLine box this Int32 internally, but you have no control over that. The important thing is that you've done the best you can and eliminated the boxing from your own code.

If you take close look at the FCL, you'll notice many overloaded methods that differ based on their value parameters. For example, the System.Console type offers several overloaded versions of the WriteLine method.

```
public static void WriteLine(Boolean);
public static void WriteLine(Char);
public static void WriteLine(Char[]);
public static void WriteLine(Int32);
public static void WriteLine(UInt32);
public static void WriteLine(Int64);
public static void WriteLine(UInt64);
public static void WriteLine(Single);
public static void WriteLine(Double);
public static void WriteLine(Decimal);
public static void WriteLine(Object);
public static void WriteLine(String);
```

You'll find a similar set of overloaded methods for System.Console's Write method, System.IO.BinaryWriter's Write method, System.IO.Text's Write and WriteLine methods, System.Runtime.Serialization.SerializationInfo's AddValue method, System.Text.StringBuilder's Append and Insert methods, and on Most of these methods offer overloaded versions for the sole purpose of reducing the number of boxing operations for the common value types.
