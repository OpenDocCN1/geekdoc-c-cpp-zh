# Delegates and Reflection

So far in this chapter, the use of delegates has required the developer to know up front the prototype of the method that is to be called. For example, if fb is a variable that references a Feedback delegate (see this first program listing), to invoke the delegate, the code would look like the following.

```csharp
fb(item); // item is defined as Int32
```

As you can see, the developer must know when coding how many parameters the callback method requires and the types of those parameters. Fortunately, the developer almost always has this information, so writing like the preceding code isn't a problem.

In rare circumstances, however, the developer doesn't have this information at compile time. I showed an example of this in Chapter 11, "Events," when I discussed the HashSet. In this example, a dictionary maintained a set of different delegate types. At runtime, to raise an event, one of the delegates was looked up in the dictionary and invoked. At compile time, it wasn't possible to know exactly which delegate would be called and which parameters were necessary to pass to the delegate's callback method.

Fortunately, System.Reflection.MethodInfo offers a CreateDelegate method that allows you to create a delegate when you don't have all the necessary information about the delegate at compile time. Here are the methodloads that MethodInfo defines.

```csharp
public abstract class MethodInfo : MethodBase {
    // Construct a delegate wrapping a static method.
    public abstract Delegate CreateDelegate(Type delegateType);

    // Construct a delegate wrapping an instance method;
    public virtual Delegate CreateDelegate(Type delegateType, Object target);

    // Invoke a delegate passing parameters
    public abstract Object Invoke(params Object args);
}
```

Using reflection APIs is discussed in detail detail, you must first acquire a MethodInfo object. The following code shows how to use CreateDelegate and DynamicInvoke, which looks like the following.

```csharp
using System;
using System.Reflection;
using System.IO;

// Here are some delegate definitions
internal delegate Object TwoInt32s(Int32 n1, Int32 n2);
internal delegate Object String(String s1);

public static class DelegateReflection {
    public static void Main(String[] args) {
        if (args.Length < 2) {
            String usage = "@Usage: {0} where delegateType must be TwoInt2s or String" + Environment.NewLine +
                           "Examples: TwoInt2s Add 123 321" + Environment.NewLine +
                           "String Reverse \"Hello there\"";
            Console.WriteLine(usage, args[0]);
            return;
        }

        // Convert the delegateType argument to a delegate
        Type delType = Type.GetType(args[0]);
        if (delType == null) {
            Console.WriteLine("Invalid delegateType argument: " + args[0]);
            return;
        }

        Delegate d;
        try {
            // Convert the methodName argument to method
            MethodInfo mi = typeof(DelegateReflection).GetMethod(args[1]);

            // Create a delegate that wraps the static method
            d = mi.CreateDelegate(delType);
        } catch (ArgumentException) {
            Console.WriteLine("Invalid methodName argument: " + args[1]);
            return;
        }

        // Create an array that will contain just the arguments
        // to pass to the method via the delegate object
        Object[] callbackArgs = new Object[args.Length - 2];

        if (d.GetType() == typeof(TwoInt32s)) {
            try {
                // Convert the String arguments to Int32 arguments
                for (int a = 2; a < args.Length; a++) {
                    callbackArgs[a - 2] = Int32.Parse(args[a]);
                }
            } catch (FormatException) {
                Console.WriteLine("Parameters must be integers.");
                return;
            }
        }

        if (d.GetType() == typeof(String)) {
            // Just copy the String argument
            Array.Copy(args, 2, callbackArgs, callbackArgs.Length);
        }

        // Invoke the delegate
        Object result = d.DynamicInvoke(callbackArgs);
        Console.WriteLine(result);
    }

    public static Object TwoInt32s(Int32 n1, Int32 n2) {
        return n1 + n2;
    }

    public static Object String(String s1) {
        char[] charArray = s1.ToCharArray();
        Array.Reverse(charArray);
        return new string(charArray);
    }
}
```
