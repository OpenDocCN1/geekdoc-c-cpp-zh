Let's look at a few examples that demonstrate boxing and unboxing.

```
public static void Main() {
    Int32 v = 5; // Create an unboxed value type variable.
    Object o = v; // o refers to a boxed Int32 containing 5.
    v = 123; // Changes the boxed value to 123

    Console.WriteLine("" + (Int32)o + \,\ + s); // Displays "123, s"
}
```

In this code, can you guess how boxing operations occur? You might be surprised to find that the answer is three! Let's analyze the code carefully to really understand what's going on.
