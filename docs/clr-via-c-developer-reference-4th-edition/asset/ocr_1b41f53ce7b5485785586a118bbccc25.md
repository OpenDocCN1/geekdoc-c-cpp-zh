When called, the JITCompiler function knows what method is called and what type defines this method. The JITCompiler function searches the assembly metadata for the called method's IL. JITCompiler next verifies and compiles the IL code into native CPU instructions. The native CPU instructions are saved in a dynamically allocated block of memory. JITCompiler goes to the entry for the called method in the type's internal data structure created by the CLR and replaces the reference it called in the first place with the address of the block of memory containing the native CPU instructions it just compiled. Finally, the JITCompiler function jumps to the memory block. This code is the implementation of the WriteLine method (the version that takes a String parameter). When this code returns, it returns to the code in Main, which continues execution as normal.

Main now calls WriteLine a second time. The code for WriteLine has already been verified and compiled. The so call goes to the block of memory, skipping the JITCompiler function entirely.
