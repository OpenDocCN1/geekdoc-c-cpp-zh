
线程池会快速创建工作线程，使得工作线程的数量等于传递给 `ThreadPool.SetMinThreads` 方法的值。如果你从未调用过此方法（建议你永远不要调用此方法），那么默认值将等于根据你的进程亲和性掩码（affinity mask）允许该进程使用的 CPU 数量。通常情况下，你的进程被允许使用机器上所有的 CPU，因此线程池会快速创建工作线程，直到达到机器上 CPU 的数量。在创建了这么多线程后，线程池会监控工作项的完成率，如果项目需要很长时间才能完成（其含义文中未说明），它将创建更多的工作线程。如果项目开始快速完成，工作线程就会被销毁。
