
```csharp
// If a delegate remains, set the new head remove the EventKey
if (d == null) m_events[eventKey] = d;
else m_events.Remove(eventKey);
}
Monitor.Exit(m_events);

// Raises Raise for the indicated EventKey
public void Raise(EventKey eventKey, Object sender, EventArgs e) {
    // Don't throw an exception if the EventKey is not in the set
    Delegate d;
    Monitor.Enter(m_events);
    m_events.TryGetValue(eventKey, out d);
    Monitor.Exit(m_events);

    if (d == null) {
        // Because the dictionary can contain several different delegate types,
        // it is impossible to construct a type-safe call to the delegate at
        // compile time. So, I call the System.Delegate type's DynamicInvoke
        // method, passing it to the callback method's parameters as an array of
        // objects. Internally DynamicInvoke will check the type safety of the
        // parameters with the callback method being called and the method.
        // If there is a type miss, DynamicInvoke will throw an exception.
        d.DynamicInvoke(new Object[] { sender });
    }
}
```

Generics in the Framework Class Library

Generics provide a way to define classes, interfaces, methods, and delegates that can be used with any data type. This is particularly useful when you want to write code that can work with different types while still maintaining type safety.

Generics are defined using type parameters, which are placeholders for types that will be specified when the generic class or method is used. Type parameters are typically enclosed in angle brackets.

```csharp
public class Box<T> {
    private T _content;
    public void Set(T content) {
        _content = content;
    }
    public T Get() {
        return _content;
    }
}
```

In this example, `T` is a type parameter. When you create an instance of `Box<T>`, you replace `T` with a concrete type.

```csharp
Box<int> intBox = new Box<int>();
intBox.Set(42);
Box<string> stringBox = new Box<string>();
stringBox.Set("Hello");
```

Generics allow you to write reusable code that is type-safe. This eliminates the need for casting and reduces the risk of runtime errors.

Generics can also be applied to methods and interfaces.

```csharp
public void Swap<T>(ref T a, ref T b) {
    T temp = a;
    a = b;
    b = temp;
}
```

```csharp
int x = 1, y = 2;
Swap(ref x, ref y);
string s1 = "Hello", s2 = "World";
Swap(ref s1, ref s2);
```

Generics also support constraints, which allow you to limit the types that can be used as type parameters. Constraints are specified using the `where` clause.

```csharp
public class Repository<T> where T : IComparable {
    public bool Compare(T item, T other) {
        return item.CompareTo(other) > 0;
    }
}
```

Generics are a powerful feature of C# that allows you to write more flexible, type-safe, and reusable code.

Generics Infrastructure

The infrastructure for generics involves how the .NET runtime handles generic types at runtime. The runtime uses a process called reification to generate specialized code for each concrete value type used with a generic type. For value types, the runtime generates a separate version of the machine code for each type. For reference types, the runtime shares the same machine code among all types because they all have the same memory size.

Generic Interfaces

Generic interfaces can be used to define contracts that can be implemented by generic classes.

```csharp
public interface IRepository<T> {

    T GetById(int id);
}
```

```csharp
public class Repository<T> : IRepository<T> {
    private List<T> _data = new List<T>();
    public void Save(T item) {
        _data.Add(item);
    }
    public T GetById(int id) {
        return _data[id];
    }
}
```

Generic Delegates

Generic delegates allow you to define callbacks that can work with any type.

```csharp
public delegate TResult<T, TResult>(T input);
```

```csharp
Func<int, string> intToString = (x) => x.ToString();
```

Delegate and Interface Contra-variant and Covariant Generic Type Arguments

Contravariance and covariance are concepts that describe how generic types relate to their underlying types. Covariance allows a more derived type to be used where a less derived type is expected. Contravariance allows a less derived type to be used where a more derived type is expected.

```csharp
public interface IComparable<in T> {
    int Compare(T other);
}

public interface IClone<out T> {
    T Clone();
}
```
