If you want to associate arbitrary data with one or more objects, you would create an instance of this class. Then, call the Add method, passing in a reference to some object for the key parameter and the data you want to associate with the object in the value parameter. If you attempt to add a reference to the same object than once, the Add method throws an ArgumentException; to change the value associated with the object, you must remove the key and add it back in the new value. Note that this class is thread-safe so multiple threads can use it concurrently, although this means the performance of the class is not stellar; you should test the performance of this to see how it works for your scenario.

Of course, a table object internally stores a WeakReference to the object passed in as the key; this ensures that the table does not forcibly keep the object alive. But what makes the Conditional-WeakTable class so special is that it guarantees the value remains in memory as long as the object identified by the key is in memory. So this is more than a normal WeakReference because it were, the value could be garbage collected even though the key object continued to live. The ConditionalWeakTable class could be used to implement the dependency property mechanism by XAML. It can also be used internally by dynamic languages to dynamically associate data with objects.

Here is some code that demonstrates the use of the ConditionalWeakTable class. It allows you to call the GCWatch extension on any object passing in String tag. Then it notifies you via the console window whenever particular object gets garbage collected.

```
internal static class GCWatcher
// Be careful with Strings due to interning and MarshalByRefObject objects
private readonly static ConditionalWeakTable<Object, String> s_cwt = new ConditionalWeakTable<Object, String>(NotifyWhenGc..Final);
```

```
private sealed class NotifyWhenGc<T>
    private readonly T m_value;
```

```
internal NotifyWhenGc(T value) { m_value = value; }
    public override string ToString() { return m_value.ToString(); }
    ~NotifyWhenGc() { Console.WriteLine("GC: " + m_value); }
```

```
public static void GCWatch<T>(this T object, String tag) where T : class {
s_cwt.Add(object, new NotifyWhenGc<T>(tag));
    return object;
}
```
