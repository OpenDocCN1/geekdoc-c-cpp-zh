{

```
// PUBLIC remove_xxx method (Xxx is the Event name)
// Allows methods to unregister interest in the event.
public void removeNewMail(NewMailEventArgs value) {
    // The loop and the call to CompareExchange is all just a fancy way
    // of removing the delegate from the event in a thread-safe way
    EventHandler<NewMailEventArgs> prevHandler;
    EventHandler<NewMailEventArgs> newMail = this.NewMail;
    {
        prevHandler = newMail;
        EventHandler<NewMailEventArgs> handler = =
            Delegate.Remove(prevHandler, value);
        newMail = Interlocked.CompareExchange<EventHandler<NewMailEventArgs>>(
            ref this.NewMail, handler, prevHandler);
    } while (newMail != prevHandler);
```

The first construct is simply a field of the appropriate delegate type. This field is initialized to null, a list of delegates that will be notified when this event occurs. meaning that no listeners have registered interest in the event. When a method registers interest in the event, this field refers to an instance of the EventHandler<NewMailDelegate>, which may refer to additional EventHandler<NewMailEventArgs> delegates. When a listener registers interest in an event, the listener is simply adding an instance of the delegate type to the list. Obviously, unregistering means removing the delegate from the list.

You'll notice the field NewMail in this example, is private even though the original line of source code defines it as public. The reason for making the delegate field private is to prevent outside code from manipulating it improperly. If the field were public, any code could alter the value in the field and potentially wipe out all of the delegates that have registered interest in the event.

The second construct the C# compiler generates a method that allows others to register their interest in the event. The C# compiler automatically names this function by prepending add. to the event's name (NewMail). The C# compiler automatically generates the code that is inside this method. The code calls Delegate's static Combine method, which adds the instance of a delegate to the list of delegates and returns the new head of the list, which gets saved back in the field.

The third construct the C# compiler generates a method that allows others to unregister its interest in the event. Again, the C# compiler automatically names this function by prepending remove_to the event's name (NewMail). The code inside this method calls Delegate's static Remove method, which removes the instance of a delegate from the list of delegates and returns the new head of the list, which gets saved back in the field.
