For anyone has been working with earlier versions of the .NET Framework, you may be familiar with some other asynchronous programming models that it offered. There is the programming model that used BeginXx and EndXx methods along with an IAsyncResult interface. There is the event-based programming model that also had XxxAsync methods (that did not return Task objects) and invoked event handler methods when an asynchronous operation completed. These two asynchronous programming models are now considered obsolete and the new model using Task is the preferred model.

While looking through the FCL, you might notice some classes that are lacking XxxAsync methods and instead offer BeginXx and EndXx methods. This is mostly due to Microsoft not having the time to update these classes with the new methods. In the future, Microsoft will be enhancing these classes so that they fully support the new model. However, until then, there is a helper method that you can use to adapt the BeginXx and EndXx model to the new Task-based model.

Earlier I showed the code for a client that makes a request over a named pipe. Let me show the server side of this code now.

```
private async void StartServer() {
while (true) {
    var pipe = new NamedPipeServerStream(pipeName, PipeDirection.InOut, -1,
    PipeTransmissionMode.Message, PipeOptions.Asynchronous | PipeOptions.WriteThrough);
    // asynchronously connect a client connection
// NOTE: NamedPipeServerStream uses the old Asynchronous Programming Model (APM)
// I convert the old APM to the new model via TaskFactory's FromAsync method
await Task.Factory.FromAsync(pipe.BeginWaitForConnection, pipe.WaitForConnection, null);
    // Start serving the client, which returns immediately because it is asynchronous
    ServiceClientRequestAsync(pipe);
}
```

The NamedPipeServer class has BeginWaitForConnection and EndWaitConnection methods defined, but it does not have a WaitForConnection method. Hopefully this method will be added in a future version of the FCL. However, all is not lost, because as you see in the preceding code, I call TaskSchedulerFromAsync method, passing it into the names of the BeginXx and EndXx methods, and then FromAsync internally creates a Task object that wraps these methods. Now I can use the Task object with the await operator.
