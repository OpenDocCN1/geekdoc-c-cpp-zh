If my GetFormat method is called and passed as any other type, I call the GetFormat method of the CultureInfo object associated with the calling thread.

In my method, I check whether the object supports rich formatting via the IFormattable interface. If the object doesn't, I call the parameterless ToString method (inherited from Object). If the object supports IFormattable, I call the rich ToString method, passing the string and the format provider.
