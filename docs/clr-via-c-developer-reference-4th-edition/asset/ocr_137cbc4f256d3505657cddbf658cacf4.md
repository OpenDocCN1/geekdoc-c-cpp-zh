```
public static async Task Go() {
    // Start the server, which returns immediately because
    // it asynchronously waits for client requests
    StartServer(); // This returns void, compiler warning to deal with

    // Make lots of async requests; save each client's Task<String>
    List<String> requests = new List<String>(10000);
    for (Int32 n = 0; n < requests.Capacity; n++) {
        requests.Add(IssueClientRequestAsync("localhost", "Request " + n));
    }

    // Asynchronously wait until all client requests have completed
    // NOTE: If 1+ tasks throws, WhenAll rethrows the last exception
    String[] responses = await Task.All(requests);

    // Process all responses
    for (Int32 n = 0; n < responses.Length; n++) {
        Console.WriteLine(responses[n]);
    }
}
```

This code starts the main pipe server that is listening and for a
op, it initializes 10,000 client requests as fast as possibly can. Each ClientRequest-
Async returns a Task<String> object, which I add to a collection. Now, the
pipe server is processing these client requests as fast as possible using thread pools that
will try to keep all the CPUs on the machine busy.¹10 Each request's Task<String> object completes with the string response returned from the server.

In the preceding code, I want to wait until all the client requests have their response before
processing their results. I accomplish this by calling Task's WhenAll method. Internally,
method creates a Task<String[]> object that completes after all of the List's objects have
completed. I await the Task[] object so that the state machine executes continu-
after all of the tasks have completed. I loop through all the
responses at once and process them (call Console.WriteLine).
