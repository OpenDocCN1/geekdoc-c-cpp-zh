# Adding Assemblies to a Project by Using the Visual Studio IDE

If you're using the Visual Studio IDE to build your project, you'll have to add any assemblies you want to reference to your project. To do so, open Solution Explorer, right-click the project you want to add a reference to, and then select the Add Reference menu item. This causes the Reference Manager dialog box, see in Figure 2-2, to appear.

![](bbox=[0.166, 0.169, 0.833, 0.516])

To have your project reference, select the assembly from the list. If the assembly you want is not in the list, click the Browse button to navigate to the desired assembly (file containing a manifest) to add the assembly reference. The Solution option allows the current project to reference another project in the same solution. The COM option in the Reference Manager dialog box allows an unmanaged COM server to be accessed from managed proxy source code automatically generated by Visual Studio. The Browse option allows you to select an assembly that you recently added to another project.

To make your own assemblies appear in the Reference Manager's dialog box, follow the instructions at http://msdn.microsoft.com/en-us/library/ze6zky(v=110).aspx.
