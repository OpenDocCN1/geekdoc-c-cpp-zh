When the device is shaken, you called the ResetDatePicker method to reset the DatePicker view to the current date:

```
- (void)motionEnded:(UIEventSubtype)motion withEvent:(UIEvent *)event {
    if (event.subtype == UIEventSubtypeMotionShake) {
        NSLog(@"motionEnded:");
        [self ResetDatePicker];
    }
}
```
