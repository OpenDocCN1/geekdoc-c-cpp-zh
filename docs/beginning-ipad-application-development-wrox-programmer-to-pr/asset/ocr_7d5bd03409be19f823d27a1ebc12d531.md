# How It Works

To rotate a view, set its transform property using a CGAffineTransform data structure returned by the CGAffineTransformMakeRotation() function. The CGAffineTransformMakeRotation() function takes a single argument, which contains the angle to rotate (in radians). After each rotation, you increment the angle by 0.02:

```
```objc
//---rotation---
imageView.transform = CGAffineTransformMakeRotation(angle);
angle += 0.02;
```
```

A full rotation takes 360 degrees, which works out to be 2π radian. If the angle exceeds 6.2857 (=2*3.142857), you reset angle to 0:

```
```objc
if (angle>6.2857) angle = 0;
```
```

# Scaling

For scaling of views, you use the CGAffineTransformMakeScale() function to return a CGAffineTransform data structure and set it to the transform property of the view:

```
```objc
imageView.transform = CGAffineTransformMakeScale(angle, angle);
```
```

CGAffineTransformMakeScale() takes two arguments: the factor to scale for the x axis and the factor to scale for the y axis.

If you modify the previous Try It Out with the preceding statement, the tennis ball gets bigger as it bounces on the screen (see Figure 11-9). It then resets back to its original size and grows again.
