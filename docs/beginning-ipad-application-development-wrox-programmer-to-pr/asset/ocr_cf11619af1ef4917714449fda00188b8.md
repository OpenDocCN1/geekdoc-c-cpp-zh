so that it could be connected to the View Controller you just added. This controller class contains the code that you will write to handle the interactions between the view and the user.

When the application has finished launching, you add the View represented by the HelloWorldViewController object to the window so that it is visible using the addSubview: method of the UIWindow instance:

```
[window addSubview:viewController.view];
```
