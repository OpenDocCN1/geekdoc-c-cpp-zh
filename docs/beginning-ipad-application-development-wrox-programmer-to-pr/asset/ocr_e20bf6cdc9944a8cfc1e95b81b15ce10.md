# FIGURE 2-4

Obviously, a blank screen is not very useful. So, it's time to try adding some views to the UI of your application. In the list of files in your project, you'll notice two files with the `.xib` extension — `MainWindow.xib` and `HelloWorldViewController.xib`. Files with `.xib` extensions are basically XML files containing the UI definitions of an application. You can edit `.xib` files by either modifying their XML content, or more easily (and more sanely), edit them using Interface Builder.
