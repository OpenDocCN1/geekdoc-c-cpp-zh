+   - **RTCCProcessEvents ()** - The function grabs the current time from the RTCC and translate it into strings. Must be called periodically to refresh time and date strings `_time_str` and `_date_str`. Each string is 16 ASCII characters

The above functions work directly with the RTCC without the advantage of the LCD and pushbuttons. Using the LCD and pushbuttons makes working with the RTCC a lot easier, and this is covered in a chapter 10 in this book for the 16 Experimenter.

# *Demos that come with PIC24F*

The Experimenter comes with a P24FJ64GA002 that is preprogrammed with the following built-in demos. The demos were written using Microchip free MPLAB and PIC24 C code. The PIC24 C Compiler, MPLAB C30 v3.11b (or later), Student Edition is free and was used for this demo. The link is below to download and see a full description of the compiler.

http://www.microchip.com/C30

Source code and full demo description as well as kit assembly instruction are included on the Experimenter's CD-ROM that comes with the kit. The demo starts as a revolving series of eleven different flash screens, each lasting about 4 seconds. The user invokes a specific functional demo by pushing one of the pushbuttons. Two of the introductory functional demos (digital thermometer and RGB LED) that come with the kit require some additional hardware and hook-up as shown. A third functional demo (Clock) does not rely on any additional hardware.

These functional demos are intended to allow user to gain familiarity with the Experimenter and insure its proper operation after kit assembly. As mentioned earlier, they can be invoked using the pushbuttons anytime during the flash screen displays and then can return to Flash Displays by simply pressing pushbutton S4.
