# The PIC24HJ128GP502 Microcontroller

Let's dig a little deeper and now explore the PIC24HJ128GP502 microcontroller more closely. This device, as mentioned earlier, comes prepackaged in a "skinny DIP". As discussed earlier the PIC24HJ128GP502 is a +3.3VDC logic part and supports 40 MIPS of operation with both a 128K FLASH, 8K RAM. Even though this part is +3.3V logic it can also support +5V Input on some of its pins (see +5V input tolerant pins) and it has the ability to drive +5VDC output logic level by using device configurable open drain setting on output levels. Interrupt handling and response times are important considerations in the use of microcontrollers for any real time operations. The PIC24H is well equipped here. It has an internal interrupt controller with guaranteed 5-cycle latency in respond to interrupts, up to 45 available interrupt sources, with seven priority levels, five traps for any processor exception handling (i.e. divide by zero) and three external interrupts.
