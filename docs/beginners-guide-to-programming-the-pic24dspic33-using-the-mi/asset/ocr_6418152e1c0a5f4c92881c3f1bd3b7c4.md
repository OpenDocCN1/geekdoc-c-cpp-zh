The actual library functions for ADC are as follows

+   - Void initADC (int ANpin) –this function initializes the ADC for 12 bit manual conversion using the "ANpin" as the single input pin. ANpin possible settings are AN0, AN1, An4, AN5, AN9, AN10, AN11, AN12
+   - Int readADC (int ANpin) –this functions forces a manual ADC conversion on the designated ANpin.
+   - Void binary_to_ASCIIconvert (int n) - this functions converts the n binary value to its ASCII equivalent. The ASCII equivalent resides in BCD variables listed below
+   - Int averagevalue (int ANpin) – this function is a high level function that automatically does four ADC conversions successfully in a row and averages the total.

In addition there are five variables location that the library holds the output from a binary to ASCII conversion
