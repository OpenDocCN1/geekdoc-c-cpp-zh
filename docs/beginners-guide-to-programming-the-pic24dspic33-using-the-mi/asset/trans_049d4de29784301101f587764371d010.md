## 安装错误

- 1. 源代码编译错误——如果出现编译错误，你可能无意中在源代码窗口中键入或输入了文本，IDE 会将其视为构建的新代码。如果出现这种情况，请关闭 IDE 并且不要保存工作区，重新加载演示代码并重新开始。
- 2. 'C' 编译器未安装——如果编译操作根本没有发生，并且输出窗口报告找不到编译器；你可能覆盖了编译器的默认位置。你现在有两个选择。第一个选择是直接将编译器重新安装到 IDE 的默认位置
