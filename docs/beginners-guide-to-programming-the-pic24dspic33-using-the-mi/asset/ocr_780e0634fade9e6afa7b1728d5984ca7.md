# Review of RTCC:

+   - The RTCC provides the PIC24h with a real time clock and calendar capability that support a hundred year Calendar.
+   - RTCC peripheral operation only requires a software setup and then runs independent of PIC24H in hardware.
+   - RTCC support alarms through interrupt.
+   - There are a number of RTCC SFR settings to initialize clock. These setting are done using BCD.
+   - An external 32 KHz Crystal and two 33 pF capacitors are required to support RTCC.

# Review of source code:

+   - The RTCC.C and RTCC.H library functions must be included as part of project.
+   - A larger function set in Main, clock_Setup (), can be used to initialize the RTTC using pushbutton and LCD.
+   - Alarms are serviced through the RTTC interrupt service routine.
