In Figure 4-1 the analog environment (typical of an input sensor value) is shown as a continuous voltage output over time. As environment conditions change the sensor output value also changes smoothly without interruption. The microcontroller, however, is a digital device; it operates only with digital numbers, and can only make a measurement periodically (as part of a normal processing loop). From the microcontroller viewpoint the continuous sensor signal is now a discrete set of values sampled at a fixed rate. The values are approximate values to true analog value given the simple fact that the digital number size itself is limited in resolution, or number of bits. For the PIC24H the ADC can generate either a 10 or 12 bit value (user selectable).

A 10 bit resolution provides a 1/1024 *3.3VDC voltage resolution or 3 millivolts (remember that the PIC24H is a +3.3VDC part). The 12 bits does better with 1/4096 * 3.3VDC or 0.8 millivolts. In both cases the ADC provides for a fixed resolution of the input sensor value based on the size of the ADC conversion. The PIC24H ADC resolution accuracy is good to +-1 LSB of the digital word size. This accuracy can be improved by averaging successive reading (assuming input does not change during averaging) to better than an LSB. A rule of thumb with this technology is to insure that the signal (by dynamically adjusting its amplitude) gets as large a signal as possible to the ADC and without exceeding full scale to achieve the best signal resolution during sample measurement. In our experiments we will not control any signal amplitude and only measure the raw output directly.

Let’s now discuss the fixed measurement rate or sample rate. As mentioned earlier, by using a fixed sample rate you are measuring the signal periodically. With periodical sampling the risk is that the signal may change between the periodic samples significantly and the microcontroller will not “see” and therefore measure and respond to these changes. A rule of thumb in engineering is that the sample rate should be high enough to capture the highest frequency of the signal. To be more precise the rule states that the sample rate = 2X Highest Input frequency (also known as Shannon’s Rule). In most cases (outside of audio) the sensor outputs are typically very low in frequency content so that a high sample rate isn’t necessary. However, the highest sample rate for the PIC24H with 10 bit ADC is 1.1MSPS (million samples per second) and for 12 bit ADC is 500 KSPS (500 thousand samples per second).

There is no free lunch in life, like everything else, there is a tradeoff for the user, and you essentially can trade off voltage resolution (10 or 12 bits) for conversion speed (1.1 MSPS or 500KSPS). The choices are up to you and should be dictated by what is needed for highest accuracy and most timely sensor reading. In our experiments we will work the 12 bit only.

Let’s cover some more basics before moving on with the experiments. Figure 4-2 shows some of the discrete steps that are involved with an ADC operation, beyond sampling rate and digital resolution. The ADC operation is broken into

two discrete steps: acquisition time (sampling and holding the signal) and then conversion (performing the ADC process on the sampled and held signal). In order to collect and hold an analog signal for conversion a sample and hold capacitor is used. This capacitor is internal to the PIC24H electronics. The capacitor follows the analog input signal and then upon a sample command stores a voltage capture of the analog value for the conversion process. This is denoted as the sample and hold process.

While the signal is held in the capacitor an analog to digital conversion process takes place. The conversion uses an exact number of CPU clock cycles (equivalent to resulting output word size), to perform the conversion. This type of conversion process is known as successive approximation, where an internal comparator is used to measure the difference between the analog sampled input and an internal generated ramp comparator. The ramp output voltage size is dictated by the number of conversion clocks. For each clock (one of the 10 or 12) a digital decision is made and a digital bit value is generated and stored as part of the final digital word result.

The PIC24H ADC peripheral is an extremely versatile part and has a number of operational modes configurable by setting peripheral specific SFR (special function registers). One of these modes is resolution and is selectable from 10 to 12 bit. The other is the number of sample and hold (S/H) channels that you can use. With 10 bit selection the number of total S/H is four, with a 12 bit ADC

- Selectable Buffer Fill modes-DMA assisted result storage

The ADC module has a total of ten SFR Control and Status registers, a subset of which we will be using in our upcoming experiments. Let's review this SFR content. We want in our experiments to be able to set the ADC for 12 bit single channel mode operation, no scanning, integer output, and manual mode trigger.

A block diagram of the ADC is shown for this type of configuration. Here only one S/H is active with the 12 bit ADC using only one input channel and no scanning. Our specific PIC24H, pre-configured in hardware with the Microstick II, doesn't have 16 analog channels but is limited to 8. These eight channels are AN0, AN1, AN4, AN5, AN9, AN10, AN11, and AN12.

Using the SFR setting for integer unsigned format for 12bits, the signal digital output format will vary from 0x0000 to 0x0FFF. This is typical for most single voltage input sensor values where 0 represents 0.0 volts and 0X0FFF represents +3.3 volts.

## Hardware description

The hardware schematic is given in Figure 4-4. Here we use an analog 10K potentiometer to function as a settable input analog source for analog input channel 0 or AN0 pin 2 of PIC24HJ128GP502. The 10K potentiometer has one terminal tied to an external +3.3 VDC voltage source. The Microstick II has two bare pads GND and VDD (or on schematic TP1). Your options are to connect to the TP1 via on card for +3.3VDC or furnish this supply voltage for this experiment. An important note in using TP1 is that there is a limitation in how much current this connection can supply. Remember that the microcontroller itself is also using this connection. Its needs will vary based upon oscillator setting and output drive current. As a rule of thumb as your prototype experiments grow beyond the 100ma mark you may want to use an external supply for your power source. In this exercise, since we are only using a potentiometer, we will connect to the VDD (TP1) for the +3.3VDC of the potentiometer and also connect pin 8 of Microstick II ground to the ground for the potentiometer. The wiper of the potentiometer is tied to the AN0 input pin 2. You must remove jumper J3 to disconnect the User Led from this pin. With the potentiometer we can vary the input voltage to AN0 to any value between +3.3VDC to ground for our ADC experiment.
