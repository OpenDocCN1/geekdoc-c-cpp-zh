Once the new source code is in place, do a build. There should be no compile errors. Let's examine the code changes before executing. Again you have the option of simulating, but it is really not necessary. Experiment 2 is a modification of experiment1. Rather than simply toggling a LED (RB5 of LATB), we increment the entire LATB and display each available pin as a digital out. To achieve this we set up a new integer variable display. We then increment this display with each cycle through the continuous loop and then output the entire display value to LATB. Note that TRISD in initialization set all LATB pins to output.

We have available to us 11 LEDs on PORTB starting with RB5 to RB15 and designated as the 'user LED'). To increment we do so with a value of 0x2f. This treats RB5 as the least significant bit in our binary counter.
