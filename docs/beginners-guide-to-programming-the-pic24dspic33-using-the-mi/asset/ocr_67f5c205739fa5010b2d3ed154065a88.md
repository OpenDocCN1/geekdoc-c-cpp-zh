# 16 bit Micro Experimenter (optional)

This is the UART experiment for the 16 bit Micro Experimenter. This operates in an identical fashion to Experiment 1 and 2 in this chapter and in fact uses similar source code modified for a different pin set on J3 I/O connector. Use source code UARTDEMO Experimenter. You need to build the code and uses either PICKIT2/3 as debugger/programmer. The Experimenter can be used with or without an external power supply if the PICKIT2 is used (the PICKIT2 senses power and automatically supplies power if not sensed). In addition the Experimenter needs an external LED with series resistor to be added to J3 PIN3 (see hookup diagram).
