# Running the Experiment

We have covered both the hardware and software so you are ready to run the prototype. Connect to the USB port of the PC. Connect your external +3.3V supply for use with the pot. Make the pot and LED circuit grounds are common with the Microstick II ground. Open chapter 9 folder to PWM.MCP. Open workspace by doubling clicking icon and do a build and download.

Run the program and as you turn the pot either clockwise or counter clockwise you should see the LED change brightness. If this does not occur please refer to schematic and prototype picture as you have a wiring error.

# 16 Bit Micro Experimenter (optional)

This is PWM experiment for the 16 bit Micro Experimenter. This operates in an identical fashion to Experiment 1 and 2 in this chapter and in fact uses similar source code modified for a different pin set on J3 I/O connector. Use source code PWMDEMO Experimenter. You need to build the code and use either PICKIT2/3 as debugger/programmer. The Experimenter can be used with or without an external power supply if the PICKIT2 is used (the PICKIT2 senses power and automatically supplies power if not sensed). In addition the Experimenter needs an external LED with series resistor and 10K to be added to J3 (see hookup diagram).
