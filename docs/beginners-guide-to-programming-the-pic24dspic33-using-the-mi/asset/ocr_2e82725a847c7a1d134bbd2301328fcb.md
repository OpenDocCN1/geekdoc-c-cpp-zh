# 16Bit Experimenter feature set:

+   - Plug in Module Format with built in 3.3V regulator for use with larger Solderless Breadboards.
+   - 16x3 low profile LCD display and 4 user defined pushbuttons
+   - ICSP interface for in circuit programming and debug
+   - Standard I/O Expansion Bus for breadboard access to PIC24F/PIC24H peripheral set
+   - On board 32KHz timing crystal for accurate timekeeping
+   - On board 32KB EEPROM
+   - Comes Equipped with PIC24FJGA002 but can Use PIC24HJ128GP502
+     - +3.3 V Operation 40 MIPS with some +5 Volt logic compatibility
+     - 128K Flash 8K RAM
+     - Host of on chip peripherals: ADC, Programmable I/O, Dual UART, Dual SPI, I2C, Analog Comparators, Capture/Compare Modules
+   - On/off switch with power on LED indicator-- power by wall transformer or direct connection. +3.3V out can be used for breadboard as well.
+   - Comes in kit format with assembly and operating instruction using full complement of thru-hole parts for ease of assembly( see www.kibacorp.com)

# Review of MPLAB Key features:

+   - Integrated development environment for Microchip Microcontrollers
+   - Uses Integrated Project Manager to organize and maintain project files and user's workspace
+   - Uses syntactic source code editors supporting both 'C' and assembly languages
+   - Single button build and program functions
+   - Support programming and debug of microcontroller using external devices like Microstick II
+   - Tool bar for run, pause, single step during debug operation.

# Review of Microstick II Key Features:

+   - Low Cost
+   - Integrated USB programmer / debugger – No external debugger required
+   - USB Powered – Ease of use, No external power required
+   - Socketed dsPIC/PIC24/PIC32 – Flexible, Easy device replacement
