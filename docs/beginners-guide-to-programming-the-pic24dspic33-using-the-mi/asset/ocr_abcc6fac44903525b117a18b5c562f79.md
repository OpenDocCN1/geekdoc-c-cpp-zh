The ADC module has a total of ten SFR Control and Status registers, a subset of which we will be using in our upcoming experiments. Let review this SFR content. We want in our experiments to be able to set the ADC for 12 bit single channel mode operation, no scanning, integer output, and manual mode trigger.

A block diagram of the ADC is shown for this type of configuration. Here only one S/H is active with the 12 bit ADC using only one input channel and no scanning. Our specific PIC24H, pre-configured in hardware with the Microstick II, doesn't have 16 analog channels but is limited to 8. These eight channels are AN0, AN1, AN4, AN5, AN9, AN10, AN11, and AN12.

Using the SFR setting for integer unsigned format for 12bits, the signal digital output format will vary from 0x0000 to 0x0FFF. This is typical for most single voltage input sensor values where 0 represents 0.0 volts and 0X0FFF represents +3.3 volts.
