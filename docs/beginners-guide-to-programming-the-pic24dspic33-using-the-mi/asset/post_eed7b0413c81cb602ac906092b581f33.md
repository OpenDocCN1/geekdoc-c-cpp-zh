Possible settings are AN0, AN1, AN4, AN5, AN9, AN10, AN11, and AN12. In this experiment, we will use AN0.

- `int readADC(int ANpin)` — This function forces a manual ADC conversion on the designated ANpin; again, we will use AN0.

The EEPROM library is really straightforward. Take a quick look at the functions listed below.

- `InitNVM()` — Initializes the Experimenter EEPROM for access. This must be called first before any other EEPROM library function is called. NVM stands for “Non-Volatile Memory.”
- `iReadNVM(address)` — Reads EEPROM at the specified address and returns the 16-bit value stored at that location.
- `iWriteNVM(address, data)` — Writes a 16-bit data value to EEPROM at the designated address.

The UART library functions used in the data logger are:

- `initU2()` — Initializes the serial port using UART2 of the PIC24F for pins 8 and 9 of the Experimenter expansion bus, with 9600 baud, 8-bit data, no parity, and 1 stop bit, or shorthand 9600 8N1.
- `putU2(character)` — Writes a character out to the serial port.
- `putsU2(string)` — Writes an entire string out to the serial port.
- `char getU2()` — Waits for a new character to arrive at the serial port and returns it.

Here are the five functions within the LCD driver. Their titles pretty much capture what they do.

- `LCD_Initialize()` — Initializes the LCD display and makes it ready for output. This needs to be called before any other LCD function is called.
- `clear_display()` — Clears the display and places the cursor at row 1, column 1 (top-left corner).
- `position_cursor(position)` — Places the cursor at the designated position, a number from 0–47.
- `write_string_LCD(string name)` — Writes a string to the display at the current cursor position (see explanation in text).
- `write_character_LCD(character)` — Writes a single character to the display at the current cursor position.

Here are the two button functions. Again, we try to keep things as straightforward as possible.

- **`RTCCProcessEvents()`** — The function grabs the current time from the RTCC and translates it into strings. It must be called periodically to refresh the time and date strings, `_time_str` and `_date_str`. Each string is 16 ASCII characters.

The above functions work directly with the RTCC without the advantage of the LCD and pushbuttons. Using the LCD and pushbuttons makes working with the RTCC a lot easier, and this is covered in Chapter 10 in this book for the 16 Experimenter.

## Demos That Come with PIC24F

The Experimenter comes with a P24FJ64GA002 that is preprogrammed with the following built-in demos. The demos were written using Microchip’s free MPLAB and PIC24 C code. The PIC24 C Compiler, MPLAB C30 v3.11b (or later), Student Edition, is free and was used for this demo. The link is below to download and see a full description of the compiler.

http://www.microchip.com/C30

Source code and a full demo description, as well as kit assembly instructions, are included on the Experimenter’s CD-ROM that comes with the kit. The demo starts as a revolving series of eleven different flash screens, each lasting about 4 seconds. The user invokes a specific functional demo by pushing one of the pushbuttons. Two of the introductory functional demos (digital thermometer and RGB LED) that come with the kit require some additional hardware and hookup as shown. A third functional demo (Clock) does not rely on any additional hardware.

These functional demos are intended to allow the user to gain familiarity with the Experimenter and ensure its proper operation after kit assembly. As mentioned earlier, they can be invoked using the pushbuttons anytime during the flash-screen displays and then can return to Flash Displays by simply pressing pushbutton S4.

## One Hundred Year Clock Calendar Demo

![](img/a9229e7b0ddd9608f171b22b52514f39_201_0.png)

Figure A-10: Clock Demo

Depressing pushbutton S3 initializes the Clock demo. This demo enters a mode where pushbuttons assume clock-setting and control operations for the internal 100-year real-time clock calendar. User options are: change the mode from clock display to clock setting and enter clock changes, stay in clock mode to simply display the clock, or exit clock mode back to “Flash Screens.” In order for this demo to work, you must have a 32 kHz crystal and two 33 pF capacitors connected to pins 11 and 12 of the PIC24F. The Experimenter provides this functionality. Designated button functions are as follows:

- Pushbutton S1 toggles between clock-run mode and clock-setting mode.
- Pushbutton S2, if in clock-setting mode, increments the current data field.
- Pushbutton S3, if in clock-setting mode, decrements the current data field.
- Pushbutton S4 advances to the next allowable data field if in clock-setting mode or, if pressed in clock-run mode, exits to “Flash Screens.”
