# RS-232 and RS-485 Industry Standard Serial Communications

There are several legacy industry standards for connecting equipment's that have UARTs. One of these standards for point to point communication is RS-232. This standard captures the connector types, baud rates, pin outs and voltage levels. RS-232 dictates that the voltage level from +3.3V to 0V of the PIC24H UART output must be modified to -12V to +12V to meet the standard. This means that voltage level changing electronics is needed. The RS-232 standard also uses a common connector set 9 PIN male and female connector pair. For RS-232 one side of the communication must be configured as DCE (data communications equipment) and the other as DTE (data terminal equipment). This partitioning establishes each side's transmitted and receives pin outs and connector type. The PC is pre-configured as DTE. This forces the PIC24H or Microstick II to be DCE.
