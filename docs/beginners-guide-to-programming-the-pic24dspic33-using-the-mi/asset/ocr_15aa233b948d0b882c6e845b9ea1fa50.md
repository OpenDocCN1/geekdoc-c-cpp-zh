# 1. Source Code- project view

+   - The source code is really the principal design. It is a .C file extension that is ANSI C compliant with the only exceptions being operations to Microchip processor specific function register (SFR) settings, and controls
+   - You can view the contents of the source code from the project view by double clicking the source code listing in the project view. -The source code Window will open up.
+   - Source code windows will open with the contents of source color code based upon language syntax. For example comments are green, C language elements are dark blue.
+   - In the source code window you have an editor that allows you to modify code or add new code
+   - In this source code there are several major components. The generic header file, configuration word, an additional function (that we incorporated to help modularize the code), and finally the Main function

# 2. Generic Header File

```
#include "p24hxxxx.h"  /* generic header for PIC24H family */
```

+   - This file is referenced in the Source code. It is known as a header file (has an .H extension). It was developed and supplied by Microchip. For our work it's internal definitions are needed in supporting reading/writing to the PIC24H microcontroller peripherals and I/O in a C language environment.
+   - The actual file exists outside our project and resides within the MPLAB C30 directory.
+   - This file contains reference to all the specific Microchip peripheral function and register definitions. This reference allows us to access Microchip SFR functions in a seamless matter with ANSI C complaint language components.

# 3. Configuration word

+   - These are C language macro (custom C language scripts) that set the configuration word. These macros are defined as part of the .H file. In this case individual scripts are used to fix the PIC24H CPU clock source to the internal RC oscillator and disable the main primary crystal oscillator.

```
_FOSCSEL(FNOSC_FRC);
_FOSC(FCKSM_CSDCMD & OSCIOFNC_ON & POSCMD_NONE);
_FWDT(FWDTEN_OFF);
```
