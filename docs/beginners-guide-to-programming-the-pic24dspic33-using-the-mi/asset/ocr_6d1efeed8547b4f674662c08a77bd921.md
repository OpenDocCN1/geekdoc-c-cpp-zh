As a reminder the benefits of PPS are as follows:

+   - Allows optimal usage of on-chip peripherals
+   - Any digital peripheral can remap to any RP pin
+   - Pin assignment is set in software
+     - Outputs assign a peripheral to a specific pin
+     - Inputs assign a pin to a specific peripheral
+     - Multiple input peripheral functions on one pin is supported
