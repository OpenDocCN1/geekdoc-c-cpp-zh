# Initializing PPS

Peripheral Pin Select or PPS has to be initialized, and once initialized it cannot be changed accidentally. To achieve this Microchip has instituted a specific sequence of steps that need to occur for PPS configuration.

Here's the basic idea; at the start of the main program, you can unlock, and configure the PPS for designated peripherals, first the outputs, and then the inputs. Once this is done the PIC24H is locked and remains with this pin state configuration. To do this the IOLOCK bit in the OSCON SFR register is set. Once set the PPS cannot be undone unless reset occurs. The PPS lock and unlock controls are really implemented as special code sequences to access the OSCON SFR. This insures that random code reads or writes cannot access and contaminate the fixed PPS settings. The general software flow is shown in Figure 7-7.
