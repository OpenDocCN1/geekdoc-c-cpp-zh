# Appendix A – 16 bit Experimenter Board

As introduced in Chapter 1 the optional 16 bit Micro Experimenter facilitates prototype exploration and testing of Microchip 16 bit PIC24HJ64GP502 Microcontroller with on board power, programming/debug interface, and peripheral support capabilities. The Experimenter, like the Microstick II, plugs into a Solderless Breadboard environment. The 16 bit Experimenter is available both in kit form and can be purchased assembled. A photo of the assembled kit and block diagram are shown. The Experimenter purchase is available through www.Kibacorp.com.
