Power can be applied to a DC barrel jack by a 9.1mm positive +6V to +9V wall transformer or optionally through a pin set designated as raw power located in lower left of the module. Incoming power is switched on/off to an on board +3V linear regulator. Power on condition is indicated by a green led. The Regulator +3.3V can also be made available to the Solderless environment through the upper board right Pin set.

The Software development tool set to use is the same MPLAB Integrated Development Environment (IDE) as used and explained with the Microstick II. However, different hardware is required for programming and debugging the Experimenter (this capability is built-in to the Microstick II).

The Microchip PICKIT 2 or PICKIT3 debugger and programmer are recommended low cost solutions. There is an install process, but once installed, the PICKIT2 or 3 is integrated to the IDE programming and debugging process. A quick 'set-up' guide comes with the Experimenter Kit CD-ROM. The PICKIT2/3 requires an In Circuit Serial Programmer interface (ICSP). Within the Experimenter the ICSP is conveniently located to the module's far right for easy Insertion.
