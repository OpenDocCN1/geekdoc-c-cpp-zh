# Timer 1 Experiment –non-Interrupt

There is a code snippet which shows how Timer 1 is initialized. The peripheral clock is the CPU internal clock divided by 2. In our case this is 8MHz / 2 or 4MHz. In this snippet the control bits for T1CON are set for internal, the prescaler to 256 giving us a final clock of (4MHz/256) or 15625 KHz. With preset set to 24999, the timer will generate interrupts every 1.6 seconds (1/15625)*24999. This time delay is sufficient for a number of application uses.

```
```c
TMR1 = 0;    // clear the timer
PR1 = 25000-1;  // set the period register
T1CON = 0x8030; // TMR1 on, prescale 1:256 Tclk/2
_T1IF =0;

Timer initialization is straightforward by writing to Timer SFR (Special Function Registers). The SFR here are TMRX-- the running counter, PRX --the preset value that TMRX will be compared against, and TXCON-- the timer control register. Where X =1, 2, 3, 4, 5 depending on what timer you elect to use.

TXCON contains TCS, TON, and prescaler as well as several other controls. A snapshot of TXCON is shown here. Follow along on the bit assignments and their specific assignments.
