# ### 可可果色

可可果色融合了天然可可的浓郁与醇厚，相比基础棕色的保守，它更给人一种充满复古感和高级调的腔调。极具包容度，适用于男女同款的设计，在西装外套、大衣以及冬季配饰上有更多的发挥空间。
