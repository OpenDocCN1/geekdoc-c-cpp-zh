# Review of I2C Key features:

+   - Only two bus lines are required (SCL –Clock, SDA-Data)
+   - No strict baud rate requirements like for instance with RS232, the master generates a bus clock
+   - I2C Communication is half-duplex, which means either a transmission or a reception can occur at a time.
+   - I2C uses synchronous communication, as both communicating entities use the same serial clock signal.
+   - I2C supports simple a master/slave relationship between all components on the same bus interface.
