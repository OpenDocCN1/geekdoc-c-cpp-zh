+   - Void turnon (int setting) -turn on RB2 pin output, Timer2 clock and the PWM OC1 configuration on this pin. The period of Timer2 is preset to 0x7FF the max value of the 12 bit ADC. Setting is any value set by the pot ADC between 0-0x7FF that adjusts the PWM duty cycle. If setting is 0 then duty cycle is zero, if setting is 0x3FF then duty cycle is 50%, if setting is 0x7FF then duty cycle is 100%
+   - Void setPWM (int setting) - This performs the same function of running turnoff (void) and turnon (int setting) with one call. This turns PWM off first before setting it.

There are also several ADC functions that we will use. These functions were introduced in Chapter 4 and are in the ADC library. If you need to, please review chapter 4 to gain an understanding of ADC.

+   - Void initADC (int ANpin) –this function initializes the ADC for 12 bit manual conversion using the "ANpin" as the single input pin. ANpin possible settings are AN0, AN1, An4, AN5, AN9, AN10, AN11, and AN12. In this experiment we will use AN0.
+   - Int readADC (int ANpin) –this functions forces a manual ADC conversion on the designated ANpin, again we will use AN0.
