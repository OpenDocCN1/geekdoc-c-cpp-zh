# Review of Key Application using LCD:

+   - LCD is a configurable intelligent device that is commanded by the PIC24H during application.

# Review of Source Code Key Features:

+   - Use of include directive makes the code highly modular and it this case an ADC driver library was introduced.
+   - Project contains multiple files for each driver where the explicit driver function are identified in .h and the body in .c
+   - Main just includes the .h its needs and can directly access all driver code
+   - Global variable identified before main function is accessible by all code
+   - Here we introduced another library function the LCD.
