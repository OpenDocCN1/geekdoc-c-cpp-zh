The 25LC256 uses an SPI interface to talk to the Microstick II PIC24H Microcontroller. For our experiment we use a software 'C' library where a SPI communication is supported with an easy to use API.

For this library each 25LC256 storage word is two bytes. Given the byte size of the 25LC256 this means we can store up to 16K words total. The double byte storage and retrieval makes sense since the PIC24H is a 16 bit machine. In general, for your experiments, you need to establish what data you want to store and how that data organized over 16K words. Figure 8-3 shows the physical EEPROM. It is an 8 pin DIP. You already can recognize the basic SPI signals /CS, SCK, SI and SO. In addition for this EEPROM there are additional control signals. There is a write protect (/WP) control line to physically lock out the Microcontroller from writing to the EEPROM. /HOLD suspends a command/data sequence, and puts the device in a suspended state that does not require restarting the sequence once /HOLD is released.

+   - CS – Chip Select
+   - SCK – Serial Clock
+   - SI – Serial Input
+   - SO – Serial Output
+   - WP – Write Protect
+   - HOLD – Hold Enable

# Experiment 1- Hardware

The PIC24H has user programmable PPS pins to place the I/O of any internal digital peripheral onto any of these pins. We will configure pins 18, 17, and 16 to function as the interface for SPI2, namely, SO, CLK and SI.
