# 16 bit Micro Experimenter (optional)

This is timer experiment for the 16 bit Micro Experimenter. This operates in an identical fashion to Experiment 1 and 2 in this chapter and in fact uses the same source code. You need to build the code and use either PICKIT2/3 as debugger/programmer. The Experimenter can be used with or without an external power supply if the PICKIT2 is used (the PICKIT2 senses power and automatically supplies power if not sensed). In addition the Experimenter needs an external LED with series resistor to be added to J3 PIN3 (see hookup diagram).

# Review of PIC24H Timers capability:

+   - Five 16 bit general purpose timers/counters
+     - Similar functionality between all 5 timers
+     - Period registers for each
+     - Interrupt generation on match with period
+     - Reset on match
+   - Four of these timers ( Timer 2+3 and 4+5) can make two 32 bit timers/counters
+   - In 32 bit operations :Timer 2+3 or Timer 4+5= Least Significant Word and Most Significant Word
