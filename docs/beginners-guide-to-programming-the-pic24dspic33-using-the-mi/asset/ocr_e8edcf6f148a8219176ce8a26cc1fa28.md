# Experiment 1- How it Works

The application uses a single C source file (main_led.c) that is a main function that references generic PIC24H headers/peripherals use (#include "pic24Hxxx.h"). This header will determine the specific PIC24H processor in use. The processor configuration is set using predefined C library macros (also referenced in the header file). These settings are internal CPU clock selection of 8Mhz, no external oscillator, no clock switch over, no watchdog operation, and finally use of RA3 as a digital/analog pin versus an external crystal pin input.

In the main function the application executes I/O initialization and then proceeds to enter a continuous loop for alternately turning on and then off the LED. A flow diagram of this specific LED display application is shown in Figure 2-5.
