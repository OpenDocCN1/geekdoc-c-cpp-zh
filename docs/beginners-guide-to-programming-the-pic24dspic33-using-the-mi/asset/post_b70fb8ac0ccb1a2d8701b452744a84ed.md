## Beginner's Guide to Programming the PIC24/dsPIC33

Thomas Kibalo, who has written many articles for Nuts & Volts magazine, delivers the beginner's book many have been looking for: Beginner's Guide to Programming the PIC24/dsPIC33. Using the low cost Microchip Microstick module with PIC24HJ128GP502 and the free to download lite version of MPLAB C Compiler for PIC24 MCUs and dsPIC MCUs, Kibalo takes you step by step through the fundamentals of programming the PIC24H which can be equally applied to the dsPIC33. His clear explanation of the inner workings makes learning the PIC24/dsPIC33 16-bit architecture easy. His code examples demonstrate how to perform the functions most applications require. The hardware is shown in simple breadboard setup so even a beginner can build along with very few extra components needed.

- Driving LEDs
- Reading momentary switch
- Analog to Digital Conversion
- Driving an LCD display
- Timers and Timer Interrupts
- Writing to/Reading from External EEPROM
- Serial RS232 communication
- SPI communication
- I2C communication
- Pulse Width Modulation
- Controlling the PIC24H Real Time Clock and Calendar

For those that don't want to build up the circuitry on a breadboard, Kibalo also shows you how to use his Experimenter board. The Experimenter Board (Kibacorp.com) is his own design with LCD, switches and other features built in. You don't have to use this hardware either. This book can be the guide for any PIC24H or even dsPIC33 development board you choose. If you wanted to move on to the Microchip 16-bit architecture this book gives you the path to get there with ease.
