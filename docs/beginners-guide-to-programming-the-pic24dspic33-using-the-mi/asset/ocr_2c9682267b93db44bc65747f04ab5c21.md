# Using USB instead of RS-232

With the proper interface a UART can still be used for USB as well as RS-232. If you're PC does not include an RS-232 port --no worries. A USB (Universal Serial Bus) port can easily be adapted to your serial communication needs. Again ACRONAME has a solution (S22), with an UART to USB Brainstem. All PIC24H to ACRONAME connections are identical to RS-232. We need to use a host to device USB cable to connect the PC to the ACRONAME.

Additional software configuration is needed. For USB, software INF files, and USB drivers will need to be installed on your PC--- ACRONAME, again, provides all software needed with their product. See Figure 7-18 for USB prototype.

When you first connect the USB-to-UART S22 ACRONAME interface, Windows will prompt you for a driver. Navigate to the ARCONAME supplied drivers that are supplied with the product and download these to your computer. Once installed it will essentially represent a new COM port (see Figure 7-21), beyond the earlier COM1 selected earlier. Use this new com port and then use the same HyperTerminal configuration procedure given earlier with this new COM port.
