# Experiment Application Library

The application library supports both low density and high density EEPROM. Low density refers to those devices that only require an 8 bit address and are under 256 Bytes. High density devices are 512 to 64K bytes and require 16 bits of address. The library supports both byte read/write as well as page (multi-byte) read/write. No additional libraries are required with the provided code. The firmware consists of two .c files (main.c, i2c_Func.c), along with an .h file organized into nine sections.

+   - Initialization
+   - Low Density Byte Write
+   - Low Density Byte Read
+   - Low Density Page Write
+   - Low Density Sequential Read
+   - High Density Byte Write
+   - High Density Byte Read
+   - High Density Page Write
+   - High Density Sequential Read
