void on_exit(void)

    printf("Normal exit--I won't be called!\n");

int main(void)
{
    at_quick_exit(on_quick_exit_1);

Which gives this output:
About to quick...
Quick exit handler 2 called!
Quick exit handler 1 called!
It works just like exit()/atexit(), except for the fact that file flushing and cleanup might not be done.

# 28.3 Nuke it from Orbit: _Exit

Calling Exit() exits immediately. No on-exit callback functions are executed. Files won't be flushed. Temp files aren't removed.
Use this if you have to exit right fargin

# 28.4 Exiting Sometimes: assert()

The assert() statement is used to insist that something is true, or else the program will exit.
Devs often use an assert to catch Should-Never-Happen type errors.
#define PI 3.14159

```
assert(PI > 3);
versus:
goats -= 100;
assert(goats >= 0);
```

In that case, if I try to run it and goats falls under 0, this happens:\goat_counter: goat.counter.c:8: main: Assertion 'goats >= 0' failed.\and I'm dropped to the command line.
This isn't very user-friendly, so it's only used for the user we will never see. And people write their own assert macros that can more easily be turned off.
