## 5.1 内存与变量

计算机内存存储各种数据，对吧？它会存储浮点数、整数或你拥有的任何内容。为了方便内存内存，内存的每个字节（byte）都由一个整数标识。当你移动内存移动时，这些整数按顺序增加。你可以把它看作一堆编号的盒子，每个盒子装着一个字节的数据。或者如果你来自有数组的语言，可以把它看作一个大数组，每个元素包含一个字节。代表每个盒子的数字被称为它的地址。

现在，并不是所有数据类型都使用字节。例如，`int` 通常是四个字节，`float` 也是如此，但它实际上取决于系统。你可以使用 `sizeof` 运算符来确定某种类型使用多少字节。

```
// zu 是 size_t 的格式指定符
```

```
printf("int uses %zu bytes of memory\n", sizeof(int));
```

```
// 在我这里它打印出 "4"，但随系统而异。
```

> 通常情况下。我确定在计算机历史那些黑暗的走廊里存在例外。
一个字节由最多 8 个二进制位（简称位，bits）组成。这意味着在像奶奶以前使用的十进制数字中，它可以存储一个 0 到 255（包含）之间的无符号数。

**内存冷知识：** 当你有一个使用多个字节内存的数据类型（比如典型的 `int`）时，组成数据的字节在内存中总是彼此相邻的。有时它们的顺序是你预期的，有时又不是。虽然 C 不保证任何内存顺序（它依赖于平台），但你仍然可以编写出与平台无关的代码，这样你就不需要考虑这些烦人的顺序了。

无论如何，如果我们能进入正题，让指针的定义伴随着一段鼓点和一些令人不安的魔法，那么，指针就是一个存储地址的变量。想象一下此时此刻，就像《2001 太空漫游》中的经典场景：Bam ba bam bam BAAAH！

好了，所以可能有点不知所措，指针并没有什么神秘的。它们是数据的地址。就像一个 `int` 可以存储值 12 一样，指针变量可以存储数据的地址。

这意味着所有这些词的意思相同，即一个代表内存中指针的数字：

- 内存索引（如果你把内存看作一个大数组）
- 地址
- 位置

我将交替使用这些词。我刚刚加了“位置”，因为意思相同的词你永远都不够。

而指针变量持有地址数字。就像一个 `float` 变量可能存储 3.14159。

想象你有一堆按地址顺序编号的便签纸。第一个是 `int 0`，下一个是索引 1，以此此类推。

除了代表位置的数字外，你还可以在每个纸上写另一个你选择的数字。你可以写剩余的天数，或者火星附近的月份……

……或者，它可能是另一个指针便签的索引！

如果你写的是你拥的数据数量，那就是普通变量。但如果你在里面写了另一个便签的索引，那就是一个指针。它指向另一张纸！

另一个类比可能是地址。你可以拥有一间具有特定属性的房子，金属屋顶、太阳能等。你拥有这间房子的地址。地址不等同于房子本身。一个是一个完整的房子，而另一个只是几行文本。但房子的地址是一个找到它所在位置的指针。它不是房子，但它告诉你去哪里找它。

我们可以在计算机里对数据这样做。你可以有一个存储某些值的数据变量。而值存储在内存的某个地址。你可以有一个不同的指针变量持有该变量的地址。

它不是数据变量本身，而是像指向数据的“指针”。它告诉我们去哪里找到它。

当我们拥有它时，我们说有一个指向数据的“指针”。顺着指针访问数据本身。

（尽管看起来不是特别有用，但它在与函数调用一起运行时变得不可或缺。耐心点，我们会讲那部分的。）

所以如果我们有一个 `int`，并且想要指向它的指针，那么获取该 `int` 地址的方法是什么，对吧？毕竟，指针持有数据的地址。你认为我们会用什么运算符来找到该 `int` 的地址？

嗯，一个让亲爱的读者感到震惊的意外惊喜是，我们使用取地址运算符（恰好是取地址符：`&`）来找到数据的地址。取地址符。

> 字节的顺序被称为数字的字节序（endianness）。常见的嫌疑人是大端序（以最高位字节在前为）和小端序（以最高位字节在最后为），或者现在常见的混合端序（以最高位字节在其他地方为）。

为了快速举个例子，我们将为 `printf()` 引入一个新的格式指定符——你可以打印一个指针。我们知道 `%d` 如何打印十进制整数吗？很好，`%p` 输出指针。现在，这个指针看起来会像一个垃圾数字（可能会以十六进制而不是十进制打印），但它仅仅是存储数据的内存索引。（如果数据是多字节的，则是存储数据第一个字节的内存索引）。在几乎所有情况下，包括在此处，打印出的数字实际值对你并不重要，我在这里展示它是为了演示取地址运算符。

```
#include <stdio.h>

int main(void)
{
    int i = 10;

    printf("The value of i is %d\n", i);
    printf("And its address is %p\n", (void *)&i);

    // %p 期望参数是 void 指
    // 所以我们进行强制转换让编译器满意
}
```

在我的电脑上，这打印出：
The value of i is 10
And its address is 0x7ffd072a4

如果你好奇，那个十六进制是十进制的 14072732696（像奶奶以前使用的十进制）。它是存储变量 i 的内存索引。它是 i 的地址。它是 i 的位置。它是指向 i 的指针。

再次，我们并不真正关心它的具体数字，通常我们只关心它是指向 i 的指针。

```

{
    int i; // i 的类型是 "int"
    int *p; // p 的类型是“指向 int 的指针”，或“int指针”
}
```
