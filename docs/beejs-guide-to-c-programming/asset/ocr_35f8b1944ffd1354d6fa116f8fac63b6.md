# Chapter 4. Functions

Before I forget, notice that I defined the function before I used it. If I hadn't done that, the compiler wouldn't know about it yet when it compiles main() and it would have given an unknown function call error. There is a more proper way to do the above code with function prototypes, we'll talk about that later.

Also notice that main() is a function!

It returns an int.

But what's this void thing? This is a keyword that's used to indicate that the function accepts arguments.
You can also return void to indicate that you don't return a value:

```
#include <stdio.h>
```

```
// This function takes no arguments and returns no value

void hello(void)
{
    printf("Hello, world!\n");
}

int main(void)
{
    hello(); // Prints "Hello, world!"
}
```

# 4.1 Passing by Value

I'd mentioned earlier that when you pass an argument to a function, a copy of that argument gets made and stored in the corresponding parameter.

If the argument is a variable, a copy of the value of that variable gets made and stored in the parameter.
More generally, the entire argument expression is evaluated and its value is determined. That value is copied to the parameter.

In any case, the value in the parameter is its own intent. It is independent of whatever values or variables you used as arguments when you made the function call.

So let's look at an example. Study it and see if you can determine the output before running it:

```
#include <stdio.h>

void increment(int a)
{
    a++;
}

int main(void)
{
    int i = 10;

    increment(i);

    printf("i == %d\n", i); // What does this print?
}
```
