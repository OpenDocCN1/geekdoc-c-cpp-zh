# Chapter 15. Types III: Conversions

Let's do an example where we convert a string to an unsigned long, discarding error information (i.e. information about bad characters in the input string):

```
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char *s = "3490";

    // Convert string s, a number in base 10, to an unsigned long int.
    // NULL means we don't care to learn about any error information.

    unsigned long int x = strtol(s, NULL, 10);

    printf("%lu\n", x); // 3490
}
```

Notice a couple things. Even though we didn't de capture any information about error characters in the string, strtol() won't give us undefined behavior; it will just return 0.
Also, we specified that this was a decimal (base 10) number.
Does this mean we can convert numbers of different bases? Sure! Let's go binary!

```
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char *s = "10110"; // What's the meaning of this number?

    // Convert string s, a number in base 2, to an unsigned long int.

    unsigned long int x = strtol(s, NULL, 2);

    printf("%lu\n", x); // 42
}
```

OK, that's all and games, but what's that NULL in there? What's that for?
That helps us figure out if an error occurred in the processing of the string. A pointer to a character, which sounds weird, but isn't once you wrap your head around it.
Let's do an example where we feed in a deliberately bad number, and we'll see how strtol() lets us where the first invalid digit is.

```
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char *s = "34X0"; // "X" is not a valid digit in base 10!
    char *badchar;

    // Convert string s, a number in base 10, to an unsigned long int.

    unsigned long int x = strtol(s, &badchar, 10);
```
