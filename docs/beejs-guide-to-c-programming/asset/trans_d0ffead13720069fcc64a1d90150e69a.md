

## 第 20 章 结构体 II：更有趣的结构体

由于联合体（union）的成员共享相同的内存，向其中一个成员写入必然影响其他成员。而且如果你从写入另一个成员的地方读取其中一个，你将得到一些奇怪的副作用。

```c
#include <stdio.h>
```

```c
union foo {
  float b;
  short a;
};

int main(void) {
  union foo x;

  x.b = 3.14159;

  printf("%f\n", x.b); // 3.14159, 理所当然

  printf("%d\n", x.a); // 但这个又是什么？
}
```

在我的系统上，它的输出是：
3.141590
4048

因为在底层，float 3.14159 的对象表示与 short 4048 的对象表示是相同的。在我的系统上是如此。你的结果可能会有所不同。

## 20.9.2 联合体的指针

如果你有一个指向联合体的指针，你可以将指针强制转换为联合体中任何字段类型的指针，并借此获取值。

在这个示例中，我们看到联合体内部包含整数和浮点数。我们获取指向联合体的指针，并将它们强制转换为 *int* 和 *float* 类型（强制转换会消除编译警告）。然后，如果对这些指针进行解引用，就会发现这些值是直接存储在联合体中的。

```c
#include <stdio.h>
```

```c
union foo {
  int a, b, c, d, e, f;
  float g, h;
  char i, j, k, l;
};

int main(void) {
  union foo x;

  int *foo_int_p = (int *)&x;
  float *foo_float_p = (float *)&x;

  x.a = 12;
  printf("%d\n", x.a);      // 12
  printf("%d\n", *foo_int_p); // 12，再次如此
}
```

反之亦然。如果我们有一个指向联合体内部类型的指针，可以可以将其转换为指向联合体的指针并访问其成员。

```c
union foo x;
int *foo_int_p = (int *)&x;      // 指向 int 字段的指针
union foo *p = (union foo *)foo_int_p;  // 回到指向联合体的指针

p->a = 12;                      // 这一行与...
x.a = 12;                        // 相同。
```

这一切告诉我们，在底层，联合体中的所有这些值都从内存中的同一个位置，这与整个联合体的位置相同。

## 20.9.3 联合体中的公共初始序列

如果你有一个结构体联合体，且所有这些结构体都以一个共同的初始序列开头，那么从该联合体的任何成员中访问该序列的成员是有效的。

什么？这里有两个具有公共初始序列的结构体：

```c
struct a {
  int x;           //
  float y;         // 公共初始序列
};

struct b {
  int x;           //
  float y;         // 公共初始序列

  double *p;
  short z;
};
```

你看到了吗？它们都以 int 开头，后面是 float——这就是公共初始序列。结构体序列中的成员必须是兼容的类型。我们在 x 和 y 上看到了这一点，它们相对而言是 int 和 float。

现在，让我们为这些结构体创建一个联合体：

```c
union foo {
  struct a sa;
  struct b sb;
};
```

这条规则告诉我们，我们可以保证公共初始序列的成员在代码中是可以互换的。也就是说：

- f.sa.x 等同于 f.sb.x。

以及

- f.sa.y 等同于 f.sb.y。

因为字段 x 和 y 都在公共初始序列中。

此外，公共初始序列中成员的名称并不重要——重要的是类型相同。

总而言之，这允许我们安全地在联合体中的结构体之间添加一些共享信息。这方面的最佳例子可能是使用一个字段来确定联合体中“正在使用”的结构体类型。

也就是说，如果我们不被这样做，并将联合体传递给某个函数，那么该函数如何知道联合体中的哪一个成员是它应该查看的呢？

看看这些结构体。注意它们的公共初始序列：

```c
#include <stdio.h>

struct common {
    int type; // 公共初始序列
};

struct antelope {
    int type; // 公共初始序列
    int loudness;
};

struct octopus {
    int type; // 公共初始序列

    int sea_creature;
    float intelligence;
};
```

现在，让我们把它们放入一个联合体：

```c
union animal {
    struct common common;
    struct antelope antelope;
    struct octopus octopus;
}
```

另外，请在演示中允许这两个 #define：

```c
#define ANTELOPE 1
#define OCTOPUS 2
```

到目前为止，这里还没有发生什么特别的事情。类型字段似乎完全没用。但现在让我们写一个打印联合体的通用函数。它必须以某种方式能够判断它看的是 struct antelope 还是 struct octopus。因为初始序列的魔力，它可以针对特定的联合体在这些任何一个地方查找类型：

```c
int type = x.common.type; // 或者...
int type = x.antelope.type; // 或者...
int type = x.octopus.type; // 或者...
```

它们都指向内存中的同一个值。

```c
void print_animal(union animal *x) {
    switch (x->common.type) {
        case ANTELOPE:
            printf("Antelope loudness=%d\n", x->loudness);
            break;
        case OCTOPUS:
            printf("Octopus sea_creature=%d\n", x->sea_creature);
            printf("intelligence=%f\n", x->intelligence);
            break;
            default:
            printf("Unknown type %s\n");
    }
}
```

```c
int main(void) {
    union animal a = {.type=ANTELOPE, .loudness=12};
    union animal b = {.type=OCTOPUS, .sea_creature=1, .intelligence=1.5};

    print_animal(&a);
    print_animal(&b);
}
```

## 20.10 匿名结构体

如果一个结构体没有名称，它被称为一个匿名结构体。你你不能像普通结构体那样声明它，但你可以在结构体或联合体内定义它。

```c
union foo {
  struct {
    int x;
    float y;
  } a;

  struct {
    int x;
    float y;
  } b;
};
```

在这个示例中，我们看到联合体内部有两个匿名结构体。我们通过成员名 `a` 和 `b` 来访问它们。

```c
union foo x;

x.a.x = 10;
x.a.y = 20.5;

printf("%d\n", x.a.x); // 10
printf("%f\n", x.a.y); // 20.5

x.b.x = 20;
x.b.y = 30.5;

printf("%d\n", x.b.x); // 20
printf("%f\n", x.b.y); // 30.5
```

这告诉我们，在底层，联合体中的所有这些值都从内存中的同一个位置开始，这与整个联合体的位置相同。

你也可以在结构体内部定义匿名结构体：

```c
struct foo {
  struct {
    int x;
    float y;
  } a;

  struct {
    int x;
    float y;
  } b;
};
```

这与联合体的情况是一样的。你可以通过成员名 `a` 和 `b` 来访问这些成员。

```c
#include <stdio.h>

struct foo {
  struct {
    int x;
    float y;
  } a;

  struct {
    int x;
    float y;
  } b;
};

int main(void) {
  struct foo s;

  s.a.x = 10;
  s.a.y = 20.5;

  printf("%d\n", s.a.x); // 10
  printf("%f\n", s.a.y); // 20.5

  s.b.x = 20;
  s.b.y = 30.5;

  printf("%d\n", s.b.x); // 20
  printf("%f\n", s.b.y); // 30.5
}
```

你还可以将匿名结构体的指针作为成员体：

```c
struct foo {
  struct {
    int x;
    float y;
  } *a;

  struct {
    int x;
    float y;
  } *b;
};

int main(void) {
  struct foo s;
  struct {
    int x;
    float y;
  } a1 = {10, 20.5};
  struct {
    int x;
    float y;
  } b1 = {20, 30.5};

  s.a = &a1;
  s.b = &b1;

  printf("%d\n", s.a->x); // 10
  printf("%f\n", s.a->y); // 20.5

  printf("%d\n", s.b->x); // 20
  printf("%f\n", s.b->y); // 30.5
}
```

你还可以在联合体内部定义匿名结构体：
