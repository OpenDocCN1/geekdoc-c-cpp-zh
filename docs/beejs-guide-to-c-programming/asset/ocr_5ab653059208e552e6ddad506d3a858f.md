```
#include <stdio.h>
```

int shared = 10; // File scope! Visible to the whole file after this!

```
void func1(void)
{
    shared += 100; // Now shared holds 110
}
```

```
void func2(void)
{
    printf("%d\n", shared); // Prints "110"
}
```

```
int main(void)
{
    func1();
    func2();
}
```

Note if shared were declared at the bottom of the file, it wouldn't compile. It has to be declared before any functions it use.

There are ways to further modify items at file scope, namely with static and extern, but we'll talk about those later.

# 13.3 for-loop Scope

I don't know what to call this. C11 §6.8.5.3 doesn't give it a proper name. We've already seen a few times in this

```
for (int i = 0; i < 10; i++)
    printf("%d\n", i);
```

printf("%d\n", i); // ILLEGAL--i is only in scope for the for-loop

In that example, i's lifetime begins the moment it is defined, and continues for the duration of the loop.

If the body is enclosed in a block, the variables defined in the for-loop are visible from that inner scope. Unless of course, that inner scope hides them. This crazy example prints 999 times:

```
#include <stdio.h>
```

```
int main(void)
{
    for (int i = 0; i < 5; i++) {
        int i = 999; // Hides the i in the for-loop scope
        printf("%d\n", i);
    }
}
```
