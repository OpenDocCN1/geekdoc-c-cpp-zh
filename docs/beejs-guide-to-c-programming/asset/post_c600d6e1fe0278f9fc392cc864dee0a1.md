## 2.3 Compilation Details

Let's talk a bit about how to build C programs, and what happens behind the scenes there.

Like other languages, C has source code. But, depending on what language you're coming from, you might never have had to compile your source code into an executable.

Compilation is the process of taking your source code and turning it into a program that your operating system can execute.

JavaScript and Python aren't used to a separate compilation step at all—though behind the scenes it is! Python compiles your source code into some bytecode that the Python virtual machine executes. Java devs are used to compilation, but that produces bytecode for the Java Virtual Machine.

When compiling C, machine code is generated. It is the 1s and 0s that can be executed directly and quickly by the CPU.

Languages that typically aren't compiled are interpreted. But for C, it is compiled into machine code. This is why C is so fast.

## 2.4 Compilation with GCC

When you want to compile C, you will likely use GCC (GNU Compiler Collection). It is a very common compiler on Unix-like systems.

To compile a file, you use the following command:

```
gcc hello.c -o hello
```

The `-o` flag tells GCC to name the output executable. If you don't use it, the output will be named `a.out`.

## 2.5 Compilation with Clang

If you're on a Mac, you might use Clang instead of GCC. The syntax is very similar:

```bash
clang hello.c -o hello
```

## 2.6 Compilation in IDEs

Many people use an Integrated Development Environment (IDE) like VS Code, CLion, or Xcode. These tools handle the compilation for you, but it's important to know what's happening underneath.

## 2.7 C Versions

C has come a long way over the years, and it has many version numbers. These generally refer to the year of the specification.

| Version | Description |
| --- | --- |
| K&R C | 1978, the original. Named after Brian Kernighan and Dennis Ritchie. |
| C89, ANSI C, C90 | In 1989, American National Standards Institute (ANSI) produced a C language specification that set the tone for C that persists today. |
| C99 | A major addition to C89 that included character support. |
| C11 | This major version includes Unicode support and multi-threading. |
| C17, C18 | Bugfree update to C17 seems to be the official name, but the publication was delayed until 2018. |
| C2x | What's coming next! Expected to eventually become C23. |
