# Chapter 15. Types III: Conversions

# 15.3.3 Integer and Floating Point Conversions

If a floating point is converted to an integer type, the fractional part is discarded with prejudice.

But—and here's the catch-catch—if the number is too large to fit in the integer, you get undefined behavior.
Don't do that.

Going From or floating point to floating point, C makes a best effort to find the closest floating point
number to that it can.

Again, though, if the original value can't be represented, it's undefined behavior.

# 15.4 Implicit Conversions

These are conversions the compiler does automatically for you when you mix and match types.

# 15.4.1 The Integer Promotions

In a number of places, if an int can be used to represent a value from char or short (signed or unsigned), that value is promoted to int. If it doesn't fit in an int, it's promoted to unsigned int.

This is how we can do something this:

```
char x = 10, y = 20;
int i = x + y;
```

In case, x and y get promoted to int by C before the match takes places.

The integer promotions take place during The Variadic Conversions, with Variadic functions⁵, unary + - operators, or when passing values to functions without prototypes⁶.

# 15.4.2 The Usual Arithmetic Conversions

These are automatic conversions that C does around numeric operations that you ask for. (That's actually what they're called, by the way, by C11 $6.3.1.8) Note that for this section, we're just talking about numeric types—strings will come.

These questions answer about what happens when you mix types, like this:

```
int x = 3 + 1.2;
// 4.2 is converted to int
// 4 is stored in x
```

```
float y = 12 * 2;
// Mixing float and int
// 24 is converted to float
// 24.0 is stored in y
```

Do you believe it? Do they become floats? How does it work?

Here are the steps, paraphrased for easy consumption.

+   1. If one in the expression is a float type, convert the other types to that float type.
2. Otherwise, if both types are integer types, perform the integer promotions on each, then make the operand as big they need to be the common largest value. Sometimes this involves signed to unsigned.
