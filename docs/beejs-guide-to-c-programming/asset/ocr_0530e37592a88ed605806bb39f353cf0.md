# 29.4 What We Actually Do?

Turns out we're pretty limited in what we can do and can't do in our signal handlers. This is one of the reasons why I say you not even bother with this and instead use your OS's signal handler instead (e.g. sigaction() for Unix-like systems).

Wikipedia goes so far as say the only reliable thing you can do is signal() with SIG_IGN or SIG_DFL and that's that.

Here's what we can't partially do:

+   Call any standard library function.
- printf(), for example.
- I think it's probably safe to call reentrant handlers, but the spec doesn't allow that liberty.
- Get or set values from a local state, file score, or thread-local variable.
- Unless it's a lock-free atomic object...
- You're assigning to a variable of volatile sig_atomic_t.

That last bit-sig_atomic_t--is your trick to getting data out of a signal handler (Unless you want to use lock-free atomic objects, which is outside the scope of this section.) It's an integer type that might or not be signed. And it's bounded by what you put in there.

You can look the minimum and maximum allowable values in the macros SIG_ATOMIC_MIN and SIG_ATOMIC_MAX.

Confusing, the spec also says you can't refer to "any object with static or storage duration that is not a lock-free atomic object other than assigning a value to an object declared as volatile sig_atomic_t"

My read on this is that you can read or write anything that's not a lock-free atomic object. You can also assign to an object that's volatile sig_atomic_t.

But can you read from it? Honestly don't see why, except that the spec is very pointed mentioning assigning. If you have to read it and make any kind of decision based on it, you might be opening room for kind of race conditions.

With that mind, we can rewrite our "CTRL-C to exit" to be a little more polite, albeit verbose on the output.

Let's choose our SIGINT handler to do nothing except increment a value's of type volatile sig_atomic_t. So we'll count the CTRL-cs that have been hit.

Then in our main loop, we'll check if that counter is over 2, then break out if it.
