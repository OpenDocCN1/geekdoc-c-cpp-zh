### 27.10 Parse State, Restartable Functions

We're going to get a little bit into the guts of multibyte conversion, which is a good thing to understand conceptually. Imagine your program tracks a sequence of multibyte characters and turns them into wide characters, or vice-versa. It might, at some point, partway through a character, it might have to wait for more bytes before it makes the determination of the final value.

This parse state is stored in an opaque variable mbstate_t and is used every time conversion is performed. That is how the conversion functions keep track of where they are mid-work. If you need to change a character mid-stream, or try to seek to a different place in your input sequence, it could get confused over that.

Now, one thing: we did some conversions, and I never mentioned any mbstate_t anywhere. That's because the conversion functions like mbstowcs(), wcstomb(), etc. each have their own mbstate_t variable that they use. There's only one function, though, if you're writing multithreaded code, they're not safe to use.

Fortunately, the standard library defines restartable versions of these functions where you can pass in your own mbstate_t per-thread if you need. If you're doing multithreaded stuff, use these!

Quick note on initializing an mbstate_t variable: just memset() it to zero. There's no built-in function to force it to be initialized.

```c
mbstate_t mbs;
// Set the state to the initial state
memset(&mbs, 0, sizeof(mbs));
```

Here is a list of restartable conversion functions—note the naming convention of putting "r" after the "from" type:

- mbrtowc() - multibyte to wide character
- wcrtomb() — wide character to multibyte
- mbstowcs() — multibyte string to wide character string
- wcstombs() — wide string to multibyte string

These are similar to their non-restartable counterparts, except they require passing a pointer to your own mbstate_t variable. And they modify the source pointer (to help you out if invalid bytes are found), so it might be useful to save a copy of the original.

Here's the example from earlier in the chapter reworked to pass your own mbstate_t.

```c
#include <stdio.h>
#include <stdlib.h>
#include <stddef.h>
#include <wchar.h>
#include <string.h>
#include <locale.h>

int main(void)
{
    // Get out of the C locale to one likely has the euro symbol
    setlocale(LC_ALL, "");

    // Original multibyte string with a euro symbol (Unicode point 20ac)
    char *mbs_string = "The cost is \u20ac.23"; // €1.23
    size_t mb_len = strlen(mbs_string);

    // Wide character array that will hold the converted string
    wchar_t wc_string[128]; // Holds up to 128 wide characters

    // Set up the conversion state
    mbsstate_t mbs;
    memset(&mbs, 0, sizeof(mbs)); // Initial state

    // mbsrtowcs() modifies the input pointer
    mbsrtowcs(wc_string, mbs_string, mb_len, &mbs);

    // (m_string processing logic truncated for brevity)
}
```
