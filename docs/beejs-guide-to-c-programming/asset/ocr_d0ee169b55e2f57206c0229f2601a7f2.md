# Chapter 19. The C Preprocessor

At first I thought that just using squirly braces would be enough, but there's a case where it fails if the coder puts a semicolon after the macro. Here's that case:

```
#include <stdio.h>
```

```
#define F0(x) { (x)++ };
```

```
int main(void)
{
    int i = 0;

    if (i == 0)
        F0(i);
    else
        printf(":\\n");
}
```

Looks simple enough, but it won't build without a syntax error:
foo.c:11:5: error: 'else' without a previous 'if'
Do you see it?
Let's look at the expansion:

The ; puts an end to the statement, so the else is floating out there illegally.
