# 21.1.3 Numeric Escapes

In addition, there are ways to specify numeric constants or other character values inside strings or characternconstants.

If you know an octal or hexadecimal representation of a byte, you can include that in a string or characterconstant.

The following table has example numbers, but any hex or octal numbers may be used. Pad with leading zerosnnecessary to read the proper digit count.

| Code | Description |
|---|---|
| \123 | Embed the byte with octal value 123, 3 digits exactly. |
| \x4D | Embed the byte with hex value 4D, 2 digits. |
| \u2620 | Embed the Unicode character at code point with hex 2628, 4 digits. |
| \u0001243F | Embed the Unicode character at code point with hex 1243F, 8 digits. |

Here's an example of the less-commonly used octal notation to represent the letter B between A and C.Normally this would be used for some kind of unprintable character, but we have other ways to dothat, and this is just an octal example:

```
printf("\A102\n"); // 102 IS 'B' in ASCII/UTF-8
```

Note there is no leading zero on the octal number when you use this way. But it needs to be threecharacters, so pad with leading zeros if you need to.
But far more common is to use hex constants days. Here's a demo that you shouldn't use, but it demembedding the UTF-8 bytes 0xE2, 0x80, and 0xA2 in a string, which corresponds to the Unicode “bulletcharacter+).

```
printf("\xE2\x80\xa2 Bullet 1\n");
printf("\xE2\x80\xa2 Bullet 2\n");
printf("\xE2\x80\xa2 Bullet 3\n");
```

Produces the output if you're on an UTF-8 console (or probably garbage if you're not):

+   - Bullet 1
- Bullet 2
- Bullet 3

But that's a crappy way to do Unicode. You can use the escapes \u (16-bit) or \u (32-bit) to just refernUnicode by code point. The bullet is 2022 (hex) in Unicode, so you can do this and get more portableresults:

```
printf("\u2022 Bullet 1\n");
printf("\u2022 Bullet 2\n");
printf("\u2022 Bullet 3\n");
```

Be sure to pad \u with enough leading zeros to get to four characters, and \u with enough to get eight.
For example, that bullet could be done with \U and leading zeros:

```
printf("\U00002022 Bullet 1\n");
```
