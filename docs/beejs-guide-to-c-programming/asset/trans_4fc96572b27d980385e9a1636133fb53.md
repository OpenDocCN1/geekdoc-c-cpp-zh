
# 第 27 章.Unicode、宽字符及其其他

```c
char *s = "\u20AC1.23";
```

```
printf("%s\n", s); // €1.23
```

但我们正在遇到一些奇怪的情况，请看这里：

```c
char *s = "\u20AC1.23"; // €1.23
```

```
printf("%zu\n", strlen(s)); // 7!
```

"€1.23" 的字符串长度是 7 吗？是的！在我的系统上是。记住 `strlen()` 返回的是字符串中的**字节数**，而不是**字符数**。（当我们后面读到“宽字符”时，我们将看到一种获取字符数的方法）。

注意，C 允许单个多字节字符（与 `char*` 不同），其行为取决于实现方式，你的编译器可能会对此你发出警告。

例如，GCC 对以下两行中的多字符常量的处理（在我的系统上，它打印出 UTF-8 编码）：

```c
printf("%s\n", '€');
```

```c
printf("%s\n", "\u20AC");
```

## 27.7.2 宽字符

如果你不是多字节字符，那么你就是宽字符。

宽字符是一个单一值，可以唯一表示当前区域（locale）中的任何字符。它类似于 Unicode 代码点。但它可能不是。或者它可能是。

基本上，多字节字符是字节数组，而宽字符字符串是字符数组。因此，你可以开始以逐字符为单位进行思考，而不是以字节为单位（当字符开始占用不同数量的字节时，后者会变得非常混乱）。

宽字符可以用多种类型表示，但最引人的是 `wchar_t`。它是主要的类型。它就像 `char`，只不过是宽的。

你可能在想它是否为 Unicode，以及 C 如何允许你在编写代码时拥有如此大的灵活性？`wchar_t` 开启了一些大门，因为有一组可以与 `wchar_t` 使用的丰富函数（如获取长度的字符串等），而无需关心编码。

## 27.8 使用宽字符和 wchar_t

该轮到新的一回合了：`wchar_t` 是这种主要的宽字符类型。记得 `char` 只有一个字节吗？而字节可能不足以表示所有可能的字符吗？嗯，这个类型就可以了。

要使用 `wchar_t`，请包含 `<wchar.h>`。

它是多少字节的？这并不完全清楚。它可能是 16 字节，也可能是 32 字节。

但等一下，你说——如果只有 16 字节，还不足以容纳所有的 Unicode 代码点，对吧？你是对的——确实不足。规范并没有要求。它只需要能够表示当前区域中的所有字符。

这在具有 16 位 `wchar_t` 的平台上（如 Windows）可能会导致 Unicode 出现麻烦。但这超出了本指南的范围。

你可以使用 `l` 前缀声明这种类型的字符串或字符：

```c
printf("%ls %lc\n", s, c);
```

现在——这些字符是存储为 Unicode 代码点，还是不是？取决于实现。但如果它们使用了宏 `_STDC_ISO_10646__`，你就可以测试它们。如果是，答案就是：“它是 Unicode！”
更详细地说，宏中的值是一个 `yyym` 年份整数，让你知道可以依赖哪种 Unicode 标准——取决于该日期生效的是哪一个。

### 27.8.1 多字节到 wchar_t 的转换

那么我们如何从面向字节的字符串转换为面向字符的宽字符串并反之呢？
我们可以可以使用字符串转换函数来实现。
首先，你会在这些函数中看到一些命名约定：

- mb: 多字节 (multibyte)
- wc: 宽字符 (wide character)
- mbs: 多字节字符串 (multibyte string)
- wcs: 宽字符字符串 (wide character string)

所以如果我们想将多字节字符串转换为宽字符，可以调用 `mbstowcs()`。反过来：`wcstombs()`。

| 转换函数 |  |
|---|---|
| mbtowc() | 将多字节字符转换为宽字符。 |
| wctow() | 将宽字符转换为多字节字符。 |
| mbstowcs() | 将多字节字符串转换为宽字符串。 |
| wcstombs() | 将宽字符串转换为多字节字符串。 |

让我们做一个快速演示，将一个多字节字符串转换为宽字符，并使用各自的函数比较两个字符串的长度。

```c
#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>
#include <string.h>
#include <locale.h>

int main(void)
{
    // 离开 C 区域进入可能包含欧元符号的区域
    setlocale(LC_ALL, "");

    // 带有欧元符号的原始多字节字符串（Unicode 点 20ac）
    char *mb_string = "The cost is \u20ac1.23"; // €1.23
    size_t mb_len = strlen(mb_string);

    // 用于存储转换字符串的宽字符数组
    wchar_t wc_string[128]; // 保存最多 128 个宽字符

    // 将 MB 字符串转换为 WC；返回宽字符的数量
    size_t wc_len = mbstowcs(wc_string, mb_string, 128);

    // 打印结果——宽字符字符串使用 %ls
    printf("multibyte: %s (%zu bytes)\n", mb_string, mb_len);
    printf("wide char: %ls (%zu characters)\n", wc_string, wc_len);
}
```

在我的系统上，输出是：
"The cost is €1.23" (19 字节)
wide char: "The cost is €1.23 (17 字符)"

你的系统字节数取决于你的区域设置。
