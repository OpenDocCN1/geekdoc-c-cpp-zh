The CMPLX() macros work on double types. There are two macros for float and long double: CMPXFL() and CMPXLL(). (These “f” and “l” suffixes appear in all the complex-number-related functions.)

Now let's reverse the: if we have a complex number, how do we break it into its real and imaginary parts?

Here we have couple functions that will extract the real and imaginary parts from the number: creal() and cimag().n

```
double complex x = 5 + 2*I;
double complex y = 10 + 3*I;
```

```
printf("x = %f + %fi\n", creal(x), cimag(x));
printf("y = %f + %fi\n", creal(y), cimag(y));
```

for the output:

```
x = 5.000000
y = 10.000000
```

Note that the i have in the printf format string is a literal that gets printed—it's not part of the format specifier. Both return values from creal(x) and cimag() ) are double.

And as usual, there are float and long double variants of these functions: creal(), cimag(), creall(), and cimag().
