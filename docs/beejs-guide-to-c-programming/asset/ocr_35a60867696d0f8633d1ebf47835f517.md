# 20.1 Initializers of Nested structs and Arrays

Remember how you could initialize structure members among these lines?

```
struct foo x = {.a=12, .b=34};
```

Turns out we have more in these initializers than we'd originally shared. Exciting!

For one thing, if you have a nested structure like the following, you can initialize members of substructure by following the variable names down the line:

```
struct foo x = {.a.b.c=12};
```

Let's look at an example:

```
#include <stdio.h>

struct cabin_information {
    int window_count;
    int o2level;
};

struct spaceship {
    char *manufacturer;
    struct cabin_information ci;
};\n
int main(void) {
    struct spaceship s = {
        .manufacturer="General Products",
        .ci.window_count = 8, // <-- NESTED INITIALIZER!
        .ci.o2level = 21
    };
}
```
