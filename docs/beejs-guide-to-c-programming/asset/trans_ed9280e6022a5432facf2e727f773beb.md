## 38.5 使用 timespec_get() 获取更高的分辨率

你可以使用 `timespec_get()` 获取自 Epoch 来的秒数和纳秒数。可能吧。

某些实现可能没有纳秒级分辨率（那是秒的十分之一），所以谁知道你能得到多少位有效数字，试一试吧。

`timespec_get()` 接受两个参数。一个是指向 `struct timespec` 结构体的指针，用于存储时间信息。另一个是基准（base），规范允许你将其设置为 `time_UTC`，表示你对自 Epoch 来的秒数感兴趣（其他实现可能会为你提供更多基准选项）。而该结构体本身包含两个字段：

```c
struct timespec {
    time_t tv_sec;   // 秒
    long tv_nsec;    // 纳秒（秒的十分之一）
};
```

这里是一个示例，我们获取时间并以整数值和浮点值的形式打印：
struct timespec ts;

```c
timespec_get(&ts, TIME_UTC);

printf("%ld %ld ns\n", ts.tv_sec, ts.tv_nsec);

double float_time = ts.tv_sec + ts.tv_nsec/1000000000.0;
printf("%f seconds since epoch\n", float_time);
```

示例输出：
161481530, 806326800 ns
161481530.806326 seconds since epoch

`struct timespec` 也出现在其中一个线程函数中，该函数需要能够指定具有该分辨率的时间。

## 38.6 时间之间的差异

关于获取两个 `time_t` 之间差异的一个快速说明：由于规范没有规定类型如何表示时间，你可能无法相减两个 `time_t` 并得到任何有意义的结果。

幸运的是，你可以使用 `difftime()` 来计算两个日期之间的秒数差。

在下面的示例中，我们有两个在某个时间之后发生的事件，我们使用 `difftime()` 来计算差。

```c
#include <stdio.h>
#include <time.h>

int main(void) {
    struct tm time_a = {
        .tm_year=82,      // 自 1900 年来的年数
        .tm_mon=3,         // 自 1 月起的月份数 -- [0, 11]
        .tm_mday=12,       // 月中的几几 -- [1, 31]
        .tm_hour=4,        // 自午夜起的小时数 -- [0, 23]
        .tm_min=0,         // 小时后的分钟数 -- [0, 59]
        .tm_sec=04,        // 分钟后的秒数 -- [0, 59]
    };
    printf("%f\n", difftime(time(NULL), mktime(&time_a        .tm_isdst=-1,     // 夏令时标志
    };

    struct tm time_b = {
        .tm_year=82,      // 自 1900 年来的年数
        .tm_mon=10,         // 自 1 月起的月份数 -- [0, 11]
        .tm_mday=15,       // 月中的几几 -- [1, 31]
        .tm_hour=4,        // 自午夜起的小时数 -- [0, 23]
        .tm_min=30,         // 小时后的分钟数 -- [0, 59]
        .tm_sec=00,        // 分钟后的秒数 -- [0, 59]
        .tm_isdst=-1,     // 夏令时标志
    };

    time_t cal_a = mktime(&time_a);
    time_t cal_b = mktime(&time_b);

    double diff = difftime(cal_b, cal_a);
    printf("%f seconds\n", diff);

    return 0;
}
```

# 39. 多线程 (Threading)

线程 允许你在同一个进程中运行多个执行流。C11 引入了它们，但 POSIX 线程更常见。

## 39.1 背景

线程是允许你在同一个进程中运行多个执行流的方式。稍后会讨论。让我们看看基础。

## 39.2 你可以做的事情

你可以创建一个线程。它将在你指定的函数上执行。

而且你可以等待线程完成。这被称为连接（join）。或者如果你不在乎线程何时完成，你可以分离它（detach）。线程也可以通过从函数返回来退出。主程序也是线程。

## 39.3 数据竞态与标准库

标准库中的某些函数返回或使用非线程元素。但通常情况下，除非另有说明，标准库会努力做到。

但要留意。如果一个线程维护了你不拥有的状态，或者一个函数返回了你没有传入的指针，它是不安全的。

## 39.4 创建和等待线程

让我们来写点东西！

我们将创建线程并等待它们完成。

首先我们需要理解：`thrd_t` 类型的不透明变量来标识线程。它是程序中线程的唯一标识符。当你创建一个线程时，它会被赋予一个新的 ID。

所以基本想法是：

-. 编写一个函数作为线程的“主”。它不是真正的 `main()`，但类似的。线程将从那里开始运行。
-. 从主线程通过 `thrd_create()` 启动新线程，并传递要运行的函数指针。
-. 在该函数中，线程将执行它需要做的事。
-. 与此同时，主线程可以继续做它需要的事。
- 当主线程决定退出时，它可以通过 `thrd_join()` 等待子线程完成以清理它，否则会泄漏内存。
