### 27.10 解析状态、可重启动函数

我们将稍微深入多字节转换的内部原理，这在概念上是有帮助理解的。想象你的程序正在跟踪一个多字节字符序列并将其转换为宽字符，或者反之。在某个某一点，即在处理字符的途中，它可能需要等待更多的字节才能确定最终的值。

这种解析状态存储在一个不透明的变量 `mbstate_t` 中，并在每次执行转换时使用它。这就是转换函数如何跟踪其工作中间位置的。如果你需要在流中途更改字符，或者尝试跳转到输入序列中的不同位置，它可能会因此困惑。

现在有一点：我们做了一些转换，但我从未在地方提到过 `mbstate_t`。这是因为像 `mbstowcs()`、`wcstomb()` 等转换函数每个都有它们使用的 `mbstate_t` 变量。不过，如果你正在编写多线程代码，这些函数是不安全的。

幸运的是，标准库定义了这些函数的可重启动版本，如果你需要，可以按线程传递自己的 `mbstate_t`。如果你在处理多线程事务，请使用这些！

关于初始化 `mbstate_t` 变量的说明：只需使用 `memset()` 将其置零即可。没有内置函数可以强制对其初始化。

```c
mbstate_t mbs;
// 将状态设置为初始状态
memset(&mbs, 0, sizeof(mbs));
```

以下是可重启动转换函数的列表——注意其在 "from" 类型后添加 "r" 的命名约定：

- `mbrtowc()` 多字节到宽字符
- `wcrtomb()` 宽字符到多字节
- `mbstowcs()` 多字节字符串到宽字符字符串
- `wcstombs()` 宽字符串到多字节字符串

这些与非重启动版本相似，区别在于它们要求传递自己的 `mbstate_t` 变量。而且它们会修改源指针（在发现无效字节时提供帮助），因此保存原始数据的副本可能是用的。

这里是本章之前的示例重构，以传递自己的 `mbstate_t`：

```c
#include <stdio.h>
#include <stdlib.h>
#include <stddef.h>
#include <wchar.h>
#include <string.h>
#include <locale.h>

int main(void)
{
    // 从 C 区域切换到一个可能包含欧元符号的区域
    setlocale(LC_ALL, "");

    // 带有欧元符号的多字节字符串（Unicode 点 20ac）
    char *mbs_string = "The cost is \u20ac.23"; // €1.23
    size_t mb_len = strlen(mbs_string);

    // 用于存储转换字符串的宽字符数组
    wchar_t wc_string[128]; // 保存最多 128 个宽字符

    // 设置转换状态
    mbstate_t mbs;
    memset(&mbs, 0, sizeof(mbs)); // 初始状态

    // mbsrtowcs() 会修改输入指针
    mbsrtowcs(wc_string, mbs_string, mb_len, &mbs);

    // (m_string 处理逻辑省略)
}
```
