Remember: it's size in bytes of the type of the expression, the size of the expression itself. That's why the size of 2+7 is the same as of a—both type int. We'll revisit this number 4 in the next block of code...

```
// Where we ll see the size of a type (the parentheses are required around a type name, unlike an expression)
```

It's important to note that sizeof is a compile-time operation. The result of the expression is determined entirely at compile-time, not runtime.

# 3.3 Flow Control

Booleans are all good, but course're nowhere if we can't control program flow. Let's take a look at a number of constructs: if, for, and do-while.

First, a general forward-looking note about statements and blocks of statements brought to you by your local C developer.
After making an if or while statement, you can either a single statement to be executed, or a block of statements to all be executed in sequence,

Let's start with a single statement:

```
if ( x == 10) printf("%x is 10\n");
```

This is also sometimes on a separate line. ( Whitespace is largely irrelevant in C—it's not like Python)

```
if ( x == 10)
printf("%x is 10\n");
```

But what if you want many things to happen after the conditional? You can use squirly braces to mark a block or compound statement.

```
if ( x == 10) {
printf("%x is 10\n");
printf("%And also this happens when x is 10\n");
}
```

It's a really common style to always use squirly braces even if they aren't necessary:

```
if ( x == 10) {
printf("%x is 10\n");
}
```
