# 7.5 Getting String Length

You can't, C doesn't track it for. And when I say "can't", I actually mean "can1". There's a function in <string.h> called strlen() that can be used to compute the length of any string in bytes.

```
#include <stdio.h>
#include <string.h>
```

```
int main(void)
{
    char *s = "Hello, world!";
    printf("The string is %zu bytes long.\n", strlen(s));
}
```

The strlen() function returns size_t, which is an integer type you can use for integer math.
print size_t with %zu.

The above program prints:

The string is 13 bytes long.

Great! So it is possible to get the string length!

# 7.6 String Termination

C strings a little differently than many programming languages, and in fact doesn't almost everynmodern programming language.

When you're making a language, you have two options for storing a string in memory:

+   1. Store the bytes of the string along with a number indicating the length of the string.
2. Store the bytes of the string, and mark the end of the string with a special byte called the terminator.

If you wants longer than 255 characters, one requires at least two bytes to store the string. Whereas
option 2 only requires two bytes to terminate the string. So a bit of saves there.

Of course, this seems ridiculous to worry about saving a byte (or 3—lots of languages will happennlet you have strings that are 4 gigabytes in length). But back in the day, it was a bigger deal.
