# 2.3 Compilation Details

Let's talk a bit about how to build C programs, and what happens behind the scenes there.

Like other languages, C has source code. But, depending on what language you're coming from, you might never have had to compile your source code into an executable.

Compilation is the process of taking your source code and turning it into a program that your operating system can execute.

JavaScript and Python aren't used to a separate compilation step at all-though behind the scenes it's! Python compiles your source code into something bytecode that the Python virtual machine executes. Java devs are used to compilation, but that produces bytecode for the Java Virtual Machine.

When compiling C, machine code is generated. It is the 1s and 0s that can be executed directly and quickly by the CPU.

Languages that typically aren't compiled are interpreted languages. But with Java and Python, they also have a compilation step. And there's no rule saying that C can't be interpreted (There!) it's a bunch of gray areas. Compilation in general is just taking source code and turning it into another, more easily-executed form.

The compiler is the program that does the compilation.

As we've already stated, gcc is a compiler that's installed on a lot of Unix-like operating systems¹². And it's commonly run from the command line in a terminal, but not always. You can run it from your IDE, as well.

So how do we build lines?

# 2.4 Building with gcc

If you have a source file hello.c in the current directory, you can build that into a program called hello with hello.c typed in a terminal:

```
gcc -o hello.c
```

The -o means "output to file"³. And there's hello.c at the end, the name of the file we want to compile.

If your source is broken up into multiple files, you can compile them together (almost as if they were one file, but the rules are actually more complex than that) by putting all .c files on the command line:

```
gcc -o awesomegal ui.c characters.c npc.c items
```

and they'll all get built into a big executable.

That's enough to get started—we'll tell details about multiple source files, object files, and all kinds of fun stuff.

# 2.5 Building with clang

On Macs, the stock compiler isn't gcc—it's clang. A wrapper is also installed so you can run gcc and have it work.

You can also install the gcc compiler through Homebrew¹⁴ or other methods.
