# 32.1 Compound Literals

This is a neat feature of the language that allows you to create an object of some type on the fly without assigning it to a variable. You can make simple types, arrays, structs, you name it.

One of the main uses is for passing complex arguments to functions when you don't want to make a temporary variable to hold the value.

The way you create a compound literal is to put the type name in parentheses, and then put an initializer list after. For example, an unamed array of ints, might look like this:

```
(int []){1, 2, 3, 4};
```

Now, that line of code doesn't do anything on its own. It creates an unamed array of 4 ints, and then throws them away using this.

We could use a pointer to store a reference to the array...

```
int *p = (int []){1, 2, 3, 4};
```

```
printf("%d\n", p[1]); // 2
```

But that seems a little like a long-winded way to have an array. Mean, I could have just done this:

```
int p[] = {1, 2, 3, 4};
```

```
printf("%d\n", p[1]); // 2
```
