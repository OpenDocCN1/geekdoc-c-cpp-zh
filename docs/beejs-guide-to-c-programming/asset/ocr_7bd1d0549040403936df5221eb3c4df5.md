If you first use a wide operation (like `fwprintf()`) it will orient the stream wide.

If you first use a byte operation (like `printf()`) it will orient the stream by bytes.

You can manually set an unoriented stream one way or another with a call to `fget()`. You can use that same function to get the orientation of a stream.

If you need to change the orientation mid-flight, you can do it with `freopen()`.
