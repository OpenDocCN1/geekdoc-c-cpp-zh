

## 第19 章
## C 预处理器

在你的程序编译之前，它实际上会通过一个名为预处理的阶段。这几乎就像在 C 语言之上有一层先运行的语言。它输出 C 代码，然后对这些代码进行编译。

我们之前在 `#include` 中已经某种程度上见过这一点！这就是 C 预处理器！当它看到指令时，它会在该处包含命名的文件，就像你直接把它写在那里一样。然后编译器会构建整个程序。

但事实证明，它的功能远比包含文件强大得多。你可以定义会被替换的宏……甚至可以定义可以带参数的宏！

### 19.1 #include

让我们从已经见过很多次的内容开始。这当然是将其他源包含到你的源码中的方法。非常常用的头文件。

虽然规范允许 `#include` 有各种行为，但我们将采取一种更务实的方法，讨论它在我见过的每个系统上的工作方式。

我们可以将头文件分为两类：系统和本地。对于内置的内容，如 `stdio.h`、`stdlib.h`、`math.h` 等，你可以使用角括号包含：

```c
#include <stdio.h>
#include <stdlib.h>
```

这当然意味着必须有一种方法从当前目录包含本地文件。这种方法就是：使用双引号：

```c
#include "header.h"
```

或者你很有可能使用正斜杠包含相对目录文件文件如下：

```c
#include "mydir/header.h"
#include "../someheader.py"
```

不要在你的 `#include` 中使用反斜杠 (\) 作为路径分隔符！那是未定义行为！请仅使用正斜杠 (/)，即使在 Windows 上也是如此。

总结来说，系统包含使用角括号（`< >`），你的个人包含使用双引号（`"`）。

### 19.2 简单宏

宏是一个标识符，它在编译器看到它之前就会展开为另一段代码。把它想象成一个占位符——当预处理器看到这些标识符之一时，它将其替换为你定义的另一个值。

使用 `#define`（通常读作 "pound define"）来操作。这里有一个例子：

```c
#include <stdio.h>

#define HELLO "Hello, world"
#define PI 3.14159

int main(void)
{
    printf("%s, %f\n", HELLO, PI);
}
```

在第 3 行和第 4 行我们定义了宏。当它们在代码的其他地方（第 8 行）出现时，会被替换为定义的值。

从编译器的角度来看，这就像我们写的是这些：

```c
#include <stdio.h>

int main(void)
{
    printf("%s, %f\n", "Hello, world", 3.14159);
}
```

看到 `HELLO` 被替换为 `"Hello, world"`，`PI` 被替换为 `3.14159` 了吗？从编译器的角度来看，这些值就像直接出现在代码中一样。如果生成的 C 代码无效，编译器就会报错。

注意，宏本身并没有特定的类型。实际上发生的是，它们被整体替换为它们被 `#define` 定义的任何内容。

你也可以定义一个没有值的宏：

```c
#define EXTRA_HAPPY
```

在这种情况下，宏是存在且已定义的，但被定义为空。因此它在文本中出现的地方会被替换为空。我们稍后会看到它的用途。

按照习惯，宏名称通常使用全大写（ALL_CAPS），尽管这在技术上并不是要求的。

总的来说，这提供了一种定义常量值的方法，这些值实际上是全局的，可以在任何地方使用。即使在常量变量不起作用的地方，例如在 `switch` 分和固定数组长度中。

尽管如此，网上一直争论在一般情况下，带类型的 `const` 变量是否比 `#define` 宏更好。

它还可以用于替换或修改关键字，这是一个对于 `const` 完全陌生的概念，尽管这种做法应该谨慎使用。

### 19.3 条件编译

可以引导预处理器决定是否向编译器呈现某些代码块，或者在编译之前直接将其完全删除。

我们基本上通过将代码封装在条件块中来实现此点，类似于 `if-else` 语句。

#### 19.3.1 Defined, #ifdef 和 #endif

首先，让我们尝试根据宏是否被定义来编译代码。

```c
#include <stdio.h>
```

```c
#define EXTRA_HAPPY

int main(void)
{
    #ifdef EXTRA_HAPPY
        printf("Im extra happy!\n");
    #endif

    printf("OK!\n");
}
```

在示例中，我们定义了 `EXTRA_HAPPY`（为空，但它是被定义的），然后在第 8 行我们使用 `#ifdef` 指令检查它是否被定义。随后的代码会被包含，直到 `#endif`。

因为被定义了，代码将被纳入编译，输出将是：

I'm extra happy!
OK!

如果我们注释掉 `#define`，如下：

```c
//define EXTRA_HAPPY
```

那么它就不会被定义，代码也不会被包含。
