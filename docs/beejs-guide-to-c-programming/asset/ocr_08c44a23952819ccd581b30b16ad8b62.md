# Chapter 23. Pointers III: Pointers to Pointers and More

Straightforward enough, right? We have two types represented: int and int*, and we set up p to point to x. Then we dereference p on line 8 and print out the value 3490.

But, like we said, we can have a pointer to any variable... so that means we can have a pointer to p?
in other words, what type is this expression?

```
int x = 3490; // Type: int
int *p = &x;    // Type: pointer to an int
```

&p // <-- what is the address of p? AKA a pointer to p?
 x is int, then &x is a pointer to an int that we've stored in p which is type int*. Follow (Repeat this paragraph until you do!)

And therefore p is a pointer to an int*, AKA "pointer to a pointer to an int". AKA "int-pointer-pointer".
Got it? (Repeat the previous paragraph until you do!)

We write this type with two asterisks: **. Let's see it in action.
#include <stdio.h>

```
int main(void) {
    int x = 3490; // Type: int
    int *p = &x;  // Type: pointer to int
    int **q = &p; // Type: pointer to pointer to int

    printf("%d %d\n", p, *q); // 3490 3490
}
```

Let's make up some addresses to address the values as examples and see what these three variables might look like in memory. The addresses, below, are just what I have made up for example purposes:

| Variable | Stored at Address | Value Stored There |
| x | 28350 | 3490--the value from the code |
| p | 29122 | 28350--the address of x! |
| q | 30848 | 29122--the address of p! |

Indeed, let's try it for on our computer and print out the pointer values with %p and I'll do the same table with actual references (printed in hex).

| Variable | Stored at Address | Value Stored There |
| x | 0x7ffd96a07b94 | 3490--the value from the code |
| p | 0x7ffd96a07b98 | 0x7ffd96a07b94--the address of x! |
| q | 0x7ffd96a07ba90 | 0x7ffd96a07b98--the address of p! |

You can see those addresses are the same except the last byte, just focus on those.
On our system, integers are 4 bytes, which is why we're seeing the address go up by 4 times from x to p* and then q goes up by 8 bytes.
