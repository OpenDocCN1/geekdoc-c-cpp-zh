# Chapter 10. typedef: Making New Types

```
struct animal {
  char *name;
  int leg_count, speed;
};
```

```
// original name    new name
//               |       |
//               V       V
//      |----------|-----
typef struct animal;
```

struct animal y; // This works because "animal" is an alias
animal z; // This also works

Personally, I don't care for this practice. I clarity the code has when you add the word struct to the type; programmers know what they're getting. But it's really common so I'm including it here.

Now I want to put the exact example in a way that you might commonly see. We're going to put the struct animal in the typedef. You can mash it all together like this:

```
// original name
//               |
//               V
//      |------------
typef struct animal {
  char *name;
  int leg_count, speed;
} animal; // <-- new name
```

struct animal y; // This works because "animal" is an alias
animal z; // This also works

That's exactly the same as the previous example, just more concise.

But that's not! There's another shortcut that you might see in code using what are called anonymous structures. Turns out you don't actually need to name the structure in a variety of places, and with typedef is one of them.

Let's do the same example with an anonymous structure:

```
// Anonymous struct! It has no name!
//               |
//               V
//      |-----
typef struct {
  char *name;
  int leg_count, speed;
} animal; // <-- new name
```

//struct animal y; // ERROR: this no longer works--no struct!
animal z; // This works because "animal" is an alias

As another example, we might find something like this: 

```
typedef struct {
  int x, y;
  point;
};
```
