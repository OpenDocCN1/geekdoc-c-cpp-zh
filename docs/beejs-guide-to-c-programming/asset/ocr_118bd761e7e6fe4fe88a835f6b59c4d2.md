# 3.2.4 The Com Operator

This is an uncommon-used way to separate expressions that will run left to right:

```
x = 10, y = 20; // First assign 10 to x, then 20 to y
```

Seems a bit silly, since you could just replace the comma with the semicolon, right?

```
x = 10; // First assign 10 to x, then 20 to y
```

But that's a little difference. The latter is separate expressions, the former is a single expression:

With the comma operator, the value of the comma expression is the value of the rightmost expression:

```
x = (1, 2, 3);
```

```
printf("%d\n", x); // Prints 3, because 3 is rightmost in the comma list
```

But even that's pretty convuted. One common place the comma operator is used is in for loops to multiple things in each section of the statement:

```
for (i = 0, j = 10; i < 100; i++, j++)
printf("%d, %d\n", i, j);
```

We'll revisit that later.

# 3.2.5 Conditional Operators

For Boolean values, we have a raft of standard operators: b

```
a == b; // True if a is equal to b
a != b; // True if a is not equivalent to b
a < b; // True if a is less than b
a > b; // True if a is greater than b
a <= b; // True if a is less than equal to b
a >= b; // True if a is greater than equal to b
```

Don't mix up assignment = with comparison ==! Use two to compare, to assign.

We can use the comparison expressions with statements:

```
if (a <= 10)
printf("Success!\n");
```
