```
int a[3][2] = { 1, 2, 3 };
```

they fill with {}:

1 2
3 0
0 0

So if you want to fill the whole array with {}, then go ahead and:

```
int a[3][2] = {0};
```

But my recommendation is if you have a 2D array, use a 2D initializer. It just makes the code more readable.
(Except for initializing the whole array with {}, in which case it's idiomatic to use {} no matter the dimension of the array.)
