# 18.2 Exit Status

Did you notice that the function signatures for main() have it returning type int? What's all about? It has to do with a thing called the exit status, which is an integer that can be returned to the program that launched to let know how things went.

Now, there are a number of ways program can exit in C, returning from main(), or calling one of the exit() variants.

All of these methods accept an int as an argument.

Side note: you did see that in basically all my examples, even main() is supposed to return an int, I don't actually returning anything? In any other function, this would be illegal, but there's a special case in C: if execution reaches the end of main() without finding a return, it automatically returns 0.

But what does it mean? What other numbers can we put there? And how are they used?

The spec is both clear and vague on, as is common. Clear because it spells out what you can do, but vague in that it doesn't particularly limit it, either.

Let's Get Inception⁴ for a second: turns out when you run your program, you're running it from another program.

Usually this other program is kind of shell⁵ which doesn't match on its own except launch other

+   1. The shell launches program
2. The shell typically goes to sleep (for command-line shells)
3. Your program runs
4. Your program terminates
5. The shell wakes up and waits for another command

Now, there's a little piece of communication that takes place between steps 4 and 5: the program can return a status value that shell can interpolate. Typically, this value is used to indicate the success or failure of your program, and, if applicable, what type of failure.

This value is we've been returning from main(). That's the status.

| Status | Description |
| --- | --- |
| EXIT_SUCCESS or 0 | Program terminated successfully. |
| EXIT_FAILURE | Program terminated with error. |
