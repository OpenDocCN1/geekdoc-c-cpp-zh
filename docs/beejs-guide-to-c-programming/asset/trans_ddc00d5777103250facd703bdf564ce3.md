
# 第 39 章. 多线程

`thrd_create()` 接收一个要运行函数的指针，其类型为 `thrd_start_t`，即 `int (*void *)`。这在希腊语中意思是“一个接收避免 void 类型参数的函数指针，并返回一个 `int`”。

让我们创建一个线程吧！我们将从主线程通过 `thrd_create()` 启动一个函数，做一些其他事情，然后使用 `thrd_join()` 等它完成。我将线程的主函数命名为 `run()`，但只要类型匹配 `thrd_start_t`，你可以将其命名为任何。

```c
int run(void *arg)
{
    int *a = arg; // 我们将从 thrd_create() 传入一个 int*

    printf("THREAD: Running thread with %d\n", *a);

    return 12; // 被 thrd_join() 拾取的值（随机选择了 12）
}
```

```c
int main(void)
{
    thrd_t t; // t 将持有线程 ID
    int arg = 3490;

    printf("Launching a thread\n");

    // 启动一个线程运行 run() 函数，传递指向 3490 的指针
    // 作为参数。并将线程 ID 存储在 t 中：
    thrd_create(&t, run, &arg);

    printf("Doing other things while the thread runs\n");

    printf("Waiting for thread to complete...\n");

    int res; // 存储线程退出时的返回值

    // 等待线程完成；将返回值存储
    // 在 res 中：
    thrd_join(t, &res);

    printf("Thread exited with return value %d\n", res);
}
```

看我们是如何使用 `thrd_create()` 调用 `run()` 函数的？接着我们在 `main()` 中做了其他事情，然后停止并使用 `thrd_join()` 等待线程完成。

示例输出（你的结果可能不同）：

```
Launching a thread
Doing other things while the thread runs
Waiting for thread to complete...
THREAD: Running with arg 3490
Thread exited with return value 12
```

你传递给函数的 `arg` 必须有足够长的寿命，以便线程在它消失之前能够拾取它。此外，在新线程使用它之前，它不能被主线程覆盖。

让我们来看一个启动 5 个线程的示例。这里需要注意的是，我们如何使用 `thread_t` 数组来跟踪所有的线程 ID。

```c
#include <stdio.h>
#include <threads.h>

int run(void *arg)
{
    int i = *(int*)arg;
    printf("THREAD %d: running!\n", i);
    return i;
}

#define THREAD_COUNT 5

int main(void)
{
    thread_t t[THREAD_COUNT];
    int i;

    printf("Launching threads...\n");
    for (int i = 0; i < THREAD_COUNT; i++)
        t[i] = thrd_create(run, &i); // 注意这里！

    printf("Doing other things while the thread runs...\n");
    printf("Waiting for thread to complete...\n");

    for (int i = 0; i < THREAD_COUNT; i++) {
        int res;
        if (thrd_join(t[i], &res) == thrd_success)
            printf("Thread %d complete!\n", i);
    }

    printf("All threads complete!\n");
    return 0;
}
```

> // 注意！在接下来的一行中，我们传递了 i 的指针，
// 但每个线程看到的都是同一个指针。因此当 i 在
// 主线程中改变值时，它们会
// 输出一些奇怪的东西！（更多内容见下文。）

当我运行这些线程时，`i` 从 0 计数到 4。并将它的指针传递给 `thrd_create()`。这个指针最终进入了 `run()` 程序，我们在那里创建了它的副本。

足够简单吗？这是输出：

```
Launching threads...
THREAD 2: running!
THREAD 3: running!
THREAD 4: running!
THREAD 2: running!
Doing things while the thread runs...
Waiting for thread to complete...
Thread 2 complete!
Thread 2 complete!
THREAD 5: running!
Thread 3 complete!
Thread 4 complete!
Thread 5 complete!
```

哇，THREAD 0 在哪里？而且为什么当我们调用 `thrd_create()` 时，`i` 从没有超过过 4，我们却有一个 THREAD 5？还有两个 THREAD 2？疯了！

这已经进入了竞态条件的有趣之处。主线程在线程有机会复制它之前就修改了它。事实上，`i` 一直到了 5，并在循环结束时最后一个线程才有机会复制它。

我们需要一个大数组。或者我们可以使用 `malloc()` 分配空间（并在地方释放它——也许在线程内部）。

让我们试一试：

```c
#include <stdio.h>
#include <stdlib.h>
#include <threads.h>

int run(void *arg)
{
    int i = *(int*)arg; // 拷贝 arg

    free(arg); // 完成了这个

    printf("THREAD %d: running!\n", i);

    return i;
}

#define THREAD_COUNT 5

int main(void)
{
    thrd_t t[THREAD_COUNT];

    int i;

    printf("Launching threads...\n");

    for (i = 0; i < THREAD_COUNT; i++) {
        // 为每个线程的参数获取一些空间
        int *arg = malloc(sizeof *arg);
        *arg = i;
        thrd_create(&t[i], run, arg);
    }
}
```

注意第27-30行，我们为每个线程的参数获取了一些空间。这确保了每个线程都获得了该值的独立副本。
