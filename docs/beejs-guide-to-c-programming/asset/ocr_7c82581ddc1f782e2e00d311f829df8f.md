Ok! There are a couple things to see here... not the least of which is that the increment() function takes an int as argument. We pass it an int in the call by changing the int variable i to an int * using the address-of operator. Remember, a pointer holds an address, so we make pointers to variables by incrementing them through the address-of operator.

The increment() function gets a copy of the pointer. Both the original pointer j (in main()) and the copy of that pointer p (the parameter in increment()) point to the same address, namely the one holding the value i. (Again, like two pieces of paper with the same address written on them). Dereferencing either allows you to modify the original variable i! The function can modify a variable in another scope!

# 5.5 The Null Pointer

Any variable of any type can be set to a special value called NULL. This indicates that this pointer doesn't point to anything.

```
int *p;
```

p = NULL;
Since it doesn't point to a value, dereferencing it is undefined behavior, and probably will result in a crash:

```
int *p = NULL;
```

*p = 12; // CRASH OR SOMETHING PROBABLY BAD. BEST AVOIDED.
Despite being the billion dollar mistake by your creator⁶ the NULL pointer is a good sentinel value⁷ and general indicator that a pointer hasn't been initialized.

(Of course, like other variables, the pointer to garbage unless you explicitly assign it to point to an address or NULL.)
