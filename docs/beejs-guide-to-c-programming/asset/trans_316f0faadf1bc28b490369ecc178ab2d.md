# 21.1.2.1 单行状态更新

\a 或 \r 的一个用途是显示在屏幕上同一行显示的状态更新，且不会导致屏幕刷新。这里是一个倒计时到 10 的示例。（注意这里使用了来自 <unistd.h> 的非标准 POSIX 函数 `sleep()`——如果你不是在 Unix 类系统，请搜索你平台对应的 `sleep` 函数）。

```c
#include <stdio.h>
#include <threads.h>

int main(void)
{
    for (int i = 10; i >= 0; i--) {
        printf("\RT minus %d second%%... \b", i, i != 1 "s": "");
    }

    fflush(stdout); // 强制更新输出

    // 睡眠 1 秒
    thrd_sleep(&(struct timespec){.tv_sec=1}, NULL);
    printf("\RLiftoff!\n");
}
```

# 第 21 章 字符与字符串 II

第 7 行发生了不少事情。首先，我们以 `\r` 开头回到当前行首，然后用当前的倒计时覆盖原来的内容。（使用了三元运算符来确保我们打印的是 1 秒而不是 2 秒。）

另外，在 `. . .` 后面有一个空格。这就是我们在 `i` 从 10 减到 9 时能覆盖最后一个 `.` 并导致列变窄的原因。尝试不加空格，看看我是什么意思。

最后用 `\b` 结尾，将那个空格退回，这样光标就能以一种美观的方式停在行的末尾。

注意第 14 行末尾所有的空格都是为了覆盖之前已经存在的字符。

最后，我们在里面有一个 `fflush(stdout)`，无论它是什么意思。大多数终端默认是缓冲的，在遇到换行符之前实际上不会显示任何内容。由于我们没有换行符（我们用了 `\r`），如果没有这个，程序就会一直在那里，直到调用 `fflush()` 然后瞬间打印所有内容。`fflush()` 覆盖了这种行为并立即输出到缓冲区。

# 21.1.2 问号的使用

为什么要这样做呢？毕竟，这样写也可以：

```c
printf("Doesn't it?\n");
```

使用转义符也可以的：

```c
printf("Doesn't it?\n");    // 注意 \?
```

那意义何在呢？？

让我们用另一个问号和感叹号来加强加强语气：

```c
printf("Doesn't it??\n");
```

当我编译这个代码时，我得到了这个警告：

```c
foo.c: In function 'main'
foo.c:5:23: warning: trigraph ?? converted to | -Wigraphs
5 |
 printf("Doesn't it??\n");
```

运行它带我们得到了这个结果：

Doesn't|

那么图形呢？这到底是什么鬼？？

我确定我们以后会再次回到语言的这个角落，但简而言之，编译器会寻找以 `??` 开头的某些三元组，并用其他字符替换它们。所以如果你在一个非常古老的终端上，键盘上没有管道符号 `|`，你可以输入 `??!` 代替。

你可以通过转义问号来修复这个问题，如下所示：

```c
printf("Doesn't it\?\?\!\n");
```

这样它就能编译并按预期工作了。

如今已经没有人使用三字符序列了。但如果你决定在字符串中使用它，例如，这种东西有时还是会出现！！！

# 21.1.3 数字转义

此外，还有方法可以在字符串或字符常量内部指定数值常量或其他字符值。

如果你知道一个字节的八进制或十六进制表示法，你可以将其包含在字符串或字符常量。

下表提供了示例数字，但可以使用任何十六进制或八进制数字。必要时在开头填充零，以便读取正确的位数。

| 代码 | 描述 |
| --- | --- |
| \123 | 嵌入八进制值为 123 的字节，正好 3 位。 |
| \x4D | 嵌入十六进制值为 4D 的字节，2 位。 |
| \u2620 | 嵌入十六进制为 2628 的代码点的 Unicode 字符，4 位。 |
| \u1243F | 嵌入十六进制为 1243F 的代码点的 Unicode 字符，8 位。 |

这里是一个使用不常用的八进制表示法表示 A 和 C 之间的字母 B 的示例。通常这会用于某些不可打印字符，但我们有其他方法来实现它，这只是一个八进制示例：

```c
printf("\A102\n"); // 102 在 ASCII/UTF-8 中是 'B'
```

注意当你使用这种方法时，八进制数字开头没有领先零。但它需要三个字符，所以如果需要，请在开头填充零。
