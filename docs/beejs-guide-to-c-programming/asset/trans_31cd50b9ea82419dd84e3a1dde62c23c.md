## 7.5 获取字符串长度

你做不到，C 语言没有跟踪它。而且当我说“做不到”时，我的意思其实是“真的做不到”。在 `<string.h>` 中有一个名为 `strlen()` 的函数，可以用于计算任何字符串按字节（bytes）的长度。

```c
#include <stdio.h>
#include <string.h>
```

```c
int main(void)
{
    char *s = "Hello, world!";
    printf("The string is %zu bytes long.\n", strlen(s));
}
```

`strlen()` 函数返回 `size_t`，这是一种你可以用于整数运算的整数类型。使用 `%zu` 打印 `size_t`。

上面的程序输出：

The string is 13 bytes long.

太棒了！所以获取字符串长度是可以可能的！

但是……如果 C 并不跟踪字符串的长度，它是如何知道字符串有多长的？

## 7.6 字符串终止

C 处理字符串的方式与许多编程语言略有不同，事实上它几乎不喜欢每种现代编程语言。

当你编写语言时，在内存中存储字符串有两种选择：

1. 存储字符串的字节，并带上一个指示字符串长度的数字。
2. 存储字符串的字节，并用一个称为“终止符”（terminator）的特殊字节来标记字符串的结束。

如果你需要的长度超过 255 个字符，至少需要两个字节来存储字符串。而选项 2 只需要两个字节就能结束字符串。所以这上节省了一点空间。

当然，为了节省一个字节（或 3 个字节——很多语言允许字符串长度达到 4GB）而操心这似乎很荒唐。但在以前，这是一件大事。

所以 C 语言采取了方法 #2。在 C 语言中，“字符串”由两个基本特征定义：

> ¹ C 确实不跟踪字符串的长度，这是事实。

> ² 如果使用基础字符集或 8 位字符集，你习惯于一个字符占用一个字节。不过，这在所有的字符编码中并非如此。

- 指向字符串第一个字符的指针。
- 指针之后内存中某处值为 0 的字节（NUL 字符），它表示字符串的结束。

NUL 字符在 C 中可以写为 `\0`，尽管你并不经常需要这样做。

当你像这样用双引号包含字符串时，NUL 字符会自动、隐式地包含在内。

```c
char *s = "Hello"; // 在背后实际上是 "Hello\0"
```

所以考虑到这一点，让我们写一个自己的 `strlen()` 函数，计算字符串中的字符，直到找到 NUL 为止。该过程是向下扫描字符串寻找单个 NUL 字符，并在计数：

```c
int my_strlen(char *s)
{
    int count = 0;

    while (s[count] != '\0') // 单引号用于单字符
        count++;

    return count;
}
```

## 7.7 复制字符串

你不能通过赋值运算符 (`=`) 复制字符串。它所做的只是创建了一个指向第一个字符指针的副本……所以你最终得到了两个指向同一个字符串的指针：

```c
#include <stdio.h>

int main(void)
{
    char s[] = "Hello, world!";
    char *t;

    // 这只是指针的副本，而不是字符串的副本！
    t = s;

    // 我们修改了 t
    t[0] = 'z';

    // 但打印 s 显示了修改！
    // 因为 t 和 s 指向同一个字符串！
    printf("%s\n", s); // "zello, world"
}
```

如果你想复制字符串，你必须字节一个字节地复制——但使用 `strcpy()` 会更简单。

> ³ 这与 NULL 指针不同，当讨论字符与 NULL 时，我会将 NUL 缩写为 NUL。

> ⁴ 我们将学习一种使用指针算术实现它的新方法。

> ⁵ 有一个更安全的函数 `strcpy()`，你可能应该使用它，但我们稍后会讲。

在复制字符串之前，确保你有足够的空间将其复制进去，即将保存这些字符的目标数组长度至少要与你复制的字符串一样长。

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[] = "Hello, world!";
    char t[100]; // 每个字符一个字节，空间充足

    // 这创建了字符串的副本！
    strcpy(t, s);

    // 我们修改了 t
    t[0] = 'z';

    // 但打印 s 显示了修改！
    // 因为 t 和 s 指向同一个字符串！
    printf("%s\n", s); // "zello, world"
}
```

注意 `strcpy()`，目标是第一个，源是第二个。

## 结构体 (Structs)

在 C 语言中，我们有一种叫做结构体（struct），它是将多个变量打包在一起的方便方式。在许多其他语言中你可能熟悉类（classes）。这些在 C 语言中不存在。

你可以定义一个包含不同类型数据的结构体：

```c
struct car {
    char *name;
    float price;
    int speed;
};
```

你可以声明一个该类型的变量并初始化它的字段。在下一节中：

```c
struct car saturn;
```

我们使用点运算符 (`.`) 来访问字段。

## 8.2 结构体初始化 (Struct Initializers)

上面的例子有点不妥。在初始化它们时，必须按照它们在结构体中出现的顺序给出值（这在定义时就会发生）：

```c
struct car {
    char *name;
    float price;
    int speed;
}

// 现在使用初始化器！与结构体定义一致
struct car saturn = {"Saturn SL/2", 15999.99, 175};
```

初始化字段必须与结构体顺序相同的做法有点棘手。如果有人更改了结构体的顺序，可能会破坏所有代码！我们可以更具体地进行初始化：

```c
struct car saturn = {.speed=175, .name="Saturn SL/2"};
```

现在它独立于结构体的定义。这种代码确实更安全。类似于数组初始化，任何缺失的字段标识符初始化为零（在这种情况下是我省略的 `.price`）。

## 8.3 将结构体传递给函数 (Passing Structs to Functions)

可以通过两种方式将结构体传递给函数：

1. 传递结构体。
2. 传递结构体的指针。

记住，当你向函数传递东西时，该东西的副本将供函数操作，无论它是指针、整数、结构体还是任何东西。

## 8.4 引用传递结构体 (Structs by Reference)

当你按值传递结构体时，会复制整个结构体。如果结构体很大，这会非常慢。在这种情况下，我们传递结构体的指针。这样只复制了指针。通过指针访问结构体的字段时，我们使用箭头运算符 (`->`)。

```c
void print_car(struct car *c)
{
    printf("Name: %s\n", c->name);
    printf("Price: %f\n", c->price);
    printf("Top Speed: %d km\n", c->speed);
}

int main(void)
{
    struct car saturn = {"Saturn SL/2", 16000.99, 175};
    print_car(&saturn);
    return 0;
}
```
