

## 第 12 章. 手动内存分配

对齐是一个大于 0 的整数幂，例如 2, 4, 8, 16 等，你需要在提供你感兴趣的字节数之前，将其传递给 `aligned_alloc()` 函数。

另一个限制是，你分配的字节数必须是对齐值的倍数。但这可能会发生。请参阅 C 缺陷报告（Defect Report） 460。

让我们来做一个例子，在 64 字节边界上分配：

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
```

```c
int main() {
    // 分配 256 字节并对齐到 64 字节边界
    char *p = aligned_alloc(64, 256); // 256 == 64 * 4

    // 在其中拷贝一个字符串并打印
    strncpy(p, "Hello, world!");
    printf("%s\n", p);

    // 释放空间
    free(p);
}
```

我想在这里提一下关于 `realloc()` 和 `aligned_alloc()` 的说明。`realloc()` 没有任何对齐保证，因此如果你需要获取某些对齐分配的空间，你必须通过 `malloc(ptr)` 这种困难的方法来处理。

这里有一个非标准的 `aligned_realloc()` 函数，如果你需要的话：

```c
void *aligned_realloc(void *ptr, size_t size, size_t alignment, size_t old_size) {
    char *new_ptr = aligned_alloc(alignment, size);

    if (new_ptr == NULL) {
        return NULL;
    }

    size_t copy_size = old_size < size ? old_size : size; // 获取最小值

    if (ptr != NULL) {
        memcpy(new_ptr, ptr, copy_size);
    }

    free(ptr);

    return new_ptr;
}
```

注意，它总是会拷贝数据，从而消耗时间，而 `realloc()` 在可能的情况下会避免这一点。这几乎并不高效。除非为了避免需要重新分配自定义对齐的数据。

## 第 13 章

## 作用域

作用域关于变量在什么上下文中可见的。

### 13.1 块作用域

这是几乎所有开发者定义的变量的作用域。它包含了其他语言可能称为“函数作用域”的内容，即在函数内部定义的变量。

基本规则是，如果你在一个由花括号分隔的块中声明了一个变量，那么该变量的作用域就是该块。

如果块内部还有另一个块，那么在内部块中声明的变量是该块的局部的，且在外部作用域中不可见。

一旦变量的作用域结束，该变量就无法再次被引用，你可以认为它的值已经进入了天空中的“大桶”¹。

一个带有嵌套作用域的示例：

```c
#include <stdio.h>

int main(void)
{
    int a = 12;           // 外部块局部，但在内部块中可见

    if (a == 12) {
        int b = 99;      // 内部块局部，在外部块中不可见

        printf("%d %d\n", a, b); // OK: "12 99"
    }

    printf("%d\n", a);      // OK，我们仍然在 a 的作用域内
    printf("%d\n", b);      // 非法，超出了 b 的作用域
}
```

> ¹https://en.wikipedia.org/wiki/Bit_bucket

### 13.1.1 在何定义变量

另一个事实是，你可以在块内的任何地方定义变量——它们拥有该块的作用域，但在定义之前无法使用它们。

```c
#include <stdio.h>

int main(void)
{
    int i = 0;

    printf("%d\n", i);    // OK: "0"

    // printf("%d\n", j);    // 非法--在定义 j 之前无法使用 j

    int j = 5;

    printf("%d %d\n", i, j);    // OK: "0 5"
}
```

历史上，C 语言要求在块中的任何代码之前定义所有变量，但在 C99 标准中不再是这样了。

### 13.1.2 变量隐藏

如果你在内部作用域中有一个与外部作用域中同名的变量，只要你运行在内部作用域中，内部作用域的变量就具有优先级。也就是说，在它的生命周期内，*隐藏*了外部作用域的那个。

```c
#include <stdio.h>

int main(void)
{
    int i = 10;

    {
        int i = 20;

        printf("%d\n", i);    // 内部作用域 i, 20 (外部 i 被隐藏了)
    }

    printf("%d\n", i);    // 外部作用域 i, 10
}
```

你可能注意到我在示例的第 7 行那里丢了一个块，而不是用一个 `for` 或 `if` 语句来启动它！这是完全合法的。有时开发者会想要将一组局部变量放在在一起以便快速处理。

### 13.3 循环作用域

如果你在循环中定义变量，它在循环的作用域内是有效的。

```c
#include <stdio.h>

int main(void)
{
    for (int i = 0; i < 5; i++) {
        printf("%d\n", i);
    }
    // printf("%d\n", i); // 非法，i 已经出了作用域
}
```

## 第 14 章. 类型：更多类型

我们熟悉 `char`、`int` 和 `float` 类型，但现在是时候深入介绍了。

### 14.1 有符号与无符号整数

到目前为止我们使用的是 `signed`，即可以包含负数的整数。但 C 也有无符号的整数类型，它们只能包含正数。

```c
int a; // 有符号
signed a; // 有符号
unsigned int b; // 无符号
unsigned b; // 无符号
```

为什么？为什么你想要持有正数？答案：在 `unsigned` 变量中可以获得比 `signed` 更更大的数字。为什么？在我的计算机上，`int` 是 64 位表示的。并且每一位（0 或 1）都表示一个数字。我们可以决定如何划分这些数字。对于有符号数，我们使用大约一半的排列表示负数，另一部分表示正数。对于无符号数，我们使用所有排列来表示正数。在我的 64 位使用补码表示无符号整数的计算机上，我有以下整数限制：

| 类型 | 最小值 | 最大值 |
|---|---|---|
| int | -9,223,372,036,854,775,808 | 9,223,372,036,854,775,807 |

> ²Bit 是 binary digit 的缩写。二进制只是表示数字的另一种方式。与其我们熟悉的 0-9 数字，它是 0 和 1。

> ³https://en.wikipedia.org/wiki/Two%27s_complement

### 14.2 字符类型

记得 `char` 吗？那个我们可以用来持有单个字符的类型？

```c
char c = 'B';

printf("%c\n", c); // "B"
// 让你惊讶：它实际上是一个整数。

char c = 'B';
```

```c
// 将此从 %c 改为 %d:
printf("%d\n", c); // 66 (!!)
```

深层上，`char` 只是一个较小的 `int`，即一个使用单字节空间的整数，其范围限制在在这里 C 规范确保了 `char` 是单字节，即 `sizeof(char) == 1`。
