# 27.9.6 String and Memory Comparing Functions

Typically include <wchar.h> for these.

| Comparing Function | Description |
| wcscmp() | Compare strings lexicographically. |
| wcscmp() | Compare strings lexicographically, length-limited. |
| wcscroll() | Compare strings in dictionary order by locale. |
| wmem() | Compare memory lexicographically. |
| wcscfrm() | Transform strings into versions that wcscmp() behaves like wcscroll()⁹. |

# 27.9.7 String Searching Functions

Typically include <wchar.h> for these.

| Searching Function | Description |
| wcchr() | Find a character in a string. |
| wscrchr() | Find a character in a string from the back. |
| wmemchr() | Find a character in memory. |
| wcstr() | Find a substring in a string. |
| wcspbrk() | Find any of a set of characters in a string. |
| wcspn() | Find length of substring including any of a set of characters. |
| wcspn() | Find length of substring before any of a set of characters. |
| wstok() | Find tokens in a string. |

# 27.9.8 Length/Miscellaneous Functions

Typically include <wchar.h> for these.

| Length/Misc Function | Description |
| wcslen() | Return the length of the string. |
| memset() | Set characters in memory. |
| wcsftime() | Formatted date and time output. |

> ⁹wcscroll() is the same as wcscfrm() followed by wcscmp().
