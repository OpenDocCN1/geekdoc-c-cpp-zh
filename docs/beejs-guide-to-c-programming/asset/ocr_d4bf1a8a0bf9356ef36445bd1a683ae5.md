# 15.1.2 String to Numeric Value

There are a couple families of functions to do this in C. We'll call all the atoi (pronounced aoi-to-i) family and the strtol (stir-to-long) family.

For basic conversion from a string to a number, try the atoi functions from <stdlib.h>. These have bad error-handling characteristics (including undefined behavior if you pass a bad string), so use them carefully.

| Function | Description |
| --- | --- |
| atoi | String to int |
| atof | String to float |
| atol | String to long int |
| strtol | String to long int |

Though the spec doesn't cot to it, a at the beginning of the function stands for ASCII, so saying that it is a bit ASCII-centric.

Here's an example converting a string to a float:

```
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char *pi = "3.14159";
    float f;

    f = atof(pi);

    printf("%f\n", f);
n}
```

But, like I said, we get undefined behavior from weird things like this:
int x = atoi("what"); // "what" ain't no number I ever heard of

(When I run it, you get 0 back, but you shouldn't count on that in any way. You could get something completely different.)

For better error handling characteristics, let's check out all strtol functions, also in <stdlib.h>. Not only that, but they convert to more types and more cases, too!

| Function | Description |
| --- | --- |
| strtol | String to long int |
| strtoll | String to long long int |
| stroul | String to unsigned long int |
| strtou | String to unsigned long int |
| atof | String to float |
| strtod | String to double |
| strtold | String to long double |

These functions all follow a similar pattern of use, and are a lot of people's first experience with pointers to pointers! But never fret—it's easier than it looks.
