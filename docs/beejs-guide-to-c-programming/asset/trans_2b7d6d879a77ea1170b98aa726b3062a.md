它也是一种解引用。

如果你仔细想想，这些规则是有道理的。所有这些操作都依赖于知道所指向的数据的大小，而对于 `void*`，我们并不知道指向的数据有多大——它可能是任何类型！

等一下——如果你不能对 `void*` 进行解引用，它对你还有什么用呢？

就像 `memcpy()` 一样，它可以帮助你编写可以处理多种类型数据的通用函数。但秘密在于，在深层，在使用之前，你会先将 `void*` 转换为另一种类型！

赋值也很简单：你只需要将其赋值给目标类型的变量即可。

```c
char a = 'X'; // 单个字符
void *p = &a; // p 指向 'X'
char *q = p; // q 也指向 'X'
```

```c
printf("%s\n", p); // 错误-无法对 void* 进行解引用
printf("%s\n", q); // 打印 "X"
```

让我们写一个自己的 `memcpy()` 来尝试一下。我们可以复制字节（char），并且知道字节数，因为它是传递进来的。

```c
void *my_memcpy(void *dest, void *src, int byte_count) {
    char *s = src, *d = dest;

    // 现在我们有了 char*s，可以对其进行解引用并复制
    while (byte_count--) {
        *d++ = *s++;
    }
    // 大多数这类函数都会返回目标地址，以万一
    // 对调用者有用。
}
```

就在开头，我们将 `void*` 拷贝到 `char*s`，这样我们就可以像使用 `char*` 一样使用它们。很简单。

然后在 `while` 循环中，我们递减 `byte_count` 直到它变为 (0)。记住，使用后自增时，表达式的值先被计算（供 `while` 使用），然后变量才递减。

在复制操作中，我们赋值 `*d = *s;` 来复制字节，但我们使用了后自增，这样在赋值完成后 `d` 和 `s` 都会移动到下一个字节。

最后，大多数内存和字符串函数都会返回目标指针的副本，以防调用者想要使用它。

既然我们已经做到了，我只想指出，我们可以使用这种技术遍历 C 语言任何对象的字节，浮点数、结构体或任何东西！

让我们用内置的 `qsort()` 例程再运行一个真实例子，得益于 `void*` 的魔法，它可以排序任何内容。

（在以下示例中，你可以忽略字数，我们还没有涵盖这一点。）

# 第 11 章：指针 II：算术

```c
#include <stdio.h>
#include <stdlib.h>

// 我们要排序的结构体类型
struct animal {
    char *name;
    int leg_count;
};

// 这是由 qsort 调用的比较函数，帮助确定
// 具体按什么进行排序。我们将用它按 leg_count 排序
// 动物结构体数组。
int comp(const void *elem1, const void *elem2)
{
    // 我们知道正在排序动物，所以让两个参数
    // 都成为指向 struct animal 的指针
    const struct animal *animal1 = elem1;
    const struct animal *animal2 = elem2;

    // 根据我们想要排序的标准返回 <0 或 >0。

    // 我们按 leg_count 升序排序，所以返回
    // leg_count 的差异
    if (animal1->leg_count > animal2->leg_count)
        return 1;

    if (animal1->leg_count < animal2->leg_count)
        return -1;

    return 0;
}

int main(void)
{
    // 我们构建一个包含 4 个不同特征动物的数组。
    // 这个数组按 leg_count 排序是有序的，
    // 我们将在几秒后对其排序。
    struct animal a[4] = {
        {.name="Dog", .leg_count=4},
        {.name="Monkey", .leg_count=2},
        {.name="Antelope", .leg_count=4},
        {.name="Snake", .leg_count=0}
    };

    // 调用 qsort 排序数组。qsort 需要明确告知
    // 根据什么排序这些数据，我们将在 comp()
    // 函数内部完成这一点。

    // 此调用表示：qsort 数组 a，它有 4 个元素，
    // 每个元素的大小为 sizeof(struct animal) 字节，
    // 这是一个比较任意两个元素的函数。
    qsort(a, 4, sizeof(struct animal), comp);

    // 打印所有内容
    for (int i = 0; i < 4; i++) {
        printf("%d: %s\n", a[i].leg_count, a[i].name);
    }
}
```

只要你给 `sort()` 提供一个可以比较排序数组中任意两个项的函数，它就可以排序任何内容。而且它这样做时不需要在任何地方硬编码项目的类型。`qsort()` 仅仅根据你传递的 `comp()` 函数的结果来重新排列字节块。

# 12. 手动分配

在许多语言中，内存是由系统处理的，但在 C 中，你必须自己管理。这意味着在你需要时分配内存，并在完成后释放它。

堆是一个可以在运行时使用的巨大内存池。为了从堆上获取内存，我们使用 `malloc()`。`malloc` 的意思是“memory allocation”（内存分配）。它返回一个指向分配块起始字节的指针。

```c
void *malloc(size_t size);
```
`size` 参数是你想要分配的字节数。它返回一个 `void*`，这是一个可以转换为任何其他指针类型的通用指针。如果 `malloc()` 分配内存失败，将返回 `NULL`。

检查 `malloc()` 是否返回 `NULL` 总是重要的。

```c
int *ptr = malloc(sizeof(int));
if (ptr == NULL) {
    // 处理错误
    return 1;
}
```

当你完成分配内存的使用后，必须调用 `free()` 将其返回系统。不这样做会导致内存泄漏。

```c
free(ptr);
```

在调用 `free(ptr)` 后，该指针会变成“悬空指针”，因为它仍然指向不再属于你的内存。在释放后将其设置为 `NULL` 是一个良好的习惯。

```c
free(ptr);
ptr = NULL;
```
