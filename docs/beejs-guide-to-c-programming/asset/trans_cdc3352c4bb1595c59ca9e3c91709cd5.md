### 20.1 嵌套结构体和数组的初始化

还记得在这些行中如何初始化结构体成员吗？

```c
struct foo x = {.a=12, .b=34};
```

事实证明这些初始化器的用法比我们最初分享的要多。令人兴奋！

首先，如果你有像这样的嵌套结构，你可以顺着变量名向下找到初始化子结构的成员：

```
struct foo x = {.a.b.c=12};
```

让我们来看一个例子：

```c
#include <stdio.h>

struct cabin_information {
    int window_count;
    int o2level;
};

struct spaceship {
    char *manufacturer;
    struct cabin_information ci;
};

int main(void) {
    struct spaceship s = {
        .manufacturer="General Products",
        .ci.window_count = 8, // <-- 嵌套初始化！
        .ci.o2level = 21
    };
}
```

```c
printf("%s:%d seats, %d oxygen\n",
    s.manufacturer, s.window_count, s.ci.o2level);
}
```

查看第 16-17 行！这就是我们如何在 `struct spaceship` 的定义中初始化 `struct cabin_information` 成员的。

这是该初始化器的另一种选择——这次我们将使用看起来更标准的写法，但两种方法都有效：

```c
struct spaceship s = {
    .manufacturer="General Products",
    .ci={
        .window_count = 8,
        .o2level = 21
    }
};
```

现在，如果上面的信息还不够精彩，我们也可以其中混合数组初始化器。
让我们修改它以包含一个乘客信息数组，也可以查看初始化在其中是如何工作的。

```c
#include <stdio.h>
```

```c
struct passenger {
    char *name;
    int covid_vacinated; // 布尔值
}
```

```c
#define MAX_PASSENGERS 8
```

```c
struct spaceship {
    char *manufacturer;
    struct passenger passenger[MAX_PASSENGERS];
}
```

```c
int main(void) {
    struct spaceship s = {
        .manufacturer="General Products",
        .passenger = {
            // 一次初始化一个字段
            [0].name = "Gridley, Lewis",
            [0].covid_vacinated = 0,
            // 或者一次性初始化
            [7] = {.name="Brown, Teela", .covid_vacinated=1},
        }
    }
}
```

```c
printf("Passengers for %s\n", s.manufacturer);
```

```c
for (int i = 0; i < MAX_PASSENGERS; i++) {
    if (s.passenger[i].name != NULL)
        printf(" %s (%svacinated)\n", s.passenger[i].name, s.passenger[i].covid_vacinated ? "yes" : "not");
}
}
```

### 20.2 匿名结构体

这些是没有名字的“结构体”。我们在 `typedef` 部分也提到过它们，但在这里我们会复习一下。

这是一个普通的结构体：

```c
struct animal {
    char *name;
    int leg_count, speed;
};
```

这是它的匿名等效物：

```c
struct { // <-- 没有名字！
    char *name;
    int leg_count, speed;
};
```

好吧。所以我们有一个结构体，但它没有名字，所以我们没有办法在以后使用它？看起来完全没意义。

诚然，在某个例子中确实是如此。我们仍然可以使用几种方法。

一种很罕见，但由于匿名结构体代表了一种类型，我们只需要在后面加上一些变量名并使用它们。

```c
struct { // <-- 没有名字！
    char *name;
    int leg_count, speed;
} a, b, c; // 3个该结构体的变量
```

a.name = "antelope"; // 例如

c.leg_count = 4;
```

但这并不用。

更常见的方法是将匿名结构体与 `typedef` 使用，以便我们以后可以使用它（例如将变量传递给函数）。

```c
typedef struct { // <-- 没有名字！
    char *name;
    int leg_count;
} animal; // 新类型：animal
```

animal a, b, c;

a.name = "antelope"; // 例如

c.leg_count = 4;
```

就个人而言，我不使用匿名结构体。我认为在声明中于变量名之前看到整个 `animal` 结构体会更舒服。

但这仅仅是我的观点而已。

### 20.3 自引用

对于自引用结构体，你必须使用指向相同类型的指针。这在链表和树中很常见。

```c
struct node {
    int data;
    struct node *next;
};
```

### 20.4 灵活数组成员

灵活数组成员是结构体末尾的一个没有指定大小的数组。这允许结构体拥有一个变大小的数组。它必须是结构体的最后一个成员。

```c
struct tree_node {
    int value;
    struct tree_node *left;
    struct tree_node *right;
    int data[]; // 灵活数组成员
};
```

要使用它，你需要分配结构体加上你需要的元素的内存：

```c
struct tree_node *root = malloc(sizeof(struct tree_node) + sizeof(int) * 10);
```

### 20.5 填充字节

注意，C 允许根据其需要在结构体内部添加填充字节。你不能保证它们在内存中是相邻的。

让我们来看这个。我们输出两个数字。一个是各个字段类型 `sizeof` 之和。另一个是整个结构体的大小。

人们期望它们是相同的。总大小应该是各个部分之和，对吧？

```c
#include <stdio.h>

struct foo {
    int a;
    char b;
    int c;
    char d;
};

int main(void) {
    printf("%zu\n", sizeof(struct foo));
}
```

在我们的系统上，这输出：

10
16

它们并不相同！编译器添加了 6 字节的填充以提高性能。可能在你的编译器上会得到不同的输出，除非你强制要求，否则你无法确定没有填充。
