# # Structs

In C, we have something called a struct, which is a user-definable type that holds multiple pieces of data, potentially of different types.

It's a convenient way to bundle variables into a single one. This can be beneficial for passing variables to functions (so you just have to pass one instead of many), and useful for organizing data and making code more readable.

If you come from another language, you might be familiar with the idea of classes and objects. These don't exist in C, natively¹. You can think of a struct as a class with only data members, and no methods.

You can declare a struct in your code like so:

```
struct car {
  char *name;
  float price;
  int speed;
};
```

This is often done at the global scope outside any functions that the struct is globally available.

When you do this, you're making a new type. The full name is struct car. (Not just car—that won't work).

There aren't any variables of type that yet, but we can declare:

```
struct saturn; // Variable "saturn" of type "struct car"
```

And we have an uninitialized variable saturn² of type struct car.

We should initialize it! But how do we set the values of those individual fields?

In many other languages that stole from C, we're going to use the dot operator (.) to access the individual fields.

```
saturn.name = "Saturn SL/2";
saturn.price = 15999.99;
```

> ¹Although in C individual items in memory are referred to as "objects", they're not objects in an object-oriented programming sense.

> ²The Saturn was a popular brand of economy car in the United States until it was put out of business by the 2008 crash, sadly so to us fans.
