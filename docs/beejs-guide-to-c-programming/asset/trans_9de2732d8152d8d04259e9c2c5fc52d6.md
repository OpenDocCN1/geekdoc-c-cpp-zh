| 字符类型 | 最小值 | 最大值 |
|---|---|---|
| 有符号 char | -128 | 127 |
| 无符号 char | 0 | 255 |

而且 char 的范围是由实现定义的。
让我确认一下。`char` 实际上是一个数字，所以我们可以对它进行数学运算吗？
是的！只需记住将结果保持在 `char` 的范围内即可！

#include <stdio.h>

```
int main(void)
{
    char a = 10, b = 20;

    printf("%d\n", a + b); // 30!
}
```

那么那些单引号里的常量字符，比如 'B' 呢？它是如何具有数值的呢？
规范也相当模糊，因为 C 设计的设计并不是运行在单一类型的底层系统上。
但让我们暂且假设你的字符集至少的前 128 个字符是基于 ASCII 的。在这种情况下，字符常量将转换为 `char`，其值与该字符的 ASCII 值相同。
这一段话真绕。我们直接看个例子：

#include <stdio.h>

```
int main(void)
{
    char a = 10;
    char b = 'B'; // ASCII 值 66

    printf("%d\n", a + b); // 76!
}
```

这取决于你的执行环境和所使用的字符集⁶（ASCII 的超集）。今天最流行的字符集之一是 Unicode（对于基础的 0-9、A-Z、a-z 和标点符号，你几乎可以得到它们的 ASCII 值）。

- char

是的，我说了两次“最小值”。规范规定类型将持有至少这些尺寸的数字，因此你的实现可能会有所不同。头文件 `<limits.h>` 定义了存储最小和最大整数值的宏；依靠它来确保万无一失，永远不要硬编码或假设这些值。

这些额外的类型是 `short int`、`long int` 和 `long long`。在这些这些类型时，C 开发者会省略 `int` 部分（例如使用 `long long`），编译器也是完全接受的。

```
// 这两行是等价的：
long int x;
long x;
```

```
// 这些也是如此：
short int;
short x;
```

让我们按从小到大、按有符号分组的方法查看整数类型和尺寸。

| 类型 | 最小字节 | 最小值 | 最大值 |
|---|---|---|---|
| char | 1 | -127 或 0 | 127 或 255 |
| signed char | 1 | -127 | 127 |
| short | 2 | -32767 | 32767 |
| int | 2 | -32767 | 32767 |
| long | 4 | -2147483648 | 2147483648 |
| long long | 8 | -9223370236854775808 | 9223370236854775807 |
| unsigned char | 1 | 0 | 255 |
| unsigned short | 2 | 0 | 65535 |
| unsigned int | 2 | 0 | 65535 |
| unsigned long | 4 | 0 | 4294967295 |
| unsigned long long | 8 | 0 | 1844674403709551615 |

并没有 `long long` 类型。你不能像那样一直增加 `long`。那太愚蠢了。
你的补码的补码可能注意到这些数字有些奇怪的地方。为什么例如，有符号的 `char` 的值是 -127 而不是 -128？记住：这些仅仅是规范要求的最小值。某些数字表示法（如符号值法）在 -127 处停止。

### 14.4 更多浮点：double 和 long double

让我们看看规范关于浮点数的 §5.2.4¶1-2：

以下参数用于定义浮点模型：

| 参数 | 定义 |
|---|---|
| s | 符号 (±1) |
| b | 基数 (整数) |
| e | 指数 (在 $e_{min}$ 到 $e_{max}$ 之间) |
| p | 精度 |
| f_k | 尾数 |

对于所有数字，尾数是相同的。唯一的区别在于指数。

在你的机器上，基数可能是 2 而不是 10。你可以通过打印 `<float.h>` 中的宏来检查。¹¹https://en.wikipedia.org/wiki/IEEE_754

所以每个类型（在我的系统上）都使用额外的字节来获得更高的精度。

但我们所说的精度是多少呢？可以表示多少十位数？

如果你使用二进制（基2）系统来存储数字（几乎所有人都是这样），这会变得有点绕口。

### 14.4.1 多少十位数？

这个关键问题是：“我可以在浮点类型中存储多少个有效十位数，以便在打印时能获得相同的十进制数字？”

浮点类型中可以存储并在打印时确定能获得相同数字的十位数由这些宏决定：

| 类型 | 可以存储的十位数 | 最小值 |
| --- | --- | --- |
| float | FLT_DIG | 6 |
| double | DBL_DIG | 10 |
| long double | LLD_DIG | 10 |
