
## 第 29 章 信号处理

- SIG_IGN 忽略信号。
- SIG_DFL 恢复信号的默认处理程序。

让我们写一个你可以通过 CTRL-C 退出的程序。（别担心——在下面的程序中，你也可以按 RETURN 退出。）

```c
#include <stdio.h>
#include <signal.h>

int main(void)
{
    char s[1024];

    signal(SIGINT, SIG_IGN); // 忽略由 ^C 引起的 SIGINT
    printf("Try hitting ^C... (hit RETURN to exit)\n");

    // 等待一行输入，以免程序直接退出
    fgets(s, sizeof s, stdin);
}
```

查看第 8 行——我们告诉程序忽略 SIGINT，这是按下 CTRL-C 时触发的中断信号。无论你按多少次，该信号都保持被忽略。如果你注释掉第 8 行，你会发现可以无顾忌地按下 CTRL-C 并立即退出程序。

## 29.3 编写信号处理程序

我提到过你也可以写一个处理函数，当信号被触发时就会被调用。
这些函数非常直观，但在规范方面其功能也是受限的。

在之前，让我们来看 `signal(int)` 的函数原型：

```c
void (*)(int sig, void (*func)(int))(int);
```

非常易读，对吧？
**错误！**：

让我们花点时间练习拆解一下。
`signal()` 接受两个参数：一个表示信号的整数，以及指向处理程序的指针 `func`（处理程序返回 void 并接受一个 int 作为参数），下文所示：

| sig | func |
| :--- | :--- |
| void (*)(int sig, void (*func)(int))(int); | |

基本上，我们将传入感兴趣要捕获的信号编号，并传入一个格式的函数指针：

```c
void f(int x);
```

将执行实际的捕获。
现在——该原型的其余部分是做什么的？它基本上全是返回类型。看，`signal()` 在成功时将返回你作为 `func` 传递的任何内容……这意味着它返回一个指向返回 void 并接受一个 int 参数的函数的指针。

| 返回的函数 | 表示我们正在 |
| :--- | :--- |
| 返回一个函数 | |
| 指向函数的空指针 | 接受一个 int |
| void | (*signal(int sig, void (*func)(int)))(int); | |

此外，发生错误时它可以返回 `SIG_ERR`。

让我们做一个例子，使其必须按两次 CTRL-C 才能退出。

我想明确的是，这个程序在几个方面涉及了未定义行为。但它对你来说可能有效，而且很难写出可移植的非平凡演示。

```c
#include <stdio.h>
#include <stdlib.h>
#include <signal.h>
```

```c
int count = 0;

void sigint_handler(int signum)
{
    // 编译器允许运行：
    //
    signal(signum, SIG_DFL)
    //
    // 当处理程序被调用时。所以我们重置处理程序
    signal(SIGINT, sigint_handler);

    (void)signum; // 消除未使用变量的警告

    count++; // 未定义行为
    printf("Count: %d\n", count); // 未定义行为

    if (count == 2) {
        printf("Exiting!\n"); // 未定义行为
        exit(0);
    }
}
```

```c
int main(void)
{
    signal(SIGINT, sigint_handler);

    printf("Try hitting C...\n");

    for(;;); // 无限等待
}
```

你会注意到的点之一是第 14 行我们重置了信号处理程序。这是因为 C 有选项在运行你的自定义处理程序之前将信号处理程序重置为 SIG_DFL。换句话说，它可能是一次性的。我们先重置它，以便在处理下一个信号时再次处理。

在这种情况下，我们忽略了 `signal(sig)` 的返回值。如果我们早些将其设置为不同的处理程序，它将返回指向该处理程序的指针，我们可以这样获取它：

```c
// old_handler 类型为“指向一个接受单个
// 参数并返回 void 的函数”
```

void (*old_handler)(int);

old_handler = signal(SIGINT, sigint_handler);
```

尽管如此，我不确定这是否有常见的用例。但如果你出于某种原因需要旧处理程序，可以通过这种获取。

关于第 16 行的快速说明——那只是为了告诉编译器我们没有使用这个变量。它在说：“我知道你在用它；你不需要警告我。”
