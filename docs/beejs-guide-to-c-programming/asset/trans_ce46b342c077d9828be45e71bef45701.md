## 23.6 指针差

正如你在指针算术节中所了解的，你可以从一个指针中减去另一个指针¹¹，得到它们之间在数组元素个数上的差。

由于差值的类型取决于实现，因此它可能会随系统而异。

为了提高可移植性，你可以将结果存储在 `<stddef.h>` 中定义的 `ptrdiff_t` 类型变量中。

```c
int cats[100];

int *f = cats + 20;
int *g = cats + 60;

ptrdiff_t d = g - f; // 差值为 40
```

你可以通过在格式说明符前加上 `t` 来进行打印：
`printf("%d\n", d);` // 打印十进制：40
`printf("%x\n", d);` // 打印十六进制：28
```

## 23.7 函数指针

函数只是内存中机器指令的集合，因此没有理由不能获取指向函数第一条指令的指针。

然后调用它。

这对于将函数指针作为参数传递给另一个函数非常有用。那么，第二个函数就可以调用传入的任何内容。

这些指针的棘之处在于，C 需要知道作为函数指针变量的类型。

而且它非常想知道所有的细节。

比如“这是一个接受两个参数并返回 `void` 的函数指针”。

你如何编写它以便声明变量呢？

事实证明，它看起来非常像函数原型，只是多了一些额外的括号。

```c
// 声明 p 为一个指向函数的指针。
// 该函数返回一个 float，并接受两个 int 作为参数。
float (*p)(int, int);
```

另外注意，你不需要给参数命名。但如果你想的话，可以命名；它们会被忽略的。

```c
// 声明 p 为一个指向函数的指针。
// 该函数返回一个 float，并接受两个 int 作为参数。
float (*p)(int a, int b);
```

> ¹假设它们指向同一个数组对象。

现在我们知道如何声明变量了，我们如何知道给它赋值什么？我们如何获取函数的地址？

事实有一个捷径，就像获取数组指针一样：你可以直接引用不带括号的裸函数。（你可以在它前面加 `&`，但这是没必要的，也不符合习惯。）

一旦你拥有了函数指针，你就可以通过添加括号和参数列表来调用它。

让我们做一个简单的例子，我通过设置指向该函数的指针来有效地为函数创建一个别名。然后我们调用它。

这段代码打印 3490：

```c
#include <stdio.h>

void print_int(int n) {
    printf("%d\n", n);
}

int main() {
    // 将 print_int 赋值给 p:
    void (*p)(int) = print_int;
    p(3490); // 通过指针调用 print_int
}
```

注意 p 的类型如何返回了 `print_int` 的返回值和参数类型。它必须这样做，否则 C 会报错说指针类型不兼容。

另一个例子展示了我们如何将函数指针作为参数传递给另一个函数。我们将编写一个接受几个整数参数的函数，加上一个操作这两个参数的函数指针。然后它打印结果。

```c
#include <stdio.h>

int add(int a
// (此处省略部分代码)
print_math(add, 5, 7);   // 12
print_mult(mult, 5, 7);   // 35
```

花点时间消化。这里的想法是我们将一个指向函数 `print_math()` 的指针，它将调用该函数进行一些数学运算。

我们可以通过向它传递另一个函数来改变 `print_math()` 的行为。你可以在第 22-23 行看到这一点，当时我们分别传递了函数 `add` 和 `mult` 的指针。

现在，在第 13 行，我想我们都能同意 `print_math()` 的函数签名是一个引人入胜的景象。而且，如果你相信的话，这与某些你能够构造的东西¹¹相比，其实非常直观。

但让我们消化一下。事实证明只有三个参数，但它们很难看清：

```c
//                op        x    y
//      [---op---] |--| |--]
void print_math(*op)(int, int), int x, int y)
```

第一个 `op` 是一个指向接受两个参数并返回 `int` 的函数指针。这与 `add()` 和 `mult()` 的签名匹配。

第二个以及 `x` 和 `y` 只是标准的 `int` 参数。

## 24 位运算

位运算允许你操作变量中的单个位，由于 C 是一种如此底层的语言¹。

如果你对位运算不熟悉，维基百科有一篇很好的介绍。²

## 24.1 位与、或、异或或非

对于这些每种运算，都会在操作数上进行常规算术转换（在这种情况下必须是整数类型），然后执行相应的位运算。

| 运算 | 运算符 | 示例 |
|---|---|---|
| 与 | & | a & b |
| 或 | | | a | b |
| 异或 | ^ | a ^ b |
| 非 | ~ | a ~ c |

注意它们有赋值变体 `&&`。

## 24.2 位移

对于位移，整数会进行提升（在这种情况下必须是整数类型），然后执行位移。结果的类型是提升的操作数的类型。

新位用零填充，下方有一个可能的实现定义的异常。

| 运算 | 运算符 | 示例 |
|---|---|---|
| 左移 | << | b << c |
| 右移 | >> | b >> c |

位移也有相同的简写形式：

| 运算 | 示例 | 等效写法 |
|---|---|---|
| >>= | c | a >> c |
| <<= | c | a << c |

注意未定义行为：负位移，以及大于提升操作数大小的移。

还要注意实现定义的行为：如果你右移负数，结果是实现定义的。（确保它是有符号整数右移是完全没问题的。）

¹并不是其他语言没有——它们有。
²https://en.wikipedia.org/wiki/Bitwise_operation

## 第 25 章 可变函数

可变是接受任意数量参数函数的术语。

普通函数接受特定数量的参数，例如：

```c
int add(int x, int y)
{
    return x + y;
}
```

你只能用两个参数调用，对应参数 x 和 y。

但如果你尝试更多，编译器将不会允许。

可变函数在某种程度上规避了这一局限性。

我们已经在 `printf()` 中见过一个著名的例子了！你可以向它传递各种东西：

它似乎不在乎你给出多少参数！

嗯，这不完全正确。零参数会导致错误：

```c
printf(); // 错误
```

这引出了 C 中可变函数的一个限制：它们必须至少有一个参数。

但除此之外，它们非常灵活，甚至允许参数具有不同类型，如 `printf()`。

让我们看看它们是如何工作的！
