# 39.6 Thread Local Data

Threads are interesting because they don't have their own memory local variables. If you want a static variable or file variable, all threads will see that same variable.

This can lead to races, where we have a static foo in block scope in run(). This variable will be visible to all threads that pass through the run() function. And the various threads can effectively step on each others.

Each thread copies foo into a local variable x (which is not shared between threads—all the threads have their own stacks). They should be the same, right?
