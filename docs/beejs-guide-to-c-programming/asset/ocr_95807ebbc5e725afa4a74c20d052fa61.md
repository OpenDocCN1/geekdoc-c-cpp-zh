# 27.1 What is Unicode?

Back in the day, it was popular in the US and much of the world to use a 7-bit or 8-bit encoding for characters in memory. This meant we could have 128 or 256 characters (including non-printable characters) total. That was fine for a US-centric world, but there are actually other alphabets out there—who knew? Chinese has over 50,000 characters, and that's not fitting in a byte.

So people came with all kinds of elements to represent their own character sets. And that was fine, but turned into a compatibility nightmare.

To escape it, Unicode was invented. One character to rule them all. It extends out into infinity (effectively) we'll never run out of space for new characters. It has Chinese, Latin, Greek, cuneiform, chess symbols, emojis... just about everything, really! And more is added all the time!
