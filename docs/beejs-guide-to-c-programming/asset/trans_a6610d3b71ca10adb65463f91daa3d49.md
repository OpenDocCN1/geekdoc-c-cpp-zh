
## 14.5.3 浮点数常量

你可能认为像 1.23 这样的浮点数常量默认类型是 `float`，对吧？惊喜吧，未加后缀的浮点数类型是 `double`！祝你迟生日快乐！

你可以通过附加 `f`（或 `F`——它不区分大小写）将其强制转换为 `float` 类型。你可以通过附加 `l`（或 `L`）将其强制转换为 `long double` 类型。

| 类型 | 后缀 |
|---|---|
| float | F |
| double | 无 |
| long double | L |

例如：

```
float x = 3.14f;
double x = 3.14;
long double x = 3.14L;
```

不过，这次，我们直一直在这么做，对吧？
float x = 3.14;

左边不是一个 `float` 和 `double` 吗？是的！但 C 语言处理自动数值转换非常出色，所以没有后缀的浮点数常量比有的更常见。或者我们以后再说。

### 14.5.3.1 科学计数法

还记得之前我们讨论过浮点数可以用系数、基数和指数来表示吗？

嗯，写这种数字有一种常用方法，这里显示了，后面是更容易识别的等价形式，当你实际运行计算时得到的结果：

1.2345 × 10³ = 1234.5

以 s × b¹⁰ 的形式写数字被称为科学计数法¹⁴。在 C 中，这些使用的是“E 计数法”，所以它们是等价的：

| 科学计数法 | E 计数法 |
|---|---|
| 1.2345 × 10⁻³ | 1.2345e-3 |
| 1.2345 × 10⁸ | 1.23450000e+8 |

你可以用 `%` 打印这种格式的数字：
printf("%s\n", 1.234560e+05);
关于科学计数法的几个小知识：

- 你不需要在小数点前只写一个数字。可以写任意数量的数字。

```
double x = 123.456e3; // 123456
```

然而，当你打印它时，它会改变指数，使得小数点前只有一个数字。

> ¹⁴https://en.wikipedia.org/wiki/Scientific_notation

指数部分可以省略加号，它是默认的，但根据我所见，在实践中这并不常见。

1.2345e10 == 1.2345e+10

你可以对 E 计数法常量应用 F 或 L 后缀：

1.2345e10
1.2345e10L

### 14.5.3.2 十进制浮点常量

但等一下，还有更多的浮点需要处理！

事实证明也有十六进制浮点常量！

它们的工作原理与十进制浮点数类似，但它们像整数一样以 0x 开头。

在于你必须指定一个指数，而这个指数会产生 2 的幂。即：2^x。

在写数字时，使用 `p` 代替 `e`：

所以 0xa.1p3 是 10.0625 × 2^3 = 80.5。

使用浮点常量时，我们可以用 `%` 打印十六进制科学计数法：

double x = 0xa.1p3;

```

printf("%f\n", x);   // 80.500000
```

## 类型 III：转换

在本章中，我们想要讨论所有从一种类型转换为另一种类型。C 语言有多种实现方法，某些可能与你在其他语言中习惯的有所不同。

在讨论转换如何发生之前，让我们先聊聊它们在发生时是如何工作的。

## 15.1 字符串转换

与许多语言不同，C 语言的 字符串到数字（以及反之）的转换不像数值转换那样流畅。

对于这些转换，我们必须调用函数来完成这些脏活工作。

### 15.1.1 数值到字符串

当我们想要将数字转换为字符串时，可以使用 `sprintf()`（读作 SPRINT-f）或 `snprintf()`（s-n-print-f*）。

它们的工作原理基本上和 `printf()` 相似，只是它们输出到字符串，你之后可以打印那个字符串，或者随意的。

例如，将值 π 的部分转换为字符串：

```c
#include <stdio.h>

int main(void)
{
    char s[10];
    float f = 3.14159;

    // 将 "f" 转换为字符串，存储在 "s" 中，最多写入 10 个字符
    // 包括空 终止符

    snprintf(s, 10, "%f", f);

    printf("String value: %s\n", s); // String value: 3.141590
}
```

所以你可以像对待整数一样使用 `%d` 或 `%u`。

> 它们是相同的，除了 snprintf() 允许你指定输出的最大字节数，防止字符串溢出。所以它更安全。

### 15.1.2 字符串到数值

C 语言中有几族函数可以实现此操作。我们称之为为 `atoi` 系列（读作 atoi-to-i）和 `strtol` 系列（str-to-long）。对于从字符串到数字的基本转换，尝试使用 `<stdlib.h>` 中的 `atoi` 函数。由于这些函数具有糟糕的错误处理特性（如果传递错误的字符串会产生未定义行为），所以请谨慎使用。

| 函数 | 描述 |
|---|---|
| atoi | 字符串转 int |
| atof | 字符串转 float |
| atol | 字符串转 long int |
| strtol | 字符串转 long int |

虽然函数开头的字母不代表 ASCII，所以说那样有点以 ASCII 为中心。这里有一个将字符串转换为 float 的示例：

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char *pi = "3.14159";
    float f;

    f = atof(pi);

    printf("%f\n", f);
}
```
