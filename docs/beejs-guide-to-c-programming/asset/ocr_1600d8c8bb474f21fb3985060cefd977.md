Like regular arrays, you can use parentheses with sizeof() to get the size of a would-be-VLA

```
int x = 12;
```

```
printf("%zu\n", sizeof(int [x]));  // Prints 48 on my system
```

# 30.3 Multidimensional VLAs

You can go ahead and make all kinds of VLAs with one or more dimensions set to a variable

```
int w = 10;
int h = 20;
```

```
int x[h][w];\int y[5][w];\int z[10][w][20];
```

Again, you can navigate these just like you would a regular array.

# 30.4 Passing One-Dimensional VLAs to Functions

Passing single-dimensional VLAs into a function can be no different than passing a regular array. You
just for it.

```
#include <stdio.h>
```

```
int sum(int count, int *v)
{
  int total = 0;

  for (int i = 0; i < count; i++)
    total += v[i];

  return total;
}
```

```
int main(void)
{
  int x[5]; // Standard array

  int a = 5;
  int y[a];  // VLA

  for (int i = 0; i < a; i++)
    x[i] = y[i] = i + 1;

  printf("%d\n", sum(5, x));
  printf("%d\n", sum(a, y));
}
```
