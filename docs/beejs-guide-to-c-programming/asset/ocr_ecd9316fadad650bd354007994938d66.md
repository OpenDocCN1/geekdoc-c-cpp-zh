# 25.4 Library Functions That Use va_lists

One of the other uses for these is pretty cool: writing your own printf() variant. It would be a pain to have handle all those format specifiers right? All zillion of them?

Luckily, there are printf() variants that accept a working va_list as an argument. You can use these to wrap and make your own custom()!

These functions start with the letter v, such as vprintf(), vfprintf(), vsprintf(), and vsnprintf(). Basically all your printf() golden idols except with a v in front.

Let's make a my_printf() that works like printf() it takes an extra argument up front.

```
#include <stdio.h>
#include <stdarg.h>

int my_printf(int serial, const char *format, ...)
{
    va_list va;
    // Do my custom work
    printf("The serial number is: %d\n", serial);

    // Then pass the rest off to vprintf()
    va_start(va, format);
    int rv = vprintf(format, va);
    va_end(va);
    return rv;
}

int main(void)
{
    int x = 10;
    float y = 3.2;

    my_printf(3490, "x is %d, y is %f\n", x, y);
}
```

See what we did there? On lines 12-14 we started a new va_list, and then passed it right into vprintf(). And it just wants to do with it, because it has all the printf() smarts built-in.

We still have to call va_end() when we're done, though, so don't forget that!
