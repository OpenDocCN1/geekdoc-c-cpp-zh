# Chapter 39. Multithreading

The destructor is type tss_dtor_which is a pointer to a function that returns void and takes a void as an argument (the "void*) points to the data stored in the variable). In other words, it's a void (*)void*) that clears it up. I admit it probably doesn't. Check out the example, below:

Generally, thread_local is probably by your go-to, but if you use the destructor, then you can make use of that.

The usage is a bit weird that we initialize it with type tss_t to be relative to the value on a per thread basis. We initialize it with tss_create(). Eventually we get rid of it with tss_delete(). Note that calling tss_delete() doesn't run the destructors-it's thrd_exit(or returning from the run function) that does. tss_delete() releases any memory allocated by tss_create().

In the middle threads we call tss_set() and tss_get() to set and get the value.

In the following code, we set up the TSS variable before creating, then clean up after the threads.

In the run() function, the thread malloc() some space for a string and then store that pointer in the TSS variable. When the thread exits, the destructor function (free in this case) is called for all the threads.

```
#include <stdio.h>
#include <stdlib.h>
#include <threads.h>

tss_t str;

void some_function(void)
{
    // Retrieve the per-thread value of this string
    char *tss_string = tss_get(str);

    // And print it
    printf("TSS string: %s\n", tss_string);
}

int run(int *arg)
{
    int serial = *(int*)arg; // Get this thread's serial number
    free(arg);

    // malloc() space to hold the data for this thread
    char *s = malloc(64);
    printf(s, "thread %d!:\n", serial); // Happy little string

    // Set this TSS variable to point at the string
    tss_set(str, s);

    // Call a function that will get the variable
    some_function();

    return 0; // Equivalent to thrd_exit(0)
}

#define THREAD_COUNT 15

int main(void)
{}
```
