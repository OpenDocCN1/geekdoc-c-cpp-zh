# 27.6 A Quick Note on UTF-8 Before We Swerve into the Weeds

It could be your source file on disk, the extended source characters, and the extended execution characters are all in UTF-8 format. The libraries you use expect UTF-8. This is the glorious future of UTF-8 everywhere.

If that's the case, and you don't mind being non-portable to systems that aren't like that, then just run with it. Stick Unicode characters in your source and data and it will be happy. Use regular C strings and be happy.

A lot of things will work (almost non-portably) because UTF-8 strings can be NULL-terminated just like any other C string. But losing much for easier character handling is a tradeoff that's worth it to you.

There are some caveats:

+   * Things strlen() returns the number of bytes in a string, not the number of characters, necessarily. (The mbstows returns the number of characters in a string when you convert it to wide characters. POSIX extends this so you can call NULL for the first argument if you just want the character count).
* The following won't work properly with characters of more than one character: strtok(), strchr() (use strcmp instead), strncpy()-functions, lower(), isalpha()-type functions, and probably more. Beware that operates on bytes.
* If you want to malloc() for a string, or declare an array of chars for, be aware that the maximum size could be more than you were expecting. Each character could take up to MB_LEN_MAX bytes (<limits.h>);except characters in the basic character set are guaranteed to be one byte.
* printf() variants allow for a way to print many bytes of a string. You want to make sure you print the number of bytes to end on a character boundary.

And others I haven't discovered. Let me know what pitfalls are out there...

# 27.7.1 Multibyte Characters

First of all, I want to change your thinking about what a string (array of chars) is. These are strings made up of multibyte characters.

That's—run-of-the-mill string of characters is multibyte. When someone says “C string”, they mean “C multibyte string".

Even if a particular character in the string is only a single byte, or if a string is made up of only single characters, it's known as a multibyte string.

For example:

```
char c[128] = "Hello, world!\ // multibyte string
```

What we're saying is a particular character that's not in the basic character set could be composed of multiple bytes. Up to MB_LEN_MAX of them (<limits.h>). Sure, it looks like one character on the screen, but it could be multiple bytes.
