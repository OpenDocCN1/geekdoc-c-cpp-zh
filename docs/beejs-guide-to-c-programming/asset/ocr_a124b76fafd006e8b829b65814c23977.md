# Chapter 1. Foreword

As a rule, the more complex the question, the less likely I am to respond. If you narrow down your question before mailing it be sure to include any pertinent information (like platform, compiler, error messages you're getting, and anything else you might help me troubleshoot), you're much more likely to get a response.

If you don't get a response, has it on them more, try to find the answer, and if it's still elusive, then tell me again with the information you've found and hopefully it will be enough to help you out.

Now I've badgered you about how to write and not to write, I'd like to let you know that I fully appreciate all the praise the guide has received over the years. It's a real morale boost, and it gladness to me that it is being used for good! :- Thank you!
