# 33.1 Type Qualifiers for Arrays in Parameter Lists

If you recall from earlier, these two are equivalent in function parameter lists:

```
int func(int p) {......}
int func(int p[]) {......}
```

And you might recall that you can add qualifiers to a pointer variable like so:

```
int const p;
int volatile p;
int const volatile p;
// etc.
```

But how can we do when we're using array notation in our parameter list?
Turns out it goes in the brackets. You can put the optional qualifier after. The two following lines are equivalent:

```
int func(int volatile p) {......}
int func(int p[const volatile]) {......}
int func(int p[const volatile 30]) {......}
```

If you have a multidimensional array, you need to put the type qualifiers in the first set of brackets.

# 33.2 static for Arrays in Parameter Lists

Similarly, you can use the static keyword in the array in a parameter list.

This is something I've never seen in the wild. It is always followed by a dimension:

```
int func(int p[static 4]) {......}
```
