## 1.2 如何阅读本书

本书由两部分组成：第一部分是教程，第二部分是参考资料。

如果你是新手，请按照顺序阅读教程部分。随着你阅读的章节增加，阅读顺序就不那么重要了。

参考资料部分包含了标准库函数调用的示例，供你需要时查阅。无论你的水平如何，这部分都有帮助。

最后，如果你阅读的是印刷版，书中的章节是*斜体*的。

## 1.3 平台与编译器

我将尽可能遵循 ISO 标准 C 语言¹⁰。在这里我可能会疯狂讨论 POSIX ¹¹，但走着吧。

**Unix** 用户（例如 Linux、BSD 等）尝试从命令行运行 `gcc`——你可能已经安装了编译器。如果没有，请搜索你的发行版以安装 `gcc`。

**Windows** 用户应该查看 Visual Studio²。或者，如果你寻找类 Unix 的体验（推荐！），请安装 WSL³。

**Mac** 用户需要 Xcode¹，特别是命令行工具。

市场上有很多编译器，几乎所有的编译器都适用于本书。而且 C++ 编译器可以编译大部分（但并非所有）¹代码。如果可能，请使用正式的编译器。
