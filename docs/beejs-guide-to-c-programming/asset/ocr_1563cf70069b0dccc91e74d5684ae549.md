Hey, so we have here a variable that is a pointer type, and it can point to other ints. That is, it can hold the
address of other ints. We know it points to ints, since it's of type int* (read "int-pointer").

When we do an assignment to a pointer variable, the type of the right hand side of the assignment has to
be the same type as the pointer variable. Fortunately for us, when we take the address of a variable, the
resultant type is pointer to that variable, so assignments like the following are perfect:

```
int;
int *p; // p is a pointer, but uninitialized and points to garbage

p = &i; // p is assigned the address of i-- now "points" to i
```

On the left of the assignment, we have a variable of type int pointer-to-int (*), and on the right side, we
have expression of type pointer-to-int is an int (address-of int gives you a pointer to int).
The address of a thing can be stored in a pointer to that.

Get it? It still might not make much sense since you haven't seen an actual use for the pointer
variable, we're taking small steps here that no one gets lost. Now, let's introduce you to the-

# 5.3 Dereferencing

A pointer variable can be thought of *referring to another by pointing to it. It's rare you'll hear
anyone in C land talking "referring" or "references", but I bring it up so that the name of this
operator will make a little more sense.

When you pare to a pointer (roughly "a reference to a variable"), you can use the original
through the pointer by *dereferencing* the pointer. (You) can think of this as "de-pointing" the pointer,
or ever says "de-pointing".

Back to our analogy, this is vaguely looking like a home address and then going to that house.

Now, what do I mean by "get access to the original variable?" Well, if you have a variable called 1, and
you have a pointer to i, you can use the dereferenced pointer p exactly as if it were the original variable
if!

You have enough knowledge to handle an example. The last thing you need to know is exactly
this: what is the dereference operator? It's actually the indirection operator, because you're accessing
values indirectly via the pointer. And it is the asterisk: *. Now, don't get confused with the asterisk
y used in the pointer declaration, earlier They are the same character, but they have different meanings in
different contexts.

Here's a full-blown example:

```
#include <stdio.h>

int main(void) {
int i;
int *p; // this is NOT a dereference--this is a type "int*"

p = &i; // p now points to i, p holds address of i

i = 10; // i is now 10
*p = 20; // the p points to (namely!) i is now 20!!
```

same*, but the context gives it different meaning.
