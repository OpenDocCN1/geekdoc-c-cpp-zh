
你可以给它们起一个标签名，这样以后就可以引用该类型并声明该类型的变量。

现在，由于枚举（enums）是整数类型，为什么不直接用 `int` 呢？

在 C 语言中，最好的理由是代码的清晰度——它是一种很好的、类型化的方式来描述你的思路。C（与 C++ 不同）实际上并没有规定特定枚举的数值范围。

让我们来看一个例子，声明一个类型为 enum resource 的变量 r，它可以持有这些值：

```c
// 命名枚举，类型为 "enum resource"

enum resource {
  SHEEP,
  WHEAT,
  WOOD,
  BRICK,
  ORE
};
```

// 声明类型为 "enum resource" 的变量 "r"

```c
enum resource r = BRICK;

if (r == BRICK) {
  printf("I'll trade you a brick for two sheep.\n");
}
```

当然，你也可以对它们进行 typedef 定义，尽管我个人不喜欢这样做。

```c
typedef enum {
  SHEEP,
  WHEAT,
  WOOD,
  BRICK,
  ORE
} RESOURCE;
```

RESOURCE r = BRICK;

另一种合法但少见的快捷方法是在声明枚举时声明该类型的变量：

// 声明一个枚举以及该类型的一些初始化变量：

```c
enum {
  SHEEP,
  WHEAT,
  WOOD,
  BRICK,
  ORE
} r = BRICK, s = WOOD;
```

你也可以给枚举命名，以便以后使用，这可能正是你大多数情况下想要做的。

// 声明一个枚举以及该类型的一些初始化变量：

```c
enum resource {
// <-- 类型现在是 "enum resource"
  SHEEP,
  WHEAT,
  WOOD,
  BRICK,
  ORE
} r = BRICK, s = WOOD;
```

简而言之，枚举是编写良好的、作用域化的、类型化的整洁代码的一种棒方法。

### 23.1 指针的指针

如果你可以有一个指向变量的指针，而变量可以是一个指针，那么你是否可以有一个指向“本身是指针的变量”的指针呢？

可以！这是一个指向指针的指针，它存储在一个类型为指针-指针的变量中。

在我们深入研究之前，我想尝试*感受*一下二级指针是如何工作的。
记住，指针只是一个数字。它是一个代表计算机内存索引的数字，通常存储着我们由于某种原因而感兴趣的值。

这个指针本身是一个数字，它必须被存储在某处。而那个地方就是内存，就像其他所有东西一样。

但因为它有一个存储的索引，对吧？指针在内存中存储时必须有一个索引。那个索引是一个数字。它是指针的地址。即指向指针的指针。

让我们从前面的章节中回到普通的 int 指针开始：

```c
#include <stdio.h>

int main(void)
{
    int x = 3490; // 类型：int
    int *p = &x; // 类型：指向 int 的指针

    printf("%d\n", p); // 3490
}
```

> 在存储在寄存器中的值中，存在一些细节，但就我们的目的而言，可以安全地忽略。此外，C 规范对 register 关键字之外的“寄存器”事务没有立场，而该关键字的描述也没有提到寄存器。
