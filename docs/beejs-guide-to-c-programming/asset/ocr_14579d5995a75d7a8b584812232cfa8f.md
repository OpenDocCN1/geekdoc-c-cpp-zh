After the C preprocessor has finished preprocessing, the results are ready for the
compiler to take and produce assembly code¹, machine code¹⁰, or whatever it's about to do. Machine
code is the "language" the CPU understands, and can understand it very rapidly. This is one of the reasons
C programs need to be.

Don't worry about the technical details of compilation for now; know that your source runs through the
preprocessor, the output of which the compiler, then produces an executable for you
run.
