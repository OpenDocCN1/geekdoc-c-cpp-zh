# 39.8.1 Condition Wait

There's a variant of cnd_wait() that allows you to specify a timeout so you can stop waiting.

Since the child thread must reload the mutex, this doesn't necessarily mean that you'll be popping back to the instant the timeout occurs; you must still wait for any other threads to release the mutex.

But it means that you won't be waiting until the cnd_signal() happens.

To make this work, call cnd_timed_wait() instead of cnd_wait(). If it returns the value thrd_timed, it timed out.

The timestamp is always in UTC, not a time-from-now. Frankly the timespec_get() function in <time.h> seems custom-made for this case.

```
struct timeout;
timespec_get(&current_time, TIME_UTC); // Get current time
time.tv_sec += 1; // Timeout 1 second after now
```

```
int result = cnd_timed_wait(&condition, &mutex, &timeout);

if (result == thrd_timedout) {
    printf("Condition variable timed out!\n");
}
```
