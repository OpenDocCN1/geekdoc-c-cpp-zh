# Chapter 11. Pointers II: Arithmetic

Infact, the prior example could be written these equivalent ways:

```
```c
printf("%d\n", *p);      // Prints 11
printf("%d\n", *(p + 0)); // Prints 11
```
```

because adding 0 to a pointer results in the same pointer.

Let's think of the upside here. We can iterate over elements of an array this way using an array:

```
```c
int a[5] = {11, 22, 33, 44, 55};

int *p = &a[0]; // Or "int *p = a;" works just well

for (int i = 0; i < 5; i++) {
    printf("%d\n", *(p + i)); // Same as p[i]!
}
```
```

And that works as if we use array notation! Oooo! Getting closer to that array/pointer equivalence thing! More on this in a later chapter.

But what's actually happening? How does it work?

Remember from early on that memory is like a big array, where a byte is stored at each array index?
And the array index into memory has a few names:

+   * Index into memory
* Location
* Address
* Pointer!

So a point is an index into memory, somewhere.

For a random example, say that a 3490 was stored at address ("index") 23,237,489,202. If we have an int pointer to 3490, that value of pointer is 23,237,489,202... because the pointer is the memory address. Different names for the same thing.

And now let's have another number, 4096, stored at address 23,237,489,210 (8 higher than the 3490 because each int in this example is 8 bytes long).

If we add 1 to that pointer, it actually jumps sizeof(int) bytes to the next int. It knows to jump that far ahead because it's an int pointer. If it were a float pointer, it'd jump sizeof(float) bytes ahead to get the next float!

So you can look at the next int, adding 1 to the pointer, the one after by adding 2 to the pointer, and so on.

# 11.1.2 Changing Pointers

We saw how we could add an integer to a pointer in the previous section. This time, let *modify* the pointer, itself.

You can just add (or subtract) integer values directly to (or from) your pointer!

Let's do that example again, except with a couple changes. First, I'm going to add a 999 to the end of our numbers to act as a sentinel value. This will let us know where the end of the data is.

```
```c
int a[] = {11, 22, 33, 44, 55, 999}; // Add 999 here as a sentinel
```
```

```
```c
int *p = &a[0]; // p points to the 11
```
```

And we also have p pointing to the element at index 0, namely, 11, just before.
