What about those constant characters in single quotes, 'B'? How does that have a numeric value?
The spec is also hand-wavey, since C isn't designed to run on a single type of underlying system.
But let's just assume the moment that your character set is based on ASCII for at least the first 128 characters. In that case, the character constant will be converted to a char whose value is the same as the ASCII value of the character.

Yes, I said "minimum" twice. The spec says that types will hold numbers of at least these sizes, so your implementation might be different. The header file <limits.h> defines macros that hold the minimum and maximum integer values; rely on that to be sure, and never hardcode or assume these values.

These additional types are short int, long int, and long long. When using these types, C developers leave the part int out (e.g. long long), and the compiler is perfectly happy.

```
// These two lines are equivalent:
long int x;
long x;
```

```
// And so are these:
short int;
short x;
```

### 14.4 More Float: double and long double

Let's see what the spec has to say about floating point numbers in §5.2.4.2¶1-2:

The following parameters are used to define the model for each floating-point type:

| Parameter | Definition |
|---|---|
| s | sign (±1) |
| b | base (integer) |
| e | exponent (between $e_{min}$ and $e_{max}$) |
| p | precision (number of digits) |
| f_k | significand (decimal digits) |

For all those numbers, the significand stays the same. The only difference is the exponent.

On your machine, the base is probably 2, not 10. You can check it by printing the macros in <float.h>.$^{11}$https://en.wikipedia.org/wiki/IEEE_754

So each of the types (on my system) uses those additional bytes for more precision.

But how much precision are we talking, How many decimal digits can be represented by the values?

Well, C provides us with a bunch of macros in <float.h> to help us figure that out.

It gets a little windy if you are using a base-2 (binary) system for storing the numbers (which is virtually everyone on the planet, but bear with me while we figure it out.

### 14.4.1 How Decimal Digits?

The million question is, “How many significant decimal digits can I store in a floating point type so that I get the same decimal number back when I print it?

The number of decimal digits you can store in a floating point type and surely get the same number out when you print it is by these macros:

| Type | Decimal Digits You Can Store | Minimum |
| --- | --- | --- |
| float | FLT_DIG | 6 |
| double | DBL_DIG | 10 |
| long double | LLD_DIG | 10 |
