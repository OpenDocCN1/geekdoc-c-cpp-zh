

## 6.6 数组与指针

[随口提到] 所以……我上面好像提到过，数组在深层其实是指针？我们现在应该进行深入探讨，以免让事情变得完全困惑。之后，我们会查看数组和指针之间的真实关系，但现在我想看看如何将数组传递给函数。

### 6.6.1 获取数组的指针

我想告诉你们一个秘密。通常情况下，当一个 C 程序员谈论数组的指针时，他们说的是指向数组第一个元素的指针。

所以，让我们获取数组第一个元素的指针。

```c
#include <stdio.h>

int main(void)
{
    int a[5] = {11, 22, 33, 44, 55};
    int *p;

    p = &a[0]; // p 指向数组
    // 实际上，指向第一个元素

    printf("%d\n", *p); // 打印 "11"
}
```

在 C 语言中这样做很常见，因为它允许一种简写：

`p = &a[0]; // p 指向数组`

// 等同于：

`p = a; // p 指向数组，但看起来好看得多！`

单独引用一个数组等同于获取数组第一个元素的指针！我们将在接后的示例中大量使用这一点。

但等一下——`p` 不是 `int*` 吗？而且 `p` 给我们的是和 `a[0]` 一样的 11？没错。你已经开始窥见 C 语言中数组和指针之间的关系了。

### 6.6.2 将一维数组传递给函数

让我们用一维数组举个例子。我会写几个函数，我们可以将数组传递给不同的东西。

准备好迎接一些震撼的函数吧！

```c
#include <stdio.h>

// 作为指向第一个元素的指针传递
void times2(int *a, int len)
{
    for (int i = 0; i < len; i++)
        printf("%d\n", a[i] * 2);
}
```

> 在技术上这是是不正确的，因为数组的指针和指向数组第一个元素的指针具有不同的类型。但当我们到那里时，再来解决这个问题。

```c
// 同样，使用数组表示法
void times3(int a[], int len)
{
    for (int i = 0; i < len; i++)
        printf("%d\n", a[i] * 3);
}
```

```c
// 同样，使用带尺寸的数组表示法
void times4(int a[5], int len)
{
    for (int i = 0; i < len; i++)
        printf("%d\n", a[i] * 4);
}
```

```c
int main(void)
{
    int x[5] = {11, 22, 33, 44, 55};

    times2(x, 5);
    times3(x, 5);
    times4(x, 5);
}
```

在函数参数列表中列出数组的所有方法都是相同的：
- `void times2(int *a, int len)`
- `void times3(int a[], int len)`
- `void times4(int a[5], int len)`

在 C 语言的规则中，第一种远比其他常见。
而且实际上，在后两种情况下，编译器甚至不在乎你传递了什么（只要它大于 0）。它完全不强制任何限制。

现在我说过，当你将多维数组传递给函数时，函数中数组的大小实际上是重要的，但我们稍后再讨论这个。

### 6.6.3 在函数中修改数组

我们已经说过数组只是伪装的指针。这意味着如果你将数组传递给函数，你很可能传递了指向数组第一个元素的指针。

但如果你有一个指向数据的指针，它就能操作这些数据！所以函数对数组所做的更改在调用者处是可见的。

这里有一个例子，我们将数组的指针传递给函数，函数修改了数组中的值，而这些更改在调用者处是的。

```c
#include <stdio.h>

void double_array(int *a, int len)
{
    // 将每个元素乘以 2
```

> C11 §6.7.2 要求它大于0。但你可能会看到在结构体末尾声明长度为数组的代码，除非使用 -pedantic 编译，否则 GCC 是宽容的。这种零长度数组是可变长度结构的机制。不幸的是，访问此类数组在技术上是未定义行为，尽管它基本上在任何地方都有效。C99 为其定义了一个良好的替代品：灵活数组成员，我们稍后会讨论。

```c
// 这倍增 main() 中 x 的值，因为 x 和 a 都指向
// 内存中的同一个数组！

for (int i = 0; i < len; i++)
    a[i] *= 2;

int main(void)
{
    x[5] = {1, 2, 3, 4, 5};

    double_array(x, 5);
```

即使我们将数组作为 `int*` 类型传递，看看我们使用数组表示法 `&a[1]` 来访问它的。哈，这是完全允许的。

以后当我们讨论数组和指针的等价性时，我们会发现这非常有意义。现在，足够知道函数对数组所做的更改在调用者处是可见的。
