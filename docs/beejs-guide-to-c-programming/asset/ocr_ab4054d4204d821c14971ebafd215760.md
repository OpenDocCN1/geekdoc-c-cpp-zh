```
for (i = 0; i < THREAD_COUNT; i++) {
    // Get some space for a per-thread argument
    int *arg = malloc(sizeof *arg);
    *arg = i;
    thrd_create(t, run, arg);
}
```

Notice on lines 27-30 malloc() space for an int and copy the value of i into it. Each new thread gets its own freshly-malloc()d variable and a pointer to the run() function.

Once run() makes its own copy of the arg on line 7, free()s the malloc()d int. And now that it has its own copy, it can do with it pleases.

# 39.5 Detaching Threads

If you want to fire-and-forget a thread (i.e. so you don't have to thrd_join() it later), you can do that with thrd_detach().

This removes the thread's ability to get the value from the child thread, but if you don't care about that and want threads to clean up nicely on their own this is the way to go.

Basically we're going to this:

```
thrd_create(&at, run, NULL);
thrd_detach(thrd);
```

where the thrd_detach() call is the parent thread saying, "Hey, I'm not going to wait for this child thread to complete with thrd_join(). So go ahead and clean it up on your own when it completes"
