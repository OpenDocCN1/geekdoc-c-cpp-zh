## 3.3.1 if-else 语句

我们已经在多个示例中使用过 `if`，因为你很可能在之前的其他语言中见过它，但这里这里有另一个例子：

```c
int i = 10;

if (i > 10) {
    printf("i is greater than 10.\n");
    printf("And this will also print if i is greater than 10.\n");
}

if (i <= 10) printf("i is less or equal to 10.\n");
```

在示例代码中，如果 `i` 大于 10，则将打印消息，否则执行到下一行。注意 `if` 语句后面的大括号；如果条件为真，将执行第一条语句或紧跟在 `if` 面的表达式，或者执行 `if` 后大括号中的代码集合。这种代码块的行为对于所有语句都是通用的。

当然 C 语言是这种方式，你也可以通过 `if` 的 `else` 子句在条件假时执行某些操作：

```c
int i = 99;

if (i == 10) {
    printf("i is 10!\n");
} else {
    printf("i is decidedly not 10.\n");
    printf("Which irritates me a little, frankly.\n");
}

int i = 99;

if (i == 10) {
    printf("i is 10!\n");
} else if (i == 20) {
    printf("i is 20!\n");
} else if (i == 99) {
    printf("i is 99! My favorite\n");
    printf("I can't tell you how I am.\n");
    printf("Really.\n");
} else
    printf("i is some crazy number I've never heard of.\n");
```

## 3.3.2 while 语句

`while` 是你最常见的循环结构。当条件表达式为真时执行某项操作。

让我们来一个！

```c
// 打印以下输出：
//
// i is now 0!
// i is now 1!
// [ 2 到 7 之间还有类似的内容 ]
// i is now 8!
// i is now 9!
```

i = 0;

```c
while (i < 10) {
    printf("i is now %d\n", i);
    i++;
}
```

```c
printf("All done!\n");
```

这让你掌握了基础循环。C 还有另一种循环，对于那个示例会更简洁。

`while` 的一个常见用法是无限循环，即在 `while` 真时重复：

```c
while (1) {
    printf("1 is always true, so this repeats forever.\n");
}
```

## 3.3.3 do-while 语句 

现在我们已经掌握了 `while` 语句，让我们来看看它紧密相关的表兄弟 `do-while`。

它们基本上是相同的，区别在于如果循环条件在第一次通过时为假，`do-while` 会执行一次，而完全不执行。换句话说，在 `do-while` 中，检查是否执行块的测试发生在块的末尾。而在 `while` 中，它发生在块的开头。

让我们通过示例来看：

```c
// 使用 while 语句：
```

i = 10;

```c
// 这部分代码没有执行，因为 i 不小于 10:
while(i < 10) {
    printf("while: i is %d\n", i);
    i++;
}
```

// 使用 do-while 语句：

```c
i = 10;

// 这部分执行了一次，因为循环条件在
// 循环体之后才被检查：

```c
do {
    printf("do-while: i is %d\n", i);
    i++;
} while (i < 10);
```

```c
printf("all done!\n");
```

注意，在所有情况下，循环条件都是假的。因此在 `while` 中，循环失败，接下来的代码块永远不会执行。但在 `do-while` 中，条件是在代码块执行后才检查的，因此它至少执行一次。在这种情况下，它打印消息，增加 i，然后条件不通过，继续执行“All done!”的输出。

这个故事的道理是：如果你想让循环至少执行一次，无论循环条件如何，请使用 `do-while`。

所有这些示例用 `for` 循环处理可能会更好。
