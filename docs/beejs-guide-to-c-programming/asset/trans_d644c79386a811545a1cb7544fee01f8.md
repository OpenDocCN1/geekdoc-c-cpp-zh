

## 第 25 章 变长函数

你该如何处理所有必须先传递的参数（记住至少有一个参数），在那之后，你写上 `. . .`。就像这样：

```c
void func(int a, ...)    // 这里字面上有 3 个点
```

这里有一些代码来演示：

```c
#include <stdio.h>
```

```c
void func(int a, ...)
{
    printf("a is %d\n", a);    // 打印 "a is 2"
}
```

```c
int main(void)
{
    func(2, 3, 4, 5, 6);
}
```

所以，太好了，我们可以把第一个参数放到变量 `a` 中，但剩下的参数呢？你如何获取它们呢？

有趣的部分开始了！

## 25.2 获取额外的参数

你需要包含 `<stdarg.h>` 来让这些功能正常工作。

首先，我们将使用一个类型为 `va_list`（可变参数列表）的特殊变量来跟踪我们当前正在访问哪一个变量。

思路是：通过调用 `va_start()` 开始处理参数，通过 `va_arg()` 逐个处理每个参数，最后在完成后，用 `va_end()` 进行收尾。

当你调用 `va_start()` 时，你需要传入上一个命名参数（即 `...` 之前的那一个），这样它就知道去哪里寻找额外的参数。

当你调用 `va_arg()` 获取下一个参数时，你需要告诉它下一个要获取的参数类型。

这里有一个演示任意数量整数整数。第一个参数是需要相加的整数个数。我们将利用这一点来确定需要调用多少 `va_arg()`。

```c
#include <stdio.h>
#include <stdarg.h>
```

```c
int add(int count, ...)
{
    int total = 0;
    va_list va;
```

```c
va_start(va, count);    // 从 "count" 之后的参数开始
for (int i = 0; i < count; i++) {
    int n = va_arg(va, int);    // 获取下一个 int
    total += n;
}
```

```c
va_end(va);    // 全部完成
```

```c
return total;
}

int main(void)
{
    printf("%d\n", add(4, 6, 2, -4, 17)); // 6 + 2 - 4 + 17 = 21
    printf("%d\n", add(2, 22, 44)); // 22 + 44 = 66
}
```

注意，`printf()` 是一个占位符，它使用格式字符串中 `%d`（或其他任何类型）的数量来确定有多少个参数。

如果你觉得 `va_arg()` 的语法看起来很奇怪（因为里面有一个漂浮的松散类型），那你并不孤单。这些都是通过预处理器宏实现的，以便获得所有正确的“魔法效果”。

## 25.3 va_list 功能

我们在这里使用的 `va_list` 变量是什么？它是一个不透明的变量，包含了关于我们接下来准备用 `va_arg()` 获取哪一个参数的信息。你看到我们是如何反复调用 `va_arg()` 的吗？`va_list` 变量就像一个占位符，记录着目前为止的进度。

但我们必须将 `va_list` 初始化为合理的状态。这就是 `va_start()` 发挥作用的地方。

这就是为什么我们必须初始化初始参数，你可以通过反复调用 `va_arg()` 轻松获取后续参数。当你这样做时，必须传入你的 `va_list`（以便它可以持续跟踪你所处的位置），以及你准备拷贝的参数类型。

作为程序员，决定要给 `va_arg()` 传递什么类型完全取决于你。在上面的示例中，我们恰是这么做的。对于 `printf()` 来说，它使用格式字符串来确定你提取的是哪种类型。

而当你调用 `va_end()` 来收尾时，你必须（规范规定）在再次调用 `va_start()` 或 `va_copy()` 之前，必须在这个特定的 `va_list` 变量上调用它。我知道我们还没有提到过 `va_copy()`。

所以，标准的流程是：

- 使用 `va_start()` 初始化你的 `va_list` 变量
- 使用 `va_arg()` 获取值
- 使用 `va_end()` 反初始化你的 `va_list` 变量

我提到 `va_copy()` 是因为它会为你的 `va_list` 变量创建一个完全相同的副本。如果你从源变量开始使用 `va_arg()`，那么新变量也不会启动。如果你已经用 `va_arg()` 消耗了 5 个参数，那么 `va_copy` 也会反映这一点。

如果你需要提前查看参数但需要记住当前的位置，`va_copy()` 会非常有用。

> ¹ 也就是说，初级开发者不应该知道里面具体是什么或它意味着什么。规范并没有规定里面具体是什么。
> ² 老实说，可以从语言中移除这个限制，但设计思想是宏 `va_start()`、`va_arg()` 和 `va_end()` 应该是可以用 C 语言编写的。为了实现这一点，我们需要某种方法来初始化指向第一个参数位置的指针。这需要语言扩展才能实现，而到目前为止如此。

由于 `printf()` 是一个占位符，它使用格式字符串中 `%d`（或其他任何类型）的数量来确定有多少个参数。

由于在 C 语言中，`va_list` 变体通常被称为 `va_lists`。

## 26. 本地化与国际化

本地化（Localization）是让你的程序适应不同的国家、语言和文化的过程。在世界各地，数字的小数和千位分隔符是不一样的。例如，在美国，本地化可能会写成这样：

100,000.00

而在巴西，同样的数字可能会写成这样：100.000,00

由于 C 语言本身并不处理这些差异，所以它提供了本地化库来处理这些问题。但是，这让本地化是可移植的。

为了让程序使用特定的本地化设置，你可能想要这样做：

```c
setlocale(LC_ALL, ""); // 使用环境本地化
```

## 26.1 设置本地化（快速且粗略的方法）

对于这些调用，`<locale>` 是必需的。你可能发现，默认情况下，程序启动时就已经初始化了本地化设置。通过传入一个空字符串作为参数，你是在告诉 C：“嘿，自己去查吧”。

## 26.2 获取货币本地化设置

因为移动绿色纸张据称是幸福的关键¹，让我们谈谈货币本地化。在编写可移植代码时，你知道该输入什么吗？无论是“S”、“C”、“V”还是“L”。幸运的是，一旦你调用了 `locale(LC_ALL, "")`，你就可以通过调用 `localeconv()` 查询：

```c
struct lconv *x = localeconv();
```

该函数返回一个指向静态分配的 `lconv` 结构的指针，它包含了你寻找的所有信息。这里是 `struct lconv` 的字段及其含义。

首先，是一些转换。`_p` 表示“正数”，`n_` 表示“负数”，`int_` 表示“国际化”。很多这些类型都是 `char` 或 `char*`。

在继续之前，要知道 `CHAR_MAX`（来自 `<limits>`）是 `char` 能容纳的最大值。并且许多字符都使用这个值来表示该字符在本地化中不可用。

| :--- | :--- |
