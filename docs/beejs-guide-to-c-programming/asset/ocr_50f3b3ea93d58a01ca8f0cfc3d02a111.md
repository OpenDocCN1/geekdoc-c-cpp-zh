# 14.1 Signed and Unsigned Integers

So far we've used int as a signed int, that is, a value that can be negative or positive. But C also has
specific unsigned integer types that can only hold positive numbers.

These types are prefixed by the keyword unsigned.

```
int a; // signed
signed int; // signed
signed a; // signed, "shorthand" for "int" or "signed int", rare
unsigned int b; // unsigned
unsigned c; // unsigned, shorthand for "unsigned int"
```

Why? Why would you decide you wanted to hold positive numbers?

Answer: you can get larger numbers in an unsigned variable than you can in a signed ones.

But why is this?

You can think of integers being represented by a number of bits¹ . On your computer, an int is repre-
sented by 64 bits.

And each permutation of bits that are either 0 or 1 represents a number. We can decide how to divvy up this
umbers

With signed numbers, we use (roughly) half the permutations to represent negative numbers, and the other
to represent positive numbers.

With unsigned, we use all the permutations to represent positive numbers.
