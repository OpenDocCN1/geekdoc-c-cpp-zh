### 20.1 Initializers of Nested structs and Arrays

Remember how you could initialize structure members among these lines?

```c
struct foo x = {.a=12, .b=34};
```

Turns out we have more in these initializers than we'd originally shared. Exciting!

For one thing, if you have a nested structure like the following, you can initialize members of substructure by following the variable names down the line:

```
struct foo x = {.a.b.c=12};
```

Let's look at an example:

```c
#include <stdio.h>

struct cabin_information {
    int window_count;
    int o2level;
};

struct spaceship {
    char *manufacturer;
    struct cabin_information ci;
};

int main(void) {
    struct spaceship s = {
        .manufacturer="General Products",
        .ci.window_count = 8, // <-- NESTED INITIALIZER!
        .ci.o2level = 21
    };
}
```

```c
printf("%s:%d seats, %d oxygen\n",
    s.manufacturer, s.window_count, s.ci.o2level);
}
```

Check out lines 16-17! That is how we're initializing members of struct cabin_information in the definition of s, our struct spaceship.

And here is another option for that initializer—this time we'll do something more standard-looking, but either approach works:

```c
struct spaceship s = {
    .manufacturer="General Products",
    .ci={
        .window_count = 8,
        .o2level = 21
    }
};
```

Now, if the above information isn't spectacular enough, we can also mix in array initializers in there, too.
Let's change this to get an array of passenger information in there, and we can check out how the initializers work in there, too.

```c
#include <stdio.h>
```

```c
struct passenger {
    char *name;
    int covid_vacinated; // Boolean
}
```

```c
#define MAX_PASSENGERS 8
```

```c
struct spaceship {
    char *manufacturer;
    struct passenger passenger[MAX_PASSENGERS];
}
```

```c
int main(void) {
    struct spaceship s = {
        .manufacturer="General Products",
        .passenger = {
            // Initialize a field at a time
            [0].name = "Gridley, Lewis",
            [0].covid_vacinated = 0,
            // Or all at once
            [7] = {.name="Brown, Teela", .covid_vacinated=1},
        }
    }
}
```

```c
printf("Passengers for %s\n", s.manufacturer);
```

```c
for (int i = 0; i < MAX_PASSENGERS; i++) {
    if (s.passenger[i].name != NULL)
        printf(" %s (%svacinated)\n", s.passenger[i].name, s.passenger[i].covid_vacinated ? "yes" : "not");
}
}
```

### 20.2 Anonymous structs

These are the "struct" with no name. We also mention these in the typedef section, but we'll refresh here.

Here's a regular struct:

```c
struct animal {
    char *name;
    int leg_count, speed;
};
```

And here's the anonymous equivalent:

```c
struct { // <-- No name!
    char *name;
    int leg_count, speed;
};
```

Okaaaay. So we have a struct, but it has no name, so we have no way of using it later? Seems pretty pointless.

Admittedly, and in an example, it is. We can still make use of a couple ways.

One is rare, but since the anonymous struct represents a type, we can just put some variable names after and use them.

```c
struct { // <-- No name!
    char *name;
    int leg_count, speed;
} a, b, c; // 3 variables of this struct
```

a.name = "antelope"; // for example

c.leg_count = 4;

But that's not useful.

Far more common to use of anonymous structs with a typedef so that we can use it later (e.g. to pass variables to functions).

```c
typedef struct { // <-- No name!
    char *name;
    int leg_count;
} animal; // New type: animal
```

animal a, b, c;

a.name = "antelope"; // for example

c.leg_count = 4;

Personally, I don't use anonymous structs. I think it's more pleasant to see the entire struct animal before the variable name in a declaration.

But that's just, like, my opinion, man.

### 20.4 Flexible Array Members

A flexible array member is an array at the end of a structure that has no specified size. This allows the structure to have a variable-sized array at it. It must be the last member of the struct.

```c
struct tree_node {
    int value;
    struct tree_node *left;
    struct tree_node *right;
    int data[]; // Flexible array member
};
```

To use it, you allocate enough memory for the struct plus the number of elements you need:

```c
struct tree_node *root = malloc(sizeof(struct tree_node) + sizeof(int) * 10);
```

### 20.5 Padding Bytes

Beware that C is allowed to add padding bytes within a struct as it sees fit. You can't trust that they will be adjacent in memory.

Let's take a look at this. We output two numbers. One is the sum of the sizeofs of the individual field types. The other is the size of the entire struct.

One would expect them to be the same. The size of the total is the sum of its parts, right?

```c
#include <stdio.h>

struct foo {
    int a;
    char b;
    int c;
    char d;
};

int main(void) {
    printf("%zu\n", sizeof(struct foo));
}
```

By our system, this outputs:

10
16

They're not the same! The compiler added 6 bytes of padding to help it be more performant. Maybe you will get different output with your compiler, unless you're forcing it, you can't be sure there's no padding.
