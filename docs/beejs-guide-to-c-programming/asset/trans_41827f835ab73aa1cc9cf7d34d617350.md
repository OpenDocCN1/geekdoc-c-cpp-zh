## 3.1 变量

人们说“变量存储值”。但另一种思考方式是，变量是一个人类可读的名称，指向内存中的某些数据。

我们在这里花一点时间，窥探一下“指针”这个兔子洞。别担心。

你可以把内存想象成一个巨大的字节数组。数据存储在这个“数组”¹¹² 中。如果一个数字大于单字节，它就会存储在多个字节中。因为内存像一个数组，所以内存的每个字节都可以通过它的索引来引用。这种对内存的索引也被称为*地址*（address）、*位置*（location）或*指针*（pointer）。

当你在 C 中 way有一个变量时，该变量的值位于某个地址的某个地方。否则，它会在哪里呢？但通过数值地址来引用值是很痛苦的，所以我们为它起了一个名字，这就是变量是什么。

我提到这一点的原因有两点：

- 1. 它会让理解指针变量变得更容易——它们是存储其他变量地址的变量！
- 2. 另外，它会让以后理解指针变得更容易。

所以，变量是存储在内存某个地址处的某些数据的名称。

¹¹“字节”（byte）通常是一个 8 位二进制数。将其看作一个可以存储从 0 到 255（包含）数值的整数。从技术上讲，C 允许字节是任意位数，如果你想无歧地指代 8 位数字，你应该使用“八字节”（octet）一词。但除非你另有指定，否则程序员假设你有 8 位。

²这里在这里极度地简化了现代内存的工作原理。但这种心理模型行得通，所以请原谅我。

### 3.1.1 变量名

你可以使用 0-9、A-Z、a-z 和下划线范围内的字符作为变量名，遵循以下规则：

- 变量不能以数字 0-9 开头。
- 变量名不能以双下划线开头。
- 变量名不能以下划线接大写字母 A-Z开头。

对于 Unicode，规范 §.2 中有些规则讨论了哪些 Unicode 码点范围允许出现在标识符的哪些，这在这里写太多了，而且你以后根本不需要考虑这些。

### 3.1.2 变量类型

取决于你的工具箱中已经有了哪些语言，你可能熟悉或不熟悉“类型”这个概念。但 C 对类型相当挑剔，所以我们应该复习一下。

这里是一些最基础的示例：

| 类型 | 示例 | C 类型 |
|---|---|---|
| 整数 | 3490 | int |
| 浮点数 | 3.14159 | float³ |
| 字符（单个） | 'c' | char |
| 字符串 | "Hello, world!" | char⁴ |

当你要求 C 转换时，它会努力转换大多数数值类型。但除此之外，所有的对话都是手动的，不是在字符串和数值之间。

C 中的所有类型都是这些类型的变体。

在使用变量之前，你必须声明一个变量并告诉 C 该变量持有什么。一旦声明，变量在以后运行时就不能被更改。你把它设为什么什么，它就是什么，直到它超出作用域并重新吸收回宇宙。

让我们回到之前的“Hello, world”并为其添加几个变量：

```c
#include <stdio.h>

int main(void) {
    int i;      // 存储有符号整数，例如 -3, 0, 1, 10
    float f;    // 存储有符号浮点数，例如 -3.14159

    printf("Hello, World!\n"); // 啊，何是神圣的熟悉感

}
```

我们声明了几个变量。我们使用了它们，并且它们都初始化了。其中一个存储整数，另一个存储浮点数（如果你有背景知识，基本上是一个实数）。

未初始化的变量具有不确的值³。它们必须初始化，否则你必须假设它们包含某个数字。

³我在这里撒小谎，小家伙。3.14159 是 double 类型，但你我还没有将 float 与“浮点”相关联，而 C 会将该类型强制转换为 float。等以后再担心它吧。

⁴把这读作“指向字符的指针”或“字符指针”。“Char”代表字符。我找不到字符串，所以我只能让人们称作“char”，少数人说“char”，极少数人说“quare”。我们以后会多介绍指针。

⁵口语上，我们说它们是“随机”值，但它们并不是真正的——甚至不是伪真实的随机数。

## 3.2 运算符与表达式

C 运算符你应该从其他语言中很熟悉。让我们快速过一下它们。
（关于这还有很多细节，但我们在这里做的足够了）。

### 3.2.1 算术

希望这些对你是熟悉的：

```c
i = i + 3; // 加法 (+) 和赋值 (=) 运算符，给 i 加 3
i = i - 8; // 减法，从 i 中减去 8
i = i * 9; // 乘法
i = i / 2; // 除法
i = i % 5; // 取模（除余数）
```

上述操作都有简写变体。这些行可以更简洁地写为：

```c
i += 3; // 同于 "i = i + 3", 给 i 加 3
i -= 8; // 同于 "i = i - 8"
i *= 9; // 同于 "i = i * 9"
i /= 2; // 同于 "i = i / 2"
i %= 5; // 同于 "i = i % 5"
```

没有幂运算。你必须使用 math.h 中的一个 pow() 函数变体。
让我们进入一些你在其他语言中可能没有的奇东西！

### 3.2.2 三元运算符

C 还包含三元运算符。这是一种值取决于其嵌入条件结果的表达式。

```c
// 如果 x > 10，给 y 加 17。否则给 y 加 37。
```
