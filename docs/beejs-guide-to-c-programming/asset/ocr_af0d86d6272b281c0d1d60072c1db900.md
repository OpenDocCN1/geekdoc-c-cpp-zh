# Chapter 12. Manual Memory Allocation

It's a void, you can assign it whatever pointer type you want... normally this will correspond in some way to the number of bytes you're allocating.

So... how many bytes should I allocate? We use sizeof(int) to help with that. If we want to allocate enough room for a single int, we can use sizeof(int) and pass that to malloc().

After we're done with some memory, we can call free() to indicate we're done with memory and it can be used for something else. As an argument, you pass the same pointer you got from malloc (or a copy of it). It's undefined behavior to use a memory region after free().

Let's try. We'll allocate enough memory for an int, and then store something there, and print it.

```
// Allocate space for a single int (sizeof(int) bytes-width):
```

```
int *p = malloc(sizeof(int));

*p = 12; // Store something there

printf("%d\n", p); // Print it: 12

free(p); // All done with that memory
```

```
*p = 3499; // ERROR: undefined behavior! Use after free()
```

Now, in that contrived example, there's really no benefit to it. We could have just used an int and it would have worked. But we'll see how to allocate memory way this has its advantages, especially with more complex structures.

One more thing you'll commonly take advantage of the fact that sizeof can give you the size of the result type of any constant expression. You could put a variable in there, too, and use that. Here's an example of that, just like the previous one:

```
int *p = malloc(sizeof(*)); // *p is an int, so same as sizeof(int)
```

# 12.2 Error Checking

All the allocation functions return a pointer to the newly-allocated stretch of memory, or NULL if the memory cannot be allocated for some reason.

Some OSes like Linux can be configured in such a way that malloc() returns NULL, if you're out of memory. But despite this, you should always check it with protections in mind.

```
int *x;

x = malloc(sizeof(int) * 10);

if (x == NULL) {
    printf("Error allocating 10 ints\n");
    // something here to handle it
}
```

Here's a common pattern that you'll see, where we do the assignment and the condition on the same line:

```
if ((x = malloc(sizeof(int) * 10)) == NULL) {
    printf("Error allocating 10 ints\n");
    // something here to handle it
}
```
