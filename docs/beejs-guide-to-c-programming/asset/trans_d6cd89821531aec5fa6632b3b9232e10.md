
# 第 9 章 文件输入/输出

```c
int main(void)
{
    FILE *fp;
    char s[1024]; // 足够容程序可能遇到的任何行
    int linecount = 0;

    fp = fopen("quote.txt", "r");

    while (fgets(s, sizeof s, fp) != NULL)
        printf("%d: %s", ++linecount, s);

    fclose(fp);
}
```

其输出如下：

- 1: 智者从愚蠢的问题中学到的
2: 比愚者从智慧的
3: 答案中学到的多。
4: --李小龙

## 9.4 格式化输入

你知道如何使用 `fprintf()` 获取格式化输出（正如我们在下面将看到的 `fscanf()`）。你对 `sscanf()` 执行同样的操作。
让我们有一个包含系列数据记录的文件。在这个情况下，是鲸鱼，包含名称、长度（米）和重量（吨）。whales.txt：

```
blue 29.0 173
right 20.7 135
gray 14.9 41
humpback 16.0 30
```

是的，我们可以用 `gets()` 读取这些内容，然后用 `sscanf()` 解析字符串（在某些方面，这对损坏的文件更具韧性），但在这种情况下，让我们使用 `fscanf()` 直接提取。
`fscanf()` 函数在读取时会跳过空白字符，并在文件结束或出错时返回 EOF。

```c
#include <stdio.h>

int main(void)
{
    FILE *fp;
    char name[1024]; // 足够容程序可能遇到的任何行
    float length;
    int mass;

    fp = fopen("whales.txt", "r");

    while (fscanf(fp, "%s %f %d", name, &length, &mass) != EOF)
        printf("%s whale, %d tonnes, %.1f meters\n", name, mass, length);

    fclose(fp);
}
```

得到结果为：

blue whale, 173 tonnes, 29.9 meters
right whale, 135 tonnes, 20.7 meters
gray whale, 41 tonnes, 14.9 meters
humpback whale, 30 tonnes, 16.0 meters

## 9.5 写入文本文件

正如我们可以使用 `fgetc()`、`fgets()` 和 `fscanf()` 读取文本流，我们也可以使用 `fputs()`、`fprintf()` 和 `fprintf()` 写入文本流。

要做到，我们必须通过向第二个参数传递 "w" 来以写模式 `fopen()` 文件。以 "w" 模式打开现有文件将立即将该文件截断为 0 字节以便重写。

我们将组合一个简单的程序，使用各种输出函数输出文件 output.txt。

```c
#include <stdio.h>

int main(void) {
    FILE *fp;
    int x = 32;

    fp = fopen("output.txt", "w");

    fputc('B', fp);
    fputs("\n", fp); // 新行
    fprintf(fp, "x = %d\n", x);
    fputs("Hello, world!\n", fp); 

    fclose(fp);
}
```

这会产生一个文件 output.txt，其内容如下：

B
x = 32
Hello, world!

趣知识：由于 stdout 是一个文件，你可以将第 8 行替换为：

fp = stdout;
这样程序将输出到控制台而不是文件。试试看！

## 9.6 二进制 I/O

我们一直一直在讨论文本文件。但还有一种我们之前提到的另一种“怪兽”，称为二进制文件或二进制流。

它们的工作方式与文本文件非常相似，I/O 子系统不会对数据进行任何像处理文本文件那样的转换。对于二进制文件，你得到的是原始字节流，仅此而已。

打开文件的主要区别在于，你必须在模式中添加一个 "b"。也就是说，要读取二进制文件，请以 "rb" 模式打开它；要写入二进制文件，请以 "wb" 模式打开它。

因为它是字节流，且字节流可以包含 NULL 字符，而 NULL 字符是 C 语言中字符串的结束标记，很少有人使用 `fprintf()` 系列函数来操作二进制文件。

# 第 9 章 文件输入/输出

相反，最常用的函数是 `fread()` 和 `fwrite()`。这些函数向流读取和写入指定数量的字节。

为了演示，我们将编写两个程序。一个将一次性将字节值序列写入磁盘。第二个程序将一个一个字节地读取并打印它们。

```c
#include <stdio.h>
```

```c
int main(void)
{
    FILE *fp;
    unsigned char bytes[6] = {5, 37, 0, 88, 255, 12};

    fp = fopen("output.bin", "wb"); // wb 模式用于“写二进制”

    // 在 fwrite 调用中，参数为：
    /*
     * 指向要写入数据的指针
     * 每个数据“块”的大小
     * 每个数据“块”的计数
     */
    fwrite(bytes, 1, 6, fp);

    fclose(fp);
}
```
