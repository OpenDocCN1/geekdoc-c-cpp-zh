One hackish thing is used to comment out large numbers of lines quickly.

If you put an #if ("if false") at the front of the block to be commented out and an #endif at the end, you can get this:

```
#if 0
printf("All this code"); /* is effectively */
printf("commented out"); // by the #if 0
#endif
```

You might have noticed that there's no #elifdef or #elifdef directives. How can we get the same with #if? That is, if I wanted

```
#ifdef FOO
x = 2;
#elifdef BAR // ERROR: Not supported by standard C
x = 3;
#endif
```

How could I do it?

Turns out there's a preprocessor operator called defined we can use with an #if statement.

These are equivalent:

```
#ifdef FOO
#if defined FOO
#if defined(FOO) // Parentheses optional
```

As are these:

```
#ifdef FOO
#if defined FOO
#if !defined(FOO) // Parentheses optional
```

Notice how we can use the standard logical NOT operator (!) for "not defined",

So now we're back in #if land and we can use #elif with impunity!

This broken code:

```
#ifdef FOO
x = 2;
#elifdef BAR // ERROR: Not supported by standard C
x = 3;
#endif
```

can be replaced with:

```
#if defined FOO
x = 2;
#elif defined FOO
x = 3;
#endif
```

You can't just wrap the code in /* */ comments because those won't nest.
