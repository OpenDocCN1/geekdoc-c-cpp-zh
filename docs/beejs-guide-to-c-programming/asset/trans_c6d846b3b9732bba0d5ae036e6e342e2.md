或者，另一个例子是判断存储在 x 中的数字是奇数还是偶数：

```
printf("The number %d is %s.", x, x % 2 == 0? "even": "odd");
```

printf 中的 `%s` 格式指定符用于打印字符串。如果表达式 `x % 2` 求值结果为 0，则整个三元表达式的值评估为 "even"。否则，评估结果为 "odd"。很酷的！

需要注意的是，三元运算符不像 `if` 语句那样是控制流。它只是一个评估为值的表达式。

### 3.2.3 前置与后置自增自减

现在，让我们玩玩另一个你可能没见过的东西。

这些是著名的后置自增和后置自减运算符：

```
i++; // i 加1（后置自增）
i--; // i 减1（后置自减）
```

通常，这些只是作为以下内容的简短版本使用：

```
i += 1; // i 加 1
i -= 1; // i 减 1
```

但它们比这要微妙得多，这些狡猾的家伙。

让我们来看前置自增和前置自减：

```
++i; // i 加1（前置自增）
--i; // i 减1（前置自减）
```

对于前置自增自减，变量的值在表达式求值之前就会增加或减少。然后使用新值对表达式进行求值。

对于后置自增自减，表达式的值先使用原始值计算，然后在表达式的值确定后，再对该值进行增加或减少。

你实际上可以将它们嵌入到表达式中，如下：

```
i = 10;
j = 5 + i++; // 计算 5 + i，然后增加 i
```

```
printf("%d, %d\n", i, j); // 输出 11, 15
```

让我们将其与前置自增运算符对比：

```
i = 10;
j = 5 + ++i; // 增加 i，然后计算 5 + i
```

```
printf("%d, %d\n", i, j); // 输出 11, 16
```

这种技术经常用于数组和指针的访问与操作。它为你提供了一种使用数组中值的方法，同时在使用值之前或之后对其进行增加或减少。

但到目前，你在 `for` 循环中最常见它的地方：

```c
for (i = 0; i < 10; i++)
    printf("i is %d\n", i);
```

稍后会介绍。

### 3.2.4 逗号运算符

这是一种不常用的方法，用于分隔从左到右运行的表达式：

```
x = 10, y = 20; // 先将 10 分给 x，然后将 20 分给 y
```

看起来有点傻，因为你只需要把逗号替换为分号，对吧？

```
x = 10; // 先将 10 分给 x，然后将 20 分给 y 
```

但这有细小的区别。后者是独立的表达式，而前者是一个单一表达式：

使用逗号运算符，逗号表达式的值是右侧表达式的值：

```
x = (1, 2, 3);
```

```
printf("%d\n", x); // 输出 3，因为 3 是逗号列表中最右侧的
```

即使这样也相当复杂。逗号运算符的一个常见用途是在 `for` 循环中，在语句的每个部分执行多个操作：

```c
for (i = 0, j = 10; i < 100; i++, j++)
    printf("%d, %d\n", i, j);
```

我们稍后会回到这里。

### 3.2.5 条件运算符

对于布尔值，我们有一系列标准运算符：

```
a == b; // 如果 a 等于 b 则为真
a != b; // 如果 a 不等于 b 则为真
a < b; // 如果 a 小于 b 则为真
a > b; // 如果 a 大于 b 则为真
a <= b; // 如果 a 小于等于 b 则为真
a >= b; // 如果 a 大于等于 b 则为真
```

不要混淆赋值 `=` 和 比较 `==`！用两个进行比较，用一个进行赋值。

我们可以在语句中使用比较表达式：

```c
if (a <= 10)
    printf("Success!\n");
```

### 3.2.6 布尔运算符

我们可以使用布尔运算符 `and` (与)、`or` (或) 和 `not` (非) 来连接或修改条件表达式。

| 运算符 | 布尔含义 |
| --- | --- |
| && | 与 |
| || | 或 |
| ! | 非 |

“与”的示例：

```c
// 如果 a 等于 b 且 y 大于 20
if (a == b && y > 20) {
    printf("Something!\n");
}
```

“非”的示例：

```c
// 如果 x 不小于 12
if (!(x < 12)) {
    printf("x is not 12\n");
}
```

`!` 的优先级高于其他布尔运算符，所以在那种情况下我们需要使用括号。

### 3.2.7 sizeof 运算符

该运算符告诉你特定变量或数据类型在内存中所占用的空间（字节）。
更具体地说，它告诉你特定表达式（可能是单个变量）在内存中所占用的空间（字节）。
这在不同系统上可能不同，`char` 及其变体除外（它们总是 1 字节）。
这看起来可能并不有用，但我们会处处引用它，所以值得介绍。
由于它计算存储类型的字节数，你可能认为它会返回一个 `int`。或者……由于大小不能为负，可能是无符号整数？

事实是 C 有一种特殊的类型来返回 `sizeof` 的值。`size_t`，读作 "size tee"。众所它是一种无符号整数类型，可以容纳任何交给 `sizeof` 的对象的字节大小。

`size_t` 出现在许多传递或返回计数的地方。把它看作一个表示计数的值。

你可以将 `sizeof` 作为一个表达式：

```
int a = 999;
// %zu 是 size_t 类型的格式指定符
```

```
printf("%zu\n", sizeof(a)); // 在你的系统上输出 4
```

> size_t 是 type 的缩写。

```c
printf("%zu\n", sizeof(int)); // 在你的系统上输出 4
printf("%zu\n", sizeof(3.14)); // 在你的系统上输出 8
```
