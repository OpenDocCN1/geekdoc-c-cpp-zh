Chapter 41. Function Specifiers, Alignment Specifiers/Operators

Here's foo.c with the inline.

```
// foo.c

#include <stdio.h>

inline char *func(void)
{
    return "foo's function";
}

int main(void)
{
    printf("%s\n", func());

    void bar(void);
    bar();
}
```

Recall that unless we're not using an optimized build with gcc, func() will vanish and we'll get a linker error. Unless, or we have a version with external linkage defined elsewhere.

And we do. In bar.c.

```
// bar.c

#include <stdio.h>

char *func(void)
{
    return "bar's function";
}

void bar(void)
{
    printf("%s\n", func());
}
```

So the question is, what is the output?

Seems like when we call func() from foo.c, it should print 'foo's function'. And from bar.c, func() should print 'bar's function'.

And if I compile with gcc with optimizations¹, it will use inline functions, and we'll get the expected:

```
foo.c: foo's function
bar.c: bar's function
```

Great!

But if we compile in gcc without optimizations, it ignores the inline function and uses the external linkage func() from bar.c! And we get this:

```
foo.c: foo's function
bar.c: bar's function
```

¹You can do this with -O on the command line.
