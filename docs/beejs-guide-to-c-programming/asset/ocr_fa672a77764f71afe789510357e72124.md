Each code point represents a unique character. And each character has a numeric code point associated with it.

For example, in Unicode, the numeric value 66 represents “B”, and 960 represents “n”. Other character mappings aren’t Unicode use different values, potentially, let’s forget them and concentrate on Unicode, the future!

# 27.3 Encoding

If we, an 8-bit can hold values from 0-255, inclusive. That’s great for “B” which is 66—that fits in a byte. But “n” is 960, and doesn’t fit in a byte! We need another byte. How do we store all that in memory? Or what about bigger numbers, like 195,024? That’s going to need a number of bytes to hold.

The Big Question: how are these numbers represented in memory? This is what we call the encoding of characters.

So we have two: the code point which tells us the serial number of a particular character. And the encoding which tells us we’re going to represent that number in memory.

There are plenty of encodings. You can make up your own right now if you want! We’re going to look at some really common encodings that we use with Unicode.

| Encoding | Description |
| UTF-8 | A byte-oriented encoding that uses a variable number of bytes per character. This is the one we use. |
| UTF-16 | A 16-bit per character encoding. |
| UTF-32 | A 32-bit per character encoding. |

With UTF-16 and UTF-32, the byte order matters, so you might use UTF-16BE for big-endian and UTF-16LE for little-endian. Same for UTF-32. Technically, if unspecified, you should assume big-endian, but Windows uses UTF-16 extensively and little-endian, sometimes it is assumed.

Let’s look at some examples. It’s good to write the values in exactly two digits per bit, and to see how things are arranged in memory.

| Character | Code Point | UTF-16BE | UTF-32BE | UTF-16LE | UTF-32LE | UTF-8 |
| A | 41 | 0041 | 00000041 | 4100 | 410000041 | 41 |
| B | 42 | 0042 | 00000042 | 4200 | 420000042 | 42 |
| E | 7E | 007E | 0000007E | 7E00 | 7E00007E | 7E |
| π | 3C0 | 03C0 | 000003C0 | C003 | 0000C03C0 | CF80 |
| € | 20AC | 20AC | 000020AC | AC20 | 0000AC20 | E28AC |
