# 32.1 Silly Unnamed Object Example

You can put any type in and make an unnamed object.

For example, these are effectively equivalent:

```
int x = 3490;
```

```
printf("%d\n", x);           // 3490 (variable)
printf("%d\n", 3490);      // 3490 (constant)
printf("%d\n", (int){3490}); // 3490 (unnamed object)
```

That last one is unnamed, but it's silly. Might as well do the one on the line before.

But hopefully that provides a little clarity on the syntax.
