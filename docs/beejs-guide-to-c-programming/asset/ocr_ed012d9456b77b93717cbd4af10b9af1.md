# 14.4 More Float: double and long double

Let's see what the spec has to say about floating point numbers in §5.2.4.2¶1-2:

The following parameters are used to define the model for each floating-point type:

| Parameter | Definition |
|---|---|
| s | sign (±1) |
| b | base or radix of exponent representation (an integer > 1) |
| e | exponent (an integer between a minimum $e_{min}$ and a maximum $e_{max}$) |
| p | precision (number of base-$b$ digits in the significand) |
| $f_k$ | nonnegative integers less than $b$ (the significant digits) |

A floating-point number ($x$) is defined by the model:

```
$x = sb\sum_{k=1}^{p} f_k b^{-k}, e_{min} \le e \le e_{max}$
```
