# 14.5.3 Floating Point Constants

You'd think a floating point constant like 1.23 would have a default type of float, right? Surprise Turns unsuffixed floating point numbers are type double! Happy belated birthday!

You can force it to be of type float by appending an f (or F—it's case-insensitive). You can force it to be of type long double by appending l (or L).

| Type | Suffix |
|---|---|
| float | F |
| double | None |
| long double | L |

For example:

```
float x = 3.14f;
double x = 3.14;
long double x = 3.14L;
```

This time though, we've been doing this, right?
float x = 3.14;

Isn't left a float and a double right? Yes! But C's pretty good with automatic numeric conversions, so it's more common to have an unsuffixed floating point constant than not. Or on that later.

# 14.5.3.1 Scientific Notation

Remember earlier when we talked how a floating point number can be represented by a significand, base, and exponent?

Well, there's a common way of writing such a number, here shown followed by it's more recognizable equivalent is what you get when you actually run the math:

1.2345 × 10³ = 1234.5

Writing numbers in the form s × b¹⁰ is called scientific notation¹⁴. In C, these are using "E notation", so these are equivalent::

| Scientific Notation | E notation |
|---|---|
| 1.2345 × 10⁻³ | 1.2345e-3 |
| 1.2345 × 10⁸ | 1.23450000e+8 |

You can print a number in this notation with %:
printf("%s\n", 1.234560e+05);
A couple of little fun facts about scientific notation:

+   - You don't have to write them with a single leading digit before the decimal point. Any number of numbers can go in.

```
double x = 123.456e3; // 123456
```

However, when you print it, it will change the exponent so there is only one digit in front of the decimal point.
