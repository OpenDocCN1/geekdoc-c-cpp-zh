# # Bitwise Operations

These numeric operations effectively allow you to manipulate individual bits in variables, fitting since C is such a low-level langauge¹.

If you're not familiar with bitwise operations, Wikipedia has a good bitwise article².

# 24.1 Bitwise AND, OR, XOR, and NOT

For each of these, the usual arithmetic conversions take place on the operands (which in this case must be integer type), and then the appropriate bitwise operation is performed.

| Operation | Operator | Example |
|---|---|---|n| AND | & | a = b & c |
| OR | | | a = b | c |
| XOR | ^ | a = b ^ c |
| NOT | | | a = ~c |

Note how they're similar to the Boolean operators && and |.|

These have assignment shorthand variants to += and -=;

| Operator | Example | Longhand equivalent |
|---|---|---|n| &= | a & c | a = a & c |
| |= | a = c | a = a | c |
| ^= | a = c | a = a ^ c |

# 24.2 Bitwise Shift

For this, the integers are promoted on each operand (which must be an integer type) and then a bitwise shift is executed. The type of the result is the type of the promoted operand.
