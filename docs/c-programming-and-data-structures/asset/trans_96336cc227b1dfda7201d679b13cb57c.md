
## 问题分析：

二项式系数可以按如下方式递归计算：

B(m,0) = 1

B(m,x) = B(m,x-1) [(m - x + 1)/x], x = 1,2,3,...,m

进一步，

B(0,0) = 1

也就是说，当 x 为零或 m 为零时，二项式系数为一。图 4.25 中的程序打印 m = 10 的二项式系数表。该程序采用一个 do 循环和一个 while 循环。

### 程序

```c
#define MAX 10
main()
{
    int m, x, binom;
    printf(" m x");
    for (m = 0; m <= 10 ; ++m)
        printf("%4d", m);
    printf("\n%4d", m);
    printf("\n-------------------------------\n");
    m = 0;
    do
    {
        printf("%2d ", m);
        x = 0; binom = 1;
        while (x <= m)
        {
            if(m == 0 || x == 0)
                printf("%4d", binom);
            else
            {
                binom = binom * (m - x + 1)/x;
                printf("%4d", binom);
            }
            x = x + 1;
        }
        printf("\n");
        m = m + 1;
    }
    while (m <= MAX);
    printf("-------------------------------\n");
}
```

## 3. 最小成本

问题：一个单位运行成本由两个分量 C1 和 C2 组成，可表示为参数 p 的函数如下：

C1 = 30 − 8p
C2 = 10 + p²

参数 p 的范围为 0 到 10。确定 p 的值，精度为 + 0.1，使运行成本最小。

### 问题分析：

总成本 = C₁ + C₂ = 40 − 8p + p²

当 p = 0 时成本为 40，当 p = 1 时为 33，当 p = 10 时为 60。因此成本先减小后增大。图 4.27 中的程序以 p 的递增间隔 0.1 评估成本，并在成本开始增大时停止。该程序采用 break 和 continue 语句退出循环。

### 程序

```c
main()
{
    float p, cost, p1, cost1;
    for (p = 0; p <= 10; p = p + 0.1)
    {
        cost = 40 - 8 * p + p * p;
        if(p == 0)
        {
            cost1 = cost;
            continue;
        }
        if (cost >= cost1)
            break;
        cost1 = cost;
        p1 = p;
    }
    p = (p + p1)/2.0;
    cost = 40 - 8 * p + p * p;
    printf("\nMINIMUM COST = %.2f AT p = %.1f\n",
        cost, p);
}
```

### 输出
    最小成本 = 24.00 在 p = 4.0
