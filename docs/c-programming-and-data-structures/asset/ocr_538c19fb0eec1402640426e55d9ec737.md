# 1.10 FLOWCHARTS

A flowchart can be defined as the pictorial representation of a process, which describes the sequence and flow of control and information within the process. The flow of information is represented inside the flowchart in a step-by-step form. This technique is mainly used for developing business workflows and solving problems using computers.

Flowchart uses different symbols for depicting different activities, which are performed at different stages of a process. The various symbols used in a flowchart are:

+   - Start and end It is represented by a rounded rectangle. It represents the starting and the ending of a process. Every process starts and ends at some point so a flowchart always contains one start as well as one end symbol. Figure 1.32 shows the start and the end symbols used in a flowchart.
