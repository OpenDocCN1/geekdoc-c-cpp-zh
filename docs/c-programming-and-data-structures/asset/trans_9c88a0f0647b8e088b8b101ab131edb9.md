## B.3 自引用结构

自引用结构是一种包含指向自身的成员指针的结构。这意味着，它将一个或多个成员声明为指向自身的指针。这类结构在数据结构的链表实现中常用。例如，考虑以下表示队列节点的结构声明：

```c
struct queue
{
 int info;
 struct queue *next;
};
```

在上述声明中，next 是指向其所属同一结构的指针。从逻辑上讲，这里 next 用于指向队列中的下一个节点。
