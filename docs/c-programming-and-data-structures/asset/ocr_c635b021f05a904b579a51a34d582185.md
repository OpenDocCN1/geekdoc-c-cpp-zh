Commonly used scanf format codes are given in Table 1.15

# Table 1.15 Commonly used scanf Format Codes

| Code | Meaning |
|------|---------|
| %c | read a single character |
| %d | read a decimal integer |
| %e | read a floating point value |
| %f | read a floating point value |
| %g | read a floating point value |
| %h | read a short integer |
| %i | read a decimal, hexadecimal or octal integer |
| %o | read an octal integer |
| %s | read a string |
| %u | read an unsigned decimal integer |
| %x | read a hexadecimal integer |
| %[...] | read a string of word(s) |

The following letters may be used as prefix for certain conversion characters.

+   - h for short integers
+   - l for long integers or double
+   - L for long double

NOTE: C99 adds some more format codes.
