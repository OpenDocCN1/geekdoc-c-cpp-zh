a) Void pointers are pointers pointing to some data of no specific type. A void pointer is defined like a pointer of any other type, except that void* is used for the type: void *pt;

We can't directly dereference a void pointer; we must cast it to a pointer with a specific type first, for instance, to a pointer of type int*: *(int*)pt;

Thus to assign a value to a void pointer, consider the following examples: *(int*)pt=42; *(float*)pt=3.14; The use of void pointers is mainly allowing for generic types Array of Pointers: Refer Section 6.12
