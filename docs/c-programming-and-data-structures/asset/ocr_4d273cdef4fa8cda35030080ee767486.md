# B.1 MATRIX OPERATIONS

A matrix can be logically represented with the help of multi-dimensional arrays. For example, A[2][2] represents a 2X2 matrix, as shown in Figure B.1:

![](bbox=[0.3, 0.5, 0.7, 0.65])

Several matrix operations can be performed with the help of multi-dimensional arrays. The following examples depict some of these operations.
