b) Write a program to display a string in the following format

+   J
+   JN
+   JNT
+   JNTU
+   JNTU
+   JNT
+   JN
+   J

```
#include<stdio.h>
#include<string.h>
main()
{
 int c,L,d;
char string1[]="JNTU";
printf("\n\n");
L=strlen(string1);
for( c=0;c<=L;c++)
{
d = c+ 1;
printf("%.*s\n",d,string1);
}
for( c=L;c>=0;c--)
{
d = c+ 1;
printf("%.*s\n",d,string1);
}
}
```
