
- 在其内存已被释放后使用指针是一个错误。
- 将 malloc 或 calloc 的返回值赋给除指针之外的任何东西都是一个错误。
- 在节点已被释放之前将指针设为 NULL 是逻辑错误。节点将无法恢复地丢失。

- 在没有结构标签的情况下声明自引用结构是错误的。
- 对使用 calloc 创建的数组的元素进行单独释放是错误的。
- 失败将最后一个节点的链接字段设为 null 是逻辑错误。
