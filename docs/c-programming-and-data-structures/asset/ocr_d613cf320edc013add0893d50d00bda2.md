# 6.4 DECLARING POINTER VARIABLES

In C, every variable must be declared for its type. Since pointer variables contain addresses that belong to a separate data type, they must be declared as pointers before you use them. The declaration of a pointer variable takes the following form:
data_type *pt_name;

This tells the compiler three things about the variable pt_name.

1. The asterisk (*) tells that the variable pt_name is a pointer variable.

2. pt_name needs a memory location.

3. pt_name points to a variable of type data_type.

```
int *p; /* integer pointer */

d eclares the variable p as a pointer variable that points to an integer data type. Remember that the type int refers to the data type of the variable being pointed to by p and not the type of the value of the pointer.

Similarly, the statement

float *x; /* float pointer */

d eclares x as a pointer to a floating-point variable.
```
