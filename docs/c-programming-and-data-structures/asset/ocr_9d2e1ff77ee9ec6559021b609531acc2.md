# EXAMPLE 3.4 Write a program for finding the largest number in an array.

+   1. Set the size of the array as n.
+   2. Store n elements in the array.
+   3. Assign each element of the array to LARGE to LARGE.
+   4. Compare each element in the array with LARGE.
+   5. If an element of the array is greater then LARGE, then set LARGE=element.
+   6. Else go to step 4.
+   7. Repeat the process until it reaches the last element of the array.
+   8. Print the largest element found in the array.

Figure 3.4 gives a program to implement this algorithm.
