The outputs of the program in Fig. 4.5, for variable specifications %12.*s, %6.*s, and %*.1s are shown in Fig. 4.6, which further illustrates the variable field width and the precision specifications.

```
Program
main()
{
    int c, d;
    char string[] = "CProgramming";
    printf("\n\n");
    printf("-------------
");
    for( c = 0 ; c <= 11 ; c++ )
    {
        d = c + 1;
        printf("%-12.*s\n", d, string);
    }
    printf("-------------
");
    for( c = 11 ; c >= 0 ; c-- )
    {
        d = c + 1;
        printf("%-12.*s\n", d, string);
    }
    printf("-------------
");
}
```
