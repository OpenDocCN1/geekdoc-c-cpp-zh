Now, we can access every value of x using p++ to move from one element to another. The relationship between p and x is shown as:

```
p = &x[0] (= 1000)
p+1 = &x[1] (= 1002)
p+2 = &x[2] (= 1004)
p+3 = &x[3] (= 1006)
p+4 = &x[4] (= 1008)
```

You may notice that the address of an element is calculated using its index and the scale factor of the data type. For instance,

address x[3] = base address + (3 x scale factor of int)
= 1000 + (3 x 2) = 1006

When handling arrays, instead of using array indexing, we can use pointers to access array elements. Note that *(p+3) gives the value of x[3]. The pointer accessing method is much faster than array indexing.

# EXAMPLE 6.4 Write a program using pointers to compute the sum of all elements stored in an array.

The program shown in Fig. 6.8 illustrates how a pointer can be used to traverse an array element. Since incrementing an array pointer causes it to point to the next element, we need only add one to p each time we go through the loop.

```
main()
{
int *p, sum, i;
int x[5] = {5,9,6,3,7};
i = 0;
p = x; /* initializing with base address of x */
printf("Element Value Address\n\n");
while(i < 5)
{
printf(" x[%d] %d %d\n", i, *p, p);
sum = sum + *p; /* accessing array element */
i++;
p++; /* incrementing pointer */
}
printf("\n Sum = %d\n", sum);
printf(" x[0] = %d\n", x[0]);
printf("\n p = %d\n", p);
}
```
