Here, name is an array variable of type char and age is an int variable.

The general format of fscanf is

```
fscanf(fp, "control string", list);
```

This statement would cause the reading of the items in the list from the file specified by fp, according to the specifications contained in the control string. Example: fscanf(f2, "%s %d", item, &quantity);

Like scanf, fscanf also returns the number of items that are successfully read. When the end of file is reached, it returns the value EOF.
