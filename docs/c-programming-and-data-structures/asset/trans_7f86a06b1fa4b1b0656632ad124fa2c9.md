a) 空指针是指向某种无特定类型数据的指针。空指针的定义类似于其他类型的指针，只是类型使用 void*：void *pt;

我们不能直接解引用空指针；必须先将其强制转换为特定类型的指针，例如 int* 类型的指针：*(int*)pt;

因此，要为一个空指针赋值，请考虑以下示例：*(int*)pt=42; *(float*)pt=3.14; 空指针的主要用途是允许通用类型 指针数组：参见第6.12节
