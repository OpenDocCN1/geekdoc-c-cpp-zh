because p is the address of quantity. The * can be remembered as 'value at address'. Thus the value of n would be 179. The two statements

```
p = &quantity;
 n = *p;
```

are equivalent to

```
n = *&quantity;
```

which in turn is equivalent to

```
n = quantity;
```

In C, the assignment of pointers and addresses is always done symbolically, by means of symbolic names. You cannot access the value stored at the address 5368 by writing *5368. It will not work. Example 6.2 illustrates the distinction between pointer value and the value it points to.
