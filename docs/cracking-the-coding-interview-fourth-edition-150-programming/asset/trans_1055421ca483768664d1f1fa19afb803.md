### ArrayList (动态数组数组):

ArrayList 是一种动态调整大小的数组，它根据需要调整自己的大小，同时提供 O(1) 的访问速度。典型的实现方式是：当向量（vector）满时，数组大小翻倍。每次翻倍需要 O(n) 时间，但由于发生频率较低，因此其摊均时间仍为 O(1)。

```java
public ArrayList<String> merge(String[] words, String[] more) {
    ArrayList<String> sentence = new ArrayList<String>();
    for (String w : words) sentence.add(w);
    for (String w : more) sentence.add(w);
    return sentence;
}
```

### StringBuffer / StringBuilder

```java
public String setName(String[] words) {
    String sentence = "";
    for (String w : words) sentence = sentence + w;
    return sentence;
}
```

**答案：** O(n^2)，其中 n 是句子中字母的数量。原因如下：每当你向 sentence 附加一个字符串时，你都会创建一个 sentence 的副本，并遍历 sentence 中的所有字母以将其复制。如果你在循环中每次都要迭代多到 n 个字符，而你循环了 n 次，就会得到 O(n^2) 的运行时间。哎呀！

StringBuffer（或 StringBuilder）可以帮助你避免这个问题。

```java
public String setName(String[] words) {
    StringBuilder sentence = new StringBuilder();
    for (String w : words) sentence.append(w);
    return sentence.toString();
}
```

### 方法方法：

链表非常常见。它们可以从简单（删除链表中的节点）到更具挑战性的不等。无论如何，我们都建议你对最简单的问题非常熟悉。能够以最简单的方法轻松操作链表将会让更困难的链表问题变得不那么棘手。因此，我们提供关于链表操作的“必知”代码。在面试之前，你应该能够自己写出这些代码。

### 创建链表：

注意：在面试中讨论链表时，请确保理解它是单向链表还是双向链表。

```java
class Node {
    Node next = null;
    int data;
    public Node(int d) { data = d; }
    void addNodeToTail(int d) {
        Node end = new Node(d);
        Node n = this;
        while (n.next != null) { n = n.next; }
        n.next = end;
    }
}
```

### 从单链表中删除节点

```java
Node delete(Node head, int d) {
    Node n = head;
    if (n.data == d) {
        return head.next; /* 移动头节点 */
    }
    while (n.next != null) {
        if (n.next.data == d) {
            n.next = n.next.next;
            return head; /* 头节点未变 */
        }
        n = n.next;
    }
}
```

### 方法：

无论你是被要求实现一个简单的栈/队列，还是被要求实现一个修改版本，只要你能够完美地处理栈和队列，你就没问题！这里是栈的一些骨架代码。

# 实现栈

```java
class Stack {
    2 top;
    Node pop() {
        if (top != null) {
            Object item = top.data;
            top = top.next;
            return item;
        }
        return null;
    }
    void push(Object item) {
        Node t = new Node(item);
        t.next = top;
        top = t;
    }
}
```

# 实现队列

```java
class Queue {
    2 first, last;
    void enqueue(Object item) {
        if (!first) {
            last = new Node(item);
            first = last;
        } else {
            last.next = new Node(item);
            last = last.next;
        }
    }
    Node dequeue() {
        if (first != null) {
            Object item = first.data;
            first = first.next;
            return item;
        }
        return null;
    }
}
```
