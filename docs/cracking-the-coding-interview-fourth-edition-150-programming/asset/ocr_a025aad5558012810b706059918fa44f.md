10.7 Design an algorithm to find the kth number such that the only prime factors are 5 and 7.

# SOLUTION

Any such number will look like (3^i)*(5^j)*(7^k). Here are the first 13 numbers:

| 1 | - | 3^0*5^0*7^0 |
| 3 | | 3^1*5^0*7^0 |
| 5 | 5 | 3^0*5^1*7^0 |
| 7 | 7 | 3^0*5^0*7^1 |
| 9 | 3*3 | 3^2*5^0*7^0 |
| 15 | 3*5 | 3^1*5^1*7^0 |
| 21 | 3*7 | 3^1*5^0*7^1 |
| 25 | 5*5 | 3^0*5^2*7^0 |
| 27 | 3*9 | 3^3*5^0*7^0 |
| 35 | 5*7 | 3^0*5^1*7^1 |
| 45 | 5*9 | 3^2*5^1*7^0 |
| 49 | 7*7 | 3^0*5^0*7^2 |
| 63 | 3*21 | 3^2*5^0*7^1 |

+   * 3* (previous number in list)
* 5* (previous number in list)
* 7* (previous number in list)

How would we find the next number in the list? Well, we could multiply 3, 5 and 7 times each number in the list and find the smallest element that has not yet been added to our list. The solution is O(n²). Not bad, but I think we can do better.

In our current algorithm, we are doing 3*1, 3*2, 3*3, 3*5, 3*7, 3*9, 3*15, 3*21, 3*25 ..., and the same for 5 and 7. We've already done almost this work before—why are we doing it again?
