```cpp
class Foo {
public:
    A(....); /* 如果调用 A，将创建一个新线程并执行*
    * 相应的函数。 */
    B(....); /* 同上述 */
    C(....); /* 同上述 */
}
Foo f;
f.A(....);
f.B(....);
f.C(....);
```

- i) 你能否设计一种机制来确保 B 在 A 之后执行，且 C 在 B 之后执行？

- ii) 假设我们有以下使用类 `Foo` 的代码。我们不知道操作系统将如何调度线程。
```cpp
Foo f;
f.A(....); f.B(....); f.C(....);
f.A(....); f.B(....); f.C(....);
```
你能否设计一种机制来确保所有方法都按顺序执行？
