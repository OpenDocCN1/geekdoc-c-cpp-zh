# Solutions to Chapter 20 | Hard

**20.9** Numbers are randomly generated and passed to a method. Write a program to find and maintain the median value as new values are generated.

pg 91

# SOLUTIONS

One solution is to use two priority heaps: a max heap for the values below the median, and a min heap for the values above the median. The median will be largest value of the max heap. When a new value arrives it is placed in the below heap if the value is less than or equal to the median, otherwise it is placed into the above heap. The heaps can be equal size or the below heap has one extra. This constraint can be easily restored by shifting an element from one heap to the other. The median is available in constant time, so operations are O(log n).

```
1 private Comparator<Integer> maxHeapComparator, minHeapComparator;
2 private PriorityQueue<Integer> maxHeap, minHeap;
3 public void addNumber(int randomNumber) {
4 if (maxHeap.size() == minHeap.size()) {
5 if ((minHeap.peek() != null) &
6 randomNumber > minHeap.peek()) {
7 maxHeap.offer(minHeap.poll());
8 minHeap.offer(randomNumber);
9 }
10 else {
11 maxHeap.offer(randomNumber);
12 }
13 }
14 else {
15 if (randomNumber < maxHeap.peek()) {
16 minHeap.offer(maxHeap.poll());
17 maxHeap.offer(randomNumber);
18 }
19 else {
20 minHeap.offer(randomNumber);
21 }
22 }
23 }
24 public static double getMedian() {
25 if (maxHeap.isEmpty()) return minHeap.peek();
26 else if (minHeap.isEmpty()) return maxHeap.peek();
27 if (maxHeap.size() == minHeap.size()) {
28 return (minHeap.peek() + maxHeap.peek()) / 2;
29 } else if (maxHeap.size() > minHeap.size()) {
30 return maxHeap.peek();
31 } else {
32 return minHeap.peek();
33 }
34}
```
