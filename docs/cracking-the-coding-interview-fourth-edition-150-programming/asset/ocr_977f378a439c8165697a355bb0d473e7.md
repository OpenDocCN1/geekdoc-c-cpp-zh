# SOLUTION

i) Can you design a mechanism to make sure that B is executed after A, and C is executed after B?

+   1 Semaphore s_a(0);
2 Semaphore s_b(0);
3 A {
4     /**/\n5     s_a.release(1);
6 }
7 B {
8     s_a.acquire(1);
9     /**/\n10    s_b.release(1);
11 }
12 C {
13    s_b.acquire(1);
14    /**/\n15 }
