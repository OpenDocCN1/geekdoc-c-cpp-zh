# Solutions to Chapter 16 | Low Level

16.9 Write an aligned malloc & free function that takes number of bytes and aligned byte (which is always power of 2)

EXAMPLE
align_malloc(1000,128) will return a memory address that is a multiple of 128 and that points to memory of size 1000 bytes.
aligned_free() will free memory allocated by align_malloc.

pg 82

# SOLUTION

+. 1. We will use malloc routine provided by C to implement the functionality.
Allocate memory of size (bytes required + alignment - 1 + sizeof(void*)) using malloc. alignment: malloc can give us any address and we need to find a multiple of alignment-1 (Therefore, at maximum multiple of alignment, we will be alignment-1 bytes away from any location).
sizeof(size_t): We are returning a modified memory pointer to user, which is different from the one that would be returned by malloc. We also need to extra space to store the address given by malloc, so that we can free memory in aligned_free by calling free routine provided by C.
2. If it returns NULL, aligned_malloc will fail and return NULL.
3. Else, find the aligned memory address which is a multiple of alignment (call this p2).
4. Store the address returned by malloc (e.g., p1 is just size_t bytes ahead of p2), which will be required by aligned_free.
5. Return p2.

```c
void* aligned_malloc(size_t required_bytes, size_t alignment) {
    void* p1; // original block
    void** p2; // aligned block
    int offset = alignment - 1 + sizeof(void*);
    if ((p1 = (void*)malloc(required_bytes + offset)) == NULL) {
        return NULL;
    }
    p2 = (void**)((size_t)(p1) + offset) & ~(alignment - 1));
    p2[-1] = p1;
    return p2;
}
```

```c
void aligned_free(void* p) {
    free((void**)p)[-1]);
}
```

# Solutions to Chapter 16 | Low Level

16.10 Write a function called my2DAlloc allocates a two dimensional array. Minimize the number of calls to malloc and make sure that the memory is accessible by the notation arr[i][j].

pg 82

# SOLUTION

We will use one call to malloc.

```c
#include <stdlib.h>
int** my2DAlloc(int rows, int cols) {
    int** arr = (int**)malloc(rows * sizeof(int*));
    for (int i = 0; i < rows; i++) {
        arr[i] = (int*)malloc(cols * sizeof(int));
    }
    return arr;
}
```

# Solutions to Chapter 17 | Low Level

17.1 Explain what happens, step by step, after you type a URL.

# SOLUTION

1. Browser contacts the DNS to find the IP address.
2. DNS returns the HTML.
3. Browser opens TCP connection to the server.
4. Browser fetches the requested page.
5. Browser renders the HTML.
6. Browser terminates connection when closed.

One of the most interesting steps is Step 1 and 2 - "Domain Resolution." The Domain Name System (DNS) is a distributed but hierarchical entity. Each domain name server is divided into zones. A single server may only be responsible for a subset of host names but DNS servers can work together to map domain names to IP addresses. If one domain name server is unable to find the IP address it requests information from neighboring servers.

17.2 Explain any common routing protocol in detail. For example: BGP, OSPF, RIP.

# SOLUTION

Depending on the reader's level of understanding, knowledge, interest or career aspirations, they may wish to explore beyond what is included here. Wikipedia and other websites are great places to look for. We provide only a short summary.

BGP: Border Gateway Protocol

BGP is the core routing protocol of the Internet. When a BGP router comes up on the Internet, either for the first time or after being off, it establishes connections with the other BGP routers with which it directly communicates. The first thing it does is download the routing table of each neighboring router. After that it exchanges update messages with other routers. BGP routers send and receive update messages to indicate a change in the preferred path to reach a computer with a given IP address. If the router decides to update its routing tables then it will be better to propagate this information to all of the other BGP routers to which it is connected, and it will turn decide to update their tables and propagate the information further.

RIP: Routing Information Protocol

> "RIP provides the standard IGP protocol for local area networks, and provides great network stability, guaranteeing that if one network connection goes down the network can quickly adapt to send packets through another connection."

> "What makes RIP work a routing database that stores information on the fastest route from computer to computer, an update process that enables each router to tell other routers which is the fastest from its point of view, and an update algorithm that enables each router to update its database with the fastest route communicated from neighboring routers."
