Condition one (P(1) is true) ignites this chain, with truth cascading off into infinity.
Base Case: c = 1 (See previous page).
Assume true for c hats, i.e., if there are c hats, it will take c nights to remove all of them.
Prove true for c+1 hats.

Each man with a hat sees c hats, and can not be immediately sure whether there are c hats or c+1 hats. However, he knows that if there are c hats, it will take exactly c nights to remove them. Therefore, when c nights have passed and everyone still has a hat, he can only conclude that there are c+1 hats. He must know that he is wearing a hat. Each man makes the same conclusion and simultaneously removes the hats on night c+1.

Therefore, we have met the principles of induction. We have proven that it will take c nights to remove c hats.
