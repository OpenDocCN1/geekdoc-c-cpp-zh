### 凯撒密码

尤利乌斯·凯撒使用一种简单的替换密码来加密军事通信。⁷ 他的技术被称为凯撒密码，将消息中的每个字母替换为字母表中向后三个位置的字母。因此，A被替换为D，B替换为E，C替换为F，……X替换为A，Y替换为B，Z替换为C。因此，未加密的文本

```
Caesar Cipher
would be encrypted as
Fdhvdu Flskhu
```

加密后的文本被称为密文。未加密的文本被称为明文或清晰文本。
