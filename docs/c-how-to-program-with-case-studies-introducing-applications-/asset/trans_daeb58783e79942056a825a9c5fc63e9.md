### 13.1 引言

在第6章中，你了解到排序根据一个或多个排序键将数据按升序或降序放置。这里，我们介绍选择排序和插入排序算法，以及更高效但更复杂的归并排序。我们介绍大O表示法，它用于估计算法的最坏情况运行时间——即算法解决问题可能需要付出多大努力。
