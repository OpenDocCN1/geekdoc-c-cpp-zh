Function memchr searches for the first occurrence of a byte, represented as unsigned char, in the specified number of bytes of an object. # 8.9.5 Function memset

Function memset copies the value of the byte in its second argument into the first n bytes of the object pointed to by its first argument, where n is specified by the third argument. You can use memset to set an array's elements to 0 rather than assigning 0 to each element. For example, a five-element int array n could be reset to 0s with memset(n, 0, 5);
