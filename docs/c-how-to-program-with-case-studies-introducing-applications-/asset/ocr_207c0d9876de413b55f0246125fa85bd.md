# 8.9 Memory Functions of the String-Handling Library

The string-handling library functions in this section manipulate, compare and search blocks of memory. These functions treat memory as character arrays and can manipulate any block of data. The following table summarizes the string-handling library's memory functions. In the function discussions, “object” refers to a block of data.

| Function prototype | Function description |
|---|---|
| `void *memcpy(void *s1, const void *s2, size_t n);` | Copies n bytes from the object pointed to by s2 into the object pointed to by s1, then returns a pointer to the resulting object. |
| `void *memmove(void *s1, const void *s2, size_t n);` | Copies n bytes from the object pointed to by s2 into the object pointed to by s1. The copy is performed as if the bytes were first copied from the object pointed to by s2 into a temporary array and then from the temporary array into the object pointed to by s1.
