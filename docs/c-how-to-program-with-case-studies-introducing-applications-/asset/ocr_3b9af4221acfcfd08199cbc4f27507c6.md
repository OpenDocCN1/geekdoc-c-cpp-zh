# 3.12 What does the following program print?

```
#include <stdio.h>

int main(void) {
    int x = 1;
    int total = 0;

    while (x <= 10) {
        int y = x * x;
        printf("%d\n", y);
        total += y;
        ++x;
    } // end while

    printf("Total is %d\n", total);
} // end main
```
