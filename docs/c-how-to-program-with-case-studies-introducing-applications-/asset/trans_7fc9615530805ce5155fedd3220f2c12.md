- a) 第一趟之后，最大数保证位于编号最大的数组元素中；第二趟之后，两个最大数已“就位”，依此类推。不要每一趟都进行九次比较，而应修改冒泡排序，使第二趟进行八次比较，第三趟进行七次比较，依此类推。
