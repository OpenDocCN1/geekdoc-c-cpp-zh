# Bitwise Complement Operator (~)

The bitwise complement operator (~) sets all 1 bits in its operand to 0 in the result and sets all 0 bits to 1. This is otherwise referred to as "taking the one’s complement of the value." Line 37 assigns number1 the value 21845

# 10.9.4 Using the Bitwise Left- and Right-Shift Operators

Figure 10.6 demonstrates the left-shift (<<) and right-shift (>>) operators. Again, we use the function displayBits to display the unsigned int values.

// fig10_06.c
// Using the bitwise shift operators
#include <stdio.h>

void displayBits(unsigned int value); // prototype
