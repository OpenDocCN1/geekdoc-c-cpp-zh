For a six-sided die, the values 1 through 6 should each occur with “equal likelihood”—the probability of each is 1/6th or 16.67%. If we rolled a die 6000 times, we’d expect about 1000 of each face. Like coin tossing, die rolling is random, so some faces could occur fewer or more than 1000 times. As the number of die rolls increases, you’ll watch the frequencies approach 16.67% and the bars in the bar chart become nearly identical in length, confirming the law of large numbers.
