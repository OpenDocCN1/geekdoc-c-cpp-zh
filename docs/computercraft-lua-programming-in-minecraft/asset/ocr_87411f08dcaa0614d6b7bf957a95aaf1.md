# # CHAPTER 6: COMPUTER NETWORK

ComputerCraft will actually allow you to create more than one computer in a world and what is more, to connect the computers together in a network. To accomplish this you just need to add a couple of computers and attach wireless modem to the sides of them.

![](bbox=[0.3, 0.407, 0.869, 0.57])

Figure 6-1. A Computer Network in ComputerCraft

In this project (Figure 6-1). There are two computers, (one is hidden behind the screen in Figure 6-1) and you can type messages on the terminal in one computer and the message will be transmitted to the other computer where it will be displayed on the large screen attached to it.

# ## Setting Up the Sending Computer

In hardware terms, you just need a Computer and a wireless modem. Remember to which side of the computer the wireless adapter is connected as you will need to specify this in the program.
