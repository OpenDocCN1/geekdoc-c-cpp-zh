# Software

The program to control the door is pretty short and can easily be typed in. If you prefer to download a file containing the code, then it is available from: https://github.com/simomonk/computercraft_examples

To install this program into your ComputerCraft installation, follow the instructions in Appendix A.

```
while true do
  term.clear()
  term.setCursorPos(1, 1)
  print("Please enter the password:")
  password = read("*")
  if password == "password" then
    rs.setOutput("left", true)
    sleep(3)
    rs.setOutput("left", false)
  end
end
```

Now I'm going to break down the program line by line, and explain how it works. While true do I have mentioned above, this just keeps the program running in an infinite loop.

```
term.clear()
```

This line clears the screen every time the loop goes round.

```
term.setCursorPos
```

This sets the position of the cursor at (1, 1) or the top right hand side of the screen.

```
print("Please enter the password")
```

Is what is displayed on the screen to tell the user what to do.

The next line needs a bit more explanation:

```
password = read("*")
```
