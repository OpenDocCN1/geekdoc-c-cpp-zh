# ## CHAPTER 4: PASSWORD PROTECTED DOOR

With our basic knowledge of Lua and ComputerCraft, we can start to make some pretty cool stuff. A password protected door can be very useful on servers, especially if you are the only one who knows how to use the ComputerCraft mod.

Something that is very important to know, before we start with this program, is that if you have this line in your program..

```
```lua
while true do
```
```

.. you cannot stop the program, once it is running, unless you break the actual computer block, or hold the CTRL key and press T. This line features in the password program, so it's important to remember CTRL-T (for terminate) to stop the program so you can edit it, as you will probably want to change the password at some point.
