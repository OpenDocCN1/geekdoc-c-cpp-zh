# The Code

For this program to work, you must first enable web access
from ComputerCraft. To do this, you need to open up the
file "ComputerCraft.cfg" in the folder "minecraft/config"
using an editor like TextPad or NotePad and edit the
following code from:

```
```
enableapi http {
    Bgeneral=false
}
```
```

to:

```
```
enableapi http {
    Bgeneral=false
}
```
```

and further down in the same text file from:

```
```
BEnableAPI_http=false
```
```

to:

```
```
BEnableAPI_http=true
```
```

Once this is done, save the file again and restart MineCraft.

The code uses the Twitter API to fetch the latest tweet from
the twitter name specified, so you will probably want to
change the first line to refer to your Twitter name.

```
```
name = "Simonmonk2"
```
```
