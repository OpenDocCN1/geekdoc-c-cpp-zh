# CHAPTER 7: TWITTER IN MINECRAFT

We thought it might be cool to be able to read tweets while you are playing Minecraft. In this project, not only can you read tweets, but also you can arrange that when a Tweet arrives you are notified by activating a piston using Redstone.

![](bbox=[0.303, 0.399, 0.865, 0.575])

Figure 7-1. Twitter in Minecraft

After the piston activates and you know a Tweet has arrived you can go and view it on the Computer's console (Figure 7-2).
