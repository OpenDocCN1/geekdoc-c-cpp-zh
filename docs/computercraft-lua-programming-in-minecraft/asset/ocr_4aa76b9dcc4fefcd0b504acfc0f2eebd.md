# Installing Programs in ComputerCraft

You do not have to type the example programs into ComputerCraft. If you wish, you can download the programs and install them into ComputerCraft. Then all you have to do is to run them.

This is how you do that.

First, point your browser at https://github.com/simonmonk/computercraft_examples and then click on the icon labelled ZIP. It looks like a cloud with an arrow beneath it.

![](bbox=[0.351, 0.619, 0.889, 0.747])

Figure A-1: The Github Repository

This will download a zip file containing the programs. Unzip this into some convenient location, say the desktop.
