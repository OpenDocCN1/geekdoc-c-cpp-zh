code using a Redstone lamp.

To build the morse code sender, you will need a computer, and a or some Redstone lamp(s).

# Hardware

Connect the two together using Redstone, and depending how far away you want your lamp, you need a repeater every 15 blocks of Redstone.

The trick to hiding the Redstone, like I have done, is to set the output to bottom instead of left which is shown on the program code below. This means you are able to easily conceal the Redstone if you want, as it can be covered by other material.

Figure 5-1 shows one arrangement with the computer below the Redstone, but you can wire it up in any way you want as long as the program specifies the right side for the connection to the computer.
