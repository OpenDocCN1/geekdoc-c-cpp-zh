first want to go into the folder "bin" and the right click on the file "minecraft", or "minecraft.jar" if you have extensions on. This is where our archiving software is used. As I have winrar, these options appear when I right click the file (Figure 2-3).

Click "open with..." and then whatever archiving software you use. Now go to wherever your downloads folder is, and double click the "forge" folder. Highlight everything in the forge folder, and simply drag it across into the Minecraft folder.

Close the two windows and run Minecraft to make sure everything still works. We have nearly finished installing the mod, as all we need to do is head back into our .minecraft folder, and right click on any empty space in the window, and click the "new folder" button, and call it "mods". Simply copy or move the computercraft folder you downloaded, into the "mods" folder we just created and your done! Sometime you will find that there is already a "mods" folder in which case you will not need to create one.
