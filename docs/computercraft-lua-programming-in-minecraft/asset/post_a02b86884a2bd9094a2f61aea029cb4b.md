### The Code

For this program to work, you must first enable web access from ComputerCraft. To do this, you need to open up the file "ComputerCraft.cfg" in the folder "minecraft/config" using an editor like TextPad or NotePad and edit the following code from:

```
enableapi http {
    general=false
}
```

to:

```
enableapi http {
    general=true
}
```

and further down in the same text file from:

```
EnableAPI_http=false
```

to:

```
EnableAPI_http=true
```

Once this is done, save the file again and restart MineCraft.

The code uses the Twitter API to fetch the latest tweet from the twitter name specified, so you will probably want to change the first line to refer to your Twitter name.

```
name = "Simonmonk2"
```

```lua
page = "http://api.twitter.com/1/statuses/" ..
       "user_timeline.xml?screen_name=" .. name ..
       "&count=1"
old_text = ""

while true do
    tweet_page = http.get(page)
    response = tweet_page.readAll()
    tweet_page.close()
    start_of_tag = string.find(response,
                     "<text>")
    end_of_tag = string.find(response,
                     "</text>")

    if (start_of_tag and end_of_tag) then
        text = string.sub(response,
             start_of_tag + 6, end_of_tag - 1)
        if (text ~= old_text) then
            print(text)
            old_text = text
            rs.setOutput("bottom", true)
            sleep(3)
            rs.setOutput("bottom", false)
            sleep(3)
        end
    end
    sleep(20)
end
```

The Twitter API returns XML containing the message. The actual message itself will be in a <text> tag so the code finds the position of <text> and </text> and chops out the text in the middle.

The main loop continues forever, but a sleep of 20 seconds ensures that Twitter is only checked every 20 seconds for tweets.

We do not want to trigger the notification unless there is a new tweet, so the message that is fetched is compared with the message in the variable old_text and only if they are different is the message printed and the Redstone activated.

When you see the Redstone do something when you receive a message, you can go and read the message on the computer console.

The turtle will not normally move without fuel. Fortunately, there is a way around this. We can set our turtle to operate without being fed coal, by modifying the config file config/CCTurtle.cfg.

The code is in two parts. There is one program that runs on the computer (TurtleSend) and another on the Turtle itself that receives commands from the computer through the Turtle's wireless modem.

### TurtleSend

This is the program that runs on the Computer. It opens a connection to the wireless modem on the "right" of the computer. Remember to change this if you attach your modem to a different side.

```lua
while true do
    rednet.open("right")
    if rs.getInput("left") then
        rednet.broadcast("l")
    elseif rs.getInput("back") then
        rednet.broadcast("r")
    elseif rs.getInput("top") then
        rednet.broadcast("g")
    elseif rs.getInput("front") then
        rednet.broadcast("s")
    end
    rednet.close("right")
    sleep(0.9)
end
```

Having opened the connection, the rs.input functions return true if the Redstone connected to buttons are active. If the button is active then the computer broadcasts a message with a single letter command of 'r', 'l', 'g' or 's' for left, right, go or stop.

### Turtle Receive

The receiving code on the turtle mirrors the code on the computer. But, instead of checking for button presses, it checks for incoming messages from the wireless modem. If it finds it, then it sends the appropriate turtle movement command.

The variable ‘moving’ is used to determine if the turtle.forward() message is carried out. This allows the turtle to move forward automatically unless stopped.

```lua
rednet.open("right")
while true do
    id, message = rednet.receive(1)
    if message == "r" then
        turtle.turnRight()
    elseif message == "l" then
        turtle.turnLeft()
    elseif message == "g" then
        moving = true
    elseif message == "s" then
        moving = false
    end
    if moving then
        turtle.forward()
    end
end
```
