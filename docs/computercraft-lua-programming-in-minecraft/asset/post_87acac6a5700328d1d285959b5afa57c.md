
The return command quits the function, sending back the value specified—in this case, 'T'.

### Lists

Variables can only hold a single value, but sometimes it is useful to be able to collect together a list of things. You will use this example later in the Morse code example. The items in a Lua list can be any type of value. They can be a number or string or even another list.

The example below shows how you can define a list of colors and then print them out one at a time.

```lua
colors = {'red', 'orange', 'yellow',
          'green', 'blue',
          'white', 'black'}

for i, color in ipairs(colors) do
  print(color)
end
```

In this case, the list is given the values of color names, each as a string. The for loop uses a special command "ipairs" that allows the "for" loop to count with both the position of each thing in the list (i) and the color string (color).

We can prove this by modifying the example so that we print both the position in the list and the string as shown below:

```lua
colors = {'red', 'orange', 'yellow',
          'green', 'blue', 'white', 'black'}
for i, color in ipairs(colors) do
  print(i, color)
end
```

This will produce an output like this:

```
1    red
2    orange
3    yellow
4    green
5    blue
6    white
7    black
```

You can also find the value of things in a list from their position, by using a square-brackets notation. Try typing the following into the Lua console:

```lua
colors = { 'red', 'orange', 'yellow',
  'green', 'blue', 'white',
  'black' }
print(colors[3])
```

You will get the answer yellow, the third item in the list.

You can use the same [] notation to change a particular item. Now type the following into the console:

```lua
colors[3] = "purple"
print(colors[3])
```

This now gives the answer purple. The command has changed the third element of the list from yellow to purple.

You can also add and remove items from the list.

To add an element to the end of a list, use the table.insert command. As shown in the example below, which will add the color gray to the end of the list.

```lua
colors = { 'red', 'orange', 'yellow',
  'green', 'blue',
  'white', 'black' }
table.insert(colors, 'gray')

print(colors[8])
```

If, rather than add the color to the end of the list, you want to specify a position in the list where the element should be added, the following code will add the new color to the start of the list.

```lua
colors = { 'red', 'orange', 'yellow',
  'green', 'blue',
  'white', 'black' }
table.insert(colors, 1, 'gray')

print(colors[1])
```

The number 1 as the second argument to insert indicates that the new item should be inserted before the first element in the list.

### Summary

This is a pretty brief introduction to what is quite a complex programming language. It should however get you started with Lua and allow you to do most of the things you want to with ComputerCraft.

If you want to find out more about Lua then check out the official web site at www.lua.org.

## CHAPTER 4: PASSWORD PROTECTED DOOR

With our basic knowledge of Lua and ComputerCraft, we can start to make some pretty cool stuff. A password protected door can be very useful on servers, especially if you are the only one who knows how to use the ComputerCraft mod.

Something that is very important to know, before we start with this program, is that if you have this line in your program:

```lua
while true do
```

... you cannot stop the program, once it is running, unless you break the actual computer block, or hold the CTRL key and press T. This line features in the password program, so it's important to remember CTRL-T (for terminate) to stop the program so you can edit it, as you will probably want to change the password at some point.

### Hardware

Before we do the programming, we need to set up the blocks as shown in Figure 4-1.

![](img/7ea6f60bb53ecc17dd8979f66d5502d6_36_0.png)

Figure 4-1. Password Protected Door.

Of course it doesn't really matter what kind of blocks or door you are using, this is just an example. Also, if you want the computer above, or to the right of the door, you will have to change the sides that are used in the program code below from "left" to whichever side of the computer the door is situated.

You can use "left", "right", "front", "back", "bottom" or "top".

### Software

The program to control the door is pretty short and can easily be typed in. If you prefer to download a file containing the code, then it is available from: https://github.com/simonmonk/computercraft_examples

To install this program into your ComputerCraft installation, follow the instructions in Appendix A.

```lua
while true do
  term.clear()
  term.setCursorPos(1, 1)
  print("Please enter the password:")
  password = read("*")
  if password == "password" then
    rs.setOutput("left", true)
    sleep(3)
    rs.setOutput("left", false)
  end
end
```

Now I'm going to break down the program line by line, and explain how it works. The `while true do` line, as I have mentioned above, just keeps the program running in an infinite loop.

```lua
term.clear()
```

This line clears the screen every time the loop goes round.

```lua
term.setCursorPos(1, 1)
```

This sets the position of the cursor at (1, 1) or the top right hand side of the screen.

```lua
print("Please enter the password:")
```

Is what is displayed on the screen to tell the user what to do.

The next line needs a bit more explanation:

```lua
password = read("*")
```

password is the variable, which has to be defined with an equals. The command read means it is looking for something to be typed in and (*) means as it is typed in, it will be displayed as `*s`. Note that this is a ComputerCraft specific feature, so if you try it on Lua not running in ComputerCraft, then it probably will not work.

```lua
if password == "password" then
```

This will look at the variable password which is what we typed in, and == means it will compare it to whatever we put on the other side, which is the text "password". This means that if you want to change the password, you have to change what's inside the quotes. The command then finishes the line off, so if what you typed in matches what is inside the quotes (your password) then it will do something.

There is another indent here to show that it is inside the *if* statement.

```lua
rs.setOutput("left", true)
```

This is saying that Redstone is turned on at the left side of the computer, which goes through the block, and triggers the door.

```lua
sleep(3)
```

This makes the computer wait 3 seconds before it moves on, and then `rs.setOutput("left", false)` turns off the Redstone signal on the left of the computer, therefore closing the door. I personally find keeping the door open for 3 seconds about right, but you can change it to anything you want.

Finally, the first *end* marks the end point of what the *if* statement should do, with *then* as the beginning point, and the second *end* is marking where the *while true do* loop should stop.

As this program is only 11 lines long, you can easily type it out, but, for example, it would be very tedious to type out the next program, so you can also refer to Appendix A for instructions on downloading all the Lua programs in this book.
