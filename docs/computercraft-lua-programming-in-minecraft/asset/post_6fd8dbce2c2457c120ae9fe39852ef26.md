## CHAPTER 1: INTRODUCTION

This book will teach you how to program using the ComputerCraft mod in Minecraft and the Lua programming language.

### Minecraft

Minecraft is the creation of Markus "Notch" Persson and has been developed further by the games company Mojang. It was first released to the world back in 2009 and has become a huge success world-wide.

Although the game includes combat and other conventional game activities, what makes Minecraft so interesting and different from many other games is the construction of objects within a virtual world (Figure 1-1).

The player can operate in a 'creative' mode where they can roam free and construct buildings and even machines from blocks. These blocks are of different types and can be purely structural or can have some special purpose. Some

![](img/7ea6f60bb53ecc17dd8979f66d5502d6_8_0.png)

of the more interesting blocks are:

- Redstone - conduct a signal
- Redstone lamp - light up
- Pistons - push blocks
- Sticky pistons - can pull as well as push blocks
- Redstone torch - acts as a power source for Redstone related objects (all of the above)
- Redstone Repeaters - can extend Redstone signals (normal limit from a torch, button, lever is 15 blocks), can also set delays and only allow signal through one way

### Technology

Minecraft players are inventive and many have set about finding ways to build incredibly complex machines in Minecraft. Some of these recreations of real-world objects within Minecraft include:

- Digital Clocks
- Cannons that fire blocks
- Digital logic gates
- BUD or Block Update Detectors
- Elevators
- 8-bit memory
- Calculators

### Mods

The Minecraft platform is quite open, allowing developers to create extensions to the original game. These extensions add new types of special purpose block to the game or other features that game players might find useful.

These mods are often bundled up into a “mod pack” that can be downloaded and added to Minecraft in one go.

Some of the interesting mods that are available include:

- Gems+ - Adds gems such as sapphires, rubies etc.
- Mo’creatures - add new animals and mobs to the game
- MAtmos - add environmental sounds to the game
- Equivalent Exchange - enables you to exchange items for other items using a EMC value (the higher the more expensive) for example, 64 dirt for one coal
- Macro / Keybind Mod - record actions and replay them
- MineVideo Mod - record video of your gameplay
- Modern Weapons - add guns and things
- PortalCraft - Adds guns that fire portals
- Optifine - Improves frame-rate of your game (less lag)

One of these mods (ComputerCraft) allows you to add a computer to the game and then program it with the Lua programming language.

This book focuses on how to program ComputerCraft in Lua.

## CHAPTER 2: COMPUTERCRAFT

ComputerCraft is a mod for Minecraft that enables all sorts of possibilities through the use of programmable computers, and turtles and an array of other interesting features such as printers and even floppy disks. It is included in two of the most well-known modpacks: The Tekkit/Technic modpack, and the newcomer, Feed The Beast.

Although the concept of using a computer in a computer game seems a bit odd, it is perfect for people who want to get in to simple programming with visible and satisfying results.

### Installing the ComputerCraft Mod

The ComputerCraft mod requires the Minecraft Forge API, so it's not the easiest mod to install, but it is still fairly easy to do. At the moment, the most recent version of ComputerCraft is for Minecraft 1.4.6, but confusingly enough, the ComputerCraft version is 1.4.8. As I already mentioned, you could download Feed The Beast or Tekkit/Technic which include the ComputerCraft mod. However, we will show you how to install it into a clean version of Minecraft.

The instructions are for Windows, but can be easily adapted for other operating systems.

First of all, you will need to download an archiving software if you do not already have one, I recommend you install either WinRAR (my preference) or 7-Zip. WinRAR can be downloaded from here: http://www.rarlab.com/ and 7-Zip from here: http://www.7-zip.org/

Now, we are going to install the correct version of Forge, simply browse to the link http://tinyurl.com/MF1-4-6

You will see a webpage that looks something like Figure 2-1.

After the timer hits 0, press the skip ad button and your zipped folder will start downloading.
