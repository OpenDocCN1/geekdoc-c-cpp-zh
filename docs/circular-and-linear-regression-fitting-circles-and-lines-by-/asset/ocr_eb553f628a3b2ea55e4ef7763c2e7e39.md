case. The matrix **X<sup>T</sup>X** is singular if and only if there exists a nonzero vector **A**<sub>0</sub> = (A, B, C, D) such that **XA**<sub>0</sub> = **0**, i.e.,

A(x<sub>i</sub><sup>2</sup> + y<sub>i</sub><sup>2</sup>) + Bx<sub>i</sub> + Cy<sub>i</sub> + D = 0

for all i = 1, ..., n. This means precisely that the data points (x<sub>i</sub>, y<sub>i</sub>) either lie on a circle (this happens if A \u2260 0) or on a line (if A = 0). In either case \u03b7 = 0 is an eigenvalue of the matrix **B**<sup>-1</sup>(**X<sup>T</sup>X**), the corresponding eigenvector is **A**<sub>0</sub>, and

\mathscr{F}_{3}(**A**_{0}) = \|**XA**_{0}\|^{2} = 0,

hence **A**<sub>0</sub> minimizes \mathscr{F}_{3}. In fact it provides a perfect fit.

**Conclusions.** The Pratt circle fit is given by an eigenvector \mathbf{A} = (A, B, C, D) of the matrix \mathbf{B}^{-1}(\mathbf{X}^{T}\mathbf{X}) that corresponds to its smallest nonnegative eigenvalue \eta \geq 0. If \mathbf{X} has full rank (the generic case), then \mathbf{A} can also be found by \mathbf{A} = \mathbf{Y}^{-1}\mathbf{A}_{*}, where \mathbf{Y} = (\mathbf{X}^{T}\mathbf{X})^{1/2} and \mathbf{A}_{*} is an eigenvector of the symmetric matrix \mathbf{Y}\mathbf{B}^{-1}\mathbf{Y} that corresponds to its smallest positive eigenvalue \eta > 0 (as a side note: \mathbf{B}^{-1}(\mathbf{X}^{T}\mathbf{X}) has three positive and one negative eigenvalue).

# **5.6 Implementation of the Pratt fit**

The analysis in the previous section uniquely identifies the eigenpair (\eta, \mathbf{A}) of the matrix \mathbf{B}^{-1}(\mathbf{X}^{T}\mathbf{X}) that provides the Pratt fit, but we also need a practical algorithm to compute it. Here we describe two such algorithms; each one has its own merit.

**SVD-based Pratt fit.** If one uses software with built-in matrix algebra operations (such as MATLAB), then one may be tempted to call a routine returning the eigenpairs of \mathbf{B}^{-1}(\mathbf{X}^{T}\mathbf{X}) and select the eigenvector \mathbf{A} corresponding to the smallest nonnegative eigenvalue. This promises a simple, albeit not the fastest, solution.

However, this solution is not numerically stable. For one reason, the condition number of the matrix \mathbf{X}^{T}\mathbf{X} is that of \mathbf{X} squared, i.e., \varkappa(\mathbf{X}^{T}\mathbf{X}) = [\varkappa(\mathbf{X})]^{2}; thus assembling and using \mathbf{X}^{T}\mathbf{X} may cause an explosion of round-off errors if \mathbf{X}^{T}\mathbf{X} happens to be nearly singular. Second, we have observed cases where the numerically computed eigenvalues of \mathbf{B}^{-1}(\mathbf{X}^{T}\mathbf{X}) turned out complex, though theoretically they all must be real.

A more stable matrix solution is achieved by the singular value decomposition (SVD). First, we compute the (short) SVD, \mathbf{X} = \mathbf{U}\mathbf{E}\mathbf{V}^{T}, of the matrix \mathbf{X}. If its smallest singular value, \sigma_{4}, is less than a predefined tolerance \varepsilon (say, \varepsilon = 10^{-12}), then we have a singular case at hand, and the solution \mathbf{A} is simply the corresponding right singular vector, i.e., the fourth column of the \mathbf{V} matrix.
