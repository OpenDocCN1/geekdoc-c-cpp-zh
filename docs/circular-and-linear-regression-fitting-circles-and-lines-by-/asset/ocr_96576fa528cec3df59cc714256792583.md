are shorthand notation. Now Karimäki arrives at the objective function

```
$$\mathscr{F}(\boldsymbol{\rho}, d, \varphi) = (1 + \boldsymbol{\rho}d)^{2} \sum_{i=1}^{n} \big( \boldsymbol{\kappa}r_{i}^{2} - r_{i} \sin(\varphi - \theta_{i}) + \mu \big)^{2} . \tag{8.35}$$
```

This is, of course, the same objective function (5.16) used by Chernov and Ososkov [45], but expressed in terms of the new parameters $\boldsymbol{\rho}, d, \varphi$.

Karimäki further simplifies the objective function (8.35) by discarding the factor $\left(1+\boldsymbol{\rho} d\right)^{2}$, so he actually minimizes

```
$$\begin{aligned}\mathscr{F}_{\mathrm{Kar}}(\boldsymbol{\rho}, d, \varphi)=& \sum_{i=1}^{n} \big(\boldsymbol{\kappa} r_{i}^{2}-r_{i} \sin (\varphi-\theta_{i})+\mu\big)^{2} \\ = & \sum_{i=1}^{n}\left(z_{i} \boldsymbol{\kappa}-x_{i} \sin \varphi+y_{i} \cos \varphi+\mu\right)^{2}, \tag{8.36}\end{aligned}$$
```

where we use our standard notation $z_{i}=x_{i}^{2}+y_{i}^{2}$.

Karimäki’s rational for dropping the factor $\left(1+\boldsymbol{\rho} d\right)^{2}$ from (8.35) is that in high energy physics experiments

```
$$|d| \ll R=1 /|\boldsymbol{\rho}|, \quad \text { hence } \quad 1+\boldsymbol{\rho} d \approx 1 .$$
```

Furthermore, Karimäki argues that the factor $\left(1+\boldsymbol{\rho} d\right)^{2}$ is almost constant, in the sense that it varies slowly (as a function of $\boldsymbol{\rho}$ and $d$), while the function $\mathscr{F}_{\mathrm{Kar}}$ in (8.36) has a sharp minimum, thus the location of that minimum should not be affected much by an extra slowly varying factor.

He supports his reasoning by experimental evidence: he shows that in typical cases the parameters minimizing (8.36) also provide the minimum of (8.35), with a relative error $<10^{-3}$; see [106]. In another paper [107] Karimäki describes the range of parameter values for which his reduction of (8.35) to (8.36) remains reasonably accurate.

We will return to this issue in Section 8.9.

**Karimäki’s minimization scheme.** The formula (8.36) suggests that $\boldsymbol{\kappa}$ and $\mu$ can be treated as new parameters that will temporary replace $\boldsymbol{\rho}$ and $d$. The minimization of (8.36) with respect to $\boldsymbol{\kappa}$, $\mu$, and $\varphi$ turns out to be a relatively simple problem that has an explicit closed form solution. It was found by Karimäki [106], we present it next.

First, one differentiates (8.36) with respect to $\boldsymbol{\kappa}$ and $\mu$ and finds

```
$$\begin{aligned}\frac{1}{2 n} \frac{\partial \mathscr{F}_{\mathrm{Kar}}}{\partial \boldsymbol{\kappa}}=& \bar{z} z \boldsymbol{\kappa}-\bar{x} z \sin \varphi+\bar{y} z \cos \varphi+\bar{z} \boldsymbol{\mu}=0, \\ \frac{1}{2 n} \frac{\partial \mathscr{F}_{\mathrm{Kar}}}{\partial \mu}=& \bar{z} \boldsymbol{\kappa}-\bar{x} \sin \varphi+\bar{y} \cos \varphi+\boldsymbol{\mu}=0, \tag{8.37}\end{aligned}$$
```
