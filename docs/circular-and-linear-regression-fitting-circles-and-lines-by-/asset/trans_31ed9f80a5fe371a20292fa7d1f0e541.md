### 泰勒展开

现在，可以利用泰勒近似，从 $\hat{\boldsymbol{\theta}}$ 的性质中轻松推导出估计量 $\hat{A}$、$\hat{B}$、$\hat{C}$ 的主要阶渐近性质。我们在 A 型模型的背景下演示这一过程。

首先，$A = \sin \boldsymbol{\theta}$ 且 $B = -\cos \boldsymbol{\theta}$，因此使用泰勒展开至三阶项，我们得到

$A = \bar{A} - \bar{B}\, \delta\boldsymbol{\theta} - \frac{1}{2}\,\bar{A}\,(\delta\boldsymbol{\theta})^2 + \frac{1}{6}\bar{B}\,(\delta\boldsymbol{\theta})^3 + \mathcal{O}\bigl((\delta\boldsymbol{\theta})^4\bigr)$

$B = \bar{B} + \bar{A}\, \delta\boldsymbol{\theta} - \frac{1}{2}\,\bar{B}\,(\delta\boldsymbol{\theta})^2 - \frac{1}{6}\bar{A}\,(\delta\boldsymbol{\theta})^3 + \mathcal{O}\bigl((\delta\boldsymbol{\theta})^4\bigr)$。

### $\hat{A}$ 和 $\hat{B}$ 的均值和方差

取均值（回忆 $\mathbb{E}(\delta\boldsymbol{\theta}) = \mathbb{E}(\delta\boldsymbol{\theta})^3 = 0$）可得

$\mathbb{E}(\hat{A}) = \hat{A}\biggl[1 - \frac{\boldsymbol{\sigma}^2}{2S}\biggr] + \mathcal{O}(\boldsymbol{\sigma}^4)$，

$\mathbb{E}(\hat{B}) = \hat{B}\biggl[1 - \frac{\boldsymbol{\sigma}^2}{2S}\biggr] + \mathcal{O}(\boldsymbol{\sigma}^4)$，

即估计量 $\hat{A}$ 和 $\hat{B}$ 向零偏斜。取方差可得

$\mathrm{Var}\,\hat{A} = \frac{\boldsymbol{\sigma}^2\hat{B}^2}{S} + \mathcal{O}(\boldsymbol{\sigma}^4)$，

$\mathrm{Var}\,\hat{B} = \frac{\boldsymbol{\sigma}^2\hat{A}^2}{S} + \mathcal{O}(\boldsymbol{\sigma}^4)$，

$\mathrm{Cov}(\hat{A}, \hat{B}) = -\frac{\boldsymbol{\sigma}^2\hat{A}\hat{B}}{S} + \mathcal{O}(\boldsymbol{\sigma}^4)$。

注意每个估计量的标准差为 $\mathcal{O}(\boldsymbol{\sigma})$，而其偏差为 $\mathcal{O}(\boldsymbol{\sigma}^2)$；因此偏差的高阶小量更高。换句话说，当我们评估估计量的均方误差时，偏差可以忽略不计，例如

$\mathrm{MSE}(\hat{A}) = \mathbb{E}\bigl[\bigl(\hat{A} - \bar{A}\bigr)^2\bigr] = \mathrm{Var}(\hat{A}) + \bigl[\mathbb{E}(\hat{A}) - \bar{A}\bigr]^2 = \frac{\boldsymbol{\sigma}^2\hat{B}^2}{S} + \mathcal{O}(\boldsymbol{\sigma}^4)$，

偏差被 $\mathcal{O}(\boldsymbol{\sigma}^4)$ 项吸收。

### $\hat{C}$ 的均值和方差

最后，通过使用 $\hat{C} = -\hat{A}\bar{x} - \hat{B}\bar{y}$ 我们得到

$\mathbb{E}(\hat{C}) = \hat{C}\biggl[1 - \frac{\boldsymbol{\sigma}^2}{2S}\biggr] + \mathcal{O}(\boldsymbol{\sigma}^4)$，

以及

$\mathrm{Var}\,\hat{C} = \boldsymbol{\sigma}^2\biggl[\frac{1}{n} + \frac{\bigl(\hat{A}\bar{y} - \hat{B}\bar{x}\bigr)^2}{S}\biggr] + \mathcal{O}(\boldsymbol{\sigma}^4)$。

其中
$$
\bar{\bar{x}} = \sum_{i=1}^n \tilde{x}_i \quad \text{和} \quad \bar{\bar{y}} = \sum_{i=1}^n \tilde{y}_i
$$
是真实值的样本均值。(2.26) 中额外的项 $\frac{1}{n}$ 来源于 $\bar{x}$ 和 $\bar{y}$（观测值的样本均值）是与 $\hat{A}$ 和 $\hat{B}$ 相关的随机变量这一事实。

### 协方差

为了完整性，我们包含另外三个协方差
$$
\begin{aligned}
\operatorname{Cov}(\hat{A}, \hat{C}) &= \frac{\sigma^2 \bar{B}(A\bar{\bar{y}} - \bar{B}\bar{\bar{x}})}{S} + \mathscr{O}(\sigma^4)\\
\operatorname{Cov}(\hat{B}, \hat{C}) &= -\frac{\sigma^2 \bar{A}(A\bar{\bar{y}} - \bar{B}\bar{\bar{x}})}{S} + \mathscr{O}(\sigma^4)\\
\operatorname{Cov}(\hat{\theta}, \hat{C}) &= -\frac{\sigma^2(A\bar{\bar{y}} - \bar{B}\bar{\bar{x}})}{S} + \mathscr{O}(\sigma^4).
\end{aligned}
$$

### 实践备注

在实践中，上述公式中出现的真实值是不可获得的。通常，人们会进一步近似，用观测值替代真实点，用估计量替代真实参数值（这不会改变上述表达式，产生的误差被 $\mathscr{O}(\sigma^4)$ 项吸收）。同样地，我们用
$$
\hat{S} = s_{xx} + s_{yy}
$$
来估计 $S$，并用
$$
\hat{\sigma}^2 = \frac{1}{n} \sum_{i=1}^n (\hat{A}x_i + \hat{B}y_i + \hat{C})^2. \tag{2.27}
$$
来估计 $\sigma^2$。Gleser [73] 和 Patefield [143] 表明所有这些估计量都是强一致的，因此它们在构建置信区间中的使用是合理的。

## 2.7 近似分析

**泰勒近似与严谨证明。** 在前一节中，我们使用泰勒展开推导了基于方差 $\operatorname{Var}(\hat{\theta})$ 的二阶近似 (2.25) 的所有重要估计量的方差和协方差公式，其证明被放在“幕后”（我们直接引用 Anderson [7] 和 Kunitomo [118] 的精确结果）。
在本节中，我们在不使用精确结果的情况下，通过泰勒近似推导 (2.25) 本身。因此我们展示了泰勒展开，如果正确使用，是一个强大的（虽然不严谨的工具，它允许我们获得正确的近似，即使包括高阶项。这将有助于我们后续对非线性回归的研究，特别是圆和椭圆。

### 矩阵近似

我们使用第 2.3 节的记号，并关注扰动 $\delta\mathbf{A} = \mathbf{A} - \tilde{\mathbf{A}}$、$\delta\mathbf{S} = \mathbf{S} - \tilde{\mathbf{S}}$ 等，其中波浪号用于表示真实值。正交拟合最小化

$\mathscr{F}(\mathbf{A}) = \mathbf{A}^T\mathbf{S}\mathbf{A} = \mathbf{A}^T\mathbf{X}^T\mathbf{X}\mathbf{A} = (\tilde{\mathbf{A}} + \delta\mathbf{A})^T(\tilde{\mathbf{X}} + \delta\mathbf{X})^T(\tilde{\mathbf{X}} + \delta\mathbf{X})(\tilde{\mathbf{A}} + \delta\mathbf{A})$。

展开，利用 $\tilde{\mathbf{X}}\tilde{\mathbf{A}} = 0$ 这一事实（由 (2.15) 得出），并保留统计显著项³ 得到

$\mathscr{F}(\mathbf{A}) = \tilde{\mathbf{A}}^T\delta\mathbf{X}^T\delta\mathbf{X}\tilde{\mathbf{A}} + \delta\mathbf{A}^T\tilde{\mathbf{X}}^T\tilde{\mathbf{X}}\delta\mathbf{A} + 2\tilde{\mathbf{A}}^T\delta\mathbf{X}^T\tilde{\mathbf{X}}\delta\mathbf{A} + 2\tilde{\mathbf{A}}^T\delta\mathbf{X}^T\delta\mathbf{X}\delta\mathbf{A}$。

现在 $\mathscr{F}$ 的最小值在 $\partial \mathscr{F} / \partial \mathbf{A} = 0$ 处取得，即在

$\tilde{\mathbf{X}}^T\tilde{\mathbf{X}}\delta\mathbf{A} + (\tilde{\mathbf{X}}^T\delta\mathbf{X} + \delta\mathbf{X}^T\delta\mathbf{X})\tilde{\mathbf{A}} = 0$，

因此

$\delta\mathbf{A} = -(\tilde{\mathbf{X}}^T\tilde{\mathbf{X}})^-(\tilde{\mathbf{X}}^T\delta\mathbf{X} + \delta\mathbf{X}^T\delta\mathbf{X})\tilde{\mathbf{A}}, \quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad(2.28)$

其中 $(\tilde{\mathbf{X}}^T\tilde{\mathbf{X}})^-$ 表示矩阵 $\tilde{\mathbf{X}}^T\tilde{\mathbf{X}}$ 的 Moore-Penrose 广义逆（因为 $\tilde{\mathbf{X}}\tilde{\mathbf{A}} = 0$，该矩阵秩亏）。

### 一个便利的假设

由于 $\delta\boldsymbol{\theta} = \boldsymbol{\theta} - \tilde{\boldsymbol{\theta}}$ 的分布不依赖于 $\tilde{\boldsymbol{\theta}}$（第 2.4 节），我们可以通过假设直线是水平的来简化计算，即 $\tilde{\mathbf{A}} = (0,1)^T$。那么 $\delta\mathbf{A} = (\delta\boldsymbol{\theta}, 0)^T$，至主要阶，且

$\tilde{\mathbf{X}}^T\tilde{\mathbf{X}} = \begin{bmatrix} S & 0 \\ 0 & 0 \end{bmatrix}, \quad \text{因此} \quad (\tilde{\mathbf{X}}^T\tilde{\mathbf{X}})^- = \begin{bmatrix} \frac{1}{S} & 0 \\ 0 & 0 \end{bmatrix}$。

矩阵 $\delta\mathbf{X}$ 是

$\begin{bmatrix} \delta_1 - \bar{\delta} & \boldsymbol{\epsilon}_1 - \bar{\boldsymbol{\epsilon}} \\ \vdots & \vdots \\ \delta_n - \bar{\delta} & \boldsymbol{\epsilon}_n - \bar{\boldsymbol{\epsilon}} \end{bmatrix}$，

其中我们继续使用样本均值记号，即 $\bar{\delta} = \sum_{i=1}^n \delta_i$ 等。现在 (2.28) 变为

$\delta\boldsymbol{\theta} = -\frac{1}{S}\sum_{i=1}^n(\bar{x}_i - \bar{\bar{x}})(\boldsymbol{\epsilon}_i - \bar{\boldsymbol{\epsilon}}) - \frac{1}{S}\sum_{i=1}^n(\delta_i - \bar{\delta})(\boldsymbol{\epsilon}_i - \bar{\boldsymbol{\epsilon}})$。

利用我们对误差 $\delta_i$ 和 $\boldsymbol{\epsilon}_i$ 的假设，我们容易计算出 $\mathbb{E}(\delta\boldsymbol{\theta}) = 0$ 以及

$\mathbb{E}\left[\sum_{i=1}^n(\bar{x}_i - \bar{\bar{x}})(\boldsymbol{\epsilon}_i - \bar{\boldsymbol{\epsilon}})\right]^2 = \sigma^2\sum_{i=1}^n(\bar{x}_i - \bar{\bar{x}})^2 = \sigma^2 S$，

³我们丢弃项 $\delta\mathbf{A}^T\delta\mathbf{X}^T\delta\mathbf{X}\delta\mathbf{A}$，它是 $\sigma^4$ 阶的，以及 $2\delta\mathbf{A}^T\tilde{\mathbf{X}}^T\delta\mathbf{X}\delta\mathbf{A}$，它是 $\sigma^2/\sqrt{n}$ 阶的。我们保留所有 $\sigma^2$ 阶或 $\sigma^3\sqrt{n}$ 阶或更高阶的项。
