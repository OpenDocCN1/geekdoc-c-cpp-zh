**Modified objective function by Pratt.** We go back to the parameters $A,B,C,D$ introduced in Section 3.2, i.e., we describe a circle by algebraic equation

```
$$A(x^2 + y^2) + Bx + Cy + D = 0, \qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad (5.20)$$
```

as it was done in (3.8). Now the function $\mathscr{F}_2$ in (5.17) can be rewritten as

```
$$\mathscr{F}_2 = \frac{1}{B^2 + C^2 - 4AD} \sum_{i=1}^n (Az_i + Bx_i + Cy_i + D)^2 \qquad\qquad\qquad (5.21)$$
```

(indeed, its value does not change if we multiply the vector $(A,B,C,D)$ by a scalar, thus it is always possible to make $A=1$ and recover (5.17)).

**Constrained minimization.** Recall that $B^2 + C^2 - 4AD > 0$ whenever the quadruple $(A,B,C,D)$ represents a circle (Section 3.2). Thus, the minimization of (5.21) over $A,B,C,D$ is equivalent to the minimization of the simpler function

```
$$\mathscr{F}_3(A,B,C,D) = \sum_{i=1}^n (Az_i + Bx_i + Cy_i + D)^2 \qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad (5.22)$$
```

subject to the constraint

```
$$B^2 + C^2 - 4AD = 1, \qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad (5.23)$$
```

which, by the way, we have already encountered in (3.10). Under this constraint, equation (5.20) describes all circles and lines in the $xy$ plane, see Section 3.2. Thus the Pratt algorithm conveniently incorporates lines into its selection of the best fit (unlike the Kása and Chernov–Ososkov methods that can only return circles).

**Reduction to an eigenvalue problem.** To solve the minimization problem (5.22)–(5.23), Pratt [150] employs methods of linear algebra. The function (5.22) can be written in matrix form as

```
$$\mathscr{F}_3 = \|\mathbf{X}\mathbf{A}\|^2 = \mathbf{A}^T (\mathbf{X}^T \mathbf{X}) \mathbf{A}, \qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad (5.24)$$
```

where $\mathbf{A} = (A,B,C,D)^T$ is the vector of parameters and

```
$$\mathbf{X} = \begin{bmatrix} z_1 & x_1 & y_1 & 1 \\ \vdots & \vdots & \vdots & \vdots \\ z_n & x_n & y_n & 1 \end{bmatrix} \qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad (5.25)$$
```

is the $n \times 4$ “extended data matrix” (note that it is different from (5.11)). The constraint (5.23) can be written as

```
$$\mathbf{A}^T \mathbf{B} \mathbf{A} = 1, \qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad (5.26)$$
```
