Another geometrical definition, see [51], results from the expansion

```
$$f_i = (r_i - R)(r_i + R), \quad r_i = \sqrt{(x_i - a)^2 + (y_i - b)^2}. \tag{5.7}$$
```

Here the first factor $d_i = r_i - R$ is the distance from $(x_i, y_i)$ to the *nearest* point on the circle $(a, b, R)$, while the second factor $D_i = r_i + R$ is the distance from $(x_i, y_i)$ to the *farthest* point on the circle. Thus the Kåsa method minimizes

```
$$\mathscr{F}_1 = \sum_{i=1}^{n} d_i^2 D_i^2. \tag{5.8}$$
```

**Chord method.** The Kåsa fit is also related to the *chord method* proposed in [184, 193]. While not practically efficient, this method is worth mentioning due to its relevance to the Kåsa fit.

Observe that if any two points $P_i = (x_i, y_i)$ and $P_j = (x_j, y_j)$ lie on the fitting circle, then the perpendicular bisector $L_{ij}$ of the chord $P_iP_j$ passes through its center, see Fig. 5.2. Thus one can find the best center $(a, b)$ by minimizing

```
$$\mathscr{F}_{ch} = \sum_{1 \le i < j \le n} w_{ij} D_{ij}^2,$$
```

where $D_{ij}$ denotes the distance from $(a, b)$ to the bisector $L_{ij}$ and $w_{ij}$ is a certain weight, see below.

By elementary geometry, $\mathscr{F}_{ch}$ is a quadratic function of $a$ and $b$:

```
$$\mathscr{F}_{ch} = \sum_{1 \le i < j \le n} w_{ij} \frac{[(a(x_i - x_j) + b(y_i - y_j) - \frac{1}{2}(x_i^2 - x_j^2 + y_i^2 - y_j^2)]^2}{(x_i - x_j)^2 + (y_i - y_j)^2}, \tag{5.9}$$
```
