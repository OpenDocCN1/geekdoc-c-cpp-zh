The constrained minimization problem (7.16)$\sim$(7.17) reduces to the generalized eigenvalue problem

```
**MA** = $\eta$**NA**,   (7.22)
```

thus **A** must be a generalized eigenvector of the matrix pair (**M**, **N**). To find the solution of the minimization problem (7.16)$\sim$(7.17) we must choose the eigenvector **A** with the smallest nonnegative eigenvalue $\eta$. This fact determines **A** up to a scalar multiple; as multiplying **A** by a scalar does not change the circle it represents, we can set ||**A**|| = 1.

**Matrix perturbation method.** As algebraic fits can be conveniently expressed in matrix form, we perform error analysis on matrices, following Kananati [104]. For every random variable, matrix or vector, **Z**, we write

```
**Z** = $\tilde{\mathbf{Z}}$ + $\Delta_1$**Z** + $\Delta_2$**Z** + $\mathscr{O}_P(\sigma^3)$,   (7.23)
```

where $\tilde{\mathbf{Z}}$ is its "true," nonrandom, value (achieved when $\sigma$ = 0), $\Delta_1$**Z** is a linear combination of $\delta_i$'s and $\varepsilon_i$'s, and $\Delta_2$**Z** is a quadratic form of $\delta_i$'s and $\varepsilon_i$'s; all the higher order terms (cubic etc.) are represented by $\mathscr{O}_P(\sigma^3)$. For brevity, we drop the $\mathscr{O}_P(\sigma^3)$ terms in the subsequent formulas.

Also note that $\tilde{\mathbf{M}}\tilde{\mathbf{A}}$ = **0**, as well as $\tilde{\mathbf{X}}\tilde{\mathbf{A}}$ = **0**, because the true points lie on the true circle. This implies

```
$\tilde{\mathbf{A}}^T \Delta_1\mathbf{M}\tilde{\mathbf{A}}$ = $n^{-1} \tilde{\mathbf{A}}^T(\tilde{\mathbf{X}}^T\Delta_1\mathbf{X} + \Delta_1\mathbf{X}^T\tilde{\mathbf{X}})\tilde{\mathbf{A}}$ = **0**,
```

hence $\mathbf{A}^T\mathbf{M}\mathbf{A}$ = $\mathscr{O}_P(\sigma^2)$, and premultiplying (7.22) by $\mathbf{A}^T$ yields $\eta$ = $\mathscr{O}_P(\sigma^2)$.

Next we expand (7.22) to the second order terms, according to the general rule (7.23), and omitting terms $\mathscr{O}_P(\sigma^3)$ gives

```
$(\tilde{\mathbf{M}} + \Delta_1\mathbf{M} + \Delta_2\mathbf{M})(\tilde{\mathbf{A}} + \Delta_1\mathbf{A} + \Delta_2\mathbf{A}) = \eta\tilde{\mathbf{N}}\tilde{\mathbf{A}}$   (7.24)
```
