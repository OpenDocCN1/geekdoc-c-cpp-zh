# ### 7.1 Error analysis of geometric circle fit

First we analyze the geometric circle fit, i.e., the estimator $\hat{\Theta} = (\hat{a}, \hat{b}, \hat{R})$ of the circle parameters (the center $(a, b)$ and the radius $R$) minimizing $\sum d_{i}^{2}$, where $d_{i}$ is the orthogonal (geometric) distance from the data point $(x_{i}, y_{i})$ to the fitted circle.
