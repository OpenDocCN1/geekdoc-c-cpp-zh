# ## 1.1 Classical regression

In a classical regression problem, one deals with a functional relation $y = g(x)$ between two variables, $x$ and $y$. As an archetype example, let $x$ represent time and $y = g(x)$ a certain quantity observed at time $x$ (say, the outside temperature or the stock market index), then one would like to model the evolution of $g$.

One records a number of observations $(x_1, y_1), \dots, (x_n, y_n)$ and tries to approximate them by a relatively simple model function, such as linear $y = a + bx$ or quadratic $y = a + bx + cx^2$ or exponential $y = a e^{bx}$, etc., where $a, b, c, \dots$ are the respective coefficients (or parameters of the model).

Generally, let us denote the model function by $y = g(x; \Theta)$, where $\Theta = (a, b, \dots)$ is the vector of relevant parameters. The goal is to find a particular function $g(x; \hat{\Theta})$ in that class (i.e., choose a particular value $\hat{\Theta}$ of $\Theta$) that approximates (fits) the observed data $(x_1, y_1), \dots, (x_n, y_n)$ best. It is not necessary to achieve the exact relations $y_i = g(x_i; \hat{\Theta})$ for all (or any) $i$, because $y_i$'s are regarded as imprecise (or noisy) observations of the functional values.
