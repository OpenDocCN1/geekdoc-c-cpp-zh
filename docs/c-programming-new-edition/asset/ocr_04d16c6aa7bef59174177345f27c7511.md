# 1.2. PROGRAMMING LANGUAGES: AN OVERVIEW

When two or more persons converse with each other there is one thing common between them. The language. Language is as important as the air you breathe or the food you eat, because it is one thing people can’t do without. Similarly, since the computer is a machine and cannot understand your dialect there must be some way of interacting with it. It needs a medium of instruction and you must see the mode by which you can impart this.

There are numerous languages that can be utilized to program the computer, the most pristine being the machine language. The machine language is an assortment of methodical cryptic instructions that influence the computer’s internals. In short, for the computer to perform a particular operation, a set of statements must be encoded.

The machine language is now seldom being used or you can say this is “extinct” because of a variety of factors, one of them being that it is very taxing to work with and another being that every computer has its own instruction set. Then what replaces it? The language, which is now being used to communicate with the computer, is called high level language.

Why this is preferred to the machine language is that a single statement in the high level is equivalent to a number of instructions in machine level. These types of programs are highly portable, i.e., the program run for one computer can be run on different computers with minimal or no alterations.
