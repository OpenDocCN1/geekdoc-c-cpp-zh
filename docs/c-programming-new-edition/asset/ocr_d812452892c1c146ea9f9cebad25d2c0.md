# 1.4. COMPILING A C PROGRAM

Coding, compiling, and executing a C program consists of different steps that will be discussed below. Before embarking on that endeavor, one must be advised that C is compatible to different operating systems like the DOS and UNIX.

Executing a program in each of these environments consists of different steps. The different steps needed for both the platforms are discussed below.

Steps involved in Turbo C:

+   1. **Step 1:** Opening a C program Once the system is ready and a screen opened (text editor), from the main menu you select file (ALT + F) and choose NEW. Once this is done a new screen is presented. Whenever you enter the turbo C text editor for the first time, by default a new file is opened and you can start coding your program.
+   2. **Step 2:** Compiling a C program Once the program is coded and is ready for execution it is compiled to check for any errors. (ALT + C) The compilation is done by a compiler, which translates the program instruction to machine language. If there are any errors in the program the compilation stops immediately.
+   3. **Step 3:** Error inspection This step comes into picture only if there are any errors in the coding. The errors, which may be in the syntax or semantics of the language, may vary. The line where the error lies and the type of error are displayed. Once the errors are rectified the program is once again compiled. This process continues until the program is error free.
+   4. **Step 4:** Running the program Once the program is declared error free you must run the program (CTRL + F9) to get a display of the result.
+   5. **Step 5:** Display the output The display of a program (ALT + F5) is done only when the program is compiled and executed.
