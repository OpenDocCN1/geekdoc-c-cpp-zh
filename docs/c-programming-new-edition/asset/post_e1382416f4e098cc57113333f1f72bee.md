## 8.7. POINTERS IN STRUCTURES

Such kinds of pointers are termed as structure pointers, though there is a difference while accessing these pointer variables. To access the other variables you used a dot (.) but this is not possible in a pointer but instead of a dot (.) you can use an arrow (->) Since you don’t have a particular key for the arrow you use a hyphen (-) and a greater than (>) symbol and that should suffice. The program below uses the above operator (->) to access the elements and print them. Therefore, things will be pretty comprehensible once you go through the program carefully.

#include<stdio.h>

struct emp

## 8.9. THE UNIONS

A union is yet another data type in C, which allows you to overlay more than one variable in the same memory area. Usually the storage procedure is that every variable is stored in separate memory locations and each one of them has a unique address. Often you discover that the variables that you use in the program are used only in a small part of the source.

Let’s say that you require a string of length 50 bytes, by name files in the first fifty lines of your source program and assume further that you need another string variable of length 100 bytes with the name display only in the later part of the program. You may now realize that it is not necessary to declare two separate strings which will consume 150 bytes.

Since these variables are not needed simultaneously, it will be highly convenient if both the strings share the same space. A Union does that. There is a striking resemblance between the unions and the structures in the way they are declared, the way the members are accessed and so on. The general format of a union declaration is shown below:

```
union tag
{
    member1;
    member2
```

union variable;

As you can see a union declaration starts with the key word union, followed by the tag, this is similar to the structures and can bear any name. In between the open and close braces are present the members of the union The amount of memory required to store a structure is the sum of sizes of all the members. On the other hand in the case of unions the amount of memory required is the same as that required for its largest member. The members of a union are accessed using the dot (.) operator just like the structure members are accessed.

## 8.10. ENUMERATED DATA TYPES

All this while you were using data types such as int, char, etc., that were defined by Ritchie. It’s time you turned a bit creative and implemented your own data types in the program. Impossible one may think But with enum it is possible. The enum gives you the opportunity to invent your own data type and define the variables that it can take. You might ask why would anyone want do such a thing when readymade stuff is available.

The advantage it can have is that it can make the program decent looking and readable and more than one programmer will be able to use it. A note about declaring predefined values. In a manner that int has a range of values from −32768 to +32768 and any value within it is recognized by int in a similar way once you define a data type you can specify the values that it can accept.

Only the values mentioned by you will be accepted when the data type is used. Consider you are creating a data type called blood group and you decide to name it as bloodgrp and you assign it 4 values A, B, AB, & O. Then the declaration can be done in the following way:

```
enum bloodgrp {a, b, ab, o};

 enum bloodgrp person1, person2;
```

If you notice in the above declaration, you will find a great amount of similarity with the declaration of structures. The first part declares the data type and specifies its possible values. These values are called enumerators and the keyword used here is “enum.” The second part declares variables of this data type. Now values can be assigned to these variables in the following manner:

person1 = ab;
person2 = o;

The compiler treats the enumerators as integers internally. Thus, the first value declared will be assigned a value 0 and the second 1 and so on. Therefore, in the above example the value of enum bloodgrp will contain the following values:

a = 0 b = 1 ab = 2 o = 3

Any other value other than a, b, ab, and o will not be accepted and would cause an error. Enumerated data types are usually used to clarify the operation of a program and it makes listing easier.

## 8.11. THE TYPEDEF STATEMENT

This is one more method in C which comes handy in situations where clarification of source code of a C program is required. This can be considered as a nickname for a data type that has a long name. The typedef is useful in the sense that it helps us to assign short readable names to data types. For example, the data type unsigned long int can be renamed as nick. It can be any word of the user’s choice and it is preferable that the rechristened name be mentioned in capitals. The following example shows the way of declaring a typedef statement. The keyword here is typedef which is followed by the original data type name which is followed by the new user defined name in capitals.

```
typedef unsigned long int NICK;
```

Once this is done the new name NICK can be used for declaring the data type of a particular variable Example:

```
NICK variable1, variable2;
```

Thus the usage of typedef provides a short and meaningful way to call a data type.
