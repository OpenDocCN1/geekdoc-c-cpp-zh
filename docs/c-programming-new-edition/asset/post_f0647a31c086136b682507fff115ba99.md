## 4.10. CHARACTER ARRAYS

Here is another eminent feature of the arrays, which amplifies the glory of C to endless heights. Till now you have dealt with integer arrays only but that does not imply that the boundary of an array is restricted to int’s. C is so flexible that it extends its services to characters also. It means that arrays can be formed using even characters. One such array of character is called a string. A string is a collection of characters that are in a particular order.

Take a look at the initialization process in character arrays with the help of an example:

```c
char name[10] = "MyDharm";
```

In the above example name is an array with an element holding capacity of 10 and it holds a string called "MyDharm". The first element is stored in the [0]th position of the array name. That is, the alphabet ‘M’ will be stored in the [0]th position, ‘y’ will be in the [1] position and so on till [9].

A doubt may arise that while the array can accommodate 10 values only 7 have been entered. What happens to the rest? Here, since only 7 values have been accommodated the 8th value will be a null character(\0) which represents the end of the string. This will be placed automatically at the end of the string if any of the array indexes are vacant.

A blank space cannot exist between any two characters while taking input from the user unless accompanied by a specific format specifier. To accommodate the above characteristic feature the initialization should be done dynamically.

### Dynamic Character Initialization

You have already dealt with the method of dynamic initialization early in this session. Just to refresh your memory, the initialization of the variable is done by the user through dynamic initialization, i.e., the initialization is not done in the program and the values tend to be refreshed each time the program is compiled.

This simple example explains the above:

```c
/* program to accept characters from the user in an array*/
#include<stdio.h>
main()
{
char cap[10];
printf("Enter the capital of your country");
scanf("%s",cap);
printf("%s is the capital of your country",cap);
}
```

Start with line 5 since the preceding ones must be quite easy to decipher. Line 5 is where the dynamic initialization of the array takes place. It indicates to the compiler that an array is to be created which can accommodate 10 elements that are of character type. The line 7 accepts the string of characters that is entered by the user based on the display statement in line 6. Line 8 retrieves the stored string from the array and displays it back onto the screen.

Another feature of dynamic initialization of character arrays is that it facilitates the inclusion of blank spaces in between the characters of the string. This can be accomplished by altering the format specifier in the scanf statement in the following way:

```c
scanf("%[^\n]", arrayname);
```

If the above statement is not specified and a blank space is even attempted to be inserted into the string the characters present after the string will be terminated without any mercy. The compiler refuses to acknowledge any characters after the blank.

If at all any criticisms can be barraged on C it will be only in this aspect. Array overflow can be simply put as crossing the boundaries. To explain it in terms of C when an array of a particular size is declared only that many elements can be inserted into an array.

If that size limit is exceeded an error is formed which results in an irregularity in the functioning of the program and C conventionally does not check for array overflow. For example, if you declare an array like sal[10] and you enter 12 elements then an illegal operation is performed which results in an irreparable loss. Not only inserting but also accessing the element whose size is not declared is an illegal operation.

Things don’t stop after an error is performed, there are possibilities that the program might be reduced to shambles.
