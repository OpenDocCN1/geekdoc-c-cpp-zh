Once you adopt the functions you will realize the amount of solace you experience in a true friend like the functions, in the sense that it simplifies your job. It performs the task that you order it to do. It is similar to hiring a specific person to do a specific job.

For example you rely on the electrician to fix up blown fuses or the carpenter to install the kitchen cabinets. In a similar way the functions perform the tasks allotted to them with immaculate perfection. It is as elegant and perfect as the live concert of Beethoven. How do Functions perform? The functions in C are generally used by C whenever a particular set of instructions have to be executed more than once during the course of the program. Say a particular section of the code finds out the average marks of the students of class 8. Later the average for class 10 also has to be found out.

It is not necessary to write the same code once again. It is like inventing the wheel. The code can be written in a function and can be used each time by just altering the values.

How this feat can be pulled off is when a code is written in a function (how this is done is dealt later) that particular function can be called anywhere in the program by mentioning the function name followed by the parentheses, e.g., sub() This is termed calling of a function. Adopting functions proves to be an added asset because functions are easy to code and understand apart from being easier to debug. That is to say finding out the errors is easy due to the simple compact nature of the functions and the errors are more apparent.

Also programs containing functions are easier to maintain because modifications if required are restricted to certain functions. If you think that this was too much listen to this. The functions can be deposited in a library
