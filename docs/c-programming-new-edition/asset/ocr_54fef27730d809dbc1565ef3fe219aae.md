# 4.10. CHARACTER ARRAYS

Here is another eminent feature of the arrays, which amplifies the glory of C to endless heights. Till now you have dealt with integer arrays only but that does not imply that the boundary of an array is restricted to int’s. C is so flexible that it extends its services to characters also. It means that arrays can be formed using even characters. One such array of character is called a string. A string is a collection of characters that are in a particular order.

Take a look at the initialization process in character arrays with the help of an example:

```
char name[10] = “MyDharm”;
```

In the above example name is an array with an element holding capacity of 10 and it holds a string called “MyDharm.” The first element is stored in the [0]th position of the array name. That is, the alphabet ‘M’ will be stored in the [0]th position, ‘y’ will be in the [1] position and so on till [9].

A doubt may arise that while the array can accommodate 10 values only 4 have been entered. What happens to the rest? Here, since only 4 values have been accommodated the 5ᵗʰ value will be a null character(\0) which represents the end of the string. This will be placed automatically at the end of the string if any of the array indexes are vacant. N
