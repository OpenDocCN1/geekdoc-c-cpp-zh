A general algorithm for insertion is as follows:

+   1. **Algorithm Begin:** If the list is empty or the new node comes before the head node then, Insert the new node as the head node, Else If the new node comes after the last node, then, Insert the new node as the end node, Else Insert the new node in the body of the list. End.

+   2. **Deletion Operator:** The deletion operation also consists of 3 phases but the operational procedure is quite different to the insertion.
+   The three types by which the deletion operation can be performed are:

+   - Deleting the first node;
+   - Deleting the last node;
+   - Deleting between two nodes.

# 9.3.1. Deleting the First Node

For the deletion of the first node from the list the second node is assigned the head pointer. Once this is done the 2nd node becomes the first node and the previous node is deleted.

# 9.3.2. Deleting the Last Node

In this the head pointer is traversed to the second last node and the link area is assigned a null. Thus, it becomes the last node of the linked list.

# 9.3.3. Deleting in Between 2 Nodes

For example if the deletion operation has to be performed on the 3rd node then the head pointer is traversed up to 2nd node and the link area is assigned the address of the 4th node and the 4th element automatically gets deleted.
