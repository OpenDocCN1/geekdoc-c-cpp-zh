```
/* program using the goto*/
#include<stdio.h>
main()
{
int i;
printf(“enter the number”);
scanf(“%d”, &i);
if(i==5)
goto rep;
printf(“hello”);
rep:
printf(“bye”);
}
```

In this program once value for I is entered by the user and accepted by the computer the condition which is line number 8 is checked. If the condition, i.e., the value is equal to 5 becomes true the go to statement in line number 9 is executed and the control is passed on to REP which is in line number 11 and the statement s there by are executed, i.e., the word bye will be displayed. If the condition is not satisfied the control ignores the go to statement and executes the statement in line number 10 and 12, i.e., both Hello and Bye are displayed.
