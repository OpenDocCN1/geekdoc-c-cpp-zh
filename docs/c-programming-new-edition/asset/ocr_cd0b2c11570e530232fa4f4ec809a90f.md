For your better comprehension the example of the factorial which was discussed earlier is taken to explain the concept of recursion. You must understand this recursive factorial function thoroughly. In the first run when the number entered through scanf() is 1, just observe what action does rec() take. The value of a (i.e., 1) is copied into x. Since x turns out to be 1 the condition if (x == 1) is satisfied and hence 1 is returned through the return statement. When the number entered through scanf() is 2, the (x == 1) test fails, so you reach the statement.

f= x*rec(x-1);

And here is where you meet recursion. How can you best handle the expression x*rec(x-1). You multiply x by rec(x-1). Since the current value of x is 2, it is same as saying that you must calculate the current (2*rec (1)). You know that the value returned by rec (1) is 1, so the expression reduces to (2 *1), or simply 2.

Thus the statement x * rec(x-1);
