# 2.12. CONSTANTS IN C

One common thing that you might have noticed in your earlier endeavors to understand C is that the procedures being explained help you gain a fairly good idea on the subject. The particular concept which you are about to learn right now just helps you to create short cuts so that programming C will be as simple as tying your shoe laces. Constants are created in C so that they can be used any number of times in the program. For example, if in your computations the symbol pi is to be used, then you have to declare pi as a real constant and assign it a value 3.14285714.

So whenever in the program, computation has to be done with pi instead of using the complete number you just address it as pi (e.g., 24 * pi + 35 * pi) C constants can be divided into two broad categories Primary constants Secondary constants The further delineation of C constants is depicted below:

C Constants Primary Constant Integer Constan Real constant Character Const Secondary Constants Array Pointer Structure Union Enum, etc. At this juncture the discussion is limited to only primary constants viz. Integer, real and character constants. For the establishment of these types of constants certain guidelines have been laid down which have to be put into practice.
