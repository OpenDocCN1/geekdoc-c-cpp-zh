
The `for` statement seduces many programmers who are steady with any of the above control structures. The `for` statement performs three functions which earlier had to be written in three separate statements. They are:

- Initializing
- Condition
- Incrementing

The general format of the `for` statement is:

```text
for(initialize; condition; increment)
    execute this statement;
```

`Initialize`: this expression initializes the particular variable to a set value, e.g., `x = 0;` or `x = 1;`

`Condition`: this expression sets the condition for the statement to be executed, e.g., `x < 9;` or `x <= 9;`

`Increment`: this expression increments the loop each time until the condition is met, e.g., `x++`

Between each of these expressions there must exist a semicolon.

**Example 3.1:**

```c
/* program to display numbers from 0 to 10 */
#include<stdio.h>
void main()
{
    int i;
    for(i=0; i<=10; i++)
    {
        printf("%d", i);
    }
}
```

The above is a simple program to display numbers from 0 to 10. Line number 5 sees the declaration of the variable `i`, which is of type `int`. Line number 6 is the one we have to concentrate on, because the `for` statement starts here. As you can see, the variable `i` is initialized to 0, the condition for `i` is mentioned, and the incrementing of `i` is all done in a single `for` statement. When this statement is written, `i` is initialized to 0, the condition is set that it must be less than or equal to 10, and `i` should be incremented each time the statements below are executed. Line number 8 is the output statement, which is executed each time the condition is satisfied.

### 3.5. THE WHILE LOOP

Now that we have a lucid sketch of what looping is, we can probe into the intricacies of the different looping concepts by ripping them one by one, starting with `while`. Comparing with the `if` statement, we can declare that only if the condition is true the desired statements will be executed; else some other, but in `while`, until a particular condition becomes true the desired statements will be executed. Just recall the afore-mentioned example: until our conditions are met, the strike will continue. This concept will be cloudless with the following example:

```c
#include<stdio.h>
void main()
```

Since you are aware of the first few lines, our area of concern will be the loop structure. The first loop statement, i.e., line number 4, is the initializing statement, i.e., it is setting the variable to a particular value from where the looping has to begin. Count is the variable and its initial value is 0. Line number 5 is where the loop starts. The `while` statement and the condition are also mentioned here. The condition here stated is that until the value of count becomes 10, execute the below statement. Line number 7 is the executable statement, i.e., until the condition is satisfied the statement is to be executed. The last statement, i.e., line number 8, is a new and important statement. Using this, we increment the loop; we make the compiler execute the loop structure one more time. Whenever the compiler encounters this statement, it is reminded that it has to go over the loop once more. This is done until the condition is satisfied.

### 3.6. THE DO WHILE STATEMENTS

In the `do while`, the statements to be executed are coded before the condition is fulfilled. That is to say, the particular loop is executed only if the condition following it is satisfied. In format it can be put as follows:

```text
do
    this statement;
while (this condition is true);
```

There can be multiple statements between the `do` and the `while`. The above example can be dealt with here:

```c
/* program to display numbers from 0 to 10 */
#include<stdio.h>
void main()
{
    int i=0;
    do
    {
        printf("%d", i++);
    }
    while(i<=10);
}
```

Here the only difference, apart from switching the statements, is that the incrementing of the variable is done within the `printf`. Since we are already aware of the first few statements, we will proceed to line number 5, where, like in the earlier example, the initializing is done. Here the variable `i` is initialized to the value of 0. Coming to line number 6, the `do` statement is given here, followed by the statements to be executed. The `do` statement opens with a brace. The executable statement is the one in line number 8, which is the `printf` statement. The important thing to note is that the increment statement is included within the `printf` statement. This is followed by the conditional statement, which is line number 10, where the condition is checked. Here the condition is that the value of `i` should be less than or equal to 10. Until this condition is satisfied, the compiler is required to execute the statement above the condition.

### 3.7. THE BREAK STATEMENTS

The `break` is an effective statement in C programming in the way that it can be used to exit from the loop without fulfilling the condition. That is to say, the `break` signals to the control that once this statement is encountered it should stop the process of looping and hop to the first statement that is present after the loop. In this, the loop is processed at least once, that means that the condition is evaluated and the statements are executed at least once.

```c
#include<stdio.h>
```

```text
statement;
statement;
break;
case expression:
statement;
break;
default:
statement;
}
```

Let's disintegrate the above format and study the different parts. The first statement is the `switch` statement followed by a pair of parentheses in which the word "choice" is given. This accepts the choice that the user makes. The case can be baptized only with either integers or characters, nothing else (not even floating point).

- **Example 3.2:**
  - case 1
  - case 2
  - case 3 or
  - case a
  - case b
  - case c

Based on the choice that the user makes, the executable statement in that particular case is activated. The next thing to be discussed is the "case." Within each of these, the options to be performed are specified. Each case has a particular set of statements to be executed. Whenever a particular case is selected, the statements in the case are executed.

The `break` has already been discussed, but the efficiency of the `break` can be best noticed in the `switch` statement. You have noticed that the `break` statements are used at the end of each case. This is done because it notifies the control that once the case has been executed, the control should not proceed any further.

The `default` takes charge when the option entered by the user does not match with the given case. When no match is found with any of the given cases, the statements in the `default` are executed.

```c
            break;

            printf("O is a vowel");
            break;

    }
}
```

### 3.10. THE GOTO STATEMENT

As the name suggests, the `goto` statement reverses the normal progression of the program execution by reassigning the control to some other part of the program. Alongside the `goto` is written an identifier (any character name), which tells the control that it should park itself wherever the identifier is present later in the program. You should write the same identifier name at the place where the control is desired to jump.

Once the control jumps to the identifier, it executes the statements below the identifier. The identifier is otherwise called the label. It should be followed by a colon (`:`). However useful the `goto` statement may seem, the `goto` is generally not preferred in programming because it can wreck a programmer's life.

The general format is as below:

```text
goto identifier name;
```

The identifier may be placed anywhere in the program after the `goto` statement in the following way:

```text
identifier name:
executable statements;
```

```c
/* program using the goto */
#include<stdio.h>
main()
{
    int i;
    printf("enter the number");
    scanf("%d", &i);
    if(i==5)
        goto rep;
    printf("hello");
    rep:
    printf("bye");
}
```

In this program, once the value for `i` is entered by the user and accepted by the computer, the condition which is line number 8 is checked. If the condition, i.e., the value is equal to 5, becomes true, the `goto` statement in line number 9 is executed and the control is passed on to `rep`, which is in line number 11, and the statements thereby are executed, i.e., the word `bye` will be displayed. If the condition is not satisfied, the control ignores the `goto` statement and executes the statements in line numbers 10 and 12, i.e., both `Hello` and `Bye` are displayed.
