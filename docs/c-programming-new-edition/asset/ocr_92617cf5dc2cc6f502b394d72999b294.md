Now that you are informed about strings and their terminator and how these characters are represented in the memory you can march into some more details about the strings which include the variations in the format specifiers and the usage of multiword strings. Well don’t be intimidated by this technical jargon and take a dislike towards strings but read on about the various aspects of strings.

The variations that you were informed are that there can be a change in the format specifiers, i.e., to say in the first program you were using %c which is perfectly valid when the string was initialized at the declaration point but if the string has to be accepted from the user at the time of display then a problem arises. To counter act the situation ‘C’ advises a change in the format specifier from %C to %S.

Take a look below and things will be crystal clear.

```
#include<stdio.h>
#include<conio.h>
void main()
{
char str[20];
clrscr();
printf("Enter name");
scanf("%%s", str);
printf("The name entered is %%s", str);

}
```

From the above program you can infer that the strings size is declared to 20 and the string is being requested from the user which is accepted using the format specifier %s in scanf(). If you still can’t comprehend the above details take it as a rule that whenever a string is being accepted from the user a %s should be visible in the scanf().

Once the size is declared to 20 the computer sets aside 20 bytes under that array name and a ‘\0’ is placed after the string is entered from the keyboard.
