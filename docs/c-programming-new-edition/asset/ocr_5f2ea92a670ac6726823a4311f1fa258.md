Everything’s fine till now, but who is going to accept the entered characters? The scanf() does. How it does is rather an intriguing fact, which will surely keep you spellbound (if not confused). What happens is that the scanf uses something called the Format Specifiers which aids it in the input proceedings. The format specifiers are special symbols allotted to the different data types. These Format Specifiers are mentioned in the parenthesis of the scanf based on the data type assigned to the variable in the beginning. Also, in the parentheses is mentioned (Figure 2.2).

| Functions | Description |
|-----------|-------------|
| scanf() | This function is used to read one or multiple inputs from the user at the console. |
| sscanf() | This function is used to read the characters from a string and stores them in variables. |
| printf() | This function is used to display one or multiple values in the output to the user at the console. |
| sprintf() | This function is used to read the values stored in different variables and store these values in a character array. |

Variable name preceded by an “&” symbol. It looks something like this:

```
printf("enter the customer number:");
```

```
scanf("%d", &cno);
```

Here the %d is the format specifier for an integer.

All format specifiers must be enclosed within quotations. & is the mandatory symbol and cno is the variable name which holds an integer. As soon as the user inserts the values the scanf identifies to which data type the inserted character belongs and stores it in the memory in that location (i.e., in int or char or float).
