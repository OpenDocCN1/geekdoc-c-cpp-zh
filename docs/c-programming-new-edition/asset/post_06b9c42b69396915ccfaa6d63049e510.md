### 9.2. LINKED LISTS

To explain the concepts of linked lists an amalgamated reference of the arrays and pointers has to be made. The reason why linked lists are so important and are given a priority is due to the fact that they result in both the effective and efficient use of computer storage and also computer time. The concept that is going to be dealt with here is similar to the arrays except that in arrays only application side was discussed in detail and internal representation was dealt to a very minimal extent. Here you will be provided with extensive amount of information about internal happenings of the arrays using linked lists as the medium.

A linked list can be compared with a train. As in a train the different compartments are hooked to each other in the similar way a linked list has a series of elements which are connected to each other. Each element in a list is called a node and it has an address by which it is recognized. The linked lists are of three different types depending on the arrangement of the nodes.

- Singly linked list
- Doubly linked list
- Circular linked list

The singly and doubly linked lists can be clubbed into a group called the linear linked lists in which the elements are arranged in a serial and contiguous fashion. The intricacies of these 2 types of linked lists will be dealt with as the session progresses.

### 9.3. SINGLY LINKED LISTS

Prior to understanding the specifics of singly linked lists, it is crucial to have a solid understanding of the node, which is a list’s fundamental building block.

The fundamental part of a list is the node, as was previously stated. There are two elements to it; the first is referred to as the info and the second as the connection Node.Info Link. The info part of the node contains information about the node that is what number is stored in the node or which character is stored in the node.

The link part of the node contains the address of the next node. As informed in the earlier sessions that whenever a value is stored in the memory it is stored at a particular address. As a result, the address of the second node in a singly linked list with four nodes or elements is stored in the link area of the first node, the address of the third node in the link area of the second, and so on (Figure 9.1).

You may wonder what the link area of the 4ᵗʰ node would contain. The 4ᵗʰ link area contains a null character, which depicts the end of the link. (If you remember a string was also terminated in the same fashion.)

The elements in the linked lists can be traversed using a pointer called head pointer which points to the first element of the list. This head pointer can be used to traverse the elements of the list from left to right and traversal of elements is possible only in this direction.

Random access is illegal, i.e., you cannot access the 2nd or the 3rd element of the list directly. You are aware of the fact that the one that holds the address of another element is called a pointer. Thus, the link can also be called the pointer because it points to the next element in the list.

Now that you have a clear picture about the singly linked lists you will see how the inserting and deleting operations are performed on this linked list.

**Insertions**

The insertion operation in the singly linked list can be performed at three different positions in the singly linked list.

- At the beginning of the list.
- At the end of the list.
- In between two nodes.

If the insertion of a new node has to be made at the beginning of the list the link area of the new node is assigned the address of the first node. The head pointer is then made to point to the new first element. Since it contains the address of the old first element a link is created between the new node and the rest of the list.

A 2010 2008 A 2008 B 2012 A 2014 2010 2012 NEW

An insertion operation can be performed on the middle of the list in between two nodes. For example if a new node has to be inserted in between the 2nd and 3rd nodes in a list then as a first step the head pointer is traversed till the 2nd node. The address of the new node to be inserted is assigned to the link area of the 2nd node and the link area of the new node is assigned the address of the 3rd node. Thus, a link is broken between the 2nd and 3rd node and new node is inserted.

For a node to be inserted at the end of the list the head pointer is traversed till the last node and the link area which contains null is reassigned to hold the address of the new node and the new node is assigned the null character in its link area. The process of insertion precedes a search for the place of insertion. The search involves locating a node after which the new item is to be inserted.

A general algorithm for insertion is as follows:

- 1. **Algorithm Begin:** If the list is empty or the new node comes before the head node then, Insert the new node as the head node, Else If the new node comes after the last node, then, Insert the new node as the end node, Else Insert the new node in the body of the list. End.

- 2. **Deletion Operator:** The deletion operation also consists of 3 phases but the operational procedure is quite different to the insertion.

  The three types by which the deletion operation can be performed are:

  - Deleting the first node;
  - Deleting the last node;
  - Deleting between two nodes.

### 9.3.1. Deleting the First Node

For the deletion of the first node from the list the second node is assigned the head pointer. Once this is done the 2nd node becomes the first node and the previous node is deleted.

### 9.3.2. Deleting the Last Node

In this the head pointer is traversed to the second last node and the link area is assigned a null. Thus, it becomes the last node of the linked list.

### 9.3.3. Deleting in Between 2 Nodes

For example if the deletion operation has to be performed on the 3rd node then the head pointer is traversed up to 2nd node and the link area is assigned the address of the 4th node and the 4th element automatically gets deleted.
