# Introduction

Major aspect of the data processing function is the logical control of programming elements necessary to ensure that data is read and processed properly and used to produce the required output. In fact, the logical control of elements within a program is the single most important aspect of programming. Various descriptive charts are used by computer professionals to indicate the logic that a program is to incorporate. We consider the following three techniques, which are the most commonly used in the EDP field to indicate program logic.

Tools used for specifying program logic:

+   - Program flowcharts;
+   - Pseudo code;
+   - HIPO charts.

1. **Program Flow Chart:** It is a diagram, or pictorial representation, of the logical flow of data in a particular program. The flowchart is drawn before the program is written to ensure that the instructions will be logically integrated. The concept is not unlike that used by architects, who prepare pictorial representations, called blueprints, prior to the actual design of a building. Blueprints verify and integrate elements of a building before construction. Similarly, flowcharts verify and integrate elements of a program prior to coding.
