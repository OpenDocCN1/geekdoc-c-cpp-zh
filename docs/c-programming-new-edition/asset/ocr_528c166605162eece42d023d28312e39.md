# 4.4. ARRAY DECLARATION

The term declaration must be quite familiar to you by now. As in your earlier endeavors at declaration, here you declare an array, i.e., the compiler should know what kind of array is to be created and of what type and size you visualize it to be. Also, when this declaration is made, it specifies to the memory that the declared amount of space has to be kept as reserve to accommodate elements of this array. The general format is as follows.

int sal [15]. The int as you know specifies the data type to the compiler and the “sal” is the variable name given to the array. Till now everything must be quite familiar. The [15] is the one to be savored. The no. 15 indicates that 16 values of the type int have to be accommodated and all of them are under the name sal. The square bracket [] indicates that the computer has encountered an array declaration. The number of square brackets increase as the dimensions of the array is increase. That is to say a two dimensional array will have two pairs of square brackets, a three-dimensional three pairs of square brackets and so on.

# 4.5. ARRAY INITIALIZATION

The initial step of declaring an array is done. You have given it a variable name and also declared its size but upto this stage the array is empty. It is like a school bag without any books in it. Similarly, declaration of the variable is done but some values have to be passed into it. You must be aware of initializing an ordinary variable but how do you initialize an array in which more than one value has to be initialized into one array variable. Entering data into an array: Now that you have declared an array by giving it a specific name and size you can try and explore the individualities of each element in the array, that is to say how each element is addressed in an array.

Array element indexing always starts with 0. Number[0] 1st element Number[1] 2nd element Number[2] 3rd element Number[3] 4th element This means that [0] will hold the first value, [1] the second, [2] the third & so on. If you want to access the fourth element of the array “sal” you have to write sal [3]. You can replace the number by using a subscript say i, a, x, etc. So, the array sal wil be written as: Sal [i] The variable i is not particular to any element but can be referred to various elements in the array one at a time.
