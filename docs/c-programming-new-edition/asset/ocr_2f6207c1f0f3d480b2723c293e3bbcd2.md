# 2.4.1. Rules for Type Declaration

All data types are keywords and they should always be written in lower case and they cannot be used as a variable name or for any other purpose (revert to the rules).

The data types should be written as depicted above and not its full form, i.e., int cannot be written as integer.

All declarations should be performed before the first executable statement.

All declarations must end with a semicolon.

# 2.5. OUTPUT FUNCTION

The formatted output function used in C is the printf (). The purpose of this function is to display the output desired by the user. To do so the desired characters are written within the inverted quotations.

For example:

```
printf(“Welcome in Dharm’s World /n”);
```

The above function when inserted in a C program displays the message that is within the quotations. The message within the quotations is displayed as it is and it does not affect the program even a wee bit.

The “/n” makes the cursor skip to the next line. Another function of the print statement is that it can be used to ask the user to enter data for the program, which will be used for computation in the program. Say two numbers have to be added and the two values are to be requested from the user using the keyboard. Then the request for the two values is made in the following fashion.

```
E.g., printf(“ enter the value for x: “);
```

```
printf(“ enter the value for y: “);
```

The entered values are then accepted by the computer in a manner that will be discussed later during the session.
