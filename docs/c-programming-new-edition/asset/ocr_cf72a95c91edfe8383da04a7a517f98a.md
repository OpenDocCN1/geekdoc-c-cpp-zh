# 9.4. DOUBLY LINKED LISTS

The singly linked list proved to be advantageous but there were more disadvantages than advantages. Using the singly linked list any element could not be accessed directly. If the last element had to be accessed the whole list had to be traversed which was time consuming and cumbersome.

One more flaw was that the traversing of elements was not possible from a right to left direction. These shortcomings can be overcome by using the doubly linked list. This is just a slight modification of the singly linked list. The mode of the doubly linked list has an extra link area on its left side. Thus, it would look like this. Link info Link You have already been apprised that the right link area contains the address of the next element. In a similar way the left link area contains the address of the predecessor node.

A list containing this type of node is called a doubly linked list or a two way chain. In a way similar to the singly linked list even the doubly linked list has a head pointer for traversal from left to right. But in addition, the doubly linked list also has an extra pointer which dons the role of the head pointer and it is used for traversing the list from right to left. The left head pointer points at the first element of the list and right the last element.
