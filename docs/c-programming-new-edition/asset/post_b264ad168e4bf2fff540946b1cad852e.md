Constants are created in C so that they can be used any number of times in the program. For example, If in your computations the symbol pi is to be used, then you have to declare pi as a real constant and assign it a value 3.14285714. So, whenever in the program, computation has to be done with pi instead of using the complete number you just address it as pi (e.g., 24 * pi + 35 * pi) C constants can be divided into two broad categories Primary constants Secondary constants.
