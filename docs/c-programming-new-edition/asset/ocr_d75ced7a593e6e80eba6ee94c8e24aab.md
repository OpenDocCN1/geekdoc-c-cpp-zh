Every node in a binary tree can be subdivided into four parts:

+   - The info;
+   - Left pointer;
+   - Right pointer;
+   - Info Left Right.

The info area as you are aware contains information about the value to be stored in the node and the left pointer points to the left child node and the right pointer points to the right child node. If a node is devoid of children then a null is present in the left and right pointers.

# 9.8.1. Preorder

The traversal of a binary tree starts with visiting the root node and then traversing the left subtree of its root node in preorder followed by the right subtree in preorder. The preorder traversal is a depth first exploration. Inorder In this type of traversal the left subtree of the root node is traversed in inorder then visit the root node and traverse the right subtree Postorder For traversing a binary tree in post order method the left subtree of the root node is traversed followed by the right subtree of the root node.
