## 7.7. ARRAY OF POINTERS

The array of pointers is a replacement for the two dimensional array of characters. The reason being that in the two dimensional the array length is fixed once it is declared and if a string is much smaller than what is specified the rest of the space is empty and wasted. Using the array of pointers can erase these side effects.

Thus one reason to store strings in an array of pointers is to make more efficient use of the available memory. Another reason is that using the pointers can also help you to manipulate the strings just like the library functions. ## 7.8. DO’S AND DON’TS

- **Do’s:**
  - The null character should be enclosed within a pair of single quotes. (`\0`)
  - The standard library functions should be terminated with a semicolon.
    E.g., strcpy();
  - The %s should be used when the string is to be accepted from the user.
  - The clrscr() should be declared after the variable declarations are done.
  
- **Don’ts:**
  - The length of the string should not exceed the dimension of the character array.
  - The scanf() is not capable of receiving multiword strings unless altered with gets()
  - And the format specifier “%[^\n]”
  - In strcpy() the destination has to be a variable because overwriting of an already existing string is not possible.
