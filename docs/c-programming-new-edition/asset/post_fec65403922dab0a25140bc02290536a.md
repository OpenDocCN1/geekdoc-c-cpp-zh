## 9.10.1. Radix Sort

The radix sort can be declared as the most efficient sorting methods available. It is generally applicable for 2 digit numbers but the concept holds good even for 3 digit numbers though the examples dealt with here are only using two digit numbers.

This version of the sorting technique is pretty simple and involves in dividing every element into two parts. The right digit or the digit in the tens place is called most significant digit (MSD) and digit in the units place is called least significant digit (LSD). Example: in the number 40 the LSD and the MSD are demarcated as follows:

MSD: 4 LSD: 0

The whole sorting process is carried out on the basis of sorting the LSD and MSD. The whole radix sort process is two step procedure where the sorting in the first step is based on lsd and sorting in second is based on msd.

Consider the list of elements:

40, 45, 61, 72, 67, 89, 98, 50, 57

To sort the element the radix sort involves a group of pockets which are numbered from 0 to 9.

These pockets can accept numbers whose lsd is equal to the respective pocket numbers.

For example 0th pocket can accommodate only elements that end with 0. Similarly, pocket no 5 accommodates elements whose lsd is 5 and each pocket can accommodate only one element per pass Step I In the first step the list is traversed and elements are placed in the pockets based on their lsd.

Once an element is placed in its respective pocket of another element with the same lsd is encountered it is ignored until the rest of the list is scanned. This scanning through a list once is called a pass.

For example in the above list you have two elements 40 and 50 having lsd as 0. In the first pass only 40 is placed in the 0th pocket since it is encountered first. The 50 is placed in the 0th pocket in the second pass.

Hence after the completion of the first step the elements can be represented as follows: P

Now based on the arrangement a new list is prepared as follows:

40, 50, 61, 72, 45, 67, 57

You will notice that while a list is prepared the element in the 2nd pass slides beside the element in the 1st pass.

This list of elements is now used as fuel for the second step.

Step II is similar to Step I with a variation that these elements are entered into their respective pockets based on the msd. 0 1 2 3 4 40 45 5 50 57 6 61 67 7 72 8 9. Hence the new ordered list can be represented as follows:

40, 45, 50, 57, 61, 67, 72.

After having dealt with the various sorting techniques it is difficult to judge which technique is the most superior one. Though some are easy to use it may not really be effective.

Certain properties of a given key set play an important role in the determination of which sorting technique should be used. The properties are the number, size, distribution, and order of keys. Often decide which method will be apt in a situation.

## 9.11. SEARCHING TECHNIQUES

The techniques used by you till now were helpful in arranging elements in different ways and means. Now that the list is sorted and arranged it is retrieval time. The searching techniques that you will now experience allows you to dig out an element of your choice from the list. The element of your choice is compared with the elements of the list and if a perfect match is found then the element is retrieved and a message is displayed.

The searching process can be done in different ways but the most popular will be taken up and dissected. C allows two major and uncomplicated means of searching elements.

- 1. **Linear Search Method:** The linear method is a fairly straightforward method of retrieving elements. This is often considered the simplest technique for searching an unordered list of elements.
  
  In the following version the list is scanned element by element for the element to be retrieved. When an appropriate match is found a message is displayed.

- 2. **Binary Search Method:** This is another relatively simple method of accessing a list of elements. An important point to be kept in mind that the binary search is possible only if the list of elements is ordered and in an ascending manner. This can be achieved by applying any of the sorting technique available in the early part of the session.

Once the list is aligned the binary search operation can proceed. this method the list is assigned a lower bound and an upper bound to the 1st and the last element. After this is done the midpoint of the list is found by finding the average of the lb and the ub. For example, if the list contains 7 elements then the midpoint will be 4 Midpoint=lb+ub/2. Consider the list of elements below and say the element to be retrieved is 91. 40, 55, 61, 71, 81, 91, 100. Once the midpoint is found the element to be searched is compared with the element present in the position of the midpoint.

In this case the element present at the midpoint is 71. The element 71 is compared with the sought after element which is 91 but since the elements differ in configuration the element is checked if it is greater than or less than the midpoint.

If the element is less than the midpoint the rest of the searching takes place with the elements on the left side of the midpoint since all those elements

are less than the midpoint. If the number is larger than the midpoint then the comparison takes place with the elements on the right of the midpoint.

In your case since the element is larger than the midpoint the latter situation will be of concern. After it is decided that the element is larger the element after the midpoint is assigned the position of the lower bound but the upper bound remains the same. In the contrasting case if the element is less than the element before the mid is made as the upper bound, but that is not the case here.

Now that you have a new lower bound in the above case the midpoint of the new lb and the ub are found out. Thus, in this case it would be 6 (5+7/2). The new midpoint is now compared with the element to be searched. Since a perfect match is found a message is displayed that the search is complete and the desired element is found.

If still a match is not found the above method is continued until a bulls eye is hit.
