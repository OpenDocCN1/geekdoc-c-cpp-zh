# 9.6. STACKS

In the above procedures you experienced a minimal amount of difficulty in creating a list and performing insertions and deletions of the list. Here is a linear data structure, which cannot be termed ineffectual, but is definitely not very popular when a consensus is required and yet remains to be an important data structure concept.

The stack as it is termed is a list of elements placed on top of each other. This can be compared to a pile of plates arranged one above the other. Thus, after the arrangement of the plates you will notice that the first plate finds the bottom most position and last plate to be placed, will acquire the first position. Thus, with reference to the elements when the second element is added to the list it causes the first one to be pushed down the stack and when the third is added the 2nd and 1st are pushed down and so on.
