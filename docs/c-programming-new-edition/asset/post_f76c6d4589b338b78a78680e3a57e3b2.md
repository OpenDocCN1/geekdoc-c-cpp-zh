Also, when this declaration is made, it specifies to the memory that the declared amount of space has to be kept as reserve to accommodate elements of this array. The general format is as follows.

int sal [15]. The int as you know specifies the data type to the compiler and the “sal” is the variable name given to the array. Till now everything must be quite familiar. ## 4.5. ARRAY INITIALIZATION

The initial step of declaring an array is done. You have given it a variable name and also declared its size but upto this stage the array is empty. It is like a school bag without any books in it. Similarly, declaration of the variable is done but some values have to be passed into it. You must be aware of initializing an ordinary variable but how do you initialize an array in which more than one value has to be initialized into one array variable. Entering data into an array: Now that you have declared an array by giving it a specific name and size you can try and explore the individualities of each element in the array, that is to say how each element is addressed in an array.

Array element indexing always starts with 0. Number[0] 1st element Number[1] 2nd element Number[2] 3rd element Number[3] 4th element This means that [0] will hold the first value, [1] the second, [2] the third & so on. If you want to access the fourth element of the array “sal” you have to write sal [3]. You can replace the number by using a subscript say i, a, x, etc. So, the array sal wil be written as: Sal [i] The variable i is not particular to any element but can be referred to various elements in the array one at a time.

```
for (i=0; i<=14;i++)
{
printf("enter sal");
```

```
scanf("%d, &sal[i]);
}
```

To enter the data you are using a for loop by which the number of elements entered by the user are placed in an array. When the user enters the 1st value for sal it is stored in the [0] position and then the position of the element is incremented using i++ and if any next element is entered it is placed in that position, i.e. [1]. The same process takes place till the 15th element is entered after which the condition is dissatisfied & the loop is broken. The above process of intializing is called the dynamic initialization, but it is not the only way by which the process of initializing can be undertaken.

To achieve that feat C describes two distinct methods:

- i. Static initialization; and
- ii. Dynamic initialization.

## 4.6. ACCESSING DATA FROM ARRAY

You have stored the data in an array by first initializing and then reading into an array. How do you get them out so that you can use them. Once again the for loop comes in the picture and unloads all element rather than loading as in the in the first case. You have input 15 elements in an array named sal. Suppose you want to find the sum of all the elements in the array. Follow the steps given below.

```
sum =0;
/* temporary variable */
for(i=0;i<=14;i++)
sum=sum+sal[i];
/* value of sal[i]added to sum*/ printf("sum=%f",sum);
```

The for unloads each element starting from [0]. The first time the element in the [0] position takes the place of [i] and when it is added with 0 its value is entered into sum. Next the element in the [1]st. position replaces [0]th. position and it is added to the sum which already has a computed value and a new sum is formed. This takes place until the element in the position 14 is entered into i and finally the sum is printed which has all the added values.

## 4.8. ARRAY INSIDE THE MEMORY

You must be well versed with the details of declaring, initializing, and retrieving an array. But what happens in the memory? Are the elements stored in a serial order or are they stored randomly? To answer the above queries consider on example:

```
int sal[5];
```

What are the activities that take place inside the memory when such a declaration is made? By now you must be aware of what the above statement does. The statement indicates that an array variable is to be created which is of an integer data type and the array can hold 5 elements. In the memory 10 bytes will be reserved because each integer will be 2 bytes long. Until the array is initialized with some numbers, this array will host some unrelated numbers. Once the array is initialized the elements are stored in a continuous manner.

## 4.9. MULTIDIMENSIONAL ARRAYS

Till now the main area of concentration has been the one-dimensional arrays. Now you enter the area of ambiguity. This statement can be argued because the multidimensional arrays are defined in a pattern that resembles the one-dimensional array. The only disparity being that the multi dimensional array requires separate square brackets for each subscript. That is to say if the one dimensional array had a pair of square brackets, a two dimensional array will have two pairs of square brackets, three dimensional array three pairs of square brackets, and so on.

Two Dimensional Array A two dimensional array can be visualized as an array below an array. As earlier mentioned, a two dimensional array will have two pairs of square brackets. The description can be explained as below.

```
Data_type array_name [expression1] [expression2];
```

The two dimensional array is often referred to as a matrix. The expression one and two are the subscripts that the two-dimensional array will hold. Therefore, in the above expression one will specify the row and expression, two will specify the column and they indicate the number of array elements associated with each subscript.

Therefore if a declaration states:

```
int arr[4][2]
```

It means that a two dimensional array with the name arr is of integer type and has four rows and two columns. Its representation would be like this: Column No. 0 Column No. 1 Row no. 0 1000 10 Row no. 1 2000 20 Row no. 2 3000 30 Row no. 3 4000 40. Thus the element in arr[0][0] will be 1000 and the element in arr [3][2] will be 30. The rest of the numbers can be figured by having a look at the above table. In the memory the elements are placed in a sequential pattern such that the element in [0][0] will be first followed by the element in [0][1] followed by [1][0] and so on. Here too, each integer element will occupy two bytes.

Initializing a 2 dimensional Array Initializing a two dim array is as equivalent to initializing a one-dimensional array.

```
int sal[4][2]={{1000,10}, {2000,20}, {3000,30} {4000,40}}
```
