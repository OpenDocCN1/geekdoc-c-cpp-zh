# 5.6. PASSING ARGUMENTS TO A FUNCTION

You have been informed about the arguments and about the passing of arguments earlier, but if you feel that the concepts were unclear then this section of the session will set things right. Here you will not only be clear about what arguments are but also you will be getting acquainted with the types of functions based on the arguments passed.

The concepts of passing arguments in a function just make it more compatible to use, the reason being that the arguments acts as a medium of communication between the caller and the called function. You might have been ignorant about the fact that you have used arguments when you dealt with the plethora of printf and scanf functions. The matter, which you specified within the parentheses, is considered as arguments. The types of function based on the arguments passed to them is mentioned below:

+   - Functions which don’t take parameters and do not return any value.
+   - Functions which accepts parameters but do not return any value.
+   - Functions which take parameter and returns values.

Each of the above types will be taken up individually so that you will get more than an over view of the types of functions that are available in the C arsenal. Functions which do not take parameters and do not return any value. For functions of this type neither the caller function nor the called function take any arguments.

What happens here is that when a function is called the control jumps directly to the called function and executes the statements that are specified within the called function. After the statements in the called function are executed, the control returns to the main program.

Example:

```
main()
{
    mus();
}

mus()
{
    printf("My Honey");
}
```
