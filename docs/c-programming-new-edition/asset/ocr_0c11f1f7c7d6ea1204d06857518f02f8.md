You will now try to pass on an array into a function or to be specific the array elements have to the passed into a function so that they can be used in that function. To pass an array to a function, the first thing to be done is to declare the array before it can be used in the function.

This can be done as you know at the declaration depot after the main function. To pass an array to a function the array name should be without the square bracket or subscript in the actual parameter, i.e., in the caller function. In the corresponding called function the formal argument must have an array name with the square bracket which is empty. The rough example given below should take care of things.
