## 9.11.2. Basic Structure of a C Program

```c
// Preprocessor Directives
#include <stdio.h> // Include necessary libraries
// Main Function
int main()
{
// Declarations (Variable and Function Declarations)
// Statements (Executable code)
return 0; // Return statement (Exit status)
}
```

- **Preprocessor Directives:** These lines begin with # and are used to include libraries and perform other pre-processing tasks.
- **main():** This is the main function where program execution begins.
- **Declarations:** This is where you declare variables and functions that will be used in your program.
- **Statements:** These are the executable statements that perform the actual work of your program.
- **return 0;:** This line is used to exit the program with a status code of 0, indicating successful execution.

## 9.11.3. Format Specifiers

Format specifiers are used in C to specify the data type of the variables you want to print or read using functions like printf and scanf. Common format specifiers include:

- `%d`: Integer
- `%f`: Float or double
- `%c`: Character
- `%s`: String

- `#include <stdio.h>`: This line includes the standard input/output library, which provides functions like `printf` for printing to the console.
- `int main()`: This is the starting point of the program. Every C program must have a main function, and execution begins here. `int` is the return type, which indicates that the main function will return an integer value when it completes.
- `{}`: These curly braces enclose the body of the main function, where the program’s statements are placed.
- `printf("Hello, World!\n");`: This line uses the `printf` function to print the text “Hello, World!” to the console. `\n` represents a newline character, which moves the cursor to the next line.
- `return 0;`: This line returns an integer value of 0 to indicate that the program has executed without any errors. In C, a return value of 0 conventionally signifies success.

To compile and run this program, you’ll need a C compiler installed on your system, such as GCC. Save the code to a file with a .c extension (e.g., hello.c), and then use the following commands to compile and run it:

- **Output:**
  
  `gcc hello.c -o hello` # Compile the program
  
  `./hello` # Run the compiled program

- **Practical 5:** Write a c program to calculate total area of Cylinder

and volume of a cylinder.

- Solution:

```c
#include <stdio.h>
#include <math.h>
int main()
{
    double radius, height;
    double pi = 3.14159265359; // Approximate value of Pi
    // Input the radius and height of the cylinder
    printf("Enter the radius of the cylinder: ");
    scanf("%lf", &radius);
    printf("Enter the height of the cylinder: ");
    scanf("%lf", &height);
    // Calculate the total surface area of the cylinder
    double surface_area = 2 * pi * radius * (radius + height);
    // Calculate the volume of the cylinder
    double volume = pi * pow(radius, 2) * height;
    // Display the results
    printf("Total surface area of the cylinder: %.2f square units\n", surface_area);
    printf("Volume of the cylinder: %.2f cubic units\n", volume);
    return 0;
}
```
