A simple program using structure:

```
/* program that accepts values and displays it back */ #include<stdio.h>
void main()
{
struct emp
{
char ename[15];
float esal;
int eno;
};
struct emp e1,e2,e3;
printf("Enter name,salaries and identity number of employees\n");
scanf(" %s %f %d",&e1.ename,&e1.esal,&e1.eno);
scanf(" %s %f %d",&e2.ename,&e2.esal,&e2.eno);
scanf(" %s%f %d",&e3.ename,&e3.esal,&e3.eno); printf("You have entered the following data:");
printf(" %s %f %d",e1.ename,e1.esal,e1.eno);
printf(" %s %f %d",e2.ename,e2.esal,e2.eno);
printf(" %s %f %d",e3.ename,e3.esal,e3.eno);
}
```

In the above program you can see that the structure members are declared inside the structure and the structure variables, i.e., e1, e2, e3 are declared outside the structure using the key word struct and the structure name The values for the structure members are requested from the user and they are accepted using the scanf.

The values are printed back by using the structure variable and the structure member with a dot(.) in between them.
