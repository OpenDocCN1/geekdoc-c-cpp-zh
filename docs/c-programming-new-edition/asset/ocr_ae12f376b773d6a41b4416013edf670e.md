# 3.1. WHY CONTROL STATEMENTS?

Well that’s an interesting query. One may ask that when C is such an omnipotent language with so many features and disciplines where does the need arise for incorporating separate control statements. Well that’s a tough one, but as mentioned in the earlier session with so many different functions being carried out by C it needs some kind of a managerial system which instructs the computer what function has to be performed at which time. The control statements act as a manager. You will be amazed at the amount of functions the different control statements handle.

For example in a program you may have a statement in which a multiplication operation is to be performed and in the next an addition operation and after the next line there may be a statement which may want itself to be repeated 8 times and another statement may like itself to be skipped and attended to at a later stage.

All these conditions are managed by the control statements. You have had a glimpse of the different types of control statements in the previous session and now is the time to get into the thick of the things. You have seen the broad classification of the control statements in the earlier session, here is the various subdivisions that they possess represented diagrammatically.

Control Statement  Sequence  Decision  Loop  Case  if  ifelse  while  dowhile  switch  goto  for
