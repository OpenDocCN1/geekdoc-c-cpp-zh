# ## 5.8. NESTED FUNCTIONS

The word nested must be familiar to you because you have been earlier acclimatized with the nested ifelse statement and also the nested loops. The nested functions are no different to the earlier ones, the change being that here the functions are being nested or one function is called from within another function. Nesting of functions in simpler terms can be thought of as calling a function from within a function. The parent function calls the child sub-functions each of them after computing a result returns their values to the parent function if required. You cannot define a function within another function, you can call a function from another function.

+   - **Example 5.1:**

```
```c
#include<stdio.h>
main()
{
nest();
call();
}
nest()
{
call();
}
call()
{
printf("\\n when you are at crossroads, make a fifth one of your own");
}
```
```

In the above program the functions are called in lines 4 and 5. When the control encounters the function nest it jumps to the function definition to line number 7 and within that function it encounters the nested function call and further jumps to the function definition of the call and executes the statements in that function.
