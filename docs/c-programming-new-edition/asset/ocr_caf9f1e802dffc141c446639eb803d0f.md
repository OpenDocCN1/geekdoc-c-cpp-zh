+   - The tag in structures and unions is not mandatory.
+   - While accessing members there must be a dot(.) in between the structure variable and the structure member.
+   - Structure type declaration appears at the top of the source code file before the variables or the functions are declared.

+   - **Don’ts:**
+     - While accessing members in structures using pointers don’t use the dot. Instead it is replaced with an arrow.
+     - A structure type declaration does not tell the compiler to reserve any space in the memory, it just defines the form of the structure.
