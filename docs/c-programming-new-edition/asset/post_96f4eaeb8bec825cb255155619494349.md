## 1.7. A SIMPLE C PROGRAM

Before embarking on writing a C program there are certain rules of thumb that have to be followed religiously under all situations and circumstances.

Defining any one of the following laws will result in a non-executable program.

### Rules To Be Followed

- The program starts with `#include <stdio.h>`. More on this is discussed later.
- The code for the program is written within a function called `main()`. Just remember that every program must begin with a `main()`.
- The entire code is written within a pair of curly braces `{}`.
- The opening braces immediately follow the `main()`. The closing braces are placed at the end of the program depicting that the program has concluded.
- C has a set of 32 keywords that cannot be used for any other purpose, even as a variable name.
- C is case sensitive, i.e., `printf()` is different from `print()` but generally C programs are written in lower case. All keywords have to be lowercased.
- All statements in a C program are terminated with a semicolon.

These are the basic ideologies that have to be maintained while solving a C program.

### 7.1. Comment-Statement

The comment statement helps you to identify the purpose of the program. A comment statement can be used anywhere in the program whenever the need arises for a particular statement to be explained or if some information about the statement has to be referenced later.

A comment statement opens with a slash followed by an asterisk (`/*`) and ends with an asterisk followed by a slash (`*/`). The compiler ignores the comments and these types of comments have no effect on the program.

The `#include<stdio.h>` statement is a stereotype statement that has to be present in every C program but it is not mandatory. Programs can be executed without this statement but it is considered good programming practice to affix this statement.

The `main()` Function: The main function is the primal function that is mandatory for every C program. The whole C program is written within this main function. More on functions is dealt with later in the book.

A pair of parentheses always follow the keyword `main`. The braces open and close the code of a program. In between the open and close braces lie the entire compound statements. Once the closing braces are applied it denotes the end of a C program.

Output Function: The formatted output function used in C is the `printf()`. The purpose of this function is to display the output desired by the user. To do so, the desired characters are written within the inverted quotations.

E.g., `printf("Welcome in Dr. Dharm’s World \n");` the above function when inserted in a C program displays the message that is within the quotations. The message within the quotations is displayed as it is and it does not affect the program even a wee bit. The `\n` makes the cursor skip to the next line. Another function of the printf statement is that it can be used to ask the user to enter data for the program which will be used for computation in the program.

`printf("enter the value for y:");`

The entered values are then accepted by the computer in a manner that will be discussed later during the session.

The Statement Terminator: The semicolon facilitates the termination of statements in C programming. This gives an indication to the computer that the statement has ended and anything after this should not be taken into consideration. The semicolon must be evident at the end of each compound statement.

## 1.11. DO’S AND DON’TS

To reap the benefits of programming in C one has to play the game with certain regulations barring which a red card can be slapped. That is to say, one has to play the game safely to ensure better results. Therefore, to play with C one has to keep in mind the boundaries that are set. Listed below are a few do’s and don’ts of the game which will prove helpful while programming with C.

- **Do’s:**
  - The main function is the first function and is mandatory for all the programs.
  - The body of a C program must be enclosed within a pair of braces.
  - All statements within the main must be terminated with a semicolon.
- **Don’ts:**
  - **Forget to Initialize Variables:** In C, variables are not automatically initialized, so failing to initialize a variable before using it can lead to unpredictable behavior and bugs in your code. Always initialize your variables before using them to avoid unexpected results.
  - **Don’t Ignore Compiler Warnings:** C compilers often provide warnings about potential issues in your code. Ignoring these warnings can lead to subtle bugs or even program crashes. Always pay attention to compiler warnings and address them to write robust and error-free code.
