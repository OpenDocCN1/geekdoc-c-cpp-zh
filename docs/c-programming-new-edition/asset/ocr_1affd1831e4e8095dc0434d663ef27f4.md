# 9.3. SINGLY LINKED LISTS

Prior to understanding the specifics of singly linked lists, it is crucial to have a solid understanding of the node, which is a list’s fundamental building block.

The fundamental part of a list is the node, as was previously stated. There are two elements to it; the first is referred to as the info and the second as the connection Node.Info Link The info part of the node contains information about the node that is what number is stored in the node or which character is stored in the node.

The link part of the node contains the address of the next node. As informed in the earlier sessions that whenever a value is stored on the memory it is stored at a particular address. As a result, the address of the second node in a singly linked list with four nodes or elements is stored in the link area of the first node, the address of the third node in the link area of the second, and so on (Figure 9.1).

You may wonder what the link area of the 4ᵗʰ node would contain. The 4ᵗʰ link area contains a null character, which depicts the end of the link. (If you remember a string was also terminated in the same fashion.)
