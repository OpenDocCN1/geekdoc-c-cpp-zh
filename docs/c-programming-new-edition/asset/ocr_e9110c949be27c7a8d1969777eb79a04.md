# 8.11. THE TYPEDEF STATEMENT

This is one more method in C which comes handy in situations where clarification of source code of a C program is required. This can be considered as a nickname for a data type that has a long name. The typedef is useful in the sense that it helps us to assign short readable names to data types. For example, the data type unsigned long int can be renamed as nick. It can be any word of the user’s choice and it is preferable that the rechristened name be mentioned in capitals. The following example shows the way of declaring a typedef statement. The keyword here is typedef which is followed by the original data type name which is followed by the new user defined name in capitals.

```
typedef unsigned long int NICK;
```

Once this is done the new name NICK can be used for declaring the data type of a particular variable Example:

```
NICK variable1, variable2;
```

Thus the usage of typedef provides a short and meaningful way to call a data type.
