# 9.4.1. Insertion

Insertion operation in a doubly linked list can be performed at three different locations:

+   - If list is empty and the first node has to be inserted;
+   - Beginning of a list; and
+   - In between two nodes.

Consider the consequence of inserting a node if a list is empty. The insertion in such a case can be performed by assigning the L and R pointers to the same node and the link areas of left and right will contain Null.
