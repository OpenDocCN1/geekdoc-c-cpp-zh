# 8.7. POINTERS IN STRUCTURES

Having learnt about functions and arrays it’s not fair to leave pointers behind. Since structure is also a data type like the int char, etc. You can have a pointer pointing to a struct. Such kinds of pointers are termed as structure pointers, though there is a difference while accessing these pointer variables. To access the other variables you used a dot (.) but this is not possible in a pointer but instead of a dot (.) you can use an arrow (->) Since you don’t have a particular key for the arrow you use a hyphen (-) and a greater than (>) symbol and that should suffice. The program below uses the above operator (->) to access the elements and print them. Therefore, things will be pretty comprehensible once you go through the program carefully.

```
#include<stdio.h>
void main()
{
struct emp
{
char ename[10];
int eno;
float esal;
};
struct emp e1={"suzzane",116,7500.00};
struct emp*point; point=&e1;
printf("%%s %%d %%f",e1.ename,e1.eno,e1.esal);
printf("%%s %%d %%f", point->ename,point->eno,point->esal);
```
