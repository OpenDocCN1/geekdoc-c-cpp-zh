
## 3.12. Do’s and Don’ts

- **Do’s:** The *if* statement is executed only if the condition following it becomes true. The condition should be enclosed within a pair of parentheses. The statements following the condition should be terminated using a semicolon. In the for statement, the initialization, condition, and incrementation are done within a pair of parentheses. Between each of the expressions in the for loop there must be a semicolon. The label in a goto should be followed by a colon.
- **Don’ts:** The choice within the parentheses of the switch case cannot take a floating point. The goto should be avoided as far as possible.

### 4.1. An Introduction to Arrays

In the previous sessions, you have come across various methods of storing a particular number or character in the memory using variables. To accomplish this feat, a variable was needed, and if 4 numbers were used, 4 variables were used. Now what if you have to store 10 numbers? Quite possible, one might say, but if 134 numbers have to be stored and retrieved whenever obligatory, is it still possible?

With arrays, it is. You may ask why didn’t you start with arrays in the first place? You needed to have some fundamental understanding of data types and their behavior in order to learn arrays. Moreover, the concept of arrays depends on other data types, which were meant to facilitate the storage of copious amounts of numbers in a single variable. One cannot imagine creating an array for a single number and wasting an entire consignment of space in the memory. It would be like buying a dozen books and ultimately using only one and dumping the rest in the garbage.

Thus arrays can be defined as a collection of similar elements. In this context, an array of elements can be formed only if all the elements are of one particular data type, i.e., all of them are either integer or character or a floating point number, but there cannot exist an array which hosts an amalgamation of these data types.

### 4.2. Advantages of Arrays

The usage of arrays is crucial to any professional programming. Arrays just make the life of a programmer a bit easier. Prima facie, it relieves him of the burden of having to keep naming the variables. They simply follow the good old slotted rack principle. An array is a single variable holding multiple data. Each data is referred to by its slot number. If, for instance, you wish to store a list of items, you could just name the variable “item,” and keep storing the data by referring to item(1), item(2), item(3), etc. It may sound pretty simple, but the magnitude of work that can be accomplished using arrays is praiseworthy.

To gain a better insight into the advantages of arrays, consider a simple example:

```c
main()
{
    int a;
    a = 2;
    a = 4;
    printf("a=%d", a);
}
```

The value that will be displayed will obviously be 4 because once another value is assigned to an existing variable with a value, the previous value is lost. The inference to be drawn is that without arrays, a variable cannot store more than one value. After the elements are arranged in an array, any element in any position can be retrieved without any hassles. Using arrays, sentences in English can be stored in the memory using what you call character arrays, which are otherwise called strings.

### 4.3. Types of Arrays

Before you get down to the brass tacks of using arrays, it wouldn’t harm you in any way if you had a shade more insight about the taxonomy of the arrays, into how many types they are classified and their functionalities. To begin with, the arrays are dichotomized broadly into two distinctive types: single dimensional arrays and multidimensional arrays. The intricacies of the above offsprings of the arrays will be dealt with in an exhaustive manner later in this session. What will be discussed here will be purely perfunctory in nature.

**Single Dimensional Arrays:** The single dimensional arrays, as the name suggests, handle only a single procession of similar elements. That is to say, you can only have one row of elements, and the size of a single dimensional array depends on the programmer.

Basically, the single dimensional arrays facilitate the accommodation of many similar elements in a single variable. More on this is discussed meticulously in the succeeding sections, after which you will have a cloudless view of the single dimensional arrays.

**Multidimensional Arrays:** The multidimensional arrays are two or more arrays clubbed together.

They can be of two-dimensional type or three-dimensional type or more, but you can restrict the research only to two and three dimensional arrays. An example of the two dimensional arrays is the matrix, because like the matrix, the two dimensional arrays have two indices, one symbolizing the row elements and the other the column elements. The three dimensional array is a shade different because the first index lists the number of tables of the two dimensional arrays. The remaining two indices are similar to the two-dimensional array in the sense that one is for the row and the other is for the column.
