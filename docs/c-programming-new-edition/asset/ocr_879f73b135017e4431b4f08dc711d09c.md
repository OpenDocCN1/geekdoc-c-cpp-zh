Since the computer cannot decipher if we write it in normal English we have to write it in a from which is understandable by the computer. The general format is specified as below:

if (this condition is true)

execute this statement; now one may ask why only the word if why not any other word. Well what the keyword if does is that it intimates the compiler that a decision control instruction follows it and if the condition in the parentheses turns out to be true then the following statements are to be executed but if the condition is not satisfied then none of the statements are to be executed.

The conditions are to be specified within the parentheses. Why? because once a statement is written the parentheses and it follows the if the compiler recognizes that it is a condition and its truth or falsity is to be checked. This is done by means of the relational operators of C (<, >, <=, >=, ==, !=).
