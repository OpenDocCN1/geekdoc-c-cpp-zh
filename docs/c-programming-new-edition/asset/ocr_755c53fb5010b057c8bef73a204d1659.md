The pointers Some programmers dread to use the pointers and that’s why the hot seat eludes them. But then you must be thinking why jitters are being given even before the definition is explained. Well it’s not to alarm you but to just apprise you of the significance of pointers in C. The reason why pointers may be a shade trickier than the rest of the is because their operations are entirely behind the screen, i.e., in the memory and it is always complex to comprehend the internals of the computer.

After reading the brief prologue about pointers you must be raring to have your first dash with pointers. According to the definition a pointer is a data type which can have a variable that represents the location of a data item like an integer. The effectiveness of pointers is admirable because pointers can be used to pass information back and forth between a function and its reference point. Before you even set your hands on pointers there is one basic brick that has to be comprehended and that is the address. You might ask address of what? What happens is whenever any variable is declared and stored in the memory it is assigned a particular location. Just like when you check into a hotel you are allotted a particular suite from the multitude of rooms which has a unique number specific to only that. Whenever any reference is to be made, it is done so using that unique number. In a similar way the location in which the variable is stored has a unique number which is called the address of the variable and any reference to the variable is done through this address. Note The address of any variable is always a whole number.
