Call by Reference Try the above thing here and you will end up losing the previous value. Why? Because you are using the addresses of the arguments and any tampering with the values would result in erasing the old value from the address and installation of the new address.

```
#include<stdio.h>
main()
{
int a=10,b=20;
ichange(&a,&b); printf("\na=%db=%d",a,b);
}
ichange(int *x,int *y)
{
int t; t=*x; *x=*y; *y=t;
}
```

The above program is similar to the one dealt with before, i.e., the swapping of two numbers. The difference being that earlier values were being used but in the above program instead of values the address of the value from the memory is used to swap the two values and hence once the control returns to the program the new values are retained.
