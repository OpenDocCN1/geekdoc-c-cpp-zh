An added advantage is evident during the deletion operations. For the deletion operation to be performed in singly linked list the predecessor node of the deleted node had to be found. This required an intensive search and traversal process starting from the first node.

The circular list avoids such a cumbersome process because as mentioned earlier any node can be accessed directly and the list can be traversed from there. A minor drawback is however detected in the circular list. Using the circular list there is high risk of the list ending in an indefinite loop, if proper care is not taken while processing. To avoid complication the end of the list has to be identified. This can be done by placing a special node often referred to as list head in the circular list.

Circular Doubly Linked Lists: For the doubly linked list to be made a circular list the null present in the right link of the last node of the list is replaced with the address of the first node and similarly the null in the left link of the first node is replaced with the address of last node.
