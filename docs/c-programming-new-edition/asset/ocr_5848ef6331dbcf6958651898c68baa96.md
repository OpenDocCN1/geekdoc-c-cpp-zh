The compilers and interpreters, to keep it simple, act as translators between the user and the computer. What some people are not aware of is that the computer understands only the machine language, i.e., 0s and 1s.

The compilers or the interpreters translate the programming language to the machine language, do the necessary computation in the machine language and once the result is obtained, translate it back into the programming language.

A compiler or the interpreter is itself a program and every computer must have its own compiler or interpreter. It is just that the approaches of translating programs in both of them are different. A compiler while translating takes the whole program, translates it, and displays it back.

An interpreter on the other hand, breaks the program into sentences and translates the sentences one by one. It is preferable to develop a new program using an interpreter rather than a compiler though it is mandatory for every computer to have its own compiler or interpreter for a particular high-level language.

# 1.6. BUILDING LOGIC THROUGH PSEUDOCODES

As they say, a good plan is half the battle. In a similar way in C before embarking on writing the program it is essential that you plan the strategy that you intend to use.

In short, a skeletal program or framework of the code must be organized so that the entire concentration is on the logic of the program. Once the program strategy is decided, emphasis can be given to the details associated with the individual statements. This line of attack is generally referred to as top-down approach. With large programs this entire process might recur numerous times.

Top-down approach can be accomplished by evolving an informal outline containing sentences that are partly in English and partly in C. In the infant stages of the program development, the exigency for C is minimal restricting it to only major program components. Auxiliary detail is then provided in English. The resulting detail is called pseudocode.

In your example you will come across a pseudocode that is written for computing simple interest on a given Principle. The formula will be SI = p*n*r/100 and the values for p, n, and r should be requested from the user. Here ‘p’ stands for the principal ‘n’ stands for the number of years ‘r’ stands for the rate of interest.
