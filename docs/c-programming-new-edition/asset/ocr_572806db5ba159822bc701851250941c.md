Random access is illegal, i.e., you cannot access the 2nd or the 3rd element of the list directly. You are aware of the fact that the one that holds the address of another element is called a pointer. Thus, the link can also be called the pointer because it points to the next element in the list.

Now that you have a clear picture about the singly linked lists you will see how the inserting and deleting operations are performed on this linked list. Insertions The insertion operation in the singly linked list can be performed at three different positions in the singly linked list.

+   - At the beginning of the list.
+   - At the end of the list.
+   - In between two nodes.

If the insertion of a new node has to made at the beginning of the list the link area of the new node is assigned the address of the first node. The head pointer is then made to point to the new first element. Since it contains the address of the old first element a link is created between the new node and the rest of the list. An insertion operation can be performed on the middle of the list in between two nodes. For example if a new node has to be inserted in between the 2nd and 3rd nodes in a list then as a first step the head pointer is traversed till the 2nd node. The address of the new node to the inserted is assigned to the link area of the 2nd node and the link area of the new node is assigned the address of the 3rd node. Thus, a link is broken between the 2nd and 3rd node and new node is inserted.

For a node to be inserted at the end of the list the head pointer is traversed till the last node and the link area which contains null is reassigned to hold the address of the new node and the new node is assigned the null character in its link area. The process of insertion precedes a search for the place of insertion. The search involves locating a node after which the new item is to be inserted.
