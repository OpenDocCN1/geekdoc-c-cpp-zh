The compound operators are conspicuously missing from this list, but if you recall that these operators perform both an arithmetic action and an assignment together, by overloading the appropriate arithmetic operator, you allow the corresponding compound assignment operator to use your new overloaded operator.

Typically, operators should always be overloaded in symmetrical groups. For example, if you overload the equality operator you should also overload the inequality operator. The only exceptions to this symmetrical overloading guideline are the one's complement operator (~) and the not operator (!). The logical symmetrical groups that should be followed for operator overloading are shown in Table 5.2.
