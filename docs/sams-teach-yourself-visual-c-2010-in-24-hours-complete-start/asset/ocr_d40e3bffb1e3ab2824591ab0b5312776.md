> **Type Safety and the CTS**

The common type system and common language specification form the foundation of the type-safety found in the .NET Framework.

This foundation provides the .NET Framework a consistent way to promote type safety but not enforce it. The task of enforcing type safety is left to the individual language compilers and the virtual execution system (which you will learn about a bit later this hour).
