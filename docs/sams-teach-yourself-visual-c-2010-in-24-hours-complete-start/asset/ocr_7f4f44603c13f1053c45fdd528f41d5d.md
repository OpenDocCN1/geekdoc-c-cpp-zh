The Step Into, Step Over, Step Out, and Step Into Specific actions all move "forward" in your program execution one line at a time. Sometimes, when you have started debugging you want to execute to a certain point and then break again. You can do this by finding the desired line, adding a new breakpoint and then continuing execution with the F5 key.

However, this isn't always necessary. You can also continue execution until it reaches the current cursor location. To do this, right-click on a line in the source code editor, and choose the Run To Cursor context menu.

# **Switching Call Stack Frames**

When you switch to another call stack frame, the current execution point remains in the original frame. When you continue execution or perform one of the Step actions, execution continues from the original frame, not the frame you selected.
