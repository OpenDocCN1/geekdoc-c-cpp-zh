The Page class supports several events that you can handle, the most common of which are shown in Table 19.1.

# TABLE 19.1 Common Page Event Handlers

| Event Handler Method Name | Description |
| :--- | :--- |
| Page_Load | Occurs when the server control is loaded into the page object |
| Page_LoadComplete | Occurs at the end of the load stage |
| Page_PreLoad | Occurs at the beginning of page initialization |
| Page_PreRender | Occurs before the page Load event |
| Page_PreRender | Occurs after the page is loaded but prior to rendering |
| Page_PreRenderComplete | Occurs before the page content is rendered |
| Page_Unload | Occurs when the server control is unloaded from memory |

# By the Way

> **Developing Web Applications Without IIS**

You do not need to have Internet Information Services (IIS) installed to develop and test web applications. Visual Studio 2010 (all editions) includes a built-in web server that will be used when you run the application. For hosting product web applications, you should still use IIS.
