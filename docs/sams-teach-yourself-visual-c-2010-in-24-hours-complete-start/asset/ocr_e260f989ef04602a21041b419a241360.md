Comparison of a for and while statement

Looking at the sequence of events that occur when a for statement executes, it is the same sequence as a while statement:

+   1. The initializer is executed, if present. If there are multiple expressions, they are executed in the order they are written. The initializer is executed once at the beginning of the statement.
2. If condition evaluates to true, control is transferred to the embedded statement.
3. The embedded statement is executed.
4. The statements in the iterator are evaluated, if present, and the condition is reevaluated. If condition evaluates to false, control is transferred to the next statement after the for statement.
