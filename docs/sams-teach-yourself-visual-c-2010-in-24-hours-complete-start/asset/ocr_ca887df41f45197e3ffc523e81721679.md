# # The break Statement

The break statement is used to exit the nearest switch, while, do, for, or foreach statement. If multiple statements are nested within each other, only the innermost statement is exited.

Listing 7.8 shows the same for statement from Figure 7.1 using a break statement that causes the loop to terminate after four iterations.

# ## LISTING 7.8 The break Statement

for (int i = 0; i < 10; i++)
{
    Console.WriteLine(i);
    if (i == 3)
    {
        break;
    }
}
