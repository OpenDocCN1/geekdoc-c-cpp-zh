Microsoft offers four primary editions of Visual Studio 2010:

+      - Express
   - Professional with MSDN
   - Premium with MSDN
   - Ultimate with MSDN

The Express editions are free and targeted at VB, C#, C++, or Web development. The three editions that include MSDN are designed for use in a corporate development setting and offer additional features and capability.

Throughout this book, the examples and screen images are from Visual C# 2010 Express using Basic settings enabled. If you run one of the Visual Studio with MSDN editions or Visual C# Express with Advanced settings enabled, the screen images can look different.

When Visual Studio starts, you see the Start Page, shown in Figure 1.3, which enables you to access recent projects, create new projects, learn about upcoming product releases, or read the latest development news.
