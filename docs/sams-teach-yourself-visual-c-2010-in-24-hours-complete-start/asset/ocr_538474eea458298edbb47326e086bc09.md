The `FileInfo` class contains instance members that provide a number of properties and methods for performing common file operations such as copying, moving, creating, and opening files. The commonly used methods and properties are listed in Table 13.4.

**TABLE 13.4** Commonly Used `FileInfo` Members

| **Member** | **Description** |
| :--- | :--- |
| `AppendText` | Creates a `StreamWriter` for appending text to the current file |
| `CopyTo` | Gets or sets the attributes of the current file |
| `Create` | Copies the current file to a new file |
| `CreateText` | Creates a file |
| `Delete` | Creates or opens a file for writing text |
| `Directory` | Deletes the current file |
| `DirectoryName` | Gets the parent directory |
| `Exists` | Gets the name of the parent directory |
| `Extension` | Determines if the current file exists on disk |
| `FullName` | The extension of the current file |
| `IsReadOnly` | Gets the full path of the current file |
| `Length` | Gets or sets a value that determines if the current file is read only |
| `MoveTo` | The size of the current file |
| `Name` | Moves the current file to a new location |
| `Open` | Gets the name of the current file |
| `OpenRead` | Opens a file |
| `OpenText` | Opens an existing file for reading |
| `OpenWrite` | Opens an existing text file for reading |
| `Refresh` | Opens an existing file for writing |
| `Replace` | Refreshes the cached file information |
|  | Replaces the contents of the specified file with the contents of the current file |
