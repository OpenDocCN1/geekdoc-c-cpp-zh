# Writing Your First Program

At this point, you should be familiar enough with the C# language and syntax to write your first program. If you haven’t already installed Visual Studio 2010, now is the time to do so. As your first introduction to C#, you will continue the tradition of starting with a simple application that displays the message “Hello, world” on the screen.
