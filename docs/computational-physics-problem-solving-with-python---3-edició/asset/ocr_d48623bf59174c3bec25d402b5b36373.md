Because of the fluid's viscosity, the velocity is stationary along the beam top:

v_x = ∂u/∂y = 0  (beam top).  (25.48)

Because the current flows smoothly along the top of the beam, v_y must also vanish. In addition, because there is no x variation, we have

∂v_y/∂x = 0  ⇒  w = -∂v_x/∂y = -∂²u/∂y².  (25.49)

After substituting these relations into the Taylor series (25.46), we can solve for w and obtain the finite-difference version of the top boundary condition:

w ≈ -2 [u(x, y + h) - u(x, y)] / h²  ⇒  w_{i,j} = -2 [u_{i,j+1} - u_{i,j}] / h²  (top).  (25.50)

Similar treatments applied to other surfaces yield the boundary conditions.

|  |  |  |
|---|---|---|
| u = 0 | w = 0 | Centerline EA |
| u = 0 | w_{i,j} = -2(u_{i+1,j} - u_{i,j})/h² | Beam back B |
| u = 0 | w_{i,j} = -2(u_{i,j+1} - u_{i,j})/h² | Beam top C |
| u = 0 | w_{i,j} = -2(u_{i-1,j} - u_{i,j})/h² | Beam front D |
| ∂u/∂x = 0 | w = 0 | Inlet F |
| ∂u/∂y = V₀ | w = 0 | Surface G |
| ∂u/∂x = 0 | ∂w/∂x = 0 | Outlet H  (25.51) |
