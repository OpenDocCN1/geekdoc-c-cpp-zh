以上是顺序栈的部分运算。

由于栈的插入和删除操作具有它的特殊性，所以用顺序存储结构表示的栈并不存在插入删除移动元素的问题，但栈容量难以扩充的弱点仍旧没有摆脱。

由于上述原因，似乎栈也可以用链式结构来表示。

那么怎样用链式结构表示栈呢？
