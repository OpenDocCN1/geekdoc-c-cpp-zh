**Listing 11.9** `tune4.f95` 通过显式写出 Do 循环的两个步骤（步长为 2）进行了一定的循环展开。这导致了更好的内存访问和更快的执行。

    PARAMETER (ldim = 2050)
    Implicit Double Precision (a-h,o-z)

    Do i = 1,ldim

             ham(j,i) = 0.0

!      start iterating towards the solution

       ham(i,i) = i
       coef(i) = 0.0
       diag(i) = ham(i,i)

    coef(1) = 1.0

    iter = 0
20  If(iter < 15 .and. err > 1.0e-6) Then
