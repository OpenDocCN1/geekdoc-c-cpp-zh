By successively selecting Φ(x) = φ₀, φ₁, …, φ_{N−1}, we obtain N simultaneous linear equations for the unknown α_j’s:

∫_a^b dx d/dx (∑_{j=0}^{N-1} α_j φ_j(x)) dφ_i/dx = ∫_a^b dx 4πρ(x) φ_i(x),    i = 0, N−1 . (23.15)

We factor out the unknown α_j’s and write the equations out explicitly:

α₀ ∫_a^b φ₀' φ₀' dx + α₁ ∫_a^b φ₀' φ₁' dx + ⋯ + α_{N−1} ∫_a^b φ₀' φ_{N−1}' dx = ∫_a^b 4πρ φ₀ dx ,

α₀ ∫_a^b φ₁' φ₀' dx + α₁ ∫_a^b φ₁' φ₁' dx + ⋯ + α_{N−1} ∫_a^b φ₁' φ_{N−1}' dx = ∫_a^b 4πρ φ₁ dx ,

⋮

α₀ ∫_a^b φ_{N−1}' φ₀' dx + α₁ ∫ + ⋯ + α_{N−1} ∫_a^b φ_{N−1}' φ_{N−1}' dx = ∫_a^b 4πρ φ_{N−1} dx .

Because we have chosen the φ_i’s to be the simple hat functions, the derivatives are easy to evaluate analytically (for other bases they can be carried out numerically):

dφ_{i,i+1}/dx = { 0,    x < x_{i−1},  or  x_{i+1} < x,  1/h_{i−1},  x_{i−1} ≤ x ≤ x_i,  −1/h_i,  x_i ≤ x ≤ x_{i+1},  0,    x < x_i,  or  x_{i+2} < x,  1/h_i,  x_i ≤ x ≤ x_{i+1},  −1/h_{i+1},  x_{i+1} ≤ x ≤ x_{i+2} . } (23.16)

The integrations are now fairly simple:

∫_{x_{i−1}}^{x_{i+1}} dx (φ_i')² = ∫_{x_{i−1}}^{x_i} dx 1/(h_{i−1})² + ∫_{x_i}^{x_{i+1}} dx 1/h_i² = 1/h_{i−1} + 1/h_i , (23.17)

∫_{x_{i−1}}^{x_{i+1}} dx φ_i' φ_{i+1}' = ∫_{x_{i−1}}^{x_{i+1}} dx φ_{i+1}' φ_i' = ∫_{x_i}^{x_{i+1}} dx −1/h_i² = −1/h_i , (23.18)

∫_{x_{i−1}}^{x_{i+1}} dx (φ_{i+1}')² = ∫_{x_i}^{x_{i+1}} dx (φ_{i+1}')² = ∫_{x_i}^{x_{i+1}} dx +1/h_i² = +1/h_i . (23.19)
