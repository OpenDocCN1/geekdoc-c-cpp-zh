![](bbox=[0.198, 0.092, 0.865, 0.359])

确定存在两个频率。在这种情况下，为了避免混叠，我们希望输入信号中不存在频率 $f>s/2$。这称为奈奎斯特准则（Nyquist criterion）。在实际应用中，一些应用通过滤除高频成分，然后只分析剩余的低频部分，来避免混叠的影响。（第 12.8.1 节讨论的低频 sinc 滤波器通常用于此目的。）虽然滤波会消除一些高频信息，但它会减小低频成分的失真，因此可能改善信号的重现效果。

如果需要高频的准确值，那么就需要通过增加在固定采样时间 $T=Nh$ 内采集的样本数量 $N$ 来提高采样率 $s$。保持采样时间不变并增加采样数量，可以使时间步长 $h$ 变小，并捕获更高的频率。增加 $N$ 的频率数量并进行计算，会使之前较高的频率成分更靠近频谱中部，从而远离容易产生误差的两端。

如果增加总采样时间 $T=Nh$ 而保持 $h$ 不变，那么采样率 $s=N/T=1/h$ 保持不变。由于 $\omega_1=2\pi/T$，这会使 $\omega_1$ 变小，从而记录更多低频，并得到更平滑的频谱。正如我们所说的，这通常是在事后通过用零填充数据集末尾来实现的。
