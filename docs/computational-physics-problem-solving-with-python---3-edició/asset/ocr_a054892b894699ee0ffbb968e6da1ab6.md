A problem that may be encountered when calculating these variables is that the sums in (17.21) can become large enough to cause overflows, although the ratio would not. You work around that by factoring out a common large factor, for example,

```
∑_{E_i} X(E_i) g(E_i) e^{-E_i / k_B T} = e^{λ} ∑_{E_i} X(E_i) e^{ln g(E_i) - E_i / k_B T - λ} , (17.39)
```

where λ is the largest value of ln g(E_i) − E_i / k_B T at each temperature. The factor e^{λ} does not actually need to be included in the calculation of the variable because it is present in both the numerator and denominator and so eventually cancels out.
