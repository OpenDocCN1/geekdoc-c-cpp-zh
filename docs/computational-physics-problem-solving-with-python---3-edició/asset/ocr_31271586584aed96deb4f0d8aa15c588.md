The best fit of this quadratic to the data is obtained by applying the minimum χ² condition (7.44) for M_p = 3 parameters and N_D (still arbitrary) data points. A solution represents the maximum likelihood that the deduced parameters provide a correct description of the data for the theoretical function g(x). Equation 7.44 leads to the three simultaneous equations for a₁, a₂, and a₃:

```
∑_{i=1}^{N_D} [y_i − g(x_i)] / σ_i² ∂g(x_i)/∂a₁ = 0 ,   ∂g/∂a₁ = 1 ,   (7.58)
∑_{i=1}^{N_D} [y_i − g(x_i)] / σ_i² ∂g(x_i)/∂a₂ = 0 ,   ∂g/∂a₂ = x ,   (7.59)

```
