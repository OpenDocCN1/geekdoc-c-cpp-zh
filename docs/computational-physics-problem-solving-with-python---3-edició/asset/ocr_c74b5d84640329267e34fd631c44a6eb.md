# Thermodynamic Properties

For a given spin configuration $a_j$, the energy and magnetization are given by

```
$E_{a_j} = -J \sum_{i=1}^{N-1} s_i s_{i+1}, \quad \mathcal{M}_j = \sum_{i=1}^{N} s_i. \tag{17.14}$
```

The internal energy $U(T)$ is just the average value of the energy,

```
$U(T) = \langle E \rangle, \tag{17.15}$
```

where the average is taken over a system in equilibrium. At high temperatures, we expect a random assortment of spins and so a vanishing magnetization. At low temperatures when all the spins are aligned, we expect $\mathcal{M}$ to approach $N/2$. Although the specific heat can be computed from the elementary definition,

```
$C = \frac{1}{N} \frac{\mathrm{d}U}{\mathrm{d}T}, \tag{17.16}$
```

the numerical differentiation may be inaccurate because $U$ has statistical fluctuations. A better way to calculate the specific heat is to first calculate the fluctuations in energy occurring during $M$ trials and then determine the specific heat from the fluctuations:

```
$U_2 = \frac{1}{M} \sum_{t=1}^{M} (E_t)^2, \tag{17.17}$
```

```
$C = \frac{1}{N^2} \frac{U_2 - \langle U \rangle^2}{k_B T^2} = \frac{1}{N^2} \frac{\langle E^2 \rangle - \langle E \rangle^2}{k_B T^2}. \tag{17.18}$
```
