The Runge–Kutta algorithms for integrating a differential equation are based upon the formal (exact) integral of our differential equation:

```
dy/dt = f(t, y)  ⇒  y(t) = ∫ f(t, y) dt  (8.31)
```

```
⇒  y_{n+1} = y_n + ∫_{t_n}^{t_{n+1}} f(t, y) dt .  (8.32)
```

To derive the second-order Runge–Kutta algorithm rk2 (Figure 8.5 and rk2.py), we expand f(t, y) in a Taylor series about the midpoint of the integration interval and retain two terms:

```
f(t, y) ≃ f(t_{n+1/2}, y_{n+1/2}) + (t − t_{n+1/2}) d f / d t (t_{n+1/2}) + O(h²) .  (8.33)
```

Because (t − t_{n+1/2}) raised to any odd power is equally positive and negative over the interval t_n ≤ t ≤ t_{n+1}, the integral of the (t − t_{n+1/2}) term in (8.32) vanishes and we obtain our algorithm:

```
∫_{t_n}^{t_{n+1}} f(t, y) dt ≃ f(t_{n+1/2}, y_{n+1/2}) h + O(h³) ,  (8.34)
```

```
⇒  y_{n+1} ≃ y_n + h f(t_{n+1/2}, y_{n+1/2}) + O(h³)  (rk2) .  (8.35)
```

We see that while rk2 contains the same number of terms as Euler's rule, it obtains a higher level of precision by taking advantage of the cancelation of the O(h) terms. Yet the price for improved precision is having to evaluate the derivative function and the solution y at the middle of the time interval, t = t_n + h/2.
