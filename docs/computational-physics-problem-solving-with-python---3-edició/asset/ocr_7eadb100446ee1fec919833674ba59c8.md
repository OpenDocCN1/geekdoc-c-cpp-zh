$$u(r)=N_0\sum_{i=1}^{N}\frac{\sin(k_i r)}{k_i r}F(k_i,k_0)^{-1}.$$  (26.42)

Here $N_0$ is a normalization constant and the $R$ amplitude is appropriate for standing-wave boundary conditions. So once we know $F$, we also know the wave function.
