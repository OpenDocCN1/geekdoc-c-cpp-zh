# 11.5 Constructors in Derived Classes

As explained in the preceding section, instantiating a derived-class constructor begins a chain of constructor calls. The derived-class constructor, before performing its own tasks, invokes its base class constructor explicitly (via a constructor with base reference) or implicitly (calling the base class's default constructor or parameterless constructor). Similarly, if the base class is derived from another class, the base-class constructor invokes the constructor of the next up in the hierarchy, and so on. The last constructor in the chain is the constructor for class object. The derived-class constructor finishes execution. Each base class constructor populates the data that the derived-class object inherits.

For example, consider again the BasePlusCommissionEmployee hierarchy from Figs. 11.10 and 11.11. When an app creates a BasePlusCommissionEmployee object, the BasePlusCommissionEmployee constructor is called. That immediately calls CommissionEmployee's constructor, which in turn immediately calls its constructor implicitly. Class object's constructor performs its task, then immediately returns control to CommissionEmployee's constructor, which then initializes the CommissionEmployee data that part of the BasePlusCommissionEmployee object. When CommissionEmployee completes execution, it returns control to BasePlusCommissionEmployee object's BaseSalary.

# 11.6 Software Engineering with Inheritance

This discusses customizing existing software with inheritance. When a new class extends an existing class, the new class inherits the members of the existing class. We can customize the new class to meet our needs by including additional members and by overriding base classes. C# simply requires access to the compiled base code, so it can compile and execute any app that extends or uses the base class. This powerful capability is attractive to independent software vendors (ISVs), who develop proprietary classes for sale or license and make them available to users in class libraries. Users can then derive new classes from these libraries rapidly, without accessing the ISV's source code.
