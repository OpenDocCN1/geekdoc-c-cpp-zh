# 20.7 Wrap-Up

This chapter introduced generics. We discussed how generics ensure compile-time safety by checking for type mismatches at compile time. You learned that the compiler will allow generic code to compile only if all operations performed on the type parameters in the generic code are supported for all types that could be used with the generic code. We also learned how to use a constraint to specify the requirements for a type parameter—a key component of compile-time type safety. We discussed several kinds of constraints, including reference-type constraints, value-type constraints, class constraints, interface and constructor constraints. Finally, we saw how generics improve code reuse. In the next chapter, we demonstrate the .NET Framework Class Library's collection classes, interfaces and algorithms. Collection classes are pre-built data structures that you can reuse in your apps, saving time.
