# Efficiency of Selection Sort

The selection algorithm runs in O(n²) time. Method SelectionSort, which implements the selection algorithm, contains nested loops. The outer loop (lines 32–47) iterates over the first n – 1 elements in the array, swapping the remaining element to its sorted position. The inner loop (lines 37–43) iterates over each element in the remaining array, searching for the smallest. This loop executes n – 1 times during the first iteration of the outer loop, n – 2 times during the second iteration, n – 3, ..., 3, 2, 1. This inner loop will iterate a total of n(n – 1) / 2 or (n² – n)/2. In Big O notation, swaps are not counted and constants are ignored, leaving a final O(n²).

# 18.3.2 Insertion Sort

Insertion sort is another simple, yet inefficient, sorting algorithm. Its first iteration takes the second element in the array, and if it’s less than the first, swaps them. The second iteration looks at the third element and inserts it in the correct position with respect to the first two elements (moving them as necessary), so all three elements are in order. At the ith iteration of this algorithm, the first i elements in the original array will be sorted.
