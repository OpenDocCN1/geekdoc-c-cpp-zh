# 5.4.3 Iteration Statements

C provides iteration statements (sometimes called repetition statements or looping statements) that enable to perform statements repeatedly as long as a condition (called the loop-continuation condition) remains true. The iteration statements are while, do..., and for statements. Chapter 6 presents the do...while statement. The while and for statements perform the action (or group of actions) in their bodies or more times—if the loop-continuation condition is initially false, the action (or group of actions) will not execute. The do...while statement performs the action (or group of actions) in its body one or more times. The words if, else, switch, do, and for are C keywords.

# 5.4.4 Summary of Control Statements

C has only three kinds of control statements: the sequence, selection (three types) and iteration (four types). Every app is formed by combining as many of these statements as appropriate for the algorithm it implements. We can model each control statement as an activity diagram. Like Fig. 5.2, each diagram contains an initial and a final state that represent a control statement's entry point and exit point, respectively. Single-entry/single-exit control statements makes it easy to build programs—simply connect the exit point of one to the entry point of the next. We call this control-statement stacking. We'll learn that there is only one way in which control statements may be connected—nested statement—in which one control statement appears inside another. Thus, algorithms in C apps are constructed from only three kinds of control statements, combined in only two ways. This is the essence of simplicity.

# 5.5 if Single-Selection Statement

We introduced the if single-selection statement briefly in Section 3.9. Apps use selection statements to choose among courses of action. For example, suppose that the passing grade on an exam is 60. The pseudocode statement

```
If student's grade is greater than or equal to 60
    Display "Passed"
```

represents an if statement that determines whether the condition "student's grade is greater or equal to 60" is true. If so, "Passed" is displayed, and the next pseudocode statement in order is "performed." (Remember, pseudocode is not a real programming language). If the condition is false, the Display statement is indented. The indentation of the line of this statement is optional, but recommended, because it emphasizes the inherent structure of structured programs.
