# Examining Array c in More Detail

Let's examine c in Fig. 8.1 closely. The name of the variable that references the
ay is c. Every array instance knows its own length and provides access to this information
with the Length property. For example, the expression c.length returns array c's
(that is, 12). The Length property of an array is read only, so it cannot be changed. The ar-
ays 12 elements are referred to as c[0], c[1], ..., c[11]. Referring to elements out-
side of this array, such as c[-1] or c[12], is a runtime error (as we demonstrate in
Fig. 8.9). The value of c[0] is -45, the value of c[1] is 6, the value of c[2] is 0, the value
of c[7] is 6 and the value of c[11] is 78. To calculate the sum of the values contained in
the three elements of array c and store the result in the array sum, we'd write

```
sum = c[0] + c[1] + c[2];
```

To divide the value of c[6] by 2 and assign the result to the variable x, we'd write

```
x = c[6] / 2;
```

# 8.3 Declaring and Creating Arrays

Arrays occupy space in memory. They're objects, they're typically created with key-word new. To create an array object, you specify the type and the number of array ele-ments in an array-expression that uses keyword new and returns a reference that can be stored in an array variable. The following statement creates an array object contain-ing 12 elements—initialized to 0 by default—and stores the array's reference in variable c:

```
int[] c = new int[12];
```

When you create an array with new, each element of the array receives the default value for the array's element—0 for the numeric single-type elements, false for bool ele-ments and null for references. The preceding statement creates the memory for the array in Fig. 8.1 but does not populate the array with the values shown in that figure. In Section 8.4.2, we will provide specific, nondfault initial values when we create an array.
