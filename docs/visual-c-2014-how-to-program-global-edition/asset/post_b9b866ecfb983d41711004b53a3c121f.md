Set a convention for the indent you prefer, then uniformly apply that convention. The Tab may be used to create indents, but tabs vary among many text editors. Due to the limited width of code lines in print books, we use three-space indents—this reduces the number of code lines that wrap to a new line, making the code bit easier to read. > ### Error-Prevention Tip 3.3
Whenever you type an opening left brace, {, in your app, the IDE immediately inserts the right brace, then repositions the cursor between the braces so you can begin typing the body. This practice prevents errors due to missing braces.

> ### Common Programming Error 3.4
It's a syntax error if braces do not occur in matching pairs.

## 3.2.5 Main Method

Line 7

```csharp
// Main method begins execution of C# app
static void Main()
```

is a comment indicating the purpose of lines 8–11. Line 8 is where the app begins execution—this is known as the entry point. The parentheses after the identifier Main indicate that it is a building block called a method. Class declarations normally contain one or more methods. Methods usually use the same capitalization conventions used for classes. For each class, one of the methods in a class must execute. A method is able to perform a task and return a value when it completes its task. Keyword void (line 8) indicates that Main will not return a value after it completes its task. Later, we will see that most methods return values. You will learn more about methods in Chapters 4 and 7. We discuss the contents of Main's parentheses in Chapter 8. For now, simply mimic Main's first line in your code.

**Body of the Method Declaration**
The left brace in line 9 begins the body of the method declaration. A corresponding right ends the body (line 11). Line 10 in the method body is indented by the braces.

Each method declaration's body statements one level of indentation between the left and right braces that define the body.

## 3.2.6 Displaying a Line of Text

Line 10

```csharp
Console.WriteLine("Welcome to C# Programming!");
```

instructs the computer to perform an action—namely, to display the string of characters within the double quotation marks, which delimit the string. A string is sometimes called a character string, a message or a string literal. We refer to them simply as strings. Whitespace characters in strings are not ignored by the compiler.

Class Console standard input/output capabilities that enable apps to read and display text in the console window from which the app executes. The Console.WriteLine method displays a line of text in the console window. The string in the parentheses in line 10 is the argument to the method. Console.WriteLine performs its task by displaying its argument in the console window. When Console.WriteLine completes its task, it positions the screen cursor (the blinking symbol indicating the next character will be) at the beginning of the next line in the console window. The movement of the cursor is similar to what happens when a user presses the Enter key while typing in a text editor—the cursor moves to the beginning of the next line in the file.

## Statements

The entire line 10, including Console.WriteLine, the parentheses, and "Welcome-to C# Programming" in the parentheses and the semicolon (;), is called a statement. Most statements end with a semicolon. When the semicolon in line 10 executes, it displays the message Welcome to C# Programming in the console window. A method is typically composed of one or more statements that perform the method's task.

## 3.2.7 Matching Left ({}) and Right ({}) Braces

You might find it difficult when reading or writing an app to match the left and right braces ({ }) that delimit a class's or method's body. Visual Studio can help you locate braces in your code. Simply place the cursor immediately in front of the left brace or after the right brace, and Visual Studio will highlight them.
