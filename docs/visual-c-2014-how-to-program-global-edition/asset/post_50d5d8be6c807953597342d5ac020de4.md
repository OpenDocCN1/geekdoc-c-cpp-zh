## 14.5 Labels, TextBoxes and Buttons

Labels provide text information (as well as optional images) and are defined with class Label(a derived class of Control). A Label displays text that the user cannot directly modify. A Label's text can be changed programmatically by modifying the Label's Text property. Figure 14.17 lists common Label properties.

| Common Label properties | Description |
| --- --- |
| Font | The font of the text on the Label. |
| Text | The text on the Label. |
| TextAlign | The alignment of the Label's text on the control—horizontal (left, center or right) and vertically (top, middle or bottom). The default is top, left. |

Fig. 14.17 Common Label properties.

A textbox (class TextBox) is an area in which either text can be displayed by a program or the user can enter text via the keyboard. A password TextBox is a TextBox that hides the information entered by the user. As the user types characters, the TextBox masks the user input by displaying a password character. If you set the property SystemPasswordChar to true, the TextBox becomes a password TextBox. Users often encounter both types of TextBoxes, when logging into a computer or website—username TextBox allows users to input their usernames; the password TextBox allows users to enter their passwords. Figure 14.18 lists the properties and a common event of TextBoxes.

| TextBox properties and an event | Description |
| --- --- |
| Common Properties AcceptsReturn | If true in a multiline TextBox, pressing Enter in the TextBox creates a new line. If false (the default), pressing Enter is the same as pressing the default Button on the Form. The default Button is the one assigned to a Form's AcceptButton property. |
| Multiline ReadOnly | If true, the TextBox can span multiple lines. The default value is false. If true, the TextBox has a gray background, and its text cannot be edited. The default value is false. |
| ScrollBars | For multiline textboxes, this property indicates which scrollbars appear (None—the default, Horizontal, Vertical or Both). |
| Text UseSystemPasswordChar | The TextBox's text content. When true, the TextBox becomes a password TextBox, and the system-specified characters mask each character type. |
| Common Event TextChanged | Generated when the text changes in a TextBox (i.e., when the user adds or deletes characters). When you double click the TextBox control in Design mode, an empty event handler for this event is generated. |

Fig. 14.18 | TextBox properties and an event.

A button is a control that the user clicks to trigger a specific action or to select an option in a program. As you'll see, a program can use several types of buttons, such as checkboxes and radio buttons. All the button classes derive from class ButtonBase (namespace System.Windows.Forms), which defines common button features. In this section, we discuss class Button, which typically enables a user to issue a command to an app. Figure 14.19 lists common properties and a common event of class Button.

## 14.6 GroupBoxes and Panels

We set displayButton's Text property to "Show Me" and clear the Text of displayPasswordLabel so that it's clear when the program begins executing. The Border of displayPasswordLabel is set to Fixed3D, giving our Label a three-dimensional appearance. We also changed its Align property to MiddleLeft so that the Label's text is centered between its top and bottom. The password character for inputPasswordField is determined by the user's system settings when you use-SystemPasswordChar to create.

We create an event handler for displayButton by double clicking this control in Design mode. We added line 23 to the event handler's body. When the user clicks the Show Me Button in the caption, line 23 displays the text entered by the user in inputTextBox and displays it in displayPasswordLabel.

GroupBox and Panel arrange controls on a GUI. GroupBoxes and Panels are typically used to group controls of similar functionality or controls that are related in a GUI. All of the controls in a GroupBox or Panel move when the GroupBox or Panel is moved. Furthermore, GroupBoxes and Panels can also be used to show or hide a set of controls. When you toggle a container's Visible property, it toggles the visibility of all the controls within it.

The difference between these two controls is that GroupBoxes can display a caption (i.e., text) and not include scrollbars, whereas Panels can include scrollbars and not include a caption. GroupBoxes have thin borders by default; Panels can be set so that they also have borders by changing their BorderStyle property. Figures 14.21–14.22 list the common properties of GroupBoxes and Panels, respectively.
