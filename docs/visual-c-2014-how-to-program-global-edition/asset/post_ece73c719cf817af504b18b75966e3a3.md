To create an MDI Form, set a Form's IsMdiContainer property to true. The Form changes appearance, as in Fig. 15.38. Next, create a child Form class to be added to the Form. To do this, right-click in the Solution Explorer, select Project > Add Windows Form... and name the file. Edit the Form as like. To add the child Form to the parent, we must create a new child object, set its MdiParent property to the parent Form and call the child Form's Show method. In general, to add a child Form to the parent,

```
ChildFormClass child = new ChildFormClass();
child.MdiParent = parentForm;
child.Show();
```

In most cases, the parent Form creates the child, so the parentForm reference is this. The code to create a child usually lies inside an event handler, which creates a new window in response to a user action. Menu selections (such as File, followed by a submenu of New) are common techniques for creating new child windows.

Class property MdiChildren returns an array of child Form references. This is useful if the parent window wants to check the status of all its children (for example, ensuring that all are saved before the parent closes). Property ActiveMdiChild returns a reference to the active child window; it returns null if there are no active child windows.
Other features of MDI windows are described in Fig. 15.39.

Child windows can be minimized, maximized and closed independently of the parent window. Figure 15.40 shows two images: one containing two minimized child windows and a second containing a maximized child window. When the parent is minimized or closed, the child windows are minimized or closed as well.

![](img/57baed2319be0bb1b5f98674846f2711_685_0.png)

**Fig. 15.40** | Minimized and maximized child windows.

Note the title bar in Fig. 15.40(b) is Form1 - [Child1]. When a window is maximized, its title-bar is inserted into the parent window's title bar. When a child is minimized, its title-bar displays a restore icon, which can be used to return the child window to its size (size before it was minimized or maximized).

C# provides a property that helps track child windows are open in an MDI container. Property MdiWindowListItem of class MenuStrip specifies which, if any, displays a list of open windows that the user can select to bring the corresponding window to the foreground. When a new child window is opened, an entry is added to the end of the list (Fig. 15.41). If ten or more child windows are open, the list includes More Options..., which allows the user to select a window from a dialog.

# Good Programming Practice 15.1

In an MDI app, include a menu that displays a list of the open windows. This helps the user select a child window quickly.

![](img/57baed2319be0bb1b5f98674846f2711_686_0.png)

MDI containers allow you to organize the placement of its child windows. The child windows in an MDI app can be arranged by calling method LayoutMdi of the parent Form. Method LayoutMdi takes an enumeration, which allows ArrangeIcons, Cascade, TileHorizontal and TileVertical. Tiled windows completely fill the parent and do not overlap; such windows can be arranged horizontally (TileHorizontal) or vertically (TileVertical). Cascaded windows (value Cascade) overlap - each is the same size and displays a visible title bar, if possible. Value ArrangeIcons arranges the icons for minimized windows. If minimized windows are scattered around the parent window, value ArrangeIcons orders them neatly at the bottom-left corner of the parent window.
