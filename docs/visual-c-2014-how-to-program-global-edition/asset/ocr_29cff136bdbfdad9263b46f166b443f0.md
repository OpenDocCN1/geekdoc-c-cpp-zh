# Terminology 979

+   - All properties of an anonymous type are public and read-only.

+   - You refer to anonymous types by implicitly typed local variables.

+   - An anonymous type's autogenerated Equals method compares the properties of the anonymous object that calls method and the anonymous object that it receives is an argument.

# Section 22.8 Creating a Master/Detail View App

+   - In a master/detail view, one part of GUI (the master) allows you to select an entry, and another-part (the details) displays detailed information about that entry.

+   - The IDE allows you to specify the type of control(s) that it will create when you drag-and-drop an object from the Data Sources window onto a Form. To do so, click a data source object's node in the Data Sources window—it changes to a drop-list from which you can select the controls to use on GUI. The Details option indicates that the IDE would generate Label-Text boxes that represent each column of the data source object.

+   - Dragging a property from a data source object in the Data Sources window creates a BindingSource and a GUI for it in another table that are associated with the data source object. The items in this BindingSource automatically update based on the currently selected master object.

# Section 22.9 Address Book Case Study

+   - You cannot bind a LINQ to Entities query's results directly to a BindingSource's DataSource.

+   - When you convert a query to a List, only changes to records in the DbContext are tracked—any that you add or remove while viewing the filtered data in a List will be tracked.
