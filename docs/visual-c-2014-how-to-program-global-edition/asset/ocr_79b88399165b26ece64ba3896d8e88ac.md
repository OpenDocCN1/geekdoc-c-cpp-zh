For the statements (15–18) displays each array element's index (represented by counter) and value (represented by array[counter]). The loop-control variable counter is initially 0—index starts at 0, so zero-based counting allows the loop to access every element. The loop-continuation condition uses the property array.Length (line 15) to obtain array's length. In this example, the length is 5, so the loop continues executing as long as counter is less than 5. The highest index in an array is 4, so using the less-than-operator in loop-continuation condition guarantees that the loop does not attempt to access an element beyond the end of the array (i.e., during the final iteration of the loop, counter is 4). We'll soon see what happens when an out-of-range index is encountered at execution time.

# 8.4.2 Using an Array Initializer

An app can create and initialize its elements with an array initializer—comma separated list of expressions (using initializer list) enclosed in braces. The array length is determined by the number of elements in the initializer list. For example,

```
int[] n = {10, 20, 30, 40, 50};
```

creates a five-element array with index values 0, 1, 2, 3 and 4. n[0] is initialized to 10, n[1] to 20 and so on. This statement does not require to create the array object—the compiler counts the number of initializers (5) to determine the array's size, then sets up the appropriate new operation "behind the scenes."
