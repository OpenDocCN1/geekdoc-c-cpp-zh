ControlLabel displays the character value of the key pressed, whereas keyInfo-Label displays information relating to the pressed key. because the KeyDown and KeyPress events carry different information, the Form (KeyDemo) handles both.
The KeyPress event handler (lines 18–21) accesses the KeyChar property of the KeyEventArgs object. This returns the key as a char, which we then display in charLabel (line1). If the key is not an ASCII character, then the KeyPress event will not occur, and charLabel will not display any text. ASCII is a common encoding for letters, numbers, punctuation marks and other characters. It does not support keys such as the function keys (F1) or modifier keys (Alt, Ctrl and Shift).
The KeyDown event handler (lines 24–33) displays information from its KeyEventArgs object. The handler tests for all Alt, Shift and Control keys that the corresponding key is pressed and false if otherwise. The handler then returns the KeyCode, KeyData and KeyValue properties.
The KeyCode property returns an enumeration value (line 30). The KeyCode property returns the key, but does not provide any information about modifier keys. Thus, both a capital and a lowercase “a” are represented as the A.
TheData property (line 31) also returns an enumeration value, but includes modifier-key data. Thus, if “A” is input, the KeyData shows both A and Shift were pressed. KeyValue(line 32) returns an integer representing the key. int is the code. The code is useful when testing for non-ASCII keys like F12.
The KeyUp event handler (lines 36–40) clears Label1 when the key is released. As we see from the output, non-ASCII keys are not displayed in charLabel, because the KeyPress event is not generated. For example, charLabel does not display any text when you press the F7 key, as shown in Fig. 14.40(b). However, the KeyDown event still is generated, and KeyInfo displays information about the key’s pressed. The Keys enumeration can be used to test for specific keys by comparing the KeyCode of the pressed key values to the Keys enumeration.

# Software Engineering Observation 14.2

To cause a control to react when a particular key is pressed (such as Enter), handle a key event and test for the pressed key. To cause a Button to be clicked when the key is pressed on a Form, the Form’s AcceptButton property.
