## 7.4 Methods with Multiple Parameters

### 7.4.1 Keyword static

Method Maximum's declaration begins with keyword static, which enables the Main method (or static method) to call Maximum as shown in line 19 without creating an object of class MaximumFinder and qualifying the method name with the class name MaximumFinder—static methods in the same class can call each other directly.

### 7.4.2 Method Maximum

Consider the declaration of Method Maximum (lines 26–43). Line 26 indicates that the method returns a double value, and that the method requires three double parameters (x, y and z) to accomplish this. When a method has more than one parameter, the parameters are specified as a comma-separated list. Maximum is called in line 19, the parameter x is initialized with the value of argument number1, the parameter y is initialized with the value of argument number2 and the parameter z is initialized with the value of argument number3. There must be one argument in the method for each call in the method declaration. Each argument must be consistent with the type of the corresponding parameter. For example, a parameter of type double can receive values like 7.35 (double), 2 (int) or 0.34 (double), but not strings like "hello". Section 7.6 discusses the argument types that can be provided in a method call for each parameter of simple type. Note the use of double's Parse in methods 12, 14 and 16 to convert into double values the strings used by the user.

### Logic of Determining the Maximum

To determine the maximum, we begin with the assumption that parameter x contains the largest value, so line 28 declares local variable maximum and initializes it with the value of parameter x. It is possible that y or z contains the largest value, so we compare each of these values with maximum. The if statement in lines 31–34 determines whether y is greater than maximum. If so, line 33 assigns y to maximum. The statement in lines 37–40 determines whether z is greater than maximum. At this point, the largest of the three values resides in maximum, so line 42 returns to value 19 where it's assigned to the variable result. When program control returns to the app where Maximum was called, Methods return at most one value; the returned value can be a type that contains one or more values (implemented as struct; Section 10.1).

### 7.4.3 Assembling strings with Concatenation

C allows strings to be created by assembling smaller strings into larger strings using operator + (or the compound assignment operator +=). This is known as string concatenation. When operands of operator + are string objects, the + operator creates a new string object containing copies of the characters in its left operand followed by copies of the characters in its right operand. For example, the expression "hello " + "there" creates the string "hello there" without disturbing the original strings.

In line 22, the expression "Maximum is: " + result uses operator + of types string and double. Every simple value has a ToString representation. When one of the + operands is a string, it is implicitly converted to a string, the two strings concatenated. In line 22, the double value is converted to its string representation and placed at the end of "Maximum is: ". If there are any trailing zeros in a double value, they are discarded. Thus, the string representation of 9.3500 is "9.35".

### Any Can Be Converted to a string

If a bool is concatenated with a string, the bool is converted to the string "True" or "False" (capitalized). Every object has a ToString method that returns a string representation of that object. When an object is concatenated with a string, the object's ToString method is called implicitly to obtain the string representation of the object. If the object is null, an empty string is written.

If a type does not have a ToString method, the default ToString implementation returns a string containing the fully qualified name—that is, the namespace in which the type is followed by a dot (.) and the type name (e.g., System.Object for the .NET class object). Each type you create a custom ToString method, as you'll see in Chapter 8 for a Card that represents a playing card in deck of cards.

### Formatting strings with String Interpolation

Line 22 of Fig. 7.3, of course, could also be written using string interpolation as:

```cs
Console.WriteLine($"Maximum is: {result}");
```

As string concatenation, using interpolation to insert an object into a string implicitly calls the object's ToString method to obtain the string representation.

### 7.4.4 Breaking Large string Literals

When a string literal or interpolated string is typed into an app's source code, you can break that string into several smaller strings and place them on multiple lines for readability. We discuss the details of string concatenation in Chapter 16.

- **Common Programming Error 7.3**: A syntax error to break a string literal or interpolated string across multiple lines of code. If a string does not fit on one line, you can split it into several smaller strings and use concatenation to form the desired string.
- **Common Programming Error 7.4**: Confusing the concatenation + operator with the addition + operator can lead to strange results. The + operator is left-associative. For example, if y has the int value 5, the expression "y + 2 = " + y results in the string "y + 2 = 52", not "y + 2 = 7", because the first value of y (s) is concatenated with the string "y + 2 = " then the value 2 is concatenated with the new string "y + 2 = 5" + (y + 2) produces the desired result "y + 2 = 7". ### 7.4.6 Implementing Maximum by Reusing Method.Max

Recall from Fig. 7.2 that Math's method can determine the larger of two values. The entire body of our maximum method could also be implemented with nested calls to Math.Max, as follows:

```cs
return Math.Max(x, Math.Max(y, z));
```

Before any method can be called, the runtime evaluates all arguments to determine their values. If an argument is a method call, the call must be performed to determine its return value. So, in the preceding statement, Math.Max(y, z) is evaluated to first determine the larger of y and z. then the result is passed as the second argument to the first Math.Max, which returns the larger of its arguments. Using Math.Max in this manner is a good example of software reuse—we find the largest of three values by reusing Math.Max, which finds the larger of two values. ## 7.5 Notes on Using Methods

### Three Ways to Call a Method

You've seen three ways to call a method:

- Using a method by name to call a method of the same class—as in line 19 of Fig. 7.3, which calls Maximum(number1,number2,number3) from Main.
- Using a reference to an object, followed by the member-access operator (.), and the method name to call a non-static method of the referred object—as in line 23 of Fig. 4.12, which each account1.Deposit(depositAmount) from the Main method of class AccountTest.
- Using the class name and the member-access operator (.), to call a static method of a class—as in lines 12–14 of Fig. 7.3, which each call Console.ReadLine(), or as in Math.Sqrt(900.0) in Section 7.3.

### Three Ways to Return from a Method

You've seen three ways to return control to the statement that a method:

- Reaching the method-ending right brace in a method with return type void.
- When the following statement executes in a method with return type void

```cs
return;
```

- When a method returns a result with a statement of the following form in which the expression is evaluated and its result (and control) are returned to the caller:

```cs
return expression;
```
