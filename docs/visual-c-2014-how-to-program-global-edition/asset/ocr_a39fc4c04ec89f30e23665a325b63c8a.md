# Class List

Class List (lines 30–161) contains instance variables firstNode and lastNodes in a list, respectively. The constructors (lines 37–44) initialize both to null and allow us to specify the List's name for output purposes. InsertFront (lines 49–59), InsertBack (lines 64–74), RemoveFront (lines 77–97) and RemoveBack (lines 100–130) are the primary methods of class List. IsEmpty (lines 133–16) is a predicate method—such a method checks and returns a boolean value without modifying the object that it's called. In this case, the method IsEmpty could also have been implemented as a getter-only property. If the list is empty, method IsEmpty returns false. Method Display (lines 139–160) displays the list's contents. A detailed discussion of List's methods follows Fig. 19.5.
