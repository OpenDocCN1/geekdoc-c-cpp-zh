# Software Engineering Observation 10.15

Overload operators to perform the same function or similar functions on objects as the operators perform on objects of simple types. Avoid nonintitive use of operators.

# Software Engineering Observation 10.16

At least one parameter of an overloaded operator must be of the type in which the operator is overloaded. This prevents you from changing how operators work on simple types.

# Software Engineering Observation 10.17

Though you cannot overload the arithmetic assignment operators (e.g., += and -=), C# allows you to use them with any type that declares the corresponding arithmetic operator (e.g., +, -).

class ComplexTest
