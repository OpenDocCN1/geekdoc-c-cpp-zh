# Self-Review Exercises

14.1 State whether each of the following is true or false. If false, explain why.

+   a) The KeyData property includes data about modifier keys.
b) A Form is a container.
c) All Forms, controls and controls are classes.
d) CheckBoxes are used to represent a set of mutually exclusive options.
e) A Label displays that a user running an app can edit.
f) Button presses generate events.
g) All events use the same event arguments.
h) Visual Studio can register an event and create an event handler.
i) The Number-down control is used to specify a range of input values.
j) A control's tool tip is set with the ToolTip property of class Control.

14.2 Fill in the blanks of the following statements:

+   a) The active control is said to have the focus.
b) The Form acts as a \_\_\_\_ for the controls that are added.
c) GUIs are \_\_\_\_ driven.
d) Every method that handles the event has the same \_\_\_\_.
e) A(n) TextBox handles user input with a character repeated.
f) Class and \_\_\_\_ help controls on a GUI and provide logical groups for radio buttons.
g) Typical events use \_\_\_\_ and \_\_\_\_.
h) Events are generated when a key on the keyboard is pressed or released.
i) The modifier keys are \_\_\_\_ and \_\_\_\_.
j) An(n) \_\_\_\_ can be used to call multiple methods.

# Answers To Self-Review Exercises

14.1 a) True; c) True; d) False. RadioButtons are used to represent a set of mutually exclusive options. e) False. A Label's text cannot be edited by the user. f) True; g) False. Some mouse event events use MouseEvents; h) True; j) False. A control's tool tip is set using a ToolTip property that must be added to the app.

14.2 a) focus; b) container; c) event; d) signature; e) password; f) GroupBox, Panel; g) mouse clicks, mouse moves; h) key; i) Shift, Ctrl, Alt; j) multicast.
