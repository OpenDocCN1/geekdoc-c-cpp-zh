**Step 9: Aligning the Label's Text**

Select the Label's TextAlign property, which determines how the text is aligned within the Label. A three-by-three grid of buttons representing alignment choices is displayed (Fig. 2.28). The position of each button corresponds to where the text appears in the Label. For this app, set the TextAlign property to MiddleCenter in the three-by-three grid—this selection centers the text horizontally and vertically within the Label.
