# 16.7 Extracting Substrings from strings

Class string provides two Substring methods, which create a new string by copying part of an existing string. Each method returns a new string. Figure 16.6 demonstrates both methods.

```
 // Fig. 16.6: SubString.cs
// Demonstrating the demonstrating string method.
using System;
class SubString
{
    static void Main()
{
        var letters = "abcdefghijklabcdefghijkl";
// invoke Substring method and pass it one parameter
        Console.WriteLine("Substring from index 20 to end is + $""{letters.Substring(20)}"");
// invoke Substring method and pass it two parameters
        Console.WriteLine("Substring from index 0 of length 6 is " + $""{letters.Substring(0, 6)}"");
    }
```

Substring from index 20 to end is "hijklm"
Substring from index 0 of length 6 is "abcdef"

16.6 | Demonstrating the demonstrating string method.

The statement in line 13 uses the Substring method that takes one argument. The argument specifies the starting index from which the method copies characters in the original string. The substring returned contains a copy of the characters from the starting index to the end of the string. If the index specified in the argument is outside the bounds of the string, the method throws an ArgumentOutOfRangeException.

The second version of Substring (line 17) takes two arguments. The first argument specifies the starting index from which the method copies characters from the original string. The second argument specifies the length of the substring to copy. The substring returned contains a copy of the characters from the original string. The supplied length of the substring is too large (i.e., the substring tries to retrieve characters past the end of the original string), an ArgumentOutOfRangeException is thrown.
