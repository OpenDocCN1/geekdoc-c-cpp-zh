### Processing a Two-Dimensional Array with a foreach Statement

Methods GetMinimum, GetMaximum and OutputChart each loop through array grades using the foreach statement—example, the foreach statement method GetMinimum (lines 50–57). To find the lowest overall grade, this statement iterates through rectangular array grades and compares each element to variable lowGrade. If a grade is less than one, lowGrade is set to that grade.

When the foreach statement traverses the elements of array grades, it looks at each element of the first row in order by index, and so on. The foreach statement (lines 50–57) traverses the elements of grades in the second row in the same order as the following equivalent code, expressed with nested statements:

```csharp
for (var row = 0; row < grades.GetLength(0); ++row)
  for (var column = 0; column < grades.GetLength(1); ++column)
    if (grades[row, column] < lowGrade)
      lowGrade = grades[row, column];
```

When the foreach statement completes, lowGrade contains the lowest grade in the rectangular array. Method GetMaximum works similarly to method GetMinimum. Note the simplicity of using foreach, vs the preceding nested statement for.

## 8.11 Variable-Argument Lists

Variable-length argument lists allows you to create methods that receive an arbitrary number of arguments. A one-dimensional array-type argument preceded by the keyword params in a parameter list indicates that the method receives a variable number of arguments with the type of the array. This use of params modifier can occur only in the parameter list's last parameter. While you can use method overloading and array passing to accomplish what is possible with variable-length lists, using the params modifier is more concise.

## 8.11 Variable-Argument Lists

Figure 8.23 demonstrates method Average (lines 8–19), which receives a variable-length sequence of doubles (line 8). C# treats the variable-argument list as a one-dimensional array whose elements are all of the same type. Hence, the method body can manipulate the parameters as an array of doubles. Lines 13–16 use the foreach loop to walk through the array and calculate the total of the doubles in the array. Line 18 accesses numbers.Length to obtain the size of the numbers for use in the calculation. Lines 30, 32 and 34 in Main call method Average with two, three and four arguments, respectively. Method Average has a variable-argument list, so it can average as many doubles as the caller passes. The output reveals that each call to method Average returns the correct value.

### Common Programming Error 8.7

The params modifier may be used only with the last parameter of the parameter list.

```csharp
// Fig. 8.23: ParamArrayTest.cs
// Using variable-length argument lists.
using System;
class ParamArrayTest
{
    // calculate average
    static double Average(params double[] numbers)
    {
        var total = 0.0; // initialize total
        // calculate total using the foreach statement
        foreach (var d in numbers)
        {
            total += d;
        }
        return numbers.Length != 0 ? total / numbers.Length : 0.0;
    }
    static void Main()
    {
        var d1 = 10.0;
        var d2 = 20.0;
        var d3 = 30.0;
        var d4 = 40.0;
        Console.WriteLine($"d1={d1:F1}\nd2={d2:F1}\nd3={d3:F1}\nd4={d4:F1}\n");
        Console.WriteLine($"Average of d1 and d2 is {Average(d1, d2):F1}");
        Console.WriteLine($"Average of d1, d2 and d3 is {Average(d1, d2, d3):F1}");
        Console.WriteLine($"Average of d1, d2, d3 and d4 is {Average(d1, d2, d3, d4):F1}");
    }
}
```
