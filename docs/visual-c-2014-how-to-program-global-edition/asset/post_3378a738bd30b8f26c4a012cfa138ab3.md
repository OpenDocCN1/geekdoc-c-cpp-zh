CommissionEmployee's attributes include public, getter-only, auto-implemented properties FirstName, LastName and SocialSecurityNumber, and private instance variables grossSales and commissionRate. The class provides:

## CommissionEmployee Constructor

Constructors are not inherited, so class CommissionEmployee does not inherit class object's constructor. However, class CommissionEmployee's constructor calls object's constructor implicitly. In fact, before executing the code in its own body, every derived class's constructor calls a constructor in its direct base class, either explicitly or implicitly (if no constructor is specified), to ensure the instance variables inherited from the base class are properly initialized.

Calling a base-class constructor is explicitly discussed in Section 11.4.3. If the code does not explicitly call the base-class constructor, the compiler generates an implicit call to the base's default or parameterized constructor, or a constructor with default arguments. The comment in line 18 indicates where the implicit call to the base class's constructor is made (you do not write the code for this call). Even if a class does not have constructors, the default constructor that the compiler implicitly declares for the class will call the base's default or parameterized constructor. Object is the only class that does not have a base class.

After the implicit call to object's constructor occurs, lines 19–23 in the constructor assign values to the class properties. We do not validate the values of arguments FirstName, lastName and socialSecurityNumber. We could validate the first and last name—by ensuring they're of a reasonable length. Similarly, a social security number could be validated to ensure that it contains nine digits, with or without dashes (e.g., 123-45-6789 or 123456789).

## CommissionEmployee Method ToString

Method ToString (lines 68–72) is special—it's one of the methods that every class inherits directly or indirectly from Object. Method ToString returns a string representing an object. It can be called explicitly, but it's called implicitly whenever an object must be converted to a string, such as when displaying an object with Console.Write or WriteLine or inserting an object in string interpolation expression. By default, class object's ToString method returns the fully qualified name in the System namespace. ToString is primarily a placeholder that can (and should be) overridden by a derived class to specify an appropriate string representation of the data in a derived class. Method ToString of CommissionEmployee (redefines) overrides object's ToString method. When invoked, CommissionEmployee's ToString method returns a string containing information about the object. Line 71 uses the format specifier C in ("grossSales:C}") to format grossSales as currency and line 72 uses the format specifier F2 in ("{commissionRate:F2}") to format commissionRate with two digits to the right of the decimal point.

## Programming Error

It's a compilation error to override a method with a different access modifier. Overriding a method with a more restrictive access modifier would break the relationship. The derived classes would not be able to respond to the same method as base-class objects. In particular, once a method is declared in a base class, the method must have the same access modifier for all direct and derived classes.
