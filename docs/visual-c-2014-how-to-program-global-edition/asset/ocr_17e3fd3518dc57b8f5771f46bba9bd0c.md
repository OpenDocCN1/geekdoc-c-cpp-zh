When this is compiled, the compiler generates error messages stating that these private members are not accessible.

```
// Fig. 10.3: MemberAccessTest.cs
// Private members are not accessible outside the class.
class MemberAccessTest {
    static void Main() {
        var time = new Time1(); // create and initialize Time1 object
        time.hour = 7; // error: hour has private access in Time1
        time.minute = 15; // error: minute has private access in Time1
        time.second = 30; // error: second has private access in Time1
    }
```

# 10.4 Referring to the Current Object’s Members with the Reference

Every object can access a reference to itself with keyword this (also called this reference). When a non-static method (or property) is called for a particular object, the method's body implicitly uses this keyword to refer to the object's instance variables and non-static class members.
