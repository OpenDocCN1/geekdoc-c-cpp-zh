# Methods ProcessGrades and OutputGrades

ProcessGrades (Fig. 8.15, lines 29–43) contains a series of method calls that result in a report summarizing the grades. Line 32 calls method OutputGrades to display the contents of array grades. Lines 139–143 in method OutputGrades use for a statement to output the student grades. We use for a statement, rather than a foreach, because lines 141–142 counter variable student's value to output each grade to a particular student number (Fig. 8.14). Although index starts at 0, an instructor would typically use student numbers starting at 1. Thus, lines 141–142 output student + 1 the student number to produce grade labels "Student 1: "Student 2: " and so on.
