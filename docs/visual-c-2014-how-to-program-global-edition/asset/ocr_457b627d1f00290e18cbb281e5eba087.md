# 14.4 Control Properties and Layout

This section covers properties that are common to many controls. Controls derive from class Control (namespace System.Windows.Forms). Figure 14.11 lists some of Control's properties and methods. The properties shown can be set for many controls. For example, the Text property specifies the text that appears on a control. The location of this text varies depending on the control. In a Form, the text appears in the title bar, and the text of a Button appears on its face.
