> Software Engineering Observation 1.I
In most cases, it's not necessary to make a copy of an existing string. All strings are immutable;their characters cannot be changed after they are created. Also, if there are one or more references to a string (or any reference-type object for matter), the object cannot be reclaimed by the garbage collector.
