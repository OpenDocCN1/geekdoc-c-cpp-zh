# 14.1 Introduction

A graphical user interface (GUI) allows a user to interact visually with a program. A GUI
pronounced 'GOO-ee' gives a distinctive 'look' and 'feel.

> Look-and-Feel-Observation 14.1
Consistent user interfaces enable a user to learn new apps more quickly because the open files.
have the same 'look' and 'feel.

As an example of a GUI, consider Fig. 14.1, which shows a Visual Studio window
containing GUI controls. Near the top, a menu bar containing the menus
File, Edit, View. Below is a tab bar of buttons, with a defined task, such as
creating a new project or opening a file. Below is that tab representing a currently open
file—this tabbed view allows to switch between the open files. These controls form a
user-friendly interface through which you are interacting with the IDE.

GUIs are built from GUI controls (which are sometimes components or wid-
gets—short for window gadgets). GUI controls are objects that display information
on the screen or allow users to interact with an app via the mouse, keyboard or some other
form of input (such as voice commands). Several common GUI controls are listed in
Fig. 14.2—in the sections that follow and in Chapter 15, we discuss each of these in detail.
Chapter 15 explores the features and properties of additional GUI controls.
