Fig. 15.23 | Using ComboBox to select a shape to draw. (Part 3 of 3.)

After creating ComboBox imageComboBox, make it uneditable by setting its DropDown-Style to DropList in the Properties window. Next, add items Circle, Square, Ellipse, Pie, Filled Square, Filled Ellipse and Filled Pie to the Items collection using the String Collection Editor. Whenever the user selects an item from imageComboBox, a SelectedChanged event occurs and event handler ComboBox_SelectedChanged (19–65) executes. Lines 23–29 create a Graphics object, and a SolidBrush, which are used to draw the form—each is an IDisposable object, so a using statement ensures disposal at the end of the event handler. The Graphics object (line 23) allows a pen or brush to draw a component, using one of several methods. The Pen object (line 26) is used by DrawEllipse, DrawRectangle and DrawPie (lines 38, 41, 44 and 47) to draw the outlines of their corresponding shapes. The SolidBrush object (line 29) is used by methods FillEllipse, FillRectangle and FillPie (lines 50–53, 55 and 60) to fill their solid shapes. Line 32 colors the entire FormWhite, using methods Clear.
