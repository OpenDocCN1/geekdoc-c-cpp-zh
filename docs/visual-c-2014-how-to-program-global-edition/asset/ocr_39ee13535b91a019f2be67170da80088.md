# Terminology 703

+   - A programmer can create a brand-new control by inheriting from class Control. This class does not define any specific behavior; task is left to you.

+   - Timers are non-visual components that generate Tick events at a interval. This interval is set by the Timer's Interval property, which defines the number of milliseconds (thousands of a second) between events. Timers are disabled by default.
