16.8 (Project: Cooking with Healthier Ingredients) Obesity in the United States is increasing at an alarming rate. Check the map from the Centers for Disease Control and Prevention (CDC) at http://www.obesity.gov/adult-obesity/ which shows obesity trends in the United States over the last 20 years. As obesity increases, so occurrences of related problems (e.g., heart disease, high blood pressure, high cholesterol, type 2 diabetes). Write a program that helps users choose healthier ingredients when cooking a recipe, and helps those allergic to certain foods (e.g., nuts, gluten) find substitutes. The program should read the recipe from the user and suggest replacements for some of the ingredients. For simplicity, your program should assume the recipe has no abbreviations for measures as teaspoons, cups, and tablespoons, and uses numerical digits for quantities (e.g., 1 egg, 2 cups) rather than spelling them out (one egg, two cups). 16.9 (Project: Spam Scanner) Spam (or j-mail) costs U.S. organizations billions of dollars a year in spam-prevention software, network resources, bandwidth, and lost productivity. Research online for the most common spam words and check your own e-mail folder. Create a list of 30 words and phrases commonly found in spam messages. Write an app in which the user enters an e-message. Then, scan the message for each of the 30 keywords or phrases. For each occurrence of one of these within the message, add a point to the message's 'spam score.' Next, the likelihood that the message is spam, based on the number of points it received.

16.10 (Project: SMS Language) Short Message Service (SMS) is a communications service that allows sending text messages of 160 or fewer characters between mobile phones. With the proliferation of mobile phone users worldwide, SMS is being used in developing nations for political purposes (e.g., voicing opinions and opposition), reporting news about natural disasters, and so on. For example, check automata.org/radio2.0/archives/87. Since the length of SMS messages is limited, SMS Language—abbreviations of common words and phrases in mobile text messages, emails, instant messages,etc.—is often used. For example, "in my opinion" is "IMO" in SMS Language. Research SMS Language online. Write a program in which the user can enter a message using SMS Language, then the program translates it into English (or your own language). Also provide a mechanism to translate text written in English (or your own language) into SMS Language. One potential problem is that one SMS abbreviation could expand into a variety of phrases. For example, IMO (as used above) could also stand for "International Maritime Organization," "in memory of," etc.
