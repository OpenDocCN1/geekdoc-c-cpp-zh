# ### Common Programming Error 21.1

> > If a collection is modified after an enumerator is created for that collection, the enumerator immediately becomes invalid—for this reason, enumerators are said to be "fail fast". Any calls to its Reset or MoveNext methods after this point throw InvalidOperationException. This is true for collections, but not for arrays.

When an enumerator is returned by the GetEnumerator method in line 51, it's initially positioned before the first element in Array doubleValues. When line 53 calls MoveNext advances to the first element in doubleValues. The while loop, in lines 53–56 iterates over each element until the enumerator passes the end of doubleValues and MoveNext returns false. In this iteration, we use the enumerator's Current property to obtain and output the current element. Lines 63–66 iterate over array intValues.

# ## 21.3.7 Iterating Over a Collection with foreach

Lines 71-74 use a foreach statement to iterate over the collection. Both foreach and an enumerator loop over the elements of an array by one in consecutive order. Neither allows you to modify the elements during the iteration. This is not a coincidence. Every foreach statement implicitly obtains an enumerator via the GetEnumerator method and uses the enumerator's MoveNext method and Current property to traverse the collection, just as we did explicitly in lines 51–55 and 61–66. For this reason, you should use the foreach statement to iterate over any collection that implements IEnumerable<T> or IEnumerable<char>—as you saw for List<T> in Section 9.4. Even class string implements IEnumerable over a string's characters.

# ## 21.3.8 Array Methods, IndexOf, LastIndexOf and Reverse

Other Array methods include:

+   * Clear sets a range of elements to 0, false or null, as appropriate.

+   * IndexOf locates the first occurrence of an object in an array or portion of an array.

+   * LastIndexOf locates the last occurrence of an object in an array or portion of an array.

+   * Reverse reverses the contents of an array or portion of an array.
