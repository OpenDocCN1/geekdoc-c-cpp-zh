Lines 45-48 filter the odd integers in values, multiply each odd integer by 10, sort the values in ascending order and display the results. This new feature is the mapping operation that takes each value and multiplies it by 10. Mapping transforms a collection's elements to new values, which sometimes are different from the original elements.

LINQ extension method Select receives as its argument a Func delegate for a method that receive one argument and maps it to a value (possibly of another type)s included in the collection returned by Select. The lambda in line 46:

Today's customers are likely to have multiple processors with four or eight cores. One vendor offers a 61-core processor² and future processors are likely to have more cores. Your computer's operating system shares the cores among operating system tasks and the apps running at a given time.

# Threads

A concept threads enables the system to run parts of an concurrent thread—for example, using the user-interface thread (commonly called the GUI thread) waits for the user to interact with a GUI control, separate threads in the same app could be forming tasks like complex calculations, downloading a video, playing music, sending an e-mail, etc. Though all of these tasks can make progress concurrently, they may do so by sharing one processor core.

# Sharing Processors

With multicore processors, apps can operate truly in parallel (that is, simultaneously) on separate cores. In addition, the operating system can allow one app's threads to operate in parallel on separate cores, possibly increasing the app's performance substantially. Parallelizing apps and algorithms to take advantage of multiple cores is difficult and highly error prone, especially if those threads share data that can be modified by one or more of the tasks.
