# 23.6.5 Asynchronously Downloading an Image's Bytes

Method imagesListBox_SelectedIndexChanged (lines 99–115) is declared async because it awaits an asynchronous download of a photo. Lines 104–105 get the URL of the selected ListBox item. Then 108–109 invoke HttpClient.GetByteArrayAsync, which gets a byte array containing the photo. The method uses the URL specified in the method's argument to request the photo from Flickr and returns a Task<byte[]>— promise to return a byte[] once the task completes. The event handler returns the result. When the Task completes, the await expression returns the tuple. Line 112 creates a MemoryStream from the byte[] (which allows reading bytes as a stream from an array), then line 113 uses the Class's static FromStream method to create an Image from the byte array and assign it to the Picture-Box's Image property to display the selected photo.
