## 17.5 Case Study: Credit-Inquiry Program

To retrieve data sequentially from a file, programs normally start from the beginning of the file, reading consecutively until the desired data is found. It is sometimes necessary to process a file several times (from the beginning of the file) during the execution of a program. A FileStream object can reposition the position-pointer (which contains the byte number of the text to be read from or written to the file) to any position in the file. When a FileStream object is opened, the position-pointer is set to position 0 (i.e., the beginning of the file).

We now present a program that builds on the concepts employed in Fig. 17.6. Class CreditInquiryForm (17.7) is a credit-inquiry program that enables a credit manager to search and display account information for customers with credit balances (i.e., customers to whom the company owes money), zero balances (i.e., customers who do not owe the company money) and debt balances (i.e., customers who owe the money for previously received goods and services). We use a RichTextBox in the program to display more functionality than regular TextBoxes—for example, RichTextBox offer better Find for searching virtual strings and LoadFile for displaying file contents. RichTextBox and TextBox both inherit from abstract class System.Windows.TextBase. In this example, we use a RichTextBox, because it displays multiple lines of text by default, whereas a regular TextBox displays only one line. Alternatively, we could have specified that a TextBox object display multiple lines of text by setting its Multiline property to.

The program displays buttons that enable a credit manager to obtain credit information. The Open button opens a file for getting data. The Credit Balance buttons display a list of accounts that have credit balances, the Debit Balance buttons display a list of accounts that have debt balances and the Zero Balance button displays a list of accounts that have zero balances. The Done button exits the app.

```
// Fig. 17.7: CreditInquiryForm.cs
// Read a file sequentially and display contents based on
// account type specified by user (credit, debit or zero balances)
using System;
using System.Windows.Forms;
using System.IO;
using BankLibrary;

namespace CreditInquiry
{
    public partial class CreditInquiryForm : Form
    {
        private FileStream input; // maintains the connection to the file
        private StreamReader FileReader; // reads data from text file

        // parameterless constructor
        public CreditInquiry()
        {
            InitializeComponent();
        }

        // invoked when user clicks Open button
        private void onClick_Click(object sender, EventArgs e)
        {
            // create dialog box enabling user to open file
            DialogResult result;
            string fileName;

            using (OpenFileDialog chooser = new OpenFileDialog())
            {
                result = chooser.ShowDialog();
                fileName = chooser.FileName;
            }

            // exit event handler if user clicked Cancel
            if (result == DialogResult.OK)
            {
                // show error if user specified invalid file
                if (string.IsNullOrEmpty(fileName))
                {
                    MessageBox.Show("Invalid File", "Error", MessageBoxButtons.OK, MessageBox.Error);
                }
                else
                {
                    // create FileStream to obtain read to file
                    input = new FileStream(fileName, FileMode.Open, FileAccess.Read);
                    FileReader = new StreamReader(input);
                }
                // set file where data is read
                FileReader = new StreamReader(input);
            }
        }

        // enable all buttons, except for Open button
        openButton.Enabled = false;
        creditButton.Enabled = true;
        debitButton.Enabled = true;
        zeroButton.Enabled = true;

        try {
            displayTextBox.AppendText($"{record.Account}\t" +
                                     $"{record.FirstName}\t{record.LastName}\t" +
                                     $"{record.Balance:C}{Environment.NewLine}");
        }
        catch (IOException)
        {
            MessageBox.Show("Cannot Read File", "Error", MessageBoxButtons.OK, MessageBox.Error);
        }

        // determine whether to display record
        private bool ShouldDisplay(decimal balance, string accountType)
        {
            if (balance > 0 && accountType == "Credit Balances")
            {
                return true; // should display credit balances
            }
            else if (balance < 0 && accountType == "Debit Balances")
            {
                return true; // should display debit balances
            }
            else if (balance == 0 && accountType == "Zero Balances")
            {
                return true; // should display zero balances
            }
            return false;
        }

        // invoked when user clicks Done button
        private void doneButton_Click(object sender, EventArgs e)
        {
            // close file and StreamReader
            try
            {
                fileReader.Close(); // close StreamReader and underlying file
            }
            catch (IOException)
            {
                // notify user of error closing file
                MessageBox.Show("Cannot close file", "Error", MessageBoxButtons.OK, MessageBox.Error);
            }
            Application.Exit();
        }
    }
}
```
