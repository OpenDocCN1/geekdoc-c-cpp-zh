# Chapter 17 Files and Streams

+   - Directory method GetDirectories obtains a string array containing the names of subdirectories in the specified directory.

+   - Dictionary method GetFiles returns a string array containing filenames in the specified directory.

+   - Path method GetExtension returns the extension for the specified filename.

+   - A Dictionary (namespace System.Collections.Generic) is a collection of key–value pairs, in which each has a corresponding value. Class Dictionary is a generic class like List.

+   - Dictionary method ContainsKey determines whether the key exists in the Dictionary.

+   - Dictionary method Add inserts a key–value pair into a Dictionary.

+   - File method Delete removes the specified file from disk.

+   - Dictionary property Keys returns all the keys in a Dictionary.

+   - Dictionary method Clear deletes the contents of a Dictionary.

+   - LINQ's group by enables you to group query results into collections.
