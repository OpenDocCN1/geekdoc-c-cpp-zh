# Answers to Self-Review Exercises

22.1 a rows, b primary key, c DbContext, d GridView, e joining, f foreign key, g BindingSource, h DataSource.

22.2 a Multiple rows can have the same value for a foreign key. Providing the same value for the primary key in multiple rows causes the DBMS to report an error, because duplicate keys would prevent each row from being identified uniquely. b True. False A Binding object allows users to browse and manipulate data displayed by any GUI control. A DbContext allows to extract data from a database. e False. You must use the Changeset method of DbContext to save the changes made back to the database.
