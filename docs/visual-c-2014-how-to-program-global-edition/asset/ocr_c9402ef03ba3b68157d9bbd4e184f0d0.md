> Software Engineering Observation 10.14
If readonly instance variable is initialized to a constant only in its declaration, it’s not necessary to have a separate copy of the instance variable for every object of the class. The variable should be declared const. Constants declared with const are implicitly static, so there will be only one copy for the entire class.

C# Getter-Auto-Implemented Properties and readonly
Section 8.6.1 introduced C# getter's getter-auto-implemented properties. When an auto-implemented property has only a getter accessor, the property can be used only to read the value, so the compiler implicitly declares the corresponding private instance variable as readonly. Getter-auto-implemented properties can be initialized in their declarations or constructors.

# 10.11 Class View and Object Browser

Now that we have introduced key concepts of object-oriented programming, we present two Visual Studio features that facilitate the design of object-oriented apps—the Class View and the Object Browser.

# 10.11.1 Using the Class View Window

The Class View displays the fields, methods and properties for all classes in a project. Select View > Class to display the Class View as a tab in the same position within the IDE as the Solution Explorer.
