The set of characters that a computer uses and the corresponding integer representations for these characters is called computer's character set. You can indicate a character value in an app by enclosing the character in single quotes, as in 'A'.

You can determine the integer equivalent of a character by preceding that character with (int), 'A'

The keyword int in parentheses is known as a cast operator, and this expression is called a cast expression (You'll learn about cast operators in Chapter 5). The following statement outputs a character and its integer equivalent:

```
Console.WriteLine("The character {A} has the value {(int)A}");
```

When the preceding statement executes, it displays the character A and the value 65 as of the string. See Appendix C for a list of characters and their integer equivalents.
