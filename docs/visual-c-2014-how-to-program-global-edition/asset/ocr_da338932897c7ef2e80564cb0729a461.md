6.21 (Pythagorean Triples) A right triangle has sides whose lengths are all integers. The set of three integer values for the sides of a right triangle is called a Pythagorean triple (http://en.wikipedia.org/wiki/Pythagorean_triple). This set must satisfy the relationship that the sum of the squares of two sides is equal to the square of the hypotenuse. Write an app to find all Pythagorean triples for s1, s2 and the hypotenuse, no larger than 500. Use a triple-loop for test all possibilities. This is an example of "brute-force" computing. You'll learn in more advanced computer science that there are no known algorithmic approach other than using brute force.
