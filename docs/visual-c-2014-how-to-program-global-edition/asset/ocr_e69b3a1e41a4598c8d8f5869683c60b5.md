The brush's properties, selected in the RadioButtons labeled Black and Medium, are default settings—the initial settings you see when you run the app. Programs include default settings to provide reasonable choices that the app will use if the user does not change the settings. Default settings also provide visual cues for users to choose their own settings. Now you'll choose your own settings as a user of this app.

# Step 4: Changing the Brush Color

Click the RadioButton labeled Red to change the brush color, then click the RadioButton Small to change the brush size. Position the mouse over the white Panel1, then drag the mouse to draw with the brush. Draw flower petals, as shown in Fig. 1.11.
