# 3.8.5 Redundant Parentheses

As in algebra, it's acceptable to use unnecessary parentheses in an expression to make the expression clear. These are called redundant parentheses. For example, the second-degree polynomial assignment statement might be parenthesized to highlight its terms as follows:

```
y = (a * x * x) + (b * x * x) + c;
```
