# 15.8 ComboBox Control

The ComboBox control combines TextBox features with a drop down list—a GUI component that contains a list from which a value can be selected. A ComboBox usually appears as a TextBox with an arrow to right. By default, the user can enter into the TextBox or click the down arrow to display a list of predefined items. If a user chooses an element from it, that element is displayed in the TextBox. If the list contains more elements than can be displayed in the drop-down list, a scrollbar appears. The maximum number of items that a drop-down list can display at one time is set by property MaxDownItems. Figure 15.21 shows a sample ComboBox in three different states.

> Look-and-Feel Observation 15.4
Use a ComboBox to save space on a GUI. A disadvantage is that, unlike with a ListBox, the user cannot see items without expanding the drop-down list.

Property DropDropDownStyle determines the type of ComboBox and is represented as a value of the ComboBoxStyle enumeration, which contains values Simple, DropDown and DropList. Simple does not display a drop-down arrow. Instead, the Com is tall enough to display a list of items, they are shown vertically—possibly with a scrollbar to allow the user to view items that cannot fit in the display. The user can also type in a style. Style DropDown (the default) displays a drop-down list when the down arrow is clicked (or the down arrow is pressed). The user can type a new item in the ComboBox. The last style is DropList, which displays a drop-down list but does not allow the user to type in the TextBox.
