**Class Employee**
Consider Employee's declaration (Fig. 12.4). The class includes auto-implemented, getter-properties for the first name, last name and social security number (lines 5–7); a constructor that initializes the first name, last name and social security number (lines 10–16); expression-bodied method ToString which uses properties to return an Employee's string representation; and abstract method Earnings (line 23), which must be implemented by concrete classes. The Employee constructor does not validate the social security number in this example. Normally, such validation should be provided.
