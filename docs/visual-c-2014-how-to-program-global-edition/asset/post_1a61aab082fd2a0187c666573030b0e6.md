## Timers

Timers (System.Windows.Forms namespace) are non-visual components that generate Tick events at set interval. This interval is set by the Timer's Interval property, defines the number of milliseconds (thousands of a second) between events. By default, timers are disabled and do not generate events.

## Sharing Custom Controls with Other Developers

Visual Studio allows you to share custom controls with other developers. To create a User-Control that can be exported to other solutions, do the following:

- 1. Create a new Class Library project.
- 2. Delete Class1.cs, initially provided with the app.
- 3. Right click the project in the Solution Explorer and select Add > User Control.... In the dialog that appears, name the user-control and click Add.
- 4. Inside the project, add controls and functionality to the UserControl (Fig. 15.51).

![](img/57baed2319be0bb1b5f98674846f2711_699_0.png)

Fig. 15.51 | Custom-control creation.

- 5. Build the project. Visual Studio creates a .dll file for the UserControl in the output directory (bin/Debug or bin/Release). The file is not executable; class libraries are used to define classes that are used in other executable apps. You can give the .dll file to other developers and they can follow Steps 6 and 7.
- 6. Create a new Windows app.
- 7. In the new Windows app, right click the Toolbox and select Choose Items.... In the Choose Items dialog that appears, click Browse.... for the .dll file from the class library created in Steps 1–5. The item will then appear in the .NET Framework Components tab of the Choose Items dialog. If it's not already checked, check this item. Click OK to add it to the Toolbox. This control can now be added to the Form as if it were any control.

## Summary

### 15.2 Menus

- Menus provide groups of related commands for Windows Forms.
- An expanded menu lists menu items and submenus.
- A menu that contains a menu item is called menu item's parent. A menu item that contains a submenu is considered to be the parent of submenu.
- All menus and menu items have shortcut keys.
- Some menu items display checkmarks, indicating that multiple options on the menu can be selected.
- The MenuStrip control is used to create menus in a GUI.
- Top-level menus and their items are represented using ToolStripMenuItem.
- To create an anchor shortcut, use an ampersand (&) before the character to be underlined.
- To add other shortcut keys, set the ShortcutKeys property of the ToolStripMenuItem.
- You can hide shortcut keys by setting ShowShortcutKeys to false. You may modify how shortcut keys are displayed in the menu by modifying ShortcutKeyDisplayStyle.
- A menu item's Checked property is used to display to the left of the menu item.

### 15.3 MonthCalendar Control

- The MonthCalendar control displays a monthly calendar.
- The user can select a date from the currently displayed month or navigate to another month.
- A MonthCalendar's DateChanged occurs when a new date is selected.

### 15.4 DateTimePicker Control

- The DateTimePicker control is used to retrieve date/or time information from the user.
- Property Format of class DateTime specifies the user's selection options.
- The DateTimePicker's ValueChanged event is raised when the selected value is changed.

### 15.5 LinkLabel Control

- The LinkLabel displays links to other resources, such as files or web pages.
- A LinkLabel appears as an underlined text (colored blue by default). When the mouse moves over the link, the pointer changes to a hand; this is similar to a hyperlink in a web page.
- The link can change color to indicate whether the link is new, visited or active.
- When clicked, the LinkLabel generates a LinkClicked event.

### 15.6 ListBox Control

- The ListBox allows the user to view and select items in a list.
