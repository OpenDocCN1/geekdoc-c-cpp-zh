# Chapter 19 Custom Linked Data Structures

```
// test class Tree
static void Main()\{
    Tree tree = new Tree();
    Console.WriteLine("Inserting values: ");
    Random random = new Random();

    // insert 10 random integers from 0-99
    for (var i = 0; i <= 10; i++) {
        int insertValue = random.Next(100);
        Console.WriteLine($"{insertValue}");
        tree.Insert(insertValue);
    }

    // perform preorder traversal of tree
    Console.WriteLine("\npreorder traversal");
    tree.PreorderTraversal();

    // perform inorder traversal of tree
    Console.WriteLine("\ninorder traversal");
    tree.InorderTraversal();

    // perform postorder traversal of tree
    Console.WriteLine("\npostorder traversal");
    tree.PostorderTraversal();
    Console.WriteLine();
}
```
