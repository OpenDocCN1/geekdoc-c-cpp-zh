### 14.4.1 Anchoring and Docking

You can anchor and dock to specify the layout of controls inside a container—such as a Form, or within a Form, a control that groups other controls (such as a Panel, discussed in Section 14.6). Anchoring places controls a fixed distance from the sides of the container. For example, if the user expects a control to appear in a particular corner of the app, anchoring ensures that the control will be in that corner—even if the user resizes the Form. Docking attaches a control to a container such that the control stretches across an edge or fills an entire area. For example, a control as a status bar typically should remain at the bottom of the Form and stretch across the entire bottom of Form, regardless of the Form's width. When the part resized, the docked control resizes as well.

A Control's Dock and Anchor properties are set with respect to the container in which the Control resides—known as the parent container—which could be a Form or another container. The minimum and maximum (or other Control) sizes can be set via properties MinimumSize and MaximumSize. Both are of type Size, which have Width and Height. Properties MinimumSize and MaximumSize allow you to design the GUI layout for a size range. The user cannot make a Form smaller than the size specified by property MinimumSize and make Form larger than the size specified by property MaximumSize. To set a Form to a fixed size (where the Form cannot be resized by the user), set its minimum and maximum size to the same value.
