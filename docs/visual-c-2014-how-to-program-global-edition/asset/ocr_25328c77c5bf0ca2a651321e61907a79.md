# 1.1 Introduction

Welcome to C#—a powerful computer-programming language that's easy for novices to learn and that professionals use to build substantial computer applications. Using this, you will write instructions commanding computers to perform tasks. Software (i.e., the instructions you write) controls hardware (i.e., computers and related devices).

There are billions of people with computers at their core. An even number of mobile devices Since it was released in 2001, C# has been used widely to build applications for mobile computers and systems that support them. The explosive growth of mobile phones, tablets and other devices is creating significant opportunities for mobile apps. With this sixth edition of Visual C# How to Program, you will be able to use Microsoft's new Universal Windows Platform (UWP) to build C# apps for both personal computers and Windows 10 mobile devices. With Microsoft's purchase of Xamarinamar, you can also develop C# mobile apps for Android devices and for iOS devices, such as iPhones and iPads.
