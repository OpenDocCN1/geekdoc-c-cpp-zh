```csharp
// determine average grade for test
public double GetAverage()
{
    var total = 0.0; // initialize total as a double
    // students' grades
    foreach (var grade in grades) {
        total += grade;
    }
    // return average of grades
    return total / grades.Length;
}
```

```csharp
// output bar chart displaying grade distribution
public void OutputBarChart()
{
    Console.WriteLine("Grade distribution:");
    
    // stores frequency of grades in each range of 10 grades
    var frequency = new int[11];
    
    // for each grade, increment the appropriate frequency
    foreach (var grade in grades) {
        frequency[grade / 10];
    }
    
    // for each grade, display bar in chart
    for (var count = 0; count < frequency.Length; ++count) {
        // output bar label ("00-09: ", ..., "90-99:", "100: ")
        if (count == 10)
            Console.Write($"{count * 100:D2}: ");
        else
            Console.Write($"{count * 10:D2}-{count * 10 + 9:D2}: ");
    }
}
```

The constructor (14–18) creates the name of the console and an array of grades. When an app (e.g., GradeBookTest in 8.16) creates an array it passes the array's reference to the constructor, as many grades as are in the caller. The value passed in the array could have been input from the user at the keyboard or read from a file (as discussed in Chapter 17). In our test app, we simply initialize an array with a set of grade values (Fig. 8.16, line 9). Once the grades are stored in instance variables of GradeBook, all the class's methods access the elements of grades as needed to perform various calculations.

Methods ProcessGrades and OutputGrades

ProcessGrades (Fig. 8.15, lines 29–43) contains a series of method calls that result in a report summarizing the grades. Line 32 calls method OutputGrades to display the contents of array. Lines 139–143 in method OutputGrades use for statement to output the student grades. We use for statement rather than than, because lines 141–142 counter variable's value to output each grade to a particular student number (Fig. 8.14). Although index starts at 0, an instructor would typically use student numbers starting at 1. Thus, lines 141–142 output student + 1 the student number to produce labels "Student 1: ", "Student 2: " and so on.

Method GetAverage

ProcessGrades calls method GetAverage (line 35) to obtain the average of grades in the array. Method GetAverage (lines 82–94) use a statement to total values in array grades before calculating the average. The iteration variable in the foreach's header indicates that for each iteration, grade takes on a value in array grades. The average calculation in line 93 uses grades.Length to determine the number of grades being averaged. That we initialized total as a double (0.0), so no cast is necessary.

Methods GetMinimum and GetMaximum

Lines 38–39 in ProcessGrades calls GetMinimum and GetMaximum to determine the lowest and highest grades of any student on the exam, respectively. Each of these methods uses a statement to loop through array grades. Lines 51–58 in GetMinimum loop through array, and lines 54–57 compare each grade to lowGrade. If a grade is less than lowGrade, lowGrade is set to grade. When line 60 executes, lowGrade contains the lowest grade in the array. GetMaximum (lines 64–79) works the same way as GetMinimum.

Method OutputBarChart

Finally, line 42 in ProcessGrades calls OutputBarChart to display a chart of the grade data, using a similar technique to that in Fig. 8.7. In this example, lines 102–108 use a similar technique to that in Figs. 8.8 and 8.9 to calculate the frequency of grades in each category. Line 102 declares frequency and initializes it with an array of 11 to store the frequency of grades in each grade category.
