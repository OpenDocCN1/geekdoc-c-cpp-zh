# 8.9 Multidimensional Arrays

Two-dimensional arrays are often used to represent tables of values consisting of information arranged in rows and columns. To identify a particular element, we specify two indices. By convention, the first identifies the row and the second its column. Multidimensional arrays can have more than two dimensions, but such arrays are beyond the scope of this book. C# supports two types of two-dimensional arrays—rectangular arrays and jagged arrays.

# 8.9.1 Rectangular Arrays

Rectangular arrays are used to represent information in the form of rows and columns, where each row has the same number of columns. Figure 8.17 illustrates a rectangular array containing three rows and four columns—a three-by-four array. In general, an array with m rows and n columns is called an m-by-n array.

| Column 0 | Column 1 | Column 2 | Column 3 |
|---|---|---|---|
| Row 0 | a[0, 0] | a[0, 1] | a[0, 2] | a[0, 3] |
| Row 1 | a[1, 0] | a[1, 1] | a[1, 2] | a[1, 3] |
| Row 2 | a[2, 0] | a[2, 1] | a[2, 2] | a[2, 3] |

Figure 8.17. Rectangular array with three rows and four columns.

Array-Access Expression for a Two-Dimensional Rectangular Array
Every element in an array is identified by 8.17 by an array-access of the form a[row, column]; it is the name of the array, and row and column are the indices that uniquely identify each element in array by row and column number. The names of the elements in row 0 have a first index of 0, and the names of the elements in column 3 all have a second index of 3.
