The C# code closely corresponds to the pseudocode. This is one of the characteristics of pseudocode that makes it a useful app-development tool.

# bool Simple Type

You saw in C# that decisions can be based on conditions containing relational or equality operators. Actually, a decision can be based on any expression that evaluates to true or false. C# provides the type bool for Boolean values that can only hold the values true and false—each of these is a C# keyword.

# UML Activity Diagram for an if Statement

Figure 5.3 illustrates the single-if statement. This figure contains the most important symbol in an activity diagram—the diamond, decision symbol, which indicates that a decision is made. The workflow continues along a path determined by the student's guard conditions, which can be true or false. Each transition emerging from a decision symbol has a guard condition in square brackets next to the arrow. If a guard condition is true, the workflow enters the action to which the transition points. In Fig. 5.3, if the student's grade is greater than or equal to 60, the app displays “Passed,” then transitions to the final state of this activity. If the grade is less than 60, the app immediately transitions to the final state without displaying a message.
