
## 6.12 Structured-Programming Summary

### Rules for Forming Structured Programs
Figure 6.22 shows the rules for forming structured apps. The rules assume that action states may be used to indicate any action. The rules also assume that we begin with the simplest activity diagram (Fig. 6.23) consisting of only an initial state, an action state, a final state and transition arrows.

| Rules for forming structured apps |
| :--- | :--- |
| 1 | Begin with the simplest activity diagram (Fig. 6.23). |
| 2 | Any action state can be replaced by two action states in sequence. |
| 3 | Any action state can be replaced by any control statement (sequence of action states, if...else, switch, while, do...while, or for foreach, we'll see in Chapter 8). |
| 4 | Rules 2 and 3 can be applied as often as necessary in any order. |

Applying the rules in Fig. 6.22 always results in a properly structured activity diagram with a neat, building-block appearance. Rule 2 generates a stack of control states, so us call Rule 2 the stacking rule. Rule 3 is called the nesting rule. Repeatedly applying Rule 3 to the simplest activity diagram results in an activity diagram with nested control statements. For example, in Fig. 6.25, the action state in the simplest activity diagram is replaced with a double-selection (if...else) statement. Then Rule 3 is applied to the double-selection statement, replacing each of these action states with a double-selection statement. The dashed action-state symbols around each of the double-selection statements represent the action state that was replaced. The dashed arrows and action-state symbols shown in Fig. 6.25 are not part of the UML—they’re used here to illustrate that any action state can be replaced with any control statement.

Structured programming promotes simplicity. Research has shown that only three forms of control are needed to implement any algorithm:
- sequence
- selection
- iteration

Sequence is trivial. Simply list the statements of the sequence in the order in which they should execute. Selection is implemented in one of three ways:
- if statement (single selection)
- if...else statement (double selection)
- switch statement (multiple selection)

In fact, it's straightforward to prove that if statement is sufficient to provide any form of selection—everything that can be done with if...else statement and the switch statement can be done by combining them (although not as clearly and conveniently).
- while statement
- for statement
- foreach statement

It's straightforward to prove that while is sufficient to provide any form of iteration. Everything that can be done with do...while, for can be done with while (although not as clearly and conveniently).

### Chapter 6 Control Statements: Part 2
Combining these results illustrates that any form of control needed in C# app can be expressed in terms of
- sequence
- if statement (selection)
- while statement (iteration)
and these can be combined in only two ways—stacking and nesting.

### 6.13 Wrap-Up
Chapter 5 discussed the if...else and while control statements. In Chapter 6, we discuss the for, do...while and switch statements. (We'll discuss the foreach statement in Chapter 8.) You learned that any algorithm can be developed using combinations of sequence (statements in the order in which they execute), the three selection statements—if, if...else and switch—and the four iteration statements—while, do...while, for and foreach. You saw that for and do...while statements are simply more convenient ways to express types of iteration. Similarly, we showed that the switch statement is a convenient notion for multiple selection, rather than using if...else statements. We discussed how you can combine control statements by stacking and nesting. You learned about the logical operators, which enable you to use more conditional expressions. ### Summary
#### Section 6.2 Essentials of Counter-Controlled Iteration
- Counter-controlled iteration requires a control variable, the initial value of the control variable, the increment (or decrement) by which the control variable is modified each time through the loop and the loop-continuation condition that determines looping should continue.

#### Section 6.3 For Iteration Statement
- Typically, for statements are used for counter-controlled iteration, and while statements for sentinel-controlled iteration.

##### Section 6.3.1 A Closer Look at for's Header
- The header "does it all"—it specifies each of the items needed for counter-controlled iteration with a control variable.

##### Section 6.3.2 General Format of a Statement
- The general format of the for statement is
```csharp
for (initialization; loopContinuationCondition; increment)
{
    statement
}
```
where the initialization expression names the loop's control variable and provides its initial value, the loopContinuationCondition is the condition that determines looping should continue and the increment modifies the control variable's value so that the loop-continuation condition becomes false.

##### Section 6.3.3 Scope of a Statement's Control Variable
- The scope of a variable defines where it can be used in an app. A local variable can be used only in the method that declares the variable and only from the point of declaration through the end of the block in which the variable is declared. A control variable declared in the initialization expression of a for statement is only that statement.

##### Section 6.3.5 Placing Arithmetic Expressions in for Statement's Header
- The increment of a for statement may also be negative, in which case it's a decrement, and the loop counts downward.

#### Section 6.6 App: Compound-Interest Calculations
- When a variable of type decimal is initialized to an int value, the value of type int is promoted to a decimal implicitly—no cast is required.

##### Section 6.6.1 Performing Iteration Calculations with Math Method
- Methods that must be called using a class name are static methods.
- C# does not include an exponentiation operator. Instead, Math.Pow(x, y) calculates the value of x raised to the yth power. The method receives two arguments and returns a double value.
- C# will not implicitly convert a double to a decimal, or vice versa, because of the possible loss of information in either conversion. To perform this conversion, a cast operator is required.

##### Section 6.6.2 Formatting with Width Fields and Alignment
- Values are right-aligned in a field. To indicate that values should be output aligned, simply use a negative field.
- In a format item, an integer n indicates that the output value should be displayed with a field width of n—that is, at least n character positions, using spaces to fill characters.

##### Section 6.6.3 Caution: Do Not Use float or double for Monetary Amounts
- Floating-point numbers of type double (or Float) can cause trouble in monetary calculations; use type decimal.

#### Section 6.7 do...while Iteration Statement
- The do...while statement tests the loop-continuation condition after executing the loop's body; therefore, the body executes at least once.
- The do...while statement has the form:
```csharp
do
{
  statement
} while (condition);
```

#### Section 6.8 switch Multiple-Selection Statement
- The switch multiple-selection statement performs different actions based on the possible values of an expression.

##### Section 6.8.1 Using a switch Statement to Count A, B, C, D and F Grades.
- Method Console.ReadLine returns null when the end-of-file key sequence is encountered.
- The switch statement block contains a sequence of case labels and an optional default label.
