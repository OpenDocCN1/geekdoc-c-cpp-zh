where type and identifier are the type and name (e.g., int number) of the iteration variable, and arrayName is the array through which to iterate. The iteration variable's type must be consistent with the array's element type. The iteration variable represents successive values in the successive iterations of the for statement.
Figure 8.6 uses the for statement (lines 13–16) to calculate the sum of array's elements. The iteration variable's type is declared as int (line 13), because array contains int values. The for statement iterates through int one by one, with the first element. The for header can be read concisely as "for each element, assign array's next element to int number, then execute the for statement." Lines 13–16 are equivalent to the counter-controlled iteration used in lines 13–16 of Fig. 8.5.
