# Making-a-Difference Exercises

3.31 (Budgeting) A savings ratio is an important tool for people when budgeting. The formulas for calculating savings ratios are

```
Savings Ratio = \frac{Average Monthly Savings}{Average Monthly Income}
or
Savings Ratio = \frac{Average Monthly Income – Average Monthly Expenses}{Average Monthly Income}
```

Create a savings ratio app that reads the user's monthly income and expenses, then calculates and displays the user's monthly savings and savings ratio. The app should also display the following information pertaining to the savings ratio analysis so the user can understand his/her savings habits:

+   Savings Ratio Analysis
< 0.20 Extravagant or Low on Savings
> 0.20 but < 0.40 Less Extravagant or Moderate on Savings
> 0.40 but < 0.75 Lively or Strong on Savings
> 0.75 Miser or Mad about Savings

3.32 (Car-Pool Calculator) Research several car-pooling websites. Create an app that calculates your daily driving cost, so that you can estimate how much money could be saved by car pooling, which also has other advantages such as reducing emissions and reducing traffic congestion. The app should input the following information and display the user's cost per day of driving to:

+   a) Total miles driven per day.
b) Cost per gallon of gasoline (in cents).
c) Average miles per gallon.
d) Parking fees per day (in cents).
e) Tolls per day (in cents).
