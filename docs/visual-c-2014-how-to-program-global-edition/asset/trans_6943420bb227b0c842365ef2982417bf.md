## 14.1 引言

图形用户界面（GUI）允许用户通过视觉方式与程序交互。GUI 的读音为“GOO-ee”，它提供了独特的“外观”和“感觉”。

> **外观感受观察 14.1**
一致的用户界面能够使用户更快地学习新应用程序，因为打开的文件具有相同的“外观”和“感觉”。

作为 GUI 的示例，请考虑图 14.1，它显示了一个包含 GUI 控件的 Visual Studio 窗口。顶部是一个包含“文件 (File)”、“编辑 (Edit)”、“视图 (View)”菜单的菜单栏。下方是按钮标签栏，具有定义的任务，例如创建新项目或打开文件。下方是代表当前打开文件的标签——这种标签视图允许在打开的文件之间进行切换。这些控件构成了一个用户友好界面，你通过该界面与 IDE 交互。

GUI 是由 GUI 控件（这些控件有时被称为组件或 widgets——window gadgets 的缩写）构建的。GUI 控件是用于在屏幕上显示信息的对象，或者允许用户通过鼠标、键盘或其他形式的输入（如语音命令）与应用程序交互的对象。图 14.2 列出了几种常见的 GUI 控件——在随后的章节和第 15 章中，我们将详细讨论这些每一个控件。第 15 章将探索其他 GUI 控件的特性和属性。

## 14.2 Windows Forms

Windows Forms 是用于创建 GUI 的库之一——你将在在线章节中学习通用 Windows 平台 (UWP) 和 Windows 呈现基础框架 (WPF)。表单 (Form) 是出现在桌面上的一个图形元素；它可以是对话框、窗口或 MDI 窗口（多文档界面窗口）——将在第 15 章讨论。组件 (Component) 是实现 `IComponent` 接口的类实例，例如 Button 或 Label，是在运行时具有图形表示的组件。某些组件缺乏图形表示（例如 `System.windows.Forms` 命名空间下的 `Timer` 类——见第 15 章）。此类组件在运行时是不可见的。

### 活动窗口与焦点

当屏幕上有多个窗口时，活动窗口是前端，并具有高亮显示的标题栏。当用户点击窗口内部时，该窗口变为活动窗口。活动窗口被称为“拥有焦点”。例如，在 Visual Studio 中，当你从工具箱中选择项目时，活动窗口是工具箱；当你编辑控件属性时，活动窗口是属性窗口。

### 存储在单独文件中的自动代码

表单是控件和组件的容器。当你从工具箱中拖动项目时，Visual Studio 会生成创建对象并设置其基本属性的代码。当在 IDE 中修改控件或组件的属性时，该代码会更新。从表单中删除控件或组件将删除相应的生成的代码。IDE 使用部分类 (partial classes) 在单独文件中维护生成的代码——部分类被拆分在多个文件中，并由编译器组合成单个类。你可以自己编写这些代码，但这样做要简单得多。

## 14.3 事件处理

通常，用户通过图形用户界面 (GUI) 与程序交互，以指示程序应该执行的任务。例如，在应用程序中编写电子邮件时，点击发送按钮会将电子邮件发送到指定的地址。GUI 是事件驱动的。当用户与 GUI 组件交互时，这种交互——被称为事件——驱动程序执行任务。在没有 GUI 之前，程序告诉用户做什么。有了 GUI，是用户告诉程序做什么。可能导致应用程序执行任务的常见事件（用户交互）：
* 点击按钮
* 在文本框中输入
* 从菜单中选择
* 关闭窗口以及
* 移动鼠标

所有的 GUI 控件都有与其相关的事件。其他类型的对象也可以事件。响应事件执行任务的方法被称为事件处理程序 (event handler)，整个响应事件的过程被称为事件处理。
