# 23.8 Wrap-Up

In this chapter, you learned how to use the async modifier, await operator and Tasks to perform long-running or compute-intensive tasks asynchronously. You learned that tasks that proceed independently of one another are said referred to as asynchronous tasks.

We showed that multithreading enables threads to execute concurrently with other threads sharing application-resources such as memory and processors. To take full advantage of multicore architecture, we wrote applications that process tasks asynchronously. You learned that asynchronous programming is a technique for writing apps that can improve app performance and GUI responsiveness in apps with long-running or compute-intensive tasks.

To provide a convincing demonstration of asynchronous programming, we presented several:

+   - The first showed how to execute a compute-intensive calculation asynchronously in a GUI app so that the GUI remained responsive while the calculation executed.

+   - The second app performed two compute-intensive calculations synchronously (sequentially). When that app executed, the GUI froze because the calculations were performed in the GUI thread. The third app executed the same-intensive calculations asynchronously. We executed these two apps on single-core and dual-core computers to demonstrate the performance of each program in scenario.

+   - The fourth app used HttpClient to interact with the Flickr website for photos. You learned that HttpClient is one of built-in .NET Framework classes that can initiate asynchronous tasks for use with async and await.
