# 6.7 do...while Iteration Statement

The do...while iteration statement is similar to the while statement. In the while, the app tests the loop-continuation condition at the beginning of the loop's body. If the condition is false, the body never executes. The do...while statement tests the loop-continuation condition after executing the loop's body; therefore, the body executes at least once. When a do...while statement terminates, execution continues with the next statement in sequence. Figure 6.7 uses a do...while (lines 11–15)

```
1 // Fig. 6.7: DoWhileTest.cs
2 // do...while iteration statement.
3 using System;
4
5 class DoWhileTest
6 {
7 static void Main()
8 {
9 int counter = 1; // initialize counter
10
11 do
12 Console.Write("{counter} ");
13 ++counter;
14
15 } while (counter <= 10); // required semicolon
16
17 Console.WriteLine();
18 }
19 }
```

**Figure 6.7** do...while iteration statement.

Line 9 declares and initializes counter. Upon entering the do...while statement, line 13 outputs counter's value, and 14 increments counter. Then the app evaluates the loop-continuation test at the bottom of the loop (line 15). If the condition is true, the loop continues from the first body statement (line 13). If the condition is false, the loop terminates, and the app continues with the next statement after the loop (line 17).
