# **MDI Parent Form**

Figure 15.43 presents class UsingMDIForm—the app's MDI parent form. This form, which is created, contains two top-level menus. The first of these menus, File (fileToolStripMenuItem), contains both an Exit item (exitToolStripMenuItem) and a New sub-menu (newToolStripMenuItem) consisting of items for each type of child window. The second menu, Window (windowToolStripMenuItem), provides options for laying out the MDI children, plus a list of the active MDI children.

```
// Fig. 15.43: UsingMDIForm.cs
// Demonstrating an MDI parent and MDI child windows.
using System;
using System.Windows.Forms;

{
    // Form demonstrates the use of MDI parent and MDI child windows
    public partial class UsingMDIForm : Form

        {
            InitializeComponent();
        }
    }
```
