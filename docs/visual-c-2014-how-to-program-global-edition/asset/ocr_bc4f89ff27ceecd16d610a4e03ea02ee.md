# 1.3.2 Computer Organization

Regardless of differences in physical appearance, computers can be divided into various logical units or sections (Fig. 1.2).

| Logical unit | Description |
| --- | --- |
| Input unit | This "receiving" section obtains information (data and computer programs) from input devices and places it at the disposal of the other units for processing. Most user input is entered into computers through keyboards, touch screens and mice devices. Other forms of input receiving voice commands, scanning images and barcodes, reading from secondary storage devices (such as hard drives, DVD, Blu-ray Disc™ and USB flash drives—also called "thumb drives" or "memory sticks"), receiving video from a webcam and having your information from the Internet (such when you stream videos from YouTube™ or ebooks from Amazon). Newer forms of input data from GPS device, motion and orientation information from an accelerometer (a device that measures left/right and forward/backward acceleration) in a smartphone or game controller (such as Microsoft® Xbox, Wii Remote and Sony PlayStation Move) and voice input from devices like Echo and the forthcoming Google Home.| Output unit | This "shipping" section takes information the computer has processed and puts it on output devices to make it available for use outside the computer. Most information from computers today is displayed on screens (including touch screens), printed on paper ("going green\ or played as video on PCs and media players (such as Apple’s iPads) and other devices, such as robots and "intelligent" appliances. Information is commonly output to storage devices, such as solid-state drives (SSDs), hard drives, DVD and USB flash drives. Popular forms of output are smartphone and game-controller vibration, virtual reality devices and mixed devices like HoloLens 3.| Memory unit | This rapid-access, relatively low-capacity—“warehouse” section retains information that has entered through the input unit, making it immediately available for processing when needed. The memory unit retains processed information until it is placed on output devices by the output unit. Information in the memory unit is volatile—it is typically lost when the computer’s power is turned off. The memory unit is often called memory, primary memory or RAM (Random Access Memory). Main memories on desktop and notebook computers contain as much as 12 GB of RAM, though 2 to 16 GB is most common. GB stands for gigabytes; a byte is approximately one bits. A bit is either a or b.| Arithmetic and logic unit (ALU) | This "manufacturing" section performs calculations, such as addition, multiplication and division. It also contains the decision mechanisms that allow the computer, for example, to compare two items from the memory unit to determine whether they're equal. In today’s systems, the ALU is implemented as part of the next logical unit, the CPU.
