# 21.8.3 Delegate Parameters

The real power of delegates is in passing method references as arguments to methods, as we do in this example with method FilterArray (lines 42–59). The method takes as arguments

+   - an int array
- a NumberPredicate that references a method used to filter the array elements.

The method returns a List<int> containing only the ints that satisfy the condition specified by the NumberPredicate. FilterArray returns a List, because we don't know how many elements will be included in the result.

The foreach statement (lines 49–66) calls the method referenced by the NumberPredicate delegate (line 52) for each element of the array. If the method returns true, the element is included in result. # 21.9 Lambda Expressions

Lambda expressions allow you to define simple, anonymous methods—that is, methods that do not have names and are defined where they are assigned to a delegate or passed to a delegate parameter. In many cases, working with lambda expressions can reduce the size of your code and the complexity of working with delegates. As you’ll see in later chapters, lambda expressions are particularly when combined with the where clause in LINQ queries.
