# Method DisplayDictionary

Line 47 returns to the main method, which then passes it to method DisplayDictionary (lines 51–65), which displays all the key–value pairs. This method uses read-only property Keys (59) to get an ICollection<T> contains all the keys. Because the interface ICollection<T> implements IEnumerable<T>, we can use this collection in the foreach statement lines 59–62 to iterate over it. This loop outputs each key and its corresponding value using the iterator and the SortedDictionaryindexer's accessor. Each key and value is displayed left aligned in a field width of 12 pixels. Because a SortedDictionary stores its key-value pairs in a binary search tree, the key–value pairs are displayed in sorted order. Line 64 uses SortedDictionary Count to get the number of key-value pairs in the dictionary.

# Iterating Over a SortedDictionary's KeyValuePairs

Lines 59–62 also used the foreach statement with the SortedDictionary object, instead of using the Keys property. If you use a foreach statement with Dictionary object, the iteration variable will be of type KeyValuePair<K,V>. The enumerator of SortedDictionary uses the KeyValuePair<K,V> structure value to store key–value pairs. KeyValuePair<K,V> provides properties Key and Value for retrieving the key and value of the current element.
