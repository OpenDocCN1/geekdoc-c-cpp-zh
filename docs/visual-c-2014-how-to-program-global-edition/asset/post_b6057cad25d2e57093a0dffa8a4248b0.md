## Using a Stream to Create an Output File
CreateFileForm (Fig. 17.4) uses instances of class Record to create a sequential-access file that may be used in an accounts-receivable system—i.e., a program that organizes reading money owed by a company's credit clients. For each client, the program obtains an account number and the client's first, last name and balance (i.e., the amount of money the client owes the company for previously received goods and services). The data obtained for each client constitutes a record for that client. In this app, the account number is used as the record key—files are created and maintained in account-number order. This program assumes that the user enters records in account-number order. However, a comprehensive accounts-receivable system uses sorting capacity. When you create a Windows Forms Application for this app, be sure to add a reference to BankLibrary.dll and change the base class from Form to BankUI. See Section 15.13 for information on adding a reference to a class library.

## 17.3 Creating a Sequential-Access Text File

```csharp
namespace CreateFile {
    public partial class CreateFileForm : BankUIForm {
        private StreamWriter fileWriter; // writes data to text file

        // parameter constructor
        public CreateFile() {
            Initialize();
        }

        // event handler for Save Button
        private void saveButton_Click(object sender, EventArgs e) {
            // create show dialog box enabling use to save file
            DialogResult result; // result of SaveFileDialog
            string fileName; // name of file
            using (var chooser = SaveFileDialog()) {
                chooser.CheckFileExists = false; // let user create file
                result = chooser.ShowDialog();
                fileName = chooser.Name; // name to save data
            }
            // ensure that user clicked "OK"
            if (result == DialogResult.Ok) {
                MessageBox.Show("Invalid Name", "Error", MessageBoxButtons.OK, MessageBoxIcon.Error);
            } else {
                // save via FileStream
                try {
                    // open file with write access
                    var output = new FileStream(fileName, FileMode.OpenOrCreate, FileAccess.Write);
                    // sets file to where data is written
                    fileWriter = new StreamWriter(output);

                    // disable Save button and enable Enter.
                    saveButton.Enabled = false;
                    enterButton.Enabled = true;
                } catch (IOException) {
                    // notify user if file does not exist
                    MessageBox.Show("Error opening file", "Error", MessageBoxButtons.OK, MessageBoxIcon.Error);
                }
            }
        }

        // handler for enterButtonClick
        private void enterButton_Click(object sender, EventArgs e) {
            // store TextBox values
            string[] values = GetTextBoxValues();

            // determine whether TextBox content is empty
            if (!string.IsNullOrEmpty(values[TextBoxIndices.Account])) {
                // determine whether accountNumber is valid
                if (accountNumber > 0) {
                    // Record TextBox values to output
                    var record = new Record(accountNumber,
                        values[TextBoxIndices.First],
                        values[TextBoxIndices.Last],
                        decimal.Parse(values[TextBoxIndices.Balance]));

                    // write Record to file, lines separated by commas
                    fileWriter.WriteLine(record.Account + "," +
                        record.FirstName + "," + record.LastName + "," + record.Balance);
                } else {
                    // notify user if invalid account number
                    MessageBox.Show("Invalid Account Number", "Error", MessageBoxButtons.OK, MessageBoxIcon.Error);
                }
            } catch (IOException) {
                MessageBox.Show("Error Writing to File", "Error", MessageBoxButtons.OK, MessageBoxIcon.Error);
            } catch (FormatException) {
                MessageBox.Show("Invalid Format", "Error", MessageBoxButtons.OK, MessageBoxIcon.Error);
            }
            ClearTextBoxes(); // clear TextBox values
        }

        // handler for exitButtonClick
        private void exitButton_Click(object sender, EventArgs e) {
            try {
                fileWriter.Close(); // close StreamWriter and underlying file
            } catch (IOException) {
                MessageBox.Show("Cannot close file", "Error",
                    MessageBoxButtons.OK, MessageBoxIcon.Error);
            }
            Application.Exit();
        }
    }
}
```

## Method saveButton_Click
When the user clicks the Save As, the program invokes the event handler saveButton_Click (lines 21–67). Line 27 instantiates an object of class SaveFileDialog (namespace System.Windows.Forms). By placing this object in a using statement (lines 27–32), we ensure that the dialog's Dispose method is called to release its resources as program has retrieved the user's input. SaveFileDialog objects are used for selecting files (see the second screen in Fig. 17.4). Line 29 indicates that the dialog should not check if the filename specified by the user already exists (this is actually the default). Line 30 calls ShowDialog method to display the dialog.

When displayed, a SaveFileDialog prevents the user from interacting with any other window in the program until the user closes the SaveFileDialog by clicking Save or Cancel. Dialog behaves in this manner, and then the user clicks Save. The user selects the appropriate directory, directory, and filename. See ShowDialog returns a DialogResult specifying which (Save or Cancel) the user clicked to create dialog. This is assigned to DialogResult variable (line 30). Line 31 gives the filename from the dialog. Line 35 tests whether the user clicked OK by comparing this value to DialogResult.Ok. If the values match, method saveButton_Click continues.
