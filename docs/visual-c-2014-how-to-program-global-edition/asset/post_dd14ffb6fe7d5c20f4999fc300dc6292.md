# 5.8 while Iteration

An iteration statement allows you to specify that a program should repeat an action while some condition remains true. The pseudocode describes the iteration during a trip. The condition "there are more items on my list" may be true or false. If it's true, the action "Purchase item and cross it off" is performed. This action will be performed while the condition remains true. The statement(s) in the iteration constitute its body, which may be a single statement or a block. Eventually, the condition becomes false (when the list has been crossed off). At this point, the iteration terminates, and the first statement after the iteration executes.

As an example of C#'s while iteration, consider a code segment to find the first multiple of 3 larger than 100. When the while statement finishes, product contains:

```csharp
int product = 3;
while (product <= 100)
{
    product = 3 * product;
}
```

When this while statement executes, product contains the value 3, so product takes on the values 9, 27, 81 and 243. When product becomes 243, product <= 100 becomes false. It terminates the iteration, and the final value of product is 243. At this point, program execution continues with the statement after the while statement.

### Common Programming Error 5.2
Not providing in the body of a while statement an action that eventually causes the condition in the while statement to become false is called an infinite loop. This often will make your program appear to "hang".

# 5.9 Formulating Algorithms: Counter-Controlled Iteration

To illustrate how algorithms are developed, we solve two variations of a problem that averages student grades. Consider the following problem statement:

> A class of 10 students took a quiz. The grades (integers in the range 0 to 100) for this quiz are available to you. Determine the class average on the quiz.

The class average is equal to the sum of the grades divided by the number of students. The algorithm for solving this problem on a computer must input each grade, keep track of the total of all grades entered, perform the averaging calculation and produce the result.
