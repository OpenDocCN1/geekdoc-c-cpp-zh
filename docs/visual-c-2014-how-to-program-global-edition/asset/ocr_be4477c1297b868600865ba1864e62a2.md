**AuthorISBN Table of the Books Database**nThe AuthorISBN table (described in Fig. 22.7) consists of two columns that maintain ISBNs for each book and their corresponding authors' ID numbers. This table associates authors with their books. The Author column is a foreign key—a column in one table that matches the primary-key column in another table (that is, Author in the Author table). The ISBN column is a foreign key—it matches the primary-key column (that is, ISBN in the Titles table). A database might consist of many tables. A goal of a database's designer is to minimize the amount of duplicated data among the database's tables. Foreign keys, which are specified when a database table is created in the database, the link in multiple tables. Together the Author and ISBN columns in this table form a composite primary key. Every row in this table uniquely matches one author to one book's ISBN. Figure 22.8 contains the data from the AuthorISBN table of the Books database.
