# 14.9 ToolTips

In Chapter 2, we demonstrated tool tips—the helpful text that appears when the mouse hovers over an item in a GUI. Recall that the tool tips in Visual Studio (and most apps GUIs) help you become familiar with the IDE's features and serve as useful reminders for each toolbar icon. This section demonstrates how to use the ToolTip component to add tool tips to your apps. Figure 14.31 describes common properties and a common event of class ToolTip.

| ToolTip properties and an event Description |
| AutoPopDelay The amount of time (milliseconds) that the tool tip appears while the mouse is over a control. | InitialDelay The amount of time (milliseconds) that a mouse must hover over a control before the tool tip appears. |
 ReshowDelay The amount of time (milliseconds) between which two different tool tips appear (when the mouse is moved from one control to another). |
 Common Event Draw Raised when the tool tip is about to be displayed. This event allows programmers to modify the appearance of the tool. |
