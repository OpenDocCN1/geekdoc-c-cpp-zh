## Introduction

This chapter introduces the .NET Framework Class Library's string- and character processing capabilities and demonstrates how to use regular expressions to search for patterns in text. The techniques it presents can be employed in many kinds of applications, and particularly in text editors, word processors, page-layout software, computerized typesetting systems and other kinds of text-processing. Previous chapters presented some basic class string and char from the System namespace and class StringBuilder from the System.

We begin with an overview of the fundamentals of characters and strings in which we discuss characters and string literals. We provide examples of class string's many constructors and methods. The examples demonstrate how to determine the length of strings, copy strings, access individual characters in strings, search strings, obtain substrings from larger strings, concatenate strings, replace characters in strings and convert strings to uppercase or lowercase letters.

Next, we introduce StringBuilder, which is used to assemble strings dynamically. We demonstrate StringBuilder capabilities for determining and specifying the size of a StringBuilder, as well as appending, inserting, removing and replacing characters in a StringBuilder object. We then introduce the character-testing methods to determine whether a character is a digit, a letter, a lowercase letter, an uppercase letter, a punctuation mark or a symbol other than a punctuation mark. Such methods are used for validating characters in user input. In addition, type Char provides methods for converting a character to uppercase or lowercase.

We provide an online section that discusses regular expressions. We present Regex and from the System.RegularExpressions namespace as well as the symbols that are used to form regular expressions. We demonstrate how to find patterns in a string, match strings to patterns, replace characters in a string that matches a pattern and split strings at delimiters specified as a pattern in a regular expression.

## 16.2 Fundamentals of Characters and Strings

Characters are the fundamental building blocks of C# source code. Every program is composed of characters, when grouped together meaningfully, create a sequence that the compiler interprets as instructions describing how to accomplish a task. A program can also contain character constants. Character constant is a constant that's represented as an integer value, called a character code. For example, the integer value 122 corresponds to the character 'z'. The integer value 10 corresponds to the newline character '\n'. Character constants are established according to the Unicode character set, an international character set that contains many symbols and letters than does the ASCII character (listed in Appendix C). To learn more about Unicode, see our online appendix.

A series of characters treated as a unit: these characters can be uppercase letters, lowercase letters, digits and special characters: +, -, *, /, and others. A string is an object of type. Just as the C keyword object is an alias for class object, string is an alias for class (namespace System). We write string literals, also called string constants, as sequences of characters in double quotation marks, as follows:

> "John Q. Doe"
> "9999 Main Street"
> "Waltham, Massachusetts"
> "(201) 555-1212"

A declaration can assign a string to a string reference. The declaration

```
string color = "blue";
```

initializes the color to refer to the string literal "blue".

### Performance Tip 16.I

If there are multiple occurrences of the same string literal in an app, a single copy of it will be referenced from each location in the program that uses that string literal. It is possible to share the object in this manner, because string literals are implicitly constant. String sharing saves memory.

### Verbatim strings

Recall that backslashes in strings introduce escape sequences and that placing a backslash in a string requires \\. On occasion, a string will contain multiple backslashes (this often in the name of a file). To avoid excessive backslashes, it is possible to exclude escape sequences and interpret all the characters in a string literally, using the @ character to mark what is known as a verbatim string. Backslashes within the double quotation marks following the @ are not considered to be part of escape sequences. This simplifies programming and makes code easier to read.

For example, consider the string in the following assignment:

```
string file = "C:\MySubFolder\MySubFolder\MyFile.txt";
```

Using the verbatim syntax may also span multiple lines, in which case they preserve all newlines, spaces and tabs between the opening @ and closing " delimiters.

## 16.3 string Constructors

Fig 16.1 demonstrates three class of string's constructors.

```c
// Fig 16.1: StringConstructor.cs
// Demonstrating string constructors.
using System;

class StringConstructor
{
    static void Main()
    {
        // string initialization
        char[] characterArray = {
            'b', 'i', 'r', 't', 'h', ' ', 'd', 'a', 'y'
        };
        var originalString = "Welcome to C# programming";
        var string1 = originalString;
        var string2 = new string(characterArray);
        var string3 = new string(characterArray, 6, 3);
        var string4 = new string('C', 5);

        Console.WriteLine($"string1 = {string1}" + 
                          $"string2 = {string2}" + 
                          $"string3 = {string3}" + 
                          $"string4 = {string4}");
    }
}
```

string1 = "Welcome to C# programming"
string2 = "birth day"
string3 = "day"
string4 = "CCCCC"

Fig. 16.1 | Demonstrating string class constructors.

Lines 10–11 create the char array characterArray, which contains nine characters. Lines 12–16 declare the strings originalString, string1, string2, string3 and string4. Line 12 assigns string literal 'welcome to C# programming!' to originalString. Line 13 sets string1 to refer the same string.

Line 14 assigns string2 a new string, using the string constructor that takes a copy of the array. The new string contains a copy of the characters. Line 15 assigns string3 a new string, using the string constructor that takes a char array and two arguments. The second argument specifies the starting position (offset) from which characters the array are to be copied. The third argument specifies the number of characters (count) to be copied from the starting position in the array. The new string contains a copy of the characters in the array. If the specified offset or count indicates that the program should access an element outside the bounds of the character array, an ArgumentRangeException is thrown.

Line 16 assigns string4 a new string, using the string constructor that takes as arguments a character and an int specifying the number of times to repeat character in the string.
