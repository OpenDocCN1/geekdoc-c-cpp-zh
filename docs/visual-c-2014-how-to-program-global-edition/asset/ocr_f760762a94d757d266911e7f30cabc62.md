
enables you to order by an additional column. This is applied to the Author objects that have already been ordered by last name. Like OrderBy, ThenBy also receives a Func delegate that you use to order the results.
Finally, 30 calls the Load extension method (defined in class DbExtensions from the namespace System.Data). This method executes the query and loads the results into memory.
