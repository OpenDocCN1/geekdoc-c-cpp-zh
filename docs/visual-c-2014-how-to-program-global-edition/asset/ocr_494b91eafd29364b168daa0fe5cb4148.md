**7.23 (Find the Minimum)** Write a method Minimum that returns the smallest of three floating-point numbers. Use the Math.min method to implement Minimum. Incorporate the method into an app that reads three values from the user, the smallest value and displays the result.

**7.24 (Amicable Numbers)** Two number are said to be amicable numbers if the sum of factors including 1 (but not the number itself) of one number is equal to the other number and vice versa. For example, (220, 284) are amicable numbers. The sum of factors of 220 are 2, 4, 5, 10, 11, 20, 22, 44, 55 and 110, which sums equals 284. Write method Checkable determines whether a pair of numbers is amicable or not. Display the factors of each number to confirm that the numbers are amicable or not.

**7.25 (Prime Numbers)** An integer is said to be prime if it's greater than 1 and divisible by only 1 and itself. For example, 2, 3, 5 and 7 are prime; but 4, 6, 8 and 9 are not.
a) Write a method that determines whether a number is prime.
b) Use this method in an app that displays all the prime numbers less than 10,000.
c) Initially, you might think that n/2 is the upper limit for you must test to see whether a number is prime, but you need go as high as the square root of n. Rewrite the app, and run it both.

**7.26 (Reversing Digits)** Write a method that takes an integer value and returns the number with its reversed digits. For example, using the number 7361 returns 1367. Incorporate the method into an app that reads a value from the user and displays the method's result.

**7.27 (Lowest Common Multiple)** The lowest common multiple (LCM) of two integers is the lowest integer that is evenly divisible by each of the two numbers. Write method lcm returns the lowest common multiple of two integers. Incorporate the method into an app that reads values from the user and displays the result.

**7.28 (Converting Average to a Four-Point Scale)** Write method QualityPoints that inputs a student's average and returns it scale of 90–100, 3 if the average is 80–89, 2 if the average is 70–79, 1 if the average is 60–69 and 0 if the average is less than 60. Incorporate the method into an app that reads values from the user and displays the result.
