19.6 (Evaluating Expressions with a Stack) Stacks are used by compilers to evaluate expressions and generate machine-code. In this and the next example, we investigate how compilers evaluate arithmetic expressions consisting only of constants, operators and operands. Humans generally write expressions like 3 + 4 and 7 / 9, in which the operator (+ or / here) is written between its operands—infix notation. Computers prefer ”postfix notation, in which the operator is to the right of its two operands. The preceding expressions would appear in postfix notation as 3 + 4 and 7 / 9, respectively.
