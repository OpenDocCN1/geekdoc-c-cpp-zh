# # 10.2.1 Time1 Class Declaration

Time1 contains three public properties of time—universal-time format—Hour, Minute and Second (Fig. 10.1, lines 7–9). These represent the time in 24-hour clock format, in which hours are in the range 0–23. Time1 contains public methods SetTime(lines 13–25), ToUniversalString(lines 28–29) and ToString(lines 32–34). These are the public services or the public interface that this class provides to its clients. In this example, Time1 does not declare a constructor, so the compiler defines a default constructor. Each property receives the default value 0 for an instance. Variables and auto-implemented properties can also be assigned in their declarations.

```
// Fig. 10.1: Time1.cs
// Class declaration maintains the time in 24-hour format.
using System; // namespace containing ArgumentOutOfRangeException
public class Time1 {
    public int Hour { get; set; } // 0 - 23
    public int Minute { get; set; } // 0 - 59
    public int Second { get; set; } // 0 - 59

    // set the new value using universal-time; throw an exception
     if the hour, minute or second is invalid
    public void SetTime(int hour, int minute, int second) {
        if (hour < 0 || hour > 23) || (minute < 0 || minute > 59) ||
            (second < 0 || second > 59) {
            throw new ArgumentOutOfRangeException();
        }
    }

    Hour Hour = hour;
    Minute Minute = minute;
    Second Second = second;

    // convert to string in universal-time format (HH:MM:SS)
    public string ToUniversalString() =>
        $"{Hour:D2}:{Minute:D2}:{Second:D2}";

    // convert to string in standard-time format (H:MM AM or PM)
    public override string ToString() =>
        $"{{(Hour == 0 || Hour == 12) ? 12 : Hour % 12}}:{Minute:D2}:{Second:D2} {(Hour < 12 ? "AM" : "PM")}"";
}
```

**Fig. 10.1** Time1 class declaration maintains the time in 24-hour format.
