BaseCommissionEmployee Method Earnings
BaseCommissionEmployee's Earnings method (Fig. 11.11, line 43) overrides CommissionEmployee's Earnings method. The new version adds the portion of the employee's earnings based on commission by calling CommissionEmployee's Earnings method with the expression base.Earnings() (Fig. 11.11, line 43), then adds the base salary to this value to calculate the total earnings of employee. The syntax used to invoke an overridden base-class method from derived class—the base keyword and the member access operator (.) over the base-class method—is a good software engineering practice—by having BaseCommissionEmployee's Earnings method to calculate part of BaseCommissionEmployee object's earnings, we avoid duplicating the code and reduce maintenance problems.

> Common Programming Error 11.3\When a base-class method is overridden in a derived class, the derived version calls the base-class version to do a portion of the work. Failure to prefix the base-class method name with the base keyword and the member access (.) operator when referencing the base-class method from the derived-class causes the derived-class method to call itself, creating recursion.

BaseCommissionEmployee Method ToString
Similarly, BaseCommissionEmployee's ToString method (Fig. 11.11, lines 46–47) overrides CommissionEmployee's ToString to return a string representation of a salary-based commission employee. The new version creates part of BaseCommissionEmployee string representation (i.e., the string "commission employee" and the values of CommissionEmployee:data) by calling CommissionEmployee's ToString() (Fig. 11.11, line 47) and incorporating the result into the string returned by the derived class's ToString method, which includes the base salary.
