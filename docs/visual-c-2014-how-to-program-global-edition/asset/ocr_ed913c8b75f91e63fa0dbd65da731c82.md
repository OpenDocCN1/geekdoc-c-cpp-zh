# Exercises

20.3 (Type Constraints) Explain one of the following constraint in a C# program: IComparable<T>

20.4 (Implementing Generic Methods) How are generic methods implemented?

20.5 (Understanding The Declared Class) Programmer declares a generic as a non-generic class. Elaborate on the concept of generic classes and the definition of non-generic class.

20.6 (What Does This Statement Do?) Explain why a C# program might use the statement var workerList = new Employees();

20.7 (Generic Linear Search Method) Write a generic method, that searches an array using the linear-search algorithm. Method search should compare the key with each element in its array parameter until the key is found or until the end of the array is reached. If the key is found, return its location in the array; otherwise, return -1. Write a test app that inputs and searches an int and a double array. Provide buttons that the user can click to randomly generate double values they can search for [Hint: Use <T : IComparable<T>>] in the clause for method search so that you can use CompareTo to compare the key to the elements in array].

20.8 (Overloading a Generic Method) Overload generic method DisplayArray of 20.3 that it takes two arguments: Index and HighIndex. A call to this method displays only the designated portion of the array. Validate Index and HighIndex. If either is out of range, or if HighIndex is less than or equal to LowIndex, otherwise the overloaded DisplayArray should throw an ArgumentException; DisplayArray should return the number of elements displayed. Modify Main to execute both versions of DisplayArray on intArray, doubleArray and Test all capabilities of both versions.

20.9 (Overloading a Generic with a Non-Generic Method) Overload generic DisplayArray of String with a nongeric version that displays an array of strings in neat, tabular format, as shown in the output that follows:

| stringArray contains: |
| one two three four |
| five six seven eight |

20.10 (Generic Method Print) Write a simple generic version of Print. Use this generic method in a program that calls Print with a variety of simple types, such as double or int. What result you get when you attempt to run this program?
