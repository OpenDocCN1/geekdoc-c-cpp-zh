**8.32 (Computer Simulator)** In this problem, you're going to build your own computer. No, you're not be soldering components together. Rather, use the power of software-based simulation to create an object-oriented software model of the Simpleton of Exercise 8.31. Your Simpleton will turn the computer you're using into a Simpleton, and you'll actually be able to run, test and debug the SML programs you enter in Exercise 8.31.
When you run your Simpleton, it should begin displaying:

```
*** Welcome to Simpleton! ***
*** Please enter your program one instruction ***
```
