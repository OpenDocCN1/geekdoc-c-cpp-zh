# Section 5.6 if...else Double-Selection Statement

+   - The if...else statement allows you to specify an action (or group of actions) to perform when the condition is true and a different action (or group of actions) when the condition is false.

# Section 5.6.3 Blocks

+   - To include all statements in the body of an if (or the body of an else for an if...else statement), enclose the statements in braces { }

+   - A set of statements contained within a pair of braces is called a block. A block can be placed anywhere in an app where a single statement can be placed.

# Section 5.6.4 Conditional Operator (?:)

+   - C# provides the conditional operator (?), which can be used in place of an if...else statement. The conditional expression evaluates the second operand if the first operand evaluates to true, and evaluates to the third operand if the first operand evaluates to false.

# Section 5.8 while Iteration Statement

+   - An iteration allows you to specify that an app should repeat an action while some condition remains true.

+   - The format for the while iteration statement is

```
while (condition)
{
  statement
}
```
