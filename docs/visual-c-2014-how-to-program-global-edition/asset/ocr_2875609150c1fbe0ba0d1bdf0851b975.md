# 13.7.2 Other Exception Properties

Class Exception provides other properties, including HelpLink, Source and TargetSite:

+   - Property HelpLink specifies a link to the help file that describes the problem that occurred. Property is null if no such file exists.
- Property Source specifies the method of the assembly (i.e., app or library) that caused the exception.
- Property TargetSite specifies the method that the exception originated.

# 13.7.3 Demonstrating Exception Properties and Stack Unwinding

Our next example (Fig. 13.5) demonstrates properties Message, StackTrace and Inner-Exception of class Exception. In addition, the example introduces stack unwinding—when an exception is thrown but not caught in a particular scope, the method call is "unwound," and an attempt is made to catch the exception in the next try block. We keep track of the methods on the call stack as we discuss Stack-Trace and the stack-unwinding mechanism. To see the proper stack trace, you should execute this program using similar steps to those presented in Section 13.2.
