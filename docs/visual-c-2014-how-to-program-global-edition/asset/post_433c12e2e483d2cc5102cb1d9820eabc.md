## 3.3.4 Compiling and Running the App

You're now ready to compile and execute your app. Depending on the project's type, the compiler may compile the code into files with a .exe (executable) extension, .dll (dynamically linked library) extension or one of several others—you can find these files in project's subfolders on disk. These files are called assemblies and are the packaging units used for C# code. These assemblies contain the Microsoft Intermediate Language (MSIL: Section 1.9.2) code for the app.

To compile the app, select Build > Build Solution. If the app contains compile-time errors, this will compile your code and build it into an executable (named Welcome1.exe, in one of project's subdirectories). To execute it, press Ctrl + F5, which invokes the Main method (Fig. 3.1). If you attempt to run the app before building it, the IDE will build your app first, then run it only if there are no compilation errors. The statement in line 10 of Main displays Welcome to C# Programming!. Figure 3.8 shows the results of executing this app, displayed in a console (Command Prompt) window. Leave the app project open in Visual Studio: we will go back to it later in this section. [Note: The console window normally has a black background and white text. ## 3.4.2 Displaying Multiple Lines of Text with Multiple Statements

A single statement can display multiple lines using newline characters. Like tabs, \n positions the cursor to the beginning of the next line.

## 3.5 String Interpolation

Many programs format data into strings. C# 6 introduces a mechanism called string interpolation that enables you to insert values into string literals to create formatted strings. Figure 3.13 demonstrates this capability.

```
// Fig. 3.13: Welcome4.cs
// Inserting content into a string with string interpolation
using System;

class Welcome4
{
    // Main method begins execution of C# app
    static void Main()
    {
        string person = "Paul"; // variable that stores the string "Paul"
        Console.WriteLine("Welcome to C# Programming, {person}!");
    } // end Main
} // end class Welcome4
```

Welcome to C# Programming, Paul!

**Fig. 3.13** | Inserting content into a string with string interpolation.
