# Invoking Class Account's Name Property to Get the Name

The get accessor of the Account class's Name property gets the account stored in a particular object. Line 13

```
Console.WriteLine($"Initial name is: {myAccount.Name}");
```

displays myAccount's initial name by accessing the object's Name property with the expression myAccount.Name. To access property, you specify the object's name (myAccount), followed by the member-accessor operator (.) and the property's name (Name). When used to get the account's name, this notation implicitly expects the property's get accessor, which returns the account's name.

When accesses the Name property in line 13:

+   1. The app transfers execution from the expression myAccount.Name (line 13 in Main) to the property Name's get accessor.
2. Next, the Name property's get accessor performs this task—that is, it returns (i.e., gives back) the value of myAccount's instance variable to line 13 where the property was accessed.
3. Console.WriteLine displays the string returned by the Name property's accessor—which inserted into the interpolated string in place of the expression myAccount.Name—then the property continues executing at line 16 in Main.

As in Fig 4.1, line 13 does not display a name, because we have not yet stored a name in the myAccount object.
