# Method RemoveFromBack

Method RemoveFromBack (Fig. 19.4, lines 100–130) removes the last node of a list and returns to the removed data. The method throws an EmptyListException (line 104) if the program attempts to remove a node from an empty list. The method consists of several steps:

+   1. Assign lastNode.Data (the data being removed from the list) to variable removeItem (line 107).

+   2. If firstNode and lastNode refer to the same object (line 110), the method sets reference firstNode and lastNode to null (line 112) to remove that node from the list (leaving the list empty).
