Let's mostivate data with an example. Suppose that we have a video game with Martians and other space creatures. Each Martian tends to be brave and to attack other space creatures when it's aware that there are at least four Martians present. If fewer than five Martians are present, each Martian becomes cowardly. Each Martian needs to know the MartianCount. We could count class Martian with MartianCount as an instance variable (as a property, but we'll use an instance variable for discussion purposes here). If we do this, every Martian will have a separate copy of the instance variable, and every time we create a new Martian, we'll have to update the instance variable MartianCount every Martian. This wastes space on redundant copies, updating the separate copies and is prone error. Instead, we declare MartianCount to be static, making the MartianCount, but only one copy of the static MartianCount is maintained. We save space by having the Martian constructor implement the static oldCount—there's only one copy, so we do not have to implement separate copies of martCount for each Martian object.

> Software Engineering Observation 10.10
Use a variable when all objects of a class share the same copy of the variable.

# static Variable Scope

The scope of a static variable is the body of its class. A class's public static members can be accessed by qualifying the member name with the class name and the member access (.) operator, as in Math.Pt. A class's private static class members can be accessed only through the class methods and properties. To access a private static member from outside its class, a public static method or property can be provided.

> Common Programming Error 10.2
It's a compilation error to access or invoke a static member by referencing it through an instance of the class, like a non-static member.

Static variables, methods and properties exist, and can be used, even if no objects of that have been instantiated. Static members are available as soon as the class is loaded into memory at execution.

# static Methods and Non-static Class Members

A static method (or property) cannot access non-static class members directly, because when no objects of the class exist. For the same reason, this cannot be used in a static method—this reference refers to a specific object of the class. When a static method is called, it does not know which object to manipulate and there might not be any objects of its class in memory.
