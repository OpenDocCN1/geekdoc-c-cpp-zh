File-Processing Classes
There are many file-processing classes in the Framework Class Library. System.IO namespace includes stream classes such as StreamReader (for input from a stream), StreamWriter (for output to a stream) and FileStream (for both input and output to a stream). These classes inherit from abstract classes TextReader, TextWriter and Stream, respectively.
Abstract class provides functionality for representing streams as bytes. FileStream, MemoryStream and BufferedStream (all from namespace.IO) inherit from class Class. FileStream can be used to write data and read data from files. Class MemoryStream enables the transfer of data directly to and from memory—much faster than reading and writing to external devices.
Class BufferedStream uses buffering technique to transfer data to or from a stream. Buffering is an I/O performance-enhancement technique, in which each operation is directed to a region in memory, called a buffer, that is large enough to hold the data for many operations. The actual transfer is performed in large physical output operation each time the buffer fills. The output operations directed to the output buffer in memory are called logical output operations. Buffering also can be used to speed input operations by initially reading more than required into a buffer, so subsequent reads get data from high-speed memory rather than a slower external device.
