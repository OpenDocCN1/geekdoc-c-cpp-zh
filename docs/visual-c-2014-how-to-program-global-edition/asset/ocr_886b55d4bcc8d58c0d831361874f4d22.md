# Chapter 2 Introduction to Visual Studio and Visual Programming

+   * Menus contain groups of commands (menu items), when selected, cause the IDE to perform actions (for example, open a window, save a file, print a file and execute an app).
* Tool tips help you become familiar with the IDE's features.

# Section 2.4 Navigating the Visual Studio IDE

+   * The Solution Explorer lists all the files in the solution.
* The Toolbox contains controls for customizing Forms.

By using visual development, you can place predefined controls over the Form instead of writing your code. Clicking an name again hides it. To "pin" a window (that is, to disable-auto), click its pin icon.

The Properties window displays the properties for a Form, control or file (in design view). Properties are information about Form or control, such as size, color and position. The Properties allow you to modify Forms and controls, without writing code.

Each control has its set of properties. The left column of the Properties window shows the property names and the right column displays the property values. This window's toolbar options for organizing properties alphabetically when the Alphabetical icon is selected or categorically (for example, Appearance, Behavior, Design) when the Categorized icon is selected.

# Section 2.5 Help Menu and Context-Sensitive Help

+   * Extensive help documentation is available via the Help menu.
* Context-sensitive help brings up a list of relevant help articles. To use context-sensitive help, select an item and press the F1 key.

# Section 2.6 Visual Programming: Creating a Simple App that Displays Text and an Image

+   * C# app development utilizes a combination of writing of the app code and having Visual Studio generate the remaining code.
* The text that appears at the top of the Form (the title bar) is specified in the Form's Text property.
* To resize the Form, click and drag one of the sizing handles (small squares around the Form). Enabled sizing handles appear as boxes.
* The BackColor property specifies the background color of a Form. The Form's background color is the default color for any controls added to the Form.
* Double clicking any control places a control of that type on the Form. Alternatively, you can drag and drop controls from the Toolbox to the Form.
* The Label's Text property determines what (if any) the Label displays. The Form and Label each have their own property.
* A property's ellipsis button, when clicked, displays a dialog containing additional options.
* In the Font dialog, you can select the font in the user interface.
* The UIText property determines how the text is aligned within Label's boundaries.
* The PictureBox displays images. The Image property specifies the image to displayed.
* An app that is in design mode is not executing.
* In run mode, the app is executing—you interact with only a few IDE features.
* When designing an app, the name of the Visual C# file appears in the project tab, followed by [Design].
* Terminate an app's execution by clicking its close box.
