+   a) Manipulating the Form's properties. Change the Text property of the Form to Calculator. Change the Font property to 9pt Segoe UI. Change the Size property of the Form to 258, 210.
b) Adding a TextBox to the Form. Set the TextBox's property in the Properties window to 0. Stretch the TextBox and position it as shown in Fig. 2.38. The TextAlign property to Right aligns this text displayed in the TextBox.
c) Adding the first Panel to the Form. Panel controls are used to group other controls. Add a Panel1 to the Form. Change the Panel's BorderStyle property to Fixed3d to make the size of the Panel appear recessed. Change the size property to 90, 120. This Panel1 will contain the calculator's numeric keys.
d) Adding the second Panel1 to the Form. Change the Panel's BorderStyle property to Fixed3d. Change the size property to 62, 120. This Panel will contain the calculator's operators.
e) Adding the third (and last) Panel to the Form. Change the Panel's BorderStyle property to Fixed3d. Change the size property to 54, 62. This Panel will contain the calculator's C (clear) and C/A (clear all) keys.
f) Adding Buttons to the Form. There are 20 Buttons on the calculator. Add a Button to the Form by dragging and dropping it onto the Panel. Change the Text property of Button to calculator it represents. The value you enter in the Text will appear on the face of the Button. Finally, resize the Buttons, using their Size properties. Each Button labeled 0-9, *, /, -, = and . should have a size of 23, 23. The 00 Button has size 52, 23. The OFF Button has size 54, 23. The + Button is sized 23, 21. The C (clear) and C/A (clear all) Buttons are sized 44, 23.
