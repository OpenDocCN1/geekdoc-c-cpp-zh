### 8.4.2 Using an Array Initializer

An app can create and initialize its elements with an array initializer—comma separated list of expressions (using initializer list) enclosed in braces. The array length is determined by the number of elements in the initializer list. For example,

```csharp
int[] n = {10, 20, 30, 40, 50};
```

creates a five-element array with index values 0, 1, 2, 3 and 4. n[0] is initialized to 10, n[1] to 20 and so on. This statement does not require to create the array object—the compiler counts the number of initializers (5) to determine the array's size, then sets up the appropriate new operation "behind the scenes." The app in Fig. 8.3

initializes an array with 5 values (line 10) and displays the array in tabular format.
Lines 15–18 for displaying the array's contents are identical to lines 15–18 of 8.2.

### 8.4.4 Summing the Elements of an Array

Often, the elements of an array represent series of values to be used in a calculation. For example, the elements of an array represent exam grades; an instructor may wish to sum the elements then calculate the class average. The GradeBook examples later in the chapter (Sections 8.8 and 8.10) use this technique. Figure 8.5 sums the values contained in a ten-element array, which is declared and initialized in line 9. For the state performs the calculations by adding each element's value to the total (line 15).

```csharp
// Fig. 8.5: SumArray.cs
// Computing the sum of the elements of an array.
class SumArray{
    static void Main()
    int[] array = {77, 68, 94, 100, 83, 78, 85, 91, 76, 87};
    int total = 0;
    // add each element's value to total
    for (int counter = 0; counter < array.Length; ++counter)
        total += array[counter]; // add element value to total
    Console.WriteLine($"Total of array elements: {total}");
}
```
