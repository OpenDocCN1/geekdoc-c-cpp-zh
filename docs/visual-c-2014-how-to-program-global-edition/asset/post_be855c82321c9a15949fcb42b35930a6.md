## 10.12 Object Initializers

Object initializers allow you to create an object and initialize its public properties (and public instance variables, any) in the same statement. This can be useful when a class does not provide an appropriate constructor to meet your needs, but does provide a constructor that can be called with no arguments and properties that you can use to set the class's data. The following statements demonstrate object initializers using the class Time2 from 10.5.

```
// create a Time2 object and initialize its properties
var aTime = new Time2 {Hour = 14, Minute = 30, Second = 12};

// create a Time2 object and initialize only its Minute property
var another = new Time2 {Minute = 45};
```

The first statement creates a Time2 object (aTime), initializes it with Time2's constructor that can be called with no arguments, then uses an object initializer to set its Hour, Minute and Second properties. Note that new Time2 is immediately followed by an object initializer list—a comma-separated list in curves { } of properties and their values. Each property name appears only once in the object-initializer list. The object initializer executes the initializers in the order in they appear.

The second statement creates a new Time2 object (another), initializes it with Time2's constructor that can be called with no arguments, then only its Minute property using an object initializer. When the Time2 constructor is called with no arguments, it initializes the time to midnight. The object initializer then sets each property to the supplied value. In this case, the Minute property is set to 45. The Hour and Second properties retain their default values, because no values are set in the object initializer.

## 10.13 Operator Overloading; Introducing struct

Method-call can be cumbersome for certain kinds of operations, such as arithmetic. In these cases, it would be convenient to use C#'s rich set of built-in operators. This section shows how to create operators with objects of your type—via a process called operator overloading.

You can overload most operators. Some are overloaded more frequently than others, especially the arithmetic operators, such as + and -, where operator notation is more natural than calling methods. For a list of overloadable operators, see

> https://msdn.microsoft.com/library/8edha9s

## 10.13 Operator Overloading: Introducing struct

### 10.13.1 Creating Value Types with struct

To demonstrate operator overloading, we'll define type ComplexNumber (Section 10.13.2). Complex numbers have the

```
realPart + imaginaryPart *
```

where i is √1. Integers and floating-point numbers, complex numbers are arithmetic types that are commonly used in calculations. As you know, C#'s simple numeric types are value types. To mimic the simple numeric types, we'll define ComplexNumber as a value type by using a struct (short for "struct") rather than a class. C#'s simple types like int and double are aliases for types—int is defined by the struct System.Int32, a long by System.Int64, a double by System.Double and so on. The operator overloading techniques shown in Section 10.13.2 can also be applied to classes.

#### When to Declare a struct Type

Microsoft recommends using classes for most types, but recommends a struct if:

- the type represents a single value—a complex number represents number that happens to have a real part and an imaginary part.
- the size of object is 16 bytes or smaller—we will represent a complex number's real and imaginary parts using two doubles (alt of 16 bytes).

For the complete list of struct recommendations, use

> https://msdn.microsoft.com/library/ms229017

### 10.13.2 Value Type ComplexNumber

Value ComplexNumber (Fig. 10.14) overflows the (+), minus (-) and multiplication (*) operators to add, subtract and multiply instances of ComplexNumber.

```
// Fig. 10.14: ComplexNumber.cs
// Value type that overflows for adding,
// subtracting and multiplying.
using System;

public struct ComplexNumber
{
    // read-only properties
    public double Real { get; }
    public double Imaginary { get; }

    // constructor
    public ComplexNumber(double real, double imaginary)
    {
        Real = real;
        Imaginary = imaginary;
    }

    // overloaded operators
    public static ComplexNumber operator +(ComplexNumber a, ComplexNumber b)
    {
        return new ComplexNumber(a.Real + b.Real, a.Imaginary + b.Imaginary);
    }

    public static ComplexNumber operator -(ComplexNumber a, ComplexNumber b)
    {
        return new ComplexNumber(a.Real - b.Real, a.Imaginary - b.Imaginary);
    }

    public static ComplexNumber operator *(ComplexNumber a, ComplexNumber b)
    {
        return new ComplexNumber(a.Real * b.Real - a.Imaginary * b.Imaginary, a.Real * b.Imaginary + a.Imaginary * b.Real);
    }
}
```

Unlike a class, you cannot define a parameterless constructor for structs—the compiler always provides a default constructor that initializes the instance variables to default values. Methods that overload binary operators must take two arguments—the first is the left operand and the second is the right operand. The method's body adds the arguments and returns a new ComplexNumber that represents the sum of the arguments. We do not modify the contents of either the original operands passed as arguments x and y. This matches our intuitive sense of how operator should behave—adding two numbers does not modify either of original values.

### 10.13.3 ComplexTest

ComplexTest (Fig. 10.15) demonstrates the overloaded ComplexNumber operators +, and *. Lines 10–21 prompt the user to enter the real and imaginary parts of two complex numbers, then use this input to create ComplexNumber objects for use in calculations.

```
// Fig. 10.15: ComplexTest
// Overloading operators for complex numbers.
class ComplexTest
{
    // prompt the user to enter the first complex number
    Console.Write("Enter the real part of complex number x: ");
    double realPart = double.Parse(Console.ReadLine());
    Console.Write("Enter the imaginary part of complex number x: ");
    double imaginaryPart = double.Parse(Console.ReadLine());
    var x = new ComplexNumber(realPart, imaginaryPart);

    // prompt the user to enter the second complex number
    Console.Write("Enter the real part of complex number y: ");
    double realPart = double.Parse(Console.ReadLine());
    Console.Write("Enter the imaginary part of complex number y: ");
    double imaginaryPart = double.Parse(Console.ReadLine());
    var y = new ComplexNumber(realPart, imaginaryPart);

    // display the results of calculations with x and y
    Console.WriteLine();
}
```
