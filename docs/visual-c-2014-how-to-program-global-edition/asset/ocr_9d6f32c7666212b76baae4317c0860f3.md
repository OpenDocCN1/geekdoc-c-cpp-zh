# 4.9 Account Class with a Balance: Processing Monetary Amounts

In this section, we will declare an Account class that maintains an Account's balance in addition to its name. Most account balances are not whole numbers (such as 0, -22 and 1024), rather they include a decimal point, such as 99.99 or -20.15. For this reason, class Account represents the account balance using type decimal, which is designed to precisely represent numbers with decimal points, especially monetary amounts.
