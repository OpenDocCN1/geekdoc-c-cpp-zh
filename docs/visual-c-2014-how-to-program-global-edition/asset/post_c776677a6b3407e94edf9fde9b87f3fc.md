
# Terminology 851

- In an inorder traversal, the value in each node is processed after the node's left subtree is processed and before the node's right subtree is processed.

- The inorder traversal of a binary search tree processes the node values in ascending order. The process of creating a binary search tree actually sorts the data (when coupled with an inorder traversal)—this, this process is called the binary-tree sort.

- The binary search tree facilitates duplicate elimination. As the tree is created, attempts to insert a duplicate value are recognized as a duplicate follows the same "go left" or "right" decisions on each comparison that the original value did. Thus, the duplicate is compared with a node containing the same value. The duplicate value may simply be discarded at this point.

19.6 (Evaluating Expressions with a Stack) Stacks are used by compilers to evaluate expressions and generate machine code. In this and the next example, we investigate how compilers evaluate expressions consisting only of constants, operators and operands. Humans generally write expressions like 3 + 4 and 7 / 9, in which the operator (+ or /) is written between operands—infix notation. Computers prefer postfix notation, in which the operator is to the right of its operands. The preceding expressions would appear in postfix notation as 3 4 + and 7 9 /, respectively. To evaluate a complex expression, a compiler would first convert the expression to postfix notation, then evaluate the postfix version of the expression. Each of these algorithms requires only a single left-to-right pass of the expression. Each algorithm uses a stack object in support of its operation, and in each algorithm the stack is used for a different purpose. Here, you'll implement the infix-to-postfix algorithm. In the next exercise, you'll implement the postfix-expression algorithm (assume a valid expression).

Write class `InfixToPostfixConverter` to convert an infix arithmetic expression (assume a valid expression), with single-digit integers, such as

```
(6 + 2) * 5 - 8 / 4
```

to a postfix expression. The postfix version of the preceding expression is

```
6 2 5 * 8 4 /
```

The program should read the expression into `StringBuilder`, then use class `StackInheritance` (implemented in Fig. 19.13) to create the postfix expression in `StringBuilder postfix. The algorithm for creating a postfix expression is as follows:
a) Push a left parenthesis '(' on the stack.
b) Append a right parenthesis ')' to the end of the infix.
c) While the stack is not empty, read infix from left to right and do the following:
   - If the current character is a digit, append it to postfix.
   - If the current character is a left parenthesis, push it onto the stack.
   - If the current character is an operator:
     - Pop operators (if there are any) at the top of the stack that have equal or higher precedence than the current operator, and append the operators to postfix.
     - Push the current character into the stack.
   - If the current character is a right parenthesis:
     - Pop operators from the top of the stack and append them to postfix until a left parenthesis is at the top of the stack.
     - Pop (and discard) the left parenthesis from the stack.

The following arithmetic operations are allowed in an expression:
* addition
* subtraction
* multiplication
* division
* exponentiation
* modulus

Some of the methods you want to provide in your program follow:
a) Method `ConvertToPostfix`, which converts the infix expression to postfix notation.
b) Method `IsOperator`, which determines whether `c` is an operator.
c) Method `Precedence`, which determines whether the precedence of `operator1` (from the infix expression) is less than, or equal to the precedence of `operator2` (from the stack). The method returns true if `operator1` has lower precedence or equal precedence to `operator2`. Otherwise, false is returned.
