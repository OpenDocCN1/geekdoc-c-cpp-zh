Line 65 calls HttpClient.GetStringAsync method, which uses the URL specified as the string argument to request information from a web server. Because this URL represents calls to a web-service method, calling GetStringAsync will invoke the Flickr web-service to perform the search. GetStringAsync returns a Task<string> representing a promise to eventually return the search results. Line 68 then awaits the Task's result. At this point, if the Task is complete, method searchButton_Click continues to line 71; otherwise, program control returns to searchButton_Click after the results are returned. This allows the GUI thread of execution to handle other events, the GUI remains responsive while the search is ongoing. Thus, you could start a different search at any time (which cancels the original search in this case).

XML Elements and Attributes
XML represents data as elements, attributes and text. XML delimits elements with start tags and end tags. A start tag consists of the element name, followed by attribute-value pairs, all enclosed in angle brackets. For example, line 1 in the sample XML

<rsp stat="ok">
is the start tag for rsp element containing the entire web-service response. This tag also contains the attribute stat (for status="ok") indicates that the Flickr web request was successful. An end tag consists of the element name preceded by a forward slash (/) in angle brackets (for example, </rsp>) in line 19, which denotes "end of response.".
