# 23.5.1 awaiting Multiple Tasks with Task Method WhenAll1

In method StartButton, Click lines 22 and 19 use Task to run and start Tasks that execute method StartFibonacci (lines 50–66)—one to calculate Fibonacci(46) and one to calculate Fibonacci(45). To show the total calculation time, the app must wait for both Tasks to complete before executing lines 34–46. You can wait by awaiting the result of static method WhenAll1 (line 31), which returns a Task that waits for all of WhenAll1's arguments to complete and places all results in an array. In this app, the Task's Result is a TimeData<>, because both of WhenAll1 executes methods that return TimeData objects. Class TimeData is defined in this project's TimeData.cs file:

```
class TimeData
{
    public DateTime StartTime { get; set; }
    public DateTime EndTime { get; set; }
}
```
