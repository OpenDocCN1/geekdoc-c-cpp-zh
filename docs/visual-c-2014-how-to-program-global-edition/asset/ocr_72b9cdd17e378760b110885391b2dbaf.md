# 438 Chapter 10 Classes and Objects: A Deeper Look

```
// Fig. 10.2: TimelTest.cs
// Timel object used in an app.
using System;

class TimelTest {
    static void Main() {
        // create and initialize a Timel object
        var time = new Timel(); // invokes Timel constructor

        // output string representations of the time
        Console.WriteLine("\n$The initial universal time is: {time.ToUniversalString()}");
        Console.WriteLine("\n$The initial standard time is: {time.ToString()}");
        Console.WriteLine("\n// output a blank line");

        // change time and output updated time
        time.SetTime(13, 27, 6);
        Console.WriteLine("\n$Universal time after SetTime is: {time.ToUniversalString()}");
        Console.WriteLine("\n$Standard time after SetTime is: {time.ToString()}");
        Console.WriteLine("\n// output a blank line");

        // attempt to set time with invalid values
        try {
            time.SetTime(99, 99, 99);
        } catch (ArgumentOutOfRangeException ex) {
            Console.WriteLine(ex.Message + "\n");
        }

        // display time after attempt to set invalid values
        Console.WriteLine("\n$After attempting invalid settings:");
        Console.WriteLine("\n$Universal time: {time.ToUniversalString()}");
        Console.WriteLine("\n$Standard time: {time.ToString()}");
    }
```

The initial universal time is: 00:00:00
The initial standard time is: 12:00:00 AM
Universal time after SetTime is: 13:27:06
Standard time after SetTime is: 1:27:06 PM

Specified argument was out of the range of valid values.

After attempting invalid settings:
Universal time: 13:27:06
Standard time: 1:27:06 PM
