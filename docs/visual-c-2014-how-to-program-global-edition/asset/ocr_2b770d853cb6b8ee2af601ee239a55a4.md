# 10.2 Time Class Study: Throwing Exceptions

# Method SetTime and Throwing Exceptions

SetTime (lines 13–25) is a public method that declares int parameters and uses them to set the time. Lines 16–17 test each argument to determine whether the value is out of range. If all values are in range, lines 22–24 assign the values to the Hour, Minute and Second properties. The hour (line 13) must be in the range 0 to 23, because universal-time format represents hours as integers from 0 to 23 (e.g., 1 PM is hour 13 and PM is hour 23; midnight is 0 and noon is 12). Similarly, both minute and second must be in the range 0 to 59. For values outside this range, line 19 throws an exception of type ArgumentOutOfRangeException (namespace System), which notifies the client that an invalid argument was passed to the method. As learned in Chapter 8, you can try...catch to catch exceptions and recover from them, which we do in 10.2. The throw statement (line 19) creates a new object of ArgumentOutOfRangeException. The parentheses following the class name indicate a call to theOutOfRangeException constructor. After the exception is created, the throw statement immediately terminates method SetTime and the exception is returned to the code that called it, where it can be caught and dealt with.

# Method ToUniversalString

ToUniversalString (lines 28–29) is an expression-bodied method—which returns no return statement. The method takes no arguments and returns a string in universal-time format, consisting of six digits—two for the hour, two for the minute and two for the second. For example, if the time were 1:30:07 PM, method ToUniversalString would return 13:30:07. The method implicitly returns the value of the string-interpolation expression in line 29. The D2 format specifier formats an integer with two digits, and where needed, a leading 0 if the integer has fewer than two digits.

# Method ToString

ToString (lines 32–34) is an expression-bodied method that takes no arguments and returns a string in the Hour. Minute and Second values are separated by colons followed by an AM or PM indicator (e.g., 1:27:06 PM). Like ToUniversalString, method ToString returns the value of a string-interpolation expression. In this case, we do not format the Hour, but we format the Minute and Second as two-digit values with leading 0s. Line 33 uses a conditional operator (:) to determine the value for the Hour—if the hour is 0 or 12 (AM or PM), it appears as 12—otherwise, it appears as a value from 1 to 11. The conditional operator in line 34 determines whether AM or PM will be inserted in the string.

# 10.2 Using Class Time1

The Time1 class (for 10.2) creates a Time1 object and assigns it to local variable. Operator invokes Time1's default constructor, since Time1 does not declare any constructors. Lines 13–17 output the first time, in universal-time format (by invoking ToUniversalString method in line 14), then in standard-time format (by invoking ToString method in line 16) to confirm that the Time1 object was initialized properly.
