# 21.3.3 Array Method Sort

Line 23 uses static array method Sort to sort doubleValues in ascending order. The elements in the array must implement the IComparable interface (all simple types do), which enables method Sort to compare elements to determine their order.

# 21.3.4 Array Method Copy

Line 26 uses static array method Copy to copy elements from intValues to array intValuesCopy. The first argument is the array to (intValues), the second is the destination array (intValuesCopy) and the third is an representing the number of elements to copy (in this case, intValues.Length specifies all elements). Class Array also provides overloads for copying portions of arrays.

# 21.3.5 Array Method BinarySearch

Lines 39 and 30 invoke static method BinarySearch to perform binary searches on array intValues. Method BinarySearch receives the sorted array in which to search and the key for which to search. The method returns the index in the array at which the key (or a negative number) was not found. BinarySearch assumes that it receives a sorted array. Its behavior on an unsorted array is undefined. Chapter 18 discusses searching in detail.

# 21.3.6 Array Method GetEnumerator and Interface IEnumeratorator

Method PrintArrays (46–77) uses class Array to iterate over the elements of the array. Class Array implements the IEnumerator (the non-generic version of IEnumerable<T>). All arrays inherit from Array, so both int[] and array types implement IEnumerator method GetEnumerator, which returns an enumerator that can iterate over the collection—this method always returns an enumerator positioned before the first element. Interface IEnumerator defines MoveNext and Reset property Current:

+   - MoveNext moves the enumerator to the next element in the collection. The first call to MoveNext moves the enumerator at the first element of the collection—if there is an element, MoveNext returns true; otherwise, the method returns false.

+   - Method Reset positions the enumerator before the first element of the collection.
