# 3.3.5 Errors, Error Messages and the Error List Window

Go back to the app in Visual Studio. As you type code, the IDE responds either by syntax-color highlighting or by generating an error. When an error occurs, the IDE underlines the error with a red squiggly line and provides a description of it in the Error List window (Fig. 3.9). If the Error List is not visible, see View > Error List to display it. In Fig. 3.9, we intentionally omitted the semicolon at the end of line 10. The error message indicates the semicolon is missing. You can double click an error message in Error to jump to the error's location in the code.

![](bbox=[0.14, 0.255, 0.212, 0.31])

> Error-Prevention Tip 3.5
Compile-time error can lead to multiple entries in the Error List window. Each error you correct could eliminate subsequent error messages when you recompile your app. So when you see an error you know how to fix it—the IDE will recompile your code in the background, so fixing an error may cause other errors.
