# 8.11 Variable-Length Argument Lists

Variable-length argument lists allows you to create methods that receive an arbitrary number of arguments. A one-dimensional array-type argument preceded by the keyword params in a parameter list indicates that the method receives a variable number of arguments with the type of the array' elements. This use of a params modifier can occur only in the parameter list's last parameter. While you can use method overloading and array passing to accomplish what is possible with variable-length argument lists, using the params modifier is more concise.
