# REST Web Services

Web services enable you to package functionality in a manner that turns the web into a library of reusable services. We include a case study on building a math question generator that is called by a math tutor.

# Building a Microsoft Azure™ Cloud Computing App

Microsoft’s azure services enable you to develop, manage and distribute your apps in the “cloud.” We’ll demonstrate how to use Azure services to store an app’s data.

# Windows Presentation Foundation (WPF) GUI, Graphics and Multimedia

Windows Presentation Foundation (WPF)—created after Windows Forms and before UWP—is another technology for building robust GUI graphics and multimedia apps. WPF provides you with complete control over aspects of a GUI’s look-and-feel and includes multimedia capabilities that are not available in Windows Forms. We discuss WPF in the context of a painting app, a text editor, a color chooser, a book-viewer, a television video player, various animations, and speech synthesis and recognition apps.

We’re moving away from WPF in favor of UWP for creating apps that can run on desktop, mobile and other Windows devices. For this reason, the WPF introduction is provided as from the previous edition—we will no longer feature this material.

# Optional Case Study: Using the UML to Develop an Object-Oriented Design and C# Implementation of an ATM (Automated Teller Machine)

The UML (Unified Modeling Language) is the industry-standard graphical language for visually modeling object-oriented systems. We use the UML in the early chapters and provide an optional object-oriented case study in which we use the UML to design and implement the software for a simple ATM. We analyze a requirements document that specifies the details of the system to be built. We determine the classes needed to implement that, the attributes the classes need to have, the behaviors the classes' methods need to exhibit and we specify how the classes need to interact with one another to meet the system requirements. From the design, we produce a working C# implementation. Students often report a “light bulb moment”—the case study helps them tie it all together and truly understand object orientation.

Live-Code Approach. The book is loaded with “live-code” examples—most concepts are presented in the context of complete working Visual C# apps, followed by one or more executions showing program inputs and outputs. In the few cases we show a code snippet, to ensure correctness we first tested it in a complete working program then copied the code from the program and pasted it into the book.
