# 23.1 Introduction

It would be nice if we focus our attention on performing one task at a time and doing it. That's usually difficult to do in a complex world in which there's so much going on at once. This chapter presents C#'s capabilities for developing programs that create and manage multiple tasks. As we've demonstrated, this can greatly improve performance, especially on multicore systems.

# Concurrency

When we say that two tasks are operating concurrently, we mean that they're making progress at once. Until, most computers had only a single processor. Operating systems on computers execute tasks concurrently by rapidly switching between them, doing a small portion of each before moving on to the next, so that all tasks keep progressing. For example, it' common for personal processors to compile a program, send a file to a printer, receive email messages over a network and, concurrently. Tasks like those that proceed independently of one another are to execute asynchronously and are referred to as asynchronous tasks.
