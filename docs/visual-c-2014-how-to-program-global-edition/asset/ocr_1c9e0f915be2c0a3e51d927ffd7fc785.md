# Exponential Complexity

A word of caution is in order about recursive methods like the one we use here to generate the Fibonacci numbers. The number of recursive calls that are required to calculate the nth Fibonacci numbers is on the order of 2ⁿ. This rapidly grows out as n gets larger. Calculating only the 20th Fibonacci number would require on the order of 2²⁰ or about a million calls, calculating the 30th Fibonacci number would require on the order of 2³⁰ or about billion calls, and so on. exponential complexity can help even the world's most powerful computers! Calculating Fibonacci(47) recursively—even on today's most recent desktop and laptop computers—can take minutes.

# 3.3.2. Method calculateButton_Click

The Calculate button's event handler (lines 21–36) initiates the call to method Fibonacci in a separate thread and displays the results when the call completes. The method is declared async (line 21) to inform the compiler that the method will initiate an asynchronous task and awaits the result. In an async method, you write code that looks as if it executes sequentially, and the compiler handles the complicated issues managing asynchronous execution. This makes your code easier to write, debug, modify and maintain, and reduces errors.
