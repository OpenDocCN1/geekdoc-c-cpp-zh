Figure 14.36 | Demonstrating the NumericUpDown control. (Part 2 of 2)

For the NumericUpDown control named yearUpDown, we set the Minimum property to 1 and the Maximum property to 10. We left the Increment property to 1, its default value. These settings allow users to enter a number of years in range 1 to 10 increments. If we had set the Increment to 0.5, we could allow input values as 1.5 or 2.5. If we had set the DecimalPlaces property (0 default), 1 and 2.5 would appear as 2 and 3, respectively. We set the NumericUpDown ReadOnly property to indicate that the user cannot type a number to make a selection. Then, the user must click the up and down arrows to modify the value in the control. By default, the ReadOnly property is set to false. The output for this app is displayed in a multiline TextBox with a vertical scrollbar, so the user can scroll through the entire output. Notice that \\n is required (lines 24 and 31) to move to the next line in the TextBox.
