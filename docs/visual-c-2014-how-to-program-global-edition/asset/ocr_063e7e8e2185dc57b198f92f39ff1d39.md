# 13.9.2 Revisiting Operators in and as

In 12.5.6, we introduced downcasting with the operator and mentioned that downcasting can cause InvalidCastExceptions. We then mentioned that you can avoid the InvalidCastException by using the operator as follows:

```
var employee = currentEmployee as BasePlusCommissionEmployee;
```

If currentEmployee is a BasePlusCommissionEmployee, employee is assigned the Base-Plus-CommissionEmployee; otherwise, it is assigned null. Since employee could be null, you must ensure that it is not null before using it. For example, to give the BasePlusCommissionEmployee a 10% raise, we could use the

```
employee?.BaseSalary *= 1.1M;
```

which accesses and modifies the BaseSalary property only if employee is not null.

# 13.9.3 Nullable Types

Suppose you'd like to capture the value of the employee?.BaseSalary, as in

```
decimal salary = employee?.BaseSalary;
```

This statement actually results in a compilation error indicating that you cannot implicitly convert decimal? to type decimal.
Normally a nullable-type variable cannot be assigned null. Because the employee reference might be null, the exception

```
employee?.BaseSalary
```

returns a nullable type—a value that can also be null. If you specify a nullable type by following a value's name with a question mark (—decimal? represents a nullable decimal). The statement

```
decimal salary = employee?.BaseSalary;
```

indicates that salary either be null or the employee's BaseSalary.
Nullable types have the following capabilities for checking their values:

+   * The GetValueOrDefault method checks whether a nullable-type variable contains a value. If so, the method returns that value; otherwise, it returns the value's default value. An overload of this method receives an argument that allows you to specify a custom default value.
* The HasValue property returns true if a nullable-type variable contains a value; otherwise, it returns false.
* The Value property returns the nullable-type variable's underlying value or throws an InvalidOperationException if the underlying value is null.

Variables of nullable type may also be used as the left operand of the null-conditional operator (?.) or the null coalescing operator (??—discussed in the next section).

> Error Prevention Tip 13.7 Before using a nullable-type Value, use the HasValue property to check whether the variable has a value. If the nullable-type is null, accessing Value results in an InvalidOperationException.
