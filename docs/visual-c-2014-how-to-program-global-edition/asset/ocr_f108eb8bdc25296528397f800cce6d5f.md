As you type IntelliSense lists items that start with or contain the letters you've typed so far. IntelliSense also displays a tool tip containing the description of the first matching item. You can either type the complete item name (e.g., Console), double click the item name in the member list or press the Tab key to complete it. Once the name is provided, the IntelliSense window closes. While the IntelliSense window is displayed, pressing the Ctrl key makes the window transparent so you can see the code behind it.

When you type the (.) after Console, the IntelliSense window reappears and initially shows only Console members that can be used on the right of the dot—as you type, this list narrows to items containing what you've typed so far. Figure 3.6 shows the IntelliSense window narrowed down to only items that contain “Write”. You can also type “WL” to find all items containing the capital letters “W” and “L” (such as WriteLine).

When you type the parenthesis character (, after Console.WriteLine, the Parameter Info window is displayed (Fig. 3.7). This contains information about the method's parameters—the data required to perform their tasks. You'll learn in Chapter 7, a method can have several versions. That is, a class can define several methods with the same name, as long as they have different numbers and/or types of parameters—a concept known as overloaded methods. These normally perform similar tasks. The Parameter Info window indicates how many versions of the selected method are available and provides up and down for scrolling through the different versions. For example, there are many versions of the WriteLine method that enable you to display different types of data—we use the one that takes a string in our app. The Parameter Info window is one of many features provided by the IDE to facilitate app development. In the next chapters, you'll learn more about the information displayed in these windows.
