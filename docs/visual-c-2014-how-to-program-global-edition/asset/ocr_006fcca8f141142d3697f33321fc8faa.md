**Fig. 8.11** DeckOfCards represents a deck of playing cards. (Part 3 of 3)

**Class DeckOfCards: Constructor**
The constructor uses a for statement (lines 22–25) to fill the deck array with Cards. The statement initializes count to 0 and loops until count is less than deck.Length, causing count to take on each integer value from 0 to 51 (the indices of the deck array). Each Card is instantiated and initialized with two strings—one from the faces array at line 17–18 (which contains the strings "Ace" to "King") and one from the suits array at line 19 ("Hearts," "Diamonds," "Clubs" and "Spades"). The calculation count % 13 (line 24) results in a value from 0 to 12—the indices. Similarly, the calculation / 13 results in a value from 0 to 3—the four indices of array suits. When the deck array is initialized, it contains the Cards with faces "Ace" to "King" in order for each suit. Note that we cannot use a foreach loop in lines 22–25, because we need to modify each element of deck.

**Class DeckOfCards: Shuffle Method**
Shuffle Method (lines 29–45) shuffles the deck. The method loops through all 52 Cards and performs the following tasks:

+   - For each Card, a random number between 0 and 51 is picked to select another Card.
- Next, the current Card object and the randomly selected Card object are swapped in the array. The exchange is performed by three assignments in lines 41–43. The extra variable temp temporarily stores one of the two Cards being swapped.

The swap cannot be performed with only the two statements

```
deck[first] = deck[second];
deck[second] = deck[first];
```

If deck[first] is the "Ace" of "Spades" and deck[second] is the "Queen" of "Hearts," after the first assignment, both array elements contain the "Queen" of "Hearts," and the "Ace" of "Spades" is lost—hence, the extra variable temp is needed. After the loop terminates, the Card objects are randomly ordered. Only 52 swaps are made in a single pass of the entire array, and the array of Cards is shuffled.

**Recommendation: Use an Unbiased Shuffling Algorithm**
It's recommended that you use a so-called unbiased shuffling for real games. An algorithm ensures that all possible shuffled card sequences are equally likely to occur. A popular unbiased shuffling is the Fisher-Yates algorithm
