## 1.12 Visual Studio Integrated Development Environment

C# programs can be created using Microsoft’s Visual Studio—a collection of software tools called Integrated Development Environment (IDE). The Visual Studio Community IDE enables you to write, run, test and debug C# quickly and conveniently. It also supports Microsoft’s Visual Basic, Visual C++ and F# programming languages and more. Most of this book were built using Visual Studio Community, which runs on Windows 7, 8, and 10. A few of the books require Windows 10.

## 1.12 Painter Test-Drive in Visual Studio Community

You’ll now use Visual Studio Community to "test-drive" an app that enables you to draw on the screen using the mouse. The Painter allows you to choose among various brushes and colors. The elements and functionality you see in this app are typical of what you’ll learn to program in this text. For this test drive, we assume that you placed the examples in your user account Documents folder in a subfolder named examples.

### Step 1: Checking Your Setup

Confirm that you’ve set up your computer and the software properly by reading the book’s Before You section that follows the Preface.

### Step 2: Locating the Painter App’s Directory

Open File Explorer (Windows 8 and 10) or Windows Explorer (Windows 7) window and navigate to

```
C:\Users\yourUserName\Documents\examples\ch01
```

Double click the Painter folder to view its contents (Fig. 1.8), then double click the Painter.sln file to open the solution in Visual Studio. An app’s solution contains all of the app’s code files, supporting files (such as images, videos, data files), and configuration information. We’ll discuss the contents of a solution in more detail in the next chapter.

### Step 3: Running the Painter App

To running the Painter app, click the Start button (Fig. 1.9) or press the F5 key.

1.10 Showing the running app and labels of the app's graphical elements—called controls. These include GroupBoxes, RadioButtons, Buttons and a Panel. These controls and others are discussed throughout the text. The app allows you to draw with a Red, Blue, Green or Black brush of Small, Medium or Large size. As you drag the mouse on the white Panel, the app draws circles of specific color and size at the mouse pointer's current position. The slower you drag, the closer the circles will be. Thus, dragging slowly draws a continuous line (as in Fig. 1.11) and dragging quickly draws individual circles with space between them. You can Undo your previous operation or Clear the drawing to start from scratch by pressing the Buttons the RadioButtons in the GUI. By using controls—which are objects—you can create powerful apps faster than if you had to write all the code yourself. This is a key benefit of software reuse.
