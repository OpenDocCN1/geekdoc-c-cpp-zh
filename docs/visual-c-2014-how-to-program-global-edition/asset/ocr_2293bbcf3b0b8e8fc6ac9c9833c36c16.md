# Chapter 20 Generics

+   - As generic methods, the type-parameter list of a generic class can have one or more type parameters separated by commas, and each type parameter can have type constraints.
- When a generic class is compiled, the compiler performs type checking on the class's type parameters to ensure they can be used with the code in the generic class. The constraints determine the operations that can be performed on the variables declared with type parameters.
