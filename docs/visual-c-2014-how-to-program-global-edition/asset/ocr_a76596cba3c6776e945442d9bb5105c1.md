Methods Earnings (Fig. 11.11, line 43) and ToString (lines 46–47) invoke proxy BaseSalary's get accessor to obtain the base-salary value, rather than accessing baseSalary directly. If we decide to rename instance variable baseSalary, only the body of BaseSalary will need to change.
