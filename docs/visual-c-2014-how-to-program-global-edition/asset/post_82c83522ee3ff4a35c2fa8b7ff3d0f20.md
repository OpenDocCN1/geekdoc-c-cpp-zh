The TreeView control displays nodes hierarchically in a tree. Traditionally, nodes are objects that contain values and can refer to others. A parent node contains child nodes, and the child nodes can be parents to other nodes. Two nodes that have the same parent are considered siblings nodes. A tree is a collection of nodes, usually organized in a hierarchical manner. The first parent of a node is the root node (a TreeView can have multiple roots). For example, the file system of a computer can be represented as a tree. The top-level directory (perhaps C:) would be the root, each subfolder of C would be a child node and each child folder could have its own children. TreeView controls are useful for displaying hierarchical information, as the file structure that we just mentioned. We cover nodes and trees in greater detail in Chapter 19, Custom Linked Data Structures. Fig. 15.24 displays a sample TreeView on a form.

To add nodes programmatically, first create a root node. Create a new TreeNode object and pass it a string to display. Then call method Add to add this TreeNode to the TreeView.

```csharp
myTreeView.Nodes.Add(new TreeNode(rootNode));
```

where myTreeView is the TreeView to which we are adding nodes, and rootLabel is the text to display. To add children to a root node, add new TreeNodes to its collection. We select the appropriate root node from the TreeView by writing

```csharp
myTreeView.Nodes[index]
```

where Index is the root node's index in TreeView's collection. We add nodes to children through the same process by which we added nodes to myTreeView. To add a child to the root node, write

```csharp
myTreeView.Nodes[index].Nodes.Add(new TreeNode(ChildLabel));
```
