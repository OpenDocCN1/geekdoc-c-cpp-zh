**Web App Development with ASP.NET**
Microsoft's .NET server-technology, ASP.NET, enables you to create robust, scalable web-based apps. You'll build several apps, including a web-based guestbook that uses ASP.NET and the ADO .NET Entity Framework to store data in a database and display data in a web page.

**Extensible Markup Language (XML)**
The Extensible Markup Language (XML) is pervasive in the software-development industry, e-business and throughout the .NET platform. It's used in most of this book's topics. XML is required to understand XAML—a Microsoft XML vocabulary used to describe graphical user interfaces, graphics and multimedia for Universal Windows Platform (UWP) GUI, graphics and multimedia apps, Windows 10 Mobile apps and Windows Presentation Foundation (WPF) apps. We present XAML fundamentals, which discuss LINQ to XAML, which allows you to query XML content using LINQ syntax.
