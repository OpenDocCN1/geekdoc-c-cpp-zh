Let's proceed with the execution of our first instruction—namely, the +1009 in location 0. As we indicated, the switch statement simulates this task by prompting the user to enter a value, reading and storing it in location memory[operand]. The value is then read into 009.

At this point, simulation of the first instruction is completed. All that remains is to prepare the Simpleton to execute the next instruction. Since the instruction performed was not a transfer of control, we now merely increment the instructionCounter. This action completes the simulated execution of the first instruction. The entire process (i.e., the instruction cycle) begins again with fetch of the next instruction to execute.

Now consider the branching instructions—the transfers of control—are simulated. All we need to do is adjust the value in the instruction counter appropriately. Therefore, the unconditional branch instruction (40) is simulated with the switch as

```
instructionCounter = operand;
```
