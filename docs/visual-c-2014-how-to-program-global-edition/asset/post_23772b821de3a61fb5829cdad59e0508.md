3.27 (Integer Equivalent of a Character) Here's another peek ahead. In this chapter, you have learned about integers and the type char. C# can also represent uppercase letters, lowercase letters and a considerable variety of special symbols. Every character has a corresponding representation. The set of characters that a computer uses and the corresponding integer representations for these characters is called computer's character set. You can indicate a character value in an app by enclosing the character in single quotes, as in 'A'.

You can determine the integer equivalent of a character by preceding that character with (int), 'A'

The keyword int in parentheses is known as a cast operator, and this expression is called a cast expression (You'll learn about cast operators in Chapter 5). The following statement outputs the character and its value:

```csharp
Console.WriteLine("A is {(int)'A'}");
```
