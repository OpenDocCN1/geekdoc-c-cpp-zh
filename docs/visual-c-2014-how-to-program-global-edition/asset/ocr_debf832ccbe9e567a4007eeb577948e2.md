5.38 (Factorials) The factorial of a nonnegative integer n is written n! (pronounced "n factorial") is defined as follows:

```
n! = n · (n - 1) · (n - 2) ··· · 1 (for values of n greater than equal to 1)
```

and

```
n! = 1 (for n = 0)
```

For example, 5! = 5 · 4 · 3 · 2 · 1, is 120. Write an app that reads a nonnegative integer and computes its factorial.
