Why did we declare Earnings as an abstract method? As explained earlier, it simply does not make sense to provide an implementation of this in class Employee. We cannot calculate the earnings for a general Employee—we must first know the specific Employee type to determine the appropriate earnings calculation. By declaring this abstract method, we indicate that each concrete class must provide an appropriate Earnings implementation and that an app will use base-class Employee variables to invoke Earnings polymorphically for any type of Employee.
