
# Terminology 471

- The type of extension method's first parameter specifies the type that you're extending.
- Extension methods must be defined as static methods in a static class.
- The compiler implicitly passes the object's used to call the method as the extension method's first argument. This allows you to call an extension method as if it were an instance method of the extended class.
- IntelliSense displays methods with the extended class's instance methods and identifies them with a distinct icon.
- Cascaded method calls are called from left to right.
- An extension method's fully qualified name is the name of the class in which the extension method is defined, followed by the name of the method and its argument list. When using the fully qualified name, you must specify an argument for parameter.
- If the type being extended defines an instance method with the same name as your extension method and a compatible signature, the method shadows the extension method.

# 10.7 (Set of Integers)

Create class IntegerSet. Each IntegerSet object can hold integers in the 0–100. The set is represented by an array of bools. Array a[i] is true if integer i is in the set. Array a[j] is false if integer j is not in the set. The parameterless constructor initializes the "empty set" (i.e., a set whose array representation contains all false values).

Provide the following methods:

- a) Union creates a set that is the set-theoretic union of two existing sets (i.e., an element of the third set's array is true if it is true in either or both of the existing sets—otherwise, the element of the third is set to false).
- b) Intersection creates a set which is the set-theoretic intersection of two existing sets (i.c., an element of the third set's array is false if element is false in either or both of the existing sets—otherwise, the element of the third is set to true).
- c) Insert inserts a new integer k into a set (by setting a[k] to true).
- d) Delete deletes integer m (by setting a[m] to false).
- e) ToString returns a string containing the set as a list of numbers separated by spaces. Include only those elements that are present in the set. Use -- to represent an empty set.
- f) Equals determines whether two sets are equal.

Write an app to test class IntegerSet. Instantiate IntegerSet objects. Test that all methods work properly.
