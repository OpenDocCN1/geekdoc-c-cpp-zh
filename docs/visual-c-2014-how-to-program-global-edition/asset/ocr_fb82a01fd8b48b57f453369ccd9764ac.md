# 13.2.3 Unhandled Exceptions Terminate the App

In the sample executions in Fig. 13.1, the program terminates when an unhandled exception occurs and a stack trace is displayed. This does not always happen—sometimes a program may continue executing even after an exception has occurred and a stack trace has been displayed. The next section demonstrates how to handle exceptions to enable the program to run to completion.
