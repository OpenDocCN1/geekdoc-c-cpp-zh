To add nodes to the TreeView visually, click the ellipsis next to the Nodes property in the Properties window. This opens the TreeNode Editor (Fig. 15.27), which displays an empty tree representing the TreeView. There are Buttons to create a root and add or delete a node. Here to the right of the current node. Here you can rename the node.

Fig. 15.27 | TreeNode Editor.

To add nodes programmatically, first create a root node. Create a new TreeNode object and pass it a string to display. Then call method Add to add this TreeNode to the TreeView's collection. Thus, to add a root node to TreeView myTreeView, write

```
myTreeView.Nodes.Add(new TreeNode(rootNode));
```
