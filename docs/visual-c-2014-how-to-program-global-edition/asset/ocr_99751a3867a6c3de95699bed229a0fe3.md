# Duplicated Code in Main

The statements in 13–14, 15–16, 27–28, 39–40 and 41–42 are almost identical—each output an Account's name and balance. They differ only in the Account object—account1 or account2. Duplicate code like this can create maintenance problems when it needs to be updated—if you make six of the same code require an error correction or change six times, without making errors. Exercise 4.13 asks you to modify Fig. 4.12 to include a Display method that takes an Account object as a parameter and outputs the object's name and balance, and contains only one copy of the code code. You'll replace Main's duplicated statements with calls to DisplayAccount.
