You can specify an event handler for multiple events by selecting controls (drag them, then Shift click or hold Ctrl and click) and selecting a single method in the Properties Events tab. If you create a new handler this way, you should rename it appropriately so that does not contain one control's name. You could also select each control individually and specify the method for each one's event.
