# 14.7 CheckBoxes and RadioButtons

C# has two types of state buttons that can be in the on/off or true/false states—CheckBoxs and RadioButtons. Like Button, classes CheckBox and RadioButton are derived from class ControlBase.

# 14.7.1 CheckBoxes

A CheckBox is a small square that is either blank or contains a check mark. When the user clicks a Check to select it, a check mark appears in the box. If the user clicks Check to deselect it, the check mark is removed. You can configure a CheckBox to toggle between three states (*checked*, *unchecked*, and *indeterminate*) by setting its Three-State property to true. Any number of CheckBoxes can be selected at a time. A list of common CheckBox properties and a common event appear in Fig. 14.25.
