The code coloring scheme used by the IDE is syntax-color highlighting and helps you differentiate code elements. For example, keywords appear in blue and comments appear in green. Here you can change the colors for various code elements, Visual Studio provides many ways to personalize your coding experience.

# 3.3.2 Changing the Name of the App File

For the apps we create in this book, we change the source-file's default name (Program.cs). To rename a file, right click Program.cs in the Solution Explorer and select Rename to make the file name. Windows automatically selects the file's base name (i.e., Program). Type welcome1, then press Enter to change the name to welcome1. Be sure to keep the .cs file extension.

> Error-Prevention Tip 3.4
When changing a file name in a Visual Studio project, always do so in Visual Studio. Changing file names outside the IDE can break the project and prevent it from executing.
