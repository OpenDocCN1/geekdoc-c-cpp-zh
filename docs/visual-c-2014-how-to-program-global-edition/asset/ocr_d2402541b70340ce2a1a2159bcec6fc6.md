# Software Engineering Observation 5.5

Some programmers do not use program-development tools like pseudocode. They feel that their ultimate goal is to solve the problem on a computer and that writing pseudocode nearly delays the production of final outputs. Although this may work for simple and familiar problems, it can lead to serious errors and delays in large, complex projects.

# 5.10.3 Implementing Sentinel-Controlled Iteration

In Fig. 5.11, method Main implements the pseudocode algorithm of Fig. 5.10. Although each grade entered by the user is an integer, the averaging calculation is likely to produce a number with decimal point—in other words, a real number or floating-point number (e.g., 0.733, 0.0975 or 100.12345). The type int cannot represent such a number, so this example must use float or double. C# provides data types like float and double to store floating-point numbers in memory. The primary difference between these types is that double variables typically store larger magnitude and finer detail (i.e., more digits to the decimal point—also known as the precision). We say more about floating-point types in Chapter 6.

```
// 5.11: ClassAverage.cs
// Solving the class-average problem using sentinel-controlled iteration.
using System;
class ClassAverage
{
    static void Main()
    {
        // initialization phase
        int total = 0; // initialize sum of grades
        int gradeCounter = 0; // initialize # of grades entered so far

        // processing phase
        Console.Write("Enter grade or -1 to quit: ");
        int grade = int.Parse(Console.ReadLine());

        // loop until sentinel value is read from the user
        while (grade != -1)
        {
            total = total + grade; // add grade to total
            gradeCounter = gradeCounter + 1; // increment counter

            // prompt for input and read grade from user
            Console.Write("Enter grade or -1 to quit: ");
            grade = int.Parse(Console.ReadLine());
        }
}
```
