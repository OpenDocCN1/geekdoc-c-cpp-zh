# 23.6 Invoking Flickr Web Service Asynchronously with HttpClient

As shown in the Fig.23.4, you can type one or more tags (e.g., pdeitel flowers) in the TextBox. When you click the Search Button, the application invokes the Flickr web service that searches for photos, returns an XML document containing links to the first 500 (or fewer if there are) that match the tags you specify. We use LINQ to XML to parse the results and display a list of photo titles in a ListBox. When you select an image, the app uses another asynchronous Task to download the full-size image from Flickr and display it in a PictureBox.

# 23.6.1 Using Class HttpClient to Invoke a Web Service

This app uses HttpClient (namespace System.Net.Http) to interact with Flickr's web service and retrieve photos that match the search. Line 21 creates the static HttpClient object that this uses to download data from Flickr. Class HttpClient is one of many .NET classes that support asynchronous programming with async and await. In searchButton_Click (lines 32–96), we use class GetStringAsync method to start a new Task (line 65). When we create the Task, we assign it to instance flickerTask (declared in line 23) so that we can test whether the Task is executing when the user initiates a new search.

> Software Engineering Observation 23.2
An HttpClient is typically declared static so it can be used by all of an app's threads. According to the HttpClient documentation, a static HttpClient object can be used from multiple threads efficiently.

# 23.6.2 Invoking the Flickr Web Service' flicker.photos.search Method

Method searchButton_Click (lines 32–96) initiates the asynchronous Flickr search, so it is declared as an async method. First, lines 35–51 check whether you are starting a search previously and, if so, whether that search has already completed (lines 34–35). If an existing search is still being performed, we display a dialog asking if you want to cancel the search (37–40). If no, the event handler simply returns. Otherwise, we call the HttpClient's CancelPendingRequests method to terminate the search (line 49).

Lines 54–57 create the URL that invokes Flickr's flicker.photos.search web-service method, searches for photos, by the parameters provided. You can learn more about this method and the format of the URL for the method at

```
https://www.flickr.com/services/api/flickr.photos.search.html
```

In this example, we specify values for the following search parameters:

+   - api_key—Your Flickr API key. Remember that you must obtain your key from https://www.flickr.com/services/apps/create/
- tags—A comma-separated list of the tags to search for. In our example it is "pdeitel, flowers". If the user separates the tags with the spaces, the app replaces the spaces with commas.
- tag_mode—We use the all mode to get results that match all the tags specified in the search. You also can use any to get results that match one or more of the tags.
