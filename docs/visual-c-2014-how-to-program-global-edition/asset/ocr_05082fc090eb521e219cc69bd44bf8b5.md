# ClassDocument and LINQ to XML

Namespace System.Xml.Linq contains the classes used to parse XML using LINQ to XML—we use several of these to process the Flickr response. The app we receives the XML result, line 68 (Fig. 23.4) uses XDocument Parse to convert into an XDocument representing the string of XML returned by the await expression. LINQ to query an XDocument to extract data from the XML.

Lines 71–83 use LINQ to gather from each element in the XDocument attributes required to locate the corresponding position from Flickr:

+   - XDocument method Descendants (line 72) returns a list of XElement objects representing the elements with the name specified as an argument—in this case, the photo elements.
- Lines 73–77 use XElement method Attribute extract XAttributes representing the element's id, title, secret, server and farm attributes from the current photo element.
- XAttribute property Value (lines 73–77) returns the value of a given attribute.

For each photo, we create a class FlickrResult (located in this project's FlickrResult.cs file containing:

+   - A Title property—initialized with the photo element's title attribute and used to display the photo's title in the app's ListBox.
- A URL property—assembly from the photo element's id, secret, server and farm (a farm is a collection of servers on the Internet) attributes. The format of the URL for each is specified

```
http://flickr.com/services/api/misc.urls.html
```

We use FlickrResult's URL in imagesListBox_SelectedChanged (Section 23.6.5) to download the corresponding photo when the user selects it in the ListBox.

# 23.6.4 Binding the Photo Titles to the ListBox

If there are any results (line 87), lines 89–90 bind the results' titles to the ListBox. You cannot bind a LINQ query directly to a ListBox, so line 89 invokes LINQ method ToList on the FlickrResult query to convert it to a List, first then the result to the List's data source should be used to populate the ListBox's Items collection. The List contains FlickrResult objects, so line 90 sets the ListBox's DisplayMember property to indicate that each Flickr-Result's Title property should be displayed in the ListBox.
