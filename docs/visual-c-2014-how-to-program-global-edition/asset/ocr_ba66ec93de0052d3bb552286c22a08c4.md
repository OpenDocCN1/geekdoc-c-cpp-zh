# Section 21.2 Collections Overview

+   - The .NET Framework collections provide high-performance, high-quality implementations of common data structures and enable effective software reuse.

+   


- In earlier versions of C#, the .NET Framework primarily provided the collection classes in the System.Collections namespace to store and manipulate object references.

+   


- The .NET Framework's System.Collections.Generic namespace contains collection classes that take advantage of .NET's generics capabilities.

# Section 21.3 Class Array and Enumerators

+   - All arrays inherit from base class array (namespace System).

# Section 21.3.1 C# using static directive

+   - C#'s using static directive allows access to a class's members without qualifying their names.

# Section 21.3.2 Array Method Sort

+   - The static method Sort sorts an array.

# Section 21.3.3 Array Method Copy

+   - The static method Copy copies elements from one array to another.

# Section 21.3.4 Array Method BinarySearch

+   - The static method BinarySearch performs binary searches on an array. This method assumes it receives a sorted array.

# Section 21.3.5 Array Method GetEnumerator and Interface IEnumerator

+   - A collection's GetEnumerator method returns an enumerator that can iterate over the collection.

+   - All enumerators have methods MoveNext and Reset property.

MoveNext moves the enumerator to the next element in the collection; MoveNext returns true if there's at least one element in the collection; otherwise, the method returns false.

+   - Read-only property Current returns the current location in the collection.

# Section 21.3.6 Iterating Over a Collection with foreach

+   - The foreach statement implicitly creates an enumerator via the GetEnumerator method and uses the enumerator's MoveNext property to traverse the collection. This can be done with any collection that implements the IEnumerable—not just arrays.

# Section 21.3.7 Array Methods Clear, IndexOf, LastIndexOf and Reverse

+   - The static method Clear sets a range of elements to 0, false or null, as appropriate.

+   - The static method IndexOf locates the first occurrence of an object in an array or portion of an array.

+   - The static method LastIndexOf locates the last occurrence of an object in an array or portion of an array.

+   - The static method Reverse reverses the contents of an array or portion of an array.

# Section 21.4 Dictionary Collections

+   - A dictionary is a collection of key–value pairs. A hash table is one way to implement a dictionary.

# Section 21.4.1 Dictionary Fundamentals

+   - Hashing is a scheme for for converting keys to unique array indices.
