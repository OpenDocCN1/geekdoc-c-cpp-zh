
## 5.6 if...else Double-Selection Statement

```
If student's grade is greater than or equal to 60
  Display "Passed"
Else
  Display "Failed"
```

represents an if...else statement that displays "Passed" if the student's grade is greater than or equal to 60, but displays "Failed" if it's less than 60. In either case, after "Passed" or "Failed" is displayed, the next pseudocode statement in sequence is performed. The preceding if...else pseudocode statement can be written in C# as

```csharp
if (grade >= 60)
{
  Console.WriteLine("Passed");
}
else
{
  Console.WriteLine("Failed");
}
```

The body of each else part is also indented. Whether indentation convention you choose should be applied throughout your apps.

- **Good Programming Practice 5.1**
  Indent both body statements of an if...else statement. Visual Studio does this for you.

- **Good Programming Practice 5.2**
  If there are several levels of indentation, each level should be indented the additional amount of space. Again, we use three-space indents for book-publication purposes, but Microsoft recommends four-space indent—the default in Visual Studio.

## 5.6.1 Nested if...else Statements

An app can test multiple cases by placing if...else statements inside other if...else statements to create nested if...else statements. For example, the following pseudocode represents a nested if...else statement displays A for exam grades greater than or equal to 90, B for 80 to 89, C for 70 to 79, D for 60 to 69 and F for all other grades:

```
If student's grade is greater than or equal to 90
  Display "A"
Else
  If student's grade is greater than or equal to 80
    Display "B"
    Else
      If student's grade is greater than or equal to 70
        Display "C"
        Else
          If student's grade is greater than or equal to 60
            Display "D"
          Display "F"
```

We use shading to highlight the nesting. This pseudocode may be written in C# as

```csharp
if (studentGrade >= 90)
{
    Console.WriteLine("A")
}
else
{
    if (studentGrade >= 80)
    {
        Console.WriteLine("B")
    }
    else
    {
        if (studentGrade >= 70)
        {
            Console.WriteLine("C")
        }
        else
        {
            if (studentGrade >= 60)
            {
                Console.WriteLine("D")
            }
            else
            {
                Console.WriteLine("F")
            }
        }
    }
}
```

If variable studentGrade is greater than or equal to 90, the first four conditions in the nested if...else statement will be true, but only the statement in the if...else statement will execute. After that statement executes, the else part of the "outermost" if...else statement is skipped. Many programmers prefer to write the preceding if...else statement in the following form, which is identical except for the spacing and indentation in the compiler ingen:

```csharp
if (studentGrade >= 90)
{
    Console.WriteLine("A");
}
else if (studentGrade >= 80)
{
    Console.WriteLine("B");
}
else if (studentGrade >= 70)
{
    Console.WriteLine("C");
}
else if (studentGrade >= 60)
{
    Console.WriteLine("D");
}
else
{
    Console.WriteLine("F");
}
```

The latter form avoids indentation to the right. Such indentation often leaves little room on a line of code, forcing lines to wrap.

> **Error-Prevention Tip 5.1**
> In a nested if...else statement, ensure that you test for all possible cases.

## 5.6.2 Dangling-else Problem

Throughout the text, we always enclose control statement bodies in braces ({ and }). This avoids a logic error called the "dangling-else" problem. We investigate this problem in Exercises 5.27–5.29.

## 5.6.3 Blocks

The if statement normally expects only one statement in its body. To include several statements in the body of an if (or the body of an if...else statement), you must enclose the statements in braces. As we've done throughout the text, it's good practice to always use the braces. Statements contained in a pair of braces (such as the body of a control statement, property or method) form a block. A block can be placed anywhere in a control statement, property or method that a single statement can be placed.

The following example includes the body of if...else:

```csharp
if (studentGrade >= 60)
{
    Console.WriteLine("Passed");
}
else
{
    Console.WriteLine("Failed");
}
```

In this case, if studentGrade is less than 60, the statement `Console.WriteLine("Failed");` is the else part.

### Empty Statement

It is also possible to have an empty statement, represented by a semicolon:

```csharp
if (studentGrade >= 60)
{
}
else
{
}
```

### 5.6.4 Conditional Operator (:)

C# provides the conditional operator that can be used in place of if...else statement. This can make your code shorter and clearer. The ternary operator takes three operands:

- The first operand (to the left of ?) is a bool expression that evaluates to true or false.
- The second operand (between ? and :) is the value of the expression if the bool expression is true.
- The third operand (to the right of :) is the value of the expression if the bool expression is false.

For now, the second and third operands should have the same type. For example:

```csharp
Console.WriteLine(studentGrade >= 60 ? "Passed" : "Failed");
```

The expression evaluates to the string passed to WriteLine's argument. The conditional operator performs essentially the same task as if...else statement shown in 5.6. The precedence of the conditional operator is low, so the entire expression is normally placed in parentheses.

## 5.7 Student Class

The example below demonstrates a nested if...else statement that determines a student's letter grade based on the student's average. The class contains:

- Auto-implemented string property Name (line 7) to store a student's name.
- Instance variable of type int (line 8) to store a Student's average in a course and the corresponding Average property (lines 18–36) to get and set the Student's average.
- Constructor (lines 11–15) that sets the Name and Average properties.
- Read-only property LetterGrade (lines 39–68), which uses nested if...else statement to determine the student's letter grade based on the student's average.

```csharp
public class Student
{
    public string Name { get; set; }
    private int average;
    public int Average
    {
        get { return average; }
        set
        {
            if (value > 0 && value <= 100)
            {
                average = value;
            }
        }
    }
    public Student(string name, int average)
    {
        Name = name;
        Average = average;
    }
    public string LetterGrade
    {
        get
        {
            string letterGrade = string.Empty;
            if (Average >= 90)
            {
                letterGrade = "A";
            }
            else
            {
                if (Average >= 80)
                {
                    letterGrade = "B";
                }
                else
                {
                    if (Average >= 70)
                    {
                        letterGrade = "C";
                    }
                    else
                    {
                        if (Average >= 60)
                        {
                            letterGrade = "D";
                        }
                        else
                        {
                            letterGrade = "F";
                        }
                    }
                }
            }
            return letterGrade;
        }
    }
}
```
