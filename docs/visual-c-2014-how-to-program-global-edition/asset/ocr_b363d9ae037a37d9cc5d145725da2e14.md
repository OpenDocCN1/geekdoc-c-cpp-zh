To create a menu, use the Toolbox and drag a MenuStrip creates a menu bar across the top of the Form (below the title bar) and places a MenuStrip icon in the component. To select the MenuStrip, click this icon. You can use Design mode to create and edit menus for your app. Menu items, like other controls, have events and events, which can be accessed through the Properties window.

To add items to a menu, click the Type Here TextBox. This action adds an entry to the menu of ToolMenuItem. After you press the Enter key, the menu item is added to the menu. Then type Here TextBox appears, allowing you to add items underneath or to the side of the original menu item (15.3).

To create a shortcut, use an ampersand (&) before the character to be underlined. For example, create the File item with the letter F underlined, type &File. To display an ampersand, use &&. To add other shortcuts (e.g., Ctrl+F) for menu items, set the ShortcutKeys of the appropriate ToolMenuItem. To do this, select the down arrow to the right of this property in the Properties window. In the window that appears (15.4), use the CheckBoxes and drop-down list to select the shortcut keys. When you're finished, click elsewhere on the screen. You can hide the shortcuts by setting property ShowShortcutKeys to false, and you can modify how shortcut keys are displayed in the menu item by modifying ShortcutKeyDisplayString.
