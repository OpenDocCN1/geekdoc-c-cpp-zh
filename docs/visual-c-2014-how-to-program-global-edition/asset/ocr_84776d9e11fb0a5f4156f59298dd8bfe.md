where i is √1. Integers and floating-point numbers, complex numbers are arithmetic types that are commonly used in calculations. As you know, C#'s simple numeric types are value types. To mimic the simple numeric types, we'll define ComplexNumber as a value type by using a struct (short for "struct") rather than a class. C#'s simple types like int and double are aliases for types—int is defined by the struct System.Int32, a long by System.Int64, a double by System.Double and so on. The operator overloading techniques shown in Section 10.13.2 can also be applied to classes.

# When to Declare a struct Type

Microsoft recommends using classes for most types, but recommends a struct if:

+   - the type represents a single value—a complex number represents number that happens to have a real part and an imaginary part.

+   - the size of object is 16 bytes or smaller—we will represent a complex number's real and imaginary parts using two doubles (alt of 16 bytes).

For the complete list of struct recommendations, use

> https://msdn.microsoft.com/library/ms229017
