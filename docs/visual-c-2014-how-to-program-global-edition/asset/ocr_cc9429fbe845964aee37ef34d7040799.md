The app reads the numbers from the array and graphs the information as a bar chart. Each grade range is followed by a bar of asterisks indicating the number of grades in that range. To label each bar, lines 17–24 display a grade range (e.g., "70-79:") based on the current value of counter. When counter is 10, line 19 displays " 100: " to align the colon with the other bar labels. When counter is not 10, line 23 uses the string-interpolation expressions

```
{counter * 10:D2}
```

and

```
{counter * 10 + 9:D2}
```

to format the label of the grade. The format specifier D indicates that the value should be formatted as an integer, and the number after the D indicates how many digits this integer must contain. The I indicates that values with fewer than two digits should begin with a leading 0.
The nested statement (lines 27–30) displays the bars. Note the loop-continuation at line 27 (stars < array[counter]). Each time the app reaches the inner, the loop counts from 0 up to less than array[counter], thus using a value in array to determine the number of asterisks to display. In this example, [0]array[5] contains no students received a grade below 60. Thus, the app displays no asterisks next to the first six grade ranges.
