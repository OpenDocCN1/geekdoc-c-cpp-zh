# Chapter 10 Classes and Objects: A Deeper Look

```
// Fig. 10.8: Employee.cs
// Employee class with references to other objects.
public class Employee
{
    public string FirstName { get; }
    public string LastName { get; }
    public Date BirthDate { get; }
    public Date HireDate { get; }

    // constructor to initialize name, birth date and hire date
    public Employee(string firstName, string lastName,
        Date birthDate, Date hireDate)
    {
        FirstName = firstName;
        LastName = lastName;
        BirthDate = birthDate;
        HireDate = hireDate;
    }

    // convert to string format
    public override string ToString() => "{LastName}, {FirstName} " +
        "$Hired: {HireDate} Birthday: {BirthDate}";
}
```

# 10.7.3 EmployeeTest

EmployeeTest (10.9) creates two Date objects (lines 9–10) to represent an Employee's birthday and hire date. Line 11 creates an Employee and initializes its instance by passing to the constructor two strings (representing the Employee's first and last names) and two Date objects (representing the birthday and hire date). Line 13 implicitly uses the Employee's ToString method to display the string representation and demonstrate that the object was initialized properly.

```
// Fig. 10.9: CompositionTest.cs
// Composition demonstration.
using System;
class EmployeeTest
{
    static void Main()
    {
        var birthday = new Date(7, 24, 1949);
        var hireDate = new Date(3, 12, 1988);
        var employee = new Employee("Bob", "Blue", birthday, hireDate);
        Console.WriteLine(employee);
    }
```
