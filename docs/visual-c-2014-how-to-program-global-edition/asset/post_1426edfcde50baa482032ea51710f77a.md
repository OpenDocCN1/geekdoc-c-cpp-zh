## Section 17.17 Value Types vs. Reference Types

- Types in C# are divided into value types and reference types.
- C# simple types (like int), enum types are all value types.
- A variable of a value type simply contains a value of that type.
- A reference-type variable (sometimes called a reference) contains the location where the data referred to by that variable is stored. A variable is said to refer to an object.
- Reference-type instance variables are initialized by default to null.
- Type is a reference type. A string variable with the value null is not an empty string, which is represented by "" or string.Empty.
- The null represents a reference that does not refer to an object.
- The empty string is a string object that does not contain characters.

## Section 17.18 Passing Arguments by Value and Reference

- Two ways to pass arguments in many programming languages are pass-by-value and pass-by-reference.
- When an argument is passed by value (the default), a copy of the argument's value is passed to the called method. Changes to the copy do not affect the original variable's value in the caller.
- When an argument is passed by reference, the caller gives the method the ability to access and modify the caller's original data.
- Value-type variables store value, so specifying a value-type variable in a method call passes a copy of that variable to the method. Reference-type variables store objects, specifying a reference-type variable as an argument passes a copy of the actual reference that refers to the object.
- When returning information from a method via a return statement, the method returns a copy of the value stored in the value-type variable or a copy of the reference stored in a reference-type variable.

## Section 17.1.1 ref and out Parameters

- C# provides the keywords ref and out to pass variables by reference.
- A ref parameter indicates that an argument will be passed to the method by reference—the called method will be able to modify the original variable in the caller.
- An out parameter indicates that a potentially uninitialized variable will be passed into the method by reference and that the called method will assign a value to the original variable in the caller.
- A method can return only one value through its return statement, but can return many values by specifying multiple output (ref and/or out) parameters.
- When a variable is passed to a method with a reference parameter, you must precede the variable with the same keyword (ref or out) that was used to declare the reference parameter.
