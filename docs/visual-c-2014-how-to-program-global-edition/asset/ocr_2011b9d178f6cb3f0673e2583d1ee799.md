# Common Programming Error 6.3

Using an incorrect relational operator in the loop-continuation condition of a loop that counts down (e.g., using < 1 instead of >= 1 in a loop counting down to 1) would cause a logic error.

![](bbox=[0.176, 0.513, 0.218, 0.553])

# Common Programming Error 6.4

Do not use equality operators (! or ==) in a loop-continuation condition if the loop's control variable increments or decrements by more than 1. For example, consider the statement header for (int counter = 1; counter += 2). The loop-continuation test (counter != 10) never becomes false (resulting in an infinite loop) because counter increases by 2 each iteration (and never becomes 10).
