# Terminology 581

# Section 13.9.1 Null-Conditional Operator (?.)

+   * C 6's new null-conditional operator (?) accesses a property or calls a method only if its left operand is not null; evaluation of the expression terminates and the value of the entire expression is null.

# Section 13.9.3 Nullable Types

+   * A nullable is a value type that can also be null.

+   * You specify a type by following a value's name with a question mark (?).

+   * GetValueOrDefault method checks whether a nullable-type variable contains a value. If so, the method returns that value; otherwise, it returns the type's default value.

+   * The HasValue property returns true if a nullable-type variable contains a value; otherwise, it returns false.

+   * The Value property returns the nullable-type's underlying value.

# Section 13.9.4 Null Coalescing Operator (??)

+   * The null coalescing operator (??) has two operands. If the left operand is not null, the entire expression evaluates to the left operand's value; otherwise, it evaluates to the right operand's value.

# Section 13.10 Exception Filters and the C# 6 when Clause

+   * Prior to C 6, you could catch an exception based only on its type.

+   * C# 6 introduces exception filters that enable you to catch an exception based on a catch's exception type and a condition that is specified with a clause.

+   * You can specify an exception filter for a general catch clause that does not provide an exception type.

+   * A catch with an exception filter catches the exception only if the catch's condition is true.

+   * If an exception filter's condition is false, the exception will not be caught and the original exception's stack-trace information will be preserved until the exception is caught.
