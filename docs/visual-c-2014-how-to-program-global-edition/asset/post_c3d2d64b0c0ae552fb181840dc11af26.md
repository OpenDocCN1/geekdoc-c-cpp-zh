## 7.9.2 Main's Local Variables

The game is reasonably involved. The player may win or lose on the first roll or lose on any subsequent roll. ## 7.9 Case Study: A Game of Chance; Introducing Enumerations

### 7.9.3 enum Status

Local variable gameStatus (line 27) is declared to be of a new type called Status, which we declared in line 11. Status is a user-defined type called enumeration, which declares a set of constants. An enumeration is introduced by the keyword enum and a name (in this case, Status). As a class, braces ({ and }) delimit the body of an enum declaration. Inside the braces is a comma-separated list of enumeration constants—by default, the first constant has the value 0 and each subsequent constant’s value is incremented by 1. The enum constants must be unique, the value associated with each constant must not be. Status is declared as a private member of class Craps, because Status is used only in that class.

Variables of type Status are assigned only one of the three constants declared in the enumeration. When the game is won, the app sets gameStatus to Status.Won (lines 37 and 59). When the game is lost, the app sets gameStatus to Status.Lost (lines 42 and 66). Otherwise, the app sets gameStatus to Status.Continue (line 45) until the die may be rolled again.
