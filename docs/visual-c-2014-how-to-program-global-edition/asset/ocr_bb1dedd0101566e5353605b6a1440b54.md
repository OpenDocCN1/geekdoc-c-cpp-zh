# 21.8.1 Declaring a Delegate Type

Line 9 declares a delegate type named NumberPredicate. A variable of this type can store a reference to any method that takes one int and returns a bool. A delegate type is declared by preceding a method header with the keyword delegate (placed after any access specifiers, as public or private) and following the method header with a semicolon. A delegate declaration includes the method header only—the header describes a set of methods with specific parameters and a specific return type.
