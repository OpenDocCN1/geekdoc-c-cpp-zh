## Section 4.3.6 Access Modifiers: private and public

- The keyword is an access modifier.
- A private variable is accessible only to methods (and other members, like properties) of the instance variable’s class. This is known as information hiding.
- Most variables are declared private.
- Methods (and other class members) that are declared public can be used by methods (and other members) of the class in which they are declared, by the class’s clients.
- By default, classes are private, unless you specify otherwise with access modifiers.

## Section 4.3.7 UML Class Diagram

- UML diagrams summarize a class’s attributes and operations.
- UML diagrams help designers specify systems in a concise, graphical, programming-independent manner, before programmers implement the systems in specific programming languages.
- In the UML, each class is modeled in a class diagram as a rectangle with three compartments.
- The top compartment contains the class name centered horizontally in boldface font.
- The middle compartment contains the class’s attributes.
- A minus sign (-) access modifier for an attribute indicates that the attribute is private.
- Following an attribute name is a colon and the attribute type.
- The bottom compartment contains the class’s operations.
- The UML models operations by listing the operation name preceded by an access modifier.
- A plus (+) indicates a public operation.
- The UML indicates the return type of an operation by placing a colon and the return type after the parentheses following the operation name.
- The UML models a parameter by listing the parameter name, followed by a colon and the parameter type in the parentheses after the operation name.

### Section 4.6.2 Class Account with an Instance Variable

- A property declaration specifies the access, type, and name.
- By convention, the property name is capitalized.

### Section 4.6.3 UML Diagram with a Property

- In UML, properties are marked with the stereotype «property».
- A public property is indicated by a plus sign (+).
- A private property is indicated by a minus sign (-).

## Section 4.7 Auto-Implemented Properties

- With auto-implemented properties, C# creates a hidden private instance variable and provides get and set accessors.
- The get accessor returns the instance variable, and the setter assigns value to it.

## Section 4.8 Account Class: Initializing Objects with Constructors

- A constructor is used to initialize an object when it is created.

### Section 4.8.1 Declaring a Constructor for Account

- A constructor must have the same name as the class.
- An important difference between constructors and methods is that constructors cannot specify a return type (not even void).
- Normally, constructors are declared public so they can be used by the client code to initialize objects of the class.

### Section 4.8.2 Class AccountTest: Initializing Objects When They Are Created

- Creating an object with `new` implicitly calls the class constructor.
- In any class that does not explicitly declare a constructor, the compiler provides a public default constructor with no parameters.
- If you declare one or more constructors for a class, the compiler will not create a default constructor.
- The UML models constructors as operations in the third compartment.
- To distinguish a constructor from the class's operations, the UML requires that the word "constructor" be enclosed in guillemets («») and placed before the constructor name.
- It is custom to list constructors before other operations in the third compartment.

## Section 4.9 Account Class with a Balance: Processing Monetary Amounts

Type decimal is designed to precisely represent numbers with decimal points, such as monetary amounts.

### Section 4.9.1 Account Class with a decimal Instance Variable

- A decimal instance variable is initialized to zero by default.
- A property setter can perform validation (also known as validity checking).
- The letter D appended to a numeric literal indicates the number is a decimal literal.
- By default, the get and set accessors of property have the same access as the property.
- Get and set accessors have different modifiers. One of the accessors must have the same access as the property and the other must be declared with more restrictive access.
- A private setter accessor may be used only by the property's class, not by the class's clients.

### Section 4.9.2 AccountTest Class That Creates and Uses Account Objects

- You can specify formatting in a C# string interpolation expression by following the value in the braces with a format specifier.
- The format specifier C formats a numeric value (C is for currency)—typically with digits to the right of the decimal point.
- The Windows culture settings on the user's machine determine the format for displaying currency amounts, such as the commas, periods for separating thousands, millions, etc.
- Unlike instance variables, local variables are not initialized by default.
- Type decimal.Parse method converts a string to a decimal value.
