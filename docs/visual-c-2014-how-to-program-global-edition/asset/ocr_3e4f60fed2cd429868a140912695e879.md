# 8.6.2 Class DeckOfCards

DeckOfCards (Fig. 8.11) creates and manages an array of Card references. The named constant NumberOfCards (line 10) specifies the number of Cards in a deck (52). Line 11 declares an instance-variable name that refers to an array of Card objects with Number-OfCards (52)—elements—the deck array is null by default. Simple-type declarations, the declaration of a variable for an array of objects (e.g., Card[] deck) indicates the type of the elements, followed by square brackets and the name of the variable. DeckOfCards also declares instance variable-Card (line 12), representing the next Card to be dealt from the deck array. Note that we cannot use var for type inference for NumberOfCards, deck and currentCard, because they are not local variables of a method or property.
