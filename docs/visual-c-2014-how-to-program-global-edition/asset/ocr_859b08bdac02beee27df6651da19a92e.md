The next sections present three Visual Studio windows that you'll use frequently—the Solution Explorer, the Properties window and the Toolbox. These windows display project information and include tools that help you build your apps.

# 2.4.1 Solution Explorer

The Solution Explorer (Fig. 2.13) provides access to all of a solution's files. If it's not shown in the IDE, select View > Solution Explorer. When you open a new or existing solution, the Solution Explorer displays the solution's contents.

![](bbox=[0.268, 0.477, 0.73, 0.65])

Fig. 2.13 Solution Explorer window showing the WindowsFormsApplication1 project.

The solution's start project (shown in **bold in the Solution Explorer) is the one that runs when you select Debug > Starting (or press F5) or select Debug > Without Debugging (or press Ctrl+F5). For a single-project solution like the example in this book, the start project is the only project (in this case, WindowsFormsApplication1). When you create an app for the first time, the Solution Explorer appears as shown in Fig. 2.13. The C# file that connects to the Form shown in Fig. 2.4 is named Form1.cs. Visual C# files use the .cs file extension, which is short for “C#.”

By default, the IDE only displays files that you need to edit—other files that the IDE generates are hidden. The **Solution Explorer** window includes a toolbar that contains several icons. Clicking the Show All Files icon (Fig. 2.13) displays all the solution's files, including those generated by the IDE. Clicking the arrow to the left of a node expands or collapses that node.
