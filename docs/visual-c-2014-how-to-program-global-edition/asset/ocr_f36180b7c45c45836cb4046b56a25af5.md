Common Multidimensional-Array Manipulations Performed with for Statements
Many common array manipulations use for statements. As an example, the following for statement sets all the elements in row 2 of rectangular array a in 8.17 to 0:

```
for (int column = 0; column < a.GetLength(1); ++column)
  a[2, column] = 0;
}
```

We specified 2; therefore, we know that the first index is always 2 (0 is the first row, and 1 is the second row). This loop varies only the second index (i.e., the column in-). The preceding for statement is equivalent to the assignment statements

```
a[2, 0] = 0;
a[2, 1] = 0;
a[2, 2] = 0;
a[2, 3] = 0;
```

The following nested statement for the values of all the elements in array a:

```
for (int row = 0; row < a.GetLength(0); ++row)
  for (int column = 0; column < a.GetLength(1); ++column)
    total += a[row, column];

```

These nested statements for total the array elements one row at a time. The outer for statement begins setting the row index to 0 so that row 0's elements can be totaled by the inner for statement. The outer for then increments row to 1 so that row 1's elements can be totaled. Then the outer for increments row to 2 so that row 2's elements can be totaled. The variable total can be displayed when the outer for statement terminates. In the next example, we show how to process a rectangular array in a more concise manner using foreach statements.
