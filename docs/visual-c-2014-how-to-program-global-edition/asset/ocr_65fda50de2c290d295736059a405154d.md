It can be difficult to remember what each toolbar icon represents. Hovering the mouse pointer over an icon highlights it, and after a brief pause, displays a description of the icon called a tool tip (2.9)—these tips help you become familiar with the IDE's features and serve as reminders for each toolbar icon's functionality.
