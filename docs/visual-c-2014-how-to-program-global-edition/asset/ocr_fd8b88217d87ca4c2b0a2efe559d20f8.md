# Keyboard events and event arguments

| Key Events with Event Arguments of Type KeyEventEventArgs |
| --- | --- |
| KeyDown | Generated when a key is initially pressed. |
| KeyUp | Generated when a key is released. |
| Key Event with Event Argument of Type KeyPressEventArgs |
| KeyPress | Generated when a key is pressed. Raised after KeyDown and before KeyUp. |
| ClassPressEventArgsProperties |
| KeyChar | Returns the ASCII character for the key pressed. |
| Class KeyEventEventArgsProperties |
| Alt | Indicates the Alt key was pressed. |
| Control | Indicates the Shift key was pressed. |
| Shift | Indicates the Shift key was pressed. |
| KeyCode | Returns the code for the key as a value from the Keys enumeration. This does not include modifier-key information. It's used to test for a specific key. |
| KeyData | Returns the code for a key combined with modifier information as a Keys. This property contains all information about the pressed key. |
| KeyValue | Returns the key as an int, rather than a value from the Keys enumeration. This property is used to obtain a numeric representation of the pressed key. The int value is known as a Windows virtual key. |
| Modifiers | Returns a value indicating any pressed modifier keys (Alt, Ctrl and Shift). This property is used to determine modifier-key information only.
