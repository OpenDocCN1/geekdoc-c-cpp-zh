# 7.3.2 Math Constants PI and E

Recall from Section 43 that each object of a class maintains its own copy of the class*instance variables. There are also variables for which each object of a class does not need its own separate copy—static variables are also known as class variables. When a class containing static variables is created, all the objects of that class share one copy of those. Together a class static and instance variables are known as their fields. You'll learn more about static fields in Section 10.9.

Class Math also declares two constants used commonly with mathematical values:

+   * Math.PI (3.1415926535897931) is the ratio of a circle's circumference to its diameter, and
* Math.E (2.718281828459045) is the base for natural logarithms (calculated with static method Math Log).

These constants are declared in class Math with the modifiers public and const. Making them public allows other programmers to use these variables in their own classes. A constant declared with the keyword const—its value cannot be changed after the constant is declared. Fields const are implicitly static, so you can access them via the class name and member-access operator (.), as in Math.PI and Math.E.

> > Common Programming Error 7.1
Declared in a class, but not inside a method or property, are implicitly static—it's a syntax error to declare such a constant with static explicitly.
