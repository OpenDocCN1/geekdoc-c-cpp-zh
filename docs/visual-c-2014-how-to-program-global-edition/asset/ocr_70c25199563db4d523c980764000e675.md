# 8.1 Introduction

This chapter introduces the important topic of data structures—collections of related data items. Arrays are data structures consisting of related data of the same type. Arrays are fixed-length entities—they remain the same length once they're created, although an array variable may be reassigned so that it refers to a new array of different length.
