# Anonymous Types

Recall from Section 9.3.5 a LINQ query can create an anonymous type with the properties in the initializer-list—in this case, FirstName, LastName and ISBN (line 26). Note that all properties of anonymous types are public and readonly. The type has no name, you must use implicitly typed local variables to store references to objects of anonymous types (e.g., line 31). Also, in addition to the ToString method in an anonymous type, the compiler provides an Equals method, which compares the properties of the anonymous object that calls the method and the anonymous object it receives as an argument.
