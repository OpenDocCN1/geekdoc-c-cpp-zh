
## SortedDictionary's Values Property

If you do not need the keys, SortedDictionary also provides a read-only Values property that gets `ICollection<T>` of all the values stored in the SortedDictionary. You could use this property to iterate through the values stored in the SortedDictionary without regard for their corresponding keys.

## 21.5 GenericList Collection

Section 9.4 introduced the generic List<T>, which defines an array-based implementation. Here, we discuss LinkedList<T>, which defines a doubly linked list that an app can navigate both forwards and backwards. A LinkedList<T> contains nodes of generic class LinkedList<T>. Each node contains property Value and read-only properties Previous and Next. The Value property matches LinkedList<T>'s single type parameter because it contains the data stored in the node. Previous gives a reference to the preceding node in the linked list (or null if the node is the first). Similarly, Next gives a reference to the subsequent reference in the linked list (or null if the node is the last of it). We demonstrate a few linked-list manipulations in Fig. 21.5.

```csharp
// Fig. 21.5: LinkedTest.cs

using System;
using System.Collections.Generic;

class LinkedTest
{
    private static readonly string[] colors =
        "black", "yellow", "green", "blue", "violet", "silver";
    private static readonly string[] colors2 =
        "gold", "white", "brown", "blue", "gray";

    // set up and manipulate LinkedList objects
    static void Main()
    {
        var list1 = new LinkedList<string>();
        // add elements to first linked list
        foreach (var color in colors)
        {
            list1.AddLast(color);
        }

        // add elements to second linked list via constructor
        var list2 = new LinkedList<string>(colors2);
        Concatenate(list1, list2); // concatenate list2 onto list1
        PrintList(list1);
        Console.WriteLine("\nconverting strings in list1 to uppercase\n");
        ToUpperStrings(list1); // convert to uppercase string
```
