# 7.17 Value Types vs. Reference Types

Types in C# are divided into two categories—value types and reference types.

# Value Types

C#'s simple types (like int, double and decimal) are all value types. A variable of a value type contains a value of that type. For example, Fig. 7.18 shows an int1 variable named that counts the value 7.

```
int count = 7;
```

| count |
| A variable (count) of a value type (int) contains a value (7) of that type |

# Reference Types

By contrast, a variable of reference type (also called a reference) contains the location where the data referred to that variable is stored. Such a variable is said to refer to an object in the program. For example, the statement

```
Account myAccount = new Account();
```

creates an object of our class Account (presented in Chapter 4), places it in memory and stores the object's variable in myAccount of type Account, as shown in Fig. 7.19. The Account object is shown with its instance variable.

# Reference-Type Instance Variables Are Initialized to null by Default

Reference-type instance variables (as as myAccount in Fig. 7.19) are initialized by default to null. The string is a reference type. For this reason, string instance variable is shown in Fig. 7.19 with an empty box representing the null-valued variable.
