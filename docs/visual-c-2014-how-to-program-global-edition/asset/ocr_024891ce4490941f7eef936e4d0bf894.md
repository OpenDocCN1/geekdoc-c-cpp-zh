When the user interacts with a GUI component, the interaction—known as an event—drives the program to perform a task. Before GUIs, the program tells the user what to do. With GUIs, the user tells the program what to do. Common events (user interactions) that might cause an app to perform a task

+   * clicking a Button,
* typing in a TextBox,
* selecting an item from a menu,
* closing a window and
* moving the mouse.

All GUI controls have events associated with them. Objects of other types can also have associated events as well. Method that performs a task in response to an event is called an event handler, and the overall process of responding to events is known as event handling.
