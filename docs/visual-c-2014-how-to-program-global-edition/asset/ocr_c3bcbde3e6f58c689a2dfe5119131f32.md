# Simple App: Displaying a Line of Text

> ### Good Programming Practice 3.4
Set a convention for the indent you prefer, then uniformly apply that convention. The Tab may be used to create indents, but tabs vary among many text editors. Microsoft recommends four-space indents, which is the default in Visual Studio. Due to the limited width of code lines in print books, we use three-space indents—this reduces the number of code lines that wrap to a new line, making the code bit easier to read. We show how to set the tab in the Before You Section that follows the Preface.

> ### Error-Prevention Tip 3.3
Whenever you type an opening left brace, {, in your app, the IDE immediately inserts the right brace, then repositions the cursor between the braces so you can begin typing the body. This practice prevents errors due to missing braces.

> ### Common Programming Error 3.4
It's a syntax error if braces do not occur in matching pairs.

# 3.2.5 Main Method

Line 7

```
// Main method begins execution of C# app
static void Main()
```

is a comment indicating the purpose of lines 8–11. Line 8
is where the app begins execution—this is known as the entry point. The parentheses after the identifier Main indicate that it is a building block called a method. Class declarations normally contain one or more methods. Methods usually use the same capitalization conventions used for classes. For each class, one of the methods in a class must execute. A method is able to perform a task and return a value when it completes its task. Keyword void (line 8) indicates that Main will not return a value after it completes its task. Later, we will see that most methods return values. You will learn more about methods in Chapters 4 and 7. We discuss the contents of Main's parentheses in Chapter 8. For now, simply mimic Main's first line in your code.

**Body of the Method Declaration**nTheleft brace in line 9 begins the body of the method declaration. A corresponding right ends the body (line 11). Line 10 in the method body is indented by the braces.

> ### Good Programming Practice 3.5
Each method declaration's body statements one level of indentation between the left and right braces that define the body.
