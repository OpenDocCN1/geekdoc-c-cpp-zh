# string Interpolation

Line 11

```
Console.WriteLine("Welcome to C# Programming, {person}");
```

uses interpolation to insert the variable's value ("Paul") into the string that Console.WriteLine is to display. Then, you can use interpolation expressions begin with a $ (dollar sign), enclosed in braces, {} (e.g., {person}), anywhere between the quotes ("). When C# encounters an interpolation string, it replaces each braced interpolation expression with the corresponding value—in this case, {person} is replaced with Paul, so line 11 displays

Welcome to C# Programming, Paul!
