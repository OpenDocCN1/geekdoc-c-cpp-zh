5.6 该程序如下：

```csharp
// Ex. 5.6: Calculate.cs
// 计算从 1 到 10 的整数的和
using System;



    class Calculate
    {
        static void Main()
        {
            int sum = 0; // 初始化 sum 为 0 用于累加
            int x = 1; // 初始化 x 为 1 用于计数

            while (x <= 10) // 当 x 小于或等于 10 时
            {
                sum += x; // 将 x 加到 sum 中
                x++; // x 递增
            } // 结束 while
            Console.WriteLine("The sum is: {sum}");
        }
    }
```

总和为：55
