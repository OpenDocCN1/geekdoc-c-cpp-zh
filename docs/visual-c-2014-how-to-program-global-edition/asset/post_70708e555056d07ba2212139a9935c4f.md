This call to Merge requires, at worst, $n-1$ comparisons to fill the original array, which is $O(n)$. (Recall that each element in the array can be chosen by comparing one element from each of the subarrays.) The two calls to method SortArray result in four recursive calls to SortArray, with each subarray roughly a quarter size of the original array, along with two calls to method Merge. These two calls require $n/2-1$ comparisons for a total number of comparisons $(n/2-1)+(n/2-1)=n-2$, which continues, until SortArray generating two additional calls to method SortArray and a Merge, until the algorithm splits the array into one-element subarrays. At each level, $O(n)$ comparisons are required to merge the subarrays. Each level splits the size of the arrays in half, so doubling the size of the array requires only one more level. Quadrupling the size of the array requires only two levels. This pattern is logarithmic with $\log n$ levels. This results in a total efficiency of $O(n \log n)$.

## Performance Tip 18.2

As you have noticed, the key to achieving the high efficiency of the merge sort is cleverly using additional memory. This is another example of the space/time trade-off if you have more space you can get your algorithm to run in less time and if you have less your algorithm may require more time. In industry, you might create apps for memory-constrained devices, which might prevent you from using the merge sort algorithm.

## Summary

### Section 18.1 Introduction

- Searching values determining if a search is present in the data and, if, finding its location.
- Sorting involves data in order.

### Section 18.2.1 Linear Search

- The linear search searches an array's elements sequentially until it finds one that matches the search key. If the search is not in the array, the search fails.

### Section 18.2.2 Binary Search

- Binary search requires the data to be sorted first. It is much faster than linear search for large datasets.

### Section 18.3.1 Selection Sort

- Selection sort finds the smallest element and swaps it into the first position. 

### Section 18.3.2 Insertion Sort

- Insertion sort builds the sorted array one element at a time by inserting each new element into its correct position.

### Section 18.3.3 Merge Sort

- Merge sort is a divide and conquer algorithm that is highly efficient for sorting large datasets.
