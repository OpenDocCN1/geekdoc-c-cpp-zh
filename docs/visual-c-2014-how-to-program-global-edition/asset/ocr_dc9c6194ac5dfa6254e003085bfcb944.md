# 18.1 Introduction

Searching data involves determining whether a value (referred to as the search key) is present in the data and, if so, finding the value's location. This chapter presents two popular algorithms—the simple linear search and the faster, but more complex, binary search.Sorting places in data, based on one or more sort keys. A list of names is sorted alphabetically, bank accounts could be sorted by account number, employee payroll records could be sorted by security number and so on. This chapter introduces two simple sorting algorithms, the selection sort and the insertion sort, and the more, but complex, merge sort. Figure 18.1 summarizes the searching and sorting capabilities in this book. We include this for the benefit of computer-science students. Most programmers will use the .Net Framework's built-in searching and sorting capabilities, as class Array's BinarySearch Sort methods and similar capabilities in .NET collections (Chapter 21).
