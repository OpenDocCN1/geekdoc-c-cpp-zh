# 13.3.2 Catching Exceptions

Exception-handling code appears in a catch block. In general, when an exception occurs in a try block, a corresponding catch block catch the exception and handles it. The try block in this is followed by two catch blocks—one handles a FormatException (lines 32–37) and one handles a DivideByZeroException (lines 38–43). A catch block specifies an exception representing the exception that the catch block can handle. The catch block can use the identifier (which you choose) to interact with a caught exception object. There's no need to use the exception object in the catch block, the exception's identifier can be omitted. The type of the catch's parameter is the type of the exception that the catch block handles.
