# 8.6.3 Shuffling and Dealing Cards
Figure 8.12 demonstrates the shuffling and dealing capabilities of class DeckOfCards

use type inference to determine the variable's type. Recall that the DeckOfCards construc-

lines 14-22 deals all 52 Cards in the deck and displays them in four columns of 13 Cards
Each line and displays a Card object by invoking myDeckCards's DealCard
Method. When a card object is placed in a string-interpolation expression, the Card’s To-
String method invoked invoked. Because the field width is negative, the result is dis-
played left-aligned in a field width of 19.

```
// Fig.8.12: DeckOfCardsTest.cs
// Card shuffling and dealing app.
using System;
class DeckOfCardsTest
{
    // execute app
    static void Main()
    {
        var myDeckCards = new DeckOfCards();
        myDeckCards.Shuffle(); // place Cards in random order

        // display all 52 Cards in the order in which they are dealt
        for (var i = 0; i < 52; i++)
        {
            Console.Write($"{myDeckCards.DealCard(i), -19}");

            if ((i + 1) % 4 == 0)
            {
                Console.WriteLine();
            }
        }
    }
}
```
