Using this as line 19 is called a constructor initializer enables a class to reuse initialization code by constructor, rather than defining simple code in another constructor. If we need to change how objects of class Time2 are initialized, only the constructor at lines 12–15 would need to be modified. # Software Engineering Observation 10.6

When executing a method of class, if that method has a reference to another object of the same class (typically received via a parameter), the method can access all of that object’s data and methods (including those that are private).

# SetTime Method and the Hour, Minute and Second Properties

Method SetTime (lines 23–28) invokes the setters of properties Hour (lines 31–47), Minute (lines 50–66) and Second (lines 69–85), which ensure that the hour is in the range 0 to 23 and that the values for the minute and second are in the range 0 to 59. If a value is out of range, each setter throws an ArgumentOutOfRangeException (lines 41–42, 60–61 and 79–80). In this example, we use the class’s overloaded constructor that receives three arguments:

+   - the name of the item that was out of range
- the value that was supplied for that item and
- a string error.

It’s common to include in an exception’s error message a variable’s or property’s identifier. This information can help a client-programmer understand the context in which the exception occurred. For C# 6, you would hard code these identifiers into your error messages.
