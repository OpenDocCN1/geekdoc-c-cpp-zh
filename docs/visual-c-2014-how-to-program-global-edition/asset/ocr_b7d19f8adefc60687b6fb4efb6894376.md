{
    // extension method that displays all elements separated by spaces
    public static void Display<T>(this IEnumerable<T> data)

    Console.WriteLine(string.Join(" ", data));
}
}

# Extension Method Display

Throughout this example, we display the results of various operations by calling our extension method named Display, which is defined in the static class Extensions (lines 57–64). The method uses string Join to concatenate the IEnumerable<T> argument's elements separated by spaces.

At the beginning and end of Main when we call Display directly on the values collection the same values are displayed in the same order. Throughout outputs confirm that the functional-programming operations performed throughout Main (which we discuss in Sections 21.11.1–21.11.4) do not modify the contents of the original values collection.
