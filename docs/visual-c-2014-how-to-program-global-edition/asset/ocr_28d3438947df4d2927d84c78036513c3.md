Tree method Insert (lines 64–74) first determines whether the tree is empty. If so, line 66 allocates a new TreeNode with the integer being inserted in the tree and assigns the new node to root. A node can be inserted only as a leaf node in binary search tree.

The TreeNode Insert compares the value to insert with the data value in the specified node. If so, line 34 allocates a new TreeNode, initializes it with the integer inserted and assigns the new node to reference LeftNode. The purpose of the helper methods in class Tree is to allow the programmer to start a traversal without needing to obtain a reference to the root first, then call the recursive method with reference.
