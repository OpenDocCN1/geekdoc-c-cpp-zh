| ++ | postfix increment | |
| -- | postfix decrement | |
| nameof | string representation of an identifier | |
| new | object creation | |
| typeof | get System.Type object for a type | |
| sizeof | get size in bytes of a type | |
| checked | checked evaluation | |
| unchecked | unchecked evaluation | |
| + | unary plus | left-to-right |
| - | unary minus | |
| ! | logical negation | |
| ~ | bitwise complement | |
| ++ | prefix increment | |
| -- | postfix decrement | |
