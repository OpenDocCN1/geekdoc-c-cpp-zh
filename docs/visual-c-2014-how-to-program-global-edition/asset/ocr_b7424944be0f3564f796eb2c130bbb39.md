Handling the Click Events for the About and Exit Menu Items
The About menu item in the File menu displays a MessageBox (lines 20–25). The Exit menu item closes the app through static method Exit of class Application (line 30). Application's static methods control program execution. Method Exit causes our app to terminate.

Color Submenu Events
We make items in the Color submenu (Black, Blue, Red and Green) exclusively-the user can select only one at a time (when we explain how we did). To indicate that a menu item is selected, we will set each Color menu item Checked property to true. This causes a check to appear to the left of item.
Each menu item has its own Click handler. The method handler for Black is blackToolStripMenuItemClick (lines 44–53). Similarly, the event handlers for Blue, Red and Green are blueToolStripMenuItemClick (lines 55–64), redToolStripMenuItemClick (lines 67–76) and greenToolStripMenuItemClick. Each menu item must be mutually exclusive, so each event handler calls methodColor (lines 34–41) before setting its corresponding Checked property to true. MethodColor sets the Checked property of each color ToolStripMenuItem to false, effectively preventing more than one menu item from being selected at a time. In the designer, we set the menu item Checked property to true, because at the start of the program, the text on the Form is block.

Font Submenu Events

The Font menu contains three items for fonts (Courier, Times New Roman and Comic) and two menu items for styles (Bold and Italic). We added a separator bar between the font and font-style menu items to indicate that these are separate options. A Font object can specify only one font at a time but can specify styles at once (e.g., a can be both bold and italic). We set the font menu items to display checks. With the Color menu, we must enforce mutual exclusion of these items in event handlers.
Event handlers for menu items Times New Roman, Courier and Comic Sans are timeToolStripMenuItemClick (lines 100–110), courierToolStripMenuItemClick (lines 113–123) and colorToolStripMenuItemClick (lines 126–136), respectively. These event handlers are similar to those of the Color menu. Each sets the Checked property for all menu items by calling method ClearFont (lines 91–97), then sets the Checked property of the menu item that raised the event to true. This enforces the mutual exclusion of the menu items. In the designer, we initially set the Times Roman menu item's Checked property to true, because this is the original font for the text
