# Error-Prevention Tip 5.2

Initializing local variables when they're declared helps you avoid compilation errors that might arise from attempts to use uninitialized data. While C# does not require local-variable initializations to be incorporated into declarations, it requires that local variables be initialized before their values are used in an expression.

# 5.9.3 Integer Division and Truncation

The averaging calculation performed in line 23 produces an integer result. The app's output indicates that the sum of the grade values in the sample execution is 848, which, when divided by 10, yields 84.8. However, the result of the calculation total / 10 is the integer 84, because total and 10 are both integers. Dividing two integers in integer division—any fractional part of the calculation is lost (i.e., truncated, not rounded).
