# 19.8 Wrap-Up

In this chapter, you learned that simple types are value-type but can still be used anywhere due to boxing and unboxing conversions. You learned that linked lists are collections of data items that are linked together. A program can perform insertions and deletions at the ends. We demonstrated that the stack and queue structures are constrained versions of lists. For stacks, we saw that insertions and deletions are made only at the top—stacks are known as last-in, first-out (LIFO) structures. For queues, representing lines, we saw that insertions are made at the tail—queues are known as first-in, first-out (FIFO) structures. We presented the binary tree structure that facilitated high-speed searching and sorting of data. In the next chapter, we introduce generics, which allow you to declare family of classes that implement the same functionality.

## 19.1 Introduction
- Dynamic data can grow and shrink at execution time.

## 19.2 Simple-type structs, Boxing and Unboxing
- All simple-type names are aliases for representing structs in namespace.
- Each simple type inherits from ValueType in System.
- A boxing conversion creates an object that contains a copy of simple-type value.
- An unboxing conversion retrieves simple-type value from object.

## 19.3 Self-Referential Classes
- A self-referential class contains a data member that refers to an object of the same class.
- Self-referential objects can be linked to form data structures, such as lists, queues, and trees.
- Creating and maintaining data structures requires dynamic memory allocation—program’s ability to obtain more memory at execution time (to hold new nodes)—calls the appropriate constructor to initialize the object. If no memory is available, new throws an OutMemoryException.

## 19.4 Linked Lists
- A linked list is a linear collection (i.e., a sequence) of self-referential class nodes, connected by reference links.
- A node can contain properties of any type, including references to other classes.
- A list is accessed via a reference to the first node of the list. Each subsequent node is accessed via the link-reference member stored in the previous node.
- By convention, the link reference in the last node of a list is set to null to mark the end of the list.
- A circular, singly linked list begins with a reference to the first node, and each node contains a reference to the next node. The "last node" does not contain a null reference; rather, the reference in the last node points back to the first, thus closing the "circle."
- A doubly linked list allows traversal forward and backward. Such a list is often implemented with two start references—one refers to the first element of the list to allow front-to-back traversal of the list and one refers to the last element to allow back-to-front traversal. Each node has a forward reference to the next node in the list and a backward reference to the previous node.
- In a circular, doubly linked list, the reference of the last node refers to the first node, and the backward reference of the first node refers to the last node, thus closing the "circle".

## 19.5 Stacks
Stacks are important in compilers and operating systems.
- A stack is a constrained version of a list—new nodes can be added and removed from a stack only at the top. A stack is referred to as a first-in, first-out (LIFO) data structure.
- The primary stack operations are push and pop. Push adds a new node to the top of the stack. Pop removes a node from the top of the stack and returns the data object from the popped node.

## 19.6 Queues
Queues represent waiting lines. Insertions occur at the back (also referred to as the tail) of a queue, and deletions occur from the front (also referred as the head) of a queue.
- A queue is similar to a checkout line in a supermarket: the first person in line is served; other customers enter the end and wait to be served.
- Queue nodes are removed only from the head of the queue and are inserted only at the tail of the queue. For this reason, a queue is referred to as a first-in, first-out (FIFO) data structure.
- The insert and remove operations for a queue are known as enqueue and dequeue.

## 19.7 Trees
- Binary trees facilitate high-speed searching and sorting of data.
- Tree nodes contain two or more links.
- A binary tree is a tree whose nodes contain two links (each of which can be null). The root node is the first node in a tree.
