where myTreeView is the TreeView to which we are adding nodes, and rootLabel is the text to display in myTreeView. To add children to a root node, add new TreeNodes to its Nodes collection. We select the appropriate root node from the TreeView by writing

```
myTreeView.Nodes[index]
```

where Index is the root node's index in myTreeView's collection. We add nodes to children through the same process by which we added nodes to myTreeView. To add a child to the root node at index, write

```
myTreeView.Nodes[index].Nodes.Add(new TreeNode(ChildLabel));
```
