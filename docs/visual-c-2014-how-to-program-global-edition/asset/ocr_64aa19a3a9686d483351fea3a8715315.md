# 5.11 Formulating Algorithms: Nested Control Statements

For the next example, we once again formulate an algorithm using pseudocode and top-down, refinement, and write a corresponding C# app. We see that control statements can be stacked on top of one another (in sequence). In this case, we examine the only other structured control statements that can be connected, namely, by nesting one statement within another.

# 5.11.1 Problem Statement

Consider the following problem statement:

> A college offers a course that prepares students for the state licensing exam for real-estate brokers. Last year, 10 of the students who completed this course took the exam. You've been asked to write an app to summarize the results. How well students did on the exam. You've been given a list of these 10 students. Next to each name is written 1 if the student passed the exam or 2 if the student failed.

Your app should analyze the results of the exam as follows:

+   1. Input each test result (i.e., a 1 or 2). Display the message "Enter result" on the screen each time the app requests a test result.
2. Count the number of test results of each type.
3. Display a summary of the test results, indicating the number of students who passed and the number who failed.
4. If more than eight students passed the exam, display the message "Bonus to instructor!

# Problem Statement Observations

After reading the statement, we make the following observations:

+   1. The app must process test results for 10 students. A counter-controlled loop can be used because the number of test results is known in advance.
2. Each test result has a numeric value—either 1 or 2. Each time the app reads a test result, the app must determine whether the number is a 1 or 2. We test for a 1 in our algorithm. If the number is not 1, we assume it's a 2. (Exercise 5.24 considers the consequences of this assumption).
3. Three counters are used to keep track of the exam results—one to count the number of students who passed the exam and one to count the number of students who failed the exam.
4. After the app has processed all the results, it must determine whether more than eight students passed the exam.
