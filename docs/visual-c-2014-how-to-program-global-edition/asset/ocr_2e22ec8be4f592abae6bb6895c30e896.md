```
// output double array
private static void DisplayArray(double[] inputArray)
{
    foreach (var element in inputArray)
    {
        Console.Write($"{element}");
    }
    Console.WriteLine();
}

//// output char array
private static void DisplayArray(char[] inputArray)
{
    foreach (var element in inputArray)
    {
        Console.Write($"{element}");
    }
    Console.WriteLine();
}
```

When the compiler calls a method, it attempts to locate a method declaration that has the same name and parameters that match the argument types in the method call.
