# 16.13 Insert, Remove and Replace Methods of Class StringBuilder

StringBuilder provides overloaded Insert methods to allow various types of data to be inserted at any position in a StringBuilder. The class provides versions for each type and for strings and objects. Each method takes its second argument, converts it to a string and inserts the into the StringBuilder in front of the character in the position specified by the first argument. The index specified by the first argument must be greater than equal to zero and less than the StringBuilder’s length; otherwise, the program throws an ArgumentOutOfRangeException.

StringBuilder also provides method Remove for deleting any portion of a StringBuilder. Remove takes two arguments—the index at which to begin deleting and the number of characters to delete. The sum of the two must be less than the StringBuilder’s length; otherwise, the program throws an ArgumentOutOfRangeException. The Insert and Remove methods are demonstrated in Fig. 16.13.

```csharp
// Fig. 16.13: StringBuilderInsertRemove.cs
// Demonstrating methods Insert and Remove of the
// StringBuilder class.
using System;
using System.Text;

class StringBuilderInsertRemove {
    static void Main() {
        var objectValue = "good bye";
        char[] characterArray = {'a', 'b', 'c', 'd', 'e', 'f'};
        var booleanValue = true;
        var characterValue = 'K';
        var longValue = 10000000L; // L suffix indicates a long literal
        var floatValue = 2.5F; // F suffix indicates a float literal
        var doubleValue = 33.333;
        var buffer = new StringBuilder();

        // insert values into buffer
        buffer.Insert(0, objectValue);
        buffer.Insert(0, " ");
        // Note: stringValue and integerValue were OCR errors in original, 
        // based on context they likely refer to parts of the logic.
        buffer.Insert(0, " "); 
        buffer.Insert(0, characterArray);
        buffer.Insert(0, " ");
        buffer.Insert(0, booleanValue);
        buffer.Insert(0, " ");
        buffer.Insert(0, characterValue);
        buffer.Insert(0, " ");
        buffer.Insert(0, " ");
        buffer.Insert(0, longValue);
        buffer.Insert(0, " ");
        buffer.Insert(0, floatValue);
        buffer.Insert(0, " ");
        buffer.Insert(0, doubleValue);
        buffer.Insert(0, " ");

        Console.WriteLine($"buffer after Inserts: \n{buffer}\n");

        buffer.Remove(10, 1); // delete 2 in 2.5
        buffer.Remove(4, 4); // delete .333 in 33.333

        Console.WriteLine($"buffer after Removes: \n{buffer}");
    }
}
```

Another method included with StringBuilder Replace, which searches for a specified string or character and substitutes another string or all occurrences. Figure 16.14 demonstrates this method.

```csharp
// Fig. 16.14: StringBuilderReplace.cs
// Demonstrating method Replace.
using System;
using System.Text;
class StringBuilderReplace{
    static void Main() {
        var builder1 = new StringBuilder("Happy Birthday Jane");
        var builder2 = new StringBuilder("goodbye greg");
        Console.WriteLine($"replacements:\n{builder1}");
        builder1.Replace("Jane", "Greg");
        builder2.Replace('g', 'G', 0, 5);
        Console.WriteLine($"after replacements:\n{builder2}");
    }
}
```

# 16.14 Char Methods

Section 10.13 introduced structs representing value types. The simple types are actually aliased for struct types. For instance, an int is defined by struct System.Int32, a long by struct System.Int64 and all struct derive from class ValueType.

In System.Char—which is the struct for characters and represented by C# keyword—most are static, at least one character argument and perform a test or a manipulation on the character. We present several of these in the next example. Figure 16.15 demonstrates static methods that test characters to determine whether they're of a specific character type and static methods that perform conversions on characters.

```csharp
// Fig. 16.15: StaticCharMethods.cs
// Demonstrates static character-testing and case-conversion methods
// from char struct
using System;

class StaticCharMethods
{
    static void main(string[] args)
    {
        Console.Write("Enter a character: ");
        var character = char.Parse(Console.ReadLine());

        Console.WriteLine($"is digit: {char.IsDigit(character)}");
        Console.WriteLine($"is letter: {char.IsLetter(character)}");
        Console.WriteLine($"is letter or digit: {char.IsLetterOrDigit(character)}");
        Console.WriteLine($"is lower case: {char.IsLower(character)}");
        Console.WriteLine($"is upper case: {char.IsUpper(character)}");
        Console.WriteLine($"to lower case: {char.ToLower(character)}");
        Console.WriteLine($"is punctuation: {char.IsPunctuation(character)}");
        Console.WriteLine($"is symbol: {char.IsSymbol(character)}");
    }
}
```

is digit: False
is letter: True
is letter or digit: True
is lower case: False
is upper case: A
to lower case: a
