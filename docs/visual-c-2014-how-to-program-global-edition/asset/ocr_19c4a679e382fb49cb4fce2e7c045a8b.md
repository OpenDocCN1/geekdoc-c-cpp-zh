You call any static method by specifying the name of the class in which the method is declared, by the member-operator (.) and ClassName.MethodName(arguments)

# 7.3.1 Math Class Methods

We use various methods of the Math class to present the concept of static methods. Class Math (from the System namespace) provides a collection of methods that enable you to perform common mathematical calculations. For example, you can calculate the square root of 900.0 with the static method

```
double value = Math.Sqrt(900.0);
```

The expression Math.Sqrt(900.0) evaluates to 30.0. Method Sqrt takes an argument of type double and returns a result of type double. The following statement displays in the console window using the preceding method:

```
Console.WriteLine(Math.Sqrt(900.0));
```

Here, that Sqrt returns the argument to WriteLine. We did not create a Math object before calling Sqrt, nor did we create a Console object before calling Write. Also, all of Math's methods are static—therefore, each is called by the name of the method with the class Math and the member-operator (.). Method arguments may be constants, variables or expressions. If c = 13.0, d = 3.0 and f = 4.0, the statement

```
Console.WriteLine(Math.Sqrt(c + d * f));
```

calculates and displays the square root of 13.0 + 3.0 * 4.0 = 25.0—namely, 5.0. Figure 7.2 summarizes several Math class methods. In the figure, x and y of type double.
