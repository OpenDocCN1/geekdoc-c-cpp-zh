# Generating a Range of ints with Enumerable Method Range

Using functional techniques, lines 13–15 create an array of 10,000,000 random ints. Class Enumerable provides static method Range to produce an IEnumerable<int> containing integer values. The expression

```
Enumerable.Range(1, 10000000)
```

produces an IEnumerable<int> containing the values 1 through 10,000,000—the first argument specifies the starting value in the range and the second specifies the number of values to produce. Next, line 14 uses LINQ extension method Select to map every element to a random index in the range 1–999. The lambda

```
x => random.Next(1, 1000)
```

ignores its parameter (x) and returns a random value that becomes part of the IEnumerable returned by Select. Finally, line 15 calls method ToArray returns an array of ints containing the elements produced by the Select operation. Note that class Enumerable also provides extension method ToList to obtain a List<T> rather than an array.

# Min, Max and Average with PLINK

Lines 31–44 perform the same tasks as lines 20–28, but use PLINK Min, Max and Average extension-method calls demonstrate the performance improvement over LINQ. To initiate parallel processing, lines 34–36 use IEnumerable<T> extension AsParallel which returns a ParallelQuery<T> (in this case, T is int). An object that implements ParallelQuery<T> can be used with PLINK's parallelized versions of the LINQ extension methods. Class ParallelEnumerable defines the ParallelQuery<T> (PLINK) parallelized versions as well as several LINQ-specific extension methods. # Performance Difference

Lines 44–46 calculate and show the percentage improvement in processing time of PLINK over LINQ. As you can see from the sample outputs, class of PLINK (via AsParallel) decreased the processing time substantially–55% and 41% less in the two samples. We run the process many times (up to three cores) and processing-time savings were generally within the 41–55% range–though we had a 61% savings on one sample execution. The overall savings will be affected by what else is running on your processor’s number of cores
