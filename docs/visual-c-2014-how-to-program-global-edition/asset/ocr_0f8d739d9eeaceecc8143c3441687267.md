The compiler will not create a default constructor for a class that explicitly declares at least one constructor. In this case, if you want to invoke the constructor with no arguments, you must declare a parameterless constructor—that is, one that is declared with no parameters or one in which all the parameters have default values (e.g., line 12 of 10.5). Like a default constructor, a parameterless constructor is invoked with empty parentheses. If you call Time2 three-argument constructor with no arguments, the compiler explicitly passes 0 to each parameter. If we omit from Time2 a constructor that can be called with no arguments, clients of this class would not be able to create a Time2 object with the expression Time2(). If a class provides both a parameterless constructor and a constructor with default arguments for all of its parameters, the compiler will use the parameterless constructor when you pass no arguments to the constructor.

# 10.7 Composition

A class can have objects of values types or references to objects of other classes as members. This is called composition and sometimes referred to as a has-relationship. For example, an object of AlarmClock needs to know the current time and when it's supposed to sound its alarm, so it's reasonable to include two references to Time objects in AlarmClock.
