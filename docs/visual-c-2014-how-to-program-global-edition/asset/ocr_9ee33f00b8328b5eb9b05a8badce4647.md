# Chapter 7 Methods: A Deeper Look

Figure 7.15 demonstrates an optional parameter. The program calculates the result of raising a base to an exponent. Method Power (lines 15–25) specifies that its second parameter is optional. In Main, lines 10–14 call method Power. Line 10 calls the method without the optional argument. In this case, the compiler provides the second argument, 2, using the default value of the optional argument, which is not visible to you in the call.

```
// Fig. 7.15: CalculatePowercs
// Optional parameter demonstration with method Power.
using System;

class CalculatePower
{
    // call Power with and without optional arguments
    static void main()
    {
        Console.WriteLine("$Power(10) = {Power(10)}");
        Console.WriteLine("$Power(2, 10) = {Power(2, 10)}");
    }

// use iteration to calculate power
static int Power(int baseValue, int exponentValue = 2)
{
    int result = 1;
    for (int i = 1; i <= exponentValue; ++i)
    {
        result *= baseValue;
    }
    return result;
}
```

| Power(2, 10) = 1024 |
