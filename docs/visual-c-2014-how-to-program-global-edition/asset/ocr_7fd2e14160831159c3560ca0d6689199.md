Write class `InfixToPostfixConverter` to convert an infix arithmetic expression (assume a valid expression), with single-digit integers, such as

```
(6 + 2) * 5 - 8 / 4
```

to a postfix expression. The postfix version of the preceding expression is

```
6 2 5 * 8 4 /
```

The program should read the expression into `StringBuilder`, then use class `StackInheritance` (implemented in Fig. 19.13) to create the postfix expression in `StringBuilder` postfix. The algorithm for creating a postfix expression is as follows:

+   a) Push a left parenthesis '(' on the stack.
b) Append a right parenthesis ')' to the end of the infix.
c) While the stack is not empty, read infix from left to right and do the following:
   If the current character is a digit, append it to postfix.
   If the current character is a left parenthesis, push it onto the stack.
   If the current character is an operator:
   Pop operators (if there are any) at the top of the stack that have equal or higher precedence than the current operator, and append the operators to postfix.
   Push the current character into the stack.
   If the current character is a right parenthesis:
   Pop operators from the top of the stack and append them to postfix until a left parenthesis is at the top of the stack.
   Pop (and discard) the left parenthesis from the stack.

The following arithmetic operations are allowed in an expression:

+   * addition
* subtraction
* multiplication
/ division
* exponentiation
* modulus

Some of the methods you want to provide in your program follow:

+   a) Method `ConvertToPostfix`, which converts the infix expression to postfix notation.
b) Method `IsOperator`, which determines whether `c` is an operator.
c) Method `Precedence`, which determines whether the precedence of `operator1` (from the infix expression) is less than, or equal to the precedence of `operator2` (from the stack).
