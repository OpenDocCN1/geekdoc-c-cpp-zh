# 15.5 LinkLabel Control

The LinkLabel control displays links to other resources, such as files or web pages (Fig. 15.12). A LinkLabel appears as underlined text (colored blue by). When the mouse moves over the label, the pointer changes to a hand; this is similar to the behavior of a hyperlink on a web page. The link can change color to indicate whether it is visited, previously visited or active. When clicked, the LinkLabel generates a LinkClicked event (see Fig. 15.13). Class LinkLabel1 is derived from ClassLabel and inherits all of classLabel's functionality.
