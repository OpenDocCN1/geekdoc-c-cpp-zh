# 22.3 A Books Database

We consider a simple Books database that stores information about some Deitel books. First, we overview the database's tables. A database's tables, their fields and the relationships among them are collectively known as a database schema. The ADO.NET Framework uses a database's schema to define classes that allow you to interact with the database. Sections 22.5–22.8 show how to manipulate the Books database. The database file—Books.mdb—is provided with this chapter's examples. SQL Server database files have the .master data file” file extension.
