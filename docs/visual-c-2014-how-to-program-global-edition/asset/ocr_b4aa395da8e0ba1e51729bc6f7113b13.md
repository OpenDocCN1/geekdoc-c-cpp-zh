Figure 14.20 uses a TextBox, a Button and a Label. The user enters text into a password box and clicks the Button, causing the text input to be displayed in the Label. Normally, we would not display this text—the purpose of password TextBox is to hide the text being entered by the user. When the user clicks the Show Me Button, app retrieves the text that the user typed in the password TextBox and displays it in a Label.
