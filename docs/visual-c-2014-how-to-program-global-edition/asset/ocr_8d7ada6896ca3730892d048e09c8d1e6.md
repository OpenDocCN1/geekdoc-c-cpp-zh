Constructors
The constructor (lines 13–19) receive three ints. Line 15 invokes Month’s set accessor (lines 28–37) to validate the Month—if Year is out-of-range accessor throws an exception. Line 16 uses Year to set the year. Since Year is an auto-implemented, it provides no validation—we’re assuming in this example that Year’s value is correct. Line 17 uses Day’s set accessor (lines 47–67) to validate and assign the value for Day based on the current Month and Year (by using properties Month and Year to obtain the values of Month and Year).

The order of initialization is important, because Day’s set accessor performs its validation assuming that Month and Year are correct. Line 53 determines whether the Day is out of range, based on the number of days in the Month and, if so, throw an exception. Lines 59–60 determine whether Month is February, and that 29 and the Year is not a leap year (in which case 29 is out of range), and if so, throw an exception. If no exceptions are thrown, the value for Day is correct and assigned to the instance variable at line 66. Line 18 in the constructor object formats this reference as a string. Since this is a reference to the object’s ToString method (line 71) is called implicitly to obtain the Date’s string representation.

private Set accessors
Class uses access modifiers to ensure that clients of the class may use the appropriate methods and properties to access private data. In the properties Year, Month and Day declare private setters (lines 9, 28 and 47, respectively)—these accessors can be used only within the class. We declare these private for the same reasons we declare instance variables private—to simplify code maintenance and control access to the class’s data. Although the constructor, method and properties in class still have all the advantages of using the setters to perform validation, clients of the class may use the constructor to initialize the data in a Date object. The getters of Year, Month and Day are implicitly public—when there is no modifier to get or set accessor, the property’s access is modified.

# 10.7.2 Class Employee

Class Employee (line 10.8) has auto-implemented, getter-only properties FirstName-LastName,BirthDate and HireDate. BirthDate and HireDate (lines 7–8) refer to Date objects, demonstrating that a class has references to objects of other classes as members. By, of course, is also first of FirstName and LastName, which refer to String objects. The Employee constructor (lines 11–18) uses its four parameters to initialize the class’s properties. When Employee’s ToString method is called, it returns a string representing the representations of the two Date objects. Each of these strings is obtained with an implicit call to the Date class’s ToString method.
