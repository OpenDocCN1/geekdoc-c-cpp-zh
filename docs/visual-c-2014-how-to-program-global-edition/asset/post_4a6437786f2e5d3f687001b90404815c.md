# 10.4 Referring to the Current Object’s Members with the Reference

Every object can access a reference to itself with keyword this (also called this reference). When a non-static method (or property) is called for a particular object, the method's body implicitly uses this keyword to refer to the object's instance variables and non-static class members. # Software Engineering Observation 10.4

Using properties throughout a class to access the class's instance variables normally eliminates shadowing because property names use Camel Case (capital first letter) and parameters names use Camel Case (lowercase first).

BuildString (lines 32–34) returns a string created by a statement that uses this reference explicitly and implicitly. Line 33 uses the this reference explicitly to call the method UniversalToString(). Line 34 uses this reference implicitly to call the same method. Programmers typically do not use the this reference explicitly to reference other methods in the current object. Also, to access each instance variable is not necessary here, because the method does not have any local variables that have the instance variables of the class.

# 10.5 Time Class Case Study: Overloaded Constructors

Next, we demonstrate a class with several overloaded constructors that enable objects of that class to be initialized in different ways. To overload constructors, simply provide multiple constructor declarations with different signatures.

# 10.5.1 Class Time2 with Overloaded Constructors

By default, the properties Hour, Minute and Second of class Time1 (Fig. 10.1) are initialized to their default values of 0–midnight in unique instance. Time1 doesn't enable the class's clients to initialize the time with specific nonzero values, because it does not provide a constructor. Class Time2 (Fig. 10.5) contains overloaded constructors. In this app, one constructor invokes the other, which in turn calls SetTime to set the private variables hour, minute; and second, which perform validation. The constructor invokes the appropriate Time2 constructor by matching the number and types of arguments specified in each constructor declaration.

```csharp
// 10.5: Time2.cs
// Time2 class declaration with overloaded constructors.
using System;
public class Time2 {
    private int hour; // 0-23
    private int minute; // 0-59
    private int second; // 0-59
```
