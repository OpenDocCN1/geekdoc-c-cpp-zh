**14.24** | Using GroupBoxes and Panels to arrange Buttons. (Part 2 of 2.)

The mainGroupBox has two—hiButton (which displays the Hi) and ByeButton (which displays the Bye). The Panel (named mainPanel) also has two Buttons, leftButton(which displays the Far Left) and rightButton(which displays the Far). The mainPanel has AutoScroll property set to true, allowing scrollbars to appear when the contents of the Panel require more than the Panel's visible area. The Label (named messageLabel) is initially blank. To controls mainGroupBox or Panel, Visual Studio calls Add of each container's Controls. This property is placed in the partial class located in the file GroupBoxPanelExampleForm.Designer.cs.
