# 3.5 String Interpolation

Many programs format data into strings. C# 6 introduces a mechanism called string interpolation that enables you to insert values into string literals to create formatted strings. Figure 3.13 demonstrates this capability.

```
// Fig. 3.13: Welcome4.cs
// Inserting content into a string with string interpolation
using System;

class Welcome4
{
    // Main method begins execution of C# app
    static void Main()
    {
        string person = "Paul"; // variable that stores the string "Paul"
        Console.WriteLine("Welcome to C# Programming, {person}!");
    } // end Main
} // end class Welcome4
```
