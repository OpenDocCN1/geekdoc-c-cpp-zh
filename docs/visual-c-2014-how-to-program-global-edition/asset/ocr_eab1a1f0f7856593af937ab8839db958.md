# Summary 323

# Section 7.2.1 Modularizing Programs

+   - Methods allow you to modularize an app by separating the tasks into self-contained units.
- Dividing an app into meaningful methods makes it easier to debug and maintain.

# Section 7.3 static Methods, static Variables and Class Math

+   - You can call any method by specifying the name of the class in which it's declared, followed-by the member-access operator (.). and the method name, as in
`ClassName.MethodName(arguments)`

# Section 7.3.1 Math Class Methods

+   - Method arguments may be constants, variables or expressions.

# Section 7.3.2 Class Constants PI and E

+   - A constant is declared with the keyword const—its value cannot be changed after the statement declared.
- Math.PI (3.1415926535897931) is the ratio of a circle's circumference to its diameter. Math.E (2.718281828490451) is the base value for natural logarithms.
- When each object has its own copy of an attribute, each (instance) of the class has a separate instance of the variable. Objects of a class containing static variables are created, all of objects that share one copy of the class's static variables.
- The static variables and instance variables represent the fields of a class.

# Section 7.3.4 Additional Comments About Main

+   - If you declare more than one method among the classes of your project, you'll need to indicate which one would like to be the entry point. You can do this by clicking the menu Project > [ProjectName] Properties... and selecting the class containing the Main method should be the entry point from the Startup object list box.

# Section 7.4.2 Method Maximum

+   - Multiple parameters are specified as a comma-separated list.
- When a method is called, each parameter is initialized with the value of the corresponding argument. There must be one argument in the method for each required parameter in the method declaration. Each argument must be consistent with the type of the corresponding parameter.
- When program control returns to the app where a method was called, the method's parameters are no longer accessible.
- Methods can return at most one value; the returned value can be a type that contains many values (as a struct) or a reference to an object that contains many values.

# Section 7.4.3 Assembling strings with Concatenation

+   - C# allows string objects to be created by assembling smaller strings into larger strings using operator +. This is known as string concatenation.
- Every value of a simple type in C# has a string representation. When one of the + operator's operands is a string, the other is implicitly converted to a string, then the two are concatenated.

# Section 7.4.4 Breaking Apart Large String Literals

+   - All objects have a ToString that returns a string representation of the object. When an object is concatenated with a string, the object's ToString method is implicitly called to obtain the string representation of the object, then the two strings are concatenated.
