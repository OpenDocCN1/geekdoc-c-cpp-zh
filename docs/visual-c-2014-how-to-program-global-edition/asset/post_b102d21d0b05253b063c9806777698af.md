XML Elements and Attributes
XML represents data as elements, attributes and text. XML delimits elements with start tags and end tags. A start tag consists of the element name, followed by attribute-value pairs, all enclosed in angle brackets. For example, line 1 in the sample XML

`<rsp stat="ok">`
is the start tag for rsp element containing the entire web-service response. This tag also contains the attribute stat (for status="ok") indicates that the Flickr web request was successful. An end tag consists of the element name preceded by a forward slash (/) in angle brackets (for example, </rsp>) in line 19, which denotes "end of response.".
