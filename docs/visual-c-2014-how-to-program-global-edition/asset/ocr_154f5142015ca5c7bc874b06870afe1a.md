# 21.11.1 LINQ Extension Methods Min, Max, Sum and Average

Class Enumerable<System.Linq> defines various LINQ extension methods for performing common reduction operations including:

+   - Min (line 19) returns the smallest value in the collection.
- Max (line 20) returns the largest value in the collection.
- Sum (line 21) returns the sum of all the values in the collection.
- Average (line 22) returns the average of all the values in the collection.

Iteration and Mutation Are Hidden from You
Note in lines 19–22 for each of these reduction operations:

+   - We simply say what we want to accomplish, not *how* to accomplish it—there are no iteration details in the app.
- *Mutable variables* are used in the app to perform these operations.
- The values collection is *not modified* (confirmed by the out of line 52).

In fact, the LINQ operations have no side effects that modify the original collection or any other variables in the app—a key aspect of functional programming.
Of course, behind the scenes iteration and mutable variables are required:

+   - All four extension methods iterate the collection and keep track of the current element they’re processing.
- While iterating the collection, Min and Average must store the current smallest and largest items, respectively, and Sum and Average must keep track of the total of the elements processed so far—all of these mutating a local variable that has been born from.

The other operations in Sections 21.11.2–21.11.4 also require iteration and mutable variables, but the *library*—which has already been debugged and tested—handles these details for you.
