**Web App Development with ASP.NET**
Microsoft's .NET server-technology, ASP.NET, enables you to create robust, scalable web-based apps. You'll build several apps, including a web-based guestbook that uses ASP.NET and the ADO .NET Entity Framework to store data in a database and display data in a web page.

**Extensible Markup Language (XML)**
The Extensible Markup Language (XML) is pervasive in the software-development industry, e-business and throughout the .NET-platform. It's used in most of this book's topics. XML is required to understand XAML—a Microsoft XML vocabulary used to describe graphical user interfaces, graphics and multimedia for Universal Windows Platform (UWP) GUI, graphics and multimedia apps, Windows 10 Mobile apps and Windows Presentation Foundation (WPF) apps. We present XAML fundamentals, which discuss LINQ to XAML, which allows you to query XML content using LINQ syntax.

## Universal Windows Platform (UWP) for Desktop and Mobile Apps
The Universal Windows Platform (UWP) is designed to provide a common platform and user experience across all devices, including personal computers, smartphones, tablets and even Microsoft’s new HoloLens virtual reality and augmented reality headset—all using nearly identical code. We present GUI, graphics and multimedia apps, and demonstrate them on both personal computers and the smartphone emulator that comes with Visual Studio 2015 Community edition.

## REST Web Services
Web services enable you to package functionality in a manner that turns the web into a library of reusable services. We include a case study on building a math generator that is called a math tutor.

## Building Microsoft Azure™ Cloud Computing
Azure services enable you to develop, manage and distribute your apps in the “cloud.” We’ll demonstrate how to use Azure services to store an app’s data.

## Windows Presentation Foundation (WPF) GUI, Graphics and Multimedia
Windows Presentation Foundation (WPF)—created after Windows Forms and before UWP—is another technology for building robust GUI and multimedia apps. WPF provides you with complete control over aspects of GUI’s look-and-feel and includes multimedia capabilities that are not available in Windows Forms. We discuss WPF in the context of a painting app, a text editor, color chooser, video player, various animations, and speech recognition apps. We’re moving away from WPF in favor of UWP for creating apps that can run on desktop, mobile and other devices. For this reason, the WPF introduction is provided as the previous edition—we will no longer feature this material.

## Optional Case Study: Using the UML to Develop Object-Oriented Design and C# Implementation of ATM (Automated Teller Machine) UML (Unified Modeling Language) is the industry-standard graphical language for visually modeling object-oriented systems. We use the UML in the early chapters and provide an optional object-oriented case study in which we use the UML to design and implement the software for a simple ATM. We analyze requirements document that specifies the details of the system to be built. We determine the classes needed to implement that, the attributes the classes need to have, the behaviors the classes need to exhibit and from the design, we produce a working implementation. Students often report a “light bulb moment”—the case study helps them tie it all together and truly understand object orientation.

## Teaching Approach
Visual C# How to Program, contains a collection of examples. We concentrate on building well-engineered software and stress complexity.

Live-Code Approach. The book is loaded with “live-code” examples—most concepts are presented in the context of complete working C# apps, followed by one or more executions showing program inputs and outputs. In the few cases we show a code snippet, to ensure correctness we first tested it in a working program then copied the code from the program and pasted it into the book.

Syntax Shading. For readability, syntax shade the code, similar to the way Studio colors the code. Our syntax-shading conventions are:

```
comments appear like this
keywords appear like this
constants and literal values appear like this
all other code appear in black
```

Code Highlighting. We emphasize key code segments by placing the key terms and the index's page reference for each occurrence in color bold. We show on in the bold Helvetica font (example, the File menu) and Visual C# program text in the Lucida font for (example, int count = 5). We use italics for emphasis.

Objectives. The chapter objectives preview the topics covered in the.

Programming Tips. We include programming tips to help you focus on important aspects of program development. These tips and practices represent the best we've gleaned from a combined nine decades of programming and teaching experience.

### Good Programming Practices
The Good Programming Practices call attention to techniques that will help you produce programs that are clearer, more understandable and maintainable.

### Common Programming Errors
Pointing out these Common Programming Errors reduces the likelihood that you'll make them.

### Error-Prevention Tips
These tips contain suggestions for exposing and removing bugs from your programs; many of the tips describe aspects of Visual C# that prevent bugs from getting into programs.

### Performance Tips
These tips highlight opportunities for making your programs faster or minimizing the amount of memory that they occupy.

### Portability Tips
These tips help you write code that will run on a variety of platforms.

### Software Engineering Observations
The Software Engineering Observations highlight architectural and design issues that affect the construction of software systems, especially large-scale systems.

### Look-and-feel Observation 3.1
These observations help you design attractive, user-friendly graphical user interfaces that conform to industry norms.

Terminology. We include an alphabetized list of the important terms defined in each chapter.

Index: We've included an extensive index for reference. Defining occurrences of key terms in the index are highlighted with a colored bold page.
