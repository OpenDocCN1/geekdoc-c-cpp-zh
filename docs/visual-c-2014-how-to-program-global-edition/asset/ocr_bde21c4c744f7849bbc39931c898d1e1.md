# Files

A file is a group of related records. More generally, a file contains arbitrary data in arbitrary
formats. In some operating systems, a file is viewed as a sequence of bytes—any or-
organization of the bytes in a file, such as organizing the data into records, is a view createdy the application programmer. It is not unusual for an organization to have many files,
some containing billions, or trillions, of characters of information.

# Database

A database is a collection of data for easy access and manipulation. The most
popular is the relational database, in which data is stored in simple tables. A table
includes records and fields. For example, a table of students might include first name, last
name, major, year, student ID number and grade-point-average fields. The data for each
student is a record, and the individual pieces of information in each record are the fields.
You can search, sort and otherwise manipulate the database based on its relationship to multiple
tables or databases. For example, a university might use data from the student database
combination with data from courses, on-campus housing, meal plans, etc.
