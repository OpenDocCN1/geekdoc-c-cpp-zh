# Generic Concatenate

Generic Concatenate (lines 55–64) iterates over its parameter (list2) with a foreach statement and calls AddLast to append each value to the end of its first parameter (list1). The LinkedList class's enumerator loops over the values of the nodes, not the nodes themselves, so the iteration is inferred to be the LinkedList's type T. Notice that this creates a new node in list1 for each list2. OneNode cannot be a member of more than one LinkedList. If you want the same data to belong to more than one LinkedList, you must make a copy of the code for each list to avoid InvalidOperationExceptions.

# Generic PrintList and Method ToUpperCaseStrings

Generic PrintList (lines 42–52) similarly uses a foreach statement to iterate over the values in a LinkedList, and outputs them. ToUpperCaseStrings (lines 67–78) takes a list of strings and converts each string to uppercase. This method replaces the strings in the list, so we cannot use a foreach statement as in the previous methods. Instead, we find the LinkedList via the First property (70) and use a sentinel-controlled while statement to loop through the list (lines 72–77). Each iteration of the while statement updates and obtains the contents of currentNode via property Value (line 74), using method ToUpper to create an uppercase version of the string (line 75). Then line 76 moves to the next node in the list by assigning currentNode to currentNode.Next, which refers to the LinkedList's next node. The Next property of the LinkedList's last node is null, so when the while statement passes the end of the list, loop exits.

# Method ToUpperCaseStrings is not a Generic Method

It does not make sense to declare ToUpperCaseStrings as a generic method, because it uses the string-specific methods of the values in the nodes.
