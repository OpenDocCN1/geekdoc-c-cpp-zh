# Section 16.6 Locating Characters and Substrings in strings

+   * string method IndexOf finds the first occurrence of a character or a substring in a string. Method LastIndexOf finds the last occurrence of a character or a substring in a string.

# Section 16.7 Extracting Substrings from strings

+   * Class string provides two Substring methods to enable a new string to be created by copying part of an existing string.

# 16.8 Concatenating strings:

+   * The static method Conc of class concatenates two strings and returns a new string containing the characters from both original strings.

# Section 16.10 ClassBuilder
