The event handlers for LinkLabels method Start of class Process (namespace System.Diagnostics), allows you to execute other programs, load documents or web sites from an app. Method Start can take one argument, or one, two arguments, to run and its command-line arguments. Method Start’s arguments can be in the same form as if they were provided for input to the Windows Run command (Start > Run...). For apps known to Windows, full names are not needed, and the file extension can be omitted. To open a file of a type that Windows recognizes (and how to handle), simply use the file's full name. For example, if you pass the .docx file, Windows will open it in Microsoft Word (whatever is registered to open .docx files, if any). The Windows operating system must be able to use the app associated with the file’s extension to open the file.

Line 23 sets the Linked property to true, which changes the link’s color from blue to purple (the LinkVisited colors can be configured through the Properties window in Visual Studio). ## 15.6 ListBox Control

The ListBox allows the user to view and select from multiple items in a list. ListBoxes are static GUI entities, which means users cannot directly edit the list of items.

The user can be provided with TextBoxes and Buttons with which to specify items to be added to the list, but the actual additions must be performed in code. The CheckedList-control (Section 15.7) extends a ListBox by including Checkboxes next to each item in the list. This allows users to place checks on multiple items at once, as is possible with CheckBox controls. (Users also select multiple items from a ListBox by setting the ListBox's SelectionMode property, which is discussed shortly.) Figure 15.15 displays a ListBox and Checked. In both controls, scrollbars appear if the number of items exceeds the ListBox's viewable area.

Both ListBox and Checked have properties Items, SelectedItem and SelectedIndex. Property Items returns a collection of the list items. Collections are a common way to manage lists of objects in the .NET framework. Many .NET GUI components (e.g., List) use collections to expose lists of internal objects (e.g., items in a ListBox). We discuss collections in Chapter 21. The collection returned by Items is an object of type ListBox.ObjectCollection. Property SelectedItem returns the currently selected item. If the user can select multiple items, use SelectedItems to return all the selected items as a ListObjectCollection. Property SelectedIndex returns the index of the selected item—if there could be more than one, use property SelectedIndices, which returns a ListBox.SelectedIndexCollection. If no items are selected, property SelectedIndex returns -1. Method GetSelected takes an index and returns true if the corresponding item is selected.

Adding Items to ListBoxes and CheckedListBox

To add items to a ListBox or a CheckedList, we must add items to its collection. This can be achieved by calling method Add a string to the ListBox's or CheckedListBox's Items. For example, we could write

```csharp
myListBox.Items.Add(myListItem);
```

to string myListItem to myListBox. To add multiple objects, you can either call method Add multiple times or call AddRange to an array of objects. Classes ListBox and CheckedListBox each call the submitted object's ToString method to determine the Label for the corresponding object's entry in the list. You can add different objects to a ListBox or a CheckedListBox that later be returned through properties SelectedItem and SelectedItems.
