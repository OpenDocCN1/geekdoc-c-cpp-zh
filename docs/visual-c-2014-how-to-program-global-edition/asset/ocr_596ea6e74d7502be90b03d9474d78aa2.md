18.10 (Quicksort) The recursive sorting technique quicksort uses the following basic algorithm for a one-dimensional array of values:

+   a) Partitioning Step: Take the first element of the unsorted array and determine its final location in the sorted array (i.e., all values to the left of the element in the array are less than it, and all values to the right of the element in the array are greater than the element—we show how to do this below). We now have one element in its location and two unsorted subarrays.

+   b) Recursive Step: Perform Step a on each unsorted subarray.
Each step a is performed on a subarray, another element two unsorted subarrays are created. When a subarray consists of one element, the element is in its final location (because a one-element array is already sorted).

The basic algorithm seems simple enough, but how do we determine the final position of the first element of each subarray? An example, consider the following set of values (the element in bold is the partitioning element—it will be placed in its final location in the sorted array):

37 2 6 4 8 9 10 12 68 45

+   Starting from the rightmost element, compare each element with 37 until an element less than 37 is found, swap and element. The first element less than 37 is 12, so 37 and 12 are swapped. The new array is

12 2 6 4 8 9 10 37 68 45

12 is in italics to indicate that it was swapped with 37.

+   Starting from the left of the array, beginning with the element 12, compare each element with 37 until an element greater than 37 is found—swap 37 and element. The first element greater than 37 is 89, so 37 and 89 are swapped. The new array is

12 2 6 4 37 8 10 89 68 45

+   Starting from the right, beginning with the element 89, compare each element with 37 until an element less than 37 is found—swap and element. The first element less than 37 is 10, so 37 and 10 are swapped. The new array is

12 2 6 4 10 37 8 89 68 45

+   Starting from the left, beginning with the element 10, compare each element with 37 until an element greater than 37 is found—swap and element. There are no elements greater than 37, so when we compare 37 with itself, we know that 37 has been placed in its final location of the sorted array. Every value to the left of 37 is smaller than it, and every value to the right of 37 is larger than it.

Once the partition has performed on the previous array, the subarray with values less than 37 contains 12, 2, 6, 4, 10 and 8. The subarray with values greater than 37 contains 89, 68, and 45. The sort continues recursively, with both subarrays being partitioned in the same manner as the original array.
