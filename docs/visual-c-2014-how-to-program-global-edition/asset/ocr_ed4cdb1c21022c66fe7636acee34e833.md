var sortAndFilter =
    from value in values // data source is values
    where value > 4
    orderby value descending

{
    Console.Write("${element}");

# 9.2.1 The From Clause

A LINQ query begins with a from clause (line 22), which specifies a range variable (value) and the data source to (values). The range variable represents each item in the data source (one at a time), like the control variable in a for statement. Since value is assigned one element at a time from the array values—an int array—the compiler infers that value should be of type int. You may also declare the range variable's type explicitly between the keyword and the range-variable's name.
