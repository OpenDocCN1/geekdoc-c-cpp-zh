# 9.5.1 The let Clause

Line 30 uses LINQ's let clause to create a new range variable. This is useful if you need to store a temporary result for later in the LINQ query. Typically, it declares a new variable to which you assign the result of an expression of the query's original range variable. In this case, we use method ToUpper to convert it to uppercase, then store it in the new range variable uppercaseString. We then use uppercaseString in the where, order and select clauses. The clause (line 31) uses method StartsWith performs a case-sensitive comparison to determine whether a string starts with the string received as an argument. If uppercaseString starts with "R", method StartsWith returns true, and the element is in the query results. More powerful string matching can be done using the regular-expression capability introduced in the online part of Chapter 16, Strings and Characters: A Deeper Look.

# 9.5.2 Deferred Execution

We create the query once (lines 29–33), yet iterating over the results (lines 37–40 and 58–61) gives two different lists of colors. This demonstrates LINQ query executes only when you access the results—like iterating over them or using the Count method—not when you define the query. This allows you to create a query once and execute it many times. Any changes to the data source are reflected in the results each time the query executes.

> Performance Tip 9.3
Deferred execution can improve performance when a query's results are not immediately needed.

# 9.5.3 Extension Methods ToArray and ToList

There may be times when you want to retrieve a collection of the results immediately. LINQ provides extension methods ToArray and ToList for this purpose. These methods execute the query on they're called and give you the results as an array or List<T>, respectively. we use ToArray in Section 21.12.

> Performance Tip 9.4
Methods ToArray and ToList also can improve efficiency if you're iterating over the results multiple times, as you execute the query only once.
