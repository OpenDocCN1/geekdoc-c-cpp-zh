7.20 Reference, output and value parameters. (Part 2 of 2.)

Method SquareRef (lines 37—40) multiplies its parameter x by itself and assigns the new value to x. SquareRef's parameter is declared as ref int, which indicates that the argument passed to this method must be an integer passed by reference. Because the argument is passed by reference, the assignment at line 39 modifies the original argument's value in the caller.

Method SquareOut (lines 44–48) multiplies the parameter value 6 (line 46), which squares that. SquareOut's parameter is declared as out int, which indicates that the argument passed to this method must be an int passed by reference and that the argument does not need to be initialized in.

Method Square (lines 52–55) multiplies its parameter x by itself and assigns the new value to x. When this method is called, a copy of the argument is passed to the parameter x. Thus, even parameter x is modified in the method, the original value in the caller is not modified.

Method Main (lines 8–34) invokes method SquareRef, SquareOut and Square. We begin by initializing y to 5 and declaring, not initializing z. Lines 18–19 call methods SquareRef and SquareOut. Notice that when you pass a value to a method with a reference parameter, you must precede the argument with the keyword (ref or out) that was used to declare the reference parameter. Lines 23–24 display the values of y and z after the calls to SquareRef and SquareOut. Notice that y has changed to 25 and z has been set to 36.
