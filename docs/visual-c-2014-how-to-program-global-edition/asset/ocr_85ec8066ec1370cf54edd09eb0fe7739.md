# 8.4.7 Using the Elements of an Array as Counters

Sometimes, apps use counter variables to summarize data, as the results of a survey. In Fig 7.7, we use counters in our die-rolling app to track the number of times each face of a six-sided die appeared as the app rolled the 60,000,000 times. An array version of the app in Fig. 7.7 is shown in Fig. 8.8.

```
1 // Fig. 8.8: RollDie.cs
2 // Roll a six-sided die 60,000,000 times.
3 using System;
4 
5 class RollDie
6 {
7     static void Main()
8 {
9         var randomNumbers = new Random(); // random-number generator
10        var frequency = new int[]; // array of frequency counters
11
12        // roll 60,000,000 times; use value as frequency index
13        for (var roll = 1; roll < 60000000; ++roll)
14
15            ++frequency[randomNumbers.Next(1, 7)];
16        }
17
18        Console.WriteLine("Face{}"Frequency{}", 10");
19
20        // output each array element's value
21        for (var face = 1; face < frequency.Length; ++face)
22        {
23            Console.WriteLine("Face{}"frequency[frequency[face], 10");
24        }
25    }
26 }
```

> Fig. 8.8 Roll a six-sided die 60,000,000 times.

The app uses array frequency (line 10) to count the occurrences of each roll. The single statement in line 15 replaces lines 24–44 of Fig. 7.7. Line 15 of Fig. 8.8 uses the random value to determine which frequency element to increment. The call to Next produces a random number from 1 to 6, so frequency must be large enough to store six counters. We use a seven-element array where we ignore index zero—it’s more logical to have the face value 1 increment frequency[1] than frequency[0]. Thus, each face value is used as an index for array frequency. We also replaced lines 48–50 of Fig. 7.7 by looping through array to output the results (Fig. 8.8, lines 21–24).
