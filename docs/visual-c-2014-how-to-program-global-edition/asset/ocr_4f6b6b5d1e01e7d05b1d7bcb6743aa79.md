# Chapter 9 Introduction to LINQ and the List Collection

LINQ Providers
The syntax of LINQ is built into C#, but LINQ queries may be used in many contexts via libraries known as providers. A LINQ provider is a set of classes that implement LINQ operations and enable programs to interact with data sources to perform tasks as sorting, grouping and filtering elements. Many LINQ providers are more specialized, allowing you to interact with a specific website or data format. Figure 9.1 shows where and how we use LINQ throughout the book.

There are two LINQ approaches—one uses a SQL-like syntax and the other method-call syntax. This chapter shows the simpler SQL-syntax. In Chapter 21, we'll show the method-call syntax, introducing the notions of delegates and lambdas—mechanisms that enable you to pass methods to other methods to help them perform their tasks.
