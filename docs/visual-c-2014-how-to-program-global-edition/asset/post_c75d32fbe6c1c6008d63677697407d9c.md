## 5.2 Algorithms
Any computing problem can be solved by executing a series of actions in a specific order. This procedure is called an algorithm. 2. Take off pajamas

4. Get dressed

6. Carpool to work

## 5.3 Pseudocode
Pseudocode is an informal language that helps develop algorithms without having to worry about the strict details of C# syntax. The pseudocode we present is particularly useful for developing algorithms that will be converted to C# apps. You may use, or use your native language(s) to develop your own pseudocode style.

Pseudocode does not execute on computers. Rather, it helps "think out" an algorithm before attempting to write it in a programming language, as C#. Output, assignments, calculations. In our pseudocode, we will not include any variable declarations, but some choose to list variables and mention their purposes.
