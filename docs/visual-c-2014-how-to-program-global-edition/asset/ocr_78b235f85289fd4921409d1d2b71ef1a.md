Creating Two-Dimensional Arrays with Array-Creation Expressions
A rectangular array may be created with an array-creation expression. For example, the fol-lowing lines declare variable b and assign a reference to a three-by-four rectangular array:

```
int[] b;
b = new int[3, 4];
```

In this case, we use the literal values 3 and 4 to specify the number of rows and number of columns, but this is not required—apps also can use variables and expressions to specify arrays. As with one-dimensional arrays, the elements of a rectangular array are initialized when the array object is created.

A jagged array cannot be completely created with a single array-creation expression. The following statement is

```
int[][][] c = new int[2][5]; // error
```

Instead, each one-dimensional array in the jagged array must be initialized separately. A jagged array can be created as follows:

```
int[][] c;
c = new int[2][]; // create 2 rows
c[0] = new int[5]; // create 5 columns for row 0
c[1] = new int[3]; // create 3 columns for row 1
```

The preceding statement creates a jagged array with two rows. Row 0 has five columns, and row 1 has three columns.
