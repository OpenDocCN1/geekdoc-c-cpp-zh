In 17.6, we know that we're inputting an account number, followed by first name and last name strings and a decimal balance. We also know that these values are separated by commas, with only one record on each line. So, we are able to parse the strings and convert the account number to int and the balance to decimal. It would be easier to read or write entire objects. Serialization provides a mechanism, called object serialization. A serialized object is an object represented as a sequence of bytes that includes the data, as well as information about the object's type and the types of data stored. After a serialized object has been written to a file, it can be read from the file and deserialized—that is, the type and bytes that represent the object and can be used to recreate the object in memory.

Class BinaryFormatter (namespace System.Runtime.Serialization.Formatters.) enables objects to be written to or read from a stream. BinaryFormatter writes a serialized representation to a file and BinaryFormatter method Deserialization reads this representation from a file and reconstruct the original object. Both methods throw a SerializationException if an error occurs during serialization or deserialization. Both methods require a Stream object (e.g., the FileStream) as a parameter so that the BinaryFormatter can access the correct stream.

In Sections 17.7–18, we create and manage sequential-access files using object serialization. Object serialization is performed with byte-based streams, so the files created and populated will be binary files. Binary files are not human-readable. For this reason, we write a separate app that reads and displays serialized objects. Other serialization formats are both human- and machine-readable. For example:

+   - JsonSerializer (namespace System.Xml.Serialization) can read and write objects in XML (Extensible Markup Language) format

+   - the DataJsonSerializer (namespace System.Runtime.Serialization.Json) can read and write objects in JSON (JavaScript Object Notation)

XML and JSON are popular formats for transferring data over the Internet.
