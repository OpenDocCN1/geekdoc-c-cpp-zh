# Chapter 7 Methods: A Deeper Look

There are several motivations for modularizing an app with methods:

+   - Soft reuse. For example, in previous apps, we did not have to define how to read a line of text from the keyboard—C# provides this capability via the Console's class's ReadLine method.
- Avoiding code repetition.
- Making programmers easier to test, debug and maintain.

> Software Engineering Observation 7.2
to promote software usability, every method should be limited to performing a single, well-defined task, and the name of the method should express effectively.

# 7.2.2 Calling Methods

As you know, a method is invoked by a call, and when the called method completes its task, it returns control and possibly a result to its caller. An analogy to the method-call-and-return structure is the hierarchical form of management (Fig. 7.1).

![](bbox=[0.142, 0.427, 0.854, 0.603])

**Fig. 7.1** Hierarchical boss-method/worker-method relationship.

A boss (caller) asks a worker (the called method) to perform a task and report back (i.e., return) the results after completing the task. The boss does not need to know how the worker method performs its designated tasks. The worker may call other worker methods, including one unknown to the boss. As we see, this hiding of implementation details promotes good software engineering. Figure 7.1 shows the boss communicating with several worker methods in a hierarchical manner. The boss divides the responsibilities among the various workers. Note that worker1 also acts as a “boss” to worker4 and worker5. The relationship does not need to be hierarchical, but often it is, which makes it easier to test, debug and update programs.

# 7.3 static methods, static Variables and Class Math

As mentioned in Section 6.6.1, although most methods are called to operate on the data of specific objects, this is not always the case. Sometimes a method performs a task that does not depend on the data of any object (other than the method's arguments). Such a method applies to the class in which it's declared as a whole and is known as a static method.
