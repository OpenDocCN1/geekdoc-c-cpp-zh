
## 4.9 Account Class with a Balance: Processing Monetary Amounts

```c
public string Name { get; set; } // auto-implemented property
private decimal balance; // instance variable

// Account constructor that receives two parameters
public Account(string accountName, decimal initialBalance)
{
    Name = accountName;
    Balance = initialBalance; // Balance's set accessor validates
}

// Balance property with validation
public decimal Balance
{
    get
    { return balance; }
    private set // can be used only within the class
    {
        // validate that the balance is greater than 0.0; if it's not,
        // instance variable keeps its prior value
        if (value > 0.0m) // m indicates that 0.0 is a decimal literal
            balance = value;
    }
}

// method that deposits (adds) only a valid amount to the balance
public void Deposit(decimal depositAmount)
{
    if (depositAmount > 0.0m) // if the depositAmount is valid
        Balance = Balance + depositAmount; // add it to the balance
}
```

## Account Property Balance

Property Balance (lines 17–32) of type decimal provides a get accessor, which allows clients of the account to obtain a particular Account object's balance. The property also provides a set accessor.

In Fig. 4.6, class Account defined a Name property in which the setter simply assigned the value in its implicit parameter value to class Account's instance variable. The Name property did not ensure that name contains only valid data.

The Balance property setter performs validation (also known as validity checking). Though we validated the balance in this example, we did not validate the name. Names are usually "free form"—there's a wide variety of acceptable name formats. ## set and get Access with Different Access Modifiers

By default, property's get and setter have the same access as the property—e.g., public Name public. It is possible to declare the get and setter with different access modifiers. In this case, one of the accessors must imply a more restrictive modifier than the property. We declared Balance property's setter private—this indicates it may be used only in Account, not by the class's. This enables us to ensure that any Account object exists, its balance can be modified only by method Deposit (and in the exercises, by method Withdraw as well).
