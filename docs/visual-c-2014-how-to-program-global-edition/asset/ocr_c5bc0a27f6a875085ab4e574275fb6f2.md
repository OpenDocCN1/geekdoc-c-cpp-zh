# 4.8 Account Class: Initializing Objects with Constructors

As mentioned in Section 4.6, when an object of class Account (Fig. 4.6) is created, its string instance variable is initialized to null by default. But what if you want to produce an actual name when you create Account object?

Each class does optionally provide a constructor with parameters that can be used to initialize an object when it’s created. C# requires a constructor for every object that’s created, which is the ideal point to initialize an instance variables. The next example enhances class Account (Fig. 4.8) with a constructor that can receive a name and use to initialize the Name property when an Account object is created (Fig. 4.9). Now you’ve seen class Account in action, this chapter’s two remaining examples present class before class AccountTest.
