# Making-a-Difference Exercises

**14.8** (Guess the Number Game) Write a program that plays "guess the number" as follows: Your program chooses the number by selecting an int random in the range 1–1000. The program displays the following text in a label:

I have a number between 1 and 1000—can you guess my number?
Please enter your first guess.

A TextBox should be used to input the guess. Each guess is input, the background color should change to red or blue. Red indicates that the user is getting "warmer," blue that the user is getting "cooler." Label should display either "Too High" or "Too Low," to help the user on the correct answer. When the user gets the correct answer, display "Correct!" in a message box, the Forms' background color to green and disable the TextBox (like other controls) can be disabled by setting the controls' enabled property to false. Provide a Button that allows the user to play again. When the Button is clicked, generate a new random number, change the background to the default color and enable the TextBox.

**14.9** (Stationery Hub) Write an app that allows users to process discounts for stationery. The app should calculate the price after deducting applicable discounts and then adding the price of purchased item, with any taxes. TextBoxes for invoicing the invoice number, order number, customer name and the office address are provided. Initially, these fields contain text that describes their purpose. Use CheckBox for selecting item and TextBoxes for quantities of items. The app should update the subtotal, total (after discount), tax and amount when the user changes any of the quantity's values. The app should also include a Button that when clicked, returns all fields to their original values. Use 5% for the discount if subtotal exceeds $500. Tax is calculated as 15% of the total. All fields must be filled out, and one must be checked for the user to enter a quantity for that item.

# Making-a-Difference Exercises

**14.10** (Econfont) Econfont—developed by SPRANG (a Netherlands-based company)—is a font designed to reduce by as much as 20% the amount of ink used for printing, further reducing the number of cartridges used and the environmental impact of manufacturing and shipping processes (using less ink, less fuel for shipping, and so on). The font, based on sans-serif Verdana, has small "holes" that are not visible in smaller sizes—such as the 9 or 10 point type used. Download the free version of Econfont http://www.ecofont.com/en/products/green/font_vera_sans.ttf tff using the fonts from the Econfont website.

Next, develop a GUI-based program that allows you to type text in a TextBox to be displayed in Econfont. Create Increase Size and Decrease Font Size buttons to allow you to scale up or down by 10 point. Set the TextBox font to 9 point Econfont. Set the TextBox's Inline property to true so the user can enter multiple lines of text. As you scale up, you will be able to see the holes in the letters more clearly. As you scale down, the font will be less apparent. To change the TextBox' font programmatically, use a statement of the form:

```
inputTextBox.Font = new (inputTextBox.Font.Family,
inputTextBox.Font.SizePoints+1);
```

This changes the TextBox's Font to a new object that uses the TextBox's current font, but adds to its SizePoints property to increase the font size. A similar method can be used to decrease the font size. What is the smallest font size at which you can notice the holes?

**14.11** (Project: Typing Tutor—A Crucial Skill for Computers) Typing quickly and correctly is an essential skill. In this exercise, you'll build an app that allows users to type without looking at the keyboard. The app should show what the user types. The app should display a keyboard on the screen and highlight the key being pressed. The app should also show a counter of how many words the user has typed. The user should be able to reset the counter at any time. The user should also be able to change the color of the text. The user should be able to change the font size of the text. The user should be able to save the text to a file.
