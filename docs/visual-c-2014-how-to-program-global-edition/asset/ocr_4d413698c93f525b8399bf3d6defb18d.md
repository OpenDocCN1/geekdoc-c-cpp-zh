As generic methods, when a generic is compiled, the compiler performs type checking on the class's parameters to ensure they can be used with the code in the generic class. For value-types, the compiler generates a custom version of the class for each unique value type to create a new Stack object, and for reference types, the compiler generates a single additional Custom Stack. The constraints determine the operations that can be performed on the type parameters. For reference types, the runtime replaces the type parameters with the actual types. For Stack, no type constraint is specified, so the default type constraint, is used. The scope of a generic class's type is the entire class.
