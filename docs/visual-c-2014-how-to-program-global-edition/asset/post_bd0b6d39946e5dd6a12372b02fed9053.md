## 5.11.6 App That Implements the Pseudocode Algorithm

The program that implements the pseudocode algorithm and two sample executions are shown in Fig. 5.13. Lines 10–12 declare the local variables that method Main uses to process the examination results.

```csharp
// Fig. 5.13: Analysis.cs
// Analysis of examination results, using nested control statements.
using System;
class Analysis {
    static void Main() {
        // initialize variables in declarations
        int passes = 0; // number of passes
        int failures = 0; // number of failures
        int studentCounter = 1; // student counter

        // process 10 students using student-controlled iteration
        while (studentCounter <= 10) {
            // prompt user for input and obtain a value from the user
            Console.Write("Enter result (1 = pass, 2 = fail): ");
            int result = int.Parse(Console.ReadLine());
            if (result == 1) {
                passes = passes + 1; // increment passes
            } else {
                failures = failures + 1; // increment failures
            }
        }
        // increment studentCounter to loop eventually terminates
        studentCounter = studentCounter + 1;
    }
    // termination phase; prepare and display results
    Console.WriteLine($"Passed: {passes}\nFailed: {failures}");
}
```

## 5.13 Increment and Decrement Operators

The increment and decrement operators are used to increase or decrease the value of a variable by one.

The increment operator is `++` and the decrement operator is `--`. These can be used either before or after the variable.

- `++variable`: The value of the variable is incremented and then the result is used.
- `variable++`: The value of the variable is used and then the variable is incremented.
- `--variable`: The value of the variable is decremented and then the result is used.
- `variable--`: The value of the variable is used and then the variable is decremented.

```csharp
int count = 5;
Console.WriteLine(+count); // displays 6
Console.WriteLine(count++); // displays 6, count becomes 7
Console.WriteLine(--count); // displays 6, count becomes 5
Console.WriteLine(count--); // displays 5, count becomes 4
```

| Operator | Type | Description |
|---|---|---|
| `++` | Prefix Increment | Increments the variable then returns the value. |
| `++` | Postfix Increment | Returns the value then increments the variable. |
| `--` | Prefix Decrement | Decrements the variable then returns the value. |
| `--` | Postfix Decrement | Returns the value then decrements the variable. |

## 5.15 Ternary Operator

The ternary operator is the only operator in C# that takes three operands. It is a shorthand for an if...else statement.

The syntax is: `condition ? expression_true : expression_false`

```csharp
int age = 20;
string result = (age >= 18) ? "Adult" : "Minor";
Console.WriteLine(result); // displays Adult
```
