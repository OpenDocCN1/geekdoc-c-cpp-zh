
# Summary 701

- ListBox property determines the number of items that can be selected.
- The SelectedIndexChanged event of class ListBox occurs when the user selects a new item.
- Property Items returns all the items as a collection.
- PropertySelectedItem returns the currently selected item.
- Use Add to add to the ListBox's Items collection.
- You can add items to ListBoxes and CheckedListBoxes visually using the Items property in the Properties window.

## Section 15.7 CheckedListBoxControl

- The CheckedListBox extends a ListBox by including a checkbox to each item.
- Items can be added via methods Add and AddRange or through the String Collection Editor.
- CheckedListBox event ItemCheck occurs when a user checks or unchecks a CheckedListBox.

## Section 15.8 ComboBox Control

- The ComboBox control provides TextBox features with a drop-down list.
- Property MaxDropDownItems specifies the maximum number of items that can display at one time.
- You can add objects to items programmatically, using methods Add and AddRange, or visually, with the String Collection Editor.
- Property DropDownStyle determines the type of ComboBox and is represented as a value of the ComboBoxStyle which contains values Simple, DropDown and DropDownList.
- There can be at most one selected item in a ComboBox (if none, then SelectedIndex is -1).
- When the selected item changes in a ComboBox, a SelectedIndex event occurs.

## Section 15.9 TreeView Control

- The Tree control displays nodes hierarchically in a tree.
- Traditionally, nodes are objects that contain values and can refer to other nodes.
- A parent node contains children, and the child nodes can be parents to other nodes.
- Two child nodes that have the same parent node are considered sibling nodes.
- A tree is a collection of nodes, usually organized in a hierarchical manner. The first node of a tree is a root node.
- In a TreeView, a node can be expanded or collapsed by clicking the plus or minus box to its left. Nodes without children do not have these boxes.
- The nodes displayed in a TreeView are instances of class TreeNode.
- Each TreeNode has its Nodes collection (type TreeNodeCollection), containing a list of TreeNodes.
- To add nodes to a TreeView, click the ellipsis next to property in the Properties window. This displays an empty tree representing the TreeView.
- To add nodes programmatically, you must create a TreeNode object and pass it to a display. Then call Add to add this new TreeNode to the TreeView's Nodes collection.

## Section 15.10 ListView Control

- ListView control is similar to a ListBox in that both display lists from the user can select one or more items. ListView is more flexible and can display items in different formats.

- Property MultiSelect (bool) determines whether multiple items can be selected.
- To display images, an ImageList control is required.
- Property SmallImageList of class ListView sets the ImageList for the small icons.
- Property LargeImageList of class ListView sets the ImageList for large icons.
- The items in a ListView are each of type ListViewItem.

## Section 15.11 TabControlControl

- The TabControl creates tabbed windows.
- TabControls contain TabPage objects. Only one Tab is displayed at a time.
- You can add TabControls by dragging and dropping them on a Form in Design mode.
- To add TabPages in Design mode, click the Control's small tasks menu and click Add Tab, or click the TabPages in the Properties window, and add tabs in the dialog that appears.
- Each Tab raises a Click event when it is clicked.

## Section 15.12 Multiple Document Interface (MDI) Windows

- The app window of a multiple document interface (MDI) program is the parent window, and each inside window is referred to as a child window.
- Child windows cannot parent themselves and cannot be moved outside their parent.
- To add a child Form to the parent, create a new child Form object, set its MdiParent property to the parent Form and call the child Form Show method.
- Property MdiWindowList of class MenuStrip specifies which menu, if any, displays a list of open windows.
- MDI containers allow you to manage the placement of child windows. The child windows in an MDI app can be arranged by calling LayoutMdi of the parent Form.

## Section 15.13 Visual Inheritance

- Visual inheritance enables you to create a new Form by inheriting from an existing Form. The derived Form contains the functionality of its base class.
- Visual inheritance can also be applied with other controls as well.
- Visual inheritance enables you to achieve visual consistency across apps by reusing code.
- A reusable control is typically placed in a class library.
- When you compile a class library, the compiler will create a .dll file, known as a dynamically linked library—a way to package classes that you can reference from other apps.

## Section 15.14 User-Defined Controls

- .NET Framework allows you to create custom controls.
- Custom controls can appear in the user's Toolbox and can be added to Forms, Panels or Groups in the same way that Buttons, Labels and other predefined controls are.
- The simplest way to create a custom control is to derive a class from an existing control, such as a Label. This is useful if you want to add functionality to an existing control, rather than replacing it with one that provides the desired functionality.
- To create a new control composed of existing controls, use userCollection.
- Controls added to a custom control are called constituent controls.

# Terminology 703

- A programmer can create a brand-new control by inheriting from class Control. This class does not define any specific behavior; task is left to you.
- Timers are non-visual components that generate Tick events at an interval. This interval is set by the Timer's Interval property, which defines the number of milliseconds (thousands of a second) between events. Timers are disabled by default.
