# 17.7 Creating a Sequential-Access File Using Object Serialization

```
// Fig. 17.8: RecordSerializable.cs
// Serializable class that represents a data record.
namespace BankLibrary
{
    [Serializable]
    public class RecordSerializable
    {
        public int Account { get; set; }
        public string FirstName { get; set; }
        public string LastName { get; set; }
        public decimal Balance { get; set; }

        // default constructor sets members to default values
        public RecordSerializable()
            :this(0, string.Empty, string.Empty, OM) {}

        // overloaded constructor sets members to parameter values
        public RecordSerializable(int account, string firstName,
        {
            Account = account;
            FirstName = firstName;
            LastName = lastName;
            Balance = balance;
        }
    }
}
```

In a class that is marked with the [Serializable] attribute or implements interface ISerializable, you must ensure that every instance variable of the class is serializable. All simple-type variables and strings are serializable. For variables of reference types, you must check the class declaration (and possibly base classes) to ensure that the type is serializable. By default, array objects are serializable. However, if the array contains references to other objects, these objects may or not be serializable.
