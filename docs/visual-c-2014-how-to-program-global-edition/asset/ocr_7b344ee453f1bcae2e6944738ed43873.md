Method *Select* transfers the focus to a control and makes it the active control. When you press the *Tab* key in editing Windows Forms app, controls receive the focus in the order specified by own. This property is set by Visual Studio in the order in which controls are added to a Form, but you can change the ordering using **View > Tab Order**. TabIndex is helpful for users who enter information in many controls, such as a TextBox that represents a user's name, address and phone number. The user can enter information then quickly select the next control by pressing the *Tab* key.

Property *Enabled* indicates whether the user can interact with a control to generate event. Often, if a control is disabled, it's because an option is unavailable to the user at that time. For example, text editors often disable the "paste" command until the user cuts or copies some text. In most cases, a disabled control's text appears in gray (rather than black). You can also hide a control from the user without disabling the control by setting the Visible property to *false* or by calling Hide. In each case, the control still exists but is not visible on the Form.
