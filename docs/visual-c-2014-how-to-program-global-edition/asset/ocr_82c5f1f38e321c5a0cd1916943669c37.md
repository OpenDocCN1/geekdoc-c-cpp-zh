# Create the GUI

To create this GUI, begin by dragging the MenuStrip from the Toolbox onto the Form. Then use Design mode to create the menu structure in the sample outputs. The **File (fileToolStripMenuItem)** has menu items

+   * **About** (aboutToolStripMenuItem)
* **Exit** (exitToolStripMenuItem).

The Format menu menu (formatToolStripMenuItem) has two submenus. The first submenu, **Color** (colorToolStripMenuItem), contains menu items

+   * **Black** (blackToolStripMenuItem)
* **Blue** (blueToolStripMenuItem)
* **Red** (redToolStripMenuItem)
* **Green** (greenToolStripMenuItem).

The second submenu, **Font** (fontToolStripMenuItem), contains menu items

+   * **Times New Roman** (timesToolStripMenuItem).
