6.10 (What Does This Code Do?) What does the following app do?

```
// Exercise 6.10 Solution: TwoForLoops.cs
using System;
class TwoForLoops {
    static void Main() {
        for (int x = 4; x >= 1; --x) {
            for (int y = 5; y >= 1; --y) {
                Console.Write("\t{y}");
            }
        }
        Console.WriteLine();
    }
}
```
