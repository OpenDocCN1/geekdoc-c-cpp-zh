# 8.10 Case Study: GradeBook Using a Rectangular Array

Processing a Two-Dimensional Array with a foreach Statement
Methods GetMinimum, GetMaximum and OutputChart each loop through array grades using the foreach statement—example, the foreach statement method GetMinimum (lines 50–57). To find the lowest overall grade, this statement iterates through rectangular array grades and compares each element to variable lowGrade. If a grade is less than one, lowGrade is set to that grade.

When the foreach statement traverses the elements of array grades, it looks at each element of the first row in order by index, and so on. The foreach statement (lines 50–57) traverses the elements of grades in the second row in the same order as the following equivalent code, expressed with nested statements:

```
for (var row = 0; row < grades.getLength(); ++row)
  for (var column = 0; column < grades.getLength(1); ++column)
    if (grades[row, column] < lowGrade)
      lowGrade = grades[row, column];


```

When the foreach statement completes, lowGrade contains the lowest grade in the rectangular array. Method GetMaximum works similarly to method GetMinimum. Note the simplicity of using foreach, vs the preceding nested statement for.

> Software Engineering Observation 8.2
“Keep it simple” is good advice for most of the code you’ll write.
