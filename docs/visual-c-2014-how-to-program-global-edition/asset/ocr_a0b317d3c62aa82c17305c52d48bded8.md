# 2.2.5 New Project Dialog and Project Templates

For the discussions in the next sections, we’ll create a new project. Select File > New > Project... to display the New Project dialog (Fig. 2.3). Dialogs that facilitate user-computer communication.

![](bbox=[0.178, 0.258, 0.821, 0.603])

**Fig. 2.3** New Project dialog.

Visual Studio provides templates (left column of Fig. 2.3)—the project types that users can create in C# and other languages. The templates includes Windows Forms apps, WPF apps and others—full versions of Visual Studio provide additional templates. In this chapter, you’ll build a Windows Forms Application—an app that executes within a Windows operating system (such as Windows 7, 8 or 10) and typically has a graphical user interface (GUI). Users editing this part of the app includes software products like Microsoft Word, Internet Explorer and Visual Studio, software products created by other vendors, and customized software that and other developers create. You’ll create many apps in this book.

To create a Windows Forms Application, under Templates select Visual C > Windows > Classic Desktop, then in the middle column select Windows Forms Application. By default, Visual Studio assigns the name WindowsFormsApplication1 to a new Windows Forms Application project and solution (Fig. 2.3). Click OK to display the IDE in Design (Fig. 2.4), which contains the features that you can enable to create an app’s GUI.
