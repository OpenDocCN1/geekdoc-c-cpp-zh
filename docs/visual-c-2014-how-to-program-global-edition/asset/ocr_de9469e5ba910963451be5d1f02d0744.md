If both operands of the division operator (/) are integers, integer division is performed and the result is an integer—for example, the expression 7/4 evaluates to 1, and 17/5 evaluates to 3. Any fractional part in integer division is simply truncated (discard)—no rounding occurs. C# provides the remainder operator, %, which yields the remainder after division.
