## 5.3 伪代码
伪代码是一种非正式语言，有助于在不担心 C# 语法严格细节的情况下开发算法。我们展示的伪代码对于开发将转换为 C# 程序的算法特别有用。你可以使用，或使用你的原生语言开发自己的伪代码风格。

伪代码并不在计算机上运行。相反，它有助于在尝试用编程语言（如 C#）编写之前“思考”算法。输出、赋值、计算。在我们的伪代码中，不会包含任何变量声明，但某些人会列出变量并说明用途。
