# 1.8.9 Other Key Programming Languages

Figure 1.6 provides brief comments on several popular programming languages.

| Programming language | Description |
| --- | --- |
| Ada | Ada, based on Pascal, was developed under the sponsorship of the U.S. Department of Defense (DOD) in the 1970s and 1980s. The DOD wanted a single language that would fill most of its needs. The Pascal-based language was named after Ada Lovelace, daughter of the poet Lord Byron. She's credited with writing the world's first computer program in the early 1800s (for the Analytical Mechanical computing device designed by Charles Babbage). Ada also supports object-oriented programming. |
| Basic | Basic was developed in the 1960s at Dartmouth to normalize with programming techniques. Many of its latest versions are object oriented. |
| C | C was developed in the early 1970s by Dennis Ritchie at Bell Laboratories. It initially became known as the UNIX operating system's development language. Today, most code for general-purpose operating systems is written in C or C++. |
| C++ | C++, which is based on C, was developed by Bjarne Stroustrup in the early 1980s at Bell Laboratories. It provides several features 'spruce' the C language, but more importantly, it provides capabilities for object-oriented programming. |
| COBOL | COBOL (Common Business Oriented Language) was developed in the late 1950s by manufacturers, the U.S. government and industrial computer users, by a language developed by Grace Hopper, a career U.S. Navy officer and computer scientist. COBOL is still widely used for commercial applications that require precise and efficient manipulation of large amounts of data. Its latest versions support object-oriented programming. |
| Fortran | Fortran (FORmula TRANslator) was developed by IBM in the mid-1950s to be used for scientific and engineering applications that require complex mathematical computations. It is still widely, and its latest versions support object-oriented programming. |
| Java | Sun Microsystems in 1991 founded an internal research project led by James Gosling, which resulted in the C+-based object-oriented programming language Java. A key goal of Java is to enable developers to write programs that run on a variety of computers and computer-controlled devices. This is sometimes called 'write once, run anywhere.' Java is used to develop large-scale enterprise applications, to enhance the functionality of web services (the computers provide the content we see in our browsers), to provide applications for consumer devices (e.g., smartphones, tablets, television set-top boxes, appliances, automobiles and more) and for many other purposes. Java is also the key language for developing Android smartphone and tablet apps. |
| Objective-C | Objective-C is an object-oriented language based on C. It was developed in the early 1980s and later acquired by NeXT, which in turn was acquired by Apple. It became the programming language for the OS operating system and all iOS-powered devices (such as iPods, iPhones and iPads).
