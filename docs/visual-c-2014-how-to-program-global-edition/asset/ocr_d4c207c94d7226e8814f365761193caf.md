# 18.7 (Bucket Sort) A bucket sort begins with one-dimensional array of positive integers is sorted into a two-dimensional array of integers with rows from 0 to 9 and columns from 0 to n-1, where n is the number of values to be sorted. Each row of the two-dimensional array is referred to as a bucket. A class named BucketSort contains a method called sort operates as follows:

+   - Place each value of the one-dimensional array into a row of the bucket array, based on the value "ones" (rightmost) digit. For example, 97 is placed in row 7, 3 is placed in row 3 and 100 is placed in row 0. This procedure is called a distribution pass.
- Loop through each bucket row and copy the values back to the original array. This procedure is called a gathering pass. The new order of preceding values in the one-dimensional array is 100, 3 and 97.
- Repeat this process for each subsequent digit (tens, hundreds, thousands, etc.).

On the second pass (tens digit), 100 is placed in row 0, 3 is placed in row 0 (because it has no tens digit) and 97 is placed in 9. After the gathering pass, the order of the values in the one-dimensional array is 100, 3 and 97. On the third pass (hundreds digit), 100 is placed in row 1, 3 is placed in row 0

The two-dimensional array of buckets is 10 times the length of the integer array being sorted. This sorting technique provides better performance than a bubble sort, but requires more memory—the bubble sort requires space for only one additional element of data. This comparison is an example of the space/time trade-off; the bubble sort uses more memory than the bubble sort, but performs better. This version of bubble sort requires copying all the data back to the original array on each pass. Another possibility is to create a two-dimensional bucket array and repeat the swap between the two buckets.
