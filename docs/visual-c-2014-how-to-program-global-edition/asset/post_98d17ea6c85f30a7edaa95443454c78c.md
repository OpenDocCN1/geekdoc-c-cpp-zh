## 19.2 Simple-Type structs, Boxing and Unboxing

The data structures we discuss in this chapter store object references. As you’ll see soon, we’re able to store both simple- and reference-type values in these data structures. This section discusses the mechanisms that enable simple-type values to be manipulated as objects.

### Simple-Type structs

Each type (see Appendix B) has a corresponding struct in Namespace that defines the simple type. These structs are all Boolean, Byte, SByte, Char, Decimal, Double, Single, Int16, UInt32, Int64 and UInt64. Types declared with keyword struct are value types.

Simple types are actually aliases for their corresponding structs, so a simple type can be declared using either the keyword for that simple type or the struct name--e.g., int and Int32 are interchangeable. The methods related to a simple type are located in the corresponding struct (e.g., method Parse, which converts a string to an int value, is located in struct Int32). Refer to the documentation for the corresponding struct to see the methods available for manipulating values of type.

### Boxing and Unboxing Conversions

Simple types and other structs inherit from ValueType in namespace System. Class ValueType inherits from class object. Thus, any simple-type value can be assigned to an object; this is referred to as a boxing conversion and enables simple types to be used as objects. In boxing, the simple value is copied into an object so that the simple-type value can be manipulated as an. Boxing conversions can be performed explicitly or implicitly as shown in the following statements:

```c
int i = 3; // create an int value
object object1 = (object) i; // explicitly box the int value
object object2 = i; // implicitly box the int value
```

After executing the code, both object1 and object2 refer to two different objects that contain a copy of the integer value in int i. Unboxing conversion can be used to convert an object reference to a simple value, as shown in the following:

```csharp
int int1 = (int) object1; // explicitly unbox the int value
```

Explicitly attempting to unbox an object reference that does not refer to the correct simple value causes InvalidCastException. In Chapters 20 and 21, we will see how you can create data structures of specific value types that you do not need boxing and unboxing conversions.

## 19.3 Self-Referential Classes

A self-referential class contains a reference member that refers to an object of the same class. For example, the class declaration in Fig. 19.1 defines the shell of a self-referential class Node. This has two properties--Data (an int) and Next (a Node). Next references another object--that is an object of the same type as the one declared here, hence the term "self-referential class." Next is referred to as a link (like the links in a chain).

```csharp
// Fig. 19.1
// Self-referential Node class declaration.
class Node
{
    public int Data { get; set; } // store integer data
    public Node Next { get; set; } // store reference to next Node

    public Node(int data)
    {
        Data = data;
    }
}
```

Self-referential objects can be linked to form useful data structures, such as lists, queues, stacks and trees. Figure 19.2 illustrates two self-referential objects linked together to a linked list. A backslash (representing a null reference) is placed in the link member of the second self-referential object to indicate that the link does not refer to another object. The backslash is for illustration purposes; it does not correspond to the backslash character in C#. A null normally indicates the end of a data structure.

Creating and maintaining dynamic data structures requires dynamic memory allocation—a program's ability to obtain more memory at execution time to hold new nodes and release space no longer needed. As you learned in Section 10.8, C# programs do not explicitly release dynamically allocated memory—rather, the CLR performs automatic garbage collection.

The new operator is dynamic to memory allocation. Operator new takes as an operand the type of object being dynamically allocated and returns a reference to an object of that type. The statement

```csharp
var nodeToAdd = new Node(10);
```

allocates the appropriate amount of memory to store a Node, initializes it and returns a reference to this object nodeToAdd. If no memory is available, it throws an OutOfMemoryException. The constructor argument specifies the Node object's data.

The following sections discuss lists, stacks, queues and trees. These data structures are created and maintained with dynamic memory allocation and self-referential classes.
