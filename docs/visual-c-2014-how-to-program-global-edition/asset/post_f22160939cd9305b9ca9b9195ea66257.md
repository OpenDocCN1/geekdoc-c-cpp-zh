## Answers to Self-Review Exercises

- 4.1 a) class. c) new. d) type, e) void. f) instance variable. g) auto-implemented property. h) decimal. i) parse. j) access
- 4.2 False. By convention, names begin with an uppercase letter and all subsequent in the name begin with an uppercase letter. False. A property's getter accessor enables a client to retrieve the value of the instance variable associated with the property. A property's setter accessor enables a client to modify the value of the instance variable associated with the property. c) Numeric-type instance variables are initialized to 0, boolean-type instance variables are initialized to false and instance variables of all other types are initialized to null. d) True. e) True. g) False. Such variables are called local variables and can be used only in the method where they're declared. h) False. A property declaration can contain a getter, a setter or both. i) True. Instance variables are initialized by default.

4.3 A local variable is declared in the body of a method and can be used only in the method where it's declared. An instance variable is declared in a class, but not in the body of any of the class's members. Every object (instance) of a class has a separate copy of the class's instance variables. Also, instance variables are accessible to all members of the class (We will see an exception to this in Chapter 10).

4.4 A parameter represents additional information that a method requires to perform its task. Each parameter required by a method is specified in the method's declaration. An argument is the actual value passed to a parameter when a method is called.
