# 8.6.1 Class Card and Getter-Only Auto-Implemented Properties

Class Card (8.10) contains two auto-implemented properties—Face and suit—that reference to the face value and name for a game set. Prior to C# 6, auto-implemented properties required both a getter and a setter. Face and suit are declared as C# 6 getter-auto-implemented properties, which client code can use only to get each property. Such properties are read only. Getter-only properties can be initialized only in their declarations or in all of the type's constructors. Initializing an auto-implemented property in its declaration is another C# 6 feature known as auto-property initializer. To do so, follow the property declaration with an = and initial value,


```csharp
class DeckOfCards
{
    // create one Random object to share among DeckOfCards objects
    private static Random randomNumbers = new Random();

    private int NumberOfCards = 52; // number of cards in a deck
    Card[] deck = new Card[NumberOfCards];
    private int currentCard = 0; // index of next card to be dealt (0-51)

    // constructor fills deck of Cards
    public DeckOfCards() {
        string[] faces = {"Ace","Deuce","Three","Four","Five","Six",
        "Seven","Eight","Nine","Ten","Jack","Queen","King"};
        string[] suits = {"Hearts","Diamonds","Clubs","Spades"};

        // populate deck with Card objects
        for (var count = 0; count < deck.Length; count++) {
            deck[count] = new Card(faces[count % 13], suits[count / 13]);
        }

        // shuffle deck of Cards with one-pass algorithm
        public void Shuffle() {
            // after shuffling, dealing should start at deck[0] again
            currentCard = 0; // reinitialize currentCard

            // for each card, pick another random Card and swap them
            for (var first = 0; first < deck.Length; ++first) {
                // select a random number between 0 and 51
                var second = randomNumbers.Next(NumberOfCards);

                // swap current Card with randomly selected Card
                Card temp = deck[first];
                deck[first] = deck[second];
                deck[second] = temp;
            }
        }

        // deal one Card
        public Card DealCard() {
            // determine whether remain to be dealt
            if (currentCard < deck.Length)
                return deck[currentCard++]; // return current Card in array
            } else {
                return null; // indicate that all Cards were dealt
            }
        }
    }
}
```

**Class DeckOfCards: Constructor**
The constructor uses a for statement (lines 22–25) to fill the deck array with Cards. The statement initializes count to 0 and loops until count is less than deck.Length, causing count to take on each integer value from 0 to 51 (the indices). Each Card is instantiated and initialized with two strings—one from faces array at 17–18 (which contains the strings "Ace" to "King") and one from suits array at line 19 ("Hearts," "Diamonds," "Clubs," "Spades"). The calculation count % 13 (line 24) results in a value from 0 to 12—the indices. Similarly, the calculation / 13 results in a value from 0 to 3—the four indices. When the deck array is initialized, it contains the Cards with faces "Ace" to "King" in order for each suit.

**Class DeckOfCards: Shuffle Method**
Shuffle Method (lines 29–45) shuffles the deck. The method loops through all 52 Cards and performs the following tasks:

- For each Card, pick another Card.
- Next, the current Card object and the randomly selected Card object are swapped in the array. The exchange is performed by three assignments in lines 41–43. The extra variable temp temporarily stores one of the two Cards being swapped.
