## Create the GUI

To create this GUI, begin by dragging the MenuStrip onto the Form. Then use Design mode to create the menu structure in the sample outputs. The **File** menu has menu items:
- **About**
- **Exit**

The **Format** menu has two submenus. The first submenu, **Color**, contains menu items:
- **Black**
- **Blue**
- **Red**
- **Green**

The second submenu, **Font**, contains menu items:
- **Times New Roman**
- **Courier**
- **Comic Sans**
- a separator bar
- **Bold**
- **Italic**

## Handling the Click Events for About and Exit Items

The About menu item in the File menu displays a MessageBox (lines 20–25). The Exit menu item closes the app through `Application.Exit()` (line 30).

## Color Submenu Events

To indicate that a menu item is selected, we will set its Checked property to true. This causes a check to appear to the left of the item. Each item has its own Click handler. The handler for Black is `blackToolStripMenuItem_Click` (lines 44–53). Similarly, the event handlers for Blue and Red are `blueToolStripMenuItem_Click` (lines 55–64), `redToolStripMenuItem_Click` (lines 67–76) and `greenToolStripMenuItem_Click`. Each menu item must be mutually exclusive, so each event handler calls `ClearColor()` (lines 34–41) before setting its corresponding Checked property to true. `ClearColor()` sets the Checked property of each color item to false, effectively preventing more than one menu item from being selected at a time. In the designer, we set the menu item Checked property to true because at the start of the program.

> The mutual exclusion of menu items is not enforced by the MenuStrip, even when the Checked property is true. You must program this yourself.

## Font Submenu Events

The Font menu contains three items for fonts (Courier, Times New Roman and Comic) and two menu items for styles (Bold and Italic). We added a separator bar between the font and style menu items to indicate that these are separate options. A Font object can specify only one font at a time but can specify styles at once (e.g., be both bold and italic). We set the font menu items to display checks. With the Color menu, we must enforce mutual exclusion of these items in event handlers. Event handlers for menu items Times New Roman, Courier and Comic Sans are `timesToolStripMenuItem_Click` (lines 100–110), `courierToolStripMenuItem_Click` (lines 113–123) and `comicToolStripMenuItem_Click` (lines 126–136), respectively. These event handlers are similar to those of the Color menu. Each sets the Checked property for all menu items by calling `ClearFont()` (lines 91–97), then sets the Checked property of the menu item that raised the event to true. This enforces the mutual exclusion of the menu items. In the designer, we initially set the Times Roman menu item's Checked property to true because this is the original font for the text Form. The event handlers for the **Bold** and *Italic* menu items (lines 139–160) use the bitwise exclusive OR (^) operator to combine styles, as we discussed in Chapter 14.

## 15.3 MonthCalendar Control

Many apps must perform date and time calculations. The .NET Framework provides two controls that allow an app to retrieve date and time information—DateTimePicker (Section 15.4).

The MonthCalendar (Fig. 15.8) control displays a monthly calendar on the Form. The user can select a date from the displayed month or use the provided arrows to navigate to another month. When a date is selected, it is highlighted. Multiple dates can be selected by clicking dates on the calendar while holding down the Shift key. The default first event for this control is the DateChanged event, which is generated when a new date is selected. Properties are provided that allow you to modify the appearance of the calendar, how many dates can be selected at once, and the minimum and maximum date that may be selected. MonthCalendar properties and a common MonthCalendar event are summarized in Fig. 15.9.
