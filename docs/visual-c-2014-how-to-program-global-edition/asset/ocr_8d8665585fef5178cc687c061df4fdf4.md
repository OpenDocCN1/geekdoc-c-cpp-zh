**CommissionEmployee Class Overview**
CommissionEmployee's attributes include public, getter-only, auto-implemented properties FirstName, LastName and SocialSecurityNumber, and private instance variables grossSales and commissionRate. The class provides

Because instance variables grossSales and commissionRate are private, other classes cannot directly access these values. Declaring instance variables as private and providing public properties to mandate and validate them helps enforce good software engineering.
