
# Chapter 14 Graphical User Interfaces with Windows Forms: Part I

## Look-and-Feel Observation 14.3

You can organize a GUI by anchoring and docking controls inside a GroupBox or Panel. The GroupBox or Panel can be anchored or docked inside a Form. This divides controls into 'groups' that can be arranged easily.

To create a GroupBox, drag it from the Toolbox onto a Form. Then, drag new controls from the Toolbox into the GroupBox. These controls are added to the GroupBox's Controls property and become part of the GroupBox. The GroupBox's Text property identifies the caption to that of the GroupBox.

To create a Panel, drag it from the Toolbox onto Form. You can add controls directly to the Panel by dragging them from the Toolbox onto the Panel. To enable scrollbars, set the Panel's AutoScroll property to true. If the Panel is resized and cannot display all of its controls, scrollbars appear (Fig. 14.23). The scrollbars are used to view all the controls in the Panel—at design time and at execution time. In Fig. 14.23, we set the Panel's BorderStyle property to FixedSingle so that you can see the Panel in the Form.

## 14.7 CheckBoxes and RadioButtons

C# has two types of state buttons that can be in the on/off or true/false states—CheckBoxs and RadioButtons. Like Button, classes CheckBox and RadioButton are derived from class ControlBase.

### 14.7.1 CheckBoxes

A CheckBox is a small square that is either blank or contains a check mark. When the user clicks a Check to select it, a check mark appears in the box. If the user clicks Check to deselect it, the check mark is removed. You can configure a CheckBox to toggle between three states (*checked*, *unchecked*, and *indeterminate*) by setting its Three-State property to true. Any number of CheckBoxes can be selected at a time. A list of common CheckBox properties and a common event appear in Fig. 14.25.

| CheckBox properties and an event | Description |
|---|---|
| **Common Properties** | |
| Appearance | By default, the property is set to Normal, and the CheckBox displays as a traditional checkbox. If it's set to Button, the CheckBox displays as a Button that loops when pressed the CheckBox is checked. This property returns a bool value. |
| Checked | Indicates whether the CheckBox is *checked* (contains a check mark) or *unchecked* (blank). The default is *false* (*unchecked*). |
| CheckState | Indicates whether the CheckBox is *checked* or *unchecked* with a value from the CheckState enumeration. |
| Text | Specifies the text. |
| Three-State | When true, the CheckBox has three states—*checked*, *unchecked*, and *indeterminate*. |
| **Common Event** | |
| Changed | Occurs any time the CheckState changes. |
