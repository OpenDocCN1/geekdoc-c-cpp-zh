In this section, we introduce regular expressions—specifically formatted strings to find patterns in text. They can be used to ensure that data is in a particular format. For example, a U.S. zip code must consist of five digits, or five followed by a dash and four digits. Compilers use regular expressions to validate syntax. If the program code does not match the regular expression, the compiler indicates there is a syntax error. We discuss Regex and Match from the System.Text.RegularExpressions namespace as the symbols used to form regular expressions. We then demonstrate how to find patterns in a string, match entire strings, replace characters in a string that match a pattern and split strings at delimiters specified in a regular expression.
