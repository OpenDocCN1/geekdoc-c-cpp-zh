# Organizing Book Titles by Author

Most queries return data arranged in a relational-style table of rows and columns. The last query (Fig. 22.33, lines 55–62) returns hierarchical results. Each element in the results contains the name of an Author and a list of Titles that the author wrote. The LINQ query does this using a nested query in the select clause. The outer query iterates over the authors in the database. The inner query takes a specific author and retrieves all titles that the author wrote. The select clause (lines 58–62) creates an anonymous type with two properties:

+   - The Property Name (line 58) is initialized with a string that separates the author's first and names by a space.
- The Property Titles (lines 59–62) is initialized with the result of the nested query, which returns the title of each book by the current author.

In this case, we're providing names for each property in the new anonymous type. When you create an anonymous type, you can specify the name for each property by using the format name = value.

**Fig. 22.33** | Getting a list of titles grouped by authors.

The range variable book in the nested query iterates over the current author's books using the Titles property. The Title1 of a given book returns the Title column from that row of the Titles table in the database.
