8.31 | Simpleton Machine Language (SML) operation codes.

Arithmetic instructions leave their results in the accumulator. The store instruction, +2109, places the result in memory location 09, from the write instruction, +109, takes the number and displays it (as a signed four-digit number). The halt instruction, +430, terminates execution.

The second SML program (Fig. 8.33) reads two numbers from the keyboard and determines and displays the larger value. Note the use of instruction +4107 as a conditional transfer of control, which is like C#'s if statement.

Now write SML programs to accomplish each of the following tasks:

- a) Use a sentinel-controlled loop to read positive numbers and compute and display the result. Terminate when a negative number is entered.
- b) Use a counter-controlled loop to read seven numbers, some positive and some negative, then compute and display their average.
- c) Read a series of numbers, then determine and display the largest number. The first number index indicates how many numbers should be processed.
