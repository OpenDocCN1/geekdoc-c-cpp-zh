So, now that you have code that publishes events (Listing 4.1), let’s take a look at some code that consumes events. In this case we’ll write a barely functional stub of a game engine. Listing 4.2 shows the implementation of this game engine class and the implementations of the methods that are called in response to the various combatant events.
