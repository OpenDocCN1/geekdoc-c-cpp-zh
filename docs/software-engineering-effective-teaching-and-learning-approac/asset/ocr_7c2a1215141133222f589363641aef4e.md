Overall, the issue of using the capstone course to measure attainment of program outcomes is in the *Works* category, although the danger exists for the capstone course to be saddled with gathering too many such measurements as we discuss in the following section.

As can be seen in Table 3, many program outcomes can be measured by capstone courses structured like CSE293. An unintended consequence of such a versatile (from an assessment perspective) course can be an undue burdening of the instructors teaching the course with the collection of a great deal of assessment data.
