+   8. Save the configuration.
+   9. Power off the router.
+   10. Install the router in the production location and power it on.

At this point, you have configured and installed the router, and it should be
performing as configured for your network. You'll want to test the network and
ensure that this is correct. Can you reach the network on the other side of the router
from each side? Can only the nodes that should be able to pass through the router
indeed do so? These and other factors should be verified.
