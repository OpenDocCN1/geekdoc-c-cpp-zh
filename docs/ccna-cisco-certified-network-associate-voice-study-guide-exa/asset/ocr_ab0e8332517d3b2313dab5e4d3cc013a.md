**exam Watch** If you are asked how to get more conference calls out of existing DSP resources, one key is to lower the codec complexity. You cannot lower the codec complexity while a profile is active on a voice card. First, shut down the profile, and then lower the codec complexity with the codec complexity command while in the voicecard configuration mode.
