# Accounting

The term accounting is used to reference any method or system that provides recordkeeping and activity tracking. In network security, an accounting system at its most basic level is a logging system that logs the activity occurring on the network. Authentication gets you onto the network. Authorization gets you onto things on the network. Accounting keeps a record. Accounting is important for incident response, and it is also important as a tool for baseline analysis and anomaly detection. Advanced accounting systems are called intrusion detection systems or intrusion prevention systems.
