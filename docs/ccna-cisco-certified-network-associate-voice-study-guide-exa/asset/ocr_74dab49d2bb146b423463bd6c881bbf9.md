# LAB ANSWER

Answers may vary, but in most networks cRTP would be used only on the WAN links. The reason for this decision is simple: while cRTP allows for more efficient network utilization, it adds processor overhead in the routers. On low-bandwidth WAN links the tradeoff is worth it. On fast connections such as 100 Mbps or 1 Gbps it’s usually not worth the processor cost.
