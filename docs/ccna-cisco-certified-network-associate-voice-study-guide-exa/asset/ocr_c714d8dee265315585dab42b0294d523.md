# 640-460: Configure Switched Infrastructure to Support Voice and Data VLANs

+   - The IOS vlan command is used to create VLANs from within configure mode on Cisco switches.
+   - The name command is used from the configure vlan mode to provide a VLAN name.
+   - Ports are assigned to VLANs with the switchport command.
+   - The show vlan brief command can be used from enable mode to view the current VLAN database on a switch.
