> > The ISO standard for the OSI model does not mention a Layer 8; however, many network administrators and engineers use this term to refer to the user. For example, a Layer 8 problem is a reference to a user mistake.

**Layer 1**   Layer 1 is the Physical layer, and analyzing it would mean evaluation of the LAN client devices or infrastructure devices to ensure that they are working properly at the hardware and possibly driver level. For example, the radio still functioning appropriately in a wireless NIC or not? With client devices, this can be tested quickly by removing the wireless LAN client device (assuming it's a USB, CardBus, or another kind of removable device) and installing it in another computer that is using the same model device and is working. If the new computer stops working too, the wireless LAN device is most likely at fault at the hardware level or the internal software level (firmware). If it is the wireless AP that is suspected and you have a spare, you could load the identical configuration on the spare, and place it in the same location to see if the problem persists.
