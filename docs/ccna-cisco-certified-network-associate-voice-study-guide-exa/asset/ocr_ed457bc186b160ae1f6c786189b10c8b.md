# IP-to-IP Gateway Functionality

The Cisco UBE functionality can be summarized as follows: The UBE acts as a VoIP gateway in the same basic way as a PSTN-to-IP gateway. In other words, the UBE joins two IP-based VoIP call legs instead of a PSTN and IP call leg. Cisco UBE can connect any of these combinations of IP voice networks:

+   - H.323-to-H.323
+   - H.323-to-SIP
+   - SIP-to-SIP
