# On the Job

> One of my favorite Cisco routers is the 2801 ISR. This router can be used for just about any learning you need to do with modern Cisco exams. You can implement security features, voice features, the Security Device Manager, Call Manager Express, and much more with this entry-level 2800 series device. It has four expansion slots, support for onboard PVDM modules, Compact Flash-based memory (for IOS storage), and two built-in Fast Ethernet ports.

+   - Acting as an H.323 gatekeeper
