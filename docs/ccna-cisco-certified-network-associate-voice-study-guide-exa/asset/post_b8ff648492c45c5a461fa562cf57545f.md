
- SIP headers use fields and values in ASCII text encoding.
- Several fields are required in a standard SIP implementation, including TO, FROM, CSEQ, CALL-ID, MAX-FORWARDS, and VIA.
- SIP methods include INVITE, BYE, CANCEL, ACK, REGISTER, OPTIONS, and INFO.
- SIP responses are categorized as informational (1xx), successful (2xx), redirection (3xx), failure (4xx), server failure (5xx), and global failure (6xx).
- Once a SIP call is established, the RTP/RTCP communications occur directly between the peers regardless of whether a proxy server is used.

## LAB ANSWER

The URI is likely to look something like the following:

```
SIPS://JoeThomas@xyznabc.net
```

The SIPS portion identifies the protocol as secure SIP rather than standard SIP, which uses no encryption or authentication. The JoeThomas portion identifies the user. The @xyznabc.net portion identifies the domain.
