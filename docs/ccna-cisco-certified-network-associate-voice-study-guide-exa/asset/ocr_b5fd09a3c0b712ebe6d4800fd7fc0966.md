# Verifying Dial Plan Implementations

Cisco provides the show voice port summary command to view voice ports. This command can be used to view signaling types, channels, and the states of the configured T1 or ISDN lines connected to your Cisco gateway.

Using the show dial-peer voice summary command, you can view a listing of all dial peers. To see the details of a dial peer, use the show dial-peer voice tag command, where tag is the number associated with the dial peer. Consider the following show dial-peer voice summary output:

```
```text
Router1# show dial-peer voice summary
dial-peer hunt 0

                                                   PASS
TAG  TYPE  ADMIN  OPER  PREFIX  DEST-PATTERN  PREF  THRU  SESS-TARGET
110  pots  up     up    0       0
111  voip  up     up    5550112 0             syst  ipv4:10.10.1.1
112  voip  up     up    5550134 0             syst  ipv4:10.10.1.1
95   voip  up     down  0       0             syst
30   pots  up     down  0       0
```
```

The show gateway command is used to view the current status of the gateway. The results of the show gateway command will differ depending on whether the gateway is registered with a gatekeeper. If it’s registered with a gatekeeper, output similar to the following will be displayed:

```
```text
Router1# show gateway
Gateway gateway2 is registered to Gatekeeper gk2
Gateway alias list
H323-ID gateway2
H323 resource thresholding is Enabled and Active
H323 resource threshold values:
    DSP: Low threshold 60, High threshold 70
    DSO: Low threshold 60, High threshold 70
```
```

When the gateway is not registered with a gatekeeper, output similar to the following will be displayed:

```
```text
Router2# show gateway
Gateway gateway1 is not registered to any gatekeeper
Gateway alias list
H323-ID gateway1
H323 resource thresholding is Enabled but NOT Active
H323 resource threshold values:
    DSP: Low threshold 60, High threshold 70
    DSO: Low threshold 60, High threshold 70
```
