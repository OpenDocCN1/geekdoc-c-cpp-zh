# Accessing Instance Variables and Data Encapsulation

You've seen how the methods that deal with fractions can access the two instance variables numerator and denominator directly by name. In fact, an instance method can always access its instance variables. A class method can't, however, because it's dealing only with the class itself, not with any instances of the class (think about a second). But what if you wanted to access your instance variables from somewhere else—for example, from inside your main routine? You can't directly access them because they are hidden. The fact that they are hidden is a key concept called data encapsulation. It enables writing encapsulation provides a new layer of insulation between the programmer and the class developer.

You can access your instance variables in a clean way by writing special methods to set and retrieve their values. We wrote setNumerator: and setDenominator: methods to set the values of the two instance variables in our Fraction class. To retrieve the values of those instance variables, you'll need to write two new methods. For example, you'll create two new methods called, appropriately enough, numerator and denominator to access the corresponding instance variables of the Fraction that is the receiver of the message. The result is the corresponding integer value, which you return. Here are the declarations for your two new methods:

+   - (int) numerator;
- (int) denominator;
