You might have realized from this program that you could have readily accomplished the task using a for statement. In fact, a for statement can always be translated into an equivalent while statement, and vice versa. For example, the general for statement

```
for ( init_expression; loop_condition; loop_expression )
    program statement
```

can be expressed in the form of a while statement, like so:

```
init_expression;
while ( loop_condition )
{
    program statement
    loop_expression;
}
```

When you become familiar with the use of the while statement, you will gain a better feel for when it becomes more logical to use a while statement and when you use a for statement. In general, a loop executed a predetermined number of times is a prime candidate for implementation as a for statement. Also, if the initial expression, looping expression, and looping all involve the same variable, the for statement is probably right choice.

The greatest common divisor (we abbreviate it as gcd) of two integers is the largest integer value that evenly divides the two integers. For example, the gcd of 10 and 15 is 5 because it is the largest integer that evenly divides both 10 and 15.

A procedure, or algorithm, that can be followed to arrive at the gcd of two arbitrary integers is based on a procedure originally developed by Euclid around 300 B.C. It can be stated as follows:

# The while Statement

Problem: Find the greatest common divisor of two nonnegative integers u and v.

Step 1: If v equals 0, then we are done and the gcd is equal to u.

Step 2: Calculate temp = u % v, u = v, v = temp and go back to step 1.

Don't concern yourself with the details of how the previous algorithm works—simply take it on faith. We are more concerned here with developing a program to find the greatest common divisor than performing an analysis of the algorithm works.

After expressing the solution to the problem of finding the greatest common divisor in terms of an algorithm, developing the computer program becomes a much simpler task. An analysis of the algorithm reveals that step 2 is repeatedly executed as long as the value of v is not equal to 0. This realization leads to the natural implementation of this algorithm in Objective-C with the use of a while statement.

Program 5.7 finds the gcd of two nonnegative integers used by the user.

```
// Find the greatest common divisor of two nonnegative integers
#import <Foundation/Foundation.h>

int main (int argc, char *argv[]) {
    NSAutoreleasePool pool = [[NSAutoreleasePool alloc] init];
    unsigned int u, v, temp;

    NSLog(@"Please type in two nonnegative integers.");
    scanf("%u %u", &u, &v);

    while (v != 0) {
        temp = u % v;
        u = v;
        v = temp;
    }

    NSLog(@@"Your greatest common divisor is %u", u);
    [pool drain];

    return 0;
}
```

# The do Statement

The two looping constructs discussed so far in this chapter test the conditions before the loop is executed. Therefore, the body of the loop might never be executed if the conditions are not satisfied. When developing programs, you sometimes want to have the test made at the end of the loop instead of the beginning. Naturally, the Objective-C language provides a special language construct to handle such a situation, known as the do statement. The syntax of this is as follows:

```
do
    program statement
while ( expression );
```

Execution of the do statement proceeds as follows: program statement is executed first. Next, the expression inside the parentheses is evaluated. If the result of evaluating expression is true, the loop continues and program statement is again executed. As long as the evaluation of expression continues to be true, program statement is repeatedly executed. When the evaluation of expression proves false, the loop is terminated and the next statement in the program is executed in the normal sequential manner.

The do statement is simply a transposition of the while statement, with the looping conditions placed at the end of the loop instead of the beginning. Back to that program and try to determine what would happen if the user had typed the number 0 instead of 1379. The loop of the while statement would have never been executed, and nothing would have been displayed for output. If you were to use a do statement of a while statement, you would be assured that the program loop would be executed at least once, guaranteeing the display of at least one digit in all cases.
