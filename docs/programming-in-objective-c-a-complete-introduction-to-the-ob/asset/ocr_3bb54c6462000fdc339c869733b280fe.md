Here's what the @interface directive should look like:

```
@interface Fraction : NSObject <NSCopying>
```

Fraction is a subclass of NSObject and conforms to the NSCopying protocol.
In the implementation file Fraction.m, add the following definition for your new method:

```
- (id) copyWithZone:(NSObject *) zone {
    Fraction *newFract = [[Fraction alloc] initWithZone:zone];

    [newFract setTo:numerator denominator:denominator];
    return newFract;
}
```

The zone argument has do with different memory zones that you can allocate and work in your program. You need to deal with these only if you are writing applications that allocate memory by grouping them into zones. You can take the value passed to copyWithZone: and hand it off to a memory allocation method called allocWithZone:. This method allocates memory in a specified zone.

After allocating a new Fraction object, you copy the receiver's numerator and denominator variables into it. The copyWithZone: method is supposed to return the new copy of the object, which you do in your method.
