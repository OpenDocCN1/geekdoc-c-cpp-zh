The triangular number is calculated by simply adding the value of n to the previous triangular number. The values of n and triangularNumber are then displayed, with appropriate blank spaces inserted into the format string to ensure that the values of the two variables line under the appropriate column headings.

Because the body of the loop has been executed, the loop expression is evaluated. The expression in for statement appears a bit strange, however Surely you must have made a typographical mistake and meant to insert n = n+1 instead of this funny-looking expression:

```
++n
```

But ++n is actually a perfectly valid Objective-C expression. It introduces a new (and unique) operator in the Objective-C programming language: the increment operator. The function of the double plus, or the increment operator, is to add 1 to its operand.Addition by 1 is such a common operation in programs that a special operator was created for this purpose.Therefore, the expression ++n is equivalent to the expression n = n+1. At first glance, it might appear that n = n+1 is more readable, but you will get used to the function of this operator and learn to appreciate its succinctness.

Of course, no programming language that offers an increment operator to add 1 would be complete without a corresponding operator to subtract 1.As you would guess, the name of this operator is the decrement operator, and it is symbolized by the double minus sign. So an expression in Objective-C reads

```
bean_counter = bean_counter - 1
```

can be equivalently expressed using the decrement operator, like so:

```
--bean_counter
```
