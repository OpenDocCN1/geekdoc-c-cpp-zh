# Using Xcode

Xcode is a sophisticated application that enables you to easily type in, compile, debug, and execute programs. If you plan on doing serious application development on the Mac, learning how to use this powerful tool is worthwhile. We just got you started. Later we return to Xcode and take you through the steps involved in developing a graphical application with it.

> Note
As mentioned, Xcode is a sophisticated tool, and the introduction of Xcode 4 added even more features. It's easy to get lost using this tool. If it happens to you, back up a little and try reading the Xcode User Guide, which can be accessed from Xcode's help menu, to get your bearings.

Xcode is located in the Developer folder inside a subfolder called Applications. Figure 2.1 shows its icon.

Figure 2.1 Xcode icon

Start Xcode. You can select "Create a Xcode Project" from the startup screen. Alternatively, under the File menu, select New, New, Project... (see Figure 2.2). A window appears, as shown in Figure 2.3.

In the left pane you will see a section labeled Mac OS X. Select Application. In the upper-right pane, select Command Line Tool, as depicted in the previous figure. On the next pane that appears, pick your application's name. Enter prog1 for the Product Name and make Foundation is selected for the Type. Your screen should look like like Figure 2.4.

Click Next. The dropdown that appears allows you to specify the name of the project folder that will contain the files related to your project. Here you can also specify where you want that project folder stored. According to Figure 2.5 we're going to store our project on the Desktop in a folder called prog1.
