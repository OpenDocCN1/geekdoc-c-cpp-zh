You might want to also look at the Foundation function NSSearchForDirectoriesInDomains, which you can use to locate special directories on the system or on your device, as the Application and Documents directories. For example, the following defines a method called saveFilePath that returns a path to a file saveFile in the CachesDirectory.You could use a method like this if you wanted to save some data from your application into a file.

```
(NSString *) saveFilePath{
Array *dirList = NSSearchForDirectoriesInDomains
(CachesDirectory, NSUserDomainMask, YES);
NSString *docDir = [dirList objectAtIndex: 0];

[docDir stringByAppendingPathComponent:@"saveFile"];
}
```
