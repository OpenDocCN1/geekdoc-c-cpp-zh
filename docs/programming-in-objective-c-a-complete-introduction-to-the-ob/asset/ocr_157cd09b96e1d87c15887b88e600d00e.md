# Chapter 4 Data Types and Expressions

To display the value of a long int using NSLog, the letter l is used as a modifier the integer format characters. This means that the format characters %li can be used to display the value of a long int in decimal format.

You also have a long int variable, or even a long double variable with greater range.

The qualifier short, when placed in front of the int declaration, tells the Objective-C compiler that the particular variable being declared is to store fairly small integer values. The motivation for using short variables is primarily one of conserving memory space, which can be an issue when the program needs a lot of memory and the amount of available memory is limited.

The final qualifier that can be placed in front of an int variable is used when integer variable will be to store only positive numbers. The following declares to the compiler that the variable counter is used to contain only positive values:

```
unsigned int counter;
```

Restricting the use of an int variable to the exclusive storage of positive integers extends the range of the integer variable.

# Type id

The id data is used to store an object of any type. In a sense, it is a generic object type. For example, this line declares graphicObject to be a variable of type id:

```
id graphicObject;
```

Methods can be declared to return values of type id, like so:

```
- (id) newObject:(int) type;
```

This declares an instance method called setObject that takes a single integer argument called type and returns a value of type id. The id data type is an important data type used often in this book. We mention it in here for the sake of completeness. The id type is the basis for very important features in Objective-C known as polymorphism and dynamic binding, tells Chapter 9, "Polymorphism, Dynamic Typing, and Dynamic Binding," discusses extensively.
