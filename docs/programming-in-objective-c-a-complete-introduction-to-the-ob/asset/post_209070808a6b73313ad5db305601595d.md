# Accessing Instance Variables and Data Encapsulation

You've seen how the methods that deal with fractions can access the two instance variables numerator and denominator directly by name. In fact, an instance method can always access its instance variables. A class method can't, however, because it's dealing only with the class itself, not with any instances of the class (think about a second). But what if you wanted to access your instance variables from somewhere else—for example, from inside your main routine? You can't directly access them because they are hidden. The fact that they are hidden is a key concept called data encapsulation. It enables writing encapsulation provides a new layer of insulation between the programmer and the class developer.

You can access your instance variables in a clean way by writing special methods to set and retrieve their values. We wrote setNumerator: and setDenominator: methods to set the values of the two instance variables in our Fraction class. To retrieve the values of those instance variables, you'll need to write two new methods. For example, you'll create two new methods called, appropriately enough, numerator and denominator to access the corresponding instance variables of the Fraction that is the receiver of the message. The result is the corresponding integer value, which you return. Here are the declarations for your two new methods:

- (int) numerator;
- (int) denominator;

And here are the definitions:

# Program 3.4

```objc
// Program to access instance variables - cont'd
#import <Foundation/Foundation.h>
//---interface section ---
@interface Fraction : NSObject
{
int numerator;
int denominator;
}
-(void) print;
-(void) setNumerator:(int) n;
-(void) setDenominator:(int) d;
-(int) numerator;
-(int) denominator;
@end
//---implementation section ---
@implementation Fraction
-(void) print
{
NSLog("@%i/%i", numerator, denominator);
}
-(void) setNumerator:(int) n
{
numerator = n;
}
-(void) setDenominator:(int) d
{
denominator = d;
}
-(int) numerator
{
return numerator;
}
```

    [myFraction release];
    pool drain;

    return 0;
}

# Program 3.4 Output

The value of myFraction is 1/3

This NSLog statement displays results of sending two messages to myFraction: the first to retrieve the value of its numerator, and the second the value of its denominator.
NSLog("@The value of myFraction is: %i/%i",
[myFraction numerator], [myFraction denominator]);

So, in the first call, the numerator will be sent to the Fraction object myFraction. In that method, the code will return the value of the numerator instance variable for fraction. Remember, the context of a method when it is executing is the object that is the receiver of the method. When the numerator method accesses and returns the value of the numerator instance variable, it's myFraction's numerator that will be accessed and returned. That returned integer value is passed along to NSLog to be displayed.

For the second call, the denominator will be called to access and return the value of myFraction's denominator, which is then passed to NSLog to be displayed.

Methods that set the value of instance variables are often collectively referred to as setters, and methods used to retrieve the values of instance variables are called getters. For the Fraction class, setNumerator and setDenominator are the setters, and numerator and denominator are the getters. Collectively, setters and getters are also referred to as accessor methods.
