# Program 5.8

// Program to reverse the digits of a number
#import <Foundation/Foundation.h>

```
int main (int argc, char *argv[]) {
    NSAutoreleasePool * pool = [[NSAutoreleasePool alloc] init];
    int number, right_digit;

    NSLog("@iEnter your number.");
    canf("%i", &number);

    while ( number != 0 ) {
        right_digit = number % 10;
        NSLog("@i", right_digit);
        number /= 10;
    }

    [pool drain];
    return 0;
}
```

# The do Statement

The two looping constructs discussed thus far in this chapter test the conditions before the loop is executed. Therefore, the body of the loop might never be executed if the conditions are not satisfied. When developing programs, you sometimes want to have the test made at the end of the loop instead of the beginning. Naturally, the Objective-C language provides a special language construct to handle such a situation, known as the do statement. The syntax of this is as follows:

```
do
    program statement
while ( expression );
```
