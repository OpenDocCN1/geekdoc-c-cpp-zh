Let's go back to the NSString function from Program 13.16 and rewrite it to incorporate

Because the to and from pointers are incremented each time after the assignment
statement inside the for loop is executed, they should be incorporated into the assignment\statement as post-increment operations. The revised loop for Program 13.16
then it becomes:

```
for ( ; *from != '\0';
*to = *from++;
```

Execution of the assignment statement inside the loop would proceed as follows.
The character that from points would be retrieved, and then would be incremented to
tnext point in the source string. The referenced character would be stored
inside the location that to points to; then to would be incremented to point to the next
location in the destination string.

The previous statement hardly seems worthwhile it has no initial expression\and no looping expression. In fact, the logic would be better served when expressed
in the form of a while loop. This has been done in Program 13.17, which presents the
new version of the NSString function. The while loop uses the fact that the null character is equal to the value 0, as experienced Objective-C programmers commonly.

    }
