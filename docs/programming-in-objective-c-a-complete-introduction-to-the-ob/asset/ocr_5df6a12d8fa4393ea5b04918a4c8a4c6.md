For this second program example, you'll start by creating a new project. This time, selectView-based Application from the New window. Call your new project Fraction_Calculator.

When your project is created, this time you'll notice you get two class templates defined for you. Fraction_CalculatorAppDelegate.h and Fraction_CalculatorAppDelegate.m define the application's controller class for your project, while Fraction_ViewController.h and Fraction_ViewController.m define the view class for your project. As noted, it's in this class where you'll perform all your work.

We'll start first with the application controller class. It contains two instance variables: one for referencing the iPhone's window and another for the view controller.These have both been set up for by Xcode. In fact, there are no changes you need to make to either the application controller's .h or .m files.

The Fraction_CalculatorAppDelegate interface file is shown in Program 21.2.
