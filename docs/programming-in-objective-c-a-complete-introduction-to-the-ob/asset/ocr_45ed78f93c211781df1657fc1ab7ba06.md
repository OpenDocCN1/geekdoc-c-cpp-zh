You can use the compare: method to test whether one numeric value is numerically less than, to or greater than another. The message expression

```
[intNumber compare:myNumber]
```

returns the value NSOrderedAscending if the numeric value stored in intNumber is less than the numeric value contained in my, returns the value NSOrderedSame if the first number is greater than the second. These values are defined in the header file NSObject.h,

Just to sure you understand the difference in using numberWithInt: versus numberWithInteger:, just follow these rules:

+   1. If you create an integer using numberWithInt: you should retrieve its value using intValue, and can display your value using %i as the format characters.

+   2. If you create an integer using numberWithInteger: you should retrieve its value using integerValue, and you should cast it to a long if it's displayed or used to a string with a method like stringWith:. The format characters to use would be %li in such cases.
