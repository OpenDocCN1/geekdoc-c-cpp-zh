Program 13.7 is Program 13.4 rewritten to use a block instead of a function. A block can be defined globally or locally. In this case, we'll define our block outside of main, making it external and global in scope.

# Program 13.7

```
#import <Foundation/Foundation.h>
// Block to calculate the nth triangular number
void (*calculateTriangularNumber) (int) =
    (int n) {
        int i, triangularNumber = 0;
        for (i = 1; i <= n; ++i) {
            triangularNumber += i;
        }
        NSLog("Triangular number %i is %i", n, triangularNumber);
    }
 main(int argc, char *argv[]) {
    NSAutoreleasePool *pool = [NSAutoreleasePool alloc init];

    calculateTriangularNumber(10);
    calculateTriangularNumber(20);
    calculateTriangularNumber(50);

    [pool drain];
    return 0;
}
```
