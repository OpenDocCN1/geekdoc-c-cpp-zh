# Arithmetic Expressions

The expression in this NSLog call of Program 4.3 reinforces the notion of operator precedence. Evaluation of this expression proceeds as follows:

+   1. Because division has higher precedence than addition, the value of a (25) is divided by 5 first. This gives the intermediate result of 5.

+   2. Because multiplication also has higher precedence than addition, the intermediate result of 5 is next multiplied by 2, the value of b, giving a new intermediate result of 10.

+   3. Finally, the addition of 6 and 10 is performed, giving a final result of 16.

The second NSLog statement introduces a new twist. You would expect dividing a by b and multiplying it by the value of a, which has been set to 25. But this does not seem to be the case, as shown by the output display of 24. Did the computer lose a bit along the way? Very unlikely. The fact of the matter is that this expression was evaluated using integer arithmetic.

If you glance back at the declarations for the variables a and b, you will recall that both were declared to be of type int. The Objective-C system performs the operation using integer arithmetic. In a case like this, consisting of two integers, all decimal portions of numbers are lost. Therefore, when the value of a is divided by the value of b, or 25 is divided by 2, you get an intermediate result of 12, and not 12.5, as you might expect. Multiplying this intermediate result by 2 gives the final result of 24, explaining the "lost" digit.

As you can see from the next-to-last NSLog statement in Program 4.3, if you perform the same operation using floating-point values instead of integers, you obtain the expected result.

The decision of whether to use a float or an int variable should be made based on the variable's intended use. If you don't need decimal places, use an integer variable. The resulting program will be more efficient—that is, it will execute quickly on many computers. On the other hand, the only question you must answer is whether to use a float or a double. The choice depends on the desired accuracy of the numbers you are dealing with, as well as their magnitude.

In the last NSLog statement, the value of a is negated by the use of the minus operator. A unary operator is one that operates on a single value, as opposed to a binary operator, which operates on two values. The minus actually has a dual role: As a binary operator, it is used for subtracting two values; as a unary operator, it is used to negate a value.

The unary minus operator has higher precedence than all arithmetic operators, except for the unary operator (+), which has the same precedence. So the following expression results in the multiplication of -a by b:

```
c = -a * b;
```
