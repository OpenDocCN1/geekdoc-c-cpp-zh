
## Chapter 16 Working with Files

You can get the filenames from the command line using the arg and argv arguments to main. These two arguments are populated, respectively, with the number of arguments on the command line (including the command name), and a pointer to an array of C-style character strings.

Instead of dealing with C strings, which is what you have to do when working with argv, use a Foundation class called NSProcessInfo. NSProcessInfo contains methods that allow you to set and retrieve various types of information about your running application (that is, your process). These methods are summarized in Table 16.6.

## Table 16.6 NSProcessInfo Methods

| Method | Description |
| --- | --- |
| + (NSProcessInfo *) processInfo | Returns information about the current process |
| - (NSArray *) arguments | Returns the arguments to the current process as an NSString objects |
| - (NSDictionary *) environment | Returns a dictionary of variable/value pairs representing the current environment variables (such as PATH and HOME) and their values |
| - (int) processIdentifier | Returns the process identifier, which is a unique number assigned by the operating system to identify each running process |
| - (NSString *) processName | Returns the name of the current executing process |
| - (NSString *) globallyUniqueString | Returns a unique string each time it is invoked. This could be used for generating unique temporary files (see Exercise 5) |
| - (NSString *) hostName | Returns the name of the host system (returns Steve-Cochran-Computer.local on my Mac OS system) |
| (NSInteger) operatingSystem | Returns a number indicating the operating system (returns value 5 on my Mac) |
| - (NSString *) operatingSystem | Returns the name of the operating system (returns the constant NSMachOperatingSystem on my Mac, where the possible return values are defined in NSProcessInfo.h) |
| - (NSString *) operatingSystemVersionString | Returns the current version of the operating system (returns Version 10.6.7 (Build J0869) on my Mac OS X) |
| (void) setProcessName:(NSString *) name | Sets the name of the current process to name. Should be used with caution because some assumptions can be made about the name of your process (for example, by the user default settings) |

## Program 16.6

```
// Implement a basic copy utility
#import <Foundation/Foundation.h>

int main (int argc, char *argv[]) {
    NSAutoreleasePool *pool = [NSAutoreleasePool alloc];
    NSFileManager *fm = [[NSFileManager alloc] init];
    NSString *source, *dest, *isDir;
    NSProcessInfo *proc = [NSProcessInfo processInfo];
    NSArray *args = [proc arguments];

    fm = [NSFileManager defaultManager];

    // Check for two arguments on the command line
    if ([argc] != 3) {
        NSLog("Usage: %s src %s", [proc processName]);
        return 1;
    }

    NSString *source = [args objectAtIndex: 1];
    NSString *dest = [args objectAtIndex: 2];

    // Make sure the source file can be read
    if ([fm isReadableFileAtPath:source] == NO) {
        NSLog("Can't read %@", source);
        return 2;
    }

    // See if the destination file is a directory
    // if it is, add the source to the end of the destination
    if ([isDir isDir == YES) {
        dest = [dest stringByByAppendingPathComponent:[source lastPathComponent]];
    }

    // Remove destination file if it already exists
    [fm removeItemAtPath:dest error:NULL];

    // Okay, time to perform the copy
    if ([fm copyItemAtPath:source toPath:dest error:NULL] == NO) {
        NSLog("Copy failed: %@");
        return 3;
    }

    NSLog("Copy of %@ to %@ succeeded!", source, dest);

    [pool drain];
    return 0;
}
```

## Note

The output will differ on your system based on the files you have stored in your directory when you run this program.

ProcessInfo's arguments method returns an array of string objects. The first element is the name of the process, and the remaining elements contain the arguments on the command line.

You first check to ensure that two arguments were typed on the command line. This is done by testing the size of the args array that is returned from the arguments method. If this succeeds, the program then extracts the source and destination filenames from the args array, assigning their values to source and dest, respectively.

The program next checks to ensure the source file can be read, issuing an error message if it can't.

The statement

```
[if fileExistsPath: dest isDirectory: &isDir];
```

checks the file specified by dest to see whether it is a directory. As you've seen previously, the answer—YES or NO—is stored in the variable isDir.

If dest is a directory, you want to append the last path component of the source filename to the end of the directory.
