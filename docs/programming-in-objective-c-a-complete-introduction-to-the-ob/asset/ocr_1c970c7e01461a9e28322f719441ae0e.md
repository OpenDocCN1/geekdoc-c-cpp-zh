# Chapter 8 Inheritance

```
// ClassA declaration and definition

@interface ClassA: NSObject
{
    int x;
}

-(void) initVar;
@end
```

Notice that no printVar method is declared. That method is declared and defined in ClassB.Therefore, even though ClassB objects and their descendants can use this method through inheritance, ClassA objects cannot because the method is defined further down in the hierarchy.

> Note
You can coerce the use of this method in some ways, but we don't go into that here—besides, it's not good programming practice.

Returning to our example, let's add a printVar method to ClassA so you can display the value of its instance variable:

```
// ClassA declaration and definition

@interface ClassA: NSObject
{
    int x;
}

-(void) initVar;
-(void) printVar;
@end

@implementation ClassA
-(void) initVar
{
    x 100;
}

-(void) printVar
{
    NSLog("@"x %@",", x);
}
@end
```
