# property list

**property list** A representation of different types of objects in a standardized format. Property lists are typically stored in XML format.

**statement** One or more expressions terminated by a semicolon.

**protocol** A list of methods that a class must implement to or adapt to the protocol. Protocols provide a way to standardize an interface across classes. See also formal protocol and informal protocol.

**statement block** One or more statements enclosed in a set of curly braces. Local variables can be declared within a statement block, and their scope is limited to that block.

**receiver** The object which a message is sent. The receiver can be referred to as *self* inside the method that it is invoked.

**static function** A function declared with the `static` keyword that can be called only by other functions or methods in the same source file.

**retain count** See retain count.

**static typing** Explicitly identifying the class to an object belongs at compile time. Also dynamic typing.

**retain count** A count of the times an object is referenced. It is incremented by sending a *retain* message to the object, and it is decremented by sending a *release* message to it.

**static variable** A variable whose scope is limited to the block or module it is defined. Static variables have default initial values of 0 and retain their value through method or function invocations.

**root object** The topmost object in the inheritance hierarchy that has no parent.

**structure** An aggregate data type that can contain members of varying types. Structures can be assigned to other structures, passed as arguments to functions, and returned by them well.

**runtime** The time when a program is executing; also the mechanism responsible for executing a program's instructions.

**subclass** Also known as a *child class*, a subclass inherits the methods and instance variables from its parent or superclass.

**selector** The name used to select the method for an object. Compiled selectors are of type *SEL* and can be generated using the `@selector` directive.

**super** A keyword used in a method to refer to the parent class of the receiver.

**self** A variable used inside a method to refer to the receiver of the message.

**super class** The parent class of a particular class. See *super*.

**set** An unordered collection of unique objects implemented with Foundation with the NSSet, NSMutableSet, and NSCounted classes.

**synthesized** A setter or getter that the compiler automatically creates for you. It was added to the Objective C 2.0 language.

**setter** An accessor method that sets the value of an instance variable. See *getter* method.
