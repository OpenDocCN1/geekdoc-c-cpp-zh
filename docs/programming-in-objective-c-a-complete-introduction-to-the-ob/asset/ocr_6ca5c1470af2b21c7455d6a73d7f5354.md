contains 16 characters. The statement

```
res = [NSString stringWithString:str];
```

shows how to create a new string with the contents of another. The resulting NSString object is assigned to res and is displayed to verify the results. An actual copy of the string contents is made here, not just another reference to the same string in memory.That str and str2 refer to two different objects, which is different from simply performing a simple assignment like this:

```
res = str;
```

As we have previously discussed, this statement would simply create another reference to the same object in memory.

The stringByAppendingString: method can join two string characters. So the expression

```
[str stringByAppendingString:str2];
```

creates a new string object that contains the characters str1 followed by str2, returning the result. The original string objects, str1 and str2, are not affected by this operation (they can't be because both are immutable strings).

The isEqual: method is used in the program to test whether two character strings are equal—that, if they contain the same characters. You can use the compare: method if you need to determine the ordering of two character strings—for example, if you wanted to sort an array of them. Similar to the method you used for comparing NSNumber objects, the result of comparison is NSOrderedAscending if the first string is lexicographically less than the second, NSSame if the two strings are equal, and NSOrderedDescending if the first string is lexicographically greater than the second. If you want to perform a case-sensitive comparison, use the caseInsensitiveCompare method to compare two strings. In a case, the two string objects @"Gregory" and @"gregory" would compare equal with caseinsensitiveCompare.

The uppercaseString and lowercase convert strings to upper case and lower case, respectively. Again, the conversion does not affect the original strings, but the last line of output verifies.

Make sure you understand that str1 and str2 are declared as immutable strings, which means the characters in the string objects they cannot be changed. However, the references, str1 and str2, can be changed. That is, these variables can be reassigned to reference different immutable strings. This is a very important point.
