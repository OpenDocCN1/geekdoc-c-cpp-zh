The writeToFile:atomically: message is sent to your dictionary object glossary, causing the dictionary to be written to the file glossary in the form of a property list. The atomically parameter is set to YES, meaning you want the write operation to be done to a temporary backup file first; once successful, the data is moved to the specified named file glossary. This is a safeguard that protects the file from becoming corrupt, for example, the system crashes in the middle of the write operation. In case, the original glossary file (if it previously existed) isn't harmed.
