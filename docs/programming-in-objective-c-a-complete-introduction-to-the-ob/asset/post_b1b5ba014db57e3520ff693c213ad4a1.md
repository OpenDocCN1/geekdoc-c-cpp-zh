
# Data Types and Expressions

In this chapter, we take a look at the basic data types and describe some fundamental rules for forming arithmetic expressions in Objective-C.

## Data Types and Constants

You have already encountered the Objective-C basic data type int. As you will recall, a variable declared to be of type int can be used to contain integral values only—that is, values that do not contain decimal digits.

The Objective-C programming language provides three other data types: float, double, and char. A variable declared to be of type float can be used for storing floating-point numbers (values containing decimal digits). The double type is the same as type float, typically with twice the range. Finally, the char data type can be used to store a single character, such as the letter a, the digit 6, or a semicolon (more on later).

In Objective-C, any literal number, the number 5 represents a constant value. The string "5" is an example of a constant string. Expressions consisting entirely of constant values are called constant expressions. So expression is a constant because each of the terms is a constant value:

```objective-c
128 + 7
```

But if i were declared to be an integer variable, this expression would not represent a constant:

```objective-c
128 + i
```

### Type int

An integer constant consists of a sequence of one or more digits. A minus sign preceding the sequence indicates that the value is negative. The values 5, -10, and 0 are all valid examples of integer constants. No embedded spaces are permitted between the digits, and (So the value -5 is a valid integer constant.)

Every value, whether it's a character, an integer, or a floating-point number, has a range associated with it. This range has to do with the amount of storage allocated to a particular type of data. In general, that amount is not defined in the language; it typically depends on the computer you're running on. For example, an integer variable might take 32 bits on your computer, or might be stored in 64. If 64 bits were used, then much larger numbers can be stored if 32 bits were used instead. Note OS X gives you the option of compiling as either 32-bit or 64-bit. In the former case, int takes 32 bits; in the latter case, 64 bits are used.

### Type float

You can use a variable declared to be of float to store values containing decimal digits. A floating-point constant is distinguished by the presence of a decimal point. The values 3., 25.8, and .001 are all examples of floating-point constants. To display a floating-point value, NSLog characters %f or %g can be used. Floating-point constants can also be expressed in so-called scientific notation. 1.7e4 is a floating-point value expressed in this notation that represents the value 1.7 x10⁴. As noted, the double type is the same as float, only with twice the range.

### Type char

You use char variable to store a single character. A character constant is formed by enclosing the character within a pair of single quotation. So 'a', '\n'; and '0' are all examples of character constants. The first constant represents the letter a, the second is a semicolon; and the third is the character zero—which is not the same as the number zero. Do not confuse a character constant, which is a single character enclosed in single quotes, with a C-style string, which is any number enclosed in double quotes. As mentioned in the last chapter, a string of characters enclosed in double quotes is an NSString object. The character constant '\n', the newline, is a valid character even though it seems to contradict the rule previously. The reason for this is that the backslash is a special character. In other words, the Objective-C compiler treats the character '\n' as a single character, even though it is actually formed by two characters. Other special characters are initiated with the backslash. The format characters %c can be used in an NSLog call to display the value of a char variable. Program 4.1 uses the basic Objective-C data types.

```objective-c
#import <Foundation/Foundation.h>

int main (int argc, char *argv[])
{
    NSAutleasePool *pool = [[NSAutleasePool alloc] init];

    int integerVar = 100;
    float floatingVar = 31.79;
    double doubleVar = 8.44e+11;
    char charVar = 'W';

    NSLog("%i", integerVar);
    NSLog("%f", floatingVar);
    NSLog("%e", doubleVar);
    NSLog("%g", doubleVar);
    NSLog("%c", charVar);

    [pool drain];
    return 0;
}
```

#### Program 4.1 Output

```
integerVar = 100
floatingVar = 31.790009
doubleVar = 8.440000e+11
doubleVar = 8.44e+11
charVar = W
```

In the second line of the program's output, notice that the value of 31.79, which is assigned to floatingVar, is actually displayed as 31.790009. The reason for this inaccuracy is the particular range in which numbers are internally represented inside the computer. You have probably noticed this inaccuracy when you divide 1 by 3 on your calculator, you get the result .3333333 with some additional 3s tacked on the end. The string of 3s is the calculator's approximation to one third. Theoretically, there should be an infinite number of 3s. But the calculator can only hold so many digits, so the inherent inaccuracy of the machine. The type of inaccuracy applies here: Certain floating-point values cannot be exactly represented inside the computer's memory.

### Qualifiers: long, short, unsigned, and signed

If the qualifier long is placed directly before the int declaration, the declared integer variable is of extended range on some computer systems. An example of a long int declaration might be this:

```objective-c
long int factorial;
```

This declares the variable factorial to be a long integer variable. As floats and doubles, the particular range of a long variable depends on your particular computer system. To display the value of a long int using NSLog, the letter l is used as a modifier the integer format characters. This means that the format characters %li can be used to display the value of a long int in decimal format.

You also have a long int variable, or even a long double variable with greater range.

The qualifier short, when placed in front of the int declaration, tells the Objective-C compiler that the particular variable being declared is to store fairly small integer values. The motivation for using short variables is primarily one of conserving memory space, which can be an issue when the program needs a lot of memory and the amount of available memory is limited.

The final qualifier that can be placed in front of an int variable is used when integer variable will to store only positive numbers. The following declares to the compiler that the variable counter is used to contain only positive values:

```objective-c
unsigned int counter;
```

Restricting the use of an int variable to the exclusive storage of positive integers extends the range of the integer variable.

### Type id

The id data is used to store an object of any type. In a sense, it is a generic object type. For example, this line declares graphicObject to be a variable of type id:

```objective-c
id graphicObject;
```

Methods can be declared to return values of type id, like so:

```objective-c
- (id)newObject:(int)type;
```

This declares an instance method called setObject that takes a single integer argument called type and returns a value of type id. The id data type is an important data type used often in this book. We mention it in here for the sake of completeness. The id type is the basis for very important features in Objective-C known as polymorphism and dynamic binding, tells Chapter 9, "Polymorphism, Dynamic Typing, and Dynamic Binding," discusses extensively.
