# Local Variables

You might have noticed the result of adding 1/4 to 1/2 was displayed as 6/8, not as 3/4, which you might have preferred (or even expected!).That's because your addition routine just the math and no more—it doesn't worry about reducing the result. To continue your exercise of adding new methods to work with fractions, let's make a new reduce method to reduce a fraction to its simplest terms.

Reaching back to your high school math again, you can reduce a fraction by finding the largest number that evenly divides the numerator and the denominator of your fraction and dividing them by that number. Technically, you want to find the greatest common divisor (gcd) of numerator and denominator.You already know how to do that from Program 5.7.You might want to refer to that program example to refresh your memory.

With the algorithm in hand, you can now write your reduce method:

```
(void) reduce
{
    int u = numerator;
    int v = denominator;
    int temp;

    while (v != 0) {
        temp = u % v;
        u = v;
        v = temp;
    }
}
```
