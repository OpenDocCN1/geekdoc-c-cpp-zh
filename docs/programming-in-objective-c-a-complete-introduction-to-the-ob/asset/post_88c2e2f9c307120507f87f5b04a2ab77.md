So I decided neither teach C first nor assume prior knowledge of the language. Instead, I decided to take the unconventional approach of teaching Objective-C and the underlying C language as a single integrated language, from an object-oriented programming perspective. The purpose of this book is as its name implies: it does not teach you how to program in Objective-C 2.0. It does not teach you in detail how to use the development tools that are available for entering debugging programs, or to provide in-depth instructions on how to develop graphical applications. You can learn all that material in detail elsewhere, after you've learned how to write programs in Objective-C. In fact, mastering material will be much easier when you have a solid foundation of programming experience. In fact, if you're a novice programmer, with some dedication and hard work, you should be able to learn Objective-C as your first programming language. Other readers have been successful with this, based on the feedback I've received from previous editions of this book.

This book teaches Objective-C by example. As I present each new feature of the language, I usually provide a small complete example to illustrate the feature. Just as a picture is worth a thousand words, so is a properly chosen example. You are strongly encouraged to run each program (all of which are available online) and compare the results on your system to those shown in the text. By doing so, you will learn the language and its syntax, and you will also become familiar with the process of compiling and running Objective-C programs.

## How This Book Is Organized

This book is divided into three logical parts. Part I, “The Objective-C 2.0 Language,” teaches the essentials of the language. Part II, “The Foundation Framework,” teaches how to use the rich aspect of predefined classes that form the Foundation framework. Part III, “Cocoa, Cocoa Touch, and the iOS SDK,” gives you an overview of the Cocoa and Cocoa Touch frameworks and walks you through developing a simple iOS application using the iOS SDK.

A framework is a set of classes and routines that will be logically grouped together to make developing programs easier. Much of the power of programming in Objective-C rests on the extensive frameworks that are available. Chapter 2, “Programming in Objective-C,” begins teaching you how to write your first program in Objective-C. Because this is not a book on Cocoa or iOS, graphical interfaces (GUIs) are not extensive and are hardly mentioned until Part III. So an approach was needed to get input into a program and produce output. Most of the examples in this text take input from the keyboard and produce output in a Terminal window if you're using the command line, or a debug window if you're using Xcode.

## Chapter 1 Introduction

Chapter 3, “Classes, Objects, and Methods,” covers the fundamentals of object-oriented programming. This chapter introduces some terminology, but is kept to a minimum. I also introduce the mechanism for defining a class and the means for sending messages to instances. I think this is the best way to get started because the compiler can catch errors, making the programs more self-documenting and encouraging programmers to explicitly declare data types. Chapter 4, “Data Types and Expressions,” describes the basic data types and how to use them in your programs. Chapter 5, “Looping,” introduces the three loop statements you can use in your programs: for, while, and do-while. Chapter 6, “Making Decisions,” covers the Objective-C language's if and switch statements in detail. Chapter 7, “On Classes,” delves more deeply into working with classes and objects. Details about methods, multiple arguments, and local variables are discussed. Chapter 8, “Inheritance,” introduces the concept of inheritance. This feature makes the development of programs easier because you can take advantage of what comes from above. The notion of subclasses make modifying and extending class definitions easy. Chapter 9 discusses three fundamental characteristics of the Objective-C language: polymorphism, dynamic typing, and dynamic binding are the key concepts covered here. Chapters 10-12 run out the discussion of the language, covering issues such as initialization of objects, protocols, the preprocessor, and some of the underlying C features including arrays, structures, and pointers. These features are often unnecessary (and often avoided) when first developing applications. I recommend that you skip Chapter 13, “Underlying Features,” the first time through the text and return to it as necessary to learn more about a particular feature. Chapter 13 also introduces a recent addition: blocks. This should be learned after you learn how to write functions.

Part II begins with Chapter 14, “Introduction to the Foundation Framework,” which gives an introduction to the Foundation framework and how to use its voluminous documentation. Chapters 15-19 cover important features of the Foundation framework. These include number and string objects, collections, the file system, memory management, and the process of copying and archiving objects. By the time you're done with Part II, you will be able to develop fairly sophisticated programs in Objective-C that work with the Foundation framework.

Part III starts with Chapter 20, “Introduction to Cocoa and Cocoa Touch.” Here you'll get a quick overview of the frameworks that provide classes you need to develop sophisticated graphical applications on the Mac and on your iOS devices. Chapter 21, “Writing iOS Applications,” introduces the iOS SDK and the UIKit framework. Chapter illustrates a step-by-step approach to writing a simple iOS application, followed by a more sophisticated calculator application that enables you to use your iPhone to perform arithmetic calculations. Because object-oriented parlance involves a fair amount of terminology, Appendix A, “Glossary,” provides definitions of some common terms. Appendix B “Address Book Source,” gives the source code for classes that are developed and used extensively in Part II of this text. These classes define address card and address book classes. Methods enable you to perform operations such as adding and removing addresses from the address book, looking up someone, listing the contents of the address book, and so on.

After you've learned how to write Objective-C programs, you can go in several directions. You might want to learn more about the underlying C programming language—or you might want to start writing Cocoa programs to run on Mac OS X, or develop more sophisticated iOS applications.
