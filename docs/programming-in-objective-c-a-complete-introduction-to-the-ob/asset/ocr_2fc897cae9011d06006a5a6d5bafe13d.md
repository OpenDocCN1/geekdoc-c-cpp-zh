# Managing Files and Directories: FileManager

Program 16.2 shows how easily you can read the contents of a file into a buffer in memory.

The program reads the contents of your file new2 and writes it to a new file called new3. In a sense, it implements a file copy operation, although not in a straightforward fashion as the copyItemAtPathToPath:error:method.

# Program 16.2

```
// Make a copy of a file
#import <Foundation/Foundation.h>

int main (int argc, char *argv[]) {
    NSAutoreleasePool pool = [[NSAutoreleasePool alloc] init];
    NSFileManager *fm;
    NSData *fileData;

    fm = [NSFileManager defaultManager];

    // Read the file new2
    fileData = [fm contentsAtPath:"@new2"];

    if (fileData == nil) {
        NSLog("@File read failed!");
        return 1;
    }

    // Write the data to new3
    if ([fm createFileAtPath:"@new3" contents:fileData attributes:nil] == NO) {
        NSLog("@Couldn't create the copy!");
        return 2;
    }

    NSLog("@File copy was successful!");

    [pool drain];
    return 0;
}
```

# Program 16.2 Output

File copy was successful!

The contentsAtPath:method simply takes a pathname and reads the contents of the specified file into a storage area that creates, returning the storage area object as the result or if the read fails (for example, if the file doesn't exist or cannot be read by).
The createFileAtPath:contents:attributes creates a file with the specified attributes (or uses the default if nil is supplied for the attributes argument). The contents of the specified NSData object are written to the file. In our example, this data area contains the contents of the previously read file.
