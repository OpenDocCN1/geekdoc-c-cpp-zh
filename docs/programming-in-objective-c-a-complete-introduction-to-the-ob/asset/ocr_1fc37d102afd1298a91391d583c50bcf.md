# Chapter 16 Working with Files

The attributes dictionary enables you to specify, among other things, the permissions for a file you are creating or obtain change information for an existing file. For file creation, if you specify nil for this parameter, the default permissions are set for the file. The attributesOfItemPath: traverseLink method returns a dictionary containing the specified attributes. The traverseLink parameter is YES or NO for symbolic links. If the file is a symbolic link and YES is specified, the attributes of the linked-to-file are returned; if NO is specified, the attributes of the link itself are returned.

For preexisting attributes, the dictionary includes information such as the file's owner, size, its creation date, and so on. Each attribute in the dictionary can be extracted based on its key, all of which are defined in <FileManager.h>. For example, fileSize is the key for a file's size.
