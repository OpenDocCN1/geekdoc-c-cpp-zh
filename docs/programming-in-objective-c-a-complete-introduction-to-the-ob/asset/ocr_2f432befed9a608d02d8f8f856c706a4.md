how does the system know which methods to execute? It's simple:The Objective-C

Note
as described more completely in Chapter 13, "Underlying C Language Features," the system
always carries information about the class to which an object belongs. This enables it to
make these decisions at runtime instead of compile time.

The corresponding methods from the Fraction class are chosen to evaluate the mes-\sage based on the class of f1 and fracResult.
as mentioned, the capability to share the same method name across different classes is
known as polymorphism. Polymorphism enables you to develop a set of classes that can
respond to the same method name. Each class definition encapsulates the code needed
to respond to that particular method, and this makes it independent of the other class defi-
itions. This also enables you to add new classes that can respond to methods with
the same name.
