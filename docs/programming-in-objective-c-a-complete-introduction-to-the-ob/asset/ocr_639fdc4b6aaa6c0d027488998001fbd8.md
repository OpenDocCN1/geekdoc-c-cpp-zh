# Chapter 15 Numbers, Strings, and Collections

Table 15.4 Common NSArray Methods

| Method | Description |
| --- | --- |
| + (id) arrayWithObjects: obj1, obj2, ... nil | Creates a new array with obj1, obj2, ... as its elements |
| (BOOL) containsObject: obj | Determines whether the array contains obj (uses the isEqual:method) |
| (NSInteger) count | Indicates the number of elements in the array |
| - (NSInteger) indexOfObject: obj | Specifies the index of the first element that contains obj (uses the isEqual:method) |
| - (NSInteger) indexOfObjectPassingTest:(BOOL*) (id obj, NSInteger idx, BOOL *stop) block | Passes each object obj (with number idx) into the block obj, which should return YES if obj passes the test, NO if it doesn't. Set variable pointed to stop to YES when ending. |
| - (id) lastObject | Returns the object in the array |
| - (id) objectAtIndex:i | Returns the object in element i |
| (void) makeObjectsPerformingSelector:(SEL) selector | Sends the message indicated by selector to every element of the array |
| (void) enumeratedObjectsUsingBlock:(void (*)(id obj, NSInteger idx, BOOL *stop)) block | Execute for each element in the array, passing in the array obj, and its number idx. Processing continues until all elements have been enumerated or the variable pointed to stop is set to YES. |
| (NSArray *) sortedArrayUsingSelector:(SEL) selector | Sorts the array according to the comparison method specified by selector |
| (NSArray *) sortedArrayUsingComparator:(NSComparator) block | Sorts the array according to the comparison performed by the block block |
| (BOOL) writeToFile:path atomically:(BOOL) flag | Writes the array to the specified file, creating a temporary file if flag is YES |
