## Designing the Interface

In Figure 21.4, and in your Xcode main window, notice a file called MainWindow.xib. An xib file contains information about the user interface for your program, including information about its windows, buttons, tab bars, text fields, and so. Of course you don't have a user interface yet! That's the next step.

Select the MainWindow.xib file from the left pane. This causes the interface design tool to appear, as shown in Figure 21.8. The right pane shows the iPhone's main window, which starts out empty and with a white background by default.

![](img/9a03a17dbf1900dce936c9665ab15c26_470_0.png)

From the View menu, select Utilities, Attributes and next select Utilities, Object Library. Your window should appear as depicted in Figure 21.9 in one of its display formats. (Look at the various options selected in the Editor and Tool bars if you want to try to match your screen to the figure. This shows the Attributes Inspector in the top rightmost pane and the Object Library in the bottom rightmost pane in icon view mode.)

The first thing we will do is to select the iPhone's window to block. To do this, first click inside the iPhone's window in the middle pane. If you glance down to the View section of the Inspector pane, you'll see an attribute labeled Background. If you click inside the white-filled rectangle next to Background, it

You can create new objects in your iPhone window by dragging an object from the Object Library pane into the iPhone window. Drag a Label now. Release the mouse when the label is near to the left of the window, close to the top, as shown in Figure 21.11.

![](img/9a03a17dbf1900dce936c9665ab15c26_472_0.png)

Blue guide lines appear as you move the label around inside your window. Sometimes they will appear to help you align objects with other objects previously placed in the window. At other times, they appear to make your objects are spaced far enough apart from other objects and from the edges of the window, to be consistent with Apple’s interface guidelines.

You can reposition the label in the window at any time in the future by selecting and dragging it to another spot inside the window.

Let’s set some attributes for this label. In your iPhone window, if it’s not selected, click the label you just created to select it. Notice that the Inspector pane gives you information about the currently selected object in your window. We don’t want any text to appear by default for this label, so change the Text value to an empty string (That is, delete the string Label from the text field shown in the Inspector’s pane).

For the Alignment attribute, select the right-justified icon. Finally, change the background-color for the label to blue (or any other color you choose), like you changed the window’s background color to black.

Now let's change the size of the label. Go back to Window and simply resize the label by pulling out along its corners and sides. Resize and reposition the label so that it looks like the one shown in Figure 21.12.

![](img/9a03a17dbf1900dce936c9665ab15c26_473_0.png)

Now we'll add a button to the interface. From the Object Library pane, drag a Rounded Rect object into your interface window, placing it toward the lower-left corner of the window, as shown in Figure 21.12 (note this figure shows the Object Library window changed from icon to list view). You can change the label on the button in one of two ways: by double-clicking the button and typing your text, or by setting the Title field in the inspector pane. Either way you choose, make your window match the one shown in Figure 21.13.

Now we have a label that we want to connect to our display instance variable in our program that we set the variable in the label's text will be changed.

We also have a label labeled 1 that we want to invoke our click method whenever it gets pressed. That method sets the value of display's text field to 1 and because variable will be connected to the label, the label will be updated. As a recap, here's the sequence we want to set up:

- 1. The user presses the button labeled 1.
- 2. This event causes the click method to be executed.
- 3. The click method changes the text property of the instance variable display to the string 1.
- 4. Because the UILabel object display connects to the label in the iPhone's window, this label updates to the corresponding text value, or to the value 1.

![](img/9a03a17dbf1900dce936c9665ab15c26_474_0.png)

For this sequence to work, we just need to make the two connections. There are several ways to do this here, we'll just describe one method.

First, let's get the source code displayed in the third pane. To do this, first select View, Utilities, Hide Utilities, Next View, Editor, Assistant. Hopefully, Xcode will be close to that shown in Figure 21.14.

First, let's connect the button to the IBaction method. You do this by holding the Control key while you click on the button and drag the blue line that appears on the screen to the click1 method displayed in the rightmost pane (and you can drag it to either the method where it is declared in the interface section or where it's defined in the implementation section). This is shown in Figure 21.15.

Now, let's connect the display variable to the label. Select the label in the iPhone's window, hold down the Control key and click-drag the blue line that appears to the display property declaration in the interface file. This is shown in Figure 21.16.

When you release the mouse, the connection is made.
