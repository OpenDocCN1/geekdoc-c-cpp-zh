There are housekeeping variables for building the fractions (currentNumber, firstOperand, and isNumerator), and for building the string for (displayString). There is also a Calculator object (myCalculator) that can perform the actual calculation between the two fractions. We will associate a single method called clickDigit: to handle the pressing of any of the digit keys 0-9. This method will take an argument that will indicate the actual digit key that was pressed, as you'll shortly see.
