The Fraction sum is set to the value of 0 by setting its numerator to 0 and its denominator to 1 (what would happen if you set both numerator and denominator to 0?). The program prompts the user to enter a value for n and returns it using scanf. You then enter a for loop to calculate the sum of the series. First, you initialize the variable pow2 to 2. This variable is used to store the value of 2². Each time the loop, its value is multiplied by 2.

The for loop starts at 1 and goes through n. Each time through the loop, aFraction to 1/pow2, or 1/2i.
Let’s look at the three keys in the loop at a time:

+   1. sum2 = [sum add: aFraction];\This calls the method, passing the argument aFraction. Inside method, aFraction is added with the receiver (sum), and the result is stored inside the fraction result that is returned by the add: method:method is stored inside the variable sum2 by the assignment statement. Make sure you understand this before you go to the next step.

+   2. [sum release];\This releases the memory taken by the sum fraction. Originally, this was the fraction we allocated main when the program started execution. However, this variable is modified each time through the loop (by the statement that follows) to point to a different fraction: the one that the add: method returns.

+   3. sum = sum2;
This takes the reference to the fraction that the add: method returned (which was the fraction we called return inside the add: method) and that we assigned to sum2 in #1 above. This is in preparation for the next iteration through the loop. At the end of this statement, sum and sum2 both point to the same fraction object, which is the one that the add: method allocated and returned.

When the for loop is completed, you display the final result as a decimal value using the Convert method. You have two objects to release: aFraction and your final object stored in sum. Program execution is complete.
