# 144 Chapter 7 More on Classes

The sigma notation is shorthand for a summation. Its use here means to add the values of 1/2i, where i varies from 1 to n. That is, add 1/2 + 1/4 + 1/8 .... If you make the value of n large enough, the sum of these series should approach 1. Let's experiment with different values for n to see how close we get.

Program 7.6 performs for the value of n to be entered and performs the calculation.

# Program 7.6 FractionTest.m

```
#import "Fraction.h"

int main (int argc, char *argv[]) {
    NSAutleasePool *pool = [NSAutleasePool alloc] init];

    Fraction *aFraction = [[Fraction alloc] init];
    Fraction *sum = [[Fraction alloc] init],sum2];
    int i, n, pow2;

    [sum setTo:0 over 1]; // set 1st fraction to 0

    NSLog(@"Enter your value for n:");
    scanf("%d",&n);
    pow2 = 2;
    for (i = 1; i<= pow2; i++) {
        [aFraction setTo:1 over pow2];
        sum2 = [sum add:aFraction];
        [sum release]; // release previous sum
        sum = sum2;
        pow2 *= 2;
    }

    NSLog(@"After %i iterations, the sum is %g", n, [sum convertNumber]);
    [aFraction release];
    [sum release];

    [pool drain];
    return 0;
}
```

After 5 iterations, the sum is 0.96875
