When the lookup: method located Stephen Kochan in the address book (taking advantage of the fact that a non-case-sensitive match was made), the returned the matching card immediately by executing the return statement, which terminates the loop and sends back the value of nextCard. That matching was then given to the AddressCard’s print method for display. In the case of the lookup, the name Haibo Zhang was not found.

This lookup method is very primitive because it needs to find an exact match of the entire name. A better method would perform partial matches and be able to handle multiple matches. For example, the expression

```
[myBook lookup: @*steve];
```

matches = [myBook lookup: @*steve];
