The general format here is:

```
instance.property
```

You can use a similar syntax to assign values as well:

```
instance.property = value
```

This is equivalent to writing the expression:[instance setProperty:value]
In Program 7.1 you set the numerator and denominator of your fraction to 1/3 using
the two lines of code:

```
[Fraction setNumerator: 1];
[Fraction setDenominator: 3];
```

Here’s an equivalent way to write the same two:

```
myFraction.numerator = 1;
myFraction.denominator = 3;
```

We use these features for synthesizing methods and accessing properties through-
out the remainder of this text.

# Multiple Arguments to Methods

Let’s continue to work with the Fraction class and make some additions.You have defined
six methods. It would be nice to have a method to set both the numerator and the denomina-
 with a single message.You define methods that take multiple arguments simply by list-
eaching successive argument followed by a colon. This becomes part of the method name.
For example, the method named addEntryWithName:andEmail takes two arguments, pre-
able and an email address. The method addEntryPointWithName:
EmailandPhone takes three arguments: a name, an email address, and a phone
number.

A method to set the numerator and the denominator could be named
setNumerator:andDenominator:, and you might use it like this:

```
[Fraction setNumerator: 1 andDenominator: 3];
```

That’s not bad. And that was the first choice for the method name. But we can
come up with a more readable method name. For example, how about setTo:over?
That might not look too appealing at a first glance, but it captures this message to
myFraction to 1/3 with the previous one:

```
[Fraction setTo: 1];
```

I think that reads a little better, but the choice is up to you (some might actually prefer
the first name because it explicitly references the instance variables contained in the
class). Again, choosing good method names is important for program readability. Writing
out the actual message expression can help you pick a good one.
