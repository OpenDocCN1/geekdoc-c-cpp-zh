The technique of Program 5.1 works fine calculating relatively small triangular numbers, but what would happen if you needed to find the value of the 200th triangular number, for example? It would certainly be tedious to modify Program 5.1 to explicitly add all the integers from 1 to 200. Luckily, there is an easier way.

One of the fundamental properties of a computer is its capability to repeatedly execute a set of statements. These looping capabilities enable programmers to conceive programs repeating processes that could require thousands or millions of program statements to perform. The Objective-C language contains three statements for program looping.
