The NSMutable array method creates an empty mutable array object for you. The number of elements in the array is not specified and the array can grow as large as you like.

Recall that you can't store a basic data type like an integer into a collection as an array. So we make an NSNumber object of each value of i, which ranges from 0 to 9.

The addObject: method adds an object to the end of an array. Here you add each NSNumber created from the integer value of i.

The program then enters a for loop to display the number of objects stored in the array.

Finally, in Program 15.7 you see how a % can be used in NSLog's string format to display the entire numbers at once.

# Note

How does NSLog know how to display the objects stored in the array? For each element in the array, NSLog will use the description method from the class element belongs to. If it's the default method inherited from NSObject, you'll just get the object's class and address, as previously noted. In this case, however, you get a meaningful display—indicating there a custom description method that has been implemented in the NSNumber class.
