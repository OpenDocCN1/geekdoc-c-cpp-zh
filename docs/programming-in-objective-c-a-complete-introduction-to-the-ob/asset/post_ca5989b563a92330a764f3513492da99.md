# Introduction

Dennis Ritchie at AT&T Bell Laboratories pioneered the C programming language in the early 1970s. However, this programming language did not begin to gain widespread popularity until the late 1970s. This was because, until that time, compilers were not readily available for commercial use outside of Bell Laboratories. Initially, this growth was also partly spurred by the equal, if not faster, growth in popularity of the UNIX operating system, which was written almost entirely in C.

Brad J. Cox called SmallTalk-80 Objective-C in the early 1980s. The language was based on a language called SmallTalk which was layered on top of the C language, meaning that extensions were added to C to create a new programming language that enabled objects to be created and manipulated.

NeXT Software licensed the Objective-C language in 1988 and developed its libraries and a development environment called NEXTSTEP. In 1992, Objective-C support was added to the Free Software Foundation's GNU development environment. The copyrights for all Free Software Foundation (FSF) products are owned by the FSF. It is released under the GNU Public License. In 1994, Apple Computer announced that it would support Objective-C, which became the basis for the next major release. # Chapter 1. Introduction

When the iPhone was released in 2007, developers clamored for the opportunity to develop applications for the device. At first, Apple did not welcome third-party developers. The company's way of placating them was to allow web-based applications. A web-based application runs under the iPhone's Safari browser and requires the user to connect to a website to run it. A native application is one that resides on the iPhone and runs the same way the built-in applications (such as Contacts, Stocks, and Weather) run on the device. The iPhone's OS is actually a version of Mac OS, which means applications could be developed and debugged on a MacBook Pro, for example. The availability of an iPhone simulator made possible for developers to debug their applications directly on their development system, obviating the need to download and test the program on an actual iPhone.

With the introduction of the iPad in 2010, Apple started to generalize the terminology for the operating system and the SDK that now support different devices with different sizes and screen resolutions. The iOS SDK allows you to develop applications for any iOS device and as of this writing, iOS 4 is the current release of the operating system.
