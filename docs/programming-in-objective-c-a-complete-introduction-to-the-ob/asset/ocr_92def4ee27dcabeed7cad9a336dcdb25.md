# Your First iPhone Application

Table 21.1 iPhone Application Templates

| Application Type | Description |
|---|--|
| Split View-based | For an application on a larger-screen device like an iPad that can simultaneously display two views (managed by two different controllers). |

Returning to your New Project window, select Window-based Application in the top rightmost pane and click on the Next button. Type in iPhone_1 for the Product Name, whatever you choose as the Company Identifier, set the Device Family to iPhone, and uncheck Use Core Data and Include Unit Tests. Your screen should resemble Figure 21.4.

![](bbox=[0.237, 0.343, 0.762, 0.613])

Figure 21.4 Selecting project options.

Click on Next and leave the Save As field that appears untouched. You can specify where to create your new project folder, and don't worry about whether the Source Control box is checked. Your screen should now look like Figure 21.5.

Now Save. As you know from previous projects you created with Xcode, a new project will be created that contains templates for files you want to use. This is shown in Figure 21.6, where the iPhone_1 folder reveals three files: iPhone_AppDelegate.h, iPhone_AppDelegate.m, and MainWindow.xib. The rightmost pane contains, among other things, orientations supported by your application and the application's icon. We ignore this pane now.

Depending on your settings and previous uses of Xcode, your window might not appear precisely as depicted in Figure 21.6. You can choose to follow along with whatever your current layout resembles or else try to match it the figure more closely.
