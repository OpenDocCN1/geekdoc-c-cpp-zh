# Chapter 8 Inheritance

If you decide to override dealloc, you also have to be sure to release the memory taken not only by your own instance variables, but by any inherited ones as well.
To do this, you need to take advantage of the special keyword super, which refers to the parent class of the message receiver.Can send a message to super to execute an overridden method. This is the most common use for this keyword. The message expression

```
[super dealloc];
```

when used inside a method invokes the dealloc method that is defined in (or inherited by) the parent class. (Think about it—if you write [self dealloc] you will just be calling the same method in the class and over again—you’d be in an infinite loop.)
So, the strategy for overriding the dealloc method for your Rectangle class is to first release the memory taken up by your origin and then invoke the dealloc method from the parent class to complete the job. Here is the new method:

```
{
  if (origin)
    [origin release];
  [super dealloc];
}
```

The dealloc method is defined to not return a value. A test is made to see if origin is nonzero before releasing it. The origin of the rectangle was never set; in this case, it has its default value of zero.Then we invoke the dealloc method from the parent class, which is the same method the Rectangle class would have inherited if it had not been overridden.
You can also write the dealloc method more simply as

```
-(void) dealloc
{
  [origin release];
  [super dealloc];
}
```

because it’s okay to send a message to a nil (zero) object.Also, you’re careful to release origin and not dealloc here. If no one else is using the origin, that release message will end up invoking the dealloc method on the origin anyway to free up its space.
With your new method, you have to release the rectangles that you allocate, without worrying about the XYPoint objects they contain. The two release messages shown in Program 8.5 will now suffice to release all the objects in the program, including the XYPoint object that setOrigin: creates:

```
[myRect release];
[myPoint release];
```
