After allocating an NSKeyedArchiver, the initForWritingMutableData message is sent to the data area in which you previously created this; the NSMutableData area dataArea The NSKeyedArchiver object stored in archiver can now be sending messages to objects in your program. In fact, until it receives a finishEncoding message, it archives and stores all messages in the specified data area.

You have two objects to encode here—the first is your address book and the second is your Foo. You can use encodeObject:forKey: for these objects because you previously implemented encoder and decoder methods for the AddressBook, AddressCard, and Foo classes.(It's important to understand that concept).

When you are finishing your two objects, you send the archiver the finishEncoding message. No more objects can be encoded after that point, and you need to send this message to complete the archiving process.

The area you set named dataArea now contains your archived objects in a format that you can write to a file. The message expression `dataArea writeToFile:@"myArchive" atomically:YES` sends the writeToFile:atomically message to your data stream to ask it it writes data to the specified file, which you named myArchive.
As you can see from the statement, the writeToFile:atomically method returns a BOOL value:YES if the operation succeeds and NO if it fails (perhaps an invalid pathname for the file was specified or the file system is full).

Restoring the data from your archive file is simple: You just do things in reverse. First, you need to allocate a data area like before. Next, you need to read your archive file into the data area; then you have to create an NSKeyedUnarchiver object and tell it to decode data from the specified area. You must invoke decode to extract and your archived objects. When you're finished, you send a finishDecoding message to the NSKeyedUnarchiver object.
This is all done in Program 19.10.

```objc
#import "AddressBook.h"
#import "Foo.h"

int main (int argc, char *argv[]) {
{
    NSAutorePool *pool = [NSAutorePool alloc init];
    NSData *dataArea;
    NSKeyedUnarchiver *unarchiver;
    Foo *myFoo;
    AddressBook *myBook;
    // Read the archive and connect an
    // NSKeyedUnarchiver object to it

    dataArea = [NSData dataWithContentsFile:@"myArchive"];

    if (!dataArea) {
        NSLog("Can't read back archive file!");
        return 1;
    }

    unarchiver = [[NSKeyedUnarchiver alloc] initForReadingWithData:dataArea];

    // Decode the objects we previously stored in the archive
    myBook = [unarchiver decodeObjectForKey:@"myaddbook"];
    myFoo = [unarchiver decodeObjectForKey:@"myfoo"];

    [unarchiver finishDecoding];

    [unarchiver release];

    // Verify that the restore was successful
    [myBook list];
    NSLog("%@\n%@", [myBook strVal], [myFoo floatVal]);

    [pool release];
    return 0;
}
}
```
