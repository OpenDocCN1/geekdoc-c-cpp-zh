# Program 5.7A Output (Rerun)

Please type in two nonnegative integers.

Their greatest common divisor is 54

After the two integer values have been entered and stored in the variables u and v (using the \u format characters to read in an unsigned integer value), the program enters a while loop to calculate their greatest common divisor. After the while loop is exited, the value of u, which represents the gcd of v and of the original value of u, is displayed with an appropriate message.

You will use the algorithm for finding the greatest common divisor in Chapter 7, when you return to working with fractions. Then you will use the algorithm to reduce a fraction to its simplest terms.

For the next part that illustrates the use of the while statement, let consider the task of reversing the digits of an integer that is entered from the terminal. For example, if the user uses the number 1234, the program should reverse the digits of this and display the result of 4321.

> Note
NSLog calls will cause each digit to appear on a separate line of the output. Programmers who are familiar with the printf function can use that instead to get the digits to appear consecutively.

To write such a program, you must first come up with an algorithm that accomplishes the task. Frequently, analyzing your method for solving the problem leads to an algorithm. For the task of reversing the digits of a number, the solution can be simply stated as "successively read the digits of the number from right to left." You can have a computer program that successively isolate or extract each digit of the number, beginning with the rightmost digit by developing a procedure to successively isolate or extract each digit of the number. The extracted digit can be subsequently displayed as the next digit of the reversed number.

You can extract the rightmost digit from an integer by taking the remainder of the integer after it is divided by 10. For example, 1234 % 10 gives the value 4, which is the rightmost digit of 1234 and also the reversed number. (Remember the modulus operator gives the remainder of one integer divided by another.)You can get the next digit of the number by using the same process if you first divide the number by 10, bearing in mind that integer division works. 1234 / 10 gives a result of 123, and 123 % 10 gives you 3, which is the next digit of the reversed number.

You can continue this procedure until you've extracted the last digit. In the general case, you know that the last digit of the number has been extracted from the result of the last division by 10 is 0.

Program 5.8 prompts the user to enter a number and then proceeds to display the digits from that number from the rightmost to leftmost digit.
