# Chapter 19 Archiving

Program 19.11 Output

```
dataArray:
one
two
tree

dArray2:
oneONE
two
tree
```

The array verifies that changing the first element of dataArray2 had no effect on the first element of dataArray. That's a new copy of the string was made through the archiving/unarchiving process.

The copy operation in Program 19.11 is performed with the following two lines:
data [NSKeyedArchiver archivedDataWithRootObject:dataArray];ndArray2 [NSKeyedUnarchiver unarchiveObjectWithData:data];

You can avoid the intermediate assignment and perform the copy with a simple statement, like:
dArray2 [NSKeyedUnarchiver unarchiveObjectWithData:
[NSKeyedArchiver archivedDataWithRootObject:dataArray]];

This is a technique you might want to keep in mind next time you need to make a deep copy of an object or of an object that doesn't support the NSCopying protocol.
