In Program 5.3, the purpose of the first three NSLog statements is simply to provide a general heading and to label the columns of the output.

After the appropriate headings have been displayed, the program calculates the first 10 triangular numbers. The variable n is used to count the current number whose you are computing, and the variable triangularNumber is used to store the value of n.

Execution of the for statement completes by setting the value of the variable n to 1. As mentioned earlier, the for statement constitutes the body of the program loop. But what happens if you want to repetitively execute just one single statement, but a group of program statements? This can be accomplished by enclosing all such program statements within a pair of braces. The system then treats this group, or block, as a single entity. In, any place in an Objective-C program where a single statement is permitted, a block of statements can be used, provided that you remember to enclose the block within a pair of braces.

Therefore, in Program 5.3, the expression that adds n into the value of triangularNumber and the NSLog statement that immediately follows constitute the body of the program loop. Pay particular attention to the way the program statements are indented. At a quick glance, you can easily determine which statements form part of the for loop. You should also note that programmers use different coding styles; some prefer to type the loop this way:

```
for ( n = 1; n < 10; ++n ) {
    triangularNumber += n;
    NSLog("@d %i", n, triangularNumber);
}
```

The opening brace is placed on the line following the for. This is strictly a matter of taste and has no effect on the program.

The triangular number is calculated by simply adding the value of n to the previous triangular number. The first time through the loop, the previous triangular number is 0, so the new value of triangularNumber when n is equal to 1 is simply the value of n, or 1. The values of n and triangularNumber are then displayed, with appropriate blank spaces inserted into the format string to ensure that the values of the two variables line under the appropriate column headings.

Because the body of the loop has been executed, the loop expression is evaluated. The expression in for statement appears a bit strange, however. Surely you must have made a typographical mistake and meant to insert n = n+1 instead of this funny-looking expression:

```
++n
```

But ++n is actually a perfectly valid Objective-C expression. It introduces a new (and unique) operator in the Objective-C programming language: the increment operator. The function of the double plus, or the increment operator, is to add 1 to its operand. Addition by 1 is such a common operation in programs that a special operator was created for this purpose. Therefore, the expression ++n is equivalent to the expression n = n+1. At first glance, it might appear that n = n+1 is more readable, but you will get used to the function of this operator and learn to appreciate its succinctness.

Of course, no programming language that offers an increment operator to add 1 would be complete without a corresponding operator to subtract 1. As you would guess, the name of this operator is the decrement operator, and it is symbolized by the double minus sign. So an expression in Objective-C reads

```
bean_counter = bean_counter - 1
```

can be equivalently expressed using the decrement operator, like so:

```
--bean_counter
```

Some programmers prefer to put the ++ or -- after the variable, as in bean_counter--. This is a matter of personal preference in the example shown for for statement. However, as you'll learn in Chapter 13, "Underlying C Language Features," the pre- or post- nature of the operator comes into play when used in more complex expressions.

You might have noticed that the line of output from Program 5.3 does not line up. You can correct this minor annoyance by substituting the NSLog statement in place of the corresponding statement from Program 5.3:

```
NSLog("%2i %i", n, triangularNumber);
```

To verify that this change solves the problem, here’s the output from the modified program (called Program 5.3A).

The change made to the NSLog statement is the inclusion of field width. The characters %2i tell the integer at least two columns. This is known as right justification. Thus, by using field width of %2i, you guarantee that the values of triangularNumber will be aligned.

# The for Statement

The scanaf routine is similar in concept to the NSLog routine. Whereas the NSLog routine is used to display values, the purpose of scanaf is to enable the programmer to type values into the program. Of course, if you are writing an Objective-C program that uses a graphical Interface (UI), such as a Cocoa or iOS application, you likely won't be using NSLog or scanaf at all.

Program 5.4 allows the user who triangular number should be calculated, calculates that number, and displays the results.

# Program 5.4

```
#import <Foundation/Foundation.h>

int main (int argc, char *argv[]) {
    NSAutleasePool *pool = [[NSAutleasePool alloc init];
    int n, number, triangularNumber;

    NSLog("@What triangular number do you want?");
    scanf("%i", &number);

    triangularNumber = 0;

    for ( n = 1; n <= number; ++n ) {
        triangularNumber += n;
    }

    NSLog("@Triangular number %i is %i\n", number, triangularNumber);

    [pool drain];
    return 0;
}
```

# Program 5.4 Output

What triangular number do you want?
100
Triangular number 100 is 5050

According to the output, the user typed the number 100. The program then calculated the 100th triangular number and displayed the result of 5050 at the terminal. The user could have just easily typed in the number 10 or 30, for example, if he or she wanted to calculate those particular numbers.

The first NSLog statement in Program 5.4 is used to prompt the user to type a number. Of course, it is always nice to remind the user of what you entered. After the message is printed, the scanaf routine is called. The first argument to scanaf is the format string, which does not begin with the @ character. Unlike NSLog, whose first argument is an NSString object, the first argument to scanaf is a C-style string. As noted earlier in this text, C-style character strings are not preceded by the @ character.
