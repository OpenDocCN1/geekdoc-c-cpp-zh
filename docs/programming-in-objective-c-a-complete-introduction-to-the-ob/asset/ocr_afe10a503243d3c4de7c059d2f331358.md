The following expression uses the "minus equals" assignment operator to subtract
from the value of counter:

```
counter -= 5
```

It is equivalent to this expression:

```
counter = counter - 5
```

This is a slightly involved expression:

```
a /= b + c
```

It divides by whatever appears to the right of the equals sign—or by the sum of b
and—stores the result in a. The addition is performed first because the addition op-
erator has higher precedence than the assignment operator. In fact, operators but the
comma operator have higher precedence than the assignment operators, which all have
the same precedence.

In this case, expression is identical to the following:

```
a = a / (b + c)
```

The motivation for using assignment operators is threefold. First, the program state-
ment becomes easier to write because whatever appears on the left side of the operator does
not to be repeated on the right side. Second, the resulting expression is usually easier
read. Third, use of these operators can result in programs that execute more quickly
because the compiler can generate less code to evaluate an expression.
