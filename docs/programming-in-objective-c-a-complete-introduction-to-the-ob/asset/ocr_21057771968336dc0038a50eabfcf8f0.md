+   4. Based on the discussions about argument and return types in this chapter, modify both add: methods in the Fraction and Complex classes to take and return id objects. Then write a program that incorporates the following code sequence:
result = [dataValue add: dataValue2];
[result print];

Here, dataValue1, and dataValue2 are objects. Make sure you set dataValue1 and dataValue2 appropriately in your program and release all objects your program terminates.

> Note
You have to change the name of the methods to something other than add:. That's because the system's NSObject class also has an add: method. As noted earlier in this chapter in the "Arguments and Return Types with Dynamic Typing" section, if multiple methods of the same name exist in different classes and the type of the receiver isn't known at compile time, the compiler will perform a consistency check to make sure the arguments and return types are consistent among the similarly named methods.
