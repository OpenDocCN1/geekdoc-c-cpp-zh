So I decided neither teach C first nor assume prior knowledge of the language. Instead, I decided to take the unconventional approach of teaching Objective-C and the underlying C language as a single integrated language, from an object-oriented programming perspective. The purpose of this book is as its name implies: it does not teach you how to program in Objective-C 2.0. It does not teach you in detail how to use the development tools that are available for entering debugging programs, or to provide in-depth instructions on how to develop graphical applications. You can learn all that material in detail elsewhere, after you've learned how to write programs in Objective-C. In fact, mastering material will be much easier when you have a solid foundation of programming experience. In fact, if you're a novice programmer, with some dedication and hard you should be able to learn Objective-C as your first programming language. Other readers have been successful with this, based on the feedback I've received from previous editions of this book.

This book teaches Objective-C by example. As I present each new feature of the language, I usually provide a small complete example to illustrate the feature. Just as a picture is worth a thousand words, so is a properly chosen example. You are strongly encouraged to run each program (all of which are available online) and compare the results on your system to those shown in the text. By doing so, you will learn the language and its syntax, and you will also become familiar with the process of compiling and running Objective-C programs.

# How This Book Is Organized

This book is divided into three logical parts. Part I, “The Objective-C 2.0 Language,” teaches the essentials of the language. Part II, “The Foundation Framework,” teaches how to use the rich aspect of predefined classes that form the Foundation framework. Part III, “Cocoa, Cocoa Touch, and the iOS SDK,” gives you an overview of the Cocoa and Cocoa Touch frameworks and walks you through developing a simple iOS application using the iOS SDK.

A framework is a set of classes and routines that will be logically grouped together to make developing programs easier. Much of the power of programming in Objective-C rests on the extensive frameworks that are available.

Chapter 2, “Programming in Objective-C,” begins teaching you how to write your first program in Objective-C.

Because this is not a book on Cocoa or iOS programming, graphical interfaces (GUIs) are not extensive and are hardly even mentioned until Part III. So an approach was needed to get input into a program and produce output. Most of the examples in this text take input from the keyboard and produce your output in a window pane: a Terminal window if you're using gee from the command line, or a debug output pane if you're using Xcode.
