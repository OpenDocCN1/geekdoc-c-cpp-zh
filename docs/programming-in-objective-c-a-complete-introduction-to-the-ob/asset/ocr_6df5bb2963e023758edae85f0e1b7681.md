# Chapter 12 The Preprocessor

To define the symbol IPAD to the preprocessor, the statement
#define IPAD 1

or even just
#define IPAD
As you can see, no text at has to appear after the defined name to satisfy the #ifdef test. The compiler allows you to define a name to the preprocessor when the program is compiled by a special option to the compiler command.The command line
gcc --framework Foundation -D IPAD program.m -
defines the name IPAD to the preprocessor, causing all #ifdef IPAD statements inside program.m to evaluate as TRUE (note that you must type the -D IPAD before the program on the command line). This technique enables you to define names without having to edit the source code.
In Xcode, you add defined names and their properties by selecting Build Settings, All, LLVM GCC 4.2 - Preprocessor, Preprocessor Macros. You can see a screenshot of the symbol IPAD defined in Code 4 in Figure 12.1.

The #undef statement follows the same lines as the #ifdef statement. This statement is used in a similar way, except it causes the subsequent lines to be processed if the indicated symbol is not defined.
