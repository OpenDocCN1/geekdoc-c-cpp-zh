You begin enumeration of a directory by sending an enumeratorAtPath: message to a file manager, in this case an NSDDirectoryEnumerator object gets returned by the enumeratorAtPath: method, which is stored inside dirEnum. Now, each time you send a nextObject to message this object, you get a path to the next file in the directory you are enumerating. When more files are left to enumerate, you get nil.

You can see the difference between the two enumeration techniques from the output of Program 16.4. The enumeratorAtPath: method lists the contents of the directory, whereas contentsOfDirectoryPath: does not. If we had contained subdirectories, they would have been enumerated by enumeratorAtPath:
