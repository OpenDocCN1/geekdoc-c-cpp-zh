# Chapter 13 Underlying Language Features

Just as you defined variables to be of type struct date, as in
struct date    todaysDate;

you can define a variable as a pointer to a struct date variable:
struct date   *datePtr;

You can then use the variable datePtr, as just defined, in the expected fashion.
for example, you can set it to point to todaysDate with the following assignment statement:
datePtr = &todaysDate;

After an assignment, you can indirectly access any of the members of the date
structure that datePtr points to in the following way:
(*datePtr).day = 21;

This statement sets the date of the date structure pointed to by datePtr to 21.
The parentheses are required because the structure member operator has higher precedence
than the indirection operator *.

To test the value of month stored in the date structure datePtr points to, you can
use a statement such as:
if (*datePtr).month == 12

Pointers to structures are so often used that the language has a special operator.
structure pointer operator -> which is the dash followed by the greater-sign, permits
expressions that would be easily expressed as
(*x).y

to be more clearly expressed as
So you can conveniently write the previous if as follows:
if (datePtr->month == 12)
