is evaluated according to the rules stated previously as

(a * b) + (c * d)

or

(100 * 2) + (25 * 4) is handed to the NSLog routine.

# Integer Arithmetic and the Unary Minus Operator

Program 4.3 reinforces what we have just discussed and introduces the concept of integer arithmetic.

Program 4.3

```
// More arithmetic expressions

#import <Foundation/Foundation.h>
{
int main(int argc, char *argv[]) {
NSAutoreleasePool *pool = [NSAutoreleasePool alloc];

int a = 25;
int b = 2;
float c = 25.0;
float d = 2.0;

NSLog("%@f a + 5 * b = %i", 6 + 5 * b);
NSLog("%@f a / b = %i", a / b);
NSLog("%@f c / d = %f", c / d);
NSLog("%@f-a = %i", -a);

[pool drain];
return 0;
}
```

```

a / b * b = 24
c / d * d = 25.000000
a-a = -25
```

We inserted extra blank spaces between int and the declaration of a, b, and result in the first three statements to align the declaration of each variable. This makes the program more readable. You might have noticed in this program presented thus far that a blank space was placed around each operator. This, too, is not required and done solely for aesthetic reasons. In general, you can add extra blank spaces about anywhere that a single extra presses of the spacebar will prove worthwhile if the resulting program is easier to read.
