You can insert comments into an Objective-C program in two ways. One is by using
two consecutive slashes ( // The compiler ignores any characters that follow
slashes, up to the end of the line.

You can also initiate a comment with the two characters / and *. This marks the
beginning of the comment. These types of comment have to be terminated. End the
comment, you use the characters * and /, without any without embedded spaces. All char-
ters included between the opening / and the closing /* are treated as part of the com-
ment statement and are ignored by the Objective-C compiler. This form of comment is
offten when using many lines of code, as in the following:

```
/
```


Which style of comment you use is entirely up to you. Just note that you can't nest the
* style comments.

Get into the habit of inserting comment statements in the program as you write it or
to the computer, for three good reasons. First, documenting the program while
t particular program logic is still fresh in your mind is far easier than going back and
rethinking the logic after the program has been completed. Second, by inserting com-
 into the program at an early stage of the game, you can reap the benefits of
the comments during the debug phase, when program errors are isolated and
debugged. Not only can a comment help you (and others) read through the program, but
it can also help point out the way to the source of the logic. Finally,I haven't yet dis-
covered a programmer who actually enjoys documenting a program. In fact, after you've
finished your program, you will probably not relish the idea of going back to
the program to insert comments. Inserting comments while developing the program
makes this sometimes tedious task a bit easier to handle.
