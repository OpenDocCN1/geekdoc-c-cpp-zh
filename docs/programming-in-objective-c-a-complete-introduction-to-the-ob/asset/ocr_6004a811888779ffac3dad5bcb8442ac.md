# Chapter 15 Numbers, Strings, and Collections

Table 15.11 Some NSIndexSet Methods

| Method | Description |
| --- | --- |
| + (NSIndexSet) indexSet | Creates an empty index set |
| - (BOOL) containIndex: idx | Returns YES if the index set contains the index, NO otherwise |
| - (NSUinteger) count | Returns the number of indices in the indexed set
| - (NSUinteger) firstIndex | Returns the first index in the set if NSNotFound if it is empty |
| - (NSUinteger) indexLessThanIndex: idx | Returns the closest index in the less than idx or NSNotFound if none is less than idx. See also indexLessThanEqualTo;: indexGreaterThanIndex;: and indexGreaterThanEqualTo;: |
| - (NSUinteger) lastIndex | Gives the last index in the set or NSNotFound if set is empty |
| - (NSIndexSet *) indexesPassingTest: (BOOL*) (NSUinteger idx, BOOL *stop) block | Block applied to each element in the set. Return YES to idx added to the resultant NSIndexSet, NO otherwise; set the variable pointed to by stop to YES to end processing |
