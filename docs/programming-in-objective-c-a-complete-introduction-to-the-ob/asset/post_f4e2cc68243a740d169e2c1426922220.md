# Chapter 16 Working with Files

The attributes dictionary enables you to specify, among other things, the permissions for a file you are creating or obtain change information for an existing file. For file creation, if you specify nil for this parameter, the default permissions are set for the file. The attributesOfItemPath: traverseLink method returns a dictionary containing the specified attributes. The traverseLink parameter is YES or NO for symbolic links. If the file is a symbolic link and YES is specified, the attributes of the linked-to-file are returned; if NO is specified, the attributes of the link itself are returned.

For preexisting attributes, the dictionary includes information such as the file's owner, size, its creation date, and so on. Each attribute in the dictionary can be extracted based on its key, all of which are defined in <FileManager.h>. For example, fileSize is the key for a file's size.

# Working with NSData Class

 working with files, you frequently need to read data into a storage area, often called a buffer. When collecting data for subsequent output, Foundation's NSData class provides an easy way to read, or write a buffer out to a file. As you would expect, you can define either immutable (NSData) or mutable (NSMutableData) storage classes. We introduce methods from this class in this chapter and in succeeding chapters as well.

# Managing Files and Directories: FileManager

Program 16.2 shows how easily you can read the contents of a file into a buffer. The program reads the contents of your file new2 and writes it to a new file called new3. In a sense, it implements a copy operation, although not in a straightforward fashion as the copyItemAtPathToPath:error:method.

# Program 16.2

```
// Make a copy of a file
#import <Foundation/Foundation.h>

int main (int argc, char *argv[]) {
    NSAutleasePool pool = [[NSAutleasePool alloc] init];
    NSFileManager *fm;
    NSData *fileData;

    fm = [NSFileManager defaultManager];

    // Read the file new2
    fileData = [fm contentsAtPath:@"new2"];

    if (fileData == nil) {
        NSLog("@File read failed!");
        return 1;
    }

    // Write the data to new3
    if ([fm createFileAtPath:@"@new3" contents:fileData attributes:nil] == NO) {
        NSLog("@Couldn't create the copy!");
        return 2;
    }

    NSLog("@File copy was successful!");

    [pool drain];
    return 0;
}
```

# Program 16.2 Output

File copy was successful!

The contentsAtPath:method simply takes a pathname and reads the contents of the specified file into a storage area that creates, returning the storage area object as the result or if the read fails (for example, if the file doesn't exist or cannot be read).
The createFileAtPath:contents:attributes creates a file with the specified attributes (or uses the default if nil is supplied for the attributes argument). The contents of the specified NSData object are written to the file. In our example, this data area contains the contents of the previously read file.
