# Working with the NSData Class

When working with files, you frequently need to read data into a temporary storage area, often called a buffer. When collecting data for subsequent output to a file, a storage area is often used. Foundation's NSData class provides an easy way to set up a buffer, read the contents of the file into, or write the contents of a buffer out to a file. And in case you're wondering, for a 32-bit application, an NSData buffer can store up to 2GB (that's exabytes) or 8 billion gigabytes of data!

As you would expect, you can define either immutable (NSData) or mutable (NSMutableData) storage classes. We introduce methods from this class in this chapter and in succeeding chapters as well.
