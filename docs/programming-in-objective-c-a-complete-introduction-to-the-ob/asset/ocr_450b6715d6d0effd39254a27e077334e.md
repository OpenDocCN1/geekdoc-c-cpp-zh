# The AddressBook Class

Your AddressCard class seems to be working okay. What if you wanted to work with a lot of AddressCards? It would make sense to collect them, which is exactly what you'll do by defining a new class AddressBook. The AddressBook class will store the name of an address book and a collection of AddressCards, which you'll store in an array object. To start, you'll want the ability to create a new address book, add new cards to it, find out how many entries are in it, and list its contents. Later, you'll want to be able to search the address book, remove entries, possibly edit existing entries, sort it, or even make a copy of its contents.

Let's get started with a simple interface file (see Program 15.10).

# Program 15.10 AddressBook.h Interface File

```
#import <Foundation/Foundation.h>
#import "AddressCard.h"

@interface AddressBook : NSObject
{
    NSString *name;
    NSMutableArray *entries;
}

-(id)initWithName:(NSString *)name;
- (void)addCard:(AddressCard *)card;
- (int)entries;
- (void)list;
- (void)dealloc;

@end
```

The initWithName: method sets up the array to hold the address cards and store the name of the book, whereas the addCard: method adds an AddressCard to the book. The entries method reports the number of addresses in your book, and the list method gets a concise list of its entries contents. Program 15.10 shows the implementation file for your AddressBook.
