# Chapter 15 Numbers, Strings, and Collections

The substringToIndex creates a substring from the leading characters in a string to not including the specified index number. Because indexing begins at 0, the argument of 3 extracts characters 0, 1, and 2 from the string and returns the resulting string object. For any of the string methods that take an index number as one of their arguments, you get a "Range or index out of bounds" error message if you provide an invalid index number in the string.

The substringFromIndex returns a substring from the receiver with the character at the specified index and up to the end of the string.
The expression

```
res = [[substringFromIndex:8] substringToIndex:6];
```

shows how the two methods can be combined to extract a substring of characters from inside a string. The substringFromIndex method is first used to extract characters from index number 8 through the end of the string; then substringToIndex is applied to the result to get the first six characters. The result is a substring representing the range of characters {8, 6} from the original string.

The substringWithRange method does in one step what we just did in two: It takes a range and returns a character in the specified range. The special function

```
NSMakeRange(8, 6)
```

creates a range from its argument and returns the result. This is given as the argument to the substringWithRange method.

# Chapter 15 Numbers, Strings, and Collections

To locate one string inside another, you can use the rangeOfString: method. If the specified string is found inside the receiver, the returned range specifies precisely where in the string it was found. However, if the string is not found, the range that returned has its location member set to NSNotFound.

So the statement

```
subRange = [rangeOfString: @"string A"];
```

assigns the NSRange structure returned by the method to the NSString variable subRange. Be to remember that subRange is not an object, but a structure variable (the declaration for subRange in the program also does not contain an asterisk—that is often a clause that you're not dealing with an object—no exception is the id type). Its members can be retrieved by using the member operator dot (). The expression subRange.location gives the value of the location member of the structure, and subRange.length gives the length member. These values are passed to the NSLog function to be displayed.

# Mutable Strings

The NSMutableString class can be used to create string objects whose characters can be changed. Because this is a subclass of NSString, all NSStrings methods can be used as well.

When we speak of mutable versus immutable strings, we talk about changing the actual characters within the string. A mutable or an immutable string can always be set to a completely different string during execution of the program. This was stressed in the discussion of Program 15.3. So, for example, consider the following:

```
str1 = @"This is a string";
```

```
str2 = [str1 substringFromIndex: 5];
```

In this case, str1 is first set to a constant character string. Later in the program, it is set to a substring. In such a case, str1 could be declared as either a mutable or an immutable string. Be sure to understand this point.

Program 15.5 shows some ways to work with mutable strings in your programs.
