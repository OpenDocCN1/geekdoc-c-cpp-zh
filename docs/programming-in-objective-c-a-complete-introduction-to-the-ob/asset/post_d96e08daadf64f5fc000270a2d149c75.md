As noted at the start of this section, a block can return a value. Here's the gcd function of Program 13.5 rewritten in block form:

```c
int (^gcd) (int, int) =
^(int u, int v) {
  int temp;

  while ( v != 0 ) {
    temp = u % v;
    u = v;
    v = temp;
  }

  return u;
};
```

A block can access variables within the scope in which it's defined. The value of that variable is what it has at the time the block is defined. This is illustrated in Program 13.8.

## Structures

The Objective-C language provides another tool besides arrays for grouping elements. You can also use structures, which form the basis for the discussions in this section. Suppose you wanted to store a date—say, 7/18/11—inside a program, perhaps to be used for the heading of some output or for computational purposes. A natural method for storing the date to an integer is to assign the date to an integer variable called month, and so on:

`int month = 7, day = 18, year = 2011;`

This would just fine. But what if your program also needed to store several dates? It would be much better to somehow group these sets of variables. You can define a structure called date in the Objective-C language that consists of three components that represent the month, day, and year. The syntax for such a definition is straightforward:

```c
struct date {
    int month;
    int day;
    int year;
};
```

The date structure just contains three integer members, called month, day, and year. Essentially, the definition of date defines a new type in the language, so variables can be subsequently declared to be of type struct date, as in the following definition:

`struct date today;`

You can also define a variable called purchaseDate to be of the same type:

`struct date purchaseDate;`

Or you can simply include both on the same line:

`struct date today, purchaseDate;`

Unlike variables of type int, float, or char, a special syntax is needed when dealing with structure variables. A member of a structure is accessed by specifying the variable name, followed by a period and then the member name. For example, to set the value of day in the variable today to 21, you would write:

`today.day = 21;`

Note that no spaces are permitted between the variable name, the period, and the member name. Now, wait! Wasn't the same operator we used to access a property on an object (myRect.width = 12;) used here? No confusion arises here: the compiler determines whether it's a structure or to the left of the dot operator and handles the situation properly. Returning to the struct date example, to set year in today to 2011, you can use this expression:

`today.year = 2011;`

## Program 13.10

```c
#import <Foundation/Foundation.h>
int main (int argc, char *argv[]) {
    NSAutleasePool * pool = [[NSAutleasePool alloc] init];

    struct {
        int month;
        int day;
        int year;
    } today;

    today.month = 9;
    today.day = 25;
    today.year = 2011;

    NSLog("Today's date is %02i/%02i/%2i.", today.day, today.year, today.year % 100);

    [pool drain];
    return 0;
}
```

## Program 13.10 Output

Today's date is 9/25/11.

The first statement inside defines the structure date to consist of three integers, called month, day, and year. In the second statement, the variable today is declared to be of type date so the first statement simply defines what a date looks like and the Objective-C compiler reserves no storage inside the computer. The second statement declares a variable to be of type struct date and, therefore, reserves memory for storing the three integer members of the structure variable today.

After the assignments, appropriate NSLog displays the values contained inside the structure. The remainder of today.year divided by 100 is calculated before being passed to the NSLog function that just displays the year. The %.2i format characters in the NSLog call a minimum of two characters to be displayed, forcing the display of the leading zero for the year.

When it comes to the evaluation of expressions, structure members follow the same rules as ordinary variables in the Objective-C language. Division of an integer member by another integer is performed as an integer division, as shown here:

`century = today.year / 100 + 1;`

Suppose you want to write a simple program that accepted today's date as input and displayed tomorrow's date to the user. At first glance, this seems a perfectly simple task to perform. You can use the user to enter today and then calculate tomorrow's date by a series of statements, like so:

```c
tomorrow.month = today.month;
tomorrow.day = today.day + 1;
tomorrow.year = today.year;
```

Of course, the previous statements would work fine for most dates, but the following two cases would not be properly handled:

- If today's date fell at the end of a month
- If today's date fell at the end of a year (that is, if today's date were December 31)

One way to easily determine whether today's date falls at the end of a month is to use an array of integers that corresponds to the number of days in each month. A lookup inside the array for a particular month would then give the number of days in month.

## Initializing Structures

Initializing structures is similar to initializing arrays—the elements are simply listed inside a pair of braces, with a comma separating each element.

To initialize the date structure variable today to July 2, 2011, you can use this statement:

```c
struct date today = { 7, 2, 2011 };
```

As with the initialization of an array, fewer values can be listed than the structure contains. So the statement

`struct date today = { 7 };`

sets today.month to 7 but gives no initial value to today.day or today.year. In such a case, their default values are undefined.

Specific members can be designated for initialization in any order with the notation .member = value in the initialization list, as in

```c
struct date today = { .month = 7, .day = 2, .year = 2011 };
```

and

```c
struct date today = { .year = 2011 };
```

The last statement just sets the year in the structure to 2011. As you know, the other two members are undefined.
