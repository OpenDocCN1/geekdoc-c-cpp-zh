# Program 18.1 Output

dataArray:
two
three
four
dataArray2:
two
three
four
dataArray:
two
three
four

The program defines the array object dataArray and sets its elements to the string objects "@one", "@two", "@three", and "@four". As we've discussed, the assignment dataArray2: dataArray;

simply creates another reference to the same array object in memory. When you move the object from dataArray2 and subsequently print the elements from both array objects, it's no surprise that the first element (the string "@one") is gone from both array references.

Next, you create a mutable copy of dataArray and assign the resulting copy to dataArray2. This creates two distinct mutable arrays in memory, containing three elements. When you remove the first element from dataArray2, it has no effect on the contents of dataArray, as verified by the last output for dataArray.

Note that making a mutable copy of an object does not require the object being copied to be mutable. The same applies to immutable objects: You can make an immutable copy of a mutable object.

Also note when making a copy of an array that the copy operation automatically increments the retain count for each element in the array. Therefore, if you make a copy of an array and subsequently release the original array, the copy still contains valid elements.
