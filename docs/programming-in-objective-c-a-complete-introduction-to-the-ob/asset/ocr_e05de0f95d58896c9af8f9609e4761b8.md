# Categories and Protocols

In this chapter, you'll learn about how to add methods to a class in a modular fashion through the use of categories and how to create a standardized list of methods for others to implement.

# Categories

Sometimes you might be working with a class definition and want to add some new methods to it. For example, you might decide for your Fraction class that, in addition to the `add:` method for adding two fractions, you want to have methods to subtract, multiply, and divide two fractions.

As another example, say you are working on a large programming project and as part of that, your group is defining a new class that contains many different methods. You have been assigned the task of writing methods for the class that work with the file system. Other project members have been assigned methods responsible for creating and initializing instances of the class, performing operations on objects in the class, and drawing representations of objects from the class on the screen.

As a final example, suppose you've learned how to use a class from the library (for example, the Foundation framework's array class NSArray) and realize that you wish the class had implemented one or more methods. Of course, you could write a subclass of the NSArray and implement the new methods, but perhaps an easier way exists.

A practical solution for all these situations is categories. A category provides an easy way for you to modularize the definition of a class into groups or categories of related methods. It also gives you an easy way to extend existing class definition without even having access to the original source code for the class and without having to create a subclass. It is a powerful yet easy concept for you to learn.
