## Array Objects

A foundation is an ordered collection of objects. Most often, elements in an array are of one particular type, but that’s not required. Just as there are mutable and immutable strings, there are mutable and immutable arrays. Mutable arrays are handled by the NSArray class, whereas mutable ones are handled by NSMutableArray. The latter is a subclass of former, which means it inherits its methods.

Program 15.6 sets an array to store the names of the months of the year and prints them.

## Program 15.6

```objc
#import <Foundation/Foundation.h>
#import <Foundation/NSAutoreleasePool.h>

int main (int argc, char *argv[]) {
    int i;
    NSAutoreleasePool *pool = [[NSAutoreleasePool alloc] init];
    // Create an array to contain the month names
    NSArray *monthNames = [NSArray arrayWithObjects:
        "January", "February", "March", "April",
        "May", "June", "July", "August", "September",
        "October", "November", "December", nil];
    
    // Now list all the elements in the array
    NSLog("Month Name:");
    NSLog("=====");

    for (i = 0; i < 12; ++i) {
        NSLog("%@ %2i", i + 1, [monthNames objectAtIndex:i]);
    }

    [pool drain];
    return 0;
}
```

## Chapter 15 Numbers, Strings, and Collections

You can use the method arrayWithObjects: to create an array with a list of objects as its elements. In such a case, the objects are ordered and separated by commas. This is a special syntax by methods that can take a variable number of arguments. To mark the end of the list, nil must be specified as the last value in the list—it isn't actually stored inside the array.

In Program 15.6 numberOf is to set the 12 values specified by the arguments to arrayWithObjects:. Elements are identified in an array by their index numbers. Similar to NSString, indexing begins with zero. An array containing 12 elements has valid index 0–11. To retrieve an element of an array using its index number, you use the objectAtIndex: method.

The program executes a for loop to extract each element from the array using the objectAtIndex: method. Program 15.7 creates an array of 10 objects, whose values range from 0 through 9. The values are retrieved for display using a simple for and then the entire array is displayed again just using the %@ format characters in NSLog format string. In this you'll learn another technique known as fast enumeration that you can also use to sequence through the elements of your array.

## Program 15.7

```objc
#import <Foundation/Foundation.h>
int main (int argc, char *argv[]) {
    NSAutoreleasePool *pool = [NSAutoreleasePool alloc];
    NSMutableArray *numbers = [NSMutableArray array];
    NSNumber *number;
    int i;

    // Create an array with the number 0-9
    for (i = 0; i < 10; ++i) {
        myNumber = [NSNumber numberWithInteger:i];
        [numbers addObject:myNumber];
    }

    // Sequence through the array and display the values
    for (i = 0; i < 10; ++i) {
        myNumber = [numbers objectAtIndex:i];
        NSLog("%@", myNumber);
    }

    // Look how NSLog can display with a single %@
    NSLog("%@", numbers);
    [pool drain];
    return 0;
}
```
