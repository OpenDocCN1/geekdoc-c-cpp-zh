# Sorting Arrays

If your address book contains a lot of entries, alphabetizing it might be convenient. You can easily do this by adding a sort method to your AddressBook class and by taking advantage of an NSMutableArray called sortUsingSelector:. This method takes as its argument the sortUsingSelector: method uses to compare two elements. Arrays can contain any type of objects in, so the only way to implement a generic sorting method is to decide whether elements in the array are order. To do this, you must add a method to compare two elements in the array. The result returned from that method is of type NSComparisonResult. It should return NSOrderedAscending if you want to sort the first element before the second in the array, return NSOrderedSame if the two elements are considered equal, or return NSOrderedDescending if the first element should come after the second element in the sorted array.

First, here's the new sort method from your AddressBook class:

```
(void) sort
{
    book sortUsingSelector: @selector(compareNames:)];
}
```

As you learned in Chapter 9, "Polymorphism, Dynamic Typing, and Dynamic Binding," the expression
@selector(compareNames:)

creates a selector, which is of type SEL, from a specified method name; this is the method sortUsingSelector: uses to compare two elements in the array.When it needs to make a comparison, it invokes the specified method, sending the message to the first element in the array (the receiver) to be compared against its argument. The returned value should be of type NSComparisonResult, as previously described.

Because the elements of your address book are AddressCard objects, the comparison method must be added to the AddressCard class (make sure you fully understand that). You must go to your AddressBook class and add a compareNames: method to it. This is shown here:

```
// Compare the two names from the specified address cards
```

```
(NSComparisonResult) compareNames:(id) element
{
    return [name compare: [element name]];
}
```

> 4 A method called sortUsingFunction:context lets you use a function instead of a method to perform the comparison.
