## Nested for Loops

Program 5.4 gives the user flexibility to have the program calculate any triangular number that is desired. But suppose the user had a list of five triangular numbers to be calculated? In such a case, the user could simply execute the program five times, each time typing the next triangular number from the list to be calculated.

Another way to accomplish the goal, and a far more interesting method, as far learning about Objective-C is concerned, is to have the program handle the situation. This can be accomplished by inserting a loop into the program to repeat the entire series of calculations five times. You can use the for statement to set up such a loop. Program 5.5 and its associated output illustrate this technique.

## Program 5.5

```objectivec
#import <Foundation.h>

int main (int argc, char *argv[]) {
	NSAutleasePool *pool = [NSAutleasePool alloc init];
	int n, triangularNumber, counter;

	for ( counter = 1; counter <= 5; ++counter ) {
		NSLog(@"What triangular number do you want?");
		scanf("%i", &number);
		triangularNumber = 0;
		for ( n = 1; n <= number; ++n)
			triangularNumber += n;

		NSLog("Triangular number %i is %i", number, triangularNumber);
	}

	[pool drain];
	return 0;
}
```

The program consists of two levels of for statements. The outermost for statement is as follows:

```objectivec
for ( counter = 1; counter <= 5; ++counter )
```

This specifies that the program loop is be executed precisely five times. The value of counter is initially set to 1 and is incremented by 1 until it is no longer than or equal to 5 (in other words, until it reaches 6).

Unlike the previous program example, the variable counter is not used anywhere else within the program. However, because it is a variable, you must declare it in the program.

The program loop actually consists of all the more remaining program statements, as indicated by the braces. You might be able to easily comprehend the way this program operates if you conceptualize it as follows:

For 5 times

```objectivec
{
  Get the number from the user.
  Calculate the requested triangular number.
  Display the results.
}
```

The portion of the loop referred to in the preceding Calculate the requested triangular number actually consists of setting the value of the variable triangularNumber to 0 plus the for loop that calculates the triangular number. Thus, a statement is actually contained within another for statement. This is perfectly valid in Objective-C, and can continue even for any desired level.

The use of indentation becomes even more critical when dealing with sophisticated program constructs, such as nested for statements. At a quick glance, you can easily determine which statements are contained within each for statement.

## Loop Variants

Before leaving this discussion of the loop, we should mention some of the syntactic variations that are permitted in forming this loop. When writing a for loop, you might discover that you want to initialize more than one variable before the loop begins, or perhaps you want to evaluate more than one expression each time through the loop. You can include multiple expressions in any of the fields of the for loop, as long as you separate such expressions by commas. For example, in the for statement begins

```objectivec
for (i = 0, j = 0; i < 10; ++i)
```

the value of i is set to 0 and the value of j is set to 0 before the loop begins. The two expressions i = 0 and j = 0 are separated from each other by a comma, and both expressions are considered part of the init_expression field of the loop. As another example, the for loop starts

```objectivec
for ( i = 0; j = 100; i++, j-=10 )
```

sets up two variables: i and j, which are initialized to 0 and 100, respectively, before the loop begins. Each time the body of the loop is executed, the value of i is incremented by 1 and the value of j is decreased by 10.

Just as you need to include more than one expression in a particular field of the for statement, you also need to omit one or more fields from the statement. You can do this simply by omitting the desired field and marking its place with a semicolon. The most common application for the omission of a field in the for statement occurs when no initial expression needs to be evaluated. You can simply leave the init_expression field blank in such a case, as long as you still leave the semicolon:

```objectivec
for ( ; j != 100; ++j )
```

This statement might be used if j were already set.

## while Statement

A for loop that has its looping_condition omitted effectively sets up an infinite loop—that is, a loop that theoretically be executed forever. A loop can be used as long as some other means is used to exit the loop (such as executing a return, break, or goto statement, as discussed in this book).

You can also define variables as part of your initial expression inside a for loop. This is done using the types you've defined in the past. For example, the following can be used to set up a for loop with an integer counter both defined and initialized to the value 1, like so:

```objectivec
for (int counter = 1; counter <= 5; ++counter)
```

The variable counter known only throughout the execution of the loop (it's a local variable) and cannot be accessed outside the loop.

A final for loop variant, for performing what's known as fast enumerations on collections of objects is described in Chapter 15, "Numbers, Strings, and Collections."

## while Statement

The while statement further extends the Objective-C's repertoire of looping capabilities. The syntax of this construct used is as follows:

```objectivec
while ( expression )
  program statement
```

The expression specified inside the parentheses is evaluated. If the result of the evaluation is true, the program statement (or statements, if enclosed in braces), expression is again evaluated. If the result of the evaluation is true, the program statement is again executed. This process continues until expression finally evaluates false, at which the loop is terminated. Execution of the program then continues with the statement that follows program statement.

As an example of its use, the following program sets up a while loop, which merely counts from 1 to 5.

## Program 5.6

```objectivec
// This program introduces the while statement

#import <Foundation/Foundation.h>

int main (int argc, char *argv[]) {
  NSAutleasePool *pool = [NSAutleasePool alloc init];
  int count = 1;

  while ( count <= 5 ) {
    NSLog("%i", count);
    ++count;
  }

  [pool drain];
  return 0;
}
```
