
## Working with Directories

Table 16.2 summarizes some of the methods provided by FileManager for working directories. Many of these methods are the same as for ordinary files, as listed in Table 16.1.

Table 16.2 Common FileManager Directory Methods

| Method | Description |
| --- | --- |
| - (NSString *) currentDirectoryPath | Gets the current directory |
| - (BOOL) changeDirectoryPath: path | Changes the current directory |
| - (BOOL) copyItemAt:toPath: to error | Copies a directory structure (to cannot previously exist) |
| (BOOL) createDirectoryAt:path withIntermediateDirectories: (BOOL) flag attributes: attr | Creates a new directory |
| (BOOL) fileExistsAt:path isDirectory:(BOOL *) flag | Tests if the file exists and is a directory (YES/NO result is stored in flag) |
| (NSArray *) contentOfDirectoryAt:path error: | Lists the contents of the directory |
| - (DirectoryEnumerator *) enumeratorAtPath:path | Enumerates the contents of the directory |
| (BOOL) removeItemAt:path error: | Deletes an empty directory |
| (BOOL) moveItemAt:from toPath: to error | Renames or moves a directory (to can not previously exist) |

Program 16.3 shows basic operations with directories.

## Program 16.3

```objc
// Some basic directory operations
#import <Foundation.h>
int main (int argc, char *argv[]) {
    NSAutoreleasePool *pool = [NSAutoreleasePool alloc init];
    NSString *dirName = @"testdir";
    NSString *path = @"/";
    NSFileManager *fm;
    // Need to create an instance of the file manager
    fm = [NSFileManager defaultManager];

// Get current directory

path = [fm currentDirectoryPath];
NSLog(@"Current directory path is %@", path);

// Create a new directory

if ([fm createDirectoryAtPath:dirName withIntermediateDirectories:YES attributes:nil error:NULL] == NO) {
    NSLog(@"Couldn't create directory!");
    return 1;
}

[pool drain];
return 0;
}
```

## Enumerating the Contents of a Directory

Sometimes you need to get a list of the contents of a directory. This enumeration process can be accomplished using either the `enumeratorAtPath:error:` method. In the former case, each file in the specified directory is enumerated one by time, and by default, if one is a directory, its contents are also enumerated. In the case of `contentsOfAtPath:error:`, the contents of the specified directory are returned in an array. You can prevent recursion by sending `skipDescendants` message to the object. Program 16.4 shows how to use this method.

## Program 16.4

```objc
// Enumerate the contents of a directory
#import <Foundation.h>
int main (int argc, char *argv[]) {
    NSAutoreleasePool *pool = [NSAutoreleasePool alloc init];
    NSString *path;
    NSFileManager *fm;
    DirectoryEnumerator *dirEnum;
    NSArray *Array;

    // Need to create an instance of the file manager
    fm = [NSFileManager defaultManager];

    // Get current directory
    path = [fm currentDirectoryPath];
    NSLog(@"Current directory path is %@", path);

    dirEnum = [fm enumeratorAtPath:path];

    while ((path = [dirEnum nextObject])) {
        if ([fm fileExistsAtPath:path isDirectory:&flag]) {
            NSLog(@"Directory: %@", path);
        } else {
            NSLog(@"File: %@", path);
        }
    }

    [pool drain];
    return 0;
}
```

## Working with Paths: NSPath

NSPath.h includes functions and extensions to NSString to enable you to manipulate pathnames. You should use whenever possible to make your program independent of the file system and locations of particular files. Program 16.5 shows how to use several of the methods provided by NSString.

## Program 16.5

```objc
// Some basic path operations
#import <Foundation.h>
int main (int argc, char *argv[]) {
    NSAutoreleasePool *pool = [NSAutoreleasePool alloc init];
    NSString *fName = @"path.m";
    NSString *path, *tempdir, *extension, *homedir, *fullpath, *components;

    // Get the working directory
    tempdir = NSTemporaryDirectory();
    NSLog(@"Temporary directory is %@", tempdir);

    // Extract the base directory from current directory
    path = [currentDirectoryPath];
    NSLog(@"Base dir is %@", [path lastPathComponent]);

    // Create a full path to the file fileName in current directory
    fullpath = [path stringByAppendingPathComponent:fName];
    NSLog(@"fullpath to %@ %@", fName, fullpath);

    // Get the file extension
    extension = [fullpath pathExtension];
    NSLog(@"extension for %@ is %@", fullpath, extension);

    // Get the user's home directory
    homedir = NSHomeDirectory();
    NSLog(@"Your home directory is %@", homedir);

    // Divide a path into its components
    components = [path pathComponents];

    for (NSString *path in components) {
        NSLog(@"%@", path);
    }

    // Standardize a path
    NSString *upath = @"-steveckochan/progs/../chi16/../path.";
    NSLog(@"%@ => %@", upath, [upath stringByStandardizingPath]);

    [pool drain];
    return 0;
}
```
