# Designing the UI

You may have noticed that you have two sib files in your project: called
MainWindow.xib and the other Fraction_CalculatorViewController.xib. You
don't need to work with the former file at all, so open the latter by selecting it in the
left pane. Design your interface in the View window that appears. This is the view that
associated with your view controller (Fraction_CalculatorViewController) and will be
loaded automatically when your application execution.

> Note
As you learn about iOS application development, you'll see that you can work with
many different views, each of typically controls a view on the iPhone's dis-
play. You'll learn to switch between views and how to send data between them. In
case you'll also have more than just nib files, and typically a separate nib file for each
view controller.

Make the connection from each digit button you lay out in your view to the
eClickDigit:method. This do by Control-dragging each button in turn to the
ClickDigit:method; either it in the interface or implementation file for your view con-
troller. Also, for each digit button, in the Inspector pane set the Tag value to the number
that corresponds to the button's title. For the digit button labeled 0 set the Tag value to
0, for the digit button labeled 1 set the Tag value to 1, and so on.

Draw the remaining buttons in the View window and make the corresponding con-
ections. That's it! Your interface design is done and your fraction calculator application is
ready to be put into action.
