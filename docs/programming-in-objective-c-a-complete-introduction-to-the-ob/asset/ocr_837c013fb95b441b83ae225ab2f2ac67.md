# The Ones Complement Operator

The ones complement operator is a unary operator, and its effect is to simply “flip” the bits of its operand. Each bit of the operand that is a 1 is changed to a 0, and each that is a 0 is changed to a 1. The truth table is provided here simply for the sake of completeness.

| b1 -bl |
| 0 1 |
| 1 0 |

If w1 is a short that is 16 bits long and set equal to hexadecimal 5a2f, then taking the ones complement of this value produces a result of hexadecimal 5ad0:

```
w1  1010 0101 0010 1111  0x5a2f
-w1 0101 1010 1011 0000  0x5ad0
```

The ones complement operator is useful when you don't know the precise bit size of the quantity that you are dealing with in an operation, its use can make a program less dependent on the particular size of an integer data type. For example, to set the low-order bit of an int called w1 to 0, you can AND w1 with an int consisting of all 1s except for a 0 in the rightmost bit. A statement in C such as this one fine on machines on which an integer is represented by 32 bits:

```
w1 & 0xFFFFFFFF;
```

If you are replacing the preceding statement with this one, w1 will be ANDed with the correct value on any machine:

```
w1 & -1;
```

This is because the ones complement of 1 will be calculated and consist of as many leftmost 1 bits as necessary to fill the size of an int (63 bits on a 64-bit integer system).
