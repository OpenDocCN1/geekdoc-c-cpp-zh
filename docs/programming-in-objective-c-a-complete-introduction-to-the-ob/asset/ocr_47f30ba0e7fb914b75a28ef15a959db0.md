Remember, the declaration of argv defines an array that contains elements of type "pointer to char.". As a practical use of command-line arguments, suppose that had developed a program that looks up a word inside a dictionary and prints its meaning. You can use command-line arguments so that the word meaning you want to find be specified at the same time that the program is executed, as in the following command: lookup aerie

This eliminates the need for the program to prompt the user to enter a word because it is typed on the command.

If the previous command executed, the system would automatically pass to the main function to a pointer to the string "aerie" in argv[1]. Recall argv[0] would contain a pointer to the name of the program, in this case, would be "lookup".
