```objective-c
#import <Foundation/Foundation.h>

int main (int argc, char *argv[]) {
    NSAutoreleasePool * pool = [[NSAutoreleasePool alloc] init];
int foo = 10;

void (*printFoo)(void) = 
^void)(void) {
    NSLog ("*foo = %i", foo);
    foo = 20; // ** THIS LINE GENERATES COMPILER ERROR
};
foo = 15;

printFoo ();
NSLog ("*foo = %i", foo);

[pool drain];
return 0;
}
```
```

If you insert the __block modifier before the local variable foo in Program 13.9 that it reads like this:

__block int foo = 10;

and run the program, you'll get these two lines of output:

foo = 10
foo = 20

The first line verifies that the value of foo passed into the block is still the value it had at the time the block was defined. The second line verifies that the block was able to change the value of foo to 20.
This concludes our introduction to blocks. In Chapter 15, you'll find more examples of how they're used.

# Structures

The Objective-C language provides another tool besides arrays for grouping elements. You can also use structures, which form the basis for the discussions in this section.
Suppose you wanted to store a date—say, 7/18/11—inside a program, perhaps to be used for the heading of some program output or for computational purposes. A natural method for storing the date to an integer variable is to assign the date to an integer variable called month, and so on

```
int month = 7, day = 18, year = 2011;
