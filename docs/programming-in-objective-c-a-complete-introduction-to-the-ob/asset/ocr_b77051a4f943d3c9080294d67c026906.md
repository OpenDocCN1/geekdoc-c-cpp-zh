You can use the setString: method to directly set the contents of a mutable string object. After using this method to set mstr to string @"This is string A", the replaceCharactersInRange:withString: method replaces some of the characters in the string with another. The sizes of the strings do not have to be the same; you can replace one string with another of equal or unequal sizes. In the statement

```
[str replaceCharactersInRange: NSNameRange(8, 8) withString: @"a mutable string"]
```

the 8 characters "string A" are replaced with the 16 characters "mutable string"
