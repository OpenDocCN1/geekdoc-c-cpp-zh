If you use Xcode to develop your programs, you have easy access to documentation in several ways. You can get to the main documentation Xcode Help from the menu. This window enables you to easily search and access documentation that is stored locally on your computer or is available online. If you are editing a file in Xcode and want to get immediate access to the documentation for a particular header file, method, class, or variable you can simply place your cursor to search for it, hold down the Option key, and Click. You'll get a quick summary of whatever is selected. Figure 14.2 shows a panel that appears when the mouse cursor is located in the text NSAAutleasePool and the Option key is pressed and the mouse clicked.

In the right corner of the pane that appears you'll notice two icons: the first is of a book, the second is of a page with the letter h in it. If you click on the former, Xcode will search the documentation for the selected class, protocol, definition, or method. If you click on the latter, you'll get the header file that contains the definition for the selected item. This Quick Help pane also gives you quick access through hyperlinks, where available, to other references, related documents, and sample code
