# Chapter 2 Programming in Objective-C

The program statement in main looks like this:
return 0;

It says to terminate execution of main and to send back, or return, a status value of 0.
By convention, 0 means the program ended normally. Any nonzero value typically\means some problem occurred—for example, perhaps the program couldn't locate a file
it it needed.

If you're using Xcode and you glance at your output window (refer to Figure 2.9),
You'll recall that the following displayed after the line of output from NSLog:

Program exited with status value:0.

You should understand what that message means now.
Now that we have finished debugging your first program, modify it to also display
the phrase "And programming in Objective-C is even more fun!" You can do this by
sim adding another call to the NSLog routine, as shown in Program 2.2. Remember
tevery Objective-C program statement must be terminated by a semicolon.

# Program 2.2

```
#import <Foundation.h>

int main (int argc, const char *argv[]) {
    NSAutleasePool *pool = [NSAutleasePool alloc];

    NSLog("Programming is fun!");
    NSLog("And programming in Objective-C is even more fun!");

    [pool drain];
    return 0;
}
```

If you type in Program 2.2 and compile and execute it, you can expect the fol-
lowing output (again, without showing the text that NSLog normally prepends to
output:

# Program 2.2 Output

Programming is fun!
Programming in Objective-C is even more fun!

First, let's talk about a special two-character sequence. The backslash (\) and the letter n
are known collectively as the newline character. A newline character tells the system to
precisely what its names imply: go to a new line. Any characters to be printed after the
newline character then appear on the next line of display. In fact, the newline character
is very similar in * the carriage return key on a typewriter (remember?).
