# Chapter 5 Program Looping

The format string tells scanf what types of values are to be read from the console (or terminal window, if you're compiling your programs using the Terminal application). As NSLog, the %i characters are used to specify an integer value.

The second argument to the routine specifies where the value that the user types is in store. The & character before the variable name is necessary in this case. Rather than supplying the value of the variable, we instead specify where the value that is entered to be stored. Don't worry about this right now. We discuss this character, which is an actual operator, in great detail when we talk about pointers in Chapter 13.

Given the discussion, you can now see that the scanf call from Program 5.4 specifies that an integer value is to be read and stored into the variable. This value represents the triangular number the user has calculated.

After the user has typed in this number (and pressed the Enter key on the keyboard to signal that type of the number is completed), the program calculates the requested triangular number. This is done in the same way as in Program 5.2; the only difference is that instead of using 200 as the limit, number is used as the limit.

# Note

Pressing the Enter key on a keyboard with a numerical keypad may not cause the number you enter to be sent to the program. Use the Return key on your keyboard instead.

After the desired triangular number has been calculated, the results are displayed. Execution of the program is then complete.

# Nested for Loops

Program 5.4 gives the user flexibility to have the program calculate any triangular number that is desired. But suppose the user had a list of five triangular numbers to be calculated? In such a case, the user could simply execute the program five times, each time typing the next triangular number from the list to be calculated.

Another way to accomplish the goal, and a far more interesting method, as far learning about Objective-C is concerned, is to have the program handle the situation. This can be accomplished by inserting a loop into the program to repeat the entire series of calculations five times. You can use the for statement to set up such a loop. Program 5.5 and its associated output illustrate this technique.
