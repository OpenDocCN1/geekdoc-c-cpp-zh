# An iPhone Fraction Calculator

The next example is a bit more involved, but the concepts from the previous example equally apply. We are not going to show all the steps to create this example, but rather give a summary of the steps and an overview of the design methodology. Of course, we'll show all the code.

First, let's see how the application works. Figure 21.17 shows what the application looks like in the simulator after launching.

The calculator application allows you to enter fractions by keying in the numerator, pressing the key labeled Over, and then keying in the denominator. To enter the fraction 2/5, you press 2, followed by Over, followed by 5. You'll note that, unlike other calculators, this one actually shows the fraction in the display, as 2/5 is displayed as 2/5.

After keying in one fraction, you then choose an operation—addition, subtraction, multiplication, or division—by pressing the appropriately labeled key +, –, ×, or ÷ respectively.

After keying-in the second fraction, you then complete the operation by pressing the = key, just as you would with a standard calculator.
