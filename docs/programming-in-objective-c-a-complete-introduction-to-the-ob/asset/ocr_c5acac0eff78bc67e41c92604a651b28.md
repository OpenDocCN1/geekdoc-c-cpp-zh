# Explanation of Your First Program

main is a special name that indicates precisely the program is to begin execution. The reserved word int precedes main specify the type of value return

Now that you have identified the system, you are ready to specify precisely what this routine is to perform. This is done by enclosing all the program statements of the routine within a pair of curly braces. In the simplest case, a statement is just an expression that is terminated with a semicolon. The system treats all the program statements included between the braces as part of the main routine. Program 2.1 has four statements.

The first statement in Program 2.1 reads

```
NSautoreleasePool pool = [NSautoreleasePool alloc] init;
```

It reserves space for an autorelease pool. We do this thoroughly in Chapter 17,"Memory Management." Xcode puts this line into your program automatically as part of the template, so leave it there for.

The next statement specifies that a routine NSLog is invoked, or called. The parameter, or argument, to be passed or handled to the NSLog routine is the string of characters:

```
"@Programming is fun!"
```

Here, the @ sign immediately precedes a string of characters enclosed in a pair of double quotes. Collectively, this is known as a constant NSString object.

> Note
If you have C programming experience, you might be puzzled by the leading @ character. Without that leading @ character, you are writing a constant C-style string; with it, you are writing an NSString object. More on this topic in Chapter 15.

The NSLog is a function in the Objective-C library that simply displays or logs its argument (or arguments, as you will see shortly). Before doing so, it displays the date and time the routine is executed, the program name, and some other numbers we do not describe here. Throughout the rest of this book, we don't bother to show this text that NSLog inserts before your output.

You must terminate all program statements in Objective-C with a semicolon (;). This is why a semicolon appears immediately after the closed parenthesis of the NSLog call.

Before you exit your program, you should release the allocated memory pool (and objects that are associated with it) with a line like the following:

```
[pool drain];
```

Again, Xcode automatically inserts this line into your program for you. Again, we defer detailed explanation of what this does until later.
