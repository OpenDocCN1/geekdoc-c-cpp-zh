Here's a statement that will return the path to a file called instructions.txt that's stored
in your application bundle:

```
NSString *txtFilePath = [[NSBundle mainBundle] 
pathForResource:@"instructions" ofType:@"txt"];
```

The mainBundle gives you the directory where the application bundle is located.
You can use this for Mac OS X or iOS applications.
pathForResource:ofType will locate the file path within that directory
and return a path to that file. You can subsequently read the contents of that file into your
application with a statement like this:

```
NSString *instructions = [[NSString stringWithContentsOfFile:txtFilePath
encoding: NSTextStringEncoding] error:&NULL];
```

If you want to load all the JPEG images with the file extension jpg in the images-irectory of your application bundle, you can use the
pathsForResourcesOfType:inDirectory: method like so:

```
NSArray *births = [[NSBundle mainBundle] pathsForResourcesOfType:@"jpg"
inDirectory:@"images"];
```

The method returns an array of path names. If your JPEG's are not stored in a subdir-ectory in your application, you can specify "" as the value of the inDirectory: parameter.
There are more methods in theBundle class you'll want to learn about. Check
y documentation for details.
