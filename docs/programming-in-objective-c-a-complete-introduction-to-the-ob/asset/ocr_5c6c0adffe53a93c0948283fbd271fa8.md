The remaining values are set to 0. Note that, in this case, the inner pairs of braces are required to force the correct initialization. Without them, the first two rows and the first two elements of the third row would have been initialized instead. (Verify for yourself that this would be the case.)

# Functions

NSLog routine is an example of a function that you have used in every program. Indeed, every program has used a function called main. Let’s go back to the first program you wrote (Program 2.1), which displayed the phrase “Programming is fun.” at the terminal:

```
#import <Foundation/Foundation.h>

int main (int argc, char *argv[])
{
    AutoreleasePool *pool = [[AutoreleasePool alloc] init];

```

This function, called printMessage, produces the same output:

```
void printMessage(void)
{
    NSLog("@Programming is fun.");
}
```

- The type of value it returns
- Its name
- The number and type of arguments it tells the compiler that

The first line of the printMessage function definition tells the compiler that printMessage is the name of the function and it returns no value (the first use of the keyword). After telling the compiler that printMessage doesn’t return a value, the second use of the keyword void says that it takes no arguments.
