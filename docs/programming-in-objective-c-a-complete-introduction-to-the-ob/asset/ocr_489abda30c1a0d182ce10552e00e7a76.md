# Managing Files and Directories: NSFileManager 371

Table 16.1 Common NSFileManager Methods

| Method | Description |
| --- | --- |
| - (NSData *) contentsAtPath: path | Reads data from a file |
| - (BOOL) createFileAtPath: path contents:(NSData *) data attributes: attr | Writes data to a file |
| - (BOOL) removeItemAtPath: path error: err | Removes a file |
| - (BOOL) moveItemAtPath: from toPath: to error: err | Renames or moves a file (to cannot already exist) |
| - (BOOL) copyItemAtPath: from toPath: to error: err | Copies a file (to cannot already exist) |
| - (BOOL) contentsAtPath: path1 andPath: path2 | Compares contents of two files |
| - (BOOL) fileExists:path | Tests for existence |
| - (BOOL) isReadableFile:path | Tests whether file exists and can be read |
| - (BOOL) isWritableFile:path | Tests whether file exists and can be written |
| - (NSDictionary *) attributesOfItem:path error: err | Gets attributes for file |
| - (BOOL) setAttributesOfAtPath: attr error: err | Changes file attributes |

Each of the file methods is invoked on an NSFileManager object that is created by sending a defaultManager message to the class

fm = [NSFileManager defaultManager];
For example, to delete a file todolist from the current directory, you would first create the NSFileManager object as shown previously and then invoke removeItemAtPath: method, like so:

```
if ([fm removeItemAtPath:@"todolist" error: NULL] == NO) {
    NSLog("@Couldn't remove file todolist");
    return 1;
}
```
