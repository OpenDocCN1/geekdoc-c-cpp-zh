# Mastering the SAS DS2 Procedure: Advanced Data Wrangling Techniques

To execute the SQL statement using a SQLMT package, we use the EXECUTE method.

```
proc ds2;
data _null;
  decl package sqlstmt make (
    'create table work.dates(DTM double, DT double, T double)');
  decl package sqlstmt apnd (
    'insert into work.dates(DTM,DT) VALUES (?,?,?)'
    ;SAS_Datetime SAS_Date SAS_Time]);
  method init();
    make.execute();
end
method run();
  set crs.dates;
  apnd.execute();
end
enddata;
run;
quit;
```

The SQLMT package also provides the FETCH method for interrogating a result set produced by executing a query, as well as the BINDRESULTS method for populating an ordered list of PDV variables by the query results.

The BINDRESULTS method need only be called once. It uses the information provided via the second argument during SQLMT package instantiation to create a map for populating PDV variables from columns in the query results. You must execute this method once before using FETCH to retrieve values.

The FETCH method reads a row from the result set and produces a zero (0) return code if a row was retrieved. A nonzero result indicates either that there was an error (1) or no more result sets are available (2). This method is typically used in a DO WHILE or DO UNTIL expression.

```
proc ds2;
data _null;
decl package sqlstmt qry{
  'select * from crs.dates';
  decl double DTM having format datetime;
  decl double DT having format mmddyy10;
  decl double T having format timeampm.
  method init();
    query.execute();
  query.bindresults({DT T});
    do while (qry.fetch(dt) = 0);
      put dt= dt= t=;
    end
end;
enddata;
run;
quit;
```
