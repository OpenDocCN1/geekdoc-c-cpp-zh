The concepts of null and missing are so fundamental to how data is processed and so radically different from each other, PROC DS2 actually has two separate operating modes on which concept for handling nonexistent data is given: SAS mode and ANSI mode. But I launch into a detailed description of missing null, I want to make clear that, in DS2, only those data types that are available in Base SAS DATA step and DS2 programs (DOUBLE and CHAR) are capable of containing missing values. Variables of any other data type are strictly ANSI in their behavior. They will always contain null when assigned a nonexistent value.

# 3.3.42 PROC DS2 SAS Mode

SAS mode is the default mode for PROC DS2, and thus it is never specified in the PROC DS2 statement. In SAS mode, expressions resolving to an unknown value produce SAS missing values as an intermediate result. When those are assigned to CHAR or DOUBLE variables, those variables will contain a SAS missing value.
