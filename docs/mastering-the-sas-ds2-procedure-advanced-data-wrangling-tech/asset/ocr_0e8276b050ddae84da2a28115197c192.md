# Chapter 1: Getting Started 5

Here is what you will be able to do after you finish this book:

+   * identify the types of processes for which the language was designed and understand the
conditions indicating that DS2 is a good choice when attempting to improve the
performance of executing DATA step processes
* identify which programming statements and functions are shared between DATA steps
and DS2 programs
* identify the DATA step functionality not available in DS2 and why it is not
included in the DS2 language
* know what new DS2 program functionality is not available in the traditional DATA step
* manipulate ANSI data types in a DS2 program
* understand the implications of handling data that contains both SAS missing and ANSI
null values in the same process
* convert a Base SAS data manipulation process from DATA step to a DS2 program
* understand the DS2 system methods and how they relate to traditional DATA step
programming constructs
* create DS2 methods, extending the functionality of the DS2 language
* store DS2 methods in packages and reuse them in subsequent DS2 programs
* use DS2 programs to create object-oriented programs
* use predefined DS2 packages to add functionality to your DS2 data programs
* create DS2 thread programs and execute them from a DS2 program for parallel
processing of data records
* use BY-GROUP and FIRST.variable and LAST.variable processing in a DS2 program
or thread to perform custom data summarizations, without requiring a preset of the data
* determine whether your system has the capability to execute DS2 programs in-database
and, if so, execute your DS2 thread programs distributed on an MPP DBMS platform

# 1.1.2 Prerequisite Knowledge

This book was written with the seasoned Base SAS programmer in mind. Before diving in, you'll\want to be familiar with the key concepts listed below. You can acquire the prerequisite
knowledge from other SAS Press books, such as An Introduction to SAS University Edition by
Ron Cody or The Little SAS Book: A Primer by Lara Deliche and Susan Slaughter.

+   * DATA step programming, in general
* SAS libraries
* accessing data with a LIBNAME statement
* reading and writing SAS data sets
* the role of the program data vector (PDV) in DATA step processing
* conditional processing techniques
* arrays
* iterative processing (DO loops)
* macro processing, in general
* assigning values to macro variables
