# 2.3.2 Considerations

+   1. Section consists of a DO group of statements that will be executed only when _N =1. The automatic variable _N_ counts the number of times the DATA step has iterated, so this block will execute only one time, when the DATA step starts execution.
2. Section 2 consists of unconditionally executed statements. These statements execute once for every observation in the input data set. In this section, the SET statement uses the END= to create last, a temporary variable containing an end-of-file indicator. The variable last is initialized to zero and remains 0 until the SET statement reads the last observation of last data listed, when it is set to 1. As an automatic variable, last is automatically flagged for DROP, and will not appear in the output data set.
3. Section 3 consists of a DO group of statements that will execute only if the variable last contains a value other than 0 or missing.

If we think about this, Section 1 code sounds like a great candidate for the INIT system method, Section 2 for the RUN method, and Section 3 for the TERM method.

# 2.3.3 The Equivalent DS2 Data Program

Here is a DS2 data program equivalent to the original SAS DATA step:

```
proc ds2;
data _null_;

/* Section 1 */
method init();
  put '*********';
  put 'Starting';
  put '*********';
end;

/* Section 2 */
method run();
  set crs.banks;
  put Bank Rate;
end;
```
