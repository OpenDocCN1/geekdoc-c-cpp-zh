```
method interest(IN_OUT double Amount, double Rate, int Years);
dcl int i;
do i=1 to Years;
  Amount=SUM(Amount,Amount*Rate);
end;
method run();
  set crs.banks;
  do Duration=1 to 5 by 4;
    Total=5000;
    interest(Total,Rate,Duration);
    output;
end;
end;
```

The user-defined interest method was used to perform the calculations using the interest rates on file for each bank in the data set.

What would we do differently if we wanted our method to return a value like a function instead of modifying one of its parameters? This version would have no IN_OUT parameters and, when called, would have to be called in an expression capable of processing the returned result. Let’s make a version that returns a value and is called from an assignment statement.
