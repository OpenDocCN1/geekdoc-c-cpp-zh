To parse the JSON text using our JSON package instance, we'll use a DO UNTIL loop to iteratively execute the GETNEXTTOKEN method until we get a nonzero return code, indicating we have parsed all of the text.

```
do until (rc ne 0);
  j.getNextToken(rc, token, tokenType, parseFlags);
  output;
end;
```
