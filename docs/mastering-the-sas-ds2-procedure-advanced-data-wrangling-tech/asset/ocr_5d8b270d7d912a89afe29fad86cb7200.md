# 5.5 The Matrix Package

# 5.5.1 General

Matrices are two-dimensional arrays of numeric or character values, arranged in rows and columns. The matrix package provides a lot of SAS/IML functionality within DS2 without requiring the purchase of additional product licenses methods to perform inversion, arithmetic, and logical operations on your matrix. Data is loaded into a matrix package from array or from external data. To produce an output, the matrix must first be output to an array, by writing the entire matrix to the array bloc or updating the matrix iteratively, one row at a time. The array data can then be written out as a DS2 result set.

# 5.5.1.1 Declaring, Instantiating, and Loading a Matrix

A matrix can have values loaded from an array instantiation, but at compile time the array will not yet have values loaded. Because of this, it is common to declare the matrix package delay instantiation until runtime time by using the _NEW_ operator. The code would look something like this:

```
dcl double a[2, 2];
dcl package m;
method init();
/* Load array values */
a :=(1, 9, 4, 16);
/* Instantiate matrix and load from array */
m=new_new matrix(a, 2, 2);
end;
```

Alternatively, the package could be instantiated at compile time and the array values loaded later in the program using the matrix package's IN method:

```
dcl double a[2, 2];
dcl package matrix m(2,2);
method init();
/* Load array values */
a :=(1, 9, 4, 16);
/* Load matrix from array */
m.in(a);
end;
```

To load data from a data table, load VARARRAY values using the matrix package's IN method:

```
data x;
v1=1;v2=2;output;
v1=4;v2=16;output;
run;

/* Get rows and columns info into marco variables */
proc sql noprint;
select nlobs
into :rows trimmed
,:columns trimmed
```
