# Chapter 3: DS2 Data Program Details

Here are the other pertinent rules for missing and null values while operating DS2 in SAS mode:

+   1. Missing values are automatically converted to null when assigned to a variable of any data type other than CHAR or DOUBLE.
2. Other times when null values are automatically converted to missing:
   a. used in expressions containing CHAR or DOUBLE values
   b. when assigned to a CHAR or DOUBLE type variable
   c. when passed to a Base SAS function as a parameter value

+   3. In expressions comparing a character value to a single blank, the single blank is interpreted as a SAS character missing value.

Executing program Ch3.3.4.2.sas demonstrates the handling of SAS missing and ANSI null values in PROC DS2 operating in SAS mode.

SAS Log:

```
*** From SAS Data Set ***
*** DS2 CHAR Values - SAS Mode ***
C is = ' 
missing(C) is true.
null(C) is not true.

*** DS2 DOUBLE Values - SAS Mode***
N is = ' 
missing(N) is true.
null(N) is not true.

*** SAS Mode Using ANSI VARCHAR and Decimal Variables ***
*** DS2 VARCHAR Values ***
Var is not = ' '
missing(Var) is true.
null(Var) is not true.

*** DS2 DECIMAL Values ***
Dec is = ' 
missing(Dec) is true.
null(Dec) is not true.
```

Note that the CHAR and DOUBLE values behave just as you would expect-both evaluate as to the constant missing representation, the Base SAS MISSING function evaluates them both as missing, and the DS2 NULL function sees them both as null.

VARCHAR null values are not equal to the constant missing value, the Base SAS MISSING function returns TRUE. This is because all null values are automatically transformed to missing before being passed to a Base SAS function. As expected, the DS2 NULL function evaluates VARCHAR as null.

DECIMAL null values are equal to the constant missing value, are evaluated as missing by the SAS MISSING function for the reasons previously stated, and evaluated as null by the DS2 NULL function.
