# 114 Mastering the SAS DS2 Procedure: Advanced Data Wrangling Techniques

Let's run the data program and check the log to see whether it might be CPU bound:

```
proc ds2;
data scored/overwrite=yes;
 dcl package crs.Scoring s;
 dcl double FinalScore;
 dcl bigint Count;
 drop Count;
 keep id FinalScore;
 method run();
  set crs.campaign;
 /*Instantiate the SCORING package with the values of the
 variables = *;
 s= new;
crs.Scoring(IM_DemMedHomeValue, IM_GiftAvgAll, IM_PromCntNall);
 /* Call the SCORE method to score the data */
 s.Score(FinalScore);
 Count=1;
end;
method term();
  put 'The DATA step processed ' Count ' observations.';
enddata;
run;
quit;
```

Here is the SAS log excerpt from the DS2 data program:

| DATA step processed 10000 observations. |
 NOTE: Execution succeeded. 10000 rows affected. |
 NOTE: PROCEDURE DS2 used (Total process time): |
 real time 0.47 seconds |
 cpu time 0.46 seconds |

Real time is very close to CPU time, so it's quite possible the process is CPU bound. Let's convert the data program to a thread, execute the thread, and compare the performance:

```
proc ds2;
thread ScoreIt / overwrite=yes;
 dcl package crs.Scoring s;
 dcl double FinalScore;
 dcl bigint Count;
 drop Count;
 keep id FinalScore;
 method run();
  set crs.campaign;
 /*Instantiate the SCORING package with input values */
s=new_ crs.Scoring
 (IM_DemMedHomeValue, IM_GiftAvgAll, IM_PromCntNall);
 /* Call the SCORE method to score the data */
 s.Score(FinalScore);
 Count=1;
end;
```
