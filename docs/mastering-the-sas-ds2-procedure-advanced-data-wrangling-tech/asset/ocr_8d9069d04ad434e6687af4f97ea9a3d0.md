# 5.7 The TZ (Time Zone) Package

# 5.7.1 General

DS2 can process ANSI date and time values of the data types DATE, TIME, and TIMESTAMP.
These data types are non-coercible, which means that, when processing SAS and RDBMS data together, it is necessary to explicitly convert SAS date, time, and datetime values to ANSI dates, time, and timestamp values using the TO_DATE, TO_TIME, and TO_TIMESTAMP functions. However, these functions do not take zones into consideration. You can think of each instance of the TZ package as a clock for a specific time zone, with methods to easily obtain details about local time as such:

+   - current time
- coordinated universal time (UTC)
- time zone ID
- time zone name
- time zone offset from UTC for a specified local time
- time zone offset from local time for a specified UTC time

The TZ package processed and returns DOUBLE SAS date, time, and datetime values.

# 5.7.1.1 Declaring, Instantiating, and Using a TZ Package

Once instantiated, package methods are used to obtain information about time. As a quick example, this program uses two instances of the TZ package to provide the hometown of Fortaleza, Ceará, Brazil:

```
proc ds2;
  null;
  dcl package tz L();
  dcl package tz F('America/Fortaleza');
  dcl double Local having format datetime;
  method init();
    Local=L.getLocalTime();
    Fortaleza=F.getLocalTime();
    put Local=Fortaleza=;
  end;
endata;
run;
quit;
```

| Local=17JAN16:09:21:30 Fortaleza=17JAN16:11:21:30 |
