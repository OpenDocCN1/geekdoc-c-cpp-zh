## 5.5 The Matrix Package

### 5.5.1 General

Matrices are two-dimensional arrays of numeric or character values, arranged in rows and columns. The matrix package provides a lot of DS2 operations. Data can be offloaded from a matrix to an array, or from an array to a matrix.

### 5.5.1.2 Declaring, Instating, and Loading a Matrix

A matrix can be instantiated at compile time, but not yet loaded until runtime. The code would look like this:

```sas
dcl double a[2];
dcl package m;
method init();
/* Load values */
a :=(1, 9, 4, 16);
end;
```

Alternatively, the matrix can be instantiated and loaded later using the IN method:

```sas
dcl double a[2];
dcl package m(2,2);
method init();
/* Load values */
a :=(1, 9, 4, 16);
end;
```

To load data from a table, using the matrix's IN method:

```sas
data x;
v1=1;v2=2;output;
v1=4;v2=16;output;
run;
```

To get rows and columns into variables:

```sas
proc sql noprint;
select nobs
into :rows :columns
from dictionary.tables
where libname='WORK'
and memename='X';
quit;
```

```sas
proc ds2;
data _null;
  varray double a[2];
  dcl package m(&rows,&columns)
  method run();
  /* Read data, load each row of matrix from varray*/
  set x;
  m.min(a, _n);
enddata;
run;
```

### 5.5.1.3 Manipulating and Retrieving Values from a Matrix

A matrix is manipulated using one of the methods available in the matrix package. Data can be moved from a matrix to a declared array or a variable array. If a variable array is used, the data is loaded into PDV variables and becomes part of program result set.

In the following example, values are loaded into array a, and the values of array a's elements are printed in the SAS log. Subsequently, the IN method is used to populate matrix from the values in array. Matrix m then transposed using the TRANS method, and its elements are passed back to array a using the TOARRAY method. The elements of array a are once again written to the SAS log. Finally, a square root transformation is performed on all the elements of matrix m, and the element values are once again passed to array a using the TOARRAY method.

```sas
proc ds2;
data _null;
  dcl double a[2, 2];
  dcl package m(2,2);
method init();
  a:=1, 9, 4, 16);
  put 'before: ' a[*]=;
  m.min(a);
  m.trans(a);
  m.toarray(a);
  put 'Trans: ' a[*]=;
  m.sqrt(sqrt);
  m.toarray(a);
  put 'SQRT ' a[*]=;
enddata;
run;
quit;
```
