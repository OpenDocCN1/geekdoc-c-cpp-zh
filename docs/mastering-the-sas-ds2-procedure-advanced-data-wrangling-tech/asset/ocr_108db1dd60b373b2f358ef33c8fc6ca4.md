# 3.2.2 The “Six Subtle Dissimilarities”

Though many things work exactly the same in a traditional DATA step and a DS2 data program, there are some differences that are quite subtle and be kept in mind when programming in DS2. Let’s go over the primary cutcuts, which I’ve come to refer to as the six subtle dissimilarities.

# 3.2.2.1 All Executable Statements Must Be Part of a Method Code Block

Executable statements in the global program space result in a syntax error:

```
proc ds2;
data _null_;
set crs.one_day;
put _all_;
enddata;
run;
quit;
```
