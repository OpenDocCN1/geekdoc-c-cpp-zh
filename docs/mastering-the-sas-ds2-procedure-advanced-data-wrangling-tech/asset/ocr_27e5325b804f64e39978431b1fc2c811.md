We will be able to search as JSON, and such API calls can generate query parameters. The parameter string follows the URI for the API method and is delimited by a question mark (?). Parameter name-value pairs follow, separated by ampersands (&). For example, to use the Kiva api and request HTML results for loans from South America to reach females who are currently fundraising, and to return the results in descending order, with five results per page, here is the properly formed URI: http://api.kivaws.org/loans/search.html?region=sa&gender=female&status=fundraising&sort=newest&page=5
