As you can see, the lamp object is working just like a real. We can move it to a new location (give it a new name), turn it on or off directly toggle the status, and test to see whether the lamp is on or off. I consider our QA testing a success.

The beauty of objects in programming is, once defined and tested, we can reuse them over and over as building blocks for new objects or new applications without having to repeat QA testing on the established objects. We can now use the lamp package as object for building a more complex house package. Let's build a house object that contains four lamps and control the house from another DATA program:

```
proc ds2;
package work.house /overwrite=;
dcl varchar(15) houseName;
dcl package work.lamp desk('Desk','On');
dcl package work.lamp floor('Floor','Off');
dcl package work.lamp oven('Oven','Off');
dcl package work.lamp task('Task','On');
method house();
nhouseName='****Unnamed';
    put '**** Instantiating house ' houseName$quote. '****';
end;
method house(varchar(15) name);
houseName=name;
    put '*** Instantiating house ' houseName$quote. '***';
end;
method statusCheck();
dcl varchar(33) status;
put;
    put 'The status of the lamps in ' houseName 'house:';
status=desk.lamp.getStatus();
    put 'Desk lamp is ' status;
status=floor.lamp.getStatus();
    put 'Floor lamp is ' status;
status=oven.lamp.getStatus()();
```
