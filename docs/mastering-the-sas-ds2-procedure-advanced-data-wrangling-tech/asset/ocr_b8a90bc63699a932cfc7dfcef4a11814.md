# 5.5.1.2 Manipulating and Retrieving Values from a Matrix

A matrix is manipulated using one of the methods available in the matrix package. Data can be offloaded from a matrix to a declared array or a variable array created with a VARARRAY statement. If a variable array is used, the data is loaded into PDV variables and becomes part of data program result set.

In the following example, values are loaded into array a, and the values of array a's elements are printed in the SAS log. Subsequently, the IN method is used to populate matrix from the values in array a. Matrix m then transposed using the TRANS method, and its elements are passed back to array a using the TOARRAY method. The elements of array a are once again written to the SAS log. Finally, a square root transformation is performed on all the elements of matrix m, and the element values are once again passed to array a using the TOARRAY method. The values of elements of array a in the SAS log show the results of the transformation.

```
proc ds2;
data _null;
  dcl double a[2, 2];
  dcl package matrix m(2,2);
method init();
  a:=1, 9, 4, 16);
  put 'before: ' a[*]=;
  m.min(a);
  m.trans(a);
  m.toarray(a);
  put 'Trans: ' a[*]=;
  m.sqrt(sqrt);
  m.toarray(a);
  put 'SQRT ' a[*]=;
enddata;
run;
quit;
```
