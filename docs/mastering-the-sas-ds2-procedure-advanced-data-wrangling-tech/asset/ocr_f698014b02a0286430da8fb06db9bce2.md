| Data Type | Class | Description |
| --- | --- | --- |
| DECIMAL(p,s) | Exact fractional numeric | Signed, exact, fixed decimal numeric value of userdefined precision and scale. Precision (p) determines the maximum number of significant digits, up to a maximum of 52. Scale (s) determines how many of the significant digits are reserved for the fractional portion of the value. NUMERIC(p,s) is an alias for DECIMAL |
| BIGINT | Integer numeric | Signed, exact numbers up to 19 significant digits. |
| INTEGER | Integer numeric | Signed, exact numbers up to 10 significant digits. |
| SMALLINT | Integer numeric | Signed, exact numbers up to 5 significant digits. |
| TINYINT | Integer numeric | Single-byte signed, exact numbers between -128 and 127. |
| BINARY(n) | Binary | Fixed-length binary data, $n =$ number of bytes allocated to store data in every row. |
| VARBINARY(n) | Binary | Variable-length binary data, uses just enough bytes to store the actual value in each row of data up to a maximum of $n$. |
| TIME | Time | Stores ANSI time values. |
| DATE | Date | Stores ANSI date values. |
| TIMESTAMP | Datetime | Stores ANSI timestamp (datetime) values. |

ANSI TIME, DATE, and TIMESTAMP values should not be confused with SAS TIME, DATE, and DATETIME values which are all stored as doubleprecision-floating-point numbers and adherence to external rules to be properly interpreted. SAS TIME values are actually SAS numeric values indicating the number of seconds between midnight and the time being expressed. SAS DATE values indicate the number of days between January 1, 1960, and the date being expressed. SAS DATETIME values are numeric values indicating the number of seconds since midnight, January 1, 1960, and the date and time being expressed. These values are not interchangeable with ANSI DATE, TIME, and TIMESTAMP values.

With 17 different data types available, you can begin to see that automatic data type conversion will be happening more frequently in a DS2 data program than ever did in a traditional SAS DATA step.
