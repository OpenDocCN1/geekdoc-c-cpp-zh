# 5.3.3 Hash Iterator Package Example

The hash iterator enables you to retrieve data from a hash object in forward or reverse key order. In this example, we will use two hash objects—one for price information and the other for product informationand a hash iterator on the price object. The hash iterator methods that we will use are FIRST, NEXT, LAST, and PREV, allow us to retrieve the first, next, last, and previous records from the hash object that is associated with the hash iterator. Methods all produce a zero return code, indicating successful execution.
