DS2 arrays with both a special array assignment operator (:=) and also with a method of referencing elements that is designed to simplify your programming. The := operator positionally assigns a list of values to the corresponding elements of an array or assigns values from one array to another.

```
proc ds2 ;
data;
/* Array of PDV variables - N1-N5 */
varray char(1) V[6];
/* Temporary array - elements are not in the PDV */
dcl char(1) T[2,3];
method init();
/* Assign a list of values to array V elements */
V=('A','B','C','D','E','F');
end;
method run();
/* Assign array V elements to array T */
T=V;
PUT T[*];
PUT V[*]=;
end;
enddata;
run;
quit;
```
