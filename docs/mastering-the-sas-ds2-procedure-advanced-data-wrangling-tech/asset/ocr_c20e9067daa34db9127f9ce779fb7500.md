# 5.4.3 JSON Package Specifications

The JSON package provides an interface to create and parse JSON text. The names of the
methods used to process JSON text all with the prefix WRITE and are generally referred to
as AS JSON package WRITE methods accurately calculate
requests in memory. The generated JSON can be retrieved into text variables. This could be useful
for creating JSON data for use with the HTTP POST method, but for writing JSON to
files, PROC JSON will be the tool to use. I'm excited about the JSON package parser, which
will enable us to parse the JSON text from our API calls.

# 5.4.3.1 Reading a JSON Parser Instance

To use the JSON package, we must first declare an instance of the package. We'll also declare
variables to handle the data that is out of the response body:

```
dcl package json();
dcl nchar(1024) token;
dcl int jsonType;
```

After initializing the package, the variables we'll all need to be preparing the instance
to receive and parse JSON text. The CREATEPARSER method creates an instance of the JSON
parser, and executing this method is the first step preparing to parse. The next step is
to execute the SETPARSERINPUT method, which accepts a single parameter specifying the JSON
text to be parsed. All of these methods return return codes, indicating that all went welln
