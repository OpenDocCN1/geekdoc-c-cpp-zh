# 7.4.2 SAS Support Communities

My favorite destination for seeking (and sometimes providing) answers is the SAS Support website at http://communities.sas.com. There are many sub-communities available, but most of the DS2 activity appears in the SAS Programming and General SAS Programming communities (under SAS Programming). The SAS Support forums are very active with seasoned users, newcomers, and SAS staff all eager to help each other.

Another excellent community resource is the Wiki at http://www.sascommunity.org. Contributors come from all the world and all walks of life. The "saspedia" portion is a unique, source of information about a wide array of SAS techniques.

When posing a question to an online community, you can get help more quickly if you prepare properly. Post your question clearly and succinctly. Provide a program that demonstrates your problem as simply as possible. And if you want a quicker response, include a sample data set. The best way to provide sample data is to include a LITTLE DATA step that produces the sample data, so the folks on the can run your code for themselves, using the same data, and be able to quickly reproduce your results. I wrote a blog about this "Jedi SAS Tricks: The DATA to STEP Macro" which included code for the data2datastep macro. This macro can create a DATA step to reproduce a data set that you specify. I've included the code for this macro in the ZIP file containing the data for this book. Look for the program file named data2datastep. The macro is self-documenting, but you can read more about the macro works at http://go.gl/spQojuc. Please note that these shortened URLs are sensitive, make sure you use a capital Q.

# 7.4.3 SAS Technical Support

Any licensed user can contact SAS Technical Support with his or her SAS questions. There is a guide to help you optimize your interactions with SAS Technical Support.

+   * What can I expect from SAS Technical Support?
  See http://support.sas.com/techsup/support.html
* How can I contact SAS Technical Support?
  a. Use the telephone for business-critical issues: +1 (919) 677-8008.
  b. Use the web form for all other issues:
  http://support.sas.com/ctx/supportform/createForm
* What information will I need when contacting SAS Technical Support?
  * If you are using a commercial version of SAS, your company name.
  * The country in which your SAS software is licensed.
  * Your name, email address, and phone number.
