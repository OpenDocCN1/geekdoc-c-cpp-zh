## 5.5 矩阵包

### 5.5.1 通用

矩阵是排列好的数值或字符值的二维数组。矩阵包提供了许多 DS2 操作。数据可以从矩阵到数组，也可以从数组到矩阵。

### 5.5.1.2 声明、实例化和加载矩阵

矩阵可以在编译时实例化，但在运行时之前尚未加载。代码如下：

```sas
dcl double a[2];
dcl package m;
method init();
/* 加载值 */
a:=(1, 9, 4, 16);
end;
```

或者，可以使用 IN 方法稍后实例化并加载矩阵：

```sas
dcl double a[2];
dcl package m(2,2);
method init();
/* 加载值 */
a:=(1, 9, 4, 16);
end;
```

使用矩阵的 IN 方法从表中加载数据：

```sas
data x;
v1=1;v2=2;output;
v1=4;v2=16;output;
run;
```

将行列获取变量：

```sas
proc sql noprint;
select nobs
into :rows :columns
from dictionary.tables
where libname='WORK'
and memename='X';
quit;
```

```sas
proc ds2;
data _null;
  varray double a[2];
  dcl package m(&rows,&columns)
  method run();
  /* 读取数据，从 varray 加载矩阵的每一行*/
  set x;
  m.append(a, _n);
enddata;
run;
```

### 5.5.1.3 操作矩阵值

使用矩阵包可用的方法之一对矩阵进行操作。数据可以从矩阵移动到声明数组或变量数组。如果使用了变量数组，数据将加载到 PDV 变量并成为程序结果集的一部分。

在以下示例中，值被加载到数组 `a`，数组 `a` 的元素值打印在 SAS 日志中。随后，使用 IN 方法从数组值填充矩阵。然后使用 TRANS 方法转置矩阵 `m`，并通过 TOARRAY 方法将其元素传回数组 `a`。数组 `a` 的元素再次写入 SAS 日志。最后，对矩阵 `m` 的所有元素执行平方根变换，并将值再次通过 TOARRAY 方法传给数组 `a`。

```sas
proc ds2;
data _null;
  dcl double a[2, 2];
  dcl package m(2,2);
method init();
  a:=1, 9, 4, 16);
  put 'before: ' a[*]=;
  m.append(a);
  m.trans(a);
  m.toarray(a);
  put 'Trans: ' a[*]=;
  m.sqrt(sqrt);
  m.toarray(a);
  put 'SQRT ' a[*]=;
enddata;
run;
quit;
```
