# 5.2 Executing FCMP Functions in DS2

# 5.2.1 The FCMP Package

The SAS Compiler procedure (PROC FCMP) enables you to create SAS functions and CALL routines that can subsequently be used in other SAS or DATA steps. PROC FCMP builds custom functions using DATA step-like syntax and stores the results in a SAS data set. With the SAS data set, FCMP functions are grouped into “packages” of related functions. These FCMP packages should not be confused with DS2 packages. An FCMP package is a subset of the functions stored in a single SAS data set containing FCMP functions. A DS2 package is entire to collect custom methods and data types.

When stored in a permanent SAS library, FCMP functions are easily reusable in subsequent SAS programs as if they were native SAS functions and CALL routines. After specifying the CMPLIB system option to identify the FCMP data set for DS2, you can use FCMP functions in your SAS code as if they were native SAS functions.

FCMP functions are an excellent means of standardizing and encapsulating programming methodologies across an enterprise, and mature SAS shops who have invested significant time and effort in building them. It would certainly be a shame if we were forced to expend extra resources for recreating and maintaining those same functions as methods in DS2 packages.

The DS2 FCMP provides an easy, one-time means of creating a wrapper package for an existing FCMP data set. The wrapper package can subsequently be used to execute the FCMP functions transparently from a DS2 program, just as the custom functions were actually DS2 methods. Modifications to the FCMP functions are immediately reflected through the DS2 package without any additional maintenance.

# 5.2.2 FCMP Package Example

Let’s build a couple of custom functions using PROC FCMP and use them in a DS2 program. We’ll subsequently modify one of the PROC FCMP functions, and then to check whether the modifications are automatically reflected in our DS2 program without any further maintenance required.

# 5.2.2.1 Creating Custom Functions with PROC FCMP

The following FCMP step builds user-defined functions:

```
/* Create the FCMP functions */
proc fcmp outlib = crs.fcmp_functions.ourFuncs;
function ourGMP(GS, Cog);
  /* Cross Margin %*/
  return ((GS-Cog)/GS);
endsub;
function forBE(GS, Fix, Units);
  /* Break Even (Units) */
  return (ceil(Fix/(GS/Units))-(Cog/Units)));
endsub;
run;
quit;
```
