# 5.3 The Hash and Hiter (Hash Iterator) Packages

# 5.3.1 General

Hash and hash iterator objects are memory-resident objects that enable quick and efficient storage, retrieving of data based on lookup keys. They are frequently used as lookup tables. Depending on the order of keys and the size of the data, a hash object can retrieve values significantly faster than a SAS format. Hash objects can be loaded from a SAS data set, referenced, manipulated, and stored back to SAS a data set using a traditional SAS DATA step or DS2 program. Data is loaded in the order in which it occurs in the data set. The order determines the order in which items are retrieved from the hash. When loading a hash object, you can specify the ORDERED argument, which determines the order. The DS2 hash and hiter packages provide hash and hash iterator functionality in DS2 programs.

Think of a hash iterator (hiter) as an ordered view of an existing hash object. It can retrieve data in whatever order, regardless of the hash ORDERED argument. A hiter object must reference an existing hash object, the referenced hash object must be instantiated before you instantiate a hash iterator object.
