### 5.4.3.2 使用 JSON 解析器实例进行解析

表 5.2：JSON 包 GETNEXTTOKEN 方法参数

为了使用我们的 JSON 包实例解析 JSON 文本，我们将使用 `DO UNTIL` 循环迭代执行 `GETNEXTTOKEN` 方法，直到获得非零返回代码，表示我们已解析了所有文本。

```sas
do until (rc ne 0);
  j.getNextToken(rc, token, tokenType, parseFlags);
  output;
end;
```
