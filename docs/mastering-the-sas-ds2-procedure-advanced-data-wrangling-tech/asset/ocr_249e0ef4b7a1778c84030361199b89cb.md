# Mastering the SAS DS2 Procedure: Advanced Data Wrangling Techniques

We can call CREATEGETMETHOD to prepare a GET request and EXECUTMETHOD to execute the request:

```
proc ds2;
data null;
  /* Declare the HTTP package */
  dcl package h();
  dcl varchar(1000000) character set utf8 API_Response;
  dcl int rc;
  method init();
    /* create a GET request */
    h.createGetMethod(
      cats('http://api.kivaws.org/vl/loans/search.json',
           '?region=sa&per_page=5&status=fundraising',
           '&gender=female&sort_by=newest'));
    /* execute the GET to query the Kiva API */
    h.executeGetMethod();
  end;
enddata;
run;
quit;
```

Executing this code produces a warning in the SAS log because we didn't retrieve the API response text:

```
WARNING: Warning reported by DS2 package d2http:
WARNING: Aborted execution of HTTP GET method with URL:
http://api.kivaws.org/vl/loans/search.json?region=sa&per_page=5&fundraising-gender=female&sort_by=newest
```

Let's use the GETRESPONSEBODYASSTRING method to retrieve the JSON produced by the API call and write the results to the SAS log using PUT statements. In addition, we'll write the data to work.json so we can use that data for future prototyping:

```
proc ds2;
data work.json/overwrite=;
  /* Declare the HTTP package */
  dcl package http();
  dcl varchar(1000000) character set utf8 API_Response;
  dcl int rc;
  method init();
    /* create a GET request */
    h.createGetMethod(
      cats('http://api.kivaws.org/vl/loans/search.json',
           '?region=sa&per_page=5&status=fundraising',
           '&gender=female&sort_by=newest'));
    /* execute the GET to query the Kiva API */
    h.executeGetMethod();
    /* retrieve Response as text, write to the log */
    h.getResponseBodyAsString(API_Response, rc);
    put(
      output);
  end;
enddata;
run;
quit;
```
