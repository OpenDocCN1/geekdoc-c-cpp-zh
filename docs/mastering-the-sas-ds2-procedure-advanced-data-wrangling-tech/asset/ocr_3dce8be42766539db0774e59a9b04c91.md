# 42 Mastering the SAS DS2 Procedure: Advanced Data Wrangling Techniques

```
data null;
dcl decimal(52,5) Dec;
dcl double SASNum;
dcl char(5) SASChar;
method init();
Dec=12345678901234567890.9n;
SASNum=1.1;
SASChar='1.1';
Dec=Dec+SASChar;
put 'dec=' 'Dec=12345678901234567892.00000';
put dec=;
put ;
Dec=12345678901234567890.99999n;
Dec=Dec+SASNum;
put 'dec=' 'Dec=12345678901234567892.00000';
put dec=;
put;
endata;
run;
;
```

# 3.3.3 Non-coercible Data Types

Binary and time-related data types will not automatically be converted to any other data type except character. These data types are classified as non-coercible:

Table 3.3: Non-coercible Data Types

| Data Type | Class | Comments |
| BINARY(n) | Binary | Non-coercible and no explicit conversion method is available. |
