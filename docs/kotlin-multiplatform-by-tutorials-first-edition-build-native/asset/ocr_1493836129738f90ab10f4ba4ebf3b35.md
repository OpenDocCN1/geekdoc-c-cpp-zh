If you read the logs carefully, you’ll notice that the compiler was unable to resolve the references to <o>Test</o>. Here’s why this happened:

As mentioned earlier, the <o>kotlin.test</o> library only provides the test annotations independently of the test library you’re using. When you ask the system to run the test on Android, it needs to find a test library on that platform to run your tests on. Since you hadn’t defined any test libraries for JVM targets, it couldn’t resolve the annotations, and the test failed. As a result, the next step would be to add test libraries to the app targets.
