# # Updating view on desktop

Since the desktop app is using Jetpack Compose, you can literally copy and paste the code from **RemindersView.kt** in the **androidApp** module to the same file in the **desktopApp** module.

> **Note**: You may see errors in your code stating that Android Studio can’t access `androidx.lifecycle.ViewModel`, which is a supertype of `com.raywenderlich.organize.presentation.RemindersViewModel`. You can safely ignore this error, as the app will build and run successfully. This seems like a bug in KMM plugin on Android Studio.

After doing so, build and run the desktop app.
