# iOS

Open **KoinIOS.kt** from **iosMain** and add the actual implementation of `platformModule` constant:

```
```kotlin
actual val platformModule = module { }
```
```

An empty module will silence the compiler.

You initialized Koin on iOS through the `initialize` method on `KoinIOS` object. You can add a parameter to that method so you can inject an instance of `UserDefaults` — or in Objective-C nomenclature, `NSUserDefaults`.

Make the following changes:

```
```kotlin
fun initialize(
    userDefaults: NSUserDefaults,
): KoinApplication = initKoin(
    appModule = module {
        single<Settings> {
            AppleSettings(userDefaults)
        }
    }
)
```
```

> **Note:** On Mac devices with Apple silicon, you may find that Android Studio fails to import the packages for `AppleSettings` and `NSUserDefaults`. Make sure these import directives are there:

```
```kotlin
import com.russhwolf.settings.AppleSettings
import platform.Foundation.NSUserDefaults
```
```

This is similar to the Android counterpart, but you’re using `AppleSettings`, which is an implementation of `Settings` on Apple platforms. `AppleSettings` needs an instance of `UserDefaults` in its constructor.
