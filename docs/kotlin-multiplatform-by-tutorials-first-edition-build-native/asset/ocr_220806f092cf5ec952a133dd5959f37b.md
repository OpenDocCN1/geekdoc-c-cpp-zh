+   5. Now that everything is ready, it’s time to define the `serialize` method. Since, the content type of `PLATFORM` is `String`, you just need to call `encodeString` and send the `value` of the received object.
+   
+   6. Finally, to deserialize, you’re going to call the opposite method, which is `decodeString`, and with the raw value (the key), you’ll call `findByKey` to see which value of the enum it corresponds to.

That’s it! `RWSerializer` is ready. You just need to add it to the class. Open the **RWContent.kt** file again, and above the declaration of `PLATFORM` add:

```
```kotlin
@Serializable(with = RWSerializer::class)
```
```

This associates the new device serializer to the `PLATFORM` class. Remember to import from `kotlinx.serialization.Serializable`.
