+   1. Many of the iOS frameworks themselves are built with Objective-C. Even when you write Swift code, you’re using a bridge.
+   
+   2. Objective-C has a more flexible and dynamic runtime than Swift. Apparently, Swift’s stricter type-safety features would have made the creation of KMP interoperability with Apple technologies more difficult.

Using Objective-C instead of Swift has some issues, though. For instance, you can’t use some newly introduced frameworks such as `Combine` as they’re Swift-only. Furthermore, you can’t use Swift-only extension functions or properties — or even Swift enum cases — either. You have no choice other than to use the verbose naming of entities in Objective-C.
