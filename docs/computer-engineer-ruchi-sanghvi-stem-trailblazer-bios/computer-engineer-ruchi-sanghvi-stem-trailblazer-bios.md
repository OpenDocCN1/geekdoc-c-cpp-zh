## 面对恐惧

当 Ruchi Sanghvi 在印度长大时，电脑并不是她生活中的重要部分。事实上，直到 2000 年上大学之前，她都没有经常使用电脑。2004 年，一个名为 Facebook 的小型、无名社交网站刚刚起。Ruchi 并不知道，她将来将成为一名技术天才，并开发出数百万每天使用的几项关键功能。

## 加入 Facebook

Ruchi 听到有一家初创公司正在寻找计算机工程师。这家公司名为 Facebook 的社交网站。几乎没有人听说过它，但 Ruchi 听说过。事实上，她自己也用过。当时，Facebook 只对大学生开放。

Ruchi 安排了在 Facebook 的面试，但当她到达时没人。有人在两小时后终于出现了。他和 Facebook 的其他工程师工作了一整晚，并且睡了觉。

面试进展顺利，Ruchi 获得了一份工作。那是 2005 年秋季，Ruchi 刚刚成为 Facebook 的第一个女性工程师。

> “当我开始在 Facebook 工作时，那里只有 20 个人。我看到它发展到有一千名员工，用户从五百万增长到十多亿。我见证了它从一个为大学生的服务演变为为全世界服务的服务。”

—Ruchi Sanghvi

# 第3章

![](img/ae9e705c714cd97fa29230fa02d2c484_13_0.png)

对于大多数外人来说，桑维（Sangvi）加入 Facebook 的决定似乎是疯狂的。她放弃了知名公司的稳定工作，选择了一家陷入困境的初创公司。Facebook 的老板是一位21 岁的大学辍学者，马克·扎克伯格（Mark Zuckerberg）。Facebook 的其他员工也是大学辍学者或应届大学毕业生。他们没有多少工作经验，也没有多年计算机程序员的资历。

他们拥有的是热情和学习的意愿。桑维也是如此。她知道 Facebook 可能会失败，自己也可能随之失败。但她没有让这些担忧阻挡她的道路。相反，她卷起袖子开始工作。

![](img/ae9e705c714cd97fa29230fa02d2c484_14_0.png)

## 初创公司的生活

在某些方面，在 Facebook 工作就像回到了大学时代。桑维和其他少数几个计算机工程师不得不自学如何从零开始构建社交网络网站。其中一位工程师是她的大学同学阿迪亚·阿加瓦尔（Aditya Agarwal）。他也 Facebook 找到了工作。他们经常工作到深夜，睡到很。有时他们甚至穿着睡衣来上班。

马克·扎克伯格对 Facebook 有着愿景。他不仅仅是想连接五百万名大学生。他希望他的网站能连接全球数以百万计的人。桑维和同事们面临着一项艰巨的任务。

## Facebook 新闻动态

2006年9月，Facebook 向全球范围内拥有电子邮箱的任何人开放了注册。但 Facebook 用户数起初增长并不多。这在部分是因为 Facebook 并不十分好用。那时，Facebook 并没有一个不断更新亲友动态的首页页。相反，Facebook 用户必须自己搜寻信息。他们必须点击一个朋友的页面，链接到另一个朋友的页面，以此类推。这就像一个复杂的迷宫。

为了解决这个问题，桑维和她的团队一直在努力开发名为“Facebook 新闻动态”（News Feed）的新功能。这个功能将允许用户在主页上看到所有朋友的信息。每当用户的朋友发布新信息时，主页就会更新。这样，每位用户都会拥有一个来自其朋友家人更新的个性化新闻动态。这是一项巨大的任务，但桑维和她的团队成功地完成了。

桑维在2006年9月5日的一篇 Facebook 博客文章中宣布了新闻动态。她兴奋地告诉用户：“现在，每当你登录时，都会看到你的朋友和社交小组活动生成的最新头条消息。”

## 技术面对谈

> “1月25日，9万万人同意参加埃及一天的革命，他们是使用 Facebook 进行组织的。我做最疯狂的梦也从未想象过，我构建的产品会以如此深刻的方式影响世界。”

— 鲁奇·桑维（Ruchi Sanghvi）

这一巨大的变化激励了更多人开始使用这个社交网站。它还通过连接为不同政治事业而斗争的人创造了历史。例如，2011年，埃及的数千万人使用 Facebook 组织抗议。他们想要一个新的、更公平的政府。在 Facebook 的帮助下，他们的抗议引发了被称为“阿拉伯之春”的中东革命。桑维还注意到，自己国家的女性正在利用 Facebook 为印度的平等权利权发声。在不知不觉中，桑维帮助连接了那些试图改变世界的人。

## 为 Facebook 做得更多

桑维（Sanghi）已经在 Facebook 做过大事情了，但她并没有结束。公司有更宏大的计划，她想成为其中的一员。只有一个问题：桑维的父母希望她履行承诺，回到印度结婚。

桑维从 Facebook 休息了一段时间回家。她的父母帮她安排了与年轻人的约会。桑维使用 Facebook 来了解更多关于他们的信息，例如他们的朋友是谁、发布了什么以及对什么感兴趣。但她不想和其中任何一个人结婚。事实上，她不确定自己是否已经准备好结婚了。

桑维25岁了。她知道在印度，这个年龄被预期结婚。

## JUSTWORKS（大有异工）

> 2013年，Sanghvi 在 Dropbox 办公室与团队成员讨论想法

Dropbox 提供云存储服务。这项技术允许用户在远程位置存储计算机文件。用户随后可以通过互联网访问并共享他们的文件。Sanghvi 成为该公司的运营副总裁，她的丈夫成为工程副总裁。他们与 Dropbox 分享了他们的技能和想法。

Sanghvi 多年来一直高强度工作。2013 年秋季，她决定休息一下。她想弄清楚自己的热情所在，以及她如何继续为世界做出贡献。

### 移民改革

作为一名美国移民，Sanghvi 面临着许多障碍。她需要政府特殊许可才能在美国上大学。为了毕业后留在该国，她必须有一份稳定的工作。但对于移民来说，找工作可能很困难。许多小型公司不愿意填写雇用移民所需的额外表格。Sanghvi 在 Facebook 的工作非常幸运。现在她想帮助其他移民。2013 年，她请求美国参议院通过新法律消除这些障碍，让美国移民获得寻找他们想要工作的自由。

Sanghvi 开始投资其他初创公司。这些公司正在开发让 Sanghvi 感到兴奋的新技术。其中一家初创公司名为 Codeacademy。这个免费网站以有趣且引人胜的方式教人们如何编写计算机代码。

Sanghvi 一生都在冒险并不断推自己去尝试新事物。她展示了人凭借勇气和努力可以成就什么。现在的问题是，Sanghvi 下一步将取得什么成就？
