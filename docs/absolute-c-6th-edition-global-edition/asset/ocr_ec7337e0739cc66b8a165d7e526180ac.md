# Self-Test Exercises (continued)

9. What output will be produced when the following lines are executed?

```
cout << "**" << setw(5) << 123;
cout.setf(ios::left);
cout << "**" << setw(5) << 123;
cout.setf(ios::right);
cout << "**" << setw(5) << 123 << "**" << endl;
```

10. What output will be produced when the following lines are executed?

```
cout << "**" << setw(5) << 123 << "**"
<< 123 << "**" << endl;
cout.setf(ios::showpos);
cout << "**" << setw(5) << 123 << "**"
<< 123 << "**" << endl;
cout.unsetf(ios::showpos);
cout.setf(ios::left);
cout << "**" << setw(5) << 123 << "**"
<< setw(5) << 123 << "**" << endl;
```

11. What output will be sent to the file stuff.txt when the following lines are executed?

```

fout.open("stuff.txt");
fout << "**" << setw(5) << 123 << "**"
<< 123 << "**" << endl;
fout.setf(ios::showpos);
fout << "**" << setw(5) << 123 << "**"
<< 123 << "**" << endl;
fout.unsetf(ios::showpos);
fout.setf(ios::left);
fout << "**" << setw(5) << 123 << "**"
<< setw(5) << 123 << "**" << endl;
```
