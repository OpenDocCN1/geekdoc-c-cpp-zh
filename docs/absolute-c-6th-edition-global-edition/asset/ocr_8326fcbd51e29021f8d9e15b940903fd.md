# continue statement

The continue statement consists of the keyword continue followed by a semicolon. When executed, the continue statement ends the current loop body iteration of the nearest enclosing loop statement. Display 2.9 contains an example of a loop that contains a continue statement.

# Display 2.9 A continue Statement in a Loop

```
1 #include <iostream>
2 using namespace std;

3 int main() {
4 {
5     int number, sum = 0, count = 0;
6     cout << "Enter 4 negative numbers, ONE PER LINE:\n";
7     while (count < 4)
8     {
9         cin >> number;
10        if (number >= 0)
11        {
12            cout << "ERROR: positive number (or zero)!\n"
13            << "Reenter that number and continue:\n";
14            continue;
15        }
16        sum = sum + number;
17        count++;
18    }
19    cout << sum << " is the sum of the "
20    << count << " numbers.\n";
21    return 0;
22 }
```
