# ## 1. 引言

本文档旨在介绍一种新型的文档解析方法，该方法能够高效地从复杂布局的图片中提取结构化信息。

+   - 支持多种文档元素识别
+   - 支持表格与图片的自动标注
+   - 输出标准 JSON 格式

# ## 2. 方法概述

我们采用基于深度学习的视觉模型，结合版面分析技术，对文档中的标题、段落、表格等元素进行定位与识别。

| 元素类型 | 识别准确率 | 平均耗时 |
|----------|------------|----------|
| 标题     | 98.2%      | 12ms     |
| 段落     | 97.5%      | 15ms     |
| 表格     | 95.8%      | 30ms     |

> > 注意：所有坐标均采用相对坐标，范围在 0 到 1 之间。
