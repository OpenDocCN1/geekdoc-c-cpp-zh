# 20.

```
cout << "Enter a line of input:\n";
char next;
do
{
    cin.get(next);
    if (!isupper(next))
        cout << next;
} while (next != '\n');
```

注意，你应该使用 isupper(next) 而不是 islower(next)。这是因为如果 next 包含非字母字符（如空格或逗号符号），islower(next) 会返回 false。
