11. 以下函数调用是可以接受的：

```
tripler(a[2]);

```

以下函数调用是不正确的：

```
tripler(a[3]);
tripler(a);

```

```

调用

```

```

是合法的，但只会填充 myArray 的前十个索引变量。如果这是期望的结果，则该调用是可以接受的。

以下函数调用都是不正确的：

```

其中第一个不正确是因为第二个参数过大，第二个因为缺少最后的分号并包含多余的方括号，第三个因为它使用了索引变量作为参数，而此处应使用整个数组。
