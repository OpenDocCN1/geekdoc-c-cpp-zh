# Display 9.3 Some Functions in <cctype> (part 1 of 2)

| FUNCTION | DESCRIPTION | EXAMPLE |
|---|---|---|
| toupper\n( Char_Exp ) | Returns the uppercase version of Char_Exp as a value of type intl. | char c = toupper('a');
cout << c;
Outputs: A |
| tolower\n( Char_Exp ) | Returns the lowercase version of Char_Exp as a value of type intl. | char c = tolower ('A');
cout << c;
Outputs: a |
| isupper\n( Char_Exp ) | Returns true provided Char_Exp is an uppercase letter; otherwise, returns false. | if (isupper(c))
  cout << "Is uppercase.";
else
  cout << "Is not uppercase."; |
| islower\n( Char_Exp ) | Returns true provided Char_Exp is a lowercase letter; otherwise, returns false. | char c = 'a';
if (islower(c))
  cout << c << " is lowercase.";
Outputs: a is lowercase. |
| isalpha\n( Char_Exp ) | Returns true provided Char_Exp is a letter of the alphabet; otherwise, returns false. | char c = '5';
if (isalpha(c))
  cout << "Is a letter.";
else
  cout << "Is not a letter.";
Outputs: Is not a letter. |
| isdigit\n( Char_Exp ) | Returns true provided Char_Exp is one of the digits '0' through '9'; otherwise, returns false. | if (isdigit('3'))
  cout << "It's a digit.";
else
  cout << "It's not a digit.";
Outputs: It's a digit. |
| isalnum\n( Char_Exp ) | Returns true provided Char_Exp is either a letter or a digit; otherwise, returns false. | if (isalnum('3') && isalnum('a'))
  cout << "Both alphanumeric";
else
  cout << "One or more are not.";
Outputs: Both alphanumeric. |

  cout << "Is punctuation.";
