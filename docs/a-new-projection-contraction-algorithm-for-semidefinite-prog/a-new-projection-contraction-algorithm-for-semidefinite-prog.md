## 摘要

本文研究了一种用于半定规划问题的投影收缩算法。内点法是求解半定规划问题的经典算法。根据初始点是否可行，它可以被分为可行算法和不可行算法。可行内点法需要使用自对策略来寻找严格可行点。虽然不可行内点法不要求初始点严格可行，但该算法的理论分析非常复杂。与内点法相比，投影收缩算法对初始点没有要求，且算法简单得多。半定规划问题的最优条件可以重写为投影方程，然后通过投影收缩算法进行求解。我们提出了一种基于下降方向的新型投影收缩算法，通过求解线性方程来改进算法，从而避免高维求逆，使算法能够解决大规模半定规划问题。数值实验表明，该算法是可行的，且改进算法与内点法一致。

**关键词**：半定规划；最优条件；投影方程；投影收缩算法

考虑半定规划问题：

(P) `min C·X` s.t. `A·X = b_i`, `i = 1,2,...,m, X ≥ 0`。(1)

以及其对偶问题

(D) `max b^T y` s.t. `Σ_{i=1}^m y_i A_i + S = C`, `S ≥ 0`。(2)

为了简单起见，我们将实数对称 `n × n` 矩阵空间记为 `S^n`，`S^n` 中所有半定矩阵记为 `S^n_+`。在系统 (1) 和 (2) 中，矩阵 `C, A_i ∈ S^n, i = 1,...,m`，向量 `b, y ∈ R^m`。`A·B` 表示 `A, B ∈ S^n` 的内积，定义为 `A·B = trace(AB)`。`X, S ≥ 0` 表示 `X, S ∈ S^n`。

在适当的约束限定下，原问题和对偶问题半定规划问题的解满足最优条件：

```math
\begin{cases} A·X = b_i, i=1,2,...,m, X ≥ 0 \\ \sum_{i=1}^m y_i A_i + S = C, S ≥ 0 \\ XS = 0 \end{cases}
```
(3)

内点法求解半定规划问题的基本思想是将互补条件 `XS = 0` 替换为互补松弛 `XS = μI`，其中 `I` 是单位矩阵，参数 `μ > 0`，从而得到中心系统：

```math
\begin{cases} A·X = b_i, i=1,2,...,m, X ≥ 0 \\ \sum_{i=1}^m y_i A_i + S = C, S ≥ 0 \\ XS = μI \end{cases}
```
(4)

然后使用牛顿法来获取搜索方向，然而矩阵乘积通常不是可交换的，得到的搜索方向是非对称的。为了获得对称的搜索方向，需要互补松弛是对称的 [1]。近年来，求解半定规划问题的内点法侧重于新核函数的构造、宽邻域的设计以及新的搜索策略 [2–4]。这些算法要求起始点必须是严格可行的，但严格可行起始点并不容易找到。常用方法是使用 SDMM [6], SDP3 [7]，另一种方法是设计不可行算法，例如 [8]，它们不要求初始点可行，但理论分析更为复杂。

投影算法源于早期对求解变分不等式的研究。基于何兵求解变分不等式的投影收缩算法 [9] 和求解变分不等式的投影收缩算法 [10]，韩其将求解变分不等式的投影收缩扩展到半定规划 [11]。该方法将 (3) 中的相容条件转换为投影方程，然后使用投影算法求解变分不等式 [12]。郑正采用求解变分不等式的投影收缩算法 [13] 来解决某些投影问题 [14]。对于二阶规划，Mu和张 [15] 结合欧几里得几何来求解二阶规划。此外，Mu和张给半定规划的投影收缩算法。二阶规划可以看作半定规划的特例，投影收缩算法的理论分析简单，且对初始点没有要求。基于 [14]，本文提出了一种新的投影收缩算法来求解半定规划问题。与内点法相比，投影收缩算法对初始点没有要求，且算法简单得多。半定规划问题的最优条件可以重写为投影方程，然后通过投影收缩算法进行求解。我们提出了一种基于下降方向的新型投影收缩算法，通过求解线性方程来改进算法，从而避免高维求逆，使算法能够解决大规模半定规划问题。数值实验表明，该算法是可行的，且改进算法与内点法一致。

## 2. 预备知识

`Ω ⊂ R^n` 为凸集，`F` 是从 `R^n` 到 `R^n` 的单调算子，变分不等式是寻找 `u* ∈ Ω` 使得：

```math
(u - u*)^T F(u*) ≥ 0, \quad \forall u ∈ Ω.
```

显然，将变分不等式 (5) 中的算子 `F` 乘以因子 `β > 0` 不改变问题的解。众所周知，上述变分不等式等价于求解投影方程：

```math
u = P_{Ω}[u - βF(u)], \quad β > 0.
```

令 `e(u, β) := u - P_{Ω}[u - βF(u)]`。特别当 `F(u) = Mu + q, q ∈ R^n, M ∈ R^{n × n}` 满足 `u^T Mu ≥ 0` 时，称为线性变分不等式。

以下引理表明 (3) 中的相容条件可以转换为投影的投影形式。

**定理 1** [11] 对于 `X, S ∈ S_+^s`，`XS = 0 ⇒ X = P_{S^s}(X - S)`。对于半定规划问题，令 `u = (X, y)^T, M = [[0, -A^T], [A, 0]], q = (c, b)^T`，其中 `A = [A_1; ...; A_m]`，则

```math
[X - P_{(X,β)}[X - C - Σ^m y_i A_i)], β[A_1·X - b_1], ..., β[A_m·X - b_m] = 0
```

`Ω = S_+^s × R^n`。因此，从定理1可知，半定规划的最优条件 (3) 等价于 `u = P_{Ω}[u - β(Mu + q)]`。注意 `M^T = -M`，即矩阵是反对称的，在实际计算中，矩阵的按列提取为向量以便操作。

## 3. 基于新方向的投影收缩算法

基于求解线性投影方程的一些新方法 [10]，文献 [14] 提出了一种用于二阶锥规划的快速投影收缩算法。同样，根据线性投影方程 (7) 与半正定规划问题最优条件的等价性，本文提出并改进了一种用于求解半正定规划问题的投影收缩算法。

假设方程 (7) 有解，解集记为 `Ω^u`。

**定理 2** 令 `u' ∈ Ω^u`, `β ∈ {0,1}`，则

```math
(u - u')^T d(u, β) ≥ ||e(u, β)||^2, \forall u ∈ R^{mn} × R^m
```

其中 `d(u, β) = (I - βM)e(u, β)`。

**证明**：根据闭凸集上的投影性质，我们得到

```math
[P_{Ω}(v)]^T[P_{Ω}(v) - u*] ≥ 0, \forall v ∈ R^{mn} × R^m. (8)
```

在 (8) 中令 `v = u - β(Mu + q)`，有

```math
[e(u,β) - β(Mu + q)]^T[P_{Ω}(u - β(Mu + q)) - u*] ≥ 0. (9)
```

然后令 `v = P_{Ω}(u - β(Mu + q))`，从 (5) 得到

```math
[β(Mu + q)]^T[P_{Ω}(u - β(Mu + q)) - u*] ≥ 0. (10)
```

将 (9) 和 (10) 相加得

```math
[e(u,β) - βM(u - u*)]^T[P_{Ω}(u - β(Mu + q)) - u*] ≥ 0. (11)
```

上述不等式给出

```math
(u - u*)^T(I + βM)e(u,β) ≥ ||e(u,β)||^2 + (u - u*)^TβM(u - u*).
```

最后，由于 `M` 是反对称的，证明结束。

定义 `F(u,β) = 1/2 ||u - u*||^2`，根据定理 2，可知 `d(u,β)` 是 `F(u,β)` 在 `G = (I + βM)^T(I + βM)` 处的下降方向。由于 `M` 是反对称的，有 `G = (I - βM)(I + βM)`。显然 `G` 是正定的，则 `-G^{-1}d(u,β) = -(I + βM)^{-1}e(u,β)` 也可以是一个下降方向 [9]。

### 算法 1 投影收缩算法如下。

给定 `u_0 ∈ R^{mn} × R^m, r ∈ (0,2), β ∈ {0,1}`。

对于 `k = 0,1,...,`，若 `u_k* ∉ Ω^u`：

步骤 1：计算 `d(u_k,β) = (I + βM)^{-1}e(u_k,β)`。

步骤 2：更新 `u_{k+1} = u_k - rβd(u_k, β)`。

根据定理 2，可以给出求解半正定规划问题的投影收缩算法的全局收敛性证明。

**定理 3** `G = (I + βM^T)`，`r ∈ (0,2), β ∈ [0,1]`，算法 1 产生的序列 `{u_k}` 满足

```math
||u_{k+1} - u_k||_G^2 ≤ ||u_k - u_k*||_G^2 - rβ(2-β)||e(u_k, β)||
```

**证明**：

```math
||u_{k+1} - u_k||_G^2 = ||(I + βM^T)(u_k - u_k*) - rβI(I + βM^T)^{-1}e(u_k, β)||_G^2
```

```math
= ||(I + βM^T)(u_k - u_k*)||_G^2 - 2rβ(u_k - u_k*)(I + βM^T)e(u_k, β) + r^2β^2||e(u_k, β)||_G^2
```

```math
≤ ||u_k - u_k*||_G^2 - 2rβ||e(u_k, β)||
```

**定理 4** [9] 算法1 产生的序列 `{u_k}` 收敛于 `u_k* ∈ Ω*`。

在算法 1 中，当计算下降方向 `d(u_k, β) = (I + βM)^{-1}e(u_k, β)` 时，如果问题规模很大，`(I + βM)^{-1}` 的计算成本过高，会导致算法运行缓慢。以下是等价形式：

```math
d(u_k, β) = (I + βM)^{-1}e(u_k, β) \Leftrightarrow (I + βM)d(u_k, β) = e(u_k, β). (12)
```

右侧方程的特定形式为线性方程组

```math
\begin{bmatrix} I_{n × n} & -βA^T \\ βA & I_{m × m} \end{bmatrix} \begin{bmatrix} d(X_k, β) \\ d(y_k, β) \end{bmatrix} = \begin{bmatrix} e(X_k, β) \\ e(y_k, β) \end{bmatrix}. (13)
```

求解方程得到：

```math
d(y_k, β) = (I_{m × m} + β^2 A^T)^{-1}[e(y_k, β) - βe(X_k, β)]. (14)
```

```math
d(X_k, β) = βA^T d(y_k, β) + e(X_k, β). (15)
```

从 (12) 到 (15) 可以看出，通过逆运算 `(I + βM)^{-1}` 和 `(I + β^2 A^T)^{-1}`，维度从 `(n^2 + m)` 降低到 `m × m`，当 `n` 大于 `m` 时，计算量可以显著减少。因此存在投影收缩算法：

### 算法 2 改进的投影收缩算法

步骤 1：给定 `u_k ∈ R^n × R^m, r ∈ (0,2), β ∈ [0,1]`。

步骤 2：对于 `k = 0, 1, ...,`，若 `u_k ∉ Ω*`：

步骤 3：从方程 (14) 和 (15) 计算 `d(y_k, β), d(X_k, β)` 以得到 `d(u_k, β)`。

步骤 4：更新 `u_{k+1} = u_k - rβd(u_k, β)`。


```math
A_3 = \begin{pmatrix} 2 & -1 & -1 & 0 \\ 2 & 0 & 2 & 1 \\ -1 & -1 & 2 & -1 \\ 1 & 1 & 0 & -2 \end{pmatrix}, C = \begin{pmatrix} 3 & -3 & 3 & 1 \\ 3 & 5 & 3 & 2 \\ -3 & 3 & 1 & -1 \\ 1 & 2 & -1 & -1 \end{pmatrix}, b = \begin{pmatrix} -2 \end{pmatrix}
```
