
### 4.2 Tests to determine the value of the rate of mutation operator and crossover operator rate

We began conducting an analysis of system behavior by varying the rate of mutation operator in a wide range of values to cover all possible situations. During experiments, we used different samples from the Reuters distribution. Thus, for the rate of mutation operator, we discussed a wide range of values: 0.01, 0.03, 0.05, 0.07, 0.1, 0.3, 0.5, 0.7; that allowed us to apply the mutation operator of GA in different circumstances and study their behavior. For the study to determine the optimal value of the rate of crossover operator, we traced the interval from 0.70 to 0.95; a high value, but oriented to frequent application of the operator we designed, because an optimum value for the mutation probability is much more important than the crossover probability, and we chose to make a more detailed study of the crossover ratio in our experiments. As a quality index value of the operator, the number of hits of the GA was used.

As for the size of the tournament, the value 2 has been chosen, because the binary tournament has shown a very good performance in a large number of applications of EAs. Although determining an optimal fitness function is not one of the fundamental objectives of this experiment, we have tried to combine in a single value measurement results as powerful and distinct as the Euclidean distance and the Pearson correlation coefficient (based on cosine similarity).

Therefore, to find the adjustment coefficient α that governs the weight that is to be given to both the distance and the inverse of similarity of the cluster documents, we made many parameter-controlled tests in order to obtain a value that allows an adequate contribution of both metrics with respect to fitness, finally finding a value for α of 0.85.

The number of maximum generations the system has been set to is 5000, but this parameter may vary depending on the convergence of the algorithm. As for the number of stemmer terms to be used for representing the feature vectors of each of the documents, we have used the terms, which have been selected through the NZIPF processing method [6][11].

Finally, we have established a limit called the threshold of depth for individuals (trees). Such a threshold, in the case of “very few and few documents”, takes the value of 7, and for the “many and enough documents” is set to 10. To analyze the results and verify their effectiveness, we compared the results of the GA with the existing real groups of the document collection [6], and also compared the results with another supervised type of clustering algorithm in optimal conditions (Kmeans). ## 5. Conclusion

In this study, we have proposed a new taxonomy of parameters of GA, numerical and structural, and examined the effects of numerical parameters on the performance of the algorithm in a GA-based simulation optimization application by the use of a test clustering problem. We start with the characteristics of the problem domain.

The main characteristic features of our problem domain are:

- There is a dominance of a set of decision variables with respect to the objective function value of the optimization problem: The objective function value is directly related with the combination of this dominant set of variables equal to a value close to 0.85.
- Good solutions are highly dominant over other solutions with respect to the objective function value, but not significantly diverse among each other.

These properties of the problem domain generate a rapid convergent behavior of GA. According to our computational results, lower mutation rates give better performance. The GA mechanism creates a lock-in effect in the search space; hence, lower mutation rates decrease the risk of premature convergence and provide diversification in the search space in this particular problem domain. Due to the dominance, the crossover operator does not have a significant impact on the performance of GA. Moreover, starting with a seeded population generates more efficient results.

We can conclude that the GA had a favourable evolution, offering optimal document clustering in an acceptable and robust manner, based on a proper adjustment of the parameters. We proved that the medium effectiveness of the GA is very acceptable, being in most cases better than the Kmeans supervised algorithm, but with the added advantage that we processed the documents in an unsupervised way, allowing the evolutionary algorithm to perform clustering with our adjustment. As a result of our experiments, we observed that we got the best performance with a rate of 0.03 for the mutation operator and using a rate of 0.80 for the crossover operator; these values appear to be ideal if we maximize the efficiency of the genetic algorithm.
