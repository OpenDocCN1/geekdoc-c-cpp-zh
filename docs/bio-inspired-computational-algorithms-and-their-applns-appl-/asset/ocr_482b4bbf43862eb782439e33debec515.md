2. Let σₙ be normalized contrast parameter, such that:
σₙ = { σ / 128      μ ≤ 64
      1 − σ / 128   otherwise }  (30)

A region is considered to have sufficient contrast when 0.25 ≤ σₙ ≤ 0.5. When σₙ < 0.25, the region has poor contrast, and when σₙ > 0.5, the region has too much contrast.

3. Let Sₙ be normalized sharpness parameter, such that Sₙ = min(2.0, S/100). When Sₙ >0.8, the region has sufficient sharpness. Image Quality is evaluated using by:
Q = 0.5 μₙ + σₙ + 0.15 Sₙ  (31)
where 0 < Q < 1.0 is the quality factor. A region is classified as good when Q >0.55, and poor when σₙ ≤0.5. An image is classified as GOOD when the total number of regions classified as GOOD, N_G > 0.6 N.
