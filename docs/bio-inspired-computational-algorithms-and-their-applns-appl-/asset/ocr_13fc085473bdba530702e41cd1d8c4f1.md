To address the shortcomings mentioned above, an autonomous agent was developed that can participate in multiple heterogeneous auctions. Two primary values that heavily influenced the bidding strategies of this agent are the k and β. These two values correspond to the polynomial function of the four bidding constraints, namely the remaining time left, the remaining auction left, the user's desire for bargain and the user's level of desesperateness. The possible combinations between these two values are endless and thus, the search space for the solution strategies is very large. Hence, genetic algorithms were used to find the nearly optimal bidding strategy for a given auction environment.
