$$ y = χ₀(ρ₁(χ₀(...)), ρ₁(χ₁(...))) . $$

Unary identity operation ρ₁(z) does not change the value of argument and this operation is necessary for the construction of the graph by graphic notation.

Since graphic notation should contain binary operations with unary operations as their arguments then we additional unary identity operations. We get

$$ y = χ₄(ρ₁(χ₀(ρ₁(x₁), ρ₁₂(x₁₁))), ρ₁(χ₁(ρ₁(χ₁(ρ₁(q₁), ρ₁(x₁))), ρ₄(ρ₂(x₂))))) . $$

This notation is not a graphic one, because it does not satisfy condition «b» of graphic notation. Here unary operation has unary operation as its argument

$$ ... ρ₄(ρ₂(x₂)) ... $$

We use additional binary operation with a unit element as its second argument, for example χ₀(...,0). According to Table 2 binary operation χ₀(z′,z″) is addition. A unit element for addition is 0 and it does not influence the result of calculation. Thus we get

$$ ... ρ₄(χ₀(ρ₂(x₂), 0)) ... $$

We obtain the graphic notation of mathematical equation

$$ y = χ₀(ρ₁(χ₀(ρ₁(x₁), ρ₁₂(x₁₁))), ρ₁(χ₁(ρ₁(χ₁(ρ₁(q₁), ρ₁(x₁))), ρ₄(χ₀(ρ₂(x₂), 0))))) . $$

This notation does not satisfy condition «c» of graphic notation, because it contains a subring where binary operation has two unary operations with the same variable as its arguments

$$ ... χ₀(ρ₁(x₁), ρ₁₂(x₁)) ... $$

We add a binary operation with a unit element and a unary identity operation to the subring

$$ ... χ₀(ρ₁(χ₀(ρ₁(x₁), 0)), ρ₁₂(x₁)) ... $$

As a result we get the following notation of mathematical equation

$$ y = χ₀(ρ₁(χ₀(ρ₁(χ₀(ρ₁(x₁), 0)), ρ₁₂(x₁))), ρ₁(χ₁(ρ₁(χ₁(ρ₁(q₁), ρ₁(x₁))), ρ₄(χ₀(ρ₂(x₂), 0))))) . $$

This notation has all properties of graphic notation and we can construct the graph of equation by this notation. To construct the graph we use the rules presented on Fig. 1 - 4.
