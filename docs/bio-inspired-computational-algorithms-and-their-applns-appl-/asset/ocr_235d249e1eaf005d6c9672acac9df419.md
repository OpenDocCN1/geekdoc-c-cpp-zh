NOM $\Psi = [\psi_{ij}]$, $i,j=1,\overline{L}$ is upper-triangular because of the numeration of nodes. NOM is not enough for calculation of mathematical equation since it does not contain information about parameters and variables. This information is kept in the initial values of vector of nodes

$$\mathbf{z}=[z_1\ ...\ z_L]^T.$$ (10)

Then the calculation of mathematical equation can be done by

$$z_j = X_{\psi_{ij}}(\rho_{\psi_{ij}}(z_i),z_j),\ \text{if}\ \psi_{ij}\neq0,\ i=1,\overline{L-1},\ j=i+1,\overline{L}.$$ (11)

To calculate the mathematical equation by its NOM we need to look through all rows consequently; $i=1,\overline{L-1}$. In each row $i$ we consider the elements that follow the diagonal element, $j=i+1,\overline{L}$. If among them we find nonzero element then we perform calculation according equation (11).

# 7. Variations of network operators

Similar network operators are network operators that satisfy the following conditions:

+   a. have the same source nodes;
+   b. have the same constructive sets.

Alike network operators are similar network operators that have equal numbers of nodes.
