# 9.4.4 String Comparison

In C, the characters are represented in the internal machine code by numbers, which are chosen that A < B < C < D, the capital letters precede the lower case letters, and so on. Most computers use the ASCII or the EBCDIC code. Thus, character strings can be compared for identity, variance, or alphabetical ordering by comparing their numeric representations. This is done using the string comparison functions found in the string.h library. There are two string functions: strcmp() and strncmp().

The strcmp() function has two arguments and returns an integer as follows:

```
int k;
k = strcmp(strng1, strng2);
```

In this case, the character strings strng1 and strng2 are compared character-by-character. When unequal characters are found the order of the two strings is determined. Based on the order of the two strings the comparison generates the following results:

+   k > 0 positive number strng1 after strng2
k = 0 positive number strng1 identical to strng2
k < 0 negative number strng1 before strng2
