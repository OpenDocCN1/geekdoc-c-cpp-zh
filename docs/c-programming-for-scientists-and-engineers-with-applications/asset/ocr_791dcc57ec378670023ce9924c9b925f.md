# 9.2.1 Declaration and Initialization of Strings

Declaration A string is stored in an array of data type char. The declaration statement to allocate the storage for a string is as follows:

char strname[20];

The data type is char, the string name is strname, and it is an array with 20 storage locations to hold 19 characters plus the null terminating character.
A string array is undefined until a string is stored in it. There are three different ways of defining a string array.

+   - Initialization at the time of declaration
- Assignment of characters to each individual array location
- Input into the string array

> Programming Warning: Make sure that storage space is allocated to store a string and a null terminating character.

Initialization Any string constant may be assigned to a string array when it is declared. The following examples show the declaration and initialization of strings.

```
char strname[10] = "computers";
```
