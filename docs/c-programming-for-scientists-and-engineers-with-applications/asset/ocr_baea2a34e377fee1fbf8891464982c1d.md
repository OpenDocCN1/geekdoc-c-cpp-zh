# 1.4 Program Processing

```
#include <stdio.h>
int main() {
    int sum, number;
    sum = 0;
    number = 1;
    For number <= 100
        sum <- sum + number;
        while(number < 101)
            sum = sum + number;
            number = number + 1;
    printf("%d\n", sum);
    return 0;
}
```

The C source code instructions outside the outer braces are instructions to the compiler. The outer braces enclose the C language equivalent of the pseudocode; the beginning and then the end of the instructions that are to be repeated. Note that all of the instructions are necessary, if the sum were not cleared in the beginning, it might give a wrong answer. If the number was not started at 1, the code would not meet the specifications of summing numbers from 1 to 100. The summation takes place by adding each new value of number to the accumulated sum. Then the number is incremented to the next value. The repetition is controlled by checking whether the current value of the number is < 101. If that check was missing, or if the number was not incremented, the repetition would never end. Whenever an algorithm contains repetition, the termination condition must be reachable.
