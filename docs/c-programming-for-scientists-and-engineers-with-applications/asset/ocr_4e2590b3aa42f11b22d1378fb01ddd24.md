Bubble Sort This is an exchange sort. In this sort, the elements of the array are compared from the bottom to the top. When any adjacent elements are out of order, they are exchanged. This results in the largest element floating to the top when the array is to be sorted in descending order, or the smallest element moving to the top when the array is to be sorted in ascending order.
