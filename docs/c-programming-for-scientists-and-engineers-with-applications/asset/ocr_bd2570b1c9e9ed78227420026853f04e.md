# 496 Multidimensional Arrays

```

#define IMAX 3
#define IMAX 4

void funcadd(int, int, int *);

int main()
{
    int a[IMAX][JMAX], b[IMAX][JMAX], c[IMAX][JMAX];
    int i, j, x, y;

    for(i = 0; i < IMAX; i++)
{
        for(j = 0; j < JMAX; j++)
{
            funcadd(a[i][j], b[i,j], &c[i][j]);
        }
    }
    ..
}

void funcadd(int a1, int b1, int *c1)
{
    *c1 = a1 + b1;
    return;
}
```

The arrays a and b cannot be passed by value. But by passing their elements by value, the arrays are protected against inadvertent change in the function. The elements of array c are passed by address as array c is to receive the result of the addition.
