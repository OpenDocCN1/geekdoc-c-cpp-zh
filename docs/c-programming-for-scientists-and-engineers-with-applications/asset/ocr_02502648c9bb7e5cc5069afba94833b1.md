# 8.4 Manipulation of Arrays

Addition:

```
#include <stdio.h>
#define IMAX 3
#define JMAX 4

int main() 
{
    int a[IMAX][JMAX], b[IMAX][JMAX], c[IMAX][JMAX];
    int i, j;
    for(i = 0; i < IMAX; i++) {
        for(j = 0; j < JMAX; j++) {
            c[i][j] = a[i][j] + b[i][j];
        }
    }
    return 0;
}
```

| a | | b | | c |
|---|---|---|---|---|---|---|---|---|---|---||
| 12 | 16 | 18 | 24 | 2 | 3 | 4 | 8 | 14 | 19 | 22 | 32 |
| 13 | 20 | 40 | 28 | 7 | 9 | 6 | 3 | 20 | 29 | 46 | 31 |
| 18 | 16 | 24 | 50 | 6 | 3 | 8 | 5 | 24 | 19 | 32 | 55 |

Notice that a is added to array b element-by-element and the result is assigned and stored in array c. Subtraction, multiplication, and division operations are similar.

# 8.4.3 Matrix Operations

The addition and subtraction operations defined on mathematical matrices are the same as array arithmetic, which is carried out element-by-element, but matrix multiplication is a special operation. Two matrices of the same size and shape may be added or subtracted element-by-element. Matrix transpose, inverse, and the following examples show arithmetic operations on matrices.

```

#define JMAX 5
```
