# Structures

Similarly the other initialized values are assigned to array elements[1]
and parts[2].

Note that the values specified in the braces are stored in the members of
elements of the array parts[3] in the order in which the structure members are
sified in the structure declaration.

If only a few values are specified in the initialization they are assigned to the
order in which the members are specified in the structure declaration. The
remaining members are automatically initialized to zero or an empty string
dending on the member type part. The following code shows shows such an initialization.

```
struct gadgetpart {
    char name[10];
    int count;
    float unitcost;
    float totalcost;
}
```

```
struct gadgetpart part = {"bolt", 20};
```

Notice that in this case there are only two values specified, but there are four
members in the structure declaration, the first two members are initialized as
sified and the last two members are initialized to zero.

Also, notice that in all initialization statements shown so far there is no need
to specify explicitly the members along with the structure variables, because the
members are implicit to the variable used in the initialization.

Assignment of Values to Variables Values may be assigned to structure mem-
bers using assignment statements. The following example shows such an assign-
ent. may be assigned using either the example member operator or by using
the structure variable pointer.

```
struct gadgetpart {
    char name[10];
    int count;
    float unitcost;
    float totalcost;
}
```

```
struct gadgetpart part, *partptr;
```
