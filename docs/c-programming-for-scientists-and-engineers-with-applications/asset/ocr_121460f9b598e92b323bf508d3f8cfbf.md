Matrix Multiplication:Matrix multiplication is not carried out by the multiplication of corresponding elements. It is an inner product of row and column vectors. If two matrices are to be multiplied, the number of columns of the left matrix must be equal to the number of rows of the right matrix. The size of the resulting matrix is equal to the number of rows of the left matrix and the number of columns of the right matrix.

```
$x_{i,j} = \sum_{k=1}^{amax} y_{i,k}z_{k,j}$
```

This product is shown in the following matrices:

```
$y = \begin{bmatrix} y_{00} & y_{01} & y_{02} \ y_{10} & y_{11} & y_{12} \end{bmatrix} \quad z = \begin{bmatrix} z_{00} & z_{01} \ z_{10} & z_{11} \ z_{20} & z_{21} \end{bmatrix}$
```
