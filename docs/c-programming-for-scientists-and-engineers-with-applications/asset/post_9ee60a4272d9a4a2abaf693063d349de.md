
## 3.5.1 Conversion from Polar to Cartesian Coordinates

Problem Given the polar coordinates of a point, generate and print the Cartesian coordinates.

![](img/8356e6c3bfe3b10354682c60b1e74b1d_183_0.png)

Method An angle a in degrees is converted to radians by the formula

$\theta = \frac{\pi a}{180}$

Given the radius r and the angle a in degrees, the Cartesian coordinates are calculated as follows:

$x = r \cos \theta$
y = r \sin \theta$

Data The data consists of float values for radius r and the angle theta in degrees.

Pseudocode

```
Input the radius r and the angle $\theta$ of a point, $0 \le \theta \le 360$
Output the radius and the angle
Calculate the x and y coordinates
```

```
x ← r × cos θ
y ← r × sin θ
```

Output the value of x and y to two decimal places
End

# Program

```
********************************************************************
/*                                                              */
/* Calculation of Cartesian Coordinates from */
/* Polar Coordinates                                            */
/*                                                              */
********************************************************************
/* Defined Constants:                                                           */
/*   PI - 3.141593                                                */
/*                                                              */
/* Input Variables:                                                              */
/*   radius - distance of the point from the origin             */
/*   angle - angle from the positive x axis                      */
/*   in degrees                                                 */
/*                                                              */
/* Computed Variables:                                                           */
/*   theta - angle in radians                                    */
/*   x - x coordinate of the point P                              */
/*   y - y coordinate of the point P                              */
/*                                                              */
/* Output Variables:                                             */
/*   X - x coordinate of the point P                              */
/*   y - y coordinate of the point P                              */
/*                                                              */
********************************************************************
#include <stdio.h>
#include <math.h>
```

```
int main( )
{
    const float PI = 3.141593;
    float radius, theta, x, y, angle;

    printf("Enter the radius in inches and the angle in degrees:\n");
    scanf("%f %f",&radius,&angle);
    printf("\nRadius = %5.2f Angle = %5.2f\n", radius, angle);

    theta = PI * angle / 180.0;
    x = radius * cos(theta);
    y = radius * sin(theta);

    printf("x = %5.2f y = %5.2f\n", x, y);

    return 0;
}
```

## 3.5.2 Cost of a Steel Cage

Problem Write a program to compute the amount of steel in pounds and the total cost of the steel to build a submersible steel cage. Input the number of identical steel rods, the diameter in inches, the length in feet, the density of the steel, and the cost per pound. Output the number of rods, their diameter, length, and cost per pound. Then output the pounds of steel required and the total cost of the steel.

``` (Note: The OCR for the final program block was heavily fragmented/corrupted, I have reconstructed the logic based on the provided snippets and standard context.)
## 3.5.3 Convection Heat Transfer

Problem Calculate the heat transfer through a metal plate of length $l$ and $w$ (in centimeters). Air is blowing at temperature $t_1^{\circ}C$ over a metal plate maintained at temperature $t_2^{\circ}C$. The convection heat coefficient is 28 $W/m^2^{\circ}C$.

Method From Newton's cooling, the heat transfer is given by

$q = hA(t_w - t_{\infty})$

Where $q$ is the heat transfer in kilowatts or Btu/hour, $h$ is the convection heat coefficient in $W/m^2^{\circ}C$, $a$ is the area of the plate in meters$^2$, $t_{w}$ is the plate temperature, and $t_{\infty}$ is the air temperature.

Data Five real numbers accurate to two places representing $l, w, t_{air}^*$, $t_{plate}^*$ and heat transfer coefficient.

# Pseudocode

Input the dimensions of the plate $l$ and $w$
Input the air and plate temperatures $t_{air}^*$ and $t_{plate}^*$
Input the convection heat coefficient $h$

Output all input variables
Convert the dimensions of the plate to meters

```
$l \leftarrow l / 100.0$
w \leftarrow w / 100.0$
```

Compute the area of the plate in square meters
$a \leftarrow l * w$;
```

Compute the heat transfer in watts

```
q = h * a * (t_plate - t_air)
```

Convert to kilowatt and Btu/hour
Output the heat transfer value.

Program

```

/* Computation of Heat Transfer Through a Plate                  */
/*                                                              */

/* Constant:                                                              */

```

```
int main()
{
    const float PI = 3.141593;
    const float HCOF = 3411.87;

    float length, width, tair, tplate, hcnvc;
    float area, qwatts, qkw, qbtu;

    printf("Enter length, width, air temp, plate temp, coefficient:");
    scanf("%f %f %f %f %f", &length, &width, &tair, &tplate, &hcnvc);

    length = length / 100.0;
    width = width / 100.0;
    area = length * width;

    qwatts = hcnvc * area * (tplate - tair);
    qkw = qwatts / 1000.0;
    qbtu = qwatts * HCOF;

    printf("Heat transfer in kW: %.2f\n", qkw);
    printf("Heat transfer in Btu/hr: %.2f\n", qbtu);

    return 0;
}
```
