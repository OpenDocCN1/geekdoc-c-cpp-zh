Summation of Array Elements Sum array elements is a very common operation used, for example, to compute the averages in scientific and engineering applications. The following code segments show the summation of elements of an array.

```
#define SIZE 5
int i;
int a[SIZE];
int sum;

sum = 0;
for(i = 0; i < SIZE; i++)
{
    sum += a[i];
}
printf("Sum is: %d", sum);
```
