# 3.1 Input and Output Functions

The format control string is a character string consisting of text with embedded format control fields. Each format control field specifies a data type of a variable specified in the input/output argument list. It may also specify the number of positions occupied by the data values that is the field width. There is one control field for each of the remaining arguments of the function call. Number, order, and type in the control fields and variables specified as arguments match.

The simplest input/output does not specify field width, but allows the programmer to use a default field width. This is practical when the programmer does not know what size to expect. On output, the computer uses a default field width and justifies numbers if the field width is not specified. If it is specified, the programmer justifies output values within the fields. By omitting the field width, the programmer can align output on the left. By specifying a field width, the programmer can align output on the right or align decimal points. When computer values are only accurate to a certain number of decimal places, or as in the case of money, are meaningless beyond a certain number of decimal places, field width should be specified so that the fractional digits printed can be controlled.

In the following sections, standard input and output are presented by file input and output. When data is input from a file, or to a file, there are additional functions that must be called. These will be discussed in Section 3.2.

# 3.1.2 Standard Input Function

The standard library function used to input data from a keyboard is scanf( ), which takes a list of items called arguments separated by commas. The first item of the function is a format control string which, like all other character strings, is enclosed in double quotation marks. The rest of the arguments are the input variables. This function can be called to input numeric, character, character string data. The general form of the input function call is follows:

```
scanf("format string", &var1, &var2,......, &var);
```

Remember that the address of var1 is &var1, &var2 is &var2, and so forth. In this context the "&" symbol is an address operator, which transmits the address of the variable to the input function so that the computer knows where to store the input value.

> Programming Rule: The addresses of the input variables must be specified in the scanf( ) function.
