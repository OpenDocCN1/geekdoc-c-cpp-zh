# Chapter Summary

Input and output in C is performed using library functions that have prototypes stored in the header file stdio.h. The header file stdio.h must be included in the program in order to use the input and output functions. To include the header file the following statement must be used.

```
#include <stdio.h>
```

Standard Input and Output The standard input function is scanf( ). The scanf( ) statement is used to enter data from the keyboard. The form of the standard input statement is

```
scanf("format control string", &var1, &var2, &var3,...varn);
```

The following format specifiers are used to input integer numbers, floating-point numbers, and character data:

+   %d for input of an integer number,
