# 4.5.4 Table of Periods of a Pendulum

Problem Write a program to compute the periods of a simple pendulum for arm lengths starting at 12 inches and reaching a period of less than or equal to 3.45. This program uses a repetition controlled by a terminating limit.

Data The arm length L in feet varies from 1 to n.

Method The formula to compute the period is

![](bbox=[0.493, 0.452, 0.615, 0.513])

where $g = 32.2$ ft/sec2.

$T$ is the period of the pendulum in seconds to be computed.
$L$ is the arm length of the pendulum in feet.

Pseudocode

```
L $\leftarrow$ 1
Calculate pendulum period
While period $\le$ 3.45
  Calculate pendulum period
  Output length and period
  L = L + 1
End while
Stop
```
