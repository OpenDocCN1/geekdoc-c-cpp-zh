# Data

Defined constant modulus of elasticity E = $30 \times 10^6$ psi

Diameter of the column
Compression load

# Pseudocode

```
constant E = 30e06
constant pi = 3.141593
input diameter
area = (pi * (diameter * diameter)) / 4
for load p = 10,000 to 100,000 increment by 10,000
stress = load / area
strain = stress / E
end
for i = 1 to 10
output load, stress, strain
end
stop
```
