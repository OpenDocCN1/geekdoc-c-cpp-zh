The American National Standards Institute (ANSI) formed a committee in 1983 to standardize the language. The features of C were published in 1989, which makes the language portable.

## 2.1 Introduction to C

The important features of C are:

- Data type declarations and definitions that eliminate undeclared variables. This forces the programmer to think about the range of values.
- Standard control structures that make the program logic simpler and reduce the number of errors.
- Functions to implement modularity. This makes the program easier to read and update. The programmer does not have to figure out all the details at the same time.
- Derived data types such as arrays, character strings, and structures are available to handle complex data so they can be processed repeatedly.
- Powerful features of the language include pointers make it possible for the programmer to utilize storage efficiently.

## 2.1 Structured Language

C is a structured programming language. In structured programming only three basic control structures are needed to design and develop programs. C has the three basic control structures of sequence, selection, and repetition. Each control structure is entered at the top and exited at the bottom.

The sequence structure corresponds to the modules in a single level of a sequence chart that have the same parent module. The selection structure and repetition structure each correspond to a parent module and its submodules. In the hierarchy chart, in 1.10, boxes 1, 2, 3, and 4 would be implemented using a sequence structure, as boxes 2.1 and 2.2.

The circular arrow above box 2 in Figure 1.10 shows that boxes 2, 2.1, and 2.2 would be implemented as a repetition structure. In the pseudocode, this is a For...Endfor construct. The diamond connectors of boxes 2.1, 2, and 3 indicate that boxes 2.1, 2, and 3 would be implemented as selection structures. The arrow connector is at a higher level in the hierarchy chart than the diamond connectors, so the selection structure is subordinate to the repetition structure and physically contained with it.
