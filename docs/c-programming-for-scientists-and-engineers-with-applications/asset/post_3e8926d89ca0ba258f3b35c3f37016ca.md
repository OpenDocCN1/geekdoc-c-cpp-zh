
## 3.5.5 Wavelength of an Electron

Problem: Write a program to compute the wavelength $\lambda$ of an electron at velocities 20%, 30%,...,100% speed of light (considered as a particle) given the mass $m$, in kilograms and velocity $v$, in meters per second. This program uses scientific data format.

Method: The De Broglie equation to compute the wavelength $\lambda$ of a particle is as follows:

$$\lambda = \frac{h}{mv}$$

Where $\lambda$ is the length in meters, $h$ is Planck’s constant $6.626 \times 10^{-34} \text{ kg m}^2/\text{s}$, $v$ is velocity meters/s, and $m$ is in kilograms.

The numbers for mass, Planck’s constant, and velocity are double precision.

**Pseudocode**

```
Defined constants mass of the electron and velocity of light
for each percentage of the velocity light
    compute the velocity of the electron as a percentage of the light
    velocity of electron = percentage of light
    compute the wavelength of the electron
    wavelength = Planck’s constant / (mass of the electron * velocity of the electron)
out the velocity and the wavelength
end for
stop
```

**Program**

```c
************************************************************
/*                                                           */
/*    Compute the Wavelength of an Electron                           */
************************************************************
/*                                                           */
/*    Constants:                                                       */
/*    H - Planck’s constant = 6.626 x 10^-34 kg m^2/s                   */
/*    VEL_LIGHT = 2.998 x 10^8 m/s                               */
/*    mass - mass of the electron in kilograms                         */
/*                                                           */
/*    Input Variables:                                                  */
/*   -none-                                                              */
/*                                                           */
/*    Computed Variables:                                                 */
/*   light - percentage                                                   */
/*   velocity - velocity of electron in m/s *                 */
/*   wavelength - wavelength of the electron in m *             */
/*                                                           */
/*    Output Variables:                                                 */
/*   wavelength - wavelength of the electron in m *             */
******************************************************************/
```

```c
#include <stdio.h>

int main() 
{
    const double H = 6.626E-34;
    const double VEL_LIGHT = 2.998E8;
    double mass = 9.109E-31;
    int light;
    double velocity, wavelength;

    printf("Planck's constant = %e\n", H);
    printf("Mass of the electron = %e kg\n", mass);

    for(light = 20; light<=100; light += 10) {
        velocity = (light / 100.0) * VEL_LIGHT;
        wavelength = H / (velocity * mass);
        printf("Velocity = %e m/s  Wavelength = %e m\n", velocity, wavelength);
    }

    return 0;
}
```
