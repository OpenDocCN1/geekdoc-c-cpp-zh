# Pointers and Dynamic Storage

```
printf("Data Output to the Monitor\n\n");

valptr = arptr;

for(i = 0; i < IMAX; i++)
{
    for(j = 0; j < JMAX; j++)
    {
        printf("%5.1f \ *valptr);
        valptr++;
    }
    printf("\n");
}

return 0;
```

Input data:
3 4
28.5 46.3 57.9 72.6
14.3 15.7 31.4 19.4
48.9 13.9 90.6 57.8

The values are stored in dynamic storage as follows:

| Address | Pointer |
|---|---|
| 1000 | 1000 28.5 arptr + 0 |
| valptr | 1004 46.3 arptr + 1 |
| 1008 57.9 arptr + 2 |
| 1012 72.6 arptr + 3 |
| 1016 14.3 arptr + 4 |
| 1020 15.7 arptr + 5 |
| 1024 31.4 arptr + 6 |
| 1028 19.4 arptr + 7 |
| 1032 48.9 arptr + 8 |
| 1036 13.9 arptr + 9 |
| 1040 90.6 arptr + 10 |
| 1044 57.8 arptr + 11 |
