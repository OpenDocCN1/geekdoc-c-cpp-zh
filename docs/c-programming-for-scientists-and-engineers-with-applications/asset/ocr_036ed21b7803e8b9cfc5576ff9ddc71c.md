# # 6.3 Storage Classes in Multiple Files

Only the extern storage class variables can be made visible across different files. A variable defined in one file can be made visible in another file by declaring it there.

# ## 6.3.1 Storage Class Extern

extern storage class variable has multiple file scope. This means an extern storage class variable defined in one file can be made visible and accessed in another file by explicitly declaring such a variable in another file. For example, if an extern variable is defined in program file A, it can be made visible and accessed in program file B by explicitly declaring it in file B. An extern variable is automatically initialized to zero when it is declared. The following code segment shows access of an extern variable across files.

```
File A:
#include <stdio.h>

void func1(void);
void func2(void);

int main() 
{
    extern int a;      /* a is made visible */
    func1();
    a = a + 5;
    printf("In main a = %d\n", a);
    func2();
    a = a + 25;
    printf("In main a = %d\n", a);

    return 0;
}

int a;                  /* a is declared and defined */
void func1(void) 
{
    a = 15;
    printf("In func a = %d\n", a);

    return;
}
```
