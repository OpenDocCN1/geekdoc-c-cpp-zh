If this is printed, starting with row 50 and ending with row 0, it has the appearance of the following graphic:

![](bbox=[0.515, 0.505, 0.635, 0.575])

An equation y=f(x) can then be graphed for integer values of x in the range 0–50 by calling a function f and rounding the results, checking that they are also in the range 0–50, and putting a character in the position x, y.

```
#include <stdio.h>
int main()
{
    char graph[51][51];
    int x, y;
    for(x = 0; x < 51; x++)
{
        y = f(x) + 0.5; /* round f(x) */
        if(0 <= y && y <= 50)
{
            graph[y][x] = '*';
        }
    }
```
