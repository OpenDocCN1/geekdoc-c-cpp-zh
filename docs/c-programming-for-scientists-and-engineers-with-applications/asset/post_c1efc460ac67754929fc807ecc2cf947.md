```c
if( a == 0)                       /* not a quadratic equation */
    flag = 0;
else if( b * b < (4 * a * c))   /* no real solutions */
    flag = -1;
else if(b * b == (4 * a * c))   /* one solution */
{
    x1 = -b / (2 * a);
    printf("x1 = %f", x1);
    flag = 1;
}
else{
    sqval = (b * b - (4 * a * c));   /* two solutions */
    x1 = (-b + sqrt(sqval)) / (2*a);
    x2 = (-b - sqrt(sqval)) / (2*a);
    printf("x1 = %f x2 = %f", x1, x2);
}
return flag;
```

Notice that there is a single return and a flag that indicates the state of the computation. The C language allows more than one return statement, which would have slightly simplified the program logic but would have violated the modular principle of one entry and one exit for each module.

## 5.3 Computation Functions

A calling function is a function that is calling (invoking) another function. A called function is a function called (invoked) by another function. For example, if main calls (invokes) a function func1 then main is the calling function and func1 is the called function. The communication between the calling function and the called function is through the argument parameter list and the value returned. The items of information passed to the called function by the calling function are called arguments. The places in the function header where arguments are received are called parameters.

### 5.3.1 Passing Arguments by Value

When arguments are passed to the function by value, the values are copied into the parameters. This means that any changes made to the parameters within the function do not affect the variables in the calling function. The following example shows what happens when arguments are passed by value.

```c
int funcsum(int, int, int);
int main()
{
    int var1 = 10, var2 = 20, var3 = 30;
    sum = funcsum(var1, var2, var3);
    printf("var1 = %d, var2 = %d, var3 = %d, sum = %d\n", var1, var2, var3, sum);
    return 0;
}

int funcsum(int x, int y, int z)
{
    int sum1;
    x += 10; // x is now 20
    y += 15; // y is now 35
    z += 20; // z is now 50
    sum1 = x + y + z;
    return sum1;
}
```
Output: var1 = 10, var2 = 20, var3 = 30, sum = 105

### 5.3.2 Passing Arguments by Pointer

The arguments from the calling function may be passed to the called function as pointers. A pointer is simply an address of a variable. Pointers, the addresses of variables, are passed as arguments instead of the variables themselves as we have done in passing by value. This is done by preceding each argument name with an address operator (&).

```c
int funcsum(int *, int *, int *);
int main()
{
    int var1 = 10, var2 = 20, var3 = 30;
    sum = funcsum(&var1, &var2, &var3);
    printf("var1 = %d, var2 = %d, var3 = %d, sum = %d\n", var1, var2, var3, sum);
    return 0;
}

int funcsum(int *x, int *y, int *z)
{
    int sum1;
    *x += 10; // var1 is now 20
    *y += 15; // var2 is now 35
    *z += 20; // var3 is now 50
    sum1 = *x + *y + *z;
    return sum1;
}
```
Output: var1 = 20, var2 = 35, var3 = 50, sum = 105
