Their storage is local to main; they exist in the storage space of the main program, x and y are given values in the declaration, z is given a value by an assignment statement, and a and b are declared in the function header and given values when the function is called. # 6.2.2 Storage Class extern

The extern storage class is used primarily to access functions that have been declared and implemented in another source code file, and to access tables that are stored in separate files.

Any variable declared global to the entire program or declared outside any function or functions is an extern storage class variable. An extern storage class variable is automatically defined when it is declared and given a default value of zero, provided that it is not declared as having the extern. When it is specifically declared as extern, no value is assigned and no value is assigned. The following examples show the definition and declaration of extern storage class variables.

```
#include <stdio.h>
void func1(void);
void func2(void);
int main ( {
    int x = 5; /* local auto class variable declaration */
    printf("In main x = %d\n", x); /* 1 */
    func1();
    x = x + 5;
    printf("In main x = %d\n", x); /* 2 * */
```
