## 4.5.6 三角形的类型

**问题** 编写一个程序，确定文件中的每组整数是否可以作为三角形的边长。如果是，则判断它是否为不等边三角形；如果是不等边三角形，再判断它是否为直角三角形。此示例演示了嵌套选择结构、while 循环以及文件输入输出的使用。

**方法** 给定三角形的边长 $a, b$ 和 $c$，通过比较确保任意两边之和大于第三边，来确定 $a, b$ 和 $c$ 是否构成三角形。如果边构成三角形，通过检查所有长度是否都不同来确定其是否为不等边三角形。如果是不等边三角形，通过确定斜边的平方是否等于另外两边的平方之和来确定其是否为直角三角形。该方法的逻辑如图 4.18 所示。![](img/8356e6c3bfe3b10354682c60b1e74b1d_274_0.png)
