

# 指针与动态存储

为表格分配存储空间。

根据公式计算应力

$\sigma = p/area$;

其中 $\sigma$ 是以每平方英寸为单位的压力，$p$ 是以磅为单位的负载，$area 是受拉载荷的棒截面积。

输出负载和应力。

# 伪代码

```
输入截面尺寸宽度 w 和厚度 t
area = w* t
输入负载最小值和最大增量
表格大小 = (loadmax - loadmin) / increment + 1
从最小到请求的最大负载循环
stress = load / area
结束
打印表格
停止
```

# 程序

```
/******************************************************/
/* main: 计算矩形截面 */
/* 钢棒的应力 */
/* 使用数组指针 */
/*
/******************************************************/
/* 定义常量: */
/* --无-- */
/*
/* 输入变量: */
/* width -- 钢棒的截面宽度 */
/* thick -- 钢棒的截面厚度 */
/* minload -- 应用的最小负载 */
/* maxload -- 应用的最大负载 */
/* inc -- 负载增量 */
```

```
/*
* 计算变量:
* area - 截面面积
* stress - 柱应力
*/
/*
* 输出变量:
* load - 柱上的负载
* stress - 以磅为单位的拉伸应力
* 每平方英寸
************************************************

#include <stdio.h>

int main() {
    int i, n;
    float width, thick, area, minload, maxload, inc, stress;
    float *loadptr, *stressptr;
    scanf("%f %f", &width, &thick);
    scanf("%f %f", &minload, &maxload, &inc);
    area = width * thick;
    n = (maxload - minload)/ inc + 1;
    loadptr = (float *) calloc(n, sizeof(float));
    stressptr = (float *) calloc(n, sizeof(float));
    for(i = 0; i < n; i++) {
        *loadptr = minload + i * inc;
        *stressptr = *loadptr / area;
        loadptr++;
        stressptr++;
    }

    loadptr -= n;
    stressptr -= n;

    for(i = 0; i < n; i++) {
        printf("%8.2f      %8.2f\n", *loadptr, *stressptr);
        loadptr++;
        stressptr++;
    }
    return 0;
}
```

# 10.6.2 高于平均温度的天数

此程序使用数组指针来操作一维数组。

# 问题

- 输入月份名称并显示该月的平均温度。确定平均温度高于该月平均水平的天数。

# 数据

月份名称。

# 方法

- 输入月份名称。
- 在表格中查找该月份以确定它有多少天（忽略闰年）。
- 为每日平均温度分配空间。
- 输入平均温度。
- 计算月平均温度。
- 打印月平均温度。
- 打印高于平均水平的天数。

# 伪代码

```
输入月份名称
在月份名称数组中定位月份并获取天数
分配数组存储
对于每一天
    输入平均温度并存储在数组中
    将平均温度加到总和
结束
naverage = sum / ndays
输出平均值
```

```
对于每一天
    比较平均温度与平均值
    统计高于平均值的数量
结束
输出计数
停止
```

> 程序
/********************************************************************/
/*  main: 计算总和和平均温度                  */
/*    使用数组指针                                     */
/* *********************************************************************/\
/*  定义常量:                                            */
/*    --无--                                                  */
/*  输入变量:                                              */
/*    month[] - 月份名称                               */
/*    dacnt - float 类型数字的个数               */
/*  计算变量:                                            */
/*    sum - 数字之和                                     */
/*    average - 数字的平均值                             */
/*    ndays - 月份中的天数                        */
/* */

```
/*
 * 输出变量:
 */
 * count - 高于平均值的天数
 */
 * sum - 数字之和
 */
 * average - 数字的平均值
 */
/*
 * 调用的函数:
 * funcmonth - 返回该份中的天数
 */
 ************************************************************************************

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int funcmonth(char []);

int main()
{
    int i, ndays, count;
    char month[10];
    float sum, average;
    float *avgtemp;

    scanf("%s", month);

    ndays = funcmonth(month);

    avgtemp = (float*)calloc(ndays, sizeof(float));

    sum = 0.0;
    for(i = 0; i < ndays; i++)
    {
        scanf("%f", avgtemp);
        sum += *avgtemp;
        avgtemp++;
    }

    average = sum / ndays;
    printf("average temperature for %s is %.2f\n", month, average);

    count = 0;
    for(i = 0; i < ndays; i++)
    {
        if(*avgtemp > average)
            count++;
        avgtemp++;
    }

{
  int days[12] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
  char month[12][10] = {"January", "February", "March", "April", "May", "June", "July", "August", "September", "October", "November", "December"};

  int k, ndays;
  for (k = 0; k < 12; k++)
    if(strcmp(month[k], datamoth) == 0)
      ndays = days[k];

}

# 10.6.3 动态存储字符字符串排序

# 问题

编写一个程序对动态存储中的字符串按字母顺序排序。打印未排序和排序后的字符串。

# 方法

使用缓冲区进行输入。
为每个字符串分配动态存储空间。
将字符串地址存储在指针数组中。
输出未排序的字符串。
按字母顺序排序字符串，重新排列它们的指针。
输出排序后的字符串。

# 数据

输入 10 个字符串。

# 伪代码

```
main())
  call funcinput
  call funcoutput
  call funcsort
  call funcoutput
stop
```

```
funcinput()
```

```
  输入字符串数量（最多 20 个）
  对于每个字符串
    将字符串输入缓冲区
    分配动态存储
    将地址分配给指针数组元素
    将字符串从缓冲区拷贝到动态存储
  end for
  return
```
end
```

```
funcsort()
```

```
  对于每个字符串 i
    对于每个字符串 j, j > i
```

```
if (字符串 i 大于字符串 j )
    交换字符串指针
end if
end for
end for
return
end
```

```
funcoutput()
```

```
  对于每个字符串
    输出字符串
end for
return
end
