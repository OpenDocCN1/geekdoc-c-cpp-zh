# Chapter Summary

C uses program units called functions to implement modularity. A function is block structured. The body of a function begins with a left brace ({}) and ends with a right brace ()

+   - Every function in C must be prototyped. The declaration of a function prototype is called a function prototype. The computer uses a function prototype
