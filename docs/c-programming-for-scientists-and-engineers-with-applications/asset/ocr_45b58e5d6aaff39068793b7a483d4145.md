Switch Statement The switch statement can also be used to implement a case structure. The general form of the switch statement is as follows:

```
switch(expression)
{
  case # or char:
  stmt1;
  break;
  case # or char:
  stmt2;
  break;
}
```

The expression is expected to evaluate to one of a predetermined set of values. The value of the expression is used as follows:
