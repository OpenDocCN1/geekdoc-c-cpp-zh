## 4.5.1 Impedance and Inductance of Electrical Coil

Problem Write a program to compute impedance Z and the inductance L of electrical coil, given the voltage V, current I (amps), resistance R (ohms), and frequency (cycles/second) for six circuits.

This example demonstrates the use of repetition controlled by counter. The coil is in the following AC circuit: ![](img/8356e6c3bfe3b10354682c60b1e74b1d_257_0.png)

Data: Input (volts), current (amps), resistance (ohms), and frequency (cycles/second).

Method
Z = V/I
Z^2 = R^2 + X_L^2
X_L = sqrt(Z^2 - R^2)
L = X_L / (2π)
where L is inductance of the coil, X_L is reactance, and Z is impedance.

Pseudocode
For each of six sets of values
Input voltage, current, and frequency
Calculate the impedance Z = V/I
Calculate the reactance X_L = sqrt(Z^2 - R^2)
Calculate the inductance L = X_L / (2.0 × f)
Output the voltage, inductance, reactance
Stop

```c
Program
/**********************************************************************
/* Inductance of a coil in a resistance and reactance */
/* AC circuit for six sets of values */
/**********************************************************************
/* Constants: */
/* PI = 3.141593 */
/* Input Variables: */
/* voltage (volts) */
/* current (amps) */
/* resistance (ohms) */
/* frequency (cycles/second) */
/* Computed Variables: */
/* impdnc - impedance */
/* indctn - inductance */
/* rectnc - reactance */
```

```c
#include <stdio.h>
#include <math.h>
int main() 
{
    int i;
    float voltage, current, frequency;
    float impdnc, indctn, rectnc;

    const float PI = 3.141593;

    /* input six sets of values */

    printf("INPUT              OUTPUT\n");
    for(i = 0; i < 6; i++) {
        scanf("%f %f %f", &voltage, &current, &frequency);

        impdnc = voltage / current;
        rectnc = sqrt(impdnc * impdnc - resistance);
        indctn = rectnc / (2.0 * PI * frequency);

        printf("%5.2f %5.2f %5.2f %5.2f\n", voltage, current, rectnc, indctn);
    }

    return 0;
}
```

## 4.5.2 Altitude of a Projectile

Problem Write a program to determine the maximum height to which a projectile will travel if atmospheric resistance is neglected, for different initial velocities. This example demonstrates the use of repetition controlled by a terminating limit.

Method The mass of the projectile is $m$, initial velocity is $v_0$ m/sec, last initial velocity is $v_f$ ft/sec.

From equations of motion:
$w = mg, \sum F_z = maz$.

Applying these equations for the projectile results in the following equations:
$-mg = ma_c$ gives $a_c = -g$

Initial conditions: $s_0 = 0, v_0 = v$

Final conditions: $s_j = h, v_j = 0$

## Control Structures

From Kinematics: $v^2 = v_0^2 + 2a_t(s_f - s_0)$
$0 = v^2 + 2a_t(h - 0)$
$2a_th = -v^2$
$h = \frac{-v^2}{2a_t}$

Data Real values of initial velocity at 50, 100, 150, and 200 ft/sec.
Real value of gravitational acceleration is 32.2 ft/sec.

# Pseudocode

For each initial velocity
Height $\leftarrow$ (initial velocity * initial velocity) / (2.0 * acceleration)
Output the initial velocity and height

End for
Stop
