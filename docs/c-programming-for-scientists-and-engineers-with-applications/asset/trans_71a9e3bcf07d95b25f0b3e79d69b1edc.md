```
输入三角形三边 a, b, c 的值

如果 a > 0 且 b > 0 且 c > 0
  根据公式计算 s 的值
  s <- (a + b + c)/2
  如果(s > a 且 s > b 且 s > c)

    输出三角形的面积
  结束如果
结束
结束
```

注意：测试是必要的，用于确定三个输入值是否为三角形的三边。

```
Program
/******************************************************/
/* *
/*  不等三角形的面积             */
/* *
/******************************************************/
/* *
/*  输入变量:                    */
/* *
/*  a, b, and c - 不等三角形的边 */
/* *
/*  计算变量:                   */
/* *

/*  area - 不等三角形的面积       */
/* *
/*  输出变量:                     */
/* */
```

```c
/* area - 三角形的面积 */
/* */
/****************************************************************/

#include <stdio.h>
#include <math.h>
int main()
{
    int a, b, c;
    float s, area;

    printf("Input integer values for the Sides:\n");
    scanf("%d %d %d", &a, &b, &c);
    printf("\nThe Sides of the Triangle: %d %d %d\n", a, b, c);

    if(a > 0 && b > 0 && c > 0)
    {
        s = (a + b + c) / 2.0;
        if(s > a && b > b && s > c)
        {
            area = sqrt(s * (s - a) * (s - b) * (s - c));
            printf("The Area of the Triangle: %5.2f\n", area);
        }
    }

    return 0;
}
```

### 输入与输出

输入边的整数值：
12 14 16

三角形的边: 12 14 16
三角形的面积: 81.33

## 2.5.6 球体体积

问题 计算半径为 $r$ 的球体体积。

数据 半径 $r$。

方法 给定半径 $r$，根据公式计算球体体积
$volume = 4/3\pi r^3$。

### 伪代码
输入 $r$ 的值
如果 $r > 0$
计算体积

$volume = 4/3\pi r^3$

输出体积
停止

注意：测试是必要的，以确保半径 $r$ 为正。

### 程序

```
/****************************************************************/
/*                                */
/*    球体体积             */
/*                                */
****************************************************************/
/*                                {}
/*   定义常量:                  */
/*                                {}
/*   PI - 3.141593                       */
/*                                {}
/*   输入变量:                    */
/*                                {}
/*   radius - 球的半径        */
```

```c
/*
 * 计算变量:
 */
 * volume - 球的体积
 *
 * 输出变量:
 *
 * radius - 球的半径
 *
 * volume - 球的体积
 *
 *******************************************************************
```

```c
#include <stdio.h>
int main ()
{
    const float PI = 3.141593;
    float radius, volume;

    printf("Input real value for the radius:\n");
    scanf("%f", &radius);

    printf("\nThe radius of the sphere: %f\n", radius);
    if(radius > 0)
    {
        volume = 4/3 * PI * radius * radius * radius;
        printf("The Volume of the sphere: %.2f cubic inches\n", volume);
    }

    return 0;
}
```

### 输入与输出

输入半径的实值：
5

球的体积: 523.60 立方英寸

## 总结

C 是一种结构化、过程化的强类型语言。C 拥有丰富的函数库，包括输入输出函数、数学函数、字符串处理函数、内存分配函数、标准库函数和其他杂项函数。C 具有处理整数和浮点数计算的能力。C 使用赋值运算符来执行数值计算。变量必须声明：

```c
int var1, var2;
```

在计算机系统中，整数变量的默认分配为 4 字节。在系统中，声明如下：

```c
long var1, var2;
```

在计算机系统中，短整数的默认分配为 2 字节。在系统中，声明如下：

```c
short var1, var2;
```

在计算机系统中，浮点数变量的默认分配为 4 字节。在系统中，声明如下：

```c
float var1, var2;
```

在计算机系统中，双精度浮点数变量的默认分配为 8 字节。在系统中，声明如下：

```c
double var1, var2;
```

字符变量的分配为 1 字节。在系统中，声明如下：

```c
char var1, var2;
```
