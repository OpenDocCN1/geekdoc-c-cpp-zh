# 11.5 Union and Enumeration Data Types

Union and enumerated data types are similar to structures in their declaration. Unions are used for customizing the storage to store only the member of the union that is accessed. An enumerated data type provides a name for a set of user-given data values. Union is very effective in optimizing storage if the members of the union are large size arrays where one array member is active at a time. This is very useful in scientific computing when we have large size one-dimensional and multidimensional arrays.
