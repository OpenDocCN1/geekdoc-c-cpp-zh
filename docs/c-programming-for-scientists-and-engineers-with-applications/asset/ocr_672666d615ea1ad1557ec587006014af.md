In order to calculate the position of an element in a three-dimensional array, the computer must know the number of planes that precede it and the size of the plane and therefore must know the number of rows and columns in a plane. Because of this, when a three-dimensional array is passed to a function, the function declaration and header must specify the number of rows and columns expected.
