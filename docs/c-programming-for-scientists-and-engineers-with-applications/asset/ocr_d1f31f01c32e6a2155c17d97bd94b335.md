# 684 Structures

```
struct Circle {
    float diam;
    float area;
};
```

```
struct Square {
    float side;
    float area;
    Circle *innercircle;
    Circle *outercircle;
};
```

```
int main() {
    const float PI = 3.141593;
    struct Square box;
    struct Circle in, out;
    float x, s;

    scanf("%f", &x);
    box.side = x;
    box.area = x * x;
    in.diam = x;
    in.area = PI * x * x / 4.0;
    box.innercircle = &in;
    s = sqrt(2.0 * x * x / 4.0);
    out.diam = s;
    out.area = PI * s * s / 4.0;
    box.outercircle = &out;

    return;
}
```

If the area of a circle inscribed in the Square box is to be printed, it can be accessed as

```
(*box.innercircle).area) or box.innercircle -> area
```
