By the use of braces as follows:

```
if(value found)
{
  if(value > 0)
  {
    s = sqrt(value);
    printf("%f %f", value ,s);
  }

  printf("no value found"););
```

or by the use of a null else statement as follows:

```
if(value found)
  if(value > 0)
  {
    s = sqrt(value);
    printf("%f %f", value, s);
  }
  else;
```
