
## 8.7.3 Computation of Pressure

Problem Compute the pressure at each point and the average pressure over a rectangular area at the bottom of the sea floor for the construction of an oil rig platform. The input to the program is the depth measurements in feet at grid points over a 400-foot by 500-foot rectangular area. The depth measurements are recorded at 50-foot intervals and stored in a file "depth.dat". This example reads a two-dimensional array from a file and processes individual elements.

Method Input the depth measurements (8 rows and 10 columns) and store them in an array depth[8][10]. The formula is derived in Section 6.4.2.

The formula for the computation of pressure is given by:

```
$p = \rho gh$
```

Where

- $p$ is the pressure (pounds per square inch),
- $\rho$ is the mass density of water (mass per unit volume),
- $g$ is the gravitational acceleration (ft/sec$^2$), and
- $h$ is the depth of water in feet.

```
where $\rho g = 0.4333$
p = 0.4333 * h$ (lbf/inch$^2$)
```

Data Values of depth input from a data file

Pseudocode

```
main:
  input the data
  output the data labeled
  for each grid point
    calculate the pressure
    calculate the average pressure
  output the pressure
  output the average pressure
stop
```

* main: Computation of Pressure at Sea Floor                    *
*/

/*
* Input Variables:                                                *
* depth[IMAX][JMAX]- depth of water at sea floor                  */
* Computed Variables:                                            *
* pressure[IMAX][JMAX]- computed pressure at sea

* depth[IMAX][JMAX]- depth of water at sea floor                 *
* pressure[IMAX][JMAX]- computed pressure at sea               */
* floor                                                          */

* funcinput - input depth values into array                     *

* funcavgpressure - compute averagepressure                      *
* funcoutput - output the arrays                                  *

```

#include <stdio.h>

#define IMAX 8
#define JMAX 10

void funcinput(float depth1[][JMAX]);
void funcpressure(float depth1[][JMAX], float pressure[][JMAX]);
float funcavgpressure(float pressure[][JMAX]);
void funcoutput(float array1[][JMAX]);

int main()
{
    float depth[IMAX][JMAX];
    float pressure[IMAX][JMAX], averagepressure;

    funcinput(depth);

    printf("Measured Depths\n");
    funcoutput(depth);
    funcpressure(depth, pressure);
    printf("Computed Pressure\n");
    funcoutput(pressure);
    averagepressure = funcavgpressure(pressure);
    printf("Average Pressure: %6.2f\n", averagepressure);
    return 0;
}
```

```c
********************************************************************/
/* funcinput: Input the Measured Values of the */
/* Depth in Feet */
********************************************************************/
/* Output Parameters: */
/* depth1[][JMAX] - measured depth of water */
/*                   in feet */
/* Input Variables: */
/* depth1[][JMAX] - measured depth of water */
/*                   in feet */
****************************************************/
void funcinput(float depth1[][JMAX])
{
  FILE *inptr;
  int i, j;

  inptr = fopen("depth.dat", "r");
  for(i = 0; i < IMAX; i++)
    for(j = 0; j < JMAX; j++)
      sscanf(inptr, "%f", &depth1[i][j]);

  fclose(inptr);
  return;
}
```

## 8.7 Sample Programs

```c
********************************************************************
/*
* funcpressure: Compute the Pressure in Pounds *
* Square Inch *
********************************************************************
/*
* Input Parameters: */
* depth1[][JMAX] - depth of water in *
* square inch *
* Computed Variables: */
* pressure[][JMAX] - pressure of water in *
* pounds square inch *
* Output Parameters: */
* pressure[][JMAX] - pressure of water in *
* pounds square inch */
********************************************************************
void funcpressure(float depth1[][JMAX], float pressure[][JMAX])
{
    int i, j;

    for(i = 0; i < IMAX; i++)
        for(j = 0; j < JMAX; j++)
            pressure[i][j] = 0.4333 * depth1[i][j];

    return;
}
```

```c
********************************************************************
/*
* funcavgpressure: Compute the Average Pressure in Pounds
* Square Inch *
********************************************************************
/*
* Input Parameters: */
* pressure[][JMAX] - pressure of water in *
* pounds square inch *
* Returned Variables: */
* avgpressure - average pressure in pounds *
* square inch */
********************************************************************
float funcavgpressure(float pressure[][JMAX])
{
    int i, j;
    float sumpressure = 0.0;
    float average_pressure = 0;

    for(i = 0; i < IMAX; i++)
        for(j = 0; j < JMAX; j++)
            sumpressure += pressure[i][j];

    average_pressure = (sumpressure / (IMAX * JMAX));
    return average_pressure;
}
```

## 8.7.4 Geometric Transformations

In computer graphics, points, lines, and polygons are translated from one position to another, and lines and polygons are rotated and scaled. These types of operations are sufficient to change the position, the orientation, and the size of the objects that are displayed. These are called geometric transformations. Transformations in two-dimensions are carried out by multiplying three-by-three square matrices. Transformations in three-dimensions are carried out by multiplying four-by-four square matrices. This example shows the development of a small library of useful functions.
