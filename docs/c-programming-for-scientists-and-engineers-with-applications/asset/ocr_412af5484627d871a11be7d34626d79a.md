Input Data:
AAXXXXAAAA

KPPKKK LLKLLKLLLL KKKKK
LLLLLL

OUTPUT STRING:
12 AAXXXXAAAA
17 XXX YYYYYYYPPPP
27 KPPKKK LLKLLKLLLL KKKKK
7 LLLLLL
31 BBBBBBBBBBBBBBBBBPPPPBBBB

Notice that the input data contains strings with embedded blank spaces and since trailing blanks are ignored, the strings are of different lengths. The input function gets() inputs strings from a data file up to and including the line feed character '\n' and stores them in strname, which has space for 80 characters.
