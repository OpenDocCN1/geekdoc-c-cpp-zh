# Pseudocode

```
For each set of data in a file
nInput sides a, b, c
Output sides a, b, c
If(a + b > c and b + c > a and c + a > b)
  {
    Output message "they form a triangle"
    If(a= b and b= c and c= a)
    {
        Output message "they form the scalene triangle"
    }
    If(a² + b² == c² || b² + c² == a² || c² + a² == b²)
      Output message "they form a right triangle"
  }
}
End for
Stop
```
