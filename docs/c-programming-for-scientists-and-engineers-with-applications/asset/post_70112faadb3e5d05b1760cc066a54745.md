## 6.1.3 Scope of Access

When variables are declared with local scope, they can be accessed by a different name outside that scope by passing their values or addresses as arguments. The following examples differ from the example of Section 6.1.2 in that each function calls the variable x by value to a function that picks it up under the local y. The print statements have been altered to print both x and y.

```c
#include <stdio.h>
void func1(int);
void func2(int);
void func3(int);

int main() 
{
    int x = 20, y = 9;
    printf("In main x = %d, y = %d\n", x, y); /* 1 */
    func1(x);
    x = x + 10;
    printf("In main x = %d, y = %d\n", x, y); /* 2 */
    func2(x);
    x = x + 40;
    printf("In main x = %d, y = %d\n", x, y); /* 3 */
    func3(x);
```

## 6.2 Storage Classes in a File

Variables are classified by storage classes according to where they are declared. There are four classes: auto, extern, static and register. All storage classes except extern have file scope, meaning they are only accessible in the file in which they are declared. The general form of storage class is:

### 6.2.1 Storage Auto

Storage auto is the default class. All variables variables declared a a and are auto storage class. An storage class variable need not be given a value when it is declared. However, such a variable must be given a value before its value is used. The following examples show the declaration and use of auto.

```c
#include <stdio.h>
int funccl(int, int);
int main() {
    int x = 10, y = 5, z;
    z = funccl(x, y);
    printf("x = %d y = %d z = %d\n", x, y, z);
    return 0;
}

int funccl(int a, int b) 
{
    int c;
    c = a + b;
    return c;
}
```

| x | y | z |
|---|---|---|
| 10 | 5 | 15 |

| c |
| 15 |

## 6.2.2 Storage Class Extern

The extern storage class is used primarily to access functions that have been declared and implemented in another source code file, and to access tables that are stored in separate files.

Any variable declared global to the entire program or declared outside any function or functions is an extern storage class variable. An extern storage class variable is automatically defined when it is declared and given a default value of zero, provided that it is not declared as extern. When it is specifically declared as extern, no value is assigned and no value is assigned. The following examples show the definition and declaration of extern storage class variables.

```c
#include <stdio.h>
void func1(void);
void func2(void);
int main ( {
    int x = 5; /* local auto class variable declaration */
    printf("In main x = %d\n", x); /* 1 */

    x = x + 5;

```
