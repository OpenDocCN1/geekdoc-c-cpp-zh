## 1.3.5 Concept of Structured Programming

The development of algorithms in top-down methodology should use only the three basic structures. A program is a sequence of steps; each step is an instruction or group of instructions to be executed by the computer. Some of the instructions are executed only once; others are executed selectively; others are executed repeatedly. The three basic structures are the sequence structure, selection structure, and repetition structure.

**Sequence Structure** A sequence structure is one in which execution flows from one step to the next in sequence, without skipping any steps, executing each step once. This is shown in the diagram in Figure 1.11. An example of this structure written in C is:

```
stmt 1    x = 18.25;
stmt 2    y = 8.75;
stmt 3    z = x + y;
```
