Figure 10.3 Variables and pointer variables

Since pointer variables are variables, they can point to different variables at different times, but they must always point to variables of the same data type. In the following code:

```
int x, y;
int *ptr;

x = 312;
y = -74;
ptr = &x;
printf("%d", "*ptr);
ptr = &y;
printf("%d", "*ptr);
```

the output is: 312 -74

The pointer variable ptr is first assigned the address of x so that it points to the value 312 stored in x. And then it is assigned the address of y so that it points to the value -74 stored in y.
