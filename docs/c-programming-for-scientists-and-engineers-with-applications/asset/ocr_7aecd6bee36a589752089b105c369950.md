# 7.3 Output of One-Dimensional Arrays 405

```
printf("Array x Array y\n");
for(i = 0; i < N; i++)
{
    printf("%d %d %d\n", i+1, x[i], y[i]);
}
```

The code above produces the following:

| Array x Array y |
| 1 | 10 26 |
| 2 | 15 45 |
| 3 | 18 53 |
| 4 | 45 98 |
| 5 | 62 70 |

Notice that the corresponding elements of arrays x and y are printed side-by-side and the lines are numbered. Depending on the application, one can choose to print on a line horizontally or vertically in columns.
Note that the data may be written to a data file one array at a time or as pairs of corresponding elements.
