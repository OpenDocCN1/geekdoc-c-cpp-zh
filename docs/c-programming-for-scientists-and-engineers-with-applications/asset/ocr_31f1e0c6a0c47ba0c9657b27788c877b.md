# 10.4 Dynamic Storage and Arrays

Dynamic storage is simply storage that is allocated while a program is executing. It is allocated from the available part of computer memory after the program determines how much storage is needed. Storage that is declared in a program is called static storage. It is allocated before the program is executed.
