```

int b[N] = {86, 67, 43, 65, 59};
```

```
a. for(i = 0; i < N; i++)
{
    printf("%d  %d\n", i, a[i], b[i]);
}
```

```
b. for(i = N - 1; i >= 0; i--)
{
    for(j = 0; j < N; j++)
        printf("%3d    %d\n", a[i]+ b[j]);

}
```
