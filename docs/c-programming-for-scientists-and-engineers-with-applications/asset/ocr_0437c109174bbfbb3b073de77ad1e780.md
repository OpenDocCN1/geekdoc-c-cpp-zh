The values contained in the arrays a and b before the assignment and after the assignment are as follows:

Before

| a + 0 | 12.75 | b + 0 | UUUUUU |
| a + 1 | 18.34 | b + 1 | UUUUUU |
| a + 2 | 9.85 | b + 2 | UUUUUU |
| a + 3 | 23.78 | b + 3 | UUUUUU |
| a + 4 | 16.96 | b + 4 | UUUUUU |

After

| a + 0 | 12.75 | b + 0 | 12.75 |
| a + 1 | 18.34 | b + 1 | 18.34 |
| a + 2 | 9.85 | b + 2 | 9.85 |
| a + 3 | 23.78 | b + 3 | 23.78 |
| a + 4 | 16.96 | b + 4 | 16.96 |

Notice that the address must be dereferenced to access the contents of the arrays and must also be dereferenced to obtain storage for the value copied. Rather than using an offset, the pointer variables could have been incremented as in the following example.

The array a can be copied into array b in reverse order by using address offset. The address must be dereferenced. The following code shows such a copy.

```
#include <stdio.h>
int main( )
{
    int i, j;
    float a[5], b[5];
    float *ptra, *ptrb;

    ptra = a;
    ptrb = &b[4];

    for(i = 0; i < 5; i++)
    {
        *ptrb = *ptra;
        ptra++;
    }
```
