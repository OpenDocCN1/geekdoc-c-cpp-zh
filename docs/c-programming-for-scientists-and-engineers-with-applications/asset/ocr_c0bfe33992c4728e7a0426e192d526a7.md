# 8.7 Sample Programs

```
void funcrotate(float rotatem1[ ][IMAX)
{
    const float PI = 3.141593;
    float angle, theta;
    printf("Input the angle of rotation (degrees):\n");
    scanf("%f",&angle);

    theta = (PI /180.0) * angle;
    rotatem1[0][0] = cos(theta);
    rotatem1[0][1] = -sin(theta);
    rotatem1[1][0] = sin(theta);
    rotatem1[1][1] = cos(theta);
    rotatem1[2][2] = 1.0;

    return;
}
```

Input and Output

Input the coordinate points x1 y1, x2 y2:
1.50 2.50
2.50 4.50

Input the angle of rotation (degrees):
10.0

Output of old coordinates points x1 y1,x2 y2:
POINT 1: ( 1.50 2.50 )
POINT 2: ( 2.50 4.50 )

Output of new coordinates points x1 y1,x2
POINT 1: ( 1.04 2.72 )
POINT 2: ( 1.68 4.87 )

Notice that the multiplication matrix funcmultiply is used from the translation of the line program with the argument of the translation matrix replaced by the rotation matrix.
