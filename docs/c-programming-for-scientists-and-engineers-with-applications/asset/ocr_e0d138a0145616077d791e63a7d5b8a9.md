The following program shows the multiplication of two matrices: x = y * z

```
#include <stdio.h>
#define IMAX 3
#define JMAX 5
#define KMAX 4
int main() 
{
    int i, j, k, sum;
    int x[IMAX][JMAX], y[IMAX][KMAX], z[KMAX][JMAX];
    for(i = 0; i < IMAX; i++) {
        for(j = 0; j < JMAX; j++) {
            sum = 0.0;
            for(k = 0; k < KMAX; k++) {
                sum = sum + y[i][k] * z[k][j];
            }
            z[i][j] = sum;
        }
    }
    return 0;
}
```

This is a standard algorithm for matrix multiplication that is used in solving a system of equations. Matrix multiplication is also used in the geometric transformations of computer graphics such as translation, rotation, and scaling.
