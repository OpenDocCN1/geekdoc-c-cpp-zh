# Input and Output

# Objectives

To learn the use of the instructions that move data in and out of the computer memory. To learn the design of readable data.

> Input means providing the information or data the program needs for computation, and output means displaying, printing, or writing to a data file the computed results or the data program produces. C provides various functions to input the data to the program and various functions to output the data from a program. The following sections present these functions.
