One or More Statements in Each Branch—an if-else Structure The C code has the form

```
if(condition)
{
    sequence 1
}
else
{
    sequence 2
}
```

The execution sequence of this code is as follows:

+   * If the condition is true, sequence 1 is executed and sequence 2 in the false branch is skipped.
* If the condition is false, sequence 2 is executed and sequence 1 in the true branch is skipped.
