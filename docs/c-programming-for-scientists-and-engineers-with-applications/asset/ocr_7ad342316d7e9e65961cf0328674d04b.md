Defining a function says what it does with the input data to produce the output data. This is done by writing a C programming language implementation of the function. If a function is defined ahead of the main function, the definition also serves as the function declaration. If a function is defined after the main function, it must be declared ahead of the main function or inside the main function block, if the function is invoked by main.

The function that processes a single positive data value should be given an appropriate name such as compute. It is not a main function as it takes as input data that has already been read and validated as positive, and is only invoked many times, once for each positive data value.
