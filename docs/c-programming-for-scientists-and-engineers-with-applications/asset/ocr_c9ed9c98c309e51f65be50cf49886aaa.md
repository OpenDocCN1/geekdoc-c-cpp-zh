Pointer variables must be dereferenced when they are used in place of ordinary
variables for instance.

```
int x;
int *ptr;
```

```
== x;               or ...= *ptr;
x = ...               or *ptr = . .
```

```
printf("%d", x);   or printf("%d", *ptr);
func(x);            or func(*ptr); call by value
```

Pointer variables are not dereferenced when they are used in context where the
address operator "&" would be used with an ordinary variable, for example.

```
int x;
int *ptr;
```

```
scanf("%d", &x);   or scanf("%d", *ptr);
..= &x;               or ..= ptr;
```

Pointer variables are also dereferenced when they point to arrays, but they are
subscribed or in array arithmetic just as array names are, for instance.

```
int arr[10];
int *ptr;
```

```
arr[6] = ..    or ptr[6] = . . .;
..= arr[6];           or ..= ptr[6];
```
