#  8.6.3 Output of Three-Dimensional Arrays

To output data from a three-dimensional array using index variables requires three nested loops. The outer loop must be the plane loop, the next inner loop must be the row loop, and the innermost loop must be the column loop. The following code shows the output of a three-dimensional array with blanks separating each set of rows and columns.

# Output Using Array Index

```
#define KMAX 5
#define IMAX 3
#define JMAX 4

float x[KMAX][IMAX][JMAX]
int i, j, k;
for(k = 0; k < KMAX; k++)
{
  printf("page no: %d\n", k);
  for(i = 0; i < IMAX; i++)
  {
    for(j = 0; j < JMAX; j++)
    {
      printf("%f ", x[k][i][j]);
    }
    printf("\n");
  }
  printf("\n\n");
}
```
