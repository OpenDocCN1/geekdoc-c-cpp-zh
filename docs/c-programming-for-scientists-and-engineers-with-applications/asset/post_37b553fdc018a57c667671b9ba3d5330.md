Arithmetic Operations Using Array Offset Offset arithmetic operations such as addition, multiplication, and division may be performed using array offset. The following program code shows the addition operation using array offset.

```c
#include <stdio.h>
int main() {

}
```

# 10.3.2 Increment and Decrement Operations

Increment and decrement operations on pointers can be used in manipulating numeric arrays and character string arrays without using subscripts. Array pointers to one-dimensional and multidimensional arrays can be incremented to access the elements of the array sequentially from the beginning of the array. The array elements can be accessed sequentially from the end of the array by decrementing the array pointer by one from the end of the array. The increment and decrement operations were presented in Chapter 2. The following code shows the increment operation for a pointer to a string.

```c
#include <stdio.h>

int main()
{
    char str[10] = "ELECTRON";
    char *strptr;
    int i;

    strptr = str;

    for(i = 0; i < 8; i++)
    {
        printf("%c ", strptr);
        strptr++;
    }

    return 0;
}
```

The output is as follows:

ELECTRON

Note that the array name strname cannot be used in the way strptr is used to scan the array, because the array name is a constant and cannot be changed.

> **Program Warning:** If an array name is assigned to a pointer variable, and if the pointer variable is incremented, it no longer points to the beginning of the array; the pointer must be reset to point to the beginning of the array.

Nested loops are used to increment the array pointer by rows and by columns.

```c
#include <stdio.h>
#define IMAX 3
#define JMAX 4

int main() 
{
    float values[IMAX][JMAX];
    int i, j;

    for(i = 0; i < IMAX; i++) {
        for(j = 0; j < JMAX; j++) {
            scanf("%f", *(values + i) + j);
        }
    }
    for(i = 0; i < IMAX; i++) {
        for(j = 0; j < JMAX; j++) {
            printf("%5.2f ", *(values + i) + j);
        }
        printf("\n");
    }
    return 0;
}
```

As the computer does not check array bounds, if an array is stored in row-major order, an array pointer and a single loop can be used to input or output all elements as in the following:
