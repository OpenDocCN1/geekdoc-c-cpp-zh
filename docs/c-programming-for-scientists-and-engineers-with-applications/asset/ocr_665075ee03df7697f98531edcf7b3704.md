# Before (function call)

| a[0] | 1 | b[0] | 6 |
| a[1] | 2 | b[1] | 7 |
| a[2] | 3 | b[2] | 8 |
| a[3] | 4 | b[3] | 9 |
| a[4] | 5 | b[4] | 10 |

# After (function call)

| a[0] | 1 | b[0] | 9 |
| a[1] | 2 | b[1] | 11 |
| a[2] | 3 | b[2] | 13 |
| a[3] | 4 | b[3] | 15 |
| a[4] | 5 | b[4] | 17 |

Notice in the function call the elements of array a are passed by value though they are scalars. The elements of array a are copied into temporary storage and the contents of the temporary storage is accessed in the function. If elements of array a are changed in the function, the original values of the elements of array a will not change because they are passed by value. This protects the original arrays but is inefficient for large arrays as the function must be called many times. The elements of array b are passed by address; therefore, changing the values in the function changes them in the original array.

> **Program Warning:** Pass array elements by value to protect the array against changes in a function.
