# The following example shows the use of the strcmp() function:

```
int k;
strng1[] = "comparison";
strng2[] = "communication";
```

k = strcmp(strng1, strng2);

Characters in strng1 and strng2 are compared character-by-character. In the fourth position m and p are unequal, and the numerical code for p is greater than the numerical code for m, which identifies strng1 as after strng2. This comparison generates a number greater than zero, because strng1 follows strng2. The programmer may test the result of this comparison and execute a statement or statements as follows:

```
if(strcmp(strng1, strng2) > 0)
    statement1;
else
    statement2;
```

In this case since strng1 is alphabetically later than strng2, statement1 is executed.
This may also be implemented in another way by declaring an integer variable and assigning the result of the string comparison to this integer variable. The following code shows such an implementation.

```
int c;
c = strcmp(strng1, strng2);
if(c > 0)
    statement1;
else
    statement2;
```

strng1 is greater than strng2, the string comparison generates a number greater than zero and assigns number to c and the relational expression c > 0 is true in this case, therefore statement1 is executed.
