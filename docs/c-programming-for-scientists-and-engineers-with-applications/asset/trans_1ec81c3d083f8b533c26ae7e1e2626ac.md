

## 7.4.2 数组算术

可以使用循环改变下标，从而对数组元素执行加法、减法、乘法和除法等算术操作。下标数组变量可以在算术表达式中使用。接下来的代码段落展示了数组在算术表达式中的用法及其结果。

### 向数组元素相加标量常量

```c
#define SIZE 5
int i;
int a[SIZE];

for(i = 0; i < SIZE; i++)
{
  a[i] = a[i] + 5;
}
```

| 之前 | 之后 | 之前 | 之后 |
|---|---|---|---|
| a[0] | 12 | a[0] | 17 |
| a[1] | 18 | a[1] | 23 |
| a[2] | 9 | a[2] | 14 |
| a[3] | 23 | a[3] | 28 |
| a[4] | 16 | a[4] | 21 |

同样，也可以对数组元素与标量常量进行减法、乘法和除法操作。

加、减、乘、除算术操作可以应用于两个数组的元素，并将结果存储在另一个数组中。以下代码段展示了此类操作。

这里展示了数组 `a` 与数组 `b` 逐元素相加，结果存储在数组 `c` 中。

```c
#define SIZE 5
int i;
int a[SIZE], b[SIZE], c[SIZE];

for(i = 0; i < SIZE; i++)
{
  c[i] = a[i] + b[i];
```

| a[0] | 12 | b[0] | 6 | c[0] | 18 |
|---|---|---|---|---|---|
| a[1] | 18 | b[1] | 9 | c[1] | 27 |
| a[2] | 9 | b[2] | 4 | c[2] | 13 |
| a[3] | 23 | b[3] | 11 | c[3] | 34 |
| a[4] | 16 | b[4] | 8 | c[4] | 24 |

同样，也可以对两个数组进行逐元素的减法、乘法或除法。

### 数组元素的求和

求和数组元素是一个非常常用的操作，例如在科学和工程应用中计算平均值。以下代码段展示了数组元素的求和。

```c
#define SIZE 5
int i;
int a[SIZE];
int sum;

sum = 0;
for(i = 0; i < SIZE; i++)
{
    sum += a[i];
}
printf("Sum is: %d", sum);
```

| a[0] | 12 |
| a[1] | 18 |
| a[2] | 9 |
| a[3] | 23 |
| a[4] | 16 |

使用上述数据，打印的求和结果如下：
Sum is: 78

> 程序警告：当访问索引范围之外的数组元素时，编译器不会给出警告。程序员负责使用正确的索引值以避免运行时错误。

### 两个向量的点积

如果 $x$ 和 $y$ 是两个向量，那么它们的内积在数学上的定义为：

$$x \cdot y = \sum_{i=1}^{n} x_i y_i$$

以下代码为长度为 $n$ 的向量计算此方程。

```c
int i, n;
float sum = 0;
for(i = 0; i < n; i++)
{
  sum += x[i] * y[i];
}
```
