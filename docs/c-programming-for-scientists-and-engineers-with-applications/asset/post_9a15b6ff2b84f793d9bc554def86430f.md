
## 7.3 Output of One-Dimensional Arrays

The elements of an array can be printed vertically in a column, as is done by the following code.

```c
#define N 5
int i;
int a[N] = {12, 13, 25, 16, 43};

for(i = 0; i < N; i++)
{
    printf("%d\n", a[i]);
}
```

12
13
25
16
43

Output to a Data File "myfile.data"

```c
#define A 5
FILE *outptr;
int i;
int a[A] = {12, 13, 25, 16, 43};

outptr = fopen("myfile.dat", "w");

for(i = 0; i < A; i++)
    fprintf(outptr, "%d", a[i]);
```

The output of the array elements will be written to a data file "myfile.dat" on a line with four blank spaces between each element as shown:

| myfile.dat |
| outptr -> 12 13 25 16 43 |

Notice that the integer number 12 is from the storage of element a[0], 13 is from the storage of element a[1], and so on, are written horizontally along a line to a data file "myfile.dat".

### 7.3.2 Output of Parallel Arrays

Several one-dimensional arrays may be printed either on separate lines or in columns. The following examples show the output of multiple arrays. The output of each array is printed horizontally.

```c
#define N 5
int i;
int x[N] = {10, 15, 18, 25, 62};
int y[N] = {26, 45, 53, 98, 70};

printf("Array x: %s");
for(i = 0; i < N; i++)
{
    printf("%d ", x[i]);
}

printf("Array y: %s");
for(i = 0; i < N; i++)
{
    printf("%d ", y[i]);
}
printf("\n\n");
```

The output is as follows:

Array x: 10  15  18  45  62
Array y: 26  45  53  98  70

Notice that array x is printed first and then array y is printed on a separate line because there are two explicit loops with an output statement between them, which forces a new line.
The arrays may be printed side-by-side vertically in columns using one for loop.

```c
#define N 5
int i;
int x[N] = {10, 15, 18, 45, 62};
int y[N] = {26, 45, 53, 98, 70};
```

```c
printf("Array x Array y\n");
for(i = 0; i < N; i++)
{
    printf("%d %d %d\n", i+1, x[i], y[i]);
}
```

The code above produces the following:

| Array x Array y |
| 1 | 10 26 |
| 2 | 15 45 |
| 3 | 18 53 |
| 4 | 45 98 |
| 5 | 62 70 |

Notice that the corresponding elements of arrays x and y are printed side-by-side and the lines are numbered. Depending on the application, one can choose to print on a line horizontally or vertically in columns.
Note that the data may be written to a data file one array at a time or as pairs of corresponding elements.

## 7.4 Manipulation of Arrays

Any operation that can be performed on individual variables can be performed on the elements of an array. Elements of type int, float, and double can be used in arithmetic and logic comparisons just as single variables. In C, arithmetic and logic operations are performed on individual elements by explicitly specifying the index of the element.

### 7.4.1 Assignment

The elements of a one-dimensional array may be manipulated using the array index. They can be accessed individually by specifying the index of a specific element, or sequentially from the beginning index or from the end index of the array. The values of one array are assigned to another using a for loop. There is no assignment operation for arrays. The elements must be copied individually from one array to another. When numeric arrays are copied, if the data type of the source does not match the data type of the destination array, data conversion will occur for each element. The values of the source array are converted to the data type of the destination array without changing the data type of the source array. The following code shows the assignment of the elements of array a to array b.

```c
#define SIZE 5
int i;
float a[SIZE], b[SIZE];
for(i = 0; i < SIZE; i++)
b[i] = a[i];
```

Notice that the arrays must have the same number of elements. The values contained in array a and the array b before and after the assignment are as follows:

| Before | After |
|---|---|---|---|
| a[0] | 12.75 | b[0] | 12.75 |
| a[1] | 18.34 | b[1] | 18.34 |
| a[2] | 9.85 | b[2] | 9.85 |
| a[3] | 23.78 | b[3] | 23.78 |
| a[4] | 16.96 | b[4] | 16.96 |

Notice that the values in array b are replaced by the corresponding values of array a. The values of array a are not altered. Only values of the target array b, which is on the left side of the assignment symbol, are altered. The array can be copied into the array b in reverse order. The following code shows such a copy.

```c
#define SIZE 5
int i;
int a[SIZE], b[SIZE];

for(i = 0; i < SIZE; i++)
{
    b[SIZE - 1 - i] = a[i];
}
```

| Before | After |
|---|---|---|---|
| a[0] | 12.75 | b[0] | 16.96 |
| a[1] | 18.34 | b[1] | 23.78 |
| a[2] | 9.85 | b[2] | 9.85 |
| a[3] | 23.78 | b[3] | 18.34 |
| a[4] | 16.96 | b[4] | 12.75 |

Notice the elements of the array a are stored in the array b in reverse order.

When it is necessary to exchange the values of elements between two arrays of the same size, a temporary variable is used. This is accomplished by using the for loop as follows:

```c
#define SIZE 5
int i;
float x[SIZE], y[SIZE], temp;

for(i = 0; i < SIZE; i++)
{
  temp = x[i];
  x[i] = y[i];
  y[i] = temp;
}
```

This swap operation is the basis of a simple but not very efficient method of sorting an array to arrange the values in ascending order called an insertion sort. The smallest element is located at position a[k] and placed in the position a[0] while the element originally in position a[0] is put in position a[k]. The second smallest element is located at position k (a new k) and placed in the position a[1] by swapping it with the element in a[1]. Each time through the array, the smallest remaining element is placed in position, until the whole array has been sorted. This is shown in the following example:

```c
#define SIZE 5
int i, j, k;
float a[SIZE], temp;

for(j = 0; j < SIZE - 1; j++)
{
    temp = a[j];
    k = j;
    /* find jth smallest number */
    for(i = j + 1; i < SIZE; i++)
    {
        if(a[i] < temp)
        {
            temp = a[i];
            k = i;
        }
    }
    a[k] = a[j];
    a[j] = temp;
}
```

Another common programming situation is moving some of the elements of a list down one position in order to insert a new element. In this example, assume that the element a[k] is to be placed at position a[j], j < k, by moving the elements a[j], a[j+1],...,a[k-1] down one position to leave an empty storage location at a[j].

```c
#define SIZE 5
int i, j = 0, k = 4, SIZE = 5;
int a[SIZE], temp;

temp = a[k];
for(i = k; i > j; i--)
{
    a[i] = a[i-1];
}
a[j] = temp;
```
