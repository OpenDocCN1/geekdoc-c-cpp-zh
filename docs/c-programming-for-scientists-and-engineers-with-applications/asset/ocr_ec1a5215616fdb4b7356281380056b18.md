# 3.4 Input and Output of Characters

Characters in ASCII are represented internally in memory by numbers. The ASCII code for the characters is given in Appendix A.

The declaration of a char variable allocates one byte of memory. One byte of memory can hold decimal numbers in the range 0 to 255. Since ASCII character codes range from 0 to 127, one byte of storage is enough to store any character in the ASCII code. Character variables are declared as follows:

```
char ch1, ch2, ch3;
```
