# 8.1 Introduction to Two-Dimensional Arrays

```
int main() {
    float value[IMAX][JMAX];
    int i, j;

    for(i = 0; i < IMAX; i++) {
        for(j = 0; j < JMAX; j++) {
            if (i == j)
                value[i][j] = 2.0;
            else if (i > j)
                value[i][j] = 4.0;
            else
                value[i][j] = 8.0;
        }
    }
    return 0;
}
```

The values assigned to the array are:

| 2.0 8.0 8.0 8.0 |
| 4.0 2.0 8.0 8.0 |
| 4.0 4.0 2.0 8.0 |
| 4.0 4.0 4.0 2.0 |

Notice that all the major diagonal elements are set to a value of 2.0, the lower triangle elements are set to 4.0, and the upper triangle elements are set to 8.0.
