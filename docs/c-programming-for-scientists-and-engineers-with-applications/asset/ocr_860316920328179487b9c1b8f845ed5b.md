# 2.1.3 Statically Typed Language

In C, the data types of variables and functions must be declared. There are basic or built-in data types. The basic or built-in data types are integer (int), floating-point (float), double precision (double), and character (char). The basic or built-in data types are not enough to represent data for applications with complicated data types such as lists, tables, vectors, matrices, and records of mixed data types. In arrays, character strings, and structures are derived data types derived from basic data types int, float, double, and char; vectors and arrays are heterogeneous aggregates of numeric and character types; character strings are homogeneous aggregates of characters; and structures are nonhomogeneous data aggregates of more than one type. These complex data types are presented in detail in Chapters 7, 8, and 9.
