3. Write a program to compute the power loss in a transmission line with a resistance of 0.05 ohms/mile. Compute the power loss if 500 kW of power is transmitted from a power generation station to cities at distances of 20, 30, 40, 50, ...,100 miles at 100 V and 200 V.
The current $i$ is calculated as from:

```
$i = \frac{\text{power transmitted in watts}}{\text{volts transmitted}}$
```

The total resistance R is computed from the equation:

```
$R = r \times \text{miles}$
```

where r is the resistance per mile.
The power loss is computed from the equation:
Power loss = $i^2 \times R$.
