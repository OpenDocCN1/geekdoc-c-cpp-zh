Method Input the translation matrix

```
$T(t_x, t_y) = \begin{pmatrix} 1 & 0 & t_x \ 0 & 1 & t_y \ 0 & 0 & 1 \end{pmatrix}$
```

Where $t_x$ is the translation in the $x$-coordinate direction, and $t_y$ is the translation in the $y$-coordinate direction.

Input the coordinates of the line.

```
$L(x_1, y_1) L(x_2, y_2)$
```

```
$L = \begin{pmatrix} x_1 & x_2 \ y_1 & y_2 \ 1 & 1 \end{pmatrix}$
```

Multiply the translation matrix and the coordinates of the line.
