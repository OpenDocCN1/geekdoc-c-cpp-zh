# 430 One-Dimensional Arrays

```
/* Input Parameters: */
/* expdata[n]- Experimental data */
/* n - number of data values */
/* Local Variables: */
/* sumqr - sum of the squares of the data values */
/* sqsum - square of the sum of the data values */
/* stdev - standard deviation */
/* Return value: */
/* stdev - standard deviation */
/* Functions Called: none */
********************************************************************************
```

```
float funcstdev(float expdata[], int n)
{
    int i;
    float sum = 0, sumqr = 0, sqsum, stdev;
    for(i = 0; i < n; i++) {
        sum += expdata[i];
        sumqr += expdata[i] * expdata[i];
    }
    sqsum = sum * sum;
    stdev = sqrt((sumqr - (sqsum / n))/(n - 1));
    return stdev;
}
```
