# 200 Control Structures

One Statement in a Single Branch Single statement in one branch of selection structure—an if structure

![](bbox=[0.328, 0.175, 0.745, 0.375])

The form of the C code is as follows:

```
if(condition)
    statement; /* single statement */
```

Notice in this structure there is only one statement in the true branch. There is no need to use braces to block a single statement in a selection branch.

> Programming Practice: Indent the statements within the branches of a selection structure.
