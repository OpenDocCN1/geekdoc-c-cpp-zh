This example demonstrates the use of repetition controlled by a counter. The coil is in the following AC circuit:

![](bbox=[0.408, 0.157, 0.683, 0.276])

*Data:*  Input voltage (volts), current (amps), resistance (ohms), and frequency (cycles/second).

Method

```
$Z = \frac{V}{I}$
$Z^2 = X_L^2 + R^2$
$X_L = \sqrt{Z^2 - R^2}$
X_L = 2\pi fL$
L = \frac{X_L}{2\pi f}$
```

where L is the inductance of the coil,
X_L$ is the reactance, and
Z$ is the impedance.

Pseudocode

For each of six sets of values
Input voltage, current, resistance, and frequency
Calculate the impedance

```
$Z \leftarrow V/I$
Calculate the reactance
X_L = \sqrt{Z^2 - R^2}$
```
