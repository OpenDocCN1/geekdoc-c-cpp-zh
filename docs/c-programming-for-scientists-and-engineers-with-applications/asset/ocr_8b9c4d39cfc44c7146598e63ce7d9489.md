4. Write a main function and the following functions to compute the velocity at various time intervals of a body sliding down a slope with an initial velocity $v_0$. If initial velocity $v_0 = 5$ and acceleration $a = 20.5t + 9.75$.

Acceleration $a$ as derivative of velocity with respect to time is given by

$a = rac{dv}{dt} \text{ at } t = 0$

therefore,

$\int_{0}^{v} dv = \int_{0}^{t} a \ dt$$
$$= \int_{0}^{t} (20.5t + 9.75) dt$

therefore,

$v - 5 = \frac{20.5}{2}t^2 + 9.75t$

therefore,

$v = 10.25t^2 + 9.75t + 5$

+   * A function to compute $v$ from the preceding formula with $t = 0.5$ to $10.0$ by increments of $0.5$.
