# 8.4 Manipulation of Arrays

In c it is not possible to perform the arithmetic operations of addition, subtraction-
mplication, and division on arrays by array name. These operations must
be performed element-by-element using nested loops for indexing the ele-\ments of the array. Also, assignment of one array to another array must be ele-
ment-by-element, not by array name.
