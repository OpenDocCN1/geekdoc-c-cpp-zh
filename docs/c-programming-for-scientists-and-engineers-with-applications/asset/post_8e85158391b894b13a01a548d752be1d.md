
## 9.3 Strings and Functions

This string can be printed in a function that does not know either the length of the string or the size of the array because a null terminator identifies the end of the string.

An array of strings may be passed to a function as a two-dimensional array. The following code indicates how an array of strings is passed to a function.

```c
#include <stdio.h>

#define NUMSTR 5
#define STRLNG 10

void funcinput(char strname[][STRLNG]);
void funcoutput(char strname[][STRLNG]);

int main() {
    char strname[NUMSTR][STRLNG];
    funcinput(strname);
    funcoutput(strname);
    return 0;
}

void funcinput(char strname1[][STRLNG]) {
    int i;
    for(i = 0; i < NUMSTR; i++)
        gets(strname1[i]);
    return;
}

void funcoutput(char strname2[][STRLNG]) {
    int i;
    for(i = 0; i < NUMSTR; i++) {
        puts(strname2[i]);
    }
    return;
}
```

## 9.4 String Library Functions

In C there are no operators to manipulate strings because string is not a basic data type. However, C has a rich library of string manipulation functions. They are in the string.h library. This library must be included in the program in order to use these functions. The statement #include <string.h> will provide access to all of the string functions. The functions are used for the common operations of joining strings to build longer strings, comparing strings, copying strings, extracting substrings from strings, and extracting characters from strings. String functions are used to implement string operations in application software such as word processors, spreadsheets, and databases. A list of string functions are presented in Appendix B.

### 9.4.1 String Assignment

Because strings are stored as arrays, the value of one string cannot be copied to a different variable by assignment. To assign a string variable to another variable in such a way that there are two string variables with the same value, it is necessary to use the string copying function strcpy.

```c
char strname1[10] = "XXABCL";
char strname2[10] = [];
```

Unless the strcpy function is used, strname1 must be copied to strname2, element-by-element strname1 and strname2 to have the same values.

### 9.4.2 String Copy (strcpy)

The string copy function is used to copy a string value from one variable to another string. There are two forms of the string copy, one with two arguments and another with three arguments.

#### First Form of the Function with Two Arguments

The following code shows the use of string copy function. This function can be used to assign the value of one variable to another. It can also be used to replace partial strings.

```c
char strname1[] = "Storage Today";
char strname2[] = "Most Advanced";
```

Characters and Strings
Strings before Copy:
```
strname1: Storage Today
strname2: Most Advanced
```

The string copy function is coded as follows:

```c
strcpy(strname1, strname2);
printf("strname1: %s", strname1);
printf("strname2: %s", strname2);
```

The output after copy is as follows:
```
strname1: Most Advanced
strname2: Most Advanced
```

Strings after Copy:
```
strname1: Most Advanced
strname2: Most Advanced
```

Notice that strname2 is copied into strname1. In doing this, make sure that the storage has enough storage to store the copied value. Also notice that when strname2 is copied into strname1 the null terminator is also copied, which marks the end of the string. The characters beyond the null terminator in strname1 cannot be accessed as a string after copying strname2 to strname1. Those characters are only accessible-by-element.

#### Second Form of the Function with Three Arguments

The second form of the string copy function has three arguments. The third argument specifies the number of characters to be copied. The use of such function is as follows:

```c
char strname1[] = "Storage Today";
char strname2[] = "Most Advanced";
```

Strings before Copy:
```
strname1: Storage Today
strname2: Most Advanced
```

The string copy function is coded as follows:

```c
strncpy(strname1, strname2, 4);
printf("strname1: %s", strname1);
printf("strname2: %s", strname2);
```

The output after copy is as follows:
```
strname1: Most
strname2: Most Advanced
```

Strings after Copy:
```
strname1: Most
strname2: Most Advanced
```

Notice that only the first characters "Most" of strname2 are copied into strname1 and the rest of the characters in strname1 are retained. If only part of strname2 is copied, in this example, then the null character is not copied.

Strings before Copy:
```
strname1: Storage Today
strname2: Most Advanced
```

The string copy function is coded as follows:

```c
strncpy(strname1, strname2, 15);
printf("strname1: %s", strname1);
printf("strname2: %s", strname2);
```

The output after copy is as follows:
```
strname1: Most Advanced
strname2: Most Advanced
```

Since the third argument is greater than the non-null terminating characters of strname2, the null character is copied along with the other characters.

Strings after Copy:
| Variable | Value |
|---|---|
| strname1 | Most Advanced |
| strname2 | Most Advanced |

**Program Warning:** If the length of the string being copied is greater than the size of the space it is copied to, the result may be unpredictable.

### 9.4.3 String Concatenation (strcat)

Joining two or more strings to build longer strings is called concatenation. This is a common operation used to construct strings from words, paragraphs from sentences, pages from paragraphs, and so on. There are several operations in word processors where word, sentences, and paragraphs can be cut from one part of the text and can be pasted to another part of the text. There are two forms of the concatenation function, one with two arguments and one with three arguments. The following examples show the use of the string concatenation function.

```c
char strname1[20] = "COMPUTER "; /* there is one blank at the end */
char strname2[15] = "SCIENCE";
```

#### First Form of the Function with Two Arguments

The general form is as follows:

```c
strcat(strname1, strname2);
```

where strcat is the function name, strname1 is the first argument, and strname2 is the second argument. When this function is executed the entire string, strname2, is concatenated to the string strname1 and the resulting string is stored in strname1. For this operation to succeed, strname1 must have enough storage to store the concatenated string.

Strings before Concatenation:
| Variable | Value |
|---|---|
| strname1 | COMPUTER |
| strname2 | SCIENCE |

Strings after Concatenation:
| Variable | Value |
|---|---|
| strname1 | COMPUTER SCIENCE |
| strname2 | SCIENCE |

Notice that when strname2 is concatenated to strname1, the value of strname2, including the null terminator, is copied into strname1 beginning at the position of the null terminator in strname1.

#### Second Form of the Function with Three Arguments

The general form is as follows:

```c
strcat(strname1, strname2, n);
```

where strcat is the function name, strname1 is the first argument, strname2 is the second argument, and n is the third argument, which is an integer. When this function is executed first n characters of strname2 are concatenated to strname1 and the resulting string is stored in strname1. Again the string variable strname1 must have enough storage to store the concatenated string. The null terminating character is automatically placed at the end of the concatenated string.
