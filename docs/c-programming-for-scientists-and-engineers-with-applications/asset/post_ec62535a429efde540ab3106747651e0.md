## 7.5.2 Passing Array Elements

Arrays can be passed to functions element-by-element either by value or by address, scalar variables. When an element of an array is passed to a function from the calling program, the index of the element must be specified. The following code shows the passing of array elements by value and by address.

When array elements are passed to the function by value they are copied into temporary storage and the function parameter can only access the value in temporary storage. The following code shows array elements of an array passed by value and of array b passed by address a. The subfunction adds the elements of the two arrays plus two, one-by-one and returns the sums to the array b.

```c
#include <stdio.h>
#define ARSIZE 5

void funcscalar(int, int *);

int main() {
{
    int i;
    int a[] = {1, 2, 3, 4, 5};
    int b[] = {6, 7, 8, 9, 10};

    for (i = 0; i < ARSIZE; i++) {
        funcscalar(a[i], &b[i]);
    }

    for (i = 0; i < ARSIZE; i++) {
        printf("%d %d\n", a[i], b[i]);
    }

    return 0;
}

void funcscalar(int x, int *y) {
{
    x = x + 2;
    *y = x + *y;
    return;
}
}
```

### Before (function call)

| a[0] | 1 | b[0] | 6 |
| a[1] | 2 | b[1] | 7 |
| a[2] | 3 | b[2] | 8 |
| a[3] | 4 | b[3] | 9 |
| a[4] | 5 | b[4] | 10 |

### After (function call)

| a[0] | 1 | b[0] | 9 |
| a[1] | 2 | b[1] | 11 |
| a[2] | 3 | b[2] | 13 |
| a[3] | 4 | b[3] | 15 |
| a[4] | 5 | b[4] | 17 |

Notice in the function call the elements of array a are passed by value though they are scalars. The elements of array a are copied into temporary storage and the contents of the temporary storage is accessed in the function. If elements of array a are changed in the function, the original values of the elements of array a will not change because they are passed by value. This protects the original arrays but is inefficient for large arrays as the function must be called many times. The elements of array b are passed by address; therefore, changing the values in the function changes them in the original array.

> **Program Warning:** Pass array elements by value to protect the array against changes in a function.

### 7.6.1 Reynolds Numbers

Write a program to compute and build a table of the Reynolds numbers at flow velocities varying from 100 to 1000 ft/s at increments of 100 given the following formula. This example shows the construction and output of an array.

> Re = \rhovl/μ

Where Re is the Reynolds number that is nondimensional,
ρ is the density of air in slug/ft³,
v is the flow velocity in ft/sec,
l is the characteristic length in ft., and
μ is the viscosity of the air in slug/ft.sec.

#### Method
- Define the constants $\rho$ and $\mu$ for air.
- Vary the velocity from 100 to 1000 in increments of 100.
- Calculate the Reynolds number for each velocity.
- Store the velocity and the Reynolds number in one-dimensional arrays.

#### Data
- Density $\rho$ of air $2.33 \times 10^{-3}$ slug/ft$^3$
- Viscosity $\mu$ for air $3.8 \times 10^{-7}$ slug/ft.sec.
- Velocity varies from 100 to 1000 at increments of 100

#### Pseudocode
```
density $\rho$ and viscosity $\mu$ for air are defined constants
for each velocity from 100 to 1000 in increments of 100
    reynolds = (density * velocity * length) / viscosity
    reynoldsnum[i] = reynolds
end
Output velocity, reynoldsnum[i]
stop
```

#### Program
> /*********************************************************************/
/* Compute the Reynolds Numbers for Different Velocities of Fluid over a Circular Cylinder */
/********************************************************************/
/* Compute the Reynolds Numbers for Different Velocities of Fluid over a Circular Cylinder */
/****************************************************/
/* Constants: */
/* density = $2.33 \times 10^{-3}$ slug/ft³ */
/* viscosity = $3.8 \times 10^{-7}$ slug/ft.sec. */
/* Input Variables: */
/* length = diameter in ft */
```c
#include <stdio.h>
#define ARSIZE 10

int main() {
    int i;
    const float density = 2.33e-3;
    const float viscosity = 3.8e-7;
    float length;
    float reynoldsnum[ARSIZE];

        printf("%d | %d | %.2f\n", i+1, 100 + (i * 100), reynoldsnum[i]);
    }

}
```

## 7.6.2 Stress and Strain

Compute the stress and strain in steel subject to compression loads from 10,000 to 100,000 pounds in increments of 10,000 pounds. The diameter of the column is input in inches. The modulus of elasticity for steel is $E = 30 \times 10^6$ psi. Store the load, stress, and strain arrays in parallel-arrays. Output the load, stress, and strain in a table. This example shows the construction and output of parallel arrays. The formulas for the stress and strain are as follows:

The stress is given by the formula: $\sigma = p(\pi d^2/4)$
The strain is given by the formula: $\epsilon = \sigma/E$

Where $\sigma$ is the stress in pounds/in^2,
- $\epsilon$ is the strain which is nondimensional,
- $p$ is the load in pounds,
- $d$ is the diameter in inches, and
- $E$ is the modulus of elasticity in pounds/in^2.

#### Program
> /*********************************************************************/
/****************************************************/
/* Compute the Stress and Strain for a Steel Column                 */
/****************************************************/
/* Constants: */
/* E = 30e6 */
/* PI = 3.141593 */
/* Input Variables: */
/* diameter = diameter of column in inches */
```c
#include <stdio.h>
#define ARSIZE 10

int main() {
    int i;
    const float E = 30e6;
    const float PI = 3.141593;
    float diameter;
    float load[ARSIZE];
    float stress[ARSIZE];
    float strain[ARSIZE];

    printf("Input the diameter of cylinder in inches: ");
    scanf("%f", &diameter);

    for (i = 0; i < ARSIZE; i++) {
        load[i] = 10000 + (i * 10000);
        stress[i] = load[i] / (PI * (diameter * diameter) / 4.0);
        strain[i] = stress[i] / E;
    }

    printf("\nIndex | Load | Stress | Strain\n");
    for (i = 0; i < ARSIZE; i++) {
        printf("%d | %d | %.2f | %.6f\n", i+1, load[i], stress[i], strain[i]);
    }

    return 0;
}
```
