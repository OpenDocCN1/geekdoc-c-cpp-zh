to solve the quadratic equation $ax^2 + bx + c = 0$, assuming the roots are real:

```
if(a == 0) {

  }
} else {
  /* solution to ax^2 + c = 0 and ax^2 + bx + c = 0 */
  d = sqrt(b * b - 4.0 * a * c);
  x1 = (-b + d) / (2.0 * a);
  x2 = (-b - d) / (2.0 * a);
}
```
