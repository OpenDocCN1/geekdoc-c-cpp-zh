# Basic Elements of the C Programming Language

# Objective

To learn the syntax and semantics of the C language. To learn the logical and physical structure of programs and the types of data that can be processed.

C is a versatile, flexible, and powerful programming language that was designed and developed in 1972. C incorporated many of the ideas of its ancestral languages BCPL and B. BCPL (Basic Programming Language) was developed in 1967 by Martin Richards. BCPL was a typeless (no data types) language using machine words and machine addresses. In 1970, Ken Thompson developed a programming language called B. B was also a typeless language, and was used for the development of the UNIX operating system. C differs from its predecessors in being strictly typed. C enforces data types such as integer, floating-point, and character.
