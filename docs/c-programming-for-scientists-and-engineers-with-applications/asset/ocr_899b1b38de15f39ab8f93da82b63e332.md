# 134 Input and Output

```
int var1;
float var2, var3;
double var4;

scanf("%d" %f %f %e", &var1, &var2, &var3, &var4);
```

The data can be entered as follows:

18 -43.00 26.765 1.2345678E-03 or

18 or 18 -43.00
-43.00 -43.00 26.765 1.2345678E-03
26.765 1.2345678E-03
1.2345678E-03

The numbers are stored in the variables as follows:

| var1 | var2 | var3 | var4 |
| --- | --- | --- | --- |
| 18 | -43.0000 | 26.76500 | 1.2345678E-03 |

Notice there is flexibility in entering the data.
