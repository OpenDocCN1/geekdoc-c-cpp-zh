Method Set up the scaling matrix.

$$S(s_x, s_y) = \begin{bmatrix} s_x & 0 & 0 \ 0 & s_y & 0 \ 0 & 0 & 1 \end{bmatrix}$$

Where $s_x$ is the scaling factor of the $x$ coordinate, and $s_y$ is the scaling factor of the $y$ coordinate.

Input the coordinates of the line. Setup up the coordinate matrix.

$$L = \begin{bmatrix} x_1 & x_2 \ y_1 & y_2 \ 1 & 1 \end{bmatrix}$$
