# Pseudocode

```
main:
call funcinput() to input the array a
call funcsort() to sort the array a
call funcoutput() to print the sorted array a
stop
```

```
funcinput:
for each element i
Input a value into array element a[i]
end
return
```

```
funcsort:
for each element i from O to n - 1
for each element j from i + 1 to n
If a[i] > a[j]
Call funcswap to swap a[i] and a[j]
end
end
return
```

```
funcoutput:
for each element i
output a[i]
end
return
```
