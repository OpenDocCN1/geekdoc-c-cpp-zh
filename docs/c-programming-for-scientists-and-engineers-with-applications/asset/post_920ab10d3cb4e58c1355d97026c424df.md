
# 10.3 Pointers and Arrays

```c
#include <stdio.h>
int main() {
    int numbers[10] = {12,25,67,85,90,72,94,86,9,18};
    int *ptr;
    ptr = numbers;
    printf("The address printed is: %d\n", ptr);
    printf("The number printed is: %d\n", *ptr);
    printf("The number printed is: %d\n", ++ptr);
    printf("The number printed is: %d\n", ++ptr);
    printf("The number printed is: %d\n", *ptr++);
    printf("The number printed is: %d\n", ++ptr);
    return 0;
}
```

*++ptr is the same as **(++ptr)
++*ptr is the same as ++(*ptr)
*ptr++ is the same as *(ptr++)

The output is as follows:

- The address printed is: 10000 /* pointer is used */
- The number printed is: 12 /* pointer is incremented then used */
- The number printed is: 25 /* array element is incremented */
- The number printed is: 26 /* pointer is used then incremented */
- The number printed is: 26 /* pointer is used */
- The number printed is: 67 /* pointer is incremented then used */
- The number printed is: 85

Notice that the address of the numeric array is printed as 10000 in the first statement. In the second print statement the number 12 is printed by *ptr, which is simply dereferencing the first memory location. In the third print statement the pointer is incremented and then dereferenced, which prints number 25. In the next print statement the pointer is dereferenced, which points to the location containing the number 25 and the value 25 is incremented by 1 so that 26 is printed. The number 26 replaces the number 25 in memory. In the next statement, the number 26 is printed, having been changed from 25, and the post-increment is not effective in that print statement. In the print statement *ptr++, the increment occurs after number 26 is printed. In the next statement, number 67 is printed because of the post-increment in the previous print statement. In the last statement the pointer is incremented and the number 85 is printed.

## 10.4 Dynamic Storage and Arrays

Dynamic storage is simply storage that is allocated while a program is executing. It is allocated from the available part of computer memory after the program determines how much storage is needed. Storage that is declared in a program is called static storage. It is allocated before the program is executed. When the size of an array is not known in advance, or storage is at a minimum space must be reused, the function calloc() from the stdlib.h library may be used to allocate dynamic storage and assign an array pointer to it. The function calloc() allocates a block of storage until it is released by the free() function or the program terminates. The calloc() function is passed arguments telling it how many data cells are needed, and what their size is, in bytes. The address returned by the calloc() function must be converted to the declared data type of the pointer to which it is assigned.

### 10.4.1 One-Dimensional Arrays

Dynamic storage for a one-dimensional array is allocated as follows:

```c
int *ptr;
xptr = (int *) calloc(5, sizeof(int));
```

This call to calloc() asks for five data cells of four bytes each. The address that is returned is converted to data type int *.

| | | |
|---|---|---|
| xptr + 0 | 45 | 1000 |
| xptr | 1 | 86 | 1004 |
| xptr + 2 | 63 | 1008 |
| xptr + 3 | 96 | 1012 |
| xptr + 4 | 54 | 1016 |

The following code shows the dynamic storage and prints the address of each.

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int i, *arptr, SIZE;
    scanf("%d", &SIZE);
    arptr = (int *) calloc(SIZE, sizeof(int));

    for(i = 0; i < SIZE; i++) {
        scanf("%d", arptr);
        arptr++;
    }

    arptr = arptr - SIZE;
    printf("The output is:\n");
    for(i = 0; i < SIZE; i++) {
        printf("%d. %d\n", i + 1, *arptr);
        arptr++;
    }
    return 0;
}
```
