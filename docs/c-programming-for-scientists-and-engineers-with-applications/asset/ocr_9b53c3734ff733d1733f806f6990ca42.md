Input/Output of Strings (String I/O) There are functions in the C library stdio.h header file specifically designed for the input and output of character strings. These functions use gets() and gets() for input, puts() and fputs() for output of character strings. These functions differ from the scanf() and printf() functions in that the string input and output (string I/O) functions only handle a single string or array of strings. These string I/O functions have fixed numbers of arguments, whereas scanf() and printf() have variable numbers of arguments.

Input of Strings The special functions available for the input of character strings in the C library stdio.h are gets() and gets().

Input Function gets() To input a character string from a keyboard, the gets() function is used. The general form of the gets() function is as follows:

gets(strname);

Where strname is a character string variable name. This function reads characters into the string variable strname until the new line character '\n' is entered. The character '\n' is not stored, but instead the function stores the null terminator '\0' in its place. The following example shows the code, the input, and the storage of a character string entered from a keyboard.

```
char strname[15];
```

gets(strname);
