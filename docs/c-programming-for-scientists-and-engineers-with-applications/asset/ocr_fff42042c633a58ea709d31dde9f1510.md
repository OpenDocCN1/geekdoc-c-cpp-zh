# Assignment Using Member Operator

```
strcpy(part.codename,"bolt");
part.count = 20;
part.unitcost = 0.25;
part.totalcost = part.count * part.unitcost; /* totalcost is calculated
```

# Assignment Using Structure Variable Pointer

```
strcpy(parttr -> pathname,"bolt");
parttr -> count = 20;
parttr -> unitcost = 0.25;
parttr -> totalcost = parttr -> count * parttr -> unitcost;
```

Notice that the first set of assignment statements assigns values using only the member operator. The second set of assignment statements assigns values using the structure pointer with the member dereference operator.

Also notice that the value of part.totalcost is computed and the result is assigned. Also by using the pointer value parttr -> totalcost is computed and the result is assigned. The input data into the structure variables is discussed in Section 11.2.

# Assignment of One Structure to Another

Once part1 has been declared and defined as being structure variable of the derived data type gadgetpart, if part2 has been declared to be a variable of the same data type, the values of part1 can be assigned to the members of part2 by the assignment statement:

```
part2 = part1;
```

This type of assignment statement is unique for structures and cannot be used for arrays or strings unless they are also structures.
