Pointer variables have have unsigned integers as their values, so they can be used for loop control. Note however, this does not provide any line control for printing or displaying a two-dimensional array by rows.

Dereferencing of Pointers to Arrays Access the contents of a memory location to which a pointer is pointing, the pointer must be dereferenced. For example if ptr is a pointer pointing to a memory location, then to access the contents of memory location *ptr must be used. The *ptr will access the contents of the memory location, which may be used for computation or for output. When dealing with numeric and character string arrays, each cell of the array may be accessed by dereferencing and then either incrementing or decrementing the pointer.
