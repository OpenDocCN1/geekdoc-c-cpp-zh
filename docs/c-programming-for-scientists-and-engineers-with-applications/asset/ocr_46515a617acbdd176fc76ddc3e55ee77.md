# 7.4 Manipulation of Arrays 413

$x \cdot y = \sum_{i=1}^{n} x_i y_i$$

The following code computes this equation for vectors of length $n$.

```
int i, n;
float sum = 0;
for(i = 0; i < n; i++)
{
  sum += x[i] * y[i];
}
```
