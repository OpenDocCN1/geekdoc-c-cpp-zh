# 5.2 Functions

```
int val;
val = func2(.. .);  /* can be called because it is declared
before func1 */
return val;

```

```
int func2(...... )  /* implementation of func2 */
{
  int val3;
  val3 = func1(..);  /* can be called because it is global to
  /* func2, but not a good idea, because of
  /* the possibility of an endless loop */
  return val3;
}
```

> Warning: If functions can call each other there must be a way to terminate the calls.
