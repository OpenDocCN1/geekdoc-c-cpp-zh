# $L' = T(t_x, t_y) * L$

```
$$\begin{bmatrix} x'_1 & x'_2 \ y'_1 & y'_2 \ 1 & 1 \end{bmatrix} = egin{bmatrix} 1 & 0 & t_x \ 0 & 1 & t_y \ 0 & 0 & 1 \end{bmatrix} * egin{bmatrix} x_1 & x_2 \ y_1 & y_2 \ 1 & 1 \end{bmatrix}$
```

Where $L'$ is the matrix for the translated line segment between points $(x'_1, y'_1)$ and $(x'_2, y'_2)$.

Data

Translation matrix

```
$$\begin{bmatrix} 1 & 0 & t_x \ 0 & 1 & t_y \ 0 & 0 & 1 \end{bmatrix}$
```

Coordinate matrix: oldline

```
$$\begin{bmatrix} x_1 & x_2 \ y_1 & y_2 \ 1 & 1 \ \end{bmatrix}$
```
