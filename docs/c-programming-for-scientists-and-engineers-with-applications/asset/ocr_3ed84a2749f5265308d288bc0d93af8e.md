# 3.2 File Input and Output 149

```
int main()
{
    float x, y;
    FILE *fptr;

    fptr = fopen("myfile.dat", "r");

    if(fptr) {
        printf("%x y\n");
        while ((sscanf(fptr, "%f %f", &x, &y)) != EOF) {
            printf("%f %f\n", x, y);
        }
        fclose(fptr);
    } else {
        printf("File <myfile.dat> not available \n");
    }

    return 0;
}
```

When the data file is successfully opened for input, the data is read until the EOF marker is found. When EOF is found, the condition != EOF will be false and the while loop terminates.

Notice that if the data file cannot be opened successfully then the following error message will be displayed on the monitor.

File <myfile.dat> not available
