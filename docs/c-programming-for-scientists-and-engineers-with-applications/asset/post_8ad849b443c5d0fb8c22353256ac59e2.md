
> Programming Hint: For small arrays, initialization in the declaration is practical, but for large arrays it is not practical.

Initialization in the declaration is recommended for debugging and testing program code for correctness.

Array Initialization by Assignment Values can be assigned to individual elements of the array after the array is declared as follows:

```
int a[5];
a[0] = 13;
a[1] = 25;
a[2] = 42;
a[3] = 12;
a[4] = 16;
```

array storage

The value 13 is stored in the element a[0], value 25 is stored in element a[1], and so on. This is shown in the diagram with a storage cell for each element. An element of an array must be initialized before it is used. An error will occur if a subscript is too large for the array.

Array Initialization Using Loops When all the elements have the same initial value, for example all the values are to be set to zero or all the values are to be set to 100.55, then a for loop can be used to initialize the values. The following code shows such an initialization:

```
int i, cons[10];
float temp[100];

for(i = 0; i < 10; i++) {
    cons[i] = 0;
}
```

```
for(i = 0; i < 100; i++)
{
  temp[i] = 100.55;
}
```

Notice that each element of the array is initialized to zero and each element of the array temp is initialized to 100.55. A loop can also be used to initialize an array with input data. The subscript must not be out of bounds. An array char is declared and accessed like any other array, for example:

```
char grade[5] = {'A', 'B', 'C', 'D', 'F'};
char student [25];
```

Type char will be discussed in Chapter 9.

> Programming Hint: Use a loop to initialize the elements of an array if all the elements have the same initial values.

# 7.2 Input of One-Dimensional Arrays

In C, for large amounts of data, initialization and assignment of data to individual array elements is not practical. The practical way to assign data to a large array is either through input or through computation. The input of data can be accomplished any of three ways: using the array index, using the array pointer, or using a dynamic pointer. Input into an array using array pointers and dynamic pointers is presented in detail in Chapter 10.

The following code shows input of numeric data using an array index. For a loop is used to index the elements of the array and the address of each element must be specified in the input statement.

# 7.2.2 Input of Parallel Arrays

Parallel arrays are arrays of the same size that contain related data such as x and y coordinates of a set of points. Data can be input into parallel arrays in several ways depending on the order of the data. The x, y coordinates of five points are stored as a list of x and a list of y. Input data to each array using a separate loop for each array. The following example shows this:

```
#define ARR 5
int i;
int x[ARR], y[ARR];

for(i = 0; i<ARR; i++)
{
    scanf("%d", &x[i]);
}

for(i = 0; i<ARR; i++)
{
    scanf("%d", &y[i]);
}
```

The data for array x and array y are entered as follows:

12 18 25 65 87
25 65 76 80 98

Notice that two separate loops are used for the array x and the array y. The data for the entire array x must be entered first from the keyboard and the data for the entire array y must be entered next. If the data is entered as x, y pairs instead of using two loops for the array x and array y, only one loop is needed. The following loop shows this:

```
#define ARR 5
int i;
int x[ARR], y[ARR];

for(i = 0; i<ARR; i++)
{
    scanf("%d %d", &x[i], &y[i]);
}
```
