C is a favored and widely used programming language, particularly within the fields of science and engineering. C Programming for Scientists and Engineers with Applications guides readers through the fundamental, as well as the advanced, concepts of the C programming language as it applies to solving engineering and scientific problems. Ideal for readers with no programming experience, this text provides numerous sample problems and their solutions in the areas of mechanical engineering, electrical engineering, heat transfer, fluid mechanics, physics, chemistry, and more. It begins with a chapter focused on the basic terminology relating to hardware, software, and problem definition and solution. From there readers are quickly brought into the key elements of C and will be writing their own code upon completion of Chapter 2. Concepts are then gradually built upon, using a strong, structured approach with syntax and semantics presented in an easy-to-understand sentence format. Readers will find C Programming for Scientists and Engineers with Applications to be an engaging, user-friendly introduction to this popular language.
