
## 2.3 Arithmetic Operations and Expressions

Since in an assignment statement the value computed for the expression on the right of the equal sign is assigned to the left, assignment statement such as the following are meaningful:

| Before | After |
|---|---||
| float a = 10; | 10.00 |
| a = a + 5.2; | 15.20 |

The computer executes the assignment statement by getting the current value from memory cell a, which is 10.00, adding 5.2 to it, and storing the result back in memory cell a, replacing the value 10.00 with the new value, 15.20. In doing this, the computer writes the new value over the old value contained in the memory cell a; the old value is erased.

The expression on the right side of an assignment statement may be of any appropriate type and may be a constant, another variable that has already been given a value, or a valid C expression that is to be evaluated. The left side must be a variable or a dereferenced pointer to a variable. The following are examples of valid assignment statements:

| Assignment Statement | Comments |
|---|---|
| factor = 12.65; | assuming factor is float, it takes the value 12.65 |
| a = e; | a is given the same value as e |
| x = 'c'; | assuming x is a character variable, it takes 'c' as its value |
| s = t * r * 1; | using the values of t, r, and l, t*r*l is calculated and the result is stored in s |
| x = x / 5 + x * y - x / z; | the previous value of x is replaced by a value calculated using y, z, and the previous value of x |
| ptrw = 27.5; | the previous value of the variable pointed to by ptrw is replaced by 27.5 |

Each assignment statement is carried out in three steps:

1. 1. The computer evaluates the expression on the right side of the equal sign.
2. If the result is not of the same data type as the variable on the left side, it is converted to the data type of variable.
3. 3. The computer assigns the resulting value to the variable on the left side. In effect, the value is stored in the memory cell allocated to that variable, except that with the pointer variable, one level of indirection is used.

When an integer value is assigned to a float variable, it is converted to a float value having a fractional part of .0 before being stored. When a float value is assigned to an int variable, the fractional part of the value is discarded before the value is stored.

> Programming Warning: The computer does not round floating-point values assigned to integer variables. The fractional parts are truncated.

int a, b, c;
float x, y, z;

For these variable declarations, the expressions and the calculated values and the values are assigned as follows:

| Assignment Statement | Calculated Value | Value Assigned |
|---|---|---|
| a = 15 / 2; | 7 | 7 |
| b = -28.0 / 3.2; | -8.75 | -8 |
| c = 3 * 4 * 1.2; | 14.4 | 14 |
| y = 2 / 5; | 0 | 0.0 |
| x = 4.5 * (1/2); | 0 | 0.0 |
| z = 4.5 * 2.3 / 1.5; | 6.9 | 6.9 |

Notice that this last value may be 6.9 or 6.89998 depending on whether the multiplication or division is carried out first. In this case, the multiplication is carried out before the division. Since multiplication and division have the same order of precedence, and operations of equal precedence are performed left to right, the value assigned is 6.9.

## 2.3.4 Order of Evaluations

The order of evaluation of operations in arithmetic expressions depends on the precedence of the operations. This precedence is:

- highest ()
- unary
- pow()
- * and / and % left to right
- lowest + and -

This order is called the hierarchy of operators. Operations of the same precedence are performed left to right. If one of the operands includes an operation of higher precedence, the higher precedence is performed first. Therefore the following are equivalent:

```
(a + b) + c
(a - b) - c
(a + b) - c
(a / b) / d
(a / b) * c
(-a) * b
a + (b * c)
```

The following calculations show the order of precedence:

```
12/3*2+4-8/3
is 4*2+4-8/3
is 8+4-8/3
is 12-8/3
is 4
is 4
```

This example shows the step-by-step evaluation of an arithmetic expression. The following example shows the details of the step-by-step evaluation of an algebraic expression.

| Algebraic Expression | C Expression |
|---|---|
| $\frac{a-bc+g}{k+f^2-xy}$ | algebraic expression |
| $\frac{a-b*c+g}{k+f*e-z}$ | C expression |
| Step 1 $\frac{a-r1+g}{k+f*e-z}$ | where $r1=b*c$ |
| Step 2 $\frac{a-r2+g}{k+f*e-z}$ | where $r2=a-r1$ |
| Step 3 $\frac{a-r3+g}{k+f*e-z}$ | where $r3=g/k$ |
| Step 4 $\frac{a-r4+g}{k+f*e-z}$ | where $r4=r2+r3$ |
| Step 5 $\frac{a-r5+g}{k+f*e-z}$ | where $r5=f*e$ |
| Step 6 $\frac{a-r6+g}{k+f*e-z}$ | where $r6=r4+r5$ |
| Step 7 $\frac{a-r7+g}{k+f*e-z}$ | where $r7=r6$ |
| Step 8 $\frac{a-r8+g}{k+f*e-z}$ | where $r8=r7/z$ |
| Step 9 $\frac{a-r9+g}{k+f*e-z}$ | where $r9=r6+r8$ |

$r1, r2, ..., r8$ are intermediate results calculated by the computer before it reaches the final result $r8$. Notice that the calculations are carried out in the order of precedence, comparing two operators at a time, from left to right, the multiplication and division are done before addition and subtraction. At each step, the computer uses the current values of variables to calculate the new value. If the types don't match, it converts the value to the type needed to carry out the operation. This is shown in the following example:

```
int a, b;
float x, y, z;

a = 4;
b = 2;
x = 5.0;
y = 4.5;
z = 2.0;
```

| Step | Expression | Comments |
|---|---|---|
| Step 1 | $a + b*x - b*a / z$ | |
| | $a + 10.0 - b*a / z$ | value of b is converted to float |
| Step 2 | $14.0 - b*a / z$ | 2.0 * 5.0 is computed; value of a is converted to float |
| Step 3 | $14.0 - 8 / z$ | 4.0 + 10.0 is computed; b*a is evaluated as integer |
| Step 4 | $6.0 / z$ | 8 is converted to float |
| | $14.0 - 8.0$ | computed |
| Step 5 | $6.0 - 2.25$ | 4.5 / 2.0 is computed |
| Step 6 | $3.75$ | 6.0 - 2.25 is computed |

The final result of the computation is a float value of 3.75.

## 2.3.5 Use of Parentheses

The examples shown in the previous section are based on the hierarchy of operations when there are no parentheses in the expression. In some algebraic expressions in C, parentheses are necessary to retaining the meaning of the expression. The following examples show the use of parentheses:

The algebraic expression $\frac{w+x}{a+b}$ becomes the C expression $(w + x) / (a + b)$

Parentheses are generally necessary when an algebraic expression has fractions or exponents. The nonparenthesized expression $w + x / a + b$ is equivalent to $\frac{x}{a} + b$.

Several possible ways of parenthesizing C expressions and their algebraic equivalence are as follows:

| Algebraic Expression | C Expression |
|---|---|
| $\frac{w+x}{a+b}$ | $(w + x) / (a + b)$ |
| $w+\frac{x}{a+b}$ | $w + x / ( a + b)$ |
| $\frac{w+x}{a}+b$ | $(w + x) / a + b$ |
| $w+\frac{x}{a}+b$ | $w + x / a + b$ |

> Programming Hint: Use extra parentheses when there is any doubt as to how the expression will be evaluated.

The hierarchy of operations shows that when an expression contains parentheses the parenthesized expressions must be evaluated first. When there are nested parentheses, the expression inside the inner parentheses is evaluated first, according to the hierarchical order of operators, resulting in the removal of the inner parentheses. Then, the innermost remaining expression is evaluated, and so on, until there are no parentheses left and the remaining parentheses-free expression can be evaluated. The following example shows the evaluation of an algebraic expression containing nested parentheses:

```
$\frac{s+t}{w+x+\frac{y+z}{a+b}}$ algebraic expression

$(s + t) / (w + x + (y + z)) / (a + b))$ C expression
r1 / (r2+r3 / r4) where $r1 = s+t$
nr2 = w+x\nr3 = y+z\nr4 = a+b$

Step 5 $r1 / (r2 + r5)$ where $r5 = r3 / r4$
Step 6 $r1 / r6$ where $r6 = r2 + r5$
Step 7 $r7$ where $r7 = r1 / r6$
```
