# The pseudocode for the sequence structure shown in Figure 4.1 is as follows:

```
stmt 1
stmt 2
stmt 3
stmt 4
```

In C an equivalent sequence of statements may appear as follows:

```
{
  c = 3.141593 * r * r;      /* area of circle */
diag = r + r;               /* diagonal of inscribed square */
s = 2 * r * r;             /* area inside square */
a = c - s;                 /* area not covered by square */
}
```

Given a circle of radius 1.0; statement c = 3.141593 * r * r assignss the value of 3.141593 to the variable c, diag = r + r assigns value 2 to the variable diag, s = 2 * r * r evaluates the expression and assigns the resulting value 2 to variable s. The use of braces holds the statements together as a logical sequence.
