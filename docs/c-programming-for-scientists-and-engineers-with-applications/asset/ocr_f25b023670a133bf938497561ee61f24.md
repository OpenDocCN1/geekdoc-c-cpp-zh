# Large computer system:

```
int count;
const int ZERO = 0;
```

the default storage is four bytes

```
short int count;
or
short count;
```

the short storage is two bytes

# Personal computer system:

```
int count;
const int ZERO = 0;
```

the default is two bytes

```
long int count;
or
long count;
```

the long storage is four bytes

The declaration statements are for storing signed integer numbers. Notice that each declaration ends with a semicolon. Every statement in C ends with a semi-colon with the exception of the control statements.

In C, one can store unsigned integer numbers. The declaration of unsigned integer numbers is as follows:

# Large computer system:

```
unsigned int var1, var2;

unsigned short int var1, var2;
or
unsigned short var1, var2;
```

the storage is four bytes

the storage is two bytes

# Personal computer system:

```
unsigned int var1, var2;

unsigned long int var1, var2;
or
unsigned long var1, var2;
```

the storage is four bytes

the long store is four bytes
