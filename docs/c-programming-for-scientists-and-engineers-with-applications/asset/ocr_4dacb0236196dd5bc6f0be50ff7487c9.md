Method The iterative solution of the problem assumes that given the value of $x$, the value $s_1$ is calculated. Then the formula for $s_{k+1}$ is repeated until sufficient accuracy has been obtained. For $k=1$, $s_2=(s_1+x/s_1)/2$

```
$k=2\quad s_3=(s_2+x/s_2)/2$
```

```
......
```

```
$k=n\quad s_{n+1}=(s_n+x/s_n)/2$
```

This process will continue until the difference between $s_k$ and $s_{k-1}$ is less than, or equal to, a predetermined value. When this happens, $s_k$ is accepted as the square root of $x$. Note that the computer must give explicit instructions about how to stop an iterative approximation, otherwise the calculations would continue indefinitely without ever providing an answer.
