Character search and substring functions:

+   - strchr() finds leftmost occurrence of character in string
- strchr() finds rightmost occurrence of character in string
- strstr() finds substring

The detailed syntax and the implementation of string functions are presented in Chapter 9.

Memory Allocation Functions There are dynamic memory allocation functions in the header file stdlib.h. To use these functions you must include the header file as follows:

```
#include <stdlib.h>
```

The memory allocation functions are:

+   - malloc() allocates memory cells for a string
- calloc() allocates memory cells for an array or structure
- realloc() reallocates multiple memory cells from free store
- free() frees the storage allocated by malloc(), calloc(), or realloc()

These functions are presented in Chapter 10.
