Notice that there are two spaces between each of the numbers 234.560000, 78.163000, and 567.050000 in the output, because there are two spaces between each of the control fields.

Numbers can be printed on separate lines as follows:

```
printf("%f%f\n%f\f\n", var1, var2, var3);
```

The output of this function call appears as follows:

```
-234.560000
78.163000
 567.050000
```

Notice that the new line character \n shifts the output of each number to the next line. The numbers are printed left justified. The following program shows the input of integer numbers that are then output with different format control specifications:

```
#include <stdio.h>
int main ()
{
    int a, b, c, d;

    printf("Enter four integer numbers:\n\");
    scanf("%d %d %d %d", &a, &b, &c, &d);
    printf("Output without spaces:\n\");
    printf("%d%d%d%d\n", a, b, c, d);
    printf("Output with four spaces:\n\");
    printf("%d %d %d %d\n", a, b, c, d);

    return 0;

}
```

The input and output of this program is as follows:

```
Enter four integer numbers:
9563 786 123987 34586
```

```
Output without spaces:
956378612398734586
```
