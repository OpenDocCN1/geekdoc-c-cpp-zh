# 8.2 二维数组的输入

向二维数组输入数据可以使用数组索引完成。可以使用嵌套循环对数组元素进行索引，以便将数据值输入到二维数组中。其他向数组输入值的方法第10章中介绍。

# 8.2.1 标准输入

按行顺序向二维数组输入数据是高效的，因为存储是按行顺序分配的。示例显示了按行向二维数组输入数据。

按行排列的数据

| 28.5 | 46.3 | 57.9 | 72.6 |
| 14.3 | 15.7 | 31.4 | 19.4 |
| 48.9 | 13.9 | 90.6 | 57.8 |

按行标准输入。这些数据从键盘输入，如行所示。以下程序显示了标准输入的代码：

```c
#include <stdio.h>
#define IMAX 3
#define JMAX 4

int main() {
    float values[IMAX][JMAX];
    int i, j;

    for(i = 0; i < IMAX; i++) {
        for(j = 0; j < JMAX; j++) {
            scanf("%f", &values[i][j]);
        }
    }

    return 0;
}
```

# 8.3 二维数组的输出

# 8.3.1 标准输出

以下存储和代码显示了二维数组的输出。假设存储的值如下：

| | | |
|---|---|---|
| row0 | a[0][0] | 28.5 |
| | a[0][1] | 46.3 |
| | a[0][2] | 57.9 |
| | a[0][3] | 72.6 |
| row1 | a[1][0] | 14.3 |
| | a[1][1] | 15.7 |
| | a[1][2] | 31.4 |
| | a[1][3] | 19.4 |
| row2 | a[2][0] | 48.9 |
| | a[2][1] | 13.9 |
| | a[2][2] | 90.6 |
| | a[2][3] | 57.8 |

这些数据按行格式输出到显示器。

```c
#include <stdio.h>
#define IMAX 3
#define JMAX 4

int main() {
    float values[IMAX][JMAX];
    int i, j;

    for(i = 0; i < IMAX; i++) {
        for(j = 0; j < JMAX; j++) {
            printf("%4f ", values[i][j]);
        }
        printf("\n");
    }
    return 0;
}
```

# 8.3.2 输出到数据文件

在许多科学应用中，从键盘输入的数据需要保存到文件中以便进一步分析。二维数组的数据可以通过写入数据文件来保存。以下程序显示按行保存到 "myfile.dat" 的二维数组数据。

```c
#include <stdio.h>
#define IMAX 3
#define JMAX 4
FILE *outptr;

int main() {
    float values[IMAX][JMAX] = {{28.5, 46.3, 57.9, 72.6},
                                  14.3, 15.7, 31.4, 19.4},
                                  48.9, 13.9, 90.6, 57.8}};
    int i, j;

    outptr = fopen("myfile.dat", "w");
    for(i = 0; i < IMAX; i++) {
        for(j = 0; j < JMAX; j++) {
            fprintf(outptr, "%5.2f ", values[i][j]);
        }
    }
    fclose(outptr);
    return 0;
}
```

注意输出中没有包含换行符。写入数据文件的数据如下：

| | | |
|---|---|---|
| row0 | a[0][0] | 28.5 |
| | a[0][1] | 46.3 |
| | a[0][2] | 57.9 |
| | a[0][3] | 72.6 |
| row1 | a[1][0] | 14.3 |
