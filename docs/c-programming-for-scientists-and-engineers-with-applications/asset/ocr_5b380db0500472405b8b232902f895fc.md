Notice the elements of the array a are stored in the array b in reverse order.

When it is necessary to exchange the values of elements between two arrays of the same size a temporary variable is used. This is accomplished by using the for loop as follows:

```
#define SIZE 5
int i;
float x[SIZE], y[SIZE], temp;

for(i = 0; i < SIZE; i++)
{
  temp = x[1];
  x[1] = y[1];
  y[1] = temp;
}
```

This swap operation is the basis of a simple but not very efficient method of sorting an array to arrange the values in ascending order called an insertion sort. The smallest element is located at position a[k] and placed in the position a[0] while the element originally in position a[0] is put in position a[k].
