# 3.5 Sample Programs 167

Method Given the number of rods, $n$; length, $l$ (ft.); the diameter, $d$ (in.); the cost/pound; and the density; calculate the following:

```
$d = \frac{d}{12}$ (converts $d$ from inches to feet)
area = \frac{\pi d^{2}}{4}$ (in square feet)
volume = number of rods $	imes$ length $	imes$ area (in cubic feet)
weight = volume $	imes$ density (in pounds)
total cost = weight $	imes$ cost per pound
```

Data Data consists of one integer number and three real numbers accurate to two decimal places.

# Pseudocode

Input the number of rods, diameter, length, density, cost per pound of steel
Output the number of rods, diameter, length, density, and cost per pound of steel
Convert the diameter from inches to feet

```
$d \leftarrow \frac{d}{12}$
```

Calculate the cross sectional area

```
area $\leftarrow \frac{\pi d^{2}}{4}$
```

Calculate the volume

```
volume $\leftarrow n \times i \times$ area
```

```
weight = volume $	imes$ density
```
