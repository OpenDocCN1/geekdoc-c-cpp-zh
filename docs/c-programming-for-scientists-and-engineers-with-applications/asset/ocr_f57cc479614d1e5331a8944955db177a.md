In this case only a storage template is set up to allocate storage to the data items of the structure variables when such variables are declared.

|---|---|---|---||
| | | | storage allocated |

Note that in this case the structure variables need not be declared in the structure declaration, because there is a structure tag. Since the structure declaration has a structure tag, a storage template is set up. When structure variables are declared, the storage is allocated to the data items of the structure variables according to the structure template. Since the structure declaration has a structure tag the programmer has the choice to declare the structure variables in the same structure declaration or the structure variables may be declared in a separate declaration statement using the structure tag. The tag acts as a data type name for the storage template. The following code shows such declarations.

Declaration of structure variables in a separate declaration statement is follows:

```
struct gadgetpart {
    char pname[10];
    int count;
    float unitcost;
    float totalcost;
}
struct gadgetpart part1, part2, part3;
```
