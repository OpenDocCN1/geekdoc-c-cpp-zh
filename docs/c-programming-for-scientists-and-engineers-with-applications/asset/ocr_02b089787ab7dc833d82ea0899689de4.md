# 582 Characters and Strings

```
Input Data:
AAAAAAA
XXXXXX
YY YY Y
PP KKKLLLL
CCCCCCCC
```

```
Output Data:
AAAAAAA
XXXXXX
YY YY Y
PP KKKLLLL
CCCCCCCC
```

In this program notice that the input function fgets() reads each string including the new line character '\n' and stores it in the storage allocated for an element of the string array. The '\n' is then replaced with '\0'. Also notice that the string I/O uses the name of the string array with the first dimension identifying the string. The string length STRLNG must be included in the function declarations and headers in order to determine where each string begins.
