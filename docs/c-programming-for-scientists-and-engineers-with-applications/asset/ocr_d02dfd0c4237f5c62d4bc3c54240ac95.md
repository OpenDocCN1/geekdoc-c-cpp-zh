# Method

Declare the structure.

Declare the structure variable.

For each cubicle:

+   - Input the dimensions of the cubicle from a data file.
- Compute the surface area of four walls to be painted.
- Compute the total cost to paint.
- Output the dimensions of the cubicle, surface area of walls to be painted, and the total cost to paint the cubicle.

# Data

Length, width, height, and cost per square foot.

# Pseudocode

```
main:
for each cubicle
  funinput()
  funcompute()
  funoutput()
end
stop
```

```
funinput()
  input length, width, height
end
```

```
funcompute()
wallarea = 2 * length * height + 2 * width * height
paintcost = wallarea * costpersft
end
```

```
funoutput()
  output length, width, height
  output wallarea
  output paintcost
end
```
