
## Pointers and Dynamic Storage

### Array Assignment

The values stored in one dynamic array may be copied into another dynamic array. A for loop may be used to copy one array to another array one element at a time. When numeric arrays are copied, if the data type of the source and the destination array do not match, a proper data type conversion within the rules of the C language will occur. The following code shows the assignment of one array to another array using dynamic pointers.

```c
#include <stdlib.h>
#define ARMAX 5

int main() {
    int i;
    float *ptrr, *bptr;

    ptrr = (float*)calloc(ARMAX, sizeof(float));
    bptr = (float*)calloc(ARMAX, sizeof(float));

    *(ptrr + 0) = 12.75;
    *(ptrr + 1) = 18.34;
    *(ptrr + 2) = 9.85;
    *(ptrr + 3) = 23.78;
    *(ptrr + 4) = 16.96;

    for(i = 0; i < ARMAX; i++) {
        *bptr++ = *ptrr++;
    }

    bptr = bptr - ARMAX;
    ptrr = ptrr - ARMAX;

    return 0;
}
```

### 10.4.2 Two-Dimensional Arrays

Dynamic storage for two-dimensional arrays may be allocated using the dynamic storage allocation function calloc() from the standard library. A block of storage is allocated from the free store. The block of storage is divided into the number of cells specified in the calloc() argument. The storage address is assigned to a pointer, which is of the same data type as the data to be stored in the free storage allocated by calloc() function. The calloc() function does not distinguish between one- and two-dimensional arrays. It simply allocates the amount of storage requested.

For an array [IMAX][JMAX] the call to calloc() should have the form

`calloc(IMAX * JMAX, sizeof(data type of array));`

The storage is allocated as follows:

```c
#include <stdlib.h>
#define IMAX 3
#define JMAX 4

int main()
{
    int *aptr; /* dynamic pointer declaration */
    aptr = (int *) calloc(IMAX * JMAX, sizeof(int));
    return 0;
}
```
