Dereferencing of Pointers In call-by-pointer, a function receives pointers through its parameters. The pointers are the addresses of arguments passed to parameters. To access the data contained in these pointers they must be dereferenced. The dereference operator (*) must be used in front of the pointer variable to access the value contained in the function

```c
int funcsum(int *varx, int *vary, int *varz)
{
    int sum;
    sum = *varx + *vary + *varz;
    return sum;
}
```

the variables varx, vary, and varz are dereferenced by placing an asterisk (*) in front of them. The value of pointer varx is an address and its content is *varx, which is 10. The value of pointer vary is an address and its content is *vary, which is 20. Finally, the value of pointer varz is an address and its content is *varz, which is 30. In the assignment statement sum = *varx + *vary + *varz, *varx is replaced by 10, *vary is replaced by 20, and *varz is replaced by 30. The result assigned to the variable sum is 60. The asterisk (*) tells the computer to use the value as an address, find that address, and pick up (or store) the value there.

If the address variable is dereferenced in an output statement, on the right side of an assignment statement, or anywhere a value is needed, the value at that address is picked and used.

```c
int x = 14;                   /* 14 is stored at say, address A1 */
func(&x);                    /* function call */
int func(int *addrx)          /* value of addrx is A1 */
{
    int y;
    printf("%d", *addrx);      /* prints 14 */
    if(*addrx > 0)             /* compares 14 and 0 */
    {
        y = *addrx;           /* assigns the value 14 to y */
        printf("%d", y);      /* prints 144 */
    }
    return 0;
}
```

If the address variable is dereferenced on the left side of an assignment statement or anywhere an address is needed for storing, a value is stored in the storage of the argument in the function call.

```c
int x, y;
x = 14;                      /* 14 is stored at say, address A1 */
y = 27;                      /* 27 is stored at say, address A2 */
func(&x, &y);               /* function call */
```

int func(int *addrx, int *addry)   /* addrx has value A1 */

Dereferencing a pointer tells where to pick up or store a value. If the values pointed to by the pointer variables are changed in the function, the changes are reflected in the arguments. The following program shows how changes in the parameters in the function will change the corresponding argument values in the main function. This was not the case in passing by value. Passing the arguments by pointers causes side effects in the arguments if the parameters in the function are dereferenced. The following program shows such effects.

In the following code the parameters are changed in the function funcsum:

```c
int funcsum(int *, int *, int *);

int main()
{
    int var1 = 10;
    int var2 = 20;
    int var3 = 30;
    int sum;

    sum = funcsum(&var1, &var2, &var3);

    printf("var1 = %d var2 = %d var3 = %d sum = %d\n", var1, var2, var3, sum);
    printf("sum = %d\n", var1 + var2 + var3);

    return 0;
}
```

```c
int funsum(int *varx, int *vary, int *varz)
{
    int sum1;
    *varx += 10;
    *vary += 15;
    *varz += 20;
    sum1 = *varx + *vary + *varz;
    return sum1;
}
```

Output: var1 = 20 var2 = 35 var3 = 50 sum = 105

Figure 5.9 shows the status of the variables after they are changed in the function. When arguments are passed as pointers to the function parameters, the function has the right to access the storage locations of the arguments used in the calling function. Any changes made through the function parameters will be reflected in the arguments of the main program. In this code the pointers varx, vary, and varz are dereferenced and their values are changed. The statements *varx += 10, *vary += 15, and *varz += 20 changed the value of var1 from 10 to 20, var2 from 20 to 35, and var3 from 30 to 50 in the function.
