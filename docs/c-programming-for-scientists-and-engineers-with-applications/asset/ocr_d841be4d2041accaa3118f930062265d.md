strn2

Strings after Concatenation:

```
strn1
| C | O | M | P | U | T | E | R | S | C | I | E | N | C | E | \0| | |
```

```
strn2
| S | C | I | E | N | C | E | \0| | | | |
```

Notice that when strn2 is concatenated to strn1, the value of strn2, including the null terminator, is copied into strn1 beginning at the position of the null terminator in strn1.

Second Form of the Function with Three Arguments The general form is as follows:

```
strcat(strn1, strn2, n);
```

where strcat is the function name, strn1 is the first argument, strn2 is the second argument, and n is the third argument, which is an integer. When this function is executed first n characters of strn2 are concatenated to strn1 and the resulting string is stored in strn1. Again the string variable strn1 must have enough storage to store the concatenated string. The null terminating character is automatically placed at the end of the concatenated string.

```
strcat(strn1, strn2, 4);
```
