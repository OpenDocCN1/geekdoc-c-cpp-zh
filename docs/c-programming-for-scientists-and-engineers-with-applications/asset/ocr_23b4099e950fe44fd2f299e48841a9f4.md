4. Write a program to compute the inventory for three car lots with five different car models. Each model has a certain number of cars with a cost for each car. Compute the total cost of all cars of each model. Also compute the total number of cars for all of the models and also compute the total cost of all the cars of all of the models. The input consists of a 20-character model name, the number of cars of each model, and the price for each car for each of the models. Output the model name, cost of each car, total cost of all cars of each model, the total number of cars of all of of the models, and the total cost of all cars of all of the models. Organize the data by model for each lot.
