# 5.2 Functions

```
if( a == 0)                       /* not a quadratic equation */
    flag = 0;
else if( b * b < (4 * a * c))   /* no real solutions */
    flag = -1;
else if(b * b == (4 * a * c))   /* one solution */
{
    x1 = -b / (2 * a);
    printf("x1 = %f", x1);
    flag = 1;
}
else{
    sqval = (b * b - (4 * a * c));   /* two solutions */
    x1 = (-b + sqrt(sqval)) / (2*a);
    x2 = (-b - sqrt(sqval)) / (2*a);
    printf("x1 = %f x2 = %f", x1, x2);
}
return flag;
```

Notice that there is a single return and a flag that indicates the state of the computation. The C language allows more than one return statement, which would have slightly simplified the program logic but would have violated the modular principle of one entry and one exit for each module.
