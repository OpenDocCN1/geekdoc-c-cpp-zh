# 2.5.3 Compression Stress in a Steel Column

Problem Compute the compression stress in a steel column of diameter $d$ inches subject to the compression load of $p$ pounds.

Data Two positive integers representing $p$ and $d$.

Method The formula for the compression stress is given as follows:

```
area = \pi d^2 / 4
f = p / area
```

Where: $p$ is the compression load in pounds,
area is the cross-sectional area of the steel column in square inches, and
$f$ is the compression stress in pounds per square inch.

# Pseudocode

```
Input the compression load $p$, and the diameter $d$
If data is valid
    Compute the area
    area $\leftarrow \pi d^2/4$
    Compute the compression stress
    $f \leftarrow p / area$
Output the compression load $p$, diameter $d$, and the compression stress $f$
End

#include <stdio.h>
int main()
{
    float x1, y1, x2, y2;
    float slope;
    const float PI = 3.141593;
    int p, diam;
    float area, stress;

    printf("Input the Load:\n");
    printf("Diameter of Column:\n");

    scanf("%d %d", &p, &diam);

    if(p > 0 && diam > 0) {
        printf("Load: %d pounds\n", p);
        printf("Diameter: %d inches\n", diam);

        area = PI * (diam * diam) / 4.0;
        stress = p / area;
        printf("Stress: %.2f per square inch\n", stress);
    }

    return 0;
}
