# Game engine-ering

The tools that have made these indie games possible are called game engines. These are systems that come with functions to handle 2D and 3D graphics, networking, sound, file IO and everything else needed to create a game. They also come with assets like 3D models, music and so on that you can use in the game. You can also download additional assets from the internet, some for free, and some in exchange for money.

To make a game you then need to write your own code to tell the engine what to do in every circumstance. Each engine has different commands, and will support different programming languages – some are very easy to use, while others are more complicated and powerful. Some are for developing games for PCs, some for the web, and some for smartphones.
