# That’s neat!

You can name a variable anything you like so long as it doesn’t have any spaces in it. Give your variables helpful names so that you don’t forget what they’re storing!

> You can convert between integers and floating points, but while going from an integer to a floating-point is easy, going the other way can cause problems. Converting 4.5 to 4, for example, but if you convert 4.99 to an integer you’ll get 4, but the computer always rounds down. This can lead to strange results if you’re not expecting it.

# Types of numbers

Computers actually split numbers up into two types: integers and floating points. Integers are round numbers with no decimal places: 5, 7983, -6 and 0 are all integers. Floating point numbers are numbers with a decimal place, such as 1.29, -98.5 and 0.00002. Not every programming language worries about the difference, but a lot do. If you need to distinguish, 4 means the number is an integer, while 4.0 means it’s a floating point.

# Words

As well as numbers you can store words and even sentences in variables too! An individual letter is called a character, while a word or sentence is called a string (because it’s made up of a string of individual characters). A single variable can contain an individual character or it can contain a whole string. A string can be as long as you want – you can store an entire book in a variable if you want to! Whenever you use a string it needs to be enclosed in quote marks, “like this”.
