# Queueing and stacking

Arrays and linked lists are used to implement certain types of storage that the computer relies upon internally: queues and stacks. These are data stores where, rather than being able to access any element, you can only read one element at a time, based on the order in which the elements were put in.

A queue operates by FIFO – First In, First Out. So if you add A, then B, to a queue, when you read from the queue you will get first A, then B. In contrast, a stack operates by LIFO – Last In, First Out. Here if you add A, then B, to a stack, then when you read from it you will first get B, then A, rather like putting things onto and taking things off a stack of paper.

> Last in, first out.

> Don’t push it!

> That’s neat! Putting an item into a stack is referred to as pushing it, whereas taking one out is called popping it!
