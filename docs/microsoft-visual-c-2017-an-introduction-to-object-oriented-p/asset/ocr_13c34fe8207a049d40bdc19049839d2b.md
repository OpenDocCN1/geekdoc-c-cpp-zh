# CHAPTER 6 Using Arrays

In C#, an array subscript must be an integer. For example, no array contains an element with a subscript of 1.5. A subscript can be an integer constant or variable or an expression that evaluates to an integer. For example, if x and y are integers, and their sum is at least 0 less than the size of an array named, then it is legal to refer to the array[x + y].

Some languages, such as COBOL, Basic, and Visual Base, use parentheses rather than square brackets to refer to individual array. By using brackets, the creators of C# make it easier for you to distinguish arrays from methods. Like C#, C++ and Java also use brackets surrounding array subscripts.

A common mistake is to forget that the first element in an array is 0 (sometimes called the zeroth element), especially if you know another programming language in which the first element is 1. Making this mistake means you will be “off by one” in your use of your array. If you are “off by one” but still using a valid subscript, your program will likely produce incorrect output. If your subscript becomes larger than the highest value allowed, you will cause a program error.

To remember that array elements begin with element 0, it might be helpful to think of the first array element as being “zero elements away” from the beginning of the array, the second element as being “one element away” from the beginning of the array, and so on.

When you work with any individual array, you treat it no differently than you treat a single variable of the same type. For example, to assign a value to the first element in the array, you use a assignment statement, such as the following:
sales[0] = 2100;

To output the value of the last sales in a 20-element array, you write:
WriteLine(sales[19]);
