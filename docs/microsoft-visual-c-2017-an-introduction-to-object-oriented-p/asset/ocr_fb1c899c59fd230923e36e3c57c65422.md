# Displaying Variable Values

If you want to display several strings and several variables, you can end up with quite a few Write() and WriteLine() statements. To make producing output easier, you can combine strings and variable values into a single Write() or WriteLine() statement by concatenating them or using a format string.

When you concatenate with another value, you join the variables with the plus sign. For example, the following statement produces the same output as shown in Figure 2-4 but uses only one WriteLine():

```
WriteLine("The money is $\ + someMoney\);
```

A format string is a string of characters that controls the appearance of output. It optionally contains fixed text and one or more placeholders for variable values. A placeholder holds a position for a variable value within a string. It consists of a pair of curly braces containing a number that indicates the desired variable's position in a list that follows the string. The first position is always 0.

You can create a formatted string using the String.Format() method that is built into C#. For example, the following statements create a formatted string and then display it:

```
double someMoney = 39.45;
string mySentence =
String.Format("The money is ${0} exactly", someMoney);
WriteLine(mySentence);
```

The curly braces that contain a digit create a placeholder {0} to which the value of someMoney is inserted. Because someMoney is the first variable after the format string (as well as the only variable in this example), its position is 0. The process of replacing place holders with values is called string interpolation or variable substitution.

C# also includes a string interpolation feature that allows you to use a dollar sign in place of the String.Format() method, as in the following:

```
string yourSentence = "The money is ${someMoney} exactly";
WriteLine(yourSentence);
```

C# also allows you to use a shortcut with the Write() and WriteLine() methods. You can format a string and output it in one line without declaring a temporary string variable and explicitly naming the String.Format() method, as in either of the following:

```
WriteLine("The money is ${0} exactly", someMoney);
WriteLine("The money is ${someMoney} exactly");
```
