For example, the program in Figure 2-5 produces the output shown in Figure 2-6.

```
using static System.Console;
class DisplaySomeMoney3
{
    static void Main()
{
        double someMoney = 39.45;
        WriteLine("The money is ${0} exactly", someMoney);
    }
}
```

**Figure 2-6** Output produced using format string

To display two variables within a single call to Write() or WriteLine(), you can use a statement like either of the following:

```
WriteLine("The money is {0} and my age is {1}", someMoney, myAge);
WriteLine("The Money is {someMoney} and age is {myAge}");
```

The two examples produce the same output. In the first example, the value of someMoney will appear at position 0, and myAge will appear at position 1. The number within any pair of braces in a format string must be the format string. In other words, if you use six values to be displayed, valid format string numbers are 0 through 5. You do not have to use the positions in order. You can also display a specific value multiple times. For example, if someMoney has been assigned the value 39.45, the following code produces the output shown in Figure 2-7:

```
WriteLine("I have {0}. ${0}!!", someMoney);
```

![](bbox=[0.137, 0.749, 0.533, 0.783])

**Figure 2-7** Displaying the same value multiple times

The output in Figure 2-7 could be displayed without using a format string, but you would have to name the someMoney variable three separate times as in either of the following examples:

```
WriteLine("I have " + someMoney + " "." + someMoney +
""! " + someMoney + "!");
WriteLine("I have ${someMoney}. ${someMoney}!!");
```
