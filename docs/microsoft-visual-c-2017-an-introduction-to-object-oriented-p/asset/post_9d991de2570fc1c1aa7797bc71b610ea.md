
class definition—The first class line that describes a class; it contains an optional access specifier, the keyword class, and any legal identifier for the name of the class. Also known as class header.

class header—The first class line that describes a class; it contains an optional access specifier, the keyword class, and any legal identifier for the name of the class. Also known as class definition.

class user—A program or class that instantiates objects of another prewritten class. Also called a client.

click-event—An action fired when a user clicks a button in a GUI environment.

client—A method that uses another method.

closing a file—The process of making a file no longer available to an application.

code bloat—Describes unnecessarily long or repetitive program statements.

code refactoring—The process of changing a program's internal structure without changing the work programs.

code snippets—Small units of C source code that are generated in the IDE using a few keystrokes.

combo box—A GUI element that is a combination of a list box and an editing control that allows a user to select from the list or enter new text.

command line—The operating system's text interface.

command prompt—A request for input that appears at the beginning of the command line.

comment out—To turn a statement into a comment so that the compiler will not execute its command.

comparison operator—An operator that compares two values.

compiler—A computer program that translates high-level language statements into machine code.

completion mode—An IDE editing mode in which suggestions are provided automatically based on context.

composed delegate—A delegate that calls the delegates from which it is built.

composition—The technique of using an object within another object.

computer file—A collection of information stored on a nonvolatile device in a computer system.

computer simulations—Programs that mimic real-world activities to foster a better understanding of them.

concatenate—To join strings together in a chain.

concrete class—A abstract class whose objects can be instantiated. Contrast with abstract class.

conditional AND operator—An operator that determines whether two expressions are true; it is written using ampersands (&&). Also called the AND operator. Contrast with Boolean logical operator.

conditional operator—A ternary operator that is used in an abbreviated version of the if-else statement; it requires expressions separated by a question mark and a colon.

conditional OR operator—An operator that determines if at least one of two conditions is true; it is written using pipes (||). Also called the OR operator.

constant—Describes a data item when it cannot be changed after a program is compiled; in other words, when it vary.

debugging—The process of removing all syntax and logical errors from a program.

constructor—A method that instantiates (creates an instance of) an object.

decimal—A floating-point data type that has a greater precision and a smaller range than a float or double, which makes it suitable for financial and monetary calculations.

constructor initializer—a class that indicates another instance of a class should be executed before any statements in the current constructor body.

decimal number system—The system that uses 10 digits, 0 through 9, arranged in columns to represent numbers.

contextual keywords—Identifiers that act like keywords in specific circumstances.

decision structure—A unit of program logic that involves choosing alternative courses of action based on value.

control—A GUI component such as a text field, button, or check box that users can manipulate to interact with a program.

control statement—The part of a structure that determines whether the subsequent block of statements executes.

decrementing—The act of decreasing the value of a variable by 1.

counted loop—A definite loop.

default constructor—A constructor that requires no parameters; it can be automatically supplied or written by a programmer.

CSV file—A file that contains separated values.

default event for a Control—The event method generated when it is double-clicked in the IDE, as well the user expects to generate when they encounter the Control in a working application.

culture—A set of rules that culturally define values such as money and dates are formatted.

default value of an object—The value initialized with a default constructor.

data files—Files that contain facts and figures; persistent connections of related records.

hierarchy—The relationship of characters, fields, records, and files.

definite loop—A loop in which the number of iterations is predetermined. A counted loop with infinite loop.

data type—A description of the function and size of data item as well as the operations that can be performed on it.

delegate—An object that contains a reference to a method.

derived class—A subclass; a class that has inherited from a base class.

deserialization—The process of converting streams of bytes into objects.

design time—The period of time during which a programmer designs a program’s interface and writes the code.

destructor—A method that contains the actions performed when an instance of a class is destroyed.

Developer Command Prompt—A special version of the command prompt for which specific settings have been enabled so you can easily compile and run C# programs.

digit separators—Symbols used to separate the digits in a number for readability.

double—A data type that can hold a floating-point number with up to fifteen significant digits of accuracy.

do loop—A loop that executes at least once, as the condition is tested at the end.

dual-alternative—Decisions that have two outcomes.

enhanced for loop—A version of the loop that iterates through a collection.

enumeration—A list of names representing constants.

escape sequence—A single character beginning with a backslash.

Equals()—A method that determines if two strings are equivalent.

empty body—A block that has no statements.

encapsulation—The technique of packaging an object’s attributes and methods into a cohesive unit.

# GLOSSARY

explicitly—Purposefully. Contrast with implicitly.

flowchart—A tool that helps programmers plan a program's logic by writing steps in diagram form, using shapes connected by arrows.

exposes—Associates a FileStream with a file.

Extended Binary Coded Interchange (EBCDIC)—An eight-bit code that is used in mainframe computers.

focus—The state of a GUI component when the user's attention is drawn to it. When a component has focus, its action can be executed by pressing the Enter key.

extended class—A derived class; a subclass; a class that has inherited from a base class.

folders—Structures used to organize files.

extension methods—Static methods that act like instance methods.

for loop—A loop that contains the starting value for the loop control, the test that controls entry, and the expression that alters the loop variable, all in one statement.

form—A GUI interface for collecting, displaying, and delivering information.

format specifier—One of nine built-in format characters in a format string that defines the most used numeric types.

file pointer—A variable that holds the next byte of memory to be read from a file.
