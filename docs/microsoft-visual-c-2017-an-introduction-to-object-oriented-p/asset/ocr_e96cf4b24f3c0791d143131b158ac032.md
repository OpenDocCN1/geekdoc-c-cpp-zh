# CHAPTER 7 Using Methods

You can create and pass an unnamed array to a method in a single step. For example, you can write the following:
nMethodThatAcceptsArray(new int[] {45, 67, 89});

You can pass a multidimensional array to a method by indicating the appropriate number of dimensions after the data type in the method header. For example, the following headers accept two-dimensional arrays of ints and doubles, respectively:
public static void displayScores(int[] , scoresArray)
public static bool areAllPricesHigh(double[] , prices)

With jagged arrays, you can insert the appropriate number of square brackets after the data type in the method header. For example, the following methods accept jagged arrays of ints and doubles, respectively:
public static void displayIds(int[][] idArray)
public static double computeTotal(double[][] , prices)

Methods that accept multidimensional arrays as parameters (whether jagged or not), notice that the brackets define the array in each method header are empty. Like any other array passed to a method, inserting numbers into the brackets for a jagged array is not necessary because array name is a starting memory address. The way you manipulate subscripts within the method determines how rows and columns are accessed.

The size of each dimension of a multidimensional array can be accessed using the GetLength() method. For example, scoresArray.GetLength() returns the value of the first dimension of scoresArray.
