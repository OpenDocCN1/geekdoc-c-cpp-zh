Figure 2-17 shows a program that makes several comparisons using the three methods; in each case the method call is shaded. Figure 2-18 shows the program’s output.

Methods like Compare() that are not preceded by an object and a dot when they are called static methods. Methods like CompareTo() that are preceded by an object and a dot are not static and are instance methods. The "Advanced Concepts" chapter explains more.

```
using System;
using static System.Console;
using static System.String;
class CompareNames2
{
    static void Main()
{
        string name1 = "Amy";
        string name2 = "Amy";
        string name3 = "Mathew";
        WriteLine("{0} and {1}: Equals(0) method gives {2}",
            name1, name2, name1.Equals(name2));
        WriteLine("{0} and {1}: Equals(0) method gives {2}",
            name1, name3, name1.Equals(name3));
        WriteLine("{0} and {1}: CompareTo() method gives {2}",
            name1, name2, name1.CompareTo(name2));
        WriteLine("{0} and {1}: CompareTo() method gives {2}",
            name1, name3, name1.CompareTo(name3));
        WriteLine("{0} and {1}: Compare() method gives {2}",
            name1, name2, Compare(name1, name2));
    }
}
```
