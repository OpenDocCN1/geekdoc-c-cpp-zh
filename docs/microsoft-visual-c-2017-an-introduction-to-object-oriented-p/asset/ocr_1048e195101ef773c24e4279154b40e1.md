# W

while loop—A structure that executes a body of statements continuously while some condition continues to be true; it uses the keyword while.

whitespace—Any combination of spaces, tabs, and carriage returns (blank lines) in a program.

widgets—Interactive controls such as labels, scroll bars, check boxes, and radio buttons.

write to a file—To store data in a computer file on a permanent storage device.

# X

XML—An abbreviation of eXtensible Markup Language, which is a standard for exchanging data over the Internet.

# XML-documentation format

comments—Comments that use a special set of tags within angle brackets to create documentation within a program.
