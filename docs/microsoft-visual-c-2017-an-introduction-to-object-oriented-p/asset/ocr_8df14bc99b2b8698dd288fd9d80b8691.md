# Files and the File and Directory Classes

Although their contents vary, text and binary files have many common characteristics

+   - Each has a name. The name often includes a dot and file extension that describes the type of the file. For example, MyNotes.txt is a plain text file, and MyPicture.jpg is an image file in Joint Pictures Expert group.
- Each file has a specific time of creation.
- Each file occupies space on a section of a storage device; that, each file has a size. Sizes are measured in bytes. A byte is small for example, in a simple text file, a byte holds only one character. Because a byte is so small, file sizes are usually expressed in kilobytes (thousands of bytes), megabytes (millions of bytes), and gigabytes (billions of bytes).

When you use a device, you never directly use the copy that is stored in a file. Instead, you use a copy that has been loaded into memory. Especially when data items are stored on a hard disk, their locations might not be clear to you—data just seems to be "in the computer." However, when you work with stored data, you must transfer copies from the storage device into memory. When you copy data from a storage device into RAM, you read from the file. When you store data in a computer on a persistent storage device, you write to the file. This means you copy data from RAM to storage

> Because you can erase data from files, some programmers prefer the term persistent to permanent storage. In other words, you can remove data from a file on a device such as a disk drive, even if it is not technically permanent. However, the data remains in the file when the computer loses power, so using RAM, the data persists, or perseveres.

Computer files are the electronic equivalent of paper documents stored in cabinets. In a physical cabinet, the easiest way to store a document is to toss it into a drawer without a folder. When storing computer files, this is the equivalent of placing a file in the main or root directory of your storage device. However, for better organization, most office clerks place documents in folders; most computer users also organize their files into folders or directories. Users can also place folders within folders to form a hierarchy. The combination of the disk drive plus the hierarchy of directories in which a file resides is its path. For example, in the Windows operating system, the following line would be the complete path for a file Data.txt on the C-drive in a folder named Chapter14 within the CSharp folder:

```
C:\CSharp\Chapter14\Data.txt
```

The terms directory and folder are used synonymously to mean an entity is used to organize files. Directory is the more general term; the folder can come into use in graphical systems. For example, Microsoft began calling directories with the introduction of Windows 95 in 1995. The folder was first used in the 1950s with the Electronic Recording Machine, Accounting (ERMA).

C# provides built-in classes F1le and Direct that contains methods to help you manipulate files and their directories, respectively.
