# Features

Microsoft Visual C# 2017 is a superior textbook because it also includes the following new features:

+   * C# 7.0 in Visual Studio 2017—This edition is written and tested using the latest edition of C.
* Conventional method names—All methods have been rewritten to follow the C# naming convention starting with an uppercase letter.
* Splitting strings—The new version of C# automatically splits strings into multiple concatenated strings.
* Returning values by reference—A new feature in C# allows methods to return a reference.
* Exercises—Each chapter includes meaningful programming exercises that provide additional practice of the skills you learned in the chapter. Several new exercises appear in each chapter of this chapter, and all the replaced exercises and solutions are available to instructors to provide additional student assignments or to be the basis for lectures.

Microsoft Visual C# 2017 also includes the following features:

+   * Early GUI applications—Students can create GUI applications in Chapter 3. The earlier introduction helps engage students who have used GUI applications their entire lives. In subsequent chapters on sections, loops, arrays, and methods, students apply concepts to applications in both console and GUI environments. This approach keeps some examples simple while increasing the undoubtedly input, processing, and output are programming universal, no matter what interface is used. The book is structured so that students who want to skip Chapter 3 until they understand object-oriented programming can do with no loss of continuity.
* Objectives—Each chapter begins with a list of objectives so you know the topics that will be presented in the chapter.
* Notes—These tips provide additional information—for example, alternative method of performing a procedure, another term for a concept, background information on a technique, or a common error to avoid.
* Figures—Each chapter contains many figures. Code figures are bold most frequently 25 lines or shorter, illustrating one concept at a time. Frequently placed screen shows exactly how program output appears. In this edition, all C# keywords that appear in figures are bold to help them stand out from programmer-created identifiers.
* Summaries—Following each chapter is a summary that recaps the concepts and techniques covered in the chapter. This feature helps you to check your understanding of the main points in each chapter.
