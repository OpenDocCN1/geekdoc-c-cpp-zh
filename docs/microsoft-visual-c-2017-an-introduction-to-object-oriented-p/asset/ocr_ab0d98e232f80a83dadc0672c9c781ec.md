# Understanding Numeric Type Conversion

When you perform arithmetic with variables or constants of the same type, the result of the arithmetic retains its type. For example, when you divide two ints, the result is an int; when you subtract two doubles, the result is a double. However, you need to perform mathematical operations on different types. For example, in the code below, you can multiply an int by a double:

```
int hoursWorked = 36;
double payRate = 12.35;
double grossPay = hoursWorked * payRate;
```
