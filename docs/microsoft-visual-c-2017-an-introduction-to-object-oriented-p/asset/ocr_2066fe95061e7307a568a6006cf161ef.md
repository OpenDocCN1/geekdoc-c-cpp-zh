# Adding MonthCalendar and DateTimePicker Controls to a Form

![](bbox=[0.116, 0.096, 0.442, 0.396])

In Chapter 14, you will learn to use DateTimePicker objects to hold data about dates and times.

If you select the minDate value to the MonthCalendar's TodayDate property, the day user cannot select a date before the date you select. For example, you cannot make appointments or schedule deliveries in the past, so you might copy the code in the form's Load() method:

```
calendar1.MinDate = calendar1.TodayDate;
```

Conversely, you might want to prevent users from selecting a date in the future—for example, if the user is entering his birth date, it cannot be in the future. In that case, you could code a statement similar to the following:

calendar1.MaxDate = calendar1.TodayDate;
