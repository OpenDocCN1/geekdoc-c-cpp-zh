In Chapter 2, you learned to use an f following a floating-point constant to indicate the float type. Recall that a numeric constant with a decimal point is a double by default.

After a Font object bigFont is instantiated, you can code statements similar to the following:

If you want to change the properties of several objects at once in the IDE, you can drag your mouse around to create a temporary group and then change the property for all of them with one entry in the Properties list.

The Font class includes a number of overloaded constructors. For example, you can also create a Font using a FancyStyle, as in the following declaration:
nFont aFancyFont = new Font("Arial", 24, Style.Italic);

Table 12-3 lists the available FontStyles. You can combine multiple styles using the pipe (| also called the logical OR operator or the bitwise OR operator. You first learned this operator in Chapter 4). The word or indicates that bits are turned on in the result when either of the operands contains an on-bit in a given position. For example, the code creates a Font that is bold and underlined because the bits indicate bold and underlined are both turned on in the result:

Font boldAndUnderlined = new Font("Helvetica", 10, Style.Underline);
