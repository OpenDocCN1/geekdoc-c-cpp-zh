You are not setting aside computer memory in which the Employee named myAssistant can be stored—that is done only for the built-in, predefined types. To allocate the needed memory for the object, you must use the new operator. You used the new operator earlier in this book when you learned to set aside memory for an array.

Defining an Employee object myAssistant requires two steps—you must declare a reference to the object and then you use the statement that actually sets aside memory to hold myAssistant:

```
Employee myAssistant;
myAssistant = new Employee();
```

You can also declare and reserve memory for myAssistant in one statement, as in the following:

```
Employee myAssistant = new Employee();
```

In this statement, Employee is the object's type (as well as its class), and myAssistant is the name of the object. The equal sign is the assignment operator, so a value is being assigned to myAssistant. The new operator is allocating a new, unused portion of computer memory for myAssistant. The value being assigned is a memory address where the object created by the Employee() constructor will be located. Memory address—when you refer to myAssistant, the compiler will locate it at the appropriate address for you.

Because the identifiers for objects are references to their memory addresses, you can call any class a reference type—in other words, a type that refers to a specific location. A reference type is a type that holds an address, as opposed to the predefined types like int, double, and char, which are value types and a value as opposed to its address. (In Chapter 2, you learned about enumerations; they are value types, to.)

In programming circles, you might debate whether everything in C# is an object. Although some disagree, the consensus is that types like int and double are not objects; only reference types are. Further continuing the issue, a value type can easily be converted to an Object with a statement such as Object myObject=Integer; The action that takes an implicit conversion is known as boxing.

In C#, you can create a struct which is similar to a class in that it can contain fields and methods but is a value type rather than a reference type. See the C# documentation for further details.

You can also use the new operator for simple data types. For example, to declare an integer variable x, you can write the following:

```
int x = new int();
```

Programmers usually use the simpler format:

```
int x;
```

With the first format, x is initialized to 0. With the second format, x holds no starting value.
