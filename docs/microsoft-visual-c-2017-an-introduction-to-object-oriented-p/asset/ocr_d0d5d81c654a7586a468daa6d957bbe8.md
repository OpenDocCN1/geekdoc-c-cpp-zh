# Writing Methods That Require Multiple Arguments

```
private void DisplaySalesTax(double saleAmount, double taxRate)
{
    double tax;
    tax = saleAmount * taxRate;
    WriteLine("The tax on {0} is {2}",
        saleAmount.ToString("C"), taxRate.ToString("P"),
        tax.ToString("C"));
}
```

**Figure 7-12** DisplaySalesTax() method that accepts two parameters

In Figure 7-12, two parameters (saleAmount and taxRate) appear within the parentheses of the method header. a comma separates the parameters, and each parameter requires its own named type (in this case, both parameters are of double) and an identifier. A declaration for a method that receives two or more arguments must list the type for each parameter separately, even if the parameters have the same type.

When you pass values to the method in a statement such as DisplaySalesTax(myPurchase, localRate); the first value will be referred to as saleAmount within the method, and the second value will be referred to as taxRate. Therefore, it is very important that arguments are passed to a method in the correct order. The following call will result in output stating that The tax on $200.00 at 10.00%: $20.00.

```
DisplaySalesTax(200.00, 0.10);
```

However, the following call results in output that The tax on $0.10 on 200.00% is $20.00. Although the arithmetic is the same, the explanation is wrong (unless there is an extremely high local tax rate).

```
DisplaySalesTax(0.10, 200.00);
```

You can write a method to take any number of parameters in any order. When you call the method, however the arguments you send must match it (both number and type) the parameters listed in the method declaration, with the following exceptions:

+   - The type of argument does not need to match the parameter list exactly if the argument can be promoted to the parameter type. For example, an int argument can be passed to a double parameter.

+   - The number of arguments does not need to match the number in the parameter list when you use default arguments. You will learn about default arguments in Chapter 8.

Thus, a method to compute and display an automobile salespersons commission might require arguments such as a string for the salesperson's name, an integer value of a sold car, a double percentage commission rate, and a character code for the vehicle type. The correct method would execute only when all arguments of the correct types are sent in the correct order.
