3. The Hello application editing window appears. A lot of code is already written for you in this window, including using some statements, a namespace named Hello, a class named Program, and a Main() method. To create the Hello program, you need to add two statements to the predefined code. Place your cursor after the last statement, press **Enter** to start a new line, and add an additional using statement:

```
using System.Console;
```

After the opening brace of the Main() method, press **Enter** to start a new line, and add the following statement:

```
WriteLine("Hello, world!");
```

Figure 1-17 shows the editing window after the using and WriteLine statements have been added.
