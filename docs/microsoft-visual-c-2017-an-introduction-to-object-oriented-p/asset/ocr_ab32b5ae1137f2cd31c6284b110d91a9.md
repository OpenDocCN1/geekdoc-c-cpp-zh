# Using the finally Block

When you act to perform at the end of a try...catch sequence, you can use a finally block, which executes whether or not the block identifies exceptions. Typically, you use the finally block to perform clean-up tasks that may occur, regardless of whether any errors occurred or were caught. Figure 11-20 shows the format of a try...catch sequence that uses a finally block.

```
try
{
  // Statements that might cause an Exception
}
catch(SomeException anInstance){
  // What to do about it
}
finally
  // Statements here execute
  // whether an Exception occurred or not
}
```

**Figure 11-20** General form of a try...catch block with a finally block

Additionally, if the try code fails and throws an Exception that is caught, the catch block executes, and control gains again to any statements that are coded after the catch block.
