ASCII is not the only computer code, but it is typical and the one used in most computers. The Extended Binary Coded Decimal Interchange Code (EBCDIC) is an eight-bit code that is used in IBM mainframe computers. In these computers, the principle is the same—every character is stored as a series of binary digits. However, the actual values used are different. For example, in EBCDIC, A is 11000001, or 93. Unicode is another code used by languages such as Java and C#. 16 bits are used to represent each character. The character A in Unicode has the same decimal (65) as the ASCII A, but it is stored as 0000000001000001. Using 16 bits provides many more combinations than using eight bits—65,536 to be exact. Unicode has enough available codes for all English letters and digits and from many international alphabets.

Ordinary computer users seldom know the numeric codes behind the letters, numbers, and punctuation marks they enter from their keyboards or see displayed on a monitor. However, they see the consequence of the value behind when they see data sorted in alphabetical order. When you sort a list of names, Andrea and Caroline comes before Brian, and Caroline because the numeric code for A is lower than the code for B, and the numeric for C is higher than the code for B, no matter whether you are using ASCII, EBCDIC, or Unicode.
