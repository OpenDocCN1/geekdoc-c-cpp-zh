# CHAPTER 3 Using GUI Objects and the Visual Studio IDE

Some of the properties listed in the Properties window have a small plus sign that appears to the left of the property. This is a node that you can click to expand or condense a property. if you click the Size node, you will see an expanded list that displays the two parts of Size (width and Height). When the list is expanded, the node changes to a minus sign, which you can then click to condense the list.

When you sort Properties in alphabetical order in the Properties window, the Name entry is not in alphabetical order—it appears near the top of the list. Name appears in parentheses because the opening parenthesis has a lower value than an A, so if the Properties list is sorted in alphabetical order, Name is near the top and easy to find. (An opening parenthesis like Appendix B contains information about Unicode.) For most professional applications, you will want to provide a Form with a recognizable identifier that is more descriptive than Form.

Do not confuse a Form's Name with its Text property. If you change a Form's Name, you don't notice any difference in the visual design, but all references to the form are changed in the code. Therefore, a Form's Name is an identifier, and it must follow the rules for variable names without digit. This means, for example, that a Form's Text appears in its title, and it can be any string. For example, in an accounting application, you might name a form BudgetForm but assign 2018 Budget Calculator as its Text.

In Chapter 2, you learned to enclose a string in quotation marks. Although a Form's Text is a string, you do not type containing quotes when you enter a value for the Text property in the Properties list. However, when you view C#, you will see quotation marks around your Text value.
