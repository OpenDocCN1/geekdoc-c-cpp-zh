
# Chapter Summary

- A constant is a data value that cannot be changed after a program is compiled; a value in a variable can change. C# provides for 15 basic built-in types of data. A variable declaration includes a data type, an identifier, an optional assigned value, and a semicolon.

- You can display variables by using the variable name within a WriteLine() or Write() method call. To make producing output easier, you can combine strings and variable values into a single Write() or WriteLine() statement by using a format string.

- C# supports nine integral data types: byte, sbyte, short, ushort, int, uint, ulong, and char.

- C# supports three floating-point data types: float, double, and decimal. You can use format and precision specifiers to display floating-point data to a specified number of decimal places.

- You use the binary arithmetic operators +, -, *, and % to manipulate values in your programs. Multiplication, division, and remainder always take place prior to addition or subtraction in unless you use parentheses to override the normal precedence. C# provides several shortcut arithmetic operators, including the binary operators +=, -=, *=, /=, and the unary prefix increment (++) and decrement (--) operators.

- A bool variable can hold only two values—true or false. C# supports six comparison operators: >, <, <=, >=, ==, and !=. An expression can return a Boolean value.

- When you perform arithmetic with variables or constants of the same type, the result of the arithmetic retains that type. When you perform arithmetic operations with operands of different types, C# provides a unifying type for the result and implicitly converts non-forming operands to the unifying type. You can explicitly override the unifying type imposed by C# by performing a cast.

- You use the char type to hold any single character. You place constant character values within string quotation marks—including nonprinting characters such as a space or a tab—in a char variable. To store these characters, you must use an escape sequence, which begins with a backslash.

- In C#, you use the string type to hold a series of characters. The value of a string is expressed in double quotation marks. Although the == and != comparison operators can be used with string literals, you can also use the Equals(), Compare(), CompareTo(), and Substring() methods and the Length property that belongs to the String class.

# CHAPTER 2 Using Data

- Named constants are program identifiers whose values cannot change. Conventionally, the identifiers are all uppercase, with underscores inserted for readability. Enumerations are lists of named constants that are integers by default, and frequently the lists hold consecutive values.

- You can use the Readline() method to accept user input. Often you must use a Convert class method to change the input string into a usable data type.

# Key Terms

**Constant** describes data items whose values are fixed.

A **literal constant** is a value that is taken literally at each use.

A **data type** describes the format and size of a data item and defines what types of operations can be performed on the item.

**Intrinsic types** of data are basic types; C# provides 15 intrinsic types.

An **alias** is another name for something.

A **simple type** is one of the following in C#: byte, sbyte, short, ushort, int, uint, ulong, float, decimal, char, and bool.

**Unicode** is a 16-bit coding scheme for characters.

A **variable declaration** is the statement that names a variable; it includes a data type, an identifier, an optional assignment operator and assigned, and an ending semicolon.

The **assignment operator** is the equal sign (=); any value to the right of the assignment is assigned to, or taken by, the variable to the left.

An **initialization** is an assignment made when a variable is declared.

An **int** data type holds an integer.

An **integer** is a whole number.

An **assignment** is a statement that provides a variable with a value.

To **concatenate** a string with another value is to join the two ends to end using a plus sign.

A **format string** is a string of characters that controls the appearance of output.

A **place holder** holds a position for a variable value within a string; it consists of a pair of braces containing a number that indicates the desired variable's position in a list that follows the string.

**String interpolation** is the process of replacing string place holders with values; also called variable substitution.

Integral data types are those that store numbers. The nine integral types are byte, sbyte, short, ushort, int, uint, long, ulong, and char. The first eight always represent whole numbers, and the ninth type, char, is used for characters such as 'A' or 'a'.

Digit separators are symbols used to separate the digits in a long number for readability; in C# the underscore (_) is the digit separator.

A floating-point number is one that contains decimal positions.

Significant digits provide a measure of the mathematical accuracy of a value.

A float data type can hold a floating-point number with as many as seven significant digits of accuracy.

A double data type can hold a floating-point number with 15 or 16 significant digits of accuracy.

The decimal data type is a floating-point type that has a greater precision and a smaller range than a float or double, which makes it suitable for financial and monetary.

Scientific notation is a means of expressing very large and small numbers using an exponent.

Standard numeric format strings are strings of characters that define the most commonly numeric types.

The precision specifier in a string controls the number of significant digits.

A C# culture is a set of rules that determines culturally dependent values.

Arithmetic operators are used to perform arithmetic; they include -, *, and %.

Operands are the values that operations use—one value to the left of the operator and another to the right.

Operator precedence determines the order in which parts of an expression are evaluated.

Order of operation is another term for operator precedence.

Associativity specifies the order in which a sequence of operations with the same precedence are evaluated.

The add and assign operator (+=) adds the operand on the right to the left and assigns the result to the left in one step.

The prefix increment operator (++ before a variable) increases the variable's value by 1 and then evaluates it.

The postfix increment operator (++ after a variable) evaluates a variable and adds 1 to it.

Unary operators are used with one operand.

The decrement operator (--) reduces the variable's value by 1. There is a prefix and a postfix version.

A Boolean variable can hold only two values—true or false.

A comparison operator compares two items; an expression containing a comparison operator has a Boolean value.

A unifying type is the type chosen for an arithmetic result when operands are of dissimilar types.

Implicitly means automatically.

Type precedence is a hierarchy of data types used to determine the unifying type in arithmetic expressions containing dissimilar types.

Explicitly means purposefully.

An explicit cast purposefully assigns a value to a different data type; it involves placing the desired result in parentheses followed by the variable or constant to cast.

The char data type can hold any single character; a literal is contained within single quotation marks.

An escape sequence is two symbols beginning with a backslash that represents a nonprinting character as a tab.

Hexadecimal, or base 16, is a mathematical system that uses 16 symbols to represent numbers.

Lexically means alphabetical.

Immutable describes unchangeable objects as strings that refer to a new memory location when a new value is assigned.

A named constant is an identifier whose value must be assigned upon declaration and whose content cannot change.

Screaming caps is a style that uses all uppercase letters and underscores to name a program component—often a named constant.
