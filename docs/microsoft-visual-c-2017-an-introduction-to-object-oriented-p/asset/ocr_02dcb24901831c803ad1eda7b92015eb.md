Everything in Figure 1-12 was generated automatically by Visual Studio except for the following:

+   * The programmer selected the project name.

+   * The programmer added a `using System.Console;` statement so that `WriteLine()` could be used without adding System and Console each time.

+   * The programmer added the three lines coded in the `Main()` method to produce output.

You can see the Visual Studio environment looks like a window, containing menu options such as File, Edit, and Help, with icons representing options such as Saved Items and Undo. Selecting many of the menu options displays a drop-down list of available options. Many of the options have shortcut keys that you can use instead. For example, if you select File from the menu bar, you can see that there is a shortcut for Save Program.cs Ctrl+S. You will see about these options later in this chapter and continue to learn more of them as you work with C# in the IDE.

In Figure 1-12 you also see a small lightbulb to the left of the using statement that was added by a programmer. In this case, if you click the lightbulb, you will see a message that you could remove the first five unnecessary statements, retaining only the `using System.Console;` `using` statement. You can also leave the extra `using` statement in place, and the program will still work correctly.

In Figure 1-12 you can also see vertical bars to the left of the code. These bars indicate changes that have been made since you opened the file. On your monitor, the bars will be green if the code has been saved, and yellow if it has not yet been saved.
