# CHAPTER 6 Using Arrays

If you modify your program to change the size of the array, you must remember to change the comparison in the for loop as well as every other reference to the array size within the program. Many editors have a "find and replace" feature that lets you change (for example) all of the 5s in a file, either simultaneously or one by one. However, you must be careful not to change 5s that have nothing to do with the array; for example, do not change the 5 in the score 75 inadvertently—it is the second value in the myScores array and has nothing to do with the array.

A better approach is to use a size that is automatically generated when you declare an array. Because every array automatically derives from the class System.Array class with any array you create can use the fields and methods that are part of the System.Array class you learned that every string has a Length property. Similarly, every array has a Length property the Length is always updated to reflect any changes you make to an array's size. The following segment of code displays Array size is 5 and subsequently displays the array's contents:

```
int[] myScores = {100, 76, 88, 90};
WriteLine("Array size is {0}");
for(int x = 0; x < myScores.Length; ++x)
WriteLine(myScores[x]);
```

> An array's read-only property—a property you can access, but to which you cannot assign a new value. It is costly, as is the convention with all C# properties. You will create identifiers for your own classes in the chapter "Using Classes and Objects."

If you want to write a program in which a large array is required, you might want to test it with a smaller array. For example, if a program requires interactive data for 50 items, you might want to test it first with three or four items so you can work out the bugs without wasting much time on data entry. After the program works correctly with just a few items, if you have used the Length property to access the array, you only need make one change to the array size at the top of the program when you are ready to test the full version.

# Using foreach

You can easily navigate through arrays using a for or while loop that varies a subscript from 0 through Array.Length - 1. C# also supports a foreach statement that you can use to cycle through every array element without a subscript. With the foreach statement, you provide a temporary iteration variable that automatically holds each array value in turn.

For example, the following code displays each element in the payRates array in sequence:

```
double[] payRates = {120.00, 17.35, 21.12, 27.45, 32.22};

WriteLine("{0}", money.ToString("C"));
```
