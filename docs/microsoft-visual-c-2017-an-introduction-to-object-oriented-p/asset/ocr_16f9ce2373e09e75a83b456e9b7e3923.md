# CHAPTER 11 Exception Handling

```
using System;
using static System.Console;
class MilesGallon {
    static void Main() {
        int milesDriven;
        int gallonsOfGas;
        int mpg;
        try {
            Write("Enter miles driven ");
            milesDriven = Convert.ToInt32(ReadLine());
            Write("Enter gallons of gas purchased ");
            gallonsOfGas = Convert.ToInt32(ReadLine());
            mpg = milesDriven / gallonsOfGas;
        }
        catch (Exception e) {
            mpg = 0;
            WriteLine("You attempted to divide by zero!");
        }
        WriteLine("You got {0} miles per gallon", mpg);
    }
```

**Figure 11-6** The MilesGallon2 program

Figure 11-7 shows two executions of the program. In the first execution, a value is entered for gallonsOfGas, and the program operates normally, bypassing the catch block. In the second execution, however, the user enters 0 for gallonsOfGas. When division is attempted, an Exception object is automatically created and thrown. The catch block catches the Exception, which becomes known as e. (The shaded arrow shows where it was caught). The statements in the catch block set mpg to 0 and display a message. Whether the catch block executes or not, the final WriteLine() statement follows that catch block's closing brace executes.
