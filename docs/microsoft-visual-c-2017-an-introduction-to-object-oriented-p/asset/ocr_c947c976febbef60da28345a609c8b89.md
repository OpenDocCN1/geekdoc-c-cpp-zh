In the program, the user enters an integer. Next, in the shaded switch control statement, the input integer is cast to an enumeration value. Then, enumeration values become the types for each case. For some reading the code, the purposes of enum values such as ACCOUNTING and CIS are clearer than their integer equivalents would be. Figure 4-24 shows a typical execution of the program.

```
using System;
using static System.Console;
class DivisionBasedOnMajor
{
    enum Major
    {
        ACCOUNTING = 1, CIS, ENGLISH, MATH, MARKETING
    }
    static void Main()
    {
        int major;
        string message;
        Write("Enter major code >> ");
        major = Convert.ToInt32(ReadLine());
        switch((Major)major)
        {
            case Major Major.ACCOUNTING:
            case Major.CIS:
            case Major.MARKETING:
                message = "Major is in the business division";
                break;
            case Major.ENGLISH:
            case Major.MATH:
                message = "Major is in the humanities division";
                break;
            default:
                message = "Department number is invalid";
                break;
        }
        WriteLine(message);
    }
}
```
