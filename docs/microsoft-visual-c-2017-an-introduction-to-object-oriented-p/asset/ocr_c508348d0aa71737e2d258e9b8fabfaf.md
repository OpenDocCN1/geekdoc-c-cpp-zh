An argument type in a method can call match the method's parameter type exactly, but it can use a different data type if the argument can be converted automatically to the parameter type. Recall from Chapter 2 that C# supports the following automatic conversions:

+   - From byte to short, int, long, float, double, or decimal
- From byte to short, us, int, uint, long, float, double, or decimal
- From short to int, long, float, double, or decimal
- From ushort to int, uint, long, float, double, or decimal
- From int to long, float, double, or decimal
- From uint to long, long, float, double, or decimal
- From long to float, double, or decimal
- From ulong to float, double, or decimal
- From char to ushort, int, uint, long, float, double, or decimal
