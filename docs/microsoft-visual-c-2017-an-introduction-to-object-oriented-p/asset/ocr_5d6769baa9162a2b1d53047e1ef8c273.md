ushort (unsigned short int). For example, a payroll program might contain a variable name numberOfDependents that is declared as type byte, because numberOfDependents will never need to hold a value exceeding 255; for that reason, you can allocate just one byte of storage to hold the value. When you declare variables, you always make a judgment about which type to use. If you use a type that is too large, you waste storage. If you use a type that is too small, your program won't compile. Many programmers simply use int for most numbers.

Saving memory is seldom an issue for an application that runs on a PC. However, when you write applications for small devices with limited memory, such as smartphones, conserving memory becomes important.

The word integer has only one r—at the end. Pronouncing it as "inter-ger," with an r in the middle will mark you as unprofessional.

When you assign a value to any numeric variable, you do not use commas or other nonnumeric characters like dollar or percent signs; you use only digits. The exception is that, starting with C# 7.0, you can insert underscores as digit separators for readability. For example, the two declarations are identical, but you might find one easier to read:

```
int aLotMoney = 23456789;
int aLotMoney = 23_456_789;
```

You can also use a plus or minus sign to indicate a positive or negative integer; a value without a sign is assumed to be positive. For example, to initialize a variable annualSalary you might write the following with a dollar sign or comma:

```
int annualSalary = 20000;
```
