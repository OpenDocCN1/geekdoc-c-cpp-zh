# Overloading Operators

C# operators are the symbols you use to perform operations on objects. You have used many operators, including arithmetic operators (such as + and -) and logical operators (such as == and &&). Separate actions can result from what seems to be the same operator or command. This occurs frequently in all computer programming languages, not just object-oriented languages. In most programming languages and applications such as spreadsheets and databases, the + operator has a variety of meanings. A few of them include:

+   - Before a value (called unary form), + indicates a positive value, as in the expression +7.
- Between two integers (called binary form), + indicates integer addition, as in the expression 5 + 9.
- Between two floating-point numbers (also called binary form), + indicates floating-point addition, as in the expression 6.4 + 2.1.
- Between two strings, + indicates concatenation, as in the expression "Hello," + "there".

Expressing a value as positive is a different operation from using the + operator to perform arithmetic or concatenate strings, so + is overloaded several times, that it can take one or two arguments and have a different meaning in each case. It can also take different types—you use a to add two ints, an int and a double, and a variety other combinations. Each use results in different actions behind the scenes.

Just as it is convenient to use + between integers and doubles to add them, it can also be convenient to use + between objects, such as Employees or Books. To be able to use arithmetic symbols with your own objects, you must overload the symbols.

C# operators are classified as unary or binary, depending on whether they take one or two arguments. The rules for overloading are shown in the following list:

+   - The unary operators are:
  + - ! -- -- true false
- The binary operators are:
  + * / % & ^ ! != > >= <=
- You cannot overload the following operators:
  && || ?? ? checked unchecked new typeof is
- You cannot overload an operator for a built-in data type. For example, you cannot change the meaning of + between two ints.
