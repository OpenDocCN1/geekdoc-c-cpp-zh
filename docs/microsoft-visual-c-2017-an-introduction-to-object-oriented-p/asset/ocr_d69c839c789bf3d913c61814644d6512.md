Table 13-5 describes KeyEventArgs properties, and Table 13-6 describes KeyPressArgs. An important difference is that KeyEventArgs objects include data about helper keys or modifier keys that are pressed with. For example, if you need to distinguish between a user pressing A and Alt+A in your application, you must use a keyboard event that uses an argument of KeyEventArgs.

| Property | Description |
---|---|
 Alt | Indicates whether the Alt key was pressed |
 Control | Indicates whether the Control (Ctrl) key was pressed |
 Shift | Indicates whether the Shift key was pressed |
 KeyCode | Returns the code for the key |
 KeyData | Returns the key code along with any modifier key |
 KeyError | Returns a numeric representation of the key (this number is known as the Windows virtual key) |
