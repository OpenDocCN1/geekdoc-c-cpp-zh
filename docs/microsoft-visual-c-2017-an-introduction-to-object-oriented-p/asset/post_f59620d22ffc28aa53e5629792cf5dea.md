
# Using Multidimensional Arrays

The sales array contains three rows and four columns. You contain the entire set of values within a pair of curly braces. The first row of the array holds four doubles 14.00, 15.00, 16.00, and 17.00. Notice that these four values are placed within their own inner set of braces to indicate that they constitute one row, or the first, which is row 0. The row and its curly braces are separated from the next row with a comma. The next four values in their set make up the second row (row 1), which you refer to the subscript 1, and the last four values constitute the third row (row 2).

When you refer to an element in a two-dimensional array, the first value always refers to the row; the second, after the comma, refers to the column. As examples, the value of sales[0, 0] is 14.00, the value of sales[0, 1] is 15.00, the value of sales[1, 0] is 21.99, and the value of sales[2, 3] is 1.17. You do not need to place each row of values that initializes a two-dimensional array on its own line. However, doing so makes the positions of values easier to understand.

As an example of how useful two-dimensional arrays can be, assume that you own an apartment building with four floors—a basement, which you refer to floor zero, and three other floors numbered one, two, and three. In addition, each of the floors has studio (with no bedroom), one-, and two-bedroom apartments. The monthly rent for each type of apartment is different, and the rent is higher for apartments with more bedrooms. Figure 6-18 shows the rental amounts.

To determine a tenant's rent, you need to know two pieces of information about the apartment: the floor and the number of bedrooms. In a C# program, you can declare an array of rents using the following code:

```csharp
int[,] rents = { {400, 450, 510},
                  {500, 560, 630},
                  {625, 676, 740},
                  {1000, 1250, 1600} };
```

If floor and bedrooms are integers with int-values, then any tenant's rent can be referred to as rents[floor, bedrooms].

Figure 6-20 shows a complete program that uses a rectangular, two-dimensional array to hold rent values.

```csharp
using System;
using static System.Console;
class RentFinder
{
    static void Main()
    {
        int[,] rents = { {400, 450, 510},
                        {500, 560, 630},
                        {625, 676, 740},
                        {1000, 1250, 1600} };

        int floor;
        int bedrooms;
        string inputStream;
        Write("Enter the floor which you want to live in part.");
        inputStream = ReadLine();
        floor = Convert.ToInt32(inputStream);
        Write("Enter the number of bedrooms you need ");
        inputStream = ReadLine();
        bedrooms = Convert.ToInt32(inputStream);
        WriteLine("The rent is {0}", rents[floor, bedrooms]);
    }
}
```

C# supports arrays with more than two dimensions. For example, as in the program in Figure 6-19, if you own a multistory apartment building with different numbers of bedrooms available in apartments on each floor, you can use a two-dimensional array to store the rental fees. However, if you own several apartment buildings, you might want to employ a third dimension to store the building number. Suppose you want to store rents for four buildings that have three floors each and that hold two types of apartments. Figure 6-21 shows how you might define such an array.

```csharp
int[,] rents = { {{400, 500}, {450, 550}, {500, 550}}, {{510, 610}, {710, 810}, {910, 1010}}, {{525, 625}, {725, 825}, {925, 1025}}, {{850, 950}, {1050, 1150}, {1250, 1350}} };
```

**Figure 6-21** A three-dimensional array definition

The empty brackets that follow the data type contain two commas, showing that the array supports three dimensions. A set of curly braces surrounds all the data; the inner braces surround the following:

- Four inner sets of braces surround the data for each building—each row represents a building (0 through 3).
- Within each row, the three sets of inner braces represent each floor—first basement, floor one, and floor two. For example, in building 0, {400, 500} are rents for floor 0, and {450, 550} are rents for floor 1.
- Within each floor, the two braced values represent the bedrooms—first a zero-bedroom apartment and then a one-bedroom apartment. For example, in building 0, 400 is the rent for a zero-bedroom apartment, and 500 is the rent for a one-bedroom apartment.

Using the three-dimensional array in Figure 6-21, an expression as rents[building, floor, bedrooms] refers to a specific value for a building whose number is stored in the `building` variable whose floor and bedrooms are stored in the `floor and bedrooms` variables. Specifically, rents[3, 1, 0] refers to a (zero-bedroom) apartment on the first floor of building 3 (which is the fourth building). The value of rents[3, 1, 0] is $1050 in Figure 6-21. If you are programming in C#, you can use four, five, or more dimensions in an array. As long as you can keep track of the order of the variables as subscripts, and as long as you don't exhaust your computer's memory, C# lets you create arrays of any size.

# Using Jagged Arrays

C# also supports jagged arrays. A **jagged array** is a one-dimensional array in which each element is another array. The major difference between jagged and rectangular arrays is that in jagged arrays, each can be a different length.

For example, consider an application in which you want to store train ticket prices for each stop along different routes. Some of the routes have as many as 10 stops and others as few as two. Each of the five routes could be represented by a row in a multidimensional array. You would have two rows—one for the route and one for the stop. You could use a jagged array to store this information because each route can have a different number of stops.

# Using Jagged Arrays

A jagged array is a one-dimensional array in which each element is another array. The major difference between jagged and rectangular arrays is that in jagged arrays, each can be a different length.

For example, consider an application in which you want to store train ticket prices for each stop along different routes. Some of the routes have as many as 10 stops and others as few as two. Each of the five routes could be represented by a row in a multidimensional array. You would have two rows—one for the route and one for the stop. You could use a jagged array to store this information because each route can have a different number of stops.

```csharp
int[][] tickets = new int[5][];
tickets[0] = new int[3];
tickets[1] = new int[2];
tickets[2] = new int[4];
tickets[3] = new int[1];
tickets[4] = new int[5];
```

**Figure 6-22** A jagged array definition

To initialize a jagged array, you first initialize the top-level array, and then you initialize each element as a one-dimensional array.

```csharp
int[][] routes = new int[5][];
routes[0] = new int[] { 10, 20, 30 };
routes[1] = new int[] { 40, 50 };
routes[2] = new int[] { 60, 70, 80, 90 };
routes[3] = new int[] { 100 };
routes[4] = new int[] { 110, 120, 130, 140, 150 };
```

To access an element in a jagged array, you use two sets of brackets, for example, tickets[route][stop]. This refers to the route and then the stop within that route.
