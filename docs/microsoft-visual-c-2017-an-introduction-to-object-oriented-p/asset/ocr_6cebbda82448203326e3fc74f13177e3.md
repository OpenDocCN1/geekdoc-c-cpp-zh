In the code in Figure 4-3, there is no semicolon at the end of the line that contains if(number < 5). The statement does not end at point; it ends after WriteLine("A"); if you incorrectly insert a semicolon at the end of if(number < 5), then the code means, "If number is less than 5, then, no matter what the value of number is, display A." Although it is customary, and good style, to indent any statement that executes when an if Boolean expression evaluates as true, the C# compiler does not pay attention to the indentation. Each of the following statements displays A when number is less than 5. The first shows an if statement written on a single line; the second shows an if statement on two lines with no indentation. The third uses conventional indentation. All three examples execute identically.

```
if(number < 5) WriteLine("A");
if(number < 5)
WriteLine("A");
if(number < 5)
WriteLine("A");
```

> Dont Do It\Although these first two formats work for if statements, they are not conventional, and using them makes a program harder to understand.
