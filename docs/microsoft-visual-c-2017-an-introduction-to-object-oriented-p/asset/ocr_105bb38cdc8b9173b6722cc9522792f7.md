# Understanding Class Concepts

Objects receive their attributes from classes; for example, if you invite me to a graduation party, I automatically know many things about the object. I assume that there will be a starting time, a number of guests, and some refreshments. I understand your party because of my previous knowledge of the Party class. I don't necessarily know the number of guests or the date or time of this particular party, but I understand that all parties have a date and time, then this one must be as well. Similarly, even though every stock purchase is unique, each must have a dollar amount and a number of shares. All objects have predictable attributes because they are instances of classes.

The data components of a class that for each object are stored in **instance variables**. Instance variables are also called **fields** to help distinguish them from other variables you might use. In Chapter 1, you learned that the field values of an object are also called its *attributes* and the set of attributes is known as an object's *state*. For example, the current state of a specific party is 8 p.m. and Friday; the state of a specific stock purchase is $10 and five shares.

In addition to their attributes, objects have methods associated with them, and every object that is an instance of the same class possesses the same methods. The methods associated with objects are **instance methods**. For example, two Party might possess the identifiers myBirthdayParty both have access to an IssueInvitations() method. The method might operate in the same way for both Party objects, but use data appropriate to the specific object. When you program in C#, frequently create classes from which objects will be instantiated. You also write applications to use the objects, along with their data and methods. Often, you will write programs that use classes created by others; similarly, you might create a class that other programmers use to instantiate objects within their own programs. A program or class that instantiates objects of another written class is a **class client** or **class user.**
