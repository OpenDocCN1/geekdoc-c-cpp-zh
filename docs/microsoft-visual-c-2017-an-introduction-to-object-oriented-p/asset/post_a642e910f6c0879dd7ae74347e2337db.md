# Chapter Summary

   - A sequential file is a collection of records stored on a nonvolatile device. You can read and write records in order.
   - To use a file, you must open it, creating a FileStream, StreamReader, or StreamWriter.
   - When you are finished, you should close the file to release resources.
   - A record is a line of data in a file.
   - A delimiter is a character used to separate fields.
   - Serialization is the process of converting objects into streams of bytes.
   - Deserialization is the reverse process; converting streams back into objects. To create a class that can be serialized, you mark it with the [Serializable] attribute.
   - An exception is an error that occurs during the execution of a program.
   - A try-catch block is used to handle exceptions and prevent the program from crashing.
