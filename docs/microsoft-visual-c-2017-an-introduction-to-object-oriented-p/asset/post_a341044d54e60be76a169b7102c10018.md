## Exercises

## Programming Exercises

- 1. Write a program named SubscriptTest that declares an array of doubles and uses a try block that prompts the user for a value and stores it in the array. If the value is negative, throw a new ApplicationException with an appropriate message. Create a catch block that catches any IndexOutOfRangeException and displays the error.

- 2. ArgumentException is a class that derives from Exception; use it when one or more arguments do not fall within expected range. Create an application named SwimmingTemperature containing a variable that can hold temperature expressed in degrees. Within the class, create a method that accepts a parameter and returns true or false whether the temperature is between 32 and 212 (the freezing and boiling points). If it is invalid, throw an ArgumentException.

- 3. Create a program FindRoot that finds the square root of a user's input. The Math class contains a static method Sqrt() that accepts a double and returns the square root. If the input cannot be converted to a double, display an appropriate message and set sqrt to 0. Otherwise, test the input value. If it is negative, throw a new ApplicationException with message.

- 4. Create a program StudentGradeDemo that attempts to create several valid and invalid ReportCard objects. Immediately after each instantiation attempt, handle any exceptions by displaying an error. Create a ReportCard class with four fields for a student name, numeric midterm grade, numeric final exam grade, and letter grade. The ReportCard constructor requires values for the midterm grade and determines the letter grade. Upon construction, throw an ArgumentException if the midterm or final exam is less than 0 or more than 100. The letter grade is based on the arithmetic average of the midterm and final exams using a grading scale of A for 90 to 100, B for 80 to 90, C for 70 to 80, D for 60 to 70, and F for an average below 60. Display all the data if the instantiation is successful.

- 5. Create a program BookException for Publishing Company. Create a BookException class that is instantiated when a Book's price exceeds 10 cents per page and whose constructor requires three arguments for title, price, and number of pages. Create an error message that is passed to the Exception constructor for the Message property when a Book does not meet the price-to-pages ratio. For example, an error might be:

  > For Good Night, ratio is invalid.
  > Price is $12.99 for 25 pages.

  a. Create a Book class that contains fields for title, price, and number of pages. Include properties for each field. Throw a BookException if a client program tries to construct a Book object for which the price is more than 10 cents per page. Create a program that creates at least four Book objects—some where the ratio is acceptable, and others where it is not. Catch any exceptions, and display the BookException Message.

  c. Using the Book class, write an application BookExceptionDemo2 that creates an array of five Books. Prompt the user for values for each Book. To handle any exceptions that are thrown because of improper or invalid data entered by the user, set the Book's price to the maximum of 10 cents per page. At the end of the program, display all the entered, and possibly corrected, records.
