# CHAPTER 6 Using Arrays

You could create a jagged array, allowing a different number of elements for each row. Figure 6-22 shows how you could implement this option.

```
double [] tickets = {
new double[] = {5.50, 6.75, 7.95, 9.00, 12.00,
  13.00, 14.50, 17.00, 19.00, 20.25},
new double[] = {7.50, 9.00, 9.95, 12.00, 13.00, 14.00},
new double[] = {3.50, 6.45, 9.95, 10.00, 12.75},
new double[] = {15.00, 16.00}};
```

Figure 6-22 A jagged array

Two squares brackets are used following the data type of array in Figure 6-22. This notation declares a jagged array that is composed of five separate one-dimensional arrays. Within the jagged array, each row needs its own operator and data type. To refer to a jagged array element, you use two sets of brackets after the array name—example, tickets[route][stop]. In Figure 6-22, the value of tickets[0][0] is 5.50, the value of tickets[0][1] is 6.75, and the value of tickets[0][2] is 7.95. The value of tickets[1][0] is 5.00, and the value of tickets[1][1] is 6.00. Referring to tickets[1][2] is invalid because there is no column 2 in the second row (that is, there are only two stops, not three, on train route).
