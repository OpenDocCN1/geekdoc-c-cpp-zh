# Using Other Controls

If you examine the Visual Studio IDE or search through the Visual Studio documentation, you will find many other Controls that are not covered in this chapter. If you click Project on the menu bar and add New Item, you can add Forms, Files, Controls, and other elements to your project. (In the next "You Do It" section, you create a project that adds new Forms that after selections are made from a primary Form.) New controls and containers will be developed in the future, and you might even design new controls of your own. Still, your controls will contain properties and methods, and your solid foundation in C# will prepare you to use new controls effectively.
