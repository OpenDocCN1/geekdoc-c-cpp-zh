## Using Floating-Point Data Types

A floating-point number is one that contains decimal positions. Floating-point numbers are described as having varying numbers of significant digits. A value of significant digits specifies the mathematical accuracy of the value. The concept is often used in rounding. For example, in the statement “The population of New York City is 8,000,000”, there is just one significant digit—8. The zeros are placeholders and mean to approximate the actual value.

> When numbers are stored in computer memory, using a decimal point that can “float” provides a possible range of values. As a simple example, suppose that the largest number you could store had only two digits with a fixed decimal point before. Then the positive numbers that could be stored would range from 0.0 to 9.9. However, if the decimal point can be first, middle, or last, then the range becomes .0 through 99.

C supports three floating-point data types: float, double, and decimal. For example, a

- A float data type can hold as many as 7 significant digits of accuracy. A float assigned the value 123456789 can be 123456788 because it is accurate only to the seventh digit (the third digit to the right of the decimal point).

- A double data type can hold 15 or 16 significant digits of accuracy. For example, a double given the value 123456789.98765431 will appear as 123456789.987654 because it is accurate up to the fifteenth digit (the sixth digit to the right of the decimal point).

- Compared to floats and doubles, the decimal type has a greater precision and a smaller range, which makes it suitable for financial and monetary calculations. A decimal is significant to 28 or 29 digits. As Table 2-1 shows, decimal cannot hold as large as a double (the highest value is about 10^38; the highest value of double is 10^308), but the decimal will be more accurate to more decimal places.

As an integer is int by default, a floating-point number is double by default. To explicitly state a constant as float, use F (either lowercase or uppercase) after the number, as in the following:
```csharp
float price = 4.87f;
```

You can place D (or d) after a floating-point value to indicate it is double; even without the D, however will be stored as double. To explicitly store a value as decimal, use M (or m) after the number (M stands for monetary; D cannot be used for decimal.)

> Monetary values are extremely important in business applications, C# developers frequently use the decimal type for floating-point values because floating-point numbers are double by default and do not require a modifier after the number. However, you should use the type that your instructor or manager decides is most appropriate for your application. Some programmers use the decimal type for any measurement created by humans (for example, halves of elements).

## Formatting Floating-Point Values

By default, C# always displays floating-point numbers in the most concise way possible that maintains the correct value. For example, if you declare a variable and display it in the following statements, the amount is 14.

```csharp
double myMoney = 14.00;
WriteLine("The amount is {0}", myMoney);
```

The zeros to the right of the decimal point in the assigned value will not appear in the output because they add no mathematical information. To see the decimal places in the output, you can convert the floating-point value to a string using a standard numeric format string.

Standard numeric format strings are strings of characters expressed in double quotation marks that indicate a format for output. They take {0:X}, where X is the format specifier and O is the precision specifier. The **format specifier** can be one of nine built-in format characters that define the commonly used numeric format types. The **precision specifier** controls the number of significant digits or zeros to the right of the decimal point. Table 2-2 lists the format specifiers.

| Format Character | Description | Default Format (if precision is given) |
| :--- | :--- | :--- |
| C c | Currency | $$XX,XXX,XX (XX,XXX,XX) |
| D d | Decimal | [-]XXXXXX |
| E e | Scientific (exponential) | [-]XXXXXe+ xxx, [-]XXXXXe- xxx, [-]XXXXxe- xxx |
| F f | Fixed point | [-]XXXX.XX |
| G g | General | Variable; either with decimal places or scientific |
| N n | Number | [-]XX,XXX,XX |
| P p | Percent | Represents a numeric value as a percentage |
| R r | Round trip | Ensure that numbers converted to strings will have the same values when they are converted back into numbers |
| X x | Hexadecimal | Minimum hexadecimal (base 16) representation |

**Table 2-2** Format specifiers

You can use a format specifier with the `toString()` method to convert a number into a string that has the desired format. For example, you can use the *F* format specifier to insert a decimal point to a number that does not contain digits to the right of the decimal point, followed by the number of zeros indicated by the precision specifier. If no precision is supplied, two zeros are inserted. For example, the first `WriteLine()` statement in the following code produces 123.000:

```csharp
double someMoney = 123;
string moneyString;
moneyString = someMoney.toString("F");
WriteLine(moneyString);
moneyString = someMoney.toString("F3");
WriteLine(moneyString);
```
