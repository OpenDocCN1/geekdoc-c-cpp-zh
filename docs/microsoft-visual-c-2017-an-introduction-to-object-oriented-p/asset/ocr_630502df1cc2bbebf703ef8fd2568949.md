# Creating and Using Abstract Classes

Creating classes can become easier after you understand the concept of inheritance. When you create a child class, it inherits all the general attributes you need; you must create only the new, more specific attributes required by the child class. For example, a Painter and a Sculptor are more specific than an Artist. They inherit all the general attributes of Artists, but you must add the attributes that are specific to Painter and Sculptor.
