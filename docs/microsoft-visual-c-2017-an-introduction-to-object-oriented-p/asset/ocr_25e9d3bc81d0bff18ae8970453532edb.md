# Passing an Array to a Method

Instead of passing a single element to a method, you can pass an entire array. You indicate that a parameter must be an array by placing square brackets around the data type in the method's parameter list. When you pass an array to a method, changes you make to elements within the method are reflected in the original array that was sent to the method. Memory address is also known as **reference**. Arrays, like objects but unlike built-in types like double and int, are passed **by reference**. When a simple int is passed to a method, it is passed **by value**. However, the method receives a copy of the value at a new memory address. However, when an array is passed to a method, the method receives the actual memory address of the array and has access to the actual values in the array elements. You have already seen that methods can alter arrays passed to them. When you used the Sort() and Reverse() methods in Chapter 6, you saw that they changed their array parameter contents.
