# Adding Comments to a Program

Comments are nonexecuting statements that help to document a program. In the following steps, you add some comments to the program you just created.

+   1. If you prefer compiling programs from the command line, then open the Hello.cs file in your text editor. If you prefer compiling programs from Visual Studio, then open Visual Studio, click File, point to Open, click Project/Solution, browse for the correct folder, double-click the Hello folder, and double-click the Hello file.
