When you use a loop within a loop, you might think of the outer loop as the all-encompassing loop. When you describe the task at hand, you use the word **each** to refer to the inner loop. If you wanted to use balances for different interest rates each 10 years, you could appropriately initialize some constants as follows:

```
const double RATE1 = 0.03;
const double RATE2 = 0.07;
const double RATE_INCREASE = 0.01;
const int END_YEAR = 10;
```

Then you could use the following nested loops:

```
for(rate = RATE1; rate <= RATE2; rate += RATE_INCREASE)
  for(year = 1; year < END_YEAR; ++year)
    WriteLine(bankBal + bankBal * rate);
```

However, if you wanted to display balances for different years each interest rate, you would use the following:

```
for(year = 1; year <= END_YEAR; ++year)
  for(rate = RATE1; rate <= RATE2; rate += RATE_INCREASE)
    WriteLine(bankBal + bankBal * rate);
```

In both of cases, the same 50 values would be displayed—five different interest rates (from 0.03 to 0.07) for 10 years (1 through 10). However, in the first example, balances for each interest rate would be displayed **within** each rate category, and in the second example, each balance for each interest rate would be displayed **within** each year category. In other words, in the first example, the 10 amounts displayed would all use the first rate of 0.03 for 10 years, and in the second example, the first five amounts displayed would use interest values all in the first year.
