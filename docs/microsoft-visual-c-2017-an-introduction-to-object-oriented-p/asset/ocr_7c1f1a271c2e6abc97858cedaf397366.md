# GLOSSARY

explicitly—Purposefully. Contrast with implicitly.

flowchart—A tool that helps programmers plan a program's logic by writing program steps in diagram form, as a series of shapes connected by arrows.

exposes—Associates a FileStream with a file.

Extended Binary Coded Interchange Code (EBCDIC)—An eight-bit code that is used in IBM mainframe computers.

focus—The state of a GUI component when the user's attention is drawn to it. When a component has focus, its action can be executed by pressing the Enter key.

extended class—A derived class; a child class; subclass; a class that has inherited from a base class.

folders—Structures used to organize files for a storage device; directories.

extension methods—Static methods that act like instance methods.

for loop—A loop that contains the starting value for the loop control, the test that controls loop entry, and the expression that alters the loop variable, all in one statement.

# F

fault-tolerant—Describes applications that are designed so that they continue, possibly at a reduced level, when some part of the system fails.

form—A GUI interface for collecting, displaying, and delivering information.

field—In a class, an instance variable. A file or database, a character or group of characters that has some meaning.

formal parameter—A parameter within a method header that accepts a value.

format specifier—One of nine built-in format characters in a format string that defines the most used numeric types.

file pointer—A variable that holds the next byte of memory to be read from a file.

format string—A string of characters that controls the appearance of output.

finally block—A block of code that optionally follows a try block; the code within a finally try block executes any Exceptions or not.

fragile—Describes classes that depend on field names from parent classes are prone to errors; that, are easy to "break".

fires an event—An event occurs. Also see raises an event and triggers an event.

fully qualified—Describes a name that includes the class name as well as the identifier.

fixed-pitch float—A float in which each character occupies the same width.

# G

float—A data type that can hold a floating-point number with as many as seven significant digits of accuracy.

garbage—An unknown memory value.

get accessors—Methods in properties that allow retrieval of a field value by using a property name.

floating-point—Describes a number that contains decimal positions.
