# Creating a Form in the IDE

![](bbox=[0.285, 0.065, 0.685, 0.403])

**Figure 3-3** Displaying properties of Form1

You can scroll through a list of properties in the Properties window. For example, if you click a property, a brief description of it appears at the bottom of the Properties window. For example, Figure 3-3 displays a description of the Text property of Form1.

You can change the appearance, size, color, and window-features of a Form by setting its properties. The Form class contains approximately 100 properties; Table 3-1 lists a few of the Form features you can change. For example, setting the Text property allows you to specify the caption of the Form in the title bar, and setting the Size, BackColor, and ForeColor allows you to customize the. The two buttons at the bottom of the list allow you to organize properties by category or alphabetically. Not every property that can be used with Form appears in the Properties window in the Visual Studio IDE—only the most used properties are listed.

| Property Name | Description |
| --- | --- |
| AcceptButton | Gets or sets the button on the form that is clicked when the user presses the Enter key |
| BackColor | Gets or sets the background color of the Form |
| CancelButton | Gets or sets the button that is clicked when the user presses the Esc key |
| ForeColor | Gets or sets the foreground color of the Form |
| Name | Gets or sets the name of the Form |
| Size | Gets or sets the size of the Form |
| Text | Gets or sets the text associated with the control |
| Visible | Gets or sets a value indicating whether the control is visible |
