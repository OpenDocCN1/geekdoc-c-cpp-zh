However, if you wanted to change a Font later in a program—for example, after a user clicks a button—you might want to create your own instance of the Font class. System.Drawing.Font bigFont = new System.Drawing.Font("Courier New", 16.5F);

Notice that you use an F (or an f) following the Font size value constant when it contains a decimal to ensure that the constant will be recognized as a float and not a double. An alternative would be to instantiate a float constant or variable and use its name as an argument to the Font constructor.

In Chapter 2, you learned to use an f following a floating-point constant to indicate the float type. Recall that a numeric constant with a decimal point is a double by default.

this.label1.Font = bigFont;
