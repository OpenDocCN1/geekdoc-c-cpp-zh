Next, you will write a short program to demonstrate the use of escape sequences.

- 1. Open a new file, and name it DemoEscapeSequences.
- 2. Enter the following code. The three writeLine() statements demonstrate using escape sequences for tabs, a newline, and an alert.

```c
using static System.Console;
class DemoEscapeSequences
{
    static void Main()
    {
        WriteLine("This line\tcontains two\ttabs");
        WriteLine("This statement\ncontains a new line");
        WriteLine("This statement sounds an alert \a");
    }
}
```

# Using the string Data Type

In C#, you use the string data type to hold a series of characters. The value of a string is expressed within double quotation marks. For example, the following statement declares a string named firstName and assigns Jane to:

```csharp
string firstName = "Jane";
```

You can compare the value of one string to another using the == and != operators in the same ways that you compare numeric or character variables.     }
```csharp
}
```

In addition to the == comparison operator, you can use several prewritten methods to compare strings, including whether one is greater than the other. A string is considered equal to, greater than, or less than another lexically in the case of letter values alphabetically. That is, when you compare two strings, you compare each character from left to right. If each Unicode value is the same, then the strings are equal. If any corresponding character values are different, the string that has the greater Unicode value earlier in the string is considered greater.

The advantage of using the comparison methods is that the == operator is that they have standard names; when you use other C classes written by others, you can compare strings with any of the following methods:

- An Equals() method calls the format name1.Equals(name2); its value is true or false.
- A CompareTo() method calls the format name1.CompareTo(name2); and its value is zero when the compared strings are equal, a negative if the first string is less, and a positive if the second string (one in parentheses) is less.

In C#, a string is **immutable**. That is, when you assign a new value to it, if you write name "Amy" the first string of characters, Amy, still exists in memory, but the variable no longer refers to string address. Instead, name refers to a new address. Programmers might say that name now points to the new address. The situation is different from that when you assign a new value to a numeric variable, the value at the named address actually changes, replacing the original value.
