# # Creating Loops with the for Statement

The LoopingBal program in 5-7 contains an indefinite loop because the number of executions is not predetermined; each time the program executes, the user might continue a different number of times. You can use a while loop for either definite or indefinite loops. To avoid either type of while loop, you initialize a loop control variable, and as long as its test expression is true, execute the body of the while loop. To avoid an infinite loop, the body of the while loop must contain a statement that alters the loop control variable.

Because you need define loops (ones with a predefined number of iterations) so frequently when you write programs, C provides a shorthand way to create such loops. With a for loop, you can indicate the starting value for the loop variable, the test condition that controls loop entry, and the expression that alters the loop control variable, all in one convenient place.

You begin a for statement with the keyword followed by a set of parentheses. Within the parentheses are three sections separated by two semicolons. The three sections are used for:

+   1. Initializing the loop control variable
2. Testing the loop control variable
3. Updating the loop control variable

As with an if or a while statement, you can use a single statement as the body of the for loop or you can use a block of statements enclosed in curly braces. The while and for statements shown in Figure 5-10 produce the integers 1 through 10.

```
// Declare loop control variable and limit
int x;
const int LIMIT = 10;

// Using a while loop to display 1 through 10
x = 1;
while(x <= LIMIT)
{
    WriteLine(x);
    ++;
}

// Using a for loop to display 1 through 10
for(x = 1; x <= LIMIT; ++x)
    WriteLine(x);
```

**Figure 5-10** Displaying integers 1 through 10 while and for loops

The amount by which a loop variable increases or decreases on each cycle the loop is often called the step value. That's because in the BASIC programming language, and its descendant, the keyword STEP is actually used in loops.
