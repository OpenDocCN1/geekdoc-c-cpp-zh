## 事件处理

在 C# 中，事件是对程序中发生的情况的反应；当对象发生某些有趣的事情时，事件就会发生。当你创建一个类时，你精确决定了什么被认为是“有趣的”。例如，当你创建一个表单（Form）时，你可能决定某些操作是有趣的。
