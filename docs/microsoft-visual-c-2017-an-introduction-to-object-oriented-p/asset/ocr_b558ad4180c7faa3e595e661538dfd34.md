Creating an enumeration type provides you with several advantages. For example, the
OfWeek enumeration improves your programs in the following ways:

+   - If you did not create an enumerated type, you could create another type to represent days,
invalid behavior could be applied to the values. For example, if you use integers to
represent days, you could multiply or divide by days, which is not logical. Programmers
using enum makes the values type-safe. Type-safe describes a data type for which only
appropriate behaviors are allowed.

+   - The enum constants provide a form of self-documentation. Someone reading your program
might misinterpret 3 means as a day value, but there is less confusion when you use the
identifier WEDNESDAY.
