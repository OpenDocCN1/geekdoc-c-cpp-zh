# Using the BinarySearch() Method

A binary search is one where a sorted list of elements is split in half repeatedly as the search gets closer and closer to a match. Perhaps you have played a guessing game, trying to guess a number from 1 to 100. If you asked “Is it less than 50?” and continued to narrow your guesses upon hearing each subsequent answer, you have performed a binary search. In C#, the BinarySearch() method finds a requested value in a sorted array.
