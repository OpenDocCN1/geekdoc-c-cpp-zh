## Exercises

### Programming Exercises

The exercises in this section should look familiar to you. Each is similar to an exercise in Chapter 2, where you created solutions using console input and output.

- 1. Write a GUI program named InchesToCentimetersGUI that allows the user to input measurement in inches, click a Button, and output the value in centimeters. There are 2.54 centimeters in an inch.
- 2. Write a GUI program named ProjectedRisesGUI that allows a user to enter an employee's salary. Then display, with explanatory text, next year's salary, which reflects a 4 percent increase.
- 3. Write a program named MoveEstimatorGUI that prompts a user to input hours for a moving job and the number of miles involved in the move. After the user clicks a Button, displaying the moving fee which includes a base rate of $200 plus $15 per hour and $2 per mile.
- 4. Write a GUI program named EggsInteractiveGUI that allows a user to input the eggs produced in a month by each five chickens. Sum the eggs, then display total in dozens and eggs. For an example, 127 eggs is 10 dozen and 7 eggs.
- 5. Write a GUI program named MakeChangeGUI that calculates and displays the conversion of an entered number of dollars into currency denominations—twenties, tens, fives, and ones. For example, $113 is 5 twenties, 1 ten, 0 fives, and 3 ones.
- 6. Write a GUI program named TestsInteractiveGUI that allows a user to enter scores of five tests he has. Display the average of the test scores to two decimal places.
- 7. Create an enumeration named Month that holds values for the months of the year, starting with JANUARY equal to 1. (Recall that an enumeration must be placed within a class but outside of any method.) Write a GUI program named MonthGUI that prompts the user for a month integer. Convert the user's entry to Month value, and display it.
- 8. Pig Latin is a nonsense language. To create a word in pig Latin, you remove the first letter and then add ay at the end of the word. For example, dog becomes ogday, and cat becomes attcay. Write a GUI program named PigLatinGUI that allows the user to enter words and display the pig latin version.

### Case Problems

- 1. In Chapter 2, you created a program for the Greenville Idol competition that prompts a user for the number of contestants entered in last year's competition and in this year's competition. The program displays the revenue expected for this year's competition if each contestant pays a $25 entrance fee. The application also displays a statement that indicates whether this year's competition has more contestants than last year's. Now, create an interactive GUI program named GreenvilleGUI that performs all the tasks.
- 2. In Chapter 2, you created a program for Marshall's Murals that prompts a user for the number of interior and exterior murals scheduled for next month. The application should display, by type, the number of murals ordered, the cost ($500 for interior and $750 for exterior), the total revenue, and whether more interior murals are scheduled. Now create an interactive GUI program named MarshallsGUI that performs all the tasks.
