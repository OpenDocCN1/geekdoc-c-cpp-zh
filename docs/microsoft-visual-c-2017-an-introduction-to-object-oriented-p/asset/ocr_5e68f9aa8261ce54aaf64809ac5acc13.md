# Adding a MenuStrip to a Form

Many programs you use in a Windows environment contain a menu strip, which is a horizontal list of general options that appears under the title bar of a Form or Window. When you click an item in a menu strip, you initiate an action. More frequently, you see a list box that contains more specific options. Each of these might initiate an action or lead to another for. For example, the Visual Studio IDE contains a horizontal menu strip that begins with the options File, Edit, and View. You probably have used word-processing, spreadsheet, and game programs with similar menus.

You can add a MenuStrip object to any Form you create. Using the Visual Studio IDE, you can add a MenuStrip to a Form by dragging it from the Toolbox onto the Form. This creates a menu bar horizontally across the top of the Form, just below the title bar. The strip extends across the width of the Form and contains a Type Here text box. When you click the text box, you can enter a menu item. Each time you add a menu, boxes are created so you can see where your next options will go, as shown in Figure 12-34.

> If you do not see MenuStrip in your Toolbox, click the Menu & Toolbars group to expose it. You can click the MenuStrip icon at the bottom of the screen view to change the properties for the MenuStrip. For example, you might want to change the Font or BackColor for the MenuStrip.

Earlier in this chapter, you learned how to create an access key for a Button. Similarly, if you create each menu item with an ampersand (&) in front of a unique letter, the letter becomes an access key, and the user can press Alt and the letter to activate the menu. For example, if two colors were Green and Gray, you might want to type &Green and G&Gray so you could type Alt+G to select Green and Alt+R to select Gray.
