# GLOSSARY

delimiter—A character used to specify the boundary between characters in text files.

derived class—A subclass; a class that has inherited from a base class.

deserialization—The process of converting streams of bytes into objects.

design time—The period of time during which a programmer designs a program’s interface and writes the code.

destructor—A method that contains the actions performed when an instance of a class is destroyed.

Developer Command Prompt—A special version of the command prompt for which specific settings have been enabled so you can easily compile and run C# programs.

digit separators—Symbols used to separate the digits in a number for readability; in C# the underscore (_) is the digit separator.

directories—Structures used to organize files on a storage device; folders

do loop—A type of post; a loop that is tested at the bottom of the loop after one repetition has occurred.

double—A data type that can hold a floating-point number with 15 or 16 significant digits of accuracy.

dual-alternative decisions—Decisions that have two possible outcomes.

enhanced for loop—A version of the loop that cycles through an array without specifying the starting and ending points for the loop control variable.

enumeration—A list in which names are substituted for numeric values.

Equals()—A method that determines equivalency. In the String class, it is the method that determines if two strings have the same value.

escape sequence—A single character composed of two symbols beginning with a backslash that represents a nonprinting character as a tab.

event—An object generated when a user interacts with a GUI object, causing the program to perform a task.

event-driven programs—Programs that contain code that causes an event such as a click to perform a task.

event handler—A method that performs a task in response to an event; an event receiver.

event receiver—A method that performs a task in response to an event; an event handler.

event sender—The object, which has a control, that generates an event.

event wiring—The act of connecting an event to its resulting actions.

exception—An error condition or unexpected behavior in an executing program.

exception handling—The set of object-oriented techniques used to manage unexpected errors.

explicit cast—Purposefully assigns a value to a different data type; it places the desired result in parentheses followed by the variable or constant to be.

# E

empty body—A block that has no statements in it.

encapsulation—The technique of packaging an object’s attributes and methods into a cohesive unit that can be used as an undivided entity.
