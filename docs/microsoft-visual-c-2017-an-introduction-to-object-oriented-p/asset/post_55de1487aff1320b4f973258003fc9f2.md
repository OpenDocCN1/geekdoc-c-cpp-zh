
getter—Another term for a class property’s get accessor.

gigabyte—Approximately one billion bytes.

governing type—In a switch statement, the type that is established by the switch expression.

graphical control elements—The components through which user interacts with a GUI program.

graphical user interface (GUI)—An interface that employs graphical controls the user manipulates.

group box—A GUI element that can be used to group controls on a form, is similar to a panel but it can contain a caption and does not have a scroll bar.

## H

hardware—The physical devices associated with a computer.

has-relationship—The relationship created using composition, so called because one class has “an” instance of another.

hash code—A number that should identify an object.

hexadecimal numbering system—A mathematical system that uses 16 symbols to represent numbers; base 16.

hide—To override a parent class member in a child class, making the parent class member invisible.

high-level programming language—A language that uses a vocabulary of reasonable terms as read, write, or add instead of referencing the sequence of on/off switches that performs these tasks.

## I

identifier—The name of a program component such as a variable, class, or method.

if statement—A program statement to make a single-alternative decision.

if-else statement—A statement that performs a dual-alternative decision.

immutable—Unchangeable.

implementation hiding—The technique of keeping the details of a method’s operations hidden.

implicit cast—The automatic transformation that occurs when a value is assigned to a type with higher precedence.

implicit conversion—The conversion that occurs when a value is automatically changed to another upon.

implicit parameter—An undeclared parameter that gets its value automatically.

implicit reference conversion—The type of conversion that occurs when a derived class object is assigned to its ancestor’s data type.

implicitly—Automatically. Contrast with explicitly.

incrementing—The act of increasing the value of a variable, often by 1.

indefinite loop—A loop in which the number of iterations is not predetermined.

index—An integer contained within brackets that indicates the position of one of an array’s elements. Also see subscript.

infinite loop—A loop that (theoretically) never ends.

## GLOSSARY

information hiding—A feature found in all object-oriented languages, in which a class's data items are changed or manipulated by their own methods.

inheritance—The ability to create a class so as to create a more specific class that contains all the attributes and methods of a more general class; the extended class contains new attributes or methods as well.

IntelliSense—Microsoft's name for the set of features designed to minimize program development time in the IDE.

interactive program—A program that allows input user.

initialization—An assignment made when a variable is declared.

interface—A collection of abstract methods (and perhaps other members) that can be used by any class as long as the class provides a definition to override the interface's abstract definitions.

initializer list—The list of values provided for an array,

intermediate language (IL)—The language into which code statements are compiled.

inner loop—The loop in a pair of nested loops that is entirely contained within another loop.

internal—A class access modifier means access is limited to the assembly to which the class belongs.

instance methods—Methods that are used with object instances.

internal access—Level of method accessibility limits access to the containing program.

instance of a class—An object; a tangible example of a class.

instance variables—Data components of a class that exist separately for each instance. Also called fields.

intrinsic types—Basic, built-in data types; C# provides 15 intrinsic types.

instantiate—To create an object.

invoke—To call a method.

instantiation—A created object.

invoking object—The object referenced by this is in an instance.

int—An integer data type that can hold a signed numeric value in four bytes.

invoking the event—Calling an event method.

integer—A whole without a fractional part.

iteration—One execution of any loop.

integral data types—Data that store numbers; the nine integral types are byte, sbyte, short, ushort, int, uint, long, uintlong, and char.

iteration variable—A temporary variable that holds each array value in a foreach statement.

Integrated Development Environment (IDE)—A program in which programmers select options from menus or by clicking buttons.

## J

jagged array—An array of arrays where each inner array can have a different length.

just in time (JIT)—A compiler that translates intermediate code into machine code.

list box—A GUI element that displays a list of items the user can select.

literal constant—A value that is entered exactly as is.

literal string—A sequence of characters used for text.

## K

keywords—Predefined and reserved identifiers that have special meaning.

kilobyte—Approximately one thousand bytes.

## L

label—A GUI control that displays text.

loop body—All the instructions contained within a pair of braces { }.

loop control—A variable that determines when execution.

loop fusion—The technique of combining two loops into one.

length—A field that contains the number of elements in an array.

lower camel casing—A style of creating identifiers where the first letter is not capitalized, but each new word is. Contrast with Pascal casing.

Pascal casing—A style of identifiers where every word is capitalized.

lexically—Alphabetically.

line comments—Comments that start with two slashes ( // ) and continue to the end of a line. Compare with block comments.

## M

machine language—The most basic circuitry-level language.

magic number—A hard-coded number.

mandatory parameters—Method parameters that are required in every call.

link label—A GUI control with text that links the user to others.

megabyte—Approximately one million bytes.

multiple inheritance—The ability to inherit from more than one class.

menu bar—In the Studio IDE, the list of choices that run horizontally across the top.

## N

method strip—A horizontal list of general options that appears under the title bar.

named argument—A method argument that is preceded by the name of the method's parameter to which will be assigned.

method—An encapsulated series of statements that carry out a task.

named constant—An identifier whose contents change not.

method body—All the instructions contained within a pair of braces { }.

namespace—A scheme that provides a way to group similar classes.

method declaration—A method header that includes a return type, identifier, and an optional parameter list.

nested if—A statement in which one decision structure is contained within another.

nested method calls—Method calls placed inside other methods.

method definition—A method header that includes a return type, identifier, and an optional parameter list.

nibble—Four bits; half a byte.

method header—The first line of a method, which includes the method name and information about what will pass into and returned from a method.

node—In the Visual Studio IDE, a box appears on a vertical tree to the left of a section of code that can be expanded or collapsed.

method's type—A method's return type.

non-application classes—Classes that do not contain a Main() method and therefore are not runtime classes; provide support for other classes.

mission critical—Describes any process that is crucial to an organization.

nonstatic—Describes a method that requires an object reference.

modal window—A secondary window that takes control from a primary window and that a user must deal with before proceeding.

volatile—The type of storage that is permanent; is not lost when a computer loses power.

multidimensional arrays—Arrays that require multiple subscripts to access the array elements.

NOT operator (!)—An operator that negates the result of any Boolean expression.

multifile assembly—A group of files containing methods that work together to create an application.

## O

object—A concrete entity that has attributes and behaviors; an object is an instance of a class.
