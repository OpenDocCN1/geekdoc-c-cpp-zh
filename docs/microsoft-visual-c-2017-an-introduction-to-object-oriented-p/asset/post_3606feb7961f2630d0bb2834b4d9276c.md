# Searching a Sequential Text File

When we read data from a sequential file, as in the SequentialFile program in Figure 14-14, the program starts at the beginning of the file and reads each record in turn until all the records have been read. Subsequent records are read in order because a file's position pointer holds the byte number of the next byte to be read. For example, if each record in a file is 32 bytes long, then the position pointer holds 0, 32, 64, and so on sequence during the execution of the file.

Sometimes it is necessary to process the file multiple times from the beginning of a program's execution. For example, suppose you want to prompt a user for a minimum salary and then search through a file for Employees who make at least that. You can compare the user's entered minimum with each salary in the file and list those employees who meet the requirement. However, after one is listed, the file pointer is the end of the file, and no more records can be read. To reread the file, you could close it and reopen it, which requires unnecessary overhead. Instead, you can reposition the file pointer using the Seek() method and the SeekOrigin enumeration. For example, the following statements reposition the pointer of a file named inFile to 0 bytes away from the beginning of the file.

```csharp
inFile.Seek(0, SeekOrigin.Begin);
```

Table 14-6 lists the values in the SeekOrigin enumeration that you can use.

| Member | Description |
| --- | --- |
| Begin | Specifies the beginning of a stream |
| Current | Specifies the current position of a stream |
| End | Specifies the end of a stream |

Figure 14-18 contains a program that repeatedly searches a file to produce lists of employees who meet a minimum salary requirement. The shaded portions of the program represent differences from the SequentialFile program in Figure 14-14. In this program, each time the user enters a minimum, the position pointer is set to the beginning of the file.

```csharp
using System;
using static System.Console;
using System.IO;

class FindEmployees
{
    const char DELIM = ',';
    class Employee
    {
        public int EmpNum;
        public string Name;
        public double Salary;
    }
    static void Main()
    {
        const int END = 999;
        const string FILENAME = "Employee.txt";
        FileStream inFile = new FileStream(FILENAME, FileMode.Open, FileAccess.Read);
        StreamReader reader = new StreamReader(inFile);
        string recordIn;
        double minSalary;

        Write("Enter minimum salary to find or " + END + " to quit: ");
        minSalary = double.Parse(ReadLine());
        inFile.Seek(0, SeekOrigin.Begin);

        WriteLine("Displaying all names:");
        int count = 1;
        while ((recordIn = reader.ReadLine()) != null)
        {
            string[] fields = recordIn.Split(DELIM);
            Employee emp = new Employee();
            emp.EmpNum = int.Parse(fields[0]);
            emp.Name = fields[1];
            emp.Salary = double.Parse(fields[2]);

            if (emp.Salary >= minSalary)
            {
                WriteLine("{0,-5}{1,-12}{2,-8}", count, emp.Name, emp.Salary);
            }
            count++;
        }
        reader.Close();
        inFile.Close();
    }
}
```
