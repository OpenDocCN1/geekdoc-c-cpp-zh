Complete the heading for the table using a writeLine() statement that advances the cursor to the next line of and a writeLine() statement that displays a dashed line.


> Recall that within a loop, the expression before the first semicolon executes, the middle expression is tested, the loop body executes, and then executes to the right of the second semicolon. In other words, TIPSTEP is not added until tipRate is displayed on each cycle through the loop.

As an alternative to typing 40 dashes in the writeLine() statement, you could use the loop to display a single 40 dashes. When the 40 dashes were completed, you could use writeLine() to advance to a new line.

```
const int NUM_DASHES = 40;
for(int x = 0; x < NUM_DASHES; ++x)
  Write("-");
  WriteLine();
```
