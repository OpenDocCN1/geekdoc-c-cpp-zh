2. Next, create some constants. Every tip from 10 percent through 25 percent will be computed in 5 percent intervals, so declare those values as LOWRATE, MAXRATE, and TIPSTEP. Tips will be calculated on dinner prices up to $100.00 in $10.00 intervals, so declare these constants, too.

```cpp
const double LOWRATE = 0.10;
const double MAXRATE = 0.25;
const double TIPSTEP = 0.05;
const double MAXDINNER = 100.00;
const double DINNERSTEP = 10.00;
```

3. To create a heading for the table, display Price. For alignment, insert three spaces after the quotes and before the $ (Price:). On the same line, use a loop that displays every tip rate from LOWRATE through increments of TIPSTEP. In other words, the tip rates are 0.10, 0.20, and 0.25. Complete the heading for the table using a writeLine() statement that advances the cursor to the next line and a writeLine() statement that displays a dashed line.

```cpp
Write("Price:");
for(tipRate = LOWRATE; tipRate <= MAXRATE; tipRate += TIPSTEP)
  Write("{0, 8}", tipRate.ToString("C"));
  WriteLine();
WriteLine("--------------------------------");
```

> Recall that within a loop, the expression before the first semicolon executes, the middle expression is tested, the loop body executes, and then it executes to the right of the second semicolon. In other words, TIPSTEP is not added until tipRate is displayed on each cycle through the loop.

As an alternative to typing 40 dashes in the writeLine() statement, you could use the loop to display a single 40 dashes. When the 40 dashes were completed, you could use writeLine() to advance to a new line.

```cpp
const int NUM_DASHES = 40;
for(int x = 0; x < NUM_DASHES; ++x)
  Write("-");
WriteLine();
```

4. Set tipRate to 0.10. You must reset the rate because after the last loop, the rate will have been increased to greater than 0.25.

5. Create a nested loop that continues while the dinnerPrice remains 100.00 (MAXDINNER) or less. Each iteration of this loop displays one row of the table. Within this loop, display the dinnerPrice, to display four tips while the tipRate varies from 0.10 through 0.25. At the end of the loop, (continued) increase the dinnerPrice by 10.00, reset the tipRate to 0.10 so it is ready for the next row, and write a new line to advance the cursor.

```cpp
while(dinnerPrice <= MAXDINNER)
{
    Write("{0, 8}", dinnerPrice.ToString("C"));
    while(tipRate <= MAXRATE)
    {
        tip = dinnerPrice * tipRate;
        Write("{0, 8}", tip.ToString("F"));
        tipRate += TIPSTEP;
    }
    dinnerPrice += DINNERSTEP;
    tipRate = LOWRATE;
    WriteLine();
}
```

Recall that the {0, 8} format string in the write() statements displays the first argument in fields that are eight characters wide. You learned about format strings in Chapter 2.
