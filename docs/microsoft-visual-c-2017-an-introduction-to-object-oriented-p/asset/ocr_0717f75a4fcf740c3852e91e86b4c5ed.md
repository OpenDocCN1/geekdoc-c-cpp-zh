8. When you create a C# program using an editor such as Notepad and compile it with the csc command, only two files are created—Hello.cs and Hello.exe. When you create a C# program using the Visual Studio editor, many additional files are created. You can view their filenames from the command prompt visually:

+   - At the command prompt, dir to view a directory of the files stored in the folder where you saved the project (for example, your Chapter01 folder). Within the folder, a new folder Hello has been created. Type the command cd Hello to change the current path to include this new folder, type dir again. You see another folder named Hello. Type cd Hello again, and dir again. You should see several folders and files (Depending on the version of Visual Studio you use, your folder configuration might be slightly different.)

+   - Use File Explorer to view the contents of the Hello folders within the Chapter01 folder.

Regardless of the technique you to examine the folders, you will find that the innermost Hello folder contains a bin folder, an obj folder, a Properties folder, and additional files. If you explore further, you will find that the bin folder contains a Debug folder, which includes several additional files. Using the Visual Studio editor to compile your programs creates a significant amount of overhead. These additional files become important as you create C# projects.

If you followed the earlier instructions when compiling a program from the command line, you will see the same folder when using the IDE, you will see the additional Hello.cs and Hello.exe files in your folder. These files will have an earlier time stamp than the files you created. If you were to execute a new program within Visual Studio without saving and executing it from the command line first, you would not see these two additional files.
