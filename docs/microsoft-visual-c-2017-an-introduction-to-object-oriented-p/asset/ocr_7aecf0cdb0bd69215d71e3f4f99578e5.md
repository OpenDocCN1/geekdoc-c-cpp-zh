# Compiling and Executing a Program Using the Visual Studio IDE

Next, you use the C# compiler environment to compile and execute the same Hello program you ran from the command line.

+   1. Open **Visual Studio**. If there is a shortcut icon on your desktop, you can double-click it. Alternatively, in Windows 10, you can start to type **Visual Studio** in the Cortana “Ask me anything” search box, and then select. When you see the Start Page, click **File** on the main menu, then click **Project**.

+   2. In the New Project window, click **Visual C#**, and then click **Console App**. By default, the name for the project is set to **ConsoleApp1**. (If you keep the name ConsoleApp1, the next project will be **ConsoleApp2** by default).

Change the project name to **Hello**, and select the path where you want save the project (see Figure 1-16). Click **OK**. Visual C# creates a new folder for your project name after the project title.
