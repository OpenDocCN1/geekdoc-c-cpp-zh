## Using the Conditional Operator

The conditional operator is used as an abbreviated version of the if-else statement; it requires two expressions expressed with a question mark and colon. Like the switch structure, using the conditional operator is never required. However, it is a convenient shortcut, especially when you want to use the result immediately as an expression. The syntax of the conditional operator is:

```
testExpression = trueResult : falseResult;
```

> Unary operators use one operand; binary operators use two. The conditional operator ?: is ternary; it requires three arguments: a test expression and false results. The conditional operator is the only ternary operator in C.

The first expression, testExpression, is evaluated as true or false. If it is true, then the entire conditional expression takes the value of the expression before the colon (trueResult). If the value of the testExpression is false, then the entire expression takes the value of the expression following the colon (falseResult). For example, consider the following statement:

```
biggerNum = (a > b) ? a : b;
```

This statement evaluates a > b. If a is greater than b, then the entire conditional expression takes the value of a, which is assigned to biggerNum. If a is not greater than b, then the entire expression assigns the value of b, and is assigned to biggerNum.

The conditional operator is most applied when you want to use the result as an expression without writing an intermediate variable. For example, a conditional operator can be used directly in an output statement using one of the following:

```
WriteLine((testScore >= 60) ? "Pass" : "Fail");
WriteLine($"{testScore > 60} ? "Pass" : "Fail");
```

## Using the NOT Operator

You use the NOT Operator, which is an exclamation point (!), to negate the result of Boolean expression. Any expression that becomes true becomes false when preceded by the operator, and any false expression preceded by the operator becomes true.

> In Chapter 2 you learned that an exclamation point and equal sign form the "not equal to" operator.
The != is a binary operator; it compares two operands. The ! is a unary operator; it reverses the meaning of a single Boolean expression.

For example, suppose that a car insurance premium is $200 if the driver is younger than age 26 and $125 if the driver is 26 or older. Each of the following statements (which have been placed on single lines for clarity) correctly assigns the premium values:

```
if(age < 26) premium = 200; else premium = 125;
if(!(age < 26)) premium = 125; else premium = 200;
if(age > 26) premium = 125; else premium = 200;
if(!(age >= 26)) premium = 200; else premium = 125;
```

## Avoiding Common Errors When Making Decisions

New programmers frequently make errors when they first learn to make decisions. As you have seen, the most frequent errors include the following:

- Using the assignment operator (=) instead of the comparison operator (==) testing for equality
- Inserting a semicolon after the Boolean expression in an if statement instead of using it after the entire statement is completed
- Failing to block a set of statements with curly braces when several statements depend on the if or the else statement
- Failing to include a complete Boolean expression on each side of && or || operator in an if statement

In this section, you will learn to avoid other types of errors with if statements. Programmers often make errors at the following times:

- When performing a range check incorrectly or inefficiently
- When using the wrong operator
- When using ! incorrectly

## Performing Accurate and Efficient Range Checks

When new programmers must make a range check, they often introduce incorrect or inefficient code into their programs. A **range check** is a series of if statements that determine whether a value falls within a specified range. Consider a situation where salespeople receive one of three possible commission rates based on an integer saleAmount. For example, a sale totaling $1000 or more gives the salesperson an 8 percent commission, a sale totaling $500 through $999 6 percent of the sale amount, and any sale $499 or less earns 5 percent. Using separate if statements to test single Boolean expressions might result in incorrect commission assignments. For example the following code:

```
if(saleAmount >= 1000)
    commissionRate = 0.08;
if(saleAmount >= 500)
    commissionRate = 0.06;
if(saleAmount < 499)
    commissionRate = 0.05;
```

> Don't Do It
Although it was not the programmer's intention, both of the first two if st are true for any saleAmount greater or equal to 1000.

Using this code, if saleAmount is $5000, the first if statement executes. The Boolean expression (saleAmount >= 1000) evaluates to `true`, and 0.08 is correctly assigned to `commissionRate`. However, the next expression, (saleAmount >= 500), also evaluates as `true`, so the `commissionRate` is incorrectly reset to 0.06.
