- Write an application named SumFiveInts that allows the user to enter five integers and displays their sum.

- Write an application named EnterUppercaseLetters that asks the user to type an uppercase letter from the keyboard. If the character entered is an uppercase letter, display OK; if it is not an uppercase letter, display an error message. The program continues until the user enters an exclamation point.

- Write an application named DailyTemps that continuously prompts a user for a series of high temperatures until the user enters a sentinel value. Valid temperatures range from -20 through 130 Fahrenheit. When the user enters a valid temperature, add it to a total; when the user enters an invalid temperature, display an error message. Before the program ends, display the number of temperatures entered and the average temperature.

- Daniel, Edward, and Francis are three salespeople at Holiday Homes. Write an application named HomeSales that prompts the user for a salesperson initial (D, E, or F). Keep a running total of the amounts sold by each salesperson. The user types Z or x for an initial salesperson's total, a grand total for all sales, and the name of the salesperson with the highest total.

- Write an application named DisplayMultiTable that displays a table of the products of every combination of two integers from 1 through 10.

- Write an application named MultiplicationTable that prompts the user for an integer value, for example 7. Then display the product of every integer from 1 through 10 when multiplied by the entered value. The first three lines of the table might read 1 × 7 = 7, 2 × 7 = 14, and 3 × 7 = 21.

- Write an application named OddNums that displays all the odd numbers from 1 through 99.

- Write an application named Sum200 that sums the integers from 1 through 200. Display the running total when the program is halfway complete (after the first 100 numbers), and at the end.

14. In Chapter 4, you created a program that generates a random number, allows a user to guess it, and displays a message indicating whether the guess is too low, high, or correct. Now, create a modified program called GuessingGame2 in which the user guesses the number and the program tracks the number of attempts. When the user guesses correctly, display the total number of attempts. Use the Random class to generate the number.

```
Random rand = new Random();
int target = rand.Next(1, 101);
int guess = 0;
int attempts = 0;
while (guess != target)
{
    Write("Enter a guess between 1-100: ");
    guess = int.Parse(Console.ReadLine());
    attempts++;
    if (guess < target)
        Write("Too low!\n");
    else if (guess > target)
        Write("Too high!\n");
    else
        Write($"Correct! It took you {attempts} attempts.\n");
```

## Debugging Exercises

The following code segments contain errors. Find and fix them.

1. The following code is intended to calculate the average of an array of integers.
```c
int[] numbers = { 10, 20, 30, 40, 50 };
int sum = 0;
for (int i = 0; i <= numbers.Length; i++)
{
    sum += numbers[i];
}
double average = sum / numbers.Length;
Console.WriteLine("The average is {0}", average);
```

```csharp
string[] fruits = { "Apple", "Banana", "Cherry" };
for (int i = 0; i < fruits.Length; i++)

    Console.WriteLine(fruits[]);
}
```

3. The following code is intended to find the maximum value in an integer array.
```csharp
int[] values = { 5, 12, 7, 21, 3 };
int max = values[0];
for (int i = 1; i < values.Length; i++)
{
    if (values[i] > max)
    {
        max = values[i];
    }
}
Console.WriteLine("The maximum value is {0}", max);
```
