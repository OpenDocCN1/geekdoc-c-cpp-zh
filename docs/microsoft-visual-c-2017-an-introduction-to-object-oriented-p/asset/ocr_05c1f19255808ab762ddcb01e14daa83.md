# You Do It

Using Reference Parameters
You use reference parameters when you want a method to have access to the memory address of arguments in a calling method. For example, suppose that you have two values and you want to exchange them (or swap them), making each equal to the value of the other. Because you want to change two values, a method that accepts copies of arguments will not work—a method can return, at, only one value. Therefore, you can use reference parameters to provide your method with the actual addresses of the values you want to change.
