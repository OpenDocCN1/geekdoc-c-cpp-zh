

自文档化程序元素是指能够自我解释的元素。

枚举（Enumeration）是一组由标识符表示的常量。

类型安全（Type-safe）指的是仅允许适当行为的数据类型。

交互式程序是指允许用户输入的程序。

提示（Prompt）是要求用户数据的指令。

解析（Parse）项目是将将其拆分为各个组成部分。
