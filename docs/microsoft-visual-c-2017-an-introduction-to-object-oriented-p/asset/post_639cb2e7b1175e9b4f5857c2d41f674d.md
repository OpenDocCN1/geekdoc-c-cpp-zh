
# Key Terms

Graphical control elements, or, more simply, controls, are the components through which a user interacts with a GUI program.

Widgets are GUI controls.

A link label is a control with text that links a user to other resources as Web pages or files.

The default event for a Control is the one generated when you double-click the Control while designing it in the IDE and is the method you are most likely to alter when you use the Control, as well as the event that users most expect to generate when they encounter the Control in a working application.

A check box is a GUI that the user can click or deselect an option.

A radio button is an option in a group in which only one can be selected at a time—selecting any radio button automatically deselects the others.

An access key provides a shortcut to make a selection using the keyboard.

A picture box is a GUI element that can display graphics.

A list box is a GUI element that displays a list of items that the user can select by clicking.

A combo box is a GUI element that is a combination of a list box and an editing control that allows a user to select from the list or enter new text.

Snap lines appear in a design environment to help you align new Controls with others already in place.

A group box is a GUI element that contains other GUI elements; it is similar to a panel that does not have a scroll bar and can contain a caption.

A panel is a GUI element that contains other GUI elements; it is similar to a group box that does not have a caption and can contain a scroll bar.

A menu strip is a horizontal list of general options that appears under the title bar of a Form or Window.

A modal window is a secondary window that takes control from a primary window and that a user must deal with before proceeding.

# Programming Exercises

+ 1. Create a project named DaySelector. Its Form contains two ListBoxes—one contains at least four names, and the others contain at least four sizes. Let the first item in each be the default.

+ 2. Create a project named BreezyApartments that contains a Form for an rental service. Allow the user to choose number of bedrooms, number of baths. After user makes selections, display the monthly rent, which is calculated using a base price of $450, $550, or $700 per month for one-, two-, or three-bedroom apartment, respectively. $75 is added to the base price for more than one bath.

+ 3. Create a project named VacationPlanner for a tropical resort that offers all-inclusive packages. The project contains a Form that allows the user to choose one option at least in each of the categories—departure city, room type, and meal plan. Assign a different price to each selection, and display the total when the user clicks a Button.

+ 4. Create a project named CarDealer that contains a Form for an automobile dealer. Include options for at least three car models. After user makes selection, proceed to a new Form that contains information about the selected model.

+ 5. Create a project named AnnualBudget that includes a Form with LinkLabels One opens a spreadsheet for viewing, and the others visit your website. Include Labels on the Form to explain each link. You can create a spreadsheet with a few numbers that represent an annual budget, or you can use the AnnualBudget.xls file in Chapter 12.

+ 6. Create a project named TinasCustomTees that includes a Form for a company that produces T-shirts. Allow the user to select from at least four sizes, with a different price, and from at least three colors. Adjust the final displayed price as the user chooses sizes, and change the background color of the frame as the user chooses different sizes. Also, allow the user to select an order date from MonthCalendar and display the date, which is three days later.

+ 7. Create a project named MenuStripDemo2 that is based on the MenuStrip project in Chapter 12 of your downloadable student files. Add appropriate functionality to the currently programmed menu options (the two options in the Font menu and the three options in the Color menu).
