
# Providing Parameter Information

When you enter a method name in the Code Editor and type an opening parenthesis, IntelliSense displays a Parameter Info ToolTip that shows the method's parameter list. If the method is overloaded, multiple method signatures are displayed, and you can scroll through them.

# Adding using Statements

If you attempt to create an instance of .NET Framework class without a sufficiently qualified name, IntelliSense displays a Smart Tag at the unresolved identifier. When you click the Smart Tag, IntelliSense displays a list of using statements to resolve the identifier. When you select a statement from the list, IntelliSense adds the using directive to the top of your source code file, and you can continue to write code at your current location.

# Code Snippets

Code snippets are small units of commonly used C# source code that you can enter accurately and quickly with only a couple of keystrokes. To access the code snippet menu, right-click in the Code Editor, select Insert Snippet, and select C#. Then you can browse from the many available snippets, or you can create your own.

# Squiggles and Lightbulbs

Squiggles which are wavy underlines give you instant feedback about errors in your code type. A red squiggle identifies a syntax error, such as a missing semicolon or mismatched braces. You also see a lightbulb in the left margin if Visual Studio has a suggestion on how to fix the problem. In Figure C-2, a squiggle appears under a partially-completed statement.

# Readability Aids

The editor assigns different colors to various categories of identifiers in a C# source code file to make the code easier to read. For example, C# keywords are bright blue, classes are blue-green, and comments are green.

# Key Terms

**IntelliSense** is Microsoft's name for the set of features designed to minimize the time spent looking for help and to help you enter code more accurately and efficiently.

**Completion mode** is an IDE editing mode in which suggestions are automatically provided for your code based on context.

**Suggestion mode** is an IDE editing mode in which completion mode is turned off.

**Code snippets** are small units of commonly used C# source code that you can enter accurately and quickly with only a couple of keystrokes.

# Glossary

A

abstract class—A class from which concrete objects cannot be instantiated but can serve as a basis for inheritance. Contrast between outside classes can derive from its class.

abstract method—A method that contains no statements and must be implemented by classes that derive from it.

access key—A shortcut way to make a menu selection using the keyboard.

access specifier—A keyword that dictates which classes can use a method.

accessibility—Describes limitations on how a method can be used.

accessors—Methods in properties that specify how a class's fields are accessed. See get accessors and set accessors.

accumulated—Describes totals that are added into a final sum by processing individual records one at a time in a loop.

actual parameters—Arguments within a method call.

add and assign operator (+=)—An operator that assigns the operand on the right to the operand on the left and assigns the results to the operand on the left in one step.

alias—An alternative name or pseudonym.

ambiguous—Describes overloaded methods between which the compiler cannot distinguish.

American Standard Code for Information Interchange (ASCII)—An eight-bit code that represents characters.

ancestors—All the superclasses from which a subclass is derived.

AND operator—An operator that determines whether two expressions are true; it is written using ampersands (&). Also called the conditional AND operator. Contrast with Boolean logic operator.

applicable methods—The collection of potential methods that could be used by a method call.

application classes—Classes that contain a Main() method and are executable programs.

application software—Programs that allow users to complete tasks, in contrast with system software that the computer needs to complete tasks.

backing field—A field that has a property coded for it.

argument—An expression passed to a method.

base 2 numbers—Binary system numbers.

arithmetic operators—Used to perform arithmetic; they include +, *, /, and %.

base 10 numbers—Decimal system numbers.

array—A list of data items that all have the same data type and the same name, but are distinguished from each other by a subscript or index.

base 16 system—A mathematical system that uses 16 symbols to represent numbers; hexadecimal.

array element—One object in an array.

base class—A class that is used as a basis for inheritance.

assembly—A group of code modules compiled together to create an executable program.

behaviors of an object—The methods associated with an object.

bestness rules—Rules that determine the best overloaded method to execute based on the arguments in a method call.

assignment—A statement that provides a variable with a value.

binary files—Files that can store any of the 256 combinations of bits in any byte instead of just those that form readable text.

assignment operator—The equal sign (=); any value to the right of the assignment operator is assigned to, or taken by, the variable or constant to the left.

binary numbering system—Numbering system that uses two digits, 0 and 1, arranged in columns to represent numbers.

associativity—Specifies the order in which a sequence of operations with the same precedence are evaluated.

binary operators—Operators that use two operands: one value to the left of the operator and another value to the right of it.

binary search—An algorithm that finds an item in a sorted list by splitting until closer to a match.

at runtime—Actions that occur during execution.

attributes of an object—The characteristics of an object.

bit—A binary digit.

auto-implemented property—A property in which the code is created automatically.

automatic properties—Auto-implemented properties.

bitwise operators—Operators that are used to manipulate individual bits.

black box—Any device that can be used without knowing it works.

# GLOSSARY

block—A collection of one or more statements contained within a pair of curly braces.

call stack—The memory location where the computer stores the list of locations to which the system must return after calls.

block comments—Comments that start with a forward slash and an asterisk ( / ) and end with an asterisk and a forward slash ( * ). Block comments can appear on a line by themselves, on a line before executable code, or after as many lines as needed. Compare with line comments.

called—Describes a method that has been invoked.

called method—A method that has been invoked by another method.

calling method—A method that calls another method.

camel casing—A style of creating identifiers in which the first letter is not capitalized, but each new word is. Contrast with Pascal casing.

bool—A type that holds a Boolean value.

case label—Identifies a course of action in a switch statement.

Boolean logical operator—An operator that determines whether two expressions are true; or is written using a single ampersand (& but unlike the conditional OR operator, it does not use short-circuit evaluation.

catch block—A block of code that can catch one type of Exception.

Boolean inclusive OR operator—An operator that determines whether at least one of conditions is true; it is written using a single pipe (| but unlike the conditional OR operator, it does not use short-circuit evaluation.

char—An integer data type that can store a character such as 'A', '4', or '$'; char values are written between single quotes.

character—Any one of the letters, numbers, or other special symbols (such as punctuation marks) that comprise data.

Boolean variable—A variable that can hold only one of two values: true or false.

character set—The group of all the characters used to represent data on a particular computer.

bugs—Program errors.

check box—A GUI widget that a user can click to select or deselect an option.

byte—An integral data type that can hold an unsigned numeric value from 0 through 255.

child class—A derived class; subclass; a class that has inherited from a base class.

class client—A program or class that instances objects of other rewritten class. Also called a class user.
