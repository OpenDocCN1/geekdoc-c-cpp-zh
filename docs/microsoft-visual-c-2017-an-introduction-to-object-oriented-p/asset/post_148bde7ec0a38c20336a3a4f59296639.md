# # Preface

Microsoft Visual C# 2017, Seventh Edition provides the beginning programmer with a guide to developing programs in C#. C# is a language developed by the Microsoft Corporation as part of the .NET Framework and Visual Studio platform. The .NET Framework contains a wealth of libraries for developing applications for the Windows family.

With C#, you can build small, reusable components that are well-suited to Web-based programming. Although similar to Java and C++, many features of C# make it easier to learn and ideal for the beginning programmer. You can program in C# using a simple text editor and you can manipulate program components using Visual Studio's sophisticated Development Environment. This textbook assumes you have little or no programming experience. The writing is nontechnical and emphasizes good programming practices. The examples are examples; they do not assume mathematical background beyond high school math.

# # Organization and Coverage

Microsoft Visual C# 2017 presents C# programming concepts, enforcing good style, logical thinking, and the object-oriented paradigm. Chapter 1 introduces you to the language by letting you create C# programs using both the simple command line and the Visual Studio environment. Chapter 2 you learn about data and how to input, store, and output data in C#. Chapter 3 provides a quick to GUI applications. You can take two approaches:

- You can cover Chapter 3 and learn about GUI objects so that you can create more interesting applications in the subsequent chapters on decision making, looping, and array manipulation. These subsequent chapters confines GUI examples to the end of the chapters, so you can postpone GUI manipulation if you want.
- You can skip Chapter 3 until you have learned the fundamentals of decision making, looping, and array manipulation, and you study object-oriented concepts such as classes, objects, polymorphism, inheritance, and exception handling. Then, after Chapter 11, you can return to Chapter 3 and use the built-in GUI component classes with a deeper understanding of how they work.
