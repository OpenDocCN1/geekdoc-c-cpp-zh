- To gain an understanding of the types of statements created by the IDE.
- To lose any intimidation you might have about the code that you is generated. You will recognize many of the C# statements from what you have already learned in this book.

- 1. In the Solution Explorer at the right side of the screen, double-click Form1.Designer.cs. Scroll down if necessary until you see the expandable box that contains Windows Form designer generated code, and expand it. If you can see a few statements, you can drag the bottom and side borders of the code window to expose more of the code, or you can scroll to see all of it. You should be able to view statements that assign values to the properties of the components that you dragged into the Form, similar to the statements shown in Figure 12-12. The numbers used in some of your statements will vary from those seen in Figure 12-12 depending on the exact placement of your Labels.
