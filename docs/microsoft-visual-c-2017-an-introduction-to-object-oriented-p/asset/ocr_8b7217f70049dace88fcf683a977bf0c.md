# CHAPTER 3 Using GUI Objects and the Visual Studio IDE

+   - Console applications look dull in comparison to GUIs, but they can be developed more quickly because you do not spend much time setting up objects for a user to manipulate. When you are learning programming concepts such as the ones you will read about the next two chapters (decision making and looping), you might prefer to keep the interface simple so that you can concentrate on the new logical constructs being presented.

In short, it doesn't matter which interface you use to develop programs while learning the intricacies of the C# programming language. In the following "You Do It" section, you will develop an application that is similar to the one you developed in Chapter 1. In the programming exercises at the end of this chapter, you will develop programs that are identical in purpose to programs written using the console in the chapter called "Using Data." Throughout the next chapters, many concepts will be illustrated in console applications because the programs are shorter and development is simpler. However, you will occasionally see the same concept illustrated in a program that uses a GUI interface, to remind you the program logic is same no matter which interface is used. After you complete the chapters "Using Classes and Objects," "Using Controls," and "Handling Events," you will be able to write even more sophisticated GUI applications.

When writing your own programs, you will use the interface you prefer or one that your instructor or boss requires. If time permits, you might even want to develop programs both ways in future exercises.
