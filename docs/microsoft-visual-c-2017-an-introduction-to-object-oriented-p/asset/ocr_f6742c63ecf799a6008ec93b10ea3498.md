# Accessing Array Elements

When you declare an array of 5 integers, such as the following, you often want to perform the same operation on each array element:
int[] myScores = {100, 76, 88, 100, 90};

To increase each array element by 3, for example, you can write the following statements:
myScores[0] += 3;
myScores[1] += 3;
myScores[2] += 3;
myScores[3] += 3;
myScores[4] += 3;
