Setting the Dock property attaches a Control to the side of a container so that the Control stretches when the container's size is adjusted. A Form has a MinimumSize property and a MaximumSize property. Each has two—Width and Height. If you set these properties, the user cannot make the Form smaller or larger than you have specified. If you do not want the user to adjust a Form's size at all, set the MinimumSize and MaximumSize properties to be equal, in whole or in part. WCN 02-200-202
