# Creating a Composed Delegate

When you compose delegates, you can invoke multiple method calls using a single statement. In the next steps, you create a composed delegate to demonstrate how composition works.

+   - Open the DiscountDelegateDemo file, and immediately save it as DiscountDelegateDemo.
- Within the Main() method, add a third DiscountDelegate object to the statement that declares the two existing versions, as follows:
DiscountHandler firstDel, secondDel, thirdDel;
- After the statements that assign values to the existing DiscountDelegate objects, add statements that assign the firstDel object to thirdDel, and then add secondDel to it composition.
thirdDel = firstDel;
thirdDel += secondDel;
