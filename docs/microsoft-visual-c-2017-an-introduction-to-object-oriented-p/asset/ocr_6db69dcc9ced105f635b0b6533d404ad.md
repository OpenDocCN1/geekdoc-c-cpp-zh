# Using Nested Loops

+   1. The body of the following loop executes six times:
for(a = 1; a < 4; ++a)
for(b = 2; b < 3; ++b)
2. The body of the following loop executes four times:
for(c = 1; c < 3; ++c)
for(d = 1; d < 3; ++d)
3. The body of the following loop executes 15 times:
for(e = 1; e < 5; ++e)
for(f = 2; f <= 4; ++f)

those iterations. When a is 1, 2, and 3, the inner loop executes just once for each of the outer loop. The false statement is #1. That inner loop executes only three times.
