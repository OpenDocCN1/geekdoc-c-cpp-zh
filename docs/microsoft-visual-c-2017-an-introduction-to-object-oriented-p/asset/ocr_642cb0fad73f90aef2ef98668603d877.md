# Using Compound Expressions in if Statements

| x | y | x && y |
|---|---|---|
| True | True | True |
| True | False | False |
| False | True | False |
| False | False | False |

For example, the two code samples shown in Figure 4-14 work exactly the same way. The age variable is tested, and if it is greater than equal to 0 and less than 120, a message is displayed to explain that the value is valid.

```
// using the && operator
if(age >= 0 && age < 120)
WriteLine("Age is valid");

// using nested ifs
if(age > 0)
  if(age < 120)
    WriteLine("Age is valid");
```

**Figure 4-14** Comparison of the && operator and nested if statements

Using the && operator is never required, because nested if statements achieve the same result, but using the && operator often makes your code more concise, error-prone, and easier to understand.

It is important to note that when you use the && operator, you must include a Boolean expression on each side of the operator. If you want to set a bonus to $400 when saleAmount is both greater than $1000 and less than $5000, the correct statement is as follows:

```
if(saleAmount > 1000 && saleAmount < 5000)
  bonus = 400;
```

The following statement is incorrect and will not compile:

```
if(saleAmount > 1000 && saleAmount < 5000)
  bonus = 400;
```

For clarity, many programmers prefer to surround each Boolean expression that is part of a compound expression with its own set of parentheses. For example:

```
if((saleAmount > 1000) && (saleAmount < 5000))
  bonus = 400;
```

> Don't Do It
< 5000 is not a Boolean expression because the < operator requires two operands, so this statement is invalid.
