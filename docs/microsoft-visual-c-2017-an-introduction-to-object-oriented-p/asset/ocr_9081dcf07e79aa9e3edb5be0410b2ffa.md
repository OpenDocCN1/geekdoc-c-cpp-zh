# APPENDIX B Understanding Numbering Systems and Computer Codes

In the hexadecimal system, each column is 16 times the value of the column to its right. Therefore, column values from right to left are 1, 16, 256, 4096, and so on. Figure B-3 shows how 171 and 305 are expressed in hexadecimal.

| Column value | Column value |
| --- | --- |
| 16 | 256 |
| A | B |
| 10 * 16 = 160 | 1 * 256 = 256 |
| 11 * 1 = 11 | 3 * 16 = 48 |
| -- 171 | 1 * 1 = 1 |
| | 305 |

**Figure B-3** Representing decimal values 171 and 305 in the hexadecimal system

# Measuring Storage

In computer systems, internal memory and external storage are measured in bits and bytes. Eight bits make a byte, and a byte frequently holds a single character (in ASCII or EBCDIC) or half a character (in Unicode).
