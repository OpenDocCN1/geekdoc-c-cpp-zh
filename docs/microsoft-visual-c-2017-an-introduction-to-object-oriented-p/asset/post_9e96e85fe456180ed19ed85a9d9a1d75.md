## Overriding Base Class Members

In Figure 10-15, the child class, the GetGreeting() method uses the keyword new in its header to eliminate compiler warning. Then, within the method, the parent's version of GetGreeting() is called. The returned string is stored in the greeting variable, and on commission is concatenated before the complete message returned to the calling program. By overriding the base class method in the child class, duplicate typing is eliminated. Additionally, if the first part of the message is altered in the future, it will be altered in only one place—in the base class.
