# Setting a Control's Font

Use the Font class to change the appearance of printed text on your Forms. When designing a Label, Button, or other Control on a Form, it is easiest to select a Font from the Properties list. After you place a Control on a Form in the IDE, you can select the ellipsis (three dots) that follows the current Font property name in the Properties list. (See Figure 12-4). Clicking the ellipsis displays a Font window in which you can choose a Font name, size, style, and other effects. (See Figure 12-5).
