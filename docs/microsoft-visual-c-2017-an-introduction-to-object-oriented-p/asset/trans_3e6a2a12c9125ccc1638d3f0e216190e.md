相反，当你使用前缀 `++(b)` 或 `--(b)` 时，值会被计算并存储；例如，在以下代码的第二行中，4 被赋值给 `c`；然后经过递增后，`b` 变为 5。如果值为 4，那么 `c` 取值为 5。

```csharp
b = 4;
c++;
c--;
```

前缀递增将变量的值增加 1。例如，如果表达式 `x++= 3` 的结果为 3——`x` 的值为 3，但随后它会变为 4。
