# GLOSSARY

Contrast with Boolean logical inclusive OR operator.

dead code—Statements that can never execute under any circumstances because the program logic “can’t get there.” Also see unreachable.

constant—Describes a data item when it cannot be changed after a program is compiled; in other words, when it vary.

debugging—The process of removing all syntax and logical errors from a program.

constructor—A method that instantiates (creates an instance of) an object.

decimal—A floating-point data type that has a greater precision and a smaller range than a float or double, which makes it suitable for financial and monetary calculations.

constructor initializer—A class that indicates another instance of a class should be executed before any statements in the current constructor body.

decimal number system—The system that uses 10 digits, 0 through 9, arranged in columns to represent numbers.

contextual keywords—Identifiers that act like keywords in specific circumstances.

decision structure—A unit of program logic that involves choosing alternative courses of action based on value.

control—A GUI component such as a text field, button, or check box that users can manipulate to interact with a program.

decrement operator (--An operator that consists of two minus signs and reduces a variable’s value by 1; there is a prefix and a postfix version.

control statement—The part of a structure that determines whether the subsequent block of statements executes.

decrementing—The act of decreasing the value of a variable by 1.

counted loop—A definite loop.

default constructor—A constructor that requires no parameters; it can be automatically supplied or written by a programmer.

CSV file—A file that contains separated values.

default event for a Control—The event method generated when it is double-clicked in the IDE, as well the user expects to generate when they encounter the Control in a working application.

culture—A set of rules that culturally define values such as money and dates are formatted.

default value of an object—The value initialized with a default constructor.

data files—Files that contain facts and figures; persistent connections of related records.

hierarchy—The relationship of characters, fields, records, and files.

definite loop—A loop in which the number of iterations is predetermined. A counted loop with infinite loop.

data type—A description of the function and size of data item as well as the operations that can be performed on it.

delegate—An object that contains a reference to a method.
