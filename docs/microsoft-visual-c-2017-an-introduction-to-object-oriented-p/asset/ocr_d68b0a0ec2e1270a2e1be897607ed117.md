# Accepting Console Input

A program that allows user input is an interactive program. You can use the ReadLine() method to create an interactive program that accepts user input from the keyboard. This method accepts all of the characters entered by a user until the user presses Enter. The characters are assigned to a string. For example, the following statement accepts a user's input and stores it in the variable myString

```
myString = ReadLine();
```

The Read() method is similar to the ReadLine() method. Read() reads just one character from the input stream, where ReadLine() reads every character in the input stream until the user presses Enter.

+   * Prior the release of C# 6.0, the qualified names Console.ReadLine() and Console.Read() were required. However, just like WriteLine() and Write(), you can now include using static Console; at the top of a file allowing you to use the shorter methods ReadLine() and Read().

If you use the input value as a type other than string, then you must use a conversion method to change the input string to the proper type. Two methods are available for converting strings—the Convert class and Parse() methods.
