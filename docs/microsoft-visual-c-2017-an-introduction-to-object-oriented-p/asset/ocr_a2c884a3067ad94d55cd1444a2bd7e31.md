# TWO TRUTHS & A LIEnHHandling Exceptions Thrown From Outside Methods

+   1. When methods from other classes throw exceptions, the methods don't have to catch them; instead, your calling program can catch them, and you can decide what to do.
2. Often, you don't want a called method to handle its own exception; in many cases, you want the calling program to handle any exception in the most appropriate for the application.
3. When you design classes containing methods that might throw exceptions, you almost always should make sure your class handles each exception appropriately.

> The false statement is #3. When you design classes containing methods that might frequently throw exceptions, you should create statements so that methods that might throw the exception but do not handle it.
