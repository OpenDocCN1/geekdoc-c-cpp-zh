Object (or object)—A class type in the System namespace that is the ultimate base class for all other types.

Also called the conditional OR operator. Contrast with Boolean logical inclusive OR operator.

object initializer—A class that assigns values to all accessible members or properties of a class at the time of instantiation without calling a constructor with parameters.

order of operation—Rules that determine the order in which parts of a mathematical expression are evaluated. Also called operator precedence.

oriented-approach—An approach to a problem that involves defining the objects needed to accomplish a task and developing classes that describe the objects so that each maintains its own data and carries out tasks when another object requests them.

orphaned method—A method that never executes in an application, and serves no purpose.

out of bounds—Describes a subscript that is not within the allowed range for an array.

out of scope—Describes a variable or name that is not usable because it has ceased to exist.

oriented-programming (OOP)—A programming technique that features objects, encapsulation, interfaces, polymorphism, and inheritance.

out variable—A variable declared at the point where it is passed to a method as an argument.

one-dimensional array—An array whose elements are accessed using a single subscript. Also seen as single-dimensional array.

outer loop—The loop in a pair of nested loops that contains another.

opening a file—The process of creating an object and associating a stream of bytes with it.

output parameter—A parameter to a method that receives the address; it is not required to have an initial value. Contrast with value parameter and reference parameter.

operands—The values that operators use in expressions.

overload resolution—The process of determining which multiple methods are the best match for a method call.

operator precedence—Rules that determine the order in parts of a mathematical expression are evaluated. Also called order of operation.

overloading—Using one term to indicate different meanings. In C#, methods are overloaded when there are multiple versions with the same name but different parameter lists.

optional parameter—A parameter to a method for which a default value is supplied when no argument is sent explicitly; a parameter is optional when it is given a value in the method declaration.

override—A keyword used in method headers when a derived class inherits an abstract method from a parent.
