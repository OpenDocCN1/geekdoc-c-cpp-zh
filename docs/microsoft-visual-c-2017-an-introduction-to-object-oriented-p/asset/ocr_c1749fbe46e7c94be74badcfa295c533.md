# GLOSSARY

**side effect**—An unintended consequence of an operation.

**signature**—A method's name and parameter list.

**significant digits**—Specify the mathematical accuracy of a value.

**simple type**—Describes one of the following in C#: byte, sbyte, short, ushort, int, uint, long, double, decimal, char, and bool.

**single-dimensional array**—An array whose elements are accessed using a single subscript. See *one-dimensional array*.

**snaps lines**—Lines that appear in a design environment to help align controls with others that are already in place.

**software**—Computer programs.

**source code**—Program statements.

**standard numeric format strings**—Strings of characters expressed within double quotation marks that indicate a format for output.

**state of object**—The collective value of all of an object's attributes at any point in time.

**static**—A keyword that indicates that a method will be executed through a class and not by an object.

**step value**—The amount by which a loop variable is altered on each iteration, especially in a for loop.

**stream**—A pipeline or channel through which bytes are input from and output to a file.

**string**—A data type that can hold a string of characters.

**string interpolation**—The process of replacing string place holders with values; called *variable substitution*.

**subclass**—A derived class; a class that has inherited from a base class.

**subscript**—An integer within square brackets that dictate the position of one of an array's elements. Also see *index*.

**suggestion mode**—An IDE editing mode in which completion is turned off.

**superclass**—A base class; a parent class; a class that is for the inheritance.

**switch structure**—A structure that tests a single variable against a series of exact matches.

**syntax**—The set of grammar rules in a programming language.

**syntax error**—An error that occurs when programming language is used incorrectly.

# T

**tab order**—The sequence of controls selected when the user presses the Tab key in a program with a GUI interface.

**ternary**—Describes an operator that requires three arguments.

**TextBox**—Controls through which a user can input data in a GUI application.

**text files**—Files that contain data that can be read in a text editor using a scheme such as ASCII or Unicode.

**this reference**—The reference to an object that is implicitly passed to an instance method of its class.
