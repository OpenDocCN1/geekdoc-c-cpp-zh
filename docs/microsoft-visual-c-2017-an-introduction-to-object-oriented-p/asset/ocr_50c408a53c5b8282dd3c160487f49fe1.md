# CHAPTER 3 Using GUI Objects and the Studio IDE

+   - Labels are controls that you use to display text to communicate with an application's user. TextBoxes are controls through which a user can enter data in a GUI application. Both have a Text property; frequently an application starts with the Text empty for TextBoxes. Because a user may enter any value, the TextBox is a string by default.

+   - Usually, you provide provable Name properties for all the controls you use on a Form. Although any identifier that starts with a letter is legal, by convention you should start control names with a lowercase letter and use camel case as appropriate, start Form names with an uppercase letter and use camel case as appropriate, and use the type of object in the name.

+   - If you build or run a program that has a syntax error, you see Build failed in the lower-left corner of the IDE and an error dialog box. An error list shows the line, position in the line, and project for each error. If you double-click an error message, the cursor is placed at the code where the error was found. If you inadvertently create an event-handling method that you do not want, you eliminate the event using the Properties window in the IDE. To remove an event method, you must refactor the code. Both console and GUI applications can contain variable declarations and similar statements. GUI applications use "snazzier," and they contain controls that a user can manipulate with a mouse. However, GUI programs usually take longer to develop than their console counterparts. When writing your own programs, you will use the interface you prefer or one that instructor or boss requires.

# Key Terms

The interface is the environment a user sees when a program executes.

Forms are GUI objects that provide an interface for collecting, displaying, and delivering information.

Controls are devices such as labels, text boxes, and buttons that users can manipulate to communicate with a GUI program.

A node is an icon that appears after a list or a section of code and can be expanded or condensed.

An access specifier is a keyword that dictates whether outside classes use a method.

An event causes a program to perform a task.

A click event is the event generated when a user clicks a control in a GUI program.

A label is a control that you display text to communicate with an application's user.

A text box is a control through which a user can enter input data in a GUI application.

Design time is the period during which a programmer designs the interface and writes the code.

Runtime is the period during which a program executes.
