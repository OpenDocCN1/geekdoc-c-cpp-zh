
Object (or object)—A class type in the System namespace that is the ultimate base class for all other types.

Also called the conditional OR operator. Contrast with Boolean logical inclusive OR operator.

object initializer—A class that assigns values to all accessible members or properties of a class at the time of instantiation without calling a constructor with parameters.

order of operation—Rules that determine the order in which parts of a mathematical expression are evaluated. Also called operator precedence.

oriented-approach—An approach to a problem that involves defining the objects needed to accomplish a task and developing classes that describe the objects so that each maintains its own data and carries out tasks when another object requests them.

orphaned method—A method that never executes in an application, and serves no purpose.

out of bounds—Describes a subscript that is not within the allowed range for an array.

out of scope—Describes a variable or name that is not usable because it has ceased to exist.

oriented-programming (OOP)—A programming technique that features objects, encapsulation, interfaces, polymorphism, and inheritance.

out variable—A variable declared at the point where it is passed to a method as an argument.

one-dimensional array—An array whose elements are accessed using a single subscript. Also seen as single-dimensional array.

outer loop—The loop in a pair of nested loops that contains another.

opening a file—The process of creating an object and associating a stream of bytes with it.

output parameter—A parameter to a method that receives the address; it is not required to have an initial value. Contrast with value parameter and reference parameter.

operands—The values that operators use in expressions.

overload resolution—The process of determining which multiple methods are the best match for a method call.

operator precedence—Rules that determine the order in parts of a mathematical expression are evaluated. Also called order of operation.

overloading—Using one term to indicate different meanings. In C#, methods are overloaded when there are multiple versions with the same name but different parameter lists.

optional parameter—A parameter to a method for which a default value is supplied when no argument is sent explicitly; a parameter is optional when it is given a value in the method declaration.

override—A keyword used in method headers when a derived class inherits an abstract method from a parent.

OR operator—An operator that determines whether at least one of two conditions is true; it is override to take precedence over another method version.

panel—A GUI element that can be used to group controls on a Form; similar to a group box, but does not have a caption and have scroll bar.

parallel array—An array that has the same elements as another and holds corresponding data.

parameter array—A local array declared within a method header that can accept any number of elements of the same type.

parameter list—The data types and names that appear between parentheses in a method header.

parameter to a method—An object or reference declared in a method definition.

parameterless constructor—A constructor that takes no parameters; one is called using arguments.

parent class—A base class; used as a basis for inheritance.

parse—To break an item into component parts.

Pascal casing—A style of creating identifiers where the first letter of all words is capitalized. Contrast with camel casing.

passed by reference—Describes how an argument is passed to a method when the method receives its memory address.

passed by value—Describes how data is passed to a method when the method receives a copy of it.

path—The drive in which file resides plus the complete hierarchy of directories.

permanent storage devices—Hardware such as hard disks, USB drives, and compact discs used to store files.

persistent—Describes storage that is nonvolatile.

picture box—A GUI element that displays graphics.

placeholder—A number within braces that holds a position for variable value.

polymorphism—The ability to create methods that act appropriately depending on the context.

populating array—The act of providing values for all elements in an array.

positional argument—An unnamed argument assigned to a parameter list by its position in the method.

prefix increment operator—An operator that adds a value and adds to it. It is represented by two plus (++) before a variable.

posttest loop—A loop in which the control variable is tested after the body executes. Contrast with pretest loop.

precedence—A feature of operators that controls the order in which they are evaluated in an expression.

precision specifier—An operator controls the significant digits or zeros to the right of the decimal point.

prefix increment operator—An operator that increases the value by 1 and then evaluates it. It is represented by two plus (++) before a variable.

pretest loop—A loop in which the control variable is tested before the body executes.

priming read—An input statement that gets a first item or record.

public—An access specifier that indicates other classes can use the method or variable.

private—An access specifier that indicates other classes cannot use the method or variable it modifies. When used as a class specifier, it means access is limited to another class to which it belongs.

public access—A level of method accessibility that allows unlimited access by any class.

private access—A level of method accessibility that limits access to the containing class.

radio buttons—GUI widgets, similar to check boxes, except that when they are placed on a form, only one can be selected at a time and selecting one automatically deselects the others.

procedural program—A program created by writing a series of steps or operations to manipulate values.

raises an event—Causes an event to occur. Also fires *event* and *triggers an event*.

program—A set of written computer instructions.

random access—A file with which records can be accessed in any order.

program comments—Nonexecutable statements that document a program.

random access memory (RAM)—Temporary storage in a computer.

prompt—An instruction to the user to enter data.

range check—A series of statements in which each statement determines whether a value falls within a specified range.

propagating an exception—The act of transmitting an exception unchanged through the call stack.

match—A process that determines whether a value falls between a pair of limiting values.

property—A member of a class that provides access to a field of a class; properties define how fields will be set and retrieved. The value of an object is.

read the file—To copy data from a file on a storage device into RAM.

proportional font—A font in which characters have different widths or sizes.

read-only—Describes a value, or file that can be accessed but not altered.

protected—A keyword that provides an intermediate level of security between **public** and **private**.

read-only property—A property that has only a getter, and not a setter.

protected access—A level of method accessibility that limits access to the containing class or types derived from the containing class.

record—A collection of fields that contains data about an entity.

pseudocode—A tool that helps programmers plan a program's logic by writing English statements.

rectangular array—An array in which each row has the same number of columns.

recursive—Describes a method that calls itself.

reference—A memory address.

scope—The area where a variable or constant is known and can be used.

reference equality—The type of equality that occurs when reference type objects refer to the same object.

screaming caps—A naming style that uses all uppercase letters and underscores; often used for named constants.

reference parameter—A parameter to a method that retrieves the argument's address; it is required to have an initial value. Contrast with value and output parameter.

sealed class—A class that cannot be extended.

reference type—A data type that holds a address. Contrast with value types.

searching an—The process of comparing a value to a list of values in an array, looking for a match.

rethrow an Exception—To throw a caught Exception instead of handling it.

self-documenting—Describes a program element that is self-explanatory.

return statement—A method statement that causes a value to be sent back from calling method.

sentinel value—A value that user must use to stop a loop.

return type—The type of a method that will return to any other method.

sequence structure—A unit of logic in which one step follows another unconditionally.

right-associative—Describes operations which are performed from right to left.

sequential file—A data file in each record is stored in order based on the value in some field.

robustness—Describes the degree to which a system is resilient to stress, maintaining correct functioning in the presence of errors.

sequential search—A search that is conducted by examining list-by-item in sequence.

root class—The ultimate or first base class in a hierarchical ancestry tree.

serialization—The process of converting objects into streams of bytes.

root directory—The main directory of a storage device.

set assessors—Methods in properties that allow the use of an assignment operator with a property name.

run time—The period of time during which a program executes.

setter—Another term for a class property's accessor.

runnable—Describes files that are executable.

short—An integral data type that can hold a signed numeric value within two bytes.

short-evaluation—The C# feature in which parts of an AND or OR expression are evaluated only far as necessary to determine whether the entire expression is true or false.

sbyte—An integral data type that can hold a signed numeric value from -128 through 127.

scientific notation—A numeric expression format that includes an E (for exponent) and specifies how many implied decimal places.
