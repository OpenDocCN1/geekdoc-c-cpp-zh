# Using the Integral Data Types

In C#, nine types are considered integral data types—that is, types that store whole numbers. The nine types are byte, sbyte, short, ushort, int, uint, long, char. The first eight represent whole numbers, and the ninth type, char, is used for characters as A or . Actually, you can think of all nine types as because Unicode character, including the letters of alphabet and punctuation marks, can be represented as a number. For example, the character A is stored within your computer as 65. Because you more commonly think of the char type as holding alphabetic characters instead of their numeric values, the char type will be discussed in this section later in this chapter.

The most basic of each integral type is int. You use variables of int to store (or hold) integers, or whole numbers without any fractional part. An int uses four bytes of memory and can hold any number value ranging from 2,147,483,647 to -2,147,483,648. When you use a whole-number such as 3 or 589 in a C# program, by default it is an int.
