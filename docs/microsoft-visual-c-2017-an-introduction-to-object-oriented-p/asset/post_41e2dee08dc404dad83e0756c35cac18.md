## Adding RadioButtons to a Form

Next you add more Controls to the BedAndBreakfast Form. You generally use RadioButtons when a user must select from mutually exclusive options.

- 1. In the Design view of the Form in the BedAndBreakfast project, add a Button near the bottom of the Form. Change the Button's Name property to mealButton and the Button's Text to Click for meal options. Adjust the size of the Button so that its text is fully visible.

- 2. From the menu bar, select Project, Add New Item, and click Windows Form. Name the Form BreakfastOptionForm, and click Add. On the new Form, make the following changes:

    - Set the Form's BackColor to Yellow.
    - Drag a Label onto the Form. Name it appropriately, and set its Text to Select your breakfast option.
    - Drag three RadioButtons onto the Form. Set their respective Text properties to **Continental, Full, and Deluxe**. Set their respective Names to contRadioButton, fullRadioButton, and deluxeRadioButton.
    - Select an appropriate font for the Label and RadioButtons.
    - Drag a Label onto the Form, and then set it to **Price:** and its Name to **priceLabel**. Make the font property a little larger than for the other Form components, and also make it **Bold.**

See Figure 12-40 for approximate placement of all these Controls.

- 3. Double-click the title bar of the BreakfastOptionForm to generate a method named BreakfastOptionForm_Load(). Within this method, you can type statements that execute each time the Form is created. Add the following statements within the BreakfastOptionForm class, which declare three constants representing prices for different breakfast options. Within the BreakfastOptionForm_Load() method, set the priceLabel Text property to the lowest price by default when the Form loads.

```csharp
public partial class BreakfastOption : Form {
    private const double CONT_BREAKFAST_PRICE = 6.00;
    private const double FULL_BREAKFAST_PRICE = 9.95;
    private const double DELUXE_BREAKFAST_PRICE = 16.50;

    public BreakfastOptionForm()
    {
        InitializeComponent();
    }

    private void BreakfastOptionForm_Load(object sender,
        EventArgs e)
    {
        priceLabel.Text = "Price: " +
        CONT_BREAKFAST_PRICE.ToString("C");
    }
}
```

- 4. Return to the Design view for the BreakfastOptionForm, and double-click the contraButton.
