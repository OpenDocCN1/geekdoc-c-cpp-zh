# GLOSSARY

**just in time (JIT)**—The C# compiler that translates intermediate code into executable code.

list box—A GUI element that displays a list of items the user can select by clicking.

**literal constant**—A value that is taken literally at each use.

**literal string**—A series of characters that is used exactly as entered.

# K

**key**—A value that uniquely identifies a record.

**local function**—A method that resides within another method and can be called only from the containing method.

**key events**—Keyboard events that occur when a user presses and releases keyboard keys.

**local variable**—A variable that is declared in the current method.

**key field**—The field used to uniquely identify records and control the order of records in a sequential file.

**logic**—The sequence of statements and methods that produce the desired results in a computer program.

**keywords**—Predefined and reserved identifiers that have special meaning to the compiler.

**long**—An integer data type that can hold a signed numeric value in eight bytes.

**kilobyte**—Approximately one bytes.

**loop**—A structure that repeated execution of a block of statements.

# L

**loop body**—The block of statements executed in a loop.

**label**—A control that typically provides descriptive text for another control or displays text information on a Form.

**loop control variable**—A variable that determines when execution will continue on each iteration.

**left-associative**—Describes operations that are performed from left to right.

**loop fusion**—The technique of combining two loops into one.

**length field**—A field that contains the number of elements in an array.

**lower camel casing**—A style of creating identifiers where the first letter is not capitalized, but each new word is. Also called camel casing. Contrast with Pascal casing.

**lexically**—Alphabetically.

**line comments**—Comments that start with two forward slashes ( // ) and continue to the end of the current line. Line comments appear on a line by themselves, or at the end of a line of executable code. Compare with block comments.

# M

**machine language**—The most basic circuitry-level language.

**magic number**—A hard-coded number.

**mandatory parameters**—Method parameters for any argument is required in every method call.

**link label**—A GUI control with text that links the user to others, such as Web pages or files.
