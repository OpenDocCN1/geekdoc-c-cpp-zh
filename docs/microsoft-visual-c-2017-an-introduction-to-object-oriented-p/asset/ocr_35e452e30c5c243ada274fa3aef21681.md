# Understanding GroupBoxes and Panels

Many types of ContainerControls are available to hold Controls. For example, a group box or panel can be used to contain a group of other controls and to move them as a group. To create either of Controls, you drag it from the Toolbox in the IDE and then drag the Controls on top of it. In C#, a group box and a panel differ in the following ways:

+   - A group is created from the GroupBox class, and a panel is created from the Panel class.
- GroupBoxes display a caption, but Panels cannot.
- Pans can include a scroll bar that the user can manipulate to view Controls; GroupBoxes do not have scroll bars.

You can anchor or dock Controls inside a GroupBox or Panel, and you can anchor or dock GroupBox or Panel inside a Form. Doing this provides Control groups that can be arranged easily.

If you place several GroupBox Controls on a Form and several RadioButtons in each GroupBox, then a user can select one RadioButton from each GroupBox instead of being able to select just one RadioButton from a Form. In other words, GroupBox operates independently.

> When an application contains multiple GroupBox or Panel on a Form, pressing Tab moves the focus to the next GroupBox or Panel. Then, within the GroupBox or Panel, you use arrow keys to progress to successive RadioButtons.

TWO TRUTHS & A LIE
Working with a Form's Layout
1. Setting the Anchor property causes a Control to remain at a fixed distance from the side of a container when the user resizes it.
2. Setting the Dock property attaches a Control to the side of a container so that the Control's size does not change when the container's size is adjusted.
3. The GroupBox and Panel controls are ContainerControls.

The false statement is #2. Setting the dock property attaches a Control to the side of a container that stretches when the container's size is adjusted.
