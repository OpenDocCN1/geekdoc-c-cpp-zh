# APPENDIX B Understanding Numbering Systems and Computer Codes

The binary numbering system works in the same way as the decimal system, except that it uses only two digits, 0 and 1. Mathematicians call these numbers base 2 numbers. When you use the binary system, if you want to express a value greater than 1, you must resort to using multiple columns, no single symbol is available that represents any value other than 0 or 1. However, instead of each new column to be 10 times greater than the previous column, when you use the binary system, each new column is only two times the value of the previous column. For example, Figure B-2 shows how the numbers 9 and 305 are represented in the binary system. Notice that in both the binary and decimal systems, it is perfectly acceptable—and often necessary—to create numbers with 0 in one or more columns. As with the decimal system, the binary system has no limit to the number of columns; you can use as many as it to express a value.

A computer stores every piece of data it uses as a set of 0s and 1s. Each 0 or 1 is known as a bit, which is short for binary digit. Every computer uses 0s and 1s because all values in a computer are stored as electronic signals that are either on or off. This two-state system is most easily represented using just two digits.

Computers use a set of binary digits to represent stored characters, then only two characters could be represented, the single bit could be only 0 or 1. If computers used only one binary digit, then only two characters could be represented—the four codes 00, 01, 10, and 11, in decimal values are 0, 1, 2, and 3, respectively. Many computers use set of binary digits to represent each character they store, using eight binary digits provide 256 different combinations. One combination can represent an A, another a B, still both a and b, and so on. Two hundred fifty-six combinations are enough so that each capital letter, small letter, digit, and punctuation in English has its own code; a space has a code.
