# Understanding Serialization and Deserialization

The Serialize() method takes two arguments—a reference to the output file and a reference to a serializable object that may contain any number of data fields. The entire object is written to the data file with this single statement.

Similarly, when you read from a data file, you use a statement like the following:
objectInstance = (TypeOf(object))formatter.Deserialize(inFile);

This statement uses the Deserialize() method with a BinaryFormatter to read one object from the file. The object is cast to the appropriate type and can be assigned to an instance of the object. Then you can access individual fields. An entire object is read with this single statement, no matter how many fields it contains.

Figure 14-22 shows a program that writes Employee classes to an output file and later reads them into the program. After the FileStream is declared for the first statement. The user enters an ID number, name, and salary for an Employee, and the completed object is written to a file in the second shaded statement. When the user enters 999, the completed object is closed.

```
using System;
using System.Console;
using System.IO;
using System.Runtime.Serialization.Formatters.Binary;
using System.Runtime.Serialization;
class SerializableDemonstration
{
    static void Main()
    {
        const int END = 999;
        const string FILENAME = "Data.ser";
        Employee emp = new Employee();
        FileStream outfile = new FileStream(FILENAME,
            FileMode.Create, FileAccess.Write);
        BinaryFormatter formatter = new BinaryFormatter();
        Write("Enter employee number or " + END + +
            " to quit >> ");\n        emp.EmpNum = Convert.ToInt32(ReadLine());
        while (emp.EmpNum != END)
        {
            Write("Enter last name >> ");\n            emp.Name = ReadLine();
            Write("Enter salary >> ");\n            emp.Salary = Convert.ToDouble(ReadLine());
            formatter.Serialize(outfile, emp);
            Write("Enter employee number or " + END + +
                " to quit >> ");
\n            emp.EmpNum = Convert.ToInt32(ReadLine());
        }
    }
```
