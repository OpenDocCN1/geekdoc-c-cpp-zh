# CHAPTER 14 Files and Streams

The classes BinaryReader and BinaryWriter exist for working with binary files, which can store any of the 256 combinations of bytes in any byte instead of just those combinations that form readable text. For example, photographs and music are stored in binary files.

The classes XmlReader and XmlTextWriter exist for working with XML files. XML is an abbreviation of Extensible Markup Language, which is a standard for exchanging data over the Internet.

# Writing and Reading a Sequential Access File

Although people think of data files as consisting of records that contain fields, C# uses only as streams of bytes. Therefore, when you write a program to store a data file or write a program to retrieve data from a file that has already been created, you must dictate the form in which the program will handle the file. Additionally, whether you are writing data to a file or reading data from one, you create a FileStream object.
