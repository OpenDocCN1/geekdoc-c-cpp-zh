
## Creating Loops with the for Statement

The LoopingBal program in 5-7 contains an indefinite loop because the number of executions is not predetermined; each time the program executes, the user might continue a different number of times. You can use a while loop for either definite or indefinite loops. To avoid either type of while loop, you initialize a loop control variable, and as long as its test expression is true, execute the body of the while loop. To avoid an infinite loop, the body of the while loop must contain a statement that alters the loop control variable.

Because you need to define loops (ones with a predefined number of iterations) so frequently when you write programs, C provides a shorthand way to create such loops. With a for loop, you can indicate the starting value for the loop variable, the test condition that controls loop entry, and the expression that alters the loop control variable, all in one convenient place.

You begin a for statement with the keyword followed by a set of parentheses. Within the parentheses are three sections separated by two semicolons. The three sections are used for:

1. Initializing the loop control variable
2. Testing the loop control variable
3. Updating the loop control variable

As with an if or a while statement, you can use a single statement as the body of the for loop or you can use a block of statements enclosed in curly braces. The while and for statements shown in Figure 5-10 produce the integers 1 through 10.

```cs
// Declare loop control variable and limit
int x;
const int LIMIT = 10;

// Using a while loop to display 1 through 10
x = 1;
while(x <= LIMIT)
{
    WriteLine(x);
    x++;
}

// Using a for loop to display 1 through 10
for(x = 1; x <= LIMIT; ++x)
    WriteLine(x);
```

**Figure 5-10** Displaying integers 1 through 10 while while and for loops

The amount by which a loop variable increases or decreases on each cycle the loop is often called the step value. That's because in the BASIC programming language, and its descendant, the keyword STEP is actually used in loops.

# CHAPTER 5 Looping

Within the parentheses of the **for** statement shown in Figure 5-10, the initialization section prior to the first semicolon sets a variable **x** to 1. The program executes this statement once, no matter how many times the body of the **for** loop executes.

After the initialization executes, program control passes to the middle section, or test, of the **for** statement. If the Boolean expression there evaluates to **true**, then the body of the **for** loop is entered. In the program segment shown in Figure 5-10, x is initialized to 1, so **x <= LIMIT** is tested, it evaluates to **true**, and the **for** loop outputs the value of **x**.

After the loop executes, the final one-third of the **for** expression (the update section that follows the last semicolon) executes, and **x** increases to 2. Following the third section, program control returns to the second (test) section, where **x** is compared to **LIMIT** a second time. Because the value of **x** is 2, it is less than or equal to **LIMIT**, so the body of the **for** loop executes, and the value of **x** is displayed. Then the third portion of the **for** statement executes again. The variable **x** increases to 3, and the **for** loop continues.

Eventually, when **x** is not less than or equal to **LIMIT** (after 1 through 10 have been output), the **for** loop ends, and the program continues with anything that follows the for loop.

Although the three sections of the **for** loop are most commonly used for initializing a variable, testing it, and incrementing it, you can also perform other tasks:

- You can initialize more than one variable by placing commas between separate initializations in the first section of the **for** statement, as in the following:
```cs
for(g = 0, h = 1; g < 6; ++g)
```
- You can declare a new variable within the **for** statement, as in the following:
```cs
for(int k = 0; k < 5; ++k)
```
In this example, **k** is declared to be an **int** and is initialized to 0. This technique is used frequently when variable exists for no other purpose to control the loop. When a variable is declared inside a loop, as **k** in this example, it can be referenced only for the duration of the loop body. When a variable (or named constant) can be accessed, it is in **scope** or in an area where it is known and can be used. When a loop ends, any declarations within it are **out of scope**, which means they are not usable because they have ceased to exist.

- You can perform more than one test in the middle section of the **for** statement by evaluating compound conditions, as in the following:
```cs
for(g = 0; g < 3 && h > 1; ++g)
```
- You can perform other tasks than incrementing at the end of the loop's execution, as in the following code that decrements a variable:
```cs
for(g = 5; g >= 1; --g)
```
- You can perform multiple tasks at the end of the loop's execution, as in the following:
```cs
for(g = 5; g >= 1; --g)
```

# Creating Loops with the Statement

- You can leave one or more portions of the for expression empty, the semicolons are still required. Generally, you should use all three sections because the for loop is clearer to someone.

- You should use the for loop in the standard manner, which is:
```cs
const int TIMES = 4;
for(int x = 0; x < TIMES; ++x)
{
    WriteLine("Hello");
    WriteLine("Goodbye");
}
```

Without the clauses in this code, the for loop would display four times. In other words, Hello would be displayed once.

# Creating Loops with the do Statement

With each of the loop statements you have learned so far, the loop body might execute many times, but it is also possible that the loop will not execute. For example, recall the balance program that displays compound interest, part of which is shown in Figure 5-11. The loop begins at the shaded line by testing the value of response. If the user has not entered Y, the loop body never executes. The while loop checks a value at the “top” of the loop.

```cs
Write("Do you want to see your balance? Y or N...");
inputString = ReadLine();
response = Convert.ToChar(inputString);
while(response == "Y") {
    WriteLine("Bank balance is {0}", bankBal.ToString("C"));
    bankBal = bankBal * INT_RATE;
    WriteLine("Do you want to see next year's balance? Y or N...");
    inputString = ReadLine();
    response = Convert.ToChar(inputString);
}
```
