# What to Do When the Program Compiles Successfully in the IDE

If you receive no error messages after compiling the code, then the program compiled
successfully, and you can run the program. Select **Debug** from the menu bar, and then select
**Start Without Debugging**. The output appears, as you saw in Figure 1-6 earlier in this chapter.

# Noticing the Differences Between the Programs in the Text Editor and the IDE

There are a few differences between the ThreeLinesOutput programs in Figures 1-8 and 1-12.
Specifically, the Visual Studio version in Figure 1-12 contains the extra components that are
highlighted in Figure 1-14.

+   * **Five using statements at the top of the file.** Visual Studio automatically provides you with
several commonly needed statements. In this case, you could delete all five statements
from the Visual Studio version of the program, and the program would still run correctly.
(The only statement you need to retain is the `using System.Console;	hat allows you to use `WriteLine()` without qualification.) Conversely, you could
add five additional `using` statements to the command-line version of the program, and it
would also run correctly.
* **A namespace declaration and its opening and closing braces.** You already know that
# uses built-in namespaces as System and others that are automatically listed at
t top of the Visual Studio version of program. C# also allows you to create your own
namespaces; Visual Studio assumes that you will want to create one name you are using
higned to the project. In this case, you could remove the namespace declaration from
t Visual Studio version of the program, or you could add one to the command-line version
of program. In both cases, the programs would still run correctly.
* **The class name Program.** Visual Studio assumes that you want to avoid confusion by having
different names for your namespace and the class contained within it, so it assigns the generic
name Program to the class that contains the Main() method. You could change this name to
match the namespace identifier, ThreeLinesOutput, or use any other identifier, and the
program would still work correctly. In the Notepad version of program, you could change
t class name to Program or any other identifier, and the program would also work.
* **The words string args between the parentheses of the Main() method header.** C#nallows a program's Main() method header to be written in several ways. For example, you can
include the words string[] args between the method's parameters, or you can omit
the. The square brackets indicate an array, as you will learn when studying arrays later
in this book. you could write the extra in either the Notepad or Visual Studio version of the program, and the
Main() method would still work correctly.
