# Creating the Loan Class and a Program That Uses It

+   1. Open a new project named **DemoLoan**, and then enter the following few lines for a Loan class. The class contains three auto-implemented properties for the loan number, the last name of the customer, and the value of the loan.
```java
class Loan {
    public int LoanNumber {get; set;}
    public string LastName {get; set;}
    public double LoanAmount {get; set;}
}
```n2. At the top of the file, enter the following code to add a DemoLoan class that contains a Main() method. The class declares a Loan object and shows how to set each field and display the results.
```java\using static System.Console;
class DemoLoan {
    static void Main() {
        Loan aLoan = new Loan();
        aLoan.LoanNumber = 2239;
        aLoan.LastName = "Mitchell";
        aLoan.LoanAmount = 1000.00;
        WriteLine("Loan #{0} is for {1}",
            aLoan.LoanNumber, aLoan.LastName,
            aLoan.LoanAmount.ToString("C2"));
    }
}
```n3. Save the file, and then compile and execute the program. The output looks like Figure 10-5. There is nothing unusual about this class or how it operates; it is similar to many you saw in the last chapter before you learned about inheritance.

```
#2239 for Mitchell is for $1,000.00
```
