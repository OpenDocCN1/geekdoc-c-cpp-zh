### Writing Methods That Require Multiple Arguments

You can pass multiple arguments to a method by listing the arguments in the call to the method and separating them with commas. For example, than creating a `DisplaySalesTax()` method that multiplies an argument by 0.07, you might prefer to create a more flexible method to which you can pass two values—the value on which the tax is calculated and the tax percentage by which it should be multiplied. Figure 7-12 shows a method that uses two parameters.

```csharp
private void DisplaySalesTax(double saleAmount, double taxRate)
{
    double tax;
    tax = saleAmount * taxRate;
    WriteLine("The tax on {0} is {1}",
        saleAmount.ToString("C"), taxRate.ToString("P"),
        tax.ToString("C"));
}
```
**Figure 7-12** DisplaySalesTax() method that accepts two parameters

In Figure 7-12, two parameters (saleAmount and taxRate) appear within the parentheses of the method header. A comma separates the parameters, and each parameter requires its own named type (in this case, both parameters are double) and identifier. A declaration for a method that receives two or more arguments must list the type for each parameter separately, even if the parameters have the same type.

When you pass values to the method in a statement such as `DisplaySalesTax(myPurchase, rate);` the first value will be referred to as `saleAmount` within the method, and the second value will be referred to as `taxRate`. Therefore, it is very important that arguments are passed to a method in the correct order. The following call will result in output stating that The tax on $200.00 at 10%: $20.00. Although the arithmetic is the same, the explanation is wrong (unless there is an extremely high tax rate). $20.00.

You can write a method to take any number of parameters in any order. When you call the method, however, the arguments you send must match the parameters listed in the method declaration (both number and type), with the following exceptions:

- The type of argument does not need to match the parameter exactly if the argument can be promoted to the parameter type. For example, an int argument can be passed to a double parameter.
- The number of arguments does not need to match the number in the parameter list when you use default arguments. You will learn about default arguments in Chapter 8.

Thus, a method to compute and display salesperson commission might require arguments such as a string for the salesperson's name, an integer value of the sold car, a double percentage commission rate. The correct method would execute only when all arguments of the correct types are sent in the correct order.

- 1. The following statement is NOT a usable C# method header:
   `private static void MyMethod(double amt, sum)`
- 2. The following is NOT a usable C# method header:
   `private static void MyMethod(int x, double y)`
- 3. The following is a usable C# method header:
   `static void MyMethod(int id, string, double rate)`

### Writing Methods That Return a Value

A method can return, at most, one value to the method that calls it. The return type for a method can be any type used in the C# programming language, which includes the built-in types int, double, and so on. You can also use a class as the return type for method, including any type built into the C# language. For example, you have used a returned value from the `ReadLine()` method when writing a statement as `input = ReadLine();`. Because the `ReadLine()` method can be assigned to a string, its return type is string. In Chapter 3 you learned about control types, such as Button and Label. Objects of these types you learn to create own in Chapter 9, and these can be returned from a method too. Of course, a method also can return nothing, in which case the return value is void.

For example, suppose that you want to create a method to accept the hours an employee worked and the hourly pay rate, and to return a calculated gross pay value. The header for this method could be:

`private static double CalPay(double hours, double rate)`

Figure 7-13 shows this method.

```csharp
private static double CalPay(double hours, double rate)
{
    double gross;
    gross = hours * rate;
    return gross;
}
```
Figure 7-13 The CalPay() method

Notice the return statement, which is the last statement in the `CalPay()` method. A return statement causes a value to be sent back to the calling method; in the `CalPay()` method, the value stored in `gross` is sent back to any method that calls the `CalPay()` method. Also notice the type `double` precedes the method name in the method header. The type used in a method's return statement must be the same as the return type declared in the method's header, or the program will not compile.

If a method returns a value and you call the method, you will typically want to use the returned value, although you are not required to use it. For example, when you invoke the `CalPay()` method, you might want to assign the value to a double variable `grossPay`, and as in the following statement:

```csharp
grossPay = CalPay(myHours, myRate);
```

The `CalPay()` method returns a double, so it is appropriate to assign the returned value to a double variable. Figure 7-14 shows a program that uses the `CalPay()` method in the shaded statement, and Figure 7-15 shows the output.

```csharp
using static System.Console;
class UseCalcPay
{
    static void Main()
    {
        double myHours = 37.5;
        double myRate = 12.75;
        double grossPay;
        grossPay = CalPay(myHours, myRate);
        WriteLine("I worked {0} hours at {1} per hour", myHours, myRate);
        WriteLine("My gross pay is {0}", grossPay.ToString("C"));
    }
    private static double CalPay(double hours, double rate)
    {
        double gross;
        gross = hours * rate;
        return gross;
    }
}
```
