# Adding Labels and TextBoxes to a Form

When an application is running, the user can give focus to a component by clicking it or can switch from one component to another using the Tab key. The order in which controls receive focus from successive key presses is the tab order. By default, controls are assigned a tab order on the order in which you place them on a Form when designing a program. The first control you place on a Form has TabIndex 0, the next control has TabIndex 1, and so on. When you start a program, the control with TabIndex 0 automatically has focus. You can control a control's tab order by viewing its TabIndex in the Properties list of the IDE. If you do not want a control to be part of the tabbing sequence from a Form, you can change its TabStop property from true to false in the Properties list.

You can control your TabIndex value by entering the entry TabIndex in the Properties list of the IDE. Alternatively, you can select View from the menu bar and select Tab Order. You see a representation of the Form with a small number next to each control to represent the values. To change the focus order for the controls, simply click each control in the desired order. Select View and the Tab Order again to remove the blue numbers.
