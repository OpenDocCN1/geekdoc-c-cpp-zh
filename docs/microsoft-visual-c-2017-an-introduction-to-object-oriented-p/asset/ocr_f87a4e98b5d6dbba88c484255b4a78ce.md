# CHAPTER 10 Introduction to Inheritance

```
class CommissionEmployee : Employee
{
    private double commissionRate;
    public double CommissionRate
    {
        get
        {
            return commissionRate;
        }
        set
        {
            commissionRate = value;
            salary = 0;
        }
    }
    new public string GetGreeting()
{
        string greeting = base.Greeting();
        greeting += "\n work on commission.";
        return greeting;
    }
}
```

> Keyword new in method eliminates header compiler warning when base class is overridden

base.GetGreeting() to access the base class version of the method. Figure 10-16 shows an application that uses the method with a CommissionEmployee object. Figure 10-17 shows the output.

```
using static System.Console;
class DemoCommissionEmployee2
{
    static void Main()
    {
        CommissionEmployee salesperson = new CommissionEmployee();
        salesperson.IdNum = 345;
        WriteLine(salesperson.GetGreeting());
    }
}
```
