# CHAPTER 1 A First Program Using C#

One way to compile a program from Visual Studio is to select Build the menu bar and select Build Solution from the drop-down menu. As an alternative, you can press Ctrl + Shift + B. You can also select Debug from the menu bar, and then click Start Without Debugging. The advantage of the later option is that the program will be compiled if there no syntax errors and then execute you to see the output.

# What to Do If You Receive a Programming Language Error Message in the IDE

If you receive a syntax error into a program in the IDE, you receive a programming language error message. For example, in Figure 1-13, WriteLine is spelled incorrectly because it uses a lowercase w. The error message displayed at the bottom is: 'writeLine does not exist in the current context.' If you cannot read the entire message on your screen, you can adjust the size of the window. The position is given (project, file, and line number), and as additional visual aids, a lightbulb appears to the left of the error, and a wavy underline emphasizes the unrecognized definition. When you fix the problem and compile the program again, the error, wavy line, and lightbulb are eliminated.
