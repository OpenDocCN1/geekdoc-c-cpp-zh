To the left of some of the items in the Solution Explorer, you see a small triangle node. A node is an icon that can be used to expand or condense a list or a section of code (In Visual Studio, nodes appear as triangles, and others as small plus or minus signs). When a triangle-shaped node points straight to the right, you see a condensed view. Clicking the triangle reveals hidden items or code—the triangle points diagonally down to the right, and you see all the items in the list (or all the hidden code). Clicking the triangle again collapses the list so you can work with a condensed view.

If you expand Form1.cs node by clicking it, you see a file named Form1.Designer.cs. The Windows Form Designer automatically writes code in the Designer.cs file; the code created implements all the actions that are performed when you drag and drop controls from the Toolbox. You should avoid making manual changes to this file because you could easily corrupt a project.

When you create a Windows Forms project, Visual C# adds a form to the project and calls it Form1. After you click the Form in the Form Designer area, you can see the name of the form in the following locations as shown in Figure 3-3:

+   * On the Design tab of the Form Designer (followed by [Design])
* In the title bar of the form in the Form Designer
* In the Solution Explorer file list (with a .cs extension)
* At the top of the Properties window indicating that the properties are listed for Form1
* As the contents of the Text property listed within the Properties window
