The Carpet class contains one private method named CalcArea(). As you examine the
code in the TestCarpet class in Figure 9-15, notice that Width and Length are set using an
assignment operator but Area is not. The TestCarpet class can make assignments to Width
and Length because these properties are public. However, you would not want a client
program to assign a value to Area because the assigned value might not agree with the Width
and Length values. Therefore, the Area property is a read-only property—it does not contain
a setter, and no assignments by clients are allowed. Instead, when Width or
Length properties are changed, the private CalcArea() method is called from the accessor.
Area() method is defined as private because there is no reason for a client class
to call CalcArea(). Programmers probably create private methods more
frequently than they create public data fields. Some programmers feel that the best style is to
use public methods that are nothing but a list of method calls with descriptive names. Then,
t methods that actually do the work are all private.
