+   1. In Chapter 4, you created an interactive application named GreenvilleRevenue that prompts a user for the number of contestants this year's and last year's Greenville Idol competition and displays the revenue expected for this year's competition if each contestant pays a $25 entrance fee. +   2. Now, modify the program so that the user must enter a month value from 1 through 12. If the user enters an incorrect number, the program prompts for a valid value.
