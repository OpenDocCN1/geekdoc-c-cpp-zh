# Displaying Variable Values

You can display variable values using the variable name within a Write() or WriteLine() method call. For example, Figure 2-1 shows a C# program that displays the value of the variable someMoney. Figure 2-2 shows the output of the program when executed at the command prompt.

```
using static System.Console;
class DisplaySomeMoney
{
    static void Main()
{
        double someMoney = 39.45;
        WriteLine(someMoney);
    }
}
```

Figure 2-2 Output of the DisplaySomeMoney program

The output shown in Figure 2-2 is rather stark—just a number with no explanation. The program in Figure 2-3 adds some explanation to the output; the result in Figure 2-4 uses the Write() method to display the string "The money is $\$ before displaying the value of someMoney. Because the program uses Write() instead of WriteLine() for the first output, the second output appears on the same line as the first.

```
using static System.Console;
class DisplaySomeMoney2
{
    static void Main()
{
        double someMoney = 39.45;
        Write("The money is $\$");
        WriteLine(someMoney);
    }
}
```
