# GLOSSARY

block—A collection of one or more statements contained within a pair of curly braces.

call stack—The memory location where the computer stores the list of locations to which the system must return after method calls.

block comments—Comments that start with a forward slash and an asterisk ( / ) and end with an asterisk and a forward slash ( * ). Block comments can appear on a line by themselves, on a line before executable code, or after extend across as many lines as needed. Compare with line comments.

called—Describes a method that has been invoked.

called method—A method that has been invoked by another method.

calling method—A method that calls another method.

camel casing—A style of creating identifiers in which the first letter is not capitalized, but each new word is. Contrast with Pascal casing.

bool—A type that holds a Boolean value.

case label—Identifies a course of action in a switch statement.

Boolean logical operator—An operator that determines whether two expressions are true; or is written using a single ampersand (& ), but unlike the conditional OR operator, it does not use short-circuit evaluation.

catch block—A block of code that can catch one type of Exception.

Boolean inclusive OR operator—An operator that determines whether at least one of conditions is true; it is written using a single pipe (| but unlike the conditional OR operator, it does not use short-circuit evaluation.

char—An integer data type that can store a character such as 'A', '4', or '$'; char values are written between single quotes.

character—Any one of the letters, numbers, or other special symbols (such as punctuation marks) that comprise data.

Boolean variable—A variable that can hold only one of two values: true or false.

character set—The group of all the characters used to represent data on a particular computer.

bugs—Program errors.

check box—A GUI widget that a user can click to select or deselect an option.

byte—An integral data type that can hold an unsigned numeric value from 0 through 255.

child class—A derived class; subclass; a class that has inherited from a base class.

# C

C# programming language—A programming language developed as an object-oriented and component-oriented language. It exists as part of Visual Studio, a package used for developing applications for the Windows family of operating systems.

class—A category of objects or a type of object.

class access specifies—Describes access to a class.

class client—A program or class that instances objects of other rewritten class. Also called a class user.

call—To invoke a method.
