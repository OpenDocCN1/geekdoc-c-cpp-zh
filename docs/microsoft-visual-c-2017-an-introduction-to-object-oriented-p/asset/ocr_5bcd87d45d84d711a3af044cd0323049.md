+   12. Create a project named LetsADeal. In this game, three prizes of varying value are assigned randomly to be hidden behind "doors" that you can implement Buttons. For example, the prizes might be a new car, a big-screen TV, and a live goat. The player chooses a Button, and then one of the other two prizes is revealed: the most desirable prize. The user then has the option of changing the original selection to the remaining unseen choice. For example, consider these two game scenarios.
    * That the most valuable prize is randomly assigned to the first button. If the user chooses the first button, reveal either of the other two prizes, and ask the user he wants to change his selection.
    * That the most valuable prize is assigned to the first button, but the user chooses the second button. Reveal the third prize so that the most valuable prize's location is still hidden, and ask the user whether he wants to change his selection.

After the user has chosen to retain his original selection or make a change, reveal what he has won.
