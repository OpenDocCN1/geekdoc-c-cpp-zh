| SizeMode | Description |
|---|---|n| Normal | The Image is positioned in the upper-left corner of the PictureBox; if the Image is too large, it is clipped. |
| StretchImage | The Image is stretched or shrunk to fit the PictureBox, but the aspect ratio is not maintained. |
| Zoom | The Image is stretched or shrunk to fit the PictureBox, but the aspect ratio is maintained. |
| AutoSize | The PictureBox is resized (rather than the Image). |
| CenterImage | The Image is centered in the PictureBox; if the Image is too large, it is clipped. |
