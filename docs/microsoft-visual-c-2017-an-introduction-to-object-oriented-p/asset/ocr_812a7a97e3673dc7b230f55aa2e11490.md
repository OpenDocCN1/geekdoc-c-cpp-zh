# CHAPTER 14 Files and Streams

The program in Figure 14-18 is intended to demonstrate the Seek() method. In a business setting, you might prefer not to leave a file open in one application if other users might be waiting for it. As an alternative, you could load all the records into an array and search the array for desired records. Problems also exist with this approach because you might overestimate the number of records in the file to create an array large to hold them.

When you seek the length of the file, you do not cause an error. Instead, the file size grows. In Microsoft Windows NT and later, any data added to the end of a file is set to zero. In Microsoft Windows 98 or earlier, any data added to the end of the file is not set to zero. This means that previously deleted data might become visible to the stream.
