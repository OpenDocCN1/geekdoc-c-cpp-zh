# CHAPTER 3 Using GUI Objects and the Visual IDE

You can drag controls onto a Form where you think they will be most useful or contribute to a pleasing design. After a control is on a Form, you can relocate it by dragging it, or delete the control by selecting and pressing the Del key on your keyboard. You can also delete a control by right-clicking and selecting the Delete option from the menu that appears. In Figure 3-5, the programmer has dragged a button onto the Form. By default, its Name is button1. You might guess that if you drag a second Button onto the Form, its Name automatically becomes button2.) In a professional application, you would probably want to change the Name property of the Button to a unique and memorable identifier.

In Figure 3-5, the programmer has clicked button1, the Properties window shows the properties for button1. (If you click the Button, the Properties window changes to show Form properties instead of Button properties.) The Text property of button1 has been changed to OK, and the Button on the Form has handles that can be used to resize. You can scroll through the Properties list and examine other properties that can be modified for the Button. For example, you can change its BackColor, Fore, Font, and Size. Table 3-2 describes a few

| Property Name | Description |
| --- | --- |
| BackColor | Gets or sets the background color of the control |
| Enabled | Gets or sets whether the control is enabled |
| Font | Gets or sets the current font for the control |
| ForeColor | Gets or sets the foreground color of the control |
| Name | Gets or sets the name of the control |
| Size | Gets or sets the size of the control |
| Text | Gets or sets the text associated with the control |
| Visible | Gets or sets a value indicating whether the control is visible |
