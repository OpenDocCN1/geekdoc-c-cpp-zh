Within a functioning loop’s body, you can change the value of the loop control variable in a number of ways. Many loop control variable values are altered by incrementing, or adding to them, as in Figures 5-2 and 5-3. Other loops are controlled by reducing, or decrementing, a variable and testing whether the value remains greater than some benchmark value.

A loop for which the number of iterations is predetermined is called a definite loop or counted loop. Often, the value of a loop control is not altered by arithmetic but instead is altered by user input. For example, perhaps you want to continue performing some task while the user indicates a desire to continue. In that case, you do not know when you write the program whether the loop will be executed twice, 200 times, or not at all. This type of loop is an infinite loop.

Consider a program that displays a bank balance and asks the user wants to see what the balance will be after one year of interest has accumulated. Each time the user indicates wants to continue, an increased balance appears. When the user finally indicates she has had enough, the program ends. The program appears in Figure 5-7, and a typical execution appears in Figure 5-8.

```
using System;
using System.Console;
class LoopingBankBal
{
    static void Main()
    {
        double bankBal = 1000;
        const INT_RATE = 0.04;
        string inputString;
        char response;
        Write("Do you want to see your balance? Y or N...");
        inputString = ReadLine();
        response = Convert.ToChar(inputString);
        while (response == 'Y')
        {
            WriteLine("Bank balance is {0}",
            bankBal.ToString(""));
            bankBal = bankBal * INT_RATE;
            Write("Do you want to see next year's balance? Y or N...");
            inputString = ReadLine();
            response = Convert.ToChar(inputString);
        }
        WriteLine("Have a nice day!");
    }
}
```

The program in Figure 5-7 continues to display bank balances while the response is Y. It could also be written to display when the response is not N, as while(response != 'N')...A value such as 'Y' or 'N' that a user must supply to stop a loop is a sentinel value.

In the program in Figure 5-7, the loop control variable is response. It is initialized by the first input and tested with the Boolean expression response=='Y'. If the user uses any character other than Y, the loop body never executes; the next statement to executes Have a nice day! instead, if the user enters Y, then all five statements in the loop body execute. The current balance is displayed, and the program increases the balance by the interest rate; this value will not displayed unless the user requests another loop repetition. Within the loop, the program prompts the user and reads in a new value for response. This input statement is the one potentially alters the loop control variable. The loop ends with a closing curly brace, and program control returns to the top of the loop, where the Boolean expression is tested again. If the user used Y at the last post, then the loop is reentered, and the increased bankBal value that was calculated during the last cycle is displayed.

In C#, character data is sensitive. If a program tests response=='Y', a user response will result in a false evaluation. Beware of the pitfall of writing a loop similar to while(response != 'Y')... to test both for uppercase and lowercase versions of the response. Every character is either Y or not y, even Y and y. A correct loop might begin with the following:

```
while(response != 'Y' && response != 'y').
```

## Creating Loops with the while Statement

## TWO TRUTHS & A LIE

- 1. To make a while loop that executes correctly, a loop control variable is initialized before entering the loop.
- 2. To make a while loop that executes correctly, the loop control variable is tested in the while expression.
- 3. To make a while loop that executes correctly, the body of the while statement must never alter the value of the loop control variable.

> The false statement is #3. To make a while loop that executes correctly, the body of the while statement alters the value of the loop control variable.
