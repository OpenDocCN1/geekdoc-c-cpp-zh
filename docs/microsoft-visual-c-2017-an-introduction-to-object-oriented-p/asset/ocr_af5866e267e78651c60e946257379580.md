In C#, a string is **immutable**. That is, when you assign a new value to it, if you write name "Amy" followed by name "Donald"; the first literal string of characters, Amy, still exists in computer memory, but the variable no longer refers to string's memory address. Instead, name refers to a new address where the characters are stored. Programmers might say that name now points to the new address. The situation is different from that when you assign a new value to a numeric variable, the value at the named memory address actually changes, replacing the original value.

The comparisons made by the **Equals()**, **Compare()**, and **CompareTo()** methods are case sensitive. In other words, **Amy does not equal any**. In Unicode, the decimal value of uppercase letter is exactly 32 less than its lowercase equivalent. The decimal value of a Unicode **a** is 97 and the value of **A** is 65.

You can use the **Length** property of a string to determine its length. For example, suppose you declare a string as follows:

```
string word = "water";
```

The value of **word.Length** is 5. Notice that **Length** is not a method and that it is not followed with parentheses.

The **Substring()** method can be used to extract a portion of a string from a starting point or specific length. For example, Figure 2-19 shows a string that contains the word **water**. The first character in a string is at position 0, and the last character is at position **Length - 1**.

Therefore, if you declare **string word = "water";**, each of the first five expressions in the figure produces an error message because the combination of the starting position and length attempt to access values outside the range of the string.

The **StartsWith()** method determines whether a string starts with the characters in the string that is used as an argument. For example, if **word** is "water", the expression **word.StartsWith("wa")** is true, and the expression **word.StartsWith("waet")** is false.
