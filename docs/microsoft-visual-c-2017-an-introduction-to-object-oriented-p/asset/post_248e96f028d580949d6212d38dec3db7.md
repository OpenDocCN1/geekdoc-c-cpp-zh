## Variable Alignment

When you use a WriteLine() statements to display a list of variable values, the values are not automatically right-aligned as you normally expect numbers to be. For example, the following code produces the unaligned output in Figure 2-8:

```cs
WriteLine("{0", 4);
WriteLine("{0", 56);
WriteLine("{0", 789);
```

If you use a second number within the curly braces in a format string, you can specify alignment and field size. By default, numbers are right-aligned in their fields. If you use a negative value for the field size in a Write() or WriteLine() statement, the displayed value will be left-aligned in the field. Most often, you want numbers to be right-aligned and string values to be left-aligned. For example, the following code produces the output in Figure 2-9. The output created by each of the first three WriteLine() statements is right-aligned in a field that is five characters, and the output created by each of the last three is left-aligned strings in a field of eight characters.

```cs
WriteLine("{0, 5}", 4);
WriteLine("{0, 5}", 56);
WriteLine("{0, 5}", 789);
WriteLine("{0, -8}", "Richard", "Lee");
WriteLine("{0, -8}", "Marcia", "Parker");
WriteLine("{0, -8}", "Ed", "Tompkins");
```

## Using the Integral Data Types

In C#, nine types are considered integral data types—that is, types that store whole numbers. The nine types are byte, sbyte, short, ushort, int, uint, long, char. The first eight represent whole numbers, and the ninth type, char, is used for characters as A or period. Actually, you can think of all nine types as numbers because Unicode character, including the letters of alphabet and punctuation marks, can be represented as a number. For example, the character A is stored within your computer as 65. Because you more commonly think of the char type as holding alphabetic characters instead of their numeric values, the char type will be discussed in this section later in this chapter.

The most basic of each integral type is int. You use variables of int to store (or hold) integers, or whole numbers without any fractional part. An int uses four bytes of memory and can hold any number ranging from 2,147,483,647 to -2,147,483,648. When you use a whole-number such as 589 in a C# program, by default it is an int.

If you want to save memory and know only a small value, you can use one of the shorter types—byte, sbyte (stands for signed byte), short (int), or ushort (unsigned short). For example, a payroll program might contain a variable name numberOfDepend that is declared as byte, because numberOfDepend will never need to exceed 255; for that reason, you can allocate just one byte of storage. Many programmers simply use int for most numbers.

Saving memory is seldom an issue for an application that runs on a PC. However, when you write applications for small devices with limited memory, such as smartphones, conserving memory becomes important. The word integer has only one r—at the end. Pronouncing it as "inter-ger," with an r in the middle will mark you as unprofessional.

When you assign a value to any numeric variable, you do not use commas or other nonnumeric characters like dollar or percent signs; you use only digits. The exception is that, starting with C# 7.0, you can insert underscores as digit separators for readability. For example, the two declarations are identical, but you might find one easier to read:

```cs
int aLotMoney = 23456789;
int aLotMoney = 23_456_789;
```

You can also use a plus or minus sign to indicate a positive or negative integer; a value without a sign is assumed to be positive. For example, to initialize a variable annualSalary you might write the following with a dollar sign or comma:

```cs
int annualSalary = 20000;
```
