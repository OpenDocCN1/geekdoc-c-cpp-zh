## Working with a Form's Layout

When you place Controls on a Form in the IDE, you can drag them to any location to achieve the effect you want.

When you drag multiple Controls onto a Form, snap lines appear and help you align new Controls with others in place. Figure 12-29 shows snap lines that you can use to align a second label below the first one. Snap lines also appear when you place a control closer to the edge of a container than is recommended.

You can also use the Location property in Control's Properties list to specify a location. With either technique, code like the following is generated: this.label1.Location = new System.Drawing.Point(23, 19);

Other properties can help you to manage the appearance of a Form (or ContainerControl). For example, setting the Anchor property causes a Control to remain at a fixed distance from the side of a container when the user resizes it. Figure 12-30 shows the properties when a Label that has been placed on a Form. The Anchor property has a drop-down window that lets you select or deselect the sides to which the label should be anchored. For Controls, the default setting for Anchor is Top, Left.

## Understanding GroupBoxes and Panels

Many types of ContainerControls are available to hold Controls. For example, a group box or panel can be used to contain a group of other controls and to move them as a group. To create either of Controls, you drag it from the Toolbox in the IDE and then drag the Controls on top of it. In C#, a group box and a panel differ in the following ways:

- A group is created from the GroupBox class, and a panel is created from the Panel class.
- GroupBoxes display a caption, but Panels cannot.
- Panels can include a scroll bar that the user can manipulate to view Controls; GroupBoxes do not have scroll bars.

You can anchor or dock Controls inside a GroupBox or Panel, and you can anchor or dock GroupBox or Panel inside a Form. Doing this provides Control groups that can be arranged easily.

If you place several GroupBox Controls on a Form and several RadioButtons in each GroupBox, then a user can select one RadioButton from each GroupBox instead of being able to select just one RadioButton from a Form. In other words, GroupBox operates independently.

> When an application contains multiple GroupBox or Panel on a Form, pressing Tab moves the focus to the next GroupBox or Panel. Then, within the menu, you use arrow keys to progress.

## Adding a MenuStrip to a Form

Many programs you use in a Windows environment contain a menu strip, which is a horizontal list of general options that appears below the title bar. When you click an item in a menu strip, you initiate an action. For example, the Visual Studio IDE contains a menu strip that begins with the options File, Edit, and View.

You can add a MenuStrip object to any Form you create. Using the Visual Studio IDE, you can add a MenuStrip to a Form by dragging it onto the Form. This creates a menu bar horizontally across the top of the Form, just below the title bar. The strip extends across the width of the Form and contains boxes. When you click the text box, you can enter a menu item. Each time you add a menu, boxes are created so you can see where your next options will go, as shown in Figure 12-34.

![](img/7516c1fecf7bbbe7afb10cf209b17ae3_604_0.png)

**Figure 12-34** Creating a Form with a MenuStrip

> If you do not see MenuStrip in your Toolbox, click the Menu & Toolbars group to expose it. You can click the MenuStrip icon at the bottom of the screen view to change the properties for the MenuStrip. For example, you might want to change the Font or BackColor for the MenuStrip.

Earlier in this chapter, you learned how to create an access key for a Button. Similarly, if you create each menu item with an ampersand (&) in front of a unique letter, the letter becomes an access key, and the user can press Alt and the letter to activate the menu. For example, if two colors were Green and Gray, you might want to type &Green and G&Gray so you could type Alt+G to select Green and Alt+R to select Gray.
