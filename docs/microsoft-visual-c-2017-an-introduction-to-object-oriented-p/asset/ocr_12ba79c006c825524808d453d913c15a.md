# Using the char Data Type

You use the char data type to hold any single character. You place constant character values within single quotation marks because the computer stores characters and integers differently. For example, the following statement assigns D to initial:

```
char initial = 'D';
```

A number can be a character, in which case it must be enclosed in single quotation marks and declared as a char type, in the following:

```
char aValue = '9';
```

When you store a char as '9' as a character, you cannot use it in ordinary arithmetic statements. If the value of 9 is needed for arithmetic, you should store it within quotes as a numeric type, such as int.

A type of char can hold only one character, and a literal is written using single quotation marks. To store a string of characters, you must use a string; a literal string is written using double quotation marks. You will learn about strings later in this chapter.

You can store any character—nonprinting characters such as a backspace or tab—in a char variable. To store these characters, you use two symbols in an escape sequence, which always begins with a backslash. The pair of symbols represents a single character. For example, the following code stores a space character and a tab character in the variables aBackSpaceChar and aTabChar, respectively:

```
char aBackSpaceChar = '\b';nchar aTabChar = '\t';
```

In the preceding code, the escape sequence indicates a unique value for each character—a backspace or tab instead of the letter b or t. Table 2-5 describes some escape sequences that are used in C#.
The characters used in C# are represented in Unicode, which is a 16-bit coding scheme for characters. For example, the letter A is stored in memory as a set of 16 zeros and one—namely 0000 0000 0100 0001 (The spaces are inserted here after every set of four digits for readability.). Because 16-bit numbers are difficult to read, programmers often use a notation called hexadecimal, or base 16. In hexadecimal shorthand, 0000 becomes 0, and 0101 becomes 1. Thus, the letter A is represented in hexadecimal as 00041. You tell the compiler to treat the \u four-digit hexadecimal 0041 as a single character by preceding it with the \u escape sequence. Therefore, there are two ways to store the character A:

```
char letter = 'A';nchar letter = '\u0041';
```
