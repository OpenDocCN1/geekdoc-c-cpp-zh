In the application Figure 5-18, it is very important that the total variable used for accumulation is set to 0 before the loop begins. Then the program will not compile. An unknown, unassigned value is known as garbage. The C# compiler prevents you from seeing an incorrect total by providing you a starting value; C# will not use the garbage value that happens to be stored at an uninitialized memory location.
