# CHAPTER 2 Using Data

In Chapter 1, you learned about programming in general and the C# programming language in particular. You wrote, compiled, and ran a C# program that produced output. In this chapter, you build on your basic C# programming skills by learning how to manipulate data and use types, variables, and constants. As you will see, using variables to hold data makes programs flexible.

# Declaring Variables

A item is constant when it cannot be changed after a program is compiled—in other words, it cannot vary. For example, if you use the 347 in a C# program, then 347 is a constant, and every time you execute the program, the value 347 will be used. You can refer to the number 347 as a literal constant because no name is associated with it. Later in this chapter you will learn about named constants.

On the other hand, when you want a data item's value to be changeable, you can create a variable. As you learned in Chapter 1, a variable is a named location in memory that can hold different values at different points in time. For example, if you create a variable named heatingBill and include it in a C# program, heatingBill might contain the value 347, or it might contain 200. Different values might be used at different times during a single program execution. Because you can use a variable to hold heatingBill within a program used by a utility's automated billing system, you can write set of instructions to compute heatingBill, use different heatingBill values for thousands of utility customers.

Whether it is constant or a variable, each data item used in a C# program has a data type. A data type defines the format and size of (amount of memory occupied) by a data and defines what types of operations can be performed with it. C# provides for 15 basic, or intrinsic types, as shown in Table 2-1. These built-in types, the most commonly used are double, decimal, string, and bool. Each intrinsic type is an alias, or other name, for a class in the System namespace. (You learned about the System namespace in Chapter 1.) All of the built-in types except object string are simple types.

The meaning of the smallest and largest values for the types in Table 2-1 is probably clear to you, but some of the other values require explanation.

+   - The highest char value, 0xFFFF represents the character in which every bit is on. The lowest value, 0x0000, represents the character in which every bit is off. Any value that begins with 0x represents a hexadecimal, or base 16, value.

+   - For two strings, the one with the higher Unicode character value for every character is considered higher. Unicode is the system that provides a numeric value for every character. You will learn more about Unicode later in this chapter, and Appendix B contains further information.) For example, "AAB" is higher than "AAA". The string has no minimum; however, you can think of the string "" as being the lowest.
