# Programming Exercises

1. Create an application class named LetterDemo that instantiates objects of two classes named Letter and CertifiedLetter and demonstrates all their methods. The classes are used by a company to track letters they may mail to clients. The Letter class includes auto-implemented properties for the name of the recipient and the date mailed. Also, include a ToString that overrides the Object class's ToString and returns a string that contains the name of the class (using GetType()) and the Letter's data field values. Create a child class named CertifiedLetter that includes an auto-implemented property that holds a tracking number for the letter.

2. Create an application class named PhotoDemo that demonstrates the methods of three related classes for a company that develops photographs. Create a class named Photo that includes fields for width and height in inches and properties for each field. The class includes a protected price field, and set it to $3.99 for an 10-inch photo, $5.99 for a 10-by-12-inch photo, and $9.99 for any other size (because custom cutting is required). The price field requires a getter but no setter. Also include a ToString method that returns a string constructed from the return value of the object's GetType() method and the values of fields. Derive two subclasses—MattedPhoto and FramedPhoto. The MattedPhoto includes a string field to hold a color, and the FramedPhoto class includes two strings that hold the frame's material (such as silver) and style (such as modern). The price for a MattedPhoto increases by $10 over its base cost, and the price for a FramedPhoto increases by $25 over its base cost. Each subclass should include a ToString that overrides the parent class version.
