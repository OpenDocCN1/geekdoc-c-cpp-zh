+   * A double data type can hold 15 or 16 significant digits of accuracy. For example, a double given the value 123456789.987654321 will appear as 123456789.9876544 because it is accurate up to the fifteenth digit (the sixth digit to the right of the decimal point).

+   * Compared to floats and doubles, the decimal type has a greater precision and a smaller range, which makes it suitable for financial and monetary calculations. A decimal is significant to 28 or 29 digits. As Table 2-1 shows, a decimal cannot hold as large as a double (the highest value is about 10^38; the highest value of a double is 10^308), but the decimal will be more accurate to more decimal places.

Just as an integer is an int by default, a floating-point number is a double by default. To explicitly state a constant as a float, use an F (either lowercase or uppercase) after the number, as in the following:

```
float priceChange = 4.87f;
```

You can place a D (or d) after a floating-point value to indicate that it is a double; even without the D, however will be stored as a double by default. To explicitly store a value as a decimal, use an M (or m) after the number. (M stands for monetary; D cannot be used for a decimal because it indicates double.)

> > Monetary values are extremely important in business applications, C# developers frequently use the decimal type for floating-point values because floating-point numbers are double by default and do not require a modifier letter after the number. However, you should use the type that your instructor or manager decides or the type that is most appropriate for your application. Some programmers use the decimal type for any measurement created by humans (for example, money or tests score) and double for measurements of naturally occurring phenomena (for example, halves of elements).

If you store a value that is too large (or too small) in a floating-point variable, you will see output expressed in scientific notation include an E (for exponent). For example, if you declare float f = 1234567890; the output is as 1.2345679E+9, the numeric constant used is approximately 1.2345678 to the tenth power, or 1.234568 with the decimal point moved nine positions to the right. When the value E is negative, it means the value is very small and the decimal point should move to the left. For example, the value 1.234E-07 represents 0.0000001234.

# Formatting Floating-Point Values

By default, C# always displays floating-point numbers in the most concise way possible that maintains the correct value. For example, if you declare a variable and display it in the following statements, The amount is 14.

```
double myMoney = 14.00;
WriteLine("The amount is {0}", myMoney);
```
