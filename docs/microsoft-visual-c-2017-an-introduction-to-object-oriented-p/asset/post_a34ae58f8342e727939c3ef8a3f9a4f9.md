# Passing Array Values to a Method

Passing an array element to a method and passing an array to a method require different approaches.

## Passing a Single Array Element to a Method

In the chapter "Using Arrays," you learned that you can declare an array to create a list of elements, and you can use any individual array element in the same manner as you use any single variable of the same type. That, suppose you declare an integer array as follows:

```
int[] someNums = new int[12];
```

You can subsequently output someNums[0] or add 1 to someNums[1], just as you would for any integer. Similarly, you can pass a single array element to a method in exactly the same manner as you would pass a variable.

Consider the program shown in Figure 7-17. This program creates and uses an array of four integers. Figure 7-18 shows the program's execution.

```c
using static System.Console;
class PassArrayElement {
    static void Main() {
        int[] someNums = {10, 12, 22, 35};
        int x;
        Write("\nBeginning of Main() method... ");
        for(x = 0; x < someNums.Length; ++x)
            Write("{0,}", someNums[x]);
        WriteLine();
        for(x = 0; x < someNums.Length; ++x)
            MethodGetsOneInt(someNums[x]);
        Write("At end of Main() method....... ");
        Write("{0,}", someNums[x]);
    }
    private static void MethodGetsOneInt(int oneVal) {
        Write("In MethodGetsOneInt() {0}", oneVal);
        oneVal = 999;
        WriteLine("After change {0}", oneVal);
    }
}
```

As you see in Figure 7-18, the program displays the four original values, passes each to the MethodGetsOneInt(1) method, where it is displayed and then changed to 999. After the method executes four times, the Main() method verifies that they are unchanged by the assignments within MethodGetsOneInt(1). The oneVal variable is local to the MethodGetsOneInt(1) method; therefore, changes passed into the method are not permanent and are not reflected in the array declared in the Main() method. Each time the MethodGetsOneInt(1) method executes, its oneVal parameter holds only a copy of the array element passed into the method, and the oneVal variable exists only while the MethodGetsOneInt(1) method is executing.

## Passing an Array to a Method

Instead of passing a single element to a method, you can pass an entire array. You indicate that a parameter must be an array by placing square brackets around the data type in the method's parameter list. When you pass an array to a method, changes you make to elements within the method are reflected in the original array that was sent to the method. Memory address is also known as **reference**. Arrays, like objects but unlike built-in types like double and int, are passed **by reference**. When a simple int is passed to a method, it is passed **by value**. However, the method receives a copy of the value at a new memory address. However, when an array is passed to a method, the method receives the actual memory address of the array and has access to the actual values in the array elements. You have already seen that methods can alter arrays passed to them. When you used the Sort() and Reverse() methods in Chapter 6, you saw that they changed their array parameter contents.

The program in Figure 7-19 creates an array of four integers. For the integers displayed, the array is passed to a method MethodGetsArray() in the shaded statement. In the method header, the parameter is declared as an array by using square brackets after the data type. With the method, the numbers are output, which show that they return their values from Main() upon entering the method, but then the value 888 is assigned to each number. Even though GetsArray() is a void method (meaning nothing is returned to the Main() method), when the program displays the array for the second time in Figure 7-20. Because arrays are passed by reference, the MethodGetsArray() method "knows" the array declared in Main() and makes changes directly to the original array that was declared in the Main() method.

```csharp
using static System.Console;
class PassEntireArray
{
    static void Main()
    {
        int[] someNums = {10, 12, 22, 35};
        int x;
        Write("\nBeginning of Main() method... ");
        for(x = 0; x < someNums.Length; ++x)
            Write("{0,}", someNums[x]);
        WriteLine();
        MethodGetsArray(someNums);
        Write("At end of Main() method....... ");
        Write("{0,}", someNums[x]);
    }

    private static void MethodGetsArray(int[] vals)
    {
        Write("\nBeginning of Main() method... ");
        for(int i = 0; i < vals.Length; ++i)
        {
            Write("In MethodGetsArray() {0}", vals[i]);
            vals[i] = 888;
            WriteLine("After change {0}", vals[i]);
        }
    }
}
```
