# CHAPTER 12 Using Controls

The statements that follow the Property Form for label are similar, but they define the properties of the Button on the Form. The TabIndex for the Button is set to 1 because it was dragged onto the Form after the Label. Additional Controls would receive consecutive TabIndex values.

+   * InitializeComponent() ends with statements that set the properties of the Form, such as adding drawing size and text, and then, the following statements add the Label and Button to the Form:
this.Controls.Add(this.Button);
this.Controls.Add(this.label);

In this chapter, you will learn about several Controls. When designing a Form, you should use the drag-and-drop features in the IDE to place components and use the Properties window in the IDE to set properties instead of typing statements in the code editor. However, this chapter also teaches you about the code behind these actions you can troubleshoot problems in projects and write usable statements when necessary.
