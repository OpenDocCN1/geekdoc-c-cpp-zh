+   3. Create a program FindSquareRoot that finds the square root of a user's input value. The Math class contains a static method Sqrt() that accepts a double and returns the parameter's square root. If the user's entry cannot be converted to a double, display an appropriate message, and set the square root value to 0. Otherwise, test the number input value. +   4. Create a program StudentGradeDemo that attempts to create several valid and invalid ReportCard objects. Immediately after each instantiation attempt, handle any exceptions by displaying an error. Create a ReportCard class with four fields for a student name, a numeric midterm grade, a numeric final exam grade, and letter grade. The ReportCard constructor requires values for the midterm grade and determines the letter grade. Upon construction, throw an ArgumentException if the midterm or final exam is less than 0 or more than 100. The letter grade is based on the arithmetic average of the midterm and final exams using a grading scale of A for an average of 90 to 100, B for 80 to 90, C for 70 to 80, D for 60 to 70, and F for an average below 60. Display all the data if the instantiation is successful.

+   5. Create a program BookException for theing Publishing Company. Create a BookException class that is instantiated when a Book's price exceeds 10 cents per page and whose constructor requires three arguments for title, price, and number of pages. Create an error message that is passed to the Exception class constructor for the Message property when a Book does not meet the price-to-pages ratio. For example, an error might be:

> For Good Night, ratio is invalid.
...Price is $12.99 for 25 pages.

Throw a BookException if a client program tries to construct a Book object for which the price is more than 10 cents per page. Create a program that creates at least four Book objects—some where the ratio is acceptable, and others where it is not. Catch any exceptions, and display the BookException Message.

To handle any exceptions that are thrown because of improper or invalid data entered by the user, set the Book's price to the maximum of 10 cents per page. At the end of the program, display all the entered, and possibly corrected, records.
