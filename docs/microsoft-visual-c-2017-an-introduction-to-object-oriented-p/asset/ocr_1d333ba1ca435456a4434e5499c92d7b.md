# Using Arithmetic Operators

Table 2-3 describes the five commonly used arithmetic operators. You use these operators to manipulate values in your programs. The values that operators use in expressions are called operands. These arithmetic operators are called binary operators because you use two operands with each—one value to the left of the operator and another value to the right of.

| Operator | Description | Example |
| --- | --- | --- |
| + | Addition | 45 + 2: the result is 47 |
| | Subtraction | 45 - 2: the result is 43 |
| * | Multiplication | 45 * 2: the result is 90 |
| / | Division | 45 / 2: the result is 22 (not 22.5) |
| % | Remainder (modulus) | 45 % 2: the result is 1 (that is, 45 / 2 = 22 with a remainder of 1) |

Unlike some other programming languages, C# does not have an exponential operator. Instead, you can use the built-in Math.Pow() that you will learn about in the chapter "Introduction to Methods."

The operators / % deserve special consideration. When you divide by two numbers at least one is a floating-point value, the answer is a floating-point value. For example, 45.0 / 2 is 22.5. When you divide using the / operator, whether they are integer or constant variables, the result is an integer; in others, any fractional part of the result is lost. For example, the result of 45 / 2 is 22, not 22.5.

When you use the remainder operator with two integers, the result is an integer with the value of the remainder after division takes place—so the result of 45 % 2 is 1 because 2 "goes into" 45 twenty-two times with a remainder of 1. Remainder operations should not be performed with floating-point numbers. The results are unpredictable because of the way floating-point numbers are stored in computer memory.

> In older languages, as assembly languages, you would had to perform division before you take a remainder. In C#, performing a division operation is not necessary before using a remainder operation. In other words, a remainder operation can stand alone.

> You might have programmers refer to the remainder operator as the modulus operator. Although modulus has a similar meaning to remainder, there are differences.
