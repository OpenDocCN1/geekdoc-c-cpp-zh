# Decision-Making Issues in GUI Programs

Making a decision within a method in a GUI application is no different from making one in a console application; you can use if, if...else, and switch statements in the same ways. For example, 4-25 shows a GUI Form that determines a movie patron discount as described in a program earlier in this chapter. Patrons are 12 younger or 65 or older seeing a G-rated movie receive a discount, and any other combination pays full price. Figure 4-26 contains the Click() method that determines the discount rate based on age and rating after a user clicks the Discount button. The Boolean expression tested in the if statement in this method is identical to the one in the console version of the program in Figure 4-16.

![](bbox=[0.114, 0.298, 0.473, 0.597])

Figure 4-25 The Movie Discount Form

```
private void DiscountButton_Click(object sender,
    EventArgs e)
{
    int age;
    char rating;
    const int CHILD_AGE = 12;
    const int SENIOR_AGE = 65;
    age = Convert.ToInt32(textBox1.Text);
    rating = Convert.ToChar(textBox2.Text);
    outputLabel.Text = String.Format(
        "When age is {0} and rating is {1}", age, rating);
    if ((age <= CHILD_AGE || age >= SENIOR_AGE) && rating == 'G')
        outputLabel.Text += "\ndiscount applies";
    else
        outputLabel.Text += "\nFull price";
}
```
