
# GLOSSARY

**side effect**—An unintended consequence of an operation.

**signature**—A method's name and parameter list.

**significant digits**—Specify the mathematical accuracy of a value.

**simple type**—Describes one of the following in C#: byte, sbyte, short, ushort, int, uint, long, double, decimal, char, and bool.

**single-dimensional array**—An array whose elements are accessed using a single subscript. See *one-dimensional array*.

**snaps lines**—Lines that appear in a design environment to help align controls with others that are already in place.

**software**—Computer programs.

**source code**—Program statements.

**standard numeric format strings**—Strings of characters expressed within double quotation marks that indicate a format for output.

**state of object**—The collective value of all of an object's attributes at any point in time.

**static**—A keyword that indicates that a method will be executed through a class and not by an object.

**step value**—The amount by which a loop variable is altered on each iteration, especially in a for loop.

**stream**—A pipeline or channel through which bytes are input from and output to a file.

**string**—A data type that can hold a string of characters.

**string interpolation**—The process of replacing string place holders with values; called *variable substitution*.

**subclass**—A derived class; a class that has inherited from a base class.

**subscript**—An integer within square brackets that dictate the position of one of an array's elements. Also see *index*.

**suggestion mode**—An IDE editing mode in which completion is turned off.

**superclass**—A base class; a parent class; a class that is for the inheritance.

**switch structure**—A structure that tests a single variable against a series of exact matches.

**syntax**—The set of grammar rules in a programming language.

**syntax error**—An error that occurs when programming language is used incorrectly.

# T

**tab order**—The sequence of controls selected when the user presses the Tab key in a program with a GUI interface.

**ternary**—Describes an operator that requires three arguments.

**TextBox**—Controls through which a user can input data in a GUI application.

**text files**—Files that contain data that can be read in a text editor using a scheme such as ASCII or Unicode.

**this reference**—The reference to an object that is implicitly passed to an instance method of its class.

**token**—A block of text within a string that represents an entity or field.

**upper camel casing**—A style of creating identifiers in the first letter of all words in a name is capitalized, even the first one; Pascal casing.

**transitive**—Inheriting all the members of one's ancestors.

**ushort**—An integral data type that can hold an unsigned numeric value in two bytes.

**triggers an event**—Causes an event to occur. Also see fires an event and raises an event.

**using clause, or using directive**—code that declares a namespace.

**true tables**—Diagrams used in mathematics and logic to describe the truth of an entire expression based on the truth of its parts.

# V

**try block**—A block of code that might create exceptions that will be handled.

**value parameter**—A parameter to a method that receives a copy of the value passed to it. Contrast with reference parameter and output parameter.

**two-dimensional arrays**—Multidimensional arrays that have two or more columns of values for each row.

**value types**—Data types that hold a value; they are predefined types such as int, double, and char. Contrast with reference type.

**type precedence**—A hierarchy of types used to determine the unifying type in arithmetic expressions containing dissimilar data types.

**variable**—A named location in memory that can hold different values at different points in time during program execution.

# U

**uint**—An integral data type that can hold an unsigned numeric value in four bytes.

**variable declaration**—The statement that names a variable; it includes a data type, an identifier, an optional assignment operator and an assigned value, and a semicolon.

**ulong**—An integral data type that can hold an unsigned numeric value in eight bytes.

**verbatim identifier**—An identifier with @ prefix.

**unary operators**—Operators used with one operand.

**virtual method**—A method whose behavior is determined by the implementation in a child class.

**Unicode**—A 16-bit coding scheme for characters.

**visible**—Describes a program element that is in scope; also describes a base class member that has not been hidden by a derived class.

**unifying type**—The type chosen for an arithmetic result when operands are of dissimilar types.

**void**—A keyword that indicates a method does not return any value when called.

**unreachable**—Describes program statements that can never execute under any circumstances because the program logic “can’t get there.” Also see de code.

**volatile**—The type of computer storage that is lost when power is lost.

# W

**while loop**—A structure that executes a body of statements continuously while some condition continues to be true; it uses the keyword while.

**whitespace**—Any combination of spaces, tabs, and carriage returns (blank lines) in a program.

**widgets**—Interactive controls such as labels, scroll bars, check boxes, and radio buttons.

**write to a file**—To store data in a computer file on a permanent storage device.

# X

**XML**—An abbreviation of eXtensible Markup Language, which is a standard for exchanging data over the Internet.

# XML-documentation format

**comments**—Comments that use a special set of tags within angle brackets to create documentation within a program.
