# CHAPTER 7 Using Methods

For example, Figure 7-5 shows a program containing two methods—Main() and MethodWithItsOwnA()—that each declare a variable a. The variable in method is completely distinct from the other and holds its own value, as shown in Figure 7-6. If you declared a variable b in the Main() and then tried to use b in MethodWithItsOwnA(), you would generate a compiler error. If you declared a variable c in MethodWithItsOwnA() and tried to use it in Main(), you would also generate a compiler error.

```
using static System.Console;
class LocalVariableDemo{
  static void Main() {
    int a = 12;
    WriteLine("In Main a is {0}", a);
    MethodWithItsOwnA();
    WriteLine("In Main a is {0}", a);
  }
  private static void MethodWithItsOwnA() {
    int a = 354;
    WriteLine("In method a is {0}", a);
  }
}
```
