# You Do It

Now that you understand the basic framework of a program written in C#, you are ready to enter your first C# program into a text editor. It is a tradition among programmers that the first program you write in any language produces Hello, world!
as its output. To create a C# program, you can use any simple text editor, such as Notepad, or the editor that is included as part of Microsoft Visual Studio. There are advantages to using the C# editor to write your programs, but using a plain text editor is simpler when you are getting started.
