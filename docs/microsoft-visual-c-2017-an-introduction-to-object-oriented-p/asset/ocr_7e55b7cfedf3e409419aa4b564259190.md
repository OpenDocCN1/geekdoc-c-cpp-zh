# CHAPTER 4 Making Decisions

Computer programs are powerful because of their ability to make decisions. Programs that decide which route will offer the best weather conditions, which website will provide the closest match to search criteria, or which recommended medical treatment has the highest probability of success all rely on a program's decision making. In this chapter, you will learn to make decisions in C# programs.

# Understanding Logic-Planning Tools and Decision Making

When computer programmers write programs, they rarely sit down at a keyboard and begin typing. Programmers must plan the complex portions of programs. Programmers often use pseudocode, a tool that helps them plan a program's logic by writing plain English statements. Using pseudocode requires that you write the logic of a given task in everyday language and not the syntax used in a programming language. (You learned the difference between logic and syntax in Chapter 1.) In fact, a task you write a list of directions to your house—for example, (1) go west on Algonquin Road, (2) turn left on Roselle Road, (3) enter expressway heading east, and so on—you have written pseudocode. A flowchart is similar to pseudocode, but you write the steps in diagram form, as a series of shapes connected by arrows or flowlines.

Some programmers use a variety of shapes to represent different tasks in their flowcharts, you can draw simple flowcharts that express complex situations using rectangles, diamonds, and connecting flowlines. You can use a rectangle to represent any process and a step to represent any decision. For example, Figure 4-1 shows a flowchart and pseudocode describing driving directions to a friend's house.
