# Overloading Methods

The Main() method calls the DisplayWithBorder() method in the program in Figure 8-16 and passes a string value, the method calculates a size as the length of the string plus 4, and then draws many symbols on a single line. The method then displays a symbol, a space, the string, another space, and another symbol on the next line. Figure 8-17 shows the output.

Suppose that you were pleased with the output of the DisplayWithBorder() method that you want to use something similar to display your company's weekly sales goal figure. The problem is that the weekly sales goal is stored as an integer, and so it cannot be passed to the existing method. You can take one of several approaches:

+   * You can convert the sales goal to a string and use the existing method. This is an acceptable approach, but it requires you to remember to write an extra step in any program in which you display an using border.

+   * You can create a new method with a unique name such as DisplayWithBorderUsingInt(int) and use it to accept an integer parameter. The drawback to this is that you must remember different method names when you use different data types.

+   * You can overload the DisplayWithBorder() method. Overloading methods involves writing multiple methods with the same name but different parameter types. For example, in addition to the DisplayWithBorder() method shown in Figure 8-16, you could use the method in Figure 8-18.
