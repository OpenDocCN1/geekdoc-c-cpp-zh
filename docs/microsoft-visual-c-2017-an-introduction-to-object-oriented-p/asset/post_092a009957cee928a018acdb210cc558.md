# Handling Control Events

Handling events requires understanding several different concepts. Fortunately, you frequently want to handle events in GUI environments when the user will manipulate Controls, and the good news is that these events have already been defined for. When you want to handle events generated by GUI Controls, use the same techniques as you want any other events. The major difference is that you create your own classes, such as Student, you must define both the data and events you want to manage. However, existing Control components, such as Buttons and ListBoxes, already contain events with names, such as Click. Table 13-1 lists some of the most common Control events. You can consult the Visual Studio Help to discover additional Control events as well as specific events assigned to individual Control classes.
