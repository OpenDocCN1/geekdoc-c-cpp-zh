## Event Handling

In C#, an event is a reaction to an occurrence in a program; an event transpires when something interesting happens to an object. When you create a class, you decide exactly what is considered "interesting." For example, when you create a Form, you might decide to respond to a user clicking a Button but ignore a user who clicks a Label—clicking the Label is not "interesting" to the Form.

A program uses an event to notify a client when something happens to an object. Events are used frequently in GUI programs—for example, a program is notified when the user clicks a Button or chooses an option from a ListBox. In addition, you can use events with ordinary classes that do not represent GUI controls. When an object’s client might want to know about any changes that occur in the object, events enable the object to signal the client.

> The actions that occur during the execution of the program occur at runtime. The expression at runtime is used to distinguish execution-time activities from those that occur during development time and compile. Events are runtime occurrences.

Because an event is generated when a user interacts with a GUI object, GUI programs are described as event-driven—an event such as a click "drives" the program to perform a task. Programmers say that an action like a button raises an event, fires an event, or triggers an event.

When you double-click a button named changeButton, Visual Studio generates an empty method named changeButton_Click. After you rename the method so it conventionally starts with an uppercase letter, the method looks like the following:

```c
private void ChangeButton_Click(object sender, EventArgs e)
{
```

A method that performs a task in response to an event is an event handler. The ChangeButton_Click() method is an event handler; it will handle clicks that generate from the Button.

Suppose that when a user clicks the button, you want the text on the label to change from Hello to Goodbye. You can write the following code for the event handler:

```csharp
private void ChangeButton_Click(object sender, EventArgs e)
{
  helloLabel.Text = "Goodbye";
}
```

## CHAPTER 13 Handling Events

The object that generates an event, such as a Button, is an event sender. The event-handling method is also known as an event receiver. The first parameter in the list for the receiver method is an object named sender; it is a reference to the object that generated the event. For example, if you click the event handler to display sender's information as a string in the following method version, the output after clicks the Button as appears in Figure 13-3.

```csharp
private void ChangeButton_Click(object sender, EventArgs e)
{
  helloLabel.Text = sender.ToString();
}
```

The label in Figure 13-3 shows that the sender of event is an instance of System.Windows.Forms.Button, whose Text property is Change the label.
The second parameter in the ChangeButton_Click(object) event handler's parameter list is a reference to an event arguments object of type EventArgs; in this method, the EventArgs argument is named e. EventArgs is a C class designed for holding event information. If you change the code in the event handler to display the EventArgs ToString() value as in the following method version and run the program and click the button, you see the output in Figure 13-4.

```csharp
private void ChangeButton_Click(object sender, EventArgs e)
{
  helloLabel.Text = e.ToString();
}
```
