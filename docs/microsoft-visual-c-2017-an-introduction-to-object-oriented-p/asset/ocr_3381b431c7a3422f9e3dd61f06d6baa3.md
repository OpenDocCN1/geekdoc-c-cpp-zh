**6-21** A three-dimensional array definition

The empty brackets that follow the data type contain two commas, showing that the array supports three dimensions. A set of curly braces surrounds all the data; the inner braces surround the following:

+   * Four inner sets of braces surround the data for each building—each row of values represents a building (0 through 3).
* Within each row, the three sets of inner braces represent each floor—first basement, floor one, and floor two. For example, in building 0, {400, 500} are rents for floor 0, and {450, 550} are rents for floor 1.
* Within each floor, the two braced values represent the bedrooms—first a zero-bedroom apartment and then a one-bedroom apartment. For example, in building 0, 400 is the rent for a zero-bedroom apartment, and 500 is the rent for a one-bedroom apartment.

Using the three-dimensional array in Figure 6-21, an expression as rents[building, floor, bedrooms] refers to a specific value for a building whose number is stored in the `building` variable whose floor and bedrooms are stored in the `floor and bedrooms` variables. Specifically, rents[3, 1, 0] refers to a (zero-bedroom) apartment on the first floor of building3 (which is the fourth building). The value of rents[3, 1, 0] is $1050 in Figure 6-21. If you are programming in C#, you can use four, five, or more dimensions in an array. As long as you can keep track of the order of the variables as subscripts, and as long as you don't exhaust your computer's memory, C# lets you create arrays of any size.

# Using Jagged Arrays

C# also supports jagged arrays. A **jagged array** is a one-dimensional array in which each element is another array. The major difference between jagged and rectangular arrays is that in jagged arrays, each can be a different length.

For example, consider an application in which you want to store train ticket prices for each stop along different routes. Some of the routes have as many as 10 stops and others as few as two. Each of the five routes could be represented by a row in a multidimensional array. You would have two logical choices for the columns:

+   * You could create a rectangular, two-dimensional array, allowing 10 columns for each row. In some of the rows, as many as eight of the columns would be empty, because some routes have only two stops.
