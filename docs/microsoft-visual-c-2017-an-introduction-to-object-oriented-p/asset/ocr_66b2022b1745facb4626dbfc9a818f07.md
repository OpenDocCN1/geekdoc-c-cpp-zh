Because increasing the value of a variable is a common task, C# provides several shortcut ways to count and accumulate. The following two statements are identical in meaning:

```
counter += 1;
```

```
counter = counter + 1;
```

The += operator is the **add and assign operator**, it adds the operand on the right to the operand and assigns the result to the left in one step. For example, if payRate is 20, then payRate += 5 results in payRate holding the value 25. The following statements both increase bankBal by a rate stored in **interestRate:

```
bankBal += bankBal * interestRate;
bankBal = bankBal + bankBal * interestRate;
```

For example, if bankBal is 100.0 and interestRate is 0.02, then both of the previous statements result in bankBal holding 102.0.

Additional shortcut operators in C# are -=, *= and /. Each of these operators is used to perform an operation and assigns the result in one step. You cannot place spaces between the two characters that compose these operators; spaces preceding or following the operators are optional. Examples in which the shortcut operators are useful:

+   - balanceDue -= payment subtracts a payment from balanceDue and assigns the result to balanceDue.
- rate *= 100 multiplies rate by 100 and assigns the result to the rate. For example, it converts a fractional value stored in rate, as 0.27, to a whole number, as just 27.
- payment /= 12 changes a variable's value from an annual amount to a monthly amount.

When you want to increase a variable's value by exactly 1, you can use either of two shortcut operators—the **prefix increment operator** and the **postfix increment operator**. To use a prefix increment operator, you type two plus before the variable name. For example, these statements result in someValue holding 7:

```
int someValue = 6;
++someValue;
```

The variable someValue holds 1 more than it before the ++ operator was applied. To use a postfix ++, you type two plus signs after the variable name. Executing the following statements result in anotherValue holding 56:

```
int anotherValue = 56;
anotherValue++;
```

You can use the prefix ++ and postfix ++ with variables but not constants. An expression such as ++84 is illegal because 84 is constant and must always remain 84. However, you can create a variable as in int val = 84; and then write out ++val or val++ to increase the variable's value to 85.

The prefix and postfix increment operators are **unary operators** because you use them with one operand. All arithmetic operators, such as those used for addition and multiplication, are binary operators that operate on two.
