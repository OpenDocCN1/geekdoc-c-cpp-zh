**Figure 12-17** The IDE with a Form that contains a PictureBox

In 12-17, in the Properties list at the right of the screen, the **Image** property is set to *(none)*. If you click the value, a button with an ellipsis appears. If you click it, a Select Resource window appears, as shown on the left in Figure 12-18. When you click the Import button, you can browse for stored images. When you select one, you see a preview in the Select Resource window, as shown in Figure 12-18.

After clicking OK, the image appears in the **PictureBox**, as in Figure 12-19. If the image does not fit the **PictureBox**, as in the left side of Figure 12-19), you can make a choice for the **SizeMode** property for the PictureBox. Table 12-8 shows the possible choices for **SizeMode** and in the right side of Figure 12-19, the **Zoom** property has selected before program execution.
