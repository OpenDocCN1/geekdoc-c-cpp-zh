# # Using Named Arguments

You can leave optional arguments in a method call if you pass the remaining arguments by name. a **named argument** is a method argument that is preceded by the name of the called method's parameter to which it will be assigned. Named arguments can appear in any order, but must appear after all the unnamed arguments have been listed. Each unnamed argument is also known as **positional argument**. You name an argument using its parameter name and a colon before the value.

> In Chapter 7, you learned that if you use the IntelliSense feature of Visual Studio, you can discover a method's parameter names. See Appendix C for more details.
