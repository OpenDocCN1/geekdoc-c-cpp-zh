
If this loop executes 1,000 times, then the expression a + b is calculated 1,000 times. Instead, if you use the code, the results are the same, but the arithmetic is performed only once:

```csharp
int sum = a + b;
while(x < sum)
// loop body
```

Of course, if a or b is altered in the loop body, then a new sum must be calculated with every loop iteration. However, if the sum of a and b is fixed prior to the start of the loop, then the code the second is far more efficient.

As another example, suppose you need a temporary variable within a loop to use for some calculation. The loop could be written as:

```csharp
while(x < LIMIT)
{
 int tempTotal = a + b;
 // more statements here
}
```

When you declare a variable tempTotal within a loop, it exists only for the duration of the loop; that is, it exists only until the loop’s closing brace. Each time the loop executes, the variable is recreated. A more efficient solution is to declare the variable outside of the loop, as:

```csharp
int tempTotal;
while(x < LIMIT)
{
 tempTotal = a + b;
 // more statements here
}
```

It is more efficient to declare this variable outside the loop to redeclare it every loop iteration.

## Considering the Order of Evaluation of Short-Circuit Operators

In Chapter 4, we learned that the expressions in each part of an AND or OR expression use short-circuit evaluation; that is, they are evaluated only as much as necessary to determine whether the entire expression is true or false. When a loop execute many times, it becomes increasingly important to consider the number of evaluations that take place.

For example, suppose that user can request any number of printed copies from 1 to 15, and now you need to validate the user’s input before printing.
```csharp
while(requestedNum > 15 || requestedNum < 1)...
```

Because you believe that the first Boolean expression is more likely to be true than the second, one, can eliminate the second one on more occasions. The order of the expressions is not important in a single loop, but if this loop is nested within others, the difference in the number of required tests increases. Similarly, the order of the evaluations in if statements is more important than the if statements are nested within a loop.

## Employing Loop Fusion

Loop fusion is the technique of combining two loops into one. For example, suppose that you want to call two methods 100 times each. You can set a constant named TIMES to 100 and use the following code:

```csharp
for(int x = 0; x < TIMES; ++x)
method1();
for(int x = 0; x < TIMES; ++x)
method2();
```

However, you can also use the following code:

```csharp
for(int x = 0; x < TIMES; ++x)
{
  method1();
  method2();
}
```

Fusing loops will not work in every situation; sometimes all the activities for each execution of method1() must be finished before method2() can begin. However, if the two methods do not depend on each other, fusing loops can improve performance. Performance issues can be crucial when you write programs for small mobile devices like phones. The other hand, if saving a few milliseconds ends up making your code harder to understand, almost always suffer in favor of slower but more readable programs.

## Using Prefix Incrementing Rather Than Postfix Incrementing

Probably the most common action after the second semicolon in a for statement is to increment the loop control variable. In many textbooks and in many professional programs, postfix increment operator is used for this purpose, in the following:

```csharp
for(int x = 0; x < LIMIT; ++x)
```

Because incrementing x is a stand-alone statement in the for loop, the result is identical unless you use x++ or +++. However, the prefix increment operator produces a faster loop is loop.

One way to prove that the prefix increment operator produces a faster loop is to use C#s Stopwatch class. To use the class, you include the statement using System.Diagnostics; at the top of the program file. You will understand how this class works after you Chapter 9, "Classes and Objects," you can use this class now by making statements similar to the following:

```csharp
Stopwatch sw = Stopwatch.StartNew();
// Place statements to be timed here
sw.Stop();
```

The first statement creates and starts a Stopwatch for timing events. The object's name is sw—you can use any C identifier. The last statement stops the Stopwatch.

Subsequently, you can use a similar statement to the following to output the object's elapsed time in milliseconds

```csharp
WriteLine("Time used: {0} ms", sw.Elapsed.TotalMilliseconds);
```
