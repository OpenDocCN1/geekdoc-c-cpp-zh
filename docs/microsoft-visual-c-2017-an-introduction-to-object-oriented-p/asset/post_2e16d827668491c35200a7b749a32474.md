You declare all variables you want to use in a program. A variable declaration is the statement that names a variable and reserves storage for it. A declaration includes the following:

- The data type that the variable will store
- The variable's name (its identifier)
- An assignment operator and assigned value when you want a variable to contain an initial value
- An ending semicolon.

For example, the following statement declares a variable of `int myAge` and assigns it an initial value of 25:

```
int myAge = 25;
```

The int type represents integer, which is a whole number. Complete discussion of this data type appears in the section "Using the Integral Data Types" later in this chapter. The equal sign (=) is the assignment operator; any value to the right of the assignment operator is assigned to the identifier to the left. An assignment when a variable is declared is an initialization; an assignment made to the left is an assignment. Thus, the statement initializes myAge to 25:

```
int myAge = 25;
```

A statement such as the following assigns a new value to the variable:

```
myAge = 42;
```

Notice that the data type is not used when an assignment is made; it is only used in a declaration.

Also note that the expression `25 = myAge;` is illegal because assignment always takes place from right to left. By definition, a literal constant cannot be altered, so it is illegal to place one (such as 25) on the left side of an assignment operator. The assignment operator means "is the value of the following expression." In other words, the statement `myAge = 25;` can be read as "myAge is assigned the value of the following expression". Instead of using a name from the Type column of Table 2-1, you could use the fully qualified name listed in the System column. For example, instead of using the name int, you can use the full name System.Int32 (The number 32 in the name System.Int32 represents the number of bits of storage allowed for the variable. There are eight bits in a byte, and an int occupies four bytes). It's better to use the shorter alias int, however, for the following reasons:

- The shorter alias is easier to read.
- The shorter alias resembles names used in other languages such as Java and C++.
- Other C# programmers expect the shorter names.

You can declare a variable without an initialization value, as in the following statement:

```
int myAge;
```

You can make an assignment to an uninitialized variable later in the program, but you can use the variable in a calculation or display it until a value has been assigned to it.

You can declare multiple variables of the same type in separate statements. For example, the following statements declare two integer variables:

```
int myAge = 25;
int yourAge = 19;
```

If variables have different types, each must be declared in its own statement, but you can declare multiple variables of the same type in a single statement by using the type once and separating the variables with a comma, as shown in the following statement:

```
int myAge = 25, yourAge = 19;
```

Some programmers prefer to break declarations across multiple lines, as in the following example:

```
int myAge = 25,
    yourAge = 19;
```

When a statement occupies more than one line, it is easier to read if lines after the first one are indented a few spaces. This book follows that convention.

# Displaying Variable Values

If you want to display several strings and variables, you can end up with quite a few Write() and WriteLine() statements. To make producing output easier, you can combine strings and variable values into a single Write() or WriteLine() statement by concatenating them or using a format string.

When you concatenate with another value, you join the variables with the plus sign. For example, the following statement produces the same output as Figure 2-4 but uses only WriteLine():

```csharp
WriteLine("The money is $" + someMoney);
```

A format string is a string of characters that controls the appearance of output. It optionally contains fixed text and one or more placeholders for variable values. A placeholder holds a position for variable value within a string. It consists of a pair of curly braces containing a number that indicates the desired variable's position in a list that follows the string. The first position is always 0.

You can create a formatted string using the String.Format() method that is built into C#. For example, the following statements create a formatted string and then display it:

```csharp
double someMoney = 39.45;
string mySentence = String.Format("The money is ${0} exactly", someMoney);
WriteLine(mySentence);
```

The curly braces that contain a digit create a placeholder {0} to which the value of someMoney is inserted. Because someMoney is the first variable after the format string (as well as the only variable in this example), its position is 0. The process of replacing placeholders with values is called string interpolation or variable substitution.

C# also includes a string interpolation feature that allows you to use a dollar sign in place of the String.Format() method, as in the following:

```csharp
string yourSentence = $"The money is ${someMoney} exactly";
WriteLine(yourSentence);
```

C# also allows you to use a shortcut with the Write() and WriteLine() methods. You can format a string and output it in one line without declaring a temporary string variable and explicitly naming the String.Format() method, as in either of the following:

```csharp
WriteLine("The money is ${0} exactly", someMoney);
WriteLine("The money is ${someMoney} exactly");
```
