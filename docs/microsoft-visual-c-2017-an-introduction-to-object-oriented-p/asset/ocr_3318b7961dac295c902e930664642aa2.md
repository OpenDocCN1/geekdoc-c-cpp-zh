# Comparing Traditional and Object-Oriented Error-Handling Methods

Programmers had to deal with error conditions long before object-oriented methods were conceived. For example, by dividing zero is an avoidable error for programmers always had to plan. If you simply check a variable's value with an if statement attempting to divide it into another number, you can prevent the creation of an *Exception* object. For example, the following code uses a if statement to check a variable to prevent division by zero.

```
if(gallonsOfGas == 0)
  mpg = milesDriven / gallonsOfGas;
else
  mpg = 0;
```

This code successfully prevents division by zero, but it does not really "handle an exception because no Exception class is created. The example code illustrates a perfectly legal and reasonable method of preventing division by zero, and it represents the most efficient method of handling the error if you think it is a frequent problem.
