# CHAPTER 13 Handling Events

The object that generates an event, such as a Button, is an event sender. The event-handling method is also known as an event receiver. The first parameter in the list for the receiver method is an object named sender; it is a reference to the object that generated the event. For example, if you click the event handler to display sender's information as a string in the following method version, the output after clicks the Button as appears in Figure 13-3.

```
private void ChangeButton_Click(object sender, EventArgs e)
{
  helloLabel.Text = sender.ToString();
}
```

**Figure 13-3** The EventDemo application modified to display sender information

The label in Figure 13-3 shows that the sender of event is an instance of System.Windows.Forms.Button, whose Text property is Change the label.
The second parameter in the ChangeButton_Click(object) event handler's parameter list is a reference to an event arguments object of type EventArgs; in this method, the EventArgs argument is named e. EventArgs is a C class designed for holding event information. If you change the code in the event handler to display the EventArgs ToString() value as in the following method version and run the program and click the button, you see the output in Figure 13-4.

```
private void ChangeButton_Click(object sender, EventArgs e)
{
  helloLabel.Text = e.ToString();
}
```
