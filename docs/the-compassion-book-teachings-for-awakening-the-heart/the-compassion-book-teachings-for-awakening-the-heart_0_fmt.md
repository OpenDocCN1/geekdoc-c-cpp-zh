# 引言

## 慈心与悲心的训练

多年来，书中的五十九句格言一直是我个人修行和教导的核心。这些西藏佛教格言（被称为`lojong`，或“转心”教法）提供了精辟而有力的提醒，告诉我们在日常生活中、在任何情况下如何唤醒我们的内心。

书中介绍的`lojong`教法出自秋恰瓦·夏额多杰（Chekawa Yeshe Dorje）的经典西藏著作《心修七道次第》。当我第一次读到这些格言时，被它们不寻常的信息所震撼了：我们可以利用生活中遇到的一切——无论愉悦还是痛苦——来唤醒真正的、不加修饰的慈悲。

`lojong`教法包含一种非常有支持性的冥想练习，称为`tonglen`（“摄与放”）。这是一种强大的练习，旨在帮助像我们这样的普通人与内心的开放与柔软连接起来。书中附带了一个可以下载的音频节目，我在其中对`tonglen`修提供了深度指导。您可以在[www.shambhala.com/openingtheheart](http://www.shambhala.com/openingtheheart)下载该节目。

`lojong`的基本概念是，我们可以与我们拒绝的事物、与我们认为自己和他人身上“坏”的事物和解。同时，我们可以学会对我们珍视的事物、我们认为的“好”的事物保持慷慨。如果我们开始这样生活，我们内心某些被埋藏已久的东西开始成熟。传统上，这种“东西”被称为`bodhichitta`，或“觉悟之心”。它是我们已经拥有但通常尚未发现的东西。

这就好像我们虽然贫穷、无家、饥饿且寒冷，但在我们睡觉的地方其实有一个金罐。黄金就是`bodhichitta`。我们的困惑和痛苦源于不知道黄金就在这里——源于总是看向别处。当我们谈论喜悦、开悟、觉醒或唤醒`bodhichitta`时，所有的意思就是我们知道黄金就在这里，并且意识到它一直都在。

`lojong`教法的核心信息是：如果是痛苦的，你可以学会坐稳你的位置，并靠近那种痛苦。反转通常那种分裂、逃避的常规模式。逆道而行，坐稳你的位置。

## 如何运用转心格言

我建议的方法是中巴（Chogyam Trungpa）推荐的。

1. 每天早上从书中随机选一句格言。
2. 阅读该格言的评语。（除了我的评语，你还可以参考其他资源部分的建议。）
3. 全天尝试按照该格言的含义生活。

有时，在一天中我会忘记所选的格言。但通常，如果发生了某些事，当天的格言（或者另一句）会出现在脑海中，给我一个视角，让我减少反应并更清晰地看待问题。即使是最困难的情况也变得可以应对。

我希望格言练习能帮助你，就像帮助我一样，将所有情境转化为道。

## 第一，修习备缘

备缘也被称为四种提醒。在日常生活中，尝试：

1. 保持对人身贵的意识。
2. 意识到生命有终点；死亡降临每个人。
3. 回忆你所做的一切，无论善恶，都有报；因果报应。
4. 思考只要你过度关注自我、过度纠结于自己的好坏，你就会遭受痛苦。执着于得到想要的和回避不想要的并不会快乐。

## 将一切法视为如梦

你在生活中经历的一切——痛苦、快乐、热、冷或任何事情——都像梦中发生的事情一样。尽管你可能认为事情非常坚固，但它们就像流逝的记忆。你可以在坐禅中体验这种开放、不固定的品质；你脑中产生的一切——恨、爱以及所有其他——都不是固态。

尽管体验可以变得极其生动，但它只是内心的产物。

## 修持五种力量，心要要

### 注释

五种力量是：

1. **坚定的决心**：训练去敞开与放下。
2. **熟练**：熟悉有助于你实现这一目标的修行（如`tonglen`相应心）。
3. 你内在的**正念种子**：表现为对修行和觉醒的渴望。
4. **自责**：这对于西方学生来说比较棘手，但是一项重要的修行：意识到自我的执着会让你受苦，并乐于自我反省、诚实，并看到自己卡在哪里。
5. **愿力**：帮助减轻世间痛苦的愿望，并向自己表达这一意图。

![18](img/Chod_9780834840645_epub3_018_r1.jpg) ![18](img/Chod_9780834840645_epub3_018_r1.jpg)

大乘关于死亡时意识出的教法就是五种力量：你如何处事非常重要。

### 注释

当你临终时，修持五种力量（基于你在活着时对它们变得非常熟悉）。

1. **坚定的决心**：当世界的幻象开始溶解时，敞开并放下。
2. **熟练**：在一生中练习敞开与放下，这样在死亡时一切溶解，你就不会恐慌。
3. **正念种子**：相信你天生具有放下和对他人的慈悲的能力。
4. **自责**：意识到这种局限的身份并非稳固且正在消融，不要沉溺于试图阻止它崩塌。
5. **愿力**：死亡时，愿在未来的所有生中都在老师面前度过，并尽力永远利益他人。

## 始终遵循三个基本原则

### 注释

三个基本原则是：

1. `守持你许下的承诺`，如果你受了出依戒和菩萨戒。当我们受出依戒时，我们发愿皈依佛，作为敞开与放下的范例；皈依法（佛的教法），作为如何做到的指导；以及皈依僧（同样在这条路上的群体）。当我们受菩萨戒时，我们发愿觉醒以帮助他人也做到同样的事。
2. `节制过分的行为`，或不参与有时被称为“菩萨表演主义”。
3. 在困难和愉悦的情况下都`培养耐心`。
