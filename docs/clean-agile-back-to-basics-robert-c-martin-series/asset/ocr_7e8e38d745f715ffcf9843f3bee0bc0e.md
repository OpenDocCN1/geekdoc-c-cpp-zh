This calculation is likely to be very disappointing. It will almost certainly exceed the original end date for the project by a significant factor. On the other hand, this new date is based upon *real data*, so it should not be ignored. It also can’t be taken too seriously because it is based on a single data point; the error bars around that projected date are pretty wide.

To narrow those error bars, we should do two or three more iterations. As we do, we get more data on how many stories can be done in an iteration. We’ll find that this number varies from iteration to iteration but averages at a relatively stable *velocity*. After four or five iterations, we’ll have a much better idea of when this project will be done (Figure 1.6).
