First, I push `std::boolalpha` into the `cout` stream to output true or false from Boolean variables literally, while the output in the `cout` line also immediately moves. The `cout << b` afterwards also outputs the value of the Boolean variable literally. From this, you can see that the setting, once activated, remains active.

The output in the function `f()` shows that the setting is globally applicable. After the function call, I deactivate the setting again by sending `std::noboolalpha` into the stream. The output of the now numeric values of 0 and 1 instead of false and true from `bool` confirm this process.
