# Specializations

In the representation in Figure 27.1, the specializations for a base type have already been shown. Apart from `ios_base`, the basic_ prefix would appear before each class template name. A specialization thus looks as follows:

```
using ostream = basic_ostream<char>;
```

This is a specialization for the char data type from the basic_ostream class template. Such specializations can also be used for other character types like wchar_t, char16_t, and so on.
