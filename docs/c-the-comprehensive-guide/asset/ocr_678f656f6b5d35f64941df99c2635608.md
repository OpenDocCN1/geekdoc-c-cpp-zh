# ARTICLE

You have been hired by a nonprofit organization that collects donations from various donors. This nonprofit has been operating slowly for a few years. As a result, the organization has not been keeping up with technology, so all the data is stored in physical paper files. The recent pandemic has made it clear that this is a big problem: no one can go to the office and access the files.

Your manager has asked you to take all the paper files and scan them into the computer. Once the files are scanned, you will need to come up with a system to store the digital files and organize them so they can be searched through easily. Before you get started, your manager has given you the following instructions.

Review the given dataset. It appears that there are multiple places where donor information exists. Based on your review, identify all potential data sources and determine if the data needs to be cleaned and/or transformed. Also, think about how to store all of the data from the various data sources in a single place (e.g., data warehouse). Finally, list a few questions that this unified data could answer.
