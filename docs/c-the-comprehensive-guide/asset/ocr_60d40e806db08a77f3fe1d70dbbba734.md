**Listing 25.18** “inclusive_scan” and “exclusive_scan”.

In `inclusive_scan`, the first element of the output already contains 100+1, so the *i*-th result already includes the *i*-th input in the sum.

The result of `exclusive_scan` starts with 100, so the *i*-th result does not include the *i*-th input, thus it is **exclusive** of the *i*-th element. You always need an initial value for the first result here. I defined `plus` for `inclusive_scan` only so that I could use a comparable overload: if you want to specify an initial value for `inclusive_scan`, you also need an operator as an argument.
