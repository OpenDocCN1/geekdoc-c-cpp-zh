# 28.2.4  Rich in Variants

We have already seen that the text to be searched can be passed in different ways. The
functions are indeed very flexible for various needs due to numerous overloads.

For example, there are variants of `regex_search` that could be informally summarized
as follows:

+   - Text to be searched, such as `string`, `const char*`, or a pair of iterators
+   - Optional `match_results`, like `match`
+   - The pattern to be searched as regex
+   - Optional flags, which default to `regex_constants::match_default` if omitted

The same applies to `regex_match` and `regex_replace` as well.
