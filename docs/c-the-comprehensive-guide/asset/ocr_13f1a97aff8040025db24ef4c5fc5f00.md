# Error Checking

For error checking when opening a file, you can use both `if(!file)` and `if(file.fail())`. In both cases, `true` will be returned if opening a file has failed and thus the `failbit` flag is set (see also Section 27.4). If a file is successfully opened, all error flags are cleared, and the `goodbit` flag is set. Therefore, you can use the `good()` method to test whether the file was successfully opened (`true`) or not (`false`).

# Flags for Opening a File

When opening a file stream, you can either stick with the default values of the `fstream`, `ofstream`, or `ifstream` class, or you can set optional flags that determine how the file is opened. In the `<ios>` header file, you will find the definition of the type (specifically the bitmask) `ios::openmode`. The individual flags (see Table 27.9) can be combined with each other using the bitwise OR operator `|`, where appropriate.

| Flag | Short | Description |
|---|---|---|
| `ios::in` | Input | Open for reading (default for `ifstream`). |
| `ios::out` | Output | Open for writing (default for `ofstream`). |
| `ios::app` | Append | Always add something at the end when writing. |
| `ios::trunc` | Truncate | The file length is set to 0, and existing content is deleted. |
| `ios::ate` | At end | Positions the read or write position at the end of the file immediately after opening. Without this flag, the read and/or write position is usually at the beginning of the file after opening. |
| `ios::binary` | Binary | Opens the file in raw binary mode. For example, line-end conversions are not performed, and raw bytes are transferred. Without this mode, a file is opened in a formatted text mode. |

Table 27.9 Various flags for opening a file.

> The default value of `ifstream` is essentially `ios::in`, that of `ofstream` is `ios::out | ios::trunc`, and that of `fstream` is `ios::in | ios::out`.
