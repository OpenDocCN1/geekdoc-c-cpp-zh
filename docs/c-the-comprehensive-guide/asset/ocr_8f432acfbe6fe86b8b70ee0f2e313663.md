In the first example of a unit test module, I will show you how to let the Boost.Test framework handle the process of combining individual tests into a suite. For this, it has a few practical macros.

The `testQwort.cpp` test module from Listing 14.6 tests the `qwort.cpp` library module. It is advisable to adhere to a naming scheme for naming the test modules. I use `test...` as a prefix, but you can also append `_Test` as a suffix or be creative in other ways.
