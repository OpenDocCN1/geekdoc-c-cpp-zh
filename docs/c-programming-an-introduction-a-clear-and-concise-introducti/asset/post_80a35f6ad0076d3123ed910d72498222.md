
## Composite Assignment Operators

There will also be plenty of situations when you need to adjust the value of a variable by more than 1, such as when counting by 5:

```cpp
count = count + 5;
```

To make it easier to write these types of statements, C++ provides a set of composite assignment operators. These operators are: +=, -=, *=, /=, and %=. They work like this:

```cpp
int var1 = 0;
var1 += 5;  // var1 has the value 5
var1 *= 2;  // var1 now has the value 10;
var1 /= 2;  // var1 has the value 5
var1 %= 5;
// var1 now has the value 0 since 5 / 5 leaves
// remainder of 0
```

Using these operators instead of more complete statements provides the programmer with a convenient shortcut and should be used when possible to make your programs easier to read.

### Determining the Average Grade

For our first problem we'll find the average of a set of test scores. The test scores are: 78, 85, 92, 99, and 81. Solving the problem involves finding the sum of the test scores and dividing the sum by the number of test scores to obtain the average. To write a program to solve this problem, we will need variables for the test scores (variables for the test scores are not absolutely required here, but we will create them to get some practice using variables), a variable for the total of the test scores, and a variable to hold the average.

First, we need to determine the data types of the variables. The test scores are all whole numbers, so the test score variables will be declared as integers. The total number of test scores is also a whole number and, therefore, an integer, but we want to declare it as a constant to demonstrate how constants are used. The sum of the test scores will also be declared as an integer variable. The average, though, can be a floating-point value so we need to declare the variable as a double.

Here are the statements to declare the variables:

```cpp
int grade1, grade2, grade3, grade4, grade5, totalGrades;
double average;
const int numGrades = 5;
```

The next step is to assign data to the test score variables:

```cpp
grade1 = 78;
grade2 = 85;
grade3 = 92;
grade4 = 99;
grade5 = 81;
```

Then we can compute the sum of the test scores:

```cpp
totalGrades = grade1 + grade2 + grade3 + grade4 + grade5;
```

And finally we can compute and display the average:

```cpp
average = totalGrades / numGrades;
cout << "The average is: " << average << endl;
```

Here is the complete program entered in Visual C++ Express:

```cpp
// avgGrades.cpp : main project file.

#include "stdafx.h"
using namespace System;
#include <iostream>
using namespace std;

int main(array<System::String ^> ^args)
{
    int grade1, grade2, grade3, grade4, grade5,
        totalGrades;
    double average;
    const int numGrades = 5;
    grade1 = 78;
    grade2 = 85;
    grade3 = 92;
    grade4 = 99;
    grade5 = 81;
    totalGrades = grade1 + grade2 + grade3 + grade4
                        + grade5;

    cout << "The average is: " << average << endl;
```

The first step is to determine the variables needed to solve the problem. We'll need constants for each denomination that store the value and a variable to store the total amount. Let's declare them now:

```cpp
double total;
```

```cpp
cout << "The total amount of change is: $" << total
```

### Voting Percentages

Here is a problem taken from a junior high mathematics book: In an election, a candidate got 60% of the total valid votes. 15% of the total votes were declared invalid. If the total number of votes is 500,000, find the number of valid votes polled in favor of the candidate.

As usual, the first thing we need to do is decide what our variables are going to be. The facts we know for sure we can enter as constants, so we have three constants:

```cpp
const int totalVotes = 500000;
const double candVotePercent = .60;
const double invalidPercent = .15;
```

Now we need variables for the total number of valid votes and the number of valid votes the candidate received:

```cpp
double validVotes, candVotes;
```

It may seem odd to declare these two variables as double, but since we will be working with floating-point values in the expressions used to compute the values for these variables, declaring them as double removes any question about a loss of data. (In fact, if you do declare them as int, the compiler will issue a warning stating that there may be a loss of data when assigning a floating-point value to an integer variable).

Next we need to find the total number of valid votes:

```cpp
validVotes = totalVotes - (totalVotes *
             invalidPercent);
```

Since the number of invalid votes equals 15 percent of the total votes, then if we subtract that 15 percent from the total number of votes we'll get the total number of valid votes. Then we can easily compute the number of votes the candidate received and display the result:

```cpp
candVotes = validVotes * candVotePercent;
cout << "The candidate received " << candVotes
     << " votes.";
```

Here is the complete C++ program:

```cpp
// votePercent.cpp : main project file.
#include "stdafx.h"
using namespace System;
#include <iostream>
using namespace std;

int main(array<System::String ^> ^args)
{
    const int totalVotes = 500000;
    const double candVotePercent = .60;
    const double invalidPercent = .15;
    double validVotes, candVotes;
    validVotes = totalVotes - (totalVotes *
                 invalidPercent);
    candVotes = validVotes * candVotePercent;
```
