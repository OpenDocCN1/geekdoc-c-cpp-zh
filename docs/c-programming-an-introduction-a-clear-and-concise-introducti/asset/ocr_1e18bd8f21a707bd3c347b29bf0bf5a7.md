The only method that was even the slightest bit tricky to write was the display() method, but it was just a matter of looping through the vector, building a string out of each element of the vector. The main decision to make was whether or not to put each vector item on a separate line. You will notice that the method returns a string rather than writing the items out directly to the console. For most situations like this one, the more flexible decision is to write the contents of a class out to a string and let the program using the class decide how best to present the information. If the data is written to the console, the calling program has no choice but to do that also. Returning the data as a string gives the calling program the opportunity to store the data in a variable, write it to the console, perhaps write it to a file, or do something else with it entirely.
