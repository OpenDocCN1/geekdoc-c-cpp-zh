
```cpp
if (guess == numberToGuess)
    cout << "Right!";
else
    cout << "Wrong. The number was "
         << numberToGuess;
Console::ReadKey();
return 0;
}
```

First, notice that two new class libraries are imported into our program – cstdlib and ctime. rand() and srand() are located in the cstdlib library and the time() function is found in the ctime library.

The program itself is fairly straightforward. We seed the random number generator and then generate a random number in the range of 1 to 10. Then we ask the user to guess a number and compare the user's guess to the random number generated earlier.

Here is the output from one run of the program:

```
Enter a guess: 4
Wrong. The number was 1
```

Now let's look at how we can generate random numbers to store in a vector. The technique is the same, we just need to put the rand() function in a loop. For this program, we generate 1000 random numbers in the range 1 to 100. Here is the code:

```cpp
// Vector.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <vector>
#include <cstdlib>
#include <ctime>
using namespace std;

int main(array<System::String ^> ^args)
{
    vector<int> numbers;
    srand(time(NULL));
    for(int i = 1; i <= 1000; ++i)
    {
        numbers.push_back(rand() % 100 + 1);
    }
    // display the numbers in the vector
    for(int i = 0; i < numbers.size(); ++i)
    {
        cout << numbers[i] << " ";
    }
    unsigned int sum = 0;
    for(int i = 0; i < numbers.size(); ++i)
    {
        sum += numbers[i];
    }
    cout << endl << endl << "The sum is: " << sum
         << endl;
    Console::ReadKey();
    return 0;
}
```

Using random numbers in this fashion is a major convenience. Very few people have the patience to enter 1000 values into a vector. Of course, another solution for finding data to test a program is to use a data file and read the data from the file into the vector. As so many textbook authors have said in the past, we'll leave that as an exercise for the reader.

### Functions

In previous sections of this text we have explored different means of controlling control flow in computer programs. So far we have seen these types of control flow:

- Sequence – programs run in a sequential manner, line-by-line.
- Selection – if statements determine which set of statements to run.
- Iteration – while loops repeatedly execute a set of statements until a condition becomes false.

There is another means of controlling the order in which programming statements are executed – subroutines. A *subroutine* is a named set of programming statements that are written to perform some well-defined operation. Subroutines modify the control flow of a program because when they are called, the set of statements that make up the subroutine are executed and then control is transferred back to the place where the subroutine was called.

In C++, subroutines are called *functions*. There are two types of functions in C++: value-returning functions and functions that do not return a value. Functions that don't return a value are called void functions to differentiate them from value-returning functions. We'll begin this section by discussing how to define and use value-returning functions.

### Value-returning Functions

A function that returns a value is a set of programming statements, which when given a specific input, will always return the same output. For example, if we define a function named square, which has the number *n* as input, to return *n* * *n*, then we know that when square is given the value 2 as input it will always return the value 4.

### Defining a Value-Returning Function

We can easily convert this definition of the square function into C++ code. Function definitions are placed outside of the main() function, placing them either before main() or after main(). If we place a function definition after main() we will have to take some extra steps, so for now we will put function definitions right after the preprocessor directives.

Here is the definition of the square function in C++:

```cpp
int square(int number)
{
    return number * number;
}
```

The first line of the function definition includes (in strict order) the data type of the return value of the function, the name of the function, and the parameter list, which is the portion of the line inside parentheses.

A value-returning function definition must always include the data type of the function's return value. The name of the function should be as descriptive of the purpose of the function as possible. In other words, use the same care in naming functions that you use when naming variables.

The *parameter list* is a list of all the inputs to a function. A function can have no inputs or it can have many inputs, though typically a function will have one to three inputs. These inputs are known more formally as *parameters*. A parameter is similar to a variable because it holds data so its data type must be specified before the parameter name. If a function has more than one parameter, each parameter must be separated in the list by a comma. We will see examples of functions with two or more parameters below.

Following the parameter list is a block which contains the *function body*. The actual contents of the *function body* will depend on the purpose of the function, of course. Somewhere in the *function body*, though, there must be a *return statement*, which is used to send the value computed by the function back to the place where the function was called. For simple functions, like our square() function, the *return statement* includes all the processing necessary to compute a return value. Many, if not most, of the functions you will write in C++ will not be this simple.

Now let's see how a function is actually used in a C++ program. Here is a simple but complete program that demonstrates how to use the square() function:

```cpp
// square.cpp : main project file.

#include "stdafx.h"
using namespace System;
#include <iostream>
using namespace std;

int square(int number)
{
    return number * number;
}

int main(array<System::String ^> ^args)
{
    int num;
    cout << "Enter a number to square: ";
    cin >> num;
    cout << num << " squared is " << square(num) << endl;
    Console::ReadKey();
    return 0;
}
```

Here is a sample run of the program:

```
Enter a number to square: 12
12 squared is 144
```

To use a function, we have to perform a *function call*. A function call can be placed wherever an expression is expected. In the program above, the function call is in the cout statement:

```cpp
cout << num << " squared is " << square(num) << endl;
```

A function call consists of the function name and an *argument* that is the input to the function. At the time of the function call, the system transfers control of the program to the function definition. The argument value is substituted for the parameter in the definition and the function body is executed.

By substituting the argument value for the parameter, you can view the definition of square() as looking like this:

```cpp
int square(12)
{
    return 12 * 12;
}
```

The normal rules of evaluation apply in the execution of the function body, so 12 * 12 evaluates to 144 and this value is returned to the calling program.
