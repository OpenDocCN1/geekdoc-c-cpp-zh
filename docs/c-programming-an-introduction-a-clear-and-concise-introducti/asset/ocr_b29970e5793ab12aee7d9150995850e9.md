# Decisions

So far, the C++ programs we have discussed have run in a sequential manner, starting with the first line of the program and continuing line-by-line to the last line of the program. For very simple problems, a sequential solution might be sufficient, but for more complex problems we need to be able to make decisions in our programs as to which lines of the program should be executed and which lines should be skipped.

For example, a company's payroll program has to decide whether to pay a worker straight time if the worker only worked their regular hours or to pay the worker overtime if the worker worked more than their regular hours. Another example is a program that prompts the user to enter their user name and password. This program has to decide if the user name and password entered match a list of acceptable user names and passwords in order to either let the user into the system or to keep them out of the system. Decisions like these are made using some form of the if statement. However, before we can look at how to use the if statement we have to talk about how we compare values in C++ using *relational* and *logical* expressions.

# Relational Expressions

Decisions are made in C++ programs by comparing two or more data values. For example, to determine if a worker should be paid overtime wages, a program will compare the number of hours the worker worked with the minimum number of hours needed to be paid for overtime, which is often 40 hours. This comparison is made with a relational expression that employs one or more of the relational operators.
