# # Logical Operators

More complex comparisons require the programmer to sometimes combine two or more relational expressions. These types of comparisons are called logical expressions and are performed with the logical operators. The logical operators are:

+   - && And
+   - || Or
+   - ! Not

Here is one example of how the && logical operator is used with two relational expressions (assuming we have declared the variables workerType and hoursWorked):

```
((workerType == "hourly") && (hoursWorked > 40))
```

Notice that both expressions must be surrounded by parentheses both individually and as a group.

&& logical expressions return true if all the relational expressions are true and they return false if either or both of the relational expressions is false. We can summarize this behavior with a truth table:

| Rel Exp 1 | Rel Exp 2 | Result |
|---|---|---|
| True | True | True |
| True | False | False |
| False | True | False |
| False | False | False |
