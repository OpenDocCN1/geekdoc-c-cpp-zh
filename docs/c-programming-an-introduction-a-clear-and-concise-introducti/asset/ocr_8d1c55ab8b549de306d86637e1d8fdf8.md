# # Creating a Text File

Most readers will already know what a text file looks like. You've probably created them using Notepad or some other text editor. Instead of entering the text for a file from the keyboard, we are going to write a C++ program to create a simple text file that stores a list of grades.

The first step in our program is to include the fstream header file in our program, as we mentioned earlier. The next step is to create a file object that represents the file we are going to create. When we write data to the console, we use a built-in object that is associated with the console, cout. We can create our own object for a file by declaring an identifier of ofstream type, which stands for “output stream.” A file we are creating is considered an output file.

Creating a file object involves more than just declaring the object. We also have to specify the name of the file. We do this by naming the full path to the file, unless the file is located in the same directory as the program. This is not often the case, though, so the complete path is usually given as the argument. For example, if we want to store our grades file in a subdirectory named data that is just off the root directory, we can create the file object with this statement:

```
ofstream outFile("c:\\data\\grades.txt");
```

Notice that the path string includes two backslashes before each directory name. If we don't do this, C++ tries to interpret the single backslash as a special character, such as “\t”, which represents the tab character. Using two backslashes ensures that the compiler won’t interpret parts of the file path string as special characters.

This statement not only creates the text file and associates the file with our file object, it also opens the file. So the file is now ready to receive data from the program.
