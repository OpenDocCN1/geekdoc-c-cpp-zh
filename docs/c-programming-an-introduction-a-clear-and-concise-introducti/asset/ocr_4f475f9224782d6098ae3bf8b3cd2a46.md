# Functions

In previous sections of this text we have explored different means of controlling control flow in computer programs. So far we have seen these types of control flow:

+   - Sequence – programs run in a sequential manner, line-by-line.
+   - Selection – if statements determine which set of statements to run.
+   - Iteration – while loops repeatedly execute a set of statements until a condition becomes false.

There is another means of controlling the order programming statements are executed – subroutines. A *subroutine* is a named set of programming statements that are written to perform some well-defined operation. Subroutines modify the control flow of a program because when they are called, the set of statements that make up the subroutine are executed and then control is transferred back to the place where the subroutine was called.

In C++, subroutines are called *functions*. There are two types of functions in C++: value-returning functions and functions that do not return a value. Functions that don't return a value are called void functions to differentiate them from value-returning functions.
