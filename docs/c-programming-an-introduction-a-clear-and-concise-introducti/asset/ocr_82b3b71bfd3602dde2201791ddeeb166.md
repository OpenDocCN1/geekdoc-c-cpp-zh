# Exercises

+   1. Write a program that stores 100 random numbers in a vector. The program should then go back through the vector and display a list of any duplicate numbers found in the vector.
+   
+   2. Write a program that stores 50 random grades in a vector. The program should then go back through the vector and record the number of grades greater than or equal to 60 and the number of grades less than 60.
+   
+   3. Write a program that stores 10 names and grades entered by the user in two vectors and then loops through the vectors displaying the names and grades one to a line.
