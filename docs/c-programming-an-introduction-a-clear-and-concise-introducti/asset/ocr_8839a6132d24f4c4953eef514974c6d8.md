However, since an array name serves as a pointer into the array, we don't need to go to the trouble of creating a pointer variable to the array. We can just use the array name as a pointer:

```
```cpp
// PointersAndArrays.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main(array<System::String ^> ^args)
{
    int nums[100];
    srand(time(NULL));
    const int size = 100;
    for (int i = 0; i < size; ++i)
        nums[i] = rand() % 100 + 1;
    cout << nums[0] << endl;
    cout << *nums << endl;
    Console::ReadKey();
    return 0;
}
```
```

The array name is a pointer to the first element of the array. All we have to do is dereference the array name to get access to the first element.

If we want to access the second element of the array using pointer notation, we do it like this:

```
```cpp
cout << *(nums+1);
```
