value at the time it is declared. This declaration is called an *initializer* and
is written like this:

```
    int hoursWorked = 51;
```

This statement both declares hoursWorked as an integer variable and also
assigns the variable the value 51.

Finally, you can declare multiple variables of the same data type in
a single declaration. The example below declares multiple integer
variables:

```
    int hours, days, weeks;
```

This is the same as writing:

```
    int hours;
    int days;
    int weeks;
```

C++ ignores whitespace so you can also write the lines above like
this:

```
    int hours; int days; int weeks;
```
