Look at how much shorter this second version of the program is than the first version. In general, most while loops that prompt the user to continue or quit can be rewritten with a do-while loop, making the program shorter and easier to understand.

In fact, many programs that use a while loop can be rewritten using a do-while loop, especially if the test condition can be set up to be true before entering the loop. For example, a program that determines how long it will take a savings account with a $5,000 balance to accumulate $10,000 dollars at a given interest rate written with a while loop can easily be rewritten with a do-while loop. Here is the while loop version:

```cpp
// DoWhile.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main(array<System::String ^> ^args)
{
    double balance, rate;
    int years = 0;
    balance = 5000;
    // Enter 1.02 for 2%
    cout << "What is the interest rate? ";
    cin >> rate;
    while (balance < 10000)
    {
        balance *= rate;
        ++years;
    }
    cout << "It will take " << years
         << " to reach $10,000.00." << endl;
    Console::ReadKey();
    return 0;
}
```

Here is the program rewritten with a do-while loop:

```cpp
// DoWhile.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main(array<System::String ^> ^args)
{
    double balance, rate;
    int years = 0;
    balance = 5000;
    // Enter 1.02 for 2%
    cout << "What is the interest rate? ";
    cin >> rate;
    do
    {
        balance *= rate;
        ++years;
    } while (balance < 10000);
    cout << "It will take " << years
         << " to reach $10,000.00." << endl;
    Console::ReadKey();
    return 0;
}
```

There is very little difference in the two programs and it is preferable to use the while loop version over the do-while loop version, though both programs execute exactly the same.

However, there are situations when you shouldn't choose a do-while loop over a while loop. The most common situation is when processing the data in a text file. The test condition for a loop processing a text file needs to test to see if the file has data in it before any statements in the loop that read data are executed. Trying to read data from a file that is empty can cause the program to crash. Always use a while loop when working with text files.

## Pointers

Pointers are an often misunderstood feature of the C++ language. The Java programming language was created at least partially as an antidote to the problems caused by pointers. There are, though, situations when pointers are useful. Pointers can be used like references to pass variables by reference to a function. Some advanced data structures must be implemented with pointers, though there are alternatives to pointer-based data structures. This chapter will introduce you to how pointers work and why you sometimes need them.

### Pointers Defined

We can define pointers very simply. A pointer is a variable that contains the address of another variable. When we access the value of a pointer, a memory address is returned. A pointer is declared by placing an asterisk before the pointer variable name, like this:

```
int *pointerVariable;
```

When we want to assign an address to a pointer variable, we use the reference operator (&) before the variable whose address we want to assign to a pointer variable. For example:

```
int num = 100;
int *ptrNum;
ptrNum = &num;
```

In this code fragment, we declared num as an int variable and assigned it the value 100. We then declared ptrNum to be a pointer variable and we assigned it the address of num in the last statement. When referring to ptrNum, programmers commonly say that ptrNum points to num.

Now if we display the value of ptrNum, by writing:

```
cout << ptrNum;
```

we get this data:

```
0018ECF8
```

which is a memory address. This value will change every time you execute the statement.

If we want to see the value that is stored at this memory address, that is the value we stored in the num variable, we have to dereference the pointer variable, like this:

```
cout << *ptrNum;
```

This complete program illustrates what we've been discussing so far:

```cpp
// pointerExample1.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
using namespace std;

int main(array<System::String ^> ^args)
{
        int num = 100;
        int *ptrNum;
        ptrNum = &num;
        cout << "The memory address of num: "
             << ptrNum << endl;
        cout << "The value stored in num: "
             << *ptrNum << endl;
        Console::ReadKey();
        return 0;
}
```

The output from this program is:

The memory address of num is: 001CEF98  
The value stored in num is: 100

### Pointers and Pass-by-Reference

Since a pointer points to a variable's memory address, a pointer can be used to pass a parameter by reference to a function.

Earlier in the book we saw how to use references to create a swap function that exchanges the values of two variables passed to the function as arguments. Here is that program again:

```cpp
// Swap.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <string>
using namespace std;

void swap(string &word1, string &word2)
{
    string temp = word1;
    word1 = word2;
    word2 = temp;
}
```

```cpp
int main(array<System::String ^> ^args)
{
    string word1, word2;
    word1 = "banana";
    word2 = "apple";
    cout << word1 << " " << word2 << endl;
    swap(word1, word2);
    cout << word1 << " " << word2 << endl;
    Console::ReadKey();
    return 0;
}
```

To use pointers instead of references, all we have to do is exchange the reference operator (&) with the pointer operator (*) in the parameter list of the swap function, and use pointer reference in the code for the body of the function, like this:

```cpp
void swap(string *word1, string *word2)
{
    string temp;
    temp = *word1;
    *word1 = *word2;
    *word2 = temp;
}
```

Running this program gives the output:

```text
banana apple
apple banana
```
