# Getting Data Into and Out of Programs

The three examples discussed in the last chapter suggest that most computer programs follow very standard stages of development. First, the program has to get data into variables, which we'll call the Input stage. This stage includes declaring variables and constants and assigning data to the variables, including getting input from the user, which we'll examine next.

The second stage is the Processing stage. In the examples above, the Processing stage involved writing one or more arithmetic expressions and assigning the values from those expressions to variables. In more complex programs, this stage can be much more involved than in the less complex examples we saw earlier.

The final stage is the Output stage. In this stage we display the result of the Processing state to the user by writing data to the console, though in this stage with more complex programs we might write data to a file or a database or send the data to a printer. In this book we will mostly display output to the console, though we will at least touch on how to store data in a file.

As I just mentioned, the Processing stage of a program is usually somewhat more complex than the examples we've looked at so far. We are almost ready to discuss how to write more complicated programs to solve more complicated problems, but before we do we need to discuss more about getting data into our programs and displaying output to the console.
