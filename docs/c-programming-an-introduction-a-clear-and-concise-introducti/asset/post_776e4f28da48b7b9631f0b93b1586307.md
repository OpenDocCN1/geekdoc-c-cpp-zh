## Function Example – Raising a Number to a Power

Let's develop another function. This function will raise a given number to a given power. There is a built-in function to do this, but it is instructive to build it ourselves in order to gain more experience with defining functions.

When defining a function, it is sometimes useful to first just write down how the function should work, using known values. For example, we know that 2 raised to the second power is 4. So, if we name our function power, and pass it the arguments 2 (for the base) and 2 (for the power), the result will be 4. We can write it like this:

```
power(2,2) → 4
```

Now try another example, again using 2:

```
power(2,3) → 8
```

Doing this a few times will help you decide how to write the function body. In this case, you know that the base is going to have to be multiplied by itself 3 times in order to compute the correct value. An easy way to do that is to use a for loop for the computation.

Now we can start writing the function definition by writing the function heading:

```cpp
int power(int base, int exp)
```

That’s the easy part. The body is more difficult but we’ve already made the decision to use a for loop to multiply the base by itself the number of times specified by the exp parameter. We have to start off with the value 1 since any number raised to the first power is that number. Here’s the code:

```cpp
int power(int base, int exp)
{
    int number = 1;
    for(int i = 1; i <= exp; ++i) {
        number *= base;
    }
    return number;
}
```

All we have to do now is use it in a program and test it with a few values to see if it works. First we’ll test it by calling power(2,3):

```cpp
int main(array<System::String ^> ^args)
{
    cout << power(2,3) << endl;
    Console::ReadKey();
    return 0;
}
```

This program displays the value 8, as expected. Now let's try it with multiple powers of 2. Here is the complete program:

```cpp
// Power.cpp : main project file.

{

}

int main(array<System::String ^> ^args)
{
        for(int i = 1; i <= 10; ++i) {

        Console::ReadKey();
        return 0;
}
```

## Advantages to Functions

Creating and using functions provide several distinct advantages to your programs. Here are some of them:

- **Functions simplify a program** – Once a function has been created and tested, you no longer need to worry about that part of your program. Being able to use the function without having to worry about its details makes it easier for you to manage the rest of your program.
- **Functions eliminate redundant code** – Once a function is defined, you can use the function over and over again in your program. Without functions, you are more likely to write the same code fragment multiple times, which can lead to more errors in your programs.
- **Functions make a program easier to maintain** – If you discover a bug in a function, you only have to correct the bug in one place, the function definition. If there are multiple code fragments with the same error, you are likely to miss it in at least one instance, or it will take you longer to find all instances of the bug.
- **Functions make your code portable** – Once you have written a function and tested it, you can use that function in other programs. Later in this text we will learn how to create .h files that contain user-defined functions.

There are other advantages to functions besides these, but these are the ones that should mean the most to you as you begin to learn C++ programming.

## Void Functions

A *void function* is a function that does not return a value. This type of function is sometimes called a *subroutine* or a *subprocedure*. Void functions are similar to value-returning functions in that they are defined in the same space where value-returning functions are defined, they can have parameters and they have a function body. Void functions just don't return a value. So you may ask – what are they used for if they don't return values?

Here's an example. You are writing a program that has to print a heading at the beginning of every page of a report, say just the name of the person preparing the report and the date. The lines of code might look like this:

```
cout << "\t" << "Mary Smith" << endl;

cout << "\t" << date << endl;
```

Because this code fragment has to be used in several places, it should be placed inside a function. However, it doesn't return any data, it just writes out two lines to the console, so it has to be placed in a void function.

A void function is defined similarly to a value-returning function. Here is the definition for the example above:

```cpp
void printHeading(string date)
{
    cout << "\t" << "Mary Smith" << endl;
    cout << "\t" << date << endl;
}
```

A void function can't be called in as many places as a value-returning function since it doesn't return a value. Most void functions are written (called) as a complete statement, like this:

```cpp
string date;
cout << "Enter the date for the heading: ";
cin >> date;
printHeading(date);
```

## Pass-by-value Versus Pass-by-reference

Another use for void functions is modifying the values of two variables at the same time. A common operation in computer programming is to swap the value of two variables, such as in a sorting operation. For example, if we need to sort two string variables into alphabetic order, we can call a void function to perform the swap. Here is the code for the swap function, along with the code that calls the function:

```cpp

```

Running the program again, we get the following output:

```
banana apple
apple banana
banana apple
```

So the values are switched inside the function but revert back to the original values after the function call.

The reason our values aren't being switched is due to a rule of parameter passing in C++. This rule states that by default, the parameters to a function are passed by value from the calling program to the function. The phrase “by value” means that when a function is called, the C++ compiler makes a copy of the parameter values and passes that copy to the called function. When the function is complete and control returns to the program, the values of the parameters are removed from memory, even if they have been changed, as in the swap() function example above, and the variables in the program retain their original values (they never actually lost their value as copies were made for use by the function parameters).

If we want a called function to be able to permanently change the function parameters, we have to pass the parameters by reference. Passing “by reference” means that the compiler is, in effect, passing the actual parameter to the function, so that the function can access and change the value of the parameter such that it will retain its new value when control is passed back to the calling program.

To pass a parameter by reference, place an ampersand (&) before the parameter name. The ampersand is called the reference operator. We’ll discuss it more later in the book.
