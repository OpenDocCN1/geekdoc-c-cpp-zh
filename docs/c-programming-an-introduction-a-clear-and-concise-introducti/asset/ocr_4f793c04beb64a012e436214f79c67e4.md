# Advantages to Functions

Creating and using functions provide several distinct advantages to your programs. Here are some of them:

+   - **Functions simplify a program** – Once a function has been created and tested, you no longer need to worry about that part of your program. Being able to use the function without having to worry about its details makes it easier for you to manage the rest of your program.
+   - **Functions eliminate redundant code** – Once a function is defined, you can use the function over and over again in your program. Without functions, you are more likely to write the same code fragment multiple times, which can lead to more errors in your programs.
+   - **Functions make a program easier to maintain** – If you discover a bug in a function, you only have to correct the bug in one place, the function definition. If there are multiple code fragments with the same error, you are likely to miss it in at least one instance, or it will take you longer to find all instances of the bug.
+   - **Function make your code portable** – Once you have written a function and tested it, you can use that function in other programs. Later in this text we will learn how to create .h files that contain user-defined functions.
