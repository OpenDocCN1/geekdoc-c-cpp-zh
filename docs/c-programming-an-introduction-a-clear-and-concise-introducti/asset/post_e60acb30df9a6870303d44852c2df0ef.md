## Chapter 13: Additional C++ Control Flow Constructs

The major C++ control flow constructs are the if statement for decisions, the while and for loops for repetition, and functions for allowing blocks of code to be treated as one unit. In this chapter, we'll examine a few constructs that also modify the control flow of a program – the switch statement for an alternative way of making decisions, and the do-while loop for an alternative way of performing repetition.

### The switch Statement

The *switch* statement provides an alternative to the if statement for making decisions about which set of statements to execute based on a condition. The switch statement is generally considered less flexible than the if statement for many decisions because the condition tested in a switch statement must be an expression that evaluates to an integral value. In practice, this means that to use the switch statement, your program must require that decisions be based on expressions of type int or char. However, in the right situation, a switch statement can be easier to create, modify, and read than an if statement.

#### Writing a switch Statement

The general form of the switch statement is:

```cpp
switch (expression)
{
    case const-expr:
        set of statements;
        break;
    case const-expr:
        set of statements;
        break;
    ...
    default:
        set of statements;
}
```

The expression tested, as mentioned above, must be of an integral type, typically an integer or a character. The branching to a set of statements occurs in the case clause portion of the switch statement. The constant expression (const-expr) in the case clause is compared with the opening expression. If the comparison is true, the set of statements inside that clause are executed and then control is transferred out of the switch statement due to the break statement. If the comparison is false, control falls to the next case clause. If none of the case clauses are executed and a default clause is present, the statements inside the default clause are executed.

Some examples will probably clear up any misconceptions you have about how the switch statement works. In this first example, a letter grade is entered and the possible numeric range of the letter grade is displayed:

```cpp
// Switch.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
using namespace std;

int main(array<System::String ^> ^args)
{
    char letterGrade;
    cout << "Enter your letter grade: ";
    cin >> letterGrade;
    switch (letterGrade)
    {
        case 'A':
            cout << "A grade is in the range of 90-100."
                 << endl;
            break;
        case 'B':
            cout << "B grade is in the range of 80-89."
                 << endl;
            break;
        case 'C':
            cout << "C grade is in the range of 70-79."
                 << endl;
            break;
        case 'D':
            cout << "D grade is in the range of 60-69."
                 << endl;
            break;
        case 'F':
            cout << "An F grade is in the range of 0-59."
                 << endl;
            break;
        default:
            cout << "The letter grade must be A-D,"
                 << " or F." << endl;
    }
    Console::ReadKey();
    return 0;
}
```

Now let’s look at an example where we let some of the case clauses “fall through.” You do this if you want the same set of statements to be executed when two or more case clauses are true. Sticking with letter grades, here's a program that determines if a student passes or fails a test, based on the letter grade (A, B, C, and D grades are all passing; only F is a failing grade):

```cpp
// Switch.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
using namespace std;

int main(array<System::String ^> ^args)
{
    char letterGrade;
    cout << "Enter your letter grade: ";
    cin >> letterGrade;
    switch (letterGrade)
    {
        case 'A':
        case 'B':
        case 'C':
        case 'D':
            cout << "You passed the test!" << endl;
            break;
        case 'F':
            cout << "Sorry, you failed the test."
                 << endl;
            break;
        default:
            cout << "Enter a valid letter grade."
                 << endl;
    }
    Console::ReadKey();
    return 0;
}
```

When the user enters an A, B, C, or D, the compiler lets control fall through the case clauses until an executable statement is encountered. That statement is executed, and control falls out of the switch statement due to the break statement. If the user enters an F, only the last case clause is true, so its statement is executed and control falls out of the switch statement. If the grade is anything other than A, B, C, D, or F, the default clause is executed.

Here's one more example that doesn't involve test grades. This program analyzes a sentence to determine how many vowels are in the sentence. It does this by looping through the sentence examining each letter. We wrote a function called isVowel that uses a switch statement to determine if the letter presented to the function is or is not a vowel. At the end of the program, the number of vowels is displayed. Here's the code:

```cpp
// isVowel.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <string>
using namespace std;

bool isVowel(char letter)
{
    switch (letter)
    {
        case 'a': case 'A': case 'e': case 'E': case 'i':
        case 'I': case 'o': case 'O': case 'u':
        case 'U':
            return true;
            break;
        default:
            return false;
    }
}

int main(array<System::String ^> ^args)
{
    string sentence;
    char ltr;
    int numVowels = 0;
    cout << "Enter a sentence: ";
    getline(cin, sentence);
    for(int i = 0; i < sentence.size(); ++i)
    {
        ltr = sentence[i];
        if (isVowel(ltr))
            ++numVowels;
    }
    cout << "There are " << numVowels
         << " vowels in the sentence.";
    Console::ReadKey();
    return 0;
}
```

If we enter the following sentence:

Now is the time for all good people to come to the aid of their party

the output is:

There are 23 vowels in the sentence.

We perform one very interesting trick in this program. We loop through the sentence variable like it is an array. We can do that because, to C++, a string is an array. Internally, C++ stores a string as an array of char values. Knowing this allowed us to easily loop through the string, pulling each character out by using its index position in the “string” array and determining if the letter is a vowel or a consonant. We'll look more at treating strings as arrays when we talk about pointers later in the book.

The switch statement cannot be a universal replacement for the if statement due to the requirement that the condition being tested must be an integral expression. However, for those situations where it is applicable, the switch statement provides an easy-to-read, easy-to-modify alternative.

### The do-while Loop

For many repetition problems in C++, the condition to be tested comes at the beginning of the loop, before any statements are executed. This is normal for many situations, but there are situations where you might want to execute the body of the loop before the condition is tested. For these situations, C++ provides an alternative repetition statement, the do-while loop.

#### Using the do-while Loop

The general form of the do-while loop is:

```cpp
do
{
    set of statements;
} while (condition);
```

The condition that controls the loop is after the statements to be executed, which guarantees that the body of the loop will be executed at least once. This is not the case with a while loop, where if the condition isn't true before the first time into the loop, the loop doesn't execute at all.
