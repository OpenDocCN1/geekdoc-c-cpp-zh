Now let's look at a situation where we need to use the || operator. An old child's game is speaking in pig latin. In pig latin, words are formed based on whether they begin with a vowel or with a consonant. If the word starts with a consonant, the first letter is moved to the back of the word and "ay" is added. For example, the word "dog" in pig latin is "ogday." If the word starts with a vowel, the pig latin word is formed by adding "ay" to the end of the word. So "apple" in pig latin is "appleay."

To write a pig latin converter in C++, we need to be able to look at the first letter of the word to decide which conversion technique to use. There is a C++ string function that pulls out a partial string from a string called substr. We can use that function to examine the first character of the word. Then we need to determine if the letter is a vowel or a consonant, and we can do that with an if statement with several conditions joined with the || operator. We'll have to decide whether to look for a vowel or a consonant, and since there are fewer vowels than consonants, we'll look for vowels to determine which conversion technique to use.

In English, we would say something like, “if the first letter is an 'a', or the first letter is an 'e', or the first letter is an 'i', or the first letter is an 'o', or the first letter is a 'u'...” We can say that in C++ like this:

```cpp
if ((letter == "a") || (letter == "e") ||
    (letter == "i") || (letter == "o") ||
    (letter == "u"))
```

Now let's put that into a complete program that will identify the type of letter that starts a word:

```cpp
// pigLatin.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <string>
using namespace std;

int main(array<System::String ^> ^args)
{
    string word, letter;
    cout << "Enter a word: ";
    cin >> word;
    letter = word.substr(0,1);
    if ((letter == "a") || (letter == "e") ||
        (letter == "i") || (letter == "o") ||
        (letter == "u"))
        cout << letter << " is a vowel";

    else
        cout << letter << " is a consonant";
    Console::ReadKey();
    return 0;
}
```

For this program to work, you need to include a reference to the string library, which is placed right under the reference to the iostream library.

## Chapter 7: Repetition

Decision-making via if statements is the first of the really powerful programming constructs needed to write useful programs. The second programming construct we need is repetition. Humans are bad at doing things over and over again; we get bored and tired and eventually start making mistakes. Computers, however, never get tired or bored and can perform the same tasks hours on end without ever making even the slightest mistake. In this section we'll study how to perform repetition in C++, also called looping, using the while loop statement.

### The while Loop

One means of performing repetition in C++ is using the while loop. The while loop examines a condition, much like an if statement does, executing a set of statements repeated while the condition is true. The process of executing statements multiple times is called *iteration*.

The general form of the while loop looks like this:

```cpp
while (condition)
{
    statement1;
    statement2;
    statementn;
}
```
