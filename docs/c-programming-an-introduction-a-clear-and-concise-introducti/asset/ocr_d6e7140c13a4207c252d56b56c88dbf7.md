The first element of an array is stored in position 0. The position is called the index. An index is referenced in C++ code using subscript notation, just as we used with vectors. If the array above is named numbers, then to access the first element we would write:

```
numbers[0]
```

Because arrays always start at position 0, the number of items in an array is always one larger than the last position of the array, also called the *upper-bound*.

# Declaring One-Dimensional Arrays

Arrays must be declared just like variables are declared. The general form of an array declaration is:

```
data-type array-name[ number of elements];
```

```
string names[10];
```
