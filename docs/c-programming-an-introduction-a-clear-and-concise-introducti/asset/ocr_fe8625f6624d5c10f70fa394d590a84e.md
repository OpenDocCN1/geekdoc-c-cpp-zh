A block is created inside the block of the main() function. This is not common but is definitely legal C++ code.

The output from this program is:

```
The value of number is: 1
The value of number in this block is: 100
The value of number is: 5
```

There are two distinct number variables in this code, one version declared in the main() function and the other declared in the block within the main() function. The variable declared within the inner block is removed from memory once execution leaves the inner block, but during the execution of the inner block it is this instance of the variable that is visible.

Block-level scoping is an important concept that keeps programs from becoming polluted with variable values. A long program can have many for loops and other block-level constructs, and if the variables that controlled these constructs had to be visible throughout the life of the program, our programs would be wasting a lot of memory, not to mention the mental work that is involved in keeping up with a large amount of variables.
