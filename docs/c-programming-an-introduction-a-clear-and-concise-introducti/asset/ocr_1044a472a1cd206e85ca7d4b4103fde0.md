Here's another example: You have to write a program to find the maximum value in a set of numbers stored in a file. In the line where the variable to store the maximum value is declared, you initialize its value to 0. You run the program and it reports that the maximum value is 0. Huh? After scratching your head for awhile, you go look at the data file and see that all the numbers in the file are negative numbers. Clearly, no value ever passed the test (currentValue > max), when max is equal to 0, so 0 is the maximum value according to the logic of your program.

Finding errors of this type can be as much of an art as it is a science. You have to work through each line of the program carefully, and you must have a thorough understanding of the data your program is working with. Experience is the best teacher for finding errors. The more experience you have, the better you will get. And you will gain experience with errors if you continue to write programs.
