# Logic Errors

Once your program compiles and runs, any errors that occur will have to be what are called *logic errors*, or errors in the logic of the program. Logic errors are much harder to find than syntax errors because a computer program only does what the programmer tells it to do, and nothing more. A program can't decipher what the programmer meant to do with the code or she writes; it can only execute the statements as it comes across them.
