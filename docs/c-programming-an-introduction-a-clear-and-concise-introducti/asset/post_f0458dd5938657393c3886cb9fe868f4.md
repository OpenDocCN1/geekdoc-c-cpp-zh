## Chapter 12 File Input and Output

The data we've worked with up to this point have been stored in memory in a variable, a vector, or an array. Once a program stops running, however, this data is removed from memory. If you want the data from a program to be saved permanently, you have to store the data in a file. This chapter discusses how to create files for saving data and how to read data from a file using C++.

### Working With Files and Streams

To C++, a file is a sequence of characters (bytes) with the end of the file marked by a special end-of-file marker. Like input and output to the console, C++ associates a file to a stream which is used to communicate with the file. The header file fstream must be included in a file that wants to read or write to a file.

Generally, there are two types of files you can work with in C++, **binary** and **text** files. Binary files, also called *random-access files*, are more efficient with storage space than text files but are somewhat harder to program. Text files, also called *sequential access files*, or just *sequential files*, are less efficient but easier to program and can be edited with standard text editors. We will work exclusively with text files in this chapter.

### Creating a Text File

Most readers will already know what a text file looks like. You've probably created them using Notepad or some other text editor. Instead of entering the text for a file from the keyboard, we are going to write a C++ program to create a simple text file that stores a list of grades.

The first step in our program is to include the fstream header file in our program, as we mentioned earlier. The next step is to create a file object that represents the file we are going to create. When we write data to the console, we use a built-in object that is associated with the console, cout. We can create our own object for a file by declaring an identifier of ofstream type, which stands for "output stream." A file we are creating is considered an output file.

Creating a file object involves more than just declaring the object. We also have to specify the name of the file. We do this by naming the full path to the file, unless the file is located in the same directory as the program. This is not often the case, though, so the complete path is usually given as the argument. For example, if we want to store our grades file in a subdirectory named data that is just off the root directory, we can create the file object with this statement:

```cpp
ofstream outFile("c:\\data\\grades.txt");
```

Notice that the path string includes two backslashes before each directory name. If we don't do this, C++ tries to interpret the single backslash as a special character, such as "\t", which represents the tab character. Using two backslashes ensures that the compiler won't interpret parts of the file path string as special characters.

This statement not only creates the text file and associates the file with our file object, it also opens the file. So the file is now ready to receive data from the program. To write data to the file, send data to the file object in the same manner you send data to the cout object. Here is an example:

```cpp
outFile << 85;
```

The two characters, 8 and 5, are written to the file in the first two positions of the file since they are the first characters written to the file. If we write another similar statement:

```cpp
outFile << 77;
```

the characters 77 will be written directly next to 85, so that the file looks like this:

```text
8577
```

If you want a space between the two grades, or if you want to put the second grade, 77, on the next line, you have to write either the space character or the newline character to the file. The statement would be

Once you are finished writing data to the file, you have to close the file to be sure the data is actually stored in the file. The statement to do this is:

```cpp
outFile.close();
```

Here is the complete program for writing the grades 85 and 77 to a file, with each grade on a separate line:

```cpp
// CreateFile.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <fstream>
using namespace std;

int main(array<System::String ^> ^args)
{
    ofstream outFile("C:\\data\\grades.txt");
    outFile << 85;
    outFile << endl;
    outFile << 77;
    outFile.close();
    Console::ReadKey();
    return 0;
}
```
