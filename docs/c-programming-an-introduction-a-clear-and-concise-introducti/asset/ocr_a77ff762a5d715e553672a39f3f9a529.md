# File Input and Output

The data we've worked with up to this point have been stored in memory in a variable, a vector, or an array. Once a program stops running, however, this data is removed from memory. If you want the data from a program to be saved permanently, you have to store the data in a file. This chapter discusses how to create files for saving data and how to read data from a file using C++.

# Working With Files and Streams

To C++, a file is a sequence of characters (bytes) with the end of the file marked by a special end-of-file marker. Like input and output to the console, C++ associates a file to a stream which is used to communicate with the file. The header file fstream must be included in a file that wants to read or write to a file.

Generally, there are two types of files you can work with in C++, **binary** and **text** files. Binary files, also called *random-access files*, are more efficient with storage space than text files but are somewhat harder to program. Text files, also called *sequential access files*, or just *sequential files*, are less efficient but easier to program and can be edited with standard text editors. We will work exclusively with text files in this chapter.
