# # Arrays

We have already looked at one data structure for organizing data into a list – the vector. There is another data structure that can be used to not only organize data into lists, but also organize data into tables and even three dimensional structures. That data structure is called the array. In this chapter we'll look at two types of arrays – the one-dimensional array that organizes data into a list, and the two-dimensional array, which organizes data into tables.

# ## One-Dimensional Arrays

The vector is one way to organize data one-dimensionally. Another way is using an array. Arrays are very similar to vectors. An array is a group of data items of the same data type grouped under a single variable name. Each data item can be accessed by its *index* position in the array, starting with position 0, just like a vector. An array, however, is a fixed-length data structure, unlike a vector, which can grow when it has reached its capacity.

Graphically, an array looks like a vector:
