# ## Exercises

1. Rewrite the following program fragment as a single if-else statement:

```
year = 2010;
if ((year % 4 == 0)
    cout << "The year is a leap year.";
if ((year % 4) != 0) {
    year = year + 4 - year % 4;
    cout << year + " is the next leap year.";
}
```

2. Rewrite the following code fragment removing any unnecessary comparisons:

```
if (age > 64)
    cout << "Senior voter";
if (age < 18)
    cout << "Under age";
if (( age >= 18) && (age < 65))
    cout << "Regular voter";
```

3. Write a program that accepts a single letter as input from the user and displays the corresponding digit on the telephone. The letters and digits are grouped on the telephone like this:

| Digit | Letters | Digit | Letters | Digit | Letters | Digit | Letters |
|---|---|---|---|---|---|---|---|
| 2 | ABC | 4 | GHI | 6 | MNO | 8 | TUV |
| 3 | DEF | 5 | JKL | 7 | PRS | 9 | WXY |

There is no digit for Q or Z, so the program should display a message to the user indicating this. Be sure to include a prompt for the user to enter a letter.
