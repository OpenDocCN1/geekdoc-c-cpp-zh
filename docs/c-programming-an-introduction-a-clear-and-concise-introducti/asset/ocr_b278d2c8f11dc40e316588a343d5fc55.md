Logic errors come in all shapes and sizes so we can only just give you a couple of examples to demonstrate how logic errors differ from syntax errors. The following program displays the last element of an array of numbers:

```
    // ErrorHandling.cpp : main project file.

    #include "stdafx.h"
    using namespace System;

    #include <iostream>
    using namespace std;

    int main(array<System::String ^> ^args)
    {
        const int size = 10;
        int numbers[size];
        for(int i = 0; i < size; ++i)
            numbers[i] = i + 1;
        cout << "The last item in the array is: "
             << numbers[size] << endl;
        Console::ReadKey();
        return 0;
    }
```

Can you spot the error? If not, what do you think the output should be? Now, run the program to see what the output actually is:

The last item in the array is -1231954775

But you thought the last item should be 10.

If you look carefully at the code, you'll see that the constant size was used in the cout statement and the value of size is 10. However, the upper bound of the array is 9, so the subscript that should have been used to display the last array element is size-1.
