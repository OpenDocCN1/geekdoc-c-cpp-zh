# More on Output With cout

We've seen several examples of how to use cout to display data on the console. Most of the examples we've seen have been of the form: cout << expression, but there are many more ways we can use cout to display data. We can combine data types like this:

```
```cpp
cout << "Pi has the value ";
cout << 3.14159;
```
```

These are output on the same line – Pi has the value 3.14159 – because we didn’t specify a newline. There is no reason, though, to use cout twice here when we could have combined the two statements into one (here we also use a variable for the value 3.14159) by stringing << operators together:
