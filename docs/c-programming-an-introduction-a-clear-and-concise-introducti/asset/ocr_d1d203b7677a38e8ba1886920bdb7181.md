# ## Using the *if* Statement to Make Decisions

Using relational and logical expression alone are not enough when solving a programming problem that has involves decisions; there must be some way to control which statements get executed based on the results of the relational and/or logical expressions. One tool for making decisions in C++ is the *if* statement.

# ## The *if-else* Statement

The simplest form of the *if* statement is the *if-else* statement. This statement is used to either execute one set of statements or another set of statements based on the value of a condition, which can be either a relational expression or a logical expression.

The general form of the *if-else* statement looks like this:

```
```
if (condition)
    statement1
else
    statement2
```
```

The *if-else* statement works this way – if the condition evaluates to true, execute statement₁, otherwise execute statement₂. Let's look at an example in C++:

```
```
int hoursWorked;
cout << "Enter the number of hours worked: ";
cin >> hoursWorked;
```
```
