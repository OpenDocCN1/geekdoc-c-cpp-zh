# Determining the Average Grade

For our first problem we'll find the average of a set of test scores. The test scores are: 78, 85, 92, 99, and 81. Solving the problem involves finding the sum of the test scores and dividing the sum by the number of test scores to obtain the average. To write a program to solve this problem, we will need variables for the test scores (variables for the test scores are not absolutely required here, but we will create them to get some practice using variables), a variable for the total of the test scores, and a variable to hold the average.

First, we need to determine the data types of the variables. The test scores are all whole numbers, so the test score variables will be declared as integers. The total number of test scores is also a whole number and, therefore, an integer, but we want to declare it as a constant to demonstrate how constants are used. The sum of the test scores will also be declared as an integer variable. The average, though, can be a floating-point value so we need to declare the variable as a double.
