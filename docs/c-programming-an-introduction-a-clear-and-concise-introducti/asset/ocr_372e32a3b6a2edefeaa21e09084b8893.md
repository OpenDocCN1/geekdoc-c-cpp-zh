+   6	7
+   7	8
+   8	9
+   9	10

There are times, though, when you want to initialize an array with values other than default values. You can do this using an *initializer list*. Here's an example of how to declare an array with an initializer list:

```
int grades[5] = {84, 77, 99, 100, 87};
```

The list is a brace-delimited list with each value separated by commas. The number of data elements in the list must match the declared size of the array. You can also leave the declared size out of the brackets and the compiler will automatically determine the array size, like this:

```
int grades[] = {84, 77, 99, 100, 87};
```

A third alternative is to leave the initializer list empty, which causes the compiler to assign the declared data type's default value to the elements of the array. Here is an example:

```
int grades[5] = {};
```

When you use an empty initializer list you must specify the array size in the declaration.

You can also provide an initializer list that has less elements than the declared size of the array, such as:

```
int grades[5] = {84, 77, 99}
```
