
## Classes Defined

When we create a class in C++, we create two distinct parts – the data members (also just called members) which define the attributes of a class, and the methods (implemented as functions), which describe the behavior of the class.

Members and methods are defined in two distinct sections of a class, either the public section or the private section. Members and methods which are defined in the public section of a class are visible to all other objects in a program. Members and methods which are defined in the private section of a class are visible only to the class itself, and not other objects interacting with the class. This will all make more sense when we examine a few examples.

Class definitions are placed in the global area, in the same place where you define functions. A class definition begins with the keyword class and a class name, followed by a block, which is where the member and method definitions are placed. For example, to create a Name class we start the definition like this:

```cpp
class Name
{
    // member and method definitions go here
};
```

Notice that the closing brace of the block is followed by a semicolon. The definitions of new types must always end with a semicolon in C++.

The next step in defining a class is to determine the members for the class. Sticking with our Name example, the members of a name can include the first name, the middle name, and the last name. We could also include things like nicknames, suffixes (Jr., Sr. etc.), but to keep things simple we'll limit a name to the first, middle, and last names.

After we determine the members of the class, we have to decide if the members are going to be placed in the public section or the private section. A common rule when defining a class is to make the members private and use public methods to access and modify their values.

The keywords public and private are called *access modifiers*. They determine the access level for a member or a method. A method or member that is declared as public can be accessed by any code in a program. A method or member that has been declared as private can only be accessed within the class definition and not by any code that uses the class.

Let’s extend our definition of the Name class by including declarations for the members:

```cpp
class Name
{
    private:
    string first, middle, last;
};
```

As you can see, the private section of a class is marked by the keyword private and a colon. Everything declared and defined below it is considered private to the class.

We now need to define a method by which we can place data into the class. This method definitely needs to be made public so that the program using the class can access the method. The method is called setName and here is its definition within the full class definition:

```cpp
class Name
{
    private:
    string first, middle, last;

    public:

    void setName(string firstName, string middleName,
                 string lastName)
    {
        first = firstName;
        middle = middleName;
        last = lastName;
    }
};
```

We’re almost ready to take our class out for a test drive, but first we need a method that allows us to display a name. We'll call this method getName() and place it in the public section as well:

```cpp
class Name
{
    private:
    string first, middle, last;

    public:

    void setName(string firstName, string middleName,
                 string lastName)
    {
        first = firstName;
        middle = middleName;
        last = lastName;
    }

    string getName()
    {
        return first + " " + middle + " " + last;
    }
};
```

Now we can use the class in a program. First, we need to declare a Name object:

```cpp
Name aName;
```

aName is declared as a Name object. It is important to understand the distinction between a class and an object. A class defines a data type and an object is an instance of that type.

After creating an object of Name type, we need to put data into the object. We can do that with the setName() method:

```cpp
aName.setName("John", "Quincy", "Adams");
```

We can then display the name using the getName() method. This method returns each member as one concatenated string, with spaces between the first and middle names.

Rather than show just another piece of the program, here is the complete program, including the Name class definition:

```cpp
// NameClass.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <string>
using namespace std;

class Name
{
    private:
    string first, middle, last;

    public:

    void setName(string firstName, string middleName,
                 string lastName)
    {
        first = firstName;
        middle = middleName;
        last = lastName;
    }

    string getName()
    {
        return first + " " + middle + " " + last;
    }
};

int main(array<System::String ^> ^args)
{
    Name aName;
    aName.setName("John", "Quincy", "Adams");
    cout << aName.getName() << endl;
    Console::ReadKey();
    return 0;
}
```

The output from this program is:

John Quincy Adams

## Using Constructor Methods to Create Class Objects

One of the design goals when creating a class is to make the class as flexible as possible. This means providing different alternatives for accomplishing tasks using the class. One example of providing flexibility in a class is having several ways of entering data into an object.

Earlier we discussed one way of entering data using the setName() method. There will also be times when you want to enter the data for an object when you are declaring the object. To do this, you need a special type of method called a constructor.

A constructor method for the Name class works exactly like the setName() method, in that it will have arguments for each of the members and the body of the method will assign the arguments of the method to the corresponding member. A major difference between a standard class method and a constructor method is that the constructor method has the same name as the class. For example, here is one possible definition of a constructor for the Name class:

```cpp
Name(string firstName, string middleName,
      string lastName)
{
    first = firstName;
    middle = middleName;
    last = lastName;
}
```

With this definition of the constructor, we can create a new object like this:

```cpp
Name yourName("Gene", "Ray", "Williams");
```

This makes working with classes more flexible because we're allowing the user of the class to declare an object with data just as it can be done with variables.

There is one problem, though. C++ won't let us use this constructor method until we create a second constructor method, known as a *default constructor*. A default constructor is a method with no arguments that assigns default values to the members of a class. The Visual C++ compiler will not allow a constructor method to be defined if there is not a default constructor method also defined. Before we defined our first constructor, the compiler let us run the program because if no constructor is provided, the compiler provides its own default constructor. However, once we define a constructor, we also have to provide a definition for a default constructor as well.

So, before we can use the constructor above, we have to define a default constructor. Here it is:

```cpp
Name()
{
    first = "";
    middle = "";
    last = "";
}
```

One thing you may have noticed by now is that we now have two constructor methods with the same name. You learned early in this book that C++ doesn't allow two identifiers to be the same within the same scope, such as when you try to declare a second variable in main() that has the same name as an already declared variable.
