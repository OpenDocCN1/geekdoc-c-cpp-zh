# Pointers and Arrays

Pointers and arrays have a very close relationship in C++. In fact, the relationship is so close that an array name can serve as a pointer into the first element of the array.

First, let's see how we would create a pointer to an array using standard pointer techniques. The following program creates an array of 100 random numbers, displays the first element of the array, initializes a pointer variable to point to the array, and prints the first element of the array via the pointer:

```
```cpp
// PointersAndArrays.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main(array<System::String ^>^args)
{
        int nums[100];
        srand(time(NULL));
        const int size = 100;
        for(int i = 0; i < size; ++i)
            nums[i] = rand() % 100 + 1;
        cout << nums[0] << endl;
        int *ptrNums;
        ptrNums = &nums[0];
        cout << *ptrNums;
        Console::ReadKey();
        return 0;
}
