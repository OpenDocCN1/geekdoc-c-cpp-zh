## Chapter 2: Data Types and Variables

You can think of a computer program as being much like a recipe. What’s in a recipe? A recipe consists of a list of ingredients and a list of instructions for transforming the ingredients into something edible. A computer program consists of data plus instructions that tell the computer how to transform the data into the information wanted from the program. So, to understand how to write programs, we first need to understand how to work with data.

Working with data in C++ involves two things – determining the data types of the data and providing storage space for the data. This chapter will discuss a few of the more common data types in C++ and then explain how to create variables so you can store data in memory while your program is running.

### C++ Data Types

Before discussing the various data types used in C++, we need to talk about why having data types is important. First, data types define and limit the range of operations that can be performed on data. For example, it makes sense to add integers together but it doesn’t make sense to add a boolean value to an integer. Along the same line, data types also ensure that the correct type of operation is performed for that type, so that if we want to add two floating-point numbers, the floating-point addition operation will be performed. Otherwise, we would have to have a separate addition operation for each operation rather than being able to use a common operator (+) for all numeric types.

Now let’s look at some of the common data types for C++. They are:

1. `int` – For integer values in the range of approximately -2,000,000,000 to 2,000,000,000
2. `double` – For double precision floating-point numbers in the range of approximately -3.4e-308 to 3.4e308 (or 17 digits)
3. `char` – For single character values (i.e., letters and symbols). Stored as an integer value in the range of -128 to 127.
4. `bool` (boolean) – For true or false values. Range is true or false.
5. `string` – For character data more than one character in length.

The first four of these data types are built into C++ and are considered fundamental data types. The `string` data type is not built into the language, but its use is such that it can be treated as a fundamental type.

There is much more to data types and we'll add to this discussion as we delve more deeply into C++ programming.

### Declaring Variables in C++

A variable is a named location of memory where data is stored while a program is running. Variables are created in C++ using the declaration statement. A declaration consists of at least the data type of the variable and the variable name. A declaration can also assign an initial value to a variable using something called an initializer. Let's start this post talking about the rules for creating variable names.

The rules for creating variables in C++ is simple – a variable name must begin with an alphabetic character; a variable name may contain other alphabetic characters, digits, and the underscore character; a variable name cannot be a C++ reserved word.

Here are some examples of legal C++ variables:

- `number`
- `last_name`
- `firstName`
- `hourlyWage`
- `PI`

Variable names that consist of more than one word can either use an underscore to separate the words, or you can combine the two words into one and capitalize the first letter of the second word. This style of variable naming is called “camel casing” and is a very popular style of naming variables, not the least of which because it is easier to capitalize a letter than it is to type the underscore character. Camel casing is, however, just a style convention and you are not required to use it. You should, though, pick a particular style and be consistent in using it.

Here are some examples of illegal variable names:

- `first name`
- `1num`
- `while`

The first illegal variable contains a space; the second example begins with a digit; the third example is a C++ reserved word.

Variable names should always be meaningful so that the name identifies the nature of the data stored in it. A meaningful variable name is `hoursWorked`; a meaningless variable name is `hw`.

To declare a variable, you first write the data type for the variable followed by the variable name. Here are some examples:

```
int hoursWorked;
bool endOfData;
string lastName;
```

Each of these lines is a separate statement, as noted by the semicolon at the end of the line. All statements in C++ are ended with a semicolon. These particular statements are called declaration statements. There will be much more discussion of statements as we learn about C++.
