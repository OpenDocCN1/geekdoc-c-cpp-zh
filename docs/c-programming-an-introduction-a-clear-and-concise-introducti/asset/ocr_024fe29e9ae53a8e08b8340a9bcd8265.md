# Additional C++ Control Flow Constructs

The major C++ control flow constructs are the if statement for decisions, the while and for loops for repetition, and functions for allowing blocks of code to be treated as one unit. In this chapter, we'll examine a few constructs that also modify the control flow of a program – the switch statement for an alternative way of making decisions, and the do-while loop for an alternative way of performing repetition.

# ***The switch Statement***

The *switch* statement provides an alternative to the if statement for making decisions about which set of statements to execute based on a condition. The switch statement is generally considered less flexible than the if statement for many decisions because the condition tested in a switch statement must evaluate be an expression that evaluates to an integral value. In practice, this means that to use the switch statement, your program must require that decisions be based on expressions of type int or char. However, in the right situation, a switch statement can be easier to create, modify, and read than an if statement.
