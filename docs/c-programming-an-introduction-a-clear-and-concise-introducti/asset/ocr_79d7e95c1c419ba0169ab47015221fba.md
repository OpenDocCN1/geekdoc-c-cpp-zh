memory for 10 string values and call the array names. You can also
declare more than one array of the same data type on the same line, as
you can with variables, like this:

```
```cpp
int grades[20], numbers[100];
```
```

This line creates two arrays, one named grades with 20 elements and one
named numbers with two elements, both of int type.

When specifying the number of elements in an array declaration,
you must use an integer literal or an integer constant. If you try to use a
variable, the compiler will issue an error saying that it was expecting an
constant expression. So, a declaration like this is fine:

```
```cpp
const int size = 10;
int numbers[size];
```
```

but a declaration like this will result in an error:

```
```cpp
int size = 10;
int numbers[size]
```
