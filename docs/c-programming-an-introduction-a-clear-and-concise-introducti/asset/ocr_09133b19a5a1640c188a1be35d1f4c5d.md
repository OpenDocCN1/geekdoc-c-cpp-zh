# Incrementing and Decrementing

One of the most common statements in all programming looks something
like this:

```
```cpp
count = count + 1;
```
```

There are innumerable situations where we need to increment the
value of a variable by 1. To make it easy to perform this operation, C++
has a dedicated operator that increments a variable by 1, the ++ operator.

The ++ operator is used like this:

```
```cpp
int count = 0;
++count; // the value of count goes from 0 to 1
```
```

You can also put the operator after the variable, like this:

```
```cpp
count++;
```
```

A logical question to ask is – what difference does it make whether
we put the ++ operator before the variable or after the variable? When a
variable exists by itself in the statement, there is no difference. However,
if a variable is used in a more complex statement, it can make a great
difference. Here is an example that demonstrates the difference:

```
```cpp
int var1, var2;
var1 = 1;
// var1 gets the value 2 and var2 gets the value 2
var2 = ++var1;
```
```
