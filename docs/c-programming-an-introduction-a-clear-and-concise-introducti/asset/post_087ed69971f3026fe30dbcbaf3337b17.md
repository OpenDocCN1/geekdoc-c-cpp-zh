
The relational operators are:

- `==` Equal to
- `!=` Not equal to
- `>` Greater than
- `<` Less than
- `>=` Greater than or equal to
- `<=` Less than or equal to

These operators are *binary* so they require operands on both sides of the operator. These operands can be any expression, including a literal value. The combination of a relational operator with two operands is called a *relational expression*.

A relational expression always evaluates to a boolean value, either true or false. Here are some examples of relational expressions:

```cpp
(2 == 2) // true
(50 >= 50) // true
(34 <= 272) // true
(9 != 9) // false
("Ronald" == "ronald")
// false because "R" is not equal to "r"
("baboon" > "ape")
// true because "b" is greater than "a"
```

Of course, variables can be used in relational expressions as well as literals. Notice that relational expressions must be written inside parentheses in C++. Some other languages (Visual Basic, for example) don't have this requirement.

## Logical Operators

More complex comparisons require the programmer to sometimes combine two or more relational expressions. These types of comparisons are called logical expressions and are performed with the logical operators. The logical operators are:

- `&&` And
- `||` Or
- `!` Not

Here is one example of how the `&&` logical operator is used with two relational expressions (assuming we have declared the variables `workerType` and `hoursWorked`):

```cpp
((workerType == "hourly") && (hoursWorked > 40))
```

Notice that both expressions must be surrounded by parentheses both individually and as a group.

`&&` logical expressions return true if all the relational expressions are true and they return false if either or both of the relational expressions is false. We can summarize this behavior with a truth table:

| Rel Exp 1 | Rel Exp 2 | Result |
|---|---|---|
| True | True | True |
| True | False | False |
| False | True | False |
| False | False | False |

Here is an example of an `||` logical expression:

```cpp
((hoursWorked < 41) || (workerType == "salary"))
```

In an `||` logical expression, the expression is true if either of the relational expressions is true, and is false only if both relational expressions are false. Here is the truth table for `||` expressions:

| Rel Exp 1 | Rel Exp 2 | Result |
|---|---|---|
| True | True | True |
| True | False | True |
| False | True | True |
| False | False | False |

The final logical operator is the `!` (not) operator. This operator is a unary operator and negates the value of a boolean expression. For example:

```cpp
! (2 == 2) // false
! (3 < 2) // true
```

We will not use the `!` operator often in this text. In fact, we'll only use it when working with text files, as you'll see later in the book.

## Using the *if* Statement to Make Decisions

Using relational and logical expressions alone is not enough when solving a programming problem that involves decisions; there must be some way to control which statements get executed based on the results of the relational and/or logical expressions. One tool for making decisions in C++ is the *if* statement.

### The *if-else* Statement

The simplest form of the *if* statement is the *if-else* statement. This statement is used to either execute one set of statements or another set of statements based on the value of a condition, which can be either a relational expression or a logical expression.

The general form of the *if-else* statement looks like this:

```cpp
if (condition)
    statement1
else
    statement2
```

The *if-else* statement works this way – if the condition evaluates to true, execute statement₁, otherwise execute statement₂. Let's look at an example in C++:

```cpp
int hoursWorked;
cout << "Enter the number of hours worked: ";
cin >> hoursWorked;
```

```cpp
double rate = 25.00;
double pay;
if (hoursWorked > 40)
    pay = (40 * rate) + ((hoursWorked - 40) * (rate
        * 1.5));
else
    pay = (hoursWorked * rate);
```

The value stored in `pay` depends on what the user enters for the `hoursWorked` variable. If the user enters an amount greater than 40, then the value of `pay` is set by the statement directly under the condition. If the user enters 40 or less for the number of hours worked, the value of `pay` is set by the statement under the `else`.

You'll notice in the example above that only one statement is executed if the condition is true and only one statement is executed if the condition is false. You are not limited to just one executed statement for each possible result of an if-else statement if you use curly braces to place the multiple statements in a block. The general form of this version of the if-else statement looks like this:

```cpp
if (condition)
{
    statement₁;
    statement₂;
    statementₙ;
}
else
{
    statement₁;
    statement₂;
    statementₙ;
}
```

When this form of the if-else is used, the first block of statements are executed when the condition is true and the second block of statements are executed when the condition is false. Let's look at an example:

```cpp
int grade, bonus;
bool passFail;
cout << "Enter your grade: ";
cin >> grade;
if (grade >= 70)
{
    passFail = true;
    bonus += 5;
}
else
    passFail = false;
```

In the example above, a passing grade (70 or above) sets a boolean variable to true and gives five bonus points. A failing grade only sets the boolean variable to false.

In order to save a little space, you will often see a block in an if-else statement written with the opening curly brace on the same line as the condition, as in:

```cpp
if (grade >= 70) {
    passFail = true;
    bonus += 5;
}
```

Starting the block this way is a stylistic convention you may follow if you want to, but whatever style you choose, you should be consistent and use the same style all the time.

An if statement can be placed inside an if statement. This is called a nested if statement. Here is an example:

```cpp
int num1, num2, num3;
cout << "Enter three numbers: ";
cin >> num1 >> num2 >> num3;
if (num1 > num2)
    if (num1 > num3)
        cout << "The largest number is " << num1
             << endl;
```

If the first condition is true, then the second if statement nested inside the first if statement is executed.

When you want to use an else statement with a nested if statement, the else statement is always paired with the closest if statement. For example:

```cpp
if (guess != number)
    if (guess < number)
        high = guess - 1;
    else
        high = guess + 1;
```

If you want the else to be joined with the first if statement, you can use braces around the nested if statement, like this:

```cpp
if (guess != number) {
    if (guess < number)
        low = guess + 1;
    else
        high = guess + 1;
}
else
    if (guess > number)
        high = guess - 1;
```

Indentation helps indicate your intent when writing nested if statements, but using braces will guarantee the compiler executes the code in the manner intended by the programmer.

### The if-else if Statement

How would you use an if statement to assign the appropriate letter grade to a numerical test score? One way would be to write a series of individual if statements like this:

```cpp
int numGrade;

string letterGrade;

cout << "Enter the numerical score: ";

cin >> numGrade;

if (numGrade >= 90)
    letterGrade = "A";

if (numGrade >= 80)
    letterGrade = "B";

if (numGrade >= 70)
    letterGrade = "C";

if (numGrade >= 60)
    letterGrade = "D";

if (numGrade < 60)
    letterGrade = "F";
```

This program solves the problem but results in unnecessary computation. If the user enters the number 86, the program will assign the value "B" to letterGrade, but will then continue down testing numGrade in each of the remaining if statements. What we would prefer to happen is that once the program assigns the letter grade to the variable, the program should not perform any more tests on numGrade and move on to its next task.

The solution to this problem is to use another variation of the if statement – the if-else if statement. The general form of the if-else if statement looks like this:

```cpp
if (condition)
    statement;
else if (condition)
```
