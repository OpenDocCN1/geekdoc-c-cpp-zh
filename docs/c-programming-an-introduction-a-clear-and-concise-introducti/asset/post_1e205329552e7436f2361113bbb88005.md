## Chapter 5: Getting Data Into and Out of Programs

The three examples discussed in the last chapter suggest that most computer programs follow very standard stages of development. First, the program has to get data into variables, which we'll call the Input stage. This stage includes declaring variables and constants and assigning data to the variables, including getting input from the user, which we'll examine next.

The second stage is the Processing stage. In the examples above, the Processing stage involved writing one or more arithmetic expressions and assigning the values from those expressions to variables. In more complex programs, this stage can be much more involved than in the less complex examples we saw earlier.

The final stage is the Output stage. In this stage we display the result of the Processing stage to the user by writing data to the console, though in this stage with more complex programs we might write data to a file or a database or send the data to a printer. In this book we will mostly display output to the console, though we will at least touch on how to store data in a file.

As I just mentioned, the Processing stage of a program is usually somewhat more complex than the examples we've looked at so far. We are almost ready to discuss how to write more complicated programs to solve more complicated problems, but before we do we need to discuss more about getting data into our programs and displaying output to the console.

### Getting Input With cin

The most common way to getting data into our programs is by entering it from the keyboard. C++ considers the keyboard to be the standard input device and has an object defined for the keyboard - cin. The operator used to get data from cin is the >> ("get from") operator. The general form for getting input from the keyboard is:

```cpp
cin >> identifier;
```

where identifier is usually a variable. Here is a simple example of how cin is used to get data from the keyboard:

```cpp
int number;
cout << "Enter a number: ";
cin >> number;
```

In this example, after the prompt, the user enters an integer value from the keyboard and the value is stored in the variable number. The data type of the identifier determines what is stored by the >> operator. If the value entered is an integer, then the value is stored in the variable as entered. If the value entered is a floating-point value, however, then just the whole number is stored. So if the value 3.14159 is entered in the example above, the value 3 is stored in number.

You can enter more than one value in a single cin statement by separating variables with the >> operator. The following code fragment demonstrates how this works:

```cpp
int number1, number2, sum;
cout << "Enter two numbers: ";
cin >> number1 >> number2;
sum = number1 + number2;
cout << sum << endl;
```

The program runs like this:

```text
Enter two numbers: 2 3
5
```

The first number entered is stored in number1 and the second number entered is stored in number2. Obviously, you must put a space between the two input values.

String values can be entered the same way. Here is an example:

If the user enters "Mary", the program outputs:

```text
Hello, Mary
```

But if the user enters "Mary Smith", the program outputs:

```text
Hello, Mary
```

What happened? Remember, the space between the two input values separates the input into distinct values. Since there wasn't a variable to hold "Smith", the program just ignored it. To read a whole line into a variable, you need to use the getline() function. Here is an example of how the function works:

```cpp
string name;
cout << "Enter your name: ";
getline(cin, name);
cout << "Hello, " << name;
```

Now when the user enters "Mary Smith", the program outputs:

Hello, Mary Smith

You can enter as long of a string as you want and the variable will expand to hold the string automatically.

### More on Output With cout

We've seen several examples of how to use cout to display data on the console. Most of the examples we've seen have been of the form: cout << expression, but there are many more ways we can use cout to display data. We can combine data types like this:

```cpp
cout << "Pi has the value ";
cout << 3.14159;
```

These are output on the same line – Pi has the value 3.14159 – because we didn’t specify a newline. There is no reason, though, to use cout twice here when we could have combined the two statements into one (here we also use a variable for the value 3.14159) by stringing << operators together:

## Chapter 6: Decisions

So far, the C++ programs we have discussed have run in a sequential manner, starting with the first line of the program and continuing line-by-line to the last line of the program. For very simple problems, a sequential solution might be sufficient, but for more complex problems we need to be able to make decisions in our programs as to which lines of the program should be executed and which lines should be skipped.

For example, a company's payroll program has to decide whether to pay a worker straight time if the worker only worked their regular hours or to pay the worker overtime if the worker worked more than their regular hours. Another example is a program that prompts the user to enter their user name and password. This program has to decide if the user name and password entered match a list of acceptable user names and passwords in order to either let the user into the system or to keep them out of the system. Decisions like these are made using some form of the if statement. However, before we can look at how to use the if statement we have to talk about how we compare values in C++ using *relational* and *logical* expressions.

### Relational Expressions

Decisions are made in C++ programs by comparing two or more data values. For example, to determine if a worker should be paid overtime wages, a program will compare the number of hours the worker worked with the minimum number of hours needed to be paid for overtime, which is often 40 hours. This comparison is made with a relational expression that employs one or more of the relational operators.
