When the user enters an A, B, C, or D, the compiler lets control fall through the case clauses until an executable statement is encountered. That statement is executed, and control falls out of the switch statement due to the break statement. If the user enters a F, only the last case clause is true, so its statement is executed and control falls out of the switch statement. If the grade is anything other than A, B, C, D, or F, the default clause is executed.

Here's one more example that doesn't involve test grades. This program analyzes a sentence to determine how many vowels are in the sentence. It does this by looping through the sentence examining each letter. We wrote a function called isVowel that uses a switch statement to determine if the letter presented to the function is or is not a vowel. At the end of the program, the number of vowels displayed. Here's the code:

```
```cpp
// isVowel.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <string>
using namespace std;

bool isVowel(char letter)
{
    switch (letter)
    {
        case 'a': case 'A': case 'e': case 'E': case 'i':
        case 'I': case 'o': case 'O': case 'u':
        case 'U':
            return true;
            break;
        default:
            return false;
    }
}
