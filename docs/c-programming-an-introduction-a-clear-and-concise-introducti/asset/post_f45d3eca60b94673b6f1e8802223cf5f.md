return 0;
}

## Reading Data From a Text File

We discussed reading text from a file in Chapter 8, but we will cover the material again now that you know more about how files and streams work in C++.

The technique for reading data from a file is similar to how we read data from the console and with how we created a text file earlier. We need a file object; we have to associate that object with an input stream, and we read data from the file into a variable.

Instead of creating a file object for output, to read data from a text file we create a file object for input. This means that we have to use the ifstream data type instead of the ofstream data type. The statement needed to open a file for input looks like this:

```cpp
ifstream inFile("c:\\data\\grades.txt");
```

Next, you need to create a variable to store the data being read. Then you can read the data from the file into the variable, using a statement like this (the variable declaration is included, as well):

```cpp
int grade;
inFile >> grade;
```

Then you can do whatever you need to do with the data you just read into the variable. Since the data in the file is stored one grade per line, to get the next grade, just use the above statement again:

```cpp
inFile >> grade;
```

Each time you read a value from the grades.txt file, an internal pointer automatically moves to the next value so that when you issue another input statement, a new data value will be read into the variable. If the data had been stored on one line, instead of on separate lines, we would have had to put a space between each value so that the compiler would know where to place the pointer to read the next value.

You can continue on in this fashion, reading data from the file and storing it in a variable until you are out of data to read. Before the program ends, you should close the file to ensure the file doesn't become corrupted. We saw how to close a file earlier:

```cpp
inFile.close();
```

Here is a program that reads and displays the first two grades from the grades.txt file:

```cpp
// ReadFile.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <fstream>
using namespace std;

int main(array<System::String ^> ^args)
{
    ifstream inFile("c:\\data\\grades.txt");
    int grade;
    inFile >> grade;
    cout << grade << endl;
    inFile >> grade;
    cout << grade << endl;
    inFile.close();
    Console::ReadKey();
    return 0;
}
```

This program isn’t what we really need for properly reading a text file because it assumes that the programmer knows exactly how much data is in the file. Remember that a pointer is automatically placed at the next data item to read after an input statement is executed. If a program tries to read beyond the last value in the file, an error is issued and the program will crash. To keep this from happening, you should write your programs so that they use a loop to read the data, using a special condition to determine when the end of the file is reached.

The condition we want to check for when reading data from a text file is called *eof*, which stands for end-of-file. C++ file objects have a method, titled eof(), which you can call to determine if you are at the end of the file. The method returns true if there is no more data to read, and false if there is more data to read.

Here is the program listing for a program that will read the complete grades.txt file and display each grade in the file using the eof() method:

```cpp
// ReadFile.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <fstream>
using namespace std;

int main(array<System::String ^> ^args)
{
    ifstream inFile("c:\\data\\grades.txt");
    int grade;
    while (!inFile.eof())
    {
        inFile >> grade;
        cout << grade << endl;
    }
    inFile.close();
    Console::ReadKey();
    return 0;
}
```

Notice that we use the ! (not) operator because the eof() method returns true if there is no more data in the file. While there is more data to read, the method returns false, which we have to negate with the ! operator until there actually isn't any more data to read.

Now let’s do something useful with this data, such as total the grades and determine the average. Here's how we do it:

```cpp
// ReadFile.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <fstream>
using namespace std;

int main(array<System::String ^> ^args)
{
    ifstream inFile("c:\\data\\grades.txt");
    int grade, total, numGrades;
    double average;
    total = numGrades = 0;
    while (!inFile.eof())
    {
        inFile >> grade;
        cout << grade << " ";
        total += grade;
        ++numGrades;
    }
    inFile.close();
    average = total / numGrades;
    cout << endl << "The average grade is: "
         << average << endl;
    Console::ReadKey();
    return 0;
}
```

The only code in this program you haven't seen before is the line:

```cpp
total = numGrades = 0;
```

Like all other statements, to evaluate it, work from right to left, so that the value 0 is assigned to numGrades and the value of numGrades (now 0) is assigned to total. Shortcut statements like this aren't always a good idea if they make your program hard to read. This particular statement, though, is simple enough that anyone with a modicum of programming knowledge will understand what it is doing.

## Appending Data to a Text File

Let's say you have a data file with your grades in it and the contents look like this:

```text
85
77
75
71
89
91
84
```

Later, you take a few more tests and you want to add those grades to the file so you can update your average. The easiest way to do that is to open the data file and append the data to the file.

C++ provides a way to open the file for that purpose by specifying the mode with which you wish to work with the file. The mode for appending data to a file is specified with the constant ios::app. The mode is an optional argument to the open() method. So if we want to open the file grades.txt for the purpose of appending data to the file, we write the following statement:

```cpp
ofstream outFile("c:\\data\\grades.txt", ios::app);
```

Now any new data written to the file will be written after the last data value already written to the file.

Here is a program that lets us add more data to the grades.txt file:

```cpp
// AppendFile.cpp : main project file.

#include "stdafx.h"
using namespace System;

#include <iostream>
#include <fstream>
using namespace std;

int main(array<System::String ^> ^args)
{
    ofstream outFile("c:\\data\\grades.txt",
        ios::app);
    outFile << endl; // next grade on new line
    int grade = 0;
    cout << "Enter a grade (-1 to quit): ";
    cin >> grade;
    while (grade > -1)
    {
        outFile << grade << endl;
        cout << "Enter a grade (-1 to quit): ";
        cin >> grade;
    }
    outFile.close();
    Console::ReadKey();
    return 0;
}
```

You'll notice that before we prompt the user to enter a new grade, we write a newline to the file. That is because when the file is opened to be appended, the internal file pointer points to the position just past the last grade written to the file, on the same line. In other words, if the last grade in the file is

```text
84
```

the contents of the last line of the file after the first grade is appended to the file will look like this (assuming 92 is the first grade appended to the file):

```text
8492
```

Our file structure is set up for one grade per line, so we need to write a newline to the file before adding any new grades, so that when 92 is written to the file, it is written on the next line after 84.

## A Brief Note About File Modes

In the previous section we used a file mode, ios::app, to specify that the file to be opened should be opened to be appended. If we hadn't used the file mode, the open() method would have assumed we meant to start a new file and the compiler would have erased the contents of the grades.txt file before writing any new data to the file. Obviously, you need to be very careful about how files are opened, especially when they are being opened for output.
