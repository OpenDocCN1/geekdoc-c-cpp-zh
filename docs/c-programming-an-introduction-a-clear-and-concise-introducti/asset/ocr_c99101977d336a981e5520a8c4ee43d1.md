# Two-Dimensional Arrays

One-dimensional arrays are used for storing lists of data. When you want to store data that is naturally organized as a table, you need to use a two-dimensional array. Two-dimensional arrays organize data into rows and columns. When we want to specify a single data item in a two-dimensional array we have to specify two positions, the row and the column of the data item.

# Declaring Two-Dimensional Arrays

A two-dimensional array is declared by specifying the number of rows and columns the array is to store. For example, if our data has two rows and two columns, the declaration for the array is:

```
```c
int numbers[2][2];
```
```

If the array has two rows and three columns, the declaration looks like this:

```
```c
int numbers[2][3];
```
```

The rows are always specified first in the declaration, followed by the columns. Of course, you should use constants in your programs rather than numeric literals (but we used literals here to save space).
