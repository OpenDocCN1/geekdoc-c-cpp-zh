# 13.3.3 Mouse and Keyboard Events

You do not need to handle mouse events explicitly if you just want the user to be able to click on a button or drag a slider. These mouse operations are handled entirely by the various controls in the user interface. However, if you want to enable the user to draw with the mouse, you will need to trap the events that happen as the user moves the mouse and clicks the mouse buttons.
