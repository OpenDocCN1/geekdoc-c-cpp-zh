For example, the get method of ObservableValue returns a String and the get method of ObservableIntegerValue returns an int. The return types of the methods of the Bindings are subinterfaces of the Binding interface, itself a subinterface of the Observable interface. A Binding knows about all properties on which it depends.

In practice, you don’t need to worry about all of these interfaces. You combine properties and you get something that you can bind to another property.
