> **NOTE:** According to the language standard: “The implementor must ensure
> `sgn(x.compareTo(y)) = -sgn(y.compareTo(x))` for all x and y. (This implies that
> `x.compareTo(y)` must throw an exception if `y.compareTo(x)` throws an exception.)”
> 
> Here, `sgn` is the sign of a number: `sgn(n)` is -1 if n is negative, 0 if n equals 0, and 1 if n is positive. In plain English, if you flip the parameters of `compareTo`, the sign (but not necessarily the actual value) of the result must also flip.
>
