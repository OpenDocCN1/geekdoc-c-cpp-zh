# Comma

,

Left to right

Consider the following code and try to compute the results. We will discuss the output

but it is better if you try it yourself before matching our results.

```
#include "iostream"

void main(void)
{

int a = 20, b = 10, c = 5;

a = b = c += 2;

printf("a= %d\n",a);

printf("b= %d\n",b);

printf("c= %d\n",c);

a = 20, b = 10, c = 5;

a = ++b -= c = 2;

printf("a= %d\n",a);

printf("b= %d\n",b);

printf("b= %d\n",c);

system("pause");

}
```
