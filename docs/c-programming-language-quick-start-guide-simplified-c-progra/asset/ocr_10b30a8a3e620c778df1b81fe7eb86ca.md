Here is an illustration of using a 1-D array, using initializer:

```c
void main(void)
{
    int table[10] = { 5, 10, 15, 20, 25, 30, 35, 40, 45, 50 };

    //printing elements of array
    for(int i = 0; i < 10 ; i++)
    {
        printf("5 x %d = %d\n",i+1,table[i]);
    }
    system("pause");
}
```
