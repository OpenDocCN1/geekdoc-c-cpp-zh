# 3.4 Storage Classes

Variables and functions in C have two attributes: type and storage class. You must have gathered around the first attribute so far. Let us now discuss the storage class attribute.

The storage classes are used for certain utilities of variables and functions. The most common storage class is auto. There are three other storage classes defined by these keywords:

+   - auto
+   - extern
+   - register
