By the early 1980s, the language has transformed itself into what it
looks like today,

commonly known as the traditional C. ANSI standard C was
introduced in the later part

of the same decade. The committee added the void, function
prototypes, a new function

definition syntax, and more functionality for the preprocessor, and in
general made the

language definition more precise.

ANSI C maintained its standard in an amazing way that it is still used
in many programs

as a system language. It is one of the most commonly used
programming languages of

the world, and it is found in colleges and universities for learning
purposes. It is mostly

the first programming course offered to any IT students. C++ is an
extension of ANSI

standard C which incorporates the object oriented programming
paradigm, which kind

of revolutionized the programming world. This book describes the
ANSI version of the C

language, along with some topics in C++ as well.
