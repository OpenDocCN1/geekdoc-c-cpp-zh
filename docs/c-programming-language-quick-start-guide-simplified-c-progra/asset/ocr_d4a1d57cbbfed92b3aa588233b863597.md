```
int strcmp(const char *s1, const char *s2);
```

Compares two strings. It returns a value less than 0 if first string is less than second, a value greater than 0 if first string is greater than second and returns 0 if both are equal.

```
char *strcpy(char *s1, const char *s2);
```

String s1 is overwritten by String s2 and s1 is returned.

```
size_t strlen(const char *s)
```

Returns number of characters in string s, excluding the ending character.
