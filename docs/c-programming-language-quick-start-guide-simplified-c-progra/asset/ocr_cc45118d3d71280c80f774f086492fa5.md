We used preprocessor #define to declare a constant PI in this program. This is a flexible and recommended way to use constants in C. There is another way to use constants as well using the keyword ‘const’. Let us see how that works too:

```
```c
#include <iostream>
void main(void)
{
int radius=10;
const float PI=3.14159265359;
float Area=PI*radius*radius;
printf("This is a Program to demonstrate use of Constants in C\n");
printf("Radius of circle is: %d\n", radius);
printf("Area of circle is: %f\n", Area);
system("pause");
}
