## 1. Mac
`Mac` 完全运行在 `C` 之上，包括其驱动程序和程序，这适用于它的所有模型，就像 `Windows` 和 `Linux` 中的情况一样。

## 1. 手机
提到 `Windows` 手机、`android` 以及 `iOS`，它们的内核都是 `C` 语言编写的。简而言之，它们的内核编写方式与上述描述的计算机内核相同，只不过它们是移动端的适配版本。

## 1. 数据库
用于金融系统；电信；娱乐；健康和教育系统；通用网络及其他领域的数据库大部分用 `C` 甚至 `C++` 编写的。这些包括最流行的，如 `Oracle`、`MySQL`、`MS SQL Server` 甚至 `PostgreSQL`。

## 使用 C 语言的主要优势
1. 它是一门结构化语言。
2. 对于初学者来说，相对容易学习。
3. 它在编写程序时非常高效。
4. 它在不同的计算机平台上表现良好。
5. 它处理低级活动的能力也很好。

## C 语言的日常用途
对于初学者来说，提供一份 `C` 编程语言常用用途的分类可能会有所帮助。`C` 语言实际上很容易找到，不仅在操作系统中，而且在语言编译器；汇编器；文本编辑器；打印机处理程序；网络驱动程序；语言解释器；实用程序；网络驱动程序；以及前面提到的，在现代程序和数据库中。

足以说明，`C` 编程语言在现代软件应用程序编写者中非常受欢迎，其中一些被用于 3D 电影和嵌入式系统（如电视、遥控器等）。

以一种常见的实用物品——汽车为例，以下是使用 `C` 语言编写的某些功能：
1. 自动变速箱。
2. 检测车辆轮胎压力的系统。
3. 监控氧气、温度和机油水平的传感器。
4. 各种内存类别，包括后视镜设置。
5. 仪表盘显示。
6. 防锁死刹车（ABS）。
7. 自动车辆稳定性控制。
8. 巡航控制以及气囊控制。
9. 儿童锁系统。
10. 气候控制。

汽车示例只是其他拥有 `C` 语言编写系统的实用物品之一。甚至许多你购买汽水的自动售卖机都有 `C` 语言系统。许多商店的收银机也运行用 `C` 语言编写的程序。

这些让生活变得相对简单的设备共同点是嵌入式系统，它们像小电脑一样运行，拥有运行 `C` 语言编写程序的微处理器。这就是为什么当有人按下按键时系统会检测到并以预设的方式做出反应。它们还会相应地显示相关信息。许多实用制造商倾向于使用 `C` 语言编写程序，因为它具有灵活性；提高效率；并且与多种类型的硬件兼容。

## 为什么要费力学习 C 编程语言？
`C` 是今天用户可以使用的唯一编程语言吗？当然不是！程序员和其他计算机用户可以学习和利用其他的编程语言，有些比 `C` 低，有些比 `C` 高且更现代。那么为什么选择 `C` 呢……

除了书中已经提到的，还有其他学习 `C` 编程语言的理由。首先，`C` 编程语言在许多其他计算机语言被提出之前就已经存在了。因此，它建立了丰富的源代码库。简而言之，你可以学到很多东西，在这方面有丰富的资源池可以利用。`C` 还有许多函数你可以用来满足你的程序需求。

同时，由于 `C` 编程语言已经使用了很长时间，你不可能在使用时遇到无法快速获得解决方案的挑战。多年来，`C` 用户在互联网上发布问题并从其他用户专家那里获得解答，你可以从中学习很多关于 `C` 的知识。

此循环的工作原理与 `while` 循环几乎相同，但有一处不同。它的循环体在检查测试表达式之前就会执行。只有在初始执行之后，才会对测试表达式进行求值。如果测试表达式被证明为真，则 `do...while` 循环的体会再次执行。重复过程将一直持续，直到测试表达式返回零（`0`）值；这意味着它变为假。

### 1. 嵌套循环

#### a) 嵌套 `for` 循环的语法格式如下：

```
for ( init; condition; increment ) { for ( init; condition; increment) { statement; } statement }
```

#### b) 嵌套 `while` 循环的语法格式如下：

```
while(condition) { while (condition) {statement;} statement; }
```

#### c) 嵌套 `do...while` 循环的语法格式如下：

```
Do { statement; do { statement; } while (condition);
```

### 2. 无限循环

你是否设想过某种情况，即给定条件永远不会变为假？这类情况就需要使用 `for` 循环。当然，在三个 `for` 表达式中，没有一个是是必须。所以，你最终得到一个无尽的循环，仅仅是因为你的条件表达式将会为空。这就是你得到无尽——或无限循环的原因。万一你想终止你的无限循环，只需同时按下 `Ctrl + C` 键即可。

# 第 8 章：C 编程中的函数

你如何定义一个函数？嗯，对于 C 编程语言而言，函数可以被视为一组执行任务的语句，而不是作为独立的语句执行。你会在每个 C 程序中找到一个函数，即使它只有一个。本质上，你始终拥有一个 `main` 函数。其他函数作为由可能存在的简单程序定义的附加项出现。如果你愿意，可以将函数看作一个代码模块，它可以很方便地接收信息——那些传统上被称为 `parameters`（参数）的符号名称的信息——然后进行某些计算，并通常返回一些新的信息。当然，函数返回的信息取决于所捕获的参数信息。

`main` 函数有什么独特之处吗？是的，有的。尽管在处理时你把 `main` 函数当成任何其他函数对待，但它的独特之处在于，每当你作为计算机用户开始运行程序时，它是操作系统需要运行的唯一函数。简而言之，每当你开始运行机器时，第一个执行的代码就是 `main` 函数。

以下是 `main` 函数的结构化外观所示：

| Int | //如果成功，预期返回零 (0) |
| :--- | :--- |
| `Main()` | //这里是放置名称的地方，就此而言，是 main |
| {} | //这里是放置大量代码的地方；即函数体 |

在 C 语言中，代码被分为不同的函数，你可以根据自己的意愿进行划分。然而，从逻辑角度考虑，你需要将代码分配到现有的函数中，使每个函数都执行一个定义的任务。你实际上需要将每个 C 函数视为程序中的一个主要构建块。简单来说，你运行的每个 C 程序都是通过使用函数编写的。这样做是为了使程序能够重复使用并保持一致的效率，同时也使其更易理解。

当你继续学习 C 编程时，你会遇到一些术语，并需要知道它们在相关语境中的含义。其中一个术语就是函数声明。

## 函数声明

你还记得函数是什么吗？函数声明本身负责指示编译器关于函数名、返回类型以及函数参数。而函数体实际上是源自函数定义。

以下是函数定义在 C 中通常采用的格式：

```
Return_type function_name( parameter list ) {function body}
```

下面是函数定义的组成部分，包括头部和体，它们是主要部分：

### 1. 返回类型

预计函数将返回一个值；而且它确实可以返回。现在，该值具有特定的数据类型。该数据类型就是我们所说的 `return_type`。然而，正如你可能已经注意，有些函数在程序中运行良好，但它们并不返回值。在这种情况下，我们声明 `return_type` 为 `void` —— `void` 是 C 语言的关键字之一。

### 2. 函数名

这是函数的精确名称。

### 3. 参数

首先，你需要意识到，在 C 编程的函数中，你不一定需要处理参数。然而，当你拥有它们时，知道它们由什么组成很重要。你实际上可以像处理占位符一样获取参数。当你启动函数时，你给参数一个值。你可以引用这个值称为实际参数；或者说是 `argument`。

从参数你得到 `parameter list`；这涉及到函数拥有的类型。如果你将参数列表添加到函数名，你得到的就是函数签名。

### 4. 函数体

当涉及到函数体时，你在其中找到的是定义实际函数的语句集合。

## 为什么要使用函数？

让我们总结一下使用函数的重要性：

a) 避免重复编写程序代码的任务
b) 当你需要类似的功能时，可以调用函数
c) 得益于函数，你可以在任何时间、任何地方访问程序
d) 函数使你能够且方便地跟踪大型程序。因为你面对的不是原始的海量数据，而是被分解为逻辑函数的数据。

## C 函数如何工作

C 函数有三个不同的方面，即：

i) 原型，你也可以将其称为函数声明。它的作用是让编译器了解函数名、函数参数以及返回值的数据类型。函数声明的语法为：

```
return_type function_name( argument list );
```

ii) 函数调用。这是实际函数的调用者。它的语法为：

```
function_name( arguments list );
```

iii) 函数定义。这是你找到所需的全部语句集合的地方。函数定义的语法为：

```
return_type function_name( arguments list ) { body of function; }
```
