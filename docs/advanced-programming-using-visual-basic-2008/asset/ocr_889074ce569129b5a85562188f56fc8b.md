# Updating in a DetailsView or a FormView

You may choose to update in a GridView, a DetailsView, or a FormView. The GridView does not have an Insert option; however, a New / Insert option is available for the DetailsView and FormView. Both of these controls display a single record at a time, so you must make sure to turn on Enable Paging to allow navigation.
