The CreateUserWizard (Figure 7.39) control provides the ability to enter information for a new member and add it to the database. The wizard requires a strong password, which must contain at least seven characters and at least one nonalphabetic character. The control allows a user to enter a name, a password, password confirmation, e-mail address, and a security question and answer. The ContinueDestinationPageUrl property specifies the page to be displayed once the new user has been created.
