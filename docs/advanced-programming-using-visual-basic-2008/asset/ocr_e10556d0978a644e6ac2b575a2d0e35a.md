# The Delete and Cancel Logic

When an Add or Edit is in progress, the Delete button becomes the Cancel button.

# Deleting a Record

Pseudocode for a Delete Operation
Confirm if record is to be deleted.
If yes,
    Display “Record deleted” in the status bar.
    Execute the RemoveCurrent method of the binding source to delete a record
        from the dataset.

# Canceling an Operation

Pseudocode for a Cancel Operation
Cancel the edit (replace the text boxes with their previous contents).
Set AddingBoolean and EditingBoolean to False.
Enable navigation.
Set the text boxes’ ReadOnly property to True.
Reset the buttons for normal operation:
    Reset the Text property of the Add and Delete buttons.
    Set the Text of the Add button back to “Add”.
    Enable the Edit button.
Clear the message in the status bar.
