# The Titles Authors M:N Program

This M:N program is written as a multitier application. Figure 4.20 shows the data relationships and Figure 4.21 shows the user interface. The data tier fills the DataSet, returns the authors used to fill the combo box, and finds and returns the titles for an author that is passed as a parameter. Note that both classes have an Imports System.Data statement above the Class declaration.

> TIP
> If you get a Null Exception error when accessing the data, make sure that you have filled all of the tables in the DataSet.
