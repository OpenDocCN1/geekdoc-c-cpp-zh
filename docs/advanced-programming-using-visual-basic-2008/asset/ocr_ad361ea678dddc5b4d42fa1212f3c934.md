# Christian's Car Rentals

Modify the Customer menu option to display and allow editing of customer information. The fields are

First Name
Last Name
Street
City
State
Zip
Vehicle ID
Drivers License Number
Rental Date

Use detail fields and make sure that all changes have been made before the Customer form closes. Include the current record number and number of records in the status bar.
