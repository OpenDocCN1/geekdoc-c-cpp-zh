# Exception Handling

When you perform updates without writing any code, you cannot handle the exceptions. Many things can go wrong when the user adds and edits data. Often database constraints, such as a duplicate primary key and referential integrity violations, will cause exceptions. Bad input data and null fields also can cause exceptions.
