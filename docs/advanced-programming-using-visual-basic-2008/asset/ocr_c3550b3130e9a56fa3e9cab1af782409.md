# AJAX Control Toolkit

Before you can start using AJAX controls, you must download the AJAX toolkit and add controls to your toolbox. You will add the items to the toolbox during a step-by-step example that demonstrates extenders applied to a button control and a slide show extender added to an image control.

> **TIP**
> Always remember that a page using AJAX must contain one and only one ScriptManager control.

# Download and Use AJAX Controls—Step-by-Step

First you must download the AJAX toolkit zip file. Note that as of this writing, all URLs are correct, but they could change in the future.

# Download the AJAX Control Toolkit

+   1. **STEP 1:** Go to www.asp.net/ajax/ and click on the *Downloads* link. Feel free to investigate the site and view any files that you'd like to see.
+   2. **STEP 2:** Click on the *Download the Control Toolkit* button. You may need to scroll down the page to see the actual link for AjaxControlToolkit-Framework3.5SP1.zip.
+   3. **STEP 3:** Click on the link for the AJAX control toolkit zip file and you will be given a license agreement to which you must agree if you want to continue.
+   4. **STEP 4:** Save the file in a convenient location, so that you can find it for the next step.
+   5. **STEP 5:** Extract all of the files in the zip files, again choosing an easily found location.
