After you publish a Web site, you can examine the files. You can open the .aspx file with Notepad only to find that it does not contain the markup language code. The file is on the site as a placeholder for use as part of the URL. The bin folder contains the compiled files for the pages and the .dll files with the executable code for the Web site.

Although you can test publishing a Web site, you must be running IIS on your computer to be able to open the page in your browser using http://localhost/foldername/Default.aspx.
