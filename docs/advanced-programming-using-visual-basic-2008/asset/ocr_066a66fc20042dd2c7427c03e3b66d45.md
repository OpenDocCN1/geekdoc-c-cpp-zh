# Reviewing Combo Box Properties

Combo boxes and list boxes have several properties that you should know how to use. As you know, the DisplayMember determines the items that appear to the user. The ValueMember can hold a key that identifies the item that displays. For the JobComboBox, the DisplayMember holds the job description and the ValueMember holds the job_id (Figure 4.14). When the user makes a selection from a combo box, the control's SelectedIndexChanged and SelectionChangeCommitted events fire and the SelectedValue property is set to the ValueMember of the selected item. You will use the SelectedValue property to create the filter to find the matching employees.
