# Testing a Service—Step-by-Step

It's time to test this WCF Service.

# Test the Service

+   1. **STEP 1:** Set the service as the startup project by right-clicking on WcfService1 in the Solution Explorer and selecting *Set as StartUp Project*.
+   2. **STEP 2:** Run the program without debugging (Ctrl + F5).
+   3. **STEP 3:** Select the link for Service.svc (Figure 6.3).

*Select Service.svc to test the service.*

![](bbox=[0.075, 0.3, 0.878, 0.661])

+   4. **STEP 4:** The service is now created. As the execution message indicates, you now need to “create a client and use it to call the service” (Figure 6.4).
+   5. **STEP 5:** Notice the address generated for svcutil.exe. You can click on this link, if you wish, to open the wsdl and take a look at the WCF Service definition.
+   6. **STEP 6:** Close the browser window.
