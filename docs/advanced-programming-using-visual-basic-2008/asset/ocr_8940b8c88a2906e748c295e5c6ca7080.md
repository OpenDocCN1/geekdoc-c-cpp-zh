# Your Hands-On Programming Example

Create a project for Katali Club for reservations for its upcoming events. The reservations page should have a drop-down list that contains the names of the events. The user should be able to indicate the member number, name, phone number, and the number of guests. Use validation controls to require that an entry is made for each of the text boxes.

Use a WCF Service including an Insert method for the reservations table in the KataliClub database (available in the StudentData folder on the text Web site).

Store the event pricing and perform the calculations in a separate class for the business tier.
