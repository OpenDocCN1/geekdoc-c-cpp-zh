Notice that you can select from a Web site, an FTP server, or a file path as the location to publish the application. Options are available to publish offline or only online. When the application is available offline, a shortcut appears on the Start menu and the user can uninstall the application by using the Add or Remove programs option of the Control Panel.
If you click on the Application Files button, you will see a list that includes the .exe file for the project. You can click on Show all files to see other options.
Many settings are available on the Publish Options dialog that displays when you select the Options button. You may find it interesting to note that the check box for CD installations includes the ability to automatically start Setup when the CD is inserted.
