# Naming a Web Form

In a new Web site, the first page is called Default.aspx. For most Web sites, the first page to display is called either default or index. For that reason, Microsoft has set the name of the first page as Default. As we add more pages and links to the site, we will give each page a meaningful name.

# Opening an Existing Web Project

To open an existing Web site, first open the IDE and select File / Open Web Site. Browse to the folder that holds the Web page files and click Open.
