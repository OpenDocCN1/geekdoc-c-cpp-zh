# View the Contents of Expressions

At break time, you can view the current values of expressions in several ways.

The three most useful techniques are

+   1. Display the value in a DataTip, which is a ToolTip-like popup in the Editor window. Point to the variable or expression that you want to view and pause; the current value pops up in a DataTip.

![](bbox=[0.07, 0.64, 0.92, 0.78])

+   2. Use the Locals window, which displays all objects and variables that are within scope at break time. You can also expand the Me entry to see the state of the form's controls.
