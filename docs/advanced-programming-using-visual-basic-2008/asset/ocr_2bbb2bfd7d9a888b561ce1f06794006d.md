# Examining the Data Bindings

The actual data bindings for Web applications are very different from the Windows version. To view the bindings, open Ch08Bindings, select the smart tag on the FormView control, and select Edit Templates. Next, click on the PublIDLabel control and select Edit DataBindings from its smart tag. Notice that the PublIDLabel uses Text as the bindable property (Figure 8.11). The Binding for Text specifies that the field is bound to PublID in the data source.

The data binding for the Text property of PublIDLabel is accomplished with the selection for Binding for Text.
