# Displaying Records in Details View

As with a Windows project, the Data Sources window allows you to drag the table for a data grid or for a details view. One difference that you notice immediately is the lack of a binding navigator.

The Ch13ProductDetails program displays the Product ID, Product Name, Unit Price, Units In Stock, and the Discontinued fields. As you can see in Figure 13.11, Product Name is in a combo box, which is used to select the record to which to navigate.
