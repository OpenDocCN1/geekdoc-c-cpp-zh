# Setting the Focus to a Control

You can set the focus to an ASP Web control using the Focus method of the control or the SetFocus method of the page. For example, to set the initial focus to QuantityTextBox, use either of these two statements in the Page_Load event handler:

```
QuantityTextBox.Focus()
```

or

```
SetFocus(QuantityTextBox)
```
