# Creating Multiple Pages—Step-by-Step

This exercise creates the two forms shown in Figure 8.18.

# Create the Project

+   STEP 1: Create a Web site called Ch08DataMultiPage and save the solution file in the project folder.
+   STEP 2: Copy the Pubs database into the App_Data folder.
+   STEP 3: Set the Title property to "Ch08DataMultiPage".

# Set Up the Data Source

+   STEP 1: Add a SqlDataSource to the Default.aspx page; select all fields in the stores table of the Pubs database.
+   STEP 2: For portability, edit the hard-coded path in the Web.config connection string to "|DataDirectory|\Pubs.mdf".
