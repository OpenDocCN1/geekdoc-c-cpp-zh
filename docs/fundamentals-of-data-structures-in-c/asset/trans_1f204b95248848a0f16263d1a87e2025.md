### 63. 答案：
4 1

解释：
布尔表达式只需在表达式的真值未知之前进行求值。j 不等于零，意味着表达式的真值为 1。因为其后跟随 ||，且 true || (任何东西) 求值为真，因此剩余表达式不被求值，所以 i 的值保持不变。
同样，当表达式中涉及 && 运算符时，当任何操作数变为假时，整个表达式的真值变为假，因此剩余表达式不会被求值，因为 false && (任何东西) 求值为假。
