# 1.16.4 The strcmp() function

The strcmp() (string compare) function compares two strings to find whether the strings are equal or not. The general form or the syntax of strcmp() function is,

```
strcmp(string1, string2);
```

where string1 and string2 are valid string variables or string constants. The strcmp() function takes two arguments for comparing and returns an integer. The string in the first argument (i.e. string1) is compared with the string in the second argument (i.e., string2) character by character until it encounters a mismatch between the two strings or end of one of the two strings.
