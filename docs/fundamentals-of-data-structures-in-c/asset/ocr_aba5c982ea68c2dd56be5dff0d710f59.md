# 18. What is meant by static linked lists.

The advantage of using linked lists is to dynamically allocate memory for the nodes when needed. This is achieved using array of structures when the size of the array of structures is fixed, the type of lists is referred to as static linked lists and also is referred to as cursor implementation of linked lists.
