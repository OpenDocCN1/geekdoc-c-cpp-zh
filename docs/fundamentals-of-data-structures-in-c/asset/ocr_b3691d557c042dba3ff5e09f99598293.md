# Program A5 :

Write a program to generate fibonacci series using arrays.

```
/* Fiboarr.c */
#include <stdio.h>
void main()
{
    int i, n, fib[30];
    printf("Enter the limit : ");
    scanf("%d", &n);
    fib[0] = 0;
    fib[1] = 1;
    for(i = 2; i < n; i++)
    fib[i] = fib[i-1] + fib[i-2];
    printf("The fibonacci series is : ");
    for(i = 0; i < n; i++)
    printf("%d ", fib[i]);
}
```

```
The program displays the following output
Enter the limit : 8
The fibonacci series is : 0 1 1 2 3 5 8 13
```
