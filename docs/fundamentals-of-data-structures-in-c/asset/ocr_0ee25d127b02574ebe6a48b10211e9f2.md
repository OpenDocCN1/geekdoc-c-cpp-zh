# C Programming Basics

# 1.1 Introduction

C is a general-purpose structured programming language developed at Bell Laboratories in 1972. It was designed and written by a systems programmer named Dennis Ritchie. C was originally written for programming under an operating system called BASIC.

C is a powerful programming language, which has attracted considerable attention world wide because it is reliable, simple, easy to use, and highly portable (i.e., a program written in C can be transferred easily from one oprating system to another).

C is characterized by the ability to write very concise source programs since it includes a large number of operators within the language. It has a relatively small instruction set but includes extensive library functions, which enhance the basic instructions. Programmers can write additional library functions of their own. Thus, the user can extend the features and capabilities of the C language.

C is often described as a Middle Level programming language. This is not a reflection on its lack of programming power but more a reflection on its capability to access the system's low level functions. It was designed to have both relatively good programming efficiency and relatively good machine efficiency. The C compiler combines the capabilities of an assembly language with the features of a high-level language and hence it is well suited for writing both system software like Operating Systems, Interpreters, Editors and Assembly programs.
