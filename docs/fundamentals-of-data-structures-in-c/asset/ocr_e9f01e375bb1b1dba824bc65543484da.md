# Program S18:
Write a program to sort the numbers in ascending order.

```
/* ascend.c */
#include<stdio.h>
void main()
{
    int a[50], i, j, n, temp;
    printf("Enter the limit : ");
    scanf("%d", &n);
    printf("Enter the elements : ");
    for(i = 0 ; i < n ; i++)
        scanf("%d", &a[i]);
    for(i = 0 ; i < n-1; i++)
        for(j = i ; j < n; j++)
            if(a[i] > a[j])
            {
                temp = a[i];
                a[i] = a[j];
                a[j] = temp;
            }
    printf("The sorted list is : ");
    for(i = 0 ; i < n ; i++)
        printf("%d", a[i]);
}
```

> The program displays the following output
> Enter the limit : 5
> Enter the elements : 17 13 12 14 16
> The sorted list is : 12 13 14 16 17
