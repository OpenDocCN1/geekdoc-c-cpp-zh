# Program S1 :

Write a program for swapping (interchanging) two numbers (using three variables).

```
/* swap1.c /
#include<stdio.h>
void main()
{
int a, b, c;
printf("Enter two numbers : ");
scanf("%d %d", &a, &b);
printf("Before swapping . . \n");
printf("A = %d B = %d", a, b);
c = a;
a = b;
b = c;
printf("After swapping . . \n");
printf("A = %d B = %d", a, b);
}
```

The program displays the following output
Enter two numbers : 90 70
Before swapping . .
A = 90 B = 70
After swapping . .
A = 70 B = 90

# Program S2 :

Write a program for swapping (interchanging) two numbers (using two variables).

```
/* swap2.c /
#include<stdio.h>
void main()
{
int a, b;
printf("Enter two numbers : ");
scanf("%d %d", &a, &b);
printf("Before swapping . . \n");
printf("A = %d B = %d", a, b);
a = a + b;
b = a - b;
a = a - b;
printf("After swapping . . \n");
printf("A = %d B = %d", a, b);
}
```

The program displays the following output
Enter two numbers : 23 54
Before swapping . .
A = 23 B = 54
After swapping . .
A = 54 B = 23
