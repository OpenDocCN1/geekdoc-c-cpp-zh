# 50. ANSWER :

Compiler error: Multiple declaration for error.

# EXPLANATION :

The name error is used in the two meanings. One means that it is a enumerator constant with value 1. The another use is that it is a type name (due to typedef) for enum errorType. Given a situation the compiler cannot distinguish the meaning of error to know in what sense the error is used, hence you get the above error.
