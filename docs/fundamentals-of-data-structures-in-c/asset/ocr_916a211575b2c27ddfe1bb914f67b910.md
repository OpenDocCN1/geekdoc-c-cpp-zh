# 5.2 Linear Search

Linear search also referred as sequential search, is the simplest searching technique. The search begins at one end of the list and searches for the required element one by one until the element is found or till the end of the list is reached. The search is said to be successful if the search element is found and unsuccessful if the search element is not found in the list. The data items in the list need not be in a sorted order for linear search technique.

```
Algorithm for Linear Search
LINEAR_SEARCH (ARR, N, FIND)
where ARR is an array of N elements in which the element FIND is to be searched.
Step 1 : Repeat For I = 0, 1, 2, ..., N-1
Step 2 : If (ARR[I] = FIND) Then
    RETURN I
    [End of If structure]
Step 3 : [End of Step 1 For loop]
Step 4 : Return -1
END LINEAR_SEARCH()
```
