# 3.5 Linked Lists

Linked list or List is an ordered collection of elements. Each element in the list is referred as a node. Each node contains two fields namely,

+   - Data field
+   - Link field.

The data field contains the actual data (i.e., value) of the element to be stored in the list and the link field also referred as the next address field contains the address of the next node in the list. Fig. 3.6 helps you understand things better.
