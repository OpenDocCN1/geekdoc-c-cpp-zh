The reverse is not an edge (i.e., 2 to 1, 3 to 2 and so on). In a digraph, all edges are in same direction, which follows a path always moving in the same direction indicated by arrows. Such a path is referred as a directed path. In a digraph, the cycle is referred as a directed cycle.
