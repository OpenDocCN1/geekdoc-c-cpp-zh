# 8. ANSWER :

hai

# EXPLANATION :

\n - newline character \b - backspace character \r - linefeed character. The first printf() function prints the string, "ab" in a new line. The second printf() function initially moves backspace by one character (i.e., b) and removes the character b, and then prints the string, "st" in the same line. After the execution of the second line, the output is "as". The third printf() function initially moves to the first position of the same line (i.e., \r) and then prints the string, "hai" in the same line. After the execution of the third line, the output is "hai".
