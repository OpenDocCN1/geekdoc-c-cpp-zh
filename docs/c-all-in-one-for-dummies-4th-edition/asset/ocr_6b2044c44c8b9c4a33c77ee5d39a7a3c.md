> > The last four lines show how C++ handles int versus float values. The float values come in three forms: default, scientific notation, and hexadecimal notation with an exponent (p0). This last form is only available in C++17 and above, and you must include the -ftext-numeric-literals switch on the Other Compiler Options tab of the Global Compiler Settings dialog to use it. If you wanted to make the int into a float, you’d need to replace 123000 with (float)123000.
