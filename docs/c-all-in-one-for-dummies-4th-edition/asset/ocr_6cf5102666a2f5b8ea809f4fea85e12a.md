# Programming with Debuggers

A *debugger* is a special tool that you use for analyzing your code in various ways, including tracing the code line by line. (*Tracing* is the act of viewing the code execution flow in an application.) Take a look at the BuggyProgram example, shown in Listing 2-1. This is just a basic application with a `main()` and a couple of functions used to demonstrate the debugger.

# **LISTING 2-1:** Tracing a Simple Application

```
```cpp
#include <iostream>
#include <cstdlib>

using namespace std;

int CountRabbits(int original) {
    int result = original * 2;
    result = result + 10;
    result = result * 4;
    cout << "Calculating " << result << endl;
    return result * 10;
}

int CountAntelopes(int original) {
    int result = original + 10;
    result = result - 2;
    cout << "Calculating " << result << endl;
    return result;
}

int main() {
    int rabbits = 5;
    int antelopes = 5;
    rabbits = CountRabbits(rabbits);
    cout << "Rabbits now at " << rabbits << endl;
    antelopes = CountAntelopes(antelopes);
    cout << "Antelopes now at " << antelopes << endl;
    //system("PAUSE"); // add this for Windows
    return 0;
}
