If you work with enums (the code form of enumerations), you need to decide what to name your new type. For example, you can choose MyColor or MyColors. Many people, when they write a line such as enum MyColor {blue, red, green, yellow, black, beige};, make the name plural (MyColors) because this is a list of colors. It’s best to make the term singular, as in MyColor, because you use only one color at a time. When you declare a variable, it makes more sense: MyColor inkColor; would mean that inkColor is a color — not a group of colors.

# Implementing a class

To implement a class in C++, you use the keyword class. And then you add the name of the class, such as Pen. You then add an open brace, list your properties and methods, and end with a closing brace.

![](bbox=[0.163, 0.655, 0.228, 0.722])

Most people capitalize the first letter of a class name in C++, and if their class name is a word, they don’t capitalize the remaining letters. Although you don’t have to follow this rule, many people do. You can choose any name for a C++ class provided it is not a C++ keyword; it consists only of letters, digits, and underscores; and it does not start with a number.
