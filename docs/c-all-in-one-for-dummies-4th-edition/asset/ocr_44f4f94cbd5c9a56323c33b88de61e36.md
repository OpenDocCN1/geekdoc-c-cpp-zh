This instance starts out having the member values OneHitWonders = 1, NumberRecordings = 20, and Phone = 8675309. The only thing the user can specify is the NumberRecordings member. The other two members are set automatically by the class.

However, you don't have to do it this way. Perhaps you want the users of this class to be able to specify the PhoneNumber when they create an instance. Here's a modified form that does it for you:

```
````cpp
class MusicInfo {
public:
    int PhoneNumber;
    MusicInfo(int Phone) : PhoneNumber(Phone) {}
};

class MyShorana : public MusicInfo {
protected:
    int OneHitWonders;
    int NumberRecordings;
public:
    MyShorana(int Records, int Phone) : OneHitWonders(1),
        NumberRecordings(Records), MusicInfo(Phone) {}
};
````
```

Look carefully at the difference: The MyShorana class now has two parameters. The second is an integer that's passed into the base class through the portion:

```
`MusicInfo(Phone)`
```

So to use this class, you might do something like this:

```
`MyShorana CD(20, 5551212);`
```

This code snippet creates an instance of MyShorana, with the members initialized to OneHitWonders = 1, NumberRecordings = 20, and PhoneNumber = 5551212.
