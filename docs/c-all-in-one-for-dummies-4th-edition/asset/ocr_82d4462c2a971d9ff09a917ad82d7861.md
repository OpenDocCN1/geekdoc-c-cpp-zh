# Coding the library

At this point, you have what amounts to a blank header file in a static library project. Your static library could conflict with other libraries, so it’s important to add a namespace to your code. The example uses MyNamespace, but normally you’d use something related to you as a person or your company, such as MyCompanyInc. The MathLibrary heading, in Listing 3-5, shows what you need to create the library used for this example.
