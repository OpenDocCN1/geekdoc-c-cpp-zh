You can see that each method calls Changed() after each change. This function is in the base class, and it calls into the Mediator’s PartChanged() method, which does all the hard work. Also note that in some of the car parts classes, the Mediator doesn’t respond to their changes (such as the Wheel class), but the methods still call Change(). The reason is that you may add features whereby the Mediator would respond to these changes. Then you won’t have to check to see whether you included a Change() call; it’s already there. This approach helps avoid the problem of wondering why Mediator isn’t doing what it’s supposed to do when the code forgets to call Change().
