## 编写 SQL 查询

查询就是你向数据库提出的问题。SQL（结构化查询语言）用于从数据库中检索数据。最常用的命令是 SELECT。

- SELECT：从一张或多张表中检索数据
- FROM：指定要查询的表
- WHERE：根据条件筛选记录
- ORDER BY：对结果集排序

```sql
SELECT first_name, last_name
FROM employees
WHERE department = 'Engineering'
ORDER BY last_name;
```
