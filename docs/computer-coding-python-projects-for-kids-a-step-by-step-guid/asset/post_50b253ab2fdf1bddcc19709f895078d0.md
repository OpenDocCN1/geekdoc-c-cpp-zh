### Using a dictionary

A dictionary is another way you can store information in Python. It is similar to a list, but each item has two parts: a key and a value. You can test it out by typing this into the shell window.

```python
favourite_foods = {'Simon': 'pizza', 'Jill': 'pancakes', 'Roger': 'custard'}
```

A colon is used immediately after the key. This is the key. This is the value. Each item in the dictionary is separated by a comma. Dictionaries use curly brackets.

```python
print(favourite_foods)
```
