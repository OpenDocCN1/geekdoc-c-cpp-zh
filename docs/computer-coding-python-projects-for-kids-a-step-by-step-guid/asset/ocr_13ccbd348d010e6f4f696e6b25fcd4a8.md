# 6 Colour it!

You've drawn a nice, neat star, but it looks rather dull at the moment. Let's add some colour to make it more attractive. Change the code as shown on the right to paint your star yellow.

```
```python
import turtle as t

size = 300
points = 5
angle = 180 - (180 / points)

t.color('yellow') # This sets the star's colour to yellow.
t.begin_fill()    # This fills the star with colour.
for i in range(points):
    t.forward(size)
    t.right(angle)

t.end_fill()
```
