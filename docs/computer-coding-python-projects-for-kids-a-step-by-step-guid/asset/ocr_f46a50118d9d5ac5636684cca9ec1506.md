# How it works

Every pattern in this project is different because the program tells the turtle to face a random new direction before painting each line. The colour for each line is also chosen at random from a list of possible colours you’ve coded. So you can never predict exactly what the turtle will do!

# Mutant Rainbow flowchart

The program uses an infinite loop that continues to paint coloured lines for as long as the program is running. Only when you close the window will the turtle stop its mazy wanderings.
