# Decrypt

Decrypting the message is quite easy. In the encrypted version of your message, all the letters in even positions are letters from the original message. So you can use the `get_even_letters()` function to get them.

> Decrypting letters is easy.

```
def decrypt(message):
    even_letters = get_even_letters(message)
    new_message = ''.join(even_letters)
    return new_message
```
