

## 海龟速度

## 设置背景

接下来，让海龟准备好开始绘制，并设置窗口的背景颜色。你需要让海龟一开始就抬笔，这样在你希望它绘制之前，它不会画出线条。只有当它到达机器人的脚时（第 5 步），它才会开始绘制。将以下代码输入到你在第 3 步添加的代码下方。

抬起海龟的笔。

将海龟的速度设为 slow。

```python
t.penup()
t.speed('slow')
t.bgcolor('Dodger blue')
```

将窗口背景设为“Dodger blue”。

## 注释

你会注意到，这个程序中有几行以 `#` 符号开头。`#` 后面的文字是注释，添加它是为了让用户更容易阅读和理解代码。Python 知道应该忽略它们。

### 更改面部

你可以通过重新排列机器人的五官来改变它脸上的表情。要给它画出歪斜的眼睛和嘴巴，请使用右侧的代码。

![](img/1bd24ab186f69fb18194b4174ca15178_78_2.png)

```python

t.goto(-60, 160)
rectangle(5, 5, 'black')
t.goto(-45, 155)

```

这一行将左瞳孔向下移动。

这一行移动机器人的右瞳孔，使它看起来像在翻白眼。

海龟稍微向右转，这使嘴巴倾斜。

### 移动手臂

既然你可以一次绘制整条手臂，就可以改变它的位置，让机器人看起来像在挠头，或者可能在跳高地舞！为此，使用 `setheading()` 函数改变海龟开始绘制手臂时面向的方向。

```python
# arms
t.goto(-90, 80)
t.setheading(135)
arm('hot pink')

t.goto(10, 80)
t.setheading(315)
arm('hot pink')
```

让海龟指向窗口的左上角。

使用 arm 函数在右侧绘制一条手臂。

让海龟指向窗口的右下角。

使用 arm 函数在左侧绘制一条手臂。
