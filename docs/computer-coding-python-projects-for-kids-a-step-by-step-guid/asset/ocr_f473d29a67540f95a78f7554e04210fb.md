+   **9. Get the even letters**
+   
+   In this step, you’ll make a function that takes a message and produces a list containing all the even-numbered letters. The function uses a for loop with a range that goes from 0 to len(message), so that it checks all the letters in the string. Add this function under the code in Step 8.

```
```python
def get_even_letters(message):
    even_letters = []
    for counter in range(0, len(message)):
        if is_even(counter):
            even_letters.append(message[counter])
    return even_letters
```
