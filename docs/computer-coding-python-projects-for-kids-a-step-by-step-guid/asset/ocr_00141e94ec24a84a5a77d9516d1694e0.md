# ## Nested loops

You might remember reading about nested loops on page 35. You can put as many loops inside one another as you want. In this project, the outer loop runs six times. Each time the outer loop runs, the inner loop runs four times. So in total, the inner loop runs 6 x 4 = 24 times.
