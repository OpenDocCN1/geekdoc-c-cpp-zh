SAS proc plan and proc optex, and they compare the properties of designs created by this method to designs created by Das's method. The example below shows the use of proc plan and proc optex to construct a partially confounded 3 x 2^2 factorial blocked in 12 blocks of 4.

```
* Create Candidate set with proc plan ;
proc plan;
factors A=B 2 B=C=3;
output out=design A nvals=( 0 1)
B nvals=( 0 1)
C nvals=( 0 1 2);
*creates a balanced confounded design with 12 blocks;
* of size 4;
proc optex data=(b)k using prior option;
class A B C;
model A, B, B C=C, A*B A*C A*B*C/prior=0, 12, 36;
blocks structure=(12#4) noexchange niter=1000 keep=10;
generate n=48;
output out=design blockname=blk; run;
proc print; run;
```

The prior=0, 12, 36; option on the model statement prompts proc optex to search for a balanced confounded design, which may exist for certain block sizes and number of runs. If the prior option is removed, proc optex will find an approximately balanced confounded design where the information recovered will be approximately equal for all degrees of freedom in the model.
