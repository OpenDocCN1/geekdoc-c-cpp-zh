```
*Reads in the library of candidates;
data cat;
input Compound HE DMz SOK ;
datalines;
1 -12.221 -0.162 64.138
;
proc optdesign data=cat coding=static; id Compound;
model HE DMz SOK HE*HE DMz*DMz SOK*SOK HE*DMz HE*SOK DMz*SOK;
generate iter= 20 keep=5 ;
output out =desgn1 ;
proc print data=desgn1;
run;
```

With three factors there are ten coefficients in the general quadratic model so the number of runs in the design must be at least n = 10. By default proc optdesign creates a design with n = p + 10 candidates where p is the number of coefficients in the model. The option iter=20 keep=5 on the generate statement instructs proc optdesign to make 20 different searches for the D-optimal design with a random starting design and to keep the results of the best 5 searches. The output statement instructs proc optdesign to store the best design found in the SAS data file desgn1. The results of the proc print statement are shown below.
