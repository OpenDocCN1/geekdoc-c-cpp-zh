The mean squares in the type I ANOVA presented in Section 5.7 are pooled estimates of the variances for each source in the design. If the four observations for lot number $i$ are denoted by $Y_{i1}$, $Y_{i2}$, $Y_{i3}$, and $Y_{i4}$ as shown below,

| | Box 1 Preparation | | Box 2 Preparation | |
| :--- | :---: | :---: | :---: | :---: |
| | 1 | 2 | 1 | 1 |
| Lot | test 1 | test 2 | test 1 | test 1 |
| $i$ | $Y_{i1}$ | $Y_{i2}$ | $Y_{i3}$ | $Y_{i4}$ |

Snee (1983) shows that the variances to be pooled from each source to create the ANOVA mean squares are given by:

| Source | Variance $s_i^2$ |
| :--- | :--- |
| Error or test(prep) | $(Y_{2i} - Y_{1i})^2 / 2$ |
| prep(box) | $\frac{2}{3} (Y_{3i} - \frac{Y_{1i}+Y_{2i}}{2})^2$ |
| box | $\frac{3}{4} (Y_{4i} - \frac{Y_{1i}+Y_{2i}+Y_{3i}}{3})^2$ |
