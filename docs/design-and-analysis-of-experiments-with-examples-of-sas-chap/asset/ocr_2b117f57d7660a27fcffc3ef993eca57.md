# 11.11 Appendix-Example of Fitting Independent Factors

The SAS code below first illustrates how to transform mixture components to independent factors using the translation and rotation of axis described in Figure 11.9 and Equations (11.11) and (11.12). The data used is the pesticide formulation data from Table 11.1. Next, a grid of independent factors is generated over the simplex experimental region.

```
data form;
input x1 x2 x3 y;
x1x2=x1*x2; x1x3=x1*x3; x2x3=x2*x3;
datalines;
1 0 0 48.7
.8 .1 .1 49.5
6 0 .2 49.2
.5 .0 5 52.8
.5 .0 49.3
.5 .0 49.3 .333334 .333333 .333334 51.1
3 .2 .5 52.7
3 .2 .5 52.3
.1 .1 .8 60.7
1 .8 .1 49.9
0 0 1.0 64.9
0 .5 .5 53.6
0 .5 .5 53.6
*Creates independent factors w1 and w2;
data orth; set form;
w1=sqrt(6)*(2*x1-x2-x3);
w2=sqrt(18)*(x2-x3);
* Creates Grid for Predicted Values;
data grid;
do flag;
y=. ; flag=1;
do w1=-2.5 to 5.0 by .05;
do w2=-4.25 to 4.25 by .05;
output;
end;
end;
*Fits Grid to Simplex Region;
data grid; set grid;
if w1<-2.44944 then delete;
if w1<4.89998-((4.89998+2.44944)/4.24264)*w2;
if w1<4.89998-((4.89998+2.44944)/4.24264)*w2;
```
