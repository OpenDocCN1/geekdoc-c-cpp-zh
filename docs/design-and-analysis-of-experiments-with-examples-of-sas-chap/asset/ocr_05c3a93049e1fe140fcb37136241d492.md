If the lower constraint for mixture component \(x_i\) is defined to be \(l_i\), then the \(i\)th pseudo component is defined to be

```
\(x'_i = \frac{x_i - l_i}{1 - \sum_{k=1}^k l_i},\) (11.17)

```
\(x_i = l_i + \left( 1 - \sum_{i=1}^k l_i \right) x'_i,\) (11.18)
