For many nested sampling designs and staggered nested sampling designs involve only samples of size two. In this case half-normal plots of standard deviations can be used in the same way. To illustrate this, consider again the data in Table 5.2. The SAS commands below compute the variances within each sample, output them to a SAS file, s, using proc rank and the data step function gaminv to compute the gamma quantiles gam. Next proc sgplot is used to make the gamma probability plot. It is shown in Figure 5.5.

```
ode graphics on;
proc sort data=naph; by sample;
proc means noprint; by sample; var cYield;
output out=var cvar;
proc rank data= out ranks; var cvar; ranks r;
data s; set r;
gscore=gaminv((.r-5)/6,.2);
proc sgplot data=gam;
scatter x=gscore y=cvar;
xaxis label="Gamma Score";
yaxis label="Sample Variance";
run;
ode graphics off;
```
