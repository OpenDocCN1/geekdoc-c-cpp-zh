```
*data for temp control design;
data cont;
input A B C D F Invar;
XA=(A-4)/2; XB=(B-2); XC=(C-8)/8; XD=(D-10)/2; XF=(F-6)/1.2;
datalines;
2.67 1.33 5.33 8 4.8 1.163
;
data mod; set cont;
XA2=XA*XA;
XB2=XB*XB;
XC2=XC*XC;
XD2=XD*XD;
XF2=XF*XF;
XAB=XA*XB;
XAC=XA*XC;
XAD=XA*XD;
XAF=XA*XF;
XBC=XB*XC;
XBD=XB*XD;
XBF=XB*XF;
XCD=XC*XD;
XCF=XC*XF;
XDF=XD*XF;
proc reg data=mod;
model Invar=XA XB XC XD XF XA2 XB2 XC2 XD2 XF2 XAB XAC XAD
XAF XBC XBD XBF XCD XCF XDF /
selection=rsquare best=4 stop=8; run;
```

The SAS commands for fitting the best six variable model are shown below.

```
proc reg data=mod;
model Invar=XB XC XD XF XAF XBD XC2/p;
output out=s p=yhat r=resid;
run;
```

The results are below the all subsets results on the next page. All the model terms appear to be significant, and residual plots showed that the least squares assumptions appear justified. Now that a model is found relating the control factor settings to the log variance of Rr, the next step is to determine the factor settings that minimize the log variance. The negative coefficient for the linear effect of factor C indicates that the low level should be chosen for this ratio of nominal factor ratings in order to minimize the hn(s^k). For factors B, D and F the interpretation is not so straightforward since there are significant interactions with these factors.
