\(\eta_{zz} = \gamma_1^0 x_1 + \gamma_2^0 x_2 + \gamma_3^0 x_3 + \gamma_{12}^0 x_1 x_2 + \gamma_{13}^0(z) x_1 x_3 + \gamma_{23}^0(z) x_2 x_3 + \gamma_1^1 z + \gamma_2^1 x_2 z + \gamma_3^1 x_3 z + \gamma_{12}^1 x_1 x_2 z + \gamma_{13}^1 x_1 x_3 z + \gamma_{23}^1 x_2 x_3 z,\) (11.26)

where \(\gamma_i^2 = \gamma_i^1 - \gamma_i^1\) for \(i = 2, 3\). If the process variable has a constant effect on the response, the last five terms in the model would be zero, and \(\gamma_i^1\) will represent the constant effect of the process variable.

Another model that allows isolation of process variable effects can be obtained by first translating the mixture components (\(x_1, x_2, \text{and } x_3\)) to independent factors (\(w_1, w_2\)) as shown in Section 11.2.2, then writing the combined model as the cross-product of the model for the \(w\)’s and the \(z\)’s.
