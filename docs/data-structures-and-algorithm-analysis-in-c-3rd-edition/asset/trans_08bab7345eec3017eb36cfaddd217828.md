
始终在主内存中。因为树分支非常快，前两层（第 0 层和第 1 层）需要的空间相对较少。如果 B 树只有高度为四，那么最多需要两次磁盘取数（第 2 层的内部节点和第 3 层的叶节点）即可到达指向任何给定记录的指针。

可以使用缓冲池来管理 B 树的节点。通常树中的多个节点会同时驻留在主内存中。最直接的方法是使用标准方法如 LRU 来进行节点替换。然而，有时可能希望将某些节点（如根节点）“锁定”在缓冲池中。一般来说，如果缓冲池的尺寸即使是适中的（例如至少是树深度的两倍），就不需要特殊的节点替换技术，因为上层节点会自然地被频繁访问。

## 高级数据结构

## 图

图提供了数据结构灵活性的终极体现。图可以模拟现实世界系统和抽象问题，因此在数百个应用中使用。以下是图被常规应用的问题范围的一个小样本。

- 1. 模拟计算机和通信网络中的连通性。
- 2. 将地图表示为一组位置及位置之间的距离；用于计算位置之间的最短路线。
- 3. 模拟运输网络中的流量容量。
- 4. 从起始条件找到通往目标条件的路径；例如，在人工智能问题求解中。
- 5. 模拟计算机算法，显示从一个程序状态到另一个程序状态的转换。
- 6. 找到完成复杂活动中子任务的合适顺序，例如建造大型建筑。
- 7. 模拟关系，如家谱、商业或军事组织，以及科学分类法。

我们首先在第 11.1 节介绍一些基本图术语，然后定义图的两种基本表示，邻接矩阵和邻接表。第 11.2 节介绍图 ADT 以及基于邻接矩阵和邻接表的简单实现。第 11.3 节介绍两种最常用的图遍历算法，称为深度优先和广度优先搜索，并应用于拓扑排序。第 11.4 节介绍用于解决图中最短路线相关问题的算法。最后，第 11.5 节介绍用于寻找最小成本生成树的算法，用于确定网络中的最低成本连通性。除了本身有用且有趣之外，这些算法还说明了在早期章节中介绍的一些数据结构的使用。
