关于文件处理的一个很好的通用文本是 Folk 和 Zoellick 的《File Structures: A Conceptual Toolkit》[FZ98]。关于文件处理中关键问题的更深入讨论是 Betty Salzberg 的《File Structures: An Analytical Approach》[Sal88]。关于外部排序方法的精彩讨论可以在 Salzberg 的书中找到。本章的介绍遵循 Salzberg 的精神。

有关磁盘驱动器建模和测量的详细信息，请参阅 Ruemmler 和 Wilkes 的文章“An Introduction to Disk Drive Modeling，”[RW94]。请参阅 Andrew S. Tanenbaum 的《Structured Computer Organization》[Tan06] 以了解计算机硬件和组织的介绍。关于内存和硬盘驱动器的优秀、详细的描述可以在 Charles M. Kozierok 的“The PC Guide，”[Koz05]（www.pcguide.com）在线找到。PC Guide 还详细描述了 Microsoft Windows 和 UNIX（Linux）文件系统。

请参阅 Megiddo 和 Modha 的“Outperforming LRU with an Adaptive Replacement Cache Algorithm”[MM04]，以了解管理缓冲区池比 LRU 更复杂的算法示例。

雪犁论证来自 Donald E. Knuth 的《Sorting and Searching》[Knu98]，该书还包含多种外部排序算法。
