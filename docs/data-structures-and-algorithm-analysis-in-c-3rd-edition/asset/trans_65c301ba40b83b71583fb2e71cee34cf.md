## 前言

我们研究数据结构是为了学会编写更高效的程序。但为什么程序必须高效，当新计算机每年都更快时？原因是我们的雄心随着能力一起增长。现代计算能力和存储能力的革命并没有使效率需求过时，反而在我们尝试更复杂的任务时提高了效率标准。

追求程序效率不必也不应与良好的设计和清晰的编码冲突。创建高效程序与“编程技巧”关系不大，而是基于信息的良好组织和良好的算法。尚未掌握清晰设计基本原则的程序员不太可能编写高效程序。相反，开发成本和可维护性相关的问题不应被用作为低效性能辩解的借口。设计中的通用性可以在不牺牲性能的情况下实现，但这只有在设计者理解如何衡量性能并将其作为设计和实现过程的组成部分进行时才可能。

大多数计算机科学课程都认识到良好的编程技能始于对基本软件工程原则的强烈强调。然后，一旦程序员学习了清晰的程序设计和实现的原则，下一步就是研究数据组织和算法对程序效率的影响。

- 1. 每个数据结构和每个算法都有成本和收益。实践者需要彻底理解如何评估成本和收益，以便能够适应新的设计挑战。这需要理解算法分析的原则，也需要认识到所用物理介质的显著影响，例如数据存储在磁盘与主内存中。
