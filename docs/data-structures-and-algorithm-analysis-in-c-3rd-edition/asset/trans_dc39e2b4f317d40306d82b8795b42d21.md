## 6.2 父指针实现

或许最简单的一般树实现是为每个节点仅存储一个指向其父节点的指针。我们将此称为父指针实现。显然，这种实现并非通用，因为它不足以支持诸如查找节点的最左子节点或右兄弟等重要操作。因此，以这种方式实现一般树似乎是一个糟糕的主意。然而，父指针实现恰好存储了回答以下有用问题所需的信息：“给定两个节点，它们是否在同一棵树中？”要回答这个问题，我们只需从每个节点沿父指针序列追溯到各自的根。如果两个节点到达同一个根，那么它们必然在同一棵树中。如果根不同，则这两个节点不在同一棵树中。对给定节点寻找其最终根的过程，我们称之为FIND。

父指针表示最常用于维护不相交集合的集合。两个不相交集合没有共同成员（它们的交集为空）。一组不相交集合对某些对象进行划分，使得每个对象恰好属于其中一个不相交集合。我们希望支持两个基本操作：

-   (1) 确定两个对象是否在同一个集合中；
-   (2) 将两个集合合并在一起。

由于两个合并后的集合并为一体，合并操作被称为UNION，而判断两个对象是否在同一集合然后合并这些集合的整个过程被称为“UNION/FIND”。

为了实现UNION/FIND，我们用一棵独立的一般树表示每个不相交集合。如果两个对象在同一棵树中，则它们属于同一个不相交集合。树中的每个节点（除根外）恰好有一个父节点。因此，每个节点需要相同的空间来表示。对象集合通常存储在一个数组中，数组的每个元素对应一个对象，每个元素存储对象的值。对象还对应于各个不相交树的节点（每个不相交集合一棵树），因此我们还在数组中为每个对象存储父值。那些作为各自树根的节点存储一个适当的指示符。注意，这种表示意味着使用单个数组来实现一组树。这使得通过UNION操作合并树变得容易。

图6.4展示了一般树的父指针实现，称为ParPtrTree。该类比图6.2中的声明大大简化，因为我们只需要一般树操作的子集。ParPtrTree没有实现单独的节点类，而是简单地存储一个数组，其中每个数组元素对应树的一个节点。数组的每个位置i存储节点i的值以及节点i的父节点的数组位置。类ParPtrTree

```cpp
// General tree representation for UNION/FIND
class ParPtrTree {
private:
    int* array;                // Node array
    int size;                  // Size of node array
    int FIND(int) const;       // Find root
public:
    ParPtrTree(int);           // Constructor
    ~ParPtrTree() { delete [] array; } // Destructor
    void UNION(int, int);      // Merge equivalences
    bool differ(int, int);     // True if not in same tree
};

int ParPtrTree::FIND(int curr) const { // Find root
    while (array[curr] != ROOT) curr = array[curr];
    return curr;  // At root
}
```
