
template <typename E> // Array-based list implementation
class AList : public List<E> {
private:
    int maxSize;            // Maximum size of list
    int listSize;           // Number of list items now
    int curr;               // Position of current element
    E* listArray;           // Array holding list elements

public:
    AList(int size=defaultSize) { // Constructor
        maxSize = size;
        listSize = curr = 0;
        listArray = new E[maxSize];
    }

    ~AList() { delete [] listArray; } // Destructor

    void clear() {                     // Reinitialize the list
        delete [] listArray;           // Remove the array
        listSize = curr = 0;           // Reset the size
        listArray = new E[maxSize];    // Recreate array
    }

    // Insert "it" at current position
    void insert(const E& it) {
        Assert(listSize < maxSize, "List capacity exceeded");
        for(int i=listSize; i>curr; i--)   // Shift elements up
            listArray[i] = listArray[i-1]; //   to make room
        listArray[curr] = it;
        listSize++;                    // Increment list size
    }

    void append(const E& it) {         // Append "it"
        Assert(listSize < maxSize, "List capacity exceeded");
        listArray[listSize++] = it;
    }

    // Remove and return the current element.
    E remove() {
        Assert((curr>=0) && (curr < listSize), "No element");
        E it = listArray[curr];        // Copy the element
        for(int i=curr; i<listSize-1; i++)  // Shift them down
            listArray[i] = listArray[i+1];
        listSize--;                    // Decrement size
        return it;
    }
}

## 4.1.2 链表

实现列表的第二种传统方法是使用指针，通常称为链表。链表使用动态内存分配，即根据需要为新列表元素分配内存。

链表由一系列对象组成，这些对象称为列表的节点。由于列表节点是一个独立的对象（而不是数组中的简单单元），最好创建单独的列表节点类。创建列表节点类的另一个好处是，它可以被本章后面介绍的栈和队列数据结构的链表实现所复用。图4.4显示了列表节点的实现，称为 Link 类。Link 类中的对象包含一个 element 字段来存储元素值，以及一个 next 字段来存储指向列表中下一个节点的指针。由这种节点构建的列表称为单链表或单向列表，因为每个列表节点只有一个指向列表中下一个节点的指针。

Link 类非常简单。它的构造函数有两种形式，一种带初始元素值，另一种不带。由于 Link 类也会被后面介绍的栈和队列实现使用，其数据成员设置为公有。虽然在技术上这破坏了封装，但实践中 Link 类应作为链表（或栈或队列）实现的私有类实现，因此对程序的其他部分不可见。

当链表为空，或当前位置位于链表末端时，我们会遇到许多潜在的特殊情况。特别是当链表为空时，head、tail 和 curr 没有元素可指向。为 insert 和 remove 实现特殊情况会增加代码复杂度，使其更难理解，从而增加引入编程错误的机会。

这些特殊情况可以通过在链表开头添加一个额外的头节点来消除。这个头节点与任何其他链接节点一样，但其值被忽略，并且不被视为列表的实际元素。头节点节省了编码工作量，因为我们不再需要考虑空链表或当前位置位于链表一端时的特殊情况。这种简化的代价是头节点所占用的空间。然而，由于省略了处理特殊情况的语句，代码量减少也带来了空间节省。在实践中，代码量的减少通常能节省比头节点所需更多的空间，这取决于创建的链表数量。图4.7显示了使用头节点时初始化或空链表的状态。
