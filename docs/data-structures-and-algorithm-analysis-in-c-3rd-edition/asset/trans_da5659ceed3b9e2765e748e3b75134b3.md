

```cpp
// Return a pointer to the node with the least value in root
// for the selected discriminator
BinNode<E>* findmin(BinNode<E>* root,
int discrim, int currdis) const {
 // discrim: discriminator key used for minimum search;
 // currdis: current level (mod D);
 if (root == NULL) return NULL;
 BinNode<E> *minnode = findmin(root->left(), discrim,
		(currdis+1)%D);
 if (discrim != currdis) { // If not at discrim's level,
	 // we must search both subtrees
	 BinNode<E> *rightmin =
			findmin(root->right(), discrim, (currdis+1)%D);
	 // Check if right side has smaller key value
	 minnode = min(minnode, rightmin, discrim);
 } // Now, minnode has the smallest value in children
 return min(minnode, root, discrim);
}
```

**图 13.12** k-d 树的 findmin 方法。在使用最小值判别符的层级上，分支向左进行。在其他层级上，必须访问两个孩子的子树。辅助函数 min 接受两个节点和一个判别符作为输入，返回在该判别符上值较小的节点。

替换记录必须来自左子树。然而，用左子树中判别符值最大的记录来替换 N 的记录并不令人满意，因为这个新值可能是重复的。如果是这样，那么 N 的左子树中就会存在相等的判别符值，这违反了 k-d 树的排序规则。幸运的是，这个问题有一个简单的解决方案。我们首先将节点 N 的左子树移动为右子树（即，直接交换 N 的左右孩子指针的值）。此时，我们继续正常的删除过程，用来自现在 N 的右子树中判别符值最小的记录来替换要删除的 N 的记录。

假设我们想要打印出所有与给定点 P 的距离在某个范围 d 之内的记录列表。我们将使用欧几里得距离，即点 P 被定义为在距离 d 之内，如果

√((Px - Nx)² + (Py - Ny)²) ≤ d。

> ¹ 更高效的计算方式是 (Px - Nx)² + (Py - Ny)² ≤ d²。这避免了执行平方根函数。

如果搜索过程到达一个节点，该节点在判别符上的键值比搜索键中对应值大 d 以上，那么右子树中任何记录都不可能位于距搜索键 d 的范围之内，因为该维度上的所有键值总是过大。类似地，如果当前节点在判别符上的键值比搜索键值小 d，那么![](img/7ea3c39173f146f675b63b146d1535f3_472_0.png)左子树中没有任何记录可以位于半径之内。在这种情况下，所涉及的子树无需搜索，这可能会节省大量时间。在平均情况下，范围查询期间必须访问的节点数量与落在查询圆内的数据记录数量成线性关系。

**示例 13.7** 现在我们将查找图 13.14 的 k-d 树中所有距离点 (25, 65) 在 25 个单位之内的城市。搜索从根节点开始，根节点包含记录 A。因为 (40, 45) 恰好距离搜索点 25 个单位，所以它将被报告。然后搜索过程决定要搜索树的哪些分支。搜索圆同时延伸到 A 的（垂直）分割线的左侧和右侧，因此必须搜索树的两个分支。首先处理左子树。在这里，记录 B 被检查，发现它落在搜索圆内。因为存储 B 的节点没有孩子，左子树的处理就完成了。现在开始处理 A 的右子树。检查记录 C 的坐标，发现它不在圆内。因此，不应报告它。然而，即使 C 本身不在圆内，C 的子树中的城市仍可能落在搜索圆内。由于 C 在第 1 层，该层的判别符是 y 坐标。因为 65 - 25 > 10，所以 C 的左子树（即 C 上方的记录）中任何记录都不可能位于搜索圆内。因此，C 的左子树（如果有的话）无需搜索。但是，C 的右子树中的城市可能落在圆内。因此，搜索继续到包含记录 D 的节点。同样，D 在搜索圆之外。因为 25 + 25 < 69，所以 D 的右子树中任何记录都不可能位于搜索圆内。因此，只需要搜索 D 的左子树。这导致将记录 E 的坐标与搜索圆进行比较。记录 E 落在搜索圆之外，处理完成。所以我们看到，我们只搜索那些矩形区域落在搜索圆内的子树。

```cpp
// Print all points within distance "rad" of "coord"
void regionhelp(BinNode<E>* root, int* coord,
    int rad, int discrim) const {
    if (root == NULL) return;        // Empty tree
    // Check if record at root is in circle
    if (InCircle((root->val())->coord(), coord, rad))
        cout << root->val() << endl;  // Do what is appropriate
    int* currcoord = (root->val())->coord();
    if (currcoord[discrim] > (coord[discrim] - rad))
        regionhelp(root->left(), coord, rad, (discrim+1)%D);
    if (currcoord[discrim] < (coord[discrim] + rad))
        regionhelp(root->right(), coord, rad, (discrim+1)%D);
}
```

**图 13.15** k-d 树区域搜索方法。

图 13.15 显示了区域搜索方法的一种实现。当访问一个节点时，使用函数 InCircle 来检查该节点的记录与查询点之间的欧几里得距离。仅仅检查 x 和 y 坐标的差值是否都小于查询距离是不够的，因为记录仍然可能在搜索圆之外，如图 13.13 所示。

### 13.3.2 PR 四叉树

在点区域四叉树（Point-Region Quadtree，以下简称 PR 四叉树）中，每个节点要么恰好有四个孩子，要么是一个叶子。也就是说，PR 四叉树在形状上是一棵完全四路分支（4 叉）树。PR 四叉树通过将包含数据点的区域分解成四个相等的象限、子象限等，直到没有叶子节点包含超过一个点，来表示二维空间中的一组数据点。换句话说，如果一个区域包含零个或一个数据点，那么它就由一个仅包含单个叶子节点的 PR 四叉树来表示。如果该区域包含多个数据点，则该区域被分成四个相等的象限。相应的 PR 四叉树随后包含一个内部节点和四棵子树，每棵子树代表该区域的一个象限，该象限又可能被进一步划分为子象限。PR 四叉树的每个内部节点代表二维区域的一次分割。该区域的四个象限（或等价地，相应的子树）按顺序指定为 NW、NE、SW 和 SE。每个包含多个点的象限将依次被递归地划分为子象限，直到相应 PR 四叉树的每个叶子节点至多包含一个点。

例如，考虑图 13.16(a) 的区域以及图 13.16(b) 中相应的 PR 四叉树。分解过程需要一个固定的键范围。在这个例子中，假设区域大小为 128 × 128。注意，PR 四叉树的内部节点仅用于表示区域的分解；内部节点不存储数据记录。由于分解线是预先确定的（即使用键空间分解），PR 四叉树是一棵 trie。

在 PR 四叉树中搜索与点 Q 匹配的记录是直接的。从根开始，我们不断分支到包含 Q 的象限，直到搜索到达一个叶子节点。如果根是叶子，那么只需检查该节点的数据记录是否与点 Q 匹配。如果根是内部节点，则继续前往包含搜索坐标的孩子。例如，图 13.16 的 NW 象限包含 x 和 y 值都落在 0 到 63 范围内的点。
