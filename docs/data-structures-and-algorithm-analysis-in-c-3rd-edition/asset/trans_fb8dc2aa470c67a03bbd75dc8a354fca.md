你如何解决这个问题？如果你不去想太多细节，这很容易。相反，考虑所有环都必须从杆 1 移动到杆 3。不可能在不先将底部（最大）环移动到杆 3 的情况下做到这一点。为此，杆 3 必须为空，并且只有底部环可以在杆 1 上。剩余的 n − 1 个环必须按顺序堆叠在杆 2 上，如图 2.2(b) 所示。你如何做到这一点？假设函数 X 可用于解决将顶部 n − 1 个环从杆 1 移动到杆 2 的问题。然后将底部环从杆 1 移动到杆 3。最后，再次使用函数 X 将剩余的 n − 1 个环从杆 2 移动到杆 3。在这两种情况下，“函数 X”只是对较小版本问题的汉诺塔函数调用。

# 2.6.3 数学归纳法证明

数学归纳法可用于证明各种各样的定理。归纳法还提供了一种思考算法设计的有用方法，因为它鼓励你通过从简单子问题开始构建来思考解决问题的方法。归纳法可以帮助证明递归函数产生正确的结果。理解递归是理解归纳法的一大步，反之亦然，因为它们本质上通过相同的过程工作。

在算法分析的背景下，数学归纳法最重要用途之一是作为检验假设的方法。如第 2.4 节所述，在寻求求和或递推的闭式解时，我们可能会首先猜测或以其他方式获得证据，认为某个公式是正确的解。如果公式确实正确，通常很容易用归纳法证明这一事实。

设 Thrm 为要证明的定理，并用正整数参数 n 表示 Thrm。数学归纳法指出，如果以下两个条件为真，则 Thrm 对参数 n 的任何值都为真（对于 n ≥ c，其中 c 是某个常数）：

- 1. 基本情况：Thrm 对 n = c 成立，且
- 2. 归纳步骤：如果 Thrm 对 n − 1 成立，则 Thrm 对 n 成立。

证明基本情况通常很容易，通常只需要将某个小值如 1 代入定理中的 n 并应用必要的简单代数或逻辑来验证定理。证明归纳步骤有时很容易，有时困难。归纳步骤的一种替代表述称为强归纳法。强归纳法的归纳步骤为：

- 2a. 归纳步骤：如果 Thrm 对所有 k，c ≤ k < n 成立，则 Thrm 对 n 成立。

证明归纳步骤的任一变体（结合验证基本情况）可得到令人满意的数学归纳法证明。

构成归纳法证明的两个条件结合起来证明了 Thrm 对 n = 2 成立，这是 Thrm 对 n = 1 成立的扩展。这一事实，再结合条件 (2) 或 (2a)，表明 Thrm 也对 n = 3 成立，依此类推。因此，一旦证明了这两个条件，Thrm 对所有 n 值（大于基本情况的值）都成立。

使数学归纳法如此强大（并且对大多数人来说起初如此神秘）的，是我们可以利用 Thrm 对小于 n 的所有值成立的假设作为工具来帮助我们证明 Thrm 对 n 成立。这就是归纳假设。有了这个假设来工作，归纳步骤比直接处理原始定理本身更容易证明。能够依赖归纳假设提供了我们可以用来解决问题的额外信息。

递归和归纳有很多相似之处。两者都以一个或多个基本情况为锚点。递归函数依靠调用自身来获取问题的较小实例的答案。同样，归纳法证明依靠归纳假设的真值来证明定理。归纳假设并非凭空而来。它当且仅当定理本身为真时才为真，因此在证明上下文中是可靠的。使用归纳假设做工作与使用递归调用做工作完全相同。

例 2.11 这里有一个数学归纳法的示例证明。设前 n 个正整数之和为 S(n)。

# 定理 2.2 S(n) = n(n + 1)/2.

证明：证明采用数学归纳法。

- 1. 检查基本情况。对于 n = 1，验证 S(1) = 1(1 + 1)/2。S(1) 只是第一个正数的和，即 1。因为 1(1 + 1)/2 = 1，所以公式对基本情况是正确的。
- 2. 叙述归纳假设。归纳假设是
  S(n - 1) = Σ_{i=1}^{n-1} i = (n-1)((n-1) + 1)/2 = (n-1)n/2 .
- 3. 使用归纳假设中对 n - 1 的假设来证明结果对 n 为真。归纳假设指出 S(n - 1) = (n - 1)n/2，并且因为 S(n) = S(n - 1) + n，我们可以代入 S(n - 1) 得到
  Σ_{i=1}^{n} i = (Σ_{i=1}^{n-1} i) + n = (n-1)n/2 + n = (n² - n + 2n)/2 = n(n + 1)/2 .
- 因此，通过数学归纳法，
  S(n) = Σ_{i=1}^{n} i = n(n + 1)/2 .

证明：为证明基本情况，我们观察到 T(1) = 1 − 1 = 0。归纳假设是 T(n − 1) = n − 2。将递推的定义与归纳假设结合，我们立即看到

T(n) = T(n − 1) + 1 = n − 2 + 1 = n − 1

对于 n > 1。因此，我们通过数学归纳法证明了定理是正确的。

# 例 2.14 该示例使用归纳法而不涉及求和或其他方程。它还说明了基本情况的更灵活使用。

# 定理 2.5 2¢ 和 5¢ 邮票可用于形成任何值（对于值 ≥ 4）。

证明：定理将问题定义为值 ≥ 4，因为它对值 1 和 3 不成立。以 4 为基本情况，4¢ 的值可以用两枚 2¢ 邮票制成。归纳假设是 n − 1 的值可以用 2¢ 和 5¢ 邮票的某种组合制成。我们现在使用归纳假设来说明如何从 2¢ 和 5¢ 邮票得到值 n。值 n − 1 的构成要么包含一枚 5¢ 邮票，要么不包含。如果包含，则用三枚 2¢ 邮票替换一枚 5¢ 邮票。如果不包含，则构成必须至少包含两枚 2¢ 邮票（因为它至少为 4¢ 且只包含 2¢ 邮票）。在这种情况下，用一枚 5¢ 邮票替换两枚 2¢ 邮票。在任何一种情况下，我们现在都有一个由 2¢ 和 5¢ 邮票组成的值 n。因此，通过数学归纳法，定理是正确的。

# 例 2.15 这里有一个使用强归纳法的例子。

# 定理 2.6 对于 n > 1，n 可被某个素数整除。

证明：对于基本情况，选择 n = 2。2 可被素数 2 整除。归纳假设是任何值 a，2 ≤ a < n，都可被某个素数整除。现在有两种情况需要考虑来证明 n 的定理。如果 n 是素数，则 n 可被其自身整除。如果 n 不是素数，则 n = a × b，其中 a 和 b 都是小于 n 但大于 1 的整数。归纳假设告诉我们 a 可被某个素数整除。相同的素数也必须整除 n。因此，通过数学归纳法，定理是正确的。
