## 搜索

信息的组织和检索是大多数计算机应用的核心，而搜索无疑是所有计算任务中最频繁执行的任务。搜索可以抽象地看作一个过程，用于确定具有特定值的元素是否是某个特定集合的成员。更常见的搜索观点是：在记录集合中查找具有特定键值的记录，或者查找键值满足某种标准（如落在某个值范围内）的记录。

我们可以如下形式化地定义搜索。假设我们有一个包含 n 条记录的集合 L，形式为

(k₁, I₁), (k₂, I₂), ..., (kₙ, Iₙ)

其中 Iⱼ 是与记录 j 的键 kⱼ 相关联的信息，1 ≤ j ≤ n。给定一个特定的键值 K，搜索问题就是在 L 中定位一条记录 (kⱼ, Iⱼ)，使得 kⱼ = K（如果存在这样的记录）。搜索是一种系统方法，用于定位键值 kⱼ = K 的记录（或若干记录）。

成功搜索是指找到键 kⱼ = K 的记录。不成功搜索是指没有找到键 kⱼ = K 的记录（且不存在这样的记录）。

精确匹配查询是查找键值与指定键值匹配的记录的搜索。范围查询是查找键值落在指定键值范围内的所有记录的搜索。

我们可以将搜索算法分为三大类方法：

- 顺序方法和列表方法。
- 按键值直接访问（散列）。
- 树索引方法。

本章和下一章将依次讨论这三种方法。这些方法中的任何一种都可能适合实现 4.4 节引入的字典 ADT。然而，每种方法都有不同的性能特征，使其在特定情况下成为首选方法。

本章讨论在列表中搜索数据的方法。这里的列表指任何列表实现，包括链表或数组。这些方法大多适用于序列（即允许重复键值），但适用于集合的特殊技术将在 9.3 节讨论。本章前三节的技术最适合搜索存储在 RAM 中的记录集合。9.4 节讨论散列，这是一种在数组中组织数据的技术，使得每条记录在数组中的位置是其键值的函数。当记录存储在 RAM 或磁盘上时，散列都是适用的。

第 10 章讨论在磁盘上组织信息的基于树的方法，包括一种常用的文件结构——B-树。几乎所有必须在磁盘上组织大型记录集合的程序，都会使用散列或 B-树的某种变体。散列仅对某些访问函数（精确匹配查询）实用，并且通常仅在不允许重复键值时才适用。只要散列不适用，B-树就是动态磁盘应用的首选方法。
