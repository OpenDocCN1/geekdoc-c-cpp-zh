## 13.3.4 其他空间数据结构

本节仅触及了空间数据结构领域的皮毛。已经发明了数十种不同的空间数据结构，其中许多还具有变体和替代实现。空间数据结构可用于存储除点之外的多种形式的空间数据。最重要的区别在于树结构（二叉或非二叉，是否规则分解）以及用于决定区域内数据是否复杂到必须细分该区域的分解规则。

其中一种空间数据结构是用于存储像素值趋于块状的图像的区域四叉树，例如世界各国的地图。区域四叉树使用类似于 PR 四叉树的四路规则分解方案。分解规则很简单：只要节点包含多于一种颜色或值的像素，就将其划分为四份。

空间数据结构也可用于存储线对象、矩形对象或任意形状的对象（如二维中的多边形或三维中的多面体）。一种简单而有效的数据结构，用于存储矩形或任意多边形形状，可以从 PR 四叉树派生出来。选择一个阈值 c，如果某个区域包含多于 c 个对象，则将其细分为四个象限。当多于 c 个对象相交时，必须处理一种特殊情况。

空间数据结构在适应磁盘应用方面的一些最有趣的发展。然而，所有此类基于磁盘的实现最终都归结为将空间数据结构存储在 B 树或哈希的某种变体中。

## 分析技术

通常很容易发明一个方程来模拟算法或数据结构的行为。通常很容易为方程求出闭式解，如果它包含递推或求和的话。但有时分析会更困难。可能需要巧妙的见解来推导出正确的模型，例如用于分析 Replacement Selection（第 8.5.2 节）平均运行长度的雪犁论证。在此示例中，一旦理解了雪犁论证，后续的方程就会自然得出。有时，建立模型很直接，但分析所得方程却不简单。一个例子是快速排序的平均情况分析。第 7.5 节给出的方程简单地枚举了枢轴位置的所有可能情况，对快速排序的递归调用的相应成本求和。然而，为所得递推关系推导出闭式解并不容易。

许多迭代算法的分析使用求和来模拟循环的成本。第 14.1 节介绍了求解求和的闭式解的技术。许多基于递归的算法的成本最好用递推关系来建模。第 14.2 节讨论了解递推关系的技术。这些章节建立在第 2.4 节中介绍的求和和递推的基础上，因此读者应已熟悉该材料。

第 14.3 节介绍了摊还分析的主题。摊还分析处理一系列操作的成本。也许该系列中的单个操作成本很高，但因此剩余操作的成本受到限制。摊还分析已成功用于分析之前各节中介绍的若干算法，包括 UNION/FIND 操作的一系列成本（第 6.2 节）、快速排序中划分的成本（第 7.5 节）、伸展树操作的一系列成本（第 13.2 节）以及自组织列表的一系列操作成本（第 9.2 节）。第 14.3 节更详细地讨论了该主题。
