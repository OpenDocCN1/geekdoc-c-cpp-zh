如果某些字符比其他字符使用得更频繁，是否可以利用这一事实，以某种方式为它们分配更短的编码？代价可能是其他字符需要更长的编码，但如果这些字符出现得足够少，这样做也许是值得的。这个概念正是当今常用文件压缩技术的核心。下一节将介绍一种分配变长编码的方法，称为霍夫曼编码。虽然它最简单的形式并未普遍用于文件压缩（因为有更好的方法），但霍夫曼编码体现了这类编码方案的特点。研究霍夫曼编码的一个动机是，它让我们第一次有机会看到一种称为搜索字典树（search trie）的树结构。

## 5.6.1 构建霍夫曼编码树

霍夫曼编码为字符分配编码，编码的长度取决于相应字符的相对频率或权重。因此，它是一种变长编码。如果字母的估计频率与编码消息中实际出现的频率相符，那么该消息的长度通常会比使用定长编码时更短。每个字母的霍夫曼编码源自一棵满二叉树，称为霍夫曼编码树，或简称为霍夫曼树。霍夫曼树的每个叶子对应一个字母，我们将叶子节点的权重定义为其对应字母的权重（频率）。

目标是构建一棵具有最小外部路径权重的树。定义叶子的加权路径长度为它的权重乘以它的深度。具有最小外部路径权重的二叉树，是对于给定叶子集合，其加权路径长度之和最小的那棵树。权重高的字母应该具有较小的深度，这样它对总路径长度的贡献最少。因此，权重较低的字母可能会被推入树的更深位置。

为 n 个字母构建霍夫曼树的过程非常简单。首先，创建 n 棵初始霍夫曼树的集合，每棵树都是包含其中一个字母的单个叶子节点。将这 n 棵部分树放入一个按权重（频率）组织的优先队列中。接下来，从优先队列中取出前两棵树（权重最低的两棵）。将这两棵树合并，生成一棵新树，其根节点以这两棵树作为子节点，权重为两棵树权重之和。将这棵新树放回优先队列。重复此过程，直到所有部分霍夫曼树都合并为一棵树。

霍夫曼树构建是贪心算法的一个例子。在每一步中，算法都会做出一个“贪心”的决定，合并权重最小的两棵子树。这使算法变得简单，但它能给出期望的结果吗？本节最后证明霍夫曼树确实为给定字母集合提供了最高效的安排。该证明需要以下引理。

## 引理 5.1 对于由函数 buildHuff 构建且包含至少两个字母的任何霍夫曼树，频率最小的两个字母存储在兄弟节点中，其深度不浅于树中任何其他叶节点。

## 证明：

将频率最小的两个字母称为 l1 和 l2。它们必定是兄弟节点，因为 buildHuff 在构建过程的第一步就选择了它们。假设 l1 和 l2 不是树中最深的节点。在这种情况下，霍夫曼树要么如图 5.30 所示，要么在某种意义上与之对称。要出现这种情况，l1 和 l2 的父节点（标记为 V）的权重必须大于标记为 X 的节点的权重。否则，函数 buildHuff 会选择节点 V 而不是节点 X 作为节点 U 的子节点。然而，这是不可能的，因为 l1 和 l2 是频率最小的字母。

// 霍夫曼树节点抽象基类
template <typename E> class HuffNode {
public:
    virtual ~HuffNode() {}                     // 基类析构函数
    virtual int weight() = 0;                  // 返回频率
    virtual bool isLeaf() = 0;                 // 判断类型
};

template <typename E>    // 叶节点子类
class LeafNode : public HuffNode<E> {
private:
    E it;                      // 值
    int wgt;                   // 权重
public:
    LeafNode(const E& val, int freq)    // 构造函数
    { it = val; wgt = freq; }
    int weight() { return wgt; }
    E val() { return it; }
    bool isLeaf() { return true; }
};

template <typename E>    // 内部节点子类
class IntlNode : public HuffNode<E> {
private:
    HuffNode<E>* lc;    // 左子节点
    HuffNode<E>* rc;    // 右子节点
    int wgt;            // 子树权重
public:
    IntlNode(HuffNode<E>* l, HuffNode<E>* r)
    { wgt = l->weight() + r->weight(); lc = l; rc = r; }
    int weight() { return wgt; }
    bool isLeaf() { return false; }
    HuffNode<E>* left() const { return lc; }
    void setLeft(HuffNode<E>* b)
    { lc = (HuffNode<E>*)b; }
    HuffNode<E>* right() const { return rc; }
    void setRight(HuffNode<E>* b)
    { rc = (HuffNode<E>*)b; }
};
