

## 5.3.3 完全二叉树的数组实现

上一节指出，典型的二叉树节点实现中，很大一部分空间用于结构开销，而非存储数据。本节介绍一种简单、紧凑的完全二叉树实现。回顾一下，完全二叉树除底层外所有层都是完全填满的，且底层所有节点从左到右依次填满。因此，包含 `n` 个节点的完全二叉树只有一种可能的形状。你可能会认为完全二叉树如此不常见，没有必要专门为其开发一种实现。然而，完全二叉树有实际用途，其中最重要的是第 5.5 节讨论的堆数据结构。堆常用于实现优先队列（第 5.5 节）以及外部排序算法（第 8.5.2 节）。

我们首先按层从左到右为完全二叉树中的节点位置编号，如图 5.12(a) 所示。数组可以高效地存储树的数据值，将每个数据值放在数组中与该节点在树中的位置相对应的位置。图 5.12(b) 列出了图 5.12(a) 中每个节点的孩子、父节点和兄弟节点的数组索引。从图 5.12(b) 中，你应该能看出一个节点的亲属在数组中的位置规律。可以推导出简单的公式，从节点 `r` 的索引计算 `r` 的每个亲属的数组索引。无需显式指针即可到达节点的左孩子或右孩子。这意味着，如果对包含 `n` 个节点的树选择大小为 `n` 的数组，则数组实现没有任何额外开销。

计算节点各种亲属的数组索引的公式如下。树中的节点总数为 `n`。所讨论节点的索引为 `r`，它必须在 `0` 到 `n − 1` 的范围内。

- 父节点(r) = ⌊(r − 1)/2⌋，如果 r ≠ 0。
- 左孩子(r) = 2r + 1，如果 2r + 1 < n。
- 右孩子(r) = 2r + 2，如果 2r + 2 < n。
- 左兄弟(r) = r − 1，如果 r 为偶数。
- 右兄弟(r) = r + 1，如果 r 为奇数且 r + 1 < n。

## 5.4 二叉搜索树

第 4.4 节介绍了字典 ADT，以及基于有序列表和无序列表的字典实现。使用无序列表实现字典时，可以通过将新记录放到列表末尾来快速插入。然而，在无序列表中搜索特定记录平均需要 Θ(n) 时间。对于大型数据库来说，这可能太慢了。另一种选择是将记录存储在有序列表中。如果列表是用链表实现的，那么按有序顺序存储记录不会使搜索操作加速。另一方面，如果我们使用有序的基于数组的列表来实现字典，那么二分查找只需 Θ(log n) 时间就能找到一条记录。然而，插入现在平均需要 Θ(n) 时间，因为一旦找到新记录在有序列表中的适当位置，可能需要移动许多记录来为新记录腾出空间。

有没有什么方法可以组织记录集合，使得插入记录和搜索记录都能快速进行？本节介绍二叉搜索树（BST），它为这个问题提供了一种改进的解决方案。

BST 是满足以下条件（称为二叉搜索树性质）的二叉树：键值为 K 的节点的左子树中存储的所有节点的键值都小于 K。键值为 K 的节点的右子树中存储的所有节点的键值都大于或等于 K。图 5.13 展示了同一组值的两棵 BST。二叉搜索树性质的一个结果是，如果使用中序遍历（见第 5.2 节）打印 BST 节点，得到的枚举将按从低到高的顺序排列。

回顾第 4.4 节的讨论，处理键和比较记录有多种方式（三种方法是：键/值对、特殊比较方法、以及传入比较器函数）。我们的 BST 实现将通过在树的每个节点显式存储一个与数据值分离的键来处理比较。

要在 BST 中查找键值为 K 的记录，从根节点开始。如果根节点存储的记录的键值为 K，则搜索结束。否则，我们必须向树深处搜索。BST 在搜索时的高效之处在于，我们只需搜索该节点的两个子树之一。如果 K 小于根节点的键值，我们只搜索左子树。如果 K 大于根节点的键值，我们只搜索右子树。此过程持续进行，直到找到键值为 K 的记录，或者到达叶节点。如果到达叶节点仍未遇到 K，则 BST 中不存在键值为 K 的记录。

### 示例 5.5

考虑在图 5.13(a) 的树中查找键值为 32 的节点。因为 32 小于根节点的值 37，搜索进入左子树。因为 32 大于 24，我们在 24 的右子树中搜索。此时，找到包含 32 的节点。如果搜索值为 35，将沿着相同路径到达包含 32 的节点。因为这个节点没有孩子，我们知道 35 不在 BST 中。

注意，在图 5.14 中，公有成员函数 find 调用私有成员函数 findhelp。方法 find 将搜索键作为显式参数，将 BST 作为隐式参数，并返回与键匹配的记录。

```
// Remove and return the root node from the dictionary.
// Return: The record removed, null if tree is empty.
E removeAny() {  // Delete min value
    if (root != NULL) {
        E temp = root->element();
        root = removehelp(root, root->key());
        nodecount--;
        return temp;
    }
    else return NULL;
}

// Return Record with key value k, NULL if none exist.
// k: The key value to find.
// Return some record matching "k".
// Return true if such exists, false otherwise. If
// multiple records match "k", return an arbitrary one.
E find(const Key& k) const { return findhelp(root, k); }

// Return the number of records in the dictionary.
int size() { return nodecount; }

void print() const { // Print the contents of the BST
    if (root == NULL) cout << "The BST is empty.\n";
    else printhelp(root, 0);
};
```

然而，find 操作最容易实现为递归函数，其参数是子树的根和搜索键。成员 findhelp 具有这个递归子程序所需的形式，实现如下。

```
template <typename Key, typename E>
E BST<Key, E>::findhelp(BSTNode<Key, E>* root,
                        const Key& k) const {
    if (root == NULL) return NULL;            // Empty tree
    if (k < root->key())
        return findhelp(root->left(), k);    // Check left
    else if (k > root->key())
        return findhelp(root->right(), k);   // Check right
    else return root->element();  // Found it
}
```
