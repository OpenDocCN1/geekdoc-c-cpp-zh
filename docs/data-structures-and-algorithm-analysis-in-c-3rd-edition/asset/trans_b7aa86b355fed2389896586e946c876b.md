## 非二叉树

许多组织在本质上是分层的，例如军队和大多数企业。考虑一家拥有总裁和若干向总裁汇报的副总裁的公司。每个副总裁都有若干直接下属，依此类推。如果我们想用数据结构来模拟这家公司，将总裁放在树的根节点、副总裁放在第 1 层、他们的下属放在树中较低的层级，随着组织层级的下降而向下，这将是自然的想法。

由于副总裁的数量很可能超过两个，这家公司的组织结构无法轻易用二叉树表示。我们需要使用节点具有任意数量子节点的树。不幸的是，当我们允许树具有任意数量子节点的节点时，与二叉树相比，它们变得更难实现。我们在本章中考虑此类树。为了将其与二叉树区分开，我们使用术语广义树。

第 6.1 节介绍广义树术语。第 6.2 节介绍了一种用于解决处理等价类这一重要问题的简单表示。几种基于指针的广义树实现在第 6.3 节中介绍。除了广义树和二叉树之外，还有对内部节点具有固定数量 K 个子节点的树的使用，其中 K 是除二之外的其他数。此类树称为 K 叉树。第 6.4 节将二叉树的性质推广到 K 叉树。第 6.5 节介绍顺序表示法，这对于将树存储在磁盘等应用很有用。

### 6.1 广义树定义和术语

树 T 是一个有限的包含一个或多个节点集合，其中有一个指定节点 R，称为 T 的根。如果集合 (T − {R}) 非空，则这些节点被划分为 n > 0 个不相交子集 T0, T1, ..., Tn−1，每个子集都是一个树，其根 R1, R2, ..., Rn 分别是 R 的子节点。子集 Ti (0 ≤ i < n) 称为 T 的子树。这些子树是有序的，即如果 i < j 则 Ti 位于 Tj 之前。按惯例，子树从左到右排列，子树 T0 称为 R 的最左子节点。节点的外度是该节点的子节点数。森林是一组一个或多个树的集合。图 6.1 展示了进一步的树记号，该记号推广了第 5 章中介绍的二叉树记号。

![](img/7ea3c39173f146f675b63b146d1535f3_222_0.png)

图 6.1 广义树的记号。节点 P 是节点 V、S1 和 S2 的父节点。因此，V、S1 和 S2 是 P 的子节点。节点 R 和 P 是 V 的祖先。节点 V、S1 和 S2 称为兄弟节点。椭圆包围以 V 为根的子树。

树中每个节点恰好有一个父节点，除了根节点没有父节点。由此立即得出，具有 n 个节点的树必须有 n − 1 条边，因为除了根节点之外的每个节点都有一条边将其连接到其父节点。

#### 6.1.1 广义树节点的 ADT

在讨论广义树实现之前，我们首先应明确此类实现必须支持哪些操作。任何实现都必须能够初始化一棵树。给定一棵树，我们需要访问该树的根。必须有某种方式访问节点的子节点。在二叉树节点的 ADT 情况下，这是通过提供成员函数来显式访问左子节点和右子节点指针来实现的。不幸的是，由于我们事先不知道广义树中给定节点将有多少个子节点，因此我们无法提供显式函数来访问每个子节点。必须找到一种适用于未知数量子节点的替代方案。
