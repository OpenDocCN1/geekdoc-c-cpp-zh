
## 前言

以既足以阐明数据结构预期运作方式、又易于修改为真正异常处理的形式，指出所需条件。Assert 的实现参见附录。

我在正文中区分了“C++ 实现”和“伪代码”。标注为 C++ 实现的代码实际上已经在一个或多个 C++ 编译器上编译并测试过。伪代码示例通常与 C++ 语法高度一致，但往往包含一行或多行更高级别的描述。在我认为更简洁但不太精确的描述对于教学更有优势的地方，我使用伪代码。

### 练习与项目：

仅仅阅读一本书是无法学会数据结构的正确实现与分析的。你必须通过编写真实程序来练习，不断比较不同技术，看看在特定情况下哪种方法真正最有效。

数据结构课程最重要的方面之一，在于学生真正学会使用指针和动态内存分配来编程——通过实现链表和树等数据结构。这往往也是学生真正学会递归的地方。在我们的课程体系中，这是学生进行重要设计的第一门课，因为它常常需要真实的数据结构来推动有意义的设计练习。最后，如果没有实际编程经验，人们就无法理解基于内存与基于磁盘的数据访问之间的根本差异。基于所有这些原因，数据结构课程若缺少重要的编程实践环节就不可能成功。在我们系里，数据结构课程是课程体系中最难的编程课程之一。

学生还应该通过做题来培养分析能力。我提供了超过450道练习题和编程项目建议。我恳请读者充分利用它们。
