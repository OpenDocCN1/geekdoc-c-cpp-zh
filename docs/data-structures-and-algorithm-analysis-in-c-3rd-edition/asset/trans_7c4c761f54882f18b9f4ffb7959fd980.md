
// Doubly linked list link node with freelist support
template <typename E> class Link {
private:
    static Link<E>* freelist; // Reference to freelist head

public:
    E element;        // Value for this node
    Link* next;       // Pointer to next node in list
    Link* prev;       // Pointer to previous node

    // Constructors
    Link(const E& it, Link* prevp, Link* nextp) {
        element = it;
        prev = prevp;
        next = nextp;
    }
    Link(Link* prevp =NULL, Link* nextp =NULL) {
        prev = prevp;
        next = nextp;
    }

    void* operator new(size_t) {  // Overloaded new operator
        if (freelist == NULL) return ::new Link<E>; // Create space
        Link<E>* temp = freelist; // Can take from freelist
        freelist = freelist->next;    // Return the link
        return temp;
    }

    // Overloaded delete operator
    void operator delete(void* ptr) {
        ((Link<E>*)ptr)->next = freelist; // Put on freelist
        freelist = (Link<E>*)ptr;
    }
};

// The freelist head pointer is actually created here
template <typename E>
Link<E>* Link<E>::freelist = NULL;

// Insert "it" at current position
void insert(const E& it) {
    curr->next = curr->next->prev =
        new Link<E>(it, curr, curr->next);
    cnt++;
}

// Append "it" to the end of the list.
void append(const E& it) {
    tail->prev = tail->prev->next =
        new Link<E>(it, tail->prev, tail);
    cnt++;
}

// Remove and return current element
E remove() {
    if (curr->next == tail)        // Nothing to remove
        return NULL;
    E it = curr->next->element;    // Remember value
    Link<E>* ltemp = curr->next;   // Remember link node
    curr->next->next->prev = curr;
    curr->next = curr->next->next; // Remove from list
    delete ltemp;                  // Reclaim space
    cnt--;                         // Decrement cnt
    return it;
}

// Move fence one step left; no change if left is empty
void prev() {
    if (curr != head)  // Can't back up from list head
        curr = curr->prev;
}

## 图4.14 双向链表 insert、append、remove 和 prev 方法的实现

```
Link<E>* ltemp = curr->next;      // Remember link node
curr->next->next->prev = curr;
curr->next = curr->next->next; // Remove from list
delete ltemp;                   // Reclaim space
```

第一行设置一个临时指针，指向被删除的结点。第二行使下一个结点的 prev 指针指向被删除结点左侧的结点。最后，调整被删除结点前一个结点的 next 字段。remove 方法的最后几步是更新链表长度、将被删除结点归还到自由存储区，并返回被删除元素的值。

与单向链表相比，双向链表唯一的缺点是额外占用的空间。双向链表每个结点需要两个指针，因此在给出的实现中，它的开销是单向链表的两倍。

## 示例4.1

有一种节省空间的技术可以消除额外的空间需求，但它会使实现更复杂，速度也会稍慢一些。因此，这是一个空间/时间权衡的例子。其原理基于这样一个观察：如果我们存储两个值的和，那么用其中一个值减去另一个值，就可以还原出任意一个值。也就是说，如果把 a + b 存入变量 c，那么 b = c − a，a = c − b。当然，要从存储的和中恢复其中一个值，必须提供另一个值。指向链表中第一个结点的指针，加上其两个链接字段中一个字段的值，就可以按顺序访问链表中所有其余结点。这是因为该结点的指针必定等于下一个结点的 prev 指针的值，也等于前一个结点的 next 指针的值。可以像拉开拉链一样，沿着链表拆开这些相加的链接字段。这种变体的实现细节留作练习。

这个技术背后的原理值得记住，因为它有很多应用。下面的代码片段可以在不使用临时变量的情况下交换两个变量的内容（代价是三次算术运算）。

```
a = a + b; // Now b contains original value of a
b = a - b; // Now b contains original value of a
a = a - b; // Now a contains original value of b
```

使用异或运算符也可以达到类似的效果。这个事实在计算机图形学中被广泛使用。计算机屏幕上的一个区域可以通过对其周围画一个方框轮廓进行异或运算来高亮显示。再次对该方框轮廓进行异或运算，即可恢复屏幕的原始内容。

## 4.2 栈

栈是一种类似列表的结构，元素只能从一端插入或移除。虽然这一限制使栈不如列表灵活，但也使栈既高效（就它们能执行的操作而言）又易于实现。许多应用只需要栈提供的有限形式的插入和删除操作。在这种情况下，使用更简单的栈数据结构比使用通用列表更高效。例如，4.1.2 节中的空闲链表实际上就是一个栈。

尽管有种种限制，栈仍有很多用途。因此，栈已经形成了一套专门的词汇。早在计算机发明之前，会计师们就使用了栈。他们称栈为“LIFO”列表，即“Last-In, First-Out”（后进先出）列表。

// Stack abstract class
template <typename E> class Stack {
private:
    void operator =(const Stack&) {}      // Protect assignment
    Stack(const Stack&) {}               // Protect copy constructor

public:
    Stack() {}                           // Default constructor
    virtual ~Stack() {}                  // Base destructor

    // Reinitialize the stack. The user is responsible for
    // reclaiming the storage used by the stack elements.
    virtual void clear() = 0;

    // Push an element onto the top of the stack.
    // it: The element being pushed onto the stack.
    virtual void push(const E& it) = 0;

    // Remove the element at the top of the stack.
    // Return: The element at the top of the stack.
    virtual E pop() = 0;

    // Return: A copy of the top element.
    virtual const E& topValue() const = 0;

    // Return: The number of elements in the stack.
    virtual int length() const = 0;
};

### 4.2.1 基于数组的栈

图4.18展示了基于数组的栈类的完整实现。与基于数组的列表实现一样，创建栈时，listArray 必须声明为固定大小。在栈构造函数中，size 用于表示这个大小。top 方法的作用有点像当前位置值（因为“当前”位置始终在栈顶），同时也表示栈中当前元素的个数。

**top** 应被设为栈顶元素的索引，而不是第一个空闲位置。如果这样做，空栈会将 **top** 初始化为 –1。方法 **push** 和 **pop** 只是将元素放入 **top** 指示的数组位置，或从该位置移除元素。因为假定 **top** 位于第一个空闲位置，所以 **push** 先将值插入 top 位置，然后递增 **top**；而 **pop** 先递减 **top**，然后移除栈顶元素。
