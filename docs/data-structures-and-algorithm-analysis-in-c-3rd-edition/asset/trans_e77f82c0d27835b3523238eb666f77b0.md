### Example 2.3

我们可以使用模函数（在下一节中定义）来定义一个等价关系。对于整数集合，使用模函数定义一个二元关系，使得两个数 x 和 y 在该关系中当且仅当 x mod m = y mod m。因此，对于 m = 4，⟨1, 5⟩ 在该关系中，因为 1 mod 4 = 5 mod 4。我们看到以这种方式使用的模数定义了整数上的等价关系，并且该关系可用于将整数划分为 m 个等价类。该关系是一个等价关系，因为

- 1. x mod m = x mod m 对所有 x 成立；
- 2. 如果 x mod m = y mod m，则 y mod m = x mod m；并且
- 3. 如果 x mod m = y mod m 且 y mod m = z mod m，则 x mod m = z mod m。

二元关系如果反自反且传递，则称为偏序。² 偏序所定义的集合称为偏序集或 poset。集合中的元素 x 和 y 在给定关系下是可比较的，如果 xRy 或 yRx。如果偏序中每一对不同元素都是可比较的，则该序称为全序或线性序。

布尔变量：布尔变量是类型为 C++ 中的 bool 的变量，它取 true 和 false 两个值中的一个。这两个值通常分别与值 1 和 0 相关联，尽管没有理由必须如此。依赖于 0 与 false 之间的对应关系是不良的编程实践，因为它们在逻辑上是不同类型的不同对象。

逻辑符号：我们偶尔会使用符号或布尔逻辑的记号。A ⇒ B 表示“A 蕴含 B”或“如果 A 则 B”。A ⇔ B 表示“A 当且仅当 B”或“A 等价于 B”。A ∨ B 表示“A 或 B”（在符号逻辑的上下文或执行布尔运算时都很有用）。A ∧ B 表示“A 且 B”。∼ A 和 Ā 都表示“非 A”或 A 的否定，其中 A 是一个布尔变量。

向下取整和向上取整：x 的向下取整（写为 ⌊x⌋）取实值 x 并返回 ≤ x 的最大整数。例如，⌊3.4⌋ = 3，⌊3.0⌋ 也是如此，而 ⌊−3.4⌋ = −4 且 ⌊−3.0⌋ = −3。x 的向上取整（写为 ⌈x⌉）取实值 x 并返回 ≥ x 的最小整数。例如，⌈3.4⌉ = 4，⌈4.0⌉ 也是如此，而 ⌈−3.4⌉ = ⌈−3.0⌉ = −3。

模运算符：模（或 mod）函数返回整数除法的余数。有时在数学表达式中写为 n mod m，C++ 模运算符的语法是 n % m。根据余数的定义，n mod m 是整数 r，使得 n = qm + r，其中 q 为整数，且 |r| < |m|。因此，当 n 和 m 为正整数时，n mod m 的结果必须在 0 到 m − 1 之间。例如，5 mod 3 = 2；25 mod 3 = 1，5 mod 7 = 5，且 5 mod 5 = 0。

分配 q 和 r 的值有不止一种方法，这取决于整数除法的解释。最常见的数学定义将 mod 函数计算为 n mod m = n − m⌊n/m⌋。在这种情况下，−3 mod 5 = 2。然而，Java 和 C++ 编译器通常使用底层处理器用于计算整数运算的机器指令。在许多计算机上，这是通过截断结果分数来完成的，意味着 n mod m = n − m(trunc(n/m))。根据此定义，−3 mod 5 = −3。

不幸的是，对于许多应用来说，这不是用户想要或期望的。例如，许多哈希系统会对记录的键值执行某些计算，然后取结果对哈希表大小取模。这里的期望是结果是哈希表中的合法索引，而不是负数。哈希函数实现者必须确保计算结果始终为正，或者在模运算结果为负时，将哈希表大小加到模运算结果上。

## 2.3 对数

值 y 的底为 b 的对数是 b 被提高到得到 y 的幂。通常写为 log_b y = x。因此，如果 log_b y = x，则 b^x = y，且 b^{log_b y} = y。

程序员经常使用对数。以下是两个典型用途。

### Example 2.6

许多程序需要一组对象的编码。表示 n 个不同代码值所需的最小位数是多少？答案是 ⌈log₂ n⌉ 位。例如，如果你有 1000 个代码要存储，你至少需要 ⌈log₂ 1000⌉ = 10 位来拥有 1000 个不同的代码（10 位提供 1024 个不同的代码值）。

### Example 2.7

考虑用于在按值从低到高排序的数组中查找给定值的二分搜索算法。二分搜索首先查看中间元素并确定要搜索的值是在数组的上半部分还是下半部分。然后算法继续将适当的子数组一分为二，直到找到所需的值为止。（二分搜索在第 3.5 节中更详细地描述。）一个大小为 n 的数组能被分成一半多少次，直到最终子数组只剩下一个元素？答案是 ⌈log₂ n⌉ 次。

在本书中，几乎所有使用的对数底数都是 2。这是因为数据结构和算法最常将事物分成两半，或使用二进制位存储代码。每当你在本书中看到 log n 的记号时，要么是指 log₂ n，要么术语是渐近使用的，因此实际底数并不重要。任何底数不为二的对数都会明确显示底数。

对数具有以下性质，对于任意正值 m、n 和 r，以及任意正整数 a 和 b。

- 1. log(nm) = log n + log m.
- 2. log(n/m) = log n − log m.
- 3. log(n^r) = r log n.
- 4. log_a n = log_b n / log_b a.
