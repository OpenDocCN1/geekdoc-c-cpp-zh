## 文件处理和外部排序

前几章介绍了在主内存中存储数据时操作的基本数据结构和算法。某些应用程序需要存储和处理大量信息——多到无法全部放入主内存。在这种情况下，信息必须驻留在磁盘上，并有选择地调入主内存进行处理。

你可能已经意识到，主内存访问比访问存储在磁盘或其他存储设备上的数据快得多。访问时间的相对差异如此之大，以至于高效的基于磁盘的程序需要不同于大多数程序员习惯的算法设计方法。因此，许多程序员在文件处理应用程序方面做得不好。

本章介绍了为磁盘应用程序设计算法和数据结构时涉及的基本问题。¹ 我们首先描述主存储器和辅助存储器之间的显著差异。第 8.2 节讨论磁盘驱动器的物理方面。第 8.3 节介绍管理缓冲池的基本方法。第 8.4 节讨论 C++ 对存储在磁盘上的数据的随机访问模型。第 8.5 节讨论对太大而无法放入主内存的记录集合进行排序的基本原则。

## 8.1 主存储与辅助存储

计算机存储设备通常分为主存储器或主内存和辅助或外围存储器。主内存通常指随机存取存储器（RAM），而辅助存储器指诸如硬盘驱动器、固态驱动器、可移动“USB”驱动器、CD 和 DVD 等设备。主内存还包括寄存器、缓存和视频内存，但我们将在本讨论中忽略它们，因为它们的存在不影响主存储器和辅助存储器之间的主要差异。

随着更快的 CPU，每台新计算机似乎都配备了更多的主内存。随着内存尺寸不断增加，相对较慢的磁盘存储是否会变得不必要？可能不会，因为存储和处理更大文件的需求至少与主内存尺寸增长一样快。近年来，主内存和外围存储设备的价格都大幅下降，如图 8.1 所示。然而，磁盘驱动器存储的每单位成本约为 RAM 的两个数量级，并且多年来一直如此。

现在有各种可移动媒体可用于传输数据或相对安全地离线存储数据。这些包括软盘（现在已基本过时）、可写 CD 和 DVD、“闪存”驱动器以及磁带。光学存储如 CD 和 DVD 的每兆字节成本约为硬盘驱动器空间的一半，并且在过去几年中已成为备份存储的实用选择。磁带过去比其他媒体便宜得多，是首选的备份手段，但随着其他媒体价格下降，现在已不再那么流行。“闪存”驱动器每兆字节成本最高，但由于其存储容量和灵活性，迅速取代了软盘，成为在没有直接网络传输时在计算机之间传输数据的首要存储设备。

辅助存储设备相比 RAM 内存还有另外两个优势。最重要的是，磁盘、“闪存”和光学媒体是持久的，这意味着关闭电源时数据不会从媒体中擦除。相比之下，用于主内存的 RAM 通常是易失性的——断电后所有信息都会丢失。第二个优势是 CD 和“USB”驱动器可以轻松在计算机之间传输。这提供了一种方便的方式将信息从一台计算机带到另一台计算机。

这需要能够准确猜测稍后需要什么信息并现在将其存储在主内存中。这被称为 **caching.**

## 8.2 磁盘驱动器

**C++** 程序员将存储在磁盘上的随机访问文件视为连续的字节序列，这些字节可能组合成数据记录。这称为 **logical** 文件。实际存储在磁盘上的 **physical** 文件通常不是连续的字节序列。它可能分散在磁盘各处。**file manager**，即操作系统的一部分，负责将对逻辑文件的数据请求映射到磁盘上数据的物理位置。同样，在写入相对于文件开头的特定逻辑字节位置时，该位置必须由文件管理器转换为磁盘上的相应物理位置。为了对这些操作的近似时间成本有所了解，你需要了解磁盘驱动器的物理结构和基本工作原理。

磁盘驱动器通常被称为 **direct access** 存储设备。这意味着访问文件中的任何记录所需的时间大致相等。这与 **sequential access** 存储设备如磁带驱动器形成对比，磁带驱动器要求磁带阅读器从磁带开头处理数据直到达到所需位置。正如你将看到的，磁盘驱动器只是近似的直接访问：在任何给定时间，一些记录比其他记录更容易访问。

### 8.2.1 磁盘驱动器架构

硬盘驱动器由一个或多个圆形 **platters** 组成，堆叠在一起并附着在中央 **spindle** 上。盘片以恒定速率连续旋转。每个盘片的每个可用表面都分配有一个 **read/write head** 或 **I/O head**，通过它读取或写入数据，有点像唱机唱臂“读取”唱片声音的布置。与唱针不同，磁盘读写头实际上并不接触硬盘表面。相反，它保持在表面上方，正常操作期间的任何接触都会损坏磁盘。这个距离非常小，比尘粒的高度还要小得多。可以将其比作从美国横跨 5000 公里的飞机飞行，飞机飞行高度为一米！
