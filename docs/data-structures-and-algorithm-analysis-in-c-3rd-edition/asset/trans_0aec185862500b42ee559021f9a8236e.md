## 16 算法模式

本章介绍与算法理论相关的几个基础主题。包括动态规划（第 16.1 节）、随机化算法（第 16.2 节）以及变换的概念（第 16.3.5 节）。其中每一个都可以看作是一种广泛应用于各种场景的“算法模式”的示例。此外，第 16.3 节介绍了一些数值算法。关于随机化算法的第 16.2 节包含跳跃表（第 16.2.2 节）。跳跃表是一种概率数据结构，可用于实现字典 ADT（抽象数据类型）。跳跃表并不比二叉搜索树（BST）复杂。然而，它通常优于 BST，因为跳跃表的效率不依赖于所存储数据集的值的顺序或插入顺序。

### 16.1 动态规划

再次考虑用于计算第 n 个斐波那契数的递归函数。

```cpp
long fibr(int n) { // Recursive Fibonacci generator
    // fibr(46) is largest value that fits in a long
    Assert((n > 0) && (n < 47), "Input out of range");
    if ((n == 1) || (n == 2)) return 1; // Base cases
    return fibr(n-1) + fibr(n-2);        // Recursion
}
```

该算法的成本（就函数调用而言）是第 n 个斐波那契数本身的大小，我们在第 14.2 节的分析表明其是指数级的（约为 φ^n）。为什么这么昂贵？主要是因为该函数进行了两次递归调用，而它们所做的工作在很大程度上是冗余的。也就是说，这两个调用中的每一个都在重新计算大部分数列，每个子调用也是如此，依此类推。因此，函数的较小值被重复计算了非常多次。如果我们能消除这种冗余，成本将大大降低。我们将采用的方法也可以改进任何将大部分时间花在重复计算常见子问题上的算法。

实现这一目标的一种方法是保留一个值表，并首先检查该表以确定是否可以避免计算。下面是一个简单的示例。

```cpp
int Fibrt(int n, int* Values) {
    // Assume Values has at least n slots, and all
    // slots are initialized to 0
    if (n <= 1) return 1;                // Base case
    if (Values[n] == 0)
        Values[n] = Fibrt(n-1, Values) + Fibrt(n-2, Values);
    return Values[n];
}
```

该算法的这个版本不会重复计算同一个值，因此其成本应该是线性的。当然，我们实际上并不需要使用表来存储所有值，因为后续的计算不需要访问所有先前的子问题。相反，我们可以从 0 和 1 开始向上计算到 n，而不是从 n 向下回溯到 0 和 1。从底部向上进行时，我们只需要存储函数的前两个值，正如我们的迭代版本所做的那样。

```cpp
long fibi(int n) { // Iterative Fibonacci generator
    // fibi(46) is largest value that fits in a long
    Assert((n > 0) && (n < 47), "Input out of range");
    long past, prev, curr;  // Store temporary values
    past = prev = curr = 1;     // initialize
    for (int i=3; i<=n; i++) { // Compute next value
        past = prev;            // past holds fibi(i-2)
        prev = curr;            // prev holds fibi(i-1)
        curr = past + prev;     // curr now holds fibi(i)
    }
    return curr;
}
```

子问题的重复计算在许多算法中都会出现。但很少能像我们在 Fibi 中那样只存储少量先前结果。因此，很多时候存储一份完整的子结果表将会很有用。

这种通过存储子问题结果表来设计算法的方法称为动态规划。这个名称有点晦涩，因为它与在表中存储子问题所发生的过程没有太多明显的相似之处。然而，它最初来自动态控制系统领域，该领域的出现早于我们所说的计算机编程。在那个领域，将预先计算好的值存储在表中以供后续重用被称为“编程”。
