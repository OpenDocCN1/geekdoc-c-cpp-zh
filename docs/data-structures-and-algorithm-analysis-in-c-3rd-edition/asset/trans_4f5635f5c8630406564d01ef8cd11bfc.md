# 列表与数组再探

简单的列表和数组是许多应用的合适工具。其他情况则需要支持那些无法通过第 4 章的标准列表表示高效实现的操作。本章介绍一系列主题，这些主题的统一线索是所包含的数据结构都是类似列表或数组的。这些结构克服了简单链表和连续数组表示的一些问题。本章还试图强化逻辑表示与物理实现的概念，因为一些“列表”实现在内部具有截然不同的组织方式。

12.1 节描述了一系列广义表的表示方法，广义表是可能包含子表的列表。12.2 节讨论了实现稀疏矩阵的表示方法，稀疏矩阵是大多数元素值为零的大型矩阵。12.3 节讨论了内存管理技术，其本质上是从一个大数组中分配可变长度片段的一种方法。

## 12.1 广义表

回顾第 4 章，列表是一个有限的有序序列，其形式为 ⟨x₀, x₁, ..., xₙ₋₁⟩，其中 n ≥ 0。我们可以用 NULL 或 ⟨⟩ 表示空列表。在第 4 章中，我们假设所有列表元素都具有相同的数据类型。在本节中，我们扩展列表的定义，允许元素本质上可以是任意的。一般来说，列表元素是两种类型之一。

- 1. **原子**，它是某种类型的数据记录，例如数字、符号或字符串。
- 2. 另一个列表，称为**子表**。

包含子表的列表将写成如下形式：

```
⟨x1, ⟨y1, ⟨a1, a2⟩, y3⟩, ⟨z1, z2⟩, x4⟩.
```

在这个示例中，列表有四个元素。第二个元素是子表 ⟨y1, ⟨a1, a2⟩, y3⟩，第三个元素是子表 ⟨z1, z2⟩。子表 ⟨y1, ⟨a1, a2⟩, y3⟩ 本身包含一个子表。如果一个列表 L 有一个或多个子表，我们称 L 为广义表（multi-list）。没有子表的列表通常称为线性表或链。注意，广义表的这一定义与定义 2.1 中集合的定义非常吻合，在集合定义中，集合的成员可以是基本元素或集合。

我们可以以多种方式限制广义表的子表，具体取决于广义表应具有树、DAG 或一般图的形式。纯表是一种列表结构，其图对应一棵树，如图 12.1 所示。换句话说，从根到任意节点恰好有一条路径，这等价于说没有对象可以在列表中出现多次。在纯表中，每一对尖括号对应树的一个内部节点。列表的成员对应节点的子节点。列表中的原子对应叶节点。

再入表是一种列表结构，其图对应一个 DAG。从根到某些节点可能存在多条路径，这等价于说对象（包括子表）在列表中可能多次出现，只要不形成环。所有边都向下指向，从表示列表或子表的节点指向其元素。图 12.2 展示了一个再入表。要用括号表示法写出这个列表，我们可以根据需要复制节点。因此，图 12.2 中列表的括号表示法可以写成：

```
⟨⟨⟨a, b⟩⟩, ⟨⟨a, b⟩, c⟩, ⟨c, d, e⟩, ⟨e⟩⟩.
```
