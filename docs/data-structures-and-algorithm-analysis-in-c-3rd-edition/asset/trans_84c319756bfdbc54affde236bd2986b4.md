# 图 17.4 旅行商问题的一个示例。

图中显示了五个顶点，每对城市之间都有边。问题是要恰好访问所有城市一次，并返回起始城市，且总成本最小。

图 17.4 展示了这个问题。图中显示了五个顶点，每对边之间都有边和相关成本。（为简单起见，图 17.4 显示的是无向图，假设两个方向的成本相同，尽管实际情况未必如此。）如果销售员按 ABCDEA 的顺序访问这些城市，他将总共旅行 13 的距离。更好的路线是 ABDCEA，成本为 11。对于这个特定图，最佳路线是 ABEDCA，成本为 9。

我们无法用猜测-测试型的非确定性计算机在多项式时间内解决这个问题。问题在于：给定一个候选回路，虽然我们可以快速检查该答案确实是一个形式合适的回路，并且可以快速计算回路的长度，但我们没有办法轻松知道它是否实际上是最短的此类回路。然而，我们可以解决这个问题的一个变体，将其转化为判定问题的形式。判定问题就是答案仅为“是”或“否”的问题。旅行商问题的判定问题形式如下：

旅行商问题（2）
输入：一个完整的、有向图 G，图中每条边都赋予了正距离，以及一个整数 k。
输出：如果存在一个总距离 ≤ k 且包含 G 中每个顶点的简单回路，则输出“是”，否则输出“否”。

我们可以用非确定性计算机在多项式时间内解决这个版本的问题。该非确定性算法只是并行地检查图中所有可能的边子集。如果任何边的子集是一个总长度小于或等于 k 的合适回路，则答案为“是”；否则答案为“否”。注意，只需要某个子集满足要求即可；有多少子集不满足并不重要。检查特定子集是在多项式时间内完成的，方法是加上各条边的距离，并验证这些边是否构成一个恰好访问每个顶点一次的回路。因此，检查算法在多项式时间内运行。不幸的是，需要检查的子集有 2^{|E|} 个，因此该算法无法在普通计算机上转换为多项式时间算法。尽管许多计算机科学家多年来已经广泛研究过这个问题，但世界上也没有人知道在普通计算机上解决旅行商问题的任何其他多项式时间算法。

事实证明，有一大类问题具有这种性质：我们知道高效的非确定性算法，但不知道是否存在高效的确定性算法。同时，我们也无法证明这些问题中的任何一个不存在高效的确定性算法。这类问题被称为 NP 完全问题。NP 完全问题真正奇特和迷人的地方在于：如果有人能够在普通计算机上找到针对其中任何一个问题的多项式时间解法，那么通过一系列归约，NP 中的每一个其他问题也可以在普通计算机上多项式时间内解决！

如果 NP 中的任何问题都可以在多项式时间内归约为某个问题 X，则将 X 定义为 NP 困难问题。因此，X 和 NP 中的任何问题一样难。一个问题 X 被定义为 NP 完全的，如果

+   1. X 属于 NP，并且
+   2. X 是 NP 困难的。

要求一个问题是 NP 困难的似乎不可能，但事实上，有数百个这样的问题，包括旅行商问题。另一个这样的问题被称为 K-团问题。

K-团问题
输入：一个任意的无向图 G 和一个整数 k。
输出：如果存在一个至少包含 k 个顶点的完全子图，则输出“是”，否则输出“否”。

没有人知道 K-团问题是否存在多项式时间解法，但如果找到了针对 K-团问题或旅行商问题的此类算法，那么该解法可以被修改以在多项式时间内解决另一个问题，或者 NP 中的任何其他问题。

图 17.5 我们对需要指数时间或更少时间的问题世界的认识。其中一些问题可以用非确定性计算机在多项式时间内解决。在这些问题中，有些已知是 NP 完全的，有些已知可以在普通计算机上多项式时间内解决。

如果一个问题是 NP 完全的，那么就可以为所有此类问题找到多项式解法。这意味着：

+   1. 因为还没有人找到这样的解法，所以它一定是困难的或者不可能做到的；并且
+   2. 为某个 NP 完全问题寻找多项式时间解法的努力，可以被视为是为所有 NP 完全问题付出的努力。

NP 完全性对典型程序员有什么实际意义呢？好吧，如果你的老板要求你提供一个快速算法来解决问题，如果你回来说你所能做到的最好结果只是一个指数时间算法，她不会高兴。但是，如果你能证明该问题是 NP 完全的，那么虽然她仍然不会高兴，但至少她不应该对你生气！通过表明她的问题是 NP 完全的，你实际上是在说，过去 50 年里最杰出的计算机科学家们一直在尝试并失败于为她的问题寻找多项式时间算法。

在普通计算机上多项式时间内可解决的问题被认为属于 P 类。显然，P 中的所有问题都可以在非确定性计算机上多项式时间内解决，只需不使用非确定性能力即可。NP 中的一些问题属于 NP 完全问题。我们可以把所有可以在指数时间或更短时间内解决的问题看作一个更大的问题类别，因为所有多项式时间内可解决的问题都可以在指数时间内解决。因此，我们可以用图 17.5 来观察指数时间或更优时间的问题世界。

理论计算机科学中最重要而未解答的问题是 P 是否等于 NP。如果它们相等，那么对于旅行商问题及其所有相关问题就存在一个多项式时间算法。由于旅行商问题已知是 𝒩𝒫 完全的，如果能找到针对该问题的多项式时间算法，那么 𝒩𝒫 中的所有问题也将可以在多项式时间内解决。反过来，如果我们能够证明旅行商问题有一个指数时间的下界，那么我们就会知道 𝒫 ≠ 𝒩𝒫。

# 17.2.2 𝒩𝒫 完全性证明

为了开始证明问题是 𝒩𝒫 完全的过程，我们需要先证明一个问题 H 是 𝒩𝒫 完全的。之后，要证明任何问题 X 是 𝒩𝒫 困难的，我们只需要将 H 归约为 X。在撰写 𝒩𝒫 完全性证明时，千万不要把归约方向搞反，这一点非常重要！如果我们将候选问题 X 归约为已知困难问题 H，这意味着我们使用 H 作为解决 X 的一个步骤。这仅仅意味着我们找到了一种（已知的）困难方法来解决问题 X。然而，当我们将已知困难问题 H 归约为候选问题 X 时，这意味着我们使用 X 作为解决 H 的一个步骤。如果我们知道 H 是困难的，那么这意味着 X 也一定是困难的（因为如果 X 不是困难的，那么 H 也不会是困难的）。

因此，让整个理论得以起步的关键第一步就是找到一个 𝒩𝒫 困难问题。第一个证明某个问题是 𝒩𝒫 困难的（并且因为它在 𝒩𝒫 中，因此也是 𝒩𝒫 完全的）是由斯蒂芬·库克完成的。正因为这一成就，库克获得了第一个图灵奖，这是计算机科学领域最接近诺贝尔奖的奖项。库克使用的“老祖宗”级 𝒩𝒫 完全问题被称为可满足性问题（或简称 SAT）。

布尔表达式包括使用运算符与（·）、或（+）和非（NOT）组合起来的布尔变量（对布尔变量 x 取非，我们写作 x̄）。文字是一个布尔变量或其否定。子句是一个或多个文字用或连接而成。设 E 是变量 x₁、x₂、…、xₙ 上的一个布尔表达式。然后我们定义合取范式（CNF）为一个布尔表达式，写成一系列用与连接起来的子句。例如，

E = (x₅ + x₇ + x̄₈ + x₁₀) · (x̄₂ + x₃) · (x₁ + x̄₃ + x₆)

就是 CNF 形式，并且有三个子句。现在我们可以定义问题 SAT。

可满足性问题（SAT）
输入：一个关于变量 x₁、x₂、... 的布尔表达式 E，采用合取范式。
输出：如果存在对变量的赋值使 E 为真，则输出“是”，否则输出“否”。
