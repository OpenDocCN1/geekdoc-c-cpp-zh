图 13.1 值集合 {2, 7, 24, 31, 37, 40, 42, 120} 的二叉字典树。所有数据值都存储在叶节点中。每条边都标有用于确定每个节点分支方向的位值。假设每个键被表示为一个 7 位值（代表 0 到 127 范围内的一个数），键值的二进制形式决定了到达记录的路径。

每个节点最多有 27 个指针。一旦构建完成，字母表字典树便用于判断给定单词是否在字典中。考虑在图 13.2 的字母表字典树中查找一个单词。搜索单词的第一个字母决定从根节点沿哪条分支走，第二个字母决定在下一层沿哪条分支走，依此类推。只有那些通向某个单词的字母才会作为分支显示。在图 13.2(b) 中，字典树的叶节点存储实际单词的副本；而在图 13.2(a) 中，单词由与每条分支关联的字母拼接而成。

实现字母表字典树节点的一种方法是使用一个由 27 个指针组成的数组，以字母作为索引。由于大多数节点只有到字母表中小部分字母的分支，另一种实现是使用指向子节点的指针链表，如图 6.9 所示。

在图 13.2(b) 的字母表字典树中，叶节点的深度与字典树中的节点数关系不大，甚至与对应字符串的长度关系也不大。更确切地说，节点的深度取决于将该节点的单词与其他任何单词区分开所需的字符数。例如，如果单词“anteater”和“antelope”都存储在字典树中，那么直到第五个字母才能将这两个单词区分开。因此，这些单词的存储深度至少必须达到第五层。一般来说，限制字母表字典树中节点深度的因素是所存储单词的长度。

图 13.1 和图 13.2 所示的字典树实现可能相当低效，因为某些键集合可能导致大量只有一个子节点的节点。字典树实现的一种变体被称为 PATRICIA，它是“Practical Algorithm To Retrieve Information Coded In Alphanumeric”的缩写，意为“一种检索以字母数字编码的信息的实用算法”。在二进制字母表的情况下，PATRICIA 字典树（下文简称 PAT 字典树）是一棵满二叉树，数据记录存储在叶节点中。内部节点只存储键位模式中用于决定下一个分支点的位置。这样，只有一个子节点的内部节点（等价地，即键中那些不能区分当前子树内任何键的位位置）就被消除了。与图 13.1 中值对应的 PAT 字典树如图 13.3 所示。
