## 3.4.3 Θ 表示法

大-Oh 和 Ω 的定义为我们提供了描述算法上界的方法，如果我们能找到特定大小为 n 的输入类的最大成本方程，以及描述算法下界的方法，如果我们能找到特定大小为 n 的输入类的最小成本方程。当上界和下界在常数因子内相同时，我们用 Θ 表示法 big-Theta 来表示这一点。算法被称为 Θ(h(n))，如果它在 O(h(n)) 中并且它在 Ω(h(n)) 中。注意，对于 Θ 表示法，我们省略了“in”这个词，因为对于具有相同 Θ 的两个方程存在严格的相等关系。换句话说，如果 f(n) 是 Θ(g(n))，那么 g(n) 是 Θ(f(n))。

> T(n) 在集合 Ω(g(n)) 中，如果存在正常数 c，使得 T(n) ≥ c g(n) 对 n 的无穷多个值成立。

该定义说明对于“有趣的”数量的情形，算法至少需要 c g(n) 时间。注意，该定义与大-Oh 的定义不对称。对于 g(n) 成为下界，该定义并不要求 T(n) ≥ c g(n) 对所有大于某个常数的 n 值都成立。它只要求这种情况发生足够频繁，特别是对 n 的无穷多个值成立。以下示例可提供这种替代定义的动机。

假设某个算法具有以下行为：

T(n) = { n 对于所有奇数 n ≥ 1；n²/100 对于所有偶数 n ≥ 0 }

根据此定义，n²/100 ≥ 1/100 n² 对于所有偶数 n ≥ 0 成立。因此，T(n) ≥ c n² 对 n 的无穷多个值成立，即对所有偶数 n 成立，其中 c = 1/100。因此，根据定义，T(n) 在 Ω(n²) 中。

对于 T(n) 的该方程，大小为 n 的所有输入至少需要 c n 时间成立。但大小为 n 的无穷多个输入需要 c n² 时间，因此我们希望说该算法在 Ω(n²) 中。不幸的是，使用我们的第一个定义会得出 Ω(n) 的下界，因为不可能选择常数 c 和 n₀ 使得 T(n) ≥ c n² 对所有 n > n₀ 成立。替代定义确实为该算法得出 Ω(n²) 的下界，这似乎更符合常识。幸运的是，很少有真实的算法或计算机程序表现出此示例的病态行为。我们的第一个 Ω 定义通常会得出预期结果。

正如你从本讨论中看到的，渐近界限表示法并不是自然法则。它只是一种强大的建模工具，用于描述算法的行为。

## 3.4.4 简化规则

一旦你确定了算法的运行时间方程，从方程中推导出大-Oh、Ω 和 Θ 表达式其实很简单。你不需要诉诸渐近分析的形式定义。相反，你可以使用以下规则来确定最简形式。

1. 如果 f(n) 在 O(g(n)) 中且 g(n) 在 O(h(n)) 中，则 f(n) 在 O(h(n)) 中。
2. 如果 f(n) 在 O(k g(n)) 中，其中任意常数 k > 0，则 f(n) 在 O(g(n)) 中。
3. 如果 f₁(n) 在 O(g₁(n)) 中且 f₂(n) 在 O(g₂(n)) 中，则 f₁(n) + f₂(n) 在 O(max(g₁(n), g₂(n))) 中。
4. 如果 f₁(n) 在 O(g₁(n)) 中且 f₂(n) 在 O(g₂(n)) 中，则 f₁(n) f₂(n) 在 O(g₁(n) g₂(n)) 中。

第一条规则说明，如果某个函数 g(n) 是你的成本函数的上界，则 g(n) 的任何上界也是你的成本函数的上界。类似的性质对 Ω 表示法也成立：如果 g(n) 是你的成本函数的下界，则 g(n) 的任何下界也是你的成本函数的下界。Θ 表示法亦然。

规则 (2) 的意义在于，使用大-Oh 表示法时，你可以忽略方程中的任何乘性常数。该规则对 Ω 和 Θ 表示法也成立。

规则 (3) 说明，给定程序的两个部分顺序运行，无论是两个语句还是两段代码，你只需考虑更昂贵的部分。该规则同样适用于 Ω 和 Θ 表示法：对于两者，你只需考虑更昂贵的部分。

规则 (4) 用于分析程序中的简单循环。如果某个操作重复若干次，且每次重复的成本相同，则总成本是操作成本乘以操作发生的次数。该规则同样适用于 Ω 和 Θ 表示法。

综合前三条规则，你可以忽略所有常数和所有低阶项来确定任何成本函数的渐近增长率。忽略常数的优点和危险在该节开头附近已讨论过。忽略低阶项在进行渐近分析时是合理的。随着 n 变大，高阶项很快就会淹没低阶项对总成本的贡献。因此，如果 T(n) = 3n⁴ + 5n²，则 T(n) 在 O(n⁴) 中。对于大的 n，n² 项对总成本的贡献相对很小。

在本书的其余部分中，在讨论程序或算法的成本时，将使用这些简化规则。

## 3.4.5 分类函数

给定增长速率以代数方程表示的函数 f(n) 和 g(n)，我们可能想确定哪一个增长更快。最好的方法是取这两个函数当 n 趋向无穷大时的极限，

limₙ→∞ f(n)/g(n)。

如果极限趋向于 ∞，则 f(n) 在 Ω(g(n)) 中，因为 f(n) 增长更快。如果极限趋向于零，则 f(n) 在 O(g(n)) 中，因为 g(n) 增长更快。如果极限趋向于非零的某个常数，则 f(n) = Θ(g(n))，因为两者以相同的速率增长。
