- 4.5 使用无序列表实现城市数据库。每个数据库记录包含城市名称（任意长度的字符串）和城市坐标，表示为整数 x 和 y 坐标。你的数据库应允许按名称或坐标插入记录、按名称或坐标删除记录，以及按名称或坐标搜索记录。另一个应支持的操作是打印指定点给定距离范围内的所有记录。使用基于数组的列表实现实现数据库，然后使用链表实现。收集两种实现中每个操作的运行时间统计。关于两种实现的相对优缺点，你的结论是什么？按城市名称按字母顺序存储记录会加快任何操作吗？保持列表按字母顺序会减慢任何操作吗？

- 4.6 修改图 4.18 的代码以支持存储最多 255 个字符的可变长度字符串。栈数组应为 char 类型。字符串由一系列字符表示（每个栈元素一个字符），字符串的长度存储在其正上方的栈元素中，如图 4.35 所示。push 操作会将需要 i 个存储单元的元素存储在从当前 top 值开始的 i 个位置中，并在 top 上方 i 个存储单元的位置存储大小。然后 top 的值会重置到新插入元素之上。pop 操作只需查看位置 top − 1 中存储的大小值，然后弹出适当数量的单元。你可以按相反顺序将字符串存储在栈上，只要在从栈弹出时按正确顺序返回即可。
