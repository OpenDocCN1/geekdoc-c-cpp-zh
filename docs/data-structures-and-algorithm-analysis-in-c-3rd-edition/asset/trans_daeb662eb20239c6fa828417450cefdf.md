我们的下一个数学归纳法示例将证明一个几何定理。它还说明了一种标准的归纳证明技巧：取 n 个对象，然后移除某个对象来使用归纳假设。

### 示例 2.16

一组区域的二染色定义为：给每个区域分配两种颜色之一，使得任意两个共边的区域颜色都不相同。例如，棋盘就是二染色的。图 2.3 展示了平面内三条直线所形成区域的一种二染色。我们假设使用的两种颜色是黑色和白色。

### 定理 2.7

平面内 n 条无限直线所形成的区域集合可以被二染色。

证明：考虑平面内只有一条无限直线的基准情形。这条直线将平面分成两个区域。一个区域染成黑色，另一个染成白色，即可得到有效的二染色。归纳假设是：由 n − 1 条无限直线形成的区域集合可以被二染色。为了对 n 证明该定理，考虑从 n 条直线中任意移除一条后，剩余的 n − 1 条直线所形成的区域集合。根据归纳假设，这个区域集合可以被二染色。现在把第 n 条直线放回去。这会将平面分成两个半平面，每个半平面（各自独立地）都从 n − 1 条直线时平面的二染色中继承了一个有效的二染色。遗憾的是，被第 n 条直线新分割的区域违反了二染色的规则。取第 n 条直线某一侧的所有区域，反转它们的颜色（这样做之后，这个半平面仍然是二染色的）。那些被第 n 条直线分割的区域现在都满足二染色，因为区域位于直线一侧的部分现在是黑色，而另一侧的部分现在是白色。因此，由数学归纳法可知，整个平面可以被二染色。

将定理 2.7 的证明与定理 2.5 的证明进行比较。对于定理 2.5，我们取一个有 n − 1 枚邮票的集合（根据归纳假设，它必定具有所需性质），然后由它“构造”出一个有 n 枚邮票且具有所需性质的集合。因此，我们证明了存在某个包含 n 枚邮票且具有所需性质的集合。

对于定理 2.7，我们必须证明任意 n 条直线的集合都具有所需性质。因此，我们的策略是取任意一个包含 n 条直线的集合，并对其进行“约简”，从而得到一个与归纳假设匹配、因而必定具有所需性质的直线集合。在此基础上，我们只需说明逆转原来的约简过程会保持所需性质。

相比之下，考虑如果我们试图从一个包含 n − 1 条直线的集合“构造”出包含 n 条直线的集合，需要做些什么。我们会很难证明所有可能的 n 条直线集合都被这一构造过程覆盖。而通过从任意 n 条直线的集合约简到更小的集合，我们避免了这一问题。

本节最后一个示例说明如何用归纳法证明递归函数产生正确结果。

### 示例 2.17

我们希望证明函数 fact 确实计算阶乘函数。这样的证明包含两个不同步骤。第一步是证明函数总能终止。第二步是证明函数返回正确的值。

### 定理 2.8

函数 fact 对任意 n 值都会终止。

证明：对于基准情形，我们注意到当 n ≤ 0 时 fact 会直接终止。归纳假设是 fact 对 n − 1 会终止。对于 n，有两种可能。一种可能是 n > 12。在这种情况下，fact 会直接终止，因为它无法通过断言测试。否则，fact 会递归调用 fact(n-1)。根据归纳假设，fact(n-1) 必定终止。

### 定理 2.9

函数 fact 对于 0 到 12 范围内的任意值都能正确计算阶乘函数。

证明：为了证明基准情形，注意当 n = 0 或 n = 1 时，fact(n) 返回正确的值 1。归纳假设是 fact(n-1) 返回正确的值 (n − 1)!。对于合法范围内任意 n ≥ 2，fact(n) 返回 n * fact(n-1)。根据归纳假设，fact(n-1) = (n − 1)!，又因为 n * (n − 1)! = n!，所以我们证明了 fact(n) 产生正确结果。

我们可以用类似的过程证明许多递归程序的正确性。一般形式是：先证明基准情形能正确执行，然后利用归纳假设证明递归步骤也能产生正确结果。

在此之前，我们必须证明函数总能终止，这也可以通过归纳证明来完成。

## 2.7 估算

你能从计算机科学训练中获得的最有用的生活技能之一，是快速估算的能力。这种能力有时被称为“餐巾纸背面”或“信封背面”的计算。这两个叫法都表明产生的只是一个粗略估算。估算技术是工程课程的标准内容，但在计算机科学中却常被忽视。估算不能替代对问题的严格、详细分析，但它可以提示何时值得进行严格分析：如果初步估算表明解决方案不可行，那么进一步分析很可能没有必要。

估算可以通过以下三步流程来形式化：

1. 确定影响问题的主要参数。
2. 推导出将参数与问题联系起来的方程。
3. 为参数选定数值，并应用该方程得出估算解。

进行估算时，一个让自己确信估算是合理的好方法是换两种不同方式估算。一般来说，如果你想知道一个系统的输出，你可以尝试直接估算输出，也可以估算进入系统的输入（假设进入系统的最终会从系统出来）。如果两种方法（独立地）得到相近的答案，那么这应增强你对估算的信心。

计算时，务必确保单位一致。例如，不要将英尺和磅相加。验证结果是否以正确的单位表示。始终记住：计算输出的可靠程度不会超过其输入。第 3 步中对输入参数的估计越不确定，输出值就越不确定。然而，信封背面的计算通常只求得到数量级以内的答案，或者至多两倍以内的答案。开始估算前，你应该确定可接受的误差范围，比如 25% 以内、两倍以内等等。一旦你确信估算落在误差范围内，就到此为止！不要试图获得超出目的所需的更精确估算。

### 示例 2.18

存放包含一百万页的书籍需要多少个图书馆书柜？我估计一本 500 页的书在图书馆书架上需要 1 英寸（看看手边任何一本书的大小会有帮助），所以一百万页大约需要 200 英尺长的书架空间。如果一层书架宽 4 英尺，则需要 50 层。如果一个书柜有 5 层，则大约需要 10 个图书馆书柜。为了得出这个结论，我估计了每英寸的页数、一层书架的宽度以及一个书柜的层数。我的估计值很可能都不精确，但我有信心我的答案在两倍以内是准确的。（写完这段后，我去了弗吉尼亚理工大学的图书馆，看了一些真实的书柜。它们只有大约 3 英尺宽，但通常有 7 层，总共 21 英尺长的书架空间。因此，我对书柜容量的估计误差在 10% 以内，远好于我预期或需要的精度。我选定的数值一个偏高，另一个偏低，误差相互抵消了。）

### 示例 2.19

买一辆每加仑汽油行驶 20 英里的车，还是买一辆每加仑行驶 30 英里但贵 3000 美元的车，哪个更经济？普通汽车每年大约行驶 12,000 英里。如果汽油价格为每加仑 3 美元，那么低效率汽车每年的油费为 1800 美元，高效率汽车为 1200 美元。如果我们忽略一些因素，例如把 3000 美元存入银行所能获得的回报，则需要 5 年才能弥补价格上的差距。此时，买家必须决定价格是否是唯一标准，以及 5 年的回收期是否可以接受。自然，开车更多的人会更快弥补差距，而汽油价格的变化也会对结果产生很大影响。

### 示例 2.20

在超市进行每周采购时，你能估算出结账时大约要付多少钱吗？一种简单的方法是：把每件商品的价格四舍五入到最近的美元，然后在把商品放入购物车时，把这个数值加到心算的累加总额中。这样得出的答案很可能与真实总额只差几美元。

## 2.8 延伸阅读

本章涵盖的大部分主题被认为是离散数学的一部分。该领域的一本入门教材是苏珊娜·S·埃普（Susanna S. Epp）所著的*《离散数学及其应用》*[Epp10]。关于许多对计算机科学家有用的数学专题的更深入论述，见葛立恒（Graham）、高德纳（Knuth）和帕塔什尼克（Patashnik）合著的*《具体数学：计算机科学基础》*[GKP94]。

关于本书中用于表示计算机存储单位的标准的讨论，见*IEEE Spectrum* 1995 年 2 月号的“技术漫谈”[Sel95]。
