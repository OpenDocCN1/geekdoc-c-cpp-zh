## 17.3.1 不可数性

在证明停机问题不可解之前，我们首先要证明并非所有函数都能用计算机程序实现。之所以如此，是因为程序的数量远小于可能函数的总数。

如果一个集合中的每个成员都能被唯一地分配到一个正整数，则该集合称为可数的（如果它是一个包含无限多个成员的集合，则称为可数无限）。如果一个集合不可能把每个成员都分配到各自的正整数，则称该集合不可数（或不可数无限）。

要理解“分配到一个正整数”的含义，可以想象有一排无限多的箱子，分别标记为 1、2、3，依此类推。取一个集合，开始将集合中的成员放入箱子，每个箱子最多放一个成员。如果我们能找到一种方法将集合的所有成员都分配到箱子，那么这个集合就是可数的。例如，考虑正整数偶数集 2、4，等等。我们可以将整数 i 分配到箱子 i/2（或者，如果我们不介意跳过一些箱子，则可以将偶数 i 分配到箱子 i）。因此，偶数集合是可数的。这并不意外，因为直观上正偶数比正整数“更少”，尽管两者都是无限集合。但正整数实际上并不比正偶数多，因为我们可以通过将正整数 i 分配给正偶数 2i 来把每个正整数唯一地分配给某个正偶数。

另一方面，全体整数集也是可数的，尽管这个集合看起来比正整数集“更大”。这是真的，因为我们可以将 0 分配给正整数 1，将 1 分配给正整数 2，将 -1 分配给正整数 3，将 2 分配给正整数 4，将 -2 分配给正整数 5，依此类推。一般地，将正整数 i 分配给正整数 2i，将负整数 −i 分配给正整数 2i + 1。我们永远不会用完可分配的正整数，并且我们确切知道每个整数被分配到了哪个正整数。因为每个整数都得到了分配，所以整数集是可数无限的。

程序的数量是可数还是不可数？一个程序可以看作一个字符串（包括特殊标点、空格和换行符）。让我们假设程序中可以出现的不同字符数为 P。（使用 ASCII 字符集时，P 必须小于 128，但实际数字无关紧要）。如果字符串的数量是可数的，那么程序的数量肯定也是可数的。我们可以按如下方式将字符串分配到箱子。将空字符串分配给第一个箱子。然后，取所有单字符串，按“字母”或 ASCII 码顺序将它们分配到接下来的 P 个箱子。接下来，取所有双字符串，按从左到右的 ASCII 码顺序将它们分配到接下来的 P² 个箱子。三字符串同样被分配到箱子中，然后是长度为四的字符串，依此类推。以这种方式，任何给定长度的字符串都可以被分配到某个箱子。

通过这个过程，任何有限长度的字符串都会被分配到某个箱子。因此任何程序，作为有限长度的字符串，都会被分配到某个箱子。因为所有程序都被分配到了某个箱子，所以所有程序的集合是可数的。自然，箱子中的大多数字符串不是合法程序，但这并不重要。重要的是，那些确实对应程序的字符串也在箱子中。

现在我们考虑可能函数的数量。为了简单起见，假设所有函数都接受一个正整数作为输入，并产生一个正整数作为输出。我们将这样的函数称为整数函数。函数只是从输入值到输出值的映射。当然，并非所有计算机程序都字面意义上接受整数作为输入并产生整数作为输出。然而，计算机读写的一切本质上都是一系列数字，可以被解释为字母或其他东西。任何有用的计算机程序的输入和输出都可以编码为整数值，因此我们关于计算机输入/输出的简单模型足够通用，可以涵盖所有可能的计算机程序。

我们现在想看看是否有可能将所有整数函数分配到无限的箱子集合中。如果能，那么函数的数量是可数的，而且可能可以将每个整数函数分配给一个程序。如果整数函数集合不能被分配到箱子中，那么就必然存在没有对应程序的整数函数。

想象每个整数函数是一个有两列和无限多行的表格。第一列列出从 1 开始的正整数。第二列列出当第一列中的值作为输入时函数的输出。因此，该表明确描述了每个函数从输入到输出的映射。称之为函数表。

## 17.3.2 停机问题不可解

虽然知道存在某个无法由计算机程序计算的函数可能会有智力上的吸引力，但这是否意味着存在任何这样有用的函数呢？毕竟，如果没有任何程序能够计算一个如图 17.7 中箱子 4 所示那样的“无意义”函数，这真的重要吗？现在我们将证明停机问题无法由任何计算机程序计算。证明采用反证法。

我们首先假设存在一个名为 halt 的函数可以解决停机问题。显然，不可能写出一个不存在的东西，但这里是一个合理的草图，说明如果这样的函数存在，解决停机问题的函数可能是什么样子。函数 halt 接受两个输入：一个表示程序或函数源代码的字符串，以及另一个表示输入的字符串，我们要确定输入程序或函数在该输入上是否停机。函数 halt 做一些工作来做决定（该工作被封装在某个虚构的函数 PROGRAM_HALTS 中）。如果输入程序或函数确实在给定输入上停机，则 halt 返回 true，否则返回 false。

```
bool halt(string prog, string input) {
    if (PROGRAM_HALTS(prog, input))
        return true;
    else
        return false;
}
```

我们现在将考察两个显然可以存在的简单函数，因为这里给出了它们的完整代码：

```
// Return true if "prog" halts when given itself as input
bool selfhalt(char *prog) {
    if (halt(prog, prog))
        return true;
    else
        return false;
}
```

```
// Return the reverse of what selfhalt returns on "prog"
void contrary(char *prog) {
    if (selfhalt(prog))
        while (true); // Go into an infinite loop
}
```

如果我们使一个程序的唯一目的是执行函数 contrary，并用它自身作为输入运行这个程序，会发生什么？一种可能是对 selfhalt 的调用返回 true；也就是说，selfhalt 声称 contrary 在以自身为输入运行时将停机。在这种情况下，contrary 会进入一个无限循环（因此不会停机）。另一方面，如果 selfhalt 返回 false，那么 halt 就是在宣称 contrary 以自身为输入时不会停机，于是 contrary 就会返回，
