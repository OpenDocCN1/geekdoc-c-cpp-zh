

# 16.3 数值算法

- 长度为 k 或更小的实例有 2^k 个。
- 值 n 的大小（长度）为 log n。
- 特定算法的成本（长度）当 n 的值增大时可能会减小（例如从 2^k - 1 的值到 2^k 再到 2^k + 1），但通常当 n 的长度增大时会增大。

我们将通过考虑如何进行指数运算来开始对标准数值算法的考察。也就是说，我们如何计算 m^n？我们可以将 m 乘以 n - 1 次。能否做得更好？可以，有一种简单的分治方法可以使用。我们可以认识到，当 n 为偶数时，m^n = m^{n/2} m^{n/2}。如果 n 为奇数，则 m^n = m^{[n/2]} m^{[n/2]} m。这导致了以下递归算法

```
int Power(base, exp) {
  if exp == 0 return 1;
  int half = Power(base, exp/2); // integer division of exp
  half = half * half;
  if (odd(exp)) then half = half * base;
  return half;
}
```

函数 Power 的递推关系为
f(n) = { 0 n = 1
  f([n/2]) + 1 + n mod 2 n > 1
}
其解为 f(n) = |log n| + β(n) - 1
其中 β 是 n 的二进制表示中 1 的个数。

这种成本与问题规模相比如何？原始问题规模为 log m + log n，而所需的乘法次数为 log n。这比进行 n - 1 次乘法要好得多（事实上是指数级更好）。

我们接下来将介绍欧几里得算法，用于求两个整数的最大公因数（LCF）。LCF 是能整除两个输入的最大整数。

首先我们做出以下观察：如果 k 整除 n 和 m，则 k 整除 n - m。我们知道这是正确的，因为如果 k 整除 n 则 n = ak 对某个整数 a，而如果 k 整除 m 则 m = bk 对某个整数 b。因此，LCF(n, m) = LCF(n - m, n) = LCF(m, n - m) = LCF(m, n)。

现在，对于任意值 n 存在 k 和 l 使得
n = km + l 其中 m > l ≥ 0。

根据 mod 函数的定义，我们可以推导出
n = [n/m]m + n mod m。

由于 LCF 是 n 和 m 的因子，并且由于 n = km + l，LCF 必须是 km 和 l 的因子，也是这两个项的最大公因数。因此，LCF(n, m) = LCF(m, l) = LCF(m, n mod m)。

这一观察导致了一个简单的算法。我们假设 n ≥ m。在每次迭代中，我们用 m 替换 n，并用 n mod m 替换 m，直到 m 被驱动为零。

```
int LCF (int n, int m) {
if (m == 0) return n;
return LCF(m, n % m);
}
```

要确定该算法的开销，我们需要知道每次迭代中我们取得了多少进展。注意，经过两次迭代后，我们已将 n 替换为 n mod m。因此关键问题是：n mod m 相对于 n 有多大？

n ≥ m ⇒ n/m ≥ 1
⇒ 2[n/m] > n/m
⇒ m[n/m] > n/2
⇒ n - n/2 > n - m[n/m] = n mod m
⇒ n/2 > n mod m

因此，函数 LCF 将在不超过 2 次迭代内将其第一个参数减半。总成本为 O(log n)。

## 16.3.3 矩阵乘法

将两个 n × n 矩阵相乘的标准算法需要 Θ(n³) 时间。通过以各种方式重新排列和分组乘法，可以做得更好。其中一个例子被称为 Strassen 矩阵乘法算法。

为简单起见，我们假设 n 是 2 的幂。在下文中，A 和 B 是 n × n 数组，而 Aij 和 Bij 指的是大小为 n/2 × n/2 的数组。使用

这种记法，我们可以用分治的方式思考矩阵乘法如下：

[ A11 A12 ; A21 A22 ] [ B11 B12 ; B21 B22 ] = [ A11B11 + A12B21 , A11B12 + A12B22 ; A21B11 + A22B21 , A21B12 + A22B22 ] .

当然，右边等式中的每个乘法和加法都是对半大小数组的递归调用，以及对半大小数组的加法，分别。 该算法的递推关系为

T(n) = 8T(n/2) + 4(n/2)^2 = Θ(n^3)。

该闭式解可以通过应用主定理 14.1 轻松获得。

Strassen 算法仔细重新排列了各种项相乘和相加的方式。它以特定顺序执行，如以下等式所表达：

[ A11 A12 ; A21 A22 ] [ B11 B12 ; B21 B22 ] = [ s1 + s2 - s4 + s6 , s4 + s5 ; s6 + s7 , s2 - s3 + s5 - s7 ] .

换句话说，n × n 数组的乘法结果是通过对 n/2 × n/2 数组进行不同系列的矩阵乘法和加法获得的。子数组之间的乘法也使用 Strassen 算法，而两个子数组的加法需要 Θ(n²) 时间。子因子定义如下：

- s₁ = (A₁₂ − A₂₂) · (B₂₁ + B₂₂)
- s₂ = (A₁₁ + A₂₂) · (B₁₁ + B₂₂)
- s₃ = (A₁₁ − A₂₁) · (B₁₁ + B₁₂)
- s₄ = (A₁₁ + A₁₂) · B₂₂
- s₅ = A₁₁ · (B₁₂ − B₂₂)
- s₆ = A₂₂ · (B₂₁ − B₁₁)
- s₇ = (A₂₁ + A₂₂) · B₁₁

经过一点努力，你应该能够验证这种奇特的操作组合确实会产生正确答案！

现在，查看计算 s 因子的操作列表，然后计算将它们组合起来得到最终答案所需的加法/减法，我们看到我们需要总共七次（数组）乘法和 18 次（数组）加法/减法来完成工作。这导致递推

T(n) = 7T(n/2) + 18(n/2)^2

T(n) = Θ(n^{log₂ 7}) = Θ(n^{2.81})。

因此，如果取对数和反对数是廉价的，那么我们可以通过取两个操作数的对数，相加，然后取和的反对数，将乘法简化为加法。

在正常情况下，取对数和反对数是昂贵的，因此这种简化不会被认为切实可行。然而，这种简化正是计算尺的基础。计算尺使用对数刻度来测量两个数字的长度，实际上自动完成了对数转换。这两个长度然后相加，反对数从另一个对数刻度读出。通常认为昂贵的部分（取对数和反对数）是廉价的，因为它是计算尺的物理部分。因此，整个乘法过程可以通过简化为加法而廉价地完成。在电子计算器出现之前，科学家和工程师经常使用计算尺来进行这种基本计算。

现在考虑乘以多项式的问题。n 个值的向量 a 可以唯一表示一个次数为 n − 1 的多项式，表示为

```
P_a(x) = sum_{i=0}^{n-1} a_i x^i
```

或者，多项式可以由其在 n 个不同点的值的列表唯一表示。求多项式在给定点的值称为求值。给定 n 个点的值求多项式的系数称为插值。

通常将两个 n − 1 次多项式 A 和 B 相乘需要 Θ(n²) 次系数乘法。然而，如果我们对两个多项式求值（在相同的点），我们可以简单地将对应值对相乘以得到多项式 AB 的对应值。

### 示例 16.5 多项式 A: x² + 1。

- 多项式 B: 2x² − x + 1。
- 多项式 AB: 2x⁴ − x³ + 3x² − x + 1。
- 当我们在点 0、1 和 -1 处乘以 A 和 B 的求值时，我们得到以下结果。

```
AB(-1) = (2)(4) = 8
AB(0) = (1)(1) = 1
AB(1) = (2)(2) = 4
```

这些结果与我们在这些点上对多项式 AB 求值时得到的结果相同。
