A d-dimensional classic cellular automaton could be defined as a quadri-tuple:

$$\Lambda=(Z^d,S,N,\delta) \tag{3}$$

- $Z^d$ stands for a $d$-dimensional discrete lattice space. It is the space structure of $d$-dimensional classic cellular automata.
- $S$ is the finite states set of cells.
- $N=\{n_j=(x_{1j},\ldots,x_{dj}),\ j\in\{1,\ldots,n\}\}$ is the finite ordered subset of $Z^d$. $N$ is called the neighbourhood of cellular automata.
- $\delta:S^{n+1}\to S$ is the local state transition function of $\Lambda$.

We can find from this definition that the essential feature of cellular automata is its discrete space-time and local interaction. If we want to apply it to social system modeling, we must extend its definition in four aspects.

The cellular automata focus on how individuals' adaptive behaviours result in complexity of the system. But when we build some models for real world, there is public information which can influence individuals' behaviours as well as interaction within them. If we adopted public information into cellular automata, it would become an open system.

Traditionally, cells in the cellular automata are homogeneous. That means all cells in a cellular automata have the same state transition function. But sometimes, we need to include individuals who would respond to the information in various ways. The problem of heterogeneous cells is that cells must interact with neighbours who may have different state transition functions. So we must guarantee the $S$ in the quadri-tuple can be accepted by all cells' state transition functions, even though they may have different logic.

The neighbourhood of cellular automata represents the interaction scope of a cell. The space of a social system is not like that of a physical system. The relationships among social members are some kind of network. So $d$-dimensional discrete lattice space must be replaced by network space. In fact, network is a universal description for discrete space. The $d$-dimensional discrete lattice space is just an example of it.

In classic cellular automata, the neighbourhood is fixed. In social system, however, the relationship between two members is not so stable. The adaptive behaviours of individuals are even the cause of the formation of the system's inner structure. Margolus designed odd-even neighbourhood for odd-even steps, then realized the change of neighbourhood. In the cellular automata based 2-dimensional fluid model, HPP Lattice Gas Automata (Hardy et al., 1973), the Margolus neighbourhood is adopted. The successor of the HPP model, FHP Lattice Gas Automata (Frisch et al., 1986), changed the lattice into a hexagonal one. The neighbourhood of the FHP model is alterable too. Network dynamics plays an increasingly important role in social networks modeling. We could add network dynamics as the neighbourhood transformation rule into the definition of cellular automata.

Considering the four extensions, we can get a new definition for cellular automata:

$$\Lambda=(Z,S,N,P,\delta,\sigma) \tag{4}$$

Because the public information and neighbourhood transformation function are supported in the cellular automata, the new definition becomes a six-tuple. In the new definition, $Z$ is used instead of the original $Z^d$, which means the space of cellular automata doesn't have to be Euclidean space. It could be a network or graph structure. Accordingly the $N$ in the cellular automata may follow the graph's neighbourhood definition. Furthermore, the $N$ doesn't have to be stable. $\sigma: N \to N$ is the neighbourhood transformation function, which can change the neighbourhood in every evolution step of the cellular automata. $P$ stands for the public information. Accordingly the state transition function becomes $\delta: P,S^{n+1}\to S$.

Although we extended the definition from classic cellular automata, we still kept its essential features. The new kinds of cellular automata are still time-space discrete systems. Each cell decides its state in the next step according to the states of neighbours and itself in the current step. The macrodynamics of cellular automata is the emergence of masses of cells' adaptive behaviours. The classic cellular automaton could be regarded as an instance of the new definition. Because the cells could be heterogeneous, a cellular automaton under the new definition could also be a multi-agent system.

The new definition of cellular automata gives us a foundation to define a cellular automata based artificial financial market. Because there could be many artificial financial markets under different assumptions, we just define the general part of them. In a cellular automata based artificial financial market, each cell represents an investor. $Z$ in the formula (4) is the set of cells. In the cellular automata based artificial financial market, the finite state set $S$ is a 6-tuple:

$$S = (C_u, C_f, S_u, S_f, Q, E) \tag{5}$$

- $C_u$ and $C_f$ stand for usable and frozen cash respectively.
- $S_u$ and $S_f$ are usable and frozen stock respectively.
- $Q$ is the set of orders which have been quoted to the exchange house but have not been completed or canceled yet. Each order includes direction (ask or bid), price and amount.
- $E$, which takes the values rise, fall, or keeping, is the price prediction of an investor.
- $C_p$ is the total property of an investor.

Given $P$ as current stock price, $C_p$ can be expressed as follows:

$$C_p = C_u + C_f + P(S_u + S_f) \tag{6}$$

Maximization of $C_p$ is the only goal for all investors.

$N$ is the neighbourhood in cellular automata. In this AFM, $N$ is a directed graph. When $Cell_i$ is making a prediction, a directed edge <i, j> between $Cell_i$ and $Cell_j$ exists only if the $S_E$ value of $Cell_j$ can affect the $S_E$ value of $Cell_i$. In this condition, $Cell_j$ is defined as a neighbour of $Cell_i$. The neighbour relationship between these two cells is not necessarily reciprocal.

In the cellular automata based artificial financial market, public information includes trading data, public financial policy, such as risk-free rate, and company news, such as financial reports and bonuses. As in the definition of cellular automata, public information is represented by $P$. The state transition function decides a cell's state according to the public information and the states of the cell itself and the neighbours. So it is defined as:

$$\delta: P, S^{n+1} \to S \tag{7}$$

The neighbourhood transition function is:

$$\sigma: N \to N \tag{8}$$

$\sigma$ is the variance of the dependency relationship between cells. Based on different assumptions, methods to rebuild the dependency networks can be different. $\sigma$ would be performed after each trading day.

Once we gave the extended definition of cellular automata a specific meaning, we defined a cellular automata based artificial financial market. We try our best to abstract the essence of the capital market. We emphasize the heterogeneous individual behaviours, as well as the complex information spread in the market. We believe the information is the decisive factor for a predictive system. The Emergence-Artificial Financial Market Framework, which would be introduced later, is a realization of the cellular automata based artificial financial market.

## 5. The Emergence-Artificial Financial Market Framework

Now we can build artificial financial market models under the above definition. As we know, the target of an artificial financial market is to find out the relationship between macrodynamics and microstructure of the capital market, and verify the financial theories which are based on different assumptions. These assumptions are focused on the investors' behaviours and the spread of information. Other components of the capital market are stable and clear. So, we built a framework, realized the common parts of the capital market in it, and defined the interfaces of the heterogeneous investors and information. Because the complex macrodynamics could be regarded as the emergence of the adaptive behaviours of individuals, we named the framework "The Emergence-Artificial Financial Market Framework (E-AFM)".

### 5.1 The structure of E-AFM

As we defined in Section 4, an E-AFM is a cellular automata based artificial market, so, first, we realized a cellular automata library under the extended definition. Then we realized E-AFM as a template instantiation of the cellular automata library. All these frameworks are realized in C++ language, in order to utilize its generic programming model and parallel technology.

The basic starting point of the cellular automata library is abstraction of the data types of the cell state (personal information) and public information. That is why we use the parameterized type feature of C++ templates. The base classes of cell, cell container, and neighbourhood are provided in the library. The base classes of cell and cell container are both template classes. The template parameters are the abstract data types of cell state and public information. The template parameter StateType is the data type of the cell states. Users can define it according to their needs. In the CellBase<StateType> class, the state transition function is declared as a pure virtual function. Any class that is derived from CellBase<StateType> should override the state transition function according to its own rule. Two derived classes of CellBase<StateType> are provided in this library, one is for synchronous cellular automata, and another is for asynchronous cellular automata. When we realize a cellular automaton, we just need to define the data type of personal and public information, design a class derived from class SyncCellBase<StateType> or class AsynchCellBase<StateType>, and provide the relevant state transition function.

In the cellular automata library, all cells are managed by cell container classes. The design targets of the cell container include the following aspects. Firstly, the cell container should provide one or more kinds of traversal methods to access all cells in the cellular automaton. Secondly, random access to cells should be supported, because we can't assume the structure of users' cellular automata, and we need to access a cell through its neighbours. Thirdly, the neighbourhood of the cellular automata should have an internal representation in the container. That means, when we access a cell, we should be able to get the cell's neighbours.
