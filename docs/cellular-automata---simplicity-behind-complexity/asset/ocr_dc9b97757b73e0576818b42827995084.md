For quantitative computation of the critical temperature of a two-layer 3-state Potts model, we considered the isotropic ferromagnetic case which $K_x = K_y = K_c \geq 0$. We have used a two-layer square lattice that each layer has 1500 × 1500 sites and to reduce the finite size effects the periodic boundary condition is used. Each site can have a value of +1, -1 or zero. We used the Glauber method with checkerboard approach to update the sites. Namely, each layer is like a checkered surfaces and at first, the updating is done for the white parts of the first layer. Then the black ones are updated.
