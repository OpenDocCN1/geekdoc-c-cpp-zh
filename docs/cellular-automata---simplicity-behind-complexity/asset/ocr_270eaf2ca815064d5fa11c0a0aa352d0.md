$$p_{i+u_1,j+v_1}, \ldots, p_{i+u_n,j+v_n}.$$

This embedding has the consequence of characterizing the transformation function of the cellular automata as a boolean function of $n$-variables

$$p^{t+1}_{(i,j)} = f(p^t_{(i,j)+N})$$

where the superscript $t$ and $t + 1$ denote the discrete time. An array

$$(r_{(i,j)})_{(i,j)\in\mathbb{Z}^2}$$

(we shall skip the indices and write simply $r$) of 0 and 1 describes the configurations obtained by $G_A$ from an array

$$(p_{(i,j)})_{(i,j)\in\mathbb{Z}^2}$$

if and only if conditions

$$r_{(i,j)} = f(p_{(i,j)+N}),$$

for all $(i,j)$ are satisfied.

Denote the infinite set of all these conditions $T_A(\bar{p}, \bar{r})$.

Then the next step is to define $f$ by a CNF (or DNF) formula. In this manner we can think of $T_A(\bar{p}, \bar{r})$ as of a propositional theory consisting of clauses.

A basic observation is that the injectivity of $G_A$ is equivalent to the fact that the theory

$$T(\bar{p}, \bar{q}) \cup T(\bar{q}, \bar{r})$$

(where $\bar{p}$, $\bar{q}$ and $\bar{r}$ are disjoints arrays of variables) logically implies all equivalences of the form:

$$p_{(i,j)} \equiv q_{(i,j)}$$

for all $(i,j) \in \mathbb{Z}^2$. Since the theory is unaltered if we replace all indices $(i,j)$, by $(i,j) + (i_0,j_0)$, (any fixed $(i_0,j_0) \in \mathbb{Z}^2$) this is equivalent to the fact that

$$T(\bar{p}, \bar{q}) \cup T(\bar{q}, \bar{r})$$

implies that

$$p_{(0,0)} \equiv q_{(0,0)}.$$

This can be reformulated in the following manner:

$$T(\bar{p}, \bar{r}) \cup \{p_{(0,0)}\} \cup T(\bar{q}, \bar{r}) \cup \{\neg q_{(0,0)}\}$$

is unsatisfiable.
