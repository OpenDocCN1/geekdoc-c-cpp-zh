教育部在2024年发布通知，部署开展第三批全国高校招生大模型录取通知书工作。通知要求各高校要主动作为，将AI大模型技术应用于录取通知书的设计与生成中，创新录取通知书的内容与形式，增强新生的归属感和荣誉感。同时，通知还要求各高校加强录取通知书工作的组织管理，确保录取通知书工作有序开展。
