# Writing to Files

Similarly, C# provides various methods for writing data to files:

+   1. StreamWriter : The StreamWriter class allows you to write text to files sequentially.

```
using (StreamWriter writer = new StreamWriter("myfile.txt"))
{
    writer.WriteLine("Hello, world!");
    writer.WriteLine("This is some text.");
}
```

+   2. File.WriteAllText() and File.WriteAllLines(): These static methods offer a concise way to write a string or an array of strings to a text file, overwriting any existing content.

```
File.WriteAllText("myfile.txt", "New content");
File.WriteAllLines("myfile.txt", new string[] { "Line 1", "Line 2" });
```
