# **Variable Naming Conventions**

In C#, variable names must adhere to certain conventions:

+   - They must start with a letter or an underscore ( _ ).
+   - They can contain letters, numbers, and underscores.
+   - They are case-sensitive, meaning age and Age are considered different variables.
+   - It's recommended to use descriptive names that reflect the purpose of the variable, making your code more readable and maintainable.
