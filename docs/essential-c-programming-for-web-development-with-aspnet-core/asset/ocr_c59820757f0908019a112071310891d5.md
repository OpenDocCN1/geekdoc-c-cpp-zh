EF Core provides basic querying capabilities that can be used for simple keyword searches. Let's see an example:

```
C#
public IActionResult Search(string query)
{
    var searchResults = _context.Posts
        .Where(p => p.Title.Contains(query) || p.Content.Contains(query))
        .ToList();

    return View(searchResults);
}
```

In this action method, we use the Where clause to filter posts based on whether their title or content contains the search query. However, this approach has limitations in terms of relevance ranking and performance, especially for large datasets.
