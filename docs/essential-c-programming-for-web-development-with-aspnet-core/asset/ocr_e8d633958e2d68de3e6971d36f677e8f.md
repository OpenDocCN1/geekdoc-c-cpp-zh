# 1. for Loop

The for loop is ideal when you know the number of iterations in advance. It consists of three parts: initialization, condition, and iteration.

C#

```
```csharp
for (int i = 0; i < 5; i++)
{
    Console.WriteLine("Iteration: " + i);
}
```
```

This loop will execute five times, printing the iteration number in each cycle.

# 2. while Loop

The while loop continues to execute as long as a specified condition remains true.

C#

```
```csharp
int count = 0;
while (count < 10)
{
    Console.WriteLine("Count: " + count);
    count++;
}
```
```

This loop will increment the count variable and print its value until it reaches 10.
