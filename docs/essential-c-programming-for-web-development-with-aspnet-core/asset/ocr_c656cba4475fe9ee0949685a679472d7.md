# Rendering Data in Views

Once you have retrieved data from the database, you can use Razor syntax in your views to dynamically render it to the user. Let's create a view to display the list of products:

```
Razor CSHTML
@model IEnumerable<Product>
<h2>Products</h2>
<ul>
@foreach (var product in Model)
{
<li>@product.Name - $@product.Price</li>
}
</ul>
```

This view iterates over the Model (the collection of products passed from the controller) and renders each product's name and price within a list item.
