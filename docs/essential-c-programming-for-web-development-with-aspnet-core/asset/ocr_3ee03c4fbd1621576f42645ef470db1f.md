Data types play a crucial role in programming by defining the kind of values a variable can store. C# offers a rich set of built-in data types, each designed for specific purposes. Let's explore some of the most common ones:

# 1. Numeric Data Types

+   - int (Integer): Represents whole numbers without decimals (e.g., -2, 0, 100).
+   - double (Double-precision floating-point number): Represents numbers with decimals (e.g., 3.14, -1.5).
+   - float (Single-precision floating-point number): Similar to double, but with less precision.
+   - decimal (Decimal floating-point number): Provides high precision for financial calculations.

# 2. Textual Data Types

+   - char (Character): Represents a single Unicode character (e.g., 'A', '!', '?').
+   - string (String): Represents a sequence of characters (e.g., "Hello, world!").

# 3. Boolean Data Type

+   - bool (Boolean): Represents a logical value, either true or false.

# 4. Other Data Types

+   - DateTime : Represents a specific date and time.
+   - object : The base class for all other types in C#.
