# More About Calling Interface Methods

The FCL's **System.String** type inherits **System.Object**'s method signatures and their implementations. In addition, the **String** type also implements several interfaces: **IComparable**, **ICloneable**, **IConvertible**, **IEnumerable**, **IComparable<String>**, **IEnumerable<Char>**, and **IEquatable<String>**. This means that the **String** type is not required to implement (or override) the methods its **Object** base type offers. However, the **String** type must implement the methods declared in all of the interfaces.

The CLR allows you to define field, parameter, or local variables that are of an interface type. Using a variable of an interface type allows you to call methods defined by that interface.
