# 23.1. USING FILE DESCRIPTORS WITH FSTREAMBUF CLASSES

Although setField could be used to configure Fistream to use or not to use fixed-sized field extraction, using manipulators is probably preferable. To allow field objects to be used as manipulators an overloaded extraction operator was defined. This extraction operator accepts istream & and a field const & object. Using this extraction operator, statements like

```
```cpp
fis >> field(2) >> x >> field(0);
```
```

are possible (assuming fis is a Fistream object). Here is the overloaded operator>>, as well as its declaration:

```
```cpp
istream &std::operator>>(istream &str, field const &params)
{
    return reinterpret_cast<Fistream *>(&str)->setField(params);
}
```
```

Declaration:

```
```cpp
namespace std
{
    istream &operator>>(istream &str, FBB::field const &params);
}
```
```

Finally, an example. The following program uses a Fistream object to url-decode url-encoded information appearing at its standard input:

```
```cpp
int main()
{
    Fistream fis(cin);

    fis >> hex;
    while (true)
    {
        size_t x;
        switch (x = fis.get())
        {
            case '\n':
                cout << '\n';
                break;
            case '+':
                cout << ' ';
                break;
            case '%':
                fis >> field(2) >> x >> field(0);
                // FALLING THROUGH
            default:
                cout << static_cast<char>(x);
                break;
            case EOF:
                return 0;
        }
    }
}
/*
    Generated output after:
        echo My+name+is+%60Ed%27 | a.out

    My name is ‘Ed’
*/
