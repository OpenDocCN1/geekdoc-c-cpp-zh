
Open HBAppDelegate.m. At the top of the file, we need to import our WeightEntry class. We also want to define a key to use with iCloud key-value storage.

```objc
#import "WeightEntry.h"
static NSString* const UbiquitousWeightUnitDefaultKey =
@"UbiquitousWeightUnitDefaultKey";
```

Next, let’s modify application:didFinishLaunchingWithOptions: to register for our notifications. Let’s examine this one chunk at a time.

```objc
- (BOOL)application:(UIApplication *)application
didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {

    // Since the delegate lasts throughout the life of the app,
    // we don't need to unregister these notifications.
    NSUbiquitousKeyValueStore* store =
    [NSUbiquitousKeyValueStore defaultStore];
    NSNotificationCenter* notificationCenter =
    [NSNotificationCenter defaultCenter];
```

So far, we’re just getting reference to the default notification center and the default iCloud key-value store.

```objc
[notificationCenter
    addObserverForName:
    NSUbiquitousKeyValueStoreDidChangeExternallyNotification
    object:store
    queue:nil
    usingBlock:^(NSNotification *note) {
        WeightUnit value =
        (WeightUnit)[store longLongForKey:
            UbiquitousWeightUnitDefaultKey];
        setDefaultUnits(value);
    }];
```

Next, we register for notifications from the iCloud key-value store. When we receive a notification, we grab the value for our key and use it to update our user defaults.

Notice that NSUbiquitousKeyValueStore looks similar to NSUserDefaults, but it does not support the same range of data types. Specifically, the only integer type it supports is the long long. That's a bit of overkill when it comes to storing our WeightUnit values—but it's the only option available. Also, we have to explicitly cast the long long back to our WeightUnit type. This lets the compiler know that we (hopefully) know what we're doing and keeps it from complaining about possible data loss.

```objc
[notificationCenter
 addObserverForName:NSUserDefaultsDidChangeNotification
 object:[NSUserDefaults standardUserDefaults]
 queue:nil
 usingBlock:^(NSNotification *note) {
     int value = getDefaultUnits();
     NSLog(@"Setting iCloud Value: %@",
           [WeightEntry stringForUnit:value]);
     [store setLongLong:value forKey:
           UbiquitousWeightUnitDefaultKey];
 }];
[store synchronize];
return YES;
}
```

Now, we register for notifications about changes to our NSUserDefaults. When a change occurs, we get the current default value and use it to update the value in the cloud.

Finally, once both notifications are set up, we synchronize our cloud storage. This forces the system to post notifications about any changes that might have occurred while the application was turned off. We don't have to synchronize NSUserDefaults, since it already automatically posts those notifications.

## Virtual Reality and Augmented Reality

### 1.1 Introduction

In recent years, virtual reality (VR) and augmented reality (AR) have become one of the most compelling technologies of the modern era, fundamentally changing the way we interact with digital content. VR creates a fully immersive digital environment that is completely isolated from the physical world, typically achieved by using head-mounted displays and motion tracking. Conversely, AR overlays digital information onto the real world, enhancing the user's perception of reality through devices such as smartphones, tablets, or smart glasses.

- Meaning: VR emphasizes full immersion and isolation from reality; AR emphasizes the blend of real and virtual.
- Device: VR commonly uses head-mounted displays; AR relies on transparent/see-through optical devices.
- Interaction: VR mainly uses controllers and spatial tracking; AR often uses gestures, voice, and eye tracking.
- Applications: VR is widely used in gaming, simulation, and training; AR is common in navigation, maintenance, and education.

### 1.2 Development History

The development of VR/AR has experienced several stages from early attempts to the present day. In the 1960s, the first head-mounted display system was created, laying the foundation for modern equipment. The 1980s and 1990s saw significant improvement in graphics and hardware, but it was the 2010s that truly became a turning point, with the rise of consumer-grade devices such as Oculus Rift and Microsoft HoloLens. Since then, the technology has rapidly evolved and integrated into various industries.

| Era | Development |
| --- | --- |
| 1960s | First HMD concept and prototype |
| 1980s | Military and expensive industrial systems |
| 1990s | Early consumer attempts with low interactivity |
| 2010s | Consumer-grade devices like Oculus Rift and HoloLens |
| 2020s | Ultra-lightweight full-color AR glasses and VR 2.0 |
