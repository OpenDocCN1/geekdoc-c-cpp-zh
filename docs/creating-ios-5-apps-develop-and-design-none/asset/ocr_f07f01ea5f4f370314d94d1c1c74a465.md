Finally, we check and respond to the gesture recognizer's state. Since this is
a continuous recognizer, we're really only worried about the ...Began, ...Changed,
and ...Ended states. We're already recalculating the acceleration values for each update.
So, all we really need to do here is display our acceleration view in the ...Began state,
and hide it in the ...Ended state. We don't pause the canvas, since the user might
want to see how the cursor's behavior changes as they adjust the cursor acceleration.
