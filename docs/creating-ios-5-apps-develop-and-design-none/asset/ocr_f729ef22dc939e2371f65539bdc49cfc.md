Now, let's implement the processWeightEntryUsingBlock: method.

```
```objective-c
- (void)processWeightEntryUsingBlock:
(void (^)(WeightEntry*)) block {
    for (WeightEntry* entry in self.entries) {
        block(entry);
    }
}
```
```

As you can see, we iterate over the array, passing each WeightEntry object to the provided block. This is a convenient technique for exposing some access to an internal collection. Anyone using our class can iterate over the entire array—but they are never given access to the array itself.
