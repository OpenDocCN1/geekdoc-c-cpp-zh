## 不断扩张的视频游戏行业

视频游戏行业的增长速度比以往任何时候都快。越来越多的美国人通过强大的手机和平板电脑将计算能力带在口袋里。有些人访问互联网玩游戏的频率甚至和收发邮件一样频繁。由于所有这些在线活动，游戏行业正以指数级增长。正如员工 Dylan Lewis 在财经话题网站 Motley Fool 上所述：“全球移动游戏市场是一个价值200亿美元的高端市场。我看到过预测，到2018年该市场将达到450亿美元。”随着对游戏需求的持续增长，这意味着游戏行业中开发人员、设计师、动画师、程序员以及许多其他人的职位也将随之扩大。

现代视频游戏不再仅仅是青少年在卧室或家庭地下室玩游戏的领地，它们的触角已经扩大。2016年《计算机和视频游戏行业基本事实》报告指出，“视频游戏玩家平均年龄为35岁，玩视频游戏已有13年。”视频游戏也吸引了年长的玩家。根据2016年6月娱乐软件协会的一项研究，“50岁以上的玩家中，四之三每周玩游戏，十分之四每天玩。在60岁及以上的玩家中，有43%的人每天玩视频游戏。”

最近发布的《Pokémon Go》让玩家走出家门与周围的世界互动（根据2016年7月13日Recode网站上的一篇文章，每天有950万用户）。这种结合了虚拟与现实世界的游戏被称为“增强现实”，它要求用户物理上走到城市中的各个地标以推进游戏，这使得运动不仅是参与的核心要素，也是在游戏中成功的要素。我们文化的游戏化正在不断加剧，昨天的极客正成为今天的领导者。

## 变化对工作者有利

尽管游戏行业自创立以来一直由男性主导，但情况正在发生变化。女性开始加入游戏行业专业人士的行列，未来可能成为该行业的重要力量。在2016年5月接受CBS新闻采访时，来自费城的摩尔艺术与设计学院的游戏艺术教授 Stephen Wood评论道：“在未来10年，将出现女性进入该行业的巨大热潮。在80年代和90年代，视频游戏被认为是男孩玩的东西。但在90年代和21世纪初，女孩们说：‘我们也要玩。’现在，女孩们正在上大学学习视频游戏。我们正在帮助缩小性别差距并成为解决方案的一部分。”

尽管如此——也许是因为 Gamergate 事件（2014年发生的丑闻，像Zoë Quinn和Brianna Wu这样的女性游戏开发者遭到了特定的网络骚扰），年轻女性渴望加入视频游戏行业，教育系统也渴望满足它们的兴趣。随着越来越多的女性加入程序员和开发者的行列，行业正变得更加包容，设计领域的女性开始与它们的男性同胞获得同样的成功。

尽管劳工统计局没有专门追踪视频游戏行业的工作，但显然，科技世界的这个角落正在蓬勃发展。全球约有26亿玩家在惊人的平台上玩游戏，视频游戏行业正爆发式增长。这对于求职者是一个好消息。

## 游戏开发者

### 游戏开发者做什么的？

游戏开发者（或游戏设计师）身兼数职。他们工作的大部分是建立游戏的剧情并开发角色。不同类型的游戏必然会有不同的剧情和角色。例如，第一人称射击游戏通常遵循军事或末日后的故事情节，需要通过身体战斗来推进，而任务类游戏通常涉及解决谜题来推进游戏。游戏角色的类型通常决定了会出现哪些种类，为玩家提供具有不同性格和各种特征的形象，帮助他们在游戏中成功。游戏开发者负责为玩家设计不同类型的任务，创建玩家要完成的关卡，为角色编写他们遵循的剧情以及角色在游戏中说的台词，甚至还要创建游戏机制以使其按计划运行。最终，开发者负责设计从角色、谜题到艺术和动画的一切内容。根据 Eurocom 对 Chunk 公司游戏设计师 Pete Low 的采访，

### 概览：游戏开发者

| 类别 | 详情 |
| :--- | :--- |
| 最低教育要求 | 学士或副专学位 |
| 个人特质 | 创造能力和叙故事能力；解决问题的能力；团队合作精神；强大的沟通能力 |
| 工作条件 | 室内 |
| 薪资范围 | 约 $58,253 至 $100,690 |
| 职位数量 | 截至 2014 年约 110 万个 |
| 未来职业前景 | 到 2024 年增长率达到 14% 或更高 |

游戏开发者（或设计师）创造一个故事及其角色。开发者还监督游戏所有组件——包括剧情、角色、规则、环境和游戏体验——如何结合在一起。

游戏设计是设计游戏内容和规则的过程；包括游戏玩法、环境、故事情节和角色。游戏设计师可能会根据项目的规模和复杂性专门负责某一个类别（关卡设计、写作、难度平衡）或所有领域。制作视频游戏涉及许多组件：艺术、动画、音频和用户界面设计。这还可能包括剧本编写、在产品内部创建经济系统、各种潜在的社交组件等。我的工作是看所有这些内容如何结合以实现游戏目标——然后能够向广泛的利益相关者传达这一愿景。

开发者可能还会参与软件编码、艺术指导或图形设计。他们甚至可能在将游戏发送给质量保证测试人员之前，参与游戏发布前的版本 Beta 测试。![](img/5ffb35298ffd34b0969fe596ba9f5b27_12_0.png) 根据他们工作工作室的规模，开发者工作的某些部分可能类似于电影行业中的制片人角色，例如保持项目在正轨上运行并准时向消费者交付完成的游戏。

不同类型的游戏开发者将负责游戏玩法的不同方面。游戏机制设计师确保游戏规则被正确定义，环境设计师则设计出可以进行游戏的许多不同场景（或环境）。首席设计师协调所有独立设计师，并帮助指导团队内部的沟通。作为领导，他们还必须负责对整个游戏做出重要决策。例如，Firemonkey Studios（EA Games 旗下）的首席设计师 Tom 在 EA Games 网站上指出，“作为首席设计师，我对项目的长期方向有很大的发言权。我还从事大量的导师工作，并帮助人们实现他们的职业目标。当我团队中的某位设计师想出了绝佳的主意、创作了一些很酷的内容或为一个问题想出了聪明的解决方案时，这总是让我感到兴奋。这让我感到自豪！[](img/5ffb35298ffd34b0969fe596ba9f5b27_13_0.png)

### 教育

寻找工作的学生应该考虑考虑计算机科学、游戏设计或证书，这对于游戏设计非常有帮助。根据 O*NET 的数据，62% 的游戏开发者拥有科学学位，19% 拥有副专学位，17% 没有学位。

### 实习

游戏开发者可能还会参与软件编码、艺术指导或图形设计。他们甚至可能在将游戏发送到质量保证测试人员之前，参与游戏发布前的版本 Beta 测试。![](img/5ffb35298ffd34b0969fe596ba9f5b27_12_0.png) 根据他们工作工作室的规模，开发者工作的某些部分可能类似于电影行业中的制片人角色，例如保持项目在正轨上运行并准时向消费者交付完成的游戏。

#### 技能与性格

解决问题的能力和耐心也是游戏开发者的核心特质。他们必须在创意财务方面保持灵活，为出现的问题提供解决方案并保持整个项目的进展。面对这些挑战时保持冷静至关重要。工作时间可能很长，会导致紧张，因此对同事保持耐心（特别是在面对截止日期时）非常重要。

### 实习

寻找工作的学生应该考虑考虑实习，这不仅可以提供宝贵的经验，还是进入游戏行业的敲门砖。Blizzard 提供了机会，且这些实习位于以下地点（德克萨斯州奥斯汀、加利福尼亚州欧尔文或加利福尼亚州旧金山）。PlayStation 也提供实习，且这些实习面向本科生和研究生。许多实习还提供津贴。

### 雇主

游戏开发者可能为顶级工作室工作，例如 Ubisoft、任天堂、索尼、EA Games 或暴雪。这些开发者负责大多数适用于主机和移动设备的视频游戏。此外还有许多自由职业游戏开发者；这些开发者是自雇的，经营自己的业务，或者在空闲时间开发游戏。Bianca Wu 和 Amanda Warner 是独立游戏开发者，也是 Giant Spacecat 的联合创始人。在公司网站上，他们指出他们创作的游戏让我们成为英雄，而不是配角。Bolt Creative 的唯一程序员 Dave Castlenuovo 是另一位自由职业者。正如 Castlenuovo 在接受 All Things GD 网站采访时所说，福利源于公司的独立地位：“我们决定保持小规模。对我来说，在家里工作让我最大的乐趣，能看到我的妻子。”

越来越多的知名开发者正从大公司转向

他们建立自己的工作室，这种趋势在未来似乎还会持续。Inkle studios 的艺术和代码总监 Joseph Humfrey 在《独立游戏评论员》的一篇文章中补充道：“Steam 和 App Store 这样的平台创造了一个繁荣的市场，而 Unity 这样的工具为不同背景和经验年限开发者提供了平等的竞争环境。你不再需要一个庞大的团队来制作一个在技术和视觉上令人印象深刻的游戏。”

### 工作条件

游戏开发人员通常在办公室或工作室环境中工作，与设计师和程序员并肩。开发者可能有自己的办公室或隔间，也可能是开放式平面布局，以便于小组协作。大多数开发者是全职工作，而且通常会有大量的加班记录。

独立游戏开发者还可能在休息日、午休或周末工作，以便与在世界其他城市的队友协作。正如 Game Bakers 的创意总监 Emeric Thoa 在《Indie Game Reviewer》网站上描述独立开发者的生活一样：“这就像在一个乐队里。你可以像艺术家和明星一样获得成功并受推崇，也可以从小场场接一个小场场，希望有一天能大红。。但无论哪种情况，这都是非常充实且疲惫的。”

### 收入

视频游戏开发人员的薪水取决于他们工作的公司类型以及他们在工作中积累的技能和经验。根据 O*NET Online（将视频游戏开发者归类为软件设计师），在光谱的一端是初级设计师，年薪约为 $63,970 到 $73,864。另一端是更高级的设计师，他们的年收入可以在 $98,260 到 $100,690 之间。根据求职网站 Indeed 在 2016 年 7 月获得的信息，典型的视频游戏设计师平均年薪 $58,253。

### 晋升机会

视频游戏开发者并不是入门级工作；因此，晋升到高级职位的空间有限。然而，开发者可以在工作中学习额外的技能，并随着技能增加和承担更大的责任获得加薪。或者他们也可以建立自己的公司，独立制作和发布自己的游戏。虽然这种选择风险最高，因为开发者必须能够独立完成一切（或雇佣员工帮助他们无法做的事情），但它包含了获得最大回报——特别是当开发者的游戏走红或在游戏社区中引起共鸣时。

#### 游戏开发者的未来前景如何？

游戏开发者的前景一片光明。根据 O*NET 的预测，到 2024 年增长率将达到 14% 或更高。这被认为远高于平均水平。O*NET 还预计同一时期（到 2024 年）将有238,000 个职位空缺，这意味着进入视频游戏行业底层并努力达到开发者水平是一个绝佳时机。消费者对新游戏有着永无止的渴望；因此，开发者将会有充足的工作要做。

## 游戏机制设计师 (Game Mechanics Designer)

### 游戏机制设计师做什么的？

游戏机制设计师也称为系统设计师，负责游戏内交互的规则和系统。这项工作让游戏玩成为可能。正如 Schell Games 创始人 Jesse Schell 在他的书《游戏设计艺术：透镜书》中所解释的：“这些是你们游戏的程序和规则。机制描述了你们游戏的目标、玩家可以和不能尝试实现目标的方式，以及他们尝试时发生了什么。”

### 概览：游戏机制设计师

| 类别 | 详情 |
| :--- | :--- |
| 最学历要求 | 学士或副学士学位 |
| 个人素质 | 创意和叙故事能力；解决问题的能力；团队合作精神；良好的文字沟通能力 |
| 工作条件 | 室内 |
| 薪资范围 | 约 $63,970 到 $100,690 |
| 职位数量 | 截至2014年约110万个 |
| 未来职业前景 | 到2024年增长率达到14%或更高 |

所有的游戏（而不仅仅是视频游戏）都是根据规则运行的。sharon Boller 在她的在线文章《学习设计系列，第3部分：游戏机制》中引用了《大富翁》的规则——“当玩家经过起点时，他们可以领取$200元”——这是一个显式规则（或机制）的例子。在视频游戏中，规则或机制被程序化到游戏中。Boller 举了一个例子：“当玩家对问题的回答不正确时，他们会立即获得关于正确答案是什么的反馈，然后获得重新尝试的机会。”

并不是所有的游戏机制设计师都做同样的事情。例如，那些从事战斗游戏的人被称为战斗设计师，他们的工作是为两个或多个角色战斗时发生的情况创建一个连贯的系统。游戏机制设计师还根据他们工作的类型持有不同的头衔，包括关卡设计师、成就设计师、世界构建者、任务或剧情设计师、经济设计师和谜题设计师。

游戏机制设计师的主要任务是为玩家创造引人入的体验。有时这些体验是简单而有趣的，但有时是极其困难或令人沮丧的。无论难度如何，目标都是确保玩家想要继续玩。更有难的游戏在过关时会提供更丰的回报，这就是鼓励用户继续玩的原因。设计师使用各种心理技术和游戏设计理论来鼓励玩家向前，，即使游戏变得艰难。不同的方法帮助设计师创作精良的游戏和玩家认为值得投入时间的独特体验。这可能包括“胡萝卜加大棒子”的方法，即对正确行为给予胡萝卜或有价值物品的奖励，对错误行为给予大棒子的惩罚或其他负面体验。游戏机制可以是复杂的，也可以是简单的，取决于游戏的类型，如果做得当，两种类型都可以创造出色的色的体验。在电脑和主机上运行的视频游戏通常比手机或平板电脑上的游戏使用更复杂的机制，因为它们更依赖于计算机的处理器速度。任何给游戏中也存在几种不同类型的机制。例如，GameDesigning.org 上的“游戏机制入门”解释道，俄罗斯方块（一种可以在多个平台玩的游戏）涉及四种不同的游戏机制：

- 1. 旋转系统：俄罗斯方块[拼图碎片]产生的位置、生成的状态、如何旋转以及它们的“墙踢”（wall kick，即当你尝试在边缘旋转时它们的位置）。
- 2. 随机生成器：俄罗斯方块类型生成的顺序/序列。
- 3. 评分系统：消除行获得的积分，包括背靠消除（back-to-back lines）、连击（combos）、T旋（T-spins）等。
- 4. 移动性：玩家操控俄罗斯方块的能力，包括旋转、下落等。

指南随后建议：“如果你是一个有抱负的游戏设计师，你能做的最佳练习之一就是选取任何游戏，并将其拆解为主要的游戏机制。”这种练习有助于想要成为设计师的人准确理解任何游戏的每一帧（tick）是如何运作的，以及他们如何开始组装自己的复杂或简单游戏。

### 教育



对于想要成为游戏机制设计师的人，理想的专业领域是计算机科学或视频游戏设计。大多数大学都设有计算机科学学位课程。根据《美国新闻与世界报道》，美国计算机科学排名前四的学校是卡内基·梅隆大学、马萨诸塞理工学院、斯坦福大学和加州大学伯克利分校，尽管在美国全美各地的其他大学也有类似的课程。这些四年制课程向学生介绍了游戏设计的核心概念，包括编程、故事情与角色开发、视觉与声音设计以及游戏引擎开发的课程。获得计算机科学学位让想要成为设计师的人接触有关各种操作系统、编程概念、输入/输出方法和算法的信息。

视频游戏设计专业的数量仍然较少，但最知名的位于艺术学院（Art Institute）、南加利福尼亚大学、卡内基·梅隆大学、犹他大学和罗彻斯特理工学院。犹他大学的计划项目与总部位于盐湖城的 EA Sports 保持着紧密的合作关系。罗彻斯特理工学院每年提供超过 150 门课程，并提供若干种不同类型的游戏设计和开发学位。对游戏机制有用的其他学习领域还有形式逻辑和数学；这些领域将帮助志向勃勃的设计师理解并提高他们的编程技能。在设计游戏机制和环境时，牢固掌握物理知识也很重要。根据 O*NET 的数据，约 62% 的游戏设计师拥有学士学位，19% 拥有专科学位，17% 上过大学但没有学位。

### 实习
想要成为游戏机制设计师的人绝对应该申请与其技能和抱负相匹配的视频游戏公司实习。实习不仅能提供宝贵的经验，还能作为进入这个极具竞争的游戏行业的敲场砖。这些机会中的大多数（如果不是全部）都是带薪实习，甚至包括住房津贴或安排，并涵盖参与者的差旅费用。暴风娱乐（Blizzard Entertainment）为大学生提供为期十二周的暑期实习，实习在公司的三个美国地点之一进行（德克萨斯州奥斯汀；加利福尼亚州尔湾；或加利福尼亚州旧金山）。PlayStation 也提供面向本科生和研究生的十二十二周暑期实习。

#### 技能与性格
游戏机制设计师是具有强大编码技能的计算机程序员，也是问题解决者。能够思考困难的问题并提出创新的解决方案是游戏机制设计师成功的关键。他们必须保持思维灵活，为出现的问题提供解决方案以保持项目进展。能够保持冷静应对这些挑战至关重要。工作时间通常很长，这可能会导致神经紧张，因此对团队成员保持耐心——尤其在截止日期面前——非常重要。

最成功的机制设计师能够在团队中良好工作。游戏设计需要许多不同的活动部分和专业能力，因此能够清晰地表达想法非常重要。机制设计师必须与同事设计师、程序员、艺术家、动画师、开发者等人合作来创作游戏，正如游戏设计师 Jake Fleming 在 2014 年 Treehouse 网站采访中解释的那样，能够理解团队中每个成员作为游戏设计师的出发点：

“当[团队对某个特定想法感到]不错时，我们开始使用基础彩色形状开发一个原型，展示给朋友、家人甚至陌生人看。在没有华华丽的艺术和音乐干扰用户判断的情况下，我们可以感知一下我们的核心游戏机制到底有多有趣。将游戏展示给每一个愿意听的人并根据反馈进行快速迭代，我们才知道知道何时想要将一个想法推向下一个水平。”

### 工作内容

### 雇主
游戏机制设计师可能为顶尖工作室工作，例如育碧（Ubisoft）、任天堂（Nintendo）、索尼（Sony）、EA Games 或暴风（Blizzard）。这些设计师负责大多数用于主机和移动设备上的视频游戏。此外，还有许多自由设计师，他们自雇职业，但将工作外包给不同的工作室。

### 工作条件
游戏机制设计师通常在办公室或工作室环境中工作，与其他设计师和程序员一起工作。设计师可能有自己的办公室或隔间，或者采用开放式平面设计以方便小组工作。大多数设计师是全职工作，而且通常会有大量的加班记录。

工作条件根据设计师的意愿和需求而大异。在 2015 年 7 月于 Medium.com 上的一次采访中，独立艺术家兼游戏设计师 Kara Stone 谈到了她的工作地及其对其工作的影响：“我主要在家里工作，周围环绕着植物，点香，花大量时间离开电脑躺在地上思考。不感到被迫坐在屏幕前，拥有我那希皮风格的环境让过程和结果变得更加宁静、个性化、深思熟虑。”简之，大多数设计师都希望并需要自己的特定时间和空间来解决他们正在制作的游戏机制以及相关的各种问题。幸运的是，大多数成功的视频游戏公司都允许他们拥有这些时间和空间。

### 收入
游戏机制设计师的薪水取决于他们工作的公司类型，以及他们在工作中积累的技能和经验。根据 O*NET 和劳工统计局的数据，在光谱的一端是初级设计师，他们的年收入约为 63,970 美到 73,864 美。另一端是更高级的设计师，他们的收入可以在 98,260 美到 100,690 美之间。根据招聘网站 Indeed 2016 年的信息，游戏设计师的平均收入为 87,000 美。

### 晋升机会
游戏机制设计师并不是入门级，因此晋升的空间很大。然而，机制设计师可以在工作中学习额外的技能，并通过承担更大的责任获得加薪。或者他们建立自己的公司，独立制作并发布游戏。虽然这种选择风险最大，因为设计师必须完成一切（或雇用员工协助），但也拥有最大的回报——如果设计师的游戏在社区中引起共鸣。

### 游戏设计师的未来如何？
游戏设计师的未来非常光明。根据 O*NET 的数据，预计到 2024 年增长率将 14%，这被认为远高于平均水平。期间预计将有 23.8 万职位空缺，这意味着现在是进入视频游戏行业并晋升到设计师水平的好时机。消费者对新游戏有着无止境的渴求，因此设计师将会有充足的工作可做。

## 程序员

### 程序员是做什么的？
视频游戏程序员在后台从事艰苦的工作：他们创建了所有让游戏顺利运行的代码。《游戏职业指南》网站这样描述视频游戏行业的程序员职业：

| 程序员简介 |
| :--- |
| 最教育要求 | 学士或副学士 |
| 个人特质 | 批判性思维、解决问题的能力以及良好的书面和口头沟通能力；团队合作精神 |
| 认证 | 需要 |
| 工作条件 | 室内 |
| 薪资范围 | 约 $77,550 至 $102,000 |
| 职位数量 | 截至2014年约 328,600 个 |
| 未来职业前景 | 随着工作流向海外，增长率正在下降 |

在最基础的层，程序员编写让视频游戏中发生事情的代码。这包括将玩家从控制面板的输入连接或“映射”到屏幕上正在发生的动作。它还包括所有非玩家角色 [NPC] 的动作或移动；例如，当你看到 NPC 在视频游戏的地形上游荡时，是程序员赋予了这些角色人工智能，让它们能够在那里某处漫游。

程序员通常专攻几个领域中的一个。

人工智能 `AI` 程序员决定游戏中的角色如何对人类玩家在计算机上执行的不同动作做出反应。一些示例包括策略（决策算法，计算执行某项动作与另一个动作相比的优缺点）、路径规划（规划游戏中两点之间的最短路线）以及敌人战术（游戏中的反派可以采取的各种动作类型，以提高或巩固其在游戏中的地位）。需要使用不同的代码脚本来编写这些内容，AI 程序员通常精通数种不同的计算机语言。

物理程序员制定管理游戏世界的规则，包括重力等效果以及角色与物体交互的方式。这些程序员还控制特效，包括爆炸、火和激光束。角色的身体也受物理定律的影响，因此程序员将负责创建身体撞击地面或遭受其他撞击的效果，这通常被称为软骨骼物理学（soft ragdoll physics）。

图形程序员专注于使用颜色、阴影、光、暗影和纹理，为玩家提供关于他们在每个场景中应该做的视觉线索。他们努力让二维艺术具有三维感，并还帮助压缩数据，以便在玩游戏时没有延迟。

用户界面程序员编写运行游戏引擎的代码。换句话说，这种编程负责玩家如何导航游戏。导航通常使用某种菜单系统来控制从选择关卡或角色服装到增大或减小音量的一切操作。

### 如何成为程序员？

### 教育
无论他们的专长是什么，对于想要成为程序员的人来说，理想的专业领域都是计算机科学。正如《游戏职业指南》网站在《游戏编程：导论》文章中所提到的：“程序员是数学和科学人才，更具体地说，是代数、微积分和计算机科学人才。通常，程序员拥有计算机科学学位（或对该领域有深知识）。”大多数学院和大学都提供计算机科学学位课程。根据《美国新闻与世界报道》（U.S. News & World Report），计算机科学排名前四的学校是卡内基·梅隆大学、麻省理工学院、斯坦福大学和加州大学伯克利分校，尽管全美各地的大学还有许多其他类似的课程。这些四年制课程向学生介绍游戏设计的的核心概念，包括编程、故事和角色开发、视觉和声音设计以及游戏引擎开发的课程。获得计算机科学学位让想要成为程序员的人接触有关各种操作系统、编程概念、输入/输出方法和算法的信息。

根据 O*NET 的数据，约 78% 的通用计算机程序员拥有学士学位，11% 拥有中专证书，6% 仅有高中毕业或同等学历。AI 专家通常拥有计算机科学或认知科学的硕士或博士学位。

### 认证
对各种编程语言的认证是必须的；如今的程序员通常被要求精通 `C++`、`OpenGL`、`PhysX`、`Perl`、`Perforce`、`Python` 和 `XML`。正如《游戏职业指南》在《游戏编程：导论》中提到的：“在程序员在游戏行业找到工作之前，他们需要对编程语言有坚实且实用的掌握，通常是 `C++`，尽管许多人也需要知道汇编、`C` 或 `Java`。`C++` 是目前游戏行业中最常用的语言。”

### 获得经验
即使对于刚开始做游戏程序员的人来说，经验也非常重要。幸运的是，有很多获得经验的方法，尽管大多数方法都需要个人的主动性。正如育碧蒙特利尔首席游戏玩法和 AI 程序员 Alessia Laidacker 在 2016 年 4 月接受 We Are Game Devs 网站采访时提到的，被视频游戏开发者和寻求招聘的公司关注的最佳方法之一是编写自己的游戏并参加游戏开发者聚会：

- 制作你自己的游戏。使用 `Unity3D` [一个游戏开发程序] 对任何人来说都非常容易，而游戏大松（Game Jams）是花费 48 小时产出一个游戏原型的极佳方式。我倾向于选择拥有个人项目、游戏大松经验、黑客松等的申请者，而不是只有成绩优秀的人。对进入游戏行业的热情以及展示出的这一点很重要。

#### 技能与性格
程序员最重要的性格特质之一是灵活性。由于他们需要使用不同的编程语言编写代码或脚本，并与艺术家和设计师合作，这正如育碧蒙特利尔首席游戏玩法和 AI 程序员 Alessia Laidacker 在 2016 年 4 月接受 We Are Game Devs 网站采访时提到的，被视频游戏开发者和寻求招聘的公司关注的最佳方法之一是编写自己的游戏并参加游戏开发者聚会：……对进入游戏行业的热情以及展示出的这一点很重要，这是我最看重的点。”

良好的书面和口头沟通能力也是必要的，还需要批判性思维能力。《游戏职业指南》建议程序员必须能够寻找他们问题的答案和面对问题的解决方案。从这个意义上说，程序员必须是强大的独立学习者。然而，程序员知道如何与他人有效沟通至关重要，因为他们的工作需要每天分享知识。

编程是任何视频游戏公司中最技术性的工作之一，但它也是一项高度创造性的活动。许多程序员将他们多种计算机语言的能力视为艺术形式。正如自称为“极客”的自由职业程序员 Gil Fewster 在 freeCodeCamp 网站的一篇文章解释道：“不写代码的人很少相信这一点，尽管有所有的技术规则和结构纪律，编程是一项高度创造性的活动。 . . 没有两个程序员会产生相同的代码，即使最终软件从外面看起来一样。给十个程序员一个功能规范，每个人都会产生独特的东西，那是他们作为程序员的自己的表达。”

### 上岗

### 雇主
大多数视频游戏程序员是全职薪薪员工，受雇于视频游戏公司，这些公司可能是资深玩家熟悉的大公司，可能是为特定移动平台发布游戏的小公司。许多程序员在育碧、任天堂、EA Games 和暴雪娱乐等领先游戏公司工作。根据《游戏职业指南》对创始人 Peter Lee 的采访，雇主最感兴趣的是那些能够把事情完成的申请者，无论是一个计算机科学学位还是他们开始开发的游戏。“我看到太多应毕业生缺乏创建一个完整应用程序的能力，无论它有多小，”Lee 说道。

### 工作条件
程序员的工作日可能会很长，特别是当他们设计新游戏时。有时他们会花整天时间与其他团队成员一起修复漏洞。即使在游戏完成后，团队通常也会很快转向下一个项目。在 2016 年的一次采访中，Laidacker 描述了他们的一天：

我的一天
这是我们正在工作的下一个系统。有时我在编写设计文档，有时我戴着耳机写一整天代码。

### 收入
视频游戏程序员的薪水取决于他们所在的公司类型以及他们的技能和经验。在这一光谱的一端是初级程序员，他们的年薪约为 77,550 美元。另一端是高级程序员，他们的年薪可达 92,000 美元。O*NET 和劳工统计局（BLS）将视频游戏程序员归类为普通计算机程序员和软件工程师，后者在2015 年的中位工资为 79,530 美元。根据职位搜索网站 Indeed 在 2016 年 7 月获得的信息，典型的视频游戏程序员平均年薪为 102,000 美元。

### 晋升机会
根据专业领域，不同类型的程序员在视频游戏行业会有不同的经历。例如，AI 程序员可以通过获得硕士或博士学位，以及通过从 `C++` 程序员或初级软件工程师逐步晋升，在该领域取得进步。他们可能感兴趣从视频游戏行业跳到专注于 AI 的研究小组，或者创立自己的公司来专注于个人项目。AI 程序员还可以在机器人、语音识别、机器视觉系统和自然语言行业工作。无论他们的专业领域是什么，程序员都必须不断提高自己的技能以及对视频游戏行业使用的工具和编程语言的知识。他们越精通技能，在简历中增加多年的经验，就越受欢迎，并伴随着相应的薪资涨幅。

![](img/5ffb35298ffd34b0969fe596ba9f5b27_32_0.png)

视频游戏程序员面临着一些严酷的现实。BLS 预测，由于工作外包到那些平均程序员薪水远低于美国程序员的国家，到 2024 年，计算机程序员的工作数量将减少 8%。因此，预计在此期间将失去 26,500 个工作岗位。然而，BLS 并没有专门针对视频游戏行业收集数据——而该行业是科技世界增长最快的分领域之一。

同样，随着消费者继续寻求更新、更复杂的游戏——包括新兴虚拟现实（VR）领域的游戏——对胜练、经验丰富的程序员的需求将持续增加。正如作者 Caroline Zaayer Kaufman 在 2015 年 10 月于职位搜索网站 Monster 发表的文章提到的：“对具有 VR 知识的候选人的需求比去年增加了 37%……由于该技术是新的，公司很难满足这一需求。”因此，尽管低级编程工作可能继续外包，但经验丰富的首席程序员、AI 程序员以及其他能够创建这些更复杂游戏的人将处于更容易找到工作的地位。

### 音效设计师做什么的？
音效设计师创建视频游戏的音频世界。他们构建游戏过程中发生的噪音和听觉线索——就像电影和电视中的拟音师。通过与创意总、游戏设计师、制作人以及游戏开发团队的其他成员合作，音效设计师了解更多关于设定、角色和故事，为游戏创建一个沉浸式环境。根据音效设计师 Aaron Marks 在 Designing 网站上的一篇文章：“许多游戏行业之外的人不知道，音效设计师仍然被要求能够创作合适的音效，还要成为现场录音师来捕捉特定的声音作为元素或真实的音效，成为拟音师来创建特定的物体处理声音以用于游戏或游戏电影场[用于引入新角色或其他以此打破游戏节奏的视频场景]，成为音频编辑师以根据需要编辑和处理音频元素……并根据需要进行后期制作。”

- 未来职业前景：到2024年的增长率为7%

#### 技能与性格
最成功的音效设计师将创造力与技术专长结合在一起。构思每一个独特的音频世界需要一种特殊的能力，即倾听现实生活中的声音并对其进行处理，以代表虚构的角色和互动。这意味着音效设计师必须在音乐方面颇有天赋，并且在通过混合和失真声音来寻求音频问题的巧妙解决方案时，能够跳出固有框进行思考。Get In Media 曾表示：“设计师不仅必须具备创造平衡、高质音效的能力，他们还应该具备创意才华去想象一个完全全新的听觉世界，比如光剑独特的声或恐龙尾巴的声音。”

在游戏开发过程的某些阶段，音效设计师会在工作室环境中独立工作；在另一些阶段，他们会与团队成员互动。他们必须既能自律工作，又能与他人良好合作。例如，音效设计师将与其他团队成员合作，确保所有声音都与游戏的视觉元素匹配。

### 工作条件

视频游戏行业的音效设计师通常在音效工作室工作，而不是公司总部。这可能是一家制作公司的工作室。对于自由职业者来说，这可能是一个家庭工作室。长时间的工作时间并不少见，特别是在接近新游戏完成的截止日期时。Gearbox Software 的内部高级设计师 Raison Varner 在接受 Careers 网站的采访时描述了他的工作日：“在低谷期，我会有节奏较慢的、相对正常的八小时工作。在高峰期，我会有一段时间每天工作八小时的高强度日，然后在重大里程碑到来前的一到两周内进行九到12小时的高强度工作。根据里程碑的情况，我有时需要工作几个周六，或者连续工作两个周末。”

游戏行业音效设计师的典型一天可以非常多样化。Varner 继续说道：

早晨，我处理电子邮件、错误跟踪通知，参加我担任负责的项目会议，有时我只需要投入到内容开发中。问题在一天中会接来又去；我们可能会收到一些让我们重新调整整个部门优先事项的新闻。其他时候，我只是埋头处理某个生物，可能是在[创建]一个声音处理链[一系列用于产生预期效果的硬件或软件效果]，或者将许多声音实现到 Boss 战斗中。偶尔，我会花整整一天的时间开会，与作曲家交流，制定外包计划和进度表。我最喜欢的日子就是当我埋头处理音乐，一切都进展得非常顺利，而且没有出现任何突发故障状况！

### 收入

### 职业发展机会

当音效设计师开始在该领域工作时，他们通常会从实习生或初级音效设计师做起，随着职业生涯的进步，逐步成为成熟的音效设计师。在行业内工作几年后，他们可以成为高级音效设计师或音频总监。此外，自由职业音效设计师可能加入公司成为内部设计师。音效设计师的其他机会包括横向转型为作曲家、录音工程师或制作人。

### 如何成为技术支持专家？

#### 教育背景

技术支持专家并不一定需要计算机科学、游戏设计或信息科学学位才能成功，但这些类型的学位无疑有助于对视频游戏和计算机系统的通用理解。它们在潜在雇主眼中也显得**很有**。根据 O*NET 的分类（该机构将技术支持专家归类为计算机网络专家或计算机用户支持专家），约 47% 的计算机网络支持专家拥有学学位，22% 的拥有专科学位，14% 的上过一些大学课程但没有学位。相比之下，约 29% 的计算机用户支持专家拥有学学位，22% 的人上过大学但没有学位，18% 的拥有专科学位。

#### 认证与许可

根据公司的不同，可能需要相关认证。通常要求获得计算机技术行业协会（CompTIA）的 A+ 认证，该认证证明了其在技术和客户服务技能方面的基础。其他可能需要的认证类型还包括 Apple、微软、Cisco 和 Linux 提供的针对这些计算机操作系统的特定计划。

#### 技能与性格

技术支持专家依靠他们的客服技能来与愤怒、沮丧的玩家进行互动。因此，他们最重要的两个特质是耐心和理解。配合良好的倾听技巧，他们需要能够迅速理解用户通过电话或即时消息描述的问题。同样，他们必须提出良好的后续问题，以帮助消除任何困惑。冷静的态度至关重要，特别是在激烈的互动期间。

解决问题的能力是技术支持的另一个关键特质。简单和更困难的问题每天都会出现。对于常规问题，技术人员通常依靠脚本回复。对于不常见且更困难的问题，专家需要开放心态来构解决方案。

沟通技能同样重要。技术支持专家必须以清晰、简洁的方式向消费者口头传解决方案。良好的书面沟通技能对于编写报告给质量保证团队以及通过电子邮件或在线聊天消息回复玩家至关重要。Get In Media 网站指出，作为负责排除故障并安抚客户的问题解决者，该职位的人应当对游戏系统有深入了解。此外，该职位要求具备出色的冲突解决能力、组织能力和专注。

### 工作

### 雇主

大多数技术支持专家是轮班制的，在暴雪、EA、任天堂和 Ubisoft 等大型游戏公司现场工作。他们也可能由猎头公司外包，或作为临时季节性员工在忙季提供帮助。2016 年 8 月，职位招聘网站 Indeed 上的一份虚拟游戏支持代表广告表明，对于具备正确技能和技术设备的申请者来说，许多技术支持工作实际上是居家办公。描述建议了以下要求：

良好的互联网连接：上传速度 5 Mbps，下载速度 7 Mbps——越快越好（无线或互联网服务提供商不兼容）。

### 工作环境

技术支持技术人员通常实行 24 小时 7 天轮班，以便快速响应玩家。因此，有志的技术支持人员在安排上应具有灵活性，因为他们可能被要求在清晨、深夜或周末工作。5CA 网站上关于游戏行业客服的文章指出：“游戏行业对技术支持和客户服务的需求呈指数级增长，而玩家以挑剔的客户著称。”在大公司工作的技术支持专家在呼叫中心工作。典型的呼叫中心由一个或多个充满隔间的大房间组成，工作人员在那里回答客户的电话。在呼叫中心工作压力很大，隔间式布局缺乏隐私和个人空间。

等等。根据 O*NET 的数据，2015 年计算机用户支持专家的位数收入为 48,620 美元，计算机网络支持专家的中位数收入为 62,250 美元。两类人群的前 10% 收入都在 81,260 美元到 106,310 美元之间。根据 Indeed 在 2016 年 7 月获得的信息，技术支持人员的平均年薪为39,000 美元。

### 晋升机会

虽然技术支持专员是一个入门职位，在公司内部的晋升空间有限，但在该职位上获得的经验可以通向游戏行业的其他工作。该行业中技术支持经验可以派上用场的两个领域是质量保证（涉及游戏测试）和在线社区管理（涉及与玩家互动以收集反馈并奖励忠实玩家）。正如 Get In Media 网站提到的，技术支持专员“通常是一个起薪较低的入门职位，但这份工作的好处是能让你进入游戏公司的大门……在担任客服（CS）技术人员期间，你可以学到很多东西，而对公司生产的系统和作品的知识在面试更好的工作时将被证明是无价的。”

## 动画师

### 动画师做什么做什么？

视频游戏动画师通过描绘虚拟世界中的屏幕动作和行为来帮助游戏生动。他们的工作是确保角色、物体和场景——本质上是出现在屏幕上的任何东西——在游戏语境及其运行平台上恰当地移动。

Creative Skillset 指出，动画师必须根据游戏的技术和平台限制，找到创建既有功能又具效益的动画的最佳方法。由于许多动作在游戏过程中会重复，动画师会为每个角色建立动作库，这有助于在无缝移动与优化游戏在不同平台的性能之间取得平衡。其中一些动作必须通过代码或手动关键帧，而另一些则可以在动画软件的帮助下更快地制作和复制。

### 动画师概览

- **最低教育要求**：学士学位或副科学学位
- **个人素质**：批判性思维；积极倾听；良好的书面和口头沟通能力；复杂问题解决；团队合作
- **认证与许可**：建议性
- **工作环境**：室内
- **薪资范围**：约 $63,970 至 $215,000
- **职位数量**：截至 2014 年约 64,000 个
- **未来职业展望**：到 2024 年增长率为 5% 到 8%

动画师经常与程序员和艺术家合作，以确保他们的工作根据游戏出现的平台得到平稳呈现。视频游戏动画师帮助让屏幕上的虚拟世界生动起来。动画师的工作是确保角色、物体、场景和所有动作在游戏语境及其运行平台（移动设备、计算机、游戏机等）中恰当得移动。Creative Skillset 描述了视频游戏动画师的工作：“游戏制作是协作性的，动画师作为艺术部门团队的一部分工作。利用 3D 艺术家创建的物体、模型，以及最重要的角色，动画师定义了它们的动作和行为，并使用所选的 3D 动画软件包提供的工具和技术来应用它们。

对单个角色进行骨骼绑定（Rigging）和蒙皮（skinning），这是一个类似于构建骨架的过程是动画师的主要任务之一，涉及计算机建模程序的使用。根据游戏的类型，动画师可能处理二维或三维（2-D 或 3-D）图像，每种图像都需要不同类型的计算机操作来实现所需的效果。通过调整游戏世界中的颜色、光影甚至透明度，可以实现逼真的效果。”

### 如何成为动画师？

### 教育

视频游戏动画师通常学习计算机动画以获得学士或副科学学位。根据 Game Designing.org 的介绍，游戏设计排名前五学校是南加州大学、卡内基·梅隆大学、犹他州大学、DigiPen 科技学院和罗彻斯特理工学院。然而，重要的是，视频游戏的动画需要电影或电视动画不同的技能组合，因此学生应该考虑具有行业针对性的课程。根据 O*NET 的数据，62% 的视频游戏动画师拥有学士学位，19% 拥有副科学学位，17% 上过大学课程但没有学位。

#### 认证与许可

动画师可能需要游戏编程认证，这通常涉及游戏数学、3D 图形编程、游戏引擎架构、C++ 编程、基础物理、游戏开发和计算机动画。有在线课程提供这些证书，因此学生可以按照自己的节奏学习，但需要高速互联网连接。

### 志愿者工作与实习

实习通常是动画专业学生的要求。实习提供了学习在职技能以及拓展潜在雇主人脉的绝佳机会。EA Games 为目前就读美术、视觉艺术、工作室艺术、计算机动画、交互娱乐、插画或相关领域的本科或硕士生提供年度艺术和动画实习计划。暴雪娱乐（Blizzard Entertainment）也为大三学生以及有天赋的大一和大二学生提供动画暑期。

此外，新动画师可能想要从事志愿者工作以帮助积累经验。虽然一些动画师可能对免费提供工作望而却步，但这种进的困境在于，公司不想给未受过训练的动画师机会，而精通所需的许多技能是在工作中获得的。因此，志愿者工作提供了一个获取领域经验的直接途径，同时建立可以通向付费工作的作品集。

对于所有致力于同一项目的艺术家来说，某些技能非常重要，例如积极倾听、批判性思维和沟通能力。Beaulieu 解释道，“首席动画师的职责是多元化的。”他/她指出，首席动画师不仅要完成动画工作，还被要求指导和支持团队的其他成员。对于 Beaulieu 来说，作为艺术家对团队成员进行指导，与确保整个团队的动画风格保持一致同样重要。耐心、理解和乐于帮助只是工作的一部分。

除了要有耐心和理解之外，动画师还必须具备有效的时间管理能力，这在面对截止日期进行工作时至关重要。无论是与他人小组合作还是单独工作，动画师都必须合理规划时间，以满足多个截止日期并保持项目推进。那些能够跟上截止日期的人将被认为更有价值的团队成员，并在职业生涯中进步得更快。

动画师还必须处理工作中遇到的复杂问题。能够对这些错误承担责任，并解决技术和设计问题，将有助于项目的推进。解决问题是视频游戏行业大多数工作共同具备的关键特质，因为每款游戏都由大量复杂的碎片以及各种团队成员的许多不同贡献组成。

#### 职场

### 雇主

大多数视频游戏动画师是受雇于视频游戏公司的全职薪资工人，这些公司可能是核心玩家 easily识别的大型机构，也可能是特定移动平台发布游戏的小公司。许多人任职 Ubisoft、天堂、EA Games 和暴雪等领先的游戏公司。

### 工作条件



视频游戏动画师通常使用许多不同类型的程序，从计算机辅助设计软件、视频和图形程序，到像 `Drupal`、`DHTML`、`JavaScript` 和 `PHP` 这样的网页开发程序。动画师还经常使用特定的计算机动画程序，如 `3D Studio Max` 和 `Maya` 来渲染他们的作品。工作的另一部分还需要关注行业趋势，并在新技术引入和开发时参与持续教育（包括职内和职外教育）。

除了跟上行业标准外，动画师还必须与同事保持同步，以便继续和谐合作。同事们在工作中花费大量时间，有时在下班后还会聚在一起，无论是正式还是非正式的，作为企业文化的一部分。Beaulieu 在接受 Animation Arena 采访时描述了她的工作条件：

制作视频游戏意味着许多人必须共同努力，包括游戏设计师、程序员、关卡设计师、3D 艺术家等。在 Ubisoft 工作非常愉快，即使是一家大公司，我们也得到了很好的对待。公司经常为生日、游戏首映和其他活动组织活动。制作游戏要求非常高，且某些项目需要加班。总的来说，我告诉你们努力工作并来制作视频游戏吧；你们会玩得很心的。

### 收入

视频游戏动画师的薪水取决于他们在领域获得的经验和技术熟练程度。根据 `O*NET` 的，光谱的一端是初级多媒体艺术家和动画师，他们的年薪约为 $63,970，并可以随着经验进入更高的薪资水平。另一端是在该领域时间更长的高级艺术家，他们的年薪约为 $70,300。根据求职网站 `Indeed` 在 2016 年 7 月获得的信息，典型的视频游戏动画师平均年薪为 $82,000。首席动画师的年薪范围从 $80,000 到 $215,000 不等，取决于资历。

### 晋升机会

动画师可以获得同行的尊重、行业内的赞誉，并且在该领域工作时间越长，就越能期待加薪。通常，在视频游戏行业工作三年后，动画师被认为具有丰富经验，并可能被考虑担任动画师职位。游戏动画师也有跳跃到电影和电视动画的可能性，但动画过程可能会显著不同。

#### 动画师的未来前景如何？

尽管由于需要大量的专业知识和在职培训，动画工作很难获得，但该职业的就业前景是好的。到 2024 年，增长率为 5 到 8%，职位数量仍在增加，随着手机和便携式平板电脑游戏的持续扩张，高质量的动画师无疑会有需求。

维护并扩大其技术熟练程度的动画师无疑会有需求。

#### 概览

- 3D 艺术家
- 最低教育要求：学士或专科学位
- 个人素质：批判性思维；积极倾听；良好的书面和口头沟通能力；复杂问题解决；团队合作精神
- 证书和许可：建议
- 工作条件：室内
- 薪资范围：约 $63,970 至 $70,300
- 职位数量：截至 2014 年约 64,000 个
- 未来就业前景：到 2024 年增长率为 5 到 8%

## 3D 艺术家

### 3D 艺术家做什么？

3D 艺术家也被称为 3D 建模师，他们创建角色、物体和环境。尽管他们的工作主要是数字化的，但他们也使用纸张、水彩或粘土等传统媒介进行绘画、上色或雕刻。根据 Creativeset 的说法，3D 艺术家的工作是“构建生命、风景、植被、家具和车辆。他们需要平衡功能性和细节。”

3D 艺术家的工作从不无聊，因为他们总是在处理不同的事情。由于每天都不一样，3D 艺术家 Mark Masters 表示，他从不知道工作中能期待什么，而这正是他喜欢这份工作的原因。在 Digital Tutors 的一中，他表示：“作为一个 3D 建模师，你无法预测推给你的项目类型。有时会有工作室招募 3D 建模师仅建模特定的角色，但你无法预测何时会发生。”

### 教育

3D 艺术家通常学习美术、平面设计或插画，以获得学士或专科学位。除了正式教育外，对于有志的 3D 艺术家来说，尽可能地尝试 3D 建模软件也同样重要。3D 打印网站 Shapeways 的自由职业 3D 艺术家 Jordan Banks 指出：

“大学是一个很好的开始，因为它教你如何专注于自己的技能……我与同龄人的区别在于，当我回到家后，我继续看教程来学习程序。没多久，我就开始自己尝试东西，甚至改变书中的内容。我曾以为看教程让我在建模和使用软件方面变得更优秀。后来我发现，并不是看教程让我建模很棒，而是对程序的实验让我理解了如何更好地操作软件。”

除了软件技能外，3D 艺术家还必须具备高级的数学技巧，以及与其选择的工作领域相关的特定技能。《Animation Career Review》网站指出，视频游戏行业中的 3D 艺术家被期望带来创造力和设计能力，但根据取决于 3D 建模师的工作地点，可能还需要其他技能。例如……科学领域的 3D 建模师可能在科学的某个特定领域具有深厚的背景。你选择的专业和研究方向将完全取决于你希望进入的领域。例如，如果你感兴趣成为游戏行业中的 3D 建模师，可以考虑主修游戏设计专业。

3D 艺术家通常使用许多不同类型的计算机程序，包括如 `3D Studio Max` 和 `Maya` 这样的 3D 图形程序、如 `ZBrush` 和 `Mudbox` 这样的雕刻程序，以及如 `Photoshop` 这样的 2D 程序。工作的一部分还要求跟进行业趋势，并在新技术不断引入和开发的同时参与持续教育（包括职内和职外教育）。

### 认证与执照

3D 艺术家可能需要游戏编程认证，这通常涉及参加四到五门课程，涵盖游戏数学、3D 图形编程、游戏引擎架构、`C++` 编程、基础物理、游戏开发和计算机动画。有提供这些证书的在线课程，学生可以按照自己的节奏进行学习，尽管需要高速互联网连接。

### 志愿者工作与实习

实习通常是美术专业学生的学生的要求，这些实习提供了学习职场技能以及与潜在雇主建立人关系的绝佳机会。此外，3D 艺术家将希望从事志愿者工作以帮助建立自己的作品集。例如，EA Games 提供了一项艺术和动画实习/合作计划，面向学习纯美术、视觉艺术、工作室艺术、计算机动画、交互式娱乐、插画或相关专业的本科生和硕士生。在同类实习期间，3D 艺术家无疑可以通过观察和与其他 3D 艺术家一起工作来学到很多知识，并感受行业内团队合作的动态。

除了追求实习之外，3D 艺术家还需要能够通过在线作品集展示自己的工作成果（实习是为作品集搜集素材的绝佳方式）。潜在的雇主希望看到艺术家制作的艺术作品类型，以及艺术家精通的不同风格。正如 3D 艺术家 Sam R. Kennedy 在他的书籍《如何成为视频游戏艺术家》中提到的：

“作品集是你最优秀艺术作品的精选，用于向潜在雇主展示你的技能、天赋和艺术愿景。艺术作品可以是画作、数字绘画、3D 模型、动画和/或其他图形。你的作品集还应该出现在网上。你作品集中的工作应该在视觉上说明你感兴趣的工作所需的技能，并应该展示你对所有所需软件程序的精通程度。”

#### 技能与性格

为了在视频游戏行业取得成功，3D 艺术家必须在技术上精通并在艺术上有造诣。除了艺术技能外，3D 艺术家一些重要的性格特质实际上围绕着软技能。与工作同一项目的设计师、程序员和艺术家小组协调的能力非常重要，例如积极倾听、批判性思维和沟通等技能。3D 艺术家还必须能够监控自己并具有主动性，以确保满足所有期限。在面对工作室截止日期时，时间管理能力也至关重要。

有抱负的艺术家需要现实的预期。游戏行业有很多优秀的3D 艺术家，年轻艺术家很容易将自己的作品与这些经验丰富的艺术家进行比较。这样做可能会让人压力巨大——甚至对年轻艺术家的成长有害。相反，2D 培训网站 CG Cookie 的 3D 艺术家 Jonathan Williamson 敦促年轻艺术家从经验丰富的艺术家那里学习一切所学，但要记住培养人才需要时间。在为 materialise 网站的一篇文章中，Williamson 解释说要专注并避免自我怀疑。

3D 艺术家或建模师通过创建三维模型赋予游戏角色、物体和环境生命。他们的工作大部分是数字化的，但他们有时也会进行绘画、插画或雕塑等。

### 职工作中

## 质量保证

### 测试员

### 质量保证测试员是做什么的？

质量保证测试员（也称为视频游戏测试员）在后期阶段定位并报告单款视频游戏中的问题。这一阶段是在游戏完成之后、交付客户之前。即使是设计最好的视频游戏也有漏洞（glitches）。测试员的目标是在游戏发布之前找到所有这些漏洞——或尽可能多地找到——但在游戏向消费者开放后，他们也可能参与重现玩家报告的漏洞。测试员通常寻找游戏软件中影响整体用户体验的 Bug。例如，Bug 可能会导致游戏卡在某个关卡的某一个点，或者可能会阻止游戏继续进行。测试员可能还会寻找艺术故障，例如未能正确渲染角色或环境。虽然质量保证测试员是发现漏洞的人，但他们并不一定负责修复它们。当他们发现游戏中的问题时，他们会提醒游戏开发团队的其他成员，以便他们修复这些问题。

发现漏洞并不总是易的。这通常需要花费几个小时玩和反复玩游戏的特定部分，以寻找玩家可能会遇到的问题。尽管他们工作的一部分像任何玩家一样玩游戏，但他们也使用特定的测试方法来根除任何问题。例如，他们可能会使用矩阵测试，这要求在游戏的每个关卡让每个角色与其它所有角色进行对决。或者他们可能会使用功能测试，涉及测试游戏的所有功能，以确保其工作符合游戏文档。此外，一旦程序员修复了报告的 Bug，质量保证测试员可能会进行回归测试，即对以前测试过的关卡进行重新测试。

有时测试的目标实际上是破坏游戏，但其他时候的目标仅仅是像普通玩家一样玩。当发现错误、故障或潜在问题时，测试员会标记该问题，将其记录，并通知首席测试员。记录通常包括对问题的书面描述、关于如何重现问题的笔记、截图（特别是针对艺术故障）以及测试员可能注意到的已发现的任何额外错误之间的任何关系。正如索尼互动娱乐美国公司高级发布经理 Brent Gocke 所说：“如果你喜欢钻研事物并尝试弄坏它们，视频游戏测试可能成为你的一条道路。它适合那些细致入微的人、热爱游戏并热衷于玩这些事物以及探索不同可能性的人。”

### 如何成为一名质量保证测试员？

#### 教育背景

成为视频游戏测试员的典型路径源于对玩游戏的热，但许多不同的技能最终将人们带入测试领域。虽然游戏测试员没有特定的教育要求，但越来越多的雇主要求接受过正式学习，无论是在计算机编程还是相关领域。技术学院和社区学院提供软件质量保证的本科证书，最快只需六个月即可完成。

然而，那些仅持有证书的人可能会发现自己面临着来自更专业领域（如计算机科学、信息技术或软件工程）的学士学位申请者的激烈竞争。根据 `O*NET` 的数据，约 64% 的软件测试员拥有学士学位，14% 拥有专科学位，9% 拥有硕士学位。想在该领域内晋升但不想选择硕士学位的学生也可以找到软件质量保证的研究证书课程，这些课程大约可以在一年内完成。这些课程通常可以在学生全职工作的同时完成，且课程分有时可以转为追求硕士学位的积分。

### 认证

许多雇主要求视频游戏测试员经过认证。最常见的资格之一是由国际软件委员会（International Software Board）提供的软件测试员认证。该证书必须每三年更新一次，而且除了笔试外，还需要工作经验。可能对质量保证测试员有利的额外认证还包括认证质量工程师和认证可靠性工程师，两者由美国质量协会（American Society for Quality）提供。

#### 技能与性格

视频游戏测试吸引特定类型的人。虽然大多数游戏爱好者都是如此，但成为优秀测试员的关键是对改进游戏的热情。但仅凭这些是不够的。质量保证测试员必须耐心、有方法，并且能够在没有直接监督的情况下独立工作。测试员应该具有分析能力，能够发现问题并提供可能的解决方案。他们还需要强大的书面和口头交流能力，向团队成员清晰地描述问题。测试员从开发者或设计者的角度分析问题，以及使用玩家的心态也会很有帮助。

| :--- | :--- |

### 雇主

大多数质量保证测试员是合同工，在不同的项目之间流动。有些是被直接雇佣的，或者通过派遣信息技术招聘公司提供的长期派遣工作。视频游戏测试员为视频游戏公司工作，这些公司可能是被狂热玩家轻易识别的大型机构，也可能是为特定移动平台发布游戏的小型公司。许多人任于 Ubisoft、任天堂（Nintendo）、EA Games 和暴雪娱乐等领先的游戏公司。

### 工作条件

质量保证测试员通常在办公环境中独立工作。首席测试员将监督一个质量保证团队，该团队规模可能从小公司的几名测试员到大公司的数百名测试员不等。有些测试员可以居家办公，每周可能远程办公几天。大多数测试员为全职工作。由于游戏开发通常由截止日期驱动，测试员长时间加班的情况并不罕见。此外，在冲刺阶段（crunch time），测试员可能需要加班和/或上夜，以确保在游戏交付消费者之前，游戏层面的所有漏洞都已定位并修复。

尽管如此，在制作游戏的公司工作确实有一些好处。正如游戏测试员 Danny McGee 在 Newsvine 网站的一篇文章中提到的，在 EA Games 工作包括福利：

- 休息室提供免费的麦片和牛奶，此外还有便宜得离谱的自动贩卖机（备有充足的山山露）和免费的街机游戏；一家摆满了 EA 旗下所有发行商和开发者的视频游戏的商店，折扣超过 50%；而且偶尔——为了保险起见——还有计薪时间内的啤酒派对，配有免费的披萨、鸡翅和视频游戏比赛。

### 收入

质量保证测试员的薪水取决于他们居住的地方、工作的对象、测试的类型类型，以及他们拥有多少经验。根据一个来源，游戏测试员通常每小时赚约 10 到 18 美元，按小时计薪而非固定月薪。但另一个来源，求职网站 `Indeed` 指出，2016 年 6 月，典型的视频游戏测试员平均年薪 45,000 美元。

### 晋升机会

即使视频游戏测试员获得了更多经验，在测试领域内的晋升机会也很少。有些人可能会获得首席测试员等更高级别的职位，但攀爬公司阶梯的额外机会非常有限。那些希望在同一公司内转型管理、设计或编程工作的人，通常需要接受更多教育才能进入这些角色。对于有管理抱负的人来说，研究生级别的管理课程是理想的选择，而对于寻求设计或编程工作的人来说，软件设计或计算机编程学位会更理想。具有高级测试技能的游戏测试员也可以成为软件质量保证工程师，他们是能够编写脚本测试复杂、专业软件的软件开发人员。无论测试员决定追求哪个方向，这种变动将是横平移动而非直接的职业晋升。

![](img/5ffb35298ffd34b0969fe596ba9f5b27_71_0.png)

与其他类型的软件测试不同，视频游戏测试员将始终需要手动玩游戏以寻找漏洞。由于测试员必须既模仿普通玩家，又要积极寻找破坏游戏的方法以提高性能，因此没有真实的方法可以实现这些职位。此外，玩游戏时必须考虑几个不同的目标，这对机器来说——即使是带有人工智能的——也是非常费劲的。尽管如此，这些工作的竞争可能会非常激烈，因为总有许多新成员渴望通过玩视频游戏谋生。

## 游戏设计师的采访



Sandra Chen 目前是一位自由职业作家和游戏设计师。她还是国际游戏开发者协会游戏设计特殊小组的组长，并在视频游戏行业工作了十五年以上。Chen 经营流行的游戏设计博客 Game Design Aspect of the Month，并是一位获得美国作家协会奖和格莱美奖提名的视频游戏设计师兼作家。她通过作者讨论了她的职业生涯。

### Q：你为什么成为一名游戏设计师？

答：游戏设计是分析与创意的完美结合。虽然很多人能看到创意的一面，但有一部分数学内容真正吸引了我。

### Q：数学在设计游戏时是如何发挥作用的？

答：游戏设计需要理解数学。即使我们看一个简单的游戏，比如平台跳跃，行走或跳跃等动作也需要数学。这些要求可能非常复杂，特别是对于需要使用算法或人工智能的游戏。游戏平衡确保游戏对玩家来说是有有趣的。需要合适的挑战水平，否则玩家会觉得游戏太简单而感到无聊。如果游戏太难，玩家会感到沮丧并可能放弃。游戏平衡还意味着确保没有胜利的“黄金路径”。例如，如果你有多种武器，那么武器的属性需要平衡，以便它们都是可行的选择。如果玩家发现某一种武器与其他武器相比过于强大，他们将只会使用那种武器。游戏的每个方面都需要平衡，包括角色属性、战斗能力、奖励表等。在平衡游戏时，游戏设计师可能花费大量时间在电子表格中操纵数字。

### Q：你能描述一下你典型的一天工作吗？

答：我处理各种项目。大部分时间花在创建文档上。游戏设计师通常是艺术家、制片人和程序员之间的社交胶水。他们需要与所有这些利益方保持良好沟通，并获得他们对建议的认可。游戏设计文档的一个重要点是让其他人阅读它们。除了团队机制之外，有时游戏设计师还要参与向发行商或其他编辑的推介。这种游戏文档必须简洁明了并让外行也能理解。

### Q：你对工作最喜欢和最讨厌什么？

答：我最喜欢的是因为每个游戏的主题都不同，我通常能学到很多新知识。虽然我可能不会面临僵尸爆发，但我可以将同样的避难所保护措施应用到其他可能的情况中。我最讨厌的是公众认为我没有正经工作或者我整天都在玩视频游戏。

### Q：你认为哪些个人特质对这类工作最有价值？

答：一个人应该对系统如何运作、一件事如何影响另一件事以及日常生活的关联性保持自然的好奇心。

## 问：你是如何产生新的游戏点意的？

答：游戏点子可以来自任何地方。我之前提到过宫见茂。《任天堂狗》（Nintendogs）的灵感源于宫见家里来了一只新幼狗。《宝可梦》的作者森井智治喜欢收集昆虫。但所有的游戏点子都需要进一步开发成纸质原型或演示版本，以便进行游戏测试。有时，原型最后发现并不好玩，设计师就必须针对该想法尝试不同的方案。

## 问：你对可能对这个职业感兴趣的学生有什么建议？

答：玩各种游戏，无论好坏。阅读书籍。多了解各种事物。

## 关于作者

Laura Roberts 为青少年和成人创作虚构和非虚构类作品。她曾担任周刊专栏作家、写作教练、专业书评人兼编辑；自2007年以来从事自由职业。她与丈夫 Brit 住在加利福尼亚州的圣迭戈。

### 高科技职业

对技术感兴趣并正在考虑职业选择的青少年，将在这一易于使用的书中找到实用的描述、核心事实以及宝贵的观点和建议。《高科技职业》系列向读者介绍了特定领域内的各种职业选择，并探讨了工作具体内容、教育要求、薪资范围、所需技能、就业前景等。该系列的所有书籍都包含了与该领域从业人士的问答访谈。每本书还列出了建议获取更多信息的来源列表。

该系列书籍包括：

- 环境与能源技术职业
- 游戏行业职业
- 互联网技术职业
- 医疗技术职业
- 机器人技术职业
