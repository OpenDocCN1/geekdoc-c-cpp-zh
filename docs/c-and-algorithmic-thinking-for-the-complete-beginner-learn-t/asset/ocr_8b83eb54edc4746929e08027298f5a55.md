```
# Absolute value

```
```cpp
abs( number )
```
```

This returns the absolute value of *number*. It is defined in the `cmath` library.

# Example

```
```cpp
#include <iostream>
#include <cmath>
using namespace std;
int main() {
  int a, b;

  a = -5;
  b = abs(a);

  cout << abs(a) << endl;       //outputs: 5
  cout << b << endl;            //outputs: 5
  cout << abs(-5.2) << endl;    //outputs: 5.2
  cout << abs(5.2) << endl;     //outputs: 5.2
  return 0;
}
```
