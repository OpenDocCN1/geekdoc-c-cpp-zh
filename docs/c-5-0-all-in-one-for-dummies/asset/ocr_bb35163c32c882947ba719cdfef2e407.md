# Making Your Console App Do Something

Edit the `Program.cs` template file until it appears this way:

![](bbox=[0.123, 0.421, 0.219, 0.49])

```
```csharp
using System;

namespace Program1
{
    public class Program
    {
        // This is where your program starts.
        static void Main(string[] args)
        {
            // Prompt user to enter a name.
            Console.WriteLine("Enter your name, please:");

            // Now read the name entered.
            string name = Console.ReadLine();

            // Greet the user with the name that was entered.
            Console.WriteLine("Hello, " + name);

            // Wait for user to acknowledge the results.
            Console.WriteLine("Press Enter to terminate...");
            Console.Read();
        }
    }
}
```
```

Choose Build→Build Program to convert this new version of `Program.cs` into the `Program1.exe` program.
