The sample shown in Listing 4-2 and Figure 4-1 uses the ApplicationCommands.Copy and ApplicationCommands.Paste commands to facilitate clipboard manipulation in your application. When the UIElement with focus supports the clipboard Paste action and there is data in the clipboard that is supportable by the element with focus, any elements bound to the Paste command are enabled. When the UIElement with focus supports the clipboard Copy action and there are items selected that can be copied to the clipboard, then any elements bound to the Copy command are enabled. (See Figures 4-2 and 4-3.) As a side note, WPF allows you to abbreviate the built-in commands by dropping the container name (ApplicationCommands), so Copy and Paste are legitimate abbreviations for the command bindings ApplicationCommands.Copy and ApplicationCommands.Paste. For readability, I prefer to fully qualify the names.
