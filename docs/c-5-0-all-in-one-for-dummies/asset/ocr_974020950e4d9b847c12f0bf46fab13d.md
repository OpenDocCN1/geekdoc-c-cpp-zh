# Using Snippets

*Snippets* are little bits of precoded logic that are meant to help you remember how to perform some standard code functions in various languages. In VB, for instance, you might not remember how to read from a file, so there is a snippet for that. In C#, you may want to implement a property getter and setter, so you use a shortcut to get the snippet in place.
