Two things to remember:

+   - The file extension you’re looking for is `.svc`.
+   - The binding you set up is abstracted away from you — one less thing you have to worry about.

Finding the file isn’t a big deal, but the binding is important. Keep in mind that selecting a binding is invisible to the developer, but it has a significant impact on functionality and especially performance. The decision of which to use is not to be made lightly; it should be done only after much research and needs analysis.
