# Setting up a WCF Service to Use REST

The WCF services model is designed for SOAP but can use REST without a problem. Fortunately, in an update to .NET, Microsoft made a template for REST services in WCF. This template greatly simplifies the process of building cross-platform REST services.

Unfortunately, as of this writing, this template is only available for Visual Studio 2010. I assume that by the time you read this book, it will be available and use some C# 4.0 code to explain what will work just fine in C# 5.0. It isn't optimal, but I think that the template is so powerful that it needs to be in the book.

# Getting the template

You should be able to go to the New Project dialog, click Online, and search for WCF REST in the dialog's Search box, and have the template appear. As you can see in Figure 4-1, it ain't there right now.

![](bbox=[0.3, 0.55, 0.9, 0.78])

Figure 4-1:
The WCF REST template

If it were there, you would click it and install it. You have to approve a license agreement, and then you are good to go. Visual Studio manages any updates to the template from then on.

If you happen to be working in Visual Studio 2010, you can get the template from the Visual Studio Gallery. The full URL is http://visualstudiogallery.msdn.microsoft.com/fbc7e5c1-a0d2-41bd-9d7b-e54c845394cd, but I imagine it is easier to go to http://visualstudiogallery.msdn.microsoft.com and search for WCF REST.
