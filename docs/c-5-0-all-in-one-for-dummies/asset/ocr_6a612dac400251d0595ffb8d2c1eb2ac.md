# Copying websites with "Copy Web"

If you have a website project, you have a Visual Studio–driven option for the xcopy option. Because these sites don't compile and you need to move the .cs files along with the .aspx files, this tool fits the bill.

To run it, look for the Copy Web icon in Solution Explorer (or find the Copy Web Site command on the Website menu). I highlighted the icon with a red box in Figure 5-8. It launches the Copy Web design surface, which looks a lot like the two Windows Explorer boxes in Figure 5-6, except it comes with neat buttons.
