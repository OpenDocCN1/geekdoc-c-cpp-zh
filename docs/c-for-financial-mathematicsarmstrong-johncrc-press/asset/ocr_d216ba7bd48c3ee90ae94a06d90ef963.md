# 8.6.2 Using PieChart

A central belief in object-oriented programming is that human beings find the code below easy to understand:

```
static void testPieChartClass() {
    // just checks that the class compiles etc.
    PieChart pieChart;
    pieChart.addEntry("Mushrooms",200);
    pieChart.addEntry("Salami",100);
    pieChart.addEntry("Spinach",150);
    pieChart.setTitle("Pizza Toppings");

    pieChart.writeAsHTML( "PizzaPie.html" );
}
```

This really summarises one of the key points of object orientation. Object-oriented software should make life easier for users of our libraries.
