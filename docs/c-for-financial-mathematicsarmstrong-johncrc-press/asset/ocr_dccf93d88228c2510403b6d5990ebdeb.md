# ## 10.6  An interface for integration

The difficulty with interfaces is not in the syntax or in the concept itself, but in spotting when you can use an interface to solve a problem. For example, we can use interfaces to perform numerical integration, but perhaps the connection between integration and interfaces is not obvious.
If you attempt to write numerical integration code in C++ you will hit a very similar problem to the one we experienced with our Monte Carlo pricer. For example, you should find it easy to write a function that integrates \( exp(-x^2) \) from $a$ to $b$ using the rectangle rule. But how could you write a function that can integrate any real valued function from $a$ to $b$ using the rectangle rule? Interfaces solve this problem.
