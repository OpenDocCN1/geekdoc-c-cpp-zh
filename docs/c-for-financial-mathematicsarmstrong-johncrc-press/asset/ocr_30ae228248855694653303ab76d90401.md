```
        out << x[i] <<","<<y[i] <<"\n";
      }
  }
  void writeCSVChart( const string& filename,
      const vector<double>& x,
      const vector<double>& y ) {
    ofstream out;
    out.open( filename.c_str() );
    writeCSVChartData( out, x, y );
    out.close();
  }
```

To make this part of a library we need to declare it in the header:

```
void writeCSVChart( const std::string& filename,
const std::vector<double>& x,
const std::vector<double>& y );
```

The function declaration in the header, uses the qualification `std::` a lot. We’ve had to fully qualify every type name. The reason is that you should never write `using namespace std;` in a header file so unfortunately all these boring `std::` prefixes are required.

Together these two functions give a very sensible solution to the problem of writing a chart in C++. It doesn’t feel very satisfying, however, because one still has to manually turn the data into a chart using the spreadsheet program. We can do a little better.
