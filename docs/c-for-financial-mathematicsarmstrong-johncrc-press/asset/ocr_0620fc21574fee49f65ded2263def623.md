# 7.2.3  Pass by reference without const

We have seen that pass by reference without the `const` keyword can lead to unwanted side effects. Nevertheless, there are times when you actually want a function to change its parameters.

One example is that C++ does not allow you to return multiple values. You can use pass by reference to get round this.

As an example, suppose that we want to write a function to convert the polar coordinates $(r, \theta)$ into the Cartesian coordinates $(x, y)$. We cannot write a function that returns two doubles, so instead we write a function that doesn't return anything, but modifies two variables $x$ and $y$ that are passed in by reference.

```
```cpp
void polarToCartesian( double r, double theta,
                       double& x, double& y ) {
  x = r*cos(theta);
  y = r*sin(theta);
}
```
```

Here is an example of how to use this function:

```
```cpp
static void testPolarToCartesian() {
  double r = 2.0;
  double theta = PI/2;
  double x=0.0, y=0.0;
  polarToCartesian(r, theta, x, y);
  ASSERT_APPROX_EQUAL( x, 0.0, 0.001 );
  ASSERT_APPROX_EQUAL( y, 2.0, 0.001 );
}
```
```
