**Tip: Returning pointers**

Never return a pointer to a local variable. If you wish, you may return pointers to member variables of an object. In this case it is the object’s job to make sure the data is deleted rather than the job of the caller. (See Section 16.2 for information on how to achieve this using *destructors*)
