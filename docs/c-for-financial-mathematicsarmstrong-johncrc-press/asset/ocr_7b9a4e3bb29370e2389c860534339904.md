# **Tip: Start counting at 0**

C++ programmers start counting at 0. This is a matter of convention. All the standard data structures in C++ are labelled so that they start with 0.

You might not like it at first, but I strongly recommend that when programming in C++ you start counting from 0 and so use < signs rather than <= signs to compensate.
