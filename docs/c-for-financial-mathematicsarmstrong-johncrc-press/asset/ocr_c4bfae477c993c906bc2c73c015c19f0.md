(v) **More natural programming:** *Very occasionally* a program will be simpler to write if you use multiple threads.

However, there is a price to be paid for all these positive benefits. Here are some of the pitfalls one must consider before deciding to write a multi-threaded program.

+   (i) **Complexity:** Multi-threaded code is much harder to write and understand than single-threaded code.

(ii) **Testability:** Multi-threaded code is much harder to test than single-threaded code.

(iii) **CPU Performance:** Using multiple threads can actually slow your computer down if the code is not written well. This is because there is some overhead in sending data between threads. If your code spends most of its time moving data from one thread to another it will perform badly.

(iv) **Difficulty:** The human brain seems to struggle with parallel processing. We’re all quite hopeless at multi-tasking and we’re all quite bad at writing multi-threaded code.
