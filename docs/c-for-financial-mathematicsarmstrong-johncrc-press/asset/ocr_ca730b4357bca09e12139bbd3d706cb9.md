# 15.3 Debugging with GDB

GDB (Gnu Debugger) is a free debugger and is the standard debugger to use on Unix systems. If you are working on Windows you should skip this section and read Section 15.4.

GDB has a command line interface which is not particularly user friendly. In practice if you are developing C++ on Unix you may want to consider using some form of “GDB front end” that makes it easier to use. For example you can integrate GDB with popular text editors such as up vim and emacs. There are also integrated development environments available, such as Eclipse. However, we will only discuss how to use GDB from the command line.
