# # Digital Evidence

Digital evidence is information stored or transmitted in binary form that may be relied on in court.

It can be found on a computer hard drive, a mobile phone, a personal digital assistant (PDA), a CD, a DVD, or a memory card, among other places.

# ### Digital Evidence Can Be Found In:

+   - Computers
+   - Mobile phones
+   - Personal digital assistants (PDAs)
+   - CDs and DVDs
+   - Memory cards
+   - Digital cameras
