以下是使用 set_intersection 求 A 与 B 的交集并将结果存储在 C 中的示例，其中所有集合都是字符串集合：

```
#include <iterator>
#include <set>
#include <string>
...
set<string> C;
// Note space between >> in line below
insert_iterator<set<string> > cIterator(C, C.begin());

                B.begin(),B.end(),
                cIter);
// set C now contains the intersection of A and B
```
