If the counter reaches zero, then the object can be safely deleted and the allocated memory returned to the freestore. This is all performed automatically, which frees the programmer from having to write his or her own memory management code!

This means that the program has a memory leak when execution returns to the main function. This could cause memory problems if the program did not immediately exit.
