# 2. Building a Sorted List

The program in Fig. 15.31 can be used to create a sorted list. This is possible by creating ‘one item’ list using the create function and then inserting the remaining items one after another using insert function.

A new program that would build a sorted list from a given list of numbers is shown in Fig. 15.32. The main function creates a ‘base node’ using the first number in the list and then calls the function insert_sort repeatedly to build the entire sorted list. It uses the same sorting algorithm discussed above but does not use any dummy node. Note that the last item points to NULL.
