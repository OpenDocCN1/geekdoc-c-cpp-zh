## 字符串处理

### 9.1 引言

字符串是字符的数组。我们在之前的许多示例中使用过字符串。任意一组字符（双引号除外）放在双引号之间，就构成一个字符串常量。

例如：

> “人显然是为了思考而被创造出来的。”

如果要在字符串中包含双引号，可以像下面这样使用反斜杠：

> "\" Man is obviously made to think, \" said Pascal."

例如，

```c
printf("\"Well Done !\" ");
```

将输出字符串

> “干得好！”

而语句

```c
printf("Well Done !");
```

将输出字符串

干得好！

字符串通常用于构建有意义且可读性强的程序。对字符串执行的常见操作包括：

- 读写字符串。
- 组合字符串。
- 将一个字符串复制到另一个字符串。
- 比较字符串是否相等。
- 提取字符串的一部分。
