# Post-order traversal:

Post-order traversal is defined as follows:

+   1. traverse the left sub-tree
+   2. traverse the right sub-tree
+   3. process the root node.

# Algorithm for post-order traversal :

+   1. check if tree is empty by verifying root pointer R. Print tree empty if R=NULL, then print "tree empty"
+   2. if leftptr(R)!=NULL then call post-order (leftptr(R))
+   3. Print data(R).
+   4. if rightptr(R)!=NULL then call post-order(rightptr(R))
+   5. return.
