# 11.7 POINTER INCREMENTS AND SCALE FACTOR—ADDRESS ARITHMETIC

We have seen that the pointers can be incremented like p1 = p2 + 2; and so on. Remember, however, an expression like p1++; will cause the pointer p1 to point to the next value of its type. For example, if p1 is an integer pointer with an initial value, say 2800, then after the operation p1 = p1 + 1, the value of p1 will be 2802, and not 2801. That is, when we increment a pointer, its value is increased by the length of the data type that it points to. This length is called the scale factor.
