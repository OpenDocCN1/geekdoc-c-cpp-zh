# Nested or if Else Statement

General form:

```
If(condition 1)
{
    If(condition 2)
    {
        Statement 1;
    }
    Else
    {
        Statement 2;
    }
}
Else
{
    Statement 3;
}
Statement x;
```

In nested if else series if decisions are involved. It has more than one if else statements.
