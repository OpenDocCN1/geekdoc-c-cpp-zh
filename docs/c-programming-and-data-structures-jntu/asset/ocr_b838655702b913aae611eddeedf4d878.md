1. What are different types of control statements available in 'C'. Explain them with an example ?

Ans: Control statements are also called as decision making statements. They are:

+   1. If statement
+   2. Switch and break statements
+   3. Conditional operator statement
+   4. Go to statement

Let us discuss these statements in detail with examples.



If statement is a powerful decision making statement and is called to control the flow of execution of statements. It is implemented in different forms



General form:

```
if(expression)
{
	Statements ;
}
Statements;
```
