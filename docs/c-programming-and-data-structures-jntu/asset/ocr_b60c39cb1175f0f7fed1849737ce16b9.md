During execution of the program, the system always associates the name quantity with the address 5000. (This is something similar to having a house number as well as a house name.) We may have access to the value 179 by using either the name quantity or the address 5000. Since memory addresses are simply numbers, they can be assigned to some variables which can be stored in memory, like any other variable. Such variables which hold memory addresses which are called pointers. A pointer is, therefore, nothing but a variable that contains an address which is a location of another variable in memory.
