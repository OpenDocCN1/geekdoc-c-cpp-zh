int *rowptr[SUBJECTS+1];

would declare rowptr as an array of SUBJECTS+1 elements.

When we increment the rowptr (by rowptr+1), the incrementing is done in units of the size of each row of array, making rowptr to point to the next row. Since rowptr points to a particular row, (*rowptr)[x] points to the xth element in the row.
