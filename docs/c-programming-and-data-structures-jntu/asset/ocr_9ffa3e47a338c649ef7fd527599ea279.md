The declaration part of main function declares not only the variables but the functions mul and div as well. This only tells the compiler that mul will return a float-type value and div a double-type value. Parentheses that follow mul and div specify that they are functions instead of variables. If we have a mismatch between the type of data that the called function returns and the type of data that the calling function expects, we will have unpredictable results. We must, therefore, be very careful to make sure that both types are compatible.
