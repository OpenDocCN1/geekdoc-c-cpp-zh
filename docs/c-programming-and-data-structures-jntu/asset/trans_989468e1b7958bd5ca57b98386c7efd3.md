## 15.12 双向循环链表

### 使用链表的队列

与栈类似，在使用链表实现队列时，必须定义一个节点。正如我们所知，队列的前端用于删除数据，后端用于添加数据。使用链表表示队列的优点是它允许我们选择任意一端来添加和删除数据项。
