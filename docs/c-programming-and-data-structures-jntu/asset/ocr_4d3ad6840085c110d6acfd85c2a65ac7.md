# 15.12 DOUBLY LINKED CIRCULAR LISTS

In a circular or singly linked list, if we want to add data items in the middle of the list, we have to search the entire list. For example, consider a list shown in Fig. 15.20. To add a new node Y before a node Z: We can change the pointer field of Y to point to Z. But we do not know the address of the node X that precedes the node Z.
