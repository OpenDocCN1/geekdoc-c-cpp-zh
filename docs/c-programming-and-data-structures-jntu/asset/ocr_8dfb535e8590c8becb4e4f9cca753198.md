# Example 7.6

A program to evaluate the series 1/(1-x) = 1 + x + x^2 + x^3 + ..... + x^n for -1 < x < 1 to evaluate to 0.01 per cent accuracy is given in Fig. 7.9. The goto statement is used to exit the loop on achieving the desired accuracy.

We have used the for statement to perform the repeated addition of each of the terms in the series. Since it is an infinite series, the evaluation of the function is terminated when the term x^n reaches the desired accuracy. The value of n decides the number of loops operations is not known and therefore we have decided arbitrarily a value of 100, which may or may not result in the desired level of accuracy.

```
/*
************** EXAMPLE OF EXIT WITH goto STATEMENT **************/
#define LOOP 100
#define ACCURACY 0.0001
main()
{
int n, term, sum;
printf("Input value of x: ");
scanf("%f", &x);
sum = 0;
for(term = 1, n = 1; n <= LOOP; ++n)
{
term *= term;
if(term <= ACCURACY)
goto EXIT;
sum += term;
}
term *= x;
/* EXIT FROM THE LOOP */
}
```
