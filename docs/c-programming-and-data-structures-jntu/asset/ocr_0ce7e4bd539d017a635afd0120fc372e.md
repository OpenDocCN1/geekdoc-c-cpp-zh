# MS-DOS System

The program can be created using any word processing software in non-document mode. The file name should end with the characters “.c”, like program.c, pay.c, etc. Then the command

```
MSC pay.c
```

under MS-DOS operating system would load the program stored in the file pay.c and generate the object code. This code is stored in another file under the name pay.obj. In case any language errors are found, the compilation is not completed. The program should then be corrected and compiled again. The linking is done by the command LINK pay.obj which generates the executable code with the filename pay.exe. Now the command pay would execute the program and give the results.
