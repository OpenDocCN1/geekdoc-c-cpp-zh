# Overloading Unary Operators

Unary operators are those operators that operate on a single operand. Some examples of unary operators are logical NOT (!), increment (++), decrement (--), and address of (&). Let’s overload the increment operator in the following program:

```
1:/* Operator Overloading Example Program 1 */
2:#include <iostream.h>
3:using namespace std;
4:
5:class TickCounter {
6:    int count;
7:public:
8:TickCounter()
9:{
10:    count=0;
11:}
12:int getCount()
13:{
14:    return this->count;
15:}
16:void operator ++()
17:{
18:    ++count;
19:}
20:};
21:
22:int main()
23:{
24:    TickCounter obj1, obj2;
25:
26:    cout<<"The value of Obj1 = "<<obj1.getCount()<<endl;
27:    cout<<"The value of Obj2 = "<<obj2.getCount()<<endl;
28:
29:    ++obj1;
30:    ++obj2;
31:    ++obj2;
32:
33:    cout<<"\nThe value of obj1 = "<<obj1.getCount()<<endl;
34:    cout<<"The value of obj2 = "<<obj2.getCount()<<endl;
35:
36:    return 0;
37:}
```

In the preceding program, we have declared a TickCounter class, with a single member variable count. The TickCounter class also holds a constructor function to initialize the count, a member function getCount() to fetch the value of the counter variable count, and a function for the overloaded ‘++’ operator. In the main() function, we have declared two objects of the TickCounter class, named obj1 and obj2. As soon as the objects are declared, the constructor function is executed and the data members are initialized for each declared object. To check whether the initialization part is done properly, we have printed the values of the member variables for both the objects in line numbers 26 and 27.
