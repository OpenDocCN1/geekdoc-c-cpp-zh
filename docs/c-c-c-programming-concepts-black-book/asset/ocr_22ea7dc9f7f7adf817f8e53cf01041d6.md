+   - Postfix Notation—In this type of notation, operators are written after their operands. The operators are evaluated from right to left and they act on the two nearest values on the left. In the postfix notation, the addition expression between A and B would be as follows:
+   
+     AB +

The postfix notation is also known as Reverse Polish notation.

Now, let's learn about various asymptotic notations that are used to describe the complexities of algorithms.

# ## Complexity of an Algorithm

An algorithm is a sequence of instructions that takes data as input and transforms it into output. Therefore, it is a well-defined set of instructions to manipulate the data given by a user or machine. Complexity of an algorithm is defined as a function that calculates the time required to complete the set of instructions (time complexity) and the space required to store the intermediate data (space complexity). Therefore, we can say that complexity is the time and space used by an algorithm.

Complexity of an algorithm is expressed using certain notations known as asymptotic notations. These asymptotic notations help in comparing the complexities of two algorithms. Following are different types of asymptotic notations :

+   - Big "Oh" notation
+   - Big "Omega" notation
+   - Big Theta notation
+   - Small "Oh" notation
+   - Small "Omega" notation

Let's start the discussion with the Big "Oh" notation.

# ### Big "Oh" Notation

Big "Oh" or Big-O notation is used to express the upper bound of runtime of an algorithm. Generally, it can be defined as follows:

For function g(n), Big-O of n (O(g(n))) is defined as,
O(g(n)) = { f(n) : there exists positive constant c and n₀ such that 0 ≤ f(n) ≤ cg(n) ∀ n ≥ n₀ }
