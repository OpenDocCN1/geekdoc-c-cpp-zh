# Chapter 13

Object-Oriented Programming (OOP) defines the concepts of classes and objects. A class is a data structure, which closely resembles a real-world entity. It contains data types and methods, which represent the attributes as well as behavior of real-world entities. An object is an instance of the class. The important OOP concepts are data abstraction, encapsulation, and polymorphism. Data abstraction refers to the use of data without knowing how the data is stored or implemented. Encapsulation is the process of hiding those details of an object that do not contribute to the significant characteristics of that object. Polymorphism implies a language’s capability to handle an object differently depending on its runtime. Some examples of OOP languages are C++, Java, and C#.

In this chapter, we first learn about the different paradigms for problem solving. Next, we learn about abstraction as well as the differences between OOP and procedure programming. Then, we get an overview of the OOP principles namely encapsulation, inheritance, and polymorphism. The chapter also discusses OOP, objects, and classes. Further, we learn about constructors, destructors, class members, data abstraction, and information hiding. The chapter also provides the relationships between classes and their components using the diagrammatic representations.

# Different Paradigms for Problem Solving

A programming paradigm is usually a basic style of computer programming. Paradigms for problem solving varies in the concepts and abstractions that are helpful in representing the elements of a program, such as materials, functions, variables, constraints, and the steps that comprises evaluation, continuations, and data streams. Three types of paradigm involved in problem solving are imperative, logical, and functional.

Let’s discuss these three types starting from the imperative programming paradigm.

# Imperative Programming Paradigm

The imperative programming paradigm signifies how a computer can preserve itself in case any environment variable changes. In other words, if the environment variables change, then a computer can preserve itself so that it does not undergo any functional changes.

In the imperative programming, computations are performed by a predefined sequence associated with the steps where environment variables are known or altered. Therefore, the order of the steps is essential because a step may have different consequence with respect to the current values of variables, once it is performed.
