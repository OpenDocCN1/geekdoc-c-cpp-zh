### Static Functions

Similar to static variables, C also defines the concept of having static functions. Static functions work similar to global static variables. If a function is declared as static, then that function is only visible inside the file in which it is declared. It means that this function cannot be accessed from any other file, which is a part of the program. To declare a static function, we need to precede the name and return type of the function with a static keyword, as shown in the following code snippet:

```c
static int myFunction();
```

The preceding code snippet describes a static function in C.

String is a special type of array that is used to store a group of characters. Therefore, strings are also known as character arrays. Similar to arrays, elements of a string are also stored in a contiguous memory location.

The C language provides various standard library functions to manipulate a string. Some of the important library functions for string manipulation are strcat(), strcmp(), strlen(), and strcpy(). The strcat() function concatenates a string with another string. The strcmp() function is used to compare two strings. The strlen() function returns the length of a string. The strcpy() function copies the content of a string into another. To use these functions in a program, we need to include the <string.h> header in it.

In this chapter, we learn about strings as well as how to display them using pointers and the printf() function. Next, we learn about some standard string library functions, such as strcat(), strcmp(), strlen(), strcpy(), strncpy(), strncat(), strchr(), and strcspn().

### Strings

A string is a one-dimensional array of characters, which is terminated by a NULL character ('\0'). Each character in a string occupies one byte of memory and the last character should always be '\0'. It might look like '\0' contains two characters, but '\' is used as an escape sequence, which signifies that the character after '\' is a special character. Note that '\0' and '0' are not similar characters because '\0' has an ASCII value 0; whereas, '0' has an ASCII value 48. Consider the code, given in Listing 3.1, to understand more about the NULL character:

Listing 3.1: Understanding the NULL Character in a String

```c
#include<stdio.h>

int main()
{
    char a[] = "Tanuman";
    int i=0;

    while(a[i]!='\0')
    {
        printf("%c",a[i++]);
    }

    getch();
    return 0;
}
```

In Listing 3.1, we can notice that the string has been displayed without considering its length. This is done because all the strings are automatically terminated by a NULL character; therefore, there is no need to check the length of the string. This implies that we do not need to define the NULL character explicitly in a string, as the compiler always puts a NULL character at the end of a string.

Output of the preceding program is as follows:

```
Tanuman
```

Let's now learn how to display a string using pointers and the printf() function.

Listing 3.2 displays a string using a pointer:

Listing 3.2: Displaying a String Using a Pointer

```c
#include<stdio.h>

int main()
{
    char a[] = "Tanuman";
    char *ptr;
    ptr = a;
    while(*ptr != '\0')
    {
        printf("%c", *ptr);
        ptr++;
    }
    getch();
    return 0;
}
```

The technique used in Listing 3.2 is similar to that of traversing an integer array using pointers. For this, we have taken the base address of the array and stored it inside a character pointer. In Listing 3.2, the following statement is used for the address assignment:

```c
ptr = a;
```

The value at the pointer can be displayed using the following statement:

```c
printf("%c", *ptr);
```

After displaying the value, the pointer is incremented to point to the next character in the string. The preceding statement also implies that the characters are stored in a contiguous memory location inside a string.

Output of the preceding program is as follows:

Tanuman

Another way of displaying a string is by using the printf() function. The function has a format specifier called ‘%s’, which is used to display a string. Listing 3.3 shows the code to display a string using the printf() function:

Listing 3.3: Displaying a String using printf()

```c
#include<stdio.h>

int main()
{
    char a[] = "Tanuman";

    printf("%s",a);
    getch();
    return 0;
}
```

Output of the preceding program is as follows:

Tanuman

The format specifier ‘%s’ can also be used for taking string inputs. The input is taken by using the scanf() function with the format specifier ‘%s’, as follows:

```c
scanf("%s", a);
```

The scanf() function would fill the characters typed from the keyboard into the character array. The process continues until the Enter key from the keyboard is pressed. After the Enter key is pressed, the scanf() function puts the NULL character at the end of the character array.

Some points need to be kept in mind while using scanf() with the ‘%s’ format specifier. First, C compilers do not perform bound checks of character arrays. Therefore, any set of characters that are entered should not exceed the length of the character array. If a set of characters exceeds the length of the character array, then there might be chances of content overwriting in the memory. Another important point is that scanf() cannot take spaced strings as an input. For example, if the input is ‘Tanuman Bhaduri’, then scanf() will only receive ‘Tanuman’ and all the characters after the white space will be omitted. To get rid of this problem, C provides the gets() function, which takes the strings along with the spaces in them. Similarly, C provides the puts() function to display a string that has spaces in between. Listing 3.4 shows the usage of gets() and puts().
