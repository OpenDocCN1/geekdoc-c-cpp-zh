# Multi-Level Inheritance

Till now, we have discussed mostly about the base class and derived class involving only single level of inheritance. However, classes can be derived from classes that are themselves derived; this phenomenon is called multi-level inheritance. In real world scenario, we need multi-level inheritance to model scenarios, such as hierarchical relationships for maintenance of company data. Consider the following code snippet:

```
```
class Base
{
    ..........
};
class Derv1 : public Base
{
    ..........
};
class Derv2 : public Derv1
{
    ..........
};
```
```

In the preceding code snippet, the Derv1 class is derived from the Base class. Similarly, the Derv2 class is derived from the Derv1 class. This process can be repeated for arbitrary number of levels; for example, Derv3 can be derived from Derv2 and Derv 4 can be derived from Derv3.

When a derived class is used as a base class for another derived class, any protected member of the initial base class that is inherited (as public) by the first derived class may also be inherited as protected again by a second derived class.
