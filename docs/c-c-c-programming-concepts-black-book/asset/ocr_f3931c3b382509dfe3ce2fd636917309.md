# Different Types of the IF Expression

We can provide different sorts of expressions inside an if statement. Note that it is not mandatory to have relational operations taking place in an if statement. The following are some examples of valid if statements:

```
1.  if(5+4>3)
    printf("\n This is valid");
2.  if(varA == 10)
    printf("\n This is valid");
3.  if(-5)
    printf("\n This is valid");
```

In C language, a non-zero value is considered to be true and zero as false. The if statement only works if the expression provided evaluates to a true value. In the first example, a logical computation is taking place, yielding a non-zero result. In the second example, a positive value is assigned to the variable varA. After assignment, the value of the variable is tested, as the variable contains a non-zero value. The same condition is applied for negative values, as shown in the third example.

# Multiple IF Statements

It is possible to have multiple statements inside an if statement. For this, a group of statements needs to be placed within a pair of curly braces. If curly braces are not provided, then the if clause will take up only a single statement and the rest will be ignored.

Listing 1.8 shows how to write multiple if statements:

**Listing 1.8: Writing Multiple IF Statements**

```
#include<stdio.h>

int main()
{
        int varA;
        printf("\n Enter a integer ");
        scanf("%d",&varA);

        if(varA > 10)
                printf("\n Statement is true ");
                printf("\n Inside IF ");
        getch();
}
```

The output of Listing 1.8 is given as follows:

```
    Enter a integer 5

        Inside IF
```

In Listing 1.8, we have given multiple statements inside a single if statement. As no parenthesis are used in the code, all the statements are not considered as part of the if statement.
