Let's discuss some of the time functions, in detail.

# ### asctime()

The asctime() function returns a pointer to a string. The prototype of the function is defined within the <time.h> header. The signature of the asctime() function is as follows:

```
~~~c
char *asctime(const struct tm *ptr);
~~~
```

The preceding function contains information stored in a structure ptr, which is passed as an argument to it. The structure pointed to by ptr is obtained from either the gmtime() function or the localtime() function. The buffer used by the asctime() function is a statically allocated array, which is overwritten every time the function is called.

The format of the output returned by the asctime() function is as follows:

```
~~~
day month date hours:minutes:seconds year\n\0
~~~
```

Let's take an example of the asctime() function as mentioned in Listing 8.16:

Listing 8.16: Usage of asctime() function.

```
~~~c
#include<stdio.h>
#include<time.h>
int main()
{
    struct tm *ptr;
    time_t t1;
    t1 = time(NULL);
    ptr = localtime(&t1);
    printf("\n The current time is %s ",asctime(ptr));
    getch();
}
~~~
```

Output of the preceding example is as follows:

```
~~~
The current time is Mon Mar 26 16:02:32 2012
~~~
```

# ### ctime()

The ctime() function takes a pointer to a calendar type variable as an argument. The calendar time is obtained from the call to the time() function. The buffer used by the ctime() function is a statically allocated buffer, which is overwritten every time it is called. The signature of the ctime() function is as follows:

```
~~~c
char *ctime(const time_t *time);
~~~
```

The ctime() function returns a pointer to a string in the following format:

```
~~~
day month year hours:minutes:seconds year\n\0
~~~
```

Let's take an example of the ctime() function as mentioned in Listing 8.17:

Listing 8.17: Usage of ctime()function.

```
~~~c
#include<stdio.h>
#include<time.h>

int main()
{
    time_t t1;
    t1 = time(NULL);
    printf("\n The current time is %s ",ctime(&t1));
    getch();
}
~~~
```
