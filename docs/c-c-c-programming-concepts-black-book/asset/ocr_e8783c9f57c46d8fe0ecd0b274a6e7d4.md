+   - **Stack Address (POSIX_THREAD_ATTR_STACKADDR)** — The stackaddr attribute defines the base of the thread’s stack. It is set to non-null and the system initializes the stack at the given address.
+   - **Stack Size (Default PTHREAD_STACK_SIZE set in pthread.h)** — The stack size is the size of the stack, which is used by a pthread during runtime.

A thread created in a joinable state can be made detachable by calling pthread_detach() with the thread ID, as follows:

```
int pthread_detach (pthread_t thread);
```

Note that once a thread is made detachable, it cannot be made joinable again.

One of the most interesting attribute state of a thread is the detach state. The following statement sets the value of the detach state for the current thread, for which it is called:

```
int pthread_setdetachstate (pthread_attr_t * attr, int *detachstate);
```

In the preceding statement, we have placed the detach state as the second argument.

The detach state can take the following two values:

+   - PTHREAD_CREATE_DETACHED
+   - PTHREAD_CREATE_JOINABLE

Let’s consider the following program to explore the detachstate thread attribute and show how a child thread can be cleaned up without calling pthread_join():

```
/* thread4.c – Demonstrating pthread_attribute handling for detachstate */
#include <stdio.h>
#include <pthread.h>

void* thread_function (void* thread_arg)
{
    /* Do work here... */
    printf("\nI am a new thread. I am detached\n");
    sleep(20);
    printf("\nI am a new thread. I am exiting\n");
}

int main ()
{
    pthread_attr_t attr;
    pthread_t thread;
    pthread_attr_init (&attr);
    pthread_attr_setdetachstate (&attr, PTHREAD_CREATE_DETACHED);
    pthread_create (&thread, &attr, &thread_function, NULL);
    pthread_attr_destroy (&attr);

    printf("\nThis is main thread. I am not waiting for the other thread\n");
    /* No need to join the thread. */
    sleep(30);
    printf("\nThis is main thread. I am exiting\n");
    return 0;
}
```

In the preceding program, we have defined an object of the pthread attribute type and set the detach state as PTHREAD_CREATE_DETACHED. We have also passed this attribute object as an argument to the pthread_create() API. The newly created thread has the detach state set as CREATE_DETACHED. This implies that whenever a child thread terminates, it will be automatically cleaned up; and thereby, there is no need to call pthread_join() explicitly for the thread.
