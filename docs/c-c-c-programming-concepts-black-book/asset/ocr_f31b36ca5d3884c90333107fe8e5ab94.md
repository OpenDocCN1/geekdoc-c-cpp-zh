# # Utility Functions

Utility functions can be used for the processing of variable-length arguments, sorting, searching, and generating random numbers. Moreover, some utility functions, such as abort(), can be used for terminating a program abnormally; thereby, avoiding the system crash and other anomalies. To use the utility functions, we need to include the <stdlib.h> header in a program.

Let's discuss some utility functions, in detail.

# ## abort()

The abort() function causes the immediate abnormal termination of a program. The signature of the abort() function is as follows:

```
void abort(void);
```

The abort() function returns an implementation-defined value to the calling process. Let's take an example of the abort() function as mentioned in Listing 8.26:

**Listing 8.26: Usage of abort () function.**

```
```c
#include<stdio.h>
#include<stdlib.h>
int main()
{
    int input;
    printf("\n Enter a value -> ");
    scanf("%d",&input);
    if(input %2)
    {
        printf("\n Before Abort ");
        abort();
        printf("\n After Abort ");
    }
    getch();
    return 0;
}
```
