## Introducing the File Compression Technique

To transfer a file having a large size over a slower network connection, we usually need to wait for a long time for the successful transfer of the file. Moreover, sometimes it may happen that the Internet does not have the bandwidth to transfer that file. This problem can be solved with the help of file compression, which is a simple technique to compress the file in a manner that it contains the original data, but only the redundancy has been removed. Therefore, whenever we need to download a huge chunk of data files from the Internet, they appear as a zip file that contains all the necessary data files. Usually, either WinZip or 7Zip is installed in a computer system to unzip the file and extract the data files in it. During the unzip process, it puts the repetitive words in the right place to prepare the file with the same size that it had before the compression.

In the .NET environment, we can compress a set of files and produce a compressed folder by using an open source library, namely ICSharpCode.SharpZipLib. It is a free open source dll implemented for writing C# codes for zip and unzip functionalities. It is implemented as an assembly, which means that it can be installed in global assembly cache. Therefore, only incorporating the dll in a project will do the needful. The library mainly provides the Zip, GZip, BZip2, and Tar implementations for .NET.

One of the important namespaces in the ICSharpCode.SharpZipLib library is the ICSharpCode.SharpZipLib.Zip namespace (which we will use to create an application later in this chapter). Table 21.8 lists the noteworthy classes of the ICSharpCode.SharpZipLib.Zip namespace:

Listing 21.16 shows the code for the `CompressFile` method:

### Listing 21.16: Showing the Code for the CompressFile() Method

```csharp
public static void CompressFile(string zipFileName, string path)
{
    //Creating the zip file at the output location
    FileStream fileStream = File.Create(zipFileName);
    ZipOutputStream zipOutputStream = new ZipOutputStream(fileStream);

    //Setting the level of compression
    zipOutputStream.SetLevel(9); //9 defines the best compression
    string[] fileList = Directory.GetFiles(path);

    //Checking the existence of the file
    if (fileList.Length == 0)
    {
        fileStream.Close();
        File.Delete(zipFileName);
    }
    else
    {
        foreach (string file in fileList)
        {
            ZipEntry zipEntry = new ZipEntry(Path.GetFileName(file));
            zipEntry.DateTime = DateTime.Now;
            byte[] buffer = new byte[4096];
            zipOutputStream.PutNextEntry(zipEntry);

            using (FileStream fs = File.OpenRead(file))
            {
                int bufferBytes;
                do
                {
                    bufferBytes = fs.Read(buffer, 0, buffer.Length);
                    zipOutputStream.Write(buffer, 0, bufferBytes);
                } while (bufferBytes > 0);
            }
            zipOutputStream.CloseEntry();
        }
    }

    // Finish is important to ensure trailing information for a Zip file is appended.
    // Without this, the created file would be invalid.
    zipOutputStream.Finish();
    //Releasing the held resources
    zipOutputStream.Close();
}
```

The steps involved in the CompressFile() method are as follows:

- 1. It takes the file name and the output location path as its two arguments. Then, it creates a file with the extension zip in the output location path and returns an object of FileStream.
- 2. It creates an object of ZipOutputStream for the FileStream object and sets the level of compression to 9, which is considered to be the best compression. Normally, a compression level is set from 0 to 9.
- 3. It gets the list of files available in the directory. If the directory does not contain any file, then it deletes the file that was created with the extension zip in the output location. Otherwise, it processes the whole operation.
- 4. If the directory contains the files, then for each file, it creates an object of the ZipEntry class and set the date time of the file as the current date time.
- 5. It defines the buffer storage as an array of bytes that holds the intermediate file data that is going to be written on the new file inside the zipped folder. In our case, we have chosen the buffer storage as 4 K since it defines the optimum storage.
- 6. Before writing the file content in the new file inside the zipped folder, it puts an entry of the ZipEntry object in the ZipOutputStream object by using the PutNextEntry() method.
- 7. Using the FileStream object, the CompressFile() method reads a portion of the file whose length is equal to the length of the buffer and writes the buffer to the new file using the ZipOutputStream object.
- 8. At the end of the process, it releases all the resources held by the ZipOutputStream object.

Listing 21.17 shows the C# code for the ZipFilesAndFolders() method:

```csharp
public static void ZipFilesAndFolders(string path, string zipFileName)
{
    //Compressing the files inside the folder
    CompressFile(zipFileName, path);
    string[] directoryList = Directory.GetDirectories(path);

    //Compressing the directories inside the folders
    foreach (string directory in directoryList)
    {
        string folderName = directory.Substring
            (directory.LastIndexOf("\\") + 1);
        string folderPath = path + "\\" + folderName + "\\";
        string zipFolderFileName = zipFileName.Substring
            (0, zipFileName.LastIndexOf("\\") + 1) + folderName + ".zip";
        CompressFile(zipFolderFileName, folderPath);
    }
}
```
