# Figure 1.6: Flowchart of the FOR Loop

Figure 1.6 describes the way in which the for loop is executed. First of all, the loop control variable is initialized. After that, the test condition is executed. If the test condition happens to be true, then the body of the for loop is executed and the loop control variable gets incremented by one at the beginning of the next iteration.

Listing 1.31 shows an example to discuss the working of the for loop:

# Listing 1.31: Using the FOR Loop

```
```c
#include<stdio.h>

int main()
{
    int count,sum=0;

    for(count=1;count<=10;count++)
    {
        sum = sum + count;
    }
    printf("\n Sum %d ",sum);
    getch();
}
```
```

Listing 1.31 shows that during the first iteration of the for statement, the loop control variable gets initialized to 1. After initialization, the test condition is executed. If the test condition comes out to be true, the body of the for loop is executed for the first time. While executing the closing brace of the loop, the control again comes back to the for statement. Now, the value of the loop control variable gets incremented by one and then the test conditions are again executed. This sequence of execution continues until the loop control variable reaches a value, which in turn makes the test condition false and the loop terminates. Once the for loop terminates, the control comes to the first statement following the body of the loop. Although initialization is done inside the for loop, it takes place only once. Second iteration onwards, the loop control variable gets modified.

The following code snippet shows an example of a generic for loop:

```
```c
for(initialise loop controller; test condition; increment/decrement loop controller)
{
        body of for loop ;
}
