The format specifier ‘%s’ can also be used for taking string inputs. The input is taken by using the scanf() function with the format specifier ‘%s’, as follows:

```

```
```

The scanf() function would fill the characters typed from the keyboard into the character array. The process continues until the Enter key from the keyboard is pressed. After the Enter key is pressed, the scanf() function puts the NULL character at the end of the character array.

Some points need to be kept in mind while using scanf() with the ‘%s’ format specifier. First, C compilers do not perform bound checks of character arrays. Therefore, any set of characters that are entered should not exceed the length of the character array. If a set of characters exceeds the length of the character array, then there might be chances of content overwriting in the memory. Another important point is that scanf() cannot take spaced strings as an input. For example, if the input is ‘Tanuman Bhaduri’, then scanf() will only receive ‘Tanuman’ and all the characters after the white space will be omitted. To get rid of this problem, C provides the gets() function, which takes the strings along with the spaces in them. Similarly, C provides the puts() function to display a string that has spaces in between. Listing 3.4 shows the usage of gets() and puts().
