# Reading Lines from a File

C also provides the flexibility to read a whole line from a file at a time. To read lines from a text file at a time, we need to use the fgets() function. The generic signature of fgets() is as follows:

```
`char * fgets ( char * str, int num, FILE * stream );`
```

In the preceding signature, str points to the array of characters, where the string to be read is stored; num refers to the number of characters to be read; and stream denotes the pointer to the file object that identifies the stream from where the information is read.

The fgets() function returns the same string that it stored inside the str parameter. Listing 5.20 shows how to read lines from a file.

Listing 5.20: Reading Lines from a File using the fgets() Function

```
```c
#include<stdio.h>

int main()
{
    char *end_char;
    char sentence[100];
    FILE *fp;

    fp = fopen("D:\\readme.txt", "r");

    if(!fp)
    {
        printf("\n Failed to open the file");
        return 0;
    }
    do
    {
        end_char = fgets(sentence, 100, fp);

        if(end_char == NULL) {
            break;
        }

        printf("%s \n", sentence);
    }while(1);

    fclose(fp); /* For closing the file pointer */
    getch();

    return 0;
}
