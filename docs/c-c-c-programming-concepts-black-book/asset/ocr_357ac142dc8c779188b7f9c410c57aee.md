Listing 24.9 shows the algorithm for insertion operation:

# **Listing 24.9:** Showing the Algorithm for Insertion

```
function QueueInsert(queue[maxsize], front, rear, item)
begin
  if rear >= maxsize
    then
      ouput “Queue Overflow”
  end if

  rear = rear + 1
  queue[rear] = item

  if front = 0
    then
      front = 1
  end if
end
```

In Listing 24.9, first we have checked the overflow condition in a queue. If the condition satisfies, then we will declare the queue to be full; else, the rear pointer is incremented by one and the element is inserted at the current rear position of the queue.

Listing 24.10 shows the algorithm for deletion operation:

# **Listing 24.10:** Showing the Algorithm for Deletion

```
function QueueDelete(queue[maxsize], front, rear, item)
begin
  if front = 0
    then
      ouput “Queue Underflow”
      Return
  end if

  item = queue[front]

  if front = rear
    then
      front = 0
      rear = 0
  else
    front = front + 1
```
