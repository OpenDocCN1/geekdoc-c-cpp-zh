Each cell of a two-dimensional array of type int occupies four bytes of data, as an integer takes up four bytes. Now, if we closely look at the preceding output, we will notice that the base address of the array is 2293552. Next, the starting address of the second single dimensional array is 2293564. From the two addresses, we can notice that the difference between the two is 12. These 12 bytes account for those three elements, which are being stored contiguously for the first single dimensional array. Therefore, we can easily say that a two-dimensional array is nothing but a collection of two single dimensional arrays.

When we declare a two-dimensional array, the `arr` pointer points to the base address of the array. Similarly, `*(arr + 1)` gives the 2nd element of the array, which happens to be the base address of the second single dimensional array. In general, the syntax `*(arr + i)` helps us in reaching the ith single dimensional array. After reaching the desired single dimensional array, we should be able to reach to its elements. For instance, as `arr[2][2]` is interpreted as the element residing in the 3rd column of the 3rd row of the array (as it starts from zero), we will reach to the 3rd row with `*(arr + 2)` and then to the 3rd column with `*(*(arr + 2) + 2)`.
