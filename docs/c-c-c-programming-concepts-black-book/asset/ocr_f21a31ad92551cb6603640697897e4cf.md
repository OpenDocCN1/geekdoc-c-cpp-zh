# Dijkstra’s Algorithm

Dijkstra’s algorithm is a graph search algorithm, which solves the single-source shortest path problem for graphs, producing a shortest path tree. The assumption made in this case is that all the costs or weights associated with the edges should be non-negative. Given a vertex in a graph, this algorithm finds the minimum distance between that vertex and every other vertex in the graph. This kind of algorithm is mainly used for communication network and travelling salesperson problems. It is designed to determine the shortest route between the source vertex and every other vertex in the network of a graph.

To explain the algorithm, we need to know some basic shortest distance metrics, on which the entire algorithm has its base. Let’s suppose that uᵢ is the shortest distance from the source vertex to any vertex ‘j’. In addition, let’s define distance dᵢⱼ ≥ 0 as the length of arc (i, j). Then, Dijkstra’s algorithm proceeds by defining the label of an immediately succeeding vertex, say vⱼ, as follows:

$$[u_j, i] = [u_i + d_{ij}, i], \text{ where } d_{ij} \ge 0$$

To start the algorithm, we define the label for the starting vertex as [0, −], which indicates that the vertex has no predecessor. Vertex label in Dijkstra’s algorithm is of two types: temporary and permanent. Initially, we always associate a temporary label with any vertex in a graph. A temporary label is modified if and only if a shorter route to that vertex can be found through some other path ensuring that it remains a tree.
