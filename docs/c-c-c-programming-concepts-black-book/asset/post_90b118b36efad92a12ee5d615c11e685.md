Another approach that leads to an immediate execution of the query is by enforcing the query to be cached to an Array or List by using the ToArray() or ToList() method, respectively. Listing 19.10 shows an example of immediate execution by using the ToArray() method:

**Listing 19.10: Showing an Example of Immediate Execution**

```csharp
using System;
using System.Linq;

class Program
{
    public static void Main()
    {
        //Initializing data source
        int[] list = { 1, 2, 3, 4, 5, 6, 7, 8, 9 };

        //Query holds an object of type int[]
        var query = (from num in list
                     where num % 2 != 0
                     select num).ToArray();

        Console.WriteLine("The odd numbers are...");
        //Executing the query
        for (int i = 0; i < query.Length; i++)
        {
            Console.WriteLine(query[i]);
        }
    }
}
```

Now, let’s discuss the area of usage of LINQ.

### Usage of LINQ

Microsoft has categorized LINQ into three distinct fields according to the area of implementation. These three fields are given as follows:

- LINQ to Object, where LINQ is used to query a set of objects or classes
- LINQ to XML, where LINQ is used to query XML
- LINQ to ADO.NET, where LINQ is used to query relational databases

In this section, we discuss all the three categories of LINQ implementation, in detail.

### LINQ to Object

Object in this respect defines the in-memory collection of items. As C# is an object-oriented language, it mainly deals with the class objects. Therefore, LINQ to Object is used to query the information in the object types of a class. In this case, LINQ is of type `IEnumerable<T>`. Listing 19.11 demonstrates the implementation of LINQ to Object.

**Listing 19.11: Showing the Implementation of LINQ to Object**

```csharp
using System;
using System.Linq;
using System.Collections;
using System.Collections.Generic;

class Program
{
    public static void Main()
    {
        List<Employee> empList = new List<Employee>();
        empList.Add(new Employee(100, "James", "Scott"));
        empList.Add(new Employee(200, "Jonathan", "Jackson"));
        empList.Add(new Employee(300, "Keith", "Scott"));
        empList.Add(new Employee(400, "Jonny", "Lee"));
        empList.Add(new Employee(500, "Amy", "John"));
        empList.Add(new Employee(600, "Leonardo", "Scott"));

        IEnumerable<Employee> empSel = from emp in empList
                                      where emp.lastName.Equals("Scott")
                                      select emp;

        foreach (Employee e in empSel)
        {
            Console.WriteLine("Employee ID: {0} Employee Name: {1}",
                              e.empID, e.firstName + " " + e.lastName);
        }
    }
}

class Employee
{
    public int empID;
    public string firstName;
    public string lastName;

    public Employee()
    {
    }

    public Employee(int id, string firstName, string lastName)
    {
        this.empID = id;
        this.firstName = firstName;
        this.lastName = lastName;
    }
}
```

In Listing 19.11, the Employee class is defined with three member variables: empID, firstName, and lastName. In the Main() method, we have first declared a list of type Employee, which contains some objects, and then the LINQ query is defined to get the list of employees whose last name is Scott. This query is stored in an object of type `IEnumerable<T>`. At the end of the program, the output is printed on the console using the foreach loop. The output of the program is given as follows:

```text
Employee ID: 100 Employee Name: James Scott
Employee ID: 300 Employee Name: Keith Scott
Employee ID: 600 Employee Name: Leonardo Scott
```

### LINQ to XML

In LINQ to XML queries, XML is used as a data source. In this case, LINQ queries are used to map the LINQ statement to the corresponding XML data source. The functionalities used for querying XML data through LINQ are defined in the System.Xml.Linq namespace. In this section, we first learn how to query an XML file whose elements contain attributes. For this, let's create an XML file, Employee.xml, to contain the information of employees. Listing 19.12 shows the content of the Employee.xml file:

**Listing 19.12: Showing the Content of the Employee.xml File**

```xml
<?xml version="1.0" encoding="utf-8" ?>
<Organization>
  <Employees>
    <Employee EmpID ="100" FirstName ="James"
              LastName ="Scott"></Employee>
    <Employee EmpID ="200" FirstName ="Jonathan"
              LastName ="Jackson"></Employee>
    <Employee EmpID ="300" FirstName ="Keith"
              LastName ="Scott"></Employee>
    <Employee EmpID ="400" FirstName ="Johny"
              LastName ="Lee"></Employee>
    <Employee EmpID ="500" FirstName ="Amy"
              LastName ="John"></Employee>
    <Employee EmpID ="600" FirstName ="Leonardo"
              LastName ="Scott"></Employee>
  </Employees>
</Organization>
```

Now, we write a program that shows how to fetch the list of employees whose last name is Scott from the Employee.xml file. Listing 19.13 shows the respective code snippet:

**Listing 19.13: Showing the Implementation of LINQ to XML**

```csharp
using System;
using System.Linq;
using System.Xml.Linq;
using System.Collections;
using System.Collections.Generic;

class Program
{
    public static void Main()
    {
        //Load the XML document
        XDocument doc = XDocument.Load(@"C:\Employee.xml");

        //LINQ Query to get XML elements
        IEnumerable<XElement> query = from child
            in doc.Element("Organization")
            .Element("Employees")
            .Descendants("Employee")
            where child.Attribute("LastName").Value
            == "Scott"
            select child;

        //Get the result
        foreach (XElement ele in query)
        {
            string empID = ele.Attribute("EmpID").Value;
            string firstName = ele.Attribute("FirstName").Value;
            string lastName = ele.Attribute("LastName").Value;

            Console.WriteLine("Employee ID : {0} Employee Name : {1}",
                empID, firstName + " " + lastName);
        }
    }
}
```

In Listing 19.13, we have first loaded the XML document using the Load() method of XDocument class and stored it into an object of the XDocument class. After that, we have written the LINQ query to reach the exact node from where we want to start the search. The XDocument.Descendants("Employee") method traverses through all the child nodes whose parent node is Employee. This query returns a variable of `IEnumerable<XElement>` type. The output of the program is given as follows:

```text
Employee ID : 100 Employee Name : James Scott
Employee ID : 300 Employee Name : Keith Scott
Employee ID : 600 Employee Name : Leonardo Scott
```
