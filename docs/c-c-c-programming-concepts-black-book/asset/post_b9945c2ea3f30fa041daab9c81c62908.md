## Protected

The protected access modifier is used when inheritance is implemented in a program. If we define a member of the base class as protected, the member can be accessed from the class that derives it. Therefore, the access of those members is restricted to the base class and its derived class only. The keyword protected is used to declare a member as protected. Listing 18.32 shows an example of the protected access modifier.

**Listing 18.32:** Showing an Example of the Protected Access Modifier

```csharp
using System;
class Vehicle
{
    protected string type;
}
class Owner
{
}
class Car : Vehicle
{
    static void Main()
    {
        Car car = new Car();
        car.type = "Four-wheeler";
        Console.WriteLine("The type of the car is " + car.type);
    }
}
```

As shown in the preceding program, the Owner class does not derive the Vehicle class; therefore, it will not have any access to the protected members of the Vehicle class. The output of the code is given as follows:

```text
The type of the car is Four-wheeler
```

## Internal

The members of the classes, which are declared internal, can only be accessed from the classes that are defined inside an assembly (or .dll file). We use the internal keyword before the declaration of the class members. Listing 18.33 shows an example of the internal access modifier:

Listing 18.33: Showing an Example of the Internal Access Modifier

```csharp
using System;
class Vehicle
{
    internal string type;
}
class Owner
{
    public void OwnerVehicle()
    {
        Vehicle vehicle = new Vehicle();
        vehicle.type = "Two-wheeler";
        Console.WriteLine("The owner has a " + vehicle.type);
    }
}
class Car : Vehicle
{
    static void Main()
    {
        Vehicle vehicle = new Vehicle();
        vehicle.type = "Four-wheeler";
        Console.WriteLine("The type of the car is " + vehicle.type);
        Owner owner = new Owner();
        owner.OwnerVehicle();
    }
}
```

In the preceding program, the Vehicle class contains an internal variable type, which is referenced in the Owner class as well as in the derived class Car. The output for the program is same as shown for the public access modifier.

## Protected Internal

The protected internal modifier represents a union between the protected and internal modifiers. We use the protected internal keyword to declare a member as protected internal. If a member of the class is declared as protected internal, then it has the following accessibility:

- Inherited classes belonged to different assemblies can access protected internal member of the current assembly
- Members that reside inside the same assembly can access the protected internal members

## Explicit Interface

An interface is said to be explicit if the methods of the class are defined on the interface. The method definition, as shown in Listing 18.36, is an explicit declaration of interface.

**Listing 18.36:** Defining an Interface Method Explicitly Inside a Class

```csharp
interface IInterface
{
    void Imethod();
}
class Iclass : IInterface
{
    //Explicit declaration of interface method
    public void IInterface.Imethod()
    {
        Console.WriteLine("This is an example of implicit interface");
    }
}
```

We use the explicit definition of an interface when a class inherits more than one interface that has the same name. Listing 18.37 shows an example of explicit interface.

Listing 18.37: Showing an Example of Explicit Interface

```csharp
using System;
class Program
{
    public static void Main()
    {
        GUIClass gui = new GUIClass();
        //Explicitly cast the IWin interface
        ((IWin)gui).GetMenu();
        //Explicitly cast the IOther interface
        ((IOther)gui).GetMenu();
    }
}
interface IWin
{
    void GetMenu();
}
interface IOther
{
    void GetMenu();
}
class GUIClass: IWin, IOther
{
    //Explicit definition of the methods of two interfaces
    void IWin.GetMenu()
    {
        Console.WriteLine("Windows menu is called");
    }
    void IOther.GetMenu()
    {
        Console.WriteLine("Other menu is called");
    }
}
```

In Listing 18.37, we have defined the two interfaces, IWin and IOther, where both the interfaces declare the same method called GetMenu(). Next, we have declared a class named GUIClass where we have explicitly defined the methods of the two interfaces. The Main() method declared inside the Program class calls the interface methods by casting the interface to the class instance; thereby, allowing type safety. It is a good practice to use the explicit interface when a program deals with more than one interface definitions. The output of the preceding program is given as follows:

```text
windows menu is called
Other menu is called
```

## Enumerators

Enumeration is a strongly typed constant whose underlying type is integral. Enumerators are used to group some constants to define definite properties of an object whose underlying type will be defined by a user. While handling the enumerators, we need to know the following important points:

- Underlying type of an enumerator can be any integral type except char.
- Enumerator of one type cannot be implicitly assigned to the enumerator of another type even though the underlying members are same. That's why it is called strongly typed.
- Enumerators cannot be inherited as it is a value type and contain their own specific values.
- If underlying types are not defined explicitly, then integers starting from 0 are assigned to the members of the enumerator type automatically.
