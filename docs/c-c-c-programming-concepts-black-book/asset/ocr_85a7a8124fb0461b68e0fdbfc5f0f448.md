# LINQ Queries

A query is a way to fetch the desired set of data from a data source. It is a set of instructions that describes which data to be fetched and what would be the format of the data. To fetch data from different data sources, we need to learn different query languages that have been developed for the data sources. For example, to work with SQL or Extensible Markup Language (XML), we need to learn SQL or XQuery. On the other hand, LINQ provides a consistent model using which we can work with different data sources without learning different query languages. Therefore, whether we query an XML database, SQL database, ADO.NET dataset, or .NET collection object, the basic structure of a LINQ query remains the same.

Following are the two different types of LINQ queries:

+   - Comprehensive queries
+   - Lambda queries

Let’s start our discussion with the comprehensive query type.

# Comprehensive Queries

+   - In the first step, the data source is defined.
