In the preceding general form, base_class1 through base_classN are the names of the base classes inherited by the derived class. Although, we have not yet covered multiple inheritance, but it is possible for a particular derived class to inherit more than one base class. In addition, the general form shows the syntax for invoking the base class constructor from within the constructor of the derived class by passing the arguments. Notice that a colon separates the declaration of derived class constructor function from the base classes, and a comma operator separates the base classes from each other.
