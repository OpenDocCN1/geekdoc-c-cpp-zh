# Insertion Sort

As the name suggests, insertion sort technique sorts a list of elements by placing each element at the right place at each iteration with respect to the sorting order. For example, in the first iteration, the A[1] element is compared with A[0]. If the sorting type is ascending and if A[1] is smaller than A[0], then A[1] is placed at the first position and A[0] is placed at the second position. In the second iteration, the third element A[2] is compared with both A[0] and A[1] and is placed in its appropriate place at the end of the second iteration. This procedure is repeated for all the elements in the list.
