# Address Conversion Functions

IP address used in network programming can be represented in two ways, they can be in either American Standard Code for Information Interchange (ASCII) strings, which are preferable for programmers, or network byte ordered binary values. The network byte ordered binary values are stored inside the socket address structures. In this section we are going to discuss about two groups of functions, one which converts ASCII strings to network byte ordered binary and vice versa. Listing 22.7 describes a group of functions which performs such interconversions:

**Listing 22.7:** Showing functions that perform address interconversion

```
```c
char *inet_ntoa(struct in_addr in);
    /* Returns pointer to dotted decimal string */

int inet_aton(const char *cp, struct in_addr *inp);
    /* Returns 1 if string was valid, 0 on error */

in_addr_t inet_addr(const char *cp);
    /* Returns 32 bit binary network byte ordered
                         IPv4 address */
```
```

In the listing, the function inet_ntoa function is used for converting a 32-bit binary network byte ordered IPv4 address to its corresponding dotted decimal string format. The function returns a dot and a number string inside a static buffer which gets overwritten every time the function gets called.

The function inet_aton which is used for converting the string pointed by cp to a 32-bit binary network byte ordered value which is stored inside the pointer inp. The function returns non-zero if the address is a valid one; else, the function returns zero.
