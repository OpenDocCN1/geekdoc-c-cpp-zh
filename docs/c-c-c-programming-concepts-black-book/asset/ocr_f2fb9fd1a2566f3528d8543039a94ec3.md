The output of the preceding program is given as follows:

```
```
Disabling flag
Enabling the flag once again
```
```

In Listing 7.10, we have first checked whether the __DEBUG__ macro is defined or not. If the macro is already defined, then it will be undefined in the #ifdef block. However, if the macro is not defined, then it will be defined in the #else block. Note that if we do not define the macro, then we get the reverse output.

Now, consider a scenario where the utilityFunc() function is defined in the header1.h file, which is included in another header file called header2.h. Suppose that a program includes both these header files. In this case, the compiler will throw an error message - Multiple declaration of utilityFunc(). This is because an instance of the header1.h file is already included in the header2.h file. If we include both the header files in a program, then multiple instances of the same function will be included in it. To solve this problem, we need to avoid including the same header file multiple times. The following code snippet shows the solution to avoid multiple inclusions of a function in a program:

```
```c
#ifndef __myheader_h
#define __myheader_h
utilityFunc()
{
}
#endif
```
```

When the __myHeader.h file is included in the program for the first time, the preprocessor checks for the flag and finds it undefined. Therefore, the preprocessor sets the flag and includes the body of the utilityFunc() function in the program. However, if the same header file is included in the program for the second time, then the preprocessor finds the defined flag; and therefore, skips this portion of code.
