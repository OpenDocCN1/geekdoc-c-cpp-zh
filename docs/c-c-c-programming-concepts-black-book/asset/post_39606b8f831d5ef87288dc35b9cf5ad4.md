Let’s now learn how to pass a function pointer as an argument.

### Passing a Function Pointer as an Argument

One of the various uses of function pointers is the ability to pass a function pointer as an argument to a function. This helps in implementing callbacks in C where we need to pass a pointer to a callback function. Listing 4.16 shows how to pass a function pointer as an argument to a function:

**Listing 4.16:** Showing the Code to Pass a Function Pointer as an Argument

```c
#include<stdio.h>
#include<string.h>
int Add(int,int);
int Sub(int,int);
int Mul(int,int);
int doOperation(int, int, int (*func_ptr)(int, int));
int main()
{
    int varA = 20;
    int varB = 10;
    printf("\n Addition : [%d] ", doOperation(varA, varB, &Add));
    printf("\n Subtraction : [%d] ", doOperation(varA, varB, &Sub));
    printf("\n Multiply : [%d] ", doOperation(varA, varB, &Mul));
    return 0;
}
int doOperation(int varA, int varB, int (*func_ptr)(int, int))
{
    return (func_ptr(varA, varB));
}
int Add(int varA, int varB) { return varA + varB; }
int Sub(int varA, int varB) { return varA - varB; }
int Mul(int varA, int varB) { return varA * varB; }
```

In Listing 4.16, the doOperation() function takes two integers and a pointer to a function (which in turn takes two integers and returns an integer) as its arguments. We invoke the doOperation() function from the main() function with the address of one of the three functions: Add(), Sub(), and Mul(). Within the doOperation() function, the address of one of these functions is assigned. Call to the function at which the function pointer is pointing is being made to get the desired result.

### Returning a Function Pointer from a Function

We can also return the address of a function using a function pointer. This becomes useful when we need to decide on invoking a function during runtime instead of determining it at the compile time. Listing 4.17 shows how to return a function pointer from a function:

**Listing 4.17:** Showing the Code to Return a Function Pointer from a Function

```c
#include<stdio.h>
#include<string.h>
typedef void (*func_ptr)(int, int);
void Add(int,int);
void Sub(int,int);
func_ptr compareValue(int, int);
int main()
{
    int varA = 05;
    int varB = 10;
    func_ptr getPtr = NULL;
    getPtr = compareValue(varA, varB);
    (*getPtr)(varA, varB);
    getch();
    return 0;
}
func_ptr compareValue(int varA, int varB)
{
    if(varA < varB)
    {
        return &Add;
    }
    else
    {
        return &Sub;
    }
}
void Add(int varA, int varB)
{
    printf("\n Sum is %d ", varA + varB);
}
void Sub(int varA, int varB)
{
    printf("\n Difference is %d ", varA - varB);
}
```

In Listing 4.17, we have defined a function pointer called func_ptr, which points to a function that takes two integers as its arguments but returns nothing. In addition, we have defined a function called compareValue(), which takes two integers as its arguments and returns a pointer to a function. Within the main() function, we have declared a function pointer called getPtr, which points to a function that is returned by compareValue(). Within the compareValue() function, we have compared two variables and depending on the comparison, we have returned the address of either the Add() function or the Sub() function. In addition, we have used getPtr to invoke either the Add() function or the Sub() function within the main() function.

Next, let’s learn about array of function pointers.

### Exploring Array of Function Pointers

An array, whose members are pointers to a function, is known as array of function pointers. An array of function pointers is not much different from array of pointers. The only difference is that instead of pointers, an array contains function pointers. An array of function pointers provides the flexibility to select one of the functions using a subscript of an array. Listing 4.18 shows the usage of an array of function pointers:

Listing 4.18: Showing the Code to use an Array of Function Pointers

```c
#include<stdio.h>
#include<string.h>
int Add(int,int);
int Sub(int,int);
int Mul(int,int);
typedef int (*func_ptr)(int, int);
func_ptr arr_func_ptr[3];
int doOperation(int, int, int (*func_ptr)(int, int));
int main()
{
    int varA = 20;
    int varB = 10;
    arr_func_ptr[0] = &Add;
    arr_func_ptr[1] = &Sub;
    arr_func_ptr[2] = &Mul;
    printf("\n Addition       : [%d] ", doOperation(varA, varB, arr_func_ptr[0]));
    printf("\n subtraction : [%d] ", doOperation(varA, varB, arr_func_ptr[1]));
    printf("\n Multiply        : [%d] ", doOperation(varA, varB, arr_func_ptr[2]));
    getch();
    return 0;
}
int doOperation(int varA, int varB, int (*func_ptr)(int, int))
{
    return (func_ptr(varA, varB));
}
int Add(int varA, int varB) { return varA + varB; }
int Sub(int varA, int varB) { return varA - varB; }
int Mul(int varA, int varB) { return varA * varB; }
```

In Listing 4.18, we have declared an array of function pointers called arr_func_ptr. This function pointer points to a function that takes two integers as its arguments and returns an integer. We have manually stored the addresses of various functions in different cells of the array. The wrapper function doOperation() is used to invoke the correct function with its argument, thereby, giving the desired result.

### Callbacks

A callback is nothing but a function that is called with the help of a function pointer. The main advantage of using a callback is the detachment between the caller function and the called function. In other words, the caller function need not care about to whom the actual call is being made. To understand the concept of callbacks, let’s take an example of various sorting techniques, such as Bubble Sort, Quick Sort, and Selection. Irrespective of the sorting techniques, a generic scheme can be devised with the help of callbacks to perform the comparison between two values. By doing this, we can keep the comparison logic same and reuse the module from different sorting techniques. Another usage of callbacks comes from event notifications. Let’s assume that we have a timer tied to an application and each time the timer expires, the application needs to be notified. However, the implementation of the timer is made in such a way that it does not know anything about the application. This issue can be solved with the help of a callback, which is provided from the application to the timer such that when the timer expires, all it does is executes the callback and notifies the application.

Listing 4.19 shows the implementation of a callback:

**Listing 4.19:** Showing the Code to Implement a Callback

```c
#include<stdio.h>
#include <conio.h>
typedef void (*callback_func)(char *info);
typedef struct callback_info
{
    callback_func func_ptr;
} cb_info;
void reg_callback(cb_info *ptr, void (*callback_func)(char *info));
void callback_function();
int main()
{
    char *info="This is a test";
    cb_info *ptr=NULL;
    ptr=(cb_info*)malloc(sizeof(cb_info));
    reg_callback(ptr, callback_function);
    ptr->func_ptr(info);
    getch();
    return 0;
}
void reg_callback(cb_info *ptr, void (*callback_func)())
{
    ptr->func_ptr = callback_func;
}
void callback_function(char *info)
{
    printf("\n Information passed [%s]", info);
}
```

In Listing 4.19, we have declared a function pointer as follows:

```c
typedef void (*callback_func)(char *info);
```

In the preceding declaration, `callback_info` is a structure, which has a function pointer as its member. Within the `main()` function, we have registered the function pointer by assigning the address of the `callback_func()` function that we want to use as the member of the `callback_info` structure. Now, the callback is ready to be used as follows:

```c
ptr->func_ptr(info);
```

The preceding statement invokes the desired function and the callback will work accordingly.

### Callback to a C++ Member Function using a Function Pointer

Pointers to a C++ non-static member functions are a bit different if compared with standard function pointers in C, as they need the this pointer of a class object to be passed. Callback to a C++ member function needs a static member function, which will work as a wrapper. For this, we first need to cast the pointer of the object of a class to void* and then pass the pointer along with the required arguments to the wrapper function.
