A markup language is used to tell Web browsers how to display a document. Every markup language consists of certain semantics, which decide how the text in a document should be structured. Two widely used markup languages are HyperText Markup Language (HTML) and Extensible Markup Language (XML), which are derived from Standard Generalized Markup Language (SGML). HTML is a language that uses the predefined tags to define the structure of a document. On the other hand, XML is a language that is used to create custom tags to describe data. XML can also be used as an exchange format to transfer data between similar applications.

Due to a well-formed structural representation of data as well as user-friendly tags and attributes, XML is an integral part of .NET Framework. Microsoft has introduced a new suite of XML application programming interfaces that are built on industry standards, such as XPath, XML Schema Definition (XSD), and Extensible Stylesheet Language Transformation (XSLT). XML is a core part in .NET because it is used to represent data in technologies, such as ASP.NET and Web Services.

To work with an XML document (or file), .NET provides five namespaces, namely System.Xml, System.Xml.Schema, System.Xml.Serialization, System.Xml.XPath, and System.Xml.Xsl. The System.Xml namespace contains major XML classes, such as XmlTextReader, XmlTextWriter, and XmlDocument, to read and write XML documents.

# # Introduction to XML

When we save an enterprise data in a document, we always try to structure the data in a certain way that can be understood later by another user. Therefore, we choose a format that is reliable and easily understood by other users. In this scenario, XML is used to provide a structured way to format the content of the document using user-friendly tags. Each XML document starts with an XML tag that holds the version of XML along with the encoding type it provides. Similar to SGML, XML also has the starting tag and the ending tag.
