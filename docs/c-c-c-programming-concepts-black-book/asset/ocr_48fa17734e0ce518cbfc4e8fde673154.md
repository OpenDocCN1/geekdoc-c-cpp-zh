# ## Stack

Stack operation follows the Last In First Out rule commonly known as LIFO. When an item is inserted into the stack, it is inserted at the bottom of the stack; this operation is known as push. In addition, when an element is removed from the stack, it is always removed from the first position, which implies that the last inserted item will be removed first. This operation of stack is known as pop. C# provides the Stack class, which holds every value type making this class a flexible data repository.
