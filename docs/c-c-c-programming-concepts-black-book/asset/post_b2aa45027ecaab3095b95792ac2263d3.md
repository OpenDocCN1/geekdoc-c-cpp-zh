        {

## The goto Statement

The *goto* statement is one of the primitive C# jump statements. This statement transfers the control from one point to another in a program with the help of a label. The label must exist within the scope of the *goto* statement. Listing 17.47 shows the structure of *goto* Statement.

**Listing 17.47: Showing the Structure of goto Statement**

```csharp
goto <label_name>;
<label_name>: Statement
```

Note that more than one *goto* statement can transfer the control to the same label. Another point to note is that the *goto* statement can work as a *break* statement, that is, it can transfer the control out of the block, but it cannot transfer the control into a new block to avoid the possibility of jumping past an initialization. Listing 17.48 shows the implementation of *goto* statement:

**Listing 17.48: Showing the Usage of goto Statement**

```csharp
using System;
class program
{
    public static void Main()
    {
        Example e = new Example();
        e.PrintFibonacci();
    }
}
class Example
{
    public int i = 0;
    public Example()
    {
    }
    public void PrintFibonacci()
    {
        int f0 = 0;
        int f1 = 1;
        int f2 = 0;
        Console.WriteLine("The fibonacci series is....");
        Console.WriteLine(f0);
        Console.WriteLine(f1);
        int i = 1;
        while (true)
        {
            f2 = f0 + f1;
            f0 = f1;
            f1 = f2;
            i += 1;
            if (i < 10)
                goto PrintLine;
            else
                goto End;

            PrintLine: Console.WriteLine(f2);
        }
        End: ;
    }
}
```

The preceding program is the modification of Listing 17.46. In this program, we are controlling the flow of the loop execution using the goto statement. Depending on the value of the variable i, we are printing the values of f2 on the console using the goto statement whose label PrintLine prints the result on the console. In addition, we are transferring the control out of the block to stop the loop execution using the goto statement. This is one of the oldest methods used to manage the control flow logic. However, nowadays, developers mostly use the continue-break statement to manage the control flow inside the code block.
