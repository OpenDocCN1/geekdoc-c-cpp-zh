# ## Definition of Member Functions and Access controls

Member functions have access to all the data members of a class. A member function can be defined, as shown in Listing 13.9:

**Listing 13.9: Showing the Definition of Member Functions**

```
```cpp
void Y :: func_1 ( int a, int b)
{
    x = a;                    // a is the data member of class Y
    y = b;                    // b is also a data member of class Y
}
int Y :: func_2 ()
{
    return a;
}
```
```

Moreover, one member function can use other member functions of a class, as shown in Listing 13.10:

**Listing 13.10: Illustrating the Access Control of Member Functions**

```
```cpp
void Y :: func_1 (int a , int b)
{
    x = a;
    y = b;
    printf ( "%d", func_2() ) ; // Y :: func_1 () calls Y :: func_2()
}
```
```

# ## Messages to Objects

Member functions of a class are invoked by the messages to objects. Messages to objects access the data members of the objects through the member functions. Listing 13.11 shows how to pass messages to objects:

**Listing 13.11: Passing Messages to Objects**

```
```cpp
1: Class A;
2: void func()
3: {
4:     A obj_A;
5:     obj_A.func (10, 10)
6: }
```
```

In the class A, obj_A is an object of type A. Line 5 of the code denotes the message to the object obj_A, where func() is the function to be invoked by the message.
