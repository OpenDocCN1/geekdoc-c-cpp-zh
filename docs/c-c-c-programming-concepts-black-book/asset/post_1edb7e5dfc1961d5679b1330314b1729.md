
Similarly, we can initialize the structure members as follows:

```cpp
struct employee_data emp = {"John", 45, 16000};
```

The values to be assigned to the structure members are surrounded by braces and separated by commas. The first value in the list is assigned to employee_name, the second value is assigned to age, and the third value is assigned to salary.

## References

In C++, a reference is essentially an implicit pointer that acts as another name for an object. A reference provides an alias — a different name — for a variable. We can use a reference to create functions that automatically use call by reference rather than call by value. One brilliant example of reference objects can be seen while defining copy constructors for classes. However, following are a number of restrictions that apply to references in C++.

- We cannot reference another reference
- We cannot obtain the address of a reference
- We cannot create arrays of references
- We cannot create a pointer to a reference
- We cannot reference a bit-field
- A reference variable must be initialized when it is declared unless it is a member of a class, a function parameter, or a return value
- NULL references are prohibited

Now, let's write the following program to understand the basics of references in C++:

```cpp
1: // demonstrating independent reference variables in C++
2: #include <iostream>
3: using namespace std;
4:
5: int main ()
6: {
7:     int var1;
8:     int &ref = var1;        //reference
9:
10:    var1 = 10;
11:    cout<<"The values of var1 = "<<var1<<" ref = "<<ref<<endl;
12:
13:    ref = 100;
14:    cout<<"The values of var1 = "<<var1<<" ref = "<<ref<<endl;
15:
16:    int var2 = 19;
17:    ref = var2;             // value of var2 sets into value of var1
18:    cout<<"The values of var1 = "<<var1<<" ref = "<<ref<<endl;
19:
20:    ref--;
21:    cout<<"The values of var1 = "<<var1<<" ref = "<<ref<<endl;
22:
23:    return 0;
24: }
```

In the preceding program, we have declared a reference variable and experimented with it. When we use a reference variable, we create a second name for another variable. All the reference variables must be initialized when they are created to make them easy to understand. Apart from initialization, we cannot change the object that a reference variable points to. Therefore, it must be initialized when it is declared. Following is the output of the preceding program.

```
The values of var1 = 10 ref = 10
The values of var1 = 100 ref = 100
The values of var1 = 19 ref = 19
The values of var1 = 18 ref = 18
```

We can also use an independent reference to refer to a constant. For example, the following statement causes `count` to point to a location where the value 9 is stored in a constant table:

```cpp
int &count = 9;
```

## Flow Control Statements

Till now, the programs we have discussed in the previous sections follow a sequential execution model. However, while solving real life problems using C++ programming, very few programs follow the execution of statements in a strict order from beginning to end. Most programs decide what to do in response to changing circumstances. As a result, the flow of a program jumps from one part to another based on the calculations and operations performed in the program. Therefore, to handle these situations, we need the help of three tools – loops, decision, and jump statements. Let’s learn about these three tools in detail.

### Decision Statements

In a program, a decision statement causes a one-time jump to the different parts of a program, depending on some expression evaluation. In C++, decisions can be made using the if, if-else, and switch statements. However, the most popular among these statements is the if-else statement, which chooses between two alternatives. This statement can even be used without an else part. We have another decision-making statement called switch. It creates branches for multiple alternatives and depending on the value of a single variable, chooses the answer or breaks the decision. Let’s learn about each of them in detail in the next sections.

### The if Statement

The if statement is the simplest of all the decision statements, as it chooses between two options based on a true or false condition. Following is a program that uses the if statement to check whether the numeric value entered by a user is negative:

```cpp
1: // Demonstrating "if" statement in C++
2: #include <iostream>
3: using namespace std;
4:
5: int main ()
6: {
7: int num;
8: cout<<"Enter a positive number: ";
9: cin >> num;
10:     if (num < 0){
11:         cout<<"You have entered a negative number"<<endl;
12:     }
13:     return 0;
14: }
```

If a user inputs a positive number, an error message is not displayed to the user; however, if the user enters a negative number, an error message is displayed. Following is the output of the preceding program:

```
Output from the First Run (Positive Case):
Enter a positive number: 10
Output from the Second Run (Negative Case):
Enter a positive number: -5
You have entered a negative number
```

### The switch Statement

Consider a scenario where we have a large decision tree to make a decision from a lot of options. In this case, it is better to use a switch statement than an if-else ladder, as a switch statement enhances the readability of the code. The value of the variable given into switch is compared with the value following each of the cases. When one value matches the value of the variable, the compiler continues executing the program from that point. To learn more about switch, let's write the following program, where we want a user to input a value from a set of three values (11, 22, and 33):

```cpp
1: // Demonstrating "switch case" in C++
2: #include <iostream>
3: using namespace std;
4:
5: int main ()
6: {
7: int num;
8: cout<<"Enter a number (11/22/33): ";
9: cin >> num;
10:        switch (num) {
11:            case 11:
12:                cout<<"Congratulations. You have entered 11."<<endl;
13:                break;
14:            case 22:
15:                cout<<"Congratulations. You have entered 22."<<endl;
16:                break;
17:            case 33:
18:                cout<<"Congratulations. You have entered 33."<<endl;
19:                break;
20:            default:
21:                cout<<"You have entered a wrong option."<<endl;
22:        }
23:    return 0;
24: }
```

In the preceding program, if a user enters a value other than 11, 22, or 33, then the default case is executed by showing the error message as output. The default case catches anything within the switch that is unexpected. Following is the output of the preceding program:

```
Output from the First Run:
Enter a number: 11
Congratulations. You have entered 11.

Output from the Second Run:
Enter a number: 9
You have entered a wrong option.
```
