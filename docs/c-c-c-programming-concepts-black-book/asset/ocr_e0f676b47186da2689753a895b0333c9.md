# Parameter Passing in Functions

Parameters or arguments are a piece of data passed from a program to a function. They allow a function to operate with different values, or even do different things based on the argument value, with which it is called. Following are the various types of values that can be passed to a function:

+   - **Constants**—A constant is an identifier, whose value ideally cannot be altered during the entire duration of program execution. Although a constant’s value is specified only once during the program duration, it can be accessed multiple times from within the program during its lifetime. Using constants in a program enhances the readability of the program and lower the chances of data redundancy errors in the program. From a program, we can make a call to a function with numeric or alphanumeric constants, as shown in the following code snippet:

```
```cpp
//Demonstrating functions in C++ with constant arguments
#include <iostream>
using namespace std;
void function(int num);
int main()
{
    cout<<"I’m in Main"<<endl;
    function(5);
    cout<<"I’m in Main again"<<endl;
}

void function(int num)
{
    cout<<"Argument in function is "<<num<<endl;
}
```
```

In the preceding code snippet, we are making a call to a function with an argument value of 5. Following is the output of the preceding code snippet:

```
```text
I’m in Main
Argument in function is 5
I’m in Main again
```
```

+   - **Variables**—A variable is a symbolic name associated with a value, which generally changes during the lifetime of a program. We can also pass variables in a function as an argument and access their values from within the function and process it, if required, as shown in the following code snippet:

```
```cpp
//Demonstrating functions in C++ with variable arguments
#include <iostream>
using namespace std;
void function(int num);
int main()
{
    int x;
    cout<<"I’m in Main"<<endl;
    for (int i=1;i<=5;i++)
        cout<<"Enter a number:"<<endl;
        cin >> x;
        function(x);
    cout<<"I’m in Main again"<<endl;
}
