As shown in the preceding definition, the derived class Manager inherits all the members or properties of the base class Employee along with its own properties. This type of inheritance not only happens with respect to the member variables, but the member functions of the base class are also attached to the derived class.

Another important concept to understand is the use of access specifiers. The access specifier determines the access status of the base class members inside the derived class. The access specifiers for the base class are public, private, and protected. In C++, if no access specifier is explicitly mentioned, then the default access specifier is private.
