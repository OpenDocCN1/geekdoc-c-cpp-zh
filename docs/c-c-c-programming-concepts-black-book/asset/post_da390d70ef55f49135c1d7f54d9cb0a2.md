
## The operator keyword

When we think of overloading a normal C++ operator to perform user-defined tasks, the question that comes to our mind is how do we achieve this? C++ offers an answer to this by providing the **operator** keyword. Consider the following example that shows the use of operator keyword:

```cpp
void operator + ();        // For '+' operator
```

The return type (in our case, void) comes first, followed by the **operator** keyword, then the operator itself (in this case, ‘+’), which is followed by the list of arguments to this function enclosed in parenthesis. This declaration tells the compiler to call the function whenever the ‘+’ operator is encountered in the program body, provided the operands are of the same class where it is defined as a member function. The compiler makes the decision seeing the operands working on that operator. When the ‘+’ operator is applied over two integer or real variables, the compiler chooses the built-in implementation of the operator and proceeds with it. However, when the compiler sees that the ‘+’ operator is operating on two user-defined objects, it searches for any overloaded operator member functions for that class to process the instruction.

## Operator Arguments

The overloaded operator function generally takes the argument, on which it is supposed to work or operate. However, the number of arguments depends on the type of operator. Let’s consider a case of overloading the binary operator ‘+’. The overloaded member function for ‘+’ should take two arguments, obj1 and obj2, on which it should operate on and return a third object containing the final result of this operation. On the other hand, while overloading any unary operator, such as ‘++’ or ‘--’, we just need to apply it over the operand itself. It should operate using the operand’s data members for which it has been invoked; and therefore, no arguments are required in the case of unary operators.

## Operator Return Values

In case we intend to return any value from the overloaded operator function, we need to design the operator function in such a way that it should return a value. Consider the following unary operator function:

```cpp
void operator ++();
```

Now, we can call the preceding function using the following object of a class:

```cpp
obj1 = obj2++;
```

During the compilation of the preceding statement, the compiler will generate an error for this operation. This is because we have defined the overloaded operator function in a class with the return type void, while in the program it is called to return an object of similar type. Therefore, we need to look on our requirement and the way the operation should be carried off, before writing an overloaded function for a built-in operator.

## Member Operator Functions

We can create an operator function within a class to perform a specific operation on the object of the class. This operator function in a class is known as the member operator function. For example, the ‘+’ operator can be overloaded inside a class definition to add two objects of the same class. The syntax for the member operator function is given as follows:

```cpp
Ret-Type Class-name::operator# (arg-list)
{
    // definition
}
```

Often operator function returns an object of the class they operate on; however, Ret-Type can be any valid C++ return types. The # is called the placeholder. When we create an operator function, we replace # with the operator itself. For example, if we overload the ‘+’ operator, then we write operator+ in place of operator#. In addition, if we overload any unary operator, then the arg-list is kept empty, as the unary operator is going to access the member variables of the caller object. Similarly, while overloading binary operators, the arg-list generally takes at least one argument. Let’s now learn how to overload unary and binary operators.

## Overloading Unary Operators

Unary operators are those operators that operate on a single operand. Some examples of unary operators are logical NOT (!), increment (++), decrement (--), and address of (&). Let’s overload the increment operator in the following program:

```cpp
1:/* Operator Overloading Example Program 1 */
2:#include <iostream.h>
3:using namespace std;
4:
5:class TickCounter {
6:    int count;
7:public:
8:TickCounter()
9:{
10:    count=0;
11:}
12:int getCount()
13:{
14:    return this->count;
15:}
16:void operator ++()
17:{
18:    ++count;
19:}
20:};
21:
22:int main()
23:{
24:    TickCounter obj1, obj2;
25:
26:    cout<<"The value of obj1 = "<<obj1.getCount()<<endl;
27:    cout<<"The value of obj2 = "<<obj2.getCount()<<endl;
28:
29:    ++obj1;
30:    ++obj2;
31:    ++obj2;
32:
33:    cout<<"\nThe value of obj1 = "<<obj1.getCount()<<endl;
34:    cout<<"The value of obj2 = "<<obj2.getCount()<<endl;
35:
36:    return 0;
37:}
```

In the preceding program, we have declared a TickCounter class, with a single member variable count. The TickCounter class also holds a constructor function to initialize the count, a member function getCount() to fetch the value of the counter variable count, and a function for the overloaded ‘++’ operator. In the main() function, we have declared two objects of the TickCounter class, named obj1 and obj2. As soon as the objects are declared, the constructor function is executed and the data members are initialized for each declared object. To check whether the initialization part is done properly, we have printed the values of the member variables for both the objects in line numbers 26 and 27. Now, in line numbers 29 to 31, we have operated the ‘++’ operator over user-defined class objects. In this case, we can observe that the compiler does not raise any error during the compilation phase, even though the ‘++’ operator is applied to a user-defined object. This is because of the operator function definition in the class body. As soon as the compiler encounters the operator function definition, it first checks the data type of the operand. If the operand is of built-in data type, the compiler knows what to do, but when ‘++’ is applied over an object, the compiler searches the class definition to see whether this operator has been overloaded as a class member function. If not, then the compiler issues an error and fails the compilation process; otherwise, it does the job as specified in the definition of ‘++’. In the preceding program, we have incremented obj1 only once and obj2 twice. To see whether this operation has been succeeded, the values are again printed in line numbers 33 and 34.

Following is the output of the preceding program:

```
The value of obj1 = 0
The value of obj2 = 0
The value of obj1 = 1
The value of obj2 = 2
```

Now, in the preceding program, we have kept the return type of the operator function as void. However, we can experiment in the same program with return types other than void. Let’s write the same program, but the operator function will return an object instead of void, given as follows:

In the preceding program, a single statement, return TickCounter(count);, performs the functionality of the following three statements in the previous program:

```cpp

```

In line number 23, a nameless object of type TickCounter is created and the value in the object is set by using the new constructor function, which is introduced in line number 12. This constructor function helps in the creation and initialization of the unnamed object returned by the operator function. Therefore, we have replaced the three statements of the previous program with the single statement serving the same purpose. However, in both the cases, the constructor function makes a copy of the original object and returns the new object (shown in line number 35). This program also outputs the same result as the previous program.

While writing programs in C++, we use two types of notations: ++x and x++. The former is the prefix notation; whereas, the latter is the postfix notation. Till now, we have seen the prefix operator being overloaded. Now let's try to overload the postfix notation for the '++' operator.

The postfix notation for the addition operator is given as follows:

```cpp
obj1++;
```

In case of postfix notation, the implementation of the addition operator for the class TickCounter, is given as follows:

```cpp
TickCounter operator ++ (int)
```

The only difference in this implementation is the use of int in the parentheses. This is not an argument as well as it does not mean integer in this particular case. It is simply a signal to the compiler to create the postfix version of the operator. This is what the designers of C++ choose to represent postfix notation of unary operator.

Now, let's write the following program to overload both prefix and postfix increment operators:

```cpp
1:/** Operator Overloading Example Program 4 */
2:#include <iostream.h>
3:using namespace std;
4:
5:class TickCounter {
6:    int count;
7:public:
8:    TickCounter()
9:    {
10:        count=0;
11:    }
12:    TickCounter(int cnt)
13:    {
14:        count = cnt;
15:    }
16:    int getCount ()
17:    {
18:        return this->count;
19:    }
20:    TickCounter operator ++ ()        //Prefix Implementation
21:    {
22:        return TickCounter(++count);
```
