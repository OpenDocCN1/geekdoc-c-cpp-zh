### Table 21.6: Noteworthy Methods of the File Class

| Method | Description |
|---|---|
| `Copy(string sourcePath, string destinationPath)` | Copies an existing file from one location to another.<br>It takes two arguments: one represents the source path from which the file is copied to and another corresponds to the destination path in which the copied file will be saved.<br><br>**Overloads:**<br>• `Copy(string sourcePath, string destinationPath, bool isOverwrite)` → Overwrites an existing file in the destination path if the `isOverwrite` flag is set to true. |
| `Create(string path)` | Creates a file at the specified location and returns an object of the `FileStream` class.<br>It takes a user-defined path as an argument.<br><br>**Overloads:**<br>• `Create(string path, int bufferSize)` → Creates a file with the specified bytes of buffer available for read and write.<br>• `Create(string path, int bufferSize, FileOptions fileOption)` → Creates a file with the specified buffer byte along with `fileOption` that defines how to create or overwrite a file.<br>• `Create(string path, int bufferSize, FileOptions fileOption, System.Security.AccessControl.FileSecurity fileSecurity)` → Creates a file with the specified buffer byte along with `fileOption` that defines how to create or overwrite a file with a specific file security mentioned in the `FileSecurity` object. |
| `CreateText()` | Returns a `StreamWriter` object in which a user can write UTF-8 encoded text. |
| `Exists(string path)` | Checks for a file in a user-specified path. If exists, then it returns true; otherwise, it returns false.<br>It takes a user-defined path as an argument. |
| `Move(string sourcePath, string destinationPath)` | Moves a file and its content from one location to another.<br>This method takes two arguments: one contains the source file path and another contains the destination file path. |
| `Open(string path, FileMode fileMode)` | Opens a `FileStream` in the user-specified path having the specified file mode, which stated whether to append, truncate, create, or overwrite a file and with the specified file sharing option.<br>It takes two arguments as input: one is the user-defined path and another represents the file mode.<br>It returns a `FileStream` object.<br><br>**Overloads:**<br>• `Open(string path, FileMode fileMode, FileAccess fileAccess)` → Opens a `FileStream` with the specified `fileMode` and `fileAccess`, which states whether delete, read, write, or read/write operations can be performed on the files.<br>• `Open(string path, FileMode fileMode, FileAccess fileAccess, FileShare fileShare)` → Opens a `FileStream` with the specified `fileMode`, `fileAccess`, and `fileShare`, which states whether delete, read, write, or read/write operations can be performed on the files. |
