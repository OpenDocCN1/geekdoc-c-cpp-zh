Employee emp = new Employee();
//Assigning values to specify the employee details
emp[0] = "John"; //Name of the employee
emp[1] = "USA"; //Country the employee lives in
emp[2] = "Software Engineer"; //Qualification of the employee
emp[3] = "12345"; //Employee ID of the employee
emp[4] = "Developer"; //Designation of the employee
emp[1.0] = "Empty"; //Overloading indexer
for (int i = 0; i < 5; i++)
{
    Console.WriteLine("Employee[{0}]: {1}", i, emp[i]);
}
Console.WriteLine("Employee[{0}] {1}", 1.0, emp[1.0]);
}
}
class Employee
{
    string[] Emp_Details = new string[6];
    string[] Emp_Det = new string[6];
    //Defining indexers
    public string this[int count]
    {
        get
        {
            return Emp_Details[count];
        }
        set
        {
            Emp_Details[count] = value;
        }
    }
    public string this[double count]
    {
        get
        {
            return Emp_Det[(int)count];
        }
        set
        {
            Emp_Det[(int)count] = value;
        }
    }
}
```
```

In this preceding code, we have added an extra member variable, which is also an array of string, and defined the indexer of the variable where we have passed the data type double. In the Main() method, we have declared one array element that has the index defined as 1.0. For this array element, the new index definition will be used. Therefore, all the defined indexer values as well as the value of the array element with the index of type double are printed on the console. The output of the preceding code is given as follows:

```
```text

Employee[1]: USA
Employee[2]: Software Engineer
Employee[3]: 12345

Employee[1] Empty
