# # Restricting Exception

The throw clause in a function definition specifies the type of exceptions the function is expected to throw. Using the throw clause, we can restrict the type of exceptions that a function can throw by specifying a comma-separated list of exception types within the throw clause. Throwing any other exception will cause abnormal program termination.

The generic declaration of the exception consists of using the throw keyword followed by a list of all the possible types of exceptions. Therefore, we can declare a function as:

```
```
void f() throw(VeryBig, VerySmall, divideByZero);
```
```

The function declaration f() signifies that any possible type of exception can be thrown from the function and void f() throw() signifies that there is no exception to be thrown from the f() function.

We should always use an exception specification while writing a function that throws an exception. This ensures good coding standards and good documentation. It also makes easier for us to use the function caller.

There might be situations within a program where we throw something than what appears as the exception specification. In such cases, a special function unexpected() is called. By default, unexpected() causes abort() to be called, which causes abnormal program termination. Presence of throw() with empty parenthesis indicates that the function within which it is defined, is not expected to throw any exception.

The general form of the throw clause is:

```
```
return_type function_name (argument_list) throw(type_list)
{
    //-
}
```
```
