# Nesting of the while Loop

It is possible to have multiple while loops getting executed simultaneously one inside the other. Such executions are called nesting of the while loop. Let’s consider an example where we need to display factorials of all the numbers ranging from 1 to 10. In order to address this problem, we need to have nesting of the while loop.

Listing 1.30 shows the nesting of the while loop:

**Listing 1.30:** Nesting of the while Loop

```
```c
#include<stdio.h>

int main()
{
    int factorial;
    int inner_count;
    int outer_count;

    outer_count=1;
    factorial=1;

    while(outer_count <= 10)
    {
        inner_count=1;
        while(inner_count <= outer_count)
        {
            factorial*=inner_count;
            inner_count++;
        }
        printf("\n Factorial of %d is %d ",outer_count,factorial);
        factorial=1;
        outer_count++;
    }
    getch();
}
```
```

The output of Listing 1.30 is given as follows:

```
```
Factorial of 1 is 1
Factorial of 2 is 2
Factorial of 3 is 6
Factorial of 4 is 24
Factorial of 5 is 120
Factorial of 6 is 720
Factorial of 7 is 5040
Factorial of 8 is 40320
Factorial of 9 is 362880
Factorial of 10 is 3628800
```
```

As stated in Listing 1.30, we have two nested while loops. The outer one controls the range of data generation, i.e. it iterates from zero to ten. The inner loop is used to calculate the factorial for each iteration of the outer loop.

# The for Loop

The for loop is one of the most-commonly used loops in the C language. The main advantage of using this loop is that one can initialize, test, and increment the loop-control variable all at once using a single statement. This makes the for loop more flexible to use.
