# Goals of Each Actor

As aforementioned, the actors in our case study are hotel manager and customer. They have different goals.

The goals of the hotel manager are as follows:

+   * Confirms customer booking
+   * Adds hotel room
+   * Cancels room booking
+   * Charges on room rent

The goals of the customer are as follows:

+   * Requests for booking
+   * Views booking details
+   * Cancels booking
+   * Checks room availability

# Main Use Cases to be Used

The main use cases that are used in our case study are as follows:

+   * UC1: Requests for booking
+   * UC2: Adds hotel room
+   * UC3: Views booking details
+   * UC4: Cancels booking
+   * UC5: Offers discounts on room rent
+   * UC6: Checks room availability

To show the generalization and extend relationship, many other use cases have been used, which we do not add in the use-case analysis.
