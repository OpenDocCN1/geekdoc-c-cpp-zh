Pointers to a C++ non-static member functions are a bit different if compared with standard function pointers in C, as they need the this pointer of a class object to be passed. Callback to a C++ member function needs a static member function, which will work as a wrapper. For this, we first need to cast the pointer of the object of a class to void* and then pass the pointer along with the required arguments to the wrapper function.
