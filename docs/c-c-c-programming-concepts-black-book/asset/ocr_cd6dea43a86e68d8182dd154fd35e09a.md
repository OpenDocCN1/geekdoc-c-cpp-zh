# Count Sort

Count sort is based on the assumption that the range of the element lies between 1 to k. This technique counts the number of elements possessing the same value and sorts them by maintaining their ordering of occurrences. This is a linear sorting algorithm, which does not implement any comparison; rather, it sorts the elements depending on their number of occurrences. The only restriction of count sort is that its overhead becomes huge if the maximum value of the list element is large. To explain the count sort, let’s consider the following list to sort:
