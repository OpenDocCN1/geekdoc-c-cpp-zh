# atof()

The atof() function converts a string into a double value. The string must contain a valid floating-point number; otherwise, the function would return an undefined value. The signature of the atof() function is as follows:

```
double atof(const char *str);
```

Let’s take an example of the atof() function as mentioned in Listing 8.29:

**Listing 8.29:** Usage of atof () function.

```
```c
#include<stdio.h>
#include<stdlib.h>

int main()
{
    char inputString[50];

    printf("\n Enter a number -> ");
    gets(inputString);

    printf("\n The value returned by atof function is %f ",atof(inputString));

    getch();
    return 0;
}
```
```

Output of the preceding example is as follows:

```
Enter a number -> 42.90876
The value returned by atof function is 42.908760
```

# atol()

The atol() function converts a string into a long integer value. The string must contain a valid integer number; otherwise, the function would return an undefined value. The signature of the atol() function is as follows:

```
long int atol(const char *str);
```

Let’s take an example of the atol() function as mentioned in Listing 8.30:

**Listing 8.30:** Usage of atol () function.

```
```c
#include<stdio.h>
#include<stdlib.h>

int main()
{
    char inputString[50];

    printf("\n Enter a number -> ");
    gets(inputString);

    printf("\n The value returned by atol function is %ld ",atol(inputString));

    getch();
    return 0;
}
```
```

Output of the preceding example is as follows:

```
Enter a number -> 1234567.89
The value returned by atol is 1234567
```
