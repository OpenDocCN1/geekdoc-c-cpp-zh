We can click the MANIFEST label to open the Notepad that contains the following information:

+   - **Name of the assembly**—Holds the name of a file containing the manifest. This name is set automatically when an assembly is created.
+   - **Version**—Contains a four part version number: Major, Minor, Build, and Revision.
+   - **Culture**—Targets the language or culture of the assembly. It has been set using the AssemblyCulture attribute. This component is optional.
+   - **Public Key Token**—Gives a strong name to the assembly.
+   - **List of files in the assembly**—Contains the list of files as a hash file.
