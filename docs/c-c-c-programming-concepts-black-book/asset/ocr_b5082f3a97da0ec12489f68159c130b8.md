# Identifiers

All kinds of variables, functions, labels, and other user defined items are called identifiers. Length of identifiers can vary from one to multiple characters. Identifiers can be alphanumeric in nature but there are some rules that need to be followed while declaring identifiers in C. For example, the first letter must be an underscore or a character. Subsequent characters can be characters, underscores, or numeric values. An identifier starting with a numeric value is not allowed to be declared in C.

Table 1.2 lists the allowed and disallowed identifiers, also known as right or wrong identifiers:

**Table 1.2: Right and Wrong Identifiers**

| Right Identifier | Wrong Identifier |
|---|---|
| `loop_count` | `3count` |
| `check45` | `Hello!world` |
| `flag` | `check_value` |

An identifier can be of any length. C has two different sets of identifiers—external and internal. The external identifiers are like global variable names and function names that are shared between files. This sharing is also called the external link process. If an identifier cannot be shared globally, it is called an internal identifier. In the C89 version of C, only first 6 characters of an external identifier and first 31 characters of an internal identifier were considered to be significant. This got changed with the C99 version, where an external identifier has 31 significant characters and an internal identifier has 63. Identifiers are case sensitive, which means that they appear upper and lower case characters distinctly.

# Data Types

There are five fundamental data types available in C, which are as follows:

+   - int
+   - char
+   - float
+   - double
+   - void

The size and range of these data types vary according to the compiler and the architecture of the computer on which the program is developed or run. The size of int varies from 2 bytes to 4 bytes, depending on the compiler and processor. The size of char remains unaltered across all architectures. The size of int generally depends on the word length of the program. To be more precise, the size depends upon the CPU architecture on which the program runs. In a 16 bit architecture, an integer has a size of 16 bits or 2 bytes. In a 32 bit architecture, it will have a size of 4 bytes, which is equal to 32 bits. The length of float and double depends upon the representation used for floating point numbers. Standard ANSI C specifies that the minimum range of a floating point value is 1E-37 to 1E+37. The void data type is typically used to define return types for functions or for pointers. They will be discussed in detail in subsequent chapters.
