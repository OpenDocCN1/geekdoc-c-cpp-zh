In Visual Studio 2008, Microsoft added a new feature called Language-Integrated Query (LINQ). This feature gives a developer the ability to query and transform the data using C# and other languages supported by .NET Framework. LINQ is deeply integrated into the .NET languages; therefore, developers need not worry about learning other query languages to retrieve any data.

Microsoft has designed LINQ to provide a general-purpose query language using which developers can query any data object and fetch any data from the data object with the use of standard query operators. In LINQ, standard query operators provide a way to build a proper query language to help developers in executing the desired operations that were used to execute using other query languages. The *System.Linq* namespace comprises the standard query operators to perform the operations, such as filtering, projecting, sorting, joining, and aggregation. These operations are executed on the data that implements the *IEnumerable<T>* type. These operators work with Common Language Specification and support the generic type.

In this chapter, we learn about LINQ, anonymous methods, and lambda expressions. We also learn about lambda queries, comprehensive queries, deferred execution, and immediate execution. Then, we learn about LINQ to Object, LINQ to XML, and LINQ to ADO.NET. Next, the chapter discusses the building mechanism of an expression tree. After that, we learn about various standard LINQ operators. Finally, we learn about exception handling using the try-catch-finally block.

Let’s start with the introduction to LINQ.

## LINQ

LINQ is used to integrate a query into the language supported by .NET Framework. In .NET, we mostly use the Structured Query Language (SQL) objects to fetch the data from the SQL datastore. However, by using LINQ, we can build a bridge between an application and a datastore.

LINQ allows us to access the data stored in various types of data sources, such as relational databases, XML files, and data objects. It provides a unified query model using which we can access the data from any type of datastore using the same syntax. As LINQ is integrated into language, it reduces the complexity of remembering different programming languages along with different query languages.

If we want to fetch data from a collection or List, then it is difficult to apply the same query used for relational database. Therefore, LINQ provides a way to fetch data from their in-memory objects.

Depending on an object type, LINQ can be categorized as follows:

- LINQ to Object
- LINQ to SQL (also called DLINQ)
- LINQ to XML (also called XLINQ)

Before discussing the three types of LINQ, let’s learn about anonymous method, which is one of the important building blocks of LINQ.
