# The StreamReader Class

The StreamReader class is used to read the text from a text file or from a document with the specified encoding. By default, the StreamReader class reads the text with the UTF-8 encoding. However, it can also read the text with the customized encoding.

We can declare a StreamReader object as follows:

```
StreamReader streamReader = new StreamReader(stream);
StreamReader streamReader = new StreamReader(stream, System.Text.Encoding.UTF8);
StreamReader streamReader = new StreamReader(path);
StreamReader streamReader = new StreamReader(path, System.Text.Encoding.UTF8);
```

In the preceding declarations, path is a string variable that contains the path of a file from which the text will be read; whereas, stream is an object of the Stream class where the read operation will take place. C# provides 10 overloaded constructors for the StreamReader class; however, the aforementioned four constructors are widely used in programming.

Table 21.2 shows the noteworthy methods of the StreamReader class:

| **Table 21.2: Noteworthy Methods of the StreamReader Class** |  |
|---|---|
| **Method** | **Description** |
| `Close()` | Closes the StreamReader object and releases all the resources that the object was using. |
| `Dispose()` | Releases all the system resources held by the StreamReader object. |
| `Peek()` | Retrieves the position of the next available character. It only returns the position of the next character as integer. |
| `Read()` | Reads the next character from the stream and increases the character position pointer by 1. The position of the next character has been returned as integer. **Overloads:** `Read(char[] buffer, int index, int count)` reads the number of characters from the input stream and stores them into the buffer starting from the index position. This method also returns the next character position as integer. |
| `ReadBlock(char[] buffer, int index, int count)` | Reads the number of characters from the input stream and stores them into the buffer starting from the index position. This method also returns the next character position as integer. |
