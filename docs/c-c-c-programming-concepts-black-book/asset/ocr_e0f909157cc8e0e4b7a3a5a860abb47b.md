+   1. The compiler first tries to find an exact match in which the type of the actual arguments is same as that of the formal arguments and then uses that function.
+   2. If an exact match is not found, then the compiler uses the automatic type promotions to the actual arguments, such as char to int or float to double, to find a match.
+   3. When either of the preceding steps fails, the compiler tries to use the built-in conversion for the actual arguments and then uses the function whose match is unique. If the conversion matches with more than one function definition, then the compiler generates an error message and fails the compilation process. Suppose we are using the following two function definitions:
+       * long square(long n);
+       * double square(double x);
+       
+       In this case, a function call, such as square(19), will cause an error because the int argument can be converted to either long or double; thereby, creating an ambiguity so as to which version of square should the compiler use.
+   4. If all the preceding steps fail, then the compiler will try the user-defined conversions to find a unique match. User-defined conversions are often used in handling class objects.

Let's now learn why overloading is useful in defining constructors and member functions of a class.

# ### Overloading Constructor Functions

A constructor function is a special type of function that is present inside a class definition and invoked every time an object is instantiated in a program. The primary benefit of constructor function is that it frees a programmer from explicitly initializing each object after it is created in the program. The programmer can write a constructor in the class definition that initializes the data members of an object and whenever the object is instantiated, the constructor for that class is fired automatically and it executes the block of code within the constructor function. Now, in this section, we learn how to overload constructor functions of a class and what benefits it gives us. In real life programming, it is very common to find overloaded constructor functions.
