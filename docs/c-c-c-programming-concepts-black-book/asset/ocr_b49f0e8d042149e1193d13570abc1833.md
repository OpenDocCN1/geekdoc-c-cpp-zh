The CLR uses the JIT compiler to convert the MSIL code into the managed native code on the demand basis as and when each part of the code is required. In addition, it optimizes the invoked module for the first time during compilation. The C# program executes the native code even if the code is initially compiled into MSIL. Therefore, the program will run nearly as fast as it can if it is compiled into the native code at the first place. However, in .NET environment, the JIT compiler gains more portability due to MSIL. Therefore, the JIT compiler dynamically converts the CIL or MSIL to a managed native code that is optimized for execution on an operating system. Moreover, JIT compilation takes place only when any method is invoked for the first time to provide the optimized code.

There are three different types of JIT compilers, which are as follows:

+   - **Pre-JIT compiler** → Compiles the entire code into the native code completely
+   - **Econo JIT compiler** → Compiles the code part by part as and when required
+   - **Normal JIT compiler** → Compiles only that part of the code when it is called for compilation and places the code in cache

When we compile the C# program, metadata also results as an output along with the MSIL. It contains the following:

+   - Information of the data used by the program
+   - The versioning information
+   - The reference information

The same file contains both the metadata and MSIL. The existence of the metadata eases the execution method and enables a code to interact with other code. Using metadata, the .NET application has the following benefits:

+   - Application does not require any header files.
+   - Metadata holds the requirement to execute .exe or .dll files.
+   - Using metadata, components do not need to register in the registry.
+   - An object's field can be automatically serialized/deserialized.
+   - Using metadata at runtime, an application can determine the kind of types the application holds and get the information of the members that type defines. This is also known as late binding.
+   - Components can be made reusable using metadata. They can be used by different languages.

CLR provides the following services:

+   - Memory management
+   - Threads
+   - Garbage collection
+   - Exception handling
+   - Security
+   - Application isolation
+   - Data interaction
+   - Encryption services
+   - Deployment
