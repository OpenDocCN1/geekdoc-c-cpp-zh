# Implementing Classes in C#

To declare a class in the .NET platform, we first need to create a class file and then write the class definition in it. Perform the following steps to implement a class for a console application:

+   1. Open a Notepad file and save it with the name Employee.cs, as shown in Figure 18.1:

![](bbox=[0.293, 0.233, 0.729, 0.517])

+   2. Store the file at the appropriate location in your system. In our case, we have stored the file at the C:\CSharp location.

+   3. Write the required classes for an employee in the Example.cs file, as shown in Listing 18.1:

# Listing 18.1: Showing the Structure of the Employee Class

```
```csharp
using System;
namespace Employee
{
    public class Program
    {
        public static void Main()
        {
            //Manipulate Employee object
        }
    }
    public class Employee
    {
        //Definition of Employee
    }
}
```
```

In Listing 18.1, we have declared a common namespace to be used in the console application and then defined the Employee class in it. This is a good practice to write the name of the namespace similar to the name of the file as it helps in avoiding problems related to naming collision.
