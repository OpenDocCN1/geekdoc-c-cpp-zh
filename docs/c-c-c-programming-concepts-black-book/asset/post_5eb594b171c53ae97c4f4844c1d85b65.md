### The setf() Function

There are two basic syntaxes to explain the use of setf() function, given as follows:

```cpp
fmtflags setf(fmtflags fmtfl);
fmtflags setf(fmtflags fmtfl, fmtflags mask);
```

The first syntax sets the stream's formatting flags whose bits are set into fmtfl, leaving the remaining unchanged, as if a call to flags(fmtfl | flags()). The second syntax sets the stream's format flags whose bits are set in both fmtfl and mask. It also clears the format flags whose bits are set in mask, but not in fmtfl, as if a call to flags((fmtfl & mask) | (flags() & ~mask)).

Consider the following program:

```cpp
#include <iostream>
using namespace std;
int main ()
{
    cout.setf(ios::hex, ios::basefield);       // set hex as the basefield
    cout.setf(ios::showbase);                  // activate showbase
    cout << 100 << endl;
    cout.setf(0, ios::showbase);               // deactivate showbase
    cout << 100 << endl;
    return 0;
}
```

The output of the preceding program is as follows:

```text
0x64
64
```

### The unsetf() Function

The unsetf() function clears the flags corresponding to the bits set within the parameter mask. The parameterized manipulator resetiosflags behaves similar to this function. The syntax of unsetf() function is as follows:

```cpp
void unsetf(fmtflags mask);
```

Consider the following example:

```cpp
#include <iostream>
using namespace std;
int main ()
{
    cout.setf(ios_base::hex, ios_base::basefield);
    cout.setf(ios_base::showbase);
    cout << 100 << endl;
    cout.unsetf(ios_base::showbase);
    cout << 100 << endl;
    return 0;
}
```

The output of the above program is as follows:

```text
0x64
64
```

### The width() Function

The width() function sets the required field size for displaying the output. The two types of width() function may be expressed as follows:

```cpp
streamsize width() const;
streamsize width(streamsize wide);
```

The first function returns the current value of the field width and the second function sets a new field width for an object.

Consider the following code:

```cpp
#include <iostream>
using namespace std;
int main ()
{
cout << 100 << endl;
cout.width(10);
cout << 100 << endl;
cout.fill('x');
cout.width(15);
cout << left << 100 << endl;
return 0;
}
```

The output of the preceding code is as follows:

```text
100
       100
100xxxxxxxxxxxx
```

### The fill() Function

The fill() function sets the padding used to fill the unused portions of a field. The two types of fill() function are given as follows:

```cpp
char fill() const;
char fill(char fillchar);
```

The first function returns the fill character. The second function sets fillchar as the new fill character and returns the previously set fill character. Consider the following example:

```cpp
#include <iostream>
using namespace std;
int main ()
{
char prev;
cout.width(10);
cout << 60 << endl;
prev = cout.fill('x');
cout.width(10);
cout << 60 << endl;
cout.fill(prev);
return 0;
}
```

The output of the preceding example is given as follows:

```text
        60
xxxxxxxx60
```

### The precision() Function

The precision() function sets the number of digits to be displayed after the decimal point of a float value. The two types of precision() function are as follows:

```cpp
streamsize precision() const;
streamsize precision(streamsize prec);
```

The first version of the function returns the value of the present floating-point precision field for a stream. The second version of the function sets it to some new value.

The specific floating-point precision determines the number of digits written upon the insertion operations to convey the floating-point values. How that is interpreted depends upon the floatfield format flag defined to some specific notation (each fixed or scientific) or it truly is unset (while using particular default notation, which is neither fixed nor scientific). Consider the following program:

```cpp
#include <iostream>
using namespace std;

int main ()
{
double f = 8.68768;
cout.setf(0, ios::floatfield);        // floatfield not set
cout.precision(5);
cout << f << endl;
cout.precision(12);
cout << f << endl;
cout.setf(ios::fixed, ios::floatfield);   // floatfield set to fixed
cout << f << endl;
return 0;
}
```

The output of the preceding program is given as follows:

```text
8.6877
8.68768
8.687680000000
```

Notice that the first number written is just five digits lengthy, while the second number is six digits lengthy, but not much more, even though the actual stream’s precision should be 12. This happens because precision with the whole default float area only specifies the most number of digits being displayed, although not the particular minimal. The third quantity displays the 12 digits following the decimal point, as the floatfield format flag is in this case set to fixed.

> **NOTE**
>
> With the exception of the field width, all the format parameter settings are permanent. The field width parameter is reset after each use.

## Manipulators

The `<iomanip.h>` header file provides a few functions called manipulators, which can often manipulate the formats of output. These functions provide the same features that adhere to that of the ios functions and format flags. Manipulators are simpler to use than their counterparts from the ios class. Two or more manipulators can be used in a chain in one statement as:

```cpp
cout << manip1 << manip2 << manip3 << item;
```

This kind of concatenation is helpful when we wish to display several columns of output. Format control sometimes demands calling a stream’s member functions. However, in case when we need to change formats inside a shift expression, the requirement of manipulators comes into play. Table 15.6 provides some frequently used manipulators with their effects:

**Table 15.6: Frequently Used Manipulators**
