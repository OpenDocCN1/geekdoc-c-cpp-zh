
Let’s demonstrate the recursive function usage in C++ as follows:

```cpp
1:// Demonstrating recursive function usage in C++ with factorial calc
2:#include <iostream>
3:using namespace std;
4:
5:long factorial(long num)
6:{
7:    if (num >1)
8:        return (num * factorial(num-1));
9:
10:    else
11:        return 1;
12:}
13:int main ()
14:{
15:    long fact;
16:    fact = factorial(5);
17:    cout << "Factorial of 5 is "<<fact;
18:    return 0;
19:}
```

The preceding program calculates the factorial of 5 in a recursive manner. In line number 8, the factorial function is called from within the same function itself. Note that the if condition in line number 7 is known as the base condition or terminating condition of recursion and the program executes based on this condition. Not going into much details of recursion, we can still observe that while calculating the factorial value of 5, the same factorial function is called with an argument of 4 with some additional information. Similarly, for factorial 4, a call will be made to factorial 3 with some multiplicative constant. This way it goes until the factorial function with argument 1 is called, which is the base condition, and recursion will break at this point. That is, when the recursive factorial function is called with argument 1, it returns argument 1; else, it returns the product of num with factorial (num-1), which in turn again makes a call to factorial with num-1 as argument. On the other hand, the non-recursive version of the same function should use a loop from 1 to num.

Now, let’s learn how a recursive call is made. When a function makes a call to itself, a new set of local or temporary variables (or arguments) are allocated storage on the stack and the function code is executed with all these new variables. A recursive call does not make a new copy of the function; only the arguments used are new for each call to the function. As each recursive call returns, its set of local variables and arguments are removed from the stack, and the program flow returns to the function invoking point. Although recursive programs are targeted to solve a particular class of problems, yet their usage in programs do not significantly reduce code size and improve memory utilization. It has been seen that in most of the cases, the recursive versions of a program is slower than its iterative counterpart. In addition, there are high chances of stack overrun, if the base condition of the recursion is not set properly. This recursive calling of functions and maintaining a stack overhead for creating and deleting local variables and parameters each time a call is made and returned, adds a good amount of overhead in function execution. However, as an advantage of recursion, we can say that it makes the code appear cleaner and it is the only way to implement certain class of problems in a simpler way than their iterative counterpart.

## Dynamic Memory Allocation and Deallocation Operators

Before discussing dynamic memory allocation and deallocation in C++, let’s discuss a little bit about the traditional way of dynamic memory management in C language. C language handles dynamic memory allocation by using calloc and malloc functions. In addition, it handles deallocation by using the free function. Note that all the memory allocation and deallocation is done at runtime and not at compile time. The primary advantage of using dynamic memory allocation is when we have no idea till runtime that how much memory is required to allocate. In case, our requirement is clear at compile time, we could have used arrays and strings to handle it. However, even with arrays and strings, that is, with pre-allocated buffers, we overcommit our memory requirement, and most of the allocated buffers remain unused at runtime occupying primary memory storage.

As we know that, when the requirement is unknown till runtime, it is beneficial to use dynamic allocation. Consider an example, where a user inputs the number of questions he/she wants to enter into a system and then starts entering one by one. Now, let’s assume that each question is kept in a buffer during the program, as the user enters it. In this case, one way is to limit the question count to a MAX value, restrict the user from entering anything more than MAX, and declare an array of strings of MAX size to keep the questions. One biggest flaw with this approach is that if the user enters a lower number as question count, then during runtime, most of the program memory is wasted, as MAX number of buffers are pre-allocated but only few of them are used. The most elegant way to handle this situation is to use the dynamic memory management approach. In this approach, we wait till the user enters the number of questions and allocate the space based on the user’s input. Such situations can be handled and managed in C++. Although, both the functions of C, that is, calloc and malloc, are available and legal to use in C++, it also defines two unary operators **new** and **delete** that perform the task of allocating and deallocating the memory in a better and easier way at runtime. Let’s learn about these operators in detail.

The new operator is a unary operator that can be used to create objects of both predefined and custom defined data types. Let’s see how to use the new operator for dynamic memory allocation. Following is the basic syntax of using the new operator in C++:

```
Pointer_variable = new data_type;
```

In the preceding syntax, Pointer_variable is a pointer type variable of data type and a call to new data type returns the address of the newly created object or NULL, if sufficient amount of memory is not available. Consider the following example:

```
int *ptr;
ptr = new int;
```

In the preceding example, we have declared an integer pointer variable ptr and assigned a new memory location dynamically using the new operator. This operator points the pointer to the address of a memory location that can accommodate a member of size data type, which in this case is an integer variable. Alternatively, we can also combine the preceding two lines into a single line as follows:

```
int *ptr = new int;
*ptr = 5;                         //value is assigned to the newly created memory
// option
```

In the first line, we have created a pointer variable and assigned it to the address of a memory location created dynamically with the new operator. In the second line, we have assigned a value to it by accessing the storage cell at the address by indirection operator *ptr. Now, let’s learn about another variant of the new operator, where we can create and assign or rather initialize the new memory location with a value as follows:

```
int *ptr = new int (5); //value is assigned to the newly created memory location
```

The preceding code declares a pointer variable ptr of type integer and allocates a memory location in the main memory of the computer, pointed to by the pointer variable ptr and sets the newly allocated memory location with a value of 5.

Till now, we have learned to create a single memory location dynamically with the new operator and assigned it to a pointer variable of similar data type, where the data type can be either default or basic data types, or custom or user-defined data types. Now, let’s learn how to allocate a set of memory locations at the same time while using the new operator, which is shown as follows:

```
pointer_variable = new data_type [size];
or
int *arr = new int [10];          // creates a dynamic array of size 10 for storing
                                  // integers.
```

The preceding code snippet demonstrates how to allocate more than one location at the same time in C++. Similar can also be done for custom or user-defined data types, shown in the following program:

```cpp
1:  // Demonstrating "new" operator usage for user-defined data types
2:  #include <iostream>
3:  using namespace std;
4:
5:  struct employee_info
6:  {
7:      char   name[20];
8:      int    age;
9:      double salary;
10: };
11:
12: int main()
13: {
14:     struct employee_info *emp;
15:     emp = new employee_info [10];
16:     .....
17:     //processing done on emp list.
18: .....
19:     return 0;
20: }
```

In the preceding program, we have defined a custom data type employee_info that contains the name, age, and salary of the employee. Now, we have used dynamic memory allocation to get the list of 10 employees, pointed to by the emp pointer. Then, after processing the details of each employee, we have deallocated the memory to return it to the operating system’s free memory pool. In the program, as our objective is to show how an array of user-defined data type can be dynamically created with new operator, we have eliminated the processing part with the emp array. In line number 15, observe that an array of user-defined data types is created dynamically in C++ program.

Similar to creating a one-dimensional array by dynamic allocation using the new operator, we can also create a multi-dimensional array. Following are some declarations to dynamically allocate multi-dimensional arrays, with a mix of both legal and illegal declarations:

```cpp
1: ptr_to_array = new int[3][4][5];       // legal
2: ptr_to_array = new int[n][4][5];       // legal
3: ptr_to_array = new int[3][n][5];       // illegal
4: ptr_to_array = new int[3][4][n];       // illegal
```

In case of multi-dimensional arrays, C++ permits the first dimension to be a variable, whose value can be supplied at runtime, but all other dimensions must be constant at the time of declaration. For example, in line number 2, we have kept the first dimension of a three-dimensional array to a variable n, which we are going to set at runtime, but all the other dimensions are specified and constant at compile time. On the other hand, compiler will generate an error while executing line number 3 and line number 4. Therefore, readers are requested to avoid such syntaxes while writing a program.

Consider a situation where allocation to memory is done but those memory blocks are not returned back to the free memory pool. It is a bad practice to do such things, as it might lead to situations, such as memory crash. Let’s now learn how to free the memory block at runtime, which was earlier fetched with a new operator. The golden rule says that when a data object is no longer required, it should be destroyed and the memory space should be released for reuse. In C++, the tool responsible for freeing the memory is a unary operator called delete. A perfect program should execute equal numbers of new and delete statements within its lifetime; otherwise, memory leaks would be present in the program.
