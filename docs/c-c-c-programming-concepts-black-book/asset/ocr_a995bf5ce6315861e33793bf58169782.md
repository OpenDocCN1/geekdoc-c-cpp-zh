# ## Quantifiers

LINQ standard operators provide three types of quantification operators. These operators are used for conditional checking throughout a collection. The three types of quantification operators are given as follows:

+   - All
+   - Any
+   - Contains

The *All* operator is used to check whether all the elements in a collection satisfy a condition by using the *All()* extension method. For example, this operator can be used to check whether all the elements in a collection are even. On the other hand, the *Any* operator is used to check whether any element in a sequence satisfies a condition by using the *Any()* extension method. For example, this operator can be used to check whether any element in a collection is even. The *Contains* operator is used to check if a particular element exists in a collection by using the *Contains()* extension method.
