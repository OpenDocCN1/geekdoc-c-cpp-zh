
## Preface

Chapter 1 introduces all the basic building blocks of C, such as variables, constants, expressions, and character sets. It will also enlighten readers on decision-making capabilities in C; this includes a comprehensive coverage of conditional statements and relational and logical operators. It is needless to mention that any programming language is not complete without the concept of loops. C happens to be no exception, so the chapter covers a vast concept of loops in C, where we will learn about for, while, and do-while loops. But prior to all this, we need to know how C evolved and what is meant by a programming language.

Chapter 2 covers the different aspects of functions in C. Function definition and declaration along with different calling conventions will be discussed in this chapter. Calling conventions include call by value as well as call by reference with their basic concepts. We learn about function prototypes and their importance and the implicit int rule for function prototypes. The chapter will also enlighten us with important concepts such as recursion and storage class specifiers.

Chapter 3 explains the functionalities of a pointer. Single and multi-dimensional arrays and their implementations using pointers are a major part which will be covered. Pointers have a vast range of applications when they are used at tandem with functions. Accessing functions using pointers and all the other use cases of function pointers will be covered in the latter half of this chapter.

Chapter 4 encompasses about strings and how to display them using pointers and the printf() function. Further, it discusses about some standard string library functions, such as strcat(), strcmp(), strlen(), strcpy(), strncpy(), strncat(), strchr(), and strspn().

Chapter 5 covers most of the advanced concepts in C programming. Structures and unions along with their implementations will be discussed in depth. An important aspect of C is the ability to perform Input/Output (I/O) operations using it. This chapter elaborates the concept of File Management using C. Binary and text files will be covered in this chapter. The chapter provides a brief explanation on bitwise operations in C along with their implementations. Memory management forms an indispensable part of any language and C happens to be no different. We learn about how C manages its memory along with all memory models that are used.

Chapter 6 discusses about another very important chapter on interrupts in C. We hardly see interrupts being discussed in any C/C++ book. We have covered that gap as well. This chapter deals with interrupt handling with the help of some C programs. We also learn how to call subroutines from interrupt handlers. Further, the chapter outlines re-entrant interrupt handlers as well as some useful signals. Next, we learn about Interrupt Service Routines and their implementation using C. In addition, we learn how to block signals. The chapter also discusses how exceptions and interrupts are handled by ARM processors.

Chapter 7 outlines the role of preprocessor while compiling a source code in C. It discusses the various preprocessor directives in C, such as #define, #ifdef, #endif, #undef, #else, #pragma, #error, and #line.

Chapter 8 provides a brief discussion on Standard Library Functions in C and stresses on mathematical functions, time functions, dynamic allocation functions, utility functions, and string functions.

Chapter 9 introduces more fundamentals and conceptual ideas rather than writing kernel modules one after another. It begins with an introduction to Linux operating system design and a discussion on Linux user space and kernel space. Then before introducing what a kernel module is, we will touch upon how Linux system call executes. Next, we will write our own kernel module and learn how to compile and execute it. This chapter will also cover the preliminary ideas in Linux task scheduling, character devices and device drivers, and interrupt handling.

Chapter 10 introduces the reader to parallel programming using C language. It defines threads and explains why we, as a programmer, require threads. After giving a formal introduction to Linux POSIX thread library, we will start writing and explaining different programs using threads. In this chapter, we will cover thread creation, termination of a thread, thread attributes, multi-threading synchronization, and thread cancellations. Once the reader is familiar with parallel programming in C, in the second part of the chapter, we learn the thread synchronization problems that come into play while working with multiple threads and then will try to propose a solution to this by the use of Mutex and Semaphores. This will make the reader more prepared while using threads in programs and will result in better programming standards.

Chapter 11 introduces a very interesting topic as an appendix that discusses on *Cross compilation over different Platforms*. It explains how to compile C codes in Linux environment and what cross compilation is and explains compiling codes across all platforms (i686, PowerPC, x86, x86_64). It also elucidates on creating .so's and dynamically linking libraries in Linux.

Chapter 12 focuses on the basics of C++ programming, starting from how to write our first C++ program to getting introduced with dynamic memory management while executing a C++ program. We learn about C++ basic data types, how variables are defined in C++, and operators and expression evaluations along with arrays, strings, structures, and references. Apart from all these, we also explore two most beautiful concepts in this chapter, that is, inline functions and recursions.

Chapter 13 deals with different Object-Oriented Programming (OOP) concepts, such as abstraction, encapsulation, inheritance, and polymorphism, and how we implement these using C++. This chapter will also elucidate on paradigms for problem solving and explain the differences between OOP and procedure-oriented programming. This chapter will focus on classes and data abstraction.

Chapter 14 explores the most powerful features of object-oriented languages in C++. We will uncover the concepts of polymorphism in C++, discussing function and operator overloading. We will also touch upon virtual functions in C++ along with its uses and application. Finally, the chapter covers another elegant tool in object-oriented paradigm - inheritance, its usage, and application. From this chapter onward, the reader will start getting a strong essence of C++ and start loving it.

Chapter 15 deals extensively on C++ I/O streams, binary I/O, open-mode bits, disk I/O using member functions, the stream status bits, member functions for accessing stream status bits, random access, formatted I/O, and manipulators. It also discusses another very important aspect in C++ programming: the exception-handling mechanisms. We will learn to define exception, describe error handling in C, describe implementation of exception handling using try, catch, and throw, handling uncaught exception, restricting exception and re-throwing exceptions, handling derived class exceptions, and the use of Standard Library exception hierarchy.

Chapter 16 introduces the .NET architecture, which includes CLR and class library. Then we explore the assembly in C# as well as the memory management in C# with the help of garbage collection technique. Toward the end of the chapter, we give an introductory discussion on C# language and represent a comparative study on various versions of C#.

Chapter 17 deals with the discussions about the basic functionality of C#. It focuses on various data types that can be used for C# along with the declaration of variables. Next, the chapter defines expression, operators, and operator precedence. Then you will get to know about the type conversion principle used for C#. After that, we will concentrate on some of the important data structures like arrays, strings, and structures. Then we will talk about collections, which will include stacks, queues. This chapter also includes a discussion on reference along with different flow control statements used in this chapter. It provides a brief discussion on function scope of variables, where we will define various scopes of a variable inside a function block. Further, this chapter includes a study on parameter passing and named and optional arguments used in a method in C#. At the end of this chapter, we will discuss about one of the most important aspects of C# language and namespace which provides a collection of classes, interfaces, structures, and enumerators.

Chapter 18 starts with a discussion of classes in the context of C#. Next, we will learn about the concept of inheritance, generalization, and specialization in respect of C#. We move on to the implementation of polymorphism in C#. Then, we will learn about function and operator overloading with suitable examples. This chapter also includes the study of objects and access modifiers and their implementation in real-life scenario. In addition, it explains interfaces and their importance in C# using an example. After that, we will talk about the enumerators and their usage in C#. At the end of this chapter, we will learn about the generics used in C# using a small Web-based application.
