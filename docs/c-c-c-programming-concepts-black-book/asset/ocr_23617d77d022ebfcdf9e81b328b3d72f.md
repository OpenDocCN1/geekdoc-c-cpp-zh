# *Function Overriding*

While implementing inheritance between two classes, a derived class inheritsall the member variables, methods, fields, and events fromitsbase class. Now if the derived class wants to change one behavior of the base class that has been defined in one of the methods of the base class, then it needs to define that method as a *virtual* method. Therefore, modifying the behavior of a method in a derived class is known as function overriding.

We can declare a method as a *virtual* method by writing the *virtual* keyword before the return type of the method. A *virtual* method can only be used to implement function overriding. It cannot be used for any other purpose. Using *virtual* methods, we can plan our programming in such a way that the derived class will have the opportunity to add its own properties to the overridden member methods. Now, a derived class uses the *override* keyword to override the method of a base class. In this case, the *override* keyword is placed just before the return type of the method. The polymorphism implemented in this case is that the name and the arguments of these overridden methods are same.
