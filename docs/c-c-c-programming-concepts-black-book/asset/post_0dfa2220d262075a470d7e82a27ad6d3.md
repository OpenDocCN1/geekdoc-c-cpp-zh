After that, we have added an event handler to the event using the delegate. In addition, the CallWhenPromoted() method is used as a delegate handler. ## Implementing Nested Classes

A class is said to be nested if it is declared inside another class. Nested class is used for implementing complex components in a .NET program. Implementation of nested class within a class provides access restriction. It implicitly gains the access level of the enclosing class. Listing 18.18 shows an example of nested class:

Listing 18.18: Showing an Example of Nested Class

```csharp
using System;
class Program
{
    public static void Main()
    {
        //Declaring an instance of OuterClass
        OuterClass outerClass = new OuterClass();
        outerClass.Print();
        //Declaring an instance of InnerClass
        OuterClass.InnerClass innerClass = new OuterClass.InnerClass();
        innerClass.Print();
    }
}
class OuterClass
{
    public void Print()
    {
        Console.WriteLine("You are in outer class");
    }
    //definition of a nested class
    public class InnerClass
    {
        public void Print()
        {
            Console.WriteLine("You are in inner class");
        }
    }
}
```

In Listing 18.18, a nested class InnerClass has been defined inside the class OuterClass. They both contain the Print() method. In the Main() method, the OuterClass object is declared using the normal approach. However, while declaring an object of the InnerClass, we need to use OuterClass as the InnerClass is defined inside it.

The output of the program is given as follows:

```text
You are in outer class
You are in inner class
```

## Concept of Inheritance, Generalization, and Specialization

One of the important properties of OOP is inheritance, which represents a parent-child relationship among the classes. As the name suggests, a program that implements inheritance has one or more base (or parent) classes from where the derived (or child) classes inherit the properties of the base classes. Moreover, a derived class can have its own properties. Note that a derived class can have more than one base class. Listing 18.19 shows an example of inheritance:

**Listing 18.19:** Showing an Example of Inheritance

```csharp
using System;
class Program
{
    public static void Main()
    {
        //Instantiating the objects of the three classes
        BaseClass baseClass = new BaseClass();
        DerivedClass derivedClass = new DerivedClass();
        DerivedDerivedClass derivedDerivedClass = new DerivedDerivedClass();
        //Calling the overridden methods
        baseClass.PrintLine();
        derivedClass.PrintLine();
        derivedDerivedClass.PrintLine();
    }
}
//Defining the Base class
class BaseClass
{
    public virtual void PrintLine()
    {
        Console.WriteLine("You are in Base class.....");
    }
}
//Defining the Derived class
class DerivedClass : BaseClass
{
    public override void PrintLine()
    {
        Console.WriteLine("You are in Derived class.....");
    }
}
//Defining the Derived class that inherits the DerivedClass properties
class DerivedDerivedClass : DerivedClass
{
    public override void PrintLine()
    {
        base.PrintLine();
    }
}
```

In the preceding program, BaseClass represents the parent class, which is inherited by the child class named DerivedClass. Now, DerivedClass has the same properties of BaseClass. In addition, DerivedClass can change the virtual method of BaseClass. Therefore, we have declared the PrintLine() method as a virtual method in BaseClass so that it can be overridden by DerivedClass. This is known as function overriding, which we discuss in the next section. In addition, we have defined another child class named DerivedDerivedClass, which inherits DerivedClass; therefore, this class possesses all the functionalities of DerivedClass. When this class tries to call the PrintLine() method of BaseClass, it will execute the same method of DerivedClass. The output of the program is given as follows:

```text
The output is
You are in base class.....
You are in derived class.....
You are in derived class.....
```

Generalization is a technique of collecting the shared characteristics of two classes and then combining them into a generalized superclass. On the other hand, specialization stands for creating a class, which has the characteristics of the generalized superclass, but it also has its own characteristics. Figure 18.8 shows an example of generalization and specialization:

![](img/43c5f409f9b17790a628c4b4df854b61_605_0.png)

**Figure 18.8:** Showing the Concept of Generalization and Specialization

In Figure 18.8, the Vehicle class extracts the common attributes from the Bike and Car classes. Therefore, the Vehicle class is a generalized class. On the other hand, the Bike and Car classes inherit the Vehicle class and add their own property called Type, which makes them a specialized class. Therefore, we can say that the generalized version of a child class is its base class; whereas, the specialized version of a base class is all its child classes. Therefore, generalization and specialization go hand in hand with inheritance. In other words, a generalized base class is derived by all its specialized child classes.

## Polymorphism

Polymorphism is another important feature of an OOP language. It is applied to methods, variables, and events; however, we use the concept of polymorphism mostly in methods. We can implement polymorphism in a C# program in the following two different approaches:

- Using function overloading
- Using function overriding

Function overloading represents a way to use the same name to define different methods whose numbers of arguments are different. On the other hand, by using function overriding, we can invoke any member method of a base class from the derived class and make changes in the derived member method, which already contains the content defined in the base class.

Let's learn about these two approaches in detail with some examples.

### Function Overloading

Each method consists of method name and a list of arguments. If we use the same name to define two different methods having different set of arguments, then those methods are overloaded. This approach is known as function overloading. Listing 18.20 shows an example of function overloading:

Listing 18.20: Showing an Example of Function Overloading

```csharp
public class Vehicle
{
   public int vehicleNo;
   public int vehicleName;
   public DateTime vehicleMFGDate;
   public string vehicleType;
   public long vehiclePrice;
   const int price = 8000;
   //defining overloaded member methods
   public void DefineVehiclePrice(string vehicleType)
   {
      if (vehicleType == "Two-wheeler")
      {
         vehiclePrice = price * 5;
      }
      if (vehicleType == "Four-wheeler")
      {
         vehiclePrice = price * 8;
      }
      if (vehicleType == "Eight-wheeler")
      {
         vehiclePrice = price * 10;
      }
      else
      {
         Console.WriteLine("Please enter a valid vehicleType");
      }
   }
   public void DefineVehiclePrice(string vehicleMFGDate, string vehicleType)
   {
      if (vehicleMFGDate < Convert.ToDateTime("2005/01/01"))
      {
         if (vehicleType == "Two-wheeler")
         {
            vehiclePrice = (price * 5) / 2;
         }
         if (vehicleType == "Four-wheeler")
         {
            vehiclePrice = (price * 8) / 2;
         }
         if (vehicleType == "Eight-wheeler")
         {
            vehiclePrice = (price * 10) / 2;
         }
         else
         {
            Console.WriteLine("Please enter a valid vehicleType");
         }
      }
      else
      {
         if (vehicleType == "Two-wheeler")
         {
            vehiclePrice = price * 5;
         }
      }
   }
}
```
