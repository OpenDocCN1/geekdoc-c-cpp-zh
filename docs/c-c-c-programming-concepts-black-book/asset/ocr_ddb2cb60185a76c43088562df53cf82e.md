In the preceding example, main() calls F1(), which calls F2(). As F2() is passed a value less than zero, an exception of type E1 is thrown. Moreover, since no exceptions are caught in F2(), execution jumps out of F2() and goes back to F1(). The variables of F2() are removed from the stack and any destructor for local objects is called. This is called **unwinding the stack**. Again, the F1() function does not catch any exception; therefore, its variables are removed from the program stack. Any destructor for local objects is called. The stack is further unwound. Now, we have reached main(). In this case, the exception is caught and handled.

Exactly what would happen in case main() did not capture the exception? This is actually the case with E2. The variables of main() function will be removed from the stack and any destructor will be called. As no handler is located, the **terminate()** system function is called and the program aborts, but this is undesirable. Attempts should be made to capture and handle all the exceptions.
