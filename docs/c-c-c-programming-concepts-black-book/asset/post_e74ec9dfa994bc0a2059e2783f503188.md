
## The continue Statement

As already learned, the break statement takes the program control out of the current scope of the loop or switch case. Sometimes, however, based on the conditions within the loop, a programmer might decide that instead of going out of the loop, the program control should go to the beginning of the loop. This can be done by using the continue statement in the program. While executing the program, if a continue statement is encountered, the program control immediately goes back to the beginning of the loop without executing the rest of the loop body.

As soon as the continue statement is encountered in a program, the program will check for the test condition again and increment or decrement the loop variable again before executing the loop body. Let’s write a program to demonstrate this feature. In the following program, we are showing the usage of a continue statement by means of a for loop:

```cpp
1: // Demonstrating the continue statement in C++
2: #include <iostream>
3: using namespace std;
4:
5: int main ()
6: {
7: for (int i=1; i<=10; i++) {
8:     if (i == 5) {
9:         continue;
10:     }
11:     cout << "The current value of i is " << i << endl;
12: }
13: return 0;
14: }
```

In the following program, the for loop iterates for ten times and prints each integer number except 5, on which a continue statement is applied.

Following is the output of the preceding program:

```text
The current value of i is 1
The current value of i is 2
The current value of i is 3
The current value of i is 4
The current value of i is 6
The current value of i is 7
The current value of i is 8
The current value of i is 9
The current value of i is 10
```

A declaration of function informs the compiler about the form and existence of a function prior to its use. C++ does not allow implicit declarations of functions; therefore, before using a function, it should be preceded with an explicit declaration. The compiler checks for the mismatches between the parameter of a function call and the function declaration based on the declaration and usage. For a program to be compiled correctly, both the declaration and the definition of a function should match to each other. ## Parameter Passing in Functions

Parameters or arguments are a piece of data passed from a program to a function. They allow a function to operate with different values, or even do different things based on the argument value, with which it is called. Following are the various types of values that can be passed to a function:

- **Constants**—A constant is an identifier, whose value ideally cannot be altered during the entire duration of program execution. Although a constant’s value is specified only once during the program duration, it can be accessed multiple times from within the program during its lifetime. Using constants in a program enhances the readability of the program and lower the chances of data redundancy errors in the program. From a program, we can make a call to a function with numeric or alphanumeric constants, as shown in the following code snippet:

```cpp
//Demonstrating functions in C++ with constant arguments
#include <iostream>
using namespace std;
void function(int num);
int main()
{
    cout<<"I'm in Main"<<endl;
    function(5);
    cout<<"I'm in Main again"<<endl;
}

void function(int num)
{
    cout<<"Argument in function is "<<num<<endl;
}
```

In the preceding code snippet, we are making a call to a function with an argument value of 5. Following is the output of the preceding code snippet:

```text
I'm in Main
Argument in function is 5
I'm in Main again
```

- **Variables**—A variable is a symbolic name associated with a value, which generally changes during the lifetime of a program. We can also pass variables in a function as an argument and access their values from within the function and process it, if required, as shown in the following code snippet:
