function Topological_Sort(Graph G with n nodes)
begin
    Q <- Initialize the array to null to store the
         output topological ordering
    n <- Count of nodes in graph
    inDegree[n] <- Initialize this array to null to
                   store the in-degree of the node
    v <- Initialize an integer that holds the intermediate node.
    H <- G

    while H is not empty do
    begin
        //Step 1
        inDegree[n] <- Store the indegree count of the particular node
        //Step 2
        if(inDegree[n] == 0)
        begin
            //Step 3
            v <- nodes[n]
            n <- n - 1
            remove v and all its outgoing edges from H
            Insert v to Q
        end
    end
end

```

The preceding algorithm implements the graph sort based on the in-degrees count. At the beginning of the algorithm, an array inDegree[] is declared to hold the in-degree values of each node in the graph. An array Q acts as the output array and the array H holds the graph G, which consists of the array nodes[]. For each node in the graph, first, the in-degree values of the nodes are calculated and then they are stored in the array inDegree[]. If the in-degree value for any node is zero, then that node and its outgoing edges are removed from the graph H and that graph node is then inserted in the output array Q. This process decrements the node count of the graph by 1 and is repeated until graph H is empty. At the end of this process, Q holds the graph nodes in a sorted order that forms a path to reach the destination from the source that passes through each node.

The complexity of the algorithm depends on the number of nodes and the number of edges the graph contains. For a graph with N nodes and E edges, the complexity of the graph sort is calculated as O(E + V). Therefore, the best case, the worst case, and the average case complexities are the same for this sorting technique.
