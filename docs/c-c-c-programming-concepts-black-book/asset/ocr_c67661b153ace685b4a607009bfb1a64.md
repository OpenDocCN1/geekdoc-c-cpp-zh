# Ordering Operators

Ordering operators in LINQ are used to sort a collection. There are five types of ordering operators:

+   - OrderBy
+   - OrderByDescending
+   - ThenBy
+   - ThenByDescending
+   - Reverse

The *OrderBy* operator sorts the values in the ascending order; the *OrderByDescending* operator sorts the values in the descending order; the *ThenBy* operator acts as a secondary sort in the ascending order; the *ThenByDescending* operator acts as a secondary operator in the descending order; and the *Reverse* operator reverses the order of a collection.
