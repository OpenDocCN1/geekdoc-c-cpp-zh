# Protected

The protected access modifier is used when inheritance is implemented in a program. If we define a member of the base class as protected, the member can be accessed from the class that derives it. Therefore, the access of those members is restricted to the base class and its derived class only. The keyword protected is used to declare a member as protected. Listing 18.32 shows an example of the protected access modifier.

**Listing 18.32:** Showing an Example of the Protected Access Modifier

```
```csharp
using System;
class Vehicle
{
    protected string type;
}
class Owner
{
}
class Car : Vehicle
{
    static void Main()
    {
        Car car = new Car();
        car.type = "Four-wheeler";
        Console.WriteLine("The type of the car is " + car.type);
    }
}
```
```

As shown in the preceding program, the Owner class does not derive the Vehicle class; therefore, it will not have any access to the protected members of the Vehicle class. The output of the code is given as follows:

```
```text
The type of the car is Four-wheeler
```
