
Listing 1.26 shows how switch statements can be nested inside each other. Whenever the break statement inside the innermost switch statement gets executed, the control comes out from the outer switch statement as well.

## Block Statements

C belongs to a family of block structured programming languages. A block is nothing but a collection of statements grouped together. A block structured programming language permits the creation of blocks, nesting of blocks, and variable declaration within a block. If closely noticed, we can see that C prohibits declaration of a variable in middle of a block. It is mandatory in C that all the variable declarations are made at the beginning of a block. Nowadays many compilers allow variable declaration anywhere inside a block but it is not a part of the ANSI standard. A block statement always starts with and ends with a curly brace.

Listing 1.28 shows how block statements are written in C:

**Listing 1.28: Writing Block Statements in C**

```c
#include<stdio.h>
int main()
{
    int i;
    for(i=1;i<10;i++)
    {
        int i;
        i=20;
        printf("\n I %d ",i);
    }
    printf("\n Another I %d ",i);
    getch();
}
```

## Looping in C

Till now, we have discussed sequential and decision making statements, such as if and else constructs. These sets of instructions are always executed exactly once. However, while dealing with a programming language, one must always keep in mind that there are situations where we need to perform a said action, repetitively. Decision making statements do not provide us with the flexibility of performing those tasks. We can handle this scenario through loops. One of the major aspects of looping in C is the ability of performing some parts of instructions repetitively while keeping the other executions constant.

A loop generally has four parts:

- Initialization
- Test condition
- Increment
- Body

It is not mandatory that all the steps mentioned must be performed in the same order.

### The while Loop

Let's take a real life scenario where we need to add a number till 100 and provide the sum as the output. The control flow shown in Figure 1.5 describes how the while loop can be used to solve the problem:

![](img/43c5f409f9b17790a628c4b4df854b61_80_0.png)

**Figure 1.5:** Flow Chart of the while Loop

Figure 1.5 shows the basic building blocks of a while loop. The first statement defines initialization where we have taken the COUNT variable and assigned it a value 1. Next comes the test condition, which is a decision making statement. Inside the test condition, we check whether the value of COUNT is lesser than 100 or not. If the value happens to be less, then we perform certain tasks else we exit from the flow graph. One of the actions that we perform inside the while loop is incrementing COUNT with one. Listing 1.29 illustrates the concept of looping in C:

**Listing 1.29: While Loop in C**

```c
#include<stdio.h>

int main()
{
    int count;
    int sum=0;

    count =1;                     /* Initialization   */
    while(count <= 100)           /* Test Condition */
    {
        sum += count;
        count++;                  /* Increment Statement */

    }
    printf("\n Sum = %d ",sum);
    getch();
    return 0;
}
```

The lines of statement inside the curly braces that follow “while” in Listing 1.29 forms the body of the whole loop. At first, the test condition gets executed and if it is found to be true, then all the statements present inside the body of the loop get executed. The process is repeated until the test condition turns out to be false. Each execution of the loop is also known as iteration. In Listing 1.29, the statements inside the loop are going to get executed for 100 times. At the 101st iteration, the test condition fails and the control comes out of the loop. The following code snippet shows how to construct a while loop:

```text
    Initialization of loop-control variable
    while (test condition is true)
    {
        perform certain actions;

        increment loop-control variable;

    } end loop
```

It should be kept in mind that a test condition should eventually turn false, else a while loop will always keep on executing endlessly.

Consider the following example:

```c
    int count = 10;
    while(count < 15 )
    {
        printf("\n Inside while loop");
    }
```

The loop given in this example will keep on executing infinitely as the test condition will never turn out to be false. A loop counter can be modified in any way possible. Any logical operation can take place on the loop counter.

### Nesting of the while Loop

It is possible to have multiple while loops getting executed simultaneously one inside the other. Such executions are called nesting of the while loop. Let’s consider an example where we need to display factorials of all the numbers ranging from 1 to 10. In order to address this problem, we need to have nesting of the while loop.

Listing 1.30 shows the nesting of the while loop:

**Listing 1.30:** Nesting of the while Loop

```c
#include<stdio.h>

int main()
{
    int factorial;
    int inner_count;
    int outer_count;

    outer_count=1;
    factorial=1;

    while(outer_count <= 10)
    {
        inner_count=1;
        while(inner_count <= outer_count)
        {
            factorial*=inner_count;
            inner_count++;
        }
        printf("\n Factorial of %d is %d ",outer_count,factorial);
        factorial=1;
        outer_count++;
    }
    getch();
}
```

The output of Listing 1.30 is given as follows:

```text
Factorial of 1 is 1
Factorial of 2 is 2
Factorial of 3 is 6
Factorial of 4 is 24
Factorial of 5 is 120
Factorial of 6 is 720
Factorial of 7 is 5040
Factorial of 8 is 40320
Factorial of 9 is 362880
Factorial of 10 is 3628800
```

As stated in Listing 1.30, we have two nested while loops. The outer one controls the range of data generation, i.e. it iterates from one to ten. The inner loop is used to calculate the factorial for each iteration of the outer loop.

### The for Loop

The for loop is one of the most-commonly used loops in the C language. The main advantage of using this loop is that one can initialize, test, and increment the loop-control variable all at once using a single statement. This makes the for loop more flexible to use.
