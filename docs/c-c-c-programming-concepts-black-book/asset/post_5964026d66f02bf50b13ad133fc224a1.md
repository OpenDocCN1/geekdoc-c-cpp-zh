### Clicking the Append Text Button

The application also provides the append operation, where text can be appended at the bottom of the file. When the Append Text button is clicked, the Web page is populated with a new blank text box and two buttons, named Append and Cancel. Listing 21.10 shows the C# code for the append operation:

**Listing 21.10:** Showing the `btnAppendText_Click()` Method

```csharp
protected void btnAppendText_Click(object sender, EventArgs e)
{
    CheckVisibility("append");

    txtAppendText.Visible = true;
    btnAppend.Visible = true;
    btnCancelAppend.Visible = true;
}
```

In Listing 21.10, the `CheckVisibility()` method is used to control the visibility of the controls used for the file modification and upload operations. Figure 21.7 shows the Web page after clicking the Append Text button:

![](img/43c5f409f9b17790a628c4b4df854b61_742_0.png)

**Figure 21.7:** Displaying the Web Page after Clicking the Append Text Button

After providing the text to be appended at the end of the file through the new text box, click the Append button. First, it gets the selected file path using the `ValuePath()` method. Then, by using an instance of the `StreamWriter` class, it writes the text to be appended in the file using the `WriteLine()` method. Simultaneously, it also updates the first text box that holds the content of the file. This method refreshes the content of the first text box by newly saved file content. Listing 21.11 shows the code that executes after clicking the Append button:

**Listing 21.11:** Showing the `btnAppend_Click()` Method

```csharp
protected void btnAppend_Click(object sender, EventArgs e)
{
    string path = tvFolderList.SelectedNode.ValuePath.Replace("/", "\\");
    try
    {
        if (File.Exists(path))
        {
            StreamWriter streamWriter = new StreamWriter(path,true);
            if (txtAppendText.Text != string.Empty)
            {
                string appendedText = "\r\n" + txtAppendText.Text;
                streamWriter.WriteLine(appendedText);
            }
            streamWriter.Close();
            txtHiddenAppendedText.Text = txtAppendText.Text;
            txtShowFile.Text = string.Empty;
            FileInfo file = new FileInfo(path);
            txtShowFile.Text = File.ReadAllText(path);
        }
    }
    catch (Exception ex)
    {
        lblError.Text = ex.Message;
    }
}
```
