# ### atanh()

The atanh() family of functions returns the arc hyperbolic tangent of the argument passed to them. The value of argument must be within the range of -1 to 1; otherwise, the compiler will throw an error. If the value of argument is equal to 1 or -1, then the compiler throws a range error. The signature of the atanh() family of functions is as follows:

```
~~~c
float atanhf(float param);
double atanh(double param);
long double atanhl(long double param);
~~~
```

The atanh(), atanhf(), and atanhl() functions were introduced by the C99 compiler. The atanhf() function is used for the float data type; whereas, the atanhl() function is used for the long double data type. Let's take an example of the atanh() function mentioned in Listing 8.6:

Listing 8.6: Usage of atanh() function.

```
~~~c
#include<stdio.h>
#include<math.h>

int main()
{
    double val = -0.5;
    printf("\n The Arc Hyperbolic Tangent of %f is %f ",val, atanh(val));
    getch();
}
~~~
```

Output of the preceding example is as follows:

```
~~~
The Arc Hyperbolic Tangent of -0.500000 is -0.549306
~~~
```

# ### tan()

The tan() family of functions returns the tangent of the argument passed to them. The value of argument must be in radians. The signature of the tan() family of functions is as follows:

```
~~~c
float tanf(float param);
double tan(double param);
long double tanl(long double param);
~~~
```

The tanf() and tanl() functions were introduced by the C99 compiler. The tanf() function is used for the float data type; whereas, the tanl() function is used for the long double data type. Let's take an example of the tan() function mentioned in Listing 8.7:

Listing 8.7: Usage of tan() function.

```
~~~c
#include<stdio.h>
#include<math.h>

int main()
{
    double val = -0.5;
    printf("\n The Tangent of %f is %f ",val, tan(val));
    getch();
}
~~~
```
