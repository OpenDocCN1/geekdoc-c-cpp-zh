As we have used a separate class library to write the zip operation, we need to add the reference to that library while calling any method residing in it. In our case, the name of the class library is ZipSource.cs, which we are referencing in the main class file called ZipFile.cs.

+   3. After getting the locations of the input and output files, the application compresses the files and directories recursively. It first compresses the files and then the folders residing inside the input directory, separately. For directories, the output location is same as C:\ZipFiles\. In this case, we have used a separate class library named ZipSource for writing the main methods for the zip and unzip operations. This class library contains three methods: `ZipFilesAndFolders()`, `CompressFile()`, and `UnzipFiles()`. For the zip operation, the first two methods are used. The `CompressFile()` method is called recursively from the `ZipFilesAndFolders()` method to execute the zip operation successfully.

In the first call of the `CompressFile()` method, the compression of the list of files take place and all the files are stored inside the specified output folder location. In this case, the format that is followed for the output file name that stores only the files inside the directory is C:\ZipFiles\<FolderName>_Zip.zip. public static void CompressFile(string zipFileName, string path)
{
    //Creating the zip file at the output location
    FileStream fileStream = File.Create(zipFileName);
    ZipOutputStream zipOutputStream = new ZipOutputStream(fileStream);

    //Setting the level of compression
    zipOutputStream.SetLevel(9); //9 defines the best compression
    string[] fileList = Directory.GetFiles(path);

    //Checking the existence of the file
    if (fileList.Length == 0)
    {
        fileStream.Close();
        File.Delete(zipFileName);
    }
    else
    {
        foreach (string file in fileList)
        {
            ZipEntry zipEntry = new ZipEntry(Path.GetFileName(file));
            zipEntry.DateTime = DateTime.Now;
            byte[] buffer = new byte[4096];
            zipOutputStream.PutNextEntry(zipEntry);

            using (FileStream fs = File.OpenRead(file))
            {
                int bufferBytes;
                do
                {
                    bufferBytes = fs.Read(buffer, 0, buffer.Length);
                    zipOutputStream.Write(buffer, 0, bufferBytes);
                } while (bufferBytes > 0);
            }
            zipOutputStream.CloseEntry();
        }
    }
}
