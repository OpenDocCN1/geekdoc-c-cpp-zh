Next, let's learn how to return a structure from a function.

# ## Returning a Structure from Function

In the previous section, we have learned how to pass structure members to a function. In the similar manner, we can make functions return the structure type variables as well. Listing 5.11 shows how to return a structure from a function:

Listing 5.11: Returning a Structure from a Function

```
~~~c
# include<stdio.h>

struct student
{
    char name[20];
    int class;
    int age;
};

struct student stu1 = {"Tanuman",12,16};
struct student* returnStruct();
int main()
{
    struct student *ptr;

    ptr = returnStruct();
    printf("\n Name %s Class %d Age %d ",ptr->name,ptr->class,ptr->age);
    getch();
    return 0;
}
struct student* returnStruct()
{
    return(&stu1);
}
~~~
```

In Listing 5.11, we have returned the address of a structure type variable from the returnStruct() function. In the main() function, the address is stored inside the structure pointer, which is used to display the members of the structure.

Output of the preceding program is as follows:

```
~~~text
Name Tanuman Class 12 Age 16
~~~
```
