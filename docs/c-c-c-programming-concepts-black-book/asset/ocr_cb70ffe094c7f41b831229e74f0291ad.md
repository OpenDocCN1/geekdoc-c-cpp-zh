# **Listing 17.42: Showing the Usage of *for* Loop**

```
~~~csharp
using System;
class program
{
    public static void Main()
    {
        Example e = new Example();
        e.PrintFibonacci();
    }
}
class Example
{
    public int i = 0;
    public Example()
    {
    }
    public void PrintFibonacci()
    {
        int f0 = 0;
        int f1 = 1;
        int f2 = 0;
        Console.WriteLine("The Fibonacci series is....");
        Console.WriteLine(f0);
        Console.WriteLine(f1);
        for (int i = 0; i < 10; i++)
        {
            f2 = f0 + f1;
            f0 = f1;
            f1 = f2;
            Console.WriteLine(f2);
        }
    }
}
~~~
```

The preceding program prints the Fibonacci numbers on the console with the help of the *for* loop whose loop limit is set to 10. Therefore, the *for* loop will execute ten times. We first initialize the first two numbers of the Fibonacci series. After that, we set the loop variable *i* to 0, keep the limit of *i* less than 10, and increment the value of *i* after the execution of the statements in the loop. Within the loop, we evaluate the next number in the Fibonacci series by adding the previous two numbers. At the end, we display the number on the console. The output of the program is as follows:
