# #define

The #define directive defines an identifier and a character sequence that will be substituted for the identifier each time the identifier is encountered in the source file. The identifier is referred to as macro name and the replacement process as macro replacement. The general form of the directive is as follows:

```
```cpp
#define MACRO_NAME    char-sequence
```
```

Notice that there is no semicolon in this statement. There can be any number of spaces between the identifier and the character sequence, but once the character sequence begins, it is terminated only by a newline. Consider the following popular example we use in programming:

```
```cpp
#define TRUE    1
#define FALSE   0
```
```

The preceding statements cause the compiler to substitute a 1 or 0 each time TRUE or FALSE is encountered in the program. Macro substitution is simply the replacement of an identifier by the character sequence associated with it. We can even use prepared error messages in macros, as follows:

```
```cpp
#define ERROR_MSG  "Error Occurred in program\n"
```
```

Now, whenever the macro ERROR_MSG is encountered, the value will be substituted in its place. One more important thing to mention about macros is that no text substitution occurs if the identifier is within a quoted string. For example, the following statement does not print “Error Occurred in program”:

```
```cpp
cout<<"ERROR_MSG";
```
```

We can also write multi-line macros as follows:

```
```cpp
#define ERROR  "This program has \
              encountered an error"
```
```

C and C++ programmers generally use upper case letters for defined identifiers. This convention helps the reader to understand that a macro replacement will take place. At times, as a typical usage of macros, we define the size of arrays or lists in macro, and operate on those data structures using the macro definition of size or max length, as a change in size of max limit only costs changing its value in the macro definition and not in all the places where it is used.

# Predefined Macro Names

A macro is a fragment of code, which has been given a name. Whenever the name is used, it is replaced by the content of the macro. We may define any valid identifier as a macro. The main benefit of using a macro is to group a common part of code, which are used multiple times in the entire program; thereby, increasing the readability of the source code. In addition, if something needs to be changed in the common code, then we need to change its related macros only. In such case, we do not need to change the common code. This makes macro very popular among programmers. C++ contains five built-in predefined macro names, which are given as follows:

+   - `__LINE__`
+   - `__FILE__`
+   - `__DATE__`
+   - `__TIME__`
+   - `__STDC__`

The __LINE__ and __FILE__ are the frequently used macros provided by C++. They help a lot during debugging a source program. The __LINE__ macro gives an integer value representing the current line in the source code file being compiled and the __FILE__ macro is a string literal containing the name of the source file being compiled. The __DATE__ macro contains a string of the form month/day/year. This string represents the date of the translation of the source file into object code. Similarly, the __TIME__ macro translate to hour:minute:second. The macro __STDC__ contains the decimal constant 1 and is used for ANSI C standards.
