In Figure 12.1, we have mentioned two broad classifications of C++ data types other than the built-in types. These two classifications are user-defined data types and derived types. A programmer can create user-defined types from a set of built-in data types. Following are the various user-defined data types:

- **Structure**—It is a collection of simple variables, which can be of basic data types or any custom or user-defined data types. Data items in a structure are referred to as members of the structure. Let’s declare a structure in C++ as follows:

```cpp
1:struct  employee_data
2:{
3:    char  employee_name[30];
4:    int   age;
5:    double salary;
6:};
7:struct employee_data emp;
```

In the preceding declaration, emp is a variable of type employee_data and contains all the members of the structure. That is, it contains employee_name, age, and salary, which can be accessed with the dot operator; for example, emp.employee_name, emp.age, and emp.salary. If we define emp as a pointer to the employee_data structure, then the access to internal structure members should be with a special symbol other than the dot operator, that is, ->. In this case, the internal data members of the structure will be accessed as emp->employee_name, emp->age, and emp->salary.

- **Class**—It is a tool of object-oriented approach in C++. By definition, a class is a description of a number of objects possessing similar characteristics. In object-oriented programming, objects are instances of a class and represent real world entities. A class is similar to a structure in definition, but with a little difference in usage and conception. Similar to structures, a class contains a set of member variables within it, but unlike structures, it also contains a set of member functions or methods to operate on those member variables. We learn more about classes in the next chapter, but for the sake of completeness, we are showing how to define a class and create objects of the class in the following code snippet:

```cpp

2: int  member_age;
3: char  member_name[30];
4: public:
5: void init_data() {
6:     member_age=0;
7: };

10:    class example    new_object;       // object of class example is defined here
```

- **Union—** A union is a memory location shared by two or more variables, generally of different types, at different times. Declaring a union is similar to declaring a structure. Following is an example of the union declaration:

```cpp
union example {
             type    var1;
             type    var2;

             type    var_n;
} union_variable;
union_type {
             int     var1;
             char    var2;
} u_var;
```

In the preceding example, we have defined a data member of union type, named u_var. In u_var, both the integer and the character data member share the same memory location. Obviously, int contains four bytes and char contains one byte, but if we check the size of u_var, it will be four bytes. This implies that union takes its size from the member of highest order present in it; in our case, it is four bytes for int. Moreover, at any point of time, we can refer to the data stored within the union as either int or char but not both. One of the best applications of union is expression trees for the evaluation of expressions.

- **Enumerations—** An enumerated data type allows us to attach names to numbers; thereby, increasing comprehensibility of the program. The enum keyword automatically enumerates a list of words or enumerators by assigning them numeric values. This facility provides an alternative way for creating symbolic constants. Following are some examples of enumerated data type in C++:

```cpp
enum process_states
{
    NEW,
    READY,
    RUNNING,
    IO,
    FINISHED,
};
Or
enum process_states
{
    NEW = 4,
    READY,
    RUNNING,
    IO,
    FINISHED,
};
Or
enum process_states
{
    NEW=4,
    READY=9,
    RUNNING=8,
    IO=2,
    FINISHED=1,
};
```

By default, the first enumerator of the data type takes the value 0 and then, each subsequent enumerator takes a value one greater than the previous enumerator does. Therefore, in the topmost enum process_states, NEW will take value 0, READY will take value 1, RUNNING will take value 2, IO will take value 3, and FINISHED will take value 4. We can also change the convention by setting the first enumerator of the enum to a particular value, and again, each subsequent enumerator takes a value one greater than the previous enumerator does. Therefore, in the second definition of enum process_states, NEW is assigned a value of 4, and consequently, READY will take value 5, RUNNING will take value 6, IO will take value 7, and FINISHED will take value 8. In addition, we can also set the values of an enum to all the custom values as shown in the third definition of the enum process_states.

Derived data types are those that are defined in terms of other data types. Following are the list of derived data types in C++:

- **Arrays**—An array is a homogeneous data type occupying a set of contiguous memory location where each cell in the array is accessed by increasing order of addressing. The application and usage of arrays in C++ is similar to that of in C. However, the definition and usage of arrays in C and C++ differ in how character arrays are initialized. For instance, the following statement is valid in C:

```c
char string [3] = "xyz"; // Valid in C
```

The preceding statement assumes that a programmer intends to leave out the NULL character \0 in the definition. However, the statement is invalid in C++. The size of string should be one character more than the total number of characters in the string, as shown in the following statement:

```c
char string [4] = "xyz"; // Valid in C++
```

- **Functions**—The definition, structure, and purpose of functions in C++ are similar to the functions in C. In addition, anything about functions that work in C, should also work in C++; however, C++ has enhanced the functionalities of functions and made them capable of doing several new things, such as overloading and overriding, which are based on object-oriented principles.

- **Pointers**—In C++, pointers can be declared and initialized as in the C language. However, C++ has introduced two new concepts that are related to pointers: constant pointer and pointer to a constant. Let’s learn about these two concepts with the help of the following examples:

```c
1: char * const char_ptr = "GOOD";          //constant pointer
2: int const *    int_ptr = &any_integer_variable;  //Pointer to a constant
```

Line number 1 shows the declaration of constant pointer, char_ptr. After its declaration, we cannot modify the address of char_ptr to which it is initialized.

In line number 2, we have declared a pointer to a constant int_ptr, which is an integer pointer that can point to an integer constant. It can point to any variable of correct type, but the content of what it points to cannot be changed.

- **References**—C++ introduces a new type of variable known as a reference variable, which provides an alternative name for a previously defined variable. For example, if we make var1 variable a reference to another variable var2 of the same type, then both var1 and var2 can be used interchangeably to access that variable. A reference variable can be created using the following syntax:

```c
Data_type & reference_var = variable_name;
```

In the preceding syntax, the & operator is used to define a reference.

Following is the example that shows how to declare a reference variable:

```c
int var1 = 200; // var1 is an integer variable
int & var2 = var1; // var2 is a reference variable of integer type referring to var1
```

In the preceding example, if we change the value by accessing any one of the variables, then the change immediately reflects into the other one.
