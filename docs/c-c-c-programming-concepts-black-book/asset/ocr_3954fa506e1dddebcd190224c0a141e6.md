# ## Constant Members

The const keyword helps us in preventing variables or function arguments to get modified by anyone else. Similar concept also can be extended for the class member variables and method. For a class, if we define a method as const, then the compiler will prevent us from modifying anything within that method. This behavior is in consistence with the literal meaning of constant. Real-life scenarios can be there when an argument is passed to a function as a reference and the owner of that argument does not want to modify the variable within the function. In other words, we can use the const keyword to protect that argument from being modified within the function. By specifying the argument as const, it is protected from getting modified within the scope of the function. For normal functions and variables, the behavior of const is not much different from the one in C language. C++ is superior since it extended this concept to classes and objects.

In this section, we will write two programs with const. The first one with a class with a const member function and the second one with a class object as const. Both the programs are simple and self-explanatory.
