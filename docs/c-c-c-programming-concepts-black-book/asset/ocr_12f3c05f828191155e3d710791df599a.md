**Q9.** Write a function `incrementByN()` to increment the value of an integer type variable declared in the calling function (`main`) by adding a given integer value to it. (The function should not return any value.)

**Q10.** Write `main()` to print the value of the integer variable before calling any function. Now, call a function and then print the value of the integer again. After calling the function, when the value of the variable is printed, it should print the updated value. Use the concept of reference variable.

**Q11.** Write a code to find the summation of all the elements of an integer array. Declare an array of integer and initialize it with 10 integers. Declare a pointer to integer and using this pointer, find the summation.

**Q12.** Write a code to declare an array of five pointers to character. Store five names in this array and sort it.

**Q13.** Write a code declaring a variable as a global variable and defining a function that returns a reference initialized to the global variable. Using the function, assign the value stored in the reference to a variable declared in `main()`.

**Q14.** Create a class Rectangle having the properties length and breadth and then perform the following:

+   a. Create a parameterized constructor for assigning customized values for length and breadth. Provide default values of 4 and 3 for length and breadth, respectively, which will be used when no values of length and breadth are provided for creating an object of Rectangle.
+   
+   b. Add member functions `findArea()` and `findPerimeter()` to find the area and perimeter of a Rectangle object, respectively.
+   
+   c. Add one more member function `isbigger()`, which takes a Rectangle object as input and returns true if the area of the current Rectangle object is greater than the one passed as parameter; otherwise, the function returns false.
+   
+   d. Write `main()` to test all the functionalities of the Rectangle class. Apply proper access specifiers for the properties and behaviors of the Rectangle class.

**Q15.** Create a class Employee having the properties empid, name, and basic. All must be declared using the private access specifier. Create another class Payroll having properties daRate, hraRate, and pfRate. Again, all must be declared using the private access specifier. Using the concept of friend, write a function to calculate the salary of an Employee object on the basis of a payroll object. Salary of an employee is calculated as:

`basic + daRate*basic + hraRate*basic - pfRate*basic.`

Write `main()` to test the preceding functionality.

+   
+   c. Add member function `findGrade()`, which returns the character A, B, C, D, F based on the total score range `>=80`, `/60–80/`, `/45–60/`, `/35–45/` and `<35`.
+   
+   d. Add a destructor for deleting the array of marks.
+   
+   e. Add a static member function `countStudents()`, which returns the number of objects created.
