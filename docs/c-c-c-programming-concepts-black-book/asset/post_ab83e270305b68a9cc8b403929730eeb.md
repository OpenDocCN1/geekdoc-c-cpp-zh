This concludes the case study which we have developed and modeled using UML. One can use the available tools, such as ArgoUML, ARTiSAN software, and GDPro, to design any UML diagram. However, the tool should support the following measures to provide a user friendly and effective way of designing any diagram:

- **UML designing**—Means tools should be used to draw any UML diagram.
- **Forward engineering**—Means any UML tool should create the necessary classes from its class diagram. Thus, any UML tool should not restrict itself in just designing a diagram. It can also convert that diagram to specific classes mentioned in the diagram. In this way, the tool can support forward engineering.
- **Reverse engineering**—Refers to the opposite of forward engineering. If someone uploads the code and wants to get the class diagram or any UML diagram, the tool should produce it.
- **Documentation**—Refers to an important part in developing any software. UML also includes writing templates for some of its diagram. Thus, it is required to support the documentation facility.

Some of the commonly used software that are used to draw UML diagram are as follows:

- **Action semantics**—Refer to a group of firms that has responded to the OMG's Request for Proposal (RFP) to define the action semantics for UML.
- **ARTiSAN software**—Provides a variety of UML-based CASE tools, including a real-time modeling tool.
- **ArgoUML**—Refers to a domain-oriented design environment that provides cognitive support for object-oriented design. It provides some of the same features of a commercial CASE tool. ArgoUML is the leading open-source UML modeling tool and includes support for all standard UML 1.4 diagrams. It runs on any Java platform and is available in 10 languages.
- **BridgePoint**—Refers to a tool to model executable and translatable UML diagram. It is an advanced tool to design UML that provides a reliable, regular, and consistent code for future use. BridgePoint incorporates the facility to implement any changing requirement, i.e., it supports manifestation of agile requirement.
- **Graphic Display Professional (GDPro)**—Refers to the software that is actually developed in Core Java and supports round-trip engineering, which is the combination of forward and reverse engineering. It allows the user to create Java bean files (Enterprise Java Beans (EJB)) and Extensible Markup Language (XML) descriptor for fast and accurate deployment of the code.
- **MagicDraw UML**—Refers to the commercial software for drawing UML diagram. It is especially known for its user-attractive features. This software is based on pure Java and can be easily downloaded from any site. It is fully featured and easily compatible with the latest UML standards.
- **Rational Rose**—Refers to a tool for UML drawing, which is owned by IBM. This software is actually developed for software engineering practice. It has the same features as other modern design tools for designing UML diagrams.
- **Visio 2000 Enterprise**—Provides an interface to draw important software engineering drawings such as UML diagrams, network diagram, or chart diagram. It creates ad hoc designs. Especially, for UML diagrams, it creates codes in Java or C++.
- **Visual Paradigm**—Refers to a tool to design UML, SysML, and database design diagrams, such as ERD or Data Flow Diagram (DFD). It supports the forward engineering concept.
- **MacA&D**—Refers to the software that is mainly used in Mac operating systems to draw UML-based designs. It also provides the database model designing and the concept of forward designing.
- **WinA&D**—Refers to the software that is used in Windows environment to support requirement management, modeling of software, forward engineering, reverse engineering, and flexible report generation.
