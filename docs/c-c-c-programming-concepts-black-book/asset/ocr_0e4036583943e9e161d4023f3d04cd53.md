# ## The this Pointer

Whenever a member function is called by an object, we can always access the object using an invisible pointer named the “this” pointer. The member functions of an object have access to the “this” pointer, which is a magical pointer that points to the object itself. In C++, the “this” pointer is a very useful tool that helps in accessing the object from within its member functions. This concept is illustrated through the following code snippet:

```
```cpp
#include <iostream>
using namespace std;

class example {
    int memberData;
public:
    example() {
        this->memberData = 1;
    }

    ~example() {
        this->memberData = 0;
    }

    void set_n_show (int var) {
        this->memberData = var;
        cout <<memberData<<endl;
    }
};

int main ()
{
    example obj1, obj2;

    obj1.set_n_show (99);
    obj2.set_n_show (88);
    return 0;
}
