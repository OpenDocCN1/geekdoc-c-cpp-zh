## The FileInfo Class

As already learned, the FileInfo class performs the operations, such as copying, creating, deleting, and opening a file. This class is mostly used in a situation where multiple operations need to be performed on a file. While instantiating the FileInfo object, we need to define the path for which the object is instantiated. Therefore, while accessing the methods through the object, we do not need to pass the path information.

The FileInfo object can be declared as follows:

```
FileInfo fileInfo = new FileInfo(path);
```

In the preceding declaration, path represents the file path along with the name of the file.
