### strtod()

The signature of the strtod() function is as follows:

```c
double strtod(const char *start, char **end);
```

The strtod() function converts a string representation of a number pointed to by a start pointer to a double and returns the result. The function strips all the white spaces from the string representation of the number. Each character that makes up the number is read. The function will stop working if any character is found that cannot be a part of a floating-point number. The end variable is set to the remainder of string. For example, if we want to convert 234.23tim, then 234.23 will be returned and the end pointer will point to tim. If the start pointer does not point to a number, then the function returns zero. In the C99 compiler, both the start and end variables are preceded by the restrict type qualifier.

### isalpha()

The isalpha() function returns a non-zero value when a letter or an alphabet is passed as an argument to it; otherwise, the function returns zero. The signature of the isalpha() function is as follows:

```c
int isalpha(int ch);
```

Let's take an example of the isalpha() function as mentioned in Listing 8.39:

**Listing 8.39:** Usage of isalpha() function.

```c
#include<stdio.h>
#include<ctype.h>

int main()
{
    char ch;

    printf("\n Enter any character -> ");
    scanf("%c",&ch);
    if(isalpha(ch))
    {
        printf("\n ALPHABET ");
    }
    else
    {
        printf("\n Not an ALPHABET ");
    }

    getch();
    return 0;
}
```

Output of the preceding example is as follows:

```text
Enter any character -> Q
Alphabet
Enter any character -> 3
Not an Alphabet
```

### iscntrl()

The iscntrl() function returns a non-zero value if the argument passed to it is a control character; otherwise, the function returns zero. In an American Standard Code for Information Interchange (ASCII) environment, the control character is a value between zero and 0x1F, or a value that is equal to 0x7F (DEL). The signature of the iscntrl() function is as follows:

```c
int iscntrl(int ch);
```

Let's take an example of the iscntrl() function as mentioned in Listing 8.40:

**Listing 8.40:** Usage of iscntrl() function.

```c
#include<stdio.h>

#include<ctype.h>

int main()
{
    char ch;

    printf("\n Enter any character -> ");
    scanf("%c",&ch);

    if(iscntrl(ch))
    {
        printf("\n %c is a Control Character ",ch);
    }
    else
    {
        printf("\n %c is not Control Character ",ch);
    }

    getch();
    return 0;
}
```

### ispunct()

The ispunct() function returns a non-zero value if the argument passed to it is a punctuation character; otherwise, it returns zero. The term punctuation is referred to all the printing characters that are neither alphanumeric nor space. Some examples of the punctuation marks are period (.), question mark (?), comma (,), semicolon (;), and hyphen (-). The signature of the ispunct() function is as follows:

```c
int ispunct(int ch);
```

Let's take an example of the ispunct() function as mentioned in Listing 8.42:

**Listing 8.42:** Usage of ispunct() function.

#include<stdio.h>
