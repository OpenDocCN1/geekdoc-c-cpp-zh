# XPath

The structured nature of XML document provides us an opportunity to address different parts of the XML document. As an XML document repeats its elements regularly, we can use this repetitive nature and develop an XPath expression to address a specific element. Therefore, XPath expressions are nothing but the expressions that help in highlighting a certain element of the XML tree. As already learned, we can view the XML document as an XML tree; however, using XPath, we can refer any tree node or prepare a list of tree nodes specifying the same element in the XML document. The slash symbol “/” is used to separate the location steps in the XML document. We can use the same XML tree specified in Figure 20.3 to some of the XPath expressions and their result, given as follows:

+   - To get the list of all the book nodes, the XPath expression will be `LIBRARY/BOOK`
+   - To get the list of all the books whose Author is Korth, the XPath expression will be `LIBRARY/BOOK[AUTHOR = “Korth”]`
+   - To get the list of names of all the books written by Korth, the XPath expression will be `LIBRARY/BOOK[AUTHOR= “Korth”]/NAME`
+   - To get the list of names of all the books available in the library, the XPath expression will be `//NAME`
+   - To select all the BOOK elements, the XPath expression will be `/*`
