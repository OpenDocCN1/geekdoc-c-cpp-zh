# # Statements in C

A statement in C refers to some action or group of actions carried out by a compiler. In C, there are three different classes of statements — expression statement, compound statement, and control statement. An expression statement consists of an expression followed by a semicolon. The execution of an expression statement causes the expression to be evaluated. For example, `c = a + b` can be treated as an expression statement, as it causes the expression at the right hand side of the assignment statement to be evaluated and assigned to the variable at the left hand side. Multiple individual statements inside a single block are treated as compound statements; whereas, individual statements can be either expression statements, control statements, or compound statements. Compound statements enable embedding statements within statements. Unlike expression statements, compound statements do not end in semicolon.

The following code represents an example of a compound statement:

```
```c
{
    a = 10;
    b = 10;
    c = a + b;
    printf("\n Result [%d]", c);
}
```
```

# # Decision Making

Decision making refers to the ability of a programming language to perform different sets of actions based on certain decisions. The major decision making modules in C are `if`, `if else`, and `else statements`. Apart from these, other statements like the `switch case` also help in making decisions; however, in this chapter, we will primarily be discussing the `if`, `if else`, and `else statements`.

# # The IF Statement

Like all other programming languages, C also uses the `if` statement for decision making. Moreover, `if` is also referred as a keyword in C. The general form of the `if` statement is:

```
```c
if(expression happens to be true)
    perform certain actions;
```
```

When an `if` statement is encountered by a compiler, it knows that a decision making needs to be done. The `if` statement always executes the statements that are enclosed within the `if` block.

Listing 1.7 shows how the `if` statement is written in C:

**Listing 1.7:** Writing the if statement in C

```
```c
#include<stdio.h>

int main()
{
    int varA = 10;

    if(varA == 10)
        printf("\n Statement is true ");

    getch();
}
```
```
