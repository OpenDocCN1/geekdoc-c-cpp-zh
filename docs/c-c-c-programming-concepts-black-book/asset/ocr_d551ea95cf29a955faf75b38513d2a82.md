+   - [ ] Dynamic loading of code.

The new features that are introduced in C# are given as follows:

+   - [ ] Reference and output parameters.
+   - [ ] Object on the stack, which is known as *struct*.
+   - [ ] Rectangular array, which is a new type of array similar to a matrix.
+   - [ ] Enumeration, which is derived from the C++ language. It provides a name value constant.
+   - [ ] Unified type system, which provides type safety so that no variable can be uninitialized. In addition, it avoids unsafe type casting.
+   - [ ] The goto statement.
+   - [ ] Versioning that makes C# more strong.
+   - [ ] Component-based programming that is implemented using properties, events, attributes, and interfaces.
+   - [ ] Delegates, which is similar to function pointers in C++.
+   - [ ] Indexer.
+   - [ ] Operator overloading, which is derived from C++.
+   - [ ] The *foreach* statement.
+   - [ ] Boxing and unboxing mechanism.
+   - [ ] LINQ.
+   - [ ] The Lambda function.
