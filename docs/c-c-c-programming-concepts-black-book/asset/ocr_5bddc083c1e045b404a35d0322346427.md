# # Bitwise Operators

Till now, we have dealt with different data types in C, but some applications require working on the smallest element present in the memory, which happens to be bits. C gives its users the flexibility to operate on bits and modify them. Manipulation over bits is a special facet of programming, as it enables the users to communicate with the hardware in an efficient way. Following are various bitwise operators in C:

+   - One's complement operator
+   - bitwise logical operators
+   - Shift operators

Let's learn about these operators, in detail.

# ## One's Complement Operator

One's complement of a number means that all the 1's present in the binary representation of that number is changed to 0's and all the 0's are changed to 1's. Let's consider a decimal number 6 whose binary representation is 0110. One's complement of this number would be 1001, which is 9 in decimal. The one's complement bitwise notation is denoted by the ~ operator. One's complement is a unary operation and the operator always precedes the operand. The operand should be an integer-type quantity, such as integer, long, and short. The associativity of the operand is from left to right. The one's complement operation is also called complementation operation. Listing 5.29 shows the one's complement operation:

**Listing 5.29:** Showing the One's Complement Operation

```
```c
#include<stdio.h>

int main()
{
    int varA, varB;

    varA = 6;
    varB = ~varA;

    printf("\n The decimal of one's complement of varA is [%d] ",varB);

    getch();
    return 0;
}
```
```

Output of the preceding program is as follows:

> > The decimal of one's complement of varA is [-7]

The one's complement of six happens to be 11111111111111111111111111111001. The number is given in 32-bit notation. The decimal equivalent of this number happens to be -7. The main usage of these sorts of techniques is in file encryption.

# ## Bitwise Logical Operators

In C, logical operators operate on expressions. Similarly, the same operators can also be used on bits to perform logical operations. The logical operators are used to establish and verify certain conditions, whereas, bitwise operators are used to manipulate the bit-level values in a variable. Three bitwise logical operators defined in C are bitwise AND (&), bitwise OR (|), and bitwise XOR (^). Each of these operators is a binary operator and requires two operands to work upon. One important point that needs to be taken care of is that both the operands should be of the same data type.
