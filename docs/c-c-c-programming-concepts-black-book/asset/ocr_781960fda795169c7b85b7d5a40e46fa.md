Following are the necessary steps to include a function in a program:

+   - Add a function declaration or a function prototype, as in line number 4 of the preceding program
+   - Add a call to the function with proper argument(s), if any, as in line number 8
+   - Add a function definition having a set of instructions that the function should execute when called explicitly within a program, as in line number 12 to line number 15

A function declaration establishes the name of the function and the number and types of its arguments. The declaration consists of a function name, return type, and a set of arguments to the function. A declaration of function informs the compiler about the formal and existence of a function prior to its use. C++ does not allow implicit declarations of functions; therefore, before using a function, it should be preceded with an explicit declaration. The compiler checks for the mismatches between the parameter of a function call and the function declaration based on the declaration and usage. It also uses the declaration for argument type checking and argument conversions. We can declare a function in two ways. First, we can declare a function at the beginning of a program, which tells the compiler that at some point, we are going to present a function similar to this, with similar signature. By function signature, we mean the name of a function, return type, and argument list specified when a function is declared at the beginning of the program. For a program to be compiled correctly, both the declaration and the definition of a function should match to each other. Secondly, for small programs, we generally do not declare the function at the beginning of a program; we rather prefer defining it at the beginning of a program, before any call to that function that is made. All other experiments with function declaration should get an error from the compiler.
