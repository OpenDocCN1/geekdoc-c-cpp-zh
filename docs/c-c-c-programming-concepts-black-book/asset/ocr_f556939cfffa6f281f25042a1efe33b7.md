In Listing 19.22, we are querying the **Employee** array of string to find whether an employee Tim is present in the collection. The output of the program is given as follows:

```
The Employee named Tim is present in the collection.
```

In Listing 19.22, notice that the query is stored in an object of the `IEnumerable<string>` interface. However, instead of using the `IEnumerable<string>`, we can also use the anonymous type `var` to store the query.

While using a non-generic collection type, such as ArrayList, Stack, or Queue, we need to use the `OfType` operator along with the `Where` operator to retrieve the result. For example, if an ArrayList contains the string values along with the integer values, then while querying the data, we need to specify the type of the element that we want to use. Listing 19.23 shows an example of using a non-generic collection type where the `OfType` operator is used to specify the exact type of the elements to be queried:

**Listing 19.23:** Showing the Implementation of the OfType Operator

```
using System;
using System.Linq;
using System.Collections;
using System.Collections.Generic;

class Employee
{
    public static void Main()
    {
        ArrayList empList = new ArrayList();
        empList.Add("Johns");
        empList.Add(1);
        empList.Add("Tim");
        empList.Add('E');
        empList.Add("Tina");

        //Using the operator OfType
        var empCount = from eCount in empList.OfType<string>()
                       where eCount == "Tim"
                       select eCount;

        if (empCount != null)
        {
            Console.WriteLine("The Employee named Tim is present in the collection.");
        }
    }
}
```

In the preceding program, the *empList* ArrayList contains the elements of a string type, an integer type, and a character type. While querying, we are specifying the string type, as the **where** condition will search for the string type element. If someone changes the type to int, then the program will throw an error at compile time. In the program, the LINQ query is stored in the anonymous type that frees a developer to remember which type of result will be assigned. The output of the program is same as that of Listing 19.22.
