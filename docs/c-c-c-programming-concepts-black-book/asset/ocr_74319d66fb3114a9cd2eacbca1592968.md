# ### *Element Operators*

In LINQ, element operators act on a collection of elements. These operators get the particular element from a collection depending upon the operations performed on the collection. Following are the five types of element operators.

+   - First
+   - Last
+   - ElementAt
+   - FirstAt
+   - Single

The *First* operator returns the first element of a collection using the *First()* extension method. Similarly, the last element in a collection can be fetched using the *Last()* extension method. The *ElementAt* operator is used to get an element depending on its position with the help of the *ElementAt()* extension method. Similarly, the *FirstAt()* extension method is used to get the first occurrence of an element that satisfies a specific condition. The *Single* operator is used to get the value of a collection that holds a single element using the *Single()* extension method. If the *Single()* method is applied to any collection that contains more than one element, then the compiler will throw an exception. Listing 19.37 shows an example of Element Operators.
