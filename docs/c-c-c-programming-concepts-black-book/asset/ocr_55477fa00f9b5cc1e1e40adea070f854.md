The main difference between a do-while loop and other loops is that a do-while loop gets executed at least once. This is due to the fact that the test condition is always right at the end of the loop. This means that only after executing all the statements at least once, the control can reach to the end of the loop.

#include<stdio.h>
int main()
{
    char answer;
    int sum,count;
    count=1;
    sum=0;
    do
    {
        fflush(stdin);
        sum+=count;
        printf("\n Sum %d ",sum);
        count++;
        printf("\n Want to Continue ?(Y/n) ");
        scanf("%c",&answer);
    }while(answer=='y');
    getch();
}

The code given in Listing 1.37 explains the working of a do-while loop. The execution of the loop starts unconditionally for the first iteration. As the control reaches the end of the loop, the user is asked to provide an input. Based on this input, the test condition is executed. If the condition becomes true, then the loop goes into its next iteration else the loop is terminated. A do-while loop always contains a semicolon at the end of the “while” statement.

# # Jump Statements

We have four kinds of jump statements in C to perform unconditional branching. These statements are return, goto, break, and continue. We can define return and goto statements anywhere in the function but break and continue are generally used with respect to a loop.

Let’s discuss these statements in details.

# ## The Return Statement

The return statement is used to mark a return point from a function. When the execution hits a return statement, the control gets shifted to the line before which the function call was made. A return statement might or might not have a value associated with it. Return statements are used for functions which have non void return types declared with them. A void function doesn’t return any value. In older versions of compilers (like C89), a return statement might not return any value explicitly. If a function is declared with a non-void return type and nothing is returned from that function, the compiler returns the garbage values. However, the advanced set of compilers (like C99) has made it mandatory that a non-void function must use a return statement which is associated with a value. Multiple return statements can be used inside the same function. The function will immediately stop executing when a return point is hit. The closing brace of a function also acts like an implicit return statement, which do not have any values associated with it. No explicit return statements are needed for functions with void return types. One thing must be kept in mind that a function whose return type is defined to be void cannot have a return statement that is used with values.
