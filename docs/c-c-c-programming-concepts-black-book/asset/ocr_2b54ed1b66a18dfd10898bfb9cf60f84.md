Let’s consider a declaration of a union as follows:

```
```c
union student
{
    int age;
    char name[20];
}stu1, stu2;
```
```

In the preceding declaration, we have declared two union variables: stu1 and stu2. Each union variable can represent either a 20-character name or an integer quantity age. A 20-character string will take more memory as compared to a 4-byte integer variable; therefore, the compiler will allocate 20 bytes of memory for both the union variables, as 20 is larger of the two sizes.

Figure 5.3 shows the memory organization of a union:

As shown in Figure 5.3, 20 bytes of memory is shared by the two variables.

A union can be a member of a structure and vice versa. Listing 5.13 shows the basic working principle of a union:

# **Listing 5.13: Showing the Working of a Union**

```
```c
#include<stdio.h>

union bookInfo
{
        int year;
        char name[10];
};

struct book
{
        char author[20];
        char publisher[20];
        union bookInfo info;
};

int main()
{
        struct book book1;

        printf("\n Enter Name of author publisher year ");
        scanf("%s %s %d",book1.author, book1.publisher,&book1.info.year);

        printf("\n The information entered is \n");
        printf("\n Author -> %s ",book1.author);
        printf("\n Publisher -> %s ",book1.publisher);
        printf("\n Year -> %d",book1.info.year);

        fflush(stdin);
        printf("\n Enter Name of the book ->");
        gets(book1.info.name);

        printf("\n Name of the book is -> %s ",book1.info.name);
