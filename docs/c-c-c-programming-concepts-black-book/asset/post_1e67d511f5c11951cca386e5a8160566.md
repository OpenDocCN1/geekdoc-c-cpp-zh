
## Chapter 16

Some of the features that are added to C# make it a strong language to develop Web-based applications. Noteworthy features that are supported by both Java and .NET are as follows:

- Encapsulation, which is one of the important features of the OOP language that allows a user to create a class and the object of that class.
- Interfaces, which are similar to classes, but only provide the skeleton of a class.
- Error handling mechanism, which uses the try-catch code block.
- Threads, which are used in a multi-user environment. By creating multiple threads, one application can be used by multiple users at a time.
- Namespaces, which are used to avoid naming anomaly. It helps in combining various features into one class file and then that file can be accessed by other applications.
- Garbage collection that helps an application to run smoothly by deallocating the memory spaces of the unused objects.
- Strongly typed language. The syntax used in C# is strongly typed.
- Dynamic loading of code.
- Reflection, which helps in locating the members in a class and invoking the methods of a class at runtime.

Therefore, we can say that C# is 70% similar to Java and 30% composed of some new features as well as the features of other languages, such as C++ and VB.

The new features that are introduced in C# are given as follows:

- Reference and output parameters.
- Object on the stack, which is known as *struct*.
- Rectangular array, which is a new type of array similar to a matrix.
- Enumeration, which is derived from the C++ language. It provides a named value constant.
- Unified type system, which provides type safety so that no variable can be uninitialized. In addition, it avoids unsafe type casting.
- The goto statement.
- Versioning that makes C# stronger.
- Component-based programming that is implemented using properties, events, attributes, and interfaces.
- Delegates, which are similar to function pointers in C++.
- Indexer.
- Operator overloading, which is derived from C++.
- The *foreach* statement.
- Boxing and unboxing mechanism.
- LINQ.
- The Lambda function.

Now, let’s discuss the design goals of the C# language, which are given as follows:

- It is proposed to be a modern, simple, and general purpose OOP language.
- The C# language and its various implementations should support software engineering principles, such as strong type checking, array bounds checking, and automatic garbage collection. In addition, programmer productivity along with the durability of the application is important.
- Source code portability is important; and therefore, it is implemented with the help of MSIL.
- It is proposed to be a language for applications that can be used for both hosted and embedded systems.
- C# applications are proposed to be economical regarding memory management and processing power requirements. However, it does not intend to be compared directly with the performance of C or any other assembly level language.
