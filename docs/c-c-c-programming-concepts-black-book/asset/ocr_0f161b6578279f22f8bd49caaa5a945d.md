Note that not all the operators in C# can be overloaded. There are certain rules and regulations that are applied to the operator overloading process, which are given as follows:

+   - Unary operators, such as `+`, `-`, `!`, `~`, `++`, `--`, `true`, and `false`, can be overloaded.
+   - Binary operators, such as `+`, `-`, `*`, `/`, `%`, `&`, `|`, `^`, `<<`, and `>>`, can be overloaded.
+   - Comparison operators, such as `==`, `!=`, `<`, `>`, `<=`, and `>=`, can be overloaded, but they have to appear as a pair. For example, if a program has an operator overloading method for the `==` operator, then there must be an operator overloading method for the `!=` operator. The reverse is also true. This rule goes for all the comparison operators.
