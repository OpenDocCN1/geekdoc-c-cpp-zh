functionBubbleSort(Array[n])
begin
  for i <- 0 to i <- n-1
    for j <- 0 to j <- n - 1 - i
      if Array[j] > Array[j+1]
        then
          Interchange the position of Array[j] and Array[j + 1]

The preceding algorithm implements the bubble sort to sort a list of elements in the ascending order. Using the two for loops, each pair of elements in the array is compared. If the element has a greater value than the element that comes afterwards, then they interchange their position. At the end of each inner loop, the greatest value of the list is placed at the rightmost position and for the next iteration, we do not consider that element anymore. At the end of this operation, each element in the list is placed in the ascending order.
