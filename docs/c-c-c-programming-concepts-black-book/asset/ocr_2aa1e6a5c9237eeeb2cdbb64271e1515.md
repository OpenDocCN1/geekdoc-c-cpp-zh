# ## LINQ to Dataset

A dataset stores a database in a disconnected representation. Using LINQ, a dataset can also be queried using the instance of DataTable. Listing 19.16 shows how to query a DataTable using LINQ.

**Listing 19.16: Showing the Implementation of LINQ to Dataset**

```
```csharp
using System;
using System.Data;
using System.Linq;
class Program
{
    public static void Main()
    {
        DataTable employeeList = new DataTable();
        //Adding the columns
        employeeList.Columns.Add("Employee_ID", typeof(Int32));
        employeeList.Columns.Add("First_Name", typeof(string));
        employeeList.Columns.Add("Last_Name", typeof(string));
        //Adding rows
        employeeList.Rows.Add("100", "James", "Scott");
        employeeList.Rows.Add("200", "Jonathan", "Jackson");
        employeeList.Rows.Add("300", "Keith", "Scott");
        employeeList.Rows.Add("400", "Johny", "Lee");
        employeeList.Rows.Add("500", "Amy", "John");
        employeeList.Rows.Add("600", "Leonardo", "Scott");

        //LINQ statement
        var query = from emp in employeeList.AsEnumerable()
                    where emp["Last_Name"].Equals("Scott")
                    select emp;

        //Printing the Employee information in the console
        foreach (var emp in query)
        {
            Console.WriteLine("Employee ID : {0} Employee Name : {1}",
                emp["Employee_ID"].ToString(),
                emp["First_Name"] + " " + emp["Last_Name"]);
        }
    }
}
```
```

In the preceding program, we have stored the data in the DataTable instance instead of storing it in a collection object or an XML file. The output of the program is same as that of Listing 19.15.

# ## LINQ to SQL

One of the important features that LINQ provides is to query a relational database. LINQ to SQL is an important feature, as it provides a way to query a database that is not under the Microsoft Corporation domain. This feature was previously known as DLINQ.

When a LINQ to SQL query is executed in a .NET environment, it is internally converted into its corresponding SQL query, which the underlying relational database can understand. This is done with the help of the expression tree, which we learn later in this chapter.
