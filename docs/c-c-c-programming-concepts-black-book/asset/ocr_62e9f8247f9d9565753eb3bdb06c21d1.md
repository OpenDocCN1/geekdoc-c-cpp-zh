Let's now learn about various access modifiers provided by C#.

# ## Access Modifiers

Access modifier is another property of OOP that implements encapsulation. Encapsulation hides the class definition from the outside world. Therefore, by using the access modifier, we can decide the amount of encapsulation that should be applied to a class. In this section, we will discuss the following five types of access modifiers:

+   - Public
+   - Private
+   - Protected
+   - Internal
+   - Protected internal

Let's start our discussion with the *public* access modifier.

# ### Public

When a public modifier is applied to methods and fields of a class, those methods and fields can be accessed from anywhere in the program and the assembly. Therefore, there is no restriction accessing the public members of a class. This makes the class public to the external world. We use the *public* keyword before the declaration of the members in a class to make its members public. Let's consider a small example to elaborate the accessibility of a public access modifier, as shown in Listing 18.29:

Listing 18.29: Showing the Example of Public Access Modifier

```csharp
using System;
class Vehicle
{
    public string type;
}
class Owner
{
    public void OwnerVehicle()
    {
        Vehicle vehicle = new Vehicle();
        vehicle.type = "Two-wheeler";
        Console.WriteLine("The owner has a " + vehicle.type);
    }
}
class Car : Vehicle
{
    static void Main()
    {
        Vehicle vehicle = new Vehicle();
        vehicle.type = "Four-wheeler";
        Console.WriteLine("The type of the car is " + vehicle.type);
        Owner owner = new Owner();
        owner.OwnerVehicle();
    }
}
