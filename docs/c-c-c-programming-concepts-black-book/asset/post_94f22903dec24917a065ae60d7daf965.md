## Creating a File

A file needs to be created before it can be processed. A text file or stream-oriented file can be created in two ways. It can be created either with the help of some external word processor or by writing some program that writes information into a data file. Unformatted files can only be created with the help of programs. Listing 5.21 shows how to create a file:

**Listing 5.21: Creating a File**

```c
#include<stdio.h>

    int main()
    {
        char ch='A';
        FILE *fp;

        fp = fopen("D:\\create_readme.txt","w");

        if(!fp)
        {
            printf("\n Failed to open the file");
            return 0;
        }

        putc(ch, fp);
        fclose(fp); /* For closing the file pointer */
        getch();

        return 0;
    }
```

## Adding Records to a File

Often a data file is used to store records, which are a group of dissimilar information. To write such records inside a data file, we can use the `fprintf()` function. Moreover, to fetch the records from a data file, we can use the `fscanf()` function. Listing 5.24 shows the working of `fprintf()` and `fscanf()` functions:

**Listing 5.24:** Adding and Fetching Records

```c
#include<stdio.h>

struct student
{
        char name[20];
        int class;
        int age;
};

int main()
{
        struct student stu;
        FILE *fp;
        int choice;

        fp = fopen("D:\\studentRecords.dat","a");

        do
        {
                printf("\n 1. Add records to a file ");
                printf("\n 2. Exit");
                printf("\n Enter your choice => ");
                scanf("%d",&choice);

                switch(choice)
                {
                        case 1:
                                printf("\n Enter Name Class Age =>");
                                scanf("%s %d",&stu.name,&stu.class,&stu.age);
                                fprintf(fp,"%s %d %d",stu.name,stu.class,stu.age);
                                break;
                        case 2:
                                break;
                        default:break;
                }
        }while(choice != 2);

        fclose(fp);

        fp = fopen("D:\\studentRecords.dat","r");

        printf("\n Records Inserted are ");

        while(fscanf(fp,"%s %d %d",&stu.name,&stu.class,&stu.age) != EOF)
        {
                printf("\n %s %d %d ",stu.name,stu.class,stu.age);
        }
        getch();
        return 0;
}
```

In the preceding program, we are writing data into the student structure using the `scanf()` function. After populating the structure variable stu, we are writing back the information to a data file. While writing the information back to the data file, we are using a `fprintf()` function, which takes the file pointer as an argument. Similar to `printf()`, `fprintf()` also allows the formatting of data in a variety of ways. While displaying the information, we are using `fscanf()`, which works as `scanf()`. The only difference is that it takes a file pointer as an argument and reads information from that file.

Let's now learn about binary files, in detail.

## Binary Files

A binary file is a collection of bytes. Example of a binary file is an audio file that contains characters, which are non-printable. Difference between a text file and a binary file is in the way end of file is detected for both the files. For text files, a special character with an ASCII value of 26 is regarded as an end of file character. If this character is encountered, then it signifies that the end of file has been reached. However, there is no such special character present in binary files. End of file is determined by the size of the file. It might happen that a binary file is used for storing numbers. In such case, a number 26 can signify end of file and cause a premature termination of the program. In a text file, a new line character is converted into a carriage return-linefeed combination (\r\n) and then it is written into the file. However, if a file is opened in the binary mode, then this sort of conversion will not take place.

Listing 5.25 shows how to read from and write to a binary file:

**Listing 5.25: Handling a Binary File**

```c
#include<stdio.h>

struct student
{
    char name[20];
    int class;
    int age;
};

int main()
{
    struct student stu;
    FILE *fp;
    int choice;

    fp = fopen("D:\\studentRecords.dat","wb");

    do
    {
        printf("\n 1. Add records to a file ");
        printf("\n 2. Exit");
        printf("\n Enter your choice -> ");
        scanf("%d",&choice);

        switch(choice)
        {
            case 1:
                printf("\n Enter Name Class Age ->");
                scanf("%s %d %d",&stu.name,&stu.class,&stu.age);
                fwrite(&stu, sizeof(stu), 1, fp);
                break;
            case 2:
                break;
            default:break;
        }
    }while(choice != 2);

    fclose(fp);

    fp = fopen("D:\\studentRecords.dat","rb");

    printf("\n Records inserted are ");

    while(fread(&stu, sizeof(stu), 1, fp))
    {
        printf("\n %s %d %d ",stu.name,stu.class,stu.age);
    }

    getch();
    return 0;
}
```

In the preceding program, we have opened a file in the `wb` mode, which indicates that we are working with a binary file.

1. Add records to a file
2. Exit
Enter your choice -> 1

Enter Name Class Age ->CHARLIE 8 16

1. Add records to a file
2. Exit
Enter your choice -> 2

Records Inserted are
MICHELLE 5 12

Instead of working with `fscanf()` and `fprintf()`, we have used two new functions while working with binary files: `fread()` and `fwrite()`.

The `fread()` function returns the number of items that were read. The signature of `fread()` is as follows:

```c
size_t fread(void *buffer, size_t num_bytes, size_t count, FILE *fp);
```

In the preceding signature, `buffer` is a pointer to a region of memory that will receive data from the file. The value of `count` determines how many items are to be read, where each item is `num_bytes` bytes in length. The value can be less than `count` if end of file has been reached or an error has occurred.

The `fwrite()` function returns the number of items that were successfully written onto the disk. The signature of `fwrite()` is as follows:

```c
size_t fwrite(const void *buffer, size_t num_bytes, size_t count, FILE *fp);
```

The parameters and their use is same as that of `fread()`.
