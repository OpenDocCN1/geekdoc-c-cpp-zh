# # Assemblies in C#

The term assembly have been around for a decade, but the definition of assembly in the context of .NET architecture is somewhat different. An assembly represents an executable file (.exe or .dll) that is executed at the end of the compilation. It can also be defined as the building block of the .NET architecture; the fundamental unit that provides deployment, version control, reuse, and security permissions; or a collection of types and resources that are built to work together and form a logical unit of functionality.
