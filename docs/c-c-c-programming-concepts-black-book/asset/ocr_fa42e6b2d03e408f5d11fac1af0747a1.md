email can be sent purposefully to alert the customers if some job execution fails. The names of the recipients in this case are certain and generally picked up from the database. In addition, the sender's address, subject, and the email body are fixed for these emails. Since these emails are circulated over an organization, security of the sender's address, subject, and email body should be the main business criteria. In addition, several Web forms in an application may use the same message body. For this purpose, all the constant values can be embedded in the Web.config file so that whenever an administrator of the application needs to change the message body, he/she can directly do so in the Web.config file. Otherwise, the administrator needs to change it in every Web form that uses the same email body. For this purpose, the <appSettings> element can be in the Web.config file, as follows:

```
```xml
<appSettings>
<add key="SenderAddress" value="sender_address@xyz.com"/>
<add key="MailSubject" value="Provide the email subject"/>
<add key="MailBody" value="Provide the email body"/>
</appSettings>
