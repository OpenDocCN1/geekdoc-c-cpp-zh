# # Generics

In the previous chapter, we have already learned about array and ArrayList as well a show they work in the .NET platform. In ArrayList, we can add the element without considering the type of the element. Therefore,ArrayList is an object-based data structure. However, the main problem with this sort of data structure is that we need to box it to Object type before inserting the value-type element and then unbox it to retrieve the exact type of element. This reduces the performance of the program as boxing and unboxing incur a significant performance penalty, as it creates more pressure on the managed heap; thereby, resulting in more garbage collection. Therefore, we can say that ArrayList is not type safe. On the other hand, Array is type safe, but the array size is restricted; whereas, there is no size limit in ArrayList. Therefore, both Array and ArrayList have their own advantages and disadvantages. In C#, Generics combine the advantages of both array and ArrayList that provide a type safe collection to a user.

In this section, we will cover the generic collection of Dictionary. To access the collection, we need to add the following assembly reference in a program:

```
```csharp
using System.Collections.Generic;
```
```

Using this reference, we can implement the collections, such as List<T> and Dictionary<Key, Value>. A List can be declared as follows, where T represents type:

```
```csharp
List<T> list = new List<T>();
```
```

If we want to create a List that contains a string, then we can declare it as follows:

```
```csharp
List<string> list = new List<string>();
```
```

On the other hand, the Dictionary collection represents a key-value list that has a key for all the text defined. We can declare the Dictionary collection as follows:

```
```csharp
Dictionary<key, value> list = new Dictionary <key, value>();
```
```
