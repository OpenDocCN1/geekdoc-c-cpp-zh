## Preface

Being in a world of software engineering has taught us how important it is to know your fundamentals. Deep root is a basic necessity of an opulent knowledge spread. The main difference between an ordinary engineer and an engineer of superlative qualities is his ability to attack a problem from various angles and then solve it in the most efficient way. It is his ability to go deeper and deeper into the problem till all that remains is the crux. At such a point, the only tool at his disposal is his grasp of basic knowledge bits he has gathered over the years.

Programming in C and C++ has become a very usual practice in modern IT world. Although programming in C and C++ starts at a very basic level, programmers find very few applications of these power languages in real life. This book presents C, C++, and C# language and object-oriented theory in an easy-to-read and comprehensive format and all under a single umbrella. It guides the reader from the very basic of programming through complex object-oriented techniques and is filled with real-life programming information including style guidance, debugging, multi-file program construction, and real-world, commonsense programming suggestions. It has been observed that programmers tend to learn concepts easily with a well written, lucid, and commented code rather than going through thousands of pages of a book. Here, we have provided every possible routes of exploring a particular topic with a systematic approach and an in-depth analysis of basic and advanced concepts. Extensive treatment of network programming is covered along with concepts on Parallel Network and Kernel Programming. A clear introduction to C, C++, and C# as well as an extensive treatment of data structures and algorithm make this book an indispensable complete reference for all variant of audiences in the field of Computer Science.

We have seen that for learners of C language, pointers have always been the greatest source of problem and confusions. Most novice programmers fumble on the use of pointers. Many of them try to ignore pointers completely, but very soon find that pointers have an extensive use in C programs. Some learners grasp only a partial knowledge of pointers, which in the beginning is not realized. Nevertheless, when they are trapped in between complex programming tasks, they find that pointers are a necessity. For this reason, pointers have been treated as a totally different chapter that deals with all its fundamental concepts with special reference to Function pointers. Function pointers have been treated as a completely different chapter where we have introduced for the first time a discussion and analysis on error handling using function pointers, which is an extremely smart type of programming.

The text is divided into three broad sections: C, C++, and C#. The text is self-contained and the language is extremely simple and lucid. Numerous examples have been provided to illustrate the basic concepts. While dealing with theorems and algorithms, emphasis is laid on constructions. Each illustration in the book is immediately followed by an example with discussion so that the reader can master the concepts before taking up and understanding the discussion. Exercises are appended at the end of each chapter, which facilitate the readers to practice the concepts learned in the chapter.
