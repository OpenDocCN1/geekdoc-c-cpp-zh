Now, if the code in Listing 7.13 is rewritten using the #line directive, then it appears, as shown in Listing 7.14:

# **Listing 7.14:** Showing the Code Written with the #line Directive

```
```c
#include<stdio.h>
#line 500 "Tanuman"
int main()
{
    printf("\\n In Line [%d] File name [%s] ",__LINE__,__FILE__);
    getch();
}
```
```

The output of the preceding program is given as follows:

```
```text
In Line [503] File name [Tanuman]
```
```

As the output suggests, the #line directive has not only changed the line number and reset it to 500, but it has also changed the file name of the program.

# ### #error

The #error directive stops the compiler from compilation. It is primarily used for debugging. The general form of #error directive is as follows:

```
```c
#error error-message
```
```

Note that the error-message should not be given inside the double quotes. Whenever the #error directive is encountered, the error-message is displayed. Listing 7.15 shows the usage of #error directive:

# **Listing 7.15:** Showing the Working of #error Directive

```
```c
#include<stdio.h>
int main()
{
    #error Stop here
    printf("\\n This is Test");
    getch();
}
```
```

The output of Listing 7.15 is given as follows:

```
```text
#error Stop here
```
```

As the output suggests, the compilation of the code stops by giving the error message.
