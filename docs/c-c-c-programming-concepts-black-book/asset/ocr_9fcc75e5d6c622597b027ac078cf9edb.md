The aim of the preceding code snippet is to include disk I/O operations into the class definition. However, it can be seen that if we include I/O operations within the class, we may compromise with the reusability of the class to some extent because the class will be associated with the disk file. To keep the variable disk file name, we could include the file name as an attribute of the class. However, in this case, file name is not an attribute of Medicine class. Moreover, if we want to reuse the Medicine class to create a list of Medicines, we cannot do so, as file I/O is not a property of a generalized Medicine class. Now, consider the code for Medicine_File class:

```
    class Medicine_File
    {
       private:
          medicine buffer;
       public:
          void diskout(void);
          void diskin(void);
    };
```

To separate the file I/O from the generalized Medicine class, we have declared a separate class called **Medicine_File**, which produces an output file called MEDICINE.TXT associated with this class. The only attribute of this class is a contained object called buffer of type medicine into which values can first be written, and then flushed on to a disk file, or an object can be read from the file into this object. This class also contains two public functions: one for writing records to the file and another to read records from the file. The member functions of the class are as follows:

+   - **diskout()**—Gets data from a user and writes the record on to the file
+   - **diskin()**—Reads the records from the file and displays them on the screen

Now, consider the following code:

```
    void Medicine_File :: diskout(void)
    {
       ofstream ofile("MEDICINE.TXT", ios::app);
       char loop;
       do
       {
          buffer.getdata();
          ofile.write((char *) &buffer, sizeof(buffer));
          cout<<"Any more records (r/N)?";
          cin>>loop;
       } while (loop == 'y');
    }
    void Medicine_File::diskin(void)
    {
       ifstream ifile("MEDICINE.TXT");
       ifile.read((char *) &buffer, sizeof(buffer));
       while (!ifile)
       {
          buffer.showdata();
          ifile.read((char *) &buffer, sizeof(buffer));
       }
    }
```

We have a self-contained class called Medicine_File for file I/O; therefore, we can implement the main() function in a very simple way, as follows:

```
    void main()
    {
       Medicine_File fileobj;
       fileobj.diskout();
       fileobj.diskin();
    }
```
