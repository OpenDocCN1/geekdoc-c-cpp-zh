# ## Queues

Queue in English describes a waiting line; in computers, we have similar concept as well. A queue is defined as a linear data structure, where insertion is made at one end and deletion is made at the other end. The information present in the list is processed in the same order as it was received. This method is also known as the FIFO mechanism. Information that came into queue first will be the first one to be processed as well.

Queues are usually represented by the means of linked lists or linear arrays. A queue has two pointers: FRONT and REAR. The FRONT pointer points to the element at the front of a queue; whereas, the REAR pointer points to the elements at the rear of a queue. In addition, the FRONT pointer is used to delete the elements from a queue and the REAR pointer is used to insert the elements in a queue. The condition FRONT = REAR at any point symbolizes an empty queue. At the beginning of any operation, both FRONT and REAR points to zero. Whenever an element is inserted into a queue, FRONT is incremented by one. Similarly, when an element is deleted from a queue, REAR is incremented by one. Figure 24.6 shows a queue:

During insertion, if the REAR pointer reaches the end of a queue, then no more insertions can take place in the queue. This situation is called Queue Overflow. Similarly, during deletion, if no more elements are left to delete and the queue becomes empty, then the situation is called Queue Underflow.
