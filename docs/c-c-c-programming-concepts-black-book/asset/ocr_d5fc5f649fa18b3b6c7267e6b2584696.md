# Partitioning Operators

Partitioning operators are used to partition a collection with respect to a given condition. LINQ offers four types of partitioning operators, which are given as follows:

+   - Skip
+   - SkipWhile
+   - Take
+   - TakeWhile

The Skip and Take operators are commonly used to get a set of elements from a collection by specifying the position of elements using the Skip() and Take() methods. In other words, these two operators partition the sequence based on a specified position of the element. The SkipWhile and TakeWhile operators are used to perform a conditional partitioning using the SkipWhile() and TakeWhile() methods. Listing 19.35 shows an example of partitioning operators:

Listing 19.35: Showing an Example of Partitioning Operators

```
```csharp
using System;
using System.Linq;

class program
{
    public static void Main()
    {
        int[] set = { 10, 20, 30, 40, 50, 60, 100 };

        Console.WriteLine("Skipping the first 5 elements...");
        var skip = set.Skip(5);

        foreach (int a in skip)
        {
            Console.WriteLine(a);
        }

        Console.WriteLine("Taking the first 2 elements...");
        var take = set.Take(2);

        foreach (int b in take)
        {
            Console.WriteLine(b);
        }

        Console.WriteLine("Printing the values whose values are between 50 and 100...");
        var query = set.SkipWhile(i => i < 50)
                       .TakeWhile(i => i <= 100);

        foreach (int i in query)
        {
            Console.WriteLine(i);
        }
    }
}
```
