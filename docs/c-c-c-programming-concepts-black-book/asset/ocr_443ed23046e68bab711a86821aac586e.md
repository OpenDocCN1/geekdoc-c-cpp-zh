In addition to the try-catch block, C# provides a finally block that is executed regardless of how the try block exits. Therefore, when the control flow reaches the end of the execution, the finally block is executed. In addition, the finally block is executed even after an error is handled in a catch block. The finally block is mainly used for:

+   - Avoiding the duplication of a statement.
+   - Releasing the resources after an exception is handled. For example, if an exception occurs while processing a data from the database, then the *finally* block can contain the code for terminating the database connection.
+   - Assigning a value to an object.
+   - Displaying a message that is useful for a user.

It is a good practice to write a finally block when we want to concentrate on the code performance. Listing 19.42 shows the structure of try-catch-finally block.

**Listing 19.42:** Showing the Structure of try-catch-finally Block

```

class Program
{
    public static void Main()
    {
        try
        {
            //write the code block that may generate an error
        }
        catch (Exception ex)
        {
            //Handle the exceptions
        }
        finally
        {
            //write the finally statement
        }
    }
}
```
