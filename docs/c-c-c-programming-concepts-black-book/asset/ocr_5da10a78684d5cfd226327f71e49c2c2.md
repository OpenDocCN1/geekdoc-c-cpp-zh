In the preceding algorithm, first, the Heap_Sort function is defined, where we build the heap using the Form_Heap function for the given array A[n]. After getting the initial heap, the root element is stored in the array A[n], which is used to hold the sorted elements. Then, the root element of the tree is replaced by the last element of the heap H[n]. After executing this function, the Form_Heap function is recursively called to rebuild the heap. This function continues until all the elements are sorted. On the other hand, the Form_Heap function traversed through the binary tree comparing the key value of the parent and the child nodes. If the key value of any child node is greater than its parent node, then the parent key value is replaced with the maximum key value of its child node. This way the heap is formed.

Now, let’s analyze the heap sort algorithm. In the heap sort, the complexity analysis is based on two procedures:

+   1. Building the heap each time after an element is removed from its last position
+   2. The initial for loop that executes to sort the array by removing the root element and placing the last element at the root position

The former procedure requires O(log n) time and the latter procedure requires O(n) time to execute. Therefore, the best case and the worst case complexities are same, that is, O(n log n). The Heap sort algorithm is efficient than the merge sort algorithm, as it requires the memory only to store the heap. However, the stability issue is still there with the heap sort algorithm, as the order of equal elements may change during its execution. This counts as one of the disadvantages of heap sort along with the fact that this sorting technique is found somewhat difficult to understand for a beginner. However, as it implements the concepts of both heap and complete tree, its study is very effective and necessary to understand the data structure concept.
