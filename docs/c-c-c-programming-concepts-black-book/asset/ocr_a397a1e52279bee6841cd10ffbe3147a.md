# The File Class

As already learned, the File class is used to move, copy, create, open, delete, and append files. In a situation where we want to perform a single operation on a file, the File class can be used to execute the operation. Using this class, we can also change the metadata attributes, such as date-time related to the creation of a file. As all the methods of the File class are static, most of the methods return the FileStream object. Table 21.6 lists the noteworthy methods of the File class:

| Method | Description |
|---|---|
| **AppendAllText(string path, string appendedText)** | Appends the text in a file. If the file is not present in the specified location, then it creates the file in that path.<br>It takes two arguments: one is the user-defined path and another is the text that is to be appended.<br><br>**Overloads:**<br>• `AppendAllText(string path, string appendedText, System.Text.Encoding encoding)` → Appends the text in a file by applying the specified encoding type. |
| **AppendText(string path)** | Appends an UTF-8 encoded text to a file mentioned in the user-defined path. It returns an object of the `StreamWriter` class.<br>It only takes a user-defined path as an argument. |
