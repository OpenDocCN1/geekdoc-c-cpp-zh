
In Listing 4.22, the base class contains a pure virtual function called ShowMessage() and the overloaded () operator. We have also derived a template class from the base class. The derived class uses a parameterized constructor, which takes a pointer to its member function and a pointer to an object as its arguments. It also overrides the pure virtual function as well as the () operator. From the overridden version of both the () operator and the pure virtual function, the actual call to the member function is made, which is passed as a parameter.
