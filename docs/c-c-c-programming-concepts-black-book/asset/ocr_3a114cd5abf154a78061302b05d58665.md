Listing 5.34 shows the code to shift the bits to right:

# Listing 5.34: Shifting Bits to Right

```
```c
#include<stdio.h>
int main()
{
    int varA = 210;
    varA = varA >> 5;
    printf("\n The result after shifting 5 bits to the right[%d] ",varA);
    getch();
    return 0;
}
```
```

Output of the preceding program is as follows:

```
```text
The result after shifting 5 bits to the right[6]
```
```

The decimal equivalent of 11010010 is 210. When we shift 5 bits of the integer to the right, we get 6 as a result. When we perform right shift operation, we need to take care of some points. Let’s consider a generic expression as:

```
```c
a >> b
```
```

In this case, if b happens to be negative, then the outcome of the expression becomes unpredictable. Some of the compilers even provide a warning during compilation, as shown with the help of Listing 5.35:

# Listing 5.35: Generating a Compilation Warning during Right Shift

```
```c
#include<stdio.h>
int main()
{
    int varA = 210;
    varA = varA >> -5;
    printf("\n The result after shifting 5 bits to the right[%d] ",varA);
    getch();
    return 0;
}
```
```

Compilation warning is shown as follows:

```
```text
[warning] right shift count is negative
```
```

Output of the preceding program is as follows:

```
```text
The result after shifting 5 bits to the right[0]
```
```

The output suggests that the result becomes unpredictable.

In the general expression a>>b, if a becomes negative, then the left most bit should always be set to 1, as it denotes the sign bit. In some of the compilers, sign bit is extended. If we consider the value of a to be -1 (11111111 in binary), then performing a right shift of 5 would result into 7 (00001111 in binary). As a negative number contains a 1 in its sign bit; therefore, instead of filling the blank positions with 0’s, the compiler would fill them with 1’s. This technique is called extension of sign bit. Listing 5.36 shows the sign bit check in C:

# Listing 5.36: Showing the Sign Bit Check in C

```
```c
#include<stdio.h>
int main()
{
    int varA = -1;
    varA = varA >> 5;
    printf("\n The result after shifting 5 bits to the right[%d] ",varA);
    getch();
    return 0;
}
```
