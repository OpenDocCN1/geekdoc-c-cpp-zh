function prototype always terminates with a semicolon; whereas, a function definition does not. The argument names given within the function prototype definition just plays the role of a dummy variable and can be omitted while writing a prototype. A function prototype declaration makes the compiler understand the signature of the function beforehand. When a compiler executes a function prototype, it comes to know that a function with a similar signature is getting used in the program. If the prototype of a function is declared, then the compiler would not throw any compilation error in case the function is accessed prior to its definition.

A function prototype helps the user to figure out if any mismatch takes place between a function prototype and function definition. In case of a mismatch, a compilation error occurs.

Listing 2.13 shows the usage of function prototypes:

# **Listing 2.13: Writing Functions with Prototypes**

```c

float myFunc(float x);        /* Function Prototype */

int main()
{
    float ret;

    ret = myFunc(87.67);
    printf("\n Ret [%f] ",ret);  /* Function Call */
    getch();
}

float myFunc(float x)    /* Function Definition */
{
    return x*3.5;        /* Function Body */
}
```
