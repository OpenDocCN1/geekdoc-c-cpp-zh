```c
{
    fprintf(fp, "\n the file is ready for reading");
}

```

The preceding code opens an already existing file in the read mode. The fopen() function performs three operations.
- Firstly, it searches the disk for the file; if the file does not exist, then an error message is displayed.
- Secondly, if the file exists, then the file is loaded from the disk to the memory (inside a buffer).
- Lastly, a character pointer is set to point to the first character of the buffer.

A file open action can fail due to multiple reasons, such as when the file does not exist in the specified location. Whenever the fopen() function fails to open a file, it returns NULL, which can be handled in the code later.

Next, let's learn how to close a file.

## Closing a File

After we have finished performing all the required operations on the file, it is important to close the file as well. This is done by using the fclose() function. The generic syntax of using the fclose() function is as follows:

```c
fclose(file_ptr);
```

When the file is closed by using the fclose() function, the file becomes inaccessible and no information can be read from the file or can be written to it. On the closing of the file, the buffer associated with the file is also removed from the memory. Listing 5.15 shows how to close a file.

### Listing 5.15: Closing a File

```c
#include<stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("D:\\_readme.txt", "r");

    if(!fp)
    {
        printf("\n failed to open the file");
        return 0;
    }
    else
    {
        fprintf(fp, "\n the file is ready for reading");
    }

    fclose(fp);  /* for closing the file */

    getch();

    return 0;
}
```

In Listing 5.15, fclose() takes a file pointer as an argument and performs some specific tasks. If some information needs to be written in a file, then it is first written to the buffer. Upon the execution of fclose(), the information is written back to the file. The buffer is then removed from the memory as well.

In the next section, let's learn how to read from a file.

## Reading from a File

After opening a file in the read mode, its content is brought into the buffer and the pointer to the first character of the buffer is returned. To read information from a file, the file pointer is used. Information can be fetched in a character-by-character manner, as a word, or as bytes of data. C provides all the flexibilities to its users to customize the retrieval of information as per their requirements.

Listing 5.16 shows how to fetch each character from a file:

### Listing 5.16: Fetching Each Character from a File

```c
#include<stdio.h>

int main()
{
    char character;
    FILE *fp;

    fp = fopen("D:\\_readme.txt","r");

    if(!fp)
    {
        printf("\n Failed to open the file");
        return 0;
    }
    do
    {
        character = fgetc(fp);
        printf("%c",character);
    }while(character != EOF);

    fclose(fp); /* For closing the file pointer */
    getch();

    return 0;
}
```

The preceding code shows how information can be fetched from a file by reading one character after another. The fgetc() function reads the character from the current pointer position, advances the pointer position so that the next character can be fetched, and returns the character, which is read. The fgetc() function is used within a do-while loop that has a terminating condition as follows:

```c
while (character != EOF)
```

A special character, which exists at the end of a file, signifies that the end of the file has been reached. While reading from the file, fgetc() encounters this special character and returns the macro EOF. In our case, the loop will terminate only when the end of file has been reached. While reading from a text file, if EOF is encountered, then C usually returns -1. If the same value is stored inside an unsigned char variable, which if encountered while reading from a file, then the loop will never terminate because we do not have a -1 for unsigned chars. Listing 5.17 shows how to fetch a character using the fgetc() function:

### Listing 5.17: Fetching a Character by using the fgetc() Function

## Reading Words from a File

Similar to characters, we can also read the words from a text file. Instead of using the fgetc() or getc() function, we have to use the fscanf() function, which is capable of reading one word from a file at a time. Listing 5.18 shows how to read words from a text file:

### Listing 5.18: Reading Words from a File

```c
#include<stdio.h>

int main()
{
    char end_char;
    char word[20];
    FILE *fp;

    fp = fopen("D:\\_readme.txt", "r");

    if(!fp)
    {
        printf("\n failed to open the file");
        return 0;
    }
    do
    {
        end_char = fscanf(fp, "%s", word);
        printf("%s \n",word);
    }while(end_char != EOF);

    fclose(fp); /* for closing the file pointer */
    getch();
    return 0;
}
```

In Listing 5.18, we have opened a file in the read-only mode. If the file exists, then each word is fetched from the file by using the fscanf() function and the same word is displayed by using the printf() function. The process continues until an EOF character is encountered. After reading the complete information from the file, we have closed the file descriptor using the fclose() function.

If the output of the preceding program is scrutinized, then it can be seen that the last word is repeated. The reason behind this is that when the check for EOF in the file takes place, we already have the last word encountered in the file inside the buffer, which is displayed twice. One of the solutions to this problem can be to incorporate the check for EOF inside the do-while loop. Listing 5.19 shows how to avoid the issue of repeating the last word in a file:

### Listing 5.19: Checking EOF in a File

```c
#include<stdio.h>

int main()
{
    char end_char;
    char word[20];
    FILE *fp;

    if(!fp)
    {
        printf("\n Failed to open the file");
        return 0;
    }
    do
    {
        end_char = fscanf(fp, "%s", word);

        if(end_char == EOF) {
            break;
        }

        printf("%s \n",word);
    }while(1);

    fclose(fp); /* For closing the file pointer */
    getch();

    return 0;
}
```

## Reading Lines from a File

C also provides the flexibility to read a whole line from a file at a time. To read lines from a text file at a time, we need to use the fgets() function. The generic signature of fgets() is as follows:

```c
char * fgets ( char * str, int num, FILE * stream );
```

In the preceding signature, str points to the array of characters, where the string to be read is stored; num refers to the number of characters to be read; and stream denotes the pointer to the file object that identifies the stream from where the information is read.

The fgets() function returns the same string that it stored inside the str parameter. Listing 5.20 shows how to read lines from a file.

### Listing 5.20: Reading Lines from a File using the fgets() Function

```c
#include<stdio.h>

int main()
{
    char *end_char;
    char sentence[100];
    FILE *fp;

    fp = fopen("D:\\readme.txt", "r");

    if(!fp)
    {
        printf("\n Failed to open the file");
        return 0;
    }
    do
    {
        end_char = fgets(sentence, 100, fp);

        if(end_char == NULL) {
            break;
        }

        printf("%s \n", sentence);
    }while(1);

    fclose(fp); /* For closing the file pointer */
    getch();

    return 0;
}
```
