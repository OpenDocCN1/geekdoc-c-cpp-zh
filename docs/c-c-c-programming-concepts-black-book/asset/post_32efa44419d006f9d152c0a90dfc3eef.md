## Defining Properties

As already learned, if we declare member variables as private in a class, then we cannot access those variables outside the class. Similarly, if we declare the member variables as public, then those can violate the rules of encapsulation. In addition, this would give access to any code to modify the values of the variables mistakenly. Properties are member variables that provide a way to read, write, and manipulate the values of private fields. They are nothing but a special method called accessor that helps the properties to appear as a public data member of a class. This mechanism provides flexibility and security in accessing any private data member of a class. Property has two parts; getters, which is used to get the value of the variable, and setters, which is used to set the value provided by a user. These are similar to other procedures where we may write the code block to manipulate the member variables. For example, we can write an error message that will alert a user about the entry of an invalid data. Listing 18.3 shows an example of property procedure using the Employee class:

- **Parameterized constructor**—Refers to a constructor that takes arguments and assigns those arguments to the respective member variables. A class can have more than one parameterized constructor. Listing 18.5 shows an example of the parameterized constructor.

### Listing 18.5: Showing an Example of the Parameterized Constructor

```csharp
using System;
class Program
{
    static void Main(string[] args)
    {
        MyClass myClass = new MyClass(1, "MyClass");
        Console.Write("The members are {0}, {1}",
            myClass.member1, myClass.member2);
    }
}
class MyClass
{
    public int member1;
    public string member2;
    //Parameterized constructor
    public MyClass(int member1)
    {
        this.member1 = member1;
    }
    public MyClass(int member1, string member2)
    {
        this.member1 = member1;
        this.member2 = member2;
    }
}
```

In Listing 18.5, we have defined two constructors for the class MyClass, where the first constructor is based on the member1 variable and the second constructor includes both member1 and member2 variables. To instantiate an object, we have chosen the second constructor where both the member variables are passed as arguments. The output of the preceding code is given as follows:

```text
The members are 1, MyClass
```

- **Copy constructor**—Refers to a constructor that is used to copy the content of one object to the newly created object. As an argument, it contains the object that is to be copied. Listing 18.6 shows an example of the copy constructor:

### Listing 18.6: Showing an Example of the Copy Constructor

```csharp
using System;
class Program
{
    static void Main(string[] args)
    {
        int member1 = 1;
        string member2 = "MyClass";
        //Object instantiated using Parameterized constructor
        MyClass myClass = new MyClass(member1, member2);
        Console.WriteLine("Object instantiated using Parameterized constructor...");
        Console.WriteLine("The members are {0}, {1}",
            myClass.member1, myClass.member2);
        //Object instantiated using Copy constructor
        MyClass newMyClass = new MyClass(myClass);
        Console.WriteLine("Object instantiated using Copy constructor...");
        Console.WriteLine("The members are {0}, {1}",
            newMyClass.member1, newMyClass.member2);
    }
}
public class MyClass
{
    public int member1;
    public string member2;
    //Parameterized constructor
    public MyClass(int member1, string member2)
    {
        this.member1 = member1;
        this.member2 = member2;
    }
    //Copy Constructor
    public MyClass(MyClass obj)
    {
        this.member1 = obj.member1;
        this.member2 = obj.member2;
    }
}
```

In Listing 18.6, we have instantiated an object of MyClass using the parameterized constructor. After that, we have again instantiated another object of MyClass by using the copy constructor where we have passed the object created using the parameterized constructor as an argument. The output of the preceding code is given as follows:

```text
Object instantiated using Parameterized constructor...
The members are 1, MyClass
Object instantiated using Copy constructor...
The members are 1, MyClass
```

- **Private Constructor**—Refers to a constructor that is used to prevent the instantiation of the class instance. If we do not provide any access modifier for a constructor, then it will automatically get set as a private constructor. This type of constructor is used to prevent the creation of objects of a class. Listing 18.7 shows an example of the private constructor:

### Listing 18.7: Showing an Example of the Private Constructor

```csharp
using System;
class Program
{
    static void Main(string[] args)
    {
        //MyClass m = new MyClass(); //This will throw an error
        MyClass.member1 = 100;
        MyClass.member2 = "Member";

        MyClass.Print();
    }
}
public class MyClass
{
    public static int member1;
    public static string member2;
    //Defining Private Constructor
    private MyClass()
    {
    }
    public static void Print()
    {
        Console.WriteLine("Member1 is: {0} and Member2 is: {1}",
            member1, member2);
    }
}
```

In Listing 18.7, we have defined the members of MyClass as static and set the default constructor as private; thereby, restricting the creation of an instance of the class. Now, if we try to create an instance of MyClass in the Main() method, then the compiler will throw an error. Therefore, we have to access the static members of the class as shown in Listing 18.7. The output of the preceding code is given as follows:

```text
Member1 is: 100 and Member2 is: Member
```

- **Static constructor**—Refers to a constructor that is used to initialize the static member variables. In addition, it is used in cases where a particular method needs to be executed only once. The static constructor is called before the creation of the class object. The peculiarity that makes it different from other constructors is that it neither takes any access modifier nor has parameters passed to it as arguments. To make a constructor static, we just need to put the static keyword before the name of the constructor. The static constructors are defined only for the static members and they cannot access any non-static member of a class. Static constructors cannot be called directly; however, they can be called automatically to initialize the class before the creation of the first instance of the class.
