Before moving on to the next section, let’s get an overview of a non-blocking mutex lock. The benefit of using a non-blocking mutex lock is that if a mutex is not already locked, then it will obtain the lock; else, if it is already locked, then the call would return with the status EBUSY. Following are the properties of a non-blocking mutex lock:

- It is possible to lock an object by mutex lock without actually blocking it using `int pthread_mutex_trylock(pthread_mutex_t *mutex);`
- If a mutex is unlocked, then the `pthread_mutex_trylock()` API would work similar to `pthread_mutex_lock()`
- If the mutex object referenced by a mutex is currently locked by any thread including the current thread, then the call to the mutex lock will return immediately.
- If the mutex type is `PTHREAD_MUTEX_RECURSIVE_NP` and the mutex is currently owned by the calling thread, then the mutex lock count will be incremented by one and `pthread_mutex_trylock()` will immediately return success.

In the next section, let’s discuss semaphore.

## Semaphore

Semaphore is a protected variable that is used to synchronize the parallel access to the shared accessible resources. Semaphore is a mechanism involving an abstract counter and two operations that can be used to synchronize multiple threads. The following two operations can be performed on semaphores:

- **The wait operation**—Decrements the value of the semaphore by one. If the value of the semaphore is zero, then the wait operation blocks a thread until some other thread increments the value of the semaphore. When the value becomes positive, the value of the semaphore is decremented by one and the wait operation returns.
- **The post operation**—Increments the value of the semaphore by one. If the value of the semaphore is zero, then the post operation unblocks one of the threads, which is blocked on a wait call to this semaphore. The unblocked thread will complete the wait call. The post operation is also called the signal operation.

Following are the steps to use a semaphore:

- 1. Include `<semaphore.h>`, as follows:

    ```c
    #include <semaphore.h>
    ```

- 2. Declare a semaphore (type is `sem_t`), as follows:

    ```c
    sem_t sem;
    ```

- 3. Initialize the semaphore, as follows:

    ```c
    sem_init(&sem, 0, 0);
    ```

- 4. Wait for a semaphore, as follows:

    ```c
    sem_wait(&sem);  /* blocking */
    sem_trywait(&sem);  /* non-blocking */
    ```

- 5. Post to a semaphore, as follows:

    ```c
    sem_post(&sem);
    ```

- 6. Destroy a semaphore when it is no longer required, as follows:

    ```c
    sem_destroy(&sem);
    ```

To understand the operation and utility of semaphores, let’s take an example of the producer-consumer problem. The problem starts with two processes – producer and consumer. The producer process produces something, such as a commercial good; whereas, the consumer process consumes the good produced by the producer. Now, to maintain the harmony between these two processes, both the producer and consumer processes must be synchronized. If they are not synchronized, then several problems might be encountered. For example, if the producer is producing at a very high rate and the consumer is consuming at a lower rate, then this will result in piling up of the commercial good. However, if the consumer is consuming at a much higher rate, then there will be a shortage of products. We can solve this problem by defining the commercial good as a semaphore variable and operating on the wait and signal operations to maintain the harmony between the producer and consumer processes. The code to solve the producer-consumer problem is given as follows:

```c
#include <stdio.h>
#include <malloc.h>
#include <pthread.h>
#include <semaphore.h>

struct job {
    struct job* next;
    int         num;
};

struct job* job_queue;

pthread_mutex_t job_queue_mutex = PTHREAD_MUTEX_INITIALIZER;

/* A semaphore counting the number of jobs in the queue. */
sem_t job_queue_count;

void initialize_job_queue ()
{
        job_queue = NULL;
        sem_init (&job_queue_count, 0, 0);
}

void process_job(struct job *job)
{
        int square = 0;
        /* Process job */
        square = job->num * job->num;
        fprintf(stdout, "\nProcessed job, num=[%d] output=[%d]", job->num, square);
}

void enqueue_job (int num)
{
        struct job* new_job;
        new_job = (struct job*) malloc (sizeof (struct job));
        pthread_mutex_lock (&job_queue_mutex);
        new_job->next = job_queue;
        new_job->num = num;
        fprintf(stdout, "\nAdding new job. num=[%d]", new_job->num);
        job_queue = new_job;
        sem_post (&job_queue_count);
        pthread_mutex_unlock (&job_queue_mutex);
}

void* thread_producer_function (void* arg)
{
    int j = 0;

    while (1) {
        struct job* next_job;
        enqueue_job(j);
        j++;
        if (j % 5 == 0) {
            sleep(5);
        }
    }
    return NULL;
}

void* thread_consumer_function (void* arg)
{
    struct job* next_job;
    while (1) {
        fprintf(stdout, "\nConsumer waiting for new job..."); fflush(stdout);
        sem_wait (&job_queue_count);
        fprintf(stdout, "\nConsumer got new job."); fflush(stdout);

        pthread_mutex_lock (&job_queue_mutex);
        next_job = job_queue;
        job_queue = job_queue->next;
        process_job (next_job);
        pthread_mutex_unlock (&job_queue_mutex);
        free (next_job);
    }
    return NULL;
}

int
main()
{
    pthread_t          thread_producer;
    pthread_t          thread_consumer;
    int                res = 0;
    int                i   = 0;

    initialize_job_queue();

    res = pthread_create(&thread_producer, NULL, thread_producer_function, NULL);
    if (res != 0) {
        fprintf(stderr, "\nthread creation failed\n");
        return 1;
    }

    res = pthread_create(&thread_consumer, NULL, thread_consumer_function, NULL);
    if (res != 0) {
        fprintf(stderr, "\nthread creation failed\n");
        return 1;
    }

    fprintf(stdout, "\nwaiting for threads to finish...\n");
    res = pthread_join(thread_producer, NULL);
    if (res != 0) {
        fprintf(stderr, "\nthread join failed\n");
        return 0;
    }
    res = pthread_join(thread_consumer, NULL);
    if (res != 0) {
        fprintf(stderr, "\nthread join failed\n");
        return 0;
    }

    pthread_mutex_destroy(&job_queue_mutex);

    return 0;
}
```

```c

sem - initialises the semaphore pointed to by sem
pshared - should be set to 0 if the semaphore is shared between threads of a process
value - initial value of the semaphore

sem - address of the semaphore
```

```c
/* Demonstrating busy waiting for cpu cycles for mutex variables */
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>

int continue_flag;
pthread_mutex_t continue_flag_mutex;

void do_work ()
{
    fprintf(stdout, "\nworker thread: working..."); fflush(stdout);
}

void* worker_thread_function(void *arg)
{
    int cont_flag = 0;
    while (1) {
        pthread_mutex_lock(&continue_flag_mutex);
        if (continue_flag) {
            do_work();
        }
        pthread_mutex_unlock(&continue_flag_mutex);
    }
}
int
main()
{
    pthread_t            worker_thread;
    int                  res = 0;

    continue_flag = 0;
    pthread_mutex_init(&continue_flag_mutex, NULL);

    res = pthread_create(&worker_thread, NULL, worker_thread_function, NULL);
    if (res != 0) {
        fprintf(stderr, "\nThread creation failed\n");
        return 1;
    }

    while (1) {
        pthread_mutex_lock(&continue_flag_mutex);
        continue_flag = 1;
        pthread_mutex_unlock(&continue_flag_mutex);
        fprintf(stdout, "\nmain thread: Start work\n\n"); fflush(stdout);
        sleep(2);
        pthread_mutex_lock(&continue_flag_mutex);
        continue_flag = 0;
        pthread_mutex_unlock(&continue_flag_mutex);
        fprintf(stdout, "\nmain thread: Stop work\n\n"); fflush(stdout);
        sleep(3);
    }

    fprintf(stdout, "\nWaiting for thread to finish...\n");
    res = pthread_join(worker_thread, NULL);
    if (res != 0) {
        fprintf(stderr, "\nThread join failed\n");
        return 0;
    }

    fprintf(stdout, "\nThread joined. \n");
    pthread_mutex_destroy(&continue_flag_mutex);

    return 0;
}
```
