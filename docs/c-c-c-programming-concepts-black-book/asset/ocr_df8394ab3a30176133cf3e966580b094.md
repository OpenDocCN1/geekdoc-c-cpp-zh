# The fill() Function

The fill() function sets the padding used to fill the unused portions of a field. The two types of fill() function are given as follows:

```
```cpp
char fill ( ) const;
char fill (char fillchar);
```
```

The first function returns the fill character. The second function sets fillchar as the new fill character and returns the previously set fill character. Consider the following example:

```
```cpp
#include <iostream>
using namespace std;
int main ()
{
char prev;
cout.width (10);
cout<< 60 << endl;
prev = cout.fill ('x');
cout.width (10);
cout<< 60 << endl;
cout.fill(prev);
return 0;
}
```
```

The output of the preceding example is given as follows:

```
```text
60
xxxxxxxx60
```
```

# The precision() Function

The precision() function sets the number of digits to be displayed after the decimal point of a float value. The two types of precision() function are as follows:

```
```cpp
streamsize precision ( ) const;
streamsize precision (streamsize prec);
```
```

The first version of the function returns the value of the present floating-point precision field for a stream. The second version of function sets it to some new value.
