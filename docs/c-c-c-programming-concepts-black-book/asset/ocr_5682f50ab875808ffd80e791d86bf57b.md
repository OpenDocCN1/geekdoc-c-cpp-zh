In aggregation, an object may only contain a reference or pointer to the object and may not have lifetime responsibility for it. Sometimes, aggregation is referred to as composition when the distinction between composition and aggregation is unimportant.

Composition may be used to store numerous instances of the composite data types. This is sometimes referred to as containment, which includes linked lists, associative arrays, and binary trees.

# Generalization

Generalization has one parent process and one or more child processes. A child process describes a specialized type of its parent process. For example, in a store, we can make payment through cash or card. Therefore, payment by cash and payment by card are the two child processes of the payment process. # Include

If a process requires the outcome of another process, then the relationship between the two processes is called include. For example, if we want to borrow a CD from a CD store, then we need to first verify that whether the CD exists in the store or not. Therefore, borrowing a CD includes the verification process.
