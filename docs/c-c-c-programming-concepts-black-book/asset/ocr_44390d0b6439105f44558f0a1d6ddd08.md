# Destructors

A member function of class A, named ~A, is called the destructor of class. A destructor is called implicitly when an object is destroyed. If no destructor is provided, then the compiler provides a default destructor. Destructors cannot take any argument, cannot be overloaded, and cannot return any value. Consider the code given in Listing 13.6.

**Listing 13.6:** Showing the Code for Destructor

```
class A
{
    public:
    int *x;
    A(int);
    ~A();
}
A::A(int y)
{
    x = new int[y];
}
A::~A()
{
    delete x[];
}
```

# Class Members

Data members and functions are the members of a class that must be declared within the class definition. Consider the code snippet given in Listing 13.7:

**Listing 13.7:** Showing an Example of Class Members

```
class A
{
    int a;             // a is a data member of class A
    int b;             // b is a data member of class A
    int a;             // Error redefinition of a
};
```

Note that we cannot declare a member twice within a function. Moreover, no member can be added elsewhere other than the class definition.

Listing 13.8 shows func_1 and func_2 as the member functions of class B:

**Listing 13.8:** Showing Another Example of Class Members

```
class B
{
        int a;
        float b;
        void func_1(int, float);
        int func_2();
};
```

In the preceding example, both the member functions determine the behavior of the objects of class B.
