Let's perform the following steps to describe the process of validating an XML document against an XSD file:

## XSLT

XSLT is an XML-based language that consists of a set of recursive rules, known as templates. Using the templates, we can transform an XML document into a new XML document that has different style without hampering the old document. In addition, XSLT can be used to transform an XML document to its respective XHTML or HTML format as well as change the style form of a Web page. As XSLT is mostly used to transform the design of a Web page, let’s discuss the procedure to convert an XML document into HTML.

### Converting an XML Document into HTML

To convert an XML document into its HTML counterpart, we use the XML document shown in Listing 20.2. The HTML form of this XML document will show the list of book titles along with the name of the authors in a tabular format. Listing 20.13 shows the XSLT code:

**Listing 20.13:** Showing the XSLT Code to Transform an XML Document into HTML

```xml
<?xml version="1.0" encoding="utf-8"?>
<xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
<xsl:output method="xml" indent="yes"/>
<xsl:template match="/">
<html>
<head>
        <h2>List of Books</h2>
</head>
<body>
        <table align="center" border="1">
                <tr>
                        <td align ="left" font="bold">
                                Name of the Book
                        </td>
                        <td align ="left" font="bold">
                                Name of the Author
                        </td>
                </tr>
                <xsl:for-each select="Library/Book">
                <tr>
                        <td>
                                <xsl:value-of select="Title"/>
                        </td>
                        <td>
                                <xsl:value-of select="Author"/>
                        </td>
                </tr>
                </xsl:for-each>
        </table>
</body>
</html>
</xsl:template>
</xsl:stylesheet>
```

## XPath

The structured nature of XML document provides us an opportunity to address different parts of the XML document. As an XML document repeats its elements regularly, we can use this repetitive nature and develop an XPath expression to address a specific element. Therefore, XPath expressions are nothing but the expressions that help in highlighting a certain element of the XML tree. As already learned, we can view the XML document as an XML tree; however, using XPath, we can refer any tree node or prepare a list of tree nodes specifying the same element in the XML document. The slash symbol “/” is used to separate the location steps in the XML document. We can use the same XML tree specified in Figure 20.3 to some of the XPath expressions and their result, given as follows:

- To get the list of all the book nodes, the XPath expression will be `LIBRARY/BOOK`
- To get the list of all the books whose Author is Korth, the XPath expression will be `LIBRARY/BOOK[AUTHOR = “Korth”]`
- To get the list of names of all the books written by Korth, the XPath expression will be `LIBRARY/BOOK[AUTHOR = “Korth”]/NAME`
- To get the list of names of all the books available in the library, the XPath expression will be `//NAME`
- To select all the BOOK elements, the XPath expression will be `/*`
