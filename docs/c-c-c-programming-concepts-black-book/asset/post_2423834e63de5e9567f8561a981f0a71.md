## The Create XML using XMLTextWriter Button

When we click the Create XML using XMLTextWriter button, a method is called which is responsible for creating an XML document in the path `C:\XML` with the help of an XmlTextWriter object. Let’s take the example of Library Management System and perform the following steps to create an XML document using the XmlTextWriter class.

- 1. Create an object of the XmlTextWriter class with the help of the FileStream object. In the XmlTextWriter object, we will write the whole XML document and save it at the end of the process.
- 2. Create the XML start tag as `<?xml version = "1.0" standalone="yes"?>`. We use the `WriteStartDocument()` method to write the start tag in the XML document. Without this tag, each time we attempt to save the XML document, the compiler will throw an error.
- 3. Add the root element and then its child elements by using the `WriteStartElement()` method. Note that if we miss to add any of these elements or if we add these elements in a wrong format, then the compiler will throw an error. In addition, error will occur if we forget to enclose any of these elements. In the Library Management System example, the root element is Library, as it represents the whole library. Under this root element, a single child element can be added, in our case, we have added Book.
- 4. Add the attributes to the child element by using the `WriteAttributeString()` method depending on the number of attributes provided by a user (1, 2, or 3). In our case, we have entered 2 as the number of attributes in the respective text box. As a result, two name-value text boxes appear where we add the name and value of the attributes. In our case, we have added two attributes, ID and ISBN, as shown in Figure 20.9:

  ![](img/43c5f409f9b17790a628c4b4df854b61_700_0.png)

- 5. Add the sub-child elements depending on the number provided by the user (1, 2, or 3). For this, we first write the element tag by using the `WriteStartElement()` method. Next, we add the text associated with this element by using the `WriteString()` method. In addition, we enclose this element by writing the `WriteEndElement()` method at the end of each sub-child element. In our case, we have added two sub-child elements, Name and Author, to the child element Book, as shown in Figure 20.10:

  ![](img/43c5f409f9b17790a628c4b4df854b61_701_0.png)

  **Figure 20.10: Providing the Sub-Child Elements**

- 6. First, enclose the tag for the child element and then write the end tag for the root node. After that, release all the resources held by the FileStream object by using the Close() method.

```csharp
protected void btnCreateXMLTextWriter_Click(object sender, EventArgs e)
{
    string path = @"C:\XML\";

    if (!Directory.Exists(path))
    {
        Directory.CreateDirectory(path);
    }

    string fileName = "MyFirstXML.xml";

    if(File.Exists(path + fileName))
    {
        File.Delete(path + fileName);
    }

    try
    {
        FileStream fileStream = new FileStream
        (path + fileName, FileMode.Create);
        XmlTextWriter xmlTextWriter = new XmlTextWriter
        (fileStream, System.Text.Encoding.UTF8);

        //Writing the start tag of the XML document
        //<?xml version = "1.0" standalone = "yes" ?>
        xmlTextWriter.WriteStartDocument();

        //Writing the root element
        xmlTextWriter.WriteStartElement(txtRootElementName.Text.ToString().Trim());

        //Writing the child element
        xmlTextWriter.WriteStartElement(txtChildElementName.Text.ToString().Trim());

        //Writing the attribute depending on the No. of attribute
        // provided by the user
        if (txtNoOfAttr.Text.ToString().Trim() == "2")
        {
            xmlTextWriter.WriteAttributeString(txtRootAttr1.Text.ToString().Trim(),
            txtRootAttrvalue1.Text.ToString().Trim());

            xmlTextWriter.WriteAttributeString(txtRootAttr2.Text.ToString().Trim(),
            txtRootAttrvalue2.Text.ToString().Trim());
        }

        if (txtNoOfAttr.Text.ToString().Trim() == "3")
        {
            xmlTextWriter.WriteAttributeString(txtRootAttr1.Text.ToString().Trim(),
            txtRootAttrvalue1.Text.ToString().Trim());

            xmlTextWriter.WriteAttributeString(txtRootAttr2.Text.ToString().Trim(),
            txtRootAttrvalue2.Text.ToString().Trim());

            xmlTextWriter.WriteAttributeString(txtRootAttr3.Text.ToString().Trim(),
            txtRootAttrvalue3.Text.ToString().Trim());
        }

        //Writing the sub-child elements depending on the No. of elements
        // provided by the user
        if (txtNoOfSubChild.Text.ToString().Trim() == "2")
        {
            xmlTextWriter.WriteStartElement(txtSubChild1.Text.ToString().Trim());
            xmlTextWriter.WriteString(txtSubChild1value1.Text.ToString().Trim());
            xmlTextWriter.WriteEndElement();

            xmlTextWriter.WriteStartElement(txtSubChild2.Text.ToString().Trim());
            xmlTextWriter.WriteString(txtSubChildvalue2.Text.ToString().Trim());
            xmlTextWriter.WriteEndElement();
        }

        if (txtNoOfSubChild.Text.ToString().Trim() == "3")
        {
            xmlTextWriter.WriteStartElement(txtSubChild1.Text.ToString().Trim());
            xmlTextWriter.WriteString(txtSubChild1value1.Text.ToString().Trim());
            xmlTextWriter.WriteEndElement();

            xmlTextWriter.WriteStartElement(txtSubChild2.Text.ToString().Trim());
            xmlTextWriter.WriteString(txtSubChild1value2.Text.ToString().Trim());
            xmlTextWriter.WriteEndElement();

            xmlTextWriter.WriteStartElement(txtSubChild3.Text.ToString().Trim());
            xmlTextWriter.WriteString(txtSubChild1value3.Text.ToString().Trim());
            xmlTextWriter.WriteEndElement();
        }
        //Closing the child element
        xmlTextWriter.WriteEndElement();

        //Closing the root element
        xmlTextWriter.WriteEndElement();

        //Releasing all the resources held by the file stream object
        xmlTextWriter.Close();

        Server.Transfer("XMLReaderPage.aspx", true);
    }
    catch (Exception ex)
    {
        lblError.Text = ex.Message;
    }
}
```

When a user clicks the Create XML Using XmlTextWriter button, a new Web page appears where the user can view the newly created XML document. This page consists of one text box control, which holds the XML document, and the Back button. When we click the Back button, the current Web page is closed. The name of this page is My XML Manager: XML Content. Perform the following steps to develop this page to view the content of the XML document by using the object of XmlTextReader:

- 1. Create an object of the XmlTextReader class by using the FileStream object whose file mode is set to open.
- 2. Read each node from the XML document in a loop by using the Read() method. If this method returns true, then the control enters into the while loop where it checks the NodeType property for each element and performs the following tasks:
  - If the NodeType property is XmlDeclaration, then the method prints the name of the node, which is xml, and the value of the node, which is version="1.0" encoding="utf-8".
  - If the NodeType property is Element, then the method prints the root element, child elements, and sub-child elements by using a count. While reading an element node, it first writes the name of the element node by using the member variable Name and then gets the value of the attributes associated with that element by using the GetAttributeList() method. Depending on the attribute count and using the MoveToNextAttribute() method, the GetAttributeList() method writes the value and name of an attribute using the member variables Value and Name in a string variable, which is then returned by the method. Listing 20.7 shows the code snippet for the GetAttributeList() method.

**Listing 20.7: Showing the GetAttributeList() Method**

```csharp
public string GetAttributeList(XmlTextReader xmlReader)
{
    string attributeList = string.Empty;
    if (xmlReader.AttributeCount > 0)
    {
        while (xmlReader.MoveToNextAttribute())
        {
            attributeList += " " + xmlReader.Name.ToString()
            + " = " + xmlReader.Value.ToString();
        }
    }

    return attributeList;
}
```
