However, if math_errhandling contains MATH_ERRNO, then the errno variable is set to ERANGE, which indicates a range error. On the other hand, if math_errhandling contains MATH_ERREXCEPT, then a floating-point exception is raised.

> > **NOTE**
> >
> > EDOM and ERANGE are the macros that are defined in the `<errno.h>` header.

Now, let's discuss some of the mathematical functions, in detail.

# ### acos()

The acos() function returns the arc cosine of the argument passed to it. The value of argument must be within the range of -1 to 1; otherwise, the compiler will throw an error. The signature of the acos() function is given as follows:

```
    double acos(double argument);
```

The C99 compiler defines two variants of the acos() function, which are as follows:

```
    float acosf(float arg);
    long double acosl(long double arg);
```

The preceding two variants are used for the float and long data types, respectively.

Now, let's take an example of the acos() function as mentioned in Listing 8.1:

Listing 8.1: Usage of acos() function.

```
    #include<stdio.h>
    #include<math.h>
    int main()
    {
        double val = -1.0;
        printf("\n the Arc Cosine of %f is %f ",val, acos(val));
        getch();
    }
```

Output of the preceding example is as follows:

```
    The Arc Cosine of -1.000000 is 3.141593
```

# ### acosh()

The acosh() family of functions returns the arc hyperbolic cosine of the argument passed to them. The value of argument must be zero or greater than zero; otherwise, the compiler will throw an error. The signature of the acosh() family of functions is as follows:

```
    float acoshf(float arg);
    double acosh(double arg);
    long double acoshl(long double arg);
```

# ### cos()

The cos() family of functions returns the cosine of the argument passed to them. The signature of the cos() family of functions is as follows:

```
    float cosf(float arg);
    double cos(double arg);
    long double cosl(long double arg);
```
