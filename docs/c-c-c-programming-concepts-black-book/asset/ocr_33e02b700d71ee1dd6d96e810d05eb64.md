# bad_cast()

When dynamic_cast fails the runtime check performed on references to polymorphic class types, the bad_cast() exception is thrown. Similar to the case of bad_alloc, a null-terminated character sequence identifying the exception is returned by the what() member function of bad_cast().

# bad_exception()

This sort of exception is a unique kind of exception created specifically to be listed in its exception specifier. If a function together with bad_exception is listed within its exception-specification throws an exception not listed inside and unexpectedly re-throws this exception (or throws almost every other exception, which is also not inside the exception-specification), then a bad_exception is automatically thrown. The what() function results in a null-terminated character series identifying the actual exception. Consider the following example:

```
```cpp
#include <iostream>
#include <exception>
using namespace std;

void myunexpected ()
{
    cerr<< "Unexpected handler is called!\n";
    throw;
}
void testFunction () throw (int,bad_exception)
{
    throw 'x'; // throws char (not in exception-specification)
}
int main (void)
{
    set_unexpected (myunexpected);
    try
    {
        testFunction();
    }
    catch (int)
    {
        cerr<<"Caught int\n";
    }
    catch (bad_exception be)
    {
        cerr<<"Caught bad Exception\n";
    }
    catch (...)
    {
        cerr<<"Caught other exception\n";
    }
    return 0;
}
```
```

The output of the preceding program is as follows:

```
```text
Unexpected handler is called!
Caught Bad Exception
```
