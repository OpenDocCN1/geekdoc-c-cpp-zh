**Listing 4.6:** Showing the Traversal in Single Dimensional Array using Pointers

```c
#include <stdio.h>

void show_value(int *value, int range);
```

The nomenclature in C is such that indexing in an array starts from the 0th location; therefore, the following two code snippets give the same result:

```c
int *ptr = &a[0];
int *ptr = a;
```

While compiling the a[i] expression, the compiler first converts it to *(a+i); therefore, the expression that uses array indexing becomes equivalent to a pointer and an offset expression.

## Two-Dimensional Arrays using Pointers

A two-dimensional array is nothing but a collection of single dimensional arrays. Following is an example of how to define a two-dimensional array syntactically:

```c
int arr[2][3];
```

In the preceding example, the first subscript of the two-dimensional array is called the row number and the second subscript is called the column number. This two-dimensional array can be thought of as a single dimensional array of two elements where each element is again a single dimensional array of three elements.

Consider the following two-dimensional array:

```c
int arr[4][2] = {
    {1,100},
    {2,200},
    {3,300},
    {4,400}
};
```

The preceding array can be shown as follows:

| Value | Index | Address |
|---:|---|---:|
| 1 | [0][0] | 8000 |
| 100 | [0][1] | 8001 |
| 2 | [1][0] | 8002 |
| 200 | [1][1] | 8003 |
| 3 | [2][0] | 8004 |
| 300 | [2][1] | 8005 |
| 4 | [3][0] | 8006 |
| 400 | [3][1] | 8007 |

Dimensions are just conceptual design. In the memory, the preceding array elements are stored in a contiguous manner; for example, 1 is stored at the location [0][0], 100 is stored at the location [0][1], and 2 is stored at the location [1][0]. This scheme is referred to as a row major order of representing an array in memory. However, there is another representation as well which is called column major representation. Let’s discuss the significant differences between the two representations. Figure 4.2 shows the two representations of a two-dimensional array:

**Row Major Representation**

| Row | Col | Info |
|---:|---:|---:|
| 0 | 0 | 1 |
| 0 | 1 | 100 |
| 1 | 0 | 2 |
| 1 | 1 | 200 |
| 2 | 0 | 3 |
| 2 | 1 | 300 |
| 3 | 0 | 4 |
| 3 | 1 | 400 |

**Column Major Representation**

| Row | Col | Info |
|---:|---:|---:|
| 0 | 0 | 1 |
| 1 | 0 | 100 |
| 0 | 1 | 2 |
| 1 | 1 | 200 |
| 0 | 2 | 3 |
| 1 | 2 | 300 |
| 0 | 3 | 4 |
| 1 | 3 | 400 |

**Figure 4.2: Showing the Row Major and Column Major Representations**

The major difference between the two representations is the way the elements are stored in a two-dimensional array. In a row major representation, after element a[0][0], the next element to be found is element a[0][1]; whereas, in a column major representation, the next element to be found is element a[1][0].

### Exploring Pointer Arithmetic in Two-Dimensional Array

As already discussed, a two-dimensional array can be considered as a collection of single dimensional arrays. Therefore, typical declaration, such as int arr[3][3], would mean that arr[0] will give the base address of the first single dimensional array, arr[1] will give the address of the second single dimensional array, and arr[2] will give the address of the third single dimensional array. Listing 4.7 shows the base address calculation for a two-dimensional array:

**Listing 4.7: Showing the Base Address Calculation for a Two-Dimensional Array**

```c
#include <stdio.h>

int main()
{
    int i;
    int arr[3][3] = {
                    {1,100,1000},
                    {2,200,2000},
                    {3,300,3000}
                    };
    for(i=0;i < 3; i++)
    {
        printf("\n Address of [%d]th 1D array is [%u]",i,arr[i]);
    }
    getch();
}
```

Output of the preceding code is given as follows:

```text
Address of [0]th 1D array is [2293552]
Address of [1]th 1D array is [2293564]
Address of [2]th 1D array is [2293576]
```

Each cell of a two-dimensional array of type int occupies four bytes of data, as an integer takes up four bytes. Now, if we closely look at the preceding output, we will notice that the base address of the array is 2293552. Next, the starting address of the second single dimensional array is 2293564. From the two addresses, we can notice that the difference between the two is 12. These 12 bytes account for those three elements, which are being stored contiguously for the first single dimensional array. Therefore, we can easily say that a two-dimensional array is nothing but a collection of three single dimensional arrays.

When we declare a two-dimensional array, the `arr` pointer points to the base address of the array. Similarly, `*(arr + 1)` gives the 2nd element of the array, which happens to be the base address of the second single dimensional array. In general, the syntax `*(arr + i)` helps us in reaching the ith single dimensional array. After reaching the desired single dimensional array, we should be able to reach to its elements. For instance, as `arr[2][2]` is interpreted as the element residing in the 3rd column of the 3rd row of the array (as it starts from zero), we will reach to the 3rd row with `*(arr + 2)` and then to the 3rd column with `*(*(arr + 2) + 2)`.

Listing 4.8 shows the usage of pointer arithmetic in two-dimensional array:

**Listing 4.8:** Showing the Usage of Pointer Arithmetic in Two-Dimensional Array

```c
#include <stdio.h>
int main()
{
    int i,j;
    int arr[3][3] = {
                        {1,100,1000},
                        {2,200,2000},
                        {3,300,3000}
                    };

    for(i=0;i < 3; i++)
    {
        for(j=0; j < 3; j++)
        {
            printf("%d  ",*(*(arr + i) + j));
        }
        printf("\n");
    }
    getch();
}
```

Output of the preceding code is as follows:

```text
1  100  1000
2  200  2000
3  300  3000
```
