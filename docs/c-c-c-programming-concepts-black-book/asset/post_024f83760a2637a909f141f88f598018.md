
C++ is an object-oriented programming language that exhibits three important properties: encapsulation, inheritance, and polymorphism. Encapsulation binds the code and data together and keeps them safe from the outside interference. This property is also known as information hiding and it forms a basis of object-oriented programming. Inheritance is the process where one object can acquire the properties of another object; and therefore, supports code reusability without defining similar class specifications. On the other hand, polymorphism allows one interface to be used with a general class of actions. In other words polymorphism allows the interface to be used in multiple forms. These three properties empower the language to improve the design, structure, and reusability of the code.

In this chapter, we learn about the most powerful properties of object-oriented programming languages. We first explore the concept of polymorphism in C++ by discussing function overloading and operator overloading. Then, we learn about inheritance and its usage with the help of some programs. Towards the end of the chapter, we discuss about virtual base classes and virtual functions.

Now, let’s discuss about polymorphism in detail.

## Polymorphism

Polymorphism, which is a Greek term, means the ability to take more than one form. This behavior is characterized by the phrase “one interface, multiple methods”. In simple words, polymorphism is a feature that allows one interface to be used with a general class of actions, where the selected action is determined by the nature of a situation. We can take a real world example of polymorphism as thermo flask, which keeps hot things hot and cold things cold. The behavior of the thermo flask depends on what type of fluid we keep in it. Similar is the case with polymorphism in C++. Let’s take the example of a program, where we define three types of stack: one for integer variable, one for user-defined structure, and one for double variable. In all the three cases, we need to access pop() and push() functions to insert and delete items from the stack. Now, as the three stacks have different data types; therefore, we need six value access functions: push_int(), push_double(), and push_userdef() to push data into the stack and pop_int(), pop_double(), and pop_userdef() to delete or pop data from the stack. However, polymorphism in C++ gives us the power to use a single name for similar types of functions. In this case, we can have a single function named push(), which pushes data into all the types of stacks depending on the type of object that is calling it. Similar is the case with the pop() function. The benefits polymorphism gives us is to use the push() and pop() functions without worrying about the specific names of functions for accessing different types of stacks. It is up to the compiler to decide which push() or pop() function to call and execute it based on the type of object, which is invoking the call.

Therefore, polymorphism helps in reducing the complexity by allowing the same interface to be used to specify a general class of actions. It is the compiler’s job to select the specific action as it applies to each situation. We, as a programmer, do not need to bother making this selection; we just only need to remember and utilize the common interface.

C++ supports polymorphism at both compile time and runtime. Compile time polymorphism is achieved through function overloading and operator overloading; whereas, runtime polymorphism is achieved through inheritance and virtual functions. Let’s learn about these concepts in detail in the next sections.

## Function Overloading

Function overloading is one of the most powerful features of C++ programming language. Unlike virtual functions that enforce runtime polymorphism, function overloading forms the basis of compile time polymorphism. As we know that in C++, we cannot have two functions with the same name in a single program because the compiler would not be able to distinguish between them. Therefore, function overloading provides the ability to declare two or more functions in a single program, having the same name. Function overloading is the process of using the same name for two or more functions. However, each redefinition of the function must use either different types of parameters or different number of parameters. It is only through these differences that the compiler knows which function to call in a given situation.

Let's learn more about this functionality by writing some programs. Listing 14.1 shows the program that has two functions with different types of arguments:

Listing 14.1: Showing the Implementation of Function Overloading

```cpp
1:/* Function Overloading Example Program 1 */
2:#include <iostream.h>
3:using namespace std;
4:
5:int func(int i);
6:double func (double j);
7:
8:int main()
9:{
10:    cout<< func(10)<<endl;
11:    cout << func(3.142)<<endl;
12:
13:    return 0;
14:}
15:
16:int func(int i)
17:{
18:    return i;
19:}
20:
21:double func(double j)
22:{
23:    return j;
24:}
```

In line numbers 5 and 6, we have two functions having the same name func; however, the compiler treats them as two different functions based on their parameter type and return type. In line numbers 10 and 11, we are making a call to func with different arguments. The function call on line number 10 causes the program control to jump to line number 16 and execute the integer version of func; whereas, the function call on line number 11 transfers the program control to line number 21 that executes the double version of func. Following is the output of the preceding program:

```
10
3.142
```

Now, let's write another program that has two functions with the same name, but differs in the number of arguments. Listing 14.2 shows the implementation of function overloading with different number of arguments:

Listing 14.2: Showing the Implementation of Function Overloading

```cpp
1:/* Function Overloading Example Program 2 */
2:#include <iostream.h>
3:using namespace std;
4:
5:int func(int i);
6:int func(int j, int k);
7:
8:int main()
9:{
10:    cout<< func(10)<<endl;
11:    cout << func(12, 15)<<endl;
12:
13:    return 0;
14:}
15:
16:int func(int i)
17:{
18:    return i;
19:}
20:
21:int func(int j, int k)
22:{
23:    return (j+k);
24:}
```

In the preceding program, we have two functions with the similar name func, but they differ in the number of arguments passed as a parameter to them. The first function in line number 5 declares itself with one integer parameter and returns an integer from it. The second function in line number 6 consumes two integer variables as arguments and returns the sum of both the input parameters. Based on the parameter list, function resolution is done at the compile time by the compiler. Following is the output of the preceding program:

```
10
27
```

As mentioned, the key point about function overloading is that the functions must differ in the types or numbers of parameters. Note that two functions differing only in their return types cannot be overloaded.

Now, let's go through some of the invalid cases of function overloading and see how the compiler handles this feature of C++ along with the rules for implementing function overloading. Following is an invalid attempt to overload func():

```cpp
int func(int i);
float func(int i);       // Error - cannot be overloaded only on return type
```

In the preceding code snippet, the second line will generate an error at the compile time. This is because two functions, having the same name and same argument list, only differing in the return type cannot be overloaded.

Let's take another example where two function declarations appear to differ, when in fact they do not, as shown in the following code snippet:

```cpp
void myFunction(char *p);
void myFunction(char p[]);    // Error, *p is same as p[]
```

Note that for the compiler, both *p and p[] are the same thing with different representation. Therefore, although the two prototypes appear to differ in the type of their parameter, in reality they do not.

Let's now learn about ambiguity in function overloading that we need to avoid while writing C++ programs.

### Ambiguity in Function Overloading

Although function overloading is a useful feature in C++, often situations might arise when the compiler is unable to choose between two (or more) overloaded functions. When this happens, the situation is said to be ambiguous. Ambiguous calls to overloaded functions give rise to compilation errors; and therefore, the program containing ambiguous statements will not compile successfully. The main cause of ambiguity in C++ is due to its automatic type conversion feature, where C++ automatically attempts to convert the arguments of functions into the type of argument as expected by the function. Let's first see how automatic type conversion works in C++ with the help of the following code snippet:

```cpp
int Foo(double d);
..
cout <<Foo('a')<<endl; // Not an error, auto-type conversion applied.
```
