
### Listing 17.64: Showing an Ambiguity by using the Alias Directive

```csharp
using System;
// Defining alias namespace
using EmpNamespace = Corporate.Organization.Employee;
class Program
{
    public static void Main()
    {
        // Calling the Print() method of the Employee class using namespace
        EmpNamespace.Print();
        // Calling the ambiguous Print() method
        Print();
    }
    // Method with the same name--ambiguous method
    public static void Print()
    {
        Console.WriteLine("This method calls from the Main method");
    }
}
namespace Corporate
{
    namespace Organization
    {
        class Employee
        {
            public static void Print()
            {
                Console.WriteLine("The employee information is as follows:");
                Console.WriteLine("Employee ID: {0}", 100);
                Console.WriteLine("Employee Name: {0}", "C. Thomas");
            }
        }
    }
}
```

While running the preceding program, when the compiler encounters the first Print() method call that contains the namespace alias reference, it will execute the Print() method of the Employee class. However, when the second Print() method is called, the compiler would have set up the Print() method of the Program class to run. The output of the program is as follows:

```text
The employee information is as follows:
Employee ID: 100
Employee Name: C. Thomas
This method calls from the Main method
```
