# ### Thread Attributes

In the previous program of pthread_create() API, we have intentionally passed its second argument as NULL to simplify the program. While calling the pthread_create() API, if we pass NULL in place of the thread attribute, then the thread will be created with the default attributes, that is, it will be a joinable thread. However, if we want to specify custom thread attributes, then we need to handle the call explicitly as follows:

+   - Create a pthread_attr_t object by declaring an automatic variable
+   - Call pthread_attr_init() on an object to initialize it with the default values
+   - Modify the pthread attribute object as per the requirements and set the necessary attributes
+   - Pass the pointer to the pthread attribute object as an argument into pthread_create()
+   - Call pthread_attr_destroy() to release the attribute object

Following different types of custom thread attributes can be passed to the pthread_create() API:

+   - Joinable Thread (Default)—When a thread terminates, it will not be cleaned up automatically. This implies that the thread becomes zombie until pthread_join() is called on it.
+   - Detached Thread—When a thread terminates, it will be cleaned up automatically, and therefore, pthread_join() need not be called.
+   - Scheduling Policy for a Thread (Real Time? PTHREAD_INHERIT_SCHED, PTHREAD_EXPLICIT_SCHED, SCHED_OTHER)—This specifies the type of scheduling policy a thread should use. It is used primarily for real time threads to differentiate them from other threads.
+   - Scheduling Parameter—This sets the scheduling parameters in the thread attribute object. By using this, the priority of a thread is set.
+   - InheritSched Attribute (Default: PTHREAD_EXPLICIT_SCHED Inherit from parent thread: PTHREAD_INHERIT_SCHED)—This is primarily used while creating new threads.
+   - Scope (Kernel threads: PTHREAD_SCOPE_SYSTEM, user thread—PTHREAD_SCOPE_PROCESS pick one or the other, but not both). This helps us to work in two different modes – kernel space and user space.
