In Listing 1.13, the second if-else construct is nested within the else block of the first if-else construct. The idea is that if the first if statement fails, then the control shifts to the statements within the respective else block and then the if-else block within the first else block will be executed. It is not always necessary that the nesting needs to take place inside the else block; it may take place inside the if block as well. However, it is extremely necessary that the code must be properly indented; otherwise, misplaced if-else blocks could occur. In addition, it is a good programming practice to include both single and multiple types of statements inside curly braces, as this increases the readability of the code.
