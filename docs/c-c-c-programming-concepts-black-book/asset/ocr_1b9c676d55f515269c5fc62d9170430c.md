Radix sort is one of the easiest sorting techniques that sorts the elements based on the individual digits of the array elements. It implements a non-comparative technique to sort a list. The basic concept of this technique is to first create a bin array whose size is defined by a user and then depending on the individual digits of the elements (or depending on the length of the element), the elements are placed into the respective bins. This process creates the relative sub-lists based on the one's position and then in the second step, it creates another sub-list and places the array elements in the bin depending on the ten's position value of the elements. Therefore, if a list has elements whose highest length is 3, then this process continues until it sorts the elements based on the hundred's position value.

The radix sorting technique uses two loops: the external loop and the inner loop. The external loop is executed a number of times depending on the highest length of the array element. On the other hand, the inner loop is executed a number of times depending on the user-specified bin value.
