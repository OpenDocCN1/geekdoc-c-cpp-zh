Let’s now learn about XML namespaces.

### XML Namespaces

.NET provides five namespaces for the implementation of XML. Table 20.1 gives a brief introduction of XML namespaces.

**Table 20.1: XML Namespaces and their Utilities**

| Namespace | Utility |
| --- | --- |
| System.Xml | Refers to a main namespace that is used in the .NET platform. It provides all the classes that are used for reading, writing, and manipulating an XML document. |

The XML nodes include the start tag, the end tag, whitespaces, comments, and the XML declaration tag. Depending on the node type, which can be an Element, Text, End Element, or Xml Declaration, the XmlTextReader class navigates through all the nodes to get the value of the required node type.

To declare an object of the XmlTextReader class, we need to create an instance of the FileStream class by specifying the file name along with its path and providing the FileMode and FileAccess specifications. The code snippet for declaring an instance of XmlTextReader is given as follows:

```
FileStream fileStream = new FileStream(path, FileMode.Open, FileAccess.Read);

XmlTextReader xmlTextReader = new XmlTextReader(fileStream);
```

Next, let’s learn about the XmlTextWriter class.

### XmlTextWriter

The easiest way to create or modify an XML document is to use the XmlTextWriter class. This class offers the same functionality of the StreamWriter class, but with the exception that the XmlTextWriter class is used for writing the XML document. The XmlTextWriter object can be created by providing a FileStream object that holds the path of the new XML document to be created or modified and the FileMode of the document, shown as follows:

```
FileStream fileStream = new FileStream(path, FileMode.Create);
XmlTextWriter xmlTextWriter = new XmlTextWriter(fileStream, System.Text.Encoding.UTF8);
```

There are two overloaded constructors to create an instance of the XmlTextWriter class.

Table 20.3 provides the important methods of the XmlTextWriter class:

**Table 20.3: Noteworthy Methods of the XmlTextWriter Class**

| Method | Description |
|---|---|
| `Close()` | Closes an XmlTextWriter object and releases all the resources that the object was using. In addition, it closes the underlying open streams. |
| `Flush()` | Flushes the buffer to the underlying stream as well as flushes the underlying stream. |
| `WriteAttributes(XmlReader reader, bool defAttribute)` | Writes an attribute to the FileStream object from the object of the XmlReader class that has been passed as an argument. In addition, it writes the default attribute if the Boolean variable, which has been passed as an argument, is set to true. |
| `WriteAttributeString(string localName, string value)` | Writes the name and value of an attribute in an XML document.<br><br>**Overloads:**<br>• `WriteAttributeString(string localName, string namespaceURI, string value)` → Writes the namespace URI of an attribute along with other properties in an XML document.<br>• `WriteAttributeString(string prefix, string localName, string namespaceURI, string value)` → Writes the prefix of an attribute along with other properties in an XML document. |
