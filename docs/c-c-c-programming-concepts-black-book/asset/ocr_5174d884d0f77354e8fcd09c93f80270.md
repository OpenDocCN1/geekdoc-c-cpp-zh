# tanh()

The tanh() family of functions returns the hyperbolic tangent of the argument passed to them. The signature of the tanh() family of functions is as follows:

```
float tanh(float param);
double tanh(double param);
long double tanh(long double param);
```

The tanh() and tanhf() functions were introduced by the C99 compiler. The tanhf() function is used for the float data type and the tanhl() function is used for the long double data type. Let's take an example of the tanh() function mentioned in Listing 8.8:

Listing 8.8: Usage of tanh() function.

```
#include<stdio.h>
#include<math.h>

int main()
{
    double val = -0.5;
    printf("\n the hyperbolic Tangent of %f is %f ",val, tanh(val));
    getch();
}
```

Output of the preceding example is as follows:

```
The hyperbolic Tangent of -0.500000 is -0.462117
```

# cbrt()

The cbrt() family of functions returns the cube root of the argument passed to them. The signature of the cbrt() family of functions is as follows:

```
float cbrtf(float param);
double cbrt(double param);
long double cbrtl(long double param);
```

The cbrt(), cbrtf(), and cbrtl() functions were introduced by the C99 compiler. Let's take an example of the cbrt() function as mentioned in Listing 8.9:

Listing 8.9: Usage of cbrt() function.

```
#include<stdio.h>
#include<math.h>
int main()
{
    double val = 27;
    printf("\n The cube root of %f is %f ",val, cbrt(val));
    getch();
}
```

Output of the preceding example is as follows:

```
The cube root of 27.000000 is 3.000000
```
