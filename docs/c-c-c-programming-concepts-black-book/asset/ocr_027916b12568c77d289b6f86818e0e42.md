# # Structure

We have already learned about structures in C and C++. However, in C#, the structure holds the definition as follows:

+   - A structure is a value type.
+   - A structure can hold fields, methods, and events similar to a class.
+   - As a structure is of value type, it can be instantiated without using a new operator.
+   - A structure is inherited from the System.Object namespace.
+   - A structure cannot be inherited by any other structure. In addition, it cannot be a base structure of any class.
+   - The members of a structure cannot be initialized unless they are declared as a constant using the *const* operator or a static using the *static* operator.
+   - Any default constructor or destructor cannot be defined inside the structure because whenever a copy of a structure is created, the compiler automatically set the default constructor or destructor.

Structure in C# behaves somewhat similar to a class, but the difference lies in the fact that class is a reference type and structure is a value type. Therefore, whenever we assign a structure to another structure, the whole structure along with its content is copied to the structure. In addition, if we make any modifications to the copied structure, it will not reflect to the structure, which is copied. This is one of the main disadvantages of using a structure instead of a class.

In C#, a structure is defined using the keyword *struct*. We can declare a structure as follows:

```
```csharp
public struct <structure_Name>
{
    //declaration of Field, Properties, Methos, Event etc
}
```
```

Listing 17.23 shows the usage of a structure in C#:

**Listing 17.23: Showing the Usage of a Structure**

```
```csharp
using System;
public struct Example
{
    public string str;
    public Example(string s)
    {
        str = s;
    }
}
public class Program
{
    public static void Main()
    {
        Example e = new Example();//calling the default constructor
        Example e1 = new Example("Hello world");//calling the parameterized
                                               //constructor
        Console.WriteLine(e1.str);
    }
}
```
```
