Now, let’s explain the entire procedure algorithmically. Following is the set of inputs, output, and the steps of algorithm:

Input: A connected graph G with vertices labeled v1, v2, ……, vn
Output: A spanning tree T for G

+   **Method:**
+   
+   1. (Visit a vertex) Let v1 be the root of T and set L = v1 (where L stands for the vertex last visited).
+   2. (Find an unexamined edge and an unexamined vertex adjacent to L) For all the vertices adjacent to L, choose the edge (L, vk), where k is the minimum index, such that adding (L, vk) to T does not form a cycle. If no such edge exists, then go to step 3; otherwise, add edge (L, vk) to T and set L = vk. Repeat the step 2 at the new value for L.
+   3. (Backtrack or terminate) If x is the parent of L in T, then set L = x and apply the step 2 at the new value of L. If, on the other hand, L has no parent in T (such that L = v1), then DFS terminates and T is the spanning tree for G.
