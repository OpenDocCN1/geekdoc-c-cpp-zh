Table 20.3: Noteworthy Methods of the XmlTextWriter Class

| Method | Description |
|---|---|
| WriteComment(string commentText) | Writes the commentText in the comment part of an XML document. |
| WriteDocType(string name, string pubid, string sysid, string subsetValue) | Writes the DOCTYPE declaration with the specified arguments to the FileStream object. This is used to define an XSD. |
| WriteElementString(string localName, string value) | Writes the name and value of an element in an XML document.<br>Overloads:<br>• WriteElementString (string localName,string namespaceURI, string value)→Writes the namespace URI of an element along with other properties to the FileStream object.<br>• WriteElementString (string prefix, string localName,string namespaceURI, string value)→Writes the prefix of an element along with other properties to the FileStream object. |
| WriteStartAttribute(string localName) | Writes the attribute with its local name to the FileStream object.<br>Overloads:<br>• WriteStartAttribute (string localName,string namespaceURI)→Writes the namespace URI of an attribute along with other properties to the FileStream object.<br>• WriteStartAttribute (string prefix, string localName,string namespaceURI)→Writes the prefix of an attribute along with other properties to the FileStream object. |
| WriteEndAttribute() | Closes the previous starting tag of an attribute. |
| WriteStartDocument() | Writes the XML declaration tag with the version 1.0 to FileStream.<br>Overloads:<br>• WriteStartDocument (bool standalone)→Writes yes to the FileStream object if the Boolean variable is set to true, otherwise, it writes no to the FileStream object. |
| WriteEndDocument() | Closes any open attribute or element tag and set the pointer of the writer back to the start position. |
| WriteStartElement(string localName) | Writes the start tag of an element to the FileStream object by providing its local name.<br>Overloads:<br>• WriteStartElement (string localName,string namespaceURI)→Writes the namespace URI in an element tag along with other properties to the FileStream object.<br>• WriteStartElement (string prefix, string localName,string namespaceURI)→Writes the prefix in an element tag along with other properties to the FileStream object. |
| WriteEndElement() | Closes any open element and pops up the corresponding namespace scope. |
| WriteName(string name) | Writes the name to the FileStream object after validating the name with the names recommended by W3C XML 1.0. |
