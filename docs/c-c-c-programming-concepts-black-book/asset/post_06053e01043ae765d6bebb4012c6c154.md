Now, let’s add the node [B] back to the linked list. The reference from node [A] is set to node [B] and the reference from [B] is set to the previous reference of [A], which is [C], as shown in Figure 24.3:

![](img/43c5f409f9b17790a628c4b4df854b61_825_0.png)

**Figure 24.3: Showing the Pictorial View of Adding an Element in a Linear Linked List**

For insertion, a record holding the new item is created. The next pointer of the new record is set to link it to the item, which follows it in the list. The next pointer of the item, which is to precede it, must be modified to point to the new item.

### Doubly Linked List

In a doubly linked list, pointer exists between the adjacent nodes in both the directions. Therefore, this type of list can be traversed in both the directions. We maintain two pointers to keep track of a doubly linked list – *head* and *tail*. As a doubly linked list allows sequential access in both the directions, it is easier to manipulate it than the linear or circular linked list. Figure 24.5 shows a doubly linked list:
