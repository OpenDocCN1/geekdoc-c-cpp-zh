Following is the stepwise execution of the partition phase:

+   1. Take the array A[N]. Consider the first element A[0] as the pivot element and assign the value of A[0] to k. Assign 1 and (N-1) to i and j, respectively.
+   
+   2. If i < j, then increment i until A[i] > k and decrement j until A[j] < k. It means that in each iteration, while moving from left to right, index i searches for the value first greater than the pivot value and stops moving immediately once the match is found. Similarly, the index j, while moving from right to left, searches the value from the right that is smaller than the pivot value and stops immediately once the match is found. At that point, the values A[i] and A[j] are interchanged.
+   
+   3. While moving from right to left, if i < j, then it implies that one iteration of i and j is completed and at that point, the A[j] is interchanged with the pivot value. This operation results the list to be divided into two sub-lists based on the pivot value, which almost occupies the middle position of the list. The left-hand side of the pivot value is a list that contains the elements having values smaller than the pivot value and the right-hand side of the pivot value is a list that holds the elements having values smaller than the pivot.

Now, let's learn about the sorting phase. After getting two separate lists in the partition phase, we apply the quick sort technique separately on them. This recursive call of quick sort method helps the entire list to be sorted in an efficient way.

Let's take the following example to explain the quick sort technique:

|  |  |  |  |  |  |  |  | Explanation |
|---|---|---|---|---|---|---|---|---|
| 40 | 30 | 10 | 80 | 90 | 20 | 100 | 70 | *It is the input list.* |
| 40 | 30<br>i→ | 10 | 80 | 90 | 20 | 100 | 70<br>←j | *40 is chosen as pivot.* |
| 40 | 30 | 10 | 80<br>i→ | 90 | 20<br>←j | 100 | 70 | *The positions of 20 and 80 are interchanged.* |
| 40 | 30 | 10 | 20<br>i→ | 90 | 80<br>←j | 100 | 70 |  |
| 40 | 30 | 10 | 20<br>←j | 90 | 80 | 100 | 70 | *As j<i, we exchange the pivot with the value at position j.* |
| 20 | 30 | 10 | **40** | 90 | 80 | 100 | 70 | *This makes the pivot to occupy the middle position of the list whose left side elements are less than 40 and the right side elements are greater than 40.* |
| 20 | 30<br>i→ | 10<br>←j | **40** |  |  |  |  | *The quick sort technique is applied recursively to the left side list where 20 is the pivot. As A[i]>pivot and A[j]<pivot, the positions of 30 and 10 are interchanged.* |
| 20 | 10<br>←j | 30<br>i→ |  |  |  |  |  | *As j<i, we exchange the pivot with the value at position j.* |
| 10 | **20** | 30 |  |  |  |  |  | *20 is placed at the middle of this sub-list.* |
| 10 |  |  |  |  |  |  |  | *Quick sort is applied recursively to 10, which results in 10.* |
|  |  | 30 |  |  |  |  |  | *Again, it is applied to 30, which results in 30.* |
|  |  |  |  | 90 | 80<br>i→ | 100 | 70<br>←j | *After that, quick sort is applied recursively to the right side list, where 90 is the pivot.* |
|  |  |  |  | **90** | 80 | 100<br>i→ | 70<br>←j | *As A[i]>pivot and A[j]<pivot, the positions of 100 and 70 are interchanged.* |
