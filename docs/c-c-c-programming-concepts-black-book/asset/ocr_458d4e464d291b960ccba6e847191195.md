# Listing 18.6: Showing an Example of the Copy Constructor

```
```csharp
using System;
class Program
{
    static void Main(string[] args)
    {
        int member1 = 1;
        string member2 = "MyClass";
        //Object instantiated using Parameterized constructor
        MyClass myClass = new MyClass(member1, member2);
        Console.WriteLine("Object instantiated using
        Parameterized constructor...");
        Console.WriteLine("The members are {0}, {1}",
        myClass.member1, myClass.member2);
        //Object instantiated using Copy constructor
        MyClass newMyClass = new MyClass(myClass);
        Console.WriteLine("Object instantiated using Copy constructor...");
        Console.WriteLine("The members are {0}, {1}",
        newMyClass.member1, newMyClass.member2);
    }
}
public class MyClass
{
    public int member1;
    public string member2;
    //Parameterized constructor
    public MyClass(int member1, string member2)
    {
        this.member1 = member1;
        this.member2 = member2;
    }
    //Copy Constructor
    public MyClass(MyClass obj)
    {
        this.member1 = obj.member1;
        this.member2 = obj.member2;
    }
}
```
```

In Listing 18.6, we have instantiated an object of MyClass using the parameterized constructor. After that, we have again instantiated another object of MyClass by using the copy constructor where we have passed the object created using the parameterized constructor as an argument. The output of the preceding code is given as follows:

```
```text
Object instantiated using Parameterized constructor...
The members are 1, MyClass
Object instantiated using Copy constructor...
The members are 1, MyClass
```
