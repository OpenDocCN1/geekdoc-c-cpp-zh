
## Creating a File System Application using C#

The My File Manager application loads a tree structure that contains all the directories, sub-directories, and files (stored in those directories and sub-directories) in a specific system drive. This application performs the following tasks:

- It loads the file and directory structure of a user-specified drive on the main page of the application.
- After the page is loaded with the drive structure, users are allowed to select the text files. The content of the selected file appears in the text box provided on the page.
- After the text box is populated with the content of the file, three buttons, named Modify, Append, and Upload, will be enabled.
- When a user clicks the Modify button, the user will be able to view the content of the file in a new text box, edit the file, and save the modified file. Through the Save button, the modified content of the file will also be reflected in the text box. The user also gets the option to undo the modifications done on the file.
- When a user clicks the Append button, the user is provided with a blank text box where he/she can write the text that is to be appended on the text file. After clicking the Save button, the text file is appended with that line of text and the text box reflects the changes. A user can also cancel the append operation.
- After clicking the Upload button, a user will be able to view the FileUpload control, where the user can upload a file to a specified location.

Now, let's discuss each operation in more detail in the next sub-sections.

### Describing the Page Load Event

Perform the following steps involved in the execution of Page Load event.

1. Specify the drive for which the tree view will be populated. For a complete tree structure, get all the drive names and then for each drive, get the directories, sub-directories, and files. The following code can be used to get a list of drives:

```csharp
string[] drives = Directory.GetLogicalDrives();
```

In our case, we have created a dummy drive, named F, and showed the directory and file structure for that drive. The code to add a drive name in the tree structure is as follows:

```csharp
string dr = "F:\\";
string drText = "F:";
TreeNode treeNode = new TreeNode(drText);
```

In the preceding code, dr represents the directory path and drText denotes the text that will be shown in the tree structure. To add a node in the tree structure, we have created an instance of the TreeNode class.

2. Add all the directories and its sub-directories in the tree view after populating the drive node in it. For this purpose, write a recursive method, as shown in Listing 21.1, to get the list of directories:

**Listing 21.1:** Showing the Code for the `GetDirectoryList()` Method

```csharp
protected string[] GetDirectoryList(string path)
{
    string[] directoryList = null;

    try
    {
        directoryList = Directory.GetDirectories(path);
        return directoryList;
    }
    catch (Exception)
    {
        return null;
    }
}
```

In Listing 21.1, the GetDirectoryList() method has used the GetDirectories() method of the Directory class to get a list of directories from the specified path.

3. Add each directory as a child node in the tree structure and search for any sub-directory that exists in the directory after getting the list of directories. If the sub-directory exists, then add it as a child node of the respective directory node. The recursive method to achieve this whole operation is as shown in Listing 21.2:

**Listing 21.2:** Showing the Code for the `GetFolderStructure()` Method

```csharp
protected void GetFolderStructure(string drive, TreeNode treeNode)
{
    DirectoryInfo directoryInfo = new DirectoryInfo(drive);
    string folderText = string.Empty;

    if (directoryInfo.Exists)
    {
        try
        {
            if (GetDirectoryAccess(directoryInfo.ToString()))
            {
                string[] directoryList = GetDirectoryList(drive);
                foreach (string folder in directoryList)
                {
                    if (folder.Contains(".") && !folder.Contains("RECYCLE"))
                    {
                        if (GetDirectoryAccess(folder))
                        {
                            folderText = folder.Substring
                                (folder.LastIndexOf("\\") + 1);
                            TreeNode childNode = new TreeNode(folderText);
                            treeNode.ChildNodes.Add(childNode);
                            GetFileStructure(folder, childNode);
                        }
                    }
                    else if (!folder.Contains("."))
                    {
                        if (GetDirectoryAccess(folder))
                        {
                            folderText = folder.Substring
                                (folder.LastIndexOf("\\") + 1);
                            TreeNode childNode = new TreeNode(folderText);
                            treeNode.ChildNodes.Add(childNode);
                            GetFolderStructure(folder, childNode);
                            GetFileStructure(folder, childNode);
                        }
                    }
                    else
                    {
                        continue;
                    }
                }
            }
        }
        catch (Exception ex)
        {
            //continue;
        }
    }
}
```

In Listing 21.2, we have first got the directory information by declaring a DirectoryInfo object on the drive path. This object tells about the directory information, such as its existence, parent node, and root node. From these properties, we have checked for the existence of this directory. If the directory exists, then we check for the access to that directory by using the GetDirectoryAccess() method. Listing 21.3 shows the code for the GetDirectoryAccess() method:

**Listing 21.3:** Showing the Code for the `GetDirectoryAccess()` Method

```csharp
protected bool GetDirectoryAccess(string dr)
{
    bool isAccess = false;
    try
    {
        System.Security.AccessControl.DirectorySecurity ds = Directory.GetAccessControl(dr);
        isAccess = true;
    }
    catch (Exception ex)
    {
        isAccess = false;
    }
    return isAccess;
}
```

In the preceding method, we have defined an object of the DirectorySecurity class that holds the access control information of the directory. If this method returns true, then we get the list of all the directories that are stored under this drive.

After that, in Listing 21.2, we have recursively called the GetFolderStructure() method until all the sub-directories under a directory are appended in the tree structure. Once this operation is complete, the files that exist in those directories and sub-directories are appended in the tree structure. This operation is achieved by calling the GetFileStructure() method recursively where we have passed the full path of the directory along with the node structure of that directory where the files will be appended as a child node. Listing 21.4 shows the code for the GetFileStructure() method:

**Listing 21.4:** Showing the Code for the `GetFileStructure()` Method

```csharp
protected void GetFileStructure(string folder, TreeNode treeNode)
{
    string[] fileList = GetFileList(folder);
    string fileText = string.Empty;
    foreach (string files in fileList)
    {
        fileText = files.Substring(files.LastIndexOf("\\") + 1);
        TreeNode childNode = new TreeNode(fileText);
        treeNode.ChildNodes.Add(childNode);
    }
}
```

After that, we populate the text box with the content of the file by executing the `ReadAllText()` method of the `File` class. For the modification operation, we also maintain a hidden text box that is populated with the file content when we click the Modify selected file button. Listing 21.7 shows the C# code for the modification operation:

**Listing 21.7:** Showing the Code for the `btnmodify_Click()` Method

```csharp
protected void btnmodify_Click(object sender, EventArgs e)
{
    CheckVisibility("modify");
    string path = txtFolderList.SelectedNode.ValuePath.Replace("/", "\\");
    txtModifyFile.Enabled = true;
    btnSave.Enabled = true;
    btnCancel.Enabled = true;
    txtModifyFile.Visible = true;
    btnSave.Visible = true;
    btnCancel.Visible = true;
    try
    {
        if (File.Exists(path))
        {
            txtModifyFile.Text = File.ReadAllText(path);
            txtHiddenModifyFile.Text = File.ReadAllText(path);
        }
    }
    catch (Exception ex)
    {
        lblError.Text = ex.Message;
    }
}
```
