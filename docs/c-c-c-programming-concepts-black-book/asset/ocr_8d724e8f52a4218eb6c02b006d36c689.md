Every stream has some format flags that control the way in which information is formatted. The ios class declares a bitmap enumeration called format flags where the following values tend to be defined:

+   - adjustfield
+   - basefield
+   - boolalpha
+   - dec
+   - fixed
+   - floatfield
+   - hex
+   - internal
+   - left
+   - oct
+   - right
+   - scientific
+   - showbase
+   - showpoint
+   - showpos
+   - skipws
+   - unitbuf
+   - uppercase

By default, console I/O is unformatted, but we can format them using different ios functions. Table 15.5 shows various ios functions:

**Table 15.5: Different ios Functions**

| Function | Description |
|---|---|
| setf() | Sets the format flags that can control the form of output display |
| unsetf() | Resets the format flags |
| width() | Sets the required field size for displaying output |
| fill() | Sets the padding used to fill unused portions of a field |
| precision() | Sets the number of digits to be displayed after the decimal point of a float value |

Let’s now learn about these functions, in detail.

# The setf() Function

There are two basic syntaxes to explain the use of setf() function, given as follows:

```
    fmtflg setf (fmtflg fmtfl );
    fmtflg setf (fmtflg fmtfl, fmtflg mask );
```
