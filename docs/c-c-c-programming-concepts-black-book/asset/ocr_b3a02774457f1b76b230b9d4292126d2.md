The answer to this question is simple – by using different macros that are defined in C. If we take a closer look at the program, then we notice that the SIGINT macro is used to register a signal handler in the main() function. The SIGINT macro is used to trap the interrupt that comes to the program. When a user presses CTRL+C, it generates an interrupt, which is forwarded by the processor to the program. This interrupt is then trapped by the signal handler function. To trap an interrupt, we need to register a signal handler function and perform certain activities when the interrupt is generated. To register a signal handler function, we use the following signal library function:

```
void (*signal(int signal, void (*func)(int)))(int);
```

he signal() function registers the function pointed to by func as a handler for the signal. This implies that the function pointed to by func will be called when the interrupt signal is received by a program. Note that the <signal.h> header should be added in the source code to use the signal() function.

# Calling Subroutines from Interrupt Handlers

After the control of a program is transferred to an interrupt handler, different subroutines can be called to perform certain actions from the interrupt handler. Listing 6.2 shows how to call subroutines from an interrupt handler:

Listing 6.2: Calling Subroutines from an Interrupt Handler

```
```c
#include<stdio.h>
#include<signal.h>

void writeToFile()
{
    FILE *fp = fopen("D:\\SignalTest.txt", "a");
    fprintf(fp,"\n SIGNAL Received ");
    fclose(fp);
}

void sighandler(int signum)
{
    writeToFile();
}

int main()
{
    signal(SIGINT, (void*)sighandler);

    while(1)
    {
        printf("\n Infinite Loop");
    }

    return 0;
}
```
```

In Listing 6.2, we have called a subroutine from the signal handler and performed certain actions in it. When the program receives a SIGINT signal, the sighandler() subroutine is invoked. This is because we have registered a signal handler from the main() subroutine. From sighandler(), we have also called the writeToFile() subroutine to perform certain tasks.
