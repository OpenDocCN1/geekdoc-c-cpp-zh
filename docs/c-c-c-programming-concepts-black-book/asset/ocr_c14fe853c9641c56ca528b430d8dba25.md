# div()

The div() function returns the quotient and the remainder of a division operation. The signature of the div() function is as follows:

```
div_t div(int numerator, int denominator);
```

As seen in the preceding signature, the div() function returns a structure of type div_t. The structure div_t has two members, which are as follows:

```
int quot;
int rem;
```

Let's take an example of the div() function as mentioned in Listing 8.31:

**Listing 8.31:** Usage of div() function.

```
#include<stdio.h>
#include<stdlib.h>

int main()
{
    div_t result;
    result = div(254, 9);
    printf("\n Quotient is %d and remainder is %d ",result.quot,result.rem);

    getch();
    return 0;
}
```

Output of the preceding example is as follows:

```
Quotient is 28 and remainder is 2
```

# exit()

The exit() function causes an immediate normal termination of a program. Any open file is flushed and closed when the function is executed. The signature of the exit() function is as follows:

```
void exit(int exit_code);
```

The value of the exit_code argument is passed to the calling function (which happens to be an operating system). By default, the value of exit_code is zero, which indicates EXIT_SUCCESS. A non-zero value or EXIT_FAILURE indicates an implementation-defined error. Let’s take an example of the exit() function as mentioned in Listing 8.32:

**Listing 8.32:** Usage of exit() function.

```
#include<stdio.h>
int main()
{
    int input;

    printf("\n Enter a value -> ");
    scanf("%d",&input);

    if(input %2)
    {
        printf("\n Gracefully Terminating Program");
        getch();
        exit(0);
    }
    return 0;
}
```
