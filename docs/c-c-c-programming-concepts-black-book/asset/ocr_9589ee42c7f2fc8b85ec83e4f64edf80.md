this, we give a weighted connected undirected graph G as an input to the algorithm and get a minimum spanning tree T as an output. The following are the steps of Kruskal’s algorithm:

+   1. Find an edge such that its weight w(eᵢ) is minimum.
+   2. At this point, we have 3 sub-steps:
+      a. If edges e₁, e₂, ..., eₙ have been chosen, then pick up an edge e₍ₙ₊₁₎ not equal to eᵢ for i = 1 to n.
+      b. The edges e₁, e₂, ..., eₙ, e₍ₙ₊₁₎ does not form a cycle.
+      c. The weight of the edge w(e₍ₙ₊₁₎) is as small as possible subject to the condition is the step 2(b).
+   3. Stop, when all the vertices of G are in T.
