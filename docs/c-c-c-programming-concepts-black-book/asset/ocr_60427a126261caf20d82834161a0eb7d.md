```

In the preceding example, we have used an integer pointer ptr_A, assigned the address of the variable var_A to it, and displayed the address. In the successive steps, we have passed the address of the variable to the increment_pointer() function. Within the function, the address is collected in an integer pointer, which is incremented by one and then returned. It is interesting to note that when the value returned by the function is displayed, a shift of four bytes from the previous value took place. This happens because an integer takes four bytes of space in the memory. When we declare an integer pointer, it enables us to access all the four bytes memory location, which the pointer is pointing at. When we perform an increment operation on that pointer, it will point to the next location, which is again of four bytes; therefore, a shift of four bytes is observed. It should be kept in mind that we can only perform the increment and decrement operations on pointers. Division and multiplication operations on pointers are not allowed.

Example 3:

```
```c
# include <stdio.h>

void increment_pointer(int);
int main()
{
    int var_A = 10;
    void *ptr_A;
    ptr_A = &var_A;

    printf("\n Address Before [%u] ",ptr_A);
    increment_pointer(&var_A);
    printf("\n Address After [%u] ",ptr_A);
    getch();
}

void increment_pointer(int ptr)
{
    printf("\n Value [%d]",ptr);
}
```
```

The preceding code will compile with the following warning:

> > [Warning] passing arg 1 of `increment_pointer' makes integer from pointer without a cast

We can collect the address of a memory location inside an integer variable and display it. However, if we try to perform any arithmetic operation on the variable, then that will not be allowed and a compile time error will be generated.

The output of Example 3 is as follows:

```
```text
    Address Before [2293620]
    Value [2293620]
    Address After [2293620]
