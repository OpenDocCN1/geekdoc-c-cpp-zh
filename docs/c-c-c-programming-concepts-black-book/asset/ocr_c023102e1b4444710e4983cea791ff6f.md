# Flow Control Statements

Till now, the programs we have discussed in the previous sections follow a sequential execution model. However, while solving real life problems using C++ programming, very few programs follow the execution of statements in a strict order from beginning to end. Most programs decide what to do in response to changing circumstances. As a result, the flow of a program jumps from one part to another based on the calculations and operations performed in the program. Therefore, to handle these situations, we need the help of three tools – loops, decision, and jump statements. Let’s learn about these three tools in detail.

# Decision Statements

In a program, a decision statement causes a onetime jump to the different parts of a program, depending on some expression evaluation. In C++, decisions can be made using the if, if-else, and switch statements. However, the most popular among these statements is the if-else statement, which chooses between two alternatives. This statement can even be used without an else part. We have another decision-making statement called switch. It creates branches for multiple alternatives and depending on the value of a single variable, chooses the answer or breaks the decision. Let’s learn about each of them in detail in the next sections.

# The if Statement
