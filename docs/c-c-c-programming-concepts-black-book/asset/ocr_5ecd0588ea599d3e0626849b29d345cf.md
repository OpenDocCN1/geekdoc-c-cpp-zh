# Inheritance

Inheritance is probably the most powerful features of object-oriented programming. It has given an extra edge to other object-oriented features, such as encapsulation and polymorphism. Inheritance is the process of creating new classes, called derived classes, from existing or base classes. By using inheritance, we create a base class that defines common traits to a set of related items. The derived classes not only inherit all the capabilities of the base class, but also add their own refinements to enrich themselves.

Inheritance is considered as an essential part of object-oriented programming, as it permits code reusability. After a base class is written and debugged, it need not be touched again; instead, we inherit the base class to any other derived class, take its common traits, and then add our own functionality to make the derived class work. Reusing existing code saves both time and money and increases program reliability.

Let’s now learn about the base and derived classes in detail.

# Defining the Base and Derived Classes

In C++, a base class is a class, which other classes may derive to extend their functionality; whereas, a derived class is a class that derives a base class to extend its functionality. The concept of base and derived classes increases modularity in the source code and readability of the program. When a class inherits another class, the general form it uses is as follows:

```
```cpp
class DerivedClassName: AccessLevel BaseClassName {
        // Member definition
};
```
```

When a derived class inherits the base class, the members of the base class also become the members of the derived class. Let’s take an example of a company that has different types of employees, such as workers, managers, sweepers, housekeepers, and electricians. As all of them are employees of the company; therefore, in this case, we can define a base class Employee, having the basic details of all the employees as common properties. Now, we can define a derived class called Manager that will inherit all the properties of the Employee base class and have some properties of its own as well, such as department and manager grade.

For our example, we can have the definition of base class and derived class as follows:

```
```cpp
class Employee {

    char address[200];

class Manager: public Employee {
