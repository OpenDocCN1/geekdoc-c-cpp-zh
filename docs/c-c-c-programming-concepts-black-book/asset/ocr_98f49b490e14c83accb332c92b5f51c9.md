# CLR

As one of the main components of the .NET Framework, CLR provides portability and security for the programs as well as manages the execution of the programs. In addition, it provides mixed language programming using CTS.

Before going into the details of CLR, let’s learn about the two different types of codes, which are given as follows:

+   - **Managed code** — CLR executes managed code which access both the managed data (refers to the memory location that is allocated and de-allocated by the CLR using the garbage collection technique) and the unmanaged data. Managed code helps the CLR:
+     - To locate the method encoded in the assembly module with the help of the metadata information provided by the managed code
