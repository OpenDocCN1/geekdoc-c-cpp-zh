While writing an email script, we need to provide the information related to the SMTP server. This information can be provided by either using the C# code or configuring the Web.config file. However, the best practice is to configure the server information in the Web.config file. Following code shows how to add the configuration settings of the SMTP server in the Web.config file:

```xml
<configuration>
  <system.net>
    <mailSettings>
      <smtp>
        <network
          host = "Name of SMTP Server"
          port = "PortNumber used by the SMTP server"
          userName = "user name"
          password = "password" />
      </smtp>
    </mailSettings>
  </system.net>
  <system.web>
    .
    .
  </system.web>
</configuration>
```

In the preceding code, we have first added the `<system.net>` element under the `<configuration>` element. Then, we have added the `<mailSettings>` element, which contains another element, named `<smtp>`. Under the `<smtp>` element, we have added another child element, named `<network/>`, which contains the configuration settings of the SMTP server.

Some emails are formatted in a manner that they always send an attachment along with the email body; for example, sending an electronic bill through an email. Email can be sent purposefully to alert the customers if some job execution fails. The names of the recipients in this case are certain and generally picked up from the database. In addition, the sender's address, subject, and the email body are fixed for these emails. Since these emails are circulated over an organization, security of the sender's address, subject, and email body should be the main business criteria. In addition, several Web forms in an application may use the same message body. For this purpose, all the constant values can be embedded in the Web.config file so that whenever an administrator of the application needs to change the message body, he/she can directly do so in the Web.config file. Otherwise, the administrator needs to change it in every Web form that uses the same email body. For this purpose, the `<appSettings>` element can be in the Web.config file, as follows:

```xml

```
