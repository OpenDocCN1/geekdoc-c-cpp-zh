# Binary Search

In the binary search, to find a key element, first the middle element of a list is found, which is then matched with the key value. If the key value is less than the middle element of the list, then the searching continues with the left-hand side set of elements recursively. However, if the key value is greater than the middle element of the list, then this technique is applied to the right-hand side of list elements recursively. This process continues until the key value is found. If a list contains millions of records, then it will take log2(1000000) ≈ 20 steps to perform the search. Therefore, this technique is much more efficient than the sequential search.

Let’s consider the following list of elements:

(-1, 1, 5, 10, 50, 60, 70, 80, 90, 100, 200, 300)

Now, suppose the key value is 80. If we apply the binary search technique, then it would be as follows:

| Step | Array / Elements | Comparison |
|---|---|---|
| Step 1 | -1, 1, 5, 10, 50, **60**, 70, 80, 90, 100, 200, 300 | Middle element = 60; 60 < 80 |
| Step 2 | 70, 80, **90**, 100, 200, 300 | Middle element = 90; 90 > 80 |
| Step 3 | 70, **80** | Middle element = 80; 80 == 80 |

In step 1, the middle element is selected, which is 60. As 80 is greater than 60, the process looks into the right-hand side list of 60. The technique is again applied to the right-hand side list, where the middle element is selected as 90. As 80 is less than 90, the binary search technique is again applied to the left-hand side list of 90, where the middle element is selected as 80. In this case, 80 matches with the key value.

function Binary_Search_Iterative(A[n], key, n):integer
    begin
        first <- 0
        mid <- 0
        last <- n-1
        while(first < last)
        begin
            mid <- (first +last)/2
            if(A[mid] == key)
            begin
                return mid
            end
            if(A[mid]< key)
            begin
                first <- 0
                last <- mid-1
            else
                first <- mid +1
                last <- n-1
            end
        end
        return -1
    end
