## Static Members

Both data and method of a class can be made Static. Whenever we precede a member variable’s declaration with the Static keyword, it instructs the compiler that only one copy of that variable will exist and all the objects of that class will share that static variable. Unlike other class member variables, individual copies of the static member variable are not made for each object of that particular class. No matter how many objects are created, there is only a single shared static member variable for that entire class. All static variables are generally initialized to 0 whenever the first object of that class is created. The main purpose of the static variable is to work as a shared variable for that entire class, and all the objects of that class access the shared static variable during the lifetime of the program. The lifetime of a static variable is the entire program.

The mere declaration of the static data member in a class does not allocate any memory for that variable; it is only a declaration of a shared member variable in the class. The static variable needs to be initialized outside the class declaration using the scope resolution operator. This statement basically allocates the space for the static variable in the computer memory. Let us assume a situation where a class keeps track of a special counter which has the count of all active objects for that class during the program runtime. Any object of that class willing to know the count of active objects in the computer memory for that class can access the counter for the information. This counter thus will be per class and not per object. This member variable will be of type Static, as illustrated in the following code snippet:

```cpp
#include <iostream>
using namespace std;

class example {
    static int counter;
    int memberData;
public:
    example() {
        counter++;
    }
    example (int var) {
        counter++;
        memberData = var;
    }
    ~example() {
        counter--;
    }
    void show() {
        cout<<"Static = "<<counter<<" Non Static = "<<memberData<<endl;
    }
};
int example::counter = 0;

int main () {
    example obj1 (10);
    obj1.show ();

    example obj2 (20);
    obj2.show ();

    example obj3 (30);
    obj3.show ();

    return 0;
}
```

Output:

```text
Static = 1 Non Static = 10
Static = 2 Non Static = 20
Static = 3 Non Static = 30
```

In the preceding program, we can very clearly see the behavior of the two different types of member variables. Here, the static variable is incremented in the class’s constructor, and it is decremented in the class’s destructor. On the other hand, “memberData” is a private variable on per object basis, which has different values set for different objects of the class example.

Similar to static member data, a class’s method can also be static. But the following restrictions are placed on a static method defined by a class:

- 1. It should only access static data
- 2. Static functions does not have a “this” pointer
- 3. Static functions does not support function overloading with any non-static function

Therefore, for static functions, it is also accessed globally, i.e., generally, the class name is used to access the static method by the scope resolution operator within the class. It is not accessed directly by the class’s object.
Let us illustrate this concept with the help of the following example:

```cpp
#include <iostream>
using namespace std;

class example {
    static int counter;
    int memberData;
public:
    example () {
        counter++;
    }
    example (int var) {
        counter++;
        memberData = var;
    }
    ~example () {
        counter--;
    }
    static void show () {
        cout<<"Static = "<<counter <<endl;
    }
};

int example::counter = 0;

int main () {
    example obj1 (10);
    example::show ();

    example obj2 (20);
    example::show();

    example obj3 (30);
    example::show();

    return 0;
}
```

Output:

```text
Static = 1
Static = 2
Static = 3
```

The preceding program clearly shows how a static method is used for a typical C++ class-object-based program.

## Friend Class and Friend Function

The basic concept of any object-oriented programming language revolves around the concept of encapsulation and data hiding. According to this basic concept, any object, unless it is its own object, cannot access the private members of a class. But there are situation where we violate this rule to gain some advantages in certain scenarios. C++ provides such an instrument – friend function – that basically works as a bridge between the objects of two different types of classes. Let us illustrate the concept of friend functions with the help of the following example:

```cpp
#include <iostream>
using namespace std;

class exampleTwo;

class exampleOne {
    int memberData;
public:
    exampleOne () {
        memberData = 0;
    }
    exampleOne (int var) {
        memberData = var;
    }
    ~exampleOne () {
        memberData = 0;
    }
    friend void show (exampleOne, exampleTwo );
};

class exampleTwo {
    int memberData;
public:
    exampleTwo () {
        memberData = 0;
    }
    exampleTwo (int var) {
        memberData = var;
    }
    ~exampleTwo () {
        memberData = 0;
    }
    friend void show ( exampleOne , exampleTwo );
};

void show (exampleOne obj1, exampleTwo obj2) {
    cout<<"ExampleOne = "<<obj1.memberData<<endl;
    cout<<"ExampleTwo = "<<obj2.memberData<<endl;
}

int main () {
    exampleOne obj1 (10);
    exampleTwo obj2 (55);

    show (obj1, obj2);

    return 0;
}
```

Output:

```text
ExampleOne = 10
ExampleTwo = 55
```

We have seen in the preceding program the usage of a friend function. Here, we have defined two different classes, namely, exampleOne and exampleTwo, with both having a single data member named “memberData.” In both the functions, we have declared the method show() as a friend function. The friend function is not a part of any of these classes, and since it is defined within the scope for both the classes, the friend function can access the content of these classes, irrespective of where its declaration is made, i.e., in the private or public space of the class definition. Although the preceding example is simple enough, these types of functions are mainly useful while performing operator overloading for both unary and binary operators.

Now that we have understood what friend function is, let us proceed to understand friend class. Friend classes, instead of making a method friend, declare the entire class as a friend. A sample program to demonstrate a friend class is as follows:

```cpp
#include <iostream>
using namespace std;

class exampleOne {
    int memberData;
public:
    exampleOne () {
        memberData = 0;
    }
    exampleOne (int var) {
        memberData = var;
    }
    ~exampleOne () {
        memberData = 0;
    }
    friend class exampleTwo;
};

class exampleTwo {
public:
    void show (exampleOne obj) {
        cout <<"From exampleTwo - "<<obj.memberData<<endl;
    }
};

int main () {
    exampleOne obj1 (10);
    exampleTwo obj2;

    obj2.show (obj1);

    return 0;
}
```

**Output:**

`From exampleTwo - 10`

It can be seen in the preceding code fragment how the friend class exampleTwo can have access to the class exampleOne’s private data members.

## Constant Members

Real-life scenarios can be there when an argument is passed to a function as a reference and the owner of that argument does not want to modify the variable within the function. In other words, we can use the const keyword to protect that argument from being modified within the function.
