## Anonymous Type

Anonymous type is a reference type, which directly inherits the Object class. It provides a way to directly encapsulate the read-only properties without declaring the data types for those properties. During the compilation, the compiler assigns the data type to those properties. The anonymous data types generally are declared using the var construct; therefore, we can use the new keyword to initialize the anonymous data types. Listing 17.5 shows a code snippet that uses an anonymous data type:

### Listing 17.5: Showing the Usage of Anonymous Type

```csharp
using System;
class Customer
{
    public static void Main()
    {
        var v = new { Id = 100, Name = "Mr. Scott" };
        Console.WriteLine("The ID and the name of customer is {0}, {1}", v.Id, v.Name);
    }
}
```

In the preceding code snippet, we have declared a var type variable v that encapsulates an integer type as well as a string type; however, these types are not mentioned during the initialization. During the execution, the variables, Id and Name will be treated as Integer and String, respectively.

## Declaration of Variables

A variable in C# is defined as a storage location. As C# is a type-safe language, every variable store values that are of same type as the type of the variable. In C#, the variable declaration follows the structure specified as follows:

```
<Data_Type> <Variable_Name>;
<Data_Type> <Variable_Name_1>, <Variable_Name_2>,...<Variable_Name_n>;
<Data_Type> <Variable_Name> = <Variable_Initializer>;
```

### Table 17.2: Operator Precedence

| Category | Operators | Associativity |
|---|---|---|
| Primary | (x), x.y, f(x), x++, x--, new, typeof, sizeof, checked, unchecked | Left associative |
| Unary | +(unary), -(unary), ~, ++x, --x, (T)x | Left associative |
| Multiplicative | *, /, % | Left associative |
| Additive | +, - | Left associative |
| Shift | <<, >> | Left associative |
| Relational and type testing | >, <, >=, <=, is, as | Left associative |
| Equality | ==, != | Left associative |
| Logical AND | & | Left associative |
| Logical XOR | ^ | Left associative |
| Logical OR | \| | Left associative |
| Conditional AND | && | Left associative |
| Conditional OR | \|\| | Left associative |
| Conditional | ?: | Right associative |
| Assignment | = *= /= %= += -= <<= >>= &= ^= \|= | Right associative |

In Table 17.2, the operators in the top rows have the higher precedence over the operators in the lower rows. Moreover, the operators on the left side on each row have the higher order of precedence over the operators in the right side of each row.

Associativity in C# can be of two types; left and right. Operators with left associativity are evaluated from left to right and operators with right associativity are evaluated from right to left. As an example of left associativity, we can consider the plus operation where the left expression is evaluated first and then the expression at the right is evaluated. On the other hand, assignment operator is right associative, as the expression to its right is evaluated before the assignment operation is invoked. The operator precedence and their associativity ensures certainty and integrity of the evaluation. Listing 17.7 shows an example of the operator precedence:

### Listing 17.7: Showing an Example to Illustrate Operator Precedence

```csharp
using System;
class Program
{
    public static void Main()
    {
        int firstNumber = 50;
        int secondNumber = 30;
        int thirdNumber = 10;
        Console.WriteLine("Calculating firstNumber * secondNumber / thirdNumber");
        Console.WriteLine(firstNumber * secondNumber / thirdNumber);
        Console.WriteLine("Calculating firstNumber / secondNumber * thirdNumber");
        Console.WriteLine(firstNumber / secondNumber * thirdNumber);
        Console.WriteLine("Calculating (firstNumber / secondNumber) * thirdNumber");
        Console.WriteLine((firstNumber / secondNumber) * thirdNumber);
    }
}
```

As the multiplicative operators are left associative, the multiplication operation is executed first and then the division operation is executed. Therefore, if we consider the expression `firstNumber * secondNumber / thirdNumber`, first the multiplication between the `firstNumber` and the `secondNumber` takes place whose result is 1500 and then this result is divided by the `thirdNumber` that gives the final outcome as 150. Similarly, for the expression `firstNumber / secondNumber * thirdNumber`, first the multiplication between the secondNumber and the thirdNumber takes place and then the result is divided by the firstNumber. In case we want to tell the compiler exactly which operation we want to execute at first, we can use the brackets to notify the order of calculation. For the expression `(firstNumber / secondNumber) * thirdNumber`, the multiplication operation follows the division operation. In this case, we are informing the compiler to execute the division operation first by placing the brackets around the division expression and thereby, it gets the highest precedence over all the other operators in the expression. Therefore, it is the best practice to simplify the calculations by placing the brackets around the expressions which we want to execute first.

The output of the preceding program is given as follows:

```text
Calculating firstNumber * secondNumber / thirdNumber
150
Calculating firstNumber / secondNumber * thirdNumber
10
Calculating (firstNumber / secondNumber) * thirdNumber
10
```

## Type Casting

Before going to learn about C# type casting, let’s first discuss the type safety. While working with script languages, we can assign any type to any other type; for example, the value of a floating point variable to an integer variable. However, the main drawback of such an assignment is that the precision the floating point variable contains will lose when we assign it to an integer variable. These types of languages are known as loosely-typed languages or un-typed languages. However, as C# is a strongly typed language, these sorts of operations are not allowed and the C# compiler will throw an error. Therefore, to solve this problem, we need to cast the data type to the floating point explicitly to convert its cast.

In C#, two types of castings are allowed, which are given as follows:

- Implicit casting
- Explicit casting

Implicit type casting allows us to cast the required type without losing the data that the variable holds. For example, when we assign a floating point number to a variable of type Double, the assignment will not cause any loss of data. Listing 17.8 shows an example of implicit type casting:

### Listing 17.8: Showing an Example of Implicit Type Casting

```csharp
using System;
class Program
{
    public static void Main()
    {
        float f = 100.125f;
        Console.WriteLine("Declaring one floating type variable {0}", f);
        //Implicit assignment
        double d = f;
        Console.WriteLine("After implicit type casting, printing the double variable: ");
        Console.WriteLine(d);
    }
}
```
