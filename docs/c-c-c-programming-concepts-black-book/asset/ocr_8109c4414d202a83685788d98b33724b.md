```
       array_ptr[ct],*array_ptr[ct]);
}

}
~~~
```

In Listing 4.13, the `array_ptr` variable is declared as an array of pointers, where each cell of the array will hold a pointer to an integer. We have also declared three integers and stored their memory addresses into the array of pointers. Note that when we display the content of the array, we get the addresses of the variables. We can display the content of the memory locations by using the dereferencing operator.


After learning about array of pointers, you must be wondering whether there is any difference between an array of pointers and a pointer to an array. For this, let's consider the following two notations:

```
~~~c
int *array_ptr[5];

int (*array_ptr)[5];
~~~
```

The first notation declares an array of integer pointers of size five. In this case, memory allocation is done during the time of declaration itself. However, the second notation declares a pointer to an array of five integers without allocating any memory. As the parenthesis has higher precedence; therefore, in the second declaration, first `array_ptr` is declared as a pointer and then it is linked to an array of five integers. Similarly, the following notation declares a pointer to an array but the allocation is static:

```
~~~c
int array_ptr[10];
~~~
```

Listing 4.14 shows the use of pointer to an array:

# **Listing 4.14: Showing the Usage of Pointer to an Array**

```
~~~c
# include<stdio.h>

int main()
{
    int *array_a[2];
    int (*array_b)[2];
    int array_c[2] = {1,2};
    int var_a = 10;
    int var_b = 20;

    array_a[0] = &var_a;
    array_a[1] = &var_b;
    array_b = &(array_c);
    printf("\n Size of a [%d] ",sizeof(array_a));
    printf("\n Size of b [%d] ",sizeof(array_b));
    printf("\n Size of b [%d] ",sizeof(array_c));
    printf("\n Value at array_a is %d ",*(array_a[0]));
    printf("\n Value at array_a is %d ",*(array_a[1]));
    printf("\n Address of array_b [%p] ",array_b);
    printf("\n Address of array_c [%p] ",&array_c);
    printf("\n Value at array_b is %d ",*(array_b[0]));
}
~~~
```

In Listing 4.14, we have assigned the address of `array_c` to `array_b`, which happens to be a pointer to an array of integers. In addition, we have accessed the elements of `array_c` with the help of `array_b`.
