## The Implicit Int Rule in C

Earlier versions of C included an implicit int feature, which stated that in the absence of a type specifier for a function, the default type would be assumed as int. This rule was included in C89 standard but later it was removed when C99 standard was introduced. According to this rule, if a function is declared without a prototype, then the compiler automatically assumes the return type of the function to be an int. Any deviation from this assumption causes a compilation error.

Listing 2.17 shows how implicit int rule works in C:

**Listing 2.17: Implicit int Rule in C**

```c

{
    myFunc(10,30,90);
    getch();
    return 0;
}

int myFunc(int x, int y, int z)
{
    printf("\n x [%d] Y [%d] Z[%d]", x,y,z);
    return x;
}
```

The output of Listing 2.17 is given as follows:

```text
x [10] Y [30] Z[90]
```

The output of the function validates the presence of the implicit int rule. In this program, the function is missing its prototype definition; however, the function definition has a return type of int that matches with the implicit int rule for functions; hence, the function compiles successfully.

## Recursion in C

In C, functions are allowed to call themselves. A function is said to be recursive, if the function calls itself from its body. Recursion is defined to be the process of defining something in terms of itself. We are going to discuss recursive functions over here. Let's take up an example of computing factorial of a number.

Factorial of a number is defined as the product of all the numbers starting from 1 to itself. For example, the factorial of 5 can be expressed as:

```text
5! = 5x4x3x2x1
   = 5 x 4!
   = 5 x 4 x 3!
   = 5 x 4 x 3 x 2!
   = 5 x 4 x 3 x 2 x 1!
```

Factorial of 1 is 1, so our recursion ends here. We start backtracking from 1 and calculate the result for 5. This is the technique behind recursion where we define something in terms of itself. A recursive algorithm needs two major steps to be defined depending on which recursion can take place. These steps are as follows:

- Specify the value of the expression at a defined point
- Give a rule for finding the value of the expression from smaller integers

If we correlate the problem of calculating factorial with the steps defined above, then step 1 conforms with our assumption that factorial of 1 is 1. The recursion can be defined as:

```text
n! = n x (n - 1)!
```

## Storage Class Specification in C

In order to define a variable in C, we need to mention its storage class. The storage class specifier of a variable tells the compiler how to store that variable. It determines the part of the memory storage that is allocated for the object and how long the allocation would exist. Storage class specifier defines the scope of a variable. Scope means the portion of the code over which the variable will be recognized. If the storage class is not mentioned explicitly, then the compiler assumes a default storage class for the variable depending on the context in which the variable is used. Generally, a variable can be either stored in memory (RAM) or CPU registers. It depends on the storage class specifications of the variable to determine which storage area would be selected for it. A storage class also helps us to determine the default value that could be assigned to a variable as well.

C defines the following four types of storage class specifications:

- Auto
- Register
- Extern
- Static

Let's now discuss all these types in detail.

### Auto Storage Class

Variables that are defined within a function or within a block of code are said to have automatic storage class specifications. These variables are local to that function and the scope of the variable is also confined within them. Some basic features of an auto variable are as follows:

- **Storage** – Refers to the primary memory of a computer.
- **Initialization** – Refers to the value with which the variable is initialized. In this case, it is mostly with an unpredictable value, also known as garbage.
- **Scope** – Refers to the portion of the code from where the variable can be accessed. In this case, it is within the block or function inside which it is declared.
- **Life** – Refers to the time till the variable retains its value. In this case, it is till the control remains within that block.

The scope of auto variables is confined to the function or block within which they are declared. It is possible for two auto variables to have same names, if they are declared inside two different blocks. Variables declared within a function have an auto storage class specification by default. We need to specify a storage class explicitly, if we want to associate that with the variable. A variable declared within a function becomes an auto variable by default, so it is not mandatory to precede a local variable declaration with the auto keyword.
