**Table 12.3: Operator Precedence and Associativity in C++**

| Operator | Meaning | Associativity | Use |
| :--- | :--- | :--- | :--- |
| != | Not equal to | | Expr1 != Expr2 |
| & | Bitwise AND | Left to right | expr1 & expr2 |
| ^ | Bitwise XOR | Left to right | expr1 ^ expr2 |
| \| | Bitwise OR | Left to right | expr1 \| expr2 |
| && | Logical AND | Left to right | expr1 && expr2 |
| \|\| | Logical OR | Left to right | expr1 \|\| expr2 |
| ?: | Conditional operator | Left to right | expr1 ? expr2 : expr3 |
| = | Assignment | Right to left | expr1 = expr2 |
| *= | Multiply and update | | expr1 *= expr2 |
| /= | Divide and update | | expr1 /= expr2 |
| %= | Modulus and update | | expr1 %= expr2 |
| += | Add and update | | expr1 += expr2 |
| -= | Subtract and update | | expr1 -= expr2 |
| <<= | Left shift and update | | expr1 <<= expr2 |
| >>= | Right shift and update | | expr1 >>= expr2 |
| &= | Bitwise AND update | | expr1 &= expr2 |
| \|= | Bitwise OR update | | expr1 \|= expr2 |
| ^= | Bitwise XOR and update | | expr1 ^= expr2 |
| Throw | Throw exception | Right to left | throw expr |
| , | Comma | Right to left | expr1, expr2 |

Operators listed first in Table 12.3 have higher precedence over those that are listed next. Moreover, operators at the same level of precedence will be evaluated from either left to right or right to left based on their associativity.
