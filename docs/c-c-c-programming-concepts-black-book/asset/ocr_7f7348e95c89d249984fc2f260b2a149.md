# # Flow Control Statements

Flow control statements are used to control the sequential flow of the program by providing the statements that perform branching and iteration. We can mainly divide flow control statements in the three divisions, which are given as follows:

+   - Conditional statements which include *if-else* and *switch*
+   - Loop statements which include *while*, *do-while*, *for*, and *foreach* loops
+   - Jump statements which include *continue-break* and *goto*

Let's first discuss the *if-else* conditional statement.

# ## The *if-else* Statement

The *if-else* statement is generally used when the program needs to decide whether the execution of an operation will take place depending on the values of certain operations or variables. The structure of *if-else* statement is shown in Listing 17.33.

**Listing 17.33: Showing the Structure of *if-else* Statement**

else

   Execute a different operation;
}
