C++ is compatible with two Input/Output (I/O) systems – the one inherited from C and the other one defined by C++ itself, which is called I/O streams. Although the I/O system inherited from C is extremely rich, flexible, and powerful, the question arises that why do we need another I/O system in C++. The answer to this question is that C's I/O system does not know anything about objects. Therefore, to provide complete support for object-oriented programming in C++, it was necessary to create an I/O stream that could operate on user-defined objects as well. Apart from this, there are several benefits of using C++'s I/O stream even in programs that do not make extensive (or any) use of user-defined objects.

Exception handling allows us to handle runtime errors in a systematic manner. With the help of exception handling, a program can invoke an error-handling routine when an error occurs without any human intervention. The primary advantage of exception handling is that it automates much of the error-handling code that previously had to be coded "by hand" in any particular program.

# I/O Streams

Generally, an I/O stream is a source or destination for a collection of characters or a flow of data. Output streams allow us to store or write the characters that are read or fetched from the input streams. The main purpose of the I/O stream is to act as a tool for the input and output of texts. Usually, input and output are the transfer of data between a program and any kind of external device. The inner representation of the transferred data is supposed to be hassle-free for the processing of data in a program. On the other hand, the external representation can vary a lot; it might be described as either a display in individual readable form or a portable data swap format. The intent of representation, such as conserving storage space, can also affect the external representation.

Stream classes form a powerful set of classes that can be modified, extended, or expanded to include the support for user-defined data types or objects. The benefits of stream classes are given as follows:

+   - Encapsulates the internal working of classes from a programmer. As a result, the programmer need not specify the type of data that is to be as input or output; rather, the stream class automatically determines it.
+   - Offers a rich set of error handling facilities.
