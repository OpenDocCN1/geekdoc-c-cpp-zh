# # Block Statements

C belongs to a family of block structured programming languages. A block is nothing but a collection of statements grouped together. A block structured programming language permits the creation of blocks, nesting of blocks, and variable declaration within a block. If closely noticed, we can see that C prohibits declaration of a variable in middle of a block. It is mandatory in C that all the variable declarations are made at the beginning of a block. Nowadays many compilers allow variable declaration anywhere inside a block but it is not a part of the ANSI standard. A block statement always starts with and ends with a curly brace.

Listing 1.28 shows how block statements are written in C:

**Listing 1.28: Writing Block Statements in C**

```
```c
#include<stdio.h>
int main()
{
    int i;
    for(i=1;i<10;i++)
    {
        int i;
        i=20;
        printf("\n I %d ",i);
    }
    printf("\n Another I %d ",i);
    getch();
}
```
```

The output of Listing 1.28 is given as follows:

```
```
I 20
Another I 1
I 20
Another I 2
I 20
