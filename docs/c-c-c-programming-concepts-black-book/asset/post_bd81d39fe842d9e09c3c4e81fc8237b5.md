
As discussed, when we assign one structure variable to another, the compiler copies the entire content of a structure variable to another. This feature has been made possible because all the members of the structure are stored in the contiguous memory locations.

Output of the preceding program is as follows:

```text
Name of student Tanuman
Class of the student 12
Age of the student 16
```

Let's now learn about the use of pointers in structures.

## Exploring Structures and Pointers

The address of a structure can be accessed in the same manner as an address of a variable is accessed. This can be done by using the & operator. Consider the following example where we declare a pointer type variable to a structure:

```c
struct student
{
    char name[20];
    int class;
    int age;
};

struct student stu1, *stu2;
```

In the preceding example, we have declared a pointer to a structure type variable, which is represented as *stu2. We assign the starting address of a structure variable to another, as follows:

```c
stu2 = &stu1;
```

A structure pointer can access the individual structure members with the help of an arrow operator (->). Listing 5.6 shows how to access the members of a structure using structure pointers:

**Listing 5.6: Accessing the Members of a Structure using Structure Pointers**

```c
# include<stdio.h>

struct student
{
    char name[20];
    int class;
    int age;
};

struct student stu1 = {"Tanuman",12,16};

struct student *stu2;

int main()
{
    stu2 = &stu1;  /* Assigning address to structure pointer */

    printf("\n Name of student %s ", stu2->name);
    printf("\n Class of the student %d",stu2->class);
    printf("\n Age of the student %d ",stu2->age);

    getch();
    return 0;
}
```

```c
getch();
return 0;
}
```

In Listing 5.7, note that the parenthesis are required when we use a dot operator with structure pointers, as a dot operator has a higher precedence over the * operator. Without using the parenthesis, the compiler will generate an error, as a pointer is not directly compatible with the dot operator.

Output of the preceding program is as follows:

```text
Name of student Tanuman
Class of the student 12
Age of the student 16
```

We can also have pointers as the member variables of a structure. Consider the following structure:

```c
struct student
{
    char name[20];
    int *class;
    int *age;
};

struct student stu1,*stu2;
```

In the preceding structure, we have declared two integer pointers: *class and *age. In addition, we have declared a structure variable stu1 as well as a structure pointer *stu2. The member variables can be accessed as follows:

```c
*stu1.class;
*stu1.age;
```

Structure pointers can access the member variables as:

```c
*stu2->class;
*stu2->age;
```

Now, consider a structure as follows:

```c
struct student
{
    char name[20];
    int class;
    int age;
};

struct student *stu;
```

We can increment or decrement the values contained inside the members of the student structure using a structure pointer. The following code snippet shows how to increment the values:

```c
++stu->class;
++stu->age;
```

Both the expressions will cause the value contained inside the member variables to get incremented. If we write an expression, such as ++stu, then this will increment stu with 28 bytes. Listing 5.8 shows the placement of members in the memory:

Listing 5.8: Showing the Placement of Members in the Memory

```c
# include<stdio.h>

struct student
{
    char name[20];
    int class;
    int age;
};

struct student stu1 = {"Tanuman",12,16};

struct student *stu2;

int main()
{
    stu2 = &stu1;  /* assigning structure variable to another */

    printf("\n Name of student %s",stu2->name);
    printf("\n Class of the student %d",stu2->class);
    printf("\n Age of the student %d",stu2->age);
    printf("\n Content of STU [%d] ",stu2);
    stu2++;
    printf("\n Content of STU after incrementing [%d] ",stu2);
    getch();
    return 0;
}
```

In Listing 5.8, the size of the structure is 28 bytes. After incrementing the structure pointer by one, the pointer points to the next block of 28 bytes in the memory.

Output of the preceding program is as follows:

```text
Name of student Tanuman
Class of the student 12
Age of the student 16
Content of STU [4202496]
Content of STU after incrementing [4202524]
```

There are different ways of passing a structure to a function; let’s learn about them in detail.

## Passing Structures to Functions

One of the simplest approaches to pass a structure to a function is to pass the structure members individually to the function. Individual structure members can be passed to a function similar to normal variables and no added handling is required for them.

Another approach is to transfer an entire structure to a function as a whole. This is done by passing a structure type pointer as an argument to a function. The process is similar to passing an array to a function. The structure is passed by reference instead of passing by value. In this case, if a value of any member is altered within the function, then that change will be reflected outside the function as well. Listing 5.9 describes how a complete structure can be passed to a function:

**Listing 5.9:** Passing a Complete Structure to a Function

```c
# include<stdio.h>

struct student
{
        char name[20];
        int class;
        int age;
};

struct student stu1 = {"Tanuman",12,16};

void display(struct student *ptr);

int main()
{
    display(&stu1);   /* Passing Address of structure to a function */
    getch();
    return 0;
}
void display(struct student *ptr)
{
    printf("\n Name of student %s ",ptr->name);
    printf("\n Class of the student %d",ptr->class);
    printf("\n Age of the student %d ",ptr->age);
}
```

In Listing 5.9, the address of the structure type variable is passed to the function by using the following expression:

```c
display(&stu1);
```

Within the display() function, the address of the structure type variable is received inside a structure pointer ptr. The structure pointer is then used to display the members of the structure.

Output of the preceding program is as follows:

```text
Name of student Tanuman
Class of the student 12
Age of the student 16
```

Members of the structure can also be modified inside a function. This is achieved by passing the starting address of the variable of a structure to the function. Inside the function, we can use a pointer to the structure to handle the value that is passed. Any operation that takes place with the help of a structure pointer will reflect outside the function as well because the structure pointer accesses the same memory location. Listing 5.10 shows how the structure members can be altered inside a function.

**Listing 5.10: Altering the Structure Members inside a Function**

```c
# include<stdio.h>
struct student
{
    char name[20];
    int class;
    int age;
};
struct student stu1 = {"Tanuman",12,16};
void modify(struct student *ptr);
int main()
{
    printf("\n Age of the student before passing to the function is %d ",stu1.age);
    modify(&stu1);  /* Passing Address of structure to a function */
    printf("\n Age of the student after passing to the function is %d ",stu1.age);
    getch();
    return 0;
}
void modify(struct student *ptr)
{
    ptr->age = 20;
}
```

In Listing 5.10, notice that the age member of the structure was modified inside the modify() function. As we are passing the reference of the variable stu1 to the modify() function, the same change will be reflected outside the function as well.

Output of the preceding program is as follows:

```text
Age of the student before passing to the function is 16
Age of the student after passing to the function is 20
```

Next, let's learn how to return a structure from a function.

### Returning a Structure from Function

In the previous section, we have learned how to pass structure members to a function. In the similar manner, we can make functions return the structure type variables as well. Listing 5.11 shows how to return a structure from a function:

Listing 5.11: Returning a Structure from a Function

```c
# include<stdio.h>

struct student
{
    char name[20];
    int class;
    int age;
};

struct student stu1 = {"Tanuman",12,16};
struct student* returnStruct();
int main()
{
    struct student *ptr;

    ptr = returnStruct();
    printf("\n Name %s Class %d Age %d ",ptr->name,ptr->class,ptr->age);
    getch();
    return 0;
}
struct student* returnStruct()
{
    return(&stu1);
}
```

In Listing 5.11, we have returned the address of a structure type variable from the returnStruct() function. In the main() function, the address is stored inside the structure pointer, which is used to display the members of the structure.

Output of the preceding program is as follows:

```text
Name Tanuman Class 12 Age 16
```
