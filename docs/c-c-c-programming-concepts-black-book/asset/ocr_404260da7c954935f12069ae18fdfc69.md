# Listing 1.15: Usage of the OR Operator

```
```c
#include<stdio.h>

int main()
{
    int sex,exp;

    printf("\n Enter type of candidate (1 for MALE 2 for FEMALE) ");
    scanf("%d",&sex);
    printf("\n Enter Years of Experience ");
    scanf("%d",&exp);

    if(((sex == 1) && (exp >= 3)) || ((sex == 2) && (exp >=2)))
        printf("\n Candidate Accepted");
    else
        printf("\n Candidate Rejected");
    getch();
}
```
```

The output of Listing 1.15 is given as follows:

```
```text
    Enter type of candidate (1 for MALE 2 for FEMALE) 1

    Enter Years of Experience 4

    Candidate Accepted
```
```

In Listing 1.15, the OR operator helps to execute the set of statements if any one of the expression becomes true. The code also shows that we can use multiple logical operators together as well. The NOT operator has a different interpretation of its own. As the name suggests, the NOT operator signifies negation of an expression. Consider the following code snippet:

```
```c
if(!expression)
```
```

In this case, if the expression returns false, then the NOT operator reverses the result and turns it to true, so the statements inside the if block get executed.

Listing 1.16 shows the implementation of the Not operator in C.

# Listing 1.16: Implementation of the Not Operator in C

```
```c
#include<stdio.h>

int main()
{
    int variable=0;
    if(!variable)
        printf("\n variable is zero");
    else
        printf("\n variable is non-zero");

    getch();
}
```
```

The code snippet mentioned in Listing 1.16 will execute the statements inside the if block, the NOT operator is another way of writing the conditional statement mentioned below

```
```c
if(variable == 0)
```
```

instead we write

```
```c
if(!variable)
```
```
