
```csharp
Console.WriteLine("Name of the employees after changing the values...");
```

## Value Type

Unlike reference type, value type holds the value of the objects. Whenever a value type is assigned to another value type, its value is copied but not the reference. Structures and enumerators are some of the examples of value type. Listing 17.32 shows the value type operation with the help of a structure type.

**Listing 17.32: Showing the Usage of Structure Value Type**

```csharp
using System;
struct Employee
{
    private int id;
    public int ID
    {
        get { return id; }
        set { id = value; }
    }
}
class Program
{
    static void Main()
    {
        Employee e1 = new Employee();
        e1.ID = 71;
        Employee e2 = new Employee();
        e2.ID = 59;
        Console.WriteLine("Name of the employees before assignment...");
        Console.WriteLine("Employee ID = " + e1.ID);
        Console.WriteLine("Employee ID = " + e2.ID);
        // assign e2 value to e1 variable
        e1 = e2;
        Console.WriteLine();
        Console.WriteLine("Name of the employees after assignment...");
        Console.WriteLine("Employee ID = " + e1.ID);
        Console.WriteLine("Employee ID = " + e2.ID);
        e2.ID = 65;
        Console.WriteLine();
        Console.WriteLine("Values After Changing One Instance:");
        Console.WriteLine("Employee ID = " + e1.ID);
        Console.WriteLine("Employee ID = " + e2.ID);
    }
}
```

In the preceding program, we have first defined a structure named Employee that holds the employee ID only. Then, we have created two objects, e1 and e2, of the Employee structure and assigned the values to the ID variable of each object. When we print these values, they will show their exact values. After that, we have assigned e2 to e1. In this case, the value of e2 is copied to the value of e1. Therefore, e1 and e2 both print the value of e2. Next, we have again modified the value of ID for e2. Now, the ID value of e1 is printed and the value of e2 is modified. This implies that the value of e1 does not modify on changing the value of e2, which demonstrates that value type holds the distinct copies of their objects.

The output of the program is given as follows:

```text
Name of the employees before assignment...
Employee ID = 71
Employee ID = 59
Name of the employees after assignment...
Employee ID = 59
Employee ID = 59
Values After Changing One Instance:
Employee ID = 59
Employee ID = 65
```

## Flow Control Statements

Flow control statements are used to control the sequential flow of the program by providing the statements that perform branching and iteration. We can mainly divide flow control statements in the three divisions, which are given as follows:

- Conditional statements which include *if-else* and *switch*
- Loop statements which include *while*, *do-while*, *for*, and *foreach* loops
- Jump statements which include *continue-break* and *goto*

Let's first discuss the *if-else* conditional statement.

### The *if-else* Statement

The *if-else* statement is generally used when the program needs to decide whether the execution of an operation will take place depending on the values of certain operations or variables. The structure of *if-else* statement is shown in Listing 17.33.

**Listing 17.33: Showing the Structure of *if-else* Statement**

```csharp
if(Condition)
{
   Execute the Operation;
}
else
{
   Execute a different operation;
}
```

According to the structure of the *if-else* statement, the code written inside the *if* block executes if the condition written against the *if* statement satisfies; otherwise, the code block written inside the *else* statement is executed. Listing 17.34 shows the implementation of *if-else* statement:

**Listing 17.34: Showing the Usage of *if-else* Statement**

```csharp
using System;
class Program
{
    public static void Main()
    {
        Example e = new Example(20,10);
        e.DoComparison();
    }
}
class Example
{
    public int high;
    public int low;
    public Example(int h, int l)
    {
        this.high = h;
        this.low = l;
    }

    public void DoComparison()
    {
        if (high > low)
        {
            Console.WriteLine("{0} is higher than {1}", high, low);
        }
        else if (high == low)
        {
            Console.WriteLine("Two values are equal");
        }
        else
        {
            Console.WriteLine("{0} is lower than {1}", high, low);
        }
    }
}
```

In the preceding program, we have declared the `DoComparison()` method in the Example class that contains a nested *if/else* statement, which compares whether the two values are same. In addition, the `Program` class instantiates an object of the Example class and calls the `DoComparison()` method. The output of the code is given as follows:

```text
20 is higher than 10
```

Next, let's learn about the *switch* statement.

### The switch Statement

The *switch* statement is used to select a particular statement by passing the enumeration to the *case* statement written inside it. The control of the program is at the *case* statement which decides the selection procedure. The structure of the *switch* statement is shown in Listing 17.35:

**Listing 17.35:** Showing the Structure of *switch* Statement

```csharp
int caseSwitch = 1;
switch (caseSwitch)
{
    case 0:
        Console.WriteLine("The case number is 0");
        break;
    case 1:
        Console.WriteLine("The case number is 1");
        break;
    default:
        Console.WriteLine("This is the default case");
        break;
}
```

According to the structure of *switch* statement, if a *case* statement is selected, then after executing the related case block, the control is transferred out of the *switch* statement using the *break* statement (discussed later in this chapter). Moreover, every *switch* statement should have a *default* case which will be executed if the code encounters any *default* statement. Therefore, the points that should be considered while writing a *switch* statement are given as follows:

- The value of the *case* statement is unique. No two *case* statements can have the same case value.
- The *break* statement should be put after the execution of each *case* statement. This helps the control to come out of the loop once the selected case execution has completed.
- It is a good practice to use a *default* statement inside the *switch* statement code body.
