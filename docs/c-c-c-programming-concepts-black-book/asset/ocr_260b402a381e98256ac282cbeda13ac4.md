The XML nodes include the start tag, the end tag, whitespaces, comments, and the XML declaration tag. Depending on the node type, which can be an Element, Text, End Element, or Xml Declaration, the XmlTextReader class navigates through all the nodes to get the value of the required node type.

To declare an object of the XmlTextReader class, we need to create an instance of the FileStream class by specifying the file name along with its path and providing the FileMode and FileAccess specifications. The code snippet for declaring an instance of XmlTextReader is given as follows:

```
FileStream fileStream = new FileStream(path, FileMode.Open, FileAccess.Read);\n\nXmlTextReader xmlTextReader = new XmlTextReader(fileStream);
```
