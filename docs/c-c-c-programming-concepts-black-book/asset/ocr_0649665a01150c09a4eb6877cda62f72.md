In Listing 2.6, you can see that while calling the function, an assignment statement is used where the function call has been put at the right hand side of the assignment statement. It states that the value returned by the function will be stored in the variable that is at the left hand side of the assignment. One important point that needs to be followed while performing such assignments is that the data type of the variable used for the assignment must be similar to the return type of the function.

There are two ways in which arguments can be passed to a function—call by value and call by reference. Let’s now discuss both these ways in detail.
