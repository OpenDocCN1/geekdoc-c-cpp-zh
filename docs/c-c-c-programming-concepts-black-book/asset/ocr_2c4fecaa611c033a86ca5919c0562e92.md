The #ifdef and #else directives work in the same way as the if and else conditional statements, but these directives are specifically used in the macros. Listing 7.10 shows the use of #ifdef and #else directives:

# Listing 7.10: Using the #ifdef and #else Directives

```
```c
#include<stdio.h>
#define __DEBUG__
int main()
{
    #ifdef __DEBUG__
        printf("\n Disabling flag");
        #undef __DEBUG__
    #else
        printf("\n Enabling flag");
        #define __DEBUG__
    #endif

    #ifndef __DEBUG__
        printf("\n Enabling the flag once again");
        #define __DEBUG__
    #else
        printf("\n Disabling the flag once again");
        #undef __DEBUG__
    #endif

    getch();
    return 0;
}
