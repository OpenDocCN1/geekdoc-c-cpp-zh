# ## LINQ to Entities

LINQ to Entities uses the Entity Data Model (EDM) to query the data in a relational database. EDM converts a query into a command tree query, executes the query, and returns the objects that can be used by both EDM and LINQ. Moreover, instead of using the data layer, LINQ to Entities uses Object Service Layer to establish the connection between a .NET application and a relational database.
