# # Looping in C

Till now, we have discussed sequential and decision making statements, such as if and else constructs. These sets of instructions are always executed exactly once. However, while dealing with a programming language, one must always keep in mind that there are situations where we need to perform a said action, repetitively. Decision making statements do not provide us with the flexibility of performing those tasks. We can handle this scenario through loops. One of the major aspects of looping in C is the ability of performing some parts of instructions repetitively while keeping the other executions constant.

A loop generally has four parts:

+   - Initialization
+   - Test condition
+   - Increment
+   - Body

It is not mandatory that all the steps mentioned must be performed in the same order.
