```

foreach (int nums in query)
{
    Console.WriteLine(nums);
```

In Listing 19.7, instead of a LINQ query, we have used a delegate that accepts a lambda expression. By using the foreach loop, the lambda query gives all the odd numbers from a list of given numbers. The output of the preceding code is same as that of Listing 19.6.

Next, let's understand the two execution methods of a LINQ query.

# ## Deferred and Immediate Executions

While writing a LINQ query, we first store the actual query in a query variable, which is of type `IEnumerable<T>` or `IQueryable<T>`. This query variable stores only the command of the query but not the result of the query. The result of the query will be retrieved only when the query will be iterated by using the foreach loop. Therefore, we can postpone or defer the execution of the query as long as we want. This type of query execution is referred to as deferred execution.

In Listing 19.7, the anonymous type variable, query, holds the actual command of the query. As the query retrieves the integer values, the integer variable num in the foreach loop holds the resultant data in each step of the iterated query execution. The code snippet responsible for the deferred execution is shown in Listing 19.8:

**Listing 19.8: Showing the Code Snippet for Deferred Execution**

```
~~~csharp
foreach (int nums in query)
{
    Console.WriteLine(nums);
}
~~~
```

Now, consider a case where we immediately require the result of the query. For this, LINQ provides some methods, which can be used to force the immediate execution of the query. When an aggregation operation method, such as count, min, or max, needs to be executed in the LINQ query, it forces an immediate execution of the foreach loop. For this, we do not need to write the foreach loop explicitly. The aggregation operation methods iterate over the result of the query and get the value. Listing 19.9 shows an example of the immediate execution:

**Listing 19.9: Showing an Example of Immediate Execution**

```
~~~csharp
using System;
using System.Linq;

class Program
{
    public static void Main()
    {
        //Initializing data source
        int[] list = { 1, 2, 3, 4, 5, 6, 7, 8, 9 };

        var query = list.Where(n => n % 2 != 0);

        int max = query.Max();
        Console.WriteLine("The maximum odd number is {0}", max);
    }
}
~~~
```
