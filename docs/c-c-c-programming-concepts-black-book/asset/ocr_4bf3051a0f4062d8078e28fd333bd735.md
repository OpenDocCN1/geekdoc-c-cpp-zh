Table 21.4 lists the important methods of the Directory class:

**Table 21.4: Noteworthy Methods of the Directory Class**

| Method | Description |
| --- | --- |
| CreateDirectory(string path) | Creates a directory at user-specified location with the defined windows security.<br>It returns an object of the *DirectoryInfo* class. It only takes a user-defined path as an argument.<br>**Overloads:**<br>• CreateDirectory(string path, System.Security.AccessControl.DirectorySecurity directorySecurity) → Creates a directory in the specified location with the defined windows security attributes mentioned in the DirectorySecurity object. |
| Delete(string path) | Deletes a directory from a specified location and if specified, it also deletes the sub-directories that come under this directory.<br>It only takes a user-defined path as an argument.<br>**Overloads:**<br>• Delete(string path, bool IsRecursive) → Deletes all the sub-directories that fall inside the directory if IsRecursive is set to true. |
| Exists() | Checks for a directory in a user-specified path. If exists, then it returns true; otherwise, it returns false.<br>It only takes a user-defined path as an argument. |
| GetCurrentDirectory() | Returns a list of strings that contains the currently working directory list. |
| GetDirectories (string path) | Returns a list of strings that contains a list of directories present in the specified path.<br>It only takes a user-defined path as an argument.<br>**Overloads:**<br>• GetDirectories (string path, string searchPattern) → Returns a list of directories with a specific searchPattern (such as Root or Personal) from the specified location.<br>• GetDirectories (string path, string searchPattern, SearchOptions searchOptions) → Returns all the directories in the current directory as well as in its sub-directories if searchOptions is set to the AllDirectory option. For the TopDirectoryOnly option, it returns a list of files from the directory path mentioned in the path variable. |
| GetFiles(string path) | Returns a list of files present in the specified path.<br>It only takes a user-defined path as an argument.<br>**Overloads:**<br>• GetFiles (string path, string searchPattern) → Returns a list of files with a specific searchPattern (such as .doc or .txt) from the specified location.<br>• GetFiles (string path, string searchPattern, SearchOptions searchOptions) → Returns all the files in the current directory as well as in its sub-directories if searchOptions is set to the AllDirectory option. For the TopDirectoryOnly option, it returns a list of files from the directory path mentioned in the path variable. |
