```
Note that the pthread_cancel() API should be used only in unusual circumstances; for example, when a thread might leave some incomplete tasks affecting the result of a program. In this case, better approach is to communicate to the thread that it should end and then wait for the thread to exit on its own.

# Cleanup Handlers

A cleanup handler is a function that is called automatically when a thread is cancelled. This is typically used for freeing up the resources and locks that might be held by a thread. When a thread is cancelled, the cleanup handlers, which were registered at the beginning of the program, are called in the reverse order from the stack. By registering a cleanup handler, we mean pushing it in the stack; whereas, by de-registering a cleanup handler, we mean removing it from the stack.

We can register a cleanup handler, as follows:

```
```c
void pthread_cleanup_push (void (*routine) (void *), void *arg);
```
```

When a thread is cancelled, routine is called with arg as its argument.

We can de-register a cleanup handler, as follows:

```
```c
void    pthread_cleanup_pop (int execute);
```
```

If the execute argument is non-zero, then the cleanup handler at the top of the stack is executed once. The preceding two APIs can also be used as macro with matching braces. They should be used in pair within the same function and at the same lexical nesting level.
```
