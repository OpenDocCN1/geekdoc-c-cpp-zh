To build a lambda expression of type `Expression<DelegateT>`, the following instructions must be followed:

- If we convert a lambda expression to the type `Expression<DelegateT>`, then there should exist a conversion technique that converts a lambda expression back to the type `DelegateT`.
- If a lambda expression contains a block of code, then it cannot be converted to an expression tree.

Let's write a program to convert a lambda expression to an expression tree. Listing 19.19 shows a program where we follow the steps to evaluate an expression tree:

**Listing 19.19:** Converting a Lambda Expression to an Expression Tree

```csharp
using System;
using System.Linq;
using System.Linq.Expressions;

class Program
{
    public static void Main()
    {
        //Defining a lambda expression that is assigned to a delegate
        //of type Func<int, bool>
        Func<int, bool> lambda1 = i => i % 2 != 0;
        //Displaying the result before building an expression tree
        Console.WriteLine("Before conversion...");
        Console.WriteLine(lambda1(5));

        //Building a lambda expression that is of type
        //Expression<Func<int, bool>>
        Expression<Func<int, bool>> lambda2 = i => i % 2 != 0;

        //Compiling the lambda expression that returns the result of type
        //Func<int, bool>
        Func<int, bool> finalLambda = lambda2.Compile();

        //Displaying the result after compiling the expression tree
        Console.WriteLine("After conversion...");
        Console.WriteLine(finalLambda(5));
    }
}
```

In Listing 19.19, we have defined a lambda expression, which can detect an odd number, and assigned it to a delegate of type `Func<int, bool>`. Then, we have displayed the result of the lambda expression, which in this case is false. After that, we have declared a variable of type `Expression<Func<int, bool>>`. This variable holds the expression tree for the lambda function. Now, when we compile this variable using the `Compile()` method, it will return the delegate of type `Func<int, bool>`.

The output of the program is given as follows:

```text
Before conversion...
True
After conversion...
True
```

### Building an Expression Tree for a Lambda Expression

We can build an expression tree by using the Expression class provided by the .NET Framework. The factory methods of the Expression class help in building the expression tree for the lambda expression manually. Listing 19.20 shows an example of building the expression tree for the lambda expression, `i => i % 2 != 0`.

**Listing 19.20:** Building an Expression Tree for a Lambda Expression

```csharp
using System;
using System.Linq;
using System.Linq.Expressions;

class Program
{
    public static void Main()
    {
        //Building expression tree for the lambda expression i => i % 2 != 0
        //Defining the parameter i
        ParameterExpression p = Expression.Parameter(typeof(int), "i");
        //Defining the constant 2
        ConstantExpression c = Expression.Constant(2, typeof(int));
        //Defining the constant 0
        ConstantExpression c1 = Expression.Constant(0, typeof(int));
        //Building the expression i%2
        BinaryExpression modulo = Expression.Modulo(p, c);
        //Building the expression i%2 != 0
        BinaryExpression isEqual = Expression.NotEqual(modulo, c1);

        //Compiler builds the lambda expression i => i % 2 != 0 at this step
        Expression<Func<int, bool>> l1 = Expression.Lambda<Func<int, bool>>(isEqual,
            new ParameterExpression[] { p });

        //Compile the lambda expression
        Func<int, bool> lambda = l1.Compile();

        //Displaying the result of the lambda expression
        Console.WriteLine(lambda(5));
    }
}
```

Listing 19.20 is self-explanatory, as it shows the stepwise execution of building an expression tree. Therefore, when run this program, the output will be True.

In an expression tree, the root node is always of type `Expression<DelegateT>`, that is, the root node holds the entire lambda expression. C# also allows us to create an expression tree from an available lambda expression.

Figure 19.21 shows the expression tree for the expression `i => i % 2 != 0`:

**Figure 19.21:** Showing an Expression Tree

Listing 19.21 uses the lambda expression, `i => i % 2 != 0`, to build an expression tree:

**Listing 19.21: Building an Expression Tree from a Lambda Expression**

```csharp
using System;
using System.Linq;
using System.Linq.Expressions;

class Program
{
    public static void Main()
    {
        //Building expression tree from the lambda expression i => i % 2 != 0
        Expression<Func<int, bool>> lambdaExpr = i => i % 2 != 0;

        BinaryExpression binaryExpr
          = (BinaryExpression)lambdaExpr.Body;//holding the expression i%2 != 0
        BinaryExpression parentLeft
          = (BinaryExpression)binaryExpr.Left;//holding the expression i % 2
        ParameterExpression left
          = (ParameterExpression)parentLeft.Left;//holding the parameter i
                                                    //of i%2
        ConstantExpression right
          = (ConstantExpression)parentLeft.Right;//holding the constant of i%2
        ConstantExpression parentRight
          = (ConstantExpression)binaryExpr.Right;//holding 0
        ParameterExpression param
          =(ParameterExpression)lambdaExpr.Parameters[0];//holding
                                                    //the parameter i

        Console.WriteLine("The expression is...");
        //Displaying the lambda expression
        Console.WriteLine("{0} => {1} {2} {3} {4} {5}",
          param.Name,left.Name,parentLeft.NodeType,
          right.Value, binaryExpr.NodeType, parentRight.Value);
    }
}
```

In the preceding program, we first got the entire body of the binary expression and then separated its tree elements accordingly. The output of the program is given as follows:

```text
The expression is...
i => i Modulo 2 NotEqual 0
```

### Standard LINQ Operators

LINQ provides a collection of the operators that can be used to create an expression similar to a SQL query. These operators are called standard LINQ operators. There are approximately 50 operators that are used to perform query operations over a collection or an array of objects. The `System.Query.Sequence` class, which comes under the `System.Query` namespace, has methods called standard query operators that are used in LINQ queries. Standard query operators are categorized into two groups:

- A set of standard query operators that comes under the `IEnumerable<T>` interface
- A set of standard query operators that comes under the `IQueryable<T>` interface
