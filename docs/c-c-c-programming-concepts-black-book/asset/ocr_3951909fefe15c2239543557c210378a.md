By default, the first enumerator of the data type takes the value 0 and then, each subsequent enumerator takes a value one greater than the previous enumerator does. Therefore, in the topmost enum process_states, NEW will take value 0, READY will take value 1, RUNNING will take value 2, IO will take value 3, and FINISHED will take value 4. We can also change the convention by setting the first enumerator of the enum to a particular value, and again, each subsequent enumerator takes a value one greater than the previous enumerator does. Therefore, in the second definition of enum process_states, NEW is assigned a value of 4, and consequently, READY will take value 5, RUNNING will take value 6, IO will take value 7, and FINISHED will take value 8. In addition, we can also set the values of an enum to all the custom values as shown in the third definition of the enum process_states.

Derived data types are those that are defined in terms of other data types. Following are the list of derived data types in C++:

+   * Arrays—An array is a homogeneous data type occupying a set of contiguous memory location where each cell in the array is accessed by increasing order of addressing. The application and usage of arrays in C++ is similar to that of in C. However, the definition and usage of arrays in C and C++ differ in how character arrays are initialized. For instance, the following statement is valid in C:

```
```c
char string [3] = "xyz"; // Valid in C
```
```

The preceding statement assumes that a programmer intends to leave out the NULL character \0 in the definition. However, the statement is invalid in C++. The size of string should be one character more than the total number of characters in the string, as shown in the following statement:

```
```c
char string [4] = "xyz"; // Valid in C++
```
```

+   * Functions—The definition, structure, and purpose of functions in C++ are similar to the functions in C. In addition, anything about functions that work in C, should also work in C++; however, C++ has enhanced the functionalities of functions and made them capable of doing several new things, such as overloading and overriding, which are based on object-oriented principles.

+   * Pointers—in C++, pointers can be declared and initialized as in the C language. However, C++ has introduced two new concepts that are related to pointers: constant pointer and pointer to a constant. Let’s learn about these two concepts with the help of the following examples:

```
```c
1: char * const char_ptr = "GOOD";          //constant pointer
2: int const *    int_ptr = &any_integer_variable;  //Pointer to a constant
```
```

Line number 1 shows the declaration of constant pointer, char_ptr. After its declaration, we cannot modify the address of char_ptr to which it is initialized.

In line number 2, we have declared a pointer to a constant int ptr, which is an integer pointer that can point to an integer constant. It can point to any variable of correct type, but the content of what it points to cannot be changed.

+   * References—C++ introduces a new type of variable known as a reference variable, which provides an alternative name for a previously defined variable. For example, if we make var1 variable a reference to another variable var2 of the same type, then both var1 and var2 can be used interchangeably to access that variable. A reference variable can be created using the following syntax:

```
```c
Data_type & reference_var = variable_name;
```
```

In the preceding syntax, the & operator is used to define a reference.

Following is the example that shows how to declare a reference variable:

```
```c
int var1 = 200; // var1 is an integer variable
int & var2 = var1; // var2 is a reference variable of integer type referring to //var1
```
```

In the preceding example, if we change the value by accessing any one of the variables, then the change immediately reflects into the other one.
