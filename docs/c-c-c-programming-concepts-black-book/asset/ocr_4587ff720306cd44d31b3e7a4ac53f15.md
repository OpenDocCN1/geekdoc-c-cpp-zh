# ### Bubble Sort

Bubble sort technique is used to put the largest number in a series at the rightmost place in one iteration. This method takes an array of elements and scans them from left to right. At each iteration, it places the largest element at the highest position by comparing two adjacent elements and swapping them if they are out of order. This process is repeated until all the elements are placed at the right index position. Therefore, at each step, the largest element of the array is bubbled up from its original position to the highest index position in an effective way.

Let's consider the following array to understand the bubble sort technique:

```
`A[n] = [30, 20, 90, 60, 100, 10]`
```

To describe the technique, we need to have two variables i and j, where i represents the number of steps required to sort the array and j represents the number of sub-steps required in each step to put the highest element at the higher index in the array. In addition, we initialize the values of i and j as 0.

Following is the stepwise execution of the bubble sort technique:

+   1. In this step, the adjacent elements are compared in each line. At the end of this step, the highest number, which is 100, is placed at the rightmost position of the array, as follows:

Iteration 1: i = 0

| | | | | | | |
|---|---|---|---|---|---|---|
| 30 | 20 | 90 | 60 | 100 | 10 | (j = 0) Swapped |
| 20 | 30 | 90 | 60 | 100 | 10 | (j = 1) |
| 20 | 30 | 90 | 60 | 100 | 10 | (j = 2) Swapped |
| 20 | 30 | 60 | 90 | 100 | 10 | (j = 3) |
| 20 | 30 | 60 | 90 | 100 | 10 | (j = 4) Swapped |
| 20 | 30 | 60 | 90 | 10 | 100 | At the end of iteration 1, 100 is placed at the rightmost side |
