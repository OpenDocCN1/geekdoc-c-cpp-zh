+   - **Member Dereferencing Operators—C++** allows us to first define a class containing various types of data and functions as members and then access these members through pointers. For this, C++ provides three pointer-to-member operators, as shown in Table 12.2:

**Table 12.2: Member Dereferencing Operators in C++**

| Operator | Function |
|---|---|
| ::* | Used to declare a pointer to a member of a class |
| .* | Used to access a member using object name and a pointer to that member |
| ->* | Used to access a member using a pointer to the object and a pointer to that member |

# ### Operator Precedence

Although C++ enables us to add multiple meanings to the operators, yet their association and precedence remains the same. For example, the multiplication operator will continue having higher precedence than the addition operator. Table 12.3 shows the operator precedence and associativity in C++:

**Table 12.3: Operator Precedence and Associativity in C++**

| Operator | Meaning | Associativity | Use |
|---|---|---|---|
| :: | Global scope | Right to left | ::name |
| :: | Class, namespace scope | Left to right | Name::member |
| . | Direct member | Left to right | Object.member |
| -> | Indirect member | Left to right | Pointer->member |
| [] | Subscript |  | Pointer [expr] or arrays |
| () | Function call |  | Function (arg) |
| ++ | Postfix increment |  | M++ |
| -- | Postfix decrement |  | M-- |
