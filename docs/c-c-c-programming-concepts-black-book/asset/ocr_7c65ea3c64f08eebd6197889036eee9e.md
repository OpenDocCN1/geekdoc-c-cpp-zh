Let's first learn about the assembly manifest and its significance in assembly.

# # Assembly Manifest

To execute a file, every assembly should keep a record of how the elements in the assembly are related to each other. This can be known from the metadata. Assembly manifest contains the metadata that specifies the versioning of the assembly and the security identity. Other than this, metadata contains the information related to the scope of the assembly as well as the reference to the classes and resource files. The assembly manifest is stored either in an .exe or .dll file (commonly known as PE file) along with the MSIL/CIL code or in a separate standalone file that contains only the assembly metadata.
