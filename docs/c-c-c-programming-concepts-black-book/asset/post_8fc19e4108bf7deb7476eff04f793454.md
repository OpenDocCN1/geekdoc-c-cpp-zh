## Identifiers

All kinds of variables, functions, labels, and other user defined items are called identifiers. Length of identifiers can vary from one to multiple characters. Identifiers can be alphanumeric in nature but there are some rules that need to be followed while declaring identifiers in C. For example, the first letter must be an underscore or a character. Subsequent characters can be characters, underscores, or numeric values. An identifier starting with a numeric value is not allowed to be declared in C.

Table 1.2 lists the allowed and disallowed identifiers, also known as right or wrong identifiers:

**Table 1.2: Right and Wrong Identifiers**

| Right Identifier | Wrong Identifier |
|---|---|
| `loop_count` | `3count` |
| `check45` | `Hello!world` |
| `flag` | `check-value` |

An identifier can be of any length. C has two different sets of identifiers—external and internal. The external identifiers are like global variable names and function names that are shared between files. This sharing is also called the external link process. If an identifier cannot be shared globally, it is called an internal identifier. In the C89 version of C, only first 6 characters of an external identifier and first 31 characters of an internal identifier were considered to be significant. This got changed with the C99 version, where an external identifier has 31 significant characters and an internal identifier has 63. Identifiers are case sensitive, which means that they appear upper and lower case characters distinctly.

## Data Types

There are five fundamental data types available in C, which are as follows:

- int
- char
- float
- double
- void

The size and range of these data types vary according to the compiler and the architecture of the computer on which the program is developed or run. The size of int varies from 2 bytes to 4 bytes, depending on the compiler and processor. The size of char remains unaltered across all architectures. The size of int generally depends on the word length of the program. To be more precise, the size depends upon the CPU architecture on which the program runs. In a 16 bit architecture, an integer has a size of 16 bits or 2 bytes. In a 32 bit architecture, it will have a size of 4 bytes, which is equal to 32 bits. The length of float and double depends upon the representation used for floating point numbers. Standard ANSI C specifies that the minimum range of a floating point value is 1E-37 to 1E+37. The void data type is typically used to define return types for functions or for pointers. They will be discussed in detail in subsequent chapters.

The basic data types except for void can be further modified with the help of different type modifiers available in C. A type modifier alters the meaning of the base type to cater some more requirements, such as the type modifier increases the length of information that a basic type can contain. The following are the basic type modifiers available in C:

- signed
- unsigned
- long
- short

An int data type can be modified by all the preceding modifiers; whereas, char can be extended by using only the unsigned and signed modifiers. Table 1.3 lists the lengths of data types in C:

**Table 1.3: Length of Data Types in C**

| Type | Standard size in bits | Range |
| --- | --- | --- |
| char | 8 | -127 to 127 |
| unsigned char | 8 | 0 to 255 |
| signed char | 8 | -127 to 127 |
| int | 16 or 32 | -32,767 to 32,767 |
| unsigned int | 16 or 32 | 0 to 65,535 |
| signed int | 16 or 32 | same as int |
| short int | 16 | -32,767 to 32,767 |
| unsigned short int | 16 | 0 to 65,535 |
| signed short int | 16 | same as short int |
| long int | 32 | -2,147,483,647 to 2,147,483,647 |
| long long int | 64 | -(2^63 -1) to 2^63 -1 |
| signed long int | 32 | same as long int |
| unsigned long int | 32 | 0 to 4,294,967,295 |
| unsigned long long int | 64 | 2^64 - 1 |
| float | 32 | 1E-37 to 1E+37 (six digit precision) |
| double | 64 | 1E-37 to 1E+37 (ten digit precision) |
| long double | 80 | 1E-37 to 1E+37 (six digit precision) |

The "signed" modifier is not used in C as the integer declaration in C is always a signed integer. The difference between a signed and unsigned integer is in their representation. The compiler treats the most significant bit of an integer as the sign bit. If the sign bit in an integer is set to zero, then the integer is considered to be positive, else negative. The negative numbers are stored in the form of 2's complement representation in C, where all the bits of the number are reversed except the sign flag and 1 is added to it. Then the sign bit is set to 1. Signed integers restrict the user to use the complete range of the numbers. For example, the positive range of a signed integer becomes 32,767 which is represented as:

```
01111111 11111111
```

If the higher order bit of this number is set to 1, then this number becomes -1. If the same number is declared as an unsigned integer, then the range goes up till 0 to 65,535, when the higher order bit is set to 1.

## Additional Data Types in C

Apart from the standard data types, three new data types have been incorporated in C in the C99 version. These three new data types are:

- **Bool**—Represents the data type that is capable of storing the values 0 or 1 (true or false) in it. The Bool data type is basically integer type. C++ defines its own version of Boolean data types which are known as bool. While dealing with C, it should be kept in mind that both the data types should not be mixed with each other.
- **_Complex**—Represents the data type that cannot be treated as a standalone data type by its own. It is more or less used as a type modifier for float, double, and long double data types.
- **_Imaginary**—Represents the data type that adds capability for handling imaginary values within the supported data types. It is a type modifier.

Both _Complex and _Imaginary data types modify the standard data types as follows:

- float _Complex
- float _Imaginary
- double _Complex
- double _Imaginary
- long double _Complex
- long double _Imaginary

As mentioned above float _Complex or float _Imaginary is a new data type all together which has the capability of storing imaginary or complex values which are floating points in nature. The same is true for all other data types mentioned above as well.

The header file <complex.h> contains the definition for both the macros **complex** and **imaginary**; these expand to _Complex and _Imaginary types. It is a good programming practice to include the header while dealing with these modifiers.

## Constants

Constants refer to fixed values which a program is not allowed to alter during the course of its execution. Constants are also known as literals in C. There are generally four basic types of constants available in C — integer constants, floating point constants, character constants, and string constants. Integer and floating point constants represent numbers so they are treated as numeric constants. The following are some rules defined for numeric constants:

- While declaring numeric constants, commas and blank spaces cannot be provided.
- A numeric constant can be preceded by a minus sign signifying its negative constant.
- The value of a constant cannot exceed a specified limit. This limit varies from compiler to compiler.

### Integer Constant

An integer constant represents an integer, so it constitutes of only digits. It is possible in C to declare integer constants in different number systems, such as in decimal, octal, and hexadecimal number systems. A decimal integer constant can be constructed by digits from 0 – 9. Some examples of invalid decimal constant representation are:

- 30,345—Incorrect representation as comma is not allowed
- 21.098—Incorrect representation as precision cannot be provided in decimal constant
