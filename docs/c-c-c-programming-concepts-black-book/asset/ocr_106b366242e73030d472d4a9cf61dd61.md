# # C, C++, C#
## Programming Concepts
### Black Book™

# Covers TCP, UDP, Kernel and Parallel Programming, OCI, Cross Compilation, Interrupts in C

This book brings to its readers a profound accumulation of concepts in C, C++ and C# which can be referred by both beginners as well as seasoned developers. It not only contains useful and in-depth information on the conceptual foundations of all the three languages but also teaches you how to implement each language concept programmatically. Each chapter is equipped with huge number of code snippets and examples making it easy for the reader to understand and learn the language fast. This edition of the book particularly deals with some new and advanced topics like Networking Programming in C, Parallel Programming using C language and also kernel programming using C. It is not only targets the core audience who are mostly involved in C and C++, it reaches out to the next generation programmers with its extensive coverage on C# as well. The versatility of content makes the book insensible for a vast spectrum of readers.
