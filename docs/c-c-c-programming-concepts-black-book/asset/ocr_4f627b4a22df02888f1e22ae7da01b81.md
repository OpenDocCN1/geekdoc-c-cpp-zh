The first syntax sets the stream's formatting flags whose bits are set into fmtfl, leaving the remaining unchanged, as if a call to up to flags (fmtfl | flags()). The second syntax sets the stream's format flags whose bits are set in both fmtfl and mask. It also clears the format flags whose bits are set in mask, but not in fmtfl, as if a call to flags ( (fmtfl & mask) | (flags() & ~mask) ).

Consider the following program:

```
```cpp
#include <iostream>
using namespace std;
int main ()
{
    cout.setf ( ios::hex, ios::basefield );       // set hex as the basefield
    cout.setf ( ios::showbase );                  // activate showbase
    cout<< 100 << endl;
    cout.setf ( 0, ios::showbase );               // deactivate showbase
    cout<< 100 << endl;
    return 0;
}
```
```

The output of the preceding program is as follows:

```
```
0x64
64
```
```

# # The unsetf() Function

The unsetf() clears the flags corresponding to the bits set within the parameter mask. The parameterized manipulator resetiosflags behaves similar to this function. The syntax of unsetf() function is as follows:

```
```cpp
void unsetf ( fmtflags mask);
```
```

Consider the following example:

```
```cpp
#include <iostream>
using namespace std;
int main ()
{
    cout.setf ( ios_base::hex, ios_base::base_field );
    cout.setf ( ios_base::show_base );
    cout<< 100 << endl;
    cout.unsetf ( ios_base::show_base );
    cout<< 100 << endl;
    return 0;
}
```
```

The output of the above program is as follows:

```
```
0x64
64
```

# # The width() Function

The width() function sets the required field size for displaying the output. The two types of width() function may be expressed as follows:

```
```cpp
streamsize width ( ) const;
streamsize width ( streamsize wide );
```
```

The first function returns the current value of the field width and the second function sets a new field width for an object.
