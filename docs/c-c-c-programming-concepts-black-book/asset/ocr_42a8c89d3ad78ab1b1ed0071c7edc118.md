In Listing 7.2, the macro is replaced with an entire conditional statement. During the preprocessing, the macro is expanded and the following line,

```
~~~c
if (CONDITION)
~~~
```

becomes,

~~~c

~~~

Now, suppose there is a constant value in a source code that appears quite a number of times in the code. If the constant value needs to be changed, then we need to manually go through the code and change every occurrence of the constant value. However, if we replace the constant value with a macro, then we need to just change the expansion value and all the occurrences will be automatically replaced with the expanded value. We can achieve the same objective with the help of a variable; however, it would make the compiler slower. Therefore, macros produce more efficient and easily comprehensible codes.

We can also use a macro to perform certain calculations, which could otherwise be done with the help of a function. However, there is a significant difference between a macro and a function. A macro is replaced by the preprocessor blindly without performing any check for errors, whereas, a function is far more secured in terms of syntax errors. A major advantage of a macro is that it is less time consuming than a function. This is because multiple context switching takes place for each call made to a function. In addition, registers and program counters need to be saved and a jump is made to the first instruction followed by the function name. In case of a macro, all this overhead is not required, as it only replaces the code block instead of any context switching. However, one disadvantage of using a macro is that it increases the size of a source code. If a macro is called multiple times in a program, then the same code will be replaced multiple times. Therefore, macros should be used as a shorthand notation, but for large-scale codes, we should still rely on functions.

+   - Nested macros

# ## Macro with Arguments

Similar to functions, arguments can also be passed to a macro. Listing 7.3 shows how to pass arguments to a macro.

**Listing 7.3:** Passing Arguments to a Macro

```
~~~c
#include<stdio.h>
#define SQUARE(num) (num*num)
int main()
{
    int varA;
    printf("\n Enter any number -> ");
    scanf("%d", &varA);
    printf("\n The square root of %d is %d ", varA, SQUARE(varA));
    getch();
    return 0;
}
~~~
```

The preprocessor will expand the SQUARE(num) macro to (num*num) during the preprocessing. In the main() function, varA is passed as an argument to the macro that substitutes for num. The output of the preceding program is given as follows:

```
~~~
Enter any number -> 11
The square root of 11 is 121
~~~
```
