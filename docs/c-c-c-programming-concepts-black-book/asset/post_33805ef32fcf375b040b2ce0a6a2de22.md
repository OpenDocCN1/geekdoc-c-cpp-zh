- **Setw Manipulator**—The operator is used with the insertion operator << to modify the way data is displayed on the screen. This operator changes the field width of an output and makes it appear better formatted. Let's demonstrate the need of setw manipulator with the help of the following program:

  ```c++
  1: // Demonstrating the need of manipulator in C++
  2: #include <iostream>
  3: using namespace std;
  4:
  5: int main()
  6: {
  7:     long var1=2544771, var2=88, var3 = 9999;
  8:     cout      <<"Location " << "POP. "<<endl
  9:               <<"PortCity " << var1 <<endl
  10:              <<"HighTown " << var2 <<endl
  11:              <<"LowVille " << var3 <<endl;
  12:     return 0;
  13: }
  ```

Following is the output of the preceding program:

```text
Location POP
PortCity 2524771
HighTown 88
LowVille 9999
```

The preceding output does not appear in a well-formatted way with no alignment. Now, let's use the setw manipulator operator in the same program to make the output appear better:

```c++
1: // Demonstrating setw manipulator usage in C++
2: #include <iostream>
3: using namespace std;
4:
5: int main()
6: {
7:         long var1=2524771, var2=88, var3 = 9999;

```

Following is the output of the preceding program:

```text
Location POPULATION
PortCity        2524771
Hightown          88
Lowville         9999
```

The setw manipulator causes the number (or string) that follows it in the stream to be printed within a field, which is n character wide, where n is the argument to setw(n).

- **Member Dereferencing Operators**—C++ allows us to first define a class containing various types of data and functions as members and then access these members through pointers. For this, C++ provides three pointer-to-member operators, as shown in Table 12.2:

**Table 12.2: Member Dereferencing Operators in C++**

| Operator | Function |
|---|---|
| ::* | Used to declare a pointer to a member of a class |
| .* | Used to access a member using object name and a pointer to that member |
| ->* | Used to access a member using a pointer to the object and a pointer to that member |

| () | Function call |  | Function (arg) |
