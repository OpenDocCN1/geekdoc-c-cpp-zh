# Creating XML Files using Visual Studio 2008

To work with an XML file in Windows and Web applications, we first need to create the file using Visual Studio 2008. Perform the following steps to create an XML file:

+   1. Create a Web or Windows application and provide a name to it. In our case, we have created a Web application and named it as My First XML, as shown in Figure 20.1:

![](bbox=[0.275, 0.25, 0.75, 0.514])

+   2. Click the Ok button. The My First XML—Microsoft Visual Studio window appears.
+   3. Right-click the project name, My First XML, in the Solution Explorer pane. A context menu appears.
+   4. Select the Add option from the context menu. The sub-context menu appears.
+   5. Select the New Item option to add a new item to the application, as shown in Figure 20.2:
