# Additional Data Types in C

Apart from the standard data types, three new data types have been incorporated in C in the C99 version. These three new data types are:

+   - **Bool**—Represents the data type that is capable of storing the values 0 or 1 (true or false) in it. The Bool data type is basically integer type. C++ defines its own version of Boolean data types which are known as bool. While dealing with C, it should be kept in mind that both the data types should not be mixed with each other.
+   - **_Complex**—Represents the data type that cannot be treated as a standalone data type by its own. It is more or less used as a type modifier for float, double long, and long double data types.
+   - **_Imaginary**—Represents the data type that adds capability for handling imaginary values within the supported data types. It is a type modifier.

Both _Complex and _Imaginary data types modify the standard data types as follows:

+   - float _Complex
+   - float _Imaginary
+   - double _Complex
+   - double _Imaginary
+   - long double _Complex
+   - long double _Imaginary

As mentioned above float _Complex or float _Imaginary is a new data type all together which has the capability of storing imaginary or complex values which are floating points in nature. The same is true for all other data types mentioned above as well.

The header file <complex.h> contains the definition for both the macro’s **complex** and **imaginary**, these expand to _Complex and _Imaginary types. It is a good programming practice to include the header while dealing with these modifiers.

# Constants

Constants refer to fixed values which a program is not allowed to alter during the course of its execution. Constants are also known as literals in C. There are generally four basic types of constants available in C — integer constants, floating point constants, character constants, and string constants. Integer and floating point constants represent numbers so they are treated as numeric constants. The following are some rules defined for numeric constants:

+   - While declaring numeric constants, commas and blank spaces cannot be provided.
+   - A numeric constant can be preceded by a minus sign signifying its negative constant.
+   - The value of a constant cannot exceed a specified limit. This limit varies from compiler to compiler.

# Integer Constant

An integer constant represents an integer, so it constitutes of only digits. It is possible in C to declare integer constants in different number systems, such as in decimal, octal, and hexadecimal number systems. A decimal integer constant can be constructed by digits from 0 – 9. Some examples of invalid decimal constant representation are:

+   - 30,345—Incorrect representation as comma is not allowed
+   - 21.098—Incorrect representation as precision cannot be provided in decimal constant
