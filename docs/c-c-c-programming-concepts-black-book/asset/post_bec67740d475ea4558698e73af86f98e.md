Note that not all the operators in C# can be overloaded. There are certain rules and regulations that are applied to the operator overloading process, which are given as follows:

- Unary operators, such as `+`, `-`, `!`, `~`, `++`, `--`, `true`, and `false`, can be overloaded.
- Binary operators, such as `+`, `-`, `*`, `/`, `%`, `&`, `|`, `^`, `<<`, and `>>`, can be overloaded.
- Comparison operators, such as `==`, `!=`, `<`, `>`, `<=`, and `>=`, can be overloaded, but they have to appear as a pair. For example, if a program has an operator overloading method for the `==` operator, then there must be an operator overloading method for the `!=` operator. The reverse is also true. This rule goes for all the comparison operators.
- The conditional logic operators, such as `&&` and `||`, cannot be overloaded, but by using the operators `&` and `|`, these conditional logic operators can be evaluated.
- Assignment operators, such as `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `|=`, `^=`, `<<=`, and `>>=`, cannot be overloaded. However, if we take the example of the `+=` operator, then the operator can be evaluated using the `+` operator.

The concept of operator overloading can be used in such a way that it may become impossible for anyone to understand the functionality of the code. For example, if we try to add two objects of Vehicle class, then it would be a bad implementation of operator overloading. Therefore, while using operator overloading, we need to create a class that actually requires the operator overloading method.

## Types of Object in C#

Object type is another name of Object class. The Object class is a base class, which is derived indirectly or directly by all the types defined in C#. It allows us to build generics and work with collections. In C#, the Object class provides two main properties: boxing and unboxing. We can assign any value type to the Object instance; this event is known as boxing. To get back the value type, we need to cast the type on the Object instance; this event is known as unboxing.

Listing 18.28 shows an example of boxing and unboxing:

Listing 18.28: Showing an Example of Boxing and Unboxing

```csharp
using System;
class Program
{
    public static void Main()
    {
        Console.WriteLine("Enter the Employee name...");
        String name = Console.ReadLine();
        Console.WriteLine("Enter the age of the Employee...");
        int age = Convert.ToInt32(Console.ReadLine());
        //Applying boxing to name and age of the employee
        Object obj1 = name; //Assigning the name of the employee
                            //to an instance of the object class
        Object obj2 = age;  //Assigning the age of the employee
                            //to an instance of the object class
        //Applying unboxing to the name and age of the employee
        string empName = (string)obj1; //Implementing type casting
                                       //to the object instance to unbox the value
        int empAge = (int)obj2; //Implementing type casting to the
                                //object instance to unbox the value
        Console.WriteLine("You Entered Name: {0}, Age: {1}", empName, empAge);
    }
}
```

In the preceding code, we have applied the boxing mechanism to the name and age variables by assigning them to two different instances of the Object class. Then, we have incorporated the unboxing mechanism by applying proper type casting to the instances of Object class. The output of the preceding code is given as follows:

```text
Enter the Employee name...
John
Enter the age of the Employee...
35
You Entered Name: John, Age: 35
```

Let's now learn about various access modifiers provided by C#.

### Access Modifiers

Access modifier is another property of OOP that implements encapsulation. Encapsulation hides the class definition from the outside world. Therefore, by using the access modifier, we can decide the amount of encapsulation that should be applied to a class. In this section, we will discuss the following five types of access modifiers:

- Public
- Private
- Protected
- Internal
- Protected internal

Let's start our discussion with the *public* access modifier.

### Public

When a public modifier is applied to methods and fields of a class, those methods and fields can be accessed from anywhere in the program and the assembly. Therefore, there is no restriction accessing the public members of a class. This makes the class public to the external world. We use the *public* keyword before the declaration of the members in a class to make its members public. Let's consider a small example to elaborate the accessibility of a public access modifier, as shown in Listing 18.29:

Listing 18.29: Showing the Example of Public Access Modifier

```csharp
using System;
class Vehicle
{
    public string type;
}
class Owner
{
    public void OwnerVehicle()
    {
        Vehicle vehicle = new Vehicle();
        vehicle.type = "Two-wheeler";
        Console.WriteLine("The owner has a " + vehicle.type);
    }
}
class Car : Vehicle
{
    static void Main()
    {
        Vehicle vehicle = new Vehicle();
        vehicle.type = "Four-wheeler";
        Console.WriteLine("The type of the car is " + vehicle.type);
        Owner owner = new Owner();
        owner.OwnerVehicle();
    }
}
```

In the preceding code, we have first created a class named Vehicle and then declared a public variable that defines the type of the Vehicle instance. Next, we have declared a class named Car that derives the Vehicle class. In the Main() method, we have first declared an object of the Vehicle class and then assigned a value to the public member variable of the Vehicle class. As this is defined as public, we can access it from the derived class. In addition, we have defined another class named Owner, which has one method that accesses the public variable of the Vehicle class. If we access that member variable through an instance of the Owner class in the Main() method, then the compiler will not generate any error. The code runs smoothly and generates the following output:

```text
The type of the car is Four-wheeler
The owner has a Two-wheeler
```
