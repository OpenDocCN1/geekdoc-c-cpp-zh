In the next section, let’s revisit the concept of encapsulation to illustrate the access control level of the members of a class and external users.

# Encapsulation - Access Control to the Members and External Users

Members of a class can be declared as *private*, *protected*, or *public*. A *private* member of a class can only be used by the member functions of the class within which it is declared. A *protected* member of a class can be accessed only by the member functions of the class within which it is defined and by the member functions of the classes that are derived from that class. On the contrary, *public* members of a class can be used by any function and the access control level is applied uniformly to all the member functions and data members.

Classes that have all the public data members are more susceptible to be misused by the users, as there is no protection for those members. This is strictly not in harmony with the object-oriented principles, as the implementation details are not isolated from the users. The concept of data or information hiding fails to prevail over these classes.

Listing 13.13 shows the GEN class to understand the concept of access controls:

**Listing 13.13:** Showing the Code for GEN Class

```
class GEN
{
private :
    int a;
    int b;
protected :
    func_1();
    int c;
public :
    func_2();
    func_3();
};
```

Now, consider the OBJ_FUNC() function, given in Listing 13.14:

**Listing 13.14:** Showing the Code for OBJ_FUNC() Function

```
1: void OBJ_FUNC()
2: {
3: GEN obj_GEN;
4: obj_GEN.a = 5;
5: obj_GEN.func_2();
6: obj_GEN.func_3();
7: obj_GEN.func_1();
8: obj_GEN.c = 3;
9: }
```

Line 3 of the function denotes that obj_GEN is an object of the GEN class. The declaration at line 4 will give an error, as a is a private member of the GEN class. Both the lines 5 and 6 are correct, as func_2() and func_3() are the public members of the GEN class. Again, line 7 gives an error, as func_1() is a protected member of GEN and not accessible to a function, which is neither its member function nor its derived class. Similar is the case for line 8.
