# ## Parameter Passing

Parameters are the arguments that are passed to the methods. In C#, there are four different ways of passing the parameters to the methods, which are given as follows:

+   - Passing values
+   - Passing a reference using the ref keyword
+   - Passing a reference using the out keyword
+   - Passing parameters by using the params keyword

Let's learn about these in detail one by one.

# ### Passing values

This is a common way of passing the parameters to the methods. By default, the value of a parameter or variable is passed whose scope is defined inside the calling method. Before passing the parameters to a method, the program creates the duplicate copies of each parameter so that any changes to the parameters that are passed to the method do not affect the values of the actual parameters.
