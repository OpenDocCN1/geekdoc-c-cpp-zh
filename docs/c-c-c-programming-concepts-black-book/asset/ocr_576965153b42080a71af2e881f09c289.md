Listing 1.26 shows how switch statements can be nested inside each other. Whenever the break statement inside the innermost switch statement gets executed, the control comes out from the outer switch statement as well.

Switch statements are also used along with the do-while loop for user input driven programing. Consider a scenario where a user decides to perform certain actions and keeps on providing input to the program from time to time till he wants to end execution. This sort of scenario can be handled by using the switch statement and do-while loop together.

Listing 1.27 shows the use of the switch statement and do while loops:

# Listing 1.27: Usage of Switch and Do While Loops

```
```c
#include<stdio.h>
int main()
{
    int choice,varA,varB;
    char opt;

    do
    {
        printf("\n Enter two numbers ");
        scanf("%d %d",&varA,&varB);
        printf("\n 1: Addition ");
        printf("\n 2: Multiplication");
        printf("\n 3: Subtraction");
        printf("\n Enter your choice (1/2/3) ? ");
        scanf("%d",&choice);
        switch(choice)
        {
            case 1:
                printf("\n Sum is %d ",varA+varB);
                break;
            case 2:
                printf("\n Product is %d ",varA*varB);
                break;
            case 3:
                printf("\n Difference is %d ",varA-varB);
                break;
            default:
                printf("\n wrong Option");
        }
        fflush(stdin);
        printf("\n Want to continue (y/n) ?");
        scanf("%c",&opt);
    }while(opt !='n');
    getch();
}
```
