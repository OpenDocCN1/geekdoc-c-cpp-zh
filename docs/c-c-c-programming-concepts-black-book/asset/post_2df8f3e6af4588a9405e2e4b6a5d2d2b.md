## Application of XML Classes

Till now, we have learned about the three main XML classes, namely XmlTextReader, XmlTextWriter, and XmlDocument, and their respective methods. Let’s now use these classes and their methods in a Web application. The functionalities incorporated in the application are as follows:

- A user can create an XML document using the XmlTextWriter class and then view it in a grid format by using XmlTextReader
- A user can create only one XML document by using the XmlDocument class

The Web application creates an XML document with only one child element. This is the main restriction of this application to make it simpler. This application provides a user to decide the name of the root element, name of the child element, and name and number of the attributes associated with the child element. In addition, the user has the option to select the name and number of the sub-child element. This makes the application much more attractive and dynamic. The application also contains two buttons, namely Create XML using XMLTextWriter and Create XML using XMLDocument.
