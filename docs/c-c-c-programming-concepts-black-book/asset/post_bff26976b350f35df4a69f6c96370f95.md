### Dynamic Allocation

Similar to any other language, C++ also has its own set of dynamic memory allocation utility functions. In C language, we have primarily used the malloc ()/calloc () functions along with the free () function. Apart from the malloc (), calloc (), and free () functions, C++ uses two newly introduced operators – new and delete. Although the basic operations of the operators new and delete are similar to that of the malloc () and free () functions, still they are little bit more superior in terms of usability. For a call to the malloc () function, we need to specify the size of the memory chunk that we were requesting from the free memory pool; however, for the new operator, no size needs to be specified. Moreover, in case of failure to return the requested number of bytes, the new operator also returns NULL similar to the malloc () or calloc () functions. Let us write a simple program to show the utility of the new and delete operators in C++.

```cpp
#include <iostream>
using namespace std;

int main ()
{
  int *ptr = NULL;

  ptr = new int;
  if (ptr == NULL) {
    cout<<"Allocation of integer member failed."<<endl;
    return -ENOMEM;
  } else {
    *ptr = 320;
  }

  cout<<*ptr<<endl;

  delete ptr;
  return 0;
}
```

Output:

```
320
```

In the preceding program, we have declared an integer pointer named ptr and tried to allocate it using the new operator. After the call to “new int,” we also check for the NULL pointer return values and return the error ENOMEM; however, for a successful compilation of the program, we assign the value 320 into the pointer variable and use it. Now, once we are done using it, we simply delete the ptr by making a call to delete.

Similar concepts can also be applied on any pointer variables to a class as well. For instance, for a dummy class, the usage of the new and delete operators is as follows:

```cpp
class Example {
  int data;
public:
    Example() {
        data = 0;
    }
    ~Example() {
        data = 0;
    }
};

int main ()
{
    Example *ptrObj;

    ptrObj = new Example;
    if (!ptrObj) {
        // Allocation failed error
    }

    // use ptrObj here by accessing the class methods using the arrow operator.
    // and once done delete and free the pointer.

    delete ptrObj;
    return 0;
}
```

The preceding code snippet is not a complete C++ program, but it is a skeleton that shows how we can use the new and delete operators for class pointer variables as well. Similar functions can also be used to allocate and de-allocate arrays as well in the similar way as follows:

```cpp

```
