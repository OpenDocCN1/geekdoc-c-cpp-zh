```
# ### invalid_argument ()

This class defines the type of objects thrown as exceptions to report an invalid argument. It is designed to ensure that any program, not only the elements from the standard library, can throw it as an exception. The constructor associated with bitset (bitset::bitset) may throw the exception. We can define this particular class as:

```
```cpp
class invalid_argument : public logic_error
{
public:
    explicit invalid_argument (const string& what_arg);
};
```
```

The constructor takes a regular string object as a parameter, which is used to generate the C-string that is returned by its inherited member function what(). The value of the string object is stored in the object.
```

# ### length_error ()

This class defines the type of objects thrown as exceptions to emphasize a length error. It is designed in such a way that apart from the elements of the standard library, any program can throw it as an exception. When attempted to resize to an excessive length, some member functions belonging to a vector and string throw this type of error.
