### exit()

The exit() function causes an immediate normal termination of a program. Any open file is flushed and closed when the function is executed. The signature of the exit() function is as follows:

```c
void exit(int exit_code);
```

The value of the exit_code argument is passed to the calling function (which happens to be an operating system). By default, the value of exit_code is zero, which indicates EXIT_SUCCESS. A non-zero value or EXIT_FAILURE indicates an implementation-defined error. Let’s take an example of the exit() function as mentioned in Listing 8.32:

### bsearch()

The bsearch() function is used to implement binary search over a sorted array. The signature of the bsearch() function is as follows:

```c
void *bsearch(const void *key, const void *buf,
              size_t num, size_t size,
              int (*compare)(const void *, const void *));
```

As shown in the preceding signature, the bsearch() function returns a pointer to the first member that matches the key pointed to by the key variable. The number of elements present in the array is defined by the num variable and the size (in bytes) of each element is specified by the size variable. The function, which is pointed to by a compare function pointer, is used to compare an element of the array with the key variable. The compare function pointer must be in the following format:

```c
int func_name(const void *arg1, const void *arg2);
```

The compare function pointer returns one of the following values:

- **Less than zero** — Denotes that arg1 is less than arg2
- **Zero** — Denotes that arg1 is equal to arg2
- **Greater than zero** — Denotes that arg1 is greater than arg2

Let’s take an example of the bsearch() function as mentioned in Listing 8.33:

**Listing 8.33:** Usage of bsearch() function.

```c
#include<stdio.h>
#include<stdlib.h>

int array[10] = {11,22,37,43,59,61,75,89};

int compare(const void *num1, const void *num2);

int main()
{
    int searchval;
    int *ptr;

    printf("\n Enter a number to search -> ");
    scanf("%d",&searchval);

    ptr = (int*)bsearch(&searchval, array, 8, 4, compare);

    if(ptr)
    {
        printf("\n Number is present ");
    }
    else
    {
        printf("\n Number is absent ");
    }

    getch();
    return 0;
}

int compare(const void *num1, const void *num2)
{
    return *((int*)num1) - *((int*)num2);
}
```

Note that the array to be searched must be in the ascending order before applying the bsearch() function on it. If the array does not have the key element, then NULL is returned.

Output of the preceding example is as follows:

```
Enter a number to search -> 22
Number is present
Enter a number to search -> 76
Number is absent
```

### qsort()

The qsort() function sorts an array using the Quicksort algorithm, which is considered as one of the efficient sorting techniques. The signature of the qsort() function is as follows:

```c
void qsort(void *buf, size_t num, size_t size,
           int (*compare) (const void *, const void *));
```

Number of elements present in an array is denoted by the num variable. Size of each variable is identified with the help of the size variable. The function pointed to a compare function pointer is used to compare two elements of the array. The compare function pointer must be in the following format:

```c
int func_name(const void *arg1, const void *arg2);
```

The compare function pointer returns one of the following values:

- **Less than zero** — Denotes that arg1 is less than arg2
- **Zero** — Denotes that arg1 is equal to arg2
- **Greater than zero** — Denotes that arg1 is greater than arg2

Let’s take an example of the qsort() function as mentioned in Listing 8.34:

**Listing 8.34:** Usage of qsort() function.

```c
#include<stdio.h>
#include<stdlib.h>

int array[10] = {29, 6, 652, 312, 72, 490, 55,176};
int compare(const void *num1, const void *num2);
int main()
{
    int i;

    printf("\n Original Unsorted Array \n\n");
    for(i=0; i < 8;i++)
    {
        printf(" %d ",array[i]);
    }

    qsort(array, 8, sizeof(int), compare);

    printf("\n\n Sorted Array \n\n");
    for(i=0; i < 8;i++)
    {
        printf(" %d ",array[i]);
    }

    getch();
    return 0;
}

int compare(const void *num1, const void *num2)
{
    return *(int*)num1 - *(int*)num2;
}
```

After the execution of the qsort() function, the array is sorted into the ascending order. Output of the preceding example is as follows:

```
Original Unsorted Array
29  6  652  312  72  490  55  176

Sorted Array
6  29  55  72  176  312  490  652
```
