## Ordering Operators

Ordering operators in LINQ are used to sort a collection. There are five types of ordering operators:

- OrderBy
- OrderByDescending
- ThenBy
- ThenByDescending
- Reverse

The *OrderBy* operator sorts the values in the ascending order; the *OrderByDescending* operator sorts the values in the descending order; the *ThenBy* operator acts as a secondary sort in the ascending order; the *ThenByDescending* operator acts as a secondary operator in the descending order; and the *Reverse* operator reverses the order of a collection.

C# provides the *orderby* keyword to implement the *OrderBy* operator. The result of the query containing this operator is of type *IOrderedEnumerable<T>*, which inherits the *IEnumerable<T>* interface. Listing 19.29 shows an example that sorts an array list, which contains the name of employees:

### Listing 19.29: Using the *orderby* Keyword

```csharp
using System;
using System.Linq;
using System.Collections;
using System.Collections.Generic;

class Employee
{
    public static void Main()
    {
        ArrayList empList = new ArrayList();
        empList.Add("Johns");
        empList.Add("Anne");
        empList.Add("Tim");
        empList.Add("Jonathan");
        empList.Add("Tina");

        IOrderedEnumerable<string> empArr = from eName
            in empList.OfType<string>()
            orderby eName
            select eName;

        Console.WriteLine("The sorted array is....");
        foreach (string name in empArr)
        {
            Console.WriteLine(name);
        }
```

In the preceding program, we have first declared an ArrayList that contains the name of employees in a random order. After that, we have written the LINQ query to get the sorted list by using the *orderby* keyword. The result of this operation is then stored in the type *IEnumerable<string>*. The output of the program is given as follows.

```text
The sorted array is....
Anne
Johns
Jonathan
Tim
Tina
```

## Grouping Operators

Grouping operation in LINQ is achieved by using the grouping operators. These operators act similar to the GROUP BY clause in SQL. LINQ has two operators for grouping operation, which are given as follows:

- GroupBy
- ToLookup

C# provides the `groupby` keyword for the GroupBy operator. This operator returns a sequence of the `IGrouping<Key, Value>` object and based on the Key value, the Value field holds the records that match with the Key value. Listing 19.30 illustrates an example of the Grouping operation by using the `groupby` keyword.

### Listing 19.30: Showing an Example of Grouping Operation by using the *groupby* Keyword

```csharp
using System;

                     group emp by emp.empCity into empCityGrp
```

## Set Operators

LINQ supports some of the set operations through the standard LINQ operators. The set operation in LINQ produces the resultant set based on the presence or absence of the equivalent elements within the same or different sets. Let’s learn about the four types of standard LINQ set operations, which are given as follows:

- Union
- Except
- Intersect
- Distinct

The Union operation in LINQ is performed with the help of Union() method. This method takes two sets of elements and returns a set containing the unique elements that appear in both the sets. The Except operation signifies the set difference between two sets that gives a set containing elements of one set that do not appear in the second set. The Except() method is used to carry the set difference operation between two sets. The Intersect operation is achieved with the Intersect() method, which gives a set that contains the common elements in two sets. The Distinct operation removes all the duplicate elements from a set and it is performed using the Distinct() method. Listing 19.32 shows the implementation of all the four operations:

### Listing 19.32: Showing an Example of Union, Except, Intersect, and Distinct Operations

```csharp
using System;
using System.Linq;

class Program
{
    public static void Main()
    {
        int[] set1 = { 1, 2, 3, 4, 5 };
        int[] set2 = { 3, 5, 6, 7, 8 };

        //Union operation
        var resultUnion = set1.Union(set2);

        Console.WriteLine("The result of Union operation is....");
        foreach (int i in resultUnion)
            Console.WriteLine(i);

        //Except operation
        var resultExcept = set1.Except(set2);

        Console.WriteLine("The result of Except operation is....");
        foreach (int i in resultExcept)
            Console.WriteLine(i);

        //Intersection operation
        var resultIntersect = set1.Intersect(set2);

        Console.WriteLine("The result of Intersection operation is....");
        foreach (int i in resultIntersect)
            Console.WriteLine(i);

        //Distinct operation
```
