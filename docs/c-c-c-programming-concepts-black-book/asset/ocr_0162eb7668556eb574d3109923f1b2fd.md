# Handling Derived Class Exceptions

As the argument type of catch applies to the objects of base classes as well as to the classes derived from the base classes, the order of declaring the catch handlers is important. Handlers from the specific derived objects must appear prior to the handlers of base classes. It is also possible to create handlers that would not execute; for example, by placing a handler for any derived class after a handler for its corresponding base class. The following code demonstrates how an exception handler does not execute, as its base class exception handler catches every exception:

```
```cpp
catch(CBaseException& ex)
{
    // Handle a base type of exception
}

catch(CDerivedException& ex)
{
    // This handler would never ‘run’ because its base would catch everything
    // it can
}
```
