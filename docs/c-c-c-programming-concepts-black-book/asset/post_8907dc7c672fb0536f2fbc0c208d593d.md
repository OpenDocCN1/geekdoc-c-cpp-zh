C++ is an extension of the C programming language. It is a derivation from the traditional language in a sense that it follows object-oriented principles, which help in managing large and complex real world problems. C++ was developed by Bjarne Stroustrup at AT&T Bell Labs in the early 1980s. Bjarne Stroustrup started working on "C with Classes" in the year 1979 and in the year 1983, the name "C with Classes" was changed to C++. Since then, C++ is one of the most popular programming languages with a wide variety of application domains including systems software, application software, device drivers, embedded software, high-performance server and client applications, and entertainment software.

In this chapter, we learn about the basic structure of a C++ program by means of programming. We also learn about data types, expressions, operators, and operator precedence in C++. In addition, we learn how to declare a variable as well as how to evaluate an expression in C++. Further, we discuss type conversions, arrays, strings, structures, references, flow control statements, and functions. Towards the end, we explore inline functions, recursive functions, dynamic memory allocation and deallocation operators, and preprocessor directives.

Let’s start the chapter by explaining the structure of a typical C++ program.

### Structure of a C++ Program

In this section, we learn about the structure of a C++ program by writing our first program. The program, which will be called Hello.cpp, prints the Hello World message on the output screen. However, the program does not take any input from a user. Listing 12.1 shows the code of the Hello.cpp file:

**Listing 12.1:** Showing the Code of the Hello.cpp File

```cpp
1: // My first Program in C++
2: #include <iostream>
3: using namespace std;
4:
5: int main ()
6: {
7:   cout << "Hello world.\n";
8:   return 0;
9: }
```

Although, the program is small, yet it contains the fundamental components about the structure of a C++ program. To analyze the program, we have indented each statement of the program with a line number. Let’s examine the program line by line in detail.

Line number 1 is a comment. C++ has introduced a new comment symbol, that is, // . All the lines beginning with the two slash signs are considered as a comment and do not have any effect on the behavior of a program. In C++ programs, this comment symbol is used for single line commenting. This particular comment symbol can start from anywhere in the line and whatever follows, till the end of the line, is ignored by the compiler. Although C++ has this new type of commenting mechanism, the traditional multiline comment (/* comment */) of C language still works in C++ programs.

Line number 2 might look like a statement but it is a directive to the preprocessor (explained later in the chapter); therefore, it does not end with a semicolon. A directive is marked by starting with the # symbol followed by include and filename. It is an instruction from the compiler to the preprocessor to include the iostream standard file before the compiler starts its job. The iostream file contains the declaration of the basic standard input-output library in C++, and is included along with the source program.

Line number 3 contains the namespace declaration. A namespace is a new concept introduced by the ANSI C++ standards committee. Any C++ program can be divided into different namespaces. The namespace declaration specifies that all the statements, which follow this declaration, are within the specified namespace (in our case, std). Various program components, such as cout, are defined within the std namespace. If we do not use the using directive, then we need to append the std name before every program component; for example, std::cout instead of cout.

Line number 5 corresponds to the beginning of the definition of the main() function, which is the entry point for all the C++ programs, irrespective of where it resides in the source code. The word main is followed by a pair of parenthesis, as it is a function declaration. In Listing 12.1, note that the parenthesis of the main() function is empty; however, it can contain two arguments to support command line input arguments.

Line number 6 and line number 9 contain the opening and closing parentheses to specify the scope of the main() function in the program.

Line number 7 causes the Hello World string to be displayed on the output screen. cout is the name of the standard output stream in C++ and the << operator is the insertion or put to operator. The << operator directs the content of the variable in its right to the variable in its left. In our case, it is sending the Hello World string to the standard output device. The character '\n', at the end of Hello World string, is a newline character, which is responsible for inserting a newline character after the string is written on the standard output device as an output.

Line number 8 contains the return statement for the program. The return statement causes the program to finish in this case. A return statement may be followed by a return code; in our case, it is zero. This tells the operating system that the program has executed as expected. A C++ program should normally terminate this way.

### Data Types

Similar to any programming language, C++ also has a list of supported data types. The data types are the allowable types of data members that a program can have along with the type of values that can be assigned to them during program execution. Every data member in a C++ program can be either from the predefined set of data types or from the custom or user-defined data types. In C++, data types can be classified into various categories, as shown in Figure 12.1:

**Figure 12.1: Displaying the Various Categories of C++ Data Types**

Similar to the C compiler, C++ compiler also supports all the basic built-in data types. With the exception of void data type, most of the other basic data types can be modified by applying modifiers, such as signed, unsigned, long, and short. All the four modifiers can be applied to an integer data type; whereas, only signed and unsigned modifiers can be applied to char data types. We can also increase the size and capacity of a double data type by preceding its definition by the keyword long.

Data representation is machine specific, and depending on which machine the program is running, the basic data types set their size. We have intentionally kept the void data type out of scope from Table 12.1 because it is different from other data types. The void data type was introduced in ANSI C, and was primarily used to specify the return type of a function that has nothing to return as well as to indicate an empty argument or parameter list to a function. However, with C++, the functionality of void was enhanced by introducing a new concept called void pointer. C++ started using void as a generic pointer by specifying the following format:

```cpp
void *generic_ptr;
```

A generic pointer can be assigned a pointer value of any data type, but it might not be dereferenced directly, as shown in the following code snippet:

```cpp
int *int_ptr;              // Declare an integer pointer
void *generic_ptr;         // Declare a generic pointer of void * type
generic_ptr = int_ptr;     // Legal assignment
*int_ptr = *generic_ptr;   // Illegal, as dereferencing is not supported on
                           // void ptr
```

The preceding code snippet shows the unsupported and supported operations of a void pointer. However, we should be careful while implementing void pointers in real life programs, because one very common mistake in C++ programming is to dereference a void pointer, which is not allowed in C++.
