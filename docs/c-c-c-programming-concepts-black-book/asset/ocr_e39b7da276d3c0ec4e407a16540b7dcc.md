# # Infix, Prefix, and Postfix Notations

An expression comprises operands and operators. Depending on an expression, we can tell the compiler which expression to execute first and which one to execute at the end. To write an expression, we can use the following three types of notations:

+   - **Infix Notation**—In this type of notation, an operator is placed in between the two operands. If A and B are the two operands and we want to write an infix expression for addition, then we can do this as follows:

A + B

To specify the order of execution, infix notation uses the brackets to manipulate the precedence of the execution. For example, consider the following two expressions:

A + B * C

(A + B) * C

For the first expression, B * C is evaluated first, as multiplication comes first in operator precedence. After that, addition takes place. However, in the second expression, the addition operation is executed first, as we have embraced the expression with the braces, thereby, increasing the precedence of execution. After executing the addition operation, the multiplication operation takes place.

+   - **Prefix Notation**—In this type of notation, operators are written before their operands. The operators are evaluated from left to right and they act on the two nearest values on the right. If we want to add the A and B operands, then the prefix notation would be as follows:

+ AB

The prefix notation is also known as the Polish notation.
