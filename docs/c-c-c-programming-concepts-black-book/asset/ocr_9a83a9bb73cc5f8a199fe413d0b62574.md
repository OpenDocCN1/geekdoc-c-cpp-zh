# isalpha()

The isalpha() function returns a non-zero value when a letter or an alphabet is passed as an argument to it; otherwise, the function returns zero. The signature of the isalpha() function is as follows:

```
```c
int isalpha(int ch);
```
```

Listing 8.39: Usage of isalpha() function.

# iscntrl()

The iscntrl() function returns a non-zero value if the argument passed to it is a control character; otherwise, the function returns zero. In an American Standard Code for Information Interchange (ASCII) environment, the control character is a value between zero and 0x1F, or a value that is equal to 0x7F (DEL). The signature of the iscntrl() function is as follows:

```
```c
int iscntrl(int ch);
```
