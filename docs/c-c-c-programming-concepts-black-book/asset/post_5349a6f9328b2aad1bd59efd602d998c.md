## Unary Operators

Operators that act upon a single operand to produce a value are called unary operators. Unary operators generally precede their operands though some of them are also often written after their operands. The most common unary operator used in C is unary minus. A negative number is declared in C by preceding the number with a unary minus operator. A subtraction operation requires two operands for its working; whereas, a unary minus only operates on a single operand.

For example, -5 becomes a negative numeric constant with a unary minus preceding it.

Apart from unary minus, the two most commonly-used operators are the increment operator and the decrement operator.

## Increment Operator

The increment operator in C is denoted by the ++ sign. The increment operator causes the value of the variable to increase by one. The operand used with these operators must be a single variable.

Consider the following statement:

```c
x = x + 1;
```

The preceding statement can also be written by using an increment operator as follows:

```c
x++;
```

We can say that the increment operator is a shorthand representation of assigning and incrementing the value inside x.

Two types of increment operations can be done on a variable. One is called the pre-increment operation and the other is called the post-increment operation.

**Listing 1.4:** Post- and Pre-Increment Operators

```c
#include<stdio.h>

int main()
{
    int a=10;
    a++;
    printf(" A %d ",a);
    getch();
}
```

The output of Listing 1.4 will come out to be 11, as we have used an increment operator. If the operator is altered from a++ to ++a, still the output will remain the same. Then, what is the use of having two different types of increment operators? Listings 1.5 and 1.6 clarify this difference:

Listing 1.5 shows the working of the post increment operator:

**Listing 1.5: Working of the Post Increment Operator**

```c
    #include<stdio.h>

    int main()
    {
        int a=10;
        printf(" a %d ",a++);
        getch();
        return 0;
    }
```

The output of Listing 1.5 will come out to be 10 instead of 11.

Listing 1.6 shows the same code altered to a pre increment operation:

**Listing 1.6: Working of the Pre Increment Operator**

```c
    #include<stdio.h>

    int main()
    {
        int a=10;
        printf(" A %d ",++a);
        getch();
    }
```

In this case, the output becomes 11, as the post-increment operation has a lower precedence compared to the pre-increment operation. When we use the print statement along with the post increment operator, first the original value inside the variable gets displayed and later the value is incremented; therefore, we do not get the updated value. On the other hand, in the pre-increment operation, the value contained inside the variable first gets incremented by one and thereafter all the succeeding operations take place. This is why we get an updated display with a pre-increment operation. We will deal with some more examples of pre- and post-increment operations later in this chapter.

## Decrement Operator

The decrement operator in C is denoted by the “--” sign. The basic working of a decrement operator is similar to that of an increment operator, with the difference that a decrement operator decreases the value of a variable by one. A decrement operator can also be used as a post-decrement and pre-decrement operator.

## Statements in C

A statement in C refers to some action or group of actions carried out by a compiler. In C, there are three different classes of statements — expression statement, compound statement, and control statement. An expression statement consists of an expression followed by a semicolon. The execution of an expression statement causes the expression to be evaluated. For example, `c = a + b` can be treated as an expression statement, as it causes the expression at the right hand side of the assignment statement to be evaluated and assigned to the variable at the left hand side. Multiple individual statements inside a single block are treated as compound statements; whereas, individual statements can be either expression statements, control statements, or compound statements. Compound statements enable embedding statements within statements. Unlike expression statements, compound statements do not end in semicolon.

The following code represents an example of a compound statement:

```c
{
    a = 10;
    b = 10;
    c = a + b;
    printf("\n Result [%d]", c);
}
```

## Decision Making

Decision making refers to the ability of a programming language to perform different sets of actions based on certain decisions. The major decision making modules in C are `if`, `if else`, and `else statements`. Apart from these, other statements like the `switch case` also help in making decisions; however, in this chapter, we will primarily be discussing the `if`, `if else`, and `else statements`.

### The IF Statement

Like all other programming languages, C also uses the `if` statement for decision making. Moreover, `if` is also referred as a keyword in C. The general form of the `if` statement is:

```c
if(expression happens to be true)
    perform certain actions;
```

When an `if` statement is encountered by a compiler, it knows that a decision making needs to be done. The `if` statement always executes the statements that are enclosed within the `if` block.

**Listing 1.7:** Writing the if statement in C

```c
#include<stdio.h>

int main()
{
    int varA = 10;

    if(varA == 10)
        printf("\n Statement is true ");

    getch();
}
```

The code given in Listing 1.7 shows the working of the `if` statement. The expression given inside the `if` statement is evaluated with the help of relational operators. Table 1.7 lists different relational operators used in C:

| --- | --- |
| X == Y | X is equal to Y |
| X != Y | X is not equal to Y |
| X <= Y | X is smaller than or equal to Y |
| X < Y | X is smaller than Y |
| X >= Y | X is greater than or equal to Y |
| X > Y | X is greater than Y |

### Different Types of the IF Expression

We can provide different sorts of expressions inside an if statement. Note that it is not mandatory to have relational operations taking place in an if statement. The following are some examples of valid if statements:

```c
1.  if(5+4>3)
    printf("\n This is valid");
2.  if(varA == 10)
    printf("\n This is valid");
3.  if(-5)
    printf("\n This is valid");
```

In C language, a non-zero value is considered to be true and zero as false. The if statement only works if the expression provided evaluates to a true value. In the first example, a logical computation is taking place, yielding a non-zero result. In the second example, a positive value is assigned to the variable varA. After assignment, the value of the variable is tested, as the variable contains a non-zero value. The same condition is applied for negative values, as shown in the third example.

### Multiple IF Statements

It is possible to have multiple statements inside an if statement. For this, a group of statements needs to be placed within a pair of curly braces. If curly braces are not provided, then the if clause will take up only a single statement and the rest will be ignored.

**Listing 1.8: Writing Multiple IF Statements**

```c
#include<stdio.h>

int main()
{
        int varA;
        printf("\n Enter a integer ");
        scanf("%d",&varA);

        if(varA > 10)
                printf("\n Statement is true ");
                printf("\n Inside IF ");
        getch();
}
```

The output of Listing 1.8 is given as follows:

```text
    Enter a integer 5

        Inside IF
```

In Listing 1.8, we have given multiple statements inside a single if statement. As no parenthesis are used in the code, all the statements are not considered as part of the if statement.
