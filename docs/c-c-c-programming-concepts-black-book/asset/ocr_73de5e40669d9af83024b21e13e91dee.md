# Queue

The queue operation is just the opposite of the stack operation. A queue has its front end and rear end. When an element is inserted into the queue, it is inserted from the rear end; whereas, when an element is deleted from the queue, it is deleted from the front end. This emphasizes the First in First Out (FIFO) operation. In C#, the Queue class performs the insert and delete operations using the two methods, Enqueue() and Dequeue(), respectively. Listing 17.28 shows the usage of the Queue class.
