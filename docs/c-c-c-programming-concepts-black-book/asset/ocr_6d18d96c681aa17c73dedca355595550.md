If the size of data is not fixed or it fluctuates widely during the stack’s lifetime, then an array is a poor choice for implementing a stack. To overcome this, we can implement a stack using either the pointers or the linked lists. Listing 24.8 shows the implementation of a stack using a linked list:

# Listing 24.8: Implementing a Stack using a Linked List

#include <stdlib.h>

int pop(void);

    p1 = stack; /* initialize p1 */
