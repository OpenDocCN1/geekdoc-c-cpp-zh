# ## Overriding Member Functions

We can use member functions in a derived class having the same name as in a base class. Generally, a derived class inherits all the member data variables and functions of its base class. Now, if the derived class also has a member function sharing the same name as that of the one in the base class, then the member function in the derived class overrides the one in the base class. Therefore, when an object of the base class calls the member function, the base class copy of the member function is executed; whereas, when the object of the derived class calls the member function, the member function of the derived class is called. This typical phenomenon is known as function overriding.
