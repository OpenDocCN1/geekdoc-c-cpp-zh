Computer is a machine to store, manipulate, and retrieve the data. However, all these operations depend on how the data is represented or on how the data is organized in the memory. Therefore, in computer science, a study regarding different types of organization of the data has been included, which is known as data structure. In other words, data structure is a way of storing and organizing the data in the memory or the disk storage. Data structure represents a logical or mathematical model of data storage using which we can efficiently use the data in our applications.

After developing a data structure, the next step that we need to focus on is how to insert a data, search for a specific data, or delete a specific data from the data structure. In this case, algorithms come in rescue, as they provide a way to manipulate the data by developing different techniques of accessing and modifying the data inside the data structure.

In this chapter, we learn about data structures and algorithms, in detail. First, the chapter discusses abstract data type, the infix, prefix, and postfix notations, complexity of an algorithm, and algorithm case analysis. Then, we learn about linked list, stack, queue, tree, and various sorting techniques. Further, the chapter discusses sequential search, binary search, hashing, and graphs. After that, we learn about spanning tree algorithms, minimum spanning tree, the Dijkstra's algorithm, and the Floyd's algorithm.

### Data Structures

As already learned, data structure provides a way of storing data in the computer memory. Computer memory may store the data in a sequential manner or it may store the data depending on some specific pattern. Following are the two types of data structures:

- **Linear data structure**—It forms a sequence of elements or a linear list. Following is a list of linear data structures:
  - 1. Array
  - 2. Stack
  - 3. Queue
  - 4. Linked list
- **Non-linear data structure**—It represents the data in a hierarchical manner. Following is a list of non-linear data structures:
  - 1. Tree
  - 2. Graph

### Infix, Prefix, and Postfix Notations

An expression comprises operands and operators. Depending on an expression, we can tell the compiler which expression to execute first and which one to execute at the end. To write an expression, we can use the following three types of notations:

- **Infix Notation**—In this type of notation, an operator is placed in between the two operands. If A and B are the two operands and we want to write an infix expression for addition, then we can do this as follows:

  A + B

  To specify the order of execution, infix notation uses the brackets to manipulate the precedence of the execution. For example, consider the following two expressions:

  A + B * C

  (A + B) * C

  For the first expression, B * C is evaluated first, as multiplication comes first in operator precedence. After that, addition takes place. However, in the second expression, the addition operation is executed first, as we have embraced the expression with the braces, thereby, increasing the precedence of execution. After executing the addition operation, the multiplication operation takes place.

- **Prefix Notation**—In this type of notation, operators are written before their operands. The operators are evaluated from left to right and they act on the two nearest values on the right. If we want to add the A and B operands, then the prefix notation would be as follows:

  + AB

  The prefix notation is also known as the Polish notation.
