Abstract classes contain one or more abstract methods. Such a method can only be declared, but cannot be implemented. Abstract classes require subclasses, which provide the implementation techniques for the abstract methods that are declared in the abstract classes.

Let’s consider an example of animals. Animals perform some common operations, such as eating, making noise, and running, but all in different ways. For instance, a dog barks, but a cat meows. Therefore, the Animal class is a perfect ADT.

Consider the following code for the Animal class:

```
```cpp
class Animal
{
    public void makeSomeNoise()
    {
    }
};
```
```

In the preceding code, we have declared Animal as an abstract class, which contains an abstract method called makeSomeNoise(). Now, if we want to create an instance of the Animal class, then it needs to be instantiated as well as implement the makeSomeNoise() method.

Consider the following code for the dog class:

```
```cpp
class dog : public Animal
{
public:
    void makeSomeNoise()
    {
        cout << “Bark !!!....” << endl;
    }
};
```
```

In the preceding code, we have created the *dog* class as an instance of the *Animal* class. The *makeSomeNoise()* method is also implemented by the *dog* class. Therefore, it is important to note that an abstract class is designed to be specifically used as a base class.
