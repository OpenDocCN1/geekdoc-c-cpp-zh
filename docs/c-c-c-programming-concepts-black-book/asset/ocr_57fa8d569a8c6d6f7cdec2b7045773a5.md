# # Value Type

Unlike reference type, value type holds the value of the objects. Whenever a value type is assigned to another value type, its value is copied but not the reference. Structures and enumerators are some of the examples of value type. Listing 17.32 shows the value type operation with the help of a structure type.

Listing 17.32: Showing the Usage of Structure Value Type

```
```csharp
using System;
struct Employee
{
    private int id;
    public int ID
    {
        get { return id; }
        set { id = value; }
    }
}
class Program
{
    static void Main()
    {
        Employee e1 = new Employee();
        e1.ID = 71;
        Employee e2 = new Employee();
        e2.ID = 59;
        Console.WriteLine("Name of the employees before assignment...");
        Console.WriteLine("Employee ID = " + e1.ID);
        Console.WriteLine("Employee ID = " + e2.ID);
        // assign e2 value to e1 variable
        e1 = e2;
        Console.WriteLine();
        Console.WriteLine("Name of the employees after assignment...");
        Console.WriteLine("Employee ID = " + e1.ID);
        Console.WriteLine("Employee ID = " + e2.ID);
        e2.ID = 65;
        Console.WriteLine();
        Console.WriteLine("Values After Changing One Instance:");
        Console.WriteLine("Employee ID = " + e1.ID);
        Console.WriteLine("Employee ID = " + e2.ID);
    }
}
```
```

In the preceding program, we have first defined a structure named Employee that holds the employee ID only. Then, we have created two objects, e1 and e2, of the Employee structure and assigned the values to the ID variable of each object. When we print these values, they will show their exact values. After that, we have assigned e2 to e1. In this case, the value of e2 is copied to the value of e1. Therefore, e1 and e2 both print the value of e2. Next, we have again modified the value of ID for e2. In addition, the old ID value of e1 is printed and the value of e2 is modified. This implies that the value of e1 does not modify on changing the value of e2, which demonstrate that value type holds the distinct copies of their objects.

The output of the program is given as follows:

```
```text
Name of the employees before assignment...
Employee ID = 71
Employee ID = 59
Name of the employees after assignment...
Employee ID = 59
```
