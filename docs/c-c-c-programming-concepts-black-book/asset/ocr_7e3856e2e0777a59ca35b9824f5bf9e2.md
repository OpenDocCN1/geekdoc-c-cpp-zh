# ## abs()

The `abs()` function returns the absolute value of a number. The signature of the `abs()` function is as follows:

```
~~~c
int abs(int num);
~~~
```

In the older versions of the C compiler, we need to include the `<stdlib.h>` header to use the `abs()` function; however, in the recent C compilers, the function is available within the `<stdio.h>` header. Let's take an example of the `abs()` function as mentioned in Listing 8.27:

Listing 8.27: Usage of abs() function.

```
~~~c
#include<stdio.h>

int main()
{
    int varA = -89;

    printf("\n the absolute value of %d is %d ",varA, abs(varA));

    getch();

    return 0;
}
~~~
```

Output of the preceding example is as follows:

```
~~~
The absolute value of -89 is 89
~~~
```

# ## atoi()

The `atoi()` function converts a string to an integer value. The string passed as an argument to the function must contain a valid integer number. The signature of the `atoi()` function is as follows:

```
~~~c
int atoi(const char *str);
~~~
```

In case of any error, the value returned by the `atoi()` function is undefined. If the `atoi()` function is called with an argument, such as 50.76, then the function returns 50 and .76 is ignored.

Listing 8.28: Usage of atoi() function.

```
~~~c
#include<stdio.h>

int main()
{
    char inputString[20];

    printf("\n Enter a number -> ");

    gets(inputString);

    printf("\n The value returned by atoi function is %d ",atoi(inputString));
    getch();

    return 0;
}
~~~
```

Output of the preceding example is as follows:

```
~~~
Enter a number -> 98.563
The value returned by atoi function is 98
~~~
```
