
**Listing 1.38: Using Return Statements in C**

```c
#include<stdio.h>
int main()
{
    printf("\n Hello world");
    return 0;
}
```

Listing 1.38 shows the simplest way of using a return statement. As mentioned earlier, a return statement can only be associated with a value if the return type of the function is non-void. The main function declared above has the return type of int. So, we have to provide a return statement which has a dummy return type of 0.

Listing 1.39 uses multiple return statements in the same function:

**Listing 1.39: Usage of Multiple Return Statements**

```c
#include<stdio.h>
int main()
{
    int i,sum=0,varA;
    char answer;
    for(;;)
    {
        printf("\n Enter an integer - ");
        scanf("%d",&varA);

}
```

Listing 1.39 shows how a function can have multiple return statements, which can be executed conditionally based on certain situations. We have created an infinite for loop which is going to run till it gets certain input from the user. The input makes the internal return statement to get executed. Once the internal return statement is executed, the control automatically comes out of the function. We will have a detailed insight into return statements in subsequent chapters.

## The GOTO Statement

The GOTO statement is used to jump from one line of code to another. Executing a goto statement is just executing any other jump statement where we specify the address of the memory location where the next instruction will be fetched from. A general form of the goto statement would look like as follows:

```c
goto label;
.
.
.
.
.
label:
```

Where label is a valid line either before or after the goto statement where we want our control to get shifted. The label must be inside the same function where the goto statement is mentioned. We cannot jump between functions using a goto statement.

Listing 1.40 shows an example of the goto statement:

**Listing 1.40: GOTO Statement**

```c
#include<stdio.h>
int main()
{
    int i,j,k,sum=0;
    for(i=1;i<=10;i++)
    {
        for(j=1;j<=10;j++)
        {
            for(k=1;k<=10;k++)
            {
                if((i <= j) && ( j <= k))
                {
                    sum = sum + i + j + k;
                }
                else
                {
                    goto label;
                }
            }
        }
    }
    label:
    printf("\n The sum is %d ",sum);
    getch();
    return 0;
}
```

Listing 1.40 shows the application of a goto statement. In this case, goto is used to jump out of a nested loop. We have used a three layered nested loop and based on certain conditions, we are using the goto statement to come directly out of the three layered loop. The moment the if condition inside the loop becomes false, the goto statement gets executed. After execution, the control will come to the line following the label, which in our case happens to be the printf statement that is used to display the sum.

## The BREAK Statement

Apart from the goto statement, one can jump from one segment to another by using the break statement. However, break is generally associated with loops only. Whenever a break statement is encountered inside a loop, the control shifts to the next statement following the loop. A loop could be terminated unconditionally using the break statement.

Listing 1.41 shows implementation of the break statement:

**Listing 1.41: Break Statement**

```c
#include<stdio.h>
int main()
{
    int i=1;
    while(1)
    {
        printf("\n I = %d ",i);
        i++;
        if(i > 50)
            break;
    }
    getch();
}
```

Listing 1.41 shows an infinite while loop that will keep on executing endlessly. We have used a break statement conditionally inside the body of the while loop. When the condition becomes true, the break statement gets executed and the control shifts to the next statement following the while loop. The code will display values from 1 to 50 and after that the loop will terminate. The break statement only shifts control from the loop which contains the statement inside its body.

Listing 1.42 shows another example of break statements in C:

**Listing 1.42: Break Statements in C**

```c
#include<stdio.h>
int main()
{
    int i=1,k;
    while(i < 10)
    {
        for(k=0;k<100;k++)
        {
            printf("\n k %d",k);
            if(k > 39)
                break;
        }
        i++;
    }
    getch();
}
```

In Listing 1.42, two nested loops are used. The outer one is a while loop that will range from 0 to 9 and the inner one is the for loop that will go on from 0 to 100. We have used a break statement inside the body of the inner loop. When the value of the loop control variable (over here k) becomes 41, the test condition returns true; hence, the break statement gets executed. However, the statement only shifts the control from the innermost for loop to the outer “while” loop, which gets executed.

## The Continue Statement

The continue statement works somewhat similar to the break statement with the major difference that the continue statement does not take the control out of the loop. Instead, it only skips the current iteration and execution of all the statements that follows it inside the body of the loop.

Listing 1.43 shows the usage of the continue statement:

**Listing 1.43: Continue Statement**

```c
#include<stdio.h>
int main()
{
    int i=1;
    while(i < 100)
    {
        i++;
        if(i >= 15)
            continue;
        printf("\n i %d ",i);
    }
    getch();
}
```

The output of Listing 1.43 is given as follows:

```
I 2
I 3
I 4
I 5
I 6
I 7
I 8
I 9
I 10
I 11
I 12
I 13
I 14
```

In Listing 1.43, we are using the continue statement conditionally inside the body of the while loop. As the output suggests, when the test condition becomes true, the continue statement is executed and the statements following it are skipped for that iteration. The display takes place only for 14 iterations. The moment the value of "I" becomes 15, the test condition becomes true and the printf statement is not executed for successive iterations.
