Besides this, one of the major flexibilities that this language provides is the freedom of defining your own functions, which can be used for carrying out multiple user-defined tasks. Functions allow users to modularize their code into a number of smaller components, each having a unique task to perform. One of the major aspects of using functions is code reusability. Consider a scenario where a user needs to perform a task repeatedly. Writing same lines of code multiple times cannot be a proper solution in such a case. The instructions that need to be carried out repeatedly can be placed inside a single function. This function can then be used from various parts of the code.

Another aspect of writing functions is the enhancement in the logical clarity of the code. Decomposing code into numerous logical components where each component is used for a dedicated purpose not only increases clarity but also makes the code easy to debug. Therefore, modularizing the code by introducing more and more functions in it is considered a good practice. The use of functions also enables a user to build a customized library of all the functions that can be stored separately in different library files. These files can be used by programs at the compilation stage. In addition, inclusion of functions inside common place holders, such as library files increases the portability of code.

# # A Brief Overview of Functions

A function can be described as a self-contained block of statements that can perform a specific task. Every C program consists of one or more functions, one of which is called the main function. As we have discussed in the previous chapter, the execution of a program always starts with the execution of the statements inside the main function. A program may contain multiple functions; however, all of them must be independent of one another. Major activities of a function can be broken down into three parts:

+   - Function declaration
+   - Function definition
+   - Function call

A function carries out the intended action whenever it is called from a part of the main code. You should note that the same function can be called from different parts of the main code. Once the function completes executing the intended action, it goes back to the location from where it was called.
