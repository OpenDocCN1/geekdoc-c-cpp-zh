### 双向链表

在双向链表中，相邻节点之间在两个方向上均存在指针。因此，这种链表可以双向遍历。我们维护两个指针来跟踪双向链表——*头* 和 *尾*。由于双向链表允许在两个方向上进行顺序访问，因此它比线性链表或循环链表更易于操作。图 24.5 展示了一个双向链表：
