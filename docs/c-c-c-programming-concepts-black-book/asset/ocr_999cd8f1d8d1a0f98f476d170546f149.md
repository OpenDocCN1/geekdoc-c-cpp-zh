# ### Defining Shared Members

Shared members are the class members for which we do not need to create an instance of a class. These members are static in nature. For example, when we use the Math class, we do not need to create an object of the Math class to access the Abs() method, which calculates the absolute value of a given number. Code snippet for this operation is given as follows:

```
~~~csharp
long result = Math.Abs(10000.9090);
~~~
```

However, when we refer the non-static class DateTime, we need to create an object of that class, as follows:

```
~~~csharp
DateTime dateTime = new DateTime();
int day = dateTime.Day();
~~~
```

**Listing 18.11** shows an example of the shared member:

```
~~~csharp
class Program
{
    public static void Main()
    {
        int result = Add.Addition(10, 20);
        Console.WriteLine("The result is {0}", result);
    }
}
class Add
{
    public static int Addition(int item1, int item2)
    {
        return (item1 + item2);
    }
}
~~~
```

In the preceding code, we have defined a class *Add* that contains a static member method called *Addition* to add two integers. In the Main() method, we have called the Addition() method without declaring the class object. The output of the preceding code is given as follows:

```
~~~
The result is 30
~~~
```
