## Error Handling

When we execute a code, it might happen that the code fails due to some data error and the execution of the ongoing process stops at runtime. To deal with this anomalous situation at runtime, C# provides a built-in support mechanism, which is known as exception handling. Exception is an unwanted behavior of a code at runtime, which leads to the termination of the execution process. Therefore, we need to ensure that our code does not fail during runtime. Rather than checking the code repeatedly for the error, it is better to handle an exception using the try-catch mechanism provided by C#.

In the try-catch mechanism, the code, which may generate the error at runtime, resides inside the try block and when an error occurs, the error is handled in the catch block. Listing 19.40 shows the structure of try-catch block:

### Listing 19.40: Showing the Structure of try-catch Block

```csharp
using System;
class Program
{
    public static void Main()
    {
        try
        {
            //write the code block that may generate an error
        }
        catch (Exception A)
        {
            //Handle the exception
        }
    }
}
```

We may also define more than one catch block for a single try block. Note that it is a good practice to arrange more than one catch block from a specific type to a generic type. Listing 19.41 shows a try block with multiple catch blocks:

### Listing 19.41: Showing a Different Structure of try-catch Block

```csharp
using System;
class Program
{
    public static void Main()
    {
        try
        {
            //write the code block that may generate an error
        }
        catch (ApplicationException aEx)
        {
            //Handle the application exceptions
        }
        catch (Exception ex)
        {
            //Handle the generic exceptions
        }
    }
}
```

In addition to the try-catch block, C# provides a finally block that is executed regardless of how the try block exits. Therefore, when the control flow reaches the end of the execution, the finally block is executed. In addition, the finally block is executed even after an error is handled in a catch block. The finally block is mainly used for:

- Avoiding the duplication of a statement.
- Releasing the resources after an exception is handled. For example, if an exception occurs while processing a data from the database, then the *finally* block can contain the code for terminating the database connection.
- Assigning a value to an object.
- Displaying a message that is useful for a user.

It is a good practice to write a finally block when we want to concentrate on the code performance. Listing 19.42 shows the structure of try-catch-finally block.

### Listing 19.42: Showing the Structure of try-catch-finally Block

```csharp
using System;

class Program
{
    public static void Main()
    {
        try
        {
            //write the code block that may generate an error
        }
        catch (Exception ex)
        {
            //Handle the exceptions
        }
        finally
        {
            //write the finally statement
        }
    }
}
```

Now, let’s write a small code in C# to understand the usage of try-catch block. Listing 19.43 shows the code snippet explaining the code behavior when an exception occurs:

### Listing 19.43: Showing the Implementation of try-catch Block

```csharp
using System;

class Program
{
    public static void Main()
    {
        try
        {
            Console.WriteLine("Enter the first number:");
            int num1 = Convert.ToInt32(Console.ReadLine());

            Console.WriteLine("Enter the second number:");
            int num2 = Convert.ToInt32(Console.ReadLine());
            int div = num1 / num2;
            Console.WriteLine("The result of division is {0}", div);
        }
        catch (Exception ex)
        {
            Console.WriteLine("Exception occurred!!!");
            Console.WriteLine(ex.Message);
        }
    }
}
```

The preceding program accepts two integers, num1 and num2. The output of the program is given as follows:

```text
Enter the first number:
5
Enter the second number:
0
Exception occurred!!!
Attempted to divide by zero.
```

We have provided the first integer as 5 and the second integer as 0. On dividing 5 by 0, the compiler would throw an exception, as 5 cannot be divided by 0. Therefore, when an exception occurs in the try block, the control of the program is transferred to the catch block.
