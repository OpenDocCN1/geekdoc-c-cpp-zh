Listing 4.6 shows the traversal in a single dimensional array using pointers:

**Listing 4.6:** Showing the Traversal in Single Dimensional Array using Pointers

```
```c
# include<stdio.h>

void show_value(int *value, int range);

int main()
{
    int arr[5]={1,2,3,4,5};
    show_value(&arr[0],5);
}

void show_value(int *value,int range)
{
    int i;

    for(i=0;i < range ;i++)
    {
        printf("\n value -> [%d] ",*(value+i));
    }
}
```
```

In Listing 4.6, we have passed the base address of the array (that is, address of arr[0]) to the show_value() function. For traversing, we have incremented the base address by one and displayed the value at that memory location.

The nomenclature in C is such that indexing in an array starts from the 0th location; therefore, the following two code snippets give the same result:

```
```c
int *ptr = &a[0]
int *ptr = a;
```
```

While compiling the a[i] expression, the compiler first converts it to *(a+i); therefore, the expression that uses array indexing becomes equivalent to a pointer and an offset expression.

# Two-Dimensional Arrays using Pointers

A two-dimensional array is nothing but a collection of single dimensional arrays. Following is an example of how to define a two-dimensional array syntactically:

int arr[2][3];
```
```

In the preceding example, the first subscript of the two-dimensional array is called the row number and the second subscript is called the column number. This two-dimensional array can be thought of as a single dimensional array of two elements where each element is again a single dimensional array of three elements.
