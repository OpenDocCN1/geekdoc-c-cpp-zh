# Table 15.6: Frequently Used Manipulators

| Manipulator | Effect |
|---|---|
| setw (int w) | Sets the field width to w |
| setprecision (int d) | Sets the floating-point precision to d |
| setiosflags (long f) | Sets the format flag f |
| resetiosflags (long f) | Clears the specified flag |
| endl | Inserts newline and flush stream |
| flush | Flushes stream buffer |
| ends | Inserts an end of string character |
| ws | Skips whitespaces |
| boolalpha | Puts bool values in alphabetic format |
| noboolalpha | Resets boolalpha |
| showbase | Generates a prefix indicating the numeric base of an integer |
| noshowbase | Resets the showbase |
| showpoint | Generates a decimal point for floating-point values |
| noshowpoint | Resets showpoint |
| showpos | Generates a + sign for non-negative numeric values |
| noshowpos | Resets showpos |
| skipws | Skips leading whitespace |
| noskipws | Resets skipws |
| uppercase | Replaces certain lowercase letters with their uppercase equivalents |
| nouppercase | Resets uppercase |
| unitbuf | Flushes output after each formatting operation |
| nounitbuf | Resets unitbuf |
| internal | Adds fill characters at designated internal point |
| left | Adds fill characters for adjustment to the left |
| right | Adds fill characters for adjustment to the right |
| dec | Converts integers to/from decimal notation |
| hex | Converts integers to/from hexadecimal notation |
| oct | Converts integers to/from octal notation |
| fixed | Puts floating-point values in fixed point notation |
| scientific | Puts floating-point values in scientific notation |
| setbase(int base) | Sets the base for integer notation (base = 8, 10, 16) |
| setfill(char c) | Sets the fill character for padding |
