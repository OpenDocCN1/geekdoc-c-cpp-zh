To set the cancel state of a thread, we can use the following API:

```
int pthread_setcancelstate (int state, int *oldstate);
```

The preceding API sets the new cancel state and returns the old cancel state. Similarly, for setting the cancel type of a thread, we can use the following API:

```
int pthread_setcanceltype (int type, int *oldType);
```

The preceding API sets the new cancel type and returns the old cancel type.

Now, to set a cancellation point in a synchronously cancellable thread, we need to call pthread_testcancel().
The cancellation point will process a pending cancellation request. The syntax for setting a cancellation point
in a synchronously cancellable thread is as follows:

```
void pthread_testcancel (void);
```
