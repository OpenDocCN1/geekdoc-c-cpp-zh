### Brief History of C

The development process of an older language called Basic Combined Programming Language (BCPL) led to the evolution of C. BCPL was developed by Martin Richards. Later, Ken Thompson developed BCPL into a more structured language called B. Ultimately, B led to the development of C in the 1970s by Dennis Ritchie. The standardization process of C took six years. The ANSI C standard was first started in December 1989. The standard was also adopted by International Standards Organization (ISO) in 1990 and was named ANSI/ISO standard for C. In 1995, the Amendment 1 to the C standard was published, resulting in the inclusion of several new library functions. The version of C defined in 1989 was commonly referred to as C89. This became a base document of the Standard in C++. In 1999, a new standard of C evolved which was commonly called as C99. It retained most of the things of C89. The C99 standard mainly focused on a few new concepts:

- i. The addition of numerous numeric libraries
- ii. Variable length arrays
- iii. The restrict pointer qualifiers

### C as a Middle Level Language

Is C a middle-level language? The answer is Yes. However, this does not mean that it is harder to use or it is not developed enough. C is called a middle-level language as it combines the best features of a high-level language with the flexibility of an assembly-level language. Being a middle-level language, C allows the freedom of manipulating with bits, bytes, and addresses. C is also very portable and can adapt to any operating system. Despite having many built in data types, it is a highly typed language. It permits all type conversions, for example, it allows you to combine characters and integer data types in a single expression. C has got another advantage of not demanding strict type compatibility between a parameter and an argument, as long as the argument can be converted into the data type of the parameter. As C allows the manipulation of bits, bytes, and pointers, it is very suitable as a system-level language. C has also got a very small number of keywords. C89 introduced 32 keywords, and with the evolution of C99, 5 more keywords were added to it. BASIC has got more than 100 keywords in comparison to 37 keywords of C.

### C as a Structured Language

C is very much a structured programming language, as it allows a program to be broken into loops (e.g. for, while, and do-while loops), if-else blocks, functions, and procedures. C is not regarded as a block structured language, as it does not allow a procedure or function to be declared inside another procedure or function. The following code snippet shows an example of a structured block in C:

```c
if ( i < 10)
{
    printf(" X");
    scanf("%d", &i);
}
```

The preceding code snippet shows that the two statements within the curly braces form a single unit, which would be executed if ‘i’ is less than 10.

To conclude, the main feature of any structured language is that its code or data can be compartmentalized. It allows a block of code to differentiate itself and hide itself from the rest of the program. One of the ways to achieve this is to use functions (the main structural components of C) and local variables inside that code.

### Writing your First C Program

A program consists of one or multiple modules called functions. One of the functions that needs to be always present in a C program is the main function. A program always starts with the execution of the main function and all the other functions are subsequently called from the main function. Function definitions must be declared separately whether before or after the main function. Each function must contain:

- A function heading that defines the name of the function. It is followed by a list of arguments, which forms the parameter list for that function. The list of parameters is enclosed inside parentheses. This list of parameters can also be empty.
- An argument list.
- A compound statement, which forms the rest of the function.

Arguments represent information that is being passed from one function to another. Each compound statement must be enclosed within a pair of curly braces {}. A compound statement can be nested within another. Each statement must terminate with a semicolon.

Listing 1.1 shows a simple C program:

Listing 1.1: Showing a Simple C Program

```c
/* Writing first C program */

#include<stdio.h>       // Header File Inclusion

main()                  // Defining main function
{                       // Beginning of function
    int test;           // Variable Declaration

    printf("Enter a number ");  // Output Statement
    scanf("%d", &test);         // Input Statement

}                       // End of Function
```

In Listing 1.1, you can notice the following things:

- The program is written in lower case, which is a standard convention for writing programs in C.
- The first line of the program indicates a comment. Use of comments in C increases the readability of the code. There are two standard ways of writing comments in C. Originally, only /* and */ were used for writing comments. However, with the advent of C99 version, we can also use the // sign to write single-line comments.
- The second line tells us about the inclusion of a special file (stdio.h) that contains the information to be used while compiling the file. This statement is also called the preprocessor directive, as it tells the preprocessor to include the file before compilation starts for the program. The file contains information about the standard input/output library, and these files are also referred to as header files in C.
- The third line forms the heading of the main function. Empty parentheses signify an empty argument list for the main function.
- The next line marks the beginning of the function. Any function written in C must have its body inside curly braces and the main function is no different.
- The remaining lines form the body of the main function.
- The first line inside the body of the function is the variable declaration. It tells the compiler to reserve a block of memory taken by an integer for the variable named test.
- The next line is used for displaying the output. This line calls the printf function with arguments as Enter a number. printf is a library function that prints the output.
- Similarly, the next line calls the scanf function, which reads the entered input.
- Finally, the program terminates with a closing curly brace.

### C Tokens

A code written in C has various building blocks or tokens. It is the responsibility of the compiler to break the code into its simpler constituents before it starts parsing. The smaller parts of the code are also called tokens. Let’s now discuss each of these parts in detail.
