## Declaration of Variables

We know that in C language, all the variables must be declared before they are used in executable statements of a program. This is true for the C++ language as well. However, there is a significant difference between C and C++ with regard to the place of their declaration. C language requires that all the variables should be defined at the beginning of the scope. In a typical C program, variable declarations are done at the top followed by executable instructions in the main() function body. At times, their actual usage is done far away from the place where it is declared, which leads to several problems in keeping track of the variables in C. Therefore, while constructing the C++ language, the designers of the language addressed this issue.

C++ allows the declaration of a variable anywhere within the scope. We only need to ensure that a variable is declared in C++, before it is used. In other words, there is no restriction regarding the place of declaration of C++ variables. This helps in making the program more realistic and readable, as a variable is declared just above where it is going to be used. In addition, every time we need to declare a variable, we need not go at the beginning of the scope to declare the variable. This approach also reduces the chances of errors that were present during the earlier days of C, which caused us to scan the program back and forth. Listing 12.2 shows the declaration of variables in C++.

Listing 12.2: Demonstrating the Declaration of Variables in C++

```cpp
//A sample program demonstrating declaration of variables in C++
#include <iostream>
using namespace std;
int main()
{
    float sum = 0;            //declaration of a variable
    for (int i=0; i<5; i++)   //declaration of a variable
    {
        sum = sum + i;
    }
    float average;
    average = sum / 5;
    cout << "The average value is " << average << endl;
    return 0;
}
```

However, one disadvantage of this approach is that we cannot see all the variables used in a scope at the same time. To solve this problem, we can write our own source code as in C language, where all the variables are defined at the beginning of the program.

## Expressions, Operators, and Operator Precedence

As we are new to C++, let's cover a little bit on expressions, operators, and operator precedence. Although, all these topics had already been covered in the section of C programming, and there is not much difference between the operators in C and C++, we will try to only focus on operators that are specific to C++. Expressions are a sequence of operators and operands that are used for computing a value from the operands and designating objects or functions. In C++, operators can be overloaded and their meaning can be user-defined, however, operator precedence and the number of operands they take cannot be modified. ### Expressions

An expression is a combination of operators, constants, and variables arranged as per the rules of a programming language. It may also include function calls, which return values. In addition, an expression may consist of one or more operands and zero or more operators to produce a value. Following are the various types of expressions in C++.

- **Constant expressions** — Refer to expressions that consist of only constant values. Following are some examples of constant expressions:
  - 15
  - 20 + 5 / 2.0
  - 'X'

- **Integral expressions** — Refer to expressions that produce integer results after implementing all the automatic and explicit type conversions. Following are some examples of integral expressions:
  - m
  - m * n - 5
  - m * 'x'
  - 5 + int(2.0)

  where, m and n are integer variables.

- **Float expressions** — Refer to expressions that produce floating-point results after all the conversions. Following are some examples of float expressions:
  - x + y
  - x * y / 10
  - 5 + float(10)
  - 10.75

  where, x and y are floating point variables.

- **Pointer expressions** — Refer to expressions that produce address values. Following are some examples of pointer expressions:
  - &m
  - ptr
  - ptr + 1
  - "xyz"

  where, m is a variable and ptr is a pointer.

- **Relational expressions** — Refer to expressions that yield results of bool type, which takes true or false value. Following are some examples of relational expressions:
  - x <= y
  - a+b == c+d
  - m+n > 100

When arithmetic expressions are used on either side of a relational operator, they are evaluated first and then the results are compared. Relational expressions are also known as Boolean expressions.

- **Logical expressions** — Refer to expressions that combine two or more relational expressions and produce bool type results. Following are some examples of logical expressions:
  - a>b && x ==10
  - `x==10 || y==5`
  - `!a`

- **Bitwise expressions** — Refer to expressions that are used to manipulate data at bit level. They are used for testing and shifting bits. Following are some examples of bitwise expressions:
  - `x << 3        //Shift 3 bit positions to the left`
  - `y >> 1        //Shift 1 bit position to the right`

Shift operators are often used for multiplication and division by powers of two. Now, let's learn about the operators in C++.
