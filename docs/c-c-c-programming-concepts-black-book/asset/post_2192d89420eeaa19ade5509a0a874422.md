## Calling Convention of a Function

A function can be accessed by mentioning its name followed by a list of arguments, which are enclosed in parenthesis and separated by commas. A function call might have an empty list of arguments in which case, the pair of parenthesis will also be empty. The arguments that appear in the function call are known as actual arguments, which differ from the formal arguments mentioned in the first line of the function definition. A normal function call has a one-to-one correspondence between the actual and the formal parameters. It should always be kept in mind that the data type of the actual arguments should be completely similar to that supplied in the formal parameters. During a function call, it is the value of the actual arguments that gets transferred to the function and assigned to each one of the formal parameters. Listing 2.5 shows an example stating some basic calling conventions in functions:

Listing 2.5: Calling Conventions in Functions

```c
# include<stdio.h>

void myFunc(int value1, int value2);

int main()
{
    printf("\n value passed to function");
    myFunc(10,20);
    getch();
    return 0;
}

void myFunc(int value1, int value2)
{
    printf("\n value are [%d] and [%d] ",value1, value2);

    return;
}
```

In Listing 2.5, you can see that two different values are passed to the myFunc function as actual arguments. When the function call is made, these two values get assigned to the formal parameters “value1” and “value2”. The assignment becomes clear when the variables are displayed inside the myFunc function. If the function returns any value, then the function call must look like an assignment statement where the value returned from the function gets stored inside a variable.

It states that the value returned by the function will be stored in the variable that is at the left hand side of the assignment. One important point that needs to be followed while performing such assignments is that the data type of the variable used for the assignment must be similar to the return type of the function.

There are two ways in which arguments can be passed to a function—call by value and call by reference. Let’s now discuss both these ways in detail.

### Call by Value

The call by value method copies the value of the actual argument into its corresponding formal parameter of the function. Any changes made to the formal parameter have no effect on the actual argument. Listing 2.7 shows an example of the call by value method:

Listing 2.7: Showing Call by Value in C

```c
#include<stdio.h>

void myFunc(int);

int main()
{
int arg_1 = 10;

printf("\n Value before function call [%d]",arg_1);
myFunc(arg_1);
printf("\n Value after function call [%d]",arg_1);


getch();
}

void myFunc(int arg_1)
{
    arg_1--;
    printf("\n Value inside function call [%d] ",arg_1);
}
```

The output of Listing 2.7 is given as follows:

```text
Value before function call [10]
Value inside function call [9]
Value after function call [10]
```

The output of the program, shown in Listing 2.7, suggests that the argument passed to the myFunc function was just a copy of the variable that was declared within the main invoking module.

### *Call by Reference*

In the call by reference method, the address of the argument is copied inside parameters and passed to the function. Call by reference guarantees that the change taking place inside the function gets reflected from the invoking function. In C, call by reference is implemented with the help of pointers. A pointer is a special type of variable that is used to hold address of a memory location. Detailed coverage of pointers will take place in Chapter 3, *Pointers and Function Pointers in C*, of the book. Since we are using address of a memory location for accessing the value of an actual parameter, the actions taking place inside the function can change the content of the arguments. Listing 2.8 shows how call by reference works in C:

Listing 2.8: Showing Call by Reference in C

```c
#include<stdio.h>

void mySwap(int *x, int *y);

int main()
{
    int x = 10;
    int y = 50;

    printf("\n Value before function call [%d] and [%d]",x,y);
    mySwap(&x,&y);
    printf("\n Value after function call [%d] and [%d] ",x,y);

    getch();
}
void mySwap(int *x, int *y)
{
    int temp;

    temp = *x;
    *x = *y;
    *y = temp;
}
```

## Function Prototypes

A function can be included in a program using two approaches. In the first approach, the body of the function precedes the main module of the program. It means when the program gets compiled, the user-defined function would be defined even before the function is accessed. However, this approach also has certain limitations. Following this approach would mean that we have to place the main module always at the end of our program, which may not be the case all the time. If we place the function definition after the main module, the code will give compilation errors. This happens when we try to access a function before defining it.
