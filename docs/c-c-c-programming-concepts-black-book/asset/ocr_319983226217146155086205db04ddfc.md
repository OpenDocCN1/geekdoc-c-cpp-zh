# ### The FileStream Class

The FileStream class is used as a buffer to perform operations, such as open, read, and write, on a file. Whenever we want to open a file in a file mode, such as read or write, we need to first declare the FileStream object to store the file stream. This helps in manipulating the content of the file later; thereby, enhances the performance of the file system. We can declare an instance of the FileStream class in C# as follows:

```
```csharp
FileStream fileStream = new FileStream(@"C:\Document & Settings\Book\",
    FileAccess.ReadWrite);

or,

FileStream fileStream = new FileStream(@"c:\Document & Settings\Book\", FileMode.Open,
    FileAccess.ReadWrite);
```
```

C# provides 15 overloaded constructors to create an instance of the FileStream class.

The FileStream class allows both synchronous and asynchronous read/write operations. In addition, it gives the freedom to read a certain portion of the file by using its methods. The FileStream class is a public class and all its methods are public as well.

Table 21.1 provides a list of noteworthy methods of the FileStream class:

**Table 21.1: Noteworthy Methods of the FileStream Class**

| Method | Description |
|---|---|
| BeginRead(byte[] bytes, int offset, int numByte, AsyncCallback callBack, Object stateObject) | Refers to a method that begins an asynchronous read. |
| BeginWrite(byte[] bytes, int offset, int numByte, AsyncCallback callBack, Object stateObject) | Refers to a method that begins an asynchronous write. |
| Close() | Closes the FileStream object and releases all the resources that the object was using. It also closes the underlying open streams. |
| Dispose() | Releases all the system resources held by the FileStream object. |
| EndRead(IAsyncResult asyncResult) | Waits for the pending asynchronous read process to complete its read operation. |
| EndWrite(IAsyncResult asyncResult) | Ends the write operation and releases the I/O resources once the I/O operations are complete. |
| Flush() | Flushes the buffer that has been used by the current FileStream object. This method also writes the buffered data to the file system. |
| Lock(long position, long lengthToRead) | Locks other I/O operations while a file has the read access. By specifying the position and length, a user restricts the important portion of the file from modification. |
| Read(char[] buffer, int index, int count) | Reads the number of characters from the input FileStream and stores them into the buffer starting from the index position. This method also returns the next character position as integer. |
| ReadByte() | Reads the bytes from the FileStream object and increases the position index by one byte. |
