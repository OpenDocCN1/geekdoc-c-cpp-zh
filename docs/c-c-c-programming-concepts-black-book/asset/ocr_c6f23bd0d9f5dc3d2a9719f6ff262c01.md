# ### *bad_alloc()*

When the new and new[] operators are unable to allocate the requested storage space, the bad_alloc() exception is thrown. A null-terminated character sequence identifying the exception is returned by its what() member function. Consider the following example:

```
```cpp
#include <iostream>
#include <new>
using namespace std;
int main ()
{
    try
    {
        int* myarray= new int[100000];
    }
    catch (bad_alloc&BA)
    {
        cerr<< "Exception caught - " << BA.what() << endl;
    }
    return 0;
}
```
```

The output of the preceding program is given as follows:

```
```text
Exception caught - bad allocation.
```
