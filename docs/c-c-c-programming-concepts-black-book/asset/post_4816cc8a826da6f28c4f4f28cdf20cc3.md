## Joining Operators

Join operation concatenates two given relations based on a specific condition. In LINQ, the join operation is performed with the help of the following two types of joining operators:

- Join
- Group Join

C# provides the join keyword using which the *Join* operator is implemented in the LINQ queries. Similar to inner join in SQL, the *Join* operator also selects those entries that satisfy the joining condition. The inner join in LINQ represents the area of intersection between the two collections or sets, as shown in Figure 19.22:
