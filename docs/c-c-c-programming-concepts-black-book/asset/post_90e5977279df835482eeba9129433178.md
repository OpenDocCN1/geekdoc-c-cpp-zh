
Figure 1.6 shows the flowchart of the for loop:

![](img/43c5f409f9b17790a628c4b4df854b61_83_0.png)

**Figure 1.6: Flowchart of the FOR Loop**

Figure 1.6 describes the way in which the for loop is executed. First of all, the loop control variable is initialized. After that, the test condition is executed. If the test condition happens to be true, then the body of the for loop is executed and the loop control variable gets incremented by one at the beginning of the next iteration.

Listing 1.31 shows an example to discuss the working of the for loop:

**Listing 1.31: Using the FOR Loop**

```c
#include<stdio.h>

int main()
{
    int count,sum=0;

    for(count=1;count<=10;count++)
    {
        sum = sum + count;
    }
    printf("\n Sum %d ",sum);
    getch();
}
```

Listing 1.31 shows that during the first iteration of the for statement, the loop control variable gets initialized to 1. After initialization, the test condition is executed. If the test condition comes out to be true, the body of the for loop is executed for the first time. While executing the closing brace of the loop, the control again comes back to the for statement. Now, the value of the loop control variable gets incremented by one and then the test conditions are again executed. This sequence of execution continues until the loop control variable reaches a value, which in turn makes the test condition false and the loop terminates. Once the for loop terminates, the control comes to the first statement following the body of the loop. Although initialization is done inside the for loop, it takes place only once. Second iteration onwards, the loop control variable gets modified.

The following code snippet shows an example of a generic for loop:

```c
for(initialise loop controller; test condition; increment/decrement loop controller)
{
        body of for loop ;
}
```

## Nesting of the for Loop

Similar to while loops, for loops can also be nested. These loops can be placed one inside the other and run simultaneously. Let's consider the same example which was used to show nesting of while loops.

Listing 1.32 shows the nesting of the for loop:

**Listing 1.32: Nesting of the FOR Loop**

```c
#include<stdio.h>

int main()
{
    int factorial;
    int inner_count;
    int outer_count;

    factorial=1;

    for(outer_count=1;outer_count<10; outer_count++)
    {
        inner_count=1;
        for(inner_count=1;inner_count <= outer_count;inner_count++)
        {
            factorial*=inner_count;
        }
        printf("\n Factorial of %d is %d ",outer_count,factorial);
        factorial=1;
    }
    getch();
}
```

The output of Listing 1.32 is given as follows:

```text
Factorial of 1 is 1
Factorial of 2 is 2
Factorial of 3 is 6
Factorial of 4 is 24
Factorial of 5 is 120
Factorial of 6 is 720
Factorial of 7 is 5040
Factorial of 8 is 40320
Factorial of 9 is 362880
```

The working of the example is similar to that we have shown while describing nesting in a while loop. The outer loop controls the range for factorial generation and the inner loop calculates the factorial.

## Different Uses of the for Loop

Depending upon the requirements and types of programs, the for loop can be used in various ways. Listings 1.33 to 1.35 show different uses of the for loop:

**Listing 1.33: Use of the FOR Loop**

```c
#include<stdio.h>

int main()
{
    int i;

    for(i=1;i <= 10;)
    {
        printf("\n i %d ",i);
        i = i + 1;
    }

    getch();
    return 0;
}
```

Listing 1.33 shows a variant of the for loop where the increment of the loop control variable has been done inside the body of the loop. Listing 1.34 shows a type of the for loop where initialization takes place outside the loop:

**Listing 1.34: Another Use of the for Loop**

```c
#include<stdio.h>

int main()
{
    int i=1;

    for(;i <= 10;i++)
    {
        printf("\n i %d ",i);
    }

    getch();
    return 0;
}
```

In Listing 1.34, we are initializing the variable before the loop starts. We are not using the initialization step while using the for loop as it's already done earlier. This is another way of using the for loop. It is even possible to make the for loop work like a while loop.

Listing 1.35 shows an example where the for loop is used as a while loop:

**Listing 1.35: Another Variant of the FOR Loop**

```c
#include<stdio.h>

int main()
{
    int i=1;

    for(;i <= 10;)
    {
        printf("\n i %d ",i);
        i = i + 1;
    }
    getch();
    return 0;
}
```

The for loop stated in Listing 1.35 works like a simple while loop. In this case, initialization is done outside the loop statement. The loop statement only contains the test condition and the increment operation is carried inside the body of the loop itself.

### Multiple Initializations of the for Loop

We can have multiple loop control variables getting initialized within a single for statement. This feature gives an added flexibility to the for loop where we can take decisions depending on multiple variables. Listing 1.36 shows multiple initialization in the for loop:

**Listing 1.36: Multiple Initialization in the For Loop**

```c
#include<stdio.h>

int main()
{
    int i,j;

    for(i=0,j=-1; (i <= 10) && (j < 20); i++,j+=2)
    {
        printf("\n i %d j %d",i,j);
    }

    getch();
    return 0;
}
```

Listing 1.36 shows how multiple initializations can be given inside a single for statement. Not only multiple initializations, we can also have multiple test conditions and multiple increment/decrement operations taking place in the for loop.

## The Do-While Loop

Till now, we have discussed the scenarios where the iteration count of a loop was predefined. This might not be the case while dealing with real life examples. Let's consider such cases where we have to decide whether we are going to continue or not based on certain inputs instead of counts. In such cases, we need to use the do-while loop which takes such cases into account.

Figure 1.7 shows the flow chart of a do-while loop:

![](img/43c5f409f9b17790a628c4b4df854b61_86_0.png)

**Figure 1.7: Flow Chart of the Do-While Loop**

The flow chart, shown in Figure 1.7, depicts the working of a typical do-while loop. Initialization happens outside the body of the loop and the statement inside the body of the loop gets executed unconditionally for the first time. After that, the loop control variable either gets incremented or decremented. The test condition is tested at the end of the loop. If the test condition happens to be true, then the control shifts to the beginning of the loop else the loop terminates. The control then shifts to the first statement that follows the loop. The main difference between a do-while loop and other loops is that a do-while loop gets executed at least once. This is due to the fact that the test condition is always right at the end of the loop. This means that only after executing all the statements at least once, the control can reach to the end of the loop.

Listing 1.37 describes working of the do-while loop:

**Listing 1.37: Basic Working of the do-while Loop**

```c
#include<stdio.h>
int main()
{
    char answer;
    int sum,count;
    count=1;
    sum=0;
    do
    {
        fflush(stdin);
        sum+=count;
        printf("\n Sum %d ",sum);
        count++;
        printf("\n Want to Continue ?(Y/n) ");
        scanf("%c",&answer);
    }while(answer=='y');
    getch();
}
```

The code given in Listing 1.37 explains the working of a do-while loop. The execution of the loop starts unconditionally for the first iteration. As the control reaches the end of the loop, the user is asked to provide an input. Based on this input, the test condition is executed. If the condition becomes true, then the loop goes into its next iteration else the loop is terminated. A do-while loop always contains a semicolon at the end of the “while” statement.

## Jump Statements

We have four kinds of jump statements in C to perform unconditional branching. These statements are return, goto, break, and continue. We can define return and goto statements anywhere in the function but break and continue are generally used with respect to a loop.

Let's discuss these statements in detail.

### The Return Statement

The return statement is used to mark a return point from a function. When the execution hits a return statement, the control gets shifted to the line before which the function call was made. A return statement might or might not have a value associated with it. Return statements are used for functions which have non-void return types declared with them. A void function doesn't return any value. In older versions of compilers (like C89), a return statement might not return any value explicitly. If a function is declared with a non-void return type and nothing is returned from that function, the compiler returns garbage values. However, the advanced set of compilers (like C99) has made it mandatory that a non-void function must use a return statement which is associated with a value. Multiple return statements can be used inside the same function. The function will immediately stop executing when a return point is hit. The closing brace of a function also acts like an implicit return statement, which does not have any values associated with it. No explicit return statements are needed for functions with void return types. One thing must be kept in mind that a function whose return type is defined to be void cannot have a return statement that is used with values.
