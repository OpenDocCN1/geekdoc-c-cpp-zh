```cpp
#include<iostream.h>
#include<conio.h>
void (*fpt)(void *,char*);
class MyClass
{
    public:
        void show_message(char *message)
        {
            cout<<"The message is "<<message;
        }
        static void caller_to_display(void *obj, char *message);
};
void MyClass::caller_to_display(void *obj,char *message)
{
    MyClass *tempObj = (MyClass*)obj;
    tempObj->show_message(message);
}
int main()
{
    MyClass obj;
    fpt = MyClass::caller_to_display;
    (*fpt)((void*)&obj, "This is a callback");
    getch();
    return 0;
}
```

In Listing 4.20, we have defined the MyClass class with two functions: show_message(), which is used to display a message, and caller_to_display(), which is a static function and used as a wrapper to invoke the show_message() function. We have also declared a function pointer called fpt, which points to the caller_to_display() function. This function takes the void and char pointers as its arguments and returns nothing. Within the main() function, we have created an instance of the MyClass class and then made fpt point to the caller_to_display() function. Moreover, we have made the call to the intended member function by passing the reference of the object along with a custom message to the function being pointed to by fpt as arguments. Inside the wrapper function, after receiving the reference, we again type cast the instance of the desired class and call the display() function with the custom message. This helps in implementing a callback to a non-static member function in C++.

## Callback to a C++ Member Function using a Global Variable

As discussed in the previous section, we can implement the concept of callbacks in C++ by using a function pointer. We can also do the same by using a global variable. However, there is a vast difference between the two approaches. In the first approach, we need to create a pointer to the instance of a class inside a wrapper function and then type cast the void* pointer, which is passed to the wrapper, to the proper instance of the class. In the second approach, instead of passing a void pointer, we use a global variable to type cast the void* pointer to the actual instance of the class. Let's now understand the usage of functors through the code given in Listing 4.23:

Listing 4.23: Showing the Usage of Functors

```cpp
#include<iostream.h>
class TBase
{
public:
    virtual void operator()(const char* string)=0;   // call using operator
    virtual void ShowMessage(const char* string)=0;  // call using function
};
// derived template class
template <class TClass> class TDerived : public TBase
{
private:
    void (TClass::*func_ptr)(const char*);   // pointer to member function
    TClass* ptr_obj;                        // pointer to object

public:
    TDerived(TClass* _pt2Object, void(TClass::*_fpt)(const char*))
    { ptr_obj = _pt2Object; func_ptr=_fpt; };

    // override operator "()"
    virtual void operator()(const char* string)
    { (*ptr_obj.*func_ptr)(string);};       // execute member function

    // override function "ShowMessage"
    virtual void ShowMessage(const char* string)
    { (*ptr_obj.*func_ptr)(string);};       // execute member function
};
class TClassA{
public:
    TClassA(){};
    void Display(const char* text) { cout << text << endl; };
};
class TClassB{
public:
    TClassB(){};
    void Display(const char* text) { cout << text << endl; };
};
int main()
{
    // 1. instantiate objects of TClassA and TClassB
    TClassA objA;
    TClassB objB;
    TDerived<TClassA> specFuncA(&objA, &TClassA::Display);
    TDerived<TClassB> specFuncB(&objB, &TClassB::Display);
    TBase* vTable[] = { &specFuncA, &specFuncB };
    vTable[0]->ShowMessage("TClassA::Display called!");
    (*vTable[1]) ("TClassB::Display called!");    // via operator "()"
    cin.get();
    return 0;
}
```

In Listing 4.23, we have defined two classes: TClassA and TClassB. Both the classes have the Display() function, which returns void and takes a char* as its argument. Note that the functions in both the classes should have the same signature. Next, we have instantiated the derived class by passing the addresses of the Display() functions of the respective classes with the addresses of the class instances. We have also created an array with two pointers to the base class and initialized the array with the two instances of the derived class. Then, we have used the array to call the respective member functions with both the overloaded () operator and the pure virtual function.

## Complex Examples of Pointers and Function Pointers

Let’s divulge into some of the typical aspects of pointers and function pointers to understand the criticality of their implementation.

### Example 1:

```c
#include <stdio.h>
int main()
{
        float var_A = 3.1416;
        float *ptr_A;
        ptr_A = &var_A;
        printf("\n Address [%u] ",ptr_A);
        printf("\n Value [%d] ",*ptr_A);
        getch();
}
```

In the preceding example, ptr_A contains the address of a floating-point variable; therefore, it is declared as a float. In the first printf statement, the address of the floating-point variable is displayed; however, in the second printf statement, when we try to print the value at the memory location, we get a garbage value. This happens because we are using the %d format while printing the value of the float pointer. The %d format does not always truncate the value of a floating-point variable, thereby, they are unreliable to be used. Note that we should use the correct format while displaying the content of a memory location using a pointer. Therefore, the same code would work fine if we have used the %f format in the second printf statement.

The output of Example 1 is as follows:

```text
    Address [2293620]
    Value [536870912]
```

### Example 2:

```c
#include <stdio.h>
int *increment_pointer(int *);
int main()
{
        int var_A = 10;
        int *ptr_A;
        ptr_A = &var_A;
        printf("\n Address Before [%u] ",ptr_A);
        ptr_A = increment_pointer(&var_A);
        printf("\n Address After [%u] ",ptr_A);
        getch();
}
int *increment_pointer(int *ptr)
{
    return ++ptr;
}
```

In the preceding example, we have used an integer pointer ptr_A, assigned the address of the variable var_A to it, and displayed the address. In the successive steps, we have passed the address of the variable to the increment_pointer() function. Within the function, the address is collected in an integer pointer, which is incremented by one and then returned. It is interesting to note that when the value returned by the function is displayed, a shift of four bytes from the previous value took place. This happens because an integer takes four bytes of space in the memory. When we declare an integer pointer, it enables us to access all the four bytes memory location, which the pointer is pointing at. When we perform an increment operation on that pointer, it will point to the next location, which is again of four bytes; therefore, a shift of four bytes is observed. It should be kept in mind that we can only perform the increment and decrement operations on pointers. Division and multiplication operations on pointers are not allowed.

The output of Example 2 is as follows:

```text
    Address Before [2293620]
    Address After  [2293624]
```
