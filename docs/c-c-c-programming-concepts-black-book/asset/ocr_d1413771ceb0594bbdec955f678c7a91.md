# Static Functions

Similar to static variables, C also defines the concept of having static functions. Static functions work similar to global static variables. If a function is declared as static, then that function is only visible inside the file in which it is declared. It means that this function cannot be accessed from any other file, which is a part of the program. To declare a static function, we need to precede the name and return type of the function with a static keyword, as shown in the following code snippet:

```
```c
static int myFunction();
```
```

The preceding code snippet describes a static function in C.
