
## Implicit Type Conversions

Implicit type conversion is an automatic type conversion by the compiler, whenever data from different data types is intermixed. Some languages allow or even require compilers to provide this facility. Consider the following program:

```cpp
1: // Demonstrating type conversion in C++
2: #include <iostream>
3: using namespace std;
4:
5:
6: int main ()
7: {
8: int count = 10;
9: float avg = 198.6F;
10:
11:         double total = count * avg;
12:         cout << "Total = " <<total<<endl;
13:         return 0;
14: }
```

In the preceding program, the count variable of integer type is multiplied with the avg variable of float type and the result is stored in the total variable of double type. The program should raise an error during compilation as the operations (in line number 11) involve different types of variables simultaneously. However, when we compile the program, it does not raise any error and executes smoothly. This is because C++ permits these kinds of operations, which are known as automatic type conversions or implicit conversions.

From Table 12.4, we get an idea of the evaluation order of data types in C++. Now consider a scenario where two operands of different data types are encountered in the same expression. In this case, the lower type variable is converted into the type of the higher type variable. Similarly, in the preceding program, the integer variable count is promoted to float and stored in a temporary variable before being multiplied with the float variable avg. The result is then converted into double and stored in the total variable. These conversions take place automatically, as C++ does not want to bother the programmers about all these small issues.

However, sometimes the compiler is not able to convert one data type into another automatically and raises an error. In addition, compiler does not automatically promote an object of one class to an object of another class. To solve these issues, C++ provides explicit type conversion. Let’s learn about it in detail in the next section.

## Explicit Type Conversions

During the lifetime of a program, situations might arise when a programmer needs to convert a value from one type to another where the compiler would not be able to do it automatically. In such cases, we need explicit type conversions that are applied to data conversions specified by programmers. Now, a question might come to our mind that how to understand what conversion the programmer need to take care of and what the compiler will do for us.

C++ is a strongly-typed language; therefore, conversions, especially those that imply a different interpretation of the value, require explicit casting or conversion, as shown in the following code snippet:

```cpp
double var1 = double (m);        // where m is a different type variable
double var2 = (double) n;        // similar is done here, but syntax is different
```

Although both the preceding statements have different syntax, they work in the same way. The preceding method of type casting is valid and permissible in C++; however, ANSI C++ has added few more cast operators, such as static_cast, dynamic_cast, reinterpret_cast, and const_cast. Let's cover each of these in the next sections.

### Static Casting

Static casts are only available in C++. Static casts can be used to convert one type into another; however, it should not be used to cast away const-ness or to cast between non-pointer and pointer types. During the conversion, no type safe checking is done by the compiler; and therefore, it is left totally on the programmer. Consider the following example of static casting in C++, where we cast an integer variable into a variable of type char:

```cpp
charVar = static_cast <char> (integerVar);
```

In the preceding example, the variable to be casted (that is, integerVar) is placed in parenthesis and the type to be casted (that is, char) is placed in angle brackets. The outcome of the statement is that the integer variable integerVar is changed to the character type, before being assigned to a character variable charVar. Therefore, while doing a type conversion from a data type of smaller order to a data type of wider order, the implicit or automatic type conversion is used, but for cases where a wider data type is casted into a data type with lower order, an explicit cast is required to complete the operation. Compiler does not get involved in this, as data truncation can result in trouble. Consider the following example:

```cpp
double d = 3.14159265;
int i = static_cast<int>(d);
```

In the preceding example, we have assigned a real value to the double variable d. Now in this case, static cast is used to convert the double value to its corresponding integer value and then we have assigned a temporary integer value to another integer variable, called i.

### Dynamic Casting

The dynamic casting is used to cast the type of an object at runtime by using the dynamic_cast operator. Its main purpose is to perform casts on polymorphic objects, which are created by base classes that contain virtual function. Following is the syntax of using dynamic casting in C++:

```cpp
dynamic_cast <type> (object);
```

In the preceding syntax, the object is a base class object whose type is to be checked and casted. Dynamic casting requires the Run-Time Type Information (which permits the type of an object to be determined during the execution of a program) to do this conversion. It never performs an invalid conversion, as it checks whether the conversion is legal at runtime. If the conversion is not valid, it returns NULL. The type must be a pointer or a reference to a defined class type. The argument object must be an expression that resolves to a pointer or a reference. The use of dynamic_cast operator is also called a type-safe downcast.

We can define arrays of any C++ data type, starting from the basic data types to user-defined data types. Following is a declaration of an array:

```cpp
data_type array[size];
```

Now, let's define an array of size 10. As soon as the processing begins, 10 memory locations each of size equal to that of data type are contiguously allocated in the memory. The base address of the array can be obtained by the array name or the address of its first member. Note that array indexing starts from 0 and ends at size-1 position. Let's take a real array declaration and see what these values are:

| Array declaration: | int array[10]; |
| :--- | :--- |
| How many elements: | 10 |
| First Element in: | array[0] |
| Last Element in: | array[9] |
| Address of the array: | array or &array[0] |

In the preceding array, each cell corresponds to an integer variable, as if they are grouped together.
