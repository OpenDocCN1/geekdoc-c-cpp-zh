## Stack

Stack operation follows the Last In First Out rule commonly known as LIFO. When an item is inserted into the stack, it is inserted at the bottom of the stack; this operation is known as push. In addition, when an element is removed from the stack, it is always removed from the first position, which implies that the last inserted item will be removed first. This operation of stack is known as pop. C# provides the Stack class, which holds every value type making this class a flexible data repository. Listing 17.27 shows the usage of the Stack class using its Push() and Pop() methods:

### Listing 17.27: Showing the Usage of the Stack Class

```csharp
using System;
using System.Collections;

class Program
{
    public static void Main()
    {
        Stack s = new Stack();
        //Pushing the elements inside the stack
        s.Push("Hi");
        s.Push("This");
        s.Push("is");
        s.Push("a");
        s.Push("stack");
        //Pushing other value types
        s.Push(1);
        s.Push(1.25);
        s.Push('F');
        //Printing the elements in the stack
        Console.WriteLine("Printing the stack elements....");
        foreach (object obj in s)
        {
            Console.WriteLine(obj);
        }
        //Popping one element
        s.Pop();
        Console.WriteLine("Printing the stack elements after executing pop operation....");
        foreach (object obj in s)
        {
            Console.WriteLine(obj);
        }
    }
}
```

In the preceding program, we have inserted the string elements as well as some value types, such as integer, double, and character, in the Stack object using the Push() method. When these elements are printed on the console, they will be displayed in the LIFO manner. Now, if we pop out one element from the stack, then the first element that was displayed on the console will be deleted from the stack. The output of the program is given as follows:

```text
Printing the stack elements....

1
stack

is
This
Hi
Printing the stack elements after executing pop operation....

stack

Hi
```

## Queue

The queue operation is just the opposite of the stack operation. A queue has its front end and rear end. When an element is inserted into the queue, it is inserted from the rear end; whereas, when an element is deleted from the queue, it is deleted from the front end. This emphasizes the First in First Out (FIFO) operation. In C#, the Queue class performs the insert and delete operations using the two methods, Enqueue() and Dequeue(), respectively. Listing 17.28 shows the usage of the Queue class.

### Listing 17.28: Showing the Usage of the Queue Class

```csharp
using System;
using System.Collections;

class Program
{
    public static void Main()
    {
        Queue q = new Queue();
        //Entering the element in a queue
        q.Enqueue("Hi");
        q.Enqueue("This");
        q.Enqueue("is");
        q.Enqueue("an");
        q.Enqueue("queue");
```

## Hash Table

Hash table represents a key-value collection where a key maps to its value. This data structure is important in implementing the search functionality to make it easier and faster. C# provides the Hashtable class, which has the functionalities to manipulate the hash table elements easily. Listing 17.30 shows the various functionalities of hash table using the Hashtable class:

### Listing 17.30: Showing the Usage of the Hashtable Class

```csharp
using System;
using System.Collections;

class Program
{
    public static void Main()
    {
        Hashtable direction = new Hashtable();
        direction.Add(1, "North");
        direction.Add(2, "South");
        direction.Add(3, "East");
        direction.Add(4, "West");
        //Displaying the first element of the hash table
        Console.WriteLine("Printing the first element of the hash table....");
        Console.WriteLine(direction[1].ToString());
        //Search for an item in hash table
        if (direction.ContainsValue("South"))
        {
        }
        else
        {
            Console.WriteLine("Element not found");
        }
        //displaying the content of hash table
        Console.WriteLine("Printing the elements in the hash table....");
        foreach (DictionaryEntry var in direction)
        {
            Console.WriteLine(var.Value);
        }
    }
}
```

In the preceding program, an object of the Hashtable class is instantiated that stores the four directions. The hash table object also stores the element in the name-value pair. This program prints the first element in the object and then searches an element by providing the value by using the `ContainsValue()` method. In our case, we have searched for the value South in the hash table. The output of the program is given as follows:


## Reference Type

In C and C++, when a pointer variable is assigned to another pointer variable, its reference is changed while its value remains the same. Similarly, in C#, reference type represents an object of a class, an interface, a delegate, or an array that holds the reference. Therefore, when a reference type is assigned to another reference type, only its reference is copied and not the value. Listing 17.31 shows the usage of reference type in C#:

### Listing 17.31: Showing the Usage of the Reference Type

```csharp
using System;

public class Program
{
    public static void Main()
    {
        Employee e1 = new Employee();
        e1.name = "Catherine";
        Employee e2 = new Employee();
        e2.name = "Thomas";
        Console.WriteLine("Name of the employees before assignment...");
        e1.Print();
        e2.Print();
        e1 = e2;
        Console.WriteLine("Name of the employees after assignment...");
        e1.Print();
        e2.Print();
        e2.name = "Bob";
        //changing the value of name of e2
    }
}
```
