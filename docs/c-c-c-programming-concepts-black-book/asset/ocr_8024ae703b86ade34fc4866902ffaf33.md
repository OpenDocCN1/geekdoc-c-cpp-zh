At first, the constructor of base class is called followed by the derived class constructor. Next, at the time of destroying the object, the destructor of the derived class is called followed by the base class destructor. When an object of derived class is created, if the base class contains a constructor; it will be called first or else the default constructor for the base class will be called, followed by the derived class constructor. When the derived class object is being destroyed, it is the reverse that happens. The derived class destructor is called first followed by the destructor of the base class.

Generally, it makes sense that constructor functions are executed in the order of their derivation. As a base class has no knowledge of any derived class, any initialization it needs to perform is separate from and possibly prerequisite to any initialization performed by the derived class. However, just the reverse works for destructors. As the base class underlies the derived class, the destruction of the base object implies the destruction of the derived object. Therefore, the derived destructor must be called first before the object is destroyed.
