the public member variable of the Vehicle class. As this is defined as public, we can access it from the derived
class. In addition, we have defined another class named Owner, which has one method that accesses the public
variable of the Vehicle class. If we access that member variable through an instance of the Owner class in the
Main() method, then the compiler will not generate any error. The code runs smoothly and generates the
following output:

```
```
The type of the car is Four-wheeler
The owner has a Two-wheeler

# ## Private

If the members of a class are defined as private, then they can be accessed from the class only. In C#, this is the
default modifier used while declaring the members of the class. Listing 18.30 shows an example of the private
access modifier:

Listing 18.30: Showing an Example of the Private Access Modifier

```
```csharp
using System;
class Vehicle
{
    private string type;
}
class Owner
{
    void OwnerVehicle()
    {
        Vehicle vehicle = new Vehicle();
        //throw an error as it tries to access a private member
        vehicle.type = "Two-wheeler";
        Console.WriteLine("The owner has a " + vehicle.type);
    }
}
class Car : Vehicle
{
    static void Main()
    {
        Vehicle vehicle = new Vehicle();
        //throw an error as it tries to access a private member
        vehicle.type = "Four-wheeler";
        Console.WriteLine("The type of the car is " + vehicle.type);
        Owner owner = new Owner();
        owner.OwnerVehicle();
    }
}
```
```

If we run the preceding code, the compiler will throw an error due to the protection level applied to the
member variable of the Vehicle class. However, if we modify the preceding code for the private members, as
shown in Listing 18.31, then it will run successfully:

Listing 18.31: Showing an Example of the Private Access Modifier

```
```csharp
using System;
class Vehicle
{
    private string type;
    public void Print()
    {
        type = "Two-wheeler";
        Console.WriteLine("The type of the car is " + type);
    }
}
