C++ is an extension of the C programming language. It is a derivation from the traditional language in a sense that it follows object-oriented principles, which help in managing large and complex real world problems. C++ was developed by Bjarne Stroustrup at AT&T Bell Labs in the early 1980s. Bjarne Stroustrup started working on "C with Classes" in the year 1979 and in the year 1983, the name "C with Classes" was changed to C++. Since then, C++ is one of the most popular programming languages with a wide variety of application domains including systems software, application software, device drivers, embedded software, high-performance server and client applications, and entertainment software.

In this chapter, we learn about the basic structure of a C++ program by means of programming. We also learn about data types, expressions, operators, and operator precedence in C++. In addition, we learn how to declare a variable as well as how to evaluate an expression in C++. Further, we discuss type conversions, arrays, strings, structures, references, flow control statements, and functions. Towards the end, we explore inline functions, recursive functions, dynamic memory allocation and deallocation operators, and preprocessor directives.

Let’s start the chapter by explaining the structure of a typical C++ program.

# Structure of a C++ Program

In this section, we learn about the structure of a C++ program by writing our first program. The program, which will be called Hello.cpp, prints the Hello World message on the output screen. However, the program does not take any input from a user. Listing 12.1 shows the code of the Hello.cpp file:

**Listing 12.1:** Showing the Code of the Hello.cpp File

```
1: // My first Program in C++
2:#include <iostream>
3: using namespace std;
4:
5:int main ()
6:{
7: cout << “Hello world.\n”;
8: return 0;
9:}
```

Although, the program is small, yet it contains the fundamental components about the structure of a C++ program. To analyze the program, we have indented each statement of the program with a line number. Let’s examine the program line by line in detail.

Line number 1 is a comment. C++ has introduced a new comment symbol, that is, // . All the lines beginning with the two slash signs are considered as a comment and do not have any effect on the behavior of a program. In C++ programs, this comment symbol is used for single line commenting. This particular comment symbol can start from anywhere in the line and whatever follows, till the end of the line, is ignored by the compiler. Although C++ has this new type of commenting mechanism, the traditional multiline comment (/* comment */) of C language still works in C++ programs.

Line number 2 might look like a statement but it is a directive to the preprocessor (explained later in the chapter); therefore, it does not end with a semicolon. A directive is marked by starting with the # symbol followed by include and filename. It is an instruction from the compiler to the preprocessor to include the iostream standard file before the compiler starts its job. The iostream file contains the declaration of the basic standard input-output library in C++, and is included along with the source program.

Line number 3 contains the namespace declaration. A namespace is a new concept introduced by the ANSI C++ standards committee. Any C++ program can be divided into different namespaces. The namespace declaration specifies that all the statements, which follow this declaration, are within the specified namespace (in our case, std).
