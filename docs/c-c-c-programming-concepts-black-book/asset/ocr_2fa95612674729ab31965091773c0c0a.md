# Nesting of the for Loop

Similar to while loops, for loops can also be nested. These loops can be placed one inside the other and run simultaneously. Let's consider the same example which was used to show nesting of while loops.

Listing 1.32 shows the nesting of the for loop:

**Listing 1.32: Nesting of the FOR Loop**

```
```c
#include<stdio.h>

int main()
{
    int factorial;
    int inner_count;
    int outer_count;

    factorial=1;

    for(outer_count=1;outer_count<10; outer_count++)
    {
        inner_count=1;
        for(inner_count=1;inner_count <= outer_count;inner_count++)
        {
            factorial*=inner_count;
        }
        printf("\n Factorial of %d is %d ",outer_count,factorial);
        factorial=1;
    }
    getch();
}
```
```

The output of Listing 1.32 is given as follows:

```
```text
Factorial of 1 is 1
Factorial of 2 is 2
Factorial of 3 is 6
Factorial of 4 is 24
Factorial of 5 is 120
Factorial of 6 is 720
Factorial of 7 is 5040
Factorial of 8 is 40320
Factorial of 9 is 362880
```
```

The working of the example is similar to that we have shown while describing nesting in a while loop. The outer loop controls the range for factorial generation and the inner loop calculates the factorial.
