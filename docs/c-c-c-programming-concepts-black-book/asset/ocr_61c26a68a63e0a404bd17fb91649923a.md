# CTS

One of the advantages of .NET Framework is that it provides cross-language interoperability. This is possible with the help of CTS provided by Microsoft that concentrates on the type conversion. CTS specifies the rules which include how the types can be declared, used, and managed at runtime that helps in integrating different languages. To summarize, CTS provides the following functionalities:

+   - Cross-language integration and type safety
+   - High performance code execution
+   - An object-oriented platform where codes from different languages can be integrated
+   - Rules that a language must follow to achieve cross-language interoperability

Types defined by CTS can be classified into the following two categories:

+   - **Value type** – Refers to a type that contains data. The instance of the value type is allocated either in a stack or in a structure itself. Following are the three kinds of value types:
+     - Built-in types
+     - User-defined types
+     - Enumeration
+   - **Reference type** – Refers to a type that is allocated in a managed heap. Reference type in OOP language refers to object of classes. In addition, pointers and interfaces can also be classified as reference types.
