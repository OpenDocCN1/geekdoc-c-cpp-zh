# ### Standard String Library Functions

C has a varied set of library functions for string manipulation. Each of these functions operates on a null-terminated string and requires the `<string.h>` header. The header also defines the `size_t` type, which is the return type of the `sizeof` operator and is a form of unsigned integer.

Some standard string library functions in C are as follows:

+   - strcat()
+   - strcmp()
+   - strlen()
+   - strncpy()
+   - strncat()
+   - strchr()
+   - strcspn()
+   - strcpy()

Let’s learn about these functions in detail, one by one.

# ### strcat()

The signature of the strcat() function is given as follows:

```
```c
char *strcat(char *str1, const char *str2);
```
```

The strcat() function concatenates a copy of str2 to str1 and terminates str1 with a NULL. The NULL terminator, which originally ending the str1 string, is overwritten by the first character of str2. The str2 string is unchanged by this operation. If both the strings overlap in the memory, then the behavior of strcat() is undefined. In the C99 compiler, both the str1 and str2 parameters are qualified by the restrict type qualifier. The strcat() function returns the str1 string after the successful concatenation.
