The operator function in line number 25 takes one Time object as an argument and returns another Time object with the resultant value set in it. When the compiler encounters the ‘+’ operator in line number 55, it immediately checks whether obj1 and obj2 are built-in data types or user-defined types and then proceeds as required. In this case, the data type of obj1 and obj2 are found as of Time class and immediately, the compiler searches the class space for a definition of the ‘+’ operator for this class. The object on the right side of the operator, that is obj2, is furnished as an argument to the operator. In the operator function, the members of the object that reside in the left side of the operator are directly accessible. To access the values of the object on the right side of the operator, we use the arguments: obj2.hour, obj2.seconds, or obj2.minutes.
