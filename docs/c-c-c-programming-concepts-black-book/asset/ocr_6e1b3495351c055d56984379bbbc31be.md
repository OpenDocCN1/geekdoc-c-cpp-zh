# ## The switch Statement

The *switch* statement is used to select a particular statement by passing the enumeration to the *case* statement written inside it. The control of the program is at the *case* statement which decides the selection procedure. The structure of the *switch* statement is shown in Listing 17.35:

**Listing 17.35:** Showing the Structure of *switch* Statement

```
    int caseSwitch = 1;
    switch (caseSwitch)
    {
        case 0:
            Console.WriteLine("The case number is 0");
            break;
        case 1:
            Console.WriteLine("The case number is 1");
            break;
        default:
            Console.WriteLine("This is the default case");
            break;
    }
```

According to the structure of *switch* statement, if a *case* statement is selected, then after executing the related case block, the control is transferred out of the *switch* statement using the *break* statement (discussed later in this chapter). Moreover, every *switch* statement should have a *default* case which will be executed if the code encounters any *default* statement. Therefore, the points that should be considered while writing a *switch* statement are given as follows:

+   - The value of the *case* statement is unique. No two *case* statements can have the same case value.
+   - The *break* statement should be put after the execution of each *case* statement. This helps the control to come out of the loop once the selected case execution has completed.
+   - It is a good practice to use a *default* statement inside the *switch* statement code body.
