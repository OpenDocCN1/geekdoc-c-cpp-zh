Listing 24.14 shows the algorithm for insertion operation in a circular queue:

# Listing 24.14: Showing the Algorithm for Insertion

```
```
function QueueInsert(queue[maxsize], front, rear, item)
  begin
    if front = 1 and rear = maxsize, OR if front = rear + 1
      then
        Output "Queue Overflow"
        Return
    end if
    if front = 0
      then
        front = 1 and rear = 1
    else
      if rear = maxsize
        then
          rear = 1
        else
          rear = rear + 1
      end if
    end if
    queue[rear] = item
  end
```
```

As shown in Listing 24.14, the queue overflow condition takes place when the front pointer remains at one and the rear pointer reaches the maxsize of the queue. Queue overflow condition can also take place when the front pointer exceeds the rear pointer by one. Initially, when the queue is empty, both the pointers are set to one. To insert the elements in the queue, the rear pointer is checked against the maxsize of the queue. If the rear pointer is equal to the maxsize, then the pointer is again set to one; else, it is incremented by one.

Listing 24.15 shows the algorithm for deletion operation in a circular queue:

# Listing 24.15: Showing the Algorithm for Deletion

```
```
function QueueDelete(queue[maxsize], front, rear, item)
  begin
    if front = 0
      then
        Output "Queue underflow"
        Return
    end if
    item = queue[front]
    if front = rear
      then
        front = 0
        rear = 0
    else
      if front = maxsize
        then
          front = 1
        else
          front = front + 1
      end if
    end if
    Return item
  end
