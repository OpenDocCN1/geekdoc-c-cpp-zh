# qsort()

The qsort() function sorts an array using the Quicksort algorithm, which is considered as one of the efficient sorting techniques. The signature of the qsort() function is as follows:

```
```c
void qsort(void *buf, size_t num, size_t size,
           int (*compare) (const void *, const void *));
```
```

Number of elements present in an array is denoted by the num variable. Size of each variable is identified with the help of the size variable. The function pointed to a compare function pointer is used to compare two elements of the array. The compare function pointer must be in the following format:

```
```c
int func_name(const void *arg1, const void *arg2);
```
```

The compare function pointer returns one of the following values:

+   - **Less than zero** — Denotes that arg1 is less than arg2
+   - **Zero** — Denotes that arg1 is equal to arg2
+   - **Greater than zero** — Denotes that arg1 is greater than arg2

Let’s take an example of the qsort() function as mentioned in Listing 8.34:

Listing 8.34: Usage of qsort() function.

```
```c
#include<stdio.h>
#include<stdlib.h>

int array[10] = {29, 6, 652, 312, 72, 490, 55,176};
int compare(const void *num1, const void *num2);
int main()
{
    int i;

    printf("\n Original Unsorted Array \n\n");
    for(i=0; i < 8;i++)
    {
        printf(" %d ",array[i]);
    }

    qsort(array, 8, sizeof(int), compare);

    printf("\n\n Sorted Array \n\n");
    for(i=0; i < 8;i++)
    {
        printf(" %d ",array[i]);
    }
}
