## Strings

String can be defined as a collection of Unicode characters; however, in .NET, it is defined as a collection of the objects of System.Char. The value of the string represents the collective value of the character objects. In .NET Framework, we need to consider the following two points about a string:

- 1. The string is a reference type of Unicode characters
- 2. The class String is a .NET Framework class whose alias is of the type string

Therefore, the type string and the class String serve the same purpose in .NET Framework, which implies that a developer can use a string class or a String class to carry out the same operation. Let's now discuss about the usage of the string type with the help of some examples.

### Declaration of a String

String objects are immutable or read only. After a string object is created, its content cannot be changed. The methods, which offer modification of a string variable, return a new string variable that contains the modified value. A string type variable in .NET can be declared in the following ways:

```csharp
string str;
OR
string str = String.Empty;
OR
string str = "Hello world";
```

By default, when a string is declared, it has the empty string value. However, as shown in the preceding declaration, we can also declare the string specifically to an empty string by using the String.Empty field in the string class or assign the value to a string.

Let's discuss some of the functionalities of the string type. We start our discussion with the comparison of strings.

### String Comparison

String comparison can be done in two ways; by using either the “==” operator or the Compare() method of the string class. Let's demonstrate the two processes using some suitable examples. First, we compare the two strings using the “==” operator, as shown in Listing 17.13:

**Listing 17.13:** Showing the String Comparison Operation by Using the “==” Operator

```csharp
using System;
class Program
{
    public static void Main()
    {
        string first = "Hello";
        string second = "Bye";
        if (first == second)
        {
            Console.WriteLine("The strings are same");
        }
        else
        {
            Console.WriteLine("The strings are different");
        }
    }
}
```

In the preceding program, we have first declared the two strings and then compared them using the operator “==”. As we have chosen two different strings; therefore, the output of program would be as follows:

```text
The strings are different
```

Next, let's consider the Compare() method that belongs to the string class. This method accepts the two strings, which are to be compared, as its arguments; and it returns 0 if both the strings are similar and 1 if both the strings are different. The syntax of Compare() method is given as follows:

```csharp
int Compare(string string1, string string2)
```

## String Concatenation

Concatenation is nothing but adding two separate strings. This operation can also be performed in two different ways: by using either the plus “+” operator or the Concat() method of the string class. Listing 17.15 shows the concatenation operation performed by using the “+” operator:

**Listing 17.15:** Showing the Usage of the “+” Operator

```csharp
using System;
class Program
{
    public static void Main()
    {
        Console.WriteLine("Please enter the first string...");
        string s1 = Console.ReadLine();
        Console.WriteLine("Please enter the second string...");
        string s2 = Console.ReadLine();
        string concat = string.Empty;
        if (s1 != string.Empty && s2 != string.Empty)
        {
            Console.WriteLine("The concatenated string is...");
            concat = s1 + s2;
            Console.WriteLine(concat);
        }
        else
        {
            Console.WriteLine("Please enter the strings");
        }
    }
}
```

In the preceding program, we first read the inputs from the console, concatenate the two strings, and then display the result on the console. The output of the program is given as follows:

```text
Please enter the first string...
Hello
Please enter the second string...
World
The concatenated string is...
Hello World
```

Now let’s perform the same operation using the Concat() method of the string class. The Concat() method accepts the two strings, which are to be concatenated, as its arguments. This method has eight overloaded methods out of which five methods are applicable to the object type. Therefore, the Concat() method can be used for concatenating the instance of the Object class besides the string class. The syntax of the Concat() method is given as follows:

```csharp
string Concat(string str1, string str2);
```

**Listing 17.16:** Showing the Usage of the Concat() Method

