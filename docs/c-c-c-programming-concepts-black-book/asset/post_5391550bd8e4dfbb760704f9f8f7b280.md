
**Table 21.4: Noteworthy Methods of the Directory Class**

Next, let's learn about the DirectoryInfo class.

## The DirectoryInfo Class

The DirectoryInfo class is similar to the Directory class, but it contains all the public members. Therefore, to access the public members of the class, developers need to create an instance of the class and associate an appropriate path variable to its object. An instance of the DirectoryInfo class can be declared as follows:

```
DirectoryInfo directoryInfo = new DirectoryInfo(path);
```

In the preceding declaration, path indicates the directory path along with the name of the directory.

The methods of the DirectoryInfo class are mostly used in a situation where multiple directory operations need to be done on a single instance. Table 21.5 lists the important methods of the DirectoryInfo class:

**Table 21.5: Noteworthy Methods of the DirectoryInfo Class**

| Method | Description |
|---|---|
| Create() | Creates a directory at a user-specified location with the defined Windows security.<br><br>**Overloads:**<br>• `Create(System.Security.AccessControl.DirectorySecurity directorySecurity)` ➔ Creates a directory in the specified location with the defined Windows security attributes mentioned in the *DirectorySecurity* object. |
| CreateSubdirectory(string path) | Creates a sub-directory in the user-specified path. The path should contain the name of the sub-directory that needs to be created.<br>It returns an object of the *DirectoryInfo* class.<br>It only takes a user-defined path as an argument.<br><br>• `CreateSubdirectory(string path, System.Security.AccessControl.DirectorySecurity directorySecurity)` ➔ Creates a sub-directory in the specified location with the defined Windows security attributes mentioned in the *DirectorySecurity* object. |
| Delete() | Deletes the object of the *DirectoryInfo* class from the location in which the instance was first created.<br><br>• `Delete(bool isRecursive)` ➔ Deletes all the sub-directories and files that are created for the object of the *DirectoryInfo* class from the location in which the instance was first created. |
| **GetDirectories(string searchPattern)** | Returns a list of directories present in the object path.<br>It takes a search pattern string as an input.<br><br>**Overloads:**<br>• `GetDirectories(string searchPattern, SearchOption searchOption)` → Returns all the directories in the current directory as well as in its sub-directories if `searchOption` is set to the `AllDirectories` option. | **MoveTo(string destinationPath)** | Moves a directory and its content from one location to another.<br>This method takes only one argument, which contains the destination directory path. The source directory path is fetched from the `DirectoryInfo` object. |

Let’s now discuss the File class in detail.

## The File Class

As already learned, the File class is used to move, copy, create, open, delete, and append files. In a situation where we want to perform a single operation on a file, the File class can be used to execute the operation. Using this class, we can also change the metadata attributes, such as date-time related to the creation of a file. As all the methods of the File class are static, most of the methods return the FileStream object. Table 21.6 lists the noteworthy methods of the File class:

**Table 21.6: Noteworthy Methods of the File Class**

| Method | Description |
|---|---|
| **AppendAllText(string path, string appendedText)** | Appends the text in a file. If the file is not present in the specified location, then it creates the file in that path.<br>It takes two arguments: one is the user-defined path and another is the text that is to be appended.<br><br>**Overloads:**<br>• `AppendAllText(string path, string appendedText, System.Text.Encoding encoding)` → Appends the text in a file by applying the specified encoding type. |
| **AppendText(string path)** | Appends a UTF-8 encoded text to a file mentioned in the user-defined path. It returns an object of the `StreamWriter` class.<br>It only takes a user-defined path as an argument. |
