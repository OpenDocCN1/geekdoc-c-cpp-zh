Table 20.2: Noteworthy Methods of the XmlTextReader Class

| Method | Description |
|---|---|
| `MoveToElement()` | Returns true if it moves the class object to the element that contains the current attribute node. |
| `MoveToFirstAttribute()` | Returns true if it moves the class object to the first attribute of an element; otherwise, it returns false. |
| `MoveToNextAttribute()` | Returns true if it moves the class object to the next attribute of an element; otherwise, it returns false. |
| `Read()` | Returns true if it reads the next node from the file stream. |
| `ReadAttributeValue()` | Returns true if it parses an attribute value into one or more text, entity reference, or end entity node. |
| `ReadEndElement()` | Checks whether the current content node is an end element node. If it is an end element node, then it moves the pointer to the next node. |
| `ReadInnerXml()` | Reads the content including the markup text as a string and returns this string. This method is a member of the base class XmlReader. |
| `ReadOuterXml()` | Reads the content including the markup text of the specified XML node and all its children nodes and returns the string. This method is a member of the base class XmlReader. |
| `ReadStartElement()` | Checks whether the current node represents the start element node. If not, then it moves the pointer to the next node.<br><br>Overloads:<br>• `IsStartElement(string name)` → Checks whether the current node represents the start element node with the specified name of the element.<br>• `IsStartElement(string localName, string namespaceURI)` → Checks whether the current node represents the start element node with the specified local name and namespace URI. |
| `ReadString()` | Reads the content or text of an element as a string and returns that string. |
| `ReadSubtree()` | Returns an object of the XmlReader class which can be used to read the current element and all its descendants. |
| `ReadToDescendant(string localName)` | Returns true if it finds the descendant with the specified local name while advancing the pointer of the XmlReader object.<br><br>Overloads:<br>• `ReadToDescendant(string localName, string namespaceURI)` → Checks the descendant value with respect to its local name and namespace URI. |
| `ReadToFollowing(string name)` | Returns true if it finds an element with the given name of the element advancing the XmlReader pointer.<br><br>Overloads:<br>• `ReadToFollowing(string localName, string namespaceURI)` → Checks the element with respect to the given local name and namespace URI of the element and returns true if it finds any match. |
| `ReadToNextSibling(string name)` | Returns true if it finds a sibling element with the given name of the element advancing the XmlReader pointer. |
