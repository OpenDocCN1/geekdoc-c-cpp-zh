# ### localtime()

The localtime() function returns a pointer to the time in the form of a structure. The structure used by the function to hold the time is statically allocated and is overwritten every time it is called. Time is represented in the local time format. The variable passed as an argument to the localtime() function is received with the help of a time() function. The signature of the localtime() function is as follows:

```
```c
struct tm *localtime(const time_t *time);
```
```

Let's take an example of the localtime() function as mentioned in Listing 8.20:

Listing 8.20: Usage of localtime() function.

```
```c
#include<stdio.h>
#include<time.h>

int main()
{
    struct tm *gmt;

    time_t t1;

    t1 = time(NULL);
    gmt = localtime(&t1);

    printf("\n The UTC time is %s ",asctime(gmt));

    getch();
}
```

The Local time is Tue Mar 27 00:07:47 2012
