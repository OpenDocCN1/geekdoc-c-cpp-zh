# runtime_error()

Some errors can only be determined during runtime. The runtime_error() class defines the type of objects thrown as exceptions to highlight such errors.

Its subclass logic_error is required as a base for exceptions exposing an error, which might be prevented before runtime. The constructor uses a standard string target as a parameter. This value is stored within the object, and is required to generate the C-string returned by the means of its inherited function what().

# range_error()

This class defines the kind of objects thrown as exceptions to emphasize the range errors within internal computations. It is designed in such a way that apart from the elements of the standard library, any program can throw it as an exception. The class can be defined as follows:

```
```cpp
class range_error : public runtime_error
{
public:
    explicit range_error (const string& what_arg);
};
```
```

# overflow_error()

The overflow_error() class defines the type of objects thrown as exceptions to emphasize the arithmetic overflow errors. We may define this class as follows:

```
```cpp
class overflow_error : public runtime_error
{
public:
    explicit overflow_error (const string& what_arg);
};
```
