+   - The first line inside the body of the function is the variable declaration. It tells the compiler to reserve a block of memory taken by an integer for the variable named test.
+   - The next line is used for displaying the output. This line calls the print function with arguments as Enter a number. printf is a library function that prints the output
+   - Similarly, the next line calls the scanf function, which reads the entered input.
+   - Finally, the program terminates with a closing curly brace.
