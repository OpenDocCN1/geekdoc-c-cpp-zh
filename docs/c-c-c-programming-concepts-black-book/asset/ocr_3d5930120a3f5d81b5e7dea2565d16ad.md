Computer is a machine to store, manipulate, and retrieve the data. However, all these operations depend on how the data is represented or on how the data is organized in the memory. Therefore, in computer science, a study regarding different types of organization of the data has been included, which is known as data structure. In other words, data structure is a way of storing and organizing the data in the memory or the disk storage. Data structure represents a logical or mathematical model of data storage using which we can efficiently use the data in our applications.

After developing a data structure, the next step that we need to focus on is how to insert a data, search for a specific data, or delete a specific data from the data structure. In this case, algorithms come in rescue, as they provide a way to manipulate the data by developing different techniques of accessing and modifying the data inside the data structure.

First, the chapter discusses abstract data type, the infix, prefix, and postfix notations, complexity of an algorithm, and algorithm case analysis. # # Data Structures

As already learned, data structure provides a way of storing data in the computer memory. Computer memory may store the data in a sequential manner or it may store the data depending on some specific pattern. Following are the two types of data structures:

+   - **Linear data structure**—It forms a sequence of elements or a linear list. Following is a list of linear data structures:
+       1. Array
+       2. Stack
+       3. Queue
+       4. Linked list
+   - **Non-linear data structure**—It represents the data in a hierarchical manner. Following is a list of non-linear data structures:
+       1. Tree
+       2. Graph
