# Opening a File

In C, the first step toward file management is opening a file, which includes creation of a temporary buffer area where the data being read from the file will be stored in the primary memory. The temporary buffer helps in minimizing the disk access while a chunk of data is fetched from auxiliary storage. Imagine a situation where every character being fetched from the file required a disk access. In such a situation, performing I/O operations would have been impossible because of the huge latency of disk access. To avoid these circumstances, the information is taken up into an intermediate buffer when the file is first opened and then the content is read character by character from the buffer itself.

To perform operations on a file and gather information about the file, C uses a function called fopen(), which is used to open a file. A general form of the fopen() function is as follows:

```
```c
FILE *fptr = fopen(file-name, file-type);
```
```

In the preceding format, FILE is a special structure, which is responsible for the information of the file that is opened. The signature of fopen() is given as follows:

```
```c
FILE *fopen(const char *restrict filename, const char *restrict mode);
```
```

In the preceding signature, fopen() returns a pointer of type FILE that contains all the necessary information about a file; the same is held by the pointer defined as fptr. The file name and file type are strings that represent name of the file and the type in which the file will be used, respectively. File types are also referred as modes of files. Table 5.1 provides a detailed coverage on different file types:

**Table 5.1: Different File Types**

| File Type | Operations Possible | Description |
|---|---|---|
| `r` | Reading | Open an existing file for reading. |
| `w` | Writing | Open a file for writing only. If the file exists, then its contents are overwritten; else, a new file is created. |
| `a` | Adding new information | Open an existing file for appending information at the end of the file. A new file is created, if the file does not exist. |
| `r+` | Reading, writing, and appending information | Open an existing file for reading as well as writing. |
| `w+` | Writing, reading, and appending new information | Open a file for writing as well as reading. If the file already exists, then its contents are overwritten; else, a new file is created. |
| `a+` | Reading and Appending | Open an existing file for appending as well as reading. In this case, existing contents cannot be modified. |
