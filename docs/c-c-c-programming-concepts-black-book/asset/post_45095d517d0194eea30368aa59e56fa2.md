## Overloading Binary Operators

Binary operators are those operators that operate on two operands at the same time. Some of the examples of binary operators are addition (+), multiplication (*), subtraction (-), and division (/). Binary operators can be overloaded similar to unary operators. Let’s write the following program to overload the binary addition

```cpp
1:/* Operator Overloading Example Program 5 */
2:#include <iostream.h>
3:using namespace std;
4:
5:class Time {
    int hour;
    int minutes;
    int seconds;

public:
    Time()
    {
        hour=minutes=seconds=0;
    }
    Time(int hr, int min, int sec)
    {
        hour = hr;
        minutes = min;
        seconds = sec;
    }
    int showTime ()
    {
        cout<<"The Time is: "<<hour<<":"<<minutes<<":"<<seconds<<endl;
    }
    Time operator + (Time T2)
    {
        int hr,min,sec;
        hr=min=sec=0;
        hr = hour + T2.hour;
        sec = seconds + T2.seconds;
        if (sec >= 60) {
            min = sec / 60;
            sec = sec % 60;
        }
        min += minutes + T2.minutes;
        if (min >= 60) {
            hour += (min / 60);
            min = min % 60;
        }
        return Time(hr,min,sec);
    }
};

int main()
{
    Time obj1(12,20,23);
    Time obj2(20,45,30);
    Time obj3, obj4;

    obj1.showTime();
    obj2.showTime();
    obj3.showTime();
    obj4.showTime();

    obj3 = obj1 + obj2;

    obj1.showTime();
    obj2.showTime();
    obj3.showTime();
    obj4.showTime();

62:        obj4 = obj1 + obj2 + obj3;
63:
64:        obj1.showTime();
65:        obj2.showTime();
66:        obj3.showTime();
67:        obj4.showTime();
68:
69:        return 0;
70:}
```

To show that the result of addition can be used in addition as well as in assignment, addition operation is performed in the main() function. That is, we have added obj1, obj2, and obj3 to obtain obj4 in line number 62. Let's first see the output before going into further explanation:

```text
The Time is:  12:20:23
The Time is:  20:45:30
The Time is:  0:0:0
The Time is:  0:0:0

The Time is:  12:20:23
The Time is:  20:45:30
The Time is:  32:5:53
The Time is:  0:0:0

The Time is:  12:20:23
The Time is:  20:45:30
The Time is:  33:5:53
```

In the Time class, the declaration for the operator+() is as follows:

```cpp
Time operator + (Time T2);
```

The preceding function takes one argument of type Time and returns a value of type Time. It is very important to understand how the return values and the arguments of the operator relate to the objects. The operator function at line number 25 adds two Time objects and returns another Time object with the resultant value set into it. The Time object contains the time in the hour:minutes:seconds format, and after the addition, the result is also expected to follow similar format with the values of seconds and minutes kept under 60. The operator function in line number 25 takes one Time object as an argument and returns another Time object with the resultant value set in it. When the compiler encounters the ‘+’ operator in line number 55, it immediately checks whether obj1 and obj2 are built-in data types or user-defined types and then proceeds as required. In this case, the data type of obj1 and obj2 are found as of Time class and immediately, the compiler searches the class space for a definition of the ‘+’ operator for this class. As the compiler finds the definition, it executes the code block implemented to overload the ‘+’ operator.

In line number 55, the argument on the left side of the operator, that is obj1, is the object of which the operator is a member. The object on the right side of the operator, that is obj2, is furnished as an argument to the operator. After the function is executed, the result of the operation is returned in a nameless temporary object and stored in obj3.

In the operator function, the members of the object that reside in the left side of the operator are directly accessible. Therefore, in our case, we can directly access the member variables of obj1 in the operator function. To access the values of the object on the right side of the operator, we use the arguments: obj2.hour, obj2.seconds, or obj2.minutes. As already learned, an overloaded operator always requires one less argument than the number of operands. Similar calculation logic is applied in line number 63, where we are adding three objects of Time class to get the resultant value. In this case, addition between obj2 and obj3 is done at first and then another addition is done between obj1 and the nameless object returned as a result of the addition between obj2 and obj3 to get the final value.
