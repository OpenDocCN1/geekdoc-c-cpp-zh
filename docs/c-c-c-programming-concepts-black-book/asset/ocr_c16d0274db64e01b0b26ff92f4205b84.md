As suggested in Figure 1.4, the argument given against the switch statement is compared against each of the case statement. If the decision happens to be true, it means that a match has been found, so execute the statement under that case; if not, then match it against the next case.

Listing 1.20 shows a simple switch statement in C:

# Listing 1.20: Simple Switch Statement

```
```c
# include<stdio.h>

int main()
{
    int choice;

    printf("\n Enter your choice from (1/2/3) ");
    scanf("%d",&choice);

    switch(choice)
    {
        case 1:
            printf("\n choice is 1");
        case 2:
            printf("\n choice is 2");
        case 3:
            printf("\n choice is 3");
        default:
            printf("\n wrong Choice");
    }
    getch();
}
```
```

The output is not valid as the program displays all the options that we have provided inside the switch statement instead of displaying only the correct option. This happens because the switch statement executes all the case statements including the default statement.
