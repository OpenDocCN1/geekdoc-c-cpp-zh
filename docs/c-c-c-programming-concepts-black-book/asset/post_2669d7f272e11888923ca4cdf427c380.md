
## Switch Case Paradigm in C

The switch statement used in C allows the user to make a decision based on a number of choices. It is a built-in branch selection utility inside C. It tests the value of an expression against a list of integer or character constants. When a correct match is found, the statements associated with that constant get executed.

The following code snippet shows the generic form of the switch statement:

```c
switch(expression)
{
        case constant1:
                statement sequence
                break;
        case constant2:
                statement sequence
                break;
        case constant3:
                statement sequence
                break;
        .
        .
        .
        default:
                statement sequence
}
```

The expression inside the switch keyword should always evaluate to an integer type. We can have integers and characters as valid expressions; however, floating point expressions are not allowed for the switch keyword. The value of the expression is tested with the values provided in the case statements. Once a match is found, the set of statements following that match gets executed until the break or the end of the switch statement is hit. The default statement gets executed, if no match is found. The constant used in each case should be different from the other.

Listing 1.20 shows a simple switch statement in C:

### Listing 1.20: Simple Switch Statement

```c
#include<stdio.h>

int main()
{
    int choice;

    printf("\n Enter your choice from (1/2/3) ");
    scanf("%d",&choice);

    switch(choice)
    {
        case 1:
            printf("\n choice is 1");
        case 2:
            printf("\n choice is 2");
        case 3:
            printf("\n choice is 3");
        default:
            printf("\n wrong Choice");
    }
    getch();
}
```

The output of Listing 1.20 is given as follows:

```text
Enter your choice from (1/2/3) 1

Choice is 1
Choice is 2
Choice is 3
Wrong Choice
```

The output is not valid as the program displays all the options that we have provided inside the switch statement instead of displaying only the correct option. This happens because the switch statement executes all the case statements including the default statement. If we want that only the statements mentioned under a case should get executed and subsequent case statements should be skipped, then we have to use the break statement.

Listing 1.21 shows the switch case with the break statement:

### Listing 1.21: Switch Case with Break

```c
#include<stdio.h>

int main()
{
    int choice;

    printf("\n Enter your choice from (1/2/3) ");
    scanf("%d",&choice);

    switch(choice)
    {
        case 1:
            printf("\n Choice is 1");
            break;
        case 2:
            printf("\n choice is 2");
            break;
        case 3:
            printf("\n Choice is 3");
            break;
        default:
            printf("\n wrong Choice");
    }
    getch();
}
```

The output of Listing 1.21 is given as follows:

```text
Enter your choice from (1/2/3) 1
Choice is 1
```

The value entered against the variable "choice" is compared against the first case statement, which checks if the choice is 1 or not. In our case, the choice is 1, so the statements inside the case get executed and the message is displayed. After displaying the message, the break statement gets executed which takes the control out of the switch statement, so no other comparison takes place. The default statement is optional, as it signifies what needs to be done if a match is absent from the switch statement.

Different versions of compilers support different numbers of case statements. Some of the compilers cannot support more than 257 case statements; whereas, some of them even go beyond 1023 case statements. Some important points that should be remembered while working with switch statements are as follows:

- A case statement is basically a label; however, it cannot exist by itself outside the switch statement.
- Whenever a break is encountered, the control shifts to the line of code following the switch statement.
- The switch statement differs from the if statement. Switch can not only test for equality but can evaluate expressions as well.
- No two cases in the switch statement can have identical values.
- Characters used in the switch statement are automatically converted to integers.

Listing 1.22 shows the usage of character variables in switch statements:

### Listing 1.22: Character Variables in Switch Case

```c
#include<stdio.h>

int main()
{
    char choice='A';

    switch(choice)
    {
        case 'A':
            printf("\n Choice is A");
            break;
        case 'B':
            printf("\n Choice is B");
            break;
        case 'C':
            printf("\n Choice is C");
            break;
        default:
            printf("\n wrong Choice");
    }
    getch();
}
```

The output of Listing 1.22 is given as follows:

```text
Choice is A
```

The code in Listing 1.22 shows how to use characters inside a switch statement. When we use characters like A, B, and C, it is actually their ASCII values which replace the characters.

Listing 1.23 shows an alternate way of writing Listing 1.22:

### Listing 1.23: Floating Point Expression in Switch-Case Statements

```c
#include<stdio.h>

int main()
{
    float choice=3.5;

    switch(choice)
    {
        case 4.2:
            printf("\n choice is 4.2");
            break;
        case 9.3:
            printf("\n choice is 9.3");
            break;
        case 8.8:
            printf("\n choice is 8.8");
            break;
        default:
            printf("\n wrong Choice");
    }
    getch();
}
```

The output of Listing 1.23 generates a compile time error, as follows:

```text
switch quantity not an integer
case label does not reduce to an integer constant
```

We cannot use floating point variables inside a switch statement as it is disallowed by the compiler itself. One of main reason for this issue could be that the output obtained by using floating point variables is less accurate. There can be certain scenarios where we may want to use multiple case statements together. Listing 1.24 shows how we can have multiple statements inside a single case:

### Listing 1.24: Multiple statements in Switch Case

```c
#include<stdio.h>

int main()
{
    char choice='a';

    switch(choice)
    {
        case 'A':
        case 'a':
            printf("\n choice is A");
            break;
        case 'B':
        case 'b':
            printf("\n Choice is B");
            break;
        case 'C':
        case 'c':
            printf("\n Choice is C");
            break;
        default:
            printf("\n wrong Choice");
    }
    getch();
}
```

After executing the first case statement, the control simply goes to the next statement until a break point is encountered. In this scenario, for a match against any one of the cases—case A or case a—a set of defined instructions will be executed.

You can also use a logical expression inside a switch statement. The statement, shown in the following code snippet, will perfectly execute in C:

```c
case(3+5)
```

Listing 1.25 shows different uses of the switch statement:

### Listing 1.25: Different uses of the Switch Statement

```c
#include<stdio.h>

int main()
{
    int choice;

    printf("\n Enter your choice from (1/2/3) ");
    scanf("%d",&choice);

    switch(choice)
    {
        case (1+4):
            printf("\n Choice is 1");
            break;
        case 2:
            printf("\n Choice is 2");
            break;
        case 3:
            printf("\n Choice is 3");
            break;
        default:
            printf("\n wrong Choice");
    }
    getch();
}
```

If the user enters the option as 5, then the output will be shown as follows:

```text
Enter your choice from (1/2/3) 5

Choice is 1
```

This happens because the case statement internally computes the value and compares against the result.
