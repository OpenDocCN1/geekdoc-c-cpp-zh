Microsoft first came with Active Server Pages (ASP) that provides a server side scripting language using which a developer can create dynamically generated Web pages. This is often called classic ASP. ASP was released on the Internet Information Service 4.0 (IIS 4.0). However, it has the problem with separating the presentation and content of the code. This compelled the developers in Microsoft to come up with a platform that help in writing a clean code.

In the year 2002, Microsoft introduced the successor of ASP known as ASP.NET. Though it is the successor, ASP.NET represents a Web application framework using which a developer can develop Web pages, Web applications, and Web services. This is built on the Common Language Runtime (CLR) platform that helps the developer to choose the languages supported by CLR to develop their Web applications. It also provides the environment of Object-Oriented Programming (OOP), garbage collection, and other features that was not supported by Microsoft's Component Object Model (COM) platform.

In the year 2000, as a response to Java, Microsoft has introduced the new language C Sharp whose name was inspired by the musical note C#. This language was Microsoft’s attempt to provide a modern, general-purpose OOP language. C# embeds a large amount of system programming that helps in developing any software component. The functionalities of C# are similar to that of JAVA, but it is not intended to compete with C or any assembly level language.

In this chapter, we learn about the .NET architecture, which includes CLR and class library. After that, we explore the assembly in C# as well as the memory management in C# with the help of garbage collection technique. Towards the end of the chapter, we give an introductory discussion on C# language and represent a comparative study on various versions of C#.

Let’s start with the introduction to .NET architecture.

# Introduction to .NET Architecture

The .NET Framework is the main building block of .NET architecture that is introduced to develop and execute highly distributed component-based applications. It enables different programming languages to work together in the same environment. Component-based application refers to the applications that support COM, which provides inter-process communication along with the dynamic object creation in large range of programming languages.

In the Windows platform, the .NET Framework provides security, program portability, and a common programming model to develop applications. It is widely known for its language interoperability, which can be done by using CLR. Figure 16.1 shows a simplified view of the .NET architecture:
