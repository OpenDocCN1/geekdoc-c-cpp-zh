# Binary Files

A binary file is a collection of bytes. Example of a binary file is an audio file that contains characters, which are non-printable. Difference between a text file and a binary file is in the way end of file is detected for both the files. For text files, a special character with an ASCII value of 26 is regarded as an end of file character. If this character is encountered, then it signifies that the end of file has been reached. However, there is no such special character present in binary files. End of file is determined by the size of the file. It might happen that a binary file is used for storing numbers. In such case, a number 26 can signify end of file and cause a premature termination of the program. In a text file, a new line character is converted into a carriage return-linefeed combination (\r\n) and then it is written into the file. However, if a file is opened in the binary mode, then this sort of conversion will not take place.
