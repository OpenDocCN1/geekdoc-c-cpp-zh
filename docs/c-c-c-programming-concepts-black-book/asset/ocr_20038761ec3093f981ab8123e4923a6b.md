There are different ways of passing a structure to a function; let’s learn about them in detail.

# Passing Structures to Functions

One of the simplest approaches to pass a structure to a function is to pass the structure members individually to the function. Individual structure members can be passed to a function similar to normal variables and no added handling is required for them.

Another approach is to transfer an entire structure to a function as a whole. This is done by passing a structure type pointer as an argument to a function. The process is similar to passing an array to a function. The structure is passed by reference instead of passing by value. In this case, if a value of any member is altered within the function, then that change will be reflected outside the function as well.
