### Nesting If-Else Statements

It is possible to have multiple if-else statements nested within each other. The requirement of such a construct comes when we have a complex decision making problem where we can have multiple branches or sub-branches within a branch.

Consider a scenario where we need to assign grades to students based on the percentage obtained in exams. The criterion for grading is as follows:

- 91% and above – Grade A
- 75% - 90% - Grade B
- 50% - 74% - Grade C
- 35% - 49% - Just Passed
- Below 35% - Fail

Listing 1.13 shows nesting of the if-else statements:

**Listing 1.13: Nesting of if-else Statements**

```c
#include<stdio.h>

int main()
{
    int marks_obtained;
    float percentage;

    printf("\n Enter marks obtained by candidate out of 500 ");
    scanf("%d",&marks_obtained);

    percentage = marks_obtained/5;

    if(percentage > 90)
    {
        printf("\n Grade Obtained is A");
    }
    else
    {
        if(percentage > 74)
        {
            printf("\n Grade Obtained is B");
        }
        else
        {
            if(percentage > 50)
            {
                printf("\n Grade obtained is C");
            }
            else
            {
                if(percentage > 39)
                {
                    printf("\n Grade obtained is Just Passed");
                }
                else
                {
                    printf("\n Candidate Failed");
                }
            }
        }
    }
    getch();
}
```

The output of Listing 1.13 is given as follows:

```text
Enter marks obtained by candidate out of 500 490

Grade Obtained is A

Enter marks obtained by candidate out of 500 100

Candidate Failed
```

In Listing 1.13, the second if-else construct is nested within the else block of the first if-else construct. The idea is that if the first if statement fails, then the control shifts to the statements within the respective else block and then the if-else block within the first else block will be executed. It is not always necessary that the nesting needs to take place inside the else block; it may take place inside the if block as well. However, it is extremely necessary that the code must be properly indented; otherwise, misplaced if-else blocks could occur. In addition, it is a good programming practice to include both single and multiple types of statements inside curly braces, as this increases the readability of the code.

There are different types of nesting. Some of them are described as follows:

- 1. `if(expression)`
  `statement;`
- 2. `if(expression)`
  ```c
  {
      statements;
  }
  ```

### The else-if Statement

The else-if statement is another way of writing decision making programs.

Listing 1.17 shows a program written using an else-if block:

**Listing 1.17: Writing the else-if Statement in C**

```c
#include<stdio.h>

int main()
{
    int marks_obtained;
    float percentage;

    printf("\n Enter marks obtained by candidate out of 500 ");
    scanf("%d",&marks_obtained);

    percentage = marks_obtained/5;

    if(percentage > 90)
    {
        printf("\n Grade Obtained is A");
    }
    else if(percentage > 74)
    {
        printf("\n Grade Obtained is B");
    }
    else if(percentage > 49)
    {
        printf("\n Grade Obtained is C");
    }
    else if(percentage > 34)
    {
        printf("\n Grade Obtained is Just Passed");
    }
    else
        printf("\n Candidate Failed");

    getch();
}
```

The output of Listing 1.17 is given as follows:

```text
Enter marks obtained by candidate out of 500 490

Grade Obtained is A
```

The else-if statement is another way of writing the if-else statement.

The following code snippet shows an example of a generic if-else statement:

```c
if(expression)
{
    statements;
}
else
{
    if(expression)
        statement;
}
```

The preceding code can be rearranged using an else-if construct as:

```c
if(expression)
{
    statements;
}
else if(expression)
    statement;
```

### The Conditional Operators

Another set of relevant operators required for decision making are ? and :. These operators are often referred to as ternary operators, as they take up three arguments. Combined together, they form a reduced version of an if-else statement.

```text
expression ? statement 1 : statement2
```

The expression shown above means that if an expression is true, then statement 1 will execute, else statement 2 will execute. Listing 1.18 shows how to write conditional operators in C:

**Listing 1.18: Writing Conditional Operators in C**

```c
#include<stdio.h>

int main()
{
    int varA=10;

    (varA < 5 ? printf("\n Less than 5"):printf("\n Greater than 5"));

    getch();
}
```

The output of Listing 1.18 is given as follows:

```text
Greater than 5
```

Listing 1.19 shows the use of conditional operators in C:

**Listing 1.19: Conditional Operators in C**

```c
#include<stdio.h>

int main()
{
    int gender,age;

    printf("\n Enter your Gender (1. MALE/ 2. FEMALE)");
    scanf("%d",&gender);
    printf("\n Enter age ");
    scanf("%d",&age);

    ((gender == 1) ?
        ((age > 18) ? printf("\n Qualified"):printf("\n Disqualified"))
        :
        ((age > 24) ? printf("\n Qualified"):printf("\n Disqualified"))
    );
    getch();
}
```

One of major shortcomings of using conditional operators is that we can only have a single statement inside a true and false block of a conditional statement. So, this construct is not frequently used.
