From the preceding output, we can see that the program runs successfully whenever the obj object of the derived class access the member function of the base class. Now, let’s learn about the various options of access specifier and their impact in a program.

When the access specifier for a base class is public, all the public members of the base class become the public members of the derived class, and all the protected members of the base class become the protected members of the derived class. For example, in the preceding program, the object of the derived class can directly access the public members of the base class, that is the set() and showBase() functions. In all the cases, the private members of the base class remain private to the base class and are not accessible by any member of the derived class.

When the base class is inherited by using the private access specifier, all the public and protected members of the base class become private members of the derived class.
