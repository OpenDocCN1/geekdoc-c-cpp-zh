![](bbox=[0.411, 0.411, 0.612, 0.499])

When the object e2 is assigned to the object e1, the reference pointer of e1 is changed. Therefore, when we print the values on the console, both the objects will print Thomas. After assigning e2 to e1, the reference of e2 is copied to the reference of e1. Therefore, the memory location of e1 is same as that of e2, as shown in Figure 17.4:
