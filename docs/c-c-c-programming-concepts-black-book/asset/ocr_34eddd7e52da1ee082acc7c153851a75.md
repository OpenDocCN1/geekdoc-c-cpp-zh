| Table 20.4: Noteworthy Methods of the XmlDocument Class |  |
|---|---|
| **Method** | **Description** |
| `InsertBefore(XmlNode newChildNode, XmlNode refChildNode)` | Inserts a new child node immediately before the reference child node. |
| `Load(string fileName)` | Loads an XML document to the XmlDocument object from the given URL. **Overloads:**<br>• `Load(Stream streamReader)` → Loads an XML document to the XmlDocument object from the given Stream object.<br>• `Load(TextReader reader)` → Loads an XML document to the XmlDocument object from the given TextReader object.<br>• `Load(XmlReader reader)` → Loads an XML document to the XmlDocument object from the given XmlReader object. |
| `LoadXml(string xml)` | Loads an XML document to the XmlDocument object from the given URL. |
| `PrependChild(XmlNode newChildNode)` | Adds a new child node at the beginning of the list of child nodes of a node, which calls this method. |
| `ReadNode(XmlReader reader)` | Returns an object of XmlNode based on the XmlReader object. The pointer in the XmlReader object should point to a node or attribute. |
| `RemoveAll()` | Removes all the child nodes of a node. |
| `RemoveChild(XmlNode childNode)` | Deletes the given child node of a node. |
| `ReplaceChild(XmlNode newChildNode, XmlNode oldChildNode)` | Replaces the old child node with the new child node of a node. |
| `Save(string fileName)` | Saves an XML document to the given URL. **Overloads:**<br>• `Save(Stream streamWriter)` → Saves an XML document to the given Stream object.<br>• `Save(TextWriter writer)` → Saves an XML document to the given TextWriter object.<br>• `Save(XmlWriter writer)` → Saves an XML document to the given XmlWriter object. |
| `SelectNodes(string xPath)` | Returns the object of XmlNodeList that contains the nodes matching the given XPath expression. **Overloads:**<br>• `SelectNodes(string xPath, XmlNamespaceManager nsmgr)` → Returns the object of XmlNodeList that contains the nodes matching the given XPath expression. Any prefixes found during the match are resolved by the object nsmgr. |
| `SelectSingleNode(string XPath)` | Returns a single XmlNode only. This method is same as the SelectNodes() method. |
| `Validate(Xml.Schema.ValidationEventHandler, XmlNode)` | Validates the given node against the supplied XSDLanguage of the XmlDocument object. |
