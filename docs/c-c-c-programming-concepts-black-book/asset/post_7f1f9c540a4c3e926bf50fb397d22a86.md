## Chapter 18

C# is an Object-Oriented Programming (OOP) language where the structure of a program depends on the implementation of classes and their objects at the right place in the program. Apart from classes and objects, OOP provides features, such as data abstraction, encapsulation, polymorphism, and inheritance. In C#, we generally declare a namespace, which is a collection of classes, and some enumerator variables at the beginning of the program. For example, if we want to work with the files and directories, then we need to declare the System.IO namespace that contains all the necessary classes used for operations related to files and directories. Therefore, by instantiating the appropriate instances of these classes, we can develop any application on files and directories.

This chapter starts with the discussion on classes in the context of C#. We also learn about the concept of inheritance, generalization, and specialization used in C#. Next, we move on to the implementation of polymorphism and operator overloading with suitable examples. This chapter also includes the study of access modifiers and their implementation in real life scenario. Towards the end, we learn about interfaces, enumerators, and generics in C#.

Let’s start the chapter with the discussion on classes.

### Classes in C#

A class represents an encapsulated form that holds the properties, methods, and events of a real life instance. For example, if we declare the class Employee, then it should have the following details embedded in itself:

- **Properties** – The Employee class should have Employee_ID, first_name, last_name, designation, salary, manager_ID, and Project_ID as its properties.
- **Methods** – The Employee class can have methods specific to the application.
- **Events** – .NET provides events that are associated with the controls. For example, if we have a text box to hold the salary of an employee, then on text change, an event will be fired that add the rupee sign before the salary. These controls add extra features to the programming and make it more attractive to a user.

Therefore, we can conclude that a class represents a black box that encapsulates all the low-level information. When we use the class, we need not waste any time in discovering what information is encapsulated inside the class. We just need to create as many objects as we need to frame our application. In addition, by using abstraction, a class hides all the details of its properties and methods.

Now, let's learn how to write member variables and methods for a class using C#. Listing 18.2 shows the C# code containing the complete class definition:

### Listing 18.2: Showing the Class Definition for the Employee Class

```csharp
using System;

namespace Employee
{
    class Program
    {
        public static void Main()
        {
            Employee emp = new Employee("George", "Mathew",
                                         "Associate", 20000, 100, 222);
            emp.IncrementSalary();
        }
    }

    public class Employee
    {
        //Declaring member variables
        public int Employee_ID;
        public string first_name;
        public string last_name;
        public string designation;
        public long salary;
        public int manager_ID;
        public int project_ID;

        //Declaring Constructors
        public Employee()
        {
        }

        //Declaring parameterized constructor
        public Employee(string firstName, string lastName,
                string designation, long salary, int managerID, int projectID)
        {
            this.first_name = firstName;
            this.last_name = lastName;
            this.designation = designation;
            this.salary = salary;
            this.manager_ID = managerID;
            this.project_ID = projectID;
        }

        //Declaring member methods
        public void IncrementSalary()
        {
            if (designation == "Trainee")
            {
                salary += 5000;
                Console.WriteLine("The revised salary is {0}", salary);
            }
            else if (designation == "Associate")
            {
                salary += 10000;
                Console.WriteLine("The revised salary is {0}", salary);
            }
            else if (designation == "Manager")
            {
                salary += 20000;
                Console.WriteLine("The revised salary is {0}", salary);
            }
            else
            {
                Console.WriteLine("Please provide an appropriate designation");
            }
        }
    }
}
```

In the preceding program, we have first defined the member variables required for an employee. Next, we have declared the constructors that help in instantiating an object of that class. Then, we have written a member method that increments the salary of an employee depending on its designation. We learn more about these features later in this section.
