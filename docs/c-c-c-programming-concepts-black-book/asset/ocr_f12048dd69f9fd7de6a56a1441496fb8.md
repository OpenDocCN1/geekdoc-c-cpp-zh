# ### Second Generation Programming Languages

Second generation languages or 2GLs are more English like and capable of expressing the normal logic used by the programmers. These languages were introduced in late 1950s with FORTRAN. Second generation languages are used to employ a static storage model where data storage was allocated only once, i.e. when the program is loaded. This resulted in making recursions difficult. Algol, another second generation programming language, was used to provide block structured naming constructs and expanded the set of features available to programmers, like concurrency management. The symbolic representation of machine instructions, registers, and memory addresses allow programmers to produce a human-readable program. An assembler is needed to convert the English like language to mnemonics and then through one-to-one mapping technique, this mnemonic is translated to the corresponding machine readable format. This language generates a machine-optimized assembly language version of a particular function. Second-generation languages are sometimes used in kernels and device drivers.

# ### Third Generation Programming Languages

Third generation programming languages (3GLs) were mainly introduced to overcome the limitations of 2GLs. 3GLs were developed in a way that they remain independent of the architecture of the computer on which the algorithm is run. Therefore, we can say that 3GLs were hardware independent. The code written in a 3GL is first converted to the assembly language by a compiler and then the assembler translates the code from assembly language into the machine readable form (binary form). While the steps to interpret 3GL were similar to those of 2GL, there was no need of one-to-one mapping between codes, segments, and machine codes. 3GL compilers could target different hardware and produce different translations of the same source code commands.

Structured programming was practiced in 3GLs where a program model was seen as a hierarchy of nested blocks rather than a list of instructions. A particular set of instructions that is meant for repeated executions is kept under a block. This block is run the number of times the statements need to be repeated through the programming language itself. It did not use jump statements to move backward to execute some instructions again and again. Structured programming is used to expand many higher level commands into a number of lower level commands. The entire code was divided into many individual blocks, subroutines, and functions that can be run independent of other blocks of the same program, making it easier for many programmers to work on the same code at the same time. Once this coding style was introduced, it was retrofitted in all the languages, such as ALGOL and FORTRAN, which did not have it originally. The block structure style of programming allows less use of global variables. In this programming style, local variables are used to occupy memory locations only when their container block of code gets executed and not the entire time the program is running. 2GLs are used to concentrate more on the logical structure while 3GLs emphasized on the usability of the same language, making them more user friendly.

# ### Fourth Generation Programming Languages

The fourth generation programming languages or 4GLs were introduced with some specific purposes in mind, such as the development of commercial business software. 4GLs surpassed the 3GLs in terms of higher abstraction and statement power. 3GLs were structured languages but slow and prone to errors. 4GLs were developed by adding higher level programming and methods to generate a language which was equivalent to 3GLs in respect to complicity but involved fewer errors. PL/SQL is an example of 4GL.
