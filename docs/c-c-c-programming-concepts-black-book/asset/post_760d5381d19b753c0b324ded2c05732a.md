## Dynamic Allocation Functions

C defines four dynamic allocation functions, namely calloc(), malloc(), realloc(), and free(), which are supported by all the compilers. These functions are used when we want to allocate the memory during the execution of code. A dynamically allocated memory needs to be returned to the system as well. The region from where the memory is allocated is called a heap.

Let’s discuss the calloc(), malloc(), realloc(), and free() functions.

### calloc()

The calloc() function is used for the dynamic memory allocation of size, say mem_size, for a number of elements say num. This implies that the total memory allocated by calloc() is of size num * mem_size. The signature of the calloc() function is as follows:

```c
void *calloc(size_t num, size_t size);
```

The <stdlib.h> header contains the prototype of the calloc() function. A key feature of the calloc() function is that all the bits of memory allocated by it are set to zero. The calloc() function returns a pointer to the first byte of the allocated portion of memory. If there is not enough memory to allocate, then a NULL pointer is returned.

Let’s take an example of the calloc() function as mentioned in Listing 8.22:

**Listing 8.22:** Usage of calloc() function.

```c
#include <stdio.h>
#include<stdlib.h>

int main(void)
{
    int *ptr;

    ptr = (int*)calloc(10, sizeof(int));
    if(!ptr)
    {
        printf("\n Failed to allocate Memory");
    }

    getch();

    return 0;
}
```

### free()

The free() function is used to return the memory pointed to by the pointer to the heap. Memory returned to the heap is made available for future allocation. The signature of the free() function is as follows:

```c
void free(void *ptr);
```

If a NULL pointer is passed to the free() function, then it does not perform any operation. Let’s take an example of the free() function as mentioned in Listing 8.23:

**Listing 8.23:** Usage of free() function.

```c
#include <stdio.h>
#include<stdlib.h>

int main(void)
{
        int *ptr, i;

        ptr = (int*)calloc(1, sizeof(int));

        if(!ptr)
        {
                printf("\n Failed to allocate Memory");
        }
        if(ptr)
        {
                printf("\n Memory Allocated ");
        }

        free(ptr);
        getch();
        return 0;
}
```

### malloc()

The malloc() function returns a pointer to the first byte of a region of memory, which has been allocated from the heap. The signature of the malloc() function is as follows:

```c
void *malloc(size_t amount);
```

If the malloc() function fails to allocate the memory, then it returns a NULL pointer. Let’s take an example of the malloc() function as mentioned in Listing 8.24:

**Listing 8.24:** Usage of malloc() function.


## Utility Functions

Utility functions can be used for the processing of variable-length arguments, sorting, searching, and generating random numbers. Moreover, some utility functions, such as abort(), can be used for terminating a program abnormally; thereby, avoiding the system crash and other anomalies. To use the utility functions, we need to include the <stdlib.h> header in a program.

Let's discuss some utility functions, in detail.

### abort()

The abort() function causes the immediate abnormal termination of a program. The signature of the abort() function is as follows:

```c
void abort(void);
```

### atoi()

The `atoi()` function converts a string to an integer value. The string passed as an argument to the function must contain a valid integer number. The signature of the `atoi()` function is as follows:

```c
int atoi(const char *str);
```

In case of any error, the value returned by the `atoi()` function is undefined. If the `atoi()` function is called with an argument, such as 50.76, then the function returns 50 and .76 is ignored.

Listing 8.28: Usage of atoi() function.

```c
#include<stdio.h>

int main()
{
    char inputString[20];

    printf("\n Enter a number -> ");

    gets(inputString);

    printf("\n The value returned by atoi function is %d ",atoi(inputString));
    getch();

    return 0;
}
```

```text
Enter a number -> 98.563
The value returned by atoi function is 98
```
