
*Chapter 19* deals with advanced concepts of C# and starts with a brief introduction to Language-Integrated Query (LINQ). It explains the Lambda expression and the anonymous methods which are the building blocks of a LINQ query. Then, this chapter discusses about LINQ queries, wherein you will learn the effective way to write a LINQ query. Also, in this part of the chapter, we will cover other important topics such as Lambda queries, comprehensive queries, deferred execution, composition strategies, projection strategies, and interpreted strategies. Further, we will learn about the transition from LINQ to Structured Query Language (SQL). Next, this chapter covers the building mechanism of an expression tree. After that, we will cover the standard LINQ queries, where we will learn in detail about various operators used in LINQ to form and execute LINQ queries. At the end of this chapter, we will discuss about the error-handling method along with the use of DLL in the light of .NET architecture.

*Chapter 20* deals with the usage of Extensible Markup Language (XML) document using C#. We will learn how we can use the XML classes to manipulate the XML documents, and using a Web application, we will explain each aspect of XML document manipulation techniques that can be done using C# classes. In this chapter, first, we will give a short introduction to the XML that covers the important features of the XML document. Later on, we will discuss about the various .NET classes that are used to manipulate a XML document. At last, we will describe a Web application named “My XML Manager” that helps the user to understand the usage of XML classes in real-life scenario. After that, we will discuss about some important features of XML language, such as XML Schema Definition (XSD), Extensible Stylesheet Language Transformations (XSLT), and XML Path Language (XPath).

*Chapter 21* focuses on file system architecture and file streams. In this chapter, we will study about File and Directory operations with the help of an example that defines one's own drive file manager. Next, we will concentrate on compression mechanism and will also study about isolated storage. At the end of this chapter, we will develop a mail delivery system, where we write scripts for two different types of mail delivery: one is with attachment and another is without attachment.

*Chapter 22* covers the basic and advanced concepts on Network Programming using C#. Network programming is inadequate without a comprehensive knowledge on sockets, which would be highly emphasized in this chapter. Implementation of Transmission Control Protocol (TCP) and User Datagram Protocol (UDP) sockets with real-case studies will help the readers to understand the intricacies. Use of Blocking and non-blocking I/Os with both SELECT and EPOLL functions adds more volume and depth to the chapter. The chapter will include test programs describing client server communication taking place in real-life scenarios as well.

*Chapter 23* discusses mostly about different design principles. Design principles are a very important phase of study before we learn how to implement concepts using different programming languages. We first need to understand the concept of modeling before we implement them. In other words, modeling is nothing but simplification of reality. We work on modeling first so that we can understand a system better before we develop them. Modeling helps us to achieve four basic goals. Firstly, modeling helps us to imagine a system as it is actually or the way we want it to be. Secondly, modeling allows us to specify the behavior or structure of a system that we want to build. Thirdly, modeling gives us a template or a blueprint that guides us in developing a system. Fourthly, modeling documents the decisions that we take in building the system. In this chapter, we would mainly concentrate on the principles of object-oriented design, analysis, and modeling. We include almost all the design diagrams such as structural and behavioral diagrams, which an organization should have to prepare a good design document that will guide the developer to construct an appropriate and efficient database management system for the organization. Further, the chapter explains about object-oriented analysis, and class diagram and relationships between classes.

*Chapter 24* constitutes the fundamental concepts of data structures and algorithm analysis. In this chapter, we will learn about data structures and algorithms. First, the chapter provides a brief discussion on abstract data type, the infix, prefix, and postfix notations, complexity of an algorithm, and algorithm case analysis. Then, we will plunge into concepts of linked lists, stack, queues, trees, and various sorting techniques. Further, the chapter will also discuss sequential search, binary search, hashing, and graphs. It also covers graph analysis and imposes discussions on spanning tree algorithms, minimum spanning tree, Dijkstra's algorithm, and Floyd's algorithm. Mathematical jargons are avoided and algorithm analysis is done, where we have derived the best case and worst-case situations.

Apart from these 24 chapters, we also have two appendices that discuss some very important topics and programs on C++.

The programming styles used in writing a C or a C++ program is another source of confusion for the programmers. Ideally, we have three styles of programming, namely, procedural, assembler, and function applicative. Pascal is procedural; assembly language follows the assembler style, and LISP being function applicative. C, however, has all the three styles and often integrates all the three styles, thereby making it more flexible.
