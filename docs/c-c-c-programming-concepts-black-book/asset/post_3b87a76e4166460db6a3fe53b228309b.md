## Bubble Sort

Bubble sort technique is used to put the largest number in a series at the rightmost place in one iteration. This method takes an array of elements and scans them from left to right. At each iteration, it places the largest element at the highest position by comparing two adjacent elements and swapping them if they are out of order. This process is repeated until all the elements are placed at the right index position. Therefore, at each step, the largest element of the array is bubbled up from its original position to the highest index position in an effective way.

Let's consider the following array to understand the bubble sort technique:

`A[n] = [30, 20, 90, 60, 100, 10]`

To describe the technique, we need to have two variables i and j, where i represents the number of steps required to sort the array and j represents the number of sub-steps required in each step to put the highest element at the higher index in the array. In addition, we initialize the values of i and j as 0.

Following is the stepwise execution of the bubble sort technique:

1. In this step, the adjacent elements are compared in each line. At the end of this step, the highest number, which is 100, is placed at the rightmost position of the array, as follows:

Iteration 1: i = 0

| | | | | | | |
|---|---|---|---|---|---|---|
| 30 | 20 | 90 | 60 | 100 | 10 | (j = 0) Swapped |
| 20 | 30 | 90 | 60 | 100 | 10 | (j = 1) |
| 20 | 30 | 90 | 60 | 100 | 10 | (j = 2) Swapped |
| 20 | 30 | 60 | 90 | 100 | 10 | (j = 3) |
| 20 | 30 | 60 | 90 | 100 | 10 | (j = 4) Swapped |
| 20 | 30 | 60 | 90 | 10 | 100 | At the end of iteration 1, 100 is placed at the rightmost side |

In the last step, after the highest element of the list is placed at the rightmost position, the list has now left with only 5 array elements to be sorted.

2. In this step, the bubble sort technique places the highest element out of the 5 array elements at the rightmost position, as follows:

Iteration 2: i = 1

| | | | | | |
|---|---|---|---|---|---|
| 20 | 30 | 60 | 90 | 10 | (j = 0) |
| 20 | 30 | 60 | 90 | 10 | (j = 1) |
| 20 | 30 | 60 | 90 | 10 | (j = 2) |
| 20 | 30 | 60 | 90 | 10 | (j = 3) Swapped |
| 20 | 30 | 60 | 10 | 90 | At the end of iteration 2, 90 is placed at the rightmost side |

3. This step applies the bubble sort technique to the remaining 4 array elements, as follows:

Iteration 3: i = 2

| | | | | |
|---|---|---|---|---|
| 20 | 30 | 60 | 10 | (j = 0) |
| 20 | 30 | 60 | 10 | (j = 1) |
| 20 | 30 | 60 | 10 | (j = 2) Swapped |
| 20 | 30 | 10 | 60 | At the end of iteration 3, 60 is placed at the rightmost side |

4. In this step, 3 array elements are considered for applying bubble sort technique, as follows:

Iteration 4: i = 3

| | | | |
|---|---|---|---|
| 20 | 30 | 10 | (j = 0) |
| 20 | 30 | 10 | (j = 1) Swapped |
| 20 | 10 | 30 | At the end of iteration 4, 30 is placed at the rightmost side |

5. This step takes only remaining 2 array elements into consideration, as follows:

Iteration 5: i = 4

| | | |
|---|---|---|
| 20 | 10 | (j = 0) Swapped |
| 10 | 20 | At the end of iteration 5, 20 is placed at the rightmost side |

After the end of iteration 5, the process terminates as all the array elements are placed at the proper position.

### Listing 24.21: Showing the Algorithm for Bubble Sort

```text
function BubbleSort(Array[n])
begin
  for i <- 0 to i <- n-1
    for j <- 0 to j <- n - 1 - i
      if Array[j] > Array[j+1]
        then
          Interchange the position of Array[j] and Array[j + 1]
end
```

The preceding algorithm implements the bubble sort to sort a list of elements in the ascending order. Using the two for loops, each pair of elements in the array is compared. If the element has a greater value than the element that comes afterwards, then they interchange their position. At the end of each inner loop, the greatest value of the list is placed at the rightmost position and for the next iteration, we do not consider that element anymore. At the end of this operation, each element in the list is placed in the ascending order.

Now, let's analyze the bubble sort algorithm. In the best case or the worst case, the execution of the outer loop is same, which is (n -1) times. The complexity of this algorithm depends on the number of times the inner loop executes.

As we can see from the bubble sort operation, the first iteration requires (n-1) comparisons, the second pass requires (n-2) comparisons, and the last pass requires only 1 comparison. Therefore, if we sum up the number of comparisons taken place for bubble sort, the result will be as follows:

## Insertion Sort

As the name suggests, insertion sort technique sorts a list of elements by placing each element at the right place at each iteration with respect to the sorting order. For example, in the first iteration, the A[1] element is compared with A[0]. If the sorting type is ascending and if A[1] is smaller than A[0], then A[1] is placed at the first position and A[0] is placed at the second position. In the second iteration, the third element A[2] is compared with both A[0] and A[1] and is placed in its appropriate place at the end of the second iteration. This procedure is repeated for all the elements in the list.

Let's consider the following array to understand the insertion sort technique:

`A[n] = {30, 20, 90, 60, 100, 10}`

To describe this technique, we need to have two variables i and j, where i represents the number of steps required to sort the array and j represents the number of sub-steps required in each step to place the ith element at the appropriate position. We initialize the values of i as 1 and j as i - 1. In addition, at the beginning of each iteration, we store the ith value of the list in a variable, named Temp.

Following is the stepwise execution of the insertion sort technique:

1. In this step, the initial values of i and j are 1 and 0. The second element is compared with the first element at this step. As the second element 20 is smaller than the first element 30, they interchange their positions, as follows:

Iteration 1: i = 1

Temp = A[i]

| | | | | | | |
|---|---|---|---|---|---|---|
| 30 | 20 | 90 | 60 | 100 | 10 | Temp < A[j] == true; Swapped the position of A[j] and A[i] |
| 20 | 30 | 90 | 60 | 100 | 10 | 20 is inserted at the first position |

2. In this step, the initial values of i and j are 2 and 1. Therefore, at the beginning of this step, the third element 90 is compared with the second element 30. As 90 is greater than 30, no swapping will take place and the element comparison process will stop at that instant, as follows:

Iteration 2: i = 2

Temp = A[i]

| | | | | | | |
|---|---|---|---|---|---|---|
| 20 | 30 | 90 | 60 | 100 | 10 | Temp < A[j] == false; |
| 20 | 30 | 90 | 60 | 100 | 10 | Temp < A[j-1] == false; |
| 20 | 30 | 90 | 60 | 100 | 10 | As 90 is greater than 30 and 20, its position is not changed |

3. In this step, the initial values of i and j are 3 and 2. Therefore, at first, the fourth element 60 is compared with the third element 90. As the outcome of the comparison is true, these two elements interchange their positions. At this point, the position of 60 is not decided, as there may be some elements at the front of the list whose values are greater than 60. Then, the comparison takes place between 60 and the second element 30. This comparison process returns false. After that, the comparison takes place between 60 and 20. As this also returns false, 60 is placed at the third position in the list. The steps in this iteration are shown as follows:

Iteration 3: i = 3

Temp = A[i]

| | | | | | | |
|---|---|---|---|---|---|---|
| 20 | 30 | 90 | 60 | 100 | 10 | Temp < A[j] == true; Swapped the position of A[j] and A[i] |
| 20 | 30 | 60 | 90 | 100 | 10 | Temp < A[j-1] == false; 90 is placed at the fourth position |
| 20 | 30 | 60 | 90 | 100 | 10 | Temp < A[j-2] == false; |
| 20 | 30 | 60 | 90 | 100 | 10 | 60 is placed at the third position |

4. In this step, the values of i and j are set as 4 and 3. As this fourth element is greater than all its previous elements, its position remains the same, as follows:

Iteration 4: i = 4

Temp = A[i]

| | | | | | | |
|---|---|---|---|---|---|---|
| 20 | 30 | 60 | 90 | 100 | 10 | Temp < A[j] == false; |
| 20 | 30 | 60 | 90 | 100 | 10 | Temp < A[j-1] == false; |
| 20 | 30 | 60 | 90 | 100 | 10 | Temp < A[j-2] == false; |
| 20 | 30 | 60 | 90 | 100 | 10 | Temp < A[j-3] == false; |
| 20 | 30 | 60 | 90 | 100 | 10 | As 100 is greater than 90, 60, 30, and 20, its position is not changed |
