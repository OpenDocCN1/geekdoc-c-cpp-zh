# Returning a Function Pointer from a Function

We can also return the address of a function using a function pointer. This becomes useful when we need to decide on invoking a function during runtime instead of determining it at the compile time. Listing 4.17 shows how to return a function pointer from a function:

**Listing 4.17:** Showing the Code to Return a Function Pointer from a Function

```
#include<stdio.h>
#include<string.h>
typedef void(*func_ptr)(int,int);
void Add(int,int);
void Sub(int,int);
func_ptr compareValue(int, int);
int main()
{
    int varA = 05;
    int varB = 10;
    func_ptr getPtr = NULL;
    getPtr = compareValue(varA, varB);
    (*getPtr)(varA,varB);
    getch();
    return 0;
}
func_ptr compareValue(int varA, int varB)
{
    if(varA < varB)
    {
        return &Add;
    }
    else
    {
        return &Sub;
    }
}
void Add(int varA, int varB)
{
    printf("\n Sum is %d ",varA+varB);
}
void Sub(int varA, int varB)
{
    printf("\n Difference is %d ",varA-varB);
}
```

In Listing 4.17, we have defined a function pointer called func_ptr, which points to a function that takes two integers as its arguments but returns nothing. In addition, we have defined a function called compareValue(), which takes two integers as its arguments and returns a pointer to a function. Within the main() function, we have declared a function pointer called getPtr, which points to a function that is returned by compareValue(). Within the compareValue() function, we have compared two variables and depending on the comparison, we have returned the address of either the Add() function or the Sub() function. In addition, we have used getPtr to invoke either the Add() function or the Sub() function within the main() function.
