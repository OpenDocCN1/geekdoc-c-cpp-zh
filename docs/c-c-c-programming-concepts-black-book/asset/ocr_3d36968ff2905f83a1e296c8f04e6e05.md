The cosf() and cosl() functions were introduced by the C99 compiler. Let's take an example of the cos() function as mentioned in Listing 8.2.

Listing 8.2: Usage of cos() function.

```
    #include<stdio.h>
    #include<math.h>
    int main()
    {
        double val = -1.0;
```

Output of the preceding example is as follows:

```
    The Cosine of -1.000000 is 0.540302
```

# cosh()

The cosh() family of functions returns the hyperbolic cosine of the argument passed to them. The signature of the cosh() family of functions is as follows:

```
    float coshf(float arg);
    double cosh(double arg);
    long double coshl(long double arg);
```

The coshf() and coshl() functions were introduced by the C99 compiler.

# asin()

The asin() family of functions returns the arc sine of the argument passed to them. The value of argument must be within the range of -1 to 1; otherwise, the compiler will throw an error. The signature of the asin() family of functions is as follows:

```
    float asinf(float arg);
    double asin(double arg);
    long double asinl(long double arg);
```

The asinl() and asinf() functions were introduced by the C99 compiler. Let's take an example of the asin() function mentioned in Listing 8.3:

Listing 8.3: Usage of asin() function.

```
    #include<stdio.h>
    #include<math.h>
    int main()
    {
        double val = -1.0;
        printf("\n The Arc Sine of %f is %f ",val, asin(val));
        getch();
    }
```

Output of the preceding example is as follows:

```
    The Arc Sine of -1.000000 is -1.570796
```
