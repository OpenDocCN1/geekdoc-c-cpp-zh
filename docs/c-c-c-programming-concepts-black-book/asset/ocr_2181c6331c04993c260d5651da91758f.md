# sqrt()

The sqrt() family of functions returns the square root of the argument passed to them. Any negative value passed as an argument can cause an error. The signature of the sqrt() family of functions is as follows:

```
float sqrtf(float num);
double sqrt(double num);
long double sqrtl(long double num);
```

The sqrtf() and sqrtl() functions were introduced by the C99 compiler. Let’s take an example of the sqrt() function as mentioned in Listing 8.10:

**Listing 8.10:** Usage of sqrt() function.

```
#include<stdio.h>
#include<math.h>

int main()
{
    double val = 121;
    printf("The Square root of %f is %f", val, sqrt(val));
    getch();
}
```

Output of the preceding example is as follows:

```
The Square root of 121.000000 is 11.000000
```

# pow()

The pow() family of functions returns the value of base raised to the exponential power, that is, base^exp. The compiler will throw an error if the base value is zero or the exp value is less than or equal to zero. Error can also occur if the base value is negative and the exp value is positive.

The signature of the pow() family of functions is as follows:

```
float powf(float base, float exp);
double pow(double base, double exp);
long double powl(long double base, long double exp);
```

The powf() and powl() functions were introduced by the C99 compiler. Let’s take an example of the pow() function as mentioned in Listing 8.11:

**Listing 8.11:** Usage of pow() function.

```
#include<stdio.h>
#include<math.h>

int main()
{
    double base = 17;
    double exp = 6;
    printf("\n %f raise to the power of %f becomes %f",base,exp,pow(base, exp));
    getch();
}
```

Output of the preceding example is as follows:

```
17.000000 raise to the power of 6.000000 becomes 24137569.000000
```
