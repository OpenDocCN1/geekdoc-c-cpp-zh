There are three types of queues: circular queues, deques, and priority queues. Let's learn about these three in the next sections.

## Circular Queues

Consider a scenario where the REAR pointer of a queue has reached the MAXSIZE, but we still want to insert some more elements into the queue. As the REAR pointer has reached the MAXSIZE, this will give rise to the Queue Overflow situation. However, it may happen that plenty of space is still left in the queue, as FRONT might have moved from its initial position after deleting some elements. In such situation, we should not consider that the queue is full. A smarter solution to this problem is to point REAR back to the initial empty positions so that further insertions in the queue can take place. This mechanism is called circular queue. In a circular queue, the queue[1] element comes just after the queue[n] element, where n is the MAXSIZE of the queue. When REAR reaches n, we simply reset REAR to 1. The same operation takes place for the FRONT pointer as well. Figure 24.8 shows some insertion and deletion operations on a circular queue:

### Listing 24.14: Showing the Algorithm for Insertion

```
function QueueInsert(queue[maxsize], front, rear, item)
  begin
    if front = 1 and rear = maxsize, OR if front = rear + 1
      then
        Output "Queue Overflow"
        Return
    end if
    if front = 0
      then
        front = 1 and rear = 1
    else
      if rear = maxsize
        then
          rear = 1
        else
          rear = rear + 1
      end if
    end if
    queue[rear] = item
  end
```

As shown in Listing 24.14, the queue overflow condition takes place when the front pointer remains at one and the rear pointer reaches the maxsize of the queue. Queue overflow condition can also take place when the front pointer exceeds the rear pointer by one. Initially, when the queue is empty, both the pointers are set to one. To insert the elements in the queue, the rear pointer is checked against the maxsize of the queue. If the rear pointer is equal to the maxsize, then the pointer is again set to one; else, it is incremented by one.

## Dequeues

Dequeue is the short form for Double Ended Queue. It is referred to as a linear data structure in which elements can be added or deleted at both the ends of the queue, but not from the middle. There are two types of dequeue: input restricted dequeue and output restricted dequeue. In the input restricted dequeue, deletion can take place from both the ends; however, insertion can take place only from one of the ends. Similarly, in the output restricted dequeue, insertion can take place from both the ends; however, deletion is allowed only from one end. ### **Listing 24.18:** Showing the Algorithm for Insertion in a Dequeue

```
function dequeueInsert(queue[maxsize], front, rear, item,pos)
begin
  if rear >= maxsize AND front = 0
    then
      Output "Queue Overflow"
      Return
  end if
  if pos = 0  [Insertion at Front]
    then
      if front > 0
        then
          front = front - 1
      else
        return
    endif

    queue[front] = item

else            [Insertion at Rear]
    if rear < maxsize
        then
            rear = rear + 1
        else
            return
    end if
    queue[rear] = item
end if
end
```

As shown in Listing 24.18, the parameters passed to the DequeInsert() function are a dequeue, the front and rear pointers, the item to be inserted, and a variable called pos. The pos variable identifies where the insertion will take place, that is, at the front or at the rear. If the insertion takes place at the front, then the front pointer is decremented by one. If the insertion takes place at the rear, then the rear pointer is incremented by one. The overflow condition in dequeue is same as that of a queue.

Listing 24.19 shows the algorithm for deletion operation in a deque:

### **Listing 24.19: Showing the Algorithm for Deletion in a Deque**

```
function DequeDelete(queue[maxsize], front, rear, item,pos)
begin
    if front = 0 AND rear = 0
        then
            Output "Queue underflow"
            return
    end if
    if pos = 0 [Deletion at front end]
        then
            if front > 0
                then
                    item = queue[front]
            end if
            if front = rear
                then
                    front = rear = 0
            else
                    front = front + 1
            end if
    else
        if rear > 0
            then
                item = queue[rear]
        end if
        if front = rear
            then
                front = rear = 0
        else
                rear = rear - 1
        end if
    end if
end
```

As shown in Listing 24.19, the conditions for underflow in a dequeue are similar to that of a queue. The pos variable identifies where the deletion will take place, that is, at the front or at the rear. If the deletion takes place at the front, then the front pointer is incremented. If the deletion takes place at the rear, then the rear pointer is decremented.
