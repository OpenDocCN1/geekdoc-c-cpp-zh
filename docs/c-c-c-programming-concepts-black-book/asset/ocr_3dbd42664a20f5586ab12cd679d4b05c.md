The running time O(n²) means that there is a function f(n) which is equal to O(n²) such that for any value of n, no matter what particular input of size n is chosen, the running time of that input is bounded from above by the value f(n).

# Big “omega” Notation

Big “omega” or Big-Ω notation is used to express the lower bound of runtime of an algorithm. Generally, it can be defined as follows:

For function g(n), Big-Ω of n (Ω(g(n))) is defined as:

$$\Omega(g(n)) = \{f(n): \text{there exists positive constant } c \text{ and } n_0 \text{ such that } 0 \leq cg(n) \leq f(n),\ \forall n \geq n_0\}$$

The running time Ω(n²) means that there is a function f(n) which is equal to Ω(n²) such that for any value of n, no matter what particular input of size n is chosen, the running time of that input is tightly bounded from bottom by the value f(n).

# Big Theta Notation

For two non-negative functions, f(n) and g(n), f(n) is theta of g(n) iff (if and only if) f(n) = O(g(n)) and f(n) = ΩΩ(g(n)). This is written as “f(n) = Θ(g(n))”. Formally, it can be defined as follows:

For function g(n), Big-theta or Big-Θ of n (Θ(g(n))) is defined as:

$$\Theta(g(n)) = \{f(n): \text{there exists some constant } c_1,c_2 \text{ and } n_0 \text{ such that } 0 \leq c_1g(n) \leq f(n) \leq c_2g(n),\ \forall n \geq n_0\}$$

The running time Θ(n²) means that there is a function f(n) which is equal to Θ(n²) such that for any value of n, no matter what particular input of size n is chosen, the running time of that input is tightly bounded by the value f(n).

# Small “Oh” Notation

For two non-negative functions, f(n) and g(n), f(n) is small-oh or small-o of g(n) iff f(n) = O(g(n)) and f(n) ≠ ΩΩ(g(n)). This is written as “f(n) = o(g(n))”. Formally, it can be defined as follows:

For function g(n), small −o of n (o(g(n))) is defined as,

$$o(g(n)) = \{f(n): \text{for any positive constant } c > 0, \text{ there exists a constant } n_0 > 0 \text{ such that } 0 \leq f(n) < cg(n)$$
$$\forall n \geq n_0\}$$

$$\lim_{n\to\infty}\frac{f(n)}{g(n)} = 0$$

# Small “omega” Notation

For two non-negative functions, f(n) and g(n), f(n) is small-omega or small-ω of g(n) iff f(n) = Ω(g(n)) and f(n) ≠ O(g(n)). This is written as “f(n) = ω(g(n))”. Formally, it can be defined as follows:

For function g(n), small −ω of n (ω(g(n))) is defined as,

$$\omega(g(n)) = \{f(n): \text{for any positive constant } c > 0, \text{ there exists a constant } n_0 > 0 \text{ such that } 0 \leq cg(n) < f(n)$$
$$\forall n \geq n_0\}$$

$$\lim_{n\to\infty}\frac{f(n)}{g(n)} = \infty$$
