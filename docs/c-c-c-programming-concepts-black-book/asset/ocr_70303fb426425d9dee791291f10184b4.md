# XmlTextWriter

The easiest way to create or modify an XML document is to use the XmlTextWriter class. This class offers the same functionality of the StreamWriter class, but in an exceptional that the XmlTextWriter class is used for writing the XML document. The XmlTextWriter object can be created by providing a FileStream object that holds the path of the new XML document to be created or modified and the FileMode of the document, shown as follows:

```
FileStream fileStream = new FileStream(path, FileMode.Create);
XmlTextWriter xmlTextWriter = new XmlTextWriter(fileStream, System.Text.Encoding.UTF8);
```

There are two overloading constructors to create the instance of XmlTextWriter class.
