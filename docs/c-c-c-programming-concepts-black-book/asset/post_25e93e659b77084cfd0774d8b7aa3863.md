Now, let’s explain the entire procedure algorithmically. Following is the set of inputs, output, and the steps of algorithm:

Input: A connected graph G with vertices labeled v1, v2, ……, vn

Output: A spanning tree T for G

**Method:**

- 1. (Visit a vertex) Let v1 be the root of T and set L = v1 (where L stands for the vertex last visited).
- 2. (Find an unexamined edge and an unexamined vertex adjacent to L) For all the vertices adjacent to L, choose the edge (L, vk), where k is the minimum index, such that adding (L, vk) to T does not form a cycle. If no such edge exists, then go to step 3; otherwise, add edge (L, vk) to T and set L = vk. Repeat the step 2 at the new value for L.
- 3. (Backtrack or terminate) If x is the parent of L in T, then set L = x and apply the step 2 at the new value of L. If, on the other hand, L has no parent in T (such that L = v1), then DFS terminates and T is the spanning tree for G.

### Minimum Spanning Tree

Typically, in a connected graph, there can be more than one spanning tree. A spanning tree of a weighted connected graph G is called a minimum spanning tree, if its weight is minimum among all the other spanning trees present in that connected graph. Two most popular algorithms to determine the minimum spanning tree of a connected weighted graph G are given as follows:

- Prim’s algorithm
- Kruskal’s algorithm

Let’s discuss both of them one by one.

### Prim’s Algorithm

Prim’s algorithm finds a minimum spanning tree for a weighted connected undirected graph G. It uses the greedy approach of problem solving, that is, it chooses the path that apparently gives rise to the minimum spanning tree. For this, we give a weighted connected undirected graph G as an input to the algorithm and get a minimum spanning tree T as an output. The following are the steps of Prim’s algorithm:

- 1. Take a vertex v₀ in a graph G such that T = {(v₀), ∅}, where the first element of T denotes the vertex set and the second element denotes the edge set.
- 2. Find the edge (v₀, v₁) in E (edge set of G) such that its one end vertex v₀ is in T and its weight is minimum. Adjoin v₁ and edge e₁ to T. Therefore, we now have T = {(v₀, v₁), (e₁)}.
- 3. Choose the next edge eᵢⱼ = (vᵢ, vⱼ) in such a way that its one end vertex vᵢ is in T and the other vertex vⱼ is not in T (that is, eᵢⱼ should not form a cycle with the edges in T) and weight of edge eᵢⱼ is as small as possible. Adjoin edge eᵢⱼ and vertex vⱼ to T.
- 4. Repeat the step 3 until T contains all the vertices of G. Therefore, set T will give the minimum spanning tree of G.

### Kruskal’s Algorithm

For this, we give a weighted connected undirected graph G as an input to the algorithm and get a minimum spanning tree T as an output. The following are the steps of Kruskal’s algorithm:

- 1. Find an edge such that its weight w(eᵢ) is minimum.
- 2. At this point, we have 3 sub-steps:
  - a. If edges e₁, e₂, ..., eₙ have been chosen, then pick up an edge e₍ₙ₊₁₎ not equal to eᵢ for i = 1 to n.
  - b. The edges e₁, e₂, ..., eₙ, e₍ₙ₊₁₎ does not form a cycle.
  - c. The weight of the edge w(e₍ₙ₊₁₎) is as small as possible subject to the condition in step 2(b).
- 3. Stop, when all the vertices of G are in T.

### Dijkstra’s Algorithm

Dijkstra’s algorithm is a graph search algorithm, which solves the single-source shortest path problem for graphs, producing a shortest path tree. The assumption made in this case is that all the costs or weights associated with the edges should be non-negative. Given a vertex in a graph, this algorithm finds the minimum distance between that vertex and every other vertex in the graph. This kind of algorithm is mainly used for communication network and travelling salesperson problems. It is designed to determine the shortest route between the source vertex and every other vertex in the network of a graph.

To explain the algorithm, we need to know some basic shortest distance metrics, on which the entire algorithm has its base. Let’s suppose that uᵢ is the shortest distance from the source vertex to any vertex ‘j’. In addition, let’s define distance dᵢⱼ ≥ 0 as the length of arc (i, j). Then, Dijkstra’s algorithm proceeds by defining the label of an immediately succeeding vertex, say vⱼ, as follows:

$$[u_j, i] = [u_i + d_{ij}, i], \text{ where } d_{ij} \ge 0$$

To start the algorithm, we define the label for the starting vertex as [0, −], which indicates that the vertex has no predecessor. Vertex label in Dijkstra’s algorithm is of two types: temporary and permanent. Initially, we always associate a temporary label with any vertex in a graph. A temporary label is modified if and only if a shorter route to that vertex can be found through some other path ensuring that it remains a tree.
