# The foreach Loop

We need to use the foreach loop in case we want to iterate through the lists, such as Arraylist or SortedList, and collections. Listing 17.43 shows the structure of the foreach loop:

Listing 17.43: Showing the Structure of foreach Loop

```
```csharp
foreach (<Type> <Iterator variable> in <List>)
{
    //Statement
}
```
```

In the preceding structure, Type represents the type of the item the list holds and Iterator variable indicates the variable declared with the list item type. The in keyword is required to use in between the list item variable and the list itself.

While iterating through the list items using the foreach loop, the list is read-only, which implies that we cannot change the list items. During this iteration, the list returns a new variable and as long as the list has the value, it creates a new variable and returns it to the program.
