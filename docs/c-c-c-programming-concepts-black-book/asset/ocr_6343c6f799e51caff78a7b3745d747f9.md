Listing 18.33: Showing an Example of the Internal Access Modifier

```csharp
using System;
class Vehicle
{
    internal string type;
}
class Owner
{
    public void OwnerVehicle()
    {
        Vehicle vehicle = new Vehicle();
        vehicle.type = "Two-wheeler";
        Console.WriteLine("The owner has a " + vehicle.type);
    }
}
class Car : Vehicle
{
    static void Main()
    {
        Vehicle vehicle = new Vehicle();
        vehicle.type = "Four-wheeler";
        Console.WriteLine("The type of the car is " + vehicle.type);
        Owner owner = new Owner();
        owner.OwnerVehicle();
    }
}
```
```

In the preceding program, the Vehicle class contains an internal variable type, which is referenced in the Ownerclass as well as in the derived class Car. The output for the program is same as shown for the public access modifier.

# Protected Internal

The protected internal modifier represents a union between the protected and internal modifiers. We use the protected internal keyword to declare a member as protected internal. If a member of the class is declared as protected internal, then it has the following accessibility:

+   - Inherited classes belonged to different assemblies can access protected internal member of the current assembly
+   - Members that reside inside the same assembly can access the protected internal members

Table 18.1 shows the default accesses (√) and the supported access modifiers (♣) for enum, class, interface, and struct:

| C# Type | Public | Private | Protected | Internal | Protected Internal |
|---|---|---|---|---|---|
| enum | √ | | | | |
| class | ♣ | √ | ♣ | ♣ | ♣ |
| interface | √ | | | | |
| struct | ♣ | √ | | ♣ | |
