# # Dequeues

Dequeue is the short form for Double Ended Queue. It is referred to as a linear data structure in which elements can be added or deleted at both the ends of the queue, but not from the middle. There are two types of dequeue: input restricted dequeue and output restricted dequeue. In the input restricted dequeue, deletion can take place from both the ends; however, insertion can take place only from one of the ends. Similarly, in the output restricted dequeue, insertion can take place from both the ends; however, deletion is allowed only from one end.
