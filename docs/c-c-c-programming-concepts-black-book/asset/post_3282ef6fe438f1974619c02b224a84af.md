
## Access Specifier Combinations in C++

Till now, we have come across three types of access specifiers in C++: public, private, and protected. Let's write a program where we combine all the three access specifiers and observe what compiles and runs fine and what gives rise to errors. Although the following program will not compile successfully, but the sole purpose of giving this code snippet is to make the reader aware of common compilation errors due to wrong usage of access specifiers in C++. The compilation errors in the preceding program are due to wrong and illegal access of private and protected data members from within the code blocks, where they are not available until declared public or protected. This is because the rule applied for protected type of access specifies that all that protected and public members of the base class become protected members of the derived class.

Let’s advance towards showing the relationship between base class and derived class constructors and destructor functions and their order of execution.

## When are Constructor and Destructor Functions Called?

Two important questions arise relative to constructors and destructors when inheritance is involved. First, when are the base classes and derived class constructors and destructors functions called? Second, how can parameters be passed to base class constructors when we define an object of a derived class?

It is possible for both the base class and the derived class to contain constructor and destructor functions. However, in this case, the order in which they are executed is important. Let’s write the following program to understand this execution:

```cpp
1: /* Inheritance Example Program 3 */
2: #include <iostream.h>
3: using namespace std;
4:
5: class Base {
6: public:
7:     Base()
8:     {
9:         cout<<"Inside Base Constructor"<<endl;
10:    }
11:    ~Base()
12:    {
13:        cout<<"Inside Base Destructor"<<endl;
14:    }
15:};
16:
17:class Derived : public Base {
18:public:
19:    Derived()
20:    {
21:        cout<<"Inside Derived Constructor"<<endl;
22:    }
23:    ~Derived()
24:    {
25:        cout<<"Inside Derived Destructor"<<endl;
26:    }
27:};
28:
29:int main()
30:{
31:    Derived object;
32:
33:    /* Do nothing and see the constructor and destructor exec order */
34:
35:    return 0;
36:}
```

Before explaining anything else, let's see the output of the program, as follows:

```text
Inside Base Constructor
Inside Derived Constructor
Inside Derived Destructor
Inside Base Destructor
```

At first, the constructor of base class is called followed by the derived class constructor. Next, at the time of destroying the object, the destructor of the derived class is called followed by the base class destructor. When an object of derived class is created, if the base class contains a constructor; it will be called first or else the default constructor for the base class will be called, followed by the derived class constructor. When the derived class object is being destroyed, it is the reverse that happens. The derived class destructor is called first followed by the destructor of the base class.

Generally, it makes sense that constructor functions are executed in the order of their derivation. As a base class has no knowledge of any derived class, any initialization it needs to perform is separate from and possibly prerequisite to any initialization performed by the derived class. However, just the reverse works for destructors. As the base class underlies the derived class, the destruction of the base object implies the destruction of the derived object. Therefore, the derived destructor must be called first before the object is destroyed.

Let's now learn how to pass parameters to base class constructors.

## Passing Parameters to Base Class Constructors

In the last program, we have seen that on declaring the object of a derived class, it first calls the no-argument constructor of the base class, if present, and then executes the constructor function of the derived class. In case, the base class does not have any no-argument constructor, a call to the default constructor is made. Now, consider a situation where defining the object of derived class needs the initialization of both the base class and the derived class data members. We have seen that on declaring a derived class object, the no-argument constructor of the base class is called automatically. However, what if we want to call any of the argumental constructors of the base class to initialize some of the members of the base class based on some user input values?

The answer is to use an expanded form of the derived class's constructor declaration that passes along arguments to one or more base class constructors. The general form of the expanded derived class constructor is as follows:

```cpp
Derived_constructor(arg-list) : base_class1(arg-list),
                             base_class2(arg-list),
                             base_class3(arg-list),
                             .
                             .
                             .
                             base_classN(arg-list)
{
} /* Body of Derived Class Constructor */
```

In the preceding general form, base_class1 through base_classN are the names of the base classes inherited by the derived class. Although, we have not yet covered multiple inheritance, but it is possible for a particular derived class to inherit more than one base class. In addition, the general form shows the syntax for invoking the base class constructor from within the constructor of the derived class by passing the arguments. Notice that a colon separates the declaration of derived class constructor function from the base classes, and a comma operator separates the base classes from each other. Let's write a program to see how values can be passed to the base class members through the derived class constructor:

```cpp
1:/* Inheritance Example Program 4 */
2:#include <iostream.h>
3:using namespace std;
4:
5:class Base {
6:protected:
7: int baseVal;
8:public:
9: Base(int x)
10:    {
11:        baseVal = x;
12:        cout<<"Inside Base Constructor"<<endl;
13:    }
14:    ~Base()
15:    {
16:        cout<<"Inside Base Destructor"<<endl;
17:    }
18:};
19:
20:class Derived : public Base {
21:    int derivedVal;
22:public:
23:    Derived(int a, int b) : Base(a)
24:    {
25:        derivedVal = b;

27:    }

29:    {
30:        cout<<"Inside Derived Destructor"<<endl;
31:    }
32:    void show()
33:    {
34:        cout<<"BaseVal = "<<baseVal<<" DerivedVal = "<<derivedVal<<endl;
35:    }
36:};
```
