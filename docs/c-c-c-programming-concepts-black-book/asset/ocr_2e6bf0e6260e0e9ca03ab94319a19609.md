While writing an email script, we need to provide the information related to the SMTP server. This information can be provided by either using the C# code or configuring the Web.config file. However, the best practice is to configure the server information in the Web.config file. Following code shows how to add the configuration settings of the SMTP server in the Web.config file:

```
```xml
<configuration>
  <system.net>
    <mailSettings>
      <smtp>
        <network
          host = "Name of SMTP Server"
          port = "PortNumber used by the SMTP server"
          userName = "user name"
          password = "password" />
      </smtp>
    </mailSettings>
  </system.net>
  <system.web>
    .
    .
  </system.web>
</configuration>
```
```

In the preceding code, we have first added the `<system.net>` element under the `<configuration>` element. Then, we have added the `<mailSettings>` element, which contains another element, named `<smtp>`. Under the `<smtp>` element, we have added another child element, named `<network/>`, which contains the configuration settings of the SMTP server.
