void Print()

In the preceding example, two class-level variables are defined which can only be accessed by the class members. However, if we want to access the variable of a different class, then we need to create an object of the class to access the variable.

## Method-Level Scope

Variables that are defined with the method-level scope can be accessed from anywhere in the method. Let’s take a small example of the method-level scope, as shown in Listing 17.50:

**Listing 17.50:** Showing an Example of Method-Level Scope of a Variable

```csharp
using System;
class Program
{
    public static void Main()
    {
        int salary = 10000;
        if (salary >= 10000)
        {
            Console.WriteLine("Designation: Manager");
        }
        else
        {
            Console.WriteLine("Designation: Team member");
        }
    }
}
```

In the preceding example, the salary variable is declared at the beginning of the method. Now, if we want to compare its value from anywhere in the method, then it can be visible and it will not throw any error.

## Nested Scope

Variables declared in a nested scope within a method are not visible to the rest of the method. Their scope is restricted to that nested part of the method only. Let’s take a small example of the nested scope, as shown in Listing 17.51:

**Listing 17.51:** Showing an Example of Nested Scope of a Variable

```csharp
using System;
class Program
{
    public static void Main()
    {
        int salary = 10000;
        if (salary >= 10000)
        {
            string printMessage = "Designation: Manager";
        }
        else
        {
            string printMessage = "Designation: Team member";
        }
        Console.WriteLine(printMessage); //Compiler will throw an error at this point
    }
}
```

In the preceding example, a string variable printMessage is defined in the scope of the if statement. When we compile the example, the compiler will throw an error and displays the error message that the printMessage variable does not exist in the scope of the method.

## Parameter Passing

Parameters are the arguments that are passed to the methods. In C#, there are four different ways of passing the parameters to the methods, which are given as follows:

- Passing values
- Passing a reference using the ref keyword
- Passing a reference using the out keyword
- Passing parameters by using the params keyword

Let's learn about these in detail one by one.

### Passing values

This is a common way of passing the parameters to the methods. By default, the value of a parameter or variable is passed whose scope is defined inside the calling method. Before passing the parameters to a method, the program creates the duplicate copies of each parameter so that any changes to the parameters that are passed to the method do not affect the values of the actual parameters. Listing 17.52 shows how to pass values of parameters in a method.

**Listing 17.52: Showing an Example of Passing Values of Parameters**

```csharp
using System;
class Program
{
    public static void Main()
    {
        int item1 = 10;
        int item2 = 10;
        Addition addition = new Addition();
        //passing value to the method Add()
        int result = addition.Add(item1, item2);
        Console.WriteLine("The addition is: {0}", result);
        Console.WriteLine("The value of item1 is: {0}", item1);
        Console.WriteLine("The value of item2 is: {0}", item2);
    }
}
class Addition
{
    public Addition()
    {
    }
    public int Add(int item1, int item2)
    {
        item1 = item1 + 10;
        item2 = item2 + 20;
        return (item1 + item2);
    }
}
```

In the preceding example, we have declared two classes, Addition and Program. The Addition class has a method named Add(), which accepts two integer parameters. Within the Main() method, which is defined inside the Program class, the Add() method is called where two values are passed. Then, the values of the item1 and item2 variables, which are passed from the Main() method, are modified in the Add() method of the Addition class. The output of the program is given as follows:

```
The addition is: 50
The value of item1 is: 10
The value of item2 is: 10
```

We can observe from the output that the values of item1 and item2 remain the same in the scope of the Main() method.

### Passing a Reference using the ref Keyword

The ref keyword in the parameter passing technique is used to pass the address of the parameter. Therefore, if any values are changed in the called method, then the values of the parameters in the calling method also reflect the same values.

We can use the ref keyword in the bi-directional manner. For example, we can send the values to the called method and get the changed value in the calling method using the ref keyword.

**Listing 17.53: Showing an Example of Passing Reference using the ref Keyword**

```csharp
using System;
class Program
{
    public static void Main()
    {
        int item1 = 10;
        int item2 = 10;
        Addition addition = new Addition();
        //Passing reference to the method Add()
        int result = addition.Add(ref item1, ref item2);
        Console.WriteLine("The addition is: {0}", result);
        Console.WriteLine("The value of item1 is: {0}", item1);
        Console.WriteLine("The value of item2 is: {0}", item2);
    }
}
class Addition
{
    public Addition()
    {
    }
    public int Add(ref int item1, ref int item2)
    {
        item1 = item1 + 10;
        item2 = item2 + 20;
        return (item1 + item2);
    }
}
```

The preceding program is the modification of Listing 17.52. In this program, we have changed the values of the item1 and item2 variables by using the ref keyword and then printed the values.

The output of the program is given as follows:

```
The addition is: 50
The value of item1 is: 20
The value of item2 is: 30
```

### Passing a Reference using the out Keyword

Unlike reference parameter, the out parameter is unidirectional and it only returns the changed values from the method that has been called. Listing 17.54 shows an example of the out keyword:

**Listing 17.54: Showing an Example of Passing Reference using the out Keyword**

```csharp
using System;
class Program
{
    public static void Main()
    {
        int item1 = 10;
        int item2 = 10;
        int item3 = 0;
        int item4 = 0;
        Addition addition = new Addition();
        //Passing reference with "out" keyword to the method Add()
        int result = addition.Add(item1, item2, out item3, out item4);
        Console.WriteLine("The addition is: {0}", result);
        Console.WriteLine("The value of item1 is: {0}", item1);
        Console.WriteLine("The value of item2 is: {0}", item2);
        Console.WriteLine("The value of item3 is: {0}", item3);
        Console.WriteLine("The value of item4 is: {0}", item4);
    }
}
class Addition
{
    public Addition()
    {
    }
    public int Add(int item1, int item2, out int item3, out int item4)
    {
        item3 = item1 + 10;
        item4 = item2 + 20;
        return (item3 + item4);
    }
}
```

The code in the preceding program is the modification of Listing 17.52. In this program, we are passing the values and in turn getting the processed values of the item1 and item2 variables as item3 and item4 respectively whose type is set to out.

The output of the program is given as follows:

```
The addition is: 50
The value of item1 is: 10
The value of item2 is: 10
The value of item3 is: 20
The value of item4 is: 30
```

### Passing Parameters using the params Keyword

Parameters with the params keyword are very useful when we do not know about the size of the array. These parameters are single dimensional or jagged array and can accept multiple values. The params keyword is mentioned in the argument part of the called method that is going to accept an array of any length.

However, few restrictions are imposed on params, which are given as follows:

- Only one argument with the params keyword is permitted in a method definition
- If a method contains a parameter with the params keyword, then no other parameters are allowed to be passed after the params keyword in the method declaration

Listing 17.55 shows an example of passing parameters with the params keyword.

**Listing 17.55: Showing an Example of Passing Parameters using the params Keyword**

```csharp
using System;
class Program
{
    public static void Main()
    {
        int[] list = { 1, 2, 3, 4, 5, 6, 7, 8, 9 };
        //Passing reference with params keyword to the method Add()
        Addition addition = new Addition();
        int result = addition.Add(list);
        Console.WriteLine("The addition is: {0}", result);
    }
}
class Addition
{
    public Addition()
    {
    }
    public int Add(params int[] numbers)
    {
        int result = 0;
        foreach (int i in numbers)
        {
            result += i;
        }
        return result;
    }
}
```

In the preceding program, we are passing an array of integer whose size is not defined. To add array elements, we are declaring a method that has an argument of integer array with the params keyword. This method adds the number of the items in the list and returns the result. The output of the program is given as follows:

The addition is: 45
