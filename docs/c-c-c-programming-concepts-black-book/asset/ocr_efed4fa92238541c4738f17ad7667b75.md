function Radix_Sort(A[n])
begin
    B[n] <- initialize output queue
    bin <- user defined value for the size bin array
    length <- maximum length of the array element

    for i <- 0 to i <- length -1
    begin
        for j <- 0 to j <- bin -1
        begin
            radix <- GetRadixValue (A[j], i)
            B[radix].enqueue(A[j])
        end
        for k <- 0 to k <- B.Length
        begin
            while(B[k] is not null)
            begin
                A[pos] <- B[k].dequeue()
                pos++
            end
        end
    end
end
function GetRadixValue(num, position)
begin
    radixVal <- num/ Powerof(10, position -1)mod 10
    return radixVal
end

The preceding algorithm implements the radix sort that involves no comparison. First, we declare the bin value and then the maximum length of the array elements. This algorithm starts from the one's position of each array element. Depending on the value of the one's position, the B queue, which is declared at the beginning of the algorithm, is populated in such a way that the ith position in B is occupied by the elements of the array A whose one's position is matched with i. The GetRadixValue() function is used to get the one's or ten's or hundred's position value of an element. When the B queue is populated with all the elements from the input array A, then A is re-populated with the values from B in a proper order. Again, this technique is applied to A, where the ten's position is considered. This process is repeated until each element of the array is sorted in a proper order.

Now, let's analyze the radix sort algorithm. In the algorithm, the outer loop executes for the d times, where d is the length of the element, and the inner loop executes for the n times, where n is the bin size supplied by a user. Therefore, the time requires to sort the list is O(n). In the worst and best cases, the behavior of the algorithm is same, as no comparisons take place. Therefore, radix sort is the most recommended sorting algorithm.
