Next, let's learn about function overriding.

## Function Overriding

While implementing inheritance between two classes, a derived class inherits all the member variables, methods, fields, and events from its base class. Now if the derived class wants to change one behavior of the base class that has been defined in one of the methods of the base class, then it needs to define that method as a *virtual* method. Therefore, modifying the behavior of a method in a derived class is known as function overriding.

We can declare a method as a *virtual* method by writing the *virtual* keyword before the return type of the method. A *virtual* method can only be used to implement function overriding. It cannot be used for any other purpose. Using *virtual* methods, we can plan our programming in such a way that the derived class will have the opportunity to add its own properties to the overridden member methods. Now, a derived class uses the *override* keyword to override the method of a base class. In this case, the *override* keyword is placed just before the return type of the method. The polymorphism implemented in this case is that the name and the arguments of these overridden methods are the same.

**Listing 18.21** shows an example of function overriding:

```csharp
//Base class
public class Vehicle
{
    public virtual void PrintVehicleType()
    {
        Console.WriteLine("Vehicle type is generic");
    }
}
//Derived classes
public class Car : Vehicle
{
    public override void PrintVehicleType()
    {
        Console.WriteLine("Vehicle type is car");
    }
}
public class Bike : Vehicle
{
    public override void PrintVehicleType()
    {
        Console.WriteLine("Vehicle type is Bike");
    }
}
```

In Listing 18.21, we have defined a base class Vehicle, which is generic in type. In addition, we have defined two derived classes that represent two different vehicle types car and bike. After that, we have overridden the PrintVehicleType() method in both the derived classes. Listing 18.22 shows how to call the overridden methods:

### Listing 18.22: Showing the Procedure to Call the Overridden Methods

```csharp
public class Program
{
    public static void Main(string[] args)
    {
        Car car = new Car();
        Bike bike = new Bike();
        car.PrintVehicleType();
        bike.PrintVehicleType();
    }
}
```

In the Main() method, we have called the overridden methods by creating the objects of derived classes.

In addition, we can call the two overridden methods by first instantiating an object array of the base class and then assigning its derived classes as array elements, as shown in Listing 18.23:

### Listing 18.23: Showing an Alternative Procedure to Call the Overridden Methods

```csharp
public class Program
{
    public static void Main(string[] args)
    {
        Vehicle[] vehicleList = new Vehicle[2];
        vehicleList[0] = new Car();
        vehicleList[1] = new Bike();
        foreach(Vehicle obj in vehicleList)
        {
            obj.PrintVehicleType();
        }
    }
}
```

The output of the preceding code is given as follows:

```text
Vehicle type is car
Vehicle type is Bike
```

Using the concept of inheritance, chain inheritance can be defined where all the classes inherit the properties, methods, and interfaces of some base classes. For example, if the Vehicle class has one virtual method that has been overridden by its derived class Four Wheeler, then regardless of whether the derived class is declared overridden or sealed, the virtual method will remain virtual indefinitely; and therefore, the child class of the Four Wheeler class can access that virtual method. Listing 18.24 shows the implementation of this example:

### Listing 18.24: Showing an Example of Chain Inheritance

```csharp
//Base class
public class Vehicle
{
    public virtual void PrintVehicleType()
    {
        Console.WriteLine("Vehicle type is generic");
    }
}
//Derived class of Vehicle
public class FourWheeler : Vehicle
{
    public sealed override void PrintVehicleType()
    {
        Console.WriteLine("Vehicle type is car");
    }
}
//Derived class of FourWheeler
public class Car : FourWheeler
{
    public new void PrintVehicleType()
    {
        //new definition
    }
}
```

Now, if we want to call the method of a base class that has been derived, then a simple type casting by the object of the base class to the invoked method will not help in achieving this goal. In this case, the method of the derived class is called every time we call the method of the base class. However, there is an option to stop the virtual inheritance by using the sealed keyword. For this, we just need to put the sealed modifier before the override operator in the derived class. Listing 18.25 shows an example of using the sealed modifier:

### Listing 18.25: Calling the Virtual Method of a Base Class by Using the sealed Modifier

```csharp
//Base class
public class Vehicle
{
    public virtual void PrintVehicleType()
    {
        Console.WriteLine("Vehicle type is generic");
    }
}
//Derived class
public class Bike : Vehicle
{
    public sealed override void PrintVehicleType()
    {
        Console.WriteLine("Vehicle type is Bike");
    }
}
```

As already learned, the override operator is used to modify the behavior of the method of a base class. However, in case we need to write a different functionality for the same method in the derived class, C# provides the new operator that replaces the definition of the method of a base class. Listing 18.26 shows the implementation of the new operator:

### Listing 18.26: Showing the Example that uses the new Operator

```csharp
//Base class
public class Vehicle
{
    public virtual void PrintVehicleType()
    {
        Console.WriteLine("Vehicle type is generic");
    }
} //derived class
public class Car : Vehicle
{
    public new void VehicleType()
    {
    } //new definition
}
public class Bike : Vehicle
{
    public new void VehicleType()
    {
    } //new definition
}
```

In the preceding program, the Car and Bike classes are derived from a common base class named Vehicle. Both these derived classes contain different definitions for the VehicleType() method using the new operator.

## Operator Overloading

Operations are meant to be operated on the C# built-in types, such as int, double, and long. Operator overloading is basically used to implement the specific operators to our own types.

Operator overloading method is generally declared using the *operator* specifier and the method has to be static.

### Listing 18.27: Showing an Example of Operator Overloading

```csharp
using System;
public class Program
{
    public static void Main()
    {
        Array arr1 = new Array();
        arr1.InitializeArray();
        Console.WriteLine("The 1st array is: ");
        arr1.PrintArray();
        Array arr2 = new Array();
        arr2.InitializeArray();
        Console.WriteLine("The 2nd array is: ");
        arr2.PrintArray();
        Array resultAddArr = arr1 + arr2;
        Console.WriteLine("The result of addition is: ");
        resultAddArr.PrintArray();
        Array resultMultArr = arr1 * arr2;
        Console.WriteLine("The result of multiplication is: ");
        resultMultArr.PrintArray();
    }
}
public class Array
{
    public const int size = 10;
```
