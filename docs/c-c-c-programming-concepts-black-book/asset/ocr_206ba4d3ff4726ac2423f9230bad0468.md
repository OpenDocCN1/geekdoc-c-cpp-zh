While working with external variables, it is important to understand the difference between their declaration and definition. Declaration of extern variables is similar to that of any other variables like auto or register. The only difference is that they should be declared outside and functions accessing them. Definition of variables links a storage class specifier with it. It is not mandatory to use the keyword "extern" while defining an extern variable. The compiler will itself link the extern storage class with the variable depending on the location of its declaration. A variable defined as extern can be assigned a value from the point of its definition.

Listing 2.27 shows how to declare extern variables:

# Listing 2.27: Extern Storage Class Specification

```
```c
#include<stdio.h>

int global_var = 10;

int main()
{
        printf("\n The value of the variable is [%d] ",global_var);
        getch();
        return 0;
}
```
```

The output of Listing 2.27 is given as follows:

```
```text
The value of the variable is [10]
```
```

The global_var variable is declared before any functions in the program, so the compiler has assigned an extern storage class to the variable. This makes the global_var variable accessible from any function inside the program.

Listing 2.28 shows how to modify values of an extern variable:

# Listing 2.28: Modifying Values of an Extern Variable

```
```c
#include<stdio.h>

int global_var = 10;

void myFunction();
int main()
{
        printf("\n The value of the variable is [%d] ",global_var);
        myFunction();
        printf("\n The value of the variable is [%d] ",global_var);
        getch();
        return 0;
}
void myFunction()
{
        global_var++;
}
```
```

The output of Listing 2.28 is given as follows:

```
```text
The value of the variable is [10]
The value of the variable is [11]
```
```

The output shows that the variable retains the values assigned to it from any function and the same value is displayed when the variable is next time displayed from the main function. One fact about extern variables is that for majority of variables, declaration also means the definition of variables. However, for extern variables, we can actually declare the variable without defining it. When we need to refer to the same variable, we can associate the name of the variable with the extern keyword that automatically links the declaration of the variable with the definition.
