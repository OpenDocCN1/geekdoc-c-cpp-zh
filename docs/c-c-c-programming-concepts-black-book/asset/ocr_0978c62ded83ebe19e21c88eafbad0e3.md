**Table 21.6: Noteworthy Methods of the File Class**

| Method | Description |
|---|---|
| `OpenRead(string path)` | Opens a *FileStream* in the user-specified path to read a file.<br>This method returns a *FileStream* object.<br>It only takes a user-defined path as an argument. |
| `OpenText(string path)` | Opens a file with the UTF-8 encoded text for reading.<br>This method returns a *StreamReader* object.<br>It only takes a user-defined path as an argument. |
| `OpenWrite(string path)` | Opens a file in the user-specified path to write.<br>This method returns a *FileStream* object.<br>It only takes a user-defined path as an argument. |
| `ReadAllBytes()` | Opens a binary file, reads the content of the file, stores the content in a byte list, and then closes the file.<br>It returns a byte array. |
| `ReadAllLines()` | Opens a file, reads the content of the file, stores the content in a string array, and then closes the file.<br>It returns a string array.<br><br>Overloads:<br>• `ReadAllLines(string path, System.Text.Encoding encoding)` → Opens a file, reads the content of the file with the specified encoding, stores the content in a string array, and then closes the file. |
| `ReadAllText()` | Opens a file, reads the content of the file, stores the content in a string, and then closes the file.<br>It returns a string.<br><br>Overloads:<br>• `ReadAllText(string path, System.Text.Encoding encoding)` → Opens a file, reads the content of the file with the specified encoding, stores the content in a string, and then closes the file. |
| `Replace(string sourcePath, string destinationPath, string destinationBackupFilePath)` | Replaces an existing file in the destination path by keeping the backup of that destination file path.<br>It takes three arguments: the first argument specifies the source file path, the second argument denotes the destination file path, and the third argument states the location of destination backup file.<br><br>Overloads:<br>• `Replace(string sourcePath, string destinationPath, string destinationBackupFilePath, bool ignoreMetadataError)` → Replaces an existing file in the destination path by keeping the backup of that destination file path and ignore the metadata error while replacing the existing file in the destination if `ignoreMetadataError` is set to true. |
| `WriteAllBytes(string sourcePath, byte[] byteList)` | Creates a file in the user-specified location, writes the bytes stored in a byte array, and then closes the file. In case of an existing file, it overwrites the file.<br>It returns void.<br>It takes two arguments: one specifies the user-defined path and another denotes the array of bytes, which is to be written in the file. |
