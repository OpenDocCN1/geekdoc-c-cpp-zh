### Listing 24.24: Showing the Algorithm for Insertion Sort

```text
function Insertion_sort(Array[n])
begin
    for i ← 1 to i ← n
    begin
        temp ← Array[i]
        j ← i − 1

        while(temp<A[j] and j>0)
        begin
            A[j+1]←A[j]
            j←j−1
        end
        A[j+1]←temp
    end
end
```

The preceding algorithm sorts a list of elements in the ascending order. It uses two loops to sort the list elements. The outer loop is implemented using the for loop and the inner loop is implemented using the while loop. This algorithm first declares a variable, named temp, which stores the first element in the loop in first iteration, second element in the second iteration, and so on. The element stored in the temp variable is then compared with every other element that is placed before this element using the while loop. If any element has a value greater than the temp variable, then they interchange their positions. At the end of this operation, the list is sorted in the ascending order.

Now, let’s analyze the insertion sort algorithm. In the algorithm, the execution of the for loop will take place in both the best case and the worst case. Therefore, the for loop will iterate (n−1) times in both the cases while performing the key comparisons. In the best case scenario, the input list will be already sorted; therefore, the order of execution will be O(n).

However, in the worst case, the list will be sorted in the reverse order and at each step, the (n−i) number of comparisons will have to take place. Therefore, the order of execution will be calculated as follows:

- (n−1) + (n−2) + … + (n−i) + … + 2 + 1
- n(n−1)/2
- O(n²)

### Quick Sort

Quick sort is one of the efficient sorting techniques invented by C.A.R. Hoare. It applies the divide and conquer strategy to solve the problem. Instead of applying the sorting technique to the entire list, it first divides the list and then applies the sorting. Therefore, this technique comprises the following two phases:

- Partition
- Sorting

In the partition phase, the list is partitioned depending on a key value, which is known as pivot. At the end of the partition phase, the list is divided into two separate lists, where the left-hand side list contains all the elements whose values are smaller than the pivot and the right-hand side list holds all the elements whose values are greater than the pivot. In the sorting phase, the quick sort technique is applied recursively to these two separate lists. This process continues until all the elements are sorted.

While sorting a list using quick sort, it is very important to choose the correct pivot, as it controls the performance of the sorting. In our case, we are considering the first element of the list as the pivot element. As quick sort implements the divide and conquer mechanism, let’s discuss the partition and sorting phases separately.

Following is the stepwise execution of the partition phase:

1. Take the array A[N]. Consider the first element A[0] as the pivot element and assign the value of A[0] to k. Assign 1 and (N-1) to i and j, respectively.

2. If i < j, then increment i until A[i] > k and decrement j until A[j] < k. It means that in each iteration, while moving from left to right, index i searches for the value first greater than the pivot value and stops moving immediately once the match is found. Similarly, the index j, while moving from right to left, searches the value from the right that is smaller than the pivot value and stops immediately once the match is found. At that point, the values A[i] and A[j] are interchanged.

3. While moving from right to left, if i < j, then it implies that one iteration of i and j is completed and at that point, the A[j] is interchanged with the pivot value. This operation results in the list being divided into two sub-lists based on the pivot value, which almost occupies the middle position of the list. The left-hand side of the pivot value is a list that contains the elements having values smaller than the pivot value and the right-hand side of the pivot value is a list that holds the elements having values greater than the pivot.

Now, let's learn about the sorting phase. After getting two separate lists in the partition phase, we apply the quick sort technique separately on them. This recursive call of quick sort method helps the entire list to be sorted in an efficient way.
