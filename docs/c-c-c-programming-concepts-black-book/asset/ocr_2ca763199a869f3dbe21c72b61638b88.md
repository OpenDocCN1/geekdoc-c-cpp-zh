```
# Unary Operators

Operators that act upon a single operand to produce a value are called unary operators. Unary operators generally precede their operands though some of them are also often written after their operands. The most common unary operator used in C is unary minus. A negative number is declared in C by preceding the number with a unary minus operator. A subtraction operation requires two operands for its working; whereas, a unary minus only operates on a single operand.

For example,

-5 becomes a negative numeric constant with a unary minus preceding it.

Apart from unary minus, the two most commonly-used operators are the increment operator and the decrement operator.

# Increment Operator

The increment operator in C is denoted by the ++ sign. The increment operator causes the value of the variable to increase by one. The operand used with these operators must be a single variable.

Consider the following statement:

```
```c
x = x + 1;
```
```

The preceding statement can also be written by using an increment operator as follows:

```
```c
x++;
```
```

We can say that the increment operator is a short hand representation of assigning and incrementing the value inside x.

Two types of increment operations can be done on a variable. One is called the pre-increment operation and the other is called the post-increment operation.
```
