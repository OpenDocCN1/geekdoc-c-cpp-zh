# ## Shift Operators

Bitwise shift operators used in C are the right shift operator and the left shift operator. Each of the two operators requires two operands to work upon. The first operand denotes the bit pattern to be shifted and the second operand denotes the number displacements that need to take place.

Let's learn about the two operators, in detail.

# ### Right Shift Operator

The right shift operator is denoted by the >> symbol. It shifts a given bit pattern to the right side. Suppose the expression for right shift operation is:

```
```
abc >> 5
```
```

This expression would shift all the bits in abc to five places to the right. Let's assume that abc contains a bit pattern, 11010010. Right shifting the bit pattern by one gives:

```
```
01101001
```
```

Further, abc >> 2 would give:

```
```
00110100
```
```

Similarly, abc >> 5 will provide:

```
```
00000110
```
```

As the bits are shifted to the right, blanks are created to the left; these blanks are filled by 0's. Therefore, shifting of bits also incorporates loss of information.
