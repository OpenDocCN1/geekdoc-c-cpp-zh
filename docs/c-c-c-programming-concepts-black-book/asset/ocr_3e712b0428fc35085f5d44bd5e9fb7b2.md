Listing 1.33 shows a variant of the for loop where the increment of the loop control variable has been done inside the body of loop. Listing 1.34 shows a type of the for loop where initialization takes place outside the loop:

**Listing 1.34: Another Use of the for loop**

```
~~~c
#include<stdio.h>

int main()
{
    int i=1;

~~~
```

In Listing 1.34, we are initializing the variable before the loop starts. We are not using the initialization step while using the for loop as it's already done earlier. This is another way of using the for loop. It is even possible to make the for loop work like a while loop.

Listing 1.35 shows an example where the for loop is used as a while loop:

**Listing 1.35: Another Variant of the FOR Loop**

```
~~~c
#include<stdio.h>

int main()
{
    int i=1;

    for(;i <= 10;)
    {
        printf("\n i %d ",i);
        i = i + 1;
    }
    getch();
    return 0;
}
~~~
```

The for loop stated in Listing 1.35 works like a simple while loop. In this case, initialization is done outside the loop statement. The loop statement only contains the test condition and the increment operation is carried inside the body of the loop itself.
