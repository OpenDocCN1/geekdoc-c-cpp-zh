# # #pragma

The #pragma directive is an implementation-driven directive that is used to provide various instructions to the compiler. Pragma varies from one compiler to another. Certain pragmas, such as startup and exit, are used for inserting comments in a source code. Listing 7.12 shows the working of pragmas:

Listing 7.12: Showing the Working of Pragmas

```
```c
void fun1( ) ;

void fun2( ) ;

#pragma startup fun1

#pragma exit fun2

main( )
{
    printf ( "\ninside main" ) ;
}
void fun1( )
{
    printf ( "\ninside fun1" ) ;
}
void fun2( )
{
    printf ( "\ninside fun2" ) ;
}
```
```

In Listing 7.12, the #pragma startup and #pragma exit directives allow a user to specify functions that should be called before and after the execution of the main() function, respectively.

The output of Listing 7.12 is given as follows:

```
```
Inside fun1
Inside main
Inside fun2
```
```

# # #line

The #line directive changes the content of __LINE__ and __FILE__, which are two predefined identifiers in the compiler. The __LINE__ identifier holds the line number of the currently compiled line of code. The __FILE__ identifier holds a string that contains the name of the source file being compiled. Listing 7.13 shows the code written without the #line directive:

Listing 7.13: Showing the Code Without Using the #line Directive

```
```c
#include<stdio.h>

int main()
{
    printf("\n In Line [%d] File name [%s] ",__LINE__,__FILE__);
    getch();
}
```
```
