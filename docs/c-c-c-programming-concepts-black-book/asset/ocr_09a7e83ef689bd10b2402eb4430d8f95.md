# # Creating a File System Application using C#

The My File Manager application loads a tree structure that contains all the directories, sub-directories, and files (stored in those directories and sub-directories) in a specific system drive. This application performs the following tasks:

+   - It loads the file and directory structure of a user-specified drive on the main page of the application.
+   - After the page is loaded with the drive structure, users are allowed to select the text files. The content of the selected file appears in the text box provided on the page.
+   - After the text box is populated with the content of the file, three buttons, named Modify, Append, and Upload, will be enabled.
+   - When a user clicks the Modify button, the user will be able to view the content of the file in a new text box, edit the file, and save the modified file. Through the Save button, the modified content of the file will also be reflected in the text box. The user also gets the option to undo the modifications done on the file.
+   - When a user clicks the Append button, the user is provided with a blank text box where he/she can write the text that is to be appended on the text file. After clicking the Save button, the text file is appended with that line of text and the text box reflects the changes. A user can also cancel the append operation.
+   - After clicking the Upload button, a user will be able to view the FileUpload control, where the user can upload a file to a specified location.

Now, let's discuss each operation in more detail in the next sub-sections.
