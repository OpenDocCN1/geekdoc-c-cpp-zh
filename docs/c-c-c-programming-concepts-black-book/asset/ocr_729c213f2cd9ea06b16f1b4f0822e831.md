The programming styles used in writing a C or a C++ program is another source of confusion for the programmers. Ideally, we have three styles or programming, namely, procedural, assembler, and function applicative. Pascal is procedural; assembly language follows the assembler style, and LISP being function applicative. C, however, has all the three styles and often integrates all the three styles, thereby making it more flexible.
