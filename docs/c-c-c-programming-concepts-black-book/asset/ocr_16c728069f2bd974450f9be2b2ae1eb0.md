# Brief History of C

The development process of an older language called Basic Combined Programming Language (BCPL) led to the evolution of C. BCPL was developed by Martin Richards. Later, Ken Tompson developed BCPL into a more structured language called B. Ultimately, B led to the development of C in 1970s by Dennis Ritchie. The standardization process of C took six years. The ANSI C standard was first started in December 1989. The standard was also adopted by International Standards Organization (ISO) in 1990 and was named ANSI ISO standard for C. In 1995, the Amendment 1 to the C standard was published, resulting in the inclusion of several new library functions. The version of C defined in 1989 was commonly referred to as C89. This became a base document of the Standard in C++. In 1999, a new standard of C evolved which was commonly called as C99. It retained most of the things of C89. The C99 standard mainly focused on few new concepts:

+   i. The addition of numerous numeric libraries
+   
+   ii. Variable length arrays
+   
+   iii. The restrict pointer qualifiers

# *C as a Middle Level Language*

Is C a middle level language? The answer is Yes. However, this does not mean that it is harder to use or it is not developed enough. C is called a middle level language as it combines the best features of a high level language with the flexibility of an assembly level language. Being a middle level language, C allows the freedom of manipulating with bits, bytes, and addresses. C is also very portable and can adapt to any operating system. Despite having many built in data types, it is a highly typed language. It permits all type conversions, for example, it allows you to combine characters and integer data types in a single expression. C has got another advantage of not demanding strict type compatibility between a parameter and an argument, as long as the argument can be converted into the data type of the parameter. As C allows the manipulation of bits, bytes, and pointers, it is very suitable as a system level language. C has also got very small numbers of keywords. C89 introduces 32 keywords and with the evolution of C99, 5 more keywords are added with it. Basic has got more than 100 keywords in comparison to 37 keywords of C.

# *C as a Structured Language*

C is very much a structured programming language, as it allows a program to be broken into loops (e.g. for, while, and do-while loops), if-else blocks, functions, and procedures. C is not regarded as a block structured language, as it allows a procedure or function to be declared inside other procedure or function. The following code snippet shows an example of a structured block in C:

```
```c
if ( i < 10)
{
    printf(" X");
    scanf("%d", &i);
}
```
```

The preceding code snippet shows that the two statements within the curly braces form a single unit, which would be executed if ‘i’ is less than 10.
