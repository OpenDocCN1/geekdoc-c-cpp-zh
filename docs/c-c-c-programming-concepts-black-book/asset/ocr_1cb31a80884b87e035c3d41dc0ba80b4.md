+   - **Static constructor**—Refers to a constructor that is used to initialize the static member variables. In addition, it is used in cases where a particular method needs to be executed only once. The static constructor is called before the creation of the class object. The peculiarity that makes it different from other constructors is that it neither takes any access modifier nor has parameters passed to it as arguments. To make a constructor static, we just need to put the static keyword before the name of the constructor. The static constructors are defined only for the static members and they cannot access any non-static member of a class. Static constructors cannot be called directly; however, they can be called automatically to initialize the class before the creation of the first instance of the class.
