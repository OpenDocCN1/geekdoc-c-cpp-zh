# Inline Specifier

C++ provides an interesting feature known as inline function, which has the feature of both a function and a MACRO. An inline function not only prevents duplication of code like a common C++ function but also saves the function calling overhead by expanding inline like a MACRO.

We all know that function saves space in the memory because every call to the function, during the program execution, causes the same memory chunk to get executed. However, this feature does not come for free. Any call to a function does a lot of background job during any function call. Whenever the compiler finds a function call in the source code, it immediately takes the program control to the calling function from the caller function. However, in between the generation of a jump to the function, a lot of instruction execution takes place, such as instruction for saving register content for the previous execution instruction, instruction for pushing arguments onto stack, instruction for restoring registers, and lots more.

Imagine a scenario where a function has a very small body, such as a utility function for calculating the power of an integer member or a function to check whether a flag is enabled or not. For such cases, we cannot afford to spend so much overhead in saving registers and doing all other instruction execution like we do for any normal function call. As a solution to this, the inline function is introduced, which resembles exactly like a function but ignores the overhead associated with the function call mechanism by expanding the function call inline.

C++ implements the inline function with the help of an “inline specifier.” Let us illustrate the concept of an inline function by writing a small program:
