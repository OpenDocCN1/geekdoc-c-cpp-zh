
## String Copy

To copy a string, the `Copy()` method of the string class is used. The `Copy()` method accepts a string as an input, copies the content of the string into a new string, and returns the new string. The syntax of the `Copy()` method is given as follows:

```csharp
string Copy(string sourceString)
```

Listing 17.17 shows the usage of the `Copy()` method to copy a string:

**Listing 17.17: Showing the Usage of the Copy() Method**

```csharp
using System;
class Program
{
    public static void Main()
    {
        Console.WriteLine("Please enter the string to be copied:");
        string str = Console.ReadLine();
        string strcopy = string.Empty;
        if (str != string.Empty)
        {
            strcopy = String.Copy(str);
            Console.WriteLine("The copied string is {0}", strcopy);
        }
        else
        {
            Console.WriteLine("You entered a null string");
        }
    }
}
```

In the preceding program, we first read the input from the console, store it into a string, and then check for the content of the string. If the string is not empty, the program creates a new string with the same content by using the `Copy()` method, which is then displayed on the console. The output of the program is given as follows:

```text
Please enter the string to be copied:
Hello world!!!
The copied string is Hello world!!!
```

## CopyTo Operation

The `CopyTo()` method provides a functionality that copies the required number of characters from an indicated position in the string to a specific position in an array. Both the string and the array should contain the Unicode characters. The syntax of the `CopyTo()` method is given as follows:

```csharp
void CopyTo(int sourceIndex, char[] destinationArray, int destinationIndex, int count)
```

Listing 17.18 shows the usage of the `CopyTo()` method:

**Listing 17.18: Showing the Usage of the CopyTo() Method**

```csharp
using System;
class Program
{
    public static void Main()
    {
        string str = "nice";
        char[] destArr = { 's', 'h', 'e', ' ', 'i', 's', ' ', 'a', ' ', 'g', 'o', 'o', 'd', ' ', 'g', 'i', 'r', 'l' };
        Console.WriteLine("The actual string is...");
        Console.WriteLine(destArr);
        str.CopyTo(0, destArr, 9, str.Length);
        Console.WriteLine("After applying the CopyTo() method, the string is...");
        Console.WriteLine(destArr);
    }
}
```

In the preceding C# code, we have first declared a string that is to be copied to the character array and then a character array is instantiated. After that, we have applied the `CopyTo()` method to the string. The output of the program is given as follows:

```text
The actual string is...
She is a good girl
After applying the CopyTo() method, the string is...
She is a nice girl
```

## Remove Operation

The `Remove()` method is used to remove a part of a string by mentioning its starting position index and the ending position index. In case we mention only the starting position index, the remove operation starts from that position and continues until the end of the string. We can also mention the ending index of the string only. The syntax of the `Remove()` method is given as follows:

```csharp
string Remove(int startIndex)
```

The `Remove()` method has an overloaded method that accepts the start index as well as the number of characters to be removed from the string. Listing 17.19 shows the usage of the `Remove()` method:

**Listing 17.19: Showing the Usage of the Remove() Method**

```csharp
using System;
class Program
{
   public static void Main()
   {
      string str = "Hello world";
      string strResult = string.Empty;
      Console.WriteLine("Removing the first part....");
      strResult = str.Remove(0, str.LastIndexOf(" ")+1);
      Console.WriteLine(strResult);
      Console.WriteLine("Removing the second part....");
      strResult = str.Remove(str.LastIndexOf(" "));
      Console.WriteLine(strResult);
   }
}
```

In the preceding program, we have removed the first part of the string "Hello World". The `Remove()` method takes the first index as 0 and the last index is set to the index of the blank string incremented by 1. This method will print only the second part, which is "World" of the actual string. Next, we have deleted the second part of the string by only mentioning the starting index. The output of the program is given as follows:

```text
Removing the first part....
world
Removing the second part....
Hello
```

## Substring Operation

The `Substring()` method is applied to a string when we want to retrieve its start position and/or end position. This method is very helpful in cases where we want to get the information from a long string or break a long string into several substrings. The two overloaded methods of `Substring()` are given as follows:

```csharp
string Substring(int startIndex)
```

or

```csharp
string Substring(int startIndex, int length)
```

Listing 17.22 shows the usage of the `Substring()` method:

**Listing 17.22: Showing the Usage of the Substring() Method**

```csharp
using System;
class Program
{
    public static void Main()
    {
        string str = "Hello world";
        string strResult = string.Empty;
        Console.WriteLine("The actual string is...");
        strResult = str.Substring(0, str.Length);
        Console.WriteLine(strResult);
        Console.WriteLine("The substring element is...");
        strResult = str.Substring(0, str.LastIndexOf(" "));
        Console.WriteLine(strResult);
    }
}
```

In the preceding program, we have first printed the complete string using the `Substring()` method by providing the starting index of the string. Then, we have displayed only the first part of the string "Hello World" by providing the starting index and the ending index with the help of the `LastIndexOf()` method. As an input of the `LastIndexOf()` method, we have passed only a blank string. This method searches for a blank position in the string and if it is the last blank position inside the string, then it returns the string literals that it already traverses. The output of the program is given as follows:

```text
The actual string is...
Hello world
The substring element is...
Hello
```

## Structure

We have already learned about structures in C and C++. However, in C#, the structure holds the definition as follows:

- A structure is a value type.
- A structure can hold fields, methods, and events similar to a class.
- As a structure is of value type, it can be instantiated without using a `new` operator.
- A structure is inherited from the `System.Object` namespace.
- A structure cannot be inherited by any other structure. In addition, it cannot be a base structure of any class.
- The members of a structure cannot be initialized unless they are declared as a constant using the `const` operator or a static using the `static` operator.
- Any default constructor or destructor cannot be defined inside the structure because whenever a copy of a structure is created, the compiler automatically sets the default constructor or destructor.

Structure in C# behaves somewhat similar to a class, but the difference lies in the fact that class is a reference type and structure is a value type. Therefore, whenever we assign a structure to another structure, the whole structure along with its content is copied to the structure. In addition, if we make any modifications to the copied structure, it will not reflect to the structure, which is copied. This is one of the main disadvantages of using a structure instead of a class.

In C#, a structure is defined using the keyword `struct`. We can declare a structure as follows:

```csharp
public struct <structure_Name>
{
    //declaration of Field, Properties, Methods, Event etc
}
```

Listing 17.23 shows the usage of a structure in C#:

**Listing 17.23: Showing the Usage of a Structure**

```csharp
using System;
public struct Example
{
    public string str;
    public Example(string s)
    {
        str = s;
    }
}
public class Program
{
    public static void Main()
    {
        Example e = new Example();//calling the default constructor
        Example e1 = new Example("Hello world");//calling the parameterized
                                               //constructor
        Console.WriteLine(e1.str);
    }
}
```

In the preceding program, we have first declared a structure named Example that contains a field str and a parameterized constructor where we have mentioned a string. Then, we have created two objects of the Example structure in the Program class: the e object using the default constructor of the structure and the e1
