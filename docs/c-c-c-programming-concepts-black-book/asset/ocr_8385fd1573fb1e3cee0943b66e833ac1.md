The following source files, Source file 1 and Source file 2, are included in the project:

```
```c
/* Source file 1 */

#include<stdio.h>

extern int global_var;

void display_file1()
{
    global_var++;
    display();
    return;
}
/* Source file 2 */

#include<stdio.h>

extern int global_var;

void display_file2()
{
    global_var++;
    display();
    return;
}
```
```

The following main module is also included:

```
```c
/* The main module */

#include <stdio.h>
#include <stdlib.h>
#include "test.h"

int main(int argc, char *argv[])
{
    display();
    display_file1();
    display_file2();
    getch();
    return 0;
}
```
```

Both the source files use the global variable “global_var” and increments it with 1 before displaying the variable. Inside the main module, we call two different functions “display_file1()” and “ display_file2()”, which are defined in the source files 1 and 2, respectively.

The output of Listing 2.30 is given as follows:

```
```text
Global Variable [10]
Global Variable [11]
Global Variable [12]
```
```

In Listing 2.30, Inside the main function, first the common display function defined inside the header gets called. This function displays the global variable. In the first case, no change has yet been made to the global variable so we get the value as 10.
