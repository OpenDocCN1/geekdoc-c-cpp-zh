# # The Stream Class Hierarchy

Similar to the C-based I/O method, the C++ I/O method also operates by the means of streams. A stream can be a logical device, which either produces or consumes information. It is connected to a logical device from the I/O system. Almost all the streams behave in the same manner even though the specific physical devices, with which they are connected to, may vary substantially. As all the streams behave identically, the same I/O capabilities can operate on virtually almost any physical device. The benefit of this approach is that we need to learn about a single I/O system only.

Standard C++ provides support for streams through the `<iostream>` header. With this header, a rather complicated group of class hierarchies is described that supports the I/O procedures. The I/O classes start with a system of template classes. A template class defines the shape of a class without fully specifying the information upon which it may operate. Once a template class is defined, specific instances of it may be created. As the template classes pertain to the I/O library, standard C++ creates two specializations for them—one for 8-bit characters and another for wide characters. The I/O system is made up on two related but different template class hierarchies. The foremost is derived from the low-level I/O class called *basic_streambuf*. This class supplies the fundamental, low-level input and result operations, as well as provides the underlying support for the whole I/O system. Note that *basic_streambuf* is used only during advanced I/O programming. Most commonly used class hierarchy is *basic_ios*, which is a high-level I/O class that provides formatting, error checking, and status information associated with an I/O stream. A base class for *basic_ios* is known as *ios_base*, which defines several non-template traits utilized by *basic_ios*. *basic_ios* can be used as a base for several derived classes, such as *basic_istream*, *basic_ostream*, and *basic_iostream*. These classes are utilized to create streams at input, output, and input/output, respectively.

Let’s now discuss the stream class hierarchy. The *ios* class defines the basic formatting and error control capabilities. It is a virtual base class for the *istream* and *ostream* classes. The *iostream* class inherits from both the *istream* and the *ostream* classes. These classes are used to take input from the keyboard and send output to the screen.
