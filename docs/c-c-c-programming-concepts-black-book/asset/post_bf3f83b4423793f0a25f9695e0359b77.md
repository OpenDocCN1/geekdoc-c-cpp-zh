## Standard String Library Functions

C has a varied set of library functions for string manipulation. Each of these functions operates on a null-terminated string and requires the `<string.h>` header. The header also defines the `size_t` type, which is the return type of the `sizeof` operator and is a form of unsigned integer.

Some standard string library functions in C are as follows:

- strcat()
- strcmp()
- strlen()
- strncpy()
- strncat()
- strchr()
- strcspn()
- strcpy()

Let’s learn about these functions in detail, one by one.

### strcat()

The signature of the strcat() function is given as follows:

```c
char *strcat(char *str1, const char *str2);
```

The strcat() function concatenates a copy of str2 to str1 and terminates str1 with a NULL. The NULL terminator, which originally ending the str1 string, is overwritten by the first character of str2. The str2 string is unchanged by this operation. If both the strings overlap in the memory, then the behavior of strcat() is undefined. In the C99 compiler, both the str1 and str2 parameters are qualified by the restrict type qualifier. The strcat() function returns the str1 string after the successful concatenation. The signature of the strcmp() function is as follows:

```c

```

The two strings are compared lexicographically until there is a mismatch or one of the strings reached its end. If both the strings are identical, then strcmp() returns a zero. ### strncat()

The signature of the strncat() function is as follows:

```c
char *strncat(char *str1, const char *str2, size_t count);
```

The strncat() function concatenates up to the count characters of the string pointed to by str2 to the string pointed to by str1. This function also terminates str1 with a NULL. The NULL terminator at the end of str1 is overwritten by the first character of str2. The str2 string is unchanged by this operation. If the str1 and str2 strings overlap, then the behavior is undefined. Listing 3.9 shows the working of strncat():

### Listing 3.9: Showing the Working of the strncat() Function

#include<stdio.h>
#include<string.h>

int main()
{

    fflush(stdin);
    printf("\n Enter String 2 -> ");
    gets(str2);
    strncat(str1, str2 , 10);

    printf("\n The result of the operation is -> %s",str1);

    getch();
    return 0;
}

### strchr()

The signature of the strchr() function is as follows:

```c
char *strchr(const char *str, int ch);
```

The strchr() function returns a pointer to the first occurrence of the low-order byte of ch in the string pointed to by str. If a match is not found, then a null pointer is returned. Listing 3.10 shows the working of strchr():

### Listing 3.10: Showing the Working of the strchr() Function

```c
#include<stdio.h>
#include<string.h>

int main()
{
    char str1[20];
    char *str2;

    printf("\n Enter String 1 -> ");
    gets(str1);

    str2 = strchr(str1,'A');

    printf("\n The result of the operation is -> %s",str2);

    getch();
    return 0;
}
```

Output of the preceding program is as follows:

```
Enter String 1 -> MY NAME IS TANUMAN

The result of the operation is -> AME IS TANUMAN
```

### strcspn()

The signature of the strcspn() function is as follows:

```c
size_t strcspn(const char *str1, const char *str2);
```

The strcspn() function returns the length of the initial substring of the string pointed to by str1, which is made up of only those characters that are not contained in str2. It also returns the index of the first character in the string pointed to by str1 that matches any of the characters in str2. Listing 3.11 shows the working of strcspn():

### Listing 3.11: Showing the Working of the strcspn() Function

```c
#include<stdio.h>
#include<string.h>

int main()
{
    char str1[20];
    char str2[20];
    int length;

    printf("\n Enter String 1 -> ");
    gets(str1);
    fflush(stdin);
    printf("\n Enter String 2 -> ");
    gets(str2);

    length = strcspn(str1, str2);

    printf("\n The result of the operation is -> %d",length);

    getch();
    return 0;
}
```

Output of the preceding program is as follows:

```
Enter String 1 -> MY NAME IS TANUMAN
Enter String 2 -> TB
The result of the operation is -> 11
```

### strcpy()

The signature of the strcpy() function is as follows:

```c
char *strcpy(char *str1, const char *str2);
```

The strcpy() function copies the content of str2 into str1. str2 must be a pointer to a null-terminated string. The strcpy() function returns a pointer to str1. If str1 and str2 overlap, then the behavior of strcpy() is undefined. Listing 3.12 shows the usage of strcpy():

### Listing 3.12: Showing the Working of the strcpy() Function

```c
#include<stdio.h>
#include<string.h>

int main()
{
    char str1[20];
    char str2[20];

    printf("\n Enter String 1 -> ");
    gets(str1);
    fflush(stdin);
    printf("\n Enter String 2 -> ");
    gets(str2);

    strcpy(str1, str2);

    printf("\n The result of the operation is -> %s",str1);

    getch();
    return 0;
}
```
