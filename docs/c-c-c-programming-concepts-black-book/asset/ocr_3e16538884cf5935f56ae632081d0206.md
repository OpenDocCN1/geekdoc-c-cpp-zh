The **SelectMany** operator is used for a collection, which in turn holds another collection. For example, if we define a List type variable that contains an object of the Employee class, which has three different types of members, then we can use the **SelectMany** operator. In this situation, we need to frame the LINQ query in different ways using the **select** keyword to get only the ID and the name of an employee. In this case, the result type of the query will be anonymous. Listing 19.25 shows the implementation of the SelectMany operator using the select keyword:

# **Listing 19.25:** Showing the Implementation of the SelectMany Operator

```
```csharp
using System;
using System.Linq;
using System.Collections;
using System.Collections.Generic;

class Program
{
    public static void Main()
    {
        List<Employee> empList = new List<Employee>();
        empList.Add(new Employee(100, "James", "Team Member"));
        empList.Add(new Employee(200, "Jonathan", "Senior Manager"));
        empList.Add(new Employee(300, "Keith", "Team Member"));
        empList.Add(new Employee(400, "Jonny", "Manager"));
        empList.Add(new Employee(500, "Amy", "Senior Manager"));
        empList.Add(new Employee(600, "Leonardo", "Team Member"));


        var empSel = from emp in empList
                     where emp.designation.Equals("Team Member")
                     orderby emp.empName
                     select new { id = emp.empID, name = emp.empName };

        foreach (var e in empSel)
        {
            Console.WriteLine("Employee ID: {0} Employee Name: {1}", e.id, e.name);
        }
    }
}

class Employee
{
    public int empID;
    public string empName;
    public string designation;

    public Employee()
    {
    }
}
