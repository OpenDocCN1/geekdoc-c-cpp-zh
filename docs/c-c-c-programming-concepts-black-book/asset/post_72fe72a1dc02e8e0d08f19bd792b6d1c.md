### Nesting of Structure

A member element of a structure can again be a variable of another structure. When we declare a variable of one structure inside another, we are nesting the structures one inside the other. In such case, nested structure members can be accessed with the repeated use of the dot operator. A general expression for accessing the nested structure members is as follows:

```c
variable.member.submember;
```

In the preceding expression, `variable` refers to the name of the outer structure type variable, `member` denotes the name of the member variable within the outer structure, and `submember` refers to the name of the member within the embedded structure.

In Listing 5.2, we have declared `mfdDate` as a member of the `Car` structure. Instead of a simple integer type variable, we can create a structure called `Date`, as follows:

```c
struct Date
{
    int day;
    int month;
    int year;
};
```

Therefore, the `Car` structure can now be reorganized as follows:

```c
struct Car
{
    char name[50];
    char model[50];
    float price;
    struct Date mfdDate;
    int mileage;
};
```

In the preceding code snippet, we have nested the `mfdDate` structure inside the `Car` structure. Listing 5.3 shows how to access the nested structure members:

**Listing 5.3: Accessing the Nested Structure Members**

```c
#include<stdio.h>

struct Date
{
    int day;
    int month;
    int year;
};

struct Car            /* Declaring the structure */
{
    char name[50];
    char model[50];
    float price;
    struct Date mfdDate; /* Nested Structure */
    int mileage;
};

struct Car varA;      /* Declaring structure type variables */

int main()
{
    int i;
    printf("\n Enter Name of the Car -> ");
    gets(varA.name);
    printf("\n Enter Model of the Car -> ");
    gets(varA.model);
    printf("\n Enter Price of the Car -> ");
    scanf("%f", &varA.price);
    printf("\n Enter Manufacturing Date of the Car ");
    printf("\n Enter Day ->");
    scanf("%d", &varA.mfdDate.day);
    printf("\n Enter Month ->");
    scanf("%d", &varA.mfdDate.month);
    printf("\n Enter Year ->");
    scanf("%d", &varA.mfdDate.year);
    printf("\n Enter Mileage of the Car -> ");
    scanf("%d", &varA.mileage);

    printf("\n Details Entered are \n");

    printf("\n Name of the Car -> %s", varA.name);
    printf("\n Model of the Car -> %s", varA.model);
    printf("\n Price of the Car -> %f", varA.price);
    printf("\n Manufacturing Date of the Car -> "
           "%d/%d/%d", varA.mfdDate.day, varA.mfdDate.month, varA.mfdDate.year);
    printf("\n Mileage of the Car -> %d", varA.mileage);

    getch();
    return 0;
}
```

In Listing 5.3, we have defined a structure called `mfdDate`. Then, we have declared a variable of the same structure inside the `Car` structure. When we declare a variable of type `Car`, the compiler allocates the memory for the members of both the structures. In case we want to access the members of the `mfdDate` structure using a variable of type `Car`, we have to use two dot operations. For example, if we want to access the month of the manufacturing date of a car, then we need to use the `varA.mfdDate.month` syntax. For accessing `mfdDate`, we need to use one dot against the variable `varA` for accessing members of another structure, that is, we need to give a dot after `mfdDate` as well. ### Exploring Array of Structures

Consider a scenario where we want to store information about 100 cars. Declaring 100 variables is not a proper way of dealing with such case. A better approach is to use array of structures that allows us to maintain a huge set of information more methodically. An array of structure is a simple array where each element of that array will contain a structure type variable. A generic format of declaring an array of structures is as follows:

```c
storage_class struct name    variable[n];
```

The preceding format creates an array of type `struct` called `name`, which is of size `n`. In addition, `variable` becomes an `n` cell array of structure. Each array element represents one customer record. Listing 5.4 shows how to handle an array of structures:

**Listing 5.4: Handling Array of Structures**

### Assigning a Structure Variable to Another

We can assign a structure variable to another structure variable of the same type. This assignment is done by using the assignment operator (`=`). When we assign one structure variable to another, we just copy the entire chunk of memory to another variable. It is similar to calling the `memcpy()` utility function for copying a chunk of memory. In fact, some of the compilers call the same utility when assignments amongst the structure variables take place. A major advantage of using structure assignment is that we are able to directly copy all the content of the structure to another variable. Moreover, there is no need of individual copy members. Listing 5.5 shows how to assign one structure variable to another:

**Listing 5.5: Assigning a Structure Variable to Another**

```c
#include<stdio.h>

struct student
{
    char name[20];
    int class;
    int age;
};

struct student stu1 = {"Tanuman",12,16};
struct student stu2;

int main()
{
    stu2 = stu1; /* Copying Structure variable to another */

    printf("\n Name of student %s", stu2.name);
    printf("\n Class of the student %d", stu2.class);
    printf("\n Age of the student %d", stu2.age);

    getch();
    return 0;
}
```
