In Listing 2.1, we are calling the display function from the main function. Whenever the term **call** gets used in the context of a function, it means that the control shifts from the caller to the called function. A typical function call made in C can be compared to a context switching operation taking place inside the operating system. A compiler has to perform a lot of actions when a function is invoked. It needs to save the registers, push the program counter onto the stack, and execute actions that are defined within the invoked function. Once the actions defined inside the function are complete, the values saved inside the stack are popped, and the control returns to the point from where the function got invoked.

# Defining a Function

Normally a function definition consists of two components—the argument declaration and the body of the function. The first line of the function definition contains the type specification of the value returned by the function, followed by the function name and a list of arguments separated by commas and enclosed within parentheses. This list of arguments is not a mandatory part of a function, which may or may not take arguments as its parameters. Let's take a look at two such instances.

The following code snippet shows a typical function definition that does not take any arguments:

```
~~~c
int myFunction()
~~~
```

Whereas a function definition taking arguments as input is shown as follows:

```
~~~c
int myFunction(int arg1, int arg2, float arg3)
~~~
```

The function definition shown in the preceding code snippet takes three arguments as its parameter, where the first two are integers and the last one is a floating point. Generally, a function definition would look like as follows:

```
~~~
data-type name(type 1 arg1, type 2 arg 2, ....., type n arg n)
~~~
```

In the preceding code snippet, the data-type represents the type of value that is returned by the function, name is the name of the function, and type 1 to type n are the data types of the arguments of the function. The arguments are also known as formal arguments as they represent the names of data items that are transferred to the function from the calling part of the program. Sometimes, these are also referred to as formal parameters. The parameters that are actually passed from the calling program are called the actual arguments or actual parameters. The formal parameters are defined to be local variables and they do not have any existence outside the function. Each formal argument must have a data type attached with it and the data must be aligned with the one that gets passed from the calling program. The remaining part of the function, which is enclosed within parenthesis, is called the body of the function. The body also defines the actions that a function is going to execute. Listing 2.2 shows an example of a function definition:

**Listing 2.2: Defining a Basic Function**

```
~~~c
unsigned int factorial(int value)
{
    unsigned int fact = 1;
    int i;

    for(i=1; i <= value; i++)
    {
        fact = fact * i;
    }

    return fact;
}
~~~
```
