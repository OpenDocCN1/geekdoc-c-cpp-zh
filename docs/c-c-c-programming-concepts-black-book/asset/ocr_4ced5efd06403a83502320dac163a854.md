# ### Open Addressing

In the open addressing technique, the hash collision is resolved by probing. Probing is the process of searching through the alternate location of the hash table until the target location or an empty space in the array is found. This searching sequence is called probing sequence. Depending on the probing sequence, different techniques of open addressing are developed, which are given as follows:

+   - Linear probing
+   - Double hashing

Let’s learn about these techniques.

# ### Linear Probing

The simplest open addressing technique is linear probing, where the probing sequence is 1. Therefore, if the position in the array is already occupied, where a new key needs to be placed, then using the probing sequence, it searches the next empty slot in the array. If such empty slot is found, then the key is placed into that slot.
