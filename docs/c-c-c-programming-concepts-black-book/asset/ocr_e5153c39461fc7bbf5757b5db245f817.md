One more interesting thing to know about inline functions is that the keyword inline is a request to the compiler to make the function an inline one. The inline keyword does not necessarily guarantee that the compiler will treat a function as an inline function. It is up to the compiler to process the request and treat the function as an inline function or to ignore the request and treat the function similar to any other normal function. For example, the compiler can keep the function size as a parameter while deciding whether to accept an inline function request or not. In addition, the inline expansion may not work in the following situations:

+   - If inline functions are recursive
+   - If inline functions contain static variables
+   - If a loop, switch, or goto statement exists for functions returning values

As inline expansion eliminates the overhead of function calls, it makes a program executes faster; however, it takes up more memory as every call to an inline function is actually expanded into the function block itself. Let's now learn about recursive functions.

# # Recursive Functions

Recursion means solving a bigger problem in terms of solving smaller instances of the similar problem, which in turn solves the bigger problem. This is a very powerful tool, which helps in solving some particular class of problems in an easier way. For example, calculating the factorial of a number, where the entire problem can be broken down into number of sub-problems, and the solution to one level can only be done once all the levels below it are solved. In other words, to calculate the factorial of a number, say 5, we need to know the factorial of 4 and multiply it with 5 to get the result. However, to evaluate the factorial of 4, we first need to calculate the factorial of 3. This concept, when used in languages, is implemented as a recursive function, which calls itself more than once depending on some terminating or base conditions. The idea behind calling the same function from within the function is to get the solutions of smaller problems and use them in determining the solution of the given problem. However, not all the problems can be solved using recursive functions. A problem first needs to qualify as recursive in nature to be solved by recursive approach. Some popular recursive problems are factorial of a number, Fibonacci series, Greatest Common Divisor (GCD), and Binary search.
