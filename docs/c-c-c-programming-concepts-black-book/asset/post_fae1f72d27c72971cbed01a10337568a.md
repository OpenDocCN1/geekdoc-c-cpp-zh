
Let’s assume that we have stored nine elements sequentially in a two-dimensional array, which is as follows:

The expression can be generalized as follows:


## Returning a Two-Dimensional Array from a Function

We can return a two-dimensional array from a function in multiple ways. However, in this chapter, we will learn about the following three ways of returning a two-dimensional array from a function:

```c

int (*display_C())[3][3];
```

In the preceding code snippet, we can observe that all the three functions are returning a two-dimensional array. Note that all the three functions would return the base address of the two-dimensional array. Let’s explore the three functions more clearly with the help of a program.

Let’s now discuss three-dimensional arrays.

## Three-Dimensional Arrays using Pointers

A three-dimensional array can be explained as an array of two-dimensional arrays. The definition of a three-dimensional array is somewhat recursive in nature. If we have a declaration, such as int arr[3][3][3], then it implies that we have an array of three two-dimensional arrays where each two-dimensional array is again a collection of three single dimensional arrays. First, a single dimensional array of three elements is created. Then, three single dimensional arrays are placed one below the other to give the two-dimensional array. Further, three two-dimensional arrays are placed one behind the other to give three-dimensional representation of array.

Pictorially, a three-dimensional array would be as follows:

### First Two-dimensional Array

| 1 | 100 | 1000 |
|---|---:|---:|
| 2 | 200 | 2000 |
| 3 | 300 | 3000 |

### Second Two-dimensional Array

| 4 | 400 | 4000 |
|---|---:|---:|
| 5 | 500 | 5000 |
| 6 | 600 | 6000 |

### Third Two-dimensional Array

| 7 | 700 | 7000 |
|---|---:|---:|
| 8 | 800 | 8000 |
| 9 | 900 | 9000 |

In memory, the elements will be stored in a contiguous manner. Consider a three-dimensional array `arr[2][2][2]`, which is declared as follows:

```c
int arr[2][2][2] = {
    {
        {1,2},
        {3,4}
    },
    {
        {5,6},
        {7,8}
    }
};
```

The memory map for the preceding declaration would be as follows:

![](img/43c5f409f9b17790a628c4b4df854b61_148_0.png)

We can observe in the memory map that the elements 1, 2, 3, and 4 form the first two-dimensional array. Each element of this two-dimensional array is placed in memory in row major order. As we have declared the three-dimensional array of type int in the preceding example, therefore each element would take four bytes of memory. The address of first two-dimensional array ranges from 8000 to 8016. Similarly, the second two-dimensional array is placed in a row major order and ranges from 8016 to 8032.
