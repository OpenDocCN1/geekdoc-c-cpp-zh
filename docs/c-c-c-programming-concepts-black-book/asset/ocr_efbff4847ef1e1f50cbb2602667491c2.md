# # Reference Type

In C and C++, when a pointer variable is assigned to another pointer variable, its reference is changed while its value remains the same. Similarly, in C#, reference type represents an object of a class, an interface, a delegate, or an array that holds the reference. Therefore, when a reference type is assigned to another reference type, only its reference is copied and not the value. Listing 17.31 shows the usage of reference type in C#:
