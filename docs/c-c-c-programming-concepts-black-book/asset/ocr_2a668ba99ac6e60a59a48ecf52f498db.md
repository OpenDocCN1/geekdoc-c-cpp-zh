The preceding code can be rearranged using an else-if construct as:

```
if(expression)
{
    statements;
}
else if(expression)
    statement;
```

# ## The Conditional Operators

Another set of relevant operators required for decision making are ? and :.These operators are often referred to as ternary operators, as they take up three arguments. Combined together, they form a reduced version of an if-else statement.

```
expression ? statement 1 : statement2
```

The expression shown above means that if an expression is true, then statement 1 will execute, else statement 2 will execute. Listing 1.18 shows how to write conditional operators in C:

**Listing 1.18: Writing Conditional Operators in C**

```
# include<stdio.h>

int main()
{
    int varA=10;

    (varA < 5 ? printf("\n Less than 5"):printf("\n Greater than 5"));

    getch();
}
```

The output of Listing 1.18 is given as follows:

```
Greater than 5
```

Listing 1.19 shows the use of conditional operators in C:

**Listing 1.19: Conditional Operators in C**

```
# include<stdio.h>

int main()
{
    int gender,age;

    printf("\n Enter your Gender (1. MALE/ 2. FEMALE)");
    scanf("%d",&gender);
    printf("\n Enter age ");
    scanf("%d",&age);

    ((gender == 1) ?
        ((age > 18) ? printf("\n Qualified"):printf("\n Disqualified"))
        :
        ((age > 24) ? printf("\n Qualified"):printf("\n Disqualified"))
    );
    getch();
}
```

One of major shortcomings of using conditional operators is that we can only have a single statement inside a true and false block of a conditional statement. So, this construct is not frequently used.
