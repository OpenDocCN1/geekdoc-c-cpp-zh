Listing 17.36: Showing the Usage of `switch` Statement

```
```csharp
using System;
class program
{
    public static void Main()
    {
        Example e = new Example();
        e.SelectDVD();
    }
}
class Example
{
    public int option;
    public const int price = 99;
    public Example()
    {
    }
    public void SelectDVD()
    {
        Console.WriteLine("How many DVD you want to select");
        option = Convert.ToInt32(Console.ReadLine());
        int dvdprice = 0;
        switch (option)
        {
            case 1:
                Console.WriteLine("The price of {0} DVDs is", option);
                dvdprice = price * 1;
                break;
            case 2:
                Console.WriteLine("The price of {0} DVDs is", option);
                dvdprice = price * 2;
                break;
            case 3:
                Console.WriteLine("The price of {0} DVDs is", option);
                dvdprice = price * 3;
                break;
            default:
                Console.WriteLine("The DVD you can get at a time is 3");
                break;
        }
        Console.WriteLine(dvdprice);
    }
}
```
```

The preceding program shows the price of the selected DVDs. However, the program does not allow us to purchase more than three DVDs at a time. When we run the program, it will prompt a user to enter a number. If the user enters 1, 2, or 3, it will show the amount that need to be paid to get the DVDs. However, if the user enters any number other than 1, 2, or 3, then it will execute the default case of the switch statement.
