
The first category of standard query operators operates on the objects that implement the `IEnumerable<T>` interface. These types of operators are defined as extension methods on the static `Enumerable` class, which extends the `IEnumerable<T>` interface. They are specifically used while working with LINQ to Object. The second category of standard query operators operates on the objects that implement the `IQueryable<T>` interface. They are also defined as extension methods of the static `Queryable` class, which extends the `IQueryable<T>` interface. If we want to work with LINQ to SQL, LINQ to DataSet, and LINQ to XML, then we need to implement both the categories of operators.

Following are the standard query operators:

- Filtering
- Projecting
- Joining
- Ordering
- Grouping
- Set
- Conversion
- Partitioning
- Equality
- Element
- Aggregation
- Quantifiers

Let's begin the discussion with filtering operators.

## Filtering Operators

Filtering operators filter the elements from a collection by applying a given condition. In SQL, this can be achieved by using the WHERE clause; however, C# provides a similar keyword to carry out this operation. The **where** keyword can be used with any generic collection or strongly typed collection. Listing 19.22 shows an example of using the Where operator.

### Listing 19.22: Showing an Example of Filter Operation using the Where Operator

```csharp
using System;
using System.Linq;
using System.Collections.Generic;
class Employee
{
    public static void Main()
    {
        string[] Employee = { "Johns", "Thomas", "Tim", "Jenny", "Tina" };

        IEnumerable<string> empCount = from eCount in Employee
                                       where eCount == "Tim"
                                       select eCount;

        if (empCount != null)
        {
            Console.WriteLine("The Employee named Tim is present in the collection.");
        }
    }
}
```

In Listing 19.22, we are querying the **Employee** array of string to find whether an employee Tim is present in the collection. The output of the program is given as follows:

```text
The Employee named Tim is present in the collection.
```

In Listing 19.22, notice that the query is stored in an object of the `IEnumerable<string>` interface. However, instead of using the `IEnumerable<string>`, we can also use the anonymous type `var` to store the query.

While using a non-generic collection type, such as ArrayList, Stack, or Queue, we need to use the `OfType` operator along with the `Where` operator to retrieve the result. For example, if an ArrayList contains the string values along with the integer values, then while querying the data, we need to specify the type of the element that we want to use. Listing 19.23 shows an example of using a non-generic collection type where the `OfType` operator is used to specify the exact type of the elements to be queried:

### Listing 19.23: Showing the Implementation of the OfType Operator

```csharp
using System;
using System.Linq;
using System.Collections;
using System.Collections.Generic;

class Employee
{
    public static void Main()
    {
        ArrayList empList = new ArrayList();
        empList.Add("Johns");
        empList.Add(1);
        empList.Add("Tim");
        empList.Add('E');
        empList.Add("Tina");

        //Using the operator OfType
        var empCount = from eCount in empList.OfType<string>()
                       where eCount == "Tim"
                       select eCount;

        if (empCount != null)
        {
            Console.WriteLine("The Employee named Tim is present in the collection.");
        }
    }
}
```

In the preceding program, the *empList* ArrayList contains the elements of a string type, an integer type, and a character type. While querying, we are specifying the string type, as the **where** condition will search for the string type element. If someone changes the type to int, then the program will throw an error at compile time. In the program, the LINQ query is stored in the anonymous type that frees a developer to remember which type of result will be assigned. The output of the program is the same as that of Listing 19.22.

## Projecting Operators

Projection operators are used to select the type of the values that will be generated once the query is executed. Standard query operators provide two types of projecting operators:

- Select
- SelectMany

C# provides a way to implement the Select operator using the select keyword. The output that it generates is of type `IEnumerable<T>`. Listing 19.24 shows the procedure to use the Select operator that returns a single element of the object of Employee class:

### Listing 19.24: Showing the Implementation of the Select Operator

```csharp
using System;
using System.Linq;
using System.Collections;
using System.Collections.Generic;

class Program
{
    public static void Main()
    {
        List<Employee> empList = new List<Employee>();
        empList.Add(new Employee(100, "James", "Team Member"));
        empList.Add(new Employee(200, "Jonathan", "Senior Manager"));
        empList.Add(new Employee(300, "Keith", "Team Member"));
        empList.Add(new Employee(400, "Jonny", "Manager"));
        empList.Add(new Employee(500, "Amy", "Senior Manager"));
        empList.Add(new Employee(600, "Leonardo", "Team Member"));

        IEnumerable<Employee> empSel = from emp in empList
                                       where emp.designation.Equals("Team Member")
                                       orderby emp.empName
                                       select emp;

        foreach (Employee e in empSel)
        {
            Console.WriteLine("Employee ID: {0} Employee Name: {1}", e.empID,
                e.empName);
        }
    }
}

class Employee
{
    public int empID;
    public string empName;
    public string designation;

    public Employee()
    {
    }

    public Employee(int id, string name, string desg)
    {
        this.empID = id;
        this.empName = name;
        this.designation = desg;
    }
}
```

In Listing 19.24, we have first defined the **Employee** class and then referred it in the Main() method. In the Main() method, a List object is defined that holds a set of objects of the **Employee** class. After that, we have written a query to get the result from the employee list whose designation is set to Team Member. At the end, we have printed only the IDs and names of the employees. The output of the program is given as follows:

```text
Employee ID: 100 Employee Name: James
Employee ID: 300 Employee Name: Keith
Employee ID: 600 Employee Name: Leonardo
```

The **SelectMany** operator is used for a collection, which in turn holds another collection. For example, if we define a List type variable that contains an object of the Employee class, which has three different types of members, then we can use the **SelectMany** operator. In this situation, we need to frame the LINQ query in different ways using the **select** keyword to get only the ID and the name of an employee. In this case, the result type of the query will be anonymous. Listing 19.25 shows the implementation of the SelectMany operator using the select keyword:

### Listing 19.25: Showing the Implementation of the SelectMany Operator

```csharp
using System;
using System.Linq;
using System.Collections;
using System.Collections.Generic;

class Program
{
    public static void Main()
    {
        List<Employee> empList = new List<Employee>();
        empList.Add(new Employee(100, "James", "Team Member"));
        empList.Add(new Employee(200, "Jonathan", "Senior Manager"));
        empList.Add(new Employee(300, "Keith", "Team Member"));
        empList.Add(new Employee(400, "Jonny", "Manager"));
        empList.Add(new Employee(500, "Amy", "Senior Manager"));
        empList.Add(new Employee(600, "Leonardo", "Team Member"));


        var empSel = from emp in empList
                     where emp.designation.Equals("Team Member")
                     orderby emp.empName
                     select new { id = emp.empID, name = emp.empName };

        foreach (var e in empSel)
        {
            Console.WriteLine("Employee ID: {0} Employee Name: {1}", e.id, e.name);
        }
    }
}

class Employee
{
    public int empID;
    public string empName;
    public string designation;

    public Employee()
    {
    }
}
```
