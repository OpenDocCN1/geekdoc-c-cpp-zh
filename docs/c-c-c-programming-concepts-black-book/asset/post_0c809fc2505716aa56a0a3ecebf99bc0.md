## Stack

A stack can be defined as a linear data structure, where items are added one at a time and can only be removed in the reverse order in which they were entered. The last item added to the stack is called the *top* of the stack. Suppose we enter A, B, C and D in a stack, then D is the *top* and these items can be removed in the order D, C, B and A; therefore, a stack follows a LIFO strategy. The common operations done with a stack are adding an element into the stack and deleting an element from the stack. Adding an element in a stack is called *push*. Listing 24.5 shows the code to implement the *push* operation:

### Listing 24.5: Implementing the Push Operation

```text
procedure add(item : items)
{add item to the global stack;
top is the current top of stack
and n is its maximum size}
begin
    if top = n then stackfull;
    top := top + 1;
    stack(top) := item;
end; {of add}
```

Deleting an item from a stack is done by deleting the last element entered in the stack first. This operation is called *pop*. Listing 24.6 shows the implementation of the *pop* operation:

### Listing 24.6: Implementing the Pop Operation

```text
procedure delete(var item : items)
{remove top element from the stack and put it in the item}
begin
    if top = 0 then stackempty;
    item := stack(top);
    top := top - 1;
end; {of delete}
```

## Queues

Queue in English describes a waiting line; in computers, we have similar concept as well. A queue is defined as a linear data structure, where insertion is made at one end and deletion is made at the other end. The information present in the list is processed in the same order as it was received. This method is also known as the FIFO mechanism. Information that came into queue first will be the first one to be processed as well.

Queues are usually represented by the means of linked lists or linear arrays. A queue has two pointers: FRONT and REAR. The FRONT pointer points to the element at the front of a queue; whereas, the REAR pointer points to the elements at the rear of a queue. In addition, the FRONT pointer is used to delete the elements from a queue and the REAR pointer is used to insert the elements in a queue. The condition FRONT = REAR at any point symbolizes an empty queue. At the beginning of any operation, both FRONT and REAR points to zero. Whenever an element is inserted into a queue, FRONT is incremented by one. Similarly, when an element is deleted from a queue, REAR is incremented by one. Figure 24.6 shows a queue:

![](img/43c5f409f9b17790a628c4b4df854b61_842_0.png)

**Figure 24.6: Showing a Queue**

During insertion, if the REAR pointer reaches the end of a queue, then no more insertions can take place in the queue. This situation is called Queue Overflow. Similarly, during deletion, if no more elements are left to delete and the queue becomes empty, then the situation is called Queue Underflow.

Listing 24.9 shows the algorithm for insertion operation:

### Listing 24.9: Showing the Algorithm for Insertion

```text
function QueueInsert(queue[maxsize], front, rear, item)
begin
  if rear >= maxsize
    then
      output "Queue Overflow"
  end if

  rear = rear + 1
  queue[rear] = item

  if front = 0
    then
      front = 1
  end if
end
```

In Listing 24.9, first we have checked the overflow condition in a queue. If the condition satisfies, then we will declare the queue to be full; else, the rear pointer is incremented by one and the element is inserted at the current rear position of the queue.

Listing 24.10 shows the algorithm for deletion operation:

### Listing 24.10: Showing the Algorithm for Deletion

```text
function QueueDelete(queue[maxsize], front, rear, item)
begin
  if front = 0
    then
      output "Queue Underflow"
      Return
  end if

  item = queue[front]

  if front = rear
    then
      front = 0
      rear = 0
  else
    front = front + 1
  end if
  Return item
end
```

In Listing 24.10, first we have checked the underflow condition in a queue. If no elements are present in the queue, then the queue is regarded as empty. If elements are present in the queue, then the elements are removed from the queue by incrementing the front pointer by one. If the front and rear pointers become equal, then this indicates that both the pointers should be again put back to zero.
