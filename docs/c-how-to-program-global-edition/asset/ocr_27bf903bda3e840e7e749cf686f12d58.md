# Sorting: A Deeper Look

# Objectives

In this appendix, you'll:

+   - Sort an array using the selection sort algorithm.
+   - Sort an array using the insertion sort algorithm.
+   - Sort an array using the recursive merge sort algorithm.
+   - Learn about the efficiency of searching and sorting algorithms and express it in 'Big O' notation.
+   - Explore (in the exercises) additional recursive sorts, including quicksort and a recursive selection sort.
+   - Explore (in the exercises) the high performance bucket sort.
