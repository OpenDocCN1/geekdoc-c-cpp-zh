## 18.8 (Complex Class)

Consider class Complex shown in Figs. 18.14–18.16. The class enables operations on so-called complex numbers. These are numbers of the form realPart + imaginaryPart * i, where i has the value √-1

- a) Modify the class to enable input and output of complex numbers via overloaded >> and << operators, respectively (you should remove the print function from the class).
- b) Overload the multiplication operator to enable multiplication of two complex numbers as in algebra.
- c) Overload the == and != operators to allow comparisons of complex numbers.

After doing this exercise, you might want to read about the Standard Library's complex class (from header <complex>).

```
// Fig. 18.14: Complex.h
// Complex class definition.
#ifndef COMPLEX_H
#define COMPLEX_H

class Complex
{
public:
    explicit Complex( double = 0.0, double = 0.0 ); // constructor
    Complex operator+( const Complex & ) const; // addition
    Complex operator-( const Complex & ) const; // subtraction
    void print( ostream & ) // output
private:

    double imaginary; // imaginary part
}; // end class Complex

#endif
```

Complex Complex::operator+( const Complex &operand2 ) const
{
    return Complex( real + operand2.real,
                     imaginary + operand2.imaginary );
} // end function operator+

// subtraction operator
Complex Complex::operator-( const Complex &operand2 ) const
{
    return Complex( real - operand2.real,
                     imaginary - operand2.imaginary );
} // end function operator-

// display a Complex object in the form: (a, b)
void Complex::print() const
{
    cout << '(' << real << ", " << imaginary << ')';
} // end function print

## 18.9 (HugeInt Class)

A machine with 32-bit integers can represent integers in the range of approximately –2 billion to +2 billion. This fixed-size restriction is rarely troublesome, but there are applications in which we would like to be able to use a much wider range of integers. This is what C++ was built to do, namely, create powerful new data types. Consider class HugeInt of Figs. 18.17–18.19. Study the class carefully, then answer the following:

- a) Describe precisely how it operates.
- b) What restrictions does the class have?
- c) Overload the * multiplication operator.
- d) Overload the / division operator.
- e) Overload all the relational and equality operators.
