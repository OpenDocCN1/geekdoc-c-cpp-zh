# 12.6.2 Function dequeue

Function dequeue (lines 102–115; illustrated in Fig. 12.16) receives the address of the pointer to the head of the queue and the address of the pointer to the tail of the queue as arguments and removes the first node from the queue. The dequeue operation consists of six steps:

+   1. Assign (*headPtr)->data to value to save the data (line 104).
+   2. Assign *headPtr to tempPtr (line 105), which will be used to free the unneeded memory.
