## 5.27 (Roots of a Quadratic Equation)
A quadratic equation is any equation of the form ax² + bx + c = 0 where a, b, and c are the coefficients of x. The roots of a quadratic equation can be calculated by the formula x = -b ± √(b² - 4ac) / 2a. If the expression, b² - 4ac, which is also called the discriminant, is positive then the equation has real roots. If the discriminant is negative, the equation has imaginary (or complex) roots. Write a function that accepts the coefficients of an equation as parameters, checks if the roots are real, and calculates the roots of the equation. Write a program to test this function.
