# 8.9.2 Function memmove

Function memmove, like memcpy, copies a specified number of bytes from the object pointed to by its second argument into the object pointed to by its first argument. Copying is performed as if the bytes were copied from the second argument into a temporary array, then copied from the temporary array into the first argument. This allows bytes from one part of a string to be copied into another part of the same string, even if the two portions overlap. Figure 8.29 uses memmove to copy the last 10 bytes of array x into the first 10 bytes of array x.
