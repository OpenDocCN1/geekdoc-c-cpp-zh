# Fig. 5.19 | Recursive fibonacci function. (Part 2 of 2.)

The call to fibonacci from main is not a recursive call (line 16), but all subsequent calls to fibonacci are recursive (line 30). Each time fibonacci is invoked, it immediately tests for the base case—n is equal to 0 or 1. If this is true, n is returned. Interestingly, if n is greater than 1, the recursion step generates two recursive calls, each a slightly simpler problem than the original call to fibonacci.
