+   1. [REOPERATION] From this rule we know that e' = e'_1 \circ e_2 and

Applying eqs. (B.17a) and (B.17c) to the inductive hypothesis results in \emptyset \vdash \text{exp } e'_1 : \text{number}. Using this information, along with eq. (B.17b) in [TARITHMETIC], results in \emptyset \vdash \text{exp } e' : \text{number}, as required.

+   2. [REOPERATION2] Analogous to [REOPERATION].

+   3. [REOPERATION3] From the rule, we know that e = v_1 \circ v_2. Since we know that \emptyset \vdash \text{exp } e : T, or \emptyset \vdash \text{exp } v_1 \circ v_2 : T, then \emptyset \vdash \text{exp } e' : T follows immediately given that e' = v = v_1 \circ v_2.

Regarding the remaining cases: Cases [TBASIC], [TVARIABLE] and [TLIST] hold trivially, since e \to e' does not apply. Cases [TCOMPARISON] and [TBOOLEAN] are analogous to [TARITHMETIC]. Cases [TLIST] and [TNOT] take a similar approach to [TTUPLE].
