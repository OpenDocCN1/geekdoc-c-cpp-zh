
where \(\Delta' : \emptyset \vdash S'' \triangleright t' : T \triangleleft S'\) is the expected result.

- [RLET] From the rule, we know that \(t = (x = v; t_2)\), \(t' = t_2 \{v/x\}\) and \(\alpha = \tau\), therefore \(\text{after}(S, \alpha) = S = S''\). Since \(t_1 = v\), by eq. (B.16b) and [RExpression], then \(\emptyset \triangleright \text{exp} : T\) holds. If we apply this latter information and eq. (B.18c) to the Substitution Lemma, we obtain \(\Delta \cdot \emptyset \vdash^w S'' \triangleright t_2 \{v/x\} : T \triangleleft S'\). This is the expected result, since by the Variable Substitution Definition, \(\text{w}[\Delta'] = \text{w}\); and by the **after** definition, \(\Delta' = \Delta\).

### [TBRANCH] From the rule, we know that for some \(n \in \mathbb{N}\) then

\(S = \& \{ ?i_1 (T_1^1, \dots, T_i^n), S_i \}_{i \in I}\) (B.19a)
\(t = \text{receive} \ \text{do} \ \{ [\langle 1_i, p_i^1, \dots, p_i^n \rangle \rightarrow t_i \}_{i \in I} \text{end}\) (B.19b)
\(S_\mu = \text{after}(\& \{ ?i_1 (T_1^1, \dots), S_i \}_{i \in I}, \alpha)\) (B.19c)

Since \(\alpha\) has to be an incoming message, we focus solely on the first case of the Session Fidelity Theorem. From the premise, we also know that some properties regarding each individual branch from the receive construct:

\(\forall i \in I . \begin{cases} \vdash^{\text{par}} p_i^j : T_i^j \triangleright \Gamma_i^j \text{ for all } j \in 1..n \\ \Delta \cdot (\Gamma_i^1, \dots, \Gamma_i^n) \vdash^w S_i \triangleright t_i : T \triangleleft S' \end{cases}\) (B.19d) (B.19e)

From the structure of \(t\) (eq. (B.19b)), term reduction (\(t \xrightarrow{\alpha} t'\)) can only be derived using [RBRANCH], where execution progresses to a single branch (i.e., \(t_\mu\)), rather than all branches. The right branch is chosen by matching its label, \(1_\mu\), to the label received in the incoming message, \(1_\mu\). Thus, for some \(k \in \mathbb{N}\), there exists some \(\mu \in I\) where \(1_\mu = 1_\mu\), and

\(\alpha = ? \{ \langle 1_\mu, \nu_1, \dots, \nu_n \rangle \}\) (B.19f)
\(\text{match}((p_\mu^1, \dots, p_\mu^n), (\nu_1, \dots, \nu_n)) = [\nu_1^{i_1} \dots \nu_n^{i_n} / x_{i_1} \dots x_{i_n}]\) (B.19g)
\(t' = t_\mu [\nu_1^{i_1} \dots \nu_n^{i_n} / x]\)

From eq. (B.19f), \(\alpha\) refers to the message received from the dual process, which is assumed (from the premise of the theorem) to be valid by the after function (eq. (B.19c)). We can compare the contents of this message to the original session type \(S\) (eq. (B.19a)), to obtain information regarding the types of the individual values inside \(\alpha\). We know that \(\alpha\) contains a label \(1_\mu\) and \(n\) values. Thus for \(j \in 1..n\), each value \(\nu_j\) has a corresponding type \(T_\mu^j\) from the session type \(S\), where \(S\) contains ?\(1_\mu (T_\mu^1, \dots, T_\mu^n). S_\mu\). Formally, this can be written as

\(\emptyset \triangleright \text{exp}_j \nu_j : T_\mu^j \text{ for all } j \in 1..n\) (B.19h)

Applying eqs. (B.20), (B.19g) and (B.19h) into Corollary 14, results in \(\widetilde{\Gamma}_\mu^j = \Gamma_\mu^1, \dots, \Gamma_\mu^n = x_1 : T_1, \dots, x_k : T_k\) and

\(\emptyset \triangleright \text{exp}_j^w : T_m \text{ for } m \in 1..k\) (B.19i)

Applying eq. (B.19i) and \(\Delta \cdot \widetilde{\Gamma}_\mu^j \vdash^w S_\mu \triangleright t_\mu : T \triangleleft S'\) (from eq. (B.19e) for \(i = \mu\)) repeatedly to the Substitution Lemma, we get

\(\Delta \cdot \emptyset \vdash^w S_\mu [\nu_1^{i_1} \dots \nu_n^{i_n} / x_{i_1} \dots x_{i_n}] : T \triangleleft S'\) (B.19j)

Since \(\text{after}(\alpha, S) = \Delta\), then eq. (B.19j) is the expected result.

### [TCHOICE] From the rule, we know that for some \(\mu \in I\), \(T = (\text{atom}, T_\mu^1, \dots, T_\mu^n)\) and

\(S = \oplus \{ \langle 1_i, (T_i^1) \rangle S_i \}_{i \in I}\) (B.20a)
\(t = \text{send} \ \langle \langle 1_\mu, e_1, \dots, e_n \rangle \rangle\) (B.20b)
\(\emptyset \triangleright \text{exp} \ e_j : T_\mu^j \text{ for all } j \in 1..n\) (B.20c)

From the structure of \(t\) (eq. (B.20b)), term reduction (\(t \xrightarrow{\alpha} t'\)) can be derived by several rules, so we have to consider two sub-cases:

- 1. Derived by the rule [RCHOICE1], we know that \(\alpha = \tau\) and

\(t' = \text{send} \ \langle \langle 1, \nu_1, \dots, v_{k-1}, e_k^i, \dots, e_n \rangle \rangle\)
\(e_k \rightarrow e_k^i\) (B.20d)

Applying eq. (B.20c) (for \(j=k\)) and eq. (B.20d) to the Preservation (Expressions) Lemma, we get \(\emptyset \vdash_{\text{exp}} e'_j : T_k\). Applying this and eq. (B.20c) to [rChoice] results in \(\Delta \cdot \emptyset \vdash^w S \triangleright t' : T \triangleleft S_\mu\). Since \(\text{after}(S, \tau) = S\) and \(\text{after}(\Delta, \alpha, S) = \Delta\), this holds.

- 2. [RCHOICE2] From this rule we know that

\(t' = \langle !_\mu, v_1, ..., v_n \rangle \quad \alpha = \langle !_\mu, v_1, ..., v_n \rangle\)

where \(\alpha\) (eq. (B.20e)) is the message being sent to the dual process with pid t - so, we only consider the second case of the Session Fidelity Theorem.

Recall eq. (B.20c), where we have \(\emptyset \vdash_{\text{exp}} e_j : T^j_\mu\) for \(j \in 1..n\). Notice that the types \(T^j_\mu\) were obtained from the session type \(S\) (eq. (B.20a)), where \(S\) contains \(!_\mu \langle T^1_\mu, ..., T^n_\mu \rangle . S_\mu\). Now, by the premise of [rChoice2], since \(e_j = v_j\), then

\(\emptyset \vdash_{\text{exp}} v_j : T^j_\mu \text{ for all } j \in 1..n\)

By the Value Typing Lemma, we also know that \(\emptyset \vdash_{\text{exp}} !_\mu : \text{atom}\). Using this latter information and eq. (B.20f) in [tTuple] and [tExpression], we get the required result:

[TTUPLE] \(\frac{\emptyset \vdash_{\text{exp}} !_\mu : \text{atom} \quad \forall j \in 1..n. \quad \emptyset \vdash_{\text{exp}} v_j : T^j_\mu}{\emptyset \vdash_{\text{exp}} \langle !_\mu, v_1, ..., v_n \rangle : \langle \text{atom}, T^1_\mu, ..., T^n_\mu \rangle}\)
[TEXPRESSION] \(\frac{\Delta \cdot \emptyset \vdash^w S \triangleright \langle !_\mu, v_1, ..., v_n \rangle : T \triangleleft S_\mu}{\emptyset \vdash_{\text{exp}} \langle !_\mu, v_1, ..., v_n \rangle : T \triangleleft S_\mu}\)

Result from eq. (B.20g) holds as required, since \(\text{after}(S, \alpha) = S_\mu\) and \(\text{after}(\Delta, \alpha, S) = \Delta\).

### [TKNOWN CALL] From the rule, we know that
\(t = f(w, e_2, ..., e_n) \quad \emptyset \vdash_{\text{exp}} e_i : T_i \text{ for all } i \in 2..n\)

From the structure of t (eq. (B.21a)), term transitions (\(t \xrightarrow{\alpha} t'\)) can be derived using two rules, so we consider two sub-cases:

- 1. [RCALL1] From this rule, we know that \(t = f(v_1, ..., v_{k-1}, e_k, ..., e_n), \alpha = \tau, w = v_1\) and

\(t' = f(v_1, ..., v_{k-1}, e'_k, ..., e_n) \quad e_k \xrightarrow{\tau} e'_k\)

Applying eq. (B.21b) (for \(i=k\)) and eq. (B.21c) to the Preservation (Expressions) Lemma, we get
\(\emptyset \vdash_{\text{exp}} e'_k : T_k\)

By eqs. (B.21b) and (B.21d) and [rKnownCall], we get
\(\Delta \cdot \emptyset \vdash^w S \triangleright f(v_1, ..., v_{k-1}, e'_k, ..., e_n) : T \triangleleft S'\)

eq. (B.21e) holds since \(v_1 = w\).

- 2. [RCALL2] From the rule, we know that \(\alpha = f/n, w = t\) and

\(t = f(t, v_2, ..., v_n) \quad t' = t[|t|/\langle v_2, ..., v_n / \alpha_n \rangle]\)

\(\Sigma(f/n) = \Omega \text{ where } \left\{ \begin{array}{l} \Omega.\text{return\_type} = T \\ \Omega.\text{param\_types} = T_2, ..., T_n \end{array} \right.\)
\(\Delta(f/n) = S\)

Since all known functions (i.e., \(f/n \in \text{dom}(\Delta)\)) by eq. (B.21h) are already typechecked once before, then from the function information environment (i.e., \(\Sigma\)) and eq. (B.21g), we can assume that
\(\Delta \cdot \Gamma' \vdash^w S \triangleright T : T \triangleleft \text{end}\)

where \(\Gamma'\) contains only the mapping from the parameter names to their types, i.e., \(\Gamma' = (y : \text{pid}, x_2 : T_2, ..., x_n : T_n)\) - our aim is to change \(\Gamma'\) to \(\Psi\). This assumption in eq. (B.21i) is possible since a well-formed \(\Sigma\) dictates that the only free variables in a function body are the parameter types, or formally, for all \(fh \in \mathbf{dom}(\Sigma)\), we have

\(\mathbf{fv}(\Sigma(fh).\text{body}) \setminus (\Sigma(fh).\text{params} \cup (\Sigma(fh).\text{dual})) = \emptyset\)

By eq. (B.21f) and Value Typing Lemma we know that \(\theta \vdash_{\text{exp}} t : \text{pid}\). Applying this information and eq. (B.21i) to the Substitution Lemma results in

\(\Delta \cdot (x_2 : T_2, ..., x_n : T_n) \vdash^w S \triangleright T [f/x] : T \triangleleft \text{end}\) (B.21j)

where by the Variable Substitution Definition, \(y [f/x] = t = w\).

Applying the Substitution Lemma multiple times to eqs. (B.22b) and (B.21j), results in

\(\Delta \cdot \emptyset \vdash^w S \triangleright T [f/x] [v_1, ..., v_n / x_1, ..., x_n] : T \triangleleft \text{end}\) (B.21k)

as required, since \(\text{after}(S, fh) = S\) and \(S' = \text{end}\). Also, \(\text{after}(\Delta, fh, S) = (\Delta, fh : S)\), but from eq. (B.21h), \(fh\) is already mapped to \(S\) in the session typing environment, therefore \((\Delta, fh : S) = \Delta\), as needed.

### [TUNKNOWNCALL] From the rule, we know

\(t = f (w, e_2, ..., e_n)\) (B.22a)

\(\theta \vdash_{\text{exp}} e_i : T_i \text{ for all } i \in 2..n\) (B.22b)

From the premise we also know that

\((\Delta, fh : S) \cdot (y : \text{pid}, \tilde{x} : \tilde{T}) \vdash^w S \triangleright \tilde{T} : T \triangleleft S'\) where \(\tilde{x}, \tilde{T}, \tilde{T}, T\) and \(y\) are obtained from the function information environment (i.e., \(\Sigma\)) (B.22c)

From the structure of \(t\) (eq. (B.22a)), term transitions (\(t \xrightarrow{\alpha} t'\)) can be derived using two rules, so we consider two sub-cases:

- 1. [RCALL1] From this rule we know that \(\alpha = \tau\), and

\(t' = f (v_1, ..., v_{k-1}, e_k', ..., e_n)\) \(e_k \rightarrow e_k'\) (B.22d)

Applying eq. (B.22b) (for \(i = j\)) and eq. (B.22d) to the Preservation (Expressions) Lemma, we get

\(\theta \vdash_{\text{exp}} e_j' : T_j\) (B.22e)

Using eq. (B.22b) and eq. (B.22e) in the rule [TUNKNOWNCALL], results in

\(\Delta \cdot \emptyset \vdash^w S \triangleright f (v_1, ..., v_{k-1}, e_k', ..., e_n) : T \triangleleft S'\)

This holds since \(\text{after}(S, \tau) = S\) and \(\text{after}(\Delta, \tau, S) = \Delta\).

- 2. [RCALL2] From the rule, we know that \(\alpha = fh\) and

\(t = f (t, v_2, ..., v_n)\) (B.22f)

\(w = t\) (B.22g)

\(t' = f [t] [v_2 ... v_n / x_2 ... x_n]\)

By eq. (B.22f) and the Value Typing Lemma we know that \(\theta \vdash_{\text{exp}} t : \text{pid}\). Applying this information and eq. (B.22c) to the Substitution Lemma results in

\((\Delta, fh : S) \cdot (\tilde{x} : \tilde{T}) \vdash^w S \triangleright T [f/x] : T \triangleleft S'\) (B.22h)

where by the Variable Substitution Definition and eq. (B.22g), \(y [f/x] = t = w\).

Applying the Substitution Lemma repeatedly to eqs. (B.22b) and (B.22h), results in

\((\Delta, fh : S) \cdot \emptyset \vdash^w S \triangleright T [f/x] [v_2 ... v_n / x_2 ... x_n] : T \triangleleft S'\)

where \(\text{after}(S, fh) = S\) and \(\text{after}(\Delta, fh, S) = (\Delta, fh : S)\), as required.
