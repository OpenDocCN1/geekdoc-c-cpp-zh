where \(\Gamma'\) contains only the mapping from the parameter names to their types, i.e., \(\Gamma' = (y : \text{pid}, x_2 : T_2, ..., x_n : T_n)\) - our aim is to change \(\Gamma'\) to \(\Psi\). This assumption in eq. (B.21i) is possible since a well-formed \(\Sigma\) dictates that the only free variables in a function body are the parameter types, or formally, for all \(fh \in \mathbf{dom}(\Sigma)\), we have

\(\mathbf{fv}(\Sigma(fh).\text{body}) \setminus (\Sigma(fh).\text{params} \cup (\Sigma(fh).\text{dual})) = \emptyset\)

By eq. (B.21f) and Value Typing Lemma we know that \(\theta \vdash_{\text{exp}} t : \text{pid}\). Applying this information and eq. (B.21i) to the Substitution Lemma results in

\(\Delta \cdot (x_2 : T_2, ..., x_n : T_n) \rightarrow W^{|S|} S \vdash T [f/x] ; T < \text{end}\) (B.21j)

where by the Variable Substitution Definition, \(y [f/x] = t = w\).

Applying the Substitution Lemma multiple times to eqs. (B.22b) and (B.21j), results in

\(\Delta \cdot \theta|^W S \vdash T [f/x] [v_1, ..., v_n / x_1, ..., x_n] ; T < \text{end}\) (B.21k)

as required, since \(\text{after}(S, fh) = S\) and \(S' = \text{end}\). Also, \(\text{after}(\Delta, fh, S) = (\Delta, fh : S)\), but from eq. (B.21h), \(fh\) is already mapped to \(S\) in the session typing environment, therefore \((\Delta, fh : S) = \Delta\), as needed.

[TUNKNOWNCALL] From the rule, we know

\(t = f (w, e_2, ..., e_n)\) (B.22a)

\(\theta \vdash_{\text{exp}} e_i : T_i \text{ for all } i \in 2..n\) (B.22b)

From the premise we also know that

\((\Delta, fh : S) \cdot (y : \text{pid}, \tilde{x} : \tilde{T}) |^W S \vdash \tilde{T} : T < S'\) where \(\tilde{x}, \tilde{T}, \tilde{T}, T\) and \(y\) are obtained from the function information environment (i.e., \(\Sigma\)) (B.22c)

From the structure of \(t\) (eq. (B.22a)), term transitions (\(t \xrightarrow{\alpha} t'\)) can be derived using two rules, so we consider two sub-cases:

+   1. [RCALL1] From this rule we know that \(\alpha = \tau\), and

\(t' = f (v_1, ..., v_{k-1}, e_k', ..., e_n)\) \(e_k \rightarrow e_k'\) (B.22d)

Applying eq. (B.22b) (for \(i = j\)) and eq. (B.22d) to the Preservation (Expressions) Lemma, we get

\(\theta \vdash_{\text{exp}} e_j' : T_j\) (B.22e)

Using eq. (B.22b) and eq. (B.22e) in the rule [TUNKNOWNCALL], results in

\(\Delta \cdot \theta|^W S \vdash f (v_1, ..., v_{k-1}, e_k', ..., e_n) ; T < S'\)

This holds since \(\text{after}(S, \tau) = S\) and \(\text{after}(\Delta, \tau, S) = \Delta\).

+   2. [RCALL2] From the rule, we know that \(\alpha = fh\) and

\(t = f (t, v_2, ..., v_n)\) (B.22f)

\(w = t\) (B.22g)

\(t' = f [t] [v_2 ... v_n / x_2 ... x_n]\)

By eq. (B.22f) and the Value Typing Lemma we know that \(\theta \vdash_{\text{exp}} t : \text{pid}\). Applying this information and eq. (B.22c) to the Substitution Lemma results in

\((\Delta, fh : S) \cdot (\tilde{x} : \tilde{T}) |^W S \vdash T [f/x] ; T < S'\) (B.22h)

where by the Variable Substitution Definition and eq. (B.22g), \(y [f/x] = t = w\).

Applying the Substitution Lemma repeatedly to eqs. (B.22b) and (B.22h), results in

\((\Delta, fh : S) \cdot \theta|^W S \vdash T [f/x] [v_2 ... v_n / x_2 ... x_n] ; T < S'\)

where \(\text{after}(S, fh) = S\) and \(\text{after}(\Delta, fh, S) = (\Delta, fh : S)\), as required.
