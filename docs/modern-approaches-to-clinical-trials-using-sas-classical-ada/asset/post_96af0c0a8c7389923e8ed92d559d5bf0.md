## 3.3.4 Sample Size Re-estimation Based on Promising Zone

### 3.3.4.1 Overview

This method builds on a series of work by several authors [3, 28]; the core idea of this method is to derive a sample size re-estimation rule based on the conditional power and use a standard (i.e. non-modified) statistic to test the null hypothesis at the end of trial. In order to protect type I error, the authors [3, 28] restrict the set of conditions under which such procedures can be performed rather modifying the final analysis.

The idea of using conditional power for interim decisions is not new or unique to this method. For example, the extensive discussion in [21] point out that when observed treatment effect is small, the resulting SSR procedure based completely on the fact that the conditional power has undesirable properties of the new sample size being large. Also, the fact that most SSR methods have to use a non-standard test statistic at the end of the trial creates some room for potential inconsistency in the final study between classical methods (GSD) and most unblind designs.

The promising zone design of Mehta and Pocock attempts to alleviate these concerns by using a conventional (in a sense of GSD) Wald test statistic $Z_M$ for the final decision, although if the final sample size is increased in a data-dependent manner, the overall type I error rate will not be inflated, provided that the sample size modifications are not too extreme [3]. The sample size modification rule is based on the conditional power assuming the treatment effect $CP_\delta$ in future observations:

CP_\delta(Z_n

Chen, Demets and Lan have shown that if sample size is increased only when 50%, then one can use conventional statistics for the final testing and the type I error rate will not be inflated [28]. Mehta and Pocock took this approach further by lowering the 50% CP threshold as described below [3].

The new sample size $M$ per group is selected so that $CP_{\zeta}[Z_n, M-n]=1-\beta$. A not too extreme sample size increase is quantified as (1) implementing a conservative cap on the total sample size and (2) increasing sample size only if $CP_{\min} \leq CP < 1-\beta$, where $1-\beta$ is the targeted study power and $\zeta$ is the minimally acceptable conditional power that would still assure type I preservation using the conventional Wald statistic at the end of the trial. The precise value of $\beta$ is determined based on the ratios $N_{\max}/N$ and $n/N$ on the targeted power $1-\beta$. For example, most commonly used trials will be in a range of 30-40%. For example, a two-fold maximum sample size increase, $N_{\max}/N=2$, and one interim look midway through the trial, would be 36% for 90% overall power [3].
