
specify $f(a_k|M_k)$ to be the prior distribution of $a_k$. As in the single CRM model, we may take a zero-mean normal distribution as the prior for $a_k$. We apply Bayes' theorem to calculate the posterior model probability of $M_k$,

```
$P(M_k|D) = \frac{P(D|M_k)P(M_k)}{\sum_{i=1} P(D|M_i)P(M_i)}$
```

where $P(D|M_k)$ is the marginal likelihood of model $M_k$ obtained by integrating out $a_k$ with respect to the corresponding prior distribution,

```
$P(D|M_k) = \int P(D|a_k, M_k)f(a_k|M_k)da_k$
```

The BMA estimate of the toxicity probability at dose level $j$ is then given by a weighted average,

```
$\pi_j = \sum_{k=1}^K \tilde{\pi}_{kj}P(M_k|D), \quad j=1, \dots, J$
```

where $\tilde{\pi}_{kj}$ is the posterior mean of the toxicity probability at dose level $j$ under model $M_k$,

```
$\tilde{\pi}_{kj} = \int p_{kj} \frac{\exp(\alpha a_k) P(D|a_k, M_k)f(a_k|M_k)}{\int P(D|a_k, M_k)f(a_k|M_k)da_k}$
```

The BMA estimate $\pi_j$ assigns each $\tilde{\pi}_{kj}$ a weight of $P(M_k|D)$, and the better the model fit the larger the weight. Under the BMA-CRM, the decision on dose escalation or de-escalation is based upon the BMA estimate $\pi_j$ as opposed to each single CRM model.

In contrast to averaging over multiple CRM models, one can also take a model selection approach by identifying the best fitting model at each step of dose assignment. Model selection can be based on certain criteria that penalizes a large model [6], for example, Akaike information criterion (AIC), Bayesian information criterion (BIC), and Deviance information criterion (DIC). Because all the candidates in the model are the same structure, except for different skeletons, for simplicity, we can take the posterior model probability as the basis for model selection: The higher the posterior model probability, the better the model fit. Therefore, we can select the CRM model that is associated with the highest posterior model probability to determine each dose assignment.

To illustrate the BMA-CRM, we consider six dose levels and the target toxicity probability is 30%. Four sets of initial guesses of the toxicity probabilities (skeletons 1-4) are specified as follows:

$(p_{11}, \dots p_{16}) = (0.02, 0.08, 0.12, 0.20, 0.30, 0.50),$

$(p_{21}, \dots p_{26}) = (0.01, 0.05, 0.14, 0.22, 0.26, 0.30),$

$(p_{31}, \dots p_{36}) = (0.10, 0.20, 0.30, 0.40, 0.50, 0.60),$

$(p_{41}, \dots p_{46}) = (0.20, 0.30, 0.40, 0.50, 0.60, 0.65).

The prior model probabilities are set equal for the four skeletons, i.e., $P(M_k) = 1/4$, for $k = 1, \dots, 4$. After seven cohorts of patients have been treated in the trial, their toxicity outcomes are presented in [Toxicity Outcomes and Dose Assignments for Second Hypothetical Trial].

The SAS macro $v_{BCRAM}$ [Example Code 5.2 Bayesian Model Averaging CRM Macro] can be used to analyze the cumulative data and recommend the most appropriate dose for the next cohort of patients. The input parameters in the $v_{BCRAM}$ macro are similar to those in the $v_{CRM}$ macro, but the %BMACRM macro requires users to specify several skeletons instead of a single skeleton. In addition, the prior probability of each skeleton is stored in the %priormodel data set for which we equal probabilities as a default. The %BMACRM macro has the same output as the %CRM macro. To illustrate this we consider the above example with seven cohorts of patients treated in the trial and the goal is to determine the dose assignment for the next cohort.

## Example Code 5.2 Bayesian Model Averaging CRM Macro

```sas
%macro BMACRM(currentdata,skeleton,priormodel,target=0.3,stop=0.9);
proc iml;
  use currentdata;
  read all;
  use &skeleton;
  read all;
  use &priormodel;
  read all;

  nmodel=nrow(priormodel);
  ndose=now(skeleton);

  dosecurr=nrow(doselevel);
  stop=0;
  /* posterior-likelihood * prior */
  start postxf(alpha) global(DLT,doselevel,cohortsize);
    sigma=2;
    lik=1;
    nn=nrow(DLT);
    do k=1 to nn;
      p=p[k]*exp(alpha);
      lik=lik*(cohortsize);
    end;
    lik=lik*exp(-alpha/sigma);
    return(lik);
  finish;

  /* used to calculate posterior mean of pi */
  start postxf(alpha) global(DLT,doselevel,cohortsize);
    post=p[j]*exp(alpha);
    return(post);
  finish;

  marginal=
  povertox=(0,ndose,nmodel);
  md=1 to nmodel;
    p=skeleton[md];
    lb=log(target)/log(p[1]);
    call quad(marginal,"posterior",1E-4,scale=0.5);
    /* default-1 */
    marginal/marginal;
    do j=1 to ndose;
      call quad(pj,"postxf",1E-4,scale=0.5);
      pi=marginal;
      p[j,md]=pi;
    end;
    call quad(povertox,"posterior",-3,lb,1E-4,scale=0.5;
    povertox=povertox/marginal;
    povertox=povertox;
  end;

  posmodel=marginal#priormodel/sum(marginal#priormodel);
  pi=pi#posmodel;
  povertox=sum(povertox#posmodel);

  if povertox>stop then stop=1;

  diff=abs(pi-target);
  dosebest=diff;
  dosenextcurr=dosecurr;

  if dosebest<dosecurr then
    if dosecurr<ndose then do
      dosenextcurr=dosecurr+1;
    end;

  if dosebest<dosecurr then /* Note: Original OCR has likely error here, usually dosebest>dosecurr or different logic */
    if dosecurr<l1 then do;
      dosenextcurr=dosecurr-1;
    end;

  if stop=1 then dosenext="The Trial should be early terminated";
  print dosenext;
  doselevel=1:ndose;
  doselevel=doselevel;
  create doselevel from doselevel[colname="doselevel"];
  append from doselevel;

  create pi from pi[colname="pi"];
  append from pi;
  quit;

  &skeleton;
  merge &skeleton. pi doselevel;
  run;

  * "Skeleton vs Estimated Toxicity*"
  proc sgplot data = skeleton;
    line doselevel / response = p1 markers label='p1'
      markerattrs=(symbol=circle,size=10) lineattrs=(pattern = solid);
    line doselevel / response = p2 markers label='p2'
      markerattrs=(symbol=triangle,size=10) lineattrs=(pattern = solid);
    line doselevel / response = p3 markers label='p3'
      markerattrs=(symbol=diamond,size=10) lineattrs=(pattern = solid);
    line doselevel / response = p4 markers label='p4'
      markerattrs=(symbol=squared,size=10) lineattrs=(pattern = solid);
    line doselevel / response = p5 markers label='p5'
      markerattrs=(symbol=star,size=10) lineattrs=(pattern = solid, thickness=2);
    yaxis min=0 max=1 label="Toxicity Probability";
    xaxis label="Dose Level";
    refine target / axis=y="Toxicity Target"
      LABEL=INSIDE LABELPOS=min lineattrs=(pattern = shortdash);
    keylegend / location=inside noborder;
  run;
%end BMACRM;

* Observed data
1st col: # of DLTs for each cohort
2nd col: # Treated dose level
3rd col: # of patients for each cohort
*/
data currentdata;
  input DLT doselevel cohortsize;
datalines;
0 1 3
0 2 3
1 3 3
0 3 3
1 4 3
1 4 3
2 5 3;
run;
```
