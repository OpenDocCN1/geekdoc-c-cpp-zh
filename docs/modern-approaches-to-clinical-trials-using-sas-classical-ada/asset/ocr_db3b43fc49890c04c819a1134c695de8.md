# 4.3.2 Model for Historical Survival Data

In this section, we consider meta-regression survival models for the different types of the historical data discussed in 4.2.3 Input Historical Data. Suppose $y_{jk}$ is the total subject year duration and $v_{jk}$ is the censoring indicator such that $v_{jk}=1$ if $y_{jk}$ is a failure time and $v_{jk}=0$ if $y_{jk}$ is censored for the $k^{th}$ trial for $j=1, \dots, K_0$. In addition, $x_{jk}$ represents only one arm (control or experimental) if it is a scalar and both arms if it is a vector, as discussed in Section 4.2.3. Suppose that the trial-level aggregate data $D_k=\{y_{jk}, v_{jk}, x_{jk}\}, k=1, \dots, K_0\}$ are available from the $K_0$ historical studies. Assume that the individual failure time follows an exponential distribution, $Exp(\lambda_{jk})$, where the hazard rate $\lambda_{jk} > 0$. Then the model assumes

$log(\lambda_{jk}) = \gamma_0 + \gamma_1(j-1) + \theta_k, \quad (4.5)$

for $x_{0k} \leq j-1 \leq x_{2k}, k=1, \dots, K_0$. Suppose that the historical data are available only for the control arm. This is the first type of historical data discussed in Section 4.2.3 and it is easy to see that $x_{0k}=0$ for this case. Then the models for the historical and current data share only one common parameter, namely, $\gamma_0$. However, if the historical data are available only for the experimental arm, which is the second type of historical data, then $x_{0k}=1$ and the models for the historical and current data share one composite parameter $\gamma_0+\gamma_1$. Now, we consider the third type of data, in which the historical data are available for both arms. In this case, the models for the historical and current data share two common parameters $\gamma_0$ and $\gamma_1$. The likelihood function for the general form of the data is given
