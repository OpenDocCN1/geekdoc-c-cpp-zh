# ## 4.7.1.3 Running MCMC to Sample from the Posterior Distribution

**Example 4.2 Running Markov Chain Monte Carlo (MCMC)** shows how to sample from the posterior distribution using the partial borrowing power prior. We allow the user to choose initial values of variances for the parameters $\gamma_0$, $	heta_{jk}$, and $\theta_k$. Since we do not need to print out posterior estimates for each simulated data set, we use an option to suppress the posterior estimates in the SAS log window. The option, `ods exclude all`, also allows us to save storage and reduce the computation time. To reproduce the simulation results, we use the values generated using the initial seed (e.g. `SEED = 123456789`) in PROC MCMC.

```
ods graphics on;\ods exclude all;
proc mcmc data=sort_new output=postout nmc=&NMCS nbi=&nbi seed=&seedmc
  MAXTUNE=30 plots=none statistics=none diagnostics=none;
%if (&hist= or &a0=0.00) and &a0<1.00) then %do;
  %if (&N_hist > 1 then %do;
    array theta_c[%eval(&N_hist-1)];
  %end;
  %if (&N_curr > 1 then %do;
    array theta_c[%eval(&N_curr-1)];
  %end;
%end;
%if (&hist= or &a0=0.00) then %do;
  %if (&N_curr > 1 then %do;
    array theta_c[%eval(&N_curr-1)];
  %end;
%end;

..(continue)
%if (&hist= or &a0=0.00) then %do;
```
