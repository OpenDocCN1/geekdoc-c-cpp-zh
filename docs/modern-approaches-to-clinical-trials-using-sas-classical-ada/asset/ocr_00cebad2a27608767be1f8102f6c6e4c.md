for $j=1, 2, \dots, J$. The parameter $\eta_1$ is determined simultaneously along with $\mathcal{C}_U(\cup\{\emptyset\}, \alpha, eta, J)$ and $\mathcal{C}_L(\cup\{\emptyset\}, \alpha, eta, J)$ through the relationship

$\eta_1 = \mathcal{C}_U(\cup\{\emptyset\}, \alpha, eta, J) + \mathcal{C}_L(\cup\{\emptyset\}, \alpha, eta, J)$

Similarly, the maximum information $I_j$ and hence the maximum sample size $n_j$ or the maximum number of events $D(C_j)$ can be estimated accordingly for a given value of $\eta_1$. For the two-sided setting, the rejection of the null hypothesis, the boundaries will be a set of top outer boundaries and bottom outer boundaries, while for the rejection of the alternative hypothesis, the boundaries will be a set of inner wedge boundaries.

Another approach that is different from using the power or shape parameter on $t_j$ is the triangular boundary method proposed by Kittelson and Emerson [4]. This boundary set takes on the following shape

$c(t_j) = C(	ilde{\emptyset}, \alpha, J)(1+	au)^{\frac{j}{J}}$

The boundary function is a linear function on $t_j$ with a variable slope parameter of $	au$. When a trial is testing a one-sided hypothesis, an early decision to stop to reject or accept the null hypothesis, this method produces a triangular continuation region on the scale of the score statistic $S(t_j)$.

# **Example: Redesigning Familial Hypercholesterolemia Trial Using Pocock and O’Brien-Fleming Methods**

In this example, we want to re-create two one-sided sequential trials using Pocock and OBF approaches for the children FH trial using design design.

**Example Code 2.6 Pocock and O’Brien-Fleming Designs for Familial Hypercholesterolemia Trial**

```
ods graphics on;
proc seqdec pass stopprob errsend;
pocdecignforth; design nstages=4 method=poc alt=upper alpha=0.025;
obfddesignforth; design nstages=4 method=obf alt=upper alpha=0.025;
samplesize model=twosample(stddev=0.045 meandiff=0.02 weight=1);
run;\ods graphics off;
```
