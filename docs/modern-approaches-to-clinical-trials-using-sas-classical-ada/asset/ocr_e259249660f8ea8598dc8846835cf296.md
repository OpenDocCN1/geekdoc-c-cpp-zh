Furthermore, the SAS macro BSMED allows a single trial for the current data along with the historical data from one or previous trials. Therefore, the macro can be used for the design of a Bayesian time-to-event clinical trial in the non-meta setting. Finally, we extend the computational algorithm discussed in [6, 10] to generate the predictive survival data by incorporating the trial duration, accrual time, and minimal follow-up time.
