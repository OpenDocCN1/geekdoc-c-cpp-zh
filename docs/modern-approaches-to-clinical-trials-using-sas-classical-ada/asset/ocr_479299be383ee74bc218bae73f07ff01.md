Occasionally, some clinical trials will include multiple groups such as multiple doses of an investigational drug. In this case, futility analysis plays an important role to drop doses that do not exhibit clear evidence of efficacy, however, since multiple comparisons are being conducted, measures to control the inflation of type I error must be in place to account for multiplicity. In fact, dropping doses cannot be addressed in a classical group-sequential framework and requires completely different methodology, similar to the one described in Chapter 3, “Sample Size Re-estimation.” The latter extends the distributional theory and methods of preserving type 1 error that we have reviewed to situations when a trial's total maximum information can be adjusted upward as well as downward during the interim analysis. This flexibility in direction of adjustment is unique to unblinded sample size re-estimation and is often used to contrast it with the group sequential methods discussed here: the group-sequential method can only adjust the sample size downward by stopping early.
