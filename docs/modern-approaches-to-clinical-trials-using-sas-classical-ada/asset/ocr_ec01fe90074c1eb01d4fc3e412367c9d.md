+   • $\sqrt{n(NE_e(n)/n-ho)} 	o N(0, \sigma^2)$ in distribution for some $\sigma^2 > 0$.

one can obtain a second-order Taylor's approximation to the power function of a RAR design [14]. It is shown that the power of a RAR design with target allocation $ho$ is mainly determined by the power of a fixed allocation design with allocation $ho$ and the values of $NE_e(n)/n-ho$ and $(NE_e(n)/n-ho)^2$ (the expected value of the latter is the variance of the allocation proportion). Therefore, one can facilitate the planning of a sample size for RAR designs based on asymptotic approximations.

Three types of sample size can be distinguished: 1) sample size to achieve power $1-eta$ for a fixed allocation design (type I sample size), 2) sample size to achieve power $1-eta$ on average (type II sample size), and 3) sample size to achieve power with probability $1-\xi$ (for some positive $\xi$) (type III sample size) [14].

If consider a type I sample size. For a fixed allocation, the treatment group sample sizes are $N_E(n)=np$ and $N_C(n)=n(1-ho)$, and the sample size to achieve power $1-eta$ is obtained from solving

```
$$\frac{PE-PC}{\frac{PEGE+PCGE}{np(1-ho)}}z_{1-\alpha} = 1-\beta$. The solution is
```

```
$n_I = \frac{(\frac{PEGE}{ho}+\frac{PCGE}{1-ho})(z_{1-\alpha}+z_{1-\beta})^2}{(PE-PC)^2} \quad (10.12)$
```

(if necessary, $n_I$ in (10.12) can be rounded to the next largest integer).

To determine type II sample size ($n_{II}$), we should consider the average power function. By our assumption, $\sqrt{n(NE_E(n)/n-\rho)} \to N(0, \sigma^2)$; therefore, $NE_E(n)=np+\sigma\sqrt{n}$ and $N_C(n)=(1-ho)n-\sigma\sqrt{n}$, where $Z$ is a standard normal random variable. The average power function is then approximated as
