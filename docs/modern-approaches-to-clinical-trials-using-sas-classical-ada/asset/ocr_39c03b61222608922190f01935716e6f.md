# 2.4.4 Spending Function Boundaries

Error spending functions are the most flexible and general way of deriving the stopping boundaries. The $\alpha$-spending functions where the $\alpha$ level is pre-specified are used to control the type I error in the trial. They are monotonic functions that are defined on the unit interval with $\alpha(t)=0$ and $\alpha(t)=\alpha$. Similarly, the $eta$-spending functions, with pre-specified $eta$ level, are used to control the type II error. They are defined on the unit interval with $eta(t=0)$ and $eta(t=1)=eta$. This idea of using an error spending function was first introduced by Lan and DeMets [10]. One can use either the $\alpha$ or the $eta$ spending function singly or combine both of them in sequentially monitoring a single trial. They can be used for either one-sided or two-sided hypotheses, and produce either symmetric or asymmetric boundaries.

There are numerous proposed error spending functions, and we will briefly describe three of the most commonly used spending functions and their properties. The forms of the functions are expressed as $\alpha(t)$ and $eta(t)$ where $t(0 < t < 1)$ is the information fraction. Here we illustrate the $\alpha$-spending function, but it can also apply to the $eta$-spending function.
