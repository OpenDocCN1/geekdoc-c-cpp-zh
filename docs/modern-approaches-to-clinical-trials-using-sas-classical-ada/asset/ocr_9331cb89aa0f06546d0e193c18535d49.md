# Optional Inputs

+   1. HIST: data set with the first three columns, $K$ (trial ID), $y$ (total subject year duration), $v$ (total number of events), and an additional column for treatment indicator ($x$), where $K$, $y$, and $v$ should be placed after column 3. Note that $x$ is an indicator \u001 variable of the treatment arm, which takes a value of 0 if it comes from the control arm and 1 if it comes from the experimental arm. The values of $K$ should be consecutive integers starting with 1. For example, if the total number of historical data sets is 5, the values of $K$ should be enumerated as 1, 2, 3, 4, and 5.

If OUTPUT is not specified, the file will be indexed by the name $BSMED\_Output\_a0$ as default. In the filename, $a0$ indicates a discounting parameter for the historical survival meta-experimental data that the user specifies in the macro.
