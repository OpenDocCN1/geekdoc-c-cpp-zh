patients based on two prognostic factors: gender and blood pressure. The factor has two levels—male or female, and the blood pressure has 3 levels—high, normal, and low. In conjunction with permuted block randomization, the stratification based on the two factors results in six mutually exclusive groups. If we take the block size of 4, the output of Example Code 9.4 Stratified Randomization produces a stratified block randomization scheme for such a trial (Output from Example Code 9.4).

# Example Code 9.4 Stratified Randomization

```
proc plan seed=123;
    factors Block=1 random Gender=2 ordered Pressure=3 ordered Sequence=4
    ordered/noprint;
    treatments Treatment=4 randomRandomization Gender cvals=('Male' 'Female') ordered
    output=stratifiedRandomization
    Pressure cvals=('High' 'Normal' 'Low') ordered
    Treatment cvals=('A' 'A' 'B' 'B') random;
```

```
run;
proc print data = StratifiedRandomization;
run;
```
