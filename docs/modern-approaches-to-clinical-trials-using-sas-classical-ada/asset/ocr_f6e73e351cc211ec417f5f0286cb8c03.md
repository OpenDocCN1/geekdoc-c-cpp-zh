# 4.5.1 Fitting Priors

We extend the fitting prior in (4.8) to the partial borrowing power prior approach formally proposed in [6] and [10]. The partial borrowing prior is that the historical data are borrowed only through the common parameters shared in the model for the historical data and the current data. Thus, the strength of the historical data is borrowed only through the common parameters. The fitting prior for $(\gamma, \theta)$ under the metaregression survival model in (4.3) is

```
$\pi^{(f)}(\gamma, \theta|D_0, a_0) \propto \prod_{j=1}^{K_0} \pi_{j=0}^{K_k}(\exp\{ij_j+l_k(\gamma_0 + \gamma_1 + \theta_k)\})\n\n\times \exp\{-(\gamma_0 + \gamma_1 + \theta_k)/a_0+l_k\} \pi_0^{(f)}(\theta_0)d\theta_0 \pi_0^{(f)}(\gamma, \theta).$ (4.10)
```

where $0 \le a_0 \le 1$, $\pi_0^{(f)}(\theta_0)$ and $\pi_0^{(f)}(\gamma)$ are the initial priors. In (4.10), independent initial priors, $N(0,\sigma_{	heta_0}^2)$, $N(0,\sigma_{\gamma}^2)$, $N(0,\tau_{	heta_k}^2)$ and $N(0,\tau_{\gamma}^2)$ are assumed for $\gamma_0, \gamma_1, \theta_k$, and $\gamma_k$.

In (4.10), the parameter $a_0$ controls the influence of the historical metasarial data $D_0$ on the current data $D_K$. The parameter $a_0$ can be interpreted as a discounting parameter for the historical meta-survival data. It is reasonable to restrict the range of $a_0$ between 0 and 1, and thus we take $0 \le a_0 \le 1$. One of the main roles of $a_0$ is that it controls the heaviness of the tails for the prior for $\gamma_0$ and $\gamma_1$ in the model. As $a_0$ becomes smaller, the tails of (4.10) become heavier. If $a_0=0$, the prior does not depend on historical meta-survival data. That is, $a_0=0$ is equivalent to a prior specification with no incorporation of historical meta-survival data for the current study. Thus, the parameter $a_0$ controls the influence of the historical meta-survival data on the current study. Such control is important in the case where there is heterogeneity between the historical and current meta-survival data, or when the sample sizes of the historical and current meta-survival data are quite different.
