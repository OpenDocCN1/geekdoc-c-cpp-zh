There are potentially several rules for sample size increases that can be used. Extensive simulations should be used to see which rule best suits the project needs, as well as one gives the best balance between overall power, power in the promising zone, and the average sample size. One simple way is the flat increase, where the sample size is increased to a percentage of throughout the promising zone. For example, if the conditional power is between 30% to 80% the sample size can be increased to a percentage of . The SSR_CP macro can be modified easily to fit this sample size calculation rule. We further explore two scenarios where we increased the sample size: 1) 2 times the initial sample size, i.e., $N_{max}=1000$ in the promising zone and 2) 1.5 times the initial sample size by setting the maximum sample size to 756 (i.e. 75% of $N_{max}=1008$). The SSR_CP macro can be updated easily to fit this flat increase rule. The only modification needed in the macro is: if zone in ("PROMISING") then do; n2tilda=\&max; end;

The actual value of $N_{max}$ can be any value, as a percentage of the initial planned sample size.
