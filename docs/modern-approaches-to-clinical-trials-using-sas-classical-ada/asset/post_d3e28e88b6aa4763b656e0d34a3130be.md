Additionally, the posterior density is somewhat irregularly shaped, and high autocorrelation persists beyond the first few lags. Also note that the posterior distribution tails abruptly around 15. This is the effect of choosing a prior distribution in the range of 0 to 15. If the prior was less informative, the credible interval for ed50 would likely be larger. The only caution is that the ed50 is a function of the independent variable (dose in this case). The evaluation of diagnostics plots corresponding to the independent variable needs to be more nuanced than the evaluation of diagnostics plots for the dependent variable. Potential ways to understand and evaluate the stability of ed50 estimates include:

- Rerunning proc mcmc using the log of ed50. (See 8.3 Analysis for Continuous Endpoint where ed50 is modeled using an appropriate and scaled prior distribution and ed50 = exp(ln50)).
- Utilize a different prior (scaled beta distribution or a less informative prior) for ed50 which may help stabilize the estimation. The posterior mean (standard deviation) estimate of ed50 is 4.99 (4.3), with a 95% credible interval of (0.16, 14.29) (Figure 8.11). This implies that the study may not have covered the dose range of interest. If the actual ed50 is above 9 mg, then no doses have been tested at ed50 and the model may not be representative of the true dose-response relationship between these values. The corrected effect of the first dose is an approximate 8% increase in SRI for 1 mg dose (95% credible interval of 1.1-24.4), 15% increase in SRI response for 3 mg dose (95% credible interval of 2.7-32.2), and 23% for 9 mg dose (95% credible interval of 5.1-40.5). The dose-response model indicates a less 25% increase in SRI response, though the observed placebo response based on the credible intervals is. The placebo response was not highly influenced by the prior since the observed data and the prior show some concordance. The modeled response at 1 mg was highly influenced by the structure of the model since the 3 and 9 mg doses exhibited a strong response on SRI. Sensitivity analyses should be performed to better understand their effect on MCMC estimation. These analyses may include varying prior distributions or running multiple chains to test for convergence, which leads to better understanding of the robustness of the conclusions. A plot of the observed proportions, posterior estimates, and 95% HPD intervals, which are the narrowest intervals including 95% of the posterior samples, is shown in Figure 8.12. This shows graphically that the whole dose range may not have been properly explored given the fact that doses appear to have approached the estimated maximum response from the model.

### Example Code 8.6 Code to Produce Figure of Observed and Posterior Estimates for SRI

```
proc sort data = summaries;
  by parameter;
run;

proc sort data = intervals;
  by parameter;
run;

data combined (drop=alpha);
  merge summaries intervals;
  by parameter;
run;

data_plot;
  retain logit0;
  set combined;
  if parameter = 'e0' then do;
    logit0 = mean;
    e0 = exp(mean)/(exp(mean)+1);
    call symput('e0', put(temp, best.8));
  end
  else if parameter = 'ed50' then call symput('ed_50', put(mean, best.8));
  else if parameter = 'emax' then do;
    temp = (exp(logit0)/(exp(mean+logit0)+1);
    call symput('maxeffect', temp);
  end
  else if parameter = 'pipred0' then dose = 0;
  else if parameter = 'pipred1' then dose = 1;
  else if parameter = 'pipred3' then dose = 3;
  else if parameter = 'pipred9' then dose = 9;
  if name in ('pipred0', 'pipred1', 'pipred3', 'pipred9');
run;

data plot_dt;
  label pct_col = "Observed Proportion";
  label mean = "Posterior Proportion";
  merge plot_dt;
  by dose;
  dose_jit = dose + 0.1;
  pct_col = pct_col / 100;
run;

proc sgplot data = plot_dt;
  title1 "Observed and Emax Posterior Estimates for SRI Response";
  title2 "With 95% Posterior Density Intervals";
  scatter x = dose_jit y = pct_col;
  markeratts=(symbol=circlefilled-red) name='scat1';
  scatter x = y = mean / hpldower yerrorupper = hpdupper
  markeratts=(symbol=circlefilled-black) name='scat2';
  errorbaratts=(color=black) name='scat2';
  series x = dose y = mean / line=(pattern=solid color = black);
  xaxis values = (0 1 3 9) label="Dose" offsetmax=0.1 offsetmax=0.03;
  yaxis values = (0 to 1 by 0.2) label="portion of SRI Responders";
  refine &e.0 &maxeffect / axis / title=" noborder";
  keylegend "scat1" / "scat2";
run;
```
