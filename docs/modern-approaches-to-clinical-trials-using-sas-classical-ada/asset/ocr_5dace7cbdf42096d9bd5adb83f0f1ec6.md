The input parameters of the optcont macro are called doses, models (determining $\mu$ for the different models), sigma (determining the matrix sigma), direction (either equal to inc or dec, determining whether an increasing or decreasing value of the response is considered beneficial), and dosename (determining the name of the dose variable in the data set and the output). The input arguments doses, models and sigma need to be provided manually through a separate data set or extracted via cod from a suitable SAS procedure. The models data set needs to be exactly in the format given in the example below, i.e., have columns modnam, par, par2 and par3, with missing values specified for the parameters when the models have less than three parameters. For the column names of the sigma data set no specific names need to be used. Given these input arguments, the macro generates a SAS data set called optcontrasts that contains the optimal contrasts for the different model shapes. In addition, it creates a global variable called modcontr that contains the string of the candidate models names and contrasts, which then can be used inside an estimate statement without re-typing them. The dose variable name that is used in the modcontr estimate statement is determined by the variable dosename. The code for the macro is provided in Appendix A.
