# 4.7.1.1 Detailed Macro Options

In this section, we present the details of SAS macro, BSMED, for Bayesian survival meta-experimental design. As discussed in 4.2 Meta Design Setting, the macro BSMED requires two input data sets, namely the current and historical data (optional), 11 input variables, and one output file (optional). Names and Descriptions of Input Variables and Design Values shows the names and descriptions of the input variables and the design values in the SAS macro.

Table 4.4 Names and Descriptions of Input Variables and Design Values

| Data | Names in macro | Description |
|---|---|-|
| Historical | a0 | Discounting parameter ($\alpha_0$) |
| | sigma0 | Initial variance of $\gamma_0$ ($\sigma_0^2$) |
| | sigma1 | Initial variance of $\gamma_1$ ($\sigma_1^2$) |
| Current | tau0 | Initial variance of $	heta_{UK}$ ($	heta_{UK}^2$) |
| | tau | Initial variance of $	heta_K$ ($	heta_K^2$) |
| Design | delta | Design non-inferiority margin ($\zeta$) |
| | eta0 | User-defined Bayesian credible level ($\eta_0$) |

The input variables, including the number of MCMC runs (NCMC), the number of simulation data sets (DEP), and the number of burn-in samples (nbi), are required to run MCMC and generate predictive survival data in the macro. We also include an initial seed number (SEEDGEN) as the input variable. The input historical data should use SAS variable names $\kappa, y, v,$ and $\kappa$ for the TID, the total subject duration, the number of events, and the treatment arm indicator, where 0 denotes control and 1 corresponds to experimental.
