$l_{opt} = \frac{\sigma1\sqrt{\mu2}}{\sigma2\sqrt{\mu1}}$

The SAS macros % NeymanRandomize and % OptimalRandomize generate the next treatment assignment based on the Neyman's and optimal randomization schemes. The example is the same as the one used in the randomized play-the-winner rule.

# Example Code 9.8 Neyman's and Optimal Randomization Schemes

```
%macro NeymanRandomize(nl,y1,n2,y2,seed);
proc iml;
  call randseed(&seed);
  /* Estimate of p1 */
  pl1=y1/nl;
  /* Estimate of p2 */
  p2=y2/n2;
  /* Neyman's allocation ratio */
  rl=sqrt((pl1/p2)/(1-p2));
  pl1=rl/(1+rl);
  /* Assign the next patient based on p */
  Assignment=rand(1);
  call randgen(Assignment, "BERNOULLI",pl1);
  if Assignment=l then Assignment='A';
  else Assignment='B';
  print pl[colname="Allocation probability to arm A" label=""]
  Assignment[colname="Next assignment" label=""]
quit;
%end NeymanRandomize;
%macro OptimalRandomize(nl,y1,n2,y2,seed);
proc iml;
  call randseed(&seed);
  /* Estimate of p1 */
  pl1=y1/nl;
  /* Estimate of p2 */
  p2=y2/n2;
  /* Neyman allocation ratio */
  rl=sqrt((pl1/p2)/(1-rl));
  pl1=rl/(1+rl);
  /* Assign the next patient based on p */
  Assignment=rand(1);
  call randgen(Assignment, "BERNOULLI",pl1);
  if Assignment=l then Assignment='A';
  else Assignment='B';
  print pl[colname="Allocation probability to arm A" label=""]
  Assignment[colname="Next assignment" label=""]
quit;
%end OptimalRandomize;
%NeymanRandomize(nl=20,y1=14,n2=13,y2=5,seed=123);
%OptimalRandomize(nl=20,y1=14,n2=13,y2=5,seed=123);
```

Based on the two randomization schemes, both the outputs recommend treatment B for the next patient (Neyman and Optimal Randomization Assignments).
