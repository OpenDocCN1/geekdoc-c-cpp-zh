For example, a linear contrast test for equally spaced doses and balanced patient allocation is defined such that the difference of any two adjacent contrast coefficients is a same constant. Assuming that the linear model has been included in the candidate model set, the linear contrast is then a powerful test to detect the linear trend. Similarly, any dose-response relationship characterized through $\mu_m$ can be tested equally by selecting an appropriate contrast test, which coefficients are defined in dependence of the assumed $\mu_m$. Note that contrast tests are shift and scale invariant. The optimal contrast test depend on the parameter(s) $	heta_2$, but not on $	heta_0$ and $	heta_1$. The right column in [Example Dose-Response Models Often Used in Clinical Trials] displays the parameters, which need to be specified at the design stage for each model. Note that these prior guesses are only used for derivation of the contrasts. For example, for the model, a prior guess is required for the $ED_{50}$ parameter.

The third step is to test for an overall dose-response signal. The single contrast tests are defined as

```
$T_m = \frac{\sum_{i=1}^k c_{mi} y_i}{\sqrt{\hat{S}^2 \sum_{i=1}^k c_{mi}^2 n_i}}$
```

$\hat{S}^2 = \sum_{i=1}^k \sum_{j=1}^{n_i} (Y_{ij} - \hat{Y}_{ij})^2 / (N-K)$ denotes the mean squared error and $N=\sum n_i$. Under the null hypothesis $H_0: \dot{\mu}=0$ of no dose-response effect, i.e., $\mu_1=\=\mu_k$, and under the distributional assumptions from above, $T_1,dots T_M$ follow a clear multivariate $t$ distribution with $N-k$ degrees of freedom, and the correlation matrix only depends on the sample sizes and the correlations between the different contrasts. Note, for the data analysis step the critical value, contrast weights, etc. cannot be taken over from the design stage due to drop-outs, covariate effects, etc. In practice these computations have, to be re-done at this point.
