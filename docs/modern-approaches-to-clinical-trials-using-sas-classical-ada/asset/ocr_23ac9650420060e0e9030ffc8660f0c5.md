```
$P(M_k|D) = \frac{P(D|M_k)P(M_k)}{\sum_{i=1} P(D|M_i)P(M_i)}$
```

where $P(D|M_k)$ is the marginal likelihood of model $M_k$ obtained by integrating out $a_k$ with respect to the corresponding prior distribution,

```
$P(D|M_k) = \int P(D|a_k, M_k)f(a_k|M_k)da_k$
```

The BMA estimate of the toxicity probability at dose level $j$ is then given by a weighted average,

```
$\pi_j = \sum_{k=1}^K \tilde{\pi}_{kj}P(M_k|D), \quad j=1, \dotssim, J$
```

where $	ilde{\pi}_{kj}$ is the posterior mean of the toxicity probability at dose level $j$ under model $M_k$,

```
$\tilde{\pi}_{kj} = \int p_{kj} \frac{\exp(\alpha a_k) P(D|a_k, M_k)f(a_k|M_k)}{\int P(D|a_k, M_k)f(a_k|M_k)da_k$
```

The BMA estimate $\pi_j$ assigns each $\tilde{\pi}_{kj}$ a weight of $P(M_k|D)$, and the better the model fit the larger the weight. Under the BMA-CRM, the decision on dose escalation or de-escalation is based upon the BMA estimate $\pi_j$ as opposed to each single CRM model.

In contrast to averaging over multiple CRM models, one can also take a model selection approach by identifying the best fitting model at each step of dose assignment. Model selection can be based on certain criteria that penalizes a large model [6], for example, Akaike information criterion (AIC), Bayesian information criterion (BIC), and Deviance information criterion (DIC). Because all the candidates in the model are the same structure, except for different skeletons, for simplicity, we can take the posterior model probability as the basis for model selection: The higher the posterior model probability, the better the model fit.
