## 2.1 引言

现代临床试验的主要进展之一是实验设计中顺序分析的发明与应用。这种设计通常被称为组顺序设计（group sequential design）。组顺序设计由多个阶段阶段组成，并采用重复显著性检验策略。它是最常用的自适应设计之一。《医学统计学百科全书》[1] 将顺序分析定义为“一种允许在试验过程中数据积累时，在多次场合进行假设检验的方法。这种受监测的试验通常被称为顺序试验。”例如，在一个具有多个阶段的III期随机临床试验中；在每个阶段都计划进行中期分析。中期分析旨在根据临床试验完成前的计划时间，基于累积的数据来评估治疗在有效性或安全性方面的效应。根据中期分析的结果，将给定的检验统计量与临界边界进行比较，然后可以决定是停止以拒绝无治疗效应的零假设、接受零假设，还是继续下一阶段。

组顺序设计有三种类型：(1) 早期有效性停止设计，仅允许早期声称有效；(2) 早期徒效停止设计，仅允许声称无效；以及(3) 早期有效性或徒效停止设计，允许同时声称有效或徒效。根据先验知识，如果我们认为测试治疗是有前景的，应使用早期有效性停止设计。如果我们担心测试治疗可能无效，则应采用早期徒效停止设计。

在临床研究中，出于伦理、经济和行政考虑，人们对顺序程序有着巨大的兴趣，方法论在临床研究的所有阶段都发挥着作用。因此，这种试验设计对临床科学家和研究人员具有吸引力，因为它为正在进行的试验数据分析增加了灵活性。监测试验数据最令人信服的理由是从伦理上考虑，当出现有关所关注特定假设的证据时，终止或修改试验是理想的。Armitage [2] 认为，伦理考虑要求一旦有明确证据表明某种治疗方法更优，就必须停止试验，这导致了顺序试验的使用。对于结果良好的试验，早期停止确保了新产品可以更早地利用。如果结果为负性，早期停止可以避免资源浪费，并使患者遭受无效的治疗。与固定样本量的经典设计相比，顺序方法通常可以导致平均样本量、时间和成本的节省。如果研究者不确定新治疗的效应量，情况尤为如此。如果真实效应量实际上更大，早期停止将是理想的；如果真实效应量小于预期，试验可能会继续，甚至因早期徒效而停止。

另一方面，在某些情况下，固定样本设计可能比组顺序设计更好。在实践中，如果我们对效应量有很好的了解，固定样本量的经典设计可能更有效。在这种情况下，它不需要定期监测，可以减轻行政负担。此外，在某些试验中，如果之前的试验未能充分评估测试治疗的安全性，使用组顺序设计因有效性而早期停止，可能会导致对潜在安全问题的探索不足。在这种情况下，不仅安全性池太小无法回答安全性问题，而且如果次要终点也很重要，针对主要有效性结果的早期停止可能无法为测试这些次要假设提供足够的功效。此外，使用组顺序方法的成功要求在招募下一组受试者之前，能够易地测量结果响应以做出终止试验的决策，因此延迟的响应可能会给试验监测带来挑战。最后，如果效应量的无偏估计是目标之一，组顺序方法将无法通过跨阶段移动抽样分布无法来实现这一目标。因此，在决定采用顺序检验方法之前，仔细考虑这些因素是非常重要的。

如果组顺序检验策略适用，可以分两个阶段执行——设计阶段和中期监测阶段。在设计阶段，用户指定以下内容：

- 生成数据的统计过程，
- 检验的零假设和备择假设，
- 期望的I类错误，
- 顺序检验程序的功效，
- 停止边界的消耗函数的形状参数，
- 计划的中期查看次数，
- 以及中期查看的时间。

为了方便设计，预先指定对数据的最大中期查看次数。在期监测阶段，可以在精确的等间隔内，或者在确定等数量受试者的结果后进行中期查看或中期分析。在试验过程中，许多因素可能会影响中期分析的频率和时间。如果分析的频率或时间与计划进度有重大改变，则上述设计将不再适用。监测有两种不同的方法：连续性和离散性。作为一个抽象概念，连续监测指的是作为连续信息份额函数的连续尺度上的统计量。在临床试验背景下，连续监测意味着在观察每一个受试者的结果后进行监测。在实践中，这很少执行。然而，离散监测是指观察一组受试者后进行监测。这种顺序监测是本章的重点。

在组顺序试验的实际执行期间，人们可能希望允许分析具有灵活性，同时维护试验的完整性，因为在对积累数据的中期检查期间可能会引入偏差。(DSMB) 数据安全监测委员会不应被忽视。例如，可能需要设定中期查看的日期以适应 DSMB 的日程。通常，DSMB 计划在相等的时间间隔后会面，这与设计阶段指定的信息份额并不重合。再次，可能需要更改计划的数据查看次数，
