Let $\mu$ denote the variance of estimated dose-response parameters under an analysis-of-variance (ANOVA) parameterization, obtained using the appropriate estimation method for the generic parametric model above via maximum likelihood (ML), generalized estimating equations, partial likelihood, etc. The key assumption needed for this generic version of MCP-Model is that the response $\hat{\mu}$ at the doses are asymptotically normally-distributed with covariance matrix $\Sigma$. This approximation has been shown to hold for most parametric estimation problems, such as generalized linear models, parametric time-to-event models, mixed-effects models, etc. The MCP step consists of specifying a set of candidate models for the dose-response relationship $\mu(d)$. Similar to the original MCP-Approach, each of the candidate model shapes determines an optimal contrast for a trend test to evaluate the associated dose-response model signal. The optimal contrasts are applied to the previously described ANOVA-type estimates $\hat{\mu}$, with the associated asymptotic distribution used for implementing the tests (i.e., critical values and p-values).
