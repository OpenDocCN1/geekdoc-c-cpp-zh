# 7.3 Considerations for MCP-Mod at the Design Stage

One main consideration when implementing MCP-Mod is the choice of the candidate set of models. As a rule of thumb, often 3-7 dose- shapes, corresponding to 2-4 dose-response models are appropriate. Note that multiple dose-response shapes might be used for each dose-response model because the shapes define the optimal contrasts to be used in the MCP step and the models are those to be fitted in the Mod step. While in general the candidate set should be broad, when there is large uncertainty, one should keep in mind that using a very broad and flexible candidate set does not come for free. Generally the sample size will increase with a broader candidate set of shapes (i.e., contrasts) as the critical value for the MCP step will increase. There is also a trade-off in will decrease potential bias (in case of a misspecified model) but it will increase the variance of the estimates. To find a good trade-off the following considerations should be taken into account.

+   - General experience: Thomas et al. showed that in many situations an or sigmoid model can adequately describe the observed data [5].

+   - Drug-specific information: Dose-response curves of similar drugs, predictions from earlier phases of development (e.g. using a PK/PD model), or dose-response information of the same drug in a different indication can be used to suggest suitable dose-response shapes.

+   - Statistical considerations: If only a few active doses are available for use (say, three), it is difficult to fit more complex models (such as the sigmoid or the beta model, which both have four parameters), which then would not be included in the candidate set. In these cases one would rather use dose-response models with fewer parameters to obtain an adequate breadth of potential dose-response shapes.
