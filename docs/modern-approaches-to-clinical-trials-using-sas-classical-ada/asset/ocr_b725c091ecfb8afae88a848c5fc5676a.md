Additionally, the posterior density is somewhat irregularly shaped, and high autocorrelation persists beyond the first few lags. Also note that the posterior distribution tails abruptly around 15. This is the effect of choosing a prior distribution in the range of 0 to 15. If the prior was less informative, the credible interval for ed50 would likely be larger. The only caution is that the ed50 is a function of the independent variable (dose in this case). The evaluation of diagnostics plots corresponding to the independent variable needs to be more nuanced than the evaluation of diagnostics plots for the dependent variable.
