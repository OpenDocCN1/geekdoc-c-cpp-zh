
# 6.4 Analysis Examples Using Simulated Data

### 6.4.1 Brief Introduction to the Emax Model

This section describes two simulated practical examples for continuous and binary endpoints. The simulated data assume that there are 5 dose groups, 0mg (placebo), 2.5mg, 5mg, 10mg, and 20mg, in a phase II dose ranging trial. The sample size in each dose group is 60. The mixed procedure is used to fit 4-parameter models to analyze the data. Note that proc nlin in SAS could be used to fit the 4-parameter model as well, which is dedicated to the nonlinear regression model. Both procedures produce very similar estimates and results. In addition, code for trend tests for PoC, using the contrast (generated with the polyorth macro) accounting for equal or unequal dose spacing, are included for practical purpose for readers on both the continuous and binary endpoint cases.

The model is one of the commonly used nonlinear endpoint in dose response studies [24]. The model is shown below,

```
$y_i = E_0 + E_{max} \tilde{A} - \frac{D_i^h}{ED_{50}^h + D_i^h} + I\mu_i$,
```

where

- 1. $i$ is the subject ID
- 2. $y_i$ is the observed continuous response variable for the $th$ patient
- 3. $E_0$ is the basal effect, i.e., the response when the dose is 0 mg
- 4. $E_{max}$ is the maximum effect attributable to the drug
- 5. $ED_{50}$ is the dose that produces half of
- 6. $h$ is the hill parameter, or slope, which measures the sensitivity of the response to the dose range of the drug, determining the steepness of the dose–response curve $(N > 0)$
- 7. $D_i$ is the dose-level for the $i$th patient
- 8. $\epsilon_i$ is the random error for the $i$th patient. A standard assumption, adopted here, is that the $\epsilon_i$ terms are independent and identically distributed with a mean of 0 and a variance $\sigma_\epsilon^2$. An additional standard assumption is that the error terms are normally distributed.

Figure 6.5 Emax Model Dose-Response Curve, reproduced from [24], shows a typical dose-response curve, based on a monotonic increase assumption. Note that the model dose-response curve can be either increasing or decreasing relative to an increase in dose. If the response is decreasing, the value of the parameter will be negative.

The above model is a traditional 4-parameter model (also called the sigmoidal model) that is commonly used in dose-response study analysis. With 4 parameters ($E_0$, $ED_{50}$ and $h$), the model provides great flexibility to fit various shapes of the dose-response relationship and makes it one of the popular dose-response models. However, there are some limitations in the applications of this model. First, because the model has 4 parameters, it requires at least 5 doses (could include a placebo as 0) and assumes a monotonic dose-response curve. Second, the 4-parameter model sometimes does not converge. In the case that the 4-parameter model does not converge or a study is designed with only 4 dose levels, a common practice is to remove the hill parameter, e.g., by the slope parameter $h=\uparrow$. The model then becomes a 3-parameter model (i.e., the so-called hyperbolic model),

```
$y_i = E_0 + E_{max} \tilde{A} - \frac{D_i}{ED_{50}+D_i} + \mu_i$,
```

where the terms are defined as above for the sigmoidal model.

The above model assumes that the response variable is continuous, but sometimes, the response variable could be binary, e.g., a response rate. In this case, the model can be readily revised to be a generalized model using a logit link,

```
$\log(\frac{\pi}{1-\pi}) = E_0 + E_{max} \tilde{A} - \frac{D^h}{ED_{50}+D^h}$
```

where $\pi$ is the observed response rate.

In the next two sections, we use the above described models to analyze the simulated data as a demonstration of applications. The data sets are simulated as `detcon` (for a continuous endpoint) and `detbin` (for a binary endpoint).

### 6.4.2 Continuous Endpoint

The sample SAS code for simulation and analysis are provided in Example Code 6.2, which simulates a data set that is based on the above model.

Example Code 6.2 Program to Simulate Continuous Data Using the $Emax$ Model

```
data dose;
  input dose@;
  datalines;
0 2.5 10 20
run;

%macro simu(n=, sd=, e0=10, emax=80, ed50=5.5, h=1, outdst=dstcon)
** n is the sample size in each dose group;
 proc sql noprint;
  select count(dose)into:ngpr
  from dose;
quit;
%let ngpr=&ngpr;

data data_null;
  set dose;
  mean=&e0.+(&emax.*dose*&h)/(dose**&h). + &ed50.**&h);
  call symput(compress("mean"|put(n_, 1)), compress(mean));
  call symput(compress("dose"|put(n_, 1)), compress(dose));
run;
%do i=1 to &ngpr; %put **** Group &i. ****&mean;&; %end;
data outdst;
  do i=1 to &ngpr;
  group=&i;
  mean=&mean;&;
  dose=&dose&i;
  do n=1 to &n;
  resp=&mean&i. &sd.*rannor(1500);*Seed number 1500 is used;
  output;
  end;
%end;
run;
%mend;
%simu(n=60, sd=10, e0=10, emax=80, ed50=5.5, h=1, outdst=dstcon);
```

The below proc nmixed in Example Code 6.3 4-parameter Emax Model Fit proc nmixed is used to fix a 4-parameter model using the simulated data.

Example Code 6.3 4-parameter $Emax$ Model Fitting proc nmixed

```
proc nmixed data=dtcn alpha=0.05;
**set initial values;
parms eo=10 emax=80 edso=5.5 h=1 v=400;
**specify that edso must be positive;
bounds edso>0;
**define model;
if dose=0 then eta= eo;
else eta= eo + {(emax**h)/(ed50**h+h)};
model resp= normal(eta, v);
**estimate the difference in means;
estimate "Diff Means (dose 20mg-placebo)"
  eo+((20**h)/(ed50**h+20**h));
estimate "Diff Means (dose 10mg-placebo)"
  eo+((10**h)/(ed50**h+10**h));
estimate "Diff Means (dose 5 mg-placebo)"
  eo+((5**h)/(ed50**h+5**h));
estimate "Diff Means (dose 2.5mg-placebo)"
  eo+((2.5**h)/(ed50**h+2.5**h));
predict eta=etah;
**output estimations;
dataset has output for the mean differences;
dataset parms has output for parameters: e0 emax ed50;
ods output Estimates=est ParameterEstimates=parms;
```
