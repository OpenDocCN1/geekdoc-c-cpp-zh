
Once a cohort of patients is treated, the toxicity data would be updated in light of the new information, and so would the likelihood function $L(\alpha|D)$ which includes all the patients enrolled in the trial so far. As a result, we re-estimate the toxicity probabilities at all the dose levels using the posterior means $\hat{\pi}_1, \dots, \hat{\pi}_J$.

In detail, the CRM dose-finding procedure is described as follows:

- 1. Treat the first cohort of patients at the lowest or the physician-specified dose level.
- 2. Denote the current dose level as $j^{curr}$. Based on the data observed thus far, we obtain the posterior means of the toxicity probabilities for all the doses under consideration, $\hat{\pi}_1, \dots, \hat{\pi}_J$. We find the dose level $j^*$ that has a toxicity probability closest to $\phi$, $j^* = \text{argmin}_{j\in\{1,\dots,J\}} |\hat{\pi}_j - \phi|$, and make decisions as follows:
    a. if $j^{curr} > j^*$, de-escalate to dose level $j^{curr}-1$;
    b. if $j^{curr} < j^*$, escalate to dose level $j^{curr}+1$;
    c. otherwise, the dose stays at the same level for the next cohort of patients.
- 3. Once the maximum sample size is reached, the dose with the toxicity probability closest to $\phi$ is selected as the MTD.

The sample size for the CRM trial is calibrated through simulation studies in order to achieve desirable operating characteristics. In, if the lowest dose is too toxic, as noted by

$P[\pi_1 > \phi|D] = \frac{\log(\phi)/\log(\rho_1)}{\int f(\alpha|D)d\alpha} > 0.9$

the trial would be terminated for safety. The tuning parameter 0.9 can be adjusted to control how stringent the safety rule is.

As an example, we illustrate the CRM with a phase I clinical trial to find the MTD of CRM dose. Six dose levels of the drug are considered, and the CRM skeleton is specified as $(p1, p2, p3, p4, p5, p6) = (0.05, 0.10, 0.25, 0.40, 0.55, 0.65)$. The MTD is defined as the dose that has a toxicity probability closest to the target toxicity level. Suppose the trial treated 5 cohorts with cohort size of 3, and the toxicity outcomes and dose assignments are listed below in Toxicity Outcomes and Dose Assignments for First Hypothetical Trial.

The SAS Macro %CRM in Example Code 5.1 Continual Reassessment Method can be used to analyze the cumulative data and determine the dose assignment under the CRM framework. The input parameters for the %CRM macro are `currentdata`, `skeleton`, `target`, and `tstop`. The `currentdata` parameter stores the observed data set based on the treated patients, and each row corresponds to the accumulated information for each cohort, where the three entries in each row represent the number of DLTs observed for each cohort, dose level, and number of patients for that cohort, respectively. The user must also specify the skeleton parameter, which is the specified toxicity denoted as `target` in the %CRM macro, which is set to be 0.3 as the default. In addition, the user can adjust the toxicity tolerance by changing the value of `tstop`. %CRM creates a plot that overlays the curves for the initial guess and the posterior estimate of toxicity probability for each dose level. The output variable of %CRM macro is the suggested dose for the next cohort of patients.

# Example Code 5.1 Continual Reassessment Method Macro

```sas
%macro CRM(currentdata,skeleton,target=0.3,tstop=0.9);
proc iml;
  use &currentdata;
read all;
use &skeleton;
read all;
phat={};
dose=dosecurse[nrow(doselevel)];
stop=0;
/* posterior-likelihood prior */
start posterior(alpha) global (DLT,doselevel,p,cohortsize);
sigma=2;
lik=1;
nn=nrow(j);
 k=1 to nn
pi=(p[doselevel[k]])##exp(alpha);
lik=lik*(pi##(DLT))##(1-pi)##(cohortsize[k]-DLT[k]);
end;
lik=exp(-0.5*alpha*alpha/sigma2);
return(lik);
finish;
```

finish;
