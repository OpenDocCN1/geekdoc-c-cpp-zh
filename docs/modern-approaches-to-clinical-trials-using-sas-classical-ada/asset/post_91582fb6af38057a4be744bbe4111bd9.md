Another example where Bayesian dose-response analysis can be helpful is when testing compounds with the same endpoints in the same indication. If another internal compound has been tested for a particular indication, information from this compound could be utilized to construct an informative prior distribution for the next dose-response study in the same indication and endoint. If there is a reluctance to use the other compound's dose response, prior results could be used as informative priors for modeling the placebo response. These examples are a few of the ways Bayesian techniques allow the use of prior information so the dose-response curve is characterized with fewer patients or is estimated with greater precision.

The ICH E4 Dose response information to support drug registration guidelines state that “knowledge of the relationship among dose, drug concentration in blood, and response (effectiveness and undesirable effects) is important for the safe and effective use of drugs in individual patients” [1]. The guidelines further state that “agencies should also be open to the use of statistical and pharmacometric techniques such as Bayesian and population methods, modeling, and pharmacokinetic-pharmacodynamic approaches.” This further emphasizes the importance and value of Bayesian dose-response analysis.

In the case of dose-response studies with limited doses and small sample size designs, the asymptotic-based maximum likelihood estimators (MLE) may not estimate the parameters of the model adequately, whereas the Bayesian model does not have such a drawback. There are some examples of sparsely designed response clinical studies where the ED50 parameter estimates using the asymptotic-based maximum likelihood here were negative [2]. However, a Bayesian sigmoid model utilizing adequate prior information was able to obtain reasonable estimates for the ED50 and parameters.

During the learning phase of the clinical trial, i.e. phase II, implementation of a Bayesian dose-response analysis allows for appropriate decisions by utilizing external belief and/or data and provides precise estimates for the dose response relation even with smaller sample sizes.

Typically, responses for clinical trials in the inflammation and immunology area are binary in nature, i.e. a success or failure of the outcome. Although there are continuous scales that are available in these disease areas, the clinicians prefer to define success on the basis of whether a subject has responded or remitted. Apart from a model for continuous endpoint we also provide an example for a Bayesian model for binary data.

## 8.2 Statistical Model for Bayesian Dose-Response

In this chapter we will only provide examples of a Bayesian hyperbolic model (Chapter 6). The sigmoid model or other non-linear models are out of scope [3,4]. It may be noted though that the sigmoid model can easily be implemented by adding a h parameter to the hyperbolic model. From Section 6.4.1, the Bayesian hyperbolic model is written as

```
$y_i = E_0 + E_{max} \tilde{A} - \frac{D_i}{ED_{50} + D_i} + I_i \mu_i$
```

where

- 1. $i$ is the subject ID
- 2. $y_i$ is the observed continuous response variable for the $i$th patient
- 3. $E_0$ is the basal effect, the response when the dose is 0mg
- 4. $E_{max}$ is the maximum effect attributable to the drug
- 5. $ED_{50}$ is the dose that produces half the effect
- 6. $D_i$ is the dose level for the $i$th patient
- 7. $\epsilon_i$ is the random error for the $i$th patient. A standard assumption, adopted here, is that the $\epsilon_i$ terms are independent and identically distributed with a mean of 0 and variance $\sigma^2$. An additional standard assumption is that the error terms are normally distributed.

Further, assume that $y_i\sim N(\mu_i, \tau)$, where $\tau=1/\sigma^2$ is the precision. For the Bayesian analysis, prior assumptions are made around the distribution of the parameters of the hyperbolic model, i.e., by assuming some distributions around the parameters of the model (i.e., $E_0, ED_{50}$, and the precision parameter $\tau$).

For a binary outcome, the model can be readily revised to be a generalized hyperbolic model using a logit link,

$\log \frac{\pi}{1-\pi} = E_0 + E_{\max} \tilde{A} - \frac{D_i}{ED_{50}+D_i},$

where $\pi$ is the observed response rate.

## 8.3 Analysis Examples for a Continuous Endpoint

### 8.3.1 Asthma Trial with 75 Patients Per Group

Consider a phase IIb study in asthma assessing the response of a new entity in a clinical trial. The typical phase II endpoint of interest is FEV1 (forced expiratory volume in 1 second) which is a common spirometry test that is used in asthma studies. An advantage of the FEV1 endpoint is that the length of follow-up required to observe changes is much shorter than the typical phase III endpoint of exacerbations. The FEV1 endpoint is continuous and can be assumed to be normally distributed. The sponsor ran a couple of phase IIa studies for this experimental drug; the first study tested the effect of the maximum tolerated dose (MTD), the second study tested another closer to the MTD and a low dose. Based on these two previous studies we have some understanding of the dose-response. The pre-clinical studies on this compound provide some understanding of the dose-response. The current study explores a wide dosing range; let us assume that the trial data are available and we will analyze the data in light of the knowledge we gained in the previous trials. For purposes of this example, code for simulating sample data is provided in Example Code 8.1.

```sas
%macro conexism(ntrt,r0,r1,r2,r3,r4,r5,r6,r7,r8,npergrp,pdrop,seed);
  data sims (keep subject dose response);
    format treatment $8;
    subject = 0;
    %do trt = 0 to &ntrt;
      do i = 1 to &npergrp;
        subject = subject + 1;
        if &trt = 0 then do;
          treatment = "Placebo";
          dose = 0;
        else do;
          treatment = "Active";
          dose = 3**(&trt-1);
        end;
        response = 0.35*ror(floor(&seed)) + &&trt;
        dropout = ranbin(floor(&seed), 1, &pdrop);
        if dropout = 0 then output;
      end;
    %end
%mend;

proc sort data = sims;
  by dose;
run;

proc means data = sims;
  var response;
  output out=sumstat mean=mean sum=sum n=n std=sd;
  by dose;
run;

  data sumstat (keep = mean dose n sd);
    set sumstat;
  run;
```
