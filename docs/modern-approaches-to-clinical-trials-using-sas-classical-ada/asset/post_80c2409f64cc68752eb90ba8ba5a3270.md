
$\frac{\partial p_C}{\partial p_E} = \frac{\rho(1-p_E)}{2p_E}$ and $\frac{\partial p_E}{\partial p_C} = \frac{\rho(1-p_C)}{2p_C}$. One can easily show that the lower bound for the variance of $N_E(m)/m$ (the asymptotic variance of ERADE) is

```
$\sigma^2_{ERADE} = \frac{1}{4(\sqrt{p_E}+\sqrt{p_C})^2}\left(\frac{\rho p_C}{\sqrt{p_E}} + \frac{\rho p_E}{\sqrt{p_C}}\right). \quad (10.9)$
```

The asymptotic variance of DBCD($\gamma$) (Section 10.3.3) is

```
$\sigma^2_{DBCD(\gamma)} = \frac{\sqrt{p_Ep_C}}{(1+\gamma)(\sqrt{p_E}+\sqrt{p_C})^2} + \frac{2(1+\gamma)}{1+2\gamma}\sigma^2_{ERADE}. \quad (10.10)$
```

The asymptotic variance of the SMLE procedure, $\sigma^2_{SMLE}$, is obtained by calculating $\sigma^2_{DBCD(\gamma)}$ with $\gamma=0$. Clearly, $\sigma^2_{SMLE} > \sigma^2_{DBCD(\gamma=2)} > \sigma^2_{ERADE}$:

Figure 10.2 is a plot of asymptotic variance $N_E(m)/m$ of three RAR designs (SMLE, DBCD($\gamma$), and ERADE) for a range of scenarios when $p_C=0.4$ and $0.2 \le p_E \le 0.9$. Interestingly, the variance is monotone decreasing as $p_E$ is increasing from 0.2 to 0.9. For SMLE the variance is decreasing from 0.6 to 0.38; for DBCD($\gamma=2$) it is decreasing from 0.26 to 0.12; and for ERADE it is decreasing from 0.18 to 0.06. For a completely randomized design (CRD) targeting 1:1 allocation (a non-adaptive procedure for which every allocation is made independently with probability 1/2), the variance is constant, 0.25, for any values of $p_C$ and $p_E$. As such, in the considered scenarios both DBCD($\gamma=2$) and ERADE are overall less variable than CRD.

## 10.4 Simulation of Optimal Response-Adaptive Randomization Procedures

### 10.4.1 Simulating a Single RAR Sequence

The target allocation ratio is pre-specified (e.g. 1:1 or 2:1), a treatment randomization sequence can be pre-generated before any subject is enrolled into a trial. In contrast, a RAR sequence cannot be pre-generated because treatment randomization probabilities are adaptively modified throughout the trial based on cumulative patient outcome data.

Standard computer packages such as SAS as R have built-in random number generators that can be used to simulate RAR designs under certain assumptions on outcomes from patients in trial. We start with a simulation of a single randomization sequence. Program ch10.4.1.sas in the supplemental material generates a sequence of assignments for a trial with $n=40$ patients using the DBCD$(\gamma=2)$ procedure (Section 10.3) targeting the RSIHR allocation (10.2). We assume that the true success probabilities for the treatments are $p_E=0.7$ and $p_C=0.4$, and therefore, $\rho=\sqrt{0.7}/\sqrt{0.7+0.4}=0.57$. The first $2m_0$ patients are randomized between $E$ and $C$ using equal randomization (in Program ch10.4.1.sas, we set $2m_0=10$). Specifically, randomization probability to $E$ for the first 10 patients is set to

```
$\phi_E=\frac{1}{2}, \quad \phi_{m+1}=\frac{5-N_E(m)}{10-m}, \quad m=1,...,9$
```

where $N_E(m)$ is the number of treatment $E$ assignments among the $m$ patients. The response-adaptive part starts from the 11th patient. The randomization probability for the $(m+1)$th patient ($m\in\{10,39\}$) is determined as follows. Assuming that all outcome data from previous $m$ patients are available, obtain $N_E(m), N_C(m), S_E(m), S_C(m)$, and estimate treatment success probabilities as $\hat{p}_{k,m}=(S_k(m)+0)/(N_k(m)+1)$. Note that $\hat{p}_{k,m}$ are Bayesian estimates under a noninformative prior, prior to estimated success probabilities equal to zero or one. The estimated target allocation is updated as $\hat{\rho}_m=\hat{p}_{E,m}/\sqrt{\hat{p}_{E,m}+\hat{p}_{C,m}}$, and the randomization probability to $E$ for the $(m+1)$st patient is set to

```
$\phi_{m+1} = \frac{\hat{p}_{E,m}^2}{N_E(m)/m + \frac{(1-\hat{p}_{E,m})^2}{N_C(m)/m}},quad m=10, \dots, 39$
```

The $(m+1)$st patient, a uniform random number $U_{m+1}\in[0,1]$ is generated, and the following rule is applied: If $U_{m+1} \le \phi_{m+1}$, assign $E$; else if $U_{m+1} > \phi_{m+1}$, assign $C$.
