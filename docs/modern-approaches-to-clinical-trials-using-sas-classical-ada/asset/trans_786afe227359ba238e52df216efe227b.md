

## 2.4.4 消耗函数边界

错误消耗函数是推导停止边界的最灵活且通用的方法。预设 $\alpha$ 水平的 $\alpha$-消耗函数被用于控制试验中的一类错误。它们是定义在单位区间上的单调函数，并满足 $\alpha(t)=0$ 且 $\alpha(t)=\alpha$。同样，预设 $\beta$ 水平的 $\beta$-消耗函数用于控制二类错误。它们定义在单位区间上，并满足 $\beta(t=0)$ 且 $\beta(t=1)=\beta$。这种使用错误消耗函数的思想最早由 Lan 和 DeMets [10] 提出。在单次试验的序贯监测中，单独使用 $\alpha$ 消耗函数或 $\beta$ 消耗函数，也可以将两者结合使用。它们可以用于单侧或双侧假设，并产生对称或非对称的边界。

目前已经提出了许多错误消耗函数，我们将简要描述其中三个最常用的消耗函数及其属性。函数的形式表示为 $\alpha(t)$ 和 $\beta(t)$，其中 $t(0 < t < 1)$ 是信息比例。这里我们说明 $\alpha$-消耗函数，但它也适用于 $\beta$-消耗函数。

- 1. Lan-DeMets 消耗函数有两种可能的形式。第一种与 OBF 边界相似：

$\alpha(t)=2-2\Phi\left(\frac{Z_{\alpha/2}}{\sqrt{t}}\right)$ 用于单侧检验，以及

$\alpha(t)=4-4\Phi\left(\frac{Z_{\alpha/4}}{\sqrt{t}}\right)$ 用于双侧检验。

第二种与 Pocock 边界相似：

$\alpha(t)=\alpha\ln<1+|\theta-1t|>$

- 2. Gamma 消耗函数最早由 Hwang、Shih 和 DeCani [24] 提出。函数形式为：

$\alpha(t) = \begin{cases} a\frac{(1-e^{-\gamma t})}{(1-e^{-\gamma})}, & \gamma \neq 0; & \gamma = 0 \end{cases}$

$\gamma$ 的负值产生的消耗函数随着 $\gamma$ 的减小而使得早期停止变得更加困难。$\gamma$ 的正值产生的凹性消耗函数随着 $\gamma$ 的增加而有利于早期停止。选择 $\gamma=0$ 时，错误是线性消耗。当 $\gamma=-4$ 时，它类似于 OBF 边界，而 $\gamma=1$ 产生的边界类似于 Pocock 边界。

- 3. Rho 消耗函数最早由 Kim 和 DeMets [25] 提出，并被进一步泛化。其函数形式简单表示为：

$\alpha(t) = \alpha t^{\rho}, \rho > 0$

当 $\rho=1$ 时，相应的停止边界类似于 Pocock 停止边界，但当 $\rho=3$ 时，边界类似于 OBF 边界。$\rho$ 的大值使得早期停止变得更加困难，而 $0 < \rho < 1$ 则有利于早期停止。

在这里，我们想通过一个示例说明如何在单侧设置下，为早期拒绝原假设或备择假设推导边界。该设计有两组停止边界。上边界组对应早期拒绝原假设，而下边界指的是早期拒绝备择假设。在第 $j$ 个中期阶段，如果检验统计量越过上边界，则试验因有效性而停止；但如果它越过下边界，则试验因效用而停止。我们施加约束，使得上下边界在试验结束时 $t_j$ 处相交，以确保做出拒绝任何一个假设的决策。上下边界形成了一个三角形继续区域。

我们规定，在原假设下，这些停止边界能够在 $\alpha$ 水平保持一类错误。
