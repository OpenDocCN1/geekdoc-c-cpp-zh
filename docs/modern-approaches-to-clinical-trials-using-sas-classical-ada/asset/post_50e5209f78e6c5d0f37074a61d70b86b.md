Below are the steps planned for sample size re-estimation using the promising zone approach:

- 1. The initial sample size of 504 subjects is computed as in the classical design with 80% power to detect $\delta = 0.25$ with a one-sided $\alpha = 0.025$ test.

- 2. An interim analysis is planned when 252 subjects reach the primary endpoint.

- 3. An O'Brien Fleming-like critical value ($c_1$) is computed using a gamma spending function with $\gamma = -4$.

- 4. The trial is stopped if the test statistic crosses $c_1$ at an interim analysis.

- 5. If test statistic does not cross $c_1$; then the conditional power is computed using the estimated value of treatment difference. If the conditional power is between 30% and 80%, then the sample size is re-estimated to achieve 80% conditional power at the estimated treatment difference. The sample size is increased to a maximum of 1008, twice the original sample size of 504. If the re-estimated sample size is more than 1008, the final sample size is capped at 1008. If the conditional power is less than 30% or greater than 80% the study continues with the original sample size of 504 subjects.

On average, the trial will land in the promising zone around 25% of the time. The promising zone approach gives the additional flexibility so that the sample size is increased only if the results are promising at an interim analysis. This example is just an illustration on how to evaluate the promising zone approach. In practice, extensive simulations aligned to the project needs should be conducted to ensure desirable properties. For example, the minimum and maximum conditional power for the promising zone can be altered or an additional futility boundary can be added.

The adaptive and group sequential designs in Operating Characteristics of Classical and Group Sequential Design and Operating Characteristics of Classical and Adaptive Design are generated using the SAS macro %SSR_CP in Example Code 3.4 SAS Macro SSR_CP.

Below we briefly summarize the macro. The initial macro calls are the following:

- 1. nSamp = number of simulations

- 2. alpha = desired $\alpha$ level

- 3. beta = desired $\beta$ level

- 4. cont = control response to be simulated

- 5. trt = treatment response to be simulated

- 6. delta = difference between treatment and control response

- 7. Nmax = maximum sample size to be committed

- 8. r = randomization ratio of treatment and control

- 9. t = timing of interim analysis

- 10. c1 = efficacy boundary at interim analysis in the standardized $Z$ scale

- 11. c2 = efficacy boundary at the final analysis in the standardized $Z$ scale

In the macro %SSR_CP, Nmax is set to initial sample size of 700 for group sequential, while it is set to a total sample size of 1008 for SSR design. After Stage 1, the conditional power (CP) is calculated and the trial is categorized into four zones:

- 1. UNFAVORABLE (CP < 0.3)
- 2. PROMISING (0.3 ≤ CP ≤ 0.8)
- 3. FAVORABLE (CP > 0.8 and $Z_1 < c_1$)
- 4. EFFICACY (CP > 0.8 and $Z_1 \ge c_1$)

The sample size is set to 504 (fixed) in unfavorable and favorable zone; in the efficacy zone the trial is stopped with a sample size of 504 ($n_1$), while the sample size is re-estimated in the promising zone so that the conditional power is 80%. If the re-estimated sample size is greater than 1008, the final sample size (final) is set to 1008. %Macro SSR_CP(Namp,alpha,beta,sigma,cont,trt,delta,Nmax,r,t,c1,c2,title=);
data SSR;
/** randomization allocation **/
/** total sample size by n and total number of subjects in each group by (1-r) and n2 = r so that the fraction of subjects in active r and total sample size is 
size=$delta.*ceil(probit(1-alpha)+probit(1-beta));
/** Total Size at Interim Analysis **/
nl=(c1.*fixed);
n2=fixed-nl;
c_seed1=736; t_seed1=624;
c_seed2=786; t_seed2=819;

do i=1 To Namp;
nl=round((1-r).*nl);
n2=round(r).*nl);
cont=Rannor(c_seed).*sigma/sqrt(n1);
trt=Rannor(t_seed1).*sigma/sqrt(n2);
deltah1=trt-c1;
sel=$sigma/sqrt(1/nl/(1-r));
Z1=deltah1/sel;
/** Calculate Conditional Power **/
cp=1-probit(c2).*sqrt(n1/(fixed-n1))-Z1*(n1/(fixed-n1))-deltah1*sqrt(&(1-r).*sqrt(fixed-n1)/sigma);
if cp < 0.3 or cp <= c1 then zone="PROMISING";
else if (cp > 0.8) and Z1 >= c1 then zone="FAVORABLE";
else if (cp > 0.8) and Z1 < c1 then zone="EFFICACY"

fixed=fixed;
w1=sqrt(n1/nl);
w2=sqrt(n2/n2);
if zone("PROMISING") then do;
a=c2./w2;
zbt=Probit(1-beta);
k=w2;
n2tilda=n1*((a+zbt)/z1-k)**2)+nl;
end;
n2tilda=n2tilda;
rejectho=0;
estop=0;
if zone("EFFICACY") then do;
n2tilda=n1;
rejectho=1;
zch=z1;
estop=1;
end;

if n2tilda > nmax then final=nmax;
else n2tilda=n2tilda;
/****** Simulate Data for Stage II *******/
cont2..trt2,r2,zch=z1;
if final=n1 then do;
n21=round((1-r)*(final-n1);
n22=round(r)*(final-n1));
cont2 = Rannor(c_seed2)*sigma/sqrt(n21)+cont;
trt2 = Rannor(t_seed2)*sigma/sqrt(n22)+trt;
deltah2=trt2;
se2=$sigma*sqrt(1/((final-n1)*r*(1-r)));
Z2=deltah2/2;
zCHW=z1*W2*Z2;
end;
if ZCH < c2 then rejectho=1;
else rejectho=rejectho;
output;
end;

/** Calculating the power and average sample size */
ods listing;
PROC MEANS DATA=SSR;
CLASS Zone;
VAR final rejectho estop;
OUTPUT Out=Results MEAN=AveSS Power ESTOP;
run;

data results;
set results;
if _type="0" then zone="Overall";
else zone=Zone;
drop _type__freq;
run;

ods listing;
title "&title";
Proc Print data=Results noobs;
run;

/* Calculating the number of times in the promising zone */
title "&Zone Frequency - &title";
Proc freq data=ssr;
tables zone;
run;
mend SSR_CP;
