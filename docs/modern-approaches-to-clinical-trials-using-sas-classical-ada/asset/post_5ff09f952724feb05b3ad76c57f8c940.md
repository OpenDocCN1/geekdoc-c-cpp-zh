
# Appendix

## Macro Call

The SAS macro BSMED could be stored in a folder named BSMED. Then %BSMED can be accessed by including the following lines:

```sas
%include BSMED (macroBSMED.sas);

%BSMED (HIST=, CURR=, delta=, eta0=, nbi=, a0=, NMCS=, REP=, sigma0=, sigmal=, tau0=, tau=, SEEDGEN=, OUTPUT=);
```

## Inputs

Below are the requirements for BSMED:

### Required Inputs

- 1. `curr`: data set with the seven columns, $K$ (trial ID) in the same format as for the historical data, $n$ (the total sample size), $p$ (the proportion of subjects in the control arm), $r$ (the annualized event rate), TD (the trial duration), and TA (the accrual time), where all variables should be arranged in columns. TF (the minimal follow-up time) is easily calculated using TA and TD.
- 2. `delta`: indicates a prespecified design margin of non-inferiority trial.
- 3. `eta`: indicates the user's choice of a Bayesian credible level in calculating the Bayesian type I error and power.
- 4. `nmcs`: indicates the number of Markov chain Monte Carlo (MCMC) samples.
- 5. `obi`: indicates the number of burn-in samples in each run of PROC MCMC.
- 6. `a0`: indicates a discounting parameter for the historical survival-experimental data.
- 7. `rep`: indicates the number of simulated data sets.
- 8. `sigma0`: indicates the initial prior variance of the parameter $\gamma_0$.
- 9. `sigma1`: indicates the initial prior variance of the parameter $\gamma_1$.
- 10. `tau0`: indicates the initial prior variance of the parameters, $\theta_{0K}$, for the historical data sets.
- 11. `tau`: indicates the initial prior variance of the parameters, $\theta_k$, for the current data sets.
- 12. `SEEDGEN`: indicates the initial seed to generate sets of seed numbers in generating predictive data and running MCMC.

### Optional Inputs

- 1. `HIST`: data set with the first three columns, $K$ (trial ID), $y$ (total subject year duration), $v$ (total number of events), and an additional column for treatment indicator ($x$), where $K$, $y$, and $v$ should be placed after column 3. Note that $x$ is an indicator variable of the treatment arm, which takes a value of 0 if it comes from the control arm and 1 if it comes from the experimental arm. The values of $K$ should be consecutive integers starting with 1. For example, if the total number of historical data sets is 5, the values of $K$ should be enumerated as 1, 2, 3, 4, and 5.
- 2. `OUTPUT`: name of the output text file (RTF). One can also specify a directory/folder where the file will be stored. For example, the output file named $output\_a0$ will be stored in $c:\...\BSMED$ by $BSMED(OUTPUT=c:\\...\\\BSMED)$. If OUTPUT is not specified, the file will be indexed by the name $BSMED\_Output\_a0$ as default. In the filename, $a0$ indicates a discounting parameter for the historical survival meta-experimental data that the user specifies in the macro.

## Notes

- 1. The name of the $K$ (trial ID) variable in HIST should be the same as that of the $K$ (trial ID) variable in CURR.
- 2. TD and TA should be in the same time unit as years.
- 3. TD is always greater than TA, and TD is allowed to be greater than or equal to less or equal to the sum of TA and TF.
- 4. The indicator variable $x$ must be coded as 0 and 1.
- 5. No missing values are allowed in both data sets. However, it is possible to leave a blank in historical data sets if historical data are not available.
- 6. Four different types of historical data sets are allowed:
    - a. hist1: only the control arm
    - b. hist2: only the experimental arm
    - c. hist3: both the control and experimental arms
    - d. hist4: mixed control and experimental arms.
- 7. The total number of trials in the current data is allowed to be 1 or greater and the total number of trials in the historical data is also allowed to be 1 or greater.

## Output

The macro automatically produces an RTF file indexed by the user-specified name. If a user does not specify the filename, the macro uses the filename as BSMED_Output_a0.rtf by default. The RTF file includes five tables:

- 1. Historical Data if a filename is specified in HIST=
- 2. Current Data with the Input Variables
- 3. Design Values
- 4. Type I Error for the Bayesian Survival Meta-Experimental Design
- 5. Power for the Bayesian Survival Meta-Experimental Design.

Note: In the absence of historical data, the macro does not produce the table for historical data and thus, it produces only four tables instead. For historical data, the macro allows users to input four different types of data sets. In the construction of tables for the Bayesian type I error and power, the macro produces three tables.

## Running Time

It takes approximately 2 hours to run this macro for 5,000 simulated sets.
