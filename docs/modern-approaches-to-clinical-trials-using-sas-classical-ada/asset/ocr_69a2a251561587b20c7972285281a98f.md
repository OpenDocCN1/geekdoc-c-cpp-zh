$\phi_{m+1}, E = \frac{\hat{p}_m^2}{N_E(m)/m}}{\frac{\hat{p}_m^2}{N_E(m)/m} + \frac{(1-\hat{p}_m)^2}{N_C(m)/m}}, m=10, \dots, 39$

The $(m+1)$st patient, a uniform random number $U_{m+1} \in[0,1]$ is generated, and the following rule is applied:

If $U_{m+1} \le \phi_{m+1}$, assign treatment $E$; else if $U_{m+1} > \phi_{m+1}$, assign treatment $C$.
