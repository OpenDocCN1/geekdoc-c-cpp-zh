# 4.6.2 Sampling from the Posterior Distributions

Under the model in (4.3), using (4.4) and (4.10), the posterior distribution of $(\gamma, 	heta_D, 	heta_0)$ is given by

$\pi(\gamma, 	heta_D, 	heta_0 | D_K, D_0) \propto \Pi_{k=1}^2 \Pi_{j=1}^2 \exp \{v_{jk}(\gamma_0 + \gamma_1 x_{jk} + \theta_k)\}\}$

$$\times \exp\{-\gamma_0 + \gamma_1 x_{jk} + \theta_k)v_{jk}\}\}$

$$\times \{\Pi_{k=1}^{K_0} \Pi_{j=x01}^{x02k} (exp \y_{0,j} + l_k(\gamma_0 + \gamma_1 + \theta_k))}\}$

$$\exp \exp\{-\gamma_0 + \gamma_1 j + y_{0,j} + l_k)\}\^{\theta_0^0} \pi_0^{(f)}(\theta_0^{(f)}(\gamma). (4.11)$

We use the Gibbs sampling algorithm to sample from the posterior distribution in (4.11) given $D_K$ and $D_0$. The Gibbs sampling algorithm requires sampling from the full conditional distribution of each parameter given the other parameters. First, the full conditional density for $[\gamma | \tilde{	heta}_D, \tilde{	heta}_0, D_K, D_0]$ is given by

$\pi(\gamma | \tilde{	heta}_D, \tilde{	heta}_0, D_K, D_0) \propto \Pi_{k=1}^2 \Pi_{j=1}^2 \exp \{v_{jk}(\gamma_0 + \gamma_1 x_{jk})}\}$

$$\exp \exp\{-\gamma_0 + \gamma_1 x_{jk} + \theta_k)v_{jk}\}\}$

$$\times \{\Pi_{k=1}^{K_0} \Pi_{j=x01}^{x02k} (exp \y_{0,j} + l_k(\gamma_0 + \gamma_1 + \theta_k))}\}$

$$\exp \exp\{-\gamma_0 + \gamma_1 j + y_{0,j} + l_k)\}\\} \exp \{-\frac{1}{2} \gamma^T \Sigma_{\gamma}^{-1} \gamma\}, (4.12)$

where $\Sigma_{\gamma} = \text{diag}(\sigma_0^2, \sigma_f^2)$ denotes a $2 \times 2$ covariance matrix of $\gamma$.

The full conditional density for $[\theta_0 | \tilde{	heta}_D, D_0, \a_0]$ is given by

$\pi(\theta_0 | \tilde{	heta}_D, D_0, \a_0) \propto \Pi_{k=1}^{K_0} \Pi_{j=x01}^{x02k} (exp \y_{0,j} + l_k(\gamma_0 + \gamma_1 + \theta_k))}\}$
