In that case, the critical value has to be calculated accounting for the possibility of early stopping. The decision tree for a combination method takes the following form:

# End of Stage 1

+   - If $p_1 < \alpha_1$, the trial stops early for efficacy

+   - If $p_1 > eta_1$, the trial stops early for futility

+   - If $p_1 < \alpha_1 < eta_1$, the trial continues into Stage 2, possibly with sample size change

# End of Stage 2

+   - Decision to reject $H_0$ is made based on $C(p_1, p_2) \le c_\alpha$.

When calculating $c_\alpha$ in the above case, the overall type I error is

$Pr(p_1 < \alpha_1) + Pr(\alpha_1 < p_1 < eta_1) \cap C(p_1, p_2) \le c_\alpha)$,

where probabilities are calculated under the null hypothesis of no treatment difference. For the sake of simplicity, we put aside the issue of early efficacy/futility stopping and focus on unblinded SSR as the only adaptation for the remainder of this chapter.

Th most widely used combination tests include Fisher’s combination test and the inverse method discussed below. Both combine pvalues. Because there is a one-to-one correspondence between p-values and test statistics, they can also be viewed as test combination methods. In Fisher’s combination test, $C(p_1, p_2) = p_1p_2$. In the case of the inverse normal method [21],

```
$C(p_1, p_2) = 1 - \Phi[\Phi^{-1}(1-p_1) + w_2\Phi^{-1}(1-p_2)], 0 < w_2 < 1, w_1^2 + w_2^2 = 1 (3.1)$
```
