+   2. How to set the final decision rule to accept/reject the null hypothesis so that type I error is preserved?

+   3. How to estimate the treatment effect in the final analysis?

Among these three issues, type I error control is probably the most researched topic in the statistical literature. The issue of determining the new sample is closely related to controlling type error (just like power and type I error are related when planning a fixed-size trial) but it has some "degree-of-freedom." Most type I error control methodologies focus on defining an end-of-study rule for accepting or rejecting the null hypothesis following the unbiased SSR, but they leave some freedom as to how the new sample size is actually selected. This is understandable sample size decisions are often heavily influenced by non-statistical considerations such as budget, regulatory, and market requirements. Because of the close relationship between issues #1 and #2 for some methods, we will discuss SSR methods in conjunction with type I error control, on a method-by-method basis.

Concerns over the final study analysis (estimation and confidence intervals) are not discussed here because the related literature is generally less mature and is still an active area of research for some methods. Nonetheless, estimation deserves attention because computing classic-point estimates and associated confidence intervals (CIs) following a trial with unbiased SSR may lead to biased results. Even if the final study inference is well defined and preserves the type I error rate, the methodology to compute point estimates and associated confidence intervals still needs to be addressed. At a minimum, simulations should be performed to quantify the magnitude of bias (often very small). For some methods, the theoretical framework addressing estimation at the end of trial is available [19-20].
