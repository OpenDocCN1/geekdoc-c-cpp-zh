# 2.3.3 Binomial Endpoint

In this section, we consider a randomized clinical trial comparing a test treatment, $T$, to a standard control treatment, $C$. We assume that the efficacy endpoint is now a binary response variable, $X$, which takes on the value of 1 if the response occurs or 0 otherwise, such that $P(X_T=1) = \pi_T$ and $P(X_C=1) = \pi_C$ where $X_T$ and $X_C$ are the response variables for the experimental and control treatments, respectively. We want to monitor the trial up to $J$ times after accruing $n_1, n_2, \dots, n_J$ patients. The information fraction at the $j$th stage is given by $t_j = n_j / n$. We let $r$ be the fraction of subjects allocated to the experimental treatment.

Similarly, we define the treatment effect to be the difference in probabilities

$\theta = \pi_T - \pi_C$.

Other parameters such as an odds ratio can also be used and its logarithm (i.e. logit) is usually assumed to be normally distributed when the sample size is sufficiently large. The null hypothesis of interest is

$H_0: \theta = 0$.

We want to construct a $j$-stage group sequential level-$\alpha$ test having desired power of $1-\beta$ at the alternative hypothesis

$H_1: \theta = \theta_1$.

We can further let $\hat{\pi}_T(t_j)$ and $\hat{\pi}_C(t_j)$ be the sample means, which are also the maximum likelihood estimators of $\pi_T$ and $\pi_C$ respectively, at time $t_j$ such that

$\hat{	heta}(t_j) = \hat{\pi}_T(t_j) - \hat{\pi}_C(t_j)$

$Var[\hat{	heta}(t_j)] = \frac{\pi_T(1-\pi_T)}{n_J r} + \frac{\pi_C(1-\pi_C)}{n_J(1-r)}$
