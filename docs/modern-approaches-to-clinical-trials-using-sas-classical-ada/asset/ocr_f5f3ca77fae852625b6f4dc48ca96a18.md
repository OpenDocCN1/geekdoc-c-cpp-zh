# 3.3.4 Sample Size Re-estimation Based on Promising Zone

# 3.3.4.1 Overview

This method builds on a series of work by several authors [3, 27, 28]; we will base our description on [3]. The core idea of this method is to derive a sample size re-estimation rule based on the conditional power, and use a standard (i.e. non-modified) statistic to test the null hypothesis at the end of trial. In order to protect type I error, the authors of [3, 27, 28] restrict the set of conditions under which such procedures can be performed rather than modifying the final analysis.

The idea of using conditional power for interim decisions is not really new or unique to this method. For example, the extensive discussion in [21] who, among other things, point out that when observed treatment effect is small, the resulting SSR procedure based completely on the fact that the conditional power has undesirable properties of the new sample size being too large. Also, the fact that most SSR methods have to use a non-standard test statistic at the end of the trial to control for type I error rate creates some room for potential inconsistency in the final study inference between classical methods (GSD) and most unblinded SSR designs.

The promising zone design of Mehta and Pocock attempts to alleviate these concerns by using a conventional (in a sense of GSD) Wald test statistic $Z_M$ for the final decision, although even if the final sample size is increased in a data-dependent manner, the overall type I error rate will not be inflated, provided that the sample size modifications are not too extreme [3].
