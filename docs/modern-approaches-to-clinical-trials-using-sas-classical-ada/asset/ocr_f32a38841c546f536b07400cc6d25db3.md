$$\beta_{sl}^{(n)} = E_{sl}[1\{P(e^{\gamma_1} < \delta D_K, \pi^{(f)}) \geq \eta_0\}], \quad (4.9)$

where the indicator function $1_{\\mathbb{A}}$ is 1 if $\mathbb{A}$ is true and 0 otherwise, $0 < \eta_0 < 1$ is a prespecified Bayesian credible level, the posterior probability $P(e^{\gamma_1} < \delta D_K, \pi^{(f)})$ is computed with respect to the posterior distribution of $\gamma_1$ given the data $D_K$ under the fitting prior $\pi^{(f)}[\gamma, \theta]$, and the expectation $E_{sl}$ is taken with respect to the predictive marginal distribution of $D_K$ under the sampling prior $\pi_l^{(s)}[\gamma, \theta]$ for $l=0,1$. From (4.9), we note that the quantities $\beta_{s0}^{(n)}$ and $\beta_{s1}^{(n)}$ correspond to the Bayesian error and power, respectively.
