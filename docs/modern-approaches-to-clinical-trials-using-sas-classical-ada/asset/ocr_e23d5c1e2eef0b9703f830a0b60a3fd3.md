there is increased efficacy in the new treatment compared to the control. At the interim look, there can be five decisions for overwhelming efficacy that can be made: (1) stop the trial for overwhelming efficacy in the Op; (2) continue the trial in Op, if the efficacy is moderate in both Op and Sp; (3) continue the trial in Sp if the efficacy is slightly better in than Op with the co-primary subgroup hypothesis at the end of the trial; (4) enrich to include only Sp at the final analysis if the efficacy is much better than the Op; (5) stop the trial for utility if the treatment is not going any better than the control. Each of the possible presspecified decisions will differ in the sample size and in the follow-up post-interim analysis. The patients who start in the first stage will remain in the study and will be monitored for their long term (final) endpoint.

Wang et al. [45] proposed a similar design but only for a single normally distributed endpoint. We present the % subpower macro for design formulations.

The % subpower macro (Example Code 11.9 Subset Power Macro) calculates the subset power given:

+   1. f: the sample size ratio

+   2. alpha_a: the significance level for testing the overall population

+   3. beta_a: type II error of the overall trial

+   4. es_ratio: effect size ratio, es_ratio = delta_g +delta

+   5. alpha_g: the significance level for testing the subgroup population.

# Example Code 11.9 Subset Power Macro

```
%macro subpower(f,alpha_a, beta_a, es_ratio, alpha_g);
  data result;
    f=&f;
    alpha_a=\&alpha_a;
    beta_a=\&beta_a;
    es_ratio=&es_ratio;
    za=quantile('Normal', 1-alpha_a);
    zb=quantile('Normal', 1-beta_a);
    zag=quantile('Normal', 1-alpha_g);
    d=sqrt(&f)*es_ratio*(za+zb)-zag;
    sub_power=normCDF('Normal', d);
  label es_ratio="effect size ratio";
  label f="sample size ratio";
```
