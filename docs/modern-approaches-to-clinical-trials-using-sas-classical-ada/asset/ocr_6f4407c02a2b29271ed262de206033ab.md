In contrast, the naive method may simply discard the missing data as if no toxicity would ever occur in the future, which inevitably loses useful information for decision making.

To fully utilize the follow-up time information, more data need to be collected during the trial conduct, for example, patients' enrollment dates, decision-making dates (censoring times), and the dates of toxicity occurrences (event times). For subject $i$, let $t_i$ denote the time to toxicity occurrence, and let $u_i (u_i \le 	au)$ denote the actual follow-up time (up to the decision-making time on dose assignment for the next cohort) that censor $t_i$. We assume $u_i$ to be independent of $t_i$, because the arrival time of a new cohort is typically independent of the time to toxicity due to patients' staggered entry. Censoring arises when patients have not completed the follow-up to $	au (u_i < 	au)$. If the toxicity event of subject $i$ is censored, the fractional contribution of this subject is given by

$Pr(t_i < \tau | t_i > u_i) = \frac{Pr(u_i < \tau)}{Pr(t_i > u_i)}$

which is the conditional probability of occurrence of the toxicity event in $(u_i, \tau)$ given that no toxicity has occurred yet by time $u_i$. As a result, the collected data in the trial include 0, 1, and some fraction between 0 and 1. The fractional contribution for a censored toxicity outcome can be easily estimated by

$$\hat{y}_i = \frac{\hat{S}(\tau)}{\hat{S}(u_i)}$

where $\hat{S}(\cdot)$ is the usual Kaplan-Meier estimator. More specifically, for subject $i$, we define $y_i=0$ if the DLT has not occurred by time $\tau$, $y_i=1$ if the DLT has occurred by time $\tau$, or $y_i=\hat{y}_i$ if the DLT is censored before time $\tau$.
