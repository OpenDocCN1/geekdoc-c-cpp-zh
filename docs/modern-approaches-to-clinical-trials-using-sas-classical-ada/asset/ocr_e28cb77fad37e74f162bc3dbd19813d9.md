```
$$\min_{\rho\in(0,1)} n\q_{EP} + q_C(1-\rho)\}\ns\ t \frac{\rho q_{EP}}{n_P} + \frac{(1-\rho)q_C}{n_C} = const$
```

The optimal solution is the RSIHR allocation named after Rosenberg, Stallard, Ivanova, Harper, and Ricks [10]:

```
$*PRSIHR = \frac{\sqrt{q_E}}{\sqrt{q_E}+\sqrt{q_C}} (10.2)$
```

Unlike the Neyman allocation, RSIHR allocation always assigns a greater proportion of patients to the more successful treatment.

Now consider testing the hypothesis of equality of treatment effects using the score test based on the log-odds ratio, $\theta=\log\{q_{EP}/q_{CE}\}$. For testing $H_0:\theta=0$, one computes $Z=(n_{SE}-n_{SC})/n$ and $V=n_{SE}n_{SC}/n^3$, where $S_E$ and $S_C$ are the number of successes on $E$ and $C$, $S=S_E+S_C$ and $F=n-S$. When $n$ is large, $Z$ is approximately normally distributed with mean $\theta$ and variance $V$. Using the large sample approximations $S=n\rho$ and $F=n(1-\rho)$, where $\rho=(n_{EP}+n_{PC})/n$, the variance of the score statistic is approximated as

```
$V=n_P\rho(1-\rho)(\rho q_{EE}+(1-\ho)q_{CE})(\rho q_{AE}+(1-\ho)q_{CE})$.
```
