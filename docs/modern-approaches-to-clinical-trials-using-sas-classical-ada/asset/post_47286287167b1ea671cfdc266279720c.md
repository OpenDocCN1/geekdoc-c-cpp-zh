
## 7.4 Further Considerations on MCP-Mod

The original MCP-Mod procedure from Bretz et al. was motivated by the work of Tukey et al., who proposed to use several trend tests simultaneously based on different functional dose-response descriptions and subsequently to adjust the resulting p-values for multiplicity [2,13]. Since then, the methodology has been the subject of several investigations. Thomas and Wakana et al. investigated extensions to Bayesian methods for estimating or selecting the dose-response curve from a sparse design [14,15]. Klingenberg applied the MCP-Mod approach to proof-of-concept studies with binary responses [16]. Benda proposed a time-dependent dose finding approach with repeated binary data [17]. Akacha and Benda investigated the impact of dropouts on the analysis with recurrent event data [18]. Wouter extended the MCP-Mod approach to investigate longitudinal toxicological data [19]. Tao et al. incorporated both efficacy and safety endpoints through point modeling [20]. Dette et al., Baeyen et al., Gutjahr and Bornkamp investigated the use of likelihood ratio tests instead of multiple contrast tests [21-23]. Miller, Tanaka, and Franchetti et al. extended the MCP-Mod approach to flexible, two-stage designs that include the possibility to perform adaptations (e.g. adding or dropping doses) under a strict FWER control [24-26]. Dragalin et al., Bornkamp et al., and Vandemeuleebroecke et al. investigated the MCP-Mod procedure in response-adaptive designs, addressing two major challenges in dose-finding studies: uncertainty about the dose-response models and large variability in parameter estimates [27-29].

## 7.5 Analysis Examples Using SAS

### 7.5.1 The optcont Macro

In this section we will illustrate the application of MCP-Mod with two examples and show how to implement it using SAS. The first example illustrates the original MCP-Mod procedure for normally distributed data, as described in 7.2.1 Original MCP-Mod Approach, using a model selection approach. In this situation proc glmix can be used for the MCP step, because it allows for the calculation of the multiplicity adjusted p-values. Proc nlmixed can be used for fitting the associated nonlinear regression models and estimating target doses. The second example illustrates a more complex application of MCP-Mod in the context of a linear mixed-effect model. In this generalized, two-step MCP-Mod methodology described in 7.2.2 MCP-Mod for General Parametric Models is used. In this we also illustrate the application of a bootstrap model-averaging to perform inferences on the dose-response curve and target doses. proc glmix is used for the MCP step and proc glm is provided for the Mod step for the nonlinear model fit based on general nonlinear-optimization routines. Both examples rely on the calculation of optimal contrasts. For purpose we first describe in detail a general SAS macro optcont before discussing the specific examples.

The optcont macro implements the optimal contrasts

```
$C_{opt} \alpha \alpha' \Sigma^{-1} ( \mu - \frac{\mu' \Sigma^{-1} \mu}{\mu' \Sigma^{-1} \mu} ) $
```

In order to calculate the optimal contrasts one needs the anticipated $\mu$ of the individual doses [4]. Typically, the mean responses are determined using dose-response models given with "gestimates" for the model parameters that determine the shape of the model (see the right column of Example Dose-Response Models Often Used in Clinical Trials). Note that adding a constant to the vector $\mu$ or multiplying $\mu$ with a constant does not change the optimal contrast. That is, only the relative magnitude of the entries in $\mu$ are relevant for calculation. Furthermore, the anticipated covariance matrix $\Sigma$ needs to be specified as well. As seen from the formula above, the matrix $\Sigma$ only needs to be known up to a multiplicative constant. To obtain a unique representation, the optimal contrast is standardized by its $L2$ norm, i.e. $C_{opt} / \|C_{opt}\|$ The input parameters of the optcont macro are doses (determining $\mu$ for the different models), sigma (determining the matrix), direction (either inc or dec, determining whether an increasing or decreasing value of the response is considered beneficial), and dosename (determining the name of the dose variable in the data set). The input arguments doses and sigma need to be provided manually through a separate data set or extracted via a suitable procedure. The models data set needs to be exactly in the format given below, i.e., have columns modnam, par2 and par3 with missing values specified when the models have less than three parameters. For the column names of the sigma data set no specific names need to be used. Given these input arguments, the macro generates a SAS data set called optcontr that contains the optimal contrasts for the different shapes. In addition, it creates a global variable called modcontr that contains the candidate models names and contrasts, which then can be used inside an estimate statement without retyping them. The dose name that is used in the modcontr statement is determined by dosename. The code for the macro is provided in Appendix A.
