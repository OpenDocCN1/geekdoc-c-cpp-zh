At the trial design stage, a suitable set of candidate models is identified, which also impacts decisions on the number of doses, required sample sizes, patient allocations, etc. At the trial analysis stage, dose-response is tested using suitable trend tests deduced from the set of candidate models. Once a dose-response signal is established, the best model out of the pre-specified candidate model set is then used for dose-response and target dose estimation. In the remainder of this chapter, we describe the core methodology of MCP-Mod in more detail, including an extension to general parametric models, illustrate its application with two examples, and provide the underlying SAS code.
