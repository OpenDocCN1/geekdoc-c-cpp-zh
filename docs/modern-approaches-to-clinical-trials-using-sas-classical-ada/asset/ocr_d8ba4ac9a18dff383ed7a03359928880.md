```
model resp = dose /NOINT solution COVB ;
  estimate &modcontr;
/ adjust=simulate(nsamp=1000000 seed=1) uppertailed;
run;
run;
```

Running this with the optcont macro once generates the optimal contrasts given in Optimal Contrasts for the Candidate Shapes for the biom Data , rounded to 2 digits. One can directly use those contrasts to calculate the test statistics and multiplicity adjusted p-values using the proc glmmix call at the bottom of Example Code 7.2 Contrasts for biom Data.
