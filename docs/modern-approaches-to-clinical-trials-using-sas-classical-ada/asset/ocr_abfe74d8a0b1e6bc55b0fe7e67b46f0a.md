In general, the flat increase rule can be attractive not only because it yields better operating characteristics, but because it can minimize reverse engineering of interim estimates based on the sample size increase since the increase is the same in the whole region of the promising zone.

The flat increase used in the example above can be further improved by using the method proposed by [33]. They propose a stepwise two-stage sample size adaptation using a step function with an inverted U-shaped observed treatment difference. This has the advantage of blinding the treatment effect, which can be potentially revealed at the interim. They use algorithms for group sequential designs to further minimize expected sample size in the class of adaptive design, namely full optimized two-stage design, optimal two-stage group sequential design and designs based on promising zone.
