## 7.1 High-Level Overview of the Original MCP-Mod Procedure

![](img/f4ec2665c3484c528370923aeb5cb99f_344_0.png)

A primary response variable $y$ for a given set of parallel groups patients responding to active doses $d_2,...,d_k$ plus placebo $d_1$, for a total of $k$ arms. For the purpose of dose-response signal testing and estimating target doses, we consider a one-way layout for the model specification $y_{ij}=\mu_i+\epsilon_{ij}, \epsilon_{ij} \sim N(0,\sigma^2)$ for $j=1,...,n$, and $i=1,...,k$, where the mean response at dose $d_i$ can be represented as $\mu_i=\mu(d_i,\theta)$ for some dose-response model $\mu$ parameterized by a vector of parameters $\theta$, $n_i$ denotes the number of patients allocated to dose $d_i$, and $e_{ij}$ is the error term for patient $j$ within group $i$ (assuming independent respondents). We note that many dose-response models used in practice can be written as $\mu(d,\theta)=\theta_0+\theta_1f^0(d,\theta_2)$ and $f^0(d,\theta_2)$ is typically a nonlinear transformation of dose levels depending on $\theta_2$. The parameters $\theta_0$ and $\theta_1$ determine location and scaling of the function $f$. An example for $f^0$ is $f^0(d,\theta_2)=d/(d+\theta_2)$, resulting in the (hyperbolic) model where $\theta_2$ denotes the $ED_{50}$ parameter. More dose-response models are given in Example Dose-Response Models Often Used in Clinical Trials. Column $\theta_2$ lists for each model parameters that determine the shape of the model. For example, for the beta model $B(\zeta_1, \zeta_2) = (\zeta_1 + \zeta_2)^2(\zeta_1\zeta_2)$, where $D$ is a constant factor larger than the dose used in the study (e.g. 1.2 times the highest dose), and for the quadratic model $\zeta = \beta_2/|\zeta_1|$.

The first step of MCP-Mod is to identify a set of $M$ parameterized models together with prior parameter values for their standardized responses. When used with the doses planned for the trial, $d_1, ..., d_k$, these candidate models produce mean responses $\mu_m = [\mu_{m1}, ..., \mu_{mk}]$, where $\mu_{mi} = \mu_m(d_i, \theta_{2m})$ with a specified parameter $\theta_{2m}$ and $\mu_m$ is the $m$th dose-response function, $m=1, ..., M$.

The second step is to test each of the dose-response shapes in the candidate set using a single contrast test, with coefficients chosen to maximize the power of the test when the underlying mean response equals $\mu_m$. This approach forms the test for a dose-response trend in terms of a linear contrast $c_\mu$, where $c$ is a contrast vector such that $\sum c_i=0$ and $\mu$ is the true mean at the dose levels. For any given vector $\mu$, optimum contrast $c(\mu_i - \mu^*), i=1, ..., k$, which after normalization leads to the unique solution (up to the sign) $c/||c||$, where $\mu^* = \mu/k$. Each of $M$ possible dose-response shapes is represented by one contrast $c_m = [c_{m1}, ..., c_{mk}]$. The contrast coefficients for the $m$th shape are specified at the trial design stage, such that they maximize the power to detect the $m$th expected dose-response shape. For example, a linear contrast test for equally spaced doses and balanced patient allocation is defined such that the difference of any two adjacent contrast is a constant. Assuming that the linear model has been included in the candidate set, the linear contrast is then a powerful test to detect the linear trend. Similarly, any dose-response relationship characterized through $\mu_m$ can be tested by selecting an appropriate contrast test, which coefficients are defined in dependence of $\mu_m$. Note that contrast tests are shift and scale invariant. The optimal contrast depend on the parameter(s) $\theta_2$, but not on $\theta_0$ and $\theta_1$. The right column in [Example Dose-Response Models Often Used in Clinical Trials] displays the parameters, which need to be specified at the design stage for each model. Note that these prior guesses are only used for derivation of the contrasts. For example, for the model, a prior guess is required for the $ED_{50}$ parameter.

The third step is to test for an overall dose-response signal. The contrast tests are defined as

$$T_m = \frac{\sum_{i=1}^k c_{mi} y_i}{\sqrt{\hat{S}^2 \sum_{i=1}^k c_{mi}^2}}$$

$\hat{S}^2 = \sum_{i=1}^k \sum_{j=1}^{n_i} (Y_{ij} - \hat{Y}_{ij})^2 / (N-k)$ denotes the mean squared error and $N=\sum n_i$. Under the null hypothesis $H_0: \mu=0$ of no dose-response effect, i.e., $\mu_1=\mu_k$, and under the distributional assumptions from above, $T_1,...,T_M$ follow a multivariate $t$ distribution with $N-k$ degrees of freedom, and the correlation matrix only depends on the sample sizes and the correlations between the different contrasts. In practice these computations have to be redone. The final statistic is based on the maximum contrast test, i.e., $T_{max}=\max_m T_m$. A dose-response signal is verified if this maximum statistic, and thus at least one contrast test, is statistically significant while controlling the familywise error rate (FWER) at pre-specified level $\alpha$. Let $q_{1-\alpha}$ denote the multiplicity adjusted critical value. A dose-response signal is then established if $T_{\max} \geq q_{1-\alpha}$. In fact, any dose-response model with a test statistic larger than $q_{1-\alpha}$ can be declared statistically significant at level $\alpha$. These models then form a reference set $\{M_1,...,M_L\}$ of significant models, provided $L \geq 1$. Every single contrast test translates into a decision procedure, while a selected dose-response curve is significant given controlling the FWER at pre-specified level $\alpha$. If no candidate model is statistically significant, the MCP-Mod procedure indicates that a dose-response signal cannot be established from the observed data. But such a result does not necessarily mean that the compound has no effect at all. In general we will assess that there was not enough evidence to get statistical significance. Possible reasons could include small sample sizes or high variance. In addition, the initial candidate set might have been poorly chosen, such that the candidate models do not fit the true curve (perhaps an umbrella-shaped curve) – although in such cases the compound has a pronounced effect and may be far from ineffective as suggested by the insignificant p-value.

The fourth step is to select one or several weighted models out of the reference set of models. Information criteria like AIC or BIC can be used for this purpose.

The fifth and final step consists of fitting the selected model(s) to the data and estimating adequately the target dose(s) of interest using inverse regression techniques. Note in this step all parameters are estimated from the data for the different dose-response models $(\theta_0, \theta_1$ and $\theta_2)$.

## 7.2.2 MCP-Mod for General Parametric Models

In this section we describe an extension of the MCP-Mod procedure to acknowledge the fact that in practice the modeling situation and study design are more complex than described above for a normally distributed endpoint. For example, the response variable might be a count, binary, or time-to-event variable instead of being normally distributed. In addition, the final analysis usually has to be adjusted for relevant covariates (e.g. region, age, ...), patients' measurements are often recorded over time (necessitating the use of longitudinal models), and patients might receive more than one treatment (such as-over or incomplete designs). The core ideas of MCP-Mod remain applicable in these situations, as described here and laid out in [4] more detail.

Let $y$ denote the response vector of an experimental unit in the trial (e.g., a patient) which has been assigned a dose $d$ (the formulation can be easily extended to the case of multiple doses). We assume that the residual distribution function is given by $y-F(z, \eta, \mu(d))$ where $\mu(d)$ denotes the dose-response parameter, $\eta$ the nuisance parameters, and $z$ possible covariates. The key features of MCP-Mod can then be formulated with respect to $\mu(d)$,:

- accounting for uncertainty in the dose-response model via a set of candidate dose-response models
- testing for a dose-response signal via optimal contrasts based on plausible dose-response shapes
- model selection or model averaging to combine different models
- dose-response estimation and dose selection using nonlinear regression.
