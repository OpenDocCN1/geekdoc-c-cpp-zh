$S(t_j) = \sqrt{\frac{X_T(t_j) - X_C(t_j)}{r(1-r)n_j}}$

$j = 1, 2, \dots, J$, and $S(t_j)$ is distributed as $N(\eta t_j, t_j)$. $\eta$ is the drift parameter such that $\eta = 0$ under null hypothesis but $\eta = \eta_1$, where $\eta_1 = 	heta_1\sqrt{t_j}$ under the alternative hypothesis.

If this trial is a non-inferiority trial, then the null hypothesis is constructed as

$H_0: 	heta \le 	heta_0$

where $	heta_0$ is the non-inferiority margin. Then, using the same notation, the stochastic process

$S(t_j) = \sqrt{\frac{X_T(t_j) - X_C(t_j)}{r(1-r)n_j}}$

follows $N(\eta t_j, t_j)$ with $\eta = 0$ under the null hypothesis but $\eta = \eta_1$ $\eta_1 = (	heta_1 - 	heta_0)\sqrt{t_j}$ under the alternative hypothesis.

In both superiority and non-inferiority testing cases, we can search for the value of $\eta_1$ and $l_j$ such that the power is $1 - eta$. From the previous section, we know that

$n_j = \frac{\sigma_j^2 l_j}{r(1-r)}$

We can use this formula to convert the maximum information $l_j$ needed to achieve a target power into the maximum sample size $n_j$ needed. However, we note that in order to make the translation, we need to know the value of $\sigma_j^2$ which is the nuisance parameter. The value of this nuisance parameter is typically unknown. In practice, we usually replace $\sigma^2$ with its sample variance $s^2(t_j)$ at each interim monitoring time point $t_j$ when the endpoint is assumed to be normally distributed. Therefore, we cannot track the path traced by these statistics in the course of a clinical trial, and we cannot know for sure if these statistics have crossed the stopping boundaries.
