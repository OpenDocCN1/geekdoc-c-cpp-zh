Each of these two designs in Example 2.6 Pocock and O'Brien-Fleming Designs for Familial Hypercholesterolemia Trial requires a separate design statement but the same samplesize statement. A userspecific label can be given to each of the designs, but they have to be valid SAS names. For the first design, a label of pocdesignfor is given, and stages=4 suggests that it has four stages. The option methodpoc specifies that we are calling for the Pocock boundaries. For the second design, a label of designfor is given, and it too has four stages. The option methodrob indicates that we are asking for the OBF boundaries. The samplesize statement returns the required sample sizes for the sequential designs that are specified in each design statement. In the twosample option, the default weight option indicates equal allocation between the two treatment arms. The standard deviation is given such that sample size can be calculated in this design. Default standard deviation is 1 if not specified. In addition to the two other display options discussed earlier, the option pas displays power and sample size under various hypothetical references. Note that these options are included by default if not specified: alpha=0.05, beta=1, alt=tousided and stop=reject. The graphical option can be turned on using ods graphics on/off, but this is sometimes not required in recent releases of SAS as graphical output is already generated by default.
