For non-insulin T2DM therapies, the risk of major adverse cardiovascular events (MACE), which includes CV death, non-fatal myocardial infarction, and non-fatal stroke events, can be assessed in two Stages, as suggested in the guidance document. Here we capitalize “Stage” to distinguish the usage in the T2DM example from the interim analyses or “stages” that are used elsewhere in the chapter. The first Stage is a pre-market evaluation of the novel compound to placebo testing the Stage 1 hypotheses using all accumulated pre-market trial data:

```
$H_{10}: \frac{\hat{\lambda}_T}{\hat{\lambda}_C} \geq 1.8 \text{ versus } H_{11}: \frac{\hat{\lambda}_T}{\hat{\lambda}_C} < 1.8$ (2.2)
```

where $\hat{\lambda}_T$ and $\hat{\lambda}_C$ are the hazard rates of MACE for the novel treatment and control arms, respectively. Assuming the new drug application (NDA) is otherwise acceptable, if the CV criterion is, the sponsor obtains full marketing approval for the new drug. In the second Stage, the sponsor must evaluate the post-marketing criteria testing Stage 2 hypotheses combining new post-market trial data and pre-market data:

```
$H_{20}: \frac{\hat{\lambda}_T}{\hat{\lambda}_C} \geq 1.3 \text{ versus } H_{21}: \frac{\hat{\lambda}_T}{\hat{\lambda}_C} < 1.3$ (2.3)
```

This approach strikes a balance between providing evidence on cardiovascular safety to reassure patients and excessive delay of novel therapies reaching the marketplace. Each Stage is tested at a separate $\alpha=0.05$, though if the 1.3 criterion is assessed during Stage 1, multiplicity adjustment is required for the $\alpha$ in Stage 2 [18].

proc power does not currently support non-inferiority calculations for time-event events, but the reader can proc seqdesign to calculate the number of events for a fixed trial. For Stage 1, we re-write the hypothesis $H_{10}: -\ln(\hat{\theta}/\hat{\theta}) + 0.5878 = -\ln(\hat{\theta}) \leq 0$, where $0.5878 = \ln(1.8)$. proc seqdesign is then used to determine the number of events for a fixed trial of size (Example Code 2.4), assuming 90% power and two-sided $\alpha=0.05$ per Stage, and equal allocation between the two arms. Only the hazard for the treatment arm needs to be specified in the hazard option. A two-sided test is implied by the literature, storing boundaries can be limited to the one-sided case to test $\lambda(e)/\lambda(c) < 1.8$ by specifying $alt=upper$ and $alpha=0.025$.
