protecting trial by the type II error of $eta$. We let the upper boundary at the $j$th interim stage $u_j$ and the lower boundary as $l_j$ for $j=1, 2, \dots, J$. Again, we will be able to use a numerical method to evaluate the set of boundaries which should satisfy the following equations at $t_1$

$P_0(S(t_1) \geq u_1) = \alpha(t_1)$.

$P_{\eta_1}(S(t_1) \leq l_1) = eta(t_1)$.

Similar conditions are evaluated subsequently at $t_2, t_3, \dots, t_j$ as follows. If we have calculated the pair of stopping boundaries up to $t_{j-1}, (l_{j-1}, u_{j-1})$, we can then find $(l_j, u_j)$ using the following equation and numerical method

$P_0(l_1 < S(t_1) < u_1, l_2 < S(t_2) < \dots < l_{j-1} < S(t_{j-1}) < u_{j-1} \geq u_j) = \alpha(t_j) - \alpha(t_{j-1})$

$P_{\eta_1}(l_1 < S(t_1) < u_1, l_2 < S(t_2) < \dots < l_{j-1} < S(t_{j-1}) < u_{j-1} \leq l_j) = eta(t_j) - eta(t_{j-1})$

For the final stage at $t_j$, we set $u_j = l_j$, so that meet and a definitive decision at the end of a trial is guaranteed. The desired maximum information $l_j$ can be evaluated and translated into the maximum sample size $n_j$ or the maximum number of events $D(c_j)$ (in case of a survival endpoint). The two-sided testing can be similarly derived by replacing $S(t_j)$ with $IS(t_j)$ which gives symmetric boundaries. In other cases, we may be interested in asymmetric boundaries. When deriving asymmetric boundaries, the $\alpha$ will be split into two parts such as $\alpha_U + \alpha_L = \alpha$ and two different $\alpha$-spending functions can be specified, $\alpha_U(t)$ and $\alpha_L(t)$. Similarly, this can be applied to $eta$ spending functions.
