where $\phi(x)=(2\pi)^{-1/2}\exp(-x^2/2)$. To achieve power $1-eta$ on average, we find the smallest positive integer $n_{III}$ for which $EP(p_E, p_C, NE(n_{III}), NC(n_{III})) \ge 1-\beta$.

In practice every clinical trial is only once, and it is important to ensure that with high probability the statistical test has adequate power. The type III sample size $n_{III}$ for a RAR design to achieve fixed power $1-eta$ with probability $1-\xi$ is the smallest positive integer that satisfies the $Pr(P(p_E, p_C, NE(n_{III}), NC(n_{III})) \ge 1-\xi)$. In [14], the authors show that $n_{III}$ can be found (approximately) as the smallest positive integer that satisfies the following conditions:

```
$$\frac{p_E q_E}{n_{III}-1-\xi/2\sqrt{n_{III}}} + \frac{p_C q_C}{(1-\rho)n_{III}+1-\xi/2\sqrt{n_{III}}} < \left(\frac{p_E-p_C}{z_{1-\alpha}+z_{1-\beta}}\right)^2 \quad (10.14)$
```

and

```
$$\frac{p_E q_E}{n_{III}-1-\xi/2\sqrt{n_{III}}} + \frac{p_C q_C}{(1-\rho)n_{III}+1-\xi/2\sqrt{n_{III}}} < \left(\frac{p_E-p_C}{z_{1-\alpha}+z_{1-\beta}}\right)^2 \quad (10.15)$
```

In (10.14) and (10.15), $\sigma$ is an asymptotic standard deviation of $NE_E(n)/n$.
