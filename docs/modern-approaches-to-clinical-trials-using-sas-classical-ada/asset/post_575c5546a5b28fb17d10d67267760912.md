## 4.2 Meta Design Setting

### 4.2.1 Notation

We consider $K$ randomized trials where each trial has two treatment arms denoted by control and experimental and $K \ge 1$. The control arm may be a placebo or an active control, and the experimental arm may be an investigative drug in the clinical trial setting. However, in the medical device application, the control arm may be an old generation medical device and the experimental arm may refer to a new generation medical device. For ease of presentation, we generically call these two arms as control and experimental.

Let $n_{jk}$ denote the sample size for the $j^{th}$ treatment arm in the $k^{th}$ randomized trial, where $j=1$ and $j=2$ denotes control and experimental, respectively, for $k=1, \dots, K$. We write $n_k = n_{1k} + n_{2k}$ which denotes the total sample size for $k^{th}$ randomized trial. We also let $p_k$ and $r_k$ denote the proportion of subjects in the control arm and the annualized event rate, respectively, for $k=1, \dots, K$. The proportion of subjects in the control arm, plays a role to allocate the sample size to the control and experimental arms. Using this quantity, we have $n_{k} = [p_k n_k]$ and $n_{kk} = n_k - n_{k}$ where $[p_k n_k]$ is the largest integer less than or equal to $p_k n_k$. The annualized event rate is a prespecific probability that an event will occur in less than a year. It is also used to specify the design value of the mean survival time in the sampling prior discussed in 4.6 Computational Algorithms. Finally, we let $\tau_k^A$ and $\tau_k^F$ denote accrual time and minimal follow-up time, respectively, for $k=1, \dots, K$.

### 4.2.2 Input Data for a Meta-Trial Design Variable

A General Design of Meta-Trials with Two Arms shows a general survival meta-experimental design setting for $K$ randomized trials with two arms introduced in the previous section. From Table 4.1, we see that the input data contain trial ID (TID), the total sample size ($n$), proportion in control arm ($\rho$), annualized event rate ($r$) in the control arm, trial duration (TD), and accrual time (TA) for each trial. Using the relationship between trial duration and accrual time, we calculate the minimum follow-up time (TF) for each trial; that is, $TF_k = TD_k - TA_k$. We note that these input data are used to generate the predictive data discussed in 4.6 Computational Algorithms. From the prior predictive data algorithm presented in 4.6 Computational Algorithms, we impose the constraints on $TD_k \ge 0$, $TF_k \ge 0$, $TD_k \ge TF_k$ and $TD_k > TA_k$. (4.1)

In (4.1), if all subjects enroll the trial at the trial entry time; if $TF_k=0$, there is no minimum follow-up requirement; and if $TD_k \le TF_k + TA_k$ subjects are followed-up during the entire trial after the subjects enroll in the trial. In addition, the number of studies ($K$), the number of MCMC samples (NMCS), the number of burn-in-samples ($nbi$), the number of simulated data sets ($REP$), design margin ($\varrho$), and user-defined Bayesian credible level ($n_0$) are required as input variables to run the SAS macro, BSMED, discussed in Section 4.7.

### 4.2.3 Input Data

Suppose that historical data are available for the control and experimental arms from $K_0$ previous trials. For the historical data, we define
$x_{0k} = \begin{cases} 1, & \text{if } y_{0k} \le n_{0k} \\ 0, & \text{otherwise} \end{cases}$
where $x_{0k} \in \{0,1\}$ indicates that the historical data are available only for the control arm. If $x_{0k}=1$ for $k=1,\dots,K_0$, the historical data are available for both arms. For example, if $x_{0k}=0$ for $k=1,\dots,K_0$, the historical data are available only for the control arm. Under this setting, we let $y_{0k} = (y_{0k1},y_{0k2})$ denote the total number of events.
