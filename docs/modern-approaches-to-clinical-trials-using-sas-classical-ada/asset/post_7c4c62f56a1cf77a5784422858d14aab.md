## 9.2 Simple Randomization

The simplest way of randomization, simple randomization fixes the assignment probabilities throughout the trial with no regard to historical allocation and response information. Nevertheless, the assignment probabilities can be equal or different across treatment arms. For a trial with K treatments, each trial participant is simply assigned with probability 1/K to one of the K arms under equal randomization. If a certain treatment is believed to be more beneficial, or investigators are interested in learning more about a specific drug, more patients can be randomized to that treatment arm. For instance, the allocation ratio to a new therapy versus the standard-of-care can be specified as 2:1 or 3:1.

In SAS, the SimpleRandomize macro can be utilized to design a simple randomized trial. The input variables include n, the total sample size of the trial, and groupdata, the set that stores the identities of the treatments and their corresponding allocation ratios.

As an illustration, we consider a three-arm trial with treatments A, B, and C. Based on the allocation ratio of 1:1:2, we can randomize 100 patients by calling the SimpleRandomize macro as shown in Example Code 9.1 Simple Randomization.

## Example Code 9.1 Simple Randomization

```sas
%macro SimpleRandomize(n, groupdata, seed);
proc iml;
  use &groupdata;
  read all;
  call randseed(&seed);

  nu=j(&n,1);
  prob=ratio/sum(ratio);
  agroup=j(&n,1);
  call randgen(u, "Uniform");
  cprob = j(nrow(group),1);
  do j=1 to nrow(group);
    cprob[j]=sum(prob[1:j]);
  end;
  do j=1 to &n;
    k=1;
    do while (u[j]>cprob[k])
      k=k+1;
    agroup[j]=k;
  end;
end;
group=group[agroup];

create SimpleRandomization var {group}; /** create data set */
append;
quit;

proc print data=SimpleRandomization;
run;

proc freq data=SimpleRandomization;
tables group;
run;
%end SimpleRandomize;
```

```sas
data ThreeArm;
input group $;
datalines;
A 1
B 1
C 2;
run;
%SimpleRandomize(n=100,groupdata=ThreeArm,seed=6);
```

The macro generates a sequence of treatment assignments for 100 subjects. We can use proc freq to show the frequency of the treatment assignments (Output from Example Code 9.1).

## 9.3 Restricted Randomization

### 9.3.1 Permuted Block Randomization

With equal probabilities of assignment, the number of patients in each arm is supposed to be close. Nevertheless, simple randomization typically cannot guarantee a perfect balance across different arms, especially when the sample size is small. By contrast, the restricted randomization aims to achieve a perfect balance across different arms.

The most popular technique for restricted randomization is permuted block design. For example, in a three-arm trial with treatments A, B, and C, the possible sequences using a block size of three are:

- ABC
- ACB
- BAC
- BCA
- CAB
- CBA

At the end of each block, the treatment assigned is known as long as the previous assignments have been track of. A natural remedy to prevent such selection bias is to randomly mix blocks of different sizes so that the block size is unpredictable as well.

Permuted block design is particularly useful to balance the number of patients across arms. To invoke proc plan, we need to specify the block sizes, as shown in Example Code 9.2.

## Example Code 9.2 Permuted Randomization

```sas
proc plan seed=3;
factors block=3 level=('A' 'B' 'C') permute;
output out=PermutedBlock;
run;

proc sort data=PermutedBlock; by block;
run;

proc print data=PermutedBlock;
run;
```

The output shows the treatment assignments for the block sizes.

## 9.3.2 Biased Coin Design

Another well-known restricted randomization method is the biased coin design (BCD), which aims to provide an approximated balance among the treatment arms. Each step of BCD favors the treatment that has been underrepresented so far. For illustration, let $n_1$ and $n_2$ denote the number of subjects that are assigned to arm 1 and 2, respectively. Let $\rho$ be the prescribed randomization probability for arm 1. As the trial proceeds, a new patient will be allocated to arm 1 with a probability of:

$$\text{(patient assigned to arm 1)} = \begin{cases} \rho, & n_1 < n_2 \\ 1/2, & n_1 = n_2 \\ 1-\rho, & n_1 > n_2 \end{cases}$$

There are many choices for the selection of $\rho$: Efron recommended $p=2/3$, such that the trial can be simply conducted by tossing a biased coin. Based on a constant $\rho$, the treatment allocation cannot characterize the extent of unbalance between the two groups. To accommodate the sample size information, Wei recommended the allocation probability to arm 1 as:

$$\rho = \frac{1}{2}(1 - \frac{\Delta}{n})$$

where $\Delta = n_1 - n_2$ and $n = n_1 + n_2$.

The BCDRandom macro implements the BCD of Wei to generate the treatment assignment for each new patient. Users need to input the accumulated number of patients in each group. At the beginning of a two-arm trial, no patient has been recruited. We use the following code to randomize the first patient with an equal probability to each arm, by chance, the first patient is assigned to treatment B.
