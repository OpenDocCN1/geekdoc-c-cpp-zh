The adaptive and group sequential designs in Operating Characteristics of Classical and Group Sequential Design and Operating Characteristics of Classical and Adaptive Design are generated using the SAS macro %SSR_CP in Example Code 3.4 SAS Macro SSR_CP.

Below we briefly summarize the macro. The initial macro calls are the following:

+   1. nSamp = number of simulations

+   2. alpha =desired $\alpha$ level

+   3. beta = desired $eta$ level

+   4. cont = control response to be simulated

+   5. trt = treatment response to be simulated

+   6. delta = difference between treatment and control response

+   7. Nmax = maximum sample size to be committed

+   8. r = randomization ratio of treatment and control

+   9. t = timing of interim analysis

+   10. c1 = efficacy boundary at interim analysis in the standardized $Z$ scale

+   11. c2 = efficacy boundary at the final analysis in the standardized $Z$ scale

In the macro %SSR_CP, Nmax is set to initial total sample size of 870 for group sequential design, while it is set to a total sample size of 1,008 for the SSR design. After Stage 1, the conditional power (CP) is calculated and the trial is categorized into four zones:

+   1. UNFAVORABLE (if CP < 0.3)
