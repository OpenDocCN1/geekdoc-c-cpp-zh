$L(\alpha|D) \propto \prod_{i=1}^{n} p_{j}^{(i)}\exp(\alpha)} \left(1-p_{j}^{(i)}ight)^{1-y_i}$

$y_i$ takes a value of 0 or 1 or a fraction of 1 for a censored observation. Once the censored data are fractionized, the rest of implementation of the fractional CRM (fCRM) is straightforward as the usual CRM.
