
## 4.3 元回归生存模型

### 4.3.1 未来生存数据模型

在本节中，我们讨论在 4.2 节讨论的通用生存实验设计下的元回归生存模型。令 $y_{jk}$ 表示个体水平的事件时间（失效时间），$v_{jk}$ 表示右删断指示，其中当 $y_{jk}$ 为失效时间时 $v_{jk}=1$，当 $y_{jk}$ 被右删断时 $v_{jk}=0$，对于第 $j$ 组的第 $k$ 次试验，$i=1, \dots, n_{jk}, j=2, \dots, K$。我们写 $\hat{y}_{jk}=\frac{\sum_{i=1}^{n_{jk}} y_{ijk}}{\sum_{i=1}^{n_{jk}} v_{ijk}}$ 分别表示总持续时长和总受人数。对于 $j=1$（控制组）令 $x_{jk}=0$，对于 $j=2$（实验组）。我们观测到的元生存数据表示为 $D_K=\{y_{jk}, v_{jk}, x_{jk}\}, j=2, \dots, K$。

进一步假设个体水平的失效时间服从均值为 $1/\lambda_{jk}$ 的指数分布，$Y_{jk}\sim Exp(\lambda_{jk})$，其中 $\lambda_{jk}>0$ 是风险率。$Y_{jk}|v_{jk}$ 的密度函数为

$f(y_{jk}|\lambda_{jk})=\lambda_{jk}e^{-\lambda_{jk}y_{jk}}$。(4.2)

对于 $\lambda_{jk}$ 的对数线性模型假设

$\log(\lambda_{jk})=\gamma_0+\gamma_1x_{jk}+\theta_k$。(4.3)

其中对于 $j=1$（控制组）$x_{jk}=0$，对于 $j=2$（实验组）$x_{jk}=1$，为了确保 (4.2) 中模型的可识别性，我们引入约束 $\sum_{k=1}^K\theta_k=0$。为了简单起见，取 $\theta_K=-\sum_{k=1}^{K-1}\theta_k$。注意，在指数模型下，设计参数 $\gamma_1$ 是实验组治疗的风险比。令 $\theta=\{\theta_1,\dots,\theta_K\}$ 且 $\gamma=(\gamma_0,\gamma_1)$。则基于元生存数据 $D_K$ 的似然函数为

$L(\gamma,\theta|D_K)=\prod_{k=1}^K\prod_{j=1}^2\exp\{y_{jk}(\gamma_0+\gamma_1x_{jk}+\theta_k)\exp\{-(\gamma_0+\gamma_1x_{jk}+\theta_k)y_{jk}\}$。(4.4)

在 (4.4) 中，我们看到似然函数依赖样本量 $n_{jk}$。这意味着在指数模型下，基于个体水平元实验数据的似然函数简化为基于治疗水平元实验数据的似然函数。

### 4.3.2 历史生存数据模型

在本节中，我们考虑 4.2.3 节讨论的不同类型历史数据的元回归生存模型。假设 $y_{jk}$ 是总时长，$v_{jk}$ 是删断指示，其中当 $y_{jk}$ 为失效时间时 $v_{jk}=1$，当 $y_{jk}$ 被删断时 $v_{jk}=0$，对于第 $k$ 次试验，$j=1, \dots, K_0$。此外，如果 $x_{jk}$ 是标量，则代表一个组（控制组或实验组），如果是向量则代表两个组，如 4.2.3 节所述。假设从 $K_0$ 项历史研究中获得试验水平汇总数据 $D_k=\{y_{jk}, v_{jk}, x_{jk}\}, k=1, \dots, K_0$。假设个体失效时间服从指数分布 $Exp(\lambda_{jk})$，其中风险率 $\lambda_{jk} > 0$。则模型假设

$log(\lambda_{jk}) = \gamma_0 + \gamma_1(j-1) + \theta_k \quad (4.5)$

对于 $x_{0k} \leq j-1 \leq x_{2k}, k=1, \dots, K_0$，假设历史数据仅来自控制组。这是 4.2.3 节讨论的第一类历史数据，很容易看出在这种情况下 $x_{0k}=0$。那么历史数据与当前数据的模型仅共享一个公共参数，即 $\gamma_0$。然而，如果历史数据仅来自实验组（即第二类历史数据），则 $x_{0k}=1$，历史数据与当前数据的模型共享一个复合参数 $\gamma_0+\gamma_1$。现在我们考虑第三类数据，即历史数据适用于两个组。在这种情况下，历史数据与当前数据的模型共享两个公共参数 $\gamma_0$ 和 $\gamma_1$。数据的似然函数为

$L(\gamma,\theta|D_K)=\prod_{k=1}^K\prod_{j=x_{0k}}^{x_{2k}}\exp\{y_{jk}(\gamma_0+\gamma_1x_{jk}+\theta_k)\exp\{-(\gamma_0+\gamma_1x_{jk}+\theta_k)y_{jk}\}$。(4.6)

## 4.4 贝叶斯实验设计

在本节中，我们介绍贝叶斯实验设计的通用方法。我们首先定义非劣性假设，其表述为：

$H_0: e^{\gamma_1} \ge \zeta$ 于 $H_1: e^{\gamma_1} < \zeta$ (4.7)

其中 $e^{\gamma_1}$ 是风险比，$\zeta$ 是非劣性边界。令 $[\gamma, \theta]$ 表示参数集合。参考文献，令 $\pi^{(S)}[\gamma, \theta]$ 和 $\pi^{(F)}[\gamma, \theta]$ 分别表示采样先验和拟合先验。采样先验的作用是捕捉参数空间的一部分。利用数据 $D_K$，$[\gamma, \theta]$ 的后验分布为

$\pi[\gamma, \theta|D_K] \propto \prod_{k=1}^K\prod_{j=1}^2\exp\{y_{jk}(\gamma_0+\gamma_1x_{jk}+\theta_k)\}\exp\{-(\gamma_0+\gamma_1x_{jk}+\theta_k)y_{jk\}}\pi^{(F)}[\gamma, \theta]$。(4.8)

为了完成贝叶斯实验设计，我们需要指定两个适当的采样先验 $\pi_0^{(s)}[\gamma, \theta]$ 和 $\pi_1^{(s)}[\gamma, \theta]$，它们定义在由假设 $H_0$ 和 $H_1$ 导出的参数空间子上。我们定义关键量为

$\beta_{sl}^{(n)} = E_{sl}[1\{P(e^{\gamma_1} < \delta D_K, \pi^{(f)}) \geq \eta_0\}], \quad (4.9)$

其中指示函数 $1_{\mathbb{A}}$ 在 $\mathbb{A}$ 为真时为1，否则为 0，$0 < \eta_0 < 1$ 是预设的贝叶斯信性水平，后验概率 $P(e^{\gamma_1} < \delta D_K, \pi^{(f)})$ 是相对于数据 $D_K$ 的 $\gamma_1$ 后验分布计算的，期望 $E_{sl}$ 是相对于采样先验 $\pi_l^{(s)}[\gamma, \theta]$ ($l=0,1$) 下 $D_K$ 的预测边缘分布取值的。
