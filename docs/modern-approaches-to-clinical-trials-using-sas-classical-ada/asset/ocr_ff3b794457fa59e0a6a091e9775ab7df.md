# ## 2.4.1 Calculation of Stopping Boundaries

We have provided an overview of the distributional theory of sequential testing in the previous section. This section focuses on the calculation of stopping boundaries. Based on the specified hypotheses, stopping boundaries can be either one-sided or two-sided. In addition, depending on the prospective outlook of the trial, investigators can specify if the set of boundaries is to (1) reject the null hypothesis ($H_0: \theta = \theta_0$), (2) reject either the null hypothesis ($H_0: \theta = \theta_0$), or (3) reject the alternative hypothesis ($H_1: \theta \neq \theta_0$). Only in the case, we call this set of boundaries efficacy boundaries while for the third case, we call it utility boundaries. We can consider planning a clinical trial with a maximum of $J$ monitoring interim stages with information fractions $t_1, t_2, ..., t_J$. If the sequential testing procedure is set at the desired $\alpha$-level, then the stopping boundaries should reflect this type of I error. In addition, if we want to achieve a target power of $1-\beta$ under the alternative hypothesis ($H_1: \theta \neq \theta_0$), then we can find the maximum information needed $l_J$ and hence the sample size $n_J$ or number of events $D(l_J)$ needed.

As we have seen earlier, there are two ways to specify the statistics, the Wald statistic $Z(t_j)$ or the stochastic process statistic $S(t_j)$. Because of the property of independent increments for the stochastic process statistic $S(t_j)$, it will be easier to illustrate the stopping boundaries using this scale. Since a relationship exists between the two, $S(t_j) = Z(t_j)\sqrt{t_j}$, the corresponding stopping boundaries for the Wald statistics can be easily obtained by appropriate transformations. In the most general form, we know that $S(t_j)-N(\theta_0, t_j) = \eta = (\theta_1-\theta_0)\sqrt{t_j}$. In the following sections, we will look into three commonly used types of stopping boundaries. They are (1) p-value method, which is also known as the Haybittle-Peto boundaries, (2) unified family (power) methods, which include the Wang-Tsiatis boundaries [22], the Pampalla-Tsiatis boundaries [23], and the triangular method proposed by Kittelson and Emerson [4], and (3) Error Spending methods, which include the Lan-Deets [10], the Gamma [24] and the Rho [25] boundaries. Brief descriptions of these methods can be found in Methods of Deriving Stopping Boundaries.
