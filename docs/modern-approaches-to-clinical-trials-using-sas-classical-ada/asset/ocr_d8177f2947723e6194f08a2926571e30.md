In turn, we can estimate the needed maximum sample size $n_J$ if we are using the normal or binomial endpoint, or the maximum number of events $D(c_J)$. In the two-sided hypothesis testing, there are upper and lower rejection boundary values, thus we can simply replace $S(t)$ in the above equations with its absolute value $|S(t)|$. It can be noted that this p-value method can be generalized to unequal p-values instead of constant $p_1$ at each of the first $J-1$ stages.

# Example: Redesigning the Familial Hypercholesterolemia Trial Using Haybottle-Peto Method

In SAS, the procedure we use to derive the operating characteristics of group sequential design is proc seqdesign and the procedure used to monitor sequential trial is proctest. We will illustrate their applications using the examples discussed in 2.2 Examples of Classical Fixed-Sample Designs. Here, we show a simple use of proc seqdesign to generate a Haybottle-Peto design as a modified design for the pediatric trial.

Example 2.5 Haybottle-Peto Design for Familial Hypercholesterolemia Trial

```
proc seqdesign altref=0.02 errsend stopprob;
hpdsdesignforn: design stages=5 method=peto(z=3) alt=upper-reject
alpha=0.025 beta=0.1;
samplesize model=twomeanample (stddev=0.045);
```

Example Code 2.5 Haybottle-Peto Design for Familial Hypercholesterolemia Trial generates a 5-stage design with a user-created label of hpdsesignforn. In the design statement, we specify the use of the Haybottle-Peto method on the scale of the $Z$-statistic using method=peto(z=3) to set the boundary constant at 3 for the first four stages. This is the default. Alternatively, for the example discussed earlier, one can specify a fixed p-value using method=peto(pvalue=0.001) to set $ho_1=0.001$ for the first stages. The number of stages is indicated using nstages=5. The alternative hypothesis is the upper-sided (alt=upper), but if one wants to change it to the two-sided, then alt=twosided. This design allows for stopping early only to reject or modify it or to retain the null hypothesis as indicated in stop=reject which is the default setting.
