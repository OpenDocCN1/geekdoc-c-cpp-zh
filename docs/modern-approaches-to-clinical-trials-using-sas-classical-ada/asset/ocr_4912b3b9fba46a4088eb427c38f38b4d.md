# 8.3.2 Asthma Trial with 100 Patients Per Group

For the previous example consider the situation that the sponsor did not conduct phase II studies for the experimental drug. The pre-clinical data for the experimental drug will shed light on the potential ED50 and the maximum effect of the drug. Due to the lack of clinical data, the pre-clinical data (after applying some uncertainty around them) is posed as diffused priors for the analysis.

The code for the simulated data remains the same as in the previous example, except that the planned sample size per group is 100 instead of 75, and the seed changes. The conamaxsim macro was rerun after updating nprxgrp = 100 and seed = 9865 (Example Code 8.3 Analysis of Asthma Trial with 100 Patients Per Group).

The summary data for the results of a this simulation are provided in Dose Summary of Asthma Trial with 100 Patients Per Group. The prec mcm call with new priors is provided in Example Code 8.3 Analysis of Asthma Trial with 100 Patients Per Group. The prior for E0 remains unchanged. The is diffused prior assumed to be normally distributed with mean 0.15 and a low precision of 1 (as opposed to a precision of 10 for the previous example). The ED50 is also diffused assuming a flat uniform prior between 0 and 20. In this example there is no prior clinical information on the drug, hence we assume a flat uniform prior from 0 to 20. If we had more information on the drug (similar to the previous example), we could have assumed a bounded beta distribution - example, bounded at 20 and tweaking the parameters of the beta distribution to make it informative. In general, to choose the priors judiciously the priors should be adequately discussed with clinical and/or pre-clinical colleagues.
