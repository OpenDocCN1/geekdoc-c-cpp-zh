## 7.3 Considerations for MCP-Mod at the Design Stage

One main consideration when implementing MCP-Mod is the choice of the candidate set of models. As a rule of thumb, often 3-7 dose-shapes, corresponding to 2-4 dose-response models are appropriate. Note that multiple dose-response shapes might be used for each dose-response model because the shapes define the optimal contrasts to be used in the MCP step and the models are those to be fitted in the Mod step. While in general the candidate set should be broad, when there is large uncertainty, one should keep in mind that using a very broad and flexible candidate set does not come for free. Generally the sample size will increase with a broader candidate set of shapes (i.e., contrasts) as the critical value for the MCP step will increase. There is also a trade-off in will decrease potential bias (in case of a misspecified model) but it will increase the variance of the estimates. To find a good trade-off the following considerations should be taken into account.

- General experience: Thomas et al. showed that in many situations an or sigmoid model can adequately describe the observed data [5].
- Drug-specific information: Dose-response curves of similar drugs, predictions from earlier phases of development (e.g. using a PK/PD model), or dose-response information of the same drug in a different indication can be used to suggest suitable dose-response shapes.
- Statistical considerations: If only a few active doses are available for use (say, three), it is difficult to fit more complex models (such as the sigmoid or the beta model, which both have four parameters), which then would not be included in the candidate set. In these cases one would rather use dose-response models with fewer parameters to obtain an adequate breadth of potential dose-response shapes. Another consideration is to evaluate the consequences of omitting a dose-response shape from the set of candidate models in case it is the true one. This does not necessarily have severe consequences, as other model shapes may be able to pick up the omitted model or shape. This can be evaluated for the MCP step (impact on power) using explicit calculations and for the Mod step (impact on precision for dose-response and dose estimation) using simulations [6].

Beyond identifying the candidate set of models, at least two other questions need to be addressed when designing a dose-fining study: (i) How many, and which doses to utilize and, (ii) how many subjects to allocate to the different doses.

Regarding (i) we suggest using 4-7 active dose levels as a rule of thumb and consider at least a dose range [7]. Equal spacing on the scale is commonly used for the dose strengths. More formally one can also consider optimal design theory to calculate doses and allocations to these doses. The essential idea is to use information on the anticipated dose-response curve and then to calculate doses and allocation to the covariance matrix of the parameter estimates is minimized in a specified sense. When MCP-Mod is being utilized in a given study, a candidate set of dose-response models has then already decided upon and this information can be used to calculate, for example, a model-averaged optimal design for calculation of the model parameters (D-optimal design) or estimation of a target dose (c-optimal design). Due to practical constraints in terms of production of the doses, it might not be possible to use the calculated optimal design directly. But one can also restrict the search for an adequate design to those that are feasible both in terms of logistics and production. Several authors discuss optimal design theory in the context of dose finding studies [8,9]. Atkinson et al. provide a general background on optimal designs and discuss how to implement them in SAS [10].

Regarding question (ii) above, one can utilize two different approaches for calculating the total sample size, according to the two steps of MCP-Mod. One can consider the MCP step and calculate the sample size so that a specific power is achieved for the multiple contrast test; see [6] for a detailed description of this approach. Alternatively, one can calculate the sample size based on achieving a specified precision for the target dose or the dose-response curve estimate (e.g. by specifying a desired confidence interval width). This typically needs to be done using simulations because closed form expressions are not available. In general, however, one needs to keep in mind that the sample size for detecting a significant trend using the MCP step will often be much smaller than the one that is necessary to determine the dose-response curve and the target dose with sufficient precision (see also the conclusions of the PhRMA working group on adaptive dose-ranging studies in [1]).

Both the determination of dose, as well as sample size calculations, can be performed in SAS, but we do not provide example code for these calculations in this chapter. The related calculations can be performed using, for example, the DoseFinding R package, which contains extensive functionality for the design of dose-finding studies [11]. The commercial software package ADDPLAN-DF also contains extensive tools for designing dose finding studies using MCP-Mod [12].
