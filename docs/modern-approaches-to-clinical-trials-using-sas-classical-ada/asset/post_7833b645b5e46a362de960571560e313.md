The partial output for these two redesigned trials (Figure 2.2 Output for Pocock Boundaries for Example Code 2.6 and Figure 2.3 Output for O'Brien-Fleming Boundaries for Example Code 2.6) shows a summary of the design. The OBF method has a smaller maximum information (or inflation factor) of 102.2% than the Pocock method with 118.3%. However, the Pocock method has a smaller average sample number (ASN in percentage of total sample size under the alternative hypothesis, 69.7%) compared to 76.7%. This is due to their differences in stagewise stopping probabilities and monitoring patterns. In this example, the Pocock design is more likely to stop the trial for efficacy in an earlier stage than the OBF design, although it requires more stagewise samples. The Powers and Expected Sample Sizes tables generated by the option show respective powers under hypothetical alternatives. If c = 0.5, meaning the alternative situation is half of the assumed alternative reference, the OBF design will have a power of 36.5%, the Pocock design has a slightly smaller power of 34.3%. The reverse is true for c = 1.5. Therefore, investigators will have to weigh in the benefits of the two designs in terms of time and resources, as well as their preferences, before deciding which approach best meets the study objectives.

# Example Code 2.7 Requesting Plots for Summary Statistics of Sequential Designs

```sas
proc segdesign plots=boundary(hscale=samplesize) boundaryscale=pocock;
  design nstages=4 method=upper alpha=0.025;
  design nstages=4 method=upper alpha=0.025;
  samplesize=twosample(stddev=0.045) weight=1;
run

proc segdesign plots=boundary(hscale=samplesize) boundaryscale=triangular;
  design nstages=4 method=upper alpha=0.025 beta=0.1 stop=both
  method(alpha)=tri(tau=1) method(beta)=tri(tau=1);
  samplesize=twosample(stddev=0.045) weight=1;
run;
```

In the updated program in Example 2.7 Requesting Plots for Summary Statistics of Sequential Designs, the option plots=boundary(hscale=samplesize) produces a user-specified graphical display of the boundaries. These boundary plots include the rejection scale and the acceptance region. With the option for horizontal scale hscale=samplesize, the boundary plot is given with sample size accrued on the horizontal axis. The other boundaryscale indicates the vertical axis uses the maximum likelihood estimator (MLE).

Figure 2.4 Pocock Boundary Plot for Familial Cholesterolemia Trial and Figure 2.5 O'Brien-Fleming Boundary Plot for Familial Cholesterolemia Trial show the boundary plots of the redesigned 4-stage FH using the Pocock and OBF boundaries, respectively. As seen in the figure, the MLE represents the estimated mean difference in change from baseline carotid IMT (mm) and the Pocock boundary allows a more lenient early stopping in early stages than the OBF's. Though not shown here, it is possible to design group sequential trial with asymmetric boundaries for two-sided hypotheses take advantage of properties of the Pocock and OBF boundaries. For example, a two-sided hypothesis can be tested using an OBF bound in the direction the test treatment shows benefit and a Pocock bound in the direction the test treatment shows (compared to the control arm). This would allow the trial to stop quickly for a safety issue, while providing a higher hurdle for benefit.

## Example: Redesigning the Psoriasis Trial Allowing Both Efficacy and Futility Stopping

In this example, we want to illustrate the redesign of the psoriasis trial to test the difference between two proportions. In addition, we want to allow the trial to stop for either claiming early efficacy or futility, knowing that if the treatment is discovered to be inefficacious we do not want to continue exposing patients to an ineffective treatment. We want to use a binary design to test the difference between two proportions. The primary endpoint is the response to the treatment. The clinical outcome is a binary response.
