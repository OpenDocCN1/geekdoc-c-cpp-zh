This approach proposed by Whitehead is also known as the Christmas-tree correction. For a design with early stopping to reject or accept the null hypothesis, the boundaries form a triangle when plotted on the score statistic scale. Therefore, it is also called the triangular test. The last test is the error (also known as $\alpha$ or $eta$) spending methods. For every sequential design, the type I error $\alpha$ and the type II error $eta$ at each stage can be computed from the boundary values. Reversibly, you can derive the boundary values from specified errors for each stage. The error spending function approach [10] uses spending functions to specify the errors at each stage for each boundary and derives the boundary values accordingly. Within each type of method, you can choose approaches that range from conservative stopping boundary values to liberal stopping values at early stages.

The control of type I and II errors is applied rigorously in later phases of clinical development and hence, most of our examples in this chapter will be in the context of phase II or III trials. Although this methodology has been developed with reference to two-arm clinical trials, it applies with some modifications to the one-sample setting. For multi-arm trials in which two or more treatments arm are compared to a common control arm, the two-arm approach to control multiple looks can still be applied if supplemented by multiple testing procedures (such as Bonferroni or Hochberg) to control multiple comparisons. A thorough coverage of group sequential methods for clinical trials is offered in the textbook by Jennison and Turnbull, which is an excellent source of indepth materials on sequential analysis [11]. In addition, Todd also provided a comprehensive 25-year review of the application of sequential methods [12].
