# 6.3 Considerations in the Design and Final Analysis Stages

Statistical thinking and considerations in the study-design stage (i.e., before data are available) could be different from those in the analysis stage (i.e., after the data are available). The main purpose of this chapter is to summarize our thinking on dose-response study design. Meanwhile, we think it may be helpful to provide a few examples with relevant SAS code for readers to practice in the analysis stage after data are available. There are many analysis approaches in the analysis stage, this chapter is not intended to summarize all possible analysis approaches.

Therefore, 6.2 Statistical Design Considerations in a Classical Dose-Response Study demonstrates an example of thinking in the statistical design and clinical development stage, while the key focus in 6.4 Analysis Examples Using Simulated Data is the analysis stage, assuming that data are already collected and unblinded for the analysis. So the main purpose in the next section is to demonstrate two for analyzing unblinded data using SAS.

Please note that 6.2 Statistical Design Considerations in a Classical Dose-Response Study describes a factor type (ANOVA) model, which technically is a linear model. 6.4 Analysis Examples Using Simulated Data utilizes nonlinear regression models. Designing a study using nonlinear regression models is not the focus of this chapter, but it could be used and is built on the asymptotic distributions. Complete coverage of this field has been presented in [23].
