# ## Example: Redesigning the Psoriasis Trial Allowing Both Efficacy and Futility Stopping

In this example, we want to illustrate the redesign of the psoriasis trial to test the difference between two proportions. In addition, we want to allow the trial to stop for either claiming early efficacy or fut, knowing that if the treatment is discovered to be inefficacious early, we do not want to continue exposing patients to the ineffective treatment. We also want to demonstrate how one can monitor the trial using proc seqtest and make necessary adjustments to the trial designs as it goes along during course.

Example Code 2.8 Efficacy and Futility Boundaries for the Psoriasis Trial

```
proc segdesignscale=mle plots=all;
proccobdfesignforso; design nstages=4 alt=upper alpha=0.025 beta=0.14 stop=
method(alpha)=ppc method(beta)=obf;
samplemodel=twosamplefref (nullprop=0.07 prop=0.4 test=prop weight=2)
ods output Boundary=boundaryinfo;

proc print data=stageldata; run;

proc genmod data=stageldata;
```
