The first set of codes allows proc seqdesign to determine the number of events for a clinical trial of fixed size. By setting nstages=1 and leaving out the specification of method, it corresponds to the fixed-sample design. Under the null hypothesis, the hazard rates for trial T and control C are specified in this order: nullhazard=1.8 1.0 0 so that their ratio is 1.8. Under the alternative hypothesis, we only need to specify the hazard rate for treatment T since for control C is assumed to be the same, i.e. 1.0, such that hazard=1.0 for T. Alternatively, we can use hardradratio=1.0. Although the output for a fixed trial is not shown, the required number of events needed 122. Similar coding for Stage 2, by replacing 1.8 and 0.5878 with 1.3 and 0.2624, respectively; 611 events are required for the trial of fixed size.
