
Therefore, the stochastic process statistic

```
$S_0(t_j) = \sqrt{\frac{\pi_T(t_j) - \pi_C(t_j)}{\pi_C(1-\pi_C) n_j r(1-r)}}
```

follows $N(0, t_j)$ with independent increments under the null hypothesis.
Under the alternative hypothesis, the stochastic process statistic

```
$S_1(t_j) = \sqrt{\frac{\pi_T(t_j) - \pi_C(t_j)}{(\pi_C+\theta_1)(1-\pi_C-\theta_1) n_j r + \pi_C(1-\pi_C) n_j(1-r)}}$
```

```
$n_J = \{\frac{(\pi_C+\theta_1)(1-\pi_C-\theta_1)}{r} + \frac{\pi_C(1-\pi_C)}{(1-r)}\} l_J$
```

and for a given target power, we can search for the value of $\eta_1$ and use to estimate the maximum information $I_J$ needed. Using the above formula, we can find the needed maximum sample size $n_J$. During the planning stage of the trial, we do not know the true value of $\pi_C$ which is considered a nuisance parameter. Sometimes, a pilot sample is used to provide an initial estimate of $\pi_C$.

Again, if it is a non-inferiority trial design having a non-inferiority margin under $\theta_0$ with sequential monitoring in $J$ stages, the stochastic process statistic will be

```
$S_0(t_j) = \sqrt{\frac{\pi_T(t_j) - \pi_C(t_j)-\theta_0}{(\pi_C+\theta_0)(1-\pi_C-\theta_0) n_j r + \pi_C(1-\pi_C) n_j(1-r)}}$
```

following $N(0, t_j)$ under the null hypothesis. But, under the alternative hypotheses,

```
$S_1(t_j) = \sqrt{\frac{\pi_T(t_j) - \pi_C(t_j)}{(\pi_C+\theta_1)(1-\pi_C-\theta_1) n_j r + \pi_C(1-\pi_C) n_j(1-r)}}$
```

follows $N(\eta_{t_j}, t_j)$ where $\eta = (\theta_1 - \theta_0)\sqrt{t_{ij}}$ is the drift parameter.

## 2.3.4 Survival Endpoint

Adopting similar notations as normal and binomial endpoints, we design a sequential trial that uses a time-to-event endpoint and monitor it up to J interim stages. We denote the monitoring calendar times as $c_1, c_2, \dots c_j$. At calendar time $c_j$, we observe $f_j$ failures or events of interest, with their corresponding event times (on patients' follow-up time-scale, normal calendar time-scale) denoted by $e_1(c_j), e_2(c_j), \dots, e_j(c_j)$.

We further let $d_T(e_i(c_j))$ be the number of events on treatment $T$ and $n_T(e_i(c_j))$ be the number of subjects at risk for the treatment arm $T$ where $i = 1, 2, \dots, f_j$. As for let $d_C(e_i(c_j))$ and $n_C(e_i(c_j))$ be defined similarly. We also let $d(e_i(c_j)) = d_T(e_i(c_j)) + d_C(e_i(c_j))$ be the total number of events in both arms, and $n(e_i(c_j)) = n_T(e_i(c_j)) + n_C(e_i(c_j))$ be the total number of subjects at risk for failure in both arms, at calendar time $c_j$.

Then the log-rank score statistic $L(c_j)$, observed at calendar time $c_j$ is given by summing up the observed number of events in treatment arm $T$, as follows:

```
$L(c_j) = -\sum_{i=1}^{f_j} \{d_T(e_i(c_j)) - \frac{n_T(e_i(c_j))d_C(e_i(c_j))}{n(e_i(c_j))}\}$
```

If $T$ and $C$ have the same underlying distribution, as in null hypothesis, it is well-known [11] the marginal distribution of $L(c_j)$ is asymptotically normal with a mean of zero and variance of

```
$Var[L(c_j)] = \sum_{i=1}^{f_j} \frac{n_T(e_i(c_j))n_C(e_i(c_j))[n_T(e_i(c_j))-d_T(e_i(c_j))]}{[n(e_i(c_j))^2[n(e_i(c_j))-1]}$
```

Since this variance term cannot be estimated priori, we need to make an additional assumption of proportional hazard, that is if $\lambda_T(e)$ and $\lambda_C(e)$ are the hazard functions for treatment $T$ and $C$ respectively, then the log ratio of hazard functions

$\theta = \ln\frac{\lambda_T(e)}{\lambda_C(e)}$

is constant for all values of $\theta$. If we let $D(c_j) = \sum_{i=1}^j d(e_i, c_j)$ be the total number of events observed at calendar time $c_j$ and $r$ be the fraction of patients randomized to treatment $T$, then $L(c_j)$ is asymptotically normal with the following mean and variance

$E[L(c_j)] = \theta D(c_j)r(1-r)$.

$Var[L(c_j)] = D(c_j)r(1-r)$.

It can be shown that the sequential log-rank statistics $L(c_1), L(c_2), \dots, L(c_j)$ have independent increments, that is if $j_1 < j_2$, $L(c_2)-L(c_1)$ are independent.

Similarly, if we define the treatment effect to be the log ratio of hazard functions above, then the null hypothesis is

$H_0 \theta = 0$

and the alternative hypothesis is

$H_1 \theta = \theta_1$

Instead of defining the information fraction on sample sizes as before, we define it as the ratio of the total number of events at $c_j$ to that at $c_J$

$t_j = \frac{D(c_j)}{D(c_J)}$

In addition, we have the stochastic statistic as

$S(t_j) = \frac{L(c_j)}{\sqrt{D(c_j)r(1-r)}}$

and

$D(c_j) = \frac{l_J}{r(1-r)}$ such that $S(t_j)$ follows $N(\eta, t_j)$ where $\eta = (\theta_1-\theta_0)\sqrt{t_j}$ under the alternative hypothesis. Under the null hypothesis, $S(t_j)$ will follow $N(0, t_j)$. In trials that use time-to-event outcomes such as progression-free survival (PFS) or overall survival (OS), the maximum number of events $D(c_j)$ is important to the determination of the study’s power, instead of the maximum sample sizes $n_j$ as in trials using normal or binomial outcome. For more practical details in theories of sequential testing, readers are encouraged to consult the *SAS/STAT User’s Guide* for fuller explanations.

## 2.4 Types of Stopping Boundaries

### 2.4.1 Calculation of Stopping Boundaries

We have provided an overview of the distributional theory of sequential testing in the previous section. This section focuses on the calculation of stopping boundaries. Based on the specified hypotheses, stopping boundaries can be either one-sided or two-sided. In addition, depending on the prospective outlook of the trial, investigators can specify if the set of boundaries is (1) reject the null hypothesis ($H_0: \theta = \theta_0$), (2) reject the null hypothesis ($H_0: \theta = \theta_0$), or (3) reject the alternative hypothesis ($H_1: \theta \neq \theta_0$). Only in the first case, we call this set of boundaries efficacy boundaries while for the third case, we call it utility boundaries. We can consider planning a clinical trial with a maximum of $J$ monitoring interim stages with information fractions $t_1, t_2, \dots t_J$. If the sequential testing procedure is set at the desired $\alpha$-level, then the stopping boundaries should reflect this type of I error. In addition, if we want to achieve a target power of $1-\beta$ under the alternative hypothesis ($H_1: \theta \neq \theta_0$), then we can find the maximum information needed $l_J$ and hence the sample size $n_J$ or number of events $D(l_J)$ needed.

As we have seen earlier, there are two ways to specify the statistics, the Wald statistic $Z(t_j)$ or the stochastic process statistic $S(t_j)$. Because of the property of independent increments for the stochastic process statistic $S(t_j)$, it will be easier to illustrate the stopping boundaries using this scale. Since a relationship exists between the two, $S(t_j) = Z(t_j)\sqrt{t_j}$, the corresponding stopping boundaries for the Wald statistics can be easily obtained by appropriate transformations. In the most general form, we know that $S(t_j) \sim N(\theta_0, t_j) = \eta = (\theta_1-\theta_0)\sqrt{t_j}$. In the following sections, we will look into three commonly used types of stopping boundaries. They are (1) p-value method, which is also known as the Haybittle-Peto boundaries, (2) unified family (power) methods, which include the Wang-Tsiatis boundaries [22], the Pampallona-Tsiatis boundaries [23], and the triangular method proposed by Barnett and Emerson [4], and (3) Error Spending methods, which include the Lan-DeMets [10], the Gamma [24] and the Rho [25] boundaries. Brief descriptions of these methods can be found in Methods of Stopping Boundaries.
