# 3.3.2 Classification of Methods Used to Control Type I Error Rate

Historically, most of the original methods were developed and published as a standalone work referencing only related methodology. As the number of adaptive designs with SSR grew, so did the confusion about them and the need for a systematic review emerged. Perhaps one of the most comprehensive approaches to provide a unified view of type I error control in adaptive designs is the work by Posch, Bauer and Brannath [21]. They argue that most of the type error control methods in adaptive trials that involve SSR can be viewed as some form of combination test, making it the cornerstone of the methodology. This is the approach that we will follow. A less philosophical and more pragmatic view is to break all methods into two categories: either performing a non-standard analysis by modifying test statistic/rejection region or performing a standard analysis, but restricting conditions under which this analysis can be done. Some examples are given below; the list is by means exhaustive:

+   1. Perform a non-standard analysis at the end of the trial:

a. Adjust the test statistic ([22]) down-weighs the 2nd stage data in case of a sample size increase

b. Adjust critical region [23]

c. Preserve conditional error function [24]

d. Combine p-values for the 2 stages (before and after the SSR) and re-define the critical region for the combined value [25]

e. Dual test (elaborates on the p-value combination test addressing some of its potential pitfalls) [26]

2. Perform a standard analysis at the end but state conditions under which sample size can be increased [3, 27, 28].
