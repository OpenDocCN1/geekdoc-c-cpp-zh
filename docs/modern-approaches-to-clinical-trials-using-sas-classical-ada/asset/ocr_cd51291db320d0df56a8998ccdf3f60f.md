A clinical trial was designed to investigate if an approved biological product is effective specifically in treating psoriasis of the feet and/or hands [14]. The primary efficacy outcome of this randomized, placebo-controlled trial was the response of achieving Physician's Global Assessment of the hands and/or feet (hfPAG) score of "clear" or "almost clear" at week 16. It has been assumed that the expected response rate for the investigational product is 40% but only 7% for placebo. Based on the superiority testing framework and the specification of Fisher's exact test, the sample sizes per arm, under a 2:1 treatment-to-placebo allocation scheme, are $n_T=50$ and $n_C=25$, achieving power of 86%, as calculated below in [Example Code 2.2 Power Calculation for Psoriasis Trial]. The type I error was set as one-sided, $\alpha=0.025$. The results of this psoriasis trial are given in [Results of Psoriasis Trial for Anti-TNF on hfPAG Response].

# Example Code 2.2 Power Calculation for Psoriasis Trial

```
proc power;
twosampleref test=fisher
groupportion=(0.4 0.07) groupns=(50 25)
alpha=0.025 sides=1 power=;
run;
```
