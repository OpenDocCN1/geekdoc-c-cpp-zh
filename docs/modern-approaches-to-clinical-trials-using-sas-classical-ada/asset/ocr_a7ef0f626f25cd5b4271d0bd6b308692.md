# Group Sequential Design

We will consider a GSD with one interim look to detect a treatment difference of 0.19 with a possibility of stopping early if the interim treatment difference is more than 0.25. As mentioned before, GSD can be a very appealing option if the savings in the potential study duration are adequately balanced with the savings in the sample size. In our hypothetical example, we conduct an interim analysis when approximately 50% of the subjects have observed the primary endpoint. For this design, we would assume that the sponsor is interested in stopping for efficacy and does not want to stop the trial for futility. Based on this assumption, we will choose the error spending function to evaluate at the interim look. In most cases, the type I error is spent very conservatively in the early look so that a decision of efficacy stop is triggered if only the results are compelling towards the new treatment. Hence, we will use an error spending function that mimics the O’Brien-Fleling boundary. Example Code 3.3 Sequential Design with Efficacy Boundaries shows how this can be done in SAS using method (alpha)=ERRFUNCF Of Using method (alpha)=ERRFUNGAMMA(GAMMA-4) in proc seqdesign [32].

Example Code 3.3 Sequential Design with Efficacy Boundaries

```
proc seqdesign altref=0.19 errspend pass(cref=0.5 0.5 1)
stoprob(cref=0.5 0.5)
plots=(asn power errspend)
boundscale=std2;
OneSidedErrorSpending: design nstages=2
```
