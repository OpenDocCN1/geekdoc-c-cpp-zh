The partial output for these two redesigned trials (Figure 2.2 Output for Pocock Boundaries for Example Code 2.6 and Figure 2.3 Output for O'Brien-Fleming Boundaries for Example Code 2.6) shows a summary of the design information. The OBF method has a smaller maximum information (or inflation factor) of 102.2% than the Pocock method with 118.3%. However, the Pocock method has a smaller average sample number (ASN in percentage of the total sample size from fixed-sample design under the alternative hypothesis, 69.7% compared to 76.7%. This is due to their differences in stage-wise stopping probabilities and monitoring patterns.
