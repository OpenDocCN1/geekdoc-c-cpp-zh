# 7.2.1 Original MCP-Mod Approach

In this section we first provide a short, technical description of the original MCP-Mod approach [2] for a single, normally distributed efficacy endpoint. Afterwards, we describe a recently developed variant of MCP-Mod that extends the methodology to dose-finfinding studies for general parametric models (e.g. for binary, count, or time-to-event endpoints and including certain longitudinal modeling approaches), [4].

The MCP-Mod procedure is implemented in five steps; see also Figure 7.1 High-Level Overview of the Original MCP-Mod Procedure :

+   1. At the trial design stage, identify several candidate dose-response shapes, which are likely to represent the underlying true dose-response.

+   2. Derive optimum contrast coefficients, such that the marginal power to detect a specific dose-response shape that is associated with the respective candidate model is maximized.

+   3. At the analysis stage, evaluate the significance of the individual shapes in terms of a multiple contrast test based on the previously optimal contrast coefficients, to assess whether a dose-response signal can be established. This constitutes the MCP part of MCP-Mod.

+   4. Select a candidate model using a model selection criteria such as AIC or BIC or use model averaging.

+   5. Use the selected model(s) to produce inferences on adequate doses, employing a model-based approach. This constitutes the Mod part of MCP-Mod.
