| 23 | 0.7 | 0.6 | 0.4 | 0.05 | 0.17842 | 0.82158 |

The parameters p1, p2, and p3 could be computed using the Monte-Carlo method. The treatment outcomes follow a Normal distribution (Example Code 11.2), the &simnorm macro computes the smallest sample size that provides a specified power $1-\beta$ for rejecting the null hypothesis using formula (6) in [25]. The parameters to be specified are:

+   1. seed1, seed2: randomization seeds used for generating random numbers

+   2. mux, muy: mean of treatment outcomes for the control and experimental groups

+   3. stdx, stdy: standard deviation of treatment outcomes for the control and experimental groups

+   4. beta: type II error rate

+   5. alpha: type I error rate

+   6. simN: number of iterations for Monte-Carlo simulation.

# Example Code 11.2 SimNorm Macro for Computing Required Sample Size

```
%macro simnorm(seed1, seed2, mux, muy, stdx, stdy, beta, simN=10000, alpha=0)
data x;
  call streaminit(&seed1);
  do i=1 to &simN
    x=rand('normal', &mux, &stdx);
    output;
  end;
run;

data y;
  call streaminit(&seed2);
  do i=1 to &simN
    y=rand('normal', &muy, &stdy);
    output;
  end;
run;

data one;
  merge x y;
```
