
估计值为 0.01（每组 75 名患者），对比 0.02（每组 100 名患者），而 emax 均值为 0.24（每组 75 名患者），对比 0.24（每组 100 名患者），但 ed50 均值为 22.04（每组 75 名患者），对比 10.37（每组 100 名患者）。此外，ed50 的后验分布存在差异：每组 75 名患者的 95% 置信区间为 (0.12, 48.30)，而每组 100 名患者的 ed50 为 (0.60, 19.53)。每组 100 名患者的 ed50 先验在 0 到 20 之间是均匀；此上限反映在 ed50 的后验分布中。作为敏感性分析，在相同的模拟数据上运行了相同的先验，但仅更改了 ed50 先验。ed50 先验被设置为均匀分布 (0, 81)，表示整个给药范围而非均匀分布 (0, 20)，所有其他先验保持不变。使用新先验后，ed50 后验分布的均值（标准差）为 53.24 (8.81)，95% 置信区间为 (37.96, 68.82)。这进一步阐明了先验可能会结果产生影响并需要仔细讨论，并使理解临床终点围绕先验的生物学依据至关重要。

## 8.4 二分类终点的分析示例

针对系统性红斑狼 (SLE) 适应症的 IIb 期研究计划已经开始。该研究将使用系统性红斑狼反应者指数 (SRI) 作为主要终点。为了在 SRI 中被认为是反应者，受试者的主要症状评分 (SLEAI-2K) 必须减少 4，且根据医生评估症状没有恶化，并且次要症状评分 (BILAG) 最高两个类别中没有新的器官领域评分。必须满足这三个标准才能被视为反应者。已决定本研究将包含三个活性剂量组和一个安慰剂组，每个剂量组有 60 名受试者。初始样本量估计假设安慰剂反应为0.4，在 $\alpha=0.05$ 且效能为 80% 的情况下治疗反应为 0.65。新化合物的剂量反应将在给药 24 周后进行评估，以估计进入 III 期测试的最优剂量（假设研究成功）。该分析提出了一个贝叶斯模型。

SLE 上最后获批准的药物是贝西尤单抗，它使用 SRI 二分类终点进行注册。在两个 III 期研究中，562 名测试受试者中有 218 名安慰剂受试者是反应者，反应率为0.388。假设新试验中的安慰剂受试者率与这些 III 期试验相同，则该 0.388 的估计值可用于 $E$ 的先验分布。因此，logit(0.388) 将用于 $E$ 参数信息量正态先验的中心趋势估计值。拟议的新化合物研究比这些研究小，且被认为具有更大的变异。此外，仅使用了两项研究来提供安慰剂反应的信息，因此将使用弱信息先验。为了使先验分布弥散，采用了方差 4。

%macro binmaxsim(ntrt=0,p1,p2,p3,p4,p5,p6,p7,p8,npergrp,dpdrop,s
data sims
  data sims (Keep = subject treatment dose response);
  format treatment $88;
  subject = 0;
  do trt = 0 to &ntrt;
    do i = 1 to &npergrp;
      subject = subject + 1;
      if trt = 0 then do;
        treatment = "Placebo";
        dose = 0;
      end;
      else do;
        treatment = "Active";

    end;
  run;

  table response * dose count pct;
run;

data sum_dt;
  set sum_dt;
  total = sum(count) by=dose;
  pct = (count / total)*100;
end;

```proc mcm data = sum_dt outpost = emax nmc = 150000 seed = 1234
  monitor (ed50 predose1 predose3 predose9 pipred0 pipred1 pipred9) = stats(percent = 2.5 5.0 10.0 95 97.5);
ods output PostIntervals = intervals;
  ods output Summaries = summaries;
  prior e0 = ~normal(mean=-0.45,var=4);
  prior emax = ~normal(mean=0,var=4);
  prior ed50 = ~uniform(0,15);
  data;
  predose1 = exp(e0+(emax*1))/(1+e0+(emax*1));
  predose3 = exp(e0+(emax*3))/(1+e0+(emax*3));
  predose9 = exp(e0+(emax*9))/(1+e0+(emax*9));
  pipred0 = exp(e0+(emax*0))/(1+e0+(emax*0));
  pipred1 = exp(e0+(emax*1))/(1+e0+(emax*1));
  pipred3 = exp(e0+(emax*3))/(1+e0+(emax*3));
  pipred9 = exp(e0+(emax*9))/(1+e0+(emax*9));
  end;
  eta = e0 + ((emax*dose)/(ed50+dose));
  expeta = exp(eta);
  p = expeta/(1+expeta);
  model count ~ binomial(total, p);
run;
```
