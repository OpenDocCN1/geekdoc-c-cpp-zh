Suppose that a new patient enters the trial on 10-May-2011, then we can use the SAS macro %crm to determine the dose level for this participant. If the cohort size is three, each patient's information in the cohort must be recorded separately to compute each individual contribution to the likelihood. Towards this goal, one needs to input the information of the twelve patients, including their observed toxicity outcomes, indicators of whether they have been fully followed, their entering dates and the dates of DLT occurrences. If a patient has completed the follow-up period without experiencing toxicity, we input the date as the last day of the follow-up period. If a patient has not experienced toxicity but is still in the follow-up period, his/her censor is specified as the current decision-making date: 10-May-2011.

The %crm macro (Example Code 5.4 Fractional CRM Macro) requires the following input variables. The location of the km.sas file should be specified in the %include statement.

+   1. currentdata is the data set that stores the accumulated information. More specifically, users need to input the dose level (doselevel), DLT outcome (DLT, 1 if DLT is observed, 0 otherwise), the indicator variable (followup) that denotes whether the patient is still under the follow-up period in the trial, the entry date (entrydate), and the event date (timetoevent) of the patient.
2. skeleton is the data set that stores the prespecified skeleton.
3. currenttime is the current date (entry date for the new patient).
4. tau is the length of the full follow-up period for toxicity evaluation.
5. target is the target toxicity rate.
6. tostop is the threshold probability to early terminate the trial if the lowest dose level is too toxic.
