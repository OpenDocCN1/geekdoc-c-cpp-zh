For illustration, we present an example to demonstrate how to achieve balance on two prognostic factors: sex and tumor stage. Assuming equal weights $w1=w2=1 for sex and tumor stage, suppose 40 subjects have been enrolled and the next subject entering the trial is a male patient with tumor stage I. If this new participant were assigned to arm B, the total imbalance between the two treatment groups would be minimized, in contrast to being assigned to arm A. Therefore, this subject will be assigned to arm B with a larger probability, say 0.75, in order to reduce the imbalance of treatment assignment.

> % MinimizationRandomize macro performs the minimization method to sequentially allocate the newly recruited subjects. To invoke the macro, users need to specify four input parameters:

+   1. TreatedPatients is the data set that contains the information of the patients who have already been assigned treatments. The first column in the data set indicates the treatment for each patient, and the remaining columns correspond to prognostic factors, whose values should be discrete integers starting from 1.

+   2. FactorWeight is the data set that specifies the weights for prognostic factors.

+   3. NewPatient is the data set that stores the covariate information of the new patient.

+   4. p is a large probability ($p > 0.5$) which is specified to reduce the imbalance of prognostic factors.
