## 4.2 元设计设置

### 4.2.1 符号

我们考虑 $K$ 个随机试验，每个试验有两个治疗组，分别表示为控制组和实验组，且 $K \ge 1$。控制组可以是安慰剂或活性对照，而实验组在临床试验设置中可能是研究药物。然而，在医疗器械应用中，控制组可能是旧一代医疗设备，实验组可能指新一代医疗设备。为了方便表述，我们通地将这两组称为控制组和实验组。

令 $n_{jk}$ 表示第 $k$ 个随机试验中第 $j$ 个治疗组的样本量，其中 $j=1$ 和 $j=2$ 分别表示控制组和实验组，$k=1, \dots, K$。我们写下 $n_k = n_{1k} + n_{2k}$，表示第 $k$ 个随机试验的总样本量。我们还让 $p_k$ 和 $r_k$ 分别表示第 $k=1, \dots, K$ 个试验中控制组的受者比例和年化事件率。控制组受者比例在分配样本量到控制组和实验组时起着作用。使用该量，我们有 $n_{k} = [p_k n_k]$ 和 $n_{kk} = n_k - n_{k}$，其中 $[p_k n_k]$ 是小于或等于 $p_k n_k$ 的最大整数。年化事件率是事件在一年内发生的预设概率。它还用于指定 4.6 计算算法中讨论的采样先验中平均生存时间的设计值。最后，我们让 $\tau_k^A$ 和 $\tau_k^F$ 分别表示 $k=1, \dots, K$ 个试验的招募时间和最小随访时间。

### 4.2.2 元试验设计变量的输入数据

《双臂元试验的通用设计》（General Design of Meta-Trials with Two Arms）展示了上一节介绍的 $K$ 个双臂随机试验的通用生存元实验设计设置。从表 4.1 中，我们看到输入数据包含每个试验的试验 ID (TID)、总样本量 ($n$)、控制组比例 ($\rho$)、控制组的年化事件率 ($r$)、试验时长 (TD) 和招募时间 (TA)。利用试验时长与招募时间之间的关系，我们计算每个试验的最小随访时间 (TF)，即 $TF_k = TD_k - TA_k$。我们注意到，这些输入数据用于生成 4.6 计算算法中讨论的预测数据。从 4.6 计算算法中提出的先验预测数据算法，我们对 $TD_k \ge 0$、$TF_k \ge 0$、$TD_k \ge TF_k$ 和 $TD_k > TA_k$ 施约束。(4.1)

在 (4.1) 中，如果所有受者都在试验开始时加入试验；如果 $TF_k=0$，则没有最小随访要求；如果 $TD_k \le TF_k + TA_k$，则受者在加入试验后，在整个试验期间都接受随访。此外，运行 4.7 节讨论的 SAS 宏 BSMED 还需要：研究数量 ($K$)、MCMC 样本数 (NMCS)、烧入样本数 ($nbi$)、模拟数据集数量 ($REP$)、设计裕量 ($\varrho$) 以及用户定义的贝叶斯置信水平 ($n_0$) 作为输入变量。

### 4.2.3 输入数据

假设从 $K_0$ 个之前的试验中获得了控制组和实验组的历史数据。对于历史数据，我们定义：
$x_{0k} = \begin{cases} 1, & \text{如果 } y_{0k} \le n_{0k} \\ 0, & \text{否则} \end{cases}$
其中 $x_{0k} \in \{0,1\}$ 表示历史数据仅对控制组可用。如果 $k=1,\dots,K_0$ 时 $x_{0k}=1$，则历史数据对两组可用。例如，如果 $k=1,\dots,K_0$ 时 $x_{0k}=0$，则历史数据仅对控制组可用。在此设置下，我们令 $y_{0k} = (y_{0k1},y_{0k2})$ 表示事件总数。
