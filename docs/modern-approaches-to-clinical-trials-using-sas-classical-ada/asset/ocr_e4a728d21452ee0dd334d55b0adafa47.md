# 11.4.2.2 Biomarker-Adaptive Threshold Design

In this design [32], the test for overall treatment effect is combined with the development and validation of a pre-specified cutpoint for a biomarker-based subgroup believed to be most sensitive to the targeted treatment. The statistical hypothesis test is carried out by splitting the overall type I error rate α. First, compare the treatment response on the overall population at α1, and if not significant, then perform the second test at α-1. For example, if the null hypotheses of no benefit (a) is rejected at a desired significance level of, say 0.04, then the testing is stopped or else the testing is carried out to the hypothesis in (b) 0.01 to control an overall α below the 0.05. A simplified cutoff model proposed by Altman et al. [33] is used to develop the proposed procedure. The overall patient population is divided into two groups: biomarker-based (sensitive) and non-biomarker-based (non-sensitive). This categorization may result in some loss of information, but the proposed testing procedure is robust to departures from the simplified cut-off model. A permutation resampling approach is used for selection of the optimal cutpoint to avoid multiplicity problems [34].

An approach to sample planning for clinical trials when the treatment effect is restricted to a subpopulation is presented in Appendix B in [32]. Assume that in a trial with time-to-event outcomes, the required number of observed events for the overall test to detect the target treatment effect (at significance level α) with power 1-β could be calculated by events macro in Example Code 11.5 Number of Events for Biomarker-Adaptive Threshold Design.

Example Code 11.5 Number of Events for Biomarker-Adaptive Threshold Design

```
%macro events(delta, alpha, beta, pi);
  data result;
    alpha=&alpha;
    power=1-&beta;
    delta=&delta;
    pi=&pi;
    za=quantile('Normal', 1-&alpha);
    zb=quantile('Normal', 1-&beta);
    logd=log(delta)/log(delta);
    D=4*(za+zb)/log(delta)**2;
    DS=D/(pi**2);

  label delta='hazard ratio';
  label pi='treatment effect fraction required';
  label Ds='events required';

run;
```
