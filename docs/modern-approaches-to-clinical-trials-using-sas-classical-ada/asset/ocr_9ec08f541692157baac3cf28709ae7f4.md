Alternatively, Maitournam and Simon [25] derived sample size formulas that should be more accurate for small sample sizes using the Mann–Whitney Wilcoxon test.

Macros ($eta_{norm}$ and $eta_{sigma}$) are developed for calculating the sample size for a certain power based on formula (6) in [25].

```
Power = 1-\\Psi\left(\\frac{0.5n^2+z_{1-\alpha/2}}{\sqrt{\frac{2(n+1)}{12}Var(W_{XY})}}-0.5n^2p_1\right)$
```

$Var(W_{XY})$ is the variance of the Mann-Whitney statistic given by

$Var(W_{XY}) = n^2\{p_1(1-p_1) + (n-1)[p_2+p_3-2p_2^2]\}$, where $p_1=Pr(X<Y)$ is the probability that a control outcome $X$ is less than a treatment outcome $\gamma$, and $p_2=Pr[X<Y_1,X<Y_2]$ is the probability that a control outcome is simultaneously less than two independent treatment outcomes, and $p_3=Pr[X_1<Y,X_2<Y]$ is the probability that a treatment outcome is simultaneously greater than two independent control outcomes. $\Psi$ denotes the cumulative distribution function for the standard normal distribution. Please refer to $efficiency\_ct.sas$ in the supplemental material of the book.

The $\%MSpower$ macro (Example Code 11.1) computes the smallest sample size that provides a specified power $1-\beta$ for rejecting the null hypothesis using formula (6) in [25]. The parameters to be specified for $\\%MSpower$ are

+   1. beta: type II error rate

+   2. alpha: type I error rate

+   3. pi: probability that a control outcome is less than a treatment outcome
