# 3.3.5 Methods Based on the Conditional Type I Error Principle

This group of methods computes the probability of rejecting the null hypothesis at the end of the trial of the interim data and uses it to guide interim decisions. One of the most well-known methods from this category is the conditional error probability method by Prochan and Hunsberger [23]. The conditional rejection probability is defined as

```
$CP_\zeta(N-n, z_\alpha|Z_n) = Pr(Z_n > z_\alpha|Z_n, \zeta)$
```

where $n$ and $N-n$ are the Stage 1 and Stage 2 sample sizes per group, respectively $Z_n$ is a standardized normal test statistic used under the original design and $\zeta$ is a standardized hypothesized effect size. When the above conditional probability is calculated under a non-zero $\zeta$ (either hypothesized effect size or observed), it becomes a conditional power. If it is calculated under $\zeta=0$, then it becomes a error probability. Integrated over all possible realizations of $Z_n$, the conditional error probability becomes the overall type I rate. One could reduce the type I error inflation resulting from data-driven sample size adjustment by selecting a larger critical value $z_\alpha$ at the final stage and agreeing to continue the trial only if the first stage p-value $p_1 < p^*, p^* \in(0, 0.5]$ (e.g. if $p^*$ is set to 0.15, which would translate into accepting the probability of futility in case the p-value from the first stage $p_1 \geq p^*=0.15$). However, these measures would only keep overall type I error below $\alpha$, but not give an exact $\alpha$-level procedure.
