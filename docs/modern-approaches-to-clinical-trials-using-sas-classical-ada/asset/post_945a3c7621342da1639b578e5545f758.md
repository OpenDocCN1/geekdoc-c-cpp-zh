These alterations to the original plan can change the operating characteristics of the study unless suitable adjustments are made in the interim monitoring phase. Therefore, in the interim monitoring phase, adjustments by implementing the error spending methodology are necessary. Any negative impact of each interim analysis on the conduct of the trial to the next stages should also be assessed and minimized if continuation is warranted.

In a group sequential design, the control of type I error is of great importance, because repeated significant tests at a fixed level on accumulating data increase the probability of a type I error [3]. Therefore, the same critical value for a fixed sample test cannot be applied to each stage of sequential design. For example, with a fixed-sample two-sided test, the critical values ±1.96 for a standardized statistic produce a type I error probability level $\alpha = 0.05$. For a two-sided sequential test with two equally spaced stages, if the critical values are used to reject the null hypothesis at these two stages, the type I error probability level is $\alpha = 0.083$, larger than the fixed-sample $\alpha$.

There are several types of methods for calculating boundary values or critical values. The first type is the fixed boundary shape method which derives boundaries based on specific boundary shapes. Examples of fixed boundary shape methods are the unified family methods and the Haybitt-Peto method. The unified family methods [4] derive boundaries from specified boundary shapes. These methods include the Pocock method [5] and the O’Brien-Fleming (OBF) method [6] as special cases, among others. The Haybitt-Peto method [7, 8] uses a value of 3 for the critical values on the scale of the $\chi$-statistic in interim stages, so the critical value at the final stage is close to the critical value for fixed-sample design. The second type is the Whitehead method which adjusts boundaries derived for continuous monitoring so that they apply to discrete monitoring [9]. With continuous monitoring, the values for each boundary fall in a straight line when plotted on the score statistic scale. By subtracting the expected overshoot from the continuous boundary, the discrete boundary is derived to obtain the desired type I and type II error probabilities. This approach proposed by Whitehead is also known as the Christmas-tree correction. For a design with early stopping to reject or accept the null hypothesis, the boundaries form a triangle when plotted on the score statistic scale. Therefore, it is also called the triangular test. The last test is the error (also known as $\alpha$ or $\beta$) spending methods. For every sequential design, the type I error $\alpha$ and the type II error $\beta$ at each stage can be computed from the boundary values. Reversibly, you can derive the boundary values from specified errors for each stage. The error spending function approach [10] uses spending functions to specify the errors at each stage for each boundary and derives the boundary values accordingly. Within each type of method, you can choose approaches that range from conservative stopping boundary values to liberal stopping values at early stages.

The control of type I and II errors is applied rigorously in later phases of clinical development and hence, most of our examples in this chapter will be in the context of phase II or III trials. Although this methodology has been developed with reference to two-arm clinical trials, it applies with some modifications to the one-sample setting. For multi-arm trials in which two or more treatments arm are compared to a common control arm, the two-arm approach to control multiple looks can still be applied if supplemented by multiple testing procedures (such as Bonferroni or Hochberg) to control multiple comparisons. A thorough coverage of group sequential methods for clinical trials is offered in the textbook by Jennison and Turnbull, which is an excellent source of in-depth materials on sequential analysis [11]. In addition, Todd also provided a comprehensive 25-year review of the application of sequential methods [12].

In order to illustrate the practical aspects of group sequential methods, this chapter is organized in the following sections. 2.2 Examples of Classical Fixed-Sample Designs presents four examples of typical clinical trials that have used the fixed-sample design to calculate the total sample size. 2.3 Theories of Group Sequential Tests explains the distributional theories of group sequential testing with a focus on normal, binomial, and time-to-event endpoints. 2.4 Types of Stopping Boundaries provides more details on the derivation of stopping boundary values and their properties. Examples in SAS are given throughout this section to illustrate how the fixed sample size scenarios are in 2.2 Examples of Classical Fixed-Sample Designs can be redesigned into a group sequential setting. 2.5 Special Issues briefly discusses some special issues in trial monitoring.

## 2.2 Examples of Classical Fixed-Sample Designs

Before we develop the theories of group sequential methods, we will describe four examples that use the fixed-sample design.

### Example 1: Pravastatin in Familial Hyperchololemia

Familial hyperchololemia is a genetic disorder characterized by high cholesterol levels. In this trial, pravastatin 20mg daily or placebo were randomized for 2 years. The primary outcome was carotid intima-media thickness (IMT). Under a fixed-sample design, assuming equal allocation, we can calculate the sample size per arm as follows:

$n_T = n_C = \frac{2(z_a+z_g)^2}{\sigma^2}$

$z_a$ is the $(1-\alpha)$ percentile of the normal distribution, and similarly is $z_g$. We allow a one-sided type $\alpha=0.025$ and power of $90\%$ such that $\beta=0.1$. $\sigma$ is the standard deviation of the primary outcome, and $\theta$ is the treatment difference. The results of this trial are tabulated in Table 2.1 and Example Code 2.1 below.

#### Table 2.1 Results of Familial Hyperchololemia Trial for Pravastatin on Carotid IMT

| Treatment Arm | n | Mean Change From Baseline, mm | SD | p-value |
|---|---|---|---|---|
| Pravastatin | 104 | -0.010 | 0.048 | 0.020 |
| Placebo | 108 | 0.005 | 0.044 | --- |

#### Example Code 2.1 Sample Size Calculation for Familial Hyperchololemia

```sas
proc power;
  twomeans test=diff
  meandiff=0.02 stddev=0.045
  alpha=0.025, sides=1 power=0.9 notal=;
run;
```
