```
$n_T = n_C = \frac{2(z_a+z_g)^2}{\sigma^2} \quad (2.1)$
```

$n_T$ and $n_C$ are the sample sizes for the pravastatin and placebo, respectively. $z_a$ is the $(1-\alpha)100\%$ percentile of the standard normal distribution, and similarly is $z_g$. The parameter $\sigma$ is the standard deviation of the primary outcome assumed known for both groups, and $	heta$ is the treatment difference in the primary outcome assumed that we are interested in detecting. In this case, we allow a one-sided type rate $\alpha=0.025(z_a=1.96)$ and power of $90\%$ such that $eta=0.1(z_g=1.28)$. Samples of measurements with without FH were obtained to provide initial estimates for $\sigma$ which was $0.045$ mm and the treatment difference $	heta$ was $0.02mm$. Therefore, the sample size per arm to achieve the target statistical power of $90\%$ is $n_T=n_C=106$. The results of this trial are tabulated in Table 2.1 and Example Code 2.1 below using the exact two-sample Student's $t$-test. In SAS, `proc power` adjusts the sample size slightly upwards to $n_T=n_C=108$ to account for the loss of freedom in estimating the standard deviation in the Student's $t$-test.

# **Example Code 2.1 Sample Size Calculation for Familial Hypercholesterolemia**

```
proc power;
  twomeleans test=diff
  meandiff=0.02 stddev=0.045
  alpha=0.025, sides=1 power=0.9 notal=;
run;
```
