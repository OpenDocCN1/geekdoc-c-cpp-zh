
4. p2: probability that a control outcome is simultaneously less than two independent treatment outcomes

5. p3: probability that a treatment outcome is simultaneously greater than two independent control outcomes.

Example Code 11.1 MSPower for Computing Required Sample Size

```sas
%macro MSPower(beta, p1, p2, p3, alpha);
  data result;
    delta=1-(alpha/2);
    za=quantile('Normal', delta);
    p1=&p1; p2=&p2; p3=&p3;alpha=&alpha;
    do i = 1 to 10000;
      nsize=i;
      denom=(i**2)*(p1*(1-p1) + (i-1)*(p2 + p3) - 2*(p1**2));
      den=sqrt(denom);
      a=0.5+(i**2) + za*sqrt((i**2)*(2*i + 1)/12) - 0.5 - (i**2)*p1)/den
      beta=CDF('Normal', a);
      power=1-beta;
      output;
      if beta<=&beta then i=10000;
    end;
  end;
run;

data result2;
  set result end = __;
  end=end;
  end;
  if beta>&&beta then do;
    warning=1;
    nsize2=>10000;
  end;
  else do;
    nsize2=compress(nsize);
  end;
  label nsize2='sample size';
run;

proc format;
  value wa='required sample size greater than 10000';
run;

proc noobs label;
  var nsize2 p1 p2 p3 alpha beta power warning;
  format warning wa.;
run;
%mend MSPower;

%MSPower(0.2, 0.7, 0.6, 0.4, 0.05);
```

The parameters p1, p2, and p3 could be computed using the Monte-Carlo method. The treatment outcomes follow a Normal distribution (Example Code 11.2), the ~simnorm macro computes the smallest sample size that provides a specified power $1-\beta$ for rejecting the null hypothesis using formula (6) in [25]. The parameters to be specified are:

- 1. seed1, seed2: randomization seeds used for generating random numbers
- 2. mux, muy: mean of treatment outcomes for the control and experimental groups
- 3. stdx, stdy: standard deviation of treatment outcomes for the control and experimental groups
- 4. beta: type II error rate
- 5. alpha: type I error rate
- 6. simN: number of iterations for Monte-Carlo simulation.
