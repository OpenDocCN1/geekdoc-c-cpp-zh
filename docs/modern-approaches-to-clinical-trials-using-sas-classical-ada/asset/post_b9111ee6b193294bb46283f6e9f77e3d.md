
## Example Code 8.2 Analysis of Asthma Trial with 75 Patients Per Group

```sas
/** MCMC syntax sets the data set to output posterior summaries, sets
number of monte carlo iterations along with the seed, parameters to monitor,
plots to monitor autocorrelation and thinning **/
proc mcmc data = outemaxsim nmc = 50000 nbi = 1000 seed = 3746
monitor = (param, var_sub, std_sub, ed50, len50)
thin = 9 stats (percentile.5 15 50 75 95 97.5);
ods output PostsummariespostIntervals-intervals;
param e0 max len50) /** set parameters **/
/** Setting prior for each parameter **/
prior e0-normal(mean=0, precision=10)
prior emax-normal(mean=0.20, precision=10)
prior tau-gamma(shape=0.001, scale=0.001)
prior len50-normal(mean=-0.69, precision=0)
beginprior
  /** Setting residual variance ***/
  var_sub = 1/tau;
  std_sub = sqrt(var_sub);
  /** Ed50 ***/
  ed50 = exp(len50);
  /** Calculating the posterior predictive distribution ***/
  Preddist output=predout nsim=5000 covariates=Sumstat;
enddata;
mu = e0 + (emax/dose)/(ed50 + dose);
model response - normal(mean=mu, precision=tau);
run;
```

The proc mcmc statement uses the input data set sims (data = ) that we have generated using the macro Example Code 8.1 Simulated Data for Asthma Trial with 75 Patients Per Group. The posterior samples will be saved in the emax_out data set using the outpost option. In this example, 50,000 markov chain simulations (nmc) are planned with 1,000 burn-in samples (nbi) and a thinning rate of 3 (thin), implying that every 3rd simulation sample is kept with the remaining samples discarded. The model parameters and all initial values are specified in the prior specified in the prior statement, the priors are specified in the prior statement.

Once the posterior distributions are computed, mcmc computes the point estimates of the parameters, along with the standard deviation and percentiles. By default, only the quantiles are provided but one can specify percentiles using the stats(percent =) option in the proc mcmc procedure also generates graphs of the posterior samples such as generated by default with ods deviance information criterion (dic), which could be used as a model diagnostic tool when multiple chains are used (not shown), and highest posterior density (HPD) intervals (not shown). The mcmc trace plots, auto-correlation plots, and kernel density plots. These are generated as shown in Figure 8.1 Diagnostic Plots for e0, Figure 8.2 Diagnostic Plots for Emax, Figure 8.3 Diagnostic Plots for tau, Figure 8.4 Diagnostic Plots for Ned50, and Figure 8.5 Diagnostic Plots for var_sub. The trace and autocorrelation plots provide a good visualization of the convergence. The trace plots for the parameters e0, emax, ed50 indicate that the Markov chain has stabilized and that the chain has good mixing properties. The auto-correlation plot shows a low degree of auto-correlation among posterior samples for the three parameters (potentially due to the thinning of the posterior samples).

## 8.3.2 Asthma Trial with 100 Patients Per Group

For the previous example consider the situation that the sponsor did not conduct phase II studies for the experimental drug. The pre-clinical data for the experimental drug will shed light on the potential ED50 and the maximum effect of the drug. Due to the lack of clinical data, the pre-clinical data (after applying some uncertainty around them) is posed as diffused priors for the analysis.

The code for the simulated data remains the same as in the previous example, except that the planned sample size per group is 100 instead of 75, and the seed changes. The conamaxsim macro was rerun after updating nprxgrp = 100 and seed = 9865 (Example Code 8.3 Analysis of Asthma Trial with 100 Patients Per Group).

The summary data for the results of this simulation are provided in Dose Summary of Asthma Trial with 100 Patients Per Group. The proc mcmc call with new priors is provided in Example Code 8.3 Analysis of Asthma Trial with 100 Patients Per Group. The prior for E0 remains unchanged. The diffused prior is assumed to be normally distributed with mean 0.15 and a low precision of 1 (as opposed to a precision of 10 for the previous example). ED50 is also diffused assuming a flat prior between 0 and 20. In this example there is no clinical information on the drug, hence we assume a flat prior from 0 to 20. If we had more information on the drug (similar to the previous example), we could have assumed a beta distribution bounded at 20 and tweaking the parameters of the beta distribution to make it informative. ## Example 8.3 Analysis of Asthma Trial with 100 Patients Per Group

```sas
proc mcmc data = outemaxsim nmc = 80000 nbi = 1000 seed = 9865
monitor = (param, var_sub, std_sub, ed50, len50)
thin = 3 stats=(percentile.5 15 50 75 95 97.5);
ods output PostsummariespostIntervals-intervals;
param e0 max len50) /** sets parameters **/
/** Setting prior for each parameter **/
prior e0-normal(mean=0, precision=1);
prior tau-gamma(shape=0.001, scale=0);
prior len50-uniform(0, 20);
beginprior
  /** Setting residual variance ***/
  var_sub = 1/tau;
  std_sub = sqrt(var_sub);
  /** Ed50 ***/
  ed50 = exp(len50);
  /** Calculating the posterior predictive distribution ***/
  Preddist output=predout nsim=5000 covariates=Sumstat;
enddata;
mu = e0 + (emax/dose)/(ed50 + dose);
model response - normal(mean=mu, precision=tau);
run;
```
