For our example, the 2:1 allocation ratio is specified in weight=2, meaning that the treatment group will receive patients double that of the placebo group. The plotsall option requests all plots available in the procedure: boundary plot, average sample size (ASN) plot, error spending plot and power plot (see Figure 2.7 Plots for the Redesigned Psoriasis Trial with Efficacy and Utility Boundaries). Again, we have chosen the MLE scale for the vertical axis, but other options exist: score (score statistics), stds (default, standardized Z statistics), and pvalue (p-values). Lastly, ods output the output of the boundary information to a data set named boundaryinfo, which can be used for monitoring the clinical trials using proc seq.
