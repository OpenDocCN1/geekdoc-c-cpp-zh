# 2.3.4 Survival Endpoint

Adopting similar notations as normal and binomial endpoints, we design a sequential trial that uses a time-to-event endpoint and monitor it up to J interim stages. We denote the monitoring calendar times as $c_1, c_2, \dots c_j$. At calendar time $c_j$, we observe $f_j$ failures or events of interest, with their corresponding event times (on patients') follow-up time-scale, normal calendar time-scale) denoted by $e_1(c_j), e_2(c_j), \dots, e_j(c_j)$.

We further let $d_T(e_i(c_j))$ be the number of events on treatment $T$ and $n_T(e_i(c_j))$ be the number of subjects at risk for the treatment arm $T$ where $i = 1, 2, \dots, f_j$. As for let $d_C(e_i(c_j))$ and $n_C(e_i(c_j))$ be defined similarly. We also let $d(e_i(c_j)) = d_T(e_i(c_j)) + d_C(e_i(c_j))$ be the total number of events in both arms, and $n(e_i(c_j)) = n_T(e_i(c_j)) + n_C(e_i(c_j))$ be the total number of subjects at risk for failure in both arms, at calendar time $c_j$.

Then the log-rank score statistic $L(c_j)$, observed at calendar time $c_j$ is given by summing up the observed number of events in treatment arm $T$, as follows:

```
$L(c_j) = -\sum_{i=1}^{f_j} \{d_T(e_i(c_j)) - \frac{n_T(e_i(c_j))d_C(e_i(c_j))}{n(e_i(c_j))}\}$
```

If $T$ and $C$ have the same underlying distribution, as in null hypothesis, it is well-known [11] the marginal distribution of $L(c_j)$ is asymptotically normal with a mean of zero and variance of

```
$Var[L(c_j)] = \sum_{i=1}^{f_j} \frac{n_T(e_i(c_j))n_C(e_i(c_j))[n_T(e_i(c_j))-d_T(e_i(c_j))]}{[n(e_i(c_j))^2[n(e_i(c_j))-1]}$
```
