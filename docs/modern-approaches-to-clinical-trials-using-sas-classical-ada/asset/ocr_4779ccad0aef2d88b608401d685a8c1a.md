# 4.6.3 Power Calculation

We discuss how to calculate the type I error and power discussed in [6]. Let $n_0$ and $a_0$ denote prespecified Bayesian credible level and discounting parameter for the historical meta-experimental survival data, respectively. We also let $\{\gamma^{(m)}, \ m=1, \dots, NMCS\}$ denote a Gibbs sample of $\gamma_1$ from the posterior distribution $\pi(\gamma, 	heta_{D_K}, D_0, a_0)$, where $NMCS$ is the Gibbs sample size. Using this Gibbs sample, we obtain a Monte Carlo estimate of $P(e^{\gamma_1} < \delta_{\pi^{(f)}})$ given by

```
$$\hat{P}_f = \frac{1}{NMCS} \sum_{m=1}^{NMCS} I(e^{\gamma_1^{(m)}} < \delta), \quad (4.14)$
```

where $\pi^{(f)}$ is the fitting prior. To simultaneously compute the Bayesian type I error and power, $\beta_{sl}^{(f)}$ in (4.9), we use the following computational algorithm:

+   1. Set $l=0$ and input $D, D_0, n_0, \varsigma, a_0, NMCS, nbi,$ and $REP$.
2. Generate $\{(\gamma, \theta)-\pi^{(s)}\}(\gamma, \theta)$ for $s=0,1$.
3. Generate $D_K$ via the predictive data generation algorithm in Section 4.6.1.
4. Run the Gibbs sampler to generate a Gibbs sample $\{\gamma_1^{(m)}, m=1, \dots, NMCS\}$ of size $NMCS$ from the posterior distribution $\pi(\gamma, \theta_{D_K}, D_0, a_0)$.
5. Compute $\hat{P}_f$ and repeat Steps 2 through 5. $REP$ times.
6. Compute the proportions of $\{\hat{P}_f \geq 0.90\},{\hat{P}_f \geq 0.95\}$ and $\{\hat{P}_f \geq 0.975\}$ (the default option) and the proportion of $\{\hat{P}_f \geq n_0\}$ (the user's choice) in these $REP$ runs, which give the estimates of $\beta_{sl}^{(n)}$.
