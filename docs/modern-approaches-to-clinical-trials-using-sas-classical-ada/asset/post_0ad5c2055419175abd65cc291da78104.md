## 2.4.3 Unified Family Boundaries

The unified family method is also known as the one-shape method, in which a power or shape parameter $\phi_a$ is adjusted. A good example is the Wang-Tsiatis boundaries [22]. This set of boundaries is used for early rejection of the null hypothesis. Generally, on the scale of the score statistic, it takes the following

```
$c(t_j) = C(\phi_a, J)^{t_{\phi_a}}$
```

for $j = 1, 2, \dots$ and $\phi$ is a shape parameter that characterizes the boundary shape. $C(\phi, J)$ is a positive constant indexed by $\phi_a$, and $j$. If $\phi=0$ then we get the OBF [6] stopping boundaries while if $\phi=0.5$, we yield the Pocock [5] stopping boundaries. For a one-sided setting, the $j$th item occurs if $S(t_j) \geq c(t_j)$. Therefore, in order to preserve the type I error, the boundary set must satisfy the following

```
$1-P_0\{n_{j=1}^J S(t_j) < c(t_j)\} = \alpha. \quad (2.4)$
```

Since the stopping boundaries $c(t_1), c(t_2), \dots, c(t_j)$ are completely specified by the single constant defined earlier, this constant can be evaluated by numerical method of recursive integration. Once the boundaries have been determined, the maximum information $l_j$ needed can be estimated. But this time, its corresponding $\eta_j$ needs to satisfy the following equation with pre-specified target power of $1-\beta$.

```
$P_{\eta_1}\{n_{j=1}^J S(t_j) < c(t_j)\} = \beta. \quad (2.5)$
```

Using this evaluated drift parameter $\eta_1$, we can get the $l_j$ using

```
$l_j = \left[ \frac{\eta_1}{\theta_1 - \theta_0} \right]^2
```

With evaluated $l_j$, we can estimate the needed maximum sample size $n_j$ if we are using the normal or binomial endpoint, but the maximum

```
$l_j = \eta_j t_j$
```

## Example: Redesigning Familialesterolemia Trial Using Pocock and OBrien-Fleming

ods graphics on;

run;
