
## 3.4 Information-Based Design

Traditional sample size calculation takes into account both the magnitude of the treatment effect ($\delta$) and values of the nuisance parameter (e.g., the variance for continuous endpoints or the placebo response for binary endpoints), with the best guesses of the nuisance parameter used for the initial sample size calculation. However, if initial estimates of the nuisance parameters are incorrect, this can adversely impact the statistical power to detect a clinically meaningful difference, if indeed a treatment difference exists. One way of addressing this uncertainty around nuisance parameters is to utilize an information-based design. Information-based design and analysis is based on the statistical information (defined below) that is available. In other words, the study continues until the required statistical information is achieved. Here, design and analysis is based on the statistical information or precision instead of the sample size scale. Information-based designs are based on the work of several authors, which is itself based on the fundamental concept that statistical information is obtained in the same manner irrespective of the parameter $\delta$ [35-37].

For the classical design, information is defined as $I_1 = \left(\frac{Z_{\alpha/2}+Z_{\delta}}{\delta}\right)^2$. Here, the statistical information depends on both the sample size and the magnitude of the nuisance parameter. For binary endpoints, information depends on the magnitude of the placebo response. For time-to-event (survival) endpoints, information is based on numerous factors, including accrual rate, event rate, length of follow up, and drop out. In longitudinal studies, information also depends on the number of time points observed per subject. In general, statistical information ($I$) is inversely related to the standard error of the estimator $\hat{\delta}$ of the parameter $\delta$; that is, $I = \frac{1}{(SE^2)}$. Hence, the greater the information that is available, the higher the precision and in a multistage design, the maximum information available is $I_{max} = I_1*F$, where $F$ is the inflation factor, a multiplicative constant which is a function of $K$ (number of stages), the form of the error spending boundary (e.g. O'Brien Fleming or Pocock), and the type I ($\alpha$) and type II ($\beta$) errors. Tsiatis provides a table of inflation factors for different combinations of K, error spending boundaries, $\alpha$ and $\beta$ [37].

The maximum sample size ($N_{max}$) in a multistage design is a function of the maximum information ($I_{max}$) and a nuisance parameter. a test for the difference between two normally distributed means has $N_{max\Delta}=4s^2/I_{max}$; a test for the difference between two binomial proportions $N_{max}=2((p_T)(1-p_T)+(p_C)(1-p_C))/I$, for treatments T and C.

We replicate an example for a binary endpoint described in Tsiatis [37]. Consider a hypothetical two-arm trial with equal allocation designed to test the efficacy of an experimental new treatment compared to the standard of care (control). We denote $p_T$ as the rate of response in the treatment and $p_C$ as the rate of response in the control arm.

The best guess for the response on the control arm is 0.15. In order to detect a meaningful difference of 0.15 with $p_T=0.30$, 316 subjects are required for 90% power for a one-sided $\alpha=0.025$ classical design. The information required is approximately 468. Partial output from `proc seqdesign` from [Example Code 3.5 Information Based Design - Fixed Sample Size](Example Code 3.5 Information Based Design - Fixed Sample Size) is presented in [Figure 3.1 Output for Example Code 3.5](Figure 3.1 Output for Example Code 3.5).

## Example Code 3.5 Information Based Design - Fixed Sample Size

```
proc seqdesign altref=0.15;
OneSidedFixedSample: design nstages=1
al=upper alpha=0.025 beta=0.10;
samplesize model=twsamplefreq(nullprop=0.15 test=prop);
```

## Example Code 3.6 Information Based Design – 4-Stage Design

```
proc seqdesign altref=0.15;
OneSidedErrorSpending: design nstages=4
method(alpha)=errfunc altype=stop-reject alpha=0.025;
samplesize model=twsamplefreq(nullprop=0.15 test=prop);
ods output Boundary_Count;
```
