# 4. N: total sample size.

Likewise, the power of the subset test can be calculated using the macro by specifying these parameters in the sensitivity subset.

For example, if the expected probability of response for a patient receiving the experimental treatment is 0.5, and the expected probability of response for a patient receiving the control treatment is 0.2, assume the one-sided significance level is 0.05 and the total sample size is 100, then the power of the overall test is calculated by Example Code 11.4 Power for Adaptive Signature Design. In this example, the power is 94.3%.

# Example Code 11.4 Power for Adaptive Signature Design

```
%macro power(pe, pc, alpha, N);
data result;
pe=&pe;
cpcpc;
alpha=&alpha;
N=N;
nb=1&alpha;
pbar=(pe+pc)/2;
za=quantile('Normal', b);
num=(pe-pc)-2*sqrt(pbar*(1-pbar)*4/N);
dend=pe*(1-pe)*2/N+pc*(1-pc)*2/N;
alpha=num/den;
power=CDF('Normal', a);

run;

proc noobs;
var pe pc N alpha power;
run;
mend power;
%power(0.5, 0.2, 100);
```

The advantage of this design is its ability to de-risk losing the label of the broader population in pivotal trials. According to Freidlin and Simon [29], this design may be ideal to use phase II clinical trials for developing an assay or signatures for patients who respond better to targeted therapies. One drawback of this design is that only half of the patients are used for development or validation. If prevalence of the subgroup of biomarker sensitive patients is low then this design will require a large number of patients to be screened. This may not be economically feasible, and it will be operationally challenging and will extend the enrollment period. The other drawback is that with a larger number of sub-groups-lead to high dimensional data, a large sample size may be needed to adequately power the trial.
