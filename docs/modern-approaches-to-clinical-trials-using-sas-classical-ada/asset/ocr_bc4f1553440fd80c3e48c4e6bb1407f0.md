# 9.2 Simple Randomization

The simplest way of randomization, simple randomization fixes the assignment probabilities throughout the trial with no regard to historical allocation and response information. Nevertheless, the assignment probabilities can be equal or different across treatment arms. For a trial with K treatments, each trial participant is simply assigned with probability 1/K to one of the K arms under equal randomization. If a certain treatment is believed to be more beneficial, or investigators are interested in learning more about a specific drug, more patients can be randomized to that treatment arm. For instance, the allocation ratio to a new therapy versus the standard-of-care can be specified as 2:1 or 3:1.

In SAS, the SimpleRandomize macro can be utilized to design a simple randomized trial. The input variables include n, the total sample size of the trial, and groupdata, the set that stores the identities of the treatments and their corresponding allocation ratios.

As an illustration, we consider a three-arm trial with treatments A, B, and C. Based on the allocation ratio of 1:1:2, we can randomize 100 patients by calling the SimpleRandomize macro as shown in Example Code 9.1 Simple Randomization.

# Example Code 9.1 Simple Randomization

```
%macro SimpleRandomize(n, groupdata, seed);
proc iml;
  use &groupdata;
  read all;
  call randseed(&seed);

nu=j(&n,1);
  prob=ratio/sum(ratio);
  agroup=j(&n,1);
  call randgen(u, "Uniform");
  cprob = j(nrow(group),1);
  do j=1 to nrow(group);
    cprob[j]=sum(prob[1:j]);
end;
do j=1 to &n;
  k=1;
  do while (u[j]>cprob[k])
    k=k+1;
end;
  agroup[j]=k;
```
