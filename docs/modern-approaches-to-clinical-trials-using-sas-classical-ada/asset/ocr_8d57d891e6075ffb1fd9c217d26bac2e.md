The @decision macros tests the benefit of the targeted therapy against the overall population at a specified significance level α1 (α1) is usually slightly lower than the overall α. It decides if it is necessary to move to the signature component of the design (Example Code 11.6 Decision Macro Call).

# Example Code 11.6 Decision Macro Call

```
libname perm "directory of sample data";
%macro Decision(outcome, gene, par, alpha, seed);
%global seed;
%let sseed = &seed;

data outcome;
set &outcome;
run;

data gene;
set &gene;
run;

data par;
set &par;
run;

proc freq data=outcome;
table response*treatment/chisq;
out out=chisqtest quisq;
run;

data null;
set chisqtest("chis_value",P_PCHI);
run;
/*If the chi-square test is significant based on prescribed*
/*alpha, then print result and abort*/
/*Otherwise, need to move on to CVSD stage*/
%if &chisq_value <&alpha %then %do
ntitle "Chi-square Test SIGNIFICANT"
proc print data=chisqtest;
run;
%abort;
%end
%mend Decision;

%Decision(perm.adsl, perm.adgene, perm.par, 0.04,12345);
```
