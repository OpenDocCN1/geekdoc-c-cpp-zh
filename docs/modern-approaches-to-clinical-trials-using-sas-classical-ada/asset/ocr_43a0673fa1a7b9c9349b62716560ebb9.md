By using modeling techniques MCPMod allows us to interpolate information across dose-levels, and the total sample size will not depend strongly on the number of doses studied. The possibility of using more doses will typically result in information-rich dose-finding designs and a better basis for decision making at end of phase II.

MCP-Mod can be applied to a broad class of parametric models beyond the standard setup of a normally distributed endpoint in a standard ANOVA model. For example, the response variable might be a count, binary, or time-to-event variable instead of being distributed. For the generalized MCP-Mod all that is needed is an estimate of the response at the doses, as well as the associated covariance matrix. In SAS, different methods can be used to produce these estimates. proc glmix is probably the most general procedure and might thus be recommended for most situations. Another advantage is that it produces the adequate multiplicity p-values. The Mod step of the procedure can then be performed using the proc code provided, which is quite flexible, and does not depend on the underlying distribution of the endpoint. Of course, other procedures, such as proc nlin or proc mixed could be used for the Mod step. In addition, the final analysis has usually to be adjusted for relevant covariates (e.g. region, age, etc.), patients' measurements are often recorded over time (necessitating the use of longitudinal models), and patients might receive more than one treatment (as in cross-over or incomplete block designs). In this chapter we have illustrated with two real data sets, how to use the MCP-Mod approach in practice. Furthermore, we have provided relevant SAS code to enable the interested reader to implement and perform the MCP-Mod approach in many situations of practical relevance. An alternative possibility to implement MCP is via the DoseFinding R package [11], which contains extensive functionality for both the design and the analysis of dose-finding studies. The commercial software package ADDPLAN-DF contains extensive tools for designing dose-finding studies using MCP-Mod [12]. In addition, Cytel has developed PROC MCPMOD as an add-on to SAS that focuses on the analysis of dose-finding studies using MCP-Mod.
