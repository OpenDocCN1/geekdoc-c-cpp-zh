
## 2.4.4 Spending Function Boundaries

Error spending functions are the most flexible and general way of deriving the stopping boundaries. The $\alpha$-spending functions where the $\alpha$ level is pre-specified are used to control the type I error in the trial. They are monotonic functions that are defined on the unit interval with $\alpha(t)=0$ and $\alpha(t)=\alpha$. Similarly, the $\beta$-spending functions, with pre-specified $\beta$ level, are used to control the type II error. They are defined on the unit interval with $\beta(t=0)$ and $\beta(t=1)=\beta$. This idea of using an error spending function was first introduced by Lan and DeMets [10]. One can use either the $\alpha$ or the $\beta$ spending function singly or combine both of them in sequentially monitoring a single trial. They can be used for either one-sided or two-sided hypotheses, and produce either symmetric or asymmetric boundaries.

There are numerous proposed error spending functions, and we will briefly describe three of the most commonly used spending functions and their properties. The forms of the functions are expressed as $\alpha(t)$ and $\beta(t)$ where $t(0 < t < 1)$ is the information fraction. Here we illustrate the $\alpha$-spending function, but it can also apply to the $\beta$-spending function.

- 1. The Lan-DeMets spending function has two possible forms. The first closely resembles the OBF boundaries:

$\alpha(t)=2-2\Phi\left(\frac{Z_{\alpha/2}}{\sqrt{t}}\right)$ for one-sided tests, and

$\alpha(t)=4-4\Phi\left(\frac{Z_{\alpha/4}}{\sqrt{t}}\right)$ for two-sided tests.

The second closely resembles the Pocock boundaries:

$\alpha(t)=\alpha\ln<1+|\theta-1t|>$

- 2. The Gamma spending function was first proposed by Hwang, Shih and DeCani [24]. The functional form is:

$\alpha(t) = \begin{cases} a\frac{(1-e^{-\gamma t})}{(1-e^{-\gamma})}, & \gamma \neq 0; & \gamma = 0 \end{cases}$

Negative values of $\gamma$ yield spending functions that make stopping early more difficult as $\gamma$ decreases. Positive values of $\gamma$ concave spending functions that favor stopping early as $\gamma$ increases. The choice of $\gamma=0$ spends the error linearly. When $\gamma=-4$, it resembles the OBF boundaries, while $\gamma=1$ produces boundaries that resemble those of Pocock.

- 3. The Rho spending function was first proposed by Kim and DeMets [25], and was further generalized. The functional form is simply represented as:

$\alpha(t) = \alpha t^{\rho}, \rho > 0$

When $\rho=1$, the corresponding stopping boundaries resemble the Pocock stopping boundaries, but when $\rho=3$, the boundaries resemble the OBF boundaries. Large values of $\rho$ yield boundaries make early stopping more difficult, while $0 < \rho < 1$ favors early stopping.

Here we want to illustrate using an example that will derive boundaries for early rejection of either the null or the alternative hypothesis given the one-sided setting. There are two sets of stopping boundaries for this design. The upper boundary set corresponds to the early rejection of the null hypothesis, while the lower boundary refers to the early rejection of the alternative hypothesis. At the $j^{th}$ interim stage, the test statistic crosses the upper boundary, then the trial will be stopped for efficacy, but if it crosses the lower boundary, the trial is stopped for utility. We impose the constraint that the upper and lower boundaries meet at $t_j$ at the end of the trial, in order to ensure that a decision is made to reject either of the hypotheses. The upper and lower boundaries form a triangular continuation region.

We specify that these stopping boundaries will be able to preserve the type I error at the $\alpha$ level under the null hypothesis when $\theta=0$, but they can offer a target power of $1-\beta$ under the alternative hypothesis when $\theta=\theta_1$ or when the drift parameter is $\eta_1$, therefore, protecting trial by the type II error of $\beta$. We let the upper boundary at the $j$th interim stage $u_j$ and the lower boundary as $l_j$ for $j=1, 2, \dots, J$. Again, we will be able to use a numerical method to evaluate the set of boundaries which should satisfy the following equations at $t_1$:

$P_0(S(t_1) \geq u_1) = \alpha(t_1)$.

$P_{\eta_1}(S(t_1) \leq l_1) = \beta(t_1)$.

Similar conditions are evaluated subsequently at $t_2, t_3, \dots, t_j$ as follows. If we have calculated the pair of stopping boundaries up to $t_{j-1}, (l_{j-1}, u_{j-1})$, we can then find $(l_j, u_j)$ using the following equation and numerical method:

$P_0(l_1 < S(t_1) < u_1, l_2 < S(t_2) < \dots < l_{j-1} < S(t_{j-1}) < u_{j-1} \geq u_j) = \alpha(t_j) - \alpha(t_{j-1})$

$P_{\eta_1}(l_1 < S(t_1) < u_1, l_2 < S(t_2) < \dots < l_{j-1} < S(t_{j-1}) < u_{j-1} \leq l_j) = \beta(t_j) - \beta(t_{j-1})$

We specify that these stopping boundaries will be able to preserve the type I error at the $\alpha$ level under the null hypothesis when $\theta=0$, but they can offer a target power of $1-\beta$ under the alternative hypothesis when $\theta=\theta_1$ or when the drift parameter is $\eta_1$, therefore, protecting trial by the type II error of $\beta$. The upper and lower boundaries form a triangular continuation region.
