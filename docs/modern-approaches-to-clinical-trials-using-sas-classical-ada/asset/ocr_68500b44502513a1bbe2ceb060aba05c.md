# Example Code 7.3 Mixed-Model of Dose Response for neurodeg Data

```
proc glimmix data=neurodeg;
  class id;
  model resp=dose*time/solution COVB / type=UN subject=id;
  random intercept time / adjust=simulate(nsamp=1000000 seed=1) uppertailed;
```

The Mod step in this example implements a bootstrap model averaging approach. The idea is to simulate a large number $B$ of values $\mu^{(b)}$ from the 5-dimensional normal distribution with mean $\hat{\mu}$ and covariance matrix $\hat{\Sigma}$. For each of the generated bootstrap data sets, each of the four dose-response models are fitted to the simulated summaries per group using the generalized least squares approach discussed in [4]. That is the function $\Psi_m[	heta_m] = (f_m[d, 	heta_m] - \mu^{(b)})' \hat{\Sigma}^{-1}(f_m[d, 	heta_m] - \mu^{(b)})$ is minimized with respect to $	heta$ for all candidate models.
