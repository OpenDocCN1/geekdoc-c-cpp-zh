$\Psi_m(\hat{	heta}_m) + 2 \dim(\hat{	heta}_m)$. At the end one can select for each simulated replication $b$ the dose-response model that provides the best fit and use this to predict the quantity of interest (for example a target dose or the dose-response estimate at specific doses). The bootstrapping approach is implemented in $proc imal$, and details can be found in Appendix D. In some of the bootstrap resamples for some models the optimization fails with a warning message. We suspect this happens for models that cannot fit or are inadequate for the current bootstrap resample. In this case these error messages had no impact on the overall results.

Figure 7.3 Estimated Dose-Response Curve for Slopes of Disease Progression for neurodeg Data one can observe the bootstrapped dose-response curve based on 5,000 bootstrap samples. One can see that the estimated curve shows a slight unimodality, which is introduced because the point estimate for the slope at 30mg is slightly smaller than for 10mg and 3mg. Looking at how often each model was selected in the bootstrap resamples, one obtains 54% of for the model and 46% for the quadratic model. For the neurodeg data set the linear and exponential model can clearly be ruled out, but both the well as the quadratic model seem to describe the data adequately. Selecting one model over another model in such a situation is potentially problematic, because it does not represent the underlying uncertainty adequately. Using a model-averaging approach seems more realistic in this example.
