# ### 3.3.3 Methods Based on Combination Tests

# #### 3.3.3.1 Overview

For the sake of simplicity, we focus on the framework of a two-stage design (i.e. one interim analysis) comparing two treatment arms with equal allocation for a normally-distributed endpoint. It should be kept in mind that many of these methods generalize to binomial or time-to-event (TTE) endpoints based as asymptotic properties. Extension of these methodologies to trials with multiple interim analyses is possible but seldom used in practice.

As mentioned earlier, the cornerstone methodology of a p-value combination test is captured in [25,29]. The basic idea is that data from a two-stage trial can be viewed as separate pieces from the two stages, before and after the interim analysis. When testing the null hypothesis of no difference between treatment arms,

> $H_0: \delta = 0$ versus

> $H_1: \delta > 0$,

the trial decisions can be based on p-values $p_1$ and $p_2$ generated from data in Stage 1 and Stage 2, respectively. For example, at the end of Stage 2 the decision to reject $H_0$ may be based on combination function $C(p_1,p_2)$, for an appropriate $c_\alpha$ chosen to preserve the type Error rate. The only requirement for the combination function $C(p_1,p_2)$ above is that it is monotone increasing for both $p_1$ and $p_2$, and strictly increasing in one of them. It is also crucial that there is no overlap in Stage 1 and Stage 2 data, assuring independence of $p_1$ and $p_2$ (which is the foundation of p-value combination methodology).

In a trial with an unblinded SSR, the critical value for the final test is calculated so that the probability to reject $H_0$ at the final test is $\alpha$.
