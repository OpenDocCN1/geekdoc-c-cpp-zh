# 4.6.1 Predictive Data Generation

In this section, we extend the computational algorithm discussed in [6] and [10] to generate the prior predictive survival data by incorporating the trial duration $\hat{T}_k^D$ and accrual time $\hat{	au}_k^A$ discussed in 4.2 Meta Design Setting. Specifically, we use $\hat{D}_k$ and $\hat{	au}_k^A$ to construct the censoring time in the generation of the predictive survival data $D_K$ in addition to the sampling prior $\pi^{(S)}(\{\gamma, 	heta\}$. Our new prior predictive data generation algorithm is given as follows:

+   1. Generate $\{\gamma, 	heta\} \sim \pi^{(S)}(\{\gamma, 	heta\})$.

+   2. Generate $Y_{ijk} \sim f(Y_{ijk}|\theta, x_{ijk})$ independently for $i=1,\dots n_{jk}, j=1,2, k=1,\dots K$.

+   3. Set $	au_{ijk}^{*A}=0$ if $\hat{	au}_k^A=0$ and generate the accrual time $	au_{ijk}^{*A}=U(0, \hat{	au}_k^A)$ independently if $\hat{	au}_k^A>0$ for $i=1,\dots n_{jk}, j=1,2, k=1,\dots K$.

+   4. Set $C_{ijk}^{*A}=	au_k^D-\hat{	au}_k^A$ for $i=1,\dots n_{jk}, j=1,2, k=1,\dots K$.

+   5. Compute $y_{jk}=\sum_{i=1}^{n_{jk}}\min(Y_{ijk}, C_{ijk}^{*A})$ and $v_{jk}=\sum_{i=1}^{n_{jk}}\{Y_{ijk} \le C_{ijk}^{*A}\}$, where the indicator function $1\{Y_{ijk} \le C_{ijk}^{*A}\}=1$ if $Y_{ijk} \le C_{ijk}^{*A}$ and 0 otherwise for $i=1,\dots n_{jk}, j=1,2, k=1,\dots K$.

+   6. Set $D_K=\{y_{jk} \cdot v_{jk}, n_{jk}, x_{ijk}\}, j=1,2, k=1,\dots K$.
