# 7.5.1 The optcont Macro

In this section we will illustrate the application of MCP-Mod with two examples and show how to implement it using SAS. The first example illustrates the original MCP-Mod procedure for normally distributed data, as described in 7.2.1 Original MCP-Mod Approach, using a model selection approach. In this situation proc glmix can be used for the MCP step, because it allows for the calculation of the multiplicity adjusted p-values. Proc nlmixed can be used for fitting the associated nonlinear regression models and estimating target doses. The second example illustrates a more complex application of MCP-Mod in the context of a linear mixed-effect model. In this generalized, two-step MCP-Mod methodology described in 7.2.2 MCP-Mod for General Parametric Models is used. In this we also illustrate the application of a bootstrap model-averaging to perform inferences on the dose-response curve and target doses. proc glmix is used for the MCP step and proc glm is provided for the Mod step for the nonlinear model fit based on general nonlinear-optimization routines. Both examples rely on the calculation of optimal contrasts. For purpose we first describe in detail a general SAS macro optcont before discussing the specific examples.

The optcont macro implements the optimal contrasts

```
$C_{opt} \alpha \alpha' \Sigma^{-1} ( \mu - \frac{\mu' \Sigma^{-1} \mu}{\mu' \Sigma^{-1} \mu} ) $
```

In order to calculate the optimal contrasts one needs the anticipated $\mu$ of the individual doses [4]. Typically, the mean responses are determined using dose-response models given with "gestimates" for the model parameters that determine the shape of the model (see the right column of Example Dose-Response Models Often Used in Clinical Trials). Note that adding a constant to the vector $\mu$ or multiplying $\mu$ with a constant does not change the optimal contrast. That is, only the relative magnitude of the entries in $\mu$ are relevant for calculation of the optimal contrasts.
