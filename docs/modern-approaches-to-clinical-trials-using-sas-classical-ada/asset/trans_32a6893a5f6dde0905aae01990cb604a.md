
只有在对当前研究的数据进行中期评估后，才有根据增加资源，而不是根据以往研究的治疗效应进行推测。

以下是计划使用前景区法（promising zone approach）重新估计样本量的步骤：

- 1. 初始样本量为 504 名受试者，按照经典设计计算，在 80% 功效下，通过单侧 $\alpha = 0.025$ 检验检测 $\delta = 0.25$。

- 2. 计划在 252 名受试者达到主要终点时进行中期分析。

- 3. 使用 $\gamma = -4$ 的 gamma 消耗函数计算类似于 O'Brien Fleming 的临界值 ($c_1$)。

- 4. 如果在期分析时检验统计量越过 $c_1$，则停止试验。

- 5. 如果检验统计量未越过 $c_1$，则使用治疗差异的估算值计算条件功效（conditional power）。如果条件功效在 30% 到 80% 之间，则重新估计样本量，以在估计的治疗差异下实现 80% 的条件功效。样本量增加到最多 1008，即原始样本量 504 的两倍。如果重新估计的样本量超过 1008，则最终样本量上限为 1008。如果条件功效小于 30% 或大于 80%，研究按原 504 名受试者的样本量继续。

“经典设计与自适应设计的运行特性”（Operating Characteristics of Classical and Adaptive Design）比较了乐观 $\delta = 0.25$ 下的三种情况：

- 1. 经典设计的功效和总样本量（见“经典设计与组序贯设计的运行特性”）。

- 2. 自适应设计的总体功效和平均总样本量。

- 3. 前景区内自适应设计的功效和平均总样本量。

场景 2 和 3 是同一种设计，只是分别在整体和前景区展示评估结果。

表格结果显示，自适应设计的总体功效比乐观 $\phi$ 下经典设计高出 4% 到 6%；然而，前景区内的样本量增加确保了试验在具有临床意义的差异下具有 80% 的理想功效。平均而言，试验有 25% 的时间落在前景区。前景区法提供了额外的灵活性，仅在期分析结果良好时才增加样本量。在实践中，应根据项目需求进行大量模拟以确保理想特性。前景区的最小和最大条件功效可以更改，或者添加额外的无效边界。

“经典设计与组序贯设计的运行特性”以及“经典设计与自适应设计的运行特性”中的自适应和组序贯设计使用示例 3.4 中的 SAS 宏 `%SSR_CP` 生成。以下简要总结该宏的参数：

- 1. nSamp：模拟次数
- 2. alpha：期望 $\alpha$ 水平
- 3. beta：期望 $\beta$ 水平
- 4. cont：对照组响应
- 5. trt：治疗组响应
- 6. delta：治疗组与对照组的响应差值
- 7. Nmax：待承诺的最大样本量
- 8. r：治疗组与对照组的随机比例
- 9. t：期分析的时间
- 10. c1：$Z$ 标准下的期分析有效边界
- 11. c2：最终分析的 $Z$ 标准下有效边界

在宏 `%SSR_CP` 中，对于组序贯设计，Nmax 设置为 700 的样本量，而对于 SSR 设计则设置为 1008 的样本量。第一阶段后，计算条件功效 (CP) 并试验分为四个区域：

- 1. 无效 (UNFAVORABLE)：CP < 0.3
- 2. 前景 (PROMISING)：0.3 ≤ CP ≤ 0.8
- 3. 有效 (FAVORABLE)：CP > 0.8 且 $Z_1 < c_1$
- 4. 显著 (EFFICACY)：CP > 0.8 且 $Z_1 \ge c_1$

在无效和有效区域，样本量设置为 504 (固定)；在显著区域试验以 504 ($n_1$) 的样本量停止；而在前景区重新估计样本量，使条件功效达到 80%。如果重新估计的样本量大于 1008，则最终样本量 (final) 设置为 1008。从配套文件中下载“经典设计与组序贯设计的运行特性”和“经典设计与自适应设计的运行特性”的代码。

示例 3.4 SAS SSR_CP

```sas
%Macro SSR_CP(Namp,alpha,beta,sigma,cont,trt,delta,Nmax,r,t,c1,c2,title=);
data SSR;
/** 随机分配 **/
/** 通过 n 和 (1-r) 以及 n2 = r 计算总样本量和每组总人数，使得活动组比例和总样本量 **/
size=$delta.*ceil(probit(1-alpha)+probit(1-beta));
/** 期分析时的总量 **/
nl=(c1.*fixed);
n2=fixed-nl;
c_seed1=736; t_seed1=624;
c_seed2=786; t_seed2=819;

do i=1 To Namp;
nl=round((1-r).*nl);
n2=round(r).*nl);
cont=Rannor(c_seed).*sigma/sqrt(n1);
trt=Rannor(t_seed1).*sigma/sqrt(n2);
deltah1=trt-c1;
sel=$sigma/sqrt(1/nl/(1-r));
Z1=deltah1/sel;
/** 计算条件功效 **/
cp=1-probit(c2).*sqrt(n1/(fixed-n1))-Z1*(n1/(fixed-n1))-deltah1*sqrt(&(1-r).*sqrt(fixed-n1)/sigma);
if cp < 0.3 or cp <= c1 then zone="PROMISING";
else if (cp > 0.8) and Z1 >= c1 then zone="FAVORABLE";
else if (cp > 0.8) and Z1 < c1 then zone="EFFICACY"

fixed=fixed;
w1=sqrt(n1/nl);
w2=sqrt(n2/n2);
if zone("PROMISING") then do;
a=c2./w2;
zbt=Probit(1-beta);
k=w2;
n2tilda=n1*((a+zbt)/z1-k)**2)+nl;
end;
n2ilda=n2ilda;
rejectho=0;
estop=0;
if zone("EFFICACY") then do;
n2ilda=n1;
rejectho=1;
zch=z1;
estop=1;
end;

if n2ilda > nmax then final=nmax;
else final=n2ilda;
output;
end;
run;
mend SSR_CP;
```
