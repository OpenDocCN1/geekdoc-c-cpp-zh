In a group sequential design, the control of type I error is of great
importance, because repeated significant tests at a fixed level on
accumulating data increase the probability of a type I error [3].
Therefore, the same critical value for a fixed sample test cannot be
applied to each stage of sequential design. For example, with a fixed-
sample two-sided test, the critical values ±1.96 for a standardized
statistic produce a type I error probability level $\alpha = 0.05$. For a two-
sided sequential test with two equally spaced stages, if the
ccritical values are used to reject the null hypothesis at these two stages,
the type I error probability level is $\alpha = 0.083$, larger than the fixed-
sample $\alpha$.

There are several types of methods for calculating boundary
values or critical values. The first type is the fixed boundary shape
method which derives boundaries based on specific boundary shapes.
Examples of fixed boundary shape methods are the unified family
methods and the Haybitt-Peto method. The unified family methods [4]
derive boundaries from specified boundary shapes. These methods
include the Pocock method [5] and the O’Brien-Fleming (OBF) method
[6] as special cases, among others. The Haybitt-Peto method [7, 8]
us a value of 3 for the critical values on the scale of the $\chi$-statistic in
interim stages, so the critical value at the final stage is close to the
critical value for fixed-sample design. The second type is the
Whitehead method which adjusts boundaries derived for continuous
