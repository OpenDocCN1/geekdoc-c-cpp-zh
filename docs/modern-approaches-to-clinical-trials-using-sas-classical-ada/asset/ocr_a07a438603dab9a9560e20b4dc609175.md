# Example: Designing Sequential Tests for Assessing Cardiovascular Risk for Type 2 Diabetes Mellitus

When evaluating CV risk for T2DM, many development options are possible; we limit our focus to a single cardiovascular outcomes trial (CVOT) to further illustrate the methods used for group sequential designs. The pros and cons of various approaches to assess CV risk for T2DM are discussed elsewhere [26, 27]. As described, for Stage 1 we can re-write the non-inferiority null hypothesis as $H_{10}: 	heta \le 0$ where $	heta = -\ln(\Delta_T / \lambda_C) + 0.5878$ and $ln(1.8) = 0.5878$. The alternative hypothesis becomes $H_{11}: 	heta > 0$. This is the preferred parameterization in SAS and Code 2.11 Sequential Analysis for Cardiovascular Outcome Trial of Type 2 Diabetes Mellitus is used to illustrate this example.

Example Code 2.11 Sequential Analysis for Cardiovascular Outcome Trial of Type 2 Diabetes Mellitus

```
* Fixed-design for Stage 1 testing, default=0.1 *
proc seqdesign;
stagefixed: design stages=1 alt=twosided alpha=0.05;
samplesize model=twamplesurv(nullhazard=1.8 1.0 hazard=1.0);
```
