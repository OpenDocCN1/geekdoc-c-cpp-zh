ignoring the different treatment assignments. For simplicity we discuss the case of equal allocation to treatment groups. For two normal samples with (unknown) means $\mu_{trl}$ and $\mu_{ctrl}$, the common variance $\sigma^2$ (nuisance parameter) can be estimated as follows:

```
$$\hat{\sigma}^2_{OS} = \frac{1}{n-1}\sum_{i=1}^{n}(X_{ij} - \bar{X})^2$$
```

where $n$ is an interim per-group sample size and $X_{ij}$ is the observed interim data with observed $\bar{X}$. The key idea here is that the overall variability is a sum of between- and within-group variability, and the former is substantially smaller in clinical trials than the latter. Even though the above estimator of variance $\hat{\sigma}^2_{OS}$ is ignoring the between-treatment variability component (and therefore is biased upward when treatment difference is non-zero), it is still a practically useful estimate because the impact of this bias is small for typical noise-to-signal ratios encountered in clinical trials.

A natural extension of this method correcting for the bias is given in an adjusted one-sample variance method [6]:

```
$$\hat{\sigma}^2_{adj} = \hat{\sigma}^2_{OS} - \frac{n}{2(2-n)}\Delta^2$$
```

The magnitude of correction depends on the interim sample size $n$ and the value of $\Delta = \mu_{trl} - \mu_{ctrl}$, where $\Delta$ is the hypothesized treatment effect for which the study was powered. Following the interim analysis, the originally planned sample size $N=f(\alpha, 1-\beta, \hat{\sigma}^2, \Delta)$ is replaced by $M=f(\alpha, 1-\beta, \hat{\sigma}^2, \Delta)$ where $\hat{\sigma}^2$ is calculated as $\hat{\sigma}^2_{adj}$ or $\hat{\sigma}^2_{OS}$ and function ($f$) refers to standard sample size calculations for a two-sample t test. Alternatively, a restriction $M<N$ is placed on the sample size adjustment requiring that the new sample size is $max(M,N)$, resulting in a restricted design. The operating characteristics (power and type error) depend very much on which version (restricted or unrestricted) is specified. It has been shown by simulation that blinded SSR trials using unrestricted design can lead to slight power losses and negligible type error inflation [5].
