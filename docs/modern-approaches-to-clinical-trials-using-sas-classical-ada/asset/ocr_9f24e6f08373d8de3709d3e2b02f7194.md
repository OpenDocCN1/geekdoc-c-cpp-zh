Below are the steps planned for sample size re-estimation using the promising zone approach:

+   1. The initial sample size of 504 subjects is computed as in the classical design with 80% power to detect $\delta = 0.25$ with a one-sided $\alpha = 0.025$ text.

+   2. An interim analysis is planned when 252 subjects reach the primary endpoint.

+   3. An O'Brien Fleming-like critical value ($c_1$) is computed using a gamma spending function with $\gamma = -4$.

+   4. The trial is stopped if the test statistic crosses $c_1$ at an interim analysis.

+   5. If test statistic does not cross $c_1$; then the conditional power is computed using the estimated value of treatment difference. The conditional power is between 30% and 80%, then the sample size is re-estimated to achieve 80% conditional power at the estimated treatment difference. The sample size is increased to a maximum of 1008, twice the original sample size of 504. If the re-estimated sample size is more than 1008, the final sample size is capped at 1008. If the conditional power is less than 30% or greater than 80% the study continues with the original sample size of 504 subjects.
