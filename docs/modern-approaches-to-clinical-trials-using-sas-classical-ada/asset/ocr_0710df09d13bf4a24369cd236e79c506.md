The first step of MCP-Mod is to identify a set of $M$ parameterized models together with prior parameter values for their standardized responses. When used with the doses planned for the trial, $d_1, ..., d_k$, these candidate models produce mean responses $\mu_m = [\mu_{m1}, ..., \mu_{mk}]$, where $\mu_{mi} = \mu_m(d_i, \theta_{2m})$ with a specified parameter $\theta_{2m}$ and $\mu_m$ is the $m$th dose-response function, $m=1, ..., M$.

The second step is to test each of the dose-response shapes in the candidate set using a single contrast test, with coefficients chosen to maximize the power of the test when the underlying mean response equals $\mu_m$. This approach form the test for a dose-response trend in terms of a linear contrast $c_\mu$, where $c$ is a contrast vector such that $\sum c_i=0$ and $\mu$ is the true mean at the dose levels. For any given vector $\mu$, optimum contrast $c(\mu_i - \mu^*), i=1, ..., k$, which after normalization leads to the unique solution (up to the sign) $c/||c||$, where $\mu^* = \mu/k$.
