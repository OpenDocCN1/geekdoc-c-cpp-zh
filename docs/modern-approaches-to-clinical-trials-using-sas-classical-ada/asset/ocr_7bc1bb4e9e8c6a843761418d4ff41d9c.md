# 2.5 Special Issues

So far, we have demonstrated some statistical implementation of group sequential methods to clinical trials with different primary objectives. The validity of the trial that uses the sequential testing procedures relies heavily on strict adherence to the pre-specified stopping rules. In practice, deviations from the rules during the trial are common, and as a result, may compromise the integrity and interpretability of the final results. The rigidity of adhering to the rule presents challenges when deviations are ethically necessary and justified. Recent research on clinical trial monitoring introduces the use of conditional power and predictive power within the Bayesian paradigm. As discussed earlier, due to possible inflation of type I error, binding utility extends no flexibility in continuing the trial when utility boundary is crossed, while non-binding utility offers flexibility but may increase sample size. Conditional power [29] and predictive power [30] become additional monitoring tools for sequential designs that only reject the null hypothesis. Conditional power at the ith stage is defined as the total probability of rejecting the null hypothesis at any future stages given the observed statistic at stage j. A small conditional power ((≪05)) signals a small probability of declaring a successful trial given the current observed evidences. The trial can be stopped to accept the null hypothesis. Predictive power is the posterior probability that the test statistic at the final stage would exceed the rejection value given the observed data and a prior distribution of the hypothetical reference. Usually, a non-controversial non-informative prior is used in calculating the predictive power. The following SAS code updates the example on monitoring the psoriasis trial.

Example Code 2.12 Conditional and Predictive Power for the Psoriasis Trial

```
proc segdesn boundaryscale=mle plots=all;
cobdefboundary: design ngasts=4 upper alpha=0.025 beta=0.14 stop=
method(alpha)=poc;
samplesize model=2samplefreq (nullprop=0.07 prop=0.4 test=prop weight=2)\ods Output=boundaryinfo;
run;
proc test boundary=boundaryinfo parms(testvar=trt)=cref=0.5, 1, 25)
infoadj=none boundaryscale=mle condpower
predpower plots=condpower;\ods output Test=boundaryinfo2;
run;
proc test boundary=boundaryinfo2 parms(testvar=trt)=paraest2
infoadj=none boundaryscale=mle condpower(cref=0.5, 1, 1.25)
predpower plots=condpower;
```
