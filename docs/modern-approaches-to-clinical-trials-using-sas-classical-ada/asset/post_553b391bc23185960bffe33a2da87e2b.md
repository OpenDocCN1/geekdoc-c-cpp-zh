
## 3.3.2 Classification of Methods Used to Control Type I Error Rate

Historically, most of the original methods were developed and published as a standalone work referencing only related methodology. As the number of adaptive designs with SSR grew, so did the confusion about them and the need for a systematic review emerged. Perhaps one of the most comprehensive approaches to provide a unified view of type I error control in adaptive designs is the work by Posch, Bauer and Brannath [21]. They argue that most of the type error control methods in adaptive trials that involve SSR can be viewed as some form of combination test, making it the cornerstone of the methodology. This is the approach that we will follow. A less philosophical and more pragmatic view is to break all methods into two categories: either performing a non-standard analysis by modifying test statistic/rejection region or performing a standard analysis, but restricting conditions under which this analysis can be done. Some examples are given below; the list is by exhaustive:

- 1. Perform a non-standard analysis at the end of the trial:
    a. Adjust the test statistic ([22]) down-weighs the 2nd stage data in case of a sample size increase
    b. Adjust critical region [23]
    c. Preserve conditional error function [24]
    d. Combine p-values for the 2 stages (before and after the SSR) and re-define the critical region for the combined value [25]
    e. Dual test (elaborates on the p-value combination test addressing some of its potential pitfalls) [26]
- 2. Perform a standard analysis at the end but state conditions under which sample size can be increased [3, 27, 28].

### 3.3.3 Methods Based on Combination Tests

#### 3.3.3.1 Overview

For the sake of simplicity, we focus on the framework of a two-stage design (i.e. one interim analysis) comparing two treatment arms with equal allocation for a normally-distributed endpoint. It should be kept in mind that many of these methods generalize to binomial or time-to-event (TTE) endpoints based as asymptotic properties. Extension of these methodologies to trials with multiple interim analyses is possible but seldom used in practice.

As mentioned earlier, the cornerstone methodology of a p-value combination test is captured in [25,29]. The basic idea is that data from a two-stage trial can be viewed as separate pieces from the two stages, before and after the interim analysis. When testing the null hypothesis of no difference between treatment arms,

$H_0: \delta = 0$ versus

$H_1: \delta > 0$,

the trial decisions can be based on p-values $p_1$ and $p_2$ generated from data in Stage 1 and Stage 2, respectively. For example, at the end of Stage 2 the decision to reject $H_0$ may be based on combination function $C(p_1,p_2)$, for an appropriate $c_\alpha$ chosen to preserve the type Error rate. The only requirement for the combination function $C(p_1,p_2)$ above is that it is monotone increasing for both $p_1$ and $p_2$, and strictly increasing in one of them. It is also crucial that there is no overlap in Stage 1 and Stage 2 data, assuring independence of $p_1$ and $p_2$ (which is the foundation of p-value combination methodology).

In a trial with an unblinded SSR, the critical value for the final test is calculated so that the probability to reject $H_0$ at the final test is $\alpha$. In practice it is very rare for a trial to include a chance for SSR but not offer an opportunity for an early efficacy/futility stop at an interim analysis. Combination test methods can be applied to such trials. Suppose that the trial has pre-specified efficacy/futility boundaries for Stage 1, similar to those under a group sequential design. In that case, the critical value has to be calculated accounting for the possibility of early stopping. The decision tree for a combination method takes the following form:

**End of Stage 1**

- If $p_1 < \alpha_1$, the trial stops early for efficacy
- If $p_1 > \beta_1$, the trial stops early for futility
- If $p_1 < \alpha_1 < \beta_1$, the trial continues into Stage 2, possibly with sample size change

**End of Stage 2**

- Decision to reject $H_0$ is made based on $C(p_1, p_2) \le c_\alpha$.

When calculating $c_\alpha$ in the above case, the overall type I error is

$Pr(p_1 < \alpha_1) + Pr(\alpha_1 < p_1 < \beta_1) \cap C(p_1, p_2) \le c_\alpha)$,

where probabilities are calculated under the null hypothesis of no treatment difference. For the sake of simplicity, we put aside the issue of early efficacy/futility stopping and focus on unblinded SSR as the only adaptation for the remainder of this chapter.

The most widely used combination tests include Fisher’s combination test and the inverse method discussed below. Both combine pvalues. Because there is a one-to-one correspondence between p-values and test statistics, they can also be viewed as test combination methods. In Fisher’s combination test, $C(p_1, p_2) = p_1p_2$. In the case of the inverse normal method [21],

```
C(p_1, p_2) = [Φ⁻¹(1-p_1) + Φ⁻¹(1-p_2)]
```

### 3.3.3.2 CHW Procedure as a Special Case

The most widely used combination tests include Fisher’s combination test and the inverse method discussed below. Both combine pvalues. Because there is a one-to-one correspondence between p-values and test statistics, they can also be viewed as test combination methods. In Fisher’s combination test, $C(p_1, p_2) = p_1p_2$. In the case of the inverse normal method [21],

$C(p_1, p_2) = [\Phi^{-1}(1-p_1) + \Phi^{-1}(1-p_2)]$

The method of Cui, Hung and Wang (CHW) can be viewed as a special case of a combination method with $w_1 = \sqrt{n/N}$ and $w_2 = \sqrt{(N-n)/N}$. The type I error property of the CHW method does not depend on what rule is used to determine the sample size and it does not require any cap on $M$. The original CHW paper suggests selecting sample size $M$ based on the power argument or setting $M=g(\Delta_0/\Delta_L)^2$, where $\Delta_L$ is the estimated treatment effect at the interim analysis and $\Delta_0$ is the treatment effect used to determine the original sample size. Another way to select the sample size $M$ is to plug-in an interim estimate of treatment effect $\Delta_L$ into a sample size calculation formula for a normally-distributed endpoint. Regardless of how the sample size is selected, the type I error rate will be preserved as long as the sample size adjustment is the only modification.
