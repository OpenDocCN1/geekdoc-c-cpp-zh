
然而，从研究设计的角度来看，也可以使用 PoC（概念验证）假设来计算样本量。同样，这种 PoC 可以仅基于针对安慰剂的最高剂量，也可以基于包含两个两个治疗组在内的对比方案。当然，如果目标是撰写一个反映底层模型的对比方案，则可以考虑更多样化的对比方案。

## 6.2.7.2 选择与安慰剂的治疗差异

在设计剂量爬坡临床试验时，识别最小临床意义差异（MCID）的概念是必须的。尽管在实践中，有时很难客观地建立一个被广泛接受的 MCID，但在计算临床试验的样本量时，将治疗差异 ($\delta$) 作为目标是至关重要的。换句话说，没有 $\delta$ 就无法计算样本量。因此，如果对于给定的适应症存在 MCID，它对新产品的临床开发将非常有帮助。

通常在 III 期临床试验中，用于试验设计的治疗差异主要基于该产品在早期研究中观察到的结果。但在 II 期早期，这种 $\delta$ 并不容易获得。通常，在实践中有三种方法可以获得用于设计早期 II 期临床试验的 $\delta$。一种流行的方法是使用其他产品的数据，特别是当已经有批准用于普通患者人群的产品时。在美国，产品获批后，美国食品药品管理局（FDA）会发布该产品的批准摘要性依据（SBA）。在欧洲，欧洲药品管理局（EMA）会发布欧洲公共评估报告（EPAR）来解释为什么该产品获准公众使用。通常，从 SBA 或 EPAR 中都可以观察到治疗差异。在某些情况下，从出版物、产品标签或注册网站（如 clinicaltrials.gov）中可以找到其他产品的治疗差异信息。因此，通过使用其他产品的观察治疗差异，可以选择一个 $\delta$ 来帮助这项新研究的设计。

选择治疗差异的方法方法是评估开发中产品观察到的早期数据。项目团队成员利用临床前数据、PK 数据、生物标志物或其他从该产品获得的其他数据，并提出一个合理的 $\delta$，使得候选药物很有可能实现目标。通常，使用其他产品（基于出版物、标签、SBA 或 EPAR）或产品本身获得的 $\delta$，团队成员之间可能会进行长时间的讨论。主要原因是，在开发早期阶段，没有直接的疗效数据来支持该候选药物的临床获益。

选择 $\delta$ 的一种方法是确定一个值，使得使用该 $\delta$ 计算出的样本量是行的。通常，在临床开发的早期，团队对测试产品是否有效且安全并没有把握。因此，由于投资风险高，投入规模往往是有限的。招募的患者总数不能超过某个数字。在此基础上，可以根据患者人数和预设的第一类错误 $(\alpha)$ 和第二类错误 $(\beta)$ 反向计算出 $\delta$。样本量计算的数学公式表明，研究所需的患者人数与预设的 $\delta$ 成反比关系。如果预算有限，导致样本量较小，则需要一个较大的 $\delta$ 以以合理的概率检测到治疗效应。作者理解这在实践中可能会发生，但不建议采用这种方法进行具有信息性的决策。在设计此类具有可行样本量的早期疗效试验时（样本量并不大，意味着使用了更大的 $\delta$，或在样本量计算中使用了更高的 $\alpha$ 或 $\beta$），最重要的一点是在获取数据和分析数据之前建立“通过/停止（Go/NoGo）”决策标准，并理解与之相关的风险（即停止一种有前景的药物以及继续推进无效药物的风险）。

## 6.2.7.3 第一类和第二类错误的选择

在新产品的临床开发中，众所周知 $\alpha$ 是犯第一类错误的概率；即 $\beta$ 是停止开发一种有前景药物的概率。在大多数 III 期开发计划中，机构通常预计 $\alpha$ 设置为双侧 0.05（单侧为 0.025）。在 III 期，$\alpha$ 可被视为监管风险，因为它代表了批准了一个对目标人群疗效不足的产品，但可能导致不良事件或其他安全顾虑。另一方面，$\beta$ 可被视为赞助者的风险，因为由于错误决策停止了有前景药物的开发，赞助者的投资就浪费了。出于这个原因，监管机构并不要求在任何临床阶段使用特定的 $\beta$。因此，$\beta$ 的选择通常由赞助者决定。通常在 III 期，赞助者倾向于为研究设计选择较小的 $\beta$（或更高的功效），以便通过较大的样本量以更准确的估计达到决策标准（即更窄的置信区间）。

然而，II 期设计中 $\alpha$ 或 $\beta$ 的选择可以是灵活的。主要原因有两个：(i) II 期临床试验后的决策主要是赞助者的决策而非监管决策，因此赞助者可以选择他们愿意承担的风险水平；(ii) II 期没有足够的证据让赞助者投入巨额投资。因此，赞助者可能会接受更高的风险（即更高的 $\alpha$ 或 $\beta$）。选择 $\delta$ 的一种方法是确定一个值，使得使用该 $\delta$ 计算出的样本量是行的。通常，在临床开发的早期，团队对测试产品是否有效且安全并没有把握。因此，由于投资风险高，投入规模往往是有限的。招募的患者总数不能超过某个数字。在此基础上，可以根据患者人数和预设的第一类错误 $(\alpha)$ 和第二类错误 $(\beta)$ 反向计算出 $\delta$。样本量计算的数学公式表明，研究所需的患者人数与预设的 $\delta$ 成反比关系。如果预算有限，导致样本量较小，则需要一个较大的 $\delta$ 以合理的概率检测到治疗效应。作者理解这在实践中可能会发生，但不建议采用这种方法进行具有信息性的决策。在设计此类具有可行样本量的早期疗效试验时（样本量并不大，意味着使用了更大的 $\delta$，或在样本量计算中使用了更高的 $\alpha$ 或 $\beta$），最重要的一点是在获取数据和分析数据之前建立“通过/停止”决策标准，并理解与之相关的风险（即停止一种有前景的药物以及继续推进无效药物的风险）。
