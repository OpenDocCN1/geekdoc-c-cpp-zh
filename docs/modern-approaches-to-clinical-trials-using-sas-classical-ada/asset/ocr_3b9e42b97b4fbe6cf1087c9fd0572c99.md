# 7.5.2 Example 1: biom Data with Normally Distributed Outcome and Model Selection

This example uses the biom data set from the DoseFinding R package [11]. The data set in Example Code 7.1 The biom Data has also been used in [2] to illustrate MCP-Mod. This was a randomized, double-blind group trial with a total of 100 patients being allocated equally to either a placebo or one of four doses coded as 0.05, 0.20, 0.60, and 1.
