We seek nontrivial solutions satisfying decay conditions as x → ±∞. We use a combination of asymptotic analysis and numerical methods. It is necessary to consider large and small |x| separately. We take the following approach:

+   - Choose a large value M > 0. For |x| > M we use u0(x) ≈ 0 and an elementary asymptotic analysis to construct solutions satisfying the decay conditions.
+   - For |x| ≤ M an asymptotic analysis is not feasible, since the contributions u0(x) and u0'(x) in (4.14)–(4.15) have to be taken into account. +   - Then the above two results are combined to find criterion (4.23) for the existence of nontrivial solutions.

# 4.3.1. Behavior of solution for large |x|.

For large values of |x| we use u0(x) ≈ 0 and arrive at a decoupled system of linear differential equations with constant coefficients.

```
(4.18) d/dx ( f \n f' \n f'' ) = [ 0 1 0 \n 0 0 1 \n -4γ (4 - 3 k²) 0 ] ( f \n f' \n f'' )
```

```
(4.19) d/dx ( g \n g' ) = [ 0 1 \n k² 0 ] ( g \n g' ) + ( 0 \n k² f' + f'' )

The characteristic equation of the matrix in (4.18) is given by

```
(4.20) λ³ + (3 k² - 4) λ + 4 γ = 0,
