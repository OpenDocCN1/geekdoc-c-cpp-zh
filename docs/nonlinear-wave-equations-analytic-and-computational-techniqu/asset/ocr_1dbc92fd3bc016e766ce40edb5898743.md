# 4.2. The Gaussian SSE.

For our numerical experiment, we restricted ourselves to the Gaussian SSE. That is, we considered the problem (1.1) with fixed initial data given by

(4.3) u₀(x) = A₀(x) = e^{-x²}.

Then, from (2.4)

(4.4) ε_N = (1/(π N)) ∫_{-∞}^{∞} e^{-x²} dx = 1/(√π N).

and formula (2.5) may be reduced to

(4.5) ∫₀^{√{-ln τ_{N,k}^{wkb}}} √{e^{-2x²} - (τ_{N,k}^{wkb})²} dx = (√π)/(2N) (k + 1/2), k = 0,1,2,…,N-1.

It is the solutions τ_{N,k}^{wkb}, k = 0,…,N-1 of (4.5) which will generate the exact N-soliton solution of (1.1). The collection of these solutions for N ∈ ℕ is the Gaussian SSE.
