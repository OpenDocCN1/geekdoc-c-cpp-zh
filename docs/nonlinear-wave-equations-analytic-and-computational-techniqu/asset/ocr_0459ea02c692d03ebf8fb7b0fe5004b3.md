# 3.3. The Inverse Scattering Map.

It turns out the the NCGO solutions μ(z, k) also solve a ∂̄-problem in the k variable determined by t(k). Letting

```
t♯(k) = t(k) / (4π k̄)
```

we have, for any p > 2:

# Lemma 3.5. Suppose that q is a smooth potential of conductivity type, and let μ(z, k) be the corresponding NCGO solutions. Then:

```
∂̄_k μ(z, k) = e_{-k} t♯(k) overline{μ(z, k̄)}
μ(z, ·) - 1 ∈ L^p (ℂ).
```

Moreover, q(z) is recovered from t and μ(z, k) by the formula

```
q(z) = (4i/π) ∂̄_z ( ∫ e_{-k}(z) t♯(k) overline{μ(z, k)} dk )
```

# Remark 3.6. This equation has at most one solution for each z, provided only that t♯ ∈ L² by a standard uniqueness theorem for the ∂̄-problem (see Brown-Uhlmann [11], Corollary 3.11).

The fact that μ(z, k) obeys a ∂̄-equation in the k-variable also implies a large-k asymptotic expansion for μ(z, k).

# Lemma 3.7. Suppose that q is a smooth potential of conductivity type, and let μ(z, k) be the corresponding NCGO solution. Then

```
μ(z, k) ~ 1 + Σ_{ℓ≥0} c_ℓ(z) / k^{ℓ+1}
```

where

```
c₀ = - i/4 ∂̄⁻¹ q
```

```
c₁ = -1/4 ∂∂̄⁻¹ q + 1/16 ∂̄⁻¹ ( q ∂̄⁻¹ q ).
```

and the remaining c_j are determined by the recurrence

```
i ∂̄ c_{j+1} = ( q/4 - ∂∂̄ ) c_j
```

# Proof. The coefficients in the asymptotic expansion may be computed recursively from the equation ∂̄(∂ + i k) μ = (q/4) μ once the existence of the asymptotic expansion is established. To do so, note that

```
μ(z, k) = 1 + 1/π ∫_ℂ 1/(k - κ) e_{-k} t♯(κ) overline{μ(z, κ)} dm(κ).
```

Writing

```
(k - κ)⁻¹ = k⁻¹ Σ_{j=0}^N (κ/k)^j + (κ/k)^{N+1} 1/(k - κ)
```

we obtain an expansion of the desired form with

```
c_j(z) = 1/π ∫ κ^j e_{-k} t♯(κ) overline{μ(z, κ)} dm(κ)
```
