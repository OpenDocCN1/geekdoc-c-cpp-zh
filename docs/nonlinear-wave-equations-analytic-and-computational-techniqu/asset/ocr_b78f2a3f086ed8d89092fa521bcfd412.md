where
\[\mathcal{S}_\kappa = \sinh(\kappa(\eta_0 + h)),\ \mathcal{C}_\kappa = \cosh(\kappa(\eta_0 + h)).\]

As before, since the problem does not depend on $y$ or $t$ explicitly, we use separation of variables to decompose $\eta_1(x,y,t)$ and $q_1(x,y,t)$ as in (3.3). Using this decomposition, we obtain

\[\left\langle\!\left\langle e^{-i\vec{k}\cdot\mathbf{x}} e^{i\rho y}\left(i\tilde{\eta}_{1,t}\mathcal{C}_\kappa - i c\eta_{0,x}\tilde{\eta}_1\mathcal{S}_\kappa - i c\tilde{\eta}_{1,x}\mathcal{C}_\kappa - \frac{1}{\kappa}\left(k_x\tilde{q}_{1,x}+i k_y\rho\tilde{q}_1\right)\mathcal{S}_\kappa - k_x q_{0,x}\tilde{\eta}_1\mathcal{C}_\kappa\right)\right\rangle\!\right\rangle = 0,\]

Since our new integrand depends on $y$ only through $e^{i(\rho - k_y) y}$, we eliminate the integration with respect to $y$ completely. Calculating the average value along the $y$ direction results in

\[\lim_{M\to\infty}\frac{1}{M}\int_{-M/2}^{M/2} e^{-i(k_y - \rho) y} dy = \lim_{M\to\infty}\frac{2}{M(k_y - \rho)}\sin\left(\frac{M(k_y - \rho)}{2}\right).\]

Taking the limit as $M \to \infty$, the contribution is identically zero if $k_y \neq \rho$. Otherwise, if $k_y = \rho$, the contribution from the integral is unity. Thus, the linearization of the nonlocal equation simplifies to

(3.5)
\[\left\langle e^{-i k_x x}\left(i\lambda\tilde{\eta}_1\mathcal{C}_\kappa - i c\tilde{\eta}_{1,x}\mathcal{C}_\kappa - \eta_{0,x}c\kappa\tilde{\eta}_1\mathcal{S}_\kappa - \frac{1}{\kappa}\left(k_x\tilde{q}_{1,x}+i\rho^2\tilde{q}_1\right)\mathcal{S}_\kappa - k q_{0,x}\tilde{\eta}_1\mathcal{C}_\kappa\right)\right\rangle = 0,\]

where now $\kappa = \sqrt{k_x^2 + \rho^2}$ and
\[\langle f\rangle = \lim_{M\to\infty}\frac{1}{M}\int_{-M/2}^{M/2} f(x)\,dx.\]

It should be noted that if we equate $\rho = 0$, the above equation reduces to the expression for the one-dimensional surface case presented elsewhere[DO].

Having linearized the equations about the traveling wave solution, we have the following generalized eigenvalue problem:

(3.6)
\[\lambda\tilde{q}_1 - c\tilde{q}_{1,x} + q_{0,x}\tilde{q}_{1,x} + g\tilde{\eta}_1 - f\cdot\left(\lambda\tilde{\eta}_1 + \tilde{\eta}_{1,x}(q_{0,x} - c) + \eta_{0,x}\tilde{q}_{1,x} - \eta_{0,x}f\cdot\tilde{\eta}_{1,x}\right) = 0,\]

(3.7)
\[\lambda\left\langle e^{-i k_x x}\left(i\tilde{\eta}_1\mathcal{C}_\kappa\right)\right\rangle = \left\langle e^{-i k_x x}\left(i c\tilde{\eta}_{1,x}\mathcal{C}_\kappa + i\eta_{0,x}c\kappa\tilde{\eta}_1\mathcal{S}_\kappa + \frac{1}{\kappa}\left(k_x\tilde{q}_{1,x}+i\rho^2\tilde{q}_1\right)\mathcal{S}_\kappa + k_x q_{0,x}\tilde{\eta}_1\mathcal{C}_\kappa\right)\right\rangle.\]
