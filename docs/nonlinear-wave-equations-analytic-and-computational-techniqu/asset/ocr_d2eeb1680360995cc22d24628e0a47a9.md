For the system to be stable we have to verify that the norm of the eigenvalues $z_{1,2}$ of $\mathbf{M}$ are less than or equal to 1. The characteristic equation is given by
$$\Phi_{NV}(z) = z^2 - \frac{b_2}{b_1}z - \frac{b_1}{b_1} = 0$$

Thus, we conclude $|z_1 \cdot z_2| = |\frac{b_1}{b_1}| = 1$ and stability of the solution is equivalent to $|z_{1,2}| = 1$, i.e., we have $|u^{n+1}| = |u^{n-1}|$. Using the explicit solution for quadratic equations and
(3.11)
$$b_2 \in i\mathbb{R}, \qquad |b_2| \le 2|b_1|,$$

we find $2\overline{b_1}\,z_{1,2} = b_2 \pm \sqrt{b_2^2 + 4|b_1|^2}$ and $|2\overline{b_1}|^2|z_{1,2}|^2 = |2b_1|^2$. Consequently, $|z_{1,2}| = 1$. With (3.10), the stability condition (3.11) for the ODE (3.9) becomes
$$((1 - 4\theta)\lambda^2 + 2(1 - 2\theta)\lambda\gamma + \gamma^2)(\Delta t)^2 \le 16.$$

For $\gamma = \alpha = 0$ and $\frac{1}{4} \le \theta \le 1$ the stability condition is satisfied, independent of the step size $\Delta t > 0$, and we have a stability result for the initial boundary value problem (3.8). This proves the following theorem.

THEOREM 1. *The numerical scheme (3.6) applied to the linearization of (1.2)–(1.4) about the zero solution is stable for $\frac{1}{4} \le \theta \le 1$.*

Proving stability for (3.8) with $\alpha \ne 0$ requires a few more computations. Using the expressions for $\lambda$ and $\gamma$ in (3.9) results in the stability condition
$$(1 - 4\theta) + 2(1 - 2\theta)\frac{3\alpha}{\eta^2 + \xi^2} + \left(\frac{3\alpha}{\eta^2 + \xi^2}\right)^2 \le \left(\frac{4}{\omega\Delta t}\right)^2.$$

For $\theta = \frac{1}{2}$ we find the sufficient conditions
$$-2 + \left(\frac{3\alpha}{\eta^2 + \xi^2}\right)^2 \le \left(\frac{3\alpha}{\eta^2 + \xi^2}\right)^2 \le \left(\frac{4}{(\xi^3 - 3\xi\eta^2)\Delta t}\right)^2$$

$$(\Delta t)^2 \le \left(\frac{4(\xi^2 + \eta^2)}{3\alpha(\xi^3 - 3\xi\eta^2)}\right)^2.$$

Since $|\xi^3 - 3\xi\eta^2| \le (\xi^2 + \eta^2) \cdot \max\{|\xi|,|\eta|\}$ we have the sufficient condition for $\Delta t$
$$\Delta t \le \frac{4}{3|\alpha|\max\{|\xi|,|\eta|\}}.$$

For the DFT with $\Delta x = \Delta y = \frac{W_s}{L}$ we find $\max\{|\xi|,|\eta|\} = \frac{\pi}{\Delta x}$, and thus we have the stability condition
(3.12)
$$\Delta t \le \frac{4}{3|\alpha|\pi}\,\Delta x.$$

As a consequence we have a stability result for the initial boundary value problem (3.8) with $\alpha \ne 0$, Theorem 2.

THEOREM 2. *The numerical scheme (3.6) applied to (3.8) is stable for $\theta = \frac{1}{2}$ if the time step $\Delta t$ satisfies condition (3.12).*
