# INSTALLING AND REMOVING APPS

You can install applications by clicking the Add button and selecting the application bundle to add. You’ll need to have a provisioning profile for the application (which is usually only an issue if a friend is letting you test one of their applications). To uninstall, select the desired applications in the list and click the Delete button. The applications *and their associated data* will be removed from the device.

# DOWNLOADING APPLICATION DATA

You can download an application’s data for safekeeping (or analysis) by locating it in the list and clicking the Download button to its right. Choose a location to which to save the data and a folder will be created at that location containing the application’s data and settings. Only applications for which you have a provisioning profile will allow you to download their data.
