# SETTING DOCUMENTATION
PREFERENCES

![](bbox=[0.282, 0.171, 0.865, 0.503])

**FIGURE C.1** The Documentation preferences panel

To open the Documentation preferences panel, choose Xcode > Preferences from the main menu, then select the Documentation tab. **Figure C.1** shows the preferences. Xcode downloads only what it considers “necessary” documentation sets at first. If you want missing libraries (the ones that are grayed out), you’ll need to press the GET button beside them. Xcode will download and install the documentation set and, from that point forward, will include those sets in its automatic update checks.

Additionally, you can add third-party documentation sets using the Add (+) button at the bottom of the list. The documentation must come from an *http://* or *feed://* URL.
