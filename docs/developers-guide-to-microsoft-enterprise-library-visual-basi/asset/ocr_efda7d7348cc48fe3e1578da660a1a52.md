# USING THE CONFIGURATION TOOLS

The most common scenario for basic configuration of an application is to store the configuration information in a local configuration file (such as Web.config or App.config). You can create a new Enterprise Library configuration in the configuration console and then save it to a disk, or you can open an existing configuration file and edit it to add Enterprise Library to your application.
