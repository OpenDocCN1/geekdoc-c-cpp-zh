Table 1 describes the complete set of validators provided with the Validation block.

**TABLE 1 The validators provided with the Validation block**

| Validator type | Validator name | Description |
| :--- | :--- | :--- |
| Value Validators | Contains Characters Validator | Checks that an arbitrary string, such as a string entered by a user in a Web form, contains any or all of the specified characters. |
| Value Validators | Date Time Range Validator | Checks that a DateTime object falls within a specified range. |
| Value Validators | Domain Validator | Checks that a value is one of the specified values in a specified set. |
| Value Validators | Enum Conversion Validator | Checks that a string can be converted to a value in a specified enumeration type. |
| Value Validators | Not Null Validator | Checks that the value is not null. |
| Value Validators | Property Comparison Validator | Compares the value to be checked with the value of a specified property. |
| Value Validators | Range Validator | Checks that a value falls within a specified range. |
| Value Validators | Regular Expression Validator | Checks that the value matches the pattern specified by a regular expression. |
| Value Validators | Relative Date Time Validator | Checks that the DateTime value falls within a specified range using relative times and dates. |
| Value Validators | String Length Validator | Checks that the length of the string is within the specified range. |
| Value Validators | Type Conversion Validator | Checks that a string can be converted to a specific type. |
| Type Validators | Object Validator | Causes validation to occur on an object reference. All validators defined for the object's type will be invoked. |
| Type Validators | Object Collection Validator | Checks that the object is a collection of the specified type and then invokes validation on each element of the collection. |
| Composite Validators | And Composite Validator | Requires all validators that make up the composite validator to be true. |
| Composite Validators | Or Composite Validator | Requires at least one of the validators that make up the composite validator to be true. |
| Single Member Validators | Field Value Validator | Validates a field of a type. |
| Single Member Validators | Method Return Value Validator | Validates the return value of a method of a type. |
| Single Member Validators | Property Value Validator | Validates the value of a property of a type. |
