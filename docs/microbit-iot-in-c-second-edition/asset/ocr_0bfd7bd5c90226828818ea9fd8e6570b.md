As the micro:bit also has a 5x5 LED display, we will use it to show the
humidity and temperature:

```
char buff[10];
sprintf(buff, "%d.%d%%", humidity / 10, abs(humidity % 10));
uuBit.display.scroll(buff, 200);
sprintf(buff, "%d.%d%%", temperature / 10, abs(temperature % 10));
uuBit.display.scroll(buff, 200);
```

To use sprintf you also need to add:

```
#include <stdio>
```

Now if you run the program you will see the humidity and temperature scroll
past. If you put the whole reading section into a loop then you can add a
uuBit.sleep(2500) to produce something that shows the data every 2.5
seconds.

```
uint32_t getByte(int b, int buf[])
{
  int i;
  uint32_t result = 0;
  b = (b - 1) * 8 + 1;
  for (int i = b; i <= b + 7; i++)
  {
    result = result << 1;
    result = result | buf[i];
  }
  return result;
}
```
