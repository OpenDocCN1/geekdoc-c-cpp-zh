# Why Choose a Micro:bit?

There are many different choices you can make for a small, low-cost programmable device - Raspberry Pi, Raspberry Pi Pico, Arduino and so on. The micro:bit is a self-contained device in the sense that it has a simple display, input buttons, accelerometer, temperature sensor and magnetometer. It also has a radio, although it lacks full WiFi capabilities and relies on Bluetooth or ad-hoc communication. From the hardware point of view it is more capable than a Raspberry Pi or basic Arduino for many applications. It isn't powerful enough to run Linux and this can be considered an advantage or a disadvantage based on the use.

The micro:bit's being a ready-built community of users is both a plus and a minus. It means that there have a very skewed set of interests. And easy-to-use languages such as Python and Scratch are the most important and powerful languages as C/C++ are a minority interest. There is also the problem of closed communities. If you are a teacher then there is no problem at all, but for the general programmer and there are communities that you cannot join. Even if you can much of the conversation around teaching issues, and while it is inspiring to see what pupils do, it can become repetitive. In addition, the interests of the not-for-profit Micro:bit Educational Foundation tend to be market-oriented. What all this means is for the general user the support provided for the micro:bit isn't as good as you might expect given the number of devices and users that are claimed.

# The Software

If you choose to program the micro:bit in one of the officially supported environments, MakeCode or MicroPython, then you have few problems. The environment makes coding easy and covers up any differences between V1 and V2 devices. If you choose to code in C/C++, which is a good idea if you want to do anything out of the ordinary, then you face some challenges.

The first thing to explain is that the micro:bit is an mbed device. Mbed is a project started by Arm to promote the 32-bit ARM Cortex-M as an IoT device. The mbed operating system is designed to make a range of ARM-based devices work in the same way. It is a low-level operating system that provides uniform access to various pieces of hardware. The V1 micro:bit uses mbed version 2, which has now been deprecated.
