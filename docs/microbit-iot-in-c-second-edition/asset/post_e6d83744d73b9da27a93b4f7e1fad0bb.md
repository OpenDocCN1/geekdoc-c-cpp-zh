
## Raspberry Pi IOT in C With Linux Drivers
ISBN:9781871962642

If you opt to use Linux drivers to connect to external devices then C is a good choice, if speed of execution is an issue. This book explains how to use C to connect to and control external devices using the standard Linux drivers.

## Raspberry Pi IoT in Python With Linux Drivers
ISBN:9781871962659

If you opt to use Linux drivers to connect to external devices then Python becomes a good choice, as speed of execution is no longer a big issue. This book explains how to use Python to connect to and control external devices using the standard Linux drivers.
