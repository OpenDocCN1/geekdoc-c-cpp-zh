# ## Pulse Width Modulation, Servos and More

One way around the problem of getting a fast response from a microcontroller is to move the problem away from the processor. In the case of micro:bit’s processor there are some built-in devices that can use GPIO lines to implement protocols without the CPU being involved. In this chapter we take a close look at pulse modulation (PWM) including sound generation, driving LEDs and servos.

At their most basic output function, the GPIO lines can be set high or low by the processor. How fast can they be set high or low on the speed of the processor. Using the GPIO line in its Pulse Width Modulation (PWM) mode you can generate pulse trains up to 9.6MHz, i.e. pulses as short as just a little more than 0.1µs.

The reason for increase in speed is that the GPIO controls a pulse generator, and also to generate pulses of a specific type, the pulse generator gets just on it without needing any intervention from the GPIO line or the processor. In fact, the pulse output can continue after your program has ended if you forget to reset it.

Of course, even though the PWM line can generate pulses as short as 0.1µs, it can only change the pulses it produces each time the processor can modify it. For example, you can't use PWM to produce a single 0.1µs pulse because you can't disable the PWM generator in just 0.1µs.

# ## Some Basic Micro:bit PWM Facts

There are some facts worth getting clear from the start, although some of their meanings will only become clear as we progress. First what is PWM? The simple answer is that a Pulse Width Modulated signal has pulses that repeat at a fixed rate, say one pulse every millisecond, but the width of the pulse can be changed.

There are two basic things to specify the pulse train that is generated, its repetition and the width of each pulse. Usually the repetition rate is set as a simple repeat period and the width of each pulse is specified as a percentage of the repeat period the duty cycle. For example, a 1ms repeat and a 50% duty cycle specifies a 1ms period which is high for 50% of the time, i.e. a pulse width of 0.5µs.
