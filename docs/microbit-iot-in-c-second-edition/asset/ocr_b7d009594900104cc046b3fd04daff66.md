The installer just gets on the job and when it finishes you should be able
to yotta which is stored in:

C:\Users\username\AppData\Local\Programs\Python\Python38-32\Scripts.
to compile the code you need first install the arm-none-eabi-gcc
compiler. This can be downloaded from a number of places including:
https://developer.arm.com/tools-and-software/open-source-software/
developer-tools/gnu-arm/tools/downloads

At the time of writing the current version of the installer was:
gcc-arm-none-eabi-10-2020-q4-major-win32
Run the installer and follow the instructions. Make sure to tick Add path to
environment variable at the end of the installation:

![](bbox=[0.231, 0.335, 0.706, 0.626])

The compiler is installed in:
C:\Program Files (x86)\U GNU Arm Embedded Toolchain
Now, finally we can install Yotta:

pip install -U yotta

The requirements for other operating systems are much the same. For OSX
You can simply download and drag the yotta app 05 X yotta.app into the
applications folder. When you run it a terminal will open.

Under Linux there is no installer, but it is easy to set things up using the
package manager. You need to install the latest Python, which is usually
installed by default. You also need the latest Python setup tools, cmake, Ninja
