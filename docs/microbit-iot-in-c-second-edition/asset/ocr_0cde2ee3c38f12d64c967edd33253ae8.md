You need to take great care if you need high accuracy. For example, you will notice there are two voltage inputs $V_{DD}$ and $V_{REF}$. $V_{DD}$ is the supply voltage that runs the chip and $V_{REF}$ is the reference voltage that is used to compare the input voltage.

Obviously if you want accuracy $V_{REF}$, which has to be lower than or to $V_{DD}$, should be set by an accurate low voltage source. However, in most applications $V_{REF}$ and $V_{DD}$ are simply connected together and the usual, low-quality, supply voltage is used as the reference. If this isn't good enough then you can use a Zener diode to a precision voltage reference chip such as the TL431. At the very least, you should add a 1uF capacitor between the $V_{DD}$ pin and the $V_{REF}$ pin to ground.

The MC3000 family implements a type of A-to-D based on a technique successive approximation. You don't need to know how to use the MC3000, but it isn't difficult. The idea is that first a voltage is generated equal to $V_{REF}/2$ and the input voltage is compared to this. If it is lower, the most significant bit is a zero; if it is more or equal, then it is a one. At the next step the voltage generated is $V_{REF}/2+V_{REF}/4$ and the comparison is repeated to generate the next bit.

You can see that successive approximation fits in well as each bit can be obtained in the time needed to transmit the previous bit. However, the conversion is relatively slow and a sample-and-hold circuit has to be used to keep the input to the converter stage fixed.
