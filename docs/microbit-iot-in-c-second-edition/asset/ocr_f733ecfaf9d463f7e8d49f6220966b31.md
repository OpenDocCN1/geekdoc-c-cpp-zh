Now our main program can be just:

```
int main() {
    init SPI();
    int data = readADC(0x0);
    int volts = data * 330 / 1023;
    uBit.serial.printf("Voltage = %d.%d\n\r", volts / 100, volts % 100);

    release_fiber();
    return 0;
}
```

# # How Fast

Once you have the basic facilities working the next question is always how fast does something work. In this case we need to know what sort of data we can achieve using this A-to-D converter. The simplest way of discovering this is to use the fastest read loop for Channel 5:

```
for();{
    int data=readADC(0x5);
}
```

With a 1MHz clock speed we get a measured clock rate of 1MHz, but there are 29µs between each reading. The sampling rate, for a micro:bit V1, is measured to be 14kHz.

![](bbox=[0.118, 0.532, 0.827, 0.735])

In principle, as it takes 24 clock periods to read the three bytes, the shortest time to read the data is 24µs, but because of the delays it actually takes 71µs. Some of this is due to the time to change the CS line. Clearly, we could make this faster by using direct memory mapping.
