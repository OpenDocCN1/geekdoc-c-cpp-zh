To read the temperature using the Hold master mode you simply send 0xE3
and read three bytes:

```
#include "MicroBit.h"
MicroBit uBit;

int main() {
    uBit.init();
    uint8_t buf[3] = {0};
    uBit.i2c.readRegister(0x80, 0xE3, buf, 3);
    uint8_t msb=buf[0];
    uint8_t lsb=buf[1];
    uint8_t check=check=buf[2];
    uBit.serial.printf("msb %d\n lsb %d\n n checksum %d\n\r",
    msb,lsb,check);

    return 0;
}
```

The buffer is unpacked into three variables with more meaningful names:
msb - most significant byte; lsb - least significant byte; check - checksum.

You should see something like:

+   msb 97
lsb 232
checksum 217

with the temperature around 20°C.

The logic analyzer reveals what is happening. First we send the usual address frame and write the 0xE3. Then after a short pulse the read address frame frame is sent and the clock line is held low by the device (lower trace):
