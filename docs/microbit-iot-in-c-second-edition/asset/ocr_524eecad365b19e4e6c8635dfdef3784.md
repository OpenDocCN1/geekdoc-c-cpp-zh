# Producing Sounds

The micro:bit V1 has no standard audio ability and no built-in speaker. If you want to create some sound you have the PWM abilities of one of the pins to create a square wave of the correct frequency. You can easily write a function to do this:

```
void analogPitch(int frequency, int vol, int ms) {
  uBit.io.P0.setAnalogValue(vol);
  uBit.io.P0.setAnalogPeriodUs(100000/frequency);
  uBit.sleep(ms);
  uBit.io.P0.setAnalogValue(0);
}
```

The frequency is in Hertz, the volume runs from 0 to 512 and the duration is in milliseconds. This works with P0 but you can use any pin that supports PWM. To hear the result you need to attach a speaker to the appropriate pin.
