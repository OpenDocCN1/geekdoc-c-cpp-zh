This means that you can no longer use the mbed online compiler, or any of the mbed tools, for the V2 micro:bit. Instead you have to use the GCC cross compiler, or similar, and the libraries provided by Lancaster University.

This software split between the two versions of the micro:bit also causes a problem in distributing software. Although it is claimed that the two versions are compatible, this is not quite true. A new combined hex format has been defined that can accommodate V1 and V2 code. It is up to you to build your programs for each device and create a single new hex file that can be downloaded both versions of the micro:bit. If you only want to support one of the versions this is not an issue.

At the time of writing only the V2 device is on, but there are far more V1 devices in use. In an ideal world we would concentrate on the V2 as software isn't deprecated, but this isnt likely to be reasonable for some time, if ever. Chapter 2 explains how to set up development environments for both versions and differences are indicated in subsequent chapters as we create programs. In theory it would be possible to create a single development environment for both versions of the micro:bit but the amount of work involved that this is unlikely to happen. Indeed it is unlikely that will be any significant improvements to the micro:bit V1 software at all.

# Why C/C++?

Before you spend time finding out how to program in C/C++ there is the good question of why bother? After all, the micro:bit's own website offers the choice of Touch Develop, JavaScript and MicroPython to program it and they are all fairly easy to use.

The answer to the question of why C/C++ is that it gets closest to the hardware. Not from the higher-level languages. For example, at the moment, you can get full access to the micro:bit's radius. Using C/C++ and the microbit Bluetooth radio as a simple point-to-point radius connection between microbits. This makes it possible to build radio control robots and similar gadgets, something much harder if all of the connections have to go through the Bluetooth stack. Another example is the LED control. In MicroPython you have nine brightness levels, in the micro:bit's other supplied languages the LEDs are either on or off. In C/C++ you can set any of 255 levels.
