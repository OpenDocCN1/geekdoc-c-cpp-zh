# # Summary

+   - The HTU21D is a simple I2C device, but getting it working involves using polling or stretching as it takes time to prepare the data ready for reading.

+   - At the time of writing, clock stretching works with both versions of the micro:bit, but polling doesn't

+   - When the data from the device have been retrieved, you need to use bit manipulation to assemble the temperature and humidity readings.

+   - Computing a checksum (CRC) to alert you to errors in the data, is an involved, but common, operation.

+   - As well as the standard I2C bus pins the HTU21D can be used on any other pins you care to select.
