As an alternative you can download a zip of:
https://github.com/I-Programmer-info/MicroBitV2

This is a slightly modified complete template that doesn't need to install Git. All you have to do is download it and unzip MicroBitV2Template to a project folder of your choice. You can rename the file or copy it and rename it. In this simple case copy and rename to HelloWorld. When you load it into VS Code, the project will be configured, you have to specify a kit, and you can do a full clean build of all projects.

No matter which you download, the result should be a .hex file stored in the root. This can be downloaded to the micro:bit V2 when you will see HelloWorld scroll across the screen.

To summarize:

+   1. Download a zip of either
https://github.com/lancaster-university/microbit-v2-samples
https://github.com/I-Programmer-info/MicroBitV2
2. If you download microbit-v2-samples you either to have Git installed or you have to manually download the missing libraries. If you download MicroBitV2 the libraries are included.
3. Once you have downloaded the zip files, you can extract the project to a suitable folder and rename it to whatever you want to call it.
4. When you load the project into VS Code, you will be asked to select a kit and then the project will be configured.
5. You need to perform a clean rebuild of all projects to make sure that everything is up-to-date. You will see a lot of warnings scroll past.
6. When the compile is complete you can copy MICROBIT.hex to the microbit and watch "Hello World" scroll past.

If anything doesn't work you try re configure followed by a clean rebuild. In the case of the microbit-v2-samples project, if it doesn't work the chances you don't have Git installed and the libraries are not being downloaded.

If you want to explore the code in the sample directory do so and then delete the directory and do a clean configure followed by a clean rebuild. It is possible for the sample programs to interact with the program you are developing so it is better to get rid of them when you longer need them.
