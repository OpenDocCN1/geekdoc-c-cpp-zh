If you are prepared not to use Button A and Button B you can add:

# Button Pins
MICROBIT_PIN_P5
MICROBIT_PIN_P11

In most cases you probably won't want to make use of the SPI bus so you can
to the list:

# SPI Bus Pins
MICROBIT_PIN_P13
MICROBIT_PIN_P14
MICROBIT_PIN_P15

Finally we have two pins dedicated to the I2C bus which you can use, but
yneed to know that in the microbit V1 these are connected to the
accelerometer and magnetometer which you cannot use if you take them out.
Notice that you can use them for your devices on the I2C bus without
disabling the on-board devices:

# I2C Bus Pins
MICROBIT_PIN_P19
MICROBIT_PIN_P20
