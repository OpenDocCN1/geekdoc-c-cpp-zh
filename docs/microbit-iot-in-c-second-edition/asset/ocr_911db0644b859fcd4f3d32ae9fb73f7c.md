# Reading the Data

With preliminary checks complete, it is time to read the 40-bit data stream.
The first thing to do is wait for the low that the device sends before the START bit:

```
for (i = 1; i < 200; i++) {
    if (P0.getDigitalValue() == 0)break;
}
```

Next we can start to read in the bitstream. When doing this there are two things to keep in mind. The first is that it is only the time line is high that matters and you need to measure this accurately. You don't care so much about how long the line is for. The second is that it is usually better to collect the bits and only process them and extract the data. To this end it is usually good idea to save the data in a buffer:

```
int buf[41];\int j;
for(j=0;j<41;j++) {
    for(i=1;i<200;i++) {
        if(P0.getDigitalValue()==1)break;
    }
    for(i=1;i<200;i++) {
        if(P0.getDigitalValue()==0) break;
    }
    buf[j]=i;
}
```

You should be able to see how this works. The outer loop, indexed on j, repeats to read in all 40 data bits and the initial START bit. The first inner loop waits for the line to go high and i gives the time that the line has been low. There is no interest because the device keeps the line low for the same length of time for a zero or a one. The second for loop waits for the line to go low. The count in i is now proportional to the time the line was high and is stored in the buffer.

If you add:

```
for(j=0;j<=40;j++){
    UBit.serial.printf("%d %d \n",buf[j]);
}
```

to the end of the program you will be able to see the counts and you should quickly be able to work out the value halfway between the long, one pulses and the short, zero pulses.
