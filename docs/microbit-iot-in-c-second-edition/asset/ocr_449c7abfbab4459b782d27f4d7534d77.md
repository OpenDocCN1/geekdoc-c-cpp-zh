# Hello World Micro:bit V2

Getting started with the V2 C/C++ environment is simpler than the V1 as, despite Yotta compatibility built-in, it Cmake-based. All you have to do is navigate to:

https://github.com/lancaster-university/microbit-v2-samples

This is a demo project and it doesn't contain all of the libraries needed to build it. However, if you download the project as a zip file and unzip it to a suitable directory you can load into VS Code. In this case the CMake file in the root the project should configure itself correctly. You will, however, be asked to select a 'kit'. Essentially a kit is a compiler collection that can be used to build the project. If you have installed GCC you will see it in the list – if you don't see it then use the Scan for kits option. If you still don't see, check that it is installed and on the path:

![](bbox=[0.178, 0.375, 0.82, 0.593])

The project configuration runs the CMakeLists.txt file in the root and this uses Git to download the missing libraries. For this work, you have to have Git – not GitHub – installed. If you don't you can download and copy the libraries manually. You need to download:

https://github.com/lancaster-university/codal-microbit-v2
https://github.com/lancaster-university/codal-core
https://github.com/lancaster-university/codal-nrf52
https://github.com/microbit-foundation/codal-microbit-nrf52sdk

All of these need to be copied into a new folder libraries:
