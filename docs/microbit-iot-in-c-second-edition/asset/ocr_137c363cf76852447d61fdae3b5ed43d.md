Using logic analyzer reveals that, on a V2, the result isn't what you might expect:

![](bbox=[0.137, 0.125, 0.795, 0.335])

You can also see that the pulse trains are not 180 degrees out of phase. The top train switches on and the bottom train takes about half a pulse before it switches off, whereas the intent is for both actions to occur at the same time. You should also notice that now the pulse is about 1.9µs, which is about double the time for a pulse train on a single GPIO line. The point is that it does take quite a long time to access and change the state of an output line. The same is true for a V1 device but the timings are slightly longer.
