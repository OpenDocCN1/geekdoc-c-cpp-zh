As p varies from 0 to 10, the position of the brightness moves from the first to the second LED.

We also need something to record how many times the button has been clicked. This can be done using an event handler that counts clicks using a global variable. There is no doubt that this would be better implemented as an object using C++ with methods such as getValue and reset, but in C we use:

```
void setUpButton() {
    uBit.buttonB.eventConfiguration(MICROBIT_BUTTON_ALL_EVENTS);
    uBit.messageBus.listen(MICROBIT_ID_BUTTON_B, MICROBIT_BUTTON_EVT_CLICK, buttonClickCount);
}
```

Now buttonClickCount is called each time the user clicks buttonB:

```
void buttonClickCount(MicroBitEvent e) {
    clickCount++;
}
```
