# Summary

+   - The micro:bit is a largely education-oriented device, but it has many good properties that make it suitable for other projects.

+   - The emphasis on education is an advantage if you are working in education, otherwise it can be a problem as you cannot gain access to private educational communities.

+   - The original micro:bit exists in two versions, V1.3 and V1.5, which are largely compatible mbed devices and can be programmed using the same development environment.

+   - The micro:bit V2 is faster and more capable and is no longer an mbed device. It needs a different development environment.

+   - To support both V1 and V2 devices you need to compile a version of your program for each and produce a targeted hex file for each.

+   - A new combined hex file format allows the packaging of V1 and V2 versions of a program in a single hex installation file.

+   - Although the system software for bothV1 and V2 is written in C++, the application programs we'll write in C for simplicity.
