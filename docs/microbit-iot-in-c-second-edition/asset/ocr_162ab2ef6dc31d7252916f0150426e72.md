# Hello Blinky

You are now ready to start on a project, but at the moment there isn't a good starter project template. However, Lancaster University has provided a template called Blinky to flash an LED, the equivalent of a Hello World program for the device.

There are two ways to work with the micro-bit - as a pure mbed device or using the library or framework, DAL, built by Lancaster University. As long as you don't want to change to a different device, the Lancaster framework is easy to write a single program that will work on different hardware and this is its big advantage.
