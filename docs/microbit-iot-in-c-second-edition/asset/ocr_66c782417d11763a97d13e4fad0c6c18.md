# Creating A Custom Protocol

In this chapter we make use of all the ideas introduced in earlier chapters to create a raw interface with the low cost DHT11/22 temperature and humidity sensor as an exercise in implementing a custom protocol directly in C.

# The DHT22

The DHT22 is a more accurate version of the DHT11 and is used in this project, but the hardware and software will work with both versions and with the AM2302, which is similar to the DHT22.

The device will work at 3.3V and makes use of a 1-wire, open collector-style bus, which makes it very easy to make the physical connection to the micro:bit. The 1-wire bus used isn't standard and is only used by this family of devices, so we have little choice but to implement the protocol in C.
