# micro:bit V1 LEDs

The LEDs in the micro:bit V1 do not have a neat row, column numbering. Instead they are arranged in an order that makes the PCB layout easier:

| 1.1 | 2.4 | 1.2 | 2.5 | 1.3 |
| 3.4 | 3.5 | 3.6 | 3.7 | 3.8 |
| 2.2 | 1.9 | 2.3 | 3.9 | 2.1 |
| 1.8 | 1.7 | 1.6 | 1.5 | 1.4 |
| 3.3 | 2.7 | 3.1 | 2.6 | 3.2 |

To illuminate the LED at position row,column, all we have to do is set the row high and the column low - this picks out just one LED to be on. For example, to set the center LED 2,3 you would need to set GPIO line p0_14 high and line p0_6 low. The problem is that the framework provides objects for GPIO lines that are brought out to the edge connector and none of the row lines and some of the column lines are.

The solution is to make use of the mbed functions with which the framework is built. The disadvantage of this is that you don't get any of the event handling facilities. There are mbed functions for most of the hardware facilities that we have encountered and you can use them if you want to. They are slightly faster than the framework functions because in general the framework functions call the mbed functions to get the work done.
