# Basic Serial Commands

There seem to be a lot of commands relating to the serial port. However, they fall into just three groups - initialization, writing and reading. Unfortunately there are many minor changes in the microbit V2 implementation of the serial object.

The initialization commands control how the port works. They all create or work with an instance of MicroBitSerial, but if you want to create an instance of your own dont create an instance of uBit. This simply causes a conflict with two instances of MicroBitSerial trying to control the hardware. If you want to use the other features provide by uBit, the simplest thing to do is create a global uBit and initialize it in the usual way. Then use its property to access the MicroBitSerial object that has been created:

```
#include "MicroBit.h"
//define setBaudrate // Uncomment for V2
MicroBit uBit;
int main() {
{
	uBit.init();
	uBit.serial.baud(115200);
	uBit.serial.send("A\r\n");
n}
```

By default this connects to the USB serial so you should see an A printed on the serial console connected to the port. Notice that for V2 the baud is called setBaudrate.

If you don't want to use uBit you need to create MicroBitSerial as a global object. To create the equivalent of the previous program you would use:

```
#include "MicroBit.h"
/* Uncomment for V2
#define setBaudrate
#define USBTX MICROBIT PIN UART TX
#define USBRX MICROBIT_PIN UART_RX
*/
MicroBitSerial serial(USBTX, USBRX);

int main() {
{
	serial.baud(115200);
	serial.send("A\r\n");
	release_fiber();
n}
```
