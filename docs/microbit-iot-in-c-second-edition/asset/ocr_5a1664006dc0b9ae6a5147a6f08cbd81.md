As this is the first time to configure the project you will be asked to select a “kit”. Essentially a kit is a compiler collection that can be used to build the project. if you have installed GCC you should see it in the list – if you don't see it then use the Scan for kits option. if you still don't see it check that it is installed and on the path.

![](bbox=[0.19, 0.185, 0.81, 0.303])

Next you should be asked for the location of the CMakeLists.txt file.

![](bbox=[0.298, 0.345, 0.702, 0.417])

Usually this is stored in the root, but in our case it is in build/bbc-microbit-classic-gcc. Select Locate and navigate to that and select the CMakeList.txt file.

![](bbox=[0.36, 0.499, 0.64, 0.626])

At this point VS Code might have a hang with a message “Configuring project: Saving open files ”. If simply restart VS Code and open the folder and select the CMake extension and use the menu option Clean Reconfigure All Projects. This will write all the Cmake and build files needed to the build/bbc-microbit-classic-gcc directory:
