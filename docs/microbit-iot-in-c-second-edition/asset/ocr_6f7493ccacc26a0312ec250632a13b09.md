Finally all remains is to build the project. If you try to build the debug target you will encounter a fatal error – this could be corrected in the future. The simplest solution is to select the release build by clicking on CMake: (Debug) in the status bar:

![](bbox=[0.163, 0.191, 0.768, 0.266])

and then select Release build from the drop-down list:

![](bbox=[0.137, 0.311, 0.8, 0.423])

Now when you have a clean rebuild you will see lots of warning messages, but no fatal errors. You could spend time fixing them, but the effort doesn't seem particularly worthwhile. You will find the built project in HelloWorld\build\source and the files you are interested in are build\source\HelloWorld.hex and build\source\HelloWorld-combined.hex.

The first file is in Intel format and you will need it to create a universal hex file for V1 and V2 microbits. The HelloWorld-combined.hex is what you copy to the microbit to run the program. When you copy the file to a microbit connected via USB you will see Hello World scroll by the display.

If you can't find the hex called "HelloWorld" but only "MicroBitV1Template" files, you haven't changed the project name as described earlier. The files should still work but they have inappropriate names.
