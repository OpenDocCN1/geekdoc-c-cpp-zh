# Push-pull Mode

In push-pull mode, which is the standard configuration for a GPIO output, two transistors of opposite polarity are used:

![](bbox=[0.263, 0.187, 0.674, 0.355])

The circuit behaves like the two-switch equivalent shown on the right. Only one of the transistors, or switches, is "closed" at any time.

If the input is high then Q1 is saturated and the output is connected to ground - exactly as if S1 was closed. If the input is low then Q2 is saturated and it is as if S2 was closed and the output connected to +V. You can see that this pushes the output line high with the same "force" as it pulls it low.

# Pull-up Mode

In pull-up mode one of the transistors is replaced by a resistor. It is used, for example, in a serial bus configuration like the I2C bus. In this case the circuit is equivalent to having a single switch. When the switch is closed the output line is connected to ground and hence driven low. When the switch is open the output line is pulled high by the resistor.
