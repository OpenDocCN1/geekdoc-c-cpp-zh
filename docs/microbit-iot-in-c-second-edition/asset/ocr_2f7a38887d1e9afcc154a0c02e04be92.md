Notice that we use the library functions to generate the microsecond pulse that starts the read. Next comes a short pause and then we change the direction by writing a zero to the DIR register, read the state of the line and AND it with the mask to just get the bit which corresponds to P$\theta$. To return a one if the third bit is set, we simply shift 2 or 3 places right. Finally we return P$\theta$ to output by writing a one to the DIR register.

With this version of the readBit function you should find that everything works as before.

# Where Next

Once you have the basic bit/write functions, the rest follow fairly easily. Missing from the program given earlier is the ability to write to the configuration register to select the resolution, but in most cases the 12-bit default is what you want. Also missing is the CRC calculation to check for errors, and most important of all, the enumeration algorithm that discovers what 1-wire devices are active on the bus. All the omissions are straightforward to rectify now that we have the low-level data functions. You can also expand the operation to other 1-wire devices such as iButtons etc.
