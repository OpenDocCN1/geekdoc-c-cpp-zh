Better, but not perfect. Perfection is slightly more complicated. To switch the two lines at the same time we need to work with the OUT register.

As a demonstration, set all lines to input apart from lines P0 and P1 and then set these to high and low and then low and high repeatedly:

```
int main() {
    volatile unsigned int *dirset=(unsigned int*) (0x50000000UL+0x518);
    volatile unsigned int *out=(unsigned int*) (0x50000000UL+0x504);
    volatile int i;
    int n = 200;
    unsigned int mask1 = 1 << 2;
    unsigned int mask2 = 1 << 3;
    *dirset=(1 << 2) | (1<<3);
    {
        *out = mask1;
        for (i = 0; i < n; i++);
        *out = mask2;
        for (i = 0; i < n; i++);
    }
```

Notice to access the OUT register we need a new pointer. We still need mask1 and mask2 to set the two lines, one to high and one to low, before we start the loop. For a general program, we should read the OUT register and modify just the two bits we are interested in. Now the two lines switch in anti-phase together:

This is typical the sort of thing you have to do if it is important that GPIO lines change state at the same time.
