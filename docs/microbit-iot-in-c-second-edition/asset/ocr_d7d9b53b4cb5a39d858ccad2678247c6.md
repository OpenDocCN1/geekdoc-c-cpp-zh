# Configuration

There are two functions that set the format of operation.
The first sets the mode and the number of bits:
void format(int bits, int mode = 0);

where mode is set according to the table listed earlier and bits sets the number of bits between 4 and 16 to be transferred in a read/write operation.
The second simply sets the frequency of operation, i.e. the clock frequency:
void frequency(int hz = 1000000);

The allowed frequencies are:

+   125 kHz
250 kHz
500 kHz
1 MHz
2 MHz
4 MHz
8 MHz

If you don't select one of these the software selects the next highest.

# Data Transfer Function

Because of the SPI bus uses a full duplex transfer, you only need a single data transfer function, but this differs according to the micro:bit version you are using.

The micro:bit V1 has only:
int write(int value);

This sends a block of data to the slave while receiving a single block sent back. The number of bits sent and received is set by the configuration to anything from 4 to 16. In practice, this is a read/write function, but you can always throw away the data from the slave or send meaningless data to the slave to create something that looks like a read/write pair.

In the case of the micro:bit V2, the write function only sends the data and returns a zero or an error code. That is, it isn't bidirectional and hence not particularly useful. The bidirectional data transfer function:
transfer(*txBuffer,Size, *rxBuffer, rxSize);

This sends the data in the txBuffer and stores returned data in the rxBuffer.
It is slightly complicated to use but it is more useful.
