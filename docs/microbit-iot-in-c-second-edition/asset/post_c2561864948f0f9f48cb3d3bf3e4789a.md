# Raspberry Pi IoT in C, Second Edition

ISBN: 9781871962635

This book takes a practical approach to understanding electronic circuits and datasheets and translating this to code, specifically using the C programming language. The main reason for choosing C is speed, a crucial when you are writing programs to communicate with the outside world. If you are familiar with another programming language, C shouldn't be hard to pick up. This second edition has been brought up-to-date and focuses on the Pi 4 and the Pi Zero. There is new material on the recently introduced GPIO driver and using the Pi 4's additional ports and scheduling.

![](img/23976341c9281123e7b181beea6e9dbd_264_0.png)

Although NetBeans is used to develop programs, VS Code is now considered an alternative development environment and all the book's code, which is available for download, works best with VS Code.

The main idea in this book is not simply implement a driver, but to work directly with the hardware using the Raspberry Pi's GPIO (General Purpose Input Output) to connect with off-the-shelf sensors. It explains how to use its standard output with custom protocols, including an in-depth exposition of the one-wire bus. You will also discover how to pick the Internet into IoT sockets.

# Applying C For The IoT With Linux

ISBN: 9781871962611

If you are C to write low-level code using small Single Board Computers (SBCs) that run Linux, or if you do any coding in C that interacts with hardware, this book brings together low-level, hardware-oriented and often hardware-specific information. It starts by looking at how programs work with user-mode Linux. When working with hardware, separate chapters are devoted to integer, fixed-point and floating-point arithmetic. It goes on the pseudo file system, memory-mapped files and sockets as a general-purpose way of communicating over networks and similar infrastructure. It continues by looking at multitasking, locking, using mutex and condition variables, and scheduling. Later chapters cover managing cores and C11's atom, memory models and barriers and it rounds out with a short look at how to mix assembler with C.

# Fundamental C: Getting Closer To The Machine ISBN: 9781817192604

At an introductory level, this book explores C from the point of view of low-level programming and keeps close to the hardware. It covers addresses, pointers, and how things are represented using binary and emphasizes the important idea that everything is a pattern. For, the book covers installing an IDE and GCC before writing a Hello World program and then presents the fundamental building blocks of program - variables, assignment and expressions, flow of control using conditionals and loops.

![](img/23976341c9281123e7b181beea6e9dbd_265_0.png)

When programming in C you need to think about the way data is represented, and this book emphasizes the idea of modifying how a pattern is treated using type punning and unions the topic of undefined behavior, which is ignored in many books on C. A particular feature of the book is the way C code is illustrated by the assembly language it generates. This helps you understand why C is the way it is. And the way it was always intended to be written - close to the metal.
