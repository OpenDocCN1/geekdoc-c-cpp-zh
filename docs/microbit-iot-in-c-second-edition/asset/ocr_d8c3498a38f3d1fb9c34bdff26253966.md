The pinout diagrams for both V1 and V2 can be seen below:

As you can see in the standard pinout diagrams, most of the GPIO lines already have jobs. If you want to use them for your own purposes then whatever they are doing for the micro:bit has be turned off. For example, if you use any of the GPIO lines that are assigned to the LED display then you cannot use the LED display and if you do this this will take over the GPIO lines that you are using.

![](bbox=[0.298, 0.23, 0.755, 0.574])

The only GPIO lines that are completely free to use are without blocking access to other features are:

+   Free GPIO Pins
MICROBIT_PIN_P0
MICROBIT_PIN_P1
MICROBIT_PIN_P2
MICROBIT_PIN_P8
MICROBIT_PIN_P9 - V2 only
MICROBIT_PIN_P16

If you are prepared not to use the LED display then you can add to this list:

+   LED Display Pins
MICROBIT_PIN_P3
MICROBIT_PIN_P4
MICROBIT_PIN_P6
MICROBIT_PIN_P7
MICROBIT_PIN_P9
MICROBIT_PIN_P10
