R1 restricts the current to 0.48mA, which is below the target 0.5mA, and assuming that the transistor has a minimum current gain (listed as hfe or beta) of 50 provides 24mA to power it. R2 limits the current to 20mA. Notice that these values are for a red LED with forward voltage drop of 1.8V and typical current 20mA. LEDs of different color have different voltage drops and currents.

Assuming that you have this circuit constructed, then a simple PWM program to modify its brightness from low to high and back to low in a loop;

```
#include "MicroBit.h"
//define wait_us system_timer_wait_us // uncomment for V2
MicroBit uBit;
```

```
int main() {
  uBit.init();
  uBit.io.P0.setAnalogValue(511);
  uBit.io.P0.setAnalogPeriodUs(1000);
  int w=1;
  int inc=1;
  for (;;) {
    uBit.io.P0.setAnalogValue(w);
    w+=inc;
    if(w>1024 || w<=0)inc=-inc;
    wait_us(5000);
  }
  release fiber();
  return 0;
}
```

The basic idea is to set up a pulse train with a period of 1ms. In the for the duty cycle is set to 0% to 100% and back down to 0%. Notice that the way that the loop counts up and down is use inc which is either 1 or -1 and using the age old trick of flipping between 1 and -1 and back again by multiplying by -1.
