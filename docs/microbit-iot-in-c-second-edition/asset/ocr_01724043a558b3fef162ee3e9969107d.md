# The Mbed Online Compiler

The Mbed online compiler for the micro-bit V1 is an easy way to get started, but it is based on deprecated software so it might not be available in the long term. It can be used as a quick start for V1 development, but it doesn't work for the micro:bit V2.

These links and instructions could change. If so they will be updated on this books web page at www.iopress.info.

First sign up for an account with mbed at https://os.mbed.com

Once you have an account and signed in, your first task is to get the compiler set up with the micro:bit as its target. One route is to go to Hardware drop-down menu, select Boards and type BBC into the Search box. There is only one product in that category, i.e. the micro:bit.
