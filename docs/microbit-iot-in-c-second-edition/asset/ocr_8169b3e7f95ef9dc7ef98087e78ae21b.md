Notice the orientation of the path separators. Cmake works best with Unix/Linux path separators but Windows works best with Windows separators. You can see from the dialog box 10,859 absolute paths are replaced, but this might change as files/folders are modified in the repo.

If you want to change the project name, which modifies the names of the compiled files including the hello files, then:
bbuild\bbc-microsoft-classic-gcv\CMakeLists.txt

and change line 74 to:
project(HelloWorld)

Now you can load the project into VS Code or any IDE that can work with Cmake. Open a new VS Code window and load the HelloWorld folder. It should be recognized as a C/C++ CMake program.

If VS Code offers to configure the project then the best answer is to select Not now. If it does the project you may have to do a clean reconfigure and clean build to get things working.
