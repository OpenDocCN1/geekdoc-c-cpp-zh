The only problem is that if your aim is to get a clean wave form you have a lot of work to do. The fastest pulse rate is around 50ms on a V1 and the usual rule of thumb is that you need ten pulses to occur per conversion, i.e. the maximum frequency you can produce is:
pulse rate/10

This means the fastest signal you can create using the micro:bit is 1/500MHz or 2kHz, which isn't fast enough for a great many applications. In particular, you can't use it for complex sound synthesis.

You also have 1024 voltage levels you can use. At 3.3v each step corresponds to about 300µV. This is unrealistic for many applications and setting the voltage to the nearest 300mV or more sensible.

To demonstrate the sort of approach that you can use for D-to-A conversion, the following program creates a triangle or ramp waveform:

```
#include "MicroBit.h"

//define wait_us system_timer_wait_us // uncomment for V2
MicroBit uBit;

int main() {
  int i;
  uBit.init();
  uBit.P0.setAnalogValue(200);
  uBit.P0.setAnalogPeriodUs(50);
  for(i=0;i<1024;i+=10) {
    uBit.io.P0.setAnalogValue(i);
    wait_us(100);
  }
  release_fiber();
  return 0;
}
```

The inner loop for sets values of 0 to 1024 in steps of 10, i.e. 300mV per step and the delay of 100ms produces a total loop time of over 180ms. This means that around three pulses of each duty cycle should be produced - which is far too few, but it is interesting to see what happens. The waveform repeats around 18ms, which makes the frequency around 66Hz. Using an oscilloscope, the measured repeat time is more like 20ms or 50Hz.
