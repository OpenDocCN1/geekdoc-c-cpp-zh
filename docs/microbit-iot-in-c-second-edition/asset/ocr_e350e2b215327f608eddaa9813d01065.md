# Greyscale

One of the features of the framework's support for the LED display that isn't so obvious that you can use it as a greyscale display. The reason it isn't obvious is that there isn't a setvalue function for a single LED. The framework doesn't have any functions that work with a single LED at all. However, the display object uses a buffer which is a MicroBitImage object. The basic idea is that you can create MicroBitImage objects and print them to the display or you work directly with the buffer MicroBitImage object to display "live" graphics.

The key method is:
setPixelValue(int16_t x,int16_t y,uint8_t value)
where value can be anything from 0 to 255.

The brightness is created by simply turning the LED on and off in the correct ratio as in PWM, although PWM isn't used in the display. It is a simple consequence of the repeated rendering of the display and the percentage of time a pixel is set to on.
