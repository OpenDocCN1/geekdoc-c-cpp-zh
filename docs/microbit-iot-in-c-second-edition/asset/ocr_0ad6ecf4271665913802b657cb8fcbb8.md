| Host pulls up | Sensor pulls up | Sensor output | Sensor output 1 bit data of "1" | Transmission |
|---|---|---|---|--|
| VCC | and wait for sensor's response | get ready to output signal | 1 bit data of "0" | Transmission ended, RL pulls up |
| GND | Host send start signal | Sensor send out response | Sensor output alternative data of "0" or "1" based upon real value | Sensor pulls low |

![](bbox=[0.415, 0.263, 0.584, 0.292])

So what we have to do is pull the line for 1ms or so to start the device sending data and this is very easy. Then we have to wait for the line down and let it pull up again for about 160µs and then read the time that the line is high 40 times.

A 1 corresponds to 70µs and a 0 corresponds to 26µs. This is within the range of pulse measurement that can be achieved using standard library function. There is also a 50µs period between each data bit and this can be used to some limited processing. Notice that we are only interested in the time that the line is held high.
