The relationship between n and t, the time delay, is linear:

```
V1 n = 1.333t - 5.83
V2 n = 6.387t - 7.09
```

and it means you can't generate pulses less than about 6µs.

# Phased Pulses

As an example of using the output functions, let's try to write a short program that pulses two lines - one high and one low and then one low and one high, i.e. two pulse trains out of phase by 180 degrees. The simplest program to do this job is:

#include "MicroBit.h"

```
MicroBit uBit;
int main()
{
  int i;
  uBit.init();
  while (1) {
    uBit.io.P0.setDigitalValue(1);
    uBit.io.P1.setDigitalValue(0);
    uBit.io.P0.setDigitalValue(0);
    uBit.io.P1.setDigitalValue(1);
  }
}
```

Notice that there is no delay in the loop, so the pulses are produced at the fastest possible speed.
