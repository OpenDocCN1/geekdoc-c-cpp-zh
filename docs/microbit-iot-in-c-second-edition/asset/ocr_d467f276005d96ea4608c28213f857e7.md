As before, this program is for the micro:bit V2. If you want to use it with V1.5 you need to change _i2c to i2c. If you want to use it with the FXOS8700 you need to change the base address to 0x3E and the registers to 0x33 to 0x88.
You can look up the datasheet of the accelerometer and access both devices using I2C, but the framework provides a comprehensive and easy to use set of functions for most tasks which means you don't need to worry about what device is being used.
