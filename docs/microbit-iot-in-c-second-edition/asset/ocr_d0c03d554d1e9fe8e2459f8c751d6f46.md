If the AT command has been successful, it returns a string containing "OK".
One of the problems of working with AT commands is that they don't have an
syntax and there is no formal "end of message" signal.
By observation, any successful command does end with OK and if you can'tind OK in the response then you either haven't read it or there has been an
error. Clearly we need a way to test if a string contains OK:

```
int find(ManagedString c, ManagedString s) {
  int i;
  for (i = 0; i < (s.length() - c.length()); i++) {
    if (c == s.substring(i, c.length())) break;
  }
  if (i == (s.length() - c.length())) return 0;
  return 1;
}
```

This is the simplest string scanning function that will do the job. It only
checks that the string c is in once and it will find c if it is embedded in
another word. So it will find "OK" in "NotOK", for example.
With all this we can now finish the ATWiFi function:

```
int ATWiFi() {
  uBit.serial.send("AT\r\n", SYNC_SPINWAIT);
  uBit.sleep(150);
  ManagedString s = uBit.serial.read(500, ASYNC);
  if (DEBUG) debug("\n\rAT \n\r" + s + "\n\r");
  return find("OK", s);
}
```
