The exact timings can be seen below:

![](bbox=[0.238, 0.126, 0.811, 0.292])

It seems reasonable to use the typical timings shown in design. For a 0 we hold the line for 60µ then let it go high for the remainder of the slot. We send a 1 we hold the line for a bit more than 1µ then let it go high for the remainder of the slot. Notice that keeping the low period closer to 1µ than 15µ is a good idea because the master could read the line after as little 15µ.

The sendZero function is:

```
void sendZero() {
  int zero = 75;
  zero = 240; // uncomment for V2
  int slot = 30;
  slot = 300; // uncomment for V2
  volatile int i;
  P0.digitalValue(0);
  for (int i = 1; i < zero; i++);
  P0.digitalValue(1);
  for (int i = 1; i < slot - zero; i++);
}
```

The sendOne function is:

```
void sendOne() {
  int one = 1;
  one = 8; // uncomment for V2
  int slot = 30;
  slot = 300; // uncomment for V2
  volatile int i;
  P0.digitalValue(0);
  for (int i = 1; i < one; i++);
  P0.digitalValue(1);
  for (int i = 1; i < slot - one; i++);
}
```
