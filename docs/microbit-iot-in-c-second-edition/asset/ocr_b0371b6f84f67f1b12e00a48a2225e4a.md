where x means indeterminate and b9 is 0 or 1 according to the value of the ninth bit of the data. The remaining 9-bits are sent back in response to the next nine clock pulses, you have to transfer three bytes to get all ten bits of data. This all makes reading the data in eight-bit chunks confusing.

The datasheet suggests a different way of doing the job that delivers the data neatly packed into three bytes. What it suggests is to send a single byte:

00000001

The slave transfers random data at the same time which is ignored. The final 1 is treated as the start bit. If you now transfer a second byte with most significant bit indicating single or differential mode, then a three-bit address and the remaining bits set to zero the slave will respond with the null and the top two bits of the conversion. Now all you have to do is get the final eight bits of data to read:

|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|n| (Aligned with falling edge of clock) | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | | | | | | | |
| MCU Received Data (Aligned with rising edge of clock) | ? | ? | ? | ? | ? | ? | ? | ? | D2 | D1 | D0 | X | X | X | X |
| X = "Don't Care" | | | | | | | | | 87 | 86 | 85 | 84 | 83 | 82 | 81

You can do it first way that the datasheet describes, but this way you get two bytes containing the data with all the low-order bits in their correct positions.

Using this information we can write some instructions that read a given channel. For example, to read Channel 0 we first send a byte set to 0x01 as the start bit and ignore the slave transfers. We send 0x80 to select single-ended and Channel 0 keep what the slave sends back as the high-order two bits. Finally, we send a zero byte so that we get the low-order bits from the slave. For the microbit V1, using the SPITransfer function given earlier, is:

```
uint8_t buf[] = {0x01, 0x00, 0x00};
uint8_t readBuf[3];
CS.setDigitalValue(0);
SPITransfer(buf, 3, readBuf, 3);
CS.setDigitalValue(1);
```

Notice that the CS line is held low for the entire transaction.

For the microbit V2 the call to SPITransfer has been changed to:
pi.transfer(buf, 3, readBuf, 3);
uBit.sleep(1);
