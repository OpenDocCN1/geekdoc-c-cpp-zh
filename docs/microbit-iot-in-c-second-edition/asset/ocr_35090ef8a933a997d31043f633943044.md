# Summary

+   - Accessing the GPIO lines directly can be ten times faster than using the framework.
- The GPIO lines, in fact all of the peripherals, are accessed via memory-mapped registers.
- Each of the two possible banks of GPIO lines has a set of registers which allow you to configure and control the line.
- Although register access to the GPIO lines is faster, it is also subject to the variations imposed by the workings of the processor. This makes producing regular pulse trains difficult.
- Slower pulses are much less effected by the speed of operation of the processor.
- Using direct register access you can switch multiple lines on and off at the same time, i.e. without a lag.
- Direct register access can also be used for input and it too is ten times faster than using the framework.
