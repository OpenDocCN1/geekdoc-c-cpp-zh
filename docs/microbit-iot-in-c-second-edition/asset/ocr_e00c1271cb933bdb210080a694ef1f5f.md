The newer mbed tools, such as the offline development tool, Mbed Studio, don't support the micro:bit and even finding the micro:bit page, if you don't know where it is, is difficult. The problem is exacerbated by the fact that the C/C++ system makes use of a build tool called Yotta, which was developed specifically for mbed. While the Yotta project is still alive, there is very little activity on its GitHub site and facilities like the Yotta registry have been deprecated.

The software used by the V1 micro:isn't simpel. The mbed operating system sits on top of a lower-level library that works with the hardware, the NRF5 SDK, and on top of it is CODAL (Component Oriented Device Abstraction Layer), a library created by Lancaster University to provide a higher level access to the devices.
