# micro:bit V1.5 and V2

There are two possible combined accelerometers in use in the micro:bit v1,5 and V2. To find out which is actually in use you have to read and test the WHO_AM register. Unfortunately this is in a different location in each case.
Looking the values up in the datasheets allows us to write a program that tests for each device:

```
#include "MicroBit.h"

#define LSM303 ADDR 0x32
#define LSM303 WHO 0x0F
#define LSM303_VAL 0x33

#define FX058700 ADDR 0x3C
#define FX058700 WHO 0x0D
#define FX058700_VAL 0xC7
MicroBit uBit;

int main({
  uBit.init();
  uint8_t data[1];
  int status = 0;

  status = uBit._i2c.readRegister(LSM303_ADDR, LSM303_WHO, data, 1);
  if (data[0] == LSM303 VAL)
    uBit.serial.printf("LSM303 \n\r");

  status=uBit._i2c.readRegister(FX058700_ADDR,FX058700_WHO,data,1);
  if (data[0] == FX058700 VAL)
    uBit.serial.printf("FX058700 \n\r");
  return 0;
}
```

This works for the micro:bit V2 and uses the _i2c object to use the dedicated bus. To make it work on the V1.5 you simply change _i2c to i2c.
 a final example let's read the data from the LSM303 magnetometer. This consists of magnetic field strengths in the x, y and z directions. Each value is a 16-bit value and this is represented as pairs of registers. The datasheet gives these register addresses as 0x68 to 0x6D.
