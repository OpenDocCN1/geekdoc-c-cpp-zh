# Radio Sounds

The micro:bit has a radio which works as a Bluetooth Low Energy (BLE) connection. It can also be used in a raw point-to-point mode. The Bluetooth aspects of the radio are fairly well documented and mostly high level. What is more interesting to the C/C++ programmer is the radio used to send small amounts of data.

The V2 also has built loudspeaker which provides some other opportunities for using the radio. If you add an external speaker to the V1 then it could be used in the same way.

# Developing With Radio

Developing programs that work with a radio or any other form of communications is a doubly difficult task. The problem is that you have to have two programs – one sends and one receives. Even if you structure your program so that the same program works in both modes, the actual task for the transmitter and the receiver is different. Put simply, you have just written two new programs and you download one to the receiver and one to the transmitter – if it doesn't which has the problem?

This is we normal debugging procedures start to get complicated by the fact that you can only debug one at a time and you have to do on the other end of the link is running. If you can find a bug at the end you are working at, you have to switch your attention to the other end of the link and assume that the end you have left is working. This isn't particularly efficient and it can be very frustrating.

The best way to work, but it's not always possible, is to write the simplest program that works at both ends of the connection. Verify that this does work. Then proceed by making small changes at one end of the link only. This, of course, isn't always possible as a change in the transmitter often needs a change in the receiver, but it is surprising how often changes are simply elaborations on what is already working. If you need to change things at both ends of the connection then making small changes is your best method of keeping things manageable.
