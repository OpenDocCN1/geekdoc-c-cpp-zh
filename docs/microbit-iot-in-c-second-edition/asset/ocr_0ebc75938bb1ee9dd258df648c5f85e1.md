# Using a Single GPIO Line

The library just isn't fast enough to change the direction of a GPIO line and read the state and switch back to output in time to read the pulse sent by the slave device. If you make of direct access to the GPIO control registers, however, this can be done. The details of the GPIO registers work are in Chapter 4.

First remove the physical connection to P1 – only P0 is used in the following.
The only function that we need to change is the readBit function. We need to set up some addresses:

```
volatile unsigned int *setdir = (unsigned int*) (0x50000000UL+0x518)
volatile unsigned int *cdir = (unsigned int*) (0x50000000UL+0x51C);
volatile unsigned int *inp = (unsigned int*) (0x50000000UL+0x510);
GPIO = 3;//change to 2 for V2
```

The pin we want to work is P0, which maps to GPIO in the case of the micro:bit V1 and GPIO P0_2 in the case of V2. First we set the mask for pin n is 1<<n.

Now all we have to do is the modify readBit function to use the same GPIO line to read the data. All we have to do is change the GPIO line's direction to input, read it and then set it back to output.

```
int readBit()
{
volatile int i;
int sample = 20;
sample = 55; // uncomment for V2
int pulse = 1;
pulse = 8; // uncomment for V2
int slot = 30;
slot = 300; // uncomment for V2
disable_irq(0);
P0.setDigitalValue(0);
for (i = 1; i < pulse; i++);
P0.setDigitalValue(1);
for (i = 1; i < sample; i++);

*pinDir = 0x0;
unsigned int b = (*inp) & mask;
b = b >> GPIO;
*pinDir = 0x1;
_enable_irq(0);
for (i = 1; i < slot - sample - pulse; i++);
return b;
}
```
