# Prerequisites

It doesn't matter whether the micro:bit you are using is a V1 or V2, the prerequisites for getting started are the same. To develop C/C++ programs for the micro:bit using the templates you need the GCC ARM compiler together with Cmake and Ninja (or make on non-Windows systems). To compile the code you also need first the arm-none-gcc compiler. This can be downloaded from a number places: https://developer.arm.com/tools-and-software/open-source-software/developer-tools/gnu-toolchain/gnu-rm/downloads

Run the installer and follow the instructions. Make sure to tick Add path to environment variable at the end of the installation:

![](bbox=[0.21, 0.345, 0.735, 0.672])

The compiler is installed in:
:\Program Files (x86)\GNU Arm Embedded Toolchain

You can check that it is installed and on the path using: arm-none-eabi-gcc -v\ which will display a lot of information about the version and configuration.

Next you need to install Cmake:
https://cmake.org/download/
