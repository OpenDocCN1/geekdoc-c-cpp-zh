# Phased Pulses

There is an almost important reason, other than, speed for using direct access to the hardware. It allows you to set multiple GPIO lines at the same time, eliminating much of the synchronization problem encountered in the previous chapter. For example, to switch P0 and P1 in phase you would:

```
int main() {
    volatile unsigned int *dirset=(unsigned int*)0x50000000UL+0x518);
    volatile unsigned int *outset=(unsigned int*)0x50000000UL+0x508);
    volatile unsigned int *outclr=(unsigned int*)0x50000000UL+0x50C);

    volatile int i;
    int n = 200;
    unsigned int mask = 1 << 2 | 1 << 3;
    *dirset = mask;
    for (;;) {
        *outset = mask;
        for (i = 0; i < n; i++){}
        *outclr = mask;
        for (i = 0; i < n; i++){}
    }
}
```

For V1 P0 and P1 on the edge connector is GPIO P0_3 and P0_2 and for V2 they are GPIO P0_2 and P0_3, hence the mask setting bits 3 and 2 works for both. If you try this out you will find that the two GPIO lines change at the same time:
