There are some differences between the V1 and V2 GPIO assignments. The micro:bit V1 has a single bank of 32 GPIO lines, P_00 to P_31. The micro:bit V2 has an additional set of ten GPIO lines, P_00 to P_09– most of which are used internally. You can see that, for example, MICROBIT_PIN_P20 is mapped to P_30 on the V1 and to P_00 on the V2, i.e. the first GPIO line in the second GPIO bank. There are also a set of definitions for p0 to p47, notice the use of lower case, which includes both banks of GPIO lines without distinguishing between them but with P1_0 mapped to P32 and so on.
Only use the GPIO line numbers if you can't avoid it as the pin names work on both versions of the micro:bit. For example if you use MICROBIT_PIN_P20 it will evaluate to either P_30 or P1_00 depending on which version you are compiling for.
There are also other pin intended for use with events.
