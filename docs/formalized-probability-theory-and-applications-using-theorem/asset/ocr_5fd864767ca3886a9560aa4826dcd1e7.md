# 12.2.2 CDF Is Monotonically Increasing

For any two real numbers a and b, if a < b then F_x(a) <= F_x(b). This property can be expressed in HOL4 as follows:

# Theorem 12.2

```
|- \/ X p a b.
prob_space p /\ (events p = POW (p_space p)) /\
a <= b ==> CDF p X a <= CDF p X b
```

The proof of Theorem 9.2 is based on the principles of set and probability theories.

# 12.2.3 Interval Probability

For any two real numbers a and b, if a < b, then Pr (a < X <= b) = F_x(b) - F_x(a). This property can be expressed in HOL4 as follows:

# Theorem 12.3

```
|- \/ X p a b.
prob_space p /\ (events p = POW (p_space p)) /\
a <= b ==> (distribution p X { y | a < y /\ y <= b } = CDF p X b - CDF p X a)
```

where the function distribution is defined in Definition 5.5. The proof of Theorem 9.3 is again based on some already verified theorems for the set and probability theories.
