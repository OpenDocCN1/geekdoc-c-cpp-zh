

## Theorem 4.4

```
\vdash f \in measurable a Borel =
sigma_algebra a \land f \in (space a \rightarrow UNIV) \land
\forall c. {x | f x < c} \cap space a \in subsets a
```

在该定理的证明中，假设 f 关于 (A, B(R)) 可测，我们在前一节中已经表明 \(\forall c \in R, ]-\infty, c[ \in B(R)\)。由于 f 可测，则 \(f^{-1}(]-\infty, c[) \in A\)。现在假设 \(\forall c \in R, f^{-1}(]-\infty, c[) \in A\)，我们需要证明 \(\forall A \in B(R), f^{-1}(A) \in A\)。这源自开集的性质，即 A 是开区间的可并集，以及等式 \(f^{-1}(\cup_{n \in N} A_n) = \cup_{n \in N} f^{-1}(A_n)\) 和 \(f^{-1}(]-\infty, c[) = \cup_{n \in N} f^{-1}(]-n, c[)\)。

同样，在 HOL4 的测度理论形式化中也已验证，f 关于 (A, B(R)) 可测当且仅当 \(\forall c, d \in R\)，以下任一类区间的原像是 A 的元素：\(]-\infty, c[\)、\([c, +\infty[\)、\(]c, +\infty[\)、\(]-\infty, c[\)、\([c, d[\)、\(]c, d[\)、\([c,d]\)。空间 X 上的每个常值实函数都是可测的。集合 A 上的指示函数可测当且仅当 A 可测。

下面描述了在 HOL4 测度理论形式化中已验证的实值可测函数的其他各种有用性质。

若 f 和 g 为 (A, B(R)) 可测且 \(c \in R\)，则 c f、|f|、f^n、f + g、f * g 和 max (f, g) 均为 (A, B(R)) 可测。

## Theorem 4.5

```
\vdash \forall a f g h c.
sigma_algebra a \land
f \in measurable a Borel \land
g \in measurable a Borel \Rightarrow
((\lambda x. c * f x) \in measurable a Borel) \land
((\lambda x. Abs (f x)) \in measurable a Borel) \land
((\lambda x. f x pow n) \in measurable a Borel) \land
((\lambda x. f x + g x) \in measurable a Borel) \land
((\lambda x. f x * g x) \in measurable a Borel) \land
((\lambda x. max (f x) (g x)) \in measurable a Borel)
```

记号 \((\lambda x. f x)\) 是 f 的 lambda 记法，用于表示函数 f: x \rightarrow f(x)。

若 (f_n) 是关于 (A, B(R)) 的扩展实值可测函数的单调递增序列，且 \(\forall x, f(x) = \sup_{n \in N} f_n(x)\)，则 f 也是 (A, B(R)) 可测。

## Theorem 4.6


每个连续函数 g: R->R 都是 (B(R), B(R)) 可测的。

## Theorem 4.7

```
|- \forall g. (\forall x. g contl x) \implies g \in measurable Borel Borel
```

若 g: R->R 连续且 f 为 (A, B(R)) 可测，则 g o f 也是 (A, B(R)) 可测。

## Theorem 4.8

```
|- \forall a f g. sigma_algebra a \land f \in measurable a Borel \land
(\forall x. g contl x) \implies g o f \in measurable a Borel
```

定理 4.7 是连续函数的开集原像为开集这一定理的直接结果。定理 4.8 例如保证，若 f 可测，则 exp (f)、Log (f)、cos (f) 均可测。这是利用定理 4.7 和等式 \((g \circ f)^{-1} (A) = f^{-1} (g^{-1} (A))\) 推导出来的。

现在，测度空间的乘积也可以形式化，以便能够形式化定义在乘积空间上的可测函数。设 m1 = (X1, S, \mu_1) 和 m2 = (X2, S_2, \mu_2) 为两个测度空间。m1 和 m2 的乘积定义为测度空间 (X1 x X2, S, \mu)，其中 S 是由形式为 A1 x A2 的子集生成的 X1 x X2 上的 sigma 代数，其中 \(A_1 \in S\)，\(A_2 \in S_2\)。测度 \mu 对于 \sigma-有限测度空间定义为

```
\mu(A) = \int_{X1} \mu_2(\{y \in X_2 | (x,y) \in A\}) d\mu_1 (4.2)
```

并且 S 使用 sigma 算子定义，该算子返回包含一组子集的最小 sigma 代数，即在此情况下的乘积子集。令 g(s1) 为函数 s2 -> (s1, s2)，并令 PREIMAGE 表示 HOL 中的原像函数，则乘积测度被形式化。

## Definition 4.24

```
⊢ ∀ m1 m2. prod_measure m1 m2 =
(λ a. integral m1 (λ s1. measure m2 (PREIMAGE g(s1) a)))
```

该定义中的积分是勒贝格积分，我们将在下一节中介绍其形式化。现在可以在 HOL4 中验证，对于有限测度空间，乘积测度可归约为 \(\mu(a_1 \times a_2) = \mu_1(a_1) \times \mu_2(a_2)\)。

## Theorem 4.9

```
⊢ prod_measure m1 m2 (a1 x a2) = measure m1 a1 x measure m2 a2
```

上述定义可用于定义多于两个测度空间的乘积，如下所示。X1 x X2 x X3 = X1 x (X2 x X3)，且 \(\mu_1 \times \mu_2 \times \mu_3\) 定义为 \(\mu_1 \times (\mu_2 \times \mu_3)\)。绝对连续测度的概念也在 HOL4 中定义，其中 \(\mu_1\) 被称为相对于 \(\mu_2\) 绝对连续，当且仅当对于每个可测集 A，\(\mu_2 (A) = 0\) 蕴含 \(\mu_1 (A) = 0\)。

## 4.3 HOL 中勒贝格积分的形式化

勒贝格积分是许多数学理论中的基本概念，例如实分析（Goldberg, 1976）和概率论（Halmos, 1944），这些理论广泛用于建模和推理物理系统中的连续和不可预测组成部分。与常见的 Riemann 积分相比，其广泛应用的原因包括能够处理更广泛的函数类（这些函数定义在比实直线更一般的类型上），以及在交换极限和积分时具有更好的性质，这一点例如在傅里叶级数研究中至关重要。

类似于阶梯函数在 Riemann 积分发展中的使用方式，勒贝格积分使用了一类称为正简单函数的特殊函数。它们是取有限多个值的可测函数。换句话说，正简单函数 g 由三元组 (s, a, α) 表示，作为可测集（aⱼ）的指示函数的有限线性组合，这些集合构成空间 X 的一个划分。

```
∀ x∈ X, g(x) = Σₖ αₖ I_{Aₖ}(x) αᵢ ≥ 0 (4.3)
```

我们还添加了正简单函数取有限值的条件，即 \(\forall i \in s, \alpha_i < \infty\)。然而，它们的勒贝格积分可以是无穷的。勒贝格积分首先针对这些函数定义，然后扩展到非负函数，最后扩展到任意函数。

设 \((X, \mathcal{A}, \mu)\) 为一个测度空间。正简单函数 g 关于测度 \(\mu\) 的积分定义为

\(\int_X g d\mu = \sum_{i \in s} \alpha_i \mu(a_i)\) (4.4)

这在 HOL4 中形式化如下：

## Definition 4.25

```
\(\vdash \forall m s a \alpha. \text{pos\_simple\_fn\_integral m s a} \alpha =\)
\(\text{SIGMA } (\lambda i. \alpha_i * \text{measure m (a i)}) s\)
```

虽然用于表示 g 的 \(((\alpha), (a), s)\) 的选择不是唯一的，但如上定义的积分与该选择无关。已验证了正简单函数勒贝格积分的若干性质，例如线性性和单调性。这些结果可以扩展，用于勒贝格积分为扩展实值积分的定义。

正简单函数勒贝格积分的定义可用于使用上确界算子定义非负可测函数的积分，如下所示：

\(\int_X f d\mu = \sup \{ \int_X g d\mu | g \le f \text{ and } g \text{ positive simple function } \}\) (4.5)

它可以在 HOL4 中如下形式化：

## Definition 4.26

```
\(\vdash \forall m f. \text{pos\_fn\_integral m f} =\)
\(\text{sup } \{ r | \exists g. r \in \text{psfis m g} \land \forall x. g x \le f x \}\)
```

其中 psfis m g 用于表示正简单函数 g 的勒贝格积分。最后，任意可测函数 f 的积分通过 f^+ 和 f^- 的积分来形式化，其中 f^+ 和 f^- 是由 f^+(x) = max (f(x), 0) 和 f^-(x) = max (-f(x), 0) 定义的非负函数。
