# KEY TERMS AND DEFINITIONS

**Reliability:** Reliability is defined as the probability of a system or component performing its desired task over a certain interval of time.

**Reliability Block Diagrams:** Reliability Block Diagrams (RBDs) are graphical structures consisting of blocks and connector lines. The blocks usually represent the system components and the connection of these components is described by the connector lines. The system is considered to be functional, if at least one path of properly functional components from input to output exists otherwise it fails.

**Survivability:** Survivability is the probability that a given system will survive after a given time.
