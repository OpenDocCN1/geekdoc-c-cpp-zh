# 11.3.1 Encoding-Decoding

We use a straddling checkerboard to convert the alphabetic plaintext into digits. With this conversion scheme, the more frequent letters in a language are encoded with a lower number of digits, leading to a compressed output and, hence, shorter messages to be transmitted. Besides, a straddling checkerboard allows to achieve a simple form of information diffusion, or in other words, it reduces the redundancy in the statistics of the plaintext. An example checkerboard for the English language can be found in Figure 7. We formalize the straddling checkerboard as the function checkerboard of the HOL4 type:

```
|- checkerboard: char -> num
```

We present the definition of checkerboard associated with Figure 7 for the first-row letters as well as P and /.

```
|- (checkerboard # "" A "" = 0) ^
(checkerboard # "" T "" = 1) ^
(checkerboard # "" O "" = 3) ^
(checkerboard # "" N "" = 4) ^
(checkerboard # "" E "" = 5) ^
(checkerboard # "" S "" = 7) ^
(checkerboard # "" I "" = 8) ^
(checkerboard # "" R "" = 9) ^
(checkerboard # "" P "" = 60) ^
(checkerboard # "" / "" = 69)
```

Using the above definition of the straddling checkerboard, we formalize the encoding and decoding blocks as encode and decode functions, respectively.
