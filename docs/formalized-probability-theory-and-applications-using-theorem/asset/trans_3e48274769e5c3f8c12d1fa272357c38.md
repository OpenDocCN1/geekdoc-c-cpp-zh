

## 12.1 生命分布

工程系统可靠性分析的首要基础（Billinton & Allan, 1992）是生命分布。根据生命可靠性分析问题的具体需求，文献中已使用了各种生命分布表示形式。例如，有时人们关注某一特定时间的故障概率（生存函数），而在其他一些应用中，例如在规划系统的可服务性和可维护性时，可能需要系统在给定时间之前的总风险量（累积风险函数）。另外两种常用的重要可靠性特性是风险函数和分位函数。风险函数表达给定时间的故障风险，而分位函数允许推理与给定故障概率对应的故障时间。生存函数 $S_T(t)$ 定义为：

$S_T(t) = 1 - F_T(t)$ (12.1)

其中 $F_T(t)$ 是随机变量 $T$ 的累积分布函数。风险函数 $h_T(t)$ 定义为：

$h_T(t) = \frac{dS_T(t)}{dt} \frac{1}{S_T(t)} = \lim_{h \to 0} \frac{S_T(t) - S_T(t+h)}{h S_T(t)}$ (12.2)

累积风险函数 $H_T(t)$ 定义为：

$H_T(t) = \int_0^t h_T(\tau) d\tau$ (12.3)

最后，随机变量 $T$ 的第 $p$ 个分位数 $t_p(p)$ 定义为：

$t_p(p) = F_T^{-1}(p)$ (12.4)

本章的主要范围是在高阶逻辑中形式化累积分布函数和生存函数，并形式化验证它们的一些关键特性。这种形式化随后可用于形式化其他生命分布，或在定理证明者（Hasan, Tahar, & Abbasi (2014); Abbasi, Hasan & Tahar (2010); Abbasi, Hasan, & Tahar, (2012); Abbasi, (2012); Abbasi, Hasan & Tahar, 2014）的可靠内核中推理工程系统的可靠性方面。

## 12.2 累积分布函数

在本节中，我们介绍了累积分布函数（CDF）的形式规范以及在 HOL4 定理证明者中对 CDF 特性的验证。CDF 及其特性一直是任何可靠性分析不可或缺的一部分，因为所有生命分布主要都基于 CDF。

从数学上讲，CDF 定义如下：

$F_x(t) = Pr(T \le t)$ (12.5)

根据方程 (12.5)，CDF 可以在 HOL4 中由一个高阶逻辑函数形式化指定，该函数接受随机变量作为参数，并返回给定随机变量小于或等于任何给定实数值的事件的概率。CDF 的形式化已在定义 5.6 中给出，我们在此重复：

### 定义 12.1

```
⊢ ∀ p x. CDF p X x = distribution p X { y | y ≤ x }
```

其中 X 表示随机变量，p 是概率空间，x 是实参数。使用 CDF 的这种形式规范，我们可以在 HOL4 定理证明者中验证经典的 CDF 特性。这些特性的形式证明不仅确保了定义 12.1 的正确性，而且在证明与生命分布相关的各种可靠性特性方面也起着至关重要的作用。

### 12.2.1 CDF 边界

根据 CDF 边界特性，对于任何实数 x，0 ≤ F_x(x) ≤ 1。换句话说，如果我们将 CDF 与其实参数 x 绘制在图上，那么 CDF 的图形 F_x 始终位于两条水平线 y=0 和 y=1 之间。这一特性可以在 HOL4 中使用基本概率定律进行验证，该定律指出事件的概率始终小于 1 且大于 0。

### 定理 12.1

```
|- \/ X p x .
prob_space p /\ (events p = POW (p_space p))
==> 0 <= CDF p X /\ CDF p X <= 1
```

### 12.2.2 CDF 单调递增

对于任何两个实数 a 和 b，如果 a < b，则 F_x(a) <= F_x(b)。该特性可以在 HOL4 中按以下方式表示：

### 定理 12.2

```
|- \/ X p a b.
prob_space p /\ (events p = POW (p_space p)) /\
a <= b ==> CDF p X a <= CDF p X b
```

定理 12.2 的证明基于集合论和概率论的原理。

### 12.2.3 区间概率

对于任何两个实数 a 和 b，如果 a < b，则 Pr (a < X <= b) = F_x(b) - F_x(a)。该特性可以在 HOL4 中按以下方式表示：

### 定理 12.3

```
|- \/ X p a b.
prob_space p /\ (events p = POW (p_space p)) /\
a <= b ==> (distribution p X { y | a < y /\ y <= b } = CDF p X b - CDF p X a)
```

其中函数 distribution 在定义 5.5 中定义。定理 12.3 的证明同样基于集合论和概率论的一些已验证定理。

### 12.2.4 正负无穷处的 CDF

根据正无穷处的 CDF 特性，如果 CDF 的参数 x 趋近于无穷大，则 CDF 的值趋近于 1，即，

lim_{x->\infty} F_x(x) = 1 (12.6)

该特性可以在 HOL4 中按以下方式表示：

### 定理 12.4

```
|- VX p.
prob_space p ∧ (events p = POW (p_space p)) ∧
(Vy. X y ≠ PosInf) ⇒ (∀n. CDF p n) → 1
```

其中 (\lambda n. f n) → k 表示 HOL 中实数序列的极限，即当函数 f 的参数趋近于无穷大时 lim (f) = k。假设 (Vy. X y ≠ PosInf) 确保随机变量永远不会取得无穷值，因为如果没有此条件，上述特性将不成立。定理 12.4 的 HOL4 证明步骤基于概率的连续性特性，该特性指定了单调递增事件序列 A_n（即对于每个 n，A_i ⊆ A_{i+1}）的概率极限值与所有可表示为 A_∞ 的事件的可数并的概率为 1 这一事实之间的关系。类似地，负无穷处的 CDF 特性可以作为以下定理进行形式化验证：

### 定理 12.5

```
|- VX p.
prob_space p ∧ (events p = POW (p_space p)) ∧
(Vy. X y ≠ NegInf ∧ X y ≠ PosInf) ⇒ (∀n. CDF p -n) → 0
```

## 12.3 生存函数

生存函数表示组件在某一特定时间 t 处于工作状态的概率，可以使用方程 (12.1) 在 HOL4 中形式化如下：

### 定义 12.2

```
|- VX p t. survival_function p X t = 1 - CDF p X t
```

使用上述生存函数的形式化，以下存在性特性可以在 HOL 中进行形式化验证。

### 12.3.1 时间 0 处的生存函数

正常组件在时间 0 工作正常的概率为 1。该特性可以在 HOL 中作为以下定理进行形式化验证：

### 定理 12.6

```
|- \forall X p.
prob_space p \land (events p = POW (p_space p)) \land
(Vy. X y # NegInf \land X y # PosInf)\land
((\lambda x. distribution p X {y | y \le Normal x}) contl 0) \land
(Vx. Normal 0 \le X x)
=> (survival_function p X 0 = 1)
```

假设 ((\lambda x. distribution p X {y | y \le Normal x}) contl 0) \land (Vx. Normal 0 \le X x) 确保随机变量 X 是一个连续且取正值的随机变量。这些条件是有效的，因为随机变量必须与实时具有相同的数据类型，而实时始终是连续且正的。定理 12.6 的证明基于 CDF 和连续函数的特性。

### 12.3.2 生存函数趋于 0

基于生存函数的定义，因此也基于其与 CDF 的关系，可以观察到，随着其参数变得非常大，生存函数的值将趋近于 0。该特性可以在 HOL4 中按以下方式表示：

### 定理 12.7

```
|- \forall X p.
prob_space p \land (events p = POW (p_space p)) \land
(Vy. X y # NegInf \land X y # PosInf) \land
=> (lim (\lambda n. survival_function p X n) = 0)
```

其中函数 lim (\lambda n. fn) 表示实数序列的极限，即 lim_{n->\infty} f(n)。

上述定理的证明基于实数序列极限、CDF 以及概率论的一些公理的特性。

### 12.3.3 生存函数是非递增函数

对于任何两个实数 a 和 b，如果 a \le b，则 S_X(b) \le S_X(a)。该特性可以在 HOL4 中按以下方式表示：
