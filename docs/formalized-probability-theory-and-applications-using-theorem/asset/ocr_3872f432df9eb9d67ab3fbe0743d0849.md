# 13.2 FORMAL ANALYSIS OF THE K-SET RANDOMIZED SCHEDULING

The formal probabilistic analysis of any system can be broadly divided into two main steps, i.e., the formalization of the given system, while modeling its random components by the formalized random variables, and using this model to formally verify properties of interest as higher-order-logic theorems. In this section, we develop a HOL4 formalization of the coverage-based random scheduling algorithm for WSNs (Elleuch, Hasan, Tahar & Abid, 2011; Elleuch, Hasan, Tahar & Abid, 2013).

# 13.2.1 Formalization of Random Variables

The challenge in the random scheduling algorithm described below, is to select a value of k so that the energy can be saved with a good coverage. Therefore, the performance of this algorithm depends essentially on the chosen value of k. A large k will imply a lot of sub-networks which would in turn result in few nodes in each of these sub-networks, and hence a poor coverage. However, a small k will imply few sub-networks with a lot of points covered simultaneously by a lot of nodes, so a waste of energy.

The random scheduling algorithm involves several random variables. The first one distributes uniformly the nodes over the sub-networks. It is formalized in HOL4 as follows:

```
Definition 13.1
|- ∀X p a n. uniform_distr X p (a: num) (n: num) =
  (real_random_variable X p) ∧
  (IMAGE X (p_space p) = (gen_set_unif n a)) ∧
  (events p = POW (p_space p)) ∧
  (∀y. (y IN (IMAGE X (p_space p))) => (distribution p X { y } = 1 / n)))
```

The above function uniform_distribution_rv accepts four parameters, i.e., a real random variable X, a probability space p, a positive integer a, and the input parameter k of the Uniform random variable. Note that the type of variables a and n is num or positive integers since X is a real-valued discrete random variable. The function gen_set_unif, used in this definition, defines the possible values for the random variable X, i.e., {a; a + 1; ... ; a + k }.
