
## 14.3 WSN FOR BORDER SURVEILLANCE

Wireless sensor networks have been widely explored for border monitoring applications (Sun et al., 2011). The main goal of a WSN deployed for border monitoring is to continuously detect intruding elements with a high probability and a small delay. These systems are useful for the detection of forces or vehicles in a military context, or the prevention of illegal intrusions of migrants or terrorists along a country border. In this context, the potential harsh nature of the field of interest makes a random deployment by air-dropping sensors much more practical. In this section, we are interested in formally analyzing the detection performances of a wireless sensor network deployed for a border monitoring application.

Due to the safety-critical feature of the target application, the deployed WSN has to remain alive as long as possible while ensuring an efficient detection. Nevertheless, most of the existing WSNs for border monitoring suffer from lifetime limitations, e.g., a REMBASS sensor node, once deployed, can be functional for 30 days only. In case of using the WSN to monitor terrorist intrusions along a mountainous border, it is obviously not required to monitor the whole area at all times. Thus, we can use the k-set randomized scheduling algorithm to preserve energy in a given border monitoring application. In the specified application, the nodes have a sensing area r = 30, and are deployed into an area of size a = 10000m², whereas, the success probability q of a sensor covering a point, is q = r/a = 0.28.

In the previous section, we analyzed the detection probability Pr (D) according to the intrusion length L by distinguishing 2 cases: { L < (k – 1) x Ts } and { L ≥ (k – 1) x Ts }. It is important to note that, in the current application analysis, we focus on the first case; { L < (k – 1) x Ts }, which reflects transient events, that may not be detected, and is thus the most pertinent part of this analysis. For the other case, i.e., { L ≥ (k–1) x Ts }, we have already discussed that the detection probability Pr (D) equals the network coverage.

Based on our theoretical development done in the previous section, we now conduct a formal asymptotic analysis (Xiao, Zhang, Sun & Chen; 2007) of the probabilistic detection and delay based on the parameters n and k. For that, we are going to tackle the generic case and then instantiate it for the given border monitoring application. Hence, we simply denote (prob p (p_space p DIFF (udset n k s L Ts q))) by (Pd_wsn p n k s L Ts q) and (delay_wsn p n D k q) as (D_wsn p D n k q). In the context of our application, we basically verify two main properties of interest related to the detection probability of the events of interest and the detection delay. Thus, we easily check in HOL4 that (prob p (p_space p DIFF (udset n k s L Ts (0.28)))) equals

```
1 - ((1 - s) \times \left( 1 - \frac{\lfloor L/T_s \rfloor}{k} \times (0.28) \right)^n - s \times \left( 1 - \frac{\lfloor L/T_s \rfloor}{k} + 1 \times (0.28) \right)^n
```

and, the expected detection delay, (delay_wsn p D n k (0.28)), is

```
\sum_{j=1}^n E(D|c=j) \times C_n^j \times (0.28)^j \times (1-(0.28))^{n-j}
```

where E (D | c = j) represents the expression specified in Equation (14.30). Next, we simply denote Equation (14.31) and Equation (14.32), by (Pd_surv p n k s L Ts (0.28)) and (D_surv p D n k (0.28)), respectively. It is important to note that, for space constraints, and in all the asymptotic analysis below, we only mention the main mathematical assumptions related to the used variables in the detection probability and delay.

Hence, we formally verify that the detection probability is an increasing function of n, i.e., a larger n value leads to a better detection probability.

### Lemma 14.1

```
\vdash \forall p k q s L Ts. (1 < k) \land (0 < s < 1) \land (0 < L) \land (0 < Ts) \land (L < s (k-1) \times Ts) \land (0 < q < 1) \Rightarrow (mono_incr (\lambda n. Pd_wsn p n k s L Ts q)) .
```

where mono_incr is the HOL4 definition of an increasing sequence, which we define as follows:

### Definition 14.7

```
\vdash \forall f. mono_incr f \iff \forall n. f n \le f (SUC n) .
```

Besides, we formally verify, in Lemma 14.2, that the probability of detecting an intrusion event approaches 1 as the number of deployed nodes becomes very very large.

### Lemma 14.2

```
|- !V p k q s L Ts. (1 < k) /\ (0 < s < 1) /\ (0 < L) /\ (0 < Ts) /\
(L < s & ((k-1) x Ts) /\
(0 < q < 1) ==> lim n-->+inf (|An. Pd_wsn p n k s L Ts q) = 1.
```

where lim is the HOL4 formalization of limit for real sequences.

Similarly, it is also very useful to investigate the delay behavior of the randomized scheduling. Thus, we formally verify, in Lemma 14.3, that the detection delay D_wsn starts to be decreasing versus the number of nodes n from a given range, denoted n0. Consequently, D_wsn becomes smaller when a large number of nodes is deployed. In this case, an intrusion is expected to be detected more quickly, since it is likely that many more covering nodes are deployed in the surrounding area.

### Lemma 14.3

```
|- !V p k q s L Ts. (1 < k) /\ (0 < s < 1) /\ (0 < L) /\ (0 < Ts) /\
(0 < q < 1)
==> (mono_decr_range (|An. (real (D_wsn p n k q)))) .
```

where the function real is used to convert the detection delay of type extended real to its corresponding real value.

### Definition 14.8

```
|- !V f. mono_decr_range f <=> (!E n0. !N. n >= n0 ==> f (SUC n) <= f n) .
```

Based on Lemmas 14.1 and 14.2, we establish that any target detection probability Pd_wsn can be achieved by increasing the number of deployed nodes n, for any values of the input variables k, q, s, L, and Ts. More specifically, these results can be easily verified for the detection probability, Pd_surv, in the context of the given border monitoring application (Lemmas 14.4 and 14.5).

### Lemma 14.4

```
|- !V p k s L Ts. (1 < k) /\ (0 < s < 1) /\ (0 < L) /\ (0 < Ts) /\
(L < s & (k - 1) x Ts)
==> (mono_incr (|An. Pd_surv p n k s L Ts (0.28)))) .
```

### Lemma 14.5

```
⊢ ∀ p k s L Ts. (1 < k) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts) ∧
(L < s & (k - 1) x Ts)
⇒ lim (∀ n. Pd_surv p n k s L Ts (0.28)) = 1.
```

In addition, we reconfirm the result of Lemma 14.3 using Lemma 14.6, i.e., increasing the number of deployed nodes n gives smaller detection delays and thus a better performance of the deployed application.

### Lemma 14.6

```
⊢ ∀ p k s L Ts. (1 < k) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts)
⇒ (mono_decr_range (∀ n. (real (D_surv p D n k (0.28))))).
```

According to Lemmas 14.1 and 14.3, enhancing the detection capacities of the deployed WSN, is possible through the deployment of more nodes. However, random deployment is known to be very costly for most WSN applications. In the context of a WSN using the k-set randomized scheduling, it is usually possible to improve the whole detection capacity of the network by simply updating the number of disjoint subsets k by a suitable value.

Based on the parameter k, we perform now an interesting study of the limiting behavior of the detection performances. First, we formally verify that a smaller k value induces a larger detection probability Pd_wsn, i.e., Pd_wsn decreases while increasing the value of k:

### Lemma 14.7

```
⊢ ∀ p k q n s L Ts. (1 ≤ n) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts) ∧
(0 < q < 1) ∧
(∀k. L < s & (SUC k) x Ts) ⇒ (mono_decr (∀k. Pd_wsn p n k s L Ts q)).
```

where the HOL4 function mono_decr defines a decreasing sequence as follows:

### Definition 14.9

```
⊢ ∀ f. mono_decr f ⇔ ∀n. f (SUC n) ≤ f n.
```

We formally confirm that given a number of nodes n, the detection probability Pd_wsn goes to 0 when k becomes very large:

### Lemma 14.8

```
⊢ ∀ p q n s L Ts. (1 ≤ n) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts)
∧ (0 < q < 1) ∧
(∀k. L < s (SUC k) x Ts) ⇒ lim (λk. Pd_wsn p n k s L Ts q) = 0.
k→∞
```

Furthermore, we show, in Lemma 14.9, that the detection delay of the randomized scheduling, D_wsn, increases as the value of k increases. In other words, the detection delay D_wsn increases when the WSN is divided into a quite large number of sub-networks k. Indeed, the allocated time slot for each subset would be small, so that the active nodes do not have enough time to detect the occurring intrusion.

### Lemma 14.9

```
⊢ ∀ p q n s L Ts. (1 ≤ n) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts) ∧
(0 < q < 1)
⇒ (mono_incr (λk. real (D_wsn p D n k q))).
```

It is important to note that the original proof of the above lemma in was missing a whole fraction term, which is fortunately positive and thus does not finally affect the validity of the function monotonicity.

Now, it is possible to confirm, in the following 2 lemmas, the validity of the generic results given in Lemmas 14.7 and 14.8 for our WSN application.

### Lemma 14.10

```
⊢ ∀ p k n s L Ts. (1 ≤ n) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts) ∧
(∀k. L < s (SUC k) x Ts)
⇒ (mono_decr (λk. Pd_surv p n k s L Ts (0.28))).
```

Consequently, for the border monitoring application, increasing k surely saves more energy, but a significant increase in k may induce several sub-networks, which in turns translates to a poor detection probability.

### Lemma 14.11

```
⊢ ∀ p k n s L Ts. (1 ≤ n) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts) ∧
(∀k. L < s (SUC k) x Ts)
⇒ lim (λk. Pd_surv p n k s L Ts (0.28)) = 0.
k→∞
```

Similarly, we check that a significant increase in k leads to larger detection delays, i.e., a poor performance:
