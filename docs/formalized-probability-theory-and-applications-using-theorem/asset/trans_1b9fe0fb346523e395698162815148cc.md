

对于具有时齐性、有限状态空间且一步转移概率为 $\{ p_{ij} \}_{i,j} \in \mathcal{Q}$ 的DTMC，稳态概率被定义为向量 $V_j = \lim_{n \to \infty} p_{ij}^{(n)}$，对所有 $j \in \mathcal{Q}$ 成立。如果对所有 $j \in \mathcal{Q}$，$V_j$ 都存在，则 $V_j$ 被称为该马尔可夫链的静态概率向量。换句话说，$V_j$ 是该DTMC的静态分布，如果它满足：

$$
V_j = \sum_{i \in \Omega} \lim_{n \to \infty} V_i p_{ij}
$$

$$
\sum_{j \in \Omega} V_j = 1
$$

$$
0 \le \lim_{n \to \infty} V_j
$$

这个静态属性可以使用高阶逻辑来验证，如下所示：

### 定理 6.6

```
|- \forall X p s p_0 P_ij.
th_dtmc X p s p_0 P_ij
db_equations (\lambda i. lim prob p {x | X n x = i}) X p s
stationary_dist (\lambda i. lim prob p {x | X n x = i}) X p s
```

上述定理正确性的推理与定理 6.5 类似。

## 6.4 静态过程的形式化

静态过程是分析时间序列中常用的随机过程，是 ergodic 定理的基础。从数学上讲，随机过程 $\{ X_t \}_{t \in T}$ 被称为严格意义下的静态过程，如果对于 $n \ge 1, t_1, t_2, ..., t_n \in T$，随机变量 $X_{t_1}, X_{t_2}, ..., X_{t_n}$ 具有与 $X_{t_1+\tau}, X_{t_2+\tau}, ..., X_{t_n+\tau}$ 相同的联合分布。在离散时间随机过程中，$\tau$ 是自然数。静态过程可以在 HOL4 中形式化如下：

### 定义 6.9

```
|- ∀ X p s .
stationary_proc X p s =
∀ f t w n. random variable (X t) p s ∧
(P ({ ⋂_{k=0}^n { x | X ( w + k ) x = f k } }) =
P ({ ⋂_{k=0}^n { x | X ( t + k ) x = f k } }))
```

其中 f 表示状态序列。
使用此定义，我们可以对变量 t 和 n 进行归纳，以证明静态过程的概率质量函数与时间无关。

### 定理 6.7

```
|- ∀ X p s t n j.
stationary_pmf X p s =>
(prob p ({ x | X n x = j }) = prob ({ x | X t x = j }))
```

然而，静态过程并不是具有静态分布的过程。事实上，DTMC 是静态的当且仅当其初始分布是静态的。该属性已在 HOL4 中从两个不同的角度得到验证；第一个角度是静态 DTMC 对所有状态都具有静态分布。

### 定理 6.8

```
|- ∀ X p s n p_0 P_{ij}.
th_dtmc X p s p_0 P_{ij} => stationary_pmf X p s =>
stationary_dist (λ i. prob p ({ x | X n x = i })) X p s
```

证明步骤与定理 6.5 的证明步骤非常相似。最后一个子目标的证明需要 P { x | X n x = j } = P { x | X (n - 1) x = j }，这可以通过使用定理 6.7 将变量 t 和 n 实例化为 n 和 n - 1 来证明。如果定理 6.8 中的变量 n 被赋值为 0，则通过应用引理 6.1 和定理 6.3 来完成证明，此时静态 DTMC 被认为具有静态初始分布。因此，定理 6.8 表明静态 DTMC 具有静态初始分布。

第二个角度是，如果 DTMC 的初始分布是静态的，那么相应的 DTMC 也是静态的。

### 定理 6.9

```
|- ∀ X p s P_0 P_1j;
th_dtmc X p s P_0 P_1j
stationary_dist (λ i. P { x | X 0 x = i }) X p s =>
stationary_proc X p s
```

该定理的验证主要基于定理 6.1，并涉及对变量 n 的归纳。

## 6.5 二进制通信模型

二进制通信信道（Trivedi, 2002）是具有二进制输入和输出的信道。假设传输信道是有噪声或不完美的，即接收器可能会收到错误的数字。该信道可以建模为具有以下状态转移概率的两状态 DTMC。

Pr { $X_{n+1} = 0 \mid X_n = 0$ } = 1 - a; Pr { $X_{n+1} = 1 \mid X_n = 0$ } = a;

Pr { $X_{n+1} = 0 \mid X_n = 1$ } = b; Pr { $X_{n+1} = 1 \mid X_n = 1$ } = 1 - b

相应的状态图和信道图如图 1 所示。

二进制通信信道在电信理论中被广泛使用，因为更复杂的信道是通过级联多个此类信道来建模的。在图 1 中，变量 $X_{n+1}$ 和 $X_n$ 分别表示离开系统 $(n-1)^{\text{th}}$ 阶段并进入 $n^{\text{th}}$ 阶段的数字。a 和 b 是交叉比特错误概率。由于 $X_n$ 也是随机变量，因此无法确定初始状态，因此 Pr ($X_0 = 0$) 和 Pr ($X_0 = 1$) 不能为 0 或 1。虽然初始分布未知，但 n 步转移概率可以验证为方程 (6.7) 中矩阵的元素。同样，稳态概率可以得出如方程 (6.8) 所示。

### 定义 6.11

|- ∀ a b t i j.
Lt a b t i j =

基于二进制通信信道的描述，可以在 HOL4 中形式化如下：

### 定义 6.12

```
|- ∀ X p a b c d.
BINARY_CHANNEL_MODEL X p a b c d =
th_dtmc X p ([0, 1], [POW [0, 1]]) (Limit c d) (Lt a b) ∧
| 1 - a - b | < 1 ∧ 0 ≤ a ∧ a ≤ 1 ∧ 0 ≤ b ∧ b ≤ 1 ∧
(c + d = 1) ∧ 0 < c ∧ c < 1 ∧ 0 < d ∧ d < 1
```

在这个形式模型中，函数 X 表示时齐 DTMC 中的随机变量，p 表示概率空间，可测状态空间表示为一对 ([0, 1], POW [0, 1])，其中 "0" 和 "1" 包含在状态值集合中，第二个元素 POW [0, 1] 是一个 σ-代数。变量 a、b、c 和 d 是初始分布和转移概率函数的参数。

第一个条件确保信道可以建模为时齐 DTMC，状态空间中有两个状态。Limit c d 和 Lt a b 分别表示一般初始分布和转移概率（分别对应定义 6.3 中矩阵 \(\begin{pmatrix} 1-a & a \\ b & 1-b \end{pmatrix}$ 的 p_g 和 p_g）。接下来的五个条件定义了概率 a 和 b 在 [0, 1] 内的允许区间。需要注意的是，$|1 - a - b| < 1$ 确保 a 和 b 不能同时等于 0 和 1，从而避免零转移概率。其余条件提供了参数 c 和 d 的允许范围，它们是概率，不能为 "0" 或 "1"。
