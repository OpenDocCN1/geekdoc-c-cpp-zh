# Definition 6.9

```
|- ∀ X p s .
stationary_proc X p s =
∀ f t w n. random variable (X t) p s ∧
(P ({ ⋂_{k=0}^n { x | X ( w + k ) x = f k } }) =
P ({ ⋂_{k=0}^n { x | X ( t + k ) x = f k } }))
```

where f denotes the state sequence.
Using this definition, we can apply induction on variables t and n to prove that
the probability mass function of a stationary process is independent of the time.

# Theorem 6.7

```
|- ∀ X p s t n j.
stationary_pmf X p s =>
(prob p ({ x | X n x = j }) = probb ({ x | X t x = j }))
```

However, a stationary process is not a process with a stationary distribution. In
fact, a DTMC is stationary if and only if its initial distribution is stationary. This
property has been verified in HOL4 from two different perspectives; the first one
being that a stationary DTMC has Stationary Distribution for all the states

# Theorem 6.8

```
|- ∀ X p s n p_0 P_{ij}.
th_dtmc X p s p_0 P_{ij} => stationary_pmf X p s =>
stationary_dist (λ i. prob p ({ x | X n x = i })) X p s
```

The proof steps are very similar to the ones for Theorem 6.5. The proof of the
last subgoal requires P { x | X n x = j } = P { x | X (n - l) x = j }, which can be
proved by instantiating the variable t and n to be n and n - l using Theorem 6.7.
The proof is finalized by applying Lemma 6.1 and Theorem 6.3 if the variable n
in Theorem 6.8 is assigned a value 0 then the stationary DTMC is said to have a
stationary initial distribution. Thus, Theorem 6.8 shows that a stationary DTMC
has stationary initial distributions.

The second perspective is that if the initial distributions of a DTMC are station-
ary then the corresponding DTMC is stationary as well.
