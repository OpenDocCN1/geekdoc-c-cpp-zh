## 8.3 证明自动化

虽然 HMM 的分析基于交互式定理证明，但尝试自动化此类计算似乎是自然而然的。这在实践中非常有用，因为人们总是有兴趣将定理应用于具体情况。在本节中，我们将描述如何使用定理 8.2 和定理 8.3 的结果，为给定的 HMM 自动获取有趣的概率并找到最佳状态路径。这使得即使是对逻辑或定理证明一无所知的用户也能使用定理证明的准确性。

为了自动化与定理 8.1 相关的计算，我们定义了一个 Standard ML (SML) 函数 hmm_joint_distribution (ini_dist trans_dist e_dist sts obs)，它以初始分布、转移概率、发射分布、状态列表和观测列表作为输入。调用此函数时，这些参数将分别自动替换为定理 8.1 中的 p0、p、pxy stx 和 sts。然后我们取 t 为 sts 的长度（这应该与 obs 相同）：这似乎是实践中最常见的情况，但如果需要，可以通过向函数添加参数来轻松放宽这一限制。然后我们可以使用 HOL4 中关于列表、实数等的定理，以精确方式（作为分数）计算定理 8.1 中方程的右侧。最后，该函数返回一个 HOL4 定理的相应实例化，该定理陈述了联合概率及其值之间的相等性。请注意，结果确实是一个 HOL4 定理：即使是实数之间的乘法或加法等运算也是通过演绎推理获得的，从而使计算的每个步骤都完全可靠且可追溯。为方便起见，结果也可以（在 HOL4 之外）转换为 SML 浮点值，以便与仿真工具生成的结果进行比较。

函数 hmm_joint_distribution 的实现需要开发一个中间引理，其中定义了一些函数，用于对定理 8.1 中的变量进行参数化，并通过 SML 输出 HOL4 给出的结果。

与定理 8.3 相关的计算也可以以类似的方式自动化。要自动获得最佳路径，我们需要计算所有可能状态路径的集合，像函数 hmm_joint_distribution 那样计算每条路径的概率，然后返回具有最高联合概率的路径。为了尽可能准确，所有这些计算都应在 HOL4 内完成。这可以通过 SML 函数 best_path (ini_dist trans_dist e_dist st_ty obs) 来实现，其中 ini_dist、trans_dist、e_dist、obs 表示与 hmm_joint_distribution 相同的对象，而 st_ty 表示表示状态的术语的类型。该类型应为非递归枚举类型，即定义为 C1 | C2 | .... Ck，其中 C1,..., Ck 是无参数的构造函数；这确保了状态空间是有限的。然后该函数负责计算所有可能路径的列表，接着像 hmm_joint_distribution 那样计算相应的联合概率，最后，返回具有最佳此类概率的状态路径（请注意，“最佳概率”的概念也是通过使用实数序的公理定义在 HOL4 内定义的）。

由于计算所有可能状态路径的集合，该函数目前非常慢，但有很大的改进空间，特别是通过过滤那些平凡地具有零概率的路径。这可以通过证明一个定理来完成，该定理与定理 8.3 非常相似，但可能的状态路径集不包括包含零转移概率或零发射概率的路径，例如，

```
L = { L | EVERY (λ x. x ∈ space s_x) L ∧ (| L | = n + 1) ∧
(∀ x y k. x ∈ space s_x ∧ y ∈ space s_y →
P (| x | X (k + 1) x = EL (k + 1) sts_x |
( x | X k x = EL k sts_x )) > 0 ∧
P (| x | Y k x = EL k sts_x ) |
( x | X k x = EL k sts_x )) > 0 ) } .
```

对于包含任何零转移概率或发射概率的应用，通过应用一个与定理 8.3 类似但 L 不同的定理，计算负载将显著减少。

我们现在通过在下一节中提供 DNA 模型 HMM 的形式分析，来展示如何在实践中应用这些定理和函数。

## 8.4 应用：DNA 序列分析

DNA 序列分析在构建基因图谱、发现新物种以及调查遗传连锁、亲子鉴定和刑事调查中的疾病表现方面起着至关重要的作用。统计方法主要用于分析 DNA 序列。特别是，获得底层 DNA 片段的状态路径概率是识别特定 DNA 序列的最关键步骤。

DNA 片段是一系列称为 A、T、G 和 C 的蛋白质的序列。然而，并非每个序列都代表有效的 DNA：在可能的序列中可以发现一些规律。例如，序列开头可能四种蛋白质都以相同概率出现，但在某个特定点之后，只有 A 和 G 可以出现，然后四种蛋白质又可以全部出现，但 A 和 C 的概率更高。因此，在此应用中，DNA 有三种不同的“状态”，其特征是每个碱基出现的概率。在这个 DNA 模型中，第一个状态称为外显子 (E)，第二个称为 5' 剪接位点 (5)，第三个称为内含子 (I)。该模型使用 HMM 非常自然地描述：使用 E、5 和 I 状态上的 DTMC 来了解蛋白质处于哪个状态，然后定义另一个随机过程，该过程根据蛋白质所处的状态来表征 A、G、T 或 C 的发射。这在图 1 中总结。
