# 13.2.2 Formalization of the Network Coverage Intensity

In a wireless sensor network, we say that a given point of the monitored area is covered, if a randomly occurring event at this point, is detected by at least one active node with a given probability. Each point of the monitored area is hence characterized by a coverage intensity, whereas the coverage behavior of the whole network is the average among all the nodes. The network coverage is thus a widely used performance metric. In what follows, we are first interested in formally analyzing the coverage intensity of a point in the monitored area, which we build upon to develop the higher-order-logic formalization of the network coverage.

Let us denote by S; the set of sensors that cover a specific point inside the field, with a cardinality c. When the randomized scheduling of nodes is applied to the set S, it will randomly assign each sensor node to one of the k disjoint subsets (Xiao et al, 2009). Consequently, during a given time slot T, a point is covered if the current active subset contains at least one node, i.e., it is not empty. Nevertheless, as we discussed previously, due to the random feature of the nodes scheduling, it may happen that a subset is completely empty. Note that the term "empty", used here, refers to a subset empty of covering nodes since the randomized scheduling is now applied to the set S. The coverage intensity of a point in the monitored area, denoted by Cp, is defined as the average time during which the point is covered in a whole scheduling cycle of length k x T. Such metric thus depends on the non-empty subsets within a whole scheduling cycle. The coverage intensity of a given point in the monitored area, Cp, is mathematically specified as

