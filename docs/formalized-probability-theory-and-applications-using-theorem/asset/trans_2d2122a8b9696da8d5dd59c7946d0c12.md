

## 内存竞争问题的形式化

要正式分析该系统的属性，我们首先在 HOL 中描述这个多处理器系统。如图 5 所示，这类系统可以描述为具有非周期性和不可约 DTMC 的 DMRM。首先，我们将请求的状态空间定义为 HOL 中的一般函数。

### 定义 7.17

```
\vdash \forall n. request n = (\{r:real\} | r \in [0, n] )
\vdash \forall n. request\_space n = (request n, POW (request n))
```

其中变量 n 指系统中的内存模块数量，POW (request n) 是请求集的 σ-代数。对于双处理器系统，在一个内存周期内最多可产生两个请求，因此 n = 2。

现在，系统状态空间和转移概率可以正式表示如下：

### 定义 7.18

```
\vdash sys\_state = \{ (0, 2); (2, 0); (1, 1) \}
\vdash sys\_space = (sys\_state, POW sys\_state)
\vdash \forall q1 q2 t i j. Lt q1 q2 t i j = case (i, j) of
((1, 1), (1, 1)) -> 2q1q2 | ((0, 2), (1, 1)) -> q1 |
((2, 0), (1, 1)) -> q2 | ((1, 1), (0, 2)) -> q22 |
((0, 2), (0, 2)) -> q2 | ((2, 0), (2, 0)) -> q1 |
((1, 1), (2, 0)) -> q21 | (\_, \_) -> 0
```

其中 sys_space 是一对，第一个元素是集合 sys_state，第二个元素是 sys_state 的 σ-代数，函数 Lt 返回转移概率。

### 定义 7.19

```
\vdash \forall t i j. rewards t (i, j) =
if (i, j) = (1, 1) then 2 else
if (i, j) = (2, 0) then 1 else
if (i, j) = (0, 2) then 1 else 0
```

这些函数现在可用于如下建模图 5 的多处理器系统：

### 定义 7.20

```
/\ Y X q p1 q2 p0 =
th_dmmr X Y q p sys_space (request_space 2) p0 (lt q1 q2) rewards /\
Aperiodic_DTMC X p sys_space p0 (lt q1 q2) /\
Irreducible_DTMC X p sys_space p0 (lt q1 q2) /\
0 < q1 /\ 0 < q2 /\ q1 < 1 /\ q2 < 1 /\ (q1 + q2 = 1)
```

其中变量 X 表示离散时间点上的系统状态（包含每个内存模块请求数的对），变量 Y 指请求，是一个随机变量，p 表示概率空间，q1 和 q2 是前面描述的转移概率中的参数，函数 p0 表示一般初始分布，请求状态空间是 request space，系统状态空间是 sys_space。

## 内存竞争的性能分析

由于模型中的底层 DTMC 是非周期且不可约的 DTMC，我们可以直接应用上述结果来证明，对于系统状态空间中的所有状态，概率分布在长期内收敛，如下所示：

### 定理 7.20

```
/\ Y X q p1 q2 p0 i.
opera_sys_model X Y q p1 q2 p0 /\ i \in space sys_space =>
convergent (\lambda t. P {x | X t x = i })
```

接下来，我们得到稳态概率（状态空间中所有状态的概率质量函数的极限）如下：

### 定理 7.21

```
/\ Y X q p1 q2 p0.
opera_sys_model X Y q p1 q2 p0 =>
lim ... P {x | X t x = (2, 0) } = q_1^3 / (1 - 2q_1q_2) /\
lim ... P {x | X t x = (0, 2) } = q_2^3 / (1 - 2q_1q_2) /\
lim ... P {x | X t x = (1, 1) } = q_1q_2 / (1 - 2q_1q_2)
```

利用期望的形式化，我们可以证明在稳态下每个内存周期完成的内存请求数的期望。

### 定理 7.22

```
|- ∀ X Y p q1 q2 p0. opera_sys_model X Y p q1 q2 p0 =>
Lim ... (λ t. xpec (Y t) p request_space) = (1 - q1 q2) / (1 - 2q1 q2)
```

上述结果对优化系统设计非常重要。例如，我们可以从定理 14 中得到完成请求期望的最大值，并找出达到最佳效率的条件（q1 = q2 = 1 / 2）。同样，当 q1 = 0.97 且 q2 = 0.03 时，我们可以得到稳态概率 lim ... P { x | X t x= (0, 2) } = 2.8669e-5，然而，像 Matlab 这样的经典模拟器，由于加速收敛速度的底层算法和中间步骤中的舍入误差，计算得到 lim ... P { x | X t x= (0, 2) } = 0。此外，由于舍入误差或收敛速度慢，这些算法永远无法提供正的转移概率矩阵。我们的方法可以克服所有这些问题并提供准确结果。

我们对 DMRM 的一般定义提供了将状态描述为任意类型的灵活性，例如本应用中的对，而不是抽象的非负整数。另一方面，本应用说明了使用定理证明正式分析分布式系统的一种方法。需要注意的是，系统可能更复杂（即处理器和内存模块的数量可能非常大），我们可以通过定义新函数（如 sys_space、request_space、Lt 和 rewards）来分析它。

用于建模和验证多处理器（两个处理器和两个内存模块）中内存竞争属性的证明脚本大约有 700 行长。能够正式验证涉及 DMRM 的定理以及简短的脚本清楚地表明了基础形式化的有用性，因为如果没有它们，推理就无法以如此直接的方式完成。

## 7.5 结论

本章首先在高阶逻辑中给出了首通过时间的正式定义。基于此形式化，引入了一系列分类状态，包括瞬态、持续态和持续零态，以及非零持续态。通过引入集合最大公约数（gcd）的形式化，在 HOL 中正式定义了周期态和非周期态。我们还介绍了通信态和吸收态的高阶逻辑形式化。在此定义基础上，我们形式化了许多最常见的分类 DTMC。这些概念主要出现在可达性分析或长期行为分析中。

为了便于 DTMC 模型的概率分析，我们验证了非周期和不可约 DTMC 的最重要属性，这些属性可以在大多数教科书中找到，并且在实际应用中经常使用。这些属性（高阶逻辑中的定理）代表了分类 DTMC 的基础，使得可以推导出分类 DTMC 的更多有趣属性。此外，由于非周期和不可约 DTMC 属于 ergodic 系统的特殊类，这些定理在 ergodic 理论中也经常使用。此外，DTMC 的 ergodicity 属性、正规 DTMC 和吸收 DTMC 的属性可以通过应用它们的定义和本章介绍的定理来验证。

本章介绍的应用表明，DTMC 和分类 DTMC 的形式化在使用定理证明技术分析马尔可夫模型方面非常有用。事实上，这些形式化促进了形式验证领域多种新研究方向的正式分析，例如在高阶逻辑中对隐马尔可夫模型（HMM）的正式分析，可应用于 DNA 序列识别。我们将在下一章中介绍 HMM 的形式化及其重要属性的验证，以及在 HOL 中的 DNA 序列分析。

## 关键术语和定义

- **吸收态：** 系统一旦进入吸收态就无法离开。
- **生死过程：** 生死过程是一种具有出生和死亡的连续时间马尔可夫链（CTMC），即状态转移分别使状态变量的值增加 1 或减少 1。
- **周期态：** 周期态是指只能在某些预定的时间周期内被访问的状态。
- **重现态：** 在未来始终保证会被重新访问的 DTMC 状态称为重现态。
- **瞬态：** 瞬态是指未来某个时间后返回不确定的状态。
