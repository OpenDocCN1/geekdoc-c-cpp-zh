# Definition 12.18

```
|- ∀ p X l. exp_dist p X l = ∀ x. (CDF p X x = if 0 ≤ x then 1

```

The predicate exp_dist ensures that the random variable X exhibits the CDF of an exponential random variable in probability space p with failure rate l. We classify a list of exponentially distributed random variables based on this definition as follows:

# Definition 12.19

```
|- ∀ p L. list_exp [ ] L = T ∧
∀ p h t L. list_exp p (h::t) L =
exp_dist p (HD L) h ∧ list_exp p t (TL L)
```

The list exp function accepts a list of failure rates, a list of random variables L and a probability space p. It guarantees that all elements of the list L are exponentially distributed with corresponding failure rates given in the other list within the probability space p. For this purpose, it utilizes the list functions HD and TL, which return the head and tail of a list, respectively.
