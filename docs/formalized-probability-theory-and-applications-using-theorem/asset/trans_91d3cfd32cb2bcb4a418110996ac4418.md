
随机变量的特性，这些特性用于构建系统的随机模型。随机变量 X 的概率分布可以由其累积分布函数（CDF）唯一描述，CDF 定义为

```
F_X(x) = \text{Pr}(X \le x)
```

对于任意数字 x，其中 Pr 表示概率函数。CDF 还允许我们区分离散随机变量和连续随机变量。离散随机变量的 CDF 总是由一系列有限跳跃组成，而对于连续随机变量，它则具有平滑的连续图形。

除了 CDF 之外，另一种对离散随机变量有用的分布函数是它们的概率质量函数（PMF），它提供了随机变量 X 正好等于某个值 x 的概率。

```
p_X(x) = \text{Pr}(X = x)
```

连续随机变量的 PMF 始终为 0。因此，另一种概率分布特性，即概率密度函数（PDF），它表示 CDF 的斜率，常被用于表征连续随机变量。

```
f_X(x) = \frac{dF_X(x)}{dx}
```

## 1.4 统计特性

统计特性允许我们将随机变量的行为总结为一个单一数字，而不是分布函数，从而为从各种概率分析结果中选择最合适的解决方案提供了非常有用的标准。最广泛使用的统计特性是期望，对于随机变量 X，其定义如下：

```
E_X[X] = \begin{cases} \sum_i x_i p_x(x_i), & \text{if } X \text{ is discrete}; \\ \int_{-\infty}^{+\infty} x f_x(x) dx, & \text{if } X \text{ is continuous.} \end{cases}
```

其中 $\sum_i$ 表示对随机变量 X 的所有可能取值求和。另一种密切相关的统计特性是随机变量 X 的 n 阶矩，基本上是随机变量 X^n 的期望值。因此，随机变量的期望和第一阶矩表示随机变量的相同统计特性。随机变量的另一种有用统计特性是其离平均值或典型值的离散程度。

最广泛使用的离散程度衡量指标是标准差和方差。随机变量 X 的方差描述了 X 与其期望值之间的差异。

```
Var[X] = \sigma_x^2 = \begin{cases} \sum_i (x_i - E_x[X])^2 p_x(x_i), & \text{if } X \text{ is discrete}; \\ \int_{-\infty}^{\infty} (x - E_x[X])^2 f_X(x) dx, & \text{if } X \text{ is continuous.} \end{cases} \quad (1.5)
```

方差的平方根（始终为正数）称为标准差；它很有用，因为它与 X 具有相同的单位，因此可以直接与期望值进行比较。基于随机变量的期望和方差特性，我们可以找到尾分布的界限，即随机变量取远离其期望值的值的概率。这些界限通常使用马可夫不等式或切比雪夫不等式来计算。马可夫不等式给出了非负随机变量 X 大于或等于某个正常数的概率的上界。

```
\text{Pr}(X \ge a) \le \frac{E_X[X]}{a} \quad (1.6)
```

马可夫不等式仅使用随机变量的期望，为非负随机变量提供了可能的最佳尾界。切比雪夫不等式通过使用随机变量的方差，提供了比马可夫不等式显著更强的尾界：

```
\text{Pr}(|X - E_X[X]| \ge a) \le \frac{Var[X]}{a^2} \quad (1.7)
```

由于对失效概率的广泛关注以及尾分布界限计算的简便性，马可夫和切比雪夫不等式现在已成为现代概率分析的核心技术之一。

## 1.5 传统概率分析方法

传统上，概率分析是使用纸笔证明技术进行的。这里的主要思想是在纸上开发给定系统的随机模型，然后使用数学推理在纸上推导所需的概率和统计特性。然而，这种方法无法应对当今工程和科学系统的复杂性。这一事实导致使用计算机进行概率分析。如今，仿真（Ross, 2002）已成为最常用的基于计算机的概率分析技术。此类仿真包通常包含大量离散和绝对连续的一元及多元分布集合，进而可用于建模具有随机或不可预测组件的系统。然后使用基于计算机的技术（如蒙特卡洛方法（MacKay, 1998））对这些模型进行分析，其主要思想是通过分析大量样本来近似回答概率查询。然后可以基于采样过程中收集的数据，在计算机中利用其数学关系计算期望、方差和尾分布界限等统计量。使用仿真技术进行的概率和统计分析基于某些近似，有时可能相当不可靠。不同软件包针对同一概率分析问题得出不同解决方案的情况很常见。这种差异的三个主要原因如下：

- 基于仿真的软件包中的随机性来源通常是伪随机数；这些数字看起来是随机的，但实际上是随机数生成器（RNG）的输出，RNG 基本上是一个确定性算法。RNG 的周期，即在开始重复之前可以对 RNG 进行调用的次数，严重影响概率或统计软件包结果的准确性。
- 在大多数基于仿真的软件包中，为任意概率分布生成非均匀随机数所需的 CPU 时间是一个主要问题。因此，使用各种算法对概率分布求值的函数进行近似，这些算法主要牺牲准确性以换取更快的计算。

## 概率分析

- 像所有其他基于计算机算术的计算一样，舍入误差和截断误差也会渗入这些基于仿真的软件包中的数值计算。这些错误的主要原因是计算机中数字的有限精度表示。

为了进一步说明上述近似问题，请考虑 MATLAB 统计工具箱中 rand 函数的示例，MATLAB 是概率分析中广泛使用的仿真环境之一。它通过生成一个由 64 位表示的伪随机双精度浮点数来近似标准均匀 [0,1] 随机变量（Yates & Goodman, 2005）。因此，rand 能够生成的唯一双精度浮点数不超过 2^64 个，而真正的标准均匀随机变量在区间 [0,1] 中可以产生不可数无限的实数。如果我们考虑由 MATLAB 中的 rand 函数生成的两个标准均匀随机变量的乘积，则会引入额外的近似。乘积结果可能长达 128 位，但由于有限位精度，该值使用各种舍入或截断技术以 64 位表示。除了结果的不准确之外，基于仿真的概率分析的另一大局限是为获得有意义的估计所需的巨大 CPU 时间。这种方法通常需要数十万次仿真来计算概率量，当每个仿真步骤涉及大量计算时，就会变得不切实际。

计算机代数系统（Grozin, 2013），如 Maple 和 Mathematica，提供了一个任意精度数值引擎，主要通过增加计算过程中保留的位数，并将实数转换为相应的有理数来实现。由于这一特性，计算机代数系统中可用的概率分析包（如可在 Mathematica 中使用的 MathStatica（Rose & Smith, 2002））提供的结果比仿真更准确。然而，根据计算的一般规则，即速度和准确性之间始终存在权衡，因此基于计算机代数系统的概率分析往往非常缓慢，不适用于分析现实世界系统。

由于这些系统在医学、交通和军事等安全和任务关键领域被广泛使用，工程和科学系统分析结果的准确性当前已变得至关重要。因此，上述传统技术不能用于此类系统的分析。迫切需要一种高效的概率分析技术，它能够具有基于纸笔的数学证明的精度，因此不依赖于计算机算术，
