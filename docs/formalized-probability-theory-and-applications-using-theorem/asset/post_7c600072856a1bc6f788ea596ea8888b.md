
## 6.2 FORMAL VERIFICATION DTMC PROPERTIES

### 6.2.1 Joint Probability Theorem

A joint probability distribution of n discrete random variables $X_0, X_n$ in a finite DTMC $\{X_t\}_{t \in S}$ satisfies

Pr (Xt = L0, ..., Xt+n = Ln) = \prod_{k=0}^{n-1} (Pr (Xt+k+1 = Lk+1 | Xt+k = Lk)) Pr (Xt = L0) (6.3)

The joint probability distribution of a DTMC is the probability of a chain of states to occur. It is very useful in analyzing multi-stage experiments, especially, the stationary process which is defined on the joint probability distribution. The joint probability distribution is also used to analyze the reversibility of a Markov chain. Moreover, this concept is the basis for the joint probability generating function, which is used in many different fields. This property has been verified in HOL4 as:

```
**Theorem 6.1**
|- ∀ X p s t L P0 P1s.
dtmc X p s P0 P1s =>
prob p (\bigcap_{k=0}^{n} {x | X (t + k) x = EL k L} =
(PROB (0, n) (\lambda k. prob p ({x | X (t + k + 1) x = EL (k + 1) L} |
{x | X (t + k) x = EL k L})))
prob p {x | X t x = EL 0 L }
```

The proof of the above theorem is based on induction on the variable n. Using some set and real arithmetic reasoning can easily verify the base case. Whereas the step case is verified by first rewriting P (\bigcap_{k=0}^{n} {x | X (t + k) x = EL k L}) as P (

\bigcap_{k=0}^{n} {x | X (t + k) x = EL k L} \cap {x | X (t + n + 1) x = EL (n + 1) L }

and thus using the properties of conditional probabilities, verified in the previous chapter.

### 6.2.2 Chapman-Kolmogorov Equation

For a finite time homogeneous DTMC $\{ X_t \}_{t \in \sigma^+}$, its transition probabilities satisfy the Chapman-Kolmogorov Equation

$P_{ij}^{(m+n)} = \sum_{k \in S} P_{ik}^{(m)} P_{kj}^{(n)}$ (6.4)

The Chapman-Kolmogorov equation is a widely used property of time homogeneous DTMCs. It gives the probability of going from state $i$ to $j$ in $m+n$ steps. Assuming the first $m$ steps take the system from state $i$ to some intermediate state $k$ and the remaining $n$ steps then take the system from state $k$ to $j$, we can obtain desired probability by adding the probabilities associated with all the intermediate steps.

### Theorem 6.2

```
|- ∀ X p s i j t m n P₀ Pᵢⱼ.
th_dtmc X p s P₀ Pᵢⱼ ⇒
(Trans X p s t (m + n) i j =
SIGMA (IMAGE (λ k. Trans X p s t m i k * Trans X p s t n k j)
(k ∈ space s)))
```

The above is again verified using induction on the variables m and n. Both of the base and step cases are discharged using the following multistep transition probability lemma.

### Lemma 6.2

```
|- ∀ X p s i j t m P₀ Pᵢⱼ.
th_dtmc X p s P₀ Pᵢⱼ ⇒
(Trans X p s t (m + 1) i j =
SIGMA (IMAGE (λ k. Trans X p s t 1 k j * Trans X p s t m i k)
(k ∈ space s)))
```

which gives the m step transition probability $P_{ij}^{(m)} = \sum_{k \in S} P_{ik}^{(m)} P_{kj}$. The proof of Lemma 6.2 is primarily based on the additivity property of probabilities.

In a time-homogeneous DTMC, n-step transition probabilities $p_{ij}^{(n)}$ are independent of time. This can be proved as:

### Lemma 6.3

```
|- ∀ X p s i j t m n P_i P_j.
th_dtmc X p s p0 pi ⇒
(Trans X p s m t i j = Trans X p s n t i j)
```

The proof of the above lemma is based on induction on variable t. This lemma is going to be utilized later in this chapter to many other theorems.

### 6.2.3 Absolute Probability

In a finite time homogeneous DTMC, the absolute probabilities \(P_j^{(n)}\) satisfy \(P_j^{(n)} = Pr(X_n = j) = \sum_{k \in \Omega} Pr(X_0 = k) Pr(X_n = j | X_0 = k)\)

The unconditional probabilities associated with a Markov chain are called absolute probabilities, which can be computed by applying the initial distributions and n-step transition probabilities. This shows that, given an initial probability distribution and the n-step transition probabilities, the absolute probability in the state j after n steps from the start time 0 can be obtained by using this equation.

This property is formally verified as:

### Theorem 6.3

```
|- ∀ X p s j n P_i P_j.
th_dtmc X p s p0 pi ⇒
(prob p { x | X n x = j } =
SIGMA (IMAGE (\k. P { x | X 0 x = k }
prob p { ( x | X n x = j ) | ( x | X 0 x = k ) }) (k \in space s)))
```

The proof of Theorem 6.3 is based on the Total Probability theorem along with some basic arithmetic and probability theoretic reasoning.

### 6.2.4 Reversibility Property

A stochastic process \(\{ X_t \}_{t \ge 0}\) is said to be reversible if the joint probability of the sequence \(X_{t_0} X_{t_1} .... X_{t_n}\) is the same as the distribution of \(X_{t_n} X_{t_{n-1}} .... X_{t_0}\) that is: \(Pr \{ X_{t_1} = x'_{t_1}, ..., X_{t_n} = x'_{t_n} \} = Pr \{ X_{t_1} = x'_{t_n}, ..., X_{t_n} = x'_{t_1} \}\).

This reversible stochastic process can be defined in HOL4 as follows:

### Definition 6.5

```
⊢ ∀ X p s L t.
Reversible_proc X p s = (prob p (⋂ {k=0}^{|L|-1} {Xt+k = EL k L }))
= prob p (⋂ {k=0}^{|L|-1} {Xt+k = EL k (REVERSE L) }))
```

where |L| represents the length of the chain considered.

In Markov chain theory, certain Markov chains satisfy the Detailed Balance Equations, which ensures that this Markov chain has an equilibrium distribution. This kind of Markov chain exhibits a reversibility feature and is called reversible Markov chain. Mathematically, the detailed balance equations are expressed as

π (i) P_ij = π (j) P_ji ∀ i,j ∈ Ω (6.5)

where the π(i) and π(j) are the equilibrium probabilities of being states i and j. The detailed balance equations can be formalized as:

### Definition 6.6

```
⊢ ∀ f X p s. db_equations f X p s =
∀ i j t. (f i * Trans X p s t 1 i j = f j * Trans X p s t 1 j i)
```

The function f represents the probability distribution π in Equation (6.5). Note that if i or j is not in state space, then it can imply both of the transition probabilities P_ij and P_ji, corresponding to Trans X p s t 1 i j and Trans X p s t 1 j i, respectively, equal to zero and thus both sides of the Equation (6.5) are zeroes.

A Markov chain is defined as reversible Markov chain if it satisfies the Detailed Balance Equations. The formal definition in HOL4 is:

### Definition 6.7

```
⊢ ∀ X p s P_0 P_1j.
rmc X p s P_0 P_1j =
th_dtmc X p s P_0 P_1j ∀ t. db_equations (λ i. prob p {X_t = i })
X p s
```

The following property of the reversible Markov chain has been verified in HOL.

### Theorem 6.4

```
|- ∀ X p s p₁ Pᵢⱼ t L.
rmc X p s p₁ Pᵢⱼ ==>
(prob p ( ⋂_{k=0}^{|L|-1} { Xt+k = EL k L } ) = prob p (
⋂_{k=0}^{|L|-1} { Xt+k = EL k (REVERSE L ) }))
```

The backward proof of this theorem involves rewriting the goal by using Definition 6.7 and Theorem 6.1, which generates the following subgoal:

```
PROD (0, | L |)
( λ k. P ( ( t + k + 1) x = EL ( k + 1) (REVERSE L ) ) |
( x | X (t + k) x = EL k (REVERSE L ) )) =
PROD (0, | L |)
( λ k. prob p ({ x | X (t + k + 1) x = EL ( | L | - k - 1) L } |
{ x | X (t + k) x = EL ( | L | - k) L })))
```

Now, the proof can be completed by applying the following lemma:

```
|- ∀ f n. PROD (0, n) (λ k. f k) = PROD (0, n) (λ k. f (n - k - 1))
```

which corresponds to the mathematical expression:

```
∏_{k=0}^n f(k) = ∏_{k=0}^n f(n-k-1) (6.6)
```

## 6.3 FORMALIZATION OF STATIONARY DISTRIBUTIONS

It is often the case that we are interested in the probability of some specific states as time tends to infinity under certain conditions. This is the main reason why stationary behaviors of stochastic processes are frequently analyzed in engineering and scientific domains.

Let {X_t}_{t>=0} be a Markov chain having state space and transition probabilities/ p_ij ... if (i, j) ∈ Ω, are nonnegative numbers summing to one, then π(j) = Σ_{i∈Ω} π(i) pij is called a stationary distribution. The corresponding HOL4 definition is as follows:

### Definition 6.8

|- ∀ f X p s .
Stationary_dist f X p s =
(SIGMA (\l k. f k) (k \in space s) = 1) /\
∀ i. i \in space s ==>
0 <= f i /\ (∀ t. f i t = SIGMA (\l k. f k * Trans X p s t 1 k i)
(k \in space s))

We then utilize this definition to prove the generalized stationary theorem, which says that if a DTMC with finite state space \(\Omega\) and one-step transition probability \(P_{ij}\) has a probability distribution \(\pi\) that satisfies the detailed balance equations, then there exists a stationary distribution for this DTMC.

### Theorem 6.5

|- ∀ X p s p0 pij n.
th_dtmc X p s p0 pij /\
db_equations (\l i. prob p { x | X n x = i }) X p s ==>
\exists f. stationary_dist f X p s

where f refers to \(\pi(x)\).
The proof of this property is done using the probability distribution function (
\l i. P { x | X n x = i }) as f, and thus the goal becomes:

|- ∀ X p s p0 pij n.
th_dtmc X p s p0 pij /\
db_equations (\l i.P { x | X n x = i }) X p s ==>
stationary_dist (\l i.P { x | X n x = i }) X p s

This subgoal can be verified by rewriting with the definitions of the detailed balance equations and stationary distribution and splitting it in the following three subgoals, which can be verified based on probability theory foundations.

- 0 <= P { x | X n x = i }
- SIGMA (\l j. P { x | X n x = i } (j \in space s) = 1)
- P { x | X n x = i } =
- SIGMA (\l j. P { x | X n x = j } Trans X p s t j i) (j \in space s)
