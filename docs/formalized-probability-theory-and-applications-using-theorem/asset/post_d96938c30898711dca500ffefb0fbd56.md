
## 12.1 LIFETIME DISTRIBUTIONS

The foremost foundation for reliability analysis of engineering systems (Billinton & Allan, 1992) is lifetime distribution. Various lifetime distribution representations have been used in the literature depending upon the specific needs of a lifetime reliability analysis problem. For example, sometimes the probability of failure is of interest at a certain time (Survival function), whereas, in some other applications, such as in planning for serviceability and maintainability of a system, the total amount of risk associated with a system up to a given time (Cumulative Hazard function) may be required. Two other commonly used important reliability properties are the hazard function and the fractile function. The hazard function expresses the failure risk at a given time and the fractile function allows reasoning about the times of failure corresponding to a given probability of failure. The survival function $S_T(t)$ is defined as:

$S_T(t) = 1 - F_T(t)$ (12.1)

where $F_T(t)$ is the cumulative distribution function of the random variable $T$. The Hazard function, $h_T(t)$, is defined as:

$h_T(t) = \frac{dS_T(t)}{dt} \frac{1}{S_T(t)} = \lim_{h \to 0} \frac{S_T(t) - S_T(t+h)}{h S_T(t)}$ (12.2)

and the cumulative hazard function, $H_T(t)$, is defined as:

$H_T(t) = \int_0^t h_T(\tau) d\tau$ (12.3)

Finally, the pth fractile $t_p(p)$ of a random variable $T$ is defined as:

$t_p(p) = F_T^{-1}(p)$ (12.4)

The main scope of this chapter is the formalization cumulative distribution function and survival function in higher-order-logic and the formal verification of some of their key properties. This formalization can then be utilized to formalize other lifetime distributions or reason about the reliability aspects of engineering systems within the sound core of a theorem prover (Hasan, Tahar, & Abbasi (2014); Abbasi, Hasan & Tahar (2010); Abbasi, Hasan, & Tahar, (2012); Abbasi, (2012); Abbasi, Hasan & Tahar, 2014).

## 12.2 CUMULATIVE DISTRIBUTION FUNCTION

In this section, we present the formal specification of the cumulative distribution function (CDF) and the verification of CDF properties in the HOL4 theorem prover. The CDF and its properties have been an integral part of any reliability analysis as all the lifetime distributions are primarily based on CDF.

Mathematically, the CDF is defined as follows:

$F_x(t) = Pr(T \le t)$ (12.5)

It follows from Equation (12.5) that the CDF can be formally specified in HOL4 by a higher-order-logic function that accepts a random variable as an argument and returns the probability of the event when the given random variable is less than or equal to the value of any given real number. A formalization of the CDF has already been given in Definition 5.6 and we repeat it here:

### Definition 12.1

```
⊢ ∀ p x. CDF p X x = distribution p X { y | y ≤ x }
```

where X represents the random variable, p is the probability space and x is the real argument. Using this formal specification of the CDF, we can verify the classical CDF properties within the HOL4 theorem prover. The formal proofs for these properties not only ensure the correctness of Definition 12.1 but also play a vital role in proving various reliability properties associated with the lifetime distributions.

### 12.2.1 CDF Bounds

According to the CDF bounds property, for any real number x, 0 ≤ F_x(x) ≤ 1. In other words, if we plot the CDF against its real argument x, then the graph of the CDF, F_x, is always going to be between the two horizontal lines y=0 and y=1. This characteristic can be verified in HOL4 using the basic probability law, which states that the probability of an event is always less than 1 and greater than 0.

### Theorem 12.1

```
|- \/ X p x .
prob_space p /\ (events p = POW (p_space p))
==> 0 <= CDF p X /\ CDF p X <= 1
```

### 12.2.2 CDF Is Monotonically Increasing

For any two real numbers a and b, if a < b then F_x(a) <= F_x(b). This property can be expressed in HOL4 as follows:

### Theorem 12.2

```
|- \/ X p a b.
prob_space p /\ (events p = POW (p_space p)) /\
a <= b ==> CDF p X a <= CDF p X b
```

The proof of Theorem 12.2 is based on the principles of set and probability theories.

### 12.2.3 Interval Probability

For any two real numbers a and b, if a < b, then Pr (a < X <= b) = F_x(b) - F_x(a). This property can be expressed in HOL4 as follows:

### Theorem 12.3

```
|- \/ X p a b.
prob_space p /\ (events p = POW (p_space p)) /\
a <= b ==> (distribution p X { y | a < y /\ y <= b } = CDF p X b - CDF p X a)
```

where the function distribution is defined in Definition 5.5. The proof of Theorem 12.3 is again based on some already verified theorems for the set and probability theories.

### 12.2.4 CDF at Positive and Negative Infinity

According to the CDF at positive infinity property, if the argument x of a CDF approaches infinity then the value of the CDF approaches 1, i.e.,

lim_{x->\infty} F_x(x) = 1 (12.6)

This property can be expressed in HOL4 as follows:

### Theorem 12.4

```
|- VX p.
prob_space p ∧ (events p = POW (p_space p)) ∧
(Vy. X y ≠ PosInf) ⇒ (∀n. CDF p n) → 1
```

where (\lambda n. f n) → k represents the limit of a real sequence in HOL, i.e., lim (f) = k when the argument of the function f approaches infinity. The assumption (Vy. X y ≠ PosInf) ensures that the random variable can never acquire an infinite value as without this condition the above property would not hold. The HOL4 proof steps for Theorem 12.4 are based on the continuity property of probability that specifies the relationship between the limit value of the probability of a monotonically increasing sequence of events A_n (i.e., A_i ⊆ A_{i+1}, for every n) and the fact that the probability of the countable union of all events that can be represented as A_∞ is 1. In a similar way, the CDF at negative infinity property can be formally verified as the following theorem:

### Theorem 12.5

```
|- VX p.
prob_space p ∧ (events p = POW (p_space p)) ∧
(Vy. X y ≠ NegInf ∧ X y ≠ PosInf) ⇒ (∀n. CDF p -n) → 0
```

## 12.3 SURVIVAL FUNCTION

The survival function represents the probability that a component is functioning at one particular time t and can be formalized in HOL4 using Equation (12.1) as follows:

### Definition 12.2

```
|- VX p t. survival_function p X t = 1 - CDF p X t
```

Using the above formalization of the survival function, the following existence properties can be formally verified in HOL.

### 12.3.1 Survival Function at Time 0

The probability that a normal component works fine at time 0 is 1. This property can be formally verified as the following theorem in HOL:

### Theorem 12.6

```
|- \forall X p.
prob_space p \land (events p = POW (p_space p)) \land
(Vy. X y # NegInf \land X y # PosInf)\land
((\lambda x. distribution p X {y | y \le Normal x}) contl 0) \land
(Vx. Normal 0 \le X x)
=> (survival_function p X 0 = 1)
```

The assumption ((\lambda x. distribution p X {y | y \le Normal x}) contl 0) \land (Vx. Normal 0 \le X x) ensures that the random variable X is a continuous and positive-valued random variable. These conditions are valid since the random variable has to have the same data type as the real time, which is always continuous and positive. The proof of Theorem 12.6 is based on the properties of CDF and continuous functions.

### 12.3.2 Survival Function Tends to 0

Based on the definition of survival function, and thus its relationship with CDF, it can be observed that the value of survival function would approach 0 as its argument becomes very large. This property can be expressed in HOL4 as follows:

### Theorem 12.7

```
|- \forall X p.
prob_space p \land (events p = POW (p_space p)) \land
(Vy. X y # NegInf \land X y # PosInf) \land
=> (lim (\lambda n. survival_function p X n) = 0)
```

where the function lim (\lambda n. fn) represents the limit of a real sequence, i.e., lim_{n->\infty} f(n).

The proof of the above theorem is based on the properties of limit of real sequence, CDF and some axioms of probability theory.

### 12.3.3 Survival Function Is a Non-Increasing Function

For any two real numbers a and b, if a \le b, then S_X(b) \le S_X(a). This property can be expressed in HOL4 as follows:
