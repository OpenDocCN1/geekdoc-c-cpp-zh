```

DB_MODEL X p a b d n \in p_o \land i + 1 \in [0, n] \land i - 1 \in [0, n] \Rightarrow
```

### 定理 7.13

```
|- \/ X p a b d n i Limit.
DB_MODEL X p a b d n \in Limit. \land i + 1 \in [0, n] \Rightarrow
(lim (\lambda t. prob p { X_t = i + 1 }) =
lim (\lambda t. prob p { X_t = 0 }) * PROD (1, i + 1) (\lambda j. \frac{b_{j-1}}{d_j}))
```

本定理的证明从对变量 n 进行归纳开始。基本情况可以通过定理 7.11 和一些实数算术推理来验证。然后，步骤情况的证明通过应用一个引理来完成，该引理基于 DB_MODEL 证明了以下方程：

$v_{n+1} = \frac{b}{d_{j+1}} v_{n,j}$ (7.5)

该引理的证明主要通过对变量 i 进行归纳来完成。基本情况通过应用定理 7.10 和 7.11 以及一些实数算术推理来验证。步骤情况的证明通过使用定理 7.12 以及一些算术推理来完成。

### 定理 7.14

```
\/ X p a b d n i Limit.
DB_MODEL X p a b d n Limit /\ i + 1 ∈ [0, n]
⇒ (lim (λ t. prob p ( X_t = 0 )) =
\frac{1}{sum (0, n + 1) \left\{ \lambda_i . PROD (1, i + 1) \lambda_j . \frac{b_{j+1}}{d_j} \right\}} )
```

本定理的证明首先将目标改写为 lim (λ t. P { X_t = 0 }) * sum (0, n + 1) (λi. PROD (1, i + 1) (λj. b_{j+1}/d_j)=1。然后，求和可以分为两项：b/d_1 和 sum (1, n + 1) (λi. PROD (1, i + 1) (λj. b_{j+1}/d_j)。证明通过应用定理 7.11、7.13 和概率可加性定理以及一些实数算术推理来完成。

现在，在对上述定理进行验证后，该模型中任何状态的极限概率可以通过实例化参数 n 和转移概率 a、b 和 d 来计算。方程 (7.4a) 和 (7.4b) 所示的解主要用于在长时期内对各种领域（如统计学和生物学）中种群发展的安全属性进行预测。

更具体地说，当状态空间中所有 i 的出生-死亡系数为 b_i = \lambda 和 d_i = \mu（\lambda 和 \mu 为常数）时，定义 7.12 所述的模型代表一个经典 M / M / 1 排队系统（在这种情况下，平均到达间隔时间变为 1/\lambda，平均服务时间为 1 / \mu）。此后，验证过的定理可以直接应用于分析 M / M / 1 排队的遍历性。

本节首先在高阶逻辑中给出首通过时间的形式定义。基于这种形式化，引入了一系列分类状态，包括瞬态、持态和持态零态，以及非零持态。通过引入集合最大公约数（gcd）的形式化，在 HOL 中正式定义了周期态和非周期态。还提供了通信状态和吸收状态的高阶逻辑形式化。基于这些定义，验证了各种常用的分类 DTMC 属性。这些概念主要出现在可达性分析或长期行为分析中。

为了便于对 DTMC 模型进行概率分析，还验证了非周期和不可约 DTMC 的一些常用属性，这些属性可以在大多数教科书中找到，并且在现实世界应用中经常使用。这些属性（高阶逻辑中的定理）代表了分类 DTMC 的基础，使得可以推导出分类 DTMC 的更多有趣属性。此外，由于非周期和不可约 DTMC 属于遍历系统的特殊类，这些定理也经常用于遍历理论。此外，DTMC 的遍历性属性，即正规和吸收 DTMC，可以通过应用在第 7.2 节中给出的定义以及在第 3.3 节中提出的定理来验证。吸收 DTMC 经常应用于建模社会心理学问题。将第 7.2 节中吸收 DTMC 的形式化与矩阵理论相结合，吸收 DTMC 的属性也可以使用高阶逻辑进行正式验证。

## 7.4.3 多处理器系统中的内存竞争

如今，多核处理器与多模块内存广泛应用于高性能计算机。在这种配置中，主要的性能评估指标之一是内存竞争问题及其对整体内存访问时间的影响（Aviztzakh, 1973）。通常，此问题使用仿真或数值方法进行分析。然而，这些方法要么无法保证准确分析，要么由于不可接受的计算时间而无法扩展。作为一种替代方法，我们探讨使用定理证明来分析多处理器系统的内存竞争问题。为此，本节介绍了离散随机变量期望和离散时间马尔可夫奖励模型的高阶逻辑形式化。这些基础随后被用于使用 HOL4 定理证明器分析具有两个处理器和两个内存模块的多处理器系统配置的内存竞争问题。

复杂工程系统的大量计算需求以及向智能消费电子设备转变的趋势，促使向在各种嵌入式系统中使用多核处理器发生了范式转移。这些处理器通常通过访问共享内存空间中的共享变量相互共享信息。为了避免对这些共享变量的并发更新（这可能导致错误结果），同一时间只允许一个处理器访问内存。然而，这种配置导致了众所周知的内存竞争问题，这会导致整体性能下降，因为处理器可能需要等待访问内存。这个问题通常通过使用多模块内存来缓解，如图 4 所示。主要思想是将缓存内存分为子模块，以便处理器可以并行同时访问不同的子模块。这种配置倾向于最大限度地减少内存竞争问题，但无法完全纠正它，因为两个或多个处理器可能想要访问同一个内存子模块。因此，进行严格的性能分析以确定给定内存访问速率下内存子模块的优化大小。

由于时间相关内存访问请求的随机性，上述配置被建模为分类离散时间马尔可夫链（DTMCs）。然后，基于分类马尔可夫链和离散时间马尔可夫奖励模型（DMRMs）的属性，可以推导出诸如平均内存访问次数和处理器等待的稳态概率等性能特征。这些属性以给定马尔可夫链的转移概率表示，从而为系统优化提供有用的洞察。

传统上，上述性能分析是通过分析方法进行的，使用纸笔证明方法、计算机仿真或数值方法。纸笔证明方法在复杂多处理器系统中扩展性不佳。此外，它们容易出现人为错误。基于计算机的仿真或数值方法具有可扩展性，但由于使用计算机算术和伪随机数及其固有的不完整性，无法保证准确结果。

由于多处理器系统在医学和交通等安全关键领域的使用日益增加，上述性能分析的准确性变得非常重要。最近，概率模型检查已被用于分析 DMRMs。典型的模型检查工具是 PRISM 和 MRMC，它们通过使用概率状态机建模随机行为并详尽验证其概率属性来提供精确的系统分析。这些工具也可用于多处理器系统的性能分析。然而，这些模型检查工具中实现的一些算法也基于数值方法。例如，幂方法（一种著名的迭代方法）在 PRISM 中应用于计算马尔可夫链的稳态概率（或极限概率）。因此，模型检查器中分析的大多数稳态属性都是时间有界的。此外，概率模型检查通常使用未经验证的算法和优化技术。最后，模型检查不能用于验证统计属性（如期望）的通用数学表达式。
