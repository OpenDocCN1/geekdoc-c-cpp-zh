
If at least one absorbing state exists in a DTMC and it is possible to go to the absorbing state from every non-absorbing state, then such a DTMC is named as an absorbing DTMC.

### Definition 7.8

```
⊢ ∀ X p s P₀ Pᵢⱼ·
Absorbing_mc X p s P₀ Pᵢⱼ =
th_dtmc X p s P₀ Pᵢⱼ
∃ i. i ∈ space s ∧ Absorbing_state X p s i ∧
(∀ j. j ∈ space s ⇒ Communicating_state X p s i j)
```

Finally, if there exists some n such that pij^(n) > 0 for all states i and j in a DTMC, then this DTMC is defined as a regular DTMC.

### Definition 7.9

```
⊢ ∀ X p s P₀ Pᵢⱼ·
Regular_mc X p s P₀ Pᵢⱼ =
th_dtmc X p s P₀ Pᵢⱼ
∃ n. ∀ i j. i ∈ space s ∧ j ∈ space s ⇒ Trans X p s t n i j > 0
```

The main utility of the higher-order logic formalization of the classified Markov chains mentioned above is to formally specify and analyze the dynamic features of Markovian systems within the sound environment of a theorem prover as will be demonstrated in the following section.

## 7.3 FORMAL VERIFICATION OF LONG-TERM PROPERTIES

The analysis of the long-term behavior of a DTMC is dependent on the type of state under consideration. Among the classified DTMCs formalized in the previous section, aperiodic and irreducible DTMCs are considered to be the most widely used ones in analyzing Markovian systems because of their attractive stationary properties, i.e., their limit probability distributions are independent of the initial distributions. For this reason, we now focus on the verification of some key properties of aperiodic and irreducible DTMCs.

### 7.3.1 Positive Transition Probability

The formalized aperiodicity and irreducibility characteristics of DTMCs can be used to verify their corresponding properties in HOL.

### Theorem 7.1

- **Property:** The set of the times when state $i$ has a non-null probability of being visited is closed under addition in a DTMC.

```
⊢ ∀ X p s P₀ Pᵢⱼ i.
Aperiodic_DTMC X p s P₀ Pᵢⱼ ∧ i ∈ space s ⇒
∀ a b. a ∈ Period_Set X p s i ∧ b ∈ Period_Set X p s i ⇒
(a + b) ∈ Period_Set X p s i
```

### Theorem 7.2

- **Property:** The transition probability $p_{ij}^{(n)}$ is greater than zero, for all states $i$ and $j$ in its state space. For any state $i$ in the finite state space $S$ of an aperiodic DTMC, there exists an $N < \infty$ such that $0 < p_{i,j}^{(n)}$, for all $n \ge N$ and all $i$ in the state space.

```
⊢ ∀ X p s P₀ Pᵢⱼ i t.
Aperiodic_DTMC X p s P₀ Pᵢⱼ ∧ i ∈ space s ⇒
∃ N. ∀ n. N ≤ n ⇒ 0 < Trans X p s t n i i
```

In this theorem, $N$ is of HOL4 datatype num that represents positive integers. Formal reasoning about the correctness of the above theorems involves Theorem 7.1, some DTMC properties and the following three lemma, along with some arithmetic reasoning and set theoretic reasoning.

### Lemma 7.1

- **Positive Element in a Closed Set:** If an integer set $S$ contains at least one nonzero element and $S$ is closed under addition and subtraction, then $S = \{ kc; k \in Z \}$, where $c$ is the least positive element of $S$.

```
⊢ ∀ s:int → bool. s ≠ ∅ ∧
(∀ a b. a ∈ s ∧ b ∈ s ⇒ (a + b) ∈ s ∧ (a - b) ∈ s) ⇒
0 < MINSET { r | 0 < r ∧ r ∈ s } ∧
(s = { r | ∃k. r = k * MINSET { r | 0 < r ∧ r ∈ s } })
```

where MINSET A refers to the minimum element in the set A.

### Lemma 7.2

- **Linearity of Two Integer Sequences**: For a positive integer sequence $a_r, a_2, ..., a_k$, there exists an integer sequence $n_r, n_2, ..., n_k$ such that $d = \sum_{i=1}^k n_i a_i$, where $d$ is the greatest common divisor of sequence $a_r, a_2, ..., a_k$.

```
|- \forall a k. 0 < k \land (\forall i. i \le k \Rightarrow 0 < a i) \Rightarrow (\exists n. GCD\_SET { a i | i \in [0, k] } = \sum_{i=1}^k n i * a i)
```

### Lemma 7.3

- **Least Number**: If a set of positive integers $A$ is non-lattice, i.e., its gcd is 1, and closed under addition, then there exists an integer $N < \infty$ such that $n \in A$ for all $N \le n$.

```
|- \forall A: (int -> bool) a. (A = { a i | 0 < a i \land i \in UNIV :(num) }) \land (GCD\_SET A = 1) \land (\forall a b. a \in A \land b \in A \Rightarrow (a + b) \in A) \Rightarrow (\exists N. { n | N \le n } \subset A)
```

The proofs of Lemmas 7.1, 7.2 and 7.3 are based upon various summation properties of integer sets and the properties of gcd of a set.

- **Property**: For any aperiodic and irreducible DTMC with finite state space $S$, there exists $N$, such that, for all $n \ge N$, the $n$-step transition probability $p_{ij}^{(n)}$ is non-zero, for all states $i, j \in S$.

### Theorem 7.3

```
|- \forall X p s P_0 Pij. \forall i j t. Aperiodic\_DTMC X p s P_0 Pij \land Irreducible\_DTMC X p s P_0 Pij \land i \in space s \land j \in space s \Rightarrow \exists N. \forall n. N \le n \Rightarrow 0 < Trans X p s t n i j
```

The proof of Theorem 7.3 is based on case analysis on the equality of $i$ and $j$ and Lemmas 7.2 and 7.3.

- **Property**: For any aperiodic and irreducible DTMC with finite state space S and transition probabilities \( p_{ij} \), there exists \( \lim_{n \to \infty} p_{ij}^{(n)} \), for all states \( i \) and \( j \in S \).

### Theorem 7.4

```
∀ X p s P₀ Pij i j t.
Aperiodic_DTMC X p s P₀ Pij ∧ Irreducible_DTMC X p s P₀ Pij ⇒
∃ u. lim (λ n. Trans X p s t n i j) = u
```

The proof of Theorem 7.4 is based on the monotonic properties of \( M_j^n \) and \( m_j^n \), which are the maximum and minimum values of the set \( \{n \ge 1: p_{jj}^{(n)} > 0\} \), respectively. Then, the proof is completed by verifying the convergence of the sequence \( (M_j^n, m_j^n) \) for all \( n \) such that \( N \le n \) and some properties of real sequences. It is important to note that we do not need to use the assumption \( j \in space \) here, like all other theorems, as \( \forall n j j \notin space \Rightarrow p_{jj}^{(n)} = 0 \), which in turn implies \( \lim_{n \to \infty} p_{jj}^{(n)} = 0 \) and \( \lim_{n \to \infty} p_{ij}^{(n)} = 0 \) by using the conditional probability properties.

### 7.3.2 Convergence Analysis

The long-run probability distributions are often considered in the convergence analysis of random variables in stochastic systems. It is not very easy to verify that the limit probability distribution of a certain state exists in a generic non-trivial DTMC, because the computations required in such an analysis are often tremendous. However, in the aperiodic and irreducible DTMCs, we can prove that all states possess limiting probability distributions, by the following two properties.

- **Property**: For any aperiodic and irreducible DTMC with finite state space S, there exists \( \lim_{n \to \infty} p_{ij}^{(n)} \), for any state \( i \in S \).

### Theorem 7.5

```
∀ X p s P₀ pij i.
Aperiodic_DTMC X p s P₀ pij ∧ Irreducible_DTMC X p s P₀ pij ⇒
∃ u. lim (λ n. P (x | X n x = i)) = u
```

The proof is based on Theorem 7.4 along with some properties of the limit of a sequence.

- **Property**: For every state \( i \) in an aperiodic and irreducible DTMC, \( \lim_{n \to \infty} p_{i}^{(n)} \) is a stationary distribution.

### Theorem 7.6

```
|- \forall X p s P₀ P_{i,j}.
Aperiodic_DTMC X p s P₀ P_{i,j} \land Irreducible_DTMC X p s P₀ P_{i,j} =>
(stationary_dist p x (i, lim (\lambda n. P (x | X n x = i))) s)
```

The proof of Theorem 7.6 is primarily based on the following three subgoals:

- 0 \le lim_{n \to \infty} p_j^{(n)}
- \sum_{i \in S} lim_{n \to \infty} p_i^{(n)} = 1
- lim_{n \to \infty} p_j^{(n)} = \sum_{i \in S} p_i^{(n)} p_{ij}

The first subgoal can be verified using the probability bounds theorem. The proof of the second subgoal is primarily based on the additivity property of conditional probability. Whereas, the last subgoal can be verified using the linearity properties of limit of a sequence and summation. The scripts, corresponding to all the formalization, presented in this section is available at (Liu, 2013b).
