Another commonly used definition of integrability is verified as a theorem in HOL4.

# Theorem 4.11

```
|- Vm f. measure_space m /\ integrable m f ==>
\<forall> ri.
\<forall>x. mono_increasing (\<lambda> i. fi i x) /\ 
\<forall>x. x \in m_space m ==>
(fn_plus f x = sup (IMAGE (\<lambda> i. fi i x) UNIV)) /\ 
\<forall>i. ri i \in psfis m (fi i) /\ 
\<forall>i x. fi i x \le fn_plus f x /\ 
pos_fn_integral m (fn_plus f) = sup (IMAGE ri UNIV) /\ 
\<exists>gi vi.
\<forall>x. mono_increasing (\<lambda> i. gi i x) /\ 
\<forall>x. x \in m_space m ==>
(fn_minus f x = sup (IMAGE (\<lambda> i. gi i x) UNIV)) /\ 
\<forall>i. vi i \in psfis m (gi i) /\ 
\<forall>i x. gi i x \le fn_minus f x /\ 
pos_fn_integral m (fn_minus f) = sup (IMAGE vi UNIV)
```

This theorem is verified by first showing that the sequence (fj)', defined below, satisfies the conditions of the Lebesgue Monotone Convergence theorem. This sequence is then applied for both f+ and f-.

```
F_n(x) = \sum_{k=0}^{i-1} \frac{k}{2^n} I_{(\frac{k}{2^n} \le f(x) < \frac{k+1}{2^n})} + 2^n I_{(2^n \le f(x))} (4.8)
```

Then the definition of (fj)' is used to verify the following lemmas in HOL:

```
|- \/ n x, 2 ^ n <= f (x) ==> fn (x) = 2 ^ n
|- \/ n x and k < 4^, 2 ^ n <= f (x) < \frac{k+1}{2^n} ==> fn (x) = \frac{k}{2^n}
|- \/ x, (f (x) >= 2 ^ n) \/ (\exists k, k < 4^ and \frac{k}{2^n} <= f (x) < \frac{k+1}{2^n})
```

Using these lemmas, the sequence (fj)' is proved to be point wise convergent to f(\/x. f(x) = sup_n fn(x)), upper bounded by f(\/n x, f_n(x) \le f(x)) and monotonically increasing (\/n x, f_n(x) \le f_n+1(x)).
