The property is verified using the probability additive law along with some set theoretic reasoning.

# 5.4.5 Union Axiom of Conditional Probability

Pr (A1 ∪ A2 | B) = Pr (A1 | B) + Pr (A2 | B) - Pr (A1 ∩ A2 | B) (5.7)

This property allows us to express the probability of an event A1 UA2 (union of the sets A1 and A2) given some other event B without using the notion of union. It can be expressed in higher-order logic, using our conditional probability definition.

# Theorem 5.10

```
|- ∀A1 A2 B p. (prob_space p) ∧ (A1 IN events p) ∧ (A2 IN events p) ∧
events p) ∧ (B IN events p) ⇒
(cond_prob p (A1 UNION A2) B =
(cond_prob p A1 B) + (cond_prob p A2 B) - (cond_prob p (A1 INTER A2) B))
```

The proof is again based on the probability additive law primarily.

# 5.4.6 Multiplication Rule of Probability

Pr (A ∩ B) = Pr (B) Pr (A | B) (5.8)

Sometimes also referred to as the theorem of compound probabilities, the multiplication rule of probabilities is quite often found to be very useful for determining the probability that two events A and B will occur simultaneously. It can be expressed in higher-order logic as follows:

# Theorem 5.11

```
|- ∀p A B. (prob_space p) ∧ (A IN events p) ∧ (B IN events p) ⇒
(prob p (A INTER B) = (prob p B) * (cond_prob p → A B))
```

The proof of the above property is based on the conditional probability definition and the fact that if the probability of event B is 0 then the probability of (A ∩ B) is also 0.
