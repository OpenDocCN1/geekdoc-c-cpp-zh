## 关键术语和定义

条件概率: 条件概率是指在另一事件发生的条件下，某一事件发生的概率。

期望: 期望或期望值是实验的长期平均值。

概率论: 概率论使我们能够对随机现象进行推理。它广泛用于对具有未知元素或大量可能性的系统进行定量分析。

概率: 概率是介于 0 和 1 之间的实数，用于衡量事件发生的可能性，即如果事件必然发生，则其概率为 1。

方差: 方差是衡量实验结果与该实验期望接近程度的指标。它始终是正数。

## 第 6 章

## HOL 中的离散时间马尔可夫链

### 摘要

本章中，作者描述了使用上一章介绍的概率论对离散时间马尔可夫链进行形式化及其最重要属性的形式验证。为了说明这项工作的实用性，在 HOL 中对自动邮件质量测量（AMQM）协议中涉及的二进制通信信道模型和收集过程模型进行了形式分析。

### 6.1 离散时间马尔可夫链的形式化

在给定概率空间的情况下，随机过程 \(\{ X_t : \Omega \to S \}\) 被定义为随机变量 X 的序列，其中 \(t\) 表示时间，可以是离散的（由非负整数表示）或连续的（由实数表示）。每个 \(X_t\) 取值的集合通常称为状态，被称为状态空间。该过程的样本空间由基于给定状态空间 S 的所有可能状态序列组成。现在，基于这些定义，马尔可夫过程可以定义为具有马尔可夫性质的随机过程。如果马尔可夫过程具有有限或可数无限状态空间，则称为马尔可夫链，并满足以下马尔可夫性质：对于状态空间中的 \(0 \le t_0 \le \dots \le t_n\) 和 \(x_0, \dots, x_n\)，则：

Pr \(\{ X_{t_{n+1}} = x_{n+1} | X_t = x_t, \dots, X_0 = x_0 \} = P \{ X_{t_{n+1}} = x_{n+1} | X_t = x_t \}\) (6.1)

该数学方程表明，未来状态 \(X_{t_{n+1}}\) 仅取决于当前状态 \(X_t\)，而与过去状态 \(X_t\) 无关。本章主要关注在有限状态空间中具有离散状态的离散时间马尔可夫链（DTMC）（Bhattacharya & Waymire (1990); Kannan, 1979）。

根据方程 (6.1) 给出的马尔可夫性质，未来状态仅取决于当前状态，而与所有其他过去状态无关（Chung, 1960）。马尔可夫性质可以形式化为（Liu, 2013）：

### 定义 6.1

```
\forall X p s. mc_property X p s =
(\forall t. random_variable (X t) p s) \\
\forall f t n. increasing_seq t (\lambda_k \in \{0..n-1\} | x | X t_k x = f k ) \neq
0 \implies
(prob p ( \{ x | X t_{n+1} x = f (n + 1) \} | \{ x | X t_n x = f n \} \\
\cap_{k \in \{0..n-1\}} ( \{ x | X t_k x = f k \} =
prob p ( \{ x | X t_{n+1} x = f (n + 1) \} | \{ x | X t_n x = f n \} ))
```

其中 increasing_seq t 定义了递增序列的概念，即 \(\forall i j. i < j \Rightarrow t i < t j\)。第一个合取式表明马尔可夫性质基于随机过程 \(\{ X_t : \Omega \to S \}\)。量化变量 X 表示与时间 t 相关的随机变量的函数，具有 HOL4 类型 num 或正整数。这确保该过程是离散时间随机过程。该过程中的随机变量是基于概率空间 p 和可测空间 s 构建的函数。合取式 \( P(\cap_{k \in \{0..n-1\}} \{x | X t_k x = f k\}) \neq 0 \) 确保相应的条件概率定义良好，其中 \( f k \) 返回状态序列的第 \( k^{th} \) 个元素。

我们还必须明确说明所有通常隐含的假设，即状态属于所考虑的空间。假设 \( P(\cap_{k \in s} \{x | X k x = f k\}) \neq 0 \) 确保相应的条件概率定义良好，其中 f k 返回状态序列的第 k 个元素。

在本章中，P { x | X t x = i } 表示 prob p { x | (X t x = i) \(\land\) (x IN p\_space ) }，其中术语 x IN p\_space 确保 x 属于所考虑概率空间 p 的样本空间。同样，条件概率 P { (x | X (t + 1) x = j ) | { x | X t x = i } } 表示 cond\_prob p { (x | (X (t + 1) x = j) \(\land\) (x IN p\_space p) ) | { x | X t x = i } \(\land\) (x IN p\_space p) ) }，基于前一节中提出的形式化。

具有有限状态空间的 DTMC 通常通过指定以下内容来表示：初始分布 p0，它给出了每个状态的初始发生概率 Pr { X0 = s } = p0(s)；以及转移概率 pij(t)，它给出了状态空间中每对状态 i, j 从 i 转移到 j 的概率。对于状态 i, j 和时间 t，转移概率 pij(t) 定义为 Pr { X_{t+1} = j \mid X_t = i }，可以轻松推广为 n 步转移概率。

\[
p_{ij}^{(n)}(t) = \begin{cases}
1 & \text{if } i = j, n = 0 \\
0 & \text{if } i \neq j, n = 0 \\
\text{Pr } \{ X_{t+n} = j \mid X_t = i \} & n > 0
\end{cases}
\] (6.2)

这在 HOL4 中形式化如下：

### 定义 6.2

```
|- \forall X p s t n i j. Trans X p s t n i j =
    if i \in space s \land j \in space s then
    if (n = 0) then
    if (i = j) then 1
    else 0
    else prob p ({x | X (t + n) x = j } | {x | X t x = i })
    else 0
```

很容易理解，当事件不在事件空间中时，该事件的概率为零。例如，i 不在状态空间中意味着事件 { X_t = i } = \(\emptyset\)。在这种情况下，与空集相关的条件概率为零。

现在，离散时间马尔可夫链（DTMC）可以形式化如下：

### 定义 6.3

```
|- ∀ X p s p0 pij.
dtmc X p s p0 =
mc_property X p s ∧ (∀ i. i ∈ space s ⇒ { i } ∈ subsets s) ∧
∀ i. i ∈ space s ⇒ p0 i = P { x | X t x = i } ∧
∀ t i j. P (x | X t x = i ) ≠ 0 ⇒
(pij t i j = Trans X p s t l i j)
```

其中前三个变量继承自定义 6.1，p0 和 pij 分别指表示给定初始状态和与此随机过程相关的转移矩阵的函数。该定义中的第一个条件描述了马尔可夫性质，第二个条件确保与状态空间（空间）相关的事件在事件空间（子集 s）中是离散的，这是一个离散空间。最后两个条件将函数 p0 和 pij 分配给初始分布和转移概率。需要注意的是，X 是多态的，即它不受特定类型的约束，这是我们定义的一个非常有用的特性。

大多数应用实际上使用时间齐次 DTMC，即具有有限状态空间和时间独立转移概率的 DTMC。时间齐次性质指随机过程的时间不变特征。因此，基于方程 (6.3)，随机过程的一步转移概率可以简化为 pij = Pr { X_{t+1} = j \mid X_t = i } = pij (t)。然后，具有有限状态空间的时间齐次 DTMC 可以形式化如下：

### 定义 6.4

```
|- ∀ X p s p0 pij.
th_dtmc X p s p0 pij =
dtmc X p s p0 pij ∧ FINITE (space s) ∧
∀ t i j. Trans X p s (t + 1) l i j = Trans X p s t l i j
```

该时间齐次性质进一步简化为：

### 引理 6.1

```
|- ∀ X p s i j t n p0 pij.
th_dtmc X p s p0 pij ⇒
(Trans X p s t l i j = Trans X p s n l i j)
```

该引理的证明主要基于对变量 n 和 t 的归纳。
