## 11.1.4 典型集

AEP的一个结果是，对于联合概率 p(x1, x2, ..., xn) 接近 2^-nH(X) 的观测序列 (x1, ..., xn) 集合，其总概率等于1。这个集合称为典型集，这样的序列称为典型序列。换句话说，在所有可能的序列中，只有少数序列会被实际观测到，且这些序列的概率近似相等。AEP保证，任何对典型序列成立的性质都将以高概率成立，并决定大样本的平均行为。

### Definition 11.1

相对于 $p(x)$ 的典型集 $A_\epsilon^n$ 是满足以下条件的序列 $(x_1, ..., x_n)$ 的集合：
$2^{-n(H(X)+\epsilon)} \le p(x_1, ..., x_n) \le 2^{-n(H(X)-\epsilon)}$ (11.6)

典型集具有以下性质

### Theorem 11.4

如果 $(x_1, ..., x_n) \in A_\epsilon^n$

则

H(X) - \(\epsilon \le - \frac{1}{n} \log (P(X_1, ..., X_n)) \le H(X) + \epsilon\) (11.7)

该定理是定义5.1的直接结果。

### Theorem 11.5

\(\forall \epsilon > 0, \exists N, \forall n \ge N, P(A_\epsilon^n) > 1 - \epsilon.\)

该定理的证明源自经过正式验证的AEP。接下来的两个定理给出了典型序列数量 \(|A_\epsilon^n|\) 的上界和下界。

### Theorem 11.6

\(|A_\epsilon^n| \le 2^{n(H(X) + \epsilon)}.\)

- 证明：设 x = (x1, ..., xn)，则 \(\sum_{x \in A_\epsilon^n} p(x) \le 1\)。根据方程5.5，\(\forall \xi \in A_\epsilon^n 2^{-n(H(X)+\epsilon)} \le p(x)\)。因此 \(\sum_{x \in A_\epsilon^n} 2^{-n(H(X)+\epsilon)} \le \sum_{x \in A_\epsilon^n} p(x) \le 1\)。进而，\(2^{-n(H(X)+\epsilon)} |A_\epsilon^n| \le 1\)，从而证明了该定理。

### Theorem 11.7 \(\forall \epsilon > 0, \exists N, \forall n \ge N, (1 - \epsilon) 2^{-n(H(X) - \epsilon)} \le |A_\epsilon^n| \).

- 证明：设 x = (x1, ..., xn)。根据定理11.5，\(\exists N, \forall n \ge N, 1 - \epsilon < \sum_{x \in A_\epsilon^n} p(x)\)。根据方程11.5，\(\forall x \in A_\epsilon^n, p(x) \le 2^{-n(H(X) - \epsilon)}\)。因此，\(\exists N, \forall n \ge N, 1 - \epsilon < \sum_{x \in A_\epsilon^n} p(x) \le \sum_{x \in A_\epsilon^n} 2^{-n(H(X) - \epsilon)}\)。进而，\(\exists N, \forall n \ge N, 1 - \epsilon < 2^{-n(H(X) - \epsilon)} |A_\epsilon^n| \)，从而证明了该定理。

## 11.1.5 数据压缩极限

源编码定理证明背后的主要思想是，所有序列的平均码字长度仅考虑典型序列的平均码字长度非常接近。这是因为根据上述典型集性质，对于足够大的 n，典型集的总概率接近 1。换句话说，对于任何 \(\epsilon > 0\) 和足够大的 n，观测到非典型序列的概率小于 \(\epsilon\)。此外，典型序列的数量小于 \(2^{n(H(X) + \epsilon)}\)，因此表示所有典型序列所需的比特数不超过 \(n(H(X) + \epsilon) + 1\) 位。如果我们用 Y 表示定义在所有可能序列上的随机变量，并返回相应的码字长度。Y 的期望等于平均码字长度 L。利用典型集的性质，我们可以证明：

```
\(\bar{L} \le n(H(X) + \epsilon')\) (11.8)
```

其中 \(\epsilon' = \epsilon + \frac{1}{n}\)

因此，对于任何 \(\epsilon > 0\) 和足够大的 n，码率 \(\bar{\pi}\) 可以尽可能接近熵 \(H(X)\)，同时保持编码器的误差概率不超过 \(\epsilon\)。

在本应用中，我们使用了前几章中提出的框架来正式验证数据压缩的极限。与其他基于计算机的仿真方法给出的不太准确的结果相比，这有助于提供结果的精确机械证明，类似于通过纸笔分析获得的证明。与基于纸笔的分析方法相比，结果的正确性由定理证明器的可靠性保证。此外，正式证明是改进问题正式规范的一种方式，通过仅关注证明结果所需的必要假设并忽略不必要的假设。

据我们所知，这是首次正式验证 AEP。这也是首次使用度量论和勒贝格积分并可应用于各种类似不等式的 Chebychev 和 Markov 不等式的正式证明。Shannon 熵的形式化使我们能够定义典型集并证明其性质。这些证明大约花费了3周的人力精力和约1000行 HOL4 代码。其好处是，这些结果可以在多个其他工程应用中重复使用。

我们的形式化影响了 Affeldt 等人的工作，他们在 Coq 证明助手中证明了 Shannon 的定理。在那项工作中，作者提供了所涉概念的简化形式化，而不是像我们在这本书中所做的那样，提供可用于其他应用的通用定义。

## 11.2 基于匿名性的单一 MIX

在通信网络中，隐私不仅要求信息的机密性，还要求隐藏通信双方的身份。已提出多种匿名网络以确保匿名通信，例如 洋葱路由 (Onion Routing) (Syverson, Goldschlag, & Reed, 1997)、Crowds (Reiter & Rubin, 1998) 等。大多数提议的解决方案都基于 Chaum 最初提出的阈值混合（threshold mix）思想。混合器（Mixes）是中继节点，它们从不同用户收集数据包，将其打乱，然后以一种方式转发到目的地，使得外部窃听者无法将发出的数据包与其对应的发送者关联起来。
