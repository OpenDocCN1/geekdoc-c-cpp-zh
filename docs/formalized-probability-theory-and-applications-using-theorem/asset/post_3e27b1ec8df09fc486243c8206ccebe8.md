
As an example, let us take an intrusion event which lasts for a duration L = 2.8T. Hence, L overlaps either ⌈L/T⌉ = ⌈2.8T/T⌉ = 3 cycles with the probability (1-s = 0.2), or 4 cycles with the probability (s = 0.8).

We can now formalize in higher-order logic the average number of overlapping cycles with an intrusion period L. For this purpose, we proceed by first formally specifying the corresponding random variable which describes the number of overlapping cycles within an intrusion period L. Based on the above description, we model this behavior by a random variable denoted by IT. This random variable can be characterized in higher-order logic by the following predicate intr_distr_rv that accepts five parameters: IT: a random variable that returns an extended real number, p: the probability space, s: the variable specified in Equation (14.1), L: the length of the intrusion period, and Ts: the length of a time slot. Please note that for the sake of simplicity, we take s as a separate variable, although it depends only on L and Ts.

## Definition 14.1

⊢ ∀ IT p s (L: real) (Ts: real) . intr_distr_rv IT p s L Ts = (real_random_variable IT p) ∧ (IMAGE IT (p_space p) = {⌈L/Ts⌉, ⌊L/Ts⌋ + 1}) ∧ (distribution p IT {⌊L/Ts⌋} = 1 - s) .

The definition above specifies IT as a real random variable on the probability space p such that the image of IT on (p_space p) is in {⌈L/Ts⌉, ⌊L/Ts⌋ + 1}, and its probability distribution over {⌊L/Ts⌋} is (1 - s).

Next, we formally verify the average number of overlapping cycles with an intrusion period L, which is the expectation of the random variable IT:

## Theorem 14.1

⊢ ∀ IT p s L Ts. (0 < Ts) ∧ (0 < L) ∧ (intr_distr_rv IT p s L Ts) ⇒ (expectation p IT = Normal (L/Ts + 1)) .

where the function expectation, used in the above theorem, designates the higher-order-logic formalization of the expectation of a random variable that returns an extended real, whereas, the HOL4 function Normal is used to convert a real value to its corresponding value in an extended real. The proof of Theorem 14.1 is based on the verification of the probability distribution on $\lceil \frac{L}{Ts} \rceil$ and $\lceil \frac{L}{Ts} \rceil + 1$, along with some analysis on extended real.

### 14.2.2 Detection Probability

The probability of detecting an intrusion event (D) is usually specified using the probability of the event “being unable to detect an intrusion (UD)”. Thus, using the probability rule of complement, we have:

$P_r (D) = 1 - P_r (UD)$ (14.2)

The detection performances of a wireless sensor network mainly depends on the number of nodes covering the occurring events. The number of nodes covering a point where the intrusion event happens is a Binomial random variable (c) with the following probability.

$P_r (c = j) = C_n^j \times \left( \frac{r}{a} \right)^j \times \left( 1 - \left( \frac{r}{a} \right) \right)^{n-j} \times \frac{n!}{j!(n-j)!}$ (14.3)

where $C_n^j$ is the binomial coefficient indexed by the number j of nodes covering an occurring event and the total number n of deployed nodes. The parameters r and a, used in Equation (14.3), are the size of the sensing area of each sensor and the size of the monitored area, respectively, and $\lceil \frac{r}{a} \rceil$ is the probability that each sensor covers a given point. The Binomial random variable with n trials and success probability $q = \lceil \frac{r}{a} \rceil$ is specified in the following definition:

### Definition 14.2

```
|- ∀ X p q n. binomial_distr_rv X p q n = (real_random_variable X p) ∧
(IMAGE X (p_space p) = IMAGE (λx. &x) (count (SUC n))) ∧
(!m. &m IN (IMAGE X (p_space p)) =>
(distribution p X ({m}) = (binomial n m) * q^m * (1 - q)^(n - m))).
```

where X is a real random variable defined on the probability space p, and IMAGE (λx.&x) (count (SUC n)) generates the support of the Binomial, while the operator & allows the conversion of the natural number m into its extended number counterpart. The function binomial, used in the above definition, is the higher order-logic formalization of the binomial coefficient for reals, which we specified in HOL4.

## Definition 14.3

```
⊢ ∀ n k. binomial n k = (binomial n 0 = (1:num)) ∧
(binomial 0 (SUC k) = (0: num)) ∧
(binomial (SUC n) (SUC k) = binomial n (SUC k) + binomial n k).
```

Given that the events { c = j, 0 ≤ j ≤ n } form a partition of the entire sample space (Ω = p_space), we can establish from Equation (14.2), using the law of total probability that

P_r(D) = 1 - ∑_{j=0}^{n} P_r(UD|c=j) × P_r(c=j) (14.4)

where P_r(UD|c=j) is the conditional probability of being unable to detect the intrusion event given that (c = j).

Next, we discuss the probability P_r(UD|c=j) according to the values of j, i.e., the number of sensor nodes covering a point when the intrusion event happens, and L, i.e., the intrusion period.

- Case 1: (j = 0) and for any duration L, P_r(UD|c=0) = 1.

Given that there is 0 covering nodes, it is sure that an intrusion event can never be detected.

- Case 2: {0 < j ≤ n} ∩ {L ≥ (k-1) × T_s}, Pr(UD|c=j) = 0.

Since there are k working rounds, each of length T_s, an event lasting more than (k-1) × T_s , and having at least one covering active node (0 < j) will be always detected.

- Case 3: {0 < j ≤ n} ∩ {L < (k-1) × T_s}, Pr(UD|c=j) ≠ 0 .

An event lasting less than (k-1) × T_s with at least one covering active node (0 < j), will be usually detected with a given probability which is not null.

By extracting the first term (j=0) of the summation in Equation (14.4), we obtain

Pr(D) = 1 - (Pr(UD|c = 0) × Pr(c = 0) + \(\sum_{j=1}^{n}\) (Pr(UD|c = j) × Pr(c = j))(14.5)

According to case 1, we have Pr ( UD | c = 0 ) = 1, and we hence can rewrite Equation (14.5), using Equation (14.3), as

Pr(D) = 1 - ((1 - q)^n + \(\sum_{j=1}^{n}\) (Pr(UD|c = j) × Pr(c = j)) (14.6)

In the following, we are interested in formally verifying the detection probability Pr (D) for occurring events of any length L. More particularly, we focus on the formalization of the summation term of Equation (14.6). For that purpose, we distinguish 2 cases, i.e., { L < (k - 1) × T_s } and { L >= (k - 1) × T_s }.

### Detection Probability for Events Such That { L < (k - 1) × T_s }

The mathematical model for the performance analysis of the detection probability has directly given the final result of Equation (14.6). However, in order to achieve accurately the higher-order-logic formalizations of Equation (14.6), we require to reason about all the implicit steps related to the probabilistic analysis.

According to the intrusion period analysis, we know that the intrusion period L may overlap either \(\lceil \frac{L}{T_s} \rceil\) or \(\lceil \frac{L}{T_s} \rceil + 1\) scheduling cycles T_s. Thus, an intrusion event which lasts L, cannot be detected either when L overlaps \(\lceil \frac{L}{T_s} \rceil\) cycles, or when L overlaps \(\lceil \frac{L}{T_s} \rceil + 1\) cycles. Using the following events

- A12: The intrusion period L overlaps \(\lceil \frac{L}{T_s} \rceil\) cycles.

- A22: The intrusion period L overlaps \(\lceil \frac{L}{T_s} \rceil + 1\) cycles.

It is possible to express the whole event of non-detection, denoted by UD, as follows

UD = UD \(\cap\) (A12 \(\cup\) A22) (14.7)

Now, simplifying Pr(UD | c = j) in Equation (14.6), along with the fact that the events A12 and A22 are disjoint, we get the following result.

Pr(UD | c = j) = Pr(UD | A12 ∩ (c = j)) × Pr(A12 | c = j)
+ Pr(UD | A22 ∩ (c = j)) × Pr(A22 | c = j)   (14.8)

Intuitively, for a given intrusion event of length L, the occurrence of the event (A12 = L overlaps ⌈ L / Ts ⌉ cycles), and the event (c = j) describing that there are j covering nodes, are governed by distinct and non-interacting physical processes. Hence, the two events turn out to be independent. Now we get hence Pr(A12 | c = j) = Pr(A12) = Pr(IT = ⌈ L / Ts ⌉), where IT is the intrusion random variable as specified in Definition 14.1. Similarly, we obtain Pr(A22 | c = j) = Pr(IT = ⌈ L / Ts ⌉ + 1). This allows us to rewrite the RHS of Equation (14.8) as

Pr(UD | A12 ∩ (c = j)) × Pr(A12) + Pr(UD | A22 ∩ (c = j)) × Pr(A22)   (14.9)

On the other hand, the event “UD | A12 ∩ (c = j)” indicates the event of “being unable to detect an intrusion event” given that “the intrusion period L overlaps ⌈ L / Ts ⌉ cycles” and “there are j covering nodes”. Indeed, if an event, covered with j nodes and overlapping (h = ⌈ L / Ts ⌉) rounds, is not detected, then it means that all the j covering nodes miss the h consecutive subsets. In other words, the sequence of h subsets do not contain covering nodes. Such event is expressed by the following equation.

B_{h,c} = H_{1,c} ∩ H_{2,c} ∩ ... ∩ H_{i,c} ∩ ... ∩ H_{h,c} = ( ⋂_{i=1}^h H_{i,c} )   (14.10)

where H_{i,c} is the event that none of the c covering sensor nodes belongs to the working subset i, i.e., H_{i,c} is empty, and the set of events { H_{1,c}, H_{2,c}, ..., H_{h,c} } is mutually independent. We say that a finite set of events is mutually independent
