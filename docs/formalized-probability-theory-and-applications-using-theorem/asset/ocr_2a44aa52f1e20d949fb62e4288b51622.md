# ## KEY TERMS AND DEFINITIONS

**Network Coverage**: A given point is said to be covered by a WSN, if any randomly occurring event at this point has a greater than 0 probability of detection by at least one active node of the network.

**Scheduling in WSNs**: Scheduling of the WSNs nodes mainly comprises of splitting the network on several sub-networks, which work alternatively to save energy. The energy savings are acquired at the cost of losing the ability to ensure continuous coverage all the time.

**Wireless Sensor Networks**: Wireless sensor networks (WSN) are an electronic and autonomous alternative for manual human-supervised monitoring or surveillance. These networks are primarily composed of tiny and wirelessly connected devices, which are mainly composed of sensors for taking various measurements. According to these measurements, a decision procedure is made at the base station.
