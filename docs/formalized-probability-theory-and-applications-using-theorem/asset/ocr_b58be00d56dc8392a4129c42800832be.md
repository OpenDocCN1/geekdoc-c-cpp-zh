In Equation (14.27), the event "(DR1 = I) ∩ (c = j)" indicates that "the intrusion event is detected in the ith round" and "there are j covering nodes". Indeed, if an event, covered with j nodes, is detected in the ith round, then it means that all the j covering nodes miss the (i – 1) consecutive subsets, and the first covering nodes belong to the subset i. Such event is exactly the same as the following event.

\( A_{(i,j)} = \left( \bigcap_{m=1}^{(i-1)} H_{m,j} \cap \bar{H}_{(i,j)} \right) = B_{i-1,j} \cap \bar{H}_{i,j} \quad (14.28) \)

+   - Hm, j and Bi–1, j are the same events used in Equation (14.10).

The probability of the above event (Equation (14.28)) has been formally verified to be equal to [ (k – i + 1 / k )^j – (k – i / k )^j ].
