# Definition 4.20

```
|- Borel = sigma UNIV (: real) (open_sets UNIV)
```

where UNIV is the universal set of real numbers R. Clearly, the formalization of the Borel sigma algebra, which is based on the open sets, requires the formalization of some topology concepts of R. Additionally, a formalization of the set of rational numbers Q is also required for verifying various properties of B (R).

A rational number can be expressed as the quotient of two integers with a positive denominator. Natural numbers in HOL4 are used to express Q, i.e., the set of rational numbers, as the union of non-negative (Q+) and non-positive (Q-) rational numbers.

# Definition 4.21

```
|- Q = { r | \3 n, m. r = n/m /\ m > 0 } \/ { r | \3 n, m. r = -n/m /\ m > 0 }
```

An extensive number of reassuring properties on the set Q as well as few other less straightforward ones, namely, Q is countable, infinite and dense in R have been formally verified in HOL.

The second main requirement for defining the Borel sigma algebra on R is the formalization of the topological concepts of neighborhood and open set in R. Let a \in A \subset R. Then A is a neighborhood of a if there exists a real number d > 0 such that \/x. |x - a| < d ==> x \in A. In other words, a is an interior point of A.

# Definition 4.22

```
|- \/ A a. neighborhood A a = \3d. 0 < d /\ \/ y. a - d < y /\ y < a + d ==> y \in A
```

If every point of a set is an interior point then the set is open.

# Definition 4.23

```
|- \/ A. open_set A = \/ x . x \in A ==> neighborhood A x
```

Based on the above formalization, the following properties related to the open sets have been verified in HOL.

+   1. The empty set and the universal set are open.
+   2. Every open interval is an open set.
+   3. The union of any family of open sets is open.
+   4. The intersection of a finite number of open sets is open.
