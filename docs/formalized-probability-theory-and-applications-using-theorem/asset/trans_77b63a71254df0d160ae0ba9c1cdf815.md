## KEY TERMS AND DEFINITIONS

**离散时间马尔可夫链**: 离散时间马尔可夫链（DTMC）是一个具有可计数时间值集合的马尔可夫链，换句话说，该马尔可夫链的时间索引表现出离散性。

**马尔可夫链**: 马尔可夫链是一种表现出马尔可夫性质的随机过程，即下一个状态仅取决于系统的当前状态，而不取决于到达当前状态所经历的历史。

**随机过程**: 随机过程描述了一组随机变量，用于建模时变系统的演化。

## ABSTRACT

本章主要关注分类DTMC的形式化。本章首先介绍了分类状态的一些基础概念的形式化，这些状态基于可达性、周期性或吸收特征进行分类。然后，这些结果与前一章中介绍的DTMC的正式定义一起，用于形式化分类马尔可夫链，如非周期性和不可约DTMCs。基于这些概念，验证了一些长期性质，以正式检查马尔可夫系统功能的正确性或分析马尔可夫链模型的性能。

## 7.1 分类状态的形式化

状态分类的首要概念是首通过时间 $\tau_j$，有时也称为首击时间。它定义为从初始状态 $i$ 到达状态 $j$ 所需的最短时间：

$\tau_j = \min \{ t > 0: X_t = j \}$ (7.1)

首通过时间可以在 HOL4 中定义为：

```
Definition 7.1
|- ∀ X x j . FPT X x j = MINSET { t | 0 < t ∧ (X t x = j) }
```

其中 X 是一个随机过程，x 是与随机变量 X 关联的概率空间中的一个样本。注意，首通过时间也是一个随机变量。

$\tau_j$ 的条件分布定义为从状态 $i$ 出发并在时间 $n$ 访问状态 $j$ 的事件的概率，表示为 $f_{ij}^{(n)} = Pr \{ \tau_j = n | X_0 = i \}$。

该定义可以在 HOL4 中形式化为（Liu, 2013）：

```
Definition 7.2
|- ∀ X p i j n.
f X p i j n = prob p { (x | FPT X x j = n) | { x | X 0 x = i } }
```

另一个重要的记号，表示为 $f_{ij}$，是从状态 $i$ 出发并在所有时间 $n$ 访问状态 $j$ 的事件的概率，表示为 $f_{ij} = \sum_{n=1}^{\infty} f_{ij}^{(n)}$。它可以在 HOL4 中表示为 (\lambda n. f X p i j n) sums $f_{ij}$。因此，$f_{ij}$ 提供了从状态 $j$ 出发并最终返回 $j$ 的事件的概率。如果 $f_{jj} = 1$，则持久状态 $j$ 的平均返回时间定义为 $\mu_j = \sum_{n=1}^{\infty} n f_{jj}^{(n)}$。该无穷求和的存在性可以在 HOL 中指定为 $summable (\lambda n. n * f X p j j n)$。

在 DTMC $\{ X_j \}_{j \ge 0}$ 中，如果 $f_{jj} < 1$，则状态 $j$ 称为瞬态；如果 $f_{jj} = 1$，则称为持久态。如果持久状态 $j$ 的平均返回时间 $\mu_j$ 是有限的，则 $j$ 称为非齐次持久态（或正持久态）。同样，如果 $\mu_j$ 是无限的，则 $j$ 称为齐次持久态。

集合的最大公约数（gcd）是在定义分类状态时经常使用的数学概念。我们对集合的 gcd 形式化如下：

### Definition 7.3

```
⊢ ∀ A. GCD_SET A = MAXSET { r | ∀x. x ∈ A ⇒ divides r x }
```

其中 MAXSET 是 HOL4 集合论中的一个函数，使得 MAXSET s 定义集合 s 中的最大元素。状态 j 的一个周期是任何使得 \(p_{jj}^{(n)}\) 大于 0 的 n，我们写 \(d_j = gcd \{ n : p_{jj}^{(n)} > 0 \}\) 作为所有周期集合的 gcd。

如果存在从状态 i 到状态 j 的非零 n 步转移概率，则称状态 i 可从状态 j 可达（记作 \(i \rightarrow j\)）。如果两个状态 i 和 j 互相可达，则称为通信态（记作 \(i \leftrightarrow j\)）。如果一步转移概率 \(p_{jj} = 1\)，则状态 j 为吸收态。分类状态的一些其他基础概念的形式化见表 1。

### Table 1. 分类状态的形式化

| Definition | Condition | HOL Formalization |
| :--- | :--- | :--- |
| 瞬态 | \(f_j < 1\) | ⊢ ∀ X p j. Transient_state X p j = ∀ x. (t 1 0 < x ∧ (∀ x n. ) # ≠ ∅) ∧ (∃ s. s < 1 ∧ (∀ n. X p j p s n) sum s) |
| 持久态 | \(f_j = 1\) | ⊢ ∀ X p j. Persistent_state X p j = ∀ x. (t 1 0 < x ∧ (∀ x n. ) # ≠ ∅) ∧ (∀ n. f X p j n) sum s = 1 |
| 非齐次持久态 | \(f_j = 1, \mu_j < \infty\) | ⊢ ∀ X p j. Nonnull_state X p j = Persistent_state X p j ∧ sum n (λ n. n * f X p j n) |

## 7.2 分类 DTMC 的形式化

在本节中，我们基于上述定义来形式化分类 DTMC。通常，如果 DTMC 的状态空间中的每个状态都可以从任何其他状态（包括其自身）在有限步内到达，则该 DTMC 称为不可约。

```
⊢ ∀ X p s P₀ Pᵢⱼ ·
Irreducible_mc X p s P₀ Pᵢⱼ =
th_dtmc X p s P₀ Pᵢⱼ ∧
(∀ i j. i ∈ space s ∧ j ∈ space s ⇒
Communicating_states X p s i j)
```

其中 th_dtmc 是时齐马尔可夫链，第二个合取式表示状态空间中的所有状态都可以互相通信。

如果 DTMC 的状态空间中存在一个无法到达其他状态的状态，则该 DTMC 称为可约。

```
⊢ ∀ X p s P₀ Pᵢⱼ ·
Reducible_mc X p s P₀ Pᵢⱼ =
th_dtmc X p s P₀ Pᵢⱼ ∧
∃ i j. i ∈ space s ∧ j ∈ space s ∧
~ Communicating_states X p s i j
```

如果 DTMC 的状态空间中的每个状态都是非周期态，则该 DTMC 被视为非周期；否则它是周期性 DTMC。

```
⊢ ∀ X p s P₀ Pᵢⱼ ·
Aperiodic_mc X p s P₀ Pᵢⱼ =
th_dtmc X p s P₀ Pᵢⱼ ∧
(∀ i. i ∈ space s ⇒ Aperiodic_state X p s i)
```

```
⊢ ∀ X p s P₀ Pᵢⱼ ·
Periodic_mc X p s P₀ Pᵢⱼ =
th_dtmc X p s P₀ Pᵢⱼ ∧ (∃ i. i ∈ space s ∧ Periodic_state X p s i)
```
