

$$
E(D) = \sum_{j=1}^{n} E(D|c=j) \times P_r(c=j)
= \sum_{j=1}^{n} E(D|c=j) \times C_n^j \times \left(\frac{r}{a}\right)^j \times \left(1 - \left(\frac{r}{a}\right)\right)^{n-j} \tag{14.17}
$$

其中，$E(D|c=j)$ 是相对于事件 $(c=j)$ 的实随机变量 $D$ 的条件期望。请注意，方程 (14.17) 中未考虑情况 $(c=0)$。确实，如果没有覆盖节点，则入侵永远无法被检测到，延迟 $E(D)$ 将为无穷大，这是不可取的。

在高阶逻辑中，我们将检测延迟行为建模为在空间 $\Omega$ 上具有有限像的实随机变量：

## 定义 14.6

```
|- $\forall$ D p. delay_rv D p = (real random variable D p) $\wedge$ FINITE (IMAGE D (p_space p)).
```

接下来，我们专注于对任何长度 $L$ 的发生事件中方程 (30) 中的项 $E(D|c=j)$ 进行形式验证。根据条件期望的定义，$E(D|c=j)$ 可以在数学上表示为

$$
E(D|c=j) = \sum_d (D=d) \times P_r(D=d|c=j) \tag{14.18}
$$

对分区 $\{ A_{12}, A_{22} \}$ 应用全概率公式，并考虑到随机变量 IT 与 $c$ 的独立性，我们可以建立

$$
E(D|c=j) = (1-s) \times \sum_d (D=d) \times P_r(D=d|A_{12} \cap (c=j)) + s \times \sum_d (D=d) \times P_r(D=d|A_{22} \cap (c=j)) \tag{14.19}
$$

方程 (14.19) 的右边现在可以重写为，使用两个事件的条件期望的逆定义为

$$
(1-s) \times E(D|A_{12}, (c=j)) + s \times E(D|A_{22}, (c=j)) \tag{14.20}
$$

基于上述方程，我们可以清楚地区分给定事件 $A_{12}$ 和 $A_{22}$ 的两个不同的条件期望。根据本小节开头的分析，这些条件期望可以建立为

$$
E \left( D \mid A_{12}, (c = j) \right) = E \left( DC_1 \mid c = j \right) \tag{14.21}
$$

$$
E \left( D \mid A_{22}, (c = j) \right) = E \left( DC_2 \mid c = j \right) \tag{14.22}
$$

其中，$DC_1$ 和 $DC_2$ 是分别描述当 $(A_{12} = L$ 重叠 $\lceil \frac{L}{T} \rceil$ 个周期) 和 $(A_{22} = L$ 重叠 $\lceil \frac{L}{T_s} \rceil + 1$ 个周期) 时的检测延迟的随机变量。更具体地说，$DC_1$ 和 $DC_2$ 可以写成

$$
DC_1 = \left( \lambda x . \left( x - \frac{3}{2} + \frac{s}{2} \right) \times T \right) \circ DR_1 \tag{14.23}
$$

$$
DC_2 = \left( \lambda x . \left( x - 2 + \frac{s}{2} \right) \times T \right) \circ DR_2 \tag{14.24}
$$

其中，$\circ$ 运算符表示函数复合，$DR_1$ 和 $DR_2$ 是分别给定 $A_{12}$ 和 $A_{22}$ 的延迟轮随机变量，如上所述。将上述两个方程代入方程 (14.21) 和 (14.22)，并应用随机变量函数的条件期望，我们推导出给定 $(c=j)$ 时 $D$ 的条件期望 $E(D|c=j)$ 等于

$$
(1-s) \times \sum_{i=2}^{ph1} \left( i - \frac{3}{2} + \frac{s}{2} \right) \times T \times P_r \left( DR1 = i \mid A_{12} \cap (c = j) \right) + s \times \sum_{i=2}^{ph2} \left( i - 2 + \frac{s}{2} \right) \times T \times P_r \left( DR2 = i \mid A_{22} \cap (c = j) \right) \tag{14.25}
$$

现在，分析随机变量之间的关系，我们可以建立 $DR1$ 和 $IT$ 在给定随机变量 $c$ 的条件下是条件独立的。确实，就事件而言，如果我们已经知道 $(c = j)$，则信息 $A_{12}$ 关于 $(DR1 = i)$ 不提供任何额外信息。同样地，给定 $(c = j)$ 时，$(DR2 = i)$ 和 $A_{22}$ 也是如此。现在，我们可以将方程 (14.25) 简化为

$$
E(D|c=j) = (1-s) \times \sum_{i=2}^{ph1} \left( i - \frac{3}{2} + \frac{s}{2} \right) \times T \times P_r(DR1=i|c=j) + s \times \sum_{i=2}^{ph2} \left( i - 2 + \frac{s}{2} \right) \times T \times P_r(DR2=i|c=j) \tag{14.26}
$$

根据条件概率的定义并结合概率推理，对上述方程中的项 $P_r(DR1=i|c=j)$ 和 $P_r(DR2=i|c=j)$ 进行展开，我们得到以下结果。

$$
E(D|c=j) = (1-s) \times \frac{\sum_{i=2}^{ph1} \left( i - \frac{3}{2} + \frac{s}{2} \right) \times T \times P_r(DR1=i|c=j)}{\sum_{i=1}^{ph1} P_r(DR1=i|A_{12} \cap (c=j))} + s \times \frac{\sum_{i=2}^{ph2} \left( i - \frac{3}{2} + \frac{s}{2} \right) \times T \times P_r(DR2=i|A_{22} \cap (c=j))}{\sum_{i=1}^{ph2} P_r(DR2=i|A_{22} \cap (c=j))} \tag{14.27}
$$

定理 14.4 的证明与从方程 (14.15) 到方程 (14.27) 的证明非常相似。特别是，推理主要基于对上述函数 `(delay_DC_rv DC DR p a Ts)` 的规范，仅考虑正值，因为它描述的检测延迟行为永远不可能为负。在此情况下，项 $(i - \frac{3}{2} + \frac{s}{2})$ 和 $(i - 2 + \frac{s}{2})$ 可以被证明等于

0 对于 $(i = 1)$，因此分子的正确求和索引可以被证明。此外，还需要大量与求和使用相关的推理，包括某些函数的单射性证明和实分析。

在方程 (14.27) 中，事件 "$(DR1 = i) \cap (c = j)$" 表示 "入侵事件在第 $i$ 轮被检测到" 和 "有 $j$ 个覆盖节点"。确实，如果一个被 $j$ 个节点覆盖的事件在第 $i$ 轮被检测到，则这意味着所有 $j$ 个覆盖节点都错过了 $(i-1)$ 个连续的子集，且第一个覆盖节点属于子集 $i$。这样的事件与以下事件完全相同。

$$
A_{(i,j)} = \left( \bigcap_{m=1}^{(i-1)} H_{m,j} \cap \bar{H}_{(i,j)} \right) = B_{i-1,j} \cap \bar{H}_{i,j} \tag{14.28}
$$

其中

- $H_{m,j}$ 和 $B_{i-1,j}$ 是方程 (14.10) 中使用的相同事件。
- 事件集 $\{ B_{i-1,j}, H_{i,j} \}$ 是相互独立的。

上述事件（方程 (14.28)）的概率已被正式验证等于 $\left[ \left( \frac{k - i + 1}{k} \right)^j - \left( \frac{k - i}{k} \right)^j \right]$。

$$
E(D) = \sum_{j=1}^n E(D|c=j) \times C_n^j \times \left( \frac{r}{a} \right)^j \times \left( 1 - \left( \frac{r}{a} \right) \right)^{n-j} \tag{14.29}
$$

其中

$$
E(D|c=j) = (1-s) \times \frac{ \sum_{i=2}^{ph1} \left( i - \frac{3}{2} + \frac{s}{2} \right) T \times \left[ \frac{ \left( \frac{k - i + 1}{k} \right)^j - \left( \frac{k - i}{k} \right)^j }{ \frac{k - i + 1}{k} } \right] }{ \sum_{i=1}^{ph1} \left[ \left( \frac{k - i + 1}{k} \right)^j - \left( \frac{k - i}{k} \right)^j \right] } + s \times \sum_{i=2}^{ph2} \frac{ \left( i - 2 + \frac{s}{2} \right) T \times \left[ \frac{ \left( \frac{k - i + 1}{k} \right)^j - \left( \frac{k - i}{k} \right)^j }{ \frac{k - i + 1}{k} } \right] }{ \sum_{i=1}^{ph2} \left[ \left( \frac{k - i + 1}{k} \right)^j - \left( \frac{k - i}{k} \right)^j \right] } \tag{14.30}
$$
