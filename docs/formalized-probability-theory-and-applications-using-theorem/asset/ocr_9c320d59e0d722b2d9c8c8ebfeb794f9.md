+   Property: For any aperiodic and irreducible DTMC with finite state space S and transition probabilities \( p_{ij} \), there exists \( \lim_{n \to \infty} p_{ij}^{(n)} \), for all states \( i \) and \( j \in S \).

# Theorem 7.4

```
∀ X p s p0 pij i j t.
Aperiodic_DTMC X s p s0 Pij ∧ Irreducible_DTMC X s p0 Pij ⇒
∃ u. lim (λ n. Trans X p s t n i j) = u
```

The proof of Theorem 7.4 is based on the monotonic properties of \( M_j^n \) and \( m_j^n \), which are the maximum and minimum values of the set \( \{n \ge 1: p_{jj}^{(n)} > 0\} \), respectively. Then, the proof is completed by verifying the convergence of the sequence \( (M_j^n, m_j^n) \) for all \( n \) such that \( N \le n \) and some properties of real sequences. It is important to note that we do not need to use the assumption \( j \in space \) here, like all other theorems, as \( \forall n j j \notin space \Rightarrow p_{jj}^{(n)} = 0) \), which in turn implies \( \lim_{n \to \infty} p_{jj}^{(n)} = 0 \) and \( \lim_{n \to \infty} p_{ij}^{(n)} = 0 \) by using the conditional probability properties.

# 7.3.2 Convergence Analysis

The long-run probability distributions are often considered in the convergence analysis of random variables in stochastic systems. It is not very easy to verify that the limit probability distribution of a certain state exists in a generic non-trivial DTMC, because the computations required in such an analysis are often tremendous. However, in the aperiodic and irreducible DTMCs, we can prove that all states possess limiting probability distributions, by the following two properties.

+   Property: For any aperiodic and irreducible DTMC with finite state space S, there exists \( \lim_{n \to \infty} p_{ij}^{(n)} \), for any state \( i \in S \).
