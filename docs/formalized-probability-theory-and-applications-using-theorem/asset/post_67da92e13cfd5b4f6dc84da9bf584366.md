
For a time-homogeneous DTMC with finite state space and one-step transition probability $\{ p_{ij} \}_{i,j} \in \mathcal{Q}$, the steady state probabilities are defined to be a vector $V_j = \lim_{n \to \infty} p_{ij}^{(n)}$, for all $j \in \mathcal{Q}$. If $V_j$ exists for all $j \in \mathcal{Q}$, then $V_j$ is known as the stationary probability vector of that Markov chain. In other words, $V_j$ is a stationary distribution of this DTMC if it satisfies:

$$
V_j = \sum_{i \in \Omega} \lim_{n \to \infty} V_i p_{ij}
$$

$$
\sum_{j \in \Omega} V_j = 1
$$

$$
0 \le \lim_{n \to \infty} V_j
$$

This stationary property can be verified using higher-order logic as:

### Theorem 6.6

```
|- \forall X p s p_0 P_ij.
th_dtmc X p s p_0 P_ij
db_equations (\lambda i. lim prob p {x | X n x = i}) X p s
stationary_dist (\lambda i. lim prob p {x | X n x = i}) X p s
```

The reasoning for the correctness of the above theorem is similar to that of Theorem 6.5.

## 6.4 FORMALIZATION OF STATIONARY PROCESS

Stationary processes are frequently used stochastic processes in analyzing time series, which is the fundamental of Ergodic theorems. Mathematically, a stochastic process $\{ X_t \}_{t \in T}$ is said to be stationary in the strict sense, if for $n \ge 1, t_1, t_2, ..., t_n \in T$, the random variables $X_{t_1}, X_{t_2}, ..., X_{t_n}$ have the same joint distributions as $X_{t_1+\tau}, X_{t_2+\tau}, ..., X_{t_n+\tau}$. In a discrete-time stochastic process, $\tau$ is a natural number. A stationary process can be formalized in HOL4 as follows:

### Definition 6.9

```
|- ∀ X p s .
stationary_proc X p s =
∀ f t w n. random variable (X t) p s ∧
(P ({ ⋂_{k=0}^n { x | X ( w + k ) x = f k } }) =
P ({ ⋂_{k=0}^n { x | X ( t + k ) x = f k } }))
```

where f denotes the state sequence.
Using this definition, we can apply induction on variables t and n to prove that the probability mass function of a stationary process is independent of the time.

### Theorem 6.7

```
|- ∀ X p s t n j.
stationary_pmf X p s =>
(prob p ({ x | X n x = j }) = prob ({ x | X t x = j }))
```

However, a stationary process is not a process with a stationary distribution. In fact, a DTMC is stationary if and only if its initial distribution is stationary. This property has been verified in HOL4 from two different perspectives; the first one being that a stationary DTMC has Stationary Distribution for all the states

### Theorem 6.8

```
|- ∀ X p s n p_0 P_{ij}.
th_dtmc X p s p_0 P_{ij} => stationary_pmf X p s =>
stationary_dist (λ i. prob p ({ x | X n x = i })) X p s
```

The proof steps are very similar to the ones for Theorem 6.5. The proof of the last subgoal requires P { x | X n x = j } = P { x | X (n - 1) x = j }, which can be proved by instantiating the variable t and n to be n and n - 1 using Theorem 6.7. The proof is finalized by applying Lemma 6.1 and Theorem 6.3 if the variable n in Theorem 6.8 is assigned a value 0 then the stationary DTMC is said to have a stationary initial distribution. Thus, Theorem 6.8 shows that a stationary DTMC has stationary initial distributions.

The second perspective is that if the initial distributions of a DTMC are stationary then the corresponding DTMC is stationary as well.

### Theorem 6.9

```
|- ∀ X p s P_0 P_1j;
th_dtmc X p s P_0 P_1j
stationary_dist (λ i. P { x | X 0 x = i }) X p s =>
stationary_proc X p s
```

The verification of this theorem is primarily based on Theorem 6.1 and involves induction on the variable n.

## 6.5 BINARY COMMUNICATION MODEL

A binary communication channel (Trivedi, 2002) is a channel with binary inputs and outputs. The transmission channel is assumed to be noisy or imperfect, i.e., it is likely that the receiver gets the wrong digit. This channel can be modeled as a two-state DTMC with the following state transition probabilities.

Pr { $X_{n+1} = 0 \mid X_n = 0$ } = 1 - a; Pr { $X_{n+1} = 1 \mid X_n = 0$ } = a;

Pr { $X_{n+1} = 0 \mid X_n = 1$ } = b; Pr { $X_{n+1} = 1 \mid X_n = 1$ } = 1 - b

The binary communication channel is widely used in telecommunication theory as more complicated channels are modeled by cascading several of them.
