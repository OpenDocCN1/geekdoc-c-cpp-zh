# 9.2 FORMALIZATION OF KULLBACK-LEIBLER DIVERGENCE

The Kullback-Leibler (KL) divergence DKL (u ‖ v) is a measure of the distance between two distributions u and ∫x (log dν / dμ) du. It can be used to define most information-theoretic measures, such as the mutual information and entropy and can, hence, be used to provide a unified framework to formalize most information leakage measures. Mathematically, the KL divergence is defined as:

```
DKL(μ ‖ ν) = - ∫x log(dν/dμ) dμ (9.7)
```

where dν/dμ is the Radon-Nikodym derivative of v with respect to u. The KL divergence is formalized in HOL4 as:

```
|- ∀ b m v. KL_divergence b m v =
-integral m (λx. logr b (RN_deriv m v x))
```
