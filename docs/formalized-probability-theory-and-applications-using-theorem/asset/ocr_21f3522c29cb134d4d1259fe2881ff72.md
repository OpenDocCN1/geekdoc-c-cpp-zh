# 12.5.1 Nineteen-Node Cyber Network

Cyber network failures are highly undesirable considering the enormous number safety-critical nature of the applications running on this communication framework. The cyber network reliability is usually defined as the probability that the network, with all its sub networks and components within specific source and target nodes, is functioning. The network reliability analysis (Sahinoglu, 2010) mainly focuses on evaluating the overall reliability between any source and target nodes. The cyber network reliability analysis become indefensible when the cost of failure of the system is high.

In order to illustrate the effectiveness of our approach, we present the formal reliability analysis of a nineteen-node cyber network, shown in Figure 4. This network primarily consists of 19 nodes, which exhibit exponentially distributed failures, and 22 links. There are 5 paths and the nodes present in each path are [ 1 -> 2 -> 4 -> 5 -> 6 -> 7 -> 8 -> 11 -> 13 ], [ 1 -> 2 -> 4 -> 5 -> 6 -> 7 -> 9 -> 10 -> 11 -> 13 ], [ 1 -> 3 -> 14 -> 15 -> 17 -> 19 -> 13 ], [ 1 -> 3 -> 14 -> 15 -> 16 -> 17 -> 19 -> 13 ], [ 1 -> 12 -> 13 ]. The objective of the reliability analysis is to assess the impact of the individual failure rates of the nodes on the overall failure of the complete nineteen-node cyber network.

The proposed theorem proving based approach for RBD based reliability analysis allows us to formally verify generic expressions involving an arbitrary configuration, number of sub-modules and failure rates. In general, the reliability of the overall network is evaluated between a source node s, where all the paths emerge from, and a target node t, where the paths terminate. For example, in the given 19 node cyber network, the source node is 1 and the target node is 13 as shown in Figure 4. The collections of these paths from the source node to the target node can be modeled as a parallel structure while the nodes at each stage from source to target can be considered as a series structure. Thus, the reliability of a general network can be evaluated using the parallel-series RBD and expressed mathematically as follows:

```
Pr(S \cap \bigcap_{i=1}^M \bigcap_{j=1}^N A_j \cap T)
```

where S and T represent the events corresponding to the reliabilities of the source s and target t nodespectively. The events in between the source and target node are the events corresponding to the nodes connected in the parallel-series network A_y.
