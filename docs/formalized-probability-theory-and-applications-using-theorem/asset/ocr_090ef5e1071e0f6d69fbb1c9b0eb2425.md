# 9.6 FORMALIZATION OF QUANTITATIVE ANALYSIS OF INFORMATION

In most applications, some information is always intended by design to ensure the functionality of the protocol. For example, in the case of an election protocol, the outcome of an individual vote has to remain secret but overall election results should be made public. Similarly, a password checking programs reveals some information when it rejects an incorrect password (Malacaria, 2007).

Quantitative analysis of information flow (Smith, 2009) is gaining a lot of attention in a variety of contexts, such as secure information flow, anonymity protocols (Serjantov & Danezis, 2003), and side channel analysis. It allows us to measure how much information about the high security inputs of a system can be leaked, accidentally or maliciously, by observing the systems outputs and possibly the low security inputs. Unlike non-interference analysis, which only determines whether a system is completely secure or not completely secure, quantitative information flow analysis provides an information-theoretic measure on how secure or insecure a system is.

We introduce two new measures of information (Mhamdi, Hasan & Tahar, 2012), namely the information leakage degree and the conditional information leakage degree, which can be used to evaluate the anonymity and security properties of various systems and protocols.
