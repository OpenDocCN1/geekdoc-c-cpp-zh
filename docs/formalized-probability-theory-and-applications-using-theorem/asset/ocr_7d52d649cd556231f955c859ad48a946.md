# 11.1.1 Chebyshev and Markov Inequalities

In probability theory, both the Chebyshev and Markov inequalities provide estimates of tail probabilities. The Chebyshev inequality guarantees, for any probability distribution, that nearly all the values are close to the mean and it plays a major role in the derivation of the laws of large numbers. The Markov inequality provides loose yet useful bounds for the cumulative distribution function of a random variable. Let X be a random variable with expected value m and finite variance σ². The Chebyshev inequality states that for any real number k > 0,

P (|X - m| ≥ kσ) ≤ 1/k² (11.1)

The HOL4 formalization of the Chebyshev inequality is stated as:

```
|- random_variable X p Borel ^
integrable p (λx. ((Xx - E [ X ])^2) ∧ 0 < k ⇒
prob p { x | x ∈ Ω ∧ kVar [ X ] ≤ | X x - E [ X ] | } ≤ 1/k²
```

The Markov inequality states that for any real number k > 0,

P (|X| ≥ k) ≤ m/k (11.2)
