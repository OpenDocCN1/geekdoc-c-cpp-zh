我们最初试图使用前几章中提出的基础结果来正式验证这一结果，但发现了一个反例，该反例针对上述结果纸笔证明所基于的一个假设。错误的假设指出，无论转移概率如何（匿名性攻击的结果），当所有输入符号都具有非零概率时，互信息达到最大。我们能够在 HOL4 中证明，发送方 s1 不需要与所有接收方通信即可达到容量。

首先，我们提供了信道容量的高阶逻辑形式化，其定义为在所有输入分布上，输入与信道输出之间互信息的最大值。我们在 HOL4 中使用第 4 章的互信息形式化和 Hilbert 选择算子对其进行形式化；即，如果存在，容量是某个 c，使得对于某个概率分布 m，c = Im (X; Y)，并且对于任何输入分布 p，Ip (X; Y) <= c。

```
|- capacity s X Y = @c. (Ex m. c = Im (X; Y)) /\ (Ym. Im (X; Y) <= c)
```

```
|- MIX_channel_1 s m X Y =
(X (s) = ( 0; 1; 2 )) /\ (Y (s) = ( 0; 1; 2 )) /\
(p X ( 0 ) = p X ( 2 )) /\
(p Y | X ( 0 ) { 0 } = 1) /\ (p Y | X ( 0 ) { 1 } = 1/2 /\ (p Y | X ( 0 ) { 2 } = 0) /\

(p Y | X ( 2 ) { 0 } = 0) /\ (p Y | X ( 2 ) { 1 } = 1/2 /\ (p Y | X ( 2 ) { 2 } = 1)
```

我们证明其互信息等于 2p。

```

```

我们还证明容量等于 1，且对应 p = 1/2。这意味着达到信道容量的输入分布为 [ p { x0 } = 1/2. p { x1 } = 0. p { x2 } = 1/2 ]。因此，我们证明发送方 s1 不需要与接收方 r2 通信仍可达到最大容量，这与 Zhu 和 Bettati (2009) 的结果相矛盾。请注意，当 p = 1/2 时，I(X; Y) = H(X) = 1，这意味着信息泄露程度 D = 0。因此，对于这个隐蔽通道，最大容量对应于完美识别。

与基于纸笔的分析不同，使用定理证明进行机器辅助的定量信息流分析保证了结果的准确性。事实上，定理证明的可靠性本质上确保只有有效公式才可被证明。要求证明的每个步骤都必须使用推理规则从公理或先前的定理推导出来，这使我们能够发现缺失的假设，甚至有时发现错误的陈述，就像在这个单一 MIX 应用程序中一样。我们能够检测出上述部分中描述的推理问题，并使用我们在 HOL 中的形式化来确认结果。在这种情况下，当我们试图证明错误的假设（即信道容量在所有输入符号都具有非零概率时达到）时，我们发现了该问题。

据我们所知，这是首次使用定理证明来分析混合网络的属性。这显然不是一个大型应用，可以扩展到推理 MIX 网络和其他匿名网络。然而，这作为一个示例来说明本书所提出的框架的有用性。得益于信息论的丰富形式化，我们能够在一周的人力投入和大约 500 行 HOL4 代码内分析该应用程序的 MIX。

## 11.3 一次性密码本

一次性密码本是一种简单而可靠的加密系统，如果正确使用，它提供不可破解的安全性。加密通过将明文的每个字符与来自秘密随机密钥（长度至少与原始消息相同）的字符进行模加来执行。如果密钥真正随机且整体或部分从不重复使用，那么可以证明一次性密码本加密提供完美安全性。我们在 HOL4 定理证明器中使用本书提出的高阶逻辑框架正式证明了这一属性。一次性密码本

一次性密码本 (Gallager, 1968) 已被广泛用于保障各国情报机构的通信安全，例如曾用于华盛顿/莫斯科热线，以在白宫和克里姆林宫之间提供完全安全的通信，且不泄露任何其他秘密加密技术。

这种加密技术的主要挑战是生成真正随机的密钥并将其分发给发送方和接收方。这有时会使该技术不切实际，并将其应用类型限制在例如绝对安全性是真正必须的情况，无论成本如何。尽管如此，如果其他理论上不那么安全但更实用的加密系统由于战争或攻击原因不可用，一次性密码本仍可作为备用加密选项。当发送方和接收方都需要在不使用计算机的情况下手动完成所有工作时（无论是因为没有计算机可用，还是为了避免标准计算机可能存在的漏洞），一次性密码本加密也非常重要。图 6 描绘了典型一次性密码本加密系统的结构。明文首先被编码为数字或比特，然后输入到加密块，该块执行模加（模 10）以生成密文。随后将其传输到接收方，接收方执行逆运算以恢复原始消息。
