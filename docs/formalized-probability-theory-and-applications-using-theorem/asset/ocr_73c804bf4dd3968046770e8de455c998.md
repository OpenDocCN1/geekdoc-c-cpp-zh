Consider the set S of c nodes covering a specific point in side the field. If the random scheduling is applied to this set, it will uniformly assign each sensor node in S to one of the k disjoint subsets. A given sub-network Sj is thus empty if the Uniform random variable never generates the number j, i.e., all the c sensors of S miss this subset. Moreover, based Sj n the uniform distribution, the probability of joining any subset is equally likely and is equal to 1/k, while the probability of not being in a particular subset is (1 – 1/k). Given that the c covering nodes independently join or miss a subset Sj, the probability of having an empty subset can be formally verified as follows:

# Theorem 13.1

```
⊢ ∀ X p k (a: num) (j: num). (1 < k) ∧
(uniform_distribution_rv X p a k) ∧
(sm ∈ (IMAGE X (p_space p))) ∧
(∀ c. (indep p (p_space p ∩ { x | X x ≠ &j }))
({ x | subset_empty (¬j) (rd_subsets c (X x)) } ∩ p_space p))
⇒ (prob p { x | subset_empty (¬j) (rd_subsets n (X x)) = T }
∩ p_space p) =
(1 – (1 / (&k)))) pow n
```

+   - The assumption (1 < k) ensures that the number of sub-networks is greater than 1, since the randomized scheduling would be meaningless for k = 1
+   - (uniform distr rv X p a k) is the Uniform random variable (Definition 13.1).
+   - The set of events, when the subset Sj is empty, is formally modelled by ({ x | subset empty k) rd_subsets n (X x)) ∩ p space p).
+   - This set utilizes the predicate subset_empty (Definition 13.3) which looks for the index k in the list generated by the function rd_subsets (Definition 13.2).
