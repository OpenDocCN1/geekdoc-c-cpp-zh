## 持续时间为 { L >= (k - 1) x T } 的事件的检测概率

根据本小节开头讨论的第二种情况，我们只需验证检测概率 Pr(D) 等于

Pr(D) = 1 - (1 - q) ^ n (14.12)

使用定理 14.2。此结果非常重要，因为它说明了前一章中提到的覆盖形式化与检测概率 Pr(D) 的新结果之间的关联。一般来说，如果区域中发生的任何事件都可以被检测到，则该区域中的一点被视为覆盖。该特性通过网络覆盖强度 Cn 进行度量，它决定了监控区域被覆盖的程度。当事件持续时间为 (L >= (k - 1) x T) 时，意味着至少花费一个完整的工作周期（持续 k T），并且所有子网络 { Si, 0 <= i <= n } 都已至少工作一次。直觉上，这样的事件肯定会在某个工作子集中被检测到，其检测概率等于网络的覆盖度量，当整个网络被视为一个子网络时，即 (k = 1) 时的 Cn。上述公式正式确认了这一直觉，并展示了持续时间为 (L >= (k - 1) x T) 的事件的检测概率 Pr(D) 的行为如何与 (k = 1) 时的网络覆盖强度 Cn 的行为相匹配。

## 14.2.3 平均检测延迟

在无线传感器网络中，平均检测延迟通常定义为从入侵事件发生到该事件被某些传感器节点检测到所经过时间的期望。在本部分中，我们针对该平均检测延迟（记为 E (D)）进行形式化验证。从数学上讲，E (D) 被指定为描述检测延迟的随机变量 D 的期望。我们假设 E (D) 是有限的。

设 DT i 为第 i 轮中入侵被检测到的平均时间。对于第一轮（i = 1），延迟显然为零（DT1 = 0）。由于节点子集按轮次工作，因此直觉上，检测入侵的延迟取决于检测轮次 i。此外，DTi 值还取决于入侵的起始时间 tz，即 A12 和 A22。因此，对于第二轮（i = 2），我们可以发现：

- 如果 tz ∈ [t0, t0 + (1 - s) x T ]，则 DT2 = T − ((1 - s) x T) / 2。
- 如果 tz ∈ ]t0 + (1 - s) x T, T [，则 DT2 = (s x T) / 2。

更一般地，根据原始规范，如果 tz ∈ [t0, t0 +(1−s) x T ]，即给定 A12，则：

\( DT_i |_{A_{12}} = \begin{cases} 0 & \text{if } i=1 \\ \left( (i-1) - \frac{(1-s)}{2} \right) \times T & \text{if } 1 < i \le \lfloor \frac{L}{T} \rfloor \end{cases} \) (14.13)

但是，当 tz ∈ ]t0 + (1 − s) x T, T [ 时，我们有

\( DT_i |_{A_{22}} = \begin{cases} 0 & \text{if } i=1 \\ \left( (i-2) - \frac{s}{2} \right) \times T & \text{if } 1 < i \le \lfloor \frac{L}{T} \rfloor + 1 \end{cases} \) (14.14)

请注意，符号 (DT i | A12) 和 (DT i | A22) 分别指在给定 A12 和 A22 时随机变量 D 所取的值。

基于公式 (14.13) 和 (14.14)，我们注意到检测延迟值如何取决于检测轮次 i。考虑描述检测轮次的随机变量 DRI。在条件为事件 A12 和 A22 时，DRI 的值为

DRI | A12 = { i + 1 | 0 ≤ i ≤ ph1 - 1 } where ph1 = min ⌈k, ⌈L / T⌉⌉ (14.15)

DRI | A22 = { i + 1, 0 ≤ i ≤ ph2 - 1 } where ph2 = min ⌈k, ⌈L / T⌉⌉ + 1 (14.16)

由于最多有 k 个检测轮次，因此考虑变量 ph1 和 ph2 的最小值。例如，考虑一个随机调度为 (k = 3) 个子网络的 WSN，以及两个入侵事件 E1 和 E2，它们的起始时间 tz 在 t0, t0 +(1–s) x T ] 中，分别持续 (L1 = 1.8 x T) 和 (L2 = 3.2 x T)。对于事件 E1，⌈ L1 / T ⌉ = 2，可能的检测轮次为 i = { 1, 2 }。对于事件 E2，⌈ L2 / T ⌉ = 4，但潜在的检测轮次为 i = { 1, 2, 3 }，即最多 3 个，等于 k。

根据上述两个公式，即最多 3 个，等于 k。
