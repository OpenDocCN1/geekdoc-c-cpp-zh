```
F_X(x) = \text{Pr}(X \le x)
```

for any number x, where Pr denotes the probability function. The CDF allows us to distinguish between discrete and continuous random variables as well. The CDF of a discrete random variable always consists of a sequence of finite jumps while it has a smooth continuous plot for continuous random variables.

Besides the CDF, another useful distribution function for discrete random variables are their probability mass function (PMF), which provides the probability that a random variable X is exactly equal to some value x.

```
p_X(x) = \text{Pr}(X = x)
```

The PMF of a continuous random variable is always 0. So another probability distribution characteristic, i.e., the probability density function (PDF), which represents the slope of the CDF, is frequently used to characterize continuous random variables.

```
f_X(x) = \frac{dF_X(x)}{dx}
```

## 1.4 STATISTICAL PROPERTIES

Statistical properties allow us to summarize the behavior of a random variable as a single number, rather than a distribution function, and thus provide a very useful criterion for choosing the most suitable solution from various probabilistic analysis results. The most widely used statistical property is expectation, which is defined for a random variable X as follows:

```
E_X[X] = \begin{cases} \sum_i x_i p_x(x_i), & \text{if } X \text{ is discrete}; \\ \int_{-\infty}^{+\infty} x f_x(x) dx, & \text{if } X \text{ is continuous.} \end{cases}
```

where $\sum_i$ denotes the summation carried over all possible values of the random variable X. Another closely associated statistical characteristic is the nth moment of a random variable X, which is basically the expected value of the random variable X^n. Thus, the expectation and the first moment of a random variable represent the same statistical characteristic of a random variable. Another useful statistical characteristic of random variables is the measure of their dispersion from the average or the typical values.

The most widely used measures of dispersion are the standard deviation and the variance. The variance of a random variable X describes the difference between X and its expected value.

```
Var[X] = \sigma_x^2 = \begin{cases} \sum_i (x_i - E_x[X])^2 p_x(x_i), & \text{if } X \text{ is discrete}; \\ \int_{-\infty}^{\infty} (x - E_x[X])^2 f_X(x) dx, & \text{if } X \text{ is continuous.} \end{cases} \quad (1.5)
```

The square root of the variance, which is always a positive number, is known as the standard deviation; which is a useful in the sense that it has the same units as X and thus can be compared directly with the expected value. Based on the expectation and variance characteristics of a random variable, we can find bounds for the tail distribution, i.e., the probability that a random variable assumes values that are far from its expectation. These bounds are usually calculated using the Markov's or the Chebyshev's inequalities. The Markov's inequality gives an upper bound for the probability that a non-negative random variable X is greater than or equal to some positive constant.

```
\text{Pr}(X \ge a) \le \frac{E_X[X]}{a} \quad (1.6)
```

Markov's inequality gives the best tail bound possible, for a nonnegative random variable, using the expectation for the random variable only. Chebyshev's inequality provides a significantly stronger tail bound than the Markov's inequality by using the variance of the random variable:

```
\text{Pr}(|X - E_X[X]| \ge a) \le \frac{Var[X]}{a^2} \quad (1.7)
```

Due to the widespread interest in failure probabilities and the ease of calculation of tail distribution bounds, Markov and Chebyshev's inequalities have now become one of the core techniques in modern probabilistic analysis.

## 1.5 TRADITIONAL PROBABILISTIC ANALYSIS METHODS

Traditionally, probabilistic analysis is done using paper-and-pencil proof techniques. The main idea here is to develop a randomized model of the given system on paper and then use mathematical reasoning to derive the desired probabilistic and statistical properties on paper. However, this method cannot cope with the complexity of the present-age engineering and scientific systems. This fact has led to the usage of computers for conducting probabilistic analysis. These days, simulation (Ross, 2002) has become the most commonly used computer based probabilistic analysis technique. Such simulation packages usually contain a large collection of discrete and absolutely continuous univariate and multivariate distributions, which in turn can be used to model systems with random or unpredictable components. These models are then analyzed using computer-based techniques, such as the Monte Carlo method (MacKay, 1998), where the main idea is to approximately answer a probabilistic query by analyzing a large number of samples. Statistical quantities, such as expectation, variance and tail distribution bounds, may then be calculated, based on the data collected during the sampling process, using their mathematical relations in a computer. The probabilistic and statistical analysis conducted using simulation techniques is based on certain approximations and can be quite unreliable at times. It is a common occurrence that different software packages come up with different solutions to the same probabilistic analysis problem. There are three main reasons for such discrepancies:

- The source of randomness in the simulation based software packages is usually pseudorandom numbers; the numbers seem random but are actually the output of a random number generator (RNG), which is basically a deterministic algorithm. The period of a RNG, i.e., the number of calls, which can be made to the RNG before it begins to repeat itself, severely affects the accuracy of the result from a probabilistic or statistical software package.
- In most simulation based software packages, the CPU time required for generating non-uniform random numbers for arbitrary probability distributions is a major issue. Therefore functions for evaluating probability distributions are approximated using a variety of algorithms, which mainly compromise the accuracy for attaining faster computations.

## Probabilistic Analysis

- Like all other computer arithmetic based computations, round-off and truncation errors also creep into the numerical computations in these simulation based software packages. The main cause of these errors is the finite precision representation of numbers in the computers.

To illustrate the above approximation issues further, consider the example of the rand function in the statistical toolbox of MATLAB, which is one of the widely used simulation environment for probabilistic analysis. It approximates the Standard Uniform [0,1] random variable (Yates & Goodman, 2005) by producing a pseudorandom double precision floating-point number, represented in the computer by 64 bits. Therefore rand is capable of producing no more than 2^64 unique double precision floating-point numbers compared to the uncountably infinite real numbers in the interval [0,1] that a True Standard Uniform random variable can produce. Additional approximations are introduced if we consider the product of two Standard Uniform random variables that are produced by the rand function in MATLAB. The result of the product could be up to 128 bits long but due to finite bit precision, the value is expressed in 64 bits using various rounding or truncation techniques. Besides the inaccuracy of the results, another major limitation of simulation based probabilistic analysis is the enormous amount of CPU time requirement for attaining meaningful estimates. This approach generally requires hundreds of thousands of simulations to calculate the probabilistic quantities and becomes impractical when each simulation step involves extensive computations.

Computer Algebra systems (Grozin, 2013), like Maple and Mathematica, provide an arbitrary-precision numeric engine, primarily by increasing the number of digits carried through calculations, and converting real numbers to their corresponding rational numbers. Because of this feature, the probabilistic analysis packages available in computer algebra systems, like MathStatica (Rose & Smith, 2002) that is available in Mathematica, provide much accurate results than simulation. However, as per the general rule of computing that is there is always a tradeoff between speed and accuracy and thus, the computer algebra system based probabilistic analysis tends to be very slow and is not practical for analyzing real-world systems.

The accuracy of the engineering and scientific system analysis results has become imperative these days because of the extensive usage of these systems in safety and mission-critical domains, such as medicine, transportation and military. Therefore, the above-mentioned traditional techniques cannot be relied upon for the analysis of such systems.
