

上述定理中的假设确保序列 A 中的集合互斥。集合 BIGUNION (IMAGE A (count n)) 表示集合 { A_i | i ∈ N }，因为函数 BIGUNION 对集合 (IMAGE A UNIV) 中的所有集合取并。上述定理等式的右边表示使用 HOL4 函数 SIGMA 对实数序列 (λi. Pr(A_i | B)) 进行无穷求和。上述属性的证明基于一些已验证的集合论原理和概率加法定律。

## 5.4.3 条件概率补集公理

$Pr(A | B) = 1 - Pr(A \cap B)$ (5.5)

根据此属性，条件概率就像概率函数一样遵循补集公理。它可以使用我们的条件概率定义，以高阶逻辑表示，如下：

### 定理 5.8

```
|- \/ A B p. (prob_space p) /\ (A IN events p) /\ (COMPL A IN events p) /\
(B IN events p) /\ (0 < (prob p B)) ==>
(cond_prob p (COMPL A) B = 1 - cond_prob p A B)
```

证明主要基于概率加法定律，因为事件 A 和 COMPL A 是不相交的。

## 5.4.4 条件概率差集公理

$Pr(A1 - A2 | B) = Pr(A1 | B) - Pr(A1 \cap A2 | B)$ (5.6)

此属性允许我们在不使用集合差概念的情况下，表示给定其他事件 B 时事件 A1 - A2（集合 A1 和 A2 之间的差）的概率。它可以以高阶逻辑表示，如下：

### 定理 5.9

```
|- \/ A1 A2 B p. (prob_space p) /\ (A1 IN events p) /\ (A2 IN events p) /\
(B IN events p) ==>
(cond_prob p (A1 DIFF A2) B =
cond_prob p A1 B - cond_prob p (A1 INTER A2) B)
```

该属性使用概率加法定律以及一些集合论推理进行验证。

## 5.4.5 条件概率并集公理

$Pr (A_1 \cup A_2 | B) = Pr (A_1 | B) + Pr (A_2 | B) - Pr (A_1 \cap A_2 | B)$ (5.7)

此属性允许我们在不使用并集概念的情况下，表示给定其他事件 B 时事件 $A_1 \cup A_2$（集合 A1 和 A2 的并）的概率。它可以使用我们的条件概率定义，以高阶逻辑表示。

### 定理 5.10

```
|- ∀A1 A2 B p. (prob_space p) ∧ (A1 IN events p) ∧ (A2 IN events p) ∧
(B IN events p) ⇒
(cond_prob p (A1 UNION A2) B =
(cond_prob p A1 B) + (cond_prob p A2 B) - (cond_prob p (A1 INTER A2) B))
```

证明再次主要基于概率加法定律。

## 5.4.6 概率乘法法则

$Pr (A \cap B) = Pr (B) Pr (A | B)$ (5.8)

概率乘法法则有时也称为复合概率定理，对于确定两个事件 A 和 B 同时发生的概率非常有用。它可以以高阶逻辑表示，如下：

### 定理 5.11

```
|- ∀p A B. (prob_space p) ∧ (A IN events p) ∧ (B IN events p) ⇒
(prob p (A INTER B) = (prob p B) * (cond_prob p A B))
```

上述属性的证明基于条件概率定义以及如果事件 B 的概率为 0 则 (A ∩ B) 的概率也为 0 这一事实。

## 5.4.7 全概率公式

对于事件的有限、互斥且穷尽序列 B_i 和事件 A，

$Pr(A) = \sum_{i=1}^m Pr(B_i) Pr(A | B_i)$

全概率公式是将概率计算分解为若干不同情况的有用工具。它可以以高阶逻辑表示，如下：

### 定理 5.12

```
|- ∀p A B s . (prob_space p) ∧ (A IN events p) ∧ FINITE s ∧
(∀x . x IN s ⇒ B x IN events p) ∧
(∀a b. a IN s ∧ b IN s ∧ ~(a = b) ⇒ DISJOINT (B a) (B b)) ∧
(BIGUNION (IMAGE B s) = p_space p) ⇒
(prob p A = SIGMA (λi. (prob p (B i)) * (cond_prob p A (B i))) s)
```

上述定理中的变量 A 表示一个事件，而 B 表示一组集合序列。与 BIGUNION 相关的假设确保序列 B 的元素是穷尽的，即它们的并给出样本空间或全集。此外，根据另一个假设，序列 B 中的集合也是互斥的。上述定理等式的右边表示使用 HOL4 函数 SIGMA 对实数序列 (λi. Pr(B_i) * Pr(A | B_i)) 的前 m 项求和。

上述定理的证明基于概率加法公理以及一些集合论原理。

## 5.4.8 贝叶斯法则

$Pr(A | B) = \frac{Pr(B | A) Pr(A)}{Pr(B)}$

贝叶斯法则以著名的英国哲学家托马斯·贝叶斯命名，关联两个随机事件的条件概率和边缘概率。在概率分析中，给定某些观测下的后验概率通常使用贝叶斯法则计算。它可以以一般形式表示，如下：

$Pr(A | B) = \frac{Pr(B | A_i) Pr(A_i)}{\sum_{i=1}^m Pr(B | A_i) Pr(A_i)}$

它可以在 HOL4 中形式化为以下高阶逻辑定理：

### 定理 5.13

```
|- ∀p A B s k. (prob_space p) ∧ (A IN events p) ∧ FINITE s ∧
(∀x . x IN s ⇒ B x IN events p) ∧
(∀a b. a IN s ∧ b IN s ∧ ~(a = b) ⇒ DISJOINT (B a) (B b)) ∧
(BIGUNION (IMAGE B s) = p_space p) ⇒
(cond_prob p (B k) A = ((cond_prob p A (B k)) * prob p (B k)) /
(SIGMA (λi. (prob p (B i)) * (cond_prob p A (B i))) s))
```

上述定理在 HOL4 中的证明基于概率乘法法则和全概率公式。

条件概率是最广泛使用的概率分析概念之一。当有关实验结果的部分信息可用时，它允许我们估计概率。本节介绍了可用于在高阶逻辑定理证明器中推理条件概率的基础形式化。马尔可夫链是物理学、排队论、互联网应用和统计测试等领域中最常用的概率建模理论之一。马尔可夫链的基本定义基于条件概率的概念，因此上述形式化可以在此基础上构建，以在定理证明器中开发表示和分析马尔可夫链的基础设施。本节介绍的形式化基础设施也可以直接用于分析许多有趣的应用，例如通信信道、用于计算问题（如最佳奖品问题）的算法以及硬件设计的故障检测方案。

## 5.5 结论

在本章中，我们使用测度论和勒贝格信息论的形式化，为概率论的主要概念提供了高阶逻辑形式化。我们形式化了概率空间和随机变量的基本定义及其统计属性。这些基础概念将在下一章中用于形式化马尔可夫链和信息论。

还有其他一些概率论形式化，但与 Mhamdi (2013) 提出的形式化相比，在某些方面有些局限。例如，Coble (2010) 的形式化仅考虑有限值测度和函数，因为它基于标准实数。在形式化中使用扩展实数（如 (Mhamdi, 2013) 所做的那样）有许多优势。它允许我们定义σ-有限和其他无限测度以及有符号测度。它还允许定义扩展实数值函数。同样，(Hölzl, 2011; Hölzl, 2013) 报告的概率论形式化缺少拉登-尼科迪姆导数、库尔贝克-莱伯散度和不同信息度量等重要属性。它未被用于形式化任何可靠性或无线传感器网络概念。此外，它也不处理有符号测度或取负值的函数，因为仅支持正扩展实数。因此，Mhamdi (2013) 提出的形式化更为通用，并被选为本手稿的主要关注点。
