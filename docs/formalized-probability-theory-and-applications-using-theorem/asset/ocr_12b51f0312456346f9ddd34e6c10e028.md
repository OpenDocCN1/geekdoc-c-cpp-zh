The main motivation of the current work is to provide an accurate approach for the probabilistic performance evaluation of the k-set randomized scheduling algorithm for wireless sensor networks. Indeed, due to the inherent randomness of the studied scheduling approach coupled with the random deployment of nodes, the analysis of such algorithm becomes very challenging for all possible cases. Rigorous performance evaluation of such algorithm is hence a non-trivial task, especially given the non-exhaustive nature of classical performance analysis techniques. This chapter presents a higher-order-logic theorem prover based approach for the formalization of the k-set randomized scheduling within the sound core of the HOL theorem prover. In Section 13.3, we have been able to formally develop the foundational formalisms of the k-set randomized scheduling algorithm, upon which we have built accurate formalizations of the network coverage intensity. The practical usefulness of our approach is shown, in Section 13.4, to analyze a WSN for forest fire detection, using the k-set randomized scheduling algorithm. Due to the undecidable nature of higher-order logic, the HOL development consumed about 730 lines of code. On the other hand, the formal analysis of our application took only 200 lines of HOL code
