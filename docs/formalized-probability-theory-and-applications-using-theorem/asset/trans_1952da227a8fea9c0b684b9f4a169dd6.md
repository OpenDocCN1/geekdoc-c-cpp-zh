

函数 rel_list 接受概率空间 p、表示组件失效时间的随机变量列表，以及一个实数 x，该实数表示希望获取可靠性的时间索引。使用定义 2，它返回在时间 x 时，随机变量列表中给定失效时间的组件正常工作所对应的可靠性列表。

最常用的 RBD 配置包括串联、并联及两者的组合。在本章中，我们介绍了串联、并联、串-并联和并-串联 RBD 配置的形式化。这些形式化配置随后可用于在 HOL4 中正式建模系统行为，并推理其可靠性、可用性、可依赖性和可维护性特性。

## 12.4.1 串联可靠性框图

如图 1 所示，组件串联连接的系统的可靠性主要取决于所有组件中可靠性最低的组件的可靠性。换句话说，如果其任何一个组件失效，系统将不再正常工作。因此，我们可以说，只有当系统的所有组件在时间 t 时都可靠运行时，系统在时间 t 时才可靠。如果 A_i(t) 是表示时间 t 时第 i 个组件可靠运行的事件，那么对于具有 N 个组件的串联系统，在时间 t 时完整系统的总体可靠性可以用数学表达为：

$R_{series}(t) = Pr(A_1(t) \cap A_2(t) \cap A_3(t) \dots \cap A_N(t))$ (12.7)

串联系统各个可靠性事件的相互独立性条件允许我们将上述表达式简化如下：

$R_{series}(t) = \prod_{i=1}^{N} R_i(t)$ (12.8)

### 定义 12.6

```
∀ p L, series_struct p L = inter_set p L
```

函数 rel_series 接受给定系统各个组件失效对应的事件列表 L 和概率空间 p，并通过使用表 12.1 中给出的交集函数 inter_set 返回完整系统的可靠性。基于此函数定义，我们正式验证了方程 (12.8) 的结果，作为以下定理：

### 定理 12.9

```
∀ p L x. prob_space p ∧
(events p = POW (p_space p)) ∧ 0 ≤ x ∧
1 ≤ LENGTH (rel_event_list p L x) ∧
mutual_indep p (rel_event_list p L x) ⇒
(prob p (series_struct p (rel_event_list p L x)) =
list_prod (rel_list p L x))
```

前两个假设确保 p 是基于 HOL4 概率理论形式化的有效概率空间。下一个假设确保建模时间的变量 x 始终大于或等于 0。接下来的两个假设保证，表示各个组件可靠性的事件列表必须至少包含两个互斥事件（或具有两个或更多组件的系统）。定理的结论表示方程 (12.8)。定理 12.9 的证明涉及各种概率理论公理、事件的相互独立性，以及函数 rel_event_list 返回列表中任何事件的概率等同于其可靠性这一事实。

基于事件的相互独立性和一些概率理论公理，上述方程可以简化为：

\( R_{parallel}(t) = 1 - \prod_{i=1}^{N} (1 - R_i(t)) \) (12.10)

现在，并联结构系统的可靠性可以正式定义为：

### 定义 12.7

```
⊢ ∀ L . parallel_struct L = union_list L
```

其中，函数 union_list 按如下方式执行一组集合的并集：

### 定义 12.8

```
⊢ ∀ p. union_list [] = {}
∀ h t. union_list (h::t) =
h ∪ (union_list t)
```

### 定理 12.10

```
|- ∀ L p x. (prob_space p) ∧
   (events p = POW (p_space p)) ∧
   (∀ x' . MEM x' (rel_event_list p L x) ⇒ x' ∈ events p) ⇒
   (prob p (parallel_struct (rel_event_list p L x)) =
    1 - prob p (inter_list p (compl_list p
    (rel_event_list p L x)))
```

基于上述定义，我们首先正式验证了以下结果，该结果提供了用串联结构表示并联结构的替代表达式（定理 12.10），其中函数 compl_list 递归地返回一个事件列表，使得该列表的每个元素都是概率空间 p 与给定列表中对应元素的差，如下所示：

### 定义 12.9

```
|- ∀ p. compl_list [ ] = [ ] ∧
∀ p h t. compl_list p (h::t) =
(p_space p DIFF h):: compl_list p t
```

现在，使用先前验证的定理，我们在 HOL4 中正式验证了时间 t 时并联结构的可靠性，作为定理 12.11。

### 定理 12.11

```
|- ∀ p L x. (prob_space p) ∧
   (events p = POW (p_space p)) ∧
   (0 ≤ x) ∧ (2 ≤ LENGTH L) ∧
   (mutual_indep p
   (rel_event_list p L x)) ∧
   (∀ x' . MEM x' (rel_event_list p L x) ⇒ x' ∈ events p) ⇒
   prob p (parallel_struct
   (rel_event_list p L x)) =
   1 - list_prod (one_minus_list
   (rel_list p L x)))
```

该定理在与定理 12.9 相同的假设下得到验证。定理的结论使用定义 12.5 和 12.7 以及函数 one_minus_list 表示方程 (5)，该函数接受一组实数 [ x1, x2, x3, ..., xn ] 并返回一组实数，使得该列表的每个元素都是给定列表中对应元素的 1 减去该元素，即 [ 1 - x1, 1 - x2, 1 - x3, ..., 1 - xn ]。

## 12.4.3 并-串联可靠性框图

现实世界中大多数安全关键系统都包含许多用于备份和确保可靠运行的预留子阶段。如果这些预留子系统中的组件串联连接，则该结构称为并-串联结构，如图 3 所示。并-串联 RBD 用于建模此类复杂结构。如果 Aj 是表示在第 i 个子系统中连接的第 j 个组件的可靠性的事件，那么完整系统的可靠性可以用数学表达如下：

$R_{Parallel-Series} = Pr(\bigcup_{i=1}^M \bigcap_{j=1}^N A_{ij})$ (12.11)

通过使用事件的相互独立性和一些基本概率理论公理，上述方程可以简化为

$R_{Parallel-Series} = 1 - \prod_{i=1}^M (1 - \prod_{j=1}^N (R_{ij}(t)))$ (12.12)

### 定义 12.11
