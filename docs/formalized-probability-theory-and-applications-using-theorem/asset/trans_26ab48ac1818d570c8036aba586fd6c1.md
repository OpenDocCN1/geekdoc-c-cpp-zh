

设 A 为空间 X 的子集集合（或子集类）。现在，可以在 HOL4 中定义一个谓词（即输出类型为布尔值的函数）subset_class，用于测试 A 是否为 X 的子集类。

## 定义 4.7

```
⊢ ∀ X A. subset_class X A = ∀ s. s ∈ A ⇒ s ⊆ X
```

如果一个集合的元素可以逐个计数，换句话说，如果存在一个满射函数 f : N → s，使得集合 s 的每个元素都可以与一个自然数关联，则该集合称为可数集。这在 HOL4 中形式化为：

## 定义 4.8

```
⊢ ∀ s. countable s = ∃ f. ∀ x. x ∈ s ⇒ ∃ (n: num). f n = x
```

现在，空间 X 的一个子集集合 A（或子集类）在 X 上定义一个 σ-代数，当 A 包含空集 ∅，并且在空间 X 内关于可数并和补集运算下封闭时。

## 定义 4.9

```
⊢ ∀ X A. sigma_algebra (X, A) =
subset_class X A ∧ { } ∈ A ∧
(∀ s. s ∈ A ⇒ X \ s ∈ A) ∧ ∀ c. countable c ∧ c ⊆ A ⇒
∪ c ∈ A
```

其中 X\s 表示 s 在 X 内的补集，∪c 即 c 中所有元素的并集。对 (X, A) 称为 σ-场或可测空间，A 是可测集的集合。现在，空间和子集函数可按定义 4.9 和 4.10 所示定义。

## 定义 4.10

```
⊢ ∀ X A. space (X, A) = X
```

## 定义 4.11

```
⊢ ∀ X A. subsets (X, A) = A
```

空间 X 上 σ-代数的平凡示例包括空集，它是 X 上最小的 σ-代数，以及 X 的幂集 P(X)，它由 X 的所有子集组成，是 X 上最大的 σ-代数。对于 X 的任何子集集合 G，我们可以构造 σ(X, G)，即包含 G 的 X 上最小的 σ-代数。σ(X, G) 称为由 G 在 X 上生成的 σ-代数。在 X 上至少存在一个包含 G 的 σ-代数，即 X 的幂集。σ(X, G) 是所有这些 σ-代数的交集。由 G 在 X 上生成的 σ-代数在 HOL4 中形式化为：

## 定义 4.12

```
⊢ ∀ X G. sigma X G = (X, ∩ { s | G ⊆ s ∧ sigma_algebra (X, s) })
```

其中 ∩c 表示 c 中所有元素的交集。

三元组 (X, A, μ) 称为度空间，当 (X, A) 是可测空间且 μ: A → R 是一个非负可数加度量函数时。

## 定义 4.13

```
⊢ ∀ X A μ. p.measure_space (X, A, μ) =
sigma_algebra (X, A) ∧ positive (X, A, μ) ∧
countably_additive (X, A, μ)
```

当可数个两两不相交可测集的并的度量等于它们各自度量之和时，度量函数称为可数加性。可数加性属性在 HOL4 中形式化为：

## 定义 4.14

```
⊢ ∀ X A μ. p.countably_additive (X, A, μ) =
∀ f. f ∈ (UNIV → A) ∧
(∀ m n. m ≠ n ⇒ DISJOINT (f m) (f n)) ∧
∪ (IMAGE f UNIV) ∈ A ⇒
μ o f sums μ (∪ (IMAGE f UNIV))
```

在此定义中，子集的可数并通过函数 f 的定义域（即自然数集 UNIV (num)）和 f 的值域（即可测集集合 A）来捕获。若序列 μ(f(n)) 收敛于 μ(∪ₙ f(n))，则函数 μ 为可数加性。

在 HOL4 的度量理论形式化中，还提供了一些方便的辅助函数 m_space、measurable_sets 和 measure，它们以度空间为参数并返回相应的分量，如下所示：

## 定义 4.15

```
⊢ ∀ X A μ. m_space (X, A, μ) = X
```

## 定义 4.16

```
⊢ ∀ X A μ. measurable_sets (X, A, μ) = A
```

## 定义 4.17

```
⊢ ∀ X A μ. measure (X, A, μ) = μ
```

可测函数是结构保持的，即它们每个可测集的逆像也是可测的。这类似于度量空间中的连续函数，其中开集的逆像是开集。设 (X₁, A₁) 和 (X₂, A₂) 为两个可测空间。函数 f: X₁ → X₂ 称为相对于 (A₁, A₂) 可测，当对于所有 A ∈ A₂，有 f⁻¹(A) ∈ A₁。

## 定义 4.18

```
⊢ ∀ a b. f ∈ measurable a b =
sigma_algebra a ∧ sigma_algebra b ∧ f ∈ (space a → space b) ∧
∀ s. s ∈ subsets b ⇒ PREIMAGE f s ∩ space a ∈ subsets a
```

HOL4 函数 PREIMAGE 表示函数的逆像。请注意，与定义 4.17 不同，形式化中的逆像需要与空间 a 相交，因为 HOL4 中的函数是全函数，即它们将某个 HOL4 类型的每个值（甚至空间 a 外部的值）映射到适当类型的某个值，该值可能在空间 b 中，也可能不在。换句话说，在 HOL4 中写出 f 是从空间 a 到空间 b 的函数，并不排除空间 a 外部的值，因此需要求交。需要注意的是，在此定义中，未指定可测空间上的任何结构。如果考虑一个在度量空间上取值的函数 f，最常见的是实数集或复数集，则使用该空间上的 Borel σ-代数。在以下内容中，我们将介绍在 HOL 中对 Borel σ-代数的形式化。

使用 Borel σ-代数使可测函数集成为一个向量空间。它还便于验证在 HOL 中形式化勒贝格积分所需的各种可测函数属性。空间 X 上的 Borel σ-代数是由 X 的开集生成的最小 σ-代数。它可以使用 sigma 函数如下定义：

## 定义 4.19

```
⊢ ∀ X. borel X = sigma X (open_sets X)
```

一个重要示例，尤其是在概率论中，是 R 上的 Borel σ-代数，记为 B(R)，通常也称为 Borel。

## 定义 4.20

```
⊢ Borel = sigma UNIV (: real) (open_sets UNIV)
```

其中 UNIV 是实数集 R 的全集。显然，基于开集的 Borel σ-代数形式化需要形式化 R 的一些拓扑概念。此外，还需要形式化有理数集 Q，以验证 B(R) 的各种属性。

有理数可以表示为两个整数的商，分母为正数。HOL4 中的自然数用于表示 Q，即有理数集，作为非负（Q+）和非正（Q-）有理数的并集。

## 定义 4.21

```
⊢ Q = { r | ∃ n, m. r = n/m ∧ m > 0 } ∪ { r | ∃ n, m. r = -n/m ∧ m > 0 }
```

关于集合 Q 的大量令人放心的属性以及另外一些不太直观的属性，即 Q 是可数的、无限的且在 R 中稠密，已在 HOL 中得到正式验证。

定义 R 上的 Borel σ-代数的第二个主要要求是形式化 R 中的邻域和开集拓扑概念。设 a ∈ A ⊂ R。如果存在实数 d > 0，使得 ∀ x. |x - a| < d ==> x ∈ A，则 A 是 a 的邻域。换句话说，a 是 A 的内点。

## 定义 4.22

```
⊢ ∀ A a. neighborhood A a = ∃ d. 0 < d ∧ ∀ y. a - d < y ∧ y < a + d ==> y ∈ A
```

如果集合的每个点都是内点，则该集合是开集。

## 定义 4.23

```
⊢ ∀ A. open_set A = ∀ x. x ∈ A ==> neighborhood A x
```

基于上述形式化，与开集相关的以下属性已在 HOL 中得到验证。

- 空集和全集是开集。
- 每个开区间都是开集。
- 任何开集族的并是开集。
- 有限个开集的交是开集。
- R 中的每个开集是可数个开区间的并。
- 连续函数下开集的逆像是开集。

在 HOL4 的度量理论形式化中验证的另一个非常有用的属性是，实直线上的 Borel σ-代数 B(R) 由开区间（c, d ∈ R 的 [c, d[）生成。该属性实际上在许多教科书中被用作 R 上 Borel σ-代数的起始定义。

## 定理 4.2

```
⊢ Borel = sigma UNIV (open_intervals set)
```

还可以在 HOL4 中验证，B(R) 由以下任一区间类生成：]-∞, c[、[c, +∞[、]c, +∞[、]-∞, c[、[c, d[、[c, d]、]c, d[，其中 c, d ∈ R。要证明此结果，只需证明任何区间 ]c; d[ 都包含在每个类对应的 σ-代数中。对于 [c, d[ 类型的区间，这源自方程 [c, d[ = ∪ₙ (c + 1/n², d[。对于开射线 ]-∞, c[，结果源自 [a, b[ 可以写成两个射线的差，即 [a, b[ = ]-∞, b[ \ ]-∞, a[。类似地，还可以在 HOL4 中验证上述所有区间类生成 R 上的 Borel σ-代数。另一个有用的结果断言，单点集是 B(R) 的可测集。

## 定理 4.3

```
⊢ ∀ c:real. { c } ∈ subsets Borel
```

该定理的证明源于 σ-代数关于可数交封闭的事实以及以下方程。

∀ c ∈ R. {c} = ∩ₙ [c - 1/2ⁿ, c + 1/2ⁿ] (4.1)

回顾，要检查函数 f 是否相对于 (A₁, A₂) 可测，需要检查对于任何 A ∈ A₂，其逆像 f⁻¹(A) ∈ A₁。对于实值函数，只需在开射线 ((-∞, c), c ∈ R) 上进行检查，即，设 (X, A) 为可测空间。函数 f : X → R 相对于 (A, B(R)) 可测，当 ∀ c ∈ R, f⁻¹((-∞, c)) ∈ A。
