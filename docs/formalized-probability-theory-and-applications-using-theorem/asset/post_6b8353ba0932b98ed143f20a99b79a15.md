
## Theorem 4.4

```
\vdash f \in measurable a Borel =
sigma_algebra a \land f \in (space a \rightarrow UNIV) \land
\forall c. {x | f x < c} \cap space a \in subsets a
```

In the proof of this theorem, suppose that f is measurable with respect to (A, B(R)), we showed in the previous section that \(\forall c \in R, ]-\infty, c[ \in B(R)\). Since f is measurable then \(f^{-1}(]-\infty, c[) \in A\). Now suppose that \(\forall c \in R, f^{-1}(]-\infty, c[) \in A\), we need to prove \(\forall A \in B(R), f^{-1}(A) \in A\). This follows from the properties of open sets stating that A is a countable union of open intervals and the equalities \(f^{-1}(\cup_{n \in N} A_n) = \cup_{n \in N} f^{-1}(A_n)\) and \(f^{-1}(]-\infty, c[) = \cup_{n \in N} f^{-1}(]-n, c[)\).

Similarly, it has also been verified in the HOL4 formalization of measure theory that f is measurable with respect to (A, B(R)) iff \(\forall c, d \in R\) the inverse image of any of the following classes of intervals is an element of A: \(]-\infty, c[\), \([c, +\infty[\), \(]c, +\infty[\), \(]-\infty, c[\), \([c, d[\), \(]c, d[\), \([c,d]\). Every constant real function on a space X is measurable. The indicator function on a set A is measurable iff A is measurable.

Various other useful properties of the real-valued measurable functions that have been verified in the HOL4 formalization of measure theory are described below.

If f and g are (A, B(R)) measurable and \(c \in R\) then c f, |f|, f^n, f + g, f * g and max (f, g) are (A, B(R)) measurable.

## Theorem 4.5

```
\vdash \forall a f g h c.
sigma_algebra a \land
f \in measurable a Borel \land
g \in measurable a Borel \Rightarrow
((\lambda x. c * f x) \in measurable a Borel) \land
((\lambda x. Abs (f x)) \in measurable a Borel) \land
((\lambda x. f x pow n) \in measurable a Borel) \land
((\lambda x. f x + g x) \in measurable a Borel) \land
((\lambda x. f x * g x) \in measurable a Borel) \land
((\lambda x. max (f x) (g x)) \in measurable a Borel)
```

The notation \((\lambda x. f x)\) is the lambda notation of f, used to represent the function f: x \rightarrow f(x).

If (f_n) is a monotonically increasing sequence of extended-real-valued measurable functions with respect to (A, B(R)), such that \(\forall x, f(x) = \sup_{n \in N} f_n(x)\), then f is also (A, B(R)) measurable.


Every continuous function g: R->R is (B(R), B(R)) measurable.

## Theorem 4.7

```
|- \forall g. (\forall x. g contl x) \implies g \in measurable Borel Borel
```

If g: R->R is continuous and f is (A, B(R)) measurable then g o f is also (A, B(R)) measurable.

## Theorem 4.8

```
|- \forall a f g. sigma_algebra a \land f \in measurable a Borel \land
(\forall x. g contl x) \implies g o f \in measurable a Borel
```

Theorem 4.7 is a direct result of the theorem stating that the inverse image of an open set by a continuous function is open. Theorem 4.8 guarantees, for instance, that if f is measurable then exp (f), Log (f), cos (f) are measurable. This is derived using Theorem 4.7 and the equality \((g \circ f)^{-1} (A) = f^{-1} (g^{-1} (A))\).

Now, the products of measure spaces can also be formalized in order to be able to formalize measurable functions defined over product spaces. Let m1 = (X1, S, \mu_1) and m2 = (X2, S_2, \mu_2) be two measure spaces. The product of m1 and m2 is defined to be the measure space (X1 x X2, S, \mu), where S is the sigma algebra on X1 x X2 generated by subsets of the form A1 x A2 where \(A_1 \in S\), \(A_2 \in S_2\). The measure \mu is defined for \sigma-finite measure spaces as

```
\mu(A) = \int_{X1} \mu_2(\{y \in X_2 | (x,y) \in A\}) d\mu_1 (4.2)
```

and S is defined using the sigma operator which returns the smallest sigma algebra containing a set of subsets, i.e., the product subsets in this case. Let g(s1) be the function s2 -> (s1, s2) and PREIMAGE denote the HOL function for inverse image, then the product measure is formalized.

## Definition 4.24

```
⊢ ∀ m1 m2. prod_measure m1 m2 =
(λ a. integral m1 (λ s1. measure m2 (PREIMAGE g(s1) a)))
```

The integral in this definition is the Lebesgue integral for which we present the formalization in the next section. Now it can be verified in HOL4 that the product measure can be reduced to \(\mu(a_1 \times a_2) = \mu_1(a_1) \times \mu_2(a_2)\) for finite measure spaces.

## Theorem 4.9

```
⊢ prod_measure m1 m2 (a1 x a2) = measure m1 a1 x measure m2 a2
```

The above definition can be used to define products of more than two measure spaces as follows. X1 x X2 x X3 = X1 x (X2 x X3) and \(\mu_1 \times \mu_2 \times \mu_3\) is defined as \(\mu_1 \times (\mu_2 \times \mu_3)\). The notion of absolutely continuous measures is also defined in HOL4 where \(\mu_1\) is said to be absolutely continuous w.r.t \(\mu_2\) iff for every measurable set A, \(\mu_2 (A) = 0\) implies \(\mu_1 (A) = 0\).

## 4.3 FORMALIZATION OF LEBESGUE INTEGRATION IN HOL

Lebesgue integration is a fundamental concept in many mathematical theories, such as real analysis (Goldberg, 1976) and probability (Halmos, 1944), which are widely used to model and reason about the continuous and unpredictable components of physical systems. The reasons for its extensive usage, compared to the commonly known Riemann integral, include the ability to handle a broader class of functions, which are defined over more general types than the real line, and its better behavior when it comes to interchanging limits and integrals, which is of prime importance, for instance, in the study of Fourier series.

Similar to the way in which step functions are used in the development of the Riemann integral, the Lebesgue integral makes use of a special class of functions called positive simple functions. They are measurable functions taking finitely many values. In other words, a positive simple function g is represented by the triple (s, a, α) as a finite linear combination of indicator functions of measurable sets (aⱼ) that form a partition of the space X.

```
∀ x∈ X, g(x) = Σₖ αₖ I_{Aₖ}(x) αᵢ ≥ 0 (4.3)
```

We also add the condition that positive simple functions take finite values, i.e., \(\forall i \in s, \alpha_i < \infty\). Their Lebesgue integral can however be infinite. The Lebesgue integral is first defined for these functions and the definition is then extended to non-negative functions and finally to arbitrary functions

Let \((X, \mathcal{A}, \mu)\) be a measure space. The integral of the positive simple function g with respect to the measure \(\mu\) is defined as

\(\int_X g d\mu = \sum_{i \in s} \alpha_i \mu(a_i)\) (4.4)

This is formalized in HOL4:

## Definition 4.25

```
\(\vdash \forall m s a \alpha. \text{pos\_simple\_fn\_integral m s a} \alpha =\)
\(\text{SIGMA } (\lambda i. \alpha_i * \text{measure m (a i)}) s\)
```

While the choice of \(((\alpha), (a), s)\) to represent g is not unique, the integral as defined above is independent of that choice. Several properties of the Lebesgue integral of positive simple functions such as the linearity and monotonicity have been verified. These results can be extended to be used for the definition in which the Lebesgue integral is an extended-real valued integral.

The definition of the Lebesgue integral of positive simple functions can be used to define the integral of non-negative measurable functions using the supremum operator as follows:

\(\int_X f d\mu = \sup \{ \int_X g d\mu | g \le f \text{ and } g \text{ positive simple function } \}\) (4.5)

It can be formalized in HOL4 as follows:

## Definition 4.26

```
\(\vdash \forall m f. \text{pos\_fn\_integral m f} =\)
\(\text{sup } \{ r | \exists g. r \in \text{psfis m g} \land \forall x. g x \le f x \}\)
```

where psfis m g is used to represent the Lebesgue integral of the positive simple function g. Finally, the integral for an arbitrary measurable function f is formalized in terms of the integrals of f^+ and f^- where f^+ and f^- are the non-negative functions defined by f^+(x) = max (f(x), 0) and f^-(x) = max (-f(x), 0).
