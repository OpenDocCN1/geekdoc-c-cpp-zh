
The function rel_list accepts a list of probability space p, random variables, representing the failure times of components, and a real number x, which represents the time index at which the reliability is desired. Using Definition 2, it returns a list of reliabilities corresponding to the proper functioning of the components, for whom the failure times are given in the list of random variables, at time x.

The most commonly used RBD configurations include series, parallel and a combination of both. In this chapter, we present the formalization of series, parallel, series-parallel and parallel-series RBD configurations. These formalized configurations can then be used in turn to formally model systems behaviors in HOL4 and reason about their reliability, availability, dependability and maintainability characteristics.

## 12.4.1 Series Reliability Block Diagram

The reliability of a system with components connected in series, depicted in Figure 1, mainly depends upon the reliability of a component that has minimum reliability among all the components. In other words, the system is no longer functional if any one of its component fails. Thus, we can say that the system will be reliable at time t only if all of its components are functioning reliably at time t. If A_i(t) is an event that represents the reliable functioning of the i^th component at time t then a serially connected system with N components at time t then the overall reliability of the complete system can be expressed mathematically as:

$R_{series}(t) = Pr(A_1(t) \cap A_2(t) \cap A_3(t) \dots \cap A_N(t))$ (12.7)

The mutual independence condition of individual reliability events of a series system allows us to simplify the above expression as follows:

$R_{series}(t) = \prod_{i=1}^{N} R_i(t)$ (12.8)

The function rel_series takes a list of events L corresponding to the failure of individual components of the given system and the probability space p and returns the reliability of the complete system by using the intersection function inter_set, given in Table 12.1. Based on this function definition, we formally verified the result of Equation (12.8) as the following theorem:

### Theorem 12.9

```
∀ p L x. prob_space p ∧
(events p = POW (p_space p)) ∧ 0 ≤ x ∧
1 ≤ LENGTH (rel_event_list p L x) ∧
mutual_indep p (rel_event_list p L x) ⇒
(prob p (series_struct p (rel_event_list p L x)) =
list_prod (rel_list p L x))
```

The first two assumptions ensure that p is a valid probability space based on the probability theory formalisation of HOL4. The next assumption ensures that the variable x, which models time, is always greater than or equal to 0. The next two assumptions guarantees that the list of events, representing the reliability of individual components, must have at least two mutually exclusive events (or a system having two or more components). The conclusion of the theorem represents Equation (12.8). The proof of Theorem 12.9 involves various probability theory axioms, the mutual independence of events and the fact that the probability of any event that is in the returned list from the function rel_event_list is equivalent to its reliability.

## 12.4.3 Parallel-Series Reliability Block Diagram

Most of the safety-critical systems in the real-world contain many reserved sub-stages for backup and ensuring reliable operation. If components in these reserved subsystems are connected serially then the structure is termed as a parallel-series structure, depicted in Figure 3. The parallel-series RBD is used to model such complex structures. If Aj is the event corresponding to the reliability of the jth component connected in a ith subsystem, then the reliability of the complete system can be expressed mathematically as follows:

$R_{Parallel-Series} = Pr(\bigcup_{i=1}^M \bigcap_{j=1}^N A_{ij})$ (12.11)

By using the mutual independence of events and some basic probability theory axioms, the above equation can be simplified to

$R_{Parallel-Series} = 1 - \prod_{i=1}^M (1 - \prod_{j=1}^N (R_{ij}(t)))$ (12.12)

```
|- ∀ p L. list_inter_set p L =

```

The list_inter_set function takes a list of list L and probability space p and returns a list by mapping the inter set function on every element of the given list of list.

The functions list_prod and rel_list are used to model the product of reliabilities and the events corresponding to the component functioning reliably at the desired time x, respectively.
