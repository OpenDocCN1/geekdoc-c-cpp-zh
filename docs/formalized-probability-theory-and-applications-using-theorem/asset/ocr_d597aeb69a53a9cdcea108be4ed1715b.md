# **Definition 4.16**

```
⊢ ∀ X A μ. measurable_sets (X, A, μ) = A
```

# **Definition 4.17**

```
⊢ ∀ X A μ. measure (X, A, μ) = μ
```

Measurable functions are structure preserving, i.e., the inverse image of each one of their measurable set is also measurable. This is analogous to continuous functions in metric spaces where the inverse image of an open set is open. Let (X1, A1) and (X2, A2) be two measurable spaces. A function f: X1 → X2 is called measurable with respect to (A1, A2) if f⁻¹(A) ∈ A1, for all A ∈ A2.

# **Definition 4.18**

```
⊢ ∀ a b. f ∈ measurable a b =
sigma_algebra a ∧ sigma_algebra b ∧ f ∈ (space a → space b) ∧
∀ s. s ∈ subsets b ⇒ PREIMAGE f s ∩ space a ∈ subsets a
```

The HOL4 function PREIMAGE denotes the inverse image of a function. Notice that unlike Definition 4.17, the inverse image in the formalization needs to be intersected with space a because the functions in HOL4 are total, meaning that they map every value of a certain HOL4 type (even those outside space a) to a value of an appropriate type which may or may not be in space b. In other words, writing in HOL4 that f is a function from space a to space b, does not exclude values outside space a and hence the intersection is needed. It is important to note that in this definition, any structure on the measurable spaces is not specified. If we consider a function f that takes its values on a metric space, most commonly the set of real numbers or complex numbers, then the Borel sigma algebra on that space is used. In the following, we present our formalization of the Borel sigma algebra in HOL.

Working with the Borel sigma algebra makes the set of measurable functions a vector space. It also facilitates the verification of various properties of the measurable functions necessary for the formalization of the Lebesgue integral in HOL. The Borel sigma algebra on a space X is the smallest sigma algebra generated by the open sets of X. It can be defined using the sigma function as follows:

# **Definition 4.19**

```
⊢∀X.borel X = sigma X (open_sets X)
```

An important example, especially in the theory of probability, is the Borel sigma algebra on R, denoted by B (R) which is also called Borel usually.
