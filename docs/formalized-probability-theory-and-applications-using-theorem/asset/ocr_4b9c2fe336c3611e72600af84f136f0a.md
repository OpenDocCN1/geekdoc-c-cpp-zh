The assumptions in the above theorem ensure that the sets in the sequence A are mutually exclusive. The set BIGUNION (IMAGE A (count n)) denotes the set { A | i \in N }, since the function BIGUNION takes the union of all sets in the set (IMAGE A UNIV). The right-hand side of the equality in the above theorem represents the infinite summation of the real sequence (\lambda i.Pr (Ai | B)) using the HOL4 function SIGMA. The proof of the above property is based on some already verified set theoretic principles and the additive law of probability.

# ## 5.4.3 Complement Axiom of Conditional Probability

$Pr(A | B) = 1 - Pr(A \cap B)$ (5.5)

According to this property, a conditional probability follows the complement axiom just like the probability function. It can be expressed in higher-order logic, using our conditional probability definition, as follows:

# ### Theorem 5.8

```
|- \/ A B p. (prob_space p) /\ (A IN events p) /\ (COMPL A IN events p) /\ 
(B IN events p) /\ (0 < (prob p B)) ==> 
(cond_prob p (COMPL A) B = 1 - cond_prob p A B)
```

The proof is primarily based on the probability additive law as the events A and COMPLA are disjoint.

# ## 5.4.4 Difference Axiom of Conditional Probability

$Pr(A1 - A2 | B) = Pr(A1 | B) - Pr(A1 \cap A2 | B)$ (5.6)

This property allows us to express the probability of an event A1 - A2 (difference between the sets A1 and A2) given some other event B without using the notion of set difference. It can be expressed in higher-order logic as follows:

# ### Theorem 5.9

```
|- \/ A1 A2 B p. (prob_space p) /\ (A1 IN events p) /\ (A2 IN 
events p) /\ (B IN events p) ==> 
(cond_prob p (A1 DIFF A2) B =
cond_prob p A1 B - cond_prob p (A1 INTER A2) B)
```
