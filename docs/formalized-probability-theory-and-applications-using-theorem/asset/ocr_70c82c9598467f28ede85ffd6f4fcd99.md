The list_list_exp function takes two lists, i.e., a two dimensional list of failure rates and random variables L, corresponding to the nodes at each stage of a parallel-series RBD. It calls the function list_exp recursively, to ensure that all the elements of the list L are exponentially distributed with the corresponding failure rates given in the other list within the probability space p.

Now, a generic expression for the reliability of any parallel series connected cyber network, can be verified in HOL4 as follows shown in Theorem 12.14 where c1 and c2 represent the failure rates of the source and target nodes, respectively, and the list C models the failure rates of the rest of the intermediate nodes. The first five assumptions of the above theorem are the same as the ones used in Theorem 12.13. The last two ensure that the length of the list containing the failure rates and the length of the random variable list must be the same and the exponential distributions of the nodes, connected in the parallel series network, are associated with their respective failure rates, respectively. The left-hand-side of the conclusion models the expression given in Equation (12.13). Whereas, the right-hand-side of the conclusion provides a simplified expression for the reliability evaluation of arbitrary-node cyber network with exponentially distributed failures. The expressions exp (-c1 * x) and exp (-c2 * x) model the reliability of the source and target nodes, respectively. The middle expression on the right-hand-side of the conclusion of Theorem 12.14 represents the overall reliability of the rest of the intermediate nodes, using the functions list_prod, one_minus_list, explained earlier, and list_exp_sum, which computes the negative exponential of the sums all the failure rates in each list of its lists argument and returns these exponential values as a list. For example, list_exp_sum [[ c1; c2; c3 ]; [c4; c5 ]; [ c6; c7; c8 ] x = [ exp -(c1 + c2 + c3) x; exp -(c4 + c5) x; exp -(c6 + c7 + c8) x ].
