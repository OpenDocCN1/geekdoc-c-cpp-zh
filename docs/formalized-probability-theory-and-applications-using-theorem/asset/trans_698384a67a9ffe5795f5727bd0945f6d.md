## 10.4.2 级联信道的信息流分析

为了分析最坏情况下的信息流，即A在一次猜测中恢复关键信息的情况，我们将先验分布建模为最大输入分布的函数，而后验行为则表示为在观察b时猜测a的分布在X上的最大值的函数。

```
leakage = Min-Entropy (X) - conditional Min-Entropy (X | Y)
```

```
IL∞ (X, Y) = H∞ (X) - H∞ (X | Y) (10.3)
```

现在，可以使用最小熵来评估级联信道中的泄漏量，相应的证明目标可以在HOL4中表示如下：

### 定理 10.9

设(X, Y, CX)为(X, Z, CXZ)和(Z, Y, CYZ)的级联。则有 IL∞ (X, Y) ≤ IL∞ (X, Z)

该定理可以在HOL4中表示为

```
⊢ ∀ p X Z Y f g.
    cascade_channel p X Z Y f g ∧
    FINITE (Q) ∧
    Q ≠ ∅ ∧
    events p = POW (Q) ∧
    ∀ x. 0 < distribution p Y ({x}) ∧
    ∀ x. 0 < distribution p Z ({x}) ∧
    (∀ x. x ∈ Q ⇒ ({x} ∈ events p) ∧
    Information_leakage p X Y ≤ information_leakage p X Z
```

利用一些代数简化，证明目标可以简化到脆弱性水平：

\( V^\infty (X | Y) \le V^\infty (X | Z) \) (10.4)

现在，利用级联的性质，我们得到

\( p (A = a | B = b) = \sum_c p (A = a, C = c) * p (B = b | C = c) \)

\(\le \sum_c \max_a p (A = a, C = c) * p (B = b | C = c) \) (10.5)

接下来，我们利用求和性质以及任何随机变量的条件分布在其第一状态空间上的和等于1这一事实，对上述子目标进行简化。

\( V (A | B) \le \sum_c \max_{a'} p (A=a, C=c) \) (10.6)

上述子目标现在可以基于代数简化进行验证。这结束了定理10.9的证明，该证明包含约850行HOL4代码。由于模型的形式化性质和机械定理证明者的可靠性，分析保证不存在近似和精度错误，因此获得的结果在数学上是精确的，并证实了基于纸笔的分析方法的结果。在级联信道行为的定义10.6中，转换函数f和g是提供通用结果的一般函数。在模型检查方法中，应指定参数和函数。此外，定理10.9中验证的结果可以使用归纳技术扩展到n个级联信道的信息泄漏最小熵分析。我们可以证明，n个级联信道的最小熵泄漏不会超过第一个信道的泄漏。验证此属性的关键是级联条件的定义。在数学上，我们可以将n个信道的连接表示如下。设X0为建模系统输入的随机变量，Xn为建模系统输出的随机变量，因此

$$ \forall i . (0 \le i \le n) \Rightarrow P(X_0, X_i) = \sum_{x_{i-1}} P(X_0, X_{i-1}) * P(X_i | X_{i-1}) $$

基于我们之前定义的内容和已有内容，该条件可以在HOL4中形式化为

```
⊢ ∀ X p f n. cascade_channel p X n f =
∀ i. (1 <= i <= n) ⇒ channel p (X (i - 1)) (X i) (f i) ∧
∀ x y i. joint_distribution p (X 0) (X i) (x, y) =
∑ z. joint_distribution p (X 0) (X (i - 1)) (x, z) *
conditional_distribution p (X (i - 1)) (X i) (z, y)
```

表达和验证针对所有变量值的通用属性的能力是定理证明的主要优势，如上述定义和与n个级联信道信息泄漏相关的属性所示。此属性是一项正在进行的任务，一旦验证，即可适用于任意数量的级联信道，并可特化以获取特定场景的表达式和值。概率模型检查作为另一种主流形式方法，由于固有的状态空间爆炸问题，无法提供此类通用结果。

## 10.5 结论

本章在高阶逻辑中提出了脆弱性、信念脆弱性、最小熵和信念最小熵的形式化。与基于Shannon熵的传统定量信息流定义相比，这些度量在某些边界情况下能提供更可靠的信息流分析。这种威胁模型的一个例子是：在给定可观察输出的情况下，对手可以在一次尝试中猜测秘密输入值。所提形式化可以用于在定理证明者的可靠内核中进行信息流分析，因此分析保证不存在近似和精度错误。为说明目的，我们使用HOL4定理证明者对两个信道的级联进行了信息流分析，分析结果被发现是通用且准确的。

所提高阶逻辑形式化可用于分析许多其他应用。我们特别旨在将其应用于Crowds协议（Reiter & Rubin, 1998）的正式信息流分析。此外，我们的工作可以扩展以反向方式分析信息流，即从特定的泄漏界限出发，相对于输出集评估输入集。该形式化可用于正式确保关键信息的特定安全级别。
