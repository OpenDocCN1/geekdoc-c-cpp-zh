**Definition 6.8**
|- V f X p s .
Stationary_dist f X p s =
(SIGMA (\l k. f k) (k \in space s) = 1) /\
V i. i \in space s ==>
0 <= f i i /\ (V t. f i t = SIGMA (\l k. f k * Trans X p s t l k I)
(k \in space s))

We then utilize this definition to prove the generalized stationary theorem, which says that if a DTMC with finite state space \(\Omega\) and one-step transition probability \(P_{ij}\) has a probability distribution \(\pi\) that satisfies the detailed balance equations, then there exists a stationary distribution for this DTMC.

**Theorem 6.5**
|- V X p s p0 pij n.
th_dtmc X p s p0 pij /\
db_equations (\l i. prob p { x | X n x = i }) X p s ==>
\exists f. stationary_dist f X p s

where f refers to \(\pi(x)\).
The proof of this property is done using the probability distribution function (
\l i. P { x | X n x = i }) as f, and thus the goal becomes:

|- V X p s p0 pij n.
th_dtmc X p s p0 pij /\
db_equations (\l i.P { x | X n x = i }) X p s ==>
stationary_dist (\l i.P { x | X n x = i }) X p s

This subgoal can be verified by rewriting with the definitions of the detailed balance equations and stationary distribution and splitting it in the following three subgoals, which can be verified based on probability theory foundations.

+   - 0 <= P { x | X n x = i }
+   - SIGMA (\l j. P { x | X n x = i } (j \in space s) = 1)
+   - P { x | X n x = i } =
+   - SIGMA (\l j. P { x | X n x = j } Trans X p s t j i) (j \in space s)
