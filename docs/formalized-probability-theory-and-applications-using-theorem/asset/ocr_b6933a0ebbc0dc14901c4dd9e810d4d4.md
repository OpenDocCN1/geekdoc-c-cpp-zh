```
|-Vp A B sk. (prob_space p) ∧ (A IN events p) ∧ FINITE s ∧

```

The proof of the above theorem in HOL4 is based on the multiplication rule of probability and the total probability theorem.

Conditional probability is one of the most widely used probabilistic analysis concepts. It allows us to estimate probabilities when some partial information concerning the result of the experiment is available. This section presents the foundational formalization that can be used to reason about conditional probabilities in a higher-order-logic theorem prover. Markov chains is one of the most commonly used probabilistic modeling theory in areas like Physics, Queueing Theory, Internet applications and statistical testing. The basic definition of a Markov chain is based on the concept of conditional probabilities and thus the above formalization can be built upon to develop an infrastructure for representing and analyzing Markov chains in a theorem prover. The formalization infrastructure, presented in this section, can also be used as is for the analysis of a number of interesting applications, such as communication channels, algorithms for computation problems like the Best Prize problem, and fault detection schemes for hardware designs.
