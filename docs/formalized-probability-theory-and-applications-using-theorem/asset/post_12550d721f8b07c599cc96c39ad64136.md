## 5.4 FORMALIZATION OF CONDITIONAL PROBABILITIES

The notion of conditional probability involves the probability of an event, say A, given the information that an event B has occurred. In order to understand usage of conditional probability, consider the example of an integrated circuit testing process where we test circuits in pairs. The concept of conditional probability allows us to compute the probability of correctness of two integrated circuits given that the first integrated circuit in the pair was found to be faultless. It is important to note that this probability would be different than the probability of both integrated circuits being accepted if no information about the first integrated circuit acceptance is given. This section provides a higher-order-logic formalization of the mathematical relationship for conditional probability and then utilizes this formal definition to verify some of its classical properties in the HOL4 theorem prover. The properties are explained in detail along with some hints on their verification to provide some insights about the formalization and verification process in HOL [Hasan, 2010b].

Conditional probability can be formally expressed in higher-order logic as follows:

### Definition 5.14

```
∀ A B p. cond_prob p A B = prob p (A inter B) / prob p B
```

by inheriting the higher-order-logic formalization of the probability function described earlier. The function cond_prob accepts the probability space p and two sets A and B, corresponding to two events, and returns a real number that corresponds to the conditional probability of the first event A given the second event B. Using the above definition, we now verify most of the classical properties of conditional probabilities have been verified within the HOL4 theorem prover. The formal proofs for these properties not only ensure the correctness of the above mentioned conditional probability definition but also play a vital role in reasoning about conditional probabilities of systems.

### 5.4.1 Conditional Probability Bounds

0 ≤ Pr(A | B) ≤ 1 (5.3)

According to this property, the value of conditional probability always remains within the closed interval [0, 1]. It can be expressed in higher-order logic, using the formal conditional probability definition, as follows:

### Theorem 5.6

```
⊢ ∀ p A B. prob_space p ∧ A ∈ events p ∧ B ∈ events p ⇒ 0 ≤ cond_prob p A B ∧ cond_prob p A B ≤ 1
```

The assumptions ensure that the events A and B are valid events of probability space p and the proof of this theorem is based on the bounds of the probability function.

### 5.4.2 Conditional Probability Is Countably Additive

If $A_i$ is a sequence of mutually exclusive events then

$\Pr(\bigcup_{i=1}^{\infty} A_i \mid B) = \sum_{i=1}^{\infty} \Pr(A_i \mid B)$ (5.4)

According to this property, conditional probability exhibits the countably additive property axiom just like the probability function. The countably additive property of conditional probability can be expressed in higher-order logic as follows:

### Theorem 5.7

```
⊢ ∀ p B A s. (prob_space p) ∧ (B ∈ events p) ∧ (A : (count n) -> events p) ∧ (s = BIGUNION (IMAGE A (count n))) ∧ (∀a b. a ≠ b ∧ DISJOINT (A a) (A b)) ⇒ (cond_prob p s B = SIGMA (λi. cond_prob p (A i) B) (count n))
```
