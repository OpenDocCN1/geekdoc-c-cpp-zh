
The last assumption ensures the independence between the set of events when the n sensor nodes are distributed over the subsets.

The proof of Theorem 13.1 is based on induction, the multiplication rule, the verification of the probability distribution of the Uniform random variable (Definition 13.1) and its complement, along with some analysis on sets.

Since a sub-network is either empty or not, we can model such behavior by a Bernoulli random variable which takes value 1 with success probability (prob p ({x | subset_empty (&j) (rd_subsets n (X x))} ∩ p space p). The higher-order-logic formalization of an empty sub-network can be expressed in HOL as follows:

### Definition 13.4

```
|- ∀ Y n X p a k j. subset_empty_rv Y n X p a k j =
(uniform_distr rv X p a k) ∧
(bernoulli_distr_rv Y p (prob p ({x | subset_empty (&j) (rd_subsets n (X x)) = T} ∩ p space p))).
```

The definition above specifies the input variable Y as a Bernoulli random variable (bernoulli_distr_rv) on the probability space p with success probability (prob p ({x | subset_empty (&j) (rd_subsets n (X x))} ∩ p space p)), and X is a Uniform random variable (uniform_dist_rv). The Bernoulli random variable with success probability pr is specified:

### Definition 13.5

```
|- ∀ X p pr. Bernoulli_distr_rv X p pr =
(real_random_variable X p) ∧ (IMAGE X (p space p) = {0;1} ∧
(distribution p X {1} = pr))
```

Based on the above formalization, we can easily verify the probability distribution of an empty sub-network.

### Theorem 13.2

```
|- ∀ Y X p m a n k. (1 < k) ∧ (subset_empty_rv Y n X p a k j) ∧
(&j ∈ IMAGE X (p space p)) ∧ (∀ c. indep p ({x | X x ≠ &j } ∩ p space p)
({x | subset_empty (&j) (rd_subsets c (X x)) } ∩ p space p))
⇒ (prob p({x | Y x = 1 } ∩ p space p) = (1 - 1/(&k)) pow n).
```

According to Theorem 13.2, we can notice that the probability distribution of an empty sub-network depends only on the input parameters k and n. Thus, for the sake of simplicity, we opt to directly model an empty subset using a Bernoulli random variable with success probability (1 – 1/k), and thus abstracting the Uniform random variable. The new higher-order-logic function, denoted sbst_empty_rv.

### Definition 13.6

```
|- ∀ X p k n. sbst_empty_rv X p k n = Bernoulli_distr_rv X p (1 - 1/k)
```

## 13.2.2 Formalization of the Network Coverage Intensity

In a wireless sensor network, we say that a given point of the monitored area is covered, if a randomly occurring event at this point, is detected by at least one active node with a given probability. Each point of the monitored area is hence characterized by a coverage intensity, whereas the coverage behavior of the whole network is the average among all the nodes. The network coverage is thus a widely used performance metric. In what follows, we are first interested in formally analyzing the coverage intensity of a point in the monitored area, which we build upon to develop the higher-order-logic formalization of the network coverage.

Let us denote by S the set of sensors that cover a specific point inside the field, with a cardinality c. When the randomized scheduling of nodes is applied to the set S, it will randomly assign each sensor node to one of the k disjoint subsets (Xiao et al, 2009). Consequently, during a given time slot T, a point is covered if the current active subset contains at least one node, i.e., it is not empty. Nevertheless, as we discussed previously, due to the random feature of the nodes scheduling, it may happen that a subset is completely empty. Note that the term "empty", used here, refers to a subset empty of covering nodes since the randomized scheduling is now applied to the set S. The coverage intensity of a point in the monitored area, denoted by Cp, is defined as the average time during which the point is covered in a whole scheduling cycle of length k x T. Such metric thus depends on the non-empty subsets within a whole scheduling cycle. The coverage intensity of a given point in the monitored area, Cp, is mathematically specified as

```
Cp = E[X] x T / k x T (13.1)
```

where E[X] denotes the expectation of the random variable X describing the total number of non-empty subsets, and

```
X = \sum_{j=0}^{k-1} X_j (13.2)
```

where Xj is the Bernoulli random variable whose value is 1 in case of a non-empty subset. Similar to the specification of an empty subset in Definition 13.6, we can model a non-empty sub-network by a Bernoulli random variable with the complement probability of (1 – 1/k).

### Definition 13.7

\(\vdash \forall p \ x \ k \ n. \ sbst\_non\_empty\_rv \ x \ p \ k \ n =\)
\(bernoulli\_distr\_rv \ x \ p \ (1 - (1 - 1/k))\)

According to the above description, we model the coverage behavior of a specific point (Equation 13.1) by the following predicate cvrg_insty_pt that accepts five parameters: p: the probability space, X: a random variable that returns an extended real number, k: the number of sub-networks, s: the summation set whose cardinality is k, and c: the number of nodes covering that point.

### Definition 13.8

\(\vdash \forall p \ x \ k \ s \ c. \ cvrg\_insty\_pt \ p \ x \ k \ s \ (c:num) =\)
\(expectation \ p \ (x. \ SIGMA \ (\lambda i. \ x \ i) \ s) \ / \ (\&k)\)

The following mathematical expression for the coverage intensity of a point has been formally verified.

### Theorem 13.3

\(\vdash \forall p \ x \ k \ s \ c. \ (prob\_space \ p) \land (FINITE \ (p \ space \ p)) \land (1 < k) \land\)
\(FINITE \ s \land (CARD \ s = k)\)
\(\land (\forall i. \ i \in s \Rightarrow sbst\_non\_empty\_rv \ (x \ i) \ p \ k \ c)\)
\(\Rightarrow (cvrg\_insty\_pt \ p \ x \ k \ s \ c = Normal \ ((1 - (1 - 1/(\&k))))\)

- The assumption FINITE (p_space p) ensures that the sample space is finite.
- The assumption ((∀ i. i ∈ s) sbst_non_empty_rv (X i) p k c) indicates that every element of the set s is a random variable of type sbst non empty rv (Definition 13.7).
- The HOL function Normal is used to convert a real value to its corresponding value in an extended real.

The proof of the above theorem mainly required lemmas about the linearity of the expectation property and the measurability of some events, along with some analysis on extended reals.

Now, it is possible to reason about the network coverage intensity, which we denote by Cn. According to Cn is described as the average value of the coverage intensity over all the points of the monitored area. Mathematically, Cn is specified, in Equation 13.3, as the expectation of the coverage intensity of a specific point Cp.

```
C_n = E[Cp] (13.3)
```

Based on Theorem 13.3, we can notice how the value of the coverage intensity of a specific point depends mainly on c, i.e., the number of nodes covering a given point. Assimilating the event of covering a point or not to a Bernoulli trial with the probability q, it is clear that, when we consider the variable c among the n nodes of the network, it becomes a Binomial random variable (C) with the following probability

```
Pr(C=j) = C_n^j (r/a)^j (1 - r/a)^{n-j} (13.4)
```

where C_n^j is the binomial coefficient, r is the size of the sensing area of each sensor, a is the size of the monitored area, and (r/a) is the probability that each sensor covers a given point. The Binomial random variable with n trials and success probability q = r/a has been formalized as follows:

### Definition 13.9

```
|- ∀ X p q n. binomial_distr_rv X p q n =
(real_random_variable X p) ∧
(IMAGE X (p space p) = IMAGE (\x. &x) (count (SUC n))) ∧
(\m. &m IN (IMAGE X (p space p))) ∧
(distribution p X (&m) = & (binomial n m) * (q pow m) * ((1 - q) pow (n - m))))
```
