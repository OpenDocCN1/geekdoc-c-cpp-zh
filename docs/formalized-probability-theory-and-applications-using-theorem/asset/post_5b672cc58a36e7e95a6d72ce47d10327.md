## KEY TERMS AND DEFINITIONS

**Discrete-Time Markov Chains**: A discrete-time Markov chain (DTMC) is a Markov chain with a countable set of time values or, in other words, the time index of this Markov chain exhibits a discrete nature.

**Markov Chains**: A Markov chain is a stochastic process that exhibits the Markovian property, i.e., the next state depends on the current state of the system only and not on the history through which the current state was reached.

**Stochastic Process**: A stochastic process describes a set of random variables that model the evolution of a time-varying system.

## ABSTRACT

The main focus of this chapter is on the formalization of classified DTMCs. The chapter begins by presenting the formalization of some foundational notions of classified states, which are categorized based on reachability, periodicity, or absorbing features. Then, these results along with the formal definition of a DTMC, presented in the previous chapter, are used to formalize classified Markov chains, such as aperiodic and irreducible DTMCs. Based on these concepts, some long-term properties are verified for the purpose of formally checking the correctness of the functions of Markovian systems or analyzing the performance of Markov chain models.

## 7.1 FORMALIZATION OF CLASSIFIED STATES

The foremost concept of states classification is the first passage time $\tau_j$, which is sometimes referred to as the first hitting time. It is defined as the minimum time required to reach a state $j$ from the initial state $i$:

$\tau_j = \min \{ t > 0: X_t = j \}$ (7.1)

The first passage time can be defined in HOL4 as:

```
Definition 7.1
|- ∀ X x j . FPT X x j = MINSET { t | 0 < t ∧ (X t x = j) }
```

where X is a random process and x is a sample in the probability space associated with the random variable X. Note that the first passage time is also a random variable.

The conditional distribution of $\tau_j$ defined as the probability of the events starting from state $i$ and visiting state $j$ at time $n$ is expressed as $f_{ij}^{(n)} = Pr \{ \tau_j = n | X_0 = i \}$.

This definition can be formalized in HOL4 as (Liu, 2013):

```
Definition 7.2
|- ∀ X p i j n.
f X p i j n = prob p { (x | FPT X x j = n) | { x | X 0 x = i } }
```

Another important notation, denoted as $f_{ij}$ is the probability of the events starting from state $i$ and visiting state $j$ at all times $n$, is expressed as $f_{ij} = \sum_{n=1}^{\infty} f_{ij}^{(n)}$. It can be expressed in HOL4 as (\lambda n. f X p i j n) sums $f_{ij}$. Thus $f_{ij}$ provides the probability of events starting from state $j$ and eventually returning back to $j$. If $f_{jj} = 1$, then the mean return time of state $j$ is defined as $\mu_j = \sum_{n=1}^{\infty} n f_{jj}^{(n)}$. The existence of this infinite summation can be specified as $summable (\lambda n. n * f X p j j n)$ in HOL.

A state $j$ in a DTMC $\{ X_j \}_{j \ge 0}$ is called transient if $f_{jj} < 1$, and persistent if $f_{jj} = 1$. If the mean return time $\mu_j$ of a persistent state $j$ is finite, then $j$ is said to be persistent non-null state (or positive persistent state). Similarly, if $\mu_j$ is infinite, then $j$ is termed as persistent null state.

The greatest common divisor (gcd) of a set is a frequently used mathematical concept in defining classified states. We formalize the gcd of a set as follows:

### Definition 7.3

```
⊢ ∀ A. GCD_SET A = MAXSET { r | ∀x. x ∈ A ⇒ divides r x }
```

where MAXSET is a function in the set theory of HOL4 such that MAXSET s defines the maximum element in the set s. A period of a state j is any n such that \(p_{jj}^{(n)}\) is greater than 0 and we write \(d_j = gcd \{ n : p_{jj}^{(n)} > 0 \}\) as the gcd of the set of all periods.

A state i is said to be accessible from a state j (written \(i \rightarrow j\)), if there exists a nonzero n-step transition probability of the events from state i to j. Two states i and j are called communicating states (written \(i \leftrightarrow j\)) if they are mutually accessible. A state j is an absorbing state if the one-step transition probability \(p_{jj} = 1\). The formalization of some other foundational notions of the classified states is given in Table 1.

## 7.2 FORMALIZATION OF CLASSIFIED DTMCs

In this section, we build upon the above mentioned definitions to formalize classified DTMCs. Usually, a DTMC is said to be irreducible if every state in its state space can be reached from any other state including itself in finite steps.

```
⊢ ∀ X p s P₀ Pᵢⱼ ·
Irreducible_mc X p s P₀ Pᵢⱼ =
th_dtmc X p s P₀ Pᵢⱼ ∧
(∀ i j. i ∈ space s ∧ j ∈ space s ⇒
Communicating_states X p s i j)
```

where th_dtmc is time-homogeneous Markov chain and the second conjunct expresses that all the states in the state space can communicate with each other.

If there exists a state in the state space of a DTMC, which cannot reach other states, then this DTMC is called reducible.

```
⊢ ∀ X p s P₀ Pᵢⱼ ·
Reducible_mc X p s P₀ Pᵢⱼ =
th_dtmc X p s P₀ Pᵢⱼ ∧
∃ i j. i ∈ space s ∧ j ∈ space s ∧
~ Communicating_states X p s i j
```

A DTMC is considered as aperiodic if every state in its state space is an aperiodic state; otherwise it is a periodic DTMC.

```
⊢ ∀ X p s P₀ Pᵢⱼ ·
Aperiodic_mc X p s P₀ Pᵢⱼ =
th_dtmc X p s P₀ Pᵢⱼ ∧
(∀ i. i ∈ space s ⇒ Aperiodic_state X p s i)
```

```
⊢ ∀ X p s P₀ Pᵢⱼ ·
Periodic_mc X p s P₀ Pᵢⱼ =
th_dtmc X p s P₀ Pᵢⱼ ∧ (∃ i. i ∈ space s ∧ Periodic_state X p s i)
```
