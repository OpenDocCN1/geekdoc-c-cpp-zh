## 定理 5.1

如果 X 和 Y 是随机变量且 c ∈ R，则以下函数也是随机变量：cX、|X|、X^n、X + Y、XY 和 max(X, Y)。两个随机变量 X 和 Y 独立当且仅当对所有 A, B ∈ B(R)，事件 { X ∈ A } 和 { Y ∈ B } 独立。集合 { X ∈ A } 表示使得 X(ω) ∈ A 的结果 ω 的集合。换句话说，{ X ∈ A } = X⁻¹(A)。

## 定义 5.4

```
\vdash \forall p X Y s t. indep_rv p X Y s t \Leftrightarrow \forall A B. A \subseteq subsets s \land B \subseteq subsets t \Rightarrow indep p (PREIMAGE X A I p_space p) (PREIMAGE Y B \cap p_space p)
```

事件 { X ∈ A } 用于定义随机变量的概率质量函数（PMF）。随机变量 X 的概率质量函数 p_x 定义为将 A 映射到事件 { X ∈ A } 概率的函数，即，对所有 A ∈ B(R)，p_x(A) = p({ X ∈ A }) = p(X⁻¹(A))。

## 定义 5.5

```
\vdash \forall p X. distribution p X = (\lambda A. prob p (PREIMAGE X A \cap p_space p))
```

随机变量的累积分布函数（CDF）定义为：

F_X(x) = P(X ≤ x) (5.1)

它可以在 HOL4 中形式化为：

## 定义 5.6

```
\vdash \forall p X. CDF p X = (\lambda x. distribution p X ( \{ y | y \le x \} ))
```

### 5.2.2 方差和协方差

在概率分析领域，通常希望通过某些适当定义的度量来总结随机变量分布的基本属性。在上一节中，我们形式化了其中一种度量，即期望，它给出了随机变量可能取值的加权平均值。非常频繁地，除了平均值外，我们还关心平均值的典型性，换句话说，即观察到远离平均值的事件的概率。衡量这些值的变化或离散程度的一种可能方法是考虑量 E|X - E[X]|，其中 |y| 表示 y 的绝对值。然而，处理这一量在数学上不太方便，因此通常考虑一个更易处理的量，称为方差，它返回 X 与其期望之差的平方的期望。同样，另一个密切相关的度量是协方差，它是两个随机变量之间相关性的度量。两个随机变量 X 和 Y 的协方差定义为 Cov(X, Y) = E[(X - E[X])(Y - E[Y])]。两个随机变量 X 和 Y 不相关当且仅当 Cov(X, Y) = 0。

方差和协方差的一些经过形式验证的属性包括：

```
|- ∀ X. Var (X) = E [ X ^ 2 ] - E [ X ] ^ 2
|- ∀ X Y. Cov (X, Y) = E [ X Y ] - E [ X ] E [ Y ]
|- ∀ X. Var (X) ≥ 0
|- ∀ a ∈ R. Var (aX) = a^2 Var (X)
|- ∀ p X Y. Var (X+Y) = Var (X) + Var (Y) + 2 Cov(X,Y)
|- ∀ X Y. X and Y uncorrelated ⇒ Var (X + Y) = Var (X) + Var (Y)
```

## 5.3 重击者问题

给定一个全集 U、长度为 n 的数据流和参数 λ ∈ [0, 1]，重击者问题旨在找出 λ-重击者列表，该列表包含在数据流中出现至少 λn 次的全集元素。重击者问题的算法广泛用于以紧凑的方式识别流中频繁出现的项目。例如，它们已被用于在金融交易流中识别交易量大的股票、检测网络中病毒传播、监控网络流量以进行统计数据收集以及检测分布式拒绝服务（DDoS）。重击者问题的一个算法如下：

```
Input: the frequency λ, a data stream DS and a Universe U with length n
Output: the list L of elements from U occurring at least λ * n times in DS
L ← [ ]
for i = 1 → n do
if freq (DS[i]) ≥ λ then
L ← L INSERT DS[i]
end if
end for
```

分析此类问题的主要目标是预测数据流中某些特定元素的行为。例如，控制金融流中的特定交易。此分析中最大的挑战是输入数据流的不可预测性。因此，概率技术用于分析，其中算法由适当的随机变量建模。

### 5.3.1 重击者问题的形式化

重击者问题可以在 HOL4 中通过将元素样本集和数据流建模为列表来形式化（Halali, Hasan & Tahar, 2012）。然后，我们建模一个函数 freq，它返回列表中元素的频率。

## 定义 5.9

```
|- ∀ L e. freq e L =
(LENGTH (FILTER (λ r.r = e) L)) / (LENGTH L)
```

其中 LENGTH 返回列表的长度，FILTER 返回其参数列表中满足给定条件的元素组成的过滤列表。上述函数稍后将用于报告 α-重击者元素列表。接下来，我们建模另一个函数 HeavyHitter_lst，它以两个列表和一个实数值为参数，并返回对应于重击者问题算法的重击者列表。

## 定义 5.10

```
|- ∀ L M α. HeavyHitter_lst L M α =
FILTER (λ r. α <= (freq (EL r L) M)) L
```

到目前为止，形式化一直基于确定性函数。我们现在使用适当的随机变量在模型中引入随机性，我们对重击者问题算法的概率分析将基于这些随机变量的特征。在我们的分析中，我们需要一个伯努利变量 X，其结果为 1 或 0。为了形式化这种随机行为，我们必须定义一个概率空间，其样本空间为集合 {0, 1}，事件空间为幂集 POW {0, 1}，而概率测度将是一个新函数：如果参数中的集合实现了 f(x)（在此处指我们的随机变量）等于 1 的事实，则返回 pr，否则返回 1 - pr。相应的概率测度在 HOL4 中定义如下：

## 定义 5.11

```
|- ∀ g pr. mu g pr =
(λ a. if (a = {x | g x = 1}) then pr else (1 - pr))
```
