# 8.3 PROOF AUTOMATION

Though the analysis of HMMs is based on interactive theorem proving, it seems natural to try to automatize such computations. This is extremely useful since, in practice as one is always interested in applying the theorems to concrete situations. In this section, we describe how to automatically acquire interesting probabilities and find the best state path, for a given HMM, using the results of Theorems 8.2 and 8.3. This makes the accuracy of theorem proving available even to users with no knowledge about logic or theorem proving.

In order to automate the computation associated with Theorem 8.1, we define a Standard ML (SML) function hmm joint distribution (ini_dist trans_dist e_dist sts obs) which takes as input the initial distributions, the transition probabilities, the emission distributions, a list of states and a list of observations: When calling this function, these parameters will be automatically substituted to, respectively, p0, p, pxy stx and sts, of Theorem 8.1. We then take t to be the length of sts (which should be the same as obs): this seems to be the most common case in practice, but could be easily relaxed if needed by adding a parameter to the function. We can then compute, using the theorems about list, real numbers, etc. in HOL4, the right-hand side of the equation in Theorem 8.1 in an exact way (as a fraction). In the end, the function returns the corresponding instantiation of a HOL4 theorem stating the equality between the joint probability and its value. Note that the result is really a HOL4 theorem: even the operations between real numbers like multiplication or addition are obtained by deductive reasoning, thus making every single step of the computation completely reliable and traceable. For convenience, the result can also be converted (outside HOL4) into a SML floating point value, in order to compare with those results created by simulation tools.

The implementation of the function hmm_joint_distribution requires the development of an intermediate lemma, in which some functions are defined for parametrizing the variables in Theorem 8.1 and outputting the results given by HOL4 through SML.
