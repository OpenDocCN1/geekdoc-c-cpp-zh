### 3.1.1 可靠性理论

系统的可靠性定义为：在特定环境条件下，系统在给定时间段内能够充分实现其指定目的的概率。因此，可靠性理论的基础主要基于概率论。常用的可靠性评估概念包括累积分布函数（CDF）、生存函数和危险函数。所有这些基础均已形式化，且其中一些重要属性也已在 HOL4 定理证明器中得到形式验证。本手稿亦对这些形式化进行了描述。

## 3.2 HOL4 定理证明器

本节简要介绍 HOL4 定理证明器（Gordon & Melham, 1993），以便于理解本书其余部分。HOL4 是由剑桥大学的 Mike Gordon 开发的交互式定理证明器，用于进行高阶逻辑证明。它利用 Church（1940）的简单类型论以及 Hindley-Milner 多态性（Milner, 1977）来实现高阶逻辑。HOL4 已成功用作软件和硬件的验证框架，以及纯数学形式化的平台。

### 3.2.1 安全定理证明

为确保安全的定理证明，HOL4 系统中的逻辑在强类型函数式编程语言 ML（Paulson, 1996）中表示。使用 ML 抽象数据类型来表示高阶逻辑定理，与定理证明器交互的唯一方式是执行对这些数据类型值进行操作的 ML 过程。HOL4 核心仅包含 5 个基本公理和 8 个原始推理规则，这些规则作为 ML 函数实现。可靠性得到保证，因为每个新定理都必须通过应用这些基本公理和原始推理规则或任何其他先前验证过的定理/推理规则来验证。

### 3.2.2 项

HOL4 项有四种类型：常量、变量、函数应用和 lambda 项（表示函数抽象）。多态性（即包含类型变量的类型）是高阶逻辑的一个特殊特征，因此 HOL 支持多态性。从语义上讲，类型表示集合，项表示这些集合的元素。公式、序列、公理和定理是使用布尔类型的项来表示的。

### 3.2.3 理论

HOL4 理论是有效的 HOL4 类型、常量、公理和定理的集合，通常作为文件存储在计算机中。用户可以在 HOL4 系统中重新加载 HOL4 理论，并立即使用相应的定义和定理。HOL4 理论的概念使我们能够高效地在现有结果基础上构建，而无需使用基本公理和原始推理规则重新生成这些结果的繁琐过程。HOL4 理论以层次结构组织。任何理论都可以从其他可用的 HOL4 理论继承类型、定义和定理。HOL4 系统防止此层次结构中的循环，且不允许任何理论同时成为同一理论的祖先和后代。各种数学概念已由 HOL4 用户形式化并保存为 HOL4 理论。当用户首次启动 HOL4 会话时，这些理论即可用。我们在工作中使用了 HOL4 的布尔、列表、集合、正整数、实数、测度和概率理论。事实上，选择 HOL4 定理证明器进行我们工作的主要动机之一，就是为了从这些内置数学理论中受益。

### 3.2.4 编写证明

HOL4 支持两种交互式证明方法：前向证明和后向证明。在前向证明中，用户从先前证明过的定理开始，应用推理规则以达到所需的定理。在大多数情况下，前向证明方法不是最简单的解决方案，因为它需要预先知道证明的确切细节。后向或目标导向证明方法是前向证明方法的逆过程。它基于策略的概念；策略是一种将目标分解为简单子目标的 ML 函数。在后向证明方法中，用户从所需的定理或主要目标开始，并指定策略将其归约为更简单的中间子目标。其中一些中间子目标可以通过匹配公理或假设，或通过应用内置决策过程来解决。对剩余的中间目标重复上述步骤，直到不再有进一步的子目标，从而完成所需定理的证明。HOL4 定理证明器包含许多证明助手和自动证明过程，以协助用户指导证明。用户与证明编辑器交互，并为其提供证明目标所需的策略，而一些证明步骤由自动证明过程自动求解。

## 关键术语和定义

- **高阶逻辑：** 高阶逻辑是一种具有精确语义的演绎系统。它通过允许对函数变量进行量化，与更常见的谓词逻辑和一阶逻辑有所不同。这一扩展大大增强了逻辑的表达能力，因此高阶逻辑可用于大多数数学概念和理论的形式规范。
- **概率分析：** 对系统的概率分析是应用基于概率论的推理来估计与给定系统相关的有趣事件相关的概率的过程。
- **定理证明：** 定理证明是一种广泛使用的形式化方法。需要分析的系统在适当的逻辑中进行数学建模，并使用基于计算机的工具验证感兴趣的属性。定理证明器的核心通常由一些著名的公理和原始推理规则组成。可靠性得到保证，因为每个新定理都必须从这些基本公理和原始推理规则或任何其他已证明的定理或推理规则中创建。
