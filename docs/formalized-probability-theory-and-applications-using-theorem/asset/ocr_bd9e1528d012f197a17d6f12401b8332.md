# Definition 8.4

```
|- state seq =
| [ START; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E;
FIVE; I; I; I; I; I; I; I; I; END ]
|- dna seq = [ C; T; T; C; A; T; G; T; G; A; A; A; G; C; A; G;
A; C; G; T; A; A; G; T; C; A ]
```

So to model the HMM represented in Figure 1, we need an initial distribution, the transition probabilities, and the emission probabilities, which we define as follows:

# Definition 8.5

```
|- ini_distr i = if (i = START) then 1 else 0
|- trans_distr t i j = case (i, j) of
(START, E) -> 1 | (E, E) -> 0.9 | (E, FIVE) -> 0.1 | (FIVE, I) -> 1 |
(I, I) -> 0.9 | (I, END) -> 0.1 | -> 0
|- e_distr a i = case (i, a) of
(E, _) -> 0.25 | (FIVE, A) -> 0.05 | (FIVE, G) -> 0.95 | (I, A) -> 0.4 |
(I, T) -> 0.4 | (I, C) -> 0.1 | (I, G) -> 0.1 | _ -> 0
```

Then, in order to work with random variables X and Y denoting the states and the observations, respectively, on a probability space p, it is sufficient to have the following predicate:

```
thmm X Y p s_x s_y ini_distr trans_distr e_distr
^ space s_x = univ(: state) ^ space s_y = univ(: dna)
```

where univ(t) is the set of all possible values of type t, e.g., univ(:dna) = { A; G; T; C }. Now, for instance, we can prove the theorem which gives the probability of obtaining the sequence dna seq if the underlying state path is state seq:

# Theorem 8.4

```
|- forall X Y p s_x s_y.
thmm X Y p s_x s_y ini_distr trans_distr e_distr ^
space s_x = univ(: state) ^ space s_y = univ(: dna) ==>
P ( \bigcap_{k=0}^{|state_seq|-1} {x | X k x = EL k state_seq} \cap
\bigcap_{k=0}^{|dna_seq|-1} {x | Y k x = EL k dna_seq} ) =
0.25^18 * 0.9^13 * 0.1^4 * 0.95 * 0.4^4
```
