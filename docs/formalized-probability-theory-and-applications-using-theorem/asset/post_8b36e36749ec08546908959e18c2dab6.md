## 11.1.4 Typical Set

A consequence of the AEP is the fact that the set of observed sequences (x1, ..., xn) for which joint probabilities p(x1, x2, ..., xn) are close to 2^-nH(X) has a total probability equal to 1. This set is called the typical set and such sequences are called the typical sequences. In other words, out of all possible sequences, only a small number of sequences will actually be observed and those sequences are nearly equally probable. The AEP guarantees that any property that is proved for the typical sequences will then be true with high probability and will determine the average behavior of a large sample.

### Definition 11.1

The typical set $A_\epsilon^n$ with respect to $p(x)$ is the set of sequences $(x_1, ..., x_n)$ satisfying:
$2^{-n(H(X)+\epsilon)} \le p(x_1, ..., x_n) \le 2^{-n(H(X)-\epsilon)}$ (11.6)

The typical set has the following properties

### Theorem 11.4

if $(x_1, ..., x_n) \in A_\epsilon^n$

then

H(X) - \(\epsilon \le - \frac{1}{n} \log (P(X_1, ..., X_n)) \le H(X) + \epsilon\) (11.7)

This theorem is a direct consequence of Definition 5.1.

### Theorem 11.5

\(\forall \epsilon > 0, \exists N, \forall n \ge N, P(A_\epsilon^n) > 1 - \epsilon.\)

The proof of this theorem is derived from the formally verified AEP. The next two theorems give upper and lower bounds for the number of typical sequences \(|A_\epsilon^n|\).

### Theorem 11.6

\(|A_\epsilon^n| \le 2^{n(H(X) + \epsilon)}.\)

- Proof: Let x = (x1, ..., xn), then \(\sum_{x \in A_\epsilon^n} p(x) \le 1\). From Equation 5.5, \(\forall \xi \in A_\epsilon^n 2^{-n(H(X)+\epsilon)} \le p(x)\). Hence \(\sum_{x \in A_\epsilon^n} 2^{-n(H(X)+\epsilon)} \le \sum_{x \in A_\epsilon^n} p(x) \le 1\). Consequently, \(2^{-n(H(X)+\epsilon)} |A_\epsilon^n| \le 1\) proving the theorem.

### Theorem 11.7 \(\forall \epsilon > 0, \exists N, \forall n \ge N, (1 - \epsilon) 2^{-n(H(X) - \epsilon)} \le |A_\epsilon^n| \).

- Proof: Let x = (x1, ..., xn). From Theorem 11.5, \(\exists N, \forall n \ge N, 1 - \epsilon < \sum_{x \in A_\epsilon^n} p(x)\). From Equation 11.5, \(\forall x \in A_\epsilon^n, p(x) \le 2^{-n(H(X) - \epsilon)}\). Hence, \(\exists N, \forall n \ge N, 1 - \epsilon < \sum_{x \in A_\epsilon^n} p(x) \le \sum_{x \in A_\epsilon^n} 2^{-n(H(X) - \epsilon)}\). Consequently, \(\exists N, \forall n \ge N, 1 - \epsilon < 2^{-n(H(X) - \epsilon)} |A_\epsilon^n| \) proving the theorem.

## 11.1.5 Data Compression Limit

The main idea behind the proof of the source coding theorem is that the average code word length for all sequences is close to the average code word length considering only the typical sequences. This is true because according to the typical set properties above, for a sufficiently large n, the typical set has a total probability close to 1. In other words, for any \(\epsilon > 0\), and sufficiently large n, the probability of observing a non-typical sequence is less than \(\epsilon\). Furthermore, the number of typical sequences is smaller than \(2^{n(H(X) + \epsilon)}\) and hence no more than \(n(H(X) + \epsilon) + 1\) bits are needed to represent all typical sequences. If we denote by Y the random variable defined over all the possible sequences and returns the corresponding code word length. The expectation of the Y is equal to the average code word length L. Using the properties of the typical set we can prove that

```
\(\bar{L} \le n(H(X) + \epsilon')\) (11.8)
```

where \(\epsilon' = \epsilon + \frac{1}{n}\)

Consequently, for any \(\epsilon > 0\) and \(n\) sufficiently large, the code rate \(\bar{\pi}\) can be made as close as needed to the entropy \(H(X)\) while maintaining a probability of error of the encoder that is bounded by \(\epsilon\).

In this application, we made use of the framework presented in previous chapters for formally verifying the limit of data compression. This has the advantage of providing an exact mechanical proof of the result, similar to the one obtained through paper-and-pencil analysis, compared to less accurate results given by other computer based simulation approaches. Compared to the paper-and-pencil based analytical method, the correctness of the result is guaranteed by the soundness of the theorem prover. Furthermore, the formal proof serves as a way to improve the formal specification of the problem, by focusing only on the necessary assumptions to prove the result and ignoring the unnecessary ones.

To the best of our knowledge, this was the first time the AEP has been formally verified. This is also the first formal proof of Chebychev and Markov inequalities that uses measure theory and Lebesgue integration and that can be applied to various similar inequalities. The formalization of Shannon entropy allowed us to define the typical set and prove its properties. These proofs required approximately 3 weeks of human effort and around 1000 lines of HOL4 code. The upside is that these results can be reused in several other engineering applications.

Our formalization has influenced the work of Affeldt et al., in which they proved the Shannon’s theorems in the Coq proof assistants. In that work, the authors provided a simplified formalization of the concepts involved instead of generalized definitions that can be used in other applications, like we did in this book.

## 11.2 ANONYMITY-BASED SINGLE MIX

In communication networks, privacy requires not only confidentiality of the information but also hiding the identities of the communicating parties. Several anonymous networks have been proposed to ensure anonymous communication, e.g. Onion Routing (Syverson, Goldschlag, & Reed, 1997), Crowds (Reiter & Rubin, 1998), etc. Most of the proposed solutions are based on Chaum’s original idea of a threshold mix. Mixes are relay nodes that collect packets from different users, shuffle them then forward them to their destinations in such a way that an external eavesdropper cannot link an outgoing packet to its corresponding sender.
