# KEY TERMS AND DEFINITIONS

**Entropy:** Entropy is defined as the average number of bits required for storing or sending one symbol/message.

**Information Theory:** Information theory allows us to quantify information. It is widely used for analyzing compressing data and ensuring reliable storage and communication of data.

**Mutual Information:** The mutual information is a measure of the mutual dependence of two random variables. In particular, it is found by measuring the reduction of uncertainty about one of these variables when the other variable is known.
