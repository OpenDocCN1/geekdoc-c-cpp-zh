

以一个持续时间为 L = 2.8T 的入侵事件为例。因此，L 与 ⌈L/T⌉ = ⌈2.8T/T⌉ = 3 个周期重叠的概率为 (1-s = 0.2)，或与 4 个周期重叠的概率为 (s = 0.8)。

我们现在可以使用高阶逻辑形式化入侵周期 L 下重叠周期的平均数量。为此，我们首先正式指定描述入侵周期 L 内重叠周期数量的相应随机变量。基于上述描述，我们用表示为 IT 的随机变量来建模此行为。该随机变量可以通过以下谓词 intr_distr_rv 在高阶逻辑中表征，该谓词接受五个参数：IT：返回扩展实数的随机变量，p：概率空间，s：公式 (14.1) 中指定的变量，L：入侵周期的长度，以及 Ts：时间槽的长度。请注意，为简单起见，我们将 s 作为一个单独的变量，尽管它仅取决于 L 和 Ts。

## 定义 14.1

⊢ ∀ IT p s (L: real) (Ts: real) . intr_distr_rv IT p s L Ts = (real_random_variable IT p) ∧ (IMAGE IT (p_space p) = {⌈L/Ts⌉, ⌊L/Ts⌋ + 1}) ∧ (distribution p IT {⌊L/Ts⌋} = 1 - s) .

上述定义将 IT 指定为概率空间 p 上的实随机变量，使得 IT 在 (p_space p) 上的像属于 {⌈L/Ts⌉, ⌊L/Ts⌋ + 1}，且其在 {⌊L/Ts⌋} 上的概率分布为 (1 - s)。

接下来，我们正式验证入侵周期 L 下重叠周期的平均数量，即随机变量 IT 的期望：

## 定理 14.1

⊢ ∀ IT p s L Ts. (0 < Ts) ∧ (0 < L) ∧ (intr_distr_rv IT p s L Ts) ⇒ (expectation p IT = Normal (L/Ts + 1)) .

其中，上述定理中使用的函数 expectation 指定了返回扩展实数的随机变量的期望的高阶逻辑形式化，而 HOL4 函数 Normal 用于将实数值转换为其对应的扩展实数值。定理 14.1 的证明基于对 $\lceil \frac{L}{Ts} \rceil$ 和 $\lceil \frac{L}{Ts} \rceil + 1$ 的概率分布验证，以及对扩展实数的一些分析。

### 14.2.2 检测概率

检测入侵事件 (D) 的概率通常使用“无法检测入侵 (UD)”事件的概率来指定。因此，使用概率补余规则，我们有：

$P_r (D) = 1 - P_r (UD)$ (14.2)

无线传感器网络的检测性能主要取决于覆盖发生事件的节点数量。入侵事件发生点的覆盖节点数量是一个二项随机变量 (c)，其概率如下。

$P_r (c = j) = C_n^j \times \left( \frac{r}{a} \right)^j \times \left( 1 - \left( \frac{r}{a} \right) \right)^{n-j} \times \frac{n!}{j!(n-j)!}$ (14.3)

其中，$C_n^j$ 是按覆盖发生事件的节点数 j 和部署节点总数 n 索引的二项系数。公式 (14.3) 中使用的参数 r 和 a 分别是每个传感器的感知区域大小和监测区域大小，而 $\lceil \frac{r}{a} \rceil$ 是每个传感器覆盖给定点的概率。具有 n 次试验和成功概率 $q = \lceil \frac{r}{a} \rceil$ 的二项随机变量在以下定义中指定：

### 定义 14.2

```
|- ∀ X p q n. binomial_distr_rv X p q n = (real_random_variable X p) ∧
(IMAGE X (p_space p) = IMAGE (λx. &x) (count (SUC n))) ∧
(!m. &m IN (IMAGE X (p_space p)) =>
(distribution p X ({m}) = (binomial n m) * q^m * (1 - q)^(n - m))).
```

其中，X 是定义在概率空间 p 上的实随机变量，IMAGE (λx.&x) (count (SUC n)) 生成二项分布的支持集，而运算符 & 允许将自然数 m 转换为其扩展数对应物。上述定义中使用的函数 binomial 是针对实数的二项系数的高阶逻辑形式化，我们已在 HOL4 中指定。

## 定义 14.3

```
⊢ ∀ n k. binomial n k = (binomial n 0 = (1:num)) ∧
(binomial 0 (SUC k) = (0: num)) ∧
(binomial (SUC n) (SUC k) = binomial n (SUC k) + binomial n k).
```

鉴于事件 { c = j, 0 ≤ j ≤ n } 构成了整个样本空间 (Ω = p_space) 的一个划分，我们可以从公式 (14.2) 出发，使用全概率公式建立如下关系：

P_r(D) = 1 - ∑_{j=0}^{n} P_r(UD|c=j) × P_r(c=j) (14.4)

其中 P_r(UD|c=j) 是在 (c = j) 条件下无法检测入侵事件的条件概率。

接下来，我们根据 j 的值（即入侵事件发生时覆盖某点的传感器节点数量）和 L（即入侵周期）来讨论概率 P_r(UD|c=j)。

- 情况 1：(j = 0) 且对于任意持续时间 L，P_r(UD|c=0) = 1。

鉴于没有覆盖节点，入侵事件绝不可能被检测到。

- 情况 2：{0 < j ≤ n} ∩ {L ≥ (k-1) × T_s}，Pr(UD|c=j) = 0。

由于有 k 个工作轮次，每个轮次长度为 T_s，持续时间超过 (k-1) × T_s 且至少有一个覆盖的活动节点 (0 < j) 的事件将始终被检测到。

- 情况 3：{0 < j ≤ n} ∩ {L < (k-1) × T_s}，Pr(UD|c=j) ≠ 0 。

持续时间少于 (k-1) × T_s 且至少有一个覆盖的活动节点 (0 < j) 的事件，通常会以非零的给定概率被检测到。

通过提取公式 (14.4) 求和中的第一项 (j=0)，我们得到

Pr(D) = 1 - (Pr(UD|c = 0) × Pr(c = 0) + \(\sum_{j=1}^{n}\) (Pr(UD|c = j) × Pr(c = j))(14.5)

根据情况 1，我们有 Pr ( UD | c = 0 ) = 1，因此我们可以使用公式 (14.3) 将公式 (14.5) 改写为

Pr(D) = 1 - ((1 - q)^n + \(\sum_{j=1}^{n}\) (Pr(UD|c = j) × Pr(c = j)) (14.6)

在以下内容中，我们有兴趣正式验证任何长度 L 的发生事件的检测概率 Pr (D)。更具体地说，我们关注公式 (14.6) 求和项的形式化。为此，我们区分 2 种情况，即 { L < (k - 1) × T_s } 和 { L >= (k - 1) × T_s }。

### 对于满足 { L < (k - 1) × T_s } 的事件的检测概率

检测概率性能分析的数学模型已直接给出了公式 (14.6) 的最终结果。然而，为了准确实现公式 (14.6) 的高阶逻辑形式化，我们需要推理与概率分析相关的所有隐式步骤。

根据入侵周期分析，我们知道入侵周期 L 可能与 \(\lceil \frac{L}{T_s} \rceil\) 或 \(\lceil \frac{L}{T_s} \rceil + 1\) 个调度周期 T_s 重叠。因此，持续时间为 L 的入侵事件，无论是在 L 与 \(\lceil \frac{L}{T_s} \rceil\) 个周期重叠时，还是在 L 与 \(\lceil \frac{L}{T_s} \rceil + 1\) 个周期重叠时，都可能无法被检测到。使用以下事件

- A12：入侵周期 L 与 \(\lceil \frac{L}{T_s} \rceil\) 个周期重叠。

- A22：入侵周期 L 与 \(\lceil \frac{L}{T_s} \rceil + 1\) 个周期重叠。

可以将整个未检测事件（表示为 UD）表示如下

UD = UD \(\cap\) (A12 \(\cup\) A22) (14.7)

现在，简化公式 (14.6) 中的 Pr(UD | c = j)，并结合事件 A12 和 A22 互斥的事实，我们得到以下结果。

Pr(UD | c = j) = Pr(UD | A12 ∩ (c = j)) × Pr(A12 | c = j)
+ Pr(UD | A22 ∩ (c = j)) × Pr(A22 | c = j)   (14.8)

直观地讲，对于给定长度 L 的入侵事件，事件 (A12 = L 与 ⌈ L / Ts ⌉ 个周期重叠) 的发生，以及描述存在 j 个覆盖节点的事件 (c = j)，由不同且非交互的物理过程控制。因此，这两个事件是独立的。现在我们得到 Pr(A12 | c = j) = Pr(A12) = Pr(IT = ⌈ L / Ts ⌉)，其中 IT 是定义 14.1 中指定的入侵随机变量。同样，我们得到 Pr(A22 | c = j) = Pr(IT = ⌈ L / Ts ⌉ + 1)。这使我们可以将公式 (14.8) 的右边改写为

Pr(UD | A12 ∩ (c = j)) × Pr(A12) + Pr(UD | A22 ∩ (c = j)) × Pr(A22)   (14.9)

另一方面，事件 “UD | A12 ∩ (c = j)” 表示在“入侵周期 L 与 ⌈ L / Ts ⌉ 个周期重叠”且“存在 j 个覆盖节点”的条件下“无法检测入侵事件”的事件。确实，如果一个被 j 个节点覆盖且与 (h = ⌈ L / Ts ⌉) 个轮次重叠的事件未被检测到，则意味着所有 j 个覆盖节点都错过了 h 个连续的子集。换句话说，h 个子集的序列不包含覆盖节点。该事件由以下方程表示。

B_{h,c} = H_{1,c} ∩ H_{2,c} ∩ ... ∩ H_{i,c} ∩ ... ∩ H_{h,c} = ( ⋂_{i=1}^h H_{i,c} )   (14.10)

其中 H_{i,c} 是 c 个覆盖传感器节点均不属于工作子集 i 的事件，即 H_{i,c} 为空，且事件集合 { H_{1,c}, H_{2,c}, ..., H_{h,c} } 是相互独立的。我们说一个有限事件集是相互独立的
