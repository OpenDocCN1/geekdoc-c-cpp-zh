## 第 1 章 概率分析

### 摘要

本章介绍了在科学和工程领域使用概率分析的动机。接着简要介绍了概率分析的一些最重要概念以及广泛使用的概率分析技术。本章最后强调了传统概率分析技术的一些局限性。

### 1.1 动机

> 值得注意的是，这门起源于机会博弈考虑的科学，竟然已成为人类知识中最重要的对象……生活中最重要的问题，大部分其实只是概率问题。（皮埃尔·西蒙，拉普拉斯侯爵 [1749-1827]）

这位著名的法国数学家和天文学家的引言可能看起来有些夸张，但概率分析已成为科学和工程几乎每个领域中根本重要的工具，这是事实。一个系统可能是纯确定性的，但其现实世界环境的不可预测和随机性质使得很难预测其确切输出。随机性可能源于不需要的噪声效应、工程系统组件老化导致的故障，或者电信协议中不可预测的流量模式。由于这些随机组件，在所有情况下建立系统的正确性通常变得不切实际地昂贵。例如，考虑一种带有握手的简单电信协议，用于在存在噪声的情况下确保可靠通信。我们永远无法正式验证发送的数据包会被正确接收，因为存在噪声信道可能始终损坏传输的可能性。因此，使用概率分析。概率分析的主要思想是通过适当的随机变量，对给定系统及其环境中的随机和不可预测元素进行数学建模。然后利用这些随机变量的概率性质来判断系统关于感兴趣参数（如停机时间、可用性、故障次数、容量和成本）的行为。因此，系统不是保证在所有情况下都满足给定规范，而是报告系统满足该规范的概率（Mitzenmacher & Upfal, 2005）。再次考虑握手协议的示例，我们可以用适当的随机变量对噪声行为进行建模，从而利用其相应的概率和统计性质来判断成功传输的概率。

### 1.2 随机模型

表现出不确定性的系统的随机模型是使用适当的随机变量构建的。例如，随机变量可用于数学描述硬币或骰子的结果。随机变量可以数学定义为将概率空间的元素映射到某个其他可测空间的函数。随机变量大致可分为两类，即离散和连续。

如果随机变量可以获得的不同值的数量，或其范围，是有限的或至多可数无穷，则称为离散随机变量。例如，投掷硬币和掷骰子可以使用离散随机变量建模。离散随机变量可用于构建许多现实世界系统的随机模型。例如，数字通信中的信道噪声通常由伯努利随机变量建模，随机算法通常使用几何随机变量，而二项式随机变量在质量控制问题中有许多应用。

如果随机变量可以取得无限数量的值，或者换句话说其范围是实数区间，则称为连续随机变量。例如，数据包到达 Web 服务器的时间和电气元件的温度可以使用连续随机变量建模。许多现实世界系统表现出连续性质的随机性，因此在概率分析中使用连续随机变量来构建其随机模型。例如，连续均匀分布用于建模计算机算术应用中的量化误差，指数分布出现在排队应用中以建模到达间隔和服务时间，正态分布广泛用于建模数据传输和数字信号处理系统中的信号。

我们经常遇到随机性具有一定时间依赖性的系统。例如，噪声信号随时间变化，电话通话的持续时间与其发生时间以某种方式相关，人口增长是时间依赖的，化学反应也是如此。此类随机过程通常表现出无记忆性，这意味着未来状态仅取决于当前状态，与任何过去状态无关。具有无记忆性的系统称为马尔可夫过程，并使用马尔可夫链进行数学建模。许多现实世界系统的随机模型是使用马尔可夫链构建的。马尔可夫链的一些常见应用包括电信和安全协议、硬件电路可靠性分析、软件测试、生物模型和统计力学。
