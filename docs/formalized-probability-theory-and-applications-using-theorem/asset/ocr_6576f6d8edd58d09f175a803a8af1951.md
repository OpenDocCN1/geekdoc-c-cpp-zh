# 7.1 FORMALIZATION OF CLASSIFIED STATES

The foremost concept of states classification is the first passage time $\tau_j$, which is sometimes referred to as the first hitting time. It is defined as the minimum time required to reach a state $j$ from the initial state $i$:

$\tau j = min \{ t > 0: X_t = j \}$ (7.1)

The first passage time can be defined in HOL4 as:

```
Definition 7.1
|- ∀ X x j . FPT X x j = MINSET { t | 0 < t ∧ (X t x = j) }
```

where X is a random process and x is a sample in the probability space associated with the random variable X. Note that the first passage time is also a random variable.

The conditional distribution of $\tau_j$ defined as the probability of the events starting from state $i$ and visiting state $j$ at time $n$ is expressed as $f_{ij}^{(n)} = Pr \{ \tau j = n | X_0 = i \}$.

This definition can be formalized in HOL4 as (Liu, 2013):

```
Definition 7.2
|- ∀ X p i j n.
f X p i j n = prob p { (x | FPT X x j = n) | { x | X 0 x = i } }
```

Another important notation, denoted as $f_{ij}$ is the probability of the events starting from state $i$ and visiting state $j$ at all times $n$, is expressed as $f_{ij} = \sum_{n=1}^{\infty} f_{ij}^{(n)}$. It can be expressed in HOL4 as ($\lambda$ n. f X p i j n) sums $f_{ij}$. Thus $f_{ij}$ provides the probability of events starting from state $j$ and eventually returning back to $j$. If $f_{jj} = 1$, then the mean return time of state $j$ is defined as $\mu_j = \sum_{n=1}^{\infty} n f_{jj}^{(n)}$. The existence of this infinite summation can be specified as $summable (\lambda$ n. n * f X p j j n) in HOL.

A state $j$ in a DTMC $\{ X_j \}_{j \ge 0}$ is called transient if $f_{jj} < 1$, and persistent if $f_{jj} = 1$. If the mean return time $\mu_j$ of a persistent state $j$ is finite, then $j$ is said to be persistent non null state (or positive persistent state). Similarly, if $\mu_j$ is infinite, then $j$ is termed as persistent null state.
