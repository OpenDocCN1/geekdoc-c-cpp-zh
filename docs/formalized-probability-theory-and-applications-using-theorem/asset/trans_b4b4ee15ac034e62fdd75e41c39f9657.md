```
|- ∀ X p a b.
prob_space p /\ (events p = POW (p_space p)) /\
(∃ y x. X y ≠ NegInf /\ X y ≠ PosInf) /\
a <= b ==> survival_function p X b <= survival_function p X a
```

定理 9.7 的证明同样基于随机变量的累积分布函数（CDF）的性质。

同样，其他寿命分布，如危险函数、累积危险函数和随机变量的 p 阶分位数，也可以在 HOL 中形式化。本章所呈现的工作，首次使得在定理证明器的可靠环境中进行精确的寿命可靠性建模与分析成为可能。尽管该方法具有交互性，但它非常灵活，允许使用单参数和多参数、有界和无界的连续随机变量来建模寿命行为。这使我们能够建模递增、恒定和递减的失效率，以及短期和长期的寿命行为。事实上，目前支持任何具有闭式 CDF 表达式的随机变量，并可以对其进行形式化推理。这种能力使其适用于安全关键工程系统中大量的可靠性分析问题。

## 12.4 可靠性框图

可靠性框图（RBD）（Abd-Allah, 1997）用于评估各种工程系统（Sahinoglu, 2007; Huffman & Antelme, 2009; Kolowrocki, 2009; Lin et al., 2010）的各种失效相关特性，例如可靠性、可用性、可依赖性和可维护性。其主要思想是用 RBD 表示给定系统的行为，即由块和连接器（线）组成的图形结构。例如，在评估计算软件的可靠性时，块可能表示计算元素，并带有给定的失效率，它们之间的连接器可用于描述使用给定软件进行成功计算所需的各种替代路径。现在，基于此 RBD，整体系统的失效特性可以基于各个组件的失效率来判断，而当所有成功执行路径都失效时，整体系统即发生失效。基于 RBD 的分析使我们能够评估组件失效对整体系统安全性和可靠性的影响，因此在系统设计阶段被广泛用于评估各种可能系统配置（如串联、并联或两者的组合）的权衡。

传统上，基于 RBD 的分析是使用纸笔证明方法和计算机仿真进行的（Sahinoglu & Ramamoorthy, 2005）。纸笔证明方法的第一步是用子模块的失效率 \(\lambda\) 和一个随机变量（如指数随机变量或韦布尔随机变量，用于建模失效时间）来表示子模块的可靠性。然后，这些信息连同系统的 RBD 一起，用于解析推导系统级失效特性的数学表达式。由于涉及手动操作和简化，这种分析容易出错，而在分析大型系统时问题会更加严重。此外，事实上，常见的情况是，解析证明所需的许多关键假设存在于数学家的脑海中，并未被记录下来。因此，这些缺失的假设未被传达给设计工程师，并在系统实现中被忽略，这也可能导致错误的设计。基于 RBD 的计算机模拟器，如 ReliaSoft (2015) 和 ASENT 可靠性分析工具 (2014)，从指数和韦布尔随机变量生成样本，以建模系统子模块的可靠性。然后，这些数据使用计算机算术和数值技术进行处理，以计算完整系统的可靠性。这些软件比纸笔证明方法更具可扩展性。然而，由于涉及伪随机数和数值方法，它们也无法保证绝对正确性。

为了克服上述不准确性问题，形式化方法也已被提出用于基于 RBD 的分析。例如，彩色 Petri 网（CPN）（Rodious, Xu, Xing & Zhou, 2010）已被用于建模动态 RBD（DRBD），用于描述系统的动态可靠性行为。然后，基于模型检查原理的 CPN 验证工具被用于验证 DRBD 模型的行为属性，以识别设计缺陷。然而，由于基于状态的模型，这种方法仅支持与状态相关的属性验证，如死锁检查，即，我们不能使用该方法验证给定系统的通用可靠性关系。另一方面，高阶逻辑定理证明器 HOL4 可以使用 HOL4 定理证明器中可用的概率理论进行 RBD 分析，以形式化可靠性框图和指数随机变量。在本章中，我们形式化了服务、并联、并串联和串并联 RBD 配置。并联配置允许我们建模系统成功路径中的冗余，且仅当所有冗余路径都失效时，整体系统才失效。因此，现实世界系统的大多数 RBD 涉及串联和并联配置的组合，而本章的结果使我们能够正式评估更广泛系统的可靠性。为了说明我们工作的实际有效性，我们利用基础形式化对一个网络网络和一个简单的石油天然气管道结构进行了正式可靠性分析。事实上，鉴于所提方法的通用性，我们能够正式验证任意节点网络网络和任意组件管道结构的通用可靠性关系，并且我们的结果可以特化以获得任何特定网络和管道的可靠性。

基于 RBD 的分析基于这样一个假设：与系统子组件相关的可靠性事件彼此相互独立。本节提供了确保 n 个事件相互独立的通用形式化，我们将在后面用于所有 RBD 配置的形式化。

任何两个事件 A 和 B，当且仅当 Pr (A ∩ B) = Pr (A) Pr (B) 时，被称为相互独立。通常，系统可靠性评估涉及多于两个随机变量，即 Pr (∩_{i=0}^{n} L_i) = ∏_{i=0}^{n} Pr (L_i)。因此，我们按照 (Ahmad, Hasan, Tahar & Hamdi, 2014) 形式化了随机变量列表的相互独立性：

### 定义 12.3

```
|- ∀ p L. mutual_indep p L = ∀ L1 n. PERM L L1 /\
2 <= n /\ n <= LENGTH L ==>
prob p (inter_set p (TAKE n L1)) =
list_prod (list_prob p (TAKE n L1))
```

### 表 1. 定义 12.3 中使用的 HOL4 函数

| 函数 | HOL 定义 |
|---|---|
| PERM | |- ∀ L1 L2. PERM L1 L2 = ∀ x. FILTER(=x) L1 = FILTER(=x) L2 |
| LENGTH | - (LENGTH [] = 0) /\ ∀ h. LENGTH (h::x) = SUC (LENGTH x) |
| TAKE | - (∀ n. TAKE n ([]:α) = []) /\ ∀ n x xs. TAKE n (x::xs) = if n = 0 then [] else x:TAKE (n - 1) xs |
| inter_list | - (∀ p. inter_list p [] = p_space p) /\ ∀ p b t. inter_list p (b::t) = b ∩ inter_list p t |
| list_prod | - (list_prod [] = 1) /\ ∀ h t. list_prod (h::t) = h * list_prod t |
| list_prob | - (∀ p. list_prob p [] = []) /\ ∀ p h t. list_prob p (h::t) = prob p (h) * list_prob p t |
| compl_list | - (∀ p L. compl_list p L = MAP (λa. p_space p DIFF a) L) |
| min | - ∀ x y. min x y = if x ≤ y then x else y |
| min_rel | - (∀ f t. min_rel f ([]:α) = 1) /\ ∀ f b t. min_rel f (b::t) = min (f b) (min_rel f t) |

函数 mutual_indep 接受事件列表 L 和概率空间 p，如果给定列表中的事件在概率空间 p 中是相互独立的，则返回 True。上述定义中使用的 HOL4 函数的正式定义见表 1。函数 PERM 接受两个列表作为参数，并确保这些列表互为排列。函数 LENGTH 返回给定列表的长度。函数 TAKE 返回其参数列表的前 n 个元素作为一个列表。函数 inter_set 对其参数列表中的所有集合进行交运算，如果给定的集合列表为空，则返回概率空间。函数 list_prob 接受一个事件列表，并返回给定概率空间中给定事件列表中事件关联的概率列表。最后，函数 list_prod 递归地将给定实数列表中的所有元素相乘。使用这些函数，定义 12.3 中给出的函数 mutual_indep 模拟了相互独立性条件，即对于从给定列表 L 的任何排列中取出的任意 2 个或更多事件 n，属性 Pr (∩_{i=0}^{n} L_i) = ∏_{i=0}^{n} Pr (L_i) 成立。

接下来，我们定义一个由给定随机变量列表构造的事件列表，使得每个事件基于相应的随机变量，对给定时间下组件或系统的正常运行进行建模。

### 定义 12.4

```
|- ∀ p. rel_event_list p [] x = [] ∧
|- ∀ p x h t. rel_event_list p (h::t) x =
PREIMAGE h {y | Normal x < y} ∩
p_space p :: rel_event_list p t x
```

函数 rel_event_list 接受概率空间 p、表示各个组件失效时间的随机变量列表，以及表示所需可靠性时间索引的实数 x。它返回一个事件列表，表示时间 x 时所有各个组件的正常运行。

同样，我们可以按如下方式建模列表中每个随机变量的个体可靠性：

### 定义 12.5

```
|- ∀ p. rel_list p [] x = [] ∧
|- ∀ p h t x. rel_list p (h::t) x =
Reliability p h x :: rel_list p t x
```
