
The assumptions in the above theorem ensure that the sets in the sequence A are mutually exclusive. The set BIGUNION (IMAGE A (count n)) denotes the set { A_i | i ∈ N }, since the function BIGUNION takes the union of all sets in the set (IMAGE A UNIV). The right-hand side of the equality in the above theorem represents the infinite summation of the real sequence (λi. Pr(A_i | B)) using the HOL4 function SIGMA. The proof of the above property is based on some already verified set theoretic principles and the additive law of probability.

## 5.4.3 Complement Axiom of Conditional Probability

$Pr(A | B) = 1 - Pr(A \cap B)$ (5.5)

According to this property, a conditional probability follows the complement axiom just like the probability function. It can be expressed in higher-order logic, using our conditional probability definition, as follows:

### Theorem 5.8

```
|- \/ A B p. (prob_space p) /\ (A IN events p) /\ (COMPL A IN events p) /\
(B IN events p) /\ (0 < (prob p B)) ==>
(cond_prob p (COMPL A) B = 1 - cond_prob p A B)
```

The proof is primarily based on the probability additive law as the events A and COMPL A are disjoint.

## 5.4.4 Difference Axiom of Conditional Probability

$Pr(A1 - A2 | B) = Pr(A1 | B) - Pr(A1 \cap A2 | B)$ (5.6)

This property allows us to express the probability of an event A1 - A2 (difference between the sets A1 and A2) given some other event B without using the notion of set difference. It can be expressed in higher-order logic as follows:

### Theorem 5.9

```
|- \/ A1 A2 B p. (prob_space p) /\ (A1 IN events p) /\ (A2 IN events p) /\
(B IN events p) ==>
(cond_prob p (A1 DIFF A2) B =
cond_prob p A1 B - cond_prob p (A1 INTER A2) B)
```

The property is verified using the probability additive law along with some set theoretic reasoning.

## 5.4.5 Union Axiom of Conditional Probability

$Pr (A_1 \cup A_2 | B) = Pr (A_1 | B) + Pr (A_2 | B) - Pr (A_1 \cap A_2 | B)$ (5.7)

This property allows us to express the probability of an event $A_1 \cup A_2$ (union of the sets A1 and A2) given some other event B without using the notion of union. It can be expressed in higher-order logic, using our conditional probability definition.

### Theorem 5.10

```
|- ∀A1 A2 B p. (prob_space p) ∧ (A1 IN events p) ∧ (A2 IN events p) ∧
(B IN events p) ⇒
(cond_prob p (A1 UNION A2) B =
(cond_prob p A1 B) + (cond_prob p A2 B) - (cond_prob p (A1 INTER A2) B))
```

The proof is again based on the probability additive law primarily.

## 5.4.6 Multiplication Rule of Probability

$Pr (A \cap B) = Pr (B) Pr (A | B)$ (5.8)

Sometimes also referred to as the theorem of compound probabilities, the multiplication rule of probabilities is quite often found to be very useful for determining the probability that two events A and B will occur simultaneously. It can be expressed in higher-order logic as follows:

### Theorem 5.11

```
|- ∀p A B. (prob_space p) ∧ (A IN events p) ∧ (B IN events p) ⇒
(prob p (A INTER B) = (prob p B) * (cond_prob p A B))
```

The proof of the above property is based on the conditional probability definition and the fact that if the probability of event B is 0 then the probability of (A ∩ B) is also 0.

## 5.4.7 Total Probability Theorem

For a finite, mutually exclusive, and exhaustive sequence B_i of events and an event A,

$Pr(A) = \sum_{i=1}^m Pr(B_i) Pr(A | B_i)$

The law of total probability is a useful tool for breaking down the computation of a probability into a number of distinct cases. It can be expressed in higher-order logic as follows:

### Theorem 5.12

```
|- ∀p A B s . (prob_space p) ∧ (A IN events p) ∧ FINITE s ∧
(∀x . x IN s ⇒ B x IN events p) ∧
(∀a b. a IN s ∧ b IN s ∧ ~(a = b) ⇒ DISJOINT (B a) (B b)) ∧
(BIGUNION (IMAGE B s) = p_space p) ⇒
(prob p A = SIGMA (λi. (prob p (B i)) * (cond_prob p A (B i))) s)
```

The variable A in the above theorem represents an event, whereas B represents a sequence of sets. The assumption with the BIGUNION ensures that the elements of the sequence B are exhaustive, i.e., their union gives the sample space or the universal set. Moreover, the sets in sequence B are also mutually exclusive according to another assumption. The right-hand side of the equality in the above theorem represents the summation of the first m terms of the real sequence (λi. Pr(B_i) * Pr(A | B_i)) using the HOL4 function SIGMA.

The proof of the above theorem is based the probability additive axiom along with some set theoretic principles.

## 5.4.8 Bayes' Law

$Pr(A | B) = \frac{Pr(B | A) Pr(A)}{Pr(B)}$

Bayes' law, named after the famous English philosopher Thomas Bayes, relates the conditional and marginal probabilities of two random events. In probabilistic analysis, posterior probabilities under some given observations are usually computed using Bayes' law. It can be expressed in the general form as follows:

$Pr(A | B) = \frac{Pr(B | A_i) Pr(A_i)}{\sum_{i=1}^m Pr(B | A_i) Pr(A_i)}$

which can be formalized in HOL4 as the following higher-order logic theorem as follows:

### Theorem 5.13

```
|- ∀p A B s k. (prob_space p) ∧ (A IN events p) ∧ FINITE s ∧
(∀x . x IN s ⇒ B x IN events p) ∧
(∀a b. a IN s ∧ b IN s ∧ ~(a = b) ⇒ DISJOINT (B a) (B b)) ∧
(BIGUNION (IMAGE B s) = p_space p) ⇒
(cond_prob p (B k) A = ((cond_prob p A (B k)) * prob p (B k)) /
(SIGMA (λi. (prob p (B i)) * (cond_prob p A (B i))) s))
```

The proof of the above theorem in HOL4 is based on the multiplication rule of probability and the total probability theorem.

Conditional probability is one of the most widely used probabilistic analysis concepts. It allows us to estimate probabilities when some partial information concerning the result of the experiment is available. This section presents the foundational formalization that can be used to reason about conditional probabilities in a higher-order-logic theorem prover. Markov chains is one of the most commonly used probabilistic modeling theory in areas like Physics, Queueing Theory, Internet applications and statistical testing. The basic definition of a Markov chain is based on the concept of conditional probabilities and thus the above formalization can be built upon to develop an infrastructure for representing and analyzing Markov chains in a theorem prover. The formalization infrastructure, presented in this section, can also be used as is for the analysis of a number of interesting applications, such as communication channels, algorithms for computation problems like the Best Prize problem, and fault detection schemes for hardware designs.

## 5.5 CONCLUSION

In this chapter, we used the formalization of measure theory and Lebesgue information theory to provide a higher-order-logic formalization of the main concepts of probability theory. We formalized the basic definitions of probability spaces and random variables as well as their statistical properties. The foundational notions will be used to formalize Markov chains and information theory in the next chapters.

There are some other formalizations of probability theory as well but they are somewhat limited in some aspects compared to the formalization presented by Mhamdi (2013). For instance, the formalization by Coble (2010) considers finitely-valued measures and functions only as it is based on standard real numbers. Using extended-real numbers in the formalization, as is the case with (Mhamdi, 2013), has many advantages. It allows us to define sigma-finite and other infinite measures as well as signed measures. It also allows defining extended-real valued functions. Similarly the formalization of probability theory, reported in (Hölzl, 2011; Hölzl, 2013), lacks the important properties of the Radon Nikodym derivative and the Kullback-Leibler divergence and the different measures of information. It has not been used to formalize any notion of reliability or wireless sensor networks. Moreover, it also does not handle signed measures or functions taking negative valued as only positive extended-real numbers are supported. Thus, the normalization presented by Mhamdi (2013) is more general and has been selected as the main focus of this manuscript.
