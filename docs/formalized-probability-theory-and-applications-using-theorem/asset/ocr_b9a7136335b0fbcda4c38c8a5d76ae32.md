The proof of Theorem 7.6 is primarily based on the following three subgoals:

+   - 0 \le lim_{n \to \infty} p_j^{(n)}
+   - \sum_{i \in S} lim_{n \to \infty} p_i^{(n)} = 1
+   - lim_{n \to \infty} p_j^{(n)} = \sum_{i \in S} p_i^{(n)} p_{ij}

The first subgoal can be verified using the probability bounds theorem. The proof of the second subgoal is primarily based on the additivity property of conditional probability. Whereas, the last subgoal can be verified using the linearity properties of limit of a sequence and summation.
