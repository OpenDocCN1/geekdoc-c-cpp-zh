

## 14.3 用于边境监控的 WSN

无线传感器网络已被广泛用于边境监控应用（Sun et al., 2011）。部署用于边境监控的 WSN 的主要目标是以高概率和小延迟持续检测入侵元素。这些系统在军事环境中用于检测部队或车辆，或用于防止沿国家边境非法入侵移民或恐怖分子。在此背景下，感兴趣区域可能的恶劣性质使得通过空投传感器进行随机部署更加实用。在本节中，我们有兴趣正式分析部署用于边境监控应用的无线传感器网络的检测性能。

由于目标应用的安全关键特性，部署的 WSN 必须在确保高效检测的同时尽可能长时间保持存活。然而，大多数现有的用于边境监控的 WSN 都存在寿命限制，例如，REMBASS 传感器节点一旦部署，只能工作 30 天。在使用 WSN 监控山区边境沿线的恐怖分子入侵时，显然不需要随时监控整个区域。因此，我们可以在给定的边境监控应用中使用 k-集随机调度算法来保存能量。在指定的应用中，节点的感知区域 r = 30，并部署在大小为 a = 10000m² 的区域内，而传感器覆盖一个点的成功概率 q 为 q = r/a = 0.28。

在上一节中，我们通过区分两种情况：{ L < (k – 1) x Ts } 和 { L ≥ (k – 1) x Ts }，根据入侵长度 L 分析了检测概率 Pr (D)。需要注意的是，在当前的应用分析中，我们关注第一种情况；{ L < (k – 1) x Ts }，它反映了可能无法被检测到的瞬态事件，因此是本分析中最相关的部分。对于另一种情况，即 { L ≥ (k–1) x Ts }，我们已经讨论过检测概率 Pr (D) 等于网络覆盖率。

基于上一节的理论发展，我们现在基于参数 n 和 k 对概率检测和延迟进行正式的渐近分析（Xiao, Zhang, Sun & Chen; 2007）。为此，我们将先处理一般情况，然后将其实例化为给定的边境监控应用。因此，我们简单地将 (prob p (p_space p DIFF (udset n k s L Ts q))) 表示为 (Pd_wsn p n k s L Ts q)，将 (delay_wsn p n D k q) 表示为 (D_wsn p D n k q)。在我们的应用背景下，我们基本上验证了与感兴趣事件的检测概率和检测延迟相关的两个主要感兴趣属性。因此，我们在 HOL4 中轻松检查 (prob p (p_space p DIFF (udset n k s L Ts (0.28)))) 等于

```
1 - ((1 - s) \times \left( 1 - \frac{\lfloor L/T_s \rfloor}{k} \times (0.28) \right)^n - s \times \left( 1 - \frac{\lfloor L/T_s \rfloor}{k} + 1 \times (0.28) \right)^n
```

并且，预期检测延迟，(delay_wsn p D n k (0.28))，为

```
\sum_{j=1}^n E(D|c=j) \times C_n^j \times (0.28)^j \times (1-(0.28))^{n-j}
```

其中 E (D | c = j) 表示方程 (14.30) 中指定的表达式。接下来，我们简单地将方程 (14.31) 和方程 (14.32) 分别表示为 (Pd_surv p n k s L Ts (0.28)) 和 (D_surv p D n k (0.28))。需要注意的是，由于空间限制，在下面的所有渐近分析中，我们只提到与检测概率和延迟中使用的变量相关的主要数学假设。

因此，我们正式验证检测概率是 n 的递增函数，即较大的 n 值会导致更好的检测概率。

### Lemma 14.1

```
\vdash \forall p k q s L Ts. (1 < k) \land (0 < s < 1) \land (0 < L) \land (0 < Ts) \land (L < s (k-1) \times Ts) \land (0 < q < 1) \Rightarrow (mono_incr (\lambda n. Pd_wsn p n k s L Ts q)) .
```

其中 mono_incr 是 HOL4 中递增序列的定义，我们定义如下：

### Definition 14.7

```
\vdash \forall f. mono_incr f \iff \forall n. f n \le f (SUC n) .
```

此外，我们在 Lemma 14.2 中正式验证，随着部署节点数量变得非常非常大，检测入侵事件的概率趋近于 1。

### Lemma 14.2

```
|- !V p k q s L Ts. (1 < k) /\ (0 < s < 1) /\ (0 < L) /\ (0 < Ts) /\
(L < s & ((k-1) x Ts) /\
(0 < q < 1) ==> lim n-->+inf (|An. Pd_wsn p n k s L Ts q) = 1.
```

其中 lim 是 HOL4 对实数序列极限的形式化。

同样，研究随机调度的延迟行为也非常有用。因此，我们在 Lemma 14.3 中正式验证，检测延迟 D_wsn 从给定范围（记为 n0）开始随节点数量 n 的增加而减小。因此，当部署大量节点时，D_wsn 会变小。在这种情况下，入侵预计会被更快地检测到，因为周围区域可能部署了更多覆盖节点。

### Lemma 14.3

```
|- !V p k q s L Ts. (1 < k) /\ (0 < s < 1) /\ (0 < L) /\ (0 < Ts) /\
(0 < q < 1)
==> (mono_decr_range (|An. (real (D_wsn p n k q)))) .
```

其中函数 real 用于将扩展实数类型的检测延迟转换为其对应的实数值。

### Definition 14.8

```
|- !V f. mono_decr_range f <=> (!E n0. !N. n >= n0 ==> f (SUC n) <= f n) .
```

基于 Lemmas 14.1 和 14.2，我们建立，对于输入变量 k、q、s、L 和 Ts 的任何值，都可以通过增加部署节点数量 n 来实现任何目标检测概率 Pd_wsn。更具体地说，这些结果可以在给定的边境监控应用背景下轻松验证检测概率 Pd_surv（Lemmas 14.4 和 14.5）。

### Lemma 14.4

```
|- !V p k s L Ts. (1 < k) /\ (0 < s < 1) /\ (0 < L) /\ (0 < Ts) /\
(L < s & (k - 1) x Ts)
==> (mono_incr (|An. Pd_surv p n k s L Ts (0.28)))) .
```

### Lemma 14.5

```
⊢ ∀ p k s L Ts. (1 < k) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts) ∧
(L < s & (k - 1) x Ts)
⇒ lim (∀ n. Pd_surv p n k s L Ts (0.28)) = 1.
```

此外，我们使用 Lemma 14.6 重新确认了 Lemma 14.3 的结果，即增加部署节点数量 n 会得到更小的检测延迟，从而获得更好的部署应用性能。

### Lemma 14.6

```
⊢ ∀ p k s L Ts. (1 < k) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts)
⇒ (mono_decr_range (∀ n. (real (D_surv p D n k (0.28))))).
```

根据 Lemmas 14.1 和 14.3，通过部署更多节点可以增强部署 WSN 的检测能力。然而，随机部署已知对大多数 WSN 应用来说成本非常高。在使用 k-集随机调度的 WSN 背景下，通常可以通过简单地将不相交子集的数量 k 更新为合适值来提高网络的整体检测能力。

基于参数 k，我们现在对检测性能的极限行为进行一项有趣的研究。首先，我们正式验证较小的 k 值会诱导更大的检测概率 Pd_wsn，即 Pd_wsn 随 k 值的增加而减小：

### Lemma 14.7

```
⊢ ∀ p k q n s L Ts. (1 ≤ n) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts) ∧
(0 < q < 1) ∧
(∀k. L < s & (SUC k) x Ts) ⇒ (mono_decr (∀k. Pd_wsn p n k s L Ts q)).
```

其中 HOL4 函数 mono_decr 将递减序列定义如下：

### Definition 14.9

```
⊢ ∀ f. mono_decr f ⇔ ∀n. f (SUC n) ≤ f n.
```

我们正式确定，给定节点数量 n 时，当 k 变得非常大时，检测概率 Pd_wsn 趋近于 0：

### Lemma 14.8

```
⊢ ∀ p q n s L Ts. (1 ≤ n) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts)
∧ (0 < q < 1) ∧
(∀k. L < s (SUC k) x Ts) ⇒ lim (λk. Pd_wsn p n k s L Ts q) = 0.
k→∞
```

此外，我们在 Lemma 14.9 中表明，随机调度的检测延迟 D_wsn 随 k 值的增加而增加。换句话说，当 WSN 被划分为相当数量的子网络 k 时，检测延迟 D_wsn 会增加。确实，分配给每个子集的时间槽会很小，以至于活动节点没有足够的时间来检测发生的入侵。

### Lemma 14.9

```
⊢ ∀ p q n s L Ts. (1 ≤ n) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts) ∧
(0 < q < 1)
⇒ (mono_incr (λk. real (D_wsn p D n k q))).
```

需要注意的是，上述引文中原始证明缺少一个完整的分数项，幸运的是它是正的，因此最终不影响函数单调性的有效性。

现在，可以在接下来的 2 个引文中，确认 Lemmas 14.7 和 14.8 给出的通用结果对于我们的 WSN 应用的有效性。

### Lemma 14.10

```
⊢ ∀ p k n s L Ts. (1 ≤ n) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts) ∧
(∀k. L < s (SUC k) x Ts)
⇒ (mono_decr (λk. Pd_surv p n k s L Ts (0.28))).
```

因此，对于边境监控应用，增加 k 当然可以节省更多能量，但 k 的显著增加可能会导致多个子网络，进而转化为较差的检测概率。

### Lemma 14.11

```
⊢ ∀ p k n s L Ts. (1 ≤ n) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts) ∧
(∀k. L < s (SUC k) x Ts)
⇒ lim (λk. Pd_surv p n k s L Ts (0.28)) = 0.
k→∞
```

同样，我们检查 k 的显著增加会导致更大的检测延迟，即性能较差：
