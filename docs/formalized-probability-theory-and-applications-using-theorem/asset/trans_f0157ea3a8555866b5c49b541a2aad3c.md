

## 第 4 章 测度论与勒贝格积论

## 摘要

如前章所述，测度和勒贝格积的基本理论是高阶逻辑中概率论形式化的先决条件。本章的范围主要是这些基础的形式化。本章介绍的测度论和勒贝格积（Mhamdi, Hasan, & Tahar, 2011）的两种形式化均基于扩展实数。这使我们能够定义 σ-有限甚至无穷测度，并处理扩展实数值可测函数。它还使我们能够验证勒贝格积及其针对任意函数的收敛定理的性质。因此，本章首先描述扩展实数的形式化。

### 4.1 扩展实数的形式化

扩展实数集 R' 是实数集 R 加上两个附加元素（即正无穷 +∞ 和负无穷 -∞）得到的集合。扩展实数在许多数学领域中用于描述极限行为。特别是，有必要使用扩展实数系统来定义积分理论，否则单调收敛和主导收敛等收敛定理的实用性将大打折扣。同样，使用扩展实数来定义测度论使我们能够定义无穷测度，如 σ-有限测度。我们现在描述 HOL4 中扩展实数的形式化。

#### 4.1.1 类型与运算符

扩展实数要么是普通实数，要么是正无穷，要么是负无穷。我们使用 Hol_datatype 定义新类型 extreal，如下所示：

```
val _ = Hol_datatype 'extreal = NegInf | PosInf | Normal of real'
```

HOL4 记法 x: extreal 用于指定变量 x 的类型为 extreal。函数 Normal 将 HOL4 中的实数转换为其对应的扩展实数。例如，Normal (1: real) 返回一个扩展实数 (1: extreal)。实数的所有算术运算都需要为新类型扩展。这可以通过在新类型上定义 HOL4 函数，然后使用这些函数重载常用运算符来完成。例如，扩展实数上的加法运算可以使用函数 extreal_add 定义如下：

### 定义 4.1

```
∀ x y. extreal_add (Normal x) (Normal y) = (Normal (x + y)) ∧
extreal_add (Normal _) a = a ∧
extreal_add b (Normal _) = b ∧
extreal_add NegInf NegInf = NegInf ∧
extreal_add PosInf PosInf = PosInf
```

当一个操作数为 PosInf 而另一个为 NegInf 时，该函数未定义。+ 运算符随后被重载为

```
val _ = overload_on ("+", Term 'extreal_add');
```

同样，其他算术运算也已为扩展实数定义，其对应的运算符可以在 HOL4 中如下重载：

```
val _ = overload_on ("--", Term 'external_sub');
val _ = overload_on ("**", Term 'external_mul');
val _ = overload_on ("//", Term 'external_div');
val _ = overload_on ("<=", Term 'external_le');
val _ = overload_on ("<<", Term 'external_lt');
val _ = overload_on ("^~", Term 'external_ainv');
val _ = overload_on ("numeric_negate", Term 'external_ainv');
val _ = overload_on ("inv", Term 'external_inv');
val _ = overload_on ("abs", Term 'external_abs');
val _ = overload_on ("logr", Term 'external_logr');
val _ = overload_on ("lg", Term 'external_lg');
val _ = overload_on ("exp", Term 'external_exp');
val _ = overload_on ("pow", Term 'external_pow');
val _ = overload_on ("sqrt", Term 'external_sqrt');
```

顺序关系（例如）被扩展为：\(\forall a \in \mathbb{R}^+, -\infty \le a \le +\infty\)。

### 定义 4.2

```
|- ∀ x y. extreal_le (Normal x) (Normal y) = (x ≤ y) ∧
 extreal_le NegInf a = T ∧
 extreal_le b PosInf = T ∧
 extreal_le e NegInf = F ∧
 extreal_le PosInf d = F
```

根据定义 4.2 所示的顺序，R' 是一个完全格，其中每个子集都有上确界和下确界。

#### 4.1.2 上确界与下确界

集合 \(s \subseteq R'\) 的上确界或最小上界是 R' 中大于或等于 s 中每个元素的最小元素。上确界可以在 HOL4 中定义为：

### 定义 4.3

```
|- ∀p. extreal_sup p =
 if ∀x. (∀y. p y ⇒ y ≤ x) ⇒ (x = PosInf) then PosInf
 else (if ∀x. p x ⇒ (x = NegInf) then NegInf
 else Normal (sup (∀r. p (Normal r))))
```

在此定义中，sup 指的是实数集合上的上确界。集合 s ⊆ R' 的下确界或最大下界是 R' 中小于或等于 s 中每个元素的最大元素。上确界的定义现在可以用于形式化下确界，如下所示：

### 定义 4.4

```
∀p. extreal_inf p = - extreal_sup (IMAGE numeric_negate p)
```

函数 numeric_negate 以集合为参数，并返回一个新集合，其中原始集合的所有元素都被取反。现在可以使用这些新定义重载常规 HOL4 运算符 sup 和 inf：

```
val _ = overload_on ("sup", Term 'external_sup');
val _ = overload_on ("inf", Term 'external_inf');
```

基于上述定义，扩展实数的各种经典性质已在 HOL 中得到正式验证。例如，一个有趣的性质指出，对于任何非空且有上界（由有限数界定）的扩展实数集 P，存在 P 中元素的一个单调递增序列，其收敛于 P 的上确界。

#### 4.1.3 集合上的求和

扩展实数在有限集合上的求和已形式化如下：

### 定义 4.5

```
⊢ ∀f s. SIGMA (f: 'a -> extreal) (s: 'a -> bool) =
   if FINITE s then
   if s = {} then 0: extreal
   else f (CHOICE s) + SIGMA f (REST s)
   else ARB
```

从该定义中，更方便使用的递归形式可以作为以下定理验证。

### 定理 4.1

```
⊢ ∀ f s. FINITE s ⇒
   ∀ e. (∀x. x ∈ e INSERT s ⇒ f x ≠ NegInf) ∨
   (∀ x. x ∈ e INSERT s ⇒ f x ≠ PosInf) ⇒
   (SIGMA f (e INSERT s) = f e + SIGMA f (s DELETE e))
```

基于此性质，已验证了许多涉及求和的有趣性质，包括其线性性、单调性以及不相交集和集合积上的求和。

最后，扩展实数的无穷和 $\sum_{r \in \mathbb{N}}$ 可以使用 SIGMA 和 sup 运算符定义如下：

### 定义 4.6

```
∀f. ext_suminf f = sup (IMAGE (λn. SIGMA f (count n)) UNIV)
```

扩展实数的 HOL4 形式化包含约 4500 行代码中编写的 220 多个定理，包含形式化测度论和概率论所需的大多数概念所需的所有必要工具。

### 4.2 测度论的形式化

测度是一种为集合赋予数值（解释为其大小）的方法，可以被视为长度、面积、体积等概念的推广。两个重要的例子是欧几里得空间上的勒贝格测度和博雷尔空间上的概率测度。前者将欧几里得几何的常规长度、面积和体积赋予 $\mathbb{R}^n, n = 1; 2; 3$ 的合适子集，后者将概率赋予事件，并满足样本空间的测度等于 1 的条件。

测度论的 HOL4 形式化（Mhamdi, Hasan & Tahar, 2010）主要基于带有著名选择公理的策梅洛-弗兰克尔集合论（ZFC）。该集合论是至今最常见的数学基础，并允许避免使用朴素集合论引起的若干悖论。然而，选择公理暗示了反直觉集合的存在，并引发其自身的悖论，特别是巴纳赫-塔斯基悖论，该悖论指出可以将一个实心单位球分解为有限多个碎片，并仅使用旋转（无缩放）将其重新组装成原球的两个副本。该悖论表明，在 ZFC 集合论的背景下，无法同时定义三维空间中的体积并要求旋转保持体积，且两个不相交集合的体积等于它们体积之和。解决办法是将某些集合标记为不可测集，并仅为可测集赋予体积。因此，测度函数定义在称为可测集的子集类上，并为每个可测集赋予一个非负实数。它满足可数可加性条件，该条件指出不相交集合集合的并的测度等于它们测度之和。
