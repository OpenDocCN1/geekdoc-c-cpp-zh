

## 6.2 形式验证 DTMC 属性

### 6.2.1 联合概率定理

有限 DTMC $\{X_t\}_{t \in S}$ 中 n 个离散随机变量 $X_0, X_n$ 的联合概率分布满足

Pr (Xt = L0, ..., Xt+n = Ln) = \prod_{k=0}^{n-1} (Pr (Xt+k+1 = Lk+1 | Xt+k = Lk)) Pr (Xt = L0) (6.3)

DTMC 的联合概率分布是状态链发生的概率。它在分析多阶段实验中非常有用，特别是定义在联合概率分布上的稳态过程。联合概率分布也用于分析马尔可夫链的可逆性。此外，这一概念是联合概率生成函数的基础，该函数用于许多不同的领域。该属性已在 HOL4 中验证为：

```
**定理 6.1**
|- ∀ X p s t L P0 P1s.
dtmc X p s P0 P1s =>
prob p (\bigcap_{k=0}^{n} {x | X (t + k) x = EL k L} =
(PROB (0, n) (\lambda k. prob p ({x | X (t + k + 1) x = EL (k + 1) L} |
{x | X (t + k) x = EL k L})))
prob p {x | X t x = EL 0 L }
```

上述定理的证明基于变量 n 的归纳。利用一些集合和实数运算推理可以轻松验证基础情况。而步骤情况则通过首先将 P (\bigcap_{k=0}^{n} {x | X (t + k) x = EL k L}) 重写为 P (

\bigcap_{k=0}^{n} {x | X (t + k) x = EL k L} \cap {x | X (t + n + 1) x = EL (n + 1) L }

，从而利用前一章中验证的条件概率属性。

### 6.2.2 查普曼-科尔莫戈罗夫方程

对于有限时间齐次 DTMC $\{ X_t \}_{t \in \sigma^+}$，其转移概率满足查普曼-科尔莫戈罗夫方程

$P_{ij}^{(m+n)} = \sum_{k \in S} P_{ik}^{(m)} P_{kj}^{(n)}$ (6.4)

查普曼-科尔莫戈罗夫方程是时间齐次 DTMC 的广泛使用属性。它给出了从状态 $i$ 到 $j$ 在 $m+n$ 步内转移的概率。假设前 $m$ 步将系统从状态 $i$ 带到某个中间状态 $k$，而剩余的 $n$ 步则将系统从状态 $k$ 带到 $j$，我们可以通过添加所有中间步骤相关的概率来获得所需概率。

### 定理 6.2

```
|- ∀ X p s i j t m n P₀ Pᵢⱼ.
th_dtmc X p s P₀ Pᵢⱼ ⇒
(Trans X p s t (m + n) i j =
SIGMA (IMAGE (λ k. Trans X p s t m i k * Trans X p s t n k j)
(k ∈ space s)))
```

上述内容再次使用变量 m 和 n 的归纳进行验证。基础情况和步骤情况都使用以下多步转移概率引理来证明。

### 引理 6.2

```
|- ∀ X p s i j t m P₀ Pᵢⱼ.
th_dtmc X p s P₀ Pᵢⱼ ⇒
(Trans X p s t (m + 1) i j =
SIGMA (IMAGE (λ k. Trans X p s t 1 k j * Trans X p s t m i k)
(k ∈ space s)))
```

这给出了 m 步转移概率 $P_{ij}^{(m)} = \sum_{k \in S} P_{ik}^{(m)} P_{kj}$。引理 6.2 的证明主要基于概率的可加性属性。

在时间齐次 DTMC 中，n 步转移概率 $p_{ij}^{(n)}$ 与时间无关。这可以如下证明：

### 引理 6.3

```
|- ∀ X p s i j t m n P_i P_j.
th_dtmc X p s p0 pi ⇒
(Trans X p s m t i j = Trans X p s n t i j)
```

上述引理的证明基于变量 t 的归纳。本引理将在本章后续用于证明许多其他定理。

### 6.2.3 绝对概率

在有限时间齐次 DTMC 中，绝对概率 \(P_j^{(n)}\) 满足 \(P_j^{(n)} = Pr(X_n = j) = \sum_{k \in \Omega} Pr(X_0 = k) Pr(X_n = j | X_0 = k)\)

与马尔可夫链相关的无条件概率称为绝对概率，可以通过应用初始分布和 n 步转移概率来计算。这表明，给定初始概率分布和 n 步转移概率，可以使用此方程从开始时间 0 后 n 步获得状态 j 的绝对概率。

该属性正式验证如下：

### 定理 6.3

```
|- ∀ X p s j n P_i P_j.
th_dtmc X p s p0 pi ⇒
(prob p { x | X n x = j } =
SIGMA (IMAGE (\k. P { x | X 0 x = k }
prob p { ( x | X n x = j ) | ( x | X 0 x = k ) }) (k \in space s)))
```

定理 6.3 的证明基于全概率定理，并结合一些基本算术和概率论推理。

### 6.2.4 可逆性属性

如果随机过程 \(\{ X_t \}_{t \ge 0}\) 的序列 \(X_{t_0} X_{t_1} .... X_{t_n}\) 的联合概率与 \(X_{t_n} X_{t_{n-1}} .... X_{t_0}\) 的分布相同，则称其为可逆的，即：\(Pr \{ X_{t_1} = x'_{t_1}, ..., X_{t_n} = x'_{t_n} \} = Pr \{ X_{t_1} = x'_{t_n}, ..., X_{t_n} = x'_{t_1} \}\)。

这种可逆随机过程可以在 HOL4 中定义如下：

### 定义 6.5

```
⊢ ∀ X p s L t.
Reversible_proc X p s = (prob p (⋂ {k=0}^{|L|-1} {Xt+k = EL k L }))
= prob p (⋂ {k=0}^{|L|-1} {Xt+k = EL k (REVERSE L) }))
```

其中 |L| 表示所考虑链的长度。

在马尔可夫链理论中，某些马尔可夫链满足详细平衡方程，这确保该马尔可夫链具有平衡分布。这种马尔可夫链表现出可逆性特征，称为可逆马尔可夫链。从数学上讲，详细平衡方程表示为

π (i) P_ij = π (j) P_ji ∀ i,j ∈ Ω (6.5)

其中 π(i) 和 π(j) 是处于状态 i 和 j 的平衡概率。详细平衡方程可以形式化为：

### 定义 6.6

```
⊢ ∀ f X p s. db_equations f X p s =
∀ i j t. (f i * Trans X p s t 1 i j = f j * Trans X p s t 1 j i)
```

函数 f 表示方程 (6.5) 中的概率分布 π。请注意，如果 i 或 j 不在状态空间中，则可以推断转移概率 P_ij 和 P_ji（分别对应 Trans X p s t 1 i j 和 Trans X p s t 1 j i）均等于零，因此方程 (6.5) 的两边均为零。

如果马尔可夫链满足详细平衡方程，则定义为可逆马尔可夫链。HOL4 中的正式定义为：

### 定义 6.7

```
⊢ ∀ X p s P_0 P_1j.
rmc X p s P_0 P_1j =
th_dtmc X p s P_0 P_1j ∀ t. db_equations (λ i. prob p {X_t = i })
X p s
```

可逆马尔可夫链的以下属性已在 HOL 中验证。

### 定理 6.4

```
|- ∀ X p s p₁ Pᵢⱼ t L.
rmc X p s p₁ Pᵢⱼ ==>
(prob p ( ⋂_{k=0}^{|L|-1} { Xt+k = EL k L } ) = prob p (
⋂_{k=0}^{|L|-1} { Xt+k = EL k (REVERSE L ) }))
```

此定理的逆向证明涉及使用定义 6.7 和定理 6.1 重写目标，从而生成以下子目标：

```
PROD (0, | L |)
( λ k. P ( ( t + k + 1) x = EL ( k + 1) (REVERSE L ) ) |
( x | X (t + k) x = EL k (REVERSE L ) )) =
PROD (0, | L |)
( λ k. prob p ({ x | X (t + k + 1) x = EL ( | L | - k - 1) L } |
{ x | X (t + k) x = EL ( | L | - k) L })))
```

现在，可以通过应用以下引理来完成证明：

```
|- ∀ f n. PROD (0, n) (λ k. f k) = PROD (0, n) (λ k. f (n - k - 1))
```

这对应于数学表达式：

```
∏_{k=0}^n f(k) = ∏_{k=0}^n f(n-k-1) (6.6)
```

## 6.3 稳态分布的形式化

在某些条件下，当时间趋于无穷大时，我们通常关心某些特定状态的概率。这是工程和科学领域经常分析随机过程稳态行为的主要原因。

设 {X_t}_{t>=0} 为具有状态空间和转移概率 p_ij ... 的马尔可夫链，如果 (i, j) ∈ Ω 是非负数且和为一，则 π(j) = Σ_{i∈Ω} π(i) pij 称为稳态分布。相应的 HOL4 定义如下：

### 定义 6.8

|- ∀ f X p s .
Stationary_dist f X p s =
(SIGMA (\l k. f k) (k \in space s) = 1) /\
∀ i. i \in space s ==>
0 <= f i /\ (∀ t. f i t = SIGMA (\l k. f k * Trans X p s t 1 k i)
(k \in space s))

然后我们利用此定义来证明广义稳态定理，该定理指出，如果具有有限状态空间 \(\Omega\) 和一步转移概率 \(P_{ij}\) 的 DTMC 具有一个满足详细平衡方程的概率分布 \(\pi\)，则该 DTMC 存在稳态分布。

### 定理 6.5

|- ∀ X p s p0 pij n.
th_dtmc X p s p0 pij /\
db_equations (\l i. prob p { x | X n x = i }) X p s ==>
\exists f. stationary_dist f X p s

其中 f 指的是 \(\pi(x)\)。

该属性的证明是使用概率分布函数 (
\l i. P { x | X n x = i }) 作为 f，因此目标变为：

|- ∀ X p s p0 pij n.
th_dtmc X p s p0 pij /\
db_equations (\l i.P { x | X n x = i }) X p s ==>
stationary_dist (\l i.P { x | X n x = i }) X p s

该子目标可以通过使用详细平衡方程和稳态分布的定义进行重写，并将其拆分为以下三个子目标来验证，这些子目标可以基于概率论基础进行验证。

- 0 <= P { x | X n x = i }
- SIGMA (\l j. P { x | X n x = i } (j \in space s) = 1)
- P { x | X n x = i } =
- SIGMA (\l j. P { x | X n x = j } Trans X p s t j i) (j \in space s)
