

### 定义 9.11

```
⊢ ∀ X Y Z. markov_chain p X Y Z ⇔
∀ x y z, P_{xyz} ( x, y, z ) = P_x ( x ) * P_{y|x} ( y | x ) * P_{z|y} ( z | y )
```

现在，可以验证 X → Y → Z 等价于在给定 Y 的条件下 X 和 Z 条件独立的陈述。事实上，p ( x ) p ( y | x ) p ( z | y ) = p ( x, y ) p ( z | y ) = p ( x | y ) p ( y ) p ( z | y ). 这反过来等价于 I ( X ; Z | Y ) = 0. 这一结果使我们能够将数据处理不等式表示为：如果 X → Y → Z，则 I ( X ; Z ) ≤ I ( X ; Y ).

数据处理不等式可以利用互信息的性质进行验证。事实上，如前所示，I ( X ; ( Y, Z ) ) = I ( X ; Z ) + I ( X ; Y | Z ). 根据互信息的对称性，我们还有 I ( X ; ( Y, Z ) ) = I ( X ; Y ) + I ( X ; Z | Y ). 最后一个等式源于这样一个事实：对于马尔可夫链，I ( X ; Z | Y ) = 0. 利用条件互信息的非负性，可以直接得出结论 I ( X ; Z ) ≤ I ( X ; Y ).

数据处理不等式是信息理论中一个非常重要的结果，例如在统计学中用于定义充分统计量的概念。我们利用数据处理不等式来解释条件信息泄露程度。对于一个具有高安全输入 S、低安全输入 L 和输出 O 的系统，如果输出仅依赖于低输入，即 p ( O | S, L ) = p ( O | L )，则 S → L → O，并且在给定 L 的条件下 S 和 O 条件独立。这是完美安全场景，此时 Dc = 1. 利用数据处理不等式，我们得出 I ( S ; O ) ≤ I ( S ; L ). 这意味着当条件互信息泄露等于 1 时，攻击者对低输入的任何巧妙操纵（无论是确定性的还是随机的）都无法增加 L 所包含的关于 S 的信息（I ( S ; L )）.

## 9.7 结论

在本章中，在测度论、勒贝格积分和概率论形式化的基础上，构建了信息理论主要概念的高阶逻辑形式化。基于 KL 散度的形式化，包括香农熵和互信息在内的大多数常用信息度量均已使用高阶逻辑定义。还引入了两种新颖的信息泄露度量，可用于推理现实世界协议和程序的信息流。

## 关键术语和定义

## 第 10 章 使用最小熵和信念最小熵的信息流形式分析

### 摘要

信息流分析在获取外部攻击导致的信息泄露定量边界方面起着至关重要的作用。传统上，信息流分析是基于香农熵和互信息的纸笔式证明或计算机模拟来完成的。然而，在处理某些特定威胁模型时，这些指标有时会提供误导性信息，例如当秘密在一次尝试中被正确猜中时。最近，Min-Entropy 和 Belief Min-Entropy 指标被提出以解决这些问题。但是，使用这些指标的信息流分析是通过模拟和纸笔方法完成的，因此由于其固有局限性无法确保准确结果。为了克服这些缺陷，本章作者在高阶逻辑中提出了 Min-Entropy 和 Belief Min-Entropy 的形式化，并使用它们在 HOL4 定理证明器的可靠内核中执行信息流分析。为说明目的，他们使用其形式化来评估 HOL 中信道级联的信息泄露。

### 10.1 信息流分析

保护敏感信息的机密性并确保完美匿名性 (Palamidessi, Chatzikokolakis & Panangaden, 2008) 在电信、电子支付、拍卖和投票等许多领域中越来越成为迫切需求。信息流分析使我们能够通过观察给定系统中的输出和低安全输入来获取关于信息泄露的定量估计 (Backes, Kopf & Rybalchenko, 2009)，从而在开发安全和匿名系统方面发挥着至关重要的作用 (Halpern & O'Neill, 2005).

文献中提出了各种评估信息流的方法 (Andrea, 2002). *可能论的* 方法背后的主要思想是使用非确定性行为来模拟给定系统。例如，基于认识逻辑（一种知识和信念逻辑）以及基于进程代数（允许我们模拟并发系统）的信息流分析属于此类。*可能论的* 方法的主要局限性在于其无法区分保护程度不同的系统。*概率论的* 方法基于信息理论和统计学，克服了这一局限性，因此被认为更可靠地评估信息流。最常用的概率信息流度量包括香农熵、敏感输入与可观测输出之间的互信息以及相对熵。最近已经表明，使用此类度量有时会导致反直觉的结果。例如，在特定威胁模型下，当秘密在一次尝试中被正确猜中时，具有高被猜中脆弱性的随机变量可能具有更大的香农熵 (Rényi, 1961).

在一次尝试模型中，对手只有一次机会获取秘密的值。这里的目标是在一次尝试中最大化猜中高输入正确值的概率，她的最佳策略是对概率分布最大的元素进行竞猜。Rényi 的熵度量，即最小熵 (Espinoza & Smith, 2012) 和信念最小熵 (Hamadou, Sassa & Palamidessi, 2010)，可以更有效地处理上述威胁模型，并常用于对确定性和概率性系统中的信息泄露进行建模和分析。

传统上，纸笔式分析或计算机模拟一直用于信息流的定量分析 (Smith (2009); (Smith 2011)). 纸笔式分析在复杂系统中扩展性不佳，且容易出现人为错误。另一方面，计算机模拟使用用于舍入计算机算术的数值近似，这会导致分析不准确。为了提高分析结果的准确性，最近已提出在信息流的安全关键分析领域使用形式化方法。
