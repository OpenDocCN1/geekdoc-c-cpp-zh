

为对Lemma 13.1至Lemma 13.3以及Lemma 13.7至Lemma 13.9进行验证。然而，Lemmas 13.13和13.14的证明相当繁琐，总共消耗了500行HOL代码。如前所述，这些证明需要数学定理lim (1 + x/k) ^k = e^x，而该定理在HOL中缺失。后者基于大量与将指数函数定义为幂级数相关的实分析，以及许多与序列收敛相关的性质。

得益于HOL定理证明器中可用的可靠概率基础，所得分析被认证为绝对准确。因此，我们能够通过对其随机性的适当建模，对k集随机调度及其覆盖性能提供严格的形式化。事实上，以前的仿真工作主要基于伪随机建模。此外，与概率模型检查器相比，本章提供的一项主要新颖性是能够对问题的统计属性进行形式和精确分析。因此，已能够正式验证网络覆盖强度作为特定点覆盖强度的统计度量。此外，定理证明技术的通用性和高阶逻辑的高表达能力使我们能够制定一种更灵活的方法。最后，因为遗漏关键假设可能导致定理证明器中的验证失败，当前方法因其对最小假设集的完整性而与众不同。

另一方面，森林火灾应用覆盖行为的正式性能分析清楚地表明了我们理论发展的有用性。因此，已能够为所有可能的设计参数值以及所考虑的森林火灾应用的特定情况，正式提供通用的渐近分析。此外，此类验证使已部署WSN的可靠渐近推理成为可能。最后，还需要注意的是，所展示的应用是一个简单的案例研究，说明了我们工作的实际兴趣，但所声称的通用结果显然也对任何其他WSN应用有价值（McIver & Fehnker, 2006）。

上述与定理证明方法相关的额外好处，是以用户在形式化随机调度算法并正式推理其覆盖属性时所花费的时间和精力为代价获得的。我们认为，我们工作中遇到的主要挑战可以分为两大类。首先，尽管高阶逻辑建模似乎依赖于简单的离散随机变量，但主要困难在于将真实WSN算法（远非纯粹数学问题）的概率模型映射到高阶逻辑中。实际上，由于现实世界系统的数学建模通常非常直观，因此我们在这项工作中使用的初始理论模型包含许多隐藏步骤，无论是在考虑随机变量还是在应用概率规则时，都缺乏附带的解释。此外，原始模型的假设从未被详尽地呈现。因此，我们必须正确推理所有缺失的步骤，以便首先理解理论分析的流程，然后实现覆盖属性的高阶逻辑形式化。在这个阶段，通常需要良好的概率背景和对WSN上下文的详细了解，才能深入理解概率推理。

## 13.4 结论

本章提出了一种可靠的方法，用于利用k集随机调度来节省能量，对无线传感器网络的覆盖性能进行正式分析。特别是，我们使用第4章和第5章中描述的概率论测度论形式化，形式化了随机调度的主要基础和覆盖强度的期望值。这种形式化使我们能够正式验证使用k集随机调度的大多数WSN的覆盖相关特征。为了说明我们基础结果的实际有效性，我们利用它们对森林火灾检测WSN应用进行正式概率分析。该应用被认为是WSN最关键的安全应用之一。所取得的结果是绝对通用的，即适用于所有参数值；这是仿真或基于概率模型检查的方法无法实现的结果。此外，已能够使用期望对统计覆盖提供精确的正式推理。最后，与大多数关注WSN算法功能方面验证的现有工作不同，我们的工作因其解决性能方面而与众不同。

这项工作为我们未来利用k集随机调度对WSN检测属性进行高阶逻辑形式化的工作奠定了有趣的基础。在下一章中，我们正式检查覆盖与检测之间的关系，表明覆盖反映检测。另一方面，一旦在HOL定理证明器中开发出检测方面的正式推理支持，其他有趣的应用（如水下监测）的性能也可以进行正式分析。
