Besides, we formally verify, in Lemma 14.2, that the probability of detecting an intrusion event approaches 1 as the number of deployed nodes becomes very very large.

# Lemma 14.2

```
|- !V p k q s L Ts. (1 < k) /\ (0 < s < 1) /\ (0 < L) /\ (0 < Ts) /\
(L < s & ((k-1) x Ts) /\
(0 < q < 1) ==> lim n-->+inf (|An. Pd_wsn p n k s L Ts q) = 1.
```

where lim is the HOL4 formalization of limit for real sequences.

Similarly, it is also very useful to investigate the delay behavior of the randomized scheduling. Thus, we formally verify, in Lemma 14.3, that the detection delay D_wsn starts to be decreasing versus the number of nodes n from a given range, denoted n0. Consequently, D_wsn becomes smaller when a large number of nodes is deployed. In this case, an intrusion is expected to be detected more quickly, since it is likely that many more covering nodes are deployed in the surrounding area.

# Lemma 14.3

```
|- !V p k q s L Ts. (1 < k) /\ (0 < s < 1) /\ (0 < L) /\ (0 < Ts) /\
(0 < q < 1)
==> (mono_decr_range (|An. (real (D_wsn p n k q)))) .
```

where the function real is used to convert the detection delay of type extended real to its corresponding real value.

# Definition 14.8

```
|- !V f. mono_decr_range f <=> (!E n0. !N. n >= n0 ==> f (SUC n) <= f n) .
```

Based on Lemmas 14.1 and 14.2, we establish that any target detection probability Pd_wsn can be achieved by increasing the number of deployed nodes n, for any values of the input variables k, q, s, L, and Ts. More specifically, these results can be easily verified for the detection probability, Pd_surv, in the context of the given border monitoring application (Lemmas 14.4 and 14.5).

# Lemma 14.4

```
|- !V p k s L Ts. (1 < k) /\ (0 < s < 1) /\ (0 < L) /\ (0 < Ts) /\
(L < s & (k - 1) x Ts)
==> (mono_incr (|An. Pd_surv p n k s L Ts (0.28)))) .
```
