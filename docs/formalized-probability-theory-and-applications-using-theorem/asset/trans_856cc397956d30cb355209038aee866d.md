## 5.4 条件概率的形式化

条件概率的概念涉及在已知事件B发生的信息下，事件（例如A）的概率。为了理解条件概率的用法，考虑集成电路测试过程的示例，其中我们成对测试电路。条件概率的概念允许我们计算在一对中的第一个集成电路被发现无故障的情况下，两个集成电路正确的概率。需要注意的是，如果没有关于第一个集成电路接受情况的信息，这个概率将与两个集成电路都被接受的概率不同。本节提供了条件概率数学关系的高阶逻辑形式化，然后利用此正式定义在HOL4定理证明器中验证其一些经典性质。这些性质将详细解释，并附带一些验证提示，以提供关于HOL中形式化和验证过程的见解 [Hasan, 2010b]。

条件概率可以在高阶逻辑中正式表达如下：

### 定义 5.14

```
∀ A B p. cond_prob p A B = prob p (A inter B) / prob p B
```

通过继承前面描述的概率函数的高阶逻辑形式化。函数cond_prob接受概率空间p和两个集合A和B，对应于两个事件，并返回一个实数，该实数对应于在第二个事件B给定的情况下第一个事件A的条件概率。使用上述定义，我们现在在HOL4定理证明器中验证了条件概率的大多数经典性质。这些性质的形式证明不仅确保了上述条件概率定义的正确性，而且在推理系统的条件概率方面也起着至关重要的作用。

### 5.4.1 条件概率界

0 ≤ Pr(A | B) ≤ 1 (5.3)

根据此性质，条件概率的值始终保持在闭区间[0, 1]内。可以使用正式的条件概率定义，在高阶逻辑中将其表示如下：

### 定理 5.6

```
⊢ ∀ p A B. prob_space p ∧ A ∈ events p ∧ B ∈ events p ⇒ 0 ≤ cond_prob p A B ∧ cond_prob p A B ≤ 1
```

这些假设确保事件A和B是概率空间p的有效事件，并且该定理的证明基于概率函数的界。

### 5.4.2 条件概率具有可数可加性

如果 $A_i$ 是一系列互斥事件，则

$\Pr(\bigcup_{i=1}^{\infty} A_i \mid B) = \sum_{i=1}^{\infty} \Pr(A_i \mid B)$ (5.4)

根据此性质，条件概率表现出与概率函数一样的可数可加性公理。条件概率的可数可加性可以在高阶逻辑中表示如下：

### 定理 5.7

```
⊢ ∀ p B A s. (prob_space p) ∧ (B ∈ events p) ∧ (A : (count n) -> events p) ∧ (s = BIGUNION (IMAGE A (count n))) ∧ (∀a b. a ≠ b ∧ DISJOINT (A a) (A b)) ⇒ (cond_prob p s B = SIGMA (λi. cond_prob p (A i) B) (count n))
```
