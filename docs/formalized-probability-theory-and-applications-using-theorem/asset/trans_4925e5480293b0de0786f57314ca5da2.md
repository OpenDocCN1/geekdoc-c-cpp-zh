

## 引理 13.3

```
|- forall p x k s C. (1 < k) /\ (0 < q < 1)
=> (lim (\An. real (Cn_wsn p x k s C n q)) = 1)
```

其中，(lim (\An. f n)) 返回序列 f 在 n 变得非常大时的值。

因此，假设目标是实现至少 70% 的网络覆盖强度，则
所需节点数 n 的下限已得到验证：

## 引理 13.4

```
|- forall p x k s C n. (1 <= n) /\ (1 < k) /\ (Normal (0.7) <= Cn_wsn_first p x k s C n)
```

例如，我们可以推断，在将网络组织为 k = 4 个子网络的随机调度下，

## 引理 13.5

```
(mono_incr (\An. real (cn_wsn_first p x k s C (SUC n)))).
```

## 引理 13.6

```
|- forall p x k s C. (1 < k) =>
(lim (\An. real (Cn_wsn_first p x k s C n)) = 1).
```

根据引理 13.2 和 13.3，通过部署更多节点，通常可以增强已部署 WSN 的覆盖能力。不过，
在初始部署阶段之后，传感器节点的数量变得
已知且固定。
此外，在森林等不适宜人居的环境中，第二次部署可能非常昂贵，
因为节点通常是通过从飞机上投掷来部署的。
基于参数 k，我们现在对覆盖性能的极限行为进行了一项有趣的
研究。首先，我们正式推断，对于给定的 n 和至少为 t 的网络覆盖强度，
不相交子集数 k 的上限如下所示：

## 引理 13.7

```
⊢ ∀ p x k s C n q. (1 ≤ n) ∧ (1 < k) ∧ (0 < q < 1) ∧ (0 < t < 1) ∧ (Normal t ≤ (Cn_wsn p x k s C n q)) ⇒ k ≤ q / (1 - e ^ (ln (-t(1))/(sn)))
```

这一结果正式确认了关于随机调度方法的一般直觉。
增加 k 可以节省能量，但会导致多个子网络，进而转化为更差的网络覆盖强度 Cn_wsn。
这可能会降低整个网络的性能，因此在部署后，对 k 值进行概率分析的准确性非常重要。

## 引理 13.8

```
⊢ ∀ p x s C n q. (1 ≤ n) ∧ (0 < q < 1) ⇒ (mono_decr (∀k. real (Cn_wsn p x (SUC (SUC k)) s C n q))).
```

其中，HOL 函数 mono_decr 将递减序列定义如下：

## 定义 13.14

```
⊢ ∀ f. mono_decr f = f (SUC n) ≤ f n.
```

此外，我们在引理 13.9 中正式确认，给定节点数 n 时，当 k 变得非常大时，网络覆盖强度 Cn_wsn 趋近于 0。
换句话说，当 WSN 被组织为相当大量的子网络 k 时，网络覆盖强度 Cn_wsn 会下降。

## 引理 13.9

```
⊢ ∀ p x s C n. (1 ≤ n) ∧ (0 < q < 1) ⇒ (lim (∀k. real (Cn_wsn p X k s C n q)) = 0).
```

上述引理已在 HOL 中使用与实数和序列极限相关的中间结果成功验证。
上述三个引理清楚地展示了 k 值对网络概率覆盖的影响。
关于我们的应用，可以确认引理 13.7、13.8 和 13.9 中给出的通用结果的有效性。
因此，我们在引理 13.10 中正式验证，为了将网络覆盖强度从 70% 提高到 90%，k 的值必须更新为 2，但对于给定的 n，k 不应超过 2：

## 引理 13.10

```
⊢ ∀ p x s k C n. (1 ≤ n) ∧ (1 < k) ∧ (Normal 0.9 ≤ (Cn_wsn_first p X k s C n)) ⇒ k ≤ 0.003 / (1 - e^(ln ((1-0.9)/(sn))))
```

在已部署的 WSN 中，k 值的调整是通过消息泛洪完成的，该消息会通知所有节点新值。
因此，对于我们的森林火灾检测应用，增加 k 当然可以节省更多能量，但 k 的显著增加可能导致多个子网络，进而转化为较差的网络覆盖强度 Cn_wsn。

## 引理 13.11

```
⊢ ∀ p x s C n. (1 ≤ n) ⇒ (mono_decr (λ k. real (cn_wsn_first p X (SUC (SUC k)) s C n))).
```

此外，我们使用引理 13.12 再次确认引理 13.9 的结果，即，增加部署节点数 n 会导致更小的网络覆盖，从而导致已部署应用性能不佳：

## 引理 13.12

```
⊢ ∀ p x s C n. (1 ≤ n) ⇒ (lim (λ k. real (cn_wsn_first p x k s C n)) = 0).
```

因此，随机调度是一种动态方法，它根据 k 值为已部署的 WSN 应用提供性能调整。

节点调度方法中的随机性会导致不同大小的子网络，其大小取决于节点数量。
显然，当算法对网络进行公平划分，使所有子集具有相同大小（即相同数量的节点，我们将其表示为 m）时，就会出现理想情况。
因此，节点数 n 可以表示为 k * m。
在以下内容中，我们将详细研究在节点均匀划分的情况下，k-集随机算法关于覆盖的渐近性能行为。

特别是，我们在引理 13.13 中成功验证了当 n = k * m 且 k 趋于无穷大时，网络覆盖 Cn_wsn 的上限：

## 引理 13.13

```
⊢ ∀ p x s C q. (0 < q < 1) ∧ (∀ k m. sn_covers p x p q (m * k)) ⇒ lim (λ k. real (Cn_wsn p x k s C (m*k))) = 1 - e^(-q*(sn))
```

引理 13.13 的证明需要重要的数学结果 lim (1 + x/k)^k = e^1，该结果必须事先在 HOL 中得到证明。

基于引理 13.13，我们可以验证，当 m 变得非常大时，均匀网络覆盖肯定会趋近于 1。
该结果被视为在 n = k * m 的特定情况下对引理 13.3 的第二次验证。

## 引理 13.14

```
⊢ ∀ X p q. (0 < q < 1) ∧ (∀ k. sn_covers p X p q (m * k)) ⇒ lim (λ m. lim (λ k. real (Cn_wsn p X k s C (m*k) q)) = 1).
```

最后，我们表明上述两个结果也通过将输入参数 q 简单实例化为其值，对给定的森林火灾检测应用具有价值。
相应的 HOL 分析在以下 2 个引理中给出。

## 引理 13.15

```
⊢ ∀ p X s C. (∀ k m. sn_covers p X p (0.003) (m * k)) ⇒ lim (λ k. real (Cn_wsn_first p X k s C (m*k))) = 1 - e^(-0.003)*(sn)
```

## 引理 13.16

```
⊢ ∀ X p. (∀ k. sn_covers p X p (0.003) (m * k)) ⇒ lim (λ m. lim (λ k. real (Cn_wsn_first p X k s C (m*k))) = 1).
```

当前工作的主要动机是为无线传感器网络的 k-集随机调度算法提供一种准确的概率性能评估方法。
确实，由于所研究的调度方法固有的随机性与节点的随机部署相耦合，对该算法在所有可能情况下的分析变得非常具有挑战性。
因此，对该算法进行严格的性能评估是一项非平凡的任务，尤其是考虑到经典性能分析技术的非穷尽性。
本章提出了一种基于高阶逻辑定理证明器的方法，用于在 HOL 定理证明器的可靠内核中形式化 k-集随机调度。
在第 13.3 节中，我们能够正式发展 k-集随机调度算法的基础形式化，在此基础上构建了网络覆盖强度的准确形式化。
