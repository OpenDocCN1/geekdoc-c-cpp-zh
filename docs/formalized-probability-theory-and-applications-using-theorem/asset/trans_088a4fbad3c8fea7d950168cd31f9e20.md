本章介绍了高阶逻辑中最小熵和信念最小熵的形式化。我们的形式化可用于在 HOL4 定理证明器的可靠内核中，对攻击者在一次尝试中猜测系统漏洞的威胁模型进行正式推理。在本章中，我们主要基于 HOL4 中的信息理论基础，主要因为与概率和信息理论的其他形式化相比，它们具有完整性和通用性。

为了说明所提形式化的有效性和实用性，我们利用它对级联信道进行信息流分析。信息理论中的级联信道拓扑是一种常用的线性连接策略，其中每个通信节点（例如，服务器、路由器、交换机）的输出作为下一个节点的输入。该结构基本上用于银行系统，以确保此类系统的可恢复性、可用性和一致性。由于将通信系统建模为信道级联的安全关键型应用，对其进行最坏情况分析的准确分析非常重要。所提的最小熵形式化使我们能够实现这一目标。

## 10.2 最小熵和信念最小熵的形式化

信息论中的最小熵和信念最小熵度量克服了香农熵在评估一次猜中秘密的安全性方面的局限性。本节将解释这些度量及其相应的高阶逻辑形式化（Hehali, 2013）。在以下小节中，X、Y 和 B 分别表示模拟高输入（秘密）、输出（可观测值）和攻击者对系统行为的信念（额外知识）的随机变量，p 和 q 表示概率空间。

### 10.2.1 最小熵的形式化

随机变量 X 的最小熵 H∞ 是当 α = ∞ 时的 Rényi 熵的特例。

定义 10.1
随机变量 X 的最小熵由以下公式给出：
H∞ (X) = -log max p (x)

这可以在 HOL4 中形式化如下：

```
|- ∀ X p.
min_entropy X p =
  -log (extreal_max_set (IMAGE
(∀x. distribution p X { x }) (IMAGE X (space p))))
```

在此定义中，函数 extreal_max_set 返回给定集合的最大值，IMAGE f s 返回由函数 f 映射的给定集合 s 的像，space p 是概率空间 p 的 Ω 的状态空间。

从上述定义可以观察到，最小熵度量主要是脆弱性的负对数，换句话说，是对手 A 在一次尝试中正确猜中秘密的最坏情况概率：

H∞ (X) = -log (V(X)) = -log (max x:x. P [ X = x ]).

最小熵仅度量初始不确定性，剩余不确定性可以由条件最小熵来量化。

### 定义 10.2

观察输出 Y 时，猜中秘密 X 的概率为

$H^\infty (X \mid Y) = -\log ( \max_{y \in Y} \sum_{x \in X} P [ Y = y ] P [ X = x \mid Y = y ] )$

这可以在 HOL4 中形式化如下：

```
|- ∀ X Y p.
conditional_min_entropy p X Y =
- log ∑ (y | y. Extrreal_max_set
(IMAGE (λx. distribution p y { y } *
Conditional_distribution p X Y ({ x }, { y })) (X (Ω))))
```

在上述定义中，我们使用了条件分布 p X Y，它指的是 P (X | Y)。这个量关联了两种行为，即输入 X 和输出 Y，这使得条件最小熵成为映射剩余不确定性的良好度量，而剩余不确定性无非是拥有可观测值时猜中秘密输入的概率。

### 10.2.2 信念最小熵的形式化

信念最小熵使我们能够处理攻击者关于系统行为的额外知识或信念。这个度量实际上是最小熵的一种改进，因为它考虑了另一个参数，即信念，预计这将提高分析的可靠性。

设 pρ 和 pβ 分别表示与系统行为和对手信念相关的分布。给定额外信息 B = b，对手根据其信念选择具有最大条件概率的值，即一个值 x' ∈ Γb，使得 Γb = argmax x∈X pβ (x | b)，并且 argmax x∈X pβ (x | b) 返回来自 X 且具有最大条件分布的元素。如果 X 中有多个值具有最大条件概率，攻击者从 Γb 中均匀随机地选择一个单一元素。

### 定义 10.3

设 \( X \) 为输入随机变量，\( B \) 为对手关于 \( X \) 的额外知识。那么 \( X \) 的信念最小熵，记作 \( H^{\infty}(X; B) \)，定义为

\( H^{\infty}(X; B) = -\log \left( \sum_{b \in \mathcal{B}} \frac{1}{\Gamma_b} \sum_{x \in \mathcal{X}} P(b) \sum_{x \in \mathcal{X}} P(x | b) \right) \)

为了在 HOL4 中形式化信念最小熵，我们首先定义信念脆弱性，通过应用逆对数可以将其扩展以获得信念最小熵。

```
|- ∀ p1 p2 X B.
Belief_vulnerability p1 p2 X B =
SIGMA (b | b.
1
| belief_set p1 p2 X B b | *
(distribution p1 B { b } ) *
(SIGMA (∀x. Conditional_distribution p1 X B {{ x }, { b }} )
(belief_set p1 p2 X B b)))
(B (Q1))
```

其中，函数 belief set p1 p2 X B b 在 HOL4 中建模 Γb，Q1 指的是 p_space p1。现在，为了建模信念最小熵，我们需要定义攻击者信念与可观测输出之间的关系。如果存在输入 \( x \in \Gamma b \) 验证 \( P_p(y | x) > 0 \)，则信念 b 与观测 y 兼容，在这种情况下，攻击者能够为猜测秘密选择适当的值。\(\Gamma_{b,y}\) 表示对手可以选择的可能性集合，定义如下：

\(\Gamma_{b,y} = \left[ \begin{array}{ll} \arg \max_{x \in \mathcal{X}} P_\beta(x | b,y) & \text{if } b \text{ and } y \text{ are compatible} \\ \arg \max_{x \in \mathcal{X}} P(x | y) & \text{otherwise} \end{array} \right] \quad (10.1)\)

上述定义形式化为 HOL4 函数 belief conditioned set，我们将稍后使用它来建模剩余不确定性，剩余不确定性将是条件信念脆弱性的函数。

### 定义 10.4

\( V (X | Y: B) = \sum_{Y \in \mathcal{Y}} \sum_{b \in \mathcal{B}} P_\rho(y | b) \frac{1}{|\Gamma_{b,y}|} \sum_{z \in \Gamma_{b,y}} P(y | b) . \)
