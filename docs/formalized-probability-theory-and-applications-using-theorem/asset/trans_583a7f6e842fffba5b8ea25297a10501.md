

以下熵属性已在 HOL 中得到验证：

```
|- ∀ X N. 0 ≤ H (X) ≤ log (N)
|- ∀ X Y. max (H (X), H (Y)) ≤ H (X, Y) ≤ H (X) + H (Y)
|- ∀ X Y. H (X | Y) = H (X, Y) - H (Y)
|- ∀ X Y. 0 ≤ H (X | Y) ≤ H (X)
|- ∀ X Y. I (X; Y) = H (X) + H (Y) - H (X, Y)
|- ∀ X Y. I (X; Y) ≤ min (H (X), H (Y))
|- ∀ X b p. H (X) = -SIGMA (λ x. p ( {x} )) logr b (p { x })) s
|- ∀ X Y b p. H (X | Y) =
-SIGMA (λ (x, y). p { (x, y) } logr b (p { (x, y) } / p { y })) s
```

## 9.5 条件互信息的形式化

条件互信息 I(X; Y|Z) 可用于在已知 Z 的情况下，衡量两个随机变量 X 和 Y 的互信息的期望值。它已被用作衡量具有高安全性输入 X、低安全性输出 Y 和低安全性输入 Z 的程序的信息泄漏度的指标。I (X; Y|Z) 然后是衡量在已知低安全性输入的情况下，通过观察程序的输出，有多少关于秘密输入的信息泄露给攻击者。条件互信息定义为联合分布 p_xyz 与乘积测度 p_xz p_yz p_z 之间的 KL 散度。其 HOL4 形式化如 (Mhamdi, Hasan & Tahar, 2011) 所示：

### 定义 9.7

```
|- ∀ X Y Z. conditional_mutual_information b p X Y Z =
    KL_divergence b (joint_distribution p X Y Z)
    (prod_measure (conditional_distribution p X Z)
    (conditional_distribution p Y Z)
    (distribution p Y))
```

对于有限空间，条件互信息的以下简化形式也可以通过首先证明 p_xyz 相对于 p_xz p_yz p_z 绝对连续，然后应用 KL 散度的简化形式来正式验证。

```
| (X; Y|Z) = \sum_{(x,y,z) \in \Omega_{XYZ}} p(x,y,z) \log \frac{p(x,y,z)}{p(x|z)p(y|z)p(z)} (9.9)
```

当两个随机变量 X 和 Y 在给定 Z 的条件下独立时，条件互信息 I (X; Y | Z) = 0。事实上，在这种情况下，

```
∀ x, y, z. p (x, y, z) = p (x, y | z) p(z) = p (x | z) p (y | z) p (z)
```

### 定义 9.8

```
⊢ ∀ X Y Z. indep_rv_cond p X Y Z ⇒ I (X; Y | Z) = 0
```

关于条件互信息的其他一些重要结果也已在 HOL 中得到验证。

- ⊢ ∀ X Y Z. 0 ≤ I (X; Y | Z)
- ⊢ ∀ X Y Z. I (X; Y | Z) = H (X | Z) - H (X | Y, Z)
- ⊢ ∀ X Y Z. I (X; Y | Z) = I (X; Z, Y) - I (X; Z)
- ⊢ ∀ X Y Z. I (X; Y | Z) ≤ H (X | Z)

第一个属性是 KL 散度非负性的直接结果。第二个属性的主要证明步骤如下：

```
| (X;Y|Z) = Σp(x, y, z) log p(x, y, z) / (p(x | z)p(y | z)p(z))
= Σp(x, y, z) log p(x | y, z) / p(x | z)
= Σp(x, y, z) log p(x, y, z) / p(x | z)
= Σp(x, y, z) log (p(x | y, z)) - Σp(x, z) log(p(x | z))
= - H (X | Y, Z) + H (X | Z)
```

第三个属性也可以以类似方式验证，而第四个属性的证明基于第二个属性和熵的非负性。

迄今为止，在本章中，我们已提供了 KL 散度的高阶逻辑形式化，该形式化用于定义各种定量信息流度量 (Sabelfeld & Myers, 2003)。这种形式化，连同度量论和概率论的形式化，使我们能够使用定理证明器进行许多定量信息流分析，我们将在下一节中展示一个示例。

## 9.6 信息定量分析的形式化

在大多数应用中，出于设计目的，总有一些信息旨在确保协议的功能。例如，在投票协议中，个人投票结果必须保密，但总体选举结果应公开。同样，密码检查程序在拒绝错误密码时会泄露一些信息 (Malacaria, 2007)。

信息流定量分析 (Smith, 2009) 在各种情境下正受到越来越多的关注，例如安全信息流、匿名协议 (Serjantov & Danezis, 2003) 和侧信道分析。它允许我们通过观察系统的输出以及可能的低安全性输入，来衡量系统高安全性输入的多少信息可能被意外或恶意地泄露。与仅确定系统是否完全安全或不完全安全的非干扰分析不同，信息流定量分析提供了一种信息论度量，用于衡量系统有多安全或不安全。

我们引入了两种新的信息度量 (Mhamdi, Hasan & Tahar, 2012)，即信息泄漏度和条件信息泄漏度，可用于评估各种系统和协议的匿名性和安全性属性。

### 9.6.1 信息泄漏度

考虑一个具有由随机变量 X 表示的一组秘密输入和由 Y 表示的一组公开输出的程序。我们定义该程序的信息泄漏度为

```
D = \frac{H(X|Y)}{H(X)} \qquad (9.11)
```

其中，$H(X)$ 和 $H(X|Y)$ 分别表示 X 的 Shannon 熵和给定 Y 时 X 的条件熵。

### 定义 9.9

```
|- ∀ X Y p. ILD p X Y = conditional_entropy p X Y / entropy p X
```

为了更好地理解此定义背后的直觉，让我们考虑完全安全程序和完全不安全程序的两种极端情况。从直觉上讲，完全安全发生在程序的公开输出 Y 的知识不影响关于秘密输入 X 的不确定性时。这等同于要求 X 与 Y 独立。在这种情况下，$H(X|Y) = H(X)$，信息泄漏度等于 1。另一方面，当程序的输出完全识别其秘密输入时，熵 $H(X|Y)$ 等于 0，因此在完全识别的情况下，信息泄漏度等于 0。对于介于两个极端之间的情况，可以验证信息泄漏度位于区间 (0, 1) 内。

### 定理 9.4

```
|- ∀ X Y p. 0 ≤ ILD p X Y ≤ 1
```

利用互信息 $I(X; Y)$ 的属性，还可以正式验证信息泄漏度等于

$D = 1 - \frac{I(X;Y)}{H(X)}$ (9.12)

此结果说明了信息泄漏度定义的重要性，因为互信息衡量了对手在观察输出 Y 后可以了解输入 X 的多少信息。

### 9.6.2 条件信息泄漏度

考虑一个具有高安全性输入集 S、低安全性输入集 L 和公开输出集 O 的程序 (Zhu & Bettati, 2009)。对手希望在了解低安全性输入 L 的情况下，通过观察输出 O 来了解高安全性输入 S。为了捕捉对手的这种附加信息（低安全性输入），可以使用以下定义，称为条件信息泄漏度

Dc = \frac{H(S | (O, L))}{H(S | L)} (9.13)

这在 HOL4 中形式化为：

### 定义 9.10

```
|- ∀ X Y p. ILD_c p S L O = conditional_entropy p S (O, L) / conditional_entropy p S L
```

与前一种情况一样，考虑完全安全和完全识别的两种极端情况。当输出和秘密输入独立时，对于给定的 L，条件熵 H(S | (O, L)) 等于 H(S | L)，这导致完全安全时的条件泄漏度等于 1。但是，如果公开输入和输出完全识别秘密输入，则 H(S | (O, L)) 等于 0，在完全识别的情况下，条件泄漏度也等于 0。与泄漏度的情况一样，我们也可以证明条件信息泄漏度位于区间 (0, 1) 内。

### 定理 9.5

```
|- ∀ X Y p. 0 <= D_c p X Y Z <= 1
```

我们还证明，条件信息泄漏度可以用条件互信息和条件熵来表示。

Dc = 1 - \frac{I(S; O | L)}{H(S | L)} (9.14)

这表明，该定义明显是针对具有额外低安全性输入的程序的信息泄漏度的推广。通过验证数据处理不等式，可以获得更多解释此定义的直觉。随机变量 X、Y 和 Z 被认为按此顺序形成马尔可夫链（表示为 X -> Y -> Z），如果 Z 的条件分布仅取决于 Y 并且与 X 条件独立。具体来说，如果联合概率质量函数可以写成，则 X、Y 和 Z 形成马尔可夫链 X -> Y -> Z

p (x, y, z) = p (x) p(y | x) p(z | y) (9.15)
