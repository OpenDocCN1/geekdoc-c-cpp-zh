By extracting the first term (j=0) of the summation in Equation (14.4), we obtain

```
Pr(D) = 1 - (Pr(UD|c = 0) x Pr(c = 0) + \(\sum_{j=1}^{n}\) (Pr(UD|c = j) x Pr(c = j))(14.5)
```

According to case 1, we have Pr ( UD | c = 0 ) = 1, and we hence can rewrite Equation (14.5), using Equation (14.3), as

```
Pr(D) = 1 - ((1 - q)n + \(\sum_{j=1}^{n}\) (Pr(UD|c = j) x Pr(c = j)) (14.6)
```

In the following, we are interested in formally verifying the detection probability Pr (D) for occurring events of any length L. More particularly, we focus on the formalization of the summation term of Equation (14.6). For that purpose, we distinguish 2 cases, i.e., { L < (k - 1) x T } and { L >= (k - 1) x T }.
