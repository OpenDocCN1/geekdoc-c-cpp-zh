## 11.1 数据压缩

数据压缩或源编码可被视为信息理论的一个分支（Cover & Thomas, 1991），其主要目标是减少冗余，最大限度地减少需要存储或传输的数据量。它通过使用特定的编码方案，使用比未编码表示更少的比特来编码信息。如图1所示，数据压缩在数据存储和数据传输等领域具有重要应用，例如，在数字蜂窝网络上进行实时传输的语音压缩。另一方面，计算机通信网络的普及导致大量数据传输，而日益增多的数据处理应用需要存储大量数据。压缩数据可以降低成本并增加容量。然而，为了保证数据的可靠传输或存储，特别是在安全关键型应用系统中，必须遵守一定的压缩限制。

我们提议正式证明一个确立数据压缩基本极限的重要结果。该结果也称为香农源编码定理（Afeldt & Hagiwara, 2012），并指出可以在不造成显著信息损失的情况下，以任意接近香农熵的速率压缩数据（Gray, 1990）。换句话说，当n趋于无穷大时，熵为H(X)的n个独立同分布（iid）随机变量平均可以用n H(X)比特表示，而不会有显著的信息丢失风险。据我们所知，本应用所需的大部分形式化框架，例如实值可测函数的性质、任意函数期望的性质、方差、随机变量的独立性以及大数定理，在公开文献中均不可用。

证明该结果包括提出一种编码方案，使平均码字长度可以任意接近n H(X)，且丢失概率可忽略。我们提议执行典型集编码。典型集包含典型序列，用于表示频繁的源符号，而非典型序列表示罕见的源符号。

### 11.1.1 切比雪夫和马尔可夫不等式

在概率论中，切比雪夫不等式和马尔可夫不等式都提供了尾概率的估计。切比雪夫不等式保证，对于任何概率分布，几乎所有值都接近均值，并且它在大数定理的推导中起着重要作用。马尔可夫不等式为随机变量的累积分布函数提供了宽松但有用的界限。设X为期望值为m且方差为σ²的随机变量。切比雪夫不等式指出，对于任何实数k > 0，

P (|X - m| ≥ kσ) ≤ 1/k² (11.1)

切比雪夫不等式的HOL4形式化表述如下：

```
|- random_variable X p Borel ^
integrable p (λx. ((Xx - E[X])^2) ∧ 0 < k ⇒
prob p { x | x ∈ Ω ∧ k Var[X] ≤ |Xx - E[X]| } ≤ 1/k²
```

马尔可夫不等式指出，对于任何实数k > 0，

P (|X| ≥ k) ≤ m/k (11.2)

其在HOL4中的形式化如下：

```
|- random_variable X p Borel ^ integrable p X ^ 0 < k ==>
prob p { x | x ∈ Ω ^ k ≤ |X x| } <= E[X] / k
```

与直接证明这些不等式不同，我们在HOL4中提供了一种更一般的证明，使用测度论和勒贝格积分，该证明可用于这两个不等式以及许多类似的不等式。概率陈述通过考虑一个度量为1的空间得出。

### 定理11.1

设(S, Σ, μ)为测度空间，f为定义在S上的可测函数。那么对于任何非负函数g，且g在f的值域上非递减，

μ ( { x ∈ S : f(x) ≥ t } ) ≤ 1/g(t) ∫_S g ∘ f dμ.

```
|- ∀ m f g t.
(let A = { x | x ∈ m_space m ^ t ≤ f x } in
measure_space m ^
f ∈ measurable (m_space m, measurable_sets m) Borel ^
(∀ x. 0 ≤ g x) ^ (∀ x y. x ≤ y ⇒ g x ≤ g y) ^
integrable m (λ x. g (f x)) ==>
measure m A ≤ (1 / (g t)) * integral m (λ x. g (f x)))
```

切比雪夫不等式通过令t = kσ、f = |X - m|以及定义g(t) = t^2（当t ≥ 0时）和0（否则）来推导。马尔可夫不等式通过令t = k、f = |X|以及定义g(t) = t（当t ≥ 0时）和0（否则）来推导。

- 证明：设A = { x ∈ S | t ≤ f(x) }，IA为A的指示函数。根据A的定义，∀ x 0 ≤ g(t) IA(x) 且 ∀ x ∈ A, t ≤ f(x)。由于g是非递减的，∀ x g(t) IA(x) ≤ g(f(x)) IA(x) ≤ g(f(x))。因此，∀ x g(t) IA(x) ≤ g(f(x))。A是可测的，因为f是(S, B(R))可测的。利用第4章验证过的积分单调性，∫_S g(t) IA(x) dμ ≤ ∫_S g(f(x)) dμ。最后，根据积分的线性性质，g(t) μ(A) ≤ ∫_S g ∘ f dμ。

### 11.1.2 大数定理（WLLN）

大数定理指出，大量独立测量的随机量的平均值在概率上收敛于该量的理论平均值。解释这一结果，大数定理指出，对于足够大的样本，平均值非常接近期望值的概率非常高。该定律在众多领域中被使用。例如，它被用来证明AEP，这是信息论领域的一个基本概念。

### 定理11.2

设X1, X2, ...为无限个独立同分布随机变量的序列，具有有限期望值E[X1] = E[X2] = ... = m，并令

```
\overline{X} = \frac{1}{n} \sum_{i=1}^n Xi \text{ then for any } \varepsilon > 0,
```

```
lim_{n \to \infty} P(|\overline{X} - m| < \varepsilon) = 1 \quad (11.3)
```

```
\vdash \text{prob\_space } p \land 0 < \varepsilon \land (\forall i j. i \neq j \Rightarrow \text{uncorrelated } p (Xi) (Xj)) \land (\forall i. E[Xi] = m) \land (\forall i. \text{Var}[Xi] = v) \Rightarrow lim (\lambda n. \text{prob } p (x | x \in \Omega \land | \frac{1}{n} \sum_{i=1}^n Xi x - m | < \varepsilon )) = 1
```

- 证明：利用勒贝格积分的线性性质以及方差的性质，我们证明E[X̄] = (1/n) Σ_{i=1}^n m = m 且 Var(X̄) = σ²/n。将切比雪夫不等式应用于X̄，我们得到 P(|X̄ - m| ≥ ε) ≤ σ²/(nε²)。等价地，1 - σ²/(nε²) ≤ P(|X̄ - m| < ε) ≤ 1。由此可得 lim_{n→∞} P(|X̄ - m| < ε) = 1。

### 11.1.3 渐近等分配性质（AEP）

渐近等分配性质（AEP）是大数定理在信息论中的类比。它指出，对于随机源X，如果其时间序列X1, X2, ...是熵为H(X)的iid随机变量序列，则 -(1/n) log p(X1, ..., Xn) 在概率上收敛于H(X)。
