

## 第 13 章

## 无线传感器网络调度算法

## 摘要

在无线传感器网络（WSN）中，传感器调度被认为是最有效的节能机制。在开阔地带的许多WSN中，传感器的随机且不可预测的部署使得传感器调度问题非常具有挑战性，因此采用了随机调度算法。这些算法的性能通常使用仿真技术进行分析，但仿真无法提供100%准确的结果。此外，当使用概率模型检查时，它不包括对期望和方差等统计量进行准确推理的强有力支持。在本章中，作者通过使用高阶逻辑定理证明来正式分析WSN的基于覆盖的随机调度算法，克服了这些局限性。利用第5章中描述的概率理论形式化，作者正式推理了在WSN覆盖背景下某些有趣事件的概率。

### 13.1 基于覆盖的随机调度算法

无线传感器网络（WSN）已被提出作为一种高效解决方案，用于在无需持续人工监视的情况下监测一个区域。此类网络由无线连接在区域上的小型微型设备组成。传感器的主要任务是对监测事件进行测量。根据这些测量，在基站上做出决策过程。目前，WSN被广泛部署于各种应用中，例如自然灾害或生物攻击的检测以及军事追踪。

考虑到这些节点始终是独立且由电池供电的，因此尽量减少传感器节点的能源需求至关重要。节点调度是保存能源的最广泛采用的解决方案之一（Lin & Chen, 2008; Jain & Srivastava, 2007; Liu, Wu, Xiao & Sun, 2006）。它包括将网络分割成多个子网络，这些子网络交替工作。这种方法面临的最大挑战是提供持续覆盖的能力，即传感器的可靠监测或追踪。

考虑一个在大小为a的区域上部署n个传感器的WSN。所有传感器都有相同的任务：收集数据并将其路由回基站。节点在二维区域上的部署是随机的，因此没有位置信息可用。每个传感器的感知区域大小用r表示。传感器只能在其感知范围内感知环境并检测事件。当监测区域上的某一点发生的任何事件可以被至少一个活动传感器检测到时，该点被认为被覆盖（Xiao et al., 2010）。每个传感器覆盖给定点的概率q为r/a。节点的随机调度以相等概率1/k将每个传感器分配给k个子网络中的一个。在时间槽Ti期间，仅属于子网络i的节点将处于活动状态并可以覆盖发生的事件。因此，创建的不相交子网络将交替工作。设：S_i为属于子网络i并覆盖区域内特定点的传感器集合，S为覆盖区域内特定点的节点集合，c为S的基数。

为说明起见，考虑在监测区域内随机部署的八个节点。节点由0到7的ID标识。有两个名为S0和S1的子网络。每个节点在0和1之间随机选择，以分配给这两个子网络之一。假设节点0；2；5；6选择数字0并加入子集S0，节点1；3；4；7选择数字1并加入子集S1。因此，这两个子网络将交替工作。换句话说，当节点0；2；5；6处于活动状态时，节点1；3；4；7将处于空闲状态，反之亦然。

### 13.2 K集随机调度的形式分析

任何系统的形式概率分析大致可分为两个主要步骤，即给定系统的形式化，同时使用形式化随机变量对其随机组件进行建模，并使用该模型将感兴趣的属性作为高阶逻辑定理进行正式验证。在本节中，我们开发了WSN基于覆盖的随机调度算法的HOL4形式化（Elleuch, Hasan, Tahar & Abid, 2011; Elleuch, Hasan, Tahar & Abid, 2013）。

### 13.2.1 随机变量的形式化

下面描述的随机调度算法的挑战在于选择一个k值，以便在良好覆盖的同时节省能源。因此，该算法的性能基本上取决于所选的k值。大的k值将意味着大量的子网络，进而导致每个子网络中的节点很少，从而导致覆盖差。然而，小的k值将意味着少量的子网络，由大量节点同时覆盖大量点，因此会浪费能源。

随机调度算法涉及多个随机变量。第一个随机变量将节点均匀地分布在子网络上。它在HOL4中形式化如下：

```
Definition 13.1
|- ∀X p a n. uniform_distr X p (a: num) (n: num) =
  (real_random_variable X p) ∧
  (IMAGE X (p_space p) = (gen_set_unif n a)) ∧
  (events p = POW (p_space p)) ∧
  (∀y. (y IN (IMAGE X (p_space p))) => (distribution p X { y } = 1 / n)))
```

上述函数uniform_distribution_rv接受四个参数，即实随机变量X、概率空间p、正整数a以及均匀随机变量的输入参数k。请注意，变量a和n的类型为num或正整数，因为X是实值离散随机变量。此定义中使用的函数gen_set_unif定义了随机变量X的可能取值，即{a；a + 1；...；a + k}。

现在，以下函数接受一个随机变量X和一个正整数c，并递归生成一个包含c个相同元素X的列表。

### Definition 13.2

```
⊢ (∀ X. rd_subsets 0 X = [ ]) ∧
(∀ c X. rd_subsets (c + 1) X = (X) :: (rd_subsets c X))
```

接下来，考虑一个谓词，它接受一个元素j和一个列表，并递归地仅在j不是给定列表的元素时返回真。

### Definition 13.3

```
⊢ (∀ j. subset_empty j [ ] = T) ∧
(∀ j h t. subset_empty j (h::t) = ((¬ (h = j)) ∧ (subset_empty j t)))
```

考虑覆盖区域内特定点的c个节点集合S。如果将随机调度应用于此集合，它将均匀地将S中的每个传感器节点分配给k个不相交子集中的一个。因此，如果均匀随机变量从未生成数字j，即S的所有c个传感器都错过了该子集，则给定的子网络Sj为空。此外，基于均匀分布，加入任何子集的概率均等且等于1/k，而不在特定子集中的概率为(1 – 1/k)。鉴于覆盖的c个节点独立地加入或错过子集Sj，存在空子集的概率可以正式验证如下：

### Theorem 13.1

```
⊢ ∀ X p k (a: num) (j: num). (1 < k) ∧
(uniform_distribution_rv X p a k) ∧
(sm ∈ (IMAGE X (p_space p))) ∧
(∀ c. (indep p (p_space p ∩ { x | X x ≠ &j }))
({ x | subset_empty (¬j) (rd_subsets c (X x)) } ∩ p_space p))
⇒ (prob p { x | subset_empty (¬j) (rd_subsets n (X x)) = T }
∩ p_space p) =
(1 – (1 / (&k)))) pow n
```

where

- 假设(1 < k)确保子网络数量大于1，因为当k = 1时随机调度将毫无意义
- (uniform distr rv X p a k)是均匀随机变量（定义13.1）。
- 子网络Sj为空时的事件集，由({ x | subset_empty (¬j) (rd_subsets n (X x)) } ∩ p_space p)正式建模。
- 该集合使用谓词subset_empty（定义13.3），该谓词在函数rd_subsets（定义13.2）生成的列表中查找索引j。
