# Definition 12.16

```
∀ p L. list_exp p [] L = T ∧
∀ p h t L. list_exp p (h::t) L =
exp_dist p (HD L) h ∧
list_exp p t (TL L)
```

The function list_exp accepts a list of failure rates, a list of random variables L and a probability space p. It guarantees that all elements of the list L are exponentially distributed with the corresponding failure rates given in the other list within the probability space p. For this purpose, it utilizes the list functions HD and TL, which return the head and tail of a list, respectively.
