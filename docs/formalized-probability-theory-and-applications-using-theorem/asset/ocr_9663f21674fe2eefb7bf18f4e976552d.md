More specifically, when the birth-death coefficients are b_i = \lambda and d_i = \mu (\lambda and \mu are constants) for all i in the state space, then the model described in Definition 7.12 represents a classical M / M / 1 queueing system (in this case, the average inter arrival time becomes 1/\lambda and the average service time is 1 / \mu). Thereafter, the verified theorems can be directly applied to analyzing the ergodicity of M / M / 1 queueing.
