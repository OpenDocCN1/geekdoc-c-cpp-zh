

函数（PMF）为 Pr (D_t = i) = a_j，其中 i = 1, 2, ..., n 指的是时间 t 时栈中最近最少使用页面的位置，且 \sum_{j=1}^n a_j = 1。这样，分布函数变为 Pr (D_t \le i) = \sum_{j=1}^i a_j。现在，如果一个标记页面在时间 t 时占据栈中的第 i 位置，如图 1 中的 s_t 所示，则该页面在栈中的位置 s_{t+1} 取决于下一次引用 x_{s_t} 和该页面在栈中的位置 s_t。

基于LRU栈中描述的更新过程，LRU页面置换算法的缺页率评估变得非常简单。如果被评估的程序已分配了 i 个主内存页面框，则当 D_t > i 时，在时间 t 会发生缺页。因此，缺页概率为

F (LRU) = Pr (D_t > i) = 1 - \sum_{j=1}^i a_j \quad (7.2)

标记页面在LRU状态中的移动则是一个随机过程 \{ E_t \}_{t \ge 0}。如果页面占据栈 s_t 中的第 i 位置，则 E_t = i，对所有 1 \le i \le n 成立。现在，我们有以下转移概率：

p_{1i} = Pr (E_{t+1} = 1 | E_t = i) = Pr (D_{t+1} = i) = a_i, 1 \le i \le n
p_{ii} = Pr (E_{t+1} = i | E_t = i) = Pr (D_{t+1} < i) = \sum_{j=1}^{i-1} a_j, 2 \le i \le n
p_{i, i+1} = Pr (E_{t+1} = i+1 | E_t = i) = Pr (D_{t+1} > i) = 1 - \sum_{j=1}^i a_j, 1 \le i \le n-1
p_{ij} = 0, otherwise.

通过假设对所有 i \in [1, n] 均有 a_i > 0，LRU栈随后被描述为一个非周期且不可约的DTMC。

### Definition 7.10
\forall a t i j. L t a i j =
If (j = 1) then a i else
If (j - i = 1) then 1 - sum (1, i) (\lambda j. a j) else
If (j = i) then sum (1, i - 1) (\lambda j. a j) else 0

定义 7.10 可用于将LRU栈模型形式化为：

### Definition 7.11
\forall X p a n p0. LRU_model X p a n p0.
Aperiodic_DTMC X p ({1, n}, POW ({1, n})) p0 (Lt a) \\
Irreducible_DTMC X p ({1, n}, POW ({1, n})) p0 (Lt a) \\
1 \le n \land (\forall j. 0 < j \land j \le n \Rightarrow 0 < a j) \\
(sum (1, n) (\lambda j. a j) = 1)

其中，状态空间被描述为一对 ([ 1, n ], POW ([ 1, n ]))，其中第一个元素包含所有状态 { 1, 2, ... n }，第二个元素是第一个元素的σ代数。条件 ( 1 <= n ) 用于避免引用字符串长度为零的情况。其他两个条件代表上述模型的规范。

使用此LRU栈模型的形式化定义，我们现在可以正式推理其极限分布，这些分布主要用于描述该模型的稳态行为。

在LRU栈模型中，对于 [ 1, n ] 中的每个 i，都存在 lim_{t->infty} p_i^(t_k)。

### Theorem 7.7

```
|- forall X p a n p0 P_o i.
LRU_model X p a n p0 P_o /\ i in [ 1, n ]
=> exists u. ( /\ t. prob p ( x | X t x = i ) -> u )
```

此属性的证明基于定理 7.5 和实数序列极限的定义。

在LRU栈模型中，lim_{t->infty} p_i^(m) = 1 / n，对于 [ 1, n ] 中的每个 i 成立。

### Theorem 7.8

```
|- forall X p a n p0 P_o i.
LRU_model X p a n p0 P_o /\ i in [ 1, n ]
=> ( lim ( /\ t. prob p ( x | X t x = i ) ) = 1 / n )
```

此属性的证明主要基于定理 7.7 以及引理 7.4：

```
|- forall X p a n P_o i j.
LRU_model X p a n P_o /\ i in [ 1, n ] /\ j in [ 1, n ]
=> ( lim ( /\ t. prob p ( x | X t x = i ) ) =
lim ( /\ t. prob p ( x | X t x = j ) ) )
```

上述引理的证明基于DTMC属性以及一些算术推理。

定理 7.8 意味着 lim_{t->infty} p_i^(t)（对于任何标记 i）与其初始分布无关，且标记页面在任何栈位置出现的概率相等。这意味着任何页面在长期内被引用的可能性相同。因此，得出结论：此LRU栈规范不涵盖某些程序的非均匀页面引用行为。

能够正式验证涉及分类马尔可夫模型的定理，且证明脚本仅由HOL中的约400行代码组成。这段简短的脚本清楚地表明了本手稿前几章中所介绍形式化的有用性，因为没有它们，推理无法以如此直接的方式完成。

## 7.4.2 生死过程

生死过程（Trivedi, 2002）是马尔可夫链的一个重要子类，因为它涉及非负整数的状态空间。其显著特征是所有一步转移都只导向最近邻状态。离散时间生死过程主要用于分析软件稳定性，例如验证数据结构是否会出现溢出问题。

离散时间生死过程可以描述为图 3 所示的状态图。

在上述图中，状态 0, 1, ..., i, ... 与人口相关联。转移概率 b_i 表示人口为 i 时发生出生的概率，d_i 表示人口变为 i 时发生死亡的概率，a_i 指状态 i 中的人口。

考虑到 0 <= a_i <= 1 < b_i < 1 且 0 < d_i < 1（对所有 i，1 <= i <= n），此处描述的生死过程不是纯出生或纯死亡过程，因为人口是有限的。因此，生死过程可以建模为非周期且不可约的DTMC。

在此DTMC模型中，通常考虑的人口数量大于 1。此外，a_i、b_i 和 d_i 应满足概率可加性公理。然后，离散时间生死过程可以形式化为：

### Definition 7.12
```
|- \/ X p a b d n p_o.
DB_MODEL X p a b d n p_o =
Aperiodic_MC X p ([ 0, n ], POW [ 0, n ]) p_o (DBLt a b d) \/
Irreducible_MC X p ([ 0, n ], POW [ 0, n ]) p_o (DBLt a b d) \/
1 < n /\ (a_0 + b_0 = 1) /\
\/ j. 0 < j /\ j < n => (a_j + b_j + d_j = 1) /\
\/ j. j < n => 0 < b_j /\ b_j < 1 /\ 0 < d_j /\ d_j < 1
```

在此定义中，该过程被正式描述为非周期且不可约的DTMC，其中状态空间表示为一对 ([0, n], POW [0, n])。集合 [ 0, n ] 表示人口，POW [ 0, n ] 是集合 [ 0, n ] 的σ代数。由于非周期且不可约的DTMC与初始分布无关，此模型中的参数 p₀ 是一个一般函数。定义 7.12 中显示的其他条件是上述离散时间生死过程规范中描述的要求。

现在，可以验证此离散时间生死过程表现出极限概率。

### Theorem 7.9

```
|- ∀ X p a b d n p₀.
DB_MODEL X p a b d n p₀ ⇒ (∃ u. prob p { Xt = i } → u)
```

该定理可以通过使用定义 7.12 重写目标，然后应用定理 7.5 来验证。

现在，我们可以证明极限概率分布是稳态分布，并且与初始概率向量无关，如下所示：

### Theorem 7.10

```
|- ∀ X p a b d n p₀.
DB_MODEL X p a b d n p₀ ⇒ (∃ f. stationary_dist p X f)
```

该定理首先通过将 f 实例化为极限概率 lim (λ t. P {X_t = i})，然后应用定理 7.9 来验证。
