
Let A be a collection of subsets (or subset class) of a space X. Now, a predicate, which is a function with an output of Boolean type, subset_class can be defined in HOL4 such that it can test whether A is a subset class of X.

## Definition 4.7

```
⊢ ∀ X A. subset_class X A = ∀ s. s ∈ A ⇒ s ⊆ X
```

A set is called countable if its elements can be counted one at a time, or in other words, if there exists a surjective function: f : N → s such that every element of the set s can be associated with a natural number. This is formalized in HOL4 as:

## Definition 4.8

```
⊢ ∀ s. countable s = ∃ f. ∀ x. x ∈ s ⇒ ∃ (n: num). f n = x
```

Now, a collection of subsets A (or subset class) of a space X, defines a sigma algebra on X if A contains the empty set ∅, and is closed under countable unions and complementation within the space X.

## Definition 4.9

```
⊢ ∀ X A. sigma_algebra (X, A) =
subset_class X A ∧ { } ∈ A ∧
(∀ s. s ∈ A ⇒ X \ s ∈ A) ∧ ∀ c. countable c ∧ c ⊆ A ⇒
∪ c ∈ A
```

where X\s denotes the complement of s within X and ∪c, i.e., the union of all elements of c. The pair (X, A) is called a σ-field or a measurable space and A is the set of measurable sets. Now, the space and subsets function can be defined as shown in Definitions 4.9 and 4.10.

## Definition 4.10

```
⊢ ∀ X A. space (X, A) = X
```

## Definition 4.11

```
⊢ ∀ X A. subsets (X, A) = A
```

Trivial examples of sigma algebra on a space X include the empty set, which is the smallest sigma algebra on X and the powerset of X, P(X) which is comprised of all subsets of X and is the largest sigma algebra on X. For any collection G of subsets of X, we can construct σ(X, G), the smallest sigma algebra on X containing G. σ(X, G) is called the sigma algebra on X generated by G. There is at least one sigma algebra on X containing G, namely the powerset of X. σ(X, G) is the intersection of all those sigma algebras. The sigma algebra on X generated by G is formalized in HOL4 as:

## Definition 4.12

```
⊢ ∀ X G. sigma X G = (X, ∩ { s | G ⊆ s ∧ sigma_algebra (X, s) })
```

where ∩c denotes the intersection of all elements of c.

A triplet (X, A, μ) is called a measure space if (X, A) is a measurable space and μ: A → R is a non-negative and countably additive measure function.

## Definition 4.13

```
⊢ ∀ X A μ. p.measure_space (X, A, μ) =
sigma_algebra (X, A) ∧ positive (X, A, μ) ∧
countably_additive (X, A, μ)
```

A measure function is countably additive when the measure of a countable union of pairwise disjoint measurable sets is the sum of their respective measures. The countable additivity property is formalized in HOL4 as:

## Definition 4.14

```
⊢ ∀ X A μ. p.countably_additive (X, A, μ) =
∀ f. f ∈ (UNIV → A) ∧
(∀ m n. m ≠ n ⇒ DISJOINT (f m) (f n)) ∧
∪ (IMAGE f UNIV) ∈ A ⇒
μ o f sums μ (∪ (IMAGE f UNIV))
```

In this definition, the countable union of subsets is captured through the domain of function f, which is the set of natural numbers UNIV (num), and the range of f, which is the set of measurable sets A. The function μ is then countably additive if the sequence μ(f(n)) converges to μ(∪ₙ f(n)).

Some convenient helper functions, m_space, measurable_sets and measure, which take a measure space as an argument and return the corresponding component as follows, are also available in the HOL4 formalization of measure theory.

## Definition 4.15

```
⊢ ∀ X A μ. m_space (X, A, μ) = X
```

## Definition 4.16

```
⊢ ∀ X A μ. measurable_sets (X, A, μ) = A
```

## Definition 4.17

```
⊢ ∀ X A μ. measure (X, A, μ) = μ
```

Measurable functions are structure preserving, i.e., the inverse image of each one of their measurable set is also measurable. This is analogous to continuous functions in metric spaces where the inverse image of an open set is open. Let (X₁, A₁) and (X₂, A₂) be two measurable spaces. A function f: X₁ → X₂ is called measurable with respect to (A₁, A₂) if f⁻¹(A) ∈ A₁, for all A ∈ A₂.

## Definition 4.18

```
⊢ ∀ a b. f ∈ measurable a b =
sigma_algebra a ∧ sigma_algebra b ∧ f ∈ (space a → space b) ∧
∀ s. s ∈ subsets b ⇒ PREIMAGE f s ∩ space a ∈ subsets a
```

The HOL4 function PREIMAGE denotes the inverse image of a function. Notice that unlike Definition 4.17, the inverse image in the formalization needs to be intersected with space a because the functions in HOL4 are total, meaning that they map every value of a certain HOL4 type (even those outside space a) to a value of an appropriate type which may or may not be in space b. In other words, writing in HOL4 that f is a function from space a to space b, does not exclude values outside space a and hence the intersection is needed. It is important to note that in this definition, any structure on the measurable spaces is not specified. If we consider a function f that takes its values on a metric space, most commonly the set of real numbers or complex numbers, then the Borel sigma algebra on that space is used. In the following, we present our formalization of the Borel sigma algebra in HOL.

Working with the Borel sigma algebra makes the set of measurable functions a vector space. It also facilitates the verification of various properties of the measurable functions necessary for the formalization of the Lebesgue integral in HOL. The Borel sigma algebra on a space X is the smallest sigma algebra generated by the open sets of X. It can be defined using the sigma function as follows:

## Definition 4.19

```
⊢ ∀ X. borel X = sigma X (open_sets X)
```

An important example, especially in the theory of probability, is the Borel sigma algebra on R, denoted by B(R) which is also called Borel usually.

## Definition 4.20

```
⊢ Borel = sigma UNIV (: real) (open_sets UNIV)
```

where UNIV is the universal set of real numbers R. Clearly, the formalization of the Borel sigma algebra, which is based on the open sets, requires the formalization of some topology concepts of R. Additionally, a formalization of the set of rational numbers Q is also required for verifying various properties of B(R).

A rational number can be expressed as the quotient of two integers with a positive denominator. Natural numbers in HOL4 are used to express Q, i.e., the set of rational numbers, as the union of non-negative (Q+) and non-positive (Q-) rational numbers.

## Definition 4.21

```
⊢ Q = { r | ∃ n, m. r = n/m ∧ m > 0 } ∪ { r | ∃ n, m. r = -n/m ∧ m > 0 }
```

An extensive number of reassuring properties on the set Q as well as few other less straightforward ones, namely, Q is countable, infinite and dense in R have been formally verified in HOL.

The second main requirement for defining the Borel sigma algebra on R is the formalization of the topological concepts of neighborhood and open set in R. Let a ∈ A ⊂ R. Then A is a neighborhood of a if there exists a real number d > 0 such that ∀ x. |x - a| < d ==> x ∈ A. In other words, a is an interior point of A.

## Definition 4.22

```
⊢ ∀ A a. neighborhood A a = ∃ d. 0 < d ∧ ∀ y. a - d < y ∧ y < a + d ==> y ∈ A
```

If every point of a set is an interior point then the set is open.

## Definition 4.23

```
⊢ ∀ A. open_set A = ∀ x. x ∈ A ==> neighborhood A x
```

Based on the above formalization, the following properties related to the open sets have been verified in HOL.

- The empty set and the universal set are open.
- Every open interval is an open set.
- The union of any family of open sets is open.
- The intersection of a finite number of open sets is open.
- Every open set in R is the union of a countable family of open intervals.
- The inverse image of an open set by a continuous function is open.

Another very useful property that has been verified in the HOL4 formalization for measure theory is that the Borel sigma algebra on the real line B(R) is generated by the open intervals ([c, d[ for c, d ∈ R). This property is actually used in many textbooks as a starting definition for the Borel sigma algebra on R.

## Theorem 4.2

```
⊢ Borel = sigma UNIV (open_intervals set)
```

It can also be verified in HOL4 that B(R) is generated by any of the following classes of intervals: ]-∞, c[, [c, +∞[, ]c, +∞[, ]-∞, c[, [c, d[, [c, d], ]c, d[ where c, d ∈ R. To prove this result this suffices to prove that any interval ]c; d[ is contained in the sigma algebra corresponding to each class. For the case of the intervals of type [c, d[, this results from the equation [c, d[ = ∪ₙ (c + 1/n², d[. For the open rays ]-∞, c[, the result follows from the fact that [a, b[ can be written as the difference of two rays, [a, b[ = ]-∞, b[ \ ]-∞, a[. In a similar manner, it can also be verified in HOL4 that all mentioned classes of intervals generate the Borel sigma algebra on R. Another useful result asserts that the singleton sets are measurable sets of B(R).

## Theorem 4.3

```
⊢ ∀ c:real. { c } ∈ subsets Borel
```

The proof of this theorem follows from the fact that a sigma algebra is closed under countable intersections and the following equation.

∀ c ∈ R. {c} = ∩ₙ [c - 1/2ⁿ, c + 1/2ⁿ] (4.1)

Recall that in order to check if a function f is measurable with respect to (A₁, A₂), it is necessary to check that for any A ∈ A₂, its inverse image f⁻¹(A) ∈ A₁. For real-valued functions, it suffices to perform the check on the open rays ((-∞, c), c ∈ R), i.e., Let (X, A) be a measurable space. A function f : X → R is measurable with respect to (A, B(R)) if ∀ c ∈ R, f⁻¹((-∞, c)) ∈ A.
