定理 13.1 的证明基于归纳法、乘法规则、对均匀随机变量（定义 13.1）及其补集的概率分布进行验证，以及对集合的一些分析。

由于子网络要么为空，要么非空，我们可以用一个伯努利随机变量来建模这种行为，该变量以成功概率（prob p ({x | subset_empty (&j) (rd_subsets n (X x))} ∩ p space p)）取值 1。空子网络的高阶逻辑形式化可以在 HOL 中表示如下：

### Definition 13.4

```
|- ∀ Y n X p a k j. subset_empty_rv Y n X p a k j =
(uniform_distr rv X p a k) ∧
(bernoulli_distr_rv Y p (prob p ({x | subset_empty (&j) (rd_subsets n (X x)) = T} ∩ p space p))).
```

上述定义将输入变量 Y 指定为概率空间 p 上的伯努利随机变量（bernoulli_distr_rv），其成功概率为（prob p ({x | subset_empty (&j) (rd_subsets n (X x))} ∩ p space p)），且 X 是均匀随机变量（uniform_dist_rv）。成功概率为 pr 的伯努利随机变量指定如下：

### Definition 13.5

```
|- ∀ X p pr. Bernoulli_distr_rv X p pr =
(real_random_variable X p) ∧ (IMAGE X (p space p) = {0;1} ∧
(distribution p X {1} = pr))
```

基于上述形式化，我们可以轻松验证空子网络的概率分布。

### Theorem 13.2

```
|- ∀ Y X p m a n k. (1 < k) ∧ (subset_empty_rv Y n X p a k j) ∧
(&j ∈ IMAGE X (p space p)) ∧ (∀ c. indep p ({x | X x ≠ &j } ∩ p space p)
({x | subset_empty (&j) (rd_subsets c (X x)) } ∩ p space p))
⇒ (prob p({x | Y x = 1 } ∩ p space p) = (1 - 1/(&k)) pow n).
```

根据定理 13.2，我们可以注意到，空子网络的概率分布仅取决于输入参数 k 和 n。因此，为了简化，我们选择直接使用成功概率为（1 – 1/k）的伯努利随机变量来建模空子集，从而抽象掉均匀随机变量。新的高阶逻辑函数表示为 sbst_empty_rv。

### Definition 13.6

```
|- ∀ X p k n. sbst_empty_rv X p k n = Bernoulli_distr_rv X p (1 - 1/k)
```

## 13.2.2 网络覆盖强度的形式化

在无线传感器网络中，如果监测区域内某一点发生的随机事件被至少一个活动节点以给定概率检测到，则称该点被覆盖。因此，监测区域内的每个点都由覆盖强度来表征，而整个网络的覆盖行为是所有节点的平均值。因此，网络覆盖是一种广泛使用的性能指标。接下来，我们首先有兴趣正式分析监测区域内某一点的覆盖强度，并在此基础上开发网络覆盖的高阶逻辑形式化。

令 S 表示覆盖场域内特定点的传感器集合，其基数为 c。当将随机节点调度应用于集合 S 时，它会随机将每个传感器节点分配到 k 个不相交子集中的一个（Xiao et al, 2009）。因此，在给定时间槽 T 内，如果当前活动子集包含至少一个节点，即非空，则该点被覆盖。然而，如前所述，由于节点调度的随机特性，子集可能完全为空。请注意，此处使用的术语“空”是指不包含覆盖节点的子集，因为随机调度现在应用于集合 S。监测区域内某一点的覆盖强度（记为 Cp）定义为在长度为 k x T 的整个调度周期内该点被覆盖的平均时间。因此，该指标取决于整个调度周期内的非空子集。监测区域内给定点的覆盖强度 Cp 在数学上指定为

```
Cp = E[X] x T / k x T (13.1)
```

其中 E[X] 表示描述非空子集总数的随机变量 X 的期望，且

```
X = \sum_{j=0}^{k-1} X_j (13.2)
```

其中 Xj 是伯努利随机变量，在子集非空时其值为 1。类似于定义 13.6 中对空子集的规范，我们可以用成功概率为（1 – 1/k）的补集概率的伯努利随机变量来建模非空子网络。

### Definition 13.7

\(\vdash \forall p \ x \ k \ n. \ sbst\_non\_empty\_rv \ x \ p \ k \ n =\)
\(bernoulli\_distr\_rv \ x \ p \ (1 - (1 - 1/k))\)

根据上述描述，我们使用以下谓词 cvrg_insty_pt 来建模特定点（方程 13.1）的覆盖行为，该谓词接受五个参数：p：概率空间；X：返回扩展实数的随机变量；k：子网络的数量；s：基数为 k 的求和集合；c：覆盖该点的节点数量。

### Definition 13.8

\(\vdash \forall p \ x \ k \ s \ c. \ cvrg\_insty\_pt \ p \ x \ k \ s \ (c:num) =\)
\(expectation \ p \ (x. \ SIGMA \ (\lambda i. \ x \ i) \ s) \ / \ (\&k)\)

监测区域内某一点覆盖强度的以下数学表达式已得到正式验证。

### Theorem 13.3

\(\vdash \forall p \ x \ k \ s \ c. \ (prob\_space \ p) \land (FINITE \ (p \ space \ p)) \land (1 < k) \land\)
\(FINITE \ s \land (CARD \ s = k)\)
\(\land (\forall i. \ i \in s \Rightarrow sbst\_non\_empty\_rv \ (x \ i) \ p \ k \ c)\)
\(\Rightarrow (cvrg\_insty\_pt \ p \ x \ k \ s \ c = Normal \ ((1 - (1 - 1/(\&k))))\)

- 假设 FINITE (p_space p) 确保样本空间是有限的。
- 假设 ((∀ i. i ∈ s) sbst_non_empty_rv (X i) p k c) 表示集合 s 的每个元素都是类型为 sbst non empty rv（定义 13.7）的随机变量。
- HOL 函数 Normal 用于将实数值转换为其在扩展实数中的对应值。

上述定理的证明主要需要关于期望属性线性性和某些事件可测性的引理，以及对扩展实数的一些分析。

现在，可以对网络覆盖强度进行推理，我们将其表示为 Cn。Cn 被描述为监测区域内所有点的覆盖强度的平均值。在数学上，Cn 在方程 13.3 中被指定为特定点覆盖强度 Cp 的期望。

```
C_n = E[Cp] (13.3)
```

基于定理 13.3，我们可以注意到特定点覆盖强度的值主要取决于 c，即覆盖给定点的节点数量。将覆盖某点或不覆盖的事件类比为成功概率为 q 的伯努利试验，很明显，当我们在网络的 n 个节点中考虑变量 c 时，它将成为一个二项随机变量（C），其概率如下

```
Pr(C=j) = C_n^j (r/a)^j (1 - r/a)^{n-j} (13.4)
```

其中 C_n^j 是二项式系数，r 是每个传感器的感知区域大小，a 是监测区域的大小，且 (r/a) 是每个传感器覆盖给定点的概率。n 次试验且成功概率为 q = r/a 的二项随机变量已形式化如下：

### Definition 13.9

```
|- ∀ X p q n. binomial_distr_rv X p q n =
(real_random_variable X p) ∧
(IMAGE X (p space p) = IMAGE (\x. &x) (count (SUC n))) ∧
(\m. &m IN (IMAGE X (p space p))) ∧
(distribution p X (&m) = & (binomial n m) * (q pow m) * ((1 - q) pow (n - m))))
```
