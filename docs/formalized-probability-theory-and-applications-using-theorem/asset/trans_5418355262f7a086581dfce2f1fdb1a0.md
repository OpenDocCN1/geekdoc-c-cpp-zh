
基于 Mhamdi 发展的概率论，我们获得了建模非时齐 DTMC/DMRM 或多个随机过程（涉及 DTMC）的灵活性，这些过程包含不同类型的状态空间。本案例研究还介绍了期望和 DMRM 的一些经典属性的形式验证。上述形式化使我们能够分析任何多处理器系统的内存竞争问题。为说明目的，我们使用 DMRM 及其可约和非周期马尔可夫链的形式化，对典型多处理器系统进行了形式分析。

现在，我们正式定义离散随机变量的期望和条件期望，然后利用这些结果以及正式的 DTMC 定义来形式化离散时间马尔可夫奖励模型（DMRM）。

## 期望

离散随机变量 X 的期望（也称为期望值）为 E [X] = \(\sum_{i \in space sx} i Pr\{X = i\}\)。而在给定条件 Y 的情况下，离散随机变量 X 的条件期望为 E [ Y | X ] = \(\sum_{i \in space sx} i Pr\{Y | X = i\}\)。

这些定义可以形式化为（Liu, Hasan & Tahar, 2013c）：

### 定义 7.13

```
⊢ ∀ X p sx . expect X p sx = \sum_{i \in space sx} i Pr\{X = i\}
```

和

### 定义 7.14

```
⊢ ∀ X Y y p sx . cond_expect X Y y p sx = \sum_{i \in space sx} i \mathbb{P}(\{x | Y x = y\} | \{x | X x = i\})
```

其中 X 是一个离散随机变量，其类型为 ’a → real，sx 是一个有限状态空间，{ x | X x = y } 是用于计算期望的条件概率中给出的离散事件。

利用这两个形式定义，我们可以验证期望的一些有趣属性，这些属性在多处理器系统性能分析中起着至关重要的作用。我们可以证明，随机变量 X 的全期望为 E [ Y ] = \(\sum_{j \in space sx} E [ Y | X j ] Pr \{ X j \}\)。这里，X j 表示事件空间（子集 sx）中涉及的离散事件，j 是随机变量 X 的状态空间（space sx）中的任意状态。

### 定理 7.15

```
⊢ ∀ X Y p sx sy.
random_variable X p sx ∧ random_variable Y p sy ∧
(∀ x. x ∈ space sx ⇒ { x } ∈ subsets sx) ∧
(∀ x. x ∈ space sy ⇒ { x } ∈ subsets sy) ∧
FINITE (space sx) ∧ FINITE (space sy) ⇒
(expect Y p sx =
∑ j∈space sx (cond_expect Y X j p sx * P{ x | X x = j }))
```

对于随机过程 / Xt / t ≥ 0，样本空间为 sx，以及事件空间（子集 sy）中的离散事件 / Yt = y / t ≥ 0（对于有限状态空间 sy 中的所有 y），随机变量 Y 的稳态全期望为：lim_{t \to \infty} E [ Y_t ] = ∑ j∈space sx lim_{t \to \infty} E [ Y_t | X_t = j ] lim_{t \to \infty} Pr { X_t = j }

### 定理 7.16

```
⊢ ∀ X Y p sx sy.
(∀ t. random_variable (X t) p sx) ∧
(∀ t. random_variable (Y t) p sy) ∧
(∀ x. x ∈ space sx ⇒ { x } ∈ subsets sx) ∧
(∀ x. x ∈ space sy ⇒ { x } ∈ subsets sy) ∧
(∀ j. convergent (λ t. P { x | X t x = j })) ∧
(∀ i. convergent (λ t. cond_expect (Y t) (X t) i p sx)) ∧
FINITE (space sx) ∧ FINITE (space sy) ⇒
(lim (λ t. expect (Y t) p sy) =
∑ j∈space sx ((lim (λ t. cond_expect (Y t) (X t) j p sx) * lim (λ t. P { x | X t x = j })))
```

## 离散时间马尔可夫奖励模型

离散时间马尔可夫奖励模型（DMRM）是考虑成本或（双重地）奖励（奖金）的扩展 DTMC。在一些现实世界系统的性能分析中，DMRM 允许系统的众多定量度量，例如经过时间、功耗、消息队列大小、净利润等。

从数学上讲，DMRM 定义在带有实值奖励函数 rxy 的 DTMC / Xt / t ≥ 0 上，该函数通过给定状态 x 的奖励（或成本）的条件期望，为所有 t（t ≥ 0）将实奖励（或成本）关联到 X 的状态空间中的状态 x。

### 定义 7.15

```
⊢ ∀ X Y p sx s0 pij rxy. dmrm X Y p sx s0 pij =
dtmc X p sx s0 pij ∧ (∀t. random_variable (Y t) p sx) ∧
(∀ y. y ∈ space sy ⇒ {y} ∈ subsets sy) ∧
(∀ x t. P (x | Y t x = y) ≠ 0 ⇒
(rxy t x = cond_expect (Y t) (X t) x p sy))
```

其中量化变量 X 指的是底层 DTMC 中涉及的随机变量，Y 表示随机奖励，p 是概率空间，sx 指的是 DTMC 的状态空间，sy 表示随机变量 Y 的可测状态空间，p0 和 pij 是 DTMC 的初始分布和转移概率，rxy 表示奖励函数。该定义的第一个合取确保底层随机过程是 DTMC，第二个和第三个合取约束期望值为离散随机变量（Y t），最后一个条件由奖励函数给出条件期望分布。

需要注意的是，此定义提供了一个通用的 DMRM，其中状态空间可以是有限或无限的，底层 DTMC 可以是时齐或非时齐的，奖励是时间的函数（此特性有助于建模某些系统中的冲激奖励）。

通常，DMRM 中的底层 DTMC 被视为具有有限状态空间的时齐 DTMC，奖励或成本被视为相应状态的常数。我们将此常用的 DMRM 形式化如下：

### 定义 7.16

```
⊢ ∀ X Y p sx sy p0 pij rxy. th_dmrm X Y p sx sy p0 pij rxy =
dmrm X Y p sx sy p0 pij rxy ∧ FINITE (space sy) ∧
(∀ x t t'. rxy t x = rxy t' x) ∧
(∀ t i j.
P (x | X t x = i) ≠ 0 ∧ P (x | X (t + 1) x = i) ≠ 0 ⇒
pij X p s (t + 1) i j = pij X p s t i j)
```

其中第一个合取说明该模型是 DMRM，第二个条件约束奖励空间是有限空间，第三个确保随机变量（X t）的状态空间中每个状态 x 的奖励都是常数，最后一个合取指底层 DTMC 转移概率的时齐性。

如果 dMRM 的底层 DTMC 是非周期 DTMC，则条件期望是收敛的。此属性可以如下验证：

### 定理 7.17

```
|- ∀ X Y p sx sy p0 pij rxy i.
th_dmrm X Y p sx sy p0 pij rxy ∧ APERIODIC_MC X p sx p0 pij =>
convergent (λt. cond_expect (Y t) (X t) i p sy)
```

长期的预期累积奖励始终是感兴趣的，如下一个定理中验证的累积属性所示，该属性可用于获得预期稳态奖励。

### 定理 7.18

```
|- ∀ X Y p sx sy p0 pij rxy i.
th_dmrm X Y p sx sy p0 pij rxy ∧ APERIODIC_MC X p sx p0 pij ∧
i ∈ space sx ⇒
(lim (λt. cond_expect (Y t) (X t) i p sy) = lim (λt. rxy t i))
```

预期稳态奖励可以通过应用以下内容获得：

### 定理 7.19

```
|- ∀ X Y p sx sy p0 pij rxy i.
th_dmrm X Y p sx sy p0 pij rxy ∧ APERIODIC_MC X p sx p0 pij ∧
i ∈ space sx ⇒
(lim (λ t. expect (Y t) p sy) =
∑ j∈space sx (lim (λ t. rxy t j) * lim (λ t. P { x | X t x = j })))
```

上述已验证的定理将用于通过推理内存访问请求的期望来分析特定多处理器系统的内存竞争问题。

## 内存竞争问题

考虑一个具有两个内存模块和两个处理器的多处理器系统。假设任何内存模块的访问时间是常数且所有内存模块均已同步，该系统可以建模为离散时间马尔可夫奖励模型（DMRM），如图 5 所示。系统的状态由对 (i, j) 表示，其中 i 表示等待内存模块 1 的处理器数量，j 表示等待内存模块 2 的处理器数量。由于内存访问时间始终长于处理器的任何其他数据事务，因此合理地假设在每个内存周期中 0 ≤ i、0 ≤ j 且 i + j = 2。因此，状态集 { (1, 1), (0, 2), (2, 0) } 提供了给定系统的所有可能状态。此外，qk（k = 1, 2）表示处理器请求直接内存访问的概率。如果两个处理器正在访问两个不同的内存模块（在这种情况下，系统保持在状态 (1, 1)），并且将在本内存周期结束时完成任务，那么本内存周期中完成的内存请求数量的期望为 2。如果在一个内存周期中有两个访问内存模块 1 的请求，那么本内存周期中只能完成一个请求。当请求访问内存模块 2 时，我们可以得到相同的期望。我们将随机变量 Y 表示为稳态下每个内存周期中完成的请求数量，请求状态空间为集合 { 0, 1, 2 }。Y 的条件期望可以在数学上描述为：

- E [ Y | 系统处于状态 (1, 1) ] = 2；
- E [ Y | 系统处于状态 (2, 0) ] = 1；
- E [ Y | 系统处于状态 (0, 2) ] = 1。

为了分析此类系统的性能，我们有兴趣了解内存模块被高效利用的状态的稳态概率，以及稳态下每个内存周期中满足的内存请求的期望数量。
