

## Conclusion

而非实时系统，而是作为一种互补技术，当结果的精确度至关重要时，这种技术证明非常有用。

该工作使用 HOL4 定理证明器进行展示，其现有的布尔代数、集合、列表、正整数和实数理论已被广泛利用。本书中提出的形式化因此可以被视为定理证明领域最新进展的有用指标。所提出的工作清楚地表明，在机械系统中形式化数学是一项繁琐的工作，需要深入理解数学概念和定理证明。经常遇到的情况是，那些通常已知为真的引理在使用定理证明进行验证时被发现相当困难，因为所有所需的真理推理都应明确提供给验证。自动推理器通过自动验证一些一阶逻辑目标，在证明过程中起到了一定的辅助作用，但大多数时候用户需要通过提供适当的重写和简化规则来指导工具。另一方面，发现定理证明在记录管理方面非常高效。例如，在进行大量纸笔证明时，很容易混淆不同的变量和数学符号并犯人为错误，这会导致大量努力的浪费。对于机械定理证明器来说，不存在这些问题。定理证明的另一大优势是，一旦定理的证明建立，就保证其有效，并且证明可以随时访问，这与纸笔证明的情况相反，在纸笔证明中我们必须探索大量的数学文献来寻找证明。因此，可以得出结论：定理证明是一项繁琐但充满希望的领域，可以帮助数学家应对数学知识的爆炸，并拯救数学概念免受腐蚀。此外，还有一些领域，如安全关键软件、军事、太空旅行和医学，在这些领域使用形式化方法将成为迫切的需求。

## 2. 未来方向

本书中提出的形式化和验证结果，为使用定理证明对表现出随机性的系统进行精确分析开辟了新途径。基于这些结果，可以添加更多功能以增强基于定理证明的概率分析框架的能力。未来的一些扩展概述如下：

概率理论的形式化可以通过定义概率密度函数（PDF）来扩展。PDF 被定义为累积分布函数相对于概率测度的 Radon-Nikodym 导数。形式化 PDF 允许分析可以由标准连续分布（如正态分布）描述的系统类。后者可以用于建模广泛的系统类，这是由于中心极限定理。对该定理的正式证明也可以是形式化的一个有趣扩展。最后，形式化 PDF 允许用密度函数来编写随机变量的统计属性（如期望），因此在连续系统的评估中可能很有用。

DTMC 形式化的一些有趣的未来方向包括连续时间马尔可夫链（CTMC）的形式化、排队论基础的形式化以及马尔可夫决策过程。这些扩展将进一步扩大使用定理证明分析系统概率方面的范围。

像 Crowds 或 Tor 这样的协议性能评估，可以是本书中报告的信息论相关形式化的一个有趣应用。第 8 章中给出的信息泄漏度量可以用于量化这些网络不同配置下的信息泄漏。

在本书中提出的可靠性框图（RBD）形式化基础上，其他常用的 RBD，包括串-并联和 K-out-of-N，可以被形式化。此外，RBD 的形式化可以导致对许多安全关键应用的分析，包括云计算、汽车系统和医疗设备。同样，我们对 WSN 属性（覆盖和检测）的形式化导致了许多有趣的形式分析案例研究，例如水下监测和体域传感器网络（BASNs）。
