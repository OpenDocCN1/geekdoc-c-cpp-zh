
\int_X f d\mu = \int_X f^+ d\mu - \int_X f^- d\mu (4.6)

### Definition 4.27

```
\vdash \forall m f. integral m f = pos_fn_integral m (fn_plus f) - pos_fn_integral m (fn_minus f)
```

The Lebesgue monotone convergence is arguably the most important theorem of the Lebesgue integration theory and it plays a major role in the proof of the Radon-Nikodym theorem and the properties of the integral. Let $(f_j)$ be a monotonically increasing sequence of non-negative measurable functions such that $\forall x. f(x) = \sup_n f_n(x)$, then

\int_X f d\mu = \sup_n \int_X f_n d\mu (4.7)

The higher-order-logic formalization of the Lebesgue monotone convergence is the following:

### Theorem 4.10

```
\vdash \forall m f fi. measure_space m \land \forall i x. 0 \le f i x \land \forall i. fi i \in measurable (m_space m, measurable_sets m) borel \land \forall x. mono_increasing (\lambda i. fi i x) \land \forall x. x \in m_space m \Rightarrow f x = sup (image (\lambda i. fi i x) UNIV) \Rightarrow pos_fn_integral m f = sup (image (\lambda i. pos_fn_integral m (fi i)) UNIV)
```

The definition of the Lebesgue integral, based on the extended-real numbers, ensures that the integral is always defined for non-negative functions even when the integral is infinite. Let $(X, \mathcal{A}, \mu)$ be a measure space then a measurable function f is integrable iff $\int_X |f| \, d\mu < \infty$ or equivalently iff $\int_X f^+ d\mu < \infty$ and $\int_X f^- d\mu < \infty$.

### Definition 4.28

```
\vdash integrable m f = f \in measurable (m_space m, measurable_sets m) Borel \land pos_fn_integral m (fn_plus f) < \infty \land pos_fn_integral m (fn_minus f) < \infty
```

Another commonly used definition of integrability is verified as a theorem in HOL4.

### Theorem 4.11

```
|- \forall m f. measure_space m /\ integrable m f ==>
\<forall> ri.
\<forall>x. mono_increasing (\<lambda> i. fi i x) /\ 
\<forall>x. x \in m_space m ==>
(fn_plus f x = sup (IMAGE (\<lambda> i. fi i x) UNIV)) /\ 
\<forall>i. ri i \in psfis m (fi i) /\ 
\<forall>i x. fi i x \le fn_plus f x /\ 
pos_fn_integral m (fn_plus f) = sup (IMAGE ri UNIV) /\ 
\<exists>gi vi.
\<forall>x. mono_increasing (\<lambda> i. gi i x) /\ 
\<forall>x. x \in m_space m ==>
(fn_minus f x = sup (IMAGE (\<lambda> i. gi i x) UNIV)) /\ 
\<forall>i. vi i \in psfis m (gi i) /\ 
\<forall>i x. gi i x \le fn_minus f x /\ 
pos_fn_integral m (fn_minus f) = sup (IMAGE vi UNIV)
```

This theorem is verified by first showing that the sequence (fj)', defined below, satisfies the conditions of the Lebesgue Monotone Convergence theorem. This sequence is then applied for both f+ and f-.

\[ F_n(x) = \sum_{k=0}^{n-1} \frac{k}{2^n} I_{(\frac{k}{2^n} \le f(x) < \frac{k+1}{2^n})} + 2^n I_{(2^n \le f(x))} \tag{4.8} \]

Then the definition of (fj)' is used to verify the following lemmas in HOL:

```
|- \forall n x, 2 ^ n <= f (x) ==> fn (x) = 2 ^ n
|- \forall n x and k < 2^n, 2 ^ n <= f (x) < \frac{k+1}{2^n} ==> fn (x) = \frac{k}{2^n}
|- \forall x, (f (x) >= 2 ^ n) \/ (\exists k, k < 2^n and \frac{k}{2^n} <= f (x) < \frac{k+1}{2^n})
```

Using these lemmas, the sequence (fj)' is proved to be pointwise convergent to f(\forall x. f(x) = sup_n fn(x)), upper bounded by f(\forall n x, f_n(x) \le f(x)) and monotonically increasing (\forall n x, f_n(x) \le f_{n+1}(x)).

Theorem 4.11 facilitates the formal verification of many useful integration properties since we can write the Lebesgue integral of any non-negative function as the supremum of sequence of integrals of positive simple functions. Using the properties of the supremum and the properties of the Lebesgue integral of positive simple functions, it is possible to prove the integral properties of non-negative functions and then for arbitrary measurable functions. Some of the useful formally verified properties available in the HOL4 formalization of Lebesgue integral are:

Let f and g be integrable functions and $c \in R$ then

- $\vdash \forall x, 0 \le f(x) \Rightarrow 0 \le \int_x f \, d\mu$
- $\vdash \forall x, f(x) \le g(x) \Rightarrow \int_x f \, d\mu \le \int_x g \, d\mu$
- $\vdash \int_x c f \, d\mu = c \int_x f \, d\mu$
- $\vdash \int_x f + g \, d\mu = \int_x f \, d\mu + \int_x g \, d\mu$
- $\vdash A \text{ and } B \text{ disjoint sets} \Rightarrow \int_{A \cup B} f \, d\mu = \int_A f \, d\mu + \int_B f \, d\mu$

### 5.1 FORMALIZATION OF PROBABILITY THEORY

The classical approach to define the probability of an event A is P(A) = N_A / N, where N_A is the number of outcomes favorable to the event A and N is the number of all possible outcomes of the experiment. However, this approach is based on the assumptions that all outcomes are equally likely (equiprobable) and that the number of possible outcomes is finite. These assumptions are not always true and thus the above-mentioned classical definition has a limited scope.

Kolmogorov introduced the axiomatic definition of probability, which overcomes the above-mentioned problem and provides a mathematically consistent way for assigning and deducing probabilities of events. This approach consists in defining a set of all possible outcomes, \(\Omega\), called the sample space, a set F of events which are subsets of \(\Omega\) and a probability measure p such that \((\Omega, F, p)\) is a measure space with \(p(\Omega) = 1\). Now, \((\Omega, F, p)\) is a probability space if it is a measure space and \(p(\Omega) = 1\).

### Definition 5.1

```
\forall p. prob_space p \Leftrightarrow measure_space p \wedge (measure p (p_space p) = 1)
```

A probability measure is a measure function and an event is a measurable set.

```
\prob = measure
events = measurable_sets
p_space = m_space
```

Two events A and B are independent iff p (A \(\cap\) B) = p (A) p (B).

### Definition 5.2

```
\forall a b. indep p a b \Leftrightarrow a \in events p \wedge b \in events p \wedge
prob p (a \cap b) = prob p a * prob p b
```

X: \(\Omega \to R\) is a random variable iff X is (F, B (R)) measurable

### Definition 5.3

```
\forall X p s. random_variable X p s \Leftrightarrow
prob_space p \wedge X \in measurable (p_space p, events p) s
```

In this book, we focus on real-valued random variables but the definition can be adapted for random variables having values on any topological space thanks to the general definition of the Borel sigma algebra.
