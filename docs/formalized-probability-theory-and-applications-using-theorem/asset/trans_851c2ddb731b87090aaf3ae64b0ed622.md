⊢ ∀ p n s L Ts. (1 ≤ n) ∧ (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts) ⇒ (mono_incr (λk. real (D_surv p D n k (0.28)))) .

随机调度因此是一种动态方法，它根据 k 的值为部署的 WSN 应用提供性能调整。

节点调度方法中的随机性会导致不同规模的子网络，其规模取决于节点数量。显然，理想情况发生在算法对网络进行公平划分，使得所有子集具有相同大小，即相同数量的节点，我们将其表示为 m。节点数量 n 因此可以写成 k × m。在以下内容中，我们将在节点均匀划分的情况下，密切研究 k-集随机算法的渐近性能行为。

特别是，我们成功验证了当 n = k × m 且 k 趋于无穷大时，检测概率 Pd_wsn 的上限：

## Lemma 14.13

⊢ ∀ p m q s L Ts. (0 < s < 1) ∧ (0 < L) ∧ (0 < Ts) ∧ (∀k. L < & (SUC k) × Ts) ∧ (0 < q < 1) ⇒ lim k→∞ (λk. Pd_wsn p (k × m) k s L Ts q) = 1 - (1 - s) ^ -⌊(L / Ts)⌋ × q × m - s - e ^ -⌊(L / Ts)⌋ + 1) × q × m.

上述引理的证明基于重要的数学结果 lim k→∞ (1 + x / k)^k = e^x，我们之前已证明该结果。

基于 Lemma 14.13，对上述极限关于各种参数（如入侵周期 L 和每个子集的节点数 m）的分析现在已可行。我们因此验证，当 m 非常大时，检测概率必然趋近于 1。该结果被视为在 n = k × m 的特定情况下对 Lemma 5.2 的第二次验证。

与传统的用于验证边境监控 WSN 的分析技术不同，使用 k-集随机调度算法，我们的方法要高效得多。的确，基于纸笔的分析或仿真无法保证调度性能结果的正确性，而本章报告的定理绝对准确。这一显著特征归因于定理证明固有的可靠性及其通用性，例如，对于 n 和 k 的任何给定值，可以通过用适当值实例化定理 14.2 来计算检测概率。相反，仿真通常局限于特定的网络配置，而概率模型检查经常使用参数抽象来应对状态空间爆炸问题（Pruth, 2006）。此外，对于每个经过形式验证的定理，所需假设集都已明确说明，因此不会有遗漏关键假设的疑虑。在仿真和模型检查中，许多假设可以被考虑而不明确提及，这一点永远无法得到保证。

在这项工作中，我们通过定理证明为 WSN 的随机调度算法性能评估提供了一种完全严谨的方法。的确，随机节点调度算法的概率特性使得对所有可能情况的分析变得具有挑战性。由于传感器节点被随机分配到 k 个子网络中，可能会出现某些子网络为空的情况。此外，由于节点的随机部署，随机调度可能导致某些区域完全不受监控或同时被许多传感器监控的情况。对这种算法进行严格的性能评估是一项非平凡的任务，尤其是考虑到传统性能分析技术的非穷尽性。

在本章中，我们在 HOL4 定理证明器中开发了使用 k-集随机调度的无线传感器网络检测属性的形式化。我们能够对任何发生事件的入侵周期进行准确的形式化，并在此基础上构建了检测概率和延迟的形式化发展。这些高阶逻辑发展的实际有效性随后通过使用 k-集随机调度算法分析边境监控 WSN 得到了说明。

由于高阶逻辑的不可判定性，检测属性的开发大约消耗了 260 人时和 2400 行代码。另一方面，我们的应用的形式分析仅用了 400 行 HOL4 代码来验证引理 14.1、14.2、14.7 和 14.8。而引理 14.3 和 14.9 中关于检测延迟相对于两个参数 n 和 k 的单调性的证明相当冗长且繁琐，各自耗费了 1500 行 HOL4 代码。的确，鉴于检测延迟数学表达式的复杂性，这两个引理的 HOL4 分析需要对级数的收敛性和无穷和的性质进行大量实数推理。更具体地说，为了证明引理 14.3，我们不得不考虑另一种数学解决方案，因为最初的纸笔证明包含了一些在 HOL4 理论中不可用的数学方面。此外，寻找检测延迟开始随 n 减少的范围也有些棘手。关于引理 14.9 的证明，它基于计算相应实函数的导数并应用中值定理。同样，引理 14.13 和 14.14 的证明相当冗长，总共消耗了 600 行 HOL4 代码。的确，如前所述，这些证明需要数学定理 lim (1 + x / k)^k = e^x，而该定理在 HOL 中缺失。后者基于大量与将指数函数定义为幂级数相关的实分析，以及许多与序列收敛性相关的性质。

得益于 HOL4 定理证明器中可用的概率理论的可靠支持，我们能够通过对其固有随机性的适当建模，提供 k-集随机调度检测性能的准确形式化。很明显，其他分析技术永远无法达到这种效率。的确，以前的仿真工作主要基于伪随机建模。同样，与概率模型检查器相比，本章提供的一项主要新功能是能够对问题的统计属性进行正式和准确的推理。因此，可以将检测延迟作为统计量度进行验证。此外，定理证明的通用性和高阶逻辑的高表达能力，使我们能够为节点数量 n、不相交子集数量 k、成功概率 q、入侵周期 L 和调度时间槽 T 的任何值建立定理。显然，这种通用性通过仿真和模型检查永远无法实现。最后，因为遗漏关键假设可能导致定理证明器中的验证失败，当前方法在最小假设集的完整性方面具有显著特征。

另一方面，边境监控应用检测行为的正式性能分析清楚地表明了理论高阶逻辑发展的有用性。此外，这种验证使对部署 WSN 的可靠渐近推理成为可能。例如，引理 14.9 证明中缺失的项清楚地突出了形式方法保证准确和完整结果的主要优势。还应注意，所展示的应用是一个简单的案例研究，说明了可行性，但这些结果对任何其他 WSN 应用也同样有价值。

上述与定理证明方法相关的额外优势，是以用户在形式化随机调度算法并正式推理其检测属性时所花费的时间和精力为代价获得的。我们认为，我们工作中面临的主要挑战是将一个远非纯粹数学问题的真实 WSN 算法的概率模型映射到高阶逻辑中。确实，在这项工作中遇到了许多困难。现实世界系统的数学建模通常非常直观。因此，初始理论模型包含许多隐藏步骤，无论是在考虑随机变量还是应用概率规则时，都缺乏相关解释。因此，我们必须正确推理所有缺失的步骤，以便首先理解理论分析的流程，然后实现检测属性的高阶逻辑形式化。在这个阶段，通常需要良好的概率背景和对 WSN 上下文的扎实了解，才能深入理解概率推理。此外，原始模型的假设从未被详尽地呈现，而完整的假设集对于成功验证至关重要。尽管如此，我们在已经验证的概率理论相关结果基础上构建的事实，在很大程度上帮助保持了证明工作量的合理性。
