R_{Series-Parallel} = \prod_{i=1}^{N} \left( 1 - \prod_{j=1}^{M} (1 - R_{ij}(t)) \right) \quad (12.14)

Now the reliability of the series-parallel structure can be formalized in HOL4 as follows:

# Definition 12.13

```
|- ∀ L. list_union_list L = MAP (λa. union_list p a) L
```

The list_union_list function takes a list of list L and returns a list by mapping the union_list function on every element of the given list of list.

# Definition 12.14

```
|- (∀ p x. list_ser_par_rel_list_prod p [] x = []) ∧
∀ p h t x.
list_ser_par_rel_list_prod p (h::t) x = list_prod (one_minus_list
(rel_list p h x))::
list_ser_par_rel_list_prod p t x
```

The function list_ser_par_rel_list_prod accepts a two dimensional list of events, representing the time to failure of individual components connected in series-parallel structure, and a variable x, which represent the time index, along with the probability space p and returns a list of product of complement reliabilities of the components connected in parallel at every stage. The functions list_prod, one_minus_list and rel_list are used to model the product of reliabilities, complement of reliabilities, and the events corresponding to the component functioning reliably at the desired time x, respectively.
