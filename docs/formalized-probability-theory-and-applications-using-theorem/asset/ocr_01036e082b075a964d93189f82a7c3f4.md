Now, simplifying P_c(UD | c = j) in Equation (14.6), along with the fact that the events A12 and A22 are disjoint, we get the following result.

```
Pr(UD | c = j) = Pr(UD | A12 ∩ (c = j)) × Pr(A12 | c = j)
+ Pr(UD | A22 ∩ (c = j)) × Pr(A22 | c = j)   (14.8)
```

Intuitively, for a given intrusion event of length L, the occurrence of the event (A12 = L overlaps ⌈ L / Ts ⌉ cycles), and the event (c = j) describing that there are j covering nodes, are governed by distinct and non-interacting physical processes. Hence, the two events turn out to be independent. Now we get hence Pr(A12 | c = j) = Pr(A12) = Pr(IT ⌈ L / Ts ⌉), where IT is the intrusion random variable as specified in Definition 14.1. Similarly, we obtain Pr(A22 | c = j) = Pr(IT ⌈ L / Ts ⌉ + 1). This allows us to rewrite the RHS of Equation (14.8) as

```
Pr(UD | A12 ∩ (c = j)) × Pr(A12) + Pr(UD | A22 ∩ (c = j)) × Pr(A22)   (14.9)
```

On the other hand, the event “UD | A12 ∩ (c = j)” indicates the event of “being unable to detect an intrusion event” given that “the intrusion period L overlaps ⌈ L / Ts ⌉ cycles” and “there are j covering nodes”. Indeed, if an event, covered with j nodes and overlapping (h = ⌈ L / Ts ⌉) rounds, is not detected, then it means that all the j covering nodes miss the h consecutive subsets. In other words, the sequence of h subsets do not contain covering nodes. Such event is expressed by the following equation.

```
Bh, c = H1, c ∩ H2, c ∩ ... ∩ Hi, c ∩ ... ∩ Hh, c = ( ⋂_{i=1}^k H_{i,c} )   (14.10)
```

where Hi, c is the event that none of the c covering sensor nodes belongs to the working subset i, i.e., Hi, c is empty, and the set of events { H1, c, H2, c, ..., Hh, c } is mutually independent. We say that a finite set of events is mutually independent
