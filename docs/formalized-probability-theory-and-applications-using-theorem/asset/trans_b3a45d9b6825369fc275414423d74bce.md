

## 第8章 隐马尔可夫模型的形式化

## 摘要

本章，作者们对扩展 DTMC 模型（即隐马尔可夫模型，HMM）进行了形式化，HMM 是正式评估特定观测序列出现概率并找出生成给定观测的最佳状态序列的核心概念（Mantyla & Tuukimuskeskus, 2001; Rabiner, 1990）。为了展示 HMM 形式化及其属性形式验证的实用性，作者在本章末尾展示了 DNA（脱氧核糖核酸）序列的形式分析。

### 8.1 HMM 的定义

为了准确分析 HMM（Eddy, 2004），我们提出应用形式化的 DTMC 来正式定义 HMM，并在高阶逻辑中验证其属性，作为扩展 DTMC 模型。

HMM 是一对随机过程 { Xk ; Yk } k ≥ 0，其中 { Xk } k ≥ 0 是马尔可夫链，{ Yk } k ≥ 0 与 { Xk } 条件独立，即 Yk 仅依赖于 Xk，而不依赖于任何 t ≠ k 的 Xt。HMM 用于建模此类情形：实验者在每个时刻都会观察到一些观测值（用 Yk 数学表示），并怀疑这些可观测值是由可用马尔可夫链（{ Xk } k ≥ 0）建模的过程产生的。“隐马尔可夫模型”这一名称源于这样一个事实：该模型在特定时刻所处的状态对观察者不可用。现在，HMM 被定义为参数化三元组 (A, B, π(0))，并满足以下条件：

- 1. 具有有限状态空间 S 的隐马尔可夫链 { Xk } k ≥ 0，初始分布 π(0) = { π i (0) } i ∈ S 和转移概率 A = { aij } i ∈ S, j ∈ S。
- 2. 具有有限状态空间 O 的随机过程 { Yk } k ≥ 0。隐马尔可夫链和随机过程与发射概率 B = { bj (Ok) } j ∈ S, k ∈ O = { Pr { Yn = Ok | Xn = j } } j ∈ S, k ∈ O 相关联。这意味着：
  - a. ∀ j k. bj (Ok) ≥ 0。
  - b. ∑ k ∈ O bj (Ok) = 1。
- 3. 随机过程 { Yk } k ≥ 0 和隐马尔可夫链 { Xk } k ≥ 0 具有条件独立性。

这得出了形式化（Liu, 2013）：

```
Definition 8.1
⊢ ∀ X Y p s_x s_y P_0 P_ij Pxy .
hmm X Y p s_x s_y P_0 P_ij Pxy =
dtmc X P p s_x P_0 P_ij ∧ (∀t. random variable (Y t) p s_y) ∧
(∀ i. i ∈ space s_x → { i } ∈ subsets s_y ) ∧
(∀ t a i. P ( { x | X t x = i } ) ≠ 0 →
P ( { x | Y t x = a } | { x | X t x = i } ) = P_xy t a i ) ∧
∀ t a i tx0 ty0 sts_x sts_y.
t ∉ { tx0 + m | m ∈ sts_x } ∧ t ∉ { ty0 + m | m ∈ sts_y } ∧
P ( { x | Y t x = a } |
( { x | X t x = i } ∩ ⋂_{k ∈ sts_x} { x | X (tx0 + k) x = EL k sts_x } ∩
⋂_{k ∈ sts_y} { x | Y (ty0 + k) x = EL k sts_y } ) ≠ 0 →
P ( { x | Y t x = a } | { x | X t x = i } )
```

在此定义中，变量 X 表示底层 DTMC 的随机变量（由第一个合取式约束），Y 表示随机观测（因此 Y t 是随机过程，如第二个条件所述），p_xy 表示发射概率，即根据状态 X 获得 Y 特定值的概率。与定义 6.3 中的第二个条件类似，条件 (∀i. i ∈ space s_y ⇒ { i } ⊆ subsets s_y) 确保事件空间是离散空间。合取式 (∀t a. i P { x | X t x = i } ≠ 0 ⇒ P ( { x | Y t x = a } | { x | X t x = i } ) = P_xy t a i) 在条件 P { x | X t x = i } ≠ 0 下将函数 p_xy 分配给发射概率，从而确保相应的条件概率定义良好。上述定义中非平凡的合取式是最后一个，它形式化了上述条件独立性概念。在我们的工作中，我们主要考虑离散时间和有限状态空间的 HMM，这是最常用的情况。

### 定义 8.2。

```
⊢ ∀ X Y p s_x s_y p_0 P_ij P_xy .
hmm X Y p s_x s_y p_0 p_ij P_xy =
hmm X Y p s_x s_y p_0 p_ij P_xy ∧
FINITE (space s_x) ∧ FINITE (space s_y) ∧
∀t a i j . P ( { x | X t x = i } ≠ 0 ∧ P ( { x | X (t + 1) x = i } ≠ 0 ⇒
(Trans X p s (t + 1) i j = Trans X p s t i j ) ∧
(p_xy (t + 1) i j = p_xy t i j )
```

其中，模型被约束为隐马尔可夫模型（由第一个条件 hmm X Y p s_x s_y p_0 p_ij P_xy 约束），状态和观测均具有有限空间；此外，最后一个合取式确保 HMM 的转移概率满足齐次性，且发射概率具有时间独立性。

接下来，我们验证 HMM 的一些经典属性，这些属性在减少可用 HMM 表示的系统形式分析中的用户交互方面起着至关重要的作用。

### 8.2 HMM 属性

HMM 用于解决三类问题：1) 评估特定观测序列出现的概率；2) 找出生成给定观测的最可能状态序列；以及 3) 在假设模型中学习参数。这些解决方案与某些重要的 HMM 属性相关，将在以下部分验证。

### 8.2.1 HMM 的联合概率

时间齐次 HMM 最重要的属性是状态序列及其对应观测的联合分布表达式，可通过其发射概率和转移概率的乘积来表示。这常用于寻找最佳状态路径或估计模型参数。在数学上，这表示为以下方程：

```
\mathcal{P}r \left( Y_{0},...,Y_{t},X_{0},...,X_{t} \right) =
\mathcal{P}r \left( X_{0} \right) \mathcal{P}r \left( Y_{0} | X_{0} \right) \prod_{k=0}^{t-1} \mathcal{P}r \left( X_{k+1} | X_{k} \right) \mathcal{P}r \left( Y_{k+1} | X_{k+1} \right) \quad (8.1)
```

并已使用 HOL4 定理证明器进行了形式验证，如下所示：

### 定理 8.1

```
⊢ ∀ X Y p s_x s_y P_0 P_ij P_xy t sts_x sts_y.
hmm X Y p s_x s_y P_0 P_ij P_xy ⇒
(P (⋂_{k=0}^{t} {x | X k x = EL k sts_x} ∩ ⋂_{k=0}^{t} {x | Y k x = EL k sts_y}) =
P {x | X 0 x = EL 0 sts_x }
P ({x | Y 0 x = EL 0 sts_y } | {x | X 0 x = EL 0 sts_x })
(PROD (0, t) (\k. P ({x | X (k + 1) x = EL (k + 1) sts_x } |
{ x | X k x = EL k sts_x })
P ({x | Y (k + 1) x = EL (k + 1) sts_y } |
{ x | X (k + 1) x = EL (k + 1) sts_x }))))
```

其中，前八个变量保留与定义 8.1 和 8.2 中相应变量相同的记号，变量 t 表示本定理中考虑的最后一个观测的索引，且等于方程 (8.1) 右侧从 0 到 (t – 1) 的乘积项数，sts_x 和 sts_y 分别表示可能的底层状态路径和可观测序列。

证明：本定理的证明主要基于定理 3.1 以及定义 8.1 和 8.2，并辅以一些算术推理。本定理为解决 HMM 主要用于解决的三类问题奠定了基础，如第 8.1 节所述。

### 8.2.2 观测序列概率

HMM 通常用于解决的第一类问题是评估特定观测序列出现的概率，可在数学上表示为：

\mathcal{P}_t \{ Y_0, ..., Y_t \} = \sum_{X_0, ..., X_t \in space s} \cdot \mathcal{P}_t \{ X_0 \} \mathcal{P}_t \{ Y_0 | X_0 \} \prod_{k=0}^{t-1} \{ \mathcal{P}_t \{ X_{k+1} | X_k \} \mathcal{P}_t \{ Y_{k+1} | X_{k+1} \} \} (8.2)

我们可以如下形式验证此方程：

```
Theorem 8.2
⊢ ∀ X Y p s s_x s_y P_0 P_{i,j} P_{xy} sts_y .
hmm X Y p s s_x s_y P_0 P_{i,j} P_{xy} ⇒
let L = {L | EVERY (λx. x ∈ space s_x) L ∧ (|L| = t + 1) }
in
( P ( ⋂_{k=0}^{t} { x | Y k x = EL k sts_y } ) =
SIGMA ( sts_x . P { x | X 0 x = EL 0 sts_x }
P ( { x | Y 0 x = EL 0 sts_y } | { x | X 0 x = EL 0 sts_x } )
(PROD ( 0, t ) ( \k .
P ( { x | X ( k + 1 ) x = EL ( k + 1 ) sts_x } | { x | X k x = EL k sts_x } )
P ( { x | Y ( k + 1 ) x = EL ( k + 1 ) sts_y } |
{ x | X ( k + 1 ) x = EL ( k + 1 ) sts_x } ) ) ( sts_x ∈ L )
```

其中，| L | 返回列表 L 的长度，EVERY p L 是一个谓词，当谓词 p 对列表 L 的每个元素都成立时为真。

证明：本定理的证明基于对变量 t 的归纳。基例通过使用一些条件概率定理和集合论推理来证明。然后，步骤案例通过应用全概率公式进行验证。
