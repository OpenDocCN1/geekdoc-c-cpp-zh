

## 定义 8.4

```
|- state seq =
| [ START; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E;
FIVE; I; I; I; I; I; I; I; I; END ]
|- dna seq = [ C; T; T; C; A; T; G; T; G; A; A; A; G; C; A; G;
A; C; G; T; A; A; G; T; C; A ]
```

因此，要对图 1 所示的 HMM 进行建模，我们需要初始分布、转移概率和发射概率，定义如下：

## 定义 8.5

```
|- ini_distr i = if (i = START) then 1 else 0
|- trans_distr t i j = case (i, j) of
(START, E) -> 1 | (E, E) -> 0.9 | (E, FIVE) -> 0.1 | (FIVE, I) -> 1 |
(I, I) -> 0.9 | (I, END) -> 0.1 | -> 0
|- e_distr a i = case (i, a) of
(E, _) -> 0.25 | (FIVE, A) -> 0.05 | (FIVE, G) -> 0.95 | (I, A) -> 0.4 |
(I, T) -> 0.4 | (I, C) -> 0.1 | (I, G) -> 0.1 | _ -> 0
```

然后，为了在概率空间 p 上处理分别表示状态和观测的随机变量 X 和 Y，只需具备以下谓词：

```
thmm X Y p s_x s_y ini_distr trans_distr e_distr
^ space s_x = univ(: state) ^ space s_y = univ(: dna)
```

其中 univ(t) 是类型 t 的所有可能值的集合，例如，univ(:dna) = { A; G; T; C }。现在，例如，我们可以证明一个定理，该定理给出了在底层状态路径为 state seq 时获得序列 dna seq 的概率：

## 定理 8.4

```
|- forall X Y p s_x s_y.
thmm X Y p s_x s_y ini_distr trans_distr e_distr ^
space s_x = univ(: state) ^ space s_y = univ(: dna) ==>
P ( \bigcap_{k=0}^{|state_seq|-1} {x | X k x = EL k state_seq} \cap
\bigcap_{k=0}^{|dna_seq|-1} {x | Y k x = EL k dna_seq} ) =
0.25^18 * 0.9^13 * 0.1^4 * 0.95 * 0.4^4
```

要证明此定理，首先验证定理 8.1 的一个引理：

## 引理 8.1

```
|- forall X Y p t s_x s_y P_0 P_1 P_X sts_x sts_y.
thmm X Y p s_x s_y P_0 P_1 P_X ^ (|sts_x| = t + 3) ^ (|sts_y| = t + 1) =>
( P ( \bigcap_{k=0}^{t+2} { x | X k x = EL k sts_x } \cap \bigcap_{k=0}^{t} { x | Y k x = EL k sts_x } ) =
P ( { x | X 0 x = EL 0 sts_x } )
P ( { x | X ( k + 2 ) x = EL ( k + 2 ) sts_x } |
{ x | X ( k + 1 ) x = EL ( k + 1 ) sts_x } )
( PROD ( 0, t ) ( \lambda k. P ( { x | X ( k + 1 ) x = EL ( k + 1 ) sts_x } |
{ x | X k x = EL k sts_x } )
P ( { x | Y ( k + 1 ) x = EL k sts_x } ) |
{ x | X k x = EL ( k + 1 ) sts_x } ))))
```

其中状态路径 stsx 涉及 START 和 END 状态，如图 1 所示。引理 8.1 允许我们考虑状态与观测事件的联合概率，其中状态数多于观测数，这与定理 8.1 在 HMM 中的情况相比。

另一个有趣的属性是，给定特定的 DNA 序列，找到出现概率最高的状态路径。在我们的特定上下文中，这个问题称为 5' 剪接位点识别。我们可以分析从任何潜在状态开始的 DNA 片段。这可以使用先前使用的 DNA 序列形式化如下：

## 定理 8.5

```
|- forall Y p s_x s_y.
thmm X Y p s_x s_y ini_distr trans_distr e_distr ^
space s_x = univ(: state) ^ space s_y = univ(: dna) =>
REAL_MAXIMIZE_SET
[ E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; E; FIVE;
I; I; I; I; I; I; I; I; I; I ]
( \lambda sts: P ( \bigcap_{k=0}^{|sts|-1} { x | X k x = EL k state_seq } \cap
\bigcap_{k=0}^{|dna_seq|-1} { x | Y k x = EL k dna_seq } )
( |sts| = 26 ))
```

其中 REAL_MAXIMIZE_SET m f s 是一个谓词，仅当 f m 是 { f x | x ∈ s } 的最大元素时才为真（之所以定义为谓词，是因为 s 中可能有多个元素具有此属性）。再次注意，此定理已得到形式验证，即，即使是概率之间的比较也是从实数的公理定义演绎证明的。因此，我们对结果的信心是最大的。

虽然定理 8.4 和 8.5 已以经典定理证明方式（即交互式）证明，但生物学家拥有进行此类研究所需的高阶逻辑和 HOL4 知识的机会很少。然而，我们通过使用前一节中介绍的 SML 函数来自动化分析。

## 8.5 结论

在本章中，我们首先给出了隐马尔可夫模型（HMM）的形式定义。在时齐 HMM 定义的基础上，我们验证了基本属性，例如状态序列和观测序列的联合概率、观测序列的联合概率以及最佳路径选择。这些属性为应用于各种仿真工具和计算机代数系统的计算算法奠定了基础，以减轻 HMM 分析中的巨大计算负载。此外，本章还介绍了一种涉及 HMM 的系统的自动验证方法。我们的自动化可以进一步优化，以便与其他仿真工具进行比较。

HMM 广泛应用于几乎所有语音识别、数据压缩、人工智能和模式识别，以及计算分子生物学应用。出于这个原因，我们利用已证明的结果对 DNA 序列进行了形式分析。我们首先使用 HOL4 类型定义了 DNA 类型和底层状态，然后通过实例化相关参数构建了 DNA 序列模型。基于给定模型，准确地得到了状态序列的联合概率。此外，我们描述了如何选择具有可能底层状态路径（最佳路径）最高联合概率的 DNA 序列。最后，我们展示了如何自动计算观测到的 DNA 序列的最佳路径。

## 关键术语和定义

**脱氧核糖核酸（DNA）**：脱氧核糖核酸包含独特的遗传密码，它控制着生物体的发育和功能。

**隐马尔可夫模型**：隐马尔可夫模型（HMM）主要由一对条件独立的随机过程组成，其中之一是马尔可夫链。分析 HMM 使我们能够在不访问底层马尔可夫链的情况下找到状态路径概率。

**HMM 的联合概率**：时齐 HMM 最重要的属性是状态序列及其相应观测的联合分布的表达式，可以使用其发射概率和转移概率的乘积来表示。这经常用于找到最佳状态路径或估计模型参数。

## 摘要

本章利用度量、勒贝格积分和概率的基础理论形式化，对信息论（Cover & Thomas, 1991）的主要概念（如香农熵和互信息）进行了高阶逻辑形式化。本章的主要成果包括 Radon-Nikodým 导数和 Kullback-Leibler（KL）散度（Coble, 2010）的形式化。后者提供了一个统一框架，大多数常用的信息度量都可以基于此定义。本章随后提供了适用于离散和连续情况的一般定义，并证明了相应的简化表达式，其中考虑的度量在有限空间上是绝对连续的。
