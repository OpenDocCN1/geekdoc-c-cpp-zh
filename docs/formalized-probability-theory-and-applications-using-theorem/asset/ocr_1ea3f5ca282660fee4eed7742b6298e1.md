# Lemma 7.2

+   • **Linearity of Two Integer Sequences**: For a positive integer sequence $a_r, a_z, ..., a_k$, there exists an integer sequence $n_r, n_z, ..., n_k$ such that $d = \sum_{i=1}^k n_i a_i$, where $d$ is the greatest common divisor of sequence $a_r, a_z, ..., a_k$.

```
|- \forall a k. 0 < k \land (\forall i. i \le k \Rightarrow 0 < a i) \Rightarrow (\exists n. GCD\_SET { a i | i \in [0, k] } = \sum_{i=1}^k n i * a i)
```

# Lemma 7.3

+   • **Least Number**: If a set of positive integers $A$ is non lattice, i.e., its gcd is 1, and closed under addition, then there exists an integer $N < \infty$ such that $n \in A$ for all $N \le n$.

```
|- \forall A: (int -> bool) a. (A = { a i | 0 < a i \land i \in UNIV :(num) }) \land (GCD\_SET A = 1) \land (\forall a b. a \in A \land b \in A \Rightarrow (a + b) \in s) \Rightarrow (\exists N. { n | N \le n } \subset A)
```

The proofs of Lemmas 7.1, 7.2 and 7.3 are based upon various summation properties of integer sets and the properties of gcd of a set.
