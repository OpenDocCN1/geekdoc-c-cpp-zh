For a time-homogeneous DTMC with finite state space and one-step transition probability $\{ p_{ij} \}_{i,j} \in \mathcal{Q}$, the steady state probabilities are defined to be a vector $V_j = \lim_{n 	o \infty} p_{ij}^{(n)}$, for all $j \in \mathcal{Q}$. If $V_j$ exists for all $j \in \mathcal{Q}$, then $V_j$ is known as the stationary probability vector of that Markov chain. In other words, $V_j$ is a stationary distribution of this DTMC if it satisfies:

$V_j = \sum_{i \in \Omega} \lim_{n 	o \infty} V_i p_{ij}$

$\sum_{i \in \Omega} V_j = 1$

$0 \le \lim_{n 	o \infty} V_j$
