# Theorem 11.3

(AEP): if X1,X2, ... are iid then

```
- 1/n log ( p ( X1, ..., Xn )) ~ H ( X ) in probability
```

We formally verify the AEP using the WLLN result proved in the previous section as well as the various properties of joint probability distributions, independence of random variables and the log operator proved in Chapter 4.

```
|- prob_space p /\ 0 < e /\
(forall i j. i ~= j --> independent_rv p (Xi) (Xj)) /\
(forall i. E [ Xi ] = m) /\ (forall i. Var [ Xi ] = v) /\ (forall i. H [ Xi ] = H
[ X ]) /\/
lim (An. prob p { x | x \in s /\
- 1/n log ( prod_{i=1}^n p Xi { x } ) - H [ X ] | < e }) = 1
```

+   • Proof: Let X1,X2, ... be iid random variables and let Yi = -log ( p (Xi). Then Y1, Y2, ... are iid random variables and forall i, E [ Yi ] = H ( X ). Using the Weak Law of Large Numbers, we have:

lim_{n -> \infty} P ( | 1/n \sum_{i=1}^n Yi - H(X) | < \epsilon ) = 1 (11.4)

Furthermore,

1/n \sum_{i=1}^n Yi = 1/n \sum_{i=1}^n -log ( p (Xi)) = - 1/n log ( \prod_{i=1}^n p (Xi))

And since X1, ..., Xn are mutually independent,

- 1/n log ( \prod_{i=1}^n p (Xi)) = - 1/n log ( p ( X1 ... Xn))

Consequently,

lim_{n -> \infty} P ( | - 1/n log ( P ( X1 ... Xn )) - H ( X ) | < \epsilon ) = 1 (11.5)
