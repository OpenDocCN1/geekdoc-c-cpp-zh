在AMQM系统中，标签旨在识别待管理的对象。读写器在其RF（Radio Frequency）通信范围内与标签通信，控制协议，从标签读取信息，在某些情况下指示标签存储数据，并确保消息被传递且有效。读写器控制在称为时隙的分配时间段内传输的消息，并在每条消息成功接收后收到确认。基于AMQM通信协议，标签收集过程的时序图如图2所示。

![](img/0e284aa46fa831bc38a68343fef110e3_93_0.png)

通信序列以唤醒周期（Wakeup Period (WP)）开始，在此期间发送唤醒信号使所有标签进入就绪状态。WP之后是名为命令周期（Command Period (CP)）的收集轮次，其又由收集命令周期、监听周期（Listen Period (LP)）和确认周期（Acknowledgment Period (AP)）组成。随后，读写器等待标签随机发送的响应。标签收集基于符合ISO/IEC 18000-7标准的预定算法进行。因此，该系统具有两个属性：

- 1. 消息在 i 个时隙内成功传递的概率为 1 - (n - 1) / n
- 2. 如果收集过程足够长，最终任何消息都可以成功传递。

该通信协议可以建模为具有4个状态的DTMC：s0（起始）、s1（尝试）、s2（丢失）和 s3（已送达），如图3所示。

在起始状态，消息被生成。下一个状态始终是尝试状态，因此从起始状态到尝试状态的概率为 1。丢失消息的概率为 $\alpha$。因此，在丢失消息的情况下，系统将以概率 $\alpha$ 移动到丢失状态。而在成功传输的情况下，它将以概率 $\beta = 1 - \alpha$ 移动到已送达状态。因此，消息成功传递的概率为 $\beta$，即等于 $1 - \alpha$。一旦消息成功传递，系统将移动到起始状态，以便在下一个时隙识别其他标签。当收集过程结束时，系统进入睡眠模式以尽量降低功耗。与图3所示的马尔可夫链对应的状态转移概率矩阵如下：

\( P = \begin{pmatrix} 0 & 1 & 0 & 0 \\ 0 & 0 & 1 - \frac{1}{n} & \frac{1}{n} \\ 0 & 1 & 0 & 0 \\ 1 & 0 & 0 & 0 \end{pmatrix}; I = \begin{pmatrix} 1 \\ 0 \\ 0 \\ 0 \end{pmatrix} \)

初始分布和转移概率可以表示为高阶逻辑中的两个函数，如下所示：

### 定义 6.13

```
|- Li i = if (i = 0) then 1 else 0
|- Lt n t i j = case (i,j) of
(0, 1) -> 1 | (0, _) -> 0 | (1, 2) -> 1 - 1/n | (1, 3) -> 1/n |
(1, _) -> 0 | (2, 1) -> 1 | (2, _) -> 0 | (3, 0) -> 1 | (3, _) -> 0
```

现在，AMQM 协议中涉及的标签收集过程可以基于状态图和初始分布及转移概率矩阵，形式化为时间齐次 DTMC。

### 定义 6.14

```
|- forall X p a b c d. AMQM_MODEL X p n =
th_dtmc X p [(0, 3)], POW [(0, 3)] Li (Itr n) \land (1 \leq n)
```

在此，状态空间表示为一对，其中集合 {0, 3} 包含所有状态，POW [0,3] 是状态集合 {0, 3} 的 σ-代数，以确保该状态空间可测。Li 和 Lt n 分别表示初始分布和转移概率矩阵。变量 n 表示随机发送的标签数量。第一个条件确保模型为时间齐次 DTMC。第二个条件表示此收集过程中考虑了多个节点。通常，成功传递消息的可能路径可以表示为 \pi = (start, try, (lost, try)*, delivered)。

在此，k 表示成功消息传输所需的迭代次数。令 Pr (<> delivered i) 表示在 \( i \) 次试验内传递消息的概率，其中 \(\Diamond\) 是表示时间算子“最终”的逻辑算符。那么，达到状态 s3 的概率由以下方程给出，其中 \( n \) 表示标签数量。

\(\text{Pr } (\Diamond \text{ delivered })_i = \sum_{k=0}^{i-1} \alpha^k \beta = 1 - \left( \frac{n-1}{n} \right)^i \quad (6.10)\)

如果收集过程足够长，即 \( i \) 趋向于 \(+\infty\)，那么消息最终总是可以成功传递。因此，未来成功传递消息的概率为

\(\text{Pr } (\Diamond \text{ delivered }) = \sum_{k=0}^{\infty} \alpha^k \beta = \frac{\beta}{1-\alpha} = \frac{\frac{1}{n}}{1 - \frac{n-1}{n}} = 1 \quad (6.11)\)

现在，方程 (6.10) 和 (6.11) 中提出的两个属性可以表示为高阶逻辑中的定理 6.12 和定理 6.13。

### 定理 6.12

```
⊢ ∀ X p n i.
AMQM_MODEL X p n ⇒
sum (0, i) (λk.
P (( X2 + k * 2 = 3 ) ∩
⋂_{m=0}^{k-1} ( ( X3 + m * 2 = 1 ) ∩
{ X2 + m * 2 = 2 } ) ∩
{ X1 = 1 } ∩ ( X0 = 0 )))
= 1 - \left( \frac{n-1}{n} \right)^i
```

### 定理 6.13

```
|- ∀ X p n .
AMQM_MODEL X p n =>
lim (\X i_sum (0, 1) (\k.
prob p ({X2 + k * 2 = 3 } n \cap
\bigcap_{m=0}^{k-1} ({X3 + m * 2 = 1 } \cap
{X2 + m * 2 = 2 } ) n {X1 = 0 } n {X0 = 0 }))) = 1
```

定理 6.12 和定理 6.13 的证明主要基于定理 6.1 以及一些算术推理。

在定理 6.12 中，它对应方程 (6.10)，变量 i 指的是成功传递 n 个标签所需的试验次数。可以通过此概率评估标签收集算法的性能。定理 6.13 验证了在无限次试验中达到已送达状态的概率为 1。也就是说，如果标签收集过程足够长，最终读写器将成功接收在起始状态生成的所有标签。

## 6.7 结论

在本章中，我们提出了具有有限状态空间的 DTMC 的高阶逻辑形式化。这种形式化允许对时间齐次和时间非齐次 DTMC 进行建模。当转移概率依赖于时间时，参数 p_g 包含对时间 t 的依赖。此外，定义 6.3 中的一般状态空间 s 涵盖两种情况：无限或有限状态空间。由于时间齐次 DTMC 在许多应用中最常用，本章提供了时间齐次 DTMC 的正式定义。在 DTMC 形式化的基础上，最常用的定理（如联合概率定理、Chapman-Kolmogorov 方程和绝对概率）已在 HOL 中得到正式验证。这些定理是分析各种 DTMC 模型的基础。此外，可逆随机过程和详细平衡方程（有助于验证 DTMC 的可逆性属性）也已得到验证。我们还描述了平稳分布和平稳过程的形式化，它们是性能分析的基本概念。利用这些概念，还介绍了满足详细平衡方程的 DTMC 的两个有趣属性的正式验证。最后，为了说明目的，本章介绍了 DTMC 两个有趣应用的正式验证。
