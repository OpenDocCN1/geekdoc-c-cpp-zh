Let A be a collection of subsets (or subset class) of a space X. Now, a predicate, which is a function with an output of Boolean type, subset_class can be defined in HOL4 such that it can test whether A is a subset class of X.

# Definition 4.7

```
⊢ ∀ X A. subset_class X A = ∀ s. s ∈ A ⇒ s ⊆ X
```

A set is called countable if its elements can be counted one at a time, or in other words, if there exists a surjective function: f : N → s such that every element of the set s can be associated with a natural number. This is formalized in HOL4 as:

# Definition 4.8

```
⊢ ∀ s. countable s = ∃ f. ∀ x. x ∈ s ⇒∃ (n: num). f n = x
```

Now, a collection of subsets A (or subset class) of a space X, defines a sigma algebra on X if A contains the empty set ∅, and is closed under countable unions and complementation within the space X.

# Definition 4.9

```
⊢ ∀ X A. sigma_algebra (X, A) =
subset_class X A ∧ { } ∈ A ∧
(∀ s. s ∈ A ⇒ X \ s ∈ A) ∧ ∀ c. countable c ∧ c ⊆ A ⇒
∪ c ∈ A
```

where X\s denotes the complement of s within X and ∪c, i.e., the union of all elements of c. The pair (X, A) is called a σ-field or a measurable space and A is the set of measurable sets. Now, the space and subsets function can be defined as shown in Definitions 4.9 and 4.10.

# Definition 4.10

```
⊢ ∀ X A. space (X, A) = X
```

# Definition 4.11

```
⊢ ∀ X A. subsets (X, A) = A
```

Trivial examples of sigma algebra on a space X include the empty set, which is the smallest sigma algebra on, X and the powerset of X, P (X) which is comprised of all subsets of X and is the largest sigma algebra on X.
