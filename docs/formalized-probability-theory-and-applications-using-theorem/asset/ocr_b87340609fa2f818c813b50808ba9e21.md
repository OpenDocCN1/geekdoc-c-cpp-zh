# Definition 7.3

```
⊢ ∀ A. GCD SET A = MAXSET { r | ∀x. x ∈ A ⇒ divides r x }
```

where MAXSET is a function in the set theory of HOL4 such that MAXSET s defines the maximum element in the set s. A period of a state j is any n such that \(p_{jj}^{(n)}\) is greater than 0 and we write \(d_j = gcd \{ n : p_{jj}^{(n)} > 0 \}\) as the gcd of the set of all periods.

A state i is said to be accessible from a state j (written \(i \rightarrow j\)), if there exists a nonzero n-step transition probability of the events from state i to j. Two states i and j are called communicating states (written \(i \leftrightarrow j\)) if they are mutually accessible. A state j is an absorbing state if the one-step transition probability \(p_{jj} = 1\). The formalization of some other foundational notions of the classified states is given in Table 1.

# Table 1. Formalization of classified states

| Definition | Condition | HOL Formalization |
| :--- | :--- | :--- |
| Transient State | \(f_j < 1\) | ⊢ ∀ X p j. Transient_state X p j = ∀ x. (t 1 0 < x ∧ (∀ x n. ) # ≠ ∅) ∧ (∃ s. s < 1 ∧ (∀ n. X p j p s n) sum s) |
| Persistent State | \(f_j = 1\) | ⊢ ∀ X p j. Persistent_state X p j = ∀ x. (t 1 0 < x ∧ (∀ x n. ) # ≠ ∅) ∧ (∀ n. f X p j n) sum s = 1 |
| Persistent Nonnull State | \(f_j = 1, \mu_j < \infty\) | ⊢ ∀ X p j. Nonnull_state X p j = Persistent_state X p j ∧ sum n (λ n. n * f X p j n) |
| Persistent Null State | \(f_j = 1, \mu_j = \infty\) | ⊢ ∀ X p j. Null_state X p j = Persistent_state X p j ∧ ¬ sum n (λ n. n * f X p j n) |
| Periods of a State | \(0 < n, 0 < p_{jj}^{(n)}\) | ⊢ ∀ X p s j. Period_set X p s j = {n | 0 < n ∧ 0 < Trans X p s t n j} |
| GCD of a Period Set | \(d_j\) | ⊢ ∀ X p s j. GCD_SET (Period_set X p s j) |
| Periodic State | \(d_j > 1\) | ⊢ ∀ X p s j. Periodic_state X p s j = (1 < Period X p s j) ∧ (Period_set X p s j ≠ ∅) |
| Aperiodic State | \(d_j = 1\) | ⊢ ∀ X p s j. Aperiodic_state X p s j = (Period X p s j = 1) ∧ (Period_set X p s j ≠ ∅) |
| Accessibility | \(i \rightarrow j\) | ⊢ ∀ X p s j. Accessibility X p s j = ∀ t. ∃ n. 0 < n ∧ 0 < Trans X p s t n j |
| Communicating State | \(i \leftrightarrow j\) | ⊢ ∀ X p s i. Communicating_states X p s i j = (Accessibility X p s i j) ∧ (Accessibility X p s j i) |
| Absorbing State | \(p_{jj} = 1\) | ⊢ ∀ X p s j. Absorbing_states X p s j = (Trans X p s t 1 j j = 1) |
