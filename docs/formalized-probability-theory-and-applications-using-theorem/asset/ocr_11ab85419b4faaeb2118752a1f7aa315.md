The proof of the above theorem mainly required lemmas about the linearity of the ex- pectation property and the measurability of some events, along with some analysis on extended reals.

Now, it is possible to reason about the network coverage intensity, which we denote by Cn. According to Cn is described as the average value of the coverage intensity over all the points of the monitored area. Mathematically, Cn is specified, in Equation 13.3, as the expectation of the coverage intensity of a specific point Cp.

C_n = E[Cp] (13.3)

Based on Theorem 13.3, we can notice how the value of the coverage intensity of a specific point depends mainly on c, i.e., the number of nodes covering a given point. Assimilating the event of covering a point or not to a Bernoulli trial with the probability q, it is clear that, when we consider the variable c among the n nodes of the network, it becomes a Binomial random variable (C) with the following probability

Pr(C=j)=C_n^j (r/a)^j 1-(r/a))^{n-j} (13.4)

where C_n^j is the binomial coeecient, r is the size of the sensing area of each sensor, a is the size of the monitored area, and (r/a) is the probability that each sensor covers a given point. The Binomial random variable with n trials and success probability q = r has been formalized as follows:
