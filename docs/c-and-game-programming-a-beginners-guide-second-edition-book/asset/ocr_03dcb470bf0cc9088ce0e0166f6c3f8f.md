When inserting the dot operator, visual compiler users may encounter a popup window resembling Screen Shot 5.1. This window is generally used as a reminder indicating to the programmer that certain fields are available. If a certain item is not present, this may indicate that it was coded incorrectly or that a certain reference is missing or incomplete. A padlock symbol indicates a protected or private member/field.

# Example 5.3. Declaring and assigning multiple instances.

```
using System;

namespace Chapter5 {
    struct BankAccount {
        public string first_name;
        public string last_name;
        public long account_number;
        public decimal checking;
        public decimal savings;
        public short pin_number;
    }

    class Class1 {
        static void Main () {
            BankAccount account1, account2;

            account1.pin_number = 2001;
            account1.account_number = 43297;
            account1.first_name = "John";
            account1.last_name = "Doe";
            account1.savings = 0;
            account1.checking = 112.53M;
        }
    }
}
```
