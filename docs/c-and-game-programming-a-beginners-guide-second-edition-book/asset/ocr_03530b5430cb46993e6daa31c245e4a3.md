# Pointers as Arrays: The Keyword stackalloc

We can manipulate pointers to include a basic value type array (this is equivalent to the standard C++ stackable array). To do so, we'll also have to call on the stack allocating command, stackalloc. Stack allocated arrays are limited to only one dimension and are generally written with the pointer reference replacing reference of the array's square brackets: for example, int* our_pointer = stackalloc int [array_size]; (see Example 4.34).
