# Table 2.4. Using Conversion specifiers with printf () and scanf ().

Two interesting command functions that continue to evolve through the C languages are the old style and member functions puts and gets. The original puts was accessed in essentially the same manner as printf, but with the restriction that it could only display character data (as in puts("this is a test 1, 2, 3."). Gets, like scanf, was also used to read data, but everything read is interpreted as a character string. This can also be thought of as an array (which we'll discuss in Chapter 4). The extended member function versions of these two types are unfortunately limited to only single character references as in cout.puts ('A') and cin.get (character), so their practicality is limited. Two alternative replacements for these older style functions are cin.getline (characters, sizeofline) and cout.write (characters, sizeofline). These will also be explained in Chapter 4 (see Example 2.23). Note that while the puts function automatically moves data to the next line, cout.write does not.
