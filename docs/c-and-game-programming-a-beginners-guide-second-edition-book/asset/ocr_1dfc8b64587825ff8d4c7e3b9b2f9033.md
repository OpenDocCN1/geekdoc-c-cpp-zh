Note that this termination sequence is actually only the keyword break, which does nothing more than move us out of a block and onto the next segment. break, like case, is repeated for each comparison.

C# also requires a break statement, which prevents the falling through of case values. You can, however, include multiple case statements, just as long as they do not contain executable statements.
