+   8. If all aliens are destroyed, a new set of ships will appear at the top.
+   9. The destruction of the aliens' ships will be scored and the scores will be saved to a file that keeps high scores.
+   10. The aliens' point values will be from lower (forward ships) to higher (rear ships).
+   11. The aliens will move faster as their numbers dwindle.
+   12. The aliens will also occasionally fire at random.
