# Exception Handling

Another feature that adds sophistication to our programs is the ability to catch exception errors. Exception errors are errors thrown by a program/Windows during execution, and can range from simple input errors to problems such as missing files, division by zero, etc. All questionable coding is placed inside of what is known as a try block, which is a block of coding that may or may not succeed. If this coding does fail, the program immediately turns to a catch block (or an assortment of catch blocks), which can be either general or specific. Upon completion of either the try or the catch block, a tertiary block is executed, known as the final or finally block, which is always executed upon the termination of try and catch blocks (see Examples 5.40 and 5.41).
