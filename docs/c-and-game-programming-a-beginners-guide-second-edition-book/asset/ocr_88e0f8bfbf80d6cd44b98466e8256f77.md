The movements for these characters will be simple, with one key set aside as a thrust and two others to turn the crafts to alternate sides (see Example 3.41). We'll continue to use the arrow keys and the numeric keypad for movements. The left and right arrows will adjust the direction of the vessel, and the upward arrow key will be the thrust. The downward arrow key will revive the characters and send the ships into hyperspace, and the zero key will fire weapons. For Player Two, <Q> turns left; <A> turns right; <X> thrusts; <S> sends the ship to hyperspace, and the spacebar fires weapons. The angles of motions are shown in Example 3.41.
