# References, Values, and the Boxing Technique

In addition to being able to convert between the standard types, we can also apply these techniques to include both value to reference and reference to value conversions. This process is most commonly referred to as *boxing*, with the term *unboxing* denoting the return of those values to their original state. The process follows the same steps used for basic type casting, but with an added note of caution when attempting to return or unbox our values: They can return to new variables, but those variables must be of the same type as the original boxed data. The conversions are made using the keyword `object`, as shown in Example 2.31.
