# Incrementing and Decrementing Operators

The incrementing (++) and decrementing (--) operators increase and decrease their variables by one numeric value, respectively. This holds true for all numeric data types, including the standard integer, floating point, or decimal references (character information is handled differently). The operators can be used in either postfix mode (x++) or prefix mode (++x). Prefix mode refers to a calculation that must occur before a variable is accessed by a secondary equation, whereas postfix mode allows for that variable to be read, equated, and then altered after the completion of the equation. There are, of course, advantages to each type, and the latter explains the pun C++. Use Example 1.44 to test these operators. You should revise the example using several of the other numeric data types, as well as both postfix and prefix modes.
