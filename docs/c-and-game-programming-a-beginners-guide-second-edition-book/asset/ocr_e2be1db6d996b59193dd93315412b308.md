Once a value exceeds that range, its variable reference no longer produces the implied response, thus that program is considered corrupt and all its data considered invalid. To protect against such errors, the designers of C# implemented two options: first, we can include coding references such as the keywords checked and unchecked; second, we can include a generalized compiler reference that tests our code for us. To implement these references see Examples 4.38–4.30 and Screen Shot 4.5.
