# Force Feedback Controls

The basic joystick controls for Battle Wave are actually much simpler then the code used to control Space Fighter and Asteroid Miner. That's because Battle Wave only requires lateral movement. This, however, affords us the opportunity to test the more advanced features included with Force Feedback. Here we'll imagine that each explosion creates a ripple in space causing a quake-like effect that affects our characters' ability to move. The most important thing to remember about Force Feedback is that it requires exclusive device access (see Example 4.48b).
