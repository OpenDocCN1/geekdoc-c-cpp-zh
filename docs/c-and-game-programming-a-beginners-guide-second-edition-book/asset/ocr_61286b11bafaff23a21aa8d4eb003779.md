# # Manipulating String Data

Another significant aspect of manipulating string data comes from the use of the *string extensions*. These are methods included in the Base Class Library that make many of the older string manipulations obsolete. A few of the basic references include commands that test, alter, and apply to both strings and their literal counterparts. The use of these string manipulators has found its way through both C ("string.h") and C++ ("cstring"), with these newly defined methods giving the clearest representation yet (see Table 4.1).
