# # Changing Levels

Another key aspect to creating a multilevel game is to include a level changing or resetting method. In this case, we'll also want to use this method to demonstrate DirectSound's 3D and special effect features explained in the last few sections. The NextLevel method uses a for-loop to reactivate all target creators. The NextLevel method is referenced as part of a time based comparison (see Examples 4.60 and 4.61).
