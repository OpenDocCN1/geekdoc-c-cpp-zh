# Writing Games

Next, we’ll have to develop our idea using a list of thoughts usually expanding in phases and always increasing in detail. As we progress, we’ll also want to turn this list into a formal document, or algorithm. This algorithm could then be enhanced both logically and pictorially through the use of mathematical and graphical designs.
