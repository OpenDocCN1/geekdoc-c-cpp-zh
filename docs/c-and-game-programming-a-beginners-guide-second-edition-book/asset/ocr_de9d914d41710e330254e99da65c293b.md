# Adding Sounds Using DirectSound

DirectSound is the DirectX alternative to using Windows Multimedia to produce sound. Here we’ll mimic the initial steps used to include DirectDraw and Input e.g., adding a namespace, including variables, setting a cooperation level, etc. However, rather than creating a single DirectSound function (as compared to `OnPaint`, `Keyboard_Tick`, etc.), we’ll apply our techniques as part of our gaming model. DirectSound has two types of buffers used to hold audio data; the stock `Buffer` object and its derivative the `SecondaryBuffer` object (see Example 3.28/Complete code listed on CD-ROM Example 3.28).
