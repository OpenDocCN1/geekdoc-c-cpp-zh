# Inheriting from Player.cs—PlayerImageArray.cs

Remember that while C# does not allow for multiple inheritances, it does allow for single inheritance in a chain of subclasses. Thus, PlayerImageArray.cs can inherit from Player.cs both the properties of Player.cs and AnimatedImage.cs. PlayerImageArray was designed for use with an array of images. A method to load the images is required, as well as notation to indicate the position of the image (see Example 5.69 and PlayerImageArray.cs on the CD-ROM).
