# Controlling the Serve

First, we’ll need to develop a random number generator that sets the initial path of our projectile (the ball). Second, we’ll need to keep track of the projectile’s location and set up scenarios that allow for the ball to switch sides. For convenience, we’ll also want to bundle these procedures into a simple function (see Example 3.25).

# Example 3.25. Controlling the serve.

```
```java
public void Serve() {
    if (!theBall.isActive) {
        theBall.isActive = true;
        HitTheBall();

        if (theBall.direction == AnimatedImage.EAST ||
            theBall.direction == AnimatedImage.NORTHEAST ||
            theBall.direction == AnimatedImage.SOUTHEAST) {
            theBall.imagePosX = playerL.imagePosX + playerL.imageWidth + 1;
            theBall.imagePosY = playerL.imagePosY;
        } else {
            theBall.imagePosX = playerR.imagePosX - theBall.imageWidth;
            theBall.imagePosY = playerR.imagePosY;
        }
    }
}
