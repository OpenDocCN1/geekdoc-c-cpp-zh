# The void Pointer

The *void* data type can be used to declare generalized pointers, that is, pointers that do not, as yet, have a set data type. These all-purpose pointers can be reassigned to different data types with each function call or as part of an abstract subroutine. void pointers can be converted to any of the other data types and can be used as a sort of template, always changing to fit the needs of a program (see Example 4.31).
