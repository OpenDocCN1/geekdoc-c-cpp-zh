# User-Defined Exception Classes

Occasionally, we'll want to define our own exception classes. These are special case exceptions that may require additional information and/or input. An exception class is an inherited class that is derived (either directly or indirectly) from a key base class (namely System.ApplicationException). In all other respects, an exception class mimics the rules of a standard inherited class (see Example 5.44).
