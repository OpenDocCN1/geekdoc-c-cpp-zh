# Overloading Comparison Operators

Another important type of overloading involves the use of the comparison operators. Here, we'll want to use the Boolean data type with our choice of constants, variables, and object references. We'll also need to include matching comparisons, like greater than and less than symbols, for each overload (see Example 5.29).

# Example 5.29. Overloading comparison operators.

```
using System;

namespace Chapter5 {
    class Objects {
        int Number;

        // Constructor
        public Objects(int Value) {
            this.Number = Value;
        }

        public static bool operator>(Objects One, Objects Two) {
            return(One.Number > Two.Number);
        }

        public static bool operator<(Objects One, Objects Two) {
            return(One.Number < Two.Number);
        }
```
