# Structures as Function Arguments: Calls-by-Reference

Next, we will pass fields using a call-by-reference procedure. Call-by-reference procedures are, simply put, limited pointer values. Any alterations in the passed variable’s values now alter the member’s stored values. These, like their variable counterparts, are also referenced with the keywords `ref` and `out` as shown below (see Example 5.7).

# Example 5.7. Calls-by-reference with structures.
