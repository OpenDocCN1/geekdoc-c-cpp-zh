# ## Drawing Characters

It is important to remember that DirectX requires our graphic files to be stored as bitmaps, and that, while Forms can also use bitmaps, most Windows' Forms programmers prefer to use the lower-resolution graphic file formats such as JPEGs to save resources. It is also important to remember that these distinctions are merely a matter of storage type and that they do not affect the steps used to draw our images. This text's CD-ROM, for example, includes both .JPG and .BMP images, which were created as bitmaps and then resaved under the JPEG format.

Our initial designs included only seven unique drawings, the four target images (each reproduced five times using multiple colors), the target weapons/bombs (also reproduced using multiple colors), and the single human image, as well as his two rockets/missiles. The four alien images include Bulb, Frog, Robot, and Eye, with the Human playfully being referred to as Gus (see Game 4 Designs).
