
One practical reason for using the goto statement in C#, which is to allow for artificial drops when dealing with switch statements. Remember, C# no longer allows us to drop between switch statements that contain executable statements, so goto makes a good fix. C#’s goto also has some limitations, including not being able to jump into localized blocks, between classes, and it can’t (and shouldn’t) be used to alter try-catch blocks, as explained in Chapter 5 (see Example 4.41).

                        goto case3;
