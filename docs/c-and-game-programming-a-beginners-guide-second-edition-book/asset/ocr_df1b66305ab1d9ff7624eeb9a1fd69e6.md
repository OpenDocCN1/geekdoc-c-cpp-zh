To load and use the source code that accompanies this book:

+   1. Create a new directory and/or subdirectory. This will be used to store the programs from the CD-ROM and the programs you create on your own. Name your folder and note where you place it (in the C drive, D drive, etc.), including which subdirectory and/or subdirectories you chose to place it under. If you use the default, you’ll more than likely find your lost files under: `C:\\Documents and settings\\YourUserName\\My Documents\\Visual Studio Projects\\ProjectsNameHere`.
+   2. Make sure your compiler is installed and working properly.
+   3. Load and make active the C# compiler. Close any and all nonessential windows (this includes the C# tour box). Closing unnecessary background programs will also help to speed up your system.
+   4. Insert the CD-ROM into the appropriate drive.
+   5. Select “Open” from the C# compiler’s file menu (see Screen Shot 1).

![](bbox=[0.269, 0.444, 0.724, 0.719])

+   6. From the “Open” Windows menu, select the folder titled “Source” and then the appropriate subfolder(s). The subfolder titled “MSNET” contains all of the source code for the Microsoft .Net compiler(s)² (see Screen Shots 2 and 3).
