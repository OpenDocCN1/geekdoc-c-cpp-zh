```
static void function(ref decimal balance) {
    decimal input;
    Console.WriteLine("Your current balance: {0}", balance);
    Console.WriteLine("Amount to deposit: ");
    input = decimal.Parse(Console.ReadLine());
    balance = balance + input;
}
```

# # Passing Entire Structures

In addition to being able to pass single structural members, we can also pass an entire structure using a call-by-value or call-by-reference procedure. In both cases, the reasoning for doing so would involve the increased portability and reusability of such generalized user-defined functions (see Examples 5.8 and 5.9).

# ### Example 5.8. Calls-by-value for entire structures.

```
using System;

namespace Chapter5 {

        public long account_number;
        public decimal checking;

    class Class1 {

            account.account_number = 43297;
            account.first_name = "John";

            account.savings = 100.00M;
            account.checking = 112.53M;
            function(account);
            function(account);
        }
    }
}
```
