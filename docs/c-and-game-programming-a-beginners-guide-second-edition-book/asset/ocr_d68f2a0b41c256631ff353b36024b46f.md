# ### The get and set Accessors

The get and set accessors aren't officially keywords, rather, they are parameterless methods named to match certain fields, and are used in classes and interfaces that hold a body of executable data pertaining to the storage and retrieval of those fields. Their executable statements may include calculations, conversions, and a large host of other tasks, but their underlying purpose must include reading or recording those properties. The body of an accessor is considered equivalent to a method, although they do not include identity signatures. The get accessor returns a value and may be set to throw a value when needed; in contrast, the set accessor is always set to void. The keyword value is also used as an implicit parameter when setting our fields. Thus, value takes on the value of any passed variables.
