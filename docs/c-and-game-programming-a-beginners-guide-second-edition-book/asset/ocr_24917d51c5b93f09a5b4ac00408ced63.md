# Displaying

The standard image display is simple, having just three steps: 1) a Graphics declaration, for which we’ll use the letter g; 2) the method DrawImage, which is included in the drawing Class accessed through g, as in g.DrawImage; and 3) the signatures for the DrawImage reference, e.g., the character’s actual image, an x-coordinate, a y-coordinate, its width, and its height. Note that the variables listed are actually the fields declared at the top part of the class (see AnimatedImage.cs on the CD-ROM and Example 3.46 in Chapter 3).

# Rescaling Images

As seen in the last section, the heights and the widths of our images play an important role in their display.
