```c
#include <stdio.h>

int main()
{
    int a;
```

我简要介绍了`if`语句在上述代码中的工作方式。大多数情况下，`if`语句的格式与我们之后要处理的其他语句略有不同。它通常会被拆分成至少两行：第一行包含用圆括号括起来的条件；如果该条件评估为真，则执行下一行的内容。本质上这是一个被分到两行的单一语句，因此分号会位于第二部分的末尾而非第一部分之后。

你当然也可以将整个 `if` 语句写在一行内（如果你愿意），但这不符合常见的编程惯例；通常将代码拆分至多行并用花括号括起来更容易阅读。

你也可以在代码中包含多个 `if` 语句来实现更复杂的逻辑——根据你所设定的条件和用户输入触发不同的动作。下面是一个很好的示例：

```c
#include <stdio.h>

int main();
{
    int a;
    
    printf("Type an integer: ");
    scanf("%d", &a);
    
    if(a > 10)
        {
            printf("%d is greater than \n" ,a);
        }
        
     if(a < 10)
         {
             printf ("%d is lesser than \n" ,a);  
          }

return(0);

}
```

在这个示例中我们可以看到两个相邻的比较操作：各自都有自己的花括号块并分别检查大于和小于的情况.请试着编译运行这段程序.

当你运行后就会发现它会根据你的输入显示相应结果 -- 对比十大的数或比十小的数字给出提示;但注意这里当我们精确键入数值等于字段变换时没有任何输出,你可以修改第 16 行为 "less than or equal to ten ",从而让等情形也能得到回应 。

## `else if` 语句（多重选择）

遇到超过两个及以上的条件，同时需要测试三种以上可能因素时，玩家就可以考虑另起炉灶使用另一种结构，又称`else if`阶梯组合。快速浏览以下代码示例，演示其运作原理：

```c
#include <stdio.h>

main()
{
    char option = getChar();
    switch (option) {
        case 'y': /* ... */
        default: break;
    }
}
```

主要成分均安放在`switch/case`框架之内，开始于列排版序列，依次枚举各类情景。每个分支携带专属任务以及结尾反闸收场，这几部分共同合成整体控制流骨干元素。

也许你已经察觉到关键词`break`出现在其中，于是总共有四个核心成员，即`case`、`default`、`switch`和`break`。把它们粘贴到编辑环境中运行几遍，选取各种选项，查验定义是否正确无误，并观察最终输出结果。

具体如何执行？`switch`针对单值开展判别，而不像过去那样进行全量对比。它可以容纳数学公式，只要最后落回到一个独立元素即可。由规定变量所做的值与每条`case`后方的标样逐项匹配，当算法发现一致时，就会激发对应分区的内容；不属于命中区域的则全部忽略不计。举例而言，假使应答者在第十二列填写`1`，那么第十三列的`puts`例程火速启动，其余章节不再问津；反之，要是输入`2`，制式首条子区间跳过，继而寻求第二个目标，直至相逢触点为止。如果在任何相符节点失联，默认缺省处理器搭载——在范例条件下，例如填写`4`，它将直抵预设置区，照步就班履行其职司。

你可以将这种方法用于任何允许用户输入内容的代码，例如菜单功能。这能为用户提供一些选项，你就能教会代码如何根据用户给出的答案或输入来进行交互。只要他们给出的答案在你的`switch`语句所允许的范围内，就能看到你设定的正确反馈。

## 第 4 章：在 C 语言中使用循环

循环是你在 C 语言代码中可以添加的一个很有用的东西。它们能让你创建列表、甚至是图表等结构嵌入到代码中。很酷的一点是，只需几行代码，你就可以得到一个巨大的图表，而不必逐行敲入每一条所需的指令。

举个例子，如果你想要生成一张从`1`排到`100`的图示，手动逐一写出每一行会非常低效；但利用合适的循环语句，就只需要写很少的代码段即可完成。

因为要比较多重数值，运算可能会令人感到困惑，但有多种选择，真能增加程序的威力。比如说`while`循环、嵌套循环、直到型（`do...while`）以及`for`循环——本章将重点解析这些内容。

### `while`（当型）循环

一个循环是重复执行控制的迭代操作。我们需要明确条件，让它重复执行下面的语句，直到满足停止条件为止；否则程序会持续运行导致机器锁死。所以我们得把这个条件添加到循环的开头或者结束位置。

下面是一段示例，展示从`20`开始计数的循环：

```c
#include <stdio.h>

int main()
{
    int x;

    while (x < 20 && x != 10) {
        printf("%d\n", x);
        x++;
    }
        else if(cond != condition)
            printf("something");
}
```

在这里，他打印别的东西然后结束并运行该程序。

代替枚举多个条件，我们利用循环这一结构。其中第八句话的含义是：“小于且不等于十”。因此只要条件成立，程序就会无限制地继续执行，直至变量观察到`13`时退出。注意，完成每个循环后，增量步骤`++`启动，以此确保循环能够跳出。最终输出显示数字，而不是都堆叠在一起。

对基准程序修改，扩展计数到二十方，仅需修改目标数，同时保留运算符（如起始点）。类似地调整增减，改为因子`2`或`5`，便能快捷完成案例——大体段落保持不变，因篇幅约束省略细节叙述。

### `do/while`（直到型，先做再判断）

另一种选择是`do...while`，它包含与`while`刚相反的版本。正常而言，任一语句以`do`开头——率先尝试执行验证需求，需要单个起始匹配。故下方示例说明`do-while`的构筑机制：

```c
/* 实际标注为 C 编译环境独占实现 */
#include <stdio.h>

int main()
{
    char ch;
    ch = 'a'; // 确保使用单引号半角

    do {
        putchar(ch);
        ch++;
    } while (ch != 'z');

    putchar('\n'); // 换行符号转义表示
    return (0);
}
```

请注意次序：始自`do`（第 9 行参数）后再检查条件（第 14 行）。依赖初始变量`ch`设定于第七行，准备好偶遇分号时的差异。这与常规表述适当防止无限循环；断开控制台测试，编译运行即可直观察觉结果，避免末字漏跳出。除非修改偏移量使其包含警告，未保存不一致的注释目前；所以建议将模块拆分，后续深入学习，全面掌握连续均较熟练的关联词汇，顺利推进学习进程。

### 多重处理的定式

初学者在解决问题时，可能会无意中引入意外行为。特此演示`break`在无条件环形中的首次迭代结束后安全停止的功能：

```c
#include <stdio.h>

int main()
{
    while (1) {
        printf("ir\n");
        break;
    }
    return (0);
}
```

应用到更变化的环境中，新编写程序编译运行，出现一次输出后即停止。凭此对比两种循环的区别，决定使用哪种方式，根据实际情况灵活选择。

这两类循环定位极其相似，主要差别在于测定时机先后。按照规则配对实行对应流程，借助成败裁断亦可灵活应对；保证最小必要次数，熟练选择运用，心中明了微小的差异也能带来高效收益。深入理解并实践，提高知识素养，为后续学习积累经验。

### `for` 关键字

`for`关键字是构建紧凑循环结构的强有力手段。虽然初学时可能觉得有些晦涩，但它已习以为常，是典型的传统结构。请看示例：

```c
#include <stdio.h>

int main()
{
    int i;
    for (i = 0; i < 10; i++) {
        printf("%d\n", i);
    }
    return (0);
}
```

该结构包含三部分：初始设定（如`i = 0`）、运行条件判断（如`i < 10`）、每次迭代后的更新（如`i++`）。只要条件满足，循环就继续执行；一旦条件不满足，则终止循环。通过调整起始值、结束条件和步长，可以灵活生成各种序列。

### 嵌套循环

`for`循环对于简化代码编写非常有用，尤其是在处理嵌套循环时。嵌套循环一开始可能听起来很复杂，但它比`while`循环更容易使用。让我们通过以下代码来看看如何处理嵌套循环：

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main()
{
    int column, r;
    srand((unsigned)time(NULL)); /* 初始化随机数生成器 */

    for (column = 0; column < 10; column++)
    {
        r = rand();
        printf("%2d\t", r % 100);
    }
    putchar('\n');

    return (0);
}
```

上面给出的代码将输出十个随机选择的数字。花点时间编译并运行这段代码，你会在输出中看到一行十个随机选择的值。这些值之间的间距是通过我们在第 14 行使用的制表符（`'\t'`）实现的。

这只是你可以用循环类型完成的一个例子；你还可以用它来生成从`1`到`100`（或更多）的数字网格等，添加到你需要的图形中去——这比自己单独写出每个部分要快得多，并且最终结果也很好。

## 第 5 章：C 语言中的变量

正如之前提到过的，“变量”是存放各种数据类型的容器。这个容器可以保存浮点数、字符型整数或者其他类型的数值。本章将更深入地讲解有关变量的知识，以及如何在编程中对它们进行使用和实际工作原理。

**那么如何区分“值”（`values`）和“变量”（`variables`）呢？**

几乎所有在程序内部的东西，例如一整串字符串，或者是在其定义范围内的数据，都可以称为`value`，这是一种形式概念。而作为对应的容器，用于装不同类型值的媒介名称统一叫作`variable`（变量）。通常，变量之间需要保证相互之间具有某些联系，但并不要求完全相同。举例来说，我们可以拥有包含铅笔、钢笔、纸张、粉笔、本子等文具用品的一个参数列表，这些都是相似物质组合，有对应关联的逻辑思维，但内容并不完全等同。

当我们要声明某个具体的`variable`时，语句中的内容包括所属类别（类型）和名字两部分。

下面是一个简单整数的初始化过程示例：

```c
#include <stdio.h>

int main()
{
    int a;

    printf("The value of A is %d\n", a);

    return (0);
}
```

在上述示例中，虽然未曾赋值，但这个`a`依然使我们可以在第七行引用该元素。尽管未明确赋值，但编译器依然允许如此使用，因为该元素在内存中有个临时分配的空间。运行时表现出的行为根据不同编译器设置，可能会显示出一些意想不到的结果。

要知道，不同于其他许多高级脚本性质的环境，C 语言并不会自动默认将未初始化的变量设置为`0`。它保留的是内存中先前存留的残余状态内容（即内存位置未被清零）。所以务必主动预先赋值后再使用，否则会沿袭历史遗留存量，直接反映出来。好的做法是像下面修正的代码块所示：

```c
#include <stdio.h>

int main()
{
    int b;

    b = 65;

    printf("B -> %d\n", b);

    return (0);
}
```

保存并修改文件，重新编译运行，就会发现输出不再是未知幻影，因为此刻我们确切知道变量的值。

除了变量名，`sizeof`运算符也可以获取此核心语法内的详细信息——比如字节占用的计数。

`sizeof`关键字既属于保留词，同时也是运算符，用于反馈指定对象所需的内存大小。以下是一个运用它得到预期目标的示例：

```c
#include <stdio.h>

int main()
{
    char a;
    int b;

    printf("Size of char: %lu bytes\n", sizeof(a));
    printf("Size of int: %lu bytes\n", sizeof(b));

    return (0);
}
```

### 获取变量的存储位置

我们可以通过取地址运算符（`&`）获取变量的存储位置。这在调试程序或进行指针操作时非常有用。

例如：

```c
#include <stdio.h>

int main()
{
    int a = 10;

    printf("Value of a: %d\n", a);
    printf("Address of a: %p\n", (void*)&a);

    return (0);
}
```

变量在内存中的具体地址会因平台、操作系统版本以及用户终端可用资源的不同而有所差异，但灵活掌握变量的存储位置有助于我们更好地理解程序的运行机制。

## 第 6 章：C 语言函数详解

C 语言库中包含了许多可供使用的函数，它们能帮助你完成相当多的任务。尽管如此，它们并不能处理所有事情。有时你需要用这种语言创建自己的函数。事实上，许多有经验的 C 程序员都编写过大量自定义函数来确保代码正常工作。

本章将详细讨论函数的各个方面：如何设置一个函数、如何进行原型声明、如何调用或访问一个函数，甚至在需要时如何提前退出程序。

在 C 语言中，每个`function`都有类型（`type`）、名称（`name`）和圆括号内的参数列表（`arguments`）。名称必须是唯一的，用于标识你所使用的那个`function`。参数是零个、一个或多个传递给该`function`的值，它们被称为输入（`input`）。

以下是一个名为`alpha`的函数——它是没有入参也没有返回值的；这在 C 中是合法有效的写法，此类函数叫作空类型（`void`）：

```c
void alpha(void)
```

这里的`void`（空白）作为函数的返回类型，基本上就是告诉编译器说这里不需要返回具体的值。至于`count`（计数），这是个整型操作单元，它会生成并返回一个整数结果。它与刚才不同之处在于：它需要接收数据（参数），但不携带任何形参列表。所以它的声明就成了：

```c
int count(void)
```

还有一个可用的函数是`hangup`（挂断），它完全不返回值，故亦为典型的`void`类型实用案例。但差异就在于，它允许接受单个字符作为输入参数；而且你可以自己选择那个字母当作实际参数。在这门技术环境下，它会被分别对应到`ch`这个变量上。然而，不论你是何种形式，都要先介绍给编译器认识，以便它可以检查函数调用时条件是否被正确使用。

当你想要唤醒并调用某个子过程时，只需要写出它的名字，并添加一对小括号即可。一旦这样做了，当前控制权就会转交给那段语句序列。等全部执行完后，程序便继续紧随其后的那句代码继续执行。下面我们就快速浏览怎样把这些方法嵌入源码中。

下列示例包含两个`utils`，它们相互配合以解决问题：

```c
#include <stdio.h>

void blorf(void);

int main()
{
    puts("The main() function always runs first");
    blorf();
    puts("Thanks, blorf()");

    return(0);
}
```

主函数（`main`）仍然是整个程序最关键的部分。此外，注意到名为`blorf`的新模块出现了。在第 3 行，我们为它创建了一个原型（`prototype`），告诉编译器有关该函数的参数形式及返回类型信息。这样即便还没正式实现，编译器也能依据原型来检查调用格式是否正确。又因为原型声明属于完整语句，所以在结尾处需要加上分号。

后来，在第八行代码中，我们调用了`blorf`函数。由于这个子例程没有参数，因此括号内保持为空。这样的例程不会在定义之前被调用，直到越过第 14 行定义的部分才被激活。定义中的代码都会包含在大括号内。现在暂停片刻，赶紧编译并运行这个程序看看实际效果。

若想再次调用同一个对象，该怎么办？很简单，复制第 8 行的调用并在其后再黏贴一行即可。改动后的代码类似：

```c
#include <stdio.h>

void blorf(void);

int main()
{
    puts("The main() function always runs first");
    blorf();
    blorf(); /* 调用两次 */

    puts("Thanks, blorf()");

    return(0);
}
```

保存代码并重新编译运行，会发现`blorf`函数的内容被打印了两次。

原型声明（`prototype`）无论出现在何处，都类似于为函数所做的声明，预先告知编译器该函数将来的调用方式和参数类型。有些场景下其实并不需要显式写出原型，那就是当你在真正调用函数之前已经编写完整函数的定义时。下面是一个完整的示例，演示这种运作方式：

```c

void soup(void)
{

}

int main()
{

    soup();
    return (0);
```
