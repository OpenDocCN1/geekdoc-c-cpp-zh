You might not have encountered many library functions in this method, so let’s go over them briefly. The StackTrace class gets the name of the calling method using Reflection. It’s rather expensive, but it greatly simplifies tasks, such as generating information about program flow. Here, it determines the name of the method called CheckState. There is a minor risk here if the calling method is inlined, but the alternative is to have each method that calls CheckState() pass in the method name using MethodBase.GetCurrentMethod(). You’ll see shortly why I decided against that strategy.
