# Chapter 19

The recordset class and the record view class cooperate to enable data to be transferred between the database and the controls in the dialog box. The CProductSet class handles transfers between the database and its data members and CProductView deals with transfers between the data members of CProductSet and the controls in the dialog.

# Sorting a Recordset

As you saw earlier, the data is retrieved from the database by the recordset, using an SQL SELECT statement that is generated by the framework using the GetDefaultSQL() member. You can add an ORDER BY clause to the statement generated by setting a value in the m_strSort member of CProductSet, which is inherited from CRecordSet. This causes the output table from the query to be sorted, based on the string stored in m_strSort. You need to set only the m_strSort member to a string that contains the field name or names that you want to sort on; the framework provides the ORDER BY keywords.
