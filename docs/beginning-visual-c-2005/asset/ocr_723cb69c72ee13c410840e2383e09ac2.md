```
CBrush* pOldBrush = (CBrush*)pDC->SelectStockObject(NULL_BRUSH);

// Now draw the circle
pDC->Ellipse(m_EnclosingRect);

pDC->SelectObject(pOldPen);            // Restore the old pen
pDC->SelectObject(pOldBrush);          // Restore the old brush
}
```

After selecting a pen of the appropriate color and a null brush, the circle is drawn by calling the Ellipse() function. The only argument is a CRect object that encloses the circle you draw. This is another example of code that’s almost for free because it’s similar to the code you wrote earlier to draw a rectangle.
