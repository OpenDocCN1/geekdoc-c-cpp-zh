# C++/CLI Keywords

The C++/CLI language specification defines the following keywords in addition to those defined for ISO/ANSI C++:

| enum class | enum struct | for each | gcnew |
| --- | --- | --- | --- |
| interface class | interface struct | nullptr | ref class |
| ref struct | value class | value struct |

Note that the word pairs are keywords, not necessarily the individual words; for example, for each is a keyword, but each is not.

The C++/CLI language also defines a number of identifiers that are not keywords but have a context-sensitive meaning in some circumstances. These are:
