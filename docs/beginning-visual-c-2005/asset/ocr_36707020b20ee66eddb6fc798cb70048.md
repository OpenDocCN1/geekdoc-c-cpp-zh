# Drawing in a Window

```
```cpp
void CSketchView::OnDraw(CDC* pDC)
{
	CSketchDoc* pDoc = GetDocument();
	ASSERT_VALID(pDoc);
	if(!pDoc)
		return;
	pDC->MoveTo(50,50); // Set the current position
	pDC->LineTo(50,200); // Draw a vertical line down 150 units
	pDC->LineTo(150,200); // Draw a horizontal line right 100 units
	pDC->LineTo(50,50); // Draw a vertical line up 150 units
	pDC->LineTo(50,50); // Draw a horizontal line left 100 units
}
```
```

If you plug this into the Sketcher program and execute it, it displays the document window shown in Figure 14-5.

![](bbox=[0.05, 0.48, 0.95, 0.78])

The four calls to the LineTo() function draw the rectangle shown counterclock wise, starting with the upper-left corner. The first call uses the current position set by the MoveTo() function; the succeeding calls use the current position set by the previous LineTo() function call. You can use this to draw any figure consisting of a sequence of lines, each connected to the previous line. Of course, you are also free to use MoveTo() to change the current position at any time.
