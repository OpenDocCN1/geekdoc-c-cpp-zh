# Communicating with Windows

As you saw in Chapter 11, Windows communicates with your program by sending messages to it. Most of the drudgery of message handling is taken care of by MFC, so you don’t have to worry about providing aWndProc() function at all. MFC enables you to provide functions to handle the individual messages that you’re interested in and to ignore the rest. These functions are referred to as message handlers or just handlers. Because your application is MFC-based, a message handler is always a member function of one of your application’s classes.
