# # Drawing in a Window

If you take a look at the end of the code for the CSketchView class definition, you’ll see that three function declarations have been added:

```
```
protected:
DECLARE_MESSAGE_MAP()
public:
afx_msg void OnLButtonDown(UINT nFlags, CPoint point);
afx_msg void OnLButtonUp(UINT nFlags, CPoint point);
afx_msg void OnMouseMove(UINT nFlags, CPoint point);
};```
```

These identify the functions that you added as message handlers.

Now you have an understanding of the information passed to the message handlers you have created, you can start adding your own code to make them do what you want.



For the WM_LBUTTONDOWN message, you want to record the cursor position as the first point defining an element. We also want to record the position of the cursor after a mouse move. The obvious place to store these is in the CSketchView class, so you can add data members to the class for these. Right-click the CSketchView class name in Class View and select Add > Add Variable from the pop-up. You’ll then be able to add details of the variable to be added to the class, as Figure 14-12 shows.
