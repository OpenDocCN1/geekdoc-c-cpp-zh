# Creating an Element

You should add the CreateElement() function as a protected member to the ‘Operations’ section of the CSketcherView class:

```
class CSketcherView: public CView
{
    // Rest of the class definition as before...
    // Operations
    public:
    protected:
        CElement* CreateElement(void);    // Create a new element on the heap
    // Rest of the class definition as before...
};
```

To do this you can either amend the class definition directly by adding the shaded line, or you can right-click on the class name, CSketcherView, in Class View, and select Add > Add Function from the context menu. This opens the dialog shown in Figure 14-19.
