This class is derived from CFrameWnd, which provides most of the functionality required for our application frame window. The derived class includes two protected data members, m_wndStatusBar and m_wndToolBar, that are instances of the MFC classes CStatusBar and CToolBar respectively. These objects create and manage the status bar that appears at the bottom of the application window, and the toolbar that provides buttons to access standard menu functions.
