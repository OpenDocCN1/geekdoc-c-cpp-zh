# Adding Rows to a Table

Extend the example to implement the capability to add a new order to the Northwind database. This provides insight into some of the practical problems and complexities you will face in this kind of operation.

An order itself is not a simple record in a table in the Northwind database. Two tables are involved in defining a new order. The basic order data is in the Orders table, where information about the customer is stored. For each order, there is one or more records in the Order Details table and one for each product in the order, the link to the record in the Orders table being the Order ID.
