```cpp
// CLine class constructor
CLine::CLine(CPoint Start, CPoint End, COLORREF aColor)
{
 m_StartPoint = Start; // Set line start point
 m_EndPoint = End; // Set line start point
 m_Color = aColor; // Set line color
}
```
```

You first store the start point in the m_StartPoint member that is inherited from the CEElement class. Later you'll add code to allow an element to be moved and to enable a line to be moved by just changing the start point and the end point must be defined relative to the start point. You do this by subtracting the x and y coordinate values of Start from those of End. Both x and y are public members of the CPoint class so you can refer to them directly. Finally, you store the color in the m_Color member that is inherited from the CEElement class.



The Draw() function for the CLine class isn’t too difficult either, although you do need to take account of the color to be used when the line is drawn:

```
```cpp
// Draw a CLine object
void CLine::Draw(CDC* pDC)
{
 // Create a pen for this object and
 // initialize it to the object color and line width of 1 pixel
 CPen aPen;
 if(!aPen.CreatePen(PS_SOLID, m_Pen, m_Color))
 {
 // Pen creation failed. Abort the program
 AfxMessageBox(_T("Pen creation failed drawing a line"), MB_OK);
 AfxAbort();
 }
 CPen* pOldPen = pDC->SelectObject(&aPen); // Select the pen
 // Now draw the line
 pDC->MoveTo(m_StartPoint);
 pDC->LineTo(m_EndPoint);
 // Restore the old pen
 pDC->SelectObject(pOldPen);
}
