The first block in the Toolbox window is labelled All Windows Forms and lists all the controls available for use with a form. You can click the plus sign for All Windows Forms tab if it is not expanded. You can collapse this block by clicking the minus sign to the left of the block heading, and you’ll see that the controls are also grouped by type in the list starting with the Common Controls block. You’ll probably find it most convenient initially to use the group containing all the controls at the beginning of the list, but after you are familiar with what controls are available, you may find it easier to collapse the groups and just have one group expanded at one time.
