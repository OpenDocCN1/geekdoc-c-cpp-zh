In order to add some extra control to the knee, I set a Pole Target on the IK Constraint for the leg. The Pole Target is the same as a Pole Vector Constraint in Maya. It allows you to rotate the IK Chain and thus give you control for rotating or pointing the knee. I added a new bone called CNTRL_Knee.L in the knee position and set the Pole Target on the IK Constraint to this bone as shown in Fig. 6.17.

The CNTRL_Knee.L bone is then parented to the CNTRL_Foot.L Bone so that as the leg is moved, the knee controller will move with it, which will also automatically point the knee as the CNTRL_Foot.L is rotated. In Fig. 6.18, you can see this basic control setup for the legs in action.
