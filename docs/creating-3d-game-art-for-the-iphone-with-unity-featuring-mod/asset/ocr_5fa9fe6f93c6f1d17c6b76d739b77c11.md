# ### Adding Grime to Maps

The level looks great with the lightmaps applied; however, for a trash yard, the scene looks way to clean. We need to introduce some dirt and grime to the scene.

This is quite simple to do in Photoshop. First, I created a grime brush preset as shown in Fig. 8.30.

I then created a new layer and chose my preset brush, changed some settings in the brush editor so that I could stamp the grime down by simply left-clicking. I then began to stamp random dirt across the scene as shown in Fig. 8.31.
