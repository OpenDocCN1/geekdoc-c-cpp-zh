Files stored in linear space will look dark on your monitor, but in this case, we actually want to view the file in its default linear gamma of 1.0 in order to accurately set the exposure. To do this in Photoshop, go to View and make sure that Proof Colors is enabled. Then, go to View > Proof Setup and choose Monitor RGB as shown in Fig. 8.27. This will set the display to view the image in its default gamma, which will make any color correction or exposure changes done in Photoshop match how they'll look in Unity iOS.
