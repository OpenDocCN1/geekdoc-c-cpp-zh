It can also be very useful to overlap certain UV shells. For instance, with Tater's shoes, I decided that they barely be visible in the game, so they are the smallest set of UV shells in the UV layout. To further save on space, I went ahead and overlapped both of the shoe's UV shells so they occupied the same UV coordinates. This allowed me to save a lot of space in the UV map as shown in Fig. 3.9.

For both Tater and Thumper, I didn't have a need for repeating textures. I think of these types of objects as having self-contained UVs, which is to say their UVs are meant to target specific parts on a single contained mesh. However, in contrast, a wall object will need to have its UVs repeat so that the object can represent many walls in a tiled fashion.
