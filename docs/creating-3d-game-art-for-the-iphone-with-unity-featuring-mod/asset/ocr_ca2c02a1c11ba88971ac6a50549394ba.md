# Setting Up IK for Arms

The arm setup is a bit less complicated than the legs. First, I need to add a bone for the IK target. This was done by simply duplicating the Hand.L Bone using Shift + D to place the new bone in the same position as the Hand.L Bone, and renaming it to IK_Hand.L as shown in Fig. 6.19.
