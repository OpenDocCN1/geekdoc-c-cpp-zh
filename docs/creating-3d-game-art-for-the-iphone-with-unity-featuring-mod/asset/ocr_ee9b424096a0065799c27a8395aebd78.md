# ## Creating UVs

Once the texture map is complete, I then import this texture into modo and set the UV window to show the image. Now, while I create the UVs, I can use the image map as a guide to line up the coordinates to the image. Again, it's backwards to the way you'd usually work with UVs, but it also makes the UV layout process simple. # ## Lightmap UVs

For this level, I used lightmapping extensively, and I needed to be sure that I created a UV map that contained coordinates that didn't overlap. Nonoverlapping UVs is the key to creating a UV layout that is correct for lightmapping and that is to say that the current UV map won't do the trick. Not to worry, creating UVs for lightmapping is by far the easiest stage in the entire process. While still working under the single mesh for the entire level, I created a new UV map, which now leaves me with two UV maps for the mesh.
