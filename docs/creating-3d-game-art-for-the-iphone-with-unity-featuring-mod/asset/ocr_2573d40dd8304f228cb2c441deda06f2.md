Again, I'm sticking with the theme of slowly building up detail. From there, the fun begins as I rotate the model and paint dirt and wear through the model. Modo allows you to paint over UV seams and across UV maps, so this technique can be very useful toward further hiding seams in your texture maps by painting some procedural noise over the UV borders.
