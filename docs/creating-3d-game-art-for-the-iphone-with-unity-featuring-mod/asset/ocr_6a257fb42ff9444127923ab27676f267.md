Mip maps are designed to optimized textures that can appear very small on screen as they are pushed into the distance in 3D space. However, as discussed in Chapter 4 in the “Building on the Grid” section, we can manually create this effect ensuring the meshes are using only a specific and proportional section of the texture atlas to mesh size, which directly relates as a one-to-one relationship between the meshes size in units and the texture size in pixels. This means that the textures will never be too small in the scene, and thus, we don’t need to worry about using Mip maps. Profiling your game will ensure it’s optimized correctly.
