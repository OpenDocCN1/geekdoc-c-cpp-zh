PVRTC compression works well for natural type surfaces such as concrete, stone, and brick, and the compression is hardly noticeable.

The texture compression can and should be set directly in Unity iOS using the Texture Importer dialog as shown in Fig. 3.17. This means that when creating your textures, you can use whatever format you prefer such as PSD or PNG.
