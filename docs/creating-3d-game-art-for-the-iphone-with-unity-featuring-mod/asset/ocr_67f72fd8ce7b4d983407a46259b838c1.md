# ## How Animation Data Works in Unity iOS

Before we get to Blender workflow, it's important to discuss how Unity's animation data works as it's translated from the FBX file. I've mentioned that FBX is used to convert your animation data as it's imported into Unity iOS. Under the hood, Unity iOS is converting all your rotations into Quaternions. So no matter what Rotation Mode you're using in Blender, which can be set on the object's Transform as shown in Fig. 6.34, the rotations will be baked into Quaternions upon import into Unity iOS.
