There is one significant impediment to using the safe string functions: although safe functions (such as strcpy_s and strtok_s others) are specified by the C standard since C11, they are actually optional in C11 because all standard library implementations are not required to provide optional features. Hence, in order to get strcpy_s and strtok_s and all the other safe string functions into your system, you will need to either 1) find a library that implements them all, or 2) implement them yourself.

+   - https://wandbox.org/
