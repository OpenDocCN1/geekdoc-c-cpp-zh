# ## CREATING AN ARCHIVE LIBRARY IN A SHELL SCRIPT

You can also use a shell script createlib.sh to create a library that contains all the object files in the current directory, as shown here:

```
```sh
mylib2="mylib2.a"
```
```

```
```sh
for f in `ls *.o`
do
    echo "Adding object file $f"
    ar r $mylib2 $f
done
```
```

Open a command shell, navigate to the location of createlib.sh, and enter the following commands:

```
```sh
chmod +x createlib.sh
./createlib.sh
```
```

The output is shown here:

```
```text
Adding object file FindChar2.o
ar: creating archive mylib2.a
Adding object file FindMain2.o
Adding object file HelloWorld.o
```
```
