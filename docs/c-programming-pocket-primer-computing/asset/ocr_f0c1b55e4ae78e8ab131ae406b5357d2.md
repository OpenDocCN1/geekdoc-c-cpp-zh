"tail recursion:" the intermediate results of the recursive calculations are passed as the third parameter. Each time the custom function `computePower()` is invoked, the third parameter is updated with a new intermediate product and the value of the exponent `e` is decremented. The terminating condition occurs when the value of `e` is `0`, whereupon the value of the third parameter `r` is returned.
