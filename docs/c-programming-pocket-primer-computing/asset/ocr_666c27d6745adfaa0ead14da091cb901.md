# The errno Global Variable

Most C function calls return either -1 or `NULL` in the event of an error, and set an error code via the global variable `errno`. Thus, you can check the value of this variable to determine how to proceed, based on the value of this variable. In case you're interested, various error codes are defined in `<error.h>` header file.

# The perror() and strerror() Functions

The C programming language provides `perror()` and `strerror()` functions to display the text message associated with `errno`.

The `perror()` function displays the string you pass to it, followed by a colon, a space, and then the textual representation of the current `errno` value. For example, if your C program does not find a particular directory, the following message is displayed:

> Error: No such file or directory

The `strerror()` function returns a pointer to the textual representation of the current `errno` value, and the output is similar to the output of the `perror()` function.
