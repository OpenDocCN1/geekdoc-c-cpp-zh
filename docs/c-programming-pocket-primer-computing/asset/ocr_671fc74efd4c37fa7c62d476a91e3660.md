+   - support for variadic macros (macros that take a variable number of arguments)
+   - support for one-line comments beginning with //

While C99 is mostly backward compatible with C90, keep in mind that there are some restrictions.

A more recent major revision (starting around 2007) of the C standard is called C11, which adds numerous new features, including:

+   - type generic macros
+   - anonymous structures
+   - improved Unicode support
+   - atomic operations
+   - multi-threading
+   - bounds-checked functions
+   - improved compatibility with C++

C11 makes some portions of the existing C99 library optional.
