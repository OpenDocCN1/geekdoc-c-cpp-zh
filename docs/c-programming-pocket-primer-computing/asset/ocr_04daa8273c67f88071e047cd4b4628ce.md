# APPENDIX

# THE MAKE UTILITY

This Appendix discusses the `make` utility that can help you manage C applications that have multiple dependencies. The `make` utility excels in managing projects that involve recompiling C programs (based on their date of modification), creating object files, updating libraries, and integrating other artifacts. Although the examples in this Appendix are for C programs, the `make` utility works just as well for C++ projects.

The first part of this Appendix starts by describing the `make` utility and a Makefile, and then briefly discusses Unix commands for managing object files and libraries, such as the `ar` command and the `ranlib` command. You will also learn how to use the `nm` command for C programs that will help you find symbol definitions.

The second part of this Appendix delves into the `make` utility, which is the bulk of the material in this Appendix. You will learn how to use the `make` utility with some simple examples, macros in makefiles, and how to create multiple executable files.
