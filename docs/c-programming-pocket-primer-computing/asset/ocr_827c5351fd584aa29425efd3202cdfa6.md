# POINTERS TO FUNCTIONS OF TYPE VOID

Listing 6.21 displays the contents of PointersNums1.c that illustrates how to define two simple functions and also a function pointer in order to “point” to those functions and execute them.

# LISTING 6.21: PointersToVoidFunctions1.c

```
#include <stdio.h>

void one()
{
    printf("Inside function one\n");
}

void two()
{
    printf("Inside function two\n");
}

int main()
{
    void (*ptr1)();

    one();
    ptr1 = &one;
    (*ptr1)();
    //ptr1 = one;
    //ptr1();

    two();
    ptr1 = &two;
    (*ptr1)();
}
```
