# # DISPLAY A LIST OF PRIME NUMBERS

`Listing 4.10` displays the contents of `DisplayPrimes.c` that shows you how to define invoke a custom function `isPrime()` that is invoked from a `for` loop that is inside the `main()` function in order to display a list of prime numbers. Although you can place the code for the function `isPrime()` inside a loop in the `main()` function, the use of a function enables you to modularize the code.

#include <stdio.h>

int isPrime(int idx)
{
    int flag=0, div=2;
    while (div <= idx/2)
    {
        if (idx % div == 0) // composite
        {
            flag = 1;
            break;
        }
        div++;
    }

    return flag;
}

    int maxVal=50, idx=0, result=0;
