C provides the union data type that enables you to store different data types in the same memory location. Although you can define a C union with multiple members, only one member "at a time" can contain an actual value. The member that contains a value can change repeatedly during the execution of a program, but there is exactly one—at any given point in time—that contains a value.

The following example shows you how to use the C union keyword to define a C union data type:

```
```c
union MyData
{
    int i;
    float f;
    char str[10];
} myunion;
```
```

The memory allocated to a C union equals the size of the largest member of the union. Thus, the MyData type requires 10 bytes because the str element occupies 10 bytes.
