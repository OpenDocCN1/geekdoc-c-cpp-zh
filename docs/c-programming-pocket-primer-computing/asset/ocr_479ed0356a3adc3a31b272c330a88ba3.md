The preceding C struct requires 8 bytes of memory even though the values are either 0 or 1. Alternatively, the following C bitfield definition is more compact:

```
struct
{
    unsigned int validDay: 1;
    unsigned int validMonth: 1;
} dateInfo;
```

On a typical system where an int is 32 bits, the previous C struct uses 4 bytes for the dateInfo variable, and 2 bits of memory for its elements. If you specify up to 32 bit values, the dateInfo variable requires 4 bytes. However, if you specify between 33 and 63 bit values, the dateInfo variable requires 8 bytes (you can no doubt see the pattern here).
