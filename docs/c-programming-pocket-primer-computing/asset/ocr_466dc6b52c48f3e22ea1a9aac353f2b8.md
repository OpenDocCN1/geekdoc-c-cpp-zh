# Automatic Variables

If you want to become really proficient with the make utility, you need to learn many of the variables that have a special significance in makefiles. Here is a short list of some supported variables, along with a short description of their purpose:

+   - $@ is the file name of the target of a rule
+   - $% is the target member name: if the target is foo.a(bar.o) then $% is bar.o and $@ is foo.a.
+   - $< is the name of the first prerequisite
+   - $? is the names of all the prerequisites that are newer than the target
+   - $^ is the names of all the prerequisites

The make utility supports many other built-in variables, and you can perform an online search to find more information.
