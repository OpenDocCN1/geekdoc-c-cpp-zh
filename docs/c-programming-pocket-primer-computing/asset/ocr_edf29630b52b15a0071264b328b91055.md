```
{
printf ("GLOBAL value of a = %d, b = %d and c = %d\n",a,b,c);

// local variable declaration
int a, b, c;

// actual initialization
a = 10;
b = 20;
c = a + b;

printf ("LOCAL value of a = %d, b = %d and c = %d\n",a,b,c);

printGlobalVariables();

return 0;
}
```

Listing 2.8 is very simple: the integer-valued *global* variables a, b, and c are declared and initialized, after which their values are printed immediately inside the main() function. The next portion of code inside the main() function declares and initializes *local* integer-valued variables a, b, and c and then prints their values. The final portion of the main() function invokes the printGlobalVariables() function that simply prints the values of the *global* integer-valued variables a, b, and c.

The output from Listing 2.8 is here:

GLOBAL value of a = 1, b = 2 and c = 3
LOCAL value of a = 10, b = 20 and c = 30
Inside the printGlobalVariables function
GLOBAL value of a = 1, b = 2 and c = 3
