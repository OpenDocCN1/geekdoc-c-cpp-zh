
Although the preceding example is somewhat artificial, you can see how to adapt the makefiles to handle multiple subdirectories containing source code for your project.

## Creating a Library Archive from Object Files

Listing A.15 displays the contents of `Makefile8` that illustrates how to create a library containing a set of object files that are located in the current directory.

**Listing A.15** Makefile8

```makefile
RM=/bin/rm -f
AR=/usr/bin/ar
MYLIB=mylib.a

# only the 'hello' target
all: lib

# create a library with .o files
lib: FindChar2.o FindMain2.o HelloWorld.o
	$(AR) r $(MYLIB) $?

clean:
	$(RM) $(MYLIB) 2>/dev/null
```

Listing A.15 contains familiar macro definitions, followed by the `all` target that depends on the `lib` target. As you can see, the `lib` target depends on three object files, and the command that is executed is the `ar` command that updates the library `mylib.a` with the three object files.

Now type the following command in a command shell:

```sh
make -f Makefile5 lib
```

The output is displayed here:

```text
/usr/bin/ar r mylib.a FindChar2.o FindMain2.o HelloWorld.o
ar: creating archive mylib.a
```

Now type the following command:

```sh
make -f Makefile5 clean
```

The output is displayed here:

```text
/bin/rm -f mylib.a 2>/dev/null
```

## Creating an Archive Library in a Shell Script

You can also use a shell script createlib.sh to create a library that contains all the object files in the current directory, as shown here:

```sh
mylib2="mylib2.a"
```

```sh
for f in `ls *.o`
do
    echo "Adding object file $f"
    ar r $mylib2 $f
done
```

Open a command shell, navigate to the location of createlib.sh, and enter the following commands:

```sh
chmod +x createlib.sh
./createlib.sh
```

The output is shown here:

```text
Adding object file FindChar2.o
ar: creating archive mylib2.a
Adding object file FindMain2.o
Adding object file HelloWorld.o
```
