# DISPLAYING SUBSTRINGS OF A STRING

The example in this section is mainly for fun, yet it's useful because it shows you how to "walk" a pointer through a character string and display partial strings, all of which is performed in a nested loop.

Listing 5.6 displays the contents of `Substrings.c` that illustrates how to display substrings of a given string.

# LISTING 5.6: Substrings.c

```c
#include <stdio.h>

int main()
{
    char *str = "thisisalongstring";
    int len = strlen(str);

    for(int i=1; i<=len; i++)
    {
        printf("%2d: ",i);
        for(int j=0; j<i; j++)
        {
            printf("%c", (char)str[j]);
        }
        printf("\n");
