# **LISTING 7.16: DontDoThis.c**

```
```c
#include <stdlib.h>

int main()
{
  // a data value and an array
  int value, array[10];

  // point to the first element
  int *arrptr = &array[0];
  printf("arrptr: %d\n", arrptr);

  // get element #0 from arrptr
  value = *arrptr++;
  printf("value1: %d\n", value);

  value = *++arrptr;
  printf("value2: %d\n", value);

  // get element #1 from arrptr
  value = ++*arrptr;
  printf("value3: %d\n", value);
}
```
```

Although the code in Listing 7.16 is syntactically correct, even experienced C programmers can inadvertently reference the memory location of a pointer instead of the contents of a pointer (a very common occurrence).

Launch the compiled code from Listing 7.16 and you will see the following output:
