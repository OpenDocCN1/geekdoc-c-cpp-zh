# # FINDING A CHARACTER IN A STRING

Listing 4.8 displays the contents of `FindChar1.c` that shows you how to find the number of occurrences of a character in a given string in a C program.

***LISTING 4.8: FindChar1.c***

```
~~~c
#include <ctype.h>
#include <stdio.h>

void findChar(char str[], char c)
{
  int matchCount = 0;

  printf("String: %s\n",str);
  printf("Char:  %c\n",c);

  for(int i=0; str[i]; i++)
  {
    if(str[i] == c)
    {
      printf("Match in position: %d\n",i);
      ++matchCount;
    }
  }
}
```
