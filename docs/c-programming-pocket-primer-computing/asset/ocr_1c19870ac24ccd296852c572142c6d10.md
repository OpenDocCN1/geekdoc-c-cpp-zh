The /usr/include directory contains the various “header” files that are included in every C program in this book. You will see an example in the next section. In addition, you can create custom header files that you can place in your projects and then reference them in your C programs.

You can include a header file in a C program by placing the following type of statement at the beginning of a C program:

```
#include <stdio.h>
```

If you have a custom header file called mystdio.h that is located in the same directory as your C program, you can reference this header file with the following syntax:

```
#include "mystdio.h"
```
