# Major Revisions to C

This book does not discuss versions of C prior to the C99 ISO standard, which was released in 1999. Note that earlier versions of the C language include K&R C, ANSI C, and C90. The C99 standard incorporates many new features, such as:

+   - inline functions
+   - new data types (such as long long int and a complex type)
+   - variable-length arrays and flexible array members
+   - improved support for IEEE 754 floating point
