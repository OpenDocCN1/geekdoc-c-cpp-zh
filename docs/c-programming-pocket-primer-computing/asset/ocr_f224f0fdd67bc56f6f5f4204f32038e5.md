# ARRAY OF POINTERS

Listing 6.9 displays the contents of `ArrayOfPointers.c` that illustrates how to initialize an array of pointers.

**LISTING 6.9: ArrayOfPointers.c**

```
```c
#include <stdio.h>

int main()
{
    int a=100, b=-200, c=500;
    int *p[3];

    p[0]= &a;
    p[1]= &b;
    p[2]= &c;

    printf("Initial a: %d b: %d c: %d\n",*p[0],*p[1],*p[2]);

    *p[0] += 100;
    *p+= 200;
    *p+= 300;

    printf("Updated a: %d b: %d c: %d\n",*p[0],*p[1],*p[2]);

    return 0;
}
