# WORKING WITH MACROS IN C

Earlier in this chapter you learned how to use the #define keyword in order to define constants or strings. You can also use the #define keyword to define so-called macros, which comprise a block of executable C code. The C preprocessor uses text substitution to replace the occurrence of each macro with its corresponding definition.
