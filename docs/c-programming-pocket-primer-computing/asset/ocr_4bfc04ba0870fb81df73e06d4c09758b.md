# Checking for C11 Compliance

The first (and simplest) way to check for C11 compliance involves specifying the switch -std=c11 whenever you compile a C program, an example of which is shown here:

```
gcc -std=c11 HelloWorld.c -o HelloWorld
```

However, you will not see a non-compliance warning message until you launch the executable (i.e., the compilation step does not generate non-compliance messages), as shown later in this section.
