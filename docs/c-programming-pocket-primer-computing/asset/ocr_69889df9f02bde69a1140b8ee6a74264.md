Another way to simplify the preceding if/else logic is via the ternary operator that has the following form:

```
expr1 ? expr2 : expr3
```

For example, the code block at the beginning of this section can be expressed as follows:

```
x = (a<b ? 1 : 2);
```

In the preceding code snippet, if the inequality a<b is true, then x is assigned the value 1; otherwise, x is assigned the value 2.
