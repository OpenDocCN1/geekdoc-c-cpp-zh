# WHAT IS A C STRUCT?

A C struct is essentially a “structure” that defines a group of logically related items. Simple examples of logically related items that can be defined via a C struct include: employee, student, mailing address, and so forth. Keep in mind that the data values might be accessed from a file, a database, or retrieved via a Web service.
