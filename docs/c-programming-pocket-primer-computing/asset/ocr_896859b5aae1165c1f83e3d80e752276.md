Exponentiation has the highest precedence, except when overridden by parentheses, as shown here:

2**4-3 = 16-3 = 13
2**(4-3) = 2**1 = 2

# LISTING 1.4: Arithmetic.c

```
```c
#include <stdio.h>

int main()
{
    int x = 5 + 3;
    int y = 5 - 3;
    int z = 5 * 3;
    int w = 5 / 3;

    printf("5 + 3 = %d\n",x);
    printf("5 - 3 = %d\n",y);
    printf("5 * 3 = %d\n",z);
    printf("5 / 3 = %d\n",w);

    return (0);
}
```
```
