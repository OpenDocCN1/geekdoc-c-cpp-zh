Listing 3.16 displays the contents of `NestedForLoop.c` that shows you how to use a nested for loop in a C program.

# LISTING 3.16: NestedForLoop.c

```
```c
#include <stdio.h>

int main()
{
   int max=5;

   for(int i=0; i<max; i++)
   {
      printf("(i,j): ");
      for(int j=0; j<max; j++)
      {
         printf("%d %d ", i, j);
      }
      printf("\n");
   }

   return 0;
}
```
```

Listing 3.16 contains a `main()` function with a nested loop that iterates through the numbers between 0 and 4 inclusive, and uses the `printf()` function to display the current (i,j) position (where i is the index of the outer loop and j is the index of the inner loop). The output from Listing 3.16 is here:
