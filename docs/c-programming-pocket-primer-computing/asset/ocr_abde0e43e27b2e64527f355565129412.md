# # SIMPLE CONDITIONAL LOGIC

This section shows you a very simple example of using if-else statements in C programs. Make note of the examples of conditional logic in this chapter because (as you will see in Chapter 3) for loops in C programs invariably contain some type of conditional logic (with the possible exception of C programs that provide report-related functionality).

Listing 2.1 displays the contents of IfElse.c that illustrates how to use if-else logic in a C program.

# **LISTING 2.1: IfElse.c**

```
    #include <stdio.h>

    int main()
    {
      int z = 10;

      if(z % 2 == 0)
      {
        printf("z is even: %d\n", z);
      }
      else
      {
        printf("z is odd: %d\n", z);
      }

      return 0;
    }
```
