Then G(x, Q) is convex, C^1, G(x, Q) \to +\infty as |x| \to +\infty. Let S(Q) be the minimum of G(x, Q), then the feedback v(x, Q) is given by the formula

```
(11.1.6) \quad \hat{v}(x, Q) = \begin{cases} Q, & \text{if } x < S(Q) - Q \\ S(Q) - x, & \text{if } S(Q) - Q < x < S(Q) \\ 0, & \text{if } x > S(Q) \end{cases}
```

S(Q) is decreasing in Q and strictly positive. The derivative u'_n(x, Q) increases in Q, except in 0. In 0, the property applies for the left and right derivatives.

PROOF. We consider the monotone increasing process u_n(x). We start with u_0(x) = 0, u_1(x, Q) = hx^+ + px^- and

```
(11.1.7) \quad u_{n+1}(x, Q) = hx^+ + px^- - cx + \inf_{\{t \le x \le t+Q\}} [cy + \alpha E u_n(\eta - D, Q)].
```

As we have seen in the case Q = +\infty, see Chapter 5, section 5.2, for 1 \le n \le n_0 + 1 with

```
\frac{\alpha p}{1-\alpha}(1 - \alpha^{n_0+1}) > c \ge \frac{\alpha p}{1-\alpha}(1 - \alpha^{n_0}),
```

we have u_n(x, Q) = u_n(x), with

```
(11.1.8) \quad u_{n+1}(x) = hx^+ + px^- + \alpha E u_n(x - D), 0 \le n \le n_0.
```

This is obvious, when n_0 = 0, which corresponds to \alpha p > c. So we can assume that c \ge \alpha p. We have n_0 \ge 1.

The functions u_n(x) defined by the sequence (11.1.8) are convex and

```
u'_n(x) = -p \frac{1-\alpha^n}{1-\alpha}, x < 0, 1 \le n \le n_0 + 1,
```

therefore

```
G_n(x) = cx + \alpha E u_n(x - D),
```

is also convex and monotone increasing, for 0 \le n \le n_0. Note that G_n(x) is C^1 since

```
G'_n(x) = c + \alpha \int_{-\infty}^x u'_n(z) (x-z) dz,
```

and

```
G'_n(x) = c - \alpha p \frac{1-\alpha^n}{1-\alpha} \ge 0, \forall x \le 0, 0 \le n \le n_0
```

It follows that u_n(x) satisfies (11.1.7), and therefore u_n(x, Q) = u_n(x), \forall 1 \le n \le n_0 + 1. Clearly u_n(x) \to +\infty, as |x| \to +\infty, and u_n(x) is C^1 except in 0. One has

```
u'_n(0+) = h - \alpha p \frac{1-\alpha^{n-1}}{1-\alpha}, 1 \le n \le n_0 + 1
```

Consider now u_{n_0+2}(x, Q). Note that

```
G'_{n_0+1}(x) = c - \alpha p \frac{1-\alpha^{n_0+1}}{1-\alpha}, x \le 0
```

Therefore the function G_{n_0+1}(x) is strictly decreasing for x negative and \to +\infty, as x \to +\infty. Hence it has a minimum.
