Moreover for any \(\varphi(x)\) bounded

```
(15.6.4) 
\(\Phi_\alpha^{s,S}(x) = E \int_0^{+\infty} \exp - \alpha t \varphi(y_\varepsilon^{s,S}(t))dt,\)
```

satisfies

```
(15.6.5) 
\(\alpha \Phi_\alpha^{s,S}(x) \to \int_s^{+\infty} \varphi(x) m^{s,S}(x) dx.\)
```

PROOF. We note that \(\tilde{m}^{*,S}(x)\) in formula (15.6.2) is continuous but not \(C^1\). The derivative is discontinuous in \(S\). We begin to prove that \(m^{*,S}(x)\) is an invariant measure and the unique one, which is continuous and \(C^1\) except for \(S\). We begin by proving that \(m^{*,S}(x)\) must vanish on the interval \((-\infty, s)\). Indeed an invariant measure must satisfy

```
\(\int m^{*,S}(x)\varphi(x)dx = \int m^{*,S}(x)E\varphi(y_\varepsilon^{*,S}(x))dx, \forall \varepsilon\)
```

Take a test function \(\varphi(x)\) which vanishes on \(s, +\infty\). We get from the preceding relation

```
\(\int_{-\infty}^s m^{*,S}(x)\varphi(x)dx = E\varphi(y_S^S(\varepsilon)) \int_{-\infty}^s m^{*,S}(x)dx + \int_s^{+\infty} m^{*,S}(x)E\varphi(y_\varepsilon^{*,S}(\varepsilon))dx\)
```

Letting \(\epsilon \to 0\) in the right hand side, we obtain

```
\(\varphi(S) \int_{-\infty}^s m^{*,S}(x)dx + \int_s^{+\infty} m^{*,S}(x)\varphi(x)dx = 0,\)
```

from the choice of \(\varphi\). Let now pick \(\varphi(x)\) in the domain of the infinitesimal generator. An invariant measure must satisfy

```
\(\int_s^{+\infty} m^{*,S}(x)A\varphi(x)dx = 0.\)
```

We write \(m(x)\) for \(m^{*,S}(x)\) to simplify notation. We recall the regularity properties on \(m\) and perform integration by parts. We get

```
\(-\frac{\sigma^2}{2} [\varphi(S)(m'(S+0) - m'(S-0)) + \varphi(s)m'(s)]\)
\(-\lambda \varphi(S) \int_s^{+\infty} m(x) \left( \int_{x-s}^{+\infty} \mu(\xi)d\xi \right) dx + \int_s^{+\infty} \varphi(x) \left( \frac{\sigma^2}{2}m''(x) - \nu m'(x) + \lambda m(x) \right) dx\)
\(-\lambda \int_s^{+\infty} m(x) \left( \int_0^{x-s} \varphi(x - \xi) \mu(\xi)d\xi \right) dx = 0.\)
```

Using the fact that \(\varphi\) satisfies \(\varphi(s) = \varphi(S)\) and rearranging we obtain

```
\(-\varphi(S) \left[ \frac{\sigma^2}{2} (m'(S+0) - m'(S-0) + m'(s)) \right.\)
\(\left. + \lambda \int_s^{+\infty} m(x) \left( \int_{x-s}^{+\infty} \mu(\xi)d\xi \right) dx \right] + \int_s^{+\infty} \varphi(x) \left( \frac{\sigma^2}{2}m''(x) - \nu m'(x) \right.\)
\(\left. + \lambda m(x) - \lambda \int_0^{+\infty} m(x + \xi) \mu(\xi)d\xi \right) dx = 0.\)
```
