
This defines a Markov chain to which is associated the operator

(12.3.4) 
\(\Phi^v \varphi(x, z) = \int_0^\infty \varphi(x + v - \zeta, c) f(\zeta | z) d\zeta,\)

hence the transition probability is given by

(12.3.5) 
\(\pi(x, z, v; d\xi, d\zeta) = \delta(\xi - (x + v - \zeta)) \otimes f(\zeta | z) d\zeta.\)

We next define the function

(12.3.6) 
\(l(x, v) = cv + hx^+ + px^-,\)

which will model the one period cost. The cost function is then

(12.3.7) 
\(J_{x,z}(V) = E \sum_{n=1}^\infty \alpha^{n-1} l(y_n, v_n).\)

We are interested in the value function

(12.3.8) 
\(u(x, z) = \inf_V J_{x,z}(V).\)

We notice again that the properties (4.31), (4.32) are satisfied. To proceed, we need to specify a ceiling function. It corresponds to a control identically 0. Set \(l_v(x) = l(x, v)\). Note the inequalities

\(\Phi^{x+} u^+(x, z) \le x^+, \quad \Phi^{x-} u^-(x, z) \le x^- + c_0 z + c_1.\)

It is easy to check that

(12.3.9) 
\((\Phi^0)^n x^+(x, z) \le x^+,\)

(12.3.10) 
\((\Phi^0)^n x^-(x, z) \le x^- + c_0 z \frac{1-c_0^n}{1-c_0} + (n - c_0(n+1) + c_0^{n+1}) \frac{c_1}{(1-c_0)^2}.\)

Consider then the function

(12.3.11) 
\(w_0(x, z) = \sum_{n=1}^\infty \alpha^{n-1} (\Phi^0)^{n-1} l_0(x)\)

### Lemma 12.2.

We assume that

(12.3.12) 
\(\alpha c_0 < 1,\)

then the series \(w_0(x, z) < \infty\), and more precisely

(12.3.13) 
\(u_0(x, z) \le \frac{hx^+ + px^-}{1 - \alpha} + \frac{p c_0 z \alpha}{(1 - c_0 \alpha)(1 - \alpha)} + \frac{p c_1}{(1 - c_0)^2} \left( \frac{\alpha - c_0}{(1 - \alpha)^2} + \frac{c_0}{1 - \alpha c_0} \right).\)

PROOF. It is an immediate consequence of formulas (13.2.10) and (12.3.9). \(\square\)

We next write the Bellman equation

(12.3.14) 
\(u(x, z) = \inf_{v \ge 0} [l(x, v) + \alpha \Phi^v u(x, z)].\)

We state the following

### Theorem 12.4.

We assume (13.2.1), (12.3.2), (12.3.6), (13.2.11). Then there exists one and only one solution of equation (13.2.15), such that \(0 \le u \le w_0\). It is continuous and coincides with the value function (12.3.8). There exists an optimal feedback \(v(x, z)\) and an optimal control policy \(\bar{V}\).

PROOF. We first notice that conditions of Theorem 4.4 and 4.3 are satisfied. Hence the set of solutions of equation (13.2.15) is not empty. It has a minimum and a maximum solution. The minimum solution is l.s.c. and the maximum solution is u.s.c. The minimum solution coincides with the value function. There exists an optimal feedback \(\hat{v}(x, z)\) and an optimal control policy \(\hat{V}\). To prove uniqueness, we have to prove that the minimum and maximum solutions coincide. We begin by proving a bound on \(\hat{v}(x, z)\). From (13.2.15), considering \(\underline{w}\), the minimum solution, we can state that

(12.3.15) 
\(\underline{w}(x, z) \ge \frac{hx^+}{1-\alpha} + px^- - \frac{\alpha h c_0 z}{(1-\alpha)(1-\alpha c_0)} - \frac{\alpha h c_1}{(1-\alpha)^2},\)

which follows from \(l(x, v) \ge hx^+ + px^-\), and

(12.3.16) 
\(\Phi^{l,v}(x, z) \ge \Phi^{0,v}(x, z), \forall v \ge 0, \forall \varphi \text{ increasing in } x,\)

which implies

\(\alpha E[\underline{w}(x+v-z_2, z_2)|z_1=z]\)
\(\ge \frac{\alpha h}{1-\alpha} E[(x-z_2)^+|z_1=z] - \frac{\alpha^2 h c_0 (c_0 z + c_1)}{(1-\alpha)(1-\alpha c_0)} - \frac{\alpha^2 h c_1}{(1-\alpha)^2}\)
\(\ge \frac{\alpha h}{1-\alpha} (x^+ - c_0 z - c_1) - \frac{\alpha^2 h c_0 (c_0 z + c_1)}{(1-\alpha)(1-\alpha c_0)} - \frac{\alpha^2 h c_1}{(1-\alpha)^2}\)

and (13.2.40) follows, using again (13.2.15). Therefore also

(12.3.17) 
\(l(x, v) + \alpha \Phi^{\underline{w}}(x, z) \ge cv + \frac{hx^+}{1-\alpha} + px^- - \frac{\alpha h c_0 z}{(1-\alpha)(1-\alpha c_0)} - \frac{\alpha h c_1}{(1-\alpha)^2}.\)

We next introduce the function \(w(x, z)\) solution of

(12.3.18) 
\(w(x, z) = hx^+ + (c+p)x^- + \alpha E[w(x^+-z_2, z_2)|z_1=z],\)

which corresponds to the feedback \(v(x) = x^-\). We note that \(\underline{w}(x, z) \le w(x, z)\). We can assert that

(12.3.19) 
\(w(x, z) \le (c+p)x^- + \frac{hx^+}{1-\alpha} + L_0 z + L_1,\)

with

\(L_0 = \frac{\alpha(c+p)c_0}{1-\alpha c_0}, \quad L_1 = \frac{\alpha c_1(c+p)}{(1-\alpha)(1-\alpha c_0)}\)

Therefore, in minimizing in \(v\), we can bound from above the range of \(v\). More precisely, we get

(12.3.20) 
\(\hat{v}(x, z) \le x^- + \frac{\alpha c_0 z}{c(1-c_0 \alpha)} \left( c+p + \frac{h}{1-\alpha} \right) + c \frac{\alpha c_1}{c(1-\alpha)} \left( \frac{h}{1-\alpha} + \frac{c+p}{1-c_0 \alpha} \right).\)

We consider the optimal trajectory \(\hat{y}_n, z_n\) obtained from the optimal feedback, namely

\(\hat{y}_{n+1} = \hat{y}_n + \hat{v}_n - z_{n+1}, \hat{v}_n = \hat{v}(\hat{y}_n, z_n)\)

with \(\hat{y}_1 = x, z_1 = z\).

To prove uniqueness, it is sufficient to show that

(12.3.21) 
\(\alpha^n E[\hat{y}_{n+1}] \to 0, \text{ as } n \to \infty.\)

We have

\(\hat{y}_{n+1} \le \hat{y}_n + \hat{v}_n\)
\(\le \hat{y}_n^+ + \frac{\alpha c_0 z_n}{c(1-c_0 \alpha)} \left( c+p+\frac{h}{1-\alpha} \right) + \frac{\alpha c_1}{c(1-\alpha)} \left( \frac{h}{1-\alpha} + \frac{c+p}{1-c_0 \alpha} \right)\)

Therefore

\(E\hat{y}_{n+1}^+ \le E\hat{y}_n^+ + \frac{\alpha \left( c_0^2 z + c_1 \frac{c_0 - c_0^2}{1-c_0} \right)}{c(1-c_0 \alpha)} \left( c+p+\frac{h}{1-\alpha} \right)\)
\(+ \frac{\alpha c_1}{c(1-\alpha)} \left( \frac{h}{1-\alpha} + \frac{c+p}{1-c_0 \alpha} \right)\)

and we deduce the estimate

\(E\hat{y}_{n+1}^+ \le x^+ + \frac{\alpha c_0}{c(1-c_0 \alpha)} \left( z \frac{1-c_0^n}{1-c_0} + c_1 \frac{n}{1-c_0 \alpha} - c_1 \frac{1-c_0^n}{(1-c_0)^2} \right) \left( c+p+\frac{h}{1-\alpha} \right)\)
\(+ \frac{n c_1}{c(1-\alpha)} \left( \frac{h}{1-\alpha} + \frac{c+p}{1-c_0 \alpha} \right),\)

and thus \(\alpha^n E\hat{y}_{n+1}^+ \to 0\), as \(n \to +\infty\). Next

\(\hat{y}_{n+1} \ge \hat{y}_n - z_{n+1},\)

and it follows easily

\(E\hat{y}_{n+1}^- \le x^- + c_0 z \frac{1-c_0^n}{1-c_0} + \frac{c_1}{1-c_0} \left( n - c_0 \frac{1-c_0^n}{1-c_0} \right),\)

and we obtain \(\alpha^n E\hat{y}_{n+1}^- \le x^- \to 0\), as \(n \to +\infty\). This completes the proof.

## 12.3.2. BASE-STOCK POLICY.

We want now to check that the optimal feedback \(\hat{v}(x, z)\) can be obtained by a base stock policy, with a base stock depending on the value of \(z\). We have the

### Theorem 12.5.

We make the assumptions of Theorem 12.4 and \(p\alpha > c(1 - \alpha)\), \(h + p - c > 0\). Assume also

(12.3.22) \(f(x)z \ge a_0(M) > 0, \forall x, z \le M.\)

Then the function \(u(x, z)\) is convex and \(C^1\) in the argument \(x\), except for \(x = 0\), where there exists a left and right derivative. Moreover the optimal feedback is given by

(12.3.23) \(\hat{v}(x, z) = \begin{cases} S(z) - x, & \text{if } x \le S(z) \\ 0, & \text{if } x \ge S(z) \end{cases}\)

where \(S(z) > 0\) is uniformly continuous.

PROOF. We consider the increasing process

\(u_{n+1}(x, z) = \inf_{v \ge 0} [(f, v) + \alpha \Phi^n u_n(x, z)], \quad u_0(x) = 0\)

which is also written as

\(u_{n+1}(x, z) = hx^+ + px^- - cx + \inf_{\eta \ge x} \{ c\eta + \alpha E[u_n(\eta - z_2, z_2)|z_1 = z] \}\)

We show recursively that the sequence \(u_n(x, z)\) is convex and \(C^1\) in \(x\), except for \(x=0\). We first have

(12.3.24) 
\(u_{n+1}(x, z) = hx^+ + px^- + \alpha E[u_n(x - z_2, z_2)|z_1 = z]\)

for \(0 \le n \le n_0\), with

\(\frac{\alpha p}{1 - \alpha}(1 - \alpha^{n_0+1}) > c > \frac{\alpha p}{1 - \alpha}(1 - \alpha^{n_0}).\)

Indeed, considering the sequence defined by (13.2.24), we have

\(u'_n(x, z) = -p \frac{1 - \alpha^n}{1 - \alpha}, \forall n \le n_0 + 1, \forall x < 0\)

Therefore \(c - \alpha p \frac{1 - \alpha^n}{1 - \alpha} > 0, \forall n \le n_0\) and the function \(\alpha \eta + \alpha E[u_n(\eta - z_2, z_2)|z_1 = z]\) is monotone increasing, \(\forall n \le n_0\).

Define

\(G_n(x, z) = cx + \alpha E[u_n(x - z_2, z_2)|z_1 = z],\)

then the function \(G_n(x, z)\) is monotone increasing for \(n \le n_0\), and for \(n = n_0 + 1\) attains its minimum in \(S_n(z) > 0\), which can be uniquely defined by taking the smallest minimum. It is \(C^1\) and convex (the derivative is continuous in 0, by the regularizing effect of the mathematical expectation).

We have then, for \(n \le n_0 + 1\)

\(u_{n+1}(x, z) = \left\{ \begin{array}{ll} hx^+ + px^- - cx + G_n(S_n(z), z) & \text{if } x \le S_n(z) \\ hx^+ + px^- - cx + G_n(x, z) & \text{if } x \ge S_n(z) \end{array} \right.\)

with \(S_n(z) = -\infty, \forall n \le n_0\). Hence \(u_n(x, z)\) is \(C^1\), except for \(x=0\), and convex, for \(n \le n_0 + 2\). By recurrence, this property is valid for any \(n\).

It follows that the limit \(u(x, z)\) is convex in \(x\). Clearly \(u(x, z) \to +\infty\), as \(|x| \to +\infty\). Also \(S_n(z) > 0, \forall n \ge n_0 + 1\). Moreover

\(u'_n(x, z) = -p - c, \forall x < 0, \forall n \ge n_0 + 2\)

and \(u'_n(x, z) \le \frac{h}{1 - \alpha}\). Therefore the limit \(u(x, z)\) is Lipschitz continuous in \(x\), and

\(u'(x, z) = -p - c, \forall x < 0, \quad u'(x, z) \le \frac{h}{1 - \alpha}.\)

Also

(12.3.25) 
\(-p - c \le u'(x, z) \le \frac{h}{1 - \alpha}.\)

The function

\(G(x, z) = cx + \alpha E[u(x - z_2, z_2)|z_1 = z],\)

is convex and \(\to +\infty\) as \(x \to +\infty\). For \(x < 0\), we have \(G'(x, z) = c(1 - \alpha) - \alpha p < 0\). Therefore the minimum of \(G(x, z)\) is attained in \(S(z) > 0\), which can be defined in a unique way, by taking the smallest minimum.

Then, from convexity

\(u(x, z) = \left\{ \begin{array}{ll} hx^+ + px^- - cx + G(S(z), z) & \text{if } x \le S(z) \\ hx^+ + px^- - cx + G(x, z) & \text{if } x \ge S(z) \end{array} \right.\)
