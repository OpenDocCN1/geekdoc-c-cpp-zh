The Bellman equation reads

```
(5.3.5) 
\( u(x) = (h - c)x + \inf_{v \ge 0} \{ l_0(x + v) + \alpha u((x + v - D)^+) \} \).
```

The solution \( u(x) \) is convex continuous and goes to \( +\infty \) as \( x \to +\infty \). We have to be careful about differentiability. We are interested in the minimum of \( l_0(x) + \alpha u((x - D)^+) \). If \( S \) is the minimum, we have for \( x \le S \), \( u(x) = (h - c)x + C \), hence for \( x \le S \), we have

```
\( l_0(x) + \alpha u((x - D)^+) = l_0(x) + \alpha(h - c)(x - D)^+ + \alpha C. \)
```

Therefore, we must have

```
\( l_0(x) + \alpha(h - c)(x - D)^+ \ge l_0(S) + \alpha(h - c)(S - D)^+, \quad \forall x < S. \)
```

Recalling that

```
\( l_0(x) + \alpha(h - c)(x - D)^+ = cx + p(x - D)^- + \alpha(h - c)(x - D)^+, \)
```

we see easily that if \( p \ge c \), this is achieved in a unique way with \( S = D \). If \( c > p \) then we have \( S = 0 \).

Therefore, if \( p \ge c \), we have

```
\( u(x) = (h - c)x + \frac{cD}{1 - \alpha}, \quad \forall x \le D. \)
```

# 5.3.2. BACKLOG ALLOWED. In the case of backlog, we have

```
(5.3.6) 
\( y_{n+1} = y_n + v_n - D \quad y_1 = x, \)
```

and the cost functional is

```
(5.3.7) 
\( J_x(V) = \sum_{n=1}^\infty \alpha^{n-1} l(y_n, v_n), \)
```

with

```
\( l(x, v) = hx^+ + px^- + cv. \)
```

Bellman equation becomes

```
(5.3.8) 
\( u(x) = hx^+ + px^- - cx + \inf_{v \ge 0} \{ c(x + v) + \alpha u(x + v - D) \} \).
```

We are interested in the minimum of the function \( cx + \alpha u(x - D) \). If \( S \) is this minimum, we have for \( x \le S \),

```
\( u(x) = hx^+ + px^- - cx + C, \)
```

so for \( x \le S \), the function \( cx + \alpha[h(x - D)^+ + p(x - D)^- - c(x - D) + C] \) must attain its minimum in \( S \). We obtain that if \( cp \ge c(1 - \alpha) \) necessarily \( S = D \), whereas if \( cp < c(1 - \alpha) \) necessarily \( S = 0 \). Therefore

```
\( u(x) = hx^+ + px^- - cx + \frac{cD}{1 - \alpha}, \quad \forall x \le D \)
```
