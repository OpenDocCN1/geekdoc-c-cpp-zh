(13.5.23) |(\tilde{u}_a)'(x;\sigma,\eta)| \le \frac{C}{F(x)}.

More generally

(13.5.24) |(\tilde{u}_a)^{(\beta)}(x;\sigma,\eta)| \le C + C \frac{|x| + \beta D}{F(x)};

(13.5.25) |((\tilde{u}_a)^{(\beta)})'(x;\sigma,\eta)| \le \frac{C}{F(x)}.

From Ascoli-Arzelà Theorem, we can find a subsequence such that

\rho_\alpha \to \rho, \sup_{|x| \le X} |\tilde{u}_a(x;\sigma,\eta) - u(x;\sigma,\alpha)| \to 0 \n \sup_{|x| \le X} |(\tilde{u}_a)^{(\beta)}(x;\sigma,\eta) - u^{(\beta)}(x;\sigma,\alpha)| \to 0 \n \forall \ \sigma, \alpha, \beta, X \text{ as } \alpha \to 1

From the estimate (13.5.25) the limit satisfies

|u'(x;\sigma,\eta)| \le \frac{C}{F(x)}.

Going back to (13.5.27) and recalling that the infimum in y is attained at \max(x, S_\alpha(\sigma,\eta)) we can restrict y to y \le L_X provided x < X. So we can write using \tilde{u}_a(x;\sigma,\eta)

\tilde{u}_a(x;\sigma,\eta) + \rho_\alpha = -cx + l^{(\sigma+\eta)}(x) \n + \inf_{L_X \ge y \ge x} \left\{ cy + \alpha E \tilde{u}_a^{(\eta+\eta+1-(\sigma+\eta'))}(y;\sigma',\eta') \right\},

and thus using the uniform convergence on compact sets of R we obtain

u(x;\sigma,\eta) + \rho = -cx + l^{(\sigma+\eta)}(x) \n + \inf_{L_X \ge y \ge x} \left\{ cy + E u^{(\sigma+\eta+1-(\sigma'+\eta'))}(y;\sigma',\eta') \right\} \n \ge -cx + l^{(\sigma+\eta)}(x) + \inf_{y \ge x} \left\{ cy + E u^{(\sigma+\eta+1-(\sigma'+\eta'))}(y;\sigma',\eta') \right\}.

On the other hand for any y > x we have also

u(x;\sigma,\eta) + \rho \le -cx + l^{(\sigma+\eta)}(x) + E u^{(\sigma+\eta+1-(\sigma'+\eta'))}(y;\sigma',\eta'),

and thus (13.5.39) is obtained. The proof has been completed.

Consider the cost functional

J^\alpha_{\sigma,\eta}(V) = E \sum_{t=1}^\infty \alpha^{t-1} (c v_t + l^{(\sigma+\eta_t)}(x_t)),

then we shall have

(13.5.26) \rho = \inf_V \lim_{\alpha \to 1} (1-\alpha) J^\alpha_{\sigma,\eta}(V),

considering only control policies V such that the limit exists. Then the infimum is attained at V characterized by a Base stock

S(\sigma,\eta) = \lim_{\alpha \to 1} S_\alpha(\sigma,\eta).
