**Theorem 5.7.** We assume (5.2.2), (5.2.3) and \(c(1-\alpha) \ge \alpha p\). Then \(u(x) = w_0(x)\), with

(5.2.19) \(w_0(x) = \sum_{j=1}^{\infty} \alpha^{j-1} (\Phi^0)^{j-1} l_0(x).\)

Therefore \(\dot{v}(x) = 0\).

**PROOF.** In fact, if we look at the proof of the preceding theorem, the present assumption corresponds to the situation when \(n_0 = +\infty\). We then see that the increasing sequence converges to \(w_0(x)\). This proves the result.

**Remark 5.2.** We obtained in Proposition 5.1 that \(\bar{v}(x) \le x^- + C\). Moreover from the Base stock policy, we have also \(\dot{v}(x) \le x^- + S\). We must check that \(S \le C\). Using again \(D \ge S\bar{F}(S)\), we can state that

\(\bar{D} \ge S \frac{c(1-\alpha) + \alpha h}{\alpha(p+h)},\)

hence

\(\frac{C}{S} \ge \frac{[h + (p+\alpha)(1-\alpha)](c(1-\alpha) + \alpha h)}{c(p+h)(1-\alpha)^2},\)

and the constant on the right hand side is bigger than 1.

We have also a remark similar to Remark 5.1

**Remark 5.3.** Suppose \(x \le S\). If we apply a Base stock policy then we shall put an order at each period, and we have

\(y_n + v_n = S \quad n \ge 1\)
\(y_n = S - D_{n-1} \quad n \ge 2\)

and thus \(v_n = D_{n-1}\). It follows that the cost of a base stock policy is

\(u(x) = hx^+ + px^- + c(S-x) + \frac{\alpha}{1-\alpha}(c\bar{D} + hE(S-D)^+ + pE(S-D)^-),\)

and minimizing this expression in \(S\) yields formula (5.2.13).

# ## 5.3. DETERMINISTIC CASE

The deterministic case is a particular case of the stochastic case, except for smoothness. We assume that we face a fixed demand \(D\) at each period. We briefly describe the results.

# ### 5.3.1. NO SHORTAGE ALLOWED.

The inventory evolves as follows

(5.3.1) \(y_{n+1} = (y_n + v_n - D)^+ \quad y_1 = x,\)

and the cost functional is

(5.3.2) \(J_x(V) = \sum_{n=1}^{\infty} \alpha^{n-1} l(y_n, v_n),\)

with

(5.3.3) \(l(x,v) = (h-c)x + l_0(x+v),\)

and

(5.3.4) \(l_0(x) = cx + p(x-D)^-.\)
