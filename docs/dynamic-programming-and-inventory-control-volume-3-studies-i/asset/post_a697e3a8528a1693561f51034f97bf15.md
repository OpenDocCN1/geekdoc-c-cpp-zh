
which converges to \(s^*, S^*\). From the expression of \(H_{\alpha, s_\alpha}(x)\), we easily deduce that \(H_{\alpha, s_\alpha}(S_\alpha) = -K \to H_\alpha(S^*)\). From this one obtains that \(s^* = s, S^* = S\), solutions of equations (10.3.22). The value \(s\) is uniquely defined, and since \(S_\alpha\) is the smallest infimum, we obtain also that \(S\) is the smallest minimum.

Note that

\(g(x) = cD + hE(x-D)^+ + pE(x-D)^-,\)

so it is a positive function. Hence \(\rho > 0\). Clearly

\((1-\alpha)u_\alpha(x) - g_\alpha(s_\alpha) \to 0, \text{ as } \alpha \uparrow 1,\)

hence

\((1-\alpha)u_\alpha(x) \to \rho = g(s).\)

We recall that we have also

\(H(x) + \rho = g(x) + EH(x-D), \forall x \ge s\)
\(H(x) = 0, \forall x \le s\)

where \(H(x) = H_s(x)\), defined by (10.3.15), for the specific \(s\), limit of \(s_\alpha\).

We can check that these conditions can be summarized into

(10.3.26) \(H(x) + \rho = \inf_{\eta \ge x} [K 1_{\eta > x} + g(\eta) + EH(\eta - D)].\)

If (10.3.26) is satisfied, then the equation for \(u\) (10.3.25) follows immediately, using the definition of \(g(x)\).

The proof of (10.3.26) is identical to that of (10.2.25) in Theorem 10.2.

This completes the proof of the Theorem.

## 10.3.3. PROBABILISTIC INTERPRETATION.

We give now the interpretation of \(\rho\) and of the solution \(u(x)\) of (10.3.25). We first associate to an \(s, S\) policy an invariant measure \(m_{s,S}(dx)\). Moreover the infimum in equations (10.3.25), (10.3.26) is attained by a feedback \(\hat{v}(x)\) associated to an \(s, S\) policy. We still denote it \(s, S\) to save notation.

We recall that

(10.3.27) \(l(x, v) = K 1_{x > 0} + cv + hx^+ + px^-,\)

and

(10.3.28) \(l(x, \hat{v}(x)) = 1_{x \le s} (K + c(S-x)) + hx^+ + px^-,\)

and (10.3.25) reads

(10.3.29) \(u(x) = l(x, \hat{v}(x)) - \rho + Eu(x + \hat{v}(x) - D).\)

Let us denote by \(m_{l(\cdot)}(\text{d}x)\) the invariant measure \(m_{s,S}(\text{d}x)\), for consistency of notation. It follows from (10.3.29) that

(10.3.30) \(\rho = \int l(x, \hat{v}(x)) m_{l(\cdot)}(\text{d}x).\)

Note that the state space of \(m_{l(\cdot)}(\text{d}x)\) is \((-\infty, S]\) but can be taken as \((-\infty, \infty)\) to work with a fixed state space (independent of \(S\)). We next define the set \(\mathcal{U}_b\) of feedbacks such that

(10.3.31) \(\mathcal{U}_b = \{v(\cdot) \ge 0 | \exists M \text{ such that } -M \le x + v(x) \le \max(x, M)\}.\)

If \(v(\cdot) \in \mathcal{U}_b\), necessarily \(v(x) = 0\), if \(x \ge M\). The Markov chain, controlled with the feedback \(v(\cdot)\) is ergodic with state space \((-\infty, M]\). Indeed, the transition probability is

\(\pi(x, dy) = \mathbf{1}_{y < x + v(x)} f(x + v(x) - \eta) d\eta\).

If we take \(X_0 = [-M-2, -M-1]\), then for \(\eta \in X_0\), we have

\(\mathbf{1}_{y < x + v(x)} f(x + v(x) - \eta) \ge \inf_{y \in [1, 2+M]} f(y) > 0\).

We denote the corresponding invariant measure by \(m_{v(\cdot)}(dx)\). Note that a feedback defined by an s, S policy belongs to \(\mathcal{U}_b\). We then have

### Theorem 10.6. We make the assumptions of Theorem 10.5. We have

(10.3.32) \(\rho = \inf_{v(\cdot) \in \mathcal{U}_b} \int l(x, v(x)) m_{v(\cdot)}(dx)\),

and there exists an optimal feedback \(v(\cdot)\), defined by an s, S policy. This s, S policy has been defined in Theorem 10.5.

Proof. Consider a feedback \(v(\cdot)\) in \(\mathcal{U}_b\). From (10.3.25) we can state

(10.3.33) \(u(x) + \rho \le l(x, v(x)) + E u(x + v(x) - D)\).

Integrating with respect to the invariant measure \(m_{v(\cdot)}(dx)\) yields

\(\rho \le \int l(x, v(x)) m_{v(\cdot)}(dx)\).

The integral is finite. Indeed, one has

\(\int |x| m_{v(\cdot)}(dx) = \int E |x + v(x) - D| m_{v(\cdot)}(dx) \le M + D\).

Since

\(l(x, v(x)) = K \mathbf{1}_{x > 0} + c|x + v(x)| - cx + hx^+ + px^-,\)

it has a finite integral with respect to \(m_{v(\cdot)}(dx)\). Recalling also that

\(u(x) = H(x) - cx + hx^+ + px^-,\)

and noting that

\(\int |H(x)| m_{v(\cdot)}(dx) = \int_s^M |H(x)| m_{v(\cdot)}(dx) < \infty\),

we see also that \(|u(\cdot)|\) is integrable with respect to \(m_{v(\cdot)}(dx)\).

Taking account of (10.3.30) the result follows immediately.

### Remark 10.3. Let \(J_{\alpha, x}(v(\cdot))\) be the cost functional with discount \(\alpha\) for a controlled Markov chain, with control defined by a feedback \(v(\cdot)\) belonging to \(\mathcal{U}_b\). From Ergodic Theory we can claim that

(10.3.34) \((1 - \alpha) J_{\alpha, x}(v(\cdot)) \to \int l(\xi, v(\xi)) m_{v(\cdot)}(d\xi)\).

Therefore we have also

(10.3.35) \(\rho = \inf_{v(\cdot) \in \mathcal{U}_b} \lim_{\alpha \to 1} (1 - \alpha) J_{\alpha, x}(v(\cdot))\).

Let us also give the interpretation of the function \(u(x)\). Let us pick a feedback in \(\mathcal{U}_b\). Let us denote by \(y_n, v_n\) the corresponding trajectory, with

\(y_{n+1} = y_n + v_n - D_n \quad v_n = v(y_n); \quad y_1 = x\)

### Lemma 10.4. We have the property

(10.3.36) \( Eu(y_n) \to \int u(x)m_{v(\cdot)}(dx). \)

Proof. The integral is well defined, as it has been seen in the proof of Theorem 10.6. However, we cannot proceed as in the proof of Lemma 10.2, because \( y_n \) does not remain in a compact interval. However we have

(10.3.37) \( E\varphi(y_n) \to \int \varphi(x)m_{v(\cdot)}(dx), \)

for any function \( \varphi(x) \) continuous and bounded on the state space \( (-\infty, M] \). This is done as in Lemma 10.2, using ergodic theory and the procedure to address the situation of an initial value \( x > M \). Recalling that

\( u(x) = H(x) - cx + hx^+ + px^-,\)

and noticing that \( H(x) \) is continuous and bounded on \( (-\infty, M] \), it remains to prove the property (10.3.37) with \( \varphi(x) = x^+ \) or \( x^- \). For \( x^+ \) it is immediate, since it is continuous and bounded on \( (-\infty, M] \). For \( x^- \), one notices that,

\( Ey_{n+1}^- = EG(y_n),\)

where

\( G(x) = E(x + v(x) - D)^-,\)

and one notices that

\( G(x) \le M + \bar{D},\)

therefore it is continuous and bounded. The proof has been completed.

Let us consider a feedback \( v(\cdot) \in \mathcal{U}_b \) and let us consider \( y_n, v_n \) the corresponding trajectory

Define

(10.3.38) \( J_\pi^n(v(\cdot)) = \sum_{j=1}^n E(l(y_j, v_j)) - n\rho. \)

We then assert

### Theorem 10.7. We make the assumptions of Theorem 10.5. Then \( J_\pi^n(\hat{v}(\cdot)) \) has a limit as \( n \to \infty \) and

(10.3.39) \( u(x) = \lim_{n \to \infty} J_\pi^n(\hat{v}(\cdot)) + \int u(x)m_{v(\cdot)}(dx). \)

Moreover, for \( v(\cdot) \in \mathcal{U}_b \), \( J_\pi^n(v(\cdot)) \) is bounded below, and one has

(10.3.40) \( u(x) = \inf_{v(\cdot) \in \mathcal{U}_b} \left[ \liminf_{n \to \infty} J_\pi^n(v(\cdot)) + \int u(x)m_{v(\cdot)}(dx) \right]. \)

## 10.3.4. PARTICULAR CASE.

We consider the particular case of an exponential distribution \(f(x) = \beta \exp -\beta x\). We recall that \(\Gamma(x) = 1 + \beta x\).

Next we have

(10.3.41) 
\(\mu(x) = h - (p + h) \exp -\beta x^+,\)

and

(10.3.42) 
\(g(x) = hx^+ + px^- + (c + p)D - \frac{p+h}{\beta}(1 - \exp -\beta x^+).\)

We next compute the function \(H(x)\), for \(x > s\). We use the formulas

\(H'(x) = \begin{cases} -p\Gamma(x - s), & \text{if } x < 0 \\ -p\Gamma(x - s) + (p + h)(\Gamma(x) - 1), & \text{if } s < 0 < x \\ h\Gamma(x - s) - (p + h)F(x) - (p + h) \int_s^x \Gamma'(x - \xi)F(\xi)d\xi & \text{if } 0 < s < x \end{cases}\)

hence

\(H'(x) = \begin{cases} -p(1 + \beta(x - s)), & \text{if } x < 0 \\ -p(1 + \beta(x - s)) + (p + h)\beta x, & \text{if } s < 0 < x \\ h(1 + \beta(x - s)) - (p + h) \exp -\beta s & \text{if } 0 < s < x \end{cases}\)

We then obtain, for \(x > s\)

(10.3.43) 
\(H(x) = -p \left( x - s + \frac{\beta}{2}(x - s)^2 \right) + (h + p) \left[ (x - s^+)^+ (1 - \exp -\beta s^+) + \frac{\beta}{2}(x^+ - s^+)^2 \right].\)

The number \(\bar{s}\) satisfies \(\mu(\bar{s})=0\), hence

(10.3.44) 
\(\exp -\beta \bar{s} = \frac{h}{p + h}.\)

We thus consider \(s \le \bar{s}\). We define \(S(s)\) by \(H'(S) = 0\), hence

(10.3.45) 
\(S(s) = \frac{p\beta s^- - h(1 - \beta s^+) + (h + p) \exp -\beta s^+}{h\beta}.\)

We can see that \(S(\bar{s}) = \bar{s}\), and \(S(s)\) is decreasing for \(s \le \bar{s}\). Moreover \(S(-\infty) = +\infty\).

We next define the value of s. We first obtain the formula

(10.3.46) 
\(H_s(S(s)) = - \frac{1}{2h\beta} [ (h + p) \exp -\beta s^+ - h ]^2 - \frac{\beta p}{2h} (p + h)(s^-)^2 - \frac{p(p + h)}{h} s^-.\)

We can check directly on this formula that \(H_s(S(s))\) increases from \(-\infty\) to 0, as s grows from \(-\infty\) to \(\bar{s}\). So there exists a unique s such that \(H_s(S(s)) = -K\).
