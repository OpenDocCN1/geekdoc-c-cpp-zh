If \(v(\cdot) \in \mathcal{U}_b\), necessarily \(v(x) = 0\), if \(x \ge M\). The Markov chain, controlled with the feedback \(v(\cdot)\) is ergodic with state space \((-\infty, M]\). Indeed, the transition probability is

\(\pi(x, dy) = \mathbf{1}_{y < x + v(x)} f(x + v(x) - \eta) d\eta\).

If we take \(X_0 = [-M-2, -M-1]\), then for \(\eta \in X_0\), we have

\(\mathbf{1}_{y < x + v(x)} f(x + v(x) - \eta) \ge \inf_{y \in [1, 2+M]} f(y) > 0\).

We denote the corresponding invariant measure by \(m_{v(\cdot)}(dx)\). Note that a feedback defined by an s, S policy belongs to \(\mathcal{U}_b\). We then have

# Theorem 10.6. We make the assumptions of Theorem 10.5. We have

(10.3.32) \(\rho = \inf_{v(\cdot) \in \mathcal{U}_b} \int l(x, v(x)) m_{v(\cdot)}(dx)\),

and there exists an optimal feedback \(v(\cdot)\), defined by an s, S policy. This s, S policy has been defined in Theorem 10.5.

Proof. Consider a feedback \(v(\cdot)\) in \(\mathcal{U}_b\). From (10.3.25) we can state

(10.3.33) \(u(x) + \rho \le l(x, v(x)) + E u(x + v(x) - D)\).

Integrating with respect to the invariant measure \(m_{v(\cdot)}(dx)\) yields

\(\rho \le \int l(x, v(x)) m_{v(\cdot)}(dx)\).

The integral is finite. Indeed, one has

\(\int |x| m_{v(\cdot)}(dx) = \int E |x + v(x) - D| m_{v(\cdot)}(dx) \le M + D\).

Since

\(l(x, v(x)) = K \mathbf{1}_{x(v) > 0} + c|x + v(x)| - cx + hx^+ + px^-\),

it has a finite integral with respect to \(m_{v(\cdot)}(dx)\). Recalling also that

\(u(x) = H(x) - cx + hx^+ + px^-\),

and noting that

\(\int |H(x)| m_{v(\cdot)}(dx) = \int_s^M |H(x)| m_{v(\cdot)}(dx) < \infty\),

we see also that \(|u(\cdot)|\) is integrable with respect to \(m_{v(\cdot)}(dx)\).

Taking account of (10.3.30) the result follows immediately.

# Remark 10.3. Let \(J_{\alpha, x}(v(\cdot))\) be the cost functional with discount \(\alpha\) for a controlled Markov chain, with control defined by a feedback \(v(\cdot)\) belonging to \(\mathcal{U}_b\). From Ergodic Theory we can claim that
