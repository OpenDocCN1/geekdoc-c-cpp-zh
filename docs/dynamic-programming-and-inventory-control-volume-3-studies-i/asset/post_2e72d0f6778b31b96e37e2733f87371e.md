
and the control process \(v_n\) is adapted to the filtration \(\mathcal{F}^n\). We define the cost function for each period

(12.6.4) \( l(x, v) = hx^+ + px^- + cv. \)

Calling \(V = \{v_1, \cdots, v_n, \cdots\}\), a control policy, we define the cost functional

(12.6.5) \( J_{x, \lambda}(V) = E \left[ \sum_{n=1}^\infty \alpha^{n-1} l(y_n, v_n) | y_1 = x, \lambda_1 = \lambda \right]. \)

We consider the value function

(12.6.6) \( u(x, \lambda) = \inf_V J_{x, \lambda}(V), \)

and the Bellman equation

(12.6.7) \( u(x, \lambda) = hx^+ + px^- - cx + \inf_{y \ge x} [\alpha y + \alpha \Phi^u(u, \eta, \lambda)]. \)

### 12.6.2. SCALABILITY.

Bellman equation (12.6.7) is, as expected, a 2 dimensional problem. We just describe here a case when the problem can be reduced to one dimension, by an interesting property, the *scalability*. We say that there is scalability with the function \(g(\lambda)\) if one has the relations

(12.6.8) \( f(x, \lambda) = \frac{f(x/q(\lambda))}{q(\lambda)}, \quad q(\rho(\lambda, x)) = q(\lambda) U\left(\frac{x}{q(\lambda)}\right). \)

Let us give examples. The first one is the function

(12.6.9) \( f(x, \lambda) = \frac{k \alpha x^{k-1}}{(\lambda + x^k)^{\alpha+1}}. \)

This probability density is called Weibull-Gamma. The reason is that it is obtained by combining a Weibull distribution with a Gamma distribution. Suppose we consider a Weibull distribution

\(\psi(y, x) = k y x^{k-1} \exp - y x^k,\)

depending on a parameter \(y\). However, the parameter \(y\) is not known. One considers that it is random with a density

\(g(y, \lambda) = \frac{\lambda^\alpha y^{\alpha-1} \exp - y \lambda}{\Gamma(a)},\)

where we recall that for \(a > 0\)

\(\Gamma(a) = \int_0^{+\infty} x^{a-1} \exp - x \, dx.\)

We see immediately that

\(f(x, \lambda) = \int_0^{+\infty} \psi(y, x) g(y, \lambda) \, dy.\)

The function \(f(x, \lambda)\) defined by (12.6.9) is scalable if \(\rho(\lambda, x) = \lambda + x^k\). The functions \(g(\lambda)\), \(f(x)\), \(U(x)\) are defined by

(12.6.10) \( q(\lambda) = \lambda \bar{k}, \quad f(x) = \frac{k \alpha x^{k-1}}{(1+x^k)^{\alpha+1}}, \quad U(x) = (1+x^k) \bar{k}. \)

A second example is the Gamma-Gamma model in which

(12.6.11) $$f(x, \lambda) = \frac{\lambda^x x^{k-1} \Gamma(k+a)}{(x+\lambda)^{k+a} \Gamma(a) \Gamma(k)}.$$

This probability density can be obtained by combining a Gamma probability density

$$\psi(x, y) = \frac{y^x x^{k-1} \exp^{-y}}{\Gamma(k)},$$

with another Gamma probability density

$$g(y, \lambda) = \frac{\lambda^a y^{a-1} \exp^{-y\lambda}}{\Gamma(a)}.$$

The probability density (12.6.11) is scalable if \(\rho(\lambda, x) = \lambda + x\). The functions \(q(\lambda), f(x), U(x)\) are defined by

(12.6.12) $$q(\lambda) = \lambda, \quad f(x) = \frac{x^{k-1} \Gamma(k+a)}{(1+x)^{k+a} \Gamma(a) \Gamma(k)}, \quad U(x) = 1+x.$$

Let us now show how the scalability property can be used to reduce the dimension of Bellman equation to 1.

Equation (12.6.7) is written as

(12.6.13) $$u(x, \lambda) = hx^+ + px^- - cx + \inf_{\eta \ge x} \left[ c\eta + \alpha \int u(\eta - \zeta, \rho(\lambda, \zeta)) f(\zeta, \lambda) d\zeta \right].$$

Replacing \(f(\zeta, \lambda)\) we get

$$u(x, \lambda) = hx^+ + px^- - cx + \inf_{\eta \ge x} \left[ c\eta + \alpha \int u(\eta - \zeta, \rho(\lambda, \zeta)) \frac{f\left(\frac{\zeta}{q(\lambda)}\right)}{q(\lambda)} d\zeta \right].$$

We can find a solution of the form

$$u(x, \lambda) = v\left(\frac{x}{q(\lambda)}\right) q(\lambda),$$

with \(v(x)\) solution of

(12.6.14) $$v(x) = hx^+ + px^- - cx + \inf_{\eta \ge x} \left[ c\eta + \alpha \int v\left(\frac{\eta - \zeta}{U(\zeta)}\right) U(\zeta) f(\zeta) d\zeta \right],$$

which is a one-dimensional problem.

## LEAD TIMES AND DELAYS

### 13.1. INTRODUCTION

In all models, so far we have considered that an order $v_n$ put at time $n$ is delivered at time $n+1$. Another equivalent way is to consider that $n$ represents the initial time of the $n^{th}$ period and the delivery is achieved at the end of the period, which is also the beginning of the $(n+1)^{th}$ period. The delivery time, called the *lead time* is 1. In this chapter, we are going to consider more complex situations, in which the lead time is larger than 1. Many situations can occur, the simplest being that the lead time is a fixed deterministic number $L$. It can also be a random variable and even a stochastic process. During the lead time, there can be limitations in the orders, for example no order is possible during a lead time, or orders can be put without any limitation.

Concerning delays, we shall consider delays in the information reception. In the preceding chapters, the delay was 0. Indeed, the demand is observed when it is realized; the demand in the $n^{th}$ period is realized at the end of the $n^{th}$ period, which is also time $n+1$, when the order $v_{n+1}$ is decided.

In these problems the dynamics is not indifferent. The backlog case, in which the evolution of the inventory is linear, can lead to important simplifications, in which an interesting concept the *inventory position* plays a major role.

### 13.2. MODELS WITH INVENTORY POSITION

### 13.2.1. DETERMINISTIC LEAD TIME.

We assume here that we have a lead time $L \ge 1$. Of course, $L=1$ is the standard case. The demand is a sequence of i.i.d random variables $D_1, \cdots, D_n, \cdots$. We define the filtration

$\mathcal{F}^n = \sigma(D_1, \cdots, D_n), \quad \mathcal{F}^0 = (\emptyset, \Omega).$

The control $V = (v_1, \cdots, v_n, \cdots)$ is adapted to the filtration $\mathcal{F}^{n-1}$. If we denote by $(y_1, \cdots, y_n, \cdots)$ the sequence of inventories, with initial inventory $y_1 = x$, we have the relation

(13.2.1) \( y_{n+L} = y_{n+L-1} + v_n - D_{n+L-1}, \quad y_1 = x. \)

We note that we allow the possibility of backlog. Also the inventories $y_1, \cdots, y_L$ do not depend on the control, instead of just $y_1$. It is convenient to introduce pending orders $x_1, \cdots, x_{L-1}$ to be received at time $2, \cdots, L$, if $L \ge 2$. They are given values, like the initial value $x$. Therefore we have the relations

(13.2.2) \( y_j = x + x_1 + \cdots + x_{j-1} - D_1 - \cdots - D_{j-1}, 2 \le j \le L, \)

for $L \ge 2$. We next define the costs per period

(13.2.3) \( C(v) = K \mathbf{1}_{v>0} + cv, \quad l(x) = hx^+ + px^-. \)

Introduce the vector in $R^L, X = (x, x_1, \cdots, x_{L-1})$. We can define the objective functional

(13.2.4) 
$$J_X(V) = \sum_{n=1}^\infty \alpha^{n-1} EC(v_n) + \sum_{j=1}^{L-1} \alpha^{j-1} El(y_j) + \sum_{n=1}^\infty \alpha^{n-2+L} El(y_{n+L-1}).$$

If $L=1$ the intermediary sum disappears and we recover the standard cost objective. This intermediary sum is a given function of $X$, not depending on the control. The rest depends on $X$ through $y_L$, so in fact depends on $X$ only through the number

(13.2.5) 
$$z = x + x_1 + \cdots + x_{L-1}.$$

Therefore we can write

$$J_X(V) = \sum_{j=1}^{L-1} \alpha^{j-1} El(y_j) + \bar{J}_z(V),$$

where

(13.2.6) 
$$\bar{J}_z(V) = \sum_{n=1}^\infty \alpha^{n-1} EC(v_n) + \sum_{n=1}^\infty \alpha^{n-2+L} El(y_{n+L-1}).$$

Note that $z$ represents the initial inventory augmented by the sum of the pending deliveries. It is called the *inventory position*. Similarly, we use for $L \ge 2$

$$y_{n+L-1} = y_n + v_{n-1} + \cdots + v_{n-L+1} - (D_n + \cdots + D_{n+L-2}),$$

with the notation

$$v_0 = x_{L-1}; v_{-1} = x_{L-2} \cdots; v_{2-L} = x_1,$$

to define

$$\begin{aligned} z_n &= y_{n+L-1} + D_n + \cdots + D_{n+L-2} \\ &= y_n + v_{n-1} + \cdots + v_{n-L+1}, \end{aligned}$$

which is the inventory position at time $n$. We have $z_1 = z$. We then have the evolution

(13.2.7) 
$$z_{n+1} = z_n + v_n - D_n.$$

This proves that the process $z_n$ is adapted to the filtration $\mathcal{F}^{n-1}$. Next

$$l(y_{n+L-1}) = l(z_n - (D_n + \cdots + D_{n+L-2})).$$

But $D_n, \cdots, D_{n+L-2}$ are independent from $z_n$. Therefore

$$\alpha^{L-1} El(y_{n+L-1}) = E\bar{l}(z_n),$$

where

(13.2.8) 
$$\bar{l}(x) = \alpha^{L-1} El\left(x - \sum_{j=1}^{L-1} D_j\right).$$

We can then write

(13.2.9) 
$$\bar{J}_z(V) = \sum_{n=1}^\infty \alpha^{n-1} EC(v_n) + \sum_{n=1}^\infty \alpha^{n-1} E\bar{l}(z_n).$$

The problem has been reduced to a standard one, replacing the inventory with the inventory position, and the function $l(x)$ with $\bar{l}(x)$.
