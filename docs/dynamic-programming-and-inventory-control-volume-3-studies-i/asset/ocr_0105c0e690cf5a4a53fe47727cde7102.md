# 13.5.4. THE CASE K > 0. The equation is written as follows

(13.5.27) 
 u_\alpha(x; \sigma, \eta) = -cx + l^{(\sigma+\eta)}(x) \
 + \inf_{y \ge x} \left\{ K \mathbb{1}_{y > x} + cy + \alpha E u_\alpha^{(\sigma+\eta+1-(\sigma'+\eta'))}(y; \sigma', \eta') \right\}.

The solution is governed by an \(s_\alpha(\sigma, \eta)\), \(S_\alpha(\sigma, \eta)\) policy. Hence

x \le s_\alpha(\sigma, \eta) \Rightarrow u_\alpha(x; \sigma, \eta) = -cx + l^{(\sigma+\eta)}(x) + K + C_{\alpha, \sigma, \eta},

and

x \ge s_\alpha(\sigma, \eta) \Rightarrow u_\alpha(x; \sigma, \eta) = l^{(\sigma+\eta)}(x) + \alpha E u_\alpha^{(\sigma+\eta+1-(\sigma'+\eta'))}(x; \sigma', \eta').

We also have the continuity condition

C_{\alpha, \sigma, \eta} = \inf_{y > s_\alpha(\sigma, \eta)} \left\{ cy + \alpha E u_\alpha^{(\sigma+\eta+1-(\sigma'+\eta'))}(y; \sigma', \eta') \right\}.

The function \(u_\alpha(x; \sigma, \eta)\) is continuous but not continuously differentiable. The only point of discontinuity of the derivative is \(s_\alpha(\sigma, \eta)\). However we can consider the discontinuous function \(u_\alpha(x; \sigma, \eta)\) and write

u'_\alpha(x; \sigma, \eta) = -c + l^{(\sigma+\eta)}(x) + \chi_\alpha(x; \sigma, \eta).

After some calculations we can write the equations

(13.5.28) 
 \chi_\alpha(x; \sigma, \eta) = \begin{cases} \mu_\alpha^{(\sigma+\eta)}(x) + \alpha E \chi_\alpha^{(\sigma+\eta+1-(\sigma'+\eta'))}(x; \sigma', \eta'), & x \ge s_\alpha(\sigma, \eta) \\ 0, & x \le s_\alpha(\sigma, \eta) \end{cases}

and

(13.5.29) 
 \mu_\alpha(x) = c(1 - \alpha) + \alpha h - \alpha(h + p)\bar{F}(x).

The continuity condition is then expressed as follows

(13.5.30) 
 0 = K + \inf_{y > s_\alpha(\sigma, \eta)} \int_{s_\alpha(\sigma, \eta)}^y \chi_\alpha(\xi; \sigma, \eta) d\xi

If we define

(13.5.31) 
 G_\alpha(x; \sigma, \eta) = cx + \alpha E u_\alpha^{(\sigma+\eta+1-(\sigma'+\eta'))}(x; \sigma', \eta'),

then we can write

(13.5.32) 
 u_\alpha(x; \sigma, \eta) = -cx + l^{(\sigma+\eta)}(x) + G_\alpha(\max(x, s_\alpha(\sigma, \eta)); \sigma, \eta),

and thus

(13.5.33) 
 \chi_\alpha(x; \sigma, \eta) = G'_\alpha(x; \sigma, \eta) \mathbb{1}_{x > s_\alpha(\sigma, \eta)}.
