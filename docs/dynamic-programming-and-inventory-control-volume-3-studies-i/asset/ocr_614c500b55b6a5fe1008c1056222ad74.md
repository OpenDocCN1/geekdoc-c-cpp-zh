For $\max(-m_0, x) \le x + v \le \max(x^+, m_0)$, we have assuming $M > m_0$

```
$$\sup_{|x| \le M \\ z} |\Phi^v u(x, z)| \le C + \frac{CM}{1 - \delta_0(2M)}$$
```

We also have

```
$$\sup_{|x| \le M \\ z} |\Phi^v (\bar{u}_\alpha - u)(x, z)| \le \sup_{|x| \le M \\ z} |\bar{u}_\alpha - u(x, z) \sup F(N, z) \\ + \sup_{|x| \le M \\ z} |\bar{u}_\alpha - u(x, z)|$$
```

Using the assumption (12.5.26) and (12.5.40), letting first $\alpha \to 1$, then $N \to \infty$, we deduce

```
$$\sup_{|x| \le M} |L_\alpha(x, z, v) - L(x, z, v)| \to 0, \text{ as } \alpha \to 1.$$
```

Therefore we deduce easily (12.5.31) and also that the pair $u(x, z), \rho$ satisfies (12.5.34). The estimates (12.5.32), (12.5.33) follow immediately from the corresponding ones on $\bar{u}_\alpha(x, z)$. The $K-$convexity of $u$ follows from the $K-$convexity of $\bar{u}_\alpha$. The proof has been completed.

# 12.6. LEARNING PROCESS

**12.6.1. MODEL.** We follow in this section [33]. We have already considered an example of Markov demand in section 12.2, Example 12.1, in which the Markov dependence was obtained trough a parameter of the probability law of the demand. The probability law of the demand $z_{n+1}$ depends on a parameter, namely $f(x, \lambda)$, but $\lambda$ is not fixed. It is a function of $z_n, \lambda(z_n)$. We show here how the common learning procedure, which is quite natural when a parameter is not really known, but is updated in function of the available information leads to a similar situation. We consider only the inventory model with backlog, to fix the ideas. So we have

```
$$(12.6.1) \quad y_{n+1} = y_n + v_n - z_{n+1}, y_1 = x.$$
```

The probability density of $z_{n+1}$ is $f(z, \lambda_n)$ where $\lambda_n$ is the value given to the parameter $\lambda$, at time $n$. Instead of writing $\lambda_n = \lambda(z_n)$, we express an evolution

```
$$(12.6.2) \quad \lambda_{n+1} = \rho(\lambda_n, z_{n+1}), \lambda_1 = \lambda.$$
```

The pair $y_n, \lambda_n$ is a controlled Markov chain, whose operator is given by

```
$$(12.6.3) \quad \Phi^v \varphi(x, \lambda) = E[\varphi(x+v-z_2, \rho(\lambda, z_2))] \\ = \int \varphi(x+v-\zeta, \rho(\lambda, \zeta)) f(\zeta, \lambda) d\zeta$$
```

The observation process is the demand. So we define the filtration

```
$$\mathcal{F}^n = \sigma(z_2, \cdots, z_n), n \ge 2 \\ \mathcal{F}^1 = (\emptyset, \emptyset)$$
```
