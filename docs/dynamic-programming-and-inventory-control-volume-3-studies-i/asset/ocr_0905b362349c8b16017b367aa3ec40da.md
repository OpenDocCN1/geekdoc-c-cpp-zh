# **Theorem 12.12.** We assume (12.5.3), (12.5.4), with \(c_0=0\), (12.5.22), (12.5.23), (12.5.25), (12.5.26). Then there exists a number \(\rho_\alpha\) such that, for a subsequence, still denoted \(\alpha \to 1\)

```
(12.5.31)
$$
\sup_{|x| \le M} \left| u_\alpha(x,z) - \frac{\rho_\alpha}{1-\alpha} - u(x,z) \right| \to 0, \forall M,
$$
```

and \(\rho_\alpha \to \rho\). The function \(u(x,z)\) is Lipschitz continuous, \(K\)-convex and satisfies

```
(12.5.32)
$$
|u(x,z)| \le C + \frac{C(x+m_0)^+}{1-\delta_0((x+m_0)^+)} + C(x+m_0)^-
$$
```

```
(12.5.33)
$$
|u_x(x,z)| \le \frac{C}{1-\delta_0((x+m_0)^+)}; |u_z(x,z)| \\
\le C + \frac{C(\max(x^+,m_0)+m_0)}{1-\delta_0(\max(x^+,m_0)+m_0)} a.e.
$$
```

The pair \(u(x,z), \rho\) is the solution of

```
(12.5.34)
$$
u(x,z) + \rho = \inf_{v \ge 1} [K \mathbb{I}_{v>0} + l(x,v) + \Phi^v u(x,z)].
$$
```

PROOF. We set

```
$$
\chi_\alpha(x,z) = u'_\alpha(x,z) - h \mathbb{I}_{x>0} + p \mathbb{I}_{x<0} + c,
$$
```

then we can write

```
(12.5.35)
$$
\chi_\alpha(x,z) = \mathbb{I}_{x>s_\alpha(z)} \{ \mu_\alpha(x,z) + \alpha E[\chi_\alpha(x-s_2,z_2)|z_1=z] \},
$$
```

with

```
$$
\mu_\alpha(x,z) = c + \alpha(h-c) - \alpha(h+p)\bar{F}(x|z)
$$
```

The function \(\chi_\alpha(x,z)\) is not continuous, but satisfies (since \(s_\alpha(z) \ge -m_0\))

```
(12.5.36)
$$
\sup_{\xi \le x} |\chi_\alpha(\xi,z)| \le \frac{\max(h,p)}{1-\delta_0(x^++m_0)}.
$$
```

Let us next define \(\Gamma_\alpha(z) = u_\alpha(-m_0, z)\). We have

```
$$
\begin{aligned}
\Gamma_\alpha(z) &= G_\alpha(s_\alpha(z), z) + (p+c)m_0 \\
&= c s_\alpha(z) + \alpha E[u_\alpha(s_\alpha(z)-z_2, z_2)|z_1=z] + (p+c)m_0 \\
&= g_\alpha(s_\alpha(z), z) + \alpha E[\Gamma_\alpha(z_2)|z_1=z] \\
&+ \alpha E \left[ \int_{-m_0}^{s_\alpha(z)-z_2} \chi_\alpha(\xi, z_2) d\xi | z_1=z \right]
\end{aligned}
$$
```

with

```
(12.5.37)
$$
\begin{aligned}
g_\alpha(x,z) &= c(1-\alpha)x + \alpha E[h(x-z_2)^+ + p(x-z_2)^-] \\
&+ c E[z_2|z_1=z] + (p+c)m_0(1-\alpha)
\end{aligned}
$$
```

Therefore we can write

```
(12.5.38)
$$
\Gamma_\alpha(z) = \Psi_\alpha(z) + \alpha E[\Gamma_\alpha(z_2)|z_1=z],
$$
```
