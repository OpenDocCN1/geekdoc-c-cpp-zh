15.6.4. CHAPMAN-KOLMOGOROV EQUATION. From the formula (15.6.34) we can see that \(y_\tau(t)\) has a density for any \(t > 0\). This follows directly that the fact that \(x - D(t)\) has a density for \(t > 0\). Therefore for \(\varphi(x) \ge 0\),

```
\(\Psi(x, t) \le E\varphi(x - D(t)) = \int \varpi(\xi, t)\varphi(\xi)d\xi,\)
```

where \(\varpi(\xi, t)\) is the density of \(x - D(t)\). Therefore we can write

```
\(z(x, t) = E\varphi(y_\tau(t)) = \int p(\xi, t)\varphi(\xi)d\xi,\)
```

and \(p(\xi, t)\) is the density of the variable \(y_\tau(t)\). Formally we can write

```
\(p(\xi, 0) = \delta(\xi - x).\)
```

Since \(z(x, t) = 0\) if \(\varphi = 0\) on \((s, +\infty)\) (see formula (15.6.34) again) we have \(p(\xi, t) = 0\) for \(\xi \le s\). The Chapman-Kolmogorov equation describes the evolution of \(p(\xi, t)\). With considerations similar as those for the invariant measure we can derive this equation and obtain

```
(15.6.41) \(\frac{\partial p}{\partial t} - \frac{\sigma^2}{2} \frac{\partial^2 p}{\partial \xi^2} - \nu \frac{\partial p}{\partial \xi} - \lambda \int_0^{+\infty} (p(\xi + \eta, t) - p(\xi, t)) \mu(\eta) d\eta = 0, \quad \text{if } \xi > s\)
\(p(\xi, t) = 0, \quad \text{if } \xi \le s\)
\(p(\xi, 0) = \delta(\xi - x)\)
```

We have proven the weak convergence

```
\(\int p(\xi, t)\varphi(\xi)d\xi \to \int m(\xi)\varphi(\xi)d\xi, \quad \text{as } t \to +\infty.\)
```

Note that \(\frac{\partial p}{\partial \xi}\) has a discontinuity in \(S\) with the relation

```
\(\frac{\sigma^2}{2} \left( \frac{\partial p}{\partial \xi}(S+0, t) - \frac{\partial p}{\partial \xi}(S-0, t) + \frac{\partial p}{\partial \xi}(s+0, t) \right) + \lambda \int_s^{+\infty} p(x, t) \int_{x-s}^{+\infty} \mu(\xi) d\xi = 0.\)
```

We do not develop details on the Chapman-Kolmogorov equation, since it has no explicit solution, and all results on ergodic theory can bypass this equation.
