## A.1. PROOF OF LEMMAS

### A.1.1. PROOF OF LEMMA 4.1.

PROOF. Let us denote by d(x, y) the distance on X. We can assume that \( f \neq +\infty \), otherwise f_n(x) = n has the required properties. We then define

(A.1.1) 
\( g_n(x) = \inf_{y \in X} [f(y) + nd(x, y)], \)

then g_n(x) is uniformly continuous. Indeed

\( |g_n(x) - g_n(x')| \le nd(x, x'). \)

Let next

\( f_n(x) = \min(n, g_n(x)), \)

then f_n = \min(n, g_n) belongs to C(X). Moreover, it is an increasing sequence. We have f_n(x) \le f(x). Suppose f(x) < \infty, then since g_n(x) \le f(x), we can assert that f_n(x) = g_n(x) for n sufficiently large. Moreover since f is l.s.c. and bounded below, there exists y_n = y_n(x) such that

\( g_n(x) = f(y_n) + nd(x, y_n). \)

Since this expression is bounded above and f is bounded below, one obtains easily that y_n \to x, as n \uparrow \infty. Since f is l.s.c we have

\( f(x) \le \liminf f(y_n) \le \liminf g_n(x). \)

But also \limsup g_n(x) \le f(x). Therefore g_n(x) \uparrow f(x). Hence also f_n(x) \uparrow f(x). Suppose now f(x) = +\infty. Necessarily g_n(x) \uparrow +\infty. Otherwise g_n(x) remains bounded above by a constant A_x, which is impossible. Indeed, considering y_n as above, we have y_n \to x, and by lower semi continuity of f, it follows f(x) \le A_x, which contradicts the assumption. Finally if g_n(x) \uparrow +\infty we have also f_n(x) \uparrow +\infty, which completes the proof.

### A.1.2. PROOF OF LEMMA 4.2.

PROOF. Without loss of generality, we may assume l_v(x) = l(x, v) \ge 0. There exists a sequence l_n^v = l^n(x, v) \uparrow l(x, v) and l^n(x, v) is uniformly continuous and bounded. From assumption (4.3.1) the sequence \Phi^l l_n^v(x) is uniformly continuous and bounded. Now we can write

\(\Phi^l l_n^v(x) = \int P(x, v; d\xi) l^v(\xi, v) = \iint P(x, v; d\xi) \otimes \delta_v(\xi') l^v(\xi, \xi),\)

therefore we can apply the convexity monotone theorem to claim that

\(\Phi^l l_n^v(x) \uparrow \Phi^l l_v(x),\)

which completes the proof.

### A.1.3. PROOF OF LEMMA 4.3.

PROOF. Firstly, for any fixed x, there exists v(x) \in U such that

G(x) = F(x, v(x)).

Indeed, let us consider a sequence v_n such that F(x, v_n) \to G(x). Since v_n is in U, which is compact, we can extract a converging subsequence v_{n_k} \to v^*. Since F is l.s.c. we can write

F(x, v^*) \le G(x).

Since the reverse is also true, we have equality. So the infimum is attained. Let us now consider a sequence x_n \to x and set v_n = v(x_n). We can extract from the sequence x_n, v_n a converging subsequence x_{n_k} \to x, v_{n_k} \to v^*. Since F is l.s.c. with respect to the two arguments x, v, we can assert that

F(x, v^*) \le \liminf F(x_{n_k}, v_{n_k}) = \liminf G(x_{n_k}).

Therefore

G(x) \le F(x, v^*) \le \liminf G(x_{n_k}).

We can always assume that x_{n_k} is itself extracted from a preliminary subsequence, such that G(x_{n_k}) \to \liminf G(x_n). Therefore, G is l.s.c.

## A.2. PROOF OF MEASURABLE SELECTION

We prove now Theorem 4.1. Note that the dependence in x of v(x) defined in the proof of Lemma 4.3 is not defined. The fact that we can choose a measurable selection is essential in obtaining an optimal feedback to solve optimal stochastic control problems. The result requires multi-valued function theory. We need some concepts and preliminary results. First we have

### Lemma A.1. If f is l.s.c. then {x|f(x) \le c} is closed, for any real c.

PROOF. Indeed consider a sequence x_n such that x_n \to x, and f(x_n) \le c. Since

f(x) \le \liminf f(x_n),

we have f(x) \le c and the closedness property is proven. Note that the converse is also true. Indeed, assume x_n \to x. Let L be an accumulation point of the sequence f(x_n). There exists a subsequence x_{n_k} such that f(x_{n_k}) \to L. Let \epsilon > 0 and define

L(\epsilon) = \begin{cases} L + \epsilon, & \text{if } L > -\infty \\ -\frac{1}{\epsilon}, & \text{if } L = -\infty \end{cases}

Then for k sufficiently large k \ge k(\epsilon) we have f(x_{n_k}) \le L(\epsilon), therefore from the closedness property f(x) \le L(\epsilon), hence also f(x) \le L. Since L is an arbitrary accumulation point, necessarily f(x) \le \liminf f(x_n).

Define \mathcal{F}(U) to be the set of closed subsets of U (including the empty set). These subsets are compact. We equip \mathcal{F}(U) with a metric, the Hausdorff metric as follows (distance between sets). First, if A \neq \emptyset, A \in \mathcal{F}(U), and u \in U, we define the distance of u to A by

d(u, A) = \min_{a \in A} d(u, a).

Note that

|d(u, A) - d(v, A)| \le d(u, v).

If \( A = \mathcal{O} \), one defines

\( d(u, \mathcal{O}) = \max_{v, w \in U} d(v, w) = \text{diam} \, (U). \)

We next define for \( A, B \in \mathcal{F}(U) \)

\(\begin{aligned} \varrho(A, B) &= \max \left\{ \max_{a \in A} d(a, B), \max_{b \in B} d(b, A) \right\}, \quad \text{if } A, B \neq \mathcal{O} \\ \varrho(A, \mathcal{O}) = \varrho(\mathcal{O}, A) &= \text{diam } (U), \quad \text{if } A \neq \mathcal{O} \\ \varrho(\mathcal{O}, \mathcal{O}) &= \varrho(\mathcal{O}, \mathcal{O}) = 0. \end{aligned}\)

This defines a metric on \(\mathcal{F}(U)\) and \(\mathcal{F}(U)\) becomes a *compact metric space*.

Consider a sequence \( A_n \) of elements of \(\mathcal{F}(U)\). One defines

\(\begin{aligned} \liminf A_n &= \{ u \in U \mid \liminf d(u, A_n) = 0 \} \\ \limsup A_n &= \{ u \in U \mid \lim d(u, A_n) = 0 \} \end{aligned}\)

Obviously \(\liminf A_n \subset \limsup A_n\). Moreover, they are closed sets belonging to \(\mathcal{F}(U)\). One can check the useful property

\( \liminf A_n = \limsup A_n = A \Leftrightarrow \varrho(A_n, A) \to 0. \)

In that case, one uses the definition \( A = \lim A_n \).

If \( X \) is a metric space, a map \( \Psi : X \to \mathcal{F}(U) \) is called a *multi valued map*. Since \( X \) and \(\mathcal{F}(U)\) are metric spaces, we have naturally the concepts of continuous, l.s.c, u.s.c and Borel functions. However, two additional concepts can be defined. These additional concepts have been introduced by K. Kuratowski, see [30]. This is why they are called (K) u.s.c or (K) l.s.c. We say that \( \Psi \) is (K) u.s.c if

\( x_n \to x \Rightarrow \limsup \Psi(x_n) \subset \Psi(x). \)

Similarly, one says that \( \Psi \) is (K) l.s.c. when

\( x_n \to x \Rightarrow \liminf \Psi(x_n) \supset \Psi(x). \)

One can prove that if \( \Psi \) is both (K) u.s.c and (K) l.s.c. then it is continuous. In fact, the most useful concept is that of (K) upper semi continuity. The reason comes these two essential properties:

(A.2.1) \( \Psi \text{ (K) u.s.c} \Rightarrow \Psi \text{ is Borel} \)

Next (A.2.2)

If \( \Psi \) is (K) u.s.c, and G is an open subset of U, then \( \{x \in X | \Psi(x) \subset G\} \) is open.

The second property shows that the concept of (K) u.s.c. reduces to continuity for ordinary functions.

### Lemma A.2. Let \( U \) be metric compact and \( g : U \to ]-\infty, +\infty[ \) be l.s.c. Define \( g^* : \mathcal{F}(U) \to ]-\infty, +\infty[ \) by

(A.2.3) \( g^*(A) = \begin{cases} \min_{u \in A} g(u), & \text{if } A \neq \mathcal{O} \\ +\infty, & \text{if } A = \mathcal{O} \end{cases} \)

then \( g^* \) is l.s.c.
