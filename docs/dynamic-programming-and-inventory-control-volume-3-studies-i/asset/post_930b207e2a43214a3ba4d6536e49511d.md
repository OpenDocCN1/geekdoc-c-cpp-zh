
Let \(\mu_\alpha(x) = g'_\alpha(x)\), then

(10.2.5) \(H_{\alpha, s}(x) = \int_s^x \Gamma_\alpha(x - \xi) \mu_\alpha(\xi) d\xi,\)

where \(\Gamma_\alpha(x)\) is the solution of the renewal equation

(10.2.6) \(\Gamma_\alpha(x) = 1 + \alpha \int_0^x f(x - \xi) \Gamma_\alpha(\xi) d\xi.\)

We define the function \(S_\alpha(s)\) such that

(10.2.7) \(\inf_{\eta \ge s} H_{\alpha, s}(\eta) = H_{\alpha, s}(S_\alpha(s)),\)

and the pair \(s_\alpha, S_\alpha\) is defined by the relations

(10.2.8) \(\inf_{\eta \ge s_\alpha} H_{\alpha, s_\alpha}(\eta) + K = 0, \quad S_\alpha = S_\alpha(s_\alpha).\)

We know that

(10.2.9) \(0 \le s_\alpha \le \bar{s}_\alpha,\)

with

(10.2.10) \(c(1 - \alpha) + \alpha h - (p - \alpha(c - h))\bar{F}(\bar{s}_\alpha) = 0.\)

Finally

(10.2.11) \(u_\alpha(x) = H_{\alpha, s_\alpha}(x) + (h - c)x + \frac{g_\alpha(s_\alpha)}{1 - \alpha}.\)

We want to study the behavior of \(u_\alpha(x)\) as \(\alpha \uparrow 1\).

## 10.2.2. CONVERGENCE.

We shall make the assumption

(10.2.12) \(F(x) < 1, \forall x.\)

Thanks to the assumption (10.2.12) the function \(\Gamma_\alpha(x)\) converges to \(\Gamma(x)\) where

\(\Gamma(x) = \sum_{n=0}^\infty F^{(n)}(x).\)

We note that

\(\Gamma(x) \le \frac{1}{1 - F(x)};\)

and \(\Gamma(x)\) is the solution of the renewal equation

(10.2.13) \(\Gamma(x) = 1 + \int_0^x f(x - \xi) \Gamma(\xi) d\xi.\)

We have next

(10.2.14) \(\mu_\alpha(x) \to \mu(x) = h - (p - c + h)\bar{F}(x).\)

Similarly

(10.2.15) \(\begin{aligned} g_\alpha(x) \to g(x) &= hx + p\bar{D} - (p - c + h) \int_0^x \bar{F}(\xi) d\xi \\ &= hx + (c - h)D + (p - c + h)E(x - D)^- \end{aligned}\)

The function

(10.2.16) \(H_{\alpha, s}(x) \to H_s(x) = \int_s^x \Gamma(x - \xi) \mu(\xi) d\xi.\)

Assuming (9.2.12) we define \(\bar{s}\) such that \(\mu(\bar{s}) = 0\), and \(\mu(s) < 0, \forall 0 \le s < \bar{s}\), \(\mu(s) > 0, \forall s > \bar{s}\).

**Lemma 10.1.** The minimum of \(H_s(x)\) for \(x \ge s\) is attained in points strictly larger than \(\bar{s}\). Moreover \(\min_{x \ge s} H_s(x) < 0\).

Proof. Unlike what has been done for \(H_{\alpha,s}(x)\), we cannot rely on the fact that \(H_{\alpha,s}(x) \to +\infty\) as \(x \to +\infty\). This is because \(\Gamma(x)\) is not a priori bounded like \(\Gamma_\alpha(x)\). For \(s < \bar{s}\), we can assume that \(s \le \bar{s}_\alpha\). Therefore we have

\(s \le \bar{s}_\alpha < S_\alpha(s) < S_\alpha(0).\)

Recalling that

\(\Gamma_\alpha(S_\alpha(0)) = \frac{p - \alpha(c - h)}{p - \alpha(p - h)},\)

we can assert that \(S_\alpha(0) \to S(0)\) solution of

(10.2.17) \(\Gamma(S(0)) = \frac{p - c + h}{h}.\)

Therefore we can extract a subsequence of \(S_\alpha(s)\) which converges to \(S^*_s\). Clearly \(s < \bar{s} \le S^*_s \le S(0)\).

Clearly \(H_{\alpha,s}(S_\alpha(s)) \to H_s(S^*_s)\). Since \(H_{\alpha,s}(S_\alpha(s)) \le H_{\alpha,s}(x), \forall x \ge s\), we get also \(H_s(S^*_s) \le H_s(x), \forall x \ge s\). Therefore \(H_s(S^*_s) = \inf_{x \ge s} H_s(x)\). So the infimum is attained. Since \(H_s(\bar{s}+) < 0\), the infimum is not attained in \(s\) and is strictly negative. Note that \(S^*_s\) is solution of the equation

(10.2.18) \(\Gamma(S - s)\mu(s) + (p - c + h) \int_s^{S^*} \Gamma(S - \xi) f(\xi) d\xi = 0,\)

and thus we cannot have \(S^*_s = s\), if \(s < \bar{s}\).

We then define in a unique way the smallest minimum, called \(S(s)\) and \(S(s) > \bar{s}\). Moreover \(S(s) = s, \forall s \ge \bar{s}\).

We have again

\(\frac{d}{ds} H_s(S(s)) = -\Gamma(S(s) - s)\mu(s) > 0, 0 \le s < \bar{s}.\)

The function \(H_s(S(s))\) increases from \(H_0(S(0))\) to 0 when \(s\) goes from 0 to \(\bar{s}\).

Assume

(10.2.19) \(H_0(S(0)) < -K,\)

then there exists a unique \(s\) such

(10.2.20) \(H_s(S(s)) = -K.\)

**Theorem 10.2.** We assume (9.2.12), (10.2.12), (10.2.19), then we have

(10.2.21) \(s_\alpha \to s, \quad S_\alpha \to S;\)

(10.2.22) \(u_\alpha(x) = \frac{g_\alpha(s_\alpha)}{1-\alpha} \to u(x) = H(x) + (h-c)x.\)

**Proof.** We use again the fact that \(S_\alpha(s)\) is decreasing, see Proposition 9.3. Hence \(S_\alpha = S_\alpha(s_\alpha) \le S_\alpha(0)\), which remains bounded. We have \(S_\alpha(0) \to S(0) = S_0\) (to shorten the notation). Also \(H_\alpha(0, S_\alpha(0)) \to H_0(S_0)\). Therefore, from the assumption (10.2.19), we can assume that, for \(\alpha\) sufficiently close to 1, \(H_\alpha(0, S_\alpha(0)) < -K\). Therefore the pair \(s_\alpha, S_\alpha\) is well defined, and these numbers remain bounded. So we can extract a subsequence which converges to \(s^*, S^*\). From the expression of \(H_\alpha(x)\), we easily deduce that \(H_{\alpha, s_\alpha}(S_\alpha) = -K \to H_{s^*}(S^*)\). From this one obtains that \(s^* = s, S^* = S\), defined by equations (10.2.20), (10.2.18).

Note that

(10.2.24) \(g(x) = hx + p \int_x^\infty F(\xi) d\xi + (c-h) \int_0^x F(\xi) d\xi,\)

so it is a positive function, thanks to the assumption (9.2.12). Hence \(\rho > 0\). Clearly \((1-\alpha)u_\alpha(x) - g_\alpha(s_\alpha) \to 0, \text{ as } \alpha \uparrow 1,\)

hence

\((1-\alpha)u_\alpha(x) \to \rho = g(s).\)

We recall that we have also

\(H(x) + \rho = g(x) + EH((x-D)^+), \forall x \ge s; H(x) = 0, \forall x \le s,\)

where \(H(x) = H_s(x)\), defined by (10.2.16), for the specific \(s\), limit of \(s_\alpha\). Let us check that these conditions can be summarized into

(10.2.25) \(H(x) + \rho = + \inf_{\eta \ge x} [K \mathbf{1}_{\eta > x} + g(\eta) + EH((\eta - D)^+)].\)

If (10.2.25) is satisfied, then the equation for \(u\) (10.2.23) follows immediately, using the definition of \(g(x)\).

Let us check (10.2.25). Take first \(x \le s\). Then \(H(x) = 0\). If we express the right hand side of (10.2.25), then we have to consider the case \(\eta = x\) and \(\eta > x\). For \(\eta = x\) we have

\(-\rho + g(x) + EH((x-D)^+) = g(x) - g(s) > 0,\)

since \(x < s < \bar{s}\). On the other hand for \(x < \eta < s\) we have

\(-\rho + K + g(\eta) + EH((\eta - D)^+) = -\rho + K + g(\eta),\)

which is decreasing. Therefore

\(-\rho + K + \inf_{\eta \ge x} [g(\eta) + EH((\eta - D)^+)]\)
\(= -\rho + K + \inf_{\eta \ge x} [g(\eta) + EH((\eta - D)^+)]\)
\(= -\rho + K + \inf_{\eta \ge x} [H(\eta) + g(s)] = 0.\)

Hence (10.2.25) is verified for \(x \le s\). Assume \(x > s\). Then

(10.2.26) \(-\rho + \inf_{\eta \ge x} [K \mathbf{1}_{\eta > x} + g(\eta) + EH((\eta - D)^+)] = \inf_{\eta \ge x} [K \mathbf{1}_{\eta > x} + H(\eta)].\)

But, from (12.5.3) we have, denoting \(H_\alpha(x) = H_{\alpha, s_\alpha}(x)\)

\(H_\alpha(x) \le K + \inf_{\eta \ge x} H_\alpha(\eta), \forall x \ge s_\alpha.\)

But \( H_{\alpha, s_\alpha}(x) \to H(x) \). We pass to the limit and obtain

\( H(x) \le K + \inf_{\eta \ge x} H(\eta), \forall x \ge s \)

and the right hand side of (10.2.26) is \( H(x) \). This completes the proof of the Theorem.

## 10.2.3. PROBABILISTIC INTERPRETATION.

We give now the interpretation of \( \rho \) and of the solution \( u(x) \) of (10.2.23). We first associate to an \( s, S \) policy an invariant measure \( m_{s, S}(dx) \). Moreover the infimum in equations (10.2.23), (10.2.25) is attained by a feedback \( \hat{v}(x) \) associated to an \( s, S \) policy. We still denote it \( s, S \) to save notation.

It is convenient to notice that

(10.2.27) \( l(x, v) = p\bar{D} + (h - p)x + \mathbb{I}_{v > 0}(K + (c - p)v) + pE(x + v - D)^+, \text{and} \)

and

(10.2.28) \( l(x, \hat{v}(x)) = p\bar{D} + (h - p)x + \mathbb{I}_{x \le S}(K + (c - p)(S - x)) + p[\mathbb{I}_{x \le S}E(S - D)^+ + \mathbb{I}_{x > S}E(x - D)^+], \)

and (10.2.23) reads

(10.2.29) \( u(x) = l(x, \hat{v}(x)) - \rho + Eu(x + \hat{v}(x) - D). \)

Let us denote by \( m_{h_c(x)}(dx) \) the invariant measure \( m_{s, S}(dx) \), for consistency of notation. It follows from (10.2.29) that

(10.2.30) \( \rho = \int l(x, \hat{v}(x))m_{h_c(x)}(dx). \)

Note that the state space of \( m_{h_c(x)}(dx) \) is \( [0, S] \) but can be taken as \( [0, \infty) \) to work with a fixed state space. Now define the set \( \mathcal{U}_b \) of feedbacks such that

(10.2.31) \( \mathcal{U}_b = \{v(.) \ge 0 | \exists M \text{ such that } x + v(x) \le \max(x, M)\} . \)

If \( v(.) \in \mathcal{U}_b \), necessarily \( v(x) = 0 \), if \( x \ge M \). The Markov chain, controlled with the feedback \( v(.) \) is ergodic with state space \( [0, M] \). We denote the corresponding invariant measure by \( m_{v(.)}(dx) \). Note that a feedback defined by an \( s, S \) policy belongs to \( \mathcal{U}_b \). We then have

**Theorem 10.3.** We make the assumptions of Theorem 10.2. We have

(10.2.32) \( \rho = \inf_{v(.) \in \mathcal{U}_b} \int l(x, v(x))m_{v(.)}(dx), \)

and there exists an optimal feedback, defined by an \( s, S \) policy. This \( s, S \) policy has been defined in Theorem 10.2.

Proof. Consider a feedback \( v(.) \) in \( \mathcal{U}_b \). From (10.2.23) we can state

(10.2.33) \( u(x) + \rho \le l(x, v(x)) + Eu(x + v(x) - D)^+. \)

Integrating with respect to the invariant measure \( m_{v(.)}(dx) \) yields

\( \rho \le \int l(x, v(x))m_{v(.)}(dx). \)

Taking account of (10.2.30) the result follows immediately.
