We are going to chow, by induction, that both \(u_n(x,z), G_n(x,z)\) are \(K-\)convex in \(x\), continuous and \(\rightarrow +\infty\) as \(|x| \rightarrow +\infty\), for \(n \ge 2\). Also

(12.5.16) \(u'_n(x,z) \le -p - c, G'_n(x,z) \le c(1-\alpha) - \alpha p, \text{ if } x < 0.\)

These relations will be true for \(n \ge 2\). We have \(G'_0(x,z) = c\) and \(u'_1(x,z) = -p\), if \(x < 0\). Then

\(G'_n(x,z) = c - \alpha p < 0, \text{ if } x < 0\)

As soon as \(G'_n(x,z) \le 0, \text{ for } x < 0\), then \(u'_{n+1}(x,z)\) satisfies (12.5.16) and \(G'_{n+1}(x,z)\) satisfies also (12.5.16).

Since \(G_n(x,z)\) is \(K-\)convex in \(x\), continuous and \(\rightarrow +\infty\) as \(|x| \rightarrow +\infty\), we can define \(s_n(z), S_n(z)\) with

(12.5.17) \(G_n(S_n(z), z) = \inf_\eta G_n(\eta, z),\)

and \(s_n(z)\) is defined by

(12.5.18) \(G_n(s_n(z), z) = K + \inf_\eta G_n(\eta, z).\)

As usual we take the smallest minimum to define \(S_n(z)\) in a unique way. Since \(G_n(\eta, z)\) is continuous, it is easy to check that \(S_n(z)\) is continuous. Also \(s_n(z)\) is continuous.

We can write

\(u_{n+1}(x,z) = hx^+ + px^- - cx + G_n(\max(x, s_n(z)), z)\)

which shows immediately that \(u_{n+1}(x,z)\) and then \(G_{n+1}(x,z)\) are \(K-\)convex and continuous. Furthermore \(u_{n+1}(x,z), G_{n+1}(x,z) \rightarrow +\infty\), as \(x \rightarrow +\infty\).

Since for \(x < 0\)

\(u'_{n+1}(x,z) = -p + c + G'_n(x) 1_{x > s_n(z)},\)

we see that (12.5.16) is satisfied for \(u_{n+1}, G_{n+1}\). Therefore \(u_{n+1}(x,z), G_{n+1}(x,z) \rightarrow +\infty\) as \(x \rightarrow -\infty\).

So the recursion is proven. Note also that \(S_n(z) > 0\).

If we write (formally)

\(u'_n(x,z) = h 1_{x > 0} - p 1_{x < 0} - c + \chi_n(x,z),\)

then one has the recurrence

\(X_{n+1}(x,z) = \begin{cases} 0 & \text{if } x < s_n(z) \\ = \mu(x,z) + \alpha E[\chi_n(x - z_2, z_2) | z_1 = z] \end{cases}\)

with

(12.5.19) \(\mu(x,z) = c(1-\alpha) + \alpha h - \alpha(p+h)\bar{F}(x|z).\)

The function \(X_{n+1}(x,z)\) is discontinuous in \(s_n(z)\). However one has the bound

\(\frac{c(1-\alpha) - \alpha p}{1-\alpha} \le X_{n+1}(x,z) \le \frac{c(1-\alpha) + \alpha h}{1-\alpha} \quad \text{a.e.}\)

Note also \(X_n(x,z) \le 0\), if \(x < 0\) and

\(X_{n+1}(x,z) \le c(1-\alpha) - \alpha p, \text{ if } s_n(z) < x < 0\)
