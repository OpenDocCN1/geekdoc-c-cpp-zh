We deduce \(u(0,z) = \Gamma(z)\). Moreover, one checks easily that

\(\Gamma(z) = \rho + cS(z) + E[u(S(z) - z_2, z_2)|z_1 = z].\)

Therefore the first relation (13.2.28) is proven.

Consider now the situation with \(x \ge S(z)\). Define the function

\(\bar{u}(x,z) = hx^+ + px^- + E[u(x - z_2, z_2)|z_1 = z].\)

We obtain

\(\begin{aligned} \bar{u}'(x,z) &= h\mathbb{I}_{x>0} - p\mathbb{I}_{x<0} + E[u'(x-z_2, z_2)|z_1 = z] \\ &= h\mathbb{I}_{x>0} - p\mathbb{I}_{x<0} + c + \chi(x,z), \quad x \ge S(z) \\ &= u'(x,z), \quad x \ge S(z). \end{aligned}\)

Also

\(\begin{aligned} \bar{u}(S(z), z) &= hS(z) + E[u(S(z) - z_2, z_2)|z_1 = z] \\ &= (h - c)S(z) + \rho + \Gamma(z) \\ &= u(S(z), z) + \rho \end{aligned}\)

From these two relations we get \(\bar{u}(x,z) = u(x,z) + \rho, \forall x \ge S(z)\).

This concludes the second part of (13.2.28).

The proof of (12.3.40) is similar to that of Theorem 12.3.

We have next

\(u_\alpha(x,z) - u_\alpha(x,z') = \Gamma_\alpha(z) - \Gamma_\alpha(z') + \int_0^x (\chi_\alpha(\xi,z) - \chi_\alpha(\xi,z')) d\xi\)

Using already proven estimates we obtain

\(|u_\alpha(x,z) - u_\alpha(x,z')| \le \left[ C_1(m_0) + \frac{C(m_0)x^+}{1 - \delta_0(x)} \right] \delta|z - z'|\)

The limit \(u(x,z)\) satisfies all the estimates (12.3.37), (12.3.39). The proof of uniqueness is similar to that of Theorem 12.3.

The proof has been completed \(\square\)
