
However we have the property

$$ \int_0^{ +\infty } \Gamma (\xi ) d\xi = +\infty . $$

Indeed if we consider for \(\pi < 0\)

$$ \hat{\Gamma} (\pi ) = \int_0^{ +\infty } \exp \xi \pi \Gamma (\xi ) d\xi , $$

we deduce from the equation (15.5.14) that

$$ \hat{\Gamma} (\pi ) = \frac{\sigma ^2 \pi - \beta _2}{2 - \chi (\pi )}. $$

As \(\pi \uparrow 0\), we know that \(\chi (\pi ) \to 0\), hence \(\hat{\Gamma} (\pi ) \uparrow +\infty \), which implies (15.5.17). We can then define a unique \(B(\bar{s})\) such that

$$ \int_0^{B(\bar{s})} \Gamma (\xi ) d\xi = \frac{p(x_0 - \bar{s})}{h}, $$

and thus

$$ S^M(\bar{s}) \le B(\bar{s}), $$

and letting \(M \uparrow +\infty \), we get the property (15.5.16).

Let us take \(s < x_0\). We can assume also for \(\alpha\) small \(s < x_{0\alpha}\). Therefore \(H_\alpha (s, S_\alpha (s)) = 0\). From the estimate (15.5.16) we can assume that for \(\alpha\) small \(S_\alpha (s)\) remains bounded by \(2B(\bar{s})\). By extracting a subsequence such that \(S_\alpha (s) \to S^*\) we obtain easily \(H_1(S^*) = 0\) and also

$$ \gamma_\alpha (s) \to \gamma (s) = \inf_{\eta > s} \int_s^\eta H_s (\xi ) d\xi = \int_s^{S^*} H_s (\xi ) d\xi $$

We call again \(S(s)\) the first point such that \(H_1(S(s)) = 0\).

We have shown above, in the proof of Theorem 15.1 that

$$ \gamma'_\alpha (s) \ge - \frac{Q_\alpha (s_1)}{\beta_{0\alpha }} (1 - \exp -\beta_{0\alpha } (x_{0\alpha } - s_1)) > 0, $$

whenever \(s < s_1 < x_{0\alpha}\). Let us fix \(s_1 < x_0\). For \(\alpha\) sufficiently small we can assume \(s_1 < x_{0\alpha}\) and for \(s < s_1\)

$$ \gamma'_\alpha (s) \ge - \frac{Q(s_1)}{2\beta _0} (1 - \exp -\beta _0 (x_0 - s_1)) = a(s_1) > 0, $$

and thus

$$ \gamma_\alpha (s_1) - \gamma_\alpha (s) \ge (s_1 - s)a(s_1). $$

Since \(\gamma_\alpha (s_1) < 0\), in fact

$$ -\gamma_\alpha (s) \ge (s_1 - s)a(s_1). $$

Consider now \(s_\alpha\). Either \(s_\alpha \ge s_1\) or \(s_\alpha < s_1\) in which case from the inequality above

$$ K \ge (s_1 - s_\alpha )a(s_1). $$

So in all cases

(15.5.18) 
$$ s_\alpha \ge s_1 - \frac{K}{a(s_1)} = \bar{s}, $$

But then from (15.5.16) we can also assert that

(15.5.19) 
$$ S_\alpha = S_\alpha (s_\alpha ) \le 2B(\bar{s}), $$

for \(\alpha\) sufficiently small. Therefore we can extract a subsequence such that \(s_\alpha \to s, S_\alpha \to S\). Also \(\gamma(s) = -K\). However, for the same reasons as for \(s_\alpha\), there is a unique \(s\) which satisfies this relation. Hence the full sequence \(s_\alpha \to s\). Define

(15.5.20) 
$$ \rho_\alpha = \alpha G_{\sigma_\alpha}(s_\alpha) \to \rho = \frac{\sigma^2}{2} Q(s) + f(s) + c\nu + c\lambda \tilde{\xi}, $$

We can then set

$$ \tilde{G}_\alpha(x) = G_\alpha(x) - \frac{\rho_\alpha}{\alpha}, $$

and claim the following ergodic result

**Theorem 15.3.** We assume (15.2.4). The function \(G_\alpha(x)\), (respectively its derivative) converges uniformly on compact sets to \(G(x)\), (respectively its derivative) and the pair \(G(x), \rho\) is the solution of the Q.V.I.

(15.5.21) 
$$ \begin{aligned} AG(x) + \rho \le l(x) \\ G(x) \le K + \inf_{\eta > x} G(\eta) \\ (AG(x) + \rho - l(x))(G(x) - K + \inf_{\eta > x} G(\eta)) = 0, \end{aligned} $$

with

\(l(x) = f(x) + cv + c\lambda \tilde{\xi}.\)

The function \(G(x)\) is \(C^1\), its derivative has linear growth. It is given by an \(s, S\) policy

(15.5.22) 
$$ \begin{aligned} AG(x) + \rho = l(x), \quad x > s \\ G(x) = K + \inf_{\eta > x} G(\eta), \quad x \le s \end{aligned} $$

## 15.6. PROBABILISTIC INTERPRETATION

We will develop in this section the probabilistic counterpart of the Q.V.I approach of the previous sections. We extend the approach of [32] to the diffusion and Poisson case. The idea is to optimize in the class of \(s, S\) policies and to show that we solve the Q.V.I in this way.

### 15.6.1. STUDY OF THE PROCESS WITH AN \(s, S\) CONTROL.

Let \(s < S\) two given numbers. We will define the process \(y_x^{s,S}(t)\) subject to an \(s, S\) policy, with initial value \(x\). Recalling the demand

$$ D(t) = \nu t + N(t) + \sigma \omega(t), $$

in the interval \(0, t\) we define

$$ \tau_x^s = \inf \{t \ge 0 \mid x - D(t) \le s\}, $$

and if \(x > s\)

$$ y_x^{s,S}(t) = x - D(t), \forall t < \tau_x^s. $$

Next we set

$$ y_x^{s,S}(\tau_x^s) = S. $$

We set

$$ \tau_{x,n}^{s,S} = \tau_x^s, $$

and suppose we have defined \(\tau_{x,n}^{s,S}\) and \(y_x^{s,S}(\tau_{x,n}^{s,S}) = S\). We then define

$$ \tau_{x,n+1}^{s,S} = \tau_{x,n}^{s,S} + \inf \{t \ge 0 \mid S - D(\tau_{x,n}^{s,S} + t) + D(\tau_{x,n}^{s,S}) \le s\}. $$

Clearly \(\tau_{x,n+1}^{s,S} > \tau_{x,n}^{s,S}\). We next set

$$ y_x^{s,S}(\tau_{x,n}^{s,S} + t) = S - D(\tau_{x,n}^{s,S} + t) + D(\tau_{x,n}^{s,S}), \forall t < \tau_{x,n+1}^{s,S} - \tau_{x,n}^{s,S}, $$

and again \(y_x^{s,S}(\tau_{x,n+1}^{s,S}) = S\). We have in this way defined the process which is controlled by an s, S policy: It has jumps at times \(\tau_{x,n}^{s,S}\), the impulse times and the size of the impulses at time \(\tau_{x,n}^{s,S}\) is \(S - y_x^{s,S}(\tau_{x,n}^{s,S}, 0)\). Note that this impulse is larger or equal to \(S - s\). The process \(y_x^{s,S}(t)\) has also jumps due to the compound Poisson part of the demand. It is a Markov process for which we are going to describe the infinitesimal generator.

Let us recall that the infinitesimal generator is the linear operator defined on the set of functions \(\varphi(x)\) such that the limit

$$ \lim_{\epsilon \to 0} \frac{E\varphi(y_x^{s,S}(\epsilon)) - \varphi(x)}{\epsilon} = \mathcal{A}^{s,S}\varphi(x), $$

is defined. Since

$$ y_x^{s,S}(s) = y_S^{s,S}(\epsilon), \forall x \le s, $$

we need to have

(15.6.1) \(\quad \varphi(x) = \varphi(S), \forall x \le s.\)

Performing the same approximate reasoning done in section 15.2, we obtain easily

$$ \mathcal{A}^{s,S}\varphi(x) = \begin{cases} -A\varphi(x), & \text{if } x > s \\ -A\varphi(s), & \text{if } x \le s \end{cases} $$

in which \(A\) is the second order differential operator defined in equation (17.2.4). Its domain is the set of functions which are bounded with bounded first and second derivatives and which satisfy (15.6.1). It is sufficient to assume that the functions \(\varphi\) and \(A\varphi\) are bounded and that (15.6.1) is satisfied. Although we refer to the domain of \(\mathcal{A}\) it will be convenient to speak of the domain of \(A\).

### 15.6.2. INVARIANT MEASURE.

We are going to show the following

**Theorem 15.4.** The process \(y_x^{s,S}(t)\) has a unique invariant measure defined as follows

$$ m^{s,S}(x) = \frac{\tilde{m}^{s,S}(x)}{\int_s^{+\infty} \tilde{m}^{s,S}(\xi) d\xi}, $$

with

(15.6.2) \(\quad \tilde{m}^{s,S}(x) = \begin{cases} 0, & \text{if } x \le s \\ \exp \beta_2 x \int_x^S \exp -\beta_2 \xi \Gamma(S-\xi) d\xi, & \text{if } s \le x \le S \\ \exp \beta_2 x \int_s^S \exp -\beta_2 \xi \Gamma(S-\xi) d\xi, & \text{if } S \le x \end{cases}\)

in which \(\Gamma(x)\) is the unique solution of

(15.6.3) \(\quad -\frac{\sigma^2}{2} \Gamma''(x) + \mu \Gamma'(x) + \lambda \Gamma(x) - \lambda \int_0^x \Gamma(x-\xi) \mu(\xi) d\xi = 0\)

\(\Gamma(0) = 1 \quad 0 \le \Gamma(x) \le 1\)

and \(\beta_2\) is the unique negative root of

\(-\frac{\sigma^2}{2} \beta_2^2 - \nu \beta_2 - \lambda - \lambda \hat{\mu}(\beta_2) = 0.\)

Moreover for any \(\varphi(x)\) bounded

(15.6.4) 
$$ \Phi_\alpha^{s,S}(x) = E \int_0^{+\infty} \exp - \alpha t \varphi(y_x^{s,S}(t))dt, $$

satisfies

(15.6.5) 
$$ \alpha \Phi_\alpha^{s,S}(x) \to \int_s^{+\infty} \varphi(x) m^{s,S}(x) dx. $$

PROOF. We note that \(\tilde{m}^{s,S}(x)\) in formula (15.6.2) is continuous but not \(C^1\). The derivative is discontinuous in \(S\). We begin to prove that \(m^{s,S}(x)\) is an invariant measure and the unique one, which is continuous and \(C^1\) except for \(S\). We begin by proving that \(m^{s,S}(x)\) must vanish on the interval \((-\infty, s)\). Indeed an invariant measure must satisfy

$$ \int m^{s,S}(x)\varphi(x)dx = \int m^{s,S}(x)E\varphi(y_x^{s,S}(\varepsilon))dx, \forall \varepsilon $$

Take a test function \(\varphi(x)\) which vanishes on \(s, +\infty\). We get from the preceding relation

$$ \int_{-\infty}^s m^{s,S}(x)\varphi(x)dx = E\varphi(y_S^{s,S}(\varepsilon)) \int_{-\infty}^s m^{s,S}(x)dx + \int_s^{+\infty} m^{s,S}(x)E\varphi(y_x^{s,S}(\varepsilon))dx $$

Letting \(\epsilon \to 0\) in the right hand side, we obtain

$$ \varphi(S) \int_{-\infty}^s m^{s,S}(x)dx + \int_s^{+\infty} m^{s,S}(x)\varphi(x)dx = 0, $$

from the choice of \(\varphi\). Let now pick \(\varphi(x)\) in the domain of the infinitesimal generator. An invariant measure must satisfy

$$ \int_s^{+\infty} m^{s,S}(x)A\varphi(x)dx = 0. $$

We write \(m(x)\) for \(m^{s,S}(x)\) to simplify notation. We recall the regularity properties on \(m\) and perform integration by parts. We get

$$
\begin{aligned}
&-\frac{\sigma^2}{2} [\varphi(S)(m'(S+0) - m'(S-0)) + \varphi(s)m'(s)] \\
&\quad -\lambda \varphi(S) \int_s^{+\infty} m(x) \left( \int_{x-s}^{+\infty} \mu(\xi)d\xi \right) dx + \int_s^{+\infty} \varphi(x) \left( \frac{\sigma^2}{2}m''(x) - \nu m'(x) + \lambda m(x) \right) dx \\
&\quad -\lambda \int_s^{+\infty} m(x) \left( \int_0^{x-s} \varphi(x - \xi) \mu(\xi)d\xi \right) dx = 0.
\end{aligned}
$$

Using the fact that \(\varphi\) satisfies \(\varphi(s) = \varphi(S)\) and rearranging we obtain

$$
\begin{aligned}
&-\varphi(S) \left[ \frac{\sigma^2}{2} (m'(S+0) - m'(S-0) + m'(s)) \right. \\
&\quad \left. + \lambda \int_s^{+\infty} m(x) \left( \int_{x-s}^{+\infty} \mu(\xi)d\xi \right) dx \right] + \int_s^{+\infty} \varphi(x) \left( \frac{\sigma^2}{2}m''(x) - \nu m'(x) \right. \\
&\quad \left. + \lambda m(x) - \lambda \int_0^{+\infty} m(x + \xi) \mu(\xi)d\xi \right) dx = 0.
\end{aligned}
