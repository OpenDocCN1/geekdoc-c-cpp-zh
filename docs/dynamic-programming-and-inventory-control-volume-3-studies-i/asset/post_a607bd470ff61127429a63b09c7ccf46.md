
hence

\[
\limsup \int_s^{+\infty} m(\varphi_s - \varphi^o)^2 dx \le \int_s^{+\infty} m \varphi^o \varphi dx - \int_s^{+\infty} m(\varphi^o)^2 dx.
\]

Noting that \(\sqrt{\epsilon}\varphi_\epsilon\) remains bounded in \(L^2_n(R)\), it follows from the equation of \(\varphi_\epsilon\) that

\[
\epsilon \int_s^{+\infty} A \varphi_\epsilon z dx \to 0, \forall z \text{ smooth with compact support in } (s, +\infty),
\]

therefore we deduce immediately that \(\varphi^o = \varphi\) and from (15.6.14) the property (15.6.22) is obtained, which completes the proof.

## 15.6.3. ERGODICITY.

The result of Theorem 15.4, although sufficient to study ergodic control and the limit of Bellman equation, as we shall see in the next sections, does not prove full ergodicity. To complete we need to prove the

### Theorem 15.5. We have the property

\[
E \varphi(y_s^{x,S}(t)) \to \int_s^{+\infty} E \varphi(\xi) m^{s,S}(d\xi), \text{ as } t \to +\infty, \forall x, \forall \varphi \text{ bounded.}
\]

### PROOF.

We shall use the fact that

\[
z^{s,S}(x,t) = E \varphi(y_s^{x,S}(t)),
\]

is the solution of the Cauchy problem

(15.6.16)
\[
\begin{align*}
\frac{\partial z}{\partial t} + Az &= 0, \quad x > s \\
z(x,t) &= z(S,t), \quad x \le s, t > 0 \\
z(x,0) &= \varphi(x)
\end{align*}
\]

We proceed with estimates. We first derive an energy equality. By testing (15.6.16) with \(mz\) and making use of Lemma 15.5.2 we can state

(15.6.17)
\[
\begin{align*}
\frac{1}{2} \frac{d}{dt} \int_s^{+\infty} m(x) z^2(x,t) dx + \frac{1}{2} \int_s^{+\infty} \sigma^2 m \left( \frac{\partial z}{\partial x} \right)^2 dx \\
+ \frac{\lambda}{2} \int_s^{+\infty} \int_0^{+\infty} m(x) (z(x) - z(x - \xi))^2 \mu(d\xi) dx d\xi = 0
\end{align*}
\]

We deduce the estimates

(15.6.18)
\[
\int_0^{+\infty} \int_s^{+\infty} \sigma^2 m \left( \frac{\partial z}{\partial x} \right)^2 (x,t) dx dt \le \int_s^{+\infty} m(x) \varphi^2(x) dx
\]

(15.6.19)
\[
\lambda \int_0^{+\infty} \int_s^{+\infty} \int_0^{+\infty} m(x) (z(x) - z(x - \xi))^2 \mu(d\xi) dx d\xi dt \le \int_s^{+\infty} m(x) \varphi^2(x) dx.
\]

Also

(15.6.20)
\[
\int_s^{+\infty} m(x) z^2(x,t) dx \le \int_s^{+\infty} m(x) \varphi^2(x) dx, \forall t.
\]

This inequality implies that without loss of generality we may assume that \(\varphi\) is in the domain of \(A\). Indeed considering the approximation \(\varphi_\epsilon\) defined in Lemma 15.3 and noting by \(z_c(x,t)\) the corresponding solution of the Cauchy problem, we deduce from the estimate (15.6.20) that

\[
\int_s^{+\infty} m(x)(z_c(x,t) - z(x,t))^2 dx \le \int_s^{+\infty} m(x)(\varphi_c - \varphi)^2 dx.
\]

Suppose we have proven that

\[
z_c(x,t) \to \int_s^{+\infty} m(x)\varphi_c(x) dx, \quad \text{as } t \to +\infty, \forall c > 0
\]

then writing

\[
\bar{\varphi} = \int_s^{+\infty} m(x)\varphi(x) dx, \quad \bar{\varphi}_c = \int_s^{+\infty} m(x)\varphi_c(x) dx
\]

\[
\begin{aligned}
\int_s^{+\infty} m(x)(z(x,t) - \bar{\varphi})^2 dx &\le 3 \left[ \int_s^{+\infty} m(x)(z_c(x,t) - z(x,t))^2 dx + \int_s^{+\infty} m(x)(z_c(x,t) - \bar{\varphi}_c)^2 dx + (\bar{\varphi}_c - \bar{\varphi})^2 \right] \\
&\le 3 \left[ \int_s^{+\infty} m(x)(\varphi_c - \varphi)^2(x) dx + \int_s^{+\infty} m(x)(z_c(x,t) - \bar{\varphi}_c)^2 dx + (\bar{\varphi}_c - \bar{\varphi})^2 \right]
\end{aligned}
\]

but then

\[
\limsup_{t \to +\infty} \int_s^{+\infty} m(x)(z(x,t) - \bar{\varphi})^2 dx \le 3 \left[ \int_s^{+\infty} m(x)(\varphi_c - \varphi)^2(x) dx + (\bar{\varphi}_c - \bar{\varphi})^2 \right],
\]

and letting \(\epsilon \to 0\) we obtain

\[
\int_s^{+\infty} m(x)(z(x,t) - \bar{\varphi})^2 dx \to 0, \text{ as } t \to +\infty
\]

We deduce also

\[
z(x,t) \to \bar{\varphi} \quad \text{a.e. } x > s
\]

So we assume that \(\varphi\) belongs to the domain of \(A\). We can then obtain further estimates.

We define the function

\[
u(x,t) = \frac{\partial z}{\partial t}(x,t),
\]

which is solution of

(15.6.21)
\[
\begin{aligned}
\frac{\partial u}{\partial t} + Au &= 0, \quad x > s \\
u(x,t) &= u(S,t), \quad x \le s, t > 0 \\
u(x,0) &= -A\varphi
\end{aligned}
\]

As for \(z\) we can write

(15.6.22)
\[
\int_0^{+\infty} \int_s^{+\infty} \sigma^2 m \left( \frac{\partial u}{\partial x} \right)^2 (x,t) dx dt \le \int_s^{+\infty} m(x)(A\varphi)^2(x) dx
\]

(15.6.23)
\[
\begin{aligned}
\lambda \int_0^{+\infty} \int_s^{+\infty} \int_0^{+\infty} m(x)(u(x) - u(x-\xi))^2 \mu(d\xi) dx dt \le \int_s^{+\infty} m(x)(A\varphi)^2(x) dx
\end{aligned}
\]

(15.6.24)
\[
\int_s^{+\infty} m(x)u^2(x,t)dx \le \int_s^{+\infty} m(x)(A\varphi)^2(x)dx, \forall t.
\]

In particular we have shown that

\[
\int_0^{+\infty} \int_s^{+\infty} m \left( \frac{\partial^2 z}{\partial x \partial t} \right)^2 (x,t) dx dt \le \frac{1}{\sigma^2} \int_s^{+\infty} m(x)(A\varphi)^2(x)dx
\]

Noting that

\[
\int_s^{+\infty} m \left( \frac{\partial z}{\partial x} \right)^2 (x,t) dx = \int_s^{+\infty} m(\varphi')^2(x)dx + 2 \int_0^t \int_s^{+\infty} m \frac{\partial z}{\partial x}(x, \tau) \frac{\partial^2 z}{\partial x \partial t}(x, \tau) dx d\tau
\]

the right hand side has a limit as \(t \to +\infty\), thanks to the estimates above. So \(\int_s^{+\infty} m \left( \frac{\partial z}{\partial x} \right)^2 (x,t) dx\) has a limit as \(t \to +\infty\). This limit must be 0 thanks to the estimate (15.6.18). Recalling that \(z\) is bounded, we can state that for any compact subset of \([s, +\infty)\) we can find a subsequence of \(z(x,t)\) which converges uniformly. The limit is necessarily a constant and since

\[
\int_s^{+\infty} m(x)z(x,t)dx = \int_s^{+\infty} m(x)\varphi(x)dx,
\]

this limit is necessarily \(\int_s^{+\infty} m(x)\varphi(x)dx\). By the uniqueness of the limit, the full sequence converges uniformly on any compact. So we have obtained the result for \(\varphi\) in the domain of \(A\) and also the general result, by the approximation above. However we have proven the result (15.6.15) only a.e. \(x\). We want to prove now that it is true for any initial value \(x\). We will need two important intermediary results. The first one is

(15.6.25)
\[
z(x,t) \text{ is continuous in } x, \quad \forall t > 0
\]

This property allows us to assume with no loss of generality that \(\varphi(x)\) is continuous and bounded. Indeed, clearly

\[
\lim_{t \to +\infty} z(x,t) = \lim_{t \to +\infty} z(x,t+1),
\]

and \(z(x, t + 1)\) satisfies the same equation as \(z(x,t)\) except for the initial condition which is \(z(x,1)\) instead of \(\varphi(x)\). But then \(z(x,1)\) is continuous and bounded. The second important result is that in the case when \(\varphi(x)\) is continuous and bounded, we can improve the approximation result of Lemma 15.3 as follows: The approximation \(\varphi_\epsilon(x)\) defined in Lemma 15.3 satisfies

(15.6.26)
\[
\sup_{s \le x \le M} |\varphi(x) - \varphi_\epsilon(x)| \to 0, \text{ as } \epsilon \to 0, \forall M \ge s.
\]

We will also prove the following regularity property for \(z(x,t)\)

(15.6.27)
\[
\int_s^{+\infty} m^3(x) \left( \frac{\partial z}{\partial x} \right)^2 (x,t) dx \le C \frac{t+1}{t} ||\varphi||^2, \forall t > 0.
\]

Note that here \(\varphi\) is only measurable and bounded. When \(\varphi\) belongs to the domain of \(A\) we have seen above that a better estimate holds. As a consequence we will have, noting \(y_x(t)\) the process \(y_x^S(t)\)

(15.6.28)
\[
\sup_{t \ge \delta} \sup_{s_0 \le x \le M} E \mathbf{1}_{y_x(t) \ge R} \to 0, \text{ as } R \to +\infty, \forall \delta > 0, s < s_0 \le M.
\]

The intermediary results (15.6.25), (15.6.26), (15.6.27), (15.6.28) will be proved later. We now assume \(\varphi(x)\) continuous and bounded. We want to prove that

(15.6.29)
\[
z(x, t) \to \int_s^{+\infty} m(x)\varphi(x)dx \text{ as } t \to +\infty, \forall x.
\]

It is sufficient to assume \(x > s\). So let us pick \(x_0 > s\). Using \(z(x, t) = E\varphi(y_x(t))\) we can write

\[
E\varphi(y_{x_0}(t)) - \int m\varphi dx = E\varphi(y_{x_0}(t)) - E\varphi_\epsilon(y_{x_0}(t)) + E\varphi_\epsilon(y_{x_0}(t)) - \int m\varphi_\epsilon dx + \int m\varphi_\epsilon dx - \int m\varphi dx.
\]

Now for \(R > x_0\) we have

\[
|E\varphi(y_{x_0}(t)) - E\varphi_\epsilon(y_{x_0}(t))| \le 2||\varphi|| E\mathbf{I}_{y_{x_0}(t) \ge R} + \sup_{s \le x \le R} |\varphi_\epsilon(x) - \varphi(x)|,
\]

hence

\[
\left| E\varphi(y_{x_0}(t)) - \int m\varphi dx \right| \le 2||\varphi|| E\mathbf{I}_{y_{x_0}(t) \ge R} + \sup_{s \le x \le R} |\varphi_\epsilon(x) - \varphi(x)| + \left| E\varphi_\epsilon(y_{x_0}(t)) - \int m\varphi_\epsilon dx \right| + \left| \int m\varphi_\epsilon dx - \int m\varphi dx \right|.
\]

Since \(\varphi\) belongs to the domain of \(A\), fixing \(\epsilon\) and \(R\), we can let \(t \to +\infty\) and deduce

\[
\limsup_{t \to +\infty} \left| E\varphi(y_{x_0}(t)) - \int m\varphi dx \right| \le 2||\varphi|| \sup_{t \ge \delta} E\mathbf{I}_{y_x(t) \ge R} + \sup_{s \le x \le R} |\varphi_\epsilon(x) - \varphi(x)| + \left| \int m\varphi_\epsilon dx - \int m\varphi dx \right|.
\]

But then letting \(\epsilon \to 0\), then \(R \to +\infty\) and making use of properties (15.6.26), (15.6.28) the right hand side tends to 0. So the property (15.6.15) is fully proven.

## PROOF OF REGULARITY:

\int_0^{+\infty} \int_s^{+\infty} \int_0^{+\infty} m(x)(z(x) - z(x - \xi))^2 \mu(d\xi) dx dt &\le \frac{1}{\lambda} ||\varphi||^2.
\end{aligned}
\]
