Next

```

= \alpha E[u'(x - x_2, z_2)|z_1 = z] - E[u'(x - x_2, z_2)|z_1 = z']

```

hence

```
|G'(x, z) - G'(x, z')| \le Cx^+ \sup_{0 < \zeta < x^+} |f(\zeta|z) - f(\zeta|z')|
```

Applying this inequality for \(x = S(z)\) and \(x = S(z')\) respectively, and combining estimates we deduce that \(S(z)\) is uniformly continuous. This completes the proof.
