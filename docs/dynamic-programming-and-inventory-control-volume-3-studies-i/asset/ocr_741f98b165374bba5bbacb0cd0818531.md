If \(s < \bar{s}\), then we can claim that

\(s < \bar{s} < S(s).\)

Indeed, for \(s < x < \bar{s}\), we can see from formula (13.3.18) that \(\Psi'_s(x) < 0\). However, we cannot compare \(S(s)\) with \(s^*\) in this case.

We then study the behavior of \(\Psi_s(S(s))\). We have already seen that, for \(s > s^*\) the function \(\Psi_s(S(s))\) is decreasing to the negative constant

\(-((1-\alpha)c+\alpha^L h)D \sum_{j=1}^{L-1} j \alpha^j.\)

In this case

(13.3.20) \(\frac{d}{ds}\Psi_s(S(s)) = -\alpha^L(h+p) \sum_{j=1}^{L-1} \alpha^j \int_0^{\bar{s}} \bar{F}^{(j)}(\zeta) f^{(L)}(s - \zeta) d\zeta, s > s^*.\)

Note that \(s > 0\). If \(s < s^*\), then \(s < S(s)\), therefore

\(\frac{d}{ds}\Psi_s(S(s)) = \frac{\partial \Psi_s}{\partial s}(S(s)),\)

hence

(13.3.21) \(\frac{d}{ds}\Psi_s(S(s)) = -\mu(s) \left[ \frac{1-\alpha^L}{1-\alpha} + \sum_{j=L}^\infty \alpha^j F^{(j)}(S(s) - s) \right].\)

Note that at \(s = s^*\) the two formulas coincide, since

\(-\mu(s^*) \frac{1-\alpha^L}{1-\alpha} = -\alpha^L(h+p) \sum_{j=1}^{L-1} \alpha^j \int_0^{\bar{s}} \bar{F}^{(j)}(\zeta) f^{(L)}(s^* - \zeta) d\zeta,\)

which can be easily checked, by remembering the definition of \(s^*(\gamma(s^*) = 0)\) and simple calculations. It follows clearly that \(\Psi_s(S(s))\) decreases on \((s, s^*)\) and increases on \((-\infty, \bar{s})\). Finally \(\Psi_s(S(s))\) decreases on \((\bar{s}, +\infty)\) and increases on \((-\infty, \infty)\). So it attains its maximum at \(\bar{s}\). From the formula for \(\Psi_s(x)\), \(H_s(x), x > \bar{s}\) and the fact that \(s\) is the minimum of \(g\), we get immediately that \(\Psi_s(S(s)) \ge 0\).
