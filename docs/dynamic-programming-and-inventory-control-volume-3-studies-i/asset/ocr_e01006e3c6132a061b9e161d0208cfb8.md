Note that this expression is also valid for \( k=0 \), by taking \( F(0)=0 \). So we can write

\( u((kD)^+) = F(k) + \alpha^k u(0), k \ge 0 \)

Therefore from (9.1.20), we can state

(9.1.21) \( \inf_{n \ge 0} z(n) = \inf_{k \ge 0} [ckD + ahDF(k) + \alpha^{k+1} u(0)] . \)

Now from (9.1.13), we have

\( u(0) = K + \inf_{k \ge 0} [c(k+1)D + ahDF(k) + \alpha^{k+1} u(0)] , \)

from which one gets easily

\( u(0) = \inf_{k \ge 0} \lambda(k), \)

with \(\lambda(k)\) given by (9.1.16). If \(\hat{k}\) achieves the infimum, then \(\hat{k}D\) achieves also the infimum of \(z(n)\). Since for \(x < D\), this infimum is achieved by \(x + \hat{v}(x) - D\), from the definition of the feedback, we can state that

\( x + \hat{v}(x) - D = \hat{k}D, \)

and we obtain (9.1.15). Note that \(\lambda(k)\) attains its infimum since \(\lambda(k) \to \infty\) as \(k \to \infty\).

We now consider particular cases

**Proposition 9.2.** Assume that

(9.1.22) \( \alpha(K + cD) \le cD + \alpha hD, \)

then \(\hat{k} = 0\).

**PROOF.** We use the fact that \(\hat{k}\) is also the value of \(k\) for which \(c(k+1)D + ahDF(k) + \alpha^{k+1} u(0)\) attains its minimum. Let us prove that this function is increasing in \(k\), when the assumption is made. Using the fact that

\( F(k+1) - F(k) = \frac{1 - \alpha^{k+1}}{1 - \alpha}, \)

we must check that for any \(k\), we have

\( u(0)(\alpha^{k+1} - \alpha^{k+2}) \le cD + \alpha hD \frac{1 - \alpha^{k+1}}{1 - \alpha}. \)

We know that

\( u(0) \le w(0) = \frac{K + cD}{1 - \alpha}. \)

Therefore, it is sufficient to verify

\( \alpha^{k+1}(K + cD) \le cD + \alpha hD \frac{1 - \alpha^{k+1}}{1 - \alpha}, \)

hence

\( \alpha^{k+1} \left[ K + cD + \frac{hD\alpha}{1 - \alpha} \right] \le cD + \frac{\alpha hD}{1 - \alpha}, \)

and it suffices to check that it is true for \(k=0\), which is exactly the condition (9.1.22).
