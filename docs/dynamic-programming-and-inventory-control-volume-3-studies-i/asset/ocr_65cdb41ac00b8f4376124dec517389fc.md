**Exercise 9.4.** Show directly formula (9.2.70) from the formulas giving \(J_\pi(V)\), formulas (9.2.35), (9.2.36). One needs to prove that the function \(\Gamma(x)\) satisfies the relation

```
(9.2.71) 
\(\Gamma(S-s)\int_0^s m(dx) + (1-\alpha)\int_s^S \Gamma(x-s)m(dx) = 1.\)
```

Indeed, from the equation of \(\Gamma\), one can state

```
\((\Gamma(x-s)-1)\mathbf{1}_{x>s} = \alpha \mathbf{1}_{x>s} E\Gamma(x-s-D)\mathbf{1}_{x-s-D>0},\)
```

and also

```
\(\Gamma(S-s)-1 = \alpha E\Gamma(S-s-D)\mathbf{1}_{S-s-D>0}.\)
```

Therefore

```
\((\Gamma(x-s)-1)\mathbf{1}_{x>s} + \mathbf{1}_{x \le s}(\Gamma(S-s)-1) = \alpha[\mathbf{1}_{x>s}E\Gamma(x-s-D)\mathbf{1}_{x-s-D>0} + \mathbf{1}_{x \le s}E\Gamma(S-s-D)\mathbf{1}_{S-s-D>0}].\)
```

Integrating both sides with respect to the invariant measure yields

```
\(\int_s^S \Gamma(x-s)m(dx) + \Gamma(S-s)\int_0^s m(dx) = 1 = \alpha \int_s^S \Gamma(x-s)m(dx),\)
```

where we have used the fundamental property of the invariant measure(9.2.62) applied to the test function \(\varphi(x) = \Gamma(x-s)\mathbf{1}_{x>s}\). This is result (9.2.71).
