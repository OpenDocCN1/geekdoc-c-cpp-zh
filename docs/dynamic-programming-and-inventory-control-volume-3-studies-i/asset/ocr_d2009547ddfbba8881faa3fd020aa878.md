and \(v_1\) is deterministic. This is more general than \(v_n = v_n(y_1, \cdots, y_n)\) and follows naturally from the information which is available at each time. If \(U\) depends on \(x\), then we have the constraint

\(v_n(D_1 \cdots, D_{n-1}) \in U(y_n),\)

and \(y_n\) is also a function of \(D_1, \cdots, D_{n-1}\). The operator \(\Phi^f f(x)\) is given by

(4.2.3) \(\Phi^f f(x) = Ef(g(x, v, D)) = \int f(g(x, v, y)) \eta(dj).\)

Let \(V = \{v_1, \cdots v_n \cdots \}\) be a control as defined above. The payoff is given by

(4.2.4) \(J_x(V) = E \sum_{n=1}^\infty \alpha^{n-1} l(y_n, v_n).\)

Note that the expectation is taken with respect to the fixed probability \(P\) and does not depend on the control policy as in formula (4.2.2). We define the value function

\(u(x) = \inf_V J_x(V).\)

**Proposition 4.3.** *The value function satisfies the functional equation (Bellman equation)*

(4.2.5) \(u(x) = \inf_{v \in U(x)} [l(x, v) + \alpha Eu(g(x, v, D))].\)

PROOF. Let us set

\(K(x, v_1, \cdots, v_n, \cdots ; D_1, \cdots, D_n, \cdots) = \sum_{n=1}^\infty \alpha^{n-1} l(y_n, v_n),\)

which is a functional on \(D_1, \cdots, D_n \cdots\) Thanks to the independence of the random variables, we have

\(EK(x, v_1, \cdots, v_n, \cdots ; D_1, \cdots, D_n, \cdots) = E_{D_1 D_2 \cdots} K(x, v_1, \cdots, v_n, \cdots ; D_1, \cdots, D_n, \cdots),\)

in which the expectations as indices in the right hand side mean that one must take the expectations successively. We start backwards. The fact that there is an infinite number of expectations is not a problem, since each term in the expression of \(K\) depends on a finite number of demands. Note the relation

\(K(x, v_1, \cdots, v_n, \cdots ; D_1, \cdots, D_n, \cdots) = l(x, v_1) + \alpha K(g(x, v_1, D_1), v_2, \cdots v_n, \cdots ; D_2, \cdots, D_n, \cdots).\)

Therefore, for fixed \(x, v_1, D_1\) we can write

(4.2.6) \(\inf_{v_2 \cdots v_n \cdots} E_{D_2 D_3 \cdots} . K(g(x, v_1, D_1), v_2, \cdots v_n, \cdots ; D_2, \cdots, D_n, \cdots) = u(g(x, v_1, D_1)).\)

Now the key point is to check that

(4.2.7) \(E_{D_1} \inf_{v_2 \cdots v_n \cdots} E_{D_2 D_3 \cdots} . K(g(x, v_1, D_1), v_2, \cdots v_n, \cdots ; D_2, \cdots, D_n, \cdots) = \inf_{v_2 \cdots v_n \cdots} E_{D_1 D_2 D_3 \cdots} . K(g(x, v_1, D_1), v_2, \cdots v_n, \cdots ; D_2, \cdots, D_n, \cdots).\)
