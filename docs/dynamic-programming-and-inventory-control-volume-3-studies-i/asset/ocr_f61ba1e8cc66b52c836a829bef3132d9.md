# 14.10.2. PROBLEM FOR THE VALUE FUNCTION.

The value function

```
\( u(x) = \inf_V J_V(V),\)
```

satisfies the set of inequalities and complementarity conditions

```
\( u(x) + cx \le K + \inf_{\eta \ge x} (c\eta + u(\eta));\)
\( (\alpha + \lambda)u(x) - \lambda u(x-1) = \lambda u(x-1) \le \phi(x);\)
\( [(\alpha + \lambda)u(x) - \lambda u(x-1) - \phi(x)][u(x) + cx - K - \inf_{\eta \ge x} (c\eta + u(\eta))] = 0.\)
```

# 14.10.3. s, S POLICY.

As we have done in the case without delays, we look for a function \( u_s(x) \) such that

```
\( u_s(x) + cx = u_s(s) + cs, \forall x \le s \)
\( (\alpha + \lambda)u_s(x) - \lambda u_s(x-1) = \phi(x), \forall x \ge s \)
\( u_s(s) + cs = K + \inf_{\eta \ge s} (c\eta + u_s(\eta)).\)
```

The last expression is an equation for s, once the function \( u_s(x) \) is uniquely determined. To define \( u_s(x) \) for any s, we need the value of \( u_s(s) \) This number is given by

```
\( u_s(s) = \frac{\phi(s) + \lambda c}{\alpha}.\)
```

This motivates the introduction of the function \( H_s(x) \) solution of

```
\( H_s(x) = 0, \forall x \le s \)
\( (\alpha + \lambda)H_s(x) - \lambda H_s(x-1) = \lambda g(x) - g(x), \forall x \ge s \)
\( 0 = K + \inf_{\eta \ge s} H_s(\eta),\)
```

and the function \( g(x) \) is defined by

```
\( g(x) = \phi(x) + \rho cx,\)
```

which is the function already introduced in the last section (14.8.7). We have the relation

```
\( H_s(x) = u_s(x) + cx - cs - \frac{\lambda c + \phi(s)}{\alpha}.\)
```

We recall the formula for \( H_s(x) \).

```
(14.10.1) \( H_s(x) = \sum_{j=0}^{[x-s]} \frac{(g(x-j) - g(s))\lambda^j}{(\alpha + \lambda)^{j+1}}, \forall x \ge s; H_s(x) = 0, \forall x \le s.\)
```

The theory developed in section 14.6 applies, with a minimum of \( g(x) \) which is \( \hat{n} \) which is a positive integer instead of 0.

Consider first \( S(s) \) which minimizes \( H_s(\eta), \eta \ge s \). We have

```
\( S(s) = s, \text{ if } s > \hat{n}\)
```

Consider next the case \( s < \hat{n} \). As in section 14.6 we prove that \( H_s(x) \) reaches its minimum on \( (s, \infty) \). Picking the smallest minimum \( S(s) \) we define the function \( S(s) \) for \( s < \hat{n} \). Necessarily

```
\( S(s) \ge \hat{n}.\)
```
