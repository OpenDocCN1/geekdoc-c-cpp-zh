
From the estimates obtained we can assert that \(\bar{u}_\alpha(x, z)\) has a converging subsequence (still denoted \(\alpha\)), in the sense

(12.4.36)
\(\sup_{x \le M \\ z \le N} |\bar{u}_\alpha(x, z) - u(x, z)| \to 0, \text{ as } \alpha \to 0.\)

Since \(\rho_\alpha\) is bounded, we can always assume that \(\rho_\alpha \to \rho\). Denote

\(L(x, z, v) = K \mathbb{I}_{v>0} + l(x, z, v) + \Phi^e u(x, z)\)

then

\(L_\alpha(x, z, v) - L(x, z, v) = \alpha \Phi^e(\bar{u}_\alpha - u)(x, z) - (1 - \alpha) \Phi^e u(x, z)\)

For \(v \le \max(x, m_0) - x\), we have assuming \(M > m_0\)

\(\sup_{x \le M \\ z} |\Phi^e u(x, z)| \le C + \frac{CM}{1 - \delta_0(M)}\)

We also have

\(\sup_{x \le M \\ z} |\Phi^e(\bar{u}_\alpha - u)(x, z)| \le \sup_{x \le M \\ z} |\bar{u}_\alpha - u|(x, z) \sup_z \bar{F}(N, z)\)
\(+ \sup_{x \le M \\ z \le N} |\bar{u}_\alpha - u|(x, z)\)

Using the assumption (12.4.25) and (12.4.36), letting first \(\alpha \to 0\), then \(N \to \infty\), we deduce

\(\sup_{v \le \max(x, m_0) - x \\ z \le M} |L_\alpha(x, z, v) - L(x, z, v)| \to 0, \text{ as } \alpha \to 0.\)

Therefore we deduce easily (12.4.28) and also that the pair \(u(x, z), \rho\) satisfy (12.4.31). The estimates (12.4.29), (12.4.31) follow immediately from the corresponding ones on \(\bar{u}_\alpha(x, z)\). The \(K\)-convexity of \(u\) follows from the \(K\)-convexity of \(\bar{u}_\alpha\). The proof has been completed.

## 12.5. BACKLOG AND SET UP COST

### 12.5.1. MODEL.

We finally consider the situation of set up cost, with backlog. The Bellman equation is

(12.5.1) \(u(x, z) = \inf_{v \ge 0} [K \mathbb{I}_{v>0} + l(x, v) + \alpha \Phi^e u(x, z)],\)

where

(12.5.2) \(\Phi^e \varphi(x, z) = E[\varphi(x + v - z_2, z_2) | z_1 = z]\)
\(= \int_0^\infty \varphi(x + v - \zeta, \zeta) f(\zeta | z) d\zeta,\)

and

(12.5.3) \(f(\zeta | z)\) is uniformly continuous in both variables and bounded

(12.5.4) \(\int_0^{+\infty} c(|z|) d\zeta \le c_0 z + c_1,\)

(12.5.5) \(l(x, v) = cv + hx^+ + px^- .\)

We look for solutions of (12.5.1) in the interval [0, w_0(x, z)] with

(12.5.6) \(w_0(x, z) = l_0(x) + \alpha E[w_0(x - z_2, z_2) | z_1 = z],\)

with l_0(x) = l(x, 0).

In Lemma 12.2, we have proven the estimate

(12.5.7) \(w_0(x, z) \le \frac{hx^+ + px^-}{1 - \alpha} + \frac{pc_0 \alpha}{(1 - c_0 \alpha)(1 - \alpha)} + \frac{pc_1}{(1 - c_0)^2} \left( \frac{\alpha - c_0}{(1 - \alpha)^2} + \frac{c_0}{1 - \alpha c_0} \right),\)

with the assumption

(12.5.8) \(c_0 \alpha < 1.\)

As usual we consider the payoff function

(12.5.9) \(J_{x,z}(V) = E \sum_{n=1}^{\infty} \alpha^{n-1} [K \mathbf{I}_{v_n > 0} + l(y_n, v_n)],\)

with V = (v_1, \cdots, v_n, \cdots) adapted process with positive values and

(12.5.10) \(y_{n+1} = y_n + v_n - z_{n+1}, y_1 = x.\)

We define the value function

(12.5.11) \(u(x, z) = \inf_V J_{x,z}(V).\)

We state the

### Theorem 12.10.
We assume (12.5.2), (12.5.3), (12.5.4), (12.5.5), (12.5.8). The value function defined in (12.5.11) is the unique l.s.c. solution of the Bellman equation (12.5.1) in the interval [0, w_0]. There exists an optimal feedback \hat{v}(x, z).

### 12.5.2. s(z), S(z) Policy.
We now prove the following result

### Theorem 12.11.
We make the assumptions of Theorem 12.10 and \alpha p > c. Then the function u(x, z) is K-convex and continuous. It tends to +\infty as |x| \to +\infty. Considering the numbers s(z), S(z) associated to u(x, z), the optimal feedback is given by

(12.5.12) \(\hat{v}(x, z) = \begin{cases} S(z) - x, & \text{if } x \le s(z) \\ 0, & \text{if } x > s(z) \end{cases}\)

The functions s(z), S(z) are continuous, S(z) > 0.

### Proof.
We consider the increasing sequence

(12.5.13) \(u_{n+1}(x, z) = hx^+ + px^- + \inf_{v \ge 0} \{ K \mathbf{I}_{v > 0} + c v + \alpha E[u_n(x + v - z_2, z_2) | z_1 = z] \},\)

with u_0(x, z) = 0. Define

(12.5.14) \(G_n(x, z) = cx + \alpha E[u_n(x - z_2, z_2) | z_1 = z].\)

We can write

(12.5.15) \(u_{n+1}(x, z) = hx^+ + px^- - cx + \inf_{\eta \ge x} [K \mathbf{I}_{\eta > x} + G_n(\eta, z)].\)

We are going to show, by induction, that both \(u_n(x,z), G_n(x,z)\) are \(K-\)convex in \(x\), continuous and \(\rightarrow +\infty\) as \(|x| \rightarrow +\infty\), for \(n \ge 2\). Also

(12.5.16) \(u'_n(x,z) \le -p - c, G'_n(x,z) \le c(1-\alpha) - \alpha p, \text{ if } x < 0.\)

These relations will be true for \(n \ge 2\). We have \(G'_0(x,z) = c\) and \(u'_1(x,z) = -p\), if \(x < 0\). Then

\(G'_n(x,z) = c - \alpha p < 0, \text{ if } x < 0\)

As soon as \(G'_n(x,z) \le 0, \text{ for } x < 0\), then \(u'_{n+1}(x,z)\) satisfies (12.5.16) and \(G'_{n+1}(x,z)\) satisfies also (12.5.16).

Since \(G_n(x,z)\) is \(K-\)convex in \(x\), continuous and \(\rightarrow +\infty\) as \(|x| \rightarrow +\infty\), we can define \(s_n(z), S_n(z)\) with

(12.5.17) \(G_n(S_n(z), z) = \inf_\eta G_n(\eta, z),\)

and \(s_n(z)\) is defined by

(12.5.18) \(G_n(s_n(z), z) = K + \inf_\eta G_n(\eta, z).\)

As usual we take the smallest minimum to define \(S_n(z)\) in a unique way. Since \(G_n(\eta, z)\) is continuous, it is easy to check that \(S_n(z)\) is continuous. Also \(s_n(z)\) is continuous.

We can write

\(u_{n+1}(x,z) = hx^+ + px^- - cx + G_n(\max(x, s_n(z)), z)\)

which shows immediately that \(u_{n+1}(x,z)\) and then \(G_{n+1}(x,z)\) are \(K-\)convex and continuous. Furthermore \(u_{n+1}(x,z), G_{n+1}(x,z) \rightarrow +\infty\), as \(x \rightarrow +\infty\).

Since for \(x < 0\)

\(u'_{n+1}(x,z) = -p + c + G'_n(x) 1_{x > s_n(z)},\)

we see that (12.5.16) is satisfied for \(u_{n+1}, G_{n+1}\). Therefore \(u_{n+1}(x,z), G_{n+1}(x,z) \rightarrow +\infty\) as \(x \rightarrow -\infty\).

So the recursion is proven. Note also that \(S_n(z) > 0\).

If we write (formally)

\(u'_n(x,z) = h 1_{x > 0} - p 1_{x < 0} - c + \chi_n(x,z),\)

then one has the recurrence

\(X_{n+1}(x,z) = \begin{cases} 0 & \text{if } x < s_n(z) \\ = \mu(x,z) + \alpha E[\chi_n(x - z_2, z_2) | z_1 = z] \end{cases}\)

with

(12.5.19) \(\mu(x,z) = c(1-\alpha) + \alpha h - \alpha(p+h)\bar{F}(x|z).\)

The function \(X_{n+1}(x,z)\) is discontinuous in \(s_n(z)\). However one has the bound

\(\frac{c(1-\alpha) - \alpha p}{1-\alpha} \le X_{n+1}(x,z) \le \frac{c(1-\alpha) + \alpha h}{1-\alpha} \quad \text{a.e.}\)

Note also \(X_n(x,z) \le 0\), if \(x < 0\) and

\(X_{n+1}(x,z) \le c(1-\alpha) - \alpha p, \text{ if } s_n(z) < x < 0\)

Therefore the limit \(u(x,z)\) is \(K-\)convex and satisfies

\(u'(x,z) = h 1_{x > 0} - p 1_{x < 0} - c + \chi(x,z),\)

with

\(\frac{c(1-\alpha)-\alpha p}{1-\alpha} \le \chi(x,z) \le \frac{c(1-\alpha)+\alpha h}{1-\alpha} \quad \text{a.e.}\)

Hence \(u(x,z)\) is continuous in \(x\) and \(\to +\infty\) as \(x \to +\infty\). For \(x < 0\), one also has

\(u'(x,z) \le -c - p\)

therefore \(u(x,z) \to +\infty\) as \(x \to -\infty\). Also

\(\chi(x,z) \le 0 \text{ if } x < 0, \quad \chi(x,z) \le c(1-\alpha) - \alpha p, \ s(z) < x < 0\)

Therefore one defines uniquely \(s(z), S(z)\) and \(S(z)\) minimizes in \(x\) the function

\(G(x,z) = cx + \alpha E[u(x-z_2, z_2)|z_1 = z]\)

From this formula and the Lipschitz continuity of \(u\) in \(x\), using the assumption (12.5.3) one can see that \(G(x,z)\) is continuous in both arguments.

Also \(G(x,z) \to +\infty\) as \(x \to -\infty\). Hence \(S(z)\) and \(s(z)\) are well defined, and are continuous. Moreover \(S(z) > 0\). The proof has been completed.

### 12.5.3. ERGODIC THEORY.

We now study the behavior of \(u(x,z)\) as \(\alpha \to +\infty\). We denote it by \(u_\alpha(x,z)\) and we write the relations

(12.5.20) \(u_\alpha(x,z) = hx^+ + px^- - cx + G_\alpha(\max(x, s_\alpha(z)), z)\)

(12.5.21) \(G_\alpha(x,z) = cx + \alpha E[u_\alpha(x-z_2, z_2)|z_1 = z].\)

We shall assume \(c_0 = 0\) and

(12.5.22) \(z_n \text{ is ergodic.}\)

We denote by \(\varpi(z)\) the invariant measure. We also assume

(12.5.23) \(\int |f(\zeta|z) - f(\zeta|z')| d\zeta \le \delta |z - z'|,\)

(12.5.24) \(\int \zeta |f(\zeta|z) - f(\zeta|z')| d\zeta \le \delta |z - z'|,\)

(12.5.25) \(\sup_z F(x|z) = \delta_0(x) < 1, \forall x\)

(12.5.26) \(\sup_z \bar{F}(x|z) \to 0 \text{ as } x \to +\infty\)

We begin with the

### Lemma 12.4.
We have the estimate

(12.5.27) \(s_\alpha^-(z) \le \frac{K}{\alpha p - c(1-\alpha)} = m_\alpha\)

Also

(12.5.28) \(0 \le S_\alpha(z) \le \frac{\alpha(p+h)E[z_2|z_1=z] + \alpha p m_\alpha}{c + \alpha(h-c)}\)
