point, otherwise this point would be a maximum, which is impossible. Therefore \(\Psi(x) < 0, \forall x \ge 0\). In addition \(\Psi'(x)\) cannot be negative or zero at any point. Otherwise, \(\Psi(x)\) would have a negative local minimum, which is also impossible. Therefore \(\Psi(x) = \Phi'(x) > 0, \forall x \in (0, \infty)\).

We thus have proved the properties (16.3.8) for \(x \in [0, \infty)\).

We next solve equation (16.3.7) in \((-\infty, 0]\) as a two-dimensional system of linear differential equations, with given initial values at 0. For convenience, we will change the sign of \(x\), to solve a system on \([0, \infty)\). Define

\(y(x) = \Phi(-x), z(x) = \Phi'(-x), x > 0\)

then the pair \(y(x), z(x)\) is solution of

(16.3.13)
\[
\begin{aligned}
y' &= -z; \\
z' &= \frac{2}{\sigma^2}((kx - (\nu - k\tau))z - (\alpha + k)y),
\end{aligned}
\]
on \([0, \infty)\) with initial conditions \(y(0) = 1, z(0) = z_0 = \Phi'(0) < 0\). Consider the matrix

\(\mathcal{A}(x) = \left( \begin{array}{ c c }
0 & -1 \\
-\frac{2}{\sigma^2}(\alpha + k) & \frac{2}{\sigma^2}(kx - (\nu - k\tau)) 
\end{array} \right),\)

then we associate to it a family of matrices, called \(\Sigma(x, x_0), x \ge x_0\), the *fundamental matrix* satisfying the differential equation

\[
\begin{aligned}
\frac{d}{dx}\Sigma(x, x_0) &= \mathcal{A}(x)\Sigma(x, x_0); \\
\Sigma(x_0, x_0) &= I,
\end{aligned}
\]

where \(I\) is the identity. From the theory of linear differential equations, the matrix \(\Sigma(x, x_0)\) is well defined, for any pair \(x \ge x_0\). Moreover the solution of (16.3.13) is given by

\(\begin{pmatrix} y(x) \\ z(x) \end{pmatrix} = \Sigma(x, 0) \begin{pmatrix} 1 \\ z_0 \end{pmatrix},\)

so it is uniquely defined for any \(x > 0\). Let

\(\varpi(x) = \exp -\frac{2}{\sigma^2} \left[ k \frac{(x+\gamma)^2}{2} - \nu x \right],\)

and

\(\bar{z}(x) = z(x)\varpi(x),\)

then the pair \(y(x), \bar{z}(x)\) is the solution of

(16.3.14)
\[
\begin{aligned}
y' &= -\frac{\bar{z}}{\varpi} \\
\bar{z}' &= -\frac{2}{\sigma^2}(\alpha + k)\varpi y
\end{aligned}
\]

with initial conditions \(y(0) = 1, \bar{z}(0) = z_0 \exp - \frac{k\gamma^2}{\sigma^2}\). It follows easily that \(y(x) > 0, \bar{z}(x) < 0\). After easy manipulations, we get the following integral equation for \(\bar{z}(x)\)

(16.3.15)
\[
\begin{aligned}
\bar{z}(x) &= \bar{z}(0) - \frac{2}{\sigma^2}(\alpha + k)y(0) \int_0^x \varpi(\xi) d\xi \\
&+ \frac{2}{\sigma^2}(\alpha + k) \int_0^x G(x, \eta) \bar{z}(\eta) d\eta,
\end{aligned}
\]
