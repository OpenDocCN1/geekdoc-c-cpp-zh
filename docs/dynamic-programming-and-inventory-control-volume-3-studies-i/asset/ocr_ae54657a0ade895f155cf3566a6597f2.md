from which we deduce easily that

\(\sup_{x \le M} \sup_z |\alpha E[\chi_a(x - z_2, z_2) 1_{\mathbb{I}_{x > z_2}} - E[\chi(x - z_2, z_2) 1_{\mathbb{I}_{x > z_2}} | z_1 = z]| \to 0, \forall M\)

From (12.2.41), it follows that

\(\chi(x, z) = g(x, z) + E[\chi(x - z_2, z_2) 1_{\mathbb{I}_{x > z_2}} | z_1 = z], \forall x > S(z),\)

where

(12.2.49) \(g(x, z) = h - (p - h + c)\bar{F}(x|z).\)

Also \(\chi(x,z)=0\), if \(x < S(z)\). Moreover, from

\(0 = g_a(S_a(z), z) + \alpha E[\chi_a(S_a(z) - z_2, z_2) 1_{\mathbb{I}_{S_a(z) > z_2}} | z_1 = z]\)

and

\(|\alpha E[\chi_a(S_a(z) - z_2, z_2) 1_{\mathbb{I}_{S_a(z) > z_2}} | z_1 = z] - E[\chi(S_a(z) - z_2, z_2) 1_{\mathbb{I}_{S_a(z) > z_2}} | z_1 = z]| \le \sup_{x \le M} \sup_z |o E[\chi_a(x - z_2, z_2) 1_{\mathbb{I}_{x > z_2}} - E[\chi(x - z_2, z_2) 1_{\mathbb{I}_{x > z_2}} | z_1 = z]|\)

\(|E[\chi(S_a(z) - z_2, z_2) 1_{\mathbb{I}_{S_a(z) > z_2}} | z_1 = z] - E[\chi(S(z) - z_2, z_2) 1_{\mathbb{I}_{S(z) > z_2}} | z_1 = z]| \le \frac{(h - c + p)||f||_1}{1 - \delta_0(m_0)} |S_a(z) - S(z)| + \frac{2 \max(h, p)}{1 - \delta_0(m_0)} |F(S_a(z)|z) - F(S(z)|z)|\)

we obtain easily

\(0 = g(S(z), z) + E[\chi((S(z) - z_2)^+, z_2) | z_1 = z],\)

and the function \(\chi(x, z)\) is continuous in \(x\).

Let us next set

\(\Gamma_a(z) = u_a(0, z);\) \(G_a(z) = E[(S_a(z) - z_2)^- | z_1 = z],\)

then from the first equation (12.2.26) one can check

\(\Gamma_a(z) = cS_a(z) + pG_a(z) + \alpha E[u_a(S_a(z) - z_2)^+, z_2) | z_1 = z] = \Psi_a(z) + \alpha E[\Gamma_a(z_2) | z_1 = z].\)

with

\(\Psi_a(z) = cS_a(z) + pG_a(z) + \alpha E[\int_0^{(S(z) - z_2)^+} (h - c + \chi(\xi, z_2)) d\xi | z_1 = z,\)

and

\(0 \le \Psi_a(z) \le [\max(h, c) + \frac{\max(h, p)}{1 - \delta(m_0)}] m_0 + pc_1.\)

This estimate also holds for the limit

\(\Psi(z) = cS(z) + pG(z) + E\left[\int_0^{(S(z) - z_2)^+} (h - c + \chi(\xi, z_2)) d\xi | z_1 = z \right]\)

with

\(G(z) = E[(S(z) - z_2)^- | z_1 = z].\)
