We have

\(H'_s(x) = \mu(x) + \int_s^x \Gamma(x-\xi)\mu(\xi)d\xi,\)

therefore

\(H'_t(x) = \mu(x) + \alpha\beta \exp-\beta(1-\alpha)x \int_s^x \exp \beta(1-\alpha)\xi \mu(\xi)d\xi,\)

and

\(H_s(x) = \int_s^x \frac{\mu(\xi)}{1-\alpha}d\xi - \frac{\alpha}{1-\alpha} \exp-\beta(1-\alpha)x \int_s^x \exp \beta(1-\alpha)\xi \mu(\xi)d\xi.\)

We recall that

\(H_s(x) \le 0, \forall x < x_0, H_s(x_0) = 0.\)

Let now \(x_1\) such that

\(\int_s^{x_1} \exp \beta(1-\alpha)\xi \mu(\xi)d\xi = 0.\)

If \(x_1 \le x_0\) then from the formula of \(H'_s(x), H'_s(x_0) > 0\) and the fact that \(\mu(x)\) increases, we see immediately that \(H'_t(x) \ge 0, \text{as } x \ge x_0\). So assume that \(s < x_0 < x_1\). For \(x \ge x_1\)

\(H'_s(x) \ge H'_s(x_1) \ge H'_s(x_0) > 0.\)

There remains the interval \((x_0, x_1)\). We know that \(H'_s(x_1) \ge H'_s(x_0) \ge 0\). If there exists a point in the interval such that \(H'_s(x) < 0\), necessarily there exists a point \(\xi\) such that

\(x_0 < \xi < x_1, H'_s(\xi) = 0.\)

If we introduce

\(\lambda(x) = \mu(x) \exp \beta(1-\alpha)x, \rho(x) = \frac{\lambda(x)}{\int_s^x \lambda(u)du},\)

then \(\xi\) satisfies \(\rho(\xi) = -\alpha\beta\). By definition of \(x_1\),

\(\int_s^x \lambda(u)du < 0, \forall s < x < x_1,\)

and \(\lambda'(x) > 0\). Therefore

\(\rho'(x) = \frac{\lambda(x) \int_s^x \lambda(u)du - \lambda^2(x)}{(\int_s^x \lambda(u)du)^2} < 0.\)

Moreover

\(H'_s(x_0) > 0 \Rightarrow \lambda(x_0) + \alpha\beta \int_s^{x_0} \lambda(u)du > 0,\)

hence

\(\rho(x_0) + \alpha\beta < 0.\)

Therefore \(\rho(x) < -\alpha\beta, \forall x \in [x_0, x_1]\). The point \(\xi\) cannot exist. So \(H'_s(x) > 0, \forall x \in [x_0, x_1]\). The result has been proven. \(\square\)
