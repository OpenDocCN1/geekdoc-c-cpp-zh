Let $\overline{u}$ to be the unique solution of $\overline{u} = T(\overline{u})$. Then $0 \le \overline{u} \le C_0$. We can define $\lambda > 0$ such that $\lambda \overline{u}(x) \le K, \forall x$.

We state the following

# Lemma 8.4. Let $z, \zeta \in C$ positive, and $\beta \in [0, 1]$ such that

$z(x) - \zeta(x) \le \beta z(x), \forall x,$

then

$A(z)(x) - A(\zeta)(x) \le \beta(1-\lambda)A(z)(x), \forall x.$

We have, by assumption, $(1-\beta)z(x) \le \zeta(x)$. From the monotonicity and the concavity of $A$ we can write

$A(\zeta)(x) \ge A((1-\beta)z)(x) \ge (1-\beta)A(z)(x) + \beta A(0)(x)$

However $A(0) = S(M(0)) = S(K)$. But from $\lambda \overline{u}(x) \le K$ and $\lambda \overline{u}(x) = \lambda T(\overline{u})(x)$ hence $\lambda \overline{u}(x) \le T(\lambda \overline{u})(x)$ we deduce, using Lemma 8.1

$\lambda \overline{u}(x) \le S(K) = A(0).$

Collecting results we write

$A(\zeta)(x) \ge (1-\beta)A(z)(x) + \beta \lambda \overline{u}(x).$

Now

$A(z) \le T A(z) \quad \overline{u} = T \overline{u}$

and by a reasoning similar to that of Lemma 8.1 we deduce $A(z)(x) \le \overline{u}(x)$. Therefore

$A(\zeta)(x) \ge (1-\beta)A(z)(x) + \beta \lambda A(z)(x),$

and this is exactly the property (8.3.8).

PROOF. Existence:

This amounts to proving that the operator $A$ has a fixed point. We consider the decreasing sequence

$u^{n+1} = A(u^n) \quad u^0 = \overline{u}$

We have

$u^0 \ge \dots \ge u^n \ge \dots$

Since $u^0 - u^1 \le u^0$, we deduce from Lemma 8.4

$A(u_0) - A(u_1) \le (1-\lambda)A(u_0),$

which reads

$u_1 - u_2 \le (1-\lambda)u_1.$

Iterating we get

$u^m - u^{m+1} \le (1-\lambda)^m u^m \le (1-\lambda)^m u^0.$
