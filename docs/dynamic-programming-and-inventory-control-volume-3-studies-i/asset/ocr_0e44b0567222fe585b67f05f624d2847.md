$C(q) = \frac{K\lambda}{q} + \left(\frac{i}{2}q + \lambda\right) \sum_j \alpha_j \mathbb{1}_{\{q_{j-1} \le q < q_j\}}.$

# **2.3.2. EOQ FORMULA WITH PROGRESSIVE DISCOUNT.** Let us consider an extension which will lead to a continuous function, see V. Giard [20]. Suppose that, if $q_{j-1} \le q < q_j$, only the part $q - q_{j-1}$ is paid at price $\alpha_j$. Let $A_j$ be the cost of procuring the quantity $q_j$, then clearly

$A_j = A_{j-1} + (q_j - q_{j-1})\alpha_j, \quad A_0 = 0,$

and for $q$ as before, the full procurement cost is $A_{j-1} + (q - q_{j-1})\alpha_j$, and the average unit price is $\frac{A_{j-1} + (q - q_{j-1})\alpha_j}{q} = \alpha_j + \frac{B_j}{q}$, where

$B_j = A_{j-1} - q_{j-1}\alpha_j,$

hence

$B_{j+1} = \sum_{h=1}^j q_h(\alpha_h - \alpha_{h+1}), \quad B_1 = 0,$

therefore, we have

$C(q) = \frac{K\lambda}{q} + \left(\frac{i}{2}q + \lambda\right) \sum_j \left(\alpha_j + \frac{B_j}{1}\right) \mathbb{1}_{\{q_{j-1} \le q < q_j\}}.$

This function is continuous, since

$\alpha_j + \frac{B_j}{q_j} = \alpha_{j+1} + \frac{B_{j+1}}{q_j}.$

If $j$ runs from 1 to $J$, then we use the convention $q_{J+1} = +\infty$. Moreover $\alpha_{J+1}$ is the price of acquiring a quantity larger than $q_J$. So

$C(q) = \frac{K\lambda}{q} + \left(\frac{i}{2}q + \lambda\right) \sum_{j=1}^{J+1} \left(\alpha_j + \frac{B_j}{q}\right) \mathbb{1}_{\{q_{j-1} \le q < q_j\}}.$
