and thus from ergodic theory

```
(13.5.37) 
\left| \Gamma_\alpha(\sigma, \eta) - \frac{\rho_\alpha}{1-\alpha} \right|.
```

We can then state the

**Theorem 13.4.** We make the assumptions of Theorem 13.3. There exists a sequence \(\rho_\alpha\) such that if \(\alpha \to 1\), for a subsequence

```
(13.5.38) 
\( u_\alpha(x; \sigma, \eta) - \frac{\rho_\alpha}{1-\alpha} \to u(x; \sigma, \eta), \)
```

uniformly on any compact of \(R\). We have also \(\rho_\alpha \to \rho\). The function \(u(x; \sigma, \eta)\) is locally Lipschitz continuous and satisfies

```
\( |u'(x; \sigma, \eta)| \le \frac{C}{F((x+m_0)^+)} \)
```

The pair \(u(x; \sigma, \eta), \rho\) satisfies

```
(13.5.39) 
\( u(x; \sigma, \eta) + \rho = -cx + l^{(\sigma+\eta)}(x) \n + \inf_{y \ge x} \left\{ K \mathbb{1}_{y > x} + cy + \sum_{k=0}^{\sigma+\eta} \gamma(k; \sigma, \eta) u^{(\sigma+\eta+1-k)}(y; 0, k) \right. \n \left. + \sum_{k=\sigma+\eta+1}^M \gamma(k; \sigma, \eta) u(y; \sigma+1, \eta) \right\} \)
```

PROOF. We define again

```
\(\bar{u}_\alpha(x; \sigma, \eta) = u_\alpha(x; \sigma, \eta) - \frac{\rho_\alpha}{1-\alpha},\)
```

then we get the equation

```
\(\bar{u}_\alpha(x; \sigma, \eta) + \rho_\alpha = -cx + l^{(\sigma+\eta)}(x) \n + \inf_{y \ge x} \left\{ K \mathbb{1}_{y > x} + cy + \alpha E \bar{u}^{(\sigma+\eta+1-(\sigma'+\eta'))}(y; \sigma', \eta') \right\} \)
```

Since the infimum is attained at \(\max(x, S A_\alpha(\sigma, \eta))\), we can consider that \(y < L_X\) if \(x < X\). Therefore we have also

```
(13.5.40) 
\( \bar{u}_\alpha(x; \sigma, \eta) + \rho_\alpha = -cx + l^{(\sigma+\eta)}(x) \n + \inf_{L_X \ge y \ge x} \left\{ K \mathbb{1}_{y > x} + cy + \alpha E \bar{u}^{(\sigma+\eta+1-(\sigma'+\eta'))}(y; \sigma', \eta') \right\}. \)
```

Assuming \(|x| < X\), using the estimates of Proposition 13.9 and Lemma 13.3, and applying the Ascoli-Arzelà theorem we can extract a subsequence such that

```
\(\sup_{|x|<X} |\bar{u}_\alpha(x; \sigma, \eta) - u(x; \sigma, \eta)| \to 0\)
```

and we can pass to the limit in (13.5.40) to obtain

```
\( u(x; \sigma, \eta) + \rho \n = -cx + l^{(\sigma+\eta)}(x) + \inf_{L_X \ge y \ge x} \left\{ K \mathbb{1}_{y > x} + cy + \alpha E u^{(\sigma+\eta+1-(\sigma'+\eta'))}(y; \sigma', \eta') \right\} \n \ge -cx + l^{(\sigma+\eta)}(x) + \inf_{y \ge x} \left\{ K \mathbb{1}_{y > x} + cy + \alpha E u^{(\sigma+\eta+1-(\sigma'+\eta'))}(y; \sigma', \eta') \right\}. \)
```
