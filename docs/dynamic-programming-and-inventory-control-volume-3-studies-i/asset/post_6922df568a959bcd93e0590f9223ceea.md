
Assumptions (4.3.1), (4.3.2), (4.3.6) are satisfied. So results of Theorems 4.3, 4.4, 4.5 are applicable. We can then state

## Theorem 9.9.
Under the assumptions (9.3.1), (9.3.5) the set of solutions of the functional equation (9.3.3), in the interval \(0 \le u \le w_0\) is not empty and has a minimum and a maximum solution \(\underline{y}\) and \(\bar{y}\). The minimum solution is l.s.c. It coincides with the value function. There exists an optimal control policy, obtained through a feedback \(\hat{v}(x)\).

We can check an estimate for the optimal feedback as in the case without fixed cost.

## Proposition 9.4.
The optimal feedback satisfies

(9.3.8)
\[
\hat{v}(x) \le x^- + \frac{\alpha \bar{D}}{c(1-\alpha)^2}[h + (p+c)(1-\alpha)] + \frac{\alpha K}{1-\alpha}.
\]

Proof. We begin by getting an estimate from below of the value function. It is the same as in the case without fixed cost, with the same proof,

\[
u(x) \ge \frac{hx^+}{1-\alpha} + px^- - \frac{ha\bar{D}}{(1-\alpha)^2}.
\]

The next step is to maximize \(u(x)\) by a convenient function. We do not use \(w_0(x)\) but the function \(w(x)\) solution of

\[
w(x) = K 1_{x<0} + (c+p)x^- + hx^+ + \alpha E w(x^+ - D).
\]

We have that \(u(x) \le w(x)\). The following estimate holds

\[
w(x) \le (c+p)x^- + \frac{hx^+}{1-\alpha} + \frac{K+\alpha(c+p)\bar{D}}{1-\alpha}.
\]

Now, going back to the functional equation (9.3.3), we minimize the quantity within brackets on the right hand side, by using

\[
u(x) \ge \frac{hx^+}{1-\alpha} - \frac{ha\bar{D}}{(1-\alpha)^2}.
\]

We see that it is minorized by

\[
K + cv + \frac{hx^+}{1-\alpha} + px^- - \frac{ha\bar{D}}{(1-\alpha)^2}.
\]

Therefore, looking for the infimum, we can restrict the controls \(v\) to the set

\[
K + cv + \frac{hx^+}{1-\alpha} + px^- - \frac{ha\bar{D}}{(1-\alpha)^2} \le w(x).
\]

Using then the estimate on \(w(x)\), we deduce that we can restrict the set of \(v\) to be bounded by the right hand side of (9.3.8). The optimal feedback must satisfy this bound, hence the result (9.3.8).

We can then prove the uniqueness of the solution of (9.3.3) in the space \(B_1\), where

\[
u \in B_1 \Longleftrightarrow \frac{|u(x)|}{1+|x|} \le C.
\]

## Theorem 9.10.
Under the assumptions (9.3.1), (9.3.5), the solution of (9.3.3) in the space \(B_1\) is unique. The function \(u\) is l.s.c.

Proof. As usual, we are going to check that the minimum and the maximum solution coincide. Define the optimal control associated with the optimal feedback. If we denote the optimal control by \(\bar{V} = (\bar{v}_1, \cdots, \bar{v}_n, \cdots)\) and the optimal trajectory by \(\{\bar{y}_1, \cdots, \bar{y}_n, \cdots\}\) we must prove that \(\bar{V}\) belongs to \(\mathcal{V}\), which means that

\[
\alpha^{j-1} E[\bar{y}_j] \to 0,
\]

as \(j \to \infty\). However, from the estimate (9.3.8) and setting

\[
C = \frac{\alpha D}{c(1-\alpha)^2} [h + (p+c)(1-\alpha)] + \frac{\alpha K}{1-\alpha},
\]

we can state that

\[
\bar{y}_{n+1} \le \bar{y}_n^+ + C,
\]

hence

\[
\bar{y}_{n+1} \le x^+ + nC.
\]

On the other hand

\[
\hat{y}_{n+1} \ge x - D_1 - \cdots - D_n.
\]

Therefore

\[
x - nD \le E\hat{y}_{n+1} \le x^+ + nC,
\]

and the condition is satisfied, hence the result.

### 9.3.2. s, S Policy.
Our objective is now to obtain the optimal feedback. We want to show that it is derived from an s, S policy.

First of all we introduce the operators

(9.3.9)
\[
T(u)(x) = hx^+ + px^- + \alpha Eu(x - D),
\]

and

(9.3.10)
\[
M(u)(x) = \inf_{\eta \ge x^+} [K \mathbf{1}_{\eta > x} + (c-h)(\eta^+ - x^+) + (p+c)(\eta^- - x^+) + u(\eta)].
\]

This operator is a little bit more involved than the one introduced for the case without shortage (see 9.2.10). The variable cost from going to an inventory x to an inventory \(\eta \ge x\) is positive, if the assumption \(c > h\) holds, but is not a function of the difference \(\eta - x\), because the inventories do not have the same meaning when they are positive or negative.

The functional equation (9.3.3) can be written as

\[
u(x) = \min[T(u)(x), M(T(u))(x)],
\]

and we see as in (9.2.11) that this is equivalent to

\[
u(x) = \min[T(u)(x), M(u)(x)].
\]

Define next

(9.3.11)
\[
g(x) = cx(1-\alpha) + \alpha cD + \alpha hE(x-D)^+ + \alpha pE(x-D)^-,
\]

and

(9.3.12)
\[
g_s(x) = (g(x) - g(s))\mathbf{1}_{x > s}.
\]

We then define the function \(H_s(x)\) by solving

(9.3.13)
\[
H_s(x) = g_s(x) + \alpha E H_s(x - D).
\]

We know that the solution is given by

(9.3.14)
\[
H_s(x) = g_s(x) + \alpha g_s * f + \sum_{n=2}^{\infty} \alpha^n g_s * f^{(n)}(x),
\]

and using

\[
F^{(n)}(x) = \int_0^x f^{(n)}(\xi) d\xi,
\]

and

\[
\Gamma(x) = \sum_{n=0}^{\infty} \alpha^n F^{(n)}(x),
\]

then we can easily verify the formula

(9.3.15)
\[
H_s(x) = \int_s^x \Gamma(x - \xi) \mu(\xi) d\xi,
\]

with \(\mu = g'\). The function \(\Gamma(x)\) is the solution of the renewal equation (9.2.19).

## Lemma 9.7.
Assume

(9.3.16)
\[
h < c < p \frac{\alpha}{1-\alpha},
\]

then the function \(H_s(x)\) attains its minimum for \(x \ge s\). Taking the smallest minimum, one defines a function \(S(s)\). If \(\bar{s}\) is the unique value such that \(\mu(s) = 0, \bar{s} > 0\), then \(S(s) = \bar{s}, \forall s \ge \bar{s}\). The equation

(9.3.17)
\[
H_s(S(s)) = \inf_{\eta \ge s} H_s(\eta) = -K,
\]

has a unique solution \(s < \bar{s}\).

Proof. It is similar to the proof of Lemma 9.4. We have

(9.3.18)
\[
g'(x) = \mu(x) = c(1 - \alpha) + \alpha h - \alpha(h + p)\bar{F}(x).
\]

Thanks to the condition (9.3.16) we can define \(\bar{s} > 0\) such that \(\mu(\bar{s}) = 0\) and \(\mu(x) < 0, \forall x < \bar{s}\) and \(\mu(x) > 0, \forall x > \bar{s}\). Since \(\Gamma\) is an increasing function, the function \(H_s(x)\) is increasing in \(x\), whenever \(s \ge \bar{s}\). Therefore we can assert

\[
S(s) = s, \quad \inf_{\eta \ge s} H_s(\eta) = 0, \quad \text{if } s \ge \bar{s}.
\]

So we limit the set of possible \(s\) to satisfy \(s < \bar{s}\). Clearly for \(s < \bar{s} < x\)

\[
H_s(x) = H_s(\bar{s}) + \int_{\bar{s}}^x \Gamma(x - \xi) \mu(\xi) d\xi.
\]

We have again

\[
H_s(x) \ge \frac{1}{1-\alpha} (g(\bar{s}) - g(s)) + g(x) - g(s).
\]

Therefore \(H_s(x) \rightarrow \infty\) as \(x \uparrow \infty\). Since \(H'_s(s+) = \mu(s) < 0\) the function \(H_s(x)\) attains a negative minimum on \((s, \infty)\). We call \(S(s)\) the smallest minimum if there are many. We have

\[
H'_s(S(s)) = 0.
\]

We have next

\[
\frac{d}{ds} H_s(S(s)) = \frac{\partial}{\partial s} H_s(x)|_{S(s)} = -\Gamma(S(s) - s)\mu(s) > 0.
\]

Also

\[
H_s(S(s)) \le H_s(\bar{s}) = \int_s^{\bar{s}} \Gamma(\bar{s} - \xi)\mu(\xi)d\xi \le \frac{1}{\alpha} \int_s^{\bar{s}} \mu(\xi)d\xi = \frac{1}{\alpha}(g(\bar{s}) - g(s)).
\]

Since \( g(s) \to +\infty \), as \( s \to -\infty \), we have \( H_s(S(s)) \to +\infty \), as \( s \to -\infty \). Hence the function \( \inf_{\eta \ge s} H_s(\eta) \) increases from \( -\infty \) to 0, as \( s \) increases from \( -\infty \) to \( \bar{s} \). Therefore there exists a unique \( s \) for which it is equal to \( -K \). We can find the pair \( s, S \) by solving the algebraic system

(9.3.19)
\[
\begin{aligned}
\Gamma(S - s)\mu(s) + \int_s^S \Gamma(S - \xi)\mu'(\xi)d\xi &= 0; \\
\int_s^S \Gamma(S - \xi)\mu(\xi)d\xi &= -K.
\end{aligned}
\]

We can finally state the

## Theorem 9.11.
Under the assumptions (9.3.2), (9.3.5) and (9.3.16) the functional equation (9.3.3) has a unique solution in \( B_1 \), which is continuous, tends to \( +\infty \) as \( |x| \) tends to \( +\infty \). The optimal feedback is defined by an \( s, S \) policy, which is a solution of the system (10.3.22).

Proof. Having defined \( s, S \) by solving (10.3.22), which defines uniquely \( s \), and then \( S \), taking possibly the smallest value, we consider \( H_s(x) \) given by (9.3.15). We will from now on drop the index \( s \), and thus consider \( H(x) \). We then define

(9.3.20)
\[
u(x) = H(x) + hx^+ + px^- - cx + \frac{g(s)}{1-\alpha}.
\]

Then \( u(x) \) satisfies

(9.3.21)
\[
u(x) = \begin{cases} hx^+ + px^- - cx + \frac{g(s)}{1-\alpha}, & x \le s \\ hx^+ + px^- + \alpha E[u(x-D)], & x \ge s \end{cases}
\]

This function is continuous and tends to \( +\infty \) as \( |x| \to +\infty \). And also, from the choice of \( s \), for \( x \le s \)

\[
\begin{aligned}
u(x) &= K + \inf_{\eta \ge x} [\eta u(\eta) + (c-h)(\eta^+ - x^+) - (c+p)(\eta^- - x^-)] \\
&= K + \inf_{\eta \ge x} [\eta u(\eta) + (c-h)(\eta^+ - x^+) - (c+p)(\eta^- - x^-)].
\end{aligned}
\]

Therefore the function \( u \) satisfies

\[
u(x) = \begin{cases} M(u)(x), & \forall x \le s \\ T(u)(x), & \forall x \ge s \end{cases}
\]

So it remains to prove that

\[
\begin{aligned}
u(x) \le T(u)(x), & \quad \forall x \le s \\
u(x) \le M(u)(x), & \quad \forall x \ge s
\end{aligned}
\]

In terms of \( H \) the first inequality amounts to \( g'(x) \ge 0, \forall x \le s \). This is true since \( \mu(\xi) < 0, \forall \xi < s \). The second inequality in terms of H amounts to

(9.3.22)
\[
H(x) \le K + \inf_{\eta \ge x} H(\eta), \quad \forall x \ge s.
\]
