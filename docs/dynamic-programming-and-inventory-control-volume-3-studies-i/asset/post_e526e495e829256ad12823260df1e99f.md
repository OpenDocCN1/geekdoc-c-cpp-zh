
Let \xi > 0. We shall consider the domain x \ge x_0 - \xi. Therefore values lower than s are possible and even negative values are possible. We can write the inequality

(9.2.28) \quad H(x) \le g_s(x) + \alpha E(H(x - D) \mathbb{1}_{x - D \ge x_0 - \xi}), \forall x.

This follows from the fact that

E(H(x - D) \mathbb{1}_{x - D \le x_0 - \xi}) \le 0.

Define next

M(x) = H(x + \xi) + K.

Clearly M(x) \ge 0. We can write thanks to this positivity

M(x) \ge \alpha E(M(x - D) \mathbb{1}_{x - D \ge x_0 - \xi}) + M(x) - \alpha E M(x - D).

Now for x \ge x_0 - \xi we have

H(x + \xi) - \alpha E H(x + \xi - D) = g_s(x + \xi),

hence

M(x) - \alpha E M(x - D) = g_s(x + \xi) + K(1 - \alpha).

Therefore we have

(9.2.29) \quad M(x) \ge g_s(x + \xi) + \alpha E(M(x - D) \mathbb{1}_{x - D \ge x_0 - \xi}), \forall x \ge x_0 - \xi.

We claim that

(9.2.30) \quad g_s(x + \xi) \ge g_s(x), \forall x \ge x_0 - \xi.

Indeed, note that g_s(x + \xi) \ge g_s(x_0) \ge 0 since g is increasing on [s, \infty). So the inequality is obvious, whenever x < s. If x \ge s the inequality amounts to g(x + \xi) \ge g(x). This is true whenever x \ge s, by the monotonicity property. So it remains the case x < s < \xi. But in this case g_s(x) < 0 and the inequality is satisfied.

Let us define Y(x) = H(x) - M(x). From the inequalities (9.2.29) and (9.2.30) we can state that

Y(x) \le \alpha E(Y(x - D) \mathbb{1}_{x - D \ge x_0 - \xi}), \forall x \ge x_0 - \xi,

and Y(x_0 - \xi) \le -K.

These two properties imply Y(x) \le 0, \forall x \ge x_0 - \xi. Therefore we have obtained (9.2.27) \forall x \ge x_0 - \xi and in particular for x > x_0 as desired. We have completed the proof of the fact that the function u(x) characterized by the function H(x) and defined by (9.2.23) is a solution of (9.2.11) or (9.2.5). So it is the value function.

Moreover the s, S policy is associated with a feedback

(9.2.31) \quad \hat{v}(x) = \begin{cases} S - x, & \text{if } x \le s \\ 0, & \text{if } x > s \end{cases}

and it is an optimal feedback corresponding to u, which means

u(x) = l(x, \hat{v}(x)) + \alpha E u((x + \hat{v}(x) - D)^+).

To this feedback rule we can associate a probability P^{\hat{v}, x} for which the canonical process y_n evolves as

y_{n+1} = (y_n + \hat{v}_n - D_n)^+ ,

with \(\tilde{v}_n = \tilde{v}(y_n)\). We can also state
\(u(x) = \sum_{j=1}^n E^{\tilde{v}, x} l(y_j, \tilde{v}_j) + \alpha^n E^{\tilde{v}, \tau} u(y_{n+1}),\)

for any n. But by definition of the s, S policy, one has 0 \le y_{n+1} \le \max(x, S). Therefore u(y_{n+1}) is bounded, hence as n \to \infty we obtain u(x) = J_{\tilde{v}}(V).

**Remark.** When K=0, we have s=S, and S is given by formula (5.1.14). The function u(x) becomes C^1.

Let us prove the following property

**Proposition 9.3.** The function S(s) is decreasing in s, hence \bar{s} \le S(s) \le \min(S_0, \frac{p\bar{D}}{c(1-\alpha)}).

Proof. From the relation H'_s(S(s)) = 0 we deduce
\frac{\partial}{\partial s} H'_s(S(s)) + H''_s(S(s)) S'(s) = 0.

Now, since S(s) is a minimum H''_s(S(s)) > 0. Next use

H'_s(x) = \mu(x) + \int_x^\infty \Gamma'(x-\xi)\mu(\xi)d\xi,

and thus
\frac{\partial}{\partial s} H'_s(x) = -\Gamma'(x-s)\mu(s),

which is positive for s < \bar{s}, since \mu(s) < 0. It follows that S'(s) < 0. The result follows.

**Remark.** We know that \bar{s} \le \frac{p\bar{D}}{c(1-\alpha)}, see Remark 5.1, since \bar{s} corresponds to the Base stock policy in the case without fixed cost. The inequality in the statement implies that \bar{s} \le S_0. Let us prove this fact directly. Indeed we use (from the equation of \Gamma, (9.2.19))

\Gamma(S_0) \le \frac{1}{1-\alpha F(S_0)} = \frac{1}{1-\alpha + \alpha \bar{F}(S_0)}.

It follows that
F(S_0) \le \frac{c(1-\alpha) + \alpha h}{p - \alpha(c-h)} = \bar{F}(s),

from which we deduce S_0 \ge \bar{s}. On the other hand S_0 is not necessarily comparable to \frac{p\bar{D}}{c(1-\alpha)}.

## **9.2.3. K-CONVEXITY THEORY.**

When K=0, we also proved that the solution was convex. The Base stock property of the optimal feedback was an easy consequence of the convexity, the continuity and the fact that the minimum solution tends to \infty as x \uparrow \infty. The properties on u were a consequence of similar properties of the increasing sequence u_n.

In the present context the minimum solution cannot be convex. Fortunately this property can be replaced by another one, the K-convexity. This will be sufficient, together with continuity and growth to \infty at \infty to guarantee that the optimal feedback is described by an s, S policy. This is the way the s, S policy is proven in the literature, since the seminal work of H. Scarf. [35]. We have seen in the previous section that the techniques of impulse control allow to obtain the result, without using K-convexity. L. Benkherouf, [3] has also considered a similar approach in the case of backlog, which will be considered in the next section.

There is however an additional difficulty, due to the fact that the function is only defined on positive arguments. So we have to clarify the properties of K-convex functions defined only on positive arguments, which is not usually the case in the literature.

A function f is K convex whenever, for a < b < c we have

$$K + f(c) - f(b) \ge \frac{c-b}{b-a}(f(b) - f(a)).$$

We need to consider functions defined on [0, \infty). In that case the property holds for a \ge 0.

**Theorem 9.5.** Let f(x) be a K convex function defined on [0, \infty), which is continuous and f(x) \to \infty as x \to \infty. Then, there exist numbers s, S with s \le S and

$$\begin{aligned} f(S) &= \min f(x) \\ s &= 0 \text{ if } f(0) \le K + f(S) \\ f(s) &= K + f(S), \text{ if } f(0) > K + f(S) \\ f(x) \text{ is strictly decreasing on } [0, s], \text{ if } s > 0 \\ f(x) \le K + f(y), \forall x < y \end{aligned}$$

**PROOF.** The continuity and the growth condition imply the existence of S at which the infimum is attained. If the minimum is attained in several points, we take S to be the smallest minimum. Assume first that f(0) \le K + f(S), then we have to prove only the last statement. Take any x such that 0 < x < S. We shall prove that f(x) \le K + f(S). This will imply the result for x < S. The statement is obvious whenever f(x) \le f(0). So we may assume f(x) > f(0). If the statement is not true, then we will have f(x) > K + f(S).

However K-convexity will imply

$$K + f(S) - f(x) \ge \frac{S-x}{x}(f(x) - f(0)),$$

and this leads to a contradiction. It remains to consider the case y > x > S then from K-convexity we get

$$K + f(y) - f(x) \ge \frac{y-x}{x-S}(f(x) - f(S)) \ge 0.$$

The case s = 0 has been completed. We may thus assume that f(0) > K + f(S). Thanks to continuity, there exists s, satisfying the condition of its definition. If they are many, we take the smallest value. Let 0 < x < s, applying K convexity we have

$$0 = K + f(S) - f(S) \ge \frac{S-s}{s-x}(f(s) - f(x)),$$

hence

$$f(x) > f(s), \forall x < s.$$

Now take 0 < x_1 < x_2 < s, by K convexity again we have

K + f(S) - f(x_2) \ge \frac{S - x_2}{x_2 - x_1} (f(x_2) - f(x_1)),

and since the left hand side is negative, we get f(x_2) - f(x_1) < 0.

Let now s < x < S we have

f(s) - f(x) = K + f(S) - f(x) \ge \frac{S - x}{x - s} (f(x) - f(s)),

which implies f(s) > f(x). Finally, for s < x < y we can write

K + f(y) - f(x) \ge \frac{y - x}{x - S} (f(x) - f(S)) \ge 0.

The proof has been completed.
