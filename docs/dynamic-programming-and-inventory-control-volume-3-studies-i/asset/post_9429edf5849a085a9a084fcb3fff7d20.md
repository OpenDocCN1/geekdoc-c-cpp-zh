
## Lemma 9.1.

The set of $v$ in the right hand side of equation (9.1.7) can be bounded by

(9.1.8)
$$ cv \le \frac{K+cD}{1-\alpha} + \frac{\alpha Dh}{(1-\alpha)^2}. $$

Proof. The result will follow from the estimate

$$ u(x) \ge \frac{hx}{1-\alpha} - \frac{\alpha Dh}{(1-\alpha)^2}, $$

which is obtained by iterating on the functional equation (9.1.7), starting with $u(x) \ge hx$. Next, we look for a ceiling function for $u(x)$. Because of the constraint, we cannot as usual the function corresponding to the choice $v=0$. We shall take $v=D$. So we consider the functional equation

$$ w_0(x) = hx + K + cD + \alpha w_0(x), $$

which is simply

(9.1.9)
$$ w_0(x) = \frac{hx + K + cD}{1 - \alpha}. $$

We look for solutions of (9.1.7) which are in the interval $0 \le u(x) \le w_0(x)$. From the bound below of $u$ and the bound above provided by the ceiling function, we deduce from the equation (9.1.7), that the values of $v$ can be restricted by the constraint

$$ hx + cv + \frac{\alpha h(x-D)}{1-\alpha} - \frac{hD\alpha^2}{(1-\alpha)^2} \le \frac{hx + K + cD}{1-\alpha}. $$

We see that the term in $x$ drops out, and there remains the estimate (9.1.8). This concludes the proof.

### 9.1.3. OBTAINING THE OPTIMAL CONTROL POLICY.

In this section we are interested in characterizing the optimal feedback $\tilde{v}(x)$. We first give a different, more convenient form of the equation (9.1.7). We introduce

(9.1.10)
$$ z(x) = cx + \alpha u(x). $$

Then it is fairly easy to rewrite equation (9.1.7) as follows

(9.1.11)
$$ u(x) = (h-c)x + cD + \inf_{\eta \ge \max(x, D)} [K \mathbb{1}_{\eta > x} + z(\eta - D)]. $$

We begin with the inequality

### Lemma 9.2.

(9.1.12)
$$ z(x) \le K + z(y), \forall y > x. $$

Proof. Let \(x < y\). From the equation (9.1.11) we can write

$$
\begin{aligned}
u(x) + (c - h)x &= cD + \inf_{\eta \ge \max(x,D)} [K \mathbf{I}_{\eta > x} + z(\eta - D)] \\
\le cD + K + \inf_{\eta \ge \max(y,D)} z(\eta - D) \\
\le K + cD + \inf_{\eta \ge \max(y,D)} [K \mathbf{I}_{\eta > y} + z(\eta - D)] \\
\le K + u(y) + (c - h)y,
\end{aligned}
$$

which implies

$$ u(x) + cx \le K + u(y) + cy.$$

But then

$$
\begin{aligned}
z(x) &= \alpha(u(x) + cx) + cx(1 - \alpha) \\
\le \alpha K + \alpha(u(y) + cy) + cy(1 - \alpha) \\
\le K + z(y),
\end{aligned}
$$

and the result follows.

### Proposition 9.1.

The solution \(u(x)\) satisfies the property

(9.1.13)
\(x < D \implies u(x) = (h - c)x + cD + K + \inf_{\eta \ge 0} z(\eta)\)

(9.1.14)
\(x \ge D \implies u(x) = hx + \alpha(x - D).\)

Proof. For \(x < D\), the equation (9.1.11) writes

$$ u(x) = (h - c)x + cD + \inf_{\eta \ge D} [K \mathbf{I}_{\eta > x} + z(\eta - D)]. $$

and thus

$$ u(x) = (h - c)x + cD + K + \inf_{\eta \ge D} z(\eta - D). $$

and the property (9.1.13) follows. Next if \(x \ge D\), the equation (9.1.11) becomes

$$ u(x) = (h - c)x + cD + \inf_{\eta \ge x} [K \mathbf{I}_{\eta > x} + z(\eta - D)]. $$

But from Lemma 9.2 we have

$$ z(x - D) \le K + z(\eta - D), \forall x < \eta, $$

hence

$$ u(x) = (h - c)x + cD + z(x - D). $$

Recalling the definition of \(z(x)\) we deduce (9.1.14). This concludes the proof.

### Lemma 9.3.

We have the property

$$ \alpha u(0) \le u(0) \le cD. $$

Proof. We have \(\alpha u(0) = z(0)\). Now from (9.1.13)

$$ u(0) = cD + K + \inf_{\eta \ge 0} z(\eta). $$

But \(\inf_{\eta \ge 0} z(\eta)\) is attained at a point \(\eta^* \ge 0\). But from Lemma 9.2, we have

$$ z(0) \le K + z(\eta^*), $$

and the result follows.

We can now assert the main result

## Theorem 9.2.

We assume (9.1.6). The optimal feedback is characterized as follows

(9.1.15)
\(\hat{v}(x) = \begin{cases} 0, & \text{if } x \ge D \\ D(1+\hat{k}) - x, & \text{if } x < D \end{cases}\)

where \(\hat{k}\) is a positive integer which minimizes the quantity

(9.1.16)
\(\lambda(k) = \frac{K + c(k+1)D + \alpha h D F(k)}{1 - \alpha^{k+1}},\)

where

(9.1.17)
\(F(k) = \frac{\alpha^{k+1} - (k+1)\alpha + k}{(1 - \alpha)^2}.\)

Proof. From Proposition 9.1 it follows that \(u(x)\) is piece wise linear, but not continuous. The discontinuity points are \(Dk, k = 1, 2, \cdots\) Let us write

$$ u(0) = cD + K + \inf_{\eta \ge 0} z(\eta). $$

We can easily obtain formulas for \(u((kD)^+)\) and \(u((kD)^-)\), where these symbols mean the limit to the right and the limit to the left at point \(kD\). Indeed for \(k \ge 1\)

$$ u(((j+1)D)^-) = hD(j+1) + \alpha u((jD)^-), $$

and we deduce easily

(9.1.18)
\(u(((k+1)D)^-) = hD \sum_{j=0}^k (k+1-j)\alpha^j + \alpha^k(u(0) - cD), k \ge 0.\)

Similarly for \(k \ge 0\)

$$ u(((j+1)D)^+) = hD(j+1) + \alpha u((jD)^+), $$

and thus

(9.1.19)
\(u(((k+1)D)^+) = hD \sum_{j=0}^k (k+1-j)\alpha^j + \alpha^{k+1}u(0), k \ge 0.\)

From Lemma 9.3 we can see that

$$ u(((k+1)D)^+) \le u(((k+1)D)^-), \forall k \ge 0 $$

Since \(z(x)\) is also piece-wise linear, with the same discontinuity points as \(u(x)\), it follows from this inequality that

(9.1.20)
\(\inf_{\eta \ge 0} z(\eta) = \inf_{k \ge 0} [ckD + \alpha u((kD)^+)].\)

We can compute for \(k \ge 1\)

$$ F(k) = \sum_{j=0}^{k-1} (k-j)\alpha^j $$
$$ = k \frac{1-\alpha^k}{1-\alpha} - \frac{\alpha}{(1-\alpha)^2}(1 - k\alpha^{k-1} + (k-1)\alpha^k) $$
$$ = \frac{\alpha^{k+1} - (k+1)\alpha + k}{(1-\alpha)^2}. $$

Note that this expression is also valid for \( k=0 \), by taking \( F(0)=0 \). So we can write

$$ u((kD)^+) = F(k) + \alpha^k u(0), k \ge 0 $$

Therefore from (9.1.20), we can state

(9.1.21)
\( \inf_{n \ge 0} z(n) = \inf_{k \ge 0} [ckD + \alpha h D F(k) + \alpha^{k+1} u(0)] . \)

Now from (9.1.13), we have

$$ u(0) = K + \inf_{k \ge 0} [c(k+1)D + \alpha h D F(k) + \alpha^{k+1} u(0)] , $$

from which one gets easily

$$ u(0) = \inf_{k \ge 0} \lambda(k), $$

with \(\lambda(k)\) given by (9.1.16). If \(\hat{k}\) achieves the infimum, then \(\hat{k}D\) achieves also the infimum of \(z(n)\). Since for \(x < D\), this infimum is achieved by \(x + \hat{v}(x) - D\), from the definition of the feedback, we can state that

$$ x + \hat{v}(x) - D = \hat{k}D, $$

and we obtain (9.1.15). Note that \(\lambda(k)\) attains its infimum since \(\lambda(k) \to \infty\) as \(k \to \infty\).

We now consider particular cases

### Proposition 9.2.

Assume that

(9.1.22)
\( \alpha(K + cD) \le cD + \alpha hD, \)

then \(\hat{k} = 0\).

Proof. We use the fact that \(\hat{k}\) is also the value of \(k\) for which \(c(k+1)D + \alpha h D F(k) + \alpha^{k+1} u(0)\) attains its minimum. Let us prove that this function is increasing in \(k\), when the assumption is made. Using the fact that

$$ F(k+1) - F(k) = \frac{1 - \alpha^{k+1}}{1 - \alpha}, $$

we must check that for any \(k\), we have

$$ u(0)(\alpha^{k+1} - \alpha^{k+2}) \le cD + \alpha hD \frac{1 - \alpha^{k+1}}{1 - \alpha}. $$

We know that

$$ u(0) \le w_0(0) = \frac{K + cD}{1 - \alpha}. $$

Therefore, it is sufficient to verify

$$ \alpha^{k+1}(K + cD) \le cD + \alpha hD \frac{1 - \alpha^{k+1}}{1 - \alpha}, $$

hence

$$ \alpha^{k+1} \left[ K + cD + \frac{hD\alpha}{1 - \alpha} \right] \le cD + \frac{\alpha hD}{1 - \alpha}, $$

and it suffices to check that it is true for \(k=0\), which is exactly the condition (9.1.22).

### Remark 9.1.

The optimal feedback is said to be derived from an s, S policy, with s = D and S = D(k + 1). Note that if K = 0, then (9.1.22) is satisfied and k = 0, which implies s = S. We have in this case a Base stock policy, with Base stock equal to the demand. If we consider the optimal policy \(\hat{V} = \{\hat{v}_1, \cdots, \hat{v}_n, \cdots \}\) and the corresponding evolution of the inventory \(\hat{y}_1, \cdots, \hat{y}_n, \cdots\) then we have the property

(9.1.23)
\(\hat{y}_n \hat{v}_n = 0, \forall n\)

This property is known as Wagner-Whitin Theorem.

## 9.2. INVENTORY CONTROL WITH FIXED COST AND NO SHORTAGE

### 9.2.1. BELLMAN EQUATION

We consider the analogue of section 5.1 of Chapter 5. We define the function \(l(x, v)\) as follows

(9.2.1)
\(l(x, v) = K \mathbf{1}_{\{v>0\}} + cv + hx + p E(x + v - D)^- ,\)

which is the same as equation (5.1.8) with a fixed cost \(K\) whenever an order is made, whatever the size. Note that \(K \mathbf{1}_{\{v>0\}}\) is l.s.c. It incorporates an ordering cost (purely a variable cost), a holding cost and a penalty for lost sales. We note the inequalities

(9.2.2)
\(K \mathbf{1}_{\{v>0\}} + cv + hx \le l(x, v) \le K \mathbf{1}_{\{v>0\}} + cv + hx + p \bar{D},\)

where \(\bar{D} = ED\). Therefore the function \(l(x, v)\) satisfies the properties (4.3.2), (4.5.1) and the first condition (4.5.4), with

(9.2.3)
\(l_0 = p \bar{D}.\)

The operator \(\Phi^v\) is defined by (5.1.2), or equivalently by (5.1.5). We note that assumptions (4.3.1), (4.5.2), (4.5.4) are satisfied.

So the results of Chapter 4, in particular Theorem 4.8 apply. The functional equation (4.3.7) reads

(9.2.4)
\(u(x) = \inf_{v \ge 0} \{ l(x, v) + \alpha E u((x + v - D)^+) \}.\)

We can also write it as

(9.2.5)
\(u(x) = (h - c)x + \inf_{\eta \ge x} \{ K \mathbf{1}_{\{\eta > x\}} + c\eta + p E((\eta - D)^-) + \alpha E u((\eta - D)^+) \}.\)

(9.2.6)
