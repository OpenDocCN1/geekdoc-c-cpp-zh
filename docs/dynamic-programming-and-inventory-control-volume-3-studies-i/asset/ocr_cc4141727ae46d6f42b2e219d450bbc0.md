Remark 9.1. The optimal feedback is said to be derived from an s, S policy, with s = D and S = D(k + 1). Note that if K = 0, then (9.1.22) is satisfied and k = 0, which implies s = S. We have in this case a Base stock policy, with Base stock equal to the demand. If we consider the optimal policy \(\hat{V} = \{\hat{v}_1, \cdots, \hat{v}_n, \cdots \}\) and the corresponding evolution of the inventory \(\hat{y}_1, \cdots, \hat{y}_n, \cdots\) then we have the property

```
(9.1.23)
\(\hat{y}_n \hat{v}_n = 0, \forall n\)
```

This property is known as Wagner-Whitin Theorem.
