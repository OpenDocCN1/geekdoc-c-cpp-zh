choice of s is dictated by a continuity condition of the cost function, and not by an optimization (unlike the choice of S). As for the case without backlog, we have shown in Theorem 9.11, that the function defined by this s, S control policy is the value function and is solution of the Bellman equation.

# 9.3.4. INVARIANT MEASURE.

We have already obtained the invariant measure in section 3.6.2 of Chapter 3. We recall the result. The state space is \(X = (-\infty, S)\) and the invariant measure has a density with respect to Lebesgue's measure given by

```
\(m(\eta) = \begin{cases} \frac{f(S-\eta)+\int_{\eta}^{S} z(x)f(x-\eta)dx}{1+\int_{\eta}^{S} z(y)dy}, & \text{if } \eta \le s \\ \frac{z(\eta)}{1+\int_{\eta}^{S} z(y)dy}, & \text{if } s \le \eta \le S \end{cases}\)
```

where the function \(z(\eta)\) is defined in \(s, S\) as the unique solution of the integral equation

```
\(z(\eta) = f(S-\eta) + \int_{\eta}^{S} z(x)f(x-\eta)dx, \quad s \le \eta \le S,\)
```

which has a unique solution in \(B(s, S)\), if \(F(S) < 1\).

Consider now the objective function \(J_{\bar{\nu}}(V_s)\), when we apply a control \(V = V_{s,S}\) defined by an \(s, S\) policy. The inventory \(y_n\) becomes ergodic so we have

```
\((1-\alpha)\int_{-\infty}^{S} J_{\bar{\nu}}(V_{s,S})m_{s,S}(x)dx = \int_{-\infty}^{S} [hx^+ + px^- + (K+c(S-x))\mathbb{1}_{s \le x}]m_{s,S}(x)dx.\)
```

Note that the integrals are well defined, in view of the fact that \(D\) is finite, see also (9.3.38) below.

Also

```
\((1-\alpha)\int_{-\infty}^{S} J_{\bar{\nu}}(V_{s,S})m_{s,S}(x)dx = \int_{-\infty}^{S} [(1-\alpha)(hx^+ + px^- - cx) + (K+c(S-x))\mathbb{1}_{s \le x}]m_{s,S}(x)dx + \int_{-\infty}^{S} [c(1-\alpha)x + \alpha(hx^+ + px^-)]m_{s,S}(x)dx.\)
```

We omit the indices s, S to simplify notation. Recall that

```
\(g(x) = cx(1-\alpha) + \alpha c\bar{D} + \alpha h E(x-D)^+ + \alpha p E(x-D)^-.\)
```

It follows that

```
\(g(x)\mathbb{1}_{x>s} + g(S)\mathbb{1}_{x \le s} = c(1-\alpha)x + \alpha c\bar{D} + c(1-\alpha)(S-x)\mathbb{1}_{x \le s} + \alpha h E(x-D)^+ \mathbb{1}_{x>s} + \alpha h E(S-D)^+ \mathbb{1}_{x \le s} + \alpha p E(x-D)^- \mathbb{1}_{x>s} + \alpha p E(S-D)^- \mathbb{1}_{x \le s}.\)
```

On the other hand, from the equation giving \(H(x)\), see (9.3.13), we have

```
\(g(x)\mathbb{1}_{x>s} + g(S)\mathbb{1}_{x \le s} = H(x) + H(S)\mathbb{1}_{x \le s} + g(s) - \alpha [EH(x-D)\mathbb{1}_{x>s} + EH(S-D)\mathbb{1}_{x \le s}].\)
```
