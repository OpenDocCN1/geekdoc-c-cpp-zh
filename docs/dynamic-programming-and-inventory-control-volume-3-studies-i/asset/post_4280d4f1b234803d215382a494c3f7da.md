
it varies continuously between \(u(0) = a_\varpi(b_\varpi(0)) < 0\) and \(u(-\infty) = +\infty\) and thus crosses the value 0.

Consider a solution \(\hat{a}, \hat{b}\) of the system

```
\(\dot{a} = a(\hat{b}); \dot{b} = b(\hat{a}),\)
```

and

```
\(\dot{A} = A(\hat{a}, \hat{b}); \dot{B} = B(\hat{a}, \hat{b}).\)
```

If \(\hat{A} < 0, \hat{B} > 0\) then

```
\(\hat{A} = \hat{a} + \varpi, \hat{B} = \hat{b} - \pi,\)
```

and also

```
\(\hat{a} = a_\varpi(\hat{b}), \hat{b} = b_\pi(\hat{a}).\)
```

If \(\hat{A} > 0\), then \(\hat{B} > 0\). Therefore

```
\(\hat{B} = \hat{b} - \pi, \hat{b} = b_\pi(\hat{a}).\)
```

Since \(\hat{a} \neq a_\varpi(\hat{b})\), then \(\hat{a} + \varpi > 0\). We must also have \(a_\varpi(b_\pi^+) + \varpi > 0\), so the interval \((b_\pi^1, b_\pi^2)\) is well defined (possibly \(b_\pi^2 = +\infty\)) and

```
\(b_\pi^1 < \hat{b} < b_\pi^2.\)
```

Since \(\hat{b} = b_\pi(\hat{a})\) the sign of \(b_\pi(a_\pi^+) - \pi\) is not specified. However if \(b_\pi(a_\pi^+) - \pi < 0\), then the interval \((a_\pi^1, a_\pi^2)\) is well defined (possibly \(a_\pi^1 = -\infty\)) and we have

```
\(\hat{a} < a_\pi^1 \text{ or } \hat{a} > a_\pi^2.\)
```

The first case disappears if \(a_\pi^1 + \varpi < 0\) (in particular if \(a_\pi^1 = -\infty\)).

Similarly if \(\hat{B} < 0\), then \(\hat{A} < 0\). So we have

```
\(\hat{A} = \hat{a} + \varpi, \hat{a} = a_\varpi(\hat{b}).\)
```

Since \(\hat{b} \neq b_\pi(\hat{a})\), then \(\hat{b} - \pi < 0\). We must also have \(b_\pi(a_\pi^+) - \pi < 0\), so the interval \((a_\pi^1, a_\pi^2)\) is well defined (possibly \(a_\pi^1 = -\infty\)) and

```
\(a_\pi^1 < \hat{a} < a_\pi^2.\)
```

Since \(\hat{a} = a_\varpi(\hat{b})\) the sign of \(a_\varpi(b_\varpi^+) + \varpi\) is not specified. However if \(a_\varpi(b_\varpi^+) + \varpi > 0\), then the interval \((b_\varpi^1, b_\varpi^2)\) is well defined (possibly \(b_\varpi^2 = +\infty\)) and we have

```
\(\hat{b} < b_\varpi^1 \text{ or } \hat{b} > b_\varpi^2.\)
```

The second case disappears if \(b_\varpi^2 > \pi\), in particular if \(b_\varpi^2 = +\infty\).

From the preceding discussion, we can define the following procedure for the search of the pair \(\hat{a}, \hat{b}\). We consider a crossing point of the curves \(a_\varpi(b)\) and \(b_\pi(a)\), denoted by \(a_0, b_0\).

- (1) If \(a_0 + \varpi \le 0\) and \(b_0 - \pi \ge 0\), then \(\hat{a} = a_0, \hat{b} = b_0\)
- (2) If \(a_\varpi(b_0^+) + \varpi \le 0\) and \(b_\pi(a_\varpi^+) - \pi \ge 0\), then \(\hat{a} = a_0, \hat{b} = b_0\)
- (3) If one condition in step 1 and 2 is not satisfied, then we consider two possible scenarios:

### Scenario 1

If \(a_\pi(b_\varpi^+) > 0\) and \(b_\pi(a_\pi^+) - \pi \ge 0\), then \(\hat{b} = b_\pi(a_\pi^+)\hat{b}_\varpi^- < b_\pi(a_\pi^+) < b_{\pi \varpi}^+\), \(\hat{B} = -\hat{b} = \hat{b} - \pi\) and \(-\infty \le \hat{a} \le 0, 0 < \hat{A} < b_\pi(a_\pi^+) - \pi\) and

\(K^+ + \frac{1}{\alpha}((h - ac^+)\hat{A} + \hat{a}(p - ac^-)) + \frac{1}{\alpha} \frac{p - ac^+}{\beta_1 \beta_2} (\beta_1 - \beta_2)\)
\(\frac{(\exp \beta_1(\hat{A} - \hat{a}) - 1)(\exp \beta_2(\hat{A} - \hat{a}) - 1)}{\exp \beta_1(\hat{A} - \hat{a}) - \exp \beta_2(\hat{A} - \hat{a})} + \frac{1}{\alpha} \frac{p + h}{\beta_1 \beta_2}\)
\(\frac{\beta_1 (\exp \beta_1(\hat{A} - \hat{a}) - 1)(1 - \exp \beta_2(\hat{A} - \hat{a})) - \beta_2 (\exp \beta_2(\hat{A} - \hat{a}) - 1)(1 - \exp \beta_1 \hat{A})}{\exp \beta_1(\hat{A} - \hat{a}) - \exp \beta_2(\hat{A} - \hat{a})} = 0;\)
\((c^+ + c^-)(\exp \beta_1(\hat{A} - \hat{a}) - \exp \beta_2(\hat{A} - \hat{a})) - \frac{h + ac^+}{\alpha}\)
\(\cdot (\exp \beta_1(\hat{A} - \hat{a}) - \exp \beta_2(\hat{A} - \hat{a}) - \exp \beta_1(b_\pi(a_\pi^+) - \hat{a}) + \exp \beta_2(b_\pi(a_\pi^+) - \hat{a}))\)
\(- \frac{p + h}{\alpha(\beta_1 - \beta_2)} (\exp \beta_2 \hat{A} + \beta_1 b_\pi(a_\pi^+)) - \exp(\beta_1 \hat{A} + \beta_2 b_\pi(a_\pi^+)))\)
\(\cdot (\beta_1 \exp -\beta_1 \hat{a} - \beta_2 \exp -\beta_2 \hat{a}) + \frac{p - ac^+}{\alpha} \exp -(\beta_1 + \beta_2)\hat{a}\)
\(\cdot (\exp(\beta_2 \hat{A} + \beta_1 b_\pi(a_\pi^+)) - \exp(\beta_1 \hat{A} + \beta_2 b_\pi(a_\pi^+))) = 0.\)

### Scenario 2

If \(a_\varpi(b_\pi^+) + \varpi \le 0\) and \(b_\pi(a_\pi^+) - \pi < 0\), then \(\hat{a} = a_\varpi(\hat{b})\), \(a_\pi^+ < a_\varpi(\hat{b}) < a_\pi^+\), \(\hat{A} = \hat{a} + \varpi, 0 < \hat{b} < \pi, a_\varpi(\hat{b}) + \varpi < \hat{B} < 0\) and

\(-K^- + \frac{1}{\alpha}((h - ac^-)\hat{b} + (p + ac^-)\hat{B})\)
\(+ \frac{1}{\alpha} \frac{h - ac^-}{\beta_1 \beta_2} (\beta_1 - \beta_2) \frac{(\exp \beta_1(\hat{B} - \hat{b}) - 1)(\exp \beta_2(\hat{B} - \hat{b}) - 1)}{\exp \beta_1(\hat{B} - \hat{b}) - \exp \beta_2(\hat{B} - \hat{b})} + \frac{1}{\alpha} \frac{p + h}{\beta_1 \beta_2}\)
\(\frac{\beta_1 (\exp \beta_1(\hat{B} - \hat{b}) - 1)(1 - \exp \beta_2 \hat{B}) - \beta_2 (\exp \beta_2(\hat{B} - \hat{b}) - 1)(1 - \exp \beta_1 \hat{B})}{\exp \beta_1(\hat{B} - \hat{b}) - \exp \beta_2(\hat{B} - \hat{b})} = 0;\)
\(-(c^+ + c^-)(\exp \beta_1(\hat{B} - \hat{b}) - \exp \beta_2(\hat{B} - \hat{b})) + \frac{p + ac^-}{\alpha}\)
\(\cdot (\exp \beta_1(\hat{B} - \hat{b}) - \exp \beta_2(\hat{B} - \hat{b}) - \exp \beta_1(a_\pi(a_\pi^+) - \hat{b}) + \exp \beta_2(a_\pi(a_\pi^+) - \hat{b}))\)
\(+ \frac{p + h}{\alpha(\beta_1 - \beta_2)} (\exp \beta_2 \hat{B} + \beta_1 a_\pi(\hat{a})) - \exp(\beta_1 \hat{B} + \beta_2 a_\pi(\hat{a})))\)
\(\cdot (\beta_1 \exp -\beta_1 \hat{b} - \beta_2 \exp -\beta_2 \hat{b}) - \frac{h - ac^-}{\alpha} \exp -(\beta_1 + \beta_2)\hat{b}\)
\(\cdot (\exp(\beta_2 \hat{B} + \beta_1 a_\pi(\hat{a})) - \exp(\beta_1 \hat{B} + \beta_2 a_\pi(\hat{a}))) = 0.\)

If \(a_\varpi(b_\pi^+) + \varpi > 0\) and \(b_\pi(a_\pi^+) - \pi < 0\), then one may have either scenario 1 or scenario 2. If scenario 1 takes place then we have the additional restriction on \(a : \hat{a} < a_\pi^+\) or \(\hat{a} > a_\pi^+\). The first case disappears if \(a_\pi^+ + \varpi < 0\) (in particular if \(a_\pi^+ = -\infty\)), if scenario 2 takes place, then we have the additional restriction on \(\hat{b} : \hat{b} < b_{\pi \varpi}^+\) or \(\hat{b} > b_{\pi \varpi}^+\). The second case disappears if \(b_{\pi \varpi}^+ > \pi\), in particular if \(b_{\pi \varpi}^+ = +\infty\).
