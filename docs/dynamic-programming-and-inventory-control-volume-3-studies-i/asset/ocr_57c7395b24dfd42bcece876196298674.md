hence

\(J(q) = h \int_0^1 t F\left(\frac{q}{t}\right) dt + p \int_0^1 t F\left(\frac{q}{t}\right) dt\)

and the optimal quantity is given by

(2.1.6) \(F(\hat{q}) + \hat{q} \int_{\hat{q}}^{\infty} \frac{f(u)}{u} du = \frac{p}{h+p}.\)

It is easy to check that equation (2.1.6) has a unique solution.

# 2.2. EOQ MODEL

# 2.2.1. BASIC EOQ MODEL.

EQO stands for Economic Order Quantity. This is also a famous and very old model. It is due to F.W. Harris, [23] and R.H. Wilson, [40]. The model is deterministic. In fact the model is not static but dynamic and time is continuous. We will revisit it when we will treat dynamic models. However, it is possible to reduce it to a static model, by a simple argument of periodicity. The demand materials uniformly (and permanently) at a rate per unit of time \(\lambda\). We forbid the possibility of shortage. We order a quantity \(q\) when the inventory vanishes. Suppose we start at time 0 with \(q\) then at time \(T\) such that

\(q = \lambda T;\)

the inventory vanishes. Clearly, \(T\) can be taken as a cycle. We want to minimize the average cost during a cycle.

The level of inventory during the cycle is given by

\(y(t) = q - t\lambda.\)

The cost of buying \(q\) is given by \(K + cq\), where \(K\) represents the fixed cost and \(c\) the variable cost. There is a storage cost proportional to the quantity held per unit of time. Therefore, during the cycle, the storage cost is given by

\(\int_0^T hy(t)dt = h \int_0^T (q - t\lambda)dt = \frac{hqT}{2}.\)

The total cost, during a cycle can then be written as

\(K + cq + \frac{hqT}{2} = T(c\lambda + C(q)),\)

with

\(C(q) = K \frac{\lambda}{q} + \frac{hq}{2}.\)

Therefore the optimal order is (EOQ Formula)

\(\hat{q} = \sqrt{\frac{2K\lambda}{h}}.\)

Note that

\(K \frac{\lambda}{\hat{q}} = \frac{h\hat{q}}{2},\)

and

\(C(\hat{q}) = h\hat{q}.\)
