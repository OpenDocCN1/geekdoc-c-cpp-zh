# -Scenario 1

If \(a_x(b_w^+) > 0\) and \(b_x(a_x^+) - \pi \ge 0\), then \(\hat{b} = b_x(a_x^+)\hat{b}_w^- < b_x(a_x^+) < b_{xw}^+\), \(\hat{B} = -\hat{b} = \hat{b} - \pi\) and \(-\infty \le \hat{a} \le 0, 0 < \hat{A} < b_x(a_x^+) - \pi\) and

\(K^+ + \frac{1}{\alpha}((h - ac^+)\hat{A} + \hat{a}(p - ac^-)) + \frac{1}{\alpha} \frac{p - ac^+}{\beta_1 \beta_2} (\beta_1 - \beta_2)\)
\(\frac{(\exp \beta_1(\hat{A} - \hat{a}) - 1)(\exp \beta_2(\hat{A} - \hat{a}) - 1)}{\exp \beta_1(\hat{A} - \hat{a}) - \exp \beta_2(\hat{A} - \hat{a})} + \frac{1}{\alpha} \frac{p + h}{\beta_1 \beta_2}\)
\(\frac{\beta_1 (\exp \beta_1(\hat{A} - \hat{a}) - 1)(1 - \exp \beta_2(\hat{A} - \hat{a})) - \beta_2 (\exp \beta_2(\hat{A} - \hat{a}) - 1)(1 - \exp \beta_1 \hat{A})}{\exp \beta_1(\hat{A} - \hat{a}) - \exp \beta_2(\hat{A} - \hat{a})} = 0;\)
\((c^+ + c^-)(\exp \beta_1(\hat{A} - \hat{a}) - \exp \beta_2(\hat{A} - \hat{a})) - \frac{h + ac^+}{\alpha}\)
\(\cdot (\exp \beta_1(\hat{A} - \hat{a}) - \exp \beta_2(\hat{A} - \hat{a}) - \exp \beta_1(b_x(a_x^+) - \hat{a}) + \exp \beta_2(b_x(a_x^+) - \hat{a}))\)
\(- \frac{p + h}{\alpha(\beta_1 - \beta_2)} (\exp \beta_2 \hat{A} + \beta_1 b_x(a_x^+)) - \exp(\beta_1 \hat{A} + \beta_2 b_x(a_x^+)))\)
\(\cdot (\beta_1 \exp -\beta_1 \hat{a} - \beta_2 \exp -\beta_2 \hat{a}) + \frac{p - ac^+}{\alpha} \exp -(\beta_1 + \beta_2)\hat{a}\)
\(\cdot (\exp(\beta_2 \hat{A} + \beta_1 b_x(a_x^+)) - \exp(\beta_1 \hat{A} + \beta_2 b_x(a_x^+))) = 0.\)

# -Scenario 2

If \(a_\infty(b_x^+) + \varpi \le 0\) and \(b_x(a_x^+) - \pi < 0\), then \(\hat{a} = a_\infty(\hat{b})\), \(a_x^+ < a_\infty(\hat{b}) < a_x^+\), \(\hat{A} = \hat{a} + \varpi, 0 < \hat{b} < \pi, a_\infty(\hat{b}) + \varpi < \hat{B} < 0\) and

\(-K^- + \frac{1}{\alpha}((h - ac^-)\hat{b} + (p + ac^-)\hat{B})\)
\(+ \frac{1}{\alpha} \frac{h - ac^-}{\beta_1 \beta_2} (\beta_1 - \beta_2) \frac{(\exp \beta_1(\hat{B} - \hat{b}) - 1)(\exp \beta_2(\hat{B} - \hat{b}) - 1)}{\exp \beta_1(\hat{B} - \hat{b}) - \exp \beta_2(\hat{B} - \hat{b})} + \frac{1}{\alpha} \frac{p + h}{\beta_1 \beta_2}\)
\(\frac{\beta_1 (\exp \beta_1(\hat{B} - \hat{b}) - 1)(1 - \exp \beta_2 \hat{B}) - \beta_2 (\exp \beta_2(\hat{B} - \hat{b}) - 1)(1 - \exp \beta_1 \hat{B})}{\exp \beta_1(\hat{B} - \hat{b}) - \exp \beta_2(\hat{B} - \hat{b})} = 0;\)
\(-(c^+ + c^-)(\exp \beta_1(\hat{B} - \hat{b}) - \exp \beta_2(\hat{B} - \hat{b})) + \frac{p + ac^-}{\alpha}\)
\(\cdot (\exp \beta_1(\hat{B} - \hat{b}) - \exp \beta_2(\hat{B} - \hat{b}) - \exp \beta_1(a_x(a_x^+) - \hat{b}) + \exp \beta_2(a_x(a_x^+) - \hat{b}))\)
\(+ \frac{p + h}{\alpha(\beta_1 - \beta_2)} (\exp \beta_2 \hat{B} + \beta_1 a_x(\hat{a})) - \exp(\beta_1 \hat{B} + \beta_2 a_x(\hat{a})))\)
\(\cdot (\beta_1 \exp -\beta_1 \hat{b} - \beta_2 \exp -\beta_2 \hat{b}) - \frac{h - ac^-}{\alpha} \exp -(\beta_1 + \beta_2)\hat{b}\)
\(\cdot (\exp(\beta_2 \hat{B} + \beta_1 a_x(\hat{a})) - \exp(\beta_1 \hat{B} + \beta_2 a_x(\hat{a}))) = 0.\)

If \(a_\infty(b_x^+) + \varpi > 0\) and \(b_x(a_x^+) - \pi < 0\), then one may have either scenario 1 or scenario 2. If scenario 1 takes place then we have the additional restriction on \(a : \hat{a} < a_x^+\) or \(\hat{a} > a_x^+\). The first case disappears if \(a_x^+ + \varpi < 0\) (in particular if \(a_x^+ = -\infty\)), if scenario 2 takes place, then we have the additional restriction on \(\hat{b} : \hat{b} < b_{xw}^+\) or \(\hat{b} > b_{xw}^+\). The second case disappears if \(b_{xw}^+ > \pi\), in particular if \(b_{xw}^+ = +\infty\).
