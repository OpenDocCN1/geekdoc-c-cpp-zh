# Lemma 15.3. For any bounded function \(\varphi\) we can construct a sequence \(\varphi_\epsilon\) belonging to the domain of \(A\) such that

```
\|\varphi_\epsilon\| = \sup_x |\varphi_\epsilon(x)| \le \|\varphi\|
```

```
(15.6.13) \quad \int_s^{+\infty} m(x)|\varphi_\epsilon(x) - \varphi(x)|^2 dx \to 0, \quad \text{as } \epsilon \to 0
```

PROOF. We consider the solution of the problem

```
A\varphi_\epsilon(x) + \frac{\varphi_\epsilon(x)}{\epsilon} = \frac{\varphi(x)}{\epsilon}, \quad \forall x > s
\varphi_\epsilon(x) = \varphi_\epsilon(S), \quad \forall x \le s
```

Set

```
\tilde{\varphi}_\epsilon(x) = \varphi_\epsilon(x) - ||\varphi||,
```

then

```
A\tilde{\varphi}_\epsilon(x) + \frac{\tilde{\varphi}_\epsilon(x) - ||\varphi||}{\epsilon} = \frac{\varphi(x) - ||\varphi||}{\epsilon}, \quad \forall x > s
\tilde{\varphi}_\epsilon(x) = \tilde{\varphi}_\epsilon(S), \quad \forall x \le s
```

and thus \(\tilde{\varphi}_\epsilon(x) \le 0\). Similarly

```
\varphi_\epsilon(x) + ||\varphi|| \ge 0,
```

and the first property (15.6.22) follows. From Lemma 15.2 we can assert that

+ \int_s^{+\infty} m \frac{\varphi_\epsilon^2}{\epsilon} dx = \int_s^{+\infty} m \frac{\varphi \varphi_\epsilon}{\epsilon} dx.
```

It follows that

```
\int_s^{+\infty} m \varphi_\epsilon^2 dx \le \int_s^{+\infty} m \varphi_\epsilon f dx.
```

Consider the Hilbert space \(L_m^2(R)\) of functions \(z\) such that

```
\int_s^{+\infty} m z^2 dx < +\infty.
```

The sequence \(\varphi_\epsilon\) remains bounded in this Hilbert space. If we consider a weakly convergent subsequence converging towards \(\varphi^*\) then

```
