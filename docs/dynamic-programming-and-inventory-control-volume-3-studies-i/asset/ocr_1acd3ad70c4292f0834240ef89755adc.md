From the estimates obtained we can assert that \(\bar{u}_\alpha(x, z)\) has a converging subsequence (still denoted \(\alpha\)), in the sense

```
(12.4.36) 
\(\sup_{x \le M \\ z \le N} |\bar{u}_\alpha(x, z) - u(x, z)| \to 0, \text{ as } \alpha \to 0.\)
```

Since \(\rho_\alpha\) is bounded, we can always assume that \(\rho_\alpha \to \rho\). Denote

```
\(L(x, z, v) = K \mathbb{I}_{v>0} + l(x, z, v) + \Phi^e u(x, z)\)
```

then

```
\(L_\alpha(x, z, v) - L(x, z, v) = \alpha \Phi^e(\bar{u}_\alpha - u)(x, z) - (1 - \alpha) \Phi^e u(x, z)\)
```

For \(v \le \max(x, m_0) - x\), we have assuming \(M > m_0\)

```
\(\sup_{x \le M \\ z} |\Phi^e u(x, z)| \le C + \frac{CM}{1 - \delta_0(M)}\)
```

We also have

```
\(\sup_{x \le M \\ z} |\Phi^e(\bar{u}_\alpha - u)(x, z)| \le \sup_{x \le M \\ z} |\bar{u}_\alpha - u|(x, z) \sup_z \bar{F}(N, z)\)
\(+ \sup_{x \le M \\ z \le N} |\bar{u}_\alpha - u|(x, z)\)
```

Using the assumption (12.4.25) and (12.4.36), letting first \(\alpha \to 1\), then \(N \to \infty\), we deduce

```
\(\sup_{v \le \max(x, m_0) - x \\ z \le M} |L_\alpha(x, z, v) - L(x, z, v)| \to 0, \text{ as } \alpha \to 1\)
```

Therefore we deduce easily (12.4.28) and also that the pair \(u(x, z), \rho\) satisfy (12.4.31). The estimates (12.4.29), (12.4.31) follow immediately from the corresponding ones on \(\bar{u}_\alpha(x, z)\). The \(K\)-convexity of \(u\) follows from the \(K\)-convexity of \(\bar{u}_\alpha\). The proof has been completed.
