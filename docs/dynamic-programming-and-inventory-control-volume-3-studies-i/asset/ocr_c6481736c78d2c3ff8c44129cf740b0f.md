which converges to \(s^*, S^*\). From the expression of \(H_{\alpha, s_\alpha}(x)\), we easily deduce that \(H_{\alpha, s_\alpha}(S_\alpha) = -K \to H_\alpha(S^*)\). From this one obtains that \(s^* = s, S^* = S\), solutions of equations (10.3.22). The value \(s\) is uniquely defined, and since \(S_\alpha\) is the smallest infimum, we obtain also that \(S\) is the smallest minimum.

Note that

\(g(x) = cD + hE(x-D)^+ + pE(x-D)^-,\)

so it is a positive function. Hence \(\rho > 0\). Clearly

\((1-\alpha)u_\alpha(x) - g_\alpha(s_\alpha) \to 0, \text{ as } \alpha \uparrow 1,\)

hence

\((1-\alpha)u_\alpha(x) \to \rho = g(s).\)

We recall that we have also

\(H(x) + \rho = g(x) + EH(x-D), \forall x \ge s\)
\(H(x) = 0, \forall x \le s\)

where \(H(x) = H_s(x)\), defined by (10.3.15), for the specific \(s\), limit of \(s_\alpha\).

We can check that these conditions can be summarized into

(10.3.26) \(H(x) + \rho = + \inf_{\eta \ge x} [K 1_{\eta > x} + g(\eta) + EH(\eta - D)].\)

If (10.3.26) is satisfied, then the equation for \(u\) (10.3.25) follows immediately, using the definition of \(g(x)\).

The proof of (10.3.26) is identical to that of (10.2.25) in Theorem 10.2.

This completes the proof of the Theorem.

# 10.3.3. PROBABILISTIC INTERPRETATION.

We give now the interpretation of \(\rho\) and of the solution \(u(x)\) of (10.3.25). We first associate to an \(s, S\) policy an invariant measure \(m_{s,S}(dx)\). Moreover the infimum in equations (10.3.25), (10.3.26) is attained by a feedback \(\hat{v}(x)\) associated to an \(s, S\) policy. We still denote it \(s, S\) to save notation.

We recall that

(10.3.27) \(l(x, v) = K 1_{x > 0} + cv + hx^+ + px^-,\)

and

(10.3.28) \(l(x, \hat{v}(x)) = 1_{x \le s} (K + c(S-x)) + hx^+ + px^-,\)

and (10.3.25) reads

(10.3.29) \(u(x) = l(x, \hat{v}(x)) - \rho + Eu(x + \hat{v}(x) - D).\)

Let us denote by \(m_{l(\cdot)}(\text{d}x)\) the invariant measure \(m_{s,S}(\text{d}x)\), for consistency of notation. It follows from (10.3.29) that

(10.3.30) \(\rho = \int l(x, \hat{v}(x)) m_{l(\cdot)}(\text{d}x).\)

Note that the state space of \(m_{l(\cdot)}(\text{d}x)\) is \((-\infty, S]\) but can be taken as \((-\infty, \infty)\) to work with a fixed state space (independent of \(S\)). We next define the set \(\mathcal{U}_b\) of feedbacks such that

(10.3.31) \(\mathcal{U}_b = \{v(\cdot) \ge 0 | \exists M \text{ such that } -M \le x + v(x) \le \max(x, M)\}.\)
