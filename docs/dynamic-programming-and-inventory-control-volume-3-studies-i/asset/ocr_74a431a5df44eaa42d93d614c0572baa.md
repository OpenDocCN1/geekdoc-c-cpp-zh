# 13.4.3. NEW MARKOV CHAIN.

We introduce the calendar time which is the largest time before $t$ when a delay has been observed. So

$\tau_t = \max_{1 \le j \le t} \{j : \beta_{j-1} < \beta_j\},$

therefore

$\beta_{\tau_t} = \tau_t - \theta_{\tau_t};$  
$\beta_{\tau_t+1} = \dots = \beta_t = \beta_{\tau_t}.$

We then set

$\sigma_t = t - \tau_t, \quad \eta_t = \theta_{\tau_t},$

therefore the pair $\beta_t, \tau_t$ can be easily derived from the pair $\sigma_t, \eta_t$ by the formulas

(13.4.10)  
$\beta_t = t - \sigma_t - \eta_t, \quad \tau_t = t - \sigma_t.$

Since $\beta_t \ge t - \theta_t$ we get $\sigma_t + \eta_t \le \theta_t, \sigma_t \ge 0, \eta_t \ge 0.$ Therefore the process $\sigma_t, \eta_t$ takes values in $\mathcal{M} \times \mathcal{M}$. Moreover

$\sigma_t + \eta_t \le M, \quad \sigma_t \le t - 1.$

The important result is the

**Proposition 13.5.** The pair $\sigma_t, \eta_t$ is a Markov chain on the state space $\mathcal{M} \times \mathcal{M}$ with the property $\sigma_t + \eta_t \le M$. It is a process adapted to the filtration $\mathcal{Z}^t$.

PROOF. We first define the transitions. Assume $\sigma_t = \sigma, \eta_t = \eta$ in which $\sigma, \eta$ are two numbers satisfying $\sigma \ge 0, \eta \ge 0, \sigma + \eta \le M$. Suppose $\sigma + \eta = M$. Then if $\beta_{t+1} = \beta_t$ we have

$\tau_{t+1} = \tau_t = t - \sigma, \quad \sigma_{t+1} = t + 1 - \tau_{t+1} = \sigma + 1.$

On the other hand $\eta_{t+1} = \eta$ and we get $\sigma_{t+1} + \eta_{t+1} = M + 1$ which is impossible. Therefore $\beta_{t+1} > \beta_t$ which implies $\tau_{t+1} = t + 1$ hence $\sigma_{t+1} = 0$. The variable $\eta_{t+1}$ can take the values $0, \cdots M$. Next assume $\sigma + \eta < M$. We may have $\beta_{t+1} = \beta_t$ in which case $\sigma_{t+1} = \sigma + 1$ and $\eta_{t+1} = \eta$. Otherwise $\beta_{t+1} > \beta_t$ which implies $\sigma_{t+1} = 0$. But then

$\eta_{t+1} = t + 1 - \beta_{t+1} < t + 1 - \beta_t = \sigma + \eta + 1.$

Therefore $\eta_{t+1}$ can take the values $0, \cdots \sigma + \eta$. So the transitions are summarized as follows:

If $\sigma + \eta < M$

(13.4.11)  
$\sigma, \eta \Rightarrow \begin{cases} \sigma' = \sigma + 1, \eta' = \eta \\ \sigma' = 0, \eta' = k, \quad 0 \le k \le \sigma + \eta \end{cases}$

If $\sigma + \eta = M$

(13.4.12)  
$\sigma, \eta \Rightarrow \sigma' = 0, \eta' = k, \quad 0 \le k \le M$

We can now define the transition probability matrix. We first note $\theta_{t-\sigma} = \eta$, and

$\beta_{\tau_t+1} = t - \sigma - \eta = \max(\sigma + 1 - \theta_{\tau_t+1}, \beta_{\tau_t})$  
$= \max(t - \sigma + 1 - \theta_{\sigma-t+1}, t - \sigma - \eta),$

from which it follows $\theta_{t-\sigma+1} \ge \eta + 1$. Similarly

$\theta_{t-\sigma+2} \ge \eta + 2, \cdots, \theta_t \ge \eta + \sigma.$
