
## 13.3.4. EXISTENCE AND CHARACTERIZATION OF THE PAIR s, S.

We recall that

(13.3.12) \(\mu(x) = (1-\alpha)c + \alpha^L h - \alpha^L(h+p)\bar{F}^{(L)}(x),\)

where \(F^{(L)}(x)\) is the cumulative distribution function of \(D^{(L)}\) and \(\bar{F}^{(L)}(x) = 1 - F^{(L)}(x)\). We assume that

(13.3.13) \((1-\alpha)c - \alpha^L p < 0.\)

There exists a unique \(\bar{s} > 0\) such that

\(\mu(x) \le 0, \text{ if } x \le \bar{s}, \mu(x) \ge 0, \text{ if } x \ge \bar{s}.\)

We perform next further computations on the function \(\Psi(x)\). We have

\(E[(g(x-D^{(j)}) - g(s)) \mathbb{1}_{x-D^{(j)} < s}]\)
\(= -E[D^{(j)} > x-s] \left( \int_{x-D^{(j)}}^s \mu(\xi) d\xi \right)\)
\(= -\int_{-s}^{+\infty} dF^{(j)}(\zeta) \int_{x-\zeta}^s \mu(\xi) d\xi\)
\(= -\int_{-s}^{+\infty} \bar{F}^{(j)}(\zeta) \mu(x-\zeta) d\zeta\)
\(= -\int_{-\infty}^x F^{(j)}(x-\xi) \mu(\xi) d\xi\)
\(= -\int_{-\infty}^x F^{(j)}(x-\xi) \mu(\xi) d\xi + \int_s^x \bar{F}^{(j)}(x-\xi) \mu(\xi) d\xi.\)

We then check that

\(H_s(x) \sum_{j=0}^{L-1} \alpha^j \int_s^x \bar{F}^{(j)}(x-\xi) \mu(\xi) d\xi\)
\(= \frac{1-\alpha^L}{1-\alpha} (g(x) - g(s)) + \sum_{j=L}^{\infty} \alpha^j \int_s^x F^{(j)}(x-\xi) \mu(\xi) d\xi.\)

This formula holds for any \(x\), and the integral term vanishes when \(x < s\). Collecting results, one obtains the formula

(13.3.14) \(\Psi_s(x) = \frac{1-\alpha^L}{1-\alpha} (g(x) - g(s)) + \sum_{j=L}^{\infty} \alpha^j \int_s^x F^{(j)}(x-\xi) \mu(\xi) d\xi\)
\(-((1-\alpha)c + \alpha^L h) D \sum_{j=1}^{L-1} j \alpha^j\)
\(+ \alpha^L (h+p) \sum_{j=1}^{L-1} \alpha^j \int_0^{+\infty} \bar{F}^{(j)}(\zeta) \bar{F}^{(L)}(x-\zeta) d\zeta.\)

It follows that \(\Psi_s(x)\) is bounded below and tend to \(+\infty\) as \(x \to +\infty\). Therefore the infimum over \(x \ge s\) is attained and we can define \(S(s)\) as the smallest infimum.

### Proposition 13.2. We assume (13.3.13). One has

(13.3.15) \(\max_s \Psi_s(S(s)) = \Psi_s(S(\bar{s})) \ge 0,\)

(13.3.16)

\(\Psi_s(S(s)) \to -\infty, \text{ as } s \to -\infty\)

(13.3.17)

\(\Psi_s(S(s)) \to -((1-\alpha)c + \alpha^L h)D \sum_{j=1}^{L-1} j \alpha^j, \text{ as } s \to +\infty.\)

There exists one and only one solution of (13.3.10) such that \(s \le \bar{s}\).

PROOF. We compute

\(\Psi'_s(x) = \frac{1-\alpha^L}{1-\alpha}\mu(x) + \sum_{j=L}^\infty \alpha^j \int_s^x f^{(j)}(x-\xi)\mu(\xi)d\xi\)
\(-\alpha^L(h+p) \sum_{j=1}^{L-1} \alpha^j \int_0^x F^{(j)}(\xi)f^{(L)}(x-\xi)d\xi\)

which can also be written as

(13.3.18)

\(\Psi'_s(x) = \gamma(x) + \sum_{j=L}^\infty \alpha^j \int_s^x f^{(j)}(x-\xi)\mu(\xi)d\xi,\)

with

(13.3.19)

\(\gamma(x) = \frac{1-\alpha^L}{1-\alpha}((1-\alpha)c - \alpha^L p) + \alpha^L(h+p) \sum_{j=0}^{L-1} \alpha^j \int_0^x F^{(j)}(x-\xi)f^{(L)}(\xi)d\xi.\)

The function \(\gamma(x)\) is increasing and

\(\gamma(x) = \frac{1-\alpha^L}{1-\alpha}((1-\alpha)c - \alpha^L p) < 0, \forall x \le 0, \gamma(+\infty) = \frac{1-\alpha^L}{1-\alpha}((1-\alpha)c + \alpha^L h),\)

therefore there exists a unique \(s^*\) such that

\(\gamma(x) < 0, \forall x < s^*, \gamma(x) > 0, \forall x > s^*, \gamma(s^*) = 0, s^* > 0.\)

Note that

\(\mu(x) \frac{1-\alpha^L}{1-\alpha} - \gamma(x) = \alpha^L(h+p) \sum_{j=0}^{L-1} \alpha^j \int_0^x \bar{F}^{(j)}(x-\xi)f^{(L)}(\xi)d\xi.\)

This quantity vanishes for \(x \le 0\) or \(L=1\). Otherwise

\(\mu(x) \frac{1-\alpha^L}{1-\alpha} - \gamma(x) > 0, \forall x > 0, L \ge 2\)

Since \(\gamma(s^*)=0\), we have \(\mu(s^*) > 0\), hence \(0 < \bar{s} < s^*\).

Next, if \(s \ge s^*\), \(\Psi'_s(x) \ge 0, \forall x \ge s\), hence \(S(s) = s\). Therefore

\(\Psi_s(S(s)) = -((1-\alpha)c + \alpha^L h)D \sum_{j=1}^{L-1} j \alpha^j\)
\(+ \alpha^L(h+p) \sum_{j=1}^{L-1} \alpha^j \int_0^{+\infty} \bar{F}^{(j)}(\xi)\bar{F}^{(L)}(s-\xi)d\xi\)

this function decreases in $s$ and converges to $-((1-\alpha)c+\alpha^L h)D \sum_{j=1}^{L-1} j \alpha^j$ as \(s \to +\infty\). Consider now \(\bar{s} < s < s^*\). We note that

\(\Psi'_s(s) = \gamma(s) < 0,\)

\(\Psi'_s(s^*) = \sum_{j=L}^\infty \int_s^{s^*} f^{(j)}(s^* - \xi) \mu(\xi) d\xi > 0,\)

hence in this case

\(\bar{s} < S < S(s) < s^*.\)

If \(s < \bar{s}\), then we can claim that

\(s < \bar{s} < S(s).\)

Indeed, for \(s < x < \bar{s}\), we can see from formula (13.3.18) that \(\Psi'_s(x) < 0\). However, we cannot compare \(S(s)\) with \(s^*\) in this case.

We then study the behavior of \(\Psi_s(S(s))\). We have already seen that, for \(s > s^*\) the function \(\Psi_s(S(s))\) is decreasing to the negative constant

\(-((1-\alpha)c+\alpha^L h)D \sum_{j=1}^{L-1} j \alpha^j.\)

In this case

(13.3.20) \(\frac{d}{ds}\Psi_s(S(s)) = -\alpha^L(h+p) \sum_{j=1}^{L-1} \alpha^j \int_0^{\bar{s}} \bar{F}^{(j)}(\zeta) f^{(L)}(s - \zeta) d\zeta, s > s^*.\)

Note that \(s > 0\). If \(s < s^*\), then \(s < S(s)\), therefore

\(\frac{d}{ds}\Psi_s(S(s)) = \frac{\partial \Psi_s}{\partial s}(S(s)),\)

hence

(13.3.21) \(\frac{d}{ds}\Psi_s(S(s)) = -\mu(s) \left[ \frac{1-\alpha^L}{1-\alpha} + \sum_{j=L}^\infty \alpha^j F^{(j)}(S(s) - s) \right].\)

Note that at \(s = s^*\) the two formulas coincide, since

\(-\mu(s^*) \frac{1-\alpha^L}{1-\alpha} = -\alpha^L(h+p) \sum_{j=1}^{L-1} \alpha^j \int_0^{\bar{s}} \bar{F}^{(j)}(\zeta) f^{(L)}(s^* - \zeta) d\zeta,\)

which can be easily checked, by remembering the definition of \(s^*(\gamma(s^*) = 0)\) and simple calculations. It follows clearly that \(\Psi_s(S(s))\) decreases on \((s, s^*)\) and increases on \((-\infty, \bar{s})\). Finally \(\Psi_s(S(s))\) decreases on \((\bar{s}, +\infty)\) and increases on \((-\infty, \infty)\). So it attains its maximum at \(\bar{s}\). From the formula for \(\Psi_s(x)\), \(H_s(x), x > \bar{s}\) and the fact that \(s\) is the minimum of \(g\), we get immediately that \(\Psi_s(S(s)) \ge 0\).

Finally, for \(s < 0\) we have

\(\Psi_s(S(s)) \le \Psi_s(0)\)

\(= ((1-\alpha)c-\alpha^L p) \left[ \frac{1-\alpha^L}{1-\alpha} (-\bar{s}) + \sum_{j=L}^\infty \alpha^j \int_s^0 F^{(j)}(-\xi) d\xi - D \sum_{j=1}^{L-1} j \alpha^j \right],\)

which tends to \(-\infty\) as \(s \to -\infty\). Therefore \(\Psi_s(S(s))\) is increasing from \(-\infty\) to a positive number as \(s\) grows from \(-\infty\) to \(\bar{s}\). Therefore there is one and only one \(s < \bar{s}\) satisfying (13.3.10). The proof has been completed.

## 13.3.5. SOLUTION AS AN s, S POLICY.

It remains to see whether the function \(H_s(x)\) defined by (13.3.5) with \(s\) solution of (13.3.10) is indeed a solution of equation (13.3.9). It is useful to use, instead of \(\Psi_s(x)\) a different function, namely

(13.3.22)

\(\Phi_s(x) = H_s(x) + E \sum_{j=1}^{L-1} \alpha^j (g(x - D^{(j)}) - g(s)) \mathbb{I}_{-x - D^{(j)} < s},\)

which differs from \(\Psi_s(x)\) by simply deleting the term corresponding to \(j=0\). Clearly

\(\Phi_s(x) = \Psi_s(x), \forall x \ge s.\)

However, when \(x < s\), the two functions differ by the term

\(\Psi_s(x) = \Phi_s(x) + g(x) - g(s), \forall x < s.\)

Note that in finding \(S\) it is indifferent to work with one or the other function. Note also that, when \(L=1\), \(\Phi_s(x) = H_s(x), \forall x\). Now we have

\(\inf_{\eta > x} \Psi_s(\eta) = \inf_{\eta > x} \Phi_s(\eta).\)

This equality is obvious when \(x > s\), since the functions are identical. If \(x < s\) we have

\(\inf_{\eta > x} \Psi_s(\eta) = \inf_{\eta > x} \Phi_s(\eta) = \inf_{\eta > x} \Phi_s(\eta) = -K.\)

Indeed, for instance

\(\inf_{\eta > x} \Psi_s(\eta) = \min \left[ \inf_{\eta > x} \Psi_s(\eta), \inf_{x < \eta < \bar{s}} \Psi_s(\eta) \right],\)

and \(\inf_{\eta > x} \Psi_s(\eta) = -K\), whereas

\(\inf_{x < \eta < \bar{s}} \Psi_s(\eta) = \inf_{x < \eta < \bar{s}} E \sum_{j=0}^{L-1} \alpha^j (g(\eta - D^{(j)}) - g(s)) \mathbb{I}_{-x - D^{(j)} < s} > 0,\)

hence the result. Therefore (13.3.9) becomes

(13.3.23)

\(H_s(x) = \min \left\{ g(x) - g(s) + \alpha E H_s(x - D), K + \inf_{\eta > x} \Phi_s(\eta) \right\}.\)

For \(x < s\), this relation reduces to

\(0 = \min[g(x) - g(s), 0]\)

which is true since \(g(x)\) is decreasing for \(x < s\). We then consider \(x > s\). Since \(H_s(x)\) is equal to the first term of the bracket. Therefore, what we have to prove is

(13.3.24)

\(H_s(x) \le K + \inf_{\eta > x} \Phi_s(\eta), \forall x > s.\)
