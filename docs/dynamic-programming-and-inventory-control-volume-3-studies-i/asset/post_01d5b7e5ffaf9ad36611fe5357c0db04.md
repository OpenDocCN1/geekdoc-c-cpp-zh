
The process $x_t$ is observable.

PROOF. The fact that the inventory position is observable follows directly from its definition. The second relation follows from

$x_t = y_{\beta_t} + \sum_{j=\beta_t}^{t-1} v_j$

$y_t = y_{\beta_t} + \sum_{j=\beta_t}^{t-1} v_j - \sum_{j=\beta_t}^{t-1} D_j$

To prove the first one, first note that

$z_{t+1} - z_t = y_{\beta_{t+1}} - y_{\beta_t}$

$= \sum_{j=\beta_t}^{\beta_{t+1}-1} (v_j - D_j), \text{if } \beta_t < \beta_{t+1}$

and (13.4.7) follows easily, by considering all the cases.

Consider now the one period cost

$c(x, v) = C(v) + l(x),$

with

$C(v) = K \mathbf{1}_{v>0} + cv, l(x) = hx^+ + px^-,$

and a control

$V = (v_1, \cdots, v_t, \cdots), v_t \text{ is } \mathcal{Z}^t \text{ measurable.}$

The objective functional is

$J(V) = E \sum_{t=1}^{\infty} \alpha^{t-1} c(y_t, v_t),$

and from (13.4.8) we get

$c(y_t, v_t) = c \left( x_t - \sum_{j=\beta_t}^t D_j, v_t \right) = C(v_t) + l \left( x_t - \sum_{j=\beta_t}^t D_j \right),$

in which the sum vanishes when $\beta_t = t$. The process $\beta_t$ is independent from the demand process. The demands being independent random variables, it is easy to check that $D_{\beta_t}, \cdots, D_t$ are independent from $\mathcal{Z}^t$. Therefore if we introduce the notation

$l^{(i)}(x) = E l \left( x - \sum_{j=1}^i D_j \right), i \ge 1, l^{(0)}(x) = l(x),$

then we can rewrite the objective functional as

(13.4.9) \( J(V) = E \sum_{t=1}^{\infty} \alpha^{t-1} (C(v_t) + l^{(t-\beta_t)}(x_t)). \)

The important attribute of this writing is that the three processes $x_t, v_t, \beta_t$ are $\mathcal{Z}^t$ measurable. However $\beta_t$ is not a Markov chain, so it is not convenient to work with this process. We will introduce a new Markov chain, from which $\beta_t$ is easily derived.

### 13.4.3. NEW MARKOV CHAIN.

We introduce the calendar time which is the largest time before $t$ when a delay has been observed. So

$\tau_t = \max_{1 \le j \le t} \{j : \beta_{j-1} < \beta_j\},$

therefore

$\beta_{\tau_t} = \tau_t - \theta_{\tau_t};$  
$\beta_{\tau_t+1} = \dots = \beta_t = \beta_{\tau_t}.$

We then set

$\sigma_t = t - \tau_t, \quad \eta_t = \theta_{\tau_t},$

therefore the pair $\beta_t, \tau_t$ can be easily derived from the pair $\sigma_t, \eta_t$ by the formulas

(13.4.10)  
$\beta_t = t - \sigma_t - \eta_t, \quad \tau_t = t - \sigma_t.$

Since $\beta_t \ge t - \theta_t$ we get $\sigma_t + \eta_t \le \theta_t, \sigma_t \ge 0, \eta_t \ge 0.$ Therefore the process $\sigma_t, \eta_t$ takes values in $\mathcal{M} \times \mathcal{M}$. Moreover

$\sigma_t + \eta_t \le M, \quad \sigma_t \le t - 1.$

The important result is the

**Proposition 13.5.** The pair $\sigma_t, \eta_t$ is a Markov chain on the state space $\mathcal{M} \times \mathcal{M}$ with the property $\sigma_t + \eta_t \le M$. It is a process adapted to the filtration $\mathcal{Z}^t$.

PROOF. We first define the transitions. Assume $\sigma_t = \sigma, \eta_t = \eta$ in which $\sigma, \eta$ are two numbers satisfying $\sigma \ge 0, \eta \ge 0, \sigma + \eta \le M$. Suppose $\sigma + \eta = M$. Then if $\beta_{t+1} = \beta_t$ we have

$\tau_{t+1} = \tau_t = t - \sigma, \quad \sigma_{t+1} = t + 1 - \tau_{t+1} = \sigma + 1.$

On the other hand $\eta_{t+1} = \eta$ and we get $\sigma_{t+1} + \eta_{t+1} = M + 1$ which is impossible. Therefore $\beta_{t+1} > \beta_t$ which implies $\tau_{t+1} = t + 1$ hence $\sigma_{t+1} = 0$. The variable $\eta_{t+1}$ can take the values $0, \cdots, M$. Next assume $\sigma + \eta < M$. We may have $\beta_{t+1} = \beta_t$ in which case $\sigma_{t+1} = \sigma + 1$ and $\eta_{t+1} = \eta$. Otherwise $\beta_{t+1} > \beta_t$ which implies $\sigma_{t+1} = 0$. But then

$\eta_{t+1} = t + 1 - \beta_{t+1} < t + 1 - \beta_t = \sigma + \eta + 1.$

Therefore $\eta_{t+1}$ can take the values $0, \cdots, \sigma + \eta$. So the transitions are summarized as follows:

If $\sigma + \eta < M$

(13.4.11)  
$\sigma, \eta \Rightarrow \begin{cases} \sigma' = \sigma + 1, \eta' = \eta \\ \sigma' = 0, \eta' = k, \quad 0 \le k \le \sigma + \eta \end{cases}$

If $\sigma + \eta = M$

(13.4.12)  
$\sigma, \eta \Rightarrow \sigma' = 0, \eta' = k, \quad 0 \le k \le M$

We can now define the transition probability matrix. We first note $\theta_{t-\sigma} = \eta$, and

$\beta_{\tau_t+1} = t - \sigma - \eta = \max(t - \sigma + 1 - \theta_{\tau_t+1}, \beta_{\tau_t})$  
$= \max(t - \sigma + 1 - \theta_{t-\sigma+1}, t - \sigma - \eta),$

from which it follows $\theta_{t-\sigma+1} \ge \eta + 1$. Similarly

$\theta_{t-\sigma+2} \ge \eta + 2, \cdots, \theta_t \ge \eta + \sigma.$

Therefore if \(\sigma + \eta < M\) we have

\(P(\sigma_{t+1} = \sigma + 1, \eta_{t+1} = \eta | \sigma_t = \sigma, \eta_t = \eta)\)
\(= P(\beta_t \ge t + 1 - \theta_{t+1} | \sigma_t = \sigma, \eta_t = \eta)\)
\(= P(\theta_{t+1} \ge \sigma + \eta + 1 | \theta_{t-\sigma} = \eta, \theta_{t-\sigma+1} \ge \eta + 1, \cdots, \theta_t \ge \eta + \sigma)\)

Next for \(0 \le k \le \sigma + \eta\)

\(P(\sigma_{t+1} = 0, \eta_{t+1} = k | \sigma_t = \sigma, \eta_t = \eta)\)
\(= P(\beta_{t+1} = t + 1 - \theta_{t+1}, \theta_{t+1} = k | \sigma_t = \sigma, \eta_t = \eta)\)
\(= P(\theta_{t+1} = k | \theta_{t-\sigma} = \eta, \theta_{t-\sigma+1} \ge \eta + 1, \cdots, \theta_t \ge \eta + \sigma)\)

We then define the function \(\gamma(k; \sigma, \eta)\) with arguments \(0 \le k \le M, \sigma + \eta \le M, \sigma \ge 0, \eta \ge 0, \sigma \le t-1\)

(13.4.13) \(\gamma(k; \sigma, \eta) = P(\theta_{t+1} = k | \theta_{t-\sigma} = \eta, \theta_{t-\sigma+1} \ge \eta + 1, \cdots, \theta_t \ge \eta + \sigma)\)

This function is uniquely defined by the Markov chain \(\theta_t\) and its transition probability function. In fact it can be defined by the recursion

(13.4.14) \(\gamma(k; \sigma, \eta) = \frac{\sum_{j=\sigma+\eta}^M p_{jk}(j; \sigma-1, \eta)}{\sum_{j=\sigma+\eta}^M \gamma(j; \sigma-1, \eta)}, \sigma \ge 1; \gamma(k; 0, \eta) = p_{\eta k}\)

The transition probability matrix of the Markov chain \(\sigma_t, \eta_t\) is given by:

If \(\sigma + \eta < M\)

(13.4.15) \(\pi(\sigma, \eta; \sigma', \eta') = \begin{cases} \gamma(k; \sigma, \eta), & \text{if } \sigma' = 0, \eta' = k, 0 \le k \le \sigma + \eta \\ \sum_{k=\sigma+\eta+1}^M \gamma(k; \sigma, \eta), & \text{if } \sigma' = \sigma + 1, \eta' = \eta \\ 0, & \text{otherwise} \end{cases}\)

If \(\sigma + \eta = M\)

(13.4.16) \(\pi(\sigma, \eta; \sigma', \eta') = \begin{cases} \gamma(k; \sigma, \eta), & \text{if } \sigma' = 0, \eta' = k, 0 \le k \le M \\ 0, & \text{otherwise} \end{cases}\)

The fact that \(\sigma_t, \eta_t\) is adapted to \(\mathcal{Z}^t\) follows from the definition of the process.

In fact, the Markov chain \(\sigma_t, \eta_t\) is not stationary from \(t=1\), because of the constraint \(\sigma_t \le t-1\). It becomes stationary from \(t \ge M+1\). In the sequel we will discard this transitory phase and consider that we are in the stationary situation from the beginning. From (13.4.7) and (13.4.9) we can write

(13.4.17) \(J(V) = E \sum_{t=1}^\infty \alpha^{t-1} (C(v_t) + [l^{\sigma_t, \eta_t}(x_t)]),\)

and

(13.4.18) \(x_{t+1} = x_t + v_t - \mathbb{I}_{\sigma_{t+1} + \eta_{t+1} \le \sigma_t + \eta_t} \sum_{j=\sigma_t + \eta_t + 1}^{\sigma_t + \eta_t} D_{t,j}\)

where we have set \(D_{t,j} = D_{t-j}\). There is the transitory period in which \(\sigma_t + \eta_t < t\). It is over when \(t \ge M+1\). In (13.4.18) the random variables \(D_{t,j}\) are identically distributed, independent of \(\mathcal{Z}^t\) and mutually independent. We discard the transitory period and consider in (13.4.17), (13.4.18) the Markov chain \(\sigma_t, \eta_t\) from \(t=1\) and we fix initial conditions by

(13.4.19) \(x_1 = x, \sigma_1 = \sigma, \eta_1 = \eta, \sigma, \eta \ge 0, \sigma + \eta \le M\)

We then call the functional \( J(V) \) as \( J_{x,\sigma,\eta}(V) \), to emphasize the initial conditions. We define

(13.4.20) \( u(x, \sigma, \eta) = \inf_V J_{x,\sigma,\eta}(V) \).

If \( M=0 \), then \( \sigma_t = 0, \eta_t = 0 \) and the problem reduces to the standard one with no delay in the information studied in Chapter 9, section 9.3.

### 13.4.4. DYNAMIC PROGRAMMING.

It is easy to write the Bellman equation related to the value function (13.4.20). We will write it as follows

(13.4.21) \( u(x; \sigma, \eta) = -cx + l^{(\sigma+\eta)}(x) + \inf_{y \ge x} \left\{ K \mathbf{1}_{y > x} + cy \right. \left. + \alpha \sum_{k=0}^{\sigma+\eta} \gamma(k; \sigma, \eta) u^{(\sigma+\eta+1-k)}(y, 0, k) + \sum_{k=\sigma+\eta+1}^{M} \gamma(k; \sigma, \eta) u(y; \sigma+1, \eta) \right\} \)

in which the last sum is dropped when \( \sigma + \eta = M \). It is equivalent and convenient to write this equation as

(13.4.22) \( u(x; \sigma, \eta) = -cx + l^{(\sigma+\eta)}(x) + \inf_{y \ge x} \left\{ K \mathbf{1}_{y \ge x} + cy + \alpha E u^{(\sigma+\eta+1-(\sigma'+\eta'))}(y; \sigma', \eta') \right\} \)

where the expectation in the parenthesis refers to a random variable \( \sigma', \eta' \) which has a probability distribution \( \pi(\sigma, \eta; \sigma', \eta') \), where \( \sigma, \eta \) are fixed.
