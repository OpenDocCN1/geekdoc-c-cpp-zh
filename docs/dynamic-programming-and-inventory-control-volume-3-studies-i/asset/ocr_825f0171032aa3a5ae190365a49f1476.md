# 3.2. CHAPMAN-KOLMOGOROV EQUATIONS

# 3.2.1. FUNCTIONAL SET UP.

Let $B$ be the Banach space of measurable functions of $X$ to $R$ which are bounded, equipped with the norm

$||f|| = \sup_x |f(x)|.$

We define the operator $\Phi \in \mathcal{L}(B; B)$ by the formula

$\Phi f(x) = \int_X f(y)\pi(x, dy).$

Clearly one has

$||\Phi|| \le 1$

# Exercise 3.1. Show that

(3.2.1) \( E[f(y_{n+1})|\mathcal{Y}^n] = \Phi f(y_n), \)

where

\(\mathcal{Y}^n = \sigma(y_1, \cdots, y_n).\)

# Exercise 3.2. Show that

(3.2.2) \( E[f(y_{n+1})|y_1] = \Phi^n f(y_1). \)

When \(m = \delta_x\) we use the notation

\( E[f(y_{n+1})|y_1 = x] = f(y_{n+1}) = \Phi^n f(x) = \int P(x, n, d\eta) f(\eta). \)

and \(P(x, n, d\eta)\) represents the probability distribution of \(y_n\) given \(y_1 = x\).

Let \(\Gamma\) be a Borel subset of \(X\), we write

\(P(x, n, \Gamma) = \int P(x, n, d\eta) \mathbb{I}_\Gamma(\eta),\)

then we have the Chapman-Kolmogorov equation

\(P(x, n + m, \Gamma) = \int P(x, n, d\eta) P(\eta, m, \Gamma),\)

and also

(3.2.3) \( E[\mathbb{I}_\Gamma(y_{k+n})|\mathcal{Y}^k] = P(y_k, n, \Gamma). \)
