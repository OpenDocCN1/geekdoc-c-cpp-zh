
In this form, the interpretation of \(u(x)\), in fact the interpretation of the minimum solution as the value function of a stochastic control problem becomes standard. We introduce \(V, D\) decision rules associated with the control variables \(v, d\), namely

\(V = \{v_1, \cdots, v_n, \cdots\}\)
\(D = \{d_1, \cdots, d_n, \cdots\}\)

and

\(v_n = v_n(x_1, \cdots, x_n)\)
\(d_n = d_n(x_1, \cdots, x_n)\)

The functions \(v_n\) and \(d_n\) are Borel functions, with values in \(U\) and \([0, 1]\) respectively. Since \(\Phi^u\) does not depend on \(d\) the probability defined on \(\Omega = X^N, \mathcal{A}\) associated to the decision rule \(V, D\) and to the initial state \(x\) depends only on \(V\) and \(x\) and is denoted \(P^{V,x}\). Considering the canonical process \(y_n\) (See Chapter 3) we know that

\(y_1 = x, P^{V,x} \text{ a.s.}\)

The decision rules define stochastic processes \(v_n(y_1, \cdots, y_n)\) and \(d_n(y_1, \cdots, y_n)\) adapted to the filtration \(\mathcal{Y}^n\) generated by the canonical process.

We now define a payoff associated with \(V, D, x\) as follows

\(J_x(V, D) = E^{V,x} \sum_{j=1}^{\infty} \alpha^{j-1} (1 - d_{j-1}) \cdots (1 - d_1) d_j \psi(y_j) + (1 - d_j) l(y_j, v_j).\)

From the theory of Chapter 4 we can assert that the minimum solution between 0 and \(w_0\) obtained with the increasing sequence is the value function corresponding to this payoff. Namely, we have

\(\underline{u}(x) = \inf_{V,D} J_x(V, D)\)

## 7.2.2. OPTIMAL STOPPING FORMULATION.

To use the trick described in the previous section is not the best way to deal with optimal stopping problems. We proceed now directly with stopping times. Let us consider \(\theta\) to be a stopping time with respect to the filtration \(\mathcal{Y}^n\). We then define the payoff

\(J_x(V, \theta) = E^{V,x} \left[ \sum_{j=1}^{\theta-1} \alpha^{j-1} l(y_j, v_j) + \alpha^{\theta-1} \psi(y_\theta) \mathbb{1}_{\theta < \infty} \right]\)

**Theorem 7.2.** Under the assumptions of Theorem 7.1 the minimum solution \(\underline{u}(x)\) satisfies

\(\underline{u}(x) = \inf_{V,\theta} J_x(V, \theta).\)

**PROOF.** Let \(V\) be a decision rule and \(\theta\) a stopping time with respect to \(\mathcal{Y}^n\). Consider the increasing sequence \(u_n(x)\). We can write for \(0 \le j \le N - 1\)

\(\alpha^{N-j-1} u_{j+1}(y_{N-j}) \mathbb{1}_{N-j < \theta} \le\)
\(\alpha^{N-j-1} l(y_{N-j}, v_{N-j}) \mathbb{1}_{N-j < \theta} + \alpha^{N-j} E^{V,x} [u(y_{N-j+1}) \mathbb{1}_{N-j < \theta} | \mathcal{Y}^{N-j}]\)

Taking expectations on both sides yields

\(E^{V,x} (\alpha^{N-j-1} u_{j+1}(y_{N-j}) \mathbb{1}_{N-j < \theta}) \le\)
\(E^{V,x} (\alpha^{N-j-1} l(y_{N-j}, v_{N-j}) \mathbb{1}_{N-j < \theta}) + E^{V,x} (\alpha^{N-j} u_j(y_{N-j+1}) \mathbb{1}_{N-j < \theta})\)

We add up for \( j = 0 \cdots, N-1 \). We obtain

\( E^{V,x} \sum_{k=1}^{(\theta-1) \wedge N} \alpha^{k-1} u_{N-k+1}(y_k) \le E^{V,x} \sum_{k=1}^{(\theta-1) \wedge N} \alpha^{k-1} l(y_k, v_k) + E^{V,x} \sum_{k=2}^{\theta \wedge (N+1)} \alpha^{k-1} u_{N-k+1}(y_k). \)

Canceling terms we deduce

\( u_N(x) E^{V,x} \mathbb{1}_{\theta \ge 2} \le E^{V,x} \sum_{k=1}^{(\theta-1) \wedge N} \alpha^{k-1} l(y_k, v_k) + E^{V,x} \alpha^{\theta-1} u_{N-\theta+1}(y_\theta) \mathbb{1}_{\theta \le N}, \)

where we have used the fact that \( u_0(x) = 0 \). By adding on both sides of this relation \( u_N(x) E^{V,x} \mathbb{1}_{\theta=1} \), we obtain by letting \( N \to \infty \) on the right hand side

\( u_N(x) \le \inf_{V,\theta} J_x(V, \theta). \)

Therefore also

\( \underline{u}(x) \le \inf_{V,\theta} J_x(V, \theta). \)

Next define the optimal feedback \(\tilde{v}(x)\) which achieves the minimum of \( l(x,v) + \alpha \Phi^v \underline{u}(x) \) for \( v \in U \). We associate to this feedback a decision rule \(\tilde{V}\). We then define the exit time

\( \widehat{\theta} = \inf \{ n \ge 1 | \underline{u}(y_n) = \psi(y_n) \}, \)

with

\( \widehat{\theta} = \infty \) if \( \underline{u}(y_n) < \psi(y_n), \forall n \).

We check that \(\forall N\)

\( \underline{u}(x) = E^{V,x} \left[ \sum_{k=1}^{(\widehat{\theta}-1) \wedge N} \alpha^{k-1} l(y_k, v_k) + \alpha^{(\widehat{\theta}-1) \wedge N} \underline{u}(y_{\widehat{\theta} \wedge (N+1)}) \right], \)

and thus also

\( \underline{u}(x) \ge E^{V,x} \left[ \sum_{k=1}^{(\widehat{\theta}-1) \wedge N} \alpha^{k-1} l(y_k, v_k) + \alpha^{\widehat{\theta}-1} \psi(y_{\widehat{\theta}}) \mathbb{1}_{\widehat{\theta} \le N+1} \right]. \)

Letting \( N \) tend to \(\infty\) we obtain

\( \underline{u}(x) \ge J_x(V, \widehat{\theta}), \)

and the proof of the theorem has been completed.

## 7.2.3. DIRECT APPROACH.

We have shown that there are two interpretations of the minimum solution \(\underline{u}(x)\)

\( \underline{u}(x) = \inf_{V,\theta} J_x(V, \theta) = \inf_{V,D} J_x(V, D). \)

We can check directly the equality of the two infimum. We first notice that without loss of generality we can restrict \( d \) to take only the values 0 or 1. This is because the optimal feedback obtained from Bellman equation, which allows to obtain the optimal decision rule, satisfies this property.

Now, consider any decision rule \( D \) which has this property, we define

\(\theta_D = k, \quad \text{if } d_j = 0, j \le k-1, d_k = 1\)
\(\theta_D = \infty, \quad \text{if } d_j = 0, \forall j\)

then one checks that \(\theta_D\) is a \(\mathcal{Y}^n\) stopping time and

\(J_x(V, \theta_D) = J_x(V, D),\)

from which we deduce \(\inf J_x(V, D) \ge \inf J_x(V, \theta).\)

On the other hand, if \(\theta\) is an arbitrary stopping time, we define

\(D_\theta = (d_1^\theta, \dots, d_j^\theta, \dots);\)
\(d_j^\theta = 0 \text{ if } j \le \theta - 1;\)
\(d_j^\theta = 1 \text{ if } j \ge \theta,\)

and we check that

\(J_x(V, \theta) = J_x(V, D_\theta),\)

from which it follows that

\(\inf J_x(V, \theta) \ge \inf J_x(V, D),\)

and the equality follows.

## 7.3. PENALTY APPROXIMATION

In this section, we develop a new idea, very useful in practice. Recall that we used the terminology “obstacle” for the function \(\psi\), reminiscent of the fact that \(u \le \psi\). The idea is that we can waive this constraint by paying a penalty. When this penalty is infinite, the obstacle constraint will be satisfied.

### 7.3.1. FORMULATION.

To simplify a little bit we consider the optimal stopping problem without control. Moreover we assume

(7.3.1) \(l, \psi \in C, l \ge 0, \psi \ge 0,\)

where \(C = C(X)\) denotes the space of uniformly continuous and bounded functions on \(X\). With this additional assumption there exists a unique solution \(u\) of

(7.3.2) \(u(x) = \min[\psi(x), l(x) + \alpha \Phi u(x)].\)

We know that this solution is continuous. To guarantee that it is uniformly continuous we make an additional assumption on \(\Phi\), which strengthens (4.3.1)

(7.3.3) \(\Phi \varphi \in C, \text{if } \varphi \text{ is continuous, bounded.}\)

We associate to the preceding problem the following one

(7.3.4) \(u_\epsilon(x) = l(x) + \alpha \Phi u_\epsilon(x) - \frac{1}{\epsilon} (u_\epsilon - \psi)^+(x),\)

called the penalty approximation. The logic is simple. Instead of imposing the constraint \(u \le \psi\) we accept that our unknown function exceeds the constraint \(\psi\), but then we add to the cost \(l\) a penalty term, to be paid only when the function exceeds the constraint. Obviously as \(\epsilon\) goes to 0 the penalty term becomes very large, forcing the unknown function to fulfill the constraint. Note that the equation (7.3.4) is a non-linear problem.

### 7.3.2. SOLUTION OF THE PENALTY PROBLEM.

We first prove the

**Lemma 7.1.** Under the assumptions (7.3.1) and (7.3.3) there exists a unique positive solution in C of the penalty problem (7.3.4).

**PROOF.** It is convenient to write the equivalent form of (7.3.4)

$$u_\epsilon \left( 1 + \frac{1}{\epsilon} \right) = l + \alpha \Phi u_\epsilon + \frac{1}{\epsilon} \min(\psi, u_\epsilon)$$

**Exercise 7.5.** Show the preceding assertion.

Therefore $u_\epsilon$ is a fixed point of the map $w_\epsilon = T_\epsilon(z)$ defined by

$$w_\epsilon \left( 1 + \frac{1}{\epsilon} \right) = l + \alpha \Phi w_\epsilon + \frac{1}{\epsilon} \min(\psi, z)$$

**Exercise 7.6.** Check that $T_\epsilon$ is a contraction with constant $\frac{1}{1+\epsilon(1-\alpha)}$.

This completes the proof of the Lemma.

**Lemma 7.2.** We have

$$0 \le u_\epsilon \le \max \left( \|\psi\|, \frac{\|l\|}{1-\alpha} \right).$$

Moreover $u_\epsilon\) decreases as \(\epsilon \downarrow 0\).

**PROOF.** If \(z \ge 0, T_\epsilon(z) \ge 0\). Hence since \(T_\epsilon\) is monotone we obtain \(u_\epsilon \ge 0\).

**Exercise 7.7.** Check that for any \(z \ge 0\) one has

$$\|T_\epsilon z\| \le \max \left( \|\psi\|, \frac{\|l\|}{1-\alpha} \right),$$

hence the same estimate follows for the solution \(u_\epsilon\).

Follow up: To prove the monotonicity consider \(\epsilon' < \epsilon\) and set \(w = T_\epsilon(u_{\epsilon'})\). We first verify that

$$(w - u_{\epsilon'}) \left( 1 + \frac{1}{\epsilon} \right) = \alpha \Phi(w - u_{\epsilon'}) + \left( \frac{1}{\epsilon'} - \frac{1}{\epsilon} \right) (u_{\epsilon'} - \psi)^+,$$

from which it follows that \(w - u_{\epsilon'} \ge 0\). Therefore \(u_{\epsilon'} \le T_\epsilon(u_{\epsilon'})\). Iterating we get \(u_{\epsilon'} \le T_\epsilon^n(u_{\epsilon'})\). Letting \(n\) tend to \(\infty\) we get \(u_{\epsilon'} \le u_\epsilon\). The proof of the lemma has been completed.

### 7.3.3. CONVERGENCE.

We state the following convergence result.

**Theorem 7.3.** Under the assumptions (7.3.1) and (7.3.3) one has \(u_\epsilon \downarrow u\) the solution of the equation (7.3.2).

**PROOF.** We can assert that \(u_\epsilon \downarrow u^*\). From (7.3.4) one can write

$$u_\epsilon \le l + \alpha \Phi u_\epsilon,$$

hence

$$u^* \le l + \alpha \Phi u^*.$$

Moreover, since \(u_\epsilon\) is bounded, we can assert that \((u_\epsilon - \psi)^+ \to 0\). Therefore

$$u^* \le \psi.$$
