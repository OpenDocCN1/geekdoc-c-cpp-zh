# 14.6.7. OBTAINING S.

The number S is characterized by the fact that it is the first number strictly larger than s such that

\( H'_s(S-0) \le 0, H'_s(S+0) \ge 0. \)

Since \( H'_s(x) \) is piecewise constant it is the first integer n such that

\( H'_s(n+0) = \frac{1}{\alpha} \left[ (\alpha c + h) \left( 1 - \left( \frac{\lambda}{\alpha + \lambda} \right)^{n+1} \right) - (p - \rho c) \left( \frac{\lambda}{\rho + \lambda} \right)^{n+1} \left( 1 - \left( \frac{\lambda}{\rho + \lambda} \right)^{[-s]} \right) \right] \ge 0, \)

and

\( H'_s(n-1+0) = \frac{1}{\rho} \left[ (\rho c + h) \left( 1 - \left( \frac{\lambda}{\rho + \lambda} \right)^n \right) - (p - \rho c) \left( \frac{\lambda}{\rho + \lambda} \right)^n \left( 1 - \left( \frac{\lambda}{\rho + \lambda} \right)^{[-s]} \right) \right] < 0. \)

# 14.7. ERGODIC CASE FOR THE POISSON DEMAND

The objective now is to let \(\alpha\) tend to 0. In this case \( g_s(x) = (f(x) - f(s)) \mathbb{1}_{x>s} \).

Next the function \( H_s(x) \) becomes

(14.7.1) \( H_s(x) = \sum_{j=0}^{[x-s]} \frac{g_s(x-j)}{\lambda}, \forall x \ge s; H_s(x) = 0, \forall x \le s \)

The number S(s) is obtained by computing the left and right derivatives

\( H'_s(x+0) = \sum_{j=0}^{[x-s]} \frac{g'_s(x-j+0)}{\lambda} \)

\( H'_s(x-0) = \begin{cases} \sum_{j=0}^{[x-s]-0} \frac{g'_s(x-j-0)}{\lambda}, & \text{if } [x-s] < x-s \\ \sum_{j=0}^{[x-s]-1} \frac{g'_s(x-j-0)}{\lambda}, & \text{if } [x-s] = x-s \end{cases} \)

and we write

\( H'_s(S+0) \ge 0; H'_s(S-0) \le 0 \)
