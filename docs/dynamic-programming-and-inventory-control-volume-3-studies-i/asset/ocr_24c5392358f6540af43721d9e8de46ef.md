Therefore

\(\sum_{j=[x-\hat{n}]+1}^{[x-s]} \frac{(g(x-j)-g(s))\lambda^j}{(\alpha+\lambda)^{j+1}} \le \frac{(h+p)\exp-\alpha L x^+}{\alpha}.\)

So we can assert

\(\limsup_{s \to -\infty} \psi_s(x) \le \sum_{j=0}^{[x-\hat{n}]} \frac{(g(x-j)-g(s))\lambda^j}{(\alpha+\lambda)^{j+1}} + \frac{(h+p)\exp-\alpha L x^+}{\alpha}.\)

The first sum is composed of terms, each of them tends to \(-\infty\) as \(s \to -\infty\). This concludes the proof of Theorem 14.3.

# 14.8.6. OPTIMALITY OF THE s, S POLICY.

We have to check the set of inequalities and complementarity slackness conditions. The complementarity slackness property is clearly satisfied. When \(x < s\) we have

\(u_s(x) = -cx + E \int_0^L f(x-D(t)) \exp-\alpha t dt + \frac{g(s)+\lambda c}{\alpha},\)

and we must check that

\((\alpha+\lambda)u_s(x) - \lambda u_s(x-1) \le f(x).\)

Using the value of \(u_s(x)\) this amounts to \(g(x) \ge g(s)\) which is obviously satisfied since \(s \le \hat{n}\).

The difficult part is for \(x \ge s\) where we must satisfy the inequality (14.8.1). Replacing with \(H_s(x)\) this amounts to

\(H_s(x) + (g(s)+\alpha c) \frac{1-\exp-\alpha L}{\alpha} \le K + c\alpha L \exp-\alpha L + \inf_{\eta \ge x} \left\{ cp(1-\exp-\alpha L) \right.\)
\(\left. + \exp-\alpha L E H_s(\eta-D(L)) + \int_0^L f(\eta-D(t+L)) \exp-\alpha t dt \right\}.\)

which is interpreted as

(14.8.13) \(H_s(x) \le K + \inf_{\eta \ge x} \psi_s(\eta).\)

Since the right hand side is positive, this has to be checked only when \(x > x_0\) first value for which \(H_s(x)\) is positive or equal to 0.

Recalling the formula

\(H'_s(x+0) = \sum_{j=0}^{[x-s]} \frac{g'(x-j+0)\lambda^j}{(\alpha+\lambda)^{j+1}},\)

we note that \(x_0 \ge \hat{n}\).

We can also write for \(x\) integer the formula

\(\left( \frac{\alpha+\lambda}{\lambda} \right)^x H'_s(x+0) = \sum_{k=-[x-s]}^x \frac{g'(k+0)}{\alpha+\lambda} \left( \frac{\alpha+\lambda}{\lambda} \right)^k .\)

Consider then \(x \ge x_0\), integer. We may assume \(H'_s(x_0+0) \ge 0\), which corresponds to assuming \(H_s(x) > 0\) slightly after \(x_0\), otherwise the property we want to prove is valid beyond \(x_0\).
