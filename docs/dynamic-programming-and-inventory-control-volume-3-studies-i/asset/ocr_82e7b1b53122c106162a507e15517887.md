We can also write this formula as

```
(15.6.43) \( u_\alpha^{*,S}(x) = E \int_0^{\tau_x^S} \exp - \alpha t f(y_x^{*,S}(t)) dt + c E [\exp - \alpha \tau_x^S (s \n - y_x^{*,S}(\tau_x^S - 0))] + \frac{E \exp - \alpha \tau_x^S}{1 - E \exp - \alpha \tau_x^S} [ E \int_0^{\tau_x^S} \exp - \alpha t f(y_x^{*,S}(t)) dt \n + K + c(S - s) + c E [\exp - \alpha \tau_x^S (s - y_x^{*,S}(\tau_x^S - 0))] ], \)

and thus

```
(15.6.44) \( u_\alpha^{*,S}(S) = -(K + c(S - s)) \n + \frac{1}{1 - E \exp - \alpha \tau_x^S} [ E \int_0^{\tau_x^S} \exp - \alpha t f(y_x^{*,S}(t)) dt + K \n + c(S - s) + c E [\exp - \alpha \tau_x^S (s - y_x^{*,S}(\tau_x^S - 0))] ]. \)

So we may write

```
(15.6.45) \( u_\alpha^{*,S}(x) = E \int_0^{\tau_x^S} \exp - \alpha t f(y_x^{*,S}(t)) dt + c E [\exp - \alpha \tau_x^S (s \n - y_x^{*,S}(\tau_x^S - 0))] + E \exp - \alpha \tau_x^S (u_\alpha^{*,S}(S) + K + c(S - s)). \)

If we introduce

```

then we get

```
\( G_\alpha^{*,S}(x) = E \int_0^{\tau_x^S} \exp - \alpha t f(y_x^{*,S}(t)) dt + c(x - E [\exp - \alpha \tau_x^S y_x^{*,S}(\tau_x^S - 0)]) \n + E \exp - \alpha \tau_x^S (K + G_\alpha^{*,S}(S)). \)

We use the relation

```
\( x - E[\exp - \alpha \tau_x^S y_x^{*,S}(\tau_x^S - 0)] = E \int_0^{\tau_x^S} \exp - \alpha t (\nu + \lambda \xi + \alpha y_x^{*,S}(t)) dt, \)

which implies

```
(15.6.46) \( G_\alpha^{*,S}(x) = E \int_0^{\tau_x^S} \exp - \alpha t g_\alpha(y_x^{*,S}(t)) dt + E \exp - \alpha \tau_x^S (K + G_\alpha^{*,S}(S)), \)

in which

```
\( g_\alpha(x) = f(x) + cv + c\lambda\xi + \alpha cr; \)

```
(15.6.47) \( G_\alpha^{*,S}(S) = \frac{E \int_0^{\tau_x^S} \exp - \alpha t g_\alpha(y_x^{*,S}(t)) dt + K E \exp - \alpha \tau_x^S}{1 - E \exp - \alpha \tau_x^S}, \)
```

and we recover that \( G_\alpha^{*,S}(x) \) is solution of the problem

(15.6.48) \( \alpha G_\alpha^{*,S}(x) + \alpha G_\alpha^{*,S}(x) = g_\alpha(x) \quad \forall x > s \n G_\alpha^{*,S}(x) = K + G_\alpha^{*,S}(S) \quad \forall x \le s \)
