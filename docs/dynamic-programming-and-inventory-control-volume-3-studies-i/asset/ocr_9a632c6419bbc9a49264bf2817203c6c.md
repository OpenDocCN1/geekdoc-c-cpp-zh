The function \( G_\alpha(x) \) is obtained from an \( s, S \) policy. We define successively \( \Gamma_\alpha(x) \) by

```
(15.5.3)

\(-\frac{1}{2}\sigma^2 \Gamma_\alpha''(x) + \nu \Gamma_\alpha'(x) + \lambda \Gamma_\alpha(x) - \lambda \int_0^x \Gamma_\alpha(x-\xi)\mu(\xi)d\xi\)

\(+ \alpha \Gamma_\alpha(x) = 0, \quad \forall x > 0\)

\(\Gamma_\alpha(0) = 1, \quad \Gamma_\alpha(+\infty) = 0\)
```

Let for \( \pi < \bar{\pi} \), \( \chi_\alpha(\pi) \) be the function

```
(15.5.4)

\(\chi_\alpha(\pi) = -\frac{\sigma^2}{2}\pi^2 - \nu \pi + \lambda - \lambda \hat{\mu}(\pi) + \alpha\)
```

The maximum is attained in a point \( \pi_0 < 0 \) which does not depend on \( \alpha \). We know that \( \chi_\alpha(x) \) has two zeros \( \beta_{2\alpha} < \pi_0 \) and \( 0 < \beta_{1\alpha} < \bar{\pi} \). We next define

```
(15.5.5)

\( Q_\alpha(x) = \frac{2}{\sigma^2} \int_x^{+\infty} \exp \beta_{2\alpha} (\eta - x) g'_\alpha(\eta) d\eta \)
```

and for any \( s \) and \( x \ge s \)

```
(15.5.6)

\( H_{\alpha,s}(x) = \int_s^x \Gamma_\alpha(x-\xi) Q_\alpha(\xi) d\xi \)
```

the function \( H_{\alpha,s}(x) \) is extended by 0 for \( x < s \). We then define the function \( G_{\alpha,s}(x) \) as follows

```
(15.5.7)

\( G'_{\alpha,s}(x) = H_{\alpha,s}(x) \quad G_{\alpha,s}(s) = \frac{\frac{\sigma^2}{2} Q_\alpha(s) + g_\alpha(s)}{\alpha} \)
```

We also need

```
(15.5.8)

\( \chi_{0\alpha}(\pi) = -\frac{\sigma^2}{2}\pi^2 - \nu \pi + \lambda + \alpha \)
```

which has two zeros, \( \beta_{0\alpha} > 0 \) and \( \bar{\beta}_{0\alpha} < 0 \).

We know that

```
\(\exp -\beta_{0\alpha} x \le \Gamma_\alpha(x) \le \exp -\beta_{1\alpha} x\)
```

Let \( x_{0\alpha} \) be the unique zero of \( Q_\alpha(x) \). We know that there exists a unique \( s_\alpha < x_{0\alpha} \) such that

```
(15.5.9)

\( 0 = K + \inf_{x \ge s_\alpha} \int_{s_\alpha}^x H_{\alpha,s_\alpha}(\xi) d\xi. \)
```

The function

```
(15.5.10)

\( G_\alpha(x) = G_{\alpha,s_\alpha}(x) \)
```

is the solution of the Q.V.I (15.5.1). We also define the number \( S_\alpha > x_{0\alpha} \) that

```
(15.5.11)

\( 0 = K + \int_{s_\alpha}^{S_\alpha} H_{\alpha,s_\alpha}(\xi) d\xi \quad H_{\alpha,s_\alpha}(S_\alpha) = 0 \)
```
