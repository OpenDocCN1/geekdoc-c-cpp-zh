
### **Proposition 13.3.** We assume

\[
(13.3.25) \quad \alpha^L((1-\alpha)c - \alpha^L p)(L-1)D + K(1-\alpha) \ge 0,
\]

then the property (13.3.24) is satisfied.

Proof. We note that this result includes the case L = 1 in which the condition is automatically satisfied. The proof is similar to that of the case L = 1.

We recall that

\[
(13.3.26) \quad H_s(x) - \alpha E H_s(x - D) = g_s(x), \forall x.
\]

We then find a similar equation for \(\Phi_s(x)\). This is where it is important to consider \(\Phi_s(x)\) and not \(\Psi_s(x)\), since we write the equation for any x and not just for x > s. It is easy to verify that \(\Phi_s(x)\) is the solution of

\[
(13.3.27) \quad \Phi_s(x) - \alpha E \Phi_s(x - D) = g_s(x) + \alpha E(g(x - D) - g(s)) \mathbb{I}_{s-D < s} - \alpha^L E(g(x - D^{(L)}) - g(s)) \mathbb{I}_{s-D^{(L)} < s},
\]

and again we check that this equation coincides with (13.3.26) when L = 1. Going back to (13.3.24) we recall that

\[
K + \inf_{\eta \ge x} \Phi_s(\eta) \ge K + \inf_{\eta > s} \Phi_s(\eta) = 0, \forall x > s.
\]

So it is sufficient to prove (13.3.24) for \(x > x_0 > s\), the first value larger than s such that \(H_s(x) \ge 0\). We necessarily have \(H_s(x_0) = 0\). We have \(s < \xi < x_0\). Let us fix \(\xi > 0\). We consider the domain \(x \ge x_0 - \xi\). We can write

\[
(13.3.28) \quad H_s(x) - \alpha E H_s(x - D) \mathbb{I}_{x-D \ge x_0 - \xi} \le g_s(x), \forall x,
\]

using the fact that

\[
E H_s(x - D) \mathbb{I}_{x-D < x_0 - \xi} \le 0.
\]

Define next

\[
M_s(x) = \Phi_s(x + \xi) + K.
\]

We note that \(M_s(x) > 0, \forall x\).

\[
M_s(x) - \alpha E M_s(x - D) = g_s(x + \xi) + \alpha E(g(x + \xi - D) - g(s)) \mathbb{I}_{x + \xi - D < s} - \alpha^L E(g(x + \xi - D^{(L)}) - g(s)) \mathbb{I}_{x + \xi - D^{(L)} < s} + K(1 - \alpha)
\]

and using the positivity of M we can assert that

\[
(13.3.29) \quad M_s(x) - \alpha E M_s(x - D) \mathbb{I}_{x-D \ge x_0 - \xi} \ge g_s(x + \xi) + \alpha E(g(x + \xi - D) - g(s)) \mathbb{I}_{x + \xi - D < s} - \alpha^L E(g(x + \xi - D^{(L)}) - g(s)) \mathbb{I}_{x + \xi - D^{(L)} < s} + K(1 - \alpha)
\]

We now consider the difference \(Y_s(x) = H_s(x) - M_s(x)\), in the domain \(x \ge x_0 - \xi\).

We have

\[
(13.3.30) \quad Y_s(x) - \alpha E Y_s(x - D) \mathbb{I}_{x-D \ge x_0 - \xi} \le g_s(x) - g_s(x + \xi) - \alpha E(g(x + \xi - D) - g(s)) \mathbb{I}_{x + \xi - D < s} + \alpha^L E(g(x + \xi - D^{(L)}) - g(s)) \mathbb{I}_{x + \xi - D^{(L)} < s} - K(1 - \alpha)
\]

We have seen from the case L = 1, Theorem 9.11, that

\[
g_s(x + \xi) - g_s(x) \ge 0, \forall x \ge x_0 - \xi.
\]

Consider next the function

\[
\chi_s(y) = \alpha E(g(y - D) - g(s)) \mathbb{I}_{y-D < s} - \alpha^L E(g(y - D^{(L)}) - g(s)) \mathbb{I}_{y-D^{(L)} < s},
\]

for \( y \ge x_0 \). We check that

\[
X_s(y) = \int_{-\infty}^s d\zeta \mu(\zeta) \int_{y-\zeta}^{\infty} (-\alpha f(\eta) + \alpha^L f^{(L)}(\eta)) d\eta,
\]

so in fact

\[
X_s(y) = \int_{-\infty}^s \mu(\zeta)(-\alpha \bar{F}(y-\zeta) + \alpha^L \bar{F}^{(L)}(y-\zeta)) d\zeta.
\]

Note that in the integral, \( \mu(\zeta) < 0 \), since \( s < \bar{s} \). We deduce

\[
X_s(y) \ge \alpha^L \int_{-\infty}^s \mu(\zeta)(\bar{F}^{(L)}(y-\zeta) - \bar{F}(y-\zeta)) d\zeta.
\]

Note that \( \bar{F}^{(L)}(y-\zeta) - \bar{F}(y-\zeta) \ge 0 \), and \( \mu(\zeta) \ge ((1-\alpha)c - \alpha^L p) \). Therefore

\[
X_s(y) \ge \alpha^L((1-\alpha)c - \alpha^L p) \int_{-\infty}^s (\bar{F}^{(L)}(y-\zeta) - \bar{F}(y-\zeta)) d\zeta,
\]

and since \( y \ge s \),

\[
\begin{aligned}
X_s(y) &\ge \alpha^L((1-\alpha)c - \alpha^L p) \int_{-\infty}^y (\bar{F}^{(L)}(y-\zeta) - \bar{F}(y-\zeta)) d\zeta \\
&= \alpha^L((1-\alpha)c - \alpha^L p) \int_0^\infty (\bar{F}^{(L)}(u) - \bar{F}(u)) du \\
&= \alpha^L((1-\alpha)c - \alpha^L p)(L-1)\bar{D}
\end{aligned}
\]

Thanks to the assumption (13.3.25) we can assert that

\[
Y_s(x) - \alpha E Y_s(x - D) \mathbb{I}_{x - D \ge x_0 - \xi} \le 0, \forall x \ge x_0 - \xi.
\]

Also

\[
Y_s(x_0 - \xi) \le -\Phi_s(x_0) - K \le -K,
\]

since \( \Phi_s(x_0) \ge H_s(x_0) = 0 \). It follows that

\[
Y_s(x) \le 0, \forall x \ge x_0 - \xi,
\]

which is the desired result.

### 13.3.6. POISSON DEMAND

We state the

### **Proposition 13.4.** We assume that the demand is distributed according to a Poisson distribution, then (13.3.24) holds.

Proof. We are going to show that

\[
(13.3.31) \quad H'_s(x) \ge 0, \text{if } x \ge x_0,
\]

then (13.3.24) will follow immediately, since for \( x \ge x_0 \)

\[
H_s(x) \le H_s(x+\xi) \le \Phi_s(x+\xi) \le \Phi_s(x+\xi) + K, \forall \xi \ge 0
\]

Assume

\[
f(x) = \beta \exp -\beta x,
\]

then, we know (see section 9.3.5) that

\[
\Gamma(x) = \frac{1}{1-\alpha} - \frac{\alpha}{1-\alpha} \exp -\beta(1-\alpha)x, x > 0,
\]

and

\[
\mu(x) = c(1-\alpha) + \alpha h - \alpha(p+h) \exp -\beta x^+.
\]

We have

\[
H'_s(x) = \mu(x) + \int_s^x \Gamma(x-\xi)\mu(\xi)d\xi,
\]

therefore

\[
H'_s(x) = \mu(x) + \alpha\beta \exp-\beta(1-\alpha)x \int_s^x \exp \beta(1-\alpha)\xi \mu(\xi)d\xi,
\]

and

\[
H_s(x) = \int_s^x \frac{\mu(\xi)}{1-\alpha}d\xi - \frac{\alpha}{1-\alpha} \exp-\beta(1-\alpha)x \int_s^x \exp \beta(1-\alpha)\xi \mu(\xi)d\xi.
\]

We recall that

\[
H_s(x) \le 0, \forall x < x_0, H_s(x_0) = 0.
\]

Let now \(x_1\) such that

\[
\int_s^{x_1} \exp \beta(1-\alpha)\xi \mu(\xi)d\xi = 0.
\]

If \(x_1 \le x_0\) then from the formula of \(H'_s(x), H'_s(x_0) > 0\) and the fact that \(\mu(x)\) increases, we see immediately that \(H'_s(x) \ge 0, \text{as } x \ge x_0\). So assume that \(s < x_0 < x_1\). For \(x \ge x_1\)

\[
H'_s(x) \ge H'_s(x_1) \ge H'_s(x_0) > 0.
\]

There remains the interval \((x_0, x_1)\). We know that \(H'_s(x_1) \ge H'_s(x_0) \ge 0\). If there exists a point in the interval such that \(H'_s(x) < 0\), necessarily there exists a point \(\xi\) such that

\[
x_0 < \xi < x_1, H'_s(\xi) = 0.
\]

If we introduce

\[
\lambda(x) = \mu(x) \exp \beta(1-\alpha)x, \rho(x) = \frac{\lambda(x)}{\int_s^x \lambda(u)du},
\]

then \(\xi\) satisfies \(\rho(\xi) = -\alpha\beta\). By definition of \(x_1\),

\[
\int_s^x \lambda(u)du < 0, \forall s < x < x_1,
\]

and \(\lambda'(x) > 0\). Therefore

\[
\rho'(x) = \frac{\lambda(x) \int_s^x \lambda(u)du - \lambda^2(x)}{(\int_s^x \lambda(u)du)^2} < 0.
\]

Moreover

\[
H'_s(x_0) > 0 \Rightarrow \lambda(x_0) + \alpha\beta \int_s^{x_0} \lambda(u)du > 0,
\]

hence

\[
\rho(x_0) + \alpha\beta < 0.
\]

Therefore \(\rho(x) < -\alpha\beta, \forall x \in [x_0, x_1]\). The point \(\xi\) cannot exist. So \(H'_s(x) > 0, \forall x \in [x_0, x_1]\). The result has been proven. \(\square\)

## 13.4. INFORMATION DELAYS

We will study here the situation when the information is not obtained immediately, but after some delay. It is a particular case of partial information, however simpler. The conditional distribution of the inventory, given the information available can be replaced by some sufficient statistics, and thus the problem remains finite-dimensional. We will rely on the works [6], [7].

### 13.4.1. MODEL AND PRELIMINARIES.

Let $\Omega, \mathcal{A}, P$ be a probability space. Time is discrete and there exists a process $D_t, t = 1, 2, \cdots$, of independent identically distributed random variables. The CDF of a generic variable $D$ is $F(x)$ and the probability density is $f(x)$. To each time $t$ is associated a random variable $\theta_t$ representing the delay in receiving the information at time $t$. In particular the inventory at time $t - \theta_t$ will be known at time $t$ provided this number is strictly positive. However $t - \theta_t$ is not necessarily the most recent time for which information is available at time $t$. The time of most recent information at time $t$ is called the *vintage*. If we denote it by $\beta_t$ then this process is defined by the evolution

\[
(13.4.1) \quad \beta_t = \max(t - \theta_t, \beta_{t-1}), t \ge 2 \quad \beta_1 = 1.
\]

The fact that $\beta_1 = 1$ means that we know the initial inventory. The inventory evolves as follows

\[
(13.4.2) \quad y_{t+1} = y_t + v_t - D_t, \quad y_1 = x.
\]

We can introduce the filtration

\[
\mathcal{F}^t = \sigma(D_1 \cdots D_{t-1}),
\]

and in the situations studied before the order $v_t$ was $\mathcal{F}^{t-1}$ measurable. This is no more the case. Call

\[
(13.4.3) \quad z_t = y_{\theta_t}.
\]

The information which is available at time $t$ is the pair $z_t, \beta_t$ and the previous values of this pair. We thus define the filtration of observations

\[
(13.4.4) \quad \mathcal{Z}^t = (\sigma(z_2, \beta_2) \cdots \sigma(z_t, \beta_t)), t \ge 2.
\]

When $\theta_t = 0$, we have $\beta_t = t$ and $\mathcal{Z}^t = \mathcal{F}^t$. The order $v_t$ is adapted to $\mathcal{Z}^t$. For $t = 1$ we have $\mathcal{Z}^1 = \{\Omega, \emptyset\}$ and $z_1 = y_1 = x$. We note moreover that

\[
(13.4.5) \quad \beta_{t-1} \le \beta_t \le t.
\]

To proceed with building the model, we have to make assumptions on the process of delays. First we shall assume that $\theta_t$ takes values in a finite state space $\mathcal{M} = \{0, 1, \cdots, M\}$. Moreover $\theta_t$ is a Markov chain with transition probability matrix $P = (p_{ij})$ with

\[
p_{ij} = P(\theta_{t+1} = j | \theta_t = i).
\]

We also assume that the two processes $\theta_t$ and $D_t$ are mutually independent.

### 13.4.2. INVENTORY POSITION.

We introduce the *inventory position*

\[
(13.4.6) \quad x_t = \begin{cases} z_t, & \text{if } \beta_t = t \\ z_t + \sum_{j=\beta_t}^{t-1} v_j, & \text{if } \beta_t < t \end{cases}
\]

We can prove the

### **Lemma 13.1.** The following relations hold

\[
(13.4.7) \quad x_{t+1} = x_t + v_t - \mathbb{I}_{\beta_{t+1} > \theta_t} \sum_{j=\beta_t}^{\beta_{t+1}-1} D_j, \quad x_1 = z_1 = y_1 = x
\]

\[
(13.4.8) \quad y_t = x_t - \sum_{j=\beta_t}^{t-1} D_j, \text{ if } \beta_t < t
