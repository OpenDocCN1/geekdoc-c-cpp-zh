A cycle is the interval min(θ, τ), τ + L. We consider the demands which arrive during a cycle, the backlog they constitute till they are served and the corresponding waiting time. If θ > τ + L there is no backlog and no waiting time. The population which is served at time τ + L is

```
-s + min(S, D(τ + L) - D(τ)) if τ > 0,
```

and

```
-x + min(S, D(L)) if τ = 0.
```

If the inventory at τ + L is negative then all demands during the cycle cannot be satisfied at time τ + L. The leftover will be served at time τ + L + τ₁. Its level is (S − D(τ + L) + D(τ))⁻. The average backlog can thus be expressed as

```
B = \int_0^1 (D(θ) + ρ(τ + L - θ)⁺ - D(θ))dρ + (S - D(τ + L) + D(τ))⁻ \frac{L}{τ + L - θ}
+ (S - D(τ + L) + D(τ))⁻ τ₁ 1_{\{S - s - D(τ + L) + D(τ) > 0\}}
```

Then the expected backlog is

```
EB = \frac{λ}{2} E(τ + L - θ)⁺ + LE \frac{(S - D(τ + L) + D(τ))⁻}{τ + L - θ}
+ E \left[ τ₁ 1_{\{S - s - D(τ + L) + D(τ) > 0\}} \frac{(S - D(τ + L) + D(τ))⁻}{τ + L - θ} \right].
```

We can consider now the waiting time. First we note that the whole population has to wait during the cycle an average time \frac{1}{2}(τ + L - θ)⁺. In addition the carry over has to wait an additional time L + τ₁, where τ₁ can be 0. Weighting with the population ratios we obtain an expected average waiting time

```
EWT = \frac{1}{2} E(τ + L - θ)⁺ + LE \frac{(S - D(τ + L) + D(τ))⁻}{D(τ + L) - D(θ)}
+ E \left[ τ₁ 1_{\{S - s - D(τ + L) + D(τ) > 0\}} \frac{(S - D(τ + L) + D(τ))⁻}{D(τ + L) - D(θ)} \right]
```

Little's Law:

```
EB = λEWT,
```

is not verified. It is verified approximately if we neglect the probability of carry over. Namely we assume that

```
Prob \{D(τ + L) - D(τ) > S\} ~ 0,
```

which means

```
\sum_{j=S+1}^\infty \frac{(λL)^j}{j!} ~ 0.
```

Another approximation consists in replacing the total population D(τ + L) - D(θ) by λ(τ + L - θ) in the coefficient of (S - D(τ + L) + D(τ))⁻. These two random variables have the same expected value. With these approximations Little's Law remains valid. These approximations require a not too large lead time.
