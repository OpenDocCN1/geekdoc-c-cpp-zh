Therefore

$$|G'_\alpha(S_\alpha(z), z') - G'_\alpha(S_\alpha(z'), z)|$$ $$\le \frac{2 \max(h, p+c)}{1 - \delta_0(m_0)} \int |f(|\zeta|^z) - f(|\zeta|^z)| d\zeta$$

Collecting results, we can then state the estimate

$$|S_\alpha(z) - S_\alpha(z')| \le \frac{\max(h, p+c)}{(h+p^\gamma)(m_0)(1-\delta_0(m_0))} \int |f(|\zeta|^z) - f(|\zeta|^z)| d\zeta$$

and using the assumption (12.3.32) we get

(12.3.43) $$|S_\alpha(z) - S_\alpha(z')| \le \frac{\delta \max(h, p+c)}{(h+p^\gamma)(m_0)(1-\delta_0(m_0))} |z' - z|.$$

So the sequence $S_\alpha(z)$ is uniformly Lipschitz continuous, from which the property (12.3.33) follows.

Consider $\chi_\alpha(x,z) = u'_\alpha(x,z) - h \mathbb{I}_{x>0} + p \mathbb{I}_{x<0} < c$. We have

(12.3.44) $$\chi_\alpha(x,z) = g_\alpha(x,z) + \alpha E[\chi_\alpha(x-x_2, z_2)|z_1=z], \text{ if } x \ge S_\alpha(z)$$ $$= 0 \text{ if } x \le S_\alpha(z)$$

with

(12.3.45) $$g_\alpha(x,z) = c + \alpha(h-c) - \alpha(h+p)\tilde{F}(x|z),$$

we deduce easily that

(12.3.46) $$\sup_{\xi \le z} |\chi_\alpha(x,z)| \le \frac{\max(h,c)}{1 - \delta_0(x)}.$$

Consider next $\psi_\alpha(x,z) = \chi'_\alpha(x,z)$. We obtain

(12.3.47) $$\psi_\alpha(x,z) = \begin{cases} \alpha(h+p)f(x|z) + \alpha E[\psi_\alpha(x-x_2, z_2)|z_1=z], & \text{if } x > S_\alpha(z) \\ 0, & \text{if } x < S_\alpha(z) \end{cases}$$

This function is not continuous but it is bounded (not uniformly in $\alpha$), and we can assert that

(12.3.48) $$\sup_{\xi \le z} |\psi_\alpha(\xi, z)| \le \frac{(h+p)\|f\|}{1 - \delta_0(x)}.$$

Next, consider $\chi_\alpha(x,z) - \chi_\alpha(x,z')$. For $x > S_\alpha(z), x > S_\alpha(z')$, we check easily that

$$|\chi_\alpha(x,z) - \chi_\alpha(x,z')| \le \left| h+p + \frac{\max(h,c)}{1-\delta_0(x)} \right| \delta |z-z'|.$$

Next operating as in Theorem 12.3 we can state that for $S_\alpha(z') > x > S_\alpha(z)$

$$|\chi_\alpha(x,z) - \chi_\alpha(x,z')| \le h \left| p + \frac{\max(h,c)}{1-\delta_0(x)} + \frac{h+p}{1-\delta_0(x)} \right| ||f|(x-S_\alpha(z)).$$

Combining estimates we obtain

(12.3.49) $$|\chi_\alpha(x,z) - \chi_\alpha(x,z')| \le \frac{C(m_0)\delta}{1-\delta_0(x)} |z-z'|.$$
