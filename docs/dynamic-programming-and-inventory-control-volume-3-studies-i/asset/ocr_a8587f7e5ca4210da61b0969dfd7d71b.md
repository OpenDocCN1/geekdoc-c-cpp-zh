# 15.2.2. CONTROL PROBLEM. Let again

$f(x) = hx^+ + px^-$.

We define the cost functional

(15.2.1) \( J_\sigma(V) = E \left[ \sum_{n=0}^\infty (K + cv_n) \exp -\alpha \theta_n + \int_0^\infty f(y_\sigma(t; V)) \exp -\alpha t dt \right] \)

and the value function

\( u(x) = \inf J_\sigma(V) \)

To obtain the relations of Dynamic Programming we can assume sufficient smoothness and write the optimality principle. If we do not order for a small amount of time \(\delta\) then we can write

\( u(x) \le \delta f(x) + (1 - \alpha \delta) Eu(x - D(\delta)), \)

and

\( Eu(x - D(\delta)) = Eu(x - \delta v - N(\delta) - \sigma w(\delta)). \)

Formally

\( N(\delta) = \begin{cases} 0, & \text{w.p. } 1 - \lambda \delta \\ \in (\xi, \xi + d\xi), & \text{w.p. } \lambda \delta \mu(\xi) d\xi \end{cases} \)

and \(w(\delta)\) is Gaussian with mean 0 and variance \(\delta\). Therefore

\( Eu(x - D(\delta)) \simeq (1 - \lambda \delta) Eu(x - \delta v - \sigma w(\delta)) + \lambda \delta \int_0^\infty u(x - \xi) \mu(\xi) d\xi \)

Expanding up to the first order in \(\delta\) assuming second order smoothness of \(u\) we obtain the inequality

\( Au(x) + \alpha u(x) \le f(x), \)

in which \(A\) is the integro-differential operator

(15.2.2) \( Au(x) = -\frac{1}{2} \sigma^2 u''(x) + \nu u'(x) - \lambda \int_0^\infty (u(x - \xi) - u(x)) \mu(\xi) d\xi. \)

In case we make an order of size \(v\), then the inventory becomes instantaneously \(x + v\) and we we write the inequality

\( u(x) \le K + cv + u(x + v), \forall v \ge 0 \)

so

\( u(x) \le M(u)(x), \)

with

(15.2.3) \( M(u)(x) = K + \inf_{v > 0} [cv + u(x + v)] \)

and since one of the two decisions must be taken, we have the complementarity slackness condition

\( (Au(x) + \alpha u(x) - f(x))(u(x) - M(u)(x)) = 0. \)
