
To prove (9.3.22) we first notice that for \(x \ge s\) we have \(\inf_{\eta \ge x} H(\eta) \ge \inf_{\eta \ge x} H(\eta) = -K\). So the inequality is certainly true whenever \(H(x) \le 0\). Consider then the smallest number called \(x_0\) for which \(H\) becomes positive. We have then \(H(x_0) = 0, H(x) < 0 \forall x, s < x < x_0\).

We can claim that \(g_s(x_0) > 0\). This follows from the relation \(g_s(x_0) = -\alpha EH(x_0 - D)\) and the properties of \(x_0\) resulting from its definition.

Let \(\xi > 0\). We shall consider the domain \(x \ge x_0 - \xi\). We can write the inequality \(H(x) \le g_s(x) + \alpha E(H(x - D)\mathbb{I}_{x - D \ge x_0 - \xi}), \forall x \ge x_0 - \xi\), which follows from the fact that \(E(H(x - D)\mathbb{I}_{x - D \le x_0 - \xi}) \le 0\).

Define next \(M(x) = H(x + \xi) + K\).

Clearly \(M(x) \ge 0\). We can write thanks to this positivity \(EM(x - D) \ge E(M(x - D)\mathbb{I}_{x - D \ge x_0 - \xi})\).

Now for \(x \ge x_0 - \xi\) we have \(H(x + \xi) - \alpha EH(x + \xi - D) = g_s(x + \xi)\), hence \(M(x) - \alpha EM(x - D) = g_s(x + \xi) + K(1 - \alpha)\).

Therefore we have \(M(x) \ge g_s(x + \xi) + \alpha E(M(x - D)\mathbb{I}_{x - D \ge x_0 - \xi}), \forall x \ge x_0 - \xi\).

We can claim that \(g_s(x + \xi) \ge g_s(x), \forall x \ge x_0 - \xi\).

Indeed, note that \(g_s(x + \xi) \ge g_s(x_0) \ge 0\) since \(g\) is increasing on \([s, \infty)\). So the inequality is obvious, whenever \(x < s\). If \(x \ge s\) the inequality amounts to \(g(x + \xi) \ge g(x)\). This is true whenever \(x \ge s\), by the monotonicity property. So it remains the case \(s < x < s\). But in this case \(g_s(x) < 0\) and the inequality is satisfied.

Let us define \(Y(x) = H(x) - M(x)\). From the inequalities above we can state that \(Y(x) \le \alpha E(Y(x - D)\mathbb{I}_{x - D \ge x_0 - \xi}), \forall x \ge x_0 - \xi\), and \(Y(x_0 - \xi) \le -K\).

These two properties imply \(Y(x) \le 0, \forall x \ge x_0 - \xi\) Therefore we have obtained (9.3.22) \(\forall x \ge x_0 - \xi\) and in particular for \(x > x_0\) as desired. So \(u\) is solution of the functional equation (9.3.3) and thus is the value function. The feedback defined from the \(s, S\) policy is optimal.

Remark. Another proof of (9.3.22) We will give another proof of (9.3.22), using an idea originated by [3].

PROOF. We recall that \(H(x) = g_s(x) + \alpha EH(x - D)\), and we want to prove \(H(x) \le K + \inf_{\eta \ge x} H(\eta)\).

Define

$$B(x) = H(x) - \inf_{\eta \ge x} H(\eta).$$

So we want to prove

$$B(x) \le K.$$

For $x \le s$ we have

$$B(x) = - \inf_{\eta \ge x} H(\eta) = - \inf_{\eta \ge x} H(\eta) = K.$$

Consider the first point $x_0$ such that $x_0 > s$ and $H(x_0) = 0$, $H(x) \le 0, \forall x \le x_0$. For $s \le x \le x_0$ we have

$$B(x) \le - \inf_{\eta \ge x} H(\eta) \le - \inf_{\eta \ge x} H(\eta) = K.$$

It remains to consider the case $x > x_0$. Assume that there exists a point $x' > x_0$ such that $B(x') \ge K$. Then there will exist a point $x'$ s.t. that

$$\bar{s} < x_0 \le x', B(x') = 0, B(x) < K, x < x'.$$

Define the point $x_3$ such that

$$H(x_3) = \inf_{\eta \ge x'} H(\eta).$$

The point $x_3$ is uniquely defined as the smallest infimum beyond $x'$. Moreover $x_3 \neq x'$ since

$$B(x') = H(x') - H(x_3) = K.$$

Next define $x_2$ such that

$$H(x_2) = \max_{\eta \le x_3} H(\eta) = \max_{s \le \eta \le x_3} H(\eta).$$

We take $x_2$ the smallest maximum. Then we can assert that $x_2 \ge x'$. Indeed if $x_2 < x'$ then

$$\inf_{\eta \ge x_2} H(\eta) \le \inf_{\eta \ge x'} H(\eta),$$

and

$$H(x_2) - \inf_{\eta \ge x_2} H(\eta) \ge H(x') - \inf_{\eta \ge x'} H(\eta) = K,$$

which will contradict the definition of $x'$. Hence $x' \le x_2 \le x_3$. Moreover $x_2 \neq x_3$ since

$$H(x_2) - H(x_3) \ge H(x') - H(x_3) = B(x') = K.$$

Let us check now that

(9.3.23) $$H(x) - H(y) \le H(x_2) - H(x_3), \forall x \le y \le x_3.$$

Indeed if $x < x'$ then

$$H(x) - H(y) \le H(x) - \inf_{\eta \ge x} H(\eta) < K \le H(x_2) - H(x_3).$$

Next if $x' \le x \le y \le x_3$ then

$$H(x) - H(y) \le H(x_2) - H(x_3).$$

Collecting results we note

$$s < \bar{s} < x_0 \le x' \le x_2 < x_3.$$

Now

$$H(x_2) = g(x_2) - g(s) + \alpha E H(x_2 - D);$$
$$H(x_3) = g(x_3) - g(s) + \alpha E H(x_3 - D),$$

and we have

$$g(x_2) - g(x_3) < 0;$$
$$H(x_2 - D) - H(x_3 - D) < H(x_2) - H(x_3),$$

from which, subtracting the equations we get $H(x_2) < H(x_3)$. This is a contradiction from the definition of $x_2$.

We finally have the equivalent of Proposition 9.3

## **Proposition 9.5.** The function $S(s)$ is decreasing, hence $S(s) \ge \bar{s}$, if $s \le \bar{s}$ and $S(s) \to S^+$, as $s \to -\infty$, with

(9.3.24) $$
\Gamma(S^+) = \frac{p - (c - h)(1 - \alpha)}{(1 - \alpha)(h + p)}.
$$

PROOF. The first property is proven as in Proposition 9.3. The second property follows from the first equation (10.3.22), which defines $S(s)$. From the monotonicity we know that $S(s) \uparrow S^+$. Then

$$\Gamma(S - s)\mu(s) \uparrow \frac{c(1 - \alpha) - \alpha p}{1 - \alpha}.$$

We can go to the limit in the first equation (10.3.22) and obtain

$$
\frac{c(1 - \alpha) - \alpha p}{1 - \alpha} + \alpha(h + p) \int_0^{S^*} \Gamma(S^* - \xi) f(\xi) d\xi = 0,
$$

then using the renewal equation, we get the formula (9.3.24). We can check directly that $S^* \ge \bar{s}$. Indeed using

$$
1 - \alpha + \alpha \bar{F}(S^*) \le \frac{1}{\Gamma(S^*)} = \frac{(1 - \alpha)(h + p)}{p - (c - h)(1 - \alpha)}.
$$

Therefore

$$
\alpha \bar{F}(S^*) \le (1 - \alpha) \frac{c(1 - \alpha) + h \alpha}{p - (c - h)(1 - \alpha)}.
$$

But, from the assumption (9.3.16), we deduce

$$
\frac{1 - \alpha}{p - (c - h)(1 - \alpha)} \le \frac{1}{h + p}.
$$

From the expression of $\bar{F}(s)$, we obtain $\bar{F}(S^*) \le \bar{F}(s)$, and the result follows.

Finally we can check the $K$-convexity property

## **Proposition 9.6.** The function $u(x)$ is $K$-convex.

PROOF. This is proven as in Theorem 9.6. One proves inductively that the increasing sequence is $K$-convex, and thus this property holds for the limit.

**Remark.** If one makes the technical assumption (9.2.33), then $Eu(x - D)$ is continuous, and the $s, S$ property of the optimal feedback can be proven as a consequence of the $K$-convexity theory, as in the proof of Theorem 9.6.

Finally, consider the situation when

$$
(9.3.25) \quad c > \frac{p\alpha}{1-\alpha},
$$

then the function $H_x(x)$ is always increasing in $x$. Therefore $S(s) = s, \forall s$. It follows that the optimal feedback is $\hat{v}(x) = 0$.

## 9.3.3. PROBABILISTIC APPROACH.

As we have done in the case without backlog, we are going to evaluate directly the cost corresponding to an arbitrary $s, S$ policy. We have the following

## Theorem 9.12. Let $V_{s,S}$ be the control corresponding to an $s, S$ policy, defined by the feedback

$$
(9.3.26) \quad V_{s,S} = \left\{ \begin{array}{ll} S - x, & \text{if } x \le s \\ 0, & \text{if } x > s \end{array} \right.
$$

The corresponding cost is: For $x \le s$

$$
(9.3.27) \quad J_s(V_{s,S}) = hx^+ + px^- - cx + \frac{g(s)}{1-\alpha} + \frac{K + H_1(S)}{(1-\alpha)\Gamma(S-s)}.
$$

For $x > s$, one has

$$
(9.3.28) \quad J_s(V_{s,S}) = hx^+ + px^- - cx + H_s(x) + \frac{g(s)}{1-\alpha} + (1 - (1-\alpha)\Gamma(x-s)) \frac{K + H_s(S)}{(1-\alpha)\Gamma(S-s)}.
$$

This function is continuous except for $x = s$.

Proof. The functions are identical to the case without backlog, however the functions $g, H$ are those corresponding to the present case, see (9.3.11), (9.3.13). The number $s$ is real, and to simplify we take $S > 0$ and $\ge s$.

Let $V_{s,S} = (v_1, \cdots, v_n, \cdots)$ and $y_1, y_2, \cdots, y_n \cdots$ be the corresponding evolution of stocks. We have $y_1 = x$. We begin by considering the case

- **I-** $x \le s \le 0$:

We then have $v_1 = S - x$. We set $\tau_1 = 1$ and we define the sequence of stopping times

$$
(9.3.29) \quad \tau_{k+1} = \tau_k + 1 + \inf\{n \ge 0 \mid D_{\tau_k} + \cdots + D_{\tau_k+n} \ge S - s\}.
$$

Since $S - s \ge S$, we will also need another sequence of stopping times

$$
(9.3.30) \quad \theta_{k+1} = \tau_k + 1 + \inf\{n \ge 0 \mid D_{\tau_k} + \cdots + D_{\tau_k+n} \ge S\},
$$

and we have $\tau_k \le \theta_{k+1} \le \tau_{k+1}$.

From Lemma 9.5, simply changing $S - s$ into $S$, we see that for $k \ge 2$, $\theta_k$ is a stopping time with respect to the filtration $\mathcal{F}^{n-1}$. Moreover $\theta_{k+1} - \tau_k - 1$ and $D_{\tau_k}, \cdots, D_{\tau_k+n}, n \ge 0$, are mutually independent of $\mathcal{F}^n$. The ordering times of the control $V_{s,S}$ are the times $\tau_k$. The inventory is then

$$
y_{\tau_k} = S - (D_{\tau_{k-1}} + \cdots + D_{\tau_k - 1}) \le s, \forall k \ge 2
$$

and the order is

$$
v_{\tau_k} = S - y_{\tau_k}, \forall k \ge 2
$$
