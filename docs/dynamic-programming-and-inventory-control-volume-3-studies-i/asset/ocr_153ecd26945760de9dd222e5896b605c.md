# 13.4.1. MODEL AND PRELIMINARIES.

Let $\Omega, \mathcal{A}, P$ be a probability space. Time is discrete and there exists a process $D_t, t = 1, 2, \cdots$, of independent identically distributed random variables. The CDF of a generic variable $D$ is $F(x)$ and the probability density is $f(x)$. To each time $t$ is associated a random variable $\theta_t$ representing the delay in receiving the information at time $t$. In particular the inventory at time $t - \theta_t$ will be known at time $t$ provided this number is strictly positive. However $t - \theta_t$ is not necessarily the most recent time for which information is available at time $t$. The time of most recent information at time $t$ is called the *vintage*. If we denote it by $\beta_t$ then this process is defined by the evolution

(13.4.1) $\beta_t = \max(t - \theta_t, \beta_{t-1}), t \ge 2 \quad \beta_1 = 1.$

The fact that $\beta_1 = 1$ means that we know the initial inventory. The inventory evolves as follows

(13.4.2) $y_{t+1} = y_t + v_t - D_t, \quad y_1 = x.$

We can introduce the filtration

$\mathcal{F}^t = \sigma(D_1 \cdots D_{t-1}),$

and in the situations studied before the order $v_t$ was $\mathcal{F}^{t-1}$ measurable. This is no more the case. Call

(13.4.3) $z_t = y_{\theta_t}.$

The information which is available at time $t$ is the pair $z_t, \beta_t$ and the previous values of this pair. We thus define the filtration of observations

(13.4.4) $\mathcal{Z}^t = (\sigma(z_2, \beta_2) \cdots \sigma(z_t, \beta_t)), t \ge 2.$

When $\theta_t = 0$, we have $\beta_t = t$ and $\mathcal{Z}^t = \mathcal{F}^t$. The order $v_t$ is adapted to $\mathcal{Z}^t$. For $t = 1$ we have $\mathcal{Z}^1 = \{\Omega, \emptyset\}$ and $z_1 = y_1 = x$. We note moreover that

(13.4.5) $\beta_{t-1} \le \beta_t \le t.$

To proceed with building the model, we have to make assumptions on the process of delays. First we shall assume that $\theta_t$ takes values in a finite state space $\mathcal{M} = \{0, 1, \cdots, M\}$. Moreover $\theta_t$ is a Markov chain with transition probability matrix $P = (p_{ij})$ with

$p_{ij} = P(\theta_{t+1} = j | \theta_t = i).$

We also assume that the two processes $\theta_t$ and $D_t$ are mutually independent.

# 13.4.2. INVENTORY POSITION.

We introduce the *inventory position*

(13.4.6) $x_t = \begin{cases} z_t, & \text{if } \beta_t = t \\ z_t + \sum_{j=\beta_t}^{t-1} v_j, & \text{if } \beta_t < t \end{cases}$

We can prove the

# **Lemma 13.1.** The following relations hold

(13.4.7) $x_{t+1} = x_t + v_t - \mathbb{I}_{\beta_{t+1} > \theta_t} \sum_{j=\beta_t}^{\beta_{t+1}-1} D_j, \quad x_1 = z_1 = y_1 = x$

(13.4.8) $y_t = x_t - \sum_{j=\beta_t}^{t-1} D_j, \text{ if } \beta_t < t$
