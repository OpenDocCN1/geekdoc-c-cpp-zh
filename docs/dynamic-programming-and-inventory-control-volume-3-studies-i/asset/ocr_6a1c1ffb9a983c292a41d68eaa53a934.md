We have the formula

$$\psi_{x^s}(\eta) - \psi_s(\eta) = \sum_{j=0}^{\lfloor \eta - s \rfloor} \frac{(g(s) - g(s'))\lambda^j}{(\alpha + \lambda)^{j+1}} + \sum_{j=\lfloor \eta - s \rfloor + 1}^{\lfloor \eta - s' \rfloor} \frac{(g(\eta - j) - g(s'))\lambda^j}{(\alpha + \lambda)^{j+1}} - \exp -(\alpha + \lambda)L \sum_{j=\lfloor \eta - s \rfloor + 1}^{\lfloor \eta - s' \rfloor} \frac{(g(\eta - j) - g(s))\lambda^j}{(\alpha + \lambda)^{j+1}} \sum_{k=j+1}^{\infty} \frac{((\alpha + \lambda)L)^k}{k!} + \exp -(\alpha + \lambda)L \sum_{j=\lfloor \eta - s' \rfloor + 1}^{\infty} \frac{(g(s) - g(s'))\lambda^j}{(\alpha + \lambda)^{j+1}} \sum_{k=j+1}^{\infty} \frac{((\alpha + \lambda)L)^k}{k!}.$$

Hence

$g(s) - g(s') < 0$

Furthermore $\lfloor \eta - s \rfloor + 1 \le j \le \lfloor \eta - s' \rfloor$ we have

$s \ge \eta - j \ge s'$

Collecting results we can assert that

$s' < s < \tilde{n}, s' < s < \eta \Rightarrow \psi_{x^s}(\eta) < \psi_s(\eta)$

Therefore for $s' < s < \tilde{n}$ we can assert that

$z(s') \le \inf_{\eta \ge s} \psi_{x^s}(\eta) \le \inf_{\eta \ge s} \psi_s(y) = z(s).$

We next check that

$z(s) \to -\infty \text{ as } s \to -\infty.$

It is sufficient to show that

$\psi_{x^s}(s) \to -\infty \text{ as } s \to -\infty, \forall x \text{ fixed.}$
