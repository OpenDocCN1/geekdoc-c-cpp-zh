The first term follows from (15.6.37), the third term will be treated by the uniform continuity of \(\varphi(x)\) on \([s, M]\). So we concentrate on the second term. We can write

\(\varphi_t(x) - \varphi(s) = \int_0^T \exp -u \, E(\varphi(y_\epsilon(eu)) - \varphi(s)) du\)
\(+ \int_T^{+\infty} \exp -u \, E\varphi(y_\epsilon(eu) - \varphi(s) \exp -T.\)

Consider \(u \le T\), then after considering possible cases, one can convince oneself of the relation

\(E\varphi(y_\epsilon(u)) - \varphi(s) = -\varphi(s) E\mathbb{I}_{\tau_T^s \le eu} \mathbb{I}_{|D(eu) - D(\tau_T^s)| \ge a_0} + E\mathbb{I}_{\tau_T^s > eu} \mathbb{I}_{|D(eu)| \ge a_0}]\)
\(+ E(\varphi(x - D(eu)) - \varphi(s)) \mathbb{I}_{\tau_T^s > eu} \mathbb{I}_{|D(eu)| < a_0}\)
\(+ E\varphi(S - D(eu) + D(\tau_T^s)) \mathbb{I}_{\tau_T^s \le eu} \mathbb{I}_{|D(eu) - D(\tau_T^s)| \ge a_0}\)
\(+ E(\varphi(S - D(eu) + D(\tau_T^s)) - \varphi(S)) \mathbb{I}_{\tau_T^s \le eu} \mathbb{I}_{|D(eu) - D(\tau_T^s)| < a_0}\)
\(+ E\varphi(y_\epsilon(eu)) \mathbb{I}_{\tau_{a_1, s} \le eu}.\)

We then take account of the estimates

\(\mathbb{I}_{|D(u)| \ge a_0} \le \nu_{cT+N(T)} + s \mathbb{I}_{\sup_{0 \le u \le T} w(u)} + \mathbb{I}_{\nu_{cT} + N(\epsilon T) + \sigma \sup_{0 \le u \le \epsilon T} w(u)}\)

and therefore

\(E\mathbb{I}_{|D(u)| \ge a_0} \le 2\Theta_{a_0}(\epsilon T).\)

With some additional effort we can also check that

\(E\mathbb{I}_{\tau_T^s \le eu} \mathbb{I}_{|D(u) - D(\tau_T^s)| \ge a_0} \le 2\Theta_{a_0}(\epsilon T);\)

\(E\mathbb{I}_{\tau_{a_1, s} \le u} \le \Theta_{S-s}(\epsilon T).\)

Also

\(E|\varphi(x - D(eu)) - \varphi(s)| \mathbb{I}_{|D(eu)| < a_0} \le \gamma_M(2a_0);\)

\(E|\varphi(S - D(eu) + D(\tau_T^s)) - \varphi(S)| \mathbb{I}_{|D(eu) - D(\tau_T^s)| < a_0} \le \gamma_M(a_0),\)

where \(\gamma_M(\delta)\) is the modulus of continuity of \(\varphi(x)\) on \([s, M]\). Collecting results we can assert that for \(u \le T\)

\(|E\varphi(y_\epsilon(u)) - \varphi(s)| \le ||\varphi|| (4\Theta_{a_*}(\epsilon T) + \Theta_{S-s}(\epsilon T)) + \gamma_M(2a_0) + \gamma_M(a_0),\)

and thus

\(\sup_{s \le u \le s+a_0} |\varphi_t(x) - \varphi(s)| \le ||\varphi|| (4\Theta_{a_*}(\epsilon T) + \Theta_{S-s}(\epsilon T) + 2 \exp -T) + \gamma_M(2a_0) + \gamma_M(a_0),\)

which implies

\(\limsup_{\epsilon \to 0} \sup_{s \le u \le s+a_0} |\varphi_t(x) - \varphi(s)| \le 2 ||\varphi|| \exp -T + \gamma_M(2a_0) + \gamma_M(a_0).\)

Therefore also

\(\limsup_{\epsilon \to 0} \sup_{s \le u \le s+a_0} |\varphi_t(x) - \varphi(s)| \le 2 ||\varphi|| \exp -T + \gamma_M(2a_0) + \gamma_M(a_0)\)
\(+ \sup_{s \le u \le s+a_0} |\varphi(x) - \varphi(s)|.\)

Letting \(a_0\) tend to 0, then \(T\) tend to \(+\infty\), we see that the right hand side is 0. This completes the proof of intermediary results and thus also the proof of Theorem 15.5
