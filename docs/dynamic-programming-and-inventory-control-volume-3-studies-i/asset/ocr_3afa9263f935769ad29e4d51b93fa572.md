# ERGODIC CONTROL OF INVENTORIES WITH SET UP COST

In this chapter, we shall consider the situations studied in the previous chapter, in the case \(\alpha \to 1\).

# 10.1. DETERMINISTIC CASE

# 10.1.1. SETTING OF THE PROBLEM.

We consider the functional equation

```
(10.1.1) 
\( u_\alpha(x) = hx + \inf_{v \ge (D-x)^+} [K \mathbf{1}_{v>0} + cv + \alpha u_\alpha(x+v-D)], \)
```

in which we have emphasized the dependence in \(\alpha\). We know that the optimal feedback is given by

```
(10.1.2) 
\( \hat{v}_\alpha(x) = \begin{cases} 0, & \text{if } x \ge D \\ D(\hat{k}_\alpha + 1) - x, & \text{if } x < D \end{cases} \)
```

where \(\hat{k}_\alpha\) minimizes

```
\( \lambda_\alpha(k) = \frac{K + c(k+1)D + \alpha h D F_\alpha(k)}{1 - \alpha^{k+1}}, \)
```

where

```
\( F_\alpha(k) = \frac{\alpha^{k+1} - (k+1)\alpha + k}{(1 - \alpha)^2}. \)
```

We want to study the behavior of \(u_\alpha(x)\) and \(\hat{v}_\alpha(x)\) as \(\alpha \to 1\).

# 10.1.2. CONVERGENCE.

We define the integer \(\hat{k}\) which minimizes

```
(10.1.3) 
\( \lambda_1(k) = \frac{K}{k+1} + hD\frac{k}{2}, \)
```

over \(k \ge 0\). We next define

```
(10.1.4) 
\( \rho = cD + \lambda_1(\hat{k}), \)
```

then we can state the following convergence result

# Theorem 10.1. We have the properties, as \(\alpha \to 1\)

```
(10.1.5) 
\( \varrho_\alpha = (1 - \alpha)u_\alpha(0) \to \rho; \)
```

```
(10.1.6) 
\( z_\alpha(x) = u_\alpha(x) - u_\alpha(0) \to z(x), \)
```

with

```
(10.1.7) 
\( z(x) = \begin{cases} (h-c)x, & \text{if } x < D \\ hx - \rho + z(X-D), & \text{if } x \ge D \end{cases} \)
```
