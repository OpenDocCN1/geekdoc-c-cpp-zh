
n = 1. We assume they are verified for n, we prove them for n + 1. Since \( G_n(x, z) \) is K-convex in x, continuous and \( \to +\infty \) as \( x \to +\infty \), we can define \( s_n(z), S_n(z) \) with

(12.4.16) \( G_n(S_n(z), z) = \inf_\eta G_n(\eta, z) \)

(12.4.17) \( s_n(z) = \begin{cases} 0, & \text{if } G_n(0, z) \le K + \inf_\eta G_n(\eta, z) \\ G_n(s_n(z), z) = K + \inf_\eta G_n(\eta, z), & \text{if } G_n(0, z) > K + \inf_\eta G_n(\eta, z) \end{cases} \)

As usual we take the smallest minimum to define \( S_n(z) \) in a unique way. Since \( G_n(\eta, z) \) is continuous, it is easy to check that \( S_n(z) \) is continuous. Also \( s_n(z) \) is continuous.

We can write

\( u_{n+1}(x, z) = (h - c)x + G_n(\max(x, s_n(z)), z), \)

which shows immediately that \( u_{n+1}(x, z) \) is K-convex and continuous. Furthermore \( u_{n+1}(x, z) \to +\infty \), as \( x \to +\infty \). We then have

\( G_{n+1}(x, z) = cx + pE[(x - z_2)^+ | z_1 = z] + \alpha(h - c)E[(x - z_2)^+ | z_1 = z] + \alpha E[G_n(\max(x - z_2, s_n(z_2)), z_2) | z_1 = z] \)

It is the sum of a convex function and a K-convex function, hence K-convex. It is continuous and \( \to +\infty \) as \( x \to +\infty \). So the recurrence is proven. If we write (formally)

\( u'_n(x, z) = h - c + \chi_n(x, z), \)

then one has the recurrence

\( \chi_{n+1}(x, z) = \begin{cases} 0 & \text{if } x < s_n(z) \\ = \mu(x, z) + \alpha E[\chi_n(x - z_2, z_2) | z_1 = z] \end{cases} \)

with

(12.4.18) \( \mu(x, z) = c + \alpha(h - c) - (p + \alpha(h - c))\bar{F}(x|z). \)

The function \( \chi_{n+1}(x, z) \) is discontinuous in \( s_n(z) \). However one has the bound

\( -\frac{(p - c)}{1 - \alpha} \le \chi_{n+1}(x, z) \le \frac{c + \alpha(h - c)}{1 - \alpha} \quad \text{a.e.} \)

Therefore the limit \( u(x, z) \) is K-convex and satisfies

\( u'(x, z) = h - c + \chi(x, z), \)

with

\( -\frac{(p - c)}{1 - \alpha} \le \chi(x, z) \le \frac{c + \alpha(h - c)}{1 - \alpha} \quad \text{a.e.} \)

Hence \( u(x, z) \) is continuous in x and \( \to +\infty \) as \( x \to +\infty \). Therefore one defines uniquely \( s(z), S(z) \) and \( S(z) \) minimizes in x the function

\( G(x, z) = cx + pE[(x - z_2)^+ | z_1 = z] + \alpha E[u((x - z_2)^+, z_2) | z_1 = z] \)

From this formula and the Lipschitz continuity of u in x, using the assumption (12.4.3) one can see that \( G(x, z) \) is continuous in both arguments. Hence \( S(z) \) and \( s(z) \) are continuous. The proof has been completed. \(\square\)

## 12.4.3. ERGODIC THEORY.

We now study the behavior of $u(x, z)$ as $\alpha \to +\infty$. We denote it by $u_\alpha(x, z)$ and we write the relations

(12.4.19) 
$u_\alpha(x, z) = (h - c)x + G_\alpha(\max(x, s_\alpha(z)), z)$

(12.4.20) 
$G_\alpha(x, z) = g_\alpha(x, z) + \alpha E[G_\alpha(\max((x - z_2)^+, s_\alpha(z_2)), z_2)|z_1 = z],$

with

(12.4.21) 
$g_\alpha(x, z) = cx + pE[(x - z_2)^-|z_1 = z] + \alpha(h - c)E[(x - z_2)^+|z_1 = z].$

We will use an approach different from that of the base stock case, since we cannot prove uniform Lipschitz properties for the function $s_\alpha(z)$. The present method will use less assumptions. We shall assume $c_0 = 0$ and

(12.4.22) 
$z_n \text{ is ergodic.}$

We denote by $\varpi(z)$ the invariant measure. We also assume

(12.4.23) 
$\int |f(\zeta|z) - f(\zeta|z')| d\zeta \le \delta|z - z'|, 
\int \zeta |f(\zeta|z) - f(\zeta|z')| d\zeta \le \delta|z - z'|$

(12.4.24) 
$\sup_z F(x|z) = \delta_0(x) < 1, \forall x$

(12.4.25) 
$\sup_z \bar{F}(x|z) \to 0 \text{ as } x \to +\infty$

We begin with the

### Lemma 12.3. If $s(z) > 0$, then

$S(z) \le \frac{p + \alpha(h - c)}{c + \alpha(h - c)} E[z_2|z]$

PROOF. If $s(z) > 0$ then we have

$u(0, z) = K + G(S(z), z).$

Set

$\dot{y}_2 = (S(z) - z_2)^+, \quad \dot{v}_2 = \dot{u}(\dot{y}_2, z_2),$

then

$G(S(z), z) = cS(z) + pE[(S(z) - z_2)^-|z_1 = z] + \alpha E[u(\dot{y}_2, z_2)|z_1 = z]$

Also we can write

$u(\dot{y}_2, z_2) = (h - c)\dot{y}_2 + K\mathbb{1}_{\dot{y}_2 > 0} + G(\dot{y}_2 + \dot{v}_2, z_2) 
= h\dot{y}_2 + K\mathbb{1}_{\dot{y}_2 > 0} + c\dot{v}_2 + pE[(\dot{y}_2 + \dot{v}_2 - z_3)^-|z_2] 
+ \alpha E[u((\dot{y}_2 + \dot{v}_2 - z_3)^+, z_3)|z_2]$

Therefore, we can write

(12.4.26) 
$u(0, z) = K + cS(z) + pE[(S(z) - z_2)^-|z_1 = z] 
+ \alpha E[h\dot{y}_2 + K\mathbb{1}_{\dot{y}_2 > 0} + c\dot{v}_2 + p(\dot{y}_2 + \dot{v}_2 - z_3)^- 
+ \alpha u((\dot{y}_2 + \dot{v}_2 - z_3)^+, z_3)|z_1 = z].$

We next have

$u(0, z) \le G(0, z) = E[pz_2 + \alpha u(0, z_2)|z_1 = z]$

Furthermore

$u(0, z_2) \le K + G(\hat{y}_2 + \hat{v}_2, z_2)$

Replacing $G$ and combining the two inequalities we get

$u(0, z) \le pE[z_2|z_1 = z] + \alpha K + \alpha E[(y_2 + \hat{v}_2) + p(y_2 + \hat{v}_2 - z_3)^- + \alpha u((y_2 + \hat{v}_2 - z_3)^+, z_3)|z_1 = z]$

Comparing with (12.4.26) we obtain easily the desired inequality.

We deduce from the Lemma that, whenever $c_0 = 0$

(12.4.27) $$s_\alpha(z) \le \frac{p + (h - c)^+}{\min(c, h)} c_1.$$

We now state the

### Theorem 12.9. We assume (12.4.3), (12.4.4), with $c_0 = 0$, (12.4.22), (12.4.23), (12.4.24), (12.4.25). Then there exists a number $\rho_\alpha$ such that, for a subsequence, still denoted $\alpha \to 1$

(12.4.28) $$\sup_{x \le M} \frac{u_\alpha(x, z) - \frac{\rho_\alpha}{1 - \alpha} - u(x, z)}{z} \to 0, \forall M,$$

and $\rho_\alpha \to \rho$. The function $u(x, z)$ is Lipschitz continuous, $K-convex$ and satisfies

(12.4.29) $$|u(x, z)| \le C_0 + \frac{C_1 x}{1 - \delta_0(x)}$$

(12.4.30) $$|u_x(x, z)| \le \frac{C}{1 - \delta_0(x)}, \quad |u_z(x, z)| \le C_0 + \frac{C_1 x}{1 - \delta_0(x)} \quad a.e.$$

The pair $u(x, z), \rho$ is the solution of

(12.4.31) $$u(x, z) + \rho = \inf_{v \ge 0} [K \mathbb{I}_{v > 0} + l(x, z, v) + \Phi^v u(x, z)].$$

PROOF. We set

$\chi_\alpha(x, z) = u'_\alpha(x, z) - h + c,$

then we can write

(12.4.32) $$\chi_\alpha(x, z) = \mathbb{I}_{x > z_\alpha(h)} \mu_\alpha(x, z) + \alpha E[\chi_\alpha(x - z_2, z_2) \mathbb{I}_{x - z_2 > 0} | z_1 = z],$$

with

$\mu_\alpha(x, z) = g'_\alpha(x, z) = c + \alpha(h - c) - (p + \alpha(h - c))\bar{F}(x|z)$

The function $\chi_\alpha(x, z)$ is not continuous, but satisfies

(12.4.33) $$\sup_{0 \le \xi \le x} \frac{|\chi_\alpha(\xi, z)|}{z} \le \frac{\max(h, p)}{1 - \delta_0(x)}.$$

Let us next define \(\Gamma_\alpha(z) = u_\alpha(0, z)\). We have
\(\begin{aligned}
\Gamma_\alpha(z) &= G_\alpha(s_\alpha(z), z) \\
&= c s_\alpha(z) + p E[(s_\alpha(z) - z_2)^- | z_1 = z] + \alpha E[u_\alpha((s_\alpha(z) - z_2)^+, z_2) | z_1 = z] \\
&= g_\alpha(s_\alpha(z), z) + \alpha E \left[ \int_0^{(s_\alpha(z) - z_2)^+} \chi_\alpha(\xi, z_2) d\xi | z_1 = z \right] + \alpha E[\Gamma_\alpha(z_2) | z_1 = z]
\end{aligned}\)

Therefore we can write
(12.4.34) \(\Gamma_\alpha(z) = \Psi_\alpha(z) + \alpha E[\Gamma_\alpha(z_2) | z_1 = z],\)

with
\(\Psi_\alpha(z) = g_\alpha(s_\alpha(z), z) + \alpha E \left[ \int_0^{(s_\alpha(z) - z_2)^+} \chi_\alpha(\xi, z_2) d\xi | z_1 = z \right].\)

Thanks to Lemma 12.3, we have the estimate (12.4.27), so \(s_\alpha(z) \le m_0\). Using the estimate (12.4.33), we see that \(|\Psi_\alpha(z)| \le C\). Let us then define
\(\rho_\alpha = \int \Psi_\alpha(z) \varpi(z) dz,\)

and \(\bar{\Gamma}_\alpha(z) = \Gamma_\alpha(z) - \frac{\rho_\alpha}{1 - \alpha}\). From ergodic theory, we can assert that
\(\sup_z |\bar{\Gamma}_\alpha(z)| \le \sup_z |\Psi_\alpha(z) - \rho_\alpha| \frac{3 - \beta}{1 - \beta} \le C,\)

and we can state the estimate
\(\left| u_\alpha(x, z) - \frac{\rho_\alpha}{1 - \alpha} \right| \le C + \frac{Cx}{1 - \delta_0(x)}.\)

Define \(\tilde{u}_\alpha(x, z) = u_\alpha(x, z) - \frac{\rho_\alpha}{1 - \alpha}\). We write equation (12.4.1) as
(12.4.35) \(\tilde{u}_\alpha(x, z) + \rho_\alpha = \inf_{v \ge 0} [K \mathbf{1}_{v>0} + l(x, z, v) + \alpha \Phi^v \tilde{u}_\alpha(x, z)].\)

From Lemma 12.3 we can assert that the optimal feedback satisfies \(x + \tilde{u}_\alpha(x, z) \le \max(x, m_0)\). Therefore we can replace (12.4.35) by
\(\begin{aligned}
\tilde{u}_\alpha(x, z) + \rho_\alpha &= \inf_{x+v \le \max(x, m_0)} [K \mathbf{1}_{v>0} + l(x, z, v) + \alpha \Phi^v \tilde{u}_\alpha(x, z)] \\
&= \inf_{0 \le v \le \max(x, m_0) - x} L_\alpha(x, z, v).
\end{aligned}\)

Next
\(L_\alpha(x, z, v) - L_\alpha(x, z', v) = \int [p(x+v-\zeta)^+ - \alpha \tilde{u}_\alpha((x+v-\zeta)^+, \zeta)] (f(z|\zeta) - f(z'|\zeta)) d\zeta\)

For \(v \le \max(x, m_0) - x\) we can write
\(\begin{aligned}
|\tilde{u}_\alpha((x+v-\zeta)^+, \zeta)| \le C + \frac{C \max(x, m_0)}{1 - \delta_0(\max(x, m_0))} \\
\le C'_1 + \frac{C_2 x}{1 - \delta_0(x)}
\end{aligned}\)

Using the assumption (12.4.23) we get easily
\(|\tilde{u}_\alpha(x, z) - \tilde{u}_\alpha(x, z')| \le \left( C_1 + \frac{C_2 x}{1 - \delta_0(x)} \right) |z - z'|.\)
