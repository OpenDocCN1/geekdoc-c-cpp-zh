
If $n_0 = 0$, it means that $c < \alpha p$. We claim that

$$
u_n(x) = \sum_{j=1}^n \alpha^{j-1} (\Phi^{(j-1)} l_0)(x), \forall 1 \le n \le n_0 + 1.
$$

Indeed we have (we use $u_n(x)$ as the definition of the sum in this expression)

$$
u'_n(x) = -p \frac{1-\alpha^n}{1-\alpha}, \forall x < 0
$$

hence

$$
c - \alpha p \frac{1-\alpha^n}{1-\alpha} > 0, \forall n \le n_0.
$$

Therefore $cx + \alpha E u_n(x - D)$ is increasing for $0 \le n \le n_0$, and thus $u_n$ is solution of equation (5.2.17), for $0 \le n \le n_0$, which implies the claim.

For $n \ge n_0 + 2$, there exists $S_n > 0$, such that

$$
c + \alpha E u'_n(S_n - D) = 0,
$$

and

$$
u_{n+1}(x) = \begin{cases} hx^+ + px^- - cx + cS_n + \alpha E u_n(S_n - D), & x < S_n \\ hx + \alpha E u_n(x - D), & x \ge S_n \end{cases}
$$

This result is proven by induction, noting that $u_n(x)$ is convex and goes to $+\infty$ for $|x| \to +\infty$. Note that $u_n$ is $C^1$ except for $x=0$. This proves that the increasing sequence is convex and goes to $+\infty$ for $|x| \to +\infty$. It follows that $u$ is convex and goes to $+\infty$ for $|x| \to +\infty$. Rewriting Bellman equation (5.2.5) as

$$
u(x) = hx^+ + px^- - cx + \inf_{v \ge 0} [c(x+v) + \alpha E u(x+v-D)],
$$

we see that the optimal feedback is defined by a base stock policy.

The base stock satisfies

$$
c + \alpha E u'(S - D) = 0,
$$

and

$$
E u(S - D) = \frac{c\bar{D} + h E(S-D)^+ + p E(S-D)^-}{1-\alpha}.
$$

Moreover $S$ is the solution of

$$
F(S) = \frac{c(1-\alpha) + \alpha b}{\alpha(p+h)}.
$$

We deduce easily (5.2.14). Next, the solution $u$ can be written as

$$
u(x) = \begin{cases} -cx + hx^+ + px^- + cS + \frac{1}{1-\alpha} (c\bar{D} + h E(S-D)^+ + p E(S-D)^-), & \forall x \le S \\ hx^+ + px^- + \alpha E u(x-D), & \forall x \ge S \end{cases}
$$

We see that $u$ is $C^1$ except for $x=0$. Defining $z$ and $g$ as in the statement of the theorem, we see easily that $z$ is the solution of

$$
z(x) = g(x) + \alpha E z(x - D),
$$

which is solved by formula (5.2.16). The proof has been completed.

We can now turn to the case when $c(1-\alpha) \ge \alpha p$. We have

### Theorem 5.7.

We assume (5.2.2), (5.2.3) and \(c(1-\alpha) \ge \alpha p\). Then \(u(x) = w_0(x)\), with

(5.2.19) \(w_0(x) = \sum_{j=1}^{\infty} \alpha^{j-1} (\Phi^0)^{j-1} l_0(x).\)

Therefore \(\dot{v}(x) = 0\).

### PROOF.

In fact, if we look at the proof of the preceding theorem, the present assumption corresponds to the situation when \(n_0 = +\infty\). We then see that the increasing sequence converges to \(w_0(x)\). This proves the result.

### Remark 5.2.

We obtained in Proposition 5.1 that \(\bar{v}(x) \le x^- + C\). Moreover from the Base stock policy, we have also \(\dot{v}(x) \le x^- + S\). We must check that \(S \le C\). Using again \(D \ge S\bar{F}(S)\), we can state that

\(\bar{D} \ge S \frac{c(1-\alpha) + \alpha h}{\alpha(p+h)},\)

hence

\(\frac{C}{S} \ge \frac{[h + (p+\alpha)(1-\alpha)](c(1-\alpha) + \alpha h)}{c(p+h)(1-\alpha)^2},\)

and the constant on the right hand side is bigger than 1.

We have also a remark similar to Remark 5.1

### Remark 5.3.

Suppose \(x \le S\). If we apply a Base stock policy then we shall put an order at each period, and we have

\(y_n + v_n = S \quad n \ge 1\)
\(y_n = S - D_{n-1} \quad n \ge 2\)

and thus \(v_n = D_{n-1}\). It follows that the cost of a base stock policy is

\(u(x) = hx^+ + px^- + c(S-x) + \frac{\alpha}{1-\alpha}(c\bar{D} + hE(S-D)^+ + pE(S-D)^-),\)

and minimizing this expression in \(S\) yields formula (5.2.13).

## 5.3. DETERMINISTIC CASE

The deterministic case is a particular case of the stochastic case, except for smoothness. We assume that we face a fixed demand \(D\) at each period. We briefly describe the results.

### 5.3.1. NO SHORTAGE ALLOWED.

The inventory evolves as follows

(5.3.1) \(y_{n+1} = (y_n + v_n - D)^+ \quad y_1 = x,\)

and the cost functional is

(5.3.2) \(J_x(V) = \sum_{n=1}^{\infty} \alpha^{n-1} l(y_n, v_n),\)

with

(5.3.3) \(l(x,v) = (h-c)x + l_0(x+v),\)

and

(5.3.4) \(l_0(x) = cx + p(x-D)^-.\)

The Bellman equation reads

(5.3.5) \( u(x) = (h - c)x + \inf_{v \ge 0} \{ l_0(x + v) + \alpha u((x + v - D)^+) \} \).

The solution \( u(x) \) is convex continuous and goes to \( +\infty \) as \( x \to +\infty \). We have to be careful about differentiability. We are interested in the minimum of \( l_0(x) + \alpha u((x - D)^+) \). If \( S \) is the minimum, we have for \( x \le S \), \( u(x) = (h - c)x + C \), hence for \( x \le S \), we have

\( l_0(x) + \alpha u((x - D)^+) = l_0(x) + \alpha(h - c)(x - D)^+ + \alpha C. \)

Therefore, we must have

\( l_0(x) + \alpha(h - c)(x - D)^+ \ge l_0(S) + \alpha(h - c)(S - D)^+, \quad \forall x < S. \)

Recalling that

\( l_0(x) + \alpha(h - c)(x - D)^+ = cx + p(x - D)^- + \alpha(h - c)(x - D)^+, \)

we see easily that if \( p \ge c \), this is achieved in a unique way with \( S = D \). If \( c > p \) then we have \( S = 0 \).

Therefore, if \( p \ge c \), we have

\( u(x) = (h - c)x + \frac{cD}{1 - \alpha}, \quad \forall x \le D. \)

### 5.3.2. BACKLOG ALLOWED.

In the case of backlog, we have

(5.3.6) \( y_{n+1} = y_n + v_n - D \quad y_1 = x, \)

and the cost functional is

(5.3.7) \( J_x(V) = \sum_{n=1}^\infty \alpha^{n-1} l(y_n, v_n), \)

with

\( l(x, v) = hx^+ + px^- + cv. \)

Bellman equation becomes

(5.3.8) \( u(x) = hx^+ + px^- - cx + \inf_{v \ge 0} \{ c(x + v) + \alpha u(x + v - D) \} \).

We are interested in the minimum of the function \( cx + \alpha u(x - D) \). If \( S \) is this minimum, we have for \( x \le S \),

\( u(x) = hx^+ + px^- - cx + C, \)

so for \( x \le S \), the function \( cx + \alpha[h(x - D)^+ + p(x - D)^- - c(x - D) + C] \) must attain its minimum in \( S \). We obtain that if \( cp \ge c(1 - \alpha) \) necessarily \( S = D \), whereas if \( cp < c(1 - \alpha) \) necessarily \( S = 0 \). Therefore

\( u(x) = hx^+ + px^- - cx + \frac{cD}{1 - \alpha}, \quad \forall x \le D \)

## ERGODIC CONTROL IN DISCRETE TIME

We have in the preceding chapters considered always a control problem with discount \(\alpha < 1\). The problem of Ergodic Control corresponds to the case when \(\alpha = 1\). This is a limit situation, we cannot just take \(\alpha = 1\) in the formulas. The value function becomes infinite. We have studied in Chapter 3 the situation without control. We develop in this Chapter the corresponding theory for controlled Markov chains.

### 6.1. FINITE NUMBER OF STATES

We study here the simplest case of a Markov chain with a finite number of states.

### 6.1.1. ASSUMPTIONS-NOTATION.

We consider a Controlled Markov chain with a finite number of states. The space of states is denoted by \(X\) and the transition probability reduces to a matrix, which is defined by \(\varpi^u(i, j) = P(y_{n+1} = j | y_n = i)\), where \(y_n\) represents the canonical process (the state of the system at time \(n\)). The control \(v \in U\). We assume

- (6.1.1)
- U compact
- \(\varpi^u(i, j)\) is continuous in \(v, \forall i, j\)
- \(\varpi^u(i, j) > 0, \forall i, j, v\)

Note that this assumption implies a uniform bound below, since we have a finite number of functions which are strictly continuous on a compact. We write

(6.1.2) \(\varpi^u(i, j) \ge \delta > 0.\)

We denote by \(\Phi^u\) the operator associated with the matrix \(\varpi^u\). We recall that

\(\Phi^u f(i) = \sum_j \varpi^u(i, j) f(j).\)

This formula extends to a feedback \(v(.)\). We will define \(\Phi^{v(.)} f\) by

\(\Phi^{v(.)} f(i) = \sum_j \varpi^{v(i)}(i, j) f(j).\)

To the operator \(\Phi^{v(.)}\) is associated the transition matrix \(\varpi^{v(i)}(i, j)\). We clearly have the property

(6.1.3) \(\varpi^{v(i)}(i, j) \ge \delta, \forall i, j\)

### 6.1.2. ERGODIC PROPERTIES.

Thanks to (6.1.3) the property (3.5.2) in Chapter 3 is satisfied, for any given feedback. Therefore there will exist a unique invariant measure denoted by $m^{v(\cdot)}$ such that

(6.1.4) $$ \sum_i m_i^{v(\cdot)} \varpi^{v(i)}(i,j) = m_j^{v(\cdot)}, \forall j. $$

Note that this invariant measure is not related to a specific value of the control, but combines all possible values of the control. There is an averaging effect taking account of all the values v(i). For any f \in B we have the property

(6.1.5) $$ \left\| (\Phi^{v(\cdot)})^n f - \sum_j m_j^{v(\cdot)} f_j \right\| \le 2 ||f|| \beta^{n-1}, \forall f \in B, \text{ with } \beta = 1 - \delta $$

### 6.1.3. DYNAMIC PROGRAMMING.

Consider a function f(i,v) such that

(6.1.6) $$ l(i,v) \text{ continuous (hence bounded), } l \ge 0. $$

The Bellman equation of ergodic control is defined by

(6.1.7) $$ z(i) + \lambda = \inf_{v \in U} [l(i,v) + \Phi^v z(i)]. $$

We see that there is no $\alpha$ in the right hand side. More precisely, $\alpha = 1$. On the left hand side we have a constant $\lambda$, which did not exist in the Bellman equation with discount. In fact we consider the pair $(z, \lambda)$ as the solution of the nonlinear equation (6.1.7). Our main result is the following

**Theorem 6.1.7.** Under the assumptions (6.1.1) and (6.1.6) there exists one and only one pair z, $\lambda$ which is the solution of (6.1.7).

### PROOF.

We consider the Bellman equation with a discount term

(6.1.8) $$ u_\alpha(i) = \inf_{v \in U} [l(i,v) + \alpha \Phi^v u_\alpha(i)], $$

and we will let $\alpha$ tend to 1.

This equation admits a unique solution $u_\alpha$ and moreover there exists an optimal feedback $v_\alpha(i)$ such that

$$ u_\alpha(i) = l(i, v_\alpha(i)) + \alpha \Phi^{v_\alpha(\cdot)} u_\alpha(i). $$

We can assert that

$$ (1 - \alpha) ||u_\alpha|| \le ||l|| = \max_{i,v} l(i,v). $$

For any fixed $\alpha$ there exists a unique invariant measure $m^{v_\alpha(\cdot)}$ such that

$$ \left\| (\Phi^{v_\alpha(\cdot)})^n \phi - \sum_j m_j^{v_\alpha(\cdot)} \phi_j \right\| \le 2 ||\phi|| \beta^{n-1}. $$

If we define the function $h_\alpha$ such that

$$ h_\alpha(i) = l(i, v_\alpha(i)) - (1 - \alpha) \Phi^{v_\alpha(\cdot)} u_\alpha(i), $$

then we have

$$ u_\alpha(i) - \Phi^{v_\alpha(\cdot)} u_\alpha(i) = h_\alpha(i), $$

therefore

$$ \sum_i m_i^{v_\alpha(\cdot)} h_\alpha(i) = 0. $$
