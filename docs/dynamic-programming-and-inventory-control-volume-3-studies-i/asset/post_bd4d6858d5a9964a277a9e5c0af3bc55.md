
## 14.10. POISSON DEMAND WITH LEAD TIME: USE OF INVENTORY POSITION

### 14.10.1. FORMULATION OF THE PROBLEM.

Considering the problem defined in the preceding section, we change slightly the notation, since the state of the system will not be the inventory, but a new concept, called _Inventory Position_. The impulse control will still be denoted by

\( M(t; V) = \sum_{\{n|\theta_n < t\}} v_n, \)

and this time there is no constraint on the stopping times \(\theta_n\). The inventory will be denoted by \(\bar{y}_x(t; V)\). However, \(x\) does not represent the initial inventory, but the initial inventory position.

With respect to the real inventory, the inventory position adds all the orders which have not been yet delivered. So, the evolution of the inventory position \(y_x(t; V)\) is described by

\( y_x(t; V) = x - D(t) + M(t; V), \)

where \(x\) is its initial value, which will become a part of the inventory at time \(L\). Clearly we have the relation

\(\bar{y}_x(t + L; V) = y_x(t; V) - D(t + L) + D(t).\)

This relation defines the inventory at times larger than \(L\). Before \(L\) the inventory is not influenced by decisions taken in the lead time interval. If we do not have a record of orders before 0, then the inventory before \(L\) is what it is at time 0 depleted by the demand. At any rate the corresponding cost is fixed and there is no optimization possibility.

The cost corresponding to an impulse control \(V\) is given by

\( J_x(V) = E \left[ \sum_{n=0}^\infty (K + c v_n) e^{-\alpha \theta_n} + \int_L^\infty f(\bar{y}_x(t; V)) e^{-\alpha t} dt \right] . \)

In this writing we have not included the cost on the interval \(0, L\) which is a constant. This cost can be immediately written as

\( J_x(V) = E \left[ \sum_{n=0}^\infty (K + c v_n) e^{-\alpha \theta_n} + e^{-\alpha L} \int_0^\infty f(y_x(t; V) - D(t + L) + D(t)) e^{-\alpha t} dt \right] \)

We note that \(D(t+L)-D(t)\) is independent of \(y_x(t; V)\). Therefore, we can introduce the function

\(\phi(x) = e^{-\alpha L} E f(x - D(L)),\)

and the cost is given by

\( J_x(V) = E \left[ \sum_{n=0}^\infty (K + c v_n) e^{-\alpha \theta_n} + \int_0^\infty \phi(y_x(t; V)) e^{-\alpha t} dt \right] . \)

We obtain for the inventory position the same problem as that for the inventory without lead time but with an integral cost \(\phi(x)\) instead of \(f(x)\). The corresponding function \( g(x) \) is the same as the one entering in the problem considered in the previous section, see equation (14.87).

### 14.10.2. PROBLEM FOR THE VALUE FUNCTION.

The value function

\( u(x) = \inf_V J_x(V), \)

satisfies the set of inequalities and complementarity conditions

\( u(x) + cx \le K + \inf_{\eta \ge x} (c\eta + u(\eta)); \)

\( (\alpha + \lambda)u(x) - \lambda u(x-1) \le \phi(x); \)

\( [(\alpha + \lambda)u(x) - \lambda u(x-1) - \phi(x)][u(x) + cx - K - \inf_{\eta \ge x} (c\eta + u(\eta))] = 0. \)

### 14.10.3. s, S POLICY.

As we have done in the case without delays, we look for a function \( u_s(x) \) such that

\( u_s(x) + cx = u_s(s) + cs, \forall x \le s \)

\( (\alpha + \lambda)u_s(x) - \lambda u_s(x-1) = \phi(x), \forall x \ge s \)

\( u_s(s) + cs = K + \inf_{\eta \ge s} (c\eta + u_s(\eta)). \)

The last expression is an equation for s, once the function \( u_s(x) \) is uniquely determined. To define \( u_s(x) \) for any s, we need the value of \( u_s(s) \). This number is given by

\( u_s(s) = \frac{\phi(s) + \lambda c}{\alpha}. \)

This motivates the introduction of the function \( H_s(x) \) solution of

\( H_s(x) = 0, \forall x \le s \)

\( (\alpha + \lambda)H_s(x) - \lambda H_s(x-1) = \lambda g(x) - g(x), \forall x \ge s \)

\( 0 = K + \inf_{\eta \ge s} H_s(\eta), \)

and the function \( g(x) \) is defined by

\( g(x) = \phi(x) + \rho cx, \)

which is the function already introduced in the last section (14.8.7). We have the relation

\( H_s(x) = u_s(x) + cx - cs - \frac{\lambda c + \phi(s)}{\alpha}. \)

We recall the formula for \( H_s(x) \).

(14.10.1)
\( H_s(x) = \sum_{j=0}^{\lfloor x-s \rfloor} \frac{(g(x-j) - g(s))\lambda^j}{(\alpha + \lambda)^{j+1}}, \forall x \ge s; H_s(x) = 0, \forall x \le s. \)

The theory developed in section 14.6 applies, with a minimum of \( g(x) \) which is \( \hat{n} \) which is a positive integer instead of 0.

Consider first \( S(s) \) which minimizes \( H_s(\eta), \eta \ge s \). We have

\( S(s) = s, \text{ if } s > \hat{n}. \)

Consider next the case \( s < \hat{n} \). As in section 14.6 we prove that \( H_s(x) \) reaches its minimum on \( (s, \infty) \). Picking the smallest minimum \( S(s) \) we define the function \( S(s) \) for \( s < \hat{n} \). Necessarily

\( S(s) \ge \hat{n}. \)

There remains to find s. It must satisfy the equation in s

\[ \min_{n \ge s} H_n(s) = -K. \]

Again the theory of section 14.6 proves the existence and uniqueness of the solution s. We next can state the equivalent of Theorem 14.2

Theorem 14.4. We assume \( c\alpha - p e^{-\alpha L} < 0 \). Then, the s, S policy is optimal.

## 14.11. ERGODIC THEORY FOR LEAD TIME WITH INVENTORY POSITION

### 14.11.1. FORMULATION OF THE PROBLEM.

We consider now \(\alpha = 0\). The problem reduces to the following. First

\[ g(x) = E f(x - D(L)), \]

and \(\phi(x) = g(x)\).

The function \(H_s(x)\) satisfies

\[ H_s(x) - H_s(x-1) = \frac{g(x) - g(s)}{\lambda}, \forall x \ge s; H_s(x) = 0, \forall x \le s. \]

The pair s, S are defined by

\[ H_s(S) = \inf_{n \ge s} H_n(s) = -K. \]

We get

\[ H_s(x) = \frac{1}{\lambda} \left[ \sum_{j=0}^{\lfloor x-s \rfloor} (g(x-j) - g(s)) \right]. \]

The derivative to the right satisfies

\[ H'_s(x+0) = \frac{1}{\lambda} \sum_{j=0}^{\lfloor x-s \rfloor} g'(x-j+0). \]

The function \(H_s(x)\) being piece-wise linear the computation of \(H_s(x)\) reduces to the case x integer with the formula

\[ H_s(x) = H_s(\lfloor x \rfloor) + H'_s(\lfloor x \rfloor+0)(x-\lfloor x \rfloor). \]

So we can consider x integer. Then

\[ H_s(x) = \frac{1}{\lambda} \sum_{j=0}^{x+\lfloor -s \rfloor} (g(x-j) - g(s)) = \frac{1}{\lambda} \sum_{k=-\lfloor -s \rfloor}^{x} (g(k) - g(s)), \]

and

\[ H'_s(x+0) = \frac{1}{\lambda} \sum_{k=-\lfloor -s \rfloor}^{x} g'(k+0). \]

To obtain s, S integer we proceed as follows: we write the conditions

\[ H'_s(S+0) = \frac{1}{\lambda} \sum_{k=-\lfloor -s \rfloor}^{S} g'(k+0) \ge 0; \]

\[ H'_s(S-1+0) = \frac{1}{\lambda} \sum_{k=-\lfloor -s \rfloor}^{S-1} g'(k+0) < 0, \]

and

\[ H_s(S) = \frac{1}{\lambda} \sum_{k=-\lfloor -s \rfloor}^{S} (g(k) - g(s)) = -K. \]

Next we use the identity

\[ g(k+1) = g(-\lfloor -s \rfloor) + \sum_{j=-\lfloor -s \rfloor}^{k} g'(j+0). \]

The second relation writes

\[ -K\lambda = (g(-\lfloor -s \rfloor) - g(s))(S + \lfloor -s \rfloor + 1) + \sum_{j=-\lfloor -s \rfloor}^{S-1} g'(j+0)(S-j). \]

Using the first conditions we can write

(14.11.1)
\[ \sum_{j=-\lfloor -s \rfloor}^{S-1} g'(j+0)j < K\lambda + (g(-\lfloor -s \rfloor) - g(s))(S + \lfloor -s \rfloor + 1); \]
\[ \sum_{j=-\lfloor -s \rfloor}^{S} g'(j+0)j \ge K\lambda + (g(-\lfloor -s \rfloor) - g(s))(S + \lfloor -s \rfloor + 1). \]

To which we add

(14.11.2)
\[ \sum_{j=-\lfloor -s \rfloor}^{S-1} g'(j+0) < 0; \]
\[ \sum_{j=-\lfloor -s \rfloor}^{S} g'(j+0) \ge 0. \]

### 14.11.2. APPROXIMATION.

If we approximate \(s\) by its integer value, we get the following system

(14.11.3)
\[ \sum_{j=s}^{S-1} g'(j+0)j < K\lambda; \]
\[ \sum_{j=s}^{S} g'(j+0)j \ge K\lambda. \]

(14.11.4)
\[ \sum_{j=s}^{S-1} g'(j+0) < 0; \]
\[ \sum_{j=s}^{S} g'(j+0) \ge 0. \]

First we notice that if we neglect \(K\), we get a base stock policy

\( s = S = \bar{n}. \)

Next we approximate the conditions by the equations

\[ \sum_{j=s}^{S} g'(j+0) = 0, \]

and

\[ \sum_{j=s}^S jg'(j+0) = K\lambda. \]

We proceed with continuous approximation of these relations

(14.11.5)
\[ g(s) = g(S) \]
\[ \int_s^S xg'(x+0)dx = K\lambda \]

### 14.11.3. INTERPRETATION.

We can recover the system (14.11.5) by performing a direct reasoning on the cost function. We consider a pair s, S which we assume integers. Applying an s, S policy the evolution of the stock is described as follows. Set Q = S - s and define successively the sequence of stopping times

\[ T_{n+1} = T_n + \tau_n, T_0 = 0, \]

with

\[ \tau_n = \inf\{t > 0 | D(T_n + t) - D(T_n) \ge Q\}, \]

and set \(\tau_0 = \tau\).

The stopping times \(\tau_n\) are independent random variables and identically distributed as the random variable \(\tau\). Consider the evolution of the stock starting with S, denoted \(y_S(t)\). We have

\[ y_S(t) = S - D(t) + D(T_n), T_n \le t < T_{n+1}, \]

and we can interpret \(T_n\) as

\[ T_{n+1} = \inf\{t \ge T_n | y_S(t-0) \le s\}, \]

and

\[ y_S(T_n) = S, y_S(T_n - 0) \le s. \]

Define

\[ C_\alpha(s, Q) = E \int_0^\infty e^{-\alpha t} \phi(y_S(t)) dt. \]

We compute

\[ C_\alpha(s, Q) = \sum_{n=0}^\infty E \int_{T_n}^{T_{n+1}} e^{-\alpha t} \phi(S - D(t) + D(T_n)) dt, \]

\[ C_\alpha(s, Q) = \sum_{n=0}^\infty E e^{-\alpha T_n} \int_0^{\tau_n} e^{-\alpha t} \phi(S - D(T_n + t) + D(T_n)) dt, \]

and by independence considerations

\[ C_\alpha(s, Q) = \sum_{n=0}^\infty E(e^{-\alpha \tau})^n E \int_0^\tau e^{-\alpha t} \phi(S - D(t)) dt. \]

Finally we obtain

(14.11.6)
\[ C_\alpha(s, Q) = \frac{E \int_0^\tau e^{-\alpha t} \phi(S - D(t)) dt}{1 - E(e^{-\alpha \tau})} \]

\[ \tau_x = \inf\{t > 0 | D(t) \ge x - s\}. \]
