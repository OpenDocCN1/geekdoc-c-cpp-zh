
and we must have

$$L_{-k+1} \ge L_{-k} \ge L_{-k^*} \ge k^* + 2.$$

It follows that

$$z_n = y_n + \sum_{-k^* \le k \le n-1 \\ k+L_k \ge n+1} v_k.$$

Of course, the orders $v_{-k}$ are given. So it is sufficient to give the inventory position at time 1, namely $z_1 = z$. Consider the cost objective

$$J(V) = \sum_{j=1}^\infty \alpha^{j-1} EC(v_j) + \sum_{j=1}^\infty \alpha^{j-1} El(y_j).$$

From our assumption on the lead times, the function $n + L_n$ is strictly monotone increasing in $k$. So we can write

$$J(V) = \sum_{j=1}^\infty \alpha^{j-1} EC(v_j) + E \sum_{j=1}^\infty \alpha^{j-1} El(y_j) + \sum_{n=1}^\infty E \sum_{n+L_{n-1}-1}^{n+L_n-1} \alpha^{j-1} El(y_j)$$

Next

$$E \sum_{n+L_{n-1}-1}^{n+L_n-1} \alpha^{j-1} El(y_j) = E \alpha^{n+L_{n-1}-2} \sum_{k=0}^{L_n-L_{n-1}-1} \alpha^k l(y_{n-1+L_{n-1}+k}).$$

However

$$y_{n-1+L_{n-1}+k} = y_{n-1+L_{n-1}} - (D_{n-1+L_{n-1}} + \cdots + D_{n-2+L_{n-1}+k}), \quad 0 \le k \le L_n - L_{n-1},$$ where the sum is omitted if $k=0$. This follows from the fact that there is no order arriving at time $n-1+L_{n-1}+k, 1 \le k \le L_n - L_{n-1}$. Taking account of the value of $y_{n-1+L_{n-1}+1}$, we get

$$y_{n-1+L_{n-1}+k} = z_n - (D_n + \cdots + D_{n-2+L_{n-1}+k}), \quad 0 \le k \le L_n - L_{n-1}.$$

Therefore

$$\sum_{n=1}^\infty E \sum_{n+L_{n-1}-1}^{n+L_n-1} \alpha^{j-1} El(y_j) = \sum_{n=1}^\infty E \alpha^{n+L_{n-1}-2} \cdot L_n - L_{n-1} \sum_{k=0}^{L_n-L_{n-1}} \alpha^k l(z_n - (D_n + \cdots + D_{n+L_{n-1}+k-2})).$$

Define the function

(13.2.41) $$\lambda(i, x) = El(x - (D_1 + \cdots + D_i)), \quad i \ge 0,$$ in which the sum is omitted for $i=0$. Hence, $\lambda(0, x) = l(x)$.

From the independence properties, one can write

$$\sum_{n=1}^\infty E \sum_{n+L_{n-1}-1}^{n+L_n-1} \alpha^{j-1} El(y_j) = \sum_{n=1}^\infty \alpha^{n-1} E \alpha^{L_{n-1}-1} \sum_{k=0}^{L_{n-1}-1} \alpha^k \lambda(L_{n-1}-1+k; z_n)$$

Define next

(13.2.42) $$\bar{I}_n(x) = E \alpha^{L_{n-1}-1} \sum_{k=0}^{\epsilon_{n-1}} \alpha^k \lambda(L_{n-1} + 1 + k, x).$$

From the independence of the demands and the lead times, we obtain

$$\sum_{n=1}^{\infty} E \sum_{n+L_{n-1}-1}^{n+L_n-1} \alpha^{j-1} El(y_j) = \sum_{n=1}^{\infty} \alpha^{n-1} E \bar{I}_n(z_n).$$

Next the quantity \(E \sum_{j=1}^{L_n-1} \alpha^{j-1} El(y_j)\) is fixed, independent of the control. So we are finally led to the following optimization problem

(13.2.43) $$J_\epsilon(V) = \sum_{n=1}^{\infty} \alpha^{n-1} E C(v_n) + \sum_{n=1}^{\infty} \alpha^{n-1} E \bar{I}_n(z_n),$$

with the evolution (13.2.40). This problem is not standard, because it is non-stationary. The cost on each period \(n\) depends on \(n\). We have not treated non-stationary problems in this book, to simplify notation. However, the techniques of Dynamic Programming adapt to non-stationary problems in infinite horizon. Unlike in the finite horizon case, it does not reduce to a sequence. It remains a functional equation, since one cannot initiate the sequence.

If \(L_n = L\) (random), then \(\epsilon_n = 0\). In this case

$$\bar{I}_n(x) = \bar{I}(x) = E \alpha^{L-1} \lambda(L-1, x),$$

and if L is deterministic we recover (13.2.8).

## 13.3. MODELS WITHOUT INVENTORY POSITION

### 13.3.1. CONSTRAINT ON THE ORDERING.

We consider the model of section 13.2.1, in which the lead time \(L\) is deterministic. However, we will introduce a constraint in the ordering process. One cannot order when there is a pending order. Therefore, the number of pending orders is at most one. An ordering policy \(V\) is composed of a sequence of ordering times

$$\tau_1, \cdots, \tau_j, \cdots,$$

which are \(\mathcal{F}^{n-1}\) stopping times. To each ordering time \(\tau_j\), one associates a quantity \(v_{\tau_j}\), which is \(\mathcal{F}^{\tau_j-1}\) measurable, which is the amount ordered. The new element is that the usual condition \(\tau_j \le \tau_{j+1}\) is replaced with the constraint

$$\tau_{j+1} \ge \tau_j + L.$$

The inventory evolves as follows

$$y_{n+1} = y_n + v_n - D_n, \quad y_1 = x,$$

with

$$v_n = 0, \quad \text{if } n \neq \tau_j, \text{ for some } j.$$

The objective function is the same as usual

$$J_\epsilon(V) = \sum_{n=1}^{\infty} \alpha^{n-1} (l(y_n) + C(v_n)),$$

and the value function is

$$u(x) = \inf_V J_\epsilon(V).$$

### 13.3.2. DYNAMIC PROGRAMMING.

It is easy to figure out the Bellman equation, considering the possibilities at the initial time. If there is no order at time 0, then the best which can be achieved is

$$l(x) + \alpha E u(x - D).$$

On the other hand if an order of size v is put at time 0, which is possible since there is no pending order, then the inventory evolves as follows

$$y_1 = x;$$
$$y_2 = x - D_1;$$
$$\dots$$
$$y_{L+1} = x - (D_1 + \dots + D_L) + v,$$

and the best which can be achieved is

$$K + c v + l(x) + E \sum_{j=2}^L \alpha^{j-1} l(-(D_1 + \dots + D_{j-1})) + \alpha^L E u(x + v - (D_1 + \dots + D_L)).$$

From these considerations we can easily derive Bellman equation

(13.3.1) $$u(x) = \min \left\{ \begin{array}{l} l(x) + \alpha E u(x - D), \\ K - c x + E \sum_{j=0}^{L-1} \alpha^j l(x - D^{(j)}) + \inf_{\eta \ge x} \{ c \eta + \alpha^L E u(\eta - D^{(L)}) \} \end{array} \right\}$$

in which we use the notation

$$D^{(j)} = D_1 + \dots + D_j \text{ if } j \ge 1, \text{ if } j = 0$$

### 13.3.3. s, S POLICY.

We first transform (13.3.1), by introducing a constant s \in R, and changing u(x) into H_s(x), using the formula

(13.3.2) $$u(x) = -c x + E \sum_{j=0}^{L-1} \alpha^j l(x - D^{(j)}) + C_s + H_s(x),$$

where C_s will be defined below. In fact, let

$$g(x) = (1 - \alpha) c x + \alpha^L E l(x - D^{(L)}),$$

then we take

$$C_s = \frac{g(s) + \alpha c \bar{D}}{1 - \alpha},$$

where \bar{D} is the expected value of D.

We then note the formula

$$E \sum_{j=0}^{L-1} \alpha^j g(x - D^{(j)}) = c x (1 - \alpha^L) - \alpha c \bar{D} \frac{1 - \alpha^L}{1 - \alpha} + \alpha^L c D L + E \sum_{j=0}^{L-1} \alpha^{j+L} l(x - D^{(j+L)})$$

We then check that H_s(x) is the solution of

(13.3.3) $$H_s(x) = \min \left\{ \begin{array}{l} g(x) - g(s) + \alpha E H_s(x - D), \\ K + \inf_{\eta \ge x} \left[ E \sum_{j=0}^{L-1} \alpha^j (g(\eta - D^{(j)}) - g(s)) + \alpha^L E H_s(\eta - D^{(L)}) \right] \end{array} \right\}.$$

On the other hand, for any s we define in a unique way the solution of

(13.3.4) $$H_s(x) = g(x) - g(s) + \alpha E H_s(x - D), \quad x \ge s$$
$$= 0, \quad x \le s$$

We have used the same notation \( H_s(x) \) between (13.3.3) and (13.3.4), because we want to find s so that the solution of (13.3.4) is also a solution of (13.3.3). Calling \( \mu(x) = g'(x) \), the solution of (13.3.4) is explicitly given by

(13.3.5) $$H_s(x) = \int_s^x \Gamma(x - \eta) f(\eta) d\eta, x > s,$$

where we recall \( \Gamma(x) \) is the solution of

(13.3.6) $$\Gamma(x) = 1 + \alpha \int_0^x \Gamma(x - \eta) f(\eta) d\eta, x > 0.$$

Let us set

$$g_s(x) = (g(x) - g(s)) \mathbb{I}_{x \ge s},$$

then the solution of (13.3.4) satisfies

(13.3.7) $$H_s(x) = g_s(x) + \alpha E H_s(x - D), \forall x.$$

From this relation we deduce, after iterating that

$$H_s(x) = E \sum_{j=0}^{L-1} \alpha^j g_s(x - D^{(j)}) + \alpha^L E H_s(x - D^{(L)}),$$

therefore also

$$E \sum_{j=0}^{L-1} \alpha^j (g(x - D^{(j)}) - g(s)) + \alpha^L E H_s(x - D^{(L)}) = H_s(x) + E \sum_{j=0}^{L-1} \alpha^j (g(x - D^{(j)}) - g(s)) \mathbb{I}_{x - D^{(j)} < s},$$

Define

(13.3.8) $$\Psi_s(x) = H_s(x) + E \sum_{j=0}^{L-1} \alpha^j (g(x - D^{(j)}) - g(s)) \mathbb{I}_{x - D^{(j)} < s},$$

then if we want \( H_s(x) \) to satisfy (13.3.3), we must have

(13.3.9) $$H_s(x) = \min \left\{ g(x) - g(s) + \alpha E H_s(x - D), K + \inf_{\eta > x} \Psi_s(\eta) \right\}.$$

This relation motivates the choice of s. We want to find s so that

(13.3.10) $$K + \inf_{\eta > s} \Psi_s(\eta) = 0.$$

If such an s exists, we define \( S = S(s) \) as the point where the infimum is attained.

(13.3.11) $$\inf_{\eta > s} \Psi_s(\eta) = \Psi_s(S(s)).$$

Note that \( \Psi_s(x) \) coincides with \( H_s(x) \), for \( x > s \), when \( L = 1 \).
