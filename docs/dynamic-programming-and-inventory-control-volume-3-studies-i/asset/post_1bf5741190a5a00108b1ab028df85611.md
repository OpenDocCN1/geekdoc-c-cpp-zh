
Consider the equation

$$u - \Phi^{u_\alpha(\cdot)}u = h_\alpha,$$

for which by construction \(u_\alpha\) is a solution. Another solution is

$$\zeta_\alpha = \sum_{n=1}^\infty (\Phi^{u_\alpha(\cdot)})^{n-1} h_\alpha.$$

But two solutions differ only by a constant. So

$$u_\alpha(i) - \zeta_\alpha(i) = K_\alpha, \forall i.$$

It follows that

$$\min_i u_\alpha(i) - \min_i \zeta_\alpha(i) = K_\alpha,$$

hence

$$u_\alpha - \min_i u_\alpha(i) = \zeta_\alpha - \min_i \zeta_\alpha(i).$$

From the expression of \(h_\alpha\) one sees that it is bounded as \(\alpha\) becomes close to 1. Therefore, from the expression of \(\zeta_\alpha\) one checks that it is also bounded as \(\alpha\) tends to 1. Therefore, we have established that

$$u_\alpha(i) - \min_j u_\alpha(j) \le C,$$

where the constant does not depend on \(\alpha\) nor \(i\). Set

$$z_\alpha = u_\alpha - \min_j u_\alpha(j).$$

It is bounded in \(\alpha\) (note that it is positive) and satisfies

$$z_\alpha(i) + \lambda_\alpha = \inf_{v \in U} [l(i, v) + \alpha \Phi^{v(\cdot)} z_\alpha(i)],$$

with \(\lambda_\alpha = (1-\alpha) \min u_\alpha\), also bounded in \(\alpha\).

We can extract subsequences \(z_{\alpha_k}, \lambda_{\alpha_k}\) which converge in \(B\) for \(z_\alpha\), to a function \(z\) and in \(R\) for \(\lambda_\alpha\), to a number \(\lambda\). It is easy to check that the pair \(z, \lambda\) is a solution of equation (6.1.7).

Let us check uniqueness. Suppose we have two solutions \(z_1, \lambda_1, z_2, \lambda_2\). There exist feedbacks \(v_1(i), v_2(i)\) such that

$$z_1(i) + \lambda_1 = l(i, v_1(i)) + \Phi^{v_1(\cdot)} z_1(i)$$
$$z_2(i) + \lambda_2 = l(i, v_2(i)) + \Phi^{v_2(\cdot)} z_2(i).$$

Note also that

$$z_2(i) + \lambda_2 \le l(i, v_1(i)) + \Phi^{v_1(\cdot)} z_2(i).$$

Therefore also

$$z_1(i) - z_2(i) + \lambda_1 - \lambda_2 \ge \Phi^{v_1(\cdot)}(z_1 - z_2)(i).$$

Hence

$$\min_i(z_1(i) - z_2(i)) + \lambda_1 - \lambda_2 \ge \min_i(z_1(i) - z_2(i)).$$

We obtain \(\lambda_1 - \lambda_2 \ge 0\) and by symmetry the reverse is also true. Therefore \(\lambda_1 = \lambda_2\).

We then have

$$z_1(i) - z_2(i) \ge \Phi^{v_1(\cdot)}(z_1 - z_2)(i),$$

hence also

$$z_1(i) - z_2(i) \ge (\Phi^{v_1(\cdot)})^n(z_1 - z_2)(i).$$

This implies, using the limit of the right hand side

$$z_1(i) - z_2(i) \ge \sum_j m_j^{v_{i_0}}(z_1(j) - z_2(j)).$$

If $i_0$ is the index of minimum of $z_1(i) - z_2(i)$, we have necessarily

$$z_1(i_0) - z_2(i_0) = \sum_j m_j^{v_{i_0}}(z_1(j) - z_2(j)).$$

This implies also

$$m_j^{v_{i_0}}(z_1(i_0) - z_2(i_0)) = m_j^{v_{i_0}}(z_1(j) - z_2(j)), \forall j.$$

Now from the property (6.1.3) we get easily $m_j^{v_{i_0}} > \delta, \forall j$ hence

$$z_1(i_0) - z_2(i_0) = z_1(j) - z_2(j), \forall j,$$

which proves the uniqueness of $z$ up to an additive constant.

### 6.1.4. EXTENSION.

In fact, the assumption (6.1.1) is much too strong. It is sufficient to assume that

(6.1.9)

- $U \text{ compact}$
- $\varpi^{v_0}(i,j) \text{ is continuous in } v, \forall i, j.$
- $\varpi^{v_0}(i,j) > 0, \forall i, j \text{ and some } v_0$

We want to prove the following improvement to Theorem 6.1

### **Theorem 6.2.** Under the assumptions (6.1.9) and (6.1.6) there exists one and only one pair $\lambda, z$ which is the solution of (6.1.7).

Proof. To the transition matrix $\varpi^{v_0}(i,j)$ corresponds a unique invariant measure $m_i^{v_0}$. These numbers are strictly positive. We can thus consider the inverse

$$q_i^{v_0} = \frac{1}{m_i^{v_0}}.$$

We omit the index $v_0$ in the following, to simplify the notation. We shall write $\varpi(i,j), m_i, q_i$, and $\Phi$ will denote the operator $\Phi^{v_0}$.

Consider the system

(6.1.10)

$$q_{ij} - \sum_{k \neq j} \varpi(i,k)q_{kj} = 1, \forall j$$
$$q_{jj} = q_j$$

We have

### **Lemma 6.1.** The system (6.1.10) has a unique positive solution.

Proof. The system can be rewritten as follows

$$q_{ij} - \sum_k \varpi(i,k)q_{kj} = \theta_{ij},$$

with

$$\theta_{ij} = 1 - \varpi(i,j)q_j,$$

and we have

$$\sum_i m_i \theta_{ij} = 1 - \sum_i m_i \varpi(i,j)q_j = 1 - m_j q_j = 0.$$

From (6.1.5) the result follows. The solution is

$$q = \sum_{n=1}^{\infty} \alpha^{n-1} \Phi^{n-1} \theta.$$

The numbers $q_{ij}$ have a probabilistic interpretation. Indeed $q_{ij}$ represents the average time to reach $j$ (or to come back to $i$ if $j=i$) starting from state $i$. More precisely we can write

$$q_{ij} = \sum_{n=1}^{\infty} n f^{(n)}(i, j),$$

where $f^{(n)}(i, j)$ is the probability to reach $j$ from $i$ in exactly $n$ steps. We have the recurrence formulas

$$f^{(n)}(i, j) = \sum_{k \neq j} \varpi(i, k) f^{(n-1)}(k, j), n \ge 2$$
$$f^{(1)}(i, j) = \varpi(i, j).$$

The key estimate is given in the following

### **Lemma 6.2.** The solution $u_\alpha$ of equation (6.1.8) satisfies the estimate

$$(6.1.11) \quad u_\alpha(i) - u_\alpha(j) \le ||I|| q_{ij}.$$

Proof. Consider the increasing iteration

$$u_\alpha^{k+1}(i) = \inf_{v \in U} [l(i, v) + \alpha \Phi^v u_\alpha^k(i)],$$

starting with $u_\alpha^0(i) = 0$. We shall check

$$u_\alpha^k(i) - u_\alpha^0(j) \le ||I|| q_{ij}, \forall k.$$

This inequality is clearly true for $k=0$. Assume it is true for $k$, then noting that

$$u_\alpha^{k+1}(i) \le ||I|| + \alpha \sum_l \varpi(i, l) u_\alpha^k(l),$$

and since all quantities are positive

$$u_\alpha^{k+1}(i) \le ||I|| + \sum_l \varpi(i, l) u_\alpha^k(l).$$

Using the recurrence we get

$$u_\alpha^{k+1}(i) \le ||I|| + \sum_{l \neq j} \varpi(i, l) u_\alpha^k(j) + ||I|| q_{ij} + \varpi(i, j) u_\alpha^k(j)$$
$$= ||I|| + u_\alpha^k(j) + ||I|| (q_{ij} - 1)$$
$$= u_\alpha^k(j) + ||I|| q_{ij}.$$

and since the sequence is increasing the property follows.

Applying the Lemma to the index $j$ corresponding to the minimum of $u_\alpha(j)$ and majorizing we obtain also

$$u_\alpha(i) - \min_j u_\alpha(j) \le ||I|| \max_{ij} q_{ij}.$$

With this estimate the proof can be carried over in the same way as in the proof of Theorem 6.1.

### 6.1.5. PROBABILISTIC INTERPRETATION.

Our next objective is to interpret the solution of equation (6.1.7). As usual we will define a decision rule

$V = (v_1, \cdots, v_n, \cdots),$

with

$v_n = v_n(i_1 \cdots i_n),$

function of the indices values in $U$. To $V$ and $i$ corresponds a probability measure on $\Omega, \mathcal{A}$, the underlying probability space.

We define the cost functions

$J_i(V) = \lim_{N \to \infty} \frac{1}{N} \sum_{n=1}^N E^{V,i}(y_n, v_n),$

considering the $V$ for which the limit exists. Similarly, define

$\bar{J} (V) = \lim_{\alpha \to 1} (1 - \alpha) \sum_{n=1}^\infty \alpha^{n-1} E^{V,i}(y_n, v_n).$

We claim the following

### **Theorem 6.3.** If there exists a solution $z(i), \lambda$ of equation (6.1.7) and if there exists a feedback $\hat{v}(i)$ such that

$z(i) + \lambda = l(i, \hat{v}(i)) + \Phi^{\hat{v}(i)} z(i),$

then one has

$\lambda = \inf_V J_i(V) = \inf_V \bar{J}_i(V) = J_i(\hat{V}) = \bar{J}_i(\hat{V}),$

where $\hat{V}$ is the decision rule associated to the feedback $\hat{v}(.)$.

Proof. Consider any decision rule $V$. We can write from equation (6.1.7)

$\lambda + E^{V,i} z(y_n) \le E^{V,i}[l(y_n, v_n) + z(y_{n+1})], \forall n,$

and for $\hat{V}$ we have

$\lambda + E^{\hat{V},i} z(y_n) = E^{\hat{V},i}[l(y_n, v_n) + z(y_{n+1})], \forall n.$

Therefore

$\lambda N + z(x) \le \sum_{n=1}^N E^{V,i} l(y_n, v_n) + E^{V,i} z(y_{N+1}).$

Hence also

$\lambda \le \liminf_{N \to \infty} \frac{1}{N} \sum_{n=1}^N E^{V,i} l(y_n, v_n), \forall V,$

finally

$\lambda \le \inf_V \liminf_{N \to \infty} \frac{1}{N} \sum_{n=1}^N E^{V,i} l(y_n, v_n) = \inf_V J_i(V).$

On the other hand we also have

$\lambda = \lim_{N \to \infty} \frac{1}{N} \sum_{n=1}^N E^{\hat{V},i} l(y_n, v_n) = J_i(\hat{V}).$

This relation implies

$$ \lambda \ge \inf_V \limsup_{N \to \infty} \frac{1}{N} \sum_{n=1}^N E^{V,i}(y_n, v_n). $$

Collecting results, we obtain

$$ \lambda = \inf_V J_i(V) = J_i(\hat{V}). $$

Similarly from the same initial relations we have also

$$ \lambda \alpha^{n-1}(1-\alpha) + \alpha^{n-1}(1-\alpha) E^{V,i} z(y_n) \\ \le \alpha^{n-1}(1-\alpha) E^{V,i} l(y_n, v_n) + \alpha^n (1-\alpha) E^{V,i} z(y_{n+1}) \\ +\alpha^{n-1}(1-\alpha)^2 E^{V,i} z(y_{n+1}) $$

Adding up we obtain

$$ \lambda + (1-\alpha)(z) \le (1-\alpha) \sum_{n=1}^\infty \alpha^{n-1} E^{V,i} l(y_n, v_n) + \sum_{n=1}^\infty \alpha^{n-1}(1-\alpha)^2 E^{V,i} z(y_{n+1}). $$

Letting \(\alpha \to 1\) and using the fact that \(z\) is bounded, we deduce

$$ \lambda \le \liminf_{\alpha \to 1} (1-\alpha) \sum_{n=1}^\infty \alpha^{n-1} E^{V,i} l(y_n, v_n) = J_i(V). $$

On the other hand one has also

$$ \lambda = \lim_{\alpha \to 1} (1-\alpha) \sum_{n=1}^\infty \alpha^{n-1} E^{V,i} l(y_n, v_n) = J_i(\hat{V}), $$

which completes the proof of the desired result.
