If $n_0 = 0$, it means that $c < \alpha p$. We claim that

```
$$u_n(x) = \sum_{j=1}^n \alpha^{j-1} (\Phi^{(j-1)} l_0(x), \forall 1 \le n \le n_0 + 1.$$
```

Indeed we have (we use $u_n(x)$ as the definition of the sum in this expression)

```
$$u'_n(x) = -p \frac{1-\alpha^n}{1-\alpha}, \forall x < 0$$
```

hence

```
$$c - \alpha p \frac{1-\alpha^n}{1-\alpha} > 0, \forall n \le n_0.$$
```

Therefore $cx + \alpha E u_n(x - D)$ is increasing for $0 \le n \le n_0$, and thus $u_n$ is solution of equation (5.2.17), for $0 \le n \le n_0$, which implies the claim.

For $n \ge n_0 + 2$, there exists $S_n > 0$, such that

```
$$c + \alpha E u'_n(S_n - D) = 0,$$
```

and

```
$$u_{n+1}(x) = \begin{cases} hx^+ + px^- - cx + cS_n + \alpha E u_n(S_n - D), & x < S_n \\ hx + \alpha E u_n(x - D), & x \ge S_n \end{cases}$$
```

This result is proven by induction, noting that $u_n(x)$ is convex and goes to $+\infty$ for $|x| \to +\infty$. Note that $u_n$ is $C^1$ except for $x=0$. This proves that the increasing sequence is convex and goes to $+\infty$ for $|x| \to +\infty$. It follows that $u$ is convex and goes to $+\infty$ for $|x| \to +\infty$. Rewriting Bellman equation (5.2.5) as

```
$$u(x) = hx^+ + px^- - cx + \inf_{v \ge 0} [c(x+v) + \alpha E u(x+v-D)],$$
```

we see that the optimal feedback is defined by a base stock policy.

The base stock satisfies

```
$$c + \alpha E u'(S - D) = 0,$$
```

and

```
$$E u(S - D) = \frac{c\bar{D} + h E(S-D)^+ + p E(S-D)^-}{1-\alpha}.$$
```

Moreover $S$ is the solution of

```
$$F(S) = \frac{c(1-\alpha) + \alpha b}{\alpha(p+h)}.$$
```

We deduce easily (5.2.14). Next, the solution $u$ can be written as

```
$$u(x) = \begin{cases} -cx + hx^+ + px^- + cS & \forall x \le S \\ + \frac{1}{1-\alpha} (c\bar{D} + h E(S-D)^+ + p E(S-D)^-), & \\ hx^+ + px^- + \alpha E u(x-D), & \forall x \ge S \end{cases}$$
```

We see that $u$ is $C^1$ except for $x=0$. Defining $z$ and $g$ as in the statement of the theorem, we see easily that $z$ is the solution of

```
$$z(x) = g(x) + \alpha E z(x - D),$$
```

which is solved by formula (5.2.16). The proof has been completed.
