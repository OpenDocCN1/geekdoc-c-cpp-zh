# Lemma 10.1. The minimum of \(H_s(x)\) for \(x \ge s\) is attained in points strictly larger than \(\bar{s}\). Moreover \(\min_{x \ge s} H_s(x) < 0\).

Proof. Unlike what has been done for \(H_{\alpha,s}(x)\), we cannot rely on the fact that \(H_{\alpha,s}(x) \to +\infty\) as \(x \to +\infty\). This is because \(\Gamma(x)\) is not a priori bounded like \(\Gamma_\alpha(x)\). For \(s < \bar{s}\), we can assume that \(s \le \bar{s}_\alpha\). Therefore we have

\(s \le \bar{s}_\alpha < S_\alpha(s) < S_\alpha(0).\)

Recalling that

\(\Gamma_\alpha(S_\alpha(0)) = \frac{p - \alpha(c - h)}{p - \alpha(p - h)},\)

we can assert that \(S_\alpha(0) \to S(0)\) solution of

(10.2.17) \(\Gamma(S(0)) = \frac{p - c + h}{h}.\)

Therefore we can extract a subsequence of \(S_\alpha(s)\) which converges to \(S^*_s\). Clearly \(s < \bar{s} \le S^*_s \le S(0)\).

Clearly \(H_{\alpha,s}(S_\alpha(s)) \to H_s(S^*_s)\). Since \(H_{\alpha,s}(S_\alpha(s)) \le H_{\alpha,s}(x), \forall x \ge s\), we get also \(H_s(S^*_s) \le H_s(x), \forall x \ge s\). Therefore \(H_s(S^*_s) = \inf_{x \ge s} H_s(x)\). So the infimum is attained. Since \(H_s(\bar{s}+) < 0\), the infimum is not attained in \(s\) and is strictly negative. Note that \(S^*_s\) is solution of the equation

(10.2.18) \(\Gamma(S - s)\mu(s) + (p - c + h) \int_s^{S^*} \Gamma(S - \xi) f(\xi) d\xi = 0,\)

and thus we cannot have \(S^*_s = s\), if \(s < \bar{s}\).

We then define in a unique way the smallest minimum, called \(S(s)\) and \(S(s) > \bar{s}\). Moreover \(S(s) = s, \forall s \ge \bar{s}\).

We have again

\(\frac{d}{ds} H_s(S(s)) = -\Gamma(S(s) - s)\mu(s) > 0, 0 \le s < \bar{s}.\)

The function \(H_s(S(s))\) increases from \(H_0(S(0))\) to 0 when \(s\) goes from 0 to \(\bar{s}\).

Assume

(10.2.19) \(H_0(S(0)) < -K,\)

then there exists a unique \(s\) such

(10.2.20) \(H_s(S(s)) = -K.\)
