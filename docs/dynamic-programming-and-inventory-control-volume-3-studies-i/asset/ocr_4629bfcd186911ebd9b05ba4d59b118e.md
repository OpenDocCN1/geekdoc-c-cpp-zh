and from assumption (3.5.2) we deduce

```
\(\le 1 - \delta \int_{X_0} \mathbb{1}_{\{\omega(x) - \pi(x, \xi) < 0\}} \mu(d\eta)\)
\(- \delta \int_{X_0} \mathbb{1}_{\{\omega(x) - \pi(x, \xi) \ge 0\}} \mu(d\eta)\)
\(= 1 - \delta \mu(X_0).\)
```

Therefore we have obtained

```
\(M_{n+1}(f) - m_{n+1}(f) \le (M_n(f) - m_n(f))(1 - \delta \mu(X_0)),\)
```

hence

```
\(M_n(f) - m_n(f) \le (1 - \delta \mu(X_0))^{n-1} ||f||.\)
```

We deduce that

```
\(M_n(f) \Downarrow m(f); \quad m_n(f) \Uparrow m(f).\)
```

Also we have the inequality

```
\(M_n(f) - m_n(f) \ge \Phi^n f(x) - m(f) \ge m_n(f) - M_n(f).\)
```

We have obtained

```
\(|\Phi^n f(x) - m(f)| \le M_n(f) - m_n(f) \le (1 - \delta \mu(X_0))^{n-1} ||f||.\)
```

When \(f\) has no sign, using the decomposition of \(f\) between its positive et negative part, we obtain

```
\(|\Phi^n f(x) - m(f)| \le M_n(f) - m_n(f) \le 2(1 - \delta \mu(X_0))^{n-1} ||f||,\)
```

which is the desired result (3.5.5) with \(\beta = 1 - \delta \mu(X_0)\).

It remains to prove that \(m(f)\) defines an invariant measure, and that such an invariant measure is unique. The map \(f \Rightarrow m(f)\) is linear and \(|m(f)| \le ||f||\). If \(f \ge 0\) then \(m(f) \ge 0\), and \(m(1) = 1\). So \(m(f)\) defines a probability on \(X, \mathcal{X}\). Clearly

```
\(m(f) = m(\Phi f).\)
```

Applying with \(f = \mathbb{1}_{\Gamma}\) yields

```
\(m(\Gamma) = \int_X m(dx) \pi(x, \Gamma),\)
```

which proves that \(m\) is an invariant measure. If \(\tilde{m}\) is another invariant measure, we have by definition

```
\(\tilde{m}(f) = \tilde{m}(\Phi^n f) \Rightarrow m(f),\)
```

hence \(\tilde{m} = m\). The proof has been completed.
