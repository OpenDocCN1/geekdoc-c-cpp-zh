the second equation reduces to

(3.6.6) 
\( u(\eta) = \frac{f(S-\eta)}{f(0)} + \int_\eta^S u(x)f(x-\eta)dx. \)

Then equation (3.6.6) has one and only one solution. Indeed the map

\( T : u \longrightarrow \frac{f(S-\eta)}{f(0)} + \int_\eta^S u(x)f(x-\eta)dx, \)

is a contraction on \( C([0, S]) \), since

\( \|Tu_1 - Tu_2\| \le \|u_1 - u_2\| \int_0^S f(x)dx, \)

and

\( \int_0^S f(x)dx < 1, \)

and \( B(S) \) is defined by

\( B(S) \left[ \frac{\int_0^S \overline{F}(x)u(x)dx}{F(S)} + \int_0^S u(x)dx \right] = 1. \)

The proof has been completed. In the case of a Poisson distribution \( f(x) = \lambda \exp -\lambda x \), one finds that \( u(\eta) = 1 \) and

\( B(\eta) = \frac{\lambda}{1 + \lambda S} : A = \frac{1}{1 + \lambda S}. \)

# 3.6.2. INVENTORY WITH BACKLOG.

The model is

\( y_{n+1} = y_n + v_n - D_n. \)

So negative inventories are permitted. The orders follow an \( s, S \) policy, with \( s < S, S > 0 \). Namely

\( v_n = 0, \text{ if } y_n > s, \)
\( v_n = S - y_n, \text{ if } y_n \le s. \)

Clearly if \( y_1 \le S \) then \( y_n \le S, \forall n \).
