### 17.5.2. PROPERTIES OF \(a_{\varpi}(b)\) AND \(b_{\pi}(a)\).

We shall prove the Proposition 17.5. We assume (17.3.11). Then \(a'_{\varpi}(b) = b'_{\pi}(0) = 1\). There exist unique points \(b^*_{\varpi} > 0\) and \(a^*_{\pi} < 0\) such that \(a'_{\varpi}(b^*_{\varpi}) = b'_{\pi}(a^*_{\pi}) = 0\).

The function \(a_{\varpi}(b)\) increases on \((0, b^*_{\varpi})\) and decreases on \((b^*_{\varpi}, +\infty)\). The function \(b_{\pi}(a)\) decreases on \((-\infty, a^*_{\pi})\) and increases on \((a^*_{\pi}, 0)\). Moreover,

(17.5.19) \(a_{\varpi}(b) < a_0(b), \forall b > 0, b_{\pi}(a) > b_0(a), \forall a < 0.\)

PROOF. We can compute \(a'_{\varpi}(b)\) from (17.5.8). We use also (17.5.8) to combine terms. After rearrangements we obtain

(17.5.20) \(a'_{\varpi}(b) = \frac{\beta_1 - \beta_2}{p - ac^+} \frac{(p - ac^+) \exp \beta_2(b - a_{\varpi}(b))((\varphi(\varpi) + \beta_1) - (p + h)\beta_1 \exp \beta_2 b + \beta_1(h - ac^-)}{p \beta_1 \exp \beta_1(b - a_{\varpi}(b))((\varphi(\varpi) + \beta_2) - \beta_2 \exp \beta_2(b - a_{\varpi}(b))((\varphi(\varpi) + \beta_1)}.\)

Note also that

\(1 - a'_{\varpi}(b) = \frac{p + h}{p - ac^+} \frac{\beta_1 \beta_2(\exp \beta_1 b - \exp \beta_2 b)}{\beta_1 \exp \beta_1(b - a_{\varpi}(b))((\varphi(\varpi) + \beta_2) - \beta_2 \exp \beta_2(b - a_{\varpi}(b))((\varphi(\varpi) + \beta_1)},\)

from which we get \(a'_{\varpi}(0) = 1\) and \(a'_{\varpi}(b) < 0\) for \(b\) sufficiently large.

Let us check that there is a unique point \(b\) such that \(a'_{\varpi}(b) = 0\). We call it \(b\) to simplify notation. From (17.5.20) we get

(17.5.21) \(\exp -\beta_2 a_{\varpi}(b) = \frac{\beta_1}{\varphi(\varpi) + \beta_1} \frac{p + h - (h - ac^-) \exp -\beta_2 b}{p - ac^+}.\)

But combining with (17.5.8) which is rewritten as

\((p - ac^+) \exp \beta_2(b - a_{\varpi}(b))((\varphi(\varpi) + \beta_1) - (p + h)\beta_1 \exp \beta_2 b = (p - ac^+) \exp \beta_1(b - a_{\varpi}(b))((\varphi(\varpi) + \beta_2) - (p + h)\beta_2 \exp \beta_1 b + (h - ac^-)(\beta_2 - \beta_1)),\)

we have also

(17.5.22) \(\exp -\beta_1 a_{\varpi}(b) = \frac{\beta_2}{\varphi(\varpi) + \beta_2} \frac{p + h - (h - ac^-) \exp -\beta_1 b}{p - ac^+}.\)

We can then eliminate \(a_{\varpi}(b)\) and obtain an equation for the value of \(b\). We have

\((p + h - (h - ac^-) \exp -\beta_2 b)(p + h - (h - ac^-) \exp -\beta_1 b)^{\frac{\beta_2}{\beta_1}} = \frac{\varphi(\varpi) + \beta_1}{\beta_1} \left( \frac{\varphi(\varpi) + \beta_2}{\beta_2} \right)^{-\frac{\beta_2}{\beta_1}} (p - ac^+)^{-1 + \frac{\beta_2}{\beta_1}}\)

Let us check that (17.5.23) defines a unique positive value of \(b\). First, the right hand side is a number between 0 and \((p - ac^+)^{-1} \frac{\beta_2}{\beta_1}\). This follows from the property

\(0 < \left(1 + \frac{x}{\beta_1}\right) \left(1 + \frac{x}{\beta_2}\right)^{-\frac{\beta_2}{\beta_1}} < 1, \forall 0 < x < -\beta_2.\)

On the other hand the left hand side of (17.5.23) decreases in the argument \(b\) on \([0, \infty)\) from \((p + ac^-)^{-1} \frac{\beta_2}{\beta_1}\) to \(-\infty\). Since

\((p + ac^-)^{-1} \frac{\beta_2}{\beta_1} > (p + ac^+)^{-1} \frac{\beta_2}{\beta_1},\)

the number \(b\) is uniquely defined. We call this number \(b^*_{\varpi}\). We show that this point is a positive maximum. First we know that \(a'_{\varpi}(0) = 1\). Since \(b^*_{\varpi}\) is the unique point such that \(a'_{\varpi}(b) = 0\), we necessarily have \(a'_{\varpi}(b) > 0, \forall 0 < b < b^*_{\varpi}\). Necessarily \(a''_{\varpi}(b^*_{\varpi}) \le 0\). We cannot have \(a''_{\varpi}(b^*_{\varpi}) = 0\). Indeed the point will be an inflection point and we would have \(a'_{\varpi}(b) = 0\) for \(b > b^*_{\varpi}\), close to \(b^*_{\varpi}\). Since we would have another stationary point different from \(b^*_{\varpi}\). This is not possible, from the uniqueness of the stationary point. This proves the properties of \(a_{\varpi}(b)\). The property (17.5.19) follows from the fact that \(Z^+(a_{\varpi}(b), b) < 0\), see (17.5.10) and the increasing monotonicity in \(a\) of the function. All the properties of \(a_{\varpi}(b)\) have been proven. The properties of \(b^*_{\pi}(a)\) are proven in a similar way. This concludes the proof.
