But the opposite inequality can be checked easily. The result follows.

Consider the cost functional

```
J_{x, \alpha, \eta}^s(V) = E \sum_{t=1}^{\infty} \alpha^{t-1} (C(v_t) + l^{(\sigma_t + \eta_t)}(x_t)),
```

then we shall have

```
(13.5.41) \n \rho = \inf_V \lim_{\alpha \to 1} (1 - \alpha) J_{x, \alpha, \eta}^s(V)
```

considering only control policies $V$ such that the limit exists. Then the infimum is attained at $V$ characterized by an $s(\sigma, \eta)$, $S(\sigma, \eta)$ policy with

```
s(\sigma, \eta) = \lim_{\alpha \to 1} s_\alpha(\sigma, \eta), S(\sigma, \eta) = \lim_{\alpha \to 1} S_\alpha(\sigma, \eta)
```
