PROOF. If one inserts (13.2.16) in (13.2.13), with u(z) solution of (13.2.15), then we obtain a functional relation for G, namely

$$\bar{l}(x) + G(x, x_1, \cdots, x_{L-2}) = l(x) + \alpha E G(x + x_1 - D, x_2, \cdots, x_{L-1}),$$

and by direct checking, we see that G defined by (13.2.17), satisfies the desired relation.

# 13.2.3. MULTI-ECHELON INVENTORY PROBLEM.

This problem was introduced by the seminal paper of Clark and Scarf, see [16]. We will consider $L=2$. So we have

(13.2.18)

$$y_{n+1} = y_n + y_n^1 - D_n;$$$$y_{n+1}^1 = v_n.$$

However, the order $v_n$ is not simply made on the market. It is obtained from an upper level installation, called installation 2, whereas the installation directly in contact with customers is called installation 1. Only installation 2 buys on the market. So we introduce the stock at installation 2, denoted by $\eta_n$ and its evolution is defined by

(13.2.19)

$$\eta_{n+1} = \eta_n + \bar{v}_n - v_n,$$

where $\bar{v}_n$ is bought externally. We need to impose the constraint

(13.2.20)

$$0 \le v_n \le \eta_n,$$

which expresses the fact that the quantity $v_n$ must be available at installation 2 to be ordered by installation 1. Note that the stock $\eta_n \ge 0$. It is convenient to introduce the quantity

$$\xi_n = \eta_n + y_n + y_n^1,$$

called by Clark-Scarf the system stock. It clearly satisfies the evolution equation

(13.2.21)

$$\xi_{n+1} = \xi_n + \bar{v}_n - D_n.$$

The costs per period involve $C(v_n)$, $C_1(\bar{v}_n)$ and costs $l(y_n)$, $l_1(\xi_n)$. Of course one could expect costs related to $\eta_n$ and possibly to $y_n^1$. The fact that these costs are summarized in a cost depending only of the system stock is a restriction. This assumption will be satisfied in the case when the holding costs are identical for $y_n, y_n^1, \eta_n$ and linear. This is thanks to the fact that $y_n^1, \eta_n \ge 0$. Define the control policy

$$V = \{v_1, \bar{v}_1, \cdots, v_n, \bar{v}_n, \cdots \},$$

and the control policy is adapted to the filtration $\mathcal{F}^{n-1}$. Recall the constraint (13.2.20), which can be expressed as

(13.2.22)

$$0 \le v_n \le \xi_n - y_n - y_n^1.$$

Denote by $\{x, x_1, \xi\}$ the initial state. We can define the cost objective

(13.2.23)

$$J_{x, x_1, \xi}(V) = \sum_{n=1}^\infty \alpha^{n-1} [C(v_n) + C_1(\bar{v}_n) + l(y_n) + l_1(\xi_n)],$$

and the value function

(13.2.24)

$$\Psi(x, x_1, \xi) = \inf_V J_{x, x_1, \xi}(V),$$
