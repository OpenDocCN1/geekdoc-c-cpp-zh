# 15.2.3. QUASI-VARIATIONAL INEQUALITY.

We shall assume $\exists \bar{\pi} > 0$, such that $\int_0^\infty \exp \pi \bar{\pi} \mu(d\xi) = +\infty$

(15.2.4) 
$$ \int_0^\infty \exp \pi \xi \mu(d\xi) < +\infty, \forall \pi < \bar{\pi} $$

We look for a function \(u(x)\) which is \(C^1\), a.e. twice differentiable with linear growth such that

(15.2.5) 
$$ \begin{aligned} Au(x) + \alpha u(x) &\le f(x) \\ u(x) &\le M(u(x)) \\ (Au(x) + \alpha u(x) - f(x))(u(x) - M(u(x))) &= 0 \end{aligned} $$

We call this system of relations a Q.V.I. (Quasi-Variational Inequality)

# 15.3. s, S POLICY

# 15.3.1. NOTATION.

Let us set

$$ \begin{aligned} G(x) &= u(x) + cx; \\ g(x) &= f(x) + \alpha cx, \end{aligned} $$

then the Q.V.I is slightly modified into

(15.3.1) 
$$ \begin{aligned} AG(x) + \alpha G(x) &\le g(x) + cv + c\lambda\tilde{\xi} \\ G(x) &\le K + \inf_{\eta > x} G(\eta) \end{aligned} $$

(15.3.2) 
$$ (AG(x) + \alpha G(x) - (g(x) + cv + c\lambda\tilde{\xi})) \left( G(x) - K - \inf_{\eta > x} G(\eta) \right) = 0, $$

in which \(\tilde{\xi}\) denotes the mean of a random variable with probability \(\mu\)

$$ \tilde{\xi} = \int_0^{+\infty} \xi \mu(d\xi). $$

If s is a real number we define \(G_s(x)\) by solving the following problem

(15.3.3) 
$$ \begin{aligned} AG_s(x) + \alpha G_s(x) &= g(x) + cv + c\lambda\tilde{\xi} & x > s \\ G_s(x) &= K + \inf_{\eta > s} G_s(\eta) & x \le s \end{aligned} $$

Since we want the solution to be \(C^1\) we must impose the condition

(15.3.4) 
$$ G'_s(s) = 0 $$

# 15.3.2. FUNCTION \(H_s(x)\).

It is natural to look for the derivative $$ H_s(x) = G'_s(x) $$

which is the solution of

(15.3.5) 
$$ \begin{aligned} AH_s(x) + \alpha H_s(x) &= g'(x) & x > s \\ H_s(x) &= 0 & x \le s \end{aligned} $$

Since \(g'(x)\) is bounded we look for bounded solutions

**Proposition 15.1.** We assume (15.2.4). Then, for any s there exists a unique continuous bounded function solution (15.3.5). The solution is \(C^2\) on \((s, +\infty)\).
