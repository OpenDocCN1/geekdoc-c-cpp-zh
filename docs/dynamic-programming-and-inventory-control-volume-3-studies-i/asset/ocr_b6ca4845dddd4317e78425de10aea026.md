Hence

```
m_n(f) \le m_{n+1}(f),\\
M_n(f) \ge M_{n+1}(f),\\
m_n(f) \le M_n(f).
```

We have successively

```
M_{n+1}(f) - m_{n+1}(f) = \sup_x \Phi^{n+1} f(x) - \inf_x \Phi^{n+1} f(x)\\= \sup_{x, \xi} (\Phi^{n+1} f(x) - \Phi^{n+1} f(\xi))\\= \sup_{x, \xi} [\Phi(\Phi^n f)(x) - \Phi(\Phi^n f)(\xi)]\\= \sup_{x, \xi} \left[ \int_X (\varpi(x, \eta) - \varpi(\xi, \eta)) \Phi^n f(\eta) \mu(d\eta) \right].
```

It follows

```
M_{n+1}(f) - m_{n+1}(f)\\\le \sup_{x, \xi} \left[ \int_X (\varpi(x, \eta) - \varpi(\xi, \eta))^+ \Phi^n f(\eta) \mu(d\eta) \right.\\
\left. - \int_X (\varpi(x, \eta) - \varpi(\xi, \eta))^- \Phi^n f(\eta) \mu(d\eta) \right]\\
\le \sup_{x, \xi} \left[ M_n(f) \int_X (\varpi(x, \eta) - \varpi(\xi, \eta))^+ \mu(d\eta) \right.\\
\left. - m_n(f) \int_X (\varpi(x, \eta) - \varpi(\xi, \eta))^- \mu(d\eta) \right].
```

Since

```
\int_X \varpi(x, \eta) \mu(d\eta) = \int_X \varpi(\xi, \eta) \mu(d\eta),
```

the coefficients of \(M_n(f)\) and \(m_n(f)\) are the same.

So we get

```
M_{n+1}(f) - m_{n+1}(f) \le (M_n(f) - m_n(f)) \sup_{x, \xi} \int_X (\varpi(x, \eta) - \varpi(\xi, \eta))^+ \mu(d\eta).
```
