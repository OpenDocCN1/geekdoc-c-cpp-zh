We deduce

(9.2.78) $$H(S) = \frac{c(1-\alpha)+\alpha h}{1-\alpha}(S-s) - \frac{(p-\alpha(c-h))\exp-\beta s - (c(1-\alpha)+\alpha h)}{\beta(1-\alpha)},$$

and \(s\) is defined by the equation \(H_s(S(s)) = -K\), assuming that \(H_0(S(0)) < -K\). The number \(S_0 = S(0)\) is defined by

(9.2.79) $$\exp-\beta(1-s)S_0 = \frac{c(1-\alpha)+\alpha h}{p(1-\alpha)+\alpha h},$$

and the condition amounts to

(9.2.80) $$\frac{c(1-\alpha)+\alpha h}{1-\alpha}S_0 - \frac{p-c}{\beta(1-\alpha)} < -K.$$

Let us now turn to the invariant measure. The solution of (9.2.65) is

(9.2.81) $$z(\eta) = \left\{ \begin{array}{ll} 1, & \text{if } \eta > s \\ \exp-\beta(s-\eta), & \text{if } \eta \le s \end{array} \right.$$

Then \(B(S) = \frac{\beta}{1+\beta(S-s)}\) and thus

(9.2.82) $$B(\eta) = \left\{ \begin{array}{ll} \frac{\beta}{1+\beta(S-s)}, & \text{if } \eta > s \\ \frac{\beta \exp-\beta(S-\eta)}{1+\beta(S-s)}, & \text{if } \eta \le s \end{array} \right. \qquad A = \frac{\exp-\beta s}{1+\beta(S-s)}.$$

# 9.3. INVENTORY CONTROL WITH FIXED COST AND BACKLOG

**9.3.1. BELLMAN EQUATION.** We consider the situation of section 5.2, in which we add a fixed cost. The Bellman functional equation is given by

(9.3.1) $$u(x) = \inf_{v \ge 0} [l(x,v) + \alpha E u(x+v-D)],$$

with

(9.3.2) $$l(x,v) = K \mathbb{I}_{v>0} + cv + hx^+ + px^-.$$

We write also (9.3.1) as

(9.3.3) $$u(x) = hx^+ + px^- + \inf_{v \ge 0} [K \mathbb{I}_{v>0} + cv + \alpha E u(x+v-D)].$$

We define the ceiling function by the linear equation

(9.3.4) $$w_0(x) = hx^+ + px^- + \alpha E w_0(x-D).$$

Recalling

(9.3.5) $$\Phi^\varphi(x) = E \varphi(x+v-D),$$

then

(9.3.6) $$w_0(x) = \sum_{n=1}^\infty \alpha^{n-1} (\Phi^0)^{n-1} (hx^+ + px^-)(x),$$

and the series is well defined with

(9.3.7) $$w_0(x) \le \max(h,p) \left[ \frac{|x|}{1-\alpha} + \frac{D}{(1-\alpha)^2} \right].$$
