with

Q(x) = \frac{2}{\sigma^2} \int_x^{+\infty} \exp \beta_2 (\eta - x) f'(\eta) d\eta = \frac{2}{\beta_2 \sigma^2} (p - (h + p) \exp \beta_2 x^-)

We call

x_0 = \lim_{\alpha \to 0} x_{0\alpha} \qquad \exp -\beta_2 x_0 = \frac{p}{h + p}.

For any s we have

H_{\alpha,s}(x) \to H_s(x),

uniformly on compact sets of R, with

(15.5.15) \quad H_s(x) = \int_s^x \Gamma(x - \xi) Q(\xi) d\xi.

Consider now the function

\gamma_\alpha(s) = \inf_{x \ge s} \int_s^x H_{\alpha,s}(\xi) d\xi = \int_s^{S_\alpha(s)} H_{\alpha,s}(\xi) d\xi.

We first check that

(15.5.16) \quad 0 > s > \bar{s} \Rightarrow \limsup_{\alpha \to 0} S_\alpha(s) \le B(\bar{s}),

for some bound B(\bar{s}) > 0 to be made precise below.

Without loss of generality we may assume S_\alpha(s) > 0. We have then H_{\alpha,s}(S_\alpha(s)) = 0. Therefore

- \int_s^{x_{0\alpha}} \Gamma_\alpha(S_\alpha(s) - \xi) Q_\alpha(\xi) d\xi = \int_{x_{0\alpha}}^{S_\alpha(s)} \Gamma_\alpha(S_\alpha(s) - \xi) Q_\alpha(\xi) d\xi,

hence

\int_0^{S_\alpha(s)} \Gamma_\alpha(S_\alpha(s) - \xi) Q_\alpha(\xi) d\xi \le - \int_s^{x_{0\alpha}} \Gamma_\alpha(S_\alpha(s) - \xi) Q_\alpha(\xi) d\xi,

Using

Q_\alpha(\xi) = - \frac{2}{\beta_{2\alpha} \sigma^2} (h + ac), \xi \ge 0 ; Q_\alpha(\xi) \ge \frac{2}{\beta_{2\alpha} \sigma^2} (p - ac),

we deduce

(h + ac) \int_0^{S_\alpha(s)} \Gamma_\alpha(\xi) d\xi \le (p - ac) \int_s^{x_{0\alpha}} \Gamma_\alpha(S_\alpha(s) - \xi) d\xi \le (p - ac)(x_{0\alpha} - s)

Let M > 0 and set S_\alpha^M(s) = min(M, S_\alpha(s)). We have

(h + ac) \int_0^{S_\alpha^M(s)} \Gamma_\alpha(\xi) d\xi \le (p - ac)(x_{0\alpha} - \bar{s}).

Let S^M(s) = lim sup_{\alpha \to 0} S_\alpha^M(s). By taking the limsup in the preceding inequality we obtain

h \int_0^{S^M(s)} \Gamma(\xi) d\xi \le p(x_0 - \bar{s}).
