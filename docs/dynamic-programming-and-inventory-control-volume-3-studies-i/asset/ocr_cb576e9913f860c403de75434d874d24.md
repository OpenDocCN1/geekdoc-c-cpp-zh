Therefore

```
$$
\begin{aligned}
\chi_\alpha(x, z) - \chi_\alpha(x, z') \\
= g_\alpha(x, z) - g_\alpha(S_\alpha(z), z) + \alpha E[\chi_\alpha(x - z_2, z_2) \mathbb{I}_{x > z_2} | z_1 = z] \\
- \alpha E[\chi_\alpha(S_\alpha(z) - z_2, z_2) \mathbb{I}_{S_\alpha(z) > z_2} | z_1 = z] \\
= (p + \alpha(h - c))(F(x|z) - F(S_\alpha(z)|z)) \\
+ \alpha E[\chi_\alpha(x - z_2, z_2) \mathbb{I}_{x > z_2 > S_\alpha(z)} | z_1 = z] \\
+ \alpha E[(\chi_\alpha(x - z_2, z_2) - \chi_\alpha(S_\alpha(z) - z_2, z_2)) \mathbb{I}_{S_\alpha(z) > z_2} | z_1 = z].
\end{aligned}
$$
```

It follows

```
$$
\begin{aligned}
|\chi_\alpha(x, z) - \chi_\alpha(x, z')| \\
\le \left[ p + (h - c)^+ + \frac{\max(h, p)}{1 - \delta_0(x)} + \frac{(h - c)^+ + p}{1 - \delta_0(x)} \right] f(||x - S_\alpha(z)||).
\end{aligned}
$$
```

Finally, we can state the estimate

```
(12.2.46) $$|\chi_\alpha(x, z) - \chi_\alpha(x, z')| \le \frac{C(m_0)}{1 - \delta_0(x)} \delta|z - z'|,$$
```

where \(C(m_0)\) depends only of constants and of \(m_0\). Therefore, considering the gradient of \(\chi_\alpha\) in both variables, we have obtained the estimate

```
(12.2.47) $$|D\chi_\alpha(x, z)| \le \frac{C}{1 - \delta_0(x)}.$$
```

From this estimate, we can assert that, for a subsequence (still denoted \(\alpha\))

```
(12.2.48) $$
\begin{aligned}
\sup_{x \le M \\ z \le N} |\chi_\alpha(x, z) - \chi(x, z)| \to 0, \text{ as } \alpha \to 0, \forall M, N.
\end{aligned}
$$
```

Therefore also

```
$$
\begin{aligned}
\sup_{x \le M \\ z \le M} |\alpha E[\chi_\alpha(x - z_2, z_2) \mathbb{I}_{x > z_2} - E[\chi(x - z_2, z_2) \mathbb{I}_{x > z_2} | z_1 = z]| \\
\le \sup_{x \le M \\ z \le M} |E[\chi_\alpha(x - z_2, z_2) \mathbb{I}_{x > z_2} - E[\chi(x - z_2, z_2) \mathbb{I}_{x > z_2} | z_1 = z]| \\
+ (1 - \alpha) \frac{\max(h, p)}{1 - \delta_0(M)},
\end{aligned}
$$
```

and

```
$$
\begin{aligned}
\sup_{x \le M \\ z \le M} |E[\chi_\alpha(x - z_2, z_2) \mathbb{I}_{x > z_2} - E[\chi(x - z_2, z_2) \mathbb{I}_{x > z_2} | z_1 = z]| \\
\le \sup_{x \le M \\ z \le N} |\chi_\alpha(x, z) - \chi(x, z)| + 2 \frac{\max(h, p)}{1 - \delta_0(M)} \frac{c_1}{N},
\end{aligned}
$$
```
