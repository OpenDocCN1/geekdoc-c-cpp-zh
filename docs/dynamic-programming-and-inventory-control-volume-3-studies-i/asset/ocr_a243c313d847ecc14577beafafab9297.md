# Theorem 9.2. We assume (9.1.6). The optimal feedback is characterized as follows

```
(9.1.15)
\(\hat{v}(x) = \begin{cases} 0, & \text{if } x \ge D \\ D(1+\hat{k}) - x, & \text{if } x < D \end{cases}\)
```

where \(\hat{k}\) is a positive integer which minimizes the quantity

```
(9.1.16)
\(\lambda(k) = \frac{K + c(k+1)D + \alpha h D F(k)}{1 - \alpha^{k+1}},\)
```

where

```
(9.1.17)
\(F(k) = \frac{\alpha^{k+1} - (k+1)\alpha + k}{(1 - \alpha)^2}.\)
```

PROOF. From Proposition 9.1 it follows that \(u(x)\) is piece wise linear, but not continuous. The discontinuity points are \(Dk, k = 1, 2, \cdots\) Let us write

```
\(u(0) = cD + K + \inf_{\eta \ge 0} z(\eta).\)
```

We can easily obtain formulas for \(u((kD)^+)\) and \(u((kD)^-)\), where these symbols mean the limit to the right and the limit to the left at point \(kD\). Indeed for \(k \ge 1\)

```
\(u(((j+1)D)^-) = hD(j+1) + \alpha u((jD)^-),\)
```

and we deduce easily

```
(9.1.18)
\(u(((k+1)D)^-) = hD \sum_{j=0}^k (k+1-j)\alpha^j + \alpha^k(u(0) - cD), k \ge 0.\)
```

Similarly for \(k \ge 0\)

```
\(u(((j+1)D)^+) = hD(j+1) + \alpha u((jD)^+),\)
```

and thus

```
(9.1.19)
\(u(((k+1)D)^+) = hD \sum_{j=0}^k (k+1-j)\alpha^j + \alpha^{k+1}u(0), k \ge 0.\)
```

From Lemma 9.3 we can see that

```
\(u(((k+1)D)^+) \le u(((k+1)D)^-), \forall k \ge 0\)
```

Since \(z(x)\) is also piece-wise linear, with the same discontinuity points as \(u(x)\), it follows from this inequality that

```
(9.1.20)
\(\inf_{\eta \ge 0} z(\eta) = \inf_{k \ge 0} [ckD + \alpha u((kD)^+)].\)
```

We can compute for \(k \ge 1\)

```
\(F(k) = \sum_{j=0}^{k-1} (k-j)\alpha^j\)
\(= k \frac{1-\alpha^k}{1-\alpha} - \frac{\alpha}{(1-\alpha)^2}(1 - k\alpha^{k-1} + (k-1)\alpha^k)\)
\(= \frac{\alpha^{k+1} - (k+1)\alpha + k}{(1-\alpha)^2}.\)
```
