# 6.1.5. PROBABILISTIC INTERPRETATION.

Our next objective is to interpret the solution of equation (6.1.7). As usual we will define a decision rule

$V = (v_1, \cdots, v_n, \cdots),$

with

$v_n = v_n(i_1 \cdots i_n),$

function of the indices values in $U$. To $V$ and $i$ corresponds a probability measure on $\Omega, \mathcal{A}$, the underlying probability space.

We define the cost functions

$J_i(V) = \lim_{N \to \infty} \frac{1}{N} \sum_{n=1}^N E^{V,i}(y_n, v_n),$

considering the $V$ for which the limit exists. Similarly, define

$\bar{J} (V) = \lim_{\alpha \to 1} (1 - \alpha) \sum_{n=1}^\infty \alpha^{n-1} E^{V,i}(y_n, v_n).$

We claim the following

**Theorem 6.3.** If there exists a solution $z(i), \lambda$ of equation (6.1.7) and if there exists a feedback $\hat{v}(i)$ such that

$z(i) + \lambda = l(i, \hat{v}(i)) + \Phi^{\hat{v}(i)} z(i),$

then one has

$\lambda = \inf_V J_i(V) = \inf_V \bar{J}_i(V) = J_i(\hat{V}) = \bar{J}_i(\hat{V}),$

where $\hat{V}$ is the decision rule associated to the feedback $\hat{v}(.)$.

PROOF. Consider any decision rule $V$. We can write from equation (6.1.7)

$\lambda + E^{V,i} z(y_n) \le E^{V,i}[l(y_n, v_n) + z(y_{n+1})], \forall n,$

and for $\hat{V}$ we have

$\lambda + E^{\hat{V},i} z(y_n) = E^{\hat{V},i}[l(y_n, v_n) + z(y_{n+1})], \forall n.$

Therefore

$\lambda N + z(x) \le \sum_{n=1}^N E^{V,i} l(y_n, v_n) + E^{V,i} z(y_{N+1}).$

Hence also

$\lambda \le \liminf_{N \to \infty} \frac{1}{N} \sum_{n=1}^N E^{V,i} l(y_n, v_n), \forall V,$

finally

$\lambda \le \inf_V \liminf_{N \to \infty} \frac{1}{N} \sum_{n=1}^N E^{V,i} l(y_n, v_n) = \inf_V J_i(V).$

On the other hand we also have

$\lambda = \lim_{N \to \infty} \frac{1}{N} \sum_{n=1}^N E^{\hat{V},i} l(y_n, v_n) = J_i(\hat{V}).$
