15.3 and noting by $z_c(x,t)$ the corresponding solution of the Cauchy problem, we deduce from the estimate (15.6.20) that

$$\int_s^{+\infty} m(x)(z(x,t) - z(x,t))^2 dx \le \int_s^{+\infty} m(x)(\varphi_c - \varphi)^2 dx.$$

Suppose we have proven that

$$z_c(x,t) 	o \int_s^{+\infty} m(x)\varphi_c(x) dx, \quad \text{as } t \to +\infty, \forall c > 0$$

then writing

$$\bar{\varphi} = \int_s^{+\infty} m(x)\varphi(x) dx, \quad \bar{\varphi}_c = \int_s^{+\infty} m(x)\varphi_c(x) dx$$

$$
\begin{aligned}
\int_s^{+\infty} m(x)(z(x,t) - \bar{\varphi})^2 dx \n\le 3 \left[ \int_s^{+\infty} m(x)(z_c(x,t) - z(x,t))^2 dx + \int_s^{+\infty} m(x)(z_c(x,t) - \bar{\varphi}_c)^2 dx + (\bar{\varphi}_c - \bar{\varphi})^2 \right] \n\le 3 \left[ \int_s^{+\infty} m(x)(\varphi_c - \varphi)^2(x) dx + \int_s^{+\infty} m(x)(z_c(x,t) - \bar{\varphi}_c)^2 dx + (\bar{\varphi}_c - \bar{\varphi})^2 \right]
\end{aligned}
$$

but then

$$
\limsup_{t \to +\infty} \int_s^{+\infty} m(x)(z(x,t) - \bar{\varphi})^2 dx \le 3 \left[ \int_s^{+\infty} m(x)(\varphi_c - \varphi)^2(x) dx + (\bar{\varphi}_c - \bar{\varphi})^2 \right],
$$

and letting $\epsilon \to 0$ we obtain

$$
\int_s^{+\infty} m(x)(z(x,t) - \bar{\varphi})^2 dx \to 0, \text{ as } t \to +\infty
$$

We deduce also

$$z(x,t) \to \bar{\varphi} \quad \text{a.e. } x > s$$

So we assume that $\varphi$ belongs to the domain of $A$. We can then obtain further estimates.

We define the function

$$u(x,t) = \frac{\partial z}{\partial t}(x,t),$$

which is solution of

(15.6.21) $$
\begin{aligned}
\frac{\partial u}{\partial t} + Au &= 0, \quad x > s \nu(x,t) &= u(S,t), \quad x \le s, t > 0 \nu(x,0) &= -A\varphi
\end{aligned}
$$

As for $z$ we can write

(15.6.22) $$
\int_0^{+\infty} \int_s^{+\infty} \sigma^2 m \left( \frac{\partial u}{\partial t} \right)^2 (x,t) dx dt \le \int_s^{+\infty} m(x)(A\varphi)^2(x) dx
$$

(15.6.23) $$
\begin{aligned}
\lambda \int_0^{+\infty} \int_s^{+\infty} \int_0^{+\infty} m(x)(u(x) - u(x-\xi))^2 \mu(\xi) d\xi dx dt \n\le \int_s^{+\infty} m(x)(A\varphi)^2(x) dx
\end{aligned}
$$
