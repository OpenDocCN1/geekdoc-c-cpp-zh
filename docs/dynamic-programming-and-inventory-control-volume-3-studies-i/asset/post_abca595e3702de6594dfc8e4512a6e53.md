
Define

$$\rho = \int \Psi(z) \varpi(z) dz.$$

Consider now the equation

$$\Gamma(z) + \rho = \Psi(z) + E[\Gamma(z_2)|z_1 = z], \quad \int \Gamma(z) \varpi(z) dz = 0.$$

From ergodic theory, see Chapter 3, Theorem 3.3 we can assert that

$$\sup_z |\Gamma(z)| \le \sup_z |\Psi(z) - \rho| \frac{3-\beta}{1-\beta},$$

where \(0 < \beta < 1\), depends only on the Markov chain. Similarly, if we set

$$\rho_\alpha = \int \Psi_\alpha(z) \varpi(z) dz, \quad \bar{\Gamma}_\alpha(z) = \Gamma_\alpha(z) - \frac{\rho_\alpha}{1-\alpha},$$

we can write

$$\bar{\Gamma}_\alpha(z) + \rho_\alpha = \Psi_\alpha(z) + \alpha E[\bar{\Gamma}_\alpha(z_2)|z_1 = z],$$

we can also assert that

$$\sup_z |\bar{\Gamma}_\alpha(z)| \le \sup_z |\Psi_\alpha(z) - \rho_\alpha| \frac{3-\beta}{1-\beta} \le 2 \left[ \left( \max(h, c) + \frac{\max(h, p)}{1-\delta(m_0)} \right) m_0 + pc_1 \right] \frac{3-\beta}{1-\beta}$$

Moreover

$$\bar{\Gamma}_\alpha(z) - \bar{\Gamma}_\alpha(z') = \Psi_\alpha(z) - \Psi_\alpha(z') + \alpha \int \bar{\Gamma}_\alpha(\zeta) (f(\zeta|z) - f(\zeta|z')) d\zeta.$$

Using properties (12.2.40), (12.2.43) and the assumption (12.2.29), we can check that

$$|\Psi_\alpha(z) - \Psi_\alpha(z')| \le C(m_0) \delta |z - z'|,$$

and thus also

$$|\bar{\Gamma}_\alpha(z) - \bar{\Gamma}_\alpha(z')| \le C_1(m_0) \delta |z - z'|.$$

Therefore the functions \(\bar{\Gamma}_\alpha(z)\) are uniformly Lipschitz continuous and bounded. It follows that for a subsequence we obtain

(12.2.50) $$\sup_{0 \le z \le N} \left| \Gamma_\alpha(z) - \frac{\rho_\alpha}{1-\alpha} - \Gamma(z) \right| \to 0, \forall M$$

Therefore, also

(12.2.51) $$\sup_{\substack{0 \le x \le M \\ 0 \le z \le N}} \left| u_\alpha(x, z) - \frac{\rho_\alpha}{1-\alpha} - u(x, z) \right| \to 0, \forall x, \forall M, N$$

with

(12.2.52) $$u(x, z) = (h - c)x + \int_0^x \chi(\xi, z) d\xi + \Gamma(z).$$

We deduce

(12.2.53) $$u(x, z) = (h - c)x + \Gamma(z), \forall x \le S(z).$$

From (12.2.50), (12.2.51) it is clear that

(12.2.54) $$\Gamma(z) = u(0, z).$$

However

$$E[u((S(z)-z_2)^+, z_2)|z_1 = z]$$
$$= E[u(0, z_2)|z_1 = z] + E \left[ \int_0^{(S(z)-z_2)^+} (h - c + \chi(\xi, z_2)) d\xi | z_1 = z \right],$$

hence

$$\Gamma(z) = -\rho + cS(z) + \rho G(z) + E[u((S(z)-z_2)^+, z_2)|z_1 = z],$$

and thus the first relation (12.2.32) is proven.

Consider now the situation with \(x \ge S(z)\). Define the function

$$\tilde{u}(x, z) = hx + pE[(x - z_2)^-|z_1 = z] + E[u((x - z_2)^+, z_2)|z_1 = z].$$

We obtain

$$\tilde{u}'(x, z) = h - p\bar{F}(x) + E[u'(x - z_2, z_2) 1_{x > z_2}|z_1 = z]$$
$$= h - c + \chi(x, z), \quad x \ge S(z).$$

Also

$$\tilde{u}(S(z), z) = hS(z) + pE[(S(z) - z_2)^-|z_1 = z] + \Gamma(z)$$
$$= u(S(z), z) + \rho.$$

From these two relations we get \(\tilde{u}(x, z) = u(x, z) + \rho, \forall x \ge S(z)\).

This concludes the second part of (12.2.32). Note also that

$$u_\alpha(x, z) - u_\alpha(x, z') = \Gamma_\alpha(z) - \Gamma_\alpha(z') + \int_0^x (\chi_\alpha(\xi, z) - \chi_\alpha(\xi, z')) d\xi.$$

Using already proven estimates we obtain

$$|u_\alpha(x, z) - u_\alpha(x, z')| \le \left[ C_0(m_0) + \frac{C_1(m_0)x}{1 - \delta_0(x)} \right] |z - z'|$$

The limit \(u(x, z)\) satisfies all the estimates (12.2.34), (12.2.35).

To prove (12.2.36), we first check that

$$u_\alpha(x, z) \le l(x, z, v) + \alpha E[u_\alpha(x + v - z_2)^+, z_2)|z_1 = z], \forall x, z, v$$

Therefore, it easily follows that

$$u(x, z) + \rho \le l(x, z, v) + E[u((x + v - z_2)^+, z_2)|z_1 = z], \forall x, z, v$$

However (12.2.36) can be read as

$$u(x, z) + \rho = l(x, z, \hat{v}(x, z)) + E[u((x + \hat{v}(x, z) - z_2)^+, z_2)|z_1 = z], \forall x, z$$

where

$$\hat{v}(x, z) = \begin{cases} S(z) - x, & \text{if } x \le S(z) \\ 0, & \text{if } x > S(z) \end{cases}$$

Combining we get the equation (12.2.36).

Let us prove uniqueness, for \(S(z)\) given. We first prove that \(\chi(x, z)\) is uniquely defined. To prove this it is sufficient to prove that if

$$\chi(x, z) = \begin{cases} E[\chi(x - z_2, z_2) 1_{x > z_2}|z_1 = z], & \forall x > S(z) \\ 0, & \forall x \le S(z) \end{cases}$$

and

$$(1 - \delta_0(x)) \sup_{0 \le \xi \le z} |\chi(\xi, z)| < \infty,$$

then \(\chi(x, z) = 0\). This is clear. The function \(\Psi(z)\) is thus uniquely defined. It follows that the pair \(\rho, \Gamma(z) = u(0, z)\) is also uniquely defined, with the condition \(\int \Gamma(z) \varpi(z) dz = 0\). Therefore \(u(x, z)\) is also uniquely defined. The proof of the theorem has been completed.

**Example 12.1.** Consider the situation of independent demands, then \(f(x|z) = f(x)\). In that case \(\varpi(x) = S\), and

$$\rho = (p + h - c)E(S - D)^+ - (p - c)S + p\bar{D}$$

and we recover the formula (6.2.4) of Chapter 6. We see also that \(\Psi(z) = \rho\), and thus \(\Gamma(z) = 0\).

Consider next the situation

$$f(x|z) = \lambda(z) \exp(-\lambda(z)x),$$

with the assumption \(0 < \lambda_0 \le \lambda(z) \le \lambda_1\). We also assume that \(\lambda(z)\) is Lipschitz continuous. Then all assumptions of Theorem 12.3 are satisfied.

We turn to the interpretation of the number \(\rho\). Consider the feedback \(\hat{v}(x, z)\) associated with the base stock \(S(z)\). Define the controlled process

$$\hat{y}_{n+1} = (\hat{y}_n + \hat{v}_n - z_{n+1})^+, \hat{v}_n = \hat{v}(\hat{y}_n, z_n),$$

with \(\hat{y}_1 = x, z_1 = z\). We define the policy \(\hat{V} = (\hat{v}_1, \cdots, \hat{v}_n, \cdots)\). We consider the averaged cost

$$J_{x,z}^n(\hat{V}) = \frac{\sum_{j=1}^n E[l(\hat{y}_j, z_j, \hat{v}_j)]}{n}.$$

Similarly, for any policy \(V = (v_1, \cdots, v_n \cdots)\) we define the averaged cost

$$J_{x,z}^n(V) = \frac{\sum_{j=1}^n E[l(y_j, z_j, v_j)]}{n},$$

with

$$y_{n+1} = (y_n + v_n - z_{n+1})^+, y_1 = x, z_1 = z.$$

We state the

**Proposition 12.1.** We have the property

$$\rho = \lim_{n \to \infty} J_{x,z}^n(\hat{V}). \tag{12.2.55}$$

Furthermore, consider the set of policies

$$\mathcal{U} = \{V \in \mathbb{V} | E|u(y_n, z_n)| \le C_x\},$$

then we have

$$\rho = \inf_{V \in \mathcal{U}} \lim_{n \to \infty} J_{x,z}^n(V). \tag{12.2.56}$$

**PROOF.** We first notice that

\(\hat{y}_n \le \max(x, m_0).\)

Therefore, from the estimate (12.2.33), we get

\(|u(\hat{y}_n, z_n)| \le C_0 + \frac{C_1 \max(x, m_0)}{1 - \delta_0(\max(x, m_0))}.\)

Therefore \(\hat{V}\) belongs to \(\mathcal{U}\). From (12.2.36) we can write

\(u(\hat{y}_n, z_n) + \rho = l(\hat{y}_n, z_n, v_n) + E[u(\hat{y}_{n+1}, z_{n+1})|\hat{y}_n, z_n].\)

Taking the expectation and adding up we obtain

\(\rho = J_{x,z}^n(\hat{V}) + \frac{E u(\hat{y}_{n+1}, z_{n+1}) - u(x, z)}{n},\)

and thus the property (12.2.55) follows immediately. Similarly, for any policy we can write

\(\rho \le J_{x,z}^n(V) + \frac{E u(y_{n+1}, z_{n+1}) - u(x, z)}{n}.\)

Therefore, if \(V \in \mathcal{U}\), we have \(\rho \le J_{x,z}^n(V)\). This implies (12.2.56). The proof has been completed.

**Remark 12.2.** We cannot state that the process \(\hat{y}_n, z_n\) is ergodic. We cannot indeed apply the property (3.5.5) of Theorem 3.3, Chapter 3. Consequently, we cannot give an interpretation of the function \(u(x, z)\) itself.

## 12.3. BACKLOG AND NO SET UP COST

### 12.3.1. THE MODEL.

We consider here the situation where backlog is permitted. This is the equivalent of Chapter 5, section 5.2. The Markov chain representing the demand is unchanged. The transition probability is \(f(\zeta|z)\). We recall that

(12.3.1) \(f(\zeta|z)\) is uniformly continuous in both variables and bounded

(12.3.2) \(\int_0^{+\infty} \zeta f(\zeta|z) d\zeta \le c_0 z + c_1.\)

We define the filtration

\(\mathcal{F}^n = \sigma(z_1, \cdots, z_n).\)

A control policy, denoted by \(V\), is a sequence of random variables \(v_n\) such that \(v_n\) is \(\mathcal{F}^n\) measurable. When \(z_1 = z\), then \(v_1\) is deterministic. Also, we assume as usual that \(v_n \ge 0\). We next define the inventory as the sequence,

(12.3.3) \(y_{n+1} = y_n + v_n - z_{n+1}, \quad y_1 = x.\)

The process \(y_n\) is adapted to the filtration \(\mathcal{F}^n\). The joint process \(y_n, z_n\) is also a Markov chain.

We can write, for a test function \(\varphi(x, z)\) (bounded continuous on \(R \times R^+\))

\(E[\varphi(y_2, z_2)|y_1 = x, z_1 = z, v_1 = v] = E[\varphi(x + v - z_2, z_2)|z_1 = z]\)
\(= \int_0^{\infty} \varphi(x + v - \zeta, \zeta) f(\zeta|z) d\zeta\)
