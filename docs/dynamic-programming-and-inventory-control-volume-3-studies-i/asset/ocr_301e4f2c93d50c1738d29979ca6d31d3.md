So if we start with a stock which is less or equal to \( S \), the stock remains always between \( 0 \) and \( S \). So \( X = [0, S] \). We already see that this model defines a Markov chain on \( X \) equipped with the Borel \( \sigma \)-algebra, with transition probability

(3.6.1) 
\(\pi(x, d\eta) = \begin{cases} \overline{F}(x)\delta(\eta) + \mathbb{1}_{0 \le \eta < x} f(x - \eta) d\eta, & \text{if } x > 0 \\ \overline{F}(S)\delta(\eta) + \mathbb{1}_{0 \le \eta < S} f(S - \eta) d\eta, & \text{if } x = 0 \end{cases}\)

So it is a mixture of a Dirac probability at 0 and probability density on positive inventories.

Assume \(\overline{F}(S) > 0\) then the conditions of Theorem 3.3 are satisfied. We have

\(\mu(d\eta) = \delta(\eta) + d\eta,\)

and

(3.6.2) 
\(\varpi(x, \eta) = \begin{cases} \overline{F}(x)\mathbb{1}_{\eta=0} + \mathbb{1}_{0 < \eta < x} f(x - \eta), & \text{if } x > 0 \\ \overline{F}(S)\mathbb{1}_{\eta=0} + \mathbb{1}_{0 < \eta < S} f(S - \eta), & \text{if } x = 0 \end{cases}\)

We can take \( X_0 = 0 \) and \(\delta = \overline{F}(S)\) (this \(\delta\) should not be confused with the Dirac measure \(\delta(x)\)).

We can in fact find the invariant measure directly. It is a probability measure \( m(dx) \) on \( [0, S] \), which we write as follows

(3.6.3) 
\( m(dx) = A\delta(x) + B(x)dx, \quad A + \int_0^S B(x)dx = 1. \)

To find \( A \) and \( B(x) \) we must write the relation

\(\int_0^S \phi(x)m(dx) = \int_0^S \phi(x)m(dx), \forall \phi.\)

We obtain the system

(3.6.4) 
\( A = A\overline{F}(S) + \int_0^S \overline{F}(x)B(x)dx, \\
B(\eta) = A\overline{F}(S - \eta) + \int_\eta^S B(x)f(x - \eta)d\eta. \)

then we have

(3.6.5) 
\( A = \frac{\int_0^S \overline{F}(x)B(x)dx}{F(S)}. \)

\( B(S) = f(0) \frac{\int_0^S \overline{F}(x)B(x)dx}{F(S)}. \)
