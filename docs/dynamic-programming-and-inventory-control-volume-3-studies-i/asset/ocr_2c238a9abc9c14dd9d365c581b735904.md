# 17.2.2. Q.V.I.

We write the Q.V.I arising from Dynamic Programming. We consider the operator

(17.2.4) $$Au(x) = -\frac{1}{2}\sigma^2 u''(x) - \mu u'(x).$$

The Q.V.I. is given by

(17.2.5) $$ \begin{aligned} Au(x) + \alpha u(x) \le f(x); \\ u(x) \le M(u)(x); \\ (Au(x) + \alpha u(x) - f(x))(u(x) - M(u)(x)) = 0, \end{aligned} $$

with

$$M(u)(x) = \inf_{v \neq 0} [C(v) + u(x+v)].$$

We look for a function which is $C^1$ with linear growth. Standard arguments show that the solution of the Q.V.I. is the value function.

# 17.2.3. TRANSFORMATION. Define

$$ \begin{aligned} M^+ u(x) &= \inf_{v \ge 0} (K^+ \mathbf{1}_{v>0} + c^+ v + u(x+v)); \\ M^- u(x) &= \inf_{v \le 0} (K^- \mathbf{1}_{v<0} - c^- v + u(x+v)), \end{aligned} $$

then

$$Mu(x) = \min(M^+ u(x), M^- u(x)),$$

(17.2.6) $$ \begin{aligned} Au(x) + \alpha u(x) \le f(x); \\ u(x) \le M^+ u(x); \\ u(x) \le M^- u(x); \\ (Au(x) + \alpha u(x) - f(x))(u(x) - M^+ u(x))(u(x) - M^- u(x)) = 0. \end{aligned} $$
