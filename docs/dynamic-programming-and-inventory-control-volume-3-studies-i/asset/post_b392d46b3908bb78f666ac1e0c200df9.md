
**Remark 5.1.** A Base Stock policy satisfies $\hat{v}(x) \le S$. We have seen in Theorem 5.1 that $\hat{v}(x) \le \frac{pD}{c(1-\alpha)}$. Let us check that $S \le \frac{pD}{c(1-\alpha)}$. This follows from formula (5.1.14). Indeed we have

$$D \ge SF(S) = S \frac{c(1-\alpha)+\alpha h}{p-\alpha c+\alpha h} \ge S \frac{c(1-\alpha)}{p},$$

and the result follows.

Suppose $x \le S$. If we apply a Base stock policy, then the stock will never be larger than $S$. Therefore we order at each period and we have

$y_n + v_n = S \quad n \ge 1$
$y_n = (S - D_{n-1})^+ \quad n \ge 2$

So the cost of the first period is $(h-c)x+l_0(S)$ and the cost of all the following periods is the same and is equal to $(h-c)E(S-D)^+ + l_0(S)$. Therefore the global cost is

$$u(x) = (h-c)x + l_0(S) + \frac{\alpha}{1-\alpha}[(h-c)E(S-D)^+ + l_0(S)],$$

and we recover what has been obtained by Dynamic Programming, and by differentiating in $S$, we recover the value in (5.1.14). This fast way to obtain the right base stock is not an alternative to Dynamic Programming, since it does not prove that a Base stock policy is optimal. It is just an optimization among base stock policies over the value of $S$. We can express $v_n$, for $n \ge 2$, by

$$v_n = \min(S, D_{n-1}).$$

This approach could be misleading, if we take $x = S$. One could be tempted to minimize in $S$ the quantity

$$(h-c)S + l_0(S) + \frac{\alpha}{1-\alpha}[(h-c)E(S-D)^+ + l_0(S)],$$

which would lead to a wrong value.

## 5.2. BACKLOG ALLOWED

### 5.2.1. STATING OF THE PROBLEM.

We consider the following evolution of the inventory $y_n$

$$y_{n+1} = y_n + v_n - D_n \quad y_1 = x,$$

where the demand $D_n$ is a sequence of independent random variables with probability density function $f(x)$ and CDF $F(x)$. The operator $\Phi^v$ is defined by

$$\Phi^v \phi(x) = E\phi(x+v-D) = \int_{-\infty}^{x+v} f(x+v-\eta)\phi(\eta)d\eta,$$

and the transition probability is given by

$$\pi(x, v; d\eta) = f(x+v-\eta)1_{\eta<x+v}d\eta.$$

The control policy $v_n$ is again a sequence of random variables measurable with respect to the filtration $\mathcal{F}^n = \sigma(D_1, \cdots D_{n-1})$. We introduce the cost per period

$$l(x, v) = cv + hx^+ + px^-,$$

where \(c\) is the variable cost per unit of order, \(h\) is the holding per unit cost and \(p\) is the shortage per unit cost. We next define the control pay-off

$$
(5.2.4) \qquad J_z(V) = \sum_{n=1}^{\infty} \alpha^{n-1} E l(y_n, v_n).
$$

The value function \( u(x) = \inf J_z(V) \) is solution of Bellman equation

$$
(5.2.5) \qquad u(x) = \inf_{v \ge 0} [l(x, v) + \alpha E u(x + v - D)].
$$

### 5.2.2. BELLMAN EQUATION.

Consider the ceiling function

$$
(5.2.6) \qquad w_0(x) = \sum_{n=1}^{\infty} \alpha^{n-1} (\Phi^0)^{n-1} (hx^+ + px^-)(x).
$$

It is easy to check that this series is well defined and

$$
(5.2.7) \qquad w_0(x) \le \max(h, p) \left[ \frac{|x|}{1-\alpha} + \frac{\bar{D}}{(1-\alpha)^2} \right].
$$

Assumptions (4.3.1), (4.3.2), (4.3.6) are satisfied. So results of Theorems 4.3, 4.4, 4.5 are applicable. We can then state

> **Theorem 5.4.** Under the assumptions (5.2.2), (5.2.3) the set of solutions of the functional equation (5.2.5), in the interval \( 0 \le u \le w_0 \) is not empty and has a minimum and a maximum solution \(\underline{u}\) and \(\bar{u}\). The minimum solution is l.s.c. It coincides with the value function. There exists an optimal control policy, obtained through a feedback \(\tilde{v}(x)\).

We turn now to the question of uniqueness. We can check that the properties (4.5.1), (4.5.2) are satisfied. However, only the first part of property (4.5.4) is satisfied. Therefore we cannot directly apply Theorem 4.8. Hence the situation is not similar to that of Theorem 5.1. The key issue is to obtain estimates on the feedback \(\tilde{v}(x)\). The feedback will not be bounded, in the case of high negative inventories. We can state the following important result

> **Proposition 5.1.** The optimal feedback satisfies

$$
(5.2.8) \qquad \tilde{v}(x) \le x^- + \frac{\alpha \bar{D}}{c(1-\alpha)^2} [h + (p+c)(1-\alpha)].
$$

Proof. We begin by getting an estimate from below of the value function. We shall check that

$$
(5.2.9) \qquad u(x) \ge \frac{hx^+}{1-\alpha} + px^- - \frac{h\alpha \bar{D}}{(1-\alpha)^2}.
$$

This estimate is proved by induction. We begin with

$$u(x) \ge hx^+ + px^-,$$

then, using \( u(x) \ge hx^+ \) in the right hand side of equation (5.2.5), we get

$$
\begin{aligned}
u(x) \ge {} & hx^+ + px^- + \alpha h E(x - D)^+ \\
\ge {} & hx^+ + px^- + \alpha h(x^+ - \bar{D}) \\
= {} & hx^+ (1 + \alpha) + px^- - \alpha h \bar{D}.
\end{aligned}
$$

Iterating again we get

$$u(x) \ge hx^+ (1 + \alpha + \alpha^2) + px^- - (\alpha + 2\alpha^2)h \bar{D},$$

and in general

$$u(x) \ge hx^+(1 + \alpha + \cdots + \alpha^n) + px^- - (\alpha + 2\alpha^2 + \cdots + n\alpha^n)h\bar{D},$$

and letting \(n \to \infty\) one obtains (5.2.9).

The next step is to minimize \(u(x)\) by a convenient function. We do not use \(w_0(x)\) but the function \(w(x)\) solution of

$$
(5.2.10) \qquad w(x) = (c+p)x^- + hx^+ + \alpha Ew(x^+ - D).
$$

We claim that \(u(x) \le w(x)\). Indeed (5.2.10) corresponds to the pay off when one uses the feedback \(x^-\). We claim that the following estimate holds

$$
(5.2.11) \qquad w(x) \le (c+p)x^- + \frac{hx^+}{1-\alpha} + L,
$$

for a convenient constant \(L\). This is checked by induction, but to identify the value of the constant \(L\), we postulate (5.2.10), insert it in the right hand side of (5.2.10). We obtain

$$w(x) \le (c+p)x^- + \frac{hx^+}{1-\alpha} + \alpha(p+c)\bar{D} + \alpha L,$$

which will be lower than the right hand side of (5.2.11), if

$$L \ge \frac{\alpha(p+c)\bar{D}}{1-\alpha},$$

so we can take the lower bound for \(L\).

Now, going back to the functional equation (5.2.5), we minimize the quantity within brackets on the right hand side, by using

$$u(x) \ge \frac{hx^+}{1-\alpha} - \frac{h\alpha\bar{D}}{(1-\alpha)^2}.$$

We see that it is minorized by

$$cv + \frac{hx^+}{1-\alpha} + px^- - \frac{h\alpha\bar{D}}{(1-\alpha)^2}.$$

Therefore, looking for the infimum, we can restrict the controls \(v\) to the set

$$cv + \frac{hx^+}{1-\alpha} + px^- - \frac{h\alpha\bar{D}}{(1-\alpha)^2} \le w(x).$$

Using then the estimate on \(w(x)\), we deduce that we can restrict the set of \(v\) to be bounded by the right hand side of (5.2.8). The optimal feedback must satisfy this bound, hence the result (5.2.8).

We can then prove the uniqueness of the solution of (5.2.5) in the space \(B_1\), where

$$u \in B_1 \iff \frac{|u(x)|}{1+|x|} \le C.$$

**Theorem 5.5.** Under the assumptions (5.2.2), (5.2.3), the solution of (5.2.5) in the space \(B_1\) is unique. Moreover \(u\) is continuous.

PROOF. As usual, we are going to check that the minimum and the maximum solution coincide. Define the optimal control associated with the optimal feedback. If we denote the optimal control by $\bar{V} = (\bar{v}_1, \cdots, \bar{v}_n, \cdots)$ and the optimal trajectory by $\{\bar{y}_1, \cdots, \bar{y}_n, \cdots\}$ we must prove that $\bar{V}$ belongs to $\mathcal{V}$, which means that

$$\alpha^{j-1} E[\hat{y}_j] \to 0,$$

as $j \to \infty$. However, from the estimate (3.8) and setting

$$C = \frac{c \alpha \bar{D}}{c(1-\alpha)^2} [h + (p+c)(1-\alpha)],$$

we can state that

$$\hat{y}_{n+1} \le \hat{y}_n^+ + C,$$

hence

$$\hat{y}_{n+1} \le x^+ + nC.$$

On the other hand

$$\hat{y}_{n+1} \ge x - D_1 - \cdots - D_n.$$

Therefore

$$x - n\bar{D} \le E\hat{y}_{n+1} \le x^+ + nC,$$

and the condition is satisfied, hence the result.

### 5.2.3. BASE STOCK POLICY

We want to show the following result

### THEOREM 5.6. We assume (5.2.2), (5.2.3) and

$$c(1-\alpha) < p\alpha,$$

then the function $u$ is convex and $C^1$, except for $x=0$. The optimal feedback is given by a Base stock policy, with the Base stock $S$ solution of

$$F(S) = \frac{c(1-\alpha) + \alpha h}{\alpha(p+h)}.$$

One has also

$$u(S) = hS + \frac{\alpha}{1-\alpha} [c\bar{D} + hE(S-D)^+ + pE(S-D)^-].$$

Define

$$g(x) = (c(1-\alpha) + \alpha h - \alpha(h+p)\bar{F}(x))^+,$$

then the function $z(x) = u'(x) + c - h \mathbb{I}_{x>0} + p \mathbb{I}_{x<0}$ is given by

$$z(x) = \sum_{n=1}^{\infty} \alpha^{n-1} g * f^{*(n-1)},$$

with the same notation as in equation (5.1.17).

PROOF. The convexity is proven by considering the monotone increasing sequence

$$u_{n+1}(x) = hx^+ + px^- - cx + \inf_{v \ge 0} [c(x+v) + c\alpha E u_n(x+v-D)],$$

with $u_1(x) = l_0(x) = hx^+ + px^-$. There exists a unique $n_0 \ge 0$ such that

$$\frac{\alpha p}{1-\alpha} (1 - \alpha^{n_0+1}) > c > \frac{\alpha p}{1-\alpha} (1 - \alpha^{n_0}).
