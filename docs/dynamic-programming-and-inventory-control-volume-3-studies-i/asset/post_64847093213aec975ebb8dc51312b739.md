
Consider now $x \ge 0$ with $[s] < s$. Consider $n - 1 < x < n$, then $[x] = n - 1$ and

$$H'_s(n-1+0) = \frac{h + \alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda + \alpha} \right)^n \right) - \frac{p - \alpha c}{\alpha} \left( \frac{\lambda}{\lambda + \alpha} \right)^n \left( 1 - \left( \frac{\lambda}{\lambda + \alpha} \right)^{-[s]} \right),$$

$$H'_s(n-1-0) = \frac{h + \alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda + \alpha} \right)^{n-1} \right) - \frac{p - \alpha c}{\alpha} \left( \frac{\lambda}{\lambda + \alpha} \right)^{n-1} \left( 1 - \left( \frac{\lambda}{\lambda + \alpha} \right)^{-[s]+1} \right).$$

Then for $n - 1 < x < n + [-s] + s$ we have

$[x - s] = n - 1 + [-s], \quad H'_s(x) = H'_s(n - 1 + 0),$

and for $n + [-s] + s < x < n$ we have

$[x - s] = n + [-s], \quad [x - s] - [x] = [-s] + 1$

and

$$H'_s(x) = \frac{h + \alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda + \alpha} \right)^n \right) - \frac{p - \alpha c}{\alpha} \left( \frac{\lambda}{\lambda + \alpha} \right)^n \left( 1 - \left( \frac{\lambda}{\lambda + \alpha} \right)^{-[s]+1} \right) = H'_s(n - 0).$$

We have a discontinuity at $n + [-s] + s$ given by

$$H'_s(n + [-s] + s + 0) - H'_s(n + [-s] + s - 0) = H'_s(n - 0) - H'_s(n - 1 + 0) = - \frac{p - \alpha c}{\alpha + \lambda} \left( \frac{\lambda}{\lambda + \alpha} \right)^{n - [s]}. $$

So for $x \ge 0, [s] < s H'_s(x)$ has discontinuity points at $x = n$ and $x = n + [-s] + s, n > 0$. It is piecewise constant, but not increasing. It increases at $n$ and decreases at $n + [-s] + s$. However

$$H'_s(n+1+0) - H'_s(n+0) = \frac{1}{\lambda + \alpha} \left( \frac{\lambda}{\lambda + \alpha} \right)^{n+1} \left[ h + \alpha c + (p - \alpha c) \left( 1 - \left( \frac{\lambda}{\lambda + \alpha} \right)^{-[s]} \right) \right]$$

The minimum $S(s)$ must satisfy $H'_s(S + 0) \ge 0$. Therefore $S$ is necessarily an integer. If $s$ is an integer, we deduce

$H'_s(x + 0) \ge 0, \forall x > S.$

Hence

$H_s(x) = \inf_{y > x} H_s(y), \forall x \ge S.$

Now for $s \le x \le S$ we have

$H_s(x) \le 0,$

and

$\inf_{\eta > s} H_s(\eta) = H_s(S) = -K$

If $s$ is not an integer, we can only deduce

$H'_s(n + 1 + 0) \ge H'_s(n + 0) \ge 0, \forall n > S.$

We may have some negative values of the derivative. This can occur at intervals $(n + [-s] + s, n)$. However, we know that for $x \ge s$

$H_s(x) \le K + H_s(x + \xi), \forall \xi \ge 0$

### 14.6.7. OBTAINING S.

The number S is characterized by the fact that it is the first number strictly larger than s such that

$H'_s(S-0) \le 0, H'_s(S+0) \ge 0.$

Since $H'_s(x)$ is piecewise constant it is the first integer n such that

$$H'_s(n+0) = \frac{1}{\alpha} \left[ (\alpha c + h) \left( 1 - \left( \frac{\lambda}{\alpha + \lambda} \right)^{n+1} \right) - (p - \alpha c) \left( \frac{\lambda}{\alpha + \lambda} \right)^{n+1} \left( 1 - \left( \frac{\lambda}{\alpha + \lambda} \right)^{[-s]} \right) \right] \ge 0,$$

and

$$H'_s(n-1+0) = \frac{1}{\alpha} \left[ (\alpha c + h) \left( 1 - \left( \frac{\lambda}{\alpha + \lambda} \right)^n \right) - (p - \alpha c) \left( \frac{\lambda}{\alpha + \lambda} \right)^n \left( 1 - \left( \frac{\lambda}{\alpha + \lambda} \right)^{[-s]} \right) \right] < 0.$$

## 14.7. ERGODIC CASE FOR THE POISSON DEMAND

The objective now is to let $\alpha$ tend to 0. In this case $g_s(x) = (f(x) - f(s)) \mathbb{1}_{x>s}$.

Next the function $H_s(x)$ becomes

(14.7.1) $$H_s(x) = \sum_{j=0}^{[x-s]} \frac{g_s(x-j)}{\lambda}, \forall x \ge s; H_s(x) = 0, \forall x \le s$$

The number S(s) is obtained by computing the left and right derivatives

$$H'_s(x+0) = \sum_{j=0}^{[x-s]} \frac{g'_s(x-j+0)}{\lambda}$$

$$H'_s(x-0) = \begin{cases} \sum_{j=0}^{[x-s]-0} \frac{g'_s(x-j-0)}{\lambda}, & \text{if } [x-s] < x-s \\ \sum_{j=0}^{[x-s]-1} \frac{g'_s(x-j-0)}{\lambda}, & \text{if } [x-s] = x-s \end{cases}$$

and we write

$H'_s(S+0) \ge 0; H'_s(S-0) \le 0$

### Lemma 14.1.

Assume -s to be integer and $\frac{ps}{h}$ not integer, then

$S(s) = \left[ -\frac{ps}{h} \right].$

PROOF. Note that

$[S-s] = [S] - s.$

Recalling that

$$g'_s(x+0) = \begin{cases} h, & \text{if } x \ge 0 \\ -p, & \text{if } x < 0 \end{cases}$$

and

$$g'_s(x-0) = \begin{cases} h, & \text{if } x > 0 \\ -p, & \text{if } x \le 0 \end{cases}$$

The first condition implies

$[S] + 1 \ge -\frac{ps}{h}.$

The equality is not possible, because of the assumption hence

$[S] + 1 > -\frac{ps}{h}.$

For the second condition we have to consider the case $S - s$ integer or not integer. If it is not an integer then $S$ cannot be integer, but then $H'_s(S-0) = H'_s(S+0) = 0$ which is not possible. If $S$ is integer then the second condition amounts to

$hS + ps \le 0,$

hence the result.

We can then compute $H'_s(S)$ by the formula

$$H'_s(S) = \frac{1}{\lambda} \left[ -p \frac{s^2}{2} + p \frac{s}{p} + S \left( ps + h \frac{S+1}{2} \right) \right].$$

To define the optimum $s$ we must write the equation

$$K \lambda = p \frac{s^2}{2} - p \frac{s}{p} - S \left( ps + h \frac{S+1}{2} \right).$$

If we approximate $S$ by $-p \frac{s}{h}$ we deduce easily that $s$ is defined by

(14.7.2) $$s = - \sqrt{\frac{2hK\lambda}{p(h+p)}},$$

and the quantity ordered $S - s$ is given by

(14.7.3) $$S - s = \sqrt{\frac{2K\lambda(p+h)}{ph}}.$$

We see that as $p \to \infty$ we obtain exactly the EOQ formulas.

## LITTLE'S LAW:

Since we have Backlog and waiting time, a natural question is whether Little's Law applies to this model. Waiting starts between the moment the stock is zero till the time it becomes $s < 0$. If $\tau$ denotes this random time we have

$\tau = \inf \{ t | D(t) = -s \}.$

To simplify we assume $s$ integer. Then

$D(\tau) = -s.$

Since on $0, \tau$ we have

$x(t) = -D(t),$

the average backlog is

$\frac{1}{\tau} \int_0^\tau D(t) dt,$

and the average waiting time is

$E \frac{1}{\tau} \int_0^\tau (\tau - t) dt = \frac{1}{2} E \tau.$

Little's Law is the following relation

$E \frac{1}{\tau} \int_0^\tau D(t) dt = \lambda \frac{1}{2} E \tau.$

The left hand-side can be written as

$E \int_0^1 D(\rho \tau) d\rho.$

The result follows from the following property:

### **Exercise 14.10.** Check the formula

$ED(\tau) = \lambda E \tau,$

for any stopping time with respect to the filtration $\mathcal{F}^t$ generated by the process $D(t)$.

The proof of the property goes as follows. Suppose

$\tau = \nu h,$

where $\nu$ is a random integer and $h$ is a deterministic real number. Then

$D(\nu h) = \sum_{j \ge 0} (D((j+1)h) - D(jh)) \mathbf{1}_{j < \nu h}.$

Noting that

$\mathbf{1}_{j < \nu h} \text{ is } \mathcal{F}^{jh} \text{ measurable},$

and $D((j+1)h) - D(jh)$ is independent from $\mathcal{F}^{jh}$, we deduce easily

$ED(\nu h) = \sum_{j \ge 0} h E \mathbf{1}_{j < \nu} = \lambda h E \nu.$

So the result is true for stopping times of the form $\nu h$. Now writing

$ED\left( \left[ \frac{\tau}{h} \right] h \right) \le ED(\tau) \le ED\left( \left[ \frac{\tau}{h} \right] h + h \right),$

it follows

$\lambda E\left( \left[ \frac{\tau}{h} \right] h \right) \le ED(\tau) \le \lambda E\left( \left[ \frac{\tau}{h} \right] + 1 \right) h,$

and the result follows.

## 14.8. POISSON DEMAND WITH LEAD TIME

### 14.8.1. DESCRIPTION OF THE MODEL.

We introduce a deterministic lead-time $L$ and we assume that we do not order while waiting for a delivery. This can be justified by logistics and security reasons. Therefore the model is transformed as follows:

$y_\varepsilon(t; V) = x - D(t) + M(t - L; V),$

with

$M(t; V) = \sum_{\{n | \theta_n < t\}} v_n,$

and the impulse times $\theta_n$ verify $\theta_{n+1} > \theta_n + L$.

The cost function is given by $J_s(V) = E \left[ \sum_{n=0}^\infty (K + c v_n) \exp -\alpha \theta_n + \int_0^\infty f(y(t; V)) \exp -\alpha t dt \right]$.

At time 0 we assume that there is no delivery in the pipe line.

### 14.8.2. INEQUALITIES FOR THE VALUE FUNCTION.

The value function $u(x) = \inf_V J_s(V)$, satisfies the following set of inequalities and complementarity slackness conditions (Variational Inequality)

(14.8.1)
$$u(x) \le K + E \int_0^L f(x - D(t)) \exp -\alpha t dt + \inf_{v \ge 0} [cv + Eu(x + v - D(L)) \exp -\alpha L] = M(u)(x),$$

and

(14.8.2) $-\lambda(u(x-1) - u(x)) + \alpha u(x) \le f(x).$

The complementarity slackness condition expresses

(14.8.3) $[((\alpha + \lambda)u(x) - \lambda u(x-1)) - f(x)][u(x) - M(u)(x)] = 0$

### 14.8.3. OPTIMAL s, S POLICY.

The concept of s, S policy extends easily. It is convenient to introduce the function

$g(x) = f(x) + \alpha c x + \lambda E \int_0^L (f(x - 1 - D(t)) - f(x - D(t))) \exp -\alpha t dt - \alpha E \int_0^L f(x - D(t)) \exp -\alpha t dt$

and we set

$g_s(x) = (g(x) - g(s)) \mathbb{I}_{x > s}.$

We solve as before, for a given s

(14.8.4) $(\alpha + \lambda)H_s(x) - \lambda H_s(x-1) = g_s(x), \forall x \ge s; H_s(x) = 0, \forall x \le s$

We define next the value function corresponding to s

$u_s(x) = H_s(x) - cx + E \int_0^L f(x - D(t)) \exp -\alpha t dt + C(s),$

where $C(s)$ depends only on s. We want

$(\alpha + \lambda)u_s(x) - \lambda u_s(x-1) = f(x), \forall x \ge s.$

We check easily that the constant $C(s)$ must satisfy

$\alpha C(s) = g(s) + \lambda c.$

On the other hand

$C(s) = K + \inf_{\eta \ge s} [c\eta + Eu_s(\eta - D(L)) \exp -\alpha L].$
