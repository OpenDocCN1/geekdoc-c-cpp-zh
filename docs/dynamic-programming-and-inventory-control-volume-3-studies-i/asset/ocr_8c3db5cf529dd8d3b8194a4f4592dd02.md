and also \(\sigma_t^{r++} \to 0\), a.s. But then we can pass to the limit in formula (15.6.35) and get

\(z(s + \epsilon, t) \to \Psi(S,t) + \sum_{m=2}^\infty \int_0^t \Psi(S, \xi) f_S^{(n-1)}(t - \xi) d\xi\)
\(= z(S,t)\)

the last equality is checked by comparing with (15.6.34).

# PROOF OF (15.6.26):

We begin by proving a weaker result. Let \(0 < a_0 \le \frac{M}{2}\), then we have

(15.6.37) \(\sup_{s+a_0 \le s \le M} |\varphi(x) - \varphi(x)| \to 0, \text{ as } \epsilon \to 0.\)

This result needs the continuity of \(\varphi\) (but not necessarily \(\varphi(s) = \varphi(S)\). We use

\(\varphi_\epsilon(x) = \frac{1}{\epsilon} E \int_0^{+\infty} \exp - \frac{t}{\epsilon} \varphi(y_\epsilon(t)) dt\)
\(= E \int_0^{+\infty} \exp - u \varphi(y_\epsilon(eu)) du\)

For \(T\) fixed set

\(\varphi_\epsilon^T(x) = E \int_0^T \exp - u \varphi(y_\epsilon(eu)) du,\)

and

(15.6.38) \(|\varphi_\epsilon(x) - \varphi_\epsilon^T(x)| \le ||\varphi|| \exp - T.\)

We next assert that for \(u \le T\)

\(E\varphi(y_\epsilon(eu)) = E\varphi(x - D(eu)) + E(\varphi(y_\epsilon(eu)) - \varphi(x - D(eu))) \mathbf{I}_{\tau_\epsilon^z \le T},\)

hence for \(u \le T\)

(15.6.39) \(|E\varphi(y_\epsilon(eu)) - E\varphi(x - D(eu))| \le 2||\varphi|| E \mathbf{I}_{\tau_\epsilon^z \le T}.\)

It is readily seen that

\(E \mathbf{I}_{\tau_\epsilon^z \le T} \le P \left( \nu \epsilon T + \sigma \sup_{0 \le u \le T} w(u) + N(\epsilon T) \ge a_0 \right) = \Theta_{a_0}(\epsilon T).\)

This quantity is of course equal to 1 when \(\nu \epsilon T \ge a_0\). To evaluate this quantity when \(\nu \epsilon T < a_0\) we shall recall the following probability distributions

\(P \left( \sup_{0 \le u \le T} w(u) \le y \right) = \frac{2}{\sqrt{2\pi t}} \int_0^y \exp - \frac{\xi^2}{2t} d\xi\)

(see I. Karatzas, S. Shreve [27]), and

\(P(N(\epsilon T) \le y) = 1 - \lambda \epsilon T \int_y^{+\infty} \mu(\eta) d\eta + o(\epsilon)\)

But then

\(P \left( N(\epsilon T) + \sigma \sup_{0 \le u \le T} w(u) \ge y \right) \le \lambda \epsilon T + P \left( \sigma \sup_{0 \le u \le T} w(u) \ge y \right).\)
