We need now to compute

```
\(\begin{aligned} E \sum_{l=0}^\theta \alpha^l D_{1+l} &= E \sum_{l=0}^\infty \alpha^l D_{1+l} \mathbb{I}_{\theta \ge l} \\ &= \bar{D} + E \sum_{l=1}^\infty \alpha^l D_{1+l} \mathbb{I}_{\theta \ge l} \\ &= \bar{D} + E \sum_{l=1}^\infty \alpha^l D_{1+l} \mathbb{I}_{D_1 + \dots + D_{1+l} < S-s} \\ &= \bar{D} + \bar{D} \sum_{l=1}^\infty \alpha^l F^{(l)}(S-s). \end\aligned}\)
```

Therefore

```
\((9.2.48) \quad E \sum_{l=0}^\theta \alpha^l D_{1+l} = D\Gamma(S-s).\)
```

We can now collect results to compute

```
\(\begin{aligned} (9.2.49) \quad J_\pi(V_s, s) &= (h-\alpha)x + K + cS \\ &+ \frac{1}{(1-\alpha)\Gamma(S-s)} E\alpha^\theta \Phi(D_1 + \dots + D_{1+\theta}) \\ &+ \frac{1}{(1-\alpha)\Gamma(S-s)} \left[ (K - \frac{\alpha}{\alpha}(p+(h-c)\alpha))(1-(1-\alpha)\Gamma(S-s)) \right. \\ &\left. + \frac{h\alpha(\Gamma(S-s)(S(1-\alpha)-\bar{D})}{1-\alpha} \right]. \end\aligned}\)
```

with

```
\(\Phi(x) = (p + \alpha(h-c))(S-x)^+ + \left(p + \frac{h\alpha}{1-\alpha}\right)x.\)
```

We have

```
\(\Phi'(x) = p + \frac{h\alpha}{1-\alpha} - (p + \alpha(h-c))\mathbb{I}_{S>x},\)
```

hence

```
\(\begin{aligned} \Phi(S-s) - \alpha E\Phi(S-s+D) &= (p + \alpha(h-c))(s - \alpha E(s-D)^+) \\ &+ ((1-\alpha)p + \alpha h)(S-s) - \alpha \bar{D} \left(p + \frac{h\alpha}{1-\alpha}\right), \end\aligned}\)
```

```
\(\Phi'(x) - \alpha E\Phi'(x+D) = (1-\alpha)p + h\alpha - (p + \alpha(h-c))(1-\alpha F(S-x))\mathbb{I}_{S>x}.\)
```

We can then apply formula (9.2.47) to obtain, after rearrangements

```
\(\begin{aligned} E\alpha^\theta \Phi(D_1 + \dots + D_{1+\theta}) &= \frac{1}{\alpha} S(p + \alpha(h-c)) \\ &- \frac{1}{\alpha} \Gamma(S-s) \left[ S((1-\alpha)p + h\alpha) + s\alpha(p-c) \right. \\ &\left. - \alpha(p + \alpha(h-c))E(s-D)^+ - \alpha \bar{D} \left(p + \frac{h\alpha}{1-\alpha}\right) \right] \\ &+ \int_0^{S-s} \Gamma(x) [c - p + (p + \alpha(h-c))F(S-x)] dx. \end\aligned}\)
```
