
So we may assume $s < 0$. Consider $s < x_0 < 0$. We can assert that

$$
H_s(x_0) \le \frac{g_s(x_0)}{\alpha + \lambda}.
$$

Therefore

$$
\inf_{\eta > s} H_s(\eta) \le H_s(x_0) \le \frac{g_s(x_0)}{\alpha + \lambda}.
$$

Letting $s$ go to $-\infty$, we obtain

$$
\inf_{\eta > s} H_s(\eta) \to -\infty, \text{ as } s \to -\infty.
$$

Finally we show that $\inf_{\eta > s} H_s(\eta)$ is an increasing function of $s$ on $(-\infty, 0)$. That will prove that there exists one and only one value of $s$ such that this function equals $-K$. Consider $s' < s < 0$. We are going to prove that

$$
H_{s'}(x) < H_s(x), \forall s' < s < x.
$$

This will imply the desired result. We note that

$$
g_{s'}(x) < g_s(x), \forall x.
$$

Writing

$$
H_{s'}(x) - H_s(x) = \sum_{j=0}^{[x-s]} \frac{(g_{s'}(x-j) - g_s(x-j))\lambda^j}{(\alpha + \lambda)^{j+1}} + \sum_{j=[x-s]+1}^{[x-s']} \frac{g_s(x-j)\lambda^j}{(\alpha + \lambda)^{j+1}}.
$$

The first term is negative from the property mentioned just above. In the second term we note that

$$
[x - s] + 1 \le j \le [x - s'] \Rightarrow s' \le s' + x - j < s < 0,
$$

and the second term is also negative. The property is proved, and $s$ is defined uniquely.

## 14.6.5. OPTIMALITY OF AN s, S POLICY.

We now turn to proving that the function $u_s(x)$ defined above with the choice of $s$ is indeed the optimal policy, i.e. that $u_s(x) = u(x)$.

### Theorem 14.2.

We assume $ca - p < 0$. Then, the s, S policy is optimal.

### PROOF.

We have to verify the inequalities, the complementarity slackness condition being trivially satisfied.

$$
(\alpha + \lambda)u(x) - \lambda u(x - 1) \le f(x), \forall x \le s,
$$

amounts to $g(x) - g(s) \ge 0, \forall x \le s$. Since $s < 0$, this property is satisfied. The second inequality reduces to

$$
H_s(x) \le K + \inf_{\eta > x} H_s(\eta), \forall x \ge s
$$

Since $K = -\inf_{\eta > s} H_s(\eta)$ the right hand side is certainly positive. So the inequality is obvious whenever $H_s(x) \le 0$. This occurs in particular for $s < x < \nu$. The function $H_s(x)$ can be negative beyond $\nu$ and there exists a first point $x_0$ with $\nu < x_0$ and $H_s(x_0) = 0$. So it is sufficient to prove the inequality for $x \ge x_0$. We also note that

$$
g_s(x_0) = -\lambda H_s(x_0 - 1) \ge 0.
$$

Let \(\xi \ge 0\). We shall consider \(x > x_0 - \xi\). Since \(\xi\) is arbitrary, we may have \(x < s\). We can write the equation for \(H_s(x)\) in a way which is valid for any \(x\) as follows (recalling the definition of \(g_s(x)\).

$$
(\alpha + \lambda)H_s(x) - \lambda H_s(x-1) = g_s(x).
$$

We can next write the following inequalities

$$
(\alpha + \lambda)H_s(x) - \lambda H_s(x-1) \mathbb{1}_{-1 \le x_0 - \xi} \le g_s(x), \quad H_s(x_0 - \xi) \le 0.
$$

The reason of the truncation is to be able to work on the domain \(x \ge x_0 - \xi\). The price to pay is that we can write only an inequality. Note Indeed that

$$
H_s(x-1)\mathbb{1}_{x-1 < x_0 - \xi} \le 0,
$$

from the definition of \(x_0\). Define next

$$
M_s(x) = H_s(x + \xi) + K \ge 0.
$$

We can write

$$
(\alpha + \lambda)M_s(x) - \lambda M_s(x-1) \mathbb{1}_{x-1 \ge x_0 - \xi} \le g_s(x + \xi) + \alpha K, \quad M_s(x_0 - \xi) = K.
$$

We claim that

$$
g_s(x + \xi) \ge g_s(x).
$$

Note that

$$
g_s(x + \xi) \ge g_s(x_0) > 0.
$$

The claim is thus obvious if \(x < s\). If \(x > s\) then we have to prove that \(g(s + \xi) \ge g(x)\).

If \(x > 0\) this follows from convexity. If \(s < x < 0\) then

$$
g(x + \xi) - g(x) \ge g(x_0) - g(s) > 0.
$$

Therefore setting

$$
Y_s(x) = H_s(x) - M_s(x),
$$

we deduce that \(Y_s(x) \le 0\). This result is valid for \(x > x_0 - \xi\), hence also for \(x > x_0\).

The proof of Theorem 14.2 has been completed. \(\square\)

## 14.6.6. COMPUTATION OF DERIVATIVE.

We will compute the derivatives \(H'_s(x + 0)\) and \(H'_s(x - 0)\). For \(x \ge s\) we have

$$
H'_s(x + 0) = \sum_{j=0}^{[x-s]} \frac{g'_s(x - j + 0)\lambda^j}{(\alpha + \lambda)^{j+1}}.
$$

We can compute also \(H'_s(x - 0)\) by the formula

$$
H'_s(x - 0) = \begin{cases} \sum_{j=0}^{[x-s]} \frac{g'_s(x - j - 0)\lambda^j}{(\alpha + \lambda)^{j+1}}, & \text{if } [x-s] < x - s \\ \sum_{j=0}^{[x-s]-1} \frac{g'_s(x - j - 0)\lambda^j}{(\alpha + \lambda)^{j+1}}, & \text{if } [x-s] = x - s \end{cases}
$$

with \(H'_s(s - 0) = 0\).

It follows that for \(x < 0\)

(14.6.8)
$$
H'_s(x + 0) = -\frac{p - \alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda + \alpha} \right)^{[x-s]+1} \right),
$$

(14.6.9)
$$
H'_s(x-0) = \begin{cases} H'_s(x+0), & \text{if } [x-s] < x-s \\ -\frac{p-\alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^{x-s} \right), & \text{if } [x-s] = x-s \end{cases}
$$

It follows that for \(x < 0\), \(H'_s(x)\) is discontinuous only at points \(x\) such that \(x - s\) is a negative integer. The discontinuity is

$$
H'_s(x+0) - H'_s(x-0) = -\frac{p-\alpha c}{\lambda+\alpha} \left( \frac{\lambda}{\lambda+\alpha} \right)^{x-s}.
$$

If \(s = [s]\) then the discontinuity points are negative integers \(-n\) with \(1 \le n \le -s\). We have

$$
H'_s(-n+0) = -\frac{p-\alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^{-n-s+1} \right),
$$

$$
H'_s(-n-0) = -\frac{p-\alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^{-n-s} \right),
$$

and for \(-n < x < -n + 1\)

$$
H'_s(x) = H'_s(-n+0).
$$

Therefore for \(s\) negative integer, \(x < 0\), \(H'_s(x)\) is piece wise constant negative and decreasing with discontinuity points at values \(x = -n, 0 \le n \le -s\).

Assume next that \([s] < s\), note that \([s] + 1 = -[-s]\). We consider the intervals

$$
(s, s+1), (s+1, s+2), \dots, (s+[-s], 0).
$$

An interval is of the form \((s+n-1, s+n)\) with \(n\) running from \(1\) to \([-s]+1\). For the last one the end \(s+[-s]+1\) is replaced by \(0\). We have

$$
s + n - 1 < x < s + n \Rightarrow [x-s] = n - 1,
$$

and

$$
H'_s(x) = H'_s(s+n-1+0) = -\frac{p-\alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^n \right).
$$

We obtain that for \([s] < s < 0\), \(H'_s(x)\) is piece wise constant negative and decreasing with discontinuity points at values \(s+n-1\) with \(n\) running from \(1\) to \([-s]+1\).

Consider now \(x \ge 0\), hence \([x] \ge 0\). We have \([x-s] \ge [x]\). We compute easily

(14.6.10)
$$
H'_s(x+0) = \frac{h+\alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^{[x]+1} \right) - \frac{p-\alpha c}{\alpha} \left( \frac{\lambda}{\lambda+\alpha} \right)^{[x]+1} \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^{[x]-[x]} \right).
$$

The situation is more complex for \(H'_s(x-0)\). We have 4 situations, depending on whether \(x\) and \(x-s\) are integers or not. If \([x-s] < x-s\) and \([x] < x\) then

(14.6.11)
$$
H'_s(x-0) = H'_s(x+0).
$$

If $[x-s] < x-s$ and $[x] = x$ which implies $[x-s] = x + [-s]$ then

(14.6.12)
$$
H'_s(x-0) = \frac{h+\alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^x \right) - \frac{p-\alpha c}{\alpha} \left( \frac{\lambda}{\lambda+\alpha} \right)^x \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^{[-s]+1} \right).
$$

Comparing with (14.6.10) we observe a discontinuity

(14.6.13)
$$
H'_s(x+0) - H'_s(x-0) = \frac{1}{\lambda+\alpha} \left( \frac{\lambda}{\lambda+\alpha} \right)^x (h+p).
$$

If $[x-s] = x-s$ then $[x] = x-s+[s]$. Note that in this case $x = [x]$ only if $s = [s]$. If $[s] < s$ we obtain

(14.6.14)
$$
H'_s(x-0) = \frac{h+\alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^{[x]+1} \right) - \frac{p-\alpha c}{\alpha} \left( \frac{\lambda}{\lambda+\alpha} \right)^{[x]+1} \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^{[-s]} \right).
$$

and if $[s] = s$ we obtain

(14.6.15)
$$
H'_s(x-0) = \frac{h+\alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^x \right) - \frac{p-\alpha c}{\alpha} \left( \frac{\lambda}{\lambda+\alpha} \right)^x \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^{-s} \right).
$$

We obtain again a discontinuity: When $[x-s] = x-s$ and $[s] < s$

$$
H'_s(x+0) - H'_s(x-0) = - \frac{p-\alpha c}{\lambda+\alpha} \left( \frac{\lambda}{\lambda+\alpha} \right)^{[x]-[s]}.
$$

When $[x] = x$ and $[s] = s$ we get

$$
H'_s(x+0) - H'_s(x-0) = \frac{1}{\lambda+\alpha} \left( \frac{\lambda}{\lambda+\alpha} \right)^x \left[ h+\alpha c + (p-\alpha c) \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^{-s} \right) \right].
$$

We begin with the case $s = [s]$, where $s$ is an integer. We have $[x-s] = [x]-s$. The only possible discontinuities are the positive integers. So we consider the intervals $(0, 1), \cdots (n-1, n), \cdots$ .

If $n-1 < x < n$, we have $[x-s] = n-1-s < x-s$,

therefore

$$
H'_s(x) = H'_s(n-1+0) = \frac{h+\alpha c}{\alpha} \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^n \right) - \frac{p-\alpha c}{\alpha} \left( \frac{\lambda}{\lambda+\alpha} \right)^n \left( 1 - \left( \frac{\lambda}{\lambda+\alpha} \right)^{-s} \right).
$$

So for $x \ge 0$ and $s$ a negative integer, the function $H'_s(x)$ is piecewise constant, has discontinuity points at values $x$ which are positive integers. The function $H'_s(x)$ is increasing.
