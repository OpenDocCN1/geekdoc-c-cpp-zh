# ## 13.3.2. DYNAMIC PROGRAMMING.

It is easy to figure out the Bellman equation, considering the possibilities at the initial time. If there is no order at time 0, then the best which can be achieved is

```
l(x) + \alpha E u(x - D).
```

On the other hand if an order of size v is put at time 0, which is possible since there is no pending order, then the inventory evolves as follows

```
y_1 = x;
y_2 = x - D_1;
\dots
y_{L+1} = x - (D_1 + \dots + D_L) + v,
```

and the best which can be achieved is

```
K + c v + l(x) + E \sum_{j=2}^L \alpha^{j-1} l(-(D_1 + \dots + D_{j-1})) + \alpha^L E u(x + v - (D_1 + \dots + D_L)).
```

From these considerations we can easily derive Bellman equation

```
(13.3.1) \quad u(x) = \min \left\{ \begin{array}{l} l(x) + \alpha E u(x - D), \\ K - c x + E \sum_{j=0}^{L-1} \alpha^j l(x - D^{(j)}) + \inf_{\eta \ge x} \{ c \eta + \alpha^L E u(\eta - D^{(L)}) \} \end{array} \right\}
```

in which we use the notation

```
D^{(j)} = D_1 + \dots + D_j \text{ if } j \ge 1, \text{ if } j = 0
```

# ## 13.3.3. s, S POLICY.

We first transform (13.3.1), by introducing a constant s \in R, and changing u(x) into H_s(x), using the formula

```
(13.3.2) \quad u(x) = -c x + E \sum_{j=0}^{L-1} \alpha^j l(x - D^{(j)}) + C_s + H_s(x),
```

where C_s will be defined below. In fact, let

```
g(x) = (1 - \alpha) c x + \alpha^L E l(x - D^{(L)}),
```

then we take

```
C_s = \frac{g(s) + \alpha c \bar{D}}{1 - \alpha},
```

where \bar{D} is the expected value of D.

We then note the formula

```
E \sum_{j=0}^{L-1} \alpha^j g(x - D^{(j)}) = c x (1 - \alpha^L) - \alpha c \bar{D} \frac{1 - \alpha^L}{1 - \alpha} + \alpha^L c D L + E \sum_{j=0}^{L-1} \alpha^{j+L} l(x - D^{(j+L)})
```

We then check that H_s(x) is the solution of

```
(13.3.3) \quad H_s(x) = \min \left\{ \begin{array}{l} g(x) - g(s) + \alpha E H_s(x - D), \\ K + \inf_{\eta \ge x} \left[ E \sum_{j=0}^{L-1} \alpha^j (g(\eta - D^{(j)}) - g(s)) + \alpha^L E H_s(\eta - D^{(L)}) \right] \end{array} \right\}.
```
