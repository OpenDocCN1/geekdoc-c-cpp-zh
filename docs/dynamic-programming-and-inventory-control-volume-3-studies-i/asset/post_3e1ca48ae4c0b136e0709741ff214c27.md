
Therefore

\(E\hat{y}_{n+1} \le E\hat{y}_n + \frac{p c_0^2 z}{c(1-c_0 \alpha)} + \frac{p c_1}{c(1-\alpha)(1-c_0 \alpha)},\)

and we deduce the estimate

\(E\hat{y}_{n+1} \le x + \frac{p z c_0}{c(1-c_0 \alpha)} \frac{1-c_0^n}{1-c_0} + \frac{n p c_1}{c(1-\alpha)(1-c_0 \alpha)}.\)

Using again the assumption (12.2.12), we deduce the first part of (12.2.18). This completes the proof.

## 12.2.2. BASE-STOCK POLICY.

We want now to check that the optimal feedback \(\hat{v}(x, z)\) can be obtained by a base stock policy, with a base stock depending on the value of \(z\). We have the

### Theorem 12.2.

We make the assumptions of Theorem 12.1 and \(p > c\). We assume also

(12.2.19) \(f(x, z) \ge a_0(M) > 0, \forall x, z \le M.\)

Then the function \(u(x, z)\) is convex and \(C^1\) in the argument \(x\). Moreover the optimal feedback is given by

(12.2.20) \(\hat{v}(x, z) = \begin{cases} S(z) - x, & \text{if } x \le S(z) \\ 0, & \text{if } x \ge S(z) \end{cases}\)

The function \(S(z)\) is uniformly continuous and the derivative in \(x\), \(u'(x, z)\) is uniformly continuous.

PROOF. We consider the increasing process

\(u_{n+1}(x, z) = \inf_{v \ge 0} [\langle x, z, v \rangle + \alpha \Phi^u u_n(x, z)], \quad u_0(x) = 0\)

which we write also as

\(u_{n+1}(x, z) = (h - c)x + \inf_{\eta \ge z} \{c\eta + p E[(\eta - z_2)^-] \mid z_1 = z\} + \alpha E[u_n((\eta - z_2)^+, z_2) \mid z_1 = z],\)

and we are going to show recursively that the sequence \(u_n(x, z)\) is convex and \(C^1\) in \(x\). Define

\(G_n(x, z) = cx + p E[(x - z_2)^- \mid z_1 = z] + \alpha E[u_n((x - z_2)^+, z_2) \mid z_1 = z],\)

then the function \(G_n(x, z)\) attains its minimum in \(S_n(z)\), which can be uniquely defined by taking the smallest minimum. We first consider

\(G_0(x, z) = cx + p E[(x - z_2)^- \mid z_1 = z].\)

It is convex and \(C^1\) in \(x\). We have

\(G'_0(x, z) = c - p \bar{F}(x|z),\)

with

\(\bar{F}(x|z) = \int_x^\infty f(\xi|z) d\xi.\)

The function \(G'_0(x, z)\) increases in \(x\), from \(c-p < 0\) to \(c\). Thanks to the assumption, we define in a unique way \(S_0(z)\) such that \(G'_0(S_0, z) = 0\). From convexity, we can assert that

\(u_1(x, z) = \begin{cases} (h-c)x + G_0(S_0(z), z), & \text{if } x \le S_0(z) \\ (h-c)x + G_0(x, z), & \text{if } x \ge S_0(z) \end{cases}\)

We see that \(u_1(x, z)\) is convex and \(C^1\) in \(x\). Then

\(G_1(x, z) = cx + pE[(x - z_2)^-|z_1 = z] + \alpha(h - c)E[(x - z_2)^+|z_1 = z] + \alpha E[G_0(\max(x - z_2, S_0(z_2)), z_2)|z_1 = z]\)

and we see that \(G_1(x, z)\) is convex and \(C^1\) in \(x\). By induction we check that \(u_n(x, z)\), \(G_n(x, z)\) are convex and \(C^1\) in \(x\).

Moreover

\(G'_n(x, z) = c - p\bar{F}(x|z) + \alpha E[u'_n(x - z_2, z_2)\mathbb{1}_{x \ge z_2}|z_1 = z]\)

We see that \(G'_n(0, z) = c - p\) and we can check that \(G'_n(+\infty, z) = c + h\alpha \frac{1-\alpha^n}{1-\alpha}\). Therefore there exists a point \(S_n(z)\) such that \(G'_n(S_n(z), z) = 0\). Note that \(S_n(z) > 0\), since \(G'_n(0, z) = c - p < 0\). We have

\(u_{n+1}(x, z) = \begin{cases} (h-c)x + G_n(S_n(z), z), & \text{if } x \le S_n(z) \\ (h-c)x + G_n(x, z), & \text{if } x \ge S_n(z) \end{cases}\)

It follows that the limit \(u(x, z)\) is convex in \(x\). Clearly \(u(x, z) \to +\infty\), as \(x \to +\infty\).

Also

\(G(x, z) = cx + pE[(x - z_2)^-|z_1 = z] + \alpha E[u((x - z_2)^+, z_2)|z_1 = z]\)

is convex and \(\to +\infty\) as \(x \to +\infty\). So the minimum is attained in \(S(z)\), which can be defined in a unique way, by taking the smallest minimum.

Since \(h-c \le u'_n(x, z) \le \frac{h}{1-\alpha}\), we can assert that \(u(x, z)\) is Lipschitz continuous in \(x\). The same is true for \(G(x, z)\). But

\(G'(x, z) = c - p\bar{F}(x|z) + \alpha E[u'(x - z_2, z_2)\mathbb{1}_{x \ge z_2}|z_1 = z] \to c - p \text{ as } x \to 0\)

therefore also \(S(z) > 0\). Then, from convexity

\(u(x, z) = \begin{cases} (h-c)x + G(S(z), z), & \text{if } x \le S(z) \\ (h-c)x + G(x, z), & \text{if } x \ge S(z) \end{cases}\)

Next, from

\(c - p\bar{F}(S_n(z)|z) + \alpha E[u'_n(S_n(z) - z_2, z_2)\mathbb{1}_{S_n(z) > z_2}|z_1 = z] = 0\)

we deduce, using the estimate on \(u'_n\) and the property

\(\bar{F}(S_n(z)|z) \le \frac{c_2 + c_1}{S_n(z)}\)

that

(12.2.21) \(S_n(z) \le \frac{(c_2 + c_1)(p + \alpha(h - c))}{c + \alpha(h - c)}.\)

The same estimate holds for \(S(z)\). It is easy to check that \(S_n(z) \to S(z)\), and \(S(z)\) is the smallest minimum of \(G(x, z)\) in \(x\). Furthermore, from the continuity properties of \(G(x, z)\) in both arguments, we can check that \(S(z)\) is a continuous function. The feedback \(\hat{v}(x, z)\) defined by (12.5.12) is also continuous in both arguments. Define

\(\chi(x, z) = u'(x, z) - h + c\)

as an element of \(B\) (space of measurable bounded functions on \(R^+ \times R^+\)), then \(\chi\) is the unique solution in \(B\) of the equation

(12.2.22) \(\chi(x, z) = g(x + \hat{v}(x, z), z) + \alpha E[\chi(x + \hat{v}(x, z) - z_2, z_2) \mathbf{1}_{\hat{v}(x, z) > z_2} | z_1 = z], x, z \in R^+,\)

where

\(g(x, z) = c + \alpha(h - c) - (p + \alpha(h - c))\bar{F}(x|z).\)

Since the function \(g(x + \hat{v}(x, z), z)\) is continuous in the pair \(x, z\), the solution \(\chi(x, z)\) is also continuous.

Let us check that \(S(z)\) is uniformly continuous. Let us first check that

(12.2.23) \((G'(x_1, z) - G'(x_2, z))(x_1 - x_2) \ge (p - \alpha(c - h))(F(x_1|z) - F(x_2|z))(x_1 - x_2).\)

Assume, to fix the ideas that \(x_1 > x_2\). We have

\((G'(x_1, z) - G'(x_2, z))(x_1 - x_2) = p(F(x_1|z) - F(x_2|z))(x_1 - x_2) + \alpha E[(u'(x_1 - z_2, z_2) - u'(x_2 - z_2, z_2))(x_1 - x_2) \mathbf{1}_{z_2 < x_1} | z_1 = z] + \alpha E[u'(x_1 - z_2, z_2) \mathbf{1}_{x_2 < z_2 \le x_1} (x_1 - x_2) | z_1 = z]\)

The second term is positive from the convexity of \(u\). Using the left estimate on \(u'\) for the last term, we deduce (12.2.23). We then obtain

\((S(z) - S(z'))(G'(S(z), z') - G'(S(z'), z)) \ge (p - \alpha(c - h))(S(z) - S(z')) \left[ \int_{S(z')}^{S(z)} (f(\xi|z) + f(\xi|z')) d\xi \right]\)

If \(z, z' < m\), then from (12.2.21) we can find \(M_m > m\) such that \(S(z), S(z') < M_m\). From the assumption (12.2.19), we deduce

\((S(z) - S(z'))(G'(S(z), z') - G'(S(z'), z)) \ge 2a_0(M_m)(p - \alpha(c - h))(S(z) - S(z'))^2\)

Next we have

\(G'(x, z') - G'(x, z) = \int_0^x (p + \alpha u'(x - \zeta, \zeta))(f(\zeta|z') - f(\zeta|z)) d\zeta,\)

hence

\(|G'(x, z') - G'(x, z)| \le xC \sup_{0 < \zeta < x} |f(\zeta|z') - f(\zeta|z)|.\)

Applying this estimate with \(x = S(z)\) and \(x = S(z')\) and combining estimates, we obtain easily that \(S(z)\) is uniformly continuous. It follows that the feedback \(\hat{v}(x, z)\) is uniformly continuous. Then from (12.2.22), we obtain that \(\chi(x, z)\) is uniformly continuous. The proof has been completed.

### **Remark 12.1.** We have \(\chi(x, z) = 0, \forall x \le S(z)\), and

(12.2.24) \(\chi(x, z) = g(x, z) + \alpha E[\chi(x - z_2, z_2) \mathbf{1}_{x > z_2} | z_1 = z], \forall x \ge S(z)\)

Also

(12.2.25) \(0 = g(S(z), z) + \alpha E[\chi(S(z) - z_2, z_2) \mathbf{1}_{S(z) > z_2} | z_1 = z].\)

So $S(z)$ is not the solution of $g(S(z), z) = 0$. If we consider the function

$G^*(x, z) = (p + \alpha(h - c))E[(x - z_2)^+|z_1 = z] - (p - c)x + pE[z_2|z_1 = z]$,

then the solution of $g(S, z) = 0$ is denoted by $S^*(z)$. We have \(G(x, z) \ge G^*(x, z)\).

## 12.2.3. ERGODIC THEORY.

We turn now to the case when \(\alpha \to 1\). We write \(u_\alpha(x, z)\) to satisfy

(12.2.26) 
$$u_\alpha(x, z) = \begin{cases} (h - c)x + cS_\alpha(z) + pE[(S_\alpha(z) - z_2)^-|z_1 = z] + \alpha E[u_\alpha((S_\alpha(z) - z_2)^+, z_2)|z_1 = z], & \text{if } x \le S_\alpha(z) \\ hx + pE[(x - z_2)^-|z_1 = z] + \alpha E[u_\alpha((x - z_2)^+, z_2)|z_1 = z], & \text{if } x \ge S_\alpha(z) \end{cases}$$

We shall make the assumptions

(12.2.27) 
$$c_0 = 0, \text{ and } \inf_{0 \le \zeta \le a} f(\zeta|z) \ge \gamma(a) > 0, \forall a$$

(12.2.28) 
$$f(\zeta|z) \text{ is ergodic}$$

(12.2.29) 
$$\int |f(\zeta|z) - f(\zeta|z')| d\zeta \le \delta|z - z'| \quad \sup_z F(x|z) = \delta_0(x) < 1, \forall x$$

We denote by \(\varpi(z)\) the invariant probability density corresponding to the Markov chain \(f(\zeta|z)\).

We state the

### **Theorem 12.3.** We assume (12.2.1), (12.2.2) with \(c_0 = 0\), (12.2.6) with \(p > c\) and (12.2.27), (12.2.28), (12.2.29). Then, for a subsequence (still denoted \(\alpha\)) converging to 1, we have, for any compact \(K\) of \(R^+\)

(12.2.30) 
$$\sup_{z \in K} |S_\alpha(z) - S(z)| \le \epsilon(\alpha, K), \quad \epsilon(\alpha, K) \to 0, \text{ as } \alpha \uparrow 1$$

(12.2.31) 
$$\sup_{\substack{x \le M \\ z \le N}} \left| u_\alpha(x, z) - \frac{\rho_\alpha}{1 - \alpha} - u(x, z) \right| \to 0, \forall M, N,$$

with \(\rho_\alpha \to \rho\) and

(12.2.32) 
$$u(x, z) + \rho = \begin{cases} (h - c)x + cS(z) + pE[(S(z) - z_2)^-|z_1 = z] + E[u((S(z) - z_2)^+, z_2)|z_1 = z] & \text{if } x \le S(z) \\ hx + pE[(x - z_2)^-|z_1 = z] + E[u((x - z_2)^+, z_2)|z_1 = z] & \text{if } x \ge S(z) \end{cases}$$

The function \(u(x, z)\) satisfies the growth condition

(12.2.33) 
$$\sup_{\substack{\xi \le x \\ z}} |u(\xi, z)| \le C_0 + \frac{C_1 x}{1 - \delta_0(x)}.$$
