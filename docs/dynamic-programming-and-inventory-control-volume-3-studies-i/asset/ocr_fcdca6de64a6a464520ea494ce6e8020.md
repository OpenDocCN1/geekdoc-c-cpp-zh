16.3.2. GREEN FUNCTION. Although it is possible to prove the existence of a solution of (16.3.3) by an approximation procedure, it is important to obtain an explicit formula as we have done in the standard case. For that purpose we need a Green function, solution of the differential equation in the whole space, without right hand side. We introduce the following problem

```
(16.3.7) 
-\frac{1}{2}\sigma^2\Phi''(x) + (\nu + k(x - \gamma))\Phi'(x) + (\alpha + k)\Phi(x) = 0, \forall x \in R \n\Phi(0) = 1, \quad \Phi(+\infty) = 0
```

We want to prove the

# Theorem 16.1. We assume (16.3.6). There exists one and only one solution of (16.3.7) such that

```
(16.3.8) \Phi(x) > 0, \Phi'(x) < 0, \Phi''(x) > 0.
```

As \(x \to -\infty, \Phi(x) \to +\infty, \Phi'(x) \to -\infty.\) Considering the roots \(\beta_k < 0, \beta_k^* > 0\) of 
\(-\frac{1}{2}\sigma^2\beta^2 + \nu\beta + \alpha + k = 0,\)

we have the growth condition

```
(16.3.9) 
0 > \Phi'(x) \ge \frac{k}{\sigma^2} \frac{(x - \gamma)^2}{\beta_k^* - \beta_k} \left[ \beta_k \left( \beta_k^* - \Phi(0) \exp - \frac{k\gamma^2}{\sigma^2} \right) \exp \beta_k x \right. \n\left. + \beta_k^* \left( \Phi(0) \exp - \frac{k\gamma^2}{\sigma^2} - \beta_k \right) \exp \beta_k^* x \right], x \le 0
```

PROOF. We begin by solving (16.3.7) in \([0, +\infty)\). It is a Dirichlet type boundary value problem. It has one and only one solution and

```
0 \le \Phi(x) \le 1, x \ge 0,
```

and we have the energy relation

```
(16.3.10) \frac{\sigma^2}{2} \int_0^{+\infty} \Phi'^2 dx + \left( \alpha + \frac{k}{2} \right) \int_0^{+\infty} \Phi^2 dx = -\frac{\sigma^2}{2} \Phi'(0) + \frac{1}{2} (\nu - k\gamma).
```

If we next test the equation (16.3.7) with \(\Phi'(x)\) and integrate between 2 and \(x > 0\). We obtain

```
-\frac{\sigma^2}{4} \Phi'^2(x) + \frac{\sigma^2}{4} \Phi'^2(0) + \int_0^x (\nu + k(\xi - \gamma)) \Phi'^2(\xi) d\xi + \frac{\alpha + k}{2} (\Phi^2(x) - 1) = 0,
```

From this formula, one can convince oneself easily that \(\Phi''(x)\) has a limit as \(x \to +\infty\), but since \(\Phi'^2(x)\) is also an \(L^1\) function, necessarily this limit is 0. Therefore, we obtain an additional energy relation

```
(16.3.11) \frac{\sigma^2}{4} \Phi'^2(0) + \int_0^{+\infty} (\nu + k(x - \gamma)) \Phi'^2(x) dx = \frac{\alpha + k}{2}.
```

Since \(\Phi(\epsilon) < 1 = \Phi(0)\), we see that \(\Phi'(0) \le 0\). In fact \(\Phi'(0) < 0\). Indeed, if we set \(\Psi(x) = \Phi'(x)\), then \(\Psi(x)\) satisfies

```
(16.3.12) -\frac{1}{2} \sigma^2 \Psi''(x) + (\nu + k(x - \gamma)) \Psi'(x) + (\alpha + 2k) \Psi(x) = 0, x > 0,
```

and we know already that \(\Psi(+\infty) = 0\). Therefore \(\Psi(0)\) cannot be 0, otherwise \(\Psi(x)\) would be identically 0, hence \(\Phi(x)\) would be constant on \([0, \infty)\) which is impossible.
