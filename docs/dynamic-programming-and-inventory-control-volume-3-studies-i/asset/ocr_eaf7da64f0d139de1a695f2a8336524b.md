\(\tau_{k+1} - \tau_k - 1 \ge 0\), and vanishes when \(\tau_{k+1} - \tau_k - 1 = 0\). Therefore, formula (9.2.40) is valid for \(\tau_{k+1} - \tau_k - 1 \ge 0\). From Lemma 9.5 we have

```
(9.2.41) \( E[y_{\tau_k+1} \cdots y_{\tau_k+\tau_{k+1}-\tau_k-1} | \mathcal{F}^{\tau_k}] = E \left[ S \frac{1-\alpha^\theta}{1-\alpha} - \sum_{l=0}^\theta D_{l+l} \frac{\alpha^l - \alpha^\theta}{1-\alpha} \right], \)
```

where \(\theta = \tau_2 - 2\). Note that for \(k \ge 1\),

```
\( y_{\tau_{k+1}} = (S - (D_{\tau_k} + \cdots + D_{\tau_k+\tau_{k+1}-\tau_k-1}))^+, \)
```

and

```
\(\alpha^{\tau_{k+1}-1} y_{\tau_{k+1}} = \alpha^{\tau_k-1} \alpha^{\tau_{k+1}-\tau_k-1} \alpha (S - (D_{\tau_k} + \cdots + D_{\tau_k+\tau_{k+1}-\tau_k-1}))^+.\)
```

Therefore we can assert that

```
(9.2.42) \( E[\alpha^{\tau_{k+1}-1} y_{\tau_{k+1}} | \mathcal{F}^{\tau_k}] = \alpha^{\tau_k-1} \alpha E \alpha^\theta (S - (D_1 + \cdots + D_{1+\theta}))^+. \)
```

Similarly, for \(k \ge 1\)

```
\(\alpha^{\tau_{k+1}-2} L S_{\tau_{k+1}-1} = \alpha^{\tau_k-1} \alpha^{\tau_{k+1}-\tau_k-1} (S - (D_{\tau_k} + \cdots + D_{\tau_k+\tau_{k+1}-\tau_k-1}))^-.\)
```

Therefore

```
(9.2.43) \( E[\alpha^{\tau_{k+1}-2} L S_{\tau_{k+1}-1} | \mathcal{F}^{\tau_k}] = \alpha^{\tau_k-1} E \alpha^\theta (S - (D_1 + \cdots + D_{1+\theta}))^-. \)
```

We can then assert that

```
\( I = (h-c)x + K + cS + p \sum_{k=1}^\infty E \alpha^{\tau_k-1} E \alpha^\theta (S - (D_1 + \cdots + D_{1+\theta}))^-; \ II = \sum_{k=1}^\infty E \alpha^{\tau_k-1} E \alpha^\theta [\alpha(K+cS) + \alpha(h-c)(S - (D_1 + \cdots + D_{1+\theta}))^+]; \ III = h \alpha \sum_{k=1}^\infty E \alpha^{\tau_k-1} E \left[ S \frac{1-\alpha^\theta}{1-\alpha} - \sum_{l=0}^\theta D_{l+l} \frac{\alpha^l - \alpha^\theta}{1-\alpha} \right]. \)
```

Using next \(\alpha^{\tau_{k+1}-1} = \alpha^{\tau_k-1} \alpha^{\tau_{k+1}-\tau_k-1} \alpha\), we get

```
\( E \alpha^{\tau_{k+1}-1} = E \alpha^{\tau_k-1} E \alpha \alpha^\theta, \)
```

and since \(E \alpha^{\tau_1-1} = 1\), we obtain

```
(9.2.44) \( E \alpha^{\tau_k-1} = (E \alpha \alpha^\theta)^{k-1}, k \ge 1. \)
```

Collecting results, we can assert that

```
(9.2.45) \( J_x(V_{\epsilon, S}) = (h-c)x + K + cS + \ + \frac{1}{1-E \alpha \alpha^\theta} E \alpha^\theta [\alpha(K+cS) + \alpha(h-c)(S - (D_1 + \cdots + D_{1+\theta}))^+] \ + \frac{1}{1-E \alpha \alpha^\theta} E \left[ E \alpha^\theta p (S - (D_1 + \cdots + D_{1+\theta}))^- \right. \ \left. + h \alpha \left( S \frac{1-\alpha^\theta}{1-\alpha} - \sum_{l=0}^\theta D_{l+l} \frac{\alpha^l - \alpha^\theta}{1-\alpha} \right) \right]. \)
```
