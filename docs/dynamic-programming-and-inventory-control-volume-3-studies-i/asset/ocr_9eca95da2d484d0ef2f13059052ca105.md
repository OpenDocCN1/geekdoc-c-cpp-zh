Theorem 11.4. The function \( w(x) \) in (11.2.10) is obtained through a generalized \( s,S \) policy. Namely, there exists \( m \le M \), and a subset of \( [1, \cdots, M] \), which we can renumber in increasing order as \( [1, \cdots, m] \), and an associated sequence \( s_1^* \), with \( s_1^* > s_{i+1}^*, s_1^* \le s_i, s_1^* = s_1 \), such that

```
\( w(x) = \begin{cases} -c_m x + G_m(s_m), & \text{if } x \le s_m^*, i(x) = m \\ -c_i x + G_i(s_i), & \text{if } s_{i+1}^* < x \le s_i^*, i=1, \cdots, m-1, i(x)=i \\ -c_1 x + G_1(x), & \text{if } x > s_1^* = s_1, \text{no order} \end{cases} \)
```

PROOF. Define

```
\( s_{ij} = \frac{G_i(s_i) - G_j(s_j)}{c_i - c_j}; \)
```

```
\( s_j^* = \min \left( s_{j1}, \min_{i=1,\cdots,j-1} s_{ij} \right). \)
```

We shall prove that

```
\( i(x) \text{ may be chosen } \ge j \text{ if } x \le s_j^* \\ i(x) \text{ may be chosen } \le j - 1 \text{ if } x > s_j^* \)
```

Indeed, if \( x \le s_j^* \), then

```
\( w_j(x) = -c_j x + G_j(s_j), \)
```

and for \( i \le j-1, x \le s_{ij} \) implies

```
\( x \le \frac{G_i(s_i) - G_j(s_j)}{c_i - c_j}. \)
```

Therefore

```
\( w_j(x) \le -c_i x + G_i(s_i), \forall i \le j-1. \)
```

However

```
\( w_i(x) = \begin{cases} -c_i x + G_i(s_i), & \text{if } x \le s_i \\ -c_{i+1} x + G_i(x), & \text{if } x > s_i \end{cases} \)
```

Note also

```
\( w_i(x) \le -c_i x + G_i(x), \forall x. \)
```

Hence if \( x \le s_i \), we can assert that \( w_i(x) \ge w_j(x) \). On the other hand, if \( x > s_i \), then \( w_i(x) = -c_{i+1} + G_i(x) \ge w_j(x) \). So the first part is proven.

Suppose now that \( x > s_j^* \), we show that there is some \( i \le j-1 \), such that \( w_i(x) \le w_j(x) \). There are several cases. If \( s_j^* = s_i \), then \( w_j(x) = -c_j x + G_j(x) \), hence

```
\( w_j(x) = -c_i x + G_i(x) \ge w_i(x) \forall i \neq j. \)
```

Suppose \( s_j^* = \min_{i=1,\cdots,j-1} s_i < s_j \), then if \( x \ge s_j \) we have the same situation as before. There remains the case when \( s_j^* < x < s_j \). In that case, \( w_j(x) = -c_j x + G_i(s_i) \), and there exists \( i \le j-1 \), such that \( s_{ij} = s_j^* < x \), which implies \( w_j(x) > -c_{i+1} + G_i(s_i) \). Moreover \( s_i > s_j \), since \( i \le j-1 \). Hence \( x < s_i \), and \( w_i(x) = -c_{i+1} + G_i(s_i) \). We get immediately \( w_i(x) < w_j(x) \). So we have proven that there exists \( i \le j-1 \), better or equivalent to \( j \).
