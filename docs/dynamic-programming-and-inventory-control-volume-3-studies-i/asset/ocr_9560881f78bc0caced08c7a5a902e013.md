Define

\(\Psi(x,t) = E\varphi(x - D(t)) \mathbb{1}_{t < \tau_x^+},\)

then, recalling \(\mathcal{F}^t = \sigma(D(s), s \le t)\), by conditioning with respect to \(\mathcal{F}^{\tau_{x,n}}\) and using the independence properties one can check that

\(E\varphi(S - D(t) + D(\tau_{x,n})) \mathbb{1}_{\tau_{x,n} \le t < \tau_{x,n+1}} = E\mathbb{1}_{\tau_{x,n} \le t} \Psi(S, t - \tau_{x,n}), n \ge 1.\)

Since

\(\tau_{x,n} = \tau_x^s + \sum_{j=1}^{n-1} x_{n,j}, n \ge 2,\)

using the independence properties, we check easily

\(E\mathbb{1}_{\tau_{x,n} \le t} = F_x \otimes F_S^{(n-1)}(t),\)

where \(F_S^{(n-1)}\) denotes the \(n - 1\) times convolution of the probability distribution \(F_S\). The cumulative distribution function \(F_S(t)\) has a density \(f_S(t)\) and

\(dF_S^{(n-1)}(t) = f_S^{(n-1)}(t)dt.\)

Note that for \(n=1\) there is no density and \(f_S^{(0)}(t) = 1, \forall t > 0\). In that case \(f_S^{(0)}(t)dt\) must be replaced with the Dirac measure in 0. Collecting results we can finally write the formula

(15.6.34) \(z(x,t) = \Psi(x,t) + \sum_{n=1}^\infty \int_0^t f_x(t-\eta) \left( \int_0^\eta \Psi(S, \xi) f_S^{(n-1)}(\eta - \xi) d\xi \right) d\eta\)

So we have to consider the limit of

(15.6.35) \(z(s+c, t) = \Psi(s+c, t) + \int_0^t f_{s+c}(t-\eta) \Psi(S, \eta) d\eta\)
\(+ \sum_{n=2}^\infty \int_0^t f_{s+c}(t-\eta) \left( \int_0^\eta \Psi(S, \xi) f_S^{(n-1)}(\eta - \xi) d\xi \right) d\eta\)

However \(\Psi(x,t)\) is the solution of the Cauchy problem

(15.6.36) \(\frac{\partial \Psi}{\partial t} + A\Psi = 0, \quad x > s\)
\(\Psi(x,t) = 0, \quad x \le s\)
\(\Psi(x,0) = \varphi(x)\)

This is a classical Cauchy problem with Dirichlet boundary conditions. Note that the solution does not depend on the value of \(\varphi(x)\) for \(x \le s\). It is then standard to check that

\(\Psi(s+c, t) \to 0, \text{ as } \epsilon \to 0, \forall t > 0.\)

Now if we take \(\varphi(x) = 1\) in (15.6.35) then we see that

\(E\mathbb{1}_{t < \tau_x^{++}} \to 0, \text{ as } \epsilon \to 0, \forall t > 0.\)

This implies

\(\mathbb{1}_{t < \tau_x^{++}} \to 0 \text{ a.s. as } \epsilon \to 0, \forall t > 0.\)
