# Proposition 13.8. The following estimate holds

(13.5.15) 
\( -c - p \le u'_a(x; \sigma, \eta) \le h \left(1 + \frac{1}{\varpi_0}\right) \frac{1}{F(x)} \).

So if \( x < X \) then one can state that

(13.5.16) 
\( -c - p \le u'_a(x; \sigma, \eta) \le L_X, \quad L_X = h \left(1 + \frac{1}{\varpi_0}\right) \overline{F(X)} \).

PROOF. The estimate to the left follows directly from (13.5.13) and \( (l')^{(\sigma+\eta)}(x) \ge -p \). We next assert that

\( u'_a(x; \sigma, \eta) \le -c + h, \text{ forall } x \le S_a(\sigma, \eta) \)
\( \le h + \alpha E(u'_a)^{(+)}(\sigma+\eta+1-(\sigma'+\eta'))(x; \sigma', \eta'), \text{ forall } x > S_a(\sigma, \eta) \)

so also

\( (u'_a)^+(x; \sigma, \eta) \le h + \alpha E((u'_a)^+)(\sigma+\eta+1-(\sigma'+\eta'))(x; \sigma', \eta'), \text{ forall } x \)

This means, expliciting the mathematical expectation

\( (u'_a)^+(x; \sigma, \eta) \le h + (u'_a)^+(x; \sigma + 1, \eta) \sum_{k=\sigma+\eta+1}^M \gamma(k; \sigma, \eta) \)
\( + \sum_{k=0}^{\sigma+\eta} \gamma(k; \sigma, \eta)((u'_a)^+)(\sigma+\eta+1-k)(x; 0, k). \)

However for \( k \le \sigma + \eta \) and from the monotonicity of \( (u'_a)^+ \) we have

\( ((u'_a)^+)(\sigma+\eta+1-k)(x; 0, k) \le E(u'_a)^+(x - D; 0, k), \)

therefore

\( (u'_a)^+(x; \sigma, \eta) \le h + (u'_a)^+(x; \sigma + 1, \eta) \sum_{k=\sigma+\eta+1}^M \gamma(k; \sigma, \eta) \)
\( + \sum_{k=0}^{\sigma+\eta} \gamma(k; \sigma, \eta) E(u'_a)^+(x - D; 0, k). \)

Set

\( w_a(x) = \sup_{\sigma, \eta} (u'_a)^+(x; \sigma, \eta), \)

we deduce

\( (u'_a)^+(x; \sigma, \eta) \le h + w_a(x) \sum_{k=\sigma+\eta+1}^M \gamma(k; \sigma, \eta) + E w_a(x - D) \sum_{k=0}^{\sigma+\eta} \gamma(k; \sigma, \eta) \)
\( = h + w_a(x) - \sum_{k=0}^{\sigma+\eta} \gamma(k; \sigma, \eta)(w_a(x) - E w_a(x - D)) \)

We use

\( \sum_{k=0}^{\sigma+\eta} \gamma(k; \sigma, \eta) \ge \varpi_0, \quad w_a(x) - E w_a(x - D) \ge 0, \)

to deduce

\( (u'_a)^+(x; \sigma, \eta) \le h + w_a(x) - \varpi_0(w_a(x) - E w_a(x - D)), \)
