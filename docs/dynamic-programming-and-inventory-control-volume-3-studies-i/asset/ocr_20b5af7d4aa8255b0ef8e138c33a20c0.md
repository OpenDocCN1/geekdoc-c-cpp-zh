# 13.5.2. ESTIMATES FOR THE CASE \( K=0 \).

We consider the Bellman equation

```
\( u_\alpha(x; \sigma, \eta) = -cx + l^{(\sigma+\eta)}(x) \)
\( + \inf_{y \ge x} \left\{ cy + \alpha E u_\alpha^{(\sigma+\eta+1-(-\sigma'+\eta'))}(y; \sigma', \eta') \right\} \)
```

where we have emphasized the dependence in \(\alpha\). Since \(K=0\), the optimal policy is a Base stock policy, defined by a base stock \(S_\alpha(\sigma, \eta)\). The function of \(x, u_\alpha(x; \sigma, \eta)\) is continuous, convex and tends to \(+\infty\) as \(|x| \to +\infty\). It is also described as follows

```
\( u_\alpha(x; \sigma, \eta) = -cx + l^{(\sigma+\eta)}(x) + c S_\alpha \)
\( + \alpha E u_\alpha^{(\sigma+\eta+1-(-\sigma'+\eta'))}(S_\alpha; \sigma', \eta'), \forall x \le S_\alpha(\sigma, \eta) \)
```

and

```
\( u_\alpha(x; \sigma, \eta) = l^{(\sigma+\eta)}(x) + \alpha E u_\alpha^{(\sigma+\eta+1-(-\sigma'+\eta'))}(x; \sigma', \eta'), \forall x \ge S_\alpha(\sigma, \eta) \)
```

The function is differentiable as a consequence of convexity. Let us check that it is continuously differentiable at \(S_\alpha(\sigma, \eta)\). Indeed

```
\( u'_\alpha(x; \sigma, \eta) = -c + (l')^{(\sigma+\eta)}(x), \forall x < S_\alpha(\sigma, \eta) \)
\( u'_\alpha(x; \sigma, \eta) = (l')^{(\sigma+\eta)}(x) + \alpha E (u'_\alpha)^{(\sigma+\eta+1-(-\sigma'+\eta'))}(x; \sigma', \eta'), \forall x > S_\alpha(\sigma, \eta) \)
```

Since at \(S_\alpha\) we have

```
\( -c = \alpha E (u'_\alpha)^{(\sigma+\eta+1-(-\sigma'+\eta'))}(S_\alpha; \sigma', \eta'), \)
```

from the definition of the Base stock, the continuity of the derivative is obtained at \(S_\alpha\).

We now derive useful properties of the Base stock. We shall clarify first some abuse of notation. Applying the definition of \(l^{[x]}\) to the Heaviside function \(\mathbb{1}_{x>0}\) we obtain the CDF of \(D_1 + \cdots + D_t\), which has been denoted by \(F^{(t)}(x)\) in Chapter 9, see equation (9.2.19).
