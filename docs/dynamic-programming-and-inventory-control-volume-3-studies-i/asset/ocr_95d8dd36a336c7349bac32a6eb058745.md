Lemma 9.5. The random times \(\tau_k\) are stopping times with respect to the filtration \(\mathcal{F}^{n-1}\). Moreover \(\tau_{k+1}-\tau_k-1\) and \(D_{t_k}, \cdots, D_{t_k+n}, n \ge 0\), are mutually independent of \(\mathcal{F}^{n-1}\).

PROOF. We shall prove that

\(\{\tau_k = n\} \in \mathcal{F}^{n-1}, n \ge 1.\)

We prove it by induction on \(k\). The result is true for \(k=1\). Note that \(\tau_k \ge k\). Assume that the result is true for \(\tau_k\), we want to prove it for \(\tau_{k+1}\). It is sufficient to assume \(n \ge k+1\), since otherwise the set is empty. If \(n = k+1\) we have

\(\{\tau_{k+1} = k+1\} = \{\tau_k = k\} \cap \{D_k \ge S - \varepsilon\} \in \mathcal{F}^k,\)

and the result is true. So we may assume \(n \ge k+2\). We then have

\(\{\tau_{k+1} = n\} = (\{\tau_k = n-1\} \cap \{D_{n-1} \ge S - s\})\)
\(\cup_{j=k}^{n-2} (\{\tau_k = j\} \cap \{D_j + \cdots + D_{n-1} \ge S - s\} \cap \{D_j + \cdots + D_{n-2} < S - s\}\)
\(\cap \{D_j + \cdots + D_{n-2} < S - s\}),\)

which belongs to \(\mathcal{F}^{n-1}\), using the induction hypothesis. Let us now prove the second part. Let \(\xi\) be a random variable which is \(\mathcal{F}^{n_k}\) measurable. So \(\mathbb{1}_{\{\tau_k \le j\}}\) is \(\mathcal{F}^{n-1}\) measurable, \(p \ge k\). Consider next a random variable defined by the formula

\(\Phi(\tau_{k+1} - \tau_k - 1, D_{\tau_k}, \cdots, D_{\tau_k+m}),\)

where the function \(\Phi\) is deterministic. We must prove

(9.2.38) \(E\Phi(\tau_{k+1} - \tau_k - 1, D_{\tau_k}, \cdots, D_{\tau_k+m}\xi = E\Phi(\tau_{k+1} - \tau_k - 1, D_{\tau_k}, \cdots, D_{\tau_k+m})E\xi.\)

Call \(X = \Phi(\tau_{k+1} - \tau_k - 1, D_{\tau_k}, \cdots, D_{\tau_k+m})\). We have

\(EX\xi = \sum_{j=k}^{\infty} \sum_{h=k}^{\infty} E\Phi(h, D_j, \cdots, D_{j+m})\mathbb{1}_{\tau_k=j}\mathbb{1}_{\tau_{k+1}=j+h+k}\xi\)
\(= \sum_{j=k}^{\infty} \sum_{h=k}^{\infty} E\Phi(h, D_j, \cdots, D_{j+m})\mathbb{1}_{\tau_k=j}\xi \mathbb{1}_{D_j+\cdots+D_{j+h} \ge S-s} \mathbb{1}_{D_j+\cdots+D_{j+h-1} < S-s}\)
\(+ \sum_{j=k}^{\infty} E\Phi(0, D_j, \cdots, D_{j+m})\mathbb{1}_{\tau_k=j}\xi \mathbb{1}_{D_j \ge S-s}.\)

Since \(\mathbb{1}_{\tau_k=j}\) is \(\mathcal{F}^{j-1}\) measurable, we obtain

\(EX\xi = \sum_{j=k}^{\infty} \sum_{h=k}^{\infty} E\Phi(h, D_j, \cdots, D_{j+m})\mathbb{1}_{D_j+\cdots+D_{j+h} \ge S-s} \mathbb{1}_{D_j+\cdots+D_{j+h-1} < S-s} E\mathbb{1}_{\tau_k=j}\xi\)
\(+ \sum_{j=k}^{\infty} E\Phi(0, D_j, \cdots, D_{j+m})\mathbb{1}_{D_j \ge S-s} E\mathbb{1}_{\tau_k=j}\xi.\)

But

\(E\Phi(h, D_j, \cdots, D_{j+m})\mathbb{1}_{D_j+\cdots+D_{j+h} \ge S-s} = E\Phi(h, D_1, \cdots, D_{1+m})\mathbb{1}_{D_1+\cdots+D_{1+h} \ge S-s} = A_h;\)
\(E\Phi(0, D_j, \cdots, D_{j+m})\mathbb{1}_{D_j \ge S-s} = E\Phi(0, D_1, \cdots, D_{1+m})\mathbb{1}_{D_1 \ge S-s} = A_0,\)
