### 基本语法

C++ 不仅可以定义为程序，还可以定义为通过调用其他方法进行集体通信的对象。当你使用 C++ 时，你最需要弄懂以下四件事的含义。

- **类（Class）**——这是一个模板或蓝图，它定义了对象及其支持类型，并描述了对象的行为。这意味着对象会按照其行为及其操作/支持被归类到符合该对象描述的类中。

- **对象（Object）**——对象具有行为和状态。例如，如果你观察一只狗，它就有状态。这些状态可以分为颜色、品种、名字、品种标准（AKC/AKA/APC 注册）。“狗”也表现出某些行为。它们摇尾巴、吠叫、喘气、吃干狗粮，或者只是像块木头一样呆坐着什么也不做。

- **实例变量（Instant Variables）**——这些指的是每个单独的对象。每个对象都有一组独特的变量，这些变量就像对象的指纹一样。这些变量通过对象创建时生成的值分配给对象。

现在你已经了解了编程的四大主要定义，让我们来看一段可以编写并打印出“Try This”的代码。与上面的示例不同，这段代码会更深层次地解释你想要做什么，以及每个函数存在的原因。

```cpp
#include <iostream>
using namespace std;

// main() [这是程序开始执行的地方。]

int main()
{
    cout << "Try This"; // [打印 Try This]
        return 0;
}
```

这个函数可以让你打印任何你想要的内容，而不仅仅是“Try This”这几个字。

现在让我们来分解上述程序的各个部分。这种语言的许多不同方面你都需要考虑。每个方面对于程序的运行都很重要，如果你没有完全执行它们，程序就无法正常运行。

- **头文件（Headers）**——C++ 有很多头文件，它们中的每一个对于你的编程操作来说都是必要的，或者至少是有用的。不过，对于大多数函数来说，你会看到上面提到的 `<iostream>` 头文件。使用头文件时，请确保正确地将它括起来，并在前面加上 `#include`，以提示程序使用该头文件。

- **命名空间（Namespace）**——命名空间是 C++ 较新的添加内容，直到 2011 年的更新中才出现。它们的作用并不大，只是描述要使用哪个命名空间。虽然它们不是必需的，但能避免你在程序函数上产生许多困惑。它仅仅是一种更系统地组织函数的方式。

- **main**——这里是主函数开始的地方。使用 `// main()` 这行是告诉程序开始执行主函数，并启动输出过程。设置主函数命令是必不可少的，否则你的程序既不知道它应该运行什么，也不知道应该在什么时候运行。这行代码在程序内部会被视为单行注释，告诉程序主函数即将开始。

- **int main**——这是函数执行正式开始的地方。如果你不包含这一行，整个过程都会停止，因为你没有引入变量，而没有变量，程序就会迷失方向。

- **cout**——这指示程序在屏幕上显示你想要的输出消息。如果你不加 cout，程序有可能会失败，也可能不会。问题是你不知道是否成功，所以如果你想确保一切顺利运行，一定要加上 cout。

- **return**——这会将值返回为零，并终止函数。它指示程序结束进程，并回到开头。

这些语句中的每一条不仅用换行分隔，还用分号分隔。你也可以这样做。

```cpp
x=y; y=y+1; add(x,y);
```

仅仅因为分号，其中每一条都会被识别为单独的语句。如此简单的东西竟能产生如此大的影响，这有点令人惊叹。

```cpp
{

```

如上所述，行尾并不是终止符。分号才是唯一终止语句的东西。

### 标识符

### 程序注释

那么，有时你会想在代码中写一些注释。这些注释很重要，因为它们允许你在代码中留下简短信息，以便之后阅读代码的人能够清楚地了解代码究竟如何运行，并“提示”你试图在代码中实现什么。此外，在代码行中留下备注是提醒自己某处代码可能出错的好方法。通过在代码中加入注释，你使用 // 符号来表示你正在写注释。你可以让注释任意长，只需确保注释结束后跳到下一行，以便程序知道它应该重新开始读取代码。

程序在 // 之后将停止读取，而且这不会影响程序的工作方式。查看代码的其他程序员会看到你写的注释，但当程序执行时，这些注释会被跳过。你可以在程序中添加任意多的注释，但请尽量保持有限，因为它可能开始堵塞代码，使其难以阅读和理解。

程序注释基本上是代码内部的语句。这些语句或注释的存在，是为了帮助使用你代码的其他人理解每个函数的用途。所有编程语言都允许某种类型的注释，但并非所有语言都允许现存的所有注释类型。最常用的是单行注释。这是所有编程语言都允许的。

这些注释是简单的解释性行，用一句简单的话告诉下一位读者其目的是什么。

还有多行注释。这是极少数编程语言允许的。C++ 就是这少数语言之一。有时你有更复杂的解释，需要跨越多行。这在 C++ 中是可行的。

当你使用单行注释时，你会看到它在代码中用 // 写出，并且可以一直延伸到行尾。例如：

```cpp
{

    return 0;
}
```

这将最终输出 "that's great"，别无其他。编译器会忽略注释，这样你就可以让其他程序员了解代码的用途，或者你需要对代码做什么。

## 第 5 章：在 C++ 中使用运算符

对于你计划使用的任何编程语言，学习如何使用运算符都很重要。它们能帮助你告诉程序你想做什么，并能让你处理自己的代码容易得多。在程序中可以使用四种主要类型的运算符，它们各自会以不同方式告诉程序如何行为。你可以在 C++ 语言中使用的一些运算符包括：

- 逻辑运算符

### 逻辑运算符

本指南中我们要使用的第一类运算符是逻辑运算符。它们会帮助你比较输入系统的某些部分。你可以使用的一些逻辑运算符包括：

- `||`：这称为逻辑 OR。使用它时，如果你的操作数之一不为零，条件就会为真。
- `&&`：这称为逻辑 AND。如果你有两个操作数且它们都不为零，条件就为真。
- `!`：这是逻辑 NOT。你可以用它反转操作数的状态。因此，如果条件最终为假，这个符号会使其变为真。

### 算术运算符

你可以使用的另一类运算符是算术运算符。它们与在学校里做数学几乎一样。你将告诉程序对提供的信息进行加、减和其他运算。你可以使用的一些算术运算符包括：

- `+`：这是加法运算符，会将你选择的两个操作数相加。
- `-`：这是减法运算符。它会取右侧操作数并从左侧操作数中减去。
- `*`：这个运算符使得在 C++ 语言中进行乘法成为可能。
- `/`：这个运算符帮助你在 C++ 中进行除法。
- `++`：这是递增运算符。它会把操作数的值增加一。
- `--`：这是递减运算符。它会把操作数的值减少一。

### 赋值运算符

赋值运算符让你更容易为变量指定名称，并有助于搜索、保存你正在编写的代码的不同部分等。你可以在 C++ 中使用的一些赋值运算符包括：

- `=`：这个运算符是简单赋值运算符。它会把右侧操作数的值赋给左侧操作数。
- `+=`：这个称为“加 AND”运算符。它会把两个操作数的值相加，然后把它们的和赋给左侧操作数。
- `*=`：这是“乘 AND”运算符。它会把两个操作数相乘，然后把结果赋给左侧操作数。
- `-=`：这个运算符会从左侧操作数中减去右侧操作数的值，然后把差值赋给左侧操作数。
- `/=`：这是“除 AND”运算符。它会用左侧的值除以右侧的值，然后把结果赋给左侧操作数。

### 关系运算符

- `==`：这个运算符会检查两个操作数是否相等。如果相等，条件就为真。
- `>`：这个运算符会检查操作数的值。如果左侧操作数高于右侧操作数，条件就为真。
- `<`：这个运算符基本上与上面的运算符相反。如果你发现左侧操作数的值小于右侧操作数，条件就为真。
- `!=`：这个运算符会检查两个操作数是否相等；如果值不相等，条件就为真。
- `<=`：这个运算符会检查左侧操作数是否小于或等于右侧操作数。如果满足此条件，条件就为真。
- `>=`：这个运算符会检查左侧操作数的值是否大于或等于右侧操作数。如果为真，条件就为真。

## 附赠：黑客简史与概述

许多人都听过 C++ 这个名字，但真的不把它当回事。如果你不太精通技术，你可能会以为它指的是一个平庸的字母等级，但事实并非如此。

### 黑客行为

黑客行为并不是一个新概念。只要有任何类型的技术存在，就会有人想办法入侵它们。黑客行为是对从一处发送到另一处的任何技术数据流进行操纵和/或中断。这是通过脚本来完成的。虽然你可以在网上获得预先打包好的脚本，但许多人更喜欢老式的方法，即编写自己的脚本，因为这让他们能更灵活地利用信息做自己想做的事。已经打包设置好的脚本灵活性有限，而且相当显眼。一个真正想要进行黑客攻击的黑客，其目标是保持隐蔽。如果你被抓到，除非你有权限做你正在做的事情，否则你可能会陷入大麻烦。

### 黑客史




黑客行为正式始于20世纪70年代，当时青少年因试图免费打电话并弄明白如何做到这一点而被禁止使用电话线路。电话黑客行为是当时最重要的事情，并持续了一百多年。过去打电话很昂贵，尤其是在电话线路刚出现时，所以人们自然会想方设法省钱，而通常这最终会让他们付出代价。一个名叫约翰·德雷珀的人就是如此。他因弄明白如何仅通过在听筒中吹一个音调来触发长途通话、从而拨打长途电话而被逮捕。

实际上直到20世纪80年代才开始。然而，一旦开始，它便像野火一样蔓延开来，很多人认为看看自己能做到什么、如何操纵这些计算机是个好主意。

### 黑客技术的类型

黑客技术有几种不同类型。虽然媒体把所有黑客都描绘成坏人，但事实并非如此。这也不是非黑即白的。虽然在谈论黑客时，这两类是最常见的群体，但中间还有许许多多类别，因此只谈论最知名的两类并无益处。

然而，所有子类别都可归入的两大主要类别是合乎道德的黑客行为与不道德的黑客行为。

道德黑客行为是仅用于正当目的的黑客行为。有很多人拥有完全权限入侵系统，并找出软件或硬件的所有漏洞。

道德黑客负责你手机、应用、平板电脑或计算机中的所有漏洞修复。这些人受公司聘用，找出其系统的问题，并找到最佳修复方法。这些黑客是黑客社区不可或缺的一部分。

如果没有黑客，我们就不会有万维网、URL 或 HTML。如果在道德黑客行为的边界内进行，黑客技术就是重要的一部分。

然而，不道德黑客行为不属于现行法律允许的黑客行为范畴。它是出于恶意目的的黑客行为。入侵银行主机、窃取他人信用卡和账户信息并用其清空账户的人，其行为被称为不道德黑客行为。

不道德黑客行为是真正黑客的祸害。正是这些人让好人背上坏名声。

现在继续介绍不同类型黑客的术语。

- 白帽黑客：这些是完全合乎道德的黑客。他们所做的一切都是为了正当目的。他们会遍历系统，仔细排查任何漏洞，并构建超强防火墙以确保系统安全。他们开发反恶意软件。
- 黑帽黑客行为：这是你必须远离的那类黑客行为。能力越大，责任越大。重大责任就是不要成为黑帽黑客行为诱惑的猎物。这类黑客行为会给你带来很多麻烦，而且不道德。入侵政府文件甚至他人隐私可能很诱人，但会导致严厉的纪律处分。
- 灰帽黑客行为：这些黑客有时出于正当理由做坏事。例如 Anonymous（匿名者）。他们可能入侵敏感信息文件的防火墙，但这样做是为了揭露防火墙背后正在发生的腐败。这些黑客常被当作罪犯对待，但实际上，取决于你的视角，他们也可以被视为英雄。
- 红帽黑客：这些是黑客世界的赏金猎人。他们利用自己的黑客技能寻找非法黑客，例如黑帽黑客，或正在做不该做的坏事的灰帽黑客。然后他们将其交给联邦探员，以便非法黑客被逮捕。这些黑客还有其他几个称呼，但都不太合适，因此我们略去不提。

如果方式得当，它甚至可以成为一种职业。

另一方面，如果你热爱在计算机世界工作，并且希望一直做这件事，那么做一名白帽黑客可能是个好主意。许多公司为其客户保存私人和个人信息，无论是医院信息、信用卡信息还是其他信息。他们一直在提防可能试图进入系统并窃取这些信息的黑帽黑客，而优秀的白帽黑客总能找到帮助这些公司所需的工作。

### 处理流程

处理大量数据时，你很容易不知所措。这是显而易见的，而且一般来说，最好使用软件来辅助你。这一点稍后会详细讨论，但本节将介绍当这种情况发生时该如何应对。

首先，保持冷静。如此庞大的数据量足以让任何人发疯。但你不应感到沮丧。相反，你应该把正在阅读的所有内容都整理起来，进行分析，决定下一步怎么做，然后再继续推进。不要让自己不堪重负，因为那只会让你之后吃亏。对一切都抱持保留态度，并问问自己：“所有这些数据对我有什么好处？”

先处理最重要的统计数据。我们来审视最重要的数据，看看它会带来什么结果。你应该仔细查看，了解公司情况的变化，然后再决定下一步。

确保将数据可视化。绘制图表，以便你能直观看到。数字确实能传达某些方面的信息，但不要让它们成为全部的决定性因素。相反，让数字成为其中的一部分，然后你可以根据这些新发现的信息来审视接下来该做什么。

如果你发现有些不对劲，不要绝望，而要把你所看到的记下来，然后处理它。记住，这些统计数据确实会变化。而让它们变化的人是你。光靠看是不会神奇地改变的，你必须采取行动。即使这意味着要解雇一名糟糕的员工，或停售一款你一直在销售的产品，这些都至关重要。

务必注意这些数字，并不仅仅进行近期对比，还要回溯到更早以前。处理大量数据的人常犯的一个问题是，他们只关注短期，而忽视长期。然而，如果那样做，你就无法达到甚至超越当前的水平。要从几天前、几周前的数据中推断趋势，但更重要的是，从*数年前*的数据中推断。许多企业没有意识到这样做有多重要。如果你只看短期数据，就会被困在那一范围内，所以在做决定之前，一定要确保自己掌握了全貌。

在分析数据时，找别人帮你，比如助理或会看图表的人。你以后会感谢自己的，因为首先，这项工作可能令人不知所措。此外，有时有第二个人在场至关重要。他能告诉你即将做出的决定是否最佳，以及是否应该继续执行手头的行动。从这个角度看，这可能会拯救你的企业，而且你也会感觉更好。另外，有时有别人在场有助于激发新想法，所以如果你想用不同的方法解决业务中的问题，雇佣统计师或数据分析师等人绝对值得投资。

## 第 3 章：数据分析的类型

在数据分析方面，重要的是要理解某些类型的数据分析与其他类型并不相同。记住，如前所述，这种大数据可以帮助进行欺诈检测、复杂层面的竞争分析、优化呼叫中心等各种结构、实时了解客户感受、改善各种智能的交通管理，甚至还能帮助管理其他此类事项。所有这些事情都可以借助数据分析来完成，而大数据是

### 三个因素

现在，所有大数据分析确实都包含三个不同部分，而正是这些部分构成了大数据和数据分析。

首先是**数据量**。你会看到，面对大数据，很难一次性处理所有这些内容。这就是为什么你会得到各种不同类型的数据分析，并且能够将它们用于不同部分。对于较小的企业，有时也会涉及数据量这个概念，但随着企业逐渐成长和成形，你会看到数据量这一要素确实会发挥作用。数据量太少不会显示出多大变化，但数据量太多确实会给你带来问题。这就是为什么在大数据分析以及一般数据分析中，你必须考虑事物的数据量。

然后是**速度**。这是指数据流入和流出的快慢。现在，有些地方的数据分析可能很容易查看，因为数据流动的速度对人类节奏来说很舒适。但在其他某些情况下，比如呼叫中心或电力公司的电网，你会注意到数据流动得快得令人难以忍受。大型公司需要像鹰一样密切注视数据分析的这一部分，因为虽然你当然可以筛选大量内容，但如果不管理这种速度，随着时间推移就会出问题，这就是为什么它是企业核心运营方式中的一个主要因素。

然后是**多样性**。多样性是指处理大数据时的差异。对于较小的公司，情况相当明确且范围狭窄，差异很小；但随着你开始成长，你会开始设立部门和其他各种职能。这些部门及类似机构之下会有需要衡量的职能。例如，看看 AT&T 及其拥有的流量，看看他们是否有办法在没有大数据分析的情况下处理所有这些流量？没有，这就是为什么必须认识到你确实需要它，以帮助确保你从中获得最多成果。因此，你需要大数据分析，才能看清这一切的纯粹多样性；当我们讨论四种类型时，你就会明白为什么这一点很重要，以及它如何与另外两个因素相关联。

### 数据分析的四种类型

从你前面看到的内容来看，大数据基本上是你用来有效管理组织的东西。你还需要确保分析也被纳入其中，并且这些分析在公司中占有一席之地，因为如果不这样做，你就无法看到隐藏的模式、任何出错之处，以及各种要素之间的关系。但在此基础上，你还需要了解各种类型，这就是接下来要讲的内容。

- **描述性：** 描述性分析在本章前面已经描述过。本质上，这是一种据称基于当前流入数据正在发生什么的数据分析类型。通常，要寻找这类分析，你会使用一个显示所有这些数据的仪表板。位置、平均值、范围、标准差是本节涵盖的一些基本描述性统计和分析。

- **诊断性：** 这是一种会回顾过去表现的数据分析类型，会告诉你当时发生了什么、为什么会这样，以及其结果。这类分析提出的问题是：“为什么会发生？”

- **规范性：** 规范性分析会告诉你何时该采取行动。现在，这是其中最重要的一个，因为这种数据分析会告诉你接下来需要做什么，并且在某种程度上决定公司的下一步。这种数据分析要么让公司倒闭，要么让公司因此跃升。

- **预测性：** 这更像是对正在发生的情况进行预测，以确定未来的行动方针以及可能由此产生的各种情景。这种预测性预报很重要，因为它会在你开始改变或启动业务中的事情之前，告诉你该做什么、该往哪里走。

### 这些分析的示例

理解数据分析的很大一部分不仅在于阅读相关内容，还在于看到示例。本章将讨论各类数据分析，以及它们在大企业中的使用方式。

如前所述，规范性分析是最有价值的，但它并不是最常用的。例如，在报告使用此类数据分析的组织中，只有13%使用预测性分析，但只有3%使用规范性分析。

例如，许多人喜欢用它来预测正在发生什么，但对正确行动给出规范性建议可以带来不同。当你拥有涉及某个主题的大数据分析时，这些规范性分析会让你聚焦于各种问题。以医疗保健行业为例，你正在基于前来就诊的病人做医院分析。也许你想管理肥胖患者病例数量，看看如何集中开展治疗。你可以查看各种类型，如坏胆固醇、糖尿病或其他疾病，并应利用这一点来聚焦患者应接受的治疗类型。




也许你还想一并审视市中心青年所面临的问题。你可以使用规范性分析，清晰地了解正在发生的情况。

预测性分析用于分析已经出现的过往模式，目的是预测未来。例如，你可以使用预测性分析来进行销售线索评分。一些公司可以用它来查看最佳销售线索来自哪里，你也可以将其用于整个销售流程，例如沟通的数量和类型、社交媒体的存在情况以及其他类似因素。预测性分析有助于提振销售并为其提供支持，使其变得更好，改进正在开展的营销活动，同时也有助于改进销售预测。

诊断性分析用于查明某事为什么会发生。当你开始出现重大变化时，这一点尤其重要。例如，假设你在Facebook上开展了一场社交媒体活动。你可能开始看到数量激增，并且可能想知道原因。那么，如果使用诊断分析，你可以查看帖子、关注者、各种提及、粉丝类型、有多少人浏览了页面、任何类型的评论、任何类型的收藏以及其他类似内容。你可能开始看到大量不同的提及，但有时正是某一种提及可能推动了整个局面的发展，这就是为什么作为社交媒体经理，开展这项分析可能很重要。

最后是描述性分析，它基本上是数据价值链中最低的一层。这基本上就是获取信息，以便寻找各种模式，从而为这类事情提供洞见。例如，在允许某人从你这里获得资金之前，你可以查看其信用记录来了解其信用风险。也许你在雇用某人之前会查看其背景，以了解其此前是什么样的人。这些都很重要，如果你拥有这些，有时可以用它来构建另外三类分析。

理解大数据分析会为你的企业增添巨大价值。从某种意义上说，它确实能讲述一个故事，因为它会将许多复杂问题简化为实际可执行的条目，以帮助你做出更好的商业决策。如果你知道如何使用它，那么你的业务可以增长十倍。

## 第 4 章：大数据、数据挖掘、数据仓库和数据可视化

现在你已经对数据分析及其细微差别有所了解，是时候探讨它的其他方面了，例如它如何被使用以及其他类似因素。本章将介绍几个概念，并帮助你理解它在一家公司中是如何使用的。

### 大数据

首先要讨论的是大数据。如前所述，大数据就是数据量并不小的数据。它横跨大量不同领域，而数据分析正是对它们进行处理。面对大数据时，你所看到的是比预想中大得多的图景。

大数据有时可能在总量上非常庞大。以呼叫中心为例，你就会看到那里的数据有多大。呼叫中心是一种大型结构，里面有许多人工作，而由于它规模庞大，就需要有一种方法来审视这些数据。

大数据帮助大型公司在未来事业方面做出正确决策。它有点像一种防止错误决策的保障；有时，当你拥有大量数据时，你能够精准定位事物的模式，看到各种较小的模式有时如何影响较大的模式。你将能够看到各种交易以及随之而来的一切，从而据此形成正确的结论。

大数据实际上是你用来收集的东西，而你需要使用数据挖掘来找到你需要找到的一切。

### 数据挖掘

现在，既然所有数据都摆在你面前，有时你需要找到你正在寻找的内容。记住，并非所有数据都是生来平等的，尤其是在审视大数据的领域里。你未必需要眼前所有事物的数据，但你需要对它有某种理解，并且需要真实的数据来讨论下一步该做什么，以及在其更大的数据库中的模式。

所以，你这里拥有所有这些信息，对吧？你会发现这项技术要强大得多，而且在计算机的帮助下，它能够筛查许多不同的扫描器之类的东西，你可以查看订单处理情况，以了解哪些做法有助于增加企业收入，哪些做法反而会损害企业。

通过数据挖掘，你将能够从各种来源获取数据，让自己审视各种起初可能看不到的内部因素，并且你将能够改变一些事情或让它们保持不变，而这反过来会对这类商品的销售、客户满意度，甚至从某种意义上说对利润产生重大影响。归根结底，你基本上是把所有内容汇总成摘要和各种交易细分，以确保你拥有正确的想法。例如，各种视频租赁服务可以调整数据库，以获得更多租赁量，从而增加租赁客户的数量。从某种意义上说，这会接收前面提到的大数据，对其进行筛查，并借助强大的软件，让你对自己究竟要追求什么以及其结果形成完整而连贯的认识。记住，数据挖掘绝对是交易与系统之间的纽带，它会基于交易寻找这些关系，从而由这些关系形成分析性结论。

### 数据仓库

现在，一旦你拥有了所有这些数据，你就需要弄清楚它应该放到哪里，对吧？那么，有一种选择可以让你找到答案，本质上，它是一种称为数据仓库的软件。

这是一种在进行分析时使用的系统；从某种意义上说，它是在进行各种数据分析时存储所有信息的地方。这是商业智能的另一个重要组成部分，而且理由充分。

数据仓库是一组存储库，它们将来自并不总是相同来源的数据放入不同区域。例如，它会采用各种历史数据，甚至一些近期事件的数据，以便为在企业中工作的人创建一份良好的分析报告。例如，它会采用企业可能进行的季度比较，然后把趋势与每日完成的详细销售分析并列展示。在此基础上，你可以从数据仓库中获取信息，并结合你通过挖掘获得的当前信息，利用它们来建立联系。

现在，数据仓库本质上是从各种运营系统上传到计算机中的。营销、销售以及企业其他重要方面很快都会被整合到那里。随后，数据将进入某种运营数据存储，再进入数据仓库，以便之后进行报告。

现在，它的作用是：将来自各种来源的数据纳入一个数据库以呈现数据，同时它还会帮助解决数据库隔离争用与交易之间的问题。尽管存在这些情况，它仍能让交易继续进行。

此外，还可以从某种数据历史的意义上来看待它。如果你确实需要回溯，你可以查看它。这也会有所帮助，因为有时交易系统可能没有你需要的数据，你可能不得不进行一些挖掘。它节省时间，你将能够轻松且无误地找到这些内容。

它还有助于提高数据质量。通常，当你处理大量数据时，会出现一些坏数据，有时编码和描述会出错。然而，有了数据仓库，你就能够将所有这些一致地放入其中，如果其中有什么问题，你就能修正一些坏数据，甚至将其删除。在此基础上，你就可以将其呈现为一个

以更一致的方式，然后调整结构，以便让企业的各类用户更容易使用。在此基础上，数据仓库将让你能够更轻松地针对其各个方面做出各种决策和查询，并且随着时间的推移，你将能够把这个有用信息的容器拿出来，将其整齐地呈现出来，并由此对你将要用它做的所有事情形成一个良好、连贯的决策。

在大数据场景中，数据仓库非常重要，因为它能让你自己更轻松，也让别人更轻松，并且你将能够利用这一切，更容易地清楚了解它们各自适合放在哪里。

### 数据可视化

现在，这算是最终的画面，也是所有这些内容的一部分。这就是数据可视化。本质上，当你处理大数据时，其庞大的数量和速度，更不用说它可能无处不在这一事实，会让人感觉自己快要发疯了。那么，如果你在看所有这些数字时感到困惑，把它们可视化难道不是合情合理的吗？最好的做法就是使用数据可视化，也就是以图形方式展示各种抽象信息，这有两个不同的原因。其一，它用于帮助你理解各种模式和其他要素，这被称为数据分析；另一个原因则是与他人沟通。如果你想完成某件事并把它处理好，就必须有效地沟通，而数据可视化正是为此而来。许多公司会依赖这些数据生存，对许多人来说，数据可视化能让你理解正在发生什么，同时理解如何把它们呈现给其他人。这些信息是抽象的，因为它是统计数据，而不是实体事物。当然，统计数据可能代表实体产品或信息，但归根结底，它实际上仍是统计数据和一些数字。这些可视化确实适用于任何事物，比如销售、绩效之类；当它与物理世界无关时，这些可视化仍然可以使用，因为它能给没有形态的事物赋予形态。许多这类内容会通过呈现给你的视觉形式，从抽象转化为视觉。你也可以看看这些可视化的设计。

通常，这些内容更多是以图表来衡量的。正如所说，一图胜千言，这里正是如此。你可以看着它，然后开始看到事物变化的方式。

现在，你也可以不借助可视化来看这些数字。我不太推荐这样做，但有时，你确实需要看一种实际的表现形式才能完全理解它。大数据会使用这些可视化，而且它们往往是一张带有一些统计点的图表；由此，你将能够看到其中包含的各种数值，并由此看到其中必要的趋势，这将让你在这方面更加成功。

本质上，可视化是做出决策之前的最后一步。它用于展示数据以改善状况，也是你取得成功所需要的东西。

现在，数据挖掘以及大数据的其他部分会一起使用，以便有效地创建你所寻找的图景。本章让你看到了这些部分共同运作的方式，以及它们如何继续协同工作，从而形成出色且易于理解的情形，供你在数据分析中使用。

## 第 5 章：如何对自己的业务进行数据分析

既然你已经了解数据分析及其全部内容，现在是时候讲解如何在你自己的业务中亲自进行数据分析。现在，你很可能不需要使用大型软件来完成这件事。毕竟，我们目前还不是在处理大数据；但本章将逐步讲解如何做好这件事以取得成功。

- 1) 获取一个电子数据库并整理你的数据。用于此目的的最佳工具是 Microsoft Excel。它将让你在一个可编辑的新文件中工作。你应该把数据复制到那里。不要在原始主文件中进行此操作，因为这在分析时可能导致损坏。然后你可以把所有数据整理到那里，并使用筛选器让你更容易看出差异。你要确保从容地做这件事，因为你最不想做的就是把它放到错误的位置。

- 2) 现在，你需要用数字对文本回答进行编码。这意味着，对于某些答案，你需要在分析之前将它们编码为各种数字。你可以根据从数据中获得的信息，为此开发自己的编码。例如，假设你正在分析销售数据。你有三种产品。给第一种产品分配数字1，第二种分配2，第三种分配3。

- 3) 完成之后，开始建立一个良好的系统来对它们进行分组。如果你处理的是真实的人类回答（这很有可能），或者只是产品，你可能希望通过给它们加上一些数字或字母来保护机密性。你应该尽量把所有分组放在文档中不同的工作表中，如果使用同一工作表，则放在不同的列和行中。你要确保在分析之前，人员或物品已被正确地分组在一起。

- 4) 此时，检查所有内容是否有错误。有时，当你输入数据并复制各种项目时，你可能没有检查主文件。你应该定期这样做，因为有些人弄混数字或把它们放错位置并非闻所未闻，而如果发生这种情况，你的数据就会变得无用。不要那样做，而应在继续之前检查。

- 5) 现在，你可以通过进行 t 检验来比较各种测试。这些通常用于比较这些样本的平均值。你可以使用单样本 t 检验来确定该做什么，以查看它落在哪个值上。你可以使用双样本 t 检验来检验各组是否不同。例如，你可以在产品制造中使用单样本 t 检验来查看数值，从而看出差异；但如果你进行的是临床研究，可以试试双样本 t 检验。

- 6) 你现在可以使用 ANOVA 来查看各组的各种结果，以便比较这些组的均值。它通常用于生物医学领域，但也适用于任何类型的组。如果你使用单因素方差分析（one-way ANOVA），可以用它来比较多个组与对照组的均值。你可以使用双因素方差分析（two-way ANOVA）来比较各组之间的不同均值。如果你有多种具有不同变量的产品，或者你正在比较不同员工的绩效和工作时间与公司当周结果的关系，就可以使用这种方法。

- 7) 你现在可以使用线性回归来查看因变量的变化，而因变量基本上是另一个变量所依赖的对象。该检验用于检查这两个变量之间的强度关系，比如你也许在看销售速度与产品交付速度之间的关系，在这种情况下，你会选择使用线性回归。

- 8) 从这一点出发，你使用 ANCOVA（协方差分析）来比较两个不同组与你所研究的同一变量之间的关系。这将让你能够控制自变量与两个组之间变异的差异。你可以用它来检查两组产品在不同时间是否具有相同的销售率。你将需要使用两条不同的线性回归线来观察这一点，所以在继续之前，请确保你保留这一点。

- 9) 现在，你可以查看其他类型的数据收集网站，例如 OHLP 以及其他可以帮助你的统计收集网站。外面有很多检验方法，虽然其中有一些常见的，但这些检验也有变体，而

可能最适合你的数据。你应该上网查找，或者寻找其他类型的软件来帮助处理这件事。

- 10) 接下来，你要定义研究问题。你绝不应偏离正在进行的研究或分析，并且要确保坚持既定的研究及其变量。你应确保收集能回答问题的正确数据，并且在处理这些数据时，你会开始看到答案。
- 11) 此时，最好也让另一个人参与进来。现在，有了大数据统计，事情会很快变得非常复杂，尤其是当数据集庞大且不变时。借助这些数据的仪表盘，你将实时获取它们，并确保在继续之前与了解统计的人交谈并进行咨询，以便确保做出正确的决定。你应查看是否需要改变某些事情、是否有某个领域被忽视了，等等，因为你不希望做出可能让你前功尽弃的错误决定。
- 12) 现在，从这里开始，你就可以实施行动了。根据分析选择你已经采取的行动，无论是撤下某款产品、实施新的销售活动，还是解雇某人。然后，你应运行测试，看看情况如何。
- 13) 现在，你可以回到这一步，将新数据输入数据仓库，取出过去的数据进行比较，并由此做出进一步的决策。

有时，你甚至可以处理更多数据和图表，以便更好地可视化事物，并为此获得高质量图表。你应确保在做出最终决定之前，所有这些都已就位，从而尽可能做出最佳决定。

- 14) 你应确保，如果遇到相似的数据，就将其归组在一起。如果不这样做，你最终可能会忽略它，所以务必花时间着手做这件事。
- 15) 从这里开始，你可以按需使用其他软件和测试，但并非必须如此。只需继续观察模式和趋势，对这些不同数据点进行回归建模，并由此继续就手头的数据决定该怎么做。

面对各种各样的大数据及其分析，要掌握它可能相当困难。不过，本章向你进一步展示了如何利用大数据来提高效率，以及如何将它用于你个人的成功与福祉。

## 第 6 章：如何利用社交媒体、软件和其他工具维持业务发展

既然你已经对大数据以及如何进行数据分析有了一些了解，现在是时候谈谈你可以获得的其他帮助形式了。这里有软件，也有社交媒体和其他工具的形式。本章将介绍它们是什么、它们如何提供帮助，以及何时使用它们。

### 助力成功的软件

所提供信息中的。

- **ELKI:** 这是另一种数据挖掘框架，同样支持 Java，包含数据挖掘可视化和与之配套的功能。
- **KNIME:** 即 Konstanz Information Miner（康斯坦茨信息挖掘器）。这是一种用户友好的综合性数据分析框架，可让你执行数据分析，以发现各种问题。
- **MEPX:** 这是一个跨平台工具，可让你将其用于回归和各种分类问题。
- **Orange:** 这是一种可视化编程工具，提供交互式数据可视化，让你既能查看其中提供的信息，也能获得分析统计数据、进行各种数据挖掘以及各种机器学习的方法。
- **QSoas:** 这是一个命令驱动程序，用于分析各种数据，以去除噪声、校正基线、将数据拟合到全局解中，并使用涉及动力学等各种方案的微分方程，等等。如果你需要，也有可用于 Mac 和 Windows 的二进制文件。
- **R:** 这是一个程序，同时也是一种语言软件，用于在计算中计算各种统计量，并配有各种图形工具。
- **ROOT:** 这是由 CERN 开发的 C++ 数据分析框架。
- **Dotplot:** 这是一个基于云的视觉设计器，可在云盘上运行，以便为呈现给它的数据创建分析和可视化模型。
- **DevInfo:** 这是一个由 UNDG 支持的数据库，用于查看和检查人类发展情况。这是一种出色的数据分析软件和工具，可用于帮助人们审视人类发展的各个方面。

你在这里看到的所有这些软件和工具都可以安装到计算机中，以帮助分析数据。通过使用它们，你将更容易为各种问题寻找可行的解决方案，并由此制定必要的解决方案，以帮助从即将产生的统计分析中生成更好的结果。

现在，对于软件，你必须确保它足够强大，能够安装到计算机上。你应确保你的计算机有运行这类软件的能力；如果没有，就买一台能运行的计算机。通过数据分析和这里提到的工具，它可以帮助你弄清自己需要什么。这些软件都是免费的，因此你不必付费；由此你就能确定这类分析会带来什么样的结果。

至于工具，其实这里已经列出了这些工具；但如果你发现任何其他类型的数据计算工具，那些总是好的。工具实际上只是有助于扩大整体数据覆盖范围；一般来说，如果你想进一步理解一家公司的各种细微之处，或者想更深入了解你看到的一组统计数据，那么它们是很好的资源。

### 社交媒体

如今，社交媒体是建立企业的另一个重要部分，不仅因为一切都公开在那里，还因为随之而来的分析功能。如今人们使用社交媒体来进行数据分析，原因有几个。

首先，你在社交媒体上发布的每一件事的所有信息都摆在那里。现在，产品和诸如此类的东西可能没问题，但如果你真的想看看公司的进展，你就得查看分析数据。

借助数据分析，你将能够查看你的页面在过去一个月左右内的流量和表现。你可以总体查看你呈现出的表现，并看出情况是变好了还是变差了。你可以看到你的页面触及了多少人，有多少人点击了各种广告之类的内容，以及有多少人愿意关注你。这些统计数据也许意义不大，但也可能很有意义。

例如，如果你从某人那里获得了某种特定的提及，并且假设仅这次提及就给你带来了比如二十个关注者，你就会由此意识到，正确的做法是继续与那个人合作。也许你聘请了一个新人来代表你的公司展示产品，或者为你的服装品牌聘请了一位新模特。如果你这样做，并且假设情况突然开始猛增，你就能查看数据，看出它来自哪里、还有哪些其他变量和因素，并由此继续采用成功的做法。本质上，这将让你继续采用那些显然为你自己、也为他人创造有益成果的成功做法。

借助社交媒体，你将有机会真正进行深入分析；在许多情况下，你甚至可以回溯，我知道尤其是 Facebook，

你将能够至少回溯几个月，最多一年，查看该页面如何发展，以及情况如何变得更好。归根结底，它当然可以成为帮助你的东西，到那时，你将能够真正获得更好的体验。

借助社交媒体和所有这些其他工具，审视你的业务并利用分析真正改变它，从未如此容易。对一些人来说，起初可能困难重重，但一旦你开始进行完整的分析，审视你从中究竟获得了什么，并对此采取行动，你就能在现在和未来，以及其他各种社交媒体尝试中，借助这一点取得大得多的成功。
