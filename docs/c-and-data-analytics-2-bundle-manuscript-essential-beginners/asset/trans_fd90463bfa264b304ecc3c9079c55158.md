
这些语句中的每一条不仅用换行分隔，还用分号分隔。你也可以这样做。

```cpp
x=y; y=y+1; add(x,y);
```

仅仅因为分号，其中每一条都会被识别为单独的语句。如此简单的东西竟能产生如此大的影响，这有点令人惊叹。

在这种编程语言中，块将是一组用括号括起来的语句。这些语句是程序因主命令提示符而显示在屏幕上的逻辑实体。例如：

```cpp
{
    cout << "I like Pizza"; //prints I like Pizza
    return 0;
}
```

如上所述，行尾并不是终止符。分号才是唯一终止语句的东西。

## 标识符

现在让我们继续了解程序中的标识符。这些标识符用于标识多种事物，例如块中的类、模块、函数和变量。标识符将是一组字母和数字，你可以用它来命名程序或文件，并且它们必须以字母开头，之后可以包含你想要的任何字母或数字。除了句子中可能见到的标点字符外，不允许其他标点字符作为标识符。你不会看到诸如 @、&、% 或 $ 这样的字符，而且这种编程语言区分大小写。这意味着 YokoOno 不同于 Yokoono、yokoOno 和 yokoono。请确保在你的程序中只对你应该大写的字母进行大写。

## 三字符组

三字符组将是由三个字符组成的序列，只表示一个字符。你会注意到它们，因为它们开头会有两个问号。当一个字符就能起作用时，使用三个字符似乎有点多余，但其背后的原因是为了不让你因字符的含义而混淆程序，因为许多字符很相似。

并非所有编译器都支持三字符组，因为它们容易让人困惑，而且大多数人都尽量避开它们；不过，人们发现，当你记住三字符组后，你在函数中按错符号而出错的概率就会降低。

## 空白

接下来是空白。空白是程序中的空行。有时它们包含注释，这些被称为空行。编译器完全忽略它们。空白描述的是空格、换行、制表符、字符和注释。它只是用来让你的程序看起来更有条理、更易读。

变量/标识符与语句之间至少应有一行空白。

### 程序注释

那么，有时你会想在代码中写一些注释。这些注释很重要，因为它们允许你在代码中留下简短信息，以便之后阅读代码的人能够清楚地了解代码究竟如何运行，并“提示”你试图在代码中实现什么。此外，在代码行中留下备注是提醒自己某处代码可能出错的好方法。通过在代码中加入注释，你使用 // 符号来表示你正在写注释。你可以让注释任意长，只需确保注释结束后跳到下一行，以便程序知道它应该重新开始读取代码。

程序在 // 之后将停止读取，而且这不会影响程序的工作方式。查看代码的其他程序员会看到你写的注释，但当程序执行时，这些注释会被跳过。你可以在程序中添加任意多的注释，但请尽量保持有限，因为它可能开始堵塞代码，使其难以阅读和理解。

程序注释基本上是代码内部的语句。这些语句或注释的存在，是为了帮助使用你代码的其他人理解每个函数的用途。所有编程语言都允许某种类型的注释，但并非所有语言都允许现存的所有注释类型。最常用的是单行注释。这是所有编程语言都允许的。

这些注释是简单的解释性行，用一句简单的话告诉下一位读者其目的是什么。

还有多行注释。这是极少数编程语言允许的。C++ 就是这少数语言之一。有时你有更复杂的解释，需要跨越多行。这在 C++ 中是可行的。

当你使用单行注释时，你会看到它在代码中用 // 写出，并且可以一直延伸到行尾。例如：

```cpp
{
    cout << "that's great"; // prints that's great
    return 0;
}
```

这将最终输出 "that's great"，别无其他。编译器会忽略注释，这样你就可以让其他程序员了解代码的用途，或者你需要对代码做什么。

```cpp
/*All he does at this point is sway from side to side */
```

那将是一个多行注释。如你所见，当你开始新的一行时，你应该在开头放置星号，以向程序表明你仍在写注释，而且下一行确实是空白。编译时它会忽略注释，只显示你希望它显示的内容。

虽然你可以混合使用注释风格，但最好暂时将它们分开，直到你掌握所有内容。
