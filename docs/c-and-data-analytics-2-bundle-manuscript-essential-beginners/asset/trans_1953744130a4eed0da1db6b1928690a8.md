### C++ 的历史
比雅尼·斯特劳斯特鲁普（Bjarne Stroustrup）当时正在撰写博士论文，他决定使用一种名为 Simula 的编程语言。这种语言是计算机时代最早的编程语言之一。然而，它运行非常缓慢且充满缺陷。

斯特劳斯特鲁普提出了“带类的 C”（C with Classes）这一构想。这是一种比 Simula 快得多的编程语言。带类的 C 后来演变为 Cfront，它加快了创建语言的过程。然而，当 C++ 出现后，Cfront 便被甩在了后面，因为 C++ 将编译器加入语言中，使其比当时任何其他编程语言都更简单、更快速易用。

自那以后，该语言不断推出带注释的参考指南和更新，使其更好、更快，甚至更易于使用。《C++ for Dummies》是这门语言的一本热门指南。

C++ 是当今最流行的语言之一。这种语言最适合许多行业，因此与其花大量时间创造一门新语言，他们只是将 C++ 适配到许多

这种编程语言在设计时兼顾了灵活性和速度，因为当时的其他语言太慢，而且只能做一件事，所以每次你想创造新东西时，都需要一门新语言。

你可以用这种语言做许多事情，而且尽管如今已有大量语言存在，这些用途至今仍然非常流行。

- **预打包脚本：** 这些是脚本爱好者和新黑客用来练习编程技巧的东西。由于如今很多人都想走捷径，现成的脚本正是大多数黑客所寻找的，因此这些包需要改进，而它们正是使用 C++ 来实现改进。
- **电子游戏：** 面对现实吧，几乎每个人在人生的某个阶段都会玩电子游戏。无论是成长过程中，还是有了孩子以后，你都会被吸入电子游戏的世界，永远无法逃脱。那些游戏在某种程度上都可以归功于使用了 C++ 语言。如果你热衷于制作游戏，并通过图形为世界带来欢乐，那么学习 C++ 语言绝对是个好主意。
