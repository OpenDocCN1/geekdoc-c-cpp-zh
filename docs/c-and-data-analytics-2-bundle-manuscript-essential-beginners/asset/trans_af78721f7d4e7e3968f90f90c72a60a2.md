

## 数据类型

当你使用任何语言编写程序时，你都必须使用不同的变量。这些变量不过是在编译器内存的某个空间中存储位置而保留的内存值。上面列出的保留关键字在这里也同样有用。虽然关键字有很多，但有七个定义数据类型的基本关键字。

| 类型 | 关键字 |
|---|---|
| 宽字符 | wchar_t |
| 无类型 | void |
| 双精度浮点 | double |
| 浮点 | float |
| 整型 | int |
| 字符 | char |
| 布尔 | bool |

你使用的大多数数据类型都可以通过以下修饰符之一进行修改，以帮助你：

- Long（长）
- Short（短）
- Unsigned（无符号）
- Signed（有符号）

### 变量类型（续）

当你在编程语言中使用变量时，你实际上是在提供一些存储空间，以便程序更容易操作这些数据。你使用的所有变量都会与一个不同的类型相关联，这些类型将决定变量内存的布局和大小，还会设定你能够在该内存空间中存储的值的范围。

变量命名与标识符命名类似。你只能使用字母或下划线作为名称的开头，并且字母区分大小写。但在开头之后，你可以使用任何你想要的数字、字母和字符。

同样，你在这里可以使用的更详细的基本变量包括：

- **wchar_t**：这是宽字符类型。
- **void**：这表示不存在类型。
- **double**：这是一种具有双精度的浮点值。
- **float**：这是一种具有单精度的浮点值。
- **int**：这是一个整数。
- **char**：这通常只占一个字节，是一种整数类型。
- **bool**：它处理的值要么为真，要么为假。

你还可以定义其他类型的变量。这些变量包括指针、数组、引用、枚举、数据结构和类等。

## 创建新行

既然你已经了解了数据类型和修饰符，也知道了如何在程序中添加注释，现在是时候学习如何创建新行了。这是很多编程新手都会遇到的问题。他们把程序在输入中排版得很好，但输出结果仍然挤在一起，非常凌乱。这是因为他们没有正确地创建新行。请记住，空白字符会被忽略，所以你不能只在程序中跳过一个空行，就指望输出中也会跳过一行。你必须向编译器表明你想开始新的一行。这非常重要，因为当你运行程序时，你希望它运行得流畅。你不会想看到类似这样的内容：

试试这个 今天我吃了披萨，还做了数学题。6=(7-1) 这就是我今天学到的。

你可能会更希望看到的是这样的：

试试这个  
今天我吃了披萨，还做了数学题  
6=(7-1)  
这就是我今天学到的

为了做出这种区分，你必须使用正确的函数，因为编程所依赖的正是正确的函数。

要创建换行，你必须使用 endl 函数；它会表示你想要一个换行。如果你不想，甚至不必添加空白字符，不过还是建议添加，因为它能让你的程序更易于人类阅读。

例如，这样：

```cpp
{
    cout << "Try This" << endl;
    cout << "Today I ate Pizza and did Math" << endl;
    cout << "6=(7-1)" << endl;
    cout << "That is what I learned today" << endl;
    return 0;
}
```

看起来比这样好得多：

```cpp
{
    cout << "Try This" << endl; cout << "Today I ate Pizza and did Math" << endl;
    cout << "6=(7-1)" << endl; cout << "That is what I learned today" << endl;
    return 0;
}
```

你能看出这会让读代码的人感到多么困惑吗？你希望自己的代码文件易于阅读，这样如果别人需要修复某些内容，他们就能轻松找到出错的地方。如果所有代码都混杂在一起，他们就不太容易找到任何内容了，不是吗？

你也可以使用 `\n` 来表示换行。这和 endl 是一样的，但输入起来要快得多。你可以使用其中任意一种方法，但请选择一种并坚持下去。

### 测验

设置如下：你应该有一个短语、一个数学问题，然后用上述整数给出该数学问题的答案。你可以自己设定所有变量，想设成什么都可以。

```cpp
#include <iostream>
using namespace std;

int main()
{
    int _ = _;
    int _ = _;
    int _ = _ + _;
    cout << "''" << endl;
    cout << "''" << endl;

```

只需输入你的数字，并确保这些数字加起来结果正确。完成之后，重新运行代码，不要依赖复制粘贴没有整数的代码。这样，你就能对变量以及 C++ 中基本整数运算的操作有一个基本的了解。

### 数组

### 初始化数组

你可以逐个初始化数组，也可以使用一条语句进行初始化。示例：

```cpp
double balance[5] = {1000.0, 2.0, 3.4, 17.0, 50.0};
```

方括号中的数字不能大于你正在使用的元素数量。这意味着，当你的数组名只指定了五个元素时，你不能有六组数字。不过，如果你不指定大小，系统会创建一个大小刚好的数组。你可以这样输入：

```cpp
double balance[] = {1000.0, 2.0, 3.4, 17.0, 50.0};
```

这会创建与上一个示例完全相同的数组，只不过你没有指定数组大小，因此它会被自动创建。相当巧妙。

既然你已经知道如何编写数组，是时候把它应用到实际程序中了。这个程序比之前的程序稍微高级一些，也多了一些元素。你可以在 www.compileonline.com 上查找这些元素。你会看到很多教程，甚至还有一个 PDF 文件可供下载。

下面是为你的程序分配数组的公式。

```cpp
#include <iostream>
using namespace std;

#include <iomanip>
using std::setw;

int main()
{
    int n[10];  // n is an array of ten integers
    // initialize elements of array n to 0
    for (int i = 0; i < 10; i++)
    {
        n[i] = i + 100; // set element at location i to i + 100
    }

    cout << "Element" << setw(13) << "Value" << endl;
    // output each array element's value
    for (int j = 0; j < 10; j++)
    {
        cout << setw(7) << j << setw(13) << n[j] << endl;
    }
    return 0;
}
```

### while 循环

只要某个条件满足，while 循环就会不断重复执行循环。它会在每次重新开始循环时测试该条件，并一直这样执行，直到条件不再为真。
