These comments are simple explanatory lines that tell the next reader what the purpose is in a simple sentence.

There are also multiple line comments. This is one that very few program languages allow for. C++ is one of those few languages. Sometimes you have a more complex explanation, and it needs to span over more than one line. This is possible to do in C++.
