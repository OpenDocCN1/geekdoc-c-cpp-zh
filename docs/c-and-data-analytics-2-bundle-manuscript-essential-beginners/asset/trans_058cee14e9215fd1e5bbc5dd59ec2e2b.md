## 第5章：在 C++ 中使用运算符

对于你计划使用的任何编程语言，学习如何使用运算符都很重要。它们能帮助你告诉程序你想做什么，并能让你处理自己的代码容易得多。在程序中可以使用四种主要类型的运算符，它们各自会以不同方式告诉程序如何行为。你可以在 C++ 语言中使用的一些运算符包括：

- 逻辑运算符
- 算术运算符
- 赋值运算符
- 关系运算符

我们来看看其中一些运算符如何工作，以及你在用 C++ 语言编写代码时如何让它们很好地发挥作用。

### 逻辑运算符

本指南中我们要使用的第一类运算符是逻辑运算符。它们会帮助你比较输入系统的某些部分。你可以使用的一些逻辑运算符包括：

- `||`：这称为逻辑 OR。使用它时，如果你的操作数之一不为零，条件就会为真。
- `&&`：这称为逻辑 AND。如果你有两个操作数且它们都不为零，条件就为真。
- `!`：这是逻辑 NOT。你可以用它反转操作数的状态。因此，如果条件最终为假，这个符号会使其变为真。

### 算术运算符

你可以使用的另一类运算符是算术运算符。它们与在学校里做数学几乎一样。你将告诉程序对提供的信息进行加、减和其他运算。你可以使用的一些算术运算符包括：

- `+`：这是加法运算符，会将你选择的两个操作数相加。
- `-`：这是减法运算符。它会取右侧操作数并从左侧操作数中减去。
- `*`：这个运算符使得在 C++ 语言中进行乘法成为可能。
- `/`：这个运算符帮助你在 C++ 中进行除法。
- `++`：这是递增运算符。它会把操作数的值增加一。
- `--`：这是递减运算符。它会把操作数的值减少一。

### 赋值运算符

赋值运算符让你更容易为变量指定名称，并有助于搜索、保存你正在编写的代码的不同部分等。你可以在 C++ 中使用的一些赋值运算符包括：

- `=`：这个运算符是简单赋值运算符。它会把右侧操作数的值赋给左侧操作数。
- `+=`：这个称为“加 AND”运算符。它会把两个操作数的值相加，然后把它们的和赋给左侧操作数。
- `*=`：这是“乘 AND”运算符。它会把两个操作数相乘，然后把结果赋给左侧操作数。
- `-=`：这个运算符会从左侧操作数中减去右侧操作数的值，然后把差值赋给左侧操作数。
- `/=`：这是“除 AND”运算符。它会用左侧的值除以右侧的值，然后把结果赋给左侧操作数。

### 关系运算符

- `==`：这个运算符会检查两个操作数是否相等。如果相等，条件就为真。
- `>`：这个运算符会检查操作数的值。如果左侧操作数高于右侧操作数，条件就为真。
- `<`：这个运算符基本上与上面的运算符相反。如果你发现左侧操作数的值小于右侧操作数，条件就为真。
- `!=`：这个运算符会检查两个操作数是否相等；如果值不相等，条件就为真。
- `<=`：这个运算符会检查左侧操作数是否小于或等于右侧操作数。如果满足此条件，条件就为真。
- `>=`：这个运算符会检查左侧操作数的值是否大于或等于右侧操作数。如果为真，条件就为真。

## 第6章：帮助 C++ 做出决策

有时你需要程序为你做决定。你可以根据用户输入计算机的信息，以及你决定条件为真需要满足什么，让它以某种方式行动。在这个系统中，决策稍微高级一些，但你会发现它很容易学习，并且会开启许多你可以在 C++ 系统中运用的思路。我们来看看你可以做些什么来帮助系统自行做出决策。

### Switch 语句

在这个系统中，我们要处理的第一种决策是 switch 语句。这些语句很好，因为它们允许你把变量的相等性与一组值（或 case）进行对照检查。你试图检查的变量将与每个 case 进行比较。你可以使用的语法的一个好例子包括：

```
switch (expression) {
    case constant-expression:
        statement(s);
        break; // optional
    case constant-expression:
        statement(s);
        break; // optional

    // you can add in as many of these case statements as you would like

    default: // optional
        statement(s);
}
```

### If 语句

你在程序中最基本的事情之一是创建 if 语句。这些语句基于系统中的真/假概念。如果系统表示输入在你设定的条件下为真，那么程序就会运行你要求它运行的任何内容。例如，你设置系统询问 2 + 2 的答案是什么。如果用户输入的答案是 4，你可以让一条消息显示“答对了！干得好！”

每当用户输入的输入根据你设定的条件最终为真时，你就会看到你选定的语句显示出来。另一方面，如果这个人输入了错误答案，会发生什么？如果他们对上面的问题输入答案 5，那就不正确，系统会认为该答案为假。

由于 if 语句相当基础，你会发现如果这个人输入错误答案，它不会做好准备。在这个阶段，如果他们在上面的示例中输入 4 以外的任何数字，屏幕只会变成空白，什么也不会发生。
