数据分析非常重要，但你可能会想，它究竟是什么，又有什么特别之处。那么，本章将介绍它是什么、为什么重要，以及为什么它对每一家乃至任何企业都必不可少。

首先，想想你在企业中所做的每一个决定。大多数时候，企业中合理、理性的决策都有证据支持，无论这些证据是图表还是类似的东西。商业分析让你能够做到这一点。你可以查看在线分析处理或其他类型的数据，看清事情的发展方向。这将让你能够做出决策。

如果你经营一家咨询公司，也许你正在监控每位顾问承接多少客户，你就能看出哪些员工不达标，谁又做得超出预期。这反过来会阻止有害和糟糕的人进入公司，保护你自己和你周围的人。

同样地，也许你有一个人做得超出预期，应该因为工作努力而获得晋升和加薪。你可以将此作为提拔人员的依据，以统计数据为根据。你可以这样做来保持士气。有时候，如果你不奖励表现好的人，最终会受苦，因为这个人之后就不会那么努力，也会给你带来问题。

但也要从其他方面来看。它甚至可以保护你免受糟糕处境的影响。例如，假设你经营一家银行或信用卡服务。这些公司和企业会随时查看某个人的任何取款和消费。如果他们突然看到从那里取出了大量金钱，这实际上可以成为欺诈的依据。这就是信用卡会被取消的原因，因为他们注意到了问题并采取行动。想想看，你不会想一觉醒来发现余额严重为负吧？这是为了你自己的保护，而这些企业知道这一点。

此外，也许你有一名员工看起来不错，但经过数据分析，你发现他一直在挪用你的资金，而且已经有一段时间了。你可以阻止这种情况发生，甚至在他们突然离开公司、让你一无所有之前抓住他们。

现在，企业也需要它，不仅是为了保护，也是为了他们的产品。假设你有一家销售不同种类服装的线上企业。也许你拥有所有衣物的数据，并发现有些产品比其他产品卖得更多。这些数据分析将让你看到顾客会更多或更少购买哪些产品，你可以据此调整，以免浪费钱。在当今时代，许多这类分析都有仪表板来展示这些数据流，以便你实时查看。

所以，归根结底，核心观念就是你需要数据分析。它对企业的生存至关重要。如果你拒绝付出分析企业的努力，那你就是在白白吃亏。另一方面，妥善传播数据确实不仅能让你的企业成功，还能让你在竞争中脱颖而出。
