现在，你可以选择直接将这段代码输入到编译器中，也可以编写多个代码并保存到计算机上，随时调用，这样就不必每次想修改时都重新输入。你可以使用多种不同类型的文本编辑器。不过，其中一些是特定于设备类型的。这意味着它们只能在你创建它们的设备类型上使用。

你可以使用的文本编辑器包括 OS edit 命令、Brief、EMACS、epsilon、Windows 记事本、vim 或 vi。不过，只有 vim 和 vi 可以跨平台使用。请确保将文件保存为扩展名为 `.c` 或 `.cpp` 的文件。

在考虑使用编译器之前，你应该先在文本编辑器中编写程序的初稿。这是因为一旦你进入编译器，程序出错的可能性会大大增加，而且难以察觉。然而，如果你在文本编辑器中已经将程序排布得整洁清晰，那么在编译器中就不会遇到什么问题。

## C++ 编译器

市面上有许多不同的编译器，其中不少价格相当昂贵。这些编译器是为那些已经精通低级编译器的精英程序员准备的。初学者只需要一个基本的编译器，而大多数这类编译器都是免费的。然而，就像任何免费的东西一样，你必须小心你得到的是什么。市面上糟糕的廉价编译器比优秀的还要多，因此，尽管它们打着免费的旗号，我还是建议你在启动页之外额外购买一些功能。这些附加功能通常也很便宜，所以你不会为此破产。

最流行的编译器之一是 GNU C/C++ 编译器。它最常用于 UNIX 和 Linux 系统中。要检查你是否已经安装了该编译器，请在 UNIX/Linux 应用程序中打开命令行，并输入以下内容：

```shell
$ g++ -v
```

如果编译器已安装，你会在屏幕上看到如下信息：

根本没有任何编译器。

要安装该软件，你可以访问软件的首页 www.mingw.org，并让它引导你前往需要去的地方。安装完成后，你至少应该安装 gcc core、gcc-g++、MinGW runtime 和 binutils，不过如果你愿意，也可以安装更多组件。安装完成后，你就可以在 Windows 的命令行中运行所有 GNU 工具了。

现在你已经把一切设置好并可以运行了，就可以开始进一步学习如何运行程序本身了。

## 基本语法

C++ 不仅可以定义为程序，还可以定义为通过调用其他方法进行集体通信的对象。当你使用 C++ 时，你最需要弄懂以下四件事的含义。

- **类（Class）**——这是一个模板或蓝图，它定义了对象及其支持类型，并描述了对象的行为。这意味着对象会按照其行为及其操作/支持被归类到符合该对象描述的类中。

- **对象（Object）**——对象具有行为和状态。例如，如果你观察一只狗，它就有状态。这些状态可以分为颜色、品种、名字、品种标准（AKC/AKA/APC 注册）。“狗”也表现出某些行为。它们摇尾巴、吠叫、喘气、吃干狗粮，或者只是像块木头一样呆坐着什么也不做。

- **实例变量（Instant Variables）**——这些指的是每个单独的对象。每个对象都有一组独特的变量，这些变量就像对象的指纹一样。这些变量通过对象创建时生成的值分配给对象。

现在你已经了解了编程的四大主要定义，让我们来看一段可以编写并打印出“Try This”的代码。与上面的示例不同，这段代码会更深层次地解释你想要做什么，以及每个函数存在的原因。

```cpp
#include <iostream>
using namespace std;

// main() [这是程序开始执行的地方。]

int main()
{
    cout << "Try This"; // [打印 Try This]
        return 0;
}
```

这个函数可以让你打印任何你想要的内容，而不仅仅是“Try This”这几个字。

现在让我们来分解上述程序的各个部分。这种语言的许多不同方面你都需要考虑。每个方面对于程序的运行都很重要，如果你没有完全执行它们，程序就无法正常运行。

- **头文件（Headers）**——C++ 有很多头文件，它们中的每一个对于你的编程操作来说都是必要的，或者至少是有用的。不过，对于大多数函数来说，你会看到上面提到的 `<iostream>` 头文件。使用头文件时，请确保正确地将它括起来，并在前面加上 `#include`，以提示程序使用该头文件。

- **命名空间（Namespace）**——命名空间是 C++ 较新的添加内容，直到 2011 年的更新中才出现。它们的作用并不大，只是描述要使用哪个命名空间。虽然它们不是必需的，但能避免你在程序函数上产生许多困惑。它仅仅是一种更系统地组织函数的方式。

- **main**——这里是主函数开始的地方。使用 `// main()` 这行是告诉程序开始执行主函数，并启动输出过程。设置主函数命令是必不可少的，否则你的程序既不知道它应该运行什么，也不知道应该在什么时候运行。这行代码在程序内部会被视为单行注释，告诉程序主函数即将开始。

- **int main**——这是函数执行正式开始的地方。如果你不包含这一行，整个过程都会停止，因为你没有引入变量，而没有变量，程序就会迷失方向。

- **cout**——这指示程序在屏幕上显示你想要的输出消息。如果你不加 cout，程序有可能会失败，也可能不会。问题是你不知道是否成功，所以如果你想确保一切顺利运行，一定要加上 cout。

- **return**——这会将值返回为零，并终止函数。它指示程序结束进程，并回到开头。

现在来编译并执行你的第一个正式的 C++ 程序。

首先，你必须知道如何保存文件。打开你选择的文本编辑器，输入上面看到的代码。完成后，点击“另存为”，选择一个容易找到的文件位置。为了便于整理，最好为所有程序建立一个单独的文件夹。将文件保存为 hello.cpp，保存好之后，你应该打开命令提示符，然后进入文件所在的目录。

要让你编译器打开文件，首先输入 `g++ hello.cpp`。然后按回车键，代码就会被正确打开。只要没有任何错误，命令提示符就会生成一个 a.out 可执行文件。要运行该程序，输入 `./a.out`，然后观察编译器的运行结果。在计算机上你从编译器获得的信息包括：

```shell
$ g++ hello.cpp
$ ./a.out
```

### 试一试

确保你以正确的方式输入所有变量，并且记住，这些东西是区分大小写的。如果你没有以正确的方式输入函数，你会发现事情往往会出错。编码的关键在于精确。这种注重细节的个人特质适用于所有编程语言！然而，只要愿意留心，任何人都能做到。

基本函数命令并不是你唯一需要使用的。在构建提示时，还有其他重要的东西，因为它们同样会指示程序执行特定的操作。这些东西包括代码块和分号。
