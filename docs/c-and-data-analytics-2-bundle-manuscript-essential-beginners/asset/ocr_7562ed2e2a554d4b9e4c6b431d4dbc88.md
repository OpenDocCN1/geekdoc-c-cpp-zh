learn about how to create a new line. This is a problem that a lot of new programmers run into. They have their program all nice and laid out in the input, but the output is still really mashed together and really unkempt. This is because they did not properly create a new line. Remember that whitespace is ignored, so you cannot just skip a line, and expect to have a line skipped in your program. You have to indicate to the compiler that you want to start a new line. This is really important, as when you play out your program, you want it to run smoothly. You do not want to see something like this.
