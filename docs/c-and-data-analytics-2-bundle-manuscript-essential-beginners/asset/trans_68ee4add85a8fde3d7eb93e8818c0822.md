|  |  |
|---|---|
| 032uu | //非法：不能重复后缀 |

### 布尔字面量

接下来我们可以讨论的字面量类型是布尔字面量。在 C++ 代码中，你可以使用两种类型。基本上，布尔值会显示为 true 或 false。如果你设定的条件为真，布尔表达式的结果就会为 true。另一方面，如果你设定的条件未满足，你最终会得到一个为 false 的条件。当答案是布尔类型时，所有答案都会是 true 或 false。

### 字符字面量

当你在代码中看到字符字面量时，你会注意到它们用单引号括起来。这些字面量可以很简单，比如用‘x’来告诉命令，也可以长得多。这些是你可以加入代码中的基础内容，能让事情更容易处理。

### 字符串字面量

你可以使用的另一种字面量类型是字符串字面量。这类字面量会用双引号括起来。字符串将包含类似字符字面量的字符，包括通用字符、转义序列和普通字符等选项。你可以通过多种方式使用字符串字面量，包括将一行拆成两行，以及分离内容以便阅读。你可以使用的字符串示例包括：

## 附赠：黑客简史与概述

许多人都听过 C++ 这个名字，但真的不把它当回事。如果你不太精通技术，你可能会以为它指的是一个平庸的字母等级，但事实并非如此。

### 黑客行为

黑客行为并不是一个新概念。只要有任何类型的技术存在，就会有人想办法入侵它们。黑客行为是对从一处发送到另一处的任何技术数据流进行操纵和/或中断。这是通过脚本来完成的。虽然你可以在网上获得预先打包好的脚本，但许多人更喜欢老式的方法，即编写自己的脚本，因为这让他们能更灵活地利用信息做自己想做的事。已经打包设置好的脚本灵活性有限，而且相当显眼。一个真正想要进行黑客攻击的黑客，其目标是保持隐蔽。如果你被抓到，除非你有权限做你正在做的事情，否则你可能会陷入大麻烦。
