# Examples of These Analytics

A big part of understanding data analytics is not just reading about it, but seeing examples of it. This chapter will discuss each of the various types of data analytics, and how they’re used in big businesses.

Prescriptive analytics, as said before, are the most valuable, but it’s not the most used. For example, only 13% of the organizations reporting on this type of data analytics use predictive, but only 3% are using prescriptive.
