
就组件而言，它相当容易学习；如果你掌握了 C++，你就能轻松掌握其他语言。原因在于，当你先学习比其余一切都稍复杂一些的东西时，较容易的内容就会水到渠成；然而，如果你习惯了容易学习的内容，你就会发现较难的内容很难学，因为你不习惯在试图学习的科目上投入那么多精力。

如果你想学习一门能在计算机技术领域内用于不同类型功能的语言，那就把全部时间花在他们确信正确的事情上吧，仅仅因为他们找不到自己错在哪里。

### 就业前景

是的，有很多工作仍然依赖 C++ 来运行。你可以做许多不同的事情，而所有这些都会影响社区中的其他人。电子游戏设计和网页设计是其中最突出的两项。你也可以成为白帽或蓝帽黑客。

但根据 payscale.com（搜索 software engineer），具有 C++ 软件工程师背景的人根据经验最高可赚到 57,000 美元至 120,000 美元。中位数约为 80,363 美元。拥有 C++ 编程语言技能的人还可以担任其他一些职位，如计算机程序员、电气工程师和应用程序开发员。

然而，为了成为最好的自己，你应该始终掌握两到三种编程语言以具备市场竞争力。虽然本书不会包含那些语言，但不要把自己绑定在单一语言上。相反，就像对待人类语言一样，拓宽你的视野，涉猎几种语言，但保留一门作为你的主要语言。

由于其多用途性，C++ 应该成为你赖以依靠的主要语言。也许可以把 JAVA 或 Linux 作为你的其他语言，但 C++ 是最好的主要语言，而你只想要最好的作为主要语言。

C++ 是一种静态类型的底层语言，这意味着它是一种清晰明确、功能广泛的语言。

C++ 是 C 的一个全功能超集，支持面向对象编程。这意味着它支持 OOP 的所有支柱，如封装、数据隐藏、继承和多态。

要了解更多关于面向对象编程的内容，你可以在线快速搜索，并进一步了解它。最好对它是什么有一些了解，但这并不是你掌握 C++ 所不可或缺的知识，因此本书不会真正涉及它，只会在顺带提及和零散信息中略有出现。

### C++ 的三个重要组成部分

标准 C++ 由三个非常重要的概念组成。

- 核心语言：它由该语言的所有变量、数据类型、字面量和其他重要方面组成，构成进入下一层次的构建块
- C++ 标准库：它允许你操作文件以及语言内的其他工作，并让它们服从你的意愿。
- STL：代表标准模板库，它为你提供操作数据结构、变量及其他类似内容的函数。

### 为什么 C++ 被认为是目前最好的语言？

好吧，除了被大量提及的灵活性、速度和简洁性之外，它还是一门已经跨越三十多年、如今仍被广泛使用的语言。在生活的任何领域中，很少有产品能说同样的话。产品和公司来来去去，但只有真正的完美才会留存。嗯，俗话说得好。老实说，自那时以来 C++ 已经有许多更新，但核心流程仍然相同。它刚问世时远远领先于时代，而今天它仍然是一项相当先进的技术，因为更新让它保持领先。

还有很多观点也与为什么 C++ 被认为是最好的语言有关。虽然有很多人说 C++ 不再相关，但更多人担保它仍然是目前最好的语言，并且是他们的备用语言。它是他们最了解的语言，也是他们珍藏在心的语言。原因各不相同，但 90% 的程序员默认选择 C++ 这一事实表明，它确实是当今最好的编程语言。

C++ 是少数完全遵循 ANSI 标准的语言之一，这就是为什么你玩过的一些最好的游戏仍然是用 C++ 编写的。因为它们的编译器被设置为确保所有命令都编写并执行无误。它还可以跨许多不同类型的平台使用，无论你拥有的是 Microsoft、Unix、Mac、Windows 还是 Alpha 设备，都可以使用 C++。这是一件很棒的事，因为许多程序员必须在许多不同平台上操作，而这种通用性使其简单且可移植。只需把你的代码放到闪存盘上，然后上传到任何需要的地方。

### 使用 C++ 语言的好处

使用 C++ 语言时，你将能够享受很多好处。其中一些好处包括：

- 庞大的库：由于 C++ 已经存在很长时间，它拥有一个相当大的库。你可以使用它，从而在脚本中挑选想要的代码，节省一些时间，甚至学到一些新东西。如果你愿意，也可以创建一些自己的代码，但这个库对正在学习的初学者非常有帮助，能让编写代码比以往更容易。
- 与其他语言协同工作的能力：C++ 是一门非常适合与现有其他一些编程语言配合使用的语言。这让你更容易真正开展自己想要的项目，因为你可以加入不同编码语言中你喜欢的部分，并将它们组合在一起，做出真正了不起的东西。
- 适用于许多项目：大多数其他编程语言只会专注于一两个小项目。例如，使用 JavaScript 意味着你只会处理网站。但使用 C++，你能够用它来协助许多不同的项目。无论你是想处理网站、创建新程序，还是用编程做其他事情，都可以借助 C++ 来实现。
- 快速可靠：如果你使用过过去流行的一些其他编码语言，你会发现它们有时并不是最可靠的。信息可能会遗漏，或者它们不会按你希望的方式开始工作。如果你想要第一次就能工作且可靠的东西，那么选择 C++ 是个好主意。
- 提供强大的能力：那些喜欢从事编程工作并希望在工作中拥有强大能力的人会发现，C++ 是他们正确的选择。它在现有编程语言中拥有一些最强大的能力。

这些只是使用 C++ 编程语言时你能享受的少数好处。它使用起来可能比 Python 等其他语言稍难一些，但它拥有你所需的强大能力，并且能够胜任工作。
