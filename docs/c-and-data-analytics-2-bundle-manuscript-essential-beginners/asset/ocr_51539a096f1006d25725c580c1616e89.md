To install this software, you can go to the homepage of the software at www.mingw.org and allow it to direct you to where you need to go. Once you install that you should install gcc core, gcc-g++, MinGW runtime and binutils, at the bare minimum, but you can install more if you would like. Once you are done with the install, you can run all of the GNU tools from the Command line on Windows.
