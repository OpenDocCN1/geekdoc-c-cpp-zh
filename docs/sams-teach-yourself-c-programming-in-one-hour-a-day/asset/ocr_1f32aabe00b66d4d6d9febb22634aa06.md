| Keyword | Description |

| while | Looping statement that executes a section of code as long as a condition remains TRUE. |

| _Bool | A type large enough to store a value of 0 or 1. |

| _Complex | Support for complex types. It is not required that _Complex be supported. |

| _Imaginary | Support for imaginary types. It is not required that _Imaginary be supported. |
