# LESSON 17 Using Disk Files

This might sound a bit complicated, but it's quite simple because of C's use of streams
for input and output. Here are the steps you follow:

+   - Open the source file for reading in binary mode. (Using binary mode ensures that
t function can copy all sorts of files, not just text files.)

+   - Open the destination file for writing in binary mode.

+   - Read a character from the source file. Remember, when a file is first opened,
t pointer is at the start of the file, so there's no position to set the file pointer
explicitly.

+   - If the function feof() indicates that you've reached the end of the source file,
y're finished and can close both files and return to the calling program.

+   - If you haven't reached end-of-file, write the character to the destination file, and
t loop back to step 3.

Listing 17.10 contains a function, copy_file(), that is passed the names of the source\and destination files and then performs the copy operation just as the preceding steps
onlinear. If there is an error opening file, the function doesn't attempt the copy
operation and returns -1 to the calling program. When the copy operation is complete,
the program closes both files and returns 0.
