# Analysis ▼

This program uses the library function ungetc() on lines 32 and 62, which you learned about Lesson 14, “Working with the Screen, Printer, and Keyboard.” Remember that this function “ungets,” or returns, a character to the specified stream. This returned character is the first one input the next time the program reads a character from that stream. This is necessary when the function get_int() reads a nonnumeric character from stdin, you want to put that character back, in case the program needs to read it.

In this program, main() is simple. An integer variable, x, is declared (line 11), assigned the value of the get_int() function (line 12), and printed to the screen (line 14). The get_int() function makes up the rest of the program.

The get_int() function isn't simple. To remove whitespace that might be entered, line 24 loops with a while command. The isspace() macro tests a character, ch, obtained with getchar(). If it is a space, another character is retrieved, until a nonwhitespace character is received. Line 30 checks whether the character is one that can be used. Line 30 could be read, “If the character input isn't a negative sign, a plus sign, a digit, or the end of the file(s).” If this is true, ungetc() is used on line 32 to put the character back, and the function returns to main(). If the character is usable, execution continues.

Lines 39–46 handle the sign of the number. Line 39 checks whether the character entered is a negative sign. If it is, a variable (sign) is set to -1. sign is used to make the number either positive or negative (line 56). Because positive numbers are the default, after you have taken care of the negative sign, you are almost ready to continue. If a sign is entered, the program must get another character. Lines 45 and 46 take care of this.
