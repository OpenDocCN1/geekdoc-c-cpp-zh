# Using Multidimensional Arrays

A multidimensional array has more than one subscript. A two-dimensional array has two subscripts, a three-dimensional array has three subscripts, and so on. There is no limit to the number of dimensions a C array can have. (There is a limit on total array size, as discussed in this lesson.)

For example, you might write a program that plays checkers. Your checkerboard contains 64 squares arranged in eight rows and eight columns. Your program could represent the board as a two-dimensional array, as follows:

```
int checker[8][8];
```

The resulting array has 64 elements: checker[0][0], checker[0][1], checker[0][2]...checker[7][6], checker[7][7]. The structure of this two-dimensional array is illustrated in Figure 8.3.

FIGURE 8.3 A two-dimensional array has a row-and-column structure.

```
int checker[8][8];
```

| checker[0][0] | checker[0][1] | checker[0][7] |
|---|---|---|
| checker[1][0] | checker[1][1] | checker[1][7] |
| checker[2][0] | checker[2][1] | checker[2][7] |
| checker[7][0] | checker[7][1] | checker[7][7] |

Similarly, a three-dimensional array could be thought of as a cube. Four-dimensional arrays (and higher) are probably best left to imagination. No, matter how many dimensions they have, they are stored sequentially in memory. More detail on array storage is presented in Lesson 15, "Pointers to Arrays of Pointers."

# Naming and Declaring Arrays

The rules for assigning names to arrays are the same as for variables, covered in Lesson 3, "Storing Information: Variables and Constants." An array name must be unique. It cannot be used for another array or any other identifier (variable, constant, and so on). As you have probably realized, array declarations follow the same form as variable declarations, except that the number of elements in the array must be enclosed in square brackets following the array name.

When you declare an array, you can specify the number of elements with a literal constant (as was done in the earlier examples) or with a symbolic constant created with #define directive. Thus the following

```c
#define MONTHS 12
int array[MONTHS];
```

is equivalent to this statement:

```c
int array[12];
```

With most compilers, however, you cannot declare an array’s elements with a symbolic constant created with const keyword:

```c
const int MONTHS = 12;
int array[MONTHS]; /* Wrong! */
```

# Storing the Point Totals of Five Players in Four Games in a Two-Dimensional Array

```c
// stats.c: Using a two-dimensional array to store basketball point totals
#include <stdio.h>
#define PLAYERS 5
#define GAMES 4
int scores[6][5];
float score_avg[6], best_avg;
int point_total, best_player;
int counter1, counter2;

int main() {
    // The outer loop is for each of the games
    for (counter2 = 1; counter2 <= GAMES; counter2++) {
        printf("\nGetting totals for Game #%d.\n", counter2);
        // The inner loop is for each player in the specific game.
        for (counter1 = 1; counter1 <= PLAYERS; counter1++) {
            printf("What did player %d score in the game? ", counter1);
            scanf("%d", &scores[counter1][counter2]);
        }
    }

    // Loop through the array to calculate scoring average per player
    for (counter1 = 1; counter1 <= PLAYERS; counter1++) {
        point_total = 0;
        for (counter2 = 1; counter2 <= GAMES; counter2++) {
            point_total += scores[counter1][counter2];
        }
        score_avg[counter1] = (float)point_total/GAMES;
    }

    // Loop now through and store who has the best scoring average
    for (counter1 = 1; counter1 <= PLAYERS; counter1++) {
        if (score_avg[counter1] > best_avg) {
            best_avg = score_avg[counter1];
            best_player = counter1;
        }
    }

    printf("\nPlayer #%d had the best scoring average,\n", best_player);
    printf("at %.2f points per game.\n", score_avg[best_player]);

    return(0);
}
```
