# 312 LESSON 13 Advanced Program Control

The switch statement is demonstrated in Listing 13.5, which displays a message based on the user's input.

# Input
LISTING 13.5 switch1.c: Using the switch Statement

```
1: /* switch1.c--Demonstrates the switch statement. */
2:
3: #include <stdio.h>
4:
5: int main( void )
6: {
7:     int reply;
8:
9:     puts("Enter a number between 1 and 5:");
10:    scanf("%d", &reply);
11:
12:    switch (reply)
13:    {
14:        case 1:
15:             puts("You entered 1.");
16:        case 2:
17:             puts("You entered 2.");
18:        case 3:
19:             puts("You entered 3.");
20:        case 4:
21:             puts("You entered 4.");
22:        case 5:
23:             puts("You entered 5.");
24:        default:
25:             puts("Out of range, try again.");
26:    }
27:
28:    return 0;
29: }
```

# Output

Enter a number between 1 and 5:
2
You entered 2.
You entered 3.
You entered 4.
You entered 5.
Out of range, try again.
