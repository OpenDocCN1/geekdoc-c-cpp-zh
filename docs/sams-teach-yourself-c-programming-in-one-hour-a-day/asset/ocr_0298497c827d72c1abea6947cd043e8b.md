This program has a function, func(), on lines 17 through 23, that defines and initializes one static variable and automatic local variable. The main() function on lines 4 through 15 contains a for loop (lines 8 through 12) that prints a message (line 10) and then calls func() (line 11). The for loop iterates 20 times.

In the output, note that x, the static variable, increases with each iteration it retains its value between calls. The automatic variable y, on the other hand, is reinitialized to 0 with each call and therefore does not increment.

This program also illustrates the difference in the way explicit variable initialization is handled (that is, when a variable is initialized at the time of definition). A static variable is initialized only the first time the function is called. At later calls, the program remembers the variable has already been initialized and therefore doesn't reinitialize. Instead, the variable retains the value it had when execution exited the function. In contrast, an automatic variable is initialized to the specified value every time the function is called.
