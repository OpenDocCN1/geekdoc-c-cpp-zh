# Q Is the following header also acceptable when using main() with command-line parameters?

```
main(int argc, char **argv);
```

A You can probably answer this one on your own. This declaration uses a pointer to a character pointer instead of a pointer to a character array. Because an array is a pointer, this definition is virtually the same as the one presented in this lesson. This declaration is also commonly used. (See Lesson 8, “Using Numeric Arrays,” and Lesson 10, “Working with Characters and Strings,” for more details.)
