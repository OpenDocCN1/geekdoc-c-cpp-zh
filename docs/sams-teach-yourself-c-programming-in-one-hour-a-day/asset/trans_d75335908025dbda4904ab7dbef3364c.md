# 分析 ▼

该程序采用从第 16 行开始的无限循环，持续执行直到输入 0 为止。当输入非零值时，它会被传递给 func1()。注意 func1() 中的第 32 行包含了一个指向函数的指针 `ptr` 的声明。在函数内部进行声明使得 `ptr` 成为 func1() 的局部变量，这是合适的，因为程序的其他部分不需要访问它。func1() 使用该值将 `ptr` 设置为适当的函数（第 34 到 39 行）。第 41 行对 ptr() 调用了相应的函数。

当然，这个程序只是为了说明。你可以不使用函数指针来实现相同的结果。
