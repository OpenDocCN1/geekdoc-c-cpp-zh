scanf() format string is matched with an input field; the end of each input field is identified by white space.

This gives you considerable flexibility. In response to the preceding scanf(), you could enter

10 12.45

You could also enter this:

10 12.45

or this:

10 12.45

As long as there's some white space between values, scanf() can assign each value to its variable.

> CAUTION Be careful when setting up scanf(). If you are looking for a character and the user enters a number, or if you are looking for a number and the user enters a character, then your user might see unexpected results.
