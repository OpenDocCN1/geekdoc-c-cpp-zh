# Handling Extra Characters

Input from scanf() is buffered; no characters are actually received from stdin until the user presses Enter. The entry of characters "arrives" from stdin, is processed, in order, by scanf(). Execution returns from scanf() only when input has been received to match the specifications in the format string. Also, scanf() processes only needed characters from stdin to satisfy its format string. Extra, unneeded characters, if any, remain in stdin. These characters can cause problems. A closer look at the operation of scanf() to see.

When a call to scanf() is executed and the user enters a single line, you have three situations. For these examples, assume that scanf("%d %d", &x, &y) being executed; in other words, scanf() is expecting two decimal integers. Here are the possibilities:

+   - The line user enters matches the format string. For example, suppose the user enters 12 followed by Enter. In this case, there are no problems. scanf() is satisfied, and no characters are left over in stdin.
- The line that the user has too few elements to match the format string. For example, suppose the user enters 12 followed by Enter. In this case, scanf() continues to wait for the missing input. After the input is received, execution continues, and no characters are left over in stdin.
- The line that the user enters more elements than requested the format string. For example, suppose the user enters 12 14 16 followed by Enter. In this case, scanf() reads the 12 and the 14 and then returns. The extra characters, the i and 6, are left waiting in stdin.
