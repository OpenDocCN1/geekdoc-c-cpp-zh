Here is the code to perform this task:

```
new = (person*)malloc(sizeof(struct person));
new->next = head;
head = new;
```

Note that malloc() is typecast so that its return value is the proper type—a pointer to the person data structure.

# CAUTION

It's important to switch the pointers in the correct order. If you reassign the head pointer first, you will lose the list!
