# Arrays of Structures

example, in a program to maintain a list of phone numbers, you can define a structure to hold each person's name and number:

```
struct entry
{
    char fname[10];
    char lname[12];
    char phone[12];
};
```

A phone list must hold many entries, so a single instance of the entry structure isn't of much use. What you need is an array of structures of type entry. After the structure has been defined, you can declare an array of structures as follows:

```
struct entry list[1000];
```
