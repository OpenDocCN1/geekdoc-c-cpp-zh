# Output ▼

The first average is 5.500000.
The second average is 87.800000.

# Analysis ▼

The function average() is first called on line 12. The first argument passed, the only fixed argument, specifies the number of values in the variable list. In the function, as each argument in the variable list is retrieved on lines 32–33, each argument is added to the total. After all arguments have been retrieved, line 43 casts total as type float and divides total by num to obtain the average.
