# Analysis

The list_it.c program in Listing 2.2 displays C programs that you have saved. These listings display on the screen with line numbers added.

Looking at this list, you can summarize where the different parts are. The required main() function is in lines 8 through 32. Lines 2 and 3 have `#include` directives. Lines 6, 10, and 11 have variable definitions. Line 4 defines a BUFF_SIZE as 256, the stand size for buffers. The value to doing this is that if the buffer size changes, you only need to adjust this one line and all lines using will automatically update. If you hardcode a number like 256, you'd have to search all your lines of code to make sure you caught all mentions.

A prototype, `void display_usage(void)`, is in line 5. This program has many statements (lines 13, 15, 16, 19, 21, 22, 25, 27, 28, 30, 31, and 37). A function definition for `display_usage()` fills lines 34 through 38. Braces enclose blocks throughout the program. Finally, only line 1 has a comment. In most programs, you should probably include more than one comment line.

list_it.c calls many functions. It calls only one user-defined function, `display_usage()`. The library functions that it uses `fopen()` in line 19; `printf()` in lines 21, 28, 36, and 37; `fgets()` in line 27; and `fclose()` in line 30. These library functions are covered in more detail throughout this book.

# Summary

This lesson was short, but it's important because it introduced you to the major components of a C program. You learned that the single required part of every C program is the `main()` function. You also learned that a program's real work is done by program statements that instruct the computer to perform your desired actions. You were also introduced to variables and variable definitions, and you learned how to use comments in your source code.

In addition to the `main()` function, a C program can use two types of subsidiary functions: library functions, supplied as part of the compiler package, and user-defined functions, created by the programmer.
