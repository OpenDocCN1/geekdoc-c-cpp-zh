# Initializing Structures

Like other C types, structures can be initialized when they're declared. This
procedure is similar to that of initializing arrays. The structure declaration is followed
an equal sign and a list of initialization values separated by commas and enclosed in
braces. For example, look at the following statements:

```
1: struct sale {
2:     char customer[20];
3:     char item[20];
4:     float amount;
5: } mysale = {
6:     "Acme Industries",
7:     "Left-handed widget",
8:     1000.00
9: };
```
