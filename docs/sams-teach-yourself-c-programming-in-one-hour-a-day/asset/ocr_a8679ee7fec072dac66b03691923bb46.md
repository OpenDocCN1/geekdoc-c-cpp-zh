# Controlling Output to the Screen

The field-width specifier determines the minimum number of characters output.
field-width specifier can be the following:

+   - A decimal integer not starting with 0. The output is padded on the left with spaces to fill the designated field width.
- A decimal integer starting with 0. The output is padded on the left with zeros to fill the designated field width.
- The * character. The value of the argument (which must be an int) is used as the field width. For example, if w is a type int with a value of 10, the statement printf("%*d", w, a); prints the value of a with a field width of 10.

If no field width is specified, or if the specified field width is narrower than the output, the output field is just as wide as needed.

The last optional part of the printf() format string is the flag, which immediately follows the % character. There are four available flags:

+   - This means that the output is left-justified in its field rather than right-justified, which is the default.
- This means that signed numbers always display with a leading + or -
- A space means positive numbers are preceded by a space.
- This applies only to x, X, and conversion characters. It specifies that nonzero numbers display with a leading 0x or 0X (for x and X) or a leading 0 (for o).

When you use printf(), the format string can be a literal enclosed in quotes in the printf() argument list. It can also be a null-terminated string stored in memory, which you pass a pointer to the string to printf(). For example, this statement

```
char *fmt = "The answer is %f.";
printf(fmt, x);
```

is equivalent to this statement

```
printf("The answer is %f.", x);
```

For example, the newline sequence (\n) in a format string causes subsequent output to appear starting on the next line.
