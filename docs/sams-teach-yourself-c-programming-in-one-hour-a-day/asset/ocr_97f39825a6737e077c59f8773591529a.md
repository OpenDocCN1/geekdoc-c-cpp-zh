# Using Structures That Are More Complex

You access individual elements of arrays that are structure members using a combination of the member operator and array subscripts:
record.x[2] = 100;
record.y[1] = 'x';

You probably remember that character arrays are most frequently used to store strings.
You should also remember (from Lesson 9, “Understanding Pointers”) that the name of an array, without brackets, is a pointer to the array. Because this holds true for arrays that are structure members, the expression
record.y

is a pointer to the first element of array y[] in the structure record. Therefore, you could print the contents of y[] onscreen using the statement
puts(record.y);
