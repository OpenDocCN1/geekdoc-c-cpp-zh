
```c
struct tm {
    int tm_sec;   // seconds after the minute - [0,59]
    int tm_min;   // minutes after the hour - [0,59]
    int tm_hour;  // hours since midnight - [0,23]
    int tm_mday;  // day of the month - [1,31]
    int tm_mon;   // months since January - [0,11]
    int tm_year;  // years since 1900
    int tm_wday;  // days since Sunday - [0,6]
    int tm_yday;  // days since January 1 - [0,36]
    int tm_isdst; // daylight savings time flag
};
```

## The Time Functions

This section describes the various C library functions that deal with time. Remember that the *term refers to the date as well as hours, minutes, and seconds. A demonstration program follows the descriptions.

## Obtaining the Current Time

To obtain the current time on your system's internal clock, use the `time()` function. The prototype is

```c
time_t time(time_t *timeptr);
```

Remember, `time_t` is defined in `time.h` as a synonym for `long`. The function `time()` returns the number of seconds elapsed since midnight, January 1, 1970. If it is passed a non-NULL pointer, `time()` also stores this value in the `time_t` variable pointed to by `timeptr`. Thus, to store the current time in the type `time_t` variable `now`, you could write

```c
time_t now;
now = time(0);
```

You also could write

```c
time_t now;
time_t *ptr_now = &now;
time(ptr_now);
```

## Converting Between Time Representations

Knowing the number of seconds since January 1, 1970, is often useful. C provides the capability to convert time represented as a `time_t` value to a `tm` structure using the `localtime()` function. A `tm` structure contains day, month, year, and other information in a format more appropriate for display. The prototype of this function is

```c
struct tm *localtime(time_t *ptr);
```

This function returns a pointer to a static `tm` structure, so you don't need to declare a type `tm` structure to use it—this static structure is overwritten each time `localtime()` is called. The reverse conversion—from a `tm` structure to a type `time_t`—is performed by the function `mktime()`. The prototype is

```c
time_t mktime(struct tm *time);
```

## Displaying Times

To convert times into strings for display, use the functions `ctime()` and `asctime()`. Both return the time as a string with a specific format, whereas `asctime()` is passed the time as a type `tm` structure. Their prototypes are

```c
char *asctime(struct tm *ptr);
char *ctime(time_t *ptr);
```

Both functions return a pointer to a static, null-terminated string that gives the time in the following format: `Thu Jun 13 10:22:23 1991`. The time is formatted in 24-hour “military” time. For more control over the format of time, use the `strftime()` function. This function is passed the type `tm` structure, formats the time to a null-terminated string, and the argument `max` should specify the amount of space. The prototype is

```c
size_t strftime(char *s, size_t max, const char *fmt, struct tm *ptr);
```

If the resulting string (including the terminating null character) has more than `max` characters, the function returns 0, and the string is invalid. Otherwise, the function returns the number of characters written—strlen(s)`.

## Calculating Time Differences

You can calculate the difference, in seconds, between two times with the `difftime()` macro, which subtracts `time_t` values and returns the difference. The prototype is

```c
double difftime(time_t later, time_t earlier);
```

This function subtracts earlier from later and returns the difference, number of seconds between the two times. A common use of `difftime()` is to calculate elapsed time, as demonstrated (along with other time operations) in Listing 20.2.

You can determine the duration of a different sort using the `clock()` function, which returns an amount of time that has passed since the program started execution, in 1/100-second units. The prototype is

```c
clock_t clock(void);
```

To determine the duration of some portion of a program, call `clock()` twice—before and after the process occurs—subtract the two return values.

## Using the Time Functions

Listing 20.2 demonstrates how to use the C time functions.

### LISTING 20.2 whtime.c: Using the C Library Functions

```c
#include <stdio.h>
#include <time.h>

int main( void )
{
    time_t start, finish, now;
    struct tm *ptr;
    char *c, buf[80];
    double duration;

    /* Record the time program starts execution. */
    start = time(0);

    /* Record the current time, using the alternate method of calling time(). */
    time(&now);

    /* Convert the time_t value into a tm structure. */
    ptr = localtime(&now);

    /* Create and display a formatted string containing the current time. */
    c = asctime(ptr);
    puts(c);
    getc(stdin);

    /* Now use the strftime() function to create several formatted versions of the time. */
    strftime(buf, 80, "This is %U of the year %Y", ptr);
    puts(buf);
    getc(stdin);

    strftime(buf, 80, "Today is %A, %x", ptr);
    puts(buf);
    getc(stdin);

    strftime(buf, 80, "It is %M minutes past hour %I.", ptr);
    puts(buf);
    getc(stdin);

    /* Now get the current time and calculate program duration. */
    finish = time(0);
    duration = difftime(finish, start);
    printf("\nProgram execution time using time() = %f seconds.", duration);

    /* Also display program duration in hundredths of seconds using clock(); */
    printf("\nProgram execution time using clock() = %ld hundredths of sec.", clock());
    return(0);
}
```
