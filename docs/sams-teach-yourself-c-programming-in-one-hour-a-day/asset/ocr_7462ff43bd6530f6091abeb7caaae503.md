# Concatenating Strings

If you're not familiar with the term concatenation, you might be asking, "What is it?" and "Is it legal?" Well, it means to join two strings—to tack one onto the end of another—and, in most states, the C standard library contains two concatenation functions—strcat() and strcat()—both of which require the header file string.h.

# Using the strcat () Function

The prototype of strcat(char *str1, const char *str2);

The function appends a copy of str2 onto the end of str1, moving the terminating null character to the end of the new string. You must allocate enough space for str1 to holding the resulting string. The return value of strcat() is a pointer to str1. Listing 18.4 demonstrates strcat().

LISTING 18.4 strcat.c:Using strcat() to Concatenate function.

```

#include <stdio.h>
#include <string.h>

char str1[27] = "a";
```
