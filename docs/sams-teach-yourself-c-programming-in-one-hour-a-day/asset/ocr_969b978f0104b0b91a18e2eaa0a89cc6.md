# Q&A

A Most compilers come with many useful functions that aren't ANSI-Standard. If you plan on always using that compiler and not porto your code to other compilers or platforms, there won't be a problem. If you use other compilers and platforms, you would be concerned with ANSI compatibility.

Q Why shouldn't I always use printf() instead of sprintf()? Or scanf() instead of scant()?

A If you use the standard output or input streams, you should use printf() and scanf(). By using these simpler functions, you don't have to bother with any other streams.
