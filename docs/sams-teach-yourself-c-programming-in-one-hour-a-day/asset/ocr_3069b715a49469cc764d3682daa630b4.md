# Passing Structures as Arguments to Functions

Like other data types, a structure can be passed as an argument to a function. Listing 11.6 shows how to do this. This program is a modification of the program shown in Listing 11.3. It uses a function to display information on the screen that is passed in, whereas Listing 11.3 uses statements that are part of main().
