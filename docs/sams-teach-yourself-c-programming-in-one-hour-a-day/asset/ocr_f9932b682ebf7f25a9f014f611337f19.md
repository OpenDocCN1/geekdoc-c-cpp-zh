# Writing and Reading File Data

A program that uses a disk file can write data to a file, read data from a file, or a
combination of the two. You can write to a disk file in three ways:

+   - You can use formatted output to save formatted data to a file. You should use
formatted output with text-mode files. The primary use of formatted output is
to create files containing text and numeric data to be read by other programs such
as spreadsheets or databases. You, if ever, use formatted output to create a
file to be read again by a C program.
 You can use character output to save single characters or lines of characters to a
file. Although technically it's possible to use character output with binary-mode
files, it can be tricky. You should restrict character-mode output to text files. The
main use of character output is to save (but not numeric) data in a form that
be read by C, as well as other programs such as word processors.
 You can use direct output to save the contents of a section of memory directly to a
d file. This method is for binary files only. The direct output is the way to save
data for later use by a C program.

When you want to read data from a file, you have the same three options: formatted
input, character input, or direct input. The type of input you use in a particular case
dends almost entirely on the nature of the file being read. Generally, you read data in
t same mode that it was saved, but this is not a requirement. However, reading a file
a mode different from the one it was written in requires a thorough knowledge of C
and formats.
