# How a Function Works

A C program doesn't execute the statements in a function until the function is called by another part of the program. When a function is called, the program can send the function information in the form of one or more arguments. An argument is program data sent to the function. This data can be used by the function to perform its task. The statements in the function then execute, performing whatever task each was designed to do. When the function's statements finish, execution passes back to the same location in the program that called the function. Functions can send information back to the program in the form of a return value.

Figure 5.1 shows a program with three functions, each of which is called once. Each time a function is called, execution passes to that function. When the function finishes, execution passes back to the place from which the function was called. A function can be called as many times as needed, and functions can be called in any order.
