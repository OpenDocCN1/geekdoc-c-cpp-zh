# The getch() Function

The getch() function obtains the next character from the stream stdin. It provides unbuffered character input without echo. The getch() function isn't part of the ANSI Standard. This means that it might not be available on every system. In addition, it might require different header files be included. Generally, the prototype for getch() is in the header file conio.h, as follows:

```
int getch(void);
```

Because it is unbuffered, getch() returns each character as soon as the key is pressed, without waiting for the user to press Enter. Because getch() doesn't echo its input, the characters aren't displayed onscreen. Listing 14.4 illustrates the use of getch().

Listing 14.4 uses getch(), which is not ANSI-compliant. You should be careful when using non-ANSI functions because there is no guarantee that all compilers support them. If you get errors from Listing 14.4, it might be because your compiler doesn't support getch().
