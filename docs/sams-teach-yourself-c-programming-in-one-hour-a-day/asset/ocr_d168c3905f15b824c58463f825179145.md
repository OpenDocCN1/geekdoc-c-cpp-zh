You have used several library functions, such as `printf()` and `scanf()`, that take a variable number of arguments. You can write your own functions that take a variable argument list. Programs that have variable argument lists must include the header file `stdarg.h`.

When you declare a function that takes a variable argument list, you first list the fixed parameters—those that are always present. (There must be at least one parameter.) You then include an ellipsis (...) at the end of the parameter list to indicate that zero or more arguments are passed to the function. During this discussion, remember the distinction between a parameter and an argument, as explained in Lesson 5, “Packaging Code in Functions."

How does the function know how many arguments have been passed to it on specific call? You tell it. One of the fixed parameters informs the function of the total number of arguments. For example, when you use the `printf()` function, the number of conversion specifiers in the format string tells the function how many additional arguments to expect. More directly, one of the function's fixed arguments can be the number of additional arguments. The example you see in this uses approaches, but first you need to look at the tools that C provides for dealing with a variable argument list.

The function must know the type of each argument in the variable list. In the case of `printf()`, the conversion specifiers indicate the type of each argument. In other cases, such as the following, all arguments in the variable list are of the same type, so there is no problem. To create a function that accepts different types in the argument list, you must devise a method of passing information about the argument types. For example, you could use a character code, as was done in the function `half()` in Listing 19.2.
