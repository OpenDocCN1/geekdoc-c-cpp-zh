# Writing and Reading File Data

A program that uses a disk file can write data to a file, read data from a file, or a combination of the two. You can write to a disk file in three ways:

- You can use formatted output to save data to a file. You should use formatted output with text mode files. The primary use of formatted output is to create files containing text and numeric data to be read by other programs such as spreadsheets or databases.
- You can use character output to save single characters or lines of characters. Although technically it's possible to use character output with binary mode files, it can be tricky. You should restrict character output to text files. The main use of character output is to save (but not numeric) data in a form to be read by C, as well as other programs.
- You can use direct output to save the contents of memory directly to a file. This method is for binary files only. The direct output is the way to save data for later use.

When you want to read data from a file, you have the same three options: formatted input, character input, or direct input. The type of input you use in a particular case depends entirely on the nature of the file being read. Generally, you read data in the same mode it was saved, but this is not a requirement. However, reading a file different from the one it was written in requires a thorough knowledge of formats. The previous descriptions of the three types of file input and output suggest tasks for each type of output. This is by no means a set of strict rules. The C language is flexible (this is one of its advantages!), a clever programmer can make any type of output suit any need. As a beginning programmer, you might find it easier if you follow these guidelines, initially.

# Formatted File Input and Output

Formatted file I/O deals with text and numeric data that is formatted in a specific way. It is directly analogous to keyboard input and screen output with the printf() and scanf() functions, as described in Lesson 14. Formatted output is discussed, followed by input.

# Formatted File Output

Formatted file output is done with the library function fprintf(). The prototype of fprintf() is in the header file stdio.h, and it reads as:

```c
int fprintf(FILE *fp, char *fmt, ...);
```

The first argument is a pointer to FILE. To write data to a particular disk file, you pass the pointer that was returned when you opened the file with fopen(). The second argument is the format string. You learned about format strings in the discussion of printf() in Lesson 14. The format string used by fprintf() follows exactly the same rules as printf(). Refer to Lesson 14 for details.

The final argument is ... What that mean? In a function prototype, ellipses represent a variable number of arguments. In other words, in addition to the file pointer and the format string, fprintf() takes zero, one, or more additional arguments. This is just like printf(). These arguments are the names of the variables to be output to the specified stream. Remember, fprintf() works just like printf(), except that it sends its output to the stream specified in the argument list. In fact, if you specify a stream argument of stdout, fprintf() is identical to printf(). Listing 17.2 demonstrates the use of fprintf().

# Analysis ▼

You might wonder why the program displays 1000.001222 when the value entered was 100.0001. This isn't an error in the program. It's a normal consequence of the way C stores numbers internally. Some floating-point values can't be stored exactly, so minor inaccuracies such as this one sometimes result.

This program uses printf() on lines 37 and 38 to send some text and numeric data to stdout and to the disk. The only difference between the two is the first argument—that is, the stream to which data is sent. Note that Listing 17.2 uses clear_kb() to remove from stdin any extra characters left over. For formatted input, use the fscanf() library function, which is used like scanf() (see Lesson 14), except that input comes from a specified stream instead of stdin. The prototype for fscanf() is

```c
int fscanf(FILE *fp, const char *fmt, ...);
```

The argument fp is the pointer to the FILE returned by fopen(), and fmt is a pointer to the format string that specifies how fscanf() is to read the input. The components of the format string are the same as scanf(). Finally, the ellipsis (...) indicates one or more additional arguments, the addresses of the variables where fscanf() is to assign the input.
