# Using Braces (Lines 10, 23, and 29)

You use braces {} to enclose the program lines that make every C function—including the main() function. A group of one or more statements enclosed within braces is called a block. As you see in later lessons, C has many uses for blocks.

# A Note on Accuracy

A computer is fast and accurate, but it is also completely literal. It doesn't know enough to correct your simplest mistake; it takes everything you enter exactly as you entered it, not as you meant it!
