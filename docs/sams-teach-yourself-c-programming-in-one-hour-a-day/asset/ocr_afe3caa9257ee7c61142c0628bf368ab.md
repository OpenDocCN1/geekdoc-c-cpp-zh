# Sorting with qsort()

The library function qsort() is an implementation of the quicksort algorithm, invented by C.A.R. Hoare. This function sorts an array into order. Usually the result is in ascending order, but qsort() can be used for descending order as well. The function prototype, defined in stdlib.h,

```
void qsort(void *base, size_t num, size_t size,
int (*cmp)(const void *element1, const void *element2);
```

The argument base points to the first element in the array, num is the number of elements in the array, and size is the size (in bytes) of one array. The argument cmp is a pointer to a comparison function. The rules for the comparison are the same as the comparison function used by search(), described in the preceding section: You often use the same comparison function for both search() and qsort(). The function qsort() has no return value.
