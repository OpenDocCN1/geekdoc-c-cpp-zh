
# LESSON 12 Understanding Variable Scope

Lesson 11, “Implementing Structures, Unions, and TypeDefs” stated that scope affects a structure instance but not a structure tag or body. Why does scope affect the structure tag or body?

When you declare a structure without instances, you are creating a template, or definition, not actually declaring any variables. It isn't until you create an instance of the structure that you declare a variable that occupies memory and has scope. For this reason, you can leave a body external to any functions with no real effect on memory. Many programmers commonly used structure bodies with tags in header files and then include these header files when they need to create an instance of the structure. (Header files are covered in Lesson 22.)

How does the computer know the difference between a global variable and a local variable that have the same name?

The answer to this question is beyond the scope of this book. The important thing to know is when a local variable is declared with the same name as a global variable, the program temporarily ignores the global variable when the local variable is in scope (inside the function where it is defined). It continues to ignore the global variable until the local variable goes out of scope.

Can I declare a local variable and a global variable that have the same name, as long as they have different types?

Yes. When you declare a local variable with the same name as a global variable, it is a completely different variable. This means that you can make whatever type you want. You should be careful, however, when declaring global and local variables that have the same name. Some programmers prefix global variables with “g” (for example, gCount instead of Count). This makes it clear in the source code which variables are global and which are local.

# Ending Loops Early

In Lesson 6, you learned how the for loop, the while loop, and the do...while loop can control program execution. In all three cases, the termination or exit of the loop occurs only when a certain condition occurs. At times, you might want to exert more control over loop execution. The break and continue statements provide this control.

# The break Statement

The break statement can be placed only in the body of a for loop, while loop, or do...while loop. (it's valid in a switch statement, but that topic isn't covered until later in the lesson.) When a break statement is encountered, execution immediately exits the loop. Following is an example:

```c
for ( count = 0; count < 10; count++)
{
    if ( count == 5 )
        break;
}
```

Left to itself, the for loop would execute 10 times. On the sixth iteration, count is equal to 5, and the break statement executes, causing the for loop to terminate. Execution then passes to the statement immediately following the for loop's brace. When a break statement is encountered inside a nested loop, it causes the program to exit the innermost loop only.
