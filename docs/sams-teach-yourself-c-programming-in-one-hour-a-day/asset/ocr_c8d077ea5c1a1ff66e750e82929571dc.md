# Working with Bits

As you know, the most basic unit of computer storage is the bit. There are times when manipulating individual bits in your C program's data is useful. C has several tools that enable you to do this.

The bitwise operators enable you to manipulate the individual bits of integer variables. Remember, a bit is the smallest unit of data storage, and it can have only one values: 0 or 1. The bitwise operators can be used with integer types: char, int, and long. Before continuing with this section, you should be familiar with binary notation—way the computer internally stores integers.

The bitwise operators are most frequently used when your C program interacts directly with your system's hardware—a topic that is beyond the scope of this book. They have other uses, however, which are introduced.

Two shift operators shift the bits in an integer variable by a specified number of positions. The << operator shifts bits to the left, and the >> operator shifts bits to the right. The syntax for these binary operators is

```
x << n
x >> n
```
