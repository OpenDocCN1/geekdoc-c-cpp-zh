# Using Functions That Have a Variable Number of Arguments

| DO | DON'T |
| :--- | :--- |
| DO cast a void pointer when you use the value it points to. | DON'T try to increment or decrement a void pointer. |

You have used several library functions, such as `printf()` and `scanf()`, that take a variable number of arguments. You can write your own functions that take a variable argument list. Programs that have variable argument lists must include the header file `stdarg.h`.

When you declare a function that takes a variable argument list, you first list the fixed parameters—those that are always present. (There must be at least one parameter.) You then include an ellipsis (...) at the end of the parameter list to indicate that zero or more arguments are passed to the function. During this discussion, remember the distinction between a parameter and an argument, as explained in Lesson 5, “Packaging Code in Functions."

How does the function know how many arguments have been passed to it on specific call? You tell it. One of the fixed parameters informs the function of the total number of arguments. For example, when you use the `printf()` function, the number of conversion specifiers in the format string tells the function how many additional arguments to expect. More directly, one of the function's fixed arguments can be the number of additional arguments. The example you see in this uses approaches, but first you need to look at the tools that C provides for dealing with a variable argument list.

The function must know the type of each argument in the variable list. In the case of `printf()`, the conversion specifiers indicate the type of each argument. In other cases, such as the following, all arguments in the variable list are of the same type, so there is no problem. To create a function that accepts different types in the argument list, you must devise a method of passing information about the argument types. For example, you could use a character code, as was done in the function `half()` in Listing 19.2.

The tools for using a variable argument list are defined in `stdarg.h`. These tools are within the function to retrieve the arguments in the variable list. They are as follows:

# Using Functions That Have a Variable Number of Arguments

- `va_list`: A pointer data type.
- `va_start()`: A macro used to initialize the argument list.
- `va_arg()`: A macro used to retrieve each argument, in turn, from the variable list.
- `va_end()`: A macro used to "clean up" when all arguments have been retrieved.

We've outlined how these macros are used in a function, and then included an example. When the function is called, the code in the function must follow these steps to access its arguments:

- 1. Declare a pointer variable of type va_list. This pointer is used to access the individual arguments. It is common practice, although certainly not required, to call this variable arg_ptr.
- 2. Call the macro va_start(), passing the pointer arg_ptr as well as the name of the last argument. The macro va_start() has no return value; it initializes the pointer arg_ptr to the first argument in the variable list.
- 3. To retrieve each argument, call va_arg(), passing the pointer arg_ptr and the data type of the next argument. The return value of va_arg() is the value of the next argument. If the function has received n arguments in the variable list, va_arg() n times to retrieve the arguments in the order listed in the function call.
- 4. When all the arguments in the variable list have been retrieved, call va_end(), passing the pointer arg_ptr. In some implementations, this performs no action, but in others, it performs necessary clean-up actions. You should get in the habit of calling va_end() in case you use a C implementation requires it.

Now for that example: the function average() in Listing 19.3 calculates the arithmetic average of a list of integers. This program passes the function a single argument, indicating the number of additional arguments followed by the list of numbers.
