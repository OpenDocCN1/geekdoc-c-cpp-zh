# Comparing Partial Strings

The library function strncmp() compares a number of characters of one string to another. Its prototype is

```
int strncmp(const char *str1, const char *str2, size_t n);
```

The function strncmp() compares n characters of str2 to str1. The comparison proceeds until n characters have been compared or the end of str1 has been reached. The method of comparison and return values are the same as for strcmp(). The comparison is case-sensitive. Listing 18 demonstrates strncmp().
