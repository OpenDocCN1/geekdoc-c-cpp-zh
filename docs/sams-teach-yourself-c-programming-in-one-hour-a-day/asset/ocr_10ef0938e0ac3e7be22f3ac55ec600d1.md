You can then declare instances of this structure using the coord identifier:

coord toleft, bottomright;

Note that a typedef is different from a structure tag, as described earlier in this lesson.
you write

```
struct coord {
  int x;
  int y;
}
```

the identifier coord is a tag for the structure. You can use the tag to declare instances of
structure, unlike using a typedef, you must include the struct keyword:
struct coord toleft, bottomright;

Whether you use typedef or a structure tag to declare structures makes little difference.
Using typedef results in slightly more concise code because the struct keyword doesn't
have to be used. On the other hand, a tag and having the struct keyword explicit
makes clear that it is a structure declared.

# Summary

This lesson showed you how to use structures, a data type that you design to meet the
eeds of your program. A structure can contain any of C's data types, including other
structures, pointers, and arrays. Each data item within a structure, called a member, is
accessed using the member operator (.) through the structure name and the
member name. Structures can be used individually and also in arrays.

Unions are similar to structures. The main difference between a union and a structure is
that union stores all its members in the same area. This means that only one member
of union can be used at a time.
