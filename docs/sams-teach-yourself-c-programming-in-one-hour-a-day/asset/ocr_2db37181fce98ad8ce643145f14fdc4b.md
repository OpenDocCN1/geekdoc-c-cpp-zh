# Analysis

This program prints the value of x twice, first on line 13 as part of main(), and then on line 22 as part of print_value(). Line 5 defines x as a type int variable equal to 999. Lines 11 and 21 declare x as an extern int. Note the distinction between a variable definition, which sets aside storage for the variable, and an extern declaration.
