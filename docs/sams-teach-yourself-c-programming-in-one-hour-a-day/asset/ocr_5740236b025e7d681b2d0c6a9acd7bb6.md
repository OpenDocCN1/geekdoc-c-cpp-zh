current directory. Remember, when using a backslash (\), you need to use the
escape sequence. Also remember that UNIX uses the forward slash (/) as a direc-
tory separator.

# Can I read beyond the end of a file?

Yes. You can also read before the beginning of a file. Results from such reads can
dastrous. Reading files is just like working with arrays. You're looking at off-
sets in memory. If you're using `fseek()`, you should check to make sure that
you don't go beyond the end of the file.

# What happens if I don't close a file?

A good programming practice to close any files you open. By default, the file
should be closed when the program exits; however, you should never count on this.
If the file isn't closed, you might not be able to access it later because the operat-
system will think that the file is already in use.

# How many files can I open at once?

This question can't be answered with a simple number. The limitation on the num-er of files that can be opened based on variables while your operating sys-
tem. Consider your operating system manuals for more information.

# Can I read a file sequentially with random-access functions?

When reading a file sequentially, there is no need to use such functions
fseek(). Because the file pointer is left at the last position occupied, it is always
where you want it for sequential reads. You can use `fseek()` to read a file sequen-\entially; however, you gain nothing.
