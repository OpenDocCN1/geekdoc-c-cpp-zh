# APPENDIX C

# # Common C Functions

This appendix lists the function prototypes contained in each of the header files supplied with most compilers. Functions that have an asterisk after them were covered in this book.

The functions are listed alphabetically. Following each name and header file is the complete prototype. Notice that the header file prototypes use a notation different from that used in this book. For each parameter function, only the type is given in the prototype; no parameter name is included. Here are two examples:

```
int func(int, int *);
int func(int x, int *);
```

Both declarations specify two parameters—the first a type int, and the second a pointer to type int. As far as the compiler is concerned, these two declarations are equivalent.
