# Analysis ▼

As implemented in this listing, the function half() on lines 38–66 includes no error checking (for example, if an invalid type argument is passed). This is because, in a real program, you wouldn't use a function to perform a task as simple as dividing a value by two. This is an illustrative example.

You might think that the need to pass the pointed-to-variable would make the function less flexible. The function would be more general if it didn't need to know the type of the pointed-to data object, but that's not how C works. You must always cast a void pointer to a specific type before you dereference it. By taking this approach, you would write only one function. If you don't make use of a void pointer, you would need to write separate functions—one for each data type.

When you need a function that can deal with different data types, you can often write a macro to take the place of the function. The example just presented—in which the task performed by the function is relatively simple—would be a good candidate for a macro. (Lesson 22, “Advanced Compiler Use,” covers macros.)
