An infinite loop can also create a menu system that directs your program’s operation. You might remember from Lesson 5, "Packaging Code in Functions," that a program’s main() function serves as a sort of "traffic cop," directing execution among the various functions that do the real work of the program. This is often accomplished by a menu of some code: The user is presented with a list of choices and makes an entry by selecting one of them. One of the available choices should be terminate the program. When a choice is made, one of C’s decision statements is used to direct program execution accurately.

13.4 demonstrates a menu system.
