# # Completing the Development Cycle

When your program is compiled and linked to create an executable file, you can run it by clicking the run button (if you are still in your IDE) or double-clicking the icon (like you would run any other program). If you run the program and receive results different from what you thought you would, you need to go back to the first step. You must identify what caused the problem and correct it in the source code. When you make a change to the source code, you need to recompile and relink to create a corrected version of the executable file. You keep following this cycle until you get the program to execute exactly as you intended.

One final note on compiling and linking: Although compiling and linking are mentioned as separate steps, most compilers do both as one step.
