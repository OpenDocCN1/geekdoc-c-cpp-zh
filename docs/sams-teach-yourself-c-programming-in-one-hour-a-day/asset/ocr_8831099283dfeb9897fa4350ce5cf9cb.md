# Pointers and Multidimensional Arrays

multi[0][0], as you might think. Remember that multi is an array of arrays, so its first element multi[0], which is an array of four type int variables (one of the such arrays contained in multi).

Now, if multi[0] is also an array, does it point to anything? Yes, indeed! multi[0] points to its first element, multi[0] [0]. You might wonder where multi[0] is a pointer. Remember that the name of an array without brackets is a pointer to the first array element. The term multi[0] is the name of the array multi[0] [0] with the last pair of brackets missing, so it qualifies as a pointer.

If you're bit confused at this point, don't worry. This material is difficult to grasp. It might help you remember the following rules for any array of n dimensions used in code:

+   - The array followed by n pairs of brackets (each pair containing an appropriate index, course) evaluates as array data (that is, the data stored in the specified array element).

+   - The array followed by fewer than n pairs of brackets evaluates as a pointer to an array element.

In the example, therefore, multi evaluates as a pointer, multi[0] evaluates as a pointer, and multi[0][0] evaluates as array data.
