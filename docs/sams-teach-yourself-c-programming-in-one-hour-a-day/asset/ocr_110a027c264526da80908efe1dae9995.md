# LESSON 15 Pointers to Pointers and Arrays of Pointers

If the memory allocation were successful, the program uses the strcpy() function on line 46 to copy the string from the temporary storage location buffer to the storage space just allocated by malloc(). The while loop repeats, getting another line of input.

After execution returns get_lines() to main(), the following has been accomplished (assuming a memory allocation error didn't occur):

+   - A number of lines have been read from the keyboard and stored in memory as null-terminated strings.
- The array [] contains pointers to all the strings. The order of pointers in the array is the order in which the strings were input.
- The variable number_of_lines holds the number of lines that we are moving the strings around,

Now it's time to sort. Remember, you're not actually going to move the strings around, only the order of pointers in the array []. Look at the code in sort(). It contains one for nested inside another (lines 57 through 68). The outer loop executes number_of_lines-1 times. Each time the outer loop executes, the inner loop steps through the array of pointers, comparing (string n) with (string n+1) for n = 0 to number_of_lines - 1. The comparison is performed by the library function strcmp() on line 61, which is passed pointers to two strings. The function strcmp() returns one of the following:

+   - A value greater than zero if the first string is greater than the second string.
- Zero if the two strings are identical.
- A value less than the second string is greater than the first string.

In the program, a return value from strcmp() that is greater than zero means that the first string is “greater than” the second string, and they must be swapped. (That is, their pointers in lines [] must be swapped). This is done using a temporary variable tmp. Lines 63 through 65 perform the swap.

When execution returns from sort(), the pointers in lines [] are ordered properly. A pointer to the “lowest” string is in lines[0], a pointer to the “next-lowest” is in lines[1], and so on. Suppose, for example, you entered the following five lines, in this order:

```
dog
apple
zoo
program
merry
```
