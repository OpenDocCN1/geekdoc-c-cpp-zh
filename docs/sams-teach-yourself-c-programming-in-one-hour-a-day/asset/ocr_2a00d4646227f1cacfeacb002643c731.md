# TABLE 14.5 The printf() and sprintf() Conversion Characters

| Character | Meaning |
|---|---|
| d, i | Display a signed integer in decimal notation. Display an unsigned integer in decimal notation. |
| o | Display an unsigned integer in octal notation. |
| x, X | Display an unsigned integer in hexadecimal notation. Use x for lowercase output and X for uppercase output. |
| c | Display a single character. (The argument gives the character's ASCII code.) |
| e, E | Display a float or double in scientific notation. (For example, 123.45000+002). Six digits to display to the right of the decimal point unless another precision is specified with the f specifier. Use e or E to control the case of output. |
| f | Display a float or double in decimal notation. (For example, 123.45000). Six digits to display to the right of the decimal unless another precision is specified. |
| g, G | Use e, or f format is used if the exponent is less -3 or greater than the precision (which defaults to 6). f format is used otherwise. Trailing zeros are truncated. |
| n | Nothing is displayed. The argument corresponding to an n conversion command is a pointer to type int. The printf() function assigns to this variable the number of characters output so far. |
| s | Display a string. The argument is a pointer to char. Characters display until a null character is encountered or the number of characters specified by precision display. The terminating null character is not output. |
| % | Display the % character |

You can place a modifier before the conversion character. This modifier applies only to the conversion characters o, u, x, i, d, and b. When applied, this modifier specifies that the argument is a type long rather than a number. If the l modifier is applied to the conversion characters e, E, f, g, or G, it specifies that the argument is a type double. If a l is placed before any conversion character, it is ignored.

In addition to the specifier, there is an ll specifier. The ll specifier works just like the l specifier except that the argument is type long instead of type long.

The precision specifier consists of a decimal point (.) or itself followed by a number. A precision specifier applies only to the conversion characters e, E, f, g, G, and s. It specifies the number of digits to display to the right of the decimal point, or when used with s, the number of characters to output. If the decimal point is used alone, it specifies a precision of 0.
