# An Example

The short program in Listing 14.1 demonstrates the equivalence of streams.

# LISTING 14.1 stream.c: The Equivalence of Streams

```
/* Input a line, then immediately output it. */
#include <stdio.h>
int main(void) {
    char buffer[256];
    /* then immediately output it. */
    puts(gets(buffer));
    return 0;
}
```

On line 10, the gets() function is used to input a line of text from the keyboard (stdin). gets() returns a pointer to the string, which can be used as the argument to puts(), which displays the string onscreen (stdout). When run, this program inputs a line of text from the user and immediately displays the string onscreen.

| DO | DON'T |
| DO take advantage of the standard input/output streams that provides. | DON'T rename or change the standard streams unnecessarily. DON'T try to use an input stream as stdin for an output function such as fprintf(). |

For a beginner learning to program C, using gets() is fine. For a real-world program, however, you should use fgets() (explained later in this lesson) gets() poses risks to program security.
