LISTING 14.8 clearing2.c: Clearing stdin of Extra Characters Using fflush()

```
1: // clearing2.c--Clearing stdin of extra characters.

4:
```

# Analysis ▼

The fflush() function is used on line 15. The prototype for the fflush() function is as follows:

```
int fflush( FILE *stream);
```

The stream is the stream to be flushed. In Listing 14.8, the standard stream, stdin, is passed for stream.
