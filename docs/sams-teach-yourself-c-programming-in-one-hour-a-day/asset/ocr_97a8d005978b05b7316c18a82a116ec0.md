# LESSON 19
Getting More from
Functions

As you know by now, functions are central to C programming. In this
chapter you learn more ways to use functions in your programs, including

+   * Passing pointers as arguments to functions
* Passing type void pointers as arguments
* Using functions with a variable number of arguments
* Returning a pointer from a function

Some of these topics have been mentioned earlier in this book, but this
lesson provides more detailed information.
