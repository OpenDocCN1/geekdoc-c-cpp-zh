

## 第 21 节 工作记忆

## 位取反运算符

本文介绍的位运算符是位取反运算符 `~`。这是一个一元运算符。它的作用是反转其操作数中的每一个位，将所有的 0 变为 1，反之亦然。例如，-254（二进制 11111110）的结果结果为 1（二进制 00000001）。

本节中的所有示例都使用了 8 位的 `char` 变量。对于更大的类型，例如 `int` 类型和 `long` 类型，工作原理完全相同。

## 结构体中的位域

最后一个与位相关的话题是在结构体中使用位域。在第 11 节“实现结构体、联合体类型定义”中，你学习了如何定义自己的数据结构，并对其进行自定义以适应你的程序。通过使用位域，你可以实现更高级的自定义，并节省内存空间。

位域是包含指定位数的结构体成员。你可以声明一个位域包含 1 位、2 位或存储字段中数据所需的任意数量的位。这提供了什么优势呢？

假设你正在编写一个员工数据库程序，用于记录公司员工的资料。数据库存储的许多信息是“是/否”类的，例如“该员工是否参加了牙科保险？”或“该员工是否大学毕业？”。每条“是/否”信息都可以存储在一个位中，1 表示“是”，0 表示“否”。

使用 C 的标准数据类型，结构体中可以使用最小类型是 `char` 类型。你可以使用 `char` 类型结构体成员来存储“是/否”数据，但 `char` 的 8 位中会有 7 位被浪费。通过使用位域，你可以在一个 `char` 中存储 8 个“是/否”值。

位域不仅限于“是/否”。继续这个数据库示例，假设你的公司有三个医疗保险计划。你的数据库需要存储每个员工参加的计划数据（如果有的话）。你可以用 0 表示没有医疗保险，用值 1、2 和 3 表示这三个计划。一个包含 2 位的位域足够了，因为 2 个二进制位可以表示 0 到 3 的值。同样，3 位的位域可以持有 0 到 7 范围的值，依此类推。

位域的命名和访问方式与普通结构体成员相同。所有位域的类型均为 `unsigned int`，你通过在成员名后跟冒号和位数来指定字段的大小（以位计）。要定义一个包含名为 `dental` 的 1 位成员、另一个名为 `college` 的 1 位成员以及名为 `health` 的 2 位成员的结构体，你可以这样写：

```c
struct emp_data
{
    unsigned dental : 1;
    unsigned college : 1;
    unsigned health : 2;
};
```

省略号 (...) 表示其他结构体成员的存储空间。成员可以是字段，也可以是由普通数据类型组成的字段。注意，位域必须放在结构体定义中，位于任何非位域结构体成员之前。要访问位域，像访问任何结构体成员一样使用结构体成员运算符。对于示例，你可以将结构体定义扩展为更有用的形式：

```c
struct emp_data
{
    unsigned dental : 1;
    unsigned college : 1;
    unsigned health : 2;
    char fname[20];
    char lname[20];
    char sname[10];
};
```

你可以声明一个结构体数组：

```c
struct emp_data workers[100];
```

要给第一个数组元素赋值，可以编写如下代码：

```c
workers[0].dental = 1;
workers[0].college = 0;
workers[0].health = 2;
strcpy(workers[0].fname, "Mildred");
```

当然，如果你在处理 1 位域时使用值为 1 和 0 的符号常量 `YES` 和 `NO`，你的代码会更清晰。无论在何种情况下，你都将每个位域视为一个具有给定位数的无符号整数。位为 $n$ 位的位域可以赋值的值范围是从 0 到 $2^n-1$。如果你尝试给位域分配超出范围的值，编译器不会报告错误，但你自己会发现。

## 总结

今天的课程涵盖了在结构体中使用位域。你学习了如何定义位域来节省内存空间。你还学习了如何像普通结构体成员一样命名和访问它们。记住，位域必须放在结构体的开头。

## 问答

- `memset()`、`memcpy()` 和 `memmove()` 函数有什么优势？
为什么我不能使用带有赋值语句的循环来初始化或复制内存？
在某些情况下，你可以使用带有赋值语句的循环来初始化内存。事实上，这是唯一的实现方法——例如，将 `float` 数组的所有元素设置为 `1.23`。但在其他情况下，内存尚未被赋值，此时 `mem()` 系列函数是你的选择。

- 我会在什么时候使用移位运算符？
这些运算符的一个常见用法是程序直接与硬件交互时——这种任务通常需要生成和解释特定的位模式。这个主题超出了本书的范围。即使你需要直接操作硬件，你也可以在某些情况下使用移位运算符来除或乘以2 的幂。

- 如果我需要调整内存大小会怎样？
只要新字符串小于或等于原始字符串，就可以覆盖。然而，如果新字符串更大，你可以调用 `realloc()`。

- 我为什么需要释放内存？
某些系统会在程序结束时自动返回内存。

- 使用位域真的能带来收益吗？
是的，你可以通过位域获得“位”（bit）的收益（双关语）。考虑一种类似于本章示例的情况：一个文件中包含问卷调查的信息。人们被要求对问题回答 `TRUE` 或 `FALSE`。如果你向 10,000 个人提 100 个问题，并将每个答案存储为 `char`  T 或 F，你将需要 10,000 × 100 字节的存储空间（因为字符是 1 字节）。这是 100 万字节。如果你改用位域并为每个答案分配 1 位，你只需要 10,000 × 100 位。因为 1 字节包含 8 位，这相当于 130,000 字节数据，远少于 100 万字节。
