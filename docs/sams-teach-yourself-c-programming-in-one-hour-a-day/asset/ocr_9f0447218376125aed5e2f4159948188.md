# How deep can I nest my loops?

You can nest as many loops as you want. If your program requires you to nest more than two loops deep, consider using a function instead. You might find searching through those braces difficult, so perhaps a function would be easier to follow in code.

# Can I nest different loop commands?

You can nest if, for, while, do...while, or any other command. You will find that many of the programs you try to write require that you nest at least a few of these.
