# Q&A

Q How many levels deep I go with pointers to pointers?

A You need to check your compiler manuals to determine whether there are limitations. There is rarely any reason to go more than three levels deep with pointers (pointers to pointers to pointers). Most programs rarely go over two.

Q Is there a difference between a pointer to a string and a pointer to an array of characters?

A No string can be considered an array of characters.
