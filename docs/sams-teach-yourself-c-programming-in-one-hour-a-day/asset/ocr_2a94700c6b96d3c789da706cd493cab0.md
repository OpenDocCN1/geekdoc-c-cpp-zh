7. Write a program that puts random numbers into a two-dimensional array that is by 4. Print the values in columns onscreen. (Hint: Use the rand() function from Listing 8.3.)

> Whenever you use the rand() function, it is a good idea to add the following line to the beginning of your program:
rand ( time (NULL));
This call is needed to ensure every time you run the program you get random numbers. Believe it or not, there are times when a user would want to generate the same set of random numbers (scientific experiments, for example), so the srand, short for seed random, function is needed to ensure each time the program runs, it generates a new set of numbers.
