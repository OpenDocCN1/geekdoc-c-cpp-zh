# Output ▼

```

```

# Analysis ▼

The actual value not be 4210752 on your system, but all three values will be the same. The address of the array multi is the same as the address of the array multi[0], and both are equal to the address of the first integer in the array, multi[0][0].

If all of these pointers have the same value, what is the practical difference between them in your program? Remember from Lesson 9 that the C compiler knows what a pointer points to. To be exact, the compiler knows the size of the item pointer is pointing to.

What are the sizes of the elements you've using? Listing 15.2 uses the operator size() to display the sizes, in bytes, of these elements.
