# Analysis

Think about these size values. The array multi contains two arrays, each of which contains four integers. Each integer requires 4 bytes of storage. With a total of eight integers, the size of 32 bytes makes sense.

Next, multi[0] is an array containing four integers. Each integer takes 4 bytes, so the size of 16 bytes for multi[0] also makes sense.

Finally, multi[0][0] is an integer, so its size is, of 4 bytes.

Now, keeping these sizes in mind, recall the discussion in Lesson 9 about pointer arithmetic. The compiler knows the size of the object being pointed to, and pointer arithmetic takes this size into account. When you increment a pointer, its value is increased by the amount needed to point it to the "next" of whatever it's pointing to. In other words, it's incremented by the size of the object to which points.

When you apply this to the case, multi is a pointer to a four-element array with a size of 16. If you increment multi, its value should increase by 16 (the size of a four-element array). If multi points to multi[0], therefore, (multi + 1) should point to multi[1]. Listing 5.3 tests this theory.
