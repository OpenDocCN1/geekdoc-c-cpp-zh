
## Using Character Variables

Like variables, you must declare chars before using them, and you can initialize them at the time of declaration. Here are some examples:

```
char a, b, c;
/* Declare three uninitialized char variables */
char code = 'x';      /* Declare the char variable named code */
                     /* and store the character x there */
code = '!';         /* Store ! in the variable code */
```

To create literal constants, you must enclose a single character in quotation marks. The compiler automatically translates literal constants into the corresponding ASCII codes, and the numeric code is assigned to the variable.

You can create symbolic constants by using either the #define directive or the
const keyword:

```c
#define EX 'x'

const char code = EX;      /* Sets code equal to 'x' */
const char A = 'Z';
```

# Analysis ▼

You learned in Lesson 3 that the allowable range for a variable of type char goes only to 127, whereas the ASCII codes go to 255. The ASCII codes are actually divided into two parts. The extended ASCII codes go only to 127; this range includes all letters, numbers, punctuation marks, and other keyboard symbols. The codes from 128 to 255 are the extended ASCII codes and represent special characters such as foreign letters and graphics symbols (see Appendix A for a full list). Thus, for standard text data, you can use char variables; if you want to print the extended ASCII characters, you must use unsigned char.

Listing 10.2 prints some of the extended ASCII characters.
