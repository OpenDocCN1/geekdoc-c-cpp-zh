**LISTING 14.5** getch2.c: Using the getch() Function to Input an Entire Line

```
// getch2.c-Using getch() to input strings.
// Non-ANSI code
#include <stdio.h>
#include <conio.h>

#define MAX 80

int main(void ) {
    char ch, buffer[MAX+1];
    int x = 0;

    while ((ch = getch()) != '\r' && x < MAX)
        buffer[x++] = ch;

    printf("%s", buffer);
    return 0;
}
```

# The getche() Function

This is a short section because getche() is exactly like getch(), except that it echoes each character to stdout. Modify the program in Listing 14.4 to use getche() instead of getch(). When the program runs, each key you press displays onscreen twice—once as echoed by getche() and once as echoed by putchar().
