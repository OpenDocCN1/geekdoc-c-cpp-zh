# LESSON 18 Manipulating Strings

**Q Does strcat() ignore trailing spaces when doing a concatenation**

A No. `strcat()` looks at a space as just another character.

**Q Can I convert numbers to strings?**

A Yes. You can write a function similar to the one in Listing 17.16, or you can check your Library Reference for available functions. Some functions available include `itoa()`, `ltoa()`, and `utol()`.print(f)` can also be used.
