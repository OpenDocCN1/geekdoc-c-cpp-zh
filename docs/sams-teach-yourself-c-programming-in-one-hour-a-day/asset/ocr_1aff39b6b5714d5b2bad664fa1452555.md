# The Binary Mathematical Operators

C's binary operators take two operands. Table 4.2 lists the binary operators, which include the common mathematical operations found on a calculator.

| TABLE 4.2 C's Binary Mathematical Operators | |
| Operator | Symbol | Action | Example |
| Addition | + | Adds two operands | × + y |
| Subtraction | - | Subtracts the second operand from the first operand | × - y |
| Multiplication | * | Multiplies two operands | × y |
| Division | / | Divides the first operand by the second operand | × / y |
| Modulus | % | Gives the remainder when the first operand is divided by the second operand | × % y |

Referring to Table 4.2, the first four operators should be familiar to you, and you should have little trouble using them. The fifth operator, modulus, might be. Modulus returns the remainder when the first operand is divided by the second operand. For example, 11 modulus 4 equals 3 (that is, 4 goes into 11 times with 3 left over). Here are some more examples:

```
100 modulus 9 equals 1
10 modulus 5 equals 0
40 modulus 6 equals 4
```
