# Analysis ▼

Lines 9 through 12 declare the data structure for the list. Lines 16 and 17 define typedefs for both the data structure and a pointer to the data structure. Strictly speaking, this isn't necessary, but it simplifies coding by enabling you to write PERSON in place of struct data and LINK in place of struct data *.

Lines 22 through 24 declare a head pointer and a couple other pointers that will be used when manipulating the list. All these pointers are initialized to NULL.
