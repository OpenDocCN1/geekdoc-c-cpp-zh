# LESSON 5 Packaging Code in Functions

```
7: float half_of(float k);
8:
9: int main(void )
10: {
11:   // In this call, x is the argument to half_of().
12:   z = half_of(x);
13:   printf("The value of z = %f\n", z);
14:
15:   // In this call, y is the argument to half_of().
16:   z = half_of(y);
17:   printf("The value of z = %f\n", z);
18:
19:   // In this third call, z is the argument to half_of().
20:   z = half_of(z);
21:   printf("The value of z = %f\n", z);
22:
23:   return 0;
24: }
25: float half_of(float k)
26: {
27:   /* k is the parameter. Each time half_of() is called, */
28:   /* k has the value that was passed as an argument. */
29:
30:   return (k/2);
31: }
```

# Output

The value of z = 1.750000
The value of z = 32.555000
The value of z = 16.277500
