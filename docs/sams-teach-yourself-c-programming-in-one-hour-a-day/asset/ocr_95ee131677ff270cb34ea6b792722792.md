# Analysis

Listing 7.2 presents eight lines of information. Lines 10 and 11 print each decimals: a, b, and c. Line 10 prints without tabs, and line 11 prints with tabs. Lines 13 and 14 print each float variables: f, g, and h. Lines 13 print on one line, and line 14 print on others. Line 16 prints a float variable, f, followed by a percent sign. Because a percent sign is normally a message to print a variable, you must place two in a row to print a single percent sign. This is exactly like the backslash escape character. Lines 17 and 18 represent a new concept. Whenever you print a floating-point variable, C prints to six decimal places as a default. Even if you define a variable with one digit past the decimal, 5.5, when C prints using the % conversion specifier, it prints 5.500000. This may not serve your purposes, so C has a simple method to reduce the number of decimal digits it prints. As you can see on lines 17 and 18, adding a period (.) and a number before % instructs the compiler to print only the number of decimal points you use. One warning, though: C truncates the number instead of rounding. So 1.05 becomes 1.0 and not 1.1. Line 19 shows one final concept. When printing values in conversion specifiers, you don't have to use variables. You can also use expressions as g / f, or even constants.

# DO

DO remember to use the newline escape character when printing multiple lines of information in separate printf() statements.

# DON'T

DON'T try to print multiple lines of text into one printf() statement. In most instances, it's clearer to print multiple lines with multiple print statements than to use just one with separate newline(\n) escape characters.

DON'T miss stdio.h. Many C programmers accidentally type studio.h; however, there is no u. It stands for Standardard I/O (Input/Output).
