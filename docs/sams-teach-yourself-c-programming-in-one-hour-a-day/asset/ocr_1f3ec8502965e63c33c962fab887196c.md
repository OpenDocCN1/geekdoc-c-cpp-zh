# Compound Assignment Operators

C's compound assignment operators provide a shorthand method for combining a binary mathematical operation with an assignment operation. For example, you say want to increase the value of x by 5, or, in other words, add 5 to x and assign the result to x.

```
x = x + 5;
```

Using a compound assignment operator, you can think of it as a shorthand for assignment, you would write

```
x += 5;
```

In general notation, the compound assignment operators have the following syntax
where op represents a binary operator):

```
exp1 op= exp2
```

This is equivalent to writing

```
exp1 = exp1 op exp2;
```
