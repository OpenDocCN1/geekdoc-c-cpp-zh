# # scanf() Examples

The best way to become familiar with the operation of the `scanf()` function is to see it. It's a powerful function, but it can be a bit confusing at times. Try it and see what happens. Listing 14.9 demonstrates some of the unusual ways to use `scanf()`. You should compile and run this program and then experiment by making changes to the `scanf()` format strings.
