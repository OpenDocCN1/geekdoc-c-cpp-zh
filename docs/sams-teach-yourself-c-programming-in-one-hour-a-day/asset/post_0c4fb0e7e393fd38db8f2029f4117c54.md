# The printf() Conversion Specifiers

The format string must contain one specifier for each printed variable. The printf() function then displays each variable directed by its corresponding conversion specifier. You learn more about this process in Lesson 14, "Working with the Screen, Printer, and Keyboard." Exactly does this mean? For now, be sure to use the conversion specifier that corresponds to the type of variable being printed. For a signed integer (types int and long), use %d. For an unsigned integer (types int and long), use %u. For a floating-point variable (types float and double), use %f. The conversion specifiers you need often are listed in Table 7.2.

# TABLE 7.2 The Most Needed Conversion Specifiers

| Specifier | Meaning | Types |
|---|---|---|
| %c | Single character | char |
| %d | Signed decimal integer | int, short |
| %ld | Signed decimal integer | long |
| %f | Decimal floating-point number | float, double |
| %s | Character string | char arrays |
| %u | Unsigned decimal integer | int, short |
| %lu | Unsigned decimal integer | long |

Any program that uses printf() should include the header stdio.h. The literal text of format specifier is anything that qualifies as either an escape sequence or a conversion specifier. Literal text is simply printed, including all spaces. What about printing values of more than one variable? A printf() statement can print an unlimited number of variables, but the format string must contain one specifier for each variable.

# LESSON 7: Fundamentals of Reading and Writing Information

The conversion specifiers are paired with variables in left-to-right order. If you write `printf("Rate = %f, amount = %d", rate, amount);`, the positions of the conversion specifiers in the format string determine the position of the output. If there are more variables than conversion specifiers, the unmatched variables aren't printed. If there are more specifiers than variables, the unmatched specifiers print "garbage". You aren't limited to printing the value of variables with printf(). The arguments can be any valid C expression. For example, to print the sum of x and y, you could write

```
total = x + y;
printf("%d", total);
```

You could also write

```
printf("%d", x + y);
```

# Analysis

Listing 7.2 presents eight lines of information. Lines 10 and 11 print each decimals: a, b, and c. Line 10 prints without tabs, and line 11 prints with tabs. Lines 13 and 14 print each float variables: f, g, and h. Lines 13 print on one line, and line 14 print on others. Line 16 prints a float variable, f, followed by a percent sign. Because a percent sign is normally a message to print a variable, you must place two in a row to print a single percent sign. This is exactly like the backslash escape character. Lines 17 and 18 represent a new concept. Whenever you print a floating-point variable, C prints to six decimal places as default. Even if you define a variable with one digit past the decimal, 5.5, when C prints using the conversion specifier, it prints 5.500000. This may not serve your purposes, so C has a simple method to reduce the number of decimal digits it prints. As you can see on lines 17 and 18, adding a period (.) and a number before % instructs the compiler to print only the number of decimal points. One warning, though: C truncates the number instead of rounding. So 1.05 becomes 1.0 and not 1.1.
