# A Short C Program

Listing 2.1 presents the source code for bigyear.c. This is a simple program. All it does accept a year of birth from the keyboard and calculate what year a person turns a specific age. At this stage, don't worry about understanding the details of how the program works. The point is for you to gain some familiarity with the parts of a C program so that you can better understand the listings presented in this book.

Before looking at the sample program, you need to know what a function is because functions are central to C programming. A function is an independent section of program code that performs a certain task and has been assigned a name. By referencing the function's name, your program can execute the code in the function. The program also can send information, called arguments, to the function and the function can return information to the main part of the program. The two types of C functions are library functions, which are part of the C compiler package, and user-defined functions, which you, the programmer, learn about both types of functions in this book.

Note that, with all the listings in this book, the line numbers in Listing 2.1 are not part of the program. They are included only for identification purposes, so don't type them.
