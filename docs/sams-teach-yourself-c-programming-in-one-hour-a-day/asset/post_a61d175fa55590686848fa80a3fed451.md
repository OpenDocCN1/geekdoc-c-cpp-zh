# Copying Strings

The C library has two functions for copying strings. Because of the way C handles strings, you cannot simply assign one string to another, as you can in other computer languages. You must copy the source string from its location to the memory location of the destination string. The string-copying functions are strcpy() and strncpy(). These functions require the header file string.h.

# The strcpy() Function

The library function strcpy() copies an entire string to another memory location. Its prototype is as follows:

```c
char *strcpy(char *destination, const char *source);
```

The function strcpy() copies the string (including the terminating null character \0) pointed to source to the location pointed by destination. The return value is a pointer to the new string, destination.

When using strcpy(), you must first allocate storage space for the destination string. The function has no way of knowing destination points to allocated space. If space hasn't been allocated, the function overwrites strlen(source) bytes of memory, starting at destination. This can cause unpredictable problems. The use of strcpy() is illustrated in Listing 18.2.

# The strcpy() Function

The strcpy function is similar to strcpy(), except that strcpy enables you to specify how many characters to copy. Its prototype is

```c
char *strncpy(char *destination, const char *source, size_t n);
```

The arguments destination and source are pointers to the destination and source strings. The function copies the first n characters of source to destination. If source is shorter than n, null characters are added at the end of source to make a total of n characters copied to destination. If source is longer than n, no terminating \0 is added. The function’s return value is destination.

# Concatenating Strings

If you're not familiar with the term concatenation, you might be asking "What is it?" and "Is it legal?" Well, it means to join two strings—to tack one onto the end of another—and in most cases, the C standard library contains two concatenation functions—strcat()—both which require the header file string.h.

# Using the strcat() Function

The prototype of strcat(char *str1, const char *source);

The function appends a copy of str2 onto the end of str1, moving the terminating null character to the end of the new string. You must allocate enough space for str1 to hold the resulting string. The return value of strcat() is a pointer to str1. Listing 18.4 demonstrates strcat().

# LISTING 18.4 strcat.c: Using strcat() to Concatenate.

```c
// strcat.c---strcat() function.
#include <stdio.h>
#include <string.h>

char str1[27] = "a";
char str2[2];

int main( void ) {
	int n;
	// Put a null character at the end of str2].
	str2[1] = '\0';
	for (n = 98; n < 123; n++) {
		str2[0] = n;
		strcat(str1, str2);
		puts(str1);
	}
	return(0);
}
```

# Using the strcat() Function

The library function strcat() also performs string concatenation, but it enables you to specify how many characters of the source string are appended to the end of the destination string. The prototype is

```c
char *strcat(char *str1, const char *str2, size_t n);
```

If str2 contains more than n characters, the first n characters are appended to the end of str1. If str2 contains fewer than n characters, all of str2 is appended to the end of str1. In either case, a terminating null character is added at the end of the resulting string.
