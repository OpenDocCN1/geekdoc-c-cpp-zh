
# LISTING 15.7 sort:c: A Program that Reads Lines of Text from the Keyboard, Sorts Them Alphabetically, and Displays the Sorted List

```c
1: // Inputs a list of strings from the keyboard,
2: // sorts them, and displays them on the screen.
3: #include <stdlib.h>
4: #include <stdio.h>
5: #include <string.h>
6: 
7: #define MAXLINES 25
8: 
9: int get_lines(char *lines[]);
10: void sort(char *p[], int n);
11: void print_strings(char *p[], int n);
12: 
13: char *lines[MAXLINES];
14: 
15: int main(void )
16: {
17: int number_of_lines;
18: 
19: // Read in the lines from the keyboard.
20: 
21: number_of_lines = get_lines(lines);
22: 
23: if ( number_of_lines < 0 )
24: {
25: puts("Memory allocation error");
26: exit(-1);
27: }
28: 
29: sort(lines, number_of_lines);
30: print_strings(lines, number_of_lines);
31: return 0;
32: }
33: 
34: int get_lines(char *lines[])
35: {
36: int n = 0;
37: char buffer[80]; // Temporary storage for each line.
38: 
39: puts("Enter one line at a time; enter blank when done.");
40: 
41: while ((n < MAXLINES) && (gets(buffer) != 0) &&
42: buffer[0] != '\0')
43: {
44: if ((lines[n] = (char *)malloc(strlen(buffer)+1)) == NULL)
45: return -1;
46: strcpy(lines[n++], buffer);
47:   }
48:   return n;
49: } // End of get_lines()
50: 
51: void sort(char *p[], int n)
52: {
53:     int a, b;
54:     char *tmp;
55:     for (a = 0; a < n - 1; a++)
56:     {
57:       for (b = a + 1; b < n; b++)
58:         {
59:             if (strcmp(p[a], p[b]) > 0)
60: {
61:                 tmp = p[a];
62:                 p[a] = p[b];
63:                 p[b] = tmp;
64:             }
65:         }
66:     }
67: }
68: 
69: void print_strings(char *p[], int n)
70: {
71:     int count;
72:     for (count = 0; count < n; count++)
73:       printf("%s\n", p[count]);
74: }
```

## Analysis

It is worthy to examine the details of this program. Several library functions are used for various types of string manipulation. They are explained briefly here and in more detail in Lesson 8, “Manipulating Strings.” The header file `string.h` must be included in a program that uses these functions.

In the `get_lines()` function, input is controlled by the `while` statement on lines 41 and 42, which read as follows (condensed here):

```c
while ((n < MAXLINES) && (gets(buffer) != 0) && (buffer[0] != '\0'))
```

The condition has three parts:
- `n < MAXLINES` ensures that the maximum number of lines has not been input.
- `gets(buffer) != 0` calls the `gets()` function to read a line from the keyboard into buffer and verifies that end-of-file or some other error has not occurred.
- `buffer[0] != '\0'` verifies that the first character of the line is not null, which would signal a blank line had been entered.

If any of these three conditions is not satisfied, the `while` loop terminates and returns to the calling program with the number of lines entered as the return value. If all three conditions are satisfied, the following statement on line 44 is executed:

```c
if ((lines[n] = (char*)malloc(strlen(buffer)+1)) == NULL)
```

This statement calls `malloc()` to allocate space for the string that was just input. `strlen()` function returns the length of the string; the value is incremented by 1 so that `malloc()` allocates space for the string plus its terminating character. `(char *)`, just before `malloc()` on line 44, is a typecast that specifies the type of pointer returned by `malloc()`. The statement assigns the value of the pointer returned by `malloc()` to the corresponding element of the array of pointers. If `malloc()` returns `NULL`, the `if` loop returns to the calling program with a return value of -1. lines 23 through 27 report a memory allocation error and terminate the program.

If the memory allocation were successful, the program uses the `strcpy()` function on line 46 to copy the string from the temporary storage buffer to the space just allocated by `malloc()`. The `while` loop repeats, getting another line of input. After execution returns `get_lines()` to `main()`, the following has been accomplished (assuming memory allocation error didn't occur):

- A number of lines have been read from the keyboard and stored in memory as null-terminated strings.
- The array contains pointers to all the strings. The order of pointers in the array is the order in which the strings were input.
- The variable `number_of_lines` holds the number of lines we are moving around.

Now it's time to sort. Remember, you're not actually going to move the strings around, only the order of pointers in the array. Look at the code in `sort()`. It contains one `for` nested inside another (lines 57 through 68). The outer loop executes `number_of_lines-1` times. Each time the outer loop executes, the inner loop steps through the array of pointers, comparing `p[n]` with `p[n+1]` for `n = 0` to `number_of_lines -1`. The comparison is performed by the library function `strcmp()` on line 61, which is passed pointers to two strings. The function `strcmp()` returns one of the following:

- A value greater than zero if the first string is greater than the second string.
- Zero if the two strings are identical.
- A value less than zero if the second string is greater.

In the program, a return value from `strcmp()` that is greater than zero means that the first string is “greater than” the second string, and they must be swapped (that is, their pointers in the array must be swapped). This is done using a temporary variable `tmp`. Lines 63 through 65 perform the swap.

When execution returns from `sort()`, the pointers in the array are ordered properly. A pointer to the “lowest” string is in `lines[0]`, a pointer to the “next-lowest” is in `lines[1]`, and so on. Suppose, for example, you entered the following five lines, in this order:

```
dog
apple
zoo
program
merry
```
