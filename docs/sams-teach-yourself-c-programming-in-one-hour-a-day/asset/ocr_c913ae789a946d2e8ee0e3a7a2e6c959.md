# # Syntax

# ## The switch Statement

```
switch (expression)
{
    case template_1: statement(s);
    case template_2: statement(s);
    ...
    case template_n: statement(s);
    default: statement(s);
}
```

The switch statement allows for follow multiple branches from a single expression. It's more efficient and easier to follow a multilevel if statement. A switch statement evaluates an expression and then branches to the case statement that contains the template matching the expression's result, control goes to the default statement. If there is no default statement, control goes to the end of the switch statement.

Program flow continues from the case statement unless a break statement is encountered. If that occurs, control goes to the end of the switch statement.

# Example 1

```
switch( letter )
{
    case 'A':
    case 'a':
        printf("You entered A");
        break;
    case 'B':
    case 'b':
        printf("You entered B");
        break;
    ...
    default:
        printf("I don't have a case for %c", letter);
}
```

# Example 2

```
switch( number )
{
    case 0: puts("Your number is 0 or less.");
    case 1: puts("Your number is 1 or less.");
    case 2: puts("Your number is 2 or less.");

    ...
```
