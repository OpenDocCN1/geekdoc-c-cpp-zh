# Analysis ▼

This program accepts a value from the keyboard and then states whether the value is 5 or less, 6 or more, or not between 1 and 10. If the value is 0, line 18 executes a call to the exit() function, thus ending the program.

You can't use break in line 18, as did in Listing 13.4 earlier. Executing a break would merely break out of the switch statement; it wouldn't break out of the infinite while loop. The exit() function terminates the program. You learn more about the exit() function in the next section.
