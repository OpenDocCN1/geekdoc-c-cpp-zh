A function can contain multiple return statements. The first return executed is the only one that has any effect. Multiple return statements can be an efficient way to return different values from a function, as demonstrated in Listing 5.4.

# Input

LISTING 5.4 roomassign: Using Multiple return Statements in the Function

```c
/* Demonstrates multiple return statements in a function. */

#include <stdio.h>

char last_init;
int room;

int room_assign(char last_init);

int main( void ) 
{
    puts("Enter the first initial of your last name: %s");
    scanf("%c", &last_init);

    room = room_assign(last_init);

    printf("\n you need to report to room %d.
", room);

    return 0;
}

int room_assign(char li)
{
    // This statement tests whether the first initial is A-M or N-Z
    // with the first group being assigned room 1045 and the rest 1055
    // The part of the statement lets us check both lower and uppercase
    if ((li >= 'a' && li <= 'm') || (li >= 'A' && li <= 'M'))
        return 1045;
    else
        return 1055;
}
