acts as an operator rather than just a separator. You can form an expression by separating two subexpressions with the comma. The result is as follows:

+   - Both expressions are evaluated, with the left expression being evaluated first.
- The entire expression evaluates to the value of the right expression.

For example, the following statement assigns the value of b to x, then increments a, and increments b:

```
x = (a++ , b++);
```

Because the ++ operator is used in postfix mode, the value of b—before it is incremented—assigned to x. Using parentheses is necessary because the comma operator has precedence, even lower than the assignment operator.

As you learn in the next lesson, the most common use of the comma operator is in for statements.
