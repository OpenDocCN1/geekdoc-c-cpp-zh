As NeXTStep became more popular and influential, it evolved into OpenStep, an open industry standard based on NeXTStep's features and design goals. The NeXT desktop became a benchmark for innovative interface development, supporting arbitrary fonts using Display PostScript, at a time when most PCs still displayed generic blocky text.

# NOTE

> Arguably, OpenStep narrowly missed out on the chance to compete with Microsoft Windows 3.0. In the early 1990s, OpenStep was an obviously superior operating system, and was already being converted to run Intel x86 machines from its original Motorola 680x0 platform. Unfortunately, OpenStep shipped later than Windows, handing Microsoft an early-adopter advantage. Had it shipped earlier and been promoted more aggressively, it might well have over-shadowed Windows and given the developer community a worthy alternative platform.
