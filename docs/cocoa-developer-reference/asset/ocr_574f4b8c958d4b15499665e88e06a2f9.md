# Setting fonts and font sizes

Click the label to select it; two marker dots appear at each side. Choose **Fonts → Show Fonts** to display a font selector and text size dialog. The label should be big and readable, so you’ll set the size to 96 points. At the right-hand side of the font selector, select 96 from the list.

You’ll also change the font to OCR A Std to create a digital look. The choice of font doesn’t affect the application, so you can select a font here if you prefer an alternative styling. The result is shown in Figure 8.6. For completeness, you can also change the font used in the buttons. Click each button in turn and select a new font from the list.
