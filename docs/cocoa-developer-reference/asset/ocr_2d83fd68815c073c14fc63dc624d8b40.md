Handling events with the Responder Chain is a tricky linking technique — linking to First Responder bypasses AViewController and sends Touch Down events directly to showB View: in the root controller. You can use this trick to handle almost any event type in any context, but it is not MVC-approved and you should save it for view swap events handled by a root controller. If you extend AViewController with more features — buttons, sliders, and so on — add the code to handle them to the AViewController.m file in the usual way.
