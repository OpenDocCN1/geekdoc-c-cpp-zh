# Using Open and Save Panes

Cocoa includes two classes that enable a user to select a file visually and return a URL while opening and saving files. **NSOpenPanel** creates the Finder-like window shown in Figure 10.1. **NSSavePanel** creates the simpler window shown in Figure 10.2, although it can be expanded to the larger pane shown in Figure 10.3.

Figure 10.1

The standard **NSOpenPane**. The pane slides down from the top of the application window. This animation is automatic — it’s built into the class and can’t be changed.
