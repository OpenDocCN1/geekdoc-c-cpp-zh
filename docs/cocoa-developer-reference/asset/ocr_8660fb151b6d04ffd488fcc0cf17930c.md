# Implementing Key-Value Observing

Data collection objects are not observable. Adding, removing, counting, and searching items don't trigger Key-Value Observing (KVO). To implement KVO, you must add it manually. Typically you wrap changes inside one or more editing methods. Each method can specify a notification that tells KVO about the edit. For example:

```
```objective-c
- (void) editMethod: (id) objectsToReplace
             atindexes: (NSIndexSet *) indexes {
    [self willChange: NSKeyValueChangeReplacement
              atIndexes: indexes
                forKey: @"key"];
}
