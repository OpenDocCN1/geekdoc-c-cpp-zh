+   - First number = 40, second number = 24, remainder = 16
+   - First number = 24, second number = 16, remainder = 8
+   - First number = 16, second number = 8, remainder = 0

Hence GCD = 8.

LCM is obtained using GCD as **LCM = product of given two numbers/GCD**.
Using same example given above, we can find the LCM (40, 64) as follows:

LCM = (40 * 64)/8 = 320

# Algorithm

```
    Start
    Step 1: Read m, n [two numbers], p←m, q←n
    Step 2: WHILE n != 0 DO
        temp ← m mod n
        m ← n
        n ← temp
        END WHILE
    Step 3: gcd ← m
        lcm ← (p*q)/gcd
    Step 4: Print gcd, lcm
    Stop
```
