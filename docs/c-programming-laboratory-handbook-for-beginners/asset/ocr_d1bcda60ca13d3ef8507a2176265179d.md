# Program 10

Write a C program to print whether a given number is positive, negative or zero.

```
```c
#include<stdio.h>
void main()
{
    int n;
    printf("\n Enter the number: ");
    scanf("%d",&n);
    if(n>0)
        printf("\n Number is positive");
    else if(n==0)
        printf("\n Number is zero");
    else
        printf("\n Number is negative");

}
```
```

```

--------------------------------
