# Program 1

C program to check the frequency of the occurrence of a character in a given string.

```
#include<stdio.h>
#include<string.h>
main()
{
    char str[100],ch;
    int i,count=0,length;
    printf("\n Enter The String : ");
    gets(str);
    printf("\n Enter the character to be searched : ");
    scanf("%c",&ch);
    length=strlen(str);
    for(i=0;i<length;i++)
    {
        if(str[i]==ch)
            count++;
    }
    printf("\n The frequency of the occurence of %c is %d\n\n", ch,count);
}
```
