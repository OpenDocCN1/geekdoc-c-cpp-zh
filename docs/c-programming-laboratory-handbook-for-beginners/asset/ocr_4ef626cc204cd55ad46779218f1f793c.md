# Related Theory

# Prime Number

A prime number which is only divisible by 1 and itself is called as a prime number. For example 2, 3, 5, 7, 11, etc. are not divisible by any number other than 1 and themselves, so they are all prime numbers. But the numbers such as 4, 6, 8, 16, etc. are divisible by 2 and hence they are non-prime numbers.

# Program Logic

Let us see now how to check whether a number is prime or not.

+   - Consider number 16 which is not divisible by 9, 10, 11, 12, 13, 14 – all are greater than 16/2. But 16 is divisible by 2, 4, 6, 8 which are less than or equal to 16/2
+   - So the first point to remember is: A number $n$ cannot be divided by a number that is greater than $n/2$.
+   - So to check if a given number $n$ is prime or not, it is sufficient to divide $n$ by 2, 3, 4, 5, …, $n/2$.
