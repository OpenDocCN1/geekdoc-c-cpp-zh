# Algorithm

Start

+   **Step 1:** Input the co-efficients (a, b, c) of the quadratic equation.
+   **Step 2:** IF first co-efficient is zero
+       Output “Invalid input”
+   ELSE
+       d ← b² – 4ac
+       r ← √|d|
+       IF the value of d is equal to zero
+           Output “Roots are Equal”
+           r1 ← r2 ← – b/(2a)
+           Output r1, r2
+       ELSE IF the value of d is greater than zero
+           Output “Roots are Real and Distinct”
+           r1 ← (–b + r)/(2a)
+           r2 ← (–b – r)/(2a)
+           Output r1, r2
+       ELSE
+           Output “Roots are Complex”
+           r1 ← – b/(2a)
+           r2 ← r/(2a)
+           Print the roots
+       END IF
+   END IF

Stop
