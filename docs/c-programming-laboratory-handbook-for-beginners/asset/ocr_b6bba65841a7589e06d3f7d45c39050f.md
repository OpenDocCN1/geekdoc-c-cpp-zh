Write a C program to find the area of a circle, given the radius.

```
#include<stdio.h>
#define PI 3.142
void main()
{
    float radius, area;
    printf("\n Enter the radius of a circle: ");
    scanf("%f", &radius);
    area=PI*radius*radius;
    printf("\n Area of a circle=%f\n", area);
}
```
