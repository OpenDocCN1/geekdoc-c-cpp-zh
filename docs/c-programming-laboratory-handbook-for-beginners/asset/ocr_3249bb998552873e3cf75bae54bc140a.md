# Algorithm

```
Start
Step 1: Read n
Step 2: For i<-1 to 99 in steps of 1
        Store in array num[i]
        END FOR
Step 3: For i<-2 to 99 in steps of 1
        IF num[i] != 0
            For j<-i+1 to 99 in steps of 1
                IF num[j] != 0
                    IF num[j] mod num[i] == 0
                        num[j] = 0
                    END IF
                END IF
            END FOR
        END IF
        END FOR
```
