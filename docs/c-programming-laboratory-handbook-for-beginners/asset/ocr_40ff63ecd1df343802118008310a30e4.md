# Right shift

The expression `n >> d`, the number *n* is moved *d* number of bits toward right. While shifting toward right, the right most bits will be lost and 0’s will be filled at the left side.

# Example

0100 1001 (decimal number 73)
Right shifting above binary number by 4 bits gives the number
0000 0100 (decimal number 4)

+   2. Left shift number by 32-*n* bits
