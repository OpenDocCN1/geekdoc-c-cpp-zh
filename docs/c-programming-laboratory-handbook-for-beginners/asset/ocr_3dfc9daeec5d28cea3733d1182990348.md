# # How to Start with Visual Studio

+   1. **Step 1:** *This is to create a new project:*
+      Click on start menu → go to all programs → click on Microsoft Visual Studio 2005 → click on file → click on new project → in new project window under visual C++, select Win32 → Win32 Console Application, then give a project name and select the location in which the new project will be opened and click ok → then click on application settings/next → in additional options select empty project → then click on finish.
+   2. **Step 2:** *This is to create a new file within the created project:*
+      Click on view and select solution explorer → in solution explorer right click on source and select add → new item → under Visual C++ select code → on right-hand side select C++ file (.cpp) → then give a file name with “.c” extension → then click on add → an editor will be opened, now type in the program and save it.
+   3. **Step 3:** *This is to build a program:*
+      Click on build and select build solution. (Every modification has to be saved and rebuilt.)
+   4. **Step 4:** *This is to run a program:*
+      Click on build and select profile guided optimization and click on run instrumented/optimized application (Ctrl + F5).
