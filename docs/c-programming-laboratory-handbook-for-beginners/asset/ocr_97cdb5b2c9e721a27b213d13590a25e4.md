# "C" Programming Language

C (pronounced like the letter C) is a general-purpose computer programming language developed between 1969 and 1973 by Dennis Ritchie at the Bell Telephone Laboratories for use with the UNIX operating system. Although C was designed for implementing system software, it is widely used for developing portable application software.

C is an imperative (procedural) systems implementation language. It is a middle-level language and it provides best combination of low- and high-level languages. Due to this feature, “C” has not lost its importance and popularity in today’s changing programming world. All concepts in “C” are useful for understanding some courses like OOPs, VB, Java and most of the system software.
