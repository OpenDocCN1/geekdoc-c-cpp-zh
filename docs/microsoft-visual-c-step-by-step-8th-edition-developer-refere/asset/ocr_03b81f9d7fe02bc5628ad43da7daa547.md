# 4. Add the following markup shown in bold to the XML file.

Click here to view code image

```
<?xml version="1.0" encoding="utf-8"?>
<VoiceCommands
xmlns="http://schemas.microsoft.com/voicecommands/1.2">
    <CommandSet xml:lang="en-us" Name="CustomersCommands">
        <CommandPrefix>Customers</CommandPrefix>
        <Example>Show details of John Sharp</Example>
    </CommandSet>
</VoiceCommands>
```

Voice commands are defined in a command set. Each command set has a command prefix (specified by the CommandPrefix element), which can be used by Cortana to identify the application at run time. The command prefix does not have to be the same as the name of the application. For example, if your application name is lengthy or contains numeric characters, Cortana might have difficulty recognizing it, so you can use the command prefix to provide a shorter and more pronounceable alias. The Example element contains a phrase that shows how a user can invoke the command. Cortana displays this example in response to inquiries such as “What can I say?” or “Help.”
