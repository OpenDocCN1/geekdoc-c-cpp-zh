# Exception handling and the Visual Studio debugger

By default, the Visual Studio debugger only stops an application that is being debugged and reports exceptions that are unhandled. Sometimes it is useful to be able to debug exception handlers themselves, and in this case you need to be able to trace exceptions when they are thrown by the application, before they are caught. You can easily do this. On the Debug menu, click Windows and then click Exception Settings. The Exception Settings pane appears below the Code and Text Editor window:
