The *CustomerID* column in the Customer table in the AdventureWorks database contains automatically generated values. The user does not provide a value for this data when a customer is created; rather, the database itself generates the value when a customer is added to the database. In this way, the database can ensure that each customer has a unique customer ID. Therefore, after you have sent the POST request to the web service, you must send a GET request to obtain the customer ID.
