# Creating and using a REST web service

You have created an entity model that provides operations to retrieve and maintain customer information. The next step is to implement a web service so that a UWP app can access the entity model.

With Visual Studio 2015, you can create a web service in an ASP.NET web app based directly on an entity model generated by the Entity Framework. The web service uses the entity model to retrieve data from a database and update the database. You create a web service by using the Add Scaffold wizard. This wizard can generate a web service that implements the REST model, which uses a navigational scheme to represent business objects and services over a network and the HTTP protocol to transmit requests to access these objects and services. A client app that accesses a resource submits a request in the form of a URL, which the web service parses and processes.
