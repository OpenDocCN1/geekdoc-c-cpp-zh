The sample AdventureWorks database contains a table named Customer in the SalesLT schema. This table includes the columns containing the data presented by the Customers UWP app and also several others. Using the Entity Framework, you can choose to ignore columns that are not relevant, but you will not be able to create new customers if any of the columns you ignore do not allow nulls and do not have default values. In the Customer table, this restriction applies to the NameStyle, PasswordHash, and PasswordSalt columns (used for encrypting users’ passwords). To avoid complications and to enable you to focus on the functionality of the app itself, in the next exercise you will remove these columns from the Customer table.

# Remove unneeded columns from the AdventureWorks database

+   1. In the Azure portal, in the All Resources pane, click the AdventureWorks database.
+   2. In the toolbar above the AdventureWorks SQL Database pane, click Open In Visual Studio.
+   3. In the Open In Visual Studio pane, click Open In Visual Studio.
+   4. If the Did You Mean To Switch Applications? message appears, click Yes.

Visual Studio will start up and prompt you to connect to the database.

+   5. If the Connect To Server dialog box appears, enter the administrator password that you specified earlier, and then click Connect.
