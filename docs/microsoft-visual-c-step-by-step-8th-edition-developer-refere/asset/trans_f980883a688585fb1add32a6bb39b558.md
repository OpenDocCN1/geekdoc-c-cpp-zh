## 引言

Microsoft Visual C# 是一种功能强大但简单的语言，主要面向在 Microsoft .NET Framework 上构建应用程序的开发人员。Visual C# 继承了 C++ 和 Microsoft Visual Basic 的许多最佳特性，但很少有不一致和过时之处，这使得语言更干净、更合乎逻辑。C# 1.0 于 2001 年首次公开发布。随着 Visual Studio 2005 带来 C# 2.0，语言中添加了几个重要的新特性，包括泛型、迭代器和匿名方法。C# 3.0 与 Visual Studio 2008 一同发布，添加了扩展方法、lambda 表达式，以及最著名的是语言集成查询设施，即 LINQ。C# 4.0 于 2010 年发布，提供了进一步的增强，改善了与其他语言和技术的互操作性。这些特性包括对命名参数和可选参数的支持以及 *dynamic* 类型，该类型表示语言运行时应为对象实现后期绑定。与 C# 4.0 同时发布的一个重要的 .NET Framework 新增内容是构成任务并行库 的类和类型。使用 TPL，您可以构建高度可扩展的应用程序，充分利用多核处理器。C# 5.0 添加了对基于任务的异步处理的原生支持，通过 *async* 方法修饰符和 *await* 运算符。C# 6.0 是一个增量升级，其特性旨在让开发人员的生活更简单。这些特性包括诸如字符串插值（您再也不需要使用 *String.Format* 了！）、属性实现方式的增强、表达式体方法等。它们都在本书中进行了描述。

对微软来说另一个重要事件是 Windows 10 的发布。这个新版本的 Windows 结合了以前版本操作系统的最佳（和最受欢迎）的方面，并支持可共享数据、协作以及连接云中运行服务的高度交互式应用程序。Windows 10 中的关键概念是通用 Windows 平台 应用——设计用于在任何 Windows 10 设备上运行的应用程序，无论是功能齐全的桌面系统、笔记本电脑、平板电脑、智能手机，甚至是资源有限的物联网 设备。一旦掌握了 C# 的核心特性，获得构建可在所有这些平台上运行的应用程序的技能就很重要。
