## 在实际应用中比较日期

现在你已经看到了如何使用相当长且复杂的 if 和 else 语句序列，我应该提到，这并不是你在实际应用中比较日期时采用的技术。如果查看前一个练习中的 dateCompare 方法，你会看到两个参数 leftHandSide 和 rightHandSide 都是 DateTime 值。你编写的逻辑仅比较这些参数的日期部分，但它们还包含你未考虑（或未显示）的<|message|> 时间元素。要使两个 DateTime 值被视为相等，它们不仅应具有相同的日期，还应具有相同的时间。比较日期和时间是如此常见的操作，以至于 DateTime 类型实际上有一个内置的方法 Compare 来执行此操作：它接受两个 DateTime 参数并比较它们，返回一个值，指示第一个参数是否小于第二个参数，在这种情况下结果为负；第一个参数是否大于第二个参数，在这种情况下结果为正；或两个参数是否代表相同的日期和时间，在这种情况下结果为 0。

## 使用 switch 语句

有时当你编写级联 if 语句时，每个 if 语句看起来相似，因为它们都评估相同的表达式。唯一的区别是每个 if 将表达式的结果与不同的值进行比较。例如，考虑以下使用 if 语句检查 day 变量中的值并确定它是星期几的代码块：

```
if (day == 0)
{
    dayName = "Sunday";
}
else if (day == 1)
{
    dayName = "Monday";
}
else if (day == 2)
{
    dayName = "Tuesday";
}
else if (day == 3)
{
    ...
}
else
{
    dayName = "Unknown";
}
```

在这些情况下，通常可以将级联 if 语句重写为 switch 语句，以使程序更高效、更易读。

## 理解 switch 语句语法

switch 语句的语法如下（switch、case 和 default 是关键字）：

Click here to view code image

```
switch ( controllingExpression )
{
    case constantExpression :
        statements
        break;
    case constantExpression :
        statements
        break;
    ...
    default :
        statements
        break;
}
```

controllingExpression 必须用括号括起来，只会被评估一次。然后控制跳转到由 constantExpression 标识的代码块，该 constantExpression 的值等于 controllingExpression 的结果。（constantExpression 标识符也称为 case 标签。）执行一直运行到 break 语句，在此点 switch 语句结束，程序继续执行 switch 语句闭合大括号之后的第一条语句。如果没有任何 constantExpression 值等于 controllingExpression 的值，则在可选的 default 标签下方的语句会运行。
