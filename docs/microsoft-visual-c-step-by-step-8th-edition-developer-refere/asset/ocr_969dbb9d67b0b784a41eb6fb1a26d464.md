# Use arrays to implement a card game

+   1. Start Microsoft Visual Studio 2015 if it is not already running.
+   2. Open the Cards project, which is located in the \Microsoft Press\VCSBS\Chapter 10\Cards folder in your Documents folder.
+   3. On the Debug menu, click Start Debugging to build and run the application.

A form appears with the caption Card Game and four text boxes (labeled North, South, East, and West). At the bottom is a command bar with an ellipsis (...). Click the ellipsis to expand the command bar. A button with the caption Deal should appear:
