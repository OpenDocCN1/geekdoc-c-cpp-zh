The syntax Text="{Binding Path}" specifies that the value of the Text property will be provided by the value of the Path expression at run time. In this case, Path is set to CustomerID, so the value held in the CustomerID expression will be displayed by this control. However, you need to provide a bit more information to indicate that CustomerID is actually a property of a Customer object. To do this, you set the DataContext property of the control, which you will do shortly.
