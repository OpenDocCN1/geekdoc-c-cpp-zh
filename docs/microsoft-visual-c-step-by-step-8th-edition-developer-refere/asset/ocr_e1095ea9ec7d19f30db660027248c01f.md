4. In the Left Operand box, type 54.

6. Click the – Subtraction option, and then click Calculate.
The text in the Expression box changes to 54 – 13, but the value 0 appears in the Result box; this is clearly wrong.

7. Click the / Division option, and then click Calculate.
The text in the Expression box changes to 54/13, and again the value 0 appears in the Result box.

8. Click the % Remainder button, and then click Calculate.
The text in the Expression box changes to 54 % 13, but, once again, the value 0 appears in the Result text box. Test other combinations of numbers and operators; you will find that they all currently yield the value 0.

# Note

If you type a noninteger value into either of the operand boxes, the application detects an error and displays the message “Input string was not in a correct format.” You will learn more about how to catch and handle errors and exceptions in Chapter 6, “Managing errors and exceptions.”
