8. In the address bar, type http://localhost:50000/api/Customers/1, and then press Enter.

This request is directed to the overloaded GetCustomer method in the CustomersController class, and the value 1 is passed as the parameter to this method. Note that the Web API uses routes that start with the path “api” after the address of the server.

The GetCustomer method retrieves the details of customer 1 from the database and returns them as a JSON-formatted object, which is displayed in the browser. The data looks like this (the value for ModifiedDate might differ from that shown here):
