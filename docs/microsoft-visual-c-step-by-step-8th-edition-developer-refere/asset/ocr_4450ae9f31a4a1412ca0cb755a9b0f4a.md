namespace Parameters
{
    class Pass

# Note

The reason you are defining this method using the *static* keyword is to keep the exercise simple. You can call the *Value* method directly on the *Pass* class without first creating a new *Pass* object. The principles illustrated in this exercise apply in exactly the same manner to instance methods.
