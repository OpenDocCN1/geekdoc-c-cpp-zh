# Operator Precedence and Association

| Classes | Operators | Association |
|---|---|---|
| primary | . -> ( args ) [ subscript ] | → |
| unary | * & + - ! ~ ++ -- ( cast ) sizeof | → |
| mults | * / % | → |
| adds | + - | → |
| shifts | << >> | → |
| relational | < > <= >= | → |
| equality | == != | → |
| bitwise and | & | → |
| bitwise xor | ^ | → |
| bitwise or | | | → |
| logical and | && | → |
| logical or | || | → |
| conditional | e1 ? e2 : e3 | → |
| assignment | = binop= | ← |
| sequence | e1 , e2 | → |
