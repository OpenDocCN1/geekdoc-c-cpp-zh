# The declaration

```
double sqrt (d)
    double d;
    |------|
```

declares sqrt to be a function returning double when called with a single argument of type double. A more complicated example follows:

```
char * p (ac,c)
    char ac [] ;
    char c;
    { body }
```

which declares p to be a function returning a pointer to char, called with the name of an array of chars (corresponding to ac), and a char (corresponding to c).

Note that, for a variety of reasons, both of these argument declarations are misleading because of the way c evaluates expressions in general and actual parameters to function calls in particular. Thus, ac is actually a pointer to char, while c is most likely an int. These mysteries will be explored in [3.6].

# 1.7 Composite types

Up to this point, we have considered very simple forms of declarator, mostly identifiers standing alone or with some simple qualification. The full syntax rule for declarator is

```
declarator =
    identifier
  | * declarator                % pointer
  | declarator ( )              % function
  | declarator [ constant-expr ] % array
  | ( declarator )              % association control
```

The form of this rule shows that a declarator is built from a unique identifier by a succession of qualifications (pointer to, function returning, or array of) and occasional parentheses to override the default associations in declarators.
