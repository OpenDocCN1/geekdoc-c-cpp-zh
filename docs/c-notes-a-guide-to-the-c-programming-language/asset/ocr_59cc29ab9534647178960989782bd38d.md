# 1.6 Function declarations

External function declarations either are defining instances of the function or they simply declare the existence of a function defined elsewhere. In the latter case, the declaration takes the simple form declarator () where declarator must be a scalar type. Note that no information regarding the number or types of the arguments is specified with this form of function declaration.

```
declarator ()
```

A defining instance of a function takes the more complex form

```
/ extern | static / opt

type-specifier opt declarator ( argument-list opt )

argument-declaration-list opt

compound-statement.
```

where declarator must again be a scalar type, argument is a simple identifier, and

```
argument-declaration = type-specifier declarator-list ;
```

Thus, the arguments in the function are specified as a comma-separated list of identifiers, enclosed in parentheses and possibly followed by a list of declarations that provide typing information for the arguments.

An argument must be of scalar type, or coercible to scalar (i.e., not a structure), and have names that are distinct from each other. The argument-declaration-list must contain declarations only for arguments in the immediately preceding argument-list; the arguments may be declared in any order, but may be declared once at most. An argument-list is optional, in which case there are no arguments.

The meaning of compound statement, and how to define a function body, will be discussed in [2.6].
