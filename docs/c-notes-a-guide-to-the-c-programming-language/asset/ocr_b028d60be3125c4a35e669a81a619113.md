# C NOTES: A GUIDE TO THE C PROGRAMMING LANGUAGE

by C.T. Zahn

C NOTES is a reference manual and tutorial for the high-level programming language C. As the book illustrates, the C language supports structured program design, allows separately compiled modules, and contains important features for ease of program maintenance. C is machine-independent yet models the basic operators and operands of most modern computers. As such, C can be translated into efficient and compact code on a variety of machines.

The book focuses primarily on the portable aspects of C and thoroughly describes the language's syntax, external and local declarations, and macro preprocessor facilities, among other topics.

Prior to joining YOURDON as a Senior Staff Consultant, C.T. ZAHN was with the Stanford Linear Accelerator Center's Computation Research Group, where he developed the SKOL programming language.

# STRUCTURED WALKTHROUGHS

by Edward Yourdon .

STRUCTURED WALKTHROUGHS is an in-depth treatment of this new and highly successful method of peer group review of functional specifications, systems design, and code. In the book's thirteen chapters, you'll learn about procedures to conduct walkthroughs and ways to avoid a variety of psychological problems that often accompany their use. Walkthroughs are credited with huge reductions in the number of errors in DP systems, as well as a significant improvement in the overall quality of systems. Topics include Types of Walkthroughs; Programming Teams; Roles; Convincing Management; Evaluating Performance; Building Teams; Review Exercises; Bibliography; Index.
