$d(x, y) = \|x - y\|^p = \sqrt{\sum_{n=1}^{N} (x_n - y_n)^2}$ (7.5.7)

The first approach is to compare vector to vector for each 10 ms slice and to sum the distances between each vector's couples. Unfortunately, a word is rarely pronounced at exactly the same speed as we expect. The signal is subject to temporal compression and dilation. Therefore, a technique that automatically adapts the rhythm of the route of the acoustic vector will be used. This technique is called Dynamic Time Warping (DTW).

The goal of DTW is to find the best path in the sequence of acoustic vectors of both words, i.e., the path with the lowest accumulated distance.
