State machines are created by asking a state machine factory for an instance of a named state machine. The state machine factory loads the file that was generated from the visual state machine dafile, installs the state machine engine meta table, and returns the object to the caller. Once the caller has this table, it can begin to update the state machine. The user of the state machine factory can be another Lua script, game engine C/C++ code, or any other code for which a Lua interface exists. Once the state machine starts, the user of the state machine should run Update() at an appropriate periodic rate. If the state machine completes, Update() returns the Lua value nil, which evaluates to false in conditional statements.

The gun should be able to fire bullets, run out of ammunition, be reloaded from ammunition stored in an inventory, and perform a dry fire when there is no more ammunition left.
