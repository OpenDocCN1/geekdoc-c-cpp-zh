condition: the magnitude of the area spanned by a and x is the same as that by a and x⊥ (this just says the area of the parallelogram is base times height). Thus, x⊥ ∧ a = x ∧ a. Adding these two equations gives the geometric product x⊥ ∧ a + x⊥ · a = x ∧ a = a ∧ x + 0 = x ∧ a, and this we can divide by x to get x⊥ = (x ∧ a) a⁻¹. To see how this fits into standard linear algebra, we pick a basis such that a = ae, and x = b∥e + b⊥e⊥, plug in and expand, getting x⊥ = ((b∥e + b⊥e⊥) ∧ ae) (e/a) = b⊥e⊥ as we would expect.

Now for the kicker. What if we want the vector component of x that is perpendicular to a plane given by a bivector A? We do the same math and obtain x⊥ = (x ∧ A) A⁻¹. Elegant indeed! (Or we just project x to the normal -A⊥ of the plane, which is equivalent by duality).

To avoid making errors by believing nice pictures, note this formula still works with the "other" normal to the plane. Computing a concrete example is instructive.
