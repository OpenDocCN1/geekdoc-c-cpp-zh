The class GPtile manages these states in a transparent way for the GP user (see Figure 1.7.8). The user will only need to implement the methods Load() and Unload().

In some situations it will be necessary to load information of different types and origin, but conceptually in the same tile. In the example, the index (100, 100) (50, 50) can reference a terrain portion located in coordinate (100, 100) and size (50, 50) and, at the same time, it can reference to a fragment of an image with the same coordinates and size that is going to be used as the texture in that portion of terrain, as shown in Figure 1.7.9.
