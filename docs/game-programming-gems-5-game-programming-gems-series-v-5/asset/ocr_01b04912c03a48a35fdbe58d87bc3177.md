# Conclusion

Frustum culling is one of the most widely used culling techniques and allows rejecting large amounts of primitives at the per-object level without much processing cost. In the majority of today's applications and games in which culling is implemented, it is done so using the six planes approach with excellent results. However, as is shown in this gem there is another faster alternative: the radar approach algorithm, which is more memory friendly, allows faster object-in-frustum tests, and is more intuitive. Best of all, it is possible to build the frustum almost for free.
