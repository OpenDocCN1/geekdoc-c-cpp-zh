# Future Development

The PSB model of deformable body simulation is in the early stages of development. Several projects have been created that are based on this model [OpenCAL, Jello, MotionPlan] and attempt to develop the model in a variety of ways. We see a lot of ideas for improving the PSB model, including the following:

+   - Implementation of implicit integration as done previously in “Large Steps in Soft Body Simulation” [Baraff98]
+   - Application of inverse dynamics constraints as done before in [Provo95], including experimentation with the behavior parameters
+   - Separation of the physical model from its graphical representation, which allows more focused work on simulating simple models as the basis for more complicated shapes (see [Meseur00])
+   - Implementation of object-object collision detection and response, a “detail” omitted here to facilitate presentation of the material (see [Matyka03])
