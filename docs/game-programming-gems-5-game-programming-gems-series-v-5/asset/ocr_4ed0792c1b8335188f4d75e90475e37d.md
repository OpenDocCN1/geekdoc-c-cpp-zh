9. To show an example of the projection formula, we project the vector a = α₁e₁ + α₂e₂ + αe₃ onto the plane B = e₁ ∧ e₂, where we have picked the plane so we can easily verify the answer. Since the plane is in a nice orientation, we know the answer should be α₁e₁ + α₂e₂. Computation verifies this, as shown in Equation 2.1.21.

```
P_B(a) = (a · B)B⁻¹
= ⟨(α₁e₁ + α₂e₂ + α₃e₃)(e₁₂)⟩₂/₄(e₂₁)
= (α₁e₂ − α₂e₁)(e₂₁)
= α₁e₁ + α₂e₂
(2.1.21)
```
