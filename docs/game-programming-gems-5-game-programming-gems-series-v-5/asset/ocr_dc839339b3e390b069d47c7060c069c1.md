Pathfinding is one of the most famous theoretical problems in game development. There is vast documentation in literature covering many aspects of the problem. This is because pathfinding issues are present not only in computer science but also in robotics, mining, and automation technology.

In games, our maps approximate reality. In most cases, maps are graphs that represent the environment using a regular grid, where each node matches a point in the map with a particular scale or resolution (see Figure 3.8.1).
