# Putting It All Together

Finally, we have the elements necessary to complete our CSG algorithm. Using the BSP, we no longer clip solid polygons against other solid polygons. Instead, we clip the polygons against the other solid BSP and vice versa. The CSG pipeline between X and Y looks like this:

+   1. Make X BSP.
+   2. Clip Y against X BSP and retain appropriate polygons.
+   3. Make Y BSP.
+   4. Clip X against Y BSP and retain appropriate polygons.

Clipping a solid with a BSP tree consists of partitioning all solid polygons with all partition nodes (the BSP tree's splitting planes). The clipping process starts at the root and continues down to the leaves. The following sample exemplifies the recursive process:
