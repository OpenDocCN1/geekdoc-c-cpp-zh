# Geometric Algebra

We fix some notation to clarify the presentation: Greek letters like \(\alpha, \beta, \gamma\) and \(\delta\) will denote real numbers. Standard vectors will be bold lowercase letters like \(\mathbf{a}, \mathbf{b}, \mathbf{c}\). Later, we will use capital bold letters like \(\mathbf{A}, \mathbf{B}, \mathbf{M}, \mathbf{R}\) for *multivectors*, which are general elements of the geometric algebra, in the same manner vectors are general elements of a vector space.

# The Algebra

Given an \(n\)-dimensional vector space \(V^n\), we construct a new vector space \(CV\) (\(C\) for Clifford from mathematics), the geometric algebra of \(V\), as follows. We usually think of \(V\) as a collection of vectors, which are just one-dimensional oriented magnitudes. The geometric algebra will extend this to handle tracking all two-dimensional oriented areas, all three-dimensional oriented volumes, etc. We start by defining what the objects of \(CV\) are, beginning with the *outer product*.

# The Outer Product

For any two vectors \(\mathbf{a}\) and \(\mathbf{b}\) in \(V\), we create a *bivector*, written \(\mathbf{a} \wedge \mathbf{b}\). This represents the plane spanned by \(\mathbf{a}\) and \(\mathbf{b}\), the orientation of the plane, and also encodes the magnitude of the area of the parallelogram with sides defined by \(\mathbf{a}\) and \(\mathbf{b}\). See Figure 2.1.2(c) for a rough idea. A bivector is also called a 2-blade or a 2-vector. The operator \(\wedge\) is called the *outer product* (also known as the wedge product or exterior product) and satisfies the properties outlined in Equation 2.1.2 for any scalars \(\alpha, \beta, \gamma\) and vectors \(\mathbf{a}, \mathbf{b}, \mathbf{c}\):

| Equation | Description |
|---|---|
| \(\lambda \mathbf{a} = \mathbf{a} \wedge \lambda = \lambda \mathbf{a}\) | vector and scalar commute |
| \(\mathbf{a} \wedge \mathbf{b} = -\mathbf{b} \wedge \mathbf{a}\) | anticommutative on vectors |
| \((\lambda \mathbf{a}) \wedge \mathbf{b} = \lambda (\mathbf{a} \wedge \mathbf{b})\) | associative with scalars |
| \(\lambda (\mathbf{a} \wedge \mathbf{b}) = (\mathbf{a} \wedge \mathbf{b}) \lambda\) | commutative with scalars |
| \((\alpha \mathbf{a} + \beta \mathbf{b}) \wedge \mathbf{c} = \alpha \mathbf{a} \wedge \mathbf{c} + \beta \mathbf{b} \wedge \mathbf{c}\) | bilinearity |
| \(\mathbf{a} \wedge (c\mathbf{b} + \beta \mathbf{c}) = c\mathbf{a} \wedge \mathbf{b} + \beta \mathbf{a} \wedge \mathbf{c}\) | (linear in both factors) |

We extend the outer product in the same manner to products of three or more vectors. One important rule we find is that for any vector \(\mathbf{a}\), anticommutativity gives \(\mathbf{a} \wedge \mathbf{a} = -\mathbf{a} \wedge \mathbf{a}\). Since the only quantity that equals its negative is zero, we must have \(\mathbf{a} \wedge \mathbf{a} = 0\), a real number.
