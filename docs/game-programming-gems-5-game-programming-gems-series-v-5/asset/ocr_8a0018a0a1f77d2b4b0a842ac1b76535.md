Normally, the procedure ends here and the next time step is ready to start. However in the Heun integrator, some of the values are used in the next step (called the correction step), as shown in the second term of Equation 4.4.12.

```
y^{n+1} = y^n + \frac{\Delta t}{2} (f(y^n, t^n) + f(\tilde{y}^{n+1}, t^{n+1})) \quad (4.4.12)
```

The entire semi-implicit integration scheme has been written with two equations: Equations 4.4.11 and 4.4.12. Note that the “dashed” y is distinct from the normal y, as it is retained separately between the two steps.
