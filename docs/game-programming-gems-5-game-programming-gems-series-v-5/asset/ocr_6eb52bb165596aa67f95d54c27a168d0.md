# Use as a Directional Field

The potential function might also be used for more applications like a damage, thrust, or suction field. You might define a field magnitude by \( H = \max(1 - v, 0) \), then use \( H \) (or \( H^2 \)) as the damage of a flame thrower or the strength of a thrust or suction field. For direction, use the normalized gradient (negate as needed). To calculate the gradient, define two new constants as follows:

\( M = aq - cp \)
\( N = bq - dp. \)
(3.2.11)

Then using these constants, compute the gradient of \( v \) as follows:

\(\nabla v = \begin{pmatrix} \partial v / \partial x \\ \partial v / \partial y \\ \partial v / \partial z \end{pmatrix} = \begin{pmatrix} 2xR / D \\ 2yS / D \\ [Mx^2 + Ny^2 + (pz + 2qz)D]/D^2 \end{pmatrix} \).
(3.2.12)
