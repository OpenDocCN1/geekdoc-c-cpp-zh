Polish it: This gem details a basic prescribed physics engine, but there are many ways to improve it. Be sure to add ramps, rewinding, animations, sounds, graphical effects, or whatever else you can think of that will add excitement to your game.

In today's competitive game industry, physics is just as important as graphics. Graphics draws the world the user sees, but if we don't make a world worth looking at, no amount of graphics will help. Prescribed physics can be a great solution for developers who want exciting physics in their game at a fraction of the time needed to create a traditional big-budget physics engine.
