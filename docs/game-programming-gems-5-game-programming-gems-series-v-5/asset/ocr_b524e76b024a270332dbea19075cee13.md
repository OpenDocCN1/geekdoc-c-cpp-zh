# Spheres, Where Are You?

One of the faster and more commonly used bounding objects in today's games is a sphere. A sphere is defined as a center point and a radius. Spheres are quite easy to create and are almost as fast as the point-to-frustum algorithm since it is just a variation of it. Knowing the position of the sphere against the frustum can no longer be an inside or outside issue, though, because that test can also return if the bounding sphere is not completely inside or completely outside but intersecting the frustum planes, which allows some clever optimizations that are going to be covered later. For the purposes of this gem, however, we will only be covering the method that returns if a bounding sphere is Visible or Completely Outside of the frustum. Please refer to [Puig03] for more advanced methods.

Consider the definition of a sphere: a center point and a radius. With that in mind, you can think of testing a point against a frustum like checking a bounding sphere with radius zero against a frustum. Now all we do is extend that to include a nonzero radius. See Figure 1.6.7.
