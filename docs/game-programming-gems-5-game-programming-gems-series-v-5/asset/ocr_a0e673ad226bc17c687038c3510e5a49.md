# Sample Application

We have implemented our algorithm in a simple demo application, which can be found on the companion CD-ROM. The demo shows a car in a three-dimensional environment followed by a camera on a tripod. The car can be controlled using the arrow keys. The camera follows the car as if it were controlled by a virtual camera operator. Pressing the Q key toggles the human behavior of the camera.
