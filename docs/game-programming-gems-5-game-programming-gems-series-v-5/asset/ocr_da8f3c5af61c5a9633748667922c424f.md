Let a general cubic Hermite spline curve be defined as

```
h(u) = au^3 + bu^2 + cu + d. (2.2.1)
```

Then the Hermite spline coefficients [Hearn04] are given by

```
[ a ]   [ 2  -2   1   1 ] [ p_1 ]
[ b ] = [ -3   3  -2  -1 ] [ p_2 ]
[ c ]   [ 0   0   1   0 ] [ \alpha_{t_1} ]
[ d ]   [ 1   0   0   0 ] [ \alpha_{t_2} ]
(2.2.2)
```

Note that variables \alpha_1 and \alpha_2 are used later to set the optimal tangent lengths. Let the vector between p_1 and p_2 be denoted p_{12}. Thus p_{12} = p_2 - p_1, and the coefficients for Equation 2.2.1 are given by Equation 2.2.3

```
a = \alpha_{t1} + \alpha_{t2} - 2p_{12}
b = 3p_{12} - 2\alpha_{t1} - \alpha_{t2}
c = \alpha_{t1}
d = p_1 .
(2.2.3)
```
