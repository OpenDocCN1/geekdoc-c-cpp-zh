A better and more general solution is to consider paths between the unit and every entry location. As we have done with exiting units we need to forgo making successive calls to the A* algorithm and make a single call to our derived algorithm. The unit's location will provide us with a start node, and possible entry locations will provide us with multiple stop nodes. To make sure the algorithm converges on the containing game object, we will need a target node inside the containing game object, preferably close to the center location of the object. Passing these parameters to the derived algorithm will give us a minimal cost path leading to the optimal entry location.
