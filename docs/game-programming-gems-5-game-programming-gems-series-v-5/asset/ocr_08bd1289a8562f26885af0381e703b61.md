Now consider a leaf, whose composition is made of eight bytes. One bit is used to specify its condition. Then again, it may depend on the number of nodes the system may use. On 32-bit systems, 31 bits are generally enough; leaving four bytes that can be used for additional information (mainly for dynamic management of resources; see Figure 1.14.8). However, 64-bit programs may want to use more nodes and therefore take more than 31 bits.
