Likewise, a game may have one to any number of unique global states within the actual gameplay. For example, a traditional first-person shooter (FPS) might allow the player to interface with a computer in the game. At this point, the game enters a different state: the rendering path changes, and the interface to the game is different. In essence, it is as though a completely different minigame is playing instead of the primary control mechanism.
