What do we do if it is decided that weapons need to be able to animate? As it stands, CWeapon and CAnimatingObject are in two different branches of the tree. A solution to this problem is to make CWeapon inherit from CAnimatingObject. But wait! A weapon is a collectable object, so we also have to make CCollectableObject inherit from CAnimatingObject.
