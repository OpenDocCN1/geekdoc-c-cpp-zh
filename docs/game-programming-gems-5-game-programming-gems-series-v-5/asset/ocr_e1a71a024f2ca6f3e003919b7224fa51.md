\(\rho_B = \frac{B}{A_b}, \rho_R = \frac{R}{A_R}.\) (3.3.21)

In our example, both \(A_b\) and \(A_R\) are 10,000:

\(\rho_B = \frac{B}{10000}, \rho_R = \frac{R}{10000}.\) (3.3.22)

The following system of equations describes this scenario:

\(\frac{dB}{dt} = -c_b R \rho_B dt\)
\(\frac{dR}{dt} = -c_r B \rho_R dt.\) (3.3.23)

In our scenario, \(B_0\) is 100, \(R_0\) is 100, \(c_b\) is 2, and \(c_r\) is 1.

Assuming that the area occupied by an army is constant, the equations can be simplified by combining the area with the constant term. We introduce a modified combat rating constant:

\(\chi_R = \frac{c_R}{A_b}, \chi_B = \frac{c_B}{A_R}.\) (3.3.24)

In our example,

\(\chi_R = \frac{1}{10000} = .0001, \chi_B = \frac{2}{10000} = .0002.\) (3.3.25)

The simplified model is the following.

\(\frac{dB}{dt} = -\chi_R R B dt\)
\(\frac{dR}{dt} = -\chi_B B R dt\) (3.3.26)

# **Who Wins?**

Blue wins if \(B > 0\) when \(R = 0\), which is the case when,

\(\frac{\chi_R}{\chi_B} < \frac{B_0}{R_0}.\) (3.3.27)
