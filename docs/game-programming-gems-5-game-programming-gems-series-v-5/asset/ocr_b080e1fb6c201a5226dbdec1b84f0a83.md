+   3. We split the solid by this splitter plane.
+   4. All faces or fragment faces ending up in front of the splitter are added on the *front* list. If a face is coplanar with the splitting plane, that face is partitioned by the plane's orientation as follows: if the normal of the face has the same orientation as the splitting plane, it is added to the *front*, otherwise, on the *back*.
+   5. All faces, or fragment faces, ending up in back are added to the *back* list.
+   6. We reference the *front* and *back* lists to the original splitter as front and back nodes.
+   7. We repeat the process for *back* and *front* lists starting at Step 1 but we always choose a nonflagged face for the next splitter as follows:
+      * For the *front* list, we stop the recursive process when all polygons have been used as splitters or when front polygon's size is 1, and we create a terminal leaf node where we add all polygons from the *front* list.
+      * On the *back* list, we continue the recursive process until no polygons are left in the list. At this stage, we create a terminal leaf node and flag it solid.
