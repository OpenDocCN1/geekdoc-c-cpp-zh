These services provide task-specific game functionality to the entire game world. Services provide a way for the game world to distribute its load on an individual task-by-task basis. Examples of typical game services include chat services, item services, position services, AI services, and combat services (See Figure 6.1.2). By using distributed services, the entire simulation of the game is now no longer run on just a single server.
