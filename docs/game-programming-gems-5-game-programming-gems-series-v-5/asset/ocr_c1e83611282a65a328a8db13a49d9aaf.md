3. Vectors are perpendicular if and only if the dot product is 0. This extends to the contraction product applied to k-blades!

4. Linear (in)dependence: the outer product of vectors is 0 if and only if the vectors are linearly dependent. Thus two vectors are parallel if and only if their outer product is 0. This allows simple line and plane equations.

5. The equation of a line through a point a and with direction u is (x - a) ^ u = 0. This works in any dimension, so it is more concise than the dimension-dependent forms.

6. Similarly, a plane through a point a and parallel to the bivector u ^ v is (x - a) ^ u ^ v = 0. Again, this is dimension-independent.

7. The orthogonal projection of a blade A onto a blade B is given by P_B(A) = (A . B) B^-1. This is nice since it is the same expression for any two spaces: points onto lines, lines onto planes, planes onto planes, etc., in any dimension.

8. Extending the projection, the expression A - P_B(A) must represent the perpendicular component of A with respect to B.

9. The pseudoscalar I commutes with all elements in odd-dimensional spaces.

10. Given a vector n, a plane perpendicular to it in 3-space is -nI, and given a plane defined by u ^ v, the normal vector is -(u ^ v) I. This is shown in Figure 2.1.6. Recall this plane has an orientation, so we include the minus signs to make this agree with the "dual."

11. Duality: the dual of a multivector A is defined by A* = A J. This is useful for exchanging "spanning" relations and "perpendicularity" relations. This generalizes the previous fact. In 3D, this exchanges bivectors with normal direction vectors, so it can be used to quickly find the normal to a plane. This is shown in 3D for a normal and plane in Figure 2.1.6.

12. The norm of a multivector generalizes the length of a vector and is written |A| = \sqrt{A . A}. It returns the area of a bivector, the length of a vector, etc.
