# Using Quaternions as Rotations

Recall that a quaternion **q** is a four-component quantity that can be written as follows.

**q** = \(\langle w, x, y, z \rangle = w + xi + yj + zk\) (2.4.1)

It consists of one scalar component _w_ and three vector components _x_, _y_, and _z_. Quaternion multiplication is defined using the ordinary distributive law with the following rules for the products of the "imaginary" numbers _i_, _j_, and _k_.

\(i^2 = j^2 = k^2 = -1\)
\(ij = -ji = k\)
\(jk = -kj = i\)
\(ki = -ik = j\) (2.4.2)

Using these rules, the product of two quaternions **a** and **b** can be expanded to

**ab** = \((a_w b_w - a_x b_x - a_y b_y - a_z b_z)\)
\(+3(a_w b_x + a_x b_w + a_y b_z - a_z b_y)i\)
\(+3(a_y b_z - a_z b_x + a_z b_x + a_x b_z)j\)
\(+3(a_x b_y + a_y b_x - a_y b_x + a_x b_y)k\) (2.4.3)

Every nonzero quaternion **q** = _w_ + _xi_ + _yj_ + _zk_ has an inverse **q**<sup>-1</sup> given by

**q**<sup>-1</sup> = \(\frac{\bar{\mathbf{q}}}{q^2}\) (2.4.4)

where the quantity \(\bar{\mathbf{q}} = w - xi - yj - zk\) is the conjugate of **q**. For a unit quaternion, _q_<sup>2</sup> = 1, and the conjugate and inverse are the same quantity.

A quaternion representing a rotation through an angle \(\theta\) about the unit-length axis \(\mathbf{A} = \langle A_x, A_y, A_z \rangle\) is usually written in the following form.

**q**<sub>rotation</sub> = \(\cos \frac{\theta}{2} + \mathbf{A} \sin \frac{\theta}{2}\) (2.4.5)
