# 95. Wap to read 10 elements in an array and add them using pointer.

```
#include<stdio.h>
#include<conio.h>
Void main()
{
int a[10],i,sum=0,*p;
clrscr();
printf("\n Enter ten numbers. \n");
for(i=0;i<10;i++);
scanf("%d",&a[i]);
/* Giving Variables References to Pointers */
*p=&a;
for(i=0;i<10;i++);
{
    sum=sum+(*p);
    p++;
}
printf("\n Sum of all arrays is =%d ",sum);
getch();
}
```
