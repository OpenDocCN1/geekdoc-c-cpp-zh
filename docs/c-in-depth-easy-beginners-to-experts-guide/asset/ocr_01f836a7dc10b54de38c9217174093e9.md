# Difference between: Compiler and Interpreter -

A interpreter is similar to sentence-by-sentence translation, whereas a compiler is similar to translation to the whole passage.

|  | Compiler | Interpreter |
|---|---|---|
| 1. | Compiler translates the entire high level language program into the machine language program at once before executing it. This optimizes the use of machine language instructions in the translated program. Therefore normally compiled programs run faster than Interpreted programs. The original high level language program is called a s source program. The compiled program i.e. machine language program generated by the compiler after translation is called object program. | The Interpreter translates the program written in high level language into machine language at the time of executing that program, instructions by instructions. That is, it reads the first instruction written in the program and converts that into equivalent machine language instructions. Then the CPU watches those machine language instructions. After that, the Interpreter reads and translates the next instruction and so on. |
| 2. | Compiler Takes Entire program as input | Interpreter Takes Single instruction as input. |
| 3. | Object code is permanently saved for future use. | No object code is saved for future use. |
| 4. | Non time consuming translation method. | Time consuming translation method |
