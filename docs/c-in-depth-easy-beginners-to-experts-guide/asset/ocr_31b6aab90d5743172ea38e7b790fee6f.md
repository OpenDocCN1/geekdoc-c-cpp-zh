2. Are the expressions *p++ and ++*p same?
**Output:** No.
*p++ increments the pointer and not the value pointed by it, whereas ++*p increments the value being pointed by p.

26. How would you dynamically allocate 2-D array?
**Output:**
```c
#include<alloc.h>
#define MAXROW 10
#define MAXCOL 10
main()
{
    int *p, i, j;
    p=(int *) malloc (MAXROW * MAXCOL * sizeof(int));
    /*input in matrix*/
    for(i=0;i<MAXROW;i++)
    {
        for(i=0;i<MAXCOL;i++)
        {
            p[i*MAXCOL+j]=i;
            printf("%d",p[i*MAXCOL+j]);
        }
        printf("\n");
    }
}
```
