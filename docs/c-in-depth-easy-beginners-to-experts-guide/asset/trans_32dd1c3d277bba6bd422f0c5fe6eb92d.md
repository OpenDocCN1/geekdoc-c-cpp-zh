### 7. 编程使用第三个变量交换两个变量的值。

```c
#include<stdio.h>
#include<conio.h>
void main()
{
float a,b,c;
clrscr();
printf("\n\t\t\tI'm Learning C with Harry's Book \n");
printf("\n\n\t Enter the value of a=");
scanf("%f",&a);
printf("\n\n\t Enter the value of b=");
scanf("%f",&b);
c=a;
a=b;
b=c;
printf("\n after swapping a=%f\n\t b=%f",a,b);
getch();
}
```

注意：交换是指将两个变量的值相互调换。

注意：这里 c 是一个临时变量。
