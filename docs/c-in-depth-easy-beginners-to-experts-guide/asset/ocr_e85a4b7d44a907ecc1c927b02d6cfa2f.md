# (Two Dimensional Array (Matrix))

# Introduction-

Two dimensional array is popularly known as tables or matrix and can be easily visualized as having rows and columns. Matrix can also be thought of as arrays of arrays.

*To create a two dimensional array, specifying both dimensions i.e. rows and columns in square brackets.*

For e.g. the following declaration creates a matrix of 4 rows and 5 columns.

```
int mat[4][5];
#define MAXROW 4
#define MAXCOL 5
int mat[MAXROW][MAXCOL];
```
