4. There is some debate as to the position of the “ * ” int* p;

The first step is to know how to declare a pointer. This is done by using C’s multiply character “*” (which obviously doesn’t perform a multiplication).

The “*” is placed at some point between the keyword int and the variable name. Instead of creating an integer, a pointer to an integer is created.

# Mind Wash Drill Table –

*Both above and below tables will help you to understand the concept of pointers on your fingertips.*

| int | *pi; | /* pi is a pointer to an int */ |
| long int | *p; | /* p is a pointer to a long int */ |
| Float* | pf; | /* pf is a pointer to a float */ |
| char | c, d, *pc; | /* c and d are a char and pc is a pointer to char */ |
| double* | pd, e, f; | /* pd is pointer to a double, e and f are double */ |
| char* | start; | /* start is a pointer to a char */ |
| char* | end; | /* end is a pointer to a char */ |

The declaration of the variable tells the compiler to -

+   1. Reserve space in the memory to hold the integer value.
+   2. Associates the name “a” with this memory location.
+   3. Stores the value 5 at this location.
