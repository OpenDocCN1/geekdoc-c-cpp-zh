3. #if, #elif, #else and #endif permit conditional compilation of the source program, depending on the value of one or more true/false conditions. They are also used in conjunction with the defined operator.

# For example:

```
#if defined(FOREGROUND)
    #define BACKGROUND 0
#else
    #define FOREGROUND 0
    #define BACKGROUND 7
#endif
```
