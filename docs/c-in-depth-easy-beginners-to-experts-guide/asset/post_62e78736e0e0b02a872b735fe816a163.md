
```
while (i = 15)
{
    printf("\n%d", i);
    i++;
}
```

Output: print 15 indefinitely.

Because in the statement `while(i = 15)`, `i` is not compared with 15. Here `i` is assigned 15, which is a non-zero value, so each time the condition is checked `i` becomes 15 and the condition becomes true and executes the body of the loop, which first prints the value of `i`, meaning 15, and then increments by 1 and `i` becomes 16. But again when the condition check is encountered, then again `i` becomes 15 and again executes the body of the loop the same as before, which causes 15 to be printed indefinitely.

```
for ( ; ; )
{
    if (i > 5)
        break;
    else
        j += i;
    printf("%d\t", j);
    i += j;
}
```

Output: 2  5

In this program, initially `i = 1` and `j = 1`. Whenever there is no condition in the `for` loop, by default it is assumed true and executes the body, and when `i > 5` is executed control jumps to the `else` block because the condition is false, and then `j += i` [`j = j + i`] gives `j = 2`, and then `j` is printed through `printf()`. Now the next statement `i += j` gives `i = 3`, and from the ending braces of the loop control jumps to the loop and checks for the condition that is true because it is missing, and again `i > 5` is checked, which becomes false, and control executes the `else` block, which causes `j = 5` (3 + 2) and gets printed. Now `i` will be 8, and now when the next time `i > 5` condition is checked it will be true and control jumps out of the loop because of the “break” statement.
