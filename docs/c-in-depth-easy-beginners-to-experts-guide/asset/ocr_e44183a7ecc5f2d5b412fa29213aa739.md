# Lab Exercise -

Print the n terms of the following series.

+   1. 1, 3, 5, 7, 9, ........
+   2. 2, 4, 6, 8, 10, ........
+   3. 1, 4, 9, 16, 25, .......
+   4. 1, 8, 27, 64, 125, .....
+   5. 1, -1, 1, -1, 1, .....
+   6. 1, 1, 2, 4, 7, 13, 24, ... (Lucas series)
+   7. 1 + x²/2! + x³/3! + x⁴/4! + x⁵/5! .......... (e^x)
+   8. x - x³/3! + x⁵/5! - x⁷/7! + x⁹/9! .......... (sinx)
+   9. 1 - x²/2! + x⁴/4! - x⁶/6! + x⁸/8! .......... (cosx)
+   10. x - x²/2 + x³/3 - x⁴/4 + x⁵/5 ............... (log(1+x))
+   11. WAP to print the table of n.
+   12. WAP to calculate the factorial of n.
+   13. WAP to calculate the power p of a number n.
