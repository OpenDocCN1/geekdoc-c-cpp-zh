### 11. main()

```c
main()
{
    int i = 35, *z;
    z = fun(&i);
    printf("\n%d", z);
}
fun( int *m)
{
    return(m + 2);
}
```

输出：不可预测的输出。
在上面的程序中，假设 i 的地址（&i）为 2005，它被传递给 m，因此 m 包含 i 的地址，并返回 m+2，等于 2007。所以该函数向 main() 返回 2007，main() 会将其存入 z，并通过 printf() 打印 z。这里的地址是编译器假定的，因此我们无法确定输出会是什么，但会打印出一个 int 值。
