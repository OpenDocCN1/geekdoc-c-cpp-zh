The rule is if the parameter name is preceded by a # in the macro expansion, the combination (of # and parameter) will be expanded into a quoted string with the parameter replaced by the actual argument. This can be combined with the string concatenation to print the output desired in our program. On expansion the macro becomes printf("x" "=%d",x); The two strings get concatenated, so the effect is printf("x=%d",x);

outputs:
DEBUG: x=4
DEBUG: y=3.140000
DEBUG: ch=A
