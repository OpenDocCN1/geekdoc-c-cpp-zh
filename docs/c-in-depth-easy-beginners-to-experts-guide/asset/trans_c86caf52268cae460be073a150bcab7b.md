## 运算符

运算符可用于对值执行所需的计算。

### 运算符类型

运算符有三种类型：

- 1. 一元运算符：仅作用于一个操作数的运算符。
- 2. 二元运算符：作用于两个操作数的运算符。
- 3. 三元运算符：作用于三个操作数的运算符。

### 优先级规则

C 中的每个运算符都有与之关联的优先级。该优先级用于确定包含多个运算符的表达式如何求值。

优先级有不同的级别，一个运算符可能属于其中一个级别。优先级较高的运算符先求值。

### 结合性规则

相同优先级的运算符根据级别从左到右或从右到左求值。这称为运算符的结合性属性。C 中有 45 个运算符：

### 1. 算术运算符

这些运算符包括 `+`、`-`、`*`、`/`、`%`；这里的 `+` 和 `-` 运算符分别用于对两个操作数进行加法和减法。`*` 用于乘法，`/` 用于除法。

```
int i=2,j=3,k,l;
float a,b;
k=i/j*j;
l=j/i*i;
a=i/j*j;
b=j/i*i;
printf("%d, %d, %f, %f",k,l,a,b);
Output:- 0, 2, 0.000000, 2.000000
```

`%` 称为取模运算符，该运算符用于计算余数。

```
int a=5,b=3,c;
c=a%b;
printf("%d", c);
Output: 2
```

> 注意：取模运算符不适用于浮点数。

### 2. 一元运算符

`+`、`-`、`++`、`--`、`sizeof`、`(typecasting)` 一元运算符中的 `+` 和 `-` 用于表示数字的符号。`++` 运算符用于将变量加 1。

```
int a=5,b=4;
a++;
b--;
printf("%d,%d",a,b);
```

**输出：6, 3**

如果我们使用 `a++` 或 `++a`，两者都会将 `a` 的值增加 1。`a++` 称为**后缀**，而 `++a` 称为**前缀**。

### 后缀

```
int a=5,b;
b=a++;
printf("%d, %d",a,b);
Output:- 6,5
```

```
int i=3;
i=i++;
printf("%d",i);
Output:- 4
```

### 前缀

```
int a=5,b;
b=++a;
printf("%d, %d",a,b);
Output:- 6,6
```

```
int i=2;
printf("%d %d",++i, ++i);
```

- 1. 3 4
- 2. 4 3
- 3. 4 4
- 4. 输出可能因编译器而异。

输出：b

### 3. 关系运算符

`<`、`>`、`<=`、`>=` 这些运算符是布尔运算符（这类运算符以 1 或 0 给出答案。这里 1 被视为真，0 为假）。

```
int x=10,a,b;
a=x>2;
b=x<2;
printf("%d, %d",a,b);
Output:- 1,0
```

```
int x=10,y=20,z=5,i;
i=x<y<z;
printf("%d",i);
```

- 1. 1
- 2. 0
- 3. 错误
- 4. 以上都不是

输出：a

### 4. 赋值运算符

`=`、`+=`、`-=`、`*=`、`/=`、`%=` 这些运算符用于为变量赋值。

```
a=5; /* assigning 5 to variable a */
a=5+2; /*valid*/
a=b; /*valid*/
5=a; /*invalid*/
a+b=5; /*invalid*/
```

其他赋值运算符用于对变量执行算术运算，然后将值赋给同一变量：

- `a+=5;` 等价于 `a=a+5`
- `a-=5;` 等价于 `a=a-5`
- `a*=5;` 等价于 `a=a*5`
- `a/=5;` 等价于 `a=a/5`
- `a%=5;` 等价于 `a=a%5`

### 5. 相等运算符 - ==, !=

这两个运算符用于检查给定表达式的左右两边是否相等。该运算符也是布尔运算符；它同样以 0 或 1 给出答案。

```
int a,b,c=5;
a==5;
b!=2;
printf("%d, %d",a,b);
```

输出：1,0

### 6. 逻辑运算符 - &&, ||, !

这些运算符也是布尔运算符。`&&` 和 `||` 运算符与两个表达式一起使用。这些表达式中通常含有关系运算符或相等运算符。

| 表达式 1 | 表达式 2 | && | \|\| |
|---|---|---|---|
| 0 | 0 | 0 | 0 |
| 1 | 0 | 0 | 1 |
| 0 | 1 | 0 | 1 |
| 1 | 1 | 1 | 1 |

NOT 运算符用于反转表达式：

| 表达式 | ! |
|---|---|
| 0 | 1 |
| 1 | 0 |

```
int a=10,b=5,c,d;
c= a>3 && b!=3;
d= (a==10 || b>20);
printf("%d, %d",c,d);
Output:- 1, 1
```

输出：1, 1

### 使用短路运算符

```
int a=5,b=4,c;
c= (b == 3 && a++);
printf("%d, %d, %d", a,b,c);
Output:- 5, 4, 0
```

输出：5, 4, 0

现在让我们试着理解这个输出。该表达式中有四种类型的运算符：`b == 3` 含有相等运算符。`a++` 是一元运算符。这两个表达式通过逻辑 AND 连接。最后将值赋给变量 `c`。

在这个表达式中，`b == 3` 是一个假表达式，因此会得到 0。下一个运算符是逻辑 AND，该运算符作用于两个不同的表达式（只有当两个表达式都为真时，AND 才会给出答案 1），第一个是 `b == 3`，第二个是 `a++`。AND 的第一个表达式为假，因此为了加快程序执行速度，它不会计算下一个表达式。

```
int i=3,j=2,k=0,m;
m = ++i && ++j || ++k;
printf("%d %d %d %d", i , j, k,m);
Output:- 4 3 0 1
```

```
int i=3,j=2,k=0,m;
m = ++j && ++i || ++k;
printf("%d %d %d %d", i , j, k,m);
Output:- 4 3 0 1
```

```
int i=3,j=2,k=0,m;
m = ++i || ++j && ++k;
printf("%d %d %d %d", i , j, k,m);
Output:- 4 2 0 1
```

```
int i=3,j=2,k=0,m;
m = ++i && ++j && ++k;
printf("%d %d %d %d", i , j, k,m);
```

### 7. 条件运算符

这是 C 中唯一的三元类型运算符。它作用于三个操作数。这类运算符由两个协同工作的运算符（`?`）和（`:`）组成。让我们先了解该运算符的语法：

```
Condition ? true statement : false statement;
```

上述表达式的意思是：如果条件为真，即如果它返回非零值，那么返回的值将是真语句；否则返回的值将是假语句。
