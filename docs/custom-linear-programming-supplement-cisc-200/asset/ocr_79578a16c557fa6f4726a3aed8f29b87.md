To find all solutions satisfying the constraint as an equality, we first set R = 0 and solve for T. This result shows that the origin (T = 0, R = 0) is on the constraint line. Setting T = 0 and solving for R provides the same point. However, we can obtain a second point on the line by setting T equal to any value other than zero and then solving for R. For instance, setting T = 100 and solving for R, we find that the point (T = 100, R = 100) is on the line.
