In January, 1952 the first successful computer solution of a linear programming problem was performed on the SEC (Standards Eastern Automatic Computer). The SEAC, the first digital computer built by the National Bureau of Standards under U.S. Air Force sponsorship, had a 512-word memory and internal magnetic tape for external storage.

Instructions on how to solve linear programs using Excel and LINGO are provided in appendixes at the end of the chapter.

Packages are also available for free download. A good example is Clp (COIN-OR linear programming) available from the COIN-OR organization at http://www.coin-or.org.

A large number of user-friendly computer programs that can solve linear programs are now available. These programs, developed by academicians and small software companies, are almost all easy to use. Most of these programs are designed to solve smaller linear programs (a few hundred variables), but some can be used to solve problems involving thousands of variables and constraints. Linear programming solvers are also available in the spreadsheet environment. In Appendix 7.1 we show how to use the solver available with Excel. Appendix 7.2 demonstrates the use of LINGO, a stand-alone software package for solving optimization problems.

Probably the most widely used tool is Solver, which is built into Microsoft Excel. Therefore, the computer output we discuss is based on the output provided by Excel Solver. The complete details for how to formulate the RMC problem in Excel and use Solver are contained in Appendix 7.1.
