| ( type ) | unary cast |  |
| * | multiplication | left to right |

| % | remainder |  |
| + | addition or string concatenation | left to right |
| - | subtraction |  |
| << | left shift | left to right |

| > | greater than |  |
| >= | greater than or equal to |  |
