# 30.1 Introduction

This chapter continues our discussion of JSF web application development with two additional examples. In the first, we present a simple address book app that retrieves data from and inserts data into a Java DB database. The app allows users to view the existing contacts in the address book and to add new contacts. In the second example, we add so-called Ajax capabilities to the Validation example from Section 29.7. As you’ll learn, Ajax improves application performance and responsiveness. This chapter’s examples, like those in Chapter 29, were developed in NetBeans.
