4.26 What does the following program print?

```
// Exercise 4.26: Mystery3.java
public class Mystery3
{
    public static void main( String[] args )
    {
        int row = 10;
        int column;

        while ( row >= 1 )
        {
            column = 1;

            while ( column <= 10 )
            {
                System.out.print( row % 2 == 1 ? "<" : ">" );
                ++column;
            } // end while

            --row;
            System.out.println();
        } // end while
    } // end main
} // end class Mystery3
```
