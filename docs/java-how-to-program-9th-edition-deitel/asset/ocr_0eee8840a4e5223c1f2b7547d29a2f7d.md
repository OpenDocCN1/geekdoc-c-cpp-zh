8. Confirming that the account information has been updated. From the main menu, select option 1 again to view your current account balance (Fig. I.17). Both the available balance and the total balance have been updated to reflect your withdrawal transaction.

9. Ending the transaction. To end your current ATM session, select option 4, "Exit", from the main menu (Fig. I.18). The ATM will exit the system and display a goodbye message to the user. The application will then return to its original prompt, asking for the next user’s account number.
