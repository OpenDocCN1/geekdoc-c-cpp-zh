随着交易的发生（即销售完成且付款寄到），有关这些交易的信息会被输入到一个文件中。在每个业务周期结束时（有些公司为一个月，有些为一周，有些甚至为一天），交易文件（称为 "trans.txt"）会被应用于主文件（称为 "oldmast.txt"），以更新每个账户的购买和付款记录。在更新过程中，主文件会被重写为文件 "newmast.txt"，该文件将在下一个业务周期结束时用于再次开始更新过程。
