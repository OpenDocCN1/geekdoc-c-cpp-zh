# 5.10 What does the following program do?

```
// Exercise 5.10: Printing.java
public class Printing
{
    public static void main( String[] args )
    {
        for ( int i = 1; i <= 10; i++ )
        {
            for ( int j = 1; j <= 5; j++ )
                System.out.print( '@' );

            System.out.println();
        } // end outer for
    } // end main
} // end class Printing
```
