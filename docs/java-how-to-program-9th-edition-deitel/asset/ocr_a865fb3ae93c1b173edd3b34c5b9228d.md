Actually, a compiler can use StringBuilder (or StringBuffer) and the append methods to implement the + and += String concatenation operators. For example, assuming the declarations

```
String string1 = "hello";
String string2 = "BC";
int value = 22;
```

the statement

```
String s = string1 + string2 + value;
```

concatenates "hello", "BC" and 22. The concatenation can be performed as follows:

```
String s = new StringBuilder().append( "hello" ).append( "BC" ).append( 22 ).toString();
```
