```
# G.6 Printing Strings and Characters

The c and s conversion characters print individual characters and strings, respectively. Conversion characters c and C require a char argument. Conversion characters s and S can take a String or any Object as an argument. When conversion characters C and S are used, the output is displayed in uppercase letters. Figure G.5 displays characters, strings and objects with conversion characters c and s. Autoboxing occurs at line 9 when an int constant is assigned to an Integer object. Line 15 outputs an Integer argument with the conversion character s, which implicitly invokes the toString method to get the integer value. You can also output an Integer object using the %d format specifier. In this case, the int value in the Integer object will be unboxed and output.

> **Common Programming Error G.1**
> 
> *Using `%c` to print a String causes an `IllegalFormatConversionException`—a String cannot be converted to a character.*

```
```java
// Fig. G.5: CharStringConversion.java
// Using character and string conversion characters.
public class CharStringConversion
{
   public static void main( String[] args )
   {
      char character = 'A';  // initialize char
      String string = "This is also a string";  // String object
      Integer integer = 1234;  // initialize integer (autoboxing)

      System.out.printf( "%c%n", character );
      System.out.printf( "%s%n", "This is a string" );
      System.out.printf( "%s%n", string );
      System.out.printf( "%S%n", string );
      System.out.printf( "%s%n", integer );  // implicit call to toString
   } // end main
} // end class CharStringConversion
```
