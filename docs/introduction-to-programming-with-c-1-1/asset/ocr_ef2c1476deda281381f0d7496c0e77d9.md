```
strncpy(dest,src,n);
```

Here n is the number of characters to be copied.

# Working

+   - If source string is less than n, the entire string is copied from source to destination and then null character is placed at the end.
+   - If the source string src is longer than n characters, only n characters are copied into destination. Then, the destination string will not have a delimiter '\0' and hence it will be invalid string.

Ex:

```
char s1[10];
```

```
char s2[8]="VTU123";
```

```
strncpy(s1,s2,5);
```
