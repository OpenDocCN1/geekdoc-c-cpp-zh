# Reading/writing single dimensional arrays:

Syntax for reading:

```
for(i=0; i<n; i++)
{
    scanf("%d",&a[i]);
}
```

Where n is the no. of elements of an array.

Syntax for writing:

```
for(i=0; i<n; i++)
{
    printf("%d\n",a[i]);
}
```
