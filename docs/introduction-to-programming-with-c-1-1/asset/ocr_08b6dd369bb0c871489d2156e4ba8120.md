# Function with parameters and no return values

This is called “void functions with parameters”. There is a data transfer from the calling function to the called function using parameters. But, no data transfer from called function to the calling function.

```
/*program to demonstrate Function with parameter and no return values*/
#include<stdio.h>

void add(int x,int y);
```
