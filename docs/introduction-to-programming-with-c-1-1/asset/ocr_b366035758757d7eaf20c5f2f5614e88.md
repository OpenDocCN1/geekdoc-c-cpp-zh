fputc(c,fp1);

C is character to be inserted to a file

Fp1 is a file pointer returned by fopen

C=fgetc(fp1);

Returns a character from the file pointed by fp1.

Example:

Program to copy a single character from one file to another file.

```
void main()
{
    FILE *fp1,*fp2;
    char c;
    fp1=fopen("f1.txt","r");
    fp2=fopen("f2.txt","w");
    c=fgetc(fp1);
    fputc(c,fp2);
}
```
