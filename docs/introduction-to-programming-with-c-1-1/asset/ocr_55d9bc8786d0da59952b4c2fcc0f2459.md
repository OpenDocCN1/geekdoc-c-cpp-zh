# 5) The & operator can be used to quickly check if a number is odd or even

The value of expression (x & 1) would be non-zero only if x is odd, otherwise the value would be zero.

```
intmain()
{

intx = 19;

(x& 1)? printf("Odd"): printf("Even");

return0;

}
```

// Output: Odd
