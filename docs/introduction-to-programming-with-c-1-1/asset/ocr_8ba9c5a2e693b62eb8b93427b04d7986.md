# for loop

Using this we can execute set of statements repeatedly for a specified number of times. So it’s also called as counter controlled loop. It’s a pretest or top testing loop.

# Syntax

```
for(initialization;condition check; updation)
{
    Statements
}
```

# working:

+   1. Here initialization, condition check and updation is done in same statement.
+   2. Initialization of the loop counter is performed
