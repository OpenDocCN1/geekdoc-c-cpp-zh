# Program to read a line from file

```
#include<stdio.h>
void main()
{
    FILE *fp;
    char str[15];
    char *ps;
    fp=fopen("input.dat","r");
    ps=fgets(str,10,fp);
    if(ps!=NULL)
    {
        puts(str);
    }
    else
        printf("unsuccessfulreading");
}
```

# Syntax of fputs:

```
Fputs(str,fp);
```

Str string to be written to a file pointed by fp.It doesn’t automatically writes a new line to file.If its present then only it writes.

# fgetc and fputc():

fgetc () is used to read a character from the file.

fputc() is used write a character to a file.
