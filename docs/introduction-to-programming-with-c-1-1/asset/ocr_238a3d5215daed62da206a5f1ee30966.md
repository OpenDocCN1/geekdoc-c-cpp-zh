```c
#include<stdio.h>

void exchange(intm,int n);

void main()
{
    int a=10,b=20;
    exchange(a,b);
    printf("a=%d\nb=%d\n",a,b);
}

void exchange(intm,int n)
{
    int temp;
    temp=m;
    m=n;
    n=temp;
}
```
```

Output:

a=10

b=20

Working:

+   - Execution starts from main() and the variables a and b are assigned the values 10 and 20 respectively.
+   - The function exchange() is called with actual parameter a and b whose values are 10,20
+   - In exchange() function, the formal parameter m and n receive 10 and 20 respectively.
+   - The values of m and n are exchanged here.
+   - But, the values of actual parameters a and b in function main() have not been exchanged.
