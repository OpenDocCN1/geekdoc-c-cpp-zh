# NESTED STRUCTURES:

A structure which includes another structure is called as nested structure(i.e) a structure can be used a member of another structure.

Example:

```
struct subject
{
        int marks1;
        int marks2;
        int marks3;
};
typedef struct
{
        char name[10];
        int usn;
        struct subject marks;
}STUDENT;
```

The above structure consists of a member marks whose type is struct subject(another structure). So this is called as nested structure.

```
STUDENT s;
```

We can access the fields suing the dot operator as follows:

```
s.name;

s.usn;

s.marks.marks1;

s.marks.marks2;

s.marks.marks3;
```

# STRUCTURE CONATINING ARRAYS:

A single or multi dimensional array of int, float,char and double can be used within the structure

Syntax:

```
Typedef struct
{
        Char name[10];
        Int marks[3];
}STUDENT;
```
