# The break statement

It’s a jump statement which can be used in switch statement and loops.

# Working

+   1. In switch statement it causes control to terminate switch statement and statement following switch statement will be executed.
+   2. If break is executed in loop(for, while, do-while), the control comes out of the loop and the statement following the loop will be executed.

Note: if break appears in the inner loop of a nested loop, control only comes out of the inner loop.
