# Difference between while-loop and do-while loop

|  | While loop | Do-while loop |
|---|---|---|
| **1** | **Syntax**<br><br>initialization;<br><br>while(condition)<br><br>{<br><br>Statement;<br><br>updation;<br><br>}<br><br>Statement; | **Syntax:**<br><br>Initialization;<br><br>do<br><br>{<br><br>statement;<br><br>updation;<br><br>}while(condition);<br><br>Statement; |
| **2** | It is a top-testing or entry control loop since the condition is checked in the beginning itself | It is a bottom-testing or exit control loop since the condition is checked at the bottom of the loop |
| **3** | It is pre-test loop and if the expression is evaluated to false in the beginning itself, then the statements within the body of the loop will not be executed even once. | It is post-test loop and the body of the loop will be executed atleast once even if the condition is false. |
