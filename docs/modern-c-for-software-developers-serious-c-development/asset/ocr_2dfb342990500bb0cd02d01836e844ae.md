# Formatted Input For A File

The function fscanf reads data from a text file and puts the data into variables. The data
elements in the file must be separated by white space. fscanf returns EOF if there is an
er or an attempt is made to read past the end of the file. Here is an example:

```
#include <stdio.h>

int main(void)
{
    FILE *fp;
    char name[1024];
    float length;
    int mass;

    fp = fopen("animals.txt", "r");
    while (fcanf(fp, "%s %f %d", name, &length, &mass) != EOF)
        printf("%s animal, %d lbs, %.1f meters\n", name, mass, length);

    fclose(fp);
}
```

# Writing To Files

We open a file for writing with fopen("filename", "w"). If the file already exists, it is
truncated to length 0.

The file read functions getc, fgets and fscanf have file write analogues: fputc, fputs
printf. We use these functions as follows:

```
#include <stdio.h>

int main(void)
{
    FILE *fp;
    int x = 32;

    fp = fopen("output.txt", "w");
    fputs(\'B', fp);
    fputc('\n', fp);
    fprintf(fp, "x = %d\n", x);
    fputs("Hello, world!\n", fp);
```
