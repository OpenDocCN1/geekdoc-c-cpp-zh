# Structured Binding For Arrays

```
// braced initialization of an array
int arr[] = { 47, 11 };
```

```
// structured binding of x and y to the array
auto [x, y] = arr;
```

```
// error: all of the elements of arr are not bound
auto [z] = arr;
```

# Inheritance And Structured Bindings

All of the non-static data members of a class used in a structured binding are members of the same class. Structured bindings do not support inheritance.

```
#include <iostream>
struct Foo {
    int a;
    int b;
    Foo(int x, int y) { a = x; b = y; }
}

struct Bar : Foo {
    int c;
    Bar(int val) : Foo(1, 2) { c = val; }
}

int main() {
    Foo foo{1, 2};
    auto [i, j] = foo; // OK
    Bar bar(3);
    auto [i, j, k] = bar{}; // Compile-Time ERROR
}
```

```
// output
error: cannot decompose type 'Bar': both it and its base class
'Foo' have non-static data members
```
