generate different versions of the function for handling the different types that are used
by the function.

Since C++ does not recognize the end-of-line as a statement terminator, the template
clause of a generic function definition does not have to be on the same line as the
function declaration. Thus, for readability, we can specify the swapargs function
template as follows:

```
template <class Ttype>
void swapargs(Ttype &a, Ttype &b)
{
    Ttype temp;
    temp = a;
    a = b;
    b = temp;
}
```

# A Function With Two Or More Generic Types

We can specify more than one generic data type in a function template declaration by
using a comma-separated list of template types.

```
#include <iostream>
using namespace std;

template <class Ttype1, class Ttype2>
void foo(Ttype1 x, Ttype2 y)
{
    cout << x << ' ' << y << '\n';
}

int main()
{
    // call foo with different argument types
    foo(10, "I like C++");
    foo(98.6, 19L);

    return 0;
}

// output
10 I like C++
```
