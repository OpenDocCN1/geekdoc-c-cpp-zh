# Modern C++: Constexpr If Statements (C++17)

Suppose that we have an if statement that can be evaluated at compile-time, then C++ lets us discard branches of this if statement at compile-time based on the evaluation of the constant if expression. This is done using the following syntax:

```
if constexpr(condition)

if constexpr(condition)
    statement1; // Discarded if condition is false
else
    statement2; // Discarded if condition is true
```

Here is an example that this uses (type traits):

```
// the std::is_integral<T> predicate function evaluates to true
// if T is an integer type and is false otherwise

#include <iostream>
#include <type_traits>

template <typename T>
constexpr bool IntegralTest()
{
    if constexpr (std::is_integral<T>::value) {
        return true;
    }
    else {
        return false;
    }
}

int main()
{
    static_assert(IntegralTest<int>() == true);
    static_assert(IntegralTest<char>() == true);
    static_assert(IntegralTest<char*>() == true);
}

// output
error: static assertion failed
```
