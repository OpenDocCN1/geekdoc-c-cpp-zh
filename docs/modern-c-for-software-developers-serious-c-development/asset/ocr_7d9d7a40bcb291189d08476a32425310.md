// point to Derived2
p = &d2;

Notice that the keyword virtual in the base class precedes the rest of the function declaration. The keyword virtual is not needed when vfunc() is redefined in Derived1 and Derived2.

The kind of object to which the base class pointer p points, determines which version of vfunc() is executed. This is run-time polymorphism.

A virtual function must be a non-static member of a class. Additionally, virtual functions cannot create friend functions. Finally, constructors cannot be virtual, but destructors cannot.
