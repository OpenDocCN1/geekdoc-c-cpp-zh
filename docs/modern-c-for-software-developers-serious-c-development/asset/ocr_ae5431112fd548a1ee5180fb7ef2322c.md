```
cout << "Original a, b: " << a << ' ' << b << '\\n';

// calls the explicitly overloaded swaparaps()
swaparaps(i, j);
// calls the generic swaparaps()
swaparaps(x, y);
// calls the generic swaparaps()
swaparaps(a, b);

cout << "Swapped i, j: " << i << ' ' << j << '\\n';
cout << "Swapped x, y: " << x << ' ' << y << '\\n';
cout << "Swapped a, b: " << a << ' ' << b << '\\n';

return 0;

// output
Original i, j: 20 10
Original x, y: 10.1 23.3
Original a, b: z x
Inside swaparaps for int specialization.
Inside template swaparaps.
Swapped i, j: 20 10
Swapped x, y: 23.3 10.1
Swapped a, b: z x
```

In the previous example, because of the explicit function definition void swaparaps(int &&, int &b), the compiler knows that it must override the generic function with the explicitly specialized version when swaparaps has two arguments.

We can signal explicit specialization by declaring an explicit swaparaps function in any of the three following ways:

```
template<> void swaparaps<int, int>(int &a, int &b) {
or

void swaparaps<int, int>(int &a, int &b) {
or

void swaparaps(int&, int&) {...} // ordinary function
```
