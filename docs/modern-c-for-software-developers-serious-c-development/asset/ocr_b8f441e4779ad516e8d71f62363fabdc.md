# Stepping Through A Program

While we are stopped at a breakpoint, we can step through a program, one program line at a time.

Both the next and step commands tell gdb to execute the next line of the program, and then pause again. If that line is a function call, then next and step will give different results. If we use step, then the program will pause will be at the first line of the function; if we use next, then the program will pause be at the line following the function call.

```
gdb> next      // gdb n
or:
gdb> s       // gdb s
```

# Stepping Out Of A Function

If we have used step to step into a function, we can use gdb> finish (or gdb fin) to step out of the function.

# Listing Program Statements

When we are at a breakpoint, we can list the program line at which we are stopped along with a few lines around it:

```
gdb> l
```
