We can print the value of the pointer p:

```
gdb> print p
$1 = (int *) 0x0
```

The value of the pointer is 0.

Lets look at code near to the statement where the segmentation fault occurred:

```
gdb> list
int x = 7;
int *p << "x = " << x;
cout << "The pointer points to the value " << *p;
```

Quit the debugger session:

```
gdb> quit
```

# SIGSEGV Signals

When we receive the signal SIGSEGV (segmentation fault), the gdb debugger populates the $siginfo structure. This structure can be examined to determine the faulty address:

```
gdb> p $siginfo._sifields._sigfault.si_addr
```

A value such as: $1 = (void *) 0x0 indicates a null pointer.
