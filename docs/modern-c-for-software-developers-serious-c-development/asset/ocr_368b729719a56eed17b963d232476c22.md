# ## The this Pointer

Every C++ object has a this pointer which is a pointer to the object itself. The value of
this pointer is the address of the object.

When a non-static member function is called, it is automatically passed the this pointer
as an implicit argument.

Consider the following program:

```
#include <iostream>

class Foo {
    int i;
    public:
    Foo(int x) { i = x; } // this pointer passed implicitly
    {
        return this->i*this->i;
    }
};

int main() {
    Foo(5);
    std::cout << foo.square() << std::endl;
}

// output
25
```
