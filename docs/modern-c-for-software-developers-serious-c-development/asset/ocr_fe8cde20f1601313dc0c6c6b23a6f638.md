# Modern C++: boolalpha (C++20)

The boolalpha keyword can be inserted into streams, bool values in converted to their textual representations: true or false, instead of integral values.

```
#include <iostream>

int main() {
    using namespace std;

    cout << boolalpha << "hello " << true << endl;
    cout << boolalpha << (10 < 1) << endl;
}

// output
hello true
false
```
