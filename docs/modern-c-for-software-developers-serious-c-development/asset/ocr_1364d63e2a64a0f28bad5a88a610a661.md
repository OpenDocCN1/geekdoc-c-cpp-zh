// body of function

}
nTtype is a symbolic name or placeholder for the data type used in the function (read
Type as template type). Ttype is a generic type. This symbolic name may be used
within the function's parameter list and body as well as the return type. However, it is
only a placeholder that the compiler will automatically replace with an actual data type
when it creates a specific version of the function.

Notice that a template function declaration creates a family of functions parameterized
on Ttype.

Although the use of the keyword class to specify a generic type in a template
declaration is traditional, we can also use the keyword typename.

Here is an example of a function template:

```
// function template example: swap two values
#include <iostream>
using namespace std;

// This is a function template declaration
template<class Ttype> void swapargs(Ttype &a, Ttype &b)
{
Ttype temp;
temp = a;
a = b;
b = temp;
}

int main()
{
    int i = 10, j = 20;
    double x = 10.1, b = 23.5;
    char a = 'x', b = 'z';

    cout << "Original i, j: " << i << ' << ' << j << "\n";
    cout << "Original x, y: " << x << ' << ' << y << "\n";
    cout << "Original a, b: " << a << ' << ' << b << "\n";

    swapargs(i, j);
}

// swap integers
```
