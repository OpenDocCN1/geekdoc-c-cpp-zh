## C 语言复习

## 声明与定义

在 C 和 C++ 中，标识符是用户分配给程序元素的名称，例如变量、类型、模板、类、函数或命名空间。

变量存储一个值。在 C 和 C++ 中，变量在使用之前之前必须进行声明。声明指定了变量的类型和名称。声明隐式地指定了变量存储一个值所需的内存量。例如：

```
int x;
```

声明 x 是一个 `int` 类型的变量，这种类型的变量需要 32 位内存。

函数声明由函数返回类型、函数名和函数参数的类型组成。例如：

```
int foo(int x, int y);
```

变量定义会创建一个变量并可能为该变量设置（赋值）值：

```
int x               // 变量 x 的声明
x = 5;             // 变量 x 的定义
```

此定义将值 5 放入分配给变量 x 的内存中。

声明和定义可以合并为一个语句。例如：

```
int x = 5;
或
int x;    // x 持有某个未知值
```

对于 `int`、`long`、`float` 和 `double` 等基础 C 和 C++ 类型，声明也是一种定义。但对于我们之后会遇到的更复杂类型，情况并非如此。

函数定义告诉编译器函数如何工作。它展示了由函数执行的指令：

```
// 函数 foo 的声明（也称为函数原型）
int foo();
// 函数 foo 的定义
int foo () {
int x = 5;
return x;
}
```

## 语句终止

在 C 和 C++ 中，语句不通过换行符（'\n'）终止。它们通过分号（;）终止。因此，C 和 C++ 语句可以自由地跨行。

## 字面量

字面量是常量。C 有四种字面量：整数字面量（如 45）、浮点数字面量（如 3.12）、字符串字面量（如 "hello world"）以及字符字面量（如 'c'）。

字面量是直接表示值的程序元素。例如，509 是一个整数字面量或常量。

## 十进制和八进制字面量

十六进制和八进制字面量是整数类型的字面量。

十六进制字面量以前缀 0x 或 0X 开头，后面是一系列 `0 到 9, a-f, A-F` 范围内的数字。例如：

```
0x23A, 0xB4C, 0XFEA, 0DEAD, 0x5
```

十六进制字面量的进制为 16。

八进制字面量以 0 开头，后面是一系列 0-7 范围内的数字。例如：

```
045, 076, 06210
```

八进制字面量的进制为 8。

## 浮点字面量

浮点字面量表示实数。实数有一个实部、小数部分可选的指数部分：

```
9.87654
987.654
9.87654e+006
9.87654e-005
```

e 是无理数 2.71821...

有效的浮点字面量具有以下属性：

- 在小数形式下，数字必须包含小数点或指数部分或两者都有。
- 在指数形式下，数字必须包含指数部分。

浮点数的类型为 `float`、`double` 或 `long double`。

## 字符字面量

字符字面量是用单引号括的单个字符。如果单引号内有多个字符，将抛出错误。

字符字面量的类型为 `char`：

```
char chr = 'G';
wchar_t chr = L'A'; // wchar_t（宽）
```

## 字符串字面量

字符串字面量是双引号内的字符序列。

```
char* s0 = "hello world"; // char*
char* s1 = u8"hello world"; // char*, UTF-8 
char_t* s2 = L"hello world"; // char*, wchar_t 编码
```

## 字面量前缀与后缀

在 C 中，字面量可以有前缀和后缀。整数字面量的前缀表示数字的基数。后缀指示整数的类型。例如，在 0xDEAD 中，0x 意味着 DEAD 是一个十六进制整数（16 进制）。
