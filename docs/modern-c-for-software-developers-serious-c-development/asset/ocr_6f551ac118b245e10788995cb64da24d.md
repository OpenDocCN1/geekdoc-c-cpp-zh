# Modern C++: Static Assertions (C++11)

The `static_assert` directive tests a constant expression at compile time. This constant expression must be an integral expression that can be cast to a `bool` type. If the expression is false, the compiler issues an error message and stops the compilation process; otherwise the `static_assert` has no effect. The condition that is being tested must be a constant integral expression that can be evaluated at compiletime.

The syntax for static assertions is:

```
static_assert( expression, string_literal );
```

`expression` is a predicate that is checked for truth or falsity at compile-time. If the condition is false, the compiler prints the string literal and stops.

Here is an example:

```
int main()
{
    constexpr double x = 123;
    static_assert(x == 456, "x value is not 456");
}

// output
static assertion failed: x value is not 456
```
