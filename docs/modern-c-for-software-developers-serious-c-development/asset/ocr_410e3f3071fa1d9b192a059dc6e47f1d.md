The promise_type struct must have a method called yield_value that parameter T has the type of the value that will be returned to the calling function. When the coroutine executes the co_yield statement, the yield_value function is called. yield_value returns an awaiter std::suspend_always_always object which will suspend the coroutine and then enables the calling function to fetch the intermediate value.

To enable the calling function to fetch the intermediate value, ReturnObject defines a utility method get_value which returns the promise_type data member val_. handle.promise() gets the promise type object.
