void clear(); Removes all the elements in a map.

bool empty() const; Returns true if the map is empty, false otherwise.

void erase(iterator i); Removes the element pointed to by i.

# Inserting Elements Into A Map

The function declaration for insert is:

```
iterator map_name.insert({key, element})
```

Note the parentheses which are required since we are inserting a pair object. This member function returns an iterator to the inserted element.

Here is an example:

```
#include <map>
#include <iostream>
#include <string>
namespace std;
int main() {
    // initialize an int map container
    map<int, int> mp;
    // insert some elements
    mp.insert({{2, 30}});
    mp.insert({1, 10});
    // declare an iterator that will iterate over a map<int,int>
    map<int, int>::iterator p;
```
