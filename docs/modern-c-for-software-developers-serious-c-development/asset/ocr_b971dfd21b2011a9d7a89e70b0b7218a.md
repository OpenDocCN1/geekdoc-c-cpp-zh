# front

char& string::front();
const char& string::front() const;

returns a reference to the first element of a string. If the string object is const-qualified,
the function returns a const char&. Otherwise, it returns a char&.

# Numeric To String

This string method converts a numeric argument to a std::string;

```
std::to_string(1.2);      // "1.2"
std::to_string(123);      // "123"
```

# replace

Replaces the portion of a string that begins at character position pos and spans len
characters by new contents:

```
string& replace (size_t pos, size_t len, const string& str);

string& replace (iterator i1, iterator i2, const string& str);
```

returns a pointer to the string after replacement.

# Replace all occurrences of a char with another char

```
#include <algorithm>
#include <string>

void foo() {
    std::string s = "example string";
    // replace each 'x' with 'y'
    std::replace( s.begin(), s.end(), 'x', 'y');
}
```
