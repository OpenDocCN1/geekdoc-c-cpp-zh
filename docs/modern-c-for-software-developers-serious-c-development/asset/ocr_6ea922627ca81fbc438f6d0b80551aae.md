# Returning A Value From A Coroutine

If co_return returns a value then the coroutine must in addition to the declaration of return_void(), declare a function called return_value in ReturnObject in order to return a value.

In the following example, the coroutine returns the string "hello, I am returning" when it returns:

```
#include <coroutine>
#include <iostream>

using namespace std;

struct ReturnObject {
    struct promise_type {
        promise_type() = default;

        ReturnObject get_return_object() {
            return ReturnObject();
        }

        std::suspend_never initial_suspend() {
            return {};
        }

        std::suspend_never final_suspend() noexcept {
            return {};
        }
};
void return_void() {}
```
