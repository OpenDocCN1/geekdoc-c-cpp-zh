# #line

The __LINE__ identifier contains the line number of the currently compiled line of code.
The __FILE__ identifier is a string that contains the name of the source file being compiled. #line changes the line number and optionally the file name. The general formor #line is:

```
#line number "filename"
```

where number is any positive integer. This becomes the new value of __LINE__ and the
optional filename is any valid file identifier, which becomes the new value of __FILE__.
#line is primarily used for debugging and special applications.

# #pragma

#pragma is a compiler defined directive that allows various instructions to be given to a
compiler. We must check the compiler's documentation for it's pragma details and
options.
