# Template Type Deduction For Classes

Until C++17, we could not deduce the types of parameters in template classes. So if we
wanted to define a vector of type *int*, we would have to do:

```
std::vector<int> x = {1,2,3,4}
```

That is, the compiler could not read the initialization values and deduce the template
type as *int.

With C++17, the compiler can apply type deduction to class templates, and thus we can
specify the previous declaration as:

```
std::vector x = {1,2,3,4}
```

This will instantiate a vector of type *std::vector<int>*. The compiler examines the
constructor arguments to deduce the template types used in a class specialization.
