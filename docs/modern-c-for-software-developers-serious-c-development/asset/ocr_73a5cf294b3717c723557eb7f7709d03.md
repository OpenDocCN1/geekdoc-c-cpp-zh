# Modern C++: #pragma once

#pragma once is not part of the ISO standard, but it is implemented by all modern C++ compilers.

The use of #pragma once in a header file can reduce build times, as the compiler won't open and read an include file after the first #include of the file in a translation unit. It has an effect similar to the **include guard idiom**, which uses a preprocessor macro definition to prevent multiple inclusions of the contents of a file. #pragma once also helps to prevent violations of the **one definition rule**, the requirement that all templates, global functions and objects have no more than one definition in our code.

There is no advantage in using both the #pragma once and the include guard idiom in a header file.

#pragma once is supported in GCC since version 5.4.
