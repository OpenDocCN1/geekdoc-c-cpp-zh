# Allocating Memory For Objects

We can allocate memory for objects with *new*. When we do this, an object is created and a pointer to the object is returned. This dynamically created object acts just like any other object. When it is created, its constructor function (if it has one) is called. When the object is freed, its destructor function is executed.

```
#include <iostream>
#include <new>
#include <cstring>

using namespace std;

class Balance {
    double cur_bal;
    char name[80];
public:
    void set(double bal, const char *s)
    {
        cur_bal = bal;
        strcpy(name, s);
    }

    double get_bal() {
        return cur_bal;
    }
};
```
