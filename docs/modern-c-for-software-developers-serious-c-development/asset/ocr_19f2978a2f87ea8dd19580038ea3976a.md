In the following example, a member function of a class object is invoked through aunction object:

```
#include <iostream>
#include <functional>

class Foo {
public:
    void print(const char* str) const {
        std::cout << str << std::endl;
    }
};

int main() {
    Foo foo;
    std::function<void(Foo&, const char*)> fun = &Foo::print;

    // invoke the print member function
    const char* p = "hello world";
    fun(foo, p);
}

// output
hello world
```

Notice the definition of the class template fun:

```
std::function<void(Foo&, const char*)> fun = &Foo::print;
```
