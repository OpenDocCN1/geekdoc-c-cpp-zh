# The typename Keyword

The typename keyword can be used instead of the keyword class in a template definition. For example, the swapargs function template could be specified like this:

```
template <typename X>
void swapargs(X &a, X &b)
{
    X temp;
    temp = a;
    a = b;
    b = temp;
}
```
