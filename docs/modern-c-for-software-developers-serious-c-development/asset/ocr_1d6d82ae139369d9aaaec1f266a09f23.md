# Suspending A Coroutine

A coroutine can suspend it's execution. It cannot be suspended by the caller. When a coroutine suspends itself, it saves it's state on the heap and returns a handle to the ReturnObject(to the function that called the coroutine). This handle can be used the calling function to resume or destroy the coroutine.

The points of the coroutine at which the coroutine is suspend are identified by the co_await and co_yield keywords. A coroutine can have multiple suspend points.
