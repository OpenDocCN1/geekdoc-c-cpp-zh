In this case, a traditional C-style cast is used to actually perform the cast. This is safe because the if statement checks the validity of the type cast using typeid before the cast is actually performed. However, a better way to accomplish this is to replace the typeid operator with a dynamic_cast:

```
dp = dynamic_cast<Derived *> (bp);
```

The parentheses around bp are required.

# dynamic_cast And Different Derived Types

Consider the following example:

```
#include <iostream>
using namespace std;

class Base
{
    virtual const char* print()
    {
        cout << "base class" << endl;
        return "in base class";
    }
}

class Derived1 : public Base
public:
    const char* print()
    {
        cout << "derived1 class" << endl;
        return "derived1 class";
    }
}

class Derived2 : public Base
public:
    const char* print() {
        cout << "derived2 class" << endl;
        return "derived2 class";
    }
};
```
