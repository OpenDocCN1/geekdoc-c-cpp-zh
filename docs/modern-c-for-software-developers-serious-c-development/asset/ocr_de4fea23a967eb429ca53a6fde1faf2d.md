# SonarLint

A linter is a static code analysis tool that examines program statements and flags
statements that though syntactically correct, are not idiomatic C++ or have a better or
sfer syntactic constructions. Use of a good linter is an excellent way to improve the
quality of a code base.

SonarLint is an excellent linter. SonarLint integrates seamlessly with Visual Code.
Install it from the VisualCode Extensions menu.

SonarLint examines our code while it being written in the code editor. An expression
that is not idiomatic C++ or those syntax could be improved will be indicated by an
squiggly line under the expression. If we right click on the squiggly line, SonarLint will
explain what the problem is with the expression and also suggest the solution.

The best practise is to use a linter such as SonarLint to monitor code quality in real-
time.
