
```cpp
cout << "Original a, b: " << a << ' ' << b << '\n';

// calls the explicitly overloaded swaparaps()
swaparaps(i, j);
// calls the generic swaparaps()
swaparaps(x, y);
// calls the generic swaparaps()
swaparaps(a, b);

cout << "Swapped i, j: " << i << ' ' << j << '\n';
cout << "Swapped x, y: " << x << ' ' << y << '\n';
cout << "Swapped a, b: " << a << ' ' << b << '\n';

return 0;

// output
Original i, j: 20 10
Original x, y: 10.1 23.3
Original a, b: z x
Inside swaparaps for int specialization.
Inside template swaparaps.
Swapped i, j: 20 10
Swapped x, y: 23.3 10.1
Swapped a, b: z x
```

In the previous example, because of the explicit function definition void swaparaps(int &&, int &b), the compiler knows that it must override the generic function with the explicitly specialized version when swaparaps has two arguments.

We can signal explicit specialization by declaring an explicit swaparaps function in any of the three following ways:

```cpp
template<> void swaparaps<int, int>(int &a, int &b) {
or

void swaparaps<int, int>(int &a, int &b) {
or

void swaparaps(int&, int&) {...} // ordinary function
```

The template<> declaration indicates to the compiler that an explicit declaration is being made.

# Overloading Function Templates

We can overload a function template with respect to the number of function parameters:

```cpp
// Overload a function template declaration
#include <iostream>
using namespace std;

// The first overloaded version of the func() template.
template <class Ttype>
void func(Ttype a)
{
    cout << "Inside func(Ttype a)";
}

// The second overloaded version of the func() template.
template <class Ttype1, class Ttype2>
void func(Ttype1 a, Ttype2 b)
{
    cout << "Inside func(Ttype1 a, Ttype2 b)";
}
```

```cpp
int main()
{
    func(10);      // calls func(X)
    func(10, 20);  // calls func(X, Y)
    return 0;
}
```

```cpp
// output
Inside func(Ttype a)
Inside func(Ttype1 a, Ttype2 b)
```

# C++ Templates: Generic Classes

A class template is a family of classes where the actual type of the data that is manipulated in the class is specified as a generic parameter.

Class templates are useful when classes use logic that can be generalized. For example, the algorithm that maintains a queue of integers will also work for a queue of characters.

When we create a class template, it can perform the operation we define, such as maintaining a queue or a linked list, for any type of data. The compiler will automatically create the correct type of object at compile-time, based upon the type we specify when the object is instantiated.

The general form of a class template declaration is:

```cpp
template <Ttype>
class class-name {
.
}
```

This is a declaration and not a definition. Since the parameter Type is a generic type, this declaration declares a family of classes parameterized on Type. A definition instantiates an object using a particular template type.

A specific class is instantiated when a particular Type (template type) is specified. If necessary, we can specify more than one generic data type in a template declaration using a comma-separated list of template types.

Once we have defined a generic class (template class), we can create a specific instance of this class using the following syntax:

```cpp
class-name<type> obj;
```

Here, **type** is the type of the data that the class will be operating upon. The **class-name<type>** declaration determines the type of object that will be instantiated.

Member functions of a generic class are themselves automatically generic. We do not need to use function templates to explicitly specify them as in a class declaration.

In the following program, a stack template class is declared:

```cpp
#include <iostream>
using namespace std;

const int SIZE = 10;

// Declare a stack template class
template <class Ttype>
class Stack {
    Ttype my_stack[SIZE]; // the stack
    int num_el; // number of elements in the stack
public:
    Stack() : num_el = 0; } // constructor
    void push(Ttype obj); // push on stack
    Ttype pop(); // pop off stack
};

// Push function
template <class Ttype>
void Stack<Ttype>::push(Ttype obj) {
    if (num_el == SIZE) {
        cout << "Stack is full.\n";
        return;
    }
    my_stack[num_el] = obj;
    num_el++;
}

// Pop function
template <class Ttype>
Ttype Stack<Ttype>::pop() {
  if (num_el == 0) {
    cout << "Stack is empty.\n";
    return Ttype();
  }
  num_el--;
  return my_stack[num_el];
}

int main() {
  // Demonstrate with two stacks.
  Stack<char> s1, s2; // create two character stacks
  int i;
  s1.push('a');
  s2.push('x');
  s1.push('b');
  s2.push('y');
  s1.push('c');
  s2.push('z');

  for (i = 0; i < 3; i++) cout << "Pop s1: " << s1.pop() << "\n";
  for (i = 0; i < 3; i++) cout << "Pop s2: " << s2.pop() << "\n";

  Stack<double> ds1, ds2; // create two double stacks
  ds1.push(1.1);
  ds2.push(2.2);
  ds1.push(3.3);
  ds2.push(4.4);
  ds1.push(5.5);
  ds2.push(0.6);

  for (i = 0; i < 3; i++) cout << "Pop ds1: " << ds1.pop() << "\n";
  for (i = 0; i < 3; i++) cout << "Pop ds2: " << ds2.pop() << "\n";
}
// output
Pop s1: c
Pop s1: b
Pop s1: a
Pop s2: z
Pop s2: y
Pop s2: x
Pop ds1: 5.5
Pop ds1: 3.3
Pop ds1: 1.1
Pop ds2: 0.6
Pop ds2: 4.4
Pop ds2: 2.2

Pay special attention to the stack declarations:

```cpp
Stack<char> s1, s2; // create two character stacks
Stack<double> ds1, ds2; // create two double stacks
```

Also notice the class function declarations:

```cpp
template <class Ttype>
void Stack<Ttype>::push(Ttype obj)
{
}
```

The template function definition must start with `template<class Ttype>`, this is followed by the return type of the function, and then the scoped function.

# Using Non-Generic Arguments with class templates

A class template can have non-template parameters. Here is an example:

```cpp
// Non-template arguments in a class template
#include <iostream>
using namespace std;

// Here, size is an int, it is not a type parameter
// since it's type is specified in the template

template <class Ttype, int size>
class Array {
    Ttype a[20];
public:
    Array(int sz) {
        int i;
        for (i = 0; i < sz; i++) a[i] = i + size;
    }

    Ttype get(int i) { return a[i]; }
}

int main() {
    Array<int, 10> ar1(2); // integer array declaration
    Array<double, 15> ar2(3); // double array declaration

    for (int i = 0; i < 2; i++) {
        cout << ar1.get(i) << " ";
        cout << std::endl;
    }

    for (int i = 0; i < 3; i++) {
        cout << ar2.get(i) << " ";
        cout << std::endl;
    }
}
// output
10 11
15 16 17
```

Look carefully at the template declaration for Array. Note that size is declared as an int and not as a generic type.

# Allowed Non-generic Template Parameters

Non-generic parameters in templates are restricted to integers, pointers, or references. Other types, such as double and float, are not allowed. This restriction has been loosened in Modern C++.

# Using Default Arguments With Class Templates

A generic type in a class template can specify a default type. For example:

```cpp
template <class Type=int>
Foo;
Foo<> foo; // the default type will be used
```

Default values are specified using the = syntax.

It is also permissible for non-generic arguments to have default values in a class declaration. The default value of the non-generic parameter will be used when an explicit value is not specified for the non-generic parameter when a particular template class is instantiated.

```cpp
template <class tType=int, int size=10>
class Foo;
Foo<> foo;
```

Here, tType defaults to int, and size defaults to 10. Notice how the class Foo is declared with <>, means Foo uses the default template parameters.
