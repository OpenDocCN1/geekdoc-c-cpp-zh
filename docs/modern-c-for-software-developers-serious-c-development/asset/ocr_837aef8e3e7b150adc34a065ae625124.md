# Using Non-Generic Arguments with class templates

A class template can have non-template parameters. Here is an example:

```
// Non-template arguments in a class template
#include <iostream>
using namespace std;

// Here, size is an int, it is not a template type parameter
// since it's type is specified in the template

templateplate <class Ttype, int size>
class Array {
    Ttype a[20];
public:
    Array(int sz) {
        int i;
        for (i = 0; i < sz; i++) a[i] = i + size;
    }

    Ttype get(int i) { return a[i]; }
}

int main() {
    Array<int, 10> ar1(2); // integer array declaration
    Array<double, 15> ar2(3); // double array declaration

    for (int i = 0; i < 2; i++) {
        cout << ar1.get(i) << " ";
        cout << std::endl;
    }

    for (int i = 0; i < 3; i++) {
        cout << ar2.get(i) << " ";
        cout << std::endl;
    }
}
// output
10 11
15 16 17
```

Look carefully at the template declaration for Arry. Note that size is declared as an int and not as a generic type.
