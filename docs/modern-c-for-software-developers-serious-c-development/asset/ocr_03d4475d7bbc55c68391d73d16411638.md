Sometimes, two function declarations will appear to be different, when in fact they are
not. For example:

```
void f(int *p);
void f(int p[]); // error, *p is same as p[]
```

A program containing these declarations will not compile. To the compiler *p is the
same as p[].

# Overloading Constructor Functions

There are three main reasons why we will want to overload a constructor: to gain
flexibility, to allow both initialized and uninitialized objects to be created, and to define
copy constructors.

# Finding the Address of an Overloaded Function

function addresses is to assign an address to a function pointer and then call this
function through the pointer.
