# # C++ Standard Library: std::string

# ## C++20 String Interpolation

In C++20 we can use std::format:

```
#include <format>

string s = std::format("From {1} to {}", "a", "b");

# From t to a
```

# ## C++17 String Interpolation

In C++17, we can use stringstreams:

```
#include <iostream>
#include <string>
#include <sstream>

using namespace std;

int main() {
    stringstream ss;
    string a = "hello";
    string b = "world";

    ss << "value is " << a << " And " << b;

    // convert the stringstream to a string
    cout << ss.str() << endl;
}

// output
value is hello And world
```

Clear the stringstream with:

```
ss.str("");
```
