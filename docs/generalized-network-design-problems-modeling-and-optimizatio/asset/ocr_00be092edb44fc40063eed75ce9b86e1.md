The initial value of all pheromone trails, \(\tau_0\) is

\(\tau_0 = \frac{1}{n \cdot L_{nn}}.\) (3.21)

where \(L_{nn}\) is the result of Nearest Neighbor, (NN) algorithm. NN is perhaps the most natural heuristic for the TSP. In the NN algorithm, the tour is always go to the nearest as-yet-unvisited location. The corresponding tour traverses the nodes in the order they were constructed.

For the pheromone evaporation phase, let \(\tau_{max}\) denote the upper bound

\(\tau_{max} = \frac{1}{1-\rho} \cdot \frac{1}{L_{nn}}.\) (3.22)

Given a randomly value \(q_0\) from the interval [0, 1], the value of the parameter \(q_0\) is modified as follows:

\(q_0 = q_0 - 0.1; \text{ if } q_0 < 0.1 \text{ then } q_0 = 0.9.\) (3.23)

As in all other ant systems, the choice of parameters in the algorithm is critical. Until now no mathematical analysis has been developed, which would give the optimal parameter in every situation.

In the proposed RACS algorithm, based on preliminary experiments, the values of the parameters were chosen as follows: \(\beta \in \{2, 5\}\), \(\rho \in (0.1, 0.5)\), \(q_0 \in \{0.9, 0.5\}\), \(c_0 = 0.1\) and \(m = 2\).
