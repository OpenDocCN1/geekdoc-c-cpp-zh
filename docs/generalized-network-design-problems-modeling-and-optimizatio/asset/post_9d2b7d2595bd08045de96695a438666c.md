
constraints (2.22) are replaced with a directed cutset constraint using Gale's [44] necessary and sufficient feasibility condition for the existence of a feasible flow.

\[
\begin{array}{ c c }
\min \sum_{e \in E} c_e x_e &  \\
\text{s.t. } z(V_k) = 1, & \forall k \in K = \{1, \dots, m\} \\
w_{ij} + w_{ji} = x_e, & \forall e = \{i, j\} \in E \\
w^{\delta^-}(V_1) = 0 &  \\
w^{\delta^-}(V_k) \le 1, & \forall k \in K_1 \\
w^{\delta^-(S)} \ge z(V_k \cap S) - z(V_1 \cap S), & \forall S \subset V, 1 \le |S| \le n - 1, \\
 & k \in K_1 \\
x, z \in \{0, 1\}. & 
\end{array}
\]

The directed cutset constraint (2.27), together with constraints (2.1), (2.11), (2.25) and (2.26), guaranteed tree design and connectivity between all clusters. We refer to this model as the *flow cut formulation* of the GMSTP and let \(P_{fcut}\) denote its set of feasible solutions in \((x, z)\)-space.

The relationship between the polyhedron defined by the linear relaxation of the flow cut formulation of the GMSTP and some of the polyhedrons of the linear relaxations of the corresponding formulations is (see [37], [142], [192]):

\(P_{spack} = P_{diskpack} = P_{fcut} = P_{mflow} = P_{bdflow}\)

## 2.3.4 A model based on Steiner tree properties

Raghavan [175] and Duin et al. [31] have transformed the GMSTP into a Steiner tree problem, which can be solved by any of the specialized algorithms developed for this problem.

### Steiner tree formulation (Raghavan [175])

The *Steiner tree formulation*, introduced by Raghavan [175], is a multicommodity flow formulation of the GMSTP, after the GMSTP has been transformed into a Steiner tree problem with degree constraints. The transformation of the GMSTP to a Steiner tree problem is achieved in the following steps: let \(s_r\) be an artificial root node, and \(T = \{t_1, t_2, \dots, t_k\}\) be a set of artificial sink nodes, which we require to be in the Steiner tree. Artificial node \(s_r\) is connected to each node \(i \in V\) with the zero cost arc \((s_r, i)\) and all nodes \(i \in V_k\) of a given cluster \(k = 1, \dots, m\) are connected with the zero cost arc \((i, t_k)\) to the corresponding artificial node \(t_k\). In this new graph, a set of commodities \(H\) is also defined, such that there is exactly one commodity \(h \in H\), originating in node \(s_r\) and terminating in node \(t_k\) for each \(k = 1, \dots, m\). The Steiner tree formulation of the GMSTP is described as follows:

```
min \sum_{e \in E} c_e x_e
s.t. \sum_{(i,j) \in A: i \in \bar{V}_k, j \in V_k} w_{ij} = 1, \quad \forall k \in K_1 \quad (2.28)
w_{ij} + w_{ji} \le 1, \quad \forall (i,j) \in A \quad (2.29)
\sum_{a \in \delta^+(i)} f_a^h - \sum_{a \in \delta^-(i)} f_a^h = \begin{cases} -1, & \text{if } i = O(h) \\ 1, & \text{if } i = D(h) \\ 0, & \text{otherwise} \end{cases} \quad \forall i \in V \text{ and } h \in H \quad (2.30)
0 \le f_{ij}^h \le w_{ij}, \quad w \in \{0, 1\}. \quad \forall (i,j) \in A, h \in H \quad (2.31)
```

The Steiner tree formulation of the GMSTP then is the standard multicommodity flow model for the Steiner tree problem with additional degree constraints (2.28) that ensure an in-degree of 1 for each of the clusters (\(k \in K\)). This formulation ensures the design of a minimum-cost directed Steiner tree, containing the root node \(s_r\), all the nodes in \(T\), and exactly one node from each cluster.

We denote by \(P_\text{steiner}\) the set of feasible solutions in \((x, z)\)-space of this formulation. In [175], Raghavan has shown that the Steiner tree formulation is equivalent to the multicommodity flow formulation, where the node variables were used to indicate whether a node is selected to be in the generalized spanning tree.

## 2.3.5 Local-global formulation of the GMSTP

Our last formulation was introduced by Pop [142] and aims at distinguishing between *global*, i.e. inter-cluster connections, and *local* ones, i.e. connections between nodes from different clusters.

We introduce variables \(y_{ij}\) (\(i, j \in \{1, \dots, m\}\)) to describe the global connections. Hence, \(y_{ij} = 1\) if cluster \(V_i\) is connected to cluster \(V_j\) and \(y_{ij} = 0\) otherwise, and we assume that \(y\) represents a spanning tree.

The convex hull of all these y-vectors is generally known as the spanning tree polytope (on the contracted graph with vertex set \(\{V_1, \dots, V_m\}\), which we assume to be complete).

Following Yannakakis [205], this polytope, denoted by \(P_\text{MST}\), can be represented by the following polynomial number of constraints:

```
\sum_{\{i,j\}} y_{ij} = m - 1
y_{ij} = \lambda_{kij} + \lambda_{jii}, \quad \text{for } 1 \le k, i, j \le m \text{ and } i \neq j \quad (2.32)
\sum_j \lambda_{kij} = 1, \quad \text{for } 1 \le k, i, j \le m \text{ and } i \neq k \quad (2.33)
\lambda_{kki} = 0, \quad \text{for } 1 \le k, j \le m \quad (2.34)
y_{ij}, \lambda_{kij} \ge 0, \quad \text{for } 1 \le k, i, j \le m.
```

where the variables \(\lambda_{kij}\) are defined for every triplet of nodes \(k, i, j\), with \(i \neq j \neq k\) and their value for a spanning tree is:

\(\lambda_{kij} = \left\{ \begin{array}{ll} 1 & \text{if } j \text{ is the parent of } i, \text{ when we root the tree at } k \\ 0 & \text{otherwise.} \end{array} \right.\)

The constraints (2.32) mean that an edge \((i, j)\) is in the spanning tree if and only if either \(i\) is the parent of \(j\) or \(j\) is the parent of \(i\). The constraints (2.33) mean that, if we root a spanning tree at \(k\), every node other than node \(k\) has a parent. Finally, the constraints (2.34) mean that the root \(k\) has no parent.

If the vector \(y\) describes a spanning tree on the contracted graph, the corresponding best (w.r.t. minimization of costs) local solution \(x \in \{0, 1\}^{|E|}\) can be obtained via one of the following two methods, described by Pop [142] using dynamic programming (see Section 2.2) or integer linear programming.

If the 0-1 vector \(y\) describes a spanning tree on the contracted graph, the corresponding local solution \(x \in \{0, 1\}^{|E|}\) minimizing the costs can be obtained by solving the following integer linear programming problem:

\[
\begin{aligned}
\min & \sum_{e \in E} c_e x_e \\
\text{s.t. } & z(V_r) = 1 && \forall k \in K = \{1, \dots, m\}, \\
& x(V_r, V_r) = y_{lr} && \forall l, r \in K = \{1, \dots, m\}, l \neq r, \\
& x(i, V_r) \le z_i && \forall r \in K, \forall i \in V \setminus V_r, \\
& x_e, z_i \in \{0, 1\} && \forall e = \{i, j\} \in E, \forall i \in V.
\end{aligned}
\]

where \(x(V_r, V_r) = \sum_{i \in V_r, j \in V_r} x_{ij}\) and \(x(i, V_r) = \sum_{j \in V_r} x_{ij}\).

For given \(y\), we denote the feasible set of the linear programming relaxation of this program by \(P_{local}(y)\). The following result holds (Pop et al. [150]):

**Proposition 2.7.** If \(y\) is the 0-1 incidence vector of a spanning tree of the contracted graph, then the polyhedron \(P_{local}(y)\) is integral.

**Proof.** Suppose that the 0-1 vector \(y\) describes a spanning tree \(T\) of the contracted graph. Then, in order to prove that the polyhedron \(P_{local}(y)\) is integral, it suffices to show that every solution of the linear programming relaxation can be written as a convex combination of solutions corresponding to spanning trees:

\((x, z) = \sum \lambda_T (x_T, z_T).\)

The proof is by induction, on the support of x, denoted by supp(x) and defined as follows:

$$supp(x) := \{x_e \mid x_e \neq 0, e \in E\}.$$

Suppose that there is a global connection between the clusters \(V_l\) and \(V_r\) (i.e. \(y_{lr} = 1\)) then

$$1 = x(V_l, V_r) = \sum_{i \in V_l} x(i, V_r) \le \sum_{i \in V_l} z_i = 1,$$

which implies that \(x(i, V_r) = z_i\).

We claim that \(supp(x) \subseteq E\) contains a tree connecting all clusters. Assume the opposite is true and let \(T^1 \subseteq E\) be a maximal tree in supp(x). Since \(T^1\) does not connect all clusters, there is some edge \((l, r)\) with \(y_{lr} = 1\), such that \(T^1\) has some vertex \(i \in V_l\) but no vertex in \(V_r\).

Then \(z_i > 0\), and thus \(x(i, V_r) = z_i > 0\), so \(T^1\) can be extended by some \(e = (i, j)\) with \(j \in V_r\), which is a contradiction.

Now, let \(x^{T^1}\) be the incidence vector of \(T^1\) and let

$$\alpha := \min\{x_e \mid e \in T^1\}.$$

If \(\alpha = 1\), then \(x = x^{T^1}\) and we are done. Otherwise, let \(z^{T^1}\) be the vector with \(z_i^{T^1} = 1\) if \(T^1\) covers \(i \in V\) and \(z_i^{T^1} = 0\) otherwise. Then

$$(\tilde{x}, \tilde{z}) := ((1 - \alpha)^{-1}(x - \alpha x^{T^1}), (1 - \alpha)^{-1}(z - \alpha z^{T^1}))$$

is again in \(P_{local}(y)\) and can be written, by induction, as a convex combination of tree solutions. Our claim now follows.

A similar argument shows that the polyhedron \(P_{local}(y)\) is integral, even in the case when the 0-1 vector \(y\) describes a cycle free subgraph in the contracted graph. If the 0-1 vector \(y\) contains a cycle of the contracted graph, then \(P_{local}(y)\) is in general not integral. In order to show that this affirmation holds, we consider the following example, depicted in Figure 2.3.

If the lines drawn in the figure (i.e., \(\{1, 3\}, \{2, 4\}\) etc.) have cost 1 and all the other lines (i.e., \(\{1, 4\}, \{2, 3\}\) etc.) have cost \(M \gg 1\), then \(z \equiv \frac{1}{2}\) and \(x \equiv \frac{1}{2}\) on the drawn lines is an optimal solution of \(P_{local}(y)\), showing that the polyhedron \(P_{local}(y)\) is not integral.
