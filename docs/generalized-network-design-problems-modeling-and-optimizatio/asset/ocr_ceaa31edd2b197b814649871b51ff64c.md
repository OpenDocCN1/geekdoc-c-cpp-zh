The solution reported by Ghiani and Improta [48] was obtained by transforming the GVRP into a Capacitated Arc Routing Problem (CARP), which was then solved using the heuristic proposed by Hertz et al. [74], to yield the objective value 532.73.

The same instance was solved to optimality by Kara and Bektas [92], using their proposed integer programming formulation, by CPLEX 6.0 on a Pentium 1100MHz PC with 1 GB RAM in 17 600.85 CPU seconds.

Using our proposed formulations for the GVRP, we solved the same instance to optimality using CPLEX 12.2, getting the same value as reported by Kara and Bektas [92]. The required computational times were 1210.01 CPU seconds in the case of the node based formulation, and 1002.87 CPU seconds in the case of the flow based formulation. The computations were performed on an Intel Core 2 Duo 2.00 GHz with 2 GB RAM.
