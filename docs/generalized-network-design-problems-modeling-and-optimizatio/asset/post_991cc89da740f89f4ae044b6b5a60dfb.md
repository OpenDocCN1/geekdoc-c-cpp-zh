
### Generalized cutset formulation (Myung et al. [128])

We may replace the subtour elimination constraints (2.2) by connectivity constraints, which results in the so-called *generalized cutset formulation* introduced in [128]:

```
min \(\sum_{e \in E} c_e x_e\)
s.t. (2.1), (2.3), (2.4), (2.5) and
\(x(\delta(S)) \ge z_i + z_j - 1, \forall i \in S \subset V, j \notin S\) (2.6)
```

where for all \(S \subset V\) the cutset \(\delta(S)\) is usually defined as:

```
\(\delta(S) = \{e = \{i, j\} \in E \mid i \in S, j \notin S\}.\)
```

We denote the feasible set of the linear programming relaxation of this formulation by \(P_{cut}\). Myung et al. [128] proved that the following relation holds: \(P_{sub} \subset P_{cut}\).

### Generalized multicut formulation (Pop [142])

Our next model, the so-called *generalized multicut formulation*, is obtained by replacing simple cutsets by multicuts. Given a partition of the nodes \(V = C_0 \cup C_1 \cup \dots \cup C_k\), we define the multicut \(\delta(C_0, C_1, \dots, C_k)\) as the set of edges connecting different \(C_i\) and \(C_j\). The generalized multicut formulation for the GMSTP is:

```
\(\sum_{e \in E} c_e x_e\)
s.t. (2.1), (2.3), (2.4), (2.5) and
\(x(\delta(C_0, C_1, \dots, C_k)) \ge \sum_{j=0}^k z_{ij} - 1,\)
\(\forall C_0, C_1, \dots, C_k \text{ node partitions of } V \text{ and } \forall i \in C_j \text{ for } j = 0, 1, \dots, k.\) (2.7)
```

Let \(P_{mcut}\) denote the feasible set of the linear programming relaxation of this model. Clearly, \(P_{mcut} \subseteq P_{cut}\), in addition, it can be proved that the following result holds:

### Proposition 2.3 (Pop [142]). \(P_{sub} = P_{mcut}\).

Proof. Let \((x, z) \in P_{sub}\) and \(C_0, C_1, \dots, C_k\) a node partition of \(V\).

Since

```
\(E = E(C_0) \cup E(C_1) \cup \dots \cup E(C_k) \cup \delta(C_0, C_1, \dots, C_k),\)
```

we get

```
\(x(\delta(C_0, C_1, \dots, C_k) = x(E) - x(E(C_0)) - x(E(C_1)) - \dots - x(E(C_k)).\)
```

For all \(j = 0, 1, \dots, k\) and \(i \in C_j\) we have:

\(x(E(C_j)) \le z(C_j) - z_{ij}\).

Therefore we obtain:

\(x(\delta(C_0, C_1, \dots, C_k) \ge z(V) - 1 - \sum_{j=0}^k [z(C_j) - z_{ij}] = \sum_{j=0}^k z_{ij} - 1\).

Conversely, let \((x, z) \in P_{mcut}\), \(i \in S \subset V\) and consider the inequality (2.7) with \(C_0 = S\) and with \(C_1, \dots, C_k\) as singletons with union \(V \setminus S\). Then

\(x(\delta(S, C_1, \dots, C_k)) \ge \sum_{j=0}^k z_{ij} - 1 = z_i + z(V \setminus S) - 1\),

where \(i \in S \subset V\). Therefore

\(x(E(S)) = x(E) - x(\delta(S, C_1, \dots, C_k)) \le z(V) - 1 - z_i - z(V \setminus S) + 1 = z(S) - z_i\).

### Cluster subpacking formulation (Feremans [37])

We may strengthen the generalized subtour formulation of the GMSTP by replacing the subtour elimination constraints (2.2) with the cluster subpacking constraints

\(x(E(S)) \le z(S \setminus V_k), \quad \forall S \subset V, 2 \le |S| \le n - 1, k \in K\)

We observe that these constraints are dominated by:

\(x(E(S')) \le z(S' \setminus V_k) = z(S') - 1\)

where \(S' = S \cup V_k\). Therefore, we arrive at the cluster subpacking formulation of the GMSTP, introduced by Feremans [37]:

```
min \(\sum_{e \in E} c_e x_e\)
s.t. (2.1), (2.3), (2.4), (2.5) and
\(x(E(S)) \le z(S) - 1, \forall S \subset V, 2 \le |S| \le n - 1, |\{k : V_k \subseteq S\}| \neq 0 \quad (2.8)\)
```

The cluster subpacking constraints (2.8) guarantee that the number of edges selected from any subset of nodes S with \(2 \le |S| \le n - 1\), cannot be greater than the number of nodes selected from that set minus 1. We will denote by \(P_{spack}\), the feasible set of the linear programming relaxation of the cluster subpacking formulation.

## 2.3.2 Formulations based on arborescence properties

Consider the directed graph \(D = (V, A)\), obtained by replacing each edge \(e = (i, j) \in E\) with the opposite arcs \((i, j)\) and \((j, i)\) in \(A\), having the same weight as the edge \((i, j) \in E\). The directed version of the GMSTP introduced by Myung et al. [128], called the generalized minimum spanning arborescence problem is defined on the directed graph \(D = (V, A)\), rooted at a given cluster, here chosen to be \(V_1\) without loss of generality, and consists of determining a minimum cost arborescence which includes exactly one node from every cluster.

The next two formulations that we will present in this section, were introduced by Feremans et al. [37].

### Directed generalized outset formulation (Feremans [37])

We first consider a directed generalized outset formulation of the GMSTP. In this model we consider the directed graph \(D = (V, A)\) with the cluster \(V_1\) chosen as a root without loss of generality, and we denote with \(K_1 = K \setminus \{1\}\).

```
min \sum_{e \in E} c_e x_e
s.t. \quad z(V_k) = 1, \quad \forall k \in K = \{1, \dots, m\}
x(E) = m - 1
w(\delta^-(S)) \ge z_i, \quad \forall i \in S \subseteq V \setminus V_1 \quad (2.9)
w_{ij} \le z_i \quad \forall i \in V_1, j \notin V_1 \quad (2.10)
w_{ij} + w_{ji} = x_e \quad \forall e = (i, j) \in E \quad (2.11)
x, z, w \in \{0, 1\}. \quad (2.12)
```

In this model, the constraints (2.9) and (2.10) guarantee existence of a path from the selected root node to any other selected node, which includes only the selected nodes. Let \(P_{rcut}\) denote the projection of the feasible set of the linear programming relaxation of this model into the \((x, z)\)-space.

Another possible directed generalized outset formulation, considered by Myung et al. in [128], was obtained by replacing (2.3) with the following constraints:

```
w(\delta^-(V_1)) = 0 \quad (2.13)
w(\delta^-(V_k)) \le 1, \quad \forall k \in K_1. \quad (2.14)
```

### Directed subpacking formulation (Feremans [37])

We now introduce a formulation of the GMSTP based on branchings. Consider, as in the previous formulation, the digraph \(D = (V, A)\), with \(V_1\) chosen as the cluster root.

The directed subpacking formulation of the GMSTP is defined as follows:

```
min \sum_{e \in E} c_e x_e
s.t. z(V_k) = 1, \forall k \in K = \{1, \dots, m\}
x(E) = m - 1
w(A(S)) \le z(S - i), \forall i \in S \subset V, 2 \le |S| \le n - 1 (2.15)
w(\delta^-(j)) = z_j, \forall j \in V \setminus V_1 (2.16)
w_{ij} + w_{ji} = x_e, \forall e = (i, j) \in E
x, z, w \in \{0, 1\}.
```

Let \(P_{dbsub}\) denote the projection of the feasible set of the linear programming relaxation of this model into the \((x, z)\)-space. Obviously, \(P_{dbsub} \subseteq P_{sub}\). The following result was established by Feremans [37]: \(P_{dbsub} = P_{dcut} \cap P_{sub}\). Here, we now present a different proof of this result, see Pop [142].

### Proposition 2.4. \(P_{branch} = P_{dcut} \cap P_{sub}\).

**Proof.** First, we prove that \(P_{dcut} \cap P_{sub} \subseteq P_{branch}\). Let \((x, z) \in P_{dcut} \cap P_{sub}\). Using the relations (2.13) and (2.14), it is easy to see that the constraint (2.16) is satisfied. Therefore, \((x, z) \in P_{branch}\).

We show that \(P_{branch} \subseteq P_{dcut} \cap P_{sub}\). It is obvious that \(P_{branch} \subseteq P_{sub}\). Therefore, it remains to show \(P_{branch} \subseteq P_{dcut}\).

Let \((x, z) \in P_{branch}\). For all \(i \in V_1\) and \(j \notin V_1\) take \(S = \{i, j\} \subset V\). Then by (2.14) we have \(w_{ij} + w_{ji} \ge z_i\), which implies (2.9).

We now show that \(w(\delta^-(l)) \le z_l\), for \(l \in V_k, k \in K_1\). Take \(V^l = \{i \in V \mid (i, l) \in \delta^-(l)\}\) and \(S^l = V^l \cup \{l\}\), then \(w(\delta^-(l)) = w(A(S^l))\) and choose \(i_l \in V^l\).

```
1 = \sum_{l \in V_k} w(\delta^-(l)) = \sum_{l \in V_k} w(A(S^l)) \le \sum_{l \in V_k} z(S^l \setminus \{i_l\})
= \sum_{l \in V_k} z_l + \sum_{l \in V_k} \sum_{j \in V \setminus \{i_l\}} z_j = 1 + \sum_{l \in V_k} \sum_{j \in V \setminus \{i_l\}} z_j.
```

Therefore, for all \(l\), there is only one \(i_l \in V^l\) with \(z_{i_l} \neq 0\) and

```
w(\delta^-(l)) = w(A(S^l)) \le z(S^l \setminus \{i_l\}) = z_l.
```

For every \(i \in S \subset V \setminus V_1\)

```
w(A(S)) = \sum_{i \in S} w(\delta^-(i)) - w(\delta^-(S)) \le z(S \setminus \{i\}).
```
