node from each cluster \(V_i, i \in \{1, \dots, m\}\) and which contains no bridges. The bridges of a connected graph are the graph edges whose removal disconnects the graph. More generally, a bridge (also known as a cut-edge or cut arc or an isthmus) is an edge whose deletion increases the number of connected components, see [72] for further details. We will call such a subgraph a generalized edge-biconnected subgraph.

The GMEBNP is an \(\mathcal{NP}\)-hard problem, since in the particular case where \(|V_i| = 1, \forall i = 1, \dots, m\), the problem of finding a minimum-cost biconnected network, spanning all the nodes of a graph is an \(\mathcal{NP}\)-hard problem. See Garey and Johnson [45].

The generalized minimum edge-biconnected network problem is closely related to some other generalized network design problems such as the generalized traveling salesman problem (GTSP). Because every solution of the GTSP is obviously edge-biconnected and therefore is also a solution of the GMEBCNP, its solution value can be seen as an upper bound of the GMEBCNP.
