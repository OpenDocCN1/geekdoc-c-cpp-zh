APP \(\le \alpha\)OPT.

Directly relating APP to OPT can be difficult. Therefore, we try instead to find a lower bound for the optimal solution, denoted by LB, satisfying the following conditions:

+   1. LB \(\le\) OPT,
+   2. APP \(\le \alpha\)LB.

Consider now the following optimization problem:

OPT = \(\min_{x \in S} f(x)\).

A lower bound on OPT can be obtained by so-called *relaxation*. Consider the following related optimization problem:

LB = \(\min_{x \in R} g(x)\).

**Definition 2.9** (Lower bound), LB is called a lower bound on OPT and the optimization problem is called a relaxation of the original problem, if the following two conditions hold:

\(S \subseteq R\)

\(g(x) \le f(x)\) for all \(x \in S\).

The above conditions imply the following:

LB = \(\min_{x \in R} g(x) \le \min_{x \in S} f(x) = \text{OPT}\).

which shows that LB is a lower bound on OPT.

Many combinatorial optimization problems can be formulated as integer or mixed integer programs and the linear programming relaxations of these programs provide a lower bound for the optimal solution. Later, we will show how to use a linear programming relaxation of an integer programming formulation of the GMSTP to get an \(\alpha\)-approximation algorithm for the GMSTP with bounded cluster size.
