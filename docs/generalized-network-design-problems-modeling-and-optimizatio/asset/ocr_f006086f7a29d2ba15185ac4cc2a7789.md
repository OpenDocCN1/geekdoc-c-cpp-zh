# 3.1 Definition and complexity of the GTSP

The generalized traveling salesman problem (GTSP) seeks to find a minimum-cost tour H, spanning a subset of nodes, such that H contains exactly one node from each cluster V_i, i \in {1, ..., m}.

We will call such a cycle a generalized Hamiltonian tour. An example of a generalized Hamiltonian tour, for a graph with nodes partitioned into 6 clusters, is presented in Figure 3.1.

Figure 3.1. Example of a generalized Hamiltonian tour.

The GTSP involves two related decisions:

+   - choosing a node subset S \subseteq V, such that |S \cap V_k| = 1, for all k = 1, ..., m.
+   - finding a minimum cost Hamiltonian cycle in the subgraph of G, induced by S.

Both the GTSP and the at least version of the GTSP are NP-hard, since they reduce to the traveling salesman problem, when each cluster consists of exactly one node.
