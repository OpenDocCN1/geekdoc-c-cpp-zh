# **Generalized cutset formulation** (Myung et al. [128])

We may replace the subtour elimination constraints (2.2) by connectivity constraints, which results in the so-called *generalized cutset formulation* introduced in [128]:

```
min \(\sum_{e \in E} c_e x_e\)
s.t. (2.1), (2.3), (2.4), (2.5) and
\(x(\delta(S)) \ge z_i + z_j - 1, \forall i \in S \subset V, j \notin S\) (2.6)
```

where for all \(S \subset V\) the cutset \(\delta(S)\) is usually defined as:

```
\(\delta(S) = \{e = \{i, j\} \in E \mid i \in S, j \notin S\}.\)
```

We denote the feasible set of the linear programming relaxation of this formulation by \(P_{cut}\). Myung et al. [128] proved that the following relation holds: \(P_{sub} \subset P_{cut}\).

# **Generalized multicut formulation** (Pop [142])

Our next model, the so-called *generalized multicut formulation*, is obtained by replacing simple cutsets by multicuts. Given a partition of the nodes \(V = C_0 \cup C_1 \cup \dots \cup C_k\), we define the multicut \(\delta(C_0, C_1, \dots, C_k)\) as the set of edges connecting different \(C_i\) and \(C_j\). The generalized multicut formulation for the GMSTP is:

```
\(\sum_{e \in E} c_e x_e\)
s.t. (2.1), (2.3), (2.4), (2.5) and
\(x(\delta(C_0, C_1, \dots, C_k)) \ge \sum_{j=0}^k z_{ij} - 1,\)
\(\forall C_0, C_1, \dots, C_k \text{ node partitions of } V \text{ and } \forall i \in C_j \text{ for } j = 0, 1, \dots, k.\) (2.7)
```

Let \(P_{mcut}\) denote the feasible set of the linear programming relaxation of this model. Clearly, \(P_{mcut} \subseteq P_{cut}\), in addition, it can be proved that the following result holds:

# **Proposition 2.3** (Pop [142]). \(P_{sub} = P_{mcut}\).

Proof. Let \((x, z) \in P_{sub}\) and \(C_0, C_1, \dots, C_k\) a node partition of \(V\).

Since

```
\(E = E(C_0) \cup E(C_1) \cup \dots \cup E(C_k) \cup \delta(C_0, C_1, \dots, C_k),\)
```

we get

```
\(x(\delta(C_0, C_1, \dots, C_k) = x(E) - x(E(C_0)) - x(E(C_1)) - \dots - x(E(C_k)).\)
```
