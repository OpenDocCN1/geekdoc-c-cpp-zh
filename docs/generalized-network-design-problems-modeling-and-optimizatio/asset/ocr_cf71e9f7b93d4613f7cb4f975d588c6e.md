In the following, we describe the new algorithm called the Railway Ant Colony (RAC) algorithm for the Railway Traveling Salesman Problem.

In the RAC algorithm m, ants individually construct candidate solutions in an imperceptible fashion. The choice of the nest node is based on two main components, pheromone trails and a heuristic value called visibility.

The algorithm works similar to the case of the reinforcing ant colony system, described in Section 3.5.1 for solving the GTSP. We considered the same probability function that favors the selection of an edge with a high pheromone value, \(\tau\), and high visibility value, \(\eta\) and the same correction rules to update the trail intensity locally respectively globally.

At the outset, the ants are in their nests and will start to search for food within a specific area. An ant goes through a given number of clusters, \(B\) exactly once, and then returns to the nest. An ant stays in each cluster for a period of time, in order to find desirable food and after that, starting from another node, continues the tour. The choice of the next node is probabilistic. The more pheromone there is on a certain road (edge) the bigger the chance that this specific road will be taken. Therefore, the pheromone trails will guide the ants to the shorter path, which is a solution of the RTSP.

When each ant has completed a tour, the amounts of pheromone are updated. On every road (edge) some fraction of pheromone evaporates whilst en route. New pheromones are deposited in those that have been visited by at least one ant. All roads on the best tour so far get an extra amount of pheromone. This is called an elitist ant approach - the best ants reinforce their associated tour even more.

The process continues until a certain condition, such as a certain number of iterations, amount of CPU time or solution quality, has been achieved.

The Railways Ant Colony (RAC) algorithm can be stated as follow:

# Algorithm 4.1 (Railways Reinforcing System algorithm for the RTSP).

```
For every edge (i, j) do \(\tau_{ij}(0) = \tau_0\)
for k = 1 to m do
    place ant k on a specified chosen node from a specified cluster
end for
let T* be the shortest tour found and L+ its length
for iter = 1 to N_iter
    for k = 1 to m do
        build tour T^k(t) by applying |B| - 1 times
        choose the next arrival node j from an unvisited cluster,
        j = \begin{cases} \arg\max_{u \in J^k_i} [\tau_{iu}(t)]^\alpha [\eta_{iu}(t)]^\beta & \text{if } q \le q_0 \\ J & \text{if } q > q_0 \end{cases}
```
