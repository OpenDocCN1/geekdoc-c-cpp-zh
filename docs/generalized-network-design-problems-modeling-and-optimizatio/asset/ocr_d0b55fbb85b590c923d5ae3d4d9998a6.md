Nowadays, branch-and-price is a well-established method to solve huge and extremely difficult combinatorial optimization problems. Its success relies on exploiting structures contained in the problem with use of a decomposition and being able to solve the occurring pricing problems rather efficiently with problem specific algorithms. Several general acceleration strategies for the branch-and-price process were proposed [22, 116].

Branch-cut-and-price is a combination of branch-and-price and branch-and-cut. The variables are given implicitly and added to the problem only when needed. Additionally, cutting planes are added to the problem during the solving process, in order to strengthen the LP relaxation. Variables and cutting planes are created alternately.

The branch-and-cut-and-price algorithm proposed by Thomadsen and Stidsen [200] is specified next.

```
**Algorithm 6.2** (The branch-cut-and-price algorithm for solving the GFCNDP (Thomadsen and Stidsen [200])).
1 VARS = initial set of variables
2 CONS = initial set of constraints
3 BRANCHES = set consisting of an initial branch
4 INCUMBENT = +∞
5 do
6   Select and remove BRANCH ∈ BRANCHES
7   do
8     LP-lowerbound = SOLVE LP (CONS, VARS, BRANCH)
9     Add variables with negative reduced cost to VARS
10    Add violated constraints to CONS
11  while variables or constraints added
12  if LP solution is integer and LP-lowerbound < INCUMBENT:
13    Update incumbent: INCUMBENT = LP-lowerbound
14    Fathom
15  else if LP-lowerbound ≥ INCUMBENT:
16    Fathom
17  else
18    Select branching variable v
19    Add the two branchings v = 1 and v = 0 to BRANCHES
20 while BRANCHES ≠ ∅
```
