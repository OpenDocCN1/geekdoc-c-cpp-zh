This can be done in polynomial time, by solving the following $r$ shortest path problems.

For each global route $(V_0, V_{k_1}, ..., V_{k_p})$, the best generalized route that visits the clusters according to the given sequence can be determined in polynomial time by constructing a layered network (LN) with $p + 2$ layers, corresponding to the clusters $V_0, V_{k_1}, ..., V_{k_p}$. In addition, we duplicate the cluster $V_0$. The layered network contains all nodes of clusters $V_0, V_{k_1}, ..., V_{k_p}$ plus an extra node $o' \in V_0$ and the arcs are defined as an arc $(0, i)$ for each $i \in V_{k_1}$ with cost $c_{0i}$, an arc $(i, j)$ for each $i \in V_{k_l}$ and $j \in V_{k_{l+1}}$ ($l = 1, ..., p - 1$) having a cost $c_{ij}$ and an arc $(i, o')$ for each $i \in V_{k_p}$ with cost $c_{io'}$.

We consider paths from 0 to $0'$, visiting exactly one node from each cluster $V_{k_1}, ..., V_{k_p}$, hence giving a feasible generalized route.

Conversely, every generalized route that visits the clusters according to the sequence $(V_0, V_{k_1}, ..., V_{k_p})$, corresponds to a path in the layered network from $0 \in V_0$ to $o' \in V_0$.

Therefore, it follows that the best (w.r.t. cost minimization) collection of routes $R^*$ can be found by determining the $r$ shortest paths from $0 \in V_0$ to the corresponding $o' \in V_0$ with the property that it visits exactly one node from each of the clusters $(V_{k_1}, ..., V_{k_p})$.

The proposed computational model to approach the problem is a genetic algorithm, applied with respect to the global graph, which substantially reduces the size of the solution space.
