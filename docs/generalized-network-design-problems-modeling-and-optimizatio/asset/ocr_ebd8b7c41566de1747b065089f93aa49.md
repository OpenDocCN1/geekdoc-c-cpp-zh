In analyzing the results, we observe large differences in running times between the instances, especially in the case of the nd_ic instance. Among instances with the same size of B, trips can contain a quite different number of nodes. This is due to the random selection of stations in B. Looking at the data from the railway timetables, some contain only a few arrival and departure-nodes, whereas others have a full lineup. This imbalance appears to a greater extent for timetable nd_ic, in which some stations contain as few as 2 nodes and others are as large as 254 nodes. This might be the reason why these instances seems to be harder to solve for Concorde B&C.
