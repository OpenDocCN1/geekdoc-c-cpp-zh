The cost of each edge is defined as follows:

```
c_{ij} = \begin{cases} 0 & \text{for all } i, j \in E'_1 \\ 1 & \text{for all } i, j \in E'_2 \\ (|E| + 1)\alpha & \text{for all } i, j \in E'_3 \end{cases}
```

We claim that G contains C if and only if

```
APP(I) \le \alpha|E|,
```

where the instance I corresponds to G' and its cost function.

Note that there always exists a generalized spanning tree in G': all clusters different from the identical clusters $V'_2, \dots, V'_{k+1}$, have only one node and if we select k nodes from $V'_2, \dots, V'_{k+1}$, where we take one node from each cluster such that each node of C is included, then these k nodes, together with the remaining nodes selected, always uniquely form a generalized spanning tree of G' with edges in $E'_1 \cup E'_2$, by the definition of G'.

Suppose now that G' contains a generalized spanning tree and let C be a set of distinct nodes selected from the clusters, $V'_2, \dots, V'_{k+1}$ in the tree, then C is a node cover of G.

Therefore, we have shown that a generalized spanning tree, only using edges in $E'_1 \cup E'_2$, exists in G' if and only if G contains a node cover C.

If G contains C, then OPT(I) = |E|. Moreover, if G does not contain C, then any generalized spanning tree of G' should use at least one edge in $E'_3$ and thus

```
OPT(I) \ge |E| - 1 + \alpha(|E| + 1) > \alpha|E|.
```

In particular, if G contains a node cover C, then the approximation algorithm APP will produce a solution with value

```
APP(I) \le \alpha|E| = \alpha OPT(I),
```

i.e. the solution does not use any edge from $E'_3$ and APP identifies a node cover.

In the next section however, after making some further assumptions, we will present a positive result for the GMSTP.
