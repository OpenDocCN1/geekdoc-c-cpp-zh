## 5.3 Integer linear programming formulations of the GVRP

In this section, we first propose a general semi-closed formulation for the GVRP and then we specify its explicit forms and present four formulations of the problem (see as well [9, 94, 163]).

### 5.3.1 A general formulation

We define the related sets, associated with the GVRP, decision variables and parameters as follows

**Sets:**
- $V = \{0, 1, 2, ..., n\}$ the set of nodes corresponding to customers, where 0 represents the origin (depot).
- $V_0, V_1, ..., V_m$ a partition of $V$ into mutually exclusive and exhaustive non-empty sub-sets, each of which represents a cluster of customers with $V_0 = \{0\}$ the origin (home city, depot).
- $C = \{0, 1, 2, ..., m\}$ the set of clusters.
- $A = \{(i, j) | i, j \in V, i \neq j\}$ the set of arcs.

### Decision Variables:

We define the following binary variables:

$$
x_{ij} = \begin{cases} 1 & \text{if the arc } (i, j) \in A \text{ is included in the tour of a vehicle} \\ & i \in V_p, j \in V_r, p, r \in C \\ 0 & \text{otherwise} \end{cases}
$$

$$
w_{pr} = \begin{cases} 1 & \text{if there is a path from cluster } V_p \text{ to cluster } V_r, p, r \in C \\ 0 & \text{otherwise} \end{cases}
$$

### Parameters:

$c_{ij}$ is the cost of traveling from node $i$ to node $j, i \neq j, i \in V_p, j \in V_r, p \neq r, p, r \in C$;
$d_i$ is the demand of customer $i, i = 1, 2, ..., n$;
$q_r$ is the demand of the cluster $V_r. q_r = \sum_{i \in V_r} d_i, r \in C$;
$K = \{1, ..., s\}$ is the set of the uniform vehicles (tours);
$Q$ is the capacity of each vehicle.

Throughout this paper, we assume that $m \ge s$.

Constraints to the problem are given below, under the corresponding header:

### Cluster Degree Constraints

For each cluster, excluding $V_0$, there can be only a single outgoing arc to any other node belonging to other clusters. This condition is implied by the following constraints:

$$
\sum_{i \in V_p} \sum_{j \in V \backslash V_p} x_{ij} = 1, \quad p \neq 0, \quad p \in C \quad (5.1)
$$

There can be only a single incoming arc to a cluster from any other node belonging to other clusters, excluding $V_0$. This condition is implied by the following constraints:

$$
\sum_{i \in V \backslash V_p} \sum_{j \in V_p} x_{ij} = 1, \quad p \neq 0, \quad p \in C \quad (5.2)
$$

There should be \( s \) outgoing arcs from and at most \( s \) incoming arcs to the home city (origin), which is implied by the following constraints:

\(\sum_{i=1}^n x_{0i} = s \quad (5.3)\)

\(\sum_{i=1}^n x_{i0} = s \quad (5.4)\)

### Cluster Connectivity Constraints

The incoming and outgoing nodes should be the same for each cluster, which is satisfied by:

\(\sum_{i \in V_p} x_{ij} = \sum_{i \in V_p} x_{ji}, \quad j \in V_p, \quad p \in C \quad (5.5)\)

Flows from cluster \( V_p \) to the cluster \( V_r \) are defined by \( w_{pr} \). Thus, \( w_{pr} \) must be equal to the sum of \( x_{ij} \) 's from \( V_p \) to \( V_r \). Hence, we write:

\( w_{pr} = \sum_{i \in V_p} \sum_{j \in V_r} x_{ij} \quad (5.6)\)

With the above definitions and constraints, a general integer programming formulation for the GVRP may be given as:

minimize \(\sum_{i=1}^n \sum_{j=1}^n x_{ij}\)
subject to (5.1)–(5.6)
Capacity bounding constraints (5.7)
Subtour elimination constraints (5.8)
\( x_{ij} \in \{0, 1\}, \forall (i, j) \in A. \)

Note that \( w_{pr} \) will automatically be 0 or 1 due to the degree constraints given by (5.1), (5.2), (5.3) and (5.4). Therefore we do not need to impose integrality constraints on \( w_{pr} \).

The constraints given in (5.1)–(5.5) are similar to those given by Noon and Bean [133] for the GTSP. The constraints given in (5.6) have been introduced by Kara and Bektas [92].

Model formulations for the GVRP may differ from each other with respect to the "capacity bounding" and/or "subtour elimination" constraints given in (5.7) and (5.8) above.

In the case of an integer programming formulation, if the number of constraints of the formulation grows exponentially, with respect to the number of nodes of the graph, it is called the *exponential size formulation*. If the number of constraints grows polynomially, it is called the *polynomial size formulation*. In addition, if a formulation has additional auxiliary decision variables, it may be classified with respect to the new decision variables as, *node based formulation* if the additional variables are relative to the nodes of the graph, and *flow based formulation* if the new variables are relative to the arcs of the graph.

In the following subsections, we propose integer programming formulations for the GVRP, by defining new auxiliary variables.

## 5.3.2 A node based formulation

In addition to the decision variables defined before, let us define the following auxiliary variables:

Let \(u_p\) be the load of a vehicle just after leaving the cluster \(V_p\) (collection case) or the delivered amount of goods from a vehicle just after leaving the cluster \(V_p\) (delivery case), \(p \neq 0, p \in C\).

### Capacity Bounding Constraints

The following proposition gives capacity bounding constraints for a node based formulation.

**Proposition 5.3.** The following inequalities are valid capacity bounding constraints for the GVRP:

$$
u_p - \sum_{r \in C, r \neq p} q_r w_{pr} \ge q_p \quad p \neq 0, \quad p \in C \quad (5.9)
$$

$$
u_p + (Q - q_p)w_{0p} \le Q \quad p \neq 0, \quad p \in C \quad (5.10)
$$

$$
u_p + \sum_{r \in C, r \neq p} q_r w_{pr} \le Q \quad p \neq 0, \quad p \in C \quad (5.11)
$$

where \(q_0 = 0\).

**Proof.** Any cluster \(V_p\) may be on the first, last or an intermediate position in a vehicle tour, i.e., either \(w_{0p} = 1\) and/or \(w_{p0} = 1\), or there exist clusters \(V_s\) and \(V_t\), such that \(w_{sp} = w_{pt} = 1\). If \(w_{0p} = 1\) (or \(w_{p0} = 1\)), the inequalities (5.10), (5.11) and (5.12) imply that \(u_p = q_p\) and if \(w_{p0} = 1\), the bounding constraints imply \(q_p = u_p = Q\). If a vehicle comes from cluster \(V_s\), goes to cluster \(V_p\) and then travels from \(V_p\) to the cluster \(V_t\), which means that \(w_{rp} = 0\) and \(w_{pr} = 0\) for all \(r \neq s\) and \(r \neq t\), then from the bounding constraint we obtain \(q_p + q_s \le u_p \le Q - q_t\).

### Subtour elimination constraints

Formation of any subtour between clusters excluding \(V_0\) is not allowed by the following constraint:

\(u_p - u_r + Qw_{pr} + (Q - q_p - q_r)w_{rp} \le Q - q_r \quad p \neq r \neq 0, p, r \in C \quad (5.12)\)

where \(w_{pr} = 0\), whenever \(q_p + q_r > Q\) with \(p \neq r\) and \(p, r \in C\).

These constraints are adapted from the subtour elimination constraints of the capacitated VRP (see Desrochers and Laporte [23] and Kara et al. [93]).

Note that the constraints given in (5.10) guarantee that \(u_p \ge 0\) for all \(p \in C\). Therefore, we do not need nonnegativity constraints.

The first integer linear programming formulation of the GVRP is given by:

\(\text{(NB) minimize } \sum_{i=1}^n \sum_{j=1}^n x_{ij}\)
subject to (5.1)–(5.6) and (5.9)–(5.12),
\(x_{ij} \in \{0, 1\}, \forall(i, j) \in A.\)

where, \(x_{ij} = 0\) whenever \(i, j \in V_r, r \in C\) and \(w_{pr} = 0\) whenever \(q_p + q_r > Q\).

In the above formulation, the total number of binary variables is \(n(n + 1)\), i.e. \(O(n^2)\). The variables \(w_{pr}\) automatically take on binary values. The respective numbers of constraints implied by (5.1), (5.2), (5.3), (5.4), (5.5), (5.6), (5.9), (5.10), (5.11) and (5.12) are \(m, m, 1, 1, (n + 1), m(m + 1), n, m, m\) and \(m(m - 1)\), respectively, where \(n\) is the number of customers, \(m\) is the number of clusters and \(m \le n\). Hence the total number of constraints is \(2m^2 + n + 5m + 3\), i.e. \(O(m^2) = O(n^2)\).

(NB) the node based formulation of the GVRP is structurally similar to the Kara-Bektas [92] formulation, but it contains completely different bounding constraints. We will show below, that the node based formulation produces a stronger lower bound than the formulation described by Kara and Bektas [92].

We denote the feasible set of the linear programming relaxation of the node based formulation of the GVRP by \(P_{NB}\), where we replace the integrality constraints \(x_{ij} \in \{0, 1\}\) by \(0 \le x_{ij} \le 1\). If we denote the feasible set of the linear programming relaxation of the Kara-Bektas formulation by \(P_{K-B}\), then the following result holds:

**Proposition 5.4.** \(P_{NB} \subseteq P_{K-B}\).

**Proof.** The degree constraints, subtour elimination constraints and route continuity constraints of the two formulations are the same. They differ from each other with respect to their bounding constraints. As we discussed in the proof of the previous proposition, any cluster \(V_p\) may be on the first, or last or an intermediate position of a vehicle tour, i.e., either \(w_{0p} = 1\) or \(w_{p0} = 1\) or there exist some clusters \(V_s\) and \(V_t\) such that \(w_{sp} = w_{pt} = 1\).
