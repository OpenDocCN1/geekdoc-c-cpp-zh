# 7.3.4 Node Exchange Neighborhood

The node exchange neighborhood is a combination of the simple node optimization neighborhood and edge augmentation neighborhood, and addresses modifications of the spanned nodes as well as the edges connected them. # 7.3.5 Variable Neighborhood Descent

In their proposed VNS scheme, Hu et al. [82] used the variable neighborhood descent (VND) as local improvement. They provided three VND variants. The first one, denoted VND1, applies the previously described neighborhood structures. The second one, denoted VND2, applies the above mentioned neighborhoods and in addition two neighborhoods, based on the graph reduction technique [82]. Finally, the last variant called the self-adapted variable neighborhood descent (SAVND), applies the same neighborhood structures as VND2, but instead of a given static order, the neighborhoods are rearranged automatically during the search process.
