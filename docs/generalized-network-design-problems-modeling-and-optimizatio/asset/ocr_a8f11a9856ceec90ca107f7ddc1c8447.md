# ## 2.3.4 A model based on Steiner tree properties

Raghavan [175] and Duin et al. [31] have transformed the GMSTP into a Steiner tree problem, which can be solved by any of the specialized algorithms developed for this problem.

# ### Steiner tree formulation (Raghavan [175])

The *Steiner tree formulation*, introduced by Raghavan [175], is a multicommodity flow formulation of the GMSTP, after the GMSTP has been transformed into a Steiner tree problem with degree constraints. The transformation of the GMSTP to a Steiner tree problem is achieved in the following steps: let \(s_r\) be an artificial root node, and \(T = \{t_1, t_2, \dots, t_k\}\) be a set of artificial sink nodes, which we require to be in the Steiner tree.
