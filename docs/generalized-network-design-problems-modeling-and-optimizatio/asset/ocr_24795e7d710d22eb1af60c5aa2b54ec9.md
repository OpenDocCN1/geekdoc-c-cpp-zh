# A node based formulation for CGVRP

We define the new variable \(v_i\) to be the rank order of node \(i\) on the tour of a vehicle, \(i \in \{1 \dots n\}\). The CGVRP can then be modeled as an integer program in the following way

```
minimize \(\sum_{i=1}^n \sum_{j=1}^n c_{ij} x_{ij}\)
subject to (5.1)-(5.4), (5.6), (5.9)-(5.12), (5.40), (5.41)
\(v_i - v_j + |V_p| x_{ij} + (|V_p| - 2) x_{ji} \le |V_p| - 1, \quad \forall p \in C, i, j \in V_p\) (5.42)
\(v_i \ge 1, \quad \forall i \in V_p, p \in C\) (5.43)
\(x_{ij} \in \{0, 1\}, \quad \forall (i, j) \in A,\)
```

where, as in the other node based formulations, \(x_{ij} = 0\), whenever \(q_i + q_j > Q\) for all \(i \neq j\), and \(c_{ii} = 0\) for all \(i \in V\).

The constraints presented in (5.42) were introduced by Desrochers and Laporte [23] for the case of the traveling salesman problem, in order to eliminate the subtours. These constraints avoid the formation of any subtours in each of the clusters. The constraints (5.43) initialize the variables \(v_i\)’s for each cluster.

# A flow based formulation for CGVRP

We introduce a new flow variable \(t_{ij}\) as the number of arcs visited within a given cluster on the route of a vehicle after just leaving the \(i\)-th node, if the vehicle goes from node \(i\) to node \(j\), or zero otherwise.

```
minimize \(\sum_{i=1}^n \sum_{j=1}^n c_{ij} x_{ij}\)
subject to (5.1)-(5.4), (5.13)-(5.16), (5.40), (5.41)
\(\sum_{j=0}^n t_{ij} - \sum_{j=0}^n t_{ji} = 1, \quad \forall i \in V_p, p \in C\) (5.44)
\(t_{ij} \le (|V_k| - 1) x_{ij}, \quad \forall i, j \in V_k, k \in C\) (5.45)
\(x_{ij} \in \{0, 1\}, \quad \forall (i, j) \in A,\)
```

where \(m \ge s\).

In the above formulation, the constraints presented in (5.44) are the standard conservation of flow equations, increasing the \(t_{ij}\)’s of the consecutive arc of any path by one after each node. Hence, they are the subtour elimination constraints of the formulation. The constraints given in (5.45) are the bounding constraints of the flow variables. They guarantee that, if the arc \((i, j)\) is not on any route, i.e. \(x_{ij} = 0\), the corresponding flow variables \(t_{ij} = 0\).
