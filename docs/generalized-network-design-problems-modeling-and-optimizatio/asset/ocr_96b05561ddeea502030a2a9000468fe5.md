\(\sum_j \lambda_{kij} = 1, \quad \text{for } 1 \le k, i, j \le m \text{ and } i \neq k \quad (2.33)\)
\(\lambda_{kki} = 0, \quad \text{for } 1 \le k, j \le m \quad (2.34)\)
\(y_{ij}, \lambda_{kij} \ge 0, \quad \text{for } 1 \le k, i, j \le m.\)

where the variables \(\lambda_{kij}\) are defined for every triplet of nodes \(k, i, j\), with \(i \neq j \neq k\) and their value for a spanning tree is:

\(\lambda_{kij} = \left\{ \begin{array}{ll} 1 & \text{if } j \text{ is the parent of } i, \text{ when we root the tree at } k \\ 0 & \text{otherwise.} \end{array} \right.\)

The constraints (2.32) mean that an edge \((i, j)\) is in the spanning tree if and only if either \(i\) is the parent of \(j\) or \(j\) is the parent of \(i\). The constraints (2.33) mean that, if we root a spanning tree at \(k\), every node other than node \(k\) has a parent. Finally, the constraints (2.34) mean that the root \(k\) has no parent.

If the vector \(y\) describes a spanning tree on the contracted graph, the corresponding best (w.r.t. minimization of costs) \(local \ solution \ x \in \{0, 1\}^{|E|}\) can be obtained via one of the following two methods, described by Pop [142] using dynamic programming (see Section 2.2) or integer linear programming.

If the 0-1 vector \(y\) describes a spanning tree on the contracted graph, the corresponding local solution \(x \in \{0, 1\}^{|E|}\) minimizing the costs can be obtained by solving the following integer linear programming problem:

\(\begin{aligned} \min & \sum_{e \in E} c_e x_e \\ \text{s.t. } & z(V_r) = 1 & \forall k \in K = \{1, \dots, m\}, \\ & x(V_r, V_r) = y_{lr} & \forall l, r \in K = \{1, \dots, m\}, l \neq r, \\ & x(i, V_r) \le z_i & \forall r \in K, \forall i \in V \setminus V_r, \\ & x_e, z_i \in \{0, 1\} & \forall e = \{i, j\} \in E, \forall i \in V, \end\aligned}\)

where \(x(V_r, V_r) = \sum_{i \in V_r, j \in V_r} x_{ij}\) and \(x(i, V_r) = \sum_{j \in V_r} x_{ij}\).

For given \(y\), we denote the feasible set of the linear programming relaxation of this program by \(P_{local}(y)\). The following result holds (Pop et al. [150]):

**Proposition 2.7.** If \(y\) is the 0-1 incidence vector of a spanning tree of the contracted graph, then the polyhedron \(P_{local}(y)\) is integral.

**Proof.** Suppose that the 0-1 vector \(y\) describes a spanning tree \(T\) of the contracted graph. Then, in order to prove that the polyhedron \(P_{local}(y)\) is integral, it suffices to show that every solution of the linear programming relaxation can be written as a convex combination of solutions corresponding to spanning trees:

\((x, z) = \sum \lambda_T (x_T, z_T).\)
