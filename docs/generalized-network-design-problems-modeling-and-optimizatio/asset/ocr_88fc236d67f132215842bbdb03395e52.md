# Computational results

In order to test the proposed TSP transformation schemes, the authors used instances based on two railway timetables, containing real-world data of train schedules in the Netherlands. The instance \(nd\_loc\) contains 23 cities and represent trains in a local region and the instance \(nd\_ic\) contains 21 larger cities in the Netherlands, which are connected by Intercity trains.

The requirements for the traveling salesman were generated at random. They were created by letting the salesman visit either 5 or 10 cities, and staying times were chosen between 10 and 240 minutes at each location. Since [46, 92] also used randomly generated data for the salesman with the same number of cities to be visited, the results should be at least roughly comparable. However, the staying times were not mentioned.

The time-expanded digraph, based on both timetables, contains more than 2000 nodes and around 4000 edges (depending on the traveling person). After reducing the graph, the transformation procedure for generating a symmetric TSP instance was carried out, and it was solved with the branch-and-cut (B&C) algorithm from the Concorde library.

The experiments were performed on an Intel Core 2 Quad 2.4 GHz PC with 4 GB memory and B&C uses ILOG CPLEX 9.0 as solver.
