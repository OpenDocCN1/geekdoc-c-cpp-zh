# 6.4 Computational results

In order to solve the GFCND problem with the branch-cut-and-price algorithm, Thomadsen and Stidsen [200] generated test instances with 50–300 nodes, in steps of 25 nodes and with 10–30 clusters, in steps of 10 clusters.

Each test instance consists of a number of nodes located randomly in the unit square [0, 1] × [0, 1]. The clusters were created in the same way as in [43], using the procedure called CLUSTERING, and is described in the following. This procedure sets the number of clusters m = [k/4], identifies the m farthest nodes from each other, and assigns each remaining node to its nearest center. Obviously, some real-world problems may have different cluster structures. However, the solution proposed in this paper is able to handle any cluster structure.

The costs of the edges ce, e = (i, j) ∈ E were set equal to the Euclidean distance between the nodes i and j and for each pair of clusters Vk and Vl, k, l ∈ {1, ..., m} a demand d is defined. The value of the communication demand, bd, is set equal to a uniformly distributed random variable between 0 and 20 times the product of the number of nodes in each of the two clusters.

The tests were performed on a 1000 MHz SUN Fire V440, running Solaris 9, using CPLEX as a LP-solver. The obtained results are given in Table 6.1.
