tree formulation of the GMSTP is described as follows:

```
min \sum_{e \in E} c_e x_e
s.t. \sum_{(i,j) \in A: i \in \bar{V}_k, j \in V_k} w_{ij} = 1, \quad \forall k \in K_1 \quad (2.28)
w_{ij} + w_{ji} \le 1, \quad \forall (i,j) \in A \quad (2.29)
\sum_{a \in \delta^+(i)} f_a^h - \sum_{a \in \delta^-(i)} f_a^h = \begin{cases} -1, & \text{if } i = O(h) \\ 1, & \text{if } i = D(h) \\ 0, & \text{otherwise} \end{cases} \quad \forall i \in V \text{ and } h \in H \quad (2.30)
0 \le f_{ij}^h \le w_{ij}, \quad w \in \{0, 1\}. \quad \forall (i,j) \in A, h \in H \quad (2.31)
```

The Steiner tree formulation of the GMSTP then is the standard multicommodity flow model for the Steiner tree problem with additional degree constraints (2.28) that ensure an in-degree of 1 for each of the clusters (\(k \in K\)). This formulation ensures the design of a minimum-cost directed Steiner tree, containing the root node \(s_r\), all the nodes in \(T\), and exactly one node from each cluster.

We denote by \(P_\text{steiner}\) the set of feasible solutions in \((x, z)\)-space of this formulation. In [175], Raghavan has shown that the Steiner tree formulation is equivalent to the multicommodity flow formulation, where the node variables were used to indicate whether a node is selected to be in the generalized spanning tree.

# 2.3.5 Local-global formulation of the GMSTP

Our last formulation was introduced by Pop [142] and aims at distinguishing between *global*, i.e. inter-cluster connections, and *local* ones, i.e. connections between nodes from different clusters.

We introduce variables \(y_{ij}\) (\(i, j \in \{1, \dots, m\}\)) to describe the global connections. Hence, \(y_{ij} = 1\) if cluster \(V_i\) is connected to cluster \(V_j\) and \(y_{ij} = 0\) otherwise, and we assume that \(y\) represents a spanning tree.

The convex hull of all these y-vectors is generally known as the spanning tree polytope (on the contracted graph with vertex set \(\{V_1, \dots, V_m\}\), which we assume to be complete).

Following Yannakakis [205], this polytope, denoted by \(P_\text{MST}\), can be represented by the following polynomial number of constraints:

```
\sum_{\{i,j\}} y_{ij} = m - 1
y_{ij} = \lambda_{kij} + \lambda_{jii}, \quad \text{for } 1 \le k, i, j \le m \text{ and } i \neq j \quad (2.32)
```
