# Display List Operation

Following code demonstrates the display list operation in a circular linked list.

```
//display the list
void printList() {
struct node *ptr = head;
printf("\n" );

//start from the beginning
if(head != NULL) {
while(ptr->next != ptr) {
printf("(%d,%d) ",ptr->key,ptr->data); ptr = ptr->next;
}
}
printf(" ]"); }
```
