# SearchOperation

Whenever an element is to be searched, compute the hash code of the key passed and locate the element using that hash code as index in the array. Use linear probing to get the element ahead if the element is not found at the computed hash code. struct DataItem

```
*search(int key){
//get the hash
int hashIndex = hashCode(key);
//move in array until an empty while(hashArray[hashIndex] != NULL){
if(hashArray[hashIndex]->key == key) return hashArray[hashIndex];
//go to next cell
++hashIndex;
//wrap around the table hashIndex %= SIZE; }
return NULL; }
```
