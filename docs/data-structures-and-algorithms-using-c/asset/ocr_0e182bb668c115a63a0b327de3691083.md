# FibonacciRecursiveAlgorithm

Let us learn how to create a recursive algorithm Fibonacci series. The base criteria of recursion.

START
Procedure Fibonacci(n)
declare f0, f1, fib, loop
set f0 to 0 set f1 to 1
display f0, f1
for loop <- 1 to n
fib <- f0 + f1 f0 <- f1
f1 <- fib
display fib end for
END
