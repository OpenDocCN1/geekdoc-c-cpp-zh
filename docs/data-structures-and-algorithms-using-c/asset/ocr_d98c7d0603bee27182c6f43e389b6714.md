# # 38. Fibonacci Series Data Structures & Algorithms

Fibonacci series generates the subsequent number by adding two previous numbers. Fibonacci series starts from two numbers – F₀ & F₁. The initial values of F₀ & F₁ can be taken as 0, 1 or 1, 1 respectively.

Fibonacci series satisfies the following conditions – Fn = Fn-1 + Fn-2

Hence, a Fibonacci series can look like this – F₈ = 0 1 1 2 3 5 8 13

or, this –

F₈ = 1 1 2 3 5 8 13 21 For illustration purpose, Fibonacci of F₈ is displayed as –
