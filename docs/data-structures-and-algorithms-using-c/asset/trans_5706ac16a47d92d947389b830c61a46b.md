

## 树遍历在 C 语言中

遍历是访问树中所有节点的过程，也可以打印它们的值。由于所有节点均通过边（链接）相连，我们总是从根节点（头节点）开始。也就是说，我们无法随机访问树中的节点。有三种遍历树的方式 –

- 中序遍历
- 前序遍历
- 后序遍历

我们将使用以下二叉树，在此查看 C 语言中树遍历的实现 –

![](img/30fc9e3f8ee01facfae8d1c9621936b3_217_0.png)

### 在 C 中实现

```
#include <stdio.h>
#include <stdlib.h>
struct node {
    int data;
    struct node *leftChild;
    struct node *rightChild;
};
struct node *root = NULL;
void insert(int data) {
    struct node *tempNode = (struct node*) malloc(sizeof(struct node));
    struct node *current;
    struct node *parent;
    tempNode->data = data;
    tempNode->leftChild = NULL;
    tempNode->rightChild = NULL;
    //if tree is empty
    if(root == NULL) {
        root = tempNode;
    } else {
        current = root;
        parent = NULL;
        while(1) {
            parent = current;
            //go to left of the tree
            if(data < parent->data) {
                current = current->leftChild;
                //insert to the left
                if(current == NULL) {
                    parent->leftChild = tempNode;
                    return;
                }
            }
            //go to right of the tree
            else {
                current = current->rightChild;
                //insert to the right
                if(current == NULL) {
                    parent->rightChild = tempNode;
                    return;
                }
            }
        }
    }
}

struct node* search(int data) {
    struct node *current = root;
    printf("Visiting elements: ");
    while(current->data != data) {
        if(current != NULL)
            printf("%d ", current->data);
        //go to left tree
        if(current->data > data) {
            current = current->leftChild;
        }
        //else go to right tree
        else {
            current = current->rightChild;
        }
        //not found
        if(current == NULL) {
            return NULL;
        }
    }
    return current;
}

void pre_order_traversal(struct node* root) {
    if(root != NULL) {
        printf("%d ", root->data);
        pre_order_traversal(root->leftChild);
        pre_order_traversal(root->rightChild);
    }
}

void inorder_traversal(struct node* root) {
    if(root != NULL) {
        inorder_traversal(root->leftChild);
        printf("%d ", root->data);
        inorder_traversal(root->rightChild);
    }
}

void post_order_traversal(struct node* root) {
    if(root != NULL) {
        post_order_traversal(root->leftChild);
        post_order_traversal(root->rightChild);
        printf("%d", root->data);
    }
}

int main() {
    int i;
    int array[7] = { 27, 14, 35, 10, 19, 31, 42 };
    for(i = 0; i < 7; i++)
        insert(array[i]);
    i = 31;
    struct node * temp = search(i);
    if(temp != NULL) {
        printf("%d] Element found.", temp->data);
        printf("\n");
    } else {
        printf("[ x ] Element not found (%d).\n", i);
    }
    i = 15;
    temp = search(i);
    if(temp != NULL) {
        printf("%d] Element found.", temp->data);
        printf("\n");
    } else {
        printf("[ x ] Element not found (%d).\n", i);
    }
    printf("\nPreorder traversal :");
    pre_order_traversal(root);
    printf("\nInorder traversal : ");
    inorder_traversal(root);
    printf("\nPost order traversal : ");
    post_order_traversal(root);
    return 0;
}
```

如果编译并运行上述程序，将产生以下结果 –
访问元素: 27 -> 35 -> [31] 元素已找到。
访问元素: 27 -> 14 -> 19 -> [ x ] 未找到元素 (15)。
前序遍历: 27 14 10 19 35 31 42 中序遍历: 10 14 19 27 31 35 42 后序遍历: 10 19 14 31 42 35 27

## 31. 树遍历 数据结构与算法

遍历是访问树中所有节点的过程，也可以打印它们的值。由于所有节点均通过边（链接）相连，我们总是从根节点（头节点）开始。也就是说，我们无法随机访问树中的节点。有三种遍历树的方式 –

- 中序遍历
- 前序遍历
- 后序遍历

通常，我们遍历树是为了在树中搜索或定位给定的项目或键，或者打印它包含的所有值。

### 中序遍历

在这种遍历方法中，首先访问左子树，然后是根节点，最后是右子树。我们应始终记住，每个节点本身也可能代表一棵子树。

如果对二叉树进行 **中序** 遍历，输出将按升序生成排序后的键值。

![](img/30fc9e3f8ee01facfae8d1c9621936b3_221_0.png)

我们从 **A** 开始，按照中序遍历，移动到其左子树 **B**。 **B** 也按中序遍历。该过程持续进行，直到访问所有节点。这棵树中序遍历的输出将是 –

**D → B → E → A → F → C → G**

#### 算法

直到所有节点都被遍历 –

- 步骤 1 – 递归遍历左子树。
- 步骤 2 – 访问根节点。
- 步骤 3 – 递归遍历右子树。

### 前序遍历

在这种遍历方法中，首先访问根节点，然后是左子树，最后是右子树。

![](img/30fc9e3f8ee01facfae8d1c9621936b3_222_0.png)

我们从 A 开始，按照前序遍历，首先访问 A 本身，然后移动到其左子树 B。 B 也按前序遍历。该过程持续进行，直到访问所有节点。这棵树前序遍历的输出将是 –

A → B → D → E → C → F → G

直到所有节点都被遍历 –

- 步骤 1 – 访问根节点。
- 步骤 2 – 递归遍历左子树。
- 步骤 3 – 递归遍历右子树。

### 后序遍历

在这种遍历方法中，根节点最后被访问，因此得名。首先我们遍历左子树，然后遍历右子树，最后访问根节点。

![](img/30fc9e3f8ee01facfae8d1c9621936b3_223_0.png)

我们从 A 开始，按照后序遍历，首先访问左子树 B。 B 也按后序遍历。该过程持续进行，直到访问所有节点。这棵树后序遍历的输出将是 –

**D → E → B → F → G → C → A**

直到所有节点都被遍历 –

- 步骤 1 – 递归遍历左子树。
- 步骤 2 – 递归遍历右子树。
- 步骤 3 – 访问根节点。
