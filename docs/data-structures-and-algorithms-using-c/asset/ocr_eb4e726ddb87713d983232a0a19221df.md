# isfull()

As we are using single dimension array to implement queue, we just check for the rear pointer to reach at MAXSIZE to determine that the queue is full. In case we maintain the queue in a circular linkedlist, the algorithm will differ. Algorithm of isfull() function –

```
begin procedure isfull
if rear equals to MAXSIZE return true
else
return false
endif
end procedure
```

Implementation of isfull() function in C programming language –

```
bool isfull() {
if(rear == MAXSIZE - 1) return true;
else
return false;
}
```
