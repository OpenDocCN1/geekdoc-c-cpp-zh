+   - Execution of the code in Listing 11-1 reaches the top of the `switch` statement, so the computer starts checking this statement's `case` clauses. The value 2 doesn't match the topmost `case` clause (the `case 1` clause), so the computer moves on to the next `case` clause.

+   - The computer displays Goodbye because that's what the statement after the `switch` statement tells the computer to do.

The first of the two statements displays No, and don't ask again on the screen. The second statement is a `break` statement. (What a surprise!) When the computer encounters a `break` statement, the computer jumps out of whatever `switch` statement it's in. So in Listing 11-1, the computer skips right past `case 3`, `case 4`, and so on. The computer jumps to the statement just after the end of the `switch` statement.
