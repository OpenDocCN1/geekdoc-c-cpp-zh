# ## Model Overview

Kimi K2 is Moonshot AI's latest open-source model, released in July 2025. It is a Mixture-of-Experts (MoE) model with 1 trillion total parameters and 32 billion active parameters per token.

The model achieves state-of-the-art performance on agentic coding benchmarks while maintaining competitive results on general language understanding tasks.

# ## Architecture

+   - **Model Type**: Mixture-of-Experts (MoE) Transformer
+   - **Total Parameters**: 1T
+   - **Active Parameters**: 32B
+   - **Context Window**: 64K tokens
+   - **Architecture**: Standard Transformer with MoE layers and Grouped-Query Attention (GQA)

# ## Key Strengths

+   - **Agentic Coding**: Excels at tool use, multi-step task execution, and code generation
+   - **Tool Use**: Seamless integration with external tools and APIs
+   - **Prompt Caching**: Supports efficient prompt caching for reduced latency and cost
+   - **Long Context**: Handles up to 64K tokens of context with 128K max output

# ## Performance Highlights

In internal evaluations, Kimi K2 demonstrates strong performance across multiple benchmarks:

+   - **88.4%** on HumanEval (pass@1)
+   - **85.7%** on MBPP (pass@1)
+   - **72.3%** on MMLU-Pro
+   - **83.9%** on MATH-500
+   - **61.2%** on AIME 2024
