Consider another example: the bank account. The wrong way to do this would look like:

```
class account
{
public:
    void set_balance(int);²
    int get_balance() const;

private:
    int balance;
};
```

2. Please, never use floats for money. Rounding errors and representation errors will propagate and degrade your output.

A better way of doing this is to introduce business logic:

Click here to view code image

```
class account
{
public:
    void deposit(int);
    void withdraw(int);
    int balance() const;

private:
    int balance_;
};
```

Now, you change the balance by doing what the business logic dictates. The deposit function will increase the balance, and the withdraw function will decrease the balance.
