If both threads start simultaneously, thread 1 can lock the writing mutex while thread 2 can lock the logging mutex. Now both threads are waiting for the other thread to unlock their mutex before continuing.

> “That’s silly,” you say. “They should simply lock the mutex they need, do the thing they need it for, and unlock it before locking the next mutex.”
