# Summary

This is a fairly simple guideline which attends to old habits. Many of the Core Guide-lines lead you toward writing more readable code that can be apprehended quickly. This guideline boils down to three considerations.

+   - There are many kinds of declaration.
+   - Names can be introduced anywhere.
+   - Do not confuse declarations by introducing more than one name per line unless the language requires it.
