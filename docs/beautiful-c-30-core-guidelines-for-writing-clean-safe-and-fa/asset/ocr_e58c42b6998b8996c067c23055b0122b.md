# # LLaVA-UHD: An LMM Perceiving Any Aspect Ratio and High-Resolution Images

Yuechen Zhang, Rui Huang, Yaxian Wang, Jinzheng He, Rui Hou, Shweta Bhardwaj, Anh Dinh, Chun-Ming Feng, Li Xiao, Chunfeng Yuan, Changhu Wang, Yifan Zhang, Hailin Jin

USTC, Amazon, Baidu, University of Sydney

# ## Abstract

Large multimodal models (LMMs) have achieved remarkable progress in visual understanding, yet processing high-resolution images with arbitrary aspect ratios remains challenging. This paper presents LLaVA-UHD, an LMM that efficiently perceives high-resolution images of any aspect ratio. It includes a vision encoder that adaptively resizes and splits images into sub-images, a visual token compression module to reduce computational cost, and a spatial schema to model the arrangement of sub-images. Experiments on various benchmarks show that LLaVA-UHD achieves competitive performance with higher efficiency.

Index Terms — Large Multimodal Models, High-Resolution Images, Visual Token Compression
