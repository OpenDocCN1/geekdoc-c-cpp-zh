## Lazy Loading of Parts

By default, parts are loaded from the container, for example, by calling the extension method ComposeParts() on the CompositionContainer. With the help of the Lazy<T> class, the parts can be loaded on first access. The type Lazy<T> allows the late instantiation of any type T and defines the properties IsValueCreated and Value. IsValueCreated is a Boolean that returns the information if the contained type T is already instantiated. Value initializes the contained type T on first access and returns the instance.

The import of an add-in can be declared to be of type Lazy<T>, as shown in the Lazy<ICalculator> example.
