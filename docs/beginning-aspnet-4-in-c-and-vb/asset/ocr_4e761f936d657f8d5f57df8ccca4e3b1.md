> Dynamic activities and Windows Workflow Foundation 4 are explained in Chapter 44, "Windows Workflow Foundation 4."

A simple example to load XAML dynamically from a file to create an object tree and to attach the object tree to a container element, such as a StackPanel, is shown here.

```
FileStream stream = File.OpenRead("Demo1.xaml");
object tree = System.Windows.Markup.XamlReader.Load(stream);
container1.Children.Add(tree as UIElement);
```
