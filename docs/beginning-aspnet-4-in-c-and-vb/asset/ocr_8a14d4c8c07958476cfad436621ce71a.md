# Adding PerformanceCounter Components

With Windows Forms or Windows Service applications, you can add PerformanceCounter components from the toolbox or from the Server Explorer with drag and drop to the designer surface.

With WPF applications that's not possible. However, it's a lot of work to define the performance counters manually, as this is done with the method InitializePerformanceCounts(). Here, the CategoryName for all performance counts is set from the const string performanceCounterCategoryName; the CounterName is set from the sorted list. Because the application writes performance counts, the ReadOnly property must be set to false. When writing an application that just reads performance counts for display purposes, you can use the default value of the ReadOnly property, which is true. The InstanceName of the PerformanceCounter object is set to an application name. If the counters are configured to be global counts, the InstanceName may not be set.
