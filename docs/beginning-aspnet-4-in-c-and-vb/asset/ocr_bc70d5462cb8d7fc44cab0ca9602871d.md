When the built-in web server is running, an icon will appear in your system tray. By double-clicking this icon, you can see what the web server is doing, and stop it if required (see Figure 40-5).

In Figure 40-5, you can see the port that the web server is running on and the URL required to see the web site you have created.

The browser that has opened should display the Click Me button on a web page. Before you press the button, take a quick look at the code received by the browser by selecting Page → View Source (in IE7). The <form> section should look something like this:

The web server controls have generated straight HTML: <span> and <input> for <asp:Label> and <asp:Button>, respectively. There is also an <input type="hidden"> field with the name __VIEWSTATE. This encapsulates the state of the form, as mentioned earlier. This information is used when the form is posted back to the server to re-create the user interface, so that the server can keep track of changes and so on. Note that the <form> element has been configured for this; it will post data back to Default.aspx (specified in action) via an HTTP POST operation (specified in method). It has also been assigned the name form1.
