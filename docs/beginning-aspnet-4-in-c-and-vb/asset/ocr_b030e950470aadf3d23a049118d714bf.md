The code behind this application is illustrated here:

```
using System;
using System.Windows.Forms;

namespace Browser
{
    partial class Form1: Form
    {
        public Form1()
        {
            InitializeComponent();
        }

        private void textBox1_KeyPress(object sender, KeyPressEventArgs e)
        {
            if (e.KeyChar == (char)13)
            {
                webBrowser1.Navigate(textBox1.Text);
            }
        }
    }
}
```

From this example, you can see that each key press that the end user makes in the text box is captured by the textBox1_KeyPress event. If the character input is a carriage return (a press of the Enter key, which is (char)13), then you take action with the WebBrowser control. Using the WebBrowser control's Navigate method, you specify the URL (as a string) using the textBox1.Text property. The end result is shown in Figure 24-4.
