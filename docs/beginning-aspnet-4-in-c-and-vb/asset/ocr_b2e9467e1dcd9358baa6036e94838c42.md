# Themes in PCSDemoSite

The PCSDemoSite web site includes three themes that you can select on the `/Configuration/Themes/Default.aspx` page — as long as you are logged in as a member of either the `RegisteredUser` or `SiteAdministrator` role. This page is shown in Figure 41-6.
