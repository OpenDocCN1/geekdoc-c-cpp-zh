# Using UDTs with SQL Server

After building the assembly, it can be deployed with SQL Server. Configuration of the UDT in SQL Server can be done either with Visual Studio 2010 using the Build Deploy Project menu or using these SQL commands:

```
CREATE ASSEMBLY SqlTypes FROM
'c:\ProCSSharp\SqlServer\SqlTypes.dll'
CREATE TYPE Coordinate EXTERNAL NAME
[SqlTypes].[Wrox.ProCSSharp.SqlServer.SqlCoordinate]
```

With EXTERNAL NAME, the name of the assembly as well as the name of the class, including the namespace, must be set.
