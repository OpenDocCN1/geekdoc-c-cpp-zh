As you can see, these wizards make it quite simple to refactor your code not just on one page but also for an entire application. Also included are the capabilities to do the following:

You will find the refactoring capabilities provided by Visual Studio 2010 a great way to get the cleaner, more readable, better-structured code that you are looking for.
