# .NET Applications Using System.Data.Service.Client

Earlier in this chapter, you read how a .NET client application can be created that simply sends HTTP requests by using the HttpWebRequest class. The client part of Data Services, with the namespace System.Data.Services.Client, offers functionality for the client to build HTTP requests. The two most important classes with this namespace are DataServiceContext and DataServiceQuery<TEntity>. DataServiceContext represents the state that is managed on the client. This state keeps track of objects that are loaded from the server as well as all the changes made on the client. DataServiceQuery<TEntity> represents an HTTP query to a data service.
