
自2005年以来，与计算机相关的入门课程数量减少了17%。尽管学生注册人数可能略有上升，但自2005年以来开设的课程数量却在下降，而且基于技术的入门课程中计算参与的缺乏意味着，很少有学生会考虑选修“计算机科学原理”（即使其学校开设了该课程），或者在其K–12教育中接触到计算机科学。

一些国家，例如以色列，已经设计了一套计算机科学课程，作为学校规定的科学必修要求，但美国仍将计算机科学课程视为选修课——即根据个人兴趣选择的课程，类似于参加乐队或文学杂志。将计算机科学视为选修课而非数学或科学学分，最初似乎不会带来重大问题，但这种做法具有严重影响。当学区被问及为什么各自学校不开设计算机科学课程时，他们通常给出两种回应之一。第一种回应是学生不感兴趣。但这种兴趣缺乏通常直接源于以下事实：该校的计算机科学只能作为选修课修读——而不是作为可计入数学或科学学分的课程。学生的课程表已经因必修课程而超负荷，不计入核心课程学分的计算机科学课程更不可能吸引学生，学校也更不愿意开设这些课程。第二种回应是能够教授计算机科学课程的合格教师很少。但由于计算机科学不被视为核心课程，教育学院和州教育部门不愿为计算机科学教学认证开发严格的课程，从而未能提供一条可认证的途径来培养合格的教师队伍。

尽管美国以苹果和谷歌等科技巨头为傲，但美国在K–12阶段的计算机教育方面正落后于其他国家。英国最近制定了一套国家计算机科学课程<sup>10</sup>，其中计算思维占据突出地位，并在教学上分为四个递进阶段，从基础应用和基本原理开始，进而学习语言和系统化问题解决。自20世纪90年代初以来，以色列已在K–12阶段强制实施严格的计算机科学教育项目，其基础是一门“强调算法思维基础”并教授“编程作为让计算机执行算法的方式”的课程。<sup>11</sup>

这两个国家提供了超越补充性课后项目和选修课程的计算机科学教育潜在模式。它们将此类课程认定为核心计算课程。谷歌教育总监玛吉·约翰逊指出，将计算机科学标准排除在美国正在形成的共同核心州立标准<sup>12</sup>之外，是国家倡议的巨大缺陷，这不仅体现在儿童接触技术的能力上，也体现在他们通过实际应用学习基础数学和科学技能的能力上。<sup>11</sup>鉴于共同核心州立标准（目前已被46个州采用）的突出地位，该倡议代表了这个国家开始在全国整合计算机科学教育的前所未有的机会，这是“核心计算”（Computing in the Core）<sup>14</sup>已经认识到并继续倡导的事业。

任何此类核心课程的结果都显而易见。访问美国任何公立或私立的小学、初中或高中的人，都不太可能看到任何与计算机科学相关的正式教学，或把计算机视为计算性、创造性设备的正式教学。正如教育历史学家拉里·库班所指出的，学校坚持*教授计算机*，而不是*用计算机教学*。<sup>15</sup>K–12阶段的技术课程关注基本功能，使设备成为教学目的而非手段，除了计算机本身之外，仍然缺乏任何真正的内容。尽管学习Microsoft Office套件应用或熟悉计算机组成部分具有教育价值，但此类活动并未体现计算的创造性和协作潜力，也不值得开设一学期的课程。缺乏扎实的入门计算教学，是全国学校失败的核心所在。尽管学校拥有这些机器已超过三十年，但学校在很大程度上未能对儿童思考和参与使用它们的方式带来有意义的改变。

学校里发生但在上课时间之外的外围活动展现了一些希望。课后项目一直是学校里发生最有趣技术学习的地方。无论是帮助学生在Scratch游戏俱乐部制作视频游戏，在乐高机器人俱乐部搭建可协作编程的机器人，还是用LilyPad Arduino设计互动发光面具，课后俱乐部历来有余地让孩子们在比传统课堂更开放、更具社交性的空间中按自己的节奏工作。全国数千个社区技术中心也支持在服务不足的社区中接触计算机活动（如文字处理、电子邮件和网页浏览）。一些中心，如计算机俱乐部（Computer Clubhouse），专注于计算的创造性使用，鼓励青少年开展自己的项目，包括动画、游戏和音乐视频的编程。Scratch旨在让编程能够触及青少年丰富的媒体兴趣。<sup>16</sup>

大多数课后俱乐部和社区技术中心的独特之处在于，它们作为空间存在，让学生有机会制作自己的项目。正如修订后的大学先修计算机科学课程（以及前几章描述的活动）所表明的那样，用技术制作东西的能力处于计算思维和计算参与的核心。正如第2章所指出的，用计算机制作将学习从抽象带入具体，然后可以像货币一样在更广泛的创客同伴网络中分享。“我们是需要制作的生物，”《MAKE》杂志创始人戴尔·多尔蒂引用诗人弗兰克·比达特的话写道。“制作是人类的基本活动。”在其文章《创客心态》中，多尔蒂将制作命名为儿童最令人兴奋、最难忘和最重要的学习场所。

多尔蒂还感叹，这种制作的倾向往往在儿童年幼时就被驱除，因为学校——尤其是随着学生年级升高——越来越将制作视为补救性的、非学术性活动而回避。“创客运动最大的挑战和最大的机会，”多尔蒂在谈到DIY社区时写道，“是转变教育……学生们正在寻求主导自己的教育生活，希望参与创造性和刺激性的体验。许多人理解教育的痛苦与真正学习的快乐之间的区别。不幸的是，他们被迫到校外寻找机会来表达自己并展示自己能做什么。”<sup>28</sup>

## 俱乐部遇见课堂：寻找中间地带

如果期望课后俱乐部中浮现的创客文化的乐趣也能在上课日存在是现实的，那么在一定程度上，学校教育的构想和实践方式必须发生根本性改变。戴尔·多尔蒂在这里是一位渴望者，许多将数字媒体和DIY编程视为对传统师生学校教育范式挑战的人也是如此。这也讨论于《新媒体与学校教育不相容吗？》一文中，媒体理论家亨利·詹金斯采访教育研究者理查德·哈尔弗森，后者与艾伦·柯林斯合著了*《技术时代的重新思考教育：数字革命与美国学校教育》*。对哈尔弗森而言，K–12学校中技术的未来较少取决于设备本身，而更多取决于关于人们如何最好地学习的各种观点。一种观点认为，学习发生在学校，学校是经认证的实体空间。哈尔弗森称之为“制度渠道”。另一种观点认为，学习不必与时间和地理绑定，Web 2.0可以通过同伴和兴趣驱动的活动提供学习机会。哈尔弗森将其称为“数字媒体渠道”，并指出这种学习方式不标准化且常常不可预测，但它确实“突出了许多学校学习活动所缺失的三个至关重要的学习方面：动机、产出和真正的受众”。<sup>19</sup>

哈尔弗森对制度渠道和数字媒体渠道的区分让人想起帕佩特对学校派和渴望派的区分。学生在课后俱乐部是否比在常规学校课堂上更有动力、更高效？学生是否更可能在同伴俱乐部而非教室里遇到真正的受众？为了研究这些关于动机、产出和真正受众的问题，我们设计了一项研究，让中学生在学校课堂和课后俱乐部中使用Scratch。<sup>20</sup>我们想知道儿童在每个空间中的受激励方式是否存在差异，他们在每种环境中产出了什么，以及他们为谁产出这些内容。
