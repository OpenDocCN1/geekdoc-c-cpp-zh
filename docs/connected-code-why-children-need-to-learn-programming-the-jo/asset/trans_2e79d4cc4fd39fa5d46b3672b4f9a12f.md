但透明性还有第二个同样重要的维度，它关乎不同文化的融合——手工艺与缝纫（在历史上与女性相关联）以及工程与计算（在历史上与男性相关联）。我们在众多工作坊和课堂中观察到，这些关于电子纺织品材料和活动性别属性的指涉如何渗透进对话中。当中学男生将自己的活动称为“做电路”而非缝纫，或当高中男生说“缝纫是女生的运动”时，他们是在宣称工程对男性更有价值、更合适。<sup>18</sup> 另一方面，也有人认为用电子纺织品学习会强化现有的性别刻板印象，女性应该参与更多由男性主导的活动，比如机器人技术。这类张力是富有成效的，因为它们开启了对话，并质疑了对计算相当狭隘的看法。

LilyPad Arduino电子纺织品构建套件让人回想起女性、纺织品与计算之间由来已久的历史联系。艾达·洛夫莱斯关于分析机的笔记在十九世纪催生了第一个“计算机程序”，而使用穿孔卡在纺织品上织出复杂图案的雅卡尔织机，被许多人视为计算硬件史上的第一步。洛夫莱斯或许写下了将时尚与计算联系起来的最优美的一句话：“我们可以最贴切地说，分析机编织代数图案，正如雅卡尔织机编织花朵与叶片。”<sup>19</sup> 计算文化在战争期间从纺织编织转向代码运算，如今又回归手工艺，并从数字制造中获得新的动力。电子纺织品构建套件使文化与计算的复杂交汇变得清晰可见，因为它们将被视为相互矛盾的领域结合在一起。它们的存在将低科技与高科技的计算形式融为一体，提供了一个可见的反证。

它们还让学生看到，简单的设计修改就能将同样的技术与截然不同的社群联系起来。LilyPad Arduino的传感器和执行器是对功能等效的Arduino主板、传感器和执行器的改造。这意味着LilyPad Arduino能做Arduino主板能做的一切，反之亦然。然而，我们从Leah Buechley和Benjamin Mako Hill<sup>20</sup>最近的一项研究中得知，参与LilyPad社群的女性远多于参与Arduino社群的女性：在发布到网上的项目中，80%的Arduino项目由男性设计师完成，而80%的LilyPad Arduino项目由女性设计师完成。尽管像乐高Mindstorms这样的机器人套件会吸引某种特定的计算生产方式和生产者，LilyPad Arduino这样的纺织品构建套件也同样如此。计算活动和材料的设计与框架，会影响谁将自己视为社群的一员，并进而加入和参与其中。

同样，作为许多电子纺织品活动设计背景的公共缝纫圈，与机器人活动中以竞赛驱动的工作坊截然不同。竞赛具有激励作用，在共同活动中提供目标和观众，但它们不应是组织、展示和庆祝计算参与的唯一模式。我们需要创建与机器人竞赛不同的社群，提供协作和支持性的氛围。我们正在围绕计算手工艺活动建设这样的新社群和活动。这些被称为电子手工艺圈（eCrafting Circles），<sup>21</sup> 有意呼应过去将邻里聚在一起制作被子、衣物等的缝被聚会和缝纫圈（见图6.3底部）。线上手工艺圈将不是竞赛，而是具有时效性、与本地相关的事件，允许分享和展示计算手工艺品。这些活动的目的是激发更多人参与和协作电子纺织品，就像FIRST乐高联盟竞赛提升了机器人技术的参与度一样，但不强调竞争，从而不会让大批人群望而却步。<sup>22</sup> 电子手工艺圈既可跨地区扩展，又能适应当地需求，旨在提供一个论坛，让志同道合且感兴趣的参与者分享所学见解，并为他们的设计提供急需的支持。计算参与的大部分焦点都在线上世界，但在实体构建和本地参与中也能发现同样多的益处。当手工艺和计算为学习提供新的材料、活动和受众时，我们或许应该重新审视计算机实验室和课堂可以是什么样子。

## 下一个千年的工坊课：动画立体书、游戏机厅与公共展示

在新的俱乐部、社区中心和课后项目中，学生将能够与计算机互动，以沟通、接收和组织信息。但新的俱乐部不能独自承担教孩子们使用计算机进行系统性和创造性思维的责任。学校课堂需要接纳在周边俱乐部中培养起来的动手型、创造性技术学习。在20世纪50年代的职业教育和工业艺术课程中，学生在实际应用中协作并建设性地使用技术。然而，到了20世纪70年代，一些改革者开始将这些课程描述为毫无意义或缺乏挑战性，尽管它们使教育更加动手、实用和以项目为导向，并代表了教育中一些最具创新性的思想，特别是约翰·杜威在*《经验与教育》*中的进步思想。<sup>23</sup>

通过技术进行动手和创造性学习的承诺并没有被遗忘。十多年前，计算机科学家和教育家Mike和Ann Eisenberg设想了新一代的工坊课，将包含计算媒介和手工艺——他们称之为计算机增强手工艺。<sup>24</sup> 工坊课通常由不打算上大学的学生选修，可以通过将计算与实体物品相结合，让所有学习者参与设计并理解技术。这种对具体学习的重新评价也得到了教育作家Mike Rose的支持，他分析了行业、手工艺和艺术的智力维度。大多数教育研究都集中在理解科学、数学和语言艺术等学科的学习和教学上，很少关注管道、木工和侍应工作中蕴含的智力需求和机会。然而，建造机器人和制作电子纺织品有力地说明了手工艺、工程和计算机科学如何能够创造出丰富而引人入胜的学习环境。

新一代工坊课的一个意想不到的方向是回归纸和颜料，并用导电性和计算加以增强。
