
## 1 编程的回归

1990年6月23日，波士顿计算机博物馆开幕了一场展览，展出全球首台可走入式计算机。这台计算机是桌面型号的五十倍大，独一无二。参观者用手抚过按钮有头那么大的键盘，抬头看有记分牌那么大的主板，还站在与视线齐平的软盘旁比身高。它不只是一个模型，还运行着可用的软件程序，让参观者在巨型屏幕上环游世界。借助巨型轨迹球控制光标，参观者从全球三百个主要城市中选择起点和终点，程序计算任意两地之间最短的陆路路线，并展示从一个地点到另一个地点沿途会遇到的地理景观。展览大获成功，并获得全球媒体报道。数千人走进这台设备的内部世界；它能在一张巨大的屏幕上向人们展示世界，而其庞大的体积似乎也在评说计算机在世界中日益增长的存在。<sup>1</sup>

距博物馆几英里外，在波士顿一所公立小学里正举办另一种展览，当时那里是全市最贫困的社区之一。车头灯项目拥有全球最大的学校计算机实验室，配备数百台计算机。作为麻省理工学院媒体实验室赞助的一项大胆实验的一部分，车头灯项目同样致力于让用户“进入”计算机的内部运作。然而，该项目不是让参观者走进去，而是把孩子们放到机器后面名副其实的驾驶座上，教他们使用编程软件 Logo 来操控计算机的行为。该项目由西摩·帕佩特发起，建立在一个当时不同寻常的理念之上——儿童应该（也能够）为计算机编程。在车头灯项目内部，计算机围成圆圈摆放在教室附近的大空间里，而不是被关进一间单独的教室。每天一次，学生用 Logo 编写故事、软件和游戏，有时还与其他国家的孩子交换作品。车头灯项目在其持续的数年里取得了巨大成功。数千名学生和教师成为将编程引入小学阶段的先驱，共同提供了一个活生生的例子，展示用计算机学习和教学可以是什么样子。<sup>5</sup>

1999年，计算机博物馆关门，迁过查尔斯河到波士顿科学博物馆时，可走入式计算机的展品被打包存放，却再未重新组装。车头灯项目的计算机被送到一间间独立的计算机实验室，因为用于协作编程的开放学习空间被认为在传统学校日程结构中不可行。一台人们可以走进去的巨型计算机？会编写计算机游戏的小学生？这两个想法似乎都属于不可行的范畴。20世纪90年代后半期，笔记本电脑设备日益流行，大型机器的概念显得过时。CD-ROM（只读光盘存储器）的发展使与编程相关的辛苦劳动同样显得过时。当应用程序只需放入一张光盘就能轻松下载时，谁还愿意费心经历编写程序的繁重过程呢？

然而，无论是巨大的可走入式计算机，还是帕佩特的编程圈，都证明了这样一种信念：我们所有人——无论年龄或经验——都有可能触摸机器本身，进入计算机的内部运作，并通过机器与自己的热情相连。如今，钟摆又摆回来了。今天，计算机已经走出博物馆和计算机实验室。它的存在最深刻地体现在无处不在的手持和触屏设备中，这些设备运行着为个体用户的专业和社交需求量身定制的数字应用。计算机——台式机、笔记本电脑、平板电脑和移动设备——已经切实而个人化地成为我们自身的延伸，<sup>5</sup> 而编程，曾经只是技术精英的博学消遣，如今正被教育者和理论家视为所有儿童的一项关键技能，甚至是一种新的读写能力。<sup>4</sup>

我们常常忘记与借助计算机、通过计算机以及关于计算机进行学习相关的社会、个人和有形要素的重要性。然而，这些要素在帮助我们理解机器的内部运作以及参与社交网络的动力方面发挥着基础性作用。在*《连接代码》*中，我们考察重新发现计算机作为个人和社会连接手段的可能性。尽管计算机博物馆的展览和帕佩特的教育工作坊最初都令人热情高涨，但为什么“进入”计算机没有成为我们学校的教育优先事项？编程如今又是如何回归的？

让编程重返学校，是对培养年轻学习者计算思维这一呼吁的回应之一。其前提是，通过学习像计算机科学家一样思考，学生能够解决日常问题，设计我们在日常生活中都会使用的系统，并在其他学科中取得进步和创新。<sup>7</sup> 计算思维如今已成为一个总括性术语，指计算机科学在日益数字化的世界中对于推理和沟通的贡献。然而，尽管计算思维作为教授编程的概念框架已经出现，编程的复兴却并非由教育者或计算思维的推动者主导。

编程复兴的一个重要推动力来自一个意想不到的来源——数字青年文化所特有的自己动手（DIY）精神。如今计算机在校内外都触手可及，孩子们使用自己的机器进行技术创新，制作自己的电子游戏、互动艺术项目，甚至通过电子纺织品制作可编程服装。他们用来创作这些自制物品的同一批计算机，也将他们连接到更广泛的网络，与其他拥有共同兴趣并致力于通过共同 DIY 伦理“自己动手”的年轻用户相连。学校或许能够将这些非正式协作社区的一些方法（尤其是创造性生产和网络化参与）纳入自己的正式环境。DIY 文化的这些方面提供了有前景的模型，说明学校可以如何在数字时代调整用计算机学习和教学的方法。学校当然负有这样的责任。

尽管 DIY 青年社区兴起，但这些社区只代表青年人口中的一小部分。<sup>8</sup> 大多数孩子使用自己的设备——无论是笔记本电脑、iPad、iPhone 还是 Droid——来消费商业媒体。计算机或许已经成为我们自身的延伸，但我们在多大程度上教孩子如何设计和管理这些延伸？我们如何帮助孩子成为数字媒体的生产者而不仅仅是消费者？编程应在促进这种生产中扮演什么角色，学校又怎样才能最好地帮助孩子培养21世纪的读写能力？在数字媒体普遍突出的情况下，我们是否需要关注获取和参与的公平问题？鉴于这些问题涉及个人身份、社会福祉以及这个国家更广泛的经济可行性，我们需要重新审视在当今社会中具备读写能力意味着什么。做到这一点的一种方式，是回到促使帕佩特在学校建立计算机编程圈的那些理念，并将这些理念置于当今的教育、文化和技术环境之中。

最初将编程引入学校的推动，受到帕佩特1980年著作*《心智风暴：儿童、计算机与强大理念》*的启发。他在书中主张，通过为计算机编程，儿童可以学习数学、控制论等新主题，以及他们自己的思维（依据约翰·杜威、保罗·弗莱雷和玛丽亚·蒙台梭利所提倡的进步教育观点）。这本书颇具争议，但也帮助全球教育者认识到让计算机进入学校的价值。*《心智风暴》*所倡导的计算机进学校愿景，通过开篇小故事中描述的车头灯项目编程圈变得生动起来。

在*《连接代码》*中，我们讨论儿童实际对什么编程感兴趣、他们在什么情境下编程以及他们如何编程。通过入门编程语言*Scratch*这一视角，我们从几个维度考察儿童与计算机编程之间的这些联系：

- *从代码到应用*，说明学生如何日益把编程不作为一门抽象学科来学习，而是作为制作实际应用（如电子游戏和数字故事）的一种方式；
- *从工具到社区*，强调从把学习代码视为个人化努力到把它视为社会性事业的转变；
