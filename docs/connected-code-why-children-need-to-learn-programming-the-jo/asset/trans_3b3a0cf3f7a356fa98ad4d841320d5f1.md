这些来自当地线下社区中心的数百个游戏迅速增加到数千个、数万个，现在已达到数百万个。Scratch网站被称为“交互式媒体的YouTube”，目前拥有150万注册会员（称为“Scratchers”），自2007年推出以来，用户已上传了超过300万个项目。Scratchers的年龄从5岁到70岁不等，但大多数成员年龄在11岁到21岁之间。Scratchers的平均年龄是15岁。Scratch有来自全球近17000个城市的访问者，其可编程积木被翻译成40多种语言。<sup>26</sup> 尽管许多网站（如YouTube和Flickr）支持用户生成内容的上传和下载，但Scratch网站为用户提供了一个分享自己编程的交互式媒体的平台。<sup>27</sup> 在网站上上传和下载项目是一种信息交换，但也是一种个人创作内容的交换，其他人可以下载和混搭这些内容，以构建全新的项目。随着用户对Scratch网站越来越熟悉，他们会遇到各种项目和代码脚本，可以对其进行采样和混搭。

当Scratch团队成员安德烈斯·蒙罗伊-埃尔南德斯着手创建第一个Scratch在线社区时，布鲁克曼的MOOSE Crossing以及她对青年程序员社区的建议都被视为范本。但布鲁克曼和蒙罗伊-埃尔南德斯都受到帕佩特建构主义原则的启发。他希望Scratch成为一个“某种‘桑巴学校’，新手和专家聚集在一起阅读、写作和混搭Scratch作品。我想让Scratch从‘仅仅’一个好工具变成一个同伴聚集在一起创作、分享、混搭，甚至只是‘闲逛’的空间：一个基于公共资源的对等生产社区。这意味着让人们接触受众、潜在合作者，以及一个创作者可以从中学习和混搭的灵感作品库。”<sup>28</sup>

在线Scratch社区的巨大成功标志着从编程工具向程序员社区的转变。其他入门编程工具也在效仿Scratch的做法。例如，编程语言Alice团队正在开发Looking Glass Community，作为其游戏工具的在线扩展。<sup>29</sup> 微软Kodu和Recreational Design的营利性商业发展

其他社区成员可以分享他们的想法的版块。评论可以包括提问、建议、批评（Scratch团队成员会定期审查是否属于“建设性批评”）和赞美（例如“喜欢！”和“酷项目！”）。Scratch团队成员最近一直专注于通过评论功能使用基本的鼓励和署名来欢迎新用户访问网站，并鼓励他们通过个人联系探索在线项目，这些联系通过评论区成为可能。<sup>18</sup> 即使是最简单的表达积极反馈的评论也能激励用户继续他们的编程。

网站上的论坛版块为分享、提问或评论所有与Scratch相关的事情提供了一个平台。如何让项目出现在首页是论坛中的热门话题，但成员们也会发帖寻找其他潜在合作者并加为“好友”，集思广益项目创意，并请求和分享技术诀窍（例如如何制作更高级的滚动游戏，或者如何将视频导入作为动画的Scratch）。论坛中的分享（特别是与技术专长有关的分享）现在已经促成了一个与Scratch相关的wiki的开发，该wiki包含近一千个独立页面，其中大部分不是由MIT Scratch团队创建的，而是由Scratchers自己创建的。<sup>19</sup>

虽然过去Scratch软件作为编程工具和作为对应社区的在线网站之间存在着区分，但该社区及其资源的巨大增长表明它本身作为一种工具也很有用。在新版Scratch 2.0中，Scratch设计团队不再将Scratch作为工具和作为社区进行任何划分。年轻的设计者在同一个网站上编写代码和交流。期望是，这些新的社区窗口最终将使人们更容易联系和协作，从而进一步降低门槛、提高上限、拓宽墙壁（指扩大参与范围）。接下来的社区案例研究将体现这三个要素。
