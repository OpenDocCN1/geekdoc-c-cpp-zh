
在头脑和心灵中构建，并与世界中的体验相连。连接式学习探讨如何将计算机视为知识转化、个人表达和社会关联的工具，从而使学习者能够创造并与他人建立联系。

Papert将学习视为创造具有个人和社会关联性的制品、连接新旧知识以及与他人互动的过程。<sup>2</sup>这种描述不仅仅指计算机。相反，它勾勒了学习过程及其条件，并将制品置于首位——即我们构建的对象或“齿轮”，以及我们赋予它们的个人意义。有些人认为这种学习观过于以心智为中心，但它通过纳入社会关联性，同样也是以社会为中心的。我们头脑中的对象并非脱离社会世界而存在。事实上，它们深深植根于我们生活的社区及其成员所珍视的事物，并与之紧密相连。在20世纪80年代，计算机仍然昂贵，只有少数人能用。但如今数字媒体更加实惠、便携，已经进入我们的日常生活。本书的目标之一就是考察参与、协作和计算如何帮助年轻人在数字世界中学习和生活。

在本章中，我们考察连接式学习的个人、社会、文化和物质维度，以及它们对设计学习机会、技术和环境的意义。Papert与让·皮亚杰一样，将学习视为构建知识结构的过程，<sup>3</sup>但他增加了一个重要维度：心智制品必须进入公共世界，在那里可以被他人审视、分享和重视。在许多方面，这一观点预见了构成互联网的庞大而分散的数字对象和社区网络。它反映了使用任何媒介进行实践、思考和互动——简言之，学习——的基础。

连接式学习的个人、社会、文化和物质维度在今天与三十年前一样具有现实意义。它们为理解计算文化中的学习提供了基础，这种文化重视生产与连接两个方面的参与。在思考这些问题时，能“唤起情感的对象”（借用雪莉·特克尔的说法）<sup>4</sup>之一是编程语言Logo，<sup>5</sup>它引发了关于学校中编程和计算机的许多讨论，以及让儿童而非计算机主导自己的学习。

## 编程工具，编程世界

Logo不是第一种，也不是唯一一种供儿童使用的编程语言。Basic以及后来的Pascal等编程语言在许多学校同样突出，关于哪种编程语言最适合学校教学，当时存在大量争论。但与Basic和许多其他编程语言不同，Logo承诺带来的不仅仅是学习编程：它以新的方式教授数学、控制论和科学，还提供了一套教学法。这些附加特色使Logo不同于其他任何编程语言，并使其成为Scratch的前身。

将程序视为可以公开分享的个人对象，这种思维方式也出现在互联网文化中。互联网文化汇集了个人物品（如照片、故事和设计），将它们引入极其广泛的公共领域，并让它们获得全新的意义。在这种背景下，计算思维变成了计算参与，因为当代码被创建时，它既具有个人价值，也具有与他人分享的价值。代码中的“可供思考的对象”不仅局限于头脑中，还会与他人分享，从而为个人维度增添了社会和文化维度。

### 社会维度

学习是一个社会过程，无论是面对面发生还是在网络公共空间中发生。教育研究者让·莱夫和艾蒂安·温格在1991年关于学徒制学习的开创性著作强调了学习的共同体性质，而这种性质在传统学校教育所特有的对个人学习的关注中常常缺失。近来，游戏研究者吉姆·吉发现了游戏社区中形成的亲和文化的重要性，以及这种替代性学习环境如何为重新评估学校教育提供了重要视角。在所有学习社区中，有效的参与要求学习者通过与他人协作来寻找、组织和分配责任，同时共同参与活动或创造制品。学习者所需的协作能动性强调了学习者在构建社区中的积极作用，这种社区既构建知识，也设计可以与他人分享的制品。<sup>10</sup>那句众所周知的“可供思考的对象”变成了“可供分享的对象”，代表了社区中协作与学习的产物和精神。

连接式学习的社会维度一直聚焦于社区，因为程序的个人建构不是发生在真空中，而是在社会情境中。Papert对巴西桑巴学校的研究体现了他的一种观念：社会规范和互动是任何形式学习的关键：

> 这些不是我们所知的那种学校；它们是社交俱乐部，会员人数从几百到数千不等。每个俱乐部都拥有一栋建筑，一个供跳舞和聚会的地方。……在一年中，每所桑巴学校都会为下一届狂欢节选择主题，选出明星，歌词被写了又改，舞蹈被编排并反复练习。学校成员年龄从儿童到祖父母不等，能力从新手到专业水平都有。但他们一起跳舞，在跳舞时，每个人都在学习、教学，同时也在跳舞。甚至明星们也在那里学习他们困难的部分。<sup>13</sup>

学习文化可以是社区中心，甚至可以是虚拟世界。英特尔计算机俱乐部网络（Intel Computer Clubhouse Network）就是前者的一个例子，它在全球有一百多个地点，年轻人自愿聚集在那里，使用创意软件应用来创作数字图形、音乐和视频。与学校不同，计算机俱乐部不遵循固定的课程，成员们在协调员和导师的支持下相互介绍新活动。这些理念也为虚拟社区提供了蓝图，例如MOOSE Crossing，它允许成员编程并分享他们的虚拟作品（更多内容见第4章），以及ClubZora，它促进了围绕价值观的讨论。如今的例子包括Scratch社区（拥有100万个项目和数十万用户）和动画网站Newgrounds（拥有超过200万成员，他们开发并分享了超过50万个基于Flash的动画和视频游戏）等虚拟环境。在所有这些例子中——巴西分散的桑巴学校、计算机俱乐部网络和虚拟社区——社区成员之间都有丰富的互动，这些互动自下而上地发展，并由共同的兴趣和价值观所引导。<sup>12</sup>在这种背景下，计算参与既关乎社交，也关乎贡献有价值的制品、专业知识和反馈。
