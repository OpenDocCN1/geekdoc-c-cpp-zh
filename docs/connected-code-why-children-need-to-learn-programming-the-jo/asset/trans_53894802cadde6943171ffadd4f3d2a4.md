
这一点在一系列由社区发布供混搭的“操作指南”项目中表现得尤为明显。这些操作指南项目（也称为教程或演示）由个人用户独自或相互协作创建，涵盖一系列项目功能，例如如何为游戏添加计时器，以及如何为移动物体添加速度。尽管有些操作指南项目会逐步解释如何构建相关编码脚本，其他项目则只是把脚本提供给混搭者。最好的操作指南视频会在演示过程中解释如何生成脚本。

项目“如何滚动”由 Scratch 用户“cougers”发布，是一个既作示范又作讲解的项目的良好范例。滚动是《超级马里奥兄弟》和《陷阱！》等主机电子游戏的基本要素。移动的背景会随着角色的移动向前“滚动”。由于滚动是那些有兴趣制作游戏的 Scratch 用户最抢手的技能之一，它位居该网站发布的教程列表之首。“如何滚动”项目很受欢迎（被混搭九十四次），它让玩家沿着不断变化的地形向前滚动，而生成脚本的分步说明会随着玩家前进沿地平线出现。其创作者“cougers”在项目说明区发帖说：“如果这能变成一个游戏，那就太酷了。”

通过这些各种各样的操作指南教程，Scratch 新手能够在相对较短的时间内创作出复杂的游戏、故事和艺术项目——当然，这比完全从零开始开发项目要短得多。关键因素在于，这些混搭形式并不仅仅是重新利用单个编码积木，而是整体采用项目并将它们彼此结合，创造出全新的项目。在这些“巨型混搭”中，用户面临的挑战是确保一个项目的代码与另一个项目的代码兼容，而这可能需要混搭者进行大量调整。但完成之后，创作者便构建了一个项目，它依靠一系列互补的“隔间”运行，这些“隔间”彼此协同，同时也各自独立运行，集中体现了计算机科学家 David Parnas 在其关于编程模块化设计的开创性论文中所指出的“信息隐藏”这一关键要素。<sup>14</sup> 在将项目作为各种模块混搭在一起的过程中，我们看到了一种进行计算性思考和参与的潜力——基于一个以相互尊重地混搭为共同约定的实践共同体，在更短的时间内创造出更复杂的项目。

## 极客式钻研：作为创造性挑战的混搭

在 Katie 和 Nadia 的混搭中，交流发生在多个个体之间。然而，这种作为混搭特征的交流要素也可以是个人的努力。Karen Brennan 在她对十一岁男孩 Jackson 的访谈中指出了这种个体性如何在混搭中体现；Jackson 在 Scratch 上进行混搭，较少出于社交目的，更多是为了自我提升。Jackson 会混搭他觉得有吸引力的游戏，以减少编程积木的总数，同时不以任何方式改变玩法。<sup>15</sup> 他把不可替代的关键代码称为“峰值”，并解释说目标是清理“噪声”或多余积木，从而创建更经济、更高效的编码方案。在这个例子中，混搭是一条学习路径，也是一种挑战，触及 Papert 所说的编码所特有的“艰苦的乐趣”要素。<sup>16</sup>

这第三类混搭的独特之处在于，其社交化程度具有“添加式”混搭的特征，而其激发更高生产力的意图则具有“操作指南式”混搭的特征。这两个目标中的第一个，以 Scratch 网站上可混搭的“涂色比赛”之流行体现得最为充分。在这些比赛中，单个用户会发布一张无色的自绘或导入图像、一套写在项目说明区的规则（例如可以使用哪些颜色，以及是否可以添加音乐和背景），以及一个截止日期。比赛创作者通常会选出获胜的彩色混搭作品，不过获胜者偶尔也会根据混搭作品获得的项目浏览量或“喜爱”数来决定。获胜者因此能在 Scratch 网站上获得声望，而如果比赛特别受社区欢迎，比赛创作者也有机会登上首页。<sup>17</sup>

与“添加式”混搭一样，这些涂色比赛能从单个参赛作品生成数百个混搭作品，但正如主要出于社交目的而开发的混搭作品的典型情况一样，它们在广度上有所得，却在深度上有所失。大多数涂色比赛混搭作品几乎不涉及编码复杂性，甚至可能根本没有代码，参赛作品通常仅根据静态图像来评判。Scratch 网站上的其他比赛则更为复杂。在“Roomba 混搭挑战”中，用户会看到一套两居室公寓的平面图，需要由自主的 Roomba 真空吸尘器来清洁（图 5.4）。

![](img/9eb64eca0f040452d3ba8df0d78b35a9_102_0.png)

图 5.4 三个“极客式钻研”混搭：“Roomba 混搭挑战”“卧室制造器”和“激光塔防”。

真空吸尘器在房间里随机移动，同时右下角的计时器（表示电池寿命）在滴答走动。当 Roomba 在地板上移动时，它会留下一条白色路径，标示已经清洁过的区域。用户没有任何控制手段。在项目说明区，项目创作者解释了该项目的用途。“我听到你问，那这有什么意义？”说明中写道，“意义在于修改 Roomba 中的编程逻辑，让它在你的电池耗尽之前，比我提供的那些非常笨的代码更高效地清洁地板。”作者提出了一些建议（例如用传感器实现更好的碰撞检测，甚至为机器添加逻辑），并解释说这个项目是“一个你必须思考编程的游戏，因为对程序的一次修改可能只需几秒钟，但你必须等上几分钟让吸尘器完成工作，才知道自己做得有多好！”

Roomba 混搭挑战面向有经验的 Scratch 程序员，处于与涂色比赛相反的另一端。它需要反复调试、创新思维和耐心。混搭者每次都必须对吸尘器进行长时间的测试运行，看看修改后的代码是否让设备成为更高效的清洁工具。媒体学者 Giorgos Cheliotis 和 Jude Yew 在分析支撑混搭文化的社会结构时指出，竞赛在吸引新用户访问网站、保持有经验成员的兴趣并激发其动机（和生产力）方面发挥着重要作用。<sup>18</sup> 这正是我们对于该网站赞助的一系列基于 Scratch 的协作挑战的经验，这些挑战将在第 4 章讨论。<sup>19</sup> 这些协作倡议如今已进入第四年，它们以一个“种子项目”开始；种子项目是一个项目的骨架，提供一个基本框架（如数字故事或互动艺术项目），参赛者可以在各自团队中以此为基础进行混搭。混搭激发协作活动，并作为在各种修订状态之间交换项目的手段，维持这种协作。

## 作为教学法的混搭：学校的挑战与可能

### 文化挑战

在上述在线 Scratch 混搭挑战的所有特征中，有三点尤为突出，因为它们特别能有效促进初学程序员的学习。第一，参赛参与者彼此合作、为彼此创作，制作出对他们个人有意义的游戏和故事。第二，这些年轻人与同龄人协作，承认他们共同完成的事情无法由个人同样出色地完成。第三，他们利用混搭作为修订和改进自己作品及他人作品的手段。这三个要素是 K–12 学校（甚至高等教育）中很少见的学习面向。<sup>20</sup>

第一，在学校里，学生通常不创作自己的内容，而是概括别人给他们的内容。即使他们创作自己的作品，也是为老师而作，很少为同龄人而作。第二，即使课堂要求协作，研究也表明，当小组中极少数人一直承担大部分责任而其他人做得很少时，小组合作是无效的。<sup>21</sup> 因此，许多学生对协作不屑一顾，而另一些学生则过于渴望协作。第三，在学校里，混搭不是混搭，而更常被视为彻头彻尾的剽窃，并且在上学期间即使不被禁止，也很大程度上受到劝阻。

这第三点也是最后一点，清楚地区分了课堂学习与 Scratch 在线等 DIY 青年文化中的学习。有人可能会认为，混搭的 DIY 文化与 K–12 学校教育的制度性质相对立；在后者中，秩序和等级往往压过自发性，而这两者是支撑整个教育体系的核心要素。尽管越来越多的媒体理论家和教育工作者将混搭视为一种新素养<sup>22</sup>，且过去十年间对数字素养进行了大量研究<sup>23</sup>，学校仍抵制将混搭作为基于课堂创作的可行形式。
