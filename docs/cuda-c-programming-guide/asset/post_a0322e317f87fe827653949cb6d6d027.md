## B.10. Read-Only Data Cache Load Function

The read-only data cache load function is only supported by devices of compute capability 3.5 and higher.

```cpp
T __ldg(const T* address);
```

returns the data of type T located at address address, where T is char, signed char, short, int, long, long long, unsigned char, unsigned short, unsigned int, unsigned long, unsigned long long, char2, short2, short4, int2, int4, longlong2, ulong2, uchar4, ulong2, ushort4, uint2, uint4, ulonglong2, float, float2, float4, double, or double2. The operation is cached in the read-only data cache (see Global Memory).
