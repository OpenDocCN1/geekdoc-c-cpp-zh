# ### 8.2.3 Inversion Method

Given is a random number generator `drand()` which is assumed to generate random numbers $U$ which are distributed uniformly in $[0, 1]$. The aim is to generate random numbers $Z$ with probability density $p_Z(z)$. The corresponding distribution function is

\[F_Z(z) \equiv P(Z \le z) \equiv \int_{-\infty}^{z} dz' p_Z(z') \qquad (8.48)\]

The target is to find a function $g(u)$, such that after the transformation $Z = g(U)$ the outcomes of $Z$ are distributed according to (8.48). It is assumed that $g$ can be inverted and is strongly monotonically increasing. Then one obtains

\[F_Z(z) = P(Z \le z) = P(g(U) \le z) = P(U \le g^{-1}(z)) \qquad (8.49)\]

Since the distribution function $F_U(u) = P(U \le u)$ for a uniformly distributed variable is just $F_U(u) = u$ ($u \in [0, 1]$), one obtains $F_Z(z) = g^{-1}(z)$. Thus, one just has to choose $g(z) = F_Z^{-1}(z)$ for the transformation function in order to obtain random numbers, which are distributed according to the probability distribution $F_Z(z)$. Of course, this only works if $F_Z$ can be inverted. If this is not possible, you may use the methods presented in the subsequent sections, or you could generate a table of the distribution function, which is in fact a discretized approximation of the distribution function, and use the methods for generating discrete random numbers as shown in Sec. 8.2.2. This can even be refined by using a linearized approximation of the distribution function. Here, we do not go into further details, but present an example where the distribution function can be indeed inverted.
