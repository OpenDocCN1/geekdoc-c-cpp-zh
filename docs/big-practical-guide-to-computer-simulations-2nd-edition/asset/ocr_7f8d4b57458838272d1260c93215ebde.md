+   - Type comments: For each data type (a structure in C or class in C++) which you define in a header file, you should attach several lines of comments describing the data type's structure and its application. For a class definition, also the methods which are available should be described. Furthermore, for a structure, each element should be explained. A nice arrangement of the comments makes everything more readable. An example of what such a comment may look like can be seen in Chap. 5 for the data type histo_t.
+   - Function comments: For each function, its purpose, the meaning of the input and output variables and the preconditions which have to be fulfilled before calling must be stated. In case you are lazy and do not write a man page, a comment atop of a subroutine is the only source of information, if you want to use the subroutine later on in another program. If you use some special mathematical methods or clever algorithms in the subroutine, you should always cite the source in the comment.
