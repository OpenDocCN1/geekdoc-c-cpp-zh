result in

```
['H', 'Li', 78, 55]
```

In this way one can iterate over all items of a dictionary:

```
for key in Z.keys():
    print "Z[", key, "]=", Z[key]
```

Alternatively, one can use the iteritems() method in the following way:

```
for key,value in Z.iteritems():
    print "Z[", key, "]=", value
```
