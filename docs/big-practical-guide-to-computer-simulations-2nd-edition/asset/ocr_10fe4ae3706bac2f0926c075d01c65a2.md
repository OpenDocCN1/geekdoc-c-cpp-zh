Now the final phase of the table setup starts. Starting from the right, the packages are filled up such that each one represents a probability $p_{\mathrm{avg}}$. For this purpose a corresponding share will be taken from package $t_1$, i.e. $q_{t_1}$ will be reduced by an amount $(p_{\mathrm{avg}} - q_t)$ and $b_t = a_{t_1}$ is assigned.

Since $q_{t_1} > p_{\mathrm{avg}}$, the amount remaining in package $t_1$ will be positive, but it might now be smaller than $p_{\mathrm{avg}}$. In this case, the package from now on belongs to those which have to be filled up.
