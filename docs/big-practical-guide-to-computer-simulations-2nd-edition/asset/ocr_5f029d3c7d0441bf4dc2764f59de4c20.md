recursion if an algorithm/function calls itself (maybe indirectly through other algorithms/functions). As a simple example we present a C function for the calculation of the factorial n! of a natural number n > 0. Its recursive definition is given by:

n! = { 1 if n = 0 or n = 1
      n × (n − 1)! else } (6.1)

This definition can be translated directly into a C function:

```
```c
int factorial(int n)
{
    if(n <= 1)
        return(1);
    else
        return(n*factorial(n-1));
}
```
```

In line 3 the test is whether n ≤1 instead of testing for n = 0 or n = 1. Therefore, it is guaranteed that the algorithm returns something on all inputs.

For n > 1, during the execution of factorial(n), a sequence of nested calls of the function is created up to the point where the function is called with argument 1.
