reads:

T(n) = { C  (n = 1)
          C n + 2 T(n/2)  (n > 1) }  (6.3)

If n is large enough, this recurrence can be solved by T(n) = C / log₂ n log n. This can be seen by inserting the solution into the second line of the equation

T(2n) = C 2n + 2 T(n)
      = C 2n + 2 C / log₂ n log n
      = C / log₂ 2n log 2 + C / log₂ 2n log n
      = C / log₂ 2n log(2n)  (6.4)

Consequently, the divide-and-conquer realization of sorting is asymptotically faster than the simple recursive sort-algorithm. Finally, note that the general recurrence equation

T(n) = { k                     for n = 1
          a T(n/c) + k n          for n > 1 }  (6.5)

is, for a > c (1), solved by T(n) = O(n^{log_c a}).

Another problem where the application of divide-and-conquer and recursion seems quite natural is the calculation of Fibonacci numbers fib(n). Their definition is as follows:
