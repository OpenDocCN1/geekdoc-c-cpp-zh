Often used important elements are fractions (\frac), and roots (\sqrt). The first commands takes two arguments, the second command one, plus an optional value [n] for the n’th root. Both commands can be nested, as the following example shows:

```
\begin{equation*}
\sqrt[3]{\frac{a+\sqrt{b+c}}{\frac{1}{x^2}+\sin(x)}}
\end{equation*}
```
