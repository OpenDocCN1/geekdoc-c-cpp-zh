# Definition 8.5

The distribution function of a random variable X is a function $F_X : \mathbb{R} \to [0, 1]$ defined via

$F_X(x) = P(X \le x)$
(8.8)

The index X is omitted if no confusion arises. Sometimes the distribution function is also named cumulative distribution function. One also says, the distribution function defines a probability distribution. Stating a random variable or stating the distribution function are fully equivalent methods to describe a random experiment.

For the fair coin, we have, see left of Fig. 8.1

$F(x) = \begin{cases} 0 & x < 0 \\ 0.5 & 0 \le x < 1 \\ 1 & x \ge 1 \end{cases}$
(8.9)

For measuring the x position of an atom in the uniformly distributed gas we obtain, see right of Fig. 8.1

$F(x) = \begin{cases} 0 & x < 0 \\ x/L_x & 0 \le x < L_x \\ 1 & x \ge L_x \end{cases}$
(8.10)

Since the outcomes of any random variable are finite, there are no possible outcomes $X \le x$ in the limit $x \to -\infty$. Also, all possible outcomes fulfill $X \le x$ for $x \to \infty$.
