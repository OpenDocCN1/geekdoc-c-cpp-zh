```
spread = 0;
for(t=0; t<num_points; t++)        /* determine closest center */
{
    c_min = -1;
    for(c=0; c<k; c++)              /* test with all centers */
    {
        dist = 0;                   /* calculate distance point/center */
        for(d=0; d<dim; d++)
        {
            diff = gsl_matrix_get(center,d,c)-gsl_matrix_get(data,d,t);
            dist += diff*diff;
        }
        if( (c_min == -1)||(dist_min > dist) ) /* closest center ? */
        {
            c_min = c;
            dist_min = dist;
        }
    }
    cluster[t] = c_min;
    spread += dist_min;
}
```

At the end of the function, the current spread is stored in the external variable which is given by the pointer spread_p. Also the memory for the center vectors and the cluster sizes is freed and finally the cluster array containing the result is returned:

```
*spread_p = spread;
gsl_matrix_free(center);
free(cluster_size);
return(cluster);
}
```
