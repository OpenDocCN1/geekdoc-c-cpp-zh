When compiling the code you have to include the option -g to allow debugging:

```
cc -o gdbtest -g gdbtest.c
```

The debugger is invoked using gdb (program name), i.e.

```
gdb gdbtest
```

Now you can enter commands in textual form. It is very useful to list the source code of the program via the list command. It is sufficient to enter just 1. By default always ten lines around the current position are printed.
