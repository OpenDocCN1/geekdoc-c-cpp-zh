This result appears as follows:

$$\sqrt[3]{\frac{a + \sqrt{b + c}}{\frac{1}{x} + \sin(x)}}$$

Binomials can be used in the following rather nonstandard² way:

```
\begin{equation*}
{ r \choose k-1}+ { r \choose k} = {r+1 \choose k}\,.
\end{equation*}
```

result in

$$\binom{r}{k-1} + \binom{r}{k} = \binom{r+1}{k}.$$

There exists also the command \atop which works in the same way but omits the brackets

```
\DeclareMathOperator!{\verb!\operator!}{\verb!\text!}
```
