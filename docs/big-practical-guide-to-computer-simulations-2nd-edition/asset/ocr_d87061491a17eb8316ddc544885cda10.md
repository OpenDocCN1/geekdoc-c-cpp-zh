```
struct node_struct
{
    int key;                 /* holds key */
    struct node_struct *left;  /* to left subtree (NULL: none) */
    struct node_struct *right; /* to right subtree (NULL: none) */
};

typedef struct node_struct node_t;  /* define new type for nodes */
```

We have defined a new data type node_t for convenience. For simplicity, only the key values are stored here. Other data belonging to an element, usually necessary for a real application, could be stored in other fields added to the structure. Note that if one wants to have trees of several types, e.g. one to store data of atoms and one to store data of full molecules (e.g. each containing a set of atoms), one would need to define two different tree node types.
