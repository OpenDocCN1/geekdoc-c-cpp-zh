So far, the values of q_i represent global probabilities for the outcomes b_i. To allow for drawing the random numbers as explained above, they have to be turned into conditional probabilities, representing only the relative fraction of outcome a_i in package i. Since each package represents an amount p_avg = 1/N, due to Eq. (8.5) all values of q_i have to be divided by p_avg, i.e., multiplied by N.
