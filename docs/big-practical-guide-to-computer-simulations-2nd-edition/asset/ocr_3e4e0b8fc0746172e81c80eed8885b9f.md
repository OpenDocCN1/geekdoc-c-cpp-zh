```
int generate_sphere(int dim, double *x, int surface)
{
    int num_trials;
    int d;                         /* loop counter */
    double magnitude;              /* square magnitude of vector */

    num_trials = 0;
    do
    {
        num_trials++;
        magnitude = 0;
        for(d=0; d<dim; d++)        /* generate point in [0,1]^dim */
        {
            x[d] = 2*drand48()-1.0;
            magnitude += x[d]*x[d];
        }
    } while(magnitude > 1.0);       /* until in unit sphere ? */

    magnitude = sqrt(magnitude);
    if(surface)
        for(d=0; d<dim; d++)        /* normalize point to length 1 */
            x[d] /= magnitude;
    return(num_trials);
}
```

The main loop lines 8–17 is performed until a point x̄ inside the hypersphere is obtained. Therein, the loop (lines 12–16) generates a uniformly distributed point inside the hypercube [−1,1]^d and calculates the length of the vector on the fly. In the final part (lines 19–22) the projection onto the surface of the hypersphere is performed in case the flag surface is set.
