\documentclass[12pt]{article}
\begin{document}
This is just a small sample text. You can write some words
\emph{emphasized}/, or in \textbf{bold face}. Also different

An empty line generates a new paragraph. \LaTeX\ is very convenient

The first line introduces the type of the text, here article, which is the standard, and the font size. You should note that all TeX commands begin with a backslash (\), in case you want to write a backslash in your text see Sec. 9.3.1.2. There are few exceptions like the dollar symbol '$' which switches the mathematical in-line mode on and off. Arguments to commands are given in { } braces, like the type of the \documentclass command, which should always be the first command in your file. Optional arguments are given in [ ] braces, such as the font size here (the default is 10pt). Note that the { } are also used to group words together.
