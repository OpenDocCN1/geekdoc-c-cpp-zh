just given without brackets in the <attribute list> form. Here we show an example which uses some attributes:

```
graph test2
{
node [shape=box]
0 [label=Milk, style=bold ]
Butter [shape=house,height=2, color=blue]
Cheese [fontname="Palatino-Italic"]
Wheat -- Sandwich
Cheese -- Butter Butter -- Cake [label = bakery]
Butter -- Sandwich [style = dashed]
Cheese -- Sandwich
}
```

Line 3 contains a global node attribute. Lines 4-6 contain node statements with some attributes. Note that the shape=house assignment overrides the global shape=box just for the node Butter. Lines 7-10 contain edge statements with some attributes. The resulting image made by dot is shown in Fig. 9.5.
