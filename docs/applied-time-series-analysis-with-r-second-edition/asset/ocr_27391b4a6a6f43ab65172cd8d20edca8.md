(i.i.d.), zero mean, unit variance random variables that are independent of the $a_{t-k}$, $k = 1, 2, ...$. Then $a_t$ is said to satisfy an ARCH(1) process.

Note that the unit variance of $\epsilon_t$ is required, so that

$$E[(\sigma_{t|t-1}\epsilon_t)^2 \mid a_{t-k},\,k=1,2,\dots] = \sigma_{t|t-1}^2 E[\epsilon_t^2 \mid a_{t-k},\,k=1,2,\dots] = \sigma_{t|t-1}^2 E[\epsilon_t^2] = \sigma_{t|t-1}^2 \tag{4.20}$$

It is also easily shown (see Shumway and Stoffer, 2010) that the $a_t$'s are uncorrelated with a conditional variance that depends on $t$. Note from Equation 4.19 that

$$a_t^2 - (\alpha_0 + \alpha_1 a_{t-1}^2) = \sigma_{t|t-1}^2 (\epsilon_t^2 - 1) \tag{4.21}$$

and thus that

$$a_t^2 = \alpha_0 + \alpha_1 a_{t-1}^2 + w_t \tag{4.22}$$

where $w_t = \sigma_{t|t-1}^2 (\epsilon_t^2 - 1)$ and $E[w_t]=0$. Thus, $a_t^2$ satisfies a non-Gaussian AR(1) process with

$$\sigma_a^2 = E[a_t^2] = \alpha_0 + \alpha_1 E[a_{t-1}^2] + E[w_t] = \alpha_0 + \alpha_1 \sigma_a^2$$

Therefore,

$$\sigma_a^2 = \frac{\alpha_0}{1 - \alpha_1}.$$
