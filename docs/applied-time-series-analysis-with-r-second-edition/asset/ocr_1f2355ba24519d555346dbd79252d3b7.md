Examination of Equation 3.17, however, does not immediately reveal the relationship between the AR(p) process and the general linear process. Actually, the specification of an AR(p) process as given by Equation 3.17 is inadequate since Equation 3.17 has many distinct solutions and, to this point, we have failed to specify which solution we wish to consider. For example, if X_t is a solution of Equation 3.17 and φ(B) y_t = 0, then X_t + c y_t is also a solution of Equation 3.17 for any constant c. Consequently, Equation 3.17 has an uncountable number of solutions. However, if c ≠ 0, then all of these solutions are nonstationary, and since for now our interest is in stationary solutions, we need to be more specific. This leads us to the following definition.

# Definition 3.2

Suppose {X_t : t = 0, ±1, ±2, ... } is a causal, stationary process satisfying the difference equation

$$\phi(B)(X_t - \mu) = a_t.$$ 
(3.19)

Then, X_t will be called an AR process of order p and denoted AR(p). Again, we will take μ = 0 unless indicated to the contrary.

To clarify Definition 3.2, consider the AR(1) model

$$\phi(B)X_t = (1 - \alpha B)X_t = a_t,$$
(3.20)

where |α| < 1. Noting that B α^{-t} = α^{-(t-1)}, then

$$ (1 - \alpha B)X_t = \alpha^t (1 - B) \alpha^{-t} X_t, $$

which can be shown by expanding each side to obtain X_t - α X_{t-1}. So the two operators 1 - αB and α^t (1 - B) α^{-t} are equivalent, that is,

$$ 1 - \alpha B \equiv \alpha^t (1 - B) \alpha^{-t}. $$
(3.21)

Therefore,

$$ \alpha^t (1 - B) \alpha^{-t} X_t = a_t. $$
