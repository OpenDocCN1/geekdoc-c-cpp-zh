
and

```
$$X_t = b_0 + A_1 \cos(2\pi f_0 t + A_2) + Z_t, \tag{6.61}$$
```

where $1 - \lambda_1 z + z^2 = 0$ has a pair of complex roots on the unit circle with the associated system frequency $f_0$, and where $Z_t$ is zero-mean white noise. We consider the case in which $f_0 = 1/12$ for both models, in which case realizations from these models will be cyclical with a period of about 12. The first 50 points in the four panels of Figure 6.11 illustrate a typical realization that might be observed from either model. The eventual forecast function from each model has the form

```
$$\hat{X}_{t_0}(\ell) = B_1 + B_2 \cos\left(\frac{2\pi \ell}{12} + B_3\right). \tag{6.62}$$
```

Forecasts using Equation 6.62 depend on a mean level, an amplitude ($B_2$), and a phase shift ($B_3$). From Equation 6.57, it is seen that eventual forecasts from Equation 6.61 are based on the signal, $s_t$, that is typically estimated from the data. That is, if Equation 6.61 is the assumed model, then the parameters $B_1$, $B_2$, and $B_3$ are estimated from the data by fitting a sinusoid to the $t_0$ values in the realization.

For comparison purposes, when forecasting from Equation 6.60 with $p = q = 0$ and $\lambda_1 = \sqrt{3}$ for which $f_0 = 1/12$, the constants $B_2$ and $B_3$, that is, the amplitude and phase, are determined by the last two observed data values, and are random variables. Figure 6.11a shows a realization of length $n = t_0 = 50$ from this ARUMA(0,2,0) model along with forecasts for the next 20 values using models in Equation 6.60 and Equation 6.61. Data values $x_{49} = -1.46$ and $x_{50} = -4.4$ are circled. In this case, the forecasts from each model are very similar and are visually difficult to distinguish from each other in Figure 6.11a. The extent to which the forecasts depend on the last two data values is not obvious in Figure 6.11a, and in order to illustrate this effect, in panels (b) through (d), we show forecasts from the two models resulting from changing $x_{50}$. In Figure 6.11b, we set $x_{50} = -10$, which results in forecasts with much larger amplitudes using Equation 6.60. The forecasts using Equation 6.61 are very similar to those in Figure 6.11a. That is, the changing of one data value did not have a substantial
effect on the fit of Equation 6.61 to the data. In Figure 6.11c, x₅₀ = 5 (>x₄₉), and forecasts based on Equation 6.60 use the information to predict that the sinusoidal behavior is “on the rise,” and consequently, X̂₅₀(1) > x₅₀. In essence, the phase shift is dramatically changed in Figure 6.11c compared to Figure 6.11a and b. Again, the fact that one data value has been altered does not have a dramatic effect on forecasts based on Equation 6.61. Finally, in Figure 6.11d, we set x₄₉ = x₅₀, and the forecasts using Equation 6.60 have much smaller amplitude and are based on an “interpretation” that the value at which the signal leveled out (i.e., −1.46) is the current minimum of the sinusoidal curve.

### b.

```
fore.aruma.wge(x,phi,theta,d,s,lambda,n.ahead,lastn,plot,limits)
```

This function forecasts n.ahead steps ahead using the Box–Jenkins forecasting approach for nonstationary ARUMA models that may have stationary ARMA components, factors such as (1 − B)^d, seasonal, and/or other nonstationary factors. The forecasts and forecast limits can optionally be plotted.

- x = realization
- phi is a vector of AR coefficients (default = 0)
- theta is a vector of MA coefficients (default = 0)
- d is the order of the difference operator, (1 − B)^d, in the model (default = 0)
- s is the seasonal order (default = 0)
- lambda is a vector containing the coefficients of the nonstationary not included in the difference or seasonal operators. (default = 0)
- n.ahead = the number of steps ahead you want to forecast (default = 2)
- lastn = logical variable. If lastn = FALSE (default) then the forecasts are for x(n + 1), x(n + 2), ..., x(n + n.ahead) where n is the length of the realization. If lastn = TRUE, then the program forecasts the last n.ahead values in the realization.
- plot = logical variable. If plot = TRUE (default) then the forecasts will be plotted along with the realization. If plot = FALSE then no
plots are output. (default = TRUE)
- limits = logical variable. If limits = TRUE then the 95% forecast limits will be plotted along with the forecasts.

**NOTE:** As was the case with the `fore.arma.wge` function, you can use either a “known” or a fitted model. The following example uses the “true” ARIMA(1,1,0) model in Equation 6.42 given in Example 6.4.

### *Example:*

```
data(fig6.6nf)
example = fore.arima.wge(fig6.6nf, phi = 8,d = 1,n.ahead = 20)
```

This code produces the plot in [Figure 6.6](#) along with the following output:

- `example$F` is a vector containing the forecasts
- `example$l1` is a vector containing the lower limits
- `example$u1` is a vector containing the upper limits
- `example$resid` is a vector containing the residuals
- `example$wnv` is the white noise variance estimate
- `example$se` is a vector containing the SE for each forecast
- `example$psi` is a vector containing the psi weights

### c. fore.sigplusnoise.wge(x,linear,freq,max.p,n.ahead,lastn,
   plot,limits)

This function forecasts n.ahead steps ahead for a signal + noise model of the form

$$X_t = b_0 + b_1t + Z_t,$$

or

$$X_t = A_0 + A_1\cos(2\pi f_0t + A_2) + Z_t.$$

Note that signals are restricted to linear or (single) sinusoidal types. As with other forecasts in this chapter we assume that the signal and the (autoregressive) noise model are known when assessing the forecast errors. The forecasts and forecast limits can optionally be plotted. You can calculate and plot forecasts n.ahead steps beyond the end of the series or you can forecast the last n.ahead data values. In the linear model above, all parameters are estimated including the order (p) and associated parameters of the AR(p) model fit to the residuals from the fitted line. In the cosine
model the user must specify f0. All other parameters are estimated.

- x = realization
- linear = logical variable. If linear = TRUE (default) then the forecasts will be based on the linear plus noise model above. If linear = FALSE then the cosine plus noise model is fit to the data.
- freq is the variable f0 that must be specified by the user (default is freq = 0).
- max.p is the maximum order autoregressive model to be fit (based on AIC) to the residuals.
- n.ahead = the number of steps ahead you want to forecast (default = 10)
- lastn = logical variable. If lastn = FALSE then the forecasts are for x(n + 1), x(n + 2), ..., x(n + n.ahead) where n is the length of the realization. If lastn = TRUE, then the program forecasts the last n.ahead values in the realization. (default = FALSE)
- plot = logical variable. If plot = TRUE then the forecasts will be plotted along with the realization. If plot = FALSE then no plots are output.
- (default = TRUE)
- limits = logical variable. If limits = TRUE then the 95% forecast limits will be plotted along with the forecasts. (default = TRUE)

Example: Suppose a realization of length n = 50 is generated from X_t = 10 + 4 cos(2πt / 12 + 2) + Z_t where (1 − .8B)Z_t = a_t and σ_a^2 = 1 using the function gen.sigplusnoise.wge described in Appendix 1.B. ```
