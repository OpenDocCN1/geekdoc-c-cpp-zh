# EXAMPLE 13.14: SAMPLING SCHEME FOR AN SLC PROCESS

Let X(t) = cos(2πt² + ψ) where ψ ~ Uniform[0, 2π], and let t ∈ [−2, 2] with Δ_t = 0.05. Then, as defined earlier, t_(0) = −2, t_(1) = 2, a = 1, and b = 0, and consequently −b/(2a) = 0. Taking u = g(t) = t², then from Equation 13.26, if t_k ∈ [t_(0), −b/(2a)] = [−2, 0] then u ∈ [0, 4]. For this example we let t_k = −√u_k where u_k = |k| Δ_u, k = −40, −39, …, −2, −1, 0, and Δ_u = 0.1. Also, if t_k ∈ (−b/(2a), t_(1)) = (0, 2], then u ∈ (0, 4] and t_k = √u_k, where u_k = |k| Δ_u, k = 1, 2, …, 39, 40, and Δ_u = 0.1. We note that Δ_u = 0.1 was selected to ensure that the number of data values in the dual realization is the same as the number of data values in the original realization.

A realization of X(t), where ψ = 0, is shown in Figure 13.16a which shows the plot of 81 equally spaced sampling points t between −2 and 2. Examining the plot shows that the sampling rate per cycle is lower in the regions of the data where the frequency is high. Conversely, the sampling rate per cycle is higher where the frequency is low, which is clearly undesirable. As evidenced by the tick marks in Figure 13.16b, this sampling strategy strategically defines t_k so that there are the same number of observations per cycle, and proceeds across the reflection point without interruption. Finally, Figure 13.16c shows a plot of the data in Figure 13.16b indexed on k. This is the dual process, and it can be seen that the frequencies are fixed.
