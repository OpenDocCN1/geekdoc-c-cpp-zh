## Appendix 5A: R Commands

### 5A.1 Basic Computation and Plot Routines

- a. `gen.arima.wge(n, phi, theta, d, lambda, vara, sn)` is a function that generates a realization of length `n` from a given AR, MA, ARMA, or ARIMA model.

  - `n` is the realization length
  - `phi` is a vector of AR parameters (of the stationary part of the model) (default = 0)
  - `theta` is a vector of MA parameters (using signs as in this text) (default = 0)
  - `d` specifies the number of factors of $(1 - B)$ in the model. For stationary models, you could use either `gen.arma.wge` or use `gen.arima.wge` with `d = 0`.
  - `vara` is the white noise variance (default = 1)
  - `plot = TRUE` (default) produces a plot of the realization generated
  - `sn` determines the seed used in the simulation (see Note 4 below).

**Notes:**

1. It will be useful to call the utility function `mult.res` if you know the factors of the model instead of the coefficients.
2. By default the white noise is zero mean, normal noise with variance `vara`.
3. This function uses a call to the base R function `arima.sim`, which uses the same signs as this text for the AR parameters but opposite signs for MA parameters. The appropriate adjustments are made within `gen.arima.wge` so that input vectors `phi` and `theta` for `gen.arima.wge` should contain parameters using the signs as in this text. However, if you use `arima.sim` directly (which has options not employed in `gen.arima.wge`), then you must remember that the signs needed for the MA parameters have opposite signs from those in `gen.arima.wge`.
4. `sn = 0` (default) produces results based on a randomly selected seed. If you want to reproduce the same realization on subsequent runs of `gen.arima.wge`, then set `sn` to the same positive integer value on each run.

Example: The command

```r
x = gen.arima.wge(n = 200, phi = c(1.6, -.9), theta = .9, d = 2, vara = 1)
```

generates and plots a realization from the model $(1 - 1.6B + 0.9B^2)(1 - B)^2X_t = (1 - 0.9B)a_t$ and stores it in the vector `x$data`. The white noise was normally distributed with mean zero and variance 1 and a random seed is used.

- b. `gen.aruma.wge(n, phi, theta, d, s, lambda, vara, sn)` is a function that generates a realization of length `n` from a given AR, MA, ARMA, ARIMA, ARUMA, or seasonal model.

  - `n` is the realization length
  - `phi` (default = 0) is a vector of AR parameters
  - `theta` (default = 0) is a vector of MA parameters (using signs as in this text)
  - `d` (default = 0) specifies the number of factors of $(1 - B)$ in the model
  - `s` (default = 0) specifies the order of the seasonal factor $(1 - B^s)$
  - `lambda` (default = 0) is the nonstationary operator, $\lambda(B)$, in Equation 5.8 of this text (technically designed to contain nonstationary factors other than differences and seasonal factors). However, see Note 1 below for discussion regarding difference and seasonal factors.
  - `vara` is the white noise variance (default = 1)
  - `plot = TRUE` (default) produces a plot of the realization generated
  - `sn` determines the seed used in the simulation (default = 0) (see Note 5 below).

**Notes:**

1. `gen.aruma.wge` is the most general function. For example, consider the model

$$\phi(B)(1 - B)(1 - B^{12})X_t = \theta(B)a_t,$$

where

$$\phi(B) = 1 + 0.05B - 0.07B^2 + 0.11B^3 + 0.04B^4 - 0.08B^5 - 0.07B^6 + 0.04B^7 - 0.04B^8 - 0.14B^9 + 0.05B^{10} + 0.12B^{11} + 0.40B^{12}$$

and

$$\theta(B) = 1 - 0.42B.$$

This model is given in Equation 8.29 in this text and was proposed by Gray and Woodward (1981) for modeling the airline data. To generate a realization of length $n = 144$ from this model using `gen.aruma.wge`, use the following snippet of R code:

```r
phi12 = c(-0.05, 0.07, -0.11, -0.04, 0.08, 0.07, -0.04, 0.04, 0.14, -0.05, -0.12, -0.40)
theta1 = 0.42
d = 1
s = 12
x = gen.aruma.wge(n = 144, phi = phi12, theta = theta1, d = 1, s = 12)
```
