### 3.1.2 MA(2) Model

Let $X_t$ denote the MA(2) model given by

$$X_t = a_t - \theta_1 a_{t-1} - \theta_2 a_{t-2}.$$

For this model, it follows that

$$\gamma_0 = \sigma_a^2(1 + \theta_1^2 + \theta_2^2) = \sigma_X^2.$$

$$\rho_1=\frac{-\theta_1+\theta_1\theta_2}{1+\theta_1^2+\theta_2^2}$$

$$\rho_2=\frac{-\theta_2}{1+\theta_1^2+\theta_2^2}$$

$$\rho_k=0,\qquad k\geq 3.$$

Using [Equation 3.6], the spectral density of the MA(2) process is given by

$$S_X(f)=\frac{\sigma_a^2}{\sigma_X^2}\left\{1+\theta_1^2+\theta_2^2-2\theta_1(1-\theta_2)\cos 2\pi f-2\theta_2\cos 4\pi f\right\}.$$

**Using R:** The `tswge` function `gen.arma.wge` can be used to generate and plot a realization from an MA model, while `true.arma.aut.wge` and `true.arma.spec.wge` calculate and plot the true autocorrelations and spectral densities for an MA model, respectively. Additionally, the `tswge` function `plotts.wge` can be used to generate a realization, calculate the true autocorrelations and spectral density, and create a plot similar to [Figure 3.11] in this text. Be careful with the coefficients. That is, for the MA(2) model $X_t=a_t-1.1a_{t-1}+0.6a_{t-2}$ the coefficients $\theta_1$ and $\theta_2$ are 1.1, and −0.6, respectively. These tswge functions can also be used for AR and ARMA models which will be discussed in the following. See [Appendix 3B] for more details.

## 3.2 AR Processes

Let $a_t$ be a white noise process and let $\phi_1,\ \phi_2,\ \ldots,\ \phi_p$ be real constants with $\phi_p\neq 0$. Then, loosely speaking, if $X_t$, $t=0,\ \pm1,\ \pm2,\ \ldots$ is specified by

$$X_t-\mu-\phi_1(X_{t-1}-\mu)-\phi_2(X_{t-2}-\mu)-\cdots-\phi_p(X_{t-p}-\mu)=a_t,\tag{3.13}$$

then $X_t$ is called an $AR$ process of order $p$, which is usually shortened to $AR(p)$. We will often write [Equation 3.13] in the operator form

$$\phi(B)(X_t-\mu)=a_t,\tag{3.14}$$

where

Examination of Equation 3.17, however, does not immediately reveal the relationship between the AR(p) process and the general linear process. Actually, the specification of an AR(p) process as given by Equation 3.17 is inadequate since Equation 3.17 has many distinct solutions and, to this point, we have failed to specify which solution we wish to consider. For example, if X_t is a solution of Equation 3.17 and φ(B) y_t = 0, then X_t + c y_t is also a solution of Equation 3.17 for any constant c. Consequently, Equation 3.17 has an uncountable number of solutions. However, if c ≠ 0, then all of these solutions are nonstationary, and since for now our interest is in stationary solutions, we need to be more specific. This leads us to the following definition.

**Definition 3.2**

Suppose {X_t : t = 0, ±1, ±2, ... } is a causal, stationary process satisfying the difference equation

$$\phi(B)(X_t - \mu) = a_t.$$ 
(3.19)

Then, X_t will be called an AR process of order p and denoted AR(p). Again, we will take μ = 0 unless indicated to the contrary.

To clarify Definition 3.2, consider the AR(1) model

$$\phi(B)X_t = (1 - \alpha B)X_t = a_t,$$
(3.20)

where |α| < 1. Noting that B α^{-t} = α^{-(t-1)}, then

$$(1 - \alpha B)X_t = \alpha^t (1 - B) \alpha^{-t} X_t,$$

which can be shown by expanding each side to obtain X_t - α X_{t-1}. So the two operators 1 - αB and α^t (1 - B) α^{-t} are equivalent, that is,

$$1 - \alpha B \equiv \alpha^t (1 - B) \alpha^{-t}. $$
(3.21)

Therefore,

$$\alpha^t (1 - B) \alpha^{-t} X_t = a_t.$$

So

$$(1 - B)\alpha^{-t} X_t = \alpha^{-t} a_t,$$

and

$$\sum_{k=-\infty}^{t} (1 - B)\alpha^{-k} X_k = \sum_{k=-\infty}^{t} \alpha^{-k} a_k,$$

which gives

$$\alpha^{-t} X_t - \lim_{j\to\infty} \alpha^{-j} X_j = \sum_{k=-\infty}^{t} \alpha^{-k} a_k.$$  (3.22)

Since $|\alpha| < 1$, it follows that $\lim_{j\to\infty} \alpha^{-j} X_j = 0$ with probability 1. Consequently,

$$X_t = \sum_{k=-\infty}^{t} \alpha^{t-k} a_k$$  (3.23)
$$= \sum_{h=0}^{\infty} \alpha^{h} a_{t-h}.$$

Clearly, $X_t$ in Equation 3.23 satisfies (3.20), is causal, and, by Theorem 2.3, is stationary since $|\alpha| < 1$ implies $\sum_{h=0}^{\infty} |\alpha|^{h} < \infty$. Therefore, $X_t$ is a (causal and stationary) AR(1) process. Because the polynomial operator $\phi(B)$ can always be factored as

$$X_t - \phi_1 X_{t-1} - \cdots - \phi_p X_{t-p} = \phi(B) X_t = (1 - \alpha_1 B)(1 - \alpha_2 B) \cdots (1 - \alpha_p B) X_t = \prod_{k=1}^{p} \alpha_k (1 - B \alpha_k^{-1}) X_t,$$  (3.24)

where the $\alpha_k$ may be real or complex, the following theorem can be shown.

**Theorem 3.1**

Let $X_t$ be causal and suppose

$$\phi(B) X_t = (1 - \alpha_1 B)(1 - \alpha_2 B) \cdots (1 - \alpha_p B) X_t = a_t,$$  (3.25)

where the $\alpha_k$ are real or complex numbers, $\alpha_k \neq \alpha_j$, $k \neq j$, $|\alpha_k| < 1$, $k = 1, \dots, p$, and $a_t$ is zero mean white noise. Then, $X_t$ is an AR$(p)$ process and

$$X_t = \sum_{\ell=0}^{\infty} \psi_{\ell}(p) a_{t-\ell}, \tag{3.26}$$

where

- a. $\psi_{\ell}(1) = \alpha_1^{\ell}$ for $p = 1$  (3.27)
- b. $\psi_{\ell}(p) = \displaystyle\sum_{k=1}^{p-1} \frac{\alpha_p^{p-2} (\alpha_p^{+1} - \alpha_{p-k}^{+1})}{(\alpha_p - \alpha_{p-k}) \prod_{h \neq p-k}^{p-1} (\alpha_{p-k} - \alpha_h)}$, for $p \ge 2$.

Proof: See Appendix 3A.

We note that Theorem 3.1 gives the $\psi$-weights for the case of no repeated roots. Problem 3.33 shows how Equation 3.27 can be used in the case of a repeated root. The constants $\psi_{\ell}(p)$ will be referred to as the “$\psi$-weights” for an AR$(p)$ process. Definition 3.3 introduces the characteristic equation, which is a useful tool in the analysis of AR$(p)$ models.

**Definition 3.3**

If $X_t$ is the AR$(p)$ process defined by Equation 3.17, then the algebraic equation $\phi(z) = 0$ is called the associated characteristic equation where

$$\phi(z) = 1 - \phi_1 z - \dots - \phi_p z^p,$$

and $z$ is a real or complex number. The polynomial $\phi(z)$ is called the characteristic polynomial.

Theorem 3.2 that follows is an important result for determining whether a given set of AR$(p)$ coefficients yield a causal, stationary AR$(p)$ process.

**Theorem 3.2**

The process $X_t$ with $\psi$ weights as defined in Theorem 3.1 is a stationary and causal AR($p$) process if and only if the roots of the characteristic equation $\phi(z)=0$ all lie outside the unit circle.

*Proof:* See [Appendix 3A](#).

Thus, $X_t$ in Equation 3.25 is an AR($p$) process if and only if $|\alpha_k|<1$, $k=1,\ldots,p$, since $\alpha_k$ is the reciprocal of the $k$th root of the characteristic equation. From Equation 3.26, it is also clear that in this case, $X_t$ is a general linear process.

### 3.2.1 Inverting the Operator

It is worth noting that properties of $\phi(B)$ can be found by examining the algebraic counterpart, $\phi(z)$, when $z$ is real or complex. That is, it can be shown (see Brockwell and Davis, 1991) that for

$$\phi(z)=1-\phi_1z-\cdots-\phi_pz^p$$
$$=\prod_{k=1}^{p}(1-\alpha_kz),$$

where $|\alpha_k|<1$, $k=1,\ldots,p$, that $\phi^{-1}(B)=\left.\phi^{-1}(z)\right|_{B}$. Thus, for example, if $(1-\phi_1B)X_t=a_t$ and $|\phi_1|<1$, then since $(1-\phi_1z)^{-1}=\sum_{k=0}^{\infty}\phi_1^kz^k$, it follows that

$$X_t=(1-\phi_1B)^{-1}a_t$$
$$=\sum_{k=0}^{\infty}\phi_1^kB^ka_t$$
$$=\sum_{k=0}^{\infty}\phi_1^ka_{t-k}$$

In this book, we will often use this formal procedure for inverting operators because of its ease of use. Note that the proof of Theorem 3.1 is actually based on the use of φ(B) as an operator.

### 3.2.2 AR(1) Model

We first consider the properties of the AR(1) model given by

$$X_t - \phi_1 X_{t-1} = a_t,\qquad (3.28)$$

where $|\phi_1| < 1.$

- 1. *ψ-weights and stationarity conditions for an AR(1)*: From Equation 3.27, we see that the general linear process form of an AR(1) process is

$$X_t = \sum_{k=0}^{\infty} \phi_1^k a_{t-k}.$$ 

That is, the ψ-weights are $\psi_k(1)=\phi_1^k$. The characteristic equation is given by $1 - \phi_1 r = 0$, which has root $r_1 = \phi_1^{-1}$ where $|r_1| = |\phi_1^{-1}| > 1$ since $|\phi_1| < 1$, from which it follows that the model in Equation 3.28 is in fact stationary and causal. Note that we also obtained the ψ-weights of an AR(1) model in the preceding discussion about inverting the operator.

- 2. *Autocorrelations of an AR(1) process*: In order to find $\gamma_k$ and $\rho_k$ for an AR(1) process, it is necessary to evaluate the expectation $E[X_t X_{t+k}] = E[X_{t-k} X_t]$. To obtain $\gamma_k$, multiply both sides of the equality in Equation 3.28 by $X_{t-k}$, where $k > 0$, to yield

$$X_{t-k}\{X_t = \phi_1 X_{t-1} + a_t\}.$$ 

Taking the expectation of both sides we obtain

$$E[X_{t-k} X_t] = \phi_1 E[X_{t-k} X_{t-1}] + E[X_{t-k} a_t].\qquad (3.29)$$
