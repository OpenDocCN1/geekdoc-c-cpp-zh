In this example, we illustrate the concepts of predicting, filtering, and smoothing using the data in Figure 10.11. In Example 10.9, it was seen that the series X_t is from an AR(1) model while the observations Y_t follow an AR(1)-plus-noise model. We will use Equations 10.50 through 10.54 to find the predictions, \hat{X}_t^{t-1}, and filters, \hat{X}_t^{t}, (along with the corresponding mean-squared errors) for the underlying signal, X_t. These predictions and filters are based on the observed signal, Y_t, and using the model parameters F = φ1 = 0.9, Γ_V = σ_V^2 = 1, G_t = 1 and Γ_W = σ_W^2 = 0.75. After the predictions and filters are computed for t = 1, ..., n, we use the smoothing Equations 10.55 through 10.57 to calculate the smoothers, \hat{X}_t^n, along with the corresponding mean-squared errors.
