
So, the GIF is the reciprocal, which is

$$ \text{GIF} = \frac{1}{2\pi t^{-\lambda+1} + \frac12(1-\lambda)(2\pi)^2 t^{-2\lambda+1}+ \dots}
= \frac{t^{\lambda-1}}{2\pi}\Big[\frac{1}{1+\pi(1-\lambda)t^{-\lambda}+ \dots}\Big].$$

Thus, for large $t$,

$$\text{GIF} \simeq \frac{t^{\lambda-1}}{2\pi} = \frac{g'(t)}{2\pi} = \text{IF}.$$

Jiang et al. (2006) show that the results of Example 13A.1 can be generalized to any analytic monotonically increasing function $g(t)$. That is, if $H(t)=A\cos[g(t)]$, and $g(t)$ is monotonically increasing, then $\delta=2\pi$ and $\mathcal{P}(t; g, 2\pi)=g^{-1}(g(t)+2\pi)-t$. They also show that the IF is a first-term Taylor series approximation to the GIF.

## 13A.2 Instantaneous Spectrum of a G(λ) Process

Since in many signals the entire frequency structure is evolving with time, the concept of an instantaneous spectrum of a $G(\lambda)$ process is needed. In this regard, let $f^* = 1/\delta$, and let $G_X(f^*; \lambda)$ denote the $G(\lambda)$ spectral density. For example, in the case of a $G(p; \lambda)$ model, the $G(\lambda)$ spectral density is the AR$(p)$ spectral density associated with the AR$(p)$ model fit to the dual. From Definition 13A.2 and Equation 13A.2, it is clear that $f^*$ is a function of $f$ (= GIF) and $t$. That is, from Equation 13A.2

$$f^* = 0, \quad \text{if } f = 0, \tag{13A.3}
= [\ln(1+1/(t f))]^{-1}, \quad \text{if } f \neq 0, \ \lambda = 0,
= \frac{\lambda}{(t+1/f)^{\lambda} - t^{\lambda}}, \quad \text{if } f \neq 0, \ \lambda \neq 0.$$

We can, therefore, capture the instantaneous frequencies through $f^*$ defined in Equation 13A.3. Note that since $G_X(f^*; \lambda)=G_X(-f^*; \lambda)$ we will always take $f^* \ge 0$ and $f \ge 0$.

### Definition 13A.3

If $X(t)$ is a $G(\lambda)$ process and $G_X(f^*;\lambda)$ is its $G(\lambda)$-spectrum, then the instantaneous spectrum of $X(t)$ at time $t$, denoted $S(f,t;\lambda)$, is defined as

$$S(f,t;\lambda)=G_X(f^*;\lambda). \tag{13A.4}$$

### Theorem 13A.1

If $X(t)$ is a $G(p,q;\lambda)$ process, then the instantaneous spectrum of $X(t)$ at time $t$ is given by

$$S(f,t;\lambda)=\sigma_a^2\frac{\prod_{j=1}^{q}|\beta_j-i2\pi f^*|^2}{\prod_{k=1}^{p}|\alpha_k-i2\pi f^*|^2}. \tag{13A.5}$$

where $f^*$ is given by Equation 13A.3.

*Proof:* Follows from Equation 13A.4.

## 13A.3 GIF and Instantaneous Spectrum of a GLC(p) Process

In the case of the GLC(p) process, the GIF is given by

$$f_t=\frac{2a}{(2at+b)\left(-1\pm\sqrt{\frac{1+8at}{(2at+b)^2}}\right)}. \tag{13A.6}$$

where the $+$ and $-$ relate to frequencies to the right and left of the reflection point, respectively. Corresponding to Equations 13A.3 and 13A.4, it follows that the instantaneous spectrum, $S(f_t,t;a,b)$, is given by $S(f_t,t;a,b)=G(f^*;a,b)$, where $G(f^*;a,b)$ is the spectrum of the dual and

$$f^*=\frac{f_t^2}{(2at+b)f_t+a}. \tag{13A.7}$$

See Robertson et al. (2010) and Jiang et al. (2006).

## Appendix 13B: R Commands

Several tswge functions are available for performing analysis of TVF data. The functions are particularly focused on the use of G(λ; p) models to analyze TVF data.

- **a.** `gen.glambda.wge(n, lambda, phi, offset, vara, plot, sn)` is a function that generates a realization of length n from a given G(λ; p) model.

  `n` is the realization length (xt, t = 1, ..., n), that is, it is evaluated at equally spaced points 1, ..., n.

  **NOTE:** The generated model is based on zero mean. If xt is the time series generated by `gen.glambda.wge`, then to convert this to a time series with mean μ = 10, simply compute yt = xt + 10

  - `lambda` is the value of λ in the model (default is lambda = 0, i.e. an M-stationary model)
  - `phi` is a vector of AR parameters (default is phi = 0)
  - `offset` is the offset parameter (see for example the discussion about Figure 13.2) (default = 60)
  - `vara` is the white noise variance (default = 1)
  - `plot = TRUE` (default) produces a plot of the realization generated
  - `sn` determines the seed used in the simulation. (see Note (5) below.)

  **NOTES:**

  - 1. This function finds p as the length of phi. If phi = 0 (default) the value for p is set to zero.
  - 2. `gen.glambda.wge` calls the tswge function `gen.arma.wge` which in turn calls the base R function `arima.sim`.
  - 3. It will be useful to call the utility function `mult.wge` if you know the factors of the AR model instead of the coefficients.
  - 4. By default the white noise is zero mean, normal noise with variance vara = 1
  - 5. sn = 0 (default) produces results based on a randomly selected seed. If you want to reproduce the same realization on subsequent runs of `gen.glambda.wge` then set sn to the same positive integer value on each run.

  **Example:** The command

  ```
  x = gen.glambda.wge(n = 500, lambda = 0.5, phi = c(1.9, -.99), offset = 25, vara = 1)
  ```

  generates and plots a realization from the model used to generate the realization in Figure 13.6b. Since the seed is randomly selected, the realization generated here will not match Figure 13.6b exactly, but it will have the same decreasing frequency TVF characteristics.

- **b.** `est.glambda.wge(x, lambda.range, offset.range)` estimates the λ and offset (within specified ranges) that produce the “most stationary” dual.

  `x` is an equally spaced TVF data set

  `lambda.range` is a 2-component vector specifying the lowest and highest values of λ to be considered.

  `offset.range` is a 2-component vector specifying the lowest and highest values of offset to be considered.

  **Example:** The commands to find the values of λ and offset that create the dual data set in Figure 13.4b are

  ```
  data(fig13.2c)
  est.glambda.wge(fig13.2c, lambda.range = c(-.5, .5), offset.range = c(0, 100))
  ```

  **NOTE:** The top values of lambda and offset that were returned are lambda = -0.4 and offset 63. See Example 13.7.

- **c.** `trans.to.dual.wge(x, lambda, offset, plot)` transforms the time axis to create a dual process using linear interpolation.

  `x` is an equally spaced TVF data set

  `lambda` is the value of λ in the G(λ; p) model (default is lambda = 0, i.e., x is a realization from an M-stationary model)

  `offset` is the offset parameter (see for example the discussion about Figure 13.2) (default = 60)

  `plot = TRUE` (default) produces a plot of the dual realization created

  The function outputs:

  `intX` and `intY`: The input realization x is of length n, and the values of x are available at the time points t = 1, ..., n. The values intY are n interpolated values of the original time series at the n values of intX in the original time scale. The dual data set is obtained by associating the n values of intY with t = 1, ..., n respectively.

  `h` is an output value of the scaling parameter that assures that the dual realization and the original realization are of the same length.

  **NOTE:** `trans.to.dual` is based on G(λ)-stationary modeling. M-stationary models are obtained by using λ = 0.

  *Example:* The command

  ```
  data(fig13.2c)
  y = trans.to.dual.wge(fig13.2c, lambda = -0.4, offset = 63)
  ```

  computes and in this case plots the dual data shown in Figure 13.4b and saves the dual data in y$intY using the G(λ) time transformation specified by lambda and offset, which in this case were obtained in Example 13.7.

- **d.** `trans.to.original.wge(xd, lambda, offset, h, plot)` transforms a dual data set in transformed time back to the original time scale.

  The values of lambda and offset are those used in the function `trans.to.dual.wge` used previously to transform the time axis, and the value of h is obtained as output from the function `trans.to.dual.wge`.

  - `xd` is the equally spaced dual data set in the transformed time specified by the G(λ) time used in `trans.to.dual`
  - `lambda` is the value of lambda in the G(λ) transformation used to create the dual
  - `offset` is the value of offset in the G(λ) transformation used to create the dual
  - `h` is a scaling parameter (obtained as output from `trans.to.dual`) designed to assure that the dual realization and the original realization are of the same length
  - `plot = TRUE` (default) produces a plot of the dual realization created

  The function outputs (and optionally plots) `reintY` which are the Y values to be plotted against t = 1, ..., n that approximate the original TVF realization.

  *Example:* The G-filtering code used to create the dual, low-pass filtered dual, and associated filtered data in the original time space discussed in Section 13.5 are as follows (using the true values lambda = 0 and offset = 175).

  ```
  data(fig13.18a)
  dual = trans.to.dual.wge(fig13.18a, lambda = 0, offset = 175)
  ```
