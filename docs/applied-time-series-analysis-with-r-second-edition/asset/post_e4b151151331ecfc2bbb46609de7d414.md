## 10A.2 Derivation of the Fact That xₜ⁽ʲ⁾ in Equation 10.65 Is a Realization from an ARMA(2,1) Model

We want to show that the real sequence xₜ⁽ʲ⁾ = ψₜⱼ + ψₜⱼ* as defined in Equation 10.65 is a realization from an ARMA(2,1) model and is in fact the additive component corresponding to the quadratic factor 1 − α₁z − α₂z² of the characteristic polynomial associated with the pair of complex conjugate roots, rⱼ and rⱼ₊₁ = rⱼ*. In the following, it is assumed that the component xₜ⁽ʲ⁾ is obtained by adding the jth and (j + 1)st rows of U⁻¹ and multiplying the resulting p real coefficients by Xₜ.

First, we define

xₜ⁽ʲ⁾ = ( xₜ₋₁⁽ʲ⁾ ; xₜ⁽ʲ⁾ ) = ( ψₜ₋₁,ⱼ + ψₜ₋₁,ⱼ* ; ψₜⱼ + ψₜⱼ* )  (10A.4)

and note from Equation 10.63 that ψₜⱼ and ψₜⱼ* are both complex-valued AR(1) realizations, that is,

ψₜⱼ = 1/rⱼ · ψₜ₋₁,ⱼ + cⱼaₜ

ψₜⱼ* = 1/rⱼ* · ψₜ₋₁,ⱼ* + cⱼ*aₜ  (10A.5)

where $c_j$ and $c_j^*$ are the last values in the $j$th row and $(j+1)$st row, respectively, of $U^{-1}$. From Equations 10A.4 and 10A.5,

$$\begin{aligned} x_t^{(j)}&=\begin{pmatrix}\psi_{t-1,j}+\psi^*_{t-1,j}\\\psi_{tj}+\psi^*_{tj}\end{pmatrix}\\ &=\begin{pmatrix}\psi_{t-1,j}+\psi^*_{t-1,j}\\\frac{1}{r_j}\psi_{t-1,j}+\frac{1}{r_j^*}\psi^*_{t-1,j}+(c_j+c_j^*)a_t\end{pmatrix}\\ &=\begin{pmatrix}1&1\\\frac{1}{r_j}&\frac{1}{r_j^*}\end{pmatrix}\psi_{t-1,j}+\begin{pmatrix}0\\1\end{pmatrix}ca_t\\ &=C\psi_{t-1,j}+\begin{pmatrix}0\\1\end{pmatrix}ca_t. \end{aligned}$$

where

$$C=\begin{pmatrix}1&1\\\frac{1}{r_j}&\frac{1}{r_j^*}\end{pmatrix},$$

$$\psi_{t-1,j}=\begin{pmatrix}\psi_{t-1,j}\\\psi^*_{t-1,j}\end{pmatrix},$$

and $c=c_j+c_j^*$. Thus, if

$$D_j=\begin{pmatrix}\frac{1}{r_j}&0\\0&\frac{1}{r_j^*}\end{pmatrix},$$

then $CD_jC^{-1}=\Phi_j$ where

$$\Phi_j=\begin{pmatrix}0&1\\\alpha_{2j}&\alpha_{1j}\end{pmatrix}.$$

and 1 − α₁ⱼz − α₂ⱼz² is the irreducible second-order factor of φ(z) = 0 associated with the roots rⱼ and rⱼ*. Specifically, using Equations 3.57 and 3.58, it can be seen that α₁ⱼ = (1 / rⱼ) + (1 / rⱼ*) and α₂ⱼ = −1 / rⱼ rⱼ*. That is, Φⱼ is a 2 × 2 matrix of the same form as Φ. Also, note that ψₜ₋₁,ⱼ can be written in terms of xₜ⁽ʲ⁾ and aₜ as

ψₜ₋₁,ⱼ = C⁻¹( xₜ⁽ʲ⁾ − (0 \ 1) c aₜ )
ψₜ₋₂,ⱼ = C⁻¹( xₜ₋₁⁽ʲ⁾ − (0 \ 1) c aₜ₋₁ ).
(10A.6)

Taking the relevant portion of the new state equation in Equation 10.63, it follows that

ψₜⱼ = Dⱼ ψₜ₋₁,ⱼ + (cⱼ \ cⱼ*) aₜ
ψₜ₋₁,ⱼ = Dⱼ ψₜ₋₂,ⱼ + (cⱼ \ cⱼ*) aₜ₋₁.
(10A.7)

Substituting Equation 10A.6 into Equation 10A.7, we obtain

C⁻¹( xₜ⁽ʲ⁾ − (0 \ 1) c aₜ ) = Dⱼ C⁻¹( xₜ₋₁⁽ʲ⁾ − (0 \ 1) c aₜ₋₁ ) + (cⱼ \ cⱼ*) aₜ₋₁,
 xₜ⁽ʲ⁾ − (0 \ 1) c aₜ = C Dⱼ C⁻¹( xₜ₋₁⁽ʲ⁾ − (0 \ 1) c aₜ₋₁ ) + C (cⱼ \ cⱼ*) aₜ₋₁,
 xₜ⁽ʲ⁾ − (0 \ 1) c aₜ = Φⱼ xₜ₋₁⁽ʲ⁾ − c Φⱼ (0 \ 1) aₜ₋₁ + ( cⱼ + cⱼ* \ cⱼ / rⱼ + cⱼ* / rⱼ* ) aₜ₋₁.

That is,

xₜ⁽ʲ⁾ − Φⱼ xₜ₋₁⁽ʲ⁾ + (0 \ 1) c aₜ + Θ aₜ₋₁,

where

$$\begin{aligned}
\Theta &= -c\Phi_j\begin{pmatrix}0\\1\end{pmatrix}+\begin{pmatrix}c_j+c_j^*\\\dfrac{c_j}{r_j}+\dfrac{c_j^*}{r_j^*}\end{pmatrix}\\
&=\begin{pmatrix}c\\-c\alpha_{1j}\end{pmatrix}+\begin{pmatrix}c_j+c_j^*\\\dfrac{c_j}{r_j}+\dfrac{c_j^*}{r_j^*}\end{pmatrix}\\
&=\begin{pmatrix}-c\\-c\left(\dfrac{1}{r_j}+\dfrac{1}{r_j^*}\right)\end{pmatrix}+\begin{pmatrix}c_j+c_j^*\\\dfrac{c_j}{r_j}+\dfrac{c_j^*}{r_j^*}\end{pmatrix}\\
&=\begin{pmatrix}0\\-\dfrac{c_j}{r_j}-\dfrac{c_j^*}{r_j^*}\end{pmatrix}.
\end{aligned}$$

Thus, $x_t^{(j)}$ is a realization from an ARMA(2,1) process.
