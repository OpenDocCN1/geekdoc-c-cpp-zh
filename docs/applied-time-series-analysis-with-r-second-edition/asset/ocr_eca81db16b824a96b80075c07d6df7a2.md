In Example 1.3, it was shown that Y_t is stationary with E[Y_t]=0, variance σ_Y^2 = A_1^2 / 2, and autocovariance function

γ_k = \frac{A_1^2}{2} \cos 2π f_1 k, \tag{4.6}

from which it immediately follows that

ρ_k = \cos 2π f_1 k. \tag{4.7}

Unlike the autocorrelation function for an ARMA(p,q) process, ρ_k in Equation 4.7 does not damp, and, in fact, |ρ_k| = 1 if 2 f_1 k is an integer. In the discrete parameter case, the spectrum defined in Equation 1.25 is given by

P_Y(f) = \sum_{k=-\infty}^{\infty} e^{-2π i f k} \frac{A_1^2}{2} \cos 2π f_1 k, \tag{4.8}

which does not converge. In order to calculate the spectrum in this case, it is necessary to use the spectral distribution function (see Brockwell and Davis, 1991). We will not cover this topic here, except to note that using this approach, the spectrum can be shown to be

P_Y(f) = \frac{A_1^2}{2} \left( \frac{Δ(f - f_1) + Δ(f + f_1)}{2} \right)

and hence

S_Y(f) = \frac{Δ(f - f_1) + Δ(f + f_1)}{2}, \tag{4.9}

where Δ(x) is the Kronecker delta function given by

Δ(x) = 1, \quad x = 0
      = 0, \quad x ≠ 0
