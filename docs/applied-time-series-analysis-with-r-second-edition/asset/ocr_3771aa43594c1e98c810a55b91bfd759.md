# 13.4 Linear Chirp Processes

Linear chirp processes have wide applications in fields such as sonar, radar, and optics. Linear chirp processes are so named because they have frequency behavior that changes linearly with time. The data in Figure 12.2a are from a linear chirp process, and the time–frequency plots in Figure 12.4 illustrate the linear change in frequency. In this section, we make use of the fact that linear chirp processes are G-stationary processes with $g(t) = at^2 + bt + c$. Without loss of generality, we take $c = 0$. Then $u = at^2 + bt = g(t)$. So, for $at^2 + bt - u = 0$, it follows that

$$t = \frac{-b \pm \sqrt{b^2 + 4au}}{2a} = g^{-1}(u)$$

and

$$g^{-1}(g(t) + g(\tau)) = \frac{-b \pm \sqrt{b^2 + 4a(g(t) + g(\tau))}}{2a} = \frac{-b \pm \sqrt{(2at + b)^2 + 4ag(\tau)}}{2a}.$$
