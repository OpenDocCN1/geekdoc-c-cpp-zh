`fracdiff.sim` from the `fracdiff` CRAN package for generating realization from a FARMA or fractional model. See Note 1 below.

+   - `n` is the realization length \((x_k,\ t = 1,\ \ldots,\ n)\)
+   - `u` and `lambda` are the parameters of the Gegenbauer factor in [Equation 11.16](#)
+   - `phi` is a vector of the AR parameters (default is `phi = 0`)
+   - `theta` is a vector of MA parameters (using signs as in this text) (default is `theta = 0`)
+   - `trun` is the truncation point of the infinite GLP form (default = 300,000)
+   - `burn_in` is the burning-in period (default is 600)
+   - `vara` is the white noise variance (default = 1)
+   - `plot = TRUE` (default) produces a plot of the realization generated
+   - `sn` determines the seed used in the simulation. (see Note 4 below)
+   - The function outputs the generated realization.

# NOTES:

+   1. While fractional and FARMA models can be generated using `gen.garma.wge`, we recommend using `fracdiff.sim` in the CRAN package `fracdiff`. For example, to generate a realization of length \(n = 500\) from the model
+   
+      \[
+      (1 + .5B^2)(1 - B)^{.45}X_t = (1 + .8B)a_t
+      \]
+   
+      you could use the statement
+   
+      ```r
+      fgen = fracdiff.sim(n = 500,sr = c(0,-.5),ma = -.8,d=.45).
+      ```
+   
+      See the fracdiff documentation for more details.
+   
+   2. It will be useful to call the utility function `mult.wge` if you know the factors of the AR or MA parts of the model instead of the coefficients.
+   
+   3. By default the white noise is zero mean, normal noise with variance `vara = 1`.
+   
+   4. `sn=0` (default) produces results based on a randomly selected seed. If you want to reproduce the same realization on subsequent runs of `gen.garma.wge` then set `sn` to the same positive integer value on each run.
