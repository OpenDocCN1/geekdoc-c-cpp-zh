## Appendix 2A: Theorem Proofs

### Proof of Theorem 2A.1

Without loss of generality, we assume μ = 0. If m > k then

E[ (∑_{j=0}^{m} h_j Z_{t-j} - ∑_{j=0}^{k} h_j Z_{t-j})^2 ] = E[ (∑_{j=k+1}^{m} h_j Z_{t-j})^2 ]  (2A.1)
≤ [ ∑_{j=k+1}^{m} { E | h_j Z_{t-j} |^2 }^{1/2} ]^2  (Minkowski inequality)
= [ ∑_{j=k+1}^{m} | h_j | sqrt(Var(Z_{t-j})) ]^2
≤ [ sqrt(M) ∑_{j=k+1}^{m} | h_j | ]^2 .

As $m \to \infty$ and $k \to \infty$, then the right side of Equation (2A.1) converges to zero. It follows then that $\sum_{j=0}^m h_j Z_{t-j}$ is a Cauchy sequence and hence converges, say to $X_t$ which will be denoted

$X_t = \sum_{j=0}^{\infty} h_j Z_{t-j}$

The fact that each Cauchy sequence of random variables converges to a random variable is based on Hilbert space concepts. See Brockwell and Davis (1991, 2002) for a discussion.

To show the uniqueness of $X_t$, we assume that there exists another random
variable \(R_t\), such that \(\sum_{j=0}^{m} h_j Z_{t-j}\) also converges in mean square to \(R_t\). Then, again using the Minkowski inequality,

$$E\left(|X_t-R_t|^2\right)=E\left[\left|X_t-\sum_{j=0}^{m}h_jZ_{t-j}+\sum_{j=0}^{m}h_jZ_{t-j}-R_t\right|^2\right]$$
$$\leq\left[E\left|X_t-\sum_{j=0}^{m}h_jZ_{t-j}\right|^2\right]^{1/2}\left[E\left|\sum_{j=0}^{m}h_jZ_{t-j}-R_t\right|^2\right]^{1/2}.$$

and thus \(E\left(|X_t-R_t|^2\right)\to 0\) as \(m\to\infty\).

### Proof of Theorem 2A.2

Letting \(\gamma_X(k)\) and \(\gamma_Z(k)\) denote the autocovariance functions of the processes \(X_t\) and \(Z_t\), respectively, then

$$\begin{aligned}
\gamma_X(k)&=E[(X_t-\mu)(X_{t+k}-\mu)]\\
&=E\left[\left(\sum_{j=0}^{\infty}h_jZ_{t-j}\right)\left(\sum_{m=0}^{\infty}h_mZ_{t+k-m}\right)\right]
\end{aligned}$$

$$=\sum_{j=0}^{\infty}\sum_{m=0}^{\infty}h_jh_m\gamma_Z(k-m+j)$$

$$=\sum_{j=0}^{\infty}\sum_{m=0}^{\infty}h_jh_m\int_{-0.5}^{0.5}e^{2\pi i(k-m+j)f}P_Z(f)\,df$$

$$=\int_{-0.5}^{0.5}\left(\sum_{j=0}^{\infty}h_je^{2\pi ifj}\right)\left(\sum_{m=0}^{\infty}h_me^{-2\pi ifm}\right)e^{2\pi ifk}P_Z(f)\,df$$

$$=\int_{-0.5}^{0.5}e^{2\pi ifk}\left|\sum_{j=0}^{\infty}h_je^{-2\pi ifj}\right|^2P_Z(f)\,df.$$

It can be shown that if \(P_V(f)\) and \(P_W(f)\) are spectra, and if for each \(k\)

∫_{-0.5}^{0.5} e^{2π i f k} P_V(f) df = ∫_{-0.5}^{0.5} e^{2π i f k} P_W(f) df,

then P_V(f) = P_W(f). Using this fact, we see that γ_X(k) = ∫_{-0.5}^{0.5} e^{2π i f k} P_X(f)

by definition, and γ_X(k) = ∫_{-0.5}^{0.5} e^{2π i f k} |∑_{j=0}^{∞} h_j e^{-2π i f j}|^2 P_Z(f) df from the preceding calculations. So, it follows that

P_X(f) = |∑_{j=0}^{∞} h_j e^{-2π i f j}|^2 P_Z(f).

## Appendix 2B: R Commands

### 2B.1 R Commands

butterworth.wge(x,order,type,cutoff) is a tswge R function that requires functions in the CRAN package signal which should be installed on your machine before calling butterworth.wge.

- x is a vector containing the time series realization x_t, t = 1, ..., n
- order is the order of the Butterworth filter you want to use (default = 4)
- type should be either "low", "high", "pass", or "stop" for a low-pass, high-pass, band-pass, or band-stop (notch) filter, respectively.
- cutoff
  - if type = "high" or "low" then cutoff is the scalar cutoff frequency
  - if type = "stop" or "band" then cutoff is a 2-component vector containing the lower and upper cutoff frequencies

Example: The data set wages is contained in 'tswge'. The tswge R commands to perform the lowpass filter described in Example 2.4 are

```
data(wages)
wages05 = butterworth.wge(wages, order = 4, type = "low", cutoff = 0.05)
```

The filtered data set is wages05$x.filt.
