
$(1 - B)^\alpha f(t) = \sum_{k=0}^{\infty} (-1)^k \binom{\alpha}{k} B^k f(t) = \sum_{k=0}^{\infty} (-1)^k \binom{\alpha}{k} f(t - k)$

where

$$\displaystyle \binom{\alpha}{k} = \frac{\Gamma(\alpha + 1)}{\Gamma(\alpha - k + 1) k!}$$  (11.2)

and $\Gamma(z) = \int_{0}^{\infty} t^{z-1} e^{-t} dt$ is the gamma function. Using the fact that $\Gamma(x + 1) = x \Gamma(x)$ for real $x$, it follows that

$$(1 - B)^\alpha f(t) = \sum_{k=0}^{\infty} (-1)^k \frac{\Gamma(\alpha + 1)}{\Gamma(\alpha - k + 1) k!} f(t - k) = \sum_{k=0}^{\infty} \frac{(k - \alpha - 1)(k - \alpha - 2) \cdots (-\alpha)}{k!} f(t - k) = \sum_{k=0}^{\infty} \frac{\Gamma(k - \alpha)}{\Gamma(-\alpha) k!} f(t - k).$$  (11.3)

*Remark:* The fractional difference can be extended to the case where $\alpha$ is any real or complex number. For our purposes here it suffices for $\alpha$ to be real. For a more general definition of the fractional difference and its applications, see Gray and Zhang (1988).

Granger and Joyeux (1980), Hosking (1981, 1984), and Geweke and Porter-Hudak (1983) proposed the fractional difference model defined in Definition 11.3.

## Definition 11.3

If $\sum_{k=0}^{\infty} \left( |\Gamma(k + d)| / (\Gamma(d) k!) \right) < \infty$ then the general linear process defined by

$$X_t - \mu = (1 - B)^{-d} a_t = \sum_{k=0}^{\infty} \frac{\Gamma(k+d)}{\Gamma(d)k!} a_{t-k}, \quad t = 0, \pm 1, \pm 2, \dots$$

where $a_t$ is white noise, is called a *fractional process*. If $X_t$ is invertible, then the fractional model is written

$$ (1 - B)^d (X_t - \mu) = a_t \tag{11.5}$$

We typically express the fractional model in the form given in Equation 11.5. Theorem 11.1 gives basic properties of the fractional model including conditions for stationarity and invertibility.

## Theorem 11.1

Let $X_t$ be a fractional process of the form Equation 11.4.

- 1. If $d < 0.5$, then $X_t$ is causal and stationary
- 2. If $d > -0.5$, then $X_t$ is invertible
- 3. The spectral density of $X_t$ is given by $S(f) = [4(\sin \pi f)^2]^{-d}$, for $0 < f \le 0.5$, and thus $\lim_{f\to0} f^{2d} S(f)$ exists and is finite
- 4. If $d \in (-0.5,\ 0.5)$, then the autocorrelation function is given by

  $$\rho_k = \frac{\Gamma(-d+1)\Gamma(k+d)}{\Gamma(d)\Gamma(k-d+1)}, \quad k = 0, \pm 1, \dots,$$

  and $\rho_k \asymp k^{2d-1}$ as $k \to \infty$. Also, $\sigma_X^2 = \Gamma(-2d+1)/[\Gamma(-d+1)]^2$

- 5. If $0 < d < 0.5$ then $X_t$ is long memory

*Proof:* See Hosking (1981). The long-memory result in (5) follows from (4) using Definition 11.1 and from (3) using Definition 11.2.

In Definition 11.4, we extend the idea of a fractional process to a FARMA process that can have both short and long-memory behavior.

## Definition 11.4

If $X_t$ is a causal, stationary, and invertible process satisfying

$$\phi(B)(1 - B)^d(X_t - \mu) = \theta(B)a_t,\tag{11.6}$$

where $a_t$ is white noise, and where $\phi(z)$ and $\theta(z)$ are pth and qth-order polynomials, respectively, that share no common factors, then $X_t$ is called a fractional ARMA (FARMA(p,d,q)) process.

## Theorem 11.2

Let $X_t$ be a FARMA$(p,d,q)$ process as defined in Equation 11.6.

- 1. If $d < 0.5$ and all the roots of $\phi(z)=0$ are outside the unit circle, then $X_t$ is causal and stationary.
- 2. If $d > -0.5$ and all the roots of $\theta(z)=0$ are outside the unit circle, then $X_t$ is invertible.
- 3. If $d \in (-0.5, 0.5)$ with $d \ne 0$, then the autocorrelation function $\rho_k$ satisfies

  $$\rho(k) \simeq k^{2d-1} \quad \text{as} \quad k \to \infty.$$  
  (11.7)

- 4. If $d \in (-0.5, 0.5)$ and $d \ne 0$, then $\lim_{f\to 0} f^{2d}S(f)$ exists and is finite.

Proof: See Hosking (1981, Theorem 2) or Brockwell and Davis (1991).

NOTE: Hosking (1981) and others call $X_t$ in Equation 11.6 an ARIMA(p,d,q) process, but we reserve the expression ARIMA(p,d,q) to refer to processes for which $d$ is a positive integer. The model in Equation 11.6 is also referred to as an ARFIMA(p,d,q) model.
