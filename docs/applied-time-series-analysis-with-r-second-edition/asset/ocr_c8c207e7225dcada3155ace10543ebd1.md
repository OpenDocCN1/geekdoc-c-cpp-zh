$$\rho_1=\frac{-\theta_1+\theta_1\theta_2}{1+\theta_1^2+\theta_2^2}$$

$$\rho_2=\frac{-\theta_2}{1+\theta_1^2+\theta_2^2}$$

$$\rho_k=0,\qquad k\geq 3.$$

Using [Equation 3.6], the spectral density of the MA(2) process is given by

$$S_X(f)=\frac{\sigma_a^2}{\sigma_X^2}\left\{1+\theta_1^2+\theta_2^2-2\theta_1(1-\theta_2)\cos 2\pi f-2\theta_2\cos 4\pi f\right\}.$$

**Using R:** The `tswge` function `gen.arma.wge` can be used to generate and plot a realization from an MA model, while `true.arma.aut.wge` and `true.arma.spec.wge` calculate and plot the true autocorrelations and spectral densities for an MA model, respectively. Additionally, the `tswge` function `plotts.wge` can be used to generate a realization, calculate the true autocorrelations and spectral density, and create a plot similar to [Figure 3.11] in this text. Be careful with the coefficients. That is, for the MA(2) model $X_t=a_t-1.1a_{t-1}+0.6a_{t-2}$ the coefficients $\theta_1$ and $\theta_2$ are 1.1, and −0.6, respectively. These tswge functions can also be used for AR and ARMA models which will be discussed in the following. See [Appendix 3B] for more details.
