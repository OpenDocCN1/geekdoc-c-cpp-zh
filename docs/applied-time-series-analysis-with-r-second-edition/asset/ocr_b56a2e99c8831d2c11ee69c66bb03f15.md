$\rho_k = \phi_1 \rho_{k-1} + \cdots + \phi_p \rho_{k-p}, \quad (3.38)$

the first p equations specified in Equation 3.38 can be written as

$\rho_1 = \phi_1 + \phi_2 \rho_1 + \cdots \phi_p \rho_{p-1}$
$\rho_2 = \phi_1 \rho_1 + \phi_2 + \cdots \phi_p \rho_{p-2}$
$\vdots$
$\rho_p = \phi_1 \rho_{p-1} + \phi_2 \rho_{p-2} + \cdots + \phi_p, \quad (3.39)$

The equations in Equation 3.39 are called the Yule–Walker equations. When the coefficients $\phi_1,\dots,\phi_p$ are known, the Yule–Walker equations are p equations that can be solved for the p unknowns $\rho_1,\dots,\rho_p$. Note that after the first p autocorrelations are found by solving the Yule–Walker equations, then $\rho_k, k > p$ can iteratively be found using the relationship in Equation 3.38.

Also note that for a given set of data assumed to follow an unknown AR(p) model, the model parameters $\phi_1,\dots,\phi_p$ can be estimated by first replacing $\rho_k, k = 1, 2, \dots, p$ with the estimates $\hat{\rho}_k, k = 1, 2, \dots, p$ and solving the resulting p equations for $\hat{\phi}_1, \dots, \hat{\phi}_p$. These estimates are called the Yule–Walker estimates and will be discussed in more detail in Chapter 7.

In order to find $\gamma_0 = \sigma_X^2$, multiply every term in Equation 3.17 by $X_t$ and take expectations to obtain

$\gamma_0 - \phi_1 \gamma_1 - \cdots - \phi_p \gamma_p = E[X_t a_t], \quad (3.40)$

The expectation $E[X_t a_t]$ can be found by post-multiplying each term in Equation 3.17 by $a_t$ and taking expectations, which gives

$E[X_t a_t] = \sum_{k=1}^{p} \phi_k E[a_t X_{t-k}] + \sigma_a^2 = \sigma_a^2, \quad (3.41)$

since $E[a_t X_{t-k}] = 0$ for $k > 0$. From Equations 3.40 and 3.41, we find that
