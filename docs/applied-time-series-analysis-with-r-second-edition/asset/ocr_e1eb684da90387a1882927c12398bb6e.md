e. est.garma.wge(x, low.u, low.lambda, high.u, high.lambda, inc.u, inc.lambda, nback) is a function that obtains parameter estimates of a GARMA(p,d,q) model using the grid-search algorithm discussed in Section 11.5.

+   - low.u is the vector of lower boundaries of u's in the grid search
+   - low.lambda is the vector of lower boundaries of λ's in the grid search
+   - high.u is the vector of upper boundaries of u's in the grid search
+   - high.lambda is the vector of upper boundaries of λ's in the grid search
+   - inc.u is the increment for u's in the grid search
+   - inc.lambda is the increment for λ's in the grid search
+   - p.max is the maximum AR order
+   - nback is the number of backcast observations (see discussion following Equation 11.27)

The program outputs:

+   - u (the estimate of u)
+   - lam (the estimate of λ
+   - phi (the estimates of the parameters $\phi_1$, ... $\phi_p$
+   - vara (the estimated white noise variance (based on backcast residuals))
+   - aic associated with the final GARMA fit

+   2. We only consider the case in which there is one Gegenbauer factor.
