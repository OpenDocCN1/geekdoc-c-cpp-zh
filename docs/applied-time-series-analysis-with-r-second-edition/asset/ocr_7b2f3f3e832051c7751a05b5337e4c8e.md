# 13.3.2 Sampling the Continuous G(λ)-Stationary Processes

Suppose X(t) is a continuous G(λ)-stationary process, and suppose

t_k = ((k + ξ) Δ λ + 1)^{1/λ},  (13.18)

where k = 1, 2, ..., n, Δ > 0, and (k + ξ) Δ λ + 1 ≥ 0, where in this case ξ determines the offset and Δ is the sampling interval. Then the dual, Y_k = X(t_k), is a stationary process. Further, if X(t) is a continuous G(p; λ) process, the dual process is a discrete ARMA(p,r) with r ≤ p − 1. Also, the Nyquist frequency of the discrete dual, Y_k, is given by 1/(2Δ). Note that lim_{ξ→0} t_k = h^{t+ξ}. For further discussion and proof of these remarks, see Jiang et al. (2006).

# Definition 13.8

If the data are sampled from a continuous G(λ)-stationary process, X(t), at t_k defined in Equation 13.18, then f_N^*(Δ ; λ) = 1 / (2 Δ ) is called the G(λ)-Nyquist frequency.

NOTE: When λ = 1, the G(λ)-Nyquist frequency is the usual Nyquist frequency. When λ = 0, the G(λ)-Nyquist frequency is f_N^*(Δ ; 0) = 1 / (2 Δ ) = 1 / (2 ln h). This follows from the fact that in the transformed time space,

u_k − u_{k−1} = ln h^k − ln h^{k−1} = ln( h^k / h^{k−1} ) = ln h.
