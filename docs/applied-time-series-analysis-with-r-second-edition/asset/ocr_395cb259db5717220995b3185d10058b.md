It is easily shown that the function f(u)= |u| / (1 + u^2) has a maximum of 0.5 at u = ±1, from which it follows that for an MA(1) process, max |ρ1| = 0.5. In particular, ρ1 = 0.5 when θ1 = -1 and ρ1 = -0.5 when θ1 = 1. From Equation 3.6, the spectral density of an MA(1) is given, for |f| ≤ 0.5, by

S_X(f) = |1 - sum_{j=1}^q θ_j e^{-2π i f j}|^2 / (1 + sum_{j=1}^q θ_j^2)
= |1 - θ1 e^{-2π i f}|^2 / (1 + θ1^2)
= 1/(1+θ1^2) {1 - θ1 e^{-2π i f}} {1 - θ1 e^{2π i f}}
= 1/(1+θ1^2) {1 + θ1^2 - 2θ1 cos 2π f}
= 1 - 2θ1 cos 2π f / (1 + θ1^2).
(3.12)

As noted in Chapter 1, the spectral density provides information concerning the periodicities present in the data. From Equation 3.12, S_X(f) for an MA(1) model can be seen to be maximized, with respect to f, whenever the numerator of the right-hand side is minimized. If θ1 ≥ 0, this numerator is minimized when f = ±0.5, while if θ1 < 0, the minimum occurs at f = 0. Consequently, data for which θ1 > 0 are higher frequency than data for which θ1 < 0.

Notice that as θ1 → 0, the MA(1) process approaches white noise. This observation is consistent with the fact that as θ1 → 0, ρ1 as given in Equation 3.11 approaches 0, and S_X(f) as given in Equation 3.12 approaches a constant spectral density.
