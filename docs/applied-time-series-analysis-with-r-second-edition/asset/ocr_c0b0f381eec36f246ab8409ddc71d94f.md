Completing the analysis we transform the temperature data to obtain $Y_t = X_t - 1.732X_{t-1} + X_{t-2}$. The transformed realization is shown in **Figure 8.10c** and the sample autocorrelations are shown in **Figure 8.10d**. These data and sample autocorrelations suggest a stationary model, so we used AIC to fit an ARMA($p,q$) model to $Y_t$. Using Burg/Tsay Tiao estimates for calculating AIC with $P = 15$ and $Q = 2$, AIC and AICC select an AR(9) as the first choice while BIC selects an AR(3). Since the AR(3) model was not selected as one of the top five choices by either AIC or AICC, we have chosen to use the less parsimonious AR(9) model. The final model is

$$(1 - 1.732B + B^2)\phi_9(B)(X_t - 52.63) = a_t, \qquad (8.30)$$
