denote the first row by $V_i$, $i = 1, ..., n + k$ and the second row by $W_i$, $i = 1, ..., n + k$. Thus, $\overline{V} = \overline{W} = 0$ and the product-moment correlation between $V$ and $W$ is given by

$$r = \frac{\sum_{i=1}^{n+k} V_i W_i}{\sqrt{\sum_{i=1}^{n+k} V_i^2}\,\sqrt{\sum_{i=1}^{n+k} W_i^2}}.$$

The denominator can be rewritten as $\sum_{t=1}^{n} (X_t - \overline{X})^2$, and the numerator can be written as $\sum_{i=1}^{k} V_i W_i + \sum_{i=k+1}^{n} V_i W_i + \sum_{i=n+1}^{n+k} V_i W_i$. The first and last sums are zero, so that the numerator can be written as

$$\sum_{i=1}^{n+k} V_i W_i = \sum_{i=k+1}^{n} V_i W_i = \sum_{i=1}^{n-k} (X_t - \overline{X})(X_{t+k} - \overline{X}).$$

Thus $r = \hat{\rho}_k$ and so $|\hat{\rho}_k| \le 1.$

Bartlett (1946) has obtained approximate expressions for $\operatorname{Cov}(\hat{\rho}_k, \hat{\rho}_{k+j})$ when $X_t$ is a stationary Gaussian process. In particular, he showed that

$$\operatorname{Cov}(\hat{\rho}_k, \hat{\rho}_{k+j}) \approx \frac{1}{n} \sum_{v=-\infty}^{\infty} \{\rho_v \rho_{v+j} + \rho_{v+k} \rho_{v+k-j} - 2 \rho_v \rho_{v+k-j} - 2 \rho_{k+j} \rho_v \rho_{v+k} + 2 \rho_k \rho_{k+j} \rho_v^2\},$$

from which it follows, with $j = 0$, that

$$\operatorname{Var}(\hat{\rho}_k) \approx \frac{1}{n} \sum_{v=-\infty}^{\infty} \{\rho_v^2 + \rho_{v+k} \rho_{v-k} - 4 \rho_k \rho_v \rho_{v-k} + 2 \rho_k^2 \rho_v^2\}. \tag{1.20}$$
