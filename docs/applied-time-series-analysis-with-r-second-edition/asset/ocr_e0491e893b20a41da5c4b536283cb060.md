**Using R:** Forecasts from the general seasonal model in Equation 6.47 can be obtained using `fore.aruma.gen` by specifying $s$ to incorporate the factor $\lambda_s(B^s) = (1 - B^s)$. The stationary components of the model are $\phi(B)$ and the stationary seasonal factor $\Phi(B^s)$ (for example $(1 - \alpha B^s)$). These factors should first be multiplied using `mult.wge`, and then entered in the vector phi. Nonstationary components of the model can be entered into the model by specifying $d$ for factors such as $(1 - B)^d$, and using the vector `lambda` to specify other nonstationary components.
