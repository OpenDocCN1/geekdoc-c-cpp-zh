**Using R:** To obtain forecasts from a nonstationary ARUMA model, you can use the `tswge` function `fore.aruma.wge`. The nonstationary components can be any combination of factors $(1 - B)^d$ where $d$ is a positive integer, seasonal factors, specified by s (discussed in Section 6.9), and other nonstationary components entered using the vector lambda.
