+   1. Fit an ARMA(p,q) model to each of Xₜ₁ and Xₜ₂ (these two models may be of different orders p₁, q₁, p₂, and q₂
+   2. Calculate the residual series âₜ₁ and âₜ₂, t = 1, ..., n based on each model fit
+   3. Calculate the estimated cross-correlations, ρ̂₁₂^(â)(k), k = 1, ..., K between the two residual series
+   4. For each k, conclude that ρ̂₁₂^(â)(k) is significantly different from zero at the α = 0.05 level if |ρ̂₁₂^(â)(k)| > 2(1/√n).

This procedure is very similar to the one described in Section 8.1 for testing H₀ : ρ(k) = 0 versus Hₐ : ρ(k) ≠ 0. As in that case, it should be noted that the significance level α = 0.05 applies separately for each k, and it would not be unusual for about 5% of the ρ̂₁₂^(â)(k)'s to exceed ±2(1/√n) when the null hypothesis is true.
