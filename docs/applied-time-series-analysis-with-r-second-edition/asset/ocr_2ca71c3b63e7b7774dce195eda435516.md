1. Thus, all of the roots of θ(z) = 0 are outside the unit circle.

+   a. `gen.arma.wge(n,phi,theta,vara,plot,sn)` is a function that generates a realization of length n from a given stationary AR, MA, or ARMA model.
+   
+      `n` is the realization length (`x_t`, `t = 1, ..., n`). Note that the generated data are based on zero mean. If `x_t` is the time series generated by `gen.arma.wge`, then to convert to a time series with mean μ = 10, simply compute `y_t = x_t + 10`.
+   
+      `phi` is a vector of AR parameters (default is `phi = 0`)
+   
+      `theta` is a vector of MA parameters (using signs as in this text) (default is `theta = 0`)
+   
+      `vara` is the white noise variance (default = 1)
+   
+      `plot = TRUE` (default) produces a plot of the realization generated
+   
+      `sn` determines the seed used in the simulation (see Note (6) below).

NOTES:

+   1. This function finds `p` and `q` as the length of `phi` and `theta`, respectively. If either `phi = 0` or `theta = 0` (default) the values for `p` and `q` are set to zero, respectively.
+   
+   2. `gen.arma.wge` calls the base R function `arima.sim` which uses the same signs as this text for the AR parameters but opposite signs for MA parameters. The appropriate adjustments are made within `gen.arma.wge` so that input parameters `phi` and `theta` for `gen.arma.wge` should contain parameters using the signs as in this text. However: if you use `arima.sim` directly (which has options not employed in `gen.arma.wge`), then you must remember that the signs needed for the MA parameters have opposite signs as those in `gen.arma.wge`.
+   
+   3. `arima.sim` allows for nonstationary models (covered in [Chapter 5](#)) with a factor `(1 − B)^d` where `d` can take on a positive integer value. However, `gen.arma.wge` is designed specifically for stationary ARMA models.
