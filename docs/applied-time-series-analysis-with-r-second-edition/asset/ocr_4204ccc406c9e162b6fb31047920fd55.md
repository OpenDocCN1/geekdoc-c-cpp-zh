$\sigma_X^2(1 - \phi_1\rho_1 - \cdots - \phi_p\rho_p) = \sigma_a^2.$

Therefore,

$\sigma_X^2 = \frac{\sigma_a^2}{1 - \phi_1\rho_1 - \cdots - \phi_p\rho_p}.$
(3.43)

The equation in Equation 3.37 is an example of a linear homogenous difference equation with constant coefficients, which we briefly discuss here.
