**Using R:** As mentioned, the base R function `ar` calculates the Yule–Walker and least squares estimates for VAR models. The mle and burg methods available in `ar` are for the univariate case only. In the following R code we create a bivariate time series Figure 10.3 using `cbind` on the univariate series in Figure 10.3a and b.

```
data(fig10.3x1)
data(fig10.3x2)
fig10.3 = cbind(fig10.3x1,fig10.3x2)
```

The call statements used in this example to identify the model order using AIC and to obtain the Yule–Walker and least squares estimates are

```
ar(fig10.3,order.max = 8,aic = TRUE,method = 'yw')
```
