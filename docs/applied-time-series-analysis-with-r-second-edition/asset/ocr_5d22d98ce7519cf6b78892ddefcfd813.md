Guégan (2008) use the Whittle likelihood to estimate the parameters of a k-factor Gegenbauer model. The Whittle likelihood is a frequency-domain-based likelihood based on a class of models parameterized by ξ (possibly vector valued). Letting P_X(f; ξ) denote the spectrum at frequency f under the assumed model with parameter value ξ, a useful approximation to -2log-likelihood based on Whittle (1953) is

-2ln L_W(X; ξ) = Σ_{j=1}^{[n/2]} I(f_j) / P_X(f_j; ξ)   (11.28)

where [z] is the greatest integer less than or equal to z, f_j = j/n, j = 1, 2, ..., [n/2] and I(f_j) is the periodogram defined in Equation 1.38. Model identification can be accomplished using AIC. In the current setting, P_X(f) is defined in Equation 11.21. Kouamé and Hili (2008) proposed minimum distance estimators for the parameters of the k-factor GARMA model which are easy to compute and are not based on an assumption that the a_t's are normally distributed.

**Using R:** The tswge package includes the function est.garma.wge to estimate the parameters of the 1-factor GARMA model. The function est.farma.wge is included for use in the special case in which a FARMA model is specifically desired. Both of these functions use the grid-search procedure recommended by Hosking (1984), Gray et al. (1989, 1994), and Woodward et al. (1998) and include model selection using AIC. See Appendix 11A for more discussion of these estimation functions. CRAN package fracdiff contains functions for estimating the parameters of a FARMA model. See discussion in Example 11.9(1).
