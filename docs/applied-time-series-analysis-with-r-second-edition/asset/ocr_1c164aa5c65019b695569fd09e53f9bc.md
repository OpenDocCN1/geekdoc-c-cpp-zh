$$\operatorname{Var}\left[e_{t_0}(\ell)\right]=\sigma_a^2\sum_{k=0}^{\ell-1}\psi_k^2,$$

has the reasonable property that $\operatorname{Var}\left[e_{t_0}(\ell)\right]\to\infty$ as $\ell\to\infty$. We conclude this section by considering forecasts from a few specific ARUMA$(p,d,q)$ models.

# **Using R:**

The $\psi$-weights for a nonstationary ARIMA, seasonal, or ARUMA process, can be found using tswge function `psi.weights.wge`. If the model contains nonstationary factors such as $(1 - B)^d$, seasonal factors, or other nonstationary factors, these factors and the stationary factor $\phi(B)$, should be multiplied using the tswge function `mult.wge` (prior to calling `psi.weights.wge`) and using the resulting model coefficients as the contents of the vector `phi` in the call to `psi.weights.wge`.
