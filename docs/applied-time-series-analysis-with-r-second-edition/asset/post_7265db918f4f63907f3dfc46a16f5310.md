- **fore.glambda.wge (x, lambda, offset, n.ahead, lastn, plot)**

  This function forecasts n.ahead steps ahead using the 3-step approach discussed in Section 13.3.3 and further illustrated in Example 13.7. You can optionally calculate and plot forecasts n.ahead steps beyond the end of the series or you can forecast the last n.ahead data values. For comparison, AR forecasts will also be plotted.

  - x: realization
  - lambda: is the value of λ in the G(λ; p) model (default is lambda = 0, i.e. an M-stationary model)
  - offset: is the offset parameter (see for example the discussion about Figure 13.2) (default = 60)
  - phi: is a vector of AR parameters for the AR model fit to the dual data (default is phi = 0)
  - n.ahead: the number of steps ahead you want to forecast (default = 2)
  - lastn: logical variable. If lastn = FALSE (default) then the forecasts are for x(n + 1), x(n + 2), ..., x(n + n.ahead) where n is the length of the realization. If lastn = TRUE, then the program forecasts the last n.ahead values in the realization. (default = FALSE). AR forecasts are also plotted for comparison.
  - plot: is a logical variable. If plot = TRUE (default) then the forecasts will be plotted along with the realization. If plot = FALSE then no plots are output. (default = TRUE)

  Example: To compute and plot the forecasts shown in Figure 13.8b, use the following commands:

  ```
  data(fig13.2c)
  dual.data = trans.to.dual.wge(fig13.2c, lambda = -.4, offset = 63)
  aic5.wge(dual.data, p = 0:12, type = 'bic')
  # BIC picks p = 5
  ardual = est.ar.wge(dual.data, p = 5)
  example = fore.glambda.wge(fig13.2c, lambda = -.1, offset = 38, phi = ardual$phi, n.ahead = 60, lastn = TRUE)
  ```

  NOTE: The dual was obtained by transforming using the λ and offset found in Example 13.7. Also see example above for est.glambda.wge.

- **is.glambda.wge (n, lambda, offset, phi)** computes and plots the instantaneous spectrum based on the AR model fit to the dual data and the lambda and offset that were used to create the dual data set.

  - n: is the length of the original data set
  - lambda: is the value of λ in the G(λ; p) model (default is lambda = 0, i.e., an M-stationary model)
  - offset: is the offset parameter (see for example the discussion about Figure 13.2) (default = 60)
  - phi: is a vector of AR parameters for the AR model fit to the dual data (default is phi = 0)

  Example: To compute the instantaneous spectrum shown in Figure 13.8c, use the following commands:

  ```
  is.glambda.wge(n = 200, lambda = -0.4, offset = 63, phi = c(.93, -.32, -.15, -.15, -.17))
  ```

  NOTE: The phi coefficients are the ML estimates obtained by fitting an AR(5) model to the dual data set coefficients. See example in (c) above.

- **is.sample.wge (data, lambda, offset, phi)** computes and plots the instantaneous spectrum based on a spectral estimate of the dual using a Parzen window.

  - lambda: is the value of λ in the G(λ; p) model (default is lambda = 0, i.e. an M-stationary model)
  - offset: is the offset parameter (see for example the discussion about Figure 13.2) (default = 60)

