Note that this model has 13 roots on the unit circle: a nonstationary factor $1-B$ and a 12 month nonstationary seasonal factor $1-B^{12}$. A factor table associated with the characteristic equation $(1-z)(1-z^{12})=0$ would be the same as the one in [Table 5.5](#), except that it would include two factors of $1-B$. Thus, in Theorem 5.1 we have $d=13$, $j=1$, $\ell=2$. Notice that the limiting autocorrelations, $\rho_k^*$, of such a process are given by

$$\rho_k^*=1,$$ (5.19)

since the root of 1 is repeated twice. These ideas will be discussed in more detail in [Section 8.3.5.3](#) as we analyze seasonal data.

**Using R:** The `tswge` function `gen.aruma.wge` can be used to generate realizations from multiplicative seasonal models. For example, to use the airline model in you would generate data from the ARUMA$(p,d,q)$ model

$$\phi(B)\lambda_1(B)(X_t-\mu)=\theta_1(B)a_t$$

where

$$\phi_1(B)=\phi(B)\Phi(B^{12}),\quad \lambda_1(B)=(1-B)(1-B^{12}),$$

and

$$\theta_1(B)=\theta(B)\Theta(B^{12}).$$

The coefficients for $\phi_1(B)$, $\lambda_1(B)$, and $\theta_1(B)$ may need to be obtained using `mult.wge` before calling `gen.aruma.wge`. For more details, see [Appendix 3A](#).
