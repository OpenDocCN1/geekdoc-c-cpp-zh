$X_t - 2.195X_{t-1} + 1.994X_{t-2} - 0.796X_{t-3} = a_t,$

with $\sigma_a^2 = 1$, which can be written in factored form as

$(1 - 0.995B)(1 - 1.2B + 0.8B^2)X_t = a_t.$

This model has a positive real root very close to the unit circle and complex conjugate roots further removed. As noted in the discussion following Equation 7.52, the YW system of equations is near singular, and, as a consequence, the YW estimates of the model parameters are expected to be poor. The parameter estimates using the YW, Burg, and MLE procedures are shown in Table 7.6 where it is seen that the Burg and ML estimates are quite good while the YW estimates are poor.
