# 3.3.4 Autocorrelations of an ARMA(p,q) Model

Multiplying each term in Equation 3.86 (without loss of generality using the zero mean form) by $X_{t-k}(k \ge 0)$ and taking expectations yields

$\gamma_k = \phi_1\gamma_{k-1} + \cdots + \phi_p\gamma_{k-p} = E[X_t X_{t-k}] - \theta_1 E[X_{t -...}] - \cdots - \theta_q E[X_{t + a_{t-q}}]$ 
$= \gamma_X(k) - \theta_1\gamma_X(k-1) - \cdots - \theta_q\gamma_X(k-q).$ (3.96)

where

$\gamma_{Xa}(m) = E[X_{t-m}a_t]$ (3.97)
$= E\Big(\sum_{j=0}^{\infty} \psi_j a_{t-m} a_t\Big).$

From Equation 3.97, it follows that

$\gamma_{Xa}(m)=0,\quad m>0$ (3.98)
$= \psi_{|m|}\sigma_a^2,\quad m\le 0.$

Thus, for $k \ge 0$

$\gamma_k = \phi_1\gamma_{k-1} + \cdots + \phi_p\gamma_{k-p} - \sigma_a^2\big(\theta_k\psi_0 + \cdots + \theta_q\psi_{q-k}\big),$ (3.99)

where $\theta_0 = -1$, and the parenthetical expression is taken to be zero if $k > q$. Specifically, $\gamma_q$ is given by
$\gamma_q = \phi_1\gamma_{q-1} + \cdots + \phi_p\gamma_{q-p} - \sigma_a^2\theta_q,$ (3.100)
and $\gamma_k$ does not satisfy a homogeneous equation, since $\sigma_a^2\theta_q \ne 0$. However, for $k > q,$
