$a_t = X_t + \theta_1 (X_{t-1} + \theta_1 a_{t-2})$ 
$= X_t + \theta_1 X_{t-1} + \theta_1^2 a_{t-2}$ 
$= X_t + \theta_1 X_{t-1} + \theta_1^2 X_{t-2} + \theta_1^3 a_{t-3}$.

Continuing, we obtain $a_t = X_t + \theta_1 X_{t-1} + \theta_1^2 X_{t-2} + \dots + \theta_1^k X_{t-k} + \theta_1^{k+1} a_{t-k-1}$ and thus $X_t = -\theta_1 X_{t-1} - \theta_1^2 X_{t-2} - \dots - \theta_1^k X_{t-k} + a_t - \theta_1^{k+1} a_{t-k-1}$. (3.84)

If $|\theta_1| > 1$ the process is not invertible and Equation 3.84 shows that in this case, the present, $X_t$, is increasingly dependent on the distant past. For most problems, this is not a physically acceptable model.

2. Imposing invertibility removes model multiplicity: We again consider the MA(1) model in Equation 3.9. From Equation 3.11, the autocorrelation function, $\rho_k$, is zero for $k > 1$ and for $k = 1$ is given by $\rho_1 = -\theta_1 / (1 + \theta_1^2)$. Now consider the MA(1) process given by

$X_t = \left(1 - \frac{1}{\theta_1} B\right) a_t.$ (3.85)

For the process in Equation 3.85, it follows that $\rho_k = 0, \quad k > 1,$ and $\rho_1$ is given by

$\rho_1 = \frac{\left(\frac{-1}{\theta_1}\right)}{1 + \left(\frac{1}{\theta_1^2}\right)} = \frac{-\theta_1}{1 + \theta_1^2}.$ (3.85)

Thus, for example, if $\theta_1 = 0.5$, then the two MA(1) processes $X_t = (1 - 0.5 B) a_t$ and $X_t = (1 - 2 B) a_t$ have the same autocorrelations. Notice, however, that only $X_t = (1 - 0.5 B) a_t$ is invertible. In general, if $\rho_k$, $k = 1, 2, \dots$ are the autocorrelations of an MA($q$) process, there are several different MA($q$) processes having these autocorrelations, but only one of these processes is invertible (see Problem 3.8).
