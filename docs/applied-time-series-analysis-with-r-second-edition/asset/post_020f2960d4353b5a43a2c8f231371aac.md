## 11.3.3 GARMA Process

In the same manner that the fractional process has been extended to FARMA process, Definition 11.6 which follows extends the Gegenbauer process by combining it with the ARMA process.

### Definition 11.6

If $X_t$ is a causal, stationary, and invertible process satisfying

$\phi(B)(1 - 2uB + B^2)^{\lambda}(X_t - \mu) = \theta(B)a_t,$  (11.16)

where $\phi(z)$ and $\theta(z)$ share no common factors, then $X_t$ is a Gegenbauer ARMA (GARMA) process which will be denoted GARMA$(p, \lambda, u, q)$.

Theorem 11.5 summarizes the properties of the GARMA process.

### Theorem 11.5

Let $X_t$ be a GARMA process $(\lambda \neq 0)$ and let all roots of $\phi(z)=0$ and $\theta(z)=0$ lie outside the unit circle. Then we have the following:

- 1. $X_t$ is stationary if $\lambda < 1/4$ when $u = \pm 1$ or $\lambda < 1/2$ when $|u| < 1$.
- 2. $X_t$ is invertible if $\lambda > -1/4$ when $u = \pm 1$ or $\lambda > -1/2$ when $|u| < 1$.
- 3. The spectrum is given by
- $$P(f) = \sigma_a^2 \left| \frac{\theta(e^{-2\pi i f})}{\phi(e^{-2\pi i f})} \right|^2 \left| 1 - 2u\exp(-2\pi i f) + \exp(-4\pi i f) \right|^{-2\lambda}$$
- $$= \sigma_a^2 \left| \frac{\theta(e^{-2\pi i f})}{\phi(e^{-2\pi i f})} \right|^2 \left[4(\cos 2\pi f - \cos 2\pi f_G)^2\right]^{-\lambda}.$$
- 4. $X_t$ is long memory if $0 < \lambda < 1/4$ when $u = \pm 1$ or $0 < \lambda < 1/2$ when $|u| < 1$.
- 5. As $k \to \infty$, 
- a. $\rho_k \simeq k^{4\lambda -1}$ when $u = 1$ and $0 < \lambda < 1/4$
- b. $\rho_k \simeq (-1)^k k^{4\lambda -1}$ when $u = -1$ and $0 < \lambda < 1/4$
- c. $\rho_k \simeq k^{2\lambda -1} \cos(2\pi f_G k)$ when $|u| < 1$ and $0 < \lambda < 1/4$

*Proof:* See Gray et al. (1989, 1994).

## 11.4 k-Factor Gegenbauer and GARMA Processes

As we introduced the Gegenbauer process in Section 11.3, we noted that the long-memory fractional difference $(1 - B)^d$ can only model “first-order” long-memory behavior associated with $f = 0$. It was noted that the restriction to this type of first-order long-memory behavior is analogous in the setting of AR($p$) models to being restricted to first-order AR models with $\phi_1 > 0$. The Gegenbauer factor $(1 - 2uB + B^2)^\lambda$ introduced in Section 11.3 provides a model for “second order” or cyclical long memory when $|u| < 1$. Continuing with the AR($p$) analogy, this corresponds to an irreducible second-order factor. In Section 3.2, we noted that for a $p$th-order AR operator, $\phi(B) = 1 - \phi_1 B - \cdots - \phi_p B^p$, can be written as $\phi(B) = \sum_{j=1}^k (1 - \alpha_{1j}B - \alpha_{2j}B^2)$ where $\alpha_{2j}=0$ for first-order factors. Thus, the first- and second-order factors are viewed as building blocks of the AR($p$) model, and the properties of an AR($p$) process represent a combination of the behaviors induced by the first- and second-order factors of $\varphi(B)$. In this section, we discuss the $k$-factor Gegenbauer process that allows for long-memory behavior to be associated with each of $m$ ($\le k$) frequencies in $[0, 0.5]$. This model includes the fractional and Gegenbauer as special cases. We also consider the $k$-factor GARMA model that similarly generalizes the GARMA and FARMA models.

In Definition 11.7, we define the $k$-factor Gegenbauer process which was considered in the $k = 2$ case by Cheng (1993) and in general by Woodward et al. (1998) and Giraitis and Leipus (1995).

### Definition 11.7

If $X_t$ is a causal, stationary, and invertible process satisfying

$$\prod_{j=1}^{k} (1 - 2u_j B + B^2)^{\lambda_j} (X_t - \mu) = a_t, \tag{11.18}$$

where $a_t$ is white noise, then it is called a $k$-factor Gegenbauer process.

Theorem 11.6 gives the stationarity, long memory, and invertibility conditions for a $k$-factor Gegenbauer process.

### Theorem 11.7

$$P(f)=\sigma_a^2\left|\frac{\theta(e^{2\pi if})}{\phi(e^{2\pi if})}\right|^2\prod_{j=1}^{k}\left[4(\cos 2\pi f-u_j)^2\right]^{-\lambda_j}.$$ \tag{11.21}
