
$\hat{X}_{t_0}(\ell) \pm 1.96 \hat{\sigma}_a \left\{ \sum_{k=0}^{\ell-1} \psi_k^2 \right\}^{1/2}, $

where $\hat{\sigma}_a^2$ is

$\hat{\sigma}_a^2 = \frac{1}{n-p} \sum_{t=p+1}^{n} \hat{a}_t^2$
$= \frac{1}{23} \sum_{t=3}^{25} \hat{a}_t^2$
$= 0.7497,$

and $n = t_0 = 25$. The $\psi_k$'s are the $\psi$-weights from the estimated model. The half width of the approximate 95% prediction interval for $\ell = 3$ is given by

$1.96 \hat{\sigma}_a \left\{ \sum_{k=0}^{2} \psi_k^2 \right\}^{1/2} = 1.96 \sqrt{.7497} (1 + 0.7^2 + 0.24^2)^{1/2}$
$= 2.11.$

We will present approximate prediction intervals obtained by replacing $\sigma_a$ in Equation 6.33 by $\hat{\sigma}_a$ (and $\psi$-weights based on the estimated model), and without further comment will refer to these as prediction intervals. In Table 6.3, we show the forecasts, $\hat{X}_{25}(\ell)$, and half widths of the 95% prediction intervals for $\ell = 1$, ..., 4.

In Figures 6.3 and 6.4, we redisplay the realizations and forecasts shown in Figures 6.1 and 6.2 along with 95% prediction limits. It can be seen that the half widths of the prediction intervals increase as $\ell$ increases, but tend to level off as $\ell$ becomes large, converging to $1.96 \sigma_X$, if in fact the true $\sigma_a$ and model parameters were used. These half widths level off for stationary ARMA models because in this case, as mentioned in the discussion following Equation 6.34, $\sigma_a \left( \sum_{k=0}^{\ell-1} \psi_k^2 \right)^{1/2} \to \sigma_X (< \infty)$ and $\psi_k \to 0$ as $k \to \infty$. In our case, using $\hat{\sigma}_a$, the half widths converge to 3.38 and 2.27 for the AR(1) and ARMA(2,1) models, respectively.

## 6.8 Forecasts Using ARUMA(p,d,q) Models

Although the forecasting results obtained in Sections 6.1 through 6.7 are for ARMA(p,q) models, which are by definition stationary, the ARUMA(p,d,q) models of Section 5.2 are also an important class of models for which forecasts are of interest. Suppose that X_t follows an ARUMA(p,d,q) model

```
$$\phi(B)\lambda(B)(X_t - \mu) = \theta(B)a_t,\tag{6.35}$$
```

where φ(z) is a pth-order polynomial for which all the roots of φ(z) = 0 lie outside the unit circle. In addition, λ(z) is a dth-order polynomial (d > 0) with all roots of λ(z) = 0 on the unit circle. Let φ^{(u)}(B) = φ(B)λ(B), so that φ^{(u)}(B) is a (p + d)th-order operator with coefficients, say φ_1^{(u)}, φ_2^{(u)}, …, φ_{p+d}^{(u)}. Consider Equation 6.35 as a limit of stationary models

```
$$\phi(B)\lambda_m(B)(X_t^{(m)} - \mu) = \theta(B)a_t,$$
```

where the d roots of λ_m(z) = 0 are outside the unit circle but approach the roots of λ(z) = 0 (on the unit circle) as m → ∞. From Equation 6.21, we obtain the “limiting” forecast equation

```
$$\hat X_{t_0}(\ell)=\sum_{j=1}^{p+d}\phi_j^{(u)}\hat X_{t_0}(\ell - j)-\sum_{j=\ell}^{q}\theta_jE_{t_0}[a_{t_0+\ell-j}]+\left(1-\sum_{j=1}^{p+d}\phi_j^{(u)}\right)\mu.$$
```

As in the stationary case, in practice, we use the forecast formula

```
$$\hat X_{t_0}(\ell)=\sum_{j=1}^{p+d}\phi_j^{(u)}\hat X_{t_0}(\ell - j)-\sum_{j=\ell}^{q}\theta_j\hat a_{t_0+\ell-j}+\left(1-\sum_{j=1}^{p+d}\phi_j^{(u)}\right)\bar X,\tag{6.36}$$
```

where the \hat a_t s are given by

$$\hat{a}_t = 0,\ t \le p + d$$ $$= X_t - \sum_{j=1}^{p+d} \phi_j^{(u)} X_{t-j} + \sum_{j=1}^{q} \theta_j \hat{a}_{t-j} - \left(1 - \sum_{j=1}^{p+d} \phi_j^{(u)}\right) \bar{X},$$

t = p + d + 1, ..., t₀. It also follows that g_ℓ = \hat{X}_{t₀}(ℓ) - \bar{X} satisfies the (p + d)th-order difference equation φ^{(u)}(B) g_ℓ = 0. However, since X_t given in Equation 6.35 follows a nonstationary model, the general linear process form

$$X_t - \mu = \sum_{j=0}^{\infty} \psi_j a_{t-j},$$

obtained by algebraically performing the inversions involved in

$$\phi^{-1}(z) \lambda^{-1}(z) \theta(z) = \psi(z),$$ (6.38)

may not converge in a meaningful sense. Thus, the expression in Equation 6.11 for forecast error, e_{t₀}(ℓ), is not immediately valid. Again, we consider X_t in Equation 6.35 to be a limit of stationary processes, φ(B) λ_m(B) (X_t^{(m)} - μ) = θ(B) a_t, where the roots of λ_m(z) = 0 are outside the unit circle for each m, yet approach the roots of λ(z) = 0 as m → ∞. Then, for each m, X_t^{(m)} is a stationary process, producing forecasts from t₀ whose forecast error is given by Equation 6.11. As m → ∞, the forecast errors associated with X_t^{(m)} approach

$$e_{t₀}(ℓ) = \sum_{k=0}^{ℓ-1} \psi_k a_{t₀+ℓ-k},$$ (6.39)

where the ψ_k's in Equation 6.39 are obtained using the algebraic inversions indicated in Equation 6.38. We use Equation 6.39 as the ℓ-step forecast error associated with forecasts, \hat{X}_{t₀}(ℓ), found using Equation 6.36 for an ARUMA model. It follows, however, that the associated error variance (6.40)

$$\operatorname{Var}\left[e_{t_0}(\ell)\right]=\sigma_a^2\sum_{k=0}^{\ell-1}\psi_k^2,$$

has the reasonable property that $\operatorname{Var}\left[e_{t_0}(\ell)\right]\to\infty$ as $\ell\to\infty$. We conclude this section by considering forecasts from a few specific ARUMA$(p,d,q)$ models.

## Using R:

The $\psi$-weights for a nonstationary ARIMA, seasonal, or ARUMA process, can be found using tswge function `psi.weights.wge`. If the model contains nonstationary factors such as $(1 - B)^d$, seasonal factors, or other nonstationary factors, these factors and the stationary factor $\phi(B)$, should be multiplied using the tswge function `mult.wge` (prior to calling `psi.weights.wge`) and using the resulting model coefficients as the contents of the vector `phi` in the call to `psi.weights.wge`.

## EXAMPLE 6.3: FORECASTS FROM AN ARIMA(0,1,0) MODEL

Consider the ARIMA(0,1,0) model

$$(1 - B)X_t = a_t.\tag{6.41}$$

A realization of length $n = 50$ from this model, which is plotted in Figure 6.5, can be found in tswge data set `fig6.5nf`. From Equation 6.36, forecasts, $\hat{X}_{t_0}(\ell)$, are given by

$$\hat{X}_{t_0}(\ell)=\hat{X}_{t_0}(\ell-1)+(1-1)\bar{X}$$ $$=\hat{X}_{t_0}(\ell-1).$$

Note that since the characteristic equation $\lambda(z)=1-z=0$ has a root of $+1$, then $\bar{X}$ plays no role in the forecasts. The eventual forecast function satisfies the difference equation $g_\ell = g_{\ell-1}$ for $\ell>0$, where $g_\ell = \hat{X}_{t_0}(\ell)-\bar{X}$. The root of the characteristic Equation $1-z=0$ is $r_1=1$, so that solutions of this difference equation are given by $g_\ell = C_1(1)^1 = C_1$, where $C_1 = g_0 = X_{t_0} - X$. Thus,

$$\hat X_{t_0}(1)=\hat X_{t_0}(0)=X_{t_0},$$
$$\hat X_{t_0}(2)=\hat X_{t_0}(1)=X_{t_0},$$

and in general

$$\hat X_{t_0}(\ell)=X_{t_0},\qquad \ell=1,2,\dots$$

Thus, these forecasts display no tendency to return to $\overline X$ as in the stationary case, but due to the random walk nature of data from this model, the best forecast of the future is the last value observed. For large $\ell$, however, these forecasts may be quite poor, as evidenced by the fact that $\operatorname{Var}\left[e_{t_0}(\ell)\right]$ grows without bound as $\ell$ increases. Forecasts and 95% prediction limits for a realization of length $n=50$ from the model in Equation 6.41 with $\sigma_a^2=1$ are given in Figure 6.5. For this realization, $\overline X=100.4$ and $\hat X_{50}(\ell)=X_{50}=9.86$ for $\ell\ge1$.
