+   1. The power spectrum, $P_X(f)$, is defined by
+   
+   $$P_X(f) = \int_{-\infty}^{\infty} e^{-2\pi i f h} \gamma(h) dh,$$  (1.23)
+   
+   where $-\infty < f < \infty$, $i = \sqrt{-1}$, and $\gamma(h)$ is the autocovariance function.
+   
+   2. The spectral density is a normalized version of $P_X(f)$. Specifically, we define the spectral density, $S_X(f)$, by
+   
+   $$S_X(f) = \frac{P_X(f)}{\sigma_X^2}$$  (1.24)
+   
+   $$= \int_{-\infty}^{\infty} e^{-2\pi i f h} \rho(h) dh.$$

The power spectrum will often be referred to as simply the spectrum. Definition 1.11 requires the index set $T$ to be continuous. It is possible to give a more general definition that also includes the discrete case. However, to do so would require us to use the Stieltjes integral in the definition. The reader should refer to Priestley (1981) and Koopmans (1974) for this approach. We have chosen instead to consider the discrete parameter case separately.
