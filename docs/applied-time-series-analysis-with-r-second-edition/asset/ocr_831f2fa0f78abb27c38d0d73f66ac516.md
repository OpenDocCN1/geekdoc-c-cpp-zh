data(ss08)

calculates and plots the periodogram (in dB). The vectors per$freq and per$pgram contain the frequencies and associated periodogram values (log or non-log)

e. parzen.wge(x, dbcalc, trunc, plot) (tswge R function) calculates and alternatively plots the smoothed periodogram based on the Parzen window.

x is a vector containing the time series realization x_t, t = 1, ..., n.

dbcalc is a logical variable. dbcalc = "TRUE" (default) calculates the smoothed spectral estimator on the log scale (in dB)

trunc (integer ≥0) specifies the truncation point.

trunc = 0 (default) (or no value for trunc is specified) indicates that the default truncation point is M = 2√n

trunc > 0 is a user specified truncation point, i.e. calculations will be based on M = trunc

plot is a logical variable. plot = "TRUE" (default) produces a plot of the smoothed spectral estimator (in log or non-log scale depending on dB).

Example:

```
data(ss08); sparz=parzen.wge(ss08)
```

calculates and plots the smoothed spectral estimator (in dB) for the sunspot data using the default truncation point, M = 2√260 = 32.

The vectors ssparz$freq and ssparz$pgram contain the frequencies and associated Parzen-based spectral estimates.

f. gen.sigplusnoise.wge(n, b0, b1, coef, freq, psi, vara, plot, sn) is a tswge R function that generates a realization from the signal-plus-noise model

x(t) = b0 + b1t + coef[1]*cos(2π freq[1]t + psi[1]) + coef[2]*cos(2π freq[2]t + psi[2]) + a(t)

n = length of realization to be generated (t in the above formula specifies the integers from 1 to n)

b0 is the y-intercept
