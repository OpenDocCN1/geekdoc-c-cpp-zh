## 2 Linear Filters

Many of the time series that we will study can be viewed as the output of a linear operator or filter. In this chapter, we introduce the basic concepts and terminology of linear filter theory. We also discuss the general linear process, which is a linear filter with white noise input that plays a fundamental role in the study of stationary processes. Finally, we discuss the application of linear filters for purposes of removing or retaining certain types of frequency behavior from a time series realization.

### 2.1 Introduction to Linear Filters

### 2.2 Stationary General Linear Processes

Many of the statistical time series that we will study can be viewed as the output, $X_t$, of a linear filter with white noise input. Such a process is called a *general linear process*, which is defined in the following.

Definition 2.1 (General Linear Process) The process $X_t$, $t = 0, \pm 1, \pm 2, \dots$ given by

$X_t - \mu = \sum_{j=0}^{\infty} \psi_j a_{t-j}$  (2.5)

is defined to be a *general linear process* if $a_t$ is a white noise process with zero mean and finite variance and $\sum_{j=0}^{\infty} |\psi_j| < \infty$.

Using the backshift operator $B$, Equation 2.5 can be written as

$X_t - \mu = \sum_{j=0}^{\infty} \psi_j B^j a_t = \psi(B) a_t$

where

$\psi(B) = \sum_{j=0}^{\infty} \psi_j B^j$.

In this section, we will consider the problem of finding stationarity conditions for $X_t$ in Equation 2.5 along with expressions for the autocovariance function and power spectrum. ### EXAMPLE 2.1: FIRST DIFFERENCE FILTER

Consider a time series realization x_t, t = 1, ..., n, and suppose we compute the first difference y_t = x_t - x_{t-1}. In order to see the effect of this differencing operation, we note that the first difference is a linear filter of the form in Equation 2.1 where h0 = 1, h1 = -1, and h_j = 0, j ≠ 0 or 1.
