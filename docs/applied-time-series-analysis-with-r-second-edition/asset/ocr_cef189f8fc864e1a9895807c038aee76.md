# ## 11.7 Testing for Long Memory

Techniques have been developed for testing for long memory. For example, simply fitting a fractional or FARMA model to a set of data and getting \(\hat{d} \ne 0\) does not imply that the data are long memory. What is needed are tests of the hypotheses \(H_0\): the data are short memory versus \(H_a\): the data are long memory that control a significance level (say at \(\alpha = 0.05\)) and have acceptable power for detecting long memory when it exists.
