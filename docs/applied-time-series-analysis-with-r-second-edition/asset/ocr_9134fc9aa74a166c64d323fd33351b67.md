4. artrans.wge(x,phi.tr,lag.max,plottr) performs an AR transformation y_t = φ(B)x_t where the coefficients of φ(B) are given in phi.tr.

+   - x = original realization
+   - phi.tr = vector of transforming coefficients
+   - lag.max = maximum lag for calculated sample autocorrelations (for original and a transformed data) (default = 25)
+   - plottr = logical variable.
+   - If plottr = TRUE (default) then artrans.wge plots the original and transformed realizations and associated sample autocorrelations

Example: In this example we use artrans.wge to factor out the second order factor, 1 − 1.6B + 0.9B², from the data in Figure 3.16a, and plot the data, sample autocorrelations, transformed data, and sample autocorrelations of the transformed data.

```
data(fig3.16a); test = artrans.wge(fig3.16a, phi = c(1.6,-0.9), lag.max = 20)
```

The vector test contains the (n − 2) values of the transformed data.
