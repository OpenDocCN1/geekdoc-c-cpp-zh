# ### 3.1.2 MA(2) Model

Let $X_t$ denote the MA(2) model given by

$$X_t = a_t - \theta_1 a_{t-1} - \theta_2 a_{t-2}.$$

For this model, it follows that

$$\gamma_0 = \sigma_a^2(1 + \theta_1^2 + \theta_2^2) = \sigma_X^2.$$
