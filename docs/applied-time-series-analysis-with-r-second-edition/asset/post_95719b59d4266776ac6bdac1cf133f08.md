## 10B.1 Additional Multiple Time Series Routines

Except for the Kalman-filtering routines listed above, tswge does not include functions specifically designed for multivariate time series data. We discussed several multivariate R functions and CRAN packages in this chapter. These include

- 1. *Base R function* `ccf`: As mentioned in Section 10.2, given univariate time series $X_i$ (x1) and $X_j$ (xj), the base R function call `ccf(x1,xj,type = 'covariance')` computes $\gamma_{ij}^{(a)}(k) = E[(X_{t+k,i} - \mu_i)(X_{tj} - \mu_j)]$ which is not the cross-covariance, $\gamma_{ij}(k) = E[(X_{ti} - \mu_i)(X_{t+k,j} - \mu_j)]$ as defined in Equation 10.2. Again, as mentioned in Section 10.2, in order to compute $\gamma_{ij}(k)$ as defined in Equation 10.2, then you can use the call statement `ccf(xj,xi,type = 'covariance')`. In order to compute cross-correlations you can specify `type = 'correlation'` in either case. The default for `ccf` is to plot the associated cross-covariance and cross-correlation.

- 2. **Base R function ar:** This function calculates the Yule–Walker and least squares estimates for VAR models. It also provides for order identification using AIC. The statements needed to perform the analyses in Example 10.4 are given in the “Using R” section at the end of the example.

- 3. **CRAN package vars:** This package is useful for analyzing VAR models. The vars commands `lsfit` (finds least squares estimates and performs model identification), `serial.test` (performs a Ljung–Box test following a call to `lsfit`), and `predict` calculates forecasts and 95% limits based on the model found using `lsfit`. The vars commands used in Example 10.4 are given in the “Using R” section at the end of the example.

- 4. **CRAN packages ursa and fUnitRoots:** In Example 10.7 we used the function `ca.jo` function in CRAN package ursa to run the Johansen trace test for cointegration. In that example we also used the function `adfTest` from CRAN package fUnitRoots that was used previously in Example 8.6.

## Long-Memory Processes

In the previous chapters, we have considered ARMA, ARUMA, seasonal, signal-plus-noise, and ARCH/GARCH processes. For the current discussion, we restrict ourselves to nonseasonal models. Stationary ARMA(p,q) processes have autocorrelations that decay (go to zero) exponentially as k gets large. That is, ρ_k ≍ α^{|k|}, |α| < 1 as k → ∞ where k is the lag. We use the notation f_k ≍ g_k as k → ∞ to indicate that lim_{k→∞}(f_k / g_k) = c , where c is a finite nonzero constant. For example, for an AR(1) model with φ_1 = 0.9, ρ_k = 0.9^{|k|}. In Example 3.10, it was shown that the autocorrelation function for the AR(3) model (1 − 0.95B)(1 − 1.6B + 0.9B²)X_t = a_t is given by ρ_k = 0.66(0.95)^k + 0.3518(0.95)^k sin[2π(0.09)k + 1.31],

so that in both cases ρ_k ≍ α^{|k|} as k → ∞. In Chapter 5 we viewed ARUMA(p,d,q) processes as limits of ARMA processes as one or more roots of the characteristic equation approach the unit circle uniformly. Since the autocorrelation of an ARMA process decays exponentially, such processes are referred to as “short-memory” processes. It was noted in Section 5.2 that the correlation function decays more slowly as one or more roots of the characteristic equation approach the unit circle, and in fact the extended autocorrelations of the limiting ARUMA(p,d,q) process with integer d > 0 do not decay as k goes to infinity. Signal-plus-noise processes also have autocorrelations that do not decay, but these models involve functional restrictions that often prove to be too limiting in practice.
