estimation, etc. Given a state-space model

$$X_t = F X_{t-1} + V_t$$
$$Y_t = G_t X_t + W_t$$

the fundamental goal is to estimate the underlying unobserved signal X_t given the observations Y_1, ..., Y_s for some time s. The typical procedure used to accomplish this goal is to

+   1. Estimate the parameters ($\mu_0$, $\Gamma_0$, $F$, $\Gamma_V$, $G_t$, and $\Gamma_W$) of the state-space model.
+   2. Use the estimated model to find the best linear estimate of $X_t$ (for some time $t$) in the mean-square sense. Specifically, we want to find $E(X_t \mid Y_1, ..., Y_s)$. For simplicity, we will use $\hat{X}_t^s$ to denote $E(X_t \mid Y_1, ..., Y_s)$, and we denote the mean-squared error by $\Gamma_t^s = E[(X_t - \hat{X}_t^s)(X_t - \hat{X}_t^s)^T]$. This step has three subcategories based on the relationship between time $t$ and the time of the last observed value, $s$.
+      a. *Prediction:* This is the case in which $s < t$. An example would be the one-step ahead forecasts $\hat{X}_2^1$, $\hat{X}_3^2$, ...
+      b. *Filtering:* The case in which $s = t$.
+      c. *Smoothing:* The case in which $s > t$. This case is called smoothing, since a time plot of $\hat{X}_1^s$, $\hat{X}_2^s$, ..., $\hat{X}_s^s$ tends to be smoother than plots of the one-step ahead forecasts $\hat{X}_1^0$, $\hat{X}_2^1$, ..., $\hat{X}_s^{s-1}$ or plots of the “filters” $\hat{X}_1^1$, $\hat{X}_2^2$, ..., $\hat{X}_s^s$.
