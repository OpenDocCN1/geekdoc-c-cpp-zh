f. is.glambada.wge(n,lambda,offset,phi) computes and plots the instantaneous spectrum based on the AR model fit to the dual data and the lambda and offset that were used to create the dual data set.

+   - n is the length of the original data set
+   - lambda is the value of λ in the G(λ; p) model (default is lambda = 0, i.e., an M-stationary model)
+   - offset is the offset parameter (see for example the discussion about Figure 13.2) (default = 60)
+   - phi is a vector of AR parameters for the AR model fit to the dual data (default is phi = 0)

Example: To compute the instantaneous spectrum shown in Figure 13.8c, use the following commands

```
is.glambada.wge(n = 200,lambda = -0.4,offset = 63,phi = c(.93,-.32,-.15,-.15,-.17))
```

NOTE: The phi coefficients are the ML estimates obtained by fitting an AR(5) model to the dual data set coefficients. See example in (c) above.

g. is.sample.wge(data,lambda,offset,phi) computes and plots the instantaneous spectrum based on a spectral estimate of the dual using a Parzen window.

+   - lambda is the value of λ in the G(λ; p) model (default is lambda = 0, i.e. an M-stationary model)
+   - offset is the offset parameter (see for example the discussion about Figure 13.2) (default = 60)

Example: To compute the instantaneous spectrum based on a periodogram fit to the dual data in Figure 13.4b obtained from the data in Figure 13.2c (and Figure 13.4a), use the following commands:

```
data(fig13.2c)

```
