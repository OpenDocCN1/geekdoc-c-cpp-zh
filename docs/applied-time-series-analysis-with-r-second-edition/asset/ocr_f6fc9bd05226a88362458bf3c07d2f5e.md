so that γ_k and ρ_k satisfy a pth-order linear homogeneous difference equation with constant coefficients for k > q. Since we have assumed that φ(z) and θ(z) share no common factors, p is the lowest order of a homogeneous linear difference equation with constant coefficients satisfied by ρ_k. The solution to Equation 3.102 can be made to satisfy p linear boundary conditions obtained from Equation 3.99 for k = q, q - 1, ..., q - p + 1. Thus, for k > q - p, it follows that

$$\rho_k = \sum_{i=1}^{v} \sum_{j=0}^{m_i-1} C_{ij} k r_i^{j-k}, \tag{3.103}$$

or in the case of no repeated roots of the characteristic equation,

$$\rho_k = C_1 r_1^{-k} + \cdots + C_p r_p^{-k}, \tag{3.104}$$

where the C_ij and C_j are constants uniquely determined from Equation 3.99 with k = q, q - 1, ..., q - p + 1.

The autocovariance function can also be found as the solution of a system of nonhomogeneous linear difference equations. Letting ν = max(p, q + 1) and for k = 0,1,...,ν in Equation 3.99 gives the ν + 1 linear equations in the ν + 1 unknowns γ0, γ1, ⋯ γν

$$\begin{aligned}
\gamma_0 &= \phi_1\gamma_1 + \phi_2\gamma_2 + \cdots + \phi_p\gamma_p - \sigma_a^2(-1 + \theta_1\psi_1 + \cdots + \theta_q\psi_q) \\
\gamma_1 &= \phi_1\gamma_0 + \phi_2\gamma_1 + \cdots + \phi_p\gamma_{p-1} - \sigma_a^2(\theta_1 + \theta_2\psi_1 + \cdots + \theta_q\psi_{q-1}) \\
&\vdots \\
\gamma_\nu &= \phi_1\gamma_{\nu-1} + \phi_2\gamma_{\nu-2} + \cdots + \phi_p\gamma_{\nu-p} - \sigma_a^2(\theta_\nu + \theta_{\nu+1}\psi_1 + \cdots + \theta_q\psi_{q-\nu})
\end{aligned}\tag{3.105}$$

where θ_j = 0 whenever j > q. The ψ-weights can be obtained from the φ_j and θ_j using a recursive algorithm to be given shortly. For k > ν, γ_k can be solved by simply using the recursion in Equation 3.101 using the starting values, γ_ν, γ_{ν-1}, ..., γ_{ν-p+1}.

Note that Equation 3.103 shows that ρ_k → 0 (and equivalently γ_k → 0) as k → ∞ for an ARMA(p,q) process. From Theorem 1.1, it thus follows that, in the case of an ARMA(p,q) process, Γ_k and ρ_k defined in Equations 1.2 and 1.3, respectively, are positive definite for each integer k > 0.
