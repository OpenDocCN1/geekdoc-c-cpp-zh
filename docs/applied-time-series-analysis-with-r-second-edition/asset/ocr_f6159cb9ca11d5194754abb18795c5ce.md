b. est.arma.wge(x,p,q,factor) is a function that obtains parameter estimates of a stationary ARMA(p,q) model that is fit to the data in the vector x.

+   - x is a vector containing the realization to be analyzed
+   - p is the AR order of the model
+   - q is the MA order of the model
+   - factor is a logical variable, and if factor = TRUE (default) a factor table (of the AR components of the model) is printed for the estimated model

The program outputs:

+   - phi the ML estimates of the parameters φ₁, ..., φₚ
+   - theta the ML estimates of the parameters θ₁, ..., θ_q
+   - res the estimated residuals (using backcasting) based on estimated model
+   - avar the estimated white noise variance (based on backcast residuals)
+   - aic the AIC value associated with this model fit
