b. The tswge R function
`plotts.wge(x)`
provides a simplified use of the basic R plot command where x is a vector containing the time series realization x_t, t = 1, ..., n. For more flexibility use the basic R command plot.
*Example:* `data(airline); airlog = log(airline); plotts.wge(airlog)` plots the log airline data shown in Figure 1.25a.

c. `acf(x, lag.max, type, plot)` (base R function): calculates (and optionally plots) the sample autocorrelations (or sample autocovariances and sample variance) of the time series realization where
x is a vector containing the time series realization x_t, t = 1, ..., n.
lag.max is the maximum lag at which to calculate the sample autocorrelations (or covariances)
type = "correlation" (default) produces the sample autocorrelations,
"covariance" specifies the autocovariances, and
"partial" indicates the partial autocorrelations (discussed in Chapter 8).
plot is a logical variable. plot = "TRUE" (default) produces a plot of the sample autocorrelations (or autocovariances)
*Example:* `data(hadley); tempaut = acf(x = hadley, lag.max = 25)`
calculates and plots the first 25 sample autocorrelations for the global temperature data in file hadley that are shown in Figure 1.24a. The sample autocorrelations are placed in the vector tempaut$acf (which has 26 elements counting tempaut$acf[1] = 1, i.e. the sample autocorrelation at lag 0). If type = "covariance" is selected, then the vector tempaut$acf contains the sample autocovariances, and tempaut$acf[1] contains the sample variance (using the divisor n).
