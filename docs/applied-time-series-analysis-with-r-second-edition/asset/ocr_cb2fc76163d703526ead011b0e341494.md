# 8A.5.1 Measuring Patterns in the GPAC Array

One measure of the strength of the GPAC identification pattern is the W-statistic. For a given P and Q, then for each j ≤ P and k ≤ Q, the W-statistic measures the strength of the GPAC pattern associated with an ARMA(j,k) model. Using the notation in Tables 8A.2 and 8A.3, then the W-statistic measures the extent to which φ_{kk}^{(j)}, φ_{kk}^{(j+1)}, φ_{kk}^{(j+2)}, φ_{kk}^{(j+3)} are “constant” and the values φ_{k+1,k+1}^{(j)}, φ_{k+2,k+2}^{(j)}, φ_{k+3,k+3}^{(j)} are near zero. That is, only four values are used to assess the constant behavior and only three to measure the zero behavior since these behaviors become more variable as you move away from the true p,q location. For this reason, we also weight the constants and zeros. For example, implementation in GW-WINKS uses the weighted average of the constants

A = (wc0 φ_{kk}^{(j)} + wc1 φ_{kk}^{(j+1)} + wc2 φ_{kk}^{(j+2)} + wc3 φ_{kk}^{(j+3)}) / (wc0 + wc1 + wc2 + wc3).

Similarly, we weight the three “zeros” using the weights wz1, wz2, and wz3. The W-statistic is then calculated as W = (C + Z)/|A| where C is the (weighted) sample standard deviation of the four “constants” and Z is the square root of the (weighted) average sum of squares of the “zeros”. The W-statistic uses wc0 = wc1 = 1, wc2 = 0.8, wc3 = 0.6, and wz1 = 1, wz2 = 0.8, wz3 = 0.6. Clearly, smaller values of W suggest a stronger pattern.
