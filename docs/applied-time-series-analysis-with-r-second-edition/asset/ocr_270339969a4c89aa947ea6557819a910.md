# Utility Routines

a. `psi.weights.wge(phi, theta, lag.max)` calculates the ψ-weights for an ARMA (or ARUMA) model.

phi = the vector of AR coefficients (in un-factored form) for a stationary model along with any (1 − B)^d, seasonal, and λ(B) factors (multiplied together using mult.wge. (default = 0)

theta = MA coefficients of the ARUMA model in un-factored form. (default = 0)

lag.max = maximum lag at which the psi weights will be calculated. The function calculates psi weights psi(1), psi(2),..., psi(lag.max). Note that psi(0) = 1. (default = 0)
