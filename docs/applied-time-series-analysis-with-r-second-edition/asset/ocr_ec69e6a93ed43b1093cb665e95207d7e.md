**Using R:** Several `tswge` R functions are available for spectral estimation.

+   1. `parzen.wge(x, dbcalc, trunc, plot)` calculates and alternatively plots the smoothed periodogram based on the Parzen window using the truncation point *M* = 2√*n* for the time series realization x.
+   2. `plot.sample.wge(x,lag.max,trunc)` plots a realization, sample autocorrelations, periodogram, and smoothed periodogram based on the Parzen window (both plotted in dB).
+   3. `plot.parzen.wge(x,m2)` plots the periodogram and up to 3 Parzen window spectral estimates with different truncation points (all plotted in dB).
