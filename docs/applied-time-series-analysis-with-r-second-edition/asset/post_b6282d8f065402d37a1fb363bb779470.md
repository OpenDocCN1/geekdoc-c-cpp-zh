### 10.5.2 Testing for Cointegration between Nonstationary Time Series

We let $X_{t1}$ and $X_{t2}$ denote the annual incidence of non-perforated appendicitis (tswge file appy) and influenza (tswge file flu), respectively, shown in [Figure 10.8](#). The disease incidence data show a wandering behavior that is indicative of models with unit roots. The question of interest here is whether the two series tend to be “tethered together,” that is, tend to wander together. Engle and Granger (1987) used the term *cointegration* to describe this “tethering together” idea, which, in our setting, implies that each series has a single unit root and there exists some linear combination of the difference sequences $\nabla X_{t1}$ and $\nabla X_{t2}$ that is stationary. The cointegration concept has been used extensively in the econometrics literature for analyzing relationships. For an extensive bibliography in this area, see Engle and Granger (1991). Engle and Granger (1987) show that it is useful to use an error correction form similar to that in [Equation 8.23](#) (see also Problem 8.10) for describing the relationship between $X_{t1}$ and $X_{t2}$. Letting $\mathbf{X}_t=(X_{t1},X_{t2})'$, we consider the model

$\mathbf{X}_t=\boldsymbol{a}+\boldsymbol{\Phi}_1\mathbf{X}_{t-1}+\cdots+\boldsymbol{\Phi}_p\mathbf{X}_{t-p}+\boldsymbol{a}_t,$

where it is assumed, in this case, that $\boldsymbol{\Phi}(B)=\mathbf{I}-\boldsymbol{\Phi}_1B-\cdots-\boldsymbol{\Phi}_pB^p$ has a factor

We now consider the disease incidence data in Figure 10.8. Let X_t1 denote incidence of non-perforated appendicitis and X_t2 denote influenza incidence. Using tswge function aic5.wge and restricting our attention to AR(p) models with max p = 4, AIC selects an AR(1) model for the appendicitis data (X_t1) and an AR(3) for the influenza (X_t2) data. Using the function adfTest in the package fUnitRoots discussed in Example 8.6, the augmented Dickey–Fuller test gives t_DF = −1.74 with p-value 0.41 for the appendicitis data and t_DF = −2.48 with p-value 0.15 for the influenza incidence data. Thus, the hypothesis of a unit root is not rejected in either case. As noted in Section 8.3.5.2, failure to reject the null hypothesis of a unit root does not provide strong evidence that a unit root exists. However, since, in each case, a unit root cannot be rejected, we proceed to test for cointegration. We will run the Johansen trace test using the ca.jo function in R package ursa, to test for cointegration between the variables X_t1 and X_t2 The hypothesis H0: rank(C) = 0 versus H_a: rank(C) > 0 is rejected but H0: rank(C) = 1 versus H_a: rank(C) > 1 is not rejected, leading to a conclusion of cointegration. See Alder et al. (2010). Also see Johansen (1988, 1991) and Johansen and Juselius (1990) for more details concerning the various options available in ca.jo.

## 10.6 State-Space Models

The state-space model (sometimes called the dynamic linear model) was originally developed by Kalman (1960) and Kalman and Bucy (1961) for control of linear systems and has more recently become widely used for the analysis of time series data. The ARUMA models (univariate and multivariate) can be seen to be special cases of the broad class of time series models that can be obtained via the state-space approach. In this section, we give a brief and introductory treatment of these models and illustrate their usefulness.

State-space formulations depend on a state equation and an observation equation.

### 10.6.1 State Equation

The state equation is a VAR(1)-type expression giving the rule by which the v × 1 random vector X_t is generated from X_{t-1} for time points t = 1, 2, ..., n. Specifically, the state equation is given by

**X**_t = **F** **X**_{t-1} + **V**_t  (10.48)

where

- **F** is a v × v matrix
- **V**_t ~ MVN(**0**, **Γ**_V) is multivariate normal white noise (MVN stands for multivariate normal)
- The process is initiated with a vector **X**_0 ~ MVN(**μ**_0, **Γ**_0).

It should be noted that a more general form of the state equation replaces the constant matrix **F** with the matrices **F**_t.

### 10.6.2 Observation Equation

The assumption in state-space analysis is that observations are made on **Y**_t which is related to **X**_t via the observation equation.

**Y**_t = **G**_t **X**_t + **W**_t  (10.49)

$X_t = \Phi X_{t-1} + V_t$  (state equation),  
$Y_t = (0\ 0\ \dots\ 1) X_t$  (observation equation),

### 10.6.3 Goals of State-Space Modeling

Recall that in the case of ARMA and ARUMA modeling, we typically analyze the data in a realization in order to estimate the model parameters and then use the estimated model for purposes of forecasting/predicting future values, spectral estimation, etc. Given a state-space model

$$X_t = F X_{t-1} + V_t$$  
$$Y_t = G_t X_t + W_t$$

the fundamental goal is to estimate the underlying unobserved signal X_t given the observations Y_1, ..., Y_s for some time s. The typical procedure used to accomplish this goal is to

- 1. Estimate the parameters ($\mu_0$, $\Gamma_0$, $F$, $\Gamma_V$, $G_t$, and $\Gamma_W$) of the state-space model.
- 2. Use the estimated model to find the best linear estimate of $X_t$ (for some time $t$) in the mean-square sense. Specifically, we want to find $E(X_t \mid Y_1, ..., Y_s)$. For simplicity, we will use $\hat{X}_t^s$ to denote $E(X_t \mid Y_1, ..., Y_s)$, and we denote the mean-squared error by $\Gamma_t^s = E[(X_t - \hat{X}_t^s)(X_t - \hat{X}_t^s)^T]$. This step has three subcategories based on the relationship between time $t$ and the time of the last observed value, $s$.
  - a. *Prediction:* This is the case in which $s < t$. An example would be the one-step ahead forecasts $\hat{X}_2^1$, $\hat{X}_3^2$, ...
  - b. *Filtering:* The case in which $s = t$.
  - c. *Smoothing:* The case in which $s > t$. This case is called smoothing, since a time plot of $\hat{X}_1^s$, $\hat{X}_2^s$, ..., $\hat{X}_s^s$ tends to be smoother than plots of the one-step ahead forecasts $\hat{X}_1^0$, $\hat{X}_2^1$, ..., $\hat{X}_s^{s-1}$ or plots of the “filters” $\hat{X}_1^1$, $\hat{X}_2^2$, ..., $\hat{X}_s^s$.
