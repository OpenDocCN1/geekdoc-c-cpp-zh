GAMIT/GLOBK 是一种高精度 GPS 数据处理软件，广泛应用于地壳变形、板块运动等研究。本文介绍其基本安装流程与常见问题。

# ## 1. 软件安装

+   - 安装前需检查系统是否满足依赖库要求。
+   - 建议使用 Linux 或 macOS 环境。
+   - 配置环境变量时注意路径正确性。

| 系统 | 版本 | 状态 |
| --- | --- | --- |
| Ubuntu | 20.04 | 通过 |
| CentOS | 8 | 通过 |
| macOS | 12+ | 部分功能受限 |
