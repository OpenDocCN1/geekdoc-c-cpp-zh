We now consider the disease incidence data in Figure 10.8. Let X_t1 denote incidence of non-perforated appendicitis and X_t2 denote influenza incidence. Using tswge function aic5.wge and restricting our attention to AR(p) models with max p = 4, AIC selects an AR(1) model for the appendicitis data (X_t1) and an AR(3) for the influenza (X_t2) data. Using the function adfTest in the package fUnitRoots discussed in Example 8.6, the augmented Dickey–Fuller test gives t_DF = −1.74 with p-value 0.41 for the appendicitis data and t_DF = −2.48 with p-value 0.15 for the influenza incidence data. Thus, the hypothesis of a unit root is not rejected in either case. As noted in Section 8.3.5.2, failure to reject the null hypothesis of a unit root does not provide strong evidence that a unit root exists. However, since, in each case, a unit root cannot be rejected, we proceed to test for cointegration. We will run the Johansen trace test using the ca.jo function in R package ursa, to test for cointegration between the variables X_t1 and X_t2 The hypothesis H0: rank(C) = 0 versus H_a: rank(C) > 0 is rejected but H0: rank(C) = 1 versus H_a: rank(C) > 1 is not rejected, leading to a conclusion of cointegration. See Alder et al. (2010). Also see Johansen (1988, 1991) and Johansen and Juselius (1990) for more details concerning the various options available in ca.jo.
