
φ(B)(1 − B²)(1 − 1.732B + B²)^{λ₁}(1 − B + B²)^{λ₂}(Xₜ − μ) = θ(B)aₜ, (11.33)

where φ(B) and θ(B) are of orders p and q, respectively.

Woodward et al. (1998) examined ML estimation and argued for the use of the estimates λ̂₁ = λ̂₂ = 0.49 since these did the best job of removing a strong long-memory type 12-month cycle. The data were then transformed by (1 − B²)(1 − 1.732B + B²)^{0.49}(1 − B + B²)^{0.49}, and usual model identification techniques selected an AR(17) for the transformed data. The final 2-factor GARMA model for this data set is

(1 − 1.732B + B²)^{0.49}(1 − B + B²)^{0.49}(1 − B²)^{λ̂}φ̂(B)(Xₜ − X̄) = aₜ,

where φ̂(B) represents the Burg estimates

φ̂(B) = 1 + 3.23B + 3.23B² + 3.52B³ + 3.42B⁴ + 3.27B⁵ + 3.25B⁶ + 3.31B⁷ + 3.29B⁸ + 3.09B⁹ + 2.86B¹⁰ + 2.54B¹¹ + 1.83

with X̄ = 327.57 and σ̂ₐ² = 1.5.
