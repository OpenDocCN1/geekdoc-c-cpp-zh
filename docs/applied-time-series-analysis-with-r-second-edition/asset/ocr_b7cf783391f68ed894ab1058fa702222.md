p = pmin:pmax specifies the range of values for the AR order p to be used in the search for the best model. (default is p = 0:5)

q = qmin:qmax specifies the range of values for MA order q to be used in the search for the best model. (default is q = 0:2)

type specifies the criterion used to select the model. Choices are type = "aic", "bic", or "aicc". (default is "aic")

The program outputs:

type = the selection criterion used (e.g., type = "aic")
value is the value of the model identification criterion for the model selected.
p is the value of p in the selected ARMA(p,q) model
q is the value of q in the selected ARMA(p,q) model
phi is a vector containing the ML estimates of the p AR parameters
theta is a vector containing the ML estimates of the q MA parameters
vara is the white noise variance estimate for the selected model
