# 12.3.5 Pyramid Algorithm

While the wavelet coefficients can be computed from Equation 12.22, the pyramid algorithm introduced in the wavelet setting by Mallat (1989) provides an efficient method for calculating them. The pyramid algorithm is outlined in the following for a data set of length $n = 2^{J_0}$:

Step 1: Beginning with the data values $x_1, x_1, ..., x_n$ (which it is convenient to denote as $s_{0,1}, s_{0,2}, ..., s_{0,n}$), down-sample these into two sets, each containing $n/2$ values, to obtain $n/2$ coefficients: $s_{1,k}, k = 1, ..., n/2$ $n/2$ coefficients: $d_{1,k}, k = 1, ..., n/2$

Step 2: Retain $d_{1,k}, k = 1, ..., n/2,$ and down-sample $s_{1,k}, k = 1, ..., n/2$ to obtain $n/4$ coefficients: $s_{2,k}, k = 1, ..., n/4$ $n/4$ coefficients: $d_{2,k}, k = 1, ..., n/4$

Step 3: Retain $d_{2,k}, k = 1, ..., n/4,$ and down-sample $s_{2,k}, k = 1, ..., n/4$ to obtain $n/8$ coefficients: $s_{3,k}, k = 1, ..., n/8$ $n/8$ coefficients: $s_{3,k}, k = 1, ..., n/8$ $n/8$ coefficients: $d_{3,k}, k = 1, ..., n/8$

Step $J_0$: Retain $d_{J_0-1,k}, k = 1, 2$ and down-sample $s_{J_0-1,k}, k = 1, 2$ to obtain 1 coefficient $s_{J_0,1}$ 1 coefficient $d_{J_0,1}$

Consider the case $J_0 = 3$. Then the eight retained coefficients are $d_{1,k}, k = 1, ..., 4$ $d_{2,k}, k = 1, 2$ $d_{3,1}$ and $s_{3,1}$,

which are the components of the vector w in Equation 12.22.
