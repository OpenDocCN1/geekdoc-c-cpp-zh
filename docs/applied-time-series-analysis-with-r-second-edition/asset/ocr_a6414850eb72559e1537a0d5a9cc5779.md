$$\hat{X}_{t_0}(\ell)=\hat{X}_{t_0}(\ell-s)+(1-1)\bar{X}$$ $$=\hat{X}_{t_0}(\ell-s),$$

which take the form

$$X_{t_0-s+1}=\hat{X}_{t_0}(1)=\hat{X}_{t_0}(s+1)=\hat{X}_{t_0}(2s+1)=\dots$$ $$X_{t_0-s+2}=\hat{X}_{t_0}(2)=\hat{X}_{t_0}(s+2)=\hat{X}_{t_0}(2s+2)=\dots$$ $$\vdots$$ $$X_{t_0}=\hat{X}_{t_0}(s)=\hat{X}_{t_0}(2s)=\hat{X}_{t_0}(3s)=\dots$$

Thus, for the simple seasonal model in Equation 6.48, the last s data values are repeatedly forecast into the future. A realization of length n = 48 from the model

$$(1-B^{12})(X_t-10)=a_t,\qquad(6.50)$$

is shown in Figure 6.8 along with forecasts, $\hat{X}_{48}(\ell)$, $\ell=1,2,...,24$. The nature of the seasonality of the data and the forecasts is clear.

Forecasts from the more general seasonal model

$$\phi(B)\Phi(B^S)(1-B^S)(X_t-\mu)=\theta(B)\Theta(B^S)a_t,$$

for which the only nonstationary components are seasonal, that is, $d=0$, will behave similarly, but the forecasts in this case will not be a precise copy of the last s data values observed.
