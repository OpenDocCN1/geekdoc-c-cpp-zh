$$\phi(B)=\prod_{i=1}^{p}(1-\alpha_iB),$$

$$\phi(B)X_t=(1-\alpha_1B)(1-\alpha_2B)\cdots(1-\alpha_pB)X_t=a_t,$$

$$a_1^t\nabla_{\alpha_1}^{-t}a_2^t\nabla_{\alpha_2}^{-t}\cdots a_p^t\nabla_{\alpha_p}^{-t}X_t=a_t \tag{3.A.1}$$

Further assuming $|\alpha_i|<1$, $i=1,\ldots,p$, then using the procedure described in the AR(1) and AR(2) cases yields the result.
