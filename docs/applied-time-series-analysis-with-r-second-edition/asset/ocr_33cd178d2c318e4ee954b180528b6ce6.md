(⇒) Suppose X(t) is covariance stationary. Then, since E[X(t)] does not depend on t, it follows from Equation 1.13 that E[cosγ'] = E[sinγ'] = 0, and so that φ(1) = 0. Likewise, since E[X(t)X(t + h)] depends on h but not on t, it follows from the last equation in Equation 1.14 that E[cos2γ'] = E[sin2γ'] = 0, that is, that φ(2) = 0 and the result follows.

We note that if γ' ~ Uniform[0, 2π], then

$$\varphi(u)=\int_{0}^{2\pi} e^{i u y}\left(\frac{1}{2\pi}\right)dy = \frac{e^{2\pi i u}-1}{2\pi i u},$$

so that φ(1) = φ(2) = 0, and, thus, the uniform [0, 2π] distribution satisfies the condition on γ', and the resulting process X(t) = C cos(λt + γ') is stationary.

Figure 1.6 shows three realizations from the process described in Equation 1.11 with λ = 0.6 and γ' ~ 𝒰[0, 2π]. The realization in Figure 1.6a is for the case in which γ' = 1.5. Unlike the realizations in Figures 1.3 and 1.5, the behavior in Figure 1.6a is very deterministic. In fact, inspection of the plot would lead one to believe that the mean of this process depends on t. However, this is not the case since γ' is random. For example, Figure 1.6b and c shows two other realizations for different values for the random variable γ'. Note that the effect of the random variable γ' is to randomly shift the “starting point” of the cosine wave in each realization. γ' is called the phase shift. These realizations are simply three realizations from the ensemble of possible realizations. Note that for these three realizations, X(10) equals 0.35, 0.98, and −0.48, respectively, which is consistent with our finding that E[X(t)] does not depend on t.
