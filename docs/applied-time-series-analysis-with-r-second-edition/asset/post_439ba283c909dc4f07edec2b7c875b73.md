## Appendix 1A: Fourier Series
In Definition 1.15, we define the periodogram of a discrete time series $X_t$ to be

I. $I(f_j)=\hat{\sigma}_X^2+2\sum_{k=1}^{n-1}\hat{\gamma}_k\cos2\pi f_j k,$  (1A.1)

where $f_j$ are the harmonics of the fundamental frequency $1/n$. Specifically,

$f_j=j/n,\quad j=1,\dots,n/2\ (\text{if }n\text{ is even})$ 
$=j/n,\quad j=1,\dots,m\ (\text{if }n\text{ is odd and }n=2m+1).$

It is interesting to note that the periodogram has two useful alternate representations. The periodogram in Equation 1A.1 can be obtained as $1/n$ times the modulus squared of the Fourier transform of the data as given by Equation 1A.2.

II. $I(f_j)=\frac{1}{n}\left|\sum_{t=1}^{n}x_t e^{(-2\pi i j t / n)}\right|^2.$  (1A.2)

The proof of the equality of forms Equations 1A.1 and 1A.2 is left as Problem 1.20.

The third form of the periodogram involves the Fourier series. In this appendix, we discuss the topic of fitting a Fourier series to a discrete time series realization $x_t$, $t = 1, ..., n$, and we assume that $n = 2m + 1$ is odd. That is, we approximate $x_t$ using a finite Fourier series

$\displaystyle \sum_{j=1}^{m}\left[a_j\cos\left(\frac{2\pi j t}{n}\right)+b_j\sin\left(\frac{2\pi j t}{n}\right)\right].$

The coefficients $a_j$ and $b_j$ are estimated using least squares, in order to find the $a_j$ and $b_j$ that minimize

$Q = \sum_{t=1}^{n}\left\{x_t - \sum_{j=1}^{m}\left(a_j\cos\left(\frac{2\pi j t}{n}\right)+b_j\sin\left(\frac{2\pi j t}{n}\right)\right)\right\}^2.$ (1A.3)

The $a_j$ and $b_j$, $j = 1, ..., m$ that minimize $Q$ in Equation 1A.3 are

$a_j = \frac{2}{n}\sum_{t=1}^{n}x_t\cos\left(\frac{2\pi j t}{n}\right)=\frac{2}{n}\sum_{t=1}^{n}(x_t-\bar{x})\cos\left(\frac{2\pi j t}{n}\right).$

$b_j = \frac{2}{n}\sum_{t=1}^{n}x_t\sin\left(\frac{2\pi j t}{n}\right)=\frac{2}{n}\sum_{t=1}^{n}(x_t-\bar{x})\sin\left(\frac{2\pi j t}{n}\right).$

The second equality in each expression follows from the fact that

$\displaystyle \sum_{t=1}^{n}\cos\left(\frac{2\pi j t}{n}\right)=\sum_{t=1}^{n}\sin\left(\frac{2\pi j t}{n}\right)=0,$

for each $j$. Using this terminology, the third form of the periodogram is given by

III. $I(f_j)=\frac{n}{4}(a_j^2+b_j^2),\quad j = 1, ..., m.$ (1A.4)

Using Parseval's equality (see Jenkins and Watts, 1968), we obtain

$\frac{1}{n}\sum_{t=1}^{n}(x_t-\bar{x})^2=\frac{1}{2}\sum_{j=1}^{m}(a_j^2+b_j^2),\quad j = 1, ..., m.$ (1A.5)

The result in Equation 1A.5 gives an analysis of variance breakdown showing the contribution of each harmonic to the sample variance. That is, large values of $a_j^2 + b_j^2$ indicate the presence of frequency behavior at or near $f_j = j/n$ in the data. The proof of the equality of Equation 1A.4 with the other two forms is left as Problem 1.20.

When $n = 2m$ is even, the formulas discussed earlier vary slightly. Specifically, the formulas for $a_j$ and $b_j$ hold for $j = 1, ..., m - 1$. However,

$a_m = \frac{1}{n}\sum_{t=1}^{n}(-1)^t x_t,\; b_m = 0,\;\text{and}\; I(f_m)= n a_m^2.$

## Appendix 1B: R Commands
As mentioned in the Preface you should install and load the R command library tswge. Some of the commands listed here are simply Base R commands that do not require the installation of a special library. These will be noted as Base R commands. R commands that perform the computations and plot results associated with topics covered in Chapter 1 fall into two categories:

- 1. Basic computations and plots
- 2. “Combination routines” that provide graphical output of related plots for pedagogical purposes

For example, plot.sample.wge plots a realization, sample autocorrelations, periodogram, and smoothed periodogram based on the Parzen window. Examination of these four plots is a typical step in understanding the features of a time series realization.

- 1. Basic Computation Routines for Chapter 1
- a. mean(x) (base R function): calculates the mean of a time series realization where x is a vector containing the time series realization $x_t$, $t = 1, ..., n$.
- Example: The basic R command
data(ss08); ssm = mean(ss08)

calculates the sample mean of the sunspot data in tswge data set ss08 and places it in variable ssm. In this case ssm = 52.24385.

b. The tswge R function
`plotts.wge(x)`
provides a simplified use of the basic R plot command where x is a vector containing the time series realization x_t, t = 1, ..., n. For more flexibility use the basic R command plot.
*Example:* `data(airline); airlog = log(airline); plotts.wge(airlog)` plots the log airline data shown in Figure 1.25a.

c. `acf(x, lag.max, type, plot)` (base R function): calculates (and optionally plots) the sample autocorrelations (or sample autocovariances and sample variance) of the time series realization where
x is a vector containing the time series realization x_t, t = 1, ..., n.
lag.max is the maximum lag at which to calculate the sample autocorrelations (or covariances)
type = "correlation" (default) produces the sample autocorrelations,
"covariance" specifies the autocovariances, and
"partial" indicates the partial autocorrelations (discussed in Chapter 8).
plot is a logical variable. plot = "TRUE" (default) produces a plot of the sample autocorrelations (or autocovariances)
*Example:* `data(hadley); tempaut = acf(x = hadley, lag.max = 25)`
calculates and plots the first 25 sample autocorrelations for the global temperature data in file hadley that are shown in Figure 1.24a. The sample autocorrelations are placed in the vector tempaut$acf (which has 26 elements counting tempaut$acf[1] = 1, i.e. the sample autocorrelation at lag 0). If type = "covariance" is selected, then the vector tempaut$acf contains the sample autocovariances, and tempaut$acf[1] contains the sample variance (using the divisor n).

d. `period.wge(x, dbcalc, plot)` (tswge R function) calculates and alternatively plots the periodogram,.
x is a vector containing the time series realization x_t, t = 1, ..., n.
dbcalc is a logical variable. dbcalc = "TRUE" (default) calculates the periodogram on the log scale (in dB, that is 10*log10(periodogram))

plot is a logical variable. plot = "TRUE" (default) produces a plot of the periodogram (in log or non-log scale depending on dbcalc).

Example:

```
data(ss08)
per = period(ss08)
```

calculates and plots the periodogram (in dB). The vectors per$freq and per$pgram contain the frequencies and associated periodogram values (log or non-log)

e. parzen.wge(x, dbcalc, trunc, plot) (tswge R function) calculates and alternatively plots the smoothed periodogram based on the Parzen window.

x is a vector containing the time series realization x_t, t = 1, ..., n.

dbcalc is a logical variable. dbcalc = "TRUE" (default) calculates the smoothed spectral estimator on the log scale (in dB)

trunc (integer ≥0) specifies the truncation point.

trunc = 0 (default) (or no value for trunc is specified) indicates that the default truncation point is M = 2√n

trunc > 0 is a user specified truncation point, i.e. calculations will be based on M = trunc

plot is a logical variable. plot = "TRUE" (default) produces a plot of the smoothed spectral estimator (in log or non-log scale depending on dB).

Example:

```
data(ss08); sparz=parzen.wge(ss08)
```

calculates and plots the smoothed spectral estimator (in dB) for the sunspot data using the default truncation point, M = 2√260 = 32.

The vectors ssparz$freq and ssparz$pgram contain the frequencies and associated Parzen-based spectral estimates.

n = length of realization to be generated (t in the above formula specifies the integers from 1 to n)
