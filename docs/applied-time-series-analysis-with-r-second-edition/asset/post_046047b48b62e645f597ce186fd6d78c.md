### 8A.5.1 Measuring Patterns in the GPAC Array

One measure of the strength of the GPAC identification pattern is the W-statistic. For a given P and Q, then for each j ≤ P and k ≤ Q, the W-statistic measures the strength of the GPAC pattern associated with an ARMA(j,k) model. Using the notation in Tables 8A.2 and 8A.3, then the W-statistic measures the extent to which φ_{kk}^{(j)}, φ_{kk}^{(j+1)}, φ_{kk}^{(j+2)}, φ_{kk}^{(j+3)} are “constant” and the values φ_{k+1,k+1}^{(j)}, φ_{k+2,k+2}^{(j)}, φ_{k+3,k+3}^{(j)} are near zero. That is, only four values are used to assess the constant behavior and only three to measure the zero behavior since these behaviors become more variable as you move away from the true p, q location. For this reason, we also weight the constants and zeros. For example, implementation in GW-WINKS uses the weighted average of the constants

A = (wc0 φ_{kk}^{(j)} + wc1 φ_{kk}^{(j+1)} + wc2 φ_{kk}^{(j+2)} + wc3 φ_{kk}^{(j+3)}) / (wc0 + wc1 + wc2 + wc3).

Similarly, we weight the three “zeros” using the weights wz1, wz2, and wz3. The W-statistic is then calculated as W = (C + Z)/|A| where C is the (weighted) sample standard deviation of the four “constants” and Z is the square root of the (weighted) average sum of squares of the “zeros”. The W-statistic uses wc0 = wc1 = 1, wc2 = 0.8, wc3 = 0.6, and wz1 = 1, wz2 = 0.8, wz3 = 0.6. Clearly, smaller values of W suggest a stronger pattern. For the sample GPAC array in Table 8A.5, the top three W-statistic choices are

p = 4, q = 3, W-STAT = 0.139.

p = 4, q = 4, W-STAT = 0.357.

p = 4, q = 0, W-STAT = 0.756.

Consequently, the W-statistic correctly identifies the realization as coming from an ARMA(4,3) model.

**Computing the GPAC Array:** The GPAC array is not implemented in R package tswge. To compute a sample GPAC for a realization in GW-WINKS, select the GPAC array option on the Time Series Analysis menu. You will be asked to specify P and Q. The GPAC array, such as that in Figure 8A.5, will be shown along with the top three order choices based on the W-statistic.

### 8A.6 A Final Note about Pattern-Recognition Methods

Other pattern-recognition methods have been developed for ARMA(p,q) model identification based on arrays, but these will not be discussed here. Other such techniques include the corner method (Beguin et al., 1980), R- and S-arrays (Gray et al., 1978), and extended sample autocorrelation function (ESACF) arrays (Tsay and Tiao, 1984). We reiterate the fact that we recommend the use of AIC-based approaches for most situations. However, pattern-recognition methods can provide useful supplemental information in cases where special care in the modeling process is called for.

## APPENDIX 8B: MODEL IDENTIFICATION FUNCTIONS IN tswge

The tswge functions `aic.wge` and `aic5.wge` can be used to select ARMA(p,q) models for a set of data using either AIC, BIC, or AICC.

- a. `aic.wge(x, p = pmin:pmax, q = qmin:qmax, type)` is a function that finds the best ARMA(p,q) model within the p and q ranges in the call statement using the selection criterion specified by `type`.

  - `x` is a vector containing the realization to be analyzed.
  - `p = pmin:pmax` specifies the range of values for the AR order p to be used in the search for the best model. (default is p = 0:5)
  - `q = qmin:qmax` specifies the range of values for MA order q to be used in the search for the best model. (default is q = 0:2)
  - `type` specifies the criterion used to select the model. Choices are `type = "aic"`, `"bic"`, or `"aicc"`. (default is `"aic"`)

The program outputs:

- `type` is the selection criterion used (e.g., `type = "aic"`)
- `value` is the value of the model identification criterion for the model selected.
- `p` is the value of p in the selected ARMA(p,q) model.
- `q` is the value of q in the selected ARMA(p,q) model.
- `phi` is a vector containing the ML estimates of the p AR parameters.
- `theta` is a vector containing the ML estimates of the q MA parameters.
- `vara` is the white noise variance estimate for the selected model.

**NOTES:**

- 1. ML parameter estimation is performed using base R function `arima`.
- 2. In order, for example, to choose the 'best' AR model, then use `q = 0:0`.

**Example:** In Example 8.3a we used `aic.wge` to identify the orders of the ARMA(p,q) model used to generate the data in Figure 3.18a (data set `fig3.18a` in tswge) allowing p to range from 0 to 8 and q to range from 0 to 4. The following commands can be used:

```
data(fig3.18a)
aic.wge(fig3.18a, p = 0:8, q = 0:4, type = "aic")
```

Inspecting the output, it can be seen that AIC correctly selects an AR(4) model. The output includes the AIC value (the minimum of all those calculated within the specified range of p and q), the selected p and q along with associated ML parameters estimates, etc.

- b. `aic5.wge(x, p = pmin:pmax, q = qmin:qmax, type)` is a function that finds the five best ARMA(p,q) models within the p and q ranges in the call statement using the selection criterion specified by `type`.

  - `x` is a vector containing the realization to be analyzed.
  - `p = pmin:pmax` specifies the range of values for the AR order p to be used in the search for the best model. (default is p = 0:5)
  - `q = qmin:qmax` specifies the range of values for MA order q to be used in the search for the best model. (default is q = 0:2)
  - `type` specifies the criterion used to select the model. Choices are `type = "aic"`, `"bic"`, or `"aicc"`. (default is `"aic"`)

The program outputs the model orders of the top five models (and associated criterion values) within the range of p and q specified in the function statement.

**NOTES:**

- 1. ML parameter estimation is performed using base R function `arima` and tswge function `aic.wge`.
- 2. In order, for example, to choose the 'best' AR model, then use `q = 0:0`.
- 3. After model orders are obtained, then parameter estimates can be obtained using `est.arma.wge` if q > 0 or `est.ar.wge` if q = 0. See Appendix 7B.

**Example:** Referring back to Example 8.3a, in order to find the five “best” models for fitting the data in `fig3.18a` and allowing p to range from 0 to 8 and q to range from 0 to 4 we use the following commands:

```
data(fig3.18a)
aic5.wge(fig3.18a, p = 0:8, q = 0:4, type = "aic")
```

The output from `aic5.wge` is as follows:

Five smallest values of aic

```
p q aic
4 0 0.1267913
4 1 0.1366794
5 0 0.1366926
5 1 0.1431634
6 0 0.1453974
```

From the output we see that an ARMA(4,0) (that is an AR(4)) is correctly chosen as the best fitting model with AIC = 0.1267913. The second best fitting model according to AIC is an ARMA(4,1) with AIC = 0.1366794 (notice that AIC for the ARMA(4,1) is larger than the one for the AR(4)). In order to estimate the parameters of the selected AR(4) model, you could use the command

```
est.ar.wge(fig3.18a, p = 4)
```

or

```
est.arma.wge(fig3.18a, p = 4, q = 0)
```
