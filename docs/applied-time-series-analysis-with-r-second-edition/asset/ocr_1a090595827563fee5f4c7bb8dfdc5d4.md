$\hat{e}_{pt}^{(0)} = X_t - \sum_{j=1}^{p} \hat{\phi}_{jp}^{(0)} X_{t-j}$

are obtained. Note that if $q > 0$, then $\hat{e}_{pt}^{(0)}$ is not an estimator of white noise and will contain information about the model. The first iterated regression model

$X_t = \sum_{j=1}^{p} \phi_{jp}^{(1)} X_{t-j} + \beta_{1p}^{(1)} e_{p,t-1}^{(0)} + e_{pt}^{(1)}$

$t = p + 2, ..., n$ is then formed. Let $\hat{\phi}_{jp}^{(1)}$ and $\hat{\beta}_{1p}^{(1)}$ denote the corresponding least squares estimates. If $q = 1$, then the $\hat{\phi}_{jp}^{(1)}$ is consistent for $\phi_j$, $j = 1, ..., p$. If $q > 1$, the procedure is continued, by calculating residuals

$\hat{e}_{pt}^{(1)} = X_t - \sum_{j=1}^{p} \hat{\phi}_{jp}^{(1)} X_{t-j} - \hat{\beta}_{1p}^{(1)} \hat{e}_{p,t-1}^{(0)}$

and forming a second iterated regression model. Tsay and Tiao (TT) estimates $\hat{\phi}_j$, $j = 1, ..., p$ for an ARMA$(p,q)$ model are given by $\hat{\phi}_{jp}^{(q)}$, $j = 1, ..., p$.

Tsay and Tiao (1984) showed that it is not necessary to go through this entire procedure, but note that the TT estimates $\hat{\phi}_{jp}^{(q)}$ can be obtained using the recursion

$\hat{\phi}_{jk}^{(m)} = \hat{\phi}_{jk+1}^{(m-1)} - \frac{\hat{\phi}_{j-1,k}^{(m-1)} \hat{\phi}_{k+1,k+1}^{(m-1)}}{\hat{\phi}_{kk}^{(m-1)}}$

where $j = 1, ..., k$ with $k \le 1$. The recursion is initialized with $\hat{\phi}_{0k}^{(m-1)} = -1$ and with estimates $\hat{\phi}_{jk}^{(0)}$ for the case $q = 0$ obtained using a method for estimating the parameters of an AR process.
