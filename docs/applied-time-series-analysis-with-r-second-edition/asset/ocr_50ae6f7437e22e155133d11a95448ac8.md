# 2.2 Stationary General Linear Processes

Many of the statistical time series that we will study can be viewed as the output, $X_t$, of a linear filter with white noise input. Such a process is called a *general linear process*, which is defined in the following.

# Definition 2.1 (General Linear Process) The process $X_t$, $t = 0, \pm 1, \pm 2, \dots$ given by

$X_t - \mu = \sum_{j=0}^{\infty} \psi_j a_{t-j}$  (2.5)

is defined to be a *general linear process* if $a_t$ is a white noise process with zero mean and finite variance and $\sum_{j=0}^{\infty} |\psi_j| < \infty$.

Using the backshift operator $B$, Equation 2.5 can be written as

$X_t - \mu = \sum_{j=0}^{\infty} \psi_j B^j a_t = \psi(B) a_t$

where

$\psi(B) = \sum_{j=0}^{\infty} \psi_j B^j$.

In this section, we will consider the problem of finding stationarity conditions for $X_t$ in Equation 2.5 along with expressions for the autocovariance function and power spectrum.
