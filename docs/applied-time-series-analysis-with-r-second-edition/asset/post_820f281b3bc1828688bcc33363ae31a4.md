
\[
\rho_k = \phi_1 \rho_{k-1} + \cdots + \phi_p \rho_{k-p}, \quad (3.38)
\]

The first \(p\) equations specified in Equation 3.38 can be written as

\[
\begin{aligned}
\rho_1 &= \phi_1 + \phi_2 \rho_1 + \cdots + \phi_p \rho_{p-1},\\
\rho_2 &= \phi_1 \rho_1 + \phi_2 + \cdots + \phi_p \rho_{p-2},\\
&\vdots\\
\rho_p &= \phi_1 \rho_{p-1} + \phi_2 \rho_{p-2} + \cdots + \phi_p,
\end{aligned} \tag{3.39}
\]

The equations in Equation 3.39 are called the Yule–Walker equations. When the coefficients \(\phi_1,\dots,\phi_p\) are known, the Yule–Walker equations are \(p\) equations that can be solved for the \(p\) unknowns \(\rho_1,\dots,\rho_p\). Note that after the first \(p\) autocorrelations are found by solving the Yule–Walker equations, then \(\rho_k, k > p\) can iteratively be found using the relationship in Equation 3.38.

Also note that for a given set of data assumed to follow an unknown AR(p) model, the model parameters \(\phi_1,\dots,\phi_p\) can be estimated by first replacing \(\rho_k, k = 1, 2, \dots, p\) with the estimates \(\hat{\rho}_k, k = 1, 2, \dots, p\) and solving the resulting \(p\) equations for \(\hat{\phi}_1, \dots, \hat{\phi}_p\). These estimates are called the Yule–Walker estimates and will be discussed in more detail in Chapter 7.

In order to find \(\gamma_0 = \sigma_X^2\), multiply every term in Equation 3.17 by \(X_t\) and take expectations to obtain

\[
\gamma_0 - \phi_1 \gamma_1 - \cdots - \phi_p \gamma_p = E[X_t a_t], \tag{3.40}
\]

The expectation \(E[X_t a_t]\) can be found by post-multiplying each term in Equation 3.17 by \(a_t\) and taking expectations, which gives

\[
E[X_t a_t] = \sum_{k=1}^{p} \phi_k E[a_t X_{t-k}] + \sigma_a^2 = \sigma_a^2, \tag{3.41}
\]

since \(E[a_t X_{t-k}] = 0\) for \(k > 0\). From Equations 3.40 and 3.41, we find that

\[
\gamma_0 - \phi_1 \gamma_1 - \cdots - \phi_p \gamma_p = \sigma_a^2, \tag{3.42}
\]

and hence

\[
\sigma_X^2(1 - \phi_1\rho_1 - \cdots - \phi_p\rho_p) = \sigma_a^2.
\]

Therefore,

\[
\sigma_X^2 = \frac{\sigma_a^2}{1 - \phi_1\rho_1 - \cdots - \phi_p\rho_p}. \tag{3.43}
\]

## 3.2.5 Linear Difference Equations

We have discussed the fact that autocorrelations of an AR(p) model satisfy Equation 3.37 and can be found using Equation 3.39. However, the behavior of these autocorrelations is not immediately apparent. The equation in Equation 3.37 is an example of a linear homogeneous difference equation with constant coefficients, which we briefly discuss here.

A function, \(g_k\), defined on a set of consecutive integers, \(I\), is said to satisfy (or is a solution of) a linear homogeneous difference equation of order \(m\) with constant coefficients, if \(g_k\) is such that

\[
g_k - b_1 g_{k-1} - \cdots - b_m g_{k-m} = 0, \tag{3.44}
\]

for \(k \in I\), where \(b_1, b_2, \dots, b_m\) are constants. Thus, from Equation 3.37, it follows that \(\rho_k\) satisfies a \(p\)th-order linear homogeneous difference equation with constant coefficients for \(k > 0\). The general solution to the difference equation in Equation 3.44 is well known (see Brockwell and Davis, 1991). Specifically, if \(g_k\) satisfies Equation 3.44 for \(k > 0\), then

\[
g_k = \sum_{i=1}^{\nu} \sum_{j=0}^{m_i-1} C_{ij} k^j r_i^{k} \tag{3.45}
\]

where the \(r_i\)'s are the roots of the characteristic equation

\[
1 - b_1 z - b_2 z^2 - \cdots - b_m z^m = 0,
\]

\(\nu\) is the number of distinct roots, \(m_i\) is the multiplicity of \(r_i\) (i.e., if \(r_i\) is repeated once, \(m_i = 2\), and if \(r_i\) is not repeated, then \(m_i = 1\)), \(\sum_{i=1}^{\nu} m_i = m\), and \(C_{ij}\) are uniquely determined by the initial conditions

\[
\begin{aligned}
g_1 &= h_1\\
g_2 &= h_2\\
&\vdots\\
g_m &= h_m
\end{aligned}
\]

where the \(h_j\) are constants. When there are no repeated roots, Equation 3.45 simplifies to

\[
g_k = C_1 r_1^{-k} + C_2 r_2^{-k} + \cdots + C_m r_m^{-k}. \tag{3.46}
\]

From Equations 3.38 and 3.45, it follows that for an AR(p) model,

\[
\rho_k = \sum_{i=1}^{\nu} \sum_{j=0}^{m_i -1} C_{ij} k^j r_i^{-k}, \tag{3.47}
\]

where

\[
\sum_{i=1}^{\nu} m_i = p,
\]

and the initial conditions are given by

\[
\rho_k = \phi_1 \rho_{k-1} + \cdots + \phi_p \rho_{k-p}, \quad k = 1, 2, \dots, p. \tag{3.48}
\]

Note that \(\rho_k \to 0\) as \(k \to \infty\) in Equation 3.47 if and only if \(|r_i| > 1\), \(i = 1, \dots, p\), and thus it follows from Theorem 3.2 and the comments following it that \(\rho_k \to 0\) as \(k \to \infty\) is a necessary and sufficient condition for the model in Equation 3.17 to be a causal and stationary AR(p) process. In addition, note that if none of the roots are repeated, it follows from Equation 3.46 that for \(k > 0\)

\[
\rho_k = C_1 r_1^{-k} + C_2 r_2^{-k} + \cdots + C_p r_p^{-k}. \tag{3.49}
\]

As noted above, for an AR(p) process, it follows from Equation 3.47 that \(\rho_k \to 0\) (and equivalently \(\gamma_k \to 0\)) as \(k \to \infty\). From Theorem 1.1, it then follows that \(\Gamma_k\) and \(\rho_k\) defined in Equations 1.2 and 1.3, respectively, are positive definite for each integer \(k > 0\) in the case of an AR process.

### EXAMPLE 3.5: AUTOCORRELATIONS OF AN AR(1) MODEL

For the case of the AR(1) model \(X_t - \phi_1 X_{t-1} = a_t\), the autocorrelation \(\rho_k\) satisfies the difference equation

\[
\rho_k - \phi_1 \rho_{k-1} = 0, \quad k > 0. \tag{3.50}
\]

Since there is only one root (and thus no repeated roots), we use Equation 3.49, and \(\rho_k\) satisfies

\[
\rho_k = C_1 r_1^{-k}, \quad k > 0.
\]

Also, for an AR(1) model, \(r_1 = 1 / \phi_1\), so this can be rewritten

\[
\rho_k = C_1 \phi_1^{k}, \quad k > 0. \tag{3.51}
\]

Since \(\rho_0 = 1\), it follows from Equation 3.50 that \(\rho_1 - \phi_1 \rho_0 = 0\). Thus, \(\rho_1 = \phi_1\), and thus \(C_1 = 1\). Notice that \(\rho_0 = 1 = \phi_1^0\), so

\[
\rho_k = \phi_1^{k}, \quad k \ge 0. \tag{3.52}
\]

Since \(\rho_k = \rho_{-k}\), the autocorrelation function for an AR(1) process satisfies \(\rho_k = \phi_1^{|k|}\), which is the result given earlier in Equation 3.32.

**NOTE:** In general, for the \(m\)th-order difference equation with no repeated roots, the values \(C_1, \dots, C_m\) are chosen in such a way that the starting values, \(g_j, g_{j-1}, \dots, g_{j+1-m}\) also satisfy Equation 3.46 although they do not satisfy Equation 3.44.

**NOTE:** In Equation 3.77, we will give an expression for Equation 3.49 that provides better insight into the behavior of the autocorrelation function of an AR(p) model.

## 3.2.6 Spectral Density of an AR(p) Model

When the roots are distinct, the autocorrelation function is given by

\[
\rho_k = C_1 r_1^{-k} + C_2 r_2^{-k}, \quad k > 0. \tag{3.55}
\]

where \(C_1\) and \(C_2\) are uniquely determined by \(\rho_1\) and \(\rho_2\). These first two autocorrelations can be obtained by solving the Yule–Walker equations

\[
\begin{aligned}
\rho_1 &= \phi_1 + \phi_2\rho_1,\\
\rho_2 &= \phi_1\rho_1 + \phi_2.
\end{aligned}
\]

which gives

\[
\begin{aligned}
\rho_1 &= \frac{\phi_1}{1-\phi_2},\\
\rho_2 &= \frac{\phi_1^2 + \phi_2 - \phi_2^2}{1-\phi_2}.
\end{aligned} \tag{3.56}
\]

The roots \(r_1\) and \(r_2\) in Equation 3.55 are (possibly complex) solutions to the characteristic equation \(1 - \phi_1 z - \phi_2 z^2 = 0\).

Therefore,

\[
r_j = \frac{-\phi_1 \pm \sqrt{\phi_1^2 + 4\phi_2}}{2\phi_2}, \quad j=1,2.
\]

Note that the characteristic equation can be written in factored form as

\[
\begin{aligned}
1-\phi_1z-\phi_2z^2 &= (1-r_1^{-1}z)(1-r_2^{-1}z)\\
&= 1-(r_1^{-1}+r_2^{-1})z+r_1^{-1}r_2^{-1}z^2,
\end{aligned}
\]

and thus

\[
\phi_1 = r_1^{-1} + r_2^{-1}, \tag{3.57}
\]

\[
\phi_2 = -r_1^{-1}r_2^{-1}. \tag{3.58}
\]

When \(X_t\) is stationary, Theorem 3.2 implies that \(|r_1^{-1}| < 1\) and \(|r_2^{-1}| < 1\), so it follows from Equation 3.58 that \(|\phi_2| < 1\).

Additionally, from Equations 3.43 and 3.56, it follows that

\[
\sigma_X^2 = \frac{(1-\phi_2)\sigma_a^2}{(1-\phi_2)[(1-\phi_2)^2 - \phi_1^2]} \tag{3.59}
\]

**Case 1—Roots are distinct:** As previously mentioned, in this case, \(\rho_k\) is given by Equation 3.55 with \(C_1\) and \(C_2\) uniquely determined by Equation 3.56. So it follows that

\[
\rho_1 = C_1 r_1^{-1} + C_2 r_2^{-1} = \frac{\phi_1}{1 - \phi_2}
\]

\[
\rho_2 = C_1 r_1^{-2} + C_2 r_2^{-2} = \frac{\phi_1^2 + \phi_2 - \phi_2^2}{1 - \phi_2}.
\]

Denoting \(\alpha_1 = r_1^{-1}\) and \(\alpha_2 = r_2^{-1}\), and solving these equations gives

\[
C_1 = \frac{\alpha_1(1 - \alpha_2^2)}{(\alpha_1 - \alpha_2)(1 + \alpha_1 \alpha_2)}
\]

and

\[
C_2 = \frac{-\alpha_2(1 - \alpha_1^2)}{(\alpha_1 - \alpha_2)(1 + \alpha_1 \alpha_2)}
\]

which yields

\[
\rho_k = \frac{(1 - \alpha_2^2)\alpha_1^{k+1} - (1 - \alpha_1^2)\alpha_2^{k+1}}{(\alpha_1 - \alpha_2)(1 + \alpha_1 \alpha_2)}, \quad k \ge 0. \tag{3.60}
\]

We consider two cases in which the roots are distinct.

- **1. Real roots, that is, \(\phi_1^2 + 4\phi_2 > 0\):** In this case, the characteristic polynomial can be written in factored form as

\[
\phi(z) = (1 - r_1^{-1}z)(1 - r_2^{-1}z)
\]
