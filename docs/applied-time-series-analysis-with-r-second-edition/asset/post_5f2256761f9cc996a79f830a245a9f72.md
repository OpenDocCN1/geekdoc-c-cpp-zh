
$$E[X_{t-k}X_t]=0.8E[X_{t-k}X_{t-1}]+E[X_{t-k}a_t],\qquad(1.10)$$

and since $E[X_{t-k}a_t]=0$, Equation 1.10 simplifies to $\gamma_k=0.8\gamma_{k-1}$, which implies $\gamma_k=\gamma_0(0.8)^k$ and $\rho_k=0.8^k$. Thus, according to Corollary 1.1, $\overline{X}$ is ergodic for $\mu$ for model (1.8). See Section 3.2.4.

In order to see the impact of condition (1.7) on the ability to estimate $\mu$ based on a single realization, note that $\rho_1=0.8$, so that $X_t$ and $X_{t+1}$ are providing correlated (and somewhat redundant) information about $\mu$, but, for example, $\rho_{20}=0.01$, so that $X_t$ and $X_{t+20}$ are providing nearly uncorrelated information about $\mu$. ## EXAMPLE 1.3: A STATIONARY COSINE PROCESS

Define $X(t)$ for $t\in(-\infty,\infty)$ by

$$X(t)=C\cos(\lambda t+\gamma),\qquad(1.11)$$

where

- $C$ and $\lambda$ are real-valued constants
- $\gamma$ is a random variable

Then, as we will show in the following, $X(t)$ is stationary if and only if $\varphi(1)=\varphi(2)=0$, where $\varphi(u)$ is the characteristic function of $\mathcal{Y}$, that is,

$$\varphi(u)=E[e^{iu\mathcal{Y}}] \qquad \text{for } i=\sqrt{-1}.$$

Before verifying this result we first note that $\varphi(u)$ can be written as

$$\varphi(u)=E[\cos(u\mathcal{Y})]+iE[\sin(u\mathcal{Y})]. \tag{1.12}$$

We will also make use of the trigonometric identities

- 1. $\cos(A+B)=\cos A\cos B-\sin A\sin B$
- 2. $\cos A\cos B=\frac{1}{2}\cos(A+B)+\frac{1}{2}\cos(A-B)$

Using identity (1), we see that $X(t)$ in [Equation 1.11](#) can be expressed as

$$X(t)=C[\cos\lambda t\cos\mathcal{Y}-\sin\lambda t\sin\mathcal{Y}], \tag{1.13}$$

while the product $X(t)X(t+h)$ can be rewritten using first (2) and then (1) as

$$\begin{aligned}
X(t)X(t+h)&=C\cos(\lambda t+\mathcal{Y})C\cos(\lambda(t+h)+\mathcal{Y})\\
&=\frac{C^2}{2}\cos(2\lambda t+\lambda h+2\mathcal{Y})+\frac{C^2}{2}\cos(\lambda h)\\
&=\frac{C^2}{2}[\cos(2\lambda t+\lambda h)\cos(2\mathcal{Y})-\sin(2\lambda t+\lambda h)\sin(2\mathcal{Y})+\cos(\lambda h)]. \tag{1.14}
\end{aligned}$$

$(\Leftarrow)$ Suppose $\varphi(1)=\varphi(2)=0$. Then, it is clear from [Equation 1.12](#) that

- a. $E[\cos\mathcal{Y}]=E[\sin\mathcal{Y}]=0$
- b. $E[\cos 2\mathcal{Y}]=E[\sin 2\mathcal{Y}]=0$

From [Equation 1.13](#), we see that (a) implies $E[X(t)]=0$. Also, upon taking the expectation of $X(t)X(t+h)$ in [Equation 1.14](#), it is seen that (b) implies

$$\gamma(h)=E[X(t)X(t+h)]=\frac{C^2}{2}\cos(\lambda h),$$

which depends on h but not on t. Moreover, σ_X² = γ(0) = (C² / 2) < ∞. Thus, X(t) is covariance stationary.

(⇒) Suppose X(t) is covariance stationary. Then, since E[X(t)] does not depend on t, it follows from Equation 1.13 that E[cosγ'] = E[sinγ'] = 0, and so that φ(1) = 0. Likewise, since E[X(t)X(t + h)] depends on h but not on t, it follows from the last equation in Equation 1.14 that E[cos2γ'] = E[sin2γ'] = 0, that is, that φ(2) = 0 and the result follows.

We note that if γ' ~ Uniform[0, 2π], then

$$\varphi(u)=\int_{0}^{2\pi} e^{i u y}\left(\frac{1}{2\pi}\right)dy = \frac{e^{2\pi i u}-1}{2\pi i u},$$

so that φ(1) = φ(2) = 0, and, thus, the uniform [0, 2π] distribution satisfies the condition on γ', and the resulting process X(t) = C cos(λt + γ') is stationary.

In fact, inspection of the plot would lead one to believe that the mean of this process depends on t. However, this is not the case since γ' is random. For example, Figure 1.6b and c shows two other realizations for different values for the random variable γ'. Note that the effect of the random variable γ' is to randomly shift the “starting point” of the cosine wave in each realization. γ' is called the phase shift. Note that for these three realizations, X(10) equals 0.35, 0.98, and −0.48, respectively, which is consistent with our finding that E[X(t)] does not depend on t.

Despite the intuitive appeal of $\tilde{\gamma}_k$, most time series analysts use an alternative estimator, $\hat{\gamma}_k$, defined by

$\hat{\gamma}_k = \frac{1}{n} \sum_{t=1}^{n-|k|} (X_t - \bar{X})(X_{t+|k|} - \bar{X}), \; k = 0, \pm 1, \pm 2, \dots \pm (n-1) \tag{1.19}$
$= 0, \quad |k| \ge n.$

From examination of Equation 1.19, it is clear that $|\hat{\gamma}_k|$ values will tend to be “small” when $|k|$ is large relative to $n$. The estimator, $\hat{\gamma}_k$, as given in Equation 1.19, has a larger bias than, $\tilde{\gamma}_k$ but, in most cases, has smaller mean square error. The difference between the two estimators is, of course, most dramatic when $|k|$ is large with respect to $n$. The comparison can be made most easily when $\bar{X}$ is replaced by $\mu$ in Equations 1.18 and 1.19, which we will assume for the discussion in the remainder of the current paragraph. The bias of $\hat{\gamma}_k$ in this case can be seen to be $(|k|/n)\gamma_k$. As $|k|$ increases toward $n$, the factor $|k|/n$ increases toward one, so that the bias tends to $\gamma_k$. As $|k|$ increases toward $n-1$, $\mathrm{Var}(\tilde{\gamma}_k)$ will increase, and $\tilde{\gamma}_k$ values will tend to have a quite erratic behavior for the larger values of $k$. This will be illustrated in Example 1.5 that follows. The overall pattern of $\gamma_k$ is usually better approximated by $\hat{\gamma}_k$ than it is by $\tilde{\gamma}_k$, and we will see later that it is often the pattern of the autocorrelation function that is of importance. The behavior of $\gamma_k$ is also better approximated by $\hat{\gamma}_k$ in that $\hat{\gamma}_k$ is also positive semidefinite in the sense of property (4) of the autocovariance function given in Section 1.3, while $\tilde{\gamma}_k$ is not necessarily positive semidefinite. For further discussion of these topics, the reader is referred to Priestley (1981).
