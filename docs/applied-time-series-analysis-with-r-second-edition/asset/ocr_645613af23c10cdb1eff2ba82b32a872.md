that φ_pp^(q)= φ_p which is nonzero. Also, as with the partial autocorrelation function, it can be shown that if k > p then φ_kk^(q)=0. See Woodward and Gray (1981). Thus, the generalized partial autocorrelation provides a unique identification of p and q for an ARMA(p,q) model in much the same way that the partial autocorrelation does for identification of p for an AR(p). In fact Equation 8A.8 is simply the special case of this result for q = 0.

The generalized partial autocorrelation function has another useful property that enhances model identification. Notice that if a process is ARMA(p,q), then

ρ_j = φ₁ρ_{j-1} + φ₂ρ_{j-2} + ⋯ + φ_pρ_{j-p}  (8A.14)

for j > q. This gives rise to the extended Yule–Walker equations

ρ_{q+1} = φ₁ρ_q + φ₂ρ_{q-1} + ⋯ + φ_pρ_{q-p+1}  (8A.15)
ρ_{q+2} = φ₁ρ_{q+1} + φ₂ρ_q + ⋯ + φ_pρ_{q-p+2}
⋮
ρ_{q+p} = φ₁ρ_{q+p-1} + φ₂ρ_{q+p-2} + ⋯ + φ_pρ_q

that can be solved for the AR parameters if the autocorrelations are known. However, since Equation 8A.14 is satisfied for j > q, then if h is a nonnegative integer it follows that the p equations associated with j = q + h, q + h + 1, ..., q + h + p - 1 can also be used to solve for the AR parameters. Thus it follows that if X_t is ARMA(p,q), then φ_pp^(q+h)= φ_p for h = 0, 1, .... Theorem 8A.1 summarizes the above discussion.

# Theorem 8A.1

Let X_t be an ARMA process with AR order greater than zero.

Then

+   1. X_t is ARMA(p,q) if and only if φ_kk^(q)=0, k > p and φ_pp^(q) ≠ 0.
+   2. If X_t is ARMA(p,q) then φ_pp^(q+h)= φ_p, h ≥ 0.

Proof: See Woodward and Gray (1981).
