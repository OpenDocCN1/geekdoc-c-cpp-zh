
Another issue that may need to be checked concerning residuals is normality. Normality is an assumption upon which ML estimates are based. Additionally, if uncorrelated residuals are non-normal, then ARCH-type behavior is a possibility. (See Section 4.2.) Methods for checking normality include the use of Q–Q plots or formal tests for normality such as the Shapiro–Wilk test (see Shapiro and Wilk, 1965). Other tests, for example the Anderson–Darling test (see Anderson and Darling, 1952) and a host of others can also be used to test for normality. In Figure 9.3, we show Q–Q plots of the (standardized) residuals in Figure 9.2. The normality of the residuals for the airline model seems like an appropriate assumption while the normality of the PA temperature residuals seems more questionable. Neither the Anderson–Darling nor the Shapiro–Wilk test reject normality for either set of residuals at α = 0.05.

**Using R:** Basic R functions are available for checking normality. The function `qqnorm(x)` plots a Q–Q plot, and `shapiro.test(x)` will perform a Shapiro–Wilk test of the null hypothesis that the data (in vector x) are normal. Other tests for normality, including the Anderson–Darling test, Cramér–von Mises, and Lilliefors (Kolmogorov–Smirnov) tests, see Stephens (1974), can be obtained using functions in the CRAN package `nortest`.

### 9.3.1 Cochrane–Orcutt and Other Methods

Consider the case in which (1 − φ₁B)Zₜ = aₜ. In this case, it follows from Equation 9.11 that

Y* = (1 − φ₁B)Xₜ  
= (1 − φ₁B)(a + b t + Zₜ)  
= a(1 − φ₁) + b(1 − φ₁B)t + (1 − φ₁B)Zₜ  
= c + b t_{φ1} + aₜ,  (9.13)

where Equation 9.13 is a regression equation with the same slope coefficient, b, as in Equation 9.11 with a new independent variable t_{φ1} = (1 − φ₁B)t = t − φ₁(t − 1) and uncorrelated residuals. In practice, however, φ₁, a, and b will not be known and must be estimated from the data. Cochrane and Orcutt (1949) suggested fitting a regression line to the data using least-squares estimates and fitting an AR(1) model to the residuals Ẑₜ = Xₜ − â − b̂t. Letting φ̂₁ denote the estimated coefficient, they suggested transforming to obtain Ŷₜ = Xₜ − φ̂₁Xₜ₋₁, t = 2, …, n. Thus, the resulting series, Ŷₜ, is of length n − 1 and satisfies

Ŷₜ = (1 − φ̂₁B)Xₜ  
= a(1 − φ̂₁) + b(1 − φ̂₁B)t + (1 − φ̂₁B)Zₜ  
= c + b t_{φ̂1} + gₜ,  (9.14)

where t_{φ̂1} = t − φ̂₁(t − 1). Noting that Zₜ = (1 − φ₁B)⁻¹aₜ, we see that gₜ = (1 − φ̂₁B)(1 − φ₁B)⁻¹aₜ, which is not white noise but should be almost uncorrelated. The Cochrane–Orcutt (CO) procedure is then used to test the null hypothesis H₀: b = 0 in Equation 9.14 where the independent variable is t_{φ̂1} using standard least-squares methods.
