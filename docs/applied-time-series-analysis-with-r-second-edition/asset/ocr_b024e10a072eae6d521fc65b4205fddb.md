(a) Linear chirp realization from Equation 13.21 with A = 1, β = 1, a = 1, b = 1, and ψ = 0, and (b) the dual realization based on the transformation g(t) = at² + bt.

It should be clear that X(t) in Example 13.12 is easily generalized. That is, it follows that

$$X(t) = \sum_{k=1}^{m} A_k \cos\left[2\pi\beta_k(at^2 + bt) + \psi_k\right] + N(t), \qquad (13.22)$$

is a GLC process, where the ψ_k are independent uniform [0, 2π] random variables, and N(t) is uncorrelated normal noise independent of the ψ_k’s. We will refer to the GLC processes defined by Equations 13.21 and 13.22 as stochastic linear chirps (SLC).
