# ## Appendix

Two parameter estimation routines are provided in `tswge`: `est.ar.wge` and `est.arma.wge`. As the names suggest, these functions are designed to estimate the parameters in the AR and ARMA model respectively. R functions mentioned in this chapter include base R functions `arima`, `ar.burg`, `ar.yw`, `ar.mle`, and `ar.ols`. Also, innovations estimates of the MA parameters (shown in [Table 7.1](#)) were obtained using itsmr function `ia` which is available in CRAN.

+   a. `est.ar.wge(x, p, factor, type)` is a function that obtains parameter estimates of a stationary AR model of order p that is fit to the data in the vector x.
+   
+      `x` is a vector containing the realization to be analyzed  
+      `p` is the order of the AR model (default = 2)  
+      `factor` is a logical variable, and if `factor = TRUE` (default) a factor table is printed for the estimated model.  
+      `type` specifies the method used to estimate the parameters: either `'mle'` (default), `'burg'`, or `'yw'` (not recommended)
+   
+      The program outputs:
+   
+      `phi` the estimates of the parameters φ₁, ..., φₚ  
+      `res` the estimated residuals (using backcasting) based on estimated model  
+      `avar` the estimated white noise variance (based on backcast residuals)  
+      `aic` the AIC value associated with this model fit  
+      `aicc` the AICC value associated with this model fit  
+      `bic` the BIC value associated with this model fit

> **NOTE:** This function uses calls to the base R functions `ar.mle`, `ar.burg`, and `ar.yw`.
