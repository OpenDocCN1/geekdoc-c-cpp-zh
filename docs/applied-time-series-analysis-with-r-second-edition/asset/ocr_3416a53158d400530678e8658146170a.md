```
g. fore.garma.wge(x,u,lambda,phi,n.ahead,lastn,plot)
```

This function forecasts *n.ahead* steps ahead based on a 1-factor GARMA model in [Equation 11.16](#). See [Section 11.6](#). For comparison, forecasts from an AR model fit to the data are also obtained.

+   - `x` = realization.
+   - `u` and `lambda` are the parameters of the Gegenbauer factor in [Equation 11.16](#).
+   - `phi` = vector of autoregressive coefficients (default = 0)
+   - `n.ahead` = the number of steps ahead you want to forecast. (default = 2)
+   - `lastn` = logical variable. If `lastn = FALSE` (default) then the forecasts are for *x(n + 1), x(n + 2), ..., x(n + n.ahead)* where *n* is the length of the realization. If `lastn = TRUE`, then the program forecasts the last *n.ahead* values in the realization.
+   - `plot` = logical variable. If `plot = TRUE` (default) then the forecasts will be plotted along with the realization. If `plot = FALSE` then no plots are output.

The function outputs

+   - `ar.fit.order` (the order of the AR model fit to the data)
+   - `garma.fore` (a vector containing the GARMA forecasts)
+   - `ar.fore` (a vector containing the AR forecasts)

**NOTE:** We assume that *q* = 0, i.e there are no moving average parameters.
