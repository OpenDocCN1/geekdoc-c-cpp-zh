$P_X(f) = \gamma_0 + 2 \sum_{j=1}^{\infty} \gamma_j \cos 2\pi f j,$

so that for an MA(q) process we have simplified expressions for $P_X(f)$ and $S_X(f)$ given by

$P_X(f) = \gamma_0 + 2 \sum_{j=1}^{q} \gamma_j \cos 2\pi f j \tag{3.7}$

and

$S_X(f) = 1 + 2 \sum_{j=1}^{q} \rho_j \cos 2\pi f j, \tag{3.8}$

where $\gamma_j$, and $\rho_j$, $j = 0,1, ...,q$ are given in Equations 3.3 and 3.4.

# 3.1.1 MA(1) Model

Let $X_t$ be the MA(1) process defined by

$X_t - \mu = a_t - \theta_1 a_{t-1} = (1 - \theta_1 B) a_t \tag{3.9}$

From Equations 3.2 and 3.3, we obtain

$\gamma_0 = \sigma_a^2 [1 + \theta_1^2] = \sigma_X^2$\n$\gamma_1 = \sigma_a^2 [-\theta_1]$\n$\gamma_j = 0, \quad j > 1. \tag{3.10}$

Thus, for an MA(1) process,

$\rho_0 = 1$\n$\rho_1 = \frac{-\theta_1}{1 + \theta_1^2}$\n$\rho_j = 0, \quad j > 1. \tag{3.11}$
