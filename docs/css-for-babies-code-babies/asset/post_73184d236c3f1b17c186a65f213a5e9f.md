## CSS (Cascading Style Sheets)

Styles define how to display HTML elements

CSS rules have two main parts: a selector and one or more declarations.

```
selector       declaration       declaration
H1 { color: blue; background: green; }
property  value   property  value
```

A declaration always ends with a semicolon and declaration groups are surrounded by curly brackets.

```
<link rel="stylesheet" type="text/css" href="hello again.css" />
```
