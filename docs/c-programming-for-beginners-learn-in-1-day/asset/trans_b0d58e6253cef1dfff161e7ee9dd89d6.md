## 总结

- C# 有许多可对文件执行的文件操作。其中大多数操作都是 File 类的一部分。
- 如果要从文件中读取数据，可以使用 File.ReadAllText 或 File.ReadAllLines 方法。
- 流用作应用程序与文件之间的中间层。
  - 每当需要从文件读取数据时，就使用 StreamReader。
  - 每当需要将数据写入文件时，就使用 StreamWriter。
- 序列化用于将类对象写入文件。反序列化用于从文件中恢复对象。
