# 9.2.2 Maintaining Exceptions Using Methods

Similar to function modules, exceptions can be maintained in methods via Class Builder by keeping the cursor on the method and selecting the EXCEPTION button, as shown in Figure 9.4.

![](bbox=[0.148, 0.208, 0.777, 0.404])

**Figure 9.4** Exception Button

Under the EXCEPTION column in the METHOD tab (Figure 9.5), give a name for the exception and maintain a description to explain the exception so that developers calling the method can understand why that exception is raised.

![](bbox=[0.148, 0.534, 0.788, 0.72])

**Figure 9.5** Exceptions Window

As shown in Figure 9.6, an exception can be raised in the method using the RAISE statement.
