The following steps walk you through activating and registering the service with SAP Gateway using Service Builder:

+   1. To register and activate the service, first double-click the SERVICE MAINTENANCE folder and click the REGISTER button, as shown in Figure 19.113.

![](bbox=[0.142, 0.212, 0.851, 0.358])

**Figure 19.113** Service Registration

+   2. In the SELECT SYSTEM ALIAS window that opens, you can use F4 help to select the system that acts as a hub to the backend. You can use the RFC destination that points to the SAP business system. Based on the IMG configuration and system installation, you can use LOCAL as the SYSTEM ALIAS.

+   3. In the ADD SERVICE window, as shown in Figure 19.114, make a note of the EXTERNAL SERVICE name. This name is used to access the service.

![](bbox=[0.142, 0.558, 0.727, 0.857])

**Figure 19.114** Add Service Window
