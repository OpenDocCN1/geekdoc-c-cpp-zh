+   - Back-End Editor (line-based mode)

The back-end editor works in a line-based mode in which only one line at a time is edited. Even though this editor is not very user friendly, it can be used in any operating system environment (unlike the front-end editor).

You can select a mode by following the menu path Utilities · Settings from any ABAP Workbench tool to open the User-Specific Settings dialog box (see Figure 3.7).

On this screen, select the ABAP Editor tab and then the Editor tab. Under the Editor tab, select the radio button for your preferred editor.
