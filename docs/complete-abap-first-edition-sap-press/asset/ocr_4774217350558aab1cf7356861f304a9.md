Proceed with the following steps:

+   1. Implement the BAdI either using Transaction SE19 or simply by right-clicking the BAdI definition name and selecting CREATE BAdI IMPLEMENTATION (see Figure 20.34).
+   2. This will open a dialog box in which you can enter the ENHANCEMENT IMPLEMENTATION name and SHORT TEXT, as shown in Figure 20.42. Similar to how you can create multiple BAdI definitions within an enhancement spot, you can create multiple implementations within an enhancement implementation.

![](bbox=[0.142, 0.354, 0.849, 0.444])

**Figure 20.42** Enhancement Implementation

+   3. Once you input the necessary settings, click the green checkmark. This will immediately open the CREATE BAdI IMPLEMENTATION dialog box, in which you can enter the BAdI IMPLEMENTATION name, DESCRIPTION, and IMPLEMENTING CLASS name (see Figure 20.43).

![](bbox=[0.142, 0.594, 0.764, 0.683])

**Figure 20.43** Create BAdI Implementation

+   4. Once the details are entered, click the green checkmark to go to the ENH. IMPLEMENTATION ELEMENTS tab, as shown in Figure 20.44. Double-click the IMPLEMENTING CLASS subobject to see the methods of the interface. Double-click the method to implement it. The system will automatically open the method in Transaction SE24, where you can write the code like you would for any regular method.
