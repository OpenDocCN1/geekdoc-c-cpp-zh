# 21.8.5 Buffer Trace

Another useful trace is the *buffer trace*. Using a buffer trace, you can identify the following:

+   - Buffer accesses executed by the program statements
+   - Which type of buffer is used
+   - How the buffer is managed

In the trace list view, you can double-click a statement in the STATEMENT column to see detailed information about the buffer, such as buffer type and buffer key, as shown in Figure 21.25.
