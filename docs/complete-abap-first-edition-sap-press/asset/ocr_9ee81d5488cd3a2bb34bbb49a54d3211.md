# 12.2.3 Screen Elements

The various screen elements of a dialog program make up the user interface (UI) of the screen. Screen elements are created in graphical or alphanumeric mode in Screen Painter.

The graphical layout editor in Screen Painter allows you to create screen elements via drag and drop functionality. You can access the graphical layout editor by clicking the LAYOUT button in the application toolbar, as shown in Figure 12.13.

![](bbox=[0.148, 0.282, 0.704, 0.384])

**Figure 12.13** Layout Button

To open the editor in alphanumeric mode, from within Screen Painter follow the menu path Utilities • Settings and select the Screen Painter tab. In the Screen Painter tab, deselect the Graphical Layout Editor option, as shown in Figure 12.14, and click the OK button (green checkmark). Once the Graphical Layout Editor option is deselected, click the LAYOUT button shown in Figure 12.13 to open the editor in alphanumeric mode.

![](bbox=[0.148, 0.578, 0.612, 0.682])

**Figure 12.14** Deselecting Graphical Layout Editor

The graphical layout editor (see Figure 12.15) provides an easy-to-use interface in which all the screen elements can be added using drag and drop functionality.

The alphanumeric layout editor doesn't support drag and drop; it requires fields to be inserted manually. To insert a screen element, position the cursor on the editor where the screen element should be inserted and follow the menu path Edit • Create Element, as shown in Figure 12.16. You are then shown a list of screen elements that you can create via the context menu.
