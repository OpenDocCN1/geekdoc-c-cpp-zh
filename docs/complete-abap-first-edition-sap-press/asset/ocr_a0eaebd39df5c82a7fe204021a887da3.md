+   - **Table controls** — Used to display data in a tabular format—for example, to display all the line items of a document.
+   - **Tabstrip controls** — Allow you to create multiple tabs on a single screen for easy navigation. Each tab of the tabstrip control loads a subscreen.
+   - **Subscreen area** — You can create a subscreen area on a screen so that another screen can be displayed there as a subscreen at runtime.
+   - **Custom container** — A custom container area can be marked on a screen where a custom control can be displayed.
