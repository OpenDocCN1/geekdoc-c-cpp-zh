The left section contains different tabs. The middle section is the design view, where we add form fields. The Preview PDF tab allows you to quickly preview the form.

The right section contains the library palette and the Object palette. The library palette consists of different form fields organized into multiple groups. Below the library palette, we maintain the properties for form fields in the Object palette. We add the form fields from the library palette to the design view. To add a field, you can simply drag the field from the group and drop it in the design view. Once the field is added, we bind it to the context from the Object palette.

Let's create an image field first. Proceed with the following steps:

+   1. To add the image field, drag the image field from the Standard Group under the Object Library and drop it in the design view, as shown in Figure 18.88.

+   2. Click on the image field in the design view to set the object properties. In the Object palette, as shown in Figure 18.89, you can set a caption for the image and provide the image URL and sizing.
