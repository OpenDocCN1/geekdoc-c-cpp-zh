+   - Screen Assignment: This box lists all the defined selection screens for which this variant can be assigned.
+   - Information icon: For each field of the selection screen, certain attributes can be set to manipulate the field. The Information button in the application toolbar documents all of the fields and their purposes—some of which we’ll discuss in Section 14.4.2.

+   5. Click Save in the standard toolbar to save the variant.
