# ## 20.4 Using Modification Browser

Modification Browser provides an overview of the modifications and enhance-ments carried out in the system. You can open Modification Browser using Trans-action SE95. The initial Modification Browser screen provides a selection screen to search for modifications using different criteria, as shown in Figure 20.13.

![](bbox=[0.138, 0.352, 0.61, 0.693])

Figure 20.13 Modification Browser Initial Screen

Here, you can search for modifications that are applied through SAP Notes or car-ried out using Modification Assistant. You can also search for modifications that are carried out without Modification Assistant or changes that were performed before Modification Assistant was introduced. Changes to BAdIs and ABAP Data Dictionary tables, views, and search helps can also be checked via Modification Browser.
