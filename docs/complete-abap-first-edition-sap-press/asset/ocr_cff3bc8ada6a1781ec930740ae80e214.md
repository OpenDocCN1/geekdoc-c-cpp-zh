Under the PAGES AND WINDOWS folder, a default page with one main window is created by default. You can double-click the page to rename it.

To create a window on the page, right-click the page and select CREATE • WINDOW from the context menu, as shown in Figure 18.35. Using the context menu, you can cut, copy, paste, or delete a node. Under the CREATE submenu, you have the options to create a new PAGE, WINDOW, GRAPHIC, or ADDRESS. We’ll use these options one by one in following subsections.

At this point, the new window should appear in Form Painter towards the right (see Figure 18.36). If you don’t see Form Painter, click the FORM PAINTER button in the toolbar. Form Painter opens in a split screen, which can be dragged to adjust the width.

You can rename the window to reflect the text it displays. For this example, we’ll use this window to print the document information, so let’s name it INFO. Maintain the window name in the WINDOW field and its short description in the MEANING field, as shown in Figure 18.36. We also need one more window to print the footer text; go ahead and create one more window and position it below the main window in Form Painter.
