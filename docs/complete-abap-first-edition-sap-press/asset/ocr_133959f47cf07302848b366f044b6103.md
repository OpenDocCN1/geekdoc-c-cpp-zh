3. If you want to bind the image field with the graphic node from the context, you can do so in the BINDING tab of the OBJECT palette. Binding to the graphic node of the context allows you to dynamically pass the image URL. Click the drop-down icon next to the DATA BINDING field and select the GRAPHIC node, as shown in Figure 18.90. Once bound, the field will display the node name preceded by a dollar sign ($) symbol.

You can also click within the image field in design view to upload the image from your local PC.
