The following steps walk you through implementing a BTE:

+   1. On the initial screen of Transaction FIBF, follow the menu path Environment • Info Systems (P/S) to find a suitable interface, as shown in Figure 20.62.

![](bbox=[0.142, 0.212, 0.735, 0.348])

+   2. On the selection screen for publish and subscribe interfaces, enter “A” (for *application component*) in the ATTRIBUTE TYPE field and click EXECUTE (see Figure 20.63).

![](bbox=[0.142, 0.453, 0.823, 0.775])

+   3. The program will list all the available events. Search for the event you want to implement. For this example, implement event 00001420, as shown in Figure 20.64.
