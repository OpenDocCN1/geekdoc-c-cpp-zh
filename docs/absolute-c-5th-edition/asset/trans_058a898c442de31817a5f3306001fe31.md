20. `cout << "Enter a line of input:\n";`

```cpp
char next;
do{
	cin.get(next) if (isupper(next)) cout << '\n';
} while (next != '\n');
```

注意，你应该使用 `isupper(next)` 而不是 `islower(next)`。这是因为如果 `next` 包含非字母字符（如空白符或逗号符号），`islower(next)` 将返回假值。

- 1. 编写一个程序，读取一个最多 100 个字符的句子，并输出修正了间距和字母大小写后的句子。换句话说，将所有两个或更多连续空格的字符串压缩为单个空格。句子应以大写字母开头，但不包含其他大写字母。不要担心专有名词；如果它们的首字母改为小写，那是可以接受的。将换行符视为句子中的一个空格，并将换行符和任何数量的空格压缩为单个空格。假设句子以句号结束，且不包含其他句号。例如，输入：

the Answer to life, the Universe, and everything IS 42.

- 3. 编写一个程序，按以下格式读取人的姓名：名，然后中间名或首字母，最后是姓。程序按以下格式输出姓名：

你的程序应该在中间首字母后加上句号，即使输入中没有句号。你的程序应允许没有中间名或中间首字母的用户。在这种情况下，输出输出显然不包含中间名或首字母。例如，输入

Mary User

如果你使用 C 语言风格字符串（C-strings），假设每个名字最多长 20 个字符。或者，使用 `string` 类。（提示：你可能希望使用三个 `string` 变量而不是一个大字符串来处理输入。你可能会发现不使用 `getline` 更容易。）

- 4. 编写一个程序，读取一行文本并将所有四个字母的单词替换为 "love"。例如，输入字符串

I love you, love!

当然，输出并不总是有意义。例如，输入字符串

应该产生以下输出：
Love run.

如果四个字母的单词以大写字母开头，它应该被替换为 "Love"而不是 "love"。你不需要检查大小写，除非是单词的首字母。单词是任何由字母组成并由空格、行尾或任何其他字符分隔的字符串。你的程序应重复此操作，直到用户说 "quit"。
