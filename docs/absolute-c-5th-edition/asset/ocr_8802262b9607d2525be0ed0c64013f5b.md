Any form of string is ultimately composed of individual characters. Thus, when doing string processing it is helpful to have tools at your disposal to test and manipulate individual values of type char. This section is about such tools.

# Character I/O

Similarly, when the user wants to type the number 10, he or she types the character '1' followed by the character '0'.
