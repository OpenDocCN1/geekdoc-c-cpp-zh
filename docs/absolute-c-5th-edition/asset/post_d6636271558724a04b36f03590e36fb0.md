```cpp
template<class T>

```

```cpp
template<class T>
PFArray<T>::PFArray(const PFArray<T>& pfaObject)
    : capacity(pfaObject.getCapacity()),
      used(pfaObject.getNumberUsed())
{
    a = new T[capacity];
    for (int i = 0; i < used; i++)
        a[i] = pfaObject[i];
}
```

```cpp
template<class T>
void PFArray<T>::addElement(const T& element)
{
    if (used >= capacity)
    {
        cout << "Attempt to exceed capacity in PFArray.";
        exit(0);
    }
    a[used] = element;
    used++;
}
```

```cpp
template<class T>
bool PFArray<T>::full() const
{
    return (capacity == used);
}
```

```cpp
template<class T>
int PFArray<T>::getCapacity() const
{
    return capacity;
}
```

```cpp
template<class T>
int PFArray<T>::getNumberUsed() const
{
    return used;
}
```

```cpp
template<class T>
T& PFArray<T>::operator[](int index)
{
    if (index >= used)
    {
        cout << "Illegal index in PFArray.";
        exit(0);
    }
    return a[index];
}
```

```cpp
template<class T>
PFArray<T>::operator=(const PFArray<T>& rightSide)
{
    if (capacity != rightSide.capacity)
    {
        delete [];
        a = new T[rightSide.capacity];
    }
    capacity = rightSide.capacity;
    used = rightSide.used;
    for (int i = 0; i < used; i++)
        a[i] = rightSide[i];
    }
    return *this;
}
```

```cpp
template<class T>
PFArray<T>::~PFArray()
{
    delete [];
}
```

## Display 16.7 Demonstration Program for Template Class PFArray (part 1 of 2)

```cpp
// Program to demonstrate the template class PFArray.
#include <iostream>
#include <string>
using std::cin;
using std::cout;
using std::endl;

#include "pfarray.h"
#include "pfarray.cpp"
using PFArray::PFArray;

int main() {
    PFArray<int> a(10);

    cout << "Enter up to 10 nonnegative integers.\n";
    cout << "Place a negative number at the end.\n";
    int next;
    cin >> next;
    while ((next >= 0) && (!a.full())) {
        a.addElement(next);
        cin >> next;
    }
    if (next >= 0) {
        cout << "Could not read all numbers.\n";
        // Clear the unused input:
        while (next >= 0) {
            cin >> next;
        }
    }

    cout << "You entered the following:\n";
    int index;
    int count = a.getNumberUsed();
    for (index = 0; index < count; index++) {
        cout << a[index] << " ";
    }
    cout << endl;
    PFArray<string> b(3);

    cout << "Enter three words:\n";
    string nextWord;
```

## The vector and basic_string Templates

If you have not done so, it would be a good time to read 7.3 of Chapter 7, which covers the template class `vector`.

Another predefined template class is the `basic_string` template class. This class can deal with strings of any type. The class `basic_string<char>` is the class for characters. The class `basic_string<double>` is the class for strings of type `double`. The class `basic_string<YourClass>` is the class for strings of objects of type `YourClass` (whatever that may be).

You have already been using a special case of the `basic_string` template class. The unnamed name `string`, which we have been, is an alternate name for the class `basic_string<char>`. All the member functions you learned for the similarly template class `basic_string<T>`.

The template class `basic_string` is defined in the library with header file `<string>`, and the definition is placed in the `std` namespace. When using the class `basic_string`, you need the following or similar near the beginning of your file:

```cpp
#include <string>
using namespace std;
```

```cpp
#include <string>
using std::basic_string;
using std::string;
```

## 16.3 Templates and Inheritance

There is very little to learn about templates and inheritance. To define a template class, start with a template class (or sometimes a nontemplate class) and derive another class from it. Do this in the same way that you derive an ordinary class from an ordinary base.

## EXAMPLE: Template Class For a Partially Filled Array with Backup

The class PFArrayD (Displays 14.8 and 14.9) was for filled arrays, but it only worked for the base type double. 16.5 converted the class PFArrayD to the template class PFArray so that it would work for any type of array. In this program, we define the template class PFArrayBak with backup. We can do this almost by starting with the regular PFArrayBak and replacing all occurrences of the array base with a type parameter, replacing the class PFArrayD with the template class PFArray, and cleaning up the syntax so it conforms to template syntax.

The interface to the class PFArrayBak is given in Display 16.8. Note that the base class is PFArray<T> with the array parameter, not simply PFArray. If you think about it, you will realize that the <T>. A partially filled array of T with backup is a derived class of a partially filled array. The T, and how it is used, is important. In what follows, we reproduce the first constructor definition in the implementation:

```cpp
template<class T>
PFArrayBak<T>::PFArrayBak() : PFArray<T>(), usedB(0)
{
    b = new T[getCapacity()];
}
```

Note that, with any definition of a template class function, it starts with ntemplate<class T>

Also notice that the base type of the array (given after the new) is the type parameter T. Other details may not be as obvious, but do make sense. Next consider the following:

```cpp
PFArrayBak<T>::PFArrayBak() : PFArray<T>(), usedB(0)
```

As with any definition of a template class function, the definition has PFArray<T> with the scope resolution operator, but the constructor is just plain, old PFArray without any type parameter.
