38. The variable moreRead is not set to false until we attempt to read the last item in the file. This means that we will output an extra newline on the last loop iteration. We can address this by outputting the value read and first reading the next string (and possibly end of file) at the end of the loop iteration. This also handles the case where the file is empty.

```cpp
string text;
bool moreToRead = inputStream >> text;
while (moreToRead) {
    cout << text << endl;
    moreToRead = inputStream >> text;
}
```

40. This solution remembers the highest score and name seen so far and outputs it after
the loop is over.

```cpp
fstream inputStream;

inputStream.open("player.txt");
int numScores;
int highScore = -1;
string highName = "";
inputStream >> numScores;
for (int i = 0; i < numScores; i++)
{
    string name;
    int score;
    inputStream >> name;
    inputStream >> score;
    if (score > highScore)
    {
        highScore = score;
        highName = name;
    }
}
inputStream.close();
cout << highName << " has the high score of "
 << highScore << endl;
```

4. Write a program that finds and prints all the prime numbers between 3 and 100. A prime number is a number that can be only divided by one and itself (i.e. 3, 5, 7, 11, 13, 17, ...).

One way to solve this problem is to use a doubly-nested loop. The outer loop iterate from 3 to 100, while the inner loop checks whether the counter value for the outer loop is prime. One way to decide whether the number $n$ is prime is to loop from 2 to $n-1$; if any of these numbers divides $n$, then $n$ cannot be prime. If none of the values from 2 to $n-1$ evenly divides $n$, then $n$ must be prime. (Note that there are several easy ways to make this algorithm efficient.)
