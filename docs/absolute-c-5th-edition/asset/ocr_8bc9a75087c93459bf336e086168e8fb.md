Or, you must use one of the other ways of specifying the names and namespace, such as the following:

```
#include <iomanip>
using std::setw;
using std::setprecision;
```

# Saving Flag Settings

A function should not have unwanted or unexpected side effects. For example, a function to output amounts of money might contain

```
cout.setf(ios::fixed);
out.setf(ios::showpoint);
out.precision(2);
```

After the function invocation, these settings will still be in effect. If you do not want side effects, you can save and restore the original settings. The function `precision` has been overloaded so that with no arguments it returns the current precision so the setting can be restored. The flags with `set` are easy to save and restore the flag settings. The member function `cout.flags()` returns a value of `long` that codes all the flags. The flags can be reset by using this `long` value as an argument to `cout.flags`. These techniques work well for file output streams as they do for `cout`. For an example, to save and restore these settings could be structured as follows:

```
void outputStream(ostream out)
{
    int precisionSetting = out.precision();
    long flagSettings = out.flags();
    out.setf(ios::fixed);
out.setf(ios::showpoint);
out.precision(2);
    //Do whatever you want here.
out.precision(precisionSetting);
out.flags(flagSettings);
}
```

Another way to restore settings

```
cout.setf(0, ios::floatfield);
```

An invocation of the member function `set` with these arguments will restore the `default` settings. Note that these the default values, not necessarily the settings before the last time they were changed. Also note that the default setting values are implementation-dependent. Finally, note that this does not reset `precision` settings or any settings that are not set with `setf`.
