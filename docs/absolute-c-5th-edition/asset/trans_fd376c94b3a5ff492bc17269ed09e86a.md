

# 第 8 章 运算符重载、友元与引用

b. 类定义中添加了以下成员函数。（我们展示了在类定义中应所示的函数声明。函数本身的定义将包含限定符 `Money::`）

```cpp
const Money percent(int percentFigure);
// 返回调用对象中金额金额的百分比。
// 例如，如果 percentFigure 为 10，则返回的数值
// 是调用对象所代表金额的 10%。
```

例如，如果 `purse` 是类型为 `Money` 的对象，其值代表 $100.10，那么调用：

```cpp
purse.percent(10);
```

返回 $100.10 的 10%；即它返回一个类型为 `Money` 的值，其金额为 $10.01。

- 2. 为有理数定义一个类。有理数是可以表示为两个整数的数。例如，1/2、3/4、6/2 等都是有理数。（我们所说的 1/2 指的是日常的分数，而不是该表达式在 C++ 程序中产生的整数除法）用两个值表示有理数：一个表示分子，一个表示分母。将类命名为 `Rational`。包含一个带有两个参数的构造函数，可以将任何对象的成员变量设置为合法值。还要包含一个带有单个 `int` 类型参数的构造函数，用于初始化为该有理数。包含一个默认构造函数，将对象初始化为 0（即 0/1）。重载输入和输出运算符 `>>` 和 `<<`。输入输出的数字格式为 1/2、300/401 或负号形式，因此 -1/32 和 -300/-401 也是可能的输入。重载所有以下运算符，使其能够正确应用于 `Rational` 类型：`==`、`!=`、`<`、`<=`、`>`、`*`、`/`。提示：如果 $ad$ 等于 $cb$，两个数 $a/b$ 和 $c/d$ 相。如果 $b$ 和 $d$ 是正有理数，如果 $ad$ 小于 $cb$，则 $ab$ 小于 $cd$。你应该包含一个函数来对存储的值进行归一化，使得在归一化后分母为正且分子和分母尽可能小。例如，归一化后 4/-8 的表示与 -1/2 相同。

- 3. 为复数定义一个类。复数是形式为 $a + bi$ 的数，对于我们的目的，$a$ 和 $b$ 是 `double` 类型的数，$i$ 是代表 $\sqrt{-1}$ 值的数。用两个 `double` 值表示复数。将成员变量命名为 `real` 和 `imaginary`。（乘以 $i$ 的数称为虚部）。将类命名为 `Complex`。包含一个带有两个 `double` 类型参数的构造函数，用于将任何对象的成员变量设置为值。包含一个只有一个 `double` 类型参数的构造函数；将其命名为 `realPart` 并定义该构造函数，使对象初始化为 `realPart+i`。包含一个将对象初始化为 0（即 0+i）的构造函数。重载所有后续运算符，使其正确应用于 `Complex` 类型：`+=`、`-`、`*`、`>>` 和 `<<`。你还应该编写一个测试程序来验证你的类。提示：要加或减两个复数，只需加或减两个 `double` 类型的变量。两个复数的乘积由以下公式给出：

```cpp
(a+b*i)*(c+d*i) == (a*c-b*d)+(a*d+b*c)*i
```

在接口文件中，你应该这样定义常量 $i$：

```cpp
const Complex i(0, 1);
```

这个定义的常量将与上面讨论的 $i$ 相同。
