# EXAMPLE: DigitalTime Class

Previously we described how the files in Displays 11.1, 11.2, and 11.3 divide a
program into three files: the interface for the class DigitalTime, and the implementation
of the class DigitalTime, and an application that uses the class. Here we discuss the
details of the class implementation. There is no new material in this example section,
but some of the details in the implementation (Display 11.2) are not completely
clear to you, this section may shed some light on your confusion.

Most of the implementation details are straightforward, but there are two things that
merit commit. Notice that the function name advance is overloaded so
it has two function definitions. Also notice that the definition for the overloaded
extraction (input) operator uses two helping functions called readHour
readMinute and that these two helping functions themselves use a third
function called digitToInt. Let us discuss these points.

The class DigitalTime (Displays 11.1 and 11.2) has two member functions called
advance. One takes a single argument, which is an integer giving the number
of minutes to advance the time. The other version takes two arguments, one for
number of hours and one for number of minutes, and advances the time by that
hour plus that number of minutes. Notice that the definition of the two-
argument version of advance is a call to the one-argument version. Look at the
definition of the two-argument version is given in Display 11.2. The first time
advance is hoursAdded hours and then the single-argument version of advance
is used to advance the time by an additional minutesAdded. At first this
seem strange, but it is perfectly legal. The two functions named advance and
different functions that, as far as the compiler is concerned, coincidentally
happen to have the same name.

Now us discuss the helping functions. The helping functions readHour
readMinute read the input one character at a time and convert the input
to integer values that are placed in the member variables hour and minute.
The functions readHour and readMinute read the hour and minute digit at a time,
so are reading values of type char. This is more complicated than reading the
input as int, but it allows us to perform error checking to see whether the
input is correctly formed and issue an error message if the input is not well formed.
The helping functions readHour and readMinute use another helping
digitToInt converts a digit, as '3', to a
number, as 3. This function was given previously in this book as the answer to
Self-Test Exercise 3 in Chapter 7.
