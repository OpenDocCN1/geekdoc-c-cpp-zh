## EXAMPLE: Searching an Array

A common programming task is to search an array for a given value. For example, the array may contain the student numbers for all students in a given course. To tell whether a particular student is enrolled, the array is searched. The simple program in Display 5.6 fills an array and then searches the array for values specified by the user. A real application program would be much more elaborate, but this shows all the essentials of the sequential search algorithm. The sequential search is the most straightforward searching algorithm you could imagine: the program looks at the array elements in order, first to last, to see if the target value is equal to any of the array elements.

In Display 5.6 the function search is used to search the array. When searching an array, you often want to know more than simply whether or not the target value is in the array. If the target value is in the array, you often want to know the index of the indexed variable holding that value, since the index may serve as a guide to some additional information about the target value. Therefore, we designed the function search to return an index giving the location of the target value in the array, provided the target value is in fact, the array. If the target value is not in the array, search returns -1. Let's look at the function search in a little more detail.

The function search uses a loop to check the array elements one after the other to see if any of them equals the target. The variable found is used as a flag to record whether or not the target has been found. If the element is found in the array, found is set to true, which in turn ends the while loop.

```cpp
void fillArray(int a[], int listSize, int &numberUsed)
{
    int index = 0;
    bool found = false;
    while (!found) && (index < numberUsed) {
        if (target == a[index])
            found = true;
        else
            index++;
    }
    if (found)
        return index;
    else
        return -1;
}
```

## EXAMPLE: Sorting Array

One of the widely encountered programming tasks, and certainly the most thoroughly studied, is sorting a list of values, as a list of sales figures that must be sorted from highest to lowest, or a list of words that must be sorted into alphabetical order. This describes a function sort that will sort a partially filled array of numbers that are ordered from smallest to largest.
The procedure sort has one array parameter, a. The array will be partially filled, so there is an additional formal parameter called numberUsed that tells how many array positions are used. Thus, the declaration and precondition for the function sort as follows:

```cpp
void sort(int a[], int numberUsed)
// Precondition: numberUsed <= size of the array a.
// The array elements a[0] through a[numberUsed-1] have values.
```

The function sort rearranges the elements in an array a so that after the function call the elements are sorted:

```
a[0] <= a[1] <= a[2] <= <= a[numberUsed-1]
```

The algorithm we use to do the sorting is called selection sort. It is one of the easiest of sorting algorithms to understand.

One way to design the algorithm is to rely on the definition of the problem. In this case problem is to sort an array from smallest to largest. That definition yields an outline for the selection sort:

```
for (int index = 0; index < numberUsed; index++)
Place the smallest element in a[index]
```

There are many ways to realize this approach. The elements could be developed using two arrays and copying the elements from one to the other, but one array should be adequate. Therefore, function sort uses only the array containing the values. Let us go through a concrete example so that you can see how the algorithm works.

Consider the array in Display 5.7. The algorithm will place the smallest value in a[0], so the algorithm interchanges a[0] and a[3]. The algorithm then looks for the next-smallest element. The value in a[0] is now the smallest, and so the next-smallest element is the smallest of the remaining elements a[1], a[2], ..., a[9]. In the example of Display 5.7 the next-smallest element is in a[5], so the algorithm interchanges a[1] and a[5]. This positioning of the second-smallest element is illustrated in the fourth and fifth array pictures in Display 5.7. The algorithm then positions the third-smallest element, and so forth. As the sorting proceeds, the beginning array elements are set equal to the correct values. The sorted portion of the array grows by adding elements one after other in the unsorted end of the array. Notice that the algorithm need not do anything with the last variable, a[9]. Once the other elements are positioned correctly, a[9] must also have the correct value. After all, the correct value for a[9] is the smallest value to be moved, and the only value to be moved is the value that is already in a[9].

The definition of the function sort, included in a demonstration program, is in Display 5.8. sort uses indexofsmallest to find the index of the smallest element in the unsorted end of the array, and then it does an interchange to move this next-smallest element down into the sorted part of the array.
