## Parsing Strings with the stringstream Class

We can look to the stringstream class for another example of inheritance. This class is derived from the istream class which in turn is derived from the istream. The stringstream class allows you to manipulate a string using the >> operator which is inherited from istream. This means that you can manipulate the string using the same format that you learned to process files, keyboard input, and console output. The stringstream class is useful when you need to create a string from variables of other data types or when you need to read variables of other data types from a string. To use it we must first include:

```cpp
#include <iostream>
using std::stringstream;
```

Next create an object of type stringstream:

```cpp
stringstream ss;
```

If you want to clear and initialize the stringstream to an empty string then use the following two instructions. The clear function is necessary to clear out any error status that may be stored with the stringstream. The str function is used to set the stringstream to an initial string. In the code we set the stringstream object to a blank string although you can initialize it to another string if you like.

```cpp
ss.clear();
ss.str("");
```

To create a stringstream ss from other variables use the stream insertion operator as you were outputting variables to the console. Instead of displaying the variables to the console they would be appended to the stringstream object. For example, given an int variable num set to 10 and a char variable c set to 'x' the following code inserts "x 10" into ss.

```cpp
ss << c << " " << num;
```

We use the str() method to return the value of the stringstream as a string.

```cpp
string s;
s = ss.str(""); // Sets s to the string "x 10"
```

To extract variables from a string, add the string to a stringstream object and then use the stream extraction operator as cin. They will be read from the string. For example, given the stringstream variable ss set to "x 10" we can read the variables back with the following code:

```cpp
// If ss = "x 10" then c is set to 'x' and num is set to 10
ss >> c >> num;
```

In its simplest form you can use a stringstream to convert a single numeric value to a string and vice versa.

### Display 12.9 Demonstration of the string class (part 1)

An example using the stringstream class is given in Display 12.9. In this example we start with a string containing a person's name and the person's scores. For example, if Luigi has three scores that are 70, 100, and 90 then the string "Luigi 70 100 90". The program uses the stringstream extraction operator to read the name and each score as an integer. The scores are added together, the average calculated, and then the name and average are put into a string using the stringstream insertion operator. In our example, the resulting string is "Name: Luigi Average: 86".

```cpp
#include <iostream>
#include <string>
#include <sstream>

using namespace std;

int main() {
    stringstream ss("Luigi 70 100 90");
    string name;
    int score, total = 0, count = 0;

    ss >> name;
    while (ss >> score) {
        total += score;
        count++;
    }

    double average = (double)total / count;
    stringstream result;
    result << "Name: " << name << " Average: " << average;
    cout << result.str() << endl;

    return 0;
}
```

## 12.4 Random Access to Files

If you want to be able to read and write a file in C++, use the stream class that is defined in the <fstream> library.

```cpp
fstream rwStream;
rwStream.open("stuff", ios::in | ios::out);
```

If you prefer, use the following in place of the last two of the lines:
fstream rwStream("stuff", ios::in | ios::out);

After this program, you can read from the file "stuff" using the stream fstream and also write to the file. There is no need to close and reopen the file when you change from reading to writing or from writing to reading.

At least two complications arise when reading and writing with random access via an ifstream: (1) You normally work in bytes using the type char or arrays of char and to handle type conversions on your own, and (2) you typically need to position a pointer (indicating where the read or write begins) before each read or write.
