Whenever your program outputs the first answer, it should replace the two symbols
N with a number between 1 and 20 (including the possibility of 1 and 20). In order
to choose a number between 1 and 20, your program should initialize a variable to
20 and decrease the variable's value by each time it outputs a number so that the
chapter numbers count backward from 20 to 1. When the variable reaches the value

NUMBER_OF_CHARACTERS with a global constant declaration using the const
modifier. (Hint: Use the function newline in this).

13. This project is the same as Programming Project 13.12 except that in this project
your program will use a more sophisticated method for choosing the answer to a
question. When your program reads a question, it counts the number of characters
in the question and stores the number in a variable named count. It then responds
with answer count ANSWERS. The first answer in the file is answer number-0, the next is answer 1, then 2, and so forth. ANSWERS is defined in a
constant declaration, as shown, so that it is equal to the number of answers in
the answer:

```
const int ANSWERS = 8;
```

This way you can change the answer file so that it contains more or fewer answers
you need to change only the constant declaration to make your program work
correctly for a different number of possible answers. Assume that the answer listed
in the file will always be the following, even if the answer file changed:

> I'm not sure but I think you will find the answer in Chapter #.

When replacing the two characters #N with a number, use the number
(count#NUMBER_OF_CHARACTERS + 1), where count is the variable discussed
previously, and NUMBER_OF_CHARACTERS is a global constant defined to
equal to the number of chapters in this book.

14. Write a program that reads from file and outputs each line preceded by a
line number. Print the line number right-aligned in a field of three spaces. Follow
the line with a comma, one space, then the text of the file. You should
get a character at a time, and write code to ignore leading blanks on each line.
You may assume that the lines are short enough to fit within a line on the screen.
Otherwise, allow default printer or screen output if the line is too long
(that is, wrap or truncate).

A somewhat harder version determines the number of spaces needed in the file
for the line numbers by counting lines before processing the lines of the file. This
version of the program should insert a new line after the last word that
fit within a 72-character line.
