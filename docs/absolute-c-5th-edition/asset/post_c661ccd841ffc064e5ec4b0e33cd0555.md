## Converting between string Objects and C-Strings

You have already seen that C++ will perform an automatic type conversion to allow to store a C-string in a variable of type string. For example, the following will work:

```cpp
char aString[] = "This is my C-string.";nstring stringVariable;
stringVariable = aString;
```

However, the following will produce a compiler error:
aString = stringVariable; //ILLEGAL

The following is also illegal:

```cpp
strcpy(aString, stringVariable); //ILLEGAL
```

strcpy cannot take a string object as its second argument and there is no automatic conversion of string objects to C-strings, which is the problem we seem to get away from.

To obtain the C-string corresponding to a string object you must perform an explicit conversion. This can be done with the string member function c_str(). The correct version of the copying we have been trying to do is the following:

```cpp
strcpy(aString, stringVariable.c_str()); //Legal;
```

## Answers to Self-Test Exercises

Note that you need to use the strcpy function to do the copying. The member function c_str() returns the C-string corresponding to the string calling object. As we noted earlier in this chapter, the assignment operator does not work with C-strings. So, just in case you thought it might work, we should point out that it too is illegal.

```cpp
CString = stringVariable.c_str(); //ILLEGAL
```

## Chapter Summary

- A C-string is the same thing as an array of characters, but it is used in a slightly different way. A string variable uses the null character, '\0', to mark the end of the string stored in the array.

- C-strings usually must be treated like arrays rather than variables of the kind we use for numbers and single characters. In particular, you cannot assign a C-string value to a C-string using the equal sign, =, and you cannot compare the values in two C-strings using the == operator. Instead, you must use special C-string functions to perform these tasks.

- The library <ctype> has a number of character-manipulating functions.

- You can use cin.get to read a single character of input without skipping whitespace. The function cin.get reads the next character no matter what kind of character it is.

- Various versions of the getline function can be used to read an entire line.

- The <string> library provides a fully featured string.

- Objects of the class are better than C-strings. In particular, the assignment and == operators have intuitive meanings when used with.
