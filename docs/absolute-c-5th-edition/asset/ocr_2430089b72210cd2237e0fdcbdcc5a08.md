rather the big if-else statement (highlighted in Display 18.1), this new program has the following smaller if statement (plus some simple nonbranching statements):

```
if (milk <= 0)
    throw donuts;
```

This statement says that if there is no milk, then do something exceptional. Something exceptional is given after the word catch. The idea is that normal situation is handled by the code following the try, and exceptional situations are handled by the code following the catch. Thus, we have separate case from the exceptional. This example does not really use us too much, but in other situations it will prove to be very helpful. Let us look at the details.

The basic way of handling exceptions in C++ consists of the try-throw-catch threesome. A try block has the following syntax:

```
try
{
    Some_Code
}
```

This try block contains the code for the basic algorithm that tells what to do when everything goes smoothly. It is called a try block because you are not 100% sure that all will go without a hitch, but you want to "give it a try."
