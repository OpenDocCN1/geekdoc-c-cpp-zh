## Display 3.4 A Function Using a Random Number Generator (part 1 of 2)

```cpp
#include <iostream>
#include <cstdlib>
using namespace std;

int main() {
    int month, day;
    cout << "Welcome to your friendly weather program.\n";
    cout << "Enter today's date as two integers for the month " <<
         "and the day:\n";
    cin >> month >> day;
    int prediction;
    char ans;
    cout << "Weather for today:\n";
    do {
        prediction = rand() % 3;
        switch (prediction) {
            case 0:
                cout << "The day will be sunny!\n";
                break;
            case 1:
                cout << "The day will be cloudy.\n";
                break;
            case 2:
                cout << "The day will be stormy!\n";
                break;
            default:
                cout << "Weather program is not " <<
                     "functioning properly.\n";
        }
    } while (ans == 'y' || ans == 'Y');
    cout << "That's it from your 24-hour weather program.\n";
    return 0;
}
```

## 3.2 Programmer-Defined Functions

### Function Basics

### Defining Functions That Return a Value

You can define your functions, either in the same file as the main part of your program or in a separate file so that the functions can be used by different programs. This subsection discusses only functions that return a value. Later subsection tells you how to define functions.

3.5 shows a sample function definition in a complete program that demonstrates a call to the function. The function is called totalCost and takes two arguments—the price for item and the number of items. The function returns the total cost, including sales tax, for many items at the specified price. The definition of the function, which the programmer must write, is a bit more complicated. The description of the function is given in two parts. The first part is called the function declaration or prototype. The following is the declaration for the function defined in 3.5:

```cpp
double totalCost(int numberParameter, double priceParameter);
```

The first word in a function declaration specifies the type of value returned by the function. For the function totalCost, the type of value returned is double. Next, the function declaration tells you the name of the function: in this case, totalCost. The function declaration tells you everything you need to know in order to use and call the functions. It tells you how many arguments the function needs and what the arguments should be; in this case, the function totalCost takes two arguments, the first one of int and the second one of double. The identifiers numberParameter and priceParameter are called formal parameters for short. A formal parameter is used as a kind of blank, or placeholder, to stand for the argument. When you write a function declaration, you do not know what the arguments will be, so you use the formal parameters in the place of the arguments. Names of formal parameters can be any identifier. Notice that a function declaration ends with a semicolon.

Although the declaration tells you all you need to write a function, it does not tell you what value will be returned. The value is determined by the program. The function definition describes how the function computes the value it returns in 24 to 30 lines. A function definition consists of a function header followed by a function body. The function header is written similar to the function declaration, except that the header has no semicolon at the end. The value is determined by the statements in the function body.

The function body follows the function header and completes the definition. The function body contains declarations and executable statements enclosed within a pair of braces. Thus, the body is just like the main part of a program. When the function is called, the argument values are plugged in for the formal parameters, and then the statements in the body are executed.

The value returned by the function is determined when the function executes a return statement. (The details of this "plugging in" will be discussed in Chapter 4.)

A return statement consists of the keyword return followed by an expression. The function definition in Display 3.5 shows the following return statement:

```cpp
return (subtotal + subtotal * TAXRATE);
```

When this return statement is executed, the value of the following expression is returned as the value of the function:

(subtotal + subtotal * TAXRATE)

The parentheses are not needed. The program will run if the parentheses are omitted. However, with longer expressions, the parentheses may make the return statement easier to read. For consistency, some programmers advocate using these parentheses with simple expressions. In the function definition in Display 3.5 there are no statements after the return statement, but if there were, they would not be executed. When a return statement is executed, the function ends.

Note that the function body can contain any C++ statements and that statements will be executed when the function is called. Thus, a function that returns a value may do any other action as well as return a value. In most cases, however, the main purpose of a function is to return a value to that.
