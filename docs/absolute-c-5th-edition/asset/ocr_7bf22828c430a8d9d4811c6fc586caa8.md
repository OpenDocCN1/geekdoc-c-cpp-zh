Since a pointer can be used to refer to a variable, your program can manipulate variables even if the variables have no identifiers to name them. The operator new can be used to create variables that have no identifiers to serve as their names. These nameless variables are referred to via pointers. For example, creating a new nameless variable of type int sets the pointer variable p1 equal to the address of this new variable (that is, p1 points to this, nameless variable):

```
pl = new int;
```

This new, nameless variable can be referred to as *p1 (that is, the variable pointed to p1). You can do anything with this nameless variable that you can with any other variable of type int. For example, the following code reads a value of type int from the keyboard, adds 7 to the value, and outputs this new value:

```
cin >> *p1;
*pl = *p1 + 7;
cout << *p1;
```

The new operator produces a new, nameless variable and returns a pointer that points to this variable. You specify the type for this new variable by writing the type name after the new operator. Variables that are created using the new operator are dynamically allocated variables or simply dynamic variables, because they are created and destroyed while the program is running.
