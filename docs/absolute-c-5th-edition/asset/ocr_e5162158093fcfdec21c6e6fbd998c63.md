# void Functions

A void function performs some action, but does not return a value. For a void function, a function call is a statement consisting of the function name followed by arguments enclosed in parentheses and then terminated with a semicolon. If there is more than one argument, the arguments are separated by commas. For a void function, invocation (function call) call is a statement that can be used like any other C++ statement.

# SYNTAX

```
Function_Name (Argument_List);
```

where the Argument_List is a comma-separated list of arguments:

```
Argument_1, Argument_2, . . Argument_Last
```

# EXAMPLE

```
exit(1);
```

Many implementations of pow have a restriction on what arguments can be used. In these implementations, if the first argument to pow is negative, then the second argument must be a whole number. It might be easiest and safest to use pow only when the first argument is nonnegative.

# Predefined void Functions

A void function performs some action, but does not return a value. Since it performs an action, a void function invocation is a statement. The function call for a void function is written similar to a function call for a function that returns a value, except that it is terminated with a semicolon and is used as a statement rather than an expression. Predefined void functions are handled in the same way as predefined functions that return a value. Thus, to use a predefined function, your program must have an include directive that gives the name of the library it defines the function.

For example, the exit is defined in the library cstdlib, and so a program that uses function must contain the following (or near) the start of the file:

```
#include <cstdlib>
using namespace std;
```

The following is a sample invocation (sample call) of the function exit:

```
exit(1);
```
