# String Processing with the Class string

The class allows you to perform the same operations that you can perform with the C-strings we discussed in Section 9.1 and more. (A lot more! There are over 100 members and other functions associated with the standard string class).
You can access the characters in a string in the same way that you access array elements, so string objects have the advantages of arrays plus a number of arrays that do not have, such as automatically increasing their capacity.

If lastName is the name of a string object, lastName[i] gives access to the ith character in the string represented by lastName. This use of array brackets is illustrated in 9.6.

length 9.6 illustrates the member function length. Every string object has a member function length that takes no arguments and returns the length of the string represented by the object. Thus, a string object not only be used like an array, and the length member function makes it behave like a partially filled array that automatically keeps track of how many positions are occupied.

The array brackets used with an object of the class string do not check for illegal indices. If you use an illegal index (that is, an index that is greater than equal to the length of the string in the object), the results are unpredictable and bound to be. You may get strange string behavior without any error message that tells you the problem is an illegal index value. There is a member function named at does check for an illegal index value.
