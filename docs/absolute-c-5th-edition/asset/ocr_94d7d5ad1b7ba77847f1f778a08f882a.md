# CHAPTER 2 Flow of Control

The body of a for statement may be, and commonly is, a compound statement, in the following example:

```
for (number = 100; number >= 0; number--) {
  cout << number;
  cout << "* bottles of beer on the shelf.\n";
  if (number > 0)
    cout << "Take one down and pass it around.\n";
}
```

The first and last expressions in parentheses at the start of a for statement may be any C++ expression and thus involve any number of variables and may be of any type. In a statement, a variable may be declared at the same time as it is initialized. For example:

```
for (int n = 1; n < 10; n++)
  cout << n << endl;
```

Compilers may vary in how they handle these declarations within a for statement. This is discussed in Chapter 3 in the subsection "Variables Declared in a for Loop." It might be wise to avoid such declarations within a for statement until you reach Chapter 3, but we mention it here for reference value.

| for Statement |
| SYNTAX |
| for (Initialization_Action; Boolean_Expression; Update_Action) Body_Statement |
| EXAMPLE |
| for (sum = 0, n = 1; n <= 10; n++) |
| sum = sum + n; |

# TIP: Repeat-N-Times Loops

A for statement can be used to produce a loop that repeats the loop body number of times. For example, the following is a loop body that repeats its loop body three times:

```
for (int count = 1; count <= 3; count++)
  cout << "Hip, Hip, Hurray\n";
```

The body of a for statement need not make any reference to a loop control variable, such as the variable count.
