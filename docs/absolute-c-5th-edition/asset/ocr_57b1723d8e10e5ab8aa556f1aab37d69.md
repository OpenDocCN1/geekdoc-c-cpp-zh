You can treat the identifier a as it were a pointer variable, but there is one important reservation: You cannot change the pointer value in an array variable. If the pointer variable p2 has a value, you might be tempted to think the following is legal, but it is not:

```
p2 = //ILLEGAL. You cannot assign a different address to a.
```

The underlying reason why this assignment does not work is that an array variable is not of type*, but its is the const version of int*. An array variable, like a, is a pointer variable with the modifier const, which means that its value cannot be changed.

# 10.6 Arrays and Pointer Variables

```
//Program to demonstrate that an array variable is a kind of pointer
//variable.
#include <iostream>
using namespace std;

typed int* IntPtr;

int main() {
    IntPtr p;
    int a[10];
    int index;

    for (index = 0; index < 10; index++)
        p = a;

    for (index = 0; index < 10; index++)
        cout << p[index] << " ";

    for (index = 0; index < 10; index++)
        p[index] = p[index] + 1;

    return 0;
}
```

> Note that changes to the array p are also changes to the array a.
