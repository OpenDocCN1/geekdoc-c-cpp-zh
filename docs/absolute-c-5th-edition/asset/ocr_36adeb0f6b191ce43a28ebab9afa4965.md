Stacks are used for many language processing tasks. Chapter 13 discussed how the computer system uses a stack to keep track of C++ function calls. However, here we will be concerned with one very simple application. Our goal in this example is to show how you can use the linked techniques to implement specific data structures, such as a stack.

The interface for our stack class is given in Display 17.17. This is a template with a type parameter τ for the type of data stored in the stack. One item stored in the stack is a value of type τ. In the example we present, τ is replaced by the type char. In most applications, an item in the stack is likely to be a struct or class object. Each record (item of type τ) is stored in the stack as a called frame, which will explain why we occasionally use stackFrame as an identifier name in the definition of the stack template class. There are two basic operations you can perform on a stack: adding an item to the stack and removing an item from the stack. Adding an item is called pushing the item onto the stack, and so we called the member function that does this. Removing an item from a stack is called popping the item off the stack, and so we called the member function that does this.

The names push and pop derive from a mechanism of visualizing a stack. A stack is analogous to a mechanism that is sometimes used to hold plates in a cafeteria. The mechanism stores plates in a hole in the countertop. There is a spring underneath the plates with its tension adjusted so that only the top plate protrudes above the countertop. If this sort of mechanism were used as a stack data structure, the data would be written on plates (which might violate some health laws, but still makes a good analogy). To add a plate to the stack, you put it on top of the other plates, the weight of the new plate pushes down the spring. When you remove a plate, the plate below it pops into view.

Display 17.18 shows a simple program that illustrates how the stack class is used. This program reads a line of text one character at a time and places the characters in a stack. The program removes the characters by one and writes them to the screen. Data is removed from a stack in the reverse of the order in which it enters the stack, the output shows the line written backward. We have #included the implementation of the stack class in our application program, as we normally do with template classes. That means we cannot run or even compile our program until we do the implementation of our stack class template.
