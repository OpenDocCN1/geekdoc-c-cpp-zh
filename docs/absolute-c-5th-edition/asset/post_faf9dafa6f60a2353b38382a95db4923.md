
## Tools for Stream I/O 537

Output streams have other member functions besides precision and setf. One commonly used formatting is width. For example, consider the following call to width made by the stream cout:

```
cout << "Start Now";
cout.width(4);
cout << 7 << endl;
```

This code will cause the line to appear on the screen:

Start Now 7

This output has exactly three spaces between the letter 'w' and the number 7. The width function tells the stream how many spaces to use when giving an item as output. In this case the number 7 occupies only one space and width is set to use four spaces, so three of the spaces are blank. If the output requires more space than you specified in the argument to width, then as much additional space as needed will be used. The entire item is always outted, no matter what argument you give to.

## The class ios

The class ios has a number of important defined constants, such as ios::app (used to indicate that you are appending to a file) and the flags listed in Display 12.5. The class ios is defined for output streams, such as <iostream> and <fstream>. One to make the class ios and hence all these constants (all these flags) available to your code is the following:

```
#include <iostream> //or #include <fstream> or both
using std::ios;
```

unset Any flag that is set. To unset a flag, use the function unsetf. For example, the following will cause your program to stop including plus signs on positive integers that are output to the stream cout:

```
unsetf(ios::showpos);
```

When a flag is set, it remains set until it is unset. The effect of a call to precision stays in effect until precision is reset. However, the member function width behaves. ## Manipulators

A manipulator is a function that is called in a nontraditional way. Manipulators are placed after the insertion operator, just as if the manipulator function call an item to be output. Like traditional functions, manipulators may or not have arguments. We have already seen one manipulator, endl. This subsection discusses setw and setprecision.

The manipulator setw and the member function width which you have already seen do exactly the same thing. You call the setw by writing it after the insertion operator, <<, if it were to be sent to the output stream, and in this calls the member function width. For example, the following will output the numbers 10, 20, and 30, using the width fields:

```
cout << "Start" << setw(4) << 10
<< setw(4) << 20 << setw(6) << 30;
```

The preceding statement will produce the following output:

```
Start 10 20    30
```

(There are two spaces before the 10, two spaces before the 20, and four spaces after the 30.)

Like the member function width, a call to setw applies only to the next item, but it is easier to make multiple calls to setw than it is to make multiple calls to width.

The manipulator setprecision does the same thing as the member function precision (which you have already seen). However, a call to setprecision is written after the insertion operator, <<, in a manner similar to how you call the setw manipulator. For example, the following will output the numbers listed using the number of digits after the decimal point that is indicated by the call to setprecision:

```
cout(ios::fixed);
cout(ios::showpoint);
out << "$" << setprecision(2) << 10.3 << endl
<< "$" << 20.5 << endl;
```

The previous statement will produce the following output:

```
$10.30
$20.50
```

When you set the number of digits after the decimal point using the manipulator setprecision, just as was case with the member function precision, the setting stays until you reset it to some other number by another call to either setprecision or precision.

To use either of the manipulators setw or setprecision, you must include the following directive in your program:

```
#include <iomanip>
using namespace std;
```

Or, you must use one of the other ways of specifying the names and namespace, such as the following:

```
#include <iomanip>
using std::setw;
using std::setprecision;
```

## Saving Flag Settings

A function should not have unwanted or unexpected side effects. For example, a function to output amounts of money might contain

```
cout.setf(ios::fixed);
out.setf(ios::showpoint);
out.precision(2);
```

After the function invocation, these settings will still be in effect. If you do not want side effects, you can save and restore the original settings. The function `precision` has been overloaded so that with no arguments it returns the current precision so the setting can be restored. The flags with `set` are easy to save and restore the flag settings. The member function `cout.flags()` returns a value of `long` that codes all the flags. The flags can be reset by using this `long` value as an argument to `cout.flags`. These techniques work well for file output streams as they do for `cout`. For an example, to save and restore these settings could be structured as follows:

```
void outputStream(ostream out)
{
    int precisionSetting = out.precision();
    long flagSettings = out.flags();
    out.setf(ios::fixed);
out.setf(ios::showpoint);
out.precision(2);
    //Do whatever you want here.
out.precision(precisionSetting);
out.flags(flagSettings);
}
```

Another way to restore settings

```
cout.setf(0, ios::floatfield);
```

An invocation of the member function `set` with these arguments will restore the `default` settings. Note that these the default values, not necessarily the settings before the last time they were changed. Also note that the default setting values are implementation-dependent. Finally, note that this does not reset `precision` settings or any settings that are not set with `setf`.
