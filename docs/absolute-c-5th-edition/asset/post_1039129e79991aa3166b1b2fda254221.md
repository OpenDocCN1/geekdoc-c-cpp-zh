## PITFALL: Unexpected '\n' in Input

When using the function `get` you must account for every character of input, even the characters you do not think of as symbols, such as blanks and the newline character, '\n'. A common problem with `get` is forgetting to dispose of the '\n' that enters every input line. If there is a newline character in the input stream that is not read (usually discarded), then when your program expects to read a "real" symbol using the function `get`, it will instead read the character '\n'. To clear the input of leftover '\n', you can use the function `newLine()`, which we defined in Display 9.2 (or you can use the function `ignore`, which we discuss in the next section). Let us look at a concrete example. It is legal to mix different forms of `cin`. For example, the following is legal:

```cpp
cout << "Enter a number:\n";
int number;
cin >> number;
cout << "Enter a letter:\n";
char symbol;
cin.get(symbol);
```

However, this can produce problems, as illustrated by the following dialogue:

```
Enter a number:
21
Enter a letter:
A
```

With this dialogue, the value of `number` will be 21 as you expect. However, if you expect the value of the `symbol` is 'A', you will be disappointed. After reading 21, the next character in the input stream is the newline character, '\n', and so that is next. Remember, `get` does not skip line breaks and spaces. (In fact, what is in the rest of the program, you may not get a chance to type in the A. Once the symbol is filled with the character '\n', the program proceeds to whatever statement is next in the program. If the next statement sends to output, the screen will be filled with output before you get a chance to type in the A.)

## PITFALL: (continued)

The following rewriting of the previous code will cause the previous dialogue to fill the variable `number` with 21 and fill the variable `symbol` with 'A':

```cpp
cout << "Enter a number:\n";
int number;
cin >> number;
cout << "Now enter a letter:\n";
char symbol;
cin >> symbol;
```

Alternatively, you can use the function `newline()`, defined in Display 9.2, as follows:

```cpp
cout << "Enter a number:\n";
int number;
cin >> number;
newline();
cout << "Now enter a letter:\n";
char symbol;
cin.get(symbol);
```

As this second rewrite indicates, you can mix the two forms of `cin` and have your program work correctly, but it requires some extra care.
As third alternative, you could use the function `ignore()`, which we discuss in the next subsection.

## The putback, peek, and ignore Member Functions

Sometimes your program needs to know the next character in the input stream. However, after reading the next character, it might turn out that you do not want to process that character and so like to "put it back". For example, if you want your program to read up to but not include the blank it encounters, your program must read that first blank in order to know when to stop reading—but then that blank is no longer in the input stream. Some other part of your program might need to read and process that blank. One way to deal with this is to use the member function `cin.putback()`. The function `cin.putback` takes one argument of type `char` and places the value of that argument back in the input stream that it will be the next character to be read. The argument is any expression that evaluates to a value of type `char`. The member function `putback` need not be the last character read; it can be any character you wish.

The `peek` member function does what you expect from its name. `cin.peek()` returns the next character to be read by `cin`, but it does not use that character; the next read starts with that character. In other words, the `peek` function peeks to tell your program what the next character to be read will be.

```
putback
```

```
peek()

If you want to skip over input up to some designated character, such as the newline character '\n', you can use the `ignore` member function. For example, the following skip over all input characters up to and including the newline character, '\n':

```cpp
cin.ignore(1000, '\n');
```

The 1000 is the maximum number of characters to ignore. For the delimiter, in this case '\n', has it not been found after 1000 characters, no more characters are ignored. Of course, a different argument can be used in place of 1000 and a different character argument can be used in place of '\n'.

As we will see in Chapter 12, the member functions `putback`, `peek`, and `ignore` can be used with `cin` replaced by a file input stream object for text file input.

## Character-Manipulating Functions

In processing you often want to convert lowercase to uppercase or vice versa. The function `toupper` can be used to convert a lowercase letter to uppercase. For example, `toupper('a')` returns 'A'. `tolower` is similar except that it converts uppercase to its lowercase version.

Note that `<ctype>` places these in the global namespace, so any program that uses these must contain:

```cpp
#include <ctype>
```

The `isspace` function returns true if its argument is a whitespace character. Whitespace characters are all the characters displayed as blank on screen, including the newline character. If the argument is not a whitespace character, then isspace returns false. Thus, isspace(' ') returns true and isspace('a') returns false.

## The putback, peek, and ignore Member Functions

## The putback, peek, and ignore Member Functions

Sometimes your program needs to know the next character in the input stream. However, after reading the next character, it might turn out that you do not want to process that character and so like to "put it back". For example, if you want your program to read up to but not include the blank it encounters, your program must read that first blank in order to know when to stop reading—but then that blank is no longer in the input stream. Some other part of your program might need to read and process that blank. One way to deal with this is to use the member function `cin.putback()`. The function `cin.putback` takes one argument of type `char` and places the value of that argument back in the input stream that it will be the next character to be read. The argument is any expression that evaluates to a value of type `char`. The member function `putback` need not be the last character read; it can be any character you wish.

The `peek` member function does what you expect from its name. `cin.peek()` returns the next character to be read by `cin`, but it does not use that character; the next read starts with that character. In other words, the `peek` function peeks to tell your program what the next character to be read will be.
