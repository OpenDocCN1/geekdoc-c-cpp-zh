A stream is a flow of characters (or other kind of data). If the flow is out your program, the stream is called an output stream. If the flow is out of your program, the stream is called an input stream. If the input stream flows from the keyboard, your program will take input from the keyboard. If the input stream flows from a file, your program will take its input from the file. Similarly, an output stream can go to the screen or to a file.

Although you may not realize it, you have already been using streams in your programs. The cin that you have already used is an input stream connected to the keyboard, and cout to the screen. These two streams are automatically available to your program as long as it has an include directive for the header <iostream> and a using directive for the std namespace. You can define other streams that come from or go to files; you can use them in your program the same way you have defined cin and cout. For example, suppose your program defines a stream called inStream that comes from some file. (We will tell you how to define it shortly.) You then fill an int variable named theNumber with a number from this file using the following in your program:

```
int theNumber;
inStream << theNumber;
```

Similarly, if your program defines an output stream outStream that goes to another file, you can output the value of the variableNumber to this file. The following will output the string "theNumber is " followed by the contents of the variableNumber to the output that is connected to the stream outStream:

```
outStream << "theNumber is " << theNumber << endl;
```

Once the streams are connected to the desired files, your program can perform I/O the same way it does I/O using the keyboard and screen.
