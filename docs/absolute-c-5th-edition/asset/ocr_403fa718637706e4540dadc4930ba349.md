<< and >> return a reference

The extraction operator >> is overloaded in a way that is analogous to what we
described for the insertion operator <<. However, with the extraction (input) operator
>>, the second argument is the object that receives the input value, so
the second parameter must be an ordinary call-by-reference parameter. In outline the
definition for the overloaded extraction >> is as follows:

```
istream operator >>(istream& inputStream, Money& amount)
    /*This part is the same as the body of
Money::input, which is given in Display 8.1 (except that
dollars are replaced with amount.dollars
and cents are replaced by amount.cents.*
    return inputStream;
}
```

The complete definitions of the overloaded operators << and >> are given in
Display 8.5, where we have rewritten the class Money yet. This time we have
ritten the class so that the operators << and >> are overloaded to allow us to use
these operators with type Money.
Note that you cannot realistically overload >> or << as members. If << and
>> to work as we want, then the first operand (first argument) must be cout or cin\(or some file I/O stream). But if we want to overload the operators as members of, say,
t class Money, then the first operand would have to be the calling object and so
will be of type Money, and that will not allow you to define the operators so they
behave in the normal way for >> and <<.
