# Pointer Arithmetic

You can perform a kind of arithmetic on pointers, but it is an arithmetic of addresses. For example, suppose your program contains the following code:

```
```
typed double* DoublePtr;
DoublePtr d;
d = new double[10];n```
```

After these statements, d contains the address of the indexed variable d[0]. The expression d + 1 evaluates to the address of d[1], d + 2 is the address of d[2], and so forth. Notice that the value of d is an address and not a number, d + 1 does not simply add 1 to the number in d. If a variable of double requires eight bytes (eight memory locations) and d contains the address 2000, d + 1 evaluates to the memory address 2008. Of course, the double can be replaced by any other type, and pointer addition moves in units of variables for that type.
