# Input and Output Member Functions

| FORM OF A FUNCTION CALL | DESCRIPTION | HEADER FILE |
|---|---|--|
| Stream_Var.open (External_File_Name); | Connects the file with the External_File_Name named by the Stream_Var. The External_File_Name is a C-string value. | fstream |
| Stream_Var.fail( ); | Returns true if the previous operation (such as open) on the stream Stream_Var has failed. | fstream |
| Stream_Var.close( ); | Disconnects the stream Stream_Var from the file it connected to. | fstream |
| Stream_Var.bad( ); | Returns true if the stream Stream_Var is corrupted. | fstream |
| Stream_Var.eof( ); | Returns true if the program has attempted to read beyond the last character in the file. Otherwise, it returns false. | fstream |
| Stream_Var.get(Char_Variable); | Reads one character from the input stream Stream_Var and sets Char_Variable equal to this character. Does not skip whitespace. | fstream |
| Stream_Var.getline(String_Var, Max_Characters); | Reads one line from the stream Stream_Var and the resulting string is placed in String_Var. If the line is more than Max_Characters long, only the first Max_Characters are read. | fstream |
| Stream_Var.peek( ); | Reads one character from the input stream Stream_Var and returns that character. The character read is not removed from the input stream. | fstream |
| Stream_Var.put(Char_Exp); | Writes the value of Char_Exp to the output stream Stream_Var. | fstream |
| Stream_Var.putback(Char_Exp); | Places the value of Char_Exp in the input stream Stream_Var so that the next value from the stream is not changed. | fstream |
| Stream_Var.precision(Int_Exp); | Specifies the number of digits output after the decimal point for floating-point values sent to the output Stream_Var. | fstream |
| Stream_Var.width(Int_Exp); | Sets the field width for the next value output to the stream Stream_Var. | fstream |
| Stream_Var.setf(Flag); | Sets flags for formatting output to the stream Stream_Var. See Display 2.5 for the list of possible flags. | fstream |
| Stream_Var.unsetf(Flag); | Unsets flags for formatting output to the stream Stream_Var. See Display 2.5 for the list of possible flags. | fstream |

# Character Functions

For all these, the actual type of the argument is int, but for most purposes you can think of the argument as char. For tolower and toupper, the type returned is an int. To use the value as char, you must perform an explicit or implicit cast.

| FUNCTION | DESCRIPTION | HEADER FILE |
|---|---|---|
| bool isnum(char); | Returns true if its argument satisfies alpha or isdigit. Otherwise returns false. | cctype |
| bool isalpha(char); | Returns true if its argument is an upper- or lowercase letter. It may also return true for other arguments. The details are implementation dependent. Otherwise returns false. | cctype |
| bool isdigit(char); | Returns true if its argument is a digit. Otherwise returns false. | cctype |
| bool ispunct(char); | Returns true if its argument is a printable character that does not satisfy isnum and is not whitespace. (These characters are considered punctuation characters.) Otherwise returns false. | cctype |
| bool isspace(char); | Returns true if its argument is a whitespace character (e.g., blank, tab, newline). Otherwise returns false. | cctype |
| bool iscntrl(char); | Returns true if its argument is a control character. Otherwise returns false. | cctype |
| bool islower(char); | Returns true if its argument is a lowercase letter. Otherwise returns false. | cctype |
| bool isupper(char); | Returns true if its argument is an uppercase letter. Otherwise returns false. | cctype |
| int tolower(char); | Returns the lowercase version of its argument. If there are no lowercase versions, returns its argument unchanged. | cctype |
| int toupper(char); | Returns the uppercase version of its argument. If there are no uppercase versions, returns its argument unchanged. | cctype |

# C-String Functions

| FUNCTION DECLARATION | DESCRIPTION | HEADER FILE |
|---|---|--|
| int atoi(const char[]); | Converts a C-string of characters to an integer. | cstdlib |
| long atol(const char[]); | Converts a C-string of characters to a long integer. | cstdlib |
| double atof(const char[]); | Converts a C-string of characters to a double. | cdbib* |

| strcmp(C-String_Variable, C-String_Expression); | Returns true if the two strings are different; otherwise, returns false. | cstring |
| strncpy(C-String_Variable, C-String_Expression); | Changes the value of the C-String_Variable to the value of C-String_Expression. | cstring |
| strstr(C-String_Expression, Pattern); | Returns a pointer to the first occurrence of the string Pattern in C-String_Expression. Returns NULL if Pattern is not found. | cstring |
| strchr(C-String_Expression, Character); | Returns a pointer to the first occurrence of the Character in C-String_Expression. Returns NULL if Character is not found. | cstring |
| strrchr(C-String_Expression, Character); | Returns a pointer to the last occurrence of the Character in C-String_Expression. Returns NULL if Character is not found. | cstring |
| strlen(C-String_Expression); | Returns the length of the C-String_Expression. | cstring |
