# Function Declaration (Function Prototype)

A function declaration (function prototype) tells you all you need to know to write a call to the function. A function declaration (or the full function definition) must appear in the main part prior to a call to the function. your program.

# SYNTAX

```
Type_Returned_Or_void FunctionName (Parameter List);
```

where the Parameter_List is a comma-separated list of parameters:

```
Type_1 Formal_Parameter_1, Type_2 Formal_Parameter_2,...
Type_3 Formal_Parameter_Last
```
