```cpp
int main ()
{
    IntPointer p;
    p = new int;
    *p = 77;
    cout << "Before call to function *p == "
         << *p << endl;

    sneaky(p);

    return 0;
}
void sneaky(IntPointer temp)
{
    *temp = 99;
    cout << "Inside function call *temp == "
         << *temp << endl;
}
```

## 10.2 Dynamic Arrays

In this section you will see that arrays are actually pointer variables. You will also find out how to write programs with dynamically allocated arrays. A dynamically allocated array (also called simply a dynamic array) is an array whose size is not specified when you write the program, but is determined when the program is running.

## Array Variables and Pointer Variables

Chapter 5 describes how arrays are kept in memory. At this point we discussed arrays in terms of memory addresses. A memory address is a pointer. So, in C++ an array variable is actually a kind of pointer variable that points to the first indexed variable of the array. Given the following two variable declarations, p and a are both pointer

```cpp
int a[10];
typedef int* IntPtr;
IntPtr p;
```

The fact that a and p are both pointer variables is illustrated in Dynamic 10.6. Since a is a pointer that points to a variable of type int (namely, the variable a[0]), the value of a can be assigned to the pointer p as follows:

```cpp
p = a;
```

After this assignment, p points to the same memory location that a points to. Thus, p[0], p[1], ... p[9] refer to the indexed variables a[0], ... a[9]. The square bracket notation you have been using for arrays applies to pointers as long as the pointer variable points to an array in memory. After the previous assignment, you can treat the identifier p as if it were an array identifier. You can treat the identifier a as it were a pointer variable, but there is one important reservation: You cannot change the pointer value in an array variable. If the pointer variable p2 has a value, you might be tempted to think the following is legal, but it is not:

```cpp
p2 = // //ILLEGAL. You cannot assign a different address to a.
```

The underlying reason why this assignment does not work is that an array variable is not of type*, but it is the const version of int*. An array variable, like a, is a pointer variable with the modifier const, which means that its value cannot be changed.

## 10.6 Arrays and Pointer Variables

```cpp
//Program to demonstrate that an array variable is a kind of pointer
// variable.
#include <iostream>
using namespace std;

typedef int* IntPtr;

int main() {
    IntPtr p;
    int a[10];
    int index;

    for (index = 0; index < 10; index++)
        p = a;

    for (index = 0; index < 10; index++)
        cout << p[index] << " ";

    for (index = 0; index < 10; index++)
        p[index] = p[index] + 1;

    return 0;
}
```

> Note that changes to the array p are also changes to the array a.

## Creating and Using Dynamic Arrays

One problem with the kinds of arrays we discussed in Chapter 5 is that you must specify the size of the array when you write the program—but you may not know what size you need until the program is run. For example, an array might hold a list of student identification numbers, but the size of the class may be different each time the program is run. With the kinds of arrays you have used so far, you must estimate the largest size you need. There are two problems with this: First, if you estimate too large, you will waste memory. Second, if you estimate too low, the program will not work.

Dynamically allocated arrays solve this by allowing the size to be determined at runtime. The size of the array is given by a variable, not a constant. For example, an array might hold a list of student identification numbers, but the size of the class may be different each time the program is run.
