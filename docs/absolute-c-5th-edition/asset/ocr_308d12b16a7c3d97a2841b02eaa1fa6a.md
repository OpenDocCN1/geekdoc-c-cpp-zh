# The break and continue Statements

In previous subsections, we have described the basic flow of control for the while-do, and for loops. This is how the loops normally be used and where they are usually applied. However, you can alter the flow of control in two ways, which rare cases can be a safe and useful technique. The two ways of altering the flow of control are to insert a break or continue statement. The break statement ends the loop. The continue statement ends the current iteration of the loop body. The break statement can be used with any of the C++ loop statements.
