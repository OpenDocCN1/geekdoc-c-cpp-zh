
## CHAPTER 8 Operator Overloading, Friends, and References

Display 8.4 << as an Operator

means the same as

```
(cout << "I have") << amount << " in my purse.\n";
```

and is evaluated as:

First evaluate (cout << "I have"), which returns cout:
((cout << "I have") << amount) << " in my purse.\n";
The string "I have" is output.

```
(cout << amount) << " in my purse.\n";
```

Then evaluate (cout << amount), which returns cout:

```
(cout << amount) << " in my purse.\n";
The value of amount is output.
```

Once we have overloaded the insertion (output) operator <<, we will no longer need the member function output. The definition of the overloaded operator << is very similar to the member function output. In form, the definition of the overloaded operator is as follows:

```cpp
ostream& operator << (ostream& outputStream, const Money&)
{
    /* This part is the same as the body of
    Money::output which is given in Display 8.1 (except that
    dollars is replaced with amount
    and cents is replaced by amount.) */
    return outputStream;
}
```

<< and >> return a reference

The extraction operator >> is overloaded in a way analogous to what we described for the insertion operator <<. However, with the extraction (input) operator >> the second argument is the object that receives the input value, so the second parameter must be an ordinary call-by-reference parameter. In the definition for the overloaded extraction >> is as follows:

```cpp
istream& operator >> (istream& inputStream, Money& amount)
{
    /* This part is the same as the body of
    Money::input which is given in Display 8.1 (except that
    dollars are replaced with amount
    and cents are replaced by amount.) */
    return inputStream;
}
```

The complete definitions of the overloaded operators << >> are given in Display 8.5, where we rewritten the class so that the operators << >> are overloaded to allow us to use these operators with type Money. Note that you cannot realistically overload >> or << as members. If we want << and >> to work as we want, then the first operand (first argument) must be cout or cin (or some I/O stream). But if we want to overload the operators as members of say, class Money, then the first operand would have to be the calling object and so will not allow you to define the operators behave in the normal way for >> <<.

### Display 8.5 Overloading << >> (part 1 of 3)

```cpp
#include <iostream>
#include <cstdlib>
#include <cmath>
using namespace std;

// Class for amounts of money in U.S.
class Money
{
public:
    Money();
    Money(double amount);
    Money(int dollars, int cents);
    Money(int dollars);
    double getAmount() const;
    int getDollars() const;
    int getCents() const;
```

### Display 8.5 Overloading << >> (part 2 of 3)

```cpp
friend const operator +(const Money& amount1, const Money& amount2);
friend const operator -(const Money& amount1, const Money& amount2);
friend bool operator==(const Money& amount1, const Money& amount2);
friend const Money operator << (ostream& outputStream, const Money& amount);
friend ostream& operator >> (ostream& inputStream, Money&);

private:
    // A negative amount is represented as negative dollars and negative cents.
    // Negative $4.50 is represented as -4 and -50.
    int dollars, cents;
    int dollarsPart(double amount) const;
    int centsPart(double amount) const;
    int round(double number) const;

int main() {
    Money yourAmount, myAmount(10, 9);
    cout << "Enter an amount of money: ";
    cin >> yourAmount;
    cout << "Your amount is " << yourAmount << endl;
    cout << "My amount is " << myAmount << endl;
    if (yourAmount == myAmount)
        cout << "We have the same amounts.\n";
    else
        cout << "One of us is richer.\n";
    Money diffAmount = yourAmount - myAmount;
    cout << yourAmount << " - " << myAmount << " equals " << diffAmount << endl;

    return 0;
}
```

### Display 8.5 Overloading << >> (part 3 of 3)

```cpp
ostream& operator << (ostream& outputStream, const Money& amount)
{
    int absDollars = abs(amount.dollars);
    int absCents = abs(amount.cents);
    if (amount.dollars < 0 || amount.cents < 0)
        // accounts for dollars == 0 or cents == 0
        outputStream << "$";
    else
        outputStream << '$';
    outputStream << absDollars;
    if (absCents >= 10)
        outputStream << '.' << absCents;
    else
        outputStream << ".00" << absCents;
    return outputStream;
}
```

```cpp
// Uses iostream and cstdlib
istream& operator >> (istream& inputStream, Money& amount)
{
    char dollarSign;
    inputStream >> dollarSign; // hopefully
    if (dollarSign != '$')
    {
        cout << "No dollar sign in Money input.\n";
        exit(1);
    }
    double amountAsDouble;
    inputStream >> amountAsDouble;
    amount.dollars = amount.dollarsPart(amountAsDouble);
    amount.cents = amount.centsPart(amountAsDouble);
    return inputStream;
}
```
