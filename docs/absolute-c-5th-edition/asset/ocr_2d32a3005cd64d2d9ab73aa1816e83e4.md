# 10.2 Dynamic Arrays

In this section you will see that arrays are actually pointer variables. You will also find out how to write programs with dynamically allocated arrays. A dynamically allocated array (also called simply a dynamic array) is an array whose size is not specified when you write the program, but is determined when the program is running.

# Array Variables and Pointer Variables

Chapter 5 describes how arrays are kept in memory. At this point we discussed arrays in terms of memory addresses. A memory address is a pointer. So, in C++ an array variable is actually a kind of pointer variable that points to the first indexed variable of the array. Given the following two variable declarations, p and a are both pointer

```
int a[10];ntyped int* IntPtr;
IntPtr p;
```

The fact that a and p are both pointer variables is illustrated in Dynamic 10.6. Since a is a pointer that points to a variable of type int (namely, the variable a[0]), the value of a can be assigned to the pointer p as follows:

```
p = a;
```

After this assignment, p points to the same memory location that a points to. Thus, p[0], p[1], ... p[9] refer to the indexed variables a[0], ... a[9].
