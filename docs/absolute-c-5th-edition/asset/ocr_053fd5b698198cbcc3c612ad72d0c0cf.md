# Type Definitions

You can assign a name to a type definition and then use the name to declare variables. This is done with the keyword typedef. These type definitions are normally placed outside the body of the main part of program and outside the body of functions, typically near the start of a file. That the typedef is global and available to your entire program. We will use typedef to define names for pointer types, as shown in the example here.

# SYNTAX

```
typedef Known_Type_Definition New_Type_Name;
```

# EXAMPLE

```
typedef int* IntPtr;
```

The name IntPtr can be used to declare pointers to dynamic variables of type int, as in the following example:

```
IntPtr pointer1, pointer2;
```

# PITFALL: Pointers as Call-by-Value Parameters

When a call-by-value parameter is a pointer type, its behavior can occasionally be subtle and troublesome. Consider the function call in Display 10.4. The parameter temp in the function sneaky is a call-by-value parameter, and hence it is a local variable. When the function is called, the value of temp is set to the value of the argument p and the function is executed. Since temp is a local variable, no changes to temp should go outside the function sneaky. In particular, the value of the pointer p should not be changed. The sample dialogue makes it like the value of the pointer variable p has changed. Before the call to the function sneaky, the value of *p was 77, and after the call to sneaky the value of *p is 99. What happened?

The situation is diagrammed in Display 10.5. Although the sample dialogue makes it as if the value of p was not changed by the function call to sneaky. p has two things associated with: p's value and the value stored where p points. But the value of p is the pointer (that is, a memory address). After the call to sneaky, the variable p contains the pointer value (that is, the same memory address). The call to sneaky has changed the value of the variable pointed to by p, but it has not changed the value of p.

If the pointer type is a class or structure that has members of a pointer type, the same kind of surprising changes can occur with call-by-value arguments of the class type. However, for classes, you can avoid (and control) these surprise changes by defining a copy constructor, as described in this chapter.
