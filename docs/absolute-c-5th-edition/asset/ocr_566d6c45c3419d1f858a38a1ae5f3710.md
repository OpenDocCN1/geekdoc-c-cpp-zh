# Old and New Header Files 5

In this book, we have used the header files for standard libraries that are part of the new ANSI/ ISO C++ standard. If you have an older compiler, you may need to use the older header files. In the following, we list the new header file names that we have used in this book along with their corresponding older header file names. If the new header do not work for you, then try the older header file names instead.

If your compiler requires the older header file names, then it also may not accommodate namespaces. In that case, you may have to eliminate all references to namespaces. A compiler that requires the older header file names and/or does not support namespaces, you should consider obtaining a new compiler that closer to meeting the new standard.

| NEW HEADER FILE | CORRESPONDING OLD HEADER FILE |
|---|---|n| cassert | assert.h |
| cctype | ctype.h |
| cstddef | stddef.h |
| cstdlib | stdlib.h |
| cmath | math.h |
| cstring | string.h |
| fstream | fstream.h |
| iomanip | iomanip.h |
| iostream | iostream.h |
| string | string or no corresponding library |
