
## Introduction to Arrays

These individual variables that make up the array are referred to by a variety of different ways. We will call them indexed variables, though they are sometimes called subscribed variables or elements of the array. In square brackets in C++, indexes are always starting with 0, not starting with 1 or any other number. The number of indexed variables in an array is called the size of the array, or sometimes simply the size of the array. When an array is declared, the size of the array is given in square brackets after the array name. The indexed variables are then numbered (using square brackets), starting with 0 and ending with the integer that is less than the size of the array.

In our example, the indexed variables were of type int, but an array can have indexed variables of any type. For example, to declare an array with indexed variables of double, simply use the type name instead of int in the declaration of the array. All indexed variables for one array, however, are of the same type. The type is called the base type of the array. Thus, by our example of the array score, the type is int.

You can declare arrays and regular variables together. For example, to declare two int variables next and in addition to the array score:

```cpp
int next, score[5], max;
```

An indexed variable such as score[3] can be used anywhere that an ordinary variable of type int can be used.

Do not confuse the two ways to use the square brackets, [], with an array name. When used in a declaration, as

```cpp
int score[5];
```

the number enclosed in the square brackets specifies how many indexed variables the array has. When used anywhere, the number enclosed in the square brackets tells which indexed variable is meant. For example, score[0] through score[4] are indexed variables of the array previously declared.

The inside square brackets need not be given as an integer constant. You can use any expression in the square brackets that evaluates to one of the integers from 0 through the one less than the size of the array. For example, the following will set the score[3] equal to 99:

```cpp
int n = 2;
score[n + 1] = 99;
```

Although they may look different, score[n + 1] and score[3] are the same indexed variables in the previous code, because n + 1 evaluates to 3.

The identity of an indexed variable, as score[i], is determined by the value of its index, which in this is i. You can write programs that say things like "do so and such to the ith indexed variable," where the value of i is computed by the program. For example, the program in Display 5.1 results in scores and processes them in the way described at the start of this chapter.

### Display 5.1 Program Using an Array

```cpp
// Reads in five scores and shows how much each
// score differs from the highest score.
#include <iostream>
using namespace std;

int main() 
{
    int i, score[5], max;

    cout << "Enter 5 scores:\n";
    cin >> score[0];
    max = score[0];
    for (i = 1; i < 5; i++) {
        cin >> score[i];
        if (score[i] > max) {
            max = score[i];
        }
        // max is the largest of the values score[0],..., score[i].
    }

    cout << "The highest score is " << max << endl;
    cout << "The scores and their\n";
    cout << "differences from the highest are:\n";
    for (i = 0; i < 5; i++) {
        cout << score[i] << " off by "
             << (max - score[i]) << endl;
    }
    return 0;
}
```

> **TIP:** Use for Loops with Arrays

The second for loop in Display 5.1 illustrates a common way to step through an array:

```cpp
for (i = 0; i < 5; i++)
cout << score[i] << " off by "
  << (max - score[i]) << endl;
```

The statement is ideally suited to array manipulations.

> **PITFALL:** Array Indexes Always Start with Zero

The indexes of an array always start with 0 and end with the integer that is less than the size of array.

> **TIP:** Use a Defined Constant for the Size of an Array

Look again at the program in Display 5.1. It only works for classes that have exactly five students. Most classes do not have exactly five. One way to make a program more versatile is to use a defined constant for the size of each array. For example, the program in Display 5.1 could be rewritten to use the following defined constant:

```cpp
const int NUMBER_OF_STUDENTS = 5;
```

The line with the array declaration would be

```cpp
int i, array[NUMBER_OF_STUDENTS], max;
```
