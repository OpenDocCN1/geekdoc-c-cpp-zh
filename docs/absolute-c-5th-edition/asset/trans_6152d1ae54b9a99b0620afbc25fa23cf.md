本节概述了 C++ 编程语言。

C++ 编程语言可以被看作增加了类（以及其他现代特性）的 C 语言。C 语言是由 AT&T 贝尔实验室的丹尼斯·里奇（Dennis Ritchie）在 20 世纪 70 年开发的。它最初用于编写和维护 UNIX 操作系统。（在此之前，UNIX 系统是用汇编语言或一种名为 B 的语言编写的，B 是由 UNIX 的创始人肯·汤普森开发的语言。）C 是一种通用语言，可以用于编写任何类型的程序，但它的成功和流行与 UNIX 操作系统紧密相关。如果你想维护你的 UNIX 系统，你需要使用 C，而 C 和 UNIX 配合得非常好，以至于不仅是系统程序，几乎所有在 UNIX 下运行的商业程序都是用 C 语言编写的。C 变得如此流行，以为其他流行的操作系统编写了该语言的版本；因此，它的使用不仅限于使用 UNIX 的计算机。然而，尽管非常流行，C 并非没有缺点。

### C++ 语言的起源

C++ 简介

C 语言很奇特，因为它是一种具有许多低级语言特性的高级语言。C 处于极高级语言和低级语言这两个极端之间，这正是它的优点和缺点所在。。像（低级）汇编语言一样，C 程序可以直接操作计算机的内存。另一方面，C 具有高级语言的特性，使得它比汇编语言更容易阅读和编写。这使得 C 成为编写系统程序的极佳选择，但对于其他程序（在某种意义上对于系统程序），C 不像其他语言那样容易理解；此外，它没有其他高级语言那样的自动检查。

为了克服 C 的这些和其他缺点，AT&T 贝尔实验室的比雅尼·斯特鲁斯特普（Bjarne Stroustrup）在 20 世纪 80 年代初开发了 C++。斯特鲁斯特普设计 C 是为了更好的 C。C 的大部分是 C++ 的子集，且大多数 C 程序也是 C 程序。反之则不然；许多 C++ 程序不是 C 程序。）与 C 不同，C++ 拥有类机制并可以用于面向对象编程。

### C++ 与面向对象编程

面向对象编程（OOP）是一种目前流行且强大的编程技术。OOP 的主要特点是封装、继承和多态。封装是信息隐藏和抽象的形式。多态指的是在继承语文中，同一个名称可以具有多种含义。在做出这些声明之后，我们必须承认对于没有听过 OOP 的读者来说，这些话意义不大。然而，我们将在书中详细描述这些术语。C++ 通过提供类来适应 OOP，类是种结合了数据和算法的类型。C++ 并不是权威所说的“纯 OOP 语言”。C++ 通过对效率以及某些可能称为“实用性”的考虑，平衡了它的 OOP 特性。这种结合使得 C++ 成为使用最广泛的 OOP 语言，尽管它并非完全严格遵循 OOP 哲学。

下一行表示 main 是一个没有参数并返回 int（整数）值的函数：

```
int main ()
```

某些编译器允许你省略 int 或将其替换为 void，表示一个不返回值的函数。然而，之前的形式是启动 C++ 程序主函数最广泛接受的形式。程序以执行以下语句结束：
