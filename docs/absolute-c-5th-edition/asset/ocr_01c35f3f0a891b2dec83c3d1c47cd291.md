# CHAPTER 12 Streams and File I/O

If D is a derived class of the class B, then every object of type D is also of type B. A convertible is also an automobile. A file input stream (object of the class istream) is also an input stream (an object of the class istream). So, if we use istream as the type for a function parameter, rather than using istream, more objects can be plugged in for the parameter. Consider the following two function definitions, which differ only in the type of the parameter (and the function name):

```
void twoSumVersion1(istream sourceFile) //istream with an 'f'
  int n1, n2;
  sourceFile >> n1 >> n2;
  cout << n1 << " " << n2 << " " << (n1 + n2) << endl;
```

```
void twoSumVersion2(istream& sourceFile) //istream without an 'f'
```

```
  int n1, n2;
  sourceFile >> n1 >> n2;
  cout << n1 << " " << n2 << " " << (n1 + n2) << endl;
```

With twoSumVersion1, the argument must be of type istream. So if in is a file input stream connected to a file,

```
twoSumVersion1(fileIn);
```

is legal, but

```
twoSumVersion1(cin); //ILLEGAL
```

is not legal, because cin is not of type istream. The object cin is only a stream and only of type cin; cin is not of a file input stream.
The function twoSumVersion2 is more versatile. Both of the following are legal:

```
twoSumVersion2(fileIn);
twoSumVersion2(cin);
```

The moral is: Use istream, not ifstream, as a parameter type you can. When choosing a parameter type, use the most general type you can. (To draw a real-life analogy consider the following: You might prefer to own a convertible, but if you borrowed a sedan from a friend that could only hold a convertible, you'd still be able to park the sedan in your garage.)

You cannot use the parameter type ifstream instead of the type istream. If you define a function with a parameter of type ifstream, then that parameter can only use istream member functions. In particular, you cannot use the functions open and close. If you cannot call all to the member functions outside the function definition, then you must use a parameter of type istream.
