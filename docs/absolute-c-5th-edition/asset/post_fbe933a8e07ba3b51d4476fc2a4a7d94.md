## EXAMPLE: An Iterator Class

Display 17.31 contains the definition of an iterator class that can be used for data structures (such as a stack or queue) that are based on a linked list. We have placed the node class and the iterator class into a namespace of ours. This means, since the iterator is intimately related to the node class and any class that uses this node can also use the iterator class. This iterator class does not have a decrement operator, because a decrement operator depends on the details of the linked list and does not depend solely on the type Node<T>. (There is nothing wrong with having the definition of iterator depend on the underlying linked list. We have just decided to avoid this complication.)

As you can see, the ListIterator class is essentially a pointer wrapped in a class that can have the needed members. The definitions of the overload operators are straightforward and in fact so that we have defined all of them as inline functions. The dereferencing operator, * produces the data member variable of node pointed to. Only the data member variable is data. The pointer member variable in a node is part of the implementation detail that the user programmer should not need to be concerned.

You can use the ListIterator class as an iterator for any class based on a linked list that uses the template node. As an example, we have rewritten the template class Queue so that it has iterator facilities. The interface for the template class Queue is given in 17.32. The definitions of the Queue template are the same as our previous version (17.20) except that we have added a type definition as well as the following member functions:

```
Iterator begin() const { return Iterator(front); }
Iterator end() const { return Iterator(); }
//The end iterator end().current = NULL.
```

Let us discuss the member functions first.
The member function begin() returns an iterator located (“pointing”) to the front node of the queue, which is the head of the underlying linked list. Each application of the increment operator, ++ moves the iterator to the next node. You can move through the nodes, and handle the data, in a queue named q as follows:

```
for (Iterator i = q.begin(); Stopping_Condition; i++)
process *i
```

where i is a variable of the iterator type.

## EXAMPLE: (continued)

The member function end() returns an iterator whose member variable is NULL. Thus, when the iterator i has passed the last node, the Boolean expression

```
i != q.end()
```

changes from true to false. This is the desired Stopping_Condition. This queue and class iterator allows you to cycle through the data in the queue in the way we outlined for iterator:

```
for (i = q.begin(); i != q.end(); i++)
    process *i
```

Note that i is not equal to q.end() until it has advanced past the last node. To remember this detail, think of q.end() as being a marker like NULL; in this case, it is essentially a version of NULL. Notice the type definition in our new queue:

```
typedef ListIterator<T> Iterator;
```

### Iterators 797 Interface File for a Queue

```
// This is the header iterator.h. This is the interface for the
// class ListIterator, which is a template class for an iterator to use
// with linked lists of items of type T. This file also contains the
// node type for a linked list
#ifndef ITERATOR_H
#define ITERATOR_H

namespace ListNodeSavitch
{
    template<class T>
    class Node
    {
    public:
        Node(T theData, Node<T>* theLink) : data(theData),
             link(theLink) {}
        Node<T>* getLink() const { return link; }
        const T& getData() const { return data; }
        void setData(const T& data) { data = theData; }
        void setLink(Node<T>* pointer) { link = pointer; }
    private:
        T data;
        Node<T>* link;
    };

    template<class T>
    class ListIterator
    {
    public:
        ListIterator() : current(NULL) {}
        ListIterator(Node<T>* initial) : current(initial) {}
        const T& operator() const { return current->getData(); }
        //Precondition: Not equal to the default constructor object;
        //that is, current != NULL;
        ListIterator& operator++() //Prefix form {
            current = current->getLink();
            return *this;
        }
        ListIterator operator ++(int) //Postfix form {
            ListIterator startVersion(current);
            current = current->getLink();
            return startVersion;
        }
        bool operator ==(const ListIterator& rightSide) const {
            return (current == rightSide.current);
        }
        bool operator !==(const ListIterator& rightSide) const {
            return (current != rightSide.current);
        }
    private:
        Node<T> *current;
    };

    template<class T>
    class Queue
    {
    public:
        typedef ListIterator<T> Iterator;
        Queue();
        Queue(const Queue<T>& rightSide);
        Queue& operator=(const Queue<T>& rightSide);
        void add(T item);
        T front();
        bool isEmpty() const;
        Iterator begin() const;
        Iterator end() const;
    private:
        Node<T> *head;
        Node<T> *back;
    };
} //ListNodeSavitch
#endif ITERATOR_H
```

### Display 17.33 Program Using the Queue template with Iterators

```cpp
// Program to demonstrate use of the Queue class with iterators.
#include <iostream>
#include "queue.h" // not needed
#include "queue.cpp"
#include "iterator.h" // not needed
using std::cin;
using std::cout;
using std::endl;
using namespace QueueSavitch;
int main() {
{
    char next, ans;
    do {
        Queue<char> q;
        cout << "Enter a line of text:\n";
        cin.get(next);
        while (next != '\n') {
            q.add(next);
            cin.get(next);
        }
        cout << "You entered:\n";
        Queue<char>::Iterator i;

        for (i = q.begin(); i != q.end(); i++) {
            cout << *i << "";
        }
        cout << endl;

        cout << "Again? (y/n): ";
        cin >> ans;
        cin.ignore(10000, '\n');
    } while (ans != 'n' && ans != 'N');
    return 0;
}
```
