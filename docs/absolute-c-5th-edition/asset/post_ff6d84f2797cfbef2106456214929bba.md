
# PITFALL: Losing Nodes

You might be tempted to write the function definition for headInsert (Display 17.4) using the zero-argument constructor to set the member variables of the new node. If you were to try, you might start the function as follows:

```
head = new IntNode;
head->setData(theData);
```

At this point, the new node is constructed, contains the correct data, and is pointed to by the pointer—all as it is supposed to be. All that is left to attach the rest of the list to this node by setting the pointer member in this new node so that it points to what was formerly the first node of the list. You could do it with the following, if you only could figure out what to point in place of the question:

```
head->setLink(?);
```

Display 17.5 shows when the new data value is 12 and illustrates the problem. If you were to proceed in this way, there would be nothing pointing to the node containing 15. Since there is no named pointer pointing to it (or to a chain of pointers extending to that node), there is no way the pointer can reference this node. Node and all nodes below it are lost. A program cannot make a pointer to any of these nodes, nor can it access the data in these nodes or anything else to it. It has no way to refer to the nodes. Such a situation uses up a memory leak for the duration of the program. A significant memory leak can result in the program running out of memory and terminating abnormally. Worse, a memory leak (lost nodes) in an ordinary users program can, in rare situations, cause the operating system to crash. To avoid such leaks, the program must always keep some pointer to the head of the list, usually the pointer in a pointer variable head.

If you want the nodes in some particular order, such as numerical or alphabetical, you cannot simply insert the node at the beginning or end of the list. We will therefore design a function to insert node after a specified node in the linked list.

We assume that some other function or program part has correctly placed a pointer called after pointing to node in the linked list. # The delete Operator

The delete operator eliminates a dynamic variable and returns the memory that the dynamic variable occupied to the heap. The memory can then be reused to create new dynamic variables. For example, the following eliminates the dynamic variable pointed to by pointer p:

```
delete p;
```

After a call to delete, the value of the pointer, like p shown, is undefined.

# PITFALL: using the Assignment Operator with Dynamic Data Structures

If head1 and head2 are pointer variables and head1 points to the head node of a linked list, the following will make head2 point to the same head node and hence the same linked list:

```
head2 = head1;
```

However, you must remember that there is only one linked list, not two. If you change the linked list pointed to by head1, then you will also change the linked list pointed to by head2 because they are the same linked list.

If head1 points to a linked list and you want head2 to be a second, identical copy of this linked list, the preceding assignment statement will not work. Instead, you must copy the entire linked list by node.

# Searching a Linked List

Next we design a function to search a linked list in order to locate a particular node. We will use the same node type called IntNode that we used in the previous subsections (The definitions of the node and pointer types are given in Display 17.4.) The function we design have two arguments: the linked list and the integer we want to locate. The function will return a pointer that points to the first node that contains that integer. If no node contains the integer, the function will return NULL.

This way our program can test whether the int in the list by checking to see if the function returns a pointer value that is not equal to NULL. The function declaration and header for our function are as follows:

```
IntNodePtr search(IntNodePtr, int target);
//Precondition: The pointer points to the head of a
linked list. The pointer variable in the last node is NULL.
//If the list is empty, then head is NULL.
//Returns a pointer that points to the first node that contains the//target. If no node contains the target, the function returns NULL.
```

# Pseudocode for search Function

```
Make the pointer variable here to point to the head node (that is, first node) of the linked list.
while (here is not pointing to a node containing target
      and here is not pointing to the last node)
{
    Make point to the next node in the list.
}
if (the node pointed to by here contains target)
    return here;
else
    return NULL;
```

To move the pointer here to the next node, we must think in terms of the pointers we have alike the one pointed to by the pointer member of the node currently pointed to by here. The pointer member of the node currently pointed to by here is given by the expression

```
here->getLink()
```

To move here to the next node, we want to change here so that it points to the node that is pointed to by the above-named pointer. Hence, the following will move the pointer here to the next node in the list:

```
here = here->getLink();
```
