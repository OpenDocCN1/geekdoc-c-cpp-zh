# 5.2 Arrays in Functions

You can use both indexed variables and entire arrays as arguments to functions. We first discuss array variables as arguments to functions.

# Indexed Variables as Function Arguments

An indexed variable can be an argument to a function exactly the same way that any variable of the array base type can be an argument. For example, suppose a program contains the following declarations:

```
double i, n, a[10];
```

If myFunction takes one argument of double, then the following is legal:

```
myFunction(n);
```

Since an indexed variable of the array is also a variable of type double, just like n, the following is equally legal:

```
myFunction(a[3]);
```

An indexed variable can be a call-by-value argument or a call-by-reference argument. One subset applies to indexed variables used as arguments, however. For example, consider the following function:

```
myFunction(a[i]);
```

If the value of i is 3, then the argument is a[3]. On the other hand, if the value of i is 0, then this call is equivalent to the following:

```
myFunction(a[0]);
```

The indexed expression is evaluated in order to determine exactly which indexed variable is given as the argument.
