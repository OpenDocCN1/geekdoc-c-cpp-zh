# Literals

Literal is a name for one specific value. Literals are often called constants in contrast to variables. Literals or constants do not change value; variables can change their values. Integer constants are written in the way you are using writing numbers. Constants of type int (or any other type) must not contain a decimal point. Constants of type double may be written in two forms. The simple form for double constants is like the everyday way of writing fractions. When written in this form a double constant must contain a decimal point. No number constant (either integer or floating-point) in C++ may contain a comma.

A more complicated notation for constants of double is called scientific notation or floating-point notation and is particularly handy for writing large numbers and very small fractions. For instance, 3.6 × 10¹⁷, which is the same

```
36700000000000000.0
```

is expressed in C++ by the constant 3.67e17. The number 5.89 × 10⁻⁶, which is the same as 0.0000589, is expressed in C++ by the constant 5.89e-6. The e stands for exponent and means “multiplied by 10 to the power of that”. The e may be uppercase or lowercase.

Think of the number e as telling you to move the decimal point. For example, change 3.494 to a numerical without e, you move the decimal point four places to the right to obtain 34900.0, which is another way of writing the same number. If the number the e is negative, you move the decimal point indicated spaces to the left, inserting extra zeros if need be. So, 3.49e-2 is the same as 0.0349.

The number before the e may contain a decimal point, it is not required. However, the exponent after the e definitely must not contain a decimal point.

# What Is Doubled?

Why is the type for numbers with a fractional part called double? No, but something like that is true. Many programming languages traditionally used two types for numbers with a fractional part. One used less storage and was very impressive (it, is not allowed many significant digits). The second type used double the amount of storage and was much more precise; it allowed numbers that were larger (programmers needed to care more about precision than about size). The kind of numbers that used twice as much storage were called double-precision numbers; those that used less storage were called single precision. Following this tradition, the type that (more or less) corresponds to this double-precision type was named double in C++. The type that corresponds to single precision in C++ was called float. C++ also has a third type for numbers with a fractional part, which is called long double.
