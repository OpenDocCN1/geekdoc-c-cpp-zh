Display 17.12 Deleting a Node from a Doubly Linked List

Existing list before deleting discard

![](bbox=[0.167, 0.168, 0.638, 0.295])

Set pointers to the previous and next nodes

```
DoublyLinkedListNode prev = discard->getPreviousLink();
DoublyLinkedListNode next = discard->getNextLink();
```

![](bbox=[0.167, 0.405, 0.718, 0.532])

Bypass discard

```
prev->setNext(next);
next->setPreviousLink(prev);
```

![](bbox=[0.167, 0.643, 0.718, 0.769])

Delete discard

```
delete discard;
```
