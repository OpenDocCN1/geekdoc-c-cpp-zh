# PITFALL: Integer Values Can Be Used as Boolean Values

C++ sometimes uses integers as they were Boolean values and bool values as if they were integers. In particular, C++ converts the integer 1 to true and converts the integer 0 to false, vice versa. The situation is a bit more complicated than simply using 1 for true and 0 for false. The compiler will convert any nonzero number as if it were the value true and convert 0 as it were the value false. As long as you make no mistakes in writing Boolean expressions, this conversion causes no problems. However, when you are debugging, it might help to know that the compiler is combine integers using the Boolean operators &&, || and !.

For example, suppose you want a Boolean expression that is provided that time has not yet out (in some game or process). You might use the following:

```
!time > limit
```

This sounds like you read it out: "not greater than limit." The Boolean expression is wrong, however, and unfortunately, the compiler will not give you an error message. The compiler will apply the precedence rules from Display 2.3 and interpret your Boolean expression as the following:

```
(time) > limit
```

This looks like nonsense, and intuitively it is nonsense. If the value of time is, for example, 36, what could possibly be the meaning of (time)? After all, it is equivalent to "not 36". In C++, any nonzero integer converts to true and 0 is converted to false. Thus, !36 is interpreted as "not true" and so it evaluates to false, which is in turn converted back to 0 because we are comparing to int.

What we mean by this Boolean expression and what C++ gives us are not the same. If time has a value of 36 and limit has a value of 0, you the previously displayed Boolean expression evaluates to true (because it is not true time > limit). Unfortunately, the Boolean expression instead evaluates as: (time) evaluates to false, which is equivalent to 0, so the entire Boolean expression is equivalent to

```
0 > limit
```

That in is equivalent to 0 > 60, because 60 is the value of limit, and evaluates to false. Thus, the above logical expression evaluates to false, when you want it to evaluate to true.

There are two ways to correct this problem. One way is to use the operator correctly. When using the ! operator, be sure to include parentheses around the argument. The correct way to write the above Boolean expression is

```
!(time > limit)
```
