The syntax for using functions in your program is simple. To set a variable xRoot equal to the square root of 9.0, you can use the following assignment statement:

```
xRoot = sqrt(9.0);
```

The expression sqrt(9.0) is known as a function call or function invocation. An argument in a function call can be a constant, such as 9.0, a variable, or a more complicated expression. A function call is an expression that can be used like any other expression. For example, the value returned by sqrt is of type double; therefore, the following is legal (although stings):

```
bonus = sqrt(sales)/10;
```

sales are variables that would normally be of type double. The function call(sales) is a single item, just as if it were enclosed in parentheses. Thus, the previous assignment is equivalent to

```
bonus = (sqrt(sales))/10;
```

You can use a function call whenever it is legal to use an expression of the type specified for the value returned by the function.

Also notice that there are three absolute value functions. If you want to produce the absolute value of a number of type int, use abs; if you want to produce the absolute value of a number of type long, use labs; if you want to produce the absolute value of a number of type double, use fabs. To complicate things even more, abs and labs are in the library with header file cstdlib, whereas fabs is in the library with header file cmath. fabs is an abbreviation for floating-point absolute value. Recall that numbers with a fraction from the decimal point, as numbers of type double, are often called floating-point numbers.

Another example of a predefined function is pow, which is in the library with header file cmath. The function pow can be used to do exponentiation in C++. If you want to set a variable result equal to x, you can use the following:

```
result = pow(x, y);
```

Hence, the three lines of code above will output the number 9.0 to the screen, because (3.0)^2.0 is 9.0:

```cpp
double result, x = 3.0, y = 2.0;
result = pow(x, y);
cout << result;
```

A function can have any number of arguments. Moreover, every argument has a specific type, and the argument used in a function call should be of that. # void Functions

A void function performs some action, but does not return a value. For a void function, a function call is a statement consisting of the function name followed by arguments enclosed in parentheses and then terminated with a semicolon. If there is more than one argument, the arguments are separated by commas. For a void function, invocation (function call) is a statement that can be used like any other C++ statement.

# SYNTAX

```
Function_Name (Argument_List);
```

where the Argument_List is a comma-separated list of arguments:

```
Argument_1, Argument_2, .. Argument_Last
```

# EXAMPLE

```cpp
exit(1);
```

Many implementations of pow have a restriction on what arguments can be used. In these implementations, if the first argument to pow is negative, then the second argument must be a whole number. It might be easiest and safest to use pow only when the first argument is nonnegative.

# Predefined void Functions

A void function performs some action, but does not return a value. Since it performs an action, a function invocation is a statement. The function call for a void function is written similar to a function call for a function that returns a value, except that it is terminated with a semicolon and is used as a statement rather than an expression. Predefined void functions are handled in the same way as predefined functions that return a value. Thus, to use a predefined function, your program must have an include directive that gives the name of the library it defines the function.

For example, the exit is defined in the library cstdlib, and so a program that uses function must contain the following (or near) the start of the file:

```cpp
#include <cstdlib>
using namespace std;
```

The following is a sample invocation (sample call) of the function exit:

```cpp
exit(1);
```
