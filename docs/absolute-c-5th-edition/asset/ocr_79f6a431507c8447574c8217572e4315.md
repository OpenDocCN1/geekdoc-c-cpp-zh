# The Comma Operator

The **comma operator** is a way of evaluating a list of expressions and returning the value of the expression. It is sometimes handy to use in a *for* loop, as in our discussion of the *for* loop in the next section. We do not advise using it in other contexts, but it is legal to use it in any expression.

The comma operator is illustrated by the following statement:

```
result = (first = 2, second = first + 1);
```

The comma operator is shown in the center of the previous statement. The **comma expression** is the expression on the right-hand side of the assignment operator. The comma operator has two operands as operands. In the case the two operands are

```
first = 2 and second = first + 1
```

The first expression is evaluated, and the second expression is evaluated. As may recall from Chapter 1, the assignment statement, when used as an expression, returns the value of the variable on the left side of the assignment operator. Since only the value of the second expression is returned, the first expression is evaluated solely for its side effects. In the previous example, the side effect of the first expression is to change the value of the variable *first*.

You may have a longer list of expressions connected with commas, but you should only do so when the order of evaluation is not important. If the order of evaluation is important, you should use parentheses. For example,

```
result = ((first = 2, second = first + 1), third = second + 1);
```
