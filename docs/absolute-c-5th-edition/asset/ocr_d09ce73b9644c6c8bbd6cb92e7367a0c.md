# The for Statement

for statement

The third and final loop statement in C++ is the for statement. The for statement is most commonly used to step through some integer variable in equal increments. We will see in Chapter 5, the for statement is often used to step through an array. The for statement is, however, a completely general looping mechanism that can do anything that a while loop can.

For example, the following for statement sums the integers 1 through 10:

```
sum = 0;
int n;
for (n = 1; n <= 10; n++)
sum = sum + n;
```

A for statement begins with the keyword for by three things in parentheses that tell the computer what to do with the controlling variable. The beginning of a for statement looks like this:

```
for (Initialization_Action, Boolean_Expression, Update_Action)
```

The first expression tells how variables, variables, or other things are initialized; the second Boolean expression is used to check when the loop should end; and the last expression tells how the loop variable is updated after each iteration of the loop body.

The three expressions at the start of a for statement are separated by two—and only two—semicolons. Do not succumb to the temptation to place a semicolon after the third (the technical explanation is that these three things are expressions, statements, and do not require a semicolon at the end.).

A for statement often uses a int variable to control loop iteration and loop ending. However, the three expressions at the start of a for statement may be any C++ expressions; therefore, they may involve more (or fewer) than one variable, and the variables may be of any type.

Using the comma operator, you can add multiple actions to either the first or the last (but not normally the second) of the three items in parentheses. For example, you can move the initialization of the variable sum inside the for loop to obtain the following, which is equivalent to for statement code we showed earlier:

```
for (sum = 0, n = 1; n <= 10; sum = sum + n)
```

Although we do not advise so because it is not as easy to read, you can make the entire body of the for loop into parentheses. The previous for statement is equivalent to the following:

```
for (sum = 0, n = 1; n <= 10; sum = sum + n, n++)
```
