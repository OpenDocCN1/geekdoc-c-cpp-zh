# 17.4 Trees

I think that I shall never see a data structure as useful as a tree.

Anonymous

A detailed treatment of trees is the scope of this chapter. The goal of this chapter is to teach the basic techniques for constructing and manipulating data structures based on nodes and pointers. The linked list served as a good example for our discussion. However, there is one detail about the nodes in a singly linked list that is restricted: The tree node has two (and in some applications more) member variables for pointers to other nodes. Moreover, trees are a very important and widely used data structure. So, we will briefly outline the general techniques used to construct and manipulate trees.
