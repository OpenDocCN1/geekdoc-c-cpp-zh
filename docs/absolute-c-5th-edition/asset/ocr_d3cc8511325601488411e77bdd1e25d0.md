# 107

A void function can have any number of arguments. The details on arguments for void functions are the same as they were for functions that return a value. In particular, if you use argument of the wrong type, then, in many cases, some automatic type conversion will be done for you by C++. However, the results may not be what you intended.

# A Random Number Generator

A random number generator is a function that returns a "randomly chosen" number. It is unlike the functions we have seen so far that the returned value is not determined by the arguments (of which there are usually none) but rather by global conditions. Since you can think of the returned value as being a random number, you can use a random number generator to simulate events, such as the result of throwing dice or flipping a coin. In addition to simulating games of chance, random number generators can be used to simulate things that strictly may not be random but that appear to us to be random, such as the amount of time between the arrival of cars at a toll booth.
