# Basic Operator Overloading

The definition of the member operator + is given in Display 8.2. Notice the following line from that definition:

```
int allC1 = cents + dollars * 100;
```

The expressions cents and dollars are member variables of the calling object, which in this case is the first operand. If this definition is applied to

```
cost + tax
```

then cents means cost.cents and dollars cost.dollars.
Note that since the first operand is the calling object, which you must, add const to the end of the operator declaration and to the end of the operator definition. Whenever the operator invocation does not change the object (which is first operand), good style dictates that you add const to the end of the operator declaration and to the end of the operator definition, as illustrated in Display 8.2.

Overloading an operator as a member variable can seem strange at first, but it is easy to get used to the new details. Many experts advise overloading operator members as nonmembers (as in Display 8.1): It is more in the spirit of object-oriented programming and is a bit more efficient, since the definition can directly reference member variables and not use accessor and mutator functions. However, as we will discover in Section 8.2, an operator as a member also has a significant disadvantage.

```
#include <iostream>
#include <cstdlib>
#include <cmath>
using namespace std;

//Class for amounts of money in U.S. currency
class Money {
public:
    Money();
    Money(double amount);
    Money(int dollars, int cents);
    Money(int dollars);
    double getAmount() const;
    int getDollars() const;
    int getCents() const;
    void input(void); //Reads the dollar sign as well as the amount number.
    void output() const;
    const Money operator+(const Money& amount2) const;
    const Money operator-(const Money& amount2) const;
    bool operator=(const Money& amount2) const;
    const Money operator-() const;
```
