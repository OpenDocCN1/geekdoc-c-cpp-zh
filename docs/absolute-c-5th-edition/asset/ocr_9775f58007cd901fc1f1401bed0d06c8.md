# CHAPTER 16 Templates

# EXAMPLE: An Array Template Class

In Chapter 10, we defined a class for a partially filled array of doubles (Displays 10.10 and 10.11). In this example, we convert definition to a template class for a partially filled array of any type. The template class PArray has a type parameter T for the base type of the array.

The conversion is routine. We replace double (when it occurs as the base type of the array) with the type parameter T and convert both the class definition and the member function definitions to template form. The template class definition is given in Display 16.5. The member function template definitions are given in Display 16.6.

Note that we have placed the templates in a namespace. Namespaces are used with templates in the same way as are used with simple, nontemplate definitions.

A sample application is given in Display 16.7. Note that we have separated the class template, implementation, and application program into three files. Unfortunately, these files cannot be used for the traditional method of separate compilation. So, we do the best we can by #include-ing the interface and implementation files in the application file. To the compiler, that makes it look everything in one file.
