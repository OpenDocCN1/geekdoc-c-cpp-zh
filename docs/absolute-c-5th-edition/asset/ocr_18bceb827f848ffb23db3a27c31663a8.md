# precision

Every output stream has a member function named precision. When your program executes a call to precision such as the one for the outStream, from that point in your program, any number with a decimal point is output to that stream will be written with a total of two significant figures or with two digits after the decimal point, depending on when your compiler was written. The following is some possible output from a compiler that sets two significant digits:

```
23.    2.2e7   2.2     6.9e-1   0.00069
```

The following is possible output from a compiler that sets two digits after the decimal point:

```
23.56   2.26e7   2.21    0.69    0.69e-4
```

In this book, the compiler sets two digits after the decimal point. Of course, you can use a different argument 2 to obtain or more precision.
Every stream has a member function setf to be used to set these flags. Flags are constants in the class ios, which is the std namespace. When set with a call to setf, the flags determine behaviors of the output stream. Following are the two calls to the member function setf with the outStream calling:

# set
flag

```
outStream.setf(ios::fixed);
outStream.setf(ios::showpoint);
```

Each of these flags is an instruction to format output in one of two ways. What causes the stream to depend on the flag.

# ios::fixed
fixed-point
notation

The flag ios::fixed causes the stream to output floating-point numbers in what is called fixed-point notation, which is a fancy phrase for the way we normally write numbers. If the flag ios::fixed is set (by a call to setf), then all floating-point numbers (as numbers of type double) are output to stream will be written in ordinary everyday notation, rather than e-notation.

# ios::nshowpoint

The flag ios::showpoint tells the stream to always include a decimal point in floating-point numbers. If the number to output has a value of 2.0, then it will be output as 2.0 and not simply as 2; that is, the output will include the decimal point even if the digits after the decimal point are zero. You can set flags with a single call to setf. Simply connect the various flags with '|' symbols, as illustrated:

```
outStream.setf(ios::fixed | ios::showpoint | ios::right);
```
