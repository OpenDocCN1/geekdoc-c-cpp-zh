# Destructor

The destructor of a class is a member function of a class that is called automatically when an object of the class goes out of scope. Among things, this means that if an object of the class type is a local variable for a function, then the destructor is automatically called as the last action before the function call ends. Destructors are used to eliminate any allocated variables that have been created by the object so the memory occupied by these dynamic variables is returned to the frestore for reuse. Destructors may perform clean up tasks as well. The name of a destructor must consist of the tilde symbol, ~, followed by the name of the class.

# Copy Constructors

A copy constructor is a constructor that has one parameter that is of the same type as the class. The one parameter must be a call-by-reference parameter, and normally the parameter is preceded by the const modifier, if it is a constant parameter. In all other respects a copy constructor is defined in the same way as any other constructor and can be used just like others. For example, if a program uses the PFArray defined in Display 10.10 might contain the following:

```
PFArray b(20);
for (int i = 0; i < 20; i++)
b.addElement(i);
PFArray temp(b); //Initialized by the copy constructor
```

The object b is initialized with the copy constructor that has a parameter of type int. type const PFArray&. When used in this copy constructor is used just like any other constructor.

A copy constructor should be defined so that the object being initialized becomes a complete, independent of its argument. So, in the declaration

```
PFArray temp(b);
```

the member variable temp.a should not be set to the same value as b.a; that would produce two pointers pointing to the same dynamic array.
