# Friend Classes and Similar Alternatives

You may have found it a nuisance to use the accessor and mutator functions getLink and setLink in the template class Node (see Display 17.17 or Display 17.20). You might be tempted to avoid the invocations of getLink and setLink by simply making the member variable link of the class public instead of private. Before you abandon the principle of making all members private, note two things. First, using getLink and setLink is not really harder for you, directly accessing the links in nodes. (However, getLink and setLink introduce some overhead and may slightly reduce efficiency.)
