# Introduction

This chapter discusses the mechanisms used by C++ for plugging in arguments for function calls. It also discusses overloading, which is a way to give two (or more) different function definitions to the same function name. Finally, it goes over some basic techniques for testing functions.

# 4.1 Parameters

You can't put a square peg in a round hole.
Common saying

This section describes the details of the mechanisms used by C++ for plugging in an argument for a function is invoked. There are two basic kinds of parameters and two basic plugging-in mechanisms in C++. The two basic kinds of parameters are call-by-value parameters and call-by-reference parameters. All the parameters that appeared before this point in the book were call-by-value parameters. With call-by-value parameters, only the value of the argument is plugged in. With call-by-reference parameters, the variable itself is be changed by the function invocation. A call-by-reference parameter is indicated by appending the ampersand sign, &, to the parameter type, as illustrated by the following function declarations:

```
void getInput(double&variable, int&variable);
```

A call-by-value parameter is indicated by not using the ampersand. The details on call-by-value and call-by-reference parameters are given in the following subsections.

# Call-by-Value Parameters

Call-by-value parameters are more than just that are filled in the argument values for the function. A call-by-value parameter is actually a local variable. When the function is invoked, the value of a call-by-value argument is computed and the corresponding call-by-value parameter, which is a local variable, is initialized to this value.

In most cases you can think of a call-by-value parameter as a kind of blank, or placeholder, that is filled in by the value of its corresponding argument in the function invocation. However, in some cases it is handy to use a call-by-value parameter as a local variable and change the value of the parameter within the body of the function

# A First Look at Call-by-Reference Parameters

The call-by-value method that we used until now is not sufficient for all tasks you might want a function to perform. For example, one common task for a function is to obtain an input value from the user and set the value of an argument variable to that input value. With the call-by-value formal parameters that we have used until now,

# Parameters 149

a corresponding argument in a function can be a variable, the function takes only the value of the variable and does not change the value in any way. With a call-by-value parameter only the value of the argument is substituted for the formal parameter. For an input function, the variable (not the value) be substituted for the formal parameter. The call-by-reference mechanism is working in just way. With call-by-reference formal parameter, this argument is substituted for the formal parameter. It is almost as if the argument were literally copied into the body of the function definition. After the argument is substituted in, the code in the function body is executed and can change the value of the argument.

A call-by-reference parameter must be marked in some way so that the compiler will know it from call-by-value parameter. The way you indicate a call-by-reference parameter is to attach the ampersand sign, & to the end of the type name in the parameter list. This is done in the function declaration (function prototype) and the header of the function definition. For example, the following function definition has one formal parameter, receiver, which is a call-by-reference parameter:

```
void getInput(double receiver)
{
    cout << "Enter input number:\n"
    cin >> receiver;
}
```

In a program that calls this definition, the following function will call the double variable inputNumber equal to a value read from the keyboard:

```
getInput(inputNumber);
```

C++ allows you to place the ampersand either with the type name or with the parameter name, so you will sometimes see
void getInput(double &receiver);
which is equivalent to
void getInput(double&receiver);

Display 4.2 demonstrates call-by-reference parameters. The program reads into two numbers and writes the same numbers out, but in the reverse order. The parameters in the functions getNumbers and swapValues are call-by-reference parameters. The input is performed by the function call

```
getNumbers(firstNum, secondNum);
```

The values of the variables firstNum and secondNum are set by this function call. After that, the following function call reverses the values in the two variables firstNum and secondNum:

```
swapValues(firstNum, secondNum);
```
