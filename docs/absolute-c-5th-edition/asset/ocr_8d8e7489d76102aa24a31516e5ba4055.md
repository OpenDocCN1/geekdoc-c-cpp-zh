# Class Templates

# Type Definitions

You can define a new class type name that has the same meaning as a specialized class template, such as Pair<int>. The syntax for a defined class type name is as follows:

```
typedef Class_Name<Type_Argument> New_Type_Name;
```

For example,

```
typedef Pair<int> PairOfInt;
```

The name PairOfInt can be used to declare objects of type Pair<int>, as in the following example:

```
PairOfInt pair1, pair2;
```

The name PairOfInt can also be used to specify the type of a formal parameter or anywhere else a type name is allowed.
