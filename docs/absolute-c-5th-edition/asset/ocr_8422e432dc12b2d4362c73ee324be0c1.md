# Introduction

An array is to process a collection of data all of which is of the same type, such as a list of temperatures or a list of names. # 5.1 Introduction to Arrays

Suppose we wish to write a program that reads five test scores and performs manipulations on these scores. For instance, the program might compute the highest score and then output the amount by which each score falls short of highest. The highest score is not known until all five are read. Hence, five scores can be maintained in storage so that the highest score is computed each score can be compared with it. To retain the five scores, we would need something equivalent to five variables of type int. We could use five individual variables of type int, but five variables are hard to keep track of, and we may later want to change our program to handle 100 scores; certainly, 100 variables are impractical. An array is the perfect solution. array behaves like a list of variables with a uniform naming convention that can be declared in a single line of code. For example, the names for the individual variables we need might be score[0], score[1], score[2], score[3], and score[4]. The part that does not change, in this case score, is the name of the array. The part that can change is the integer in the square brackets, [ ].

# Declaring and Referencing Arrays

In C++, an array consisting of five variables of type int be declared as follows:

```
int score[5];
```

This declaration is like declaring the following five variables to all be of type int:

```
score[0], score[1], score[2], score[3], score[4]
```
