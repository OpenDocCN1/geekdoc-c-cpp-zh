The expression n evaluates to the value of the variable n, and then the value of the variable n is incremented by 1. If you reverse the order and use ++ in front of the variable, the order of these two actions is reversed. The expression ++n first increments the value of the variable n and then returns this increased value of n. For example, consider the following code:

v++ versus ++v

```
int n = 2;
int valueProduced = 2*(++n);
cout << valueProduced << "\n";
cout << n << "\n";
```

This code is same as the previous piece of code except that the ++ is before the variable, so this code will produce the output:

6
3

Notice that the two increment operators in n++ and ++n have the same effect on a variable: n. They increase the value of n. But the two expressions evaluate to different values. Remember, if the ++ is before the variable, the incrementing is done before the variable is returned; if the ++ is after the variable, the incrementing is done after the value is returned.

Everything we said about the increment operator applies to the decrement operator as well, except that the value of the variable is decreased by 1 rather than increased by 1. For example, consider the following code:

```
int n = 8;
int valueProduced = n--;
cout << valueProduced << "\n";
cout << n << "\n";
```

This produces the output

8
7

On the other hand, the code

```
int n = 8;
int valueProduced = -n;
cout << valueProduced << "\n";
cout << n << "\n";
```

produces the output

7
7

n-- returns the value of n and decrements n; on the other hand, --n first decrements n and then returns the value of n.
