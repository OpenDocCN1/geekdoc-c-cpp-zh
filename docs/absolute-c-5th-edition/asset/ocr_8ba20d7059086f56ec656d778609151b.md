Partially filled arrays require some care. The program must keep track of how much the array is used and not refer any indexed variable that has not been given a value. The program in Display 5.5 illustrates this. The program reads a list of golf scores and how much each score differs from the average. This program will work for lists as short as one score, as long as ten scores, and of any length between. The scores are stored in the array score, which has ten indexed variables, the program uses only as much of the array as it needs. The variableUsed keeps track of how many elements are stored in the array score. The elements (that is, scores) are stored in positions score[0] were very similar to what would be if numberUsed were the declared size of the array and the entire array were. In particular, the variable numberUsed usually be an argument to any function that manages the partially filled array. Since the argument (when properly) can often ensure that the function will not refer an illegal index, sometimes (but not always) eliminates the need for an argument that gives the declared size of array. For example, the functions showDifference and computeAverage use the argument numberUsed to ensure that only legal array indexes are used. > TIP: Do Not Skimp on Formal Parameters

Notice the fillArray in Display 5.5. When fillArray is called, the declared array size MAX_NUMBER_SCORES is given as one of the arguments, as shown in the following function call from Display 5.5:

```
fillArray(score, MAX_NUMBER_SCORES, numberUsed);
```

You might protest that MAX_NUMBER_SCORES is a globally defined constant and so could be in the definition of fillArray without the need to make an argument. You would be correct, and if we did not use fillArray in any program other than one in Display 5.5, we could get by making MAX_NUMBER_SCORES an argument to fillArray. However, fillArray is a generally useful function that you may want to use in different programs. We do in fact also use the function fillArray in the program in Display 5.6, discussed in the next subsection. The program in Display 5.6 the argument for the declared array size is a different named constant. If we had written the constant MAX_NUMBER_SCORES into the body of the function fillArray, we would not have able to reuse the function in the program in Display 5.6.
