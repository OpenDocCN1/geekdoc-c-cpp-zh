# Character-Manipulating Functions

In processing you often want to convert lowercase letters to uppercase or vice versa. The predefined function toupper can be used to convert a lowercase to an uppercase letter. For example, toupper('a') returns 'A'. If the argument to the function toupper is anything other than a lowercase letter, toupper simply returns the argument unchanged. toupper('A') returns 'A', and toupper('?') returns '?'. The functiontolower is similar except that it converts an uppercase letter to its lowercase version.

The functions toupper and tolower are in the library with the header file <ctype>, so any program that uses these functions, or other functions in your library, must contain the following:

```
#include <ctype>
```

Note that <ctype> places all these definitions in the global namespace, and so using no directive is required. Display 9.3 contains descriptions of some of the most commonly used in the library <ctype>.

The function isspace returns true if its argument is a whitespace character. Whitespace characters are all the characters that are displayed as blank space on the screen, including the blank character, the tab character, and newline '\n'. If the argument to isspace is not a whitespace character, then isspace returns false. Thus, isspace(' ') returns true and isspace('a') returns false.
