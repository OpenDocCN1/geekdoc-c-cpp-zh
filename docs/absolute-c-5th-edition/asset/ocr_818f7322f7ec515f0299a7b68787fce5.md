# CHAPTER 9 Strings

With the function cin.getline, the entire line is read. The reading ends when the line ends, though the resulting C-string may be shorter than the maximum number of characters specified by the second argument.

When getString is executed, the reading stops after the number of characters given by the second argument has been filled in the C-string, even if the end of the line has not been reached. For example, consider the following code:

```
char getString(5);
out << "Enter some input:\n";
cin.getline(getString, 5);
out << "  END OF OUTPUT\n";
```

When embedded in a complete program, this code produces a dialogue like the following:

+   - Enter input:
dobedowap
dobeeEND OF OUTPUT

Note that not five, characters are read into the C-string variable shortString, even though the second argument is 5. This is because the null character '\0' fills one array position. Every C-string is terminated with the null character when it is stored in a C-string variable, and this always consumes one array.

The C-input and output techniques we illustrated for cout and cin work the same way for input and output. The input stream cin can be replaced by an input stream that is connected to a file. The output stream cout can be replaced by an output stream that is connected to a file. (File I/O is discussed in Chapter 12.)

# getline

# SYNTAX

```
cin.getline(String_Var, Max_Characters + 1);
```

One line of input is read from the stream Input_Stream and the resulting C-string is placed in String_Var. If the line more Max_Characters long, only the first Max-Characters on the line are read. (The +1 is needed because C-string has the null character '\0' added to the end of the C-string and thus the string stored in String_Var is longer than the number of characters read in.)

# EXAMPLE

```
char oneLine[80];ncin.getline(oneLine, 80);
```
