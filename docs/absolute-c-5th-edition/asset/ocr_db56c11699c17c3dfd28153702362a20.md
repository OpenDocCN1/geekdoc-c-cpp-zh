# Default Arguments

You can specify a default argument for one or more call-by-value parameters in a function. If the corresponding argument is omitted, it is replaced by the default argument. For example, the function volume in Display 4.8 computes the volume of a box from its length, width, and height. If no height is given, the height is assumed to be 1. If neither a width nor a height is given, they are both assumed to be 1.

Note that in 4.8 the default arguments are given in the function declaration but not in the function. A default argument is given the first time the function is declared (or defined, if that occurs). Subsequent declarations or a following definition should not cause this error even if the arguments are consistent with the ones given previously.

You may have more than one default argument, but all the default positions must be in the rightmost positions. Thus, for the function volume in Display 4.8, we could have default arguments for the last one, two, or three parameters, but any other combinations of default arguments are not allowed.

If you have more than one default argument, when the function is invoked, you must omit arguments starting from the last. For example, note that in Display 4.8 there are two default arguments. When only one is omitted, it is assumed to be the last. There is no way to omit the second argument in an invocation of volume without omitting the third argument.

Default arguments are limited in value, but sometimes they can be used to reflect your way of thinking about arguments. Default arguments can only be used with call-by-value parameters. They do not make sense for call-by-reference parameters. Anything you can do with default arguments can be done using overloading, although the default argument version will probably be shorter than the overloading version.
