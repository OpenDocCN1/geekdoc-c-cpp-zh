A class can be a friend of another class in the same way that a function can be a friend of a class. If the class F is a friend of the class c, then every member function of the class F is a friend of the class C. Thus, if, for example, the Queue template class is a friend of the Node template class, then the private member variables would be directly available in the definitions of the member functions of Queue. The details are outlined in Display 17.22.
