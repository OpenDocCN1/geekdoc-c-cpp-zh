4. Write a program that takes its input from a file of type double. The program outputs to the screen the average and standard deviation of the numbers in the file. The file contains nothing but numbers of type double separated by blanks and/or line breaks. The standard deviation of a list of numbers $n_1, n_2, ...$ and so, is defined as the square root of the average of the following numbers:

$(n_1 - \bar{n}), (n_2 - \bar{n}), (n_i - \bar{n})$, and so forth

The number is a average of the numbers $n_1, n_2, ... n_n$ and so forth.

Hint: write your program that it first reads the entire file and computes the average of all the numbers, then closes the file, reopens the file and computes the standard deviation. You will find it helpful to do Programming Project 12.2 and then modify that program to obtain the program for this project.

You can use your editor to enter the initial piece of advice in the file so that the first person who runs the program receives some advice. The user to type in advice of any length (any number of lines long). The user is to end his or her by pressing the Return key two times. Your program can then test to see if it has reached the end of the input by checking to see two consecutive occurrences of the character '!'.

7. Write a program to generate personalized mail. The program takes input from an input file and keyboard. The input file contains the text of a letter, let the name of the recipient be indicated by the characters ##. The program asks the user for a name and then writes the letter to a second file with ## replaced by the name. ## will occur once at the end of the letter.

Hint: Have your program read from the input file until it encounters the characters ## and have it copy what it reads to the output file as it goes. When it encounters the characters ##, it then sends the name from the keyboard to the screen. Your program should be able to figure out the rest. Your program should define a function with the input- and output-file as arguments.

Harder version: Allow the string ## to occur any number of times in the file. This case is stored in string variables. For this version assume that there is a first name and last name but no middle names or initials.

The data in the output file will be the same as in the input file except there will be one additional (of type double) at the end of each line: the average of the quiz scores. `cin >>`

12. Write a program that allows the user to type in any one-line question and answers that answer the question, but will simply not really pay attention to the question line and discard all that it is. It always gives one of the following:

- Imm not sure but I think you will find the answer in Chapter #N.
- That's a good question.
- If I were you, I would not worry about such things.
- That question has puzzled philosophers for centuries.
- I don't know. I'm just a machine.
- Think about it and the answer will come to you.
- I used to know the answer to that question, but I've forgotten it.
- The answer can be found in a secret place in the woods.

These answers are stored in a file (one answer per line), and your program simply reads the next answer from the file and writes it out as the answer to the question. After your program has read the entire file, it simply closes the file, reopens it, and starts down the list of answers again.
