# 492 CHAPTER 11 Separate Compilation and Namespaces

```
using Declarations
```

This subsection describes a way to qualify a single name so that you can make only one name from a namespace available to your program, rather than making all the names in a namespace available. We saw this technique in Chapter 1 and so this is a review and amplification of what we saw in Chapter 1.

Suppose you are faced with the following situation. You have two namespaces, NS1 and NS2. You want to use the function fun defined in NS1 and the function fun2 defined in namespace NS2. The complication is that both NS1 and NS2 define a function myFunction. (Assume all functions in this discussion take no arguments, so overloading does not apply). You cannot use

```
using namespace NS1;
using namespace NS2;
```

This would potentially provide conflicting definitions for myFunction. (If the name myFunction is not used, the compiler will not detect the problem and will allow you to compile and run).

What you need is a way to say you use fun in namespace NS1 and fun2 in namespace NS2 and else in the namespaces NS1 and NS2. We have already been using a technique that can handle this situation. The following is your solution:

```
NS1::fun;
NS2::fun2;
```

A qualification of the form

```
using Name_Space::One_Name;
```

 (the definition of) the name Name_Name from the namespace Name_Space available, but does not make any other names in Name_Space available. This is called a using declaration.

Note that the scope resolution operator :: that we use in using declarations is the same as the scope resolution operator we use when defining member functions. These two uses of the scope resolution operator have a similarity. For example, Display 11.2 has the following function:

```
void DigitalTime::advance(int hoursAdded, int minutesAdded)
{
  hour = (hours + hoursAdded) % 24;
  advance(minutesAdded);
}
```

In this case :: means we are defining the function advance for the class DigitalTime, as opposed to any other function advance in any other class. Similarly,

```
using NS1::fun;
```

we are using the function fun as defined in the namespace NS1, as opposed to any other definition of fun in any other namespace.
