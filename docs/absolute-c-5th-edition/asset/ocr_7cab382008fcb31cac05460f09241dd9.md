# The const Parameter Modifier

When you use an argument in a function call, the function can change the values stored in the array. This is usually fine. However, in a complicated function definition, you might write code that inadvertently changes one or more of the values stored in an array the array should not be changed at all. As a precaution, you can tell the compiler that you do not intend to change the array argument, and the computer will tell you to make sure your code does not inadvertently change any of the values in the array. To tell the compiler an array argument should not be changed by your function, insert the const before the array parameter for that position. An array parameter that is modified with a const is called an array parameter.

For example, the following function outputs the values in an array but does not change the values in the array:

```
void showTheWorld(int a[], int sizeOf)
//Precondition: sizeOf is the declared size of the array a.
//All indexed variables of a have been given values.
//Postcondition: The values in a have been written to the screen.

cout << "The array contains the following values:\\n"
for (int i = 0; i < sizeOf; i++)
    cout << a[i] << " ";
cout << endl;
```

This function works however, as an added safety measure, you can add the modifier const to the function heading as follows:

```
void showTheWorld(const int a[], int sizeOf)
```

With this modifier const, the computer will issue an error message if your function definition contains a mistake that changes any of the values in the array argument. For example, this is a version of the function showTheWorld that contains a mistake that inadvertently changes the value of the array argument. Fortunately, this version of the function definition includes us that the array has been changed. This error message will help you to explain the mistake:

```
void showTheWorld(const int a[], int sizeOf)
//Precondition: sizeOf is the declared size of the array a.
//All indexed variables of a have been given values.
//Postcondition: The values in a have been written to the screen.
```

```
cout << "The array contains the following values:\\n"
for (int i = 0; i < sizeOf; i++)
    cout << a[i] << " ";
cout << endl;
```
