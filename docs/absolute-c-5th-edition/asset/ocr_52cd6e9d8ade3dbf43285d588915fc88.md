More generally, you can combine any of the arithmetic types in expressions. If all the types are integer types, the result will be the integer type. If at least one of the subexpressions is a floating-point type, the result will be a floating-point type. C++ tries its best to make the value of an expression either int or double, but if the value produced by the expression is not one of these types because of the value's size, a suitable integer or floating-point type will be produced.

You can specify the order of operations in an arithmetic expression by inserting parentheses. If you omit parentheses, the computer will follow rules called precedence rules to determine the order in which the operations, such as addition and multiplication, are performed. These precedence rules are similar to rules used in algebra and other mathematics classes. For example,

```
x + y * z
```
