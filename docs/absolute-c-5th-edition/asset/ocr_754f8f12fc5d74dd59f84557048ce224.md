# defining member functions

The member functions for a class template are defined the same way as member functions for ordinary classes. The only difference is that member function definitions are themselves templates. For example, Display 16.4 shows appropriate definitions for the member function setFirst and getFirst, and for the constructor with two arguments for the template class Pair. Notice that the class name before the scope operator is PairT, and not Pair. However, the constructor name after the scope operator is the simple name Pair without <T>nThe name of a class template may be used as the type for a function. For example, the following is a possible function declaration for a function with a parameter of integers:

```
int addUp(const PairInt& thePair);
//Returns the sum of the two integers in thePair.
```

Now that we specified the type—in this case, int—that is filled for the type parameter TnYou can use a class template within a function template. For example, rather than defining the specialized function addUp in the given code, so that the function applies to all kinds of numbers:

```
template<class T>
T addUp(const Pair<T>& thePair);
//Precondition: the operator + is defined for values of type T.
//Returns the sum of the two values in thePair. *
```
