One way to design an algorithm is to rely on the definition of the problem. In this case problem is to sort an array from smallest to largest. That means rearranging the values that a[0] is the smallest, a[1] is the next smallest, and so forth. That definition yields an outline for the selection sort algorithm:

```
for (int index = 0; index < numberUsed; index++)
Place the smallest element in a[index]
```

There are many ways to realize this general approach. The elements could be developed using two arrays and copying the elements from one array to the other in sorted order, but one array should be adequate and economical. Therefore, the function sort uses only the array containing the values to be sorted. The function sort rearranges the values in the array by exchanging pairs of values. Let us go through a concrete example so that you can see how the algorithm works.

Consider the array in Display 5.7. The algorithm will place the smallest value in a[0], so the algorithm interchanges values of a[0] and a[3]. The algorithm then looks for the next-smallest element. The value in a[0] is now the smallest element, and so the next-smallest element is the smallest of the remaining elements a[1], a[2], a[3], ..., a[9]. In the example of Display 5.7 the next-smallest element is in a[5], so the algorithm interchanges of a[1] and a[5]. This positioning of the second-smallest element is illustrated in the fourth and fifth array pictures in Display 5.7. The algorithm then positions the third-smallest element, and so forth. As the sorting proceeds, the beginning array elements are set equal to the correct sorted values. The sorted portion of the array grows by adding elements one after the other in the unsorted end of the array. Notice that the algorithm need not do anything with the last variable, a[9]. Once the other elements are positioned correctly, a[9] must also have the correct value. After all, the correct value for a[9] is the smallest value to be moved, and the only value to be moved is the value that is already in a[9].

The definition of the function sort, included in a demonstration program, is in Display 5.8. sort uses indexofsmallest to find the index of the smallest element in the unsorted end of the array, and then it does an interchange to move this next-smallest element down into the sorted part of the array.

The function swapValues, shown in Display 5.8, is used to interchange the values of indexed variables. For example, the following call will interchange the values of a[0] and a[3]:

```

```
