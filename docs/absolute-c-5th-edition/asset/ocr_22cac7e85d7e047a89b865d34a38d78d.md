> The "or" Operator, ||
nYou can form a more elaborate Boolean expression by combining two simpler Boolean expressions using the "or" operator, ||.

SYNTAX FOR A BOOLEAN EXPRESSION USING ||
(Boolean_Exp_1) || (Boolean_Exp_2)

EXAMPLE WITHIN AN if-else STATEMENT

```
if (x == 1) || (x == y) {
    cout << "x is 1 or equals y.\n";
} else {
    cout << "x is neither 1 nor equal to y.\n";
}
```

If the value of x is equal to 1 or the value of x is equal to the value of y (or both), then the first statement will be executed; otherwise, the second statement will be executed. if-else statements are covered bit later in this chapter, but the meaning of this simple example should be intuitively clear.
