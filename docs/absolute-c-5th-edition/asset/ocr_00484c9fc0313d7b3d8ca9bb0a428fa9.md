# Precedence of Operators

All the operators in a given box have the same precedence. Operators in higher boxes have higher precedence operators in lower boxes. Unary operators and the assignment operator are right to left when operators have the same precedence. For example, x = y = z means x = (y = z). Other operators that have the same precedence are left to right. For example, x + y + z means (x + y) + z.
