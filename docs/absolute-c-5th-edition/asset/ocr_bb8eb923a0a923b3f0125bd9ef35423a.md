# EXAMPLE: Template Class For a Partially Filled Array with Backup

Chapter 14 (Displays 14.10 and 14.11) defined the class PFArrayBak for partially filled arrays of double with backup. We defined it as a derived class of PFArrayD (Displays 14.8 and 14.9). The class PFArrayD was for a partially filled array, but it only worked for the base type double. 16.5 and 16. converted the class PFArrayD to the template class PFArray so that it would work for any type of array base. In this program, we define a template class PFArrayBak with backup that will work for any type of array base. We will define the template class PFArrayBak as a derived class of the template PFArray. We can do this almost by starting with the regular derived PFArrayBak and replacing all occurrences of the array base type with a type parameter T, replacing the class PFArrayD with the template class PFArray, and cleaning up the syntax so it fully conforms to template syntax.

The interface to the class PFArrayBak is given in Display 16.8. Note that the base class is PFArray<T> with the array parameter, not simply PFArray. If you think about it, you will realize that the <T>. A partially filled array of T with backup is a derived class of a partially filled array of T. The T, and how it is used, is important. In what follows, we reproduce the first constructor definition in the implementation:

```
template<class T>
PFArrayBak<T>::PFArrayBak() : PFArray<T>(), usedB(0)
{
    b = new T[getCapacity()];
}
```

Note that, with any definition of a template class function, it starts withntemplate<class T>

Also notice that the base type of the array (given after the new) is the type parameter T. Other details may not be as obvious, but do make sense.
Next consider the following:

```
PFArrayBak<T>::PFArrayBak() : PFArray<T>(), usedB(0)
```

As with any definition of a template class function, the definition has PFArray<T> with the type parameter the scope resolution operator, but the constructor is just plain, old PFArray without any type parameter. Also notice that the base class constructor includes the type parameter T in the initialization PFArray<T>(). This is so that the constructor will match the base type PFArray<T> as given in the following line of the interface:

```
class PFArrayBak : public PFArray<T>
```
