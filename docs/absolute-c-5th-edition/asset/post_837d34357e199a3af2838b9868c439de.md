## 19.2 Containers

Can put all your eggs in one basket, but be sure it's a good basket.

> WALTER SAVITCH, Absolute C++

The container classes of the STL are different kinds of structures for holding data, such as lists, queues, and stacks. Each is a template class with a parameter for the type of data to be stored. For example, you can specify a list of ints or strings, or any class or struct you wish. Each template may have its own specialized accessor and mutator functions for adding and removing data from the container. For example, one container class may have bidirectional iterators, whereas another container class may have only forward iterators. However, when they are defined, the iterator operations and the member functions begin() and end() have the same meaning for all STL containers.

## Sequential Containers

A sequential container arranges its data into a list such that there is a first element, a next element, and so forth, up to a last. The linked lists we discussed in Chapter 17 are examples of a sequential container; these kinds of lists are sometimes singly linked lists because there is only one link from one location to another. The STL has no container corresponding to such a singly linked list, although some implementations offer an implementation of a singly linked list, typically doubly linked list. The simplest list that is part of the STL is the doubly linked list, the difference between these two kinds of lists is illustrated in Display 19.4 and described in more detail in Section 17.1.

slist and list The lists in Display 19.4 contain the three integer values 1, 2, and 3 in order. The types for the two lists are slist<int> and list<int>. The Display also indicates the location of the iterators begin() and end(). We have not yet told you how to enter the integers into the lists.

In Display 19.4 we have drawn our singly and doubly lists as nodes and pointers of the form discussed in Chapter 17. The STL class list and the nonstandard class list might (or may not) be implemented in this way. However, when using the STL template classes, you are shielded from these implementation details. So, you simply think in terms of locations for the data (which may or not be nodes) and of iterators (not pointers). You can think of the arrows in Display 19.4 as indicating the directions for ++ (which is down) and -- (which is up).

We presented the template class slist to help give a context for the sequential containers. It corresponds to what we discussed in Chapter 17 and the first thing comes to the mind of most programmers who you mention linked lists. However, since the template class slist is not standard, we will not discuss it further. If your implementation uses the template class slist and you want to use it, the details are similar to those we describe for list, except that the decrement operator (prefix and suffix) are not defined for slist.

Display 19.5 Using the list

```cpp
// Program to demonstrate the STL class list.
#include <iostream>
#include <list>

using std::cout;
using std::endl;
using std::list;

int main() {
    list<int> listObject;

    for (int i = 1; i <= 3; i++)
        listObject.push_back(i);

    cout << "List contains:" << endl;
    list<int>::iterator iter;
    for (iter = listObject.begin(); iter != listObject.end(); iter++)
        cout << *iter << " ";
    cout << endl;

    cout << "Setting all entries to 0:" << endl;
    // push back logic
    for (iter = listObject.begin(); iter != listObject.end(); iter++)
        *iter = 0;

    cout << "List now contains:" << endl;
    for (iter = listObject.begin(); iter != listObject.end(); iter++)
        cout << *iter << " ";
    cout << endl;

    return 0;
}
```
