
# Display 19.1 Iterators Used with a Vector

```cpp
//Program to demonstrate STL iterators.
#include <iostream>
#include <vector>
using std::cout;
using std::endl;
using std::vector;

int main() 
{
    vector<int> container;

    for (int i = 1; i <= 4; i++)
        container.push_back(i);

    cout << "Here is what is in the container:\n";
    vector<int>::iterator p;
    for (p = container.begin(); p != container.end(); p++)
        cout << "*" << *p << "\n";
    cout << std::endl;

    cout << "Setting entries to 0:\n";
    for (p = container.begin(); p != container.end(); p++)
        *p = 0;

    cout << "Container now contains:\n";
    for (p = container.begin(); p != container.end(); p++)
        cout << "*" << *p << " ";
    cout << std::endl;

    return 0;
}
```

Sample Dialogue

```
Here is what is in the container:
1 2 3 4
Setting entries to 0:
Container now contains:
0 0 0 0
```

# CHAPTER 19 Standard Template Library

The basic use of iterators with vector (or any container class) is illustrated by the following lines from Display 19.1:

```cpp
vector<int>::iterator p;
for (p = container.begin(); p != container.end(); ++p)
  cout << *p << " ";
```

Recall that container is of type `vector<int>`, and that the type iterator really stands for `std::vector<int>::iterator`.

A vector v can be thought of as a linear arrangement of its data elements. There is a first element v[0], and so forth. An iterator p is an object that can be located at one of these elements (or points to one of them). An iterator can move its location from one element to another. If p is located at v[i], then p++ moves p to v[i+1]. This allows an iterator to move through the vector from the first to the last, but it needs to find the first element and know when it has seen the last element.

You can tell if an iterator is at the same location as another iterator using the operator ==. Thus, if you have an iterator pointing to the first, last, or other element, you could test another iterator to see if it is located at the first, last, or other element.

If p1 and p2 are iterators, then the comparison

```
p1 == p2
```

is true only when p1 and p2 are located at the same element. This is analogous to pointers (if p1 and p2 were pointers, this comparison would be true if they pointed to the same thing). As usual, != is just the negation of ==, and so

```
p1 != p2
```

is true when p1 and p2 are not located at the same element.

The member function begin() is used to position an iterator at the first element in a container. For vectors, and many other container classes, the member function begin() returns an iterator located at the first element. (For a vector v, the first element is v[0]). Thus,

```cpp
vector<int>::iterator p = v.begin();
```

initializes the iterator p to an iterator located at the first element. The basic loop for visiting all elements of the vector v is therefore

```cpp
vector<int>::iterator p;
for (p = v.begin(); Boolean_Expression; p++)
  Action_At_Location p;
```

The desired stopping condition is

```cpp
p == v.end()
```

The member function end() returns a sentinel value that can be checked to see if an iterator has passed the last element. If p is located at the last element, then p++, the test p == p.end() changes from false to true. So the correct Boolean_Expression is the negation of this condition:

```cpp
vector<int>::iterator p;
for (p = v.begin(); p != v.end(); p++)
    Action_At_Location;
```

Note that p.end() does not change from false to true until p's position has passed the last element. So, v.end() is not located at any element. The value v.end() is a special value that serves as a sentinel. It is not an iterator, but you can compare v.end() to an iterator using == and !=. The value v.end() is analogous to the value NULL that is used to mark the end of a linked list of the kind discussed in Chapter 17.

The following loop for Display 19.1 uses this same technique with the vector named container:

```cpp
vector<int>::iterator p;
for (p = container.begin(); p != container.end(); p++)
    cout << *p << " ";
```

The action at the location of the iterator p is

```cpp
cout << *p << " ";
```

The dereferencing operator, *, is overloaded for STL container iterators so that *p produces the element located at location p. In particular, for a vector container, *p produces the element located at the iterator p. The preceding cout statement *p outputs the element located at the iterator p.

The dereferencing operator *p always produces the element at the iterator p. In some situations *p produces read-only access, which does not allow you to change the element. In other situations it gives access to the element and will let you change it. For vectors, *p will allow you to change the element located at p, as illustrated by the following loop for Display 19.1:

```cpp
for (p = container.begin(); p != container.end(); p++)
    *p = 0;
```

This for loop cycles through all the elements in the vector container and changes all the elements to 0.

# PITFALL: Compiler Problems

Some compilers have problems with iterator declarations. You can declare an iterator in different ways. For example, we have been using the following:

```cpp
using std::vector;
vector<char>::iterator p;
```

Alternatively, you could use the following:

```cpp
using std::vector<char>::iterator;
iterator p;
```

You could also use the following, which is not as quite nice:

```cpp
using std::vector;
vector<char>::iterator p;
```

There are other variations of how to declare iterators. However, some compilers may not support all of them. In such cases, you may need to use a typedef or a using declaration:

```cpp
typedef vector<char>::iterator char_iterator;
char_iterator p;
```

# Kinds of Iterators

Iterators are classified according to the operations they support. The main types are:

- Input iterators: Can only be moved forward and are read-only.
- Output iterators: Can only be moved forward and are writeable.
- Bidirectional iterators: Can be moved forward and backward.
- Random-access iterators: Can be moved to any element in constant time.

The `vector::iterator` provides random-access capabilities. The `list::iterator` provides bidirectional iterators. The `deque::iterator` also provides random-access capabilities.
