# The Member Functions get and put

The function get allows your program to read one character of input and store it in a variable of type char. Every input stream, whether it is an input-stream or the stream cin, has get as a member function. We will describe get here as a member function of the object cin. We will discuss I/O in Chapter 12 where it behaves exactly as for input-file streams as it does for cin.

Now here have used cin with the extractor, >> to read a character of input (or any other input, for that matter). When you use the extractor >>, some things are done for you automatically, such as skipping over whitespace. But sometimes you do not want to skip over whitespace. The member cin.get reads the next input character whatever the character is whitespace or not.

The member function takes one argument, which should be a variable of type char. Argument receives the input character that is read from the input stream. For example, the following will read the next input character from the keyboard and store it in the variable nextSymbol:

![](img/f4b6fc3d28ec32a6e3350e2846d6e0d1_411_0.png)

```cpp
char nextSymbol;
cin.get(nextSymbol);
```

It is important to note that your program can read any character in this way. If the next input character is a blank, this code will read the blank character. If the next character is the newline character '\n' (that is,), the previous call to cin.get will set the value of nextSymbol equal to '\n'. For example, suppose your program contains the following code:

```cpp
char c1, c2, c3;
cin.get(c1);
cin.get(c2);
cin.get(c3);
```

and suppose you type in the following two lines of input to be read by this code:

```
AB
CD
```

The value of c1 is set to 'A', the value of c2 is set to 'B', and the value of c3 is set to '\n'. The variable c3 is not equal to 'C'.

# detecting the end of an input line

One thing you can do with the member function get is to have your detect the end of a line. The following loop will read a line of input and stop after passing the newline character '\n'. Any subsequent input will be read from the beginning of the next line. For this example, we have simply echoed the input, but the same technique would allow you to do whatever you want with the input.

```cpp
cout << "Enter a line of input and I will echo it:\n";
char symbol;
{
	cin.get(symbol);
	cout << symbol;
} while (symbol != '\n');
cout << "That's all for this demonstration.\n";
```

This loop will read any line of input and echo exactly, including blanks. The following is a dialogue produced by this code:

Enter a line of input and I will echo it:
Do Be Do 1  32
Do Be Do 1  34
That's all for this demonstration.

Notice that the newline '\n' is both read and output. Since the string begins with the word "That's" is on a new line.
