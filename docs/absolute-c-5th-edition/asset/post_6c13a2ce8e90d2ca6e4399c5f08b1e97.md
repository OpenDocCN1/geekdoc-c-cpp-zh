
## PITFALL: Division with Whole Numbers

When you use the division operator / on two integers, the result is an integer. This can be a problem if you expect a fraction. Moreover, the problem can easily go unnoticed, resulting in a program that looks fine but producing incorrect output without you even aware of the problem. For example, suppose you are a landscape architect who charges $5,000 per mile to landscape a highway, and suppose you know the length of the highway you are working on. The price you charge can easily be calculated by the following C++ statement:

```cpp
totalPrice = 5000 * (feet/5280.0);
```

This works because there are 5,280 feet in a mile. If the stretch of highway you are landscape is 15,000 feet long, this formula will tell you that the total price is

```cpp
5000 * (15000/5280.0);
```

Your C++ program obtains the final value as follows: 15000/5280.0 is computed as 2.84. The program then multiplies 5000 by 2.84 to produce the value 14200.00. With the aid of your C++ program, you know that you should charge $14,200 for the project.

Now suppose the variable feet is of type int, and you forget to put in the decimal point and zero, so that the assignment statement in your program reads

```cpp
totalPrice = 5000 * (feet/5280);
```

It looks fine, but will cause serious problems. If you use this second form of the assignment statement, you are dividing two values of type int, so the result of the division feet/15000/5280, which is the int value 2 (instead of the value 2.84 that you think are getting). The value assigned to totalPrice is 5000*2, or 10000.0. If you forget the decimal point, you will charge $10,000. However, as we have already seen, the correct value is $14,200. A missing decimal point can cost you $4,200. Note that this will be true whether the type of totalPrice is int or double; the damage is done before the value is assigned to totalPrice.

## Type Casting

A type cast is a way of changing a value of one type to a value of another type. A type cast is a kind of function that takes a value of one type and produces a value of another type. C++ has four to six kinds of casts, depending on how you count them. There is an older form of type cast that has two notations for expressing it, and there are four new kinds of type casts introduced with the latest standard. The new kinds of type casts were designed as replacements for the older form; in this book, we will use the newer ones. However, C++ retains the older kind() along with the newer kinds, so we will describe the older kind as well.

Let's start with the newer kind of type casts. Consider the expression 9/2 when operands are an integer type, C++ performs integer division. In some situations, you might want the answer to be the double value 4.5. You can get a result of 4.5 by using the "equivalent" floating-point value 2.0 in place of the integer value 2, as in 9/2.0, which evaluates to 4.5. But what if the 9 and the 2 are variables of type int n and m? Then n/m yields 4. If you want floating-point division in this case, you must do a type cast from int to double (or another floating-point type), as in the following:

```cpp
ans = n/static_cast<double>(m);
```
