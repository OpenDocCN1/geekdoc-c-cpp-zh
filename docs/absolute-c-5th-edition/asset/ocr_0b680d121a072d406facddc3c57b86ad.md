> Hash Table
A hash table is a data structure that associates a data item with a key. The key is computed by a hash function.

# Efficiency of Hash Tables

The efficiency of our hash table depends on several factors. First, let us examine inserted extreme cases. The worst-case run-time performance occurs if every item inserted into the table has the same key. Everything will be stored in a single linked list, and the find operation may require searching through each item in the list. Fortunately, if the items that we insert are random, the possibility that all of them have the same key is highly unlikely. In contrast, the best-case run-time performance occurs if every item inserted into the table has a different key. This means that there will be no collisions, so the find operation will only to search through a one-item list because the target will always be the first node in the linked list.

We can decrease the chance of collisions by using a better hash function. For example, the sample hash function that sums each letter of a string ignores the order of the letters. The "rat" and "tar" would have the same value. A better hash function for a string is to multiply each letter by an increasing weight depending on the position in the word:

```
int hash = 0;
for (int i = 0; i < s.length( ); i++) {
  hash = 31 * hash + s[i];
}
```

Another way to decrease the chance of collisions is by making the hash table bigger. For example, if the hash table array had a 10,000-capacity but we were only inserting 1000 items, the probability of a collision would be much smaller than if the hash table array could store only 1000 entries.
