# Stacks for Recursion

To keep track of recursion (and a number of other things), most computer systems make use of a structure called a stack. A stack is a very specialized kind of memory structure that is analogous to a stack of paper. In this analogy, there is an inexhaustible supply of extra sheets of paper. To place some information in the stack, it is written on one of these sheets of paper and placed on top of the stacks of paper. To place more information in the stack, a clear sheet of paper is placed, the information is written on it, and this new sheet of paper is placed on top of the stack. This is straightforward way, and more information can be placed on the stack.

Getting out of the stack is also accomplished by a very simple procedure. The top sheet of paper can be read, and when it is no longer needed, it is thrown away. In order to read, the third sheet from the top, the two sheets must be thrown away. Since the last sheet that is put on the stack is the first sheet taken off the stack, a stack is often called last-in-first-out memory structure.

Using a stack, we can easily keep track of recursion. When a function is called, a new sheet of paper is taken. The function definition is copied onto top of this sheet of paper, and the arguments are plugged in for the function parameters. Then the computer encounters a recursive call, it starts the computation it is doing on that sheet in order to compute the value returned by the recursive call. But before computing the recursive call, it saves the value returned by the recursive call, written on a sheet of paper and placed on the stack. A new sheet of paper is used for the recursive call. The computer writes a second copy of the function definition on this new sheet of paper, plugs in the arguments for the function parameters, and starts to execute the recursive call. When it gets to a recursive call within the recursively called copy, it repeats the process of saving information on the stack and using a new sheet of paper for the new recursive call.
