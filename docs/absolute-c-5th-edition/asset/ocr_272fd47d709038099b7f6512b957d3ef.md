# Summary of File I/O Statements

In this example the input comes from a file with the name infile.txt, and the output goes to a file with the name outfile.txt.

+   Place the include directives in your program file:

```
#include <fstream> // For file I/O
#include <iostream> // Forcout
#include <cstdlib> // Forexit
```

Add the following using directives (or something similar):

```
using std::fstream;
using std::ofstream;
using std::cout;
using std::endl; // endl is used
```

+   Choose a name for the input stream and declare it to be a variable of type ifstream. Choose a stream name for the output file and declare it to be of type ofstream. For example,
if inStream;
ofstream outStream;

+   Connect each stream to a file using the member function with the external name as an argument. Remember to use the member function fail to test that the call to open was successful:
inStream.open("infile.txt");
if (inStream.fail()) {
	cout << "Input file opening failed.\n";
	exit(1);
}
outStream.open("outfile.txt");
if (outStream.fail()) {
	cout << "Output file opening failed.\n";
	exit(1);
}

+   Use the instream to get input from the file infile.txt just like you use cin to get input from the keyboard.
inStream >> someVariable >> someOtherVariable; (continued)
