
## CHAPTER 12 Streams and File I/O

If D is a derived class of the class B, then every object of type D is also of type B. A convertible is also an automobile. A file input stream (object of the class istream) is also an input stream (an object of the class istream). So, if we use istream as the type for a function parameter, rather than using ifstream, more objects can be plugged in for the parameter. Consider the following two function definitions, which differ only in the type of the parameter (and the function name):

```cpp
void twoSumVersion1(istream sourceFile) //istream with an 'f'
  int n1, n2;
  sourceFile >> n1 >> n2;
  cout << n1 << " " << n2 << " " << (n1 + n2) << endl;
}
```

```cpp
void twoSumVersion2(istream& sourceFile) //istream without an 'f'
  int n1, n2;
  sourceFile >> n1 >> n2;
  cout << n1 << " " << n2 << " " << (n1 + n2) << endl;
}
```

With twoSumVersion1, the argument must be of type ifstream. So if fileIn is a file input stream connected to a file,

```cpp
twoSumVersion1(fileIn);
```

is legal, but

```cpp
twoSumVersion1(cin); //ILLEGAL
```

is not legal, because cin is not of type ifstream. The object cin is only a stream and only of type cin; cin is not of a file input stream.
The function twoSumVersion2 is more versatile. Both of the following are legal:

```cpp
twoSumVersion2(fileIn);
twoSumVersion2(cin);
```

The moral is: Use istream, not ifstream, as a parameter type you can. When choosing a parameter type, use the most general type you can. (To draw a real-life analogy consider the following: You might prefer to own a convertible, but if you borrowed a sedan from a friend that could only hold a convertible, you'd still be able to park the sedan in your garage.)

You cannot use the parameter type ifstream instead of the type istream. If you define a function with a parameter of type ifstream, then that parameter can only use istream member functions. In particular, you cannot use the functions open and close. If you cannot call all the member functions outside the function definition, then you must use a parameter of type istream.

## EXAMPLE: Another newLine Function

As an example of how you can make a stream more versatile, consider the function newLine that we defined in Display 9.2. That function works only for input from the keyboard, which is input from the predefined stream cin. The function newLine in Display 9.2 has no arguments. Next we have rewritten the function newLine so it has a formal parameter of type istream for the input stream.

```cpp
// <iostream>
void newLine(istream& inStream)
{
    char symbol;
    do
        inStream.get(symbol);
    } while (symbol != '\n');
}
```

Now, suppose your program contains this new version of the function newLine. If your program is taking input from an input stream called fin (which is connected to an input file), the following will discard all the input left on the line currently being read from the file:

```cpp
newLine(fin);
```

If your program is also reading some input from the keyboard, the following will discard the remainder of the input line that was typed in the keyboard:

```cpp
newLine(cin);
```

If your program has only the previous rewritten version of the function, which takes a stream argument, you must always give the stream name. To avoid overloading, you can have both versions of the newLine in the same program: the version with no arguments is given in 9.2 and the version with one argument of istream serve all your needs. However, many programmers find it convenient to have a version with no arguments for keyboard input, since keyboard input is used frequently.
An alternative to having overloaded versions of the function is to use a default argument (as discussed in Chapter 4). In the following code, we have rewritten the newLine function a third time.

```cpp
// <iostream>
void newLine(istream& stream = cin)
{
    char symbol;
    do
        stream.get(symbol);
    } while (symbol != '\n');
}
```

## Making Stream Parameters Versatile

If you want to define a function that takes an input stream as an argument and you want that argument to be cin in some cases and an input-file stream in other cases, use a formal parameter of type istream (without an 'f'). However, an input-file stream, even if used as an argument of istream, must still be declared to type ifstream (with an 'f').
Similarly, if you want to define a function that takes an output stream as an argument and you want that argument to be cout in some cases and an output-file stream in other cases, use a formal parameter of type ostream. However, an output-file stream, even if used as an argument of ostream, must still be declared to type ofstream (with an 'f'). You cannot open or close a stream parameter of istream or ostream. These objects exist before passing them to your function and close them after the function.
The stream classes istream and ostream are defined in the iostream library and placed in the std namespace. One way to make them available to your code is the following:

```cpp
#include <iostream>
using std::istream;
using std::ostream;
```
