The member function end() returns a sentinel value that can be checked to see if an iterator has passed the last element. If p is located at the last, then p++, the test = p.end() changes from false to true. So the correct Boolean_Expression is the negation of this condition:

```
vector<int>::iterator p;
for (p = p.begin()); p != p.end(); p++)
    Action_At_Location;
```

Note that p.end() does not change from true to false until p's position has passed the last element. So, v.end() is not located at any element. The value v.end() is a special value that serves as a sentinel. It is not an iterator, but you can compare v.end() to an iterator using == and !=. The value v.end() is analogous to the value NULL that is used to mark the end of a linked list of the kind discussed in Chapter 17.

The following loop for Display 19.1 uses this same technique with the vector named container:

```
vector<int>::iterator p;
for (p = container.begin()); p != container.end(); p++)
    cout << *p << " "
```

The action at the location of the iterator p is

```
cout << *p << " ",
```

The dereferencing operator, *, is overloaded for STL container iterators so that *p produces the element located at location p. In particular, for a vector container, *p produces the element located at the iterator p. The preceding cout statement *p produces outputs the element located at the iterator p.

The dereferencing operator *p always produces the element at the iterator p. In some situations *p produces read-only access, which does not allow you to change the element. In other situations it gives access to the element and will let you change it. For vectors, *p will allow you to change the element located at p, as illustrated by the following loop for Display 19.1:

```
for (p = container.begin()); p != container.end(); p++)
    *p = 0;
```

This for loop cycles through all the elements in the vector container and changes all the elements to 0.
