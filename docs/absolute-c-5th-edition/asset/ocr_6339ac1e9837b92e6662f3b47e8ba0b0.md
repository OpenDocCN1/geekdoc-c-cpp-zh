# TIP: More Versions of getline

So far, we have described the following way of using getline:

```
string line;
cout << "Enter a line of input:\\n";ngetline(cin, line);
```

This version stops when it encounters the end-of-line marker, '\n'. There is a version that allows you to specify a different character as a stopping signal. For example, the following will stop when the first question mark is encountered:

```
string line;
cout << "Enter some input:\\n";ngetline(cin, line, '?');');
```

It makes sense to use getline as if it were a void function, but it actually returns a reference to its first argument, which is cin in the previous code. Thus, the following will read a line of text into s1 and a string of non-whitespace characters into s2:

```
string s1, s2;
getline(cin, s1) >> s2;
```

The invocation getline(cin, s1) returns a reference to cin, so that after the invocation of getline, the next thing to happen is equivalent to

```
cin >> s2;
```

This kind of use getline seems to have been designed for use in a C++ quiz show than to meet any actual programming need, but it can come in handy sometimes.

# PITFALL: Mixing cin >> variable; and getline

Take care in mixing input cin >> variable; with input using getline. For example, consider the following code:

```
int n;
string line;
cin >> n;
getline(cin, line);
```
