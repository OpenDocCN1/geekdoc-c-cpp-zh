Since the output is in thousands of units, the program will scale the values of the array elements. If the total output for plant number 3 is 4040 units, the value of production[2] will initially be set to 4040. This value of 4040 will be scaled to 4 so that the value of production[2] is changed to 4 and four asterisks will be output to represent the output for plant number 3. This scaling is done by the function scale, which takes the entire array production as an argument and changes the values stored in the array.

The function round rounds its to the nearest integer. For example, round (2.3) returns 2, and round (2.6) returns 3. The function round was discussed in Chapter 3, in the programming example entitled "A Rounding Function."
