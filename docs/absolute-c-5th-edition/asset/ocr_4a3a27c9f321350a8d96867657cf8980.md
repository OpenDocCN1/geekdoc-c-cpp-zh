The definition of the postfix version ignores int parameter, as shown in Display 8.6. When the compiler sees a++, it treats it as an invocation of IntPair::operator++(int), with as the calling object.

The increment and decrement operator on simple types, as int and char, return by reference in the prefix form and by value in the postfix form. If you want to emulate what happens with simple types when you overload these operators for your class, then you would return by reference for the prefix form and by value for the postfix form. However, we find it the door to too many problems to return by reference with increment and decrement operators, and we always simply return by value for all versions of the increment and decrement operators.
