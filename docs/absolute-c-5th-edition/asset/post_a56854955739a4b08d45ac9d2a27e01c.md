
# Recursion Iteration

Recursion is not absolutely necessary. In fact, some programming languages do not allow it. Any task that can be accomplished using recursion can be done in some other way without using recursion. For example, Display 13.2 contains a nonrecursive version of the function in Display 13.1. The nonrecursive version of a function typically uses a loop (or loops) of some sort in place of recursion. For this reason, the nonrecursive version is usually referred to as an iterative version. If definition of the function vertical in Display 13.1 is replaced by the version in Display 13.2, the output will be the same. As is true in this case, a recursive version of a function can be much simpler and more elegant than an iterative version so a gain in efficiency is not always preferable.

Display 13.2 Iterative Version of the Function in Display 13.1

```cpp
//Uses iostream:
void writeVertical(int n)
{
    int nsTens = 1;
    int leftPiece = n;
    while (leftPiece > 9)
    {
        leftPiece = leftPiece / 10;
        nsTens = nsTens * 10;
    }
    //nsTens is a power of ten that has the same number
    //of digits as n. For example, if n is 2,345, then
    //nsTens = 1000;

    for (int powerOf10 = 1; powerOf10 < nsTens; powerOf10 *= 10)
    {
        cout << (n / powerOf10) << endl;
        n = n % powerOf10;
    }
}
```

Modern compilers will convert certain recursive functions to equivalent iterative ones automatically for you. A function that uses tail recursion has the property that no further computation occurs after the recursive call; the function immediately returns. In the next section, when we use recursive functions with a return value, a function is tail if the value of a recursive call is returned without modification. In such cases, a tail recursion can be easily converted to an equivalent iterative solution. Check your compiler’s documentation and optimization flags to see if this operation is available.

# General Form for a Recursive Function That Returns a Value

The recursive functions you have seen thus far are all void functions, but recursion is not limited to void functions. A recursive function can return a value of any type. The technique for designing recursive functions that return a value is basically the same as for void functions. An outline for a successful recursive function definition that returns a value is as follows:

- One or more cases in which the value returned is computed in terms of calls to the same function (using recursive calls). As was the case with void functions, the arguments for the recursive calls should intuitively be “smaller.”
- One or more cases in which the value returned is computed without the use of any recursive calls. These cases without any recursive calls are called base cases or stopping cases (just as they were with void functions).

# EXAMPLE: Another Powers Function

Chapter 3 introduced the predefined function pow that computes powers. For example, pow(2.0, 3.0) returns 2.0^3, so the following sets the variable result equal to 8.0.

```cpp
double result = pow(2.0, 3.0);
```

The function takes two arguments of type double and returns a value of double. Display 13.3 contains a recursive definition for a function that is similar but works with the type int rather than double. For example, the following will set the value of result2 to 8, since 2^3 is:

```cpp
int result2 = power(2, 3);
```

Our reason for defining the function power is to have a simple example of a recursive function, but there are situations in which the function power would be preferable to the pow function. The function power returns a value of type double, which is only an approximate quantity. In some situations, you might need the additional accuracy provided by the power function.

The definition of the function power is based on the following formula:

```cpp
x^n = x^{n-1} * x
```

Translating this formula into C++ says that the value returned by power(x, n) is the product of power(x, n-1) and x. If n is 0, the function returns 1, which is the base case.

```cpp
int power(int x, int n)
{
    if (n == 0)
        return 1;
    else
        return power(x, n - 1) * x;
}
```
