```

```

You may use other identifier in place of DTIME_H, but the normal convention is to use the name in all uppercase letters with the underscore instead of the period. You should follow this so that others can easily read your code and that you do not have to remember the flag name. This way the flag name is determined automatically and there there is nothing arbitrary to remember.
