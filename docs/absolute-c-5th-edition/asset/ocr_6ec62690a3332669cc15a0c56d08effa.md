# Character Functions

For all these, the actual type of the argument is int, but for most purposes you can think of the argument as char. For tolower and toupper, the type returned is truly an int. To use the value as type char, you must perform an explicit or implicit cast.

| FUNCTION | DESCRIPTION | HEADER FILE |
|---|---|---|
| bool isnum(char); | Returns true if its argument satisfies alpha or isdigit. Otherwise returns false. | cctype |
| bool isalpha(char); | Returns true if its argument is an upper- or lowercase letter. It may also return true for other arguments. The details are implementation dependent. Otherwise returns false. | cctype |
| bool isdigit(char); | Returns true if its argument is a digit. Otherwise returns false. | cctype |
| bool ispunct(char); | Returns true if its argument is a printable character that does not satisfy isnum and is not whitespace. (These characters are considered punctuation characters.) Otherwise returns false. | cctype |
| bool isspace(char); | Returns true if its argument is a whitespace character (e.g., blank, tab, newline). Otherwise returns false. | cctype |
| bool iscntrl(char); | Returns true if its argument is a control character. Otherwise returns false. | cctype |
