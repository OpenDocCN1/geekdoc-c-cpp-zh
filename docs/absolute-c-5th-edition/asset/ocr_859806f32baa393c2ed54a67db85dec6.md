# Pointer Variables

A pointer can be stored in a variable. However, even though a pointer is a memory address and a memory address is a number, you cannot store a pointer in a variable of type int or double. A variable to hold a pointer must be declared to have a pointer type. For example, the following declarations p to be a pointer variable that can hold one pointer to points to a variable of type double:

```
double *p;
```

The variable p can hold pointers to variables of type double, but it cannot normally contain a pointer to a variable of some other type, such as int or char. Each variable requires a different pointer type.

In general, to declare a variable that can hold pointers to other variables of a specific type, you declare the pointer just as you would declare an ordinary variable of that type, but you use an asterisk in front of the variable name. For example, the following declares the variables p1 and p2 so they can hold pointers to variables of type int; it also declares two ordinary variables v1 and v2 of type int:

```
int *p1, *p2, v2;
```

There must be an asterisk before each of the pointer variables. p2 will not be a pointer variable; it will instead be an ordinary variable of type int.

When discussing pointers and pointer variables, we usually speak of pointing rather than speaking of addresses. When a pointer variable, such as p1, contains the address of a variable, such as v1, the pointer variable is said to point to the variable v1 or to be a pointer to the variable v1.

> There are ways to get a pointer of one type into a pointer variable of another type, but it does not happen automatically and is very poor style anyway.
