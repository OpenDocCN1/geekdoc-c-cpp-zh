# Efficiency of Sets Using Linked Lists

We can analyze the run-time efficiency of our data structure in terms of the fundamental set operations. Adding an item to the set always inserts a new node on the front of the list. This requires only one link on the linked list. The contains iterates through the entire set for the target, which may require examining every node in the list. When we invoke the union function for sets A and B, it iterates through both sets and adds each item into a new set. If there are n items in set A and m items in set B, this requires examining n + m items. However, there is a high cost because the add function searches through its list for any duplicates before a new item is added. This cost becomes significant as the number of items added to the set increases. Finally, the intersection function applied to sets A and B invokes the contains function of B for each item in set A. Since the contains function requires examining up to m nodes for each item in set A, then intersection requires examining at most m nodes. These are inefficient functions.
