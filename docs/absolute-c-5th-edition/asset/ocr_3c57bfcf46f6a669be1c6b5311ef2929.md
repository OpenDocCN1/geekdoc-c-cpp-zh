# Introduction

This chapter covers two topics that have to do with how to organize a C++ program into separate parts. Section 11.1 on separate compilation discusses how a C++ program can be distributed across a number of files so that some parts of the program change only those parts need to be recompiled and so that the separate parts can be easily reused in other applications.

Section 11.2 discusses namespaces, which were introduced briefly in Chapter 1. Namespaces are a way of allowing you to reuse the names of classes, functions, and other items by qualifying the names to indicate different users. Namespaces divide your code into sections so that the different sections reuse the same names with differing meanings. They allow a kind of local naming for names that are more general than local variables.

This chapter can be covered earlier in its location in the book. This chapter does not use any of the material from Chapters 5 (arrays), 9 (strings), 10 (pointers and dynamic arrays) or Section 7.3 (vectors) of Chapter 7.

# 11.1 Separate Compilation

> Your "if" is the only peacemaker; much virtue in "if."

WILLIAM SHAKESPEARE, As You Like It

C++ has facilities for dividing a program into parts that are kept in separate files, compiled separately, and then linked together (or just before) the program is run. You can place the definition for a class (and its associated function definitions) in files that are separate from the programs that use the class. In this way you can build a library of classes so that many programs can use the same class. You can compile the class once and use it in many different programs, like you use the predefined libraries such as header files `iostream` and `cstring`. Moreover, you can define the class itself in two files so that the specification of the class is separate from how the class is implemented. If you only change the implementation of the class, then you only recompile the file containing the class implementation. The other files, including the files containing the programs that use the class, need not be changed or recompiled: This section tells you how to carry out this separate compilation of classes.
