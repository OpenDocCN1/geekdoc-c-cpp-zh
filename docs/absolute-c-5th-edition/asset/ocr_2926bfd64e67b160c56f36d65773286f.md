# The Standard Class string

You cannot use cin and >> to read a blank character. If you want to read one character at a time, you can use cin.get(), which we discussed in Section 9.2. The function cin.get reads values of type char, not type string, but it can be helpful when handling string input. Display 9.5 contains a program that illustrates both getline and cin.get() for string input. The significance of the function newline is explained in the Pitfall called "Mixing >> variable; and getline."

I/O with string Objects
nYou can use the insertion operator << with cout to output string objects. You can input a string with the extraction operator >> and cin. When using >> input, the code reads in a string delimited with whitespace. You can use the function getline to input an entire line of text into a string object.
