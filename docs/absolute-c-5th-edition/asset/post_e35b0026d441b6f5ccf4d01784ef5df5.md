## Identifiers

The name of a variable (or other item you might define in a program) is called an identifier. A C++ identifier must start with either a letter or the underscore symbol, and all of the rest must be letters, digits, or the underscore symbol. For example, the following are all valid:

```
x x1 x1 _abc ABC123z7 sum RATE count2 bigBonus
```

All the names are legal and will be accepted by the compiler, but the first five are poor choices for identifiers because they are not de-identifier's use. None of the following are legal, and all will be rejected by the compiler:

```
12 3X %change data-1 myfirst.c PROG_CPP
```

The first three are not allowed because they do not start with a letter or an underscore. The remaining three are not identifiers because they contain symbols other than letters, digits, and the underscore symbol.

Although it is legal to start an identifier with an underscore, you should avoid doing so, because identifiers starting with an underscore are informally reserved for system identifiers and standard libraries.

C++ is a case-sensitive language: that is, it distinguishes between uppercase and lowercase letters in the spelling of identifiers. Hence, the following three distinct identifiers could be used to name three distinct variables:

```
rate RATE Rate
```

However, it is not a good idea to use two such variants in the same program, since that might be confusing. Although it is not required by C++, variables are usually spelled with their first letter in lowercase. The predefined identifiers, such as main, cin, and out, must be spelled in all lowercase letters. The convention that is now becoming universal in object-oriented programming is to spell variable names with a mix of upper- and lowercase letters (and digits), to always start a variable name with a lowercase letter, and to indicate "word" boundaries with an uppercase letter, as illustrated by the following variable names:

```
topSpeed, bankRate1, bankRate2, timeOfArrival
```

This convention is not common in C++ as in some other object-oriented languages, but is becoming more widely used and is a good convention to follow.

A C++ identifier can be any of length, although some compilers will ignore characters after some (length) specified number of initial characters.

### keyword or reserved word

There is a special class of identifiers, called **keywords** or **reserved words**, which have a predefined meaning in C++ and cannot be used as names for variables or anything else. In the code displays of these keywords are shown in a different color. A complete list of keywords is given in Appendix 1.
Some words, such as `in` and `cout`, are not keywords. These predefined words are not part of the core C++ language, and you are allowed to redefine them. Although these predefined words are not keywords, they are defined in libraries required by the C++ language standard. Needless to say, using a predefined identifier for anything other than its standard meaning can be confusing and dangerous thus should be avoided. The safest and easiest practice is to treat predefined identifiers as if they were keywords.

## Variables

Every variable in a C++ program must be **declared** before it is used. When you **declare** a variable you are telling the compiler—and, the computer—what kind of data you will be storing in the variable. For example, the following are two definitions that might occur in a C++ program:

```cpp
int numberOfBeans;
double oneWeight, totalWeight;
```

The first defines the variable numberOfBeans so that it can hold a value of type int, which is a number. The name int is an abbreviation for "integer". The second declares oneWeight and totalWeight to variables of type double, which is one of the types for numbers with a decimal point (known as **floating-point numbers**). As illustrated here, when there is more than one variable in a declaration, the variables are separated by commas. Note that each declaration ends with a semicolon.
Every variable must be declared before it is used; otherwise, variables may be declared anyplace. Of course, they should be declared in a location that makes the program easier to read. Typically, variables are declared either before they are used or at the start of a block (using an opening brace, {}). Any legal identifier, other than a reserved word, may be used for a variable name.
