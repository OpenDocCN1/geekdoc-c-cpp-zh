# Protected Members

If you use the qualified protector (rather than private or public) before a member of a class, then for any class or function other than a derived class the effect is the same as if the member variable were labeled private. However, in the definition of a member function of a derived class, the variable can be accessed by name. Similarly, if you use the qualified protector before a member function of a class, or function other than a derived class, the effect is the same as if the member variable were labeled private. However, in the definition of a member function of a derived class, the protected function can be used.

Protected members are inherited in the derived class as if they were protected in the derived class. In other words, if a member is marked as protected in a base class, then it can be accessed by name in the definitions of all descendant classes, not just in those classes directly derived from the base class.
