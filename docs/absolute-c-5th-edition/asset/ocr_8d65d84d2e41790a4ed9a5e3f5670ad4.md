# Binary Search Tree Storage Rule

+   1. All the values in the left subtree are less than the value in the root node.
2. All the values in the right subtree are greater than equal to the value in the root node.
3. This rule applies recursively to each of the two subtrees.

(The base case for the recursion is an empty tree, which is always considered to satisfy the rule.)

Note that if a tree satisfies the Binary Search Tree Storage Rule and you output the values using the in-order processing method, the numbers will be output in order from smallest to largest.
For trees that follow the Binary Search Tree Storage Rule that are short and fast rather than long and thin, values can be very quickly retrieved from the tree using a binary search algorithm that is similar in spirit to the binary search algorithm presented in 13.5. The topic of searching and maintaining a binary search tree to realize this efficiency is a large topic that goes beyond what we have here for.

# EXAMPLE: A Tree Template Class

Display 17.36 contains the definition of a template class for a binary search tree. In this example, we have made the SearchTree class friend of the TreeNode class. This allows us to access the node member variables by name in the definitions of the tree class variables. The implementation of SearchTree class is given in 17.37, and a demonstration program is given in 17.38.
This class is designed to give you the flavor of tree processing, but it is not a complete example. A real class would have more functions. In particular, a real tree would have a constructor and an overloaded assignment operator. We have omitted these to conserve space.
There are some things to notice about the definitions in the class SearchTree. The function insert and delete are overloaded. The versions we are not. However, the clearest algorithms are recursive, and the recursive algorithms require one additional parameter for the root of a subtree. Therefore, we defined helping functions with two arguments for each of these functions and implemented the recursive algorithms in the two-parameter function. The single-parameter function simply makes a call to the two-parameter version with the subtree root parameter set equal to the root of the entire tree. A similar situation holds for the overloaded member function name inOrderShow. The function deleteSubtree serves a similar purpose for the destructor function.
