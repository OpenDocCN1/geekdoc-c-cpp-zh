- 19. HTML files use tags enclosed in brackets to denote formatting instructions. For example, <b> and <i> indicates italics. If a web browser is displaying an HTML document that contains < >, it might mistake these symbols for tags. This is a common problem with C++ files, which may contain many & and >. For example, the line #include <iostream> may result in the browser interpreting <iostream> as a tag.

To avoid this, HTML uses symbols to denote < and >. The symbol is created with the &lt; while the > is created with the string &gt;

Write a program that reads a C++ source file and converts all < symbols to &lt and all > symbols to &gt;. Also add the tag <PRE> to the beginning of the file and </PRE> to the end of the file. This preserves whitespace and formatting in the HTML document. Your program should output the HTML file to disk.
