# Introduction

This chapter discusses two types whose values represent strings of characters, such as "Hello". One type is just an array with base char that stores strings of characters in the array and marks the end of the string with the null character, '\0'. This is the older way of representing strings, C++ inherited from the C programming language. These sorts of strings are called *C-strings*. Although C-strings are an older way of representing strings, it is difficult to do any string processing in C++ without least passing contact with C-strings. quoted strings, such as "Hello", are implemented as C-strings in C++.

The ANSI/ISO C++ standard includes a more modern string handling in the form of the class. The *class string* is the second type that we will discuss in this chapter. If the choice between a *C-string* or the *class* string* then the general recommendation is to use the *class string* because it offers greater functionality and checks for error conditions that results in a more secure application. The full *class string* uses templates and is similar to the template classes in the Standard Template Library (STL). Templates are covered in Chapter 16 and the STL is covered in Chapter 19. This chapter covers basic uses of the class string that does not require knowledge of templates.

This material does not require extensive knowledge of arrays, but you should be familiar with array notation, such as [i]. Section 5.1 of Chapter 5 covers more than enough material about arrays to allow you to read the material of this chapter. This material also does not require extensive knowledge of classes. Section 9.1 on C-strings and 9.2 on manipulation can be covered before Chapters 6, 7, and 8, which covers classes. However, before reading Section 9.3 on the standard class *string*, you should read Chapter 6 and the following parts of Chapter 7: Section 7.1 and the subsection of Section 7.2 entitled “The *const* Parameter Modifier” along with its accompanying pitfall section.
