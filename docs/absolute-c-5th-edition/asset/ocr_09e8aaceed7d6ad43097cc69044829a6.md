# Tools for Stream I/O 537

width Output streams have other member functions besides precision and setf. One commonly used formatting width. For example, consider the following call to width made by the stream cout:

```
cout << "Start Now";
cout.width(4);
cout << 7 << endl;
```

This code will cause the line to appear on the screen:

Start Now 7

This output has exactly three spaces between the letter 'w' and the number 7. The width function tells the stream how many spaces to use when giving an item as output. In this case the number 7 occupies only one space and width is set to use four spaces, so three of the spaces are blank. If the output requires more space than you specified in the argument to width, then as much additional space as needed will be used. The entire item is always outted, no matter what argument you give to.

# The class ios

The class ios has a number of important defined constants, such as ios::(used to indicate that you are appending to a file) and the flags listed in Display 12.5. The class ios is defined for output streams, such as <iostream> and <fstream>. One to make the class ios and hence all these constants (all these flags) available to your code is the following:

```
#include <iostream> //or #include <fstream> or both
using std::ios;
```

unset Any flag that is set. To unset a flag, use the function unsetf. For example, the following will cause your program to stop including plus on positive integers that are output to the stream cout:

```
unsetf(ios::showpos);
```

When a flag is set, it remains set until it is unset. The effect of a call to precision stays in effect until precision is reset. However, the member function width behaves. A call to width applies only to the next item that is output. If you want to output 12 numbers, using four spaces to output each number, then you must call to width 12 times.
