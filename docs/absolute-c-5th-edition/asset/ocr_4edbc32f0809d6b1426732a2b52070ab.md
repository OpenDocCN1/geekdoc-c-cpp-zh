# Variables, Expressions, and Assignment Statements

Constants of type char are expressed by placing the character in single quotes,
illustrated in what follows:

```
char symbol = 'Z';
```

Note that the left and right single quote symbols are the same symbol.
Constants for strings of characters are given in double quotes, as illustrated by the
following line from Display 1.1:

```
cout << "How many programming languages have you used?\";"
```

Be sure to ensure that constants are placed inside double quotes, while constants
of char are placed inside single quotes. The two kinds of quotes mean
in particular, 'A' and "A" mean different things. 'A' is a value of type char and
be stored in a variable of type char. "A" is a string of characters. The fact that the
string happens to contain only one character does not make "A" a value of type char.
Also notice that for both strings and characters, the left and right quotes are the same.

Strings in double quotes, like "hello", are also called C-string. A C-string is
ot the same as the string class introduced earlier both are used to store
sequences of text and we sometimes use the two interchangeably. The difference is
explained in detail in Chapter 9. Experts recommend you use the string class
instead of a C-string for purposes of security and flexibility.

The bool has two constants, true and false. These two constants may
assigned to a variable of type bool or use anyplace an expression of type bool
alallowed. They must be spelled with all lowercase letters.

# Escape Sequences

A backslash, \ preceding a character tells the compiler that the sequence following
is not have the same name as the character appearing itself. The sequence is
called an escape sequence consists of two characters with
no space between the symbols. Several escape sequences are defined in C++

If you want to put a backslash, \/ or a quote symbol, \* in a string constant, you
escape the backslash of \" to terminate a string constant using \" or the ability of
to escape \, using \\. The \\ tells the compiler you a real backslash, \-
escape sequence; the \" tells you a real quote, not the end of a string constant.

A stray, say \z in a string constant will have different effects on different
characters. One compiler may make a z; another might produce an error.
The ANSI/ISO standard states that specified escape sequences have undefined
behavior. This means a compiler can do anything it finds convenient.
The consequence is that code uses undefined escape sequences is not portable.
You should not use escape sequences other than those provided by the C++ standard.
These C++ control characters are listed in Display 1.3.
