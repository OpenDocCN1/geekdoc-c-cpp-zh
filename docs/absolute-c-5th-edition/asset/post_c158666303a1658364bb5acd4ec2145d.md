# File Names as Input

Thus, we have written the literal file names for our input and output files into the code of our programs. We did this by giving the file name as the argument to a call to the istream.open in the following example:

```cpp
istream.open("infile.txt");
```

You can instead read the file name from the keyboard, as illustrated by the following:

```cpp
char fileName[16];
istream inStream;
```

```cpp
cout << "Enter file name (maximum of 15 characters):\n"
cin >> filename;
instream.open(filename);
```

# as a C-string

Note that your code reads the file name as a C-string. The member function open takes an argument that is a C-string. You cannot use a string as an argument to open, and there is no predefined type cast operator to convert a string object to a C-string. However, as an alternative, you can read the file into a string variable and use the member function c_str() to get the corresponding C-string value. The code would be as follows:

# as a string object

```cpp
string filename;
instream;
```

```cpp
cout << "Enter file name:\n"
getline(cin, filename);
instream.open(filename.c_str());
```

Note when you use a string variable for the file name, there is essentially no limit to the size of the file.

# Formatting Output with Stream Functions

You can control the format of your output to a file or to the screen with commands that determine such details as the number of spaces between items and the number of digits after the decimal point. For example, in Chapter 1 we gave the "magic formula" to use for outputting amounts of money:

```cpp
cout.setf(ios::fixed);
cout.setf(ios::showpoint);
out.precision(2);
```

We are now in a position to explain this and other formulas for formatting output. The first thing to note is that you can use these formatting commands on any output stream. Output streams connected to a file have these member functions as the object cout. If OutputStream is a file stream (of type ofstream), you can use format output in the following way:

```cpp
outStream.setf(ios::fixed);
outStream.setf(ios::showpoint);
outStream.precision(2);
```

To explain this magic formula, we will consider the member functions in reverse order.
