This allows you to omit names that are in the namespace but are not used. That in avoids potential name conflicts. Moreover, it nicely documents which names you use, and it is not as messy as always qualifying a name with notation of the form Space::f.

If your files are structured so that different namespaces are used in different locations, it sometimes be preferable to place your using directives and declarations inside blocks, as the bodies of function definitions, rather than at the start of the file.

To invoke sample outside the namespace S1, you use
S1::sample();

To invoke sample outside the namespace S2 but within namespace S1, you use
S2::sample();

Alternatively, you could use a suitable using directive.
