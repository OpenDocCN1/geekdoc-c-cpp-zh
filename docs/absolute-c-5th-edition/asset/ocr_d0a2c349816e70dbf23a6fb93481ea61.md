The function always returns the nearest number less than (or equal to) the argument. So, floor(2.9) returns 2.0, not 3.0. Fortunately, it is easy to define a function that does true. The function is defined in Display 3.6. The function rounds its argument to the nearest integer. For example, round(2.3) returns 2, and round(2.6) returns 3.

To see that round works correctly, let's look at some examples. Consider round(2.4). The value returned is the following (converted to an int value),

```
floor(2.4 + 0.5)
```

which is floor(2.9), or 2.0. In for any number that is greater than 2.0 and strictly less than 2.5, that number 0.5 will be less than 3.0, and so floor applied to that number plus 0.5 returns 2.0. Thus, round applied to any number that is greater than or equal to 2.0 and strictly less than 2.5 returns 2. (Since the function declaration for round specifies the type for the value returned is int, we have cast the call to the type int).

Now consider numbers greater than equal to 2.5: 2.6. The value returned by the call round(2.6) is the following (converted to an int value),

```
floor(2.6 + 0.5)
```

which is floor(3.1), or 3.0. In for any number that is greater than 2.5 and less or equal to 3.0, that number plus 0.5 will be greater than 3.0. Thus, round called with any number that is greater than 2.5 and less than or equal to 3.0 will return 3.

Thus, round works correctly for all arguments between 2.0 and 3.0. A similar argument applies to all nonnegative numbers. So, round works correctly for all nonnegative arguments.
