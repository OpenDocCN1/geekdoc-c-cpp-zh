# CHAPTER 8 Operator Overloading, Friends, and References

Display 8.4 << as an Operator

means the same as

```
(cout << "I have") << amount << " in my purse.\n";
```

and is evaluated as:

First evaluate (cout << "I have"), which returns cout:
((cout << "I have") << amount) << " in my purse.\n";
The string "I have" is output.

```
(cout << amount) << " in my purse.\n";
```

Then evaluate (cout << amount), which returns cout:

```
(cout << amount) << " in my purse.\n"
The value of amount is output.
```

```
cout << " " in my purse.\n";
```

Then evaluate cout << " " in my purse.\n", which returns cout:

```
cout << " " in my purse.\n"
The string " " in my purse.\
" is output.
```

```
cout;
```

> Once we have overloaded the insertion (output) operator <<, we will no longer need the member function output and delete output from our definition of the class Money. The definition of the overloaded operator << is very similar to the member function output. In outline form, the definition of the overloaded operator is as follows:

```
ostream& operator << (ostream& outputStream, const Money&)
{
    /*This part is the same as the body of
Money::output which is given in Display 8.1 (except that dollars is replaced with amount.dollars
and cents is replaced by amount.cents.)*/

    return outputStream;
}
```
