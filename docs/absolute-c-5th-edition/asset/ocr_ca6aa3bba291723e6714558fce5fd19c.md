# EXAMPLE: Partially Filled Array with Backup

This example presents a derived class of the partially filled array PArrayD that we presented in Chapter 10 (Display 10.10). For reference, we repeat the header file for the base class PArrayD in Display 14.8. We use as much as we discuss the implementation of the base class PArrayD in Display 14.9. Note that we have made one important change to the definition presented in Chapter 10. We have changed the member variables from private to protected. This will allow member functions in the derived class to access the member variables by name.,

We define a derived class PArrayDBak using PArrayD as a base class. An object of the derived class PArrayDBak will have all the member functions of the base class PArrayD and can be used just like an object of the class PArrayD, but it will have the following added feature: There is a member function backup that can make a backup of all the data in the partially filled array; at any later time the programmer can use the member function to restore the partially filled array to the state it was just before the last invocation of backup. If the meaning of these added member functions is not clear, should peek ahead to the sample demonstration program in Display 14.12.

The interface for the derived class PArrayDBak is shown in Display 14.10. The PArrayDBak adds two member variables to hold a backed-up copy of type double* that will point to a dynamic array with the backup version of the (inherited) array, and an integer variable named used to indicate how much of the backed-up array b is filled with. Since there is no need to change the capacity of a PArrayD (or a PArrayDBak), there is no need to back up the capacity value. All the basic functions for handling a partially filled array are inherited unchanged from the base class PArrayD. These functions manipulate the inherited array and the inherited variable used just as they did in the base class PArrayD.

The implementation of the new member functions for the class PArrayDBak is shown in Display 14.11. The constructors of the derived class PArrayDBak rely on the constructors of the base class to set up the regular partially filled array (inherited) member variables a, used, and capacity). Each constructor also creates a new dynamic array of the same size as the array a. This second array is used for backing up the data in a.
