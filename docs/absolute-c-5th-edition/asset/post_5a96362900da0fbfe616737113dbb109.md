## Linked Lists

Lists as those shown in Display 17.1 are called linked lists. A linked list is a list of nodes in which each node has a member variable that points to the next node in the list. The first node in a linked list is called the head, which is why the pointer variable points to the first node is named head. Note that the pointer named head is not itself the head but only points to it. The last node has no special name, but it has a special property: it is NULL as the value of its member pointer. To test whether a node is the last node, you need only test whether the pointer in the node is equal to NULL.

Our goal is to write some basic functions for manipulating linked lists. For variety, and to simplify the notation, we will use a simpler type of data for the nodes than those used in Display 17.2. These nodes will contain only an integer and a pointer. However, we will make our nodes complicated in one sense. We will make them objects of a class, rather than just a simple struct. The node and pointer type definitions that we use as follows:

```
class IntNode {
public:
  IntNode() {}
  IntNode(int data, IntNode* theLink) : data(data), link(theLink) {}
  IntNode* getLink() const { return link; }
  int getData() const { return data; }
void setData(int theData) { data = theData; }
void setLink(IntNode* pointer) { link = pointer; }
private:
    int data;
    IntNode *link;
};
typedef IntNode* Ptr;
```

Note that all the member functions in the class IntNode are simple enough to have inline definitions.

Notice the two-parameter constructor for the class IntNode. It will allow us to create nodes with a specified integer data and with a linked list member. For example, if p1 points to a node n1, the following creates a new node pointed to by p2 such that this node has data 42 and has its link member pointer to n1:

```
IntNodePtr p2 = new IntNode(42, p1);
```

After we define basic functions for creating and manipulating linked lists with this type, we will convert the node and the functions to template versions so they work to store any type of data in nodes.

As a warm-up exercise, let us see how we might construct the start of a linked list with nodes of this type. We first declare a pointer variable, called head, that will point to the head of our linked list:

a one-node linked list

```
IntNodePtr head;
```

To create our first node, we use the operator new to create a new dynamic variable that will become the first node in our linked list:

```
head = new IntNode;
```

We then give values to the member variables of this node:

```
head->setData(3);
head->setLink(NULL);
```

Notice that the pointer member of this node is set to NULL because this node is the last node in the list (as well as the first node in the list). At this stage our linked list looks like this:

That was more than we needed to do. By using the IntNode constructor with two parameters, we can create our one-node linked list much easier. The following is an easier way to obtain the one-node linked list just pictured:

```
head = new IntNode(3, NULL);
```

## CHAPTER 17 Linked Data Structures

As it turns out, we will always create new nodes using the two-argument constructor for IntNode. Many programs would omit the zero-argument constructor so it would be impossible to create a node without specifying values. The one-node list was built ad hoc. To have a larger list, your program must be able to add nodes in a systematic way. We next describe how to insert linked lists.

### Inserting a Node at the Head

In this subsection, we assume our list contains one or more nodes, and we develop a function to add to the head. The function `headInsert` in Display 17.4 is as follows:

```
void headInsert(IntNodePtr& head, int theData);
```

To insert a node into the linked list, you use the new operator and the two-argument constructor. The complete function body is:

```
{
    head = new IntNode(theData, head);
}
```
