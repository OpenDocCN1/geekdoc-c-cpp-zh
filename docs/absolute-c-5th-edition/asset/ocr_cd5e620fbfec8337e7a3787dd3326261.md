9. In the game of craps, a “Pass Line” proceeds as follows. The first roll of the two, six-sided die in a round is called the “come out.” The player immediately wins when the out roll is 7 or 11, and loses when the out roll is 2, 3, or 12. If 4, 5, 6, 8, 9, or 10 are rolled on the come out, that number becomes the “point.” The player keeps rolling the die until 7 or the point is rolled. If the point is rolled first, the player wins the bet. If the player rolls a 7 first, then the player loses.

A program that plays craps using those rules to simulate a game without human input. Instead of asking for a wager, the program should calculate whether the player would win or lose. Create a function that simulates rolling the dice and returns the sum. Add a loop so that the program plays 10,000 games. Add counters that count how many times the player wins, and how many times the player loses. At the end of the 10,000 games, compute the probability of winning, as Wins /(Wins + Losses), and output this value. Over the long run, who is going to win more of craps, you or the house?

10. One to estimate the height of a child is to use the following formula, which uses the height of the parents:

```
H_{male} = (H_{mother} * 13/12 + H_{father})/2
H_{female} = (H_{father} * 12/13 + H_{mother})/2
```

All heights are in inches. Write a function that takes as parameters the gender of the child, height of the mother in inches, and height of the father in inches, and outputs the estimated height of the child in inches. Embed your function in a program that allows you to test the function over and again until telling the program to exit. The user should be able to input the heights in feet and inches, and the program should output the estimated height of the child in feet and inches. Use the integer data type to store the heights.
