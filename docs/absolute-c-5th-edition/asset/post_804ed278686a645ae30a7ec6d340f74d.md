## Chapter Summary

- A node is a struct or class object that has one or more member variables that are pointer variables. These nodes can be connected by their member pointer variables to produce data structures that can grow and shrink in size while your program is running.
- A linked list is a list of nodes in which each node contains a pointer to the next node in the list.
- The end of a linked list (or other linked data structure) is indicated by the pointer member variable equal to NULL.

> Note that you normally have a "less-than-or-equal" relation and a "less-than" relation. These rules apply only to the "less-than" relation. You can actually do with an even weaker notion of ordering as a strict weak ordering, which is defined in Chapter 19, but is more detail than you need for normally encountered orders.

## Answers to Self-Test Exercises

- Nodes in a doubly linked list have two links—one to the previous node in the list and one to the next node. This makes operations as insertion and deletion slightly easier.

- A stack is a first-in/last-out data structure. A queue is a first-in/first-out data structure. Both can be implemented using a linked list.

- A hash table is a data structure that is used to store objects and retrieve them efficiently. A hash function is used to map an object to a value that can be used to index the object.

- Linked lists can be used to implement sets, including common operations such as union, intersection, and set membership.

- An iterator is (typically an object class) that allows you to cycle through items stored in data structure.

- A tree is data structure whose nodes have two (or more) member variables of pointers to other nodes. If a tree satisfies the Binary Search Tree Storage Rule, then a function can be used to rapidly find data in the tree.
