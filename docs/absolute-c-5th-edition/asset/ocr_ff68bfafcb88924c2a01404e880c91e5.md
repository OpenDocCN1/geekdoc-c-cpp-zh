As it turns out, we will always create new nodes using this two-argument constructor for IntNode. Many programs would omit the zero-argument constructor from the definition of IntNode so that it would be impossible to create a node without specifying values for each member variable.

Our one-node list was built in an ad hoc way. To have a larger linked list, your program must be able to add nodes in a systematic way. We next describe one way to insert nodes in a linked list.

# Inserting a Node at the Head of a List

In this subsection we assume that our list already contains one or more nodes, and we develop a function to add another node. The first parameter for the insertion function will be a call-by-reference parameter for a pointer variable points to the head of the linked list—that is, a pointer that points to the first node in the linked list. The other parameter will give the number to be stored in the new node. The function declaration for our insertion function is as follows:

```
void headInsert(IntNode* head, int theData);
```

To insert a node into the linked list, your function will use the new operator and our two-argument constructor for IntNode. The new node will have theData as its link member pointer points to the first node in the linked list (before insertion). The dynamic variable is created as:

```
new IntNode(theData, head);
```

We want the header to point to this new node, so the function body can be

```
{ head = new IntNode(theData, head); }
```

You will want to allow for the possibility that a list contains nothing. For example, a list having nothing insert might not happen because there is nothing to show you. A list with nothing in it is called an empty list. List is named by a pointer that points to the head of the list, but an empty list has no head node. To specify an empty list, use the NULL. If the pointer variable head is supposed to point to the head of a linked list and you want to indicate that the list is empty, set the value of head as follows:

```
head = NULL;
```
