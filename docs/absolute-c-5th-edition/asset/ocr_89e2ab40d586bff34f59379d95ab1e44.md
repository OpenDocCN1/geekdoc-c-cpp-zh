Functions are self-contained units that do not interfere with other functions— or any other code for that matter. To achieve this you often need to give the function variables of its one that are distinct from any other variables that are declared outside the function definition and may have the same names as the variables that belong to the function. These variables that are declared in a function definition are called local variables and are the topic of this section.

# Local Variables

Look back at the program in Display 3.1. It includes a call to the predefined function sqrt. We did not need to know anything about the details of the function definition for sqrt in order to use it. In particular, we did not need to know what variables were declared in the definition of sqrt. A function that you define is no. Variable declarations within a function definition are the same as if they were declarations in a predefined function or in another program. If you declare a variable in a function and then declare another of the same name in the main function of the program (or in some of other function), then these variables are two different entities, though they have the same name. Let's look at an example:

The program in Display 3.8 has two variables named averagePe; one is declared and used in the function definition for estimateOfTotal, and the other is declared and used in the main function of the program. Variable averagePe in the function definition for estimateOfTotal and the variable averagePe in the main are two different variables. It is as if in the function estimateOfTotal was a predefined function. The two variables named averagePe will not interfere with each other nor two variables in completely different programs. When the averagePe is given in the function call to estimateOfTotal, this does not change the value of the variable in the main function that is also named averagePe.

Variables that are declared within the body of a function definition are said to be local to function or to have function as scope. If a variable is local to function, we sometimes call it a local variable, without specifying the function.
