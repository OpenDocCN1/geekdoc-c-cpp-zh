To search [first] through [last] do the following:

With any recursive algorithm, we must ensure that recursion ends rather than producing infinite. If the sought-after is found on the list, then there is no recursive call and the process terminates, but we need some way to detect whether the number is not on the list. On each recursive the value of first is increased or the value of last is decreased. If they ever pass each other and first actually becomes larger than last, we will know that there are no more indices left to check and that the number is not in the array.
