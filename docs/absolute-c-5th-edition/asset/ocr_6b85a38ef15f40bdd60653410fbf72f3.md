The class ostream is the class of all output streams. The streams cout and cerr are of type ostream, but not type of ofstream. In contrast to cout or cerr, an output-file stream is declared to be of type ofstream. The class ofstream of output-file streams is a derived class of the class ostream. ```

    anyOutStream << "Hello";

The first of the following calls "Hello" to the screen; the second writes "Hello" to the file with the external file name afile.txt.

```
ofstream fout;
fout.open("file.txt");
sayHello(cout);
sayHello(fout);
```

Note that an output-file stream is of type ofstream and the metaphor of inheritance and family relationships. Derived classes are often discussed using if D is a derived class of class B, then D is called a child of class B and class B is called a parent of class D. The derived class is said to inherit the member functions of its parent class, for example, every automobile inherits the fact that it has four wheels from the class of all automobiles, and every input-file stream inherits the extractor operator, >>, from the class of all input streams.
