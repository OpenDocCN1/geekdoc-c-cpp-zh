# 12.3 继承层次：预览

一种组织类的有效方法是通过“派生自”关系。当我们说一个类派生自另一个类时，意味着派生类通过另一个类获得了特性。例如，输入文件类派生自所有输入流，增加了 open 和 close 等成员函数。cin 属于所有输入流，但不属于输入文件类，因为 cin 没有名为 open 的成员函数。
