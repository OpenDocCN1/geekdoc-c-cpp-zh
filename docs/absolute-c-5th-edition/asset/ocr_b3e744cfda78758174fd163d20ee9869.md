Does work with absolutely any container? No, quite. It starts with, iterators as arguments, and some containers, such as stack, do not have iterators. To use the find function, the container must have iterators, the elements must be stored in a linear sequence so that the ++ operator moves through the container, and the elements must be comparable using ==. In other words, the container must have forward iterators (or stronger kind of iterators, such as bidirectional iterators).
When presenting generic templates, we will describe the iterator type by using the required kind of iterator as the type parameter name. So, ForwardIterator should be replaced by a type that is for some kind of forward iterator, as the iterator type in a list, vector, or other template class.
