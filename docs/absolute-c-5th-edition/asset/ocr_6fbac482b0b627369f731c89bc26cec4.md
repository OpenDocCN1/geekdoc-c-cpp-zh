# Array Declaration

SYNTAX

```
Type_Name Array_Name[Declared_Size];
```

EXAMPLES

```
int bigArray[100];
double a[3];
double b[5];
char grade[10], oneGrade;
```

Array declaration of the form shown here will Declared_Size index variables, namely, the indexed variables Array_Name[0] through Array_Name[Declared_Size-1]. Each index variable is a variable of type Type_Name.

An array consists of the indexed variables a[0], [1], and a[2], all of type double. The array b consists of the indexed variables b[0], b[1], b[2], and b[3], and all of type double. You can combine array declarations with simple variables, such as the variable oneGrade shown here.

# Arrays in Memory

Before discussing how arrays are represented in a computer's memory, let us first see how a variable, such as a variable of type int or double, is represented in the computer's memory. A computer memory consists of a list of numbered locations called bytes.¹ A simple variable is implemented as a portion of memory consisting of some number of consecutive bytes. The number of bytes is determined by the type of the variable. Thus, a simple variable in memory is described by two pieces of information: an address in memory (giving the location of the first byte for variable) and the type of the variable, which tells how many bytes the memory variable requires. When we speak of the address of a variable, we real what happens to the value (coded as zeros and ones) is placed in those bytes of memory that are assigned to that variable. Similarly, when a variable is given as a (call-by-reference) argument to a function, it is the address of the variable that is actually given to the calling function. Now let us discuss on how arrays are stored in memory.

Array indexed variables are represented in memory the same way as ordinary variables, but with arrays there is a little more to the story. The locations of the various indexed variables are always placed next to one another in memory. For example, consider the following:

```
int a[6];
```

> ¹A byte consists of eight bits, the exact size of a byte is not important to this discussion.
