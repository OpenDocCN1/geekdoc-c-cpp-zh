# Kinds of Iterators

Different containers have different kinds of iterators. Iterators are classified according to the kinds of operations that work on them. Vector iterators are of the most general form; that the operations work with iterators. Thus, we will again use the vector container to illustrate iterators. In this case we use a vector to illustrate the iterator operations of *decrement* and *random access*. Display 19.2 shows another program using a vector object `container` and iterator p.

The decrement operator is used on line 29 of 19.2. As you would expect, $p--$ moves $p$ to the previous location. The decrement operator, `--$, is similar to the increment operator, $++$, which moves the iterator in the opposite direction.

The increment and decrement operators can be used in prefix (++++) or postfix (p++) notation. In changing $p$, the details of the value returned are completely analogous to what happens with the increment and decrement operators on `int` variables. In prefix notation, the first variable is changed and the value is returned. In postfix notation, the value is returned before the variable is changed. We prefer not to use the increment and decrement operators as expressions that return a value; we use them only to change the variable.

The following lines from 19.2 illustrate the fact that vectors have random access to the elements of a vector, such as:

```
char*iterator p = container.begin();
cout << "The third entry is " << container[2] << endl;
cout << "The third entry is " << p[2] << endl;\ncout << "The third entry is " << *(p + 2) << endl;
```

Random access means you can go directly to any particular element in one step. We have already used `container[2]` as a form of random access to a vector. This is simply the square bracket operator that is standard with arrays and vectors. What is new is that you can use square bracket notation with an iterator. The expression $p[2]$ is a way to access the element indexed by 2.

The expressions $p[2]$ and $*(p + 2)$ are completely equivalent. By analogy to pointer arithmetic, $(p + 2)$ names the location two places beyond $p$. Since $p$ is at the first (index 0) location in the previous code, $(p + 2)$ is at the third (index 2) location. The expression $(p + 2)$ returns an iterator. The expression $*(p + 2)$ dereferences it. Of course, you can replace 2 with a different nonnegative integer to obtain a pointer to a different element.
