20. The following code is supposed to compute the total from a list of numbers stored in a string. This is accomplished by putting the string into a stringstream and using the getline function to extract values separated by a comma. Another stringstream object is used to convert the field from a string to a double. However, the code does not quite calculate the correct total. What is wrong?

```
stringstream ssList, ssNum;
string numbers = "1.1, 1.2, 1.3";

double total = 0;
double num;

ssList.clear();
ssList.str(numbers);

string field;
while (getline(ssList, field, ',')) {
  ssNum.str(field);
  ssNum >> num;
  total += num;
}
cout << total << endl;
```
