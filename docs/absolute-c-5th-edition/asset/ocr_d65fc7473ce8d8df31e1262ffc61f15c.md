# Introduction to C++

The C language is peculiar because it is a high-level language with many of the features of a low-level language. C is somewhere in between the two extremes of a very high-level language and a low-level language, and therein lies its strengths and its weaknesses. Like (low-level) assembly language, C programs can directly manipulate the computer's memory. On the other hand, C has the features of a high-level language, which makes it easier to read and write than assembly language. This makes C an excellent choice for writing systems programs, but for other programs (and in some sense for systems programs) C is not as easy to understand as other languages; also, it does not have as automatic checks as other high-level languages.

To overcome these and other shortcomings of C, Bjarne Stroustrup of AT&T Bell Laboratories developed C++ in the early 1980s. Stroustrup designed C to be a better C. Most of C is a subset of C++ and most C programs are also C programs. The reverse is not true; many C++ programs are not not programs.) Unlike C, C++ has facilities for classes and can be used for object-oriented programming.

# C++ and Object-Oriented Programming

Object-oriented programming (OOP) is a currently popular and powerful programming technique. The main characteristics of OOP are encapsulation, inheritance, and polymorphism. Encapsulation is a form of information hiding and abstraction. Polymorphism refers to a way that a single name can have multiple meanings in the context of inheritance. Having made these statements, we must admit that they hold little meaning for readers who have not heard of OOP before. However, we will describe these terms in detail later in this book. C++ accommodates OOP by providing classes, a kind of type combining both data and algorithms. C++ is not what authorities would call a "pure OOP language." C++ tempers its OOP features with concerns for efficiency and what some might call "practicality." This combination has made C++ the most widely used OOP language, although not all of its strictly follows the OOP philosophy.

# The Character of C++

C++ allows it to be used as an object-oriented language. It allows for overloading of functions and operators. (All these terms will be explained eventually, so not to be concerned if you do not fully understand some terms.) C++'s connection to the C language gives it a traditional look over newer object-oriented languages, yet it has more abstraction mechanisms than many currently popular languages. C++ has a template facility that allows for full and direct implementation of algorithm abstraction. C++ templates allow you to code parameters for types. The newest C++ standard, and most C++ compilers, allow multiple namespaces to accommodate more reuse of class and function names.
