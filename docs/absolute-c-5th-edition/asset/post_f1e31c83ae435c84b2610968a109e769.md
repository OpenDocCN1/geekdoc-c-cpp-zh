Once the Date is defined, you can declare and initialize a structure variable called dueDate as follows:

```cpp
Date dueDate = {12, 31, 2012};
```

The initializing values must be given in the order that corresponds to the order of member variables in the structure-type definition. In this example, dueDate.month receives the first initializing value of 12, dueDate.day receives the second value of 31, and dueDate.year receives the third value of 2012.

If there are more initializer values than struct members. If there are fewer initializer values, in order, the provided values are used to initialize data members. Each data member without an initializer is initialized to a zero value of an appropriate type for the variable.

A class is basically a structure with member functions as well as member data. Classes are central to the programming methodology known as object-oriented programming.

# Defining Classes and Member Functions

A class is a type that is similar to a structure type, but a class type normally has member functions as well as member variables. An object is simple, but illustrative, example of a class called DayOfYear is given in Display 6.3. This class has one member function output as well as the two member variables month and day. The term public is an access specifier. It simply means that there are no restrictions on the members that follow. We will discuss public: and its alternatives after going through this example. The type DayOfYear defined in Display 6.3 is a definition for objects whose values are dates, as January 1 or July 4.

The value of a class type is called an object (when speaking loosely, a variable of a class is also called an object). An object has both data members and member functions. When programming with classes, a program is viewed as a collection of interacting objects. The objects can interact because they are capable of actions, namely invocation of member functions. Variables of a class type hold objects as values. Variables of a class type are declared in the same way as variables of the predefined types and in the same way as structure variables.

# Classes

For the moment ignore the word public: shown in Display 6.3. The rest of the definition of the class DayOfYear is much like a structure definition, except that it uses the keyword class instead of and lists the member function as well as the member variables month and day. Notice that the member function output is listed by its declaration (prototype). A class definition contains only the declaration for its members. The definitions for the member functions are usually elsewhere. In C++ class definition, you can intermix the member variables and functions in any way you wish, but the style has a tendency to list the member functions before the member variables.

# Display 6.3 Class with a Member Function (part 1 of 3)

```cpp
//Program to demonstrate a simple example of a class.
//A better version of the class DayOfYear will be given in Display 6.4.
#include <iostream>
using namespace std;
//Normally member variables are private and not public, this is discussed later in this chapter.
class DayOfYear {
public:
    void output (); // Member function declaration
    int month;
    int day;
};
int main() {
    DayOfYear today, birthday;
    cout << "Today's date:\n";
    cout << "Enter month as a number: ";
    cin >> today.month;
    cout << "Enter the day of the month: ";
    cin >> today.day;
    cout << "Enter your birthday:\n";
    cout << "Enter month as a number: ";
    cin >> birthday.month;
    cout << "Enter the day of the month: ";
    cin >> birthday.day;
    cout << "Today's date is ";
    today.output(); // Calls the member function
    cout << endl;
    cout << "Your birthday is ";
    birthday.output();
    cout << endl;
    if (today.month == birthday.month && today.day == birthday.day)
        cout << "Happy Birthday!\n";
}
```

Member variables for an object of a class type are specified using the dot operator in the same way that the dot operator is used to specify member variables of a structure. For example, if today is a variable of the class DayOfYear in Display 6.3, then today.month and today.day are the variables of the object today.

Member functions for classes that you invoke using the dot operator in a way that is similar to how you show a member variable. For example, the program in Display 6.3 declares two objects of type DayOfYear in the following:

```cpp
DayOfYear today, birthday;
```

The member function output is called with the object today as follows:

```cpp
today.output();
```

and the member function output is called with the object birthday as follows:

```cpp
birthday.output();
```

When a function is called, the definition must include the class name because there may be two or more classes that have functions with the same name. In Display 6.3 there is only one class definition, but in other situations you may have many class definitions, and more than one class may have member functions with the same name. The definition for the member function output of the class DayOfYear is shown in part 2 of Display 6.3. The definition is similar to an ordinary function definition except that you must specify the class name in the heading of the function.

The heading of the function for the member function output is as follows:

```cpp
void DayOfYear::output()
```

The operator :: is called the scope resolution operator and serves a purpose similar to that of the dot operator. Both the dot operator and the scope resolution operator are used to tell what member function is a member of. However, the scope resolution operator :: is used with a class name, whereas the dot operator is used with objects.
