# Creating a Namespace

To place some code in a namespace, you simply place it in a namespace grouping of the following form:

```
namespace Name_Space_Name
{
Some_Code
}
```

When you include one of these groupings in your code, you are said to place the names defined in Some_Code into the namespace Name_Space_Name. These names (namely, the definitions of these names) can be made available with the using directive

using namespace Name_Space_Name;

For the example, taken from Display 11.5, a function declaration in the namespace Spac1:

```
namespace Spac1
{
void greeting();
}
```

If you look again at Display 11.5, you see that the definition of the function greeting is also placed in namespace Spac1. That is done with the following additional namespace grouping:

```
namespace Spac1
{
void greeting()
{
cout << "Hello from namespace Spac1.\\n";
}
```

Note that you can have any number of these namespace groupings for a single namespace. In Display 11.5, we used two namespace groupings for namespace Spac1 and other groupings for namespace Spac2.
Every name defined in a namespace is available inside the namespace groupings, but the names can also be made available to code outside the namespace groupings. For example, the function declaration and function definition in the namespace Spac1 can be made available with the using directive

using namespace Spac1

as illustrated in Display 11.5.
