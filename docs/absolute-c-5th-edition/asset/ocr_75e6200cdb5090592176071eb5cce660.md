# C-String Input and Output

C-strings can be output using the insertion operator, <<. In fact, we have already been doing so with quoted strings. You can use a C-string variable in the same way. For example,

```
cout << news << "Wow.\n";
```

where news is a C-string variable.
it is possible to fill a C-string variable using the input operator >>, but there is one thing to keep in mind. As for all other types of data, all whitespace (blanks, tabs, and line breaks) are skipped when C-strings are read this. Moreover, each reading of input stops at the next space or line break. For example, consider the following code:

```
char a[80], b[80];
cout << "Enter some input:\n";ncin >> a >> b;
out << a << b << "END OF OUTPUT\n";
```

When embedded in a complete program, this code produces a dialogue like the following:

+   Enter input:
Do be to you!
DoEND OF OUTPUT

C-string variables a and b each receive only one word of the input: a receives the C-string value "Do" because the input character following Do is a blank; b receives "be" because the input character following be a blank.

If you want your program to read an entire line of input, you can use the extraction operator, >> to read one line at a time. This can be tedious and still will not read the lines in the blank. There is an easier way to read an entire line of input and place the C-string into a C-string variable: use the predefined function getline, which is a member of every input stream (such as cin or a file stream). The function getline has two arguments. The first argument is a C-string variable to receive the input and the second is an integer that is typically the declared size of the C-string variable. The second argument specifies the maximum number of array elements in the C-string variable that getline will be allowed to fill with characters. For example, consider the following code:

```
char a[80];
cout << "Enter some input:\n";ncin.getline(a, 80);
out << a << b << "END OF OUTPUT\n";
```

When embedded in a complete program, this code produces a dialogue like the following:

+   Enter input:
Do be to you!
Do be to you!END OF OUTPUT
