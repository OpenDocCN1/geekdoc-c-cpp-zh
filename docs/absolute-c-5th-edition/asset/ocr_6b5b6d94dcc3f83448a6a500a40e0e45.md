The removePunct function is of interest in that it uses the string member functions subst find. The member function substr a substring of the calling object, given the position and length of the desired substring. The first three lines of removePunct declare variables for the function. The for loop runs through the characters of parameter s at a time and tries to find them in the punct string. To do this, a string that is of s, length 1 at each character position, is extracted. The position of this substring in punct is determined using the find function. If this one-character string is not in the punct string, then the one-character string is concatenated to the nopunct string that is to be returned.
