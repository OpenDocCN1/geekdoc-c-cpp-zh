# defining member functions

The member functions for a class template are defined the same way as member functions for ordinary classes. The only difference is that member function definitions are themselves templates. For example, Display 16.4 shows appropriate definitions for the member function setFirst and getFirst, and for the constructor with two arguments for the template class Pair. Notice that the class name before the scope operator is PairT, and not Pair. However, the constructor name after the scope operator is the simple name Pair without <T>. The name of a class template may be used as the type for a function. For example, the following is a possible function declaration for a function with a parameter of integers:

```
int addUp(const PairInt& thePair);
//Returns the sum of the two integers in thePair.
```

Now that we specified the type—in this case, int—that is filled for the type parameter T. You can use a class template within a function template. For example, rather than defining the specialized function addUp in the given code, so that the function applies to all kinds of numbers:

```
template<class T>
T addUp(const Pair<T>& thePair);
//Precondition: the operator + is defined for values of type T.
//Returns the sum of the two values in thePair.
```

## restrictions on the type parameter

Almost all template class definitions have some restrictions on what types can be reasonably substituted for the type parameter (or parameters). Even a straightforward template class such as Pair does not work well with absolutely all types T. The Pair<T> may not be well unless the assignment operator and copy constructor are defined for the type T, since the assignment operator is used in member functions and since there are member functions with call-by-value parameters of T. If T involves pointers and dynamic variables, T should also have a suitable destructor. However, these requirements might expect a well-behaved class T to have. With other template classes, the requirements on the types that can be substituted for a type parameter may be more restrictive.

# Class Template Syntax

A class template definition and the definitions of its member functions are prefaced with the following:

```
template<class Type_Parameter>
```

The class and member function definitions are then the same as for any ordinary class, except that the Type_Parameter can be used in a place of type.

For example, the following is the beginning of a class template definition:

```
template<class T>
class Pair
{
public:
    Pair( );
    Pair(T firstValue, T secondValue);
```

Member functions and overloaded operators are then defined as function templates. For example, the definition of the two-argument constructor for the preceding sample class template would begin as follows:

```
template<class T>
Pair<T>::Pair(T firstValue, T secondValue)
{
  ...
```

You can specialize a class template by giving a type argument to the class name, as in the following example:

```
Pair<int>
```

The specialized class name, like Pair<int>, can then be used just like any class name. It can be used to declare objects or to specify the type of a formal parameter.

# Type Definitions

You can define a new class type name that has the same meaning as a specialized class template, such as Pair<int>. The syntax for a defined class type name is as follows:

```
typedef Class_Name<Type_Argument> New_Type_Name;
```

For example,

```
typedef Pair<int> PairOfInt;
```

The name PairOfInt can be used to declare objects of type Pair<int>, as in the following example:

```
PairOfInt pair1, pair2;
```

The name PairOfInt can also be used to specify the type of a formal parameter or anywhere else a type name is allowed.

# EXAMPLE: An Array Template Class

In Chapter 10, we defined a class for a partially filled array of doubles (Displays 10.10 and 10.11). In this example, we convert definition to a template class for a partially filled array of any type. The template class PArray has a type parameter T for the base type of the array.

The conversion is routine. We replace double (when it occurs as the base type of the array) with the type parameter T and convert both the class definition and the member function definitions to template form. The template class definition is given in Display 16.5. The member function template definitions are given in Display 16.6.

Note that we have placed the templates in a namespace. Namespaces are used with templates in the same way as are used with simple, nontemplate definitions.

A sample application is given in Display 16.7. Note that we have separated the class template, implementation, and application program into three files. Unfortunately, these files cannot be used for the traditional method of separate compilation. So, we do the best we can by #include-ing the interface and implementation files in the application file. To the compiler, that makes it look everything in one file.
