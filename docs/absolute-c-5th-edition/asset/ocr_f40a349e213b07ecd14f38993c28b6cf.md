# Exception Handling Basics

If something unusual does happen, the way to indicate this is to throw an exception.
So the basic outline, when we add a throw, is as follows:

```
try {
  Code_To_Try
  Possibly_Throw_An_Exception
  More_Code
}
```

The following is an example of a try block with a throw statement included (copied from Display 18.2):

```
try {
  cout << "Enter number of donuts:\\n";n  cin >> donuts;
  cout << "Enter number of glasses of milk:\\n";n  cin >> milk;
  if (milk <= 0)
    throw donuts;
}

dpg = donuts / static_cast<double>(milk);
cout << donuts << " \n"
cout << milk << " glasses of milk.\\n"
cout << "You have " << dpg << " \n"
cout << " " donuts for each glass of milk.\\n";
```

The following statement throws the int value donuts:
throw donuts;

The value thrown (in this case, donuts) is called called an; the execution of of a is called throwing an exception. You can You a value of any type. In this case, an int value is thrown.

### Throw Statement

throw Expression_for_Value_to_Be_Thrown;

When the throw statement is executed, the execution of the try block is stopped. If the try block is followed by a suitable catch block, then flow of control is transferred to the catch block. A throw statement is almost always embedded in a branching statement, such as an if statement. The value can be of any type.

EXAMPLE
if (milk <= 0)
  throw donuts;
