#Naming Constants with the const Modifier

When you initialize a variable inside a declaration, you can mark the variable so that
program is not allowed to change its value. To do this, place the word const in front of the
declaration, as described here:

SYNTAX

```
const Type_Name Variable_Name = Constant;
```

EXAMPLES

```
const int MAX_TRIES = 3;
const double PI = 3.14159;
```

order of operations is the one dictated by the precedence rules. The parentheses make
the expression easier to read and less prone to programmer error. A complete set of
++ precedence rules are given in Appendix 2.

# Integer and Floating-Point Division

When used with one or both operands of type double, the division operator, /
behaves as you might. However, when used with two operands of type int, the
doperator yields the integer part resulting from division. In other words, integer
discards the part after the decimal point. 10/3 is 3 (not 3.3333...), 5/2 is 2
(not 2.5), and 11/3 is 3 (not 3.6666...). Notice that the number is not rounded; the
part after the decimal point is discarded no matter how large it is.

The operator % can be used with operands of type int to recover the information
lose when / to do division with numbers of type int. When used with values
of int, the two operators / and % yield the two numbers produced when
perform the long division algorithm you learned in grade school. For example, 17
divided by 5 yields 3 with a remainder of 2. The / operation yields the number of times
one number "goes into" another. The % operation gives the remainder. For example,
the statements

```
cout << "17 divided by 5 is " << (17 / 5) << "\n";
cout << "with a remainder of " << (17 % 5) << "\n";
```

yielding the following:

```
17 divided by 5 is 3
with a remainder of 2
```

When used with negative values of type int, the result of the operators / and % can
be different for different implementations of C++. Thus, you should use / and % with
int values only when you know that both values are nonnegative.
