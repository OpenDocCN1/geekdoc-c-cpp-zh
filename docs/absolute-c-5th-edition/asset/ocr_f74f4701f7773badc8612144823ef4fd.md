```
template<class T>
int search(const T a[], int numberUsed, T target)
{
    int index = 0;
    bool found = false;
    while ((!found) && (index < numberUsed))
        if (target == a[index])
            found = true;
        else
            index++;
    if (found)
        return index;
    else
        return -1;
}
```

+   6. Function overloading works only for types for which overloading is provided. (Overloading may work for types that automatically convert to some type for which an overloading is provided, but it may not do what you expect.) The template solution will work for any type that is defined at the time of invocation, provided that the template function makes sense for that type.

+   8. a contains: 0 1 2
b contains: 0 100 200
c contains: 0 1 2
After swapping a and b,
and changing b:
a contains: 0 100 200
b contains: 42 1 2
c contains: 42 1 2

Note that before swapValues(a, b); c is an alias (another name) for the array a. After swapValues(a, b); c is an alias for b. Although the values of a and b are in some sense swapped, they are not as simple as you might have hoped. With pointer variables, there can be side effects of using swapValues.

The point illustrated here that the assignment operator is not as well behaved as you might want array pointers and the template swapValues does not work as you might want with variables that are pointers to arrays. The assignment operator does not element-element swapping but merely swaps two pointers. swapValues function used with pointers to arrays simply swaps two pointers. It might be best not to use swapValues with pointers to arrays
