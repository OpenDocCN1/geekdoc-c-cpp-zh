When a program uses different classes and functions written by different programmers there is a possibility that two programmers will use the same name for two different things. A namespace is a collection of name definitions, such as class definitions and variable declarations. A namespace can, be turned on and off so that when some of its names would otherwise conflict with other names, it can be turned off.

# Namespaces and using Directives

We have already used the namespace that is named std. The std namespace contains all the names defined in many of the standard C++ libraries (such as iostream). For example, when you place the following line at a start of a file,

```
#include <iostream>
```

it places all the definitions (for names like cin and count) into the std namespace. Your program does not know about names in the std namespace unless you specify that it is using the std namespace. To make all the definitions in the std namespace available to your code, insert the following using directive:

```
using namespace std;
```

A good way to see why you might want to include this using directive is to think about why you might want to not include it. If you do not include this using directive for the namespace, then you can define cin and count to have some other meaning than their standard. (Perhaps you want to redefine cin and count because you want them to behave a differently from the standard versions.) Their standard is in the std namespace; without the using directive (or something like it), as far as your code is concerned, the only definitions of cin and count are whatever definitions you give them.

Every bit of code you write; if you do not place the code in some specific namespace, the code is known as the global namespace. So for we have not placed any code we wrote in any namespace and so all our code is in the global namespace. The global namespace does not have a using directive because you are always using the global namespace. You could say there is an implicit automatic using directive that says you are using the global namespace.
