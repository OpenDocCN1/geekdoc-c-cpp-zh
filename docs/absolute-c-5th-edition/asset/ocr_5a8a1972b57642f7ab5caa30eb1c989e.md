You use function notation with at, so instead of a[i], you use a.at(i), and the at member function checks to see if i evaluates to an illegal index. If the value of i a.at(i) is an illegal index, you should get a runtime error message telling you that is wrong. In the following code fragment, the attempted access is out of range, yet it will probably not produce an error message, although it is accessing a nonexistent index:

```
string str("Mary");
cout << str.at(6) << endl;
```

The next example, will cause the program to terminate abnormally, so that you know something is wrong:

```
string str("Mary");
cout << str.at(6) << endl;
```

But be warned that some systems give poor error messages when a.at(i) has an illegal index i.
You can change a single character in the string by assigning a char value to the indexed variable, as str[i]. Since the member function returns a reference, this may also be done with the member function. For example, to change the third character in the string object str to 'X', you can use either of the following code fragments:

```
str.at(2)='X';
```
