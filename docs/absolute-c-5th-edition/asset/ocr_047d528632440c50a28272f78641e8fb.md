# Display 19.3 Reverse Iterator

```
// //Program to demonstrate a reverse iterator.
#include <iostream>
#include <vector>
using std::cout;
using std::endl;
using std::vector;

int main() {
    vector<char> container;

    container.push_back('A');
    container.push_back('B');
    container.push_back('C');

    cout << "Forward:\\n";
    for (auto p = container.begin(); p != container.end(); ++p++) {
        cout << *p << " ";
    }
    cout << std::endl;

    cout << "Reverse:\\n";
    vector<char>::reverse_iterator rp;
    for (auto rp = container.rbegin(); rp != container.rend(); ++rp++) {
        cout << *rp << " ";
    }
    cout << std::endl;

    return 0;
}
```

Sample Dialogue

| Forward: |
| A B C |
| Reverse: |
| C B A |

# Other Kinds of Iterators

There are other kinds of iterators, which we will not cover in this book. We will briefly mention two kinds of iterators whose names you may encounter. **Input iterator** is essentially a forward iterator that can be used with input streams. **Output iterator** is essentially a forward iterator that can be used with output streams.
