As in an ordinary array of characters, character positions for objects of type string are indexed starting 0, so that the third character in a string is in index position 2.
9.7 gives a partial list of the member functions of the class string.
in many ways objects of the class string are better behaved than the C-strings were introduced in Section 9.1. In particular, the == operator on objects returns a value that corresponds to our intuitive notion of strings being equal; namely, it returns true if two strings contain the same characters in the same order and returns false otherwise. Similarly, the comparison operators <, >, and >= compare objects using lexicographic ordering. (Lexicographic ordering is alphabetical ordering using the order of symbols given in the ASCII table in Appendix 3. If the strings consist of all letters and are either uppercase or lowercase letters, then for this case lexicographic ordering is the same as everyday alphabetical ordering.).
