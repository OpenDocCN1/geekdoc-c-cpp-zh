# Inline Functions

You can give the complete definition of a member function within the definition of its class. Such definitions are called inline function definitions. These are typically used for short function definitions. Display 7.5 shows the class in Display 7.4 rewritten with a number of inline functions.

Inline functions are more than just a notational variant of the kind we have already seen. The compiler treats an inline function in a special way. The code for an inline function declaration is inserted at location where the function is invoked. This saves the overhead of a function invocation.

All other things being equal, an inline function should be more efficient and hence preferable in the usual way. However, all other things are seldom, if ever equal, Inline functions have the disadvantage of mixing the interface and implementation of an equal and so go against the principle of encapsulation.

It is generally believed that only short function definitions should be defined inline. The inline version can actually be less efficient, because a large piece of code is repeated frequently. Beyond that general rule, you will have to decide for yourself whether to use inline functions.

Any function can be defined to an inline function. To define a nonmember function to be inline, just place the keyword inline before the function declaration and function definition. We will not use, or further discuss, inline nonmember functions in this book.
