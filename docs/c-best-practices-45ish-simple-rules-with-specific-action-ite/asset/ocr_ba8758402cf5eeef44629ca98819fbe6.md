# Exercise: Become familiar with auto deduction.

Ex1: what is the type of val?

```
const int *get();

int main() {
    const auto val = get();
}
```

Ex2: what is the type of val?

```
const int &get();

int main() {
    const auto val = get();
}
```

Ex3: what is the type of val?

```
const int *get();

int main() {
    const auto *val = get();
}
```
