# 37. Prefer Stack Over Heap

Stack objects (locally scoped objects that are not dynamically allocated) are much more optimizer friendly, cache-friendly, and may be entirely eliminated by the optimizer. As Björn Feller has said, “assume any pointer redirection is a cache miss.

In the most simple terms:

OK idea, uses stack and can be optimized.

```
std::string make_string() { return "Hello World"; }
```

Bad idea, uses the heap.

```
std::unique_ptr<std::string> make_string() {
  return std::make_unique<std::string>("Hello World");
}
```

OK idea.

```
void use_string() {
  // This string lives on the stack
  std::string value("Hello World");
}
```
