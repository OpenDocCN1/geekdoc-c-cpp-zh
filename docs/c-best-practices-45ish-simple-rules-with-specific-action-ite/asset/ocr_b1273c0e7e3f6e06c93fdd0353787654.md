Fuzzing and Mutating

You must provide some sort of entry point. The entry point generally takes the form of a function like:

libFuzzer entry point.

```
extern "C" int LLVMFuzzerTestOneInput(const uint8_t *Data, size_t Size);
```

The Data pointer is always valid, and the Size parameter is >=0.
If your library merely parses input files (think libpng) then your job is quite easy:

libFuzzer data being used.

```
extern "C" int LLVMFuzzerTestOneInput(const uint8_t *Data, size_t Size)
{
    parseInput(Data, Size);
}
```

If your functions take data structures instead of input strings, your job is slightly more complicated but doable.

Advanced libFuzzer usage.

```
template<typename Type>
std::pair<const uint8_t *, size_t, Type>
createStruct(const uint8_t *Data, size_t Size)
{
    // we're only allowed to do this with trivial types
    static_assert(std::is_trivial_v<Type>); // default initialize
    Type result{};
    const auto bytesToRead = std::min(sizeof(Type), Size);
    std::memcpy(&result, Data, bytesToRead);
    return {std::next(Data, bytesToRead), bytesToRead, result};
}
```
