Note that you use various Matrix4 static functions to create the component matrices. CreateScale creates a uniform scale matrix, CreateRotationZ creates a rotation matrix about the z-axis, and CreateTranslation creates a translation matrix.

You call ComputeWorldTransform in Actor::Update, both before you update any components and after you call UpdateActor (in case it changes in the interim):
