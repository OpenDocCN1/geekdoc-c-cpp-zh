Here, the x/y coordinates of the top-left corner are (o, o), meaning the rectangle will be at the top left of the screen. You hard-code the width of the rectangle to 1024, corresponding to the width of the window. (It’s generally frowned upon to assume a fixed window size, as is done here, and you’ll remove this assumption in later chapters.) The `thickness` variable is `const int` set to 15, which makes it easy to adjust the thickness of the wall.
