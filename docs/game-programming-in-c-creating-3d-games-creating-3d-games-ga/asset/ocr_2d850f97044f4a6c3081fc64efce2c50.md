Other engines provide exporter plugins for popular modeling programs. The exporter plugin converts the modeling program’s format into a custom format designed for the game runtime’s consumption.

In the spirit of independence, this book uses a custom file format. While a binary file format is more efficient (and what most real games use), for simplicity, this book’s model file format is a JSON (JavaScript Object Notation) text format. This makes it very easy to manually edit a model file and validate that the model file loads properly. You will eventually explore how to use a binary format in Chapter 14, “Level Files and Binary Data.”

Listing 6.3 shows the representation of a cube in the gpmesh file format this book uses. The first entry specifies the version, which currently is 1. The next line specifies the vertex format for the model. Recall that in Chapter 5, “OpenGL,” you used three floats for position and two floats for texture coordinates as the vertex format. The PosNormTex format specified here adds three floats for the vertex normal in between the position and texture coordinates. For now, don’t worry about what a vertex normal is; we revisit this topic in the lighting discussion later in this chapter.
