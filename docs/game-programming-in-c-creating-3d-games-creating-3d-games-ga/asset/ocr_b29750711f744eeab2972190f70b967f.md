# Matrix Multiplication

Much as with scalars, you can multiply two matrices together. Suppose you have the following matrices:

```
A = [ a b ]   B = [ e f ]
    [ c d ]       [ g h ]

A = [ a b ] B = [ e f ]
    [ c d ]     [ g h ]
```

The result of the multiplication C = AB is:

```
C = AB = [ a b ] [ e f ] = [ a·e+b·g  a·f+b·h ]
         [ c d ] [ g h ]   [ c·e+d·g  c·f+d·h ]

C = AB
= [ a b ] [ e f ] = [ a·e+b·g  a·f+b·h ]
  [ c d ] [ g h ]   [ c·e+d·g  c·f+d·h ]
```

In other words, the top-left element of C is the dot product of the first row of A with the first column of B.

Matrix multiplication does not require matrices to have identical dimensions, but the number of columns in the left matrix must be equal to the number of rows in the right matrix. For instance, the following multiplication is also valid:

```
[ a b ] [ c d ] = [ a·c+b·e  a·d+b·f ]
        [ e f ]

[ a b ] [ c d ] = [ a·c+b·e  a·d+b·f ]
        [ e f ]
```
