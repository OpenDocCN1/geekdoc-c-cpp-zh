Figure 3.5 Vector addition

Note that the order of the addition\ doesn't change the result. This is because vector addition is commutative, just like addition between two real numbers:

\(\vec{a} + \vec{b} = \vec{b} + \vec{a}\)

You can use vector addition in a variety of ways. For example, suppose the player is at point \(p\), and the player's forward vector is \(\vec{f}\). The point that is 150 units “in front” of the player is then \(\vec{p} + 150 \cdot \vec{f}\).

In the provided `Math.h` library, the `+` operator adds two vectors:

```
Vector2 a, b;
Vector2 result = a + b;
```
