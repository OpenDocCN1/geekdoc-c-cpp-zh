# Loading/Unloading Banks

Loading a bank minimally requires calling the loadBank function on the mSystem object. However, this does not load the sample data and does not give easy access to the event descriptions. It makes sense to create a new function in AudioSystem called LoadBank, as shown in Listing 7.2, that does a bit more than the minimum loadBank call. Once the bank loads, you add the bank to the mBanks map. You then load the sample data for the bank. Then use getEventCount and getEventList to get the list of all event descriptions in the bank.
