Because the order of multiplication of quaternions often confuses game programmers (for example, to rotate p followed by q, you multiply q by p), instead of using the multiplication operator, the Math.h library declares a Concatenate function. This function simply takes in the quaternions in the order many expect—so the rotation “p followed by q” is as follows:

```
Quaternion result = Quaternion::Concatenate(q, p);
```
