To solve for t, you need some method to extract it from inside the length operation. To do this, you square both sides of the equation and replace the length squared operation with a dot product:

```
||X + Yt||^2 = r^2
(X + Yt) · (X + Yt) = r^2
```

Because the dot product is distributive over vector addition, you can apply the FOIL (first, outside, inside, last) distribution rule:

```
(X + Yt) · (X + Yt) = r^2
X · X + 2X · Yt + Y · Yt^2 = r^2
```

```
(X + Yt) · (X + Yt) = r^2

```

You then rewrite this in the quadratic form:

```
Y · Yt^2 + 2X · Yt + X · X - r^2 = 0
a = Y · Y
b = 2X · Y
c = X · X - r^2
```
