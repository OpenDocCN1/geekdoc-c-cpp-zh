The final step is to add a function to Renderer that draws the G-buffer quad using the global lighting shader. You create a new DrawFromGBuffer function, as shown in Listing 13.11. Because the first step in Renderer::Draw is now to draw the scene to the G-buffer, DrawFromGBuffer is now the first code that draws to the default framebuffer. You need to disable depth testing for the quad, as you don’t want it to affect the depth buffer. You then set the G-buffer shader and sprite quad vertices as active and call the SetTexturesActive function to activate all the G-buffer textures. You then use the SetLightUniforms function, created in Chapter 6, to set all the directional light uniforms in the G-buffer shader. Finally, you draw the quad, which invokes your G-buffer fragment shader for every fragment onscreen.
