Now imagine that a mouse AI character starts at some square in the maze (the **start node**) and wants to find the shortest path to a piece of cheese in the maze (the **goal node**). One approach is to first check all squares one move away from the start. If none of these squares contains the cheese, you then check all squares two moves away from the start. Repeat this process until either the cheese is found or there are no valid moves left.
