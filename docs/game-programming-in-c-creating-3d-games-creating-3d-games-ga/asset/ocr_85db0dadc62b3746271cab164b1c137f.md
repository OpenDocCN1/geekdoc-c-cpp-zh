# DEFERRED SHADING

Recall that the Phong lighting implemented in Chapter 6 performs the lighting calculations for each fragment when drawing a mesh. The pseudocode for this type of lighting calculation is as follows:

Click here to view code image

```
foreach Mesh m in Scene
    foreach Pixel p to draw from m
        if p passes depth test
            foreach Light li that effects p
                color = Compute lighting equation(li, p)
```
