```cpp
DynamicArray(const DynamicArray& other)
    : mSize(other.mSize)
    , mArray(nullptr)
{
    // Dynamically allocate my own data
    mArray = new int[mSize];

    // Copy from other's data
    for (int i = 0; i < mSize; i++)
    {
        mArray[i] = other.mArray[i];
    }
}
```
```

Note that the only parameter to the copy constructor is a `const` reference to another instance of the class. The implementation in this case dynamically allocates a new array and then copies over the data from the other `DynamicArray`.
