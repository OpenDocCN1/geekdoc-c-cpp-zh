# The Load Function

The Load function in Listing 5.8 takes in the filenames of both the vertex and fragment shaders and then tries to compile and link these shaders together.

As shown in Listing 5.8, you compile both the vertex and fragment shaders using CompileShader and then save their objects IDs in mVertexShader and mFragShader, respectively. If either of the CompileShader calls fail, Load returns false.
