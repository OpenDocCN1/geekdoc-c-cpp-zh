```
void Ship::UpdateActor(float deltaTime)
{
    mLaserCoolDown -= deltaTime;
}
```

This way, mLaserCoolDown keeps track of the amount of time until the player can fire again. And because ActorInput doesn't create a laser if the timer hasn't run out, you make sure the player can't fire more often than desired. With lasers firing, you can then shoot and destroy asteroids with the previously covered collision code (see Figure 3.15).
