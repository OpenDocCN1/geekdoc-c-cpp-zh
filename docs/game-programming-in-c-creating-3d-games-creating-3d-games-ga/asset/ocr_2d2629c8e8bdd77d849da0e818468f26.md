Recall that a 2D image is just a grid of pixels with different colors. So, once you have a texture coordinate for a specific pixel, you need to convert this UV coordinate to correspond to a specific pixel in the texture. This “pixel in the texture” is a **texture pixel**, or **texel**. The graphics hardware uses a process called **sampling** to select a texel corresponding to a specific UV coordinate.
