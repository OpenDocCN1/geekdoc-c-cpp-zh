[1 3] S(5, 2) = [1 3] [5 0; 0 2]

# Rotation Matrix

A 2D rotation matrix represents a rotation (about the z-axis) by angle θ:

```
R(θ) = [ cosθ  sinθ ]
    [ -sinθ  cosθ ]
```

```
R(θ) = [ cosθ  sinθ ]
    [ -sinθ  cosθ ]
```

So, you can rotate (0,3) by 90° with the following:

```
[0 3] R(90°) = [0 3] [ cos90°  sin90° ]
                       [ -sin90°  cos90° ]
= [0 3] [ 0  1 ]
        [ -1  0 ]
= [-3 0].
```

```
[0 3] R(90°)
= [0 3] [ cos90°  sin90° ]
        [ -sin90°  cos90° ]
= [0 3] [ 0  1 ]
        [ -1  0 ]
= [-3 0].
```
