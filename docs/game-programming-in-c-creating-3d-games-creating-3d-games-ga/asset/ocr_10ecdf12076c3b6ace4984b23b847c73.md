If you take your left hand and pretend that the thumb is up, the index finger is forward, and the middle finger is right, you see that it matches the coordinate system in Figure 6.1 perfectly. # Transform Matrices for 3D

Using 3D coordinates means that the homogenous coordinates are now (x,y,z,w). Recall that you need the w component for translation matrices to work. With 3D coordinates, the translation matrices become 4×4 matrices. This modification is simple for translation and scale.
