```
};
```

Then, you define a `std::vector` of bones that you can fill in based on the skeleton. The root bone sets its parent index to -1, but every other bone has a parent indexing into the array. To simplify later calculations, parents should be at earlier indices in the array than their children bones. For example, because the left hip is a child of spine, it should never be the case that left hip has a lower index than spine.
