looks like this:

```
V_{InCurrentPose}
= V \left( [SpineBind]^{-1} [SpineCurrentPose] \right)
```

Now, suppose that $v$ instead has two bone influences: The spine has a weight of 0.75, and the left hip has a weight of 0.25. To calculate $v$ in the current pose in this case, you need to calculate each bone's current pose vertex position separately and then interpolate between them, using these weights:

```
v_0 = v \left( [SpineBind]^{-1} [SpineCurrentPose] \right)
v_0 = v \left( [HipLBind]^{-1} [HipLCurrentPose] \right)
v_{InCurrentPose} = 0.75 + v_0 + 0.25 \cdot v_1
```

You could similarly extend the calculation for a vertex with four different bone influences.

Some bones, such as the spine, influence hundreds of vertices on the character model. Recalculating the multiplication between the spine's inverse bind pose matrix and the current pose matrix for each of these vertices is redundant. On a single frame, the result of this multiplication will never change. The solution is to create an array of matrices called the **matrix palette**. Each index in this array contains the result of the multiplication between the inverse bind pose matrix and the current pose matrix for the bone with the corresponding index.
