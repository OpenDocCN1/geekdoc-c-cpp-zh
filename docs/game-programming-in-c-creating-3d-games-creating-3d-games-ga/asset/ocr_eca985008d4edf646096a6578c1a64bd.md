Although this book uses OpenGL, there are alternative graphics APIs. For PC and Xbox, the DirectX API dominates. Frank Luna's book covers how to use DirectX 11. Finally, Matt Pharr's text is an excellent overview of a realistic lighting technique called physically based rendering.
