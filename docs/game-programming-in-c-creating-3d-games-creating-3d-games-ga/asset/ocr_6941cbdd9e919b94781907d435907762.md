The `OrbitCamera` class requires the following member variables:

Click here to view code image

```
// Offset from target
Vector3 mOffset;
// Up vector of camera
Vector3 mUp;
// Rotation/sec speed of pitch
float mPitchSpeed;
// Rotation/sec speed of yaw
float mYawSpeed;
```

The pitch speed (mPitchSpeed) and yaw speed (mYawSpeed) simply track the current rotations per second of the camera for each type of rotation. The owning actor can update these speeds as needed, based on the mouse rotation. In addition, the OrbitCamera needs to track the offset of the camera (mOffset), as well as the up vector of the camera (mUp).
