The implementation of `Mesh::Load` is lengthy but not especially interesting. It constructs two temporary vectors: one for all the vertices and one for all the indices. When it's finished reading in all the values through the RapidJSON library, it constructs a `VertexArray` object. To see the full implementation of `Mesh::Load`, open this chapter's game project in the `Chapter06` directory on GitHub.

You also create a map of loaded meshes and a `GetMesh` function in `Game`. As with textures, `GetMesh` determines whether a mesh is already in the map or you need to load it from disk.
