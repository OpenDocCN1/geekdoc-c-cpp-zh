The implementation of `Load` contains the bulk of the `Texture` class code. You first declare a local variable to store the number of channels and then call `SOIL_load_image` to load in the texture:

Click here to view code image

```
int channels = 0;

unsigned char* image = SOIL_load_image(
    fileName.c_str(), // Name of file
    &mWidth, // Stores width
    &mHeight, // Stores height
    &channels, // Stores number of channels
    SOIL_LOAD_AUTO // Type of image file, or auto f
);
```

If SOIL fails to load the image file, `SOIL_load_image` returns `nullptr`. Therefore, you should add a check to make sure the image loaded.

Then you need to determine whether the image is RGB or RGBA. You can assume that this is based on the number of channels (three means RGB, four means RGBA):

```
int format = GL_RGB;
```
