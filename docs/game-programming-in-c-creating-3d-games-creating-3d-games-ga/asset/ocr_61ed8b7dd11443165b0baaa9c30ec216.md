As before, there are a constructor and a destructor as well as `Load` and `Unload`. However, notice that `Load` also takes in a pointer to `Game`. This is so that `Mesh` can access any textures associated with the meshes because the game has a map of the loaded textures.

The member data of `Mesh` contains a vector of texture pointers (one for each texture specified in the gpmesh file), a `VertexArray` pointer (for the vertex/index buffer), and a radius for the object space bounding sphere. This bounding sphere radius computes as the mesh file loads. The radius is simply the distance between the object space origin and the point farthest away from the origin. Computing this on load means that later, any collision components that require an object space radius have access to the data. **Chapter 10**, “Collision Detection,” covers collision in detail.
