# Creating a CircleComponent Subclass

To support collision detection of actors, you can create a CircleComponent and a method to test for intersection between two circle components. You can then add a CircleComponent to any actor that needs collision.

First, declare CircleComponent as a subclass of Component, as in Listing 3.6. The only member data CircleComponent needs is a radius because the center of the circle is simply the position of the owning actor.

# Listing 3.6 CircleComponent Declaration

```
class CircleComponent : public Component
{
public:
CircleComponent(class Actor* owner);
void SetRadius(float radius) { mRadius = radius; }
float GetRadius() const;
const Vector2& GetCenter() const;
private:
```
