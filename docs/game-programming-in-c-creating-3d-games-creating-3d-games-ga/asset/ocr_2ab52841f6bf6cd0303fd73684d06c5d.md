# Oriented Bounding Boxes

An **oriented bounding box (OBB)** does not have the parallel restrictions of an AABB. This means that an OBB maintains the tightness of its bounds, regardless of the rotation of the underlying object, as in **Figure 10.5**. One way to represent an OBB is with a center point, a quaternion for the rotation, and the **extents** (width, height, and depth) of the box:

```
struct OBB
{

Vector3 mCenter;

Quaternion mRotation;

Vector3 mExtents;

};
```
