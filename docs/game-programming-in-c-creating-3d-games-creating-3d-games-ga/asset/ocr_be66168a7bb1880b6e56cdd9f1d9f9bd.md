Even though where you draw a vector doesn’t change its value, it often simplifies solving vector problems to draw the vector such that its start, or tail, is at the origin. You can then think of the arrow part of the vector (the head) as “pointing at” a specific point in space. When drawn in this manner, the position that the vector “points at” has the same components as the vector. For example, if you draw the 2D vector <1, 2> such that it starts at the origin, its head points at (1, 2), as shown in Figure 3.2.
