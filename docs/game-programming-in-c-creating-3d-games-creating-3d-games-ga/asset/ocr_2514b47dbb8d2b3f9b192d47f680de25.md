```
[ a b ]^T = [ a c ]
[ c d ]     [ b d ]
```

If you wanted to switch the equation to transform q using column vectors, you would calculate as follows:

```
q' = R^T R^T q
q' = R^T T^T q
```

The matrices in the remainder of this book assume that you are using row vectors. However, a simple transpose of these matrices converts them to work with column vectors.

Finally, the **identity matrix** is a special type of matrix represented by an uppercase l. An identity matrix always has an equal number of rows and columns. All values in the identity matrix are o, except for the diagonal, which is all 1s. For example, the 3x3 identity matrix is as follows:

```
I_3 = [ 1 0 0 ]
      [ 0 1 0 ]
      [ 0 0 1 ]
```

```
I_3 = [ 1 0 0 ]
      [ 0 1 0 ]
      [ 0 0 1 ]
```

Any arbitrary matrix multiplied by the identity matrix does not change. In other words:

```
MI = M
```
