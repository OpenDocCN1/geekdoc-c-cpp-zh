# Converting from an Angle to a Forward Vector

Recall that the `Actor` class from Chapter 2 has a rotation represented by an angle in radians. This allows you to rotate the way an actor faces. Because the rotations are in 2D for now, the angle directly corresponds to an angle on the unit circle, as in Figure 3.6.

![](bbox=[0.2, 0.33, 0.7, 0.68])

Figure 3.6 Unit circle

The equation of the unit circle in terms of an angle, theta, is:

```
x = cos θ
y = sin θ
```
