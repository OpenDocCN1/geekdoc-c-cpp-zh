The SetIntUniform calls associate each of the three sampler2D uniforms in the fragment shader with a specific texture index. The first SetMatrixUniform call sets the view-projection matrix to be identical to the sprite view-projection matrix (because you're drawing a quad). The second call sets the world transform to scale the quad to the entire screen and invert the y-axis (to solve the inverted y problem, as when drawing the mirror texture to the screen).
