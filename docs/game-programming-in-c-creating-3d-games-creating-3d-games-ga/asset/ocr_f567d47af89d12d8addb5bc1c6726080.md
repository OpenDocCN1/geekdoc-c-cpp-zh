OpenGL provides a default framebuffer object with ID 0, which is the framebuffer that you’ve been drawing up to this point. However, you can also create additional framebuffers and switch to other framebuffers as needed.

For now, you will use a custom framebuffer object for a reaview mirror that you display in the HUD onscreen. First, you must add two new member variables to the Renderer class:

```
// Framebuffer object for the mirror

// Texture for the mirror
class Texture* mMirrorTexture;
```

You store the ID of the framebuffer object you create in mMirrorBuffer and the texture object associated with the framebuffer in mMirrorTexture.
