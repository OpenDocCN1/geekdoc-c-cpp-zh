L(t) = Start + (End - Start)t where 0 \le t \ge 1

For convenience, you can add a member function to LineSegment that returns a point on the line segment given a t value:

![](bbox=[0.156, 0.252, 0.425, 0.268])

```
Vector3 LineSegment::PointOnSegment(float t) const
{
    return mStart + (mEnd - mStart) * t;
}
```

The parametric representation of a line segment easily expands to define a ray or a line. A ray follows the above equation, but the bounds for t are as follows:

0 \le t \le \infty
0 \le t \le \infty

Similarly, a line has an unbounded t:

-\infty \le t \le \infty
-\infty \le t \ge \infty
