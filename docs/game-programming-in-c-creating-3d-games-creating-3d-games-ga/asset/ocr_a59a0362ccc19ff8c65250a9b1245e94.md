The world transform matrix for SpriteComponent is a little more complex. The actor's world transform matrix describes the position, scale, and orientation of the actor in the game world. However, for a sprite, you also want to scale the size of the rectangle based on the size of the texture. For example, if an actor has a scale of 1.0f, but the texture image corresponding to its sprite is 128x128, you need to scale up the unit square to 128x128.
