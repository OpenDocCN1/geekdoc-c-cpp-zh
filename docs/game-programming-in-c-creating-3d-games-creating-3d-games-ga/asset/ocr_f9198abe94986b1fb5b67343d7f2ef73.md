Next, construct an instance of an FMOD Studio system with this code:

```
FMOD_RESULT result;

result = FMOD::Studio::System::create(&mSystem);

if (result != FMOD_OK)
{
    SDL_Log("Failed to create FMOD system: %s",
        FMOD_ErrorString(result));

    return false;
}
```

Note that the function call returns an `FMOD_RESULT`. An FMOD function always returns a result value to let the caller know if everything went okay. The `FMOD_ErrorString` function converts the error code into a human-readable message. In this case, if the system fails to create, `AudioSystem::Initialize` returns `false`.
