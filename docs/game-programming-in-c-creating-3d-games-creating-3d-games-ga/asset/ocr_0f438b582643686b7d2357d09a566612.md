One way to compute an AABB after rotation is to first construct the eight points representing the corners of the AABB. These points are simply all possible permutations of the min and max x, y, and z components. Then you rotate each point individually and use the UpdateMinMax function to create a new AABB from these rotated points. Note that this process, shown in Listing 10.3, does not compute the minimal possible AABB of the underlying object after rotation. Thus, the game should save the original object space AABB to avoid error propagation after multiple rotations.
