velocity and position on every frame.

Finally, collision detection is how a game decides if two objects touch each other. For some types of games, such as this chapter's game project, you can use circles to represent the collisions of objects. Two circles are considered to intersect if the distance between their centers is less than the sum of their radii. As an optimization, you can square both sides of this equation.

# ADDITIONAL READING

Eric Lengyel provides an in-depth look at all the different mathematical concepts used in 3D game programming. Aspiring graphics programmers especially should review the more advanced material in his book.
