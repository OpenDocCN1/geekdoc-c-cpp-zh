# CHAPTER 6

# 3D GRAPHICS

This chapter covers how to switch from a 2D environment to a full 3D game, which requires several changes. The `Actor` transform, including 3D rotations, becomes more complex. In addition, you need to load and draw 3D models. Finally, most 3D games have some type of lighting applied to the scene. The game project for this chapter demonstrates all these 3D techniques.
