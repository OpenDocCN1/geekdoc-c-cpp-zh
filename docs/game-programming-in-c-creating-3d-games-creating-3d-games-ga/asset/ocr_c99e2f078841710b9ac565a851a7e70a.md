Of course, a model file format isn't particularly useful if there's no way to create a model of that format in a modeling program. To solve this, the GitHub code repository provides two exporters in the `Exporter` directory. One is an export script for the Blender modeling program, and it supports the basic style of mesh used throughout most of this book. The other is an exporter plug-in for Epic Unreal Engine, which can export not only meshes but also the animation data used in Chapter 12, “Skeletal Animation.” The code for these exporters is very specific to Blender and Unreal, respectively, so we omit the discussion here. However, interested readers can peruse the code in the repository. Each exporter also includes a text file with instructions on how to use each exporter with its respective program.
