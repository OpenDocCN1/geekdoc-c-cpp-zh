# GAME PROJECT

This chapter's game project implements the full _Pong_ game code constructed throughout the chapter. To control the paddle, the player uses the `W` and `S` keys. The game ends when the ball moves offscreen. The code is available in the book's GitHub repository in the `Chapter01` directory. Open `Chapter01-windows.sln` in Windows and `Chapter01-mac.xcodeproj` on Mac. (For instructions on how to access the GitHub repository, consult the instructions at the beginning of this chapter.)
