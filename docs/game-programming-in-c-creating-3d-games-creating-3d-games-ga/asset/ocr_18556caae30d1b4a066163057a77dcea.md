For now, you will only use a value of 1 for the w component. For example, you can represent the point p= (x,y) with the homogeneous coordinate (x,y,1). To understand how homogeneous coordinates work, suppose you wish to translate the point (1,3) by (20,15). First, you represent the point as a homogeneous coordinate with a w component of 1 and then you multiply the point by the translation matrix:

```
[ 1 3 1 ] T(20,15) = [ 1 3 1 ] [ 1 0 0 ; 0 1 0 ; 20 15 1 ]
= [ 1*1+3*0+1*20   1*0+3*1+1*15   1*0+3*0+1*1 ]
= [ 21 18 1 ]
```

```
[ 1 3 1 ]
T(20,15)
= [ 1 3 1 ] [ 1 0 0 ; 0 1 0 ; 20 15 1 ]
=
[ 1*1 + 3*0 + 1*20   1*0 + 3*1 + 1*15   1*0 + 3*0 + 1*1 ]
= [ 21 18 1 ]
```
