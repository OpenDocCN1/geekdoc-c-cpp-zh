The MatrixMultiplicationExample, located in the javagames.transform package and shown in Figure 3.9, demonstrates using matrices to concatenate transformation operations on objects. The reason the matrix is such a powerful tool is because operations such as transformations and rotations can be stored into a single matrix and then applied to objects all at once. Although it is not necessary for a single object, if hundreds or thousands of polygons need to be transformed, the savings can really add up.

> **Tip**
> Just for fun, this example also creates some random stars that can be toggled on or off using the “space” bar (get it?).
