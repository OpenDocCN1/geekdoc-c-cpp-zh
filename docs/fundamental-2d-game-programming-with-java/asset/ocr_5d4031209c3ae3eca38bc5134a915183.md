The first thing to notice about the SimpleFramework class, located in the javagames.util package, is all the properties. Although there could be methods to access each individual property, it is easier to just use the default values or change them in the constructor. Since all the properties start with app, using code completion in a code editor will bring up a list of available properties. See Figure 5.1.
