The example displays a lot of information about the font. These values are also listed at the bottom of the application. Notice that some of the font values are negative. The negative values are added to the baseline, not subtracted.

```
package javagames.text;

import java.awt.*;
import java.awt.font.*;
import java.awt.geom.Rectangle2D;
import java.util.ArrayList;
import javagames.util.*;

public class TextMetricsExample extends SimpleFramework {
    public TextMetricsExample() {
        appWidth = 640;
        appHeight = 480;
        appSleep = 10L;
        appTitle = "Text Metrics Example";
    }
}

@Override
protected void initialize() {
    super.initialize();
}
}
```
