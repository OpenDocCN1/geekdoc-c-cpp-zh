The getRandomAsteroid() method creates a random position and then chooses a random size: small, medium, or large. Remember that each method of the factory chooses from one of the three different polygon models for each size and produces four mirrored versions of each model. With four mirrors per polygon, three shapes per size, and three sized, that's 36 different models.

Also notice that because the PrototypeAsteroid uses the new Utility.fillPolygon() method, the Graphics object is cast to a Graphics2D object.
