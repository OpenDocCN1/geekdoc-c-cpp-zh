# THE STATECONTROLLER CLASS

The StateController class is the key class in the entire game. This class handles the transition from one state to another, passes all the game loop calls to the current state, and contains a map of game objects referenced by name. This is a very simple way to pass resources around, and new objects can be added and retrieved without adding any extra methods to the controller. As long as a class knows the name of the resource and the type of the object, that object can be accessed.
