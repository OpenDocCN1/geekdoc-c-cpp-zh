To keep points that start out touching or almost touching the polygon from getting stuck, they have to be ignored. But this causes another problem. If the new position is almost touching the polygon, it will not intersect the polygon until the next frame, but at that point, since it is so close, it will be ignored, so it does not get stuck. This causes the point, if it stops right before the polygon line, to pass right through it.

```
if end-point really close to the line
    collision has occurred
else if start-point really close to the line
    ignore it, or it will get stuck
```

This pseudocode describes the checks needed to keep the point from sticking to or passing through the polygon line.
