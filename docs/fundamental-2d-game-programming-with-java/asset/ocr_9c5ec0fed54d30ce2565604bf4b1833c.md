To find the intersection point, one of the properties of the dot product is used.

$A * B^{\perp} = 0$

Recall that the dot product of two perpendicular vectors is always zero. This equation is used as a starting point. The parametric line equation is plugged into this equation, which allows the t value to be found. See Figure 15.18.
