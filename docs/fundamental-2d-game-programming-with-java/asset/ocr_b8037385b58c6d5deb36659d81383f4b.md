If the direction vector for the parametric line equation is normalized, as shown in Figure 15.5, then the distance from the point o to the point p occurs when the t value is equal to the length from 0 to p. If, however, the vector used is not normalized, and instead is formed by just subtracting the two line end points, as shown on the right, the line will go from point 0 to point p when the t value is equal to 1.0.
