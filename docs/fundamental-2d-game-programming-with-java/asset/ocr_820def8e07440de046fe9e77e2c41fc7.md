Notice that the createReverseViewport() translates and scales instead of scaling and translating, performing the reverse of the viewport transformation. This can been used to convert the mouse screen coordinates into world coordinates.

getViewportTransform() and getReverseViewportTransform() have been added as utility methods, using the canvas size and the world size to create the transformation matrices. getWorldMousePosition() is used to transform the screen coordinates into world coordinates. The getRelativeWorldMousePosition() method is used when the mouse is set to return relative positions.

protected Vector2f getWorldMousePosition() {

    Vector2f screenPos = new Vector2f( mousePos.x, mousePos.y );
    return screenToWorld.mul( screenPos );
