# INPUT

As you can see in Figure 2.1, input is very important to video games. It is the reason games are not the same as movies, and it is the topic of this chapter. Although many people place more effort on looks, no matter how spectacular a game looks, if the controls are jumpy, awkward, or difficult, the players can get very frustrated.
