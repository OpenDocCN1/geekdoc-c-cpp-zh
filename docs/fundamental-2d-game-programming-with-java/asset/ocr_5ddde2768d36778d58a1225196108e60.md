**Tip**

Most of the time, you never have to worry about cleaning up memory in Java, but the Graphics2D object created from a BufferedImage.createGraphics() method is the exception. Make sure to always call dispose() when you are finished or memory can quickly disappear.

The render() method draws the usual help text and draws the created image. The file information is displayed when the file has been loaded. The createFile() method generates a new image with random colors and saves it to the hard drive in the given format. The loadFile() method attempts to load an already saved file from the hard drive. If the file isn't available, the loaded file is set to null. The processInput() method uses the 1–4 number keys to save files and the 5–8 number keys to load files from the hard drive.
