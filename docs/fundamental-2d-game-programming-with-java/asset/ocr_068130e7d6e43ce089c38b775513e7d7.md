# CREATING AN ACTIVE RENDERED WINDOW

The rendering code can be moved from the event dispatch thread to the custom game thread by using active rendering. The Window class and the Canvas class are the two classes available to allow the creation of a BufferStrategy. By adding the canvas, you can access the buffer strategy and force the size of the canvas to exactly the size required, just like the JPanel example in the Hello World application.
