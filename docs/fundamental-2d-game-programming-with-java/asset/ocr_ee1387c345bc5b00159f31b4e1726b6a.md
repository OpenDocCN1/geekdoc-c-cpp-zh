# PERFORMING COLOR INTERPOLATION

Color interpolation is blending from one color to another. The first part of the process is linear interpolation, and because the equation is a straight line, the math is not complicated. This example involves many interesting concepts. You can apply the math behind the color blending to any values that need to be interpolated over a distance. The techniques used to capture the individual pixel values enable you to perform custom image manipulation. Plus, it is always fun to learn how to perform an image effect by hand instead of relying on hidden algorithms.
