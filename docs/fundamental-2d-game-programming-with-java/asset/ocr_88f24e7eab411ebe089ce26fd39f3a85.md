The File class can represent a file or a directory. There are many ways to create a file:

+   - File(URI uri)
+   - File(String pathname)
+   - File(String parent, String child)
+   - File(File parent, String child)

Most of the methods in the File class are self-explanatory, and since all you need to do at this point is introduce ourselves, walking a file tree is a good example. See Figure 9.1.

The FilesAndDirectories example, located in the javagames.filesandres package, walks a directory on the hard drive and displays information for each file and folder. The main() method invokes the runTest() method, which contains the code to walk the file tree. The runTest() method starts by creating a new file object for each folder on the hard drive and then calling the displayInfo() method, which prints the information about the file to the console, recursively walking the remaining files.

The following methods are used to gather the information about each file:

+   - canExecute()—Whether the file is executable
+   - canRead()—Whether the file is readable
+   - canWrite()—Whether the file is writable
+   - isHidden()—If it’s a hidden file
+   - isDirectory()—True if it’s a directory, false if it’s a file
