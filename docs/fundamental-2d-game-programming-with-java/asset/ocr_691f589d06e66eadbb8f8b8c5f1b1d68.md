# THE COMPLETEGAME CLASS

The CompleteGame class is the extension of the GameFramework. This is the class that is launched when the game is first started. However, there isn’t much for this class to do, because all of the game items are loaded during the loading screen. The application’s properties are set with the GameConstants and the StateController is created. Various items are created and added as named attributes in the controller. The processInput(), updateObjects(), and render() methods pass control to the controller, and other than shutting down the sound threads, this class does little else.
