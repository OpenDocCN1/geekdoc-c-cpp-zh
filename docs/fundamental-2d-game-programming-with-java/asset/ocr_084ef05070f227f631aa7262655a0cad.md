Notice the Java magic in the `updateObject()` method. If the collection of bullets tries to remove the bullet while iterating through it, then the list will throw a `ConcurrentModificationException`. By making a copy of the list and removing it from the original, the exception is not thrown.

```
```java
// FlyingShipExample.java
protected void updateObjects( float delta ) {
    super.updateObjects( delta );

    ship.update( delta );

    ArrayList<PrototypeBullet> copy =
        new ArrayList<PrototypeBullet>( bullets );
    for( PrototypeBullet bullet : copy ) {
        bullet.update( delta );
        if( wrapper.hasLeftWorld( bullet.getPosition() ) ) {
            bullets.remove( bullet );
        }
    }
}
