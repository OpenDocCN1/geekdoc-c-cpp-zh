# 62. Write a program that prints all even numbers from 1 to 100 using a while loop without using any if statement.

```
#include <iostream>

int main() {
    int i = 2;

    while (i <= 100) {
        std::cout << i << "";
        i += 2; // Increment by 2 to get the next even number
    }

    return 0;
}
```
