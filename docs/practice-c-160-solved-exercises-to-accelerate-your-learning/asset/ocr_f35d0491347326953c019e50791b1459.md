# 74. Write a program that calculates and displays the sum of even numbers from 1 to 100 using a repeating loop.

```
#include <iostream>

int main() {
  int sum = 0;

  for (int i = 2;i <= 100;i += 2) {
    sum += i;
  }

  std::cout << "The sum of even numbers from 1 to 100 is:" << sum << std::endl;

  return 0;
```
