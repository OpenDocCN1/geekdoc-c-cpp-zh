# Repeat Loops

56. Write a program that displays the numbers 1 through 10 using a while loop.

```
#include <iostream>

int main() {
    int i = 1; // Initialize counter to 1

    while (i <= 10) {
        std::cout << i << std::endl;
        i++; // Increment the counter
    }

    return 0;
}
```
