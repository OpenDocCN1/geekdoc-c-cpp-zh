# 78. Write a program that prompts the user
for a number and displays its divisors.

```
#include <iostream>

int main() {
    int num;

    std::cout << "Enter a number: ";
    std::cin >> num;

    std::cout << "Divisors of " << num << " are: ";

    for (int i = 1; i <= num; i++) {
        if (num % i == 0) {
            std::cout << i << "";
        }
    }
}
```
