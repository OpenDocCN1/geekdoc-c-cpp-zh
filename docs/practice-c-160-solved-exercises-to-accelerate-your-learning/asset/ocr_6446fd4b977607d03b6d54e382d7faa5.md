# 61. Write a program that prints all even numbers from 1 to 100 using a while loop and an if statement inside the loop to check if the number is even or not.

```
#include <iostream>

int main() {
    int i = 1;

    while (i <= 100) {
        if (i % 2 == 0) { // Check if the number is even
            std::cout << i << " ";
        }
        i++;
    }

    return 0;
}
```
