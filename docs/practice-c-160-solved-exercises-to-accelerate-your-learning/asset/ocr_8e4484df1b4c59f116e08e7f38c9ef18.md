# Recursive Functions

136. Write a recursive function to calculate the factorial of a number.

```
#include <iostream>

long long factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

int main() {
    int num;
    std::cout << "Enter a number:";
    std::cin >> num;
    std::cout << "Factorial of " << num << " is " << factorial(num) << std::endl;

    return 0;
}
```
