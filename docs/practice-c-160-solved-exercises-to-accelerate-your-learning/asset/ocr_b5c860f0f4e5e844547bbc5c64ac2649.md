# 7. Make a program that asks for the
user's name, and prints the name on
the screen immediately after.

```
#include <iostream>
#include <string>

int main() {
    std::string name;

    std::cout << "Please enter your name: ";
    std::getline(std::cin, name);
    std::cout << "Hello, " << name << "!" << std::endl;

    return 0;
}
```
