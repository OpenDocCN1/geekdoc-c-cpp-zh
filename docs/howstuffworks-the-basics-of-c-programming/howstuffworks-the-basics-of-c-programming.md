
# C 语言编程基础指南

C 语言是一种用于创建计算机程序的流行且广泛使用的编程语言。程序员青睐 C 语言是因为它为程序员提供了最大的控制权和效率。

如果你是一名程序员，或者你对成为程序员感兴趣，学习 C 语言可以带来几个好处：

- 你将能够为许多平台读取和编写代码——从微控制器到最先进的科学系统，都可以用 C 编写。
- 考虑到 C 的性能和可移植性，几乎所有流行的跨平台编程语言和脚本语言（如 `C++`、`Java`、`Python`、`Objective-C`、`Perl`、`Ruby`、`PHP`、`Lua` 和 `Bash`）都是用 C 实现的，并大量借鉴了 C 的语法和函数。它们共享相似的运算符、表达式、循环语句、控制结构、数组、输入输出以及函数。此外，几乎所有语言都可以与 C 和 C++ 接口，以利用大量的现有 C/C++ 库。

在本文中，我们将贯穿整个语言，并教你如何从开始成为一名 C 程序员。

### 什么是 C？

C 是一种计算机编程语言。这意味着你可以使用 C 为计算机创建一组供其遵循的指令。C 是目前使用的数千种编程语言之一。C 已经存在了几十年，并被广泛接受，因为它为程序员提供了最大的控制和效率。C 是一门容易学习的语言。它的风格比其他某些语言稍微晦涩一点，但你很快就能掌握。

C 是一种所谓的编译型语言。这意味着一旦你写好了程序，就必须通过 C 编译器运行它，将你的程序转换为计算机可以运行（执行）的可执行文件。C 程序是人类可读的形式，而编译器输出的可执行文件是机器可读可执行的格式。这意味着要编写和运行 C 程序，你必须拥有 C 编译器。


### 循环：一个示例

假设你想创建一个程序，打印华氏度到摄氏度的转换表。这可以通过 `for` 循环或 `while` 循环很容易实现：

```c
#include <stdio.h>

int main(void)
{
    int a = 0;
    while (a <= 100)
    {
        printf("%4d degrees F = %4d degrees C\n",
               a, (a - 32) * 5 / 9);
        a = a + 10;
    }
    return 0;
}
```

- `60 degrees F = 15 degrees C`
- `70 degrees F = 21 degrees C`
- `80 degrees F = 26 degrees C`
- `90 degrees F = 32 degrees C`

```c
#include <stdio.h>
```

现在假设我们想修改程序，将温度 98.6 插入表格的正确位置。也就是说，我们希望表格每隔 10 度增加一次，但我们也希望表格中额外包含一行针对 98.6 华氏度的数据，因为这是人体正常体温。以下程序实现了这一目标：

```c
#include <stdio.h>

int main(void)
{
    float a = 0;
    while (a <= 100)
    {
        if (a > 98.6)
        {
          printf("%6.2f degrees F = %6.2f degrees C\n",
              98.6, (98.6 - 32.0) * 5.0 / 9.0);
          printf("%6.2f degrees F = %6.2f degrees C\n",
              a, (a - 32.0) * 5.0 / 9.0);
          a = a + 10;
        }
    }
    return 0;
}
```

这个程序在结束值为 100 时可以工作，但如果你将结束值更改为 200，你会发现程序有一个 bug。它重复打印了多次 98.6 度的那行。我们可以通过不同的方法修复这个问题。这里是其中一种：

```c
#include <stdio.h>

int main(void) {
  float a, b;
  a = 0;
  b = -1;
  while (a <= 100) {
    if ((a > 98.6) && (b < 98.6)) {
      printf("%6.2f degrees F = %6.2f degrees C\n",
          98.6, (98.6 - 32.0) * 5.0 / 9.0);
    }
    printf("%6.2f degrees F = %6.2f degrees C\n",
        a, (a - 32.0) * 5.0 / 9.0);
    a = a + 10;
  }
  return 0;
}
```

## 运算符

## 结构

C 语言中的结构允许你将变量分组为一个包。这里有一个示例：

```c
struct rec
{
    int a, b, c;
    float d, e, f;
}

struct rec r;
```

如所示，每当你想要声明类型为 `rec` 的结构时，必须说 `struct rec`。这一行很容易被忘记，你会得到很多编译器错误，因为你心不在焉地漏掉了 `struct`。你可以将代码压缩为形式：

```c
struct rec
{
```

```c
typedef struct rec rec_type;
```

然后通过说声明类型为 `rec_type` 的记录：

```c
rec_type r;
```

## 库

库在 C 语言中非常重要，因为 C 语言只支持它需要的最基础的功能。C 语言甚至不包含从键盘读取和写入屏幕的 I/O 函数。任何超出基础语言的内容必须由程序员编写。生成的代码块通常放在库中，以便于重复使用。我们已经见过了标准 I/O 即 `stdio` 库。标准库为标准 I/O、数学函数、字符串处理、时间操作等提供了标准支持。你可以在自己的程序中使用库将你的程序拆分成模块。这使得它们更容易被理解、测试和调试，同时也使得复用你编写其他程序的代码成为可能。

## Makefiles

反复输入所有的 `gcc` 命令可能非常麻烦，特别是当你对代码进行大量修改且它有多个库时。`make` 工具解决了这个问题。你可以使用下面的 `makefile` 来替换上面的编译序列：

```
main: main.o util.o
    gcc -o main.o util.o
main.o: main.c util.h
    gcc -c -g main.c
util.o: util.c util.h
    gcc -c -g util.c
```

将此内容输入名为 `makefile` 的文件中，并输入 `make` 来构建可执行文件。注意，你必须在所有 `gcc` 行之前加上一个制表符 `tab`。八个空格是不够的——必须是制表符。所有其他行必须左对齐。

## 指针基础

为了理解指针，将它们与普通变量进行比较会有帮助。

“普通变量”是内存中一个可以存储值的位置。例如，当你声明一个变量 `i` 为整数类型时，系统会为它分配四个字节的内存。在你的程序中，你通过名称 `i` 来引用该内存位置。在机器层级，一个位置有一个内存地址。对于你程序员来说，该地址上的四个字节被命名为 `i`，而这四个字节可以存储一个整数值。

指针是一个指向另一个变量的变量。这意味着指针持有另一个变量的内存地址。换句话说，指针在传统意义上并不持有值；相反，它持有另一个变量的地址。指针通过持有该变量地址的副本来“指向”另一个变量。

由于指针持有的是地址而不是值，因此包含两个部分。指针本身持有地址，而该地址指向一个值。这包含了指针本身和被指向的变量。在你不熟悉它之前，这个事实可能会让你感到困惑，但它会变得极其强大。

## 指针：常见错误

### 错误 #1 - 未初始化的指针

创建指针错误的最简单方法之一是尝试引用指针的值，即使该指针尚未初始化且尚未指向有效的地址。例如：

```c
int *p;
*p = 12;
```

指针 `p` 在你声明它时是未初始化的，并且指向内存中的一个随机位置。它可能指向系统栈、全局变量、程序代码空间或操作系统。当你说 `*p = 12;` 时，程序将简单地尝试向 `p` 指向的任何随机位置写入 12。程序可能会立即崩溃，或者等待半小时后才崩溃，也可能会损坏程序中其他部分的数据，而你可能永远无法察觉。这使得这种错误非常难以追踪。在解引用指针之前，请确保将指针初始化为有效地址。

### 错误 #2 - 无效的指针引用

当引用指针的值，但该指针并没有指向有效的内存块时，就会发生无效的指针引用。

创建此错误的一种方法是在 `q` 未初始化时说 `p = q;`。此时，指针 `p` 也会变成未初始化状态，对 `*p` 的任何引用都是无效的指针引用。

避免此问题的唯一方法是为程序的每一步画图，并确保所有指针都指向某个地方。无效的指针引用会导致程序由于错误 #1 中提到的相同原因莫名其妙的崩溃。

### 错误 #3 - 零指针引用

当指向 0 的指针被用于尝试引用内存块的语句时，就会发生零指针引用。例如，如果 `p` 是指向整数的指针，以下代码是无效的：

```c
p = 0;
*p = 12;
```

`p` 没有指向任何内存块。因此，尝试对该块进行任何读取或写入都是无效的指针引用。正如我们将在随后的文章中看到的，将指针指向 0 有充分且合法的理由。然而，解引用这样的指针是无效的。

所有这些错误对于包含它们的程序来说都是致命的。你必须监控你的代码，以防止这些错误的发生。做到点的最好方法是逐步绘制代码执行执行图。

要理解可变参数是如何工作的，让我们看看如何在 C 中实现一个 `swap`（交换）函数。要实现一个 `swap` 函数，你想传入两个变量并让函数交换它们的值。这里有一个实现尝试——输入并执行以下代码，看看发生了什么：

```c
#include <stdio.h>

void swap(int i, int j)
{
    int t;

    t = i;
    i = j;
    j = t;
}

void main(void)
{

```

当你执行这个程序时，你会发现交换确实发生了。`a` 和 `b` 的值被传递给了 `swap`，`swap` 函数确实交换了它们，但当函数返回时，什么都没有发生。

```c
{

    *i = *j;
    *j = t;
}

{

    a = 5;
    b = 10;
```

# 第 12 章 动态数据结构 MALLOC 和 FREE

```c
if (p == 0)
{
    printf("ERROR: Out of memory\n");
    return 1;
}
*p = 5;
printf("%d\n", *p);
free(p);
return 0;
```

该程序的第一行调用了 `malloc` 函数。该函数执行了三件事：

1. `malloc` 语句首先查看堆 `heap` 上可用内存量，并询问：“是否有足够的内存来分配请求大小的块？”该块所需的内存量通过传递给 `malloc` 的参数已知——在这种情况下是 4 字节。如果没有足够的可用内存，`malloc` 函数返回地址零表示错误（零的另一个名称是 `NULL`，你会在 C 代码中到处看到它）。否则，`malloc` 继续执行。
2. 如果堆上有可用内存，系统将从堆中“分配”或“预留”一个指定大小的块。系统预留该块内存，以防止它被多个 `malloc` 语句意外使用。
3. 系统随后将预留块的地址放入指针变量（本例中为 `p`）中。指针变量本身包含分配块可以持有指定类型的值，且指针指向它。

程序接下来通过 `if (p == 0)` 这一行检查指针，以确保分配请求成功（该行也可以写成 `if (p == NULL)` 甚至 `if (!p)`）。如果分配失败（如果 `p` 为零），程序将终止。如果分配成功，程序随后将该块初始化为值 5，打印该值，并在程序终止前调用 `free` 函数将内存返回给堆。

这段代码与之前将 `p` 赋值为现有整数 `i` 的地址的代码之间真的没有区别。唯一的区别在于，在变量 `i` 的情况下，内存作为程序预留内存空间的一部分存在，并有两个名称：`i` 和 `*p`。在从堆上分配内存的情况下，该块只有一个名称 `*p`，并且是在程序执行期间分配的。有两个常见问题：

- 在每次分配后检查指针是否为零真的重要吗？是的。堆的大小不断变化，取决于运行哪些程序、它们分配了多少内存等，没有任何保证能确保 `malloc` 成功。你应该在每次调用 `malloc` 后检查指针，以确保指针是有效的。
- 如果我在程序终止前忘记删除内存块会发生什么？当程序终止时，操作系统会对其进行清理，释放其可执行代码空间、栈、全局内存空间以及任何堆分配以供回收。因此，在程序终止时留下悬挂的分配不会产生长期后果。然而，这被认为是一种不规范，而且程序执行期间的“内存泄漏”是有害的，正如下面讨论的那样。

这两个程序展示了指针的不同有效用法，并尝试区分指针的使用与指针值的区别：

```c
void main() {
    int *p, *q;

    p = (int *)malloc(sizeof(int));
    q = p;
    *p = 10;
    printf("%d\n", *q);
    *q = 20;
    printf("%d\n", *q);
}
```

这段代码的最终输出将是第 4 行的 10 和第 6 行的 20。

以下代码略有不同：

```c
void main(void)
{
    int *p, *q;

    p = (int *)malloc(sizeof(int));
    q = (int *)malloc(sizeof(int));
    *p = 10;
    *q = 20;
    *p = *q;
    printf("%d\n", *p);
}
```

这段代码的最终输出将是 `*p = *q`，第 6 行的 20。

注意，编译器允许 `*p = *q`，因为 `p` 和 `*q` 都是整数。这条语句的意思是：“将 `q` 指向的值移动到 `p` 指向的整数值中。”这条语句移动的是值。编译器也会允许 `p = q`，因为 `p` 和 `q` 都是指针，且都指向相同类型（如果 `s` 是指向字符的指针，则不允许 `p = s`，因为它们指向不同类型）。语句 `p = q` 的意思是：“让 `p` 指向 `q` 所指向的同一个内存块。” 换句话说，`q` 指向的地址被移动到了 `p` 中，因此它们都指向同一个块。这条语句移动的是地址。

从所有这些示例中，你可以看到初始化指针有四种方法。当指针被声明为 `int *p` 时，它在程序启动时处于未初始化状态。它可能指向任何地方，因此对其解引用是一个错误。初始化指针变量涉及将其指向内存中的一个已知位置。

1. 方法一种如前所示，使用 `malloc` 语句。该语句从堆上分配一块内存，然后指针指向该块。这初始化了指针，因为它现在指向了一个已知位置。指针被初始化，因为它被填充了一个有效地址——新块的地址。
2. 第二种方法正如刚才所示，使用如 `p = q` 的语句，使 `p` 指向与 `q` 相同的地方。如果 `q` 指向一个有效块，那么 `p` 就被初始化了。指针 `p` 加载了 `q` 的有效地址。然而，如果 `q` 未初始化或无效，`p` 将同样的无用地址。
3. 第三种方法是将指针指向已知地址，例如全局变量的地址。例如，如果 `i` 是整数而 `p` 是指向整数的指针，那么语句 `p = &i` 通过指向 `i` 来初始化 `p`。
4. 第四种初始化指针的方法是使用零值。零是与指针使用的特殊值，如下：

```c
p = 0;
```

或：

```c
p = NULL;
```

这在物理上的作用是将零放入 `p` 中。指针 `p` 的地址为零。

任何指针都可以设置为零。但是，当 `p` 指向零时，它并不指向任何块。指针仅仅包含零。

```c
int main(void)
{
    struct rec *p;
    p=(struct rec *) malloc(sizeof(struct rec));
    (*p).i=10;
    (*p).f=3.14;
    (*p).c='a';
    printf("%d %f %c\n",(*p).i,(*p).f,(*p).c);
    free(p);
    return 0;
}
```

注意以下行：

```
(*p).i=10;
```

许多人奇奇为什么下面的写法不起：

```
(*p).i=10;
```

答案与 C 语言中运算符的优先级有关。计算 5+3*4 的结果是 17 而不是 32，因为在大多数计算机语言中，`*` 运算符的优先级高于 `+`。在 C 中，运算符的优先级高于 `*`，所以括号强制了正确的优先级。

## 命令行参数

C 语言了一种非常简单的机制来获取用户输入的命令行参数。它会将一个 `argv` 参数传递给程序的 `main` 函数。`argv` 结构体出现在许多高级库函数调用中，因此理解它们对任何 C 语言程序员都是有用的。

输入以下代码并编译：

```c
#include <stdio.h>

int main(int argc, char *argv[])
{
    printf("%d\n",argc);
    for (x = 0; x < argc; x++)
        printf("%s\n", argv[x]);
    return 0;
}
```

在这段代码中，主程序接受两个参数：`argv` 和 `argc`。`argv` 参数是一个指向字符串的指针数组，包含了程序在 UNIX 命令行调用时输入的参数。`argc` 整数包含参数数量的计数。这段特定的代码会打印出命令行参数。要尝试尝试，请将代码编译为一个名为 `aaa xxx yyy zzz` 的可执行文件。该代码将打印出命令行参数 `xxx`、`yyy` 和 `zzz`，每行一个。

由于 `argv` 的存在，你可以相当容易让你的程序对用户输入的命令行参数做出反应。例如，你可能让程序检测程序名后的第一个参数为单词 `help`，并将帮助文件转储到 `stdout`。文件名也可以被传递并在你的 `fopen` 语句中使用。

- `putc` - 将字符打印到 `stdout`

```c
return 0;
```

`fgets` 语句在文件结束标记处返回 `NULL` 值。它读取一行（在本例中最多 1000 个字符）并将其打印到 `stdout`。注意 `printf` 语句格式字符串中没有包含 `\n`，因为 `fgets` 在它读取的每行末尾包含了 `\n`。因此，在溢出第二个参数指定的最大长度的情况下，你可以判断行是否不完整。

## main 函数返回值



这个程序是该系列中第一个从 `main` 函数返回错误值的程序。如果 `fopen` 命令失败，`f` 将包含一个 NULL 值（0）。我们用 `if` 语句检查错误。该语句查看变量 `f` 的真假值。记住在 C 语言中，0 是假，任何其他值都是真。所以如果打开文件发生错误，`f` 将包含零，即为假。`!` 是取反运算符。它反转一个布尔值。所以语句可以写成这样：

```c
if ( f == 0)
```

这是等价的。然而，`(!f)` 更常见。如果发生文件错误，我们从 `main` 函数返回 1。在 Linux 中，你实际上可以在命令行上测试此值。详情请参 shell 文档。

# 第18章：二进制文件

二进制文件与结构体数组非常相似，不同之处在于结构体在磁盘文件中，其速度比在内存数组中更快。由于二进制文件中的结构体在磁盘上，你可以创建非常大的集合（仅受限于你的可用磁盘空间）。它们也是永久的，并且始终可用的。唯一的缺点是磁盘访问时间带来的速度慢问题。

二进制文件有两个区别于文本文件的特征：

- 你可以立即跳转到文件中的任何结构体，这提供了类似于数组的随机访问能力。
- 你可以在任何时间在任何位置修改文件中任何位置的结构体内容。

二进制文件的读写速度也比文本文件快，因为记录的二进制镜像直接从内存存储到磁盘（或反之）。在文本文件中，所有内容都必须在文本和二进制之间反复转换，这会消耗时间。

C 语言非常纯粹地支持了“结构体文件”的概念。一旦打开文件，你就可以读取一个结构体、写入一个结构体或定位到文件中的任何结构体。这种文件概念支持**文件指针**的概念。当文件被打开时，指针指向记录 0（文件中的第一条记录）。任何**读取操作**都会读取当前指向的结构体并将指针向下移动一个结构体。任何**写入操作**都会写入当前指向的结构体并将指针向下移动一个结构体。**Seek** 将指针移动到请求的记录。

请记住，C 语言将磁盘文件中的所有内容都视为从磁盘读取到内存或从内存写入磁盘的字节块。C 语言使用文件指针，但它可以指向文件中的任何字节位置。因此，你必须跟踪这些。

以下程序说明了这些概念：

```c
#include <stdio.h>

/* 随机记录描述 - 可以是任意 */
struct rec {
    int x, y, z;
};

/*
 * 从 "junk" 文件写入并读取 10 条任意记录。
 */
int main(void) {
    int i, j;
    FILE *f;
    struct rec r;

    /* 创建包含 10 条记录的文件 */
    f = fopen("junk", "w");
    if (!f) {
        return 1;
    }
    for (i = 1; i <= 10; i++) {
        r.x = i;
        fwrite(&r, sizeof(struct rec), 1, f);
    }
    fclose(f);
```

```c
/* 读取这 10 条记录 */
f = fopen("junk", "r");
if (!f)
{
    return 1;
}
for (i = 1; i <= 10; i++)
{
    fread(&r, sizeof(struct rec), 1, f);
    printf("%d\n", r.x);
}
fclose(f);
printf("%d\n");

/* 使用 fseek 倒序读取这 10 条记录 */
f = fopen("junk", "r");
if (!f)
{
    return 1;
}
for (i = 9; i >= 0; i--)
{
    fseek(f, sizeof(struct rec)*i, SEEK_SET);
    fread(&r, sizeof(struct rec), 1, f);
    printf("%d\n", r.x);
}
fclose(f);
printf("%d\n");

/* 使用 fseek 每隔读取一条记录 */
f = fopen("junk", "r");
if (!f)
{
    return 1;
}
fseek(f, 0, SEEK_SET);

for (i = 0; i < 5; i++)
{
    fread(&r, sizeof(struct rec), 1, f);
    printf("%d\n", r.x);
    fseek(f, sizeof(struct rec), SEEK_CUR); // 注意：此处原文逻辑可能有误，但按原文翻译
}
fclose(f);
printf("\n");
```

```c
/* 使用 fseek 修改第 4 条记录并写回 */
f = fopen("junk", "r+");
if (!f)
{
    return 1;
}
fseek(f, sizeof(struct rec)*3, SEEK_SET);
r.x = 100;
fseek(f, sizeof(struct rec)*3, SEEK_SET);
fwrite(&r, sizeof(struct rec), 1, f);
fclose(f);
printf("\n");
```

```c
/* 读取这 10 条记录以确保第 4 条记录已修改 */
f = fopen("junk", "r");
if (!f)
{
    return 1;
}
for (i = 1; i <= 10; i++)
{
    fread(&r, sizeof(struct rec), 1, f);
    printf("%d\n", r.x);
}
fclose(f);

    return 0;
}
```

在这个程序中，使用了结构体描述 `rec`，但你可以使用任何结构体描述。可以看到 `fopen` 和 `fclose` 的工作方式与文本文件相同。

新函数是 `fread`、`fwrite` 和 `fseek`。`fread` 函数四个四个参数：

- 内存
- 每个块读取的字节数
- 读取的块数
- 文件变量

因此，`fread(&r, sizeof(struct rec), 1, f);` 表示从文件 `f`（从指针当前位置）读取 12 字节（`rec` 的大小）。通过将 1 改为 100，就可以轻松地从磁盘读取 100 块到数组中。

`fwrite` 函数以相同的方式工作，但将字节块从内存移动到文件。`fseek` 函数将文件指针移动到文件的字节。通常，你按 `sizeof(struct rec)` 的增量移动指针，以保持在记录边界。定位时可以使用三个选项：

- `SEEK_SET`
- `SEEK_CUR`
- `SEEK_END`

`SEEK_SET` 将指针从文件开头移动 x 字节（从文件的字节 0 开始）。`SEEK_CUR` 将指针从当前位置移动 x 字节。`SEEK_END` 从文件末尾移动（因此在使用此选项时必须使用负偏移量）。

上面的代码出现了几种不同的选项。特别注意使用 `r+` 模式打开文件的部分。它以读写模式打开文件，允许修改记录。代码定位到一条记录，读取它并修改一个字段；然后由于读取移动了指针而返回，并写回更改。
