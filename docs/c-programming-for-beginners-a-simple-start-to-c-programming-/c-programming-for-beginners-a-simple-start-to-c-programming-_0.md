# C++ 基础

C++ 是一种面向对象的语言，其大部分特性和基础结构都源于 C。这可能就是为什么 C++ 被称为 C 的“超集”的原因。任何用 C 语言编写的程序在法律和语法上都是一个 ANSI C++ 程序。然而，这一陈述的反面并不成立。在不纠结于过多理论的情况下，让我们直接进入编程，这无疑是学习任何编程语言的最好方式。

### 基础基础 C++ 程序

最简单的入门程序是在屏幕上打印“Hello World!”。该程序的代码如下：

代码：

```cpp
//Simple C++ Program

#include <iostream>

using namespace std;

int main ()
{

cout << "Hello World!";

return 0;
}
```

输出：
Hello World!

在继续深入之前，让我们逐行分析这个程序。第一行是注释行。这一行不包含在机器运行的实际代码中。它仅供开发者日后参考，并使代码更容易理解。在 C++ 中有两种编写注释的方法。其中一种方法是在文本前使用 `//`，另一种方法是在文本前使用 `/*` 并在结束处使用 `*/`。

第二行使用 `#include` 并向代码中包含了 `iostream` 库。该库方便了输入/输出操作，并允许用户使用控制台进行输入和获取输出。第三条语句指定代码正在使用 `std` 命名空间。`std` 命名空间包含了 C++ 包中所有的内置库。因此，如果你希望使用这些任何一个库，包含此语句对你来说是关重要的。

打印“Hello World!”的程序从第四条语句开始。`main()` 函数是 C++ 编程语言执行开始的函数。`main()` 必须返回一个整数值。函数的作用域使用大括号 `{` 和 `}` 来描述。

函数体包含两个语句。第一条语句使用标准 I/O 操作 `cout`，用于在屏幕上打印指定的输出。类似的函数 `cin` 用于从控制台获取输入。而 `cout` 操作使用 `<<` 运算符，`cin` 操作则使用 `>>` 运算符。下一条语句返回一个整数值，如前所述。

这两个语句都以分号（`;`）结束，这是 C++ 的标准。然而，此规则不适用于像 `include` 这样的指令。。 C++ 并不是特定格式的。如果你在 Windows 上，可以使用 Dev-C++；在 Unix/Linux 上可以使用 GCC。

## 数据类型、变量与常量

虽然上一章所示的程序相当简单且用处存疑，但它应该为开始 C++ 编程奠定必要的基础。显而易见，编程不仅仅是在控制台上打印文本。当我们深入这门编程语言的复杂性时，首先要看的是变量。

当你还是孩子学习加法和减法时，你的老师或父母一定要求过你在记忆中记住一个数字，然后记住第二个数字。一旦你有了这两个数字，就必须将它们相加并记住结果。当我们提到“记住”这个操作时，我们实际上指的是变量。

因此，变量可以简单地描述为保存定义值的内存单元。例如，如果你回到加法的示例，可以假设有两个单元 `a` 和 `b`，它们包含要加的值。一个名为 `result` 的结果将包含相加的值。因此，`a`、`b` 和 `result` 都是变量。

### 标识符

记住内存单元地址并在每次想要对其执行操作时引用它们是非常的。为了解决这个问题，引入了标识符的概念。标识符是给具有定义值的内存单元的名称，是在其声明时指定的。对该内存单元值的任何更改都通过关联的标识符进行。在之前的的示例中，名称 `a`、`b` 和 `result` 就是标识符。

用作变量名称的标识符也应该是有效的。有几个决定标识符是否有效的准则，如下：

1. 应该是字母、数字和下划线（`_`）的序列。
2. 不应包含空格、符号或标点符号。
3. 应以下划线或字母开头。
4. 不应以数字开头。
5. 不应该是保留关键字。在本章末的附录 I 中提供了保留关键字列表。





请注意，某些编译器可能不支持以下划线开头的关键字。它们是留给编译器本身使用的。此外，C++ 是区分大小写的。因此，`x` 和 `X` 是两个不同的变量。所以，请小心！

### 变量声明

可以使用以下语句声明变量：

`<数据类型> <标识符>`

示例：

```cpp
int a;
```

该语句声明变量 `a` 将包含整数值。该语句有几种变体。你可以按照以下相同语句定义变量：

```cpp
int a = 0;
```

此声明将值 `0` 赋值给变量 `a`。

此外，你还可以使用同一语句声明多个变量。示例所示：

```cpp
int a, b, c;
```

在这种情况下，所有变量 `a`、`b` 和 `c` 都被声明为整数。

整数（`int`、`short` 和 `long`）可以声明为有符号或无符号。你需要在语句中如下方式使用 `signed` 和 `unsigned` 关键字：

```cpp
signed int a;
```

或

```cpp
unsigned int a;
```

在没有关键字的情况下，系统假设该变量本质上是有符号的。你也可以对 `char` 使用 `signed` 和 `unsigned` 关键字。如果你使用 `unsigned char`，则你可以在变量中存储字符。然而，如果你使用 `signed char`，你可以在变量中存储一个字节长的整数。

### 变量的作用域

按照规则，你只有在声明变量后才能使用它。此外，存在“作用域”的概念。作用域有两种：全局和局部。如果变量声明在代码体之外，则该变量具有全局作用域。结果是该变量对程序中的所有函数都可用。

任何在代码体内声明的变量本质上都是局部的，并具有局部作用域。变量的作用域限制是变量所在的块，该块由大括号 `{` 和 `}` 定义。

### 变量初始化

当你声明一个变量时，它包含垃圾值。换句话说，变量的值无法预测。为了让变量变得可用且有用，你需要通过给它赋值来定义它。变量的初始化可以通过两种方法完成。

根据第一种方法，必须在声明时定义变量。

标准格式：

`<类型> <标识符> <变量> = <值>`

示例实现：

```cpp
int a = 0;
```

另一种初始化类型使用了构造函数方法。

标准格式：

`<类型> <标识符> <变量>(值)`

示例实现：

```cpp
int a(0);
```

## 运算符

当我们知道变量和常量的存在时，就可以开始使用它们了。为了方便处理这些变量和常量，C++ 编程语言提供了运算符。与许多编程语言（其运算符本质上是基本的单词）不同，C++ 的运算符大部分由符号组成，这些符号不在字母表中，但在所有控制台中都是可用的。这使得 C++ 代码更短、更具通用性，因为它对英语单词的依赖较少，但在初期需要付出一些学习精力。

### 赋值 (=)

此运算符将一个值分配给变量。

语法：

`<variable identifier> = <value>`

示例：

```
x = 0;
```

此条语句将数值 5 赋值给变量 `a`。运算符（`=`）左侧的部分称为 `rvalue`（右值），右侧称为 `lvalue`（左值）。尽管 `rvalue` 可以是常量、变量或这些者的任何组合，但 `lvalue` 必须是一个变量。分配时最重要的原则是从右到左操作，即操作可靠地从右向左执行，而绝不是反过来。

语法：

`<lvalue> = <rvalue>;`

示例：

```
x = y;
```

此语句将变量 `y` (`rvalue`) 中包含的值分配给变量 `x` (`lvalue`)。C++ 相比其他编程语言的一个特性是，任务操作可以作为另一个任务操作的 `rvalue`（或 `rvalue` 的）。

示例：

```
x = 7 + (y = 0);
```

在示例语句中，`0` 被分配给变量 `y`，然后在该值的基础上加上 `7`。结果被赋值给 `x`。

以下语句在 C++ 中也是合法的：

```
x = y = z = 0;
```

它将 0 赋值给三个变量：`x`、`y` 和 `z`。

C++ 语言支持的五种算术运算是：加（`+`）、减（`-`）、乘（`*`）、除（`/`）和取模（`%`）。其中你可能不太熟悉的运算符是取模。该运算符将除法的余数作为结果。例如，如果你执行以下操作：

```
a = 21 % 4;
```

`21` 除以 `4` 的余数为 `1`。这就是该操作的输出。

### 复合赋值

复合运算符包括减（`-=`）、加（`+=`）、除（`/=`）、乘（`*=`）、`>>=`、`<<=` 和取模（`%=`）。此外，还可以使用位逻辑运算符。当我们需要通过对变量的当前值进行操作来调整其估计时，可以使用复合赋值。

语法：

`<variable identifier><operator> = <value>`

示例：

```
x += 1
```

在上面的示例中，`x` 的值增加了 `1`。

### 递增递减 (++, --)

为了减少使用的语句数量，提供了递增和减操作。这些语句分别等同于 `+=1` 和 `-=1`。

在早期的 C 编译器中，三种表述方式可能根据使用的不同而产生不同的可执行代码。如今，这种代码优化由编译器完成，因此这三种解释应该产生完全相同的可执行代码。

该操作的一个特性是它既可以作为前缀使用，也可以作为后置使用。这意味着它可以位于变量标识符之前（`++a`），也可以之后（`a++`）。尽管在 `a++` 或 `++a` 等基础语句中，两者的重要性完全相同。然而，在不同的声明中，如果构建或减少操作的结果在外部解释中被评估为一个值，那么它们的意义可能会有显著区别。

如果递增操作作为前缀使用（`++a`），则值在语句结果被评估之前增加，随后扩展后的值在外部流流中被考虑。如果它作为后置使用（`a++`），则值在评估之后增加，因此在外部表示中评估的是增加操作之前保存的值。

### 关系和相等运算符

这些运算符包括不等于（`!=`）、等于（`==`）、小于（`<`）、小于等于（`<=`）、大于（`>`）和大于等于（`>=`）。

为了评估两个解释之间的之间的关系，我们可以使用关系和对应操作。关系操作的结果是一个布尔值。该结果可以是两个值之一：`false` 或 `true`。

我们可能需要查看两个解释，例如判断它们是否等价，或者一个是否比另一个大。以下是 C++ 中可以使用的运算符列表：

示例：

```
(7 == 3) // 此表达式的结果为 false
(6 > 5) // 此表达式的结果为 true
(3 != 4) // 此表达式的结果为 true
(6 >= 6) // 此表达式的结果为 true
(5 < 5) // 此表达式的结果为 false
```

### 逻辑运算符

C++ 编程语言支持三种逻辑操作，即：非（`!`）、和（`&&`）和或（`||`）。

运算符 `not`（`!`）是 C++ 执行布尔操作 NOT 的运算符。它只有一个操作数，其主要功能是反转它的值。如果操作数的值为 `true`，则它会被转换为 `false`。相反，如果值为 `false`，则被转换为 `true`。本质上，它提供了与其操作数评估结果相关的布尔结果。

另外两个操作 `&&` 和 `||` 使用两个变量。操作 `&&` 对应布尔操作 AND。当且仅当两个操作数都为 `true` 时，该操作结果为 `true`。相反，操作 `||` 与布尔操作 OR，如果至少有一个操作数为 `true`，则结果为真值。

### 条件运算符 (?)

此运算符评估一个声明，如果该流为真则返回一个值，如果语句被评估为假则返回另一个。

语法：

`conditionForTesting ? resultIfTrue : resultIfFalse`

如果 `conditionForTesting` 为 `true`，语句将返回 `resultIfTrue`。但如果 `conditionForTesting` 为 `false`，它将返回 `resultIfFalse`。

### 逗号运算符 (,)

逗号操作（`,`）用于在通常是独立语句的地方两个或多个独立流。当一组声明必须被评估为一个值时，只考虑最右边的表达式。

### 位运算符

位运算包括位与（`&`）、位或（`|`）、`~`、`^`、`>>` 和 `<<`。这些运算符根据代表它们所存储属性的位设计来调整变量。

### 显式类型转换运算符

此运算符允许将数据从一种指定的类型转换为另一种。在 C++ 中有几种方法可以实现这一点。最简单的方法继承自 C 语言，是在要转换的声明之前将新类型封装在括号 `()` 之间。

示例

```
int i;
float f;
i = int ( f );
```

上述代码声明了两个变量 `i` 和 `f`。虽然 `i` 是整数，但 `f` 是浮点数。直接将 `f` 赋值给 `i` 将引发警告。因此，你需要对其进行类型转换。第三条语句将浮点变量的值转换为整数，并将相同的值赋予整数变量。

## C++ 中的基础输入/输出

利用标准包含文件和程序库，我们将能够通过在屏幕上打印消息以及从控制台获取客户端信息与客户端进行交互。C++ 利用一种名为“流”（streams）的实用机制在连续的介质（例如屏幕或控制台）中执行输出和输入操作。

流是一个系统可以向其嵌入或从从中提取字符的项。我们通常不需要考虑与流连接的物理介质的大量判断——我们只需要知道它会连续确认或提供字符即可。

标准 C++ 库包含了头文件 `iostream`，其中定义了标准输出和输入流项。

### 标准输出 (cout)

自然地，项目的标准输出是屏幕，而特征用于访问它的 C++ 流项是 `cout`。`cout` 与插入运算符结合使用，该运算符构造为 `<<`。

示例实现：

```
cout << "This is C++";
```

示例实现：

```
int x;
cin >> x;
```

### Cin 与字符串

我们可以像处理基本信息排序变量一样，利用提取运算符（`>>`）使用 `cin` 获取字符串：

```
cin >> stringIn;
```

然而，正如所说，`cin` 提取在遇到任何空白字符时会停止读取。因此，在这种情况下，我们每次提取只能获取单个单词。

## 控制结构

系统通常不局限于指令的直线分组。在它的处理过程中，它可能会进行分支、重构代码或做出选择。因此，C++ 提供了控制结构，用于指定我们的系统必须执行什么、在何时以及在什么情况下执行。

我们在这一领域看到的大部分控制结构，作为语言结构的一个主要方面需要一个简单的解释。一个声明可以是基本语句（以分号结尾的简单指令），也可以是复合语句（在方括号中的几条指令）。如果我们需要声明是简单语句，则不需要用大括号（`{}`）括起来。尽管如此，如果我们需要声明是复合声明，它必须被封装在大括号（`{}`）之间，形成一个代码块。

### if-else 结构

`if` 结构定义了一个条件和一组指令。在满足条件的情况下会执行 `if` 块。

`if` 构造的语法如下：

```
if (<condition>)
{
//Code
}
```

在这里，condition 是被不断评估的语句。如果该条件为真，则执行代码。如果它为假，代码将被忽略（不执行），系统将继续执行该条件结构之后的后续内容。

`if` 结构的扩展版本是 `if-else` 结构。该结构的语法如下：

```
if (<condition>)
{
// 条件为真时执行的代码
}
else
{
// 条件为假时执行的代码
}
```

如果条件为真，则执行 code-if-true。如果它为假，code-if-true 将被忽略（不执行），系统将继续执行 code-if-false。

示例：

```
if (a == 0)
{
    cout << "Value of a: 0";
}
else
{
    cout << "Value of a is not 0";
}
```

### 循环

循环的目的是按照特定次数重复执行一段代码，或者在 while 条件满足时重复执行。

`while` 结构的语法：

```
while (<condition>)
{
//Code
}
```

它的作用仅仅是当声明中设置的条件为真时重复执行语句。

`do-while` 循环的语法：

```
do
{
//Code
} while (<condition>);
```

它的作用与 `while` 循环完全相同，不同在于 `do-while` 循环中的条件是在代码执行之后评估的，而不是在之前评估，这使得无论条件是否从不满足，代码都至少执行一次。

当需要确定循环结束的条件在循环语句内部被解决时，通常使用 `do-while` 循环，正如之前的例子所示，用户进入代码块的内容被用于判断循环是否需要结束。

`for` 循环的语法：

```
for (<initialization>; <condition>; <build>)
{
//Code
}
```

它的主要功能是在条件有效时执行代码，与 `while` 循环相同。然而，`for`-循环提供了特定的区域来包含初始化语句和递增/递减声明。因此，这种循环专门用于执行带有计数器的单调任务，计数器在每个周期中被初始化和增加。

它按照以下方式工作：

1. **执行初始化**：大多数情况下，它是计数器变量的初始值设置。这只执行一次。
2. **检查条件**：如果条件为真，循环继续。然而，如果条件为假，循环在执行完构建条件后执行。
3. **执行语句**：当然，它可以是单行代码，也可以是花括号括起来的代码行，如 `{ }`。
4. **最后**，执行构建 字段中确定的任何内容，并返回到步骤 2。

### 跳跃语句

C++ 支持多种形式的跳转语句。下文将讨论这些语句。

### break 语句

使用 `break`，无论循环结束条件是否满足，我们都可以循环。它可以用于终止无限循环，或者强制其在正常结束之前终止。例如，我们将在其正常结束前停止计数。

### continue 语句

`continue` 语句导致代码跳过当前循环语句中的剩余部分，就像已经到达代码块的结尾一样，使其跳转到循环的开始。

### goto 语句

`goto` 允许跳转到代码中的另一个点。你应该谨慎使用此特性。执行其后会导致忽略任何类型限制的无条件跳转。目标点通过一个名称来标识，该名称随后作为 `goto` 行的内容。名称由一个合法标识符后跟冒号（:）组成。

### exit() 函数

`exit()` 是 `stdlib` 库可用函数。可以使用特定的代码终止当前执行。使用该函数的语法如下：

```
void exit (int exitcode);
```

`exitcode` 被某些工作框架使用并可能被调用函数使用。按照惯例，退出代码 0 表示系统正常完成，其他值表示发生了某些错误或意外结果。

示例实现：

```
exit (0);
```

### switch 结构





`switch` 构造的语法有点特殊。它的目标是针对解释对几个可能的值进行检查。这类似于我们在在本节开始时链接几个 `if` 和 `else if` 指令所做的操作。该构造的语法如下：

```cpp
switch (<要监控的整数>)
{
case value1:
    //code
    break;
case value2:
    //code
    break;
.
.
default:
    //code
    break;
}
```

考虑到 `switch` 构造并不使用块（blocks），它在 C++ 方言中显得有些特殊。相反，它使用标签（labels）。这使得我们能够在针对特定条件需要执行的相关行之后放置 `break` 代码。

### 示例实现：

```cpp
int a;
cin >> a;
switch (a)
{
case 0:
    cout <<”Entered value is 0”;
    break;
case 1:
    cout << “Entered value is 1”;
    break;
default:
    cout << “Value other than 0 and 1 entered by the user”;
    break;
}
```

这段代码要求用户输入一个整数。如果输入的值为 `0`，则执行 `case 0` 代码。然而，如果用户输入 `1`，则执行 `case 1`。如果用户输入一个随机值，`switch-case` 将跳过所有情况并执行 `default` 情况。惯例上用 `break` 语句为 `default` 情况结束标记。

此外，请注意，如果你跳过了 `break` 语句，系统将执行真值情况之后的所有情况。例如，如果你在上述代码中跳过了 `break` 语句且用户输入了 `0`，系统将执行所有情况。因此，所有三个语句都将被打印。

## 函数

你可以使用函数来组织你的代码，这允许你充分利用 C++ 中组织化编程所能为你提供的所有潜力。函数是语句的集合，当从项目的某个位置调用时就会执行。其结构如下：

```cpp
<data type> <function identifier> (<parameter1>, <parameter2>, ...)
{
    //code
}
```

这里：
- **数据类型（Data type）** 是函数返回的信息的数据类型。
- **函数标识符（Function identifier）** 是调用该函数时的标识符。
- **参数（Parameters）**（数量与要求相同）：每个参数由数据类型和标识符组合组成。参数的声明方式与普通变量的相同。它们允许在调用函数时将值从调用函数传递到函数。这些参数通常用逗号分隔。
- **代码语句（Code statements）** 构成函数体。它是包含在大括号中的部分声明。

### 变量作用域

在函数或其他内部方块内声明的变量范围仅限于其函数或代码块，且不能在外部使用。考虑以下示例以更好地理解作用域概念。

```cpp
void func1()
{
    int a;
    //code
}

void func2()
{
    int b;
    //code
}
```

在上面的示例代码中，变量 `a` 仅在 `func1()` 内部可用，变量 `b` 仅在 `func2()` 内部可用。因此，附近变量的范围限制在它们声明的块级别。考虑到所有因素，我们同样有机会具有全局作用域的变量。这在代码的任何位置（函数内部和外部）都是显而易见的。如果有声明全局变量的特定目标，你只需要在任何块或函数之外声明变量即可。然而，该位置必须在项目的汇范围内。

### 带有 void 返回值的函数

如果你回到函数的声明语法，你会发现数据类型声明了函数返回的值的数据类型。然而，某些函数可能不返回任何内容，在这种情况下，你将数据类型指定为 `void`。

假设我们需要创建一个功能函数来在屏幕上显示消息。我们不需要担心提供返回值。对于这种情况，我们应该对函数使用 `void` 数据类型。这是一个表示“无类型”的非空指定符。

`void` 也可以用于函数的参数列表，以明确指出我们希望函数在被调用时不接受实际参数。

### 按引用传递和按值传递的值

在调用带有参数的函数时，进入函数的是它们值的副本。变量本身从未被发送。在函数内部对变量值进行的任何更改都不会反映在原始变量上。另一方面，如果向函数发送变量的引用，函数内部对变量的更改将原样反映在原始变量上。

### 参数中的默认值

在声明函数时，我们可以为每个参数定义默认值。当在调用函数时留空相关内容时，该属性将被使用。要做到这一点，我们基本上需要在函数声明中使用赋值运算符并为变量指定一个值。如果在调用函数时没有传递该参数的值，则使用默认值。然而，如果定义了该值，则该默认属性将被忽略并使用传递的值。

### 重载函数

在 C++ 中，如果两个函数的参数类型或数量不同，则它们可以具有相同的名称。这意味着只要它们具有不同数量的参数或不同的参数数据类型，你就可以给多个函数赋予相同的名称。

所示是一个示例实现：

```cpp
#include <iostream>

using namespace std;

float processnum (float x, float y)
{
  return (x/y);
}

int processnum (int x, int y)
{
    return (x+y);
}

int main () {
  int a=2, b=2;
  float c=4.0,m=4.0;
  cout << processnum (a, b)<<endl;
  cout << processnum (c, d)<<endl;
  return 0;
}
```

在这种情况下，我们声明并定义了两个具有相同名称 `processnum` 的函数。其中一个接受两个 `int` 类型的参数，另一个接受两个 `float` 类型的参数。编译器通过分析调用函数时作为值传递的数据，知道在每种情况下应该引入哪一个。如果用两个 `ints` 作为参数调用它，它将调用声明中具有两个 `int` 参数的函数。另一方面，如果用两个 `floats` 调用它，它将调用模型中具有两个 `float` 参数的特定用例。

在第一次调用 `processnum()` 时，传递的两个参数是 `int` 类型。随后，调用了第二个声明的函数，它将两个值相加并返回结果。然而，第二次调用传递了两个 `float` 类型的参数。因此，调用了具有第一个模型的函数。这个函数具有不同的行为，将一个参数除以另一个参数。因此，函数调用的行为取决于所传递参数的类型，因为函数已经被重载了。

重要重要的是，函数还可以以其他方式进行重载，且至少有一个参数必须具有不同的数据类型。

### 内联函数

`inline` 指定符向编译器表示对相关函数进行内联替换。这不会改变函数本身的行为。然而，它用于建议编译器将函数体产生的代码必须在函数被调用的地方嵌入，而不是仅嵌入一次并对其进行通用调用，后者在大多数情况下会产生运行时的某些额外开销。

标准语法：

```cpp
inline <data type> <identifier> ( <parameters with their data types> )
{
    //Code
}
```





请注意，该调用与调用任何其他标准函数非常相似。此外，在调用函数时，不需要包含内联单词。它只需要在函数的声明-定义处指定即可。

### 递归

递归是允许在没有任何输入或外部干预的情况下调用函数的属性。它对于实现某些功能（如排序或计算数字的阶乘）非常有价值。

## 数组

数组是相同数据类型组件的排列，存放在顺序内存区域中，可以通过以下格式进行排他引用：

`arrayRef[i]`

在这里，`arrayRef` 是任何数组，`i` 可以是任何整数值，但不大于数组中的元素个数。这意味着，例如，我们可以在数组中存储 5 个 `int` 类型的值，而不需要声明 5 个独立的变量。所有这些值都使用一个标识符进行引用。与普通变量一样，数组在使用之前必须先声明。在 `C++` 中声明数组的标准形式为：

`<data type> <identifier> [<number of elements>];`

在这里，`data type` 是数组将包含的元素的数据类型，`identifier` 是赋予数组的唯一名称，`number of elements` 表示数组中存在的元素个数。

### 示例：

如果你想存储五个整数类型的数字，你需要使用以下声明来定义此结构：

`int num [5];`

### 数组初始化

在声明一个普通数组实例时（例如在函数内部），如果我们没有进行其他标记，它的组件将自然地不会初始化为任何值。因此，在我们向它们存储某些值之前，其内容将是不确定的。全局和静态性质的组件会被自然地初始化为默认值。因此，所有全局或静态数组的元素都被初始化为 `0`。

### 访问数组元素

在任何存在数组的系统中，我们可以独立地获取其任何元素的值，就像它是典型变量一样，因此具有读取和调整其值的能力。配置非常简单：

`<identifier> [<index>]`

例如，如果你想访问在上一节声明的数组 `num` 的第一个元素，你必须使用语句：

`a = num [0];`

在 `C++` 中，超出记录范围在语言上是允许的。这可能会导致问题，因为访问超出范围的组件不会导致编译错误，但可能导致运行时错误。允许这种行为背后的原因在我们开始使用指针时会进一步看到。

### 多维数组

多维数组可以被描述为“数组的数组”。例如，二维数组可以被想象成由组件组成的二维表格，其中每个组件都具有相同的统一信息类型。

多维簇不仅限于两个索引（即两个测量）。它们可以包含所需的数量的记录。然而，请注意！簇所需的内存尺寸会随着每次增加而迅速增加。

### 数组作为参数

在某些情况下，我们可能需要将数组作为参数传递函数。在 `C++` 中，将整个内存块按值作为参数传递给函数是不实际的。然而，我们允许传递它的地址。在实践中，这几乎具有相同的影响，而且是一种更快、更高效的操作。

记住将数组作为参数识别的目标，我们在声明函数时需要做的主要工作是在参数中指定数组的组件类型、标识符和一对空括号 `[]`。

## 字符序列

如你所知，`C++` 标准库实现了一个有效的字符串类，这对于处理和控制字符序列非常有帮助。另一方面，由于字符串确实是字符的排列，我们可以像普通的 `char` 组件数组一样对待它们。

### 空 终止字符序列的初始化

由于字符簇是普通数组，它们遵循所有的相同标准。例如，如果我们需要引入一个具有预定字符顺序的字符数组，我们可以像其他数组一样这样做。此功能的示例实现如下：

`char name[] = { 'J', 'o', 'h', 'n', '\0' };`

在这种情况下，你声明了一个具有 5 个元素的 `char` 数组。虽然你可以按照上述方式初始化 `char` 数组，但可以使用字符串字面量以更好的方式执行相同的功能。

### 使用空终止字符序列

`C++` 编程语言中定义字符串的标准方法是以空字符 `\0` 终止的字符序列。这也是字符串字面量使用的格式。

## 指针

到目前为止，我们知道变量被视为可以通过其标识符访问的内存单元。因此，我们不需要考虑信息在内存中的物理区域。每当我们需要引用变量时，基本上都使用它的标识符。

你机器的内存可以被想象为一系列内存单元，每个单元的大小很小，机器会处理它们（一个字节）。内存单元在本质上是顺序的。因此，此块中的每个元素都是前一个元素的数字加一。

### 引用运算符 (`&`)

当我们声明变量时，所需的内存尺寸分配在内存中的特定区域（其内存地址）。通常情况下，我们并不热衷于在想象的内存单元板中选择变量的准确区域。

幸运的是，这是工作框架在运行时自然完成的任务。尽管如此，有时我们可能对知道变量在运行时一直存储的位置感兴趣，以便相对于它的相对位置进行操作。

在内存中标记变量的地址就是我们所说的变量的引用。这种对变量的引用可以通过在变量标识符之前放置取地址符号 `&`（称为引用运算符）获得，它可以实际上被解释为“……的位置”。

### 解引用运算符 (`*`)

我们刚刚看到，存储指向另一个变量引用的变量被称为指针。使用指针，我们可以专门获取它所指示的变量中存储的值。要做到这一点，我们基本上需要在指针标识符之前放置一个引用点 `*`，它相当于解引用运算符，并且实际上可以意为“……所指向的值”。

### 引用运算符与解引用运算符的区别

- 取地址符 (`&`) 是引用运算符，可以被读取为“……的位置”
- 星号 (`*`) 是解引用运算符，可以被读取为“……所指向的值”

### 指针与数组

数组的概念与指针的概念密切相关。实际上，簇的标识符等于其第一个组件的位置，正如指针等于它所指示的第一个组件的位置。事实上，它们是同一个概念。

随后的操作是法的：

```
p = num;
```

如果 `p` 是指针且 `num` 是数组，两者类型相同，在该语句之后，`p` 和 `numbers` 是可以比较的并且具有相同的属性。主要的区别是我们可以更改指针 `p` 的值，而 `numbers` 将始终地指示它所特征的固定数据类型不同元素中的第一个。




因此，与传统的指针 `p` 不同，`numbers` 是一个数组。因此，数组可以被视为一个常量指针。在这种情况下，随后的赋值将没有实质意义：

```
num = p;
```

由于 `numbers` 是一个数组，它作为一个常量指针工作，我们不能将值赋予常量。

## 指针的指针

C++ 允许使用指向指针的指针，这种指针反过来指向信息（甚至指向不同的指针）。为了实现这一目标，我们只需要在声明中为每一层级的引用添加一个星号 `*` 即可。

## 空指针

空指针是任何指针类型的惯用指针，它有一个特殊值，表示它没有指向任何合法的引用或内存地址。这种属性是由于向任何指针类型抛出数值零零导致的。

不要将空指针与空类型指针（void pointers）混淆。空指针是不指向任何内容的指针。相反，空类型指针指向一个包含 `void` 类型值的位置。前者指的是指针本身存储的值，而后者指的是它所指示的信息类型。

## 函数指针

C++ 允许对函数指针进行操作。这种操作常见的用途是将函数作为参数传递给另一个函数，因为这些函数不能在解引用后传递。要声明一个指向函数的指针，我们需要像声明函数一样声明它，只不过函数名被封装在括号 `()` 之间，并在名称前嵌入一个标记符号 `*`。

## 动态内存分配

直到最近，在我们所有的示例中，我们已经知道所需的内存量，并根据此估算声明了变量（甚至是数组）。结果是在代码执行之前，我们就预先分配了程序所需的所有内存。

同时，假设你面临一种情况，你需要一个变量的内存，且这种测量必须在运行时解决。例如，当需要根据某些客户端数据来确定所需的内存空间大小时。

这种需求的答案是动态内存，C++ 允许使用 `new` 和 `delete` 运算符来实现它。

### new 和 new [] 运算符

为了请求元素内存的目标，我们使用 `new` 运算符。数据类型指定符跟在 `new` 运算符后面。然而，如果需要一组多个组件，可以在括号 `[]` 中指定这些数量。它返回一个指向分配的新内存块起始位置的指针。

语法：

```
<pointer identifier> = new <data type>
<pointer identifier> = new <type> [<number_of_elements>]
```

主语句用于分配包含一个指定数据类型的单个组件的内存。第二个语句用于分配一个指定数据类型的组件数组，其中 `number_of_elements` 是表示这些数量的整数值。

### delete 和 delete[] 运算符

由于对元素内存的需求通常局限于代码中的特定时刻，一旦它不再需要，它就应该被释放，以便内存可以被不同的元素内存请求再次访问。这就是提供 `delete` 运算符的原因。

语法：

```
delete <pointer identifier>;
delete [] <pointer identifier>;
```

主表示应用于删除为单个组件分配的内存，第二个用于删除为组件数组分配的内存。作为参数传递删除的值必须是指向由 `new` 分配内存的指针，或者是空指针（对于空指针，`delete` 不产生任何影响）。

## 面向对象编程简介：类

类是信息结构的扩展概念，而不仅仅是持有信息。它可以同时包含函数和数据。相反，对象是类的实例化。对于变量来说，类是类型，而对象是变量。

类通常使用关键字 `class` 声明，其语法如下：

```cpp
class <className> {
accessSpecifier_1:
    memberData;
    memberFunction;
access_specifier_2:
    memberData;
    memberFunction;
} <objectName>;
```

其中 `className` 是类的标识符，`objectName` 是该类对象的可选名称标识符。展示的内容可以包含部分，这些部分可以是数据成员或函数语句，并且可以带有指定符。

示例：

```
int a;
```

在这里，`a` 是 `int` 类的一个对象。

### 访问修符

这与信息结构的语句本质上相同，只是我们现在可以额外包含函数和数据部分，以及这种称为访问修符的新事物。访问权限或访问修符包括以下三个关键字之一：`private`、`public` 或 `protected`。这些修符改变了对其作用范围内的成员的访问权限。

- **Private (私有)**：类的此类成员仅从同类的其他成员或其伴侣内部访问。
- **Protected (受保护)**：此类成员可以从同类成员及其伴侣访问，还可以从其派生类的部分访问。
- **Public (公有)**：此类成员可以在对象可见的任何地方访问。

默认情况下，类的所有成员对于其所有成员来说都是私有的。

示例：

```cpp
class myRectangle {
    double a, b;
public:
    void setValues (double, double);
    double func (void);
} myRect;
```

在这个示例中，`a` 和 `b` 是私有的，而函数 `setValues()` 和 `func()` 是公有的。

### 构造函数和析构函数

你大多数时候需要在创建过程中引入变量或分配动态内存，以清理内存并避免在程序执行期间返回意外值。

考虑之前的示例，如果你在没有初始化它们的情况下将 `a` 和 `b` 作为参数传递给函数，那么函数获得的值将是垃圾值。你的代码可能会给出错误的结果或突然崩溃。

考虑到避免这种情况的目标，类可以包含一个名为 `constructor`（构造函数）的特殊函数，该函数在此类的另一个对象被创建时会被自然调用。这个构造函数的名称必须与类名相同，并且不能有任何返回类型。

示例：

```cpp
#include <iostream>
using namespace std;

class myRectangle {
    double x, y;
public:
    myRectangle (double, double);
    double areaRect () {return (x*y);}
};

myRectangle :: myRectangle (double a, double b) {
  x = a;
  y = b;
}

int main () {
    myRectangle rectx (1,2);
    cout << "rect area: " << rectx.areaRect() << endl;
    return 0;
}
```

`main()` 中的第一条语句实例化类 `myRectangle`。创建对象时传递的参数调用了构造函数，并将矩形的尺寸初始化为 1 和 2。因此，当调用 `areaRect()` 时，函数返回正确的面积值 2。

构造函数不能像普通函数那样显式地调用。它们只在创建类的另一个对象时执行。你同样注意到构造函数（类内部）和最后的构造函数定义都没有包含返回值，甚至没有 `void`。

析构函数实现相反的作用。当对象需要被销毁时会被调用，可能是因为它的生存周期已结束（例如，它被定义为函数内部的局部变量且函数关闭了），或者它是一个显式分配的对象并使用 `delete` 运算符释放。




析构函数的名称必须与类相同。然而，在名称之前会放置波浪号（`~`），并且它同样不应该有返回值。析构函数的使用特别适用于对象在其生命周期内使用了动态内存，而在它被销毁时，我们需要释放该项所分配的内存。

### 构造函数重载

与其他函数一样，构造函数也可以通过重载来包含多个函数定义，这些函数定义具有相同的名称，但参数类型或数量有所不同。请记住，为了使重载生效，编译器将调用其参数与函数调用中所使用的值相匹配的那一个。由于构造函数在对象创建时被调用，因此，执行的是与对象断言中传递的值相匹配的那个特定情况。

### 默认构造函数

如果你在类定义中没有声明任何构造函数，编译器允许该类拥有一个无参数的默认构造函数。即使你没有创建自己的，编译器也会自动为你创建一个默认构造函数。

如果你没有声明自己的构造函数，它总会声明三个特殊的函数。这些是拷贝构造函数、默认析构函数和拷贝赋值运算符。

拷贝构造函数和拷贝赋值运算符会将另一个对象中包含的所有信息复制到当前对象的成员中。

### 类指针

创建指向类的指针是完全合法的。我们基本上只需要考虑，一旦声明，类就变成了一种实质的数据类型，因此我们可以使用类名作为指针的数据类型。

示例：

```
myRectangle * pointerRect;
```

`pointerRect` 是一个指向类 `myRectangle` 对象的指针。

与结构体的情况一样，为了具体引用指针所指向对象的特定成员，我们可以使用间接运算符（`->`）。

C++ 整合了使用标准运算符对类进行操作的选项，就像对基本数据类型一样。C++ 有一项功能，允许你通过设计准备好使用标准运算符操作的类来重载运算符。

为了重载某个运算符以实现特定目标并与类一起使用，我们声明运算符函数，这些是一致函数，其名称是我们需要重载的运算符符号所模拟的函数关键字。格式为：

`<data type> <operator> <operator sign> (<parameters>)`

}

在这里你有一个重载了加法运算符（`+`）的示例。我们将创建一个类来存储 2 维向量，然后包含两个这样的向量：`a` (2,4) 和 `b` (3,4)。两个 2 维向量的加是一个与两个 x 方向相加以得到后续 x 方向一样基础的操作。该操作在点‘a’和‘b’上执行的结果应该是 `(2+3, 4+4)`，它等于 `(5, 8)`。

### 静态成员

类可以包含静态部分，可以是数据或函数。类的静态数据通常被称为“类变量”，因为对于该类的所有对象来说都有独特的值。它们的内容在该类的一个对象和另一个对象之间是不相同的。

### 友函数

从根本上说，类的私有成员无法从声明它们的类外部访问。然而，这一标准并不影响友函数。

如果我们需要声明一个外部函数为类的友元，从而允许该功能访问此类类的私有和保护成员，我们通过在类内部声明该外部函数的模型，并在其前面放置 `friend` 关键字来实现。

示例：

```cpp
#include <iostream>

using namespace std;

class myRectangle {
int x, y;
public:
void setValues (int, int);
int func () {return (x * y);} friend myRectangle copy (myRectangle);
};

void myRectangle :: setValues (int a, int b) {
  x = a;
  y = b;
}

myRectangle copy (myRectangle rectParam) {
  myRectangle rects;
  rects.x = rectParam.x*2;
  rects.y = rectParam.y*2;
  return (rects);
}

int main () {
  myRectangle rectx, recty;
  rectx.setValues (2,3);
  recty = copy (rectx);
  cout << recty.func();
  return 0;
}
```

`copy` 函数是 `myRectangle` 的友函数。在该函数内部，我们拥有了访问类私有成员 `x` 和 `y` 的能力。注意，在 `copy()` 的语句中或其后在 `func()` 中的使用中，我们都没有将 `copy` 视为 `myRectangle` 类的一部分。它不是的！它本质上在不作为类的一部分的情况下进入了它的私有和保护成员。

友函数可以用于，例如指导两个独立类之间的操作。大多数情况下，友函数的使用超出了面向对象的编程技术，因此在任何可能的情况下，最好使用同一类的部分来执行它们的操作。

### 友类

通常正如我们可以声明友函数能力一样，我们也可以将一个类声明为另一个类的友，允许该类访问后者的私有和保护成员。

示例：

```cpp
#include <iostream>

using namespace std;

class mySquare;

class myRectangle {
int x, y;
public:
int myArea () {return (x * y);}
void convert (mySquare a);
};

class mySquare {
private:
int x;
public:
void setSide (int a)
{side=a;}
friend class myRectangle;
};

void myRectangle::convert (mySquare a) {
  x = a.x;
  y = a.x;
}

int main () {
  mySquare sqr;
  myRectangle rect;
  sqr.setSide(4);
  rect.convert(sqr);
  cout << rect.myArea();
  return 0;
}
```

在这个示例中，我们将 `myRectangle` 声明为 `mySquare` 的友，以便 `myRectangle` 函数能够访问 `mySquare` 的私有和保护成员，特别是 `mySquare::x`。

### 类之间的继承

C++ 类的一项关键特性是继承，它允许你创建自不同类的类。因此，除了它们自身的之外，它们自然地包含了“父类”的部分成员。

继承自其他类继承了基类的所有可用部分。这意味着如果基类包含部分 A 并且我们确定到一个具有部分 B 的另一个类，那么派生类将包含部分 A 和 B。




要从派生类确定一个类，我们利用冒号（`:`）作为推断类显示的一部分，并如下安排：

```cpp
class <derived class name>: public <base_class_name>
{
//Code
};
```

其中 `derived_class_name` 是推断类的名称，`base_class_name` 是其所基于的基类的名称。`public` 修饰符可以被任何其他访问修饰符 `protected` 或 `private` 替换。该访问修饰符描述了继承自基类的部分的基类访问级别。

```cpp
#include <iostream>
using namespace std;

class myPol {
protected:
    double x, y;
public:
    void setValues (double a, double b)
    { x = a; y = b;}
};

class myRect: public myPol {
public:
    double myArea ()
    {
        return (x * y);
    }
};

class myTri: public myPol {
public:
    int myArea ()
    {
        return (x * y/ 2);
    }
};

int main () {
    myRect rect;
    myTri trgl;
    rect.setValues (4,5);
    trgl.setValues (4,5);
    cout << rect.myArea() << endl;
    cout << trgl.myArea() << endl;
    return 0;
}
```

类 `myRectangle` 和 `myTriangle` 的对象各包含继承自 `myPolygon` 的成员。这些成员是：`x`、`y` 和 `setValues()`。

`protected` 访问修饰符类似于 `private`。它的不同之处实际上发生在继承中。当一个类继承自另一个类时，被继承类的部分可以访问继承自基类的 `protected` 成员，但不能访问其 `private` 成员。

由于我们需要让推断类 `myRectangle` 和 `myTriangle` 的部分将 `x` 和 `y` 设为公开，而不仅仅是 `myPolygon` 的内部部分，因此我们使用了 `protected` 而不是 `private`。

## 从基类继承了什么

从基础层面上说，继承类继承基类的每个成员，但以下除外：
* 构造函数
* 析构函数
* `Operator=()` 成员
* 友元

尽管基类的析构函数和构造函数本身没有被继承，但在创建或销毁继承类的对象时，析构函数和默认构造函数会被调用。如果基类没有默认构造函数，或者你需要在创建另一个继承对象时调用重载构造函数，你可以在推断类的每个构造函数定义中详细说明：

```cpp
<derived constructor name> (<parameters>) : <base constructor name> (<parameters>) {
//Code
}
```

### 多重继承

C++ 中规定了一个类可以继承自多个类。这可以通过在类声明中使用逗号分隔基类来实现。例如，如果我们有一个用于在屏幕上打印的特定类（`myOutput`），并且我们需要我们的类 `myRectangle` 和 `myTriangle` 同样继承它的成员（尽管它们已经继承了 `myPolygon`），我们可以相应地进行组合。

### 指向基类的指针

继承类的一个关键特性是，指向推断类的指针与指向其基类的指针是兼容的。多态是利用这种简单但强大且灵活的特性的技巧，这种特性将面向对象的方法发挥到了最大优势。

### 虚拟成员

类中可以在其推断类中被重新分类的部分被称为**虚拟成员**（virtual member）。为了实现将类的一部分声明为虚拟的特定目标，我们必须在它的语句之前放置 `virtual` 关键字。

`virtual` 关键字的作用是允许推断类中与基类中具有同名的部分能够通过指针被正确调用，更准确地说，当指针类型是指向基类的指针但它指向一个推断类对象时也是如此。

### 抽象基类

抽象基类和普通多态类之间的根本区别在于，由于抽象基类中至少有一个部分需要被使用，因此我们无法为它创建实例（对象）。尽管如此，一个无法实例化对象的类并不是完全没用的。我们可以创建它的指针并利用它所有的多态能力。

虚拟成员和动态类为 C++ 赋予了多态特性，这使得面向对象的编程在大型活动中成为一种非常有用的工具。显然，我们已经看到了这些特性的非常简单的应用，但这些特性可以与对象的展示或渐进分配的对象相结合。

## 函数模板和类模板

函数模板是用于处理非特定数据类型的唯一函数。这允许我们创建一个函数布局，其实用性可以调整到多种类型或类，而无需为每种类型重新编写整个代码。

在 C++ 中，可以通过模板参数来实现。模板参数是一种特殊的参数，可以用于将类型作为参数传递：就像普通参数用于将值传递给函数一样，格式参数允许向函数传递类型。这些模板可以像使用其他普通数据类型一样使用这些参数。

使用的语法如下：

```cpp
template <typename identifier> function_declaration;
template <class identifier> function_declaration;
```

上述两个语句具有相同的含义和效果。唯一的区别在于关键字 `typename` 或 `class` 的使用。

### 示例：

为了说明函数模板的概念，让我们创建一个返回其所提供的两个参数中较大值的模板。

```cpp
template <class eType>
eType GetMaxVal (eType x, eType y)
{
    return (x > y) ? x : y;
}

int a, b;
GetMaxVal<int>(a, b);
```

在这个示例中，使用了 `eType`，它代表尚未指定的类型类型。为了调用此函数，你需要执行：

`<函数名> <数据类型> (<参数>)`

 

例如，如果你想为 `int` 调用 `GetMaxVal`，那么你可以进行如下调用：`GetMaxVal<int>(a, b)`。在这里，`a` 和 `b` 是任何整数。

### 示例代码：

```cpp
#include <iostream>
using namespace std;

template <class X>
X GetMaxVal (X a, X b)
{
    X result;
    result = (a > b) ? a : b;
    return (result);
}

int main () {
    int x = 1, y = 2, z;
    long i = 21, j = 10, k;
    z = GetMaxVal<int>(x, y);
    k = GetMaxVal<long>(i, j);
    cout << z << endl;
    cout << k << endl;
    return 0;
}
```

在这个示例中，`X` 被用作数据类型。然而，你可以使用你喜欢的名称。对 `GetMaxVal` 的两次函数调用针对不同的数据类型：`int` 和 `long`。事实上，它也被用作创建新对象的数据类型。函数的输出是调用该函数时对应的数据类型。

在上面的示例中，如果你使用参数 `x` 和 `y` 调用函数，编译器将隐式地使用 `int` 调用该模板函数。然而，如果你使用 `long` 参数调用函数，编译器将为 `long` 调用该模板函数。在这些情况下，不需要指定 `<int>` 或 `<long>`，因为用于调用模板函数的参数已经声明过了。因此，接下来的函数调用就足够：`GetMaxVal(x, y);`

然而，请注意，你不能在函数调用中使用不同类型的参数。如果你需要执行此类操作，那么你必须在模板函数中定义两个如 `X` 不同的数据类型。




就像函数模板一样，你也可以选择编写类模板。该类的成员可以使用用户定义的类型作为参数。

```cpp
template <class myType>
class myNums {
    myType vals [2];
    public:
    myNums (myType one, myType two)
    {
```

## 异常处理

异常处理提供了一种应对系统中异常情况（如运行时错误）的方法，通过将控制权转移到称为处理器（handlers）的特殊函数来实现。然而，为了处理异常，你需要将代码放在异常检查块中。

当该块内部出现异常情况时，会抛出一个异常，并将控制权转移到特殊的特殊情况处理器。如果没有抛出特殊情况，代码将正常继续，所有的处理器都被忽略。

通过在 `try` 块内部使用 `throw` 关键字抛出异常。处理器用 `catch` 关键字声明，它必须必须紧跟在 `try` 块之后：

```cpp
#include <iostream>
using namespace std;
int main () {
    try
    {
        throw 0;
    }
    catch (int e)
    {
        cout << "Catch Block Entered!"
        cout << "Exception ID:" << e;
        cout<<"\n";
    }
    return 0;
}
```

这段代码输出了 `cout` 中的语句以及异常 ID。

异常处理器用 `catch` 关键字声明。显而易见，它位于 `try` 语句块之后。`catch` 语句就像一个函数，它可靠地至少有一个参数。该参数的类型至关重要，因为 `throw` 输出传递的异常类型将与其进行比对，只有当它们匹配时，异常才会被获取。

我们可以链联不同的处理器（`try` 输出），每个处理器都关联一个不同的参数类型。只有与其在 `throw` 声明中标记的异常相匹配的处理器会被执行。

在处理完特殊情况后，程序执行将在 `try-catch` 之后继续，而不是 `throw` 之后！

## 异常规范

在声明函数时，我们可以限制异常类型。它可以通过特定或隐式地通过向函数声明中添加 `throw` 附加项来抛出。

`float myFunction (char myParam) throw (int);`

这声明了一个函数 `myFunction`，它接受一个参数并返回一个 `float`。该函数可能抛出的主要异常是 `int` 的特殊情况。如果它抛出了另一种类型的特殊情况（无论是特定的还是间接的），那么 `int` 类型的处理器将无法捕获。

如果此 `throw` 指定符为空且没有类型，则意味着该函数不允许抛出异常。没有指定器的函数允许抛出任何类型的特殊情况。

## 标准异常

C++ 标准库提供了一个基类，专门用于声明作为异常抛出的对象。这些存在于头文件 `<exception>` 中。

建议将所有动态内存分配放在 `try` 块中，以获取这种异常来执行清理工作，而不是异常终止（这是当这种特殊情况被抛出且未被捕获时发生的情况）。

## 类型转换

将给定数据类型的某种解释转换为另一种数据类型称为类型转换。我们到为止已经看到了一些类型转换的方法。

### 隐式转换




某些更改不需要任何操作符。当值被复制到另一种类型时，这些更改会自然完成。`a` 的值已从 `short` 提升为 `int`，而我们不需要指定任何数据类型转换操作符。这被称为隐式转换。

隐式转换影响基本数据类型并允许转换，例如数值类型之间的转换（`short` 到 `int`、`int` 到 `float`）以及某些指针变化。这些更改中的某些可能意味着精确性的损失，编译器会带有警告进行处理。这可以通过显式转换来避免。

隐式转换同样包含了构造函数或操作符的更改，这会影响到包含特定构造函数或具有执行转换管理能力的类。

### 显式转换

`C++` 是一门强大的编程语言。许多转换，特别是那些建议对值进行另一种解释的转换，都需要显式转换。我们目前已经见过这种类型的类型转换文档，即类 C 语言风格和函数式。

对于大多数基本数据类型，这些转换的用性已足够需求。然而，这些操作符可能会随机地应用于类和指向类的指针上，这可能导致代码在语法上是正确的，但在运行时会导致错误。

传统的类型转换允许将任何指针转换为任何其他指针类型，无论它们所指示的类型是什么。随后的成员调用可能会导致运行时错误或意想不到的结果。

考虑到控制类之间此类转换的最终目标，我们有四个特定的操作符：`reinterpret_cast`、`dynamic_cast`、`const_cast` 和 `static_cast`。它们的功能说明如下。

### dynamic_cast

`dynamic_cast` 可能仅用于对象的指针和引用。它的设计是为了确保转换后的结果是目标类的合法完整对象。因此，当我们从一个类转换到其基类之一时，`dynamic_cast` 是有效的。

### static_cast

`static_cast` 可以在指针和相关类之间执行转换，不仅是从派生类到其基类，还可以从基类到其派生类。这保证了只要转换了正确的对象，类就是安全的。然而，在运行时不会进行安全检查以确认被转换的对象是否正确。

这依赖于开发者来确保转换是安全的。另一方面，它避免了 `dynamic_cast` 的安全检查开销。`static_cast` 还可以用于执行其他可以被验证执行的非指针转换，例如基本数据类型之间的标准转换。

### reinterpret_cast

`reinterpret_cast` 将任何指针类型转换为任何其他指针类型，即使是随机的类。操作结果是将值从一个指针到另一个指针的简单位复制。允许所有的指针转换：不检查所指向的元素或指针类型本身。

它还可以将指针转换为或从整数类型转换为指针。整数值表示指针的配置是平台特定的。主要的保证是，转换到数字类型足够大以完全包含它，被认为有能力转换回相应的指针。

然而，由 `reinterpret_cast` 可能执行的而 `static_cast` 无法执行的更改在 C++ 中没有特定的用途，它们是底层操作，理解这些操作会产生在很大程度上特定于框架的代码，因此不具有通用性。

这是重要的 C++ 代码，尽管这并不预示着什么，因为现在我们有一个指向矛盾的类对象的指针，因此对其进行解引用是有风险的。

### const_cast

这种类型转换控制对象的常量属性，可以被设置或取消。

### typeid

`typeid` 允许检查表达式的类型：`typeid (expression)`

该操作符返回一个指向 `type_info` 类型对象的引用，该类型在标准头文件 `<typeinfo>` 中定义。返回的属性值可以使用操作符 `==` 和 `!=` 与另一个进行比较，或者可以利用其 `name()` 部分获取有关信息类型或类名的无效结束字符串标识符。

当 `typeid` 连接到类时，`typeid` 利用 RTTI 来获取元素对象的类型。当 `typeid` 连接到类型为多态类的代码时，结果是最确定的完整对象的类型。

## 预处理器指令

我们示例代码中包含的虽不是程序代码但要求预处理器处理的行被称为处理器指令。这些行始终被频繁使用，并可以通过哈希符号 (#) 来识别。预处理器在代码正式汇编之前执行。通过这种方式，预处理器在语句创建任何代码之前处理所有这些指令。

这些预处理器指令仅扩展到单行代码。当发现换行符时，预处理器指令被认为结束。预处理器指令末尾通常不使用分号（`;`）。预处理器指令跨越多行的主要方法是在行末尾的换行符之前加上反斜杠（\）。

### 宏定义

为了描述预处理器宏，我们可以使用 `#define`。其语法为：

```
#define <标识符名称> <替换代码>
```

当预处理器发现此指令时，它会将代码剩余部分中任何标识符出现的情况通过替换进行替换。这种替换可以是代码、语句、片段或任何内容。预处理器不理解 C++。它基本上是将任何标识符出现的情况进行替换。

示例：

```cpp
#define getMaxVal(x,y) x>y?x:y
```

这将通过替换解释替换任何 `getMaxVal` 的出现及其两个参数，同时用其标识符替换每个表达式，正如你假设它是一个函数时预期的那样。

宏不受结构影响。宏一直持续，直到使用 `#undef` 预处理器指令取消。函数宏定义在替换序列中识别两个独特的操作符（`#` 和 `##`）。如果在参数用作替换方案之前使用了操作符 `#`，则该参数将被替换为字符串字符串（就像封装在引号之间一样）。

`#ifndef` 服务于相反的操作：`#ifndef` 和 `#endif` 之间的代码仅在指定的标识符尚未被定义时才被编译。

`#if`、`#else` 和 `#elif`（即 "else if"）指令用于在编译它们包含的代码之前指示满足某些条件。`#if` 或 `#elif` 之后的条件可以评估常量表达式，包括宏表示。

### 关闭文件

当调用此函数时，流对象可以被用于打开另一个记录，该文档再次可以通过不同的方法打开。如果对象在析构时仍连接到已打开的文档，析构函数自然会调用 `close()`。

### 文本文件

内容文档流是指在打开模式中排除 `ios::binary` 要求的流。这些记录旨在存储内容，因此我们输入或从从中输出的所有值都可以经历一些设计更改，这些更改与它们严格的二进制值没有本质区别。

除了 `eof()`（检查是否已到达文档末尾）外，还有其他函数可以检查流的状态（每一个都返回一个 `bool` 值）。此外，还有 `bad()`、`good()` 和 `eof()` 等其他可用函数。

为了重置由任何这些函数之一检查的状态标志的特定目标，我们最近看到可以使用 `clear()`，它不接受参数。

### get 和 put 流指针





所有的 i/o 流都至少有一个输入流指针。`ifstream` 与 `istream` 一样，有一个名为 `get pointer`（获取指针）的指针，它用于指示在后续信息操作中要读取的组件。

- 如果读取或组合操作失败，则返回 `true`。例如，当我们尝试连接一个未以写入模式打开的文档，或者我们尝试写入的设备没有足够留空间时。
- 在与 `bad()` 相同的情况下返回 `valid`；此外，在发生格式错误时也会返回，例如当尝试读取一个数字时遇到一个顺序字符时。
- 如果用于读取的记录到达末尾，则返回 `true`。

它是最非排他的状态标志位：在调用任何一个之前的成员会返回真（true）的情况下，它会返回 `false`。

`ofstream` 与 `ostream` 一样，有一个名为 `put pointer`（输出指针）的指针，它用于指示后续组件必须写入的区域。最后，`fstream` 从 `iostream` 继承了 `get` 和 `put` 指针（而 `iostream` 本身是由 `istream` 和 `ostream` 决定的）。这些指示流内部读取或写入区域的内部流指针可以通过相应的函数进行控制：

`tellg()` 和 `tellp()`

这两个函数没有参数，并返回一个 `pos_type` 类型的值，这是一种整数数据类型，指示 `get stream pointer`（对应 `tellg`）或 `put stream pointer`（对应 `tellp`）当前的位置。

`seekg()` 和 `seekp()`

这些函数允许我们更改 `get` 流指针和 `put` 流指针的位置。它们都针对两个不同的模型进行了重载。主要的模型是：

```cpp
seekg ( position );
seekp ( position );
```

利用此模型，流指针将被明确地更改到指定的位置（从记录的最早开始点计算）。该参数的类型与 `tellg` 和 `tellp` 返回的类型相同：`pos_type` 类型，即整数值。

这些成员的另一个模型是：

```cpp
seekg ( balance, heading );
seekp ( balance, heading );
```

利用此模型，`get` 或 `put` 指针的位置将被设置为相对于参数 `course` 控制的某个特定点的偏移值。`balance` 的类型为 `off_type`，也是一个数字。此外，`heading` 的类型是 `seekdir`，这是一个枚举类型（enum），决定了从哪个点开始计算偏移量，它可以取以下任何一个属性：

随后的情况利用了我们最近看到的成员来获取文档的大小：

- `ios::beg` - 从流的最早开始点计算偏移
- `ios::curoffset` - 从流指针当前的位置计算
- `ios::end` - 从流的末尾计算偏移

### 二进制文件

在二进制记录中，使用提取和插入运算符（`<<` 和 `>>`）以及 `getline` 等函数进行输入输出信息是无效，因为我们不需要组织任何信息，且信息可能不会使用文本文档用于独立组件的分隔代码。记录流包含两个专门用于连续输出输出信息的函数：`write` 和 `read`。

语法：

```cpp
write ( memoryBlock, size );
read ( memoryBlock, size );
```

`memoryBlock` 的类型是“字符指针”（`char*`），指示一个字节簇的位置，读取的信息组件存于此处，或要写入的信息组件从此处取出。`size` 参数是一个整数，指示从/到内存块中读取或写入的字符数量。

示例：

```cpp
#include <fstream>
#include <iostream>

using namespace std;

char * memoryBlock;
ifstream::pos_type size;

int main () {
    ifstream newFile ("sample.bin", ios::in|ios::binary|ios::ate);
    if (myFile.is_open())
    {
        mySize = newFile.tellg();
        memoryBlock = new char [size];
        newFile.seekg (0, ios::beg);
        newFile.read (memblock, size);
        newFile.close();
        cout << "the complete document substance is in memory"; delete[] memoryBlock;
    }
    else
        cout << "Not able to open document";
    return 0;
}
```

在此示例中，整个文档被读取并存储在内存中。

### 缓冲区与同步

当我们处理文档流时，它们涉及到 `streambuf` 类型的内部支持。该缓冲区是一个内存块，是流和物理记录之间的介质。缓冲器的刷新（flushing）强制在流为输出流时将其上所有可用数据写入物理内存，并在流为输入流时释放内存。这一过程被称为同步。可以通过调用函数 `sync()` 或借助借助操纵符（manipulators）显式执行。
