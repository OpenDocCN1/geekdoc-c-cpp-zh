### 8.1 引言

我们在第 7 章已经看到，通过引入一个计数器，并在之后使用 if 语句对其进行测试，可以重复执行程序中的某个代码段。虽然这种方法对于所有实际用途来说都相当令人满意，但我们需要初始化并递增计数器，并在程序中合适的位置测试其值，以完成循环。例如，假设我们要计算 1 到 10 之间所有整数的平方和，可以使用 if 语句编写如下程序：

```
sum = 0;
n = 1;
loop:
    sum = sum + n*n;
    if (n == 10)
        goto print;
    else
    {
        n = n+1;
        goto loop;
    }
print:
```
