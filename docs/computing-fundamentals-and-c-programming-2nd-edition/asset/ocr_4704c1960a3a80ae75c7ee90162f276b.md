# WORKED-OUT PROBLEM 13.2

Write a program to illustrate the use of indirection operator `*` to access the value pointed by a pointer.

The program and output are shown in Fig. 13.8. The program clearly shows how we can access the value of a variable through a pointer. Note that the variable ptr contains the address 6040 and the value of pointer ptr is 10. Further, you may also note the following important points:

```
```c
Program main()
{
    int x, y;
    int *ptr;
    x = 10;
    ptr = &x;
    y = *ptr;
    printf("The value of x is %d", x);
    printf("The value of y is %d", y);
    printf("The address of x is %u", &x);
    printf("The address of ptr is %u", &ptr);
    printf("The value of ptr is %u", ptr);
    printf("The value at *ptr is %d", *ptr);
}

# 2.7 BINARY ARITHMETIC OPERATIONS

The purpose of this section is to introduce binary arithmetic because the computer can handle only binary numbers. As you can see, binary arithmetic operations are performed in exactly the same manner as decimal arithmetic. The four basic arithmetic operations are: addition, subtraction, multiplication, and division. However, they are not carried out by the computer in the same way as we do. The arithmetic operations are carried out with two digits 0 and 1 and is the binary operations. The different operations performed by the computer are:

+   - Binary addition
+   - Binary subtraction
+   - Binary multiplication
+   - Binary division
