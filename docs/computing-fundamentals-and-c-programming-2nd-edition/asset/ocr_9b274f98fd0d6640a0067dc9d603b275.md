+   4. Repeat step 5 to 11.
+   5. If n<=x num, then go to 12
+   6. Else
+   7. Divide n by x.
+   8. If the remainder of the division is 0, print x.
+   9. Set n=n/x.
+   10. Increment x by 1 and go to step 5.
+   11. Endif
+   12. Exit.
