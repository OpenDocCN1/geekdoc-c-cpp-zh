# Wi-Fi

As we mention in Chapter 11, Wi-Fi is typically the fastest wireless network you can use to surf the web, send email, and perform other Internet tricks on your iPhone, including (in some cases) making calls. You use the Wi-Fi setting to determine which Wi-Fi networks are available to you and which one to exploit based on its signal.

Tap Wi-Fi, and you see any Wi-Fi networks in range, as shown in Figure 14–2.

A signal-strength indicator can help you choose the network to connect to if more than one is listed; tap the appropriate Wi-Fi network when you reach a decision. If a network is password-protected, you see a lock icon.

You can turn on or off the Ask to Join Networks working. Networks that the iPhone is already familiar with joined automatically, regardless of which one you use. If the Ask feature is on, you're asked joining a new network. If it's off, you have to select a new network manually.

If you used a particular network automatically in the past but no longer want your iPhone to join it, tap the i-in-circle to select (in Wi-Fi settings), and then tap Forget Network. The iPhone developer provides a quick case of selective amnesia. If you haven't selected a given Wi-Fi network, you'll see the option to Join Network instead of Forget This Network.
