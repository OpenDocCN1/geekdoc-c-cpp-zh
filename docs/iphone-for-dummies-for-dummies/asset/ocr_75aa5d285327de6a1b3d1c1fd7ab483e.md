# Making conference calls

Now suppose caller number one and call number two know each other. You'd like to play matchmaker so they get to know each other. Tap Merge Calls (the button appears automatically when you've added a second call so that all of you can chat. At first, the phone number of each caller will scroll to the top of your screen a few seconds later, the ticker is replaced by the names of the callers.

Now assume you have to talk to your entire sales team at once. It's time to initiate a full-blown conference call, which effectively takes this merge call to be extreme. You can merge up to five calls at a time. In fact, creating a conference call on the iPhone may be simpler than getting the same five people in a physical room at the same time.

Start by making a call and placing the caller on hold as noted in the preceding section, "Juggling calls." Tap Add Call to make another call, and then tap Merge Calls to bring everyone together. Repeat this exercise to add the other calls.
