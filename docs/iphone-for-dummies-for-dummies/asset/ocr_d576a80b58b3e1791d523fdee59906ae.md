# HOW DOES IT DO?

The Maps app determines your approximate location by using iPhone's Location Services, which uses available information from your wireless data network, local Wi-Fi network (if Wi-Fi is turned on), Bluetooth, and GPS. If you're not using Location Services, turning it off (at SettingsGeneralGeneralLocation Services) will conserve your battery. Don't worry if Location Services is turned off when you tap the current location icon—you'll be prompted to turn it on. Note that Location Services may not be available in all areas at times. One last thing: The arrow in the status bar whenever any app (not Maps) is using Location Services and GPS to determine your current location.

When you are typing, tap Search. After a few seconds, a map appears. If you searched for a single location, it's marked with a single bubble. If you searched for a category (Pizza 60611, for example), you see multiple bubbles, or for each matching location (pizza joints in or close to the 60611 zip code), as shown in Figure 13-2.

If a bubble has a number rather than a name, you'll see that number of places when you zoom in (and then you find out how to do in the next section).

The Maps app is adept at interpreting search terms and finding the right place. After you've used the app a few times, we're sure you'll be amazed as we are.

When you start a search in Maps, icons pop up just below the search field: Restaurants, Fast Food, Coffee Shops, Groceries, Shopping Centers, Bars, Hotels, and Gas Stations. Tap an icon to see nearby establishments of type.
