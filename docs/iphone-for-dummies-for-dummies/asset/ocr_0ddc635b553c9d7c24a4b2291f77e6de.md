Older way to include pictures (or video) in an email is to tap the Photos icon on the screen and then find the photo you want to send. Tap the share icon (see the margin), in the lower-left corner of the screen, and then tap the Mail button.

An message appears-screen with the photo already attached. The image appears to be embedded in the body of the outgoing message and appear in the same way to the recipient, but the recipient receives the image as a regular email. Just address the message and type whatever text you like, as you did for an-text message in the preceding section, and then tap the Send button. You again choose a file size for your picture: Small, Medium, Large, or Actual Size.

# Saving an email message so that you can send it later

Sometimes you start an email message but don't have time to finish it. When happens, you can save it as a draft and finish some other time.

Figure 12-19:
You can admire an inserted picture before sending it in an email.

Here's how: Start an email message as described in one of the two sections. When you're ready to save the message as a draft, tap the Cancel button in the upper-left corner of the screen and two buttons appear. Tap the Save Draft button you want to save the message as a draft and complete it another time; tap the Delete Draft button to ditch your efforts; or tap Cancel to return to the message and continue it to perfection.

If you tap the Delete Draft button, the message disappears immediately without a second chance. Don't tap Delete unless you mean it.

To work on the message again, tap the Draft mailbox for the account in question. All messages you saved as drafts hang out in mailbox. The one you want to resume working on stays until it reappears on the screen. When you're finished, tap Send to send it or Cancel to go through the drill of saving it as a draft.

The number of drafts appears to the right of the Drafts folder, the same way that the number of unread messages appears to the right of other mail folders, as your inbox.
