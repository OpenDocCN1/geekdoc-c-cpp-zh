### 4.4 Function and Pointer

```c
}
```

### 5.2.2 gets() and puts() functions

gets() is used to read text. It stops reading if you type a newline (ENTER key). Unfortunately, gets() is an unsafe function. We can use fgets() to read text with a length limitation.

For testing, we add the get_puts() function to the keyboard.c file, and write this code.

```c
#include <stdio.h>

void gets_puts();

int main() {

    gets_puts();

    return 0;
}

void gets_puts(){
    printf("-----unsafe input-----\n");
    char name[256];

    printf ("Your name: ");
    gets (name);
    printf ("name: %s\n", name);
    puts(name);

    printf ("-----fgets() input-----\n");
    name[0] = '\0'; // clear
    printf ("Your name: ");
    fgets(name,256,stdin);
    printf ("name: %s\n",name);
    puts(name);
}
```

### 5.4 Writing Data Into A File

We can write data into a file. The following is the algorithm for writing data:

- Create a file using fopen() function

- Close a file using fclose() function

For testing, we create data in a file, **demo.txt**. For implementation, create a file called **filewrite.c**, and write this code.

```c
#include <stdio.h>

int main(int argc, const char* argv[]) {

        fputs("fputs message\n", f); // no format

}
```
