## 1. Development Environment

This chapter explains how to start with development environment using C.

### 1.2 Compilers

There are many C compilers to develop C programs. In this book, we use GCC as C compiler for Linux, Mac and Windows. For Windows users, you also can use Visual C++ compiler.

#### 1.2.1 Linux

Installation of GCC C is easy. For Ubuntu Linux, you can do it using the console and write this script:

```bash
$ sudo apt-get install build-essential
```

If installation has already finished, you can check GCC version on console and write the script as below:

```bash
gcc --version
```

![](img/4e69d9ab92a6fdfd6a6bac3671deb952_9_0.png)

You will see gcc version, for instance shown in Figure above.

#### 1.2.2 Windows

If your computer has Windows platform, you can use **Cygwin**. Download it on http://cygwin.com/setup.exe and then run it.

### 1.4 Hello World

Now we start to write the first program using C.

Firstly, open your text editor and create a new file, called **hello.c**.

Let’s write this code:

```c
#include <stdio.h>

int main() {
        printf("Hello C\n");
        return 0;
}
```

Save this file.

Now open your Terminal and compile this file.

```bash
sudo gcc hello.c
```

![](img/4e69d9ab92a6fdfd6a6bac3671deb952_13_0.png)

If you check, you will get file **a.out**. GCC will generate an a.out file if you don’t specify an output file name. You can define the output compiled file as follows:

```bash
sudo gcc hello.c -o hello
```

## HOW TO BREAK UP WITH YOUR MUSE

A FIELD GUIDE TO CREATIVE RECOVERY

Write faster with perfect concentration by breaking up with your muse. Artists who depend on inspiration fail. Learn how to identify your muse, assess the attachment, develop a ritual, and create new habits for sustainable creative work.

- Identify your muse
- Assess the attachment
- Develop a ritual
- Create new habits

The following field guide is a compilation of the artistic and creative recovery techniques used by authors to sever ties with their muse forever.

> The artist is free, but the muse is a ball and chain. - J. T.

| Type | Characteristics | Prescription |
| --- | --- | --- |
| Type One: The Romantic Muse | Mood swings, requires inspiration, waxing and waning energy | Use a schedule, not a feeling; work in consistent blocks |
| Type Two: The Monumental Muse | Overwhelming, full of grand ideas, none of which are finished | Cut projects into smaller pieces; finish every day |
| Type Three: The Distracted Muse | Feeds on novelty, social media craving, disrupts workflow | Build a single daily workspace and one list of tasks |
| Type Four: The Competitive Muse | Compares you to others, fuels jealousy and procrastination | Work in isolation; compare only to yesterday's output |
| Type Five: The Critic Muse | Judges your first draft, simplifies nothing, chases perfection | Write ugly first drafts; edit only in separate sessions |

### MUSE TYPE ONE: THE ROMANTIC MUSE

This is the passionate lover of the art. It wants you to wait for the perfect moment, the warm glow, the beautiful sunrise. It gives you sensations and takes away your discipline. The cure: ignore the feeling. Set an alarm. Work begins when the alarm rings, not when the inspiration sings.

In practical terms, schedule your writing for the same time each day. This allows the subconscious to be ready. Lean into the boring ritual of showing up. Over time, routine becomes charismatic and the muse loses its power.

## 2. Basic C Programming Language

### 2.1 Common Rule

In C language if you write a line of code we must write semicolon (;) at the end of code.
Here is the syntax rule:

```
syntax_code;
```

### 2.2 Declaring Variable

To declare a variable called *myvar1*, write the following:

```c
int myvar1;
```

**int** is data type.

The following is the list of common data types you can use in C language.

- int
- long
- float
- char
- double

We can also write many variables as follows:

```c
int myvar1, myvar2;
```

Once declared, these variables can be used to store data based on its data type.

### 2.3 Assigning Variables

Variable that you already declare can be assigned a value. It can be done using the equals sign (=). For example, variable myvar1 will assign the number 100, you would write this:

```c
int myvar1 = 100;
```

You can also declare as below:

```c
int myvar1;
myvar1 = 100;
```

You must assign a value to a variable properly based on data type. If not, you will get an error on compiling process. For instance, write this code:

```c
#include <stdio.h>

int main() {
    int n;
    int i, j;

    n="hello";

    return 0;
}
```

Save this code as a file, called var1.c.

Try to compile this file. You will get a warning message as shown in Figure below:
