# ## 19.4 Stacks

You learned the notion of a stack in Section 6.12, Section 15.7.1, Stack Adapter and Section 18.2. Recall that a node can be added to a stack and removed from a stack only at its *top*, so a stack is referred to as a *last-in, first-out (LIFO)* data structure. One way to implement a stack is as a *constrained* version of a linked list. In such an implementation, the link member in the last node of the stack is set to `nullptr` to indicate the *bottom* of the stack.

The primary member functions used to manipulate a stack are push and pop. Function push *inserts* a new node at the top of the stack. Function pop *removes* a node from the top of the stack, stores the popped value in a reference variable that's passed to the calling function and returns true if the pop operation was successful (false otherwise).
