
## 第2.7节 决策：相等运算符与关系运算符

- if语句（第53页）允许程序根据条件是否满足来采取替代操作。if语句的格式为

```cpp
if ( condition )
    statement;
```

- if语句中的条件通常使用相等运算符和关系运算符（第53页）构成。使用这些运算符的结果始终是true或false。

- using声明（第55页）

```cpp
using std::cout;
```

告知编译器在哪里找到cout（命名空间std），并免去重复编写std::前缀的需要。

- using指令（第55页）

```cpp
using namespace std;
```

使程序能够使用所包含的任何C++标准库头文件中的所有名称。
