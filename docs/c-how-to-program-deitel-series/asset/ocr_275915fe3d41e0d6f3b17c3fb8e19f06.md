# Linux安全基线

1. 账号和口令安全

+   - 检查项：检查空密码账号
+   - 操作：`awk -F: '($2==""){print $1}' /etc/shadow`
+   - 加固：为所有空密码账号设置强密码

+   - 检查项：检查弱口令
+   - 操作：使用 John the Ripper 等工具进行口令强度检测
+   - 加固：设置密码复杂度策略，如 `minlen=8`

2. 授权与访问控制

+   - 检查项：检查用户 sudo 权限
+   - 操作：`cat /etc/sudoers`，检查是否有不必要的授权
+   - 加固：遵循最小权限原则，删除不必要的 sudo 授权

3. 日志审计

+   - 检查项：检查日志服务是否开启
+   - 操作：`systemctl status rsyslog` 或 `systemctl status syslog-ng`
+   - 加固：确保日志服务自启动并配置日志轮转
