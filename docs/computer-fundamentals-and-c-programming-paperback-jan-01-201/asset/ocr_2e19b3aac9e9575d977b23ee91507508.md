# 17.11 POINTERS TO FUNCTIONS

*A pointer to a function* is a powerful and useful tool that enables a function f2 or f3 to be passed as an argument to a function f1. Because the decision to select f2 or f3 can be made at runtime, the entire process of declaring, assigning and invoking functions through their pointers can be somewhat tricky. However, it need not be so as you’ll soon find out.

Just as a variable has an address in memory, so does a function. You can set a pointer to point to the base address of the function code and its variables in memory. The variable representing a pointer to a function has to be declared, a function assigned to it, and then dereferenced to execute the pointed-to function.
