# ## 4.1 THE C LANGUAGE

The C language was created by Dennis Ritchie of AT&T (now Lucent) fame in the 1970s. C was created with an unusual objective—not to replace Fortran or BASIC—but to rewrite the code for the UNIX operating system. In those days, operating systems were written in assembly language, but Ritchie’s out-of-the-box thinking produced a language that was portable, compact and fast. In retrospect, we find that he achieved the best of both worlds. Today, the UNIX/Linux operating systems run on practically any hardware, while C is widely favored for programming.

But the C originally created for UNIX systems is significantly different from the one used on Windows computers (often, Visual Studio) or iPhones (Objective C). Ritchie’s C could make direct calls (called *system calls*) to the UNIX operating system. The UNIX OS does all of its work using a standardized set of these system calls. However, non-UNIX systems don't use most of these calls, so UNIX C programs containing these calls would fail to compile on other systems. But C had too many advantages to be ignored for this reason alone.
