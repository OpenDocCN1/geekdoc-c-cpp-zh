| Function | Description |
|---|---|
| `strcat(char *dest, const char *src)` | Appends `src` to `dest`. Returns pointer to `dest`. |
| `strncat(char *dest, const char *src, size_t n)` | Similar to `strcat` except that at most `n` characters of `src` will be appended. |
| `strcmp(const char *s1, const char *s2)` | Compares `s1` to `s2`. Returns negative, zero or positive integer depending on whether `s1 <`, `==`, or `> than s2. |
| `strncmp(const char *s1, const char *s2, size_t n)` | Similar to `strcmp` except that at most `n` characters of `s1` and `s2` are compared. |
| `strchr(const char *s, int c)` | Searches character `c` in string `s`. Returns pointer to first occurrence of `c` in `s`, or NULL if `c` is not found in `s`. |
| `strrchr(const char *s, int c)` | Similar to `strchr` except that the function returns a pointer to last occurrence of `c` in `s`, or NULL if `c` is not found in `s`. |
| `strstr(const char *s1, const char *s2)` | Searches `s2` in `s1`. Returns pointer to `s2` or NULL if `s2` not found in `s1`. |
| `sprintf(char *s, cstring, var1, var2, ...)` | Writes `var1`, `var2`, ... to string `s` using the formats specified in `cstring`. Returns number of characters printed on success, a negative value on error. |
| `sscanf(char *s, cstring, &var1, &var2, ...)` | Reads data from string `s` using the formats specified in `cstring` and saves the items in variables `var1`, `var2`, ..., whose addresses are specified as arguments. Returns number of items successfully matched or EOF if end of input is encountered before conversion of first item. |

# I. File-handling Functions (stdio.h)

| Function | Description |
|---|---|
| `fopen(pathname, mode)` | Opens file whose name is represented by `pathname`. File can be opened in read ("r"), write ("w") or append ("a") mode. Using the + suffix, file can be opened in the following modes: read-write ("r+"), read-write with truncation ("w+"), read-append ("a+"). Returns pointer to FILE, NULL on error. |
| `fclose(FILE *stream)` | Closes file associated with `stream` after flushing the buffer. Returns 0 on success, EOF on error. |
