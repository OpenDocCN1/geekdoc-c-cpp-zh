| Operator | Significance | Associativity |
|---|---|---|
| `( )` | Function call | |
| `[ ]` | Array subscript | |
| `.`, `->` | Member selection (for structures) | |
| `++`, `--` | Postfix increment/decrement | L-R |
| `++`, `--` | Prefix increment/decrement | |
| `+`, `-` | Unary | |
| `!` | Logical NOT | |
| `sizeof` | Size of data or type | |
| `(data type)` | Cast | |
| `*`, `&` | Dereference/address (for pointers) | R-L |
| `*`, `/`, `%` | Arithmetic | L-R |
| `+`, `-` | Arithmetic (binary) | L-R |
| `<<`, `>>` | Bitwise shift left/right | L-R |
| `<`, `<=`, `>`, `>=` | Relational | L-R |

| `|` | Bitwise OR | L-R |

| `&=`, `^=`, `|=`, `<<=`, `>>=` | Assignment (bitwise) | R-L |
| `,` | Comma (expression delimiter) | L-R |

# C. Character-handling Functions (ctype.h)

| Function | Description |
|---|---|
| `isalnum(c)` | Returns true if c is an alphanumeric character. |
| `isalpha(c)` | Returns true if c is an alphabetic character. |
| `isascii(c)` | Returns true if c is a 7-bit ASCII character within the range 0 to 127. |
| `isblank(c)` | Returns true if c is a blank character (space or tab) (C99). |
