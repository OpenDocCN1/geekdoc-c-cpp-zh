Loops work great with arrays. The array has a Length property, which tells you how many elements are in the array.

Add the following:

```
for (int i=0; i < writers.Length; i++)
{
    string writer = writers[i];
    Console.WriteLine(writer);
}
```

This loops through all the elements of the array and print each element to the console.
Click the Run it button and you'll see all the names.
