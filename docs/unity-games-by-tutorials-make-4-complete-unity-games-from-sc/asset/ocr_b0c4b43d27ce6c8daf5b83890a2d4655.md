These variables represent the clips for each sound in the game. You've made them all public so you can set them to the clips in the Unity editor.

**Save** and return to Unity. Select **SoundManager** in the Hierarchy, open the **Sounds** folder, and assign the following sounds to the SoundManager:

+   - Gun Fire: **bw_shoot**
- Upgraded Gun Fire: **bw_triple_shot**
- Hurt: **bw_marine_death**
- Alien Death: **bw_alien_death**
- Marine Death: **bw_marine_death**
- Victory: **bw_victory**
- Elevator Arrived: **bw_elevator**
- PowerUp Pickup: **bw_powerup_pickup**
- PowerUp Appear: **bw_powerup_appear**
