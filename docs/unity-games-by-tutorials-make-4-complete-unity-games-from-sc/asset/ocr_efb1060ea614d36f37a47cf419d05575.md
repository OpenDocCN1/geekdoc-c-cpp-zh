# Unity Games by Tutorials

First, you'll create the animations, and in Chapter 13, you'll write scripts to hook them up with triggers, so that they work during gameplay. In this chapter, you'll script the running animation and do some other pre-work for the Character Controller.

In the Hierarchy, click **SoyBoy** then open the **Animation** editor to display it. You may need to use the **Window ▸ Animation** menu option. You can click the **Create** button in the **Animation** editor. You should see the **Create New Animation** dialog.

Make a new sub-folder named **Animations** under **Assets** in the Project browser, save the animation to the new sub-folder. Name it **RunAnimation.anim.

The Animation editor will switch to a Timeline view that has RunAnimation.anim ready for editing. Your task is to make little cube of tofu run! You'll use the sprites you sliced earlier and use the **SuperBoySpriteSheet.png** spritesheet.

> Note: Unity actually created two files in the Animations folder. RunAnimation.anim, the file you're editing, and an Animation Controller called SoyBoy, controller that helps control animation states.

With the SoyBoy GameObject selected and the Animation window, navigate to the Sprites folder in the **Project browser**.

Expand **SuperBoySpriteSheet.png** to reveal the sliced sprites. Select **run_0**, press and hold Shift then click **run_14** to select all. Drag and drop the whole lot onto the **RunAnimation** window timeline.

![](bbox=[0.118, 0.587, 0.858, 0.7])

They should be laid out on the timeline in order, from **run_0** to **run_14**.

![](bbox=[0.246, 0.767, 0.752, 0.836])

Float the **Animation** editor and position it next to the **Scene** view. Click the **Play** button in the Animation window and watch the **SoyBoy** animation preview. It will loop.
