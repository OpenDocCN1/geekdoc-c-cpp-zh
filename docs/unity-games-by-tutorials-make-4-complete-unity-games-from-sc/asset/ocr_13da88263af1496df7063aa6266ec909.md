On the left, you have a Property List where you select the properties you intend to animate. On the right, you have the Dope Sheet where you create keyframes — more on in a moment.

Above the dope sheet is the Timeline where you scrub back and forth on the animation to preview how it looks. Finally, above the property list, you'll see Frame Navigation where you control playback and animation events.

Animation events allow you to run code at certain frames in animation.

# Introducing keyframe animations

Unity anim objects through the use of keyframe animation.

In keyframe animation, you set up a series of pairs (time, value) to indicate how you want an object to animate over time. You don't need to specify every single second; the beauty is that the game engine will automatically calculate the values in your keyframes.

For example, say you have a cube at ($	heta$, $	heta$, $	heta$) that you want to move to ($	heta$, 10, 10, 0) two seconds later. Then you would set up two keyframes:

+   - Time 0 seconds: Position ($	heta$, $	heta$, $	heta$)
- Time 2 seconds: Position ($	heta$, 10, 10, 0)
