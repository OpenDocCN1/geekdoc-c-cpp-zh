# WTF is CR LF?

When you first open a script in Unity, you may encounter a weird dialog that looks like the following:

![](bbox=[0.236, 0.433, 0.763, 0.653])

No warning is fun, never mind those warnings that make absolutely no sense. This pesky warning relates to the line endings of the generated script files.

That's right, the cause of the problem is the *file itself.*

Whoever created the file did it in a Unix-based system, whereas you're using a Windows-based system. Unity manages line endings differently than Windows, so this error is Visual Studio's way of asking how to handle these mysterious line endings.

Simply click **OK** and Visual Studio will politely convert the line endings for you.
