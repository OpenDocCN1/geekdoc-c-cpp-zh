# Chapter 4: Physics

First, stop the game and navigate to Edit > Project Settings > Tags and Layers. The Inspector will the Tags and Layers view with the layers section expanded. The first eight layers are controlled by Unity but the rest are wide open.

There's a layer called PostProcessing which is meant for adding post-processing effects such as anti-aliasing, depth of field, motion blur and others. Since you won't be doing any post-processing, you can replace it.

Starting with layer 8 and onwards, add the following: Alien, Alien Head, Bullet, Column, Floor, Head, Player, Wall and Upgrade.
