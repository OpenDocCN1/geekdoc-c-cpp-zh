# Chapter 10: Adding Enemies

![](bbox=[0.336, 0.087, 0.663, 0.303])

Now to configure each of the pickups. Select the **PickupAmmoPrefab** in the **Resources** folder and set its Type to **1**, select the **PickupAssaultRifle** to **2**, the **PickupAmmoShotgun** to **3**, the **PickupHealth** to **4**, and finally, the **PickupArmor** to 5.

The last thing is to add for you: spinning and bouncing animation to the pickup. you just need to create the Animator. In the Project browser, select the **Animations** folder and click the **Create** button. Select **Animator Controller** and name it **Pickup**.

Double-click the **Pickup** Animator to open the Animator. Right-click in the empty grid and select **Create State > Empty**. In the Inspector, it **Spin** and set the **Motion** to **cubeSpin**.

![](bbox=[0.336, 0.577, 0.663, 0.753])

Excellent! Your pickups are ready to spin! Next, return back to the Project and select the **Resources** folder. Click the arrow next to each of the **Pickup[Type]** prefabs and select the only child prefab in each.
