# # Joining the body parts

Now that the arms are UV mapped, you can join them with the Body object. If you joined them before UV mapping them, you'd have to UV map each one separately.

Joining these three objects will help in the next chapter, Chapter 17, "Animating with Blender," when you'll be animating the entire body. It's easiest if the meshes you are animating are all in one object.

Select one of the arms, then Shift-select the other arm; Shift-select the body last. The order of selection matters! The last object selected is the one that the other objects are merged into, and it is the one that keeps its origin point.

Press Ctrl-J to join the three objects.
