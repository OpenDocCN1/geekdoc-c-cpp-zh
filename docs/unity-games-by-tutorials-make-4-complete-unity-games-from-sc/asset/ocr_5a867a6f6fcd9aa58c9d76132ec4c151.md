Switch back to your code editor and open Gun.cs.

The gun should fire when the user presses the mouse button and stop when the user releases it.

You could simply check to see if the button is pressed in Update() and call fireBullet() if so, since Update() is called every frame, that would mean your space marine would shoot to 60 times per second! Our space marine can shoot fast, but not that fast.

What you need is a slight delay between you shoot bullets. To do this, add the following to Update():

First, you check with the Input Manager to see if the left mouse button is held down.

> Note: If you wanted to check the right mouse button, you would pass in 1, and for the middle mouse button, you would pass in 2.

If the mouse is being held down, you check if fireBullet() is being invoked. If not, call InvokeRepeating(), which repeatedly calls a method until you CancelInvoke().

InvokeRepeating() needs a method name, a time to start and the repeat rate.
