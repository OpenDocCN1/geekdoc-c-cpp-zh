Now you'll need a way of distinguishing whether the player is touching the ground or a wall. Luckily you already have two methods that do these two jobs.

In order to know both of these in one simple method you'll simply combine them by creating a convenience method that calls both methods and returns true or false.

public bool PlayerTouchingGroundOrWall()

        return true;

    {
        return false;
    }
}

This method will return true if the character is either on the ground, or has a wall to the left or right of them. If they are against a wall, or on the ground, then you'll know to apply the jump value to the character rigidbody's Y velocity. Otherwise, you'll just leave the Y velocity as it is currently.
