# Setting up physics 2D layers

To get started, you need to set up the layer collision matrix. You can learn more about this matrix in Chapter 4, "Physics".

# Configuring the Layer Collision Matrix

Click **Edit > Project Settings > Tags and Layers** to open the **Tags and Layers** Inspector.

Unity provides you with a series of **User Layers** under the **Layers** rollout that you can use to define your custom collision layers, in addition to the built-in layers.

Use **Layer 8** and **User Layer 9** to create two new layers called **Player** and **Hazards**.

The player will be placed on the **Player** layer, and the saw blades will use the **Hazards** layer.

Click **Edit > Project Settings > Physics 2D** to open the **Physics2DSettings** Inspector. At the bottom you will see the **Layer Collision Matrix**. Expand it if it is not already shown.

You will see that Unity has added your new layers, **(Player and Hazards)**, to the matrix.

Uncheck the boxes where **Hazards** intersects **Hazards**, and ensure the box is checked for where **Player** intersects with **Hazards**. Make sure the box where **Default** intersects with **Hazards** is also unchecked.

![](bbox=[0.373, 0.635, 0.626, 0.803])

The reasons for these changes:

+   **Hazards intersection with Hazards removed**: This prevents saw blades that are placed close together (or overlapping) from performing collision checks, hitting each other in the physics engine, and can help increase performance.
