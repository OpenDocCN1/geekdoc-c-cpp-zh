# Chapter 11: Introducing the UI

The UI should look as follows:

![](bbox=[0.118, 0.1275, 0.872, 0.4135])

Now, create the following buttons:

> Note: Once you have created your first button, configure the text as explained in the table below. Then duplicate the button to save yourself some time.

| Type | Name | Position | Width | Height | Source Image | Transition | Highlighted Sprite | Pressed Sprite |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Button | Restart | (0, 12.0) | 260 | 60 | Pink_Grey_Texture | Sprite swap | Pink_Black_Texture | Pink_Texture |
| Button | Exit | (0, -34.5) | 260 | 60 | Pink_Grey_Texture | Sprite swap | Pink_Black_Texture | Pink_Texture |
| Button | Menu | (0, -67.0) | 260 | 60 | Pink_Grey_Texture | Sprite swap | Pink_Black_Texture | Pink_Texture |

Next, you need to configure the text on all of the buttons.

Expand the Restart GameObject and select its Text child. Change the Text to Restart, the Font Size to 22, the Font to heavy_data and the Color to White.

Do this for both the Exit and the Menu, changing the actual text to Exit and Menu, respectively.
