# Chapter 11: Introducing the UI

By Anthony Uccello

In Chapter 10, "Adding Enemies," you added pickups, spawning robots and flying bullets to your game. Now, it's time to add the user interface (UI), wave-spawning mechanics, enhanced sound and music, and the capacity to do extra damage by using the right gun for the right robot.

Pre-Unity 4.0, the UI tools were difficult. For the most part, you had to write everything inside of MonoBehaviour() and, as your UI grew in complexity, so did your code. Frankly, Unity listened to developers and, after many many years, they released their new UI in Unity 4.6.

# Getting started

In Chapter 9, "Making a First-Person Shooter," you created a canvas named GameUI. A canvas is the root object for all UI elements. You used an overlay canvas, but there other options. For instance, a world space allows you to create interfaces that can be accessed in your own game! Think of the computer terminals from Doom 3.

For a canvas to be useful, you need controls, and Unity comes with plenty of them. The most common UI elements are Image, Button and Text.
