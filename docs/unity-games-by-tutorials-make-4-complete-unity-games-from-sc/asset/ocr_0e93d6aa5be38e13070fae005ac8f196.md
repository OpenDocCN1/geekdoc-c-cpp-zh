# Unity Games by Tutorials

You need some solid, flat colors to use for your model. You can use whatever colors like, and you'll learn a simple trick for getting some variations on each base color.

+   1. Start by clicking the Rectangle Select tool from the toolbar.

+   2. Make a selection at the top-left of the document that is five-grid-squares wide.

+   3. Click the Foreground Color in the toolbar to pick a color.

![](bbox=[0.153, 0.243, 0.846, 0.487])

Use the color picker to select one of the colors you want to use on your model. I started with a gray. Enter 707070 in the HTML notation field to use the same color, and click OK.

+   4. Select Edit ▸ Fill with FG Color (Cmd-) to fill the selection with the foreground color.

+   5. Drag the selection down the grid space and select a new color, repeating the process for several colors.

![](bbox=[0.257, 0.676, 0.742, 0.839])

If you want to use the same colors as this example, here are their values: 707070, 907e52, ffd200, 97b8db, 933990, e23715, 375f1f, 438891.
