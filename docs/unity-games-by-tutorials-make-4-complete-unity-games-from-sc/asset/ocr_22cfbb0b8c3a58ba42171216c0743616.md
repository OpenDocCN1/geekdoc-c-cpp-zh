+   1. Input.GetAxisis() gets X and Y values from the built-in Unity controls named Horizontal and Jump. These values will either be -1, 0 or 1, depending on whether the controls are left, right, up, down or neutral. The value is held in the x and y properties of the input variable, which is a Vector2.

+   2. If input.x is greater than 0, then the player is facing right, the sprite gets flipped on the X-axis. Otherwise, the player must be facing left, so the sprite is set back to “not flipped”.
