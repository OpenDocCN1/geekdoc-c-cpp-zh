
# Getting started with the HTC Vive

If you're not already a proud owner of a HTC Vive headset, you can buy one on their website (https://htcvive.com) or (depending on where you live) in a store near you. Be sure your PC meets at least the minimum requirements. Once it's in your possession, download and install the software and set up the hardware. Also update the firmware on all devices if there are updates available.

Open up the **HTC Vive** starter project in Unity and open the **Game** scene:

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_586_0.png)

If you try the game, you'll notice it's impossible to add any towers as the AddTowerWindow isn't showing up on-screen. This is because the Screen Space Canvas has been replaced by a **World Space Canvas**. This means the elements are free to be placed, scaled and rotated in the game world instead of being locked to the screen.

Also take a look at the giant floating UI elements around the camera. These have been placed along a curved mesh.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_586_1.png)

To use the **Vive** in Unity, you'll need to download and import the newest version of the **SteamVR** Plugin from the **Asset Store**.

Click **Window ▷ Asset Store** to open the **Asset Store**. Now type in **SteamVR** in the side search box at the top and press **Enter**. Scroll down to the results and find the **SteamVR Plugin**. It should be the first entry.

# Setting up Unity for the HTC Vive

In the Hierarchy, disable the Main Camera and drag **CameraRig** from the SteamVR > Prefabs folder to the scene:

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_588_1.png)

Rename it to ViveRig and set its position to (0, 0, 0). Now take a look at it in the Scene view:

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_589_0.png)

The blue border represents the player's room. Right now it's tiny compared to the world as it uses real-world units. Get your Vive and its controllers ready and run the scene. Put on the HMD and walk around a bit. The enemies are huge!

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_589_1.png)

To fix this, change the scale of ViveRig to (10, 10, 10) to make the room a lot bigger:

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_589_2.png)

Try playing the scene again with the Vive on and you'll notice the difference:

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_590_0.png)

You're now a giant walking on the map! Walk around a bit and crouch to look up at the enemies. Also test out if the controllers are working properly. If the controllers aren't moving, reboot the headset by the SteamVR Status app. If that doesn't fix it, update to the latest version of SteamVR by deleting the SteamVR folder and importing a new package from the asset store. The next step is adding interaction with the world by putting down towers.

# Interacting with the world

There are several ways of handling input in VR. But for project you'll be using one of the controllers to point at the world and the UI to interact with it. The SteamVR plugin doesn't come with such a system out of the box, so you'll have to add it yourself.

Start off by expanding the ViveRig in the Hierarchy so you can see its children. Select Controller (right). Right-click it, and select Camera to create a new camera as a child. Name it ControllerCamera. This camera isn't used to actually see through. It's going to be used purely to fire raycasts into the scene so you can see and interact with colliders and UI elements. Change the camera's Clear Flags to Solid Color, set its Depth to -5 and adjust your Target Eye to None (Main Display). Next, remove the Flare Layer, GUI Layer and Audio Listener components. This camera wasn't used for rendering anything. It doesn't need to listen to sounds or music either, so those components aren't necessary. Finally, adding a Physics Raycaster component so it can send raycasts to 3D colliders. Do this in the Inspector panel by clicking Add Component and searching for it by name.

Create a new folder named VR in the Prefabs folder drag the ViveRig into it to make it into a prefab. The next thing to add is a method to know where the controller is pointing. You'll do this through a combination of a 3D reticle and a laser to make it easy for the player:

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_591_0.png)

First up — the reticle in the Hierarchy. Create a new Sphere (3D Object ▸ Sphere) and name it Reticle. Reset its Transform, set its scale to (0.1, 0.1, 0.1) and remove the Sphere Collider component. Finally, drag the Reticle to the Prefabs ▸ VR folder to make it into a prefab.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_591_1.png)

For the laser, create a new Cube (3D Object ▸ Cube) and name it Laser. Reset its Transform and set its scale to (0.1, 0.1, 1). Remove its Box Collider. Drag the Laser to the VR prefabs folder as well.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_592_0.png)

You might be wondering why the "laser" is just a long 

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_592_1.png)

Coupled with the unlit material, the cube has a consistent width no matter which angle you view it.
