Chapter 14: Saving Data

You're almost there! Add the following the last piece of code you just added:

```
var levelDataToJson = JsonUtility.ToJson(level);
var savePath = System.IO.Path.Combine(Application.dataPath, level.name + ".json");
Debug.Log("Level saved to " + savePath);
```

This uses JsonUtility to serialize the LevelRepresentation object, and all of its nested level item values, to a JSON string named levelDataToJson.

Then it combines the level value specified in the editor of the game's app data path (pointing to your Assets folder). This path is used to write the JSON string out to a file.

Save your changes. Go to the Game scene in Unity, click the Level GameObject, type in your super awesome level in the name field and click Save.

# A menu scene to load levels

Right now, the Menu scene will have a Simple Play button that starts the Game scene when clicked. It would suffice if you just wanted some weak single-level game, but can't handle the stress of multiple levels.

Ideally, the Menu scene should parse any JSON level files stored in the game's directory and display them to the player. When the player clicks a level name, the game should interpret the level's JSON file then build and load it into the Game scene.
