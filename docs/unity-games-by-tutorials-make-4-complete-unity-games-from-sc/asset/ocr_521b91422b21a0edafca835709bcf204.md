# Animating robots

Right now, the robots move statically towards the player; it would look much better if they actually rolled on their ball feet. Also, the robots should make a firing motion when they are at the player.

Click a RobotRampage_BotBall_v1 GameObject on any robot (expand the arrows on children to find it), then go to Window > Animation > Animation to open the Animation window. Click the Create button.

Enter Ball for the name, set the path to the folder, then click AddProperty, click the arrow beside Transform, then click the + next to Rotation:

![](bbox=[0.203, 0.474, 0.8, 0.597])

A pair of keyframes (grey diamonds) will appear one second apart on the timeline:

![](bbox=[0.183, 0.638, 0.81, 0.705])

Click the Record button and then the last keyframe; notice that the Rotation fields for the GameObject have turned red in the Transform component in the Inspector. Set the Rotation X value to -360. This will cause the ball to rotate 360 degrees.

Select the two RobotRampage_BotBall_v1 GameObjects at the same time. You can find this by expanding the child GameObjects BotRed, BotYellow and BotBlue. With all the RobotRampage_BotBall_v1 GameObjects selected, drag the RobotRampage_BotBall_v1 into the Inspector.
