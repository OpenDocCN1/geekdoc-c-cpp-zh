# Creating a texture

Launch GIMP. Before you create a new document, set the grid to make it easier to work with. From the menu bar, select GIMP ▸ Preferences. Click Default Grid, on the left, and change the Spacing to 32 × 32.

![](bbox=[0.233, 0.211, 0.766, 0.543])

Click OK, then select File ▸ New.... It’s good practice to make your texture sizes “power of 2”; 128 × 128, 256 × 256, 512 × 512, and so on. Because we’re going to be working with flat colors, we don’t need your new document to be 256 × 256:

![](bbox=[0.333, 0.641, 0.666, 0.796])

Select View ▸ Show Grid, the View ▸ Snap to Grid. Before you go any further, select File ▸ Save As... and save your document into the same folder as your 3D model.
