Before you can add GameManager to this list, you need to create a public method to subscribe to the event. The GameManager script and add the following at the bottom of the file, just before the closing brace:

```
public void AlienDestroyed()
{
    Debug.Log("dead alien");
}
```

This prints a message to the console to let you know that the GameManager got a notification. Save and switch to Unity.

In the Project browser, select the Alien in the Prefabs folder again. Find and select OnDestroy in the Inspector and click the + to add a new event.

![](bbox=[0.292, 0.501, 0.707, 0.637])

This is where you add event listeners. You'll notice a drop-down that reads Runtime Only, which means the events will run in Play mode.

Click the circle next to where it says None, and a Select Object pop-up will appear. Scroll through, and you'll notice that the GameManager GameObject does not appear in the list (the script you created, but not the GameManager itself). What gives?

There's a logical explanation for this: A prefab can't contain a reference to a GameObject in the Hierarchy because object may not be around when the game instantiates the prefab. For example, if you link the two together, you're introducing a potential error. You could create another scene with aliens in it, but that scene may not have a GameManager in the other scene.
