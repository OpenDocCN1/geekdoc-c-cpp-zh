Select Alien in the Hierarchy and, in the Inspector, set the position to: (2.9, 15.6, 8.41).

From the Project Browser, drag BobbleEnemy-Body from the Models folder into the Alien GameObject.

![](bbox=[0.177, 0.193, 0.822, 0.463])

Select BobbleEnemy-Body Position to (0, 0, 0). Now the alien and hero should be by side in the arena.

![](bbox=[0.303, 0.542, 0.696, 0.773])

As creepy as the alien is without a head, the hero needs more to shoot at that spindly little frame. From the Project Browser, drag BobbleEnemy-Head into the Alien GameObject. Set Position to (0.26, 1.74, 0.31), Rotation to (-89.96, 0, 0) and Scale to (100, 100, 100).
