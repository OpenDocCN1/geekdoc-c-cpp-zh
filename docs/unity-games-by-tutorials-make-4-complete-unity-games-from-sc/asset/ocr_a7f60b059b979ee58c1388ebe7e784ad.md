# Rendering and saving an image

+   1. Press F12 to render the scene using the camera. This replaces the entire 3D View with a UV/Image Editor panel, displaying your shiny new renderer.

+   2. In the menu bar at the bottom of the window, select Image ▸ Save as Image (or press F3). Choose a place on your computer to save it, and you're done!
