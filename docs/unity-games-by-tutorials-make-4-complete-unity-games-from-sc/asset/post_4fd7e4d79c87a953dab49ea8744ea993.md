# Standalone

Windows, Mac OSX and Linux are considered **standalone** platforms. The builds have both the executable and the data in a folder you can easily share.

Open up **Player Settings** and expand the **Resolution and Presentation** module:

| Settings for PC, Mac & Linux Standalone |
| :--- | :--- |
| Resolution and Presentation |

These are some of the most important settings exporting for a standalone platform. Most of the defaults are just fine. The common ones:

- **Default Is Full Screen**: Enables Full-Screen mode by default when the game starts.

- **Run In Background**: Keep the game running when it is out of focus. This is especially handy for networked games as the connection might be lost otherwise.

- **Display Resolution Dialog**: When enabled, pops up the resolution configuration dialog at the start of the game. It can also be set to **Hidden By Default**, which means the dialog will only show when the players holds down **Alt** (or **Option** on a Mac) while starting up the game.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_604_0.png)

- **Supported Aspect Ratios**: These checkboxes decide aspect ratios can be selected in the resolution dialog at startup if they are supported by the player's monitor. Uncheck all checkboxes here except for **16:9**. Runestife only supports this aspect ratio, as anything less wide will cause some tower slots to be cut off from the screen. You can try it out for yourself by changing the aspect in the **Game** view's control bar.

# WebGL

WebGL lets you to incorporate your game directly into a webpage — no plugins needed! This build option was first introduced in Unity 5.0, but was hardly usable at that point due to several limitations and bugs. The build sizes were also huge so people had to wait a long time for the game page to load.

As of Unity 5.4, WebGL is now a respected platform to target. Most of the limitations have been removed, and the builds are now compressed to avoid large downloads.

To start using WebGL, open the Build Settings, select WebGL and click Switch Platform.
