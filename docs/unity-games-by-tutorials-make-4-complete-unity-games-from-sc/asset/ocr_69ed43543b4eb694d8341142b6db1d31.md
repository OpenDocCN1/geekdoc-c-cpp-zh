# The Enemy Manager

Now that you have a bunch of enemies moving about, it's wise to think about a way of managing them so you can find them again when needed. At the moment, there are no references to them saved anywhere. They get spawned and that's it.

To fix this, you can make an Enemy Manager that will let enemies register themselves as they spawn and unregister as they die.
