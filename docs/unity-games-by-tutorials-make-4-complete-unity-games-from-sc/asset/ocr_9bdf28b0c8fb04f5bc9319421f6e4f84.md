Select the SoyBoy GameObject in your scene then add a Rigidbody 2D component and an Edge Collider 2D component. Don't select Kinematic for the body type of the Rigidbody. Super Soy Boy will be subject to the forces of physics.

With SoyBoy still selected, look in the Scene view for a small green edge that represents the edge collider.

![](bbox=[0.344, 0.313, 0.652, 0.463])

That's not going to cut it. You saw those blades, right?

Unless Super Soy Boy somehow makes contact with them on that little line — which is difficult given this is a 2D game — we'll avoid the fate of becoming shredded tofu.

Using the Inspector panel, expand the Points node on the Edge Collider 2D component and change the Size to 5 press Enter.

Apply the following to each element's X and Y values:

+   - Element 0: (X:-0.23, Y:0.195)
- Element 1: (X:-0.23, Y:-0.192)
- Element 2: (X:0.225, Y:-0.192)
- Element 3: (X:0.225, Y:0.195)
- Element 4: (X:-0.23, Y:0.195)
