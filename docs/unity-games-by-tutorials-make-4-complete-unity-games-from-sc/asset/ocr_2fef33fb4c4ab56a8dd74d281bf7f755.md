# Chapter 22: C# Crash Course
Brian Moakley

Playing games is fun, but making your own games is divine!

With Unity's powerful oriented visual editor, you can do a lot without writing any code at all. You can place objects, lay out levels, configure behavior and more.

However, you can only go so far without coding. To get the full power of Unity, you need to write some scripts for your game logic.

A few years ago, Unity provided three different languages to use: C#, Unity (often referred to as Javascript) and Boo. Over time, developers coalesced around C# whereas Boo and Script languished. In 2015, Boo was removed from the editor and in 2017, Unity soon followed. This leaves us to use C#.

C# is a modern object-oriented programming language. Granted, for the non-programmer, it will take time to fully understand the language and how to use it, but those skills can be directly transferred to other languages and/or apps.

If you already know a programming language, getting up-to-speed should be relatively easy; that's what this chapter is for. In particular, if you have any Java experience, you will be at home as C# and Java are very similar.

Unfortunately, if you have no programming whatsoever, this chapter is not going to help you. In fact, it will probably do confuse you. Frankly, we offer a free C# video course over at www.raywenderlich.com, which will teach you the basics of the language one step at a time, so we recommend that you watch that instead and then come back to this chapter.
