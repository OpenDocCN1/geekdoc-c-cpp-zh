# Automatically positioning and scaling world UI

Open the UIManager (Scripts > Game > UI folder) and add the following variable under txtEscapedEnemies at the top of the script:

```
public static float vrUIScaleDivider = 12;
```

This will be used to automatically scale UI elements based on the distance to the player, similarly to the reticle.

Now add this method at the end of ShowAddTowerWindow() :

```
UtilityMethods.MoveElementToWorldPosition(addTowerWindow.GetComponent<RectTransform>(), towerSlot.transform.position);
```

Also add this at the end of ShowTowerInfoWindow():

```
UtilityMethods.MoveElementToWorldPosition(towerInfoWindow.GetComponent<RectTransform>(), towerInfo.transform.position);
```

Both of these are the same; they'll make sure the window is moved and resized to the position of either the tower slot or the tower that was selected. MoveElementToWorldPosition() needs to be updated for this functionality; you'll need to do this once the UIManager is complete.

Also, add this to the beginning of Show...Window() methods:

```
if (GameManager.Instance.gameOver)
{
  return;
}
```

This ensures that the windows won't open up if the game is over. In both ShowWinScreen() and ShowLoseScreen(), remove this line:

```
blackBackground.SetActive(true);
```

Because you can see the world at any time, the background doesn't make much sense and would just disrupt the player.
