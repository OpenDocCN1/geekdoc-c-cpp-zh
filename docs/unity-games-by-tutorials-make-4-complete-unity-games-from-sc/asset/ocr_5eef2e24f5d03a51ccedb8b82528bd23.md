The smaller, the more the camera will “lag” behind the space marine’s position, letting the player “jump ahead” of the camera. # # Adding gunplay

Unfortunately, the finer parts of diplomacy are lost on the flesh-eating antagonists of this game. It’s best to give the hero some firepower so he can protect himself on terribly relaxing (terrible?) vacation.

First, you need to create a bullet. In the Hierarchy, click the Create button. From the dropdown, select 3D Object to create a sphere in the Scene view.

![](bbox=[0.313, 0.399, 0.686, 0.513])

Give it name Projectile. With it still selected, check out the Inspector. You’ll notice a bunch of new components.
