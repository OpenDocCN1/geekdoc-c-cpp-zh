# # WebGL

WebGL lets you to incorporate your game directly into a webpage — no plugins needed! This build option was first introduced in Unity 5.0, but was hardly usable at that point due to several limitations and bugs. The build sizes were also huge so people had to wait a long time for the game page to load.

As of Unity 5.4, WebGL is now a respected platform to target. Most of the limitations have been removed, and the builds are now compressed to avoid large downloads.

To start using WebGL, open the Build Settings window, select WebGL and click Switch Platform.
