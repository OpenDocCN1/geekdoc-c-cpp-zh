# Enemies

Enemies, often called minions or creeps in tower defense games, are the cannon fodder for the towers as they try to reach the exit of the map.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_507_1.png)

In Runestife, there are three kinds of enemies: A normal one (Knight), a fast one (Airship) and a sturdy one (Ram). Each of these have different speeds and amount of health but, in essence, they are the same; they all try to reach the exit of the player kills them.

These enemies are located in the Prefabs Enemy folder. Go to the folder and drag the Fast Enemy to the Hierarchy and set its Position to (2, 0, -5). Press the Play button to see what happens.

He's just standing there right now. That's no good! To make him move, you'll have to edit the Enemy script so it uses the WaypointManager that you made earlier.

Open up the Enemy script in the Scripts > Game > Enemy folder and add these methods underneath Die():

```csharp
void Update()
{
    // /1
    if (waypointIndex < WaypointManager.Instance.Paths[pathIndex].WayPoints.Count)
    {
        UpdateMovement();
    }
    else
    {
        // /2
        OnToGoWaypoint();
    }
}

private void UpdateMovement()
{
    // /3
    Vector3 targetPosition = WaypointManager.Instance.Paths[pathIndex].WayPoints[waypointIndex];
    // /4
    transform.position = Vector3.MoveTowards(transform.position, targetPosition,
        moveSpeed * Time.deltaTime);
    // /5
    transform.LookAt(targetPosition);
    // /6
    if (Vector3.Distance(transform.position, targetPosition) < .1f)
    {
        waypointIndex++;
    }
}

private void OnToGoWaypoint()
{
    waypointIndex = 0;
}
```

# Adding some utility

- Moving an item up and down
- Constantly rotating an object
- Scaling an object up and down

When working with Unity, there are often utility scripts that you need to use. In the Project Browser, create a new C# Script in the Utility folder named LoopRotate and open it.

```csharp
public class LoopRotate : MonoBehaviour
{
    public Vector3 rotation;

    void Update()
    {
        transform.Rotate(rotation * Time.deltaTime);
    }
}
```

This will make the object rotate every frame by the rotation specified. Save this script and return to the Unity editor. You should still have the FastEnemy in your Hierarchy. If not, drag it in from the Enemy prefabs. Expand FastEnemy and Airship to see the children Airship and Prop.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_510_0.png)

This seems like a perfect candidate to test the out rotator script on.

Add the Loop Rotate component on Prop and set the Rotation value on that to (1000, 0, 0). In the Prefab section near the top of the Inspector, click the Apply button. This will apply changes to the prefab that the GameObject was based on.

Press the Play button to see the effect. Looks pretty neat! Time to give Knight and Ram some rotation, too.
