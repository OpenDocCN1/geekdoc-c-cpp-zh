# Unity Games by Tutorials

In the Project view, select the **Animations** folder and click the **Create** button. From drop-down, select the **Animator Controller** and name it **AlienHead**.

Drag the **AlienHead** animator controller to the **Controller** property of the animator component.

![](bbox=[0.278, 0.187, 0.722, 0.313])

Open the Animations window, make sure you've selected **BobbleEnemy-Head** and click the **Create** button. Call it **HeadBob.anim** and save it in the **Animations** folder.

Click the **Add Property** button. From the flyout menu, expand the Transform component and click the **plus** sign to **Rotation**.

![](bbox=[0.228, 0.431, 0.772, 0.542])

You'll use three keyframes in this animation. But first, you will need to make the animation smaller. Select the **last keyframe** and drag it to **frame 0:10**.

![](bbox=[0.125, 0.613, 0.875, 0.706])

Next, put the **scrubber** to **0:05** **right-click** and select **Add Key**.

![](bbox=[0.225, 0.756, 0.775, 0.826])

With the middle keyframe still selected, expand the **BobbleEnemy-Head: Rotation** property and set the **Rotation.x** property to **-61.00**.
