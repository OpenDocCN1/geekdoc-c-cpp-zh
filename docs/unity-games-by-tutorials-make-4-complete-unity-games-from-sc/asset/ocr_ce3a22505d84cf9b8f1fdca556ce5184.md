# Setting up colliders

Now it's time to get your sprites to play nice with the 2D physics engine. Select the single-block GameObject in your scene. In the Inspector, click Add Component and choose Rigidbody2D under the Physics 2D menu. Select Kinematic for the Body Type selection as Super Boy won't need to move any terrain — the blocks will be static.

Click Add Component again, and under Physics 2D, choose Box Collider 2D. Unity will add a BoxCollider2D to the sprite and size it to the bounds of your sprite.

![](bbox=[0.118, 0.587, 0.881, 0.796])

Excellent! Your single-block sprite can now interact with the 2D physics engine.
