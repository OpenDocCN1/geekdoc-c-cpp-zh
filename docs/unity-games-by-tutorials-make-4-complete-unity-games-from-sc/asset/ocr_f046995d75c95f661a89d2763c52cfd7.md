Now unpause the game, and prepare to be confronted by a lot of aliens. If you experience a slowdown, delay the numbers until you find what works for your system.

Once you find the right amount, **pause the game one more time. Do not stop the game.** You need to copy the GameManager values. You could write them down, but there's a better way.

Select**GameManager** in the Hierarchy (if it isn't already), and in the Inspector, **click the gear icon** over the GameManager script component. From the drop-down, select **Copy Component.**

![](bbox=[0.32, 0.301, 0.68, 0.473])

**stop** your game. Pay no attention to the fact that the GameManager reverts the values. **Click the gear icon** again and select **Paste Component Values.**

![](bbox=[0.32, 0.534, 0.68, 0.706])

The component will update with all the values you added during run time. Pretty awesome, eh? The downside is that you can only do this with one component at a time.
