
```javascript
{
  //2
  currentLookAtHandler = ExecuteEvents.GetEventHandler<IPointerClickHandler>(pointerEventData.pointerEnter);
  //3
  if (currentLookAtHandler != null &&
      OVRInput.GetDown(OVRInput.Button.One)) {
    //4
    ExecuteEvents.ExecuteHierarchy(currentLookAtHandler, pointerEventData, ExecuteEvents.pointerClickHandler);
  }
  else {
    //5
    currentLookAtHandler = null;
  }
}
```

This is pretty straightforward:

- 1. Continue only if the pointer has entered an object to interact.
- 2. Get the OnPointerClick() event of the entered object.
- 3. Check that there's still something to click on the player and the player has pressed the Select button on their remote.
- 4. Execute the object's OnPointerClick() event.
- 5. No object to interact with, reset the currentLookAtHandler.

HandlesSelection();
```

# Automatically positioning and scaling world UI

There are some tweaks that need to be to the UIManager script for the windows to come into view when you click the tower slots or the towers.

Open the UIManager script (Scripts > Game > UI folder) and add this variable under txtEscapedEnemies at the top of the script:

```
public static float vrUIScaleDivider = 12;
```

This will be used to automatically scale UI elements based on their distance to the player.

Now add this method at the end of ShowAddTowerWindow():

```
UtilityMethods.MoveUIElementToPosition(addTowerWindow.GetComponent<RectTransform>(), towerSlot.transform.position);
```

Also add this to the end of ShowTowerInfoWindow()

```
UtilityMethods.MoveUIElementToPosition(towerInfoWindow.GetComponent<RectTransform>(), tower.transform.position);
```

Both of these do the same thing: They'll make sure the will get moved and resized to the position of either the tower slot or the tower that was selected.

MoveUIElementToPosition() needs to be updated for this new functionality. You'll do that once the UIManager is complete.

Add this to the beginning of both of those methods:

```
if (GameManager.Instance.gameOver) {
  return;
}
```

This ensures that the windows won't open if the game is over.

In both ShowWinScreen() and ShowLoseScreen(), remove this line:

```
blackBackground.SetActive(true);
```

Because you can fully see the world at any time, the background doesn't make sense and would distract the player.

private static void ScaleTransformBasedCamera(RectTransform rectTransform)
{
  float distance = Vector3.Distance(Camera.main.position, rectTransform.position);
  rectTransform.localScale = Vector3.one * distance / UIManager.vrUIScaleDivider;
}
```

Here's what the code does:

- 1. Get the RectTransform that needs to be scaled.
- 2. Calculate the distance between the camera and the object.
- 3. Set the object to Scale.

```javascript
//1
rectTransform.position = worldPosition + Vector3(0,0,3);

rectTransform.LookAt(Camera.main.position + Camera.main.forward * 1000);
//3
ScaleTransformBasedCamera(rectTransform);
```

This makes the UI appear the same size regardless of distance.
