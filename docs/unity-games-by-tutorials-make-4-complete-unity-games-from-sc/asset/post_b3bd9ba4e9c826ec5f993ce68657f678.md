
You've undoubtedly seen some adjustments you can make to the game. Play around with the map layout; add or change spawn positions; or even give power-ups a limited lifespan on the map — you snooze, you lose!

There's a real art to creating FPS games that are intuitive enough to pick up easily, but take some time to master; games that are easy enough in the first few levels to hook players, but take repeated plays to learn the subtle strategy to conquer the game. The most important part of any game is to test-play it with a range of players to find the sweet spot that creates an addictive experience.

Happy blasting!

> Note: You can manipulate a sprite the same way you manipulate any other GameObject. For example, you can change its scale, position and rotation using the Transform component and other Unity tools in the editor.

Sprites have a few different modes you can set. You'll focus on Single and Multiple. You saw how to use sprites when you created the single-block GameObject, but what about Multiple mode? They are special sprites that use a sprites, otherwise known as a texture atlas.

- **Single**: A single-image sprite.
- **Multiple**: A sprite with multiple elements. For instance, it might have several versions — like arms, legs and a torso. Using singles means every image in your game takes up one draw call, which isn't a big deal if you're just working with a few sprites. However, as your game grows in complexity and size, singles can cause performance issues. With spritesheets, you may just do one draw call for multiple sprites, thus reducing the performance cost.

Super Boy uses a Multiple mode so that animation frames — running, jumping and sliding — are stored in one spritesheet. Select the SuperBoySpriteSheet.png in the Sprites sub-folder and make sure Sprite Mode is set to Multiple. Click Apply if you change the setting.

There are other slice modes that you won't use right, but they're good to know about:
