# Chapter 8: Finishing Touches

![](bbox=[0.368, 0.085, 0.631, 0.252])

They’re working, but they fall through the floor, so clearly you need special treatment for the particles. You could have the particles collide with the world, but in this case, a death floor makes more sense.

In the Hierarchy, select BobbleArena. Click the Create button, select 3D Object and choose Plane. Name it DeathFloor and drag it to BobbleArena. Set Position to (8.66, -0.16, 12.15) and Scale to (-14.9, 0.5, 15.6). Uncheck the Collider and Mesh Renderer.

In the Hierarchy, select AlienDeathParticles. You will see there many options for particles.

![](bbox=[0.336, 0.483, 0.663, 0.814])

Expand the Collision section by clicking on it — scroll down if you don’t see it. Drag the DeathFloor to the Planes property.
