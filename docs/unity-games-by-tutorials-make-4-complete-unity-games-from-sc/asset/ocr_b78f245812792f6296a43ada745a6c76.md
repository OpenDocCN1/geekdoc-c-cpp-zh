# Unity Games by Tutorials

Press the small Lock icon at the top-right of the Inspector to lock the view:

![](bbox=[0.218, 0.122, 0.781, 0.298])

In the Hierarchy, expand **EnemyPaths > Path 0** to see all the waypoints. Select all of and drag them to WaypointManager's **Waypoints** field.

![](bbox=[0.118, 0.355, 0.881, 0.463])

This should fill up the Waypoints field with a list of all waypoints. Press the Lock icon again to unlock the Inspector. You now have the first set of waypoints stored away for later use.

To make things more interesting, there will be two paths the enemies can take.

Create a new empty GameObject, name **Path 1** and parent it to **EnemyPaths** in the Hierarchy. Now reset its **Transform**.

![](bbox=[0.418, 0.627, 0.553, 0.687])

Duplicate **Waypoint (1)** of **Path 0** and drag it onto **Path 1** to parent. Name it **Waypoint (1)** and set its position to (-25, 0, 13). Also disable **Path 0** in the Inspector by unchecking the checkbox next to its name so that it won't get in your way.
