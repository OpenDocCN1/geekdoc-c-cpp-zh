Click the Physics category then select Rigidbody.

![](bbox=[0.358, 0.125, 0.638, 0.427])

You'll see that a Rigidbody component was attached to the GameObject. Congratulations! You've added your first component.

![](bbox=[0.338, 0.493, 0.643, 0.677])

Each component has its own set of properties, and values there can be changed in the Inspector or in code. Components also have their own icons to make it easy to determine their type at a glance.
