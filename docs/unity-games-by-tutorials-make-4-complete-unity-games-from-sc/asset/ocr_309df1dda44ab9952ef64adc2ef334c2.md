As you can see, toggling the display of the face normals makes it easy to tell which ones are facing the right way.

Fortunately, it’s easy to fix. Select one of the culprit faces and press **L** to Select Linked. In the menu bar at the bottom of the 3D View, select **Mesh ▸ Normals ▸ Flip Normals**. Press **Tab** to return to Object mode.

> Reminder: Don’t forget to save (Ctrl-S).
