# Unity Games by Tutorials

You'll see the hero move much like before but with simpler code. In addition, your hero stops when he collides with the wall of the arena.

Unfortunately, you still have the problem of a character who runs through columns, which is easy to fix with colliders. Go ahead and make the fix now.

Stop your game. In the Project Browser, select the BobbleArena-Column in the Prefabs then click the Add Component button. In the Physics category, add a Box Collider. In the Inspector, set Center to (0, 2.66, 0) and Size to (2.07, 5.25, 2).

![](bbox=[0.207, 0.266, 0.792, 0.403])

When you make changes to the column, your next thought is probably that you need to apply these changes to the rest of the prefabs. You don't have to worry because you've modified the source prefab. These changes are added automatically to all the instances.

Now play your game and charge at a column. You're now blocked!

![](bbox=[0.292, 0.515, 0.707, 0.84])
