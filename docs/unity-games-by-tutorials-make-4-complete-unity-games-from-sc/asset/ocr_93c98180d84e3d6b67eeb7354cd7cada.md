After the Fire animation plays, the animation will change to the Base state, where the gun is at rest.

Right-click the **Base** state and select **Set as Layer Default State** to make it the base animation:

![](bbox=[0.316, 0.477, 0.683, 0.584])

There's only one thing left to do: Hook up this animation to the code! Open the **Gun** script and add the line to **Fire()**

```
GetComponentChildren<Animator>().Play("Fire");
```

This fetches the Animator Controller and tells it to play the Fire animation. But before the animation can play, you'll need to add that component to your GameObjects.

Of course, by creating an Animator Controller for the pistol, you need one for the shotgun and assault rifle. In the Project browser, select the **Pistol Animator Controller** in the Animations folder. **Duplicate** twice by pressing **Control-D** (or **Command-D** on a Mac). Name one **Shotgun** and the other **AssaultRifle**.

Open the **Shotgun** Animator Controller, and select the **Fire** state. In the Inspector, select the **Motion** to **GripFire**, making sure it originates from the **Assets > Models > RobotRampage_Shotgun.fbx** model.
