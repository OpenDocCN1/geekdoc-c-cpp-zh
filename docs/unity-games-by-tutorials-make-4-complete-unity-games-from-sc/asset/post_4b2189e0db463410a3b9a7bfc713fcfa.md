Here's's going on in the code:

1. Initializes the player health and ammunition text.
2. The rest of the methods is simply a setter that sets the related text values.

Now, to actually update the UI, to do this, you'll use coroutines. Coroutines were covered in Chapter 10, "Adding Enemies," if you feel unsure of them. Coroutines are perfect for the UI because you want to show some text for a few seconds and then hide it. With this in mind, add the following methods to your GameUI script:

```
// 1
public void showWaveClear()
{
    waveClearText.GetComponent<Text>().enabled = true;
    StartCoroutine("hideWaveClear");
}
```

```
// 2
IEnumerator hideWaveClear()
{
    yield return WaitForSeconds(4);
    waveClearText.GetComponent<Text>().enabled = false;
}
```

```
// 3
public void SetPickupText(string text)
{
    pickupText.GetComponent<Text>().enabled = true;
    inputText.text = text;
    // Restart the Coroutine so it doesn't end early

StopCoroutine("hidePickupText");
    StartCoroutine("hidePickupText");
}
```

```
// 4
IEnumerator hidePickupText()
{
    yield return new WaitForSeconds(4);
    pickupText.GetComponent<Text>().enabled = false;
}
```

```
// 5
public void showNewWaveText()
{
    StartCoroutine("hideNewWaveText");
    newWaveText.GetComponent<Text>().enabled = true;
}
```

```
// 6
IEnumerator hideNewWaveText()
{
    yield return WaitForSeconds(4);
    newWaveText.GetComponent<Text>().enabled = false;
}
```

Taking each section in turn, you:

1. Show the clear bonus text by setting its enabled state to true, then immediately call a coroutine that will hide the wave text again. You do this by using the coroutine before it hides the text.
2. Wait for four seconds before setting the enabled state to false — therefore, hiding the text.
3. Enable and set the text for the pickup alert and restart the hidePickup() coroutine. This lets the player pick up two or more pickups in quick succession, without the second pickup label displaying the first pickup's text times out.
4. Wait for four seconds before removing the pickup text.
5. Show the new wave text.
6. Wait for four seconds before removing the new wave text.

In pickupArmor(), add the following just above the closing brace:

```

gameUI.SetAmmoText(armor);
```

This shows the pickup text alert.

In pickupAssaultRifleAmmo() add

```
gameUI.SetPickupText("Assault rifle ammo picked up + 50 ammo");
if (gunEquipper.GetActiveWeapon().tag == Constants.AssaultRifle)
{
    gameUI.SetAmmoText(ammo.GetAmmo(Constants.AssaultRifle));
}
```

First, this alerts the player of the ammunition in the UI. Then, the code checks to see if the gun matches the assault rifle before matching the ammo count. If you didn't do this check, every time you picked up ammo for a different gun, it would change the ammo displayed to the wrong type.
