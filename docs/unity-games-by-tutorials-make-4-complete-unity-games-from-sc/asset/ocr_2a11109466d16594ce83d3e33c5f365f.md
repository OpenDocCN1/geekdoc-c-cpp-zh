Before you can play, you need to make a few adjustments. First, open the Build Settings and make sure your Unity project is using the Android platform. From the Build Settings menu, change Texture Compression to ASTC.

Next, click the Player Settings button and select the Android tab. First, you need to indicate that your game supports VR and you also need to select a VR SDK. You can find this in XR Settings. Simply click the Virtual Reality Supported checkbox and click the plus sign under Virtual Reality SDKs. Make sure to select Oculus as the SDK:

![](bbox=[0.307, 0.345, 0.692, 0.693])

Now, for the Quality Settings. From the menu, select Edit\Project Settings\Quality. Oculus suggests the following settings:

Pixel Light Count: 1

Texture Quality: Full Res

Anisotropic Textures: Per Texture

Anti-Aliasing: 2x Multi Sampling
