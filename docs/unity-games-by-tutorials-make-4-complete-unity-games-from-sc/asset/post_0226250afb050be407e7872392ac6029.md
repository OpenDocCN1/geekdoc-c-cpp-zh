Currently, BobbleHeadWars doesn't provide a winning or losing condition. After a bit of time, the aliens stop spawning, leaving the space marine to ponder existence with nothing more than a loaded weapon in an empty arena.

In this chapter, you'll provide a winning and losing condition and add some realism. In the process, you'll learn about UnityEvent, the Unity particle system, and some additional animation features.

Of course, before you even think about endings, you need to understand what UnityEvent is. A UnityEvent is a message that allows one script to call functions in another script without needing to know anything about that script. It's like a button click: when the button is clicked, it sends a message, and anyone listening for that message can react.

To use a UnityEvent, you need to define a variable of that type in your script:

```csharp
using UnityEngine.Events;

public class MyScript : MonoBehaviour {
    public UnityEvent onSomethingDone;
}
```

Once you've defined the event, it will appear in the Inspector. You can then drag objects into the list and select which functions should be called when the event is triggered. To trigger the event in code, you simply call:

```csharp
onSomethingDone.Invoke();
```

In our case, we'll use UnityEvent to notify the GameManager when an alien dies. This is better than the GameManager having a reference to every alien, because the alien just tells the world "I'm dead!"

First, open the Alien script and add the UnityEvent variable:

```csharp
using UnityEngine;
using UnityEngine.Events;

public class Alien : MonoBehaviour {
    public UnityEvent onDeath;
    // ...
}
```

Now, trigger the event when the alien dies:

```csharp
public void Die() {
    onDeath.Invoke();
    Destroy(gameObject);
}
```

Next, go to the Alien prefab. In the Inspector, you'll see the OnDeath event. Click the +, drag the GameManager-object into the slot, and select the `AddScore` function. (Wait, the GameManager isn't in the prefab! This is why we need a different approach.)

Actually, the best way is to have the GameManager subscribe to the event when the alien is spawned:

```csharp
// In GameManager script
void SpawnAlien() {
    GameObject alien = Instantiate(alienPrefab, position, Quaternion.rotation);
    Alien alienScript = alien.GetComponent<Alien>();
    alienScript.onDeath.AddListener(AddScore);
}
```

Now, when the alien dies, the GameManager will be notified and can update the score. This is a much cleaner way to handle the interaction.

# Fixing the GameManager

Wait, there's a problem. If the alien is destroyed, the listener might still be there. To be safe, we should unsubscribe the listener when the alien is destroyed:

```csharp
void OnDestroy() {
    alienScript.onDeath.RemoveListener(AddScore);
}
```

Wait, the alien is already destroyed! We can't call `OnDestroy` on it. The real solution is to unsubscribe before the alien is destroyed, or just rely on the fact that the object is gone anyway. For this tutorial, let's keep it simple.

# Adding Particle Effects

Now let's add some visual flair when an alien dies. We'll use the Unity particle system.

1. Create a Particle System in your scene.
2. Configure it to look like an explosion.
3. Make it a prefab.
4. In the Alien script, add a reference to the explosion prefab and instantiate it when `Die()` is called.

```csharp
public GameObject explosionPrefab;

public void Die() {
    onDeath.Invoke();
    Instantiate(explosionPrefab, transform.position, Quaternion.rotation);
    Destroy(gameObject);
}
```
