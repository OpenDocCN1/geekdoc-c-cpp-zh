
# 创建关键帧

首先，你将为尾部创建一个循环动画，让它在小人在路径移动时上下摆动。在 3D 视图（3D View）中，按 1 切换到前视图（Front view），按 5 关闭透视。按 N 打开属性面板（Properties shelf）。

你将为 Tail IK 骨骼，使其沿着如下路径移动：

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_480_0.png)

> 注意：我将给出每个关键帧的精确坐标，但你也可以根据视觉效果调整，使用你认为合适的值。这些数值可能会略有不同，因为它们是相对于 Tail IK 骨骼最初创建的位置。

- 1. 确保你处于姿态模式（Pose mode），并选中 Tail IK 骨骼。在属性面板中，将位置（Location）坐标设置为：X 0, Y 3, Z 10.3（如上方截图右上角所示）。
- 2. 确保播放头位于第 0 帧，然后在 X 字段（你刚刚设置为零的那个）上点击右键并选择“插入单个关键帧”（Insert Single Keyframe）。对 Y 字段执行相同的操作。字段会变为黄色，表示它们已设置关键。
- 3. 查看概要编辑器（Dope Sheet）；每个你设置的关键帧数值都会出现一个新通道，名称为数值名称 — X Location — 后面跟着括号中的对象名称 — (Tail IK)。关键帧本身在概要编辑器的时间轴上显示为菱形。

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_480_1.png)

# Unity 游戏教程

太棒了，你创建了第一批关键帧！目前还没有东西在移动，因为这是起始位置。创建更多关键帧来查看效果：

- 4. 在时间轴上右键点击并拖动，将播放头移动到第 15 帧。记得你可以使用滚轮进行放大；点击中间键进行平移/滚动查看。

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_481_0.png)

- 5. 确保 Tail IK 骨骼仍被选中，并将位置值更改为：X -1.3, Y 3.3（你完全不需要对 Z 值加密，保持不变即可）。对更改的每个字段点击右键并选择“插入关键帧”（Insert Keyframe）。

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_481_1.png)

- 6. 在 Blender 窗口底部的时间轴（Timeline）面板中，将结束（End）字段设置为 80。这为你的动画提供了 80 帧的持续。按下播放按钮预览你的动画。

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_481_2.png)

> 提示：按 Alt-A 可以随时播放/暂停播放头。你可以在动画播放时旋转 3D 视图，以便从任何角度良好观察。

以下是其余关键帧的帧数和坐标。记住在每次更改后、在移动播放头之前，点击右键并选择“插入单个关键帧”，否则你的更改不会被记录。

- 第 25 帧 - X -1.3, Y 3.5
- 第 40 帧 - X 0, Y 3.6
- 第 55 帧 - X 1.3, Y 3.3
- 第 65 帧 - X 1.3, Y 3.9

你的概要编辑器（Dope Sheet）应该是这样的：

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_482_0.png)

# 图表编辑器

此时，你的图表编辑器应该是这样的：

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_482_1.png)

如果你的图表看起来很小，可以随意放大查看更多细节。注意，你也可以拖动面板边缘来调整任何面板的大小。

图表编辑器为每个动画通道绘制一条曲线线。横轴代表时间；纵轴代表通道的值。线上的点代表你设置的关键帧。

# 使用图表编辑器创建平滑动作

点击 X Location 曲线上的第一个点。一旦选中，每个点两边都有手柄，用于控制曲线的强度和方向。拖动右侧的手柄使其大约成 45 度：

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_482_2.png)

这将在动画从第 80 帧跳回第 1 帧时，创建一个更平滑的循环动作。平滑所有点上的曲线，使你的路径看起来像这样：

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_483_0.png)

> 注意：在编辑曲线上的点时，你需要点击并拖动一下让手柄，然后释放鼠标。手柄将保持激活状态，移动鼠标将对其重新定位。

按 Alt-A 预览你的动画。好多了！但还可以更好。观察图表编辑器，看到你的波谷和波峰看起来不太对吗？它们不够平滑。要修复这个问题，将使用一个熟悉的工具（缩放 Scale）和一个新的：框选（Box Select）。

- 1. 按 A 取消选择，然后按 B 框选。
- 2. 点击并拖动你想选中的对象。
- 3. 对象已被选中。

![](img/ca20ea33da76d2b61297cc57f6c_483_1.png)

> 注意：框选几乎可以用于任何面板。现在你已选择了关键帧，只需按 S 然后拖动鼠标进行缩放。将关键帧相互拉开直到获得完美的曲线。对第 55 和 65 帧的关键帧重复此操作，使你的图表看起来如下所示。缩放后，你可能需要微调点上的手柄。

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_484_0.png)

查看概要编辑器（Dope Sheet）。注意 X Location 的关键帧已移动；这反映了你在图表编辑器中的更改。

> 注意：选择一个点并按 G 在图表编辑器中垂直移动。如果播放头位于该关键帧，你将在 3D 视图中看到更改。这是在运动曲线中视觉编辑关键帧的快速方法。

不要忘记保存！

# 制作 Pole Target

尾部动画看起来不错，但记得我提到过那个看起来很重的球吗？现在该为 Pole Target 让尾部领先一点，让它看起来像是在拉拽。

确保你仍处于姿态模式。选中 Tail Target。这个对象只会左右滑动，所以你只需要制作 X 值。这里是设置的关键帧：

- 第 0 帧 - X 0
- 第 20 帧 - X -1.5
- 第 40 帧 - X 0
- 第 60 帧 - X 1.5
- 第 80 帧 - X 0

在图表编辑器中，微调点使其变得美观且平滑，得到这样的曲线：

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_485_0.png)

现在预览动画，它看起来和之前几乎完全一样！那是因为 Pole Target 与尾部同步移动。要让它领先，你需要调整时间。

在概要编辑器（Dope Sheet）中，按 B 框选 X Location (Tail Pole Target) 通道中的所有关键帧。

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_485_1.png)

按 G-20，然后回车将选的关键帧向左移动 20 帧。

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_485_2.png)

现在预览动画，你会发现尾部在领先。太棒了！动画不再正确正确循环。在概要编辑器中，按 A 取消选择，并点击第 0 帧的关键帧进行选择。

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_485_3.png)

按 Shift-D 复制。将复制的关键帧拖过整个时间轴，在到达第 80 帧时**左键点击**。

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_486_0.png)

按 Alt-A 预览你的动画。在播放时绕着你的*场景*旋转一下，仔细观察 Pole Target 是如何影响尾部的。

尾部动画完成了。干得好！该为手臂创建一个新的 Action（动作）了。

不要忘记保存。

# 为爪动画创建 Action

尾部摆动很复杂；现在你需要一个**Action**来存储下一个动画。

- 1. 在概要编辑器底部，点击 **Tail Sway** 名称旁的 **+**（加号）按钮创建一个新 Action。

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_486_1.png)

- 2. Blender 实际上复制了当前动作；将新 Action 重命名为 **Claw Attack.L**。不要忘记点击 **F** 按钮。

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_486_2.png)

- 3. 现在需要删除关键帧。将光标移动到概要编辑器上，按 **A** 全选，然后按 **X**，选择“删除关键帧”（Delete Keyframes）删除它们。

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_486_3.png)
