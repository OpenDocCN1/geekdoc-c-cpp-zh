# Chapter 21: Publishing Your Game

![](bbox=[0.378, 0.087, 0.621, 0.283])

Everything is now ready for you to create builds!

Select **File > Build Settings...** to open the Build Settings window. Here, you can choose what platform to build for in the **Target Platform** drop-down:

| Target Platform |
| --- | --- |
| Architecture | Windows |
| Copy PDB files | Mac OS X |
| Development Build | Linux |
| Autoconnect Profiler |

You can also choose the architecture, which means **32-bit, 64-bit or both (or for Mac OSX and Linux)**. Almost all computers since around 2006 have 64-bit processors, so it's safe to build for this architecture. You can build for 32-bit if you like to be safe. In the case of Mac OSX and Linux, always select the universal architecture as that covers both.

| x86 | x86 | |
| --- | --- | --- |
| ✓ | ✓ |
| x86 | x86,64 | x86,64 |
| Universal | x86+x64 (Universal) | |
| Windows | Mac OSX | linux |

Select **Windows** and **x86,64** in their respective drop-downs and click **Build** in the bottom right. Choose a folder to store the build and create a new folder at that location named Runestife-Windows. Choose the new folder as the location, then click **Save**. Unity will now compile the project into a build. The time it takes depends on the size of the project; Runestife shouldn't take more than a minute or so.
