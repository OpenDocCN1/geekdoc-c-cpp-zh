# Shaping the body

When you finish a loop cut, you'll be automatically switched to Edge Select mode. This is perfect:

+   1. Click the edge in the middle, on the top.
2. Drag the blue arrow up a bit, or type G Z 0.3.
3. Press Ctrl-Tab and switch to Face Select mode. Select the back two faces.

# Extrude, scale, repeat

The Extrude tool takes your selected faces and extrudes them outward, creating faces along the sides. This is the primary tool you'll use to create the ridged body.

+   1. Press E to extrude the selected faces. You only need a small extrusion this time, to move the mouse just a bit, then click to complete the extrusion.
2. Press S to scale the new face down a bit.
