# Applying Transformations

When modeling for Unity, it's very important to apply the rotation and scale of all objects. After scaling an object to the size you want, applying the Transforms will reset the scale to 1 and the rotation values to zero.

You will have scale and rotation problems with your 3D models in Unity, if you don't this!

+   1. Click the axle to select it, and press N to display the Properties Region. Notice that both the rotation and scale values have been modified.
2. Press Ctrl-A and select Rotation & Scale.
3. The object doesn't change shape, and all the values are now nice and clean.
