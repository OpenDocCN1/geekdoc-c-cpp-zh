# # Chapter 12: Beginning Unity 2D
By Sean Duffy

So you want to learn about creating 2D games with Unity? You're in the right place. In this chapter, you'll learn how to leverage Unity's 2D tools and components to create a game wherein a vulnerable cube of tofu braves a terrifying gauntlet.

You'll start by learning 2D fundamentals and then move on to script a really fun platformer. Through it all, you'll learn how to tackle your own 2D projects with confidence!

![](bbox=[0.228, 0.501, 0.771, 0.719])

The game is a 2D platformer with super-tight controls. You'll navigate Super Soy Boy around obstacles, while running, jumping and wall sliding. He's in a big hurry to reach a steaming bowl of noodles at the end of the level.

Although it's possible to take obstacles slowly and thoughtfully, the most enjoyable gameplay will come from passing levels in one fluid motion. This is not about taking the sights or carefully calculating your next move!
