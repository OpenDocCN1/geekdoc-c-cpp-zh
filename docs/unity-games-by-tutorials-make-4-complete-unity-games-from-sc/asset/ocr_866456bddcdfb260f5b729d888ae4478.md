All of the appropriate C# code is run in Main(). This is the method called at the start of all C# programs, and in this case, the program simply prints a message to the console. In Unity, you won't need to create Main() since Unity does it for you.

# The basics

C# is a strongly typed language. This means, you must define your variable types you use them. The more common types are: int, float, double, string and bool.

Inside Main(), add the following before the closing brace:

```
int meaningLife = 42;
float smallPi = 3.14f;
double bigPi = 3.14159265359;
string vaporWare = "Half Life 3";nbool likesPizza = true;
```
