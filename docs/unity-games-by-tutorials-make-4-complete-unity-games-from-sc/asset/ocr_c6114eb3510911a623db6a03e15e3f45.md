# Chapter 20: Virtual Reality

The Oculus Go runs a heavily modified version of the Android operating system. This means you'll need to set up Unity for publishing to the Android platform. Check out the Chapter 20, "Virtual Reality," on how to do this.

Setting up your Oculus Go requires a little bit of work on your part. Thankfully, once you have it up, testing your game is easy and quick.

To get started, you have to enable developer mode on the Oculus Go companion app on your phone. In the settings of the companion app, select your paired Oculus Go headset, and then select **More Settings.** From that menu, select **Developer Mode** and then switch it to **On.**
