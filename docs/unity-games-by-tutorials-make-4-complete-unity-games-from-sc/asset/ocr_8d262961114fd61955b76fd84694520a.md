# Scaling keyframes in the Dope Sheet

Selecting some keyframes and squashing or stretching them on the timeline is simple, using the Scale tool. One important to note is that the point in time it scales is from the playhead position.

+   Move your playhead to frame zero and press A to Select All. Press S to Scale:
