Create a new folder named VR in the Prefabs folder drag the ViveRig into it to make it into a prefab.

The next thing to add is a method to know where the controller is pointing. You'll do this through a combination of a 3D reticle and a laser to make it easy for the player:

![](bbox=[0.339, 0.199, 0.65, 0.413])

First up — the reticle in the Hierarchy. Create a new Sphere (3D Object ▸ Sphere) and name it Reticle. Reset its Transform, set its scale to (0.1, 0.1, 0.1) and remove the Sphere Collider component. Finally, drag the Reticle to the Prefabs ▸ VR folder to make it into a prefab.

![](bbox=[0.313, 0.523, 0.686, 0.676])

For the laser, create a new Cube (3D Object ▸ Cube) and name it Laser. Reset its Transform and adjust its scale to (0.01, 0.01, 0.1). Remove its Box Collider and set its Material to LaserMaterial, which is simply an unlit white material.
