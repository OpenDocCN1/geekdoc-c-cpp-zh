# Chapter 11: Introducing the UI

![](bbox=[0.313, 0.076, 0.686, 0.283])

Double-click the scene you want to open it. Drag over the RobotRampageTitle prefab from the Resources folder to the Hierarchy.

Set its Position to (15, -61, 538) and its Rotation to (18.07, 180, 0). This position is a good starting point that chosen when the game was being developed.

Recalling how you handled UI > Canvas in the Hierarchy, create a Canvas as you've done before and name it MenuUI.

![](bbox=[0.313, 0.453, 0.686, 0.623])

First, we need to create a button. Right-click in the Hierarchy, Create UI > Button and rename it to BeginButton. Set the anchor preset to bottom-center, pivot to (0.5, 0.5), position to (0, 165.8, 0), width to 260, and height to 75.

In the Image component, set the Image to Pink Grey_Texture. In the Button component, set the Transition to Sprite Swap, set the Highlighted Sprite to Pink_Black_Texture and the Pressed Sprite to Pink_Texture.

The Sprite Swap transition means that different Sprite Images are used for the button, depending on its state.
