
# Modifying the Menu

The Menu scene currently has a UI panel named LevelItemsPanel that has a built-in scrolling system. When the panel is full of items, the scroll bar allows the player to scroll through them.

You'll fill the panel with buttons that represent each level file in the directory. As you'd expect, you'll click a button to load the relevant level.

The starter project includes a button pref in Assets ▸ Prefabs that'll be the template for each level's button.

Start by removing the PlayButton from the Menu scene.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_403_0.png)

Open GameManager. Add these two fields to the top of the class:

```csharp
public GameObject buttonPrefab;
private string selectedLevel;
```

- `buttonPrefab` will hold a reference to the button template each level button will use.
- `selectedLevel` will temporarily hold the path to a level file based on which level button the player clicks.

Now, add a new method:

```csharp
private void SetLevelName(string levelFilePath)
{
    selectedLevel = levelFilePath;
    SceneManager.LoadScene("Game");
}
```

This sets `selectedLevel` to the path passed into the method and then loads the Game scene. It'll also come into play later when you add code to load level content based on its value.

Create another new method:

```csharp
private void DiscoverLevels()
{
    var levelPanelRectTransform =
    GameObject.Find("LevelItemsPanel").GetComponent<RectTransform>();
    var levelFiles = Directory.Files(Application.dataPath, "*.json");
}
```

You guessed it, this method will seek out and discover JSON level files! First, it locates the UI panel in the Menu scene and gets a reference to the RectTransform component. It searches for JSON files — by looking at JSON extensions — in the game's `Application.dataPath`.

Still inside DiscoverLevels()`, add the following below the previous code:

For a little chunk of code, it's got a lot going on. You're looping through the `levelFiles` array. Each iteration calculates the `yOffset`, starting at -30f and reducing by 65 credits. This calculation determines the vertical position of each button on the panel.

At this point, you've got a button, a way to find levels and a way to place and name the buttons. Good work! You still need a method that listens for clicks on the button. A handy trick is to add listener methods to the onClick event on a button.

Just beneath the code you added, but still inside the for loop, add the following:

```csharp
var levelButton = levelButtonObj.GetComponent<Button>();

    SetLevelName(levelFile);
    levelPanelRectTransform.sizeDelta = new Vector2(levelPanelRectTransform.sizeDelta.x, levelPanelRectTransform.sizeDelta.y);

```

Remember that you added earlier named `SetLevelName()`? Did you know at the time that you could use that as the listener?

This code passes into the `AddListener()` method on the onClick event with a string parameter that indicates the level file name `levelFile`.

Each iteration of the for loop changes the value of `levelFile` because each can point to different JSON files. By passing in a delegate to `SetLevelName()`, you can dynamically assign different names to `SetLevelName()` to each instance of a button. Pretty cool! :)

# Scripting logic to load levels

You're in the homretch where you'll write the final bit of code to interpret JSON files and dynamically reconstruct whatever the player chooses.

Open GameManager.cs and add the following:

```csharp
private void LoadLevelContent()
{
  var existingLevelRoot = GameObject.Find("Level");
  Destroy(existingLevelRoot);
  var levelRoot = new GameObject("Level");
}
```

This code runs when the game scene loads. It finds the existing Level GameObject, destroys it and creates a new, "clean" Level GameObject.

This might seem a little backward, but there's a good reason for it. The Game scene already contains a Level GameObject that has a layout, which was used to design and edit the example levels and save them to JSON.

If you just reconstruct a level with the Game scene, then you would get duplicate objects and a big, sticky mess. When you destroy the level root GameObject and its children, you tidy up the scene. When the script creates that new Level GameObject, it's ready to host the loaded level.

Just below the last line of code inside the LoadLevelContent() method, add the following:

```csharp
// 1
var levelJsonContent = File.ReadAllText(selectedLevel);
var levelData = JsonUtility.FromJson<LevelDataRepresentation>(levelJsonContent);
// 2
foreach (var li in levelData.items) {
  var pieceResource = Resources.Load("Prefabs/" + li.prefabName);
  if (pieceResource == null)
    Debug.LogError("Cannot find resource: " + li.prefabName);
  // 4
  var piece = (GameObject)Instantiate(pieceResource, li.position, Quaternion.identity);
  var spritePiece = piece.GetComponent<SpriteRenderer>();
  if (spritePiece != null) {
    spritePiece.sortingOrder = li.spriteOrder;
    spritePiece.sortingLayer = li.spriteLayer;
    spritePiece.color = li.spriteColor;
  }
  // 5
  piece.transform.parent = levelRoot.transform;
}
```
