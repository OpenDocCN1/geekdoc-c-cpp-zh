# Introduction

If you're reading this book, chances are that you have a dream of making your own video game. But if you're like I was a few years ago, you might be worried that this is too difficult, or something that's out of your reach.

Don't worry! The Unity platform makes that dream a reality for aspiring game developers everywhere. Unity's aim is to "democratize" game development, by providing a AAA-level engine to independent game developers in a way that is both affordable and accessible.

And with this book, we'll show you how to make your own games with Unity step-by-step — if you're a complete beginner.

You'll learn by doing. Through this book, you will develop four complete games from scratch:

- A twin-stick shooter
- A first-person shooter
- A 2D platformer
- A tower defense game (with VR support!)

By the time you're done reading this book, not only will you have created four killer games, but you'll be ready to create that dream game of your own!

# Why Unity?

Unity is one of the most powerful and popular game frameworks used today. But why we use it rather than other frameworks?

Well, here are a few good reasons:

- **It's free to use.** If you're an indie game developer, you can download and start using Unity for free, which is great when you're learning. You do not have to pay your company earns $100K or more in a year or in certain situations, but a lot of the time the free version is just fine. For example, the free version is all you need for this book!

- **It's cross-platform.** With Unity, you can make any game and build it for a variety of platforms, including Windows, macOS, iOS, and more.

- **It's powerful.** Unity isn't just for indie games — it has been used by AAA game developers in popular games such as Mario Run, Cuphead, Subnautica, Hearthstone, and more.

- **It has a visual editor.** Unlike other game frameworks where you have to type tons of code before you see anything on the screen, with Unity you can simply import an asset and drag it. This visual style of development is great for beginners and professionals alike, makes game development fast and fun.

- **Live debugging.** With Unity you can click a button to preview your game instantly in the editor, and you can even modify game objects on the fly. For example, you can drag new enemies onto the level as you play, tweak gameplay values and more, allowing for an iterative design process.

- **Asset store.** Need some functionality Unity doesn't provide on its own? Chances somebody has provided the functionality through the Asset Store — a place where you can buy scripts, models, sounds, and more for your games.

- **Unity is fun!** You can think of Unity like a box of LEGO: the limits are those of your imagination.

- **Learning curve.** But if you want to make a game, in addition to knowing how to build it in Unity, you'll also need 3D models, textures, and sounds.
