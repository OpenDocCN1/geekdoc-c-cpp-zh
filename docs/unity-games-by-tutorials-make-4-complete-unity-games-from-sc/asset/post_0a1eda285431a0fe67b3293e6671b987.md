# Music

It would be awesome if this game had a soundtrack — that's what you'll do next.

In the MainMenu scene, create an empty GameObject and name it BackgroundMusic. Create a C script, name it BackgroundMusic and open it in the code editor. Delete the boilerplate texts and replace them with the following method:

```
void Start()
{
    DestroyOnLoad(gameObject);
}
```

This ensures the GameObject that the script that it is attached to is not deleted when changing scenes, so the music will keep playing when you switch to the battle! You'll see this reflected in the Hierarchy when you play your game:

Save your changes. Back in Unity, drag this over the BackgroundMusic GameObject.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_317_1.png)

Select the BackgroundMusic GameObject and add an Audio Source component. For the Loop check to Selected and set the AudioClip to music. Now, click Play and click the Begin button. Start killing robots with some epic tunes!

# Game Over

This game is almost done but it needs a Game Over screen. Open up the Battle scene (double-clicking in the **Scenes** folder).

First, create a Panel by right-clicking in the **Hierarchy** and selecting **UI ▸ Panel**. Rename it to **GameOverScreen**. Set its **Anchor Preset** to **middle-center**, **Position Y** to **0**, its **Width** to **400**, and its **Height** to **500**. Set the **SourceImage** in the Image component to **Box**, and set its **Alpha** to **1** (just click the **Color** box and slide the A over the right).

A panel is just another UI control, which you can use to organize your controls. All subsequent UI controls will be **children of the GameOverScreen**.

Create a Text UIGameObject, rename it to **GameOverText** and put it under the **GameOverScreen** GameObject (by dragging it under it or by having it selected when you create the text). Set the **position** to **(0, 0, 0)**, the **Width** to **400**, the **Height** to **290**.

In the **Text** component, set the **Text** to **Game Over**, the **Alignment** to **Center**, the **Font** to **heavy_data**, the **Font Size** to **70** and the **Color** to **White**.

The UI should look as follows:

With the layout complete, just need hook it up in code.

Open the Game script, and add the class declaration, as the following:

```
using UnityStandardAssets.Characters.FirstPerson;
using UnityEngine.SceneManagement;
```

You'll need these resources in just moment. Add the following variable at the top of the script before the opening brace of the class:

```
public GameObject gameOverPanel;
```

Now, add these methods to the body of the class:

```c
// 1
public void OnGUI()
{
    if (isGameOver && Cursor.visible == false)
    {
        Cursor.visible = true;
        Cursor.lockState = CursorLockMode.None;
    }
}

// 2
public void GameOver()
{
    isGameOver = true;
    Time.timeScale = 0;
    player.GetComponent<FirstPersonController>().enabled = false;
    player.GetComponent<CharacterController>().enabled = false;
    gameOverPanel.SetActive(true);
}

// 3
public void RestartGame() {
    SceneManager.LoadScene(Constants.Battle);
    gameOverPanel.SetActive(true);
}

// 4
public void Exit() {
    Application.Quit();
}

// 5
public void MainMenu() {
    SceneManager.LoadScene(Constants.SceneMenu);
}
```

Here's the play-by:

1. This method frees the mouse cursor when the game is over so the user can select something from the menu.
2. This will be called when the game is over. It sets the timeScale to 0 so that robots stop moving. It also disables the controls and displays the Game Over panel you created.
3. When the user wants to restart the game, this method will be used to reload the scene to start the game again.
4. This will be called when the user selects the Exit button. It quits the app, but only if its from build.
5. You also need a method to go back to the Main menu when the user selects the Menu button.

Save your changes and switch back to Unity. Click the Game GameObject and drag over the GameOverScreen GameObject to the Game Over panel.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_321_0.png)

Now, deactivate the GameOver GameObject. This way, it only appears when the game is over.

Open the Player script, and add these variables after the opening brace of the class:

```
public Game game;
public AudioClip playerDead;
```

These are references to the Game script, and an AudioClip that you'll play when the player dies. Replace Debug.Log("GameOver") with:

```
GetComponent<AudioSource>().PlayOneShot(playerDead);
game.GameOver();
```

This will play the playerDead audio and then call GameOver on the Game script.

Save your work and switch back to Unity. Click the Player GameObject, and drag the Game to the Game field.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_322_0.png)

Next, set PlayerDead to the playerDead audio file.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_323_0.png)

Now, when the player's health reaches 0, it calls the Game Over screen and it plays a death sound.

The last thing to do is configure the button callbacks.

Click the Restart GameObject. Add an event to clicking +, Next, drag the GameObject onto the field, and select Game > RestartGame() in the drop-down menu.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_323_1.png)

Do this two times for the Exit and Menu GameObjects. When selecting the methods, select Game > Exit() for the Exit GameObject, and Game > MainMenu() for the Menu GameObject.

Click Play, and blast until your health reaches 0 to see the Game Over screen. You should hear the player scream as he dies.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_324_0.png)

Click the **Menu** button while the Game Over screen is displayed — it's not working! Don't worry; it's simply a matter of adding the MainMenu scene to the build.

Open the **MainMenu** scene, select **File > Build Settings** and click **Add Open Scenes.**

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_324_1.png)

Now, go back to the **Battle** scene by double-clicking it in the **Scenes** folder, click **Play** and die again. With the Game Over screen open, click **Menu** and you should be taken to the **MainMenu** scene.
