
# Playing background music

Select Main Camera in the Hierarchy. Click the Add Component button and select Audio Source in the Audio category.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_184_0.png)

You're adding the Audio Source for the background music to the camera, since that's the same place the audio listener. This way, the volume of the background music will always stay the same; think of it carrying around your own boom box!

As you can see, you have an array of options. Here's the breakdown:

- *AudioClip*: The actual sound file. You create a clip by dragging a sound file into Unity, and then the engine converts it to an audio clip. In your case, you imported the sounds when you imported the models in Chapter 1, "Hello, Unity."

> > Pro Tip: Avoid formats such as MP3 because Unity sometimes re-encodes compressed files to a lower quality when it exports the game. To avoid this, we have provided the audio as OGG files.

- *Output*: This represents the Audio Mixer to use. You'll learn what this means later in this chapter.

- *Mute*: Check if you'd like to mute the audio. This can be useful to programmatically mute sounds mid-game or disable sounds while testing.

- *Bypass Effects/Listener/Reverb Zones*: Turns off any additional effects that you might add to a sound. Effects can add depth and increase realism. For instance, consider the difference between footsteps in a cavernous structure with and without an echo.

By the way, you used to have to buy a paid Unity license to access these features — but they are free for all to use.

- *Play Awake*: Plays the sound as soon as the GameObject is activated. Note that this is checked, which is great: It means the background music will start playing automatically as soon as the game begins.

- *Sound Sliders*: Adjusts the current sound's properties, such as volume and pan location.

- *3D Sound Settings*: Changes how a sound plays in 3D space. For instance, you can adjust the doppler level to create the pitch and frequency of the sound for a fast-moving object, as a bullet whizzing past your player.

It's important to understand that Unity doesn't factor in level geometry when playing sounds. Here's a case in which level geometry matters: Imagine two players, each with a large ray gun, stand on opposite sides of a two-meter thick wall. If player one fires, in Unity the player would hear the sound as if player one were right next to him (rather than being muffled, as you might expect).

Look at the audio clip for the background music. In the Project browser, open the Sounds folder and select bw_bg. Inspector shows you all the properties for this audio clip.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_185_0.png)

In here, you can decide whether or not to go with stereo or mono, load the clip in a background thread or normalize.

You also have the ability to change how the audio clip plays, which can have a ripple effect on performance. By default, audio clips are decompressed in memory when loaded. OGG files expand ten times when decompressed, so a 1 MB file requires 10 MB when it's loaded. It's not ideal.

From the Load Type option, select Compressed in Memory. Instead of hogging memory space, the audio will decompress as it plays. This setting does increase CPU usage, but it's a fair trade-off in this case.

Note that you have the option to stream the file too, but you can try that out another time.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_186_0.png)

Click Apply to save changes.

Next, select the Main Camera and drag bw_bg from the Project browser to the AudioClip property's audio source. Check the Loop checkbox to make it repeat continuously.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_186_1.png)

# Building a sound manager

Sounds stack up quickly when you're building a game. I bet you're already thinking about audio you'd like in Bobblehead Wars — like a sound effect for when the marine fires gun, or perhaps a battle cry for the aliens.

You could create AudioClip properties throughout your scripts, but it's hard to keep things organized. It's actually easier to build and use a sound manager as an audio library for your game.

In the Hierarchy, click the Create button and from the drop-down, select Create Empty. Give it the name SoundManager.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_187_0.png)

Click the Add Component button, and from the Audio category, select Audio Source. SoundManager will provide audio clips when asked most of the time, but sometimes it will play sounds directly, too.

Now that you have a sound manager, you should move the background audio source to the Main Camera.

Next, add the following to Start():

```csharp
if (Instance == null)
{
    Instance = this;
} else if (Instance != null)
{
    Destroy(gameObject);
}
```

This is a simple coding design pattern, known as a singleton pattern, that ensures there is always only one copy of this object in existence. If this is the first SoundManager created, it sets the static variable to the current object. If, for some reason, a second SoundManager is created, it automatically destroys itself to make sure that there is only one SoundManager.
