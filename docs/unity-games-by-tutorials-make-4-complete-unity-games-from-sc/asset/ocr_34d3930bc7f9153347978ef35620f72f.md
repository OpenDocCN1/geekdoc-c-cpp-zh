# Opening the claws using Forward Kinematics

For the claws, instead of moving an object that they are aimed at, simply rotate them. This is called Forward Kinematics.

+   Move the playhead to frame 0 then select the Thumb.L bone. Look in the Properties shelf, ensure the Rotation Mode popup is set to XYZ Euler, then right-click the Z value and create a single keyframe of 0.

![](bbox=[0.27, 0.252, 0.728, 0.471])

+   Move the playhead to frame 20 and change the Z Rotation to -50. Don't forget to right-click and select Insert Single Keyframe.

![](bbox=[0.27, 0.539, 0.728, 0.758])

+   Move the playhead to frame 40 and set a keyframe with the Z Rotation back to 0 (remember that you could also duplicate the keyframe at frame zero in the Dope Sheet and move it to frame 40).
