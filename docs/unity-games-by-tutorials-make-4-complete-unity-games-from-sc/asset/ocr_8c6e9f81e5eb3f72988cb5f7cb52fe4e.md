# Summary of keyboard commands

+   L - Select Linked

+   Alt-click - (on an edge in Edit mode) Loop Select

+   U - UV Unwrap selected faces

+   Ctrl + - Select More

+   Ctrl - Select Less

+   Ctrl-j - Join Objects

+   Shift-Z - Toggle rendered view

+   N - Toggle Properties panel

+   T - Toggle Tools panel

+   0 (zero) - Switch to Camera view

+   F12 - Render

+   F3 - Save image
