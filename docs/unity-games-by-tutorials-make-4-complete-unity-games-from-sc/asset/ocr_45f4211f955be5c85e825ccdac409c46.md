Open the Resolution and Presentation module:

Here's what all of these options:

+   **Preserve Framebuffer Alpha:** When enabled, it preserves the alpha value in the framebuffer to rendering over native UI.

+   **Resolution Scaling Mode:** When enabled, you can pass a custom fixed DPI to use. This allows you to use a lower internal resolution that the screen resolution. Doing this can drastically improve performance.

+   **Blit Type:** This changes how we content is drawn to the screen. **Always** is selected by default, it renders the content offscreen then blits (copies) it to the screen. **Never** renders directly to the screen and is a lot faster, but not compatible with all configurations. **Auto** chooses between offscreen or direct.Generally, it's a good idea to set this to Auto for its performance gains.

+   **Aspect Ratio Mode:** This lets you define custom aspect ratios. The default is Native Aspect Ratio, which uses the device's native ratio.

+   **Default Orientation:** By default this is set to **Auto Rotation**, which means it will always render the game at the device's orientation and size, whether it's landscape or portrait.

This is not usually what you want. Most mobile game developers design the game and UI around particular orientation, which is also the case with Runestrike. It will only look correct in landscape — unless, is, you want to nail that “peeking through a keyhole” feel.
