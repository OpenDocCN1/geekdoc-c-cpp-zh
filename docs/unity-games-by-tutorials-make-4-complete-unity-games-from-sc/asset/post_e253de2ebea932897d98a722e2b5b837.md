## Chapter 16: Texturing With Blender
By Mike Berg

In the previous chapter, Chapter 15, "Modeling with Blender," you just created a sweet model with Blender, but it's a little, uh... monochrome. What's next? Giving it some color, of course!

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_441_0.png)

Texturing involves taking 2D artwork and applying it to 3D surfaces.

> Note: This chapter builds on the skills learned and the model made in Chapter 15. I recommend you read through that chapter before this one.

## Getting started

Texturing a model in Blender can be done in many different ways. You'll be covering the most common method used in video games: UV Mapping.

UV Mapping allows you to take each face in your mesh and "project" part of a 2D image onto it. Typically, this is done by "unwrapping" the mesh so that it can be "laid flat" and arranged onto a 2D image.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_442_0.png)

In the above example, each face of the cube is mapped to different areas of the texture. Note that UV mapping allows for any area of texture to be used for multiple faces; in this case, all sides use the same texture.

To create your 2D texture, you need an image editor. You could use Photoshop, but GIMP is a great alternative. GIMP is an open-source image editor that works on all platforms. It's free and packed with features. The instructions below are for GIMP, but you can use any image editor. Start by downloading GIMP for Windows, Mac or Linux: http://www.gimp.org/downloads/

## Creating a texture

Launch GIMP. Before you create a new document, set the grid to make it easier to work. From the menu bar, select GIMP ▸ Preferences. Click Default Grid on the left, and change the Spacing to 32 × 32.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_443_0.png)

Click OK, then select File ▸ New... It’s good practice to make your texture sizes powers of 2: 128 × 128, 256 × 256, 512 × 512, and so on. Because we’re going to be working with flat colors, you don’t need your new document to be larger than 256 × 256.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_443_1.png)

Select View ▸ Show Grid, View ▸ Snap to Grid. Before you go any further, select File ▸ Save As... and save your document into the same folder as your Blender model.

You need some solid, flat colors to use for your model. You can use whatever colors like, and you'll learn a simple trick for getting some variations on each base color.

- 1. Start by clicking the Rectangle tool from the toolbar.
- 2. Make a selection at the top-left of the document that is five squares wide.
- 3. Click the Foreground Color in the toolbar to pick a color.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_444_0.png)

Use the color picker to select one of the colors you want to use on your model. I started with a gray. Enter 707070 in the hex field to use the same color, and click OK.
- 4. Select Edit ▸ Fill with FG Color (Cmd-) to fill the selection with the foreground color.
- 5. Drag the selection down the grid and select a new color, repeating the process for several colors.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_444_1.png)

If you want to use the same colors as this example, here are their values: 707070, 907e52, ffd200, 97b8db, 933990, e23715, 375f1f, 438891.

## Adding shading

While you may not want to hand-pick each color, there's a simple trick for adding darker and lighter versions of all these colors at once — in just a few steps.

- In the Layers Palette, click the New Layer button and click OK on the resulting dialog to create a new layer.
- Click the tiny Foreground/Background icon in the Tools palette to reset the colors to black and white.
- Use the Rectangle Select tool to select the left-most column in the grid, and press Ctrl-, to fill it with black.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_445_0.png)

- Use the Rectangle Select tool to select the right-most column in the grid, and press Ctrl-, to fill it with white.
- In the Layers palette, change the Mode pop-up to Overlay.
- Your left-most column is now nicely shaded, and your right-most column has a nice highlight.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_446_0.png)
![](img/fd5c2ca20ea33da76d2b61297cc57f6c_446_1.png)

Create another layer and repeat this process, but this time you select the second column and fill it with black. Select the fourth column and fill it with white.

- 7. After setting the mode to Overlay, set the Opacity to 50%. The opacity setting can be found directly underneath Mode field.
- 8. Now you have a nice range of colors to work with and some variation in shading.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_446_2.png)
