# Unity Games by Tutorials

You also have the ability to change how the audio clip plays, which can have a ripple
effect on performance. By default, audio clips are decompressed in memory when
loaded. OGG files expand ten times when decompressed, so a 1 MB file requires 10 MB
it's loaded. It's not ideal.

From the Load Type option, select Compressed in Memory. Instead of hogging
memory space, the audio will decompress as it plays. This setting does increase CPU
usage, but it's a fair trade-off in this case.

Note that you have the option to stream the file too, but you can try that out another
time.
