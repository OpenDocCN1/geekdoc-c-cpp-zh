# Anchor Presets

Shift: Also set pivot Alt: Also set position

Set Pivot to (0, 0), Pos to (-40, -50, 0), Width to (520, Height to 100), and Source Image to Pink_Grey_Texture.

You’ll end up with an image in the lower left-hand side of the canvas like so:

![](bbox=[0.253, 0.553, 0.746, 0.676])

> Note: Since this is an overlay UI, it’s helpful to switch the Scene view to Isometric mode. In the Scene view, simply click the center cube in the gizmo to change modes, then click it again to return back to Perspective mode.

The Pos fields work in relation to the anchor. In your case, you set the PosY to -50. This has the effect of lowering the image from the lower left-hand corner of the canvas by -50.
