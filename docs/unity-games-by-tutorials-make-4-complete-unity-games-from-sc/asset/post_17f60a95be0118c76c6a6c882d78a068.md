## The Game Manager

There are a few variables and functionality that don't fit into any specific script need to be accessed from many other scripts. A Game Manager fits perfectly in this situation. It stores all of global information such as the amount of gold the player has or the number of enemies that have escaped. It also contains some methods for things like restarting the game and returning to the title screen.

Create a new C# Script in the Scripts > folder and name it GameManager. Open it in a code editor. Remove the Start() and Update() methods completely. Put this below the other using statements at the top of the file:

```
using UnityEngine.SceneManagement;
```

Insert these variable declarations into the class definition:

```cs
//1
public static GameManager Instance;
//2
public int gold;
//3
public int waveNumber;
//4
public int escapedEnemies;
//5
public int maxAllowedEscapedEnemies = 5;
//6
public bool enemySpawningOver;
//7
public AudioClip gameWinSound;
public AudioClip gameLoseSound;
//8
private bool gameOver;
```

Here's the role of each:
1. The static variable for global access.
2. The amount of gold the player has.
3. Number of the wave that's currently spawned.
4. Amount of enemies that made it to the exit.
5. Number of escaped enemies before you lose the game. (img/fd5c2ca20ea33da76d2b61297cc524_0.png)
6. Checks if the game isn't over yet, but the enemies have been spawned.
7. If there are no more enemies, the player has won, call OnGameWin().
8. When the Escape key is pressed, call Quit().
9. When the player wins, play the win audio clip and set gameOver to true.
10. Return to Title scene.

Now add these methods below the others:

```cs
//1
public void OnEnemyEscape()
{
    escapedEnemies++;
    if (escapedEnemies == maxAllowedEscapedEnemies)
    {
        // Too many enemies escaped, lose the game
        OnGameLoss();
    }
}
//2
private void OnGameLoss()
{
    gameOver = true;
    AudioSource.PlayAtPoint(gameLossSound, Camera.main.transform.position);
    EnemyManager.Instance.DestroyAllEnemies();
    WaveManager.Instance.StopSpawning();
}
//3
public void RetryLevel()
{
    SceneManager.LoadScene("Game");
}
```

Quite simply:
1. If the amount of enemies that have escaped surpasses the amount allowed, OnGameLoss.
2. Set gameOver to true, destroy all enemies that still on the map and tell WaveManager to stop spawning.
3. Reload the Game scene.

That's it for the GameManager script! Save the script and return to the editor. Create a new empty GameObject, name it GameManager and parent it to Managers. Add the GameManager script to it. (img/fd5c2ca20ea33da76d2b61297cc525_0.png)

There are just two fields that need some setup: Game Win and Game Lose. In the Project view, open the Sound folder to see all the sound effects present in the project: (img/fd5c2ca20ea33da76d2b61297cc526_0.png)

Drag GameWin to the Game Win field and drag GameLose to Game Lose Sound. (img/fd5c2ca20ea33da76d2b61297cc527_0.png)

Now that the GameManager is in place, there are a few scripts that need to be modified to use its features. Open the WaveManager script (Scripts > Game > Wave) and add this inside the SearchForWave() method, right under `spawnCounter = 0;`:

```cs
GameManager.Instance.waveNumber++;
```

This will notify the GameManager that a new wave started. Add this line to the UpdateWave() method, right under `if (activatedWaves.Count == enemyWaves.Count) {`:

```cs
GameManager.Instance.enemySpawningOver = true;
```

This is to tell GameManager that the WaveManager has stopped spawning. Save the WaveManager script and open the Enemy script (Scripts -> Game -> Enemy). Add this line to OnGotoLastPoint(), right above Die():

```cs
GameManager.Instance.OnEnemyEscape();
```

That will notify the GameManager that this enemy got to the exit. Now add the following method under TakeDamage():

```cs
void DropGold()
{
    GameManager.Instance.gold += goldDrop;
}
```

Also place a call to the method in TakeDamage(), right above Die():

```cs
DropGold();
```

Now, the enemy will give the player gold when it dies of an attack. Save the script and return to the editor. Press the Play button and look at the GameManager in the Inspector. Each time an enemy escapes the EscapedEnemies variable will go up: (img/fd5c2ca20ea33da76d2b61297cc528_0.png)

Once the number reaches the maximum allowed, all enemies will be destroyed and the lose sound will play.

That concludes the GameManager; all the global values are now stored neatly in that class.

## Chapter 19: Making Towers
By Eric Van de Kerckhove

In the previous chapter, Chapter 18, "Making a Tower Defense Game," you learned how to create paths and spawn your enemies to follow those paths. But that's not much of a game. To even the playing field a little, you need some killer towers to lob stones, ice and even fire at your invaders!

In this chapter, you'll create all the missing pieces to make the final game. In the process, you'll learn how to:
- Create waves of enemies.
- Make towers that shoot projectiles.
- Craft a UI that binds everything together.
- Make winning and losing logic.

You can continue from where you left off in Chapter 18, but if you want to start fresh, open the starter project in Unity. Open the Game scene and prepare for making some awesome scripts!

### Creating a tower

### Creating your tower

Before creating any towers, you need a TowerSlot to place them. Drag the TowerSlot prefab from the Tower folder into the Hierarchy. Set its position to (-4, 0, 10). (img/fd5c2ca20ea33da76d2b61297cc531_0.png)

This is a quad with a texture on it and a Box Collider to allow interaction by clicking. Notice that there's an Event Trigger attached. This handles all the events when the player's cursor enters and exits, and when a click happens.

### Stone tower

The first of the towers is the affordable and reliable Stone Tower. (img/fd5c2ca20ea33da76d2b61297cc531_1.png)

Drag the StoneTower prefab from the Tower folder into the Hierarchy and change its position to (-1, 0, 10) so you can still see the TowerSlot.

Create a new folder Tower inside the Scripts folder. Create a new C# Script named Tower and open it in a code editor. At this point, you may be thinking "Wait a minute, I'm making the script for a Stone Tower here. Shouldn't the script be StoneTower?"

The answer is "no." While there's going to be a StoneTower script as well, it will derive from this common Tower script. That means all logic shared between towers is into Tower and the other tower scripts inherit its properties and functionality while still having to add their own. (img/fd5c2ca20ea33da76d2b61297cc532_0.png)

Back to the script, delete everything that's in there, then add these lines:

```cs
using UnityEngine;
using System.Collections.Generic;
```

These statements make sure you can access Unity classes and use lists. Now add this snippet:

```cs
public enum TowerType
{
    Stone, Fire, Ice
}
```

This small enum will be used throughout several classes so they know what type of tower they're dealing with. It contains the three types of towers you'll be adding to the project.

Add this code block right underneath:

```cs
public class Tower : MonoBehaviour
{}
```

This is the actual class declaration where you should now insert these variables:

```cs
//1
public float attackPower = 3f;
//2
public float timeBetweenAttacksInSeconds = 1f;
//3
public float aggroRadius = 15f;
//4
public int towerLevel = 1;
```
