In the next few chapters, you'll create a first-person shooter game, or FPS as it's more commonly known. Some well-known FPS titles include Halo, Call of Duty, and Doom.

The game that you'll create is called **Robot Rampage**; you'll control a player who has to mow down robots to survive. The robots will spawn in waves and the player must collect health, ammunition and armor pickups in order to starve the robots as long as possible. The longer the player survives, and the more robots they kill, the higher the score.

In the next chapter, you'll add the robot bad guys, some power-ups and lots of flying projectiles.

In the final chapter, you'll add all the user interface elements to keep track of the score, ammo and even a menu to restart the game when it's over.

## Getting started

To get started, open up the starter project in Unity. In the Project browser, open the Scenes folder and double-click the Battle scene to open it.

Believe it or not, the map is mostly set up for you. The map itself consists of a floor, surrounded by a series of walls. After you complete the tutorial, feel free to create other configurations for the game by adjusting the wall positions.

To get started, you'll need to set up the GameObjects so that the robots can avoid them. So in this book, you've been using layers, but Unity has another tool known as tags. A tag is just a bit of text used to identify GameObjects. Each GameObject can have only one tag and, thankfully, they're easy to use. By assigning a tag to each GameObject, you'll be able to set up some pathfinding rules for the robots to follow that they can move around walls.

In the Hierarchy, click on the InnerWalls GameObject. In the Inspector, click the Tag drop-down and click Add Tag.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_241_0.png)

## Adding player

Currently, the camera is divorced from the player when you want them to be a happy couple, frolicking through the wasteland. Frankly, you don't have to play matchmaker.

In the Hierarchy, create an empty GameObject and name it Player. With the Player still selected, find the Character Controller in the Inspector and set the Position to (0, 1, 0) and Rotation to (0, 0, 0).

The FirstPersonController script also has values for run and walk speed. Set the Walk Speed to 10 and Run Speed to 20.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_244_0.png)

## Adding the camera

Click the Camera and drag it onto the Player GameObject to make it a child of Player. The camera will now move with the player.

Set the Camera position as (0, 0.8, 0) and Rotation to (0, 0, 0).

Click Play; use the WASD keys to move around and the mouse to look around as you move. You can also hold the Shift key to run.
