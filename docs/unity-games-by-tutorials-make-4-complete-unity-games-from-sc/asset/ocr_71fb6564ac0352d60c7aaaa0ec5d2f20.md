# Chapter 10: Adding Enemies

With the PickupSpawnGameObject select, lock the PickupAmmoAssaultRifle, PickupAmmoPistol,

In the Resources folder, select the PickupAmmoAssaultRifle, PickupAmmoPistol,
PickupAmmoShotgun, PickupHealth and PickupArmor prefabs and drag them to
the Pickup properties to add them to the array.

![](bbox=[0.118, 0.193, 0.882, 0.483])

Unlock the Inspector.

Now, drag the PickupSpawn GameObject into the Resources folder to create a
prefab of it.

Create an empty GameObject and name it PickupSpaw. Set its position to (0, 0, 0),
Drag the PickupSpawn GameObject underneath the PickupSpaw and duplicate it
six times by pressing Control-D (or Command-D, on the Mac).

To stay organized, change the each of the names to: PickupSpawn.
