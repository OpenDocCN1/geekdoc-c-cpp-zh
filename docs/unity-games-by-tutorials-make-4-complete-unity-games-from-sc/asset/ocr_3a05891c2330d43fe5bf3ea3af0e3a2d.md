These settings are **extremely** important for publishing and updating Android games:

+   **Bundle Identifier:** The string used to uniquely identify your game. You set this up once per game, never change it again. Otherwise, it would be considered a different game. The format of this string is: **com.[DEVELOPER].\[GAME NAME\]].**

+   **Version:** The version of the game. This could be **1.0, 2.4.0.1** or **Unicorn Rainbow** — it's your choice.

+   **Bundle Version Code:** This is the number you have to increment every time you build a new version of your game for publication.
