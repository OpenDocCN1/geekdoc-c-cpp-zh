# # Adding a simple level timer

Next up, you'll hook up a simple timer script that will time your level runs. The timer will just be used as a reference for how long you take to do level runs. Later in Chapter 14, "Saving Data," you'll extend it to add more functionality to the game.

Create a new C# script in the Scripts folder, called Timer. Open the script for editing.
Add the following statement to the top of the script:

```
using UnityEngine.UI;
```

Now, replace the Start() and Update() methods with the following:

```
private Text timerText;

void Awake()
{
    timerText = GetComponent<Text>();
}

void Update()
{
    timerText.text = System.Math.Round((decimal)Time.timeSinceLevelLoad, 2).ToString();
}
```

This code will cache a reference to the Text component on the same GameObject it exists on. In the Update() loop, the text will be changed to display the time since the level last re, rounded to two decimal places. Nice and simple!

Save the script and return to Unity.

Attach the Timer.cs script to the Timer GameObject, which is nested under the Canvas GameObject.

Run the game, and you'll see the timer counting over the time each time the level starts or restarts.
