# Chapter 11: Introducing the UI

The position property has been replaced by a new set of properties that are specifically designed for the UI. This is called the **Rect Transform**.

Whenever you want to set the position of a control in code, you use the RectTransform instead of the regular Transform.

To position this image at the bottom-left of the screen, click the **anchor presets**.

![](bbox=[0.333, 0.383, 0.666, 0.531])

You'll get a whole bunch of options that correspond to positions on the screen. Along the bottom and right-hand side, you'll see stretching presets as well.
