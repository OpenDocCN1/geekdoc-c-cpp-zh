You'll need to call UpdateReticle() from somewhere to change the reticles. The GunEquiper script looks like the perfect sort.

Open the GunEquiper script in your code editor. Create a reference to the GameUI by creating a GameUI variable at the top of the script, just below the opening brace:

```
[SerializeField]

```
