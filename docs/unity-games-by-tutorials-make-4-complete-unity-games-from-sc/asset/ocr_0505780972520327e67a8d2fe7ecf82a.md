Polygon Colliders allow more flexibility when defining odd physics shapes, as you’ll see in a moment.

There's a triangle block sprite in the starter project that makes a nice building block for levels. You added it to the scene earlier. Now you'll complete it by adding Rigidbody 2D and Polygon Collider 2D components to it.

Select the top-left-small GameObject in your scene. As you did for the previous objects, add a Rigidbody 2D. These blocks will be part of the static platform and won’t move, select Kinematic for body type. Next, click Add Component. Under Physics 2D, choose Polygon Collider 2D.

Select the top-left-small GameObject in the Scene view and look at how the collider edges align with the triangular shape.

Unity does a pretty good job with polygons, but sometimes you’ll need a little different configuration. To learn how to adjust them, go to the Inspector and click Edit Collider on the Polygon Collider 2D component. Hover your mouse over the collider shape in the Scene view. Drag the points and the lines to make fine adjustments. When you’re done playing, put the lines back on the edges.
