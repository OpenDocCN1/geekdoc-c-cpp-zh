Now that you have a series of waypoints, you can store their positions in an array. The array will form a path used by enemies to decide how they should move.

In the Project browser, inside the Scripts ▸ Game ▸ Enemy folder, create a sub-folder named Waypoints. Inside the Waypoints folder, create a new C# Script and name it WayPoint Manager.
