# Chapter 21: Publishing Your Game

![](bbox=[0.3015, 0.0869, 0.6984, 0.4535])

If you are using Unity Personal, your games will show a Made with Unity screen. If you have the Pro version of Unity, you can disable this splash screen or customize it. You can even display a list of logos to show as your game loads and designate the team between them.

The launch screen options are where you'll put your image of your launch icon. This section allows you to use custom XIBs, Storyboards, or you can use the legacy launch images. You'll need to get the dimensions of each device and make a corresponding image.

For more information about the screen sizes, please see Unity's documentation: https://docs.unity3d.com/Manual/class-PlayerSettingsiOS.html).

Finally, expand the Other Settings section and change the Bundle Identifier to match your company name. This is very important, as every app must have a unique identifier. The format of this string is: com.[DEVELOPER].[GAME NAME]. When configuring your app in iTunes Connect, you'll need to use this identifier.
