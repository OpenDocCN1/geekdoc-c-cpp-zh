# Mesh Select mode

While in Edit mode, sometimes you want to work just with points (vertices), sometimes with edges, and sometimes with entire faces. There are three options for working with these elements of mesh: Vertex Select, Edge Select and Face Select. Switch between them by pressing Ctrl-Tab or by using the toggle buttons at the bottom of the 3D View.
