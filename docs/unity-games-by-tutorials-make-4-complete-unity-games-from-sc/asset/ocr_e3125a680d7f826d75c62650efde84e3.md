In the Graph editor, tweak the points so that they are nice and smooth, giving you a curve like this:

![](bbox=[0.303, 0.142, 0.696, 0.276])

Preview the animation now, and it will look almost exactly the same as it did before! That's because the Pole Target is moving in sync with the tail. To get it to lead the tail, you need to adjust the timing.

In the Dope Sheet, press B and Box Select all the keyframes in the X Location (Tail Pole Target) channel.

![](bbox=[0.158, 0.423, 0.839, 0.529])

Press G-20, then Enter to move the selected keyframes 20 frames to the left.

![](bbox=[0.158, 0.579, 0.839, 0.683])

Preview the animation now, and you'll see that the tail is leading the way. Nice! The animation no longer loops correctly. In the Dope Sheet, press A to Select None, and click on the keyframe at frame 0 to select.

![](bbox=[0.158, 0.782, 0.839, 0.887])
