# Unity Games by Tutorials

The variables just hold the data. int holds integer data. float and double hold numbers with decimal points, otherwise known as floating point data.

A double uses twice as much memory to store as a float, so it can hold a much larger range of values.

strings are meant to hold text and a bool can only be set to true or false. This is important when making decisions in your code.

Notice that the value for smallPi is 3.14f. The f indicates that the number is a float. By default, all floating point numbers are considered doubles, so you must indicate that you mean to use a float.

**Delete the f and click the Run** button. You'll see the following:

![](bbox=[0.118, 0.353, 0.425, 0.396])

```
Error CS:
{19,5} Literal of type double cannot be implicitly converted to 'float'; use an 'F' suffix to create a literal of this type
```

C# thinks you are assigning a double to a float — and there isn't enough room to store a double in a float.

Unity uses floats all over the place so you'll run into this.

Add the **f** back to **3.14**.

You'll also notice that each line concludes with a semicolon. In C#, this is the same as at the end of a sentence. It lets the compiler know that a statement is concluded. If you forget to add a semicolon, you'll experience a compiler error. In C#,# will not be able to determine the intent of your code, and it will stop compiling.

C# can also infer the type of a variable. Change the variables to the following:

```
var meaningOfFloat = 42;
var smallPi = 3.14;
var bigPi = 3.14159265359;
var vaporWare = "Half Life 3";
var likesPizza = true;
```

By using the **var** keyword, C# is able to determine the type based on the value being assigned to it. This is a nice feature to save time. If you are new to the language, then defer to declaring your types so that you can get used to thinking in types.
