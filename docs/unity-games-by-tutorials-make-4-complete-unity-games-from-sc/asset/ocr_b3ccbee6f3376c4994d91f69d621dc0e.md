# Unity Games by Tutorials

Run the program once installation completes. The first thing you'll see is a dialog asking for your Unity credentials.

![](bbox=[0.276, 0.147, 0.723, 0.298])

If you don't have an account, click create one and follow the steps. Unity accounts are free. You'll have to log in every time you it up, but the engine does have offline mode for times when you have no network.

Once you're logged in, you'll be presented with a project list that provides an easy place to access all of your projects.

![](bbox=[0.276, 0.449, 0.723, 0.599])

With Unity 2018, you now have a Learn tab. This tab provides a bunch of different Unity tutorials to get you to speed with the editor.

![](bbox=[0.276, 0.674, 0.723, 0.813])

Definitely check them out when you are doing this with book. To get started, click the New button.
