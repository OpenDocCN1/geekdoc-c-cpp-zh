# Summary of keyboard commands

+   * X - Delete
* Shift-A - Create new objects
* G - Move
* R - Rotate
* S - Scale
* K - Knife
* I - Inset
* E - Extrude
* Ctrl-Tab - Mesh Selection mode
* Shift-D - Duplicate
* Alt-D - Linked Duplicate
* Ctrl-B - Bevel
* Ctrl-A - Apply (Rotation & Scale)
* Ctrl-R - Loop Cut
* Alt-M - Merge Points
* Ctrl-M - Mirror
* (period) - Move pivot point to 3D Cursor
* (comma) - Move pivot point to current object
* Shift-Z - Toggle rendered view

# 3D View controls:

+   * 1 - Front view
* 3 - Side view
* 7 - Top view
* 5 - Toggle perspective
