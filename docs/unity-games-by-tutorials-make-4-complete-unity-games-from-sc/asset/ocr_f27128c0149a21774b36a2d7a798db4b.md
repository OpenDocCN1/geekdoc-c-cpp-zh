Chapter 20: Virtual Reality

![](bbox=[0.345, 0.093, 0.654, 0.185])

Click on the SteamVR icon to open the store page and click the **Download** button.

![](bbox=[0.423, 0.233, 0.576, 0.316])

Once the plugin has finished downloading it will open an **Asset Import** dialog. Click the **Import** button at the bottom right to add it to the project.

![](bbox=[0.243, 0.386, 0.756, 0.599])

If a window pops up asking you to make recommended changes for **SteamVR**, accept them all — except if it asks for the color to be **Linear** instead of **Gamma**. The project will become dark if you'd do that, as all lighting is configured for gamma space coloring.

You can now close the **Asset Store**; you won't be needing that further for this project.
