Descriptive Name and Negative Name are the names presented to the user in the Unity game launcher if they want to rename the keys. You can disable the Unity game launch and provide your own key mapping interface if you'd, so these aren't required properties.* Negative and Positive Buttons are the actual keys being used. Allow buttons to have negative or opposite keys. For instance, the right arrow key is positive while the left arrow is. You don't need to provide a negative for all keys — it wouldn't make sense to provide a negative key for a use.*Alt Negative and Alt Positive Buttons are alternative keys. In this case, instead of Left and Right Arrow keys, you enable the A and D keys.

The other fields mostly relate to the functionality of analog sticks. For simplicity, this game will only use keyboard input. If you wanted to make the game bonafide twin stick shooter, these are the options you'd tweak to create a tight control scheme.
