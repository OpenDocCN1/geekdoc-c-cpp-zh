# Adding shading

While you maynt want to hand-pick each color, there's a simple trick for adding darker and lighter versions of all of these colors at once — in just a few steps.

+   In the Layers Palette, click the New Layer button and click OK on the resulting dialog to create a new layer.

+   Click the tiny Foreground/Background icon in the Tools palette to reset the colors to black and white.

+   Use the Rectangle Select tool to select the left-most column in the grid, and press Ctrl-, to fill it with black.

![](bbox=[0.144, 0.375, 0.855, 0.597])

+   Use the Rectangle Select tool to select the right-most column in the grid, and press Ctrl-, to fill it with white.

+   In the Layers palette, change the Mode pop-up to Overlay.

+   Your left-most column is now nicely shaded, and your right-most column has a nice highlight.
