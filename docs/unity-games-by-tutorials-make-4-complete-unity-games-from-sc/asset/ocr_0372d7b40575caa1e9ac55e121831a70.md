This lets you access the Unity UI (user interface) classes. Next, add the following variables in the class:

```
[SerializeFieldField]
Sprite redReticle;
[SerializeFieldField]
Sprite yellowReticle;
[SerializeFieldField]
Sprite blueReticle;
[SerializeFieldField]
Image reticle;
```

There's a few things going on in this code block. First, you'll notice the SerializeField attribute. Attributes allow you to convey information about particular classes. In this case, you are declaring variables that are accessible from the Unity Inspector but not from other scripts.

You'll notice that there are both a Sprite and an Image. A Sprite represents an imported texture to be used with a 2D game or the UI. These are JPG and PNG files that you have imported into Unity. By setting the texture type to a Sprite in the Inspector, you can add them to the user interface.

![](bbox=[0.331, 0.466, 0.668, 0.576])

An Image what displays the Sprite to the screen. You can think of it like so: The Sprite is a real film whereas the Image is the film projector.

In this case, you have three Sprites acting as source image data for the reticle. Since only one will be displayed, there is only one Image.

Add the following method below the variable:

```
public void UpdateReticle()
{
    switch (GunEquipper.activeWeaponType)
{
        case Constants.Pistol:
            reticle.sprite = redReticle;
            break;
        case Constants.Shotgun:
            reticle.sprite = yellowReticle;
            break;
        case Constants.AssaultRifle:
            reticle.sprite = blueReticle;
    }
```
