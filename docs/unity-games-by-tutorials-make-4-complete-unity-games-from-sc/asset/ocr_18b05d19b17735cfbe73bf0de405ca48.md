# Setting up Unity for the Oculus Rift headset

Unity has built-in support for the Oculus Rift headset since version 5.4, so it's easy to start using it!

Select File > Build Settings..., to open the Build Settings window and click the Player Settings... button. This opens up the PlayerSettings in the Inspector.

Now check the Virtual Reality Supported checkbox to enable the Rift support.

This list will now appear, showing all detected and enabled built-in VR SDKs:

| Virtual Reality SDKs |
| - Oculus |

With that, jump over to the section called Running in the Oculus.

# Getting started with the Oculus Go

At the 2018 F8 developer conference, Facebook made a bit of a splash. Their long-awaited VR headset — Oculus Go — was released to the public for an affordable price of $199.99. This makes for a great low cost platform for developing VR games. Of course, you are limited to only three degrees of movement.
