## Chapter 6: Animation

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_176_0.png)

In the Project browser, select the **Animations** folder and click the **Create** button. From the drop-down, select **Animator Controller** and call it **AlienBody**. With the Animation Controller selected in the Project browser, open the **Animator** window.

Next, **right-click** in the Animator window and select **Create State** → **Empty.**

Select the new empty and name it **Walking** in the Inspector. Next, **click** the circle beside the **Motion** property.

You're looking for **Default Take** but, in the list of animations, there are many clones. Select the **top-most Default Take**. Check the footer to see which model owns the animation.

Click through the Default Takes to find the one that belongs to **Assets/Models/Bobbleenemy-Body.blend**. Double-click it to select it.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_176_1.png)

Go to the Prefabs folder in the Project browser and expand **Alien's** disclosure triangle. Select **BobbleEnemy-Body**. You'll see that it already has an animator component attached.

In the Project browser, drag the AlienBody animation controller to the Controller property in the Inspector.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_177_0.png)

Play your game. Congrats! You officially have creepy-crawly aliens!

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_177_1.png)

## Animating the space marine

Now that the aliens mobilized, it's time to summon the space marine.

In the Models folder in the Project view, select the BobbleMarine-Body and click the Animation tab in the Inspector.

You'll see many unused animations that were imported with the model. This may have been the result of the export to FBX, but in future projects you may have animations that don't need.

Delete all of them except Armature|Walk and Armature|Idle by selecting and clicking the minus sign. Unfortunately, you must do this one at a time.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_178_0.png)

If you mistakenly delete the wrong animation, just click the Reset button at the bottom of the Inspector.

Breathe a sigh of relief now that you have a tidy workspace. Select the Armature|Walk animation and check the Loop Time bone checkbox to loop the animation indefinitely.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_178_1.png)

Click Apply to save changes.

You'll need to create a transition between the two different states. In the Project browser, select the Animations folder and click the Create button. From the dropdown, select Animator Controller. Give it the name SpaceMarine.

In the Hierarchy, select the SpaceMarine and BobbleMarine-Body. There is already an animator attached to it — you can see it in the Inspector. Drag the SpaceMarine animation controller from the Project browser to the Controller property on the Animator.

With the BobbleMarine-Body still selected in the Hierarchy, switch to the Animator. Create two states: MarineIdle and MarineWalk. Assign Armature|Idle to the MarineIdle and Armature|Walk animation to the MarineWalk state.

Set MarineIdle as the default state.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_178_2.png)

Now, you need to add some transitions. Right-click MarineIdle and select Make Transition. Drag it to MarineWalk. Do the same from MarineWalk to MarineIdle. Your animator controller should look like the following:

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_179_0.png)

Click the Parameters tab then click the plus sign. Select Bool from the drop-down and name it: IsMoving.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_179_1.png)

Now, click the transition from MarineIdle to MarineWalk, and in the Inspector, uncheck Has Exit Time. Also, click the plus sign under Conditions, and set the value to true.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_179_2.png)

Do the same for the transition from MarineWalk to MarineIdle, but set the Condition to false. When IsMoving is true, the walking animation will play, the marine will stand still.

## Where to go next?

To make this work, you need to write some code. Open the PlayerController script and add the following:

```csharp
public Animator animator;
```

Next, in FixedUpdate(), find the if statement that checks moveDirection. Insert the following:

```csharp
if (moveDirection != Vector3.zero)
{
    animator.SetBool("IsMoving", true);
}
else
{
    animator.SetBool("IsMoving", false);
}
```

Finally, drag the BobbleMarine-Body from the Hierarchy into the animator slot in the Inspector.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_180_0.png)

Now the game is coming together. You've learned:

- Keyframe animation: The basics of creating animation.
- Animator: How to use and manage animations.
- Triggering animations: How to do this in code.
- Outside animations: How to use animations created outside of Unity.
