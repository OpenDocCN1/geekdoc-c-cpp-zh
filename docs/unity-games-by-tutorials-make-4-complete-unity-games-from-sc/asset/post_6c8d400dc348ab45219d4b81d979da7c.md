![](img/fd5c2ca20ea33da76d2b61297cc57f6c_219_0.png)

This strange behavior is due to gravity and scaling. The typical gravity level is set to -9.81. If you scaled the models to one meter per unit, then they'd play well with gravity. However, your models are somewhat larger. You can fix this by scaling down the models or scaling up the gravity—you will scale the gravity in this book.

| Gravity | X:0 | Y:-900 | Z:0 |
|---|---|---|---|

| Bounce Threshold | 2 | | |

# Managing script order

When you play your game, you may see a null reference exception in the console.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_220_0.png)

This line points to the Gun script where the SoundManager is being accessed. Yet, this code worked in the past. What could have possibly changed?

```cs
void Start()
{
    audioSource = GetComponent<AudioSource>();
    audioSource.PlayOneShot(SoundManager.Instance.gunfire);
}
```

This is an example of script execution bug. The Gun script loads before SoundManager, yet SoundManager needs to run first before it can be used. You could rewrite the script or alter the order of the scripts.

Click Edit > Project Settings > Execution Order. You will see the following dialog:

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_220_1.png)

In the center, you'll see a box called Default Time. By default, scripts are loaded in your game. You can order your scripts before or after the default time.

Click the + to add a new script and select the Gun script.

### Decapitating the alien

Aliens have bobheads too, so they should die in the same way as the hero, but you'll have a little fun with the poor alien heads. Open the Alien script and add the following instance variables:

```cs
public Rigidbody head;
public bool isAlive = true;
```

head will help you launch the head, and isAlive will track the alien's state. Replace Die() with the following:

```cs
public void Die()
{
    isAlive = false;
    head.GetComponent<Animator>().enabled = false;
    head.isKinematic = false;
    head.useGravity = true;
    head.GetComponent<SphereCollider>().enabled = true;
    head.gameObject.transform.parent = null;
    head.velocity = new Vector3(0, 2.0f, 0.0f);
}
```

This code works similarly to the marine's death, but you disable the Animator for the alien. In addition, this code launches the head off the body. Add this code before the closing brace:

```cs
OnDestroy.RemoveAllListeners();
SoundManager.Instance.PlayOneShot(SoundManager.alienDeath);
Destroy(gameObject);
```

This block notifies the listeners, removes them and then deletes the GameObject. You want to make sure you don't call Die() more than once, so modify OnTriggerEnter(Collider other) as follows:

```cs
void OnTriggerEnter(Collider other)
{
    if (isAlive)
    {
        Die();
        SoundManager.Instance.PlayOneShot(SoundManager.alienDeath);
    }
}
```

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_222_0.png)

Here you check isAlive first. Finally, in Update(), surround the existing code with a similar check to see if the alien is alive.

```cs
if (isAlive)
{
    ...
}
```

Save and switch to Unity. In the Project view, click the disclosure triangle next to the Alien prefab to reveal its children, and select BobbleEnemy-Head. Click the Add Component button and select Rigidbody from the physics category. Uncheck the Use Gravity option and check the Is Kinematic option.

Click Add Component once again, and select Sphere Collider from the physics category. Set Center to (0, 0, 0.02) and Radius to 0.03. Disable the component by unchecking the component checkbox.

Finally, assign to the layer Alien Head and select Yes, change children when prompted.

Select the Alien prefab in the Project view. In the Inspector, drag the BobbleEnemy-Head to the head property.

Play the game.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_223_0.png)

It won't take long to accumulate an excess of disembodied alien heads. After a while, the space marine will struggle to differentiate the dead aliens from the living.

Name it SelfDestruct and click the Create Add button. Open it in your editor. Inside the class, replace the contents of the class with the following:

```cs
public float destructTime = 3.0f;
public void Initiate()
{
    Invoke("selfDestruct", destructTime);
}

private void selfDestruct()
{
    Destroy(gameObject);
}
```

This deletes the attached GameObject after a given amount of time. Now, the player's death makes both the head and body fall like you'd see in a episode of Game of Thrones.

### Adding particles

Are you having trouble believing that the process is so clean? Normally, you'll use particles to create effects such as fire, water and other systems. Ever play a game that featured snow? In most cases, the particle emitter was produced by the particle. Particles are a deep topic you should cover in depth.

> **Note:** If you'd like to explore Unity's particle system in depth, please check out our free introduction at https://raywender.com/introduction-particle-systems.

In the Project browser, drag an instance of the AlienDeath prefab into the scene. You'll see an instant splash of alien blood. Ew!

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_225_0.png)

Select it in the Hierarchy; you'll see a dialog in the Scene view with a few options.

| Particle Effect | | |
|---|---|---|
| Play | Restart | Stop |
| Playback Speed | 1.00 | |
| Playback Time | 0.00 | |
| Particles | 0 |
| Speed Range | 0.6 - 0.0 |
| Simulate Layers | Nothing | |
| Resumable | ✓ | |
| Show Bounds | | |

This control panel lets you tweak settings in real time when building particle effects. Press the **Play** button. You'll see the blood fly once again and notice that the button becomes a Pause button. You also have a Stop button to end the particle effect.

Temporarily drag an **Alien** prefab into the scene, and in the Hierarchy, drag **AlienDeathParticles** to make it a child of Alien. With **AlienDeathParticles** selected, set **Position** to (0, 1.07, -1.7) and **Rotation** to (-90, 0, 0). Click the **Apply** button to apply the changes to the AlienDeathParticle prefab.

Also apply the changes to all the instances of the Alien prefab by selecting the **Alien** in the Hierarchy and clicking the **Apply** button in the Inspector.

Now, click **AlienDeathParticles** in the Hierarchy and click on the **Play** button to see the alien bathed in green blood.
