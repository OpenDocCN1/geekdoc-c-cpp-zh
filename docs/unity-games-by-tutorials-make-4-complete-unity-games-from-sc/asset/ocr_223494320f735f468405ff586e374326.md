# Unity Games by Tutorials

Select the single-block prefab in the Hierarchy by pressing Control+D on PC or Command+D on a Mac, then drag the clone left or right in the scene to snap it to unit-spaces. Move SoyBoy over the line of single-block GameObjects so that it falls onto them when the game starts.

> Note: Matching the corners of the 2D blocks can be a little tedious. Frankly, you have vertex snapping to help you out. First select a sprite, hold V and select a vertex (a corner of the sprite), still holding V, and it will snap to any nearby vertex. Pretty convenient!

![](bbox=[0.201, 0.306, 0.798, 0.403])

In the Project Browser, right-click the Scripts folder and create a new C# Script. Name it SoyBoyController Double-click it to open the script in your editor.

At the top of the script, just add the public class SoyBoyController definition, add the following:

```
[Require(typeof(SpriteRenderer), typeof(Rigidbody2D), typeof(Animator))]
```

This line validates that any GameObject attached to this script has the necessary components required to work — it basically pre-qualifies the components. Your SoyBoy GameObject meets the requirement so it will pass with flying colors.

This is a handy script-writing trick that ensures the script only applies to GameObjects that meet the requirements.

Now you need fields that hold useful values and cache component reference for later use. Add the following variables inside the SoyBoyController definition but above the Start():

```
public float speed = 14;
public float accel = 6f;
private Vector2 input;
private SpriteRenderer sr;
private Rigidbody2D rb;
private Animator animator;
```
