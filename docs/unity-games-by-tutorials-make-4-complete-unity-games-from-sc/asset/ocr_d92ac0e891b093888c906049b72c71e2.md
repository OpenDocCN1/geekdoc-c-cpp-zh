Open the script in your code editor. Replace the contents of the class with the following:

```
public Gun gun;
nvoid OnTriggerEnter(Collider other)
{
    gun.UpgradeGun();
    Destroy(gameObject);
    SoundManager.Instance.PlayOneShot(SoundManager.Instance.powerUpPickup);
}
```

When the player collides with the power-up, this sets the gun to Upgrade mode, and then it will destroy itself (each pickup is good for one upgrade only). Also, a sound plays when the player picks up the upgrade and switches back to Unity.

# Save

Since the power-up should only be available to the space marine, you will need to adjust the physics layers. Select the Pickup and the Layer drop-down, set it to Upgrade. When prompted, select Yes, change children.

Now, you need to adjust the collision matrix. Click Edit > Project Settings > Physics. In the layers, uncheck the following from the Upgrade column: Bullet and Alien Head.
