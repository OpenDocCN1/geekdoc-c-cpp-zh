# Unity Games by Tutorials

In the FixedUpdate() method, just above the rb.AddForce(...), line the following:

```
var yVelocity = 0f;
if (PlayerIsTouchingOrWall() && input.y == 1)
{
    yVelocity = jump;
}
else
{
    yVelocity = rb.velocity.y;
}
```

This ensures that the yVelocity value is set to the jump value of 14 when the character is jumping from the ground, or from a wall. Otherwise, it's set to the current velocity of the rigidbody.

Still in the FixedUpdate() method, change the line that reads:

```
rb.velocity = new Vector2(xVelocity, rb.velocity.y);
```

To instead read:

```
rb.velocity = new Vector2(xVelocity, yVelocity);
```

The yVelocity is now used to modify the velocity of the character's Rigidbody.

At this point, your character can jump up walls, but he will just move straight up next to them when jumping. This definitely doesn't look right. The right way would be to propel him away from walls in the opposite direction jumping.

Just below the PlayerIsTouchingGroundWall() method, add another method:

```
public int GetWallDirection()
{
    bool isWallLeft = Physics2D.Raycast(new Vector2(
        transform.position.x - width, transform.position.y),
        Vector2.right, right, raycastLengthCheck);
    bool isWallRight = Physics2D.Raycast(new Vector2(
        transform.position.x + width, transform.position.y),
        Vector2.right, right, raycastLengthCheck);
    if (isWallLeft)
    {
        return -1;
    }
    else if (isWallRight)
    {
        return 1;
    }
    else
    {
        return 0;
    }
}
```
