# Unity Games by Tutorials

Here's the play-by-play:

+   1. The Enemy projectile needs to follow.

+   2. Speed at which this projectile moves, in units per second.

+   3. If the enemy this projectile is following doesn't exist anymore, it should destroy itself.

+   4. As long as there's still a target enemy, look at the target and move towards it.

+   5. If this projectile hits an object, and it's the enemy it's following, then call OnHitEnemy().

+   6. OnHitEnemy() is an abstract method that needs to be implemented by the derived class. It's also protected, which is the same as private except that it can be called from derived classes.
