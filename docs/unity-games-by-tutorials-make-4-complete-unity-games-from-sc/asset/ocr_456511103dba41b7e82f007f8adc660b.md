+   1. Set Instance to the UIMager script.
2. Update the gold, wave and escaped enemies Text values.
3. Takes a Tower Slot as a parameter, passes it to the Add Tower Window field and shows it at the position of the slot using the utility method MoveUiElementToWorldPosition().

Finally, add this method calls the Update() method:

```
UpdateTopBar();
```
