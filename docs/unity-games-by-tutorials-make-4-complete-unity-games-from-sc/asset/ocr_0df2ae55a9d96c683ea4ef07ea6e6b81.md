However, this model will be "flat shaded," wherein each face has a single, flat color. This greatly simplifies things for your UV map.

+   1. In the 3D View, select the Body object. Press Tab to switch to Edit mode. Make sure you are in Face Select mode (Ctrl-Tab).

+   2. Start by selecting the faces that make up the body. Press A for Select All doesn't work, since you don't want the spiked ball included. Press A to Select None, then select one face on the body.

+   3. Press L to Select Linked. This selects everything that's attached to the current selection. When you have multiple meshes combined into a single object, this is an essential shortcut for selecting them.

![](bbox=[0.157, 0.674, 0.842, 0.819])

+   4. Press 1, then 5 to switch to Front view, no perspective. Press U and select Project From View.
