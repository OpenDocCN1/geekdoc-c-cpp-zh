这非常直观：

- 1. 只有当指针进入了可交互的对象时，才继续执行。
- 2. 获取进入进入对象的 `OnPointerClick()` 事件。
- 3. 检查玩家身上仍然有可点击的内容，并且玩家按下了遥控器上的 Select（选择）按钮。
- 4. 执行对象的 `OnPointerClick()` 事件。
- 5. 没有可交互的对象，则重置 `currentLookAtHandler`。
