# Managing script order

When you play your game, you may see a null reference exception in the console.

![](bbox=[0.308, 0.175, 0.691, 0.219])

This line in points to the Gun script where the SoundManager is being accessed. Yet, this code worked in the past. What could have possibly changed?

```
void Start()
{
    audioSource = GetComponent<AudioSource>();
    audioSource.PlayOneShot(SoundManager.Instance.gunfire);
}
```

This is an example of script execution bug. The Gun script loads before the SoundManager script, yet the SoundManager needs to run first before it can be used.

You could rewrite the script or you alter the order of the scripts. In this case, you'll have to do.

Click Edit > Project Settings > Script Execution Order. You will see the following dialog:

![](bbox=[0.308, 0.493, 0.691, 0.725])

In the center, you'll see a box called Default Time. This is the time scripts are loaded in your game. By default, scripts are loaded in an arbitrary time during this period.

You can order your scripts before the default time or after the default time.

Click the + to add a new script and select the Gun script.
