# Animating the Pole Target

The tail animation is looking good, but remember when I talked about that heavy spiked ball looking like light-weight? It's time to animate the Pole Target to make the tail lead the bit, to make it look like it's pulling it along.

Make sure you are still in Pose mode. Select the Tail Pole Target bone. This object will only slide from side to side, so you'll only need to animate the X Location value.
