# Unity Games by Tutorials

This code rotates the alien towards the hero using the alien's y-axis position so that it doesn't look upwards and stare straight ahead.

Save and play your game.

You'll notice a bunch of things, none of which will bring you immediate joy:

+   1. There are aton of errors in the console.

+   2. The aliens move crazy slow.

+   3. The aliens walk through the columns.

Start with the first issue. You should see the following in the console:

> UnassignedReferenceException: The variable target of Alien has not been assigned.
You probably need to assign the target variable of the Alien script in the inspector.

If you only see one message, you may have the console set on Collapse. The collapse option groups allows repeating messages into one statement. The number after the log message indicates the count of log messages that have been generated.

![](bbox=[0.188, 0.506, 0.811, 0.567])

UnassignedReferenceException: The variable target of Alien has not been assigned
You probably need to assign the target variable of the Alien script in the inspector.

The error message states that no variable was assigned to the alien, i.e., one of the aliens doesn't have a reference to the space maine. This is an easy fix. Change update() to match the following:

```
if (target != null) {
  agent.destination = target.position;
}
```

Now run your game and check if the console is clear. If, make sure to click the On Play option.
