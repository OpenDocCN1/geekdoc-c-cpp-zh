# Unity Games by Tutorials

C# may take some time to learn, but you can leverage those programming skills outside of Unity. For instance, if you find yourself dising game development (or having a hard time making a living) but enjoying the language, you can transition those skills into a C# development job, creating desktop or mobile apps, or even developing backend servers.

The way coding works in Unity is that you create scripts. Scripts are simply another type of component that you attach to GameObjects, you just get to write the code for.

A script derives from a class called MonoBehaviour, and you can override several methods to get notified upon certain events:

+   - **Update():** This event occurs at every single frame. If your game runs at sixty frames per second, Needless to say, you don't want to do any heavy processing in this method.

+   - **OnEnable():** This is called when a GameObject is enabled and when an inactive GameObject suddenly activates. Typically, you deactivate GameObjects when you don't need them for a while but will need a at a later point in time.

+   - **Start():** This is called in the script's lifetime and before Update() is called. It's a good place to do setup and initialization.

+   - **Destroy():** This is called right before the object goes to the GameObject after. It's a good place to clean up, such as shutting down network connections.

There are many other events that you will discover throughout this book. To see a complete listing, head to the MonoBehaviour reference on Unity's site:

+   - https://docs.unity3d.com/ScriptReference/MonoBehaviour.html

# Creating your first script

It's showtime!

You have many options for creating a script. You could click the Add Component button and then Select New.

But I'd like you to try it well: Select the Scripts folder in the Project Browser, and then click the Create C# Script from the drop-down menu and name it PlayerController..

You'll see that your new script in the Scripts folder. Drag it from the Scripts folder onto the SpaceMarine GameObject.
