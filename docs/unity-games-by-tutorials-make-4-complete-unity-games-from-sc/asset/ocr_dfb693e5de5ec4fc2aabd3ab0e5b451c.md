# Getting started

Unity's extensive list of features and components empower you to create compelling 2D games. Aside from standard components as sprites, animations and physics colliders, you also get specialized physics, joints and zone effector components. As you create Super Soy Boy, you'll explore the most common and useful 2D components. They generally work hand-in-hand with colliders.

To begin your 2D pilgrimage, open the Starter project for this chapter in Unity. It contains all the resources and sprites you will need to get working. Load the Game scene located the Scenes sub-folder.

# Sprites: Building blocks of 2D games

All the sprites you'll need in the Assets Sprites sub-folder. Locate the single-block.png sprite in the Sprites sub-folder and then drag and drop it into the Scene window.
