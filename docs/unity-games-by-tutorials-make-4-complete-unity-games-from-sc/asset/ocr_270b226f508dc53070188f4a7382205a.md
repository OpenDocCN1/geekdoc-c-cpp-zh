Now, add the following to the end of the existing Start() method:

```
DiscoverLevels();
```

DiscoverLevels() is called when the Game Manager initializes to retrieve any level files from JSON, and populate the menu with buttons for each.

Save your changes and switch back to Unity. In the Menu scene, drag and drop the LevelButton prefab from the Prefabs folder onto the Button Prefab reference on the GameManager in the scene Inspector.

Now make a bunch of duplicate JSON level files with different names. Remember you can do this by loading the Game scene, selecting the Level GameObject, and clicking Save level with different names. Run the game from the Menu scene.
