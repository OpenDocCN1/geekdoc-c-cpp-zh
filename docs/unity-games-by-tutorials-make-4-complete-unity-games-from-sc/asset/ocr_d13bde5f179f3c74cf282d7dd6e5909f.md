Players should be able to easily return to the Menu scene and use the level selection interface.

Add this Update() method to GameManager.cs:

```
void Update()
{
    if (Input.GetKeyDown(KeyCode.Escape))
    {
        SceneManager.LoadScene("Menu");
    }
}
```

This checks for an Escape keypress and loads the Menu scene if detected.

Now, it's easy to go back to the level selection UI in the Menu scene at any point.
