# Unity Games by Tutorials

If you don't see the Character Controller option, then you didn't import the Standard Assets when you installed Unity. To fix this, re-run the Unity installer and only check Standard Assets for the install. A standard Unity Asset is any regular package; it's just a collection of files.

Click Import in the dialog to import the character assets. When the import is completed, you will notice a new folder in the Project browser called Standard Assets. This contains everything you imported.

The first modification is to remove the jumping action and a few other actions that you won't need, such as footsteps and headbobbing. Robot Rampage doesn't jump obstacles, and by default, the Unity Character Controller uses the spacebar to jump.

In the Project browser, open the FirstPersonController in your code editor located in Assets > Standard Assets > Characters > FirstPersonCharacter > Scripts.

Comment out lines 39, 50, 112 to 127, 165–176, and 182–200. To comment out a line, simply place // in front of the line. To comment multiple lines put // above the last line to comment.

Save the file and switch back to Unity. Drag the FirstPersonController script on top of the Player GameObject. Click the Game GameObject, and use the Inspector to set Position to (23.7, 2.68, 24.11). Rotation to (0, -88.18, 0).

This puts the player in one of the corners and rotates the player facing the hallway as opposed to staring at a wall.

The FirstPersonController script also has values for run speed and walk speed. Set the Player Walk Speed to 10, and Run Speed to 20.
