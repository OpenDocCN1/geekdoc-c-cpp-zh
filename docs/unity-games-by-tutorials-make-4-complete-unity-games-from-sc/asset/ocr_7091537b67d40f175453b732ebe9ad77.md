# Setting up Unity for the HTC Vive

In the Hierarchy, disable the Main Camera and drag in [CameraRig] from the SteamVR > Prefabs folder to the scene:

![](bbox=[0.219, 0.517, 0.78, 0.696])

Rename it to ViveRig, and set its position to (0, 0, 10).
