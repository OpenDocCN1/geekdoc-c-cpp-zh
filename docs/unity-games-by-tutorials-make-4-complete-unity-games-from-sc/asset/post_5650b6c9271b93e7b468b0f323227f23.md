# The basics

C# is a strongly typed language. This means, you must define your variable types you use. The more common types are: int, float, double, string and bool.

Inside Main(), add the following before the closing brace:

```csharp
int meaningLife = 42;
float smallPi = 3.14f;
double bigPi = 3.14159265359;
string vaporWare = "Half Life";
bool likesPizza = true;
```

Your code should look like:

```csharp
// retester.Main is the entry point for your code. Don't change it.
// Compiler version 4.0.30319 .NET Framework 4.5
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text.RegularExpressions;

namespace retester
{
    public class Program
    {
        public static void Main(string[] args)
        {
            // Your code goes here
            Console.WriteLine("Hello, world!");

            int meaningLife = 42;
            float smallPi = 3.14f;
            double bigPi = 3.14159265359;
            string vaporWare = "Half Life";
            bool likesPizza = true;
        }
    }
}
```

The variables hold the data. int holds integer data. float and double hold numbers with decimal points, otherwise known as floating point data. A double uses twice as much memory to store as a float, so it can hold a much larger range of values.

Strings are meant to hold text and a bool can only be set to true or false. This is important when making decisions in your code.

Notice that the value for smallPi is 3.14f. The f indicates that the number is a float. By default, all floating point numbers are considered doubles, so you must indicate that you mean to use a float. Delete the f and click the Run button. You'll see the following:

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_622_0.png)

```
Error CS0664: Literal of double cannot be implicitly converted to 'float'; use an 'F' suffix to create a literal of this type
```

C# thinks you are assigning a double to a float — there isn't enough room to store a double in a float. Unity uses floats all over the place so you'll run into this. Add the f back to 3.14.

You'll also notice that each line concludes with a semicolon. In C#, this is the same as the end of a sentence. It lets the compiler know that a statement is concluded. If you forget to add a semicolon, you'll experience a compiler error. C# will not be able to determine the intent of your code, and it will stop compiling.

C# can also infer the type of a variable. Change the variables to the following:

```csharp
var meaningOfFloat = 42;
var smallPi = 3.14;
var bigPi = 3.14159265359;
var vaporWare = "Half Life";
var likesPizza = true;
```

By using the var keyword, C# is able to determine the type based on the value being assigned to it. This is a nice feature to save time. If you are new to the language, then defer to declaring your types so that you can get used to thinking in types.

Often times, you'll want your variables to be immutable. Add the keyword const before likesPizza like so:

```csharp
const var likesPizza = true;
```

Now change it. Add the following code underneath the previous statement:

```csharp
likesPizza = false;
```

Click the Run button. You'll get two errors:

```
(22:19) Implicitly-typed local variables cannot be constant
(23:13) The left-hand side of an assignment must be a variable, property or indexer
```

First, you cannot use a constant with an inferred type. This means you should replace var with bool. Second, you are trying to change something that you've defined as a constant. Update the definition of likesPizza like so:

```csharp
const bool likesPizza = true;
```

and delete:

```csharp
likesPizza = false;
```

Click the Run button and your code will run.

# Arrays

Arrays constructs hold multiple values. Add the following:

```csharp
string[] writers = { "Anthony", "Brian", "Eric", "Sean" };
```

This creates a list of writers, all accessible from the variable called writers. If you don't know the values that you are using, you can just define the number of values you think you need, like so:

```csharp
string[] editors = new string[5];
```

This creates an array with a capacity of five elements. Notice the new keyword. This creates an instance of the array of strings. This keyword becomes important when working with objects.

Add the following:

```csharp
Console.WriteLine(writers[2]);
```

Click the Run button and you will see Eric's name printed to the console.

![](img/fd5c2ca20ea33da76d2b61297cc57f6c_624_0.png)

C# starts with zero, so the second element of the array is 1. You can replace a value in the array.

```csharp
writers[0] = "Ray";
```

This replaces the first string in the array.

# Control flow

When writing your programs, you'll need to control how the code flows based on certain values. Your if statement will get started. Add the following underneath the previous code:

```csharp
if (likesPizza == false)
{
    Console.WriteLine("You monster!");
}
```

Like other languages, the statement is evaluated and the code between the braces is run. When assigning variables, C# also contains a ternary operator. Add the following:

```csharp
bool isMonster = (likesPizza == true) ? false : true;
```

This is just a shorthand for assigning a value.

Like other languages, you also have a bevy of loops at your disposal. The first loop is the traditional for loop.

```csharp
for (int i=0; i < 10; i++)
{
    Console.WriteLine("C# Rocks!");
}
```

The loop works to initialize a variable named i, then loops 10 times, all while incrementing i after each iteration. Click the Run button and you'll see that C# really does rock.

Loops work great with arrays. The array has a Length property, which tells you how many elements are in the array. Add the following:

```csharp
for (int i=0; i < writers.Length; i++)
{
    string writer = writers[i];
    Console.WriteLine(writer);
}
```

This loops through all the elements of the array and prints each element to the console.
