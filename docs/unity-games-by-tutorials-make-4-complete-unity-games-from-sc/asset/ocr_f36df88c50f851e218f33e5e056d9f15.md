# Scripting the controller for jumping and wall sliding

The first bit of extra functionality you will add is the ability to perform a basic jump.

Open SoyBoyController.cs in your code editor, and add the following, new public fields to the top of the script, just below the other existing fields:

```
public bool isJumping;
public float jumpSpeed = 8f;
private float raycastLength = 0.005f;
private float width;
private float height;
```

At the bottom of the Awake() method, add the following code:

```
width = GetComponent<Collider2D>().bounds.extents.x + 0.1f;
height = GetComponent<Collider2D>().bounds.extents.y + 0.2f;
```

Here, you grab the width and height of SoyBoy's sprite. In addition to these dimensions, you also add 0.1 and 0.2 to the width and height of the sprite respectively. This gives a little bit of buffer, to allow the raycast checks later to stay outside of the sprite, rather than inside the sprite bounds.

Remember that this script is attached to SoyBoy, so the GetComponent calls will search for these components on the SoyBoy GameObject.
