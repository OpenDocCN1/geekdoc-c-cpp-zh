Select Game Manager and set the amount of Gold to 400. This will be the starting gold so players can buy towers from the start. It would be a pretty pointless game if you started off with zero!

Press the Play button and test out the tower slot. When you click on it, the AddTower window should appear and, when you click on the Stone Tower icon, a tower should be built in that spot!

![](bbox=[0.293, 0.293, 0.707, 0.373])

With that working, it's a good idea to make all the tower slots and organize them. In the Hierarchy, create a new empty GameObject and name TowerSlots. Reset its Transform and drag TowerSlot to TowerSlots in the Hierarchy to make it a child GameObject.

Now, keep duplicating TowerSlot and move the copies around using snapping (hold Ctrl until you've got all these positions covered):

![](bbox=[0.362, 0.527, 0.637, 0.643])

You can use Y-axis half-tile snapping to get to those higher parts on the top-right of the map. Now, save the scene, run it again and buy some stone towers to kill all enemies. You should hear the “win” sound effect when you cleared the wave of enemies.
