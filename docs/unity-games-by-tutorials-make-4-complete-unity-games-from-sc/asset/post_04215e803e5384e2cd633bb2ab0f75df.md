Now you have to address a small rendering issue. In this case, Unity renders the particles underneath the floor because it draws the floor *after* it draws the particles.

To avoid this, you need to assign the particles to a Sorting Layer, which will determine the order in which Unity renders objects. Typically, you use these with Unity 2D, but there are use cases for sorting layers in 3D games, too.

Expand the **Renderer** section of the particle system. In the **Sorting Layer** property, select **Add Sorting Layer...**. The Inspector will change to **Tags & Layers**. Click the + and name the sorting layer **Foreground.**

| Sorting Layers |
|---|---|
| Layer | Default |
| Layer | Foreground |

Return to the **Renderer** module, and in the **Sorting Layer**, select the **Foreground** property. Keep in mind that you'll need to do the same thing for the space marine.

Now click the **Apply** button to apply the changes to the prefab.

## Activating particles in code

Unity allows for all sorts of adjustments to particle systems in code. In your case, just need to know if the particle system is running or not.

In the Project view, select the Scripts folder and click the Create button. Choose C# Script and name it DeathParticles. Open the script in your editor.

Add the following instance variables:

```
private ParticleSystem deathParticles;
bool didStart = false;
```

deathParticles refers to the current particle system and didStart lets you know the particle system has started to play.

You need to get a reference to the particle system, so add the following to Start():

```csharp
deathParticles = GetComponent<ParticleSystem>();
```

Add the following method:

```csharp
public void Activate(){
    didStart = true;
    deathParticles.Play();
}
```

This starts the particle system and informs the script that it started. In Update(), add the following:

```csharp
if (didStart && deathParticles.isStopped){
    Destroy(gameObject);
}
```

Once the particle system stops playing, the script deletes the death particles because they are meant to play only once.

Finally, to address the need for a collision plane set in code, add the following method:

```csharp
public void SetDeathFloor(GameObject deathFloor){
    if (deathParticles == null){
        deathParticles = GetComponent<ParticleSystem>();
    }
    deathParticles.collision.SetPlane(0, deathFloor.transform);
}
```

The script first checks to see if a particle system has been loaded, which is necessary because the Alien prefab is instantiated and used immediately.

In Start() the deathParticles isn't populated, this line populates it. Then it sets the collision plane.

Now to activate the particles — it's a similar process for the aliens and the marine, but the aliens need a little set-up work.

First, you need to get a reference to the particle system and it's a child of the Alien GameObject, so you need code to get it.

Open Alien in your code editor, and add the following instance variable:

```csharp
private DeathParticles deathParticles;
```

Then create the following method:

```csharp
public DeathParticles GetDeathParticles()
{
    if (deathParticles == null)
    {
        deathParticles = GetComponentInChildren<DeathParticles>();
    }
    return deathParticles;
}
```

The magic occurs in GetComponentChildren(). It returns the first death particle script that it finds. With only one script there's no possibility of grabbing the wrong one.

In Die(object), add the following before Destroy(gameObject):

```csharp
if (deathParticles)
{
    deathParticles.transform.parent = null;
    deathParticles.Activate();
}
```

This makes the blood splatter when an alien dies. You have to remove the parent.
Otherwise, the particles are destroyed along with the GameObject.

Open GameManager add this instance variable:

```csharp
public GameObject deathFloor;
```

In Start() add the following after alienScript.Destroy:

```csharp
alienScript.GetDeathParticles().SetDeathFloor(deathFloor);
```

The winning sequence will run as follows:

- When the marine kills all the aliens, the hatch opens and the elevator rises.
- Once the space marine steps onto the elevator, the elevator ascends to the ceiling — perhaps to elevate the marine to immortal status or the next game level. Who knows?
