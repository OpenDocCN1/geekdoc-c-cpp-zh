# Chapter 18: Making A Tower Defense

This will notify the GameManager that a new wave started.

Add this line to the UpdateActiveWave() method, right under if
(activatedWaves.Count == enemyWaves.Count) {

```
GameManager.Instance.enemySpawningOver = true;
```

This is to tell GameManager that the WaveManager has stopped spawning enemies.

Save the WaveManager script and open the Enemy script (Scripts -> Game -> Enemy folder). Add this line to OnGotoLastWayPoint(), right above Die():

```
GameManager.Instance.OnEnemyEscape();
```

That will notify the GameManager that this enemy got to the exit.

Now add the following method under TakeDamage():

```
void DropGold()
{
    GameManager.Instance.gold += goldDrop;
}
```

Also place a call to the method in TakeDamage(), right above Die():

```
DropGold();
```

Now, the enemy will give the player gold when it dies of an attack. Save the script and return to the editor. Press the Play button and look at the Game Manager in the Inspector. Each time an enemy escapes the Escaped Enemies variable will go up:

![](bbox=[0.283, 0.623, 0.735, 0.814])

Once the number reaches the maximum allowed, all enemies will be destroyed and the lose sound will play.
