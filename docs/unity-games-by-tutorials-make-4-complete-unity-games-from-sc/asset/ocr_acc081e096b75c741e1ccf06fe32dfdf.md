# # Chapter 24: Visual Studio

By Brian Moakley

Prior to Unity 2018.1, Unity shipped with a code editor MonoDevelop. It worked well enough, but there were lots of quality issues (such as code highlighting inconsistencies) when working with it. Over a period of time, these quality issues could make the code editor frustrating to use. This earned it quite a bad reputation among developers.

Thankfully, in 2017, Microsoft released its much-loved Visual Studio for macOS, which is now installed by default with Unity. The days of MonoDevelop are behind you. That said, the two versions of Visual Studio are not identical and you may run into inconsistencies.

In this chapter, you'll get an overview of the Windows version; the screenshots may look slightly different but functionally, they are the same.
