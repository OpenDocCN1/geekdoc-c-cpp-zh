# Adding some utility

When working with Unity, there are often actions that you use in several different scripts across your game. Some examples:

+   - Moving an item up and down like it's floating.
- Constantly rotating an object.
- Scaling an object up and down.
- Making objects look like others.

Instead of adding these functions to each script that might need it, you can write small utility scripts that you can reference and use instead. The utility scripts you will write can be useful for just about any game. It's like a toolbox for Unity!

First is a script that constantly rotates the GameObject it's attached to. This will be handy for the enemies as two have wheels and one of them has a rotor.

In the Project Browser, create a new C# Script in the Scripts > Utility folder named LoopRotate and open it in your code editor. Remove the Start() method completely and put this line under the class declaration:

```
public Vector3 rotation;
```

This is the desired rotation of the GameObject that this script will attach to.

Inside the Update() method, add this line:

```
transform.Rotate(rotation * Time.deltaTime);
```

This will make the object rotate every frame by the rotation specified in rotation.
Pretty simple, right? It will help tremendously though!

Save this script and return to the Unity editor.
