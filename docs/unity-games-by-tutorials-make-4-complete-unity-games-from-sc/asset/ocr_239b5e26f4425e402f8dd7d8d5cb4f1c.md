If you try the game, you'll notice it's impossible to add any towers as the AddTowerWindow GameObject isn't showing up on-screen. This is because the Screen Canvas has been replaced by a World Space Canvas. This means the elements are free to be placed, scaled and rotated in the game world instead of being locked to the screen.

Also, take a look at the giant floating UI elements around the camera. These have been placed along a curved mesh.

![](bbox=[0.424, 0.258, 0.575, 0.332])

This lets the UI stay at a relatively constant size without being squished. Try looking at a poster or a TV screen from a sharp angle, and you'll immediately know what I'm talking about.

In order to use the Oculus Rift and its remote in Unity, you'll need to download the newest version of the Oculus Utilities found here: https://developer.oculus.com/downloads/unity.

Once you've downloaded the utilities, unzip the file and click the unitypackage. Open the Import Package. Press the Import button at the bottom right to import the package into Unity. Now, take a look at the Project view. A new folder called OVR has been added to the Assets folder.
