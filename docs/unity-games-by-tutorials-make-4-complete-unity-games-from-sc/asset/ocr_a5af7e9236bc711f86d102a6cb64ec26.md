# # Interacting with the world

There are several ways of handling input in VR. But for Runestife,you'll be using one of the controllers to point at the world and the UI to interact with it. The SteamVR plugin doesn't come with such a system out of the box, so you'll have to add it yourself.

Start off by expanding the ViveRig in the Hierarchy so you can see its children. Select Controller (right). Right-click it, and select Camera to create a new camera as a child. Name it ControllerCamera.

This camera wasn't used to actually see through. It's going to be used purely to firecasts into the scene so you can see and interact with colliders and UI elements.

Change the camera's Clear Flags to Solid Color, set its Depth to -5 and adjust your Target Eye to None (Main Display). Next, remove the Flare Layer, GUI Layer and Audio Listener components. This camera wasn't used for rendering anything. It doesn't need to listen to sounds or music either, so those components aren't necessary.

Finally, adding a Physics Raycaster component so it can send raycasts to 3D colliders. Do this in the Inspector panel by clicking Add Component and searching for it by name.
