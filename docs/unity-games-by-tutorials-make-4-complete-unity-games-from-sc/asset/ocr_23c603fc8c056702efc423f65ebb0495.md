Your game logs GameOver when the player's health hits zero. Later on, you'll code a proper game-over screen.

Those pesky robots are still invincible. It's time for them to take some damage, too.

Open the Robot script and add the following methods:

```
// 1
public void TakeDamage(int amount)
{
    if (isDead)
    {
        return;
    }

    health -= amount;

    if (health <= 0)
    {
        isDead = true;
        robot.Play("Die");
        StartCoroutine("DestroyRobot");
    }
}

// 2
Enumerator DestroyRobot()
{
    yield return new WaitForSeconds(1.5f);
    Destroy(gameObject);
}
```

Looking closely at the above:

+   1. This has roughly the same logic as the player TakeDamage() method, except when health hits zero, it plays a death animation before calling DestroyRobot().

+   2. This adds a delay before destroying the robot. This lets the Die animation finish.
