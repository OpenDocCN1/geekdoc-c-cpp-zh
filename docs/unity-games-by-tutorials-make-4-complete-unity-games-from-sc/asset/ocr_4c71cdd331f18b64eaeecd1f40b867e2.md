# Chapter 18: Making A Tower Defense Game

![](bbox=[0.125, 0.083, 0.875, 0.296])

You can now make waves from inside the editor. Set the **Size of Enemy Waves to 1** to create the first one. Fully expand all field to expose all variables:

![](bbox=[0.125, 0.358, 0.875, 0.532])

For this first wave, leave the **Path Index and Start Spawn Time In Seconds to 0** and set **Time Between Spawns In Seconds to 2**.

To add the actual enemies, use the **Prefabs > Enemy** folder in the Project browser and select the **Wave Manager** in the Hierarchy. Now drag and drop the enemy prefab onto the **List of Enemies** field to add them to the list.

The prefabs will spawn to top bottom:

![](bbox=[0.125, 0.704, 0.875, 0.868])

Fill up the list with **NormalEnemy** and sprinkle a few of the others around.
