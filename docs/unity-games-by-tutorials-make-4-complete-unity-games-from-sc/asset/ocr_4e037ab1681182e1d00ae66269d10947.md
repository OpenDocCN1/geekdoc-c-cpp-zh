# Unity attributes

Unity attributes are special declarations you can use throughout your code. These attributes perform a variety of functions on your GameObjects.

One of the great things about attributes, as you've seen in the previous example, is that you can use them to extend the editor. By default, all code runs in Play mode, but with an attribute, you can run it in the editor as well.
