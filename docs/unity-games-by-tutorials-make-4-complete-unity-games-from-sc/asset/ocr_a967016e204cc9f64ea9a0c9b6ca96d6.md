# # Creating a Game Manager

You'll create a Game Manager that will allow you to manage the win and lose states for the game. To keep things simple, this game manager will restart the level when you win or lose. For this purpose, you will create a singleton instance script. A singleton is essentially an instance of class that should only have one instance at any time.

In the Scripts folder, create a new script called GameManager. Create a new GameObject in the game called GameManager and attach the new GameManager.cs script to it.

Open GameManager.cs in your code editor. At the top of the class, add a new public static field that holds the instance reference for the GameManager singleton:

```
public static GameManager instance;
```

Create the following Awake() method:

```
void Awake() {
    if (instance == null) {
        instance = this;
    }
    else if (instance != this) {
        Destroy(gameObject);
    }
    DontDestroyOnLoad(gameObject);
}
```
