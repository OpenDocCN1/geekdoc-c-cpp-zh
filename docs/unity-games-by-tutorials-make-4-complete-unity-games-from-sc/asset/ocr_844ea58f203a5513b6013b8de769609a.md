```
{
  //2
  currentLookAtHandler = ExecuteEvents.GetEventHandler<IPointerClickHandler>(pointerEventData.pointerEnter);
  //3
  if (currentLookAtHandler != null &&
      OVRInput.GetDown(OVRInput.Button.One)) {
    //4
    ExecuteEvents.ExecuteHierarchy(currentLookAtHandler, pointerEventData, ExecuteEvents.pointerClickHandler);
  }
  else {
    //5
    currentLookAtHandler = null;
  }
}
```

This is pretty straightforward:

+   1. Continue only if the pointer has entered an object to interact.
2. Get the OnPointerClick() event of the entered object.
3. Check that there's still something to click on the player and the player has pressed the Select button on their remote.
4. Execute the object's OnPointerClick() event.
5. No object to interact with, reset the currentLookAtHandler.
