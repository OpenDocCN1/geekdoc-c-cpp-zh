

# 还有哪些地方我可以读到关于 C++0x 的资料？

随着标准的日趋完善，有关 C++0x 的资料会愈来愈多，C++ 的各种实现（例如 GCC、Visual C++）开始提供新的语言特性和库。下面是资源列表：

- [委员会的网址](http://www.open-std.org/jtc1/sc22/wg21/docs/papers/)

- [C++0x 草案](http://www2.research.att.com/~bs/SC22-N-4411.pdf)

- [the C++0x 维基百科](http://en.wikipedia.org/wiki/C%2B%2B0x)。积极维护，但明显不是委员会的成员。

- 帮助页：[GCC’s experimental implementation of C++0x features](http://gcc.gnu.org/projects/cxx0x.html)
