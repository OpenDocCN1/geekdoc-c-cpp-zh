# C STATEMENT SUMMARY

Preprocessor directives to include information from the files in the Standard C library:

```
#include <stdio.h>
#include <math.h>
#include <ctype.h>
```

Preprocessor directive to define a symbolic constant:

```
#define PI 3.141593
```

Declarations for integers:

```
short sum=0;
int year_1, year_2;
long k;
```

Declarations for floating-point values:

```
float height_1, height_2;
double length=10, side1, side2;
long double distance, velocity;
```

Assignment statement:

```
area = 0.5*base*(height_1 + height_2);
```

Keyboard input statement:

```
scanf("%i",&year);
```

Screen output statement:

```
printf("The area is %f square feet. \n",area);
```

Program exit statement:

```
return 0;
```

Directive to read a character from keyboard:

```
c = getchar();
```

Directive to print a character to the screen:

```
putchar(c);
```

# NOTES

+   1. Use comments throughout a program to improve the readability and to document the steps in it.
+   2. Use blank lines and indenting to identify the structure of a program.
+   3. Use the units in a variable name when possible.
+   4. Symbolic constants should be used for engineering constants such as π, and they should be uppercase so that they are easily identified.
+   5. Use consistent spacing around arithmetic and assignment operators.
+   6. Use parentheses in complicated expressions to improve readability.
