# Function Arguments

When arrays are used as function parameters, the references are call-by-address instead of call-by-value. In Section 5.1, which discussed one-dimensional arrays, we learned that array references in a function refer to the original array and not a copy of the array. Thus, we must be careful so we do not unintentionally change values in the original array. Of course, an advantage of a call-by-address reference is that we can make changes in the array values, in addition to returning a value from the function call.
