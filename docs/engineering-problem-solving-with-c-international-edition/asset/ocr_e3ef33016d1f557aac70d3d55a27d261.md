A graph with two arbitrary data points f(a) and f(c) is shown in Figure 2.2. If we assume that the function between the two points can be estimated by a straight line, we can then compute the function value at any point f(b) using an equation derived from similar triangles:

$f(b) = f(a) + \frac{b - a}{c - a}[f(c) - f(a)]$

Recall that we are also assuming that a < b < c.

To illustrate using this interpolation equation, assume that we have a set of temperature measurements taken from the cylinder head in a new engine that is being tested for possible use in a race car. These data are plotted with straight lines connecting the points in Figure 2.3, and they are also listed here:
