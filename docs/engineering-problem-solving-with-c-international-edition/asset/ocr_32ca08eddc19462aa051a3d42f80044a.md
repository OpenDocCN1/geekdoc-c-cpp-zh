```
/* Declare and initialize variables. */
int k;
double x[6], sum=0;
...
/* Sum the values in the array x. */
for (k=0; k<=5; k++)
    sum += *(x+k);
```

This example illustrates the use of an array name as an address. In most statements, the array name can replace a pointer, but it cannot be used on the left side of an assignment statement, because its value cannot be changed.
