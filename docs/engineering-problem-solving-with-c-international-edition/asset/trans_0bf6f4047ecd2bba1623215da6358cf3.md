

## 5. 测试

我们解决问题过程的最后一步是测试解决方案。我们应该首先使用手算示例中的数据来测试解决方案，因为我们已经计算出了解决方案。当执行此解决方案中的 C 语句时，计算机会显示以下输出：

```
The distance between the two points is 3.61
```

此输出与我们手算计算出的值一致。如果 C 解决方案与手算解决方案不匹配，那么我们应该审查两种解决方案以找出错误。一旦解决方案对手算示例有效，我们还应该使用其他数据集进行测试，以确保解决方案对其他有效数据集也有效。

本示例中演示的步骤用于开发后续章节中“应用问题求解”部分的程序。

- 1. 清晰地陈述问题。
- 2. 描述输入和输出信息。
- 3. 对一组简单数据手算（或使用计算器）解决问题。
- 4. 开发算法并将其转换为计算机程序。
- 5. 使用各种数据测试解决方案。

在整个文本中，我们将在开发问题解决方案时使用此过程。

### 判断题

指示以下陈述是正确 (T) 还是错误 (F)：

- 1. CPU 由 ALU、内存和处理器组成。T F
- 2. 链接/加载是为目标程序执行做准备的步骤。T F
- 3. 算法逐步描述问题的解决方案，而计算机程序一步解决问题。T F
- 4. 计算机程序是算法的实现。T F
- 5. 实用程序将 C 转换为二进制。T F
- 6. 微处理器是非常小的处理器。T F
- 7. 数据可以通过 ALU 在内部内存和外部内存之间通信。T F
- 8. 电子表格可用于以图形方式操作对象。T F
- 9. 计算机辅助设计仅用于设计微型计算机。T F
- 10. 字处理器允许我们输入和编辑文本。T F
- 11. 数学软件工具在计算和可视化方面都非常强大。T F
- 12. 要纠正逻辑错误，我们只重复执行步骤。T F
- 13. 编译步骤识别程序中的所有错误。T F
- 14. 算法给出了解决问题的步骤。T F
- 15. 计算机程序是解决问题的一组指令。T F
- 16. 如果程序对一组数据有效，则该程序已完全测试。T F
- 17. 内核是一块硬件。T F
- 18. C 是最早开发的高级语言之一。T F
- 19. 软件维护是当今软件系统成本中微不足道的一部分。T F
- 20. 用机器语言编写的程序可以表示为二进制字符串。T F

### 选择题

圈出完成每个陈述的最佳答案的字母：

- 21. 指令和数据存储在
- (a) 算术逻辑单元 (ALU)。
- (b) 控制单元 (处理器)。
- (c) 中央处理器 (CPU)。
- (d) 内存。
- (e) 键盘。

- 22. 操作系统是
- (a) 由用户设计的软件。
- (b) 用户与硬件之间方便高效的接口。
- (c) 允许我们执行常见操作的实用程序集合。
- (d) 一组软件工具。

- 23. 源代码是
- (a) 编译器操作的结果。
- (b) 从处理器获取信息的过程。
- (c) 用计算机语言编写的解决特定问题的一组指令。
- (d) 存储在计算机内存中的数据。
- (e) 通过键盘输入的值。

- 24. 目标代码是
- (a) 编译器对源代码进行操作的结果。
- (b) 从处理器获取信息的过程。
- (c) 一个计算机程序。
- (d) 涉及列出解决特定问题所需命令的过程。
- (e) 链接/加载过程的结果。

- 25. 算法是指
- (a) 解决特定问题的逐步解决方案。
- (b) 计算机可以理解的一组指令。
- (c) 允许我们输入文本材料的代码。
- (d) 逐步细化。
- (e) 一组用于推导问题解决方案的数学方程。

- 26. 硬拷贝是
- (a) 存储在硬盘上的信息。
- (b) 打印在纸上的信息。
- (c) 显示在屏幕上的信息。
- (d) 一个计算机程序。
- (e) 以上全部。

- 27. 计算机硬件包括
- (a) 键盘。
- (b) 打印机。
- (c) 磁盘驱动器。
- (d) 终端屏幕。
- (e) 以上全部。

- 28. 软件示例是
- (a) 打印机。
- (b) 屏幕。
- (c) 计算机代码。
- (d) 以上全部。
- (e) 高级语言。

- 29. 高级语言是
- (a) 适合实时编程。
- (b) 第二代计算机语言。
- (c) 称为自然语言。
- (d) 用类似英语的单词编写。

- 30. 源程序和目标程序之间的区别是
- (a) 源程序可能包含一些错误，而目标程序不包含任何错误。
- (b) 源程序是原始代码，而目标程序是修改后的代码。
- (c) 源程序以高级语言指定，而目标程序以机器语言指定。
- (d) 目标程序也是源程序。
- (e) 源程序可以执行，而目标程序不能执行。

- 31. 解决问题时的起点是
- (a) 开发算法。
- (b) 编写程序。
- (c) 编译源程序。
- (d) 链接到目标程序。

- 32. 手算示例是指
- (a) 用手做算术。
- (b) 使用一组简单数据详细计算问题的解决方案。
- (c) 列出问题解决方案的大纲。
- (d) 展开解决方案的大纲。
- (e) 使用计算器逐步测试算法。

- 33. 计算机程序是
- (a) 包含输入和输出设备的组件集合。
- (b) 解决问题所需的一组指令列表。
- (c) 一组由计算机执行并以计算机可以理解的语言编写的指令。
- (d) 解决问题的逐步过程。
- (e) 将问题分解为更简单步骤的大纲。
