| Operation | Result |
|---|---|
| c1 + c2 | (a1 + a2) + (b1 + b2)i |
| c1 - c2 | (a1 - a2) + (b1 - b2)i |
| c1 * c2 | (a1a2 - b1b2) + (a1b2 + a2b1)i |
| c1 / c2 | (a1a2 + b1b2)/(a2^2 + b2^2) + (a2b1 - a1b2)i/(a2^2 + b2^2) |
| (c1 = a1 + b1i, c2 = a2 + b2i) | |
