Because sinc(_x_) is not part of the mathematical functions provided by the Standard C library, we implement this problem solution in two ways. In one solution, we include the statements to perform the computations of sinc(_x_) in the main function; in the other solution, we write a programmer-defined function to compute sinc(_x_), and then reference the programmer-defined function each time that the computations are needed. Both solutions are now presented so that you can compare them.
