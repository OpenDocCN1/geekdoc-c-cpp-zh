Repetition. The repetition structure allows us to repeat (or loop through) a set of steps as long as a condition is true. For example, we might want to compute a set of velocity values that correspond to time values of 0, 1, 2, ..., 10 seconds. We do not want to develop a sequential structure that has a statement to compute the velocity for a time of 0, then another statement to compute the velocity for a time of 1, and then another statement to compute the velocity for a time of 2, and so on.
