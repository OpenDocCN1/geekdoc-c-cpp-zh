# PROGRAMMING PROBLEMS

Conversions. This set of problems involves converting a value in one unit to a value in another unit. Each program should prompt the user for a value in the specified units and then print the converted value, along with the new units.

+   21. Write a program to convert miles to kilometers. (Recall that 1 mi = 1.6093440 km.)
+   22. Write a program to convert meters to miles. (Recall that 1 mi = 1.6093440 km.)
+   23. Write a program to convert pounds to kilograms. (Recall that 1 kg = 2.205 lb.)
+   24. Write a program to convert newtons to pounds. (Recall that 1 lb = 4.448 N.)
+   25. Write a program that converts degrees Fahrenheit (TF) to degrees Rankin (TR). (Recall that TF = TR – 459.67°R.)
+   26. Write a program that converts degrees Celsius (TC) to degrees Rankin (TR). (Recall that TF = TR – 459.67°R and that TF = (9/5) TC + 32°F.)
+   27. Write a program that converts degrees Kelvin (TK) to degrees Fahrenheit (TF). (Recall that TR = (9/5) TK and that TF = TR – 459.67°R.)

Areas and Volumes. These problems involve computing an area or a volume using input from the user. Each program should include a prompt to the user to enter the variables needed.

+   28. Write a program to compute the area of a rectangle with sides a and b. (Recall that A = a x b.)
+   29. Write a program to compute the area of a triangle with base b and height h. (Recall that A = 1/2(b x h).)
+   30. Write a program to compute the area of a circle with radius r. (Recall that A = πr².)
+   31. Write a program to compute the area of a sector of a circle when θ is the angle in radians between the radii. (Recall that A = r²θ/2, where θ is in radians.)
+   32. Write a program to compute the area of a sector of a circle when d is the angle in degrees between the radii. (Recall that A = r²θ/2, where θ is in radians.)
+   33. Write a program to compute the area of an ellipse with semiaxes a and b. (Recall that A = πa x b.)
