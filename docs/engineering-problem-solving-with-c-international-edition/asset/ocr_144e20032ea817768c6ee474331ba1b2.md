# 3. HAND EXAMPLE

Suppose that the length of the femur is 15 in, and the length of the humerus is 12 in. Then the height estimates are:

femur_height_female = femur_length × 1.94 + 28.7 = 57.8 in = 4.82 ft = 4 ft 9.8 in
femur_height_male = femur_length × 1.88 + 32 = 60.2 in = 5.02 ft = 5 ft .24 in
humerus_height_female = humerus_length × 2.8 + 28.2 = 61.8 in = 5.15 ft = 5 ft 1.8 in
humerus_height_male = humerus × 2.9 + 27.9 = 62.7 in = 5.23 ft = 5 ft 2.76 in

# 4. ALGORITHM DEVELOPMENT

The first step in the development of an algorithm is the decomposition of the problem solution into a set of sequentially executed steps.

# Decomposition Outline

+   1. Read the lengths of the femur and the humerus.
+   2. Compute the height estimates.
+   3. Print the height estimates.
