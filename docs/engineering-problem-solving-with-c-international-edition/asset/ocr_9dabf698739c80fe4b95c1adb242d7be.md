# 1. PROBLEM STATEMENT

Compute the molecular weight of a chemical formula for an amino acid.

# 2. INPUT/OUTPUT DESCRIPTION

The input to the program is a chemical formula entered from the keyboard, and the output is the corresponding molecular weight displayed on the computer screen.

![](bbox=[0.355, 0.685, 0.745, 0.765])

# 3. HAND EXAMPLE

If the input is the chemical formula for alanine, which is 02C3NH7, then the corresponding output should be computed in the following way:

Two atoms of oxygen:
2 · 15.9994 = 31.9988
