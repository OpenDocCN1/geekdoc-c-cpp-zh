The prototype for the function to delete nodes is:

```
void remove(struct node **ptr_to_head, int old);
```

The function begins at the head of the list and searches for the node with a data value of old. If old is not found in the list, a message is printed. If old is found, the node is deleted and memory is freed. Since the head pointer must be updated whenever the first node in the list is deleted, we must pass a pointer to the head of the list.
