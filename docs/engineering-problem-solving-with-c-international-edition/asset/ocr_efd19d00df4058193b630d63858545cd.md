Screen output statement:

```
cout << data;
```

Class declaration:

```
class class_name
{
public:
function prototypes;
private:
declarations;
function prototypes;
};
```

Member function definition:

```
return_type class_name::function_name(parameter list)
{
declarations;
statements;
}
```

Declaring an object (instance of a class):

```
xy_coordinate pt1;
```

Initializing an object:

```
xy_coordinate pt2(3,4);
```
