# 1. PROBLEM STATEMENT

Determine the wavelength of two waves and the maximum possible wave height from the combination of the two waves.

# 2. INPUT/OUTPUT DESCRIPTION

The following diagram shows that the input to the program is the period and wave height for each wave. The output is the two individual wavelengths and the maximum wave height from the combination of the two waves.

![](bbox=[0.35, 0.3, 0.78, 0.4])

# 3. HAND EXAMPLE

Assume that we have measured the wave period and wave height (distance between crest and trough) for two waves:

| | Period (s) | Height (ft) |
|---|---|---|
| Wave 1 | 4 | 0.5 |
| Wave 2 | 10 | 1.0 |

We first compute the wavelength for each wave using the equation given earlier in this section:

wavelength 1 = 5.13 T₁² = 82.08 ft, and
wavelength 2 = 5.13 T₂² = 513 ft.

For the combined wave period, we use the product of the periods of the two waves, or 40 s. Thus, the increment in time between the 200 points is 40/200, or 0.2 s. Using 10 points for the hand example (instead of 200), we have the following set of information:

| t | w₁(t) | w₂(t) | w₁(t) + w₂(t) |
|---|---|---|---|
| 0 | 0 | 0 | 0 |
| 0.2000 | 0.0773 | 0.0627 | 0.1399 |
| 0.4000 | 0.1469 | 0.1243 | 0.2713 |
| 0.6000 | 0.2023 | 0.1841 | 0.3863 |
| 0.8000 | 0.2378 | 0.2409 | 0.4786 |
| 1.0000 | 0.2500 | 0.2939 | 0.5439 |
| 1.2000 | 0.2378 | 0.3423 | 0.5800 |
| 1.4000 | 0.2023 | 0.3853 | 0.5875 |
| 1.6000 | 0.1469 | 0.4222 | 0.5691 |
| 1.8000 | 0.0773 | 0.4524 | 0.5297 |

The maximum height for the combined wave (in the first 10 points) is 2(0.5875) ft, or 1.175 ft.
