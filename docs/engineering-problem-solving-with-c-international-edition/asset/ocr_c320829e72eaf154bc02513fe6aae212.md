The term under the square root symbol, $b^2 - 4ac$, is called the discriminant. If the discriminant is greater than or equal to zero, then the two roots are real values, and they can be expressed as follows:

```
root$_1$ = $-\frac{b}{2a} + \frac{\sqrt{\text{discriminant}}}{2a}$
root$_2$ = $-\frac{b}{2a} - \frac{\sqrt{\text{discriminant}}}{2a}$
```

If the discriminant is less than zero, then the two roots are complex values, and they can be expressed as follows:

```
root$_1$ = $\frac{b}{2a} + \frac{\sqrt{-\text{discriminant}}}{2a} i$
root$_2$ = $-\frac{b}{2a} - \frac{\sqrt{-\text{discriminant}}}{2a} i$
```
