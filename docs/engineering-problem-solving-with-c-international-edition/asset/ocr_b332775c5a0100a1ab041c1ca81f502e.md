Selection. A selection structure contains a condition that can be evaluated as either true or false. If the condition is true, then one set of statements is executed; if the condition is false, then another set of statements is executed. For example, suppose that we have computed values for the numerator and denominator of a fraction. Before we compute the division, we want to be sure that the denominator is not close to zero. Therefore, the condition that we want to test is “denominator close to zero.” If the condition is true, then we want to print a message indicating that we cannot compute the value. If the condition is false, which means that the denominator is not close to zero, then we compute and print the value of the fraction.
