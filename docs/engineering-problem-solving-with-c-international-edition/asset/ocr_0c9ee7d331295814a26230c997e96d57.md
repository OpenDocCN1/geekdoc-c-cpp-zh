If a linear equation contains three variables, x, y, and z, then it represents a plane in three-dimensional space. If we have two equations with three variables, they can represent two planes that intersect in a straight line, they can represent two parallel planes, or they can represent the same plane; these possibilities are shown in Figure 5.4. If we have three equations with three variables, the three planes can intersect in a single point, they can intersect in a plane, they can have no common intersection point, or they can represent the same plane.
