# Listing and Configuring Exceptions

The .NET Framework contains a host of exception types, and you are free to throw and handle any of these in your own code. The IDE supplies a dialog box for examining and editing the available exceptions, which can be called up with the Debug ▸ Exception Settings menu item (or by pressing Ctrl+I, D, E).
