the `SelectNodes` method. This will either return an `XmlNodeList` object or throw one of the exceptions regarding XPath if the query used is illegal.

The `Update` method is responsible for looping through the content of the `XmlNodeList` selected by `SelectNodes`. It calls `FormatText` from the earlier examples with each of the nodes, and `FormatText` is responsible for recursively traversing the node tree and creating readable text you can use in the `textBoxResult` control.
