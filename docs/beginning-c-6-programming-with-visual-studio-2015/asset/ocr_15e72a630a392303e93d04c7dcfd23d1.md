The constructor should also be able to take an initial list of items via an IEnumerable<T> parameter. The class should function exactly like List<T> but throw an exception of type IndexOutOfRangeException if an attempt is made to add too many items to the collection, or if the IEnumerable<T> passed to the constructor contains too many items.
