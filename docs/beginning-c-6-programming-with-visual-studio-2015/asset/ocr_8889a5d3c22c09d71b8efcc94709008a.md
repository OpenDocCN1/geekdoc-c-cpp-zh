These rules apply to all Card objects in every Deck in an application. It's not possible to have two decks of cards with cards contained in each that obey different rules. That's fine for this class library, however, as you can safely assume that if a single application wants to use separate rules, then it could maintain these itself, perhaps setting the static members of Card whenever decks are switched.

Because you have done this, it is worth adding a few more constructors to the Deck class to initialize decks with different characteristics:

public Deck(bool useTrumps, Suit trump) : this()
