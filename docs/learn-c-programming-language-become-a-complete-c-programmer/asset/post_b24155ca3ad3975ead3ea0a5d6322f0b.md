```

{y2,22}
{zaq,34567}
```

Note the annoying “spurious” spaces at the beginning of the lines. By default, **regex_match()** copies unmatched characters to its output, so the two spaces that were not matched by **pat** are printed.

```

```

```
{y2,22}
{zaq,34567}
```
