## 34.2.4 Tuples

标准库提供了两种将任意类型的值分组到单个对象中的方法：

- **pair** (§34.2.4.1) 包含两个值。
- **tuple** (§34.2.4) 包含零个或多个值。

当我们需要静态地知道我们恰好有两个值时，我们使用 **pair**。使用 **tuple** 时，我们总是必须处理所有可能的值数量。
