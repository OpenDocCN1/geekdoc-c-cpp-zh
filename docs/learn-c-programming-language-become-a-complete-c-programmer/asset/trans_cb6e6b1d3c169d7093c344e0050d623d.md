与通用 remove() 和 unique() 算法 (§32.5) 相比，成员算法确实会影响列表的大小。例如：

```
void use()
{

lst.remove(3); // lst is now{2,2,5}
lst.unique(); // lst is now{2,5}
cout << lst.size() << '\n'; // writes2
}
```
