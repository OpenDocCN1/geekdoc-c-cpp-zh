# # 消费者告知书

尊敬的消费者：

根据《中华人民共和国电子商务法》及其他相关法律法规的规定，为保障您的合法权益，请您在购买商品或接受服务前，仔细阅读本告知书内容。

+   1. 【商品信息】您在本平台购买的商品信息以页面展示为准，包括商品名称、规格、价格、产地、保质期等。

感谢您的信任与支持，祝您购物愉快！
