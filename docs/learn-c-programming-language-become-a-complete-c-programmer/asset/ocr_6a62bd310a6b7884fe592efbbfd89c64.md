The type property predicates don’t do access checking depending on where they are used. Instead, they consistently give the result you would expect for a use outside members and friends.
For example:

```
class X {
public:
  void inside();

private:
  X& operator=(const X&);
  ~X();
};

void X::inside() {
  cout << “inside = ” << is_copy_assignable<X>::value << '\n';
  cout << “inside ~: ” << is_destructible<X>::value << '\n';
}

void outside() {
  cout << “outside = ” << is_copy_assignable<X>::value << '\n';
  cout << “outside ~: ” << is_destructible<X>::value << '\n';
}
```
