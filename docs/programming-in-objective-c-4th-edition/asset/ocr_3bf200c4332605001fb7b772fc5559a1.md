For each basic data type, a class method exists that allocates an NSNumber object and sets it to a specified value. These methods begin with numberWith followed by the type, as in numberLong:, numberWithFloat:, and so on. In addition, instance methods can be used to set a previously alloc'ed NSNumber object to a specified value. These all begin with initWith: as initWithLong: and initWithFloat::

# Note

In versions of Xcode prior to 4.2, it mattered more version of the method you used. The class method would create an object that was autoreleased, whereas the alloc'ed versions created objects whose memory were responsible for releasing when you were done using them. The introduction of Automatic Reference Counting (ARC) to Objective-C means that there's no longer a strong motivation to use one form of a method over the other as memory management is now handled automatically.
