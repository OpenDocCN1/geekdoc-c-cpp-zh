You could extend Rectangle class to store the x, y coordinate of the rectangle's origin as two separate values. Or you might realize that, in the development of your graphics application, you'll have to deal with it of coordinates and, therefore, decide to define a class called XYPoint (you might recall this problem from exercise 7 in Chapter 3);

```
#import <Foundation/Foundation.h>

@interface XYPoint: NSObject
@property int x, y;

-(void) setX:(int)xVal andY:(int)yVal;
@end
```

```
@implementation Rectangle
{
XYPoint *origin;
}
...
```
