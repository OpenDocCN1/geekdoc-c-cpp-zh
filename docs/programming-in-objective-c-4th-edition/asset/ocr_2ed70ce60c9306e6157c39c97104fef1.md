Programming is fun.

Program 13.7 is Program 13.4 rewritten to use a block instead of function. A block can be defined globally or locally. In this case, we'll define our block outside of main, making it external and global in scope.

# Program 13.7

```
#import <Foundation/Foundation.h>
// Block to calculate the nth triangular number
void (^calculateTriangularNumber) (int) = ^(int n) {
    int i, triangularNumber = 0;
    for (i = 1; i <= n; ++i) {
        triangularNumber += i;
    }
    NSLog("@Triangular number %i is %i", n, triangularNumber);
}

int main (int argc, char * argv[]) {
    @autoreleasepool {
        calculateTriangularNumber(10);
        calculateTriangularNumber(20);
    }
```
