Of course, you could have used both special assignment operator in the statement, as in this statement:

```
w1 |= 07;
```

# The Bitwise Exclusive-OR Operator

The bitwise Exclusive-OR operator, which is often called the XOR operator, works as follows: For corresponding bits of the two operands, if either is a 1—but not both bits—the corresponding bit of the result is a 1; otherwise, it is a 0. The truth table for this operator is as shown.

| b1 | b2 | b1 ^ b2 |
|---|---||
| 0 | 0 | 0 |
| 0 | 1 | 1 |
| 1 | 0 | 0 |
| 1 | 1 | 0 |

If w1 and w2, set equal to hexadecimal 5e and d6, respectively, the result of w1 Exclusive-ORed w2 would be hexadecimal e8, as illustrated:

```
w1 0000 0000 0101 1110 0x5e
w2 0000 0000 1011 0110 ^ 0xd6

0000 0000 1110 1000 0xe8
```
