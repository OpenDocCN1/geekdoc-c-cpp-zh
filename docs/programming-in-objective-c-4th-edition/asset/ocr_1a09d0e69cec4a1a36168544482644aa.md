Relative file positioning is done by obtaining the current file offset and then adding to or subtracting from it. So, to skip to the next 128 bytes in the file, write the following:

```
[databaseHandle seekToFileOffset: [databaseHandle offsetInFile] + 128];
```

And to move back the equivalent of five integers in the file, write this:

```
[databaseHandle seekToFileOffset: [databaseHandle offsetInFile] - 5 * sizeof(int)];
```
