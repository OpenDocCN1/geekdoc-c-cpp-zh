# Program 3.3. Output

First fraction is:
2/3
Second fraction is:
3/7

The @interface and @implementation sections remain unchanged from Program 3.2. The program creates two Fraction objects, called frac1 and frac2, and assigns the value 2/3 to the first fraction and 3/7 to the second. Realize that when the setNumerator: method is applied to frac1 to set its numerator to 2, the instance variable numerator is set to 2. Also, when frac2 uses the same method to set its numerator to 3, its instance variable numerator is set to the value 3. Each time you create a new object, it gets its distinct set of instance variables. Figure 3.5 depicts this.

# Figure 3.5. Unique instance variables

| Object | frac1 | frac2 |
| --- | --- | --- |
| Instance Variables | numerator 2
 denominator 3 | numerator 3
 denominator 7 |

Based on which object is getting sent the message, the correct instance variables are referenced. Therefore, here frac1's numerator is referenced whenever setNumerator: uses the name numerator inside the method:

```
[frac1 setNumerator: 2];
```
