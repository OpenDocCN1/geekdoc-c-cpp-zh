# Which Method Is Selected?

We covered how the system searches up the hierarchy for a method to apply to an object. If you have methods in different classes with the same name, the correct method is chosen based on the receiver of the message. [Program 8.7](https://example.com) uses the same class definition for ClassA and ClassB as before.
