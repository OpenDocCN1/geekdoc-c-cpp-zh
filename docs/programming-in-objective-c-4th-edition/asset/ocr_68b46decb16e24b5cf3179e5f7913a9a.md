As you can see from the statement, the writeToFile:atomic returns a BOOL value: YES if the write operation succeeds or NO if it fails (perhaps invalid pathname for the file was specified or the file system is full).

You must invoke decode methods to extract and decode your archived objects. When you're finished, you send a finishDecoding message to the NSKeyedUnarchiver object.
