The first thing we'll do is set the iPhone's window to black. To do this, first click inside the iPhone's window in the middle pane.

If you glance down to the View section of the Inspector pane, you'll see an attribute labeled Background. If you click inside the gray-filled rectangle next to Background, it brings up a choice of colors for you. Choose Black Color, which changes the rectangle next to the Background attribute in the Inspector from gray to black.

If you take a look at the middle pane, which represents the iPhone's window, you see that it has changed to black, as shown in Figure 21.10.
