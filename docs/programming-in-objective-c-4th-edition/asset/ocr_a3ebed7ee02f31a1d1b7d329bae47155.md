# Accessing Instance Variables and Data Encapsulation

You've seen the methods that deal with fractions can access the two instance variables numerator and denominator directly by name. In fact, an instance method can always directly access its instance variables. A class method can, however, because it's dealing with only the class itself, not with any instances of the class (think about that for a second). But what if you wanted to access your instance variables from someplace else—for example, from inside your main routine? You can't directly access because they are hidden. The fact that they are hidden from you is a key concept called data encapsulation.
