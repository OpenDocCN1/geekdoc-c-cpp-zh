```
#if MAC_OS_X_VERSION_MIN_REQUIRED <nMAC_OS_X_VERSION_10_5
#define NSMaximumStringLength (INT_MAX-1)
#endif
```

This tests the value of the defined variable MAC_OS_X_VERSION_MIN_REQUIRED against the defined variable MAC_OS_X_VERSION_10_5. If the former is less than the latter, #define that follows is processed; otherwise, it is skipped. Presumably, this sets the maximum length of a string to the maximum size of an integer minus 1 if the program is being compiled on Mac OS X 10.5 or later versions.

The special operator

```
defined (name)
```

```
#if defined (DEBUG)
...
#endif
```

and

```
#ifdef DEBUG
...
#endif
```
