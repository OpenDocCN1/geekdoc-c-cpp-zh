# Enumerating the Contents of a Directory

Sometimes you need to get a list of the contents of a directory. This enumeration process can be accomplished using either enumeratorAtPath: or the contentsOfAtPath:error method. In the former case, each file in the specified directory is enumerated one at a time and by, if one of those files is a directory, its contents are also recursively enumerated. During this process you can dynamically prevent this recursion by sending a skipDescendants message to an enumeration object so that its contents will not be enumerated.
