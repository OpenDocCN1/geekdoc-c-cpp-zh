The continue statement is most often used to bypass a group of statements inside a loop based on some condition, but then to otherwise continue executing the loop. The format of the continue statement is as follows:

```
continue;
```

Don't use the break continue statements until you become very familiar with writing program loops and gracefully exiting them. These statements are too easy to abuse and can result in programs that are hard to follow.
