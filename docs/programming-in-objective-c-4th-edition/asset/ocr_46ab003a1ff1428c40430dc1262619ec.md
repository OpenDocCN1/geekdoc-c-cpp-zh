# A Calculator Class

It's time now to define a new class. We're going to make a Calculator class, which will be a simple four-function calculator you can use to add, multiply, subtract, and divide numbers. Similar to a regular calculator, this one must keep track of the running total, or what's usually called the accumulator. So methods must let you the accumulator to a specific value, clear (or set it to zero), and retrieve its value when you're done.
