Be careful to make the distinction between character pointers and character arrays because the type of assignment shown previously is not valid with a character array. For example, if text were defined instead to be an array of chars, with a statement such as

```
char text[80];
```

you could not write a statement such as this:

```
text = "This is not valid.";
```

The only time Objective-C lets you get away with performing this type of assignment to a character array when initializing it:

```
char text[80] = "This is okay.";
```

Initializing the text array in this manner does not have the effect of storing a pointer to the character string "This is okay." inside text. Instead, the actual characters themselves are followed by a terminating null character, inside corresponding elements of the text array.
