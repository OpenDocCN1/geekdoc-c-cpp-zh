Another common use of #if is in code sequences that look like this:

```
#if defined (DEBUG) && DEBUG
...
#endif
```

This causes the statements after the #if and up to the #endif to be processed only if DEBUG is defined and has a nonzero value.

Because expressions can be used and 0 is always false, programmers (myself included) will often comment out a block of code by enveloping it inside a #if 0 ... #endif pair of preprocessor statements.
