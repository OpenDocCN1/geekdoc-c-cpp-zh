The main routine tests to ensure that a word was typed after the program name when the program was executed. If it wasn't, or more than one word was typed, the value of argc is not equal to 2. In that case, the program writes an error message to standard error and terminates, returning an exit status of 1.

If argc is equal to 2, the lookup function is called to find the word that argv[1] points to the dictionary. If the word is found, its definition is displayed.
