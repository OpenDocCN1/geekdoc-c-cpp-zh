# The Bitwise AND Operator

When two values are ANDed, the binary representations of the values are compared bit by bit. Each corresponding bit that is a 1 in the first value and a 1 in the second value produce a 1 in the corresponding position of the result; anything else produces a 0. If b1 and b2 represent corresponding bits of the two operands, the following table, called a truth table, shows the result of b1 ANDed with b2 for all possible values of b1 and b2.
