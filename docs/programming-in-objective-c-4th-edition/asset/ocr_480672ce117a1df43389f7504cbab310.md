In Xcode, you added new defined names and specify their compiler values by selecting Build Settings, All, Apple LLVM compiler 3.0 - Preprocessing, Preprocessor Macros. You can see a shot of the symbols IPAD and DEBUG (defined as 1) in Xcode 4 in Figure 12.1.
