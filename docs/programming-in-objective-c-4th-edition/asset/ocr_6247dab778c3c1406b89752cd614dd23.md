When you create an application, the system stores all the the data associated with that application—which includes resources such as images, localized strings, icons, and so on—into a package known as an application bundle. In order to access those resources from your application, you want to become familiar with the NSBundle class.

It's easy to add a resource like an image or a text file to your application: you simply drag the file into the left pane in Xcode. When prompted, you'll usually want to copy the resource into your project folder, so that your project is all self-contained.

Here's a statement that will return the path to a file called instructions.txt that stores in your application bundle:

```
NSString *txtFilePath = [[NSBundle mainBundle] pathForResource:@"instructions" ofType:@"txt"];
```

The main method gives the directory where the application bundle is located. You can use this method for Mac OS X or iOS applications. The pathForResource:ofType will locate the specified file within that directory and return a path to that file. You can subsequently read the contents of that file into your application with a statement like this:

```
NSString *instructions = [[NSString stringWithContentsOfFile:txtFilePath encoding:NSUTF8StringEncoding error:NULL];
```

If you want to locate all JPEG images with the file extension jpg in the images directory of your application bundle, you can use the pathsForResourcesOfType:inDirectory: method like so:

```
NSArray *birds = [[NSBundle mainBundle] pathsForResourcesOfType:@"jpg"]
```
