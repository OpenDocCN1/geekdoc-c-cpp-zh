```objective-c
-(void) setName: (NSString *) theName
{
    if (name != theName)
        name = [NSString stringWithString:
        theName];
}

-(void) setEmail: (NSString *) theEmail
{
    if (email != theEmail)
        email = [NSString stringWithString:
        theEmail];
}
```
```

The test is there in case someone sends into the setter the same object that's already stored in the instance variable. If the object being passed in is in the same as what's stored, we don't have to do any work at all.
