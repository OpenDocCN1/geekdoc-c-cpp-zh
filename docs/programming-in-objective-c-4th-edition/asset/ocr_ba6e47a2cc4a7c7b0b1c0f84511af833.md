This expression produces a structure of type struct date with the specified initial values. You can assign this to another struct date structure, like so:

```
theDate = (struct date) { .month = 7, .day = 2,
.year = 2011 };
```

Or you can pass it to a function or method that expects an argument of struct date, like so:

```
setStartDate ((struct date) { .month = 7, .day
= 2, .year = 2011 });
```

In addition

```
intPtr = (int [100]) { [0] = 1, [50] = 50, [99]
= 99 };
```

(which can appear anywhere in the program) sets intptr pointing to an array of 100 integers, whose 3 elements are initialized as specified.

If the size of the array is not specified, the initializer list determines it.
