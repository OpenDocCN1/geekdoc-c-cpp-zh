# Looking Up Someone in the Address Book

When you have a large address book, you don’t want to list its complete contents each time you want to look up someone. Therefore, adding a method to do that for you makes sense. Let’s call the method lookup: and have it as its argument the name to locate. The method will search the address book for a match (ignoring case) and return the matching entry, if found. If the name does not appear in the phone book, you’ll have it return nil.

Here’s our new lookup: method:
