# Note

This might be the most instructive exercise in the entire text, but it's not easy! Figure 15.6 shows what a sample MusicCollection called myMusic might look like. It has three playlists, which includes the main playlist library. The library contains five songs. playlist1 has two songs and playlist2 has one. Here are some hints: Make good use of the NSMutableArray class and just store references (and not copies) of your songs in each new playlist (use the addObject: method to do that).
