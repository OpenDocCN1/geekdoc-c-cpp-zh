# Mutable Versus Immutable Objects

When you create a string object by writing an expression such as
"Programming is fun"

Frequently, you'll want to deal with strings characters you can change. For example, you might want to delete some characters from a string or perform a search-and-replace operation on a string. These types of strings are handled through NSMutableString class.
