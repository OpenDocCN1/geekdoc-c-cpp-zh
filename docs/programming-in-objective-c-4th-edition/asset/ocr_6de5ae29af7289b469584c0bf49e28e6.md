A block can access variables within the scope in which it's defined. The value of that variable is the value it has at at the time the block is defined. This is illustrated in Program 13.8.

# Program 13.8

```
#import <Foundation/Foundation.h>

int main (int argc, char * argv[]) {
    @autoreleasepool {
        int foo = 10;

        void (^printFoo)(void) = 
^(void) {
            NSLog (@"foo = %i", foo);
        };

        foo = 15;

        printFoo ();
    }
    return 0;
}
```

# Program 13.8. Output

foo = 10
