Note that this file does not include the definition of the Fraction class. However, it does import a file called Fraction.h.

Typically, a class declaration (that is, the @interface section) is placed in its own file, called class.h. The definition (that is, the @implementation section that contains the code) is normally placed in a file of the same name, using the extension .m instead. So let's put the declaration of the Fraction class in the file Fraction.h and the definition in Fraction.m.
