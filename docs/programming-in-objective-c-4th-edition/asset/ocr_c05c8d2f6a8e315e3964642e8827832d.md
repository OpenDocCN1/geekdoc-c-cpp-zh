To initialize the date structure variable today to July 2, 2011, you can use this statement:

```
struct date today = { 7, 2, 2011 };
```

As with the initialization of an array, fewer values can be listed than the structure contains. So the statement

```
struct date today = { 7 };
```

sets today.month to 7 but gives no initial value to today.day today.year. In such a case, their default initial values are undefined.

Specific members can be designated for initialization in any order with the notation

```
.member = value
```

in the initialization list, as in

```
struct date today = { .month = 7, .day = 2, .year = 2011 };
```

and

```
struct date today = { .year = 2011 };
```

The last statement just sets the year in the structure to 2011. As you know, the other two members are undefined.
