Notice something new about this reduce method: It declares three integer variables called u, v, and temp. These variables are local variables, meaning that their values exist only during execution of the reduce method and that they can be accessed only from within the method in which they are defined. In that sense, they are similar to the variables you have been declaring inside the main routine; those variables were also local to main and could be accessed directly from within the main routine. None of the methods developed could directly access those variables defined in main.

Local variables are basic C data types have no default initial value, so you must set them to some value before using them. The three local variables in the reduce method are set to values before they are used, so that's not a problem. Local object variables are initialized to nil by default. Unlike your instance variables (which retain their values through method calls), these local variables have no memory. Therefore, after the method returns, the values of these variables disappear. Every time a method is called, each local variable defined in that method is reinitialized to the value specified (if any) with the variable’s declaration.
