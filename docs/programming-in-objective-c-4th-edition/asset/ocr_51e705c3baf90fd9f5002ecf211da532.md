# Bit Operators

Various operators in the Objective-C language work with the particular bits used to represent an integer value. Table 10.1 presents these operators.

# Table 10.1. Bit Operators

| Symbol | Operation |
| --- | --- |
| & | Bitwise AND |
| / | Bitwise inclusive-OR |
| ^ | Bitwise OR |
| ~ | Ones complement |
| << | Left shift |
| >> | Right shift |

> Note
You't use bitwise operators much, if at all, in your Objective-C programs, although you will come across them in framework header files. As this material may be a little dense for new programmers, you can just skim this section and refer back to it later, if necessary.

All the operators listed in Table 10.1, with the exception of the ones complement operator (~), are binary operators, and as such, take two operands. Bit operations can be performed on any type of integer value but cannot be performed on floating-point values.
