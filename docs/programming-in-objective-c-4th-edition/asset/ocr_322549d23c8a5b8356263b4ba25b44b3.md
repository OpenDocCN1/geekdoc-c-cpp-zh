As you will see from the next program example, you don't need to make a separate call to the NSLog routine for each line of output.

First, let's talk about a special two-character sequence. The backslash (\) and the letter n are known collectively as the newline character. A newline character tells the system to precisely what its names implies: go to a new line. Any characters to be printed after the newline character then appear on the next line of the display. In fact, the newline character is very similar in concept to the carriage return on a typewriter (remember those?).
