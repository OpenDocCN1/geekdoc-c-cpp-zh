# Customizing the Side Switch

You can customize the Side switch on your iPad mini 3 (It's at the top-right side if you're holding the iPad in vertical orientation). Use these steps to set it to control the screen orientation or mute sound:

+   1. From the Home screen, tap the Settings icon.
2. In the General pane, tap either the Lock Rotation or Mute option in the Use Side Switch section to choose which feature you want the switch to control.
3. Tap the Home button to return to the Home screen.
4. Move the Side switch up or down to toggle between the settings chose: screen rotation locked or unlocked, or sound muted or unmuted.

If you choose to use the Side switch to mute or unlock system sound, you can use the Control Center to lock and unlock the screen rotation. This works the same way if you have set the switch to handle handheld screen rotation and want to mute or unmute the sound using the Control Center.
