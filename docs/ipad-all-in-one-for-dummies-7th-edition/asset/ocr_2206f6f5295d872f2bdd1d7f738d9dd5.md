Also note that at the right of the keyboard is a set of buttons than the text, date, and number keyboards. On the right side of the keypad, you'll find four buttons that are present the following:

+   * Functions: Brings up a list of functions for use in formulas.
* abc: Displays the text keyboard. You can type text and tap Done, and the text is added to the formula you're constructing. You return to the formula keyboard.
* Date/Time: Takes you to the date-and-time keyboard. The date or duration you enters the same interface shown in Figure 3-19. When you tap Done, the date or duration is added to the formula, and you return to the formula keyboard.
* True/False: Uses the same interface as check boxes; the result is added to the formula you're constructing, and you return to the formula keyboard.
