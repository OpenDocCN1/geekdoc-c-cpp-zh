# Adjusting the Volume

+   - **Larger Type**: If having larger text in apps such as Contacts, Mail, and Notes would be helpful to you, you can turn on the Larger Type feature and choose the text size that works for you.

+   - **Bold Text**: Turning on this setting will restart your iPad (after asking for permission to do so) and then cause text in various apps and in Settings to be bold. This is a handy setting because text in the iOS 7 redesign (also used by iOS 8) was simplified, making it get thinner!

+   - **Increase Contrast**: Use this setting to set up backgrounds in areas of iPad and apps with greater contrast, which should improve visibility.

+   - **Reduce Motion**: Tap this accessibility feature and tap the On/Off switch to turn off the parallax effect, which causes the background of your Home screens to float as you move the phone around.

+   - **Manage On/Off Labels**: If you have trouble making colors, and so have trouble telling when an On/Off setting is On (green) or Off (white), use the On/Off Labels setting to add a circle to the right of a setting when it's off and a vertical white line to a setting when it's on (see Figure 3-6).
