# 3. Tap a header or footer to customize it.

You can use the three footer sections to insert the author's name, title, the version number, or the page number, for example.

4. Type some text in the section of the header or footer that you want to customize.

5. To add page numbers to your document, tap in the header or footer section that you want to use for the page number; then tap the Page Numbers button in the contextual menu that appears.

This contextual menu is displayed only when you tap a header or footer. You can choose the format of the page numbers, as shown in Figure 2-12.
