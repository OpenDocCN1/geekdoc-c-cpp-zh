# Working with Your Events

After you have entered some events in Calendar, you can use features to search for events, sync your events with other calendars on other devices, or delete events that have been canceled.

In this section, you work with the various events on your calendar to keep up-to-date and organized.

# Searching calendars

Displaying events by day or week and scrolling the pages is one way to remember its time frame, but if you need to view a particular event and can't remember its time frame, you can use the Calendar Search feature to find it.

Don't forget that you can also search for events in your calendar by searching a command to Siri or searching with the Spotlight Search feature.

Follow these steps to search for events in Calendar:
