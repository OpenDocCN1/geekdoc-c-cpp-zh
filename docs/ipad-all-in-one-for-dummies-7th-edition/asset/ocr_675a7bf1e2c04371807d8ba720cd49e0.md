# Create an Event from Email Contents

Invitations sent to you in email that you accept have always been placed in the Calendar app automatically. In addition, Mail will create a Calendar event from certain information contained within an email such as a flight reservation.

To check this feature out, follow these steps:

+   1. Create an event to yourself mentioning a reservation on a specific date and time.

+   You can also mention another type of reservation, such as for dinner, or just a phone number.

+   2. Send the message to yourself and open Mail.

+   3. In your Inbox, open the mail. Note that pertinent information is displayed in blue, underlined text.

+   4. Tap some underlined text; in the menu shown in Figure 7-17, choose to Create Event.

A New Event form from Calendar appears.

+   5. Enter additional information about the event and then tap Done.
