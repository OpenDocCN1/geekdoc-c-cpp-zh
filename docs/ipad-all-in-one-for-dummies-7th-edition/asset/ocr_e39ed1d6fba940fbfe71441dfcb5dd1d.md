TIP You might need to ask your network administrator for information on how to make settings for accessing a VPN. If you set up VPN on your computer, you should be able to use the same VPN settings on your iPad. You might want to let your admin which iPad can connect to VPNs that use the L2TP, PPTP, PPTP, or Cisco IPSec protocol.

Add a new VPN configuration, go to Settings and tap General > VPN > Add VPN configuration. The settings shown in Figure 1-5 appear. Fill in the information requested and tap Save.

![](bbox=[0.237, 0.31, 0.535, 0.585])

**Figure 1-5:** The Add Configuration settings.

You can have multiple VPNs set up, for example if you consult with companies with their own VPNs. Tap the one you want to use, and then set the VPN switch to On. To switch VPNs, disconnect from one, select the new one, and then turn VPN back on. Only one VPN can be active at any time. To delete a VPN configuration, tap the arrow to the right of the configuration in the General settings and tap Delete VPN.
