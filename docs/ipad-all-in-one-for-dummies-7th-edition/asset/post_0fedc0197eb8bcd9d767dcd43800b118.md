# VoiceOver 51

After VoiceOver is turned on, you need to figure out how to use it. I won't lie — it is awkward at first, but you'll get the hang of it! Here are the main gestures you should know how to:

- Tap an item to select. VoiceOver speaks its name.
- Double-tap the selected item. This action activates the item.
- Flick three fingers. It takes three fingers to scroll around a page with VoiceOver on.

Table 3-1 provides additional gestures to help you use VoiceOver. If you want to use this feature, read the VoiceOver section of the iPad's User Guide, which goes into detail about the ins and outs of VoiceOver. You'll find the User Guide at http://www.apple.com/manuals/iPad/en_US/iphone_user.pdf or download it from the Books Store.

# Making Additional Settings

| Table 3-1 | VoiceOver Gesture | Effect |
| :--- | :--- |
| Flick right or left | Select the next or preceding item. |
| Tap with two fingers | Stop speaking the current item. |
| Flick two fingers up | Read everything from the screen. |
| Flick two fingers down | Read everything from the current position. |
| Flick three fingers up or down | Scroll one page at a time. |
| Flick three fingers right or left | Go to the next or preceding page. |
| Tap three fingers | Speak the scroll status (for example, line 20). |
| Flick four fingers up or down | Go to the first or last element on a page. |
| Flick four fingers right or left | Go to the next or preceding section (as on a web page). |

Check out some of the settings for VoiceOver, including a choice for Braille, Language Rotor for language choices, the ability to navigate images, and a setting to have iPad notifications.

Several features are simple on/off settings, so rather than giving you the steps to get those settings repeatedly, I provide this useful list of additional features that you can turn on or off after you tap Settings > General > Accessibility:

- Zoom: The Zoom feature enlarges the contents displayed on the iPad screen when you double-tap the screen with three fingers. The Zoom feature works almost everywhere in iPad: in Photos, on web pages, and on Home screens, in Mail, and in Videos — give it a try!
- Invert Colors: The Invert Colors reverses colors on your screen so that backgrounds are black and text is white.

![](img/2a8a8d89daeb1b3896bd38ebf18af126_68_2.png)

The Invert Colors work well in some places and not in others. For example, in the Photos application, pictures appear as photo negatives. Your Home screen image will likewise look a bit strange. However, don't even think about playing a video with this feature turned on! If you need help reading text, Invert Colors can be useful in several applications.

# Adjusting the Volume

- Larger Type: If having larger text in apps such as Contacts, Mail, and Notes would be helpful to you, you can turn on the Larger Type feature and choose the text size that works for you.
- Bold Text: Turning on this setting will restart your iPad (after asking for permission to do so) and then cause text in various apps and in Settings to be bold. This is a handy setting because text in the iOS 7 redesign (also used by iOS 8) was simplified, making it get thinner!
- Increase Contrast: Use this setting to set up backgrounds in areas of iPad and apps with greater contrast, which should improve visibility.
- Reduce Motion: Tap this accessibility feature and tap the On/Off switch to turn off the parallax effect, which causes the background of your Home screens to float as you move the phone around.
- Manage On/Off Labels: If you have trouble making colors, and so have trouble telling when an On/Off setting is On (green) or Off (white), use the On/Off Labels setting to add a circle to the right of a setting when it's off and a vertical white line when it's on (see Figure 3-6).
