# Getting Helpful Tips

Note that Siri can understand many languages and therefore work in many countries. If you love to travel, Siri could help make your next trip much easier.

# Searching the web

Siri can use various resources to respond to specific requests such as "Who is the Queen of England?" For more general requests, however, Siri searches for the web.

For example, if you speak a phrase, such as "Find a website about birds" or "Find information about the World Series," Siri can respond in a couple of ways. The can simply display a list of search results using the default search engine in your settings for Safari, or "If you like, I can search the web for such-and-such." In the first instance, just tap a result to go to that. In the second instance, you can confirm that you want to search the web or cancel.

# Sending Email, Tweets, or Messages

You can create an email, a tweet, or an instant message using Siri and existing contacts. For example, if you say, "Email Jack Wilkes," a form opens already addressed to that contact. Siri asks you the subject and what to say in the message; speak your message and say "Send to your message on you.

Siri also works with the Messages app. Tap Siri and say, "Message Sarah." Siri creates a message and asks what you want to say. Say, "Tell Sarah I'll call" and asks for permission to approve and send.

It's hard to stump Siri. For example, at this point in time, Siri can't tweet unless you download and set up the Twitter app. But if you try to post a tweet, Siri gives you a link to tap to install the app! After you install these apps, you can say things to Siri like "Post Tweet" or "Post to Facebook," and Siri asks what you want to say, lets you review it, and Siri can also connect you with Flickr and Vimeo when you have those apps installed.
