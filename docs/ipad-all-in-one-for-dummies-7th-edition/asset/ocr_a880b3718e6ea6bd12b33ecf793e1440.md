# # Printing Emails

iPad has native printing capabilities that can be used by certain apps, including Mail. You need an AirPrint-compatible wireless printer set up to use this feature. For more about options for printing from your iPad, see Book V, Chapter 1.

With an email message open, follow these steps to print:

+   1. **Tap the Reply button and then Print.**
2. **In the Printer Options dialog that appears (if you haven't used this feature with your printer before), tap Print Select.**
   The iPad searches for any available printers.
3. **Tap your printer to select it.**
4. **Tap Back to return to the Printer Options dialog and use the plus or minus buttons (as necessary) in the Copies field to adjust the number of copies. If you use a printer that supports two-sided printing, you can use the Double-Sided switch to choose that option.
5. **Tap Print.**

Your print job is on its way to your printer.
