When you tap bookmarks, you can tap Edit and use the New Folder option to create folders to organize your bookmarks. First, turn on the Show Favorites Bar switch in Settings in Safari pane. When you next add a bookmark, you can then choose, from the dialog that appears, to add the new bookmark to any folder by tapping Location.
