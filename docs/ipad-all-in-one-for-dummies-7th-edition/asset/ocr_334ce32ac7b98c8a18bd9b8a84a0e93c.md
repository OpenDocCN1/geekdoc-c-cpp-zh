# Finding Some Very Cool Games 277

Minecraft Pocket Edition ($6.99): Minecraft is a wildly popular game that involves a virtual reality in which you build things with blocks (see Figure 8-3). These aren't Tinkertoys — with Minecraft, people are building entire cities, engineering feats, and realities.

Chess Pro ($79.99): You can play against the computer or another player. You can modify the appearance of the chess pieces. It even features that help beginners learn the game painfully, but more advanced players will enjoy it as well.

As well as costing money, games take up a lot of memory, so choose the games you buy. If you no longer want to play a game, delete it from your iPad to save space.

**Special mention:** ComicBookLover (free) isn't a game, but it's a blast of an app that most gamers appreciate. The iPad screen is perfect for those bright, crisp graphics, and iPad’s navigation tools let you swipe your way through the panes in several interesting ways. This app uses CBR and CBZ
