# Setting Basic Formatting by Using the Ruler

As is the case in most word-processing programs, a ruler at the top of a page in document editing lets you set basic formatting. The ruler can be hidden, but tapping in the document displays it, as shown in Figure 2-3. Tapping text also shows the keyboard with formatting tools at the top. You can also tap the Format button shaped like a paintbrush at any time to display the Form dialog.

The ruler shows the settings for whatever is selected in the document. Tap text in the document, and the ruler is immediately enabled and reflects the settings for the selection (in this case, the margins). Tapping in the document may also bring up the onscreen keyboard and a contextual set of tool buttons, as shown in Figure 2-3. You can use them to use features such as Cut, Copy, Delete, and Paste.
