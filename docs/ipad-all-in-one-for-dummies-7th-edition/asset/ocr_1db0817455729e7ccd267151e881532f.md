+   **Other:** If you want to join a network that doesn't appear on the list, tap under the Choose a Network section of these settings. In the dialog that appears, enter the network name and choose a type of security, as WEP or WPA. When you choose a form of security and return to the dialog shown in 1-2, the Password field appears. Some networks might need other information, such as a username or IP address, to complete this dialog. Check with your administrator for any information you need.

+   **Ask to Join Networks:** iPad automatically connects to the previously joined network. With this setting, an alert will appear if you want to join networks that come in range. Tap this switch to the On, and iPad displays all possible network connections. If a network requires a password, it sports a padlock symbol. If no networks are available, you're asked whether you want to join unknown networks. To connect to a network that iPad doesn't join it automatically, tap the Information icon on the right of the network name and then tap Forget This Network.

To adjust settings for individual Wi-Fi networks, tap the Information icon to the right of a listed network.

You can set up Home Sharing to share music and video content from Mac or PC with your iPad if they are on the same network and have the same Home Sharing ID as your iPad. See Book V, Chapter 1 for more about Home Sharing.
