To select all text in a note to either delete or copy it, tap the Select All button in the menu (refer to Figure 2-5). All is selected, and you can select commands from the menu to cut, copy, or paste the selected text.

To delete text, you can use the Select or Select All command and then press the Delete key on the onscreen keyboard.
