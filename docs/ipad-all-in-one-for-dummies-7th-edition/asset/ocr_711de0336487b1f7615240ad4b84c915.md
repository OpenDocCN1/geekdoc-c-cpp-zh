# 8. Tap Double to save changes to the contact.

To edit a photo you've added to a contact record, simply display the contact information and tap Edit. Tap Edit under the photo and then Edit Photo from the menu that appears, and then, in the dialog that appears (refer to Figure 5-8), use the gestures for moving and scaling the image with your fingers. Tap Use when you're ready to save the changed figure.
