

## 选择适合你的 iPad 13 

功能、数据流量额（例如访问电子邮件或从互联网下载项目）以及价格因运营商而异，并可能随时更改，请访问每个运营商的网站查看其提供的服务。请注意，如果你打算流媒体视频（在 iPad 上通过互联网观看视频），可能会迅速耗尽你的数据流量额。

![](img/2a8a8d89daeb1b3896bd38ebf18af126_30_0.png)

如果你有可用的 Wi-Fi 网络，并且有一个数据流量允许通过 3G/4G 共享的智能手机，你可能考虑使用仅限 Wi-Fi 的 iPad 型号，如果你只需要偶尔使用 3G/4G，这样可以节省运营商方案的高昂费用以及蜂窝型号的额外费用。

![](img/2a8a8d89daeb1b3896bd38ebf18af126_30_1.png)

当然，AT&T、Sprint、T-Mobile 和 Verizon 可能随时更改其定价和选项，因此请访问这些链接获取 iPad 数据流量计划的信息：AT&T 位于 www.att.com/shop/wireless/devices/ipad。Sprint 的主页是 http://sprint.com，T-Mobile 的 URL 是 WW-T-Mobile.com，Verizon 位于 www.verizon.com/b2c/splash/ipad.jspd。

![](img/2a8a8d89daeb1b3896bd38ebf18af126_30_2.png)

你可以使用手机上的热点功能，如果你支付了支持热点服务的运营商数据流量，iPad 就可以使用你手机的 3G 或 4G 连接上网。请查看你手机的功能以开启热点。有关此功能的更多信息，请参阅第 3 本第 3 章。

![](img/2a8a8d89daeb1b3896bd38ebf18af126_30_3.png)

那么如何选择呢？如果你想带着 iPad 环游世界或在长途驾驶时连接互联网——3G/4G，那么请考虑价格。但如果你在家里使用 iPad 或使用 Wi-Fi 热点（可以访问互联网的 Wi-Fi 位置，如网吧、办公室或图书馆），就不要费心 3G/4G 了。坦率地说，你可以到处找到很多热点，包括餐厅、酒店和商场。

![](img/2a8a8d89daeb1b3896bd38ebf18af126_30_4.png)

因为 3G/4G iPad 是 GPS 设备，它们知道你所在的位置并能带你从这里去到那里。仅限 Wi-Fi 型号使用数字指南针和三角测量法来确定你的当前位置，准确性较低；由于没有持续的互联网连接，它无法帮助你出行。在旅途中获取准确的路线是一个让你兴奋的 iPad 功能之一，请购买 3G/4G 版，然后参阅第 III 本第 2 章获取更多关于 Maps 应用的介绍。

## 了解使用 iPad 所需的

在去购买 iPad 之前，你应该了解需要配合哪些其他设备、连接以及你自己才能达到最佳工作效果。至少，你需要能够连接到互联网以充分利用大多数 iPad 功能。你可以开设一个 iCloud 账户（Apple 的在线存储和同步服务，用于在网上存储和共享内容），或者可以使用计算机从非 Apple 在线源（如当地图书馆之类的商店或共享网站）下载照片、音乐或应用程序，然后通过名为“同步”的过程将其传输到 iPad。你还可以使用计算机或 iCloud 在首次启动时注册你的 iPad。

你可以在没有电脑仅依靠公共 Wi-Fi 热点的情况下使用 iPad 吗（如果你有 3G/4G 连接）？是的，要在家里使用仅限 Wi-Fi 的 iPad 许多内置功能，你需要家庭 Wi-Fi 网络，或者足够幸运住在全镇覆盖 Wi-Fi 的地区。你还需要使用 iCloud 或同步计算机来获取 iPad 操作系统的更新。为了与计算机进行同步，iPad 用户指南建议你拥有：

- 带有 USB 2.0 或 USB 3.0 端口的 Mac 或 PC，以及以下操作系统：
    - Mac OS X 10.6.8 或更高版本
    - Windows 8、Windows 7、带有 Service Pack 3 的 Windows XP
    - iTunes 11.0 或更高版本，可在 www.apple.com/it 获取
    - Apple ID 和 iTunes 账户
    - 互联网访问
    - iCloud 账户

Apple 设置了 iTunes 软件和 iCloud 服务来让你管理 iPad 内容——包括电影、音乐或你下载的照片——以及如何同步日历和联系信息。第 4 章详细介绍了这些设置。

## 获取你的 iPad

正如本文所示，你可以在 Apple Store 以及 Buy、WalMart、Sam's Club 和 Target 等实体店，以及 MacMall 等在线网站购买 iPad。你还可以购买 3G/4G 型号，这需要来自 AT&T、Sprint、T-Mobile 以及 Verizon 等手机运营商账户。

## 考虑 iPad 配件

如果你从 Apple（无论是通过零售店还是在线商店）购买 iPad，购买体验是不同的。实体 Apple Store 的优势在于销售人员会帮你拆箱 iPad 并确保其运行正常，在你在使用之前注册设备，并帮助你学习基础知识。偶尔提供的研讨会帮助人们学习如何使用 iPad，Apple 员工以乐于帮助而闻名。然而，Apple Store 并非随可见，如果你去（或只想自己去），可以访问 Apple Store 网站 http://store.apple.com/us/browse/home/ipad/ 如图 1-2 所示，并订购一个送给你（如果你愿意，还可以刻字）。标准运输通常是免费的，如果有问题，Apple 在线商店的服务代表非常有帮助——他们可以帮你解决问题或更换你的 iPad。

### Apple 配件系列

目前，Apple 在你购买 iPad 时提供了可能需要的配件（或者你以后购买），包括：

- iPad Smart Case/Smart Cover：你的 iPad 并不便宜，与笔记本电脑不同，它很容易损坏。Smart Case 保护 iPad 的正反面，而 Smart Cover 保护屏幕并用于唤醒或睡眠 iPad。Smart Case 价格为 $79，Smart Cover 价格为 $29。
- 带遥控器和麦克风的 Apple EarPods：该设备提供入耳式收听和对音频的远程控制，价格约为 $29。
- Apple 数字 AV 适配器：为了使用允许设备通过电视、显示器和投影仪上的 HDMI 端口输出高清媒体的 HDMI 技术，可以使用此适配器（图 1-3），售价 $49。
- AirPrint 打印机：HP、Canon、Brother、Lexmark 和 Epson 提供支持 Apple AirPrint 功能的打印机。价格从 $129 到 $399 不等。HandPrint 和 Printopia 是可以将网络共享打印机打印到 iPad 的 Macintosh 应用。
- iPad 相连接：由于 iPad 上没有 USB 端口，可以使用 USB 连接从相机或内存卡上传照片。如果你想添加此功能，可以使用 MicroUSB 相机和 MicroSD 阅读器，每个花费 $30。
- 支架：Apple Store 提供了多种支架，包括价格 $29.95 的 Origami Workstand 和价格 $49.95 的 Twelfth Mobile Upstand。iPad Twelfth Hover Stand 价格为 $16.95，可连接在你的计算机上。Twelfth SouthBook 是另一个 $29.99 的良好选择。对于真正特别的手工支架，请访问 http://www.webskit.com/accessories.html 找到一个独一无二的平板支架供你选择。
