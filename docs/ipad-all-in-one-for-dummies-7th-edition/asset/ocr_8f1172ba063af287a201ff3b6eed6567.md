# 78 Making Settings and Syncing

![](bbox=[0.258, 0.125, 0.872, 0.408])

Figure 5-3: This pane includes settings to control how backups and syncing occur.

+   4. Make all settings for the types of content you plan to obtain on your computer and sync to your iPad, and then click the Sync button in the bottom-right corner to sync files with the iPad.

| Table 5-1
| Tab Name | What You Can Do with These Settings |
| Summary | Perform updates to iPad software and set general backup and syncing options. |
| Info | Specify which information to sync: Contacts, Calendars, Email accounts, Bookmarks, or Notes. Perform an advanced replacement of info on the iPad from the computer. Note that for users of OS X Mavericks, this tab doesn't appear, and all syncing must be done via iCloud. |
| Apps | Sync apps and data that you've downloaded to your computer to the iPad and manage the location of those apps and folders. Choose whether to automatically install new apps and organize arrange icons, folders, and the order of Home screens. |
| Tones | Choose to select or sync all tones. |
| Music | Choose which music to download to your iPad when you sync. |
| Movies | Specify whether to automatically download movies. |
| TV Shows | Choose which shows and episodes to sync automatically. |
| Podcasts | Choose which podcasts and episodes to sync automatically. |
