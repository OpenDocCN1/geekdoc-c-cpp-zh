# Using tagged browsing

Safari has a feature called tabbed browsing, which allows you to have several pages open at one time on separate tabs so you can easily move among those sites. You may have used tabbed browsing in other browsers, such as the desktop version of Safari, Internet Explorer, Google Chrome, or Mozilla Firefox. This is a handy feature of Safari that's worth exploring.

To add a tab, follow these steps:

+   1. With Safari open, tap the Add button (shaped like a + symbol) near the upper-right corner of the screen (refer to Figure 6-1).

A new tab opens with a list of your saved Favorites (see how to save Favorites later in this chapter), the Address/Search field becomes active, and the onscreen keyboard appears (see Figure 6-5).
