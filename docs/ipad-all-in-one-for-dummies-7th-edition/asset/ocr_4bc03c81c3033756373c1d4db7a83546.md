# Creating a new note

If you have stored notes, when you open Notes, the most recently used notes displays. If you want to create a new note, it's a simple procedure. To create a new note, tap the New Note button (the one looks like a page with a pen on it) in the top-right corner. The current note is saved and a new, blank note appears (refer to Figures 2-1 and 2-2). Enter and edit text as described in the preceding section.

# Using copy and paste

Let's face it, most of us don't nail what we write on our first draft. That's why, after you enter content into a note, you may want to modify it. The Notes app includes essential editing tools you're familiar with from using word processors: Select, Copy, and Paste. You can use these to duplicate content or copy and paste from one part of a note to another.

Use the Copy and Paste tools, follow these steps:

+   1. With a note displayed, press and hold your finger on a word.
