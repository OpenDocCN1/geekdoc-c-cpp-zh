# Getting Familiar with the iWork Interface

You will find that each of the iWork apps has a similar look and feel. One of the coolest aspects of iWork is that major features—not just small operations such as changing a font or selecting a color—are the same method in all its apps. You have only one set of features that you must understand when you are using iWork, so I give you an overview of all functionality to get you started.

The iWork apps (like all apps) are updated periodically. If an update is available, you see the App Store on your iPad Home screen with a number indicating that downloads are available. Updating your iWork when updates are available is generally a good idea so that their interfaces remain in sync.
