# Creating a List

You can create your own lists of tasks to help you organize different parts of your life. To do so, follow these steps:

+   1. Tap Reminders on the Home screen.
   Reminders opens.

+   2. Tap Add List to display the New List form, shown in Figure 4-5.

![](bbox=[0.263, 0.747, 0.735, 0.911])

**Figure 4-5:** Lists might include reminders for personal or work-related events.
