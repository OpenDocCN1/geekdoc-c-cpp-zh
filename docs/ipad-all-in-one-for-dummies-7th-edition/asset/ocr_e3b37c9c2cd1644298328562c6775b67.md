# Entering date/time data

Tap the clock button on the keyboard to enter date/time or duration data, as shown in Figure 3-19. The Date & Time button lets you specify a particular moment, and the Duration button lets you specify (or calculate) a length of time.

**Figure 3-19:** Enter date and time, or duration, data.

Above the keyboard, the units of a date or duration display. To edit a date or time (or both), tap Month in the Formula bar and use the keypad to select the month. (The keys have both the month name abbreviations and the numbers on them). Similarly, tap any other time increment and enter a value. As you do, the display changes to show the value. (Tapping AM or PM toggles the value — you don't need to type anything.)

# Entering text data

When you tap the T button to enter text, the standard QWERTY keyboard appears, as shown in Figure 3-20.

As with most keyboards, you can switch among letters, numbers, and special characters. (If you need a refresh on how to do it, see Book 1, Chapter 2.)) Everything you type or dictate is inserted into the selected cell you tap until the Done button, which is at the right of the display above the keyboard. If you enter a Return character, it's part of the text in the cell. The cell automatically expands vertically to accommodate the text you type, and you can resize the column so that the cell is the appropriate size. Remember, these specialized features are not available on Bluetooth keyboards, so it's often preferable to use the onscreen keyboard when using Numbers.
