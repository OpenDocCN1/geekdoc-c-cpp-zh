# Adding Calendar Events

+   1. Scroll down and tap Calendar Alerts and then tap any alert tone, which causes iPad to play the tone for you.

+   2. After you choose a tone, tap Sounds to return to the Sounds settings.

+   3. Press the Home button and tap Calendar.

+   4. Create an event in your calendar or open an existing one for editing (see the preceding sections).

+   5. In the Add Event dialog or Edit dialog for an existing event (refer to Figure 3-6), tap the alert field.

The New Alert appears, as shown in Figure 3-9. Note that if you want two alerts — say, one day before and one hour before — you can repeat this procedure using Second Alert instead. The Second Alert appears directly below the alert field in the Add Event dialog after you set an alert.

+   6. Tap any preset interval, from 5 Minutes before to 2 Days Before or at the time of an event.

+   7. Tap New Event or Edit Event to return to the New Event or Edit Event dialog.

+   8. Tap Add (for a new event) or Done (if you're done editing an existing event) to save the alert.

+   9. Tap the Day button to display the date of your event in Day view and then tap the event.
