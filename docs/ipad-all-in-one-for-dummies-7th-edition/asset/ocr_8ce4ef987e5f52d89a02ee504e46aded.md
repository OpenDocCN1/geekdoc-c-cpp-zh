# 428 Making Notes

Here are the steps to get going with Notes:

+   1. Tap the Notes app icon on the Home screen.

Depending on how you have your iPad oriented, you see the screen shown in Figure 2-1 (portrait) or Figure 2-2 (landscape).

+   2. Tap the blank page.

The onscreen keyboard, shown in Figure 2-3, appears.

+   3. Tap keys on the keyboard to enter text.

If you're using a third-generation (or later) iPad or an iPad mini, tap the Dictation key — see Figure 2-3 — and speak your text using iPad's speech recognition feature.

For more about Dictation, see Book I, Chapter 3.
