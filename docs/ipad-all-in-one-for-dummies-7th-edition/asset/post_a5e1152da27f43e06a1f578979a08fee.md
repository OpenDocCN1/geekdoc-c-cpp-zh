
## Exploring Safari

If you need to know how to connect to the Internet, see Chapter 5 in this minibook. After you're connected, you're ready to browse with Safari.

If you've used Safari before, you'll notice a major difference in how it works on your iPad. It offers all the typical browser tools, but an important iPad feature is the use of gestures on the touchscreen to manipulate pages and navigate the web.

Though Safari is a fine browser, you're not limited to it. You can download other browsers to iPad, such as Google Chrome, Atomic Web Browser, and Safe. Check out the App Store for the latest available browsers.

Try the following steps to practice using Safari:

- 1. **After you're connected to a network, tap the Safari icon on the Home screen.**
  Safari opens, probably displaying the Apple Home page the first time you go online. (See Figure 6-1.)

When you enlarge the display, you gain more control using two fingers drag from left to right or from top to bottom on the screen. On a reduced display, one finger works for making these gestures.

## Navigating among web pages

I expect that you have entered URLs and used the Forward and Back buttons in a browser to navigate around the web. However, the iPad's onscreen keyboard differs slightly from a standard keyboard, and it might help you to run through the mobile version of Safari.

Follow these steps for a bit of navigating practice:

- 1. With Safari, tap in the Address/Search field.
  The onscreen keyboard appears, as shown in Figure 6-3.

- 2. To clear the field, press the Delete key on the keyboard. Enter a web address, using the .com key to make entry faster.

Hold down the .com key to access options .edu, .gov, and .net. If you have no website in mind, go to this book's companion site, www.ipadmadeclear.com.

- 3. Tap the Go key on the keyboard (refer to Figure 6-3).
  The website appears.
- If for some reason, a page doesn't display, tap the Reload Icon at the end of the Address/Search field.
- If Safari is loading a web page and you change your mind about viewing the page, you can tap the Cancel icon (the X) at the end of the Address/Search field during this process to stop loading the page.

- 4. Tap the Back button to go to the last Safari displayed.
- 5. Tap the Forward button to go forward to the page you came from when you tapped Previous.
- 6. To follow a link to another web page, tap the link with your finger.

To view the destination web address of the link before you tap it, just touch and hold the link, and a menu appears that displays the address at the top, as shown in Figure 6-4.

## Using tagged browsing

Safari has a feature called tabbed browsing, which allows you to have several pages open at one time. This feature is useful when you want to move between open tabs, such as Safari, Google Chrome, or Firefox.

To add a tab, follow these steps:

- 1. With Safari, tap the Add button (shaped like +) near the top corner.
  A new tab opens. You can then enter an address or search for a site.
- 2. To close a tab, tap the X in the tab corner.
  - 3. To switch among open tabs, tap the All Tabs button and select the tab you want to view.

Safari also allows you to save pages as Favorites. To save a page, tap the Share button and then Add to Bookmark. You can access these favorites later by tapping the Bookmarks button.
