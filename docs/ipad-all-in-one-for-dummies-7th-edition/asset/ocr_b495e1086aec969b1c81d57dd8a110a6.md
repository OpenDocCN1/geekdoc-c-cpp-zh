# # Posting photos and printing from Safari

You can post photos on your iPad to save them as eBay, Craigslist, or Facebook from within Safari. Follow these steps (to follow this example), download the Facebook for iPad app and create a Facebook account, if you haven't already:

+   1. Go to Facebook and sign in.

+   2. Click an Add Photos/Video, Upload, or similar link, like the one in Figure 6-17.
