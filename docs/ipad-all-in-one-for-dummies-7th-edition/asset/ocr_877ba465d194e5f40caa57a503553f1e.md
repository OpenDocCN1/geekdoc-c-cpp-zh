# VoiceOver

After VoiceOver is turned on, you need to figure out how to use it. I won't lie — it is awkward at first, but you'll get the hang of it! Here are the main gestures you should know how to:

+   Tap an item to select. VoiceOver speaks its name.
Double-tap the selected item. This action activates the item.
Flick three fingers. It takes three fingers to scroll around a page with VoiceOver turned on.

Table 3-1 provides additional gestures to help you use VoiceOver. If you want to use this feature, read the VoiceOver section of the iPad's User Guide, which goes into a deal of detail about the ins and outs of VoiceOver. You'll find the User Guide at http://manualsinfo.apple.com/MANUALS/I100/MA1565/en_US/iphone_user.pdf or download it from the Books Store.
