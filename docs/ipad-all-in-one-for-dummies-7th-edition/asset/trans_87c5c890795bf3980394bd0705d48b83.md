# 更改页面背景、字体大小和类型

如果屏幕上的字体对你的口味来说太小，你可以更改为更大的尺寸或选择不同的字体以提高可读性。遵循以下步骤：

- 1. 打开一本书时，点击显示按钮。

它有一个小字母 a 和一个大写字母 A，如图 7-11 所示。

## 使用书签和高亮

Books 中的书签和高亮是帮助你记住位置或情节的收藏。要添加书签和高亮，请遵循以下步骤：

- 1. 打开你想要阅读的书时，点击右上角的书签（丝带图标），如图 7-15 所示。一个彩色书签被放在页面上。
