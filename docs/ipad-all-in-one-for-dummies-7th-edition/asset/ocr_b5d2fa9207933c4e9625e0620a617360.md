# Working with Cells

Double-tap a cell if you want to add or edit data. A blue outline appears around the cell, and the keyboard appears so that you can begin entering data.

Single-tap if you want to select a cell. The cell is outlined, and the table-selection elements (the column and row frames, the Cells button at the left of the column frame, and the button to the right of the column frame as the button beneath the row frame).

Double-tap makes the cell available for editing. Figure 3-15 shows how, after a double-tap in a cell, the keyboard appears.
