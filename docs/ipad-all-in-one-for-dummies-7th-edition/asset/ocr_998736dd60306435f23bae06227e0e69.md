These two work very similarly: Tap the Stopwatch or Timer and tap the Start button. When you set the Timer, iPad uses a sound to notify you when time's up. When you start the Stopwatch, you have to tap the Stop button when the activity is done (see Figure 3-21).

Note that you can use the Lap feature with Stopwatch to time a quick series of events within a larger event, such as timing each of ten laps in a swimming race and getting a total time at the end of the race. Just tap the lap button while recording time to tally one lap and move on to the next. Tap Stop all laps are complete.
