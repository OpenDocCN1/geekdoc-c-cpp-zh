+   4. Swipe from one page to another to find the table layout you you like.

Though you can change any element in the table layout, start with one close to what you want to end up.

There are five pages of templates — each of the five pages has the same layouts with different color schemes. This list describes them from the upper-left corner, as shown in Figure 3-28:

+   * Header row and a header column at the left: This is one of the most common table layouts.

+   * Header row at the top: This works well for a list as students in a class.

+   * No header row or header column: Before choosing this blank spreadsheet, headers and titles for the tables will make your spreadsheet more usable. You can add (delete) them later and change them, but take a few moments to identify the table along with its rows and columns as you create it.

+   * Header and footer rows and a label column: This works well for titles at the top and left for some or other calculations at the bottom.

+   * Check boxes in the left column: This option makes a great list of things to do.
