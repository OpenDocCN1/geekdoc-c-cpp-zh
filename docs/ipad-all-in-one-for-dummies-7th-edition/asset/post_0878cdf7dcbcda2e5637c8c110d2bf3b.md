# Changing the page background and font size and type

If the type on your screen is a small bit for your taste, you can change to a larger size or choose a different font for readability. Follow these steps:

- 1. With a open book, tap the Display button.

It sports small letter a and a large capital A, as shown in Figure 7-11.

![](img/2a8a8d89daeb1b3896bd38ebf18af126_276_0.png)

Figure 7-11: Need larger text? That seems easy.

- 2. In the Display that appears, the small letter a button on the left to use smaller text, or tap the font labeled with the capital A on the right to use larger text.

- 3. Tap the Fonts boots, as shown in Figure 7-12, appears. This list may vary slightly if Apple adds more or if you're using a larger language than English on iPad.

# 4. Tap a font name to select it.

The font changes on the book page.

# 5. Tap White, Sepia, or Night to choose the font you want to display.

If you want to have a sepia tint on the pages or to reverse black and white, which can be easier on the eyes, you can change from the default White to one of them. Turning Auto-Night Theme on your iPad determines whether you are reading in dimmer light and adjusts to the Night theme accordingly.

# 6. Tap the Display dialog to return to.

Some fonts appear a bit larger on your screen because of their design. If you want the largest font, you're reading a PDF file rather than an electronic book, so be aware that you can't modify the page's appearance.

## Using bookmarks and highlights

Bookmarks and highlights in iBooks are favorites that help you remember a spot or plot point. To add a bookmark and use highlights, follow these steps:

- 1. With a book you want to read, tap the Bookmark (the ribbon) in the upper-right corner, as seen in Figure 7-15. A colored bookmark is placed on page.

![](img/2a8a8d89daeb1b3896bd38ebf18af126_279_1.png)

Figure 7-15: Assign a bookmark to page.

2. To highlight a word or phrase, press on the text. The contextual menu shown in Figure 7-1 appears.

3. Tap the Highlight button. A colored highlight is placed on the word.

![](img/2a8a8d89daeb1b3896bd38ebf18af126_280_0.png)

Figure 7-1: Use these tools to perform actions.

4. To change the color of the highlight, or add a note, tap the highlighted word.

5. Tap one of these items:

- Colors: Tap the color button to change the highlight.
- Remove Highlight: Tapping the text with a red line removes the highlight.
- Note: Tap the Note icon to add a note.
- Share: Tap the button to choose sharing the text via Messages, Mail, or Facebook.

6. Tap outside the highlighted word to close the menu.

7. To go to a list of bookmarks, tap the Table of Contents on a book page.

8. In the Table of Contents, tap the Bookmarks or notes tabs. As shown in Figure 17-18, all contents, bookmarks, or notes (including hlights) display on their respective tabs.
