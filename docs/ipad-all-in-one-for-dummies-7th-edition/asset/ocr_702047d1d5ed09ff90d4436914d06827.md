# Locating a document

Before long, you'll have created several documents, and chances are good that you'll want to go back and work on some of them, print them, or share them via iCloud, AirDrop, Mail, or Message. As with creating new documents, locating a document is done the same way in each of the iWork apps.

To locate a document, follow these steps:
