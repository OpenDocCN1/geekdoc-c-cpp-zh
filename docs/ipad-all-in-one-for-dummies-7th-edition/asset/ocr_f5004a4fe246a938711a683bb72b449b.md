# Going on Safari

Safari is Apple's web browser. If you've owned a Mac computer, iPhone, or
iPad touch, you've already used Safari (see Figure 4-1) to navigate around
t Internet, create and save bookmarks of favorite sites, and add web clipsnto Home screen so you can quickly visit sites from there.

![](bbox=[0.153, 0.752, 0.225, 0.824])

If you've a Windows user in the past, you may also have used Safari,
or you may be more familiar with browsers such as Internet Explorer, Chrome,
or Firefox. If you haven't used Safari, don't worry; the browser should be
pretty easy for you to get the hang of, with its familiar integrated address-
search fields, tab navigation, and bookmarks.

Using a browser on iPad is a lot of fun because of the touchscreen functional-
ity gives you the ability to zoom in or out of a page by flipping two-
gers inward or outward. Tabbing browsing allows you to move easily amongnown pages, and the All Tabs view with iOS 8 for iPad lets you see
 your open tabs as thumbnails on a single screen. You can read more
out using Safari in Chapter 6 of this minibook.
