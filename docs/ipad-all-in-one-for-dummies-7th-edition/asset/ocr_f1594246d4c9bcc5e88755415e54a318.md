5. If you make a mistake (and when you may first use it), use the Delete key (the key in the top-right corner of the keyboard with a letter x on it) to delete text to the left of the insertion point.

6. To create a new paragraph, press the Return key, just as you on a computer keyboard.

7. To type numbers and some symbols, press one of the number keys (labeled ..123) located on either side of the spacebar (refer to Figure 2-9).

Characters on the keyboard change. To return to the letter keyboard at any time, simply tap one of the letter keys (labeled ABC) on either side of the spacebar.

If you type a number in the number/symbol keyboard and then tap the keys, the keyboard automatically returns to the letter keyboard.
