2. **To add a new page (meaning that you're opening a new website),** tap one of the Favorites or frequently used sites displayed (refer to Figure 6-5) or tap in the address bar that appears, enter a website address, and then tap the Go key.

Note that you can get to the same page by simply tapping the address bar from any site.

The site opens.

3. **Switch among open sites by tapping another tab, or tap the Show All Tabs to see all open web pages.**

If you tap Show All Tabs, you can tap a page to go to it or tap Done to close the All Tabs view.

4. **To close a tab, scroll to the tab and then tap the Close button in the upper-left corner of the tab.**
