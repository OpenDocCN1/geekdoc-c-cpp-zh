# Working with Tabs and Sheets

Every tab displays a sheet, which can have one or more tabs or charts (or both) on it as graphics and text frames. Tabs help you organize the contents of your Numbers documents. In this section, I will tell you what need to know about setting up tabs in a document.

# Adding a new tab

As with iWork apps, starting a new Numbers document involves choosing a template. Each template has its own predefined tabs. The Blank template has only one tab (cleverly titled Sheet 1). You can add more tabs by using the plus sign (+) tab on the left end of the tabs (Figure 3-4).

Tap here to add a new tab.

![](bbox=[0.238, 0.501, 0.706, 0.546])

Figure 3-4: The plus sign (+) tab always appears to the left.

Tap the plus sign (+) tab, and Numbers asks whether you want to add a new sheet or a new form. Tap New Sheet, and Numbers creates a new tab that contains one tab (see Figure 3-5). The sheet is labeled Sheet 1. See the section "Changing a tab's name," later in this chapter, for how to rename the tab. If you're interested in forms, I tell you about that topic later in this chapter, "Using Forms Efficiently")
