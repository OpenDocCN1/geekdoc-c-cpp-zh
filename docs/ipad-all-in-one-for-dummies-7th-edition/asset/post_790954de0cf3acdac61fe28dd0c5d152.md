## Finding Notes

After you create a note, you need to find it if you want to view or edit it. You can scan the Notes List to find a note or use the Search tool. You can also swipe on the Notes pad to move among notes. The following sections help you find and move among notes you've created.

## Displaying the Notes List

The Notes List contains all your notes listed chronologically by the last date/time you modified the note. This list isn't available in portrait orientation, but it's the list you need in order to see the notes you have stored. If you're using landscape orientation, a list of notes appears by default on the left side of the screen.

If you're using portrait orientation, you can display this list in portrait orientation by tapping the Notes button in the top-left corner of the screen; the Notes List appears, as shown in Figure 2-7. Tap any note in the list to display it.

The Notes List is also the Accounts List if you enabled notes syncing in iCloud or other shared settings in Settings.

## Moving around notes

If you want to look for a note based on how long ago you created it, you should know that notes are stored with the most recently created or modified notes at the top of the Notes List. Older notes fall toward the bottom of the list. The date and/or time you modified a note also appears in the Notes List to help you out.

It's easy to move among notes you created:

- 1. Tap the app on the Home screen to open it.
2. With the Notes List displayed, tap a note to open it.

You can display the Notes List by either turning iPad to landscape orientation or tapping the Notes button in portrait orientation; see the proceeding for viewing your Notes List.

Notes isn't a file-management pro; it allows you to enter multiple notes with the same title, which can cause confusion. Be advised, and name your notes uniquely!

## Searching Notes

If you're not sure which note contains that very important item, you can search to locate a note that contains certain text. The search feature lists only notes that contain your search criteria; it highlights only the first instance of the word or words that you enter within a note.

The Spotlight search feature in iPad also locates notes that matches your search term you enter there, along with many other types of content. Book I, Chapter 2, for more about the Search feature.

Follow this procedure to use the Notes search feature:

- 1. Tap the Notes app on the Home screen to open it.

## Sharing a Note

Today, if you want to share a note with a friend or colleague, you can share it by following these steps:

- 1. With a note displayed, tap the Share button.
- 2. In the pop-up menu, tap Mail.
- 3. In the email form, enter addresses in the To, Cc, or Bcc fields.
- 4. If you need to make changes to the subject or message, use either keyboard or Dictation to speak your changes.
- 5. Tap the Send button.
Your email is sent.

To cancel an email and return to Notes without sending it, tap Cancel. If you want to save a draft for later, tap Save Draft. Your draft will appear in the Drafts in Notes.
