# 382 Working with Cells

Here's how check box customization can work:

+   1. Double-tap a cell to start editing it; tap the 42 icon and tap the Checkbox button when the keyboard opens.

You see a check box in the selected cell; in the area above the keyboard, you see the word *false*, as shown in Figure 3-17. The green outline distinguishes the word *false* from text you type in. It has the value *false* because, before you type anything, its numeric value is zero.

![](bbox=[0.287, 0.301, 0.758, 0.355])

+   2. Type a nonzero value.

This value can represent the number of items in stock, for example.

+   3. Tap the Checkbox button again.

You see the value you changed to *true* (see Figure 3-18) and that the check box is selected in the table.

Because the formatting is separate from the data value, you sometimes display the in-stock inventory count as a number and sometimes the check box. Customers are likely to care only about the check box, but the inventory manager cares about the number.

![](bbox=[0.287, 0.606, 0.758, 0.652])

Everything in Numbers is linked, so you don't have to worry about a sequence for most things. If you've followed these steps, you've seen how to enter a number and have control it check box, but that's only one of at least three ways of working with a check box.

With a selected cell and the Checkbox formatting selected, you see the true/false value above the keyboard and the check box itself in the table. Tap the check box in the table: The true/false value is reversed, and it is the state of the check box itself.

Likewise, if you tap the word *true* or *false* in the display above the keyboard, the check box flips its value and true/false reverses.
