If you have GPS, 3G or 4G, and/or a connection to a virtual private network (VPN), symbols appear on the status bar when these features are activated. The GPS and 3G icons appear only with 3G-enabled iPad models. If you have a 3G/4G model but no 3G/4G available, you may see an icon for EDGE. If you are out of range of 3G/4G and EDGE, you see GPRS. iPad tries for the best connection and jumps to a lesser connection if the best isn't available.

# Using Control Center

Control Center is a one-stop screen for common features and settings as connecting to a network, increasing screen brightness or volume, and using the Calculator or Camera. Control Center settings include

+   - Music playback controls
- Audio volume
- Airplane mode
- Wi-Fi connection
- Bluetooth
- Do Not Disturb

Orientation Lock or M, depending on what the Side switch is set to control (the side switch is not available on the iPad Air 2, though those Center settings allow you to change orientation and volume settings)
