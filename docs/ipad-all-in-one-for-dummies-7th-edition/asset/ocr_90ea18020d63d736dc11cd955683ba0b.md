+   4. Tap Table Options to return to popover and then tap Table Font or the Smaller or Larger text size buttons to format the text in the table.

+   5. Tap Table in the popover and then tap the Headers to modify headers for rows and columns.

You can set the number of header rows or columns. (You have either footer rows or one footer row.) These elements are created using the existing color scheme.

Freezing rows and columns keeps the header rows and columns on each page. As you scroll the data, the data itself moves, but the headers scroll out of sight. This option is often the best one unless the table's content is self-explanatory.

+   6. When you're finished, tap anywhere outside the popover to close it.
