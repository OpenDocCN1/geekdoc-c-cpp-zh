This is because the conversion from binary to such a radix involves _carry propagation_ from lower order digits to higher order digits. When using a radix that is a power of 2, say 2<sup>_k_</sup> for _k_ > 1, such carry propagations do not occur as the equivalent digit in the new radix of 2<sup>_k_</sup> can be obtained by simply grouping successive _k_ bits from the least significant bit position, independent of the other bits.

Consider as an example the transmission of the binary number (0111111)<sub>2</sub> = (63)<sub>10</sub> using ternary encoding. The ternary representation of (63)<sub>10</sub> is (2100)<sub>3</sub>. If the least significant digit of this ternary number transmission, i.e., 0 is wrongly interpreted at the receiver as 1, the received binary number after decoding will be (1000000)<sub>2</sub>, representing a propagation of error from the least significant bit to the most significant bit position. A BER-based error analysis would not be able to capture such _ripple effects_ (on the original binary number) of error in interpreting a single digit (in radix other than power of 2) at the receiver.

The FER-based error analysis overcomes the limitation of BER-based error analysis in capturing the transitive nature of error propagation to the higher significant bit positions of the decoded binary number, caused by a single digit error in the received ternary data. Although we show the error analysis of only the TSS scheme based on FER, this concept of FER-based error analysis is generally applicable to any transmission scheme that uses recoding of binary data to another radix which is not a power of 2 for the reason mentioned above.
