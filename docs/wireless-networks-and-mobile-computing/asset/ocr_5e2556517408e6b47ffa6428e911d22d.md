We now describe the assignment algorithm, illustrating each step with the example of the benchmark Problem 6 defined on the hexagonal cellular network shown in Figure 3.2. For the purpose of illustration, the demand vector $D_2$ has been explicitly shown in Figure 3.2 where the label $[d]$ associated with a node denotes the demand of that node. The frequency separation constraints for this benchmark problem is given by $s_0 = 5$, $s_1 = 2$ and $s_2 = 1$. The frequency separation matrix $C = (c_{ij})$ can be derived by using the $s_0$, $s_1$ and $s_2$ values. In $C$, $c_{ii} = 5 \ \forall i$ and $c_{ij}$ is equal to 2, 1 and 0 if nodes $i$ and $j$ are distance 1, 2 and $\geq 3$ apart, respectively, from each other in the cellular graph of the figure.

As a first step of the assignment algorithm, we rearrange the nodes of the network according to the descending order of their demands. The resulting order may reveal several nodes with the same demand. We further rearrange these nodes according to the descending order of their $S_i$ values, where $S_i$ is the sum of the demands from adjacent nodes of node $i$. Let this ordered set of nodes be termed $S$.

We now consider the subgraph of the cellular graph containing only the highest demand nodes and look into its assignment by using a greedy algorithm. This greedy algorithm will start with assigning the frequency $origin$ to the first highest demand node in the ordered set $S$. It takes the next node from the ordered set $S$ and tries to assign the minimum frequency to that node from the ordered sequence $\langle origin, origin + 1, origin + 2, \ldots \rangle$, satisfying the frequency separation constraints with the previously assigned node. This process is repeated for all the remaining nodes of the set $S$ taken in order.
