# Step 4: Calculation of $Z_1$ and $Z_2$.

The main idea to get the most from loop un-rolling in RC4 is to bypass the generation of $S_1$, and move directly from $S_0$ to $S_2$, as discussed. However, note that we require the state $S_1$ for computing the output byte $Z_1 = S_1[S_0[j_1] + S_0[i_1]]$. We apply the following method of cross-loop look-back to resolve this issue.

Using Step 4 of Algorithm 2, we can rewrite the output $Z_1 = S_1[S_1[i_1] + S_1[j_1]] = S_1[S_0[j_1] + S_0[i_1]]$ as

$$Z_1 = \begin{cases}
S_2[i_2] & \text{if } S_0[j_1] + S_0[i_1] = j_2,\\
S_2[j_2] & \text{if } S_0[j_1] + S_0[i_1] = i_2,\\
S_2[S_0[j_1] + S_0[i_1]] & \text{otherwise.}
\end{cases}$$
