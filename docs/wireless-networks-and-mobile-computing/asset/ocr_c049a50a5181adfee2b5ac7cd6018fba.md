# 1.3.4 Security

Security in communication is one of the very important aspects to be considered in most real-life applications involving message communication. In particular, the wireless networks are more vulnerable to attacks by intruders than the wired networks. This has given rise to security issues like user authentication, encryption and decryption of messages and jamming. However, often the algorithms designed for these purposes consume a lot of time and energy (through the use of large programs or complex hardware) which may not suitable for online wireless communication. Research to find suitable techniques for online low-energy secure communication in cellular mobile networks is ongoing.

# 1.4 Issues in Ad Hoc Networks

The important issues that need to be considered by the researchers and developers of ad hoc networks include the following:

+   - Initialization
+   - Leader election
+   - Communication protocol
+   - Location identification
+   - Energy
+   - Security
