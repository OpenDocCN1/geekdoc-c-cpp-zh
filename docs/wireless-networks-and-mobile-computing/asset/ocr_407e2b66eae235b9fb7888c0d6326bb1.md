Because of Lemma 31 it follows that if we consider *n*-digit representation of numbers in TFNS, not all possible $3^n$ code values will be generated by the *DTFNS* algorithm. To be more precise, whenever we come across some number *N* with the lowermost *k* digits in its TFNS representation as 2111…1, the next consecutive number *N* + 1 will have its lowermost *k* + 1 digits in TFNS as 1000…0, thus eliminating many of the possible code values between them. The number system differs from the Zeckendorf number system in having the alternate Fibonacci numbers as positional weights. Such a choice of alternate Fibonacci numbers leads to a number representation using 0, 1 and 2 for any digit position. Moreover, Zeckendorf representation does not have two consecutive 1’s as we will see below; specifically there will not be two consecutive 2’s in the number representation stated in the following lemma.

**Lemma 32.** *TFNS representation of any given number may have consecutive 1’s but no consecutive 2’s.*

The proof follows as a corollary of Lemma 31.

Thus, unlike the Zeckendorf representation which does not allow consecutive 1’s in the representation, this number system allows two consecutive 1’s but no consecutive 2’s. The properties given in Lemma 31 and Lemma 32 lead to unequal distribution in the total numbers of 0’s, 1’s and 2’s in the TFNS coding of numbers for any given *n*-digit representation. A careful look at the digit generation process in the *DTFNS* algorithm would reveal the exact distribution of the numbers of 0’s, 1’s and 2’s in the TFNS code values.
