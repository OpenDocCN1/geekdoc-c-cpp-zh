Note that although the hearing zone of a given cell *i* in our assumption extends up to cells at Distance 1 from cell *i*, the interference zone of cell *i* extends up to cells at Distance 2 from cell *i*. Hence, for scheduling the transmission slots, at a time we need to consider *only* the nodes lying in a cell and all other cells within Distance 2 from it, but not the entire set of nodes in the whole ad hoc network. This may result in using a much smaller number of communication slots for effecting broadcast, as discussed below.

Using the location information of the nodes, the number of active nodes and the actual *demand* of each cell at that instant of time are computed. We use this cell demand information to assign time slots to each mobile node by a clever *re-use* of the time slots by cells lying farther than Distance 2 as explained above, by exploiting the hexagonal symmetry of the imposed cellular structure and avoiding interference among the nodes. The technique described below ensures an *optimal collision-free assignment* for every node of the network in O(m) time, *m* being the number of nodes in the network. This problem of finding an *optimal* time slot assignment schedule for the ad hoc network is called the *slot assignment problem* (SAP). The slot assignment algorithm presented here supersedes the existing algorithms [3, 7] with respect to optimality, and requires O(log log *m* + *mD* + *n*) time to determine an optimal, collision-free slot assignment schedule for the entire network where *n* is the number of cells in the overlaid cellular graph and *D* is the diameter of the ad hoc network.
