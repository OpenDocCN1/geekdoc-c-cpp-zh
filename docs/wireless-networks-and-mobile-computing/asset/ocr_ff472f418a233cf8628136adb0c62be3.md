$$P_S=P_N\left[1-\left(1-e^{-e_{th}^2/2\sigma^2}\right)^3\right]$$

$$\qquad +P_A(1-X_1X_2)+P_B(1-X_1X_2)$$

$$\qquad +P_C(1-X_1X_2).$$ (8.44)

Assuming $P_A=P_B=P_C$ for equal likelihood of the symbols $A$, $B$ and $C$, we get

$$P_S=P_N\left[1-\left(1-e^{-e_{th}^2/2\sigma^2}\right)^3\right]+3P_A(1-X_1X_2).$$

Assuming $P_N=0.25$ and $P_A+P_B+P_C=0.75$, we get the following expression for $P_S$:

$$P_S=0.25\left[1-\left(1-e^{-e_{th}^2/2\sigma^2}\right)^3\right]+0.75(1-X_1X_2).$$ (8.45)

Thus, from Equations (8.38) and (8.45), using $k=2$ for the CNS scheme, the bit error rate is given by

$$BER=\frac{2}{3}\left[0.25\left[1-\left(1-e^{-e_{th}^2/2\sigma^2}\right)^3\right]+0.75(1-X_1X_2)\right].$$ (8.46)
