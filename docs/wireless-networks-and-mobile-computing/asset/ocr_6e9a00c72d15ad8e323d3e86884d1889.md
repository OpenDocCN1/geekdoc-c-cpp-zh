+   1. Advertisement Lifetime: There is a _lifetime_ field in the main body of the Internet Control Message Protocol (ICMP) router advertisement portion of the agent advertisement. The MN records this information for the lifetime of the binding with the current CoA, until the lifetime expires. When the lifetime expires, the MN must attempt to solicit a new agent.

+   2. Network Prefix: This scheme uses a network prefix consisting of some number of initial bits in the IP address to detect movement. If the prefix received through the agent advertisement differs from the prefix in the current CoA of the MN, the MN decides that it has moved to a different AP.

Once the MN discovers that it is on a new foreign network, it obtains a new CoA from the new AP and performs the location update procedure, which includes the creation or modification of a mobility binding at its home agent by associating the current CoA with the associated lifetime for the binding. This is in contrast to the location update process in PLMN which involves modifying location databases at various places of the network.
