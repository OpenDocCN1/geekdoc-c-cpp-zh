# 8.4.3 Non-coherent Detection

In this section, we compare the FER of communicating a binary data frame using non-coherent BFSK, with the FER of communicating the equivalent ternary data in the TSS scheme using a receiver based on non-coherent detection as shown in Figure 8.10.

In the hybrid FSK-ASK modulation scheme, let α be the probability that a transmitted ternary symbol was a 0 and was received correctly as a 0. Similarly, let β (or δ) be the probabilities that a transmitted symbol was a 1 (or 2) and the received symbol is also a 1 (or 2). From symmetry, β = δ. Note that α = P{q_A = 0|0}·P{q_B = 0|0}, where P{q_A = 0|0} and P{q_B = 0|0} are the probabilities of correctly receiving a 0 at q_A and q_B, respectively, given that a 0 was transmitted. Hence,

$$\alpha = P\{q_A=0|0\}\cdot P\{q_B=0|0\} = [P\{q_A=0|0\}]^2 \quad \text{(by symmetry).} \tag{8.19}$$

Also, note that q_A for 0 transmission follows Rayleigh distribution. Assuming a zero mean and a standard deviation of σ for AWGN channel, we can write

$$P\{q_A=0|0\}=\int_0^{e_{th}} \frac{e_A}{\sigma^2}e^{-e_A^2/2\sigma^2}\,de_A = (1-e^{-e_{th}^2/2\sigma^2}).$$
