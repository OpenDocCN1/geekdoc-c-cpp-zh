# 8.3.3  Analysis of Energy Savings

Let us first compute the average number of non-zero digits after applying reduction rule 1 on a binary string of length \(n\). We first find the total number of occurrences of runs of 1’s of length \(k\), \(1 \leq k \leq n\) in all possible binary strings of 0’s and 1’s of length \(n\).

We denote a run of 1’s of length \(k\) by \(R_k\). Clearly, two consecutive runs of 1’s of length \(k_1\) and \(k_2\), \(1 \leq k_1, k_2 \leq n\) in a bit string will be separated by at least one zero. Let us append a zero on left of each such \(R_k\), \(1 \leq k \leq n\) and denote the symbol 0\(R_k\) by \(y_k\). We also denote a single zero by the symbol \(y_0\). Each such \(y_k\), \(0 \leq k \leq n\), will be a string of length \(k+1\). We describe two techniques for solving this counting problem: one using generating functions and the other using recurrence relations.
