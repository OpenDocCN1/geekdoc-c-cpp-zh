After computing this increment value in Step 4, given the whole set of nodes of the network in order, we find the assignment of frequencies to as many nodes as possible with the frequencies in [origin, origin + increment). V is the set of nodes assigned a frequency and V' are those not assigned in Step 4. Note that the value of increment is computed in such a way that the set V must include all the highest demand nodes in W. Next, we have derived the round vector D = (d_v) where d_v = (γ_max - γ'_max) if w_v ≥ (γ_max - γ'_max) and d_v = w_v otherwise. The algorithm then repeats the assignment of the nodes in V for d_v rounds and the residual demand vector after reducing d_v demands corresponding to the nodes in V is computed. However, the demands corresponding to the nodes in V' remain unchanged. Thus, after satisfying d_v demands of the nodes in V, the highest demand of the nodes of V will reduce to γ'_max. This will ensure that the highest demand node in V' will now move to the set of highest demand nodes in the residual demand vector. As a result, in the next phase of assignment, this node must be covered by the assignment algorithm. Note that for the first phase of assignment, the set V must include all the highest demand nodes of the entire network. Therefore, in the worst case, if V' includes the second highest demand of the entire network, the highest demand in the residual demand vector will become the second highest demand of the entire network.
