# **FIGURE 5.35:** Dynamic source routing

when *S* needs to send a packet to a destination node *D*, and *S* does not find an entry in its route cache for a valid (unexpired) route to *D*, *S* sends a *route request* message *RREQ* to all of its neighbors. The *RREQ* contains the source id *S*, destination id *D* and a unique identification number for the request from *S*. When node *u* receives this *RREQ* message, it looks into its own route cache to see whether it has an entry for a route from *u* to node *D*. If no such entry exists and node *u* is not the destination node *D*, *u* forwards this *RREQ* to all of its neighbors, appending the currently known route from the source *S* to *u*. If an entry for a route from *u* to *D* is found in the route cache of *u* or *u* is the destination node *D*, the accumulated route information from node *u* to *D* is appended to the *RREQ* message to generate a route from *S* to *D* and the route is sent from *u* to *S* (unicast) in the form of a route reply message *RREP*, by traversing the discovered route in the backward direction.
