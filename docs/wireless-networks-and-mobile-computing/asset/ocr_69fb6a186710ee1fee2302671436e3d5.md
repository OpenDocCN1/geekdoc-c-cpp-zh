Repeated transmission of messages from $u_1$ to $v_1$ through this node $w$ would eventually deplete the energy of $w$ to such a low level that it will no longer be able to communicate to other nodes of the network. Thus, if $w$ has some message to be transmitted to another node of the network, it can no longer do so. In the same way, it would not be possible for some other node to send its data to $w$. Thus, effectively, the node $w$ is altogether eliminated from the network. The situation can worsen if node $w$ falls in the shortest paths between more than one source-destination pair, e.g., the shortest path between source node $u_2$ and destination node $v_2$ also passes through $w$. In such a situation, the node $w$ will have a reduced lifetime serving as an intermediate node for message communication between several source-destination pairs. In essence, blind shortest path routing does not yield the best possible result considering the operational lifetime of a whole network. This is particularly true for low power wireless networks, e.g., wireless sensor networks in which each sensor node is battery powered. Despite the limited energy source, we want to extend the lifetime of each sensor node as much as possible.

To mitigate the above situation, several alternative message routing techniques have been proposed and consider the residual energy of the constituent nodes. Essentially, the idea is i) to maintain the residual energy level of each node above some chosen threshold value so that no node goes out of network connectivity, ii) the individual messages are transmitted with minimum communication latency (delay) and iii) the total energy required for communication of all messages throughout the network is also minimized. Note that if the communication ranges (which are dependent on the transmitting power of a node) of all nodes are same, the last two conditions are not mutually conflicting. Communicating each individual message via the shortest path will lead to the minimum energy expenditure for the total message communication between all source-destination pairs (we assume that no congestion or queuing delay at any intermediate node).
