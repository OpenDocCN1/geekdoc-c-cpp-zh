
## Step 3:

Compute $Fit(S_i)$ for each string $S_i$ $(0 \leq i \leq M - 1)$ of $q_t$. Find the best string $S_{best1}$ (i.e., the string with the least fitness value) and the worst string $S_{worst1}$ (i.e., the string with the highest fitness value) of $q_t$. If $S_{best1}$ or $S_{worst1}$ is not unique, choose one arbitrarily.

# Step 4: *(Selection or Reproduction)*

Perform the selection operation as described below on the strings of $q_t$ to generate a mating pool $q_{mat}$ of size M.

# *Selection operation*

+   - Calculate the probability $p_i$ of selection of $S_i$ $(i = 0, 1, \ldots, M - 1)$

$$p_i = \frac{\frac{1}{Fit(S_i)}}{\sum_{i=0}^{M-1}\frac{1}{Fit(S_i)}}$$

> *Note:* With this choice of $p_i$, the probability of selection of $S_i$ will be higher if $Fit(S_i)$ is smaller. This is required because we are dealing with the minimization problem.

[PAGE 133]

+   - Calculate the cumulative probability \(q_i\) for \(S_i\) (\(i = 0, 1, \cdots, M - 1\))

\[q_i = \sum_{j=0}^{i} p_j.\]

+   - Generate a random number \(r_j\) from \([0, 1]\) for \(j = 0, 1, \cdots, M - 1\). Now, if \(r_j \leq q_0\), select \(S_0\); otherwise select \(S_i\) (\(1 \leq i \leq M - 1\)) if \(q_{i-1} < r_j \leq q_i\).

*Note:* \(p_0 = q_0\) and \(p_i = q_i - q_{i-1}\) for \(1 \leq i \leq M - 1\).

> **Remark 2.** With this implementation, if \(p_i\) is higher, i.e., the interval \((q_{i-1}, q_i]\) is of greater length, the probability that the random number generated falls within the interval \((q_{i-1}, q_i]\) will be higher. In other words, the probability of selection of \(S_i\) will be higher if \(Fit(S_i)\) is smaller. In this way, from a current population of size \(M\), a mating pool \(q_{mat}\) of the same size with potential strings is constructed. Since we are dealing with a minimization problem, we will say the string \(S_i\) has more potential than the string \(S_j\) if \(Fit(S_i) < Fit(S_j)\). The strings of the mating pool then undergo crossover and mutation. This strategy for construction of the mating pool is close to that used in [49].
