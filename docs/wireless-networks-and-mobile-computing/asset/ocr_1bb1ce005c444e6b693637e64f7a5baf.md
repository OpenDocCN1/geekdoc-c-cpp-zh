However, our focus here is on arriving at an optimal value of *k* to strike a balance between hardware complexity and transmission energy. It is possible to arrive at a different value for optimal *k* by using an optimization function different from Equation (8.31).

While increasing the number of permissible symbols increases the energy consumption by the encoding and decoding logic, typically the energy requirement for communication is significantly larger than that for encoding and decoding [22, 41]. However, we use only four symbols corresponding to *k* = 2, so that the effect of this increased encoding and decoding logic on energy consumption will be nominal. Moreover, we need to use only three frequencies for communication in the corresponding hybrid FSK-ASK modulation scheme for implementing this idea with *k* = 2. Higher values of *k* would imply more frequencies for transmission, which in turn would lead to an increase in transceiver cost, complexity and energy consumption.
