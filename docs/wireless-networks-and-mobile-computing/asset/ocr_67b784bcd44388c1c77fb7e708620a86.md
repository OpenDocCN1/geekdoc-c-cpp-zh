> Is it possible to find some transmission schedule for a given node $u$ so that during all the rounds in a phase, there will be at least one round in which only one node belonging to the set $N(u)$ will be in transmit state?

The answer to the above question is “yes” by virtue of the results in [3, 2]. We describe below the protocol proposed in [2] and then compare its performance with that in [3]. To do this, we define a node as *covered* if it has already received the message, and *uncovered* if it is yet to receive the message. At any time instant, the sets of covered and uncovered neighbors of a node $i$ will be denoted by $N_c(i)$ and $N_u(i)$, respectively. A set $C$ of covered nodes will be called a **conflicting set** if there is at least one neighbor common to all the nodes in $C$ that has not yet received the message. By following the protocol in [2], the broadcast proceeds in a layer-by-layer fashion, i.e., all nodes at layer $\ell$, $1 \leq \ell \leq D - 1$, become informed of the message $m$ before any node at layer $\ell + 1$. Also, the transmission slots for every node will be independent of the identities of the current neighbors of the node, i.e., independent of the topology of the network. These transmission slots will also be independent of the mobility of the nodes subject to the conditions that the topology does not change during the broadcast of a single message and the network always remains connected, as assumed in the system model mentioned above.
