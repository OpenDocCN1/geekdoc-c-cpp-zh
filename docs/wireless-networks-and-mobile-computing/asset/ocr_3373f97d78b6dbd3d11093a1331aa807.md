For a given *k* ≥ 1, if we now sum the expression $N_{n}^{i_k,k}$ for all possible values of $i_k$, $1 \le i_k \le \lfloor(n+1)/(k+1)\rfloor$, we get the total occurrences of $R_k$ in all possible strings of length *n*. Tables 8.1 and 8.2 show the numbers of occurrences of all possible runlengths of 1’s in binary strings of length 8 and 16 bits, respectively. The tables along with Figure 8.8 demonstrate that the number of occurrences of run of 1’s of length *k* in a binary string of length *n*, $1 \le k \le n$, decreases exponentially as *k* increases.
