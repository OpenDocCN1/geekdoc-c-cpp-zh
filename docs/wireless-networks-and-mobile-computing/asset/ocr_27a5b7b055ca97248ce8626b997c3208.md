# 3.6  Fast Near-Optimal Channel Assignment

We now present a novel method [50] for solving channel assignment problems (CAPs) in hexagonal cellular networks with non-homogeneous demands in a two-band buffering system (where channel interference does not extend beyond two cells). The CAP with non-homogeneous demand is first partitioned into a sequence of smaller subproblems, each of which has a homogeneous demand from a subset of the nodes of the original network. The solution to such a subproblem constitutes an assignment phase in which multiple homogeneous demands are assigned to the nodes corresponding to the subproblem, satisfying all the frequency separation constraints. The whole assignment process for the original network consists of a succession of multiple homogeneous assignments for all the subproblems. Based on this concept, we present a polynomial time approximation algorithm given in [50] for solving the channel assignment problem for cellular networks having non-homogeneous demands. The assignment algorithm, when executed on well-known benchmark instances, yields an assignment which is always within about 6% more than the optimal bandwidth, but requires very little execution time (less than 5 milliseconds on a HPxw8400 workstation). This algorithm is suitable for real-life situations where fast channel assignment is of primary importance and a marginal deviation (6%) from the optimal bandwidth is tolerable.

The ultimate objective of this study is to devise a greedy algorithm that can produce a very fast assignment of the required channels (in milliseconds), while requiring a bandwidth as close as possible to the optimal bandwidth.
