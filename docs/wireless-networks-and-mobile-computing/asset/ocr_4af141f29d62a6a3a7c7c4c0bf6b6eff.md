Consider n = 8. The only string containing R₈ is 1111 1111, and there are only two possible strings containing R₇ given by 0111 1111 and 1111 1110. For R₆, there are five possible strings: 0011 1111, 1011 1111, 1111 1100, 1111 1101 and 0111 1110. We now try to find a systematic way to generate the strings containing R₆ from the two strings containing R₇. For this we define the following rules.

+   Left Replacement Rule (LRR): If there is a string containing Rₙ₋ₖ₊₁, k ≥ 2, by applying this rule, we can generate two possible strings containing Rₙ₋ₖ from Rₙ₋ₖ₊₁ by replacing the leftmost 1 in Rₙ₋ₖ₊₁ by a 0 and its immediate preceding 0 (if it exists) by either a 0 or a 1.

+   Remark 22. If there is no 0 preceding Rₙ₋ₖ₊₁, then only one string containing Rₙ₋ₖ is generated by replacing the leftmost I bit.

+   Right Replacement Rule (RRR): If there is a string containing Rₙ₋ₖ₊₁, k ≥ 2, by applying this rule, we can generate two possible strings containing Rₙ₋ₖ from Rₙ₋ₖ₊₁ by replacing the rightmost 1 in Rₙ₋ₖ₊₁ by a 0 and its immediate succeeding 0 (if it exists) by either a 0 or a 1.

+   Remark 23. If there is no 0 following Rₙ₋ₖ₊₁, then only one string containing Rₙ₋ₖ is generated by replacing the rightmost 1 bit.

+   Example 30. Thus, from R₇ in 0111 1111, we can generate two strings containing R₆ by left replacement rule (LRR) as 0011 1111 and 1011 1111. Also, by right replacement rule (RRR) on R₇ in 1111 1110, we can generate the two strings containing R₆ as 1111 1100 and 1111 1101. By LRR on R₇ in 1111 1110 or by RRR on R₇ in 0111 1111, we get the same string 0111 11110, i.e., 0R₆0 (duplicate generation).
