Note that $\log(FCR)=n(0.75\log\alpha+0.25\log\beta)$, from which we can easily evaluate $FCR$. Next we obtain the frame error rate ($FER$) for the RBNS message as $FER_{rbns}=1-FCR$.

Let us consider the situation that we transmit the original binary message of $n$ bits using non-coherent FSK with a BER of $\rho$. The probability that the whole frame will be received correctly is $(1-\rho)^n$. Thus, the FER for binary FSK will be given by $FER_{bfsk}=1-(1-\rho)^n$, which may be approximated as $n\rho$, since $\rho$ is usually very small. For a given frame size $n$, we can compare $FER_{rbns}$ with $FER_{bfsk}(=n\rho)$, or in other words, $FER_{rbns}/n$ with $\rho$. To compute $FER_{rbns}/n$, we set $s_A=1$, i.e., signal power $=s_A^2/2=1/2$ and a signal-to-noise ratio (SNR) $=1/2\sigma^2$. The computations to find the optimum threshold voltage $e_{th}$ that gives the minimum $FER_{rbns}/n$ for a given SNR were implemented in $MATLAB^\circledR$. Note that from Equation(8.13), we get the required peak transmitter power with RBNSiZeComm for a given value of $FER_{rbns}$.

The SNR values for binary FSK modulation are determined from the relation, $\rho=\frac{1}{2}e^{-\gamma/2}$ where SNR in dB $=10\log_{10}\gamma$.
