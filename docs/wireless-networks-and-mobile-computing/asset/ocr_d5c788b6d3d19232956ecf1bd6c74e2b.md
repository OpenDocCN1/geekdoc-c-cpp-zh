# 5.5.3  Gossiping

Under the collision detection model, we extend the above idea of breadth-first broadcast to devise an algorithm for gossiping among the nodes of ad hoc mobile network so that every node $u$ has some message $m_u$ to be broadcast to all other nodes of the network.

# 5.5.3.1  Basic Idea

In the algorithm $bf\_broadcast$, some of the nodes in $transmit$ state at, say, layer $j-1$, are selectively dropped so that eventually a receiving node in the layer $j$ would have exactly one transmitting node as its neighbor. A node in layer $j$ receiving the message without any collision sends an $ack$ signal in the $S$ slot.

Let $m_u$ denote the message that node $u$ wishes to broadcast. Each node maintains a message array of length $n$. The message from node $i$ is stored in the $i$th location of this message array. Let $\mathcal{M}_u$ denote the message set of a node $u$, which consists of all clean messages that $u$ has received so far. The source node $s$ that initiates the gossip algorithm initially has only one message $(m_s)$ in its message set. Each neighbor of $s$ subsequently appends its own message $m_u$ and all other messages it has received from its neighbors to form its message set $\mathcal{M}_u$. When $u$ moves to the $transmit$ state, it transmits $\mathcal{M}_u$. The algorithm terminates when every node in the network has received the message of every other node in the network.
