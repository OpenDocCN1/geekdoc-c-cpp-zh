## Lemma 18. Given any subset $R$ of $V$ such that $|R| \leq 2n/r$, there exists a block $P(2,k)$, $0 \leq k \leq r^2m(m-1)-1$ which contains at most $\lfloor |R|/4 \rfloor$ elements of $R$.

Proof. By Lemma 16, there exists a partition $P(1,k)$, $0 \leq k \leq rm-1$ which contains at most $\lfloor |R|/2 \rfloor \leq n/r$ elements of $R$. This level 1 block $P(1,k)$ is now subjected to level 2 partitioning and by similar arguments as in the proof of Lemma 16, we get a level 2 block of size $\lfloor |R|/4 \rfloor$ at most.

The partitioning process can now be generalized. We generate blocks of level $(i+1)$ partition from the blocks of level $i$ partition, $i \geq 1$, as follows. For each element $id \in P(i,k)$, we compute $j=\lfloor k/r\rfloor$ and $\alpha=id-d_j\times r^j$, where $d_{m-i-1}\cdots d_0$ is the $(m-i)$-digit radix-$r$ code of the element $id$. We then map $id$ to $id' = (\lfloor \alpha/r^{j+1}\rfloor)\times r^j + \alpha\ MOD\ r^j$, so that all the elements in $P(i,k)$ are now mapped to a set of integers $\{0,1,\cdots,r^{m-i}-1\}$ via a one-to-one and onto mapping. These $id'$ values, corresponding to the elements of $P(i,k)$, are used to re-code the elements of $P(i,k)$ into $(m-i-1)$-digit radix-$r$ numbers to generate the blocks of level $(i+1)$ partition. This successive partitioning scheme is illustrated by a partition tree as in Figure 5.1 for $r=4$ and $n=64$ where $V$ is the root (assumed to be at level $i=0$) with blocks $P(1,k)$ as its children, and at every successive level $i$, $P(i,k')$ is a child of $P(i-1,k)$, $1<i\leq m$, iff $P(i,k')$ is obtained from the block $P(i-1,k)$ by the above process. At level $i$, we get the blocks $P(i,k)$, $0\leq k\leq r^i\times m(m-1)(m-2)\cdots(m-i+1)-1$ corresponding to level $i$ partitioning. As before, blocks $P(i+1,k')$ obtained from $P(i,k)$, $i\geq 1$, are numbered with $k'$ from $r(m-i)k$ to $r(m-i)(k+1)-1$.

The partitioning process is formalized by the find_partition procedure as given below, where we use a simple primitive procedure radix_code(value, q, r, D) in which value, q and r are integer inputs, and D is a q-dimensional output array of integers. The radix_code(value, q, r, D) procedure converts the integer value, (0 ≤ value ≤ r^q − 1 to a q-digit radix-r number and stores the digits in locations D(0) through D(q) (from least significant to most significant digit).

```
procedure find_partition(value, i, h, offset, Flag);
begin;
radix_code(value, m - i + 1, r, D);
for j = 0 to m - i do
  temp \(\leftarrow\) r × (j - 1) + D(j);
  set Flag(i, offset + temp) ← 1;
  if i ≤ h - 1 then
    value ← value − D(j) × r^j;
    value ← (valueDIVr^(j+1)) × r^j + valueMODr^j;
    offset ← r × (m - i) × temp;
    find_partition(value, i + 1, h, offset, Flag);
  end if
end for
end procedure;
```

Lemma 19. Given an arbitrary subset R of V such that |R| ≤ n × (2/r)^i for some i, i ≥ 0, there exists a block P(i + 1, k) at level (i + 1) partitioning, that contains at most ⌊|R|/2^(i+1)⌋ elements of R.

Proof. Since |R| ≤ n/(r/2)^i, ∀i ≥ 0, we can apply level 1 partitioning on elements of R to get at least one block, say R_s, of size (n/2)/(r/2)^i at most. If i ≥ 1, then (n/2)/(r/2)^i ≤ n/r, (for r ≥ 2) and hence we can apply level 2 partitioning on block R_s. We use induction on j, 1 ≤ j ≤ i + 1 to show that it is possible to successively apply level 1 through level (i + 1) partitioning on the smallest block at each step. The induction hypothesis is true for j = 1 and j = 2. Assume that it holds up to level j partitioning. Hence, after level j partitioning, (j < i + 1), we

# **Theorem 16.** Given any arbitrary subset $R$ of $V$, $2^h \leq |R| \leq 2^{h+1}-1$, $h \geq 0$ and $n \geq r^h(2^{h+1}-1)/2^h$, there exists at least one block of level $j$ partitioning, $j \leq h$, which contains only one element of $R$.

*Proof.* It follows from the previous discussions that every time we apply the partitioning scheme corresponding to a specific level on a given set of elements, there will be at least one block with no more than half the number of elements in the given set. If $2^h \leq |R| \leq 2^{h+1}-1$, it follows that $h$ levels of partitioning are sufficient. From Lemma 19, we see that for $h$ successive levels of partitioning to be applied to the smallest block derived from the previous partitioning step, $|R| \leq 2^h n/r^h$, i.e., $2^{h+1}-1 \leq 2^h n/r^h$. Hence the theorem.

# **Example 23.**

Let $R = \{0, 1, 2, 4, 5, 6, 16, 17, 18, 20, 22, 32, 33, 34, 36\}$ with $n = 64$ and $r = 4$. Since there are 15 elements in $R$, $h = 3$ for this example. Applying level 1 partitioning, the partition blocks derived from $R$ are $(0, 4, 16, 20, 32, 36)$, $(1, 5, 17, 33)$, $(2, 6, 18, 22, 34)$; $(0, 1, 2, 16, 17, 18, 32, 33, 34)$, $(4, 5, 6, 20, 22, 36)$; $(0, 1, 2, 4, 5, 6)$, $(16, 17, 18, 20, 22)$, $(32, 33, 34, 36)$. The smallest cardinality of all these blocks is 4. Consider a smallest block, say $(32, 33, 34, 36)$. The elements in this block will first be mapped as $32 \to 0$, $33 \to 1$, $34 \to 2$, and $36 \to 4$. Then these will be recoded in radix-4 as $32:(00)$, $33:(01)$, $34:(02)$, $36:(10)$. Level 2 partitioning then generates the following blocks from $(32, 33, 34, 36)$: $(32, 36)$, $(33)$, $(34)$; $(32, 33, 34)$, $(36)$. Thus, another level of partitioning is not even necessary to generate a singleton block from $R$.

# ### 5.3 Transmission Schedule

We use the successive partitioning scheme developed in the previous section to design the transmission schedule of an arbitrary node in an ad hoc network. Consider a node with identification number *my_id*; the node knows only its own identification number *n* (total number of nodes in the network) and Δ, the maximum node degree of the network. Given Δ, we compute *h* such that 2^h ≤ Δ < 2^(h + 1). The node then computes the blocks up to the level *h* partitioning, P(*h*, *k*), 0 ≤ *k* ≤ r^h · m!/(m−h)! − 1. The details of the pseudo-code for the protocol to be used at each node to compute its own transmission slot or round are given in the algorithm below. The *find_my_slots* and *compute_slot* procedures needed for this purpose are also given below.

```
/* code to be executed by each node having my_id as identifier */

h = ⌊log₂ Δ⌋;
max_slot_number ← r^h × m × (m − 1) × ··· × (m − h + 1) − 1;
find_my_slots(my_id, n, Δ);
for phase_number = 1 to D − 1 do
    for i = 0 to max_slot_number do
        if T(i) = 1 then
            transmit the message;
        end if
    end for
end for
```

```
procedure find_my_slots(my_id, n, Δ);
begin;
    h = ⌊log₂ Δ⌋;
    offset ← 0;
    Flag ← 0;
    T ← 0;
    find_partition(my_id, 1, h, offset, Flag);
    compute_slot(Flag, h, T);
end procedure;
```

```
procedure compute_slot(Flag, h, T);  
begin;  
for \(k = 0\) to \([r^h \times m \times (m - 1) \times \cdots \times (m - h + 1)] - 1\) do  
&nbsp;&nbsp;if \(Flag(h,k) = 1\) then  
&nbsp;&nbsp;&nbsp;&nbsp;\(T(k) \leftarrow 1\);  
&nbsp;&nbsp;end if  
end for  
end procedure
```

Note that \(Flag[\ ]\) is a two dimensional array and \(T[\ ]\) is a one-dimensional array; \(Flag(i,j)\) is set to 1 iff \(my\_id\) value of a node belongs to the block \(P(i,j)\), and \(T(k)\) is set to 1 iff \(Flag(h,k)\) is set to 1. \(Flag\) and \(T\) are both initialized to all zero values. Thus, in phase \(i\), the node with identification \(my\_id\) will transmit during a time slot or round \(k\) iff \(Flag(i,my\_id) = 1\). The variable offset is used for properly numbering the partition blocks at any level.
