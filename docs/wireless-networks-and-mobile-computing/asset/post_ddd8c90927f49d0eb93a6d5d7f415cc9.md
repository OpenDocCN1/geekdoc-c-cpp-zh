
Note that $\log(FCR)=n(0.75\log\alpha+0.25\log\beta)$, from which we can easily evaluate $FCR$. Next we obtain the frame error rate ($FER$) for the RBNS message as $FER_{rbns}=1-FCR$.

Let us consider the situation that we transmit the original binary message of $n$ bits using non-coherent FSK with a BER of $\rho$. The probability that the whole frame will be received correctly is $(1-\rho)^n$. Thus, the FER for binary FSK will be given by $FER_{bfsk}=1-(1-\rho)^n$, which may be approximated as $n\rho$, since $\rho$ is usually very small. For a given frame size $n$, we can compare $FER_{rbns}$ with $FER_{bfsk}(=n\rho)$, or in other words, $FER_{rbns}/n$ with $\rho$. To compute $FER_{rbns}/n$, we set $s_A=1$, i.e., signal power $=s_A^2/2=1/2$ and a signal-to-noise ratio (SNR) $=1/2\sigma^2$. The computations to find the optimum threshold voltage $e_{th}$ that gives the minimum $FER_{rbns}/n$ for a given SNR were implemented in $MATLAB^\circledR$. Note that from Equation(8.13), we get the required peak transmitter power with RBNSiZeComm for a given value of $FER_{rbns}$.

The SNR values for binary FSK modulation are determined from the relation, $\rho=\frac{1}{2}e^{-\gamma/2}$ where SNR in dB $=10\log_{10}\gamma$. For different values of frame size in the range $8\le n\le1024$, the SNR values of the hybrid modulation scheme with RBNS message and the corresponding SNR values for binary FSK to meet the same $FER$ values are summarized in Table 8.4. We see that for the same $FER$, the required SNR values with RBNSiZeComm are on an average 2.76 dB higher than those with binary non-coherent FSK. However, in the RBNSiZeComm scheme, the transmitter will be in the transmit state only during the non-zero symbols (1 or $\bar{1}$), and in the idle state during the 0’s in the RBNS encoded message. Hence, the required average transmitter power for a given $FER$ will be less than the value demanded by Equation(8.13). We first consider the transmission length duration. The transmission time in CtS is exponential in the number of bits to be sent. VarBaTaC uses a variable coding base and controls the communication time by suitably tuning the base value. Suppose, without any loss of generality, we want to transmit a value _M_, where \(0 \leq M < 2^k$, _k_ \(\geq\) 0. Let _t_avg be the average number of time slots required in the VarBaTaC scheme. We need to transmit _m_ + 1 pulses for the _m_ digits to be transmitted. In addition, we need on average, \(\frac{m(r-1)}{2}\) time slots for the digits (assuming equal likelihood for all possible values of the message). Hence, _t_avg is given by

\( t_{avg} = (m+1) + \frac{m(r-1)}{2} = \frac{m(r+1)}{2} + 1.\) (8.14)

Thus, for a given _k_, _t_avg_ monontonically increases with _p_ due to the function \(\frac{2^p+1}{p}\) .
