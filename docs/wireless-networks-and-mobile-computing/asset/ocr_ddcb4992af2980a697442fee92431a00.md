the initial placement of the points in $P$ was chosen as follows: compute $m = \lceil\sqrt{k}\rceil$.

If $m^2 = k$, we split the region into $m \times m$ cells, and in each cell placed a point of $P$ randomly. If $(k - m^2) < m$, we split the region into $m$ rows of equal width, then arbitrarily chose $(k - m^2)$ rows and split each of these rows into $(m + 1)$ cells; the other rows were split into $m$ cells. We then placed one point in each cell. If $(k - m^2) > m$, we split the square region into $(m + 1)$ rows, and each row was split into $m$ or $(m + 1)$ rows to accommodate all the points in $P$.

For each $k$, authors in [8] considered 1000 initial instances. For each instance, they computed the value of $\rho$ by executing the above iterative algorithm. Finally, they reported the value of $\rho^*_{opt}$ = minimum value of $\rho$ over all 1000 instances.
