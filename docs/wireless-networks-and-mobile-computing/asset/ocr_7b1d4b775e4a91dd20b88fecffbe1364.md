# 9.2.3 Message Encryption

To guard against eavesdropping or man-in-the-middle attack, it is necessary that the source node properly encrypts its message *m* which can be decrypted only by its intended recipient. Thus, the message cannot be known by an external attacker or an intermediate internal node. As a consequence, this message cannot be changed by the attacker. There are two different types of encryption algorithms. The first is based on a **symmetric key encryption** in which every pair of sender and receiver nodes share a common key which is kept secret from all other nodes. The example is the **Data Encryption Standard (DES)** adopted by the National Institute of Standards and Technology (NIST) in the U.S. and largely used for civilian applications. However, in 2001, DES was considered insecure for many applications as it used key values only 56 bits long which can be exhaustively searched with available computing resources. DES was replaced by the **Advanced Encryption Standard (AES)** which works on blocks of 128 bits and key lengths of 128 bits to 256 bits.

The main problem with the symmetric key encryption is key management. If there are *n* nodes in the network, the number of possible communicating pairs will be *n(n − 1)/2*, and thus we need *O(n²)* secret keys. Managing such a large number of secret keys, one for each pair of communicating nodes, is a problem in practice when the security of communication channel is questionable.

The other type of encryption algorithm is based on **asymmetric key encryption** which started with a ground-breaking idea of Diffie and Hellman in 1976. They proposed the notion of public key cryptography involving two different keys, one *public key* known to all and the other a *private key* known only to the recipient of a message. Anyone can use the public key to encrypt a message, but someone who has the private key can only decrypt the message. Thus, effectively, for all *n* nodes, we need to manage only *n* secret keys, far better than the *O(n²)* secret keys required for symmetric key encryption.
