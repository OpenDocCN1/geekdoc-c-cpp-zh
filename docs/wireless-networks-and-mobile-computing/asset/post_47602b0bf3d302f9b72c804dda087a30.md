Since any node in layer 2 will have at most \(\Delta\) neighbors in layer 1, it follows that after the completion of phase 1 transmissions, all nodes in layer 2 will receive the message. This process continues for the successive layers so that at the beginning of phase \(i\), \(i \ge 2\), all nodes in layer \(i\) have received the message successfully and are ready to transmit the message during phase \(i\) at their respective time slots. By Theorem 17, it follows that all nodes in layer \(i+1\) will receive the message at the end of phase \(i\). Thus, at the end of phase \(\mathcal{D}-1\), all nodes of the layer \(\mathcal{D}\) of the network will receive the message and the broadcast is complete. Hence, we have the following result.

**Theorem 18.** *The broadcast process completes in \((\mathcal{D}-1)\) phases consisting of a total of \((\mathcal{D}-1)\times\tau\) rounds (where \(\tau=r^h\frac{m!}{(m-h)!}\)), or in \(O(\mathcal{D}r^h\log_r^h n)\) time.*

**Remark 18.** *In light of the \(\Omega(\mathcal{D}\log n)\) lower bound [5] for a deterministic distributed broadcast protocol in mobile multi-hop networks, the bound given in Theorem 18 is tight when \(h=1\), i.e., for networks with \(\Delta=3\).*

**Theorem 19.** *The above broadcast protocol is resilient to node mobility as long as the network is not disconnected and at least one node from a conflicting set always remains in the hearing range of any neighboring uncovered node.*

*Proof.* By assumption, when the nodes are mobile, the network never gets disconnected, and at least one node from a conflicting set always remains in the hearing range of any neighboring uncovered node. Now, consider the situation after phase \(i\), \(i\ge 1\). At this stage, because of the layer-by-layer broadcast, the nodes in the conflicting sets constitute the last layer of nodes that have received the message. The neighboring uncovered nodes of each conflicting set will be members of the next layer of nodes. Hence the claim.

## 5.4 Slot Assignment Based on Location Information

We now introduce another strategy for assigning time slots to the nodes in an ad hoc network based on the location information of the individual nodes. The technique in [6] significantly improves slot utilization by an elegant technique of *re-using* the time slots by sufficiently distant nodes, avoiding collisions during transmission. The basic idea is that if the number of nodes in an ad hoc network is very large and spread over a large geographical region and we follow the technique of determining the transmission schedule as discussed in the preceding section, the number of transmission cycles needed for a successful broadcast of a message may be very large. Instead, we can first partition the deployment zone into regular hexagonal cells similar to the cellular networks with the assumption that *a given node in some cell i may hear from the nodes which lie in the same cell or any other cell j which is at Distance 1 from cell i (i.e., adjacent to cell i), but not beyond that.* Thus the nodes in some cell i cannot hear anything from any node in some cell at Distance 2 from cell i. Note that with this assumption, a node p lying in some cell i may be in the *hearing zones* of two nodes q and r lying in cells j and k, respectively, where j and k are both adjacent (intercell distance is equal to one) to the cell i, but they are Distance 2 apart from each other. Under such a situation, it is likely that nodes q and r are both trying to send messages to node p in the same transmission cycle, causing collision at node p. To avoid this situation while allowing a time slot used by a node in some cell to be re-used by some other node in some other cell, we put the restriction that *a time slot used by the nodes in some cell i may be re-used only by the nodes in other cells which are at least Distance 3 away from cell i.* Thus, basically, we define an *interference zone* of the nodes in a cell *i* as the region which spreads over only cells within Distance 2 from cell *i*. Note that although the hearing zone of a given cell *i* in our assumption extends up to cells at Distance 1 from cell *i*, the interference zone of cell *i* extends up to cells at Distance 2 from cell *i*. Hence, for scheduling the transmission slots, at a time we need to consider *only* the nodes lying in a cell and all other cells within Distance 2 from it, but not the entire set of nodes in the whole ad hoc network. This may result in using a much smaller number of communication slots for effecting broadcast, as discussed below.

Using the location information of the nodes, the number of active nodes and the actual *demand* of each cell at that instant of time are computed. We use this cell demand information to assign time slots to each mobile node by a clever *re-use* of the time slots by cells lying farther than Distance 2 as explained above, by exploiting the hexagonal symmetry of the imposed cellular structure and avoiding interference among the nodes. The technique described below ensures an *optimal collision-free assignment* for every node of the network in \(O(m)\) time, \(m\) being the number of nodes in the network. This problem of finding an *optimal* time slot assignment schedule for the ad hoc network is called the *slot assignment problem* (SAP). The slot assignment algorithm presented here supersedes the existing algorithms [3, 7] with respect to optimality, and requires \(O(\log\log m + mD + n)\) time to determine an optimal, collision-free slot assignment schedule for the entire network where \(n\) is the number of cells in the overlaid cellular graph and \(D\) is the diameter of the ad hoc network.
