## 8.4 Ternary with Silent Symbol (TSS) Communication Protocol

We now describe another energy-efficient communication protocol called _ternary with silent symbol (TSS)_ [3, 4] which is based on a source coding scheme using the ternary number system, along with silent communication. Of the three symbols 0, 1 and 2 in the encoded message, one symbol (say 0) is made silent while the other two (say 1 and 2) are transmitted using a hybrid modulation scheme. In a noiseless channel there will be energy savings of 33% in the transmitter due to the non-transmission of carrier during the periods of 0. However, in a channel with additive white Gaussian noise (AWGN) and a receiver based on non-coherent detection, the amount of transmitter energy savings is expected to be less than this value as the peak signal power needs to be increased in the presence of the noise to distinguish the silent symbol from the no-signal situation of the channel.

### 8.4.1 Basic Idea and Algorithm Descriptions

Let a given binary message B be represented by an n-bit binary string b_{n-1} b_{n-2} ... b_2 b_1 b_0. Let T be its equivalent m-digit ternary representation given by T = t_{m-1} t_{m-2} ... t_2 t_1 t_0. We assume that n is even, otherwise we pad the message with a 0 bit at leftmost, i.e., most significant bit (msb) position. For conversion from binary to ternary, we successively scan every two bits of the binary message starting from its msb position and then convert the leftmost part of the binary message (starting from its msb to the currently scanned bit position) to its equivalent ternary representation. To do this, we replace the currently scanned two bits (bit pair) by a single ternary digit (0, 1 or 2 depending on whether the binary bit pair is 00, 01 or 10), or by two ternary digits (10)3 (if the binary bit pair is 11), and add it to four times the obtained ternary number T from all the previous bit positions (on the left of this bit pair). Note that this addition will be in the ternary number system, and the multiplying factor four is to adjust the weight of T with respect to the currently scanned bit pair. Also, since this addition will be in the ternary number system, the weight of four can be assigned to T by adding the two ternary numbers T0 and 0T. Thus, the equivalent ternary representation of the part of the binary message from its msb to the currently scanned bit pair will then be obtained as T0 ⊕ 0T ⊕ x, where ⊕ represents a ternary addition operator and x is the ternary number equal to 0, 1, or 2 (when the scanned bit pair is 00, 01 or 10, respectively), or equal to (10)3 (when the scanned bit pair is 11).

**Example 33.** Consider the binary number 10011100. First, we get T = 2 from the leftmost two bits 10. Then, for the next two bits, the equivalent ternary digit is 1. We add (in ternary) the three numbers (20)3, (02)3 and (1)3 to get the changed value of T = (100)3 (which is equal to 9 in decimal corresponding to the binary digits 1001 scanned so far). For the next two bits, we get the equivalent ternary representation as (10)3, which is added to (1000)3 (= T0) and (0100)3 (= 0T) in ternary to get the changed value of T = (1110)3 = (39)10. Finally, for the bit pair 00, we add (11100)3 to (01110)3 to get the equivalent ternary number as (12210)3 = (156)10.

The _Binary2Ternary_ algorithm outlines the steps required to convert a number from binary to ternary.

- 1: **procedure** BINARY2TERNARY(IN bit vector B, integer n, OUT ternary number T)
- 2: /* Initialization */
- 3: **if** b_{n-1} b_{n-2} = 00 **then**
- 4: T <- 0;
- 5: **end if**
- 6: **if** b_{n-1} b_{n-2} = 01 **then**
- 7: T <- 1;

In a similar manner, we can reconvert the received m-digit ternary message to its equivalent binary form by using the _Ternary2Binary_ algorithm, and again we scan the given ternary number from its most significant (leftmost) position in a digit-by-digit manner, and convert the scanned ternary digits to their equivalent binary representation. In the algorithm, we denote a ternary digit by t_i and the converted binary number by B. As in the _Binary2Ternary_ algorithm, we need to adjust the weight of the binary representation of the previously scanned ternary digits by attaching a weight of three with respect to the currently scanned ternary digit, and this is achieved by adding B0, 0B and the equivalent binary representation of the currently scanned ternary digit (note that this time it is a binary addition).

**Example 34.** Let the given ternary number T = 2102. The leftmost digit is 2, whose binary representation is 10. We initially form the binary number as B = 10. The next ternary digit is 1. We add the three binary numbers 100 (= B0), 010 (= 0B) and 1 to get the changed value of B = 111. The next scanned ternary digit is 0 and we add 1110 to 0111 to get the changed value of B as 10101. Finally, for the rightmost ternary digit 2, we add 101010, 010101 and 10 to get 1000001 as the equivalent binary representation B of the given ternary number T.

- 1: **procedure** TERNARY2BINARY(IN ternary number T, integer m, OUT binary number B)
- 2: /* Initialization */
- 3: **if** t_{m-1} = 0 **then**
- 4: B <- 00;
- 5: **end if**
- 6: **if** t_{m-1} = 1 **then**
- 7: B <- 01;
- 8: **end if**
- 9: **if** t_{m-1} = 2 **then**
- 10: B <- 10;
- 11: **end if**
- 12: **for** i = m-2 **to** 0 **step** -1 **do**
- 13: **if** t_i = 0 **then**
- 14: B <- B0 + 0B; // this is a binary addition
- 15: **end if**
- 16: **if** t_i = 1 **then**
- 17: B <- B0 + 0B + 1; // binary addition
- 18: **end if**
- 19: **if** t_i = 2 **then**
- 20: B <- B0 + 0B + 10; // binary addition
- 21: **end if**
- 22: **end for**
- 23: **end procedure**

Binary to ternary conversion of data provides the advantage of reduction in the total number of symbols to be transmitted and reduces total transmission duration. As both the transmitter and the receiver consume energy proportional to the duration for which they are switched on, regardless of the symbol transmitted, recoding to a higher radix will lead to a savings in energy at both the transmitter and the receiver. Additional energy savings can be obtained at the transmitter by adopting the silent symbol strategy as explained in the preceding sections for one of the three possible ternary digits. The ternary with silent symbol (TSS) combines these two strategies to derive an energy-efficient communication scheme that saves energy at both the transmitter and the receiver. Assuming equal likelihood of all the three symbols, we assume 0 to be the silent symbol. In practice, however, the relative frequencies of the three symbols will depend on the nature of the data to be transmitted. A better strategy would be to assign the most frequent symbol as the silent symbol based on the relative frequencies of the symbols, determined statistically or assigned for each message to be transmitted.
