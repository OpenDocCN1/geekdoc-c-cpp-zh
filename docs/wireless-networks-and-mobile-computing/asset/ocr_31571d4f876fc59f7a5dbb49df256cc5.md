Note that for both approaches, the MAC layer protocol must provide the support for communicating to the receiver the information regarding the BpS mapping. For Scheme 1, the mapping needs to be transmitted once at the beginning of transmission of a set of data frames; for Scheme 2 the mapping needs to be transmitted with each frame.

Based on the above discussions, the transmitter and receiver side operations for an energy-efficient communication scheme are presented below as CNSTransmit and CNSReceive, respectively.

For the CNSTransmit procedure, data_frame refers to the binary string of length frame_len that needs to be transmitted. The transmitter first determines the BpS mapping of symbols, using either Scheme 1 or Scheme 2 described above. For Scheme 2, the BpS mapping needs to be transmitted for every frame, while for Scheme 1, transmitting just once for an entire session is sufficient. Using this mapping, the transmitter then interprets every bit pair, starting from the lsb and transmits the corresponding symbol sym.

On the other side, the receiver first receives the BpS mapping of the symbols from the transmitter, once for the entire session for Scheme 1 or with every frame for Scheme 2. Then, it uses this mapping for each received symbol from the transmitter to determine whether the transmitted symbol corresponds to the bit pair 00, 01, 10 or 11.
