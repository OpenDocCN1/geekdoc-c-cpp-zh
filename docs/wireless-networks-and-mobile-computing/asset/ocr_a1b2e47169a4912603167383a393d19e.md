Consider now any one of the blocks P(1, k), \( 0 \leq k \leq rm - 1 \) where each element (integer) has a unique radix-r code using (m - 1) digits \( d'_{m-2} d'_{m-3} \cdots d'_1 d'_0 \) obtained through the above process. We apply the partitioning process on each of these blocks using the digits similar to the level-1 partitioning we applied on the entire set V. We call this as level 2 partitioning.

**Definition 5.** _If we partition the elements of_ \( P(1, i), 0 \leq i \leq rm - 1 \) _into r blocks in_ (m - 1) _different ways, each induced by a digit of the new_ (m - 1)_-digit code, the new blocks are called the blocks of level 2 partitioning. If a level 2 partitioning block is obtained from_ \( P(1, i) \) _induced by its j<sup>th</sup> digit code_ \( d'_j, 0 \leq j \leq m - 2 \) _such that_ \( d'_j = \beta, 0 \leq \beta \leq r - 1 \)_, we denote this block as_ \( P(2, k) \) _where_ \( k = r \times (m - 1) \times i + r \times j + \beta \)_._

**Example 22.** _Consider the previous example again. We have_ \( r(m - 1) = 8 \)_._ Hence, the blocks from level 2 partitioning are given as _P_(2, 56) = (12, 28, 44, 60), _P_(2, 57) = (13, 29, 45, 61), _P_(2, 58) = (14, 30, 46, 62), _P_(2, 59) = (15, 31, 47, 63), _P_(2, 60) = (12, 13, 14, 15), _P_(2, 61) = (28, 29, 30, 31), _P_(2, 62) = (44, 45, 46, 47), _P_(2, 63) = (60, 61, 62, 63).

**Remark 15.** _Each block P_(1, k) _of level 1 partitioning generates_ \( r(m - 1) \) _blocks of level 2 partitioning. The total number of blocks in level 2 partitioning is given by_ \( r^2 m(m - 1) \)_._
