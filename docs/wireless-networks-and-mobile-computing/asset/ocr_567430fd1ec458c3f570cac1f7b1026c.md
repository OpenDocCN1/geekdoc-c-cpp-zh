The second stage of handoff management, new connection generation, may be performed in three different ways. In case of network-controlled handoff (NCHO) or mobile-assisted handoff (MAHO), the network generates a new connection and finds the resources and the additional routing operations. In mobile-controlled handoff (MCHO), the MT finds the new resources and the network approves them. The third stage, i.e., data flow control, involves the delivery of data from the old connection path to the new connection path according to the agreed-upon services to be provided to the MT. In Chapter 2, we address handoff management in somewhat more detail.

# 1.3.1.3  Internetworking and Interoperability

There are different backbone networks which can support cellular mobile communication. Examples of such backbone networks include public land mobile networks (PLMNs), mobile IP networks, wireless asynchronous transfer mode (WATM) networks, low earth orbit (LEO) satellite networks, and so on. Each such backbone network has its own kind of signal propagation techniques and communication protocols to provide services to cellular mobile users. While roaming, it is quite possible that an MT moves from one place to another where the supporting backbone network is changed. The future generation mobile communication system aims at global roaming capability for mobile users. In order to implement this idea, the associated problem of internetworking must be properly addressed. The mobile devices need to be equipped with the appropriate hardware (physical layer and MAC layer issues) and software (network layer issues) to operate in different backbone networks during roaming. Also, this switching from one backbone network to another should be smooth and transparent to the users without disrupting the ongoing calls of the moving MTs.
