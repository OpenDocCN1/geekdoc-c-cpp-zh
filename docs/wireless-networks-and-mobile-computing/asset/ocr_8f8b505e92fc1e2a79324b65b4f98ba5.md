# 5.5.3.2 Algorithm bf_gossip

We describe in this section the modifications required to *bf_broadcast* to convert it to the algorithm *bf_gossip*. First, a node \(i\) gathers the clean messages received by all its neighbors by executing the procedure *gather_messages*.

Next, for a node in state *transmit*, Step 4.4 of algorithm *bf_broadcast* is modified as follows:

**Step 4.4:** If an ack was received only in slot \(S\) but not in \(C\) and \(N\), execute procedure *gather_messages* and change the state back to *active*. Increment *round_count* by 1 and return to Step 3 for the next round.

Also, if the state of a node is *receive*, Step 5.2 for the case when a clean signal is received in the *message* slot will now be as follows:

**Step 5.2:** If a clean signal is received in *message* slot, send an acknowledgment in \(S\) slot, and change the state of the node to *back transmit*. Increment *round_count* by 1 and go back to Step 3 for the next round.

Further, if the state of a node is *collision*, Step 6.4 will be changed as follows:

**Step 6.4:** If a clean signal is received in *message* slot, send an acknowledgment in \(S\) slot, and change the state of the node to *back transmit*. Increment *round_count* by 1 and go back to Step 3 for the next round.

Finally, a procedure *back_transmit_actions* is needed which will perform the actions corresponding to the *back transmit* state.
