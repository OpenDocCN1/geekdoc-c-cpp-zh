
23, 46, 92, 185, 369, 738 and 1475, respectively. The ratio \(\frac{n}{m}\) asymptotically tends to 1.44. This shows that the number of bits in FNS representation is 1.44 times higher than that of the original binary representation. Such an increase in the length of the code may not be desirable in many engineering applications.

## 8.6.2 Tri-digit Fibonacci Number System

To overcome the problem of increase in the length of a codeword in FNS, we describe a number system [40] in which i) the digits at each position will be taken from the set \(\{0,1,2\}\), and ii) the positional weight at the \(i^{th}\) (\(i \geq 0\)) digit position (\(i=0\) corresponds to the least significant digit position) is equal to \(F_{2i+2}\). That is, the positional weights at different digit positions are \(F_2,F_4,F_6,\ldots\), with \(F_2\) as the weight of the least significant digit. We term this number system as the *tri-digit Fibonacci number system* (TFNS) [40]. The weights at different digit positions are alternate numbers in the Fibonacci sequence. Given a decimal number \(N < F_{2k+2}\) for some \(k\), we can represent \(N\) in its equivalent TFNS form using \(k\) digits \(d_0,d_1,d_2,\ldots,d_{k-1}\) by the decimal-to-TFNS conversion algorithm *DTFNS* as given below.

```text
**Input:** Decimal number \(N\), integer \(k\) such that \(N < F_{2k+2}\)
**Output:** Equivalent TFNS form for \(N\)

1. **for** \(i = k - 1\) **downto** 0 **do**
2.     **if** \(N \geq 2F_{2i+2}\) **then**
3.         \(d_i \leftarrow 2\)
4.         \(N \leftarrow N - 2F_{2i+2}\)
5.     **else if** \(N \geq F_{2i+2}\) **then**
6.         \(d_i \leftarrow 1\)
7.         \(N \leftarrow N - F_{2i+2}\)
8.     **else**
9.         \(d_i \leftarrow 0\)
10.    **end if**
11. **end for**
```

Following the *DTFNS* conversion algorithm, the representations of all decimal numbers in the range 0 to 12 (both inclusive) using four digits in TFNS are shown in Table 8.20. Note that the decimal number 8 is *uniquely* represented as 0100 in TFNS using the above conversion algorithm. Although another possible representation of the decimal number 8 in TFNS with the above positional weights could be 0022; this representation cannot be obtained by the algorithm *DTFNS* because of the *if* statement in line 3 which, in effect, forces the number to be represented by using non-zero digits at the highest possible digit positions whenever possible.

**Lemma 31.** Let \(N\) be a decimal number whose representation in *TFNS* is \(2111\cdots 1\) having \((k-1)\) 1’s following a 2. The decimal number \(N+1\) will be represented by \(1000\cdots 0\), with \(k\) 0’s after the 1.

**Proof:** From the TFNS representation of \(N\), it follows that:

\[
N = 2F_{2k} + F_{2k-2} + F_{2k-4} + \cdots + F_4 + F_2
\]

\[
\Rightarrow N + 1 = 2F_{2k} + F_{2k-2} + F_{2k-4} + \cdots + F_4 + F_2 + 1
\]

\[
= 2F_{2k} + F_{2k-2} + F_{2k-4} + \cdots + F_4 + F_2 + F_1
\]

\[
= 2F_{2k} + F_{2k-2} + F_{2k-4} + \cdots + F_6 + F_4 + F_3
\]

\[
= 2F_{2k} + F_{2k-2} + F_{2k-4} + \cdots + F_8 + F_6 + F_5 + \cdots
\]

\[
= 2F_{2k} + F_{2k-1}
\]

\[
= F_{2k} + F_{2k+1}
\]

\[
= F_{2k+2}.
\]

By virtue of the conversion algorithm *DTFNS*, \(N+1\) will thus be represented as \(1000\cdots 0\) in TFNS, with \(k\) 0’s after the 1.

Because of Lemma 31 it follows that if we consider \(n\)-digit representation of numbers in TFNS, not all possible \(3^n\) code values will be generated by the *DTFNS* algorithm. To be more precise, whenever we come across some number \(N\) with the lowermost \(k\) digits in its TFNS representation as \(2111\ldots 1\), the next consecutive number \(N+1\) will have its lowermost \(k+1\) digits in TFNS as \(1000\ldots 0\), thus eliminating many of the possible code values between them. The number system differs from the Zeckendorf number system in having the alternate Fibonacci numbers as positional weights. Such a choice of alternate Fibonacci numbers leads to a number representation using 0, 1 and 2 for any digit position. Moreover, Zeckendorf representation does not have two consecutive 1’s as we will see below; specifically there will not be two consecutive 2’s in the number representation stated in the following lemma.

**Lemma 32.** *TFNS representation of any given number may have consecutive 1’s but no consecutive 2’s.*

The proof follows as a corollary of Lemma 31.

Thus, unlike the Zeckendorf representation which does not allow consecutive 1’s in the representation, this number system allows two consecutive 1’s but no consecutive 2’s. The properties given in Lemma 31 and Lemma 32 lead to unequal distribution in the total numbers of 0’s, 1’s and 2’s in the TFNS coding of numbers for any given \(n\)-digit representation. A careful look at the digit generation process in the *DTFNS* algorithm would reveal the exact distribution of the numbers of 0’s, 1’s and 2’s in the TFNS code values. We follow this digit generation process (starting from the most significant digit position) for all possible codes with \(n\) digits (to represent numbers in the range 0 to \(F_{2n+2} - 1\)) by constructing a weighted ternary tree \(T\) shown in Figure 8.24.

First, we start at the root of \(T\) and insert its three children nodes labeled 0, 1 and 2 (with three edges connected from the root to these three nodes), meaning that

![](img/6578f6fc95ac71d2c7109e594d9df12f_476_0.png)

the leftmost digit position of the code values can be filled by a 0, 1 or 2. Since a 0 at the leftmost digit position will appear for all the numbers having the decimal values ranging from 0 to \(F_{2n}\), the weight of the edge connecting the root to its child node labeled 0, will be set as \(F_{2n}\). This is also the case with the weight of the edge connecting the root to its child labeled 1. But the weight of the edge connecting the root to the child labeled 2 will be \(F_{2n+2}-2F_{2n}=F_{2n-1}\). We now derive expressions for the distribution of 0’s, 1’s and 2’s in TFNS.

### 8.6.2.1 Deriving TFNS Digit Distributions

From Figure 8.24, we see that the total number of 0’s in all the \(n\)-digit valid codewords representing all numbers in the range 0 to \(F_{2n+2}-1\) (both inclusive) is given by:

\[
\nu'_0=F_{2n}+3F_{2n-2}+8F_{2n-4}+\cdots=F_2F_{2n}+F_4F_{2n-2}+F_6F_{2n-4}+\cdots+F_{2n}F_2.
\]

Similarly, the total number of 1’s in all valid codewords is:

\[
\nu'_1=F_{2n}+(2F_{2n-2}+F_{2n-3})+\cdots=F_1F_{2n}+(F_3F_{2n-2}+F_2F_{2n-3})
\]

\[
\qquad +(F_5F_{2n-4}+F_4F_{2n-5})+\cdots +(F_{2n-1}F_2+F_{2n-2}F_1).
\]

The total number of 2’s in all the valid codewords is:

\[
\nu'_2=F_1F_{2n-1}+2F_{2n-3}+5F_{2n-5}+\cdots
\]

\[
\qquad =F_1F_{2n-1}+F_3F_{2n-3}+F_5F_{2n-5}+\cdots+F_{2n-1}F_1.
\]

To express \(\nu'_0\), \(\nu'_1\) and \(\nu'_2\) in closed form we proceed as follows.

Let

\[
G(z)=F_0+F_1z+F_2z^2+F_3z^3+F_4z^4+\cdots
\]

Thus, \(G(z)\) is given by \(G(z)=\frac{z}{1-z-z^2}\) as in [36]. Now,

\[
G(-z)=F_0-F_1z+F_2z^2-F_3z^3+F_4z^4+\cdots.
\]

Hence, we have:

\[
\frac{G(z)+G(-z)}{2}=F_0+F_2z^2+F_4z^4+F_6z^6+\cdots=H(z),\quad\text{(say).}
\]

That is,

\[
H(z)=\frac{z^2}{(1-z^2)^2-z^2}=\frac{z^2}{1-3z^2+z^4}
\]

\[
\qquad=\frac{z^2}{(1-\alpha z^2)(1-\beta z^2)},\quad\text{(say)}
\]

where \(\alpha\) and \(\beta\) are given by:

\[
\begin{cases}
\alpha+\beta=3\\
\alpha\beta=1.
\end{cases}
\tag{8.54}
\]

Hence, \(\alpha=\frac{3+\sqrt5}{2}=1+\phi\) and \(\beta=\frac{3-\sqrt5}{2}=1-\bar{\phi}\). Also, \(H^2(z)=(F_0+F_2z^2+F_4z^4+\cdots)^2\), in which the coefficient of \(z^{2n+2}\) is

\[
F_0F_{2n+2}+F_2F_{2n}+F_4F_{2n-2}+\cdots+F_{2n+2}F_0=\nu'_0.
\]

Hence,

\[
H(z)=\frac{z^2}{[1-(1+\phi)z^2][1-(1+\bar{\phi})z^2]}
\]

\[
\Rightarrow H^2(z)=\frac{z^4}{[1-(1+\phi)z^2]^2[1-(1+\bar{\phi})z^2]^2}.
\]

Let \((1+\phi)z^2=x\) and \((1-\bar{\phi})z^2=y\). Then, \(H^2(z)=\frac{z^4}{(1-x)^2(1-y)^2}\). The coefficient of \(z^{2n+2}\) in \(H^2(z)\)

\[
=\text{ the coefficient of }z^{2n-2}\text{ in }(1-x)^{-2}(1-y)^{-2}.
\]

\[
=\text{ the sum of the coefficients of }x^iy^j\text{ in }(1-x)^{-2}(1-y)^{-2}\text{ with }i+j=n-1.
\]

\[
=(1+\phi)^0\cdot1\cdot n(1-\bar{\phi})^{n-1}+2(1+\phi)(n-1)(1-\bar{\phi})^{n-2}
\]

\[
+3(1+\phi)^2(n-2)(1-\bar{\phi})^{n-3}+\cdots+n(1+\phi)^{n-1}\cdot1\cdot(1-\bar{\phi}).
\]

### 8.6.2.2 Computation of \(\nu'_0\)

Collecting the terms from the right side of the above expression and noting that \((1+\phi)(1-\bar{\phi})=1\), we get

\[
\nu'_0=n(1+\phi)^{n-1}+2(n-1)(1+\phi)^{n-3}+3(n-2)(1+\phi)^{n-5}+\cdots+n(1+\phi)^{1-n}.
\]

Replacing \((1+\phi)\) by \(\alpha\), we get

\[
\nu'_0=n\alpha^{n-1}+2(n-1)\alpha^{n-3}+3(n-2)\alpha^{n-5}+\cdots+n\alpha^{1-n}. \tag{8.55}
\]

\[
\frac{\nu'_0}{\alpha^2}=n\alpha^{n-3}+2(n-1)\alpha^{n-5}+\cdots+(n-1)\cdot2\alpha^{1-n}+n\alpha^{-n-1}. \tag{8.56}
\]

Subtracting Equation (8.56) from Equation (8.55) we get:

\[
\nu'_0\left(1-\frac{1}{\alpha^2}\right)=n\alpha^{n-1}+(n-2)\alpha^{n-3}+(n-4)\alpha^{n-5}
\]

\[
\quad +(n-6)\alpha^{n-7}+\cdots+[n-2(n-1)]\alpha^{1-n}-n\alpha^{-n-1}
\]

\[
\quad =n(\alpha^{n-1}+\alpha^{n-3}+\alpha^{n-5}+\cdots)-2(\alpha^{n-3}+2\alpha^{n-5}+3\alpha^{n-7}+\cdots)
\]
