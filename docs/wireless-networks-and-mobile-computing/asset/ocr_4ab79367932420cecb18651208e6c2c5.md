Each node $id \in V = \{0,1,2,\cdots,n-1\}$ is converted into an $m$-digit code in radix $r$ number system as $id=d_{m-1}d_{m-2}\cdots d_0$, where $0\le d_i\le r-1$ for all $i$, $0\le i\le m-1$. Consider the $d_i$ values of each node for a specific $i$; the set $V$ is partitioned into $r$ disjoint blocks $B_i(j)$, $0\le j\le r-1$, i.e., $d_i(id)=j\ \Longrightarrow\ id\in B_i(j)$. Since there are $m$ digits ($m$ different values of $i$), we get $m$ different partitions of $V$ each into $r$ different blocks, each partition induced by a digit of $id$. The total number of blocks generated by these partitions is thus equal to $rm$. A given $id$ value is a member of exactly $m$ of these $rm$ blocks.

**Definition 4.** The blocks $B_i(j)$, $0\le i\le m-1$, $0\le j\le r-1$ will be called the **blocks of level 1 partitioning** and will be denoted by $P(1,k)$, $k=0,1,\cdots,rm-1$, where $P(1,k)=B_i(j)$, if $k=ri+j$.

Note that $P(1,k)$, $0\le k\le rm-1$ of the above level 1 partitioning will have exactly $n/r$ elements (nodes).
