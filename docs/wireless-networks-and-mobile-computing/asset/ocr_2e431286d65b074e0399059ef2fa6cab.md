As in the _Binary2Ternary_ algorithm, we need to adjust the weight of the binary representation of the previously scanned ternary digits by attaching a weight of three with respect to the currently scanned ternary digit, and this is achieved by adding \( B0 \), \( 0B \) and the equivalent binary representation of the currently scanned ternary digit (note that this time it is a binary addition).

**Example 34.** _Let the given ternary number_ \( T = 2102 \). _The leftmost digit is 2 whose binary representation is_ 10_. We initially form the binary number as_ \( B = 10 \). _The next ternary digit is 1. We add the three binary numbers_ 100(_= B0_), 010(_= 0B_) _and_ 1 _to get the changed value of_ \( B = 111 \). _The next scanned ternary digit is 0 and we add_ 1110 _to_ 0111 _to get the changed value of_ \( B \) _as_ 10101_. Finally, for the rightmost ternary digit 2, we add_ 101010_,_ 010101 _and_ 10 _to get_ 1000001 _as the equivalent binary representation_ \( B \) _of the given ternary number_ \( T \)_._
