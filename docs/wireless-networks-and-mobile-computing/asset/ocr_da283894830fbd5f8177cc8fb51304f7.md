We can therefore express \( H'(z) \) as \( \frac{z}{2} \left[ \frac{C_1}{1 - \alpha z^2} + \frac{C_2}{1 - \beta z^2} \right] \), where \( C_1 = 1 + \frac{1}{\sqrt{5}} \) and

\( C_2 = 1 - \frac{1}{\sqrt{5}} \). Hence,

\( H'^2(z) = \frac{z^2}{4} \left[ \frac{C_1}{1 - \alpha z^2} + \frac{C_2}{1 - \beta z^2} \right]^2 = \frac{z^2}{4} \left[ C_1(1 - \alpha z^2)^{-1} + C_2(1 - \beta z^2)^{-1} \right]^2 = \frac{z^2}{4} [C_1^2(1 + 2\alpha z^2 + 3\alpha^2 z^4 + 4\alpha^3 z^6 + \dots) + C_2^2((1 + 2\beta z^2 + 3\beta^2 z^4 + 4\beta^3 z^6 + \dots) + 2C_1C_2(1 + \alpha z^2 + \alpha^2 z^4 + \alpha^3 z^6 + \dots)(1 + \beta z^2 + \beta^2 z^4 + \beta^3 z^6 + \dots)]. \)

Thus, \( \nu'_2 = \text{coefficient of } z^{2n} \text{ in } H'^2(z) \) and is given by the expression

\( \frac{1}{4} [C_1^2 n \alpha^{n-1} + C_2^2 n \beta^{n-1} + 2C_1C_2(\beta^{n-1} + \beta^{n-2}\alpha + \beta^{n-3}\alpha^3 + \alpha^{n-1})]. \)

Let \( S' = \beta^{n-1} + \beta^{n-2}\alpha + \beta^{n-3}\alpha^3 + \dots + \beta\alpha^{n-2} + \alpha^{n-1} \). Thus we get:

\( S'(1 - \frac{\beta}{\alpha}) = \alpha^{n-1} - \frac{\beta^n}{\alpha} \Rightarrow S' = \frac{\alpha^n - \beta^n}{\sqrt{5}}, \text{ since } \alpha - \beta = \sqrt{5}. \)
