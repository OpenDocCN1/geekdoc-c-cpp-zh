Whatever the value of the message to be transmitted in the range 0 to $M$ (both inclusive), we need to transmit $m+1$ pulses for the $m$ digits to be transmitted. In addition, we need on an average, $\frac{m(r-1)}{2}$ time slots for the digits (assuming equal likelihood for all possible values of the message). Hence, $t_{avg}$ is given by

$$t_{avg}=(m+1)+\frac{m(r-1)}{2}=\frac{m(r+1)}{2}+1. \tag{8.36}$$

Let $r=2^p$. Hence, $m=\left\lceil\frac{k}{p}\right\rceil$, and from Equation (8.36) we have

$$\frac{k}{p}\left(\frac{2^p+1}{2}\right)+1\leq t_{avg}<\left(\frac{k}{p}+1\right)\left(\frac{2^p+1}{2}\right)+1.$$

Thus, for a given $k$, $t_{avg}$ monotonically increases with $p$ due to the function $\frac{2^p+1}{p}$. Table 8.14 shows the values of $t_{avg}$ for different values of $r=2^p$, while Table 8.15 shows the variation of $t_{avg}$ with radix $r$, even when $r$ is not a power of 2.

As we can see from Tables 8.14 and 8.15, on average, CNS will require fewer time slots than VarBaTaC. In general, the transmission time of CNS will be less than that of CtS and VarBaTaC, while generating significant savings in energy at both the transmitter and the receiver. Note that neither CtS nor VarBaTaC generates energy savings at the receiver.
