Once we form the backbone network with the induced graph on a connected dominating set of the network graph, routing of messages can be done in the same technique used in the approach based on clustering, with cluster heads forming a backbone network. A message from any node (not included in the chosen connected dominating set) will be sent first to an adjacent node in the connected dominating set (CDS) and from there it will be routed to a node in the (CDS) adjacent to the destination node, following the shortest route along the backbone network.
