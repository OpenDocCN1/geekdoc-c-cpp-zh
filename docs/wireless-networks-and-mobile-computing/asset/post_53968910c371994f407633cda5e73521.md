> Is it possible to find some transmission schedule for a given node $u$ so that during all the rounds in a phase, there will be at least one round in which only one node belonging to the set $N(u)$ will be in transmit state?

The answer to the above question is “yes” by virtue of the results in [3, 2]. We describe below the protocol proposed in [2] and then compare its performance with that in [3]. To do this, we define a node as *covered* if it has already received the message, and *uncovered* if it is yet to receive the message. At any time instant, the sets of covered and uncovered neighbors of a node $i$ will be denoted by $N_c(i)$ and $N_u(i)$, respectively. A set $C$ of covered nodes will be called a **conflicting set** if there is at least one neighbor common to all the nodes in $C$ that has not yet received the message. By following the protocol in [2], the broadcast proceeds in a layer-by-layer fashion, i.e., all nodes at layer $\ell$, $1 \leq \ell \leq D - 1$, become informed of the message $m$ before any node at layer $\ell + 1$. Also, the transmission slots for every node will be independent of the identities of the current neighbors of the node, i.e., independent of the topology of the network. These transmission slots will also be independent of the mobility of the nodes subject to the conditions that the topology does not change during the broadcast of a single message and the network always remains connected, as assumed in the system model mentioned above.

## 5.2.2.3 Successive Partitioning Scheme

The transmission slots of a given node $i$ will be computed by using the successive partitioning scheme based on radix encoding of the node identifiers $(id)$ in the set $V$. To simplify our discussions, let us assume a radix $r$, $r \geq 2$ and $n = r^m$ for some integer $m$. Each node $id \in V = \{0,1,2,\cdots,n-1\}$ is converted into an $m$-digit code in radix $r$ number system as $id=d_{m-1}d_{m-2}\cdots d_0$, where $0\le d_i\le r-1$ for all $i$, $0\le i\le m-1$. Consider the $d_i$ values of each node for a specific $i$; the set $V$ is partitioned into $r$ disjoint blocks $B_i(j)$, $0\le j\le r-1$, i.e., $d_i(id)=j\ \Longrightarrow\ id\in B_i(j)$. Since there are $m$ digits ($m$ different values of $i$), we get $m$ different partitions of $V$ each into $r$ different blocks, each partition induced by a digit of $id$. The total number of blocks generated by these partitions is thus equal to $rm$. A given $id$ value is a member of exactly $m$ of these $rm$ blocks.

**Definition 4.** The blocks $B_i(j)$, $0\le i\le m-1$, $0\le j\le r-1$ will be called the **blocks of level 1 partitioning** and will be denoted by $P(1,k)$, $k=0,1,\cdots,rm-1$, where $P(1,k)=B_i(j)$, if $k=ri+j$.

Note that $P(1,k)$, $0\le k\le rm-1$ of the above level 1 partitioning will have exactly $n/r$ elements (nodes).

**Lemma 16.** *For an arbitrary subset $R$ of the set $V$, there exists at least one $P(1,k)$, $0\leq k\leq rm-1$, which contains at most $(\lfloor |R|/2\rfloor)$ elements of $R$.*

**Proof:** Consider the $m$-digit radix-$r$ codes of the elements in $R$. Since all these codes are distinct, there exists at least one digit position where there will be at least two different values $v_1$ and $v_2$, $0\leq v_1,v_2\leq r-1$, in all these codes in $R$. This means that the elements of $R$ will be placed in at least two different blocks of the partitions at level 1. One of these blocks must contain at most $(\lfloor |R|/2\rfloor)$ elements.

**Lemma 17.** *Each element in any arbitrary block $P(1,k)$, $0\leq k\leq rm-1$ of level 1 partitioning can be uniquely re-coded by using only $m-1$ digits in the radix-$r$ number system.*

**Proof:** Let $j=\lfloor k/r\rfloor$. It follows from the definition that the block $P(1,k)$ is induced by $j^{th}$ digit, $d_j$, $0\leq j\leq m-1$ of the radix-$r$ codes for the elements in $V$. Consider an element $id\in P(1,k)$. Let the $m$-digit code for $id$ be $d_{m-1}d_{m-2}\cdots d_{j+1}d_jd_{j-1}\cdots d_1d_0$. Since $\forall\ id\in P(1,k)$, the value of $d_j$ is the same, it does not play any role in distinguishing the elements in $P(1,k)$.

Thus, if we have a new $(m-1)$-digit code for each $id$ in $P(1,k)$ given by $d_{m-1}d_{m-2}\cdots d_{j+1}d_{j-1}\cdots d_1d_0$ by removing the $j^{th}$ digit in each code, these $m-1$ digit codes are sufficient to uniquely identify the elements in $P(1,k)$. It follows from this process of re-coding that each element $id$ in $P(1,k)$ is mapped to a unique element $id'\in V_1=\{0,1,2,\ldots,n/r-1\}$ by the following one-to-one and onto mapping:

$$id'=\left(\left\lfloor \alpha/r^{j+1}\right\rfloor\times r^j+\alpha\ MOD\ r^j\right),\quad\text{where }\alpha=id-d_j\times r^j.$$
