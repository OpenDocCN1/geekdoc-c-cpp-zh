# ### 5.2 Broadcast in Ad Hoc Networks

Broadcast protocols in ad hoc networks may be centralized or distributed and may be based on deterministic or randomized algorithms. A broadcast protocol should have the following desirable properties:

+   - The protocol should be *mobility independent* or *mobility resilient* so that the broadcast is always completed correctly without knowledge of the identities of the neighbors of a node or the mobility of the nodes.
+   - It should be *deterministic* so that an upper bound on the broadcast completion time can be ascertained.
+   - It should be *distributed* rather than centralized so that the nodes can execute the protocol without *a priori* knowledge of the topology of the entire network. This property would successfully handle the dynamic network topology of an ad hoc network in a more efficient way than a centralized protocol.
+   - It should be *simple* so that the computational overhead at each node is minimized.
