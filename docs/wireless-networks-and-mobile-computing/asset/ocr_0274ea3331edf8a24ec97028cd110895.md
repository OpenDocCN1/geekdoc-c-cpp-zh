The partitioning process is formalized by the find_partition procedure as given below, where we use a simple primitive procedure radix_code(value, q, r, D) in which value, q and r are integer inputs, and D is a q-dimensional output array of integers. The radix_code(value, q, r, D) procedure converts the integer value, (0 ≤ value ≤ r^q − 1 to a q-digit radix-r number and stores the digits in locations D(0) through D(q) (from least significant to most significant digit).

```
procedure find_partition(value, i, h, offset, Flag);
begin;
radix_code(value, m - i + 1, r, D);
for j = 0 to m - i do
  temp \(\leftarrow\) r × (j - 1) + D(j);
  set Flag(i, offset + temp) ← 1;
  if i ≤ h - 1 then
    value ← value − D(j) × r^j;
    value ← (valueDIVr^(j+1)) × r^j + valueMODr^j;
    offset ← r × (m - i) × temp;
    find_partition(value, i + 1, h, offset, Flag);
  end if
end for
end procedure;
```
