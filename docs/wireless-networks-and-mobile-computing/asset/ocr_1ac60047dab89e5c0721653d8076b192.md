# 5.4 Slot Assignment Based on Location Information

We now introduce another strategy for assigning time slots to the nodes in an ad hoc network based on the location information of the individual nodes. The technique in [6] significantly improves slot utilization by an elegant technique of *re-using* the time slots by sufficiently distant nodes, avoiding collisions during transmission. The basic idea is that if the number of nodes in an ad hoc network is very large and spread over a large geographical region and we follow the technique of determining the transmission schedule as discussed in the preceding section, the number of transmission cycles needed for a successful broadcast of a message may be very large. Instead, we can first partition the deployment zone into regular hexagonal cells similar to the cellular networks with the assumption that *a given node in some cell i may hear from the nodes which lie in the same cell or any other cell j which is at Distance 1 from cell i (i.e., adjacent to cell i), but not beyond that.* Thus the nodes in some cell i cannot hear anything from any node in some cell at Distance 2 from cell i.
