
# 3.6 Fast Near-Optimal Channel Assignment

We now present a novel method [50] for solving channel assignment problems (CAPs) in hexagonal cellular networks with non-homogeneous demands in a two-band buffering system (where channel interference does not extend beyond two cells). The CAP with non-homogeneous demand is first partitioned into a sequence of smaller subproblems, each of which has a homogeneous demand from a subset of the nodes of the original network. The solution to such a subproblem constitutes an assignment phase in which multiple homogeneous demands are assigned to the nodes corresponding to the subproblem, satisfying all the frequency separation constraints. The whole assignment process for the original network consists of a succession of multiple homogeneous assignments for all the subproblems. Based on this concept, we present a polynomial time approximation algorithm given in [50] for solving the channel assignment problem for cellular networks having non-homogeneous demands. The assignment algorithm, when executed on well-known benchmark instances, yields an assignment which is always within about 6% more than the optimal bandwidth, but requires very little execution time (less than 5 milliseconds on a HPxw8400 workstation). This algorithm is suitable for real-life situations where fast channel assignment is of primary importance and a marginal deviation (6%) from the optimal bandwidth is tolerable.

## 3.6.1 Assignment Algorithm

The ultimate objective of this study is to devise a greedy algorithm that can produce a very fast assignment of the required channels (in milliseconds), while requiring a bandwidth as close as possible to the optimal bandwidth. This is a long-standing challenge in the study of the frequency assignment problem.

The essence of this approach is to partition the given channel assignment problem into a sequence of subproblems, each consisting of a specific subgraph with a uniform demand to be satisfied at each node. To satisfy a uniform demand from each node of the subgraph, we apply a greedy algorithm to first find a single frequency assignment to each node, and then multiple frequencies are assigned on a round-by-round basis (one frequency at each round) using the _increment_ in the starting frequency for the next consecutive round. The concept of _increment_ is such that if frequency φ(v) can be assigned at node v without any conflict with already assigned frequencies, the set of multiple frequencies φ(v)+k×increment for k = 1, 2, 3, ⋯, can also be assigned round by round at node v without conflict. Since s0 is the minimum frequency separation requirement between two calls in the same cell, the value of _increment_ will be at least s0. Thus, the multiple homogeneous demand can be satisfied easily using the single frequency assignment and the value of _increment_. The solution to the original problem will constitute a series of assignment phases. The starting frequency of a particular phase of assignment will be the frequency immediately next to the highest frequency assigned during the previous phase of assignment. When we move from one assignment phase, say phase i, to the next phase i + 1, we must ensure at the start that every node in the subgraph of phase i + 1 is assigned a frequency that does not cause any interference with the frequencies assigned at the last round to the nodes in phase i. It is sufficient to satisfy the last round frequencies assigned to the nodes in phase i while assigning frequencies at phase i + 1 because these are the only frequencies which may conflict with the frequencies of phase i + 1. This is because even the highest frequency assigned in the second last round in phase i and the least frequency in the first round of phase i + 1 are separated by at least i0 since the _increment_ is always greater than or equal to s0. Since s0 ≥ s1 ≥ s2, no frequencies assigned in the second last round of phase i can conflict with the frequencies in the first round of phase i + 1. This prevents conflict in the frequency assignment across subsequent phases of assignment.

As a first step of the assignment algorithm, we rearrange the nodes of the network according to the descending order of their demands. The resulting order may reveal several nodes with the same demand. We further rearrange these nodes according to the descending order of their Si values, where Si is the sum of the demands from adjacent nodes of node i. Let this ordered set of nodes be termed S.

We now consider the subgraph of the cellular graph containing only the highest demand nodes and look into its assignment by using a greedy algorithm. This greedy algorithm will start with assigning the frequency origin to the first highest demand node in the ordered set S. It takes the next node from the ordered set S and tries to assign the minimum frequency to that node from the ordered sequence <origin, origin + 1, origin + 2, …>, satisfying the frequency separation constraints with the previously assigned node. This process is repeated for all the remaining nodes of the set S taken in order. On completion of this process, we find the minimum value of increment such that the frequency channels in the interval [origin, origin + increment] are sufficient for a single frequency assignment to each highest demand node. The multiple frequencies can be assigned to these nodes using the value of increment and the single frequency assignment.

We next consider the assignment of the whole network with the frequencies explicitly in the interval [origin,origin + increment), satisfying all the frequency separation criteria. The way the value of increment will be computed, the frequencies in the interval [origin,origin + increment) will definitely cover the assignment of all the highest demand nodes, but may or may not be able to cover the other nodes of the entire network. Let V be the set of nodes covered with frequencies in [origin,origin + increment) in this phase of assignment and γmax be their highest demand, and also let V′ be the set of nodes left out and γ′max be their highest demand. Let γmax − γ′max = w. We then repeat the assignment of the nodes in V for w rounds, avoiding any interference, so as to satisfy w demands of each of the nodes in V, and reducing their highest demand to γ′max. For those nodes in V whose actual demand is less than the value of w, the assignment will be repeated for rounds equal to their respective actual demands. This will ensure that the highest demand node in V′ will now move to the set of highest demand nodes of the entire network. As a result, in the next phase of assignment, this node must be covered by the algorithm. We will now consider the residual demand vector after reducing w or the actual demand corresponding to the nodes in V and start the second phase of assignment by setting the value of origin equal to the frequency immediately next to the highest frequency channel used in this first phase of assignment.
