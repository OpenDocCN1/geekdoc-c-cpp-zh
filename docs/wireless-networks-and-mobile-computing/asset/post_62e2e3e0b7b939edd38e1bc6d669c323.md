One possibility for meeting the requirement is clustering of nodes with a cluster head in each cluster so that the heads form the backbone network. Usually, the node in a cluster having the maximum residual energy is chosen as the cluster head. Thus, a node in a specific cluster sends its message first to its cluster head, then the cluster head routes this message directly to the destination node (if it lies in the same cluster) or to another cluster head that may function as an intermediate node for a shortest path routing in the backbone network. Note that a node may have a direct (single hop communication) link to its destination, but this would not be allowed by the above technique if the source node is not a cluster head. A variant of this technique may be that when the destination node is in the same cluster, the source node may directly send its message to the destination node, relieving the cluster head of functioning as the intermediate node for this communication. This would reduce the time required for communication and the total energy for routing this message, with the negative point that the source node (which is a non-cluster head node) may be required to increase its peak transmission power, i.e., spend more energy to directly reach the farthest node of the same cluster. This, in turn, needs a careful clustering algorithm that considers the residual energy and transmission range of each node to be included in the cluster along with the selection of the appropriate nodes as the cluster heads. Thus, if a node in the cluster does not have enough residual energy to increase the peak transmission power to reach another node in the same cluster at the farthest distance, this node can not be included in the cluster. Basically, this requirement should reduce the cluster size and hence the maximum delay in the backbone network. Again there is a question of tradeoff to get the best possible result.

The technique of clustering and routing requires changing the clusters and the cluster heads dynamically. After certain time, a cluster head may be depleted of its energy and will no longer have the maximum residual energy among all nodes in the cluster. Also, the network connectivity may be changed if the nodes are mobile, energy of a node is so much depleted that it is disconnected from the network, or new nodes may have joined since the last computation of the clusters (and corresponding cluster heads). These situations should invoke computing the clusters afresh, depending on the current status of the network, e.g., network connectivity, residual energy of nodes, and transmission range of nodes.

An alternative approach for energy-efficient message routing is the use of a connected dominating set (CDS) as the backbone network, instead of the cluster heads forming the backbone network in the earlier technique. In this approach, we first construct a network graph \( G(V, E) \) with \( V \) as the set of vertices and \( E \) as the set of edges from the network. Corresponding to each node in the network, there is a vertex in the set \( V \), and two vertices will have an undirected edge between them if the corresponding two nodes of the network are within the transmission range of each other. We assume, for simplicity, that the transmission range of each node is the same. A dominating set \( DS \) of the graph \( G(V, E) \) consists of a subset of \( V \) such that every vertex of the graph is in \( DS \) or adjacent (at Distance 1) from at least one vertex in \( DS \). # Energy-Efficient Communication

## Some Elegant Physical Layer-Centric Techniques

Conventional communication strategies utilize energy-based transmission (EbT) schemes, which require energy for transmitting each bit of information, whether a 0 or a 1. Depending on the transmission strategy, both 0 and 1 are represented by non-zero voltage levels or one of the bit values is represented by a zero voltage level while a non-zero voltage level is used to distinguish the other bit value. An example of the latter is the polar return-to-zero (polar-RZ) transmission scheme, where a 0 corresponds to a zero voltage level, while a 1 represents a non-zero voltage level.

However, most existing transmission schemes utilize non-zero voltage levels for both 0 and 1 to distinguish between silent and busy channels. Communication strategies that require energy expenditure for transmitting both 0 and 1 bit values are known as *energy-based transmission* (EbT) schemes. For example, to communicate a value of 278, a node will transmit the bit sequence < 1, 0, 0, 0, 1, 0, 1, 1, 0 >, consuming energy for every bit it transmits. Thus, if the energy required per bit transmitted is $e_b$, the total energy consumed to transmit the value 278 would be $9e_b$.

In 2005, Zhu and Sivakumar [9] proposed a communication strategy called *communication through silence* (CtS), that involved using silent periods instead of energy-based transmissions. CtS, however, suffers from the disadvantage of being exponential in time. It introduces long delays and adversely affects the network throughput. Another problem is maintaining synchronization between sender and receiver over long periods of silence. Chen et al. proposed [10] an alternative strategy called variable-base tacit communication (VarBaTaC) that uses a variable radix-based information coding coupled with CtS for communication. The throughput with VarBaTac decreases exponentially with an exponential increase of the radix. Also the hardware circuit complexity increases significantly for representing higher radix numbers and handling dynamic changes of radix.

All these techniques are based on some type of source coding along with selective silent communication of the dominant symbol (most frequently occurring) after encoding the message.
