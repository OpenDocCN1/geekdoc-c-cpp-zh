## 4.8 Counting Number of Nodes in a Doubly Link List

Counting the number of nodes in a doubly link list is needed on many occasions, for instance, to learn about the length of the doubly link list, during insertion of a node, during deletion of a node, etc. Therefore, counting the number of nodes is a significant function in a doubly link list. Counting all the nodes of a doubly link list does not involve much complexity. Here, the user has to start from the first node and go up to the last node. Counting the nodes is needed during the traversal of nodes. Since the doubly link list facilitates traversal in both directions, we can also count the number of nodes by starting the traversal from the end. During this traversal, we can use the previous pointer to reach up to the first node, and at the same time, we can count the number of nodes in the doubly link list. However, in our example, we have considered traversal from the beginning towards the end node. The same has been depicted in the following program.

```cpp
// Program to count the number of nodes in a doubly link list
Solution:
int count()
{
    dnode *current = first;
    int cnt = 0;
    while (current != NULL)       // till the doubly link list is not exhausted
    {
        cnt++;                    // count the node
        current = current->next;  // move to the next node
    }
    return cnt;
}
```

## 4.9 Circular Doubly Link List

Even though a doubly link list permits the traversal in both directions, yet sometimes we need to connect the last node to the first node. Such a type of doubly link list is known as a circular doubly link list. A doubly link list has the following advantages.

- Does not have any null pointer.
- Improves the efficiency, specifically if required to be traversed from the last node towards the first node.
- Improves the performance, if required to be traversed from the first node towards the last node side.

### 4.9.1 Creation of Circular Link List

Creation of a circular doubly link list is different from its counterpart doubly link list. Once the first node is created, unlike the doubly link list, we do not point the previous and next pointers to NULL. Instead, we connect them to the node itself. The same has been illustrated in Figure 4.7(a). Once the second node is created, its previous node is connected to the first node. The pointer of the first node is also to be adjusted, because the next pointer of the first (existing) node will point to this newnode and the next pointer of this new node is to be pointed to the first node. Functions such as insertions, removal, and traversal can be performed similar to that of a normal link list. The class that performs various activities (functions) on a circular doubly link list has been depicted in the following program.

### 4.9.2 Function to Create Circular Doubly Link List

In the creation of the circular doubly link list, we have assumed two pointers, namely first and end. These two pointers represent the first and the last node of the circular doubly link list. By using the last's next, we can reach the first node of the circular doubly link list. Correspondingly, we can also reach the last node by using the first's previous. When the first node is created and the doubly link list is having only one node, in that case, both the first and the last node will point to the same node. To insert the other node, the pointer of last and the previous pointer of the first node need to be connected to the newly created newnode. The complete program has been depicted as follows.

### 4.9.3 To Count the Number of Nodes in a Circular Doubly Link List

To count the number of nodes in a circular doubly link list, we need to begin the traversal either from the front or from the back. In a circular doubly link list, since the first is connected to the last node and the last node is pointing to the first node, correspondingly, due care needs to be observed in order to prevent cycling during the traversal. In our case, we have applied the condition, thereby it is examined that we have not reached the node from which we began. The function for this effect has been depicted as follows:

```cpp
// To count the number of nodes in a doubly link list
int dblyList::count()
{
    // initialize the count to 0
    int c = 0;
    // store the address of first to the current node
    dnode *current = first;
    // run the loop till we are not reaching the first node
    while (current->next != first)
    {
        c++;       // increment the count
        // move the pointer to the next node
        current = current->next;
    }

    // One node was left due to current->next, count that node also;
    c = c + 1;
    return c;
}
```

The variable 'c' represents the count; initially, this value will be zero, and correspondingly, it has been initialized with zero. During the visit to each node, we increment the value of this variable by one. Since we have terminated at the last node, this node has not been reached. To count this node, we have incremented the current value of variable 'c' by 1. Finally, the value of 'c' has been returned to the caller.

### 4.9.4 To Insert a Node at a Given Position

During inserting a node in a circular link list, we need to ensure that the circular property is not lost upon insertion. This is particularly applicable during the insertion of a node at either the first position or at the last position. When the node to be inserted is in between, then there is no difference between the circular doubly link list and the doubly link list. - Figure out the validity of the position where the new node is to be inserted (must lie between the first and last node plus one).
- If the position where the node to be inserted is first, connect the previous node of the newnode to the previous node of the existing first node. Connect the next pointer to the first node. Name this newnode as the first node by shifting the first pointer to this newnode. Similarly, change the next pointer of the last node to this newnode (first node).

Connect the previous node of the newnode with the current node. Connect the next pointer of the current node to the newnode.

Connect the next pointer of the existing end node to the newnode (this will act as the last node), connect the previous node of newnode to the existing last node. Finally, move the end node to this newnode.
