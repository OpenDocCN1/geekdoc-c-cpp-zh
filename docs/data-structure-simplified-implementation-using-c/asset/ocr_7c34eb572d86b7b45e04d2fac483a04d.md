# 3.3.3 Deleting the node in a link list

Link list holds the data similar to other type with the difference that it is dynamic in nature. It may happen that the data stored in a link list may no longer needed. This leads to need of another operation term as deletion to be envisioned on a link list. Snce, link list is connected with the help of pointers, therefore, due care need to be exercised to ensure that link list remains connected even after the deletion of a node(s). During deletion of a node, the following possibilities related to the position need to be taken into account.

+   - Deleting first node.
+   - Deleting other than the first node.
