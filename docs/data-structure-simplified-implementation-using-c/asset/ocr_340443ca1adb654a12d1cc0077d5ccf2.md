Finally, with the insertion of 10 and subsequently 2, balancing factor of the node 2’s grandparent will be changed to 2 and this condition is unacceptable. Therefore, we need to balance this tree in order to ensure that it continue to qualify the definition of an AVL, we rotate the grandparent considering the homogeneous and heterogeneous unbalancing.
