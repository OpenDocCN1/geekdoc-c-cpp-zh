# ## 12.1

# ### Erroneous Code:

```
```cpp
int getNumber( )
{
    return intNumber;
}
float getNumber( )
{
    return floatNumber;
}
```
```

# ### Correction:

Functions can not be overloaded on the basis of distinct return types. Hence, some other overloading criteria must be chosen to overload the getNumber() functions.
