
```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string s1("Road");
    string s2("Read");
    string s3("Red");
    cout << "s1 = " << s1 << "\n";
    cout << "s2 = " << s2 << "\n";
    cout << "s3 = " << s3 << "\n";

    int x = s1.compare(s2);
    if (x == 0)
        cout << "s1 == s2\n";
    else if (x > 0)
        cout << "s1 > s2\n";
    else
        cout << "s1 < s2\n";

    int a = s1.compare(0, 2, s2, 0, 2);
    int b = s2.compare(0, 2, s1, 0, 2);
    int c = s2.compare(0, 2, s3, 0, 2);
    int d = s2.compare(s2.size() - 1, 1, s3, s3.size() - 1, 1);

    cout << "a = " << a << "\n";
    cout << "b = " << b << "\n";
    cout << "c = " << c << "\n";
    cout << "d = " << d << "\n";

    cout << "\nBefore swap:\n";
    cout << "s1 = " << s1 << "\n";
    cout << "s2 = " << s2 << "\n";

    s1.swap(s2);

    cout << "\nAfter swap:\n";
    cout << "s1 = " << s1 << "\n";
    cout << "s2 = " << s2 << "\n";

    return 0;
}
```
程序15.6的输出将是：

交换字符串s1和s2的内容。

# 小结

+   对C风格字符串的操作和使用变得复杂且低效。ANSI C++ 提供了一个名为 **string** 的新类来克服C字符串的缺陷。
+   string 类支持许多构造函数、成员函数和运算符，用于创建和操作字符串对象。我们可以对字符串执行以下操作：
    +   从键盘读取字符串
    +   将一个字符串赋值给另一个
    +   查找子字符串
    +   修改字符串
    +   比较字符串和子字符串
    +   访问字符串中的字符
    +   获取字符串的大小和容量
    +   交换字符串
    +   对字符串排序
