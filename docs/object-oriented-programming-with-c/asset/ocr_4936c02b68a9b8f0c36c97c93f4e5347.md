```
class item
{
    int code;
    float price;
    public:
    void getdata(int a, float b)
    {
    }
    };

    code = a;
    price = b;

    } void show(void)
    {
    cout << "Code : " << code << "\n";
    << "Price: " << price
    << "\n\n";
    }
};
```

Let us declare an item variable x and a pointer ptr to x as follows:

```
item x;
item *ptr = &x;
```

The pointer ptr is initialized with the address of x.
