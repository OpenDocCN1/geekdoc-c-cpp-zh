
- **seekp()** 将输出指针移动到指定位置。
- **tellg()** 返回 get 指针的当前位置。
- **tellp()** 返回 put 指针的当前位置。

例如，语句

```
infile.seekg(10);
```

会将文件指针移动到字节号 10 的位置。记住，文件中的字节从零开始计数。因此，指针将指向文件中的第 111th 字节。

考虑下面的语句：

```
ofstream fileout;
fileout.open("hello", ios::app);
int p = fileout.tellp();
```

执行这些语句后，输出指针位于文件 “hello” 的末尾，变量 p 的值表示文件中的字节数。
