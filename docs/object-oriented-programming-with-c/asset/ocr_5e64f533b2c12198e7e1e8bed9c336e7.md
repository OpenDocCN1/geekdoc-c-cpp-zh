Telephone Billing System is a command-driven application that helps manage records of the customers as well as generate their telephone bills.

| Option | Description |
|---|---|
| 'M'anage Customer Records | Helps to manipulate customer records |
| 'A'dd new record | Adds a new customer record |
| 'M'odify existing record | Modifies an existing customer record |
| 'D'elete existing record | Deletes an existing customer record |
| 'D'isplay list of customers | Displays the list of existing customers |
| 'G'enerate Bill | Helps to generate a telephone bill |
| 'H'elp | Provides help documentation |
| 'E'xit | Exits the current screen/application |

Press any key to go back..
