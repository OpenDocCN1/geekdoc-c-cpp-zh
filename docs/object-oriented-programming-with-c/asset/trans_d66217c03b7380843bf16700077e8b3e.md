## 3.1 引言

如前所述，C++ 是 C 的超集，因此 C 的大多数结构在 C++ 中都是合法的，且含义不变。然而，也存在一些例外和新增内容。在本章中，我们将讨论这些与记号和控制结构相关的例外和新增内容。

## 3.2 记号

+   - 关键字
+   - 标识符
+   - 常量
+   - 字符串
+   - 运算符
