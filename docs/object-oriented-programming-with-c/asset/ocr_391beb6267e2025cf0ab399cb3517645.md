The _type-list_ specifies the type of exceptions that may be thrown. Throwing any other type of exception will cause abnormal program termination. If we wish to prevent a function from throwing any exception, we may do so by making the _type-list_ empty. That is, we must use

```
throw(); // Empty list
```

in the function header line.

> NOTE: A function can only be restricted in what types of exceptions it throws back to the try block that called it. The restriction applies only when throwing an exception out of the function (and not within a function).
