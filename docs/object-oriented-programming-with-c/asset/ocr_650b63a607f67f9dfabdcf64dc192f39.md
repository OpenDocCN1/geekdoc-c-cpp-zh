These values are assigned to various parameters by the constructor D() as follows:

+   5 — a1
+   12 — a2
+   2.5 — b1
+   7.54 — b2
+   30 — d1

The constructors for virtual base classes are invoked before any nonvirtual base classes. If there are multiple virtual base classes, they are invoked in the order in which they are declared. Any nonvirtual bases are then constructed before the derived class constructor is executed. See

\begin{tabular}{cc}
Method of inheritance & Order of execution \\
Class B: public A & A() ; base constructor \\
{ & B() ; derived constructor \\
}; &  \\
class A : public B, public C & B() ; base(first) \\
{ & C() ; base(second) \\
}; & A() ; derived \\
class A : public B, virtual public C & C() ; virtual base \\
{ & B() ; ordinary base \\
}; & A() ; derived \\
\end{tabular}
