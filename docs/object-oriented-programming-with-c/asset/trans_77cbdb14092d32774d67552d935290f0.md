
## 16.8 新头文件

ANSI C++ 标准定义了一种指定头文件的新方式。它们不使用 .h 扩展名作为文件名。示例：

```
#include <iostream>
#include <fstream>
```

然而，传统的 **<iostream.h>, <fstream.h>,** 等风格仍完全受支持。一些旧头文件被重命名如下表所示：

| 旧风格 | 新风格 |
|---|---|
| <assert.h> | <cassert> |
| <ctype.h> | <cctype> |
| <float.h> | <cfloat> |
