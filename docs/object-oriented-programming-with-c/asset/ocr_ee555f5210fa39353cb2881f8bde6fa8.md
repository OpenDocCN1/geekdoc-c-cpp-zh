# 8.5 Multilevel Inheritance

It is not uncommon that a class is derived from another derived class as shown in Fig. 8.7. The class A serves as a base class for the derived class B, which in turn serves as a base class for the derived class C. The class B is known as _intermediate_ base class since it provides a link for the inheritance between A and C. The chain ABC is known as inheritance path.
