# Fig. 5.5 Storage of data items of an object array

Program 5.6 illustrates the use of object arrays.



```
#include <iostream.h>
using namespace std;
class employee
{
char name[30]; // string as class member
float age;
public:
void getdata(void);
void putdata(void);
};
void employee :: getdata(void)
{
cout << "Enter name: ";
cin << name;
cout << "Enter age: ";
cin >> age;
}
```
