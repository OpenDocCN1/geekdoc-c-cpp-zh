The only disadvantage of this style of declaration is that we cannot see all the variables used in a scope at a glance.

# ### 3.12 Dynamic Initialization of Variables

In C, a variable must be initialized using a constant expression, and the C compiler would fix the initialization code at the time of compilation. C++, however, permits initialization of the variables at run time. This is referred to as _dynamic initialization_. In C++, a variable can be initialized at run time using expressions at the place of declaration. For example, the following are valid initialization statements:
