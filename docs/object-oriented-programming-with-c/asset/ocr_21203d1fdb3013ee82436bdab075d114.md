# 11.2 Classes for File Stream Operations

The I/O system of C++ contains a set of classes that define the file handling methods. These include **ifstream**, **ofstream** and **fstream**. These classes are derived from **fstreambase** and from the corresponding *iostream* class as shown in [Fig. 11.1](#). These classes, designed to manage the disk files, are declared in *fstream* and therefore, we must include this file in any program that uses files.

[Table 11.1](#) shows the details of file stream classes. Note that these classes contain many more features. For more details, refer to the manual.
