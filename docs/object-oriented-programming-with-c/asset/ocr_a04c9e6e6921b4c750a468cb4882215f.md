```
Another function often used is **sort()** for sorting arrays of various types such as **int** and **double**. The following example shows a function template for bubble sort:

```
```cpp
template<class T>
bubble(T v[], int n)
{
    for(int i=0; i<n-1; i++)
        for(int j=n-1; i<j; j--)
            if(v[j] < v[j-1])
            {
                T temp = v[j];
                v[j] = v[j-1];
                v[j-1] = temp;
            }
}
```
