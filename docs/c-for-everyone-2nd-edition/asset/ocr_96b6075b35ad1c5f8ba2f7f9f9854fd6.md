# APPENDIX D
# CHARACTER CODES

These escape sequences can occur in strings (for example, "\\n") and characters (for example, '\\').

| Escape Sequence | Description |
|---|---|
| `\n` | Newline |
| `\r` | Carriage return |
| `\t` | Tab |
| `\v` | Vertical tab |
| `\b` | Backspace |
| `\f` | Form feed |
| `\a` | Alert |
| `\\` | Backslash |
| `\"` | Double quote |
| `\'` | Single quote |
| `\?` | Question mark |
| `\x₁h₂` | Code specified in hexadecimal |
| `\o₁o₂o₃` | Code specified in octal |
