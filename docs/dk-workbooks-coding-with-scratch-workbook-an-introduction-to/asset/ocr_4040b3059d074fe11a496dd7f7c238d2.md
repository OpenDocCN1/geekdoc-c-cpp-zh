# Which Way?

When you want to move a sprite, you need to know two things: how far and which way. Every sprite has a built-in direction arrow. When a script gets to a dark blue move block, that's the direction in which the sprite will go.

# Cat Follows Mouse!

Let's spin our cat in every possible direction. Open a new project in the Scratch editor. Build this script for the cat sprite. Read the script. What do you think it does? Click the green flag to see if you guessed correctly.

# Sprites Know Where to Go!

direction: -90

Every sprite knows what direction it's pointing. A sprite's direction is shown in the sprite information panel when you click the blue i.

Direction circle shown on sprite information panel

Direction -90° means "left"

Direction 0° means "up"

As the cat spins around, you'll see its direction value change and the blue line pointer move around the circle.

![](bbox=[0.163, 0.715, 0.443, 0.915])

Direction 180° means "down"

Direction 90° means "right"
