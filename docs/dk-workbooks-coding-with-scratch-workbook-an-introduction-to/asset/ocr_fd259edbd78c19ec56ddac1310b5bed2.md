# Glossary

animation
Changing pictures quickly to make something appear to move on the screen.

Stuck in Scratch? Click on Tips on the menu bar for advice. Or use the Help tool ?—click on it, and then click a block to bring up the help page for that block.

backdrop
The picture behind the sprites on the stage.

debug
To remove bugs; to find and fix the errors in a program.

operating system (OS)
The program that controls everything on your computer, such as OS or Windows.

backpack
A way to copy things between Scratch projects.

event
Something that happens on the computer, like a mouse click.

run
To start a program.

block
An instruction in Scratch. Blocks can be joined together.

input
Data that goes into the program; for example, from the keyboard.

script
A stack of instructions that are run in.

bug
A mistake in a program. A bug because insects got into the wiring of the first computers, causing errors.

library
A collection of sprites, sounds, or costumes.

sprite
A picture on the stage that can move and change.

condition
A ‘true’ or false?’ question that is used to make a decision in a computer program.

loop
An instruction that makes instructions repeat.

stage
The area containing the sprites, where a Scratch project runs.

costume
The picture sprite shows on the stage.

program
A list of instructions that tell a computer to do.

string
The word used by programmers for data that contains words.

data
Information—for example, numbers or words.

operator
A block that works out from data, such as adding two numbers together.

variable
A place to store data in a program. A variable always has a name and a value.

> Note for Parents
Help your child work logically through any difficulties. Check for obvious errors, such as swapping similar blocks in scripts. Also check that scripts are controlling the correct sprites. Don't forget that Scratch should be fun. The Scratch website is run by Massachusetts Institute of Technology (MIT) and is intended to be safe for children to use. Try it yourself!
