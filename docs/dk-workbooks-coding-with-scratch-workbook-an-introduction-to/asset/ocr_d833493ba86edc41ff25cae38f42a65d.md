# Repeat Loops

If we want to repeat a group of blocks only a few times and then move on to the rest of the script, we can use the repeat loop block.

Try this script for a siren that annoys the cat. The repeat loop runs the two play note blocks 10 times and only runs the think block. Try changing the number of repeats.
