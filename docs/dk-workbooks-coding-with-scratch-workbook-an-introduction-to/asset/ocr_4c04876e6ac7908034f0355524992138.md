# A Closer Look at the if-then Block

Look at this if-then block taken from a script.
Read carefully and think about what it does.

If answer's "false," blocks are skipped

Condition
(answer is "true" or "false")

If answer's "true," blocks are run

![](bbox=[0.187, 0.178, 0.833, 0.273])

+   - The if-then block is a yellow Control block, because it controls blocks inside it are run.

+   - An if-then block has a question known as a condition. The question must have a true/false answer.

+   - The blocks inside the if-then block are only run when the answer to the question is "true."

![](bbox=[0.633, 0.316, 0.873, 0.638])

+   - If the answer to the question is "false," then the blocks inside the if-then block are ignored.
