# What is Scratch?

Scratch is a visual programming language that allows you to create stories, games, and animations. It is designed for beginners, but it is powerful enough for advanced users.

What You'll Learn:
- How to use the interface
- How to move and animate sprites
- How to use loops and conditionals
- How to use variables and events
- How to create your own games

# What is Scratch?

Scratch is a fun way to learn the basics.

# What Does a Computer Understand?

A program is a set of instructions that tells a computer what to do. In Scratch, these instructions are made using blocks that you snap together like puzzle pieces.

# What Makes Up Scratch Project?

A project consists of several parts:
- The Stage: Where the action happens
- Sprites: The characters or objects in the project
- Scripts: The sets of blocks that tell the sprites what to do
- Backdrops: The backgrounds of the stage

# Scripts for Sprites

Scripts are used to control the behavior of sprites. Each sprite can have multiple scripts. Here is an example:

```
when green flag clicked
forever
  move 10 steps
  if edge on then
    bounce
```

# Getting Scratch

You can use Scratch online at the website, but if you aren't always connected to the Internet, you can install it on your computer.

# Using Scratch Online

If you register for a Scratch account, you will be able to save your projects online and share them with friends.

# Sign Up for Scratch

Go to scratch.mit.edu and select Join Scratch for instructions on how to register. You will need to get permission from an adult with an e-mail address.

# Create in Scratch

When you want to use Scratch, go to the Scratch website and click on Create. This will open the editor window.

# Save in Scratch

Projects save automatically if you're logged in your Scratch account. You can see your saved projects by clicking the file with “S” at the top right of the screen.

> Top Tip from Scratch Cat
Need to "right click" but only have one button on your mouse? Usually you can hold down the CTRL key on the keyboard as you click. Not working? Then ask the owner of the computer.
