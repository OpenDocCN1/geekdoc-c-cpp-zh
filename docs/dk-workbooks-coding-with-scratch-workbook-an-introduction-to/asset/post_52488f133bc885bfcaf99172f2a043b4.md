
# Math

Scratch can do all the math you know about. But some of the symbols it uses are different, to fit with what's on your computer's keyboard. We can do equations in Scratch and use variables in them. Scratch can even roll dice for us.

# Math Tools

To do math you need the green Operators blocks. Each block does a different problem with the numbers in the two windows.

### Add (+)
The "+" block adds the two numbers in block together.

### Subtract (-)
The "-" block takes the second number away from the first.

# Placing Operators

Wherever you put an operator block, it will put the answer to the problem. So if you put it into the window of a say block, the cat will say the answer.

### Multiply (*)
Scratch uses the "*" symbol, because "x" looks like a letter.

### Divide (/)
The keyboard has no division sign. Scratch uses "/" instead.

# Enter the Dragon

![](img/c8b294ee7af329f5e2b96cede7af2ab1_33_1.png)

# Get the Dragon Bouncing

Choose the dragon in the sprite list and add this script. This is the bouncing script we used before, but with a slight change. We control the dragon’s speed with a variable and set the dragon off in a different direction each game. Read and run the script. The dragon bounces around the stage.

```
when clicked
set [speed] to [10]
point toward [cursor]
forever
  move [speed] steps
  if on edge, bounce
```

# Mouse Controls Cat!

Now select the cat in the sprite list and add this script. Carefully read the script. It “sticks” to the cat to the cursor. Inside the loop it checks if we’re touching the dragon. If we are, it stops the project—game over! Run the script to check that it works.

```
when clicked
wait [1] secs
forever
  go [cursor]
  if [touching Dragon ?] then
    stop [all]
```
