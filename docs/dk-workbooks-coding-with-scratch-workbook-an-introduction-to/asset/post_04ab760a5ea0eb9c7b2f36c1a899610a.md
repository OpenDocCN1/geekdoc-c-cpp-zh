
## Which Way?

When you want to move a sprite, you need to know two things: how far and which way. Every sprite has a built-in direction arrow. When a script gets to a dark blue move block, that's the direction in which the sprite will go.

- What You'll Learn:
- How to point a sprite in different directions
- How to make a sprite

## Cat Follows Mouse!

## Sprites Know Where to Go!

direction: -90

Every sprite knows what direction it's pointing. A sprite's direction is shown in the sprite information panel when you click the blue i.

Direction circle shown on sprite information panel

Direction -90° means "left"

Direction 0° means "up"

As the cat spins around, you'll see its direction value change and the blue line pointer move around the circle.

![](img/c8b294ee7af329f5e2b96cede7af2ab1_15_1.png)

Direction 180° means "down"

Direction 90° means "right"

Use the "compass" shown here to decode the direction number.

## Loops

In computer programs, we often want to carry out the same instructions more than once. To avoid having to put down the same blocks many times, we can wrap them in a loop instruction that repeats the blocks. Meet forever and repeat loops!

- What You'll Learn:

## Animation

The characters in cartoons seem to move, but really you are just watching lots of slightly different pictures that fool your brain into seeing movement. This is called animation. Sprites can be animated in the same way.

- What You'll Learn:
- How to animate sprites
- Sprites can change how they look
- How to use costumes

## Changing Costumes

Our cat sprite has two different pictures, or "costumes," it can show. Start a new scratch project and click on the Costumes tab above the block list. You will then see the two costumes the cat sprite can "wear".

To animate the cat, build and run this script. The forever loop repeats the next costume block. The picture of the sprite changes every half second, and this makes the cat look like it's walking. Try adding move block in the loop to improve the animation.

![](img/c8b294ee7af329f5e2b96cede7af2ab1_19_1.png)

![](img/c8b294ee7af329f5e2b96cede7af2ab1_19_2.png)

> Sprite's costumes are listed in order

This picks the next costume.
Quickly swapping costumes makes it look as if the cat is walking.

```
when clicked
forever
  next costume
  wait 0.5 secs
```

![](img/c8b294ee7af329f5e2b96cede7af2ab1_19_3.png)

Wait stops the costumes from changing too quickly
