# ► Throwing Dice

A random number is one we can't predict. It's like a number we get when we roll dice—we don't know what the numbers will be before we roll. Scratch can act like dice and “roll” for us. Try this script in a new project.

Read the script, then run it. The cat will show you four random numbers as it thinks of them. Random numbers are useful in games, because they make the action difficult to guess.
