# Installing Scratch on a Computer

If you don't have access to the Internet or you want to work offline, you'll need the Scratch installer. Go to scratch.mit.edu/scratch2download and just follow the installation instructions.

To start Scratch, double-click the Scratch 2.0 icon on your desktop.

# Operating Systems

Check that your computer's operating system is able to run Scratch.

+   - The online version of Scratch 2.0 will run on Windows (PC), OS X (Macs), and some Linux computers.
- The offline version might not work with some Linux computers.
- The Raspberry Pi can't run Scratch 2.0 at the moment.
