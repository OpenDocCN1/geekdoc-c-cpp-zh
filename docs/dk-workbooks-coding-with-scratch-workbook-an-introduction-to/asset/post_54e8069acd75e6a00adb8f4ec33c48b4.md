
# Installing Scratch on a Computer

If you don't have access to the Internet or you want to work offline, you'll need the Scratch installer. Go to scratch.mit.edu/scratch2download and just follow the installation instructions.

To start Scratch, double-click the Scratch 2.0 icon on your desktop.

![](img/c8b294ee7af329f5e2b96cede7af2ab1_8_0.png)

# Operating Systems

Check that your computer's operating system is able to run Scratch.

- The online version of Scratch 2.0 will run on Windows (PC), OS X (Macs), and some Linux computers.
- The offline version might not work with some Linux computers.
- The Raspberry Pi can't run Scratch 2.0 at the moment.

# Your First Project

Time for our Scratch project. We're going to create some simple instructions to make the cat talk. By moving the blocks around with the mouse, we can build a simple program called a script.

- What You'll Learn:
- Sprites are controlled by scripts
- How to build a script from Scratch blocks
- Things in scripts happen one at a time
- You can read Scratch to find out what it does

![](img/c8b294ee7af329f5e2b96cede7af2ab1_11_0.png)

# Scratch—The Friendly Cat

First, open the Scratch editor: either choose on the Scratch website, or click the icon on your computer. You'll see the cat sprite standing on the stage. Let's make a script to tell the cat what to do.

![](img/c8b294ee7af329f5e2b96cede7af2ab1_11_1.png)

Click on the Looks label

![](img/c8b294ee7af329f5e2b96cede7af2ab1_11_2.png)

- 1 Start a New Script
We'll begin by getting the cat to say "Hello!" Click on the purple label under Scripts in the center of the editor.

- 2 Select a Say Block
The list of blocks in the middle of the editor will change. Click with the mouse on the top say block and drag it to the right, into the scripts area.

```
Hello! for 2 secs
```

- 3 Do It Again!
Drag a second say block into the scripts area. Release the button when the blocks overlap, so they lock together like jigsaw pieces.

```
Hello! for 2 secs
Hello! for 2 secs
```

- 4 Change What the Cat Says
We can tell the cat to say something different. Click on the lower say box in the stack. Type in a new message, such as "Nice day!"

```
Hello! for 2 secs
Nice day! for 2 secs
```

New message goes here

# Completing Your Script

Click on the Events tab. Drag the brown block in the list to the right, into the scripts area. Hover over the top say block, then let go of the mouse. The brown block will clip on the two say blocks.

Clicking the flag runs the script

# Read the Whole Script

The script tells us that to start we need to click on the green flag in the top right of the stage. This is called "running" the script.

![](img/c8b294ee7af329f5e2b96cede7af2ab1_12_0.png)

# Watch the Action

When you click on the flag, Scratch Cat will say "Hello!" for two seconds. Then it will say "Nice day!" for two seconds.

> See how the blocks work in order—the cat does each action in turn.

# Move It!

### You'll Learn:
* How to make a sprite
* That Scratch measures distance in steps
* How to keep sprites the right up

![](img/c8b294ee7af329f5e2b96cede7af2ab1_13_0.png)

Now for some action. Let's get our cat moving using the dark blue Motion blocks. Scratch measures distances in "steps." The stage is 480 steps wide and 360 steps tall. There is a block to stop sprites from getting stuck to the walls. They just bounce off them!

- Let's Move the Cat
Start a new project. Click on File above the stage and select New. Add this script and think about what the blocks do.

img/c8b294ee7af329f5e2b96cede7af2ab1_13_1.png)

Click the green flag to run the script. The cat will move a short way to the right. Try it a few times.

![](img/c8b294ee7af329f5e2b96cede7af2ab1_13_2.png)

Click on the 10 in the move block and type 100. The cat now moves much further each time. Experiment by trying different numbers of steps.

![](img/c8b294ee7af329f5e2b96cede7af2ab1_13_3.png)

- Bouncing Off the Walls
Now change your script to this. Read the script. What do you think it does? The forever block repeats the blocks inside—forever! The if edge, bounce block turns the cat around the edge.

![](img/c8b294ee7af329f5e2b96cede7af2ab1_13_4.png)

Run the new script. The cat will now move right, then left, across the stage. Experiment—the more steps there are, the faster the cat goes.

img/c8b294ee7af329f5e2b96cede7af2ab1_13_5.png)
