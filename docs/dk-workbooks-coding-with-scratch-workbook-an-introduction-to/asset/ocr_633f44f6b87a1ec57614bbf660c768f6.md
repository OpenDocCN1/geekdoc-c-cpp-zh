# if-then-else

Let's meet the if-then-else block. This block uses a question, or condition, to choose between two groups of blocks to run. We'll also look at some handy condition blocks that use variables and values to ask “true or false?”

# Password Checker

An if-then-else block has two groups of blocks inside. It runs the first group if the condition is true, and the second group if the condition is false. We can use it to check a password.

![](bbox=[0.375, 0.517, 0.93, 0.653])

Block runs if answer is “dragon”

Block runs if answer is NOT “dragon”

![](bbox=[0.495, 0.715, 0.91, 0.888])

Equals (=) block compares answer with password
