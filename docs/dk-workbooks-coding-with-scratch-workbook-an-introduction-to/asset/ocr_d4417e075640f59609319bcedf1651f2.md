# Score

A proper game needs a score and a challenge. Add a new variable for all sprites called score. Leave it checked so that it shows on the stage.

Add this script to the cat. Read it. For every 3 seconds you drag the dragon, you score a point. But every time you score, the dragon's game speed goes up one!

Run the game to see that it works as you expect. If it doesn't, check everything from the beginning. Compete with your friends to get the best score. Why not add a backdrop and some music?
