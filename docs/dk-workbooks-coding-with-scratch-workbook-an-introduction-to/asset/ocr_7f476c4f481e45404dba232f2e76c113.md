# Loops

In computer programs, we often want to carry out the same instructions more than once. To avoid having to put down the same blocks many times, we can wrap them in a loop instruction that repeats the blocks. Meet forever and repeat loops!

+   What You'll Learn:
- How to repeat a group of blocks using a loop
- The difference between forever and repeat loops
- How to make some noise in Scratch

# Forever Loops

A loop instruction runs a script in the normal order from top to bottom, but then loops back to the top. The loop runs the blocks inside and over again. Try wrapping a forever loop around the blocks from the last script.

![](bbox=[0.555, 0.603, 0.915, 0.723])

When the actions finish, the program always goes back to the start of the loop

Now the cat turns more and changes color each time the blocks in the forever loop are repeated.
