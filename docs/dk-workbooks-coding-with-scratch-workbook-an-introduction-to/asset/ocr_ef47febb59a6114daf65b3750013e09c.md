pages 4–5 What is Scratch?

+   1. A **script** is a set of instructions (program) in Scratch.
2. Objects that perform actions in a project are called **sprites**.
3. In a Scratch program, the action takes place on the **stage**.
4. Starting a program is called **running** it.
5. A collection of sounds or graphics is called a **library**.
