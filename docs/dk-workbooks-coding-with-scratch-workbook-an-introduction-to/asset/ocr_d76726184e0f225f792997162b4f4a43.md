# Math

Scratch can do all the math you know about. But some of the symbols it uses are different, to fit with what's on your computer's keyboard. We can do equations in Scratch and use variables in them. Scratch can even roll dice for us.

# Math Tools

To do math you need the green Operators blocks. Each block does a different problem with the numbers in the two windows.

Add (+)
The "+" block adds the two numbers in block together.

Subtract (-)
The "-" block takes the second number away from the first.

# Placing Operators

Wherever you put an operator block, it will put the answer to the problem. So if you put it into the window of a say block, the cat will say the answer.

Multiply (*)
Scratch uses the "*" symbol, because "x" looks like a letter.

Divide (/\)
The keyboard has no division sign. Scratch uses "/" instead.

# Math and Variables

We can use operator blocks to solve problems with variables. For example, to find the total number of pets, we can use the add (+) block to add up the values of the variables dogs and cats, and store the answer in a variable called pets.
