+   1. Why do we leave the check box on the score variable checked?
The box is checked so the score is shown on the stage.

+   2. How could you make the dragon go at half speed at the start?
Change “set speed 10” to “set speed 5.”

+   3. Which block could you add inside the cat’s forever loop to make it
it it’s walking? The “next costume” block from “Looks.”

altering the game script so that the dragon changes costumes when it
touches the cat.)

chose duplicate?

make the game very hard!
