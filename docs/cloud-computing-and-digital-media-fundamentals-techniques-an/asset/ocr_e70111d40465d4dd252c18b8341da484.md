Figure 5.2 shows the overall architecture of DASH in a cloud environment. When the video is uploaded to the front-end Web server clusters, the server load balancer will accept the job and assign it to an HTTP server that can process this job with the consideration of balancing the workload. The HTTP server will then forward the job with a video transcoding request to the job scheduler and store the uploaded video in the video storage repository. In the back-end cloud environment, the job scheduler maintains two queues: One for normally uploaded videos (referred as Nqueue), whereas the other one is for videos with high priority (referred as Pqueue). The job scheduler does not dispatch jobs in Nqueue until the Pqueue is empty.
