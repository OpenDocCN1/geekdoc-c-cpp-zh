After obtaining $f$, we can further approximate the value of $k_R$, which achieves the best query evaluation time. As discussed earlier, $k_R$ affects two parts of our cost model: the network volume and the expected input size to Reduce tasks, both of which are the dominating factors of the execution time. Therefore, an approximation of the optimal $k_R$ can be obtained when we try to minimize the value $\Delta$:

```
$D=1^{\Delta} \bar{A} \sum_{i=1}^A \frac{R_i}{j} Cnt(r_i^j, \mathcal{C}) + (1-\lambda)^{\frac{m}{n-1}} \frac{P|R_i|}{k_R} \quad (9.10)$
```

Intuitively, $\Delta$ is a linear combination of the two cost factors. Coefficient $\lambda$ denotes the importance of each cost factor. For instance, if $\lambda < 0.5$, it implies that reducing the workload of each task brings more saving. Note that the first cost factor in Equation 9.10 is also a linear function of $k_R$. Therefore, by making $\Delta'=0$, we get $[k_R]$
