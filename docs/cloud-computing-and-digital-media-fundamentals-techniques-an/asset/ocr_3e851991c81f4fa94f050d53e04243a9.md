For any pair of vertices $v_i$, and $v_j$, any different noedge-repeating path between them is a “subpath” of a Eulerian trail. If we know all the no-edge-repeating paths between any pair of vertices, we can enumerate all the Eulerian trails in polynomial time. Therefore, the complexity of constructing $G_J$ is at least as hard as enumerating all the Eulerian trails of a given graph, which is known to be #complete [25]. Moreover, we find that $G_J$ does not have an Eulerian trail and the problem complexity is not reduced at all, as we elaborate in the proof of the following theorem.

**THEOREM 1:** Generating $G_{J\}$ from a given $G_J$ is a #complete problem.

PROOF: If $G_J$ has the Eulerian trail, constructing $G_{J\}$ is #complete
(see the discussion above).$\square$

On the contrary, if $G_J$ does not have the Eulerian trail, it implies that there are $r$ vertices having odd degrees, where $r > 2$. Now consider that we have one virtual vertex and connect it with $r-1$ vertices of odd degrees. Now the graph must have an Eulerian trail. If we can easily construct the joinpath of the new graph, the original graph $G_{J\}$ can be computed in polynomial time. We elaborate with following example, as shown in Figure 9.4. Assume $v_s$ is added to the original $G_J$. By computing the joinpath of the new graph, we know all the no-edge-repeating paths between $v_i$ and $v_j$. Then, a no-edge-repeating path between $v_i$ and $v_j$ cannot exist if it has $v_s$ involved. By simply removing all the enumerated paths that go through $v_s$, we can obtain the $G_{J\}$ of the original $G_J$. Thus, the dominating cost of constructing $G_{J\}$ is still the enumeration of all Eulerian trails. Therefore, this problem is #complete.
