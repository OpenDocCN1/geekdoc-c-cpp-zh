10.4.4.4 Connection Management Commands
As mentioned earlier, the CGDG maintains dedicated connections between users and workers for enabling dynamic game tree search. There are user-broker and worker-broker HEART_BEAT messages to identify the network node availability. When the broker detects that some node fail, it will try to automatically reestablish the last connection via sending NEW_WORKER and INIT_WORKER messages (Figure 10.9).
