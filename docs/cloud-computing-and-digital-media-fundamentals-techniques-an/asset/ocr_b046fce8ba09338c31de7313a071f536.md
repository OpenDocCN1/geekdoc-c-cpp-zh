As presented earlier, the existing cloud video transcoding services have their own scheduling algorithms that are transparent to end users. The users do not know how the cloud schedulers are implemented. These services are appropriate for users who only want to encode all the videos as soon as possible without any specific requirement. However, in cases (e.g., if one video is being watched but the required bit rate is not available on the server), the existing video transcoding services cannot handle these situations. Specifically, for specific purposes, we may want to develop our own application-oriented scheduling algorithm.
