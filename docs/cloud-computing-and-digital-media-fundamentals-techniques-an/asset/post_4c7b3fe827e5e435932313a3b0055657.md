## 10.4.4.3 Task Management

The task management commands are used for managing the life cycle of the execution of a task, including initiation, cancel, abort, suspend, and wakeup.

The JABORT message is used to abort the execution of a task. Since the task may be hosted in some other organization, this message is first submitted to the broker and then forwarded to the destination worker. The destination worker issues a JABORT_ACK to the broker after successfully aborting the task (Figure 10.8).

### 10.4.4.4 Connection Management Commands
