```
$t_{CP} = C_2\frac{\mathbf{a} \neq S_t}{n\times m} + q\times n \quad (9.3)$
```

network
q$ is a random variable that represents the cost of a Map task serving $n
connections from n Reduce tasks

Intuitively, there is a rapid growth of $q$ when $n$ gets larger. Thus, $J_{CP}$ can
computed as follows:

```
$J_{CP} = \frac{m}{m'}t_{CP} \quad (9.4)$
```
