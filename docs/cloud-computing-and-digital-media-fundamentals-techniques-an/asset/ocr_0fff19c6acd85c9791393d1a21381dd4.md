# 7.2.1.1 Approach Based on Operator Tree

Hall presents a bottom-up heuristic method of using algebraic operator tree (expression tree) to detect the common subexpressions in a single query [12,13]. Specifically, he views the existence of common subexpressions in terms of lattices formed from the expression trees. Considering tree structure, it can be divided into balanced and unbalanced trees to deal with different kind of queries [12]. Identification of the common subexpressions is equivalent to converting a simple query tree to a lattice in which no nodes are redundant. This conversion can be achieved by working from the bottom level of the tree, and the leaves go upward a level at a time, considering all convergences recursively with the pruning operations based on idempotency and null relations.
