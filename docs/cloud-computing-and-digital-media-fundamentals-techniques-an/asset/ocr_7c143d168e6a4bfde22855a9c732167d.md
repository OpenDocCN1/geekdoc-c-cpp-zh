# Main Steps of Automatic Computing H

+   1. Putative correspondences: Matches fit fundamental matrix F.
2. RANSAC robust estimation: Repeat for N samples, where N is predetermined trial or no better F is found.
   a. Select a random sample of four correspondences and compute the homography h using inhomogeneous solution of H.
   b. Use H to apply a new four-point set F and compute the weight of error matches.
   c. If the weight of error matches is smaller than a specific threshold T, then use S' to develop new F.
   d. Choose another new random set F to determine F and repeat the above steps.
   e. Until predetermined trial or no better F is found, stop the step.

# 11.2.4 Computing Track of Matches

In Section 11.2.3, all matches have been refined, and we organize the matches into finding connected sets of matching features across multiple images. For instance, if feature $F(I_1)$ matches feature $F(I_2)$, and $f_2$ matches feature $F(I_3)$ these features will be grouped into a track $\{f_1, f_2, f_3\}$. Tracks are found by examining each feature $f$ in each image and performing a breath-first search of the set of features in other images that match $f$ until an entire component of features has been explored. These features are then grouped together into a track, and the next unvisited feature is considered, until all features have been visited. Because of spurious matches, inconsistencies can arise in tracks; in particular, a track can contain multiple features from the same image, which violates the assumption that a track corresponds to a single 3D point. In the case, the tracks are identified as inconsistent, and any image that observes a track multiple times has all of its features removed from that track.
