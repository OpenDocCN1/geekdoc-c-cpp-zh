The number of music notes equals the positions needed to start the comparison, whereas the number of pitch points represents the length of the sequence required for comparison. In our QBSH system, the scaling factor varies from 0.6 to 1.5 to obtain 31 compressed or stretched versions of the original input vector. The frame size is 256 points with no overlap; the sample rate is 8 kHz, leading to a pitch rate of 31.25 per second.
