## 11.2.3.3 Epipolar Geometry and Fundamental Matrix

The epipolar geometry is the intrinsic projective geometry between two views. It is independent of scene structure, and only depends on the cameras' internal parameters and relative pose. Then the fundamental matrix $F$ encapsulates this intrinsic geometry. It is a $3 \times 3$ matrix of rank 2. For each pair of images, we define the following:

- An epipolar $e,e'$ is the point of intersection of the line joining the camera centers (the baseline)
- An epipolar plane $\pi$ is a plane containing the baseline. There is a one-parameter family of epipolar planes.
- An epipolar line $l,l'$ is the intersection of an epipolar with the image plane. All epipolar lines intersect at the epipole.

The fundamental matrix is the algebraic representation of epipolar geometry. In this part, we derive the fundamental matrix from the mapping between a point and its epipolar line, and then specify the properties of the matrix.

### 11.2.3.1 Algebraic Derivation of F
Two cameras whose projective matrices are $P$ and $P'$ and the relevant images are $I$ and $I'$. $m$ is an image point of $I$ and the ray back-projected from $m$ by $P$ is obtained by solving $PX = m$. Then we have

```
$X(s)=P^*m+sC \quad (11.7)$
```

where:

```
$P^*=P^\top(PP^\top)^{-1}$
$P^*P=1$
```

The epipolar line of $I'$

```
$l^c=e^cm=(P^c)Y[P^c(s)]=(P^c)Y(P^*+sC)=[e^c,P^*m] \quad (11.8)$
```

More briefly, we have $l^c=Fm, where F=[e^c, P\Phi^*]$.
Because $m$ is in the line of $l^c$, we have $m^\top Fm=0$.

### 11.2.3.4 Computing Fundamental Matrix Using Eight-Point Algorithm
In this section, the equations on $F$ generated by point correspondences between two images and their minimal solution are described. Then an algorithm is described for automatically obtaining point correspondences that $F$ may be estimated directly from an image pair.

#### 11.2.3.4.1 Basic Equations
In Section 11.2.3.3, the fundamental matrix is defined by the equation: $m^\top Fm=0$. Given sufficiently many point matches $m^\top$ (at least seven), the equation can be used to compute the unknown matrix $F$. Specifically, the equation corresponds to a pair of points $(x, y, 1)$ and $(x', y', 1)$ is

```
$xf11+xf12+xf13+yf21+yf22+yf23+xf31+yf32+f33=0 \quad (11.9)$
```

The nine-vector made up of the entries of $F$ in row-order is denoted by $f$. From a set of $n$ point matches, we obtain a set of linear equations for the form:

```
$Af=\begin{bmatrix}\tilde{x}_1 & x_1 & y_1 & & x_1 & y_1 & \sim & & & & & & 1. & \tilde{x}_n & y_n & & x_n & y_n & 1\end{bmatrix}f=0 \quad (11.10)$
```

This is a homogeneous set of equations, and $f$ can only be determined to scale. However, if the data are not exact, because of noise in the point coordinates, the rank may be greater than 8 (in fact equal to 9). In this case, one finds a least-squares solution.

#### 11.2.3.4.2 Least-Squares Solution Adding constraint to $F$

```
$$\begin{aligned} \mathbf{m} &= \mathbf{Af} \ \text{subject to} & \mathbf{f} = 1 \end{aligned} (11.11)$$
```

To attain $FUDV^\top$ by applying singular value decomposition (SVD). The solution $F=V$, is the ninth column of $V$. Finally, since the rank of $F$ is 2, the epipolar lines intersect at the same point. However, in Equation 11.10, the matrix we computed has a rank of 3. Then we have to compute $F_p$.

#### 11.2.3.4 Rank 2 Constraint
Then we have the formula:

```
$$\begin{aligned} \mathbf{m} &= \frac{F-F_p}{F_p} \ \text{subject to} & \text{rank} = 2 \end{aligned} (11.12)$$
```

To compute $F_p$, again SVD of $F$ to find $F=U\text{diag}(\mathbf{s}_1, \mathbf{s}_2, \mathbf{s}_3)V^\top$ and $F_p=U\text{diag}(\mathbf{s}_1, \mathbf{s}_2, \mathbf{s}_3)V^\top$.

### 11.2.3.5 Automatic Computation of $F$ Using RANSAC
Since the matching of features are spurious, we cannot determine which points are reliable and which are not. Then we induce RANSAC to help us set up the reliable matches. This part introduces the pipeline of automatic computation of $F$ using RANSAC.

**Pipeline of Automatic Computing $F$**

- 1. **Interest points**: Compute interest points in each image (the SIFT algorithm).
- 2. **Putative correspondences**: Compute a set of interest matches based on proximity and similarity of their neighborhood (the ANN algorithm).
- 3. **RANSAC robust estimation**: Repeat for $N$ samples, where $N$ is determined by predetermined trial or no better $F$ is found.
    - a. Select a random sample of eight correspondences and compute the fundamental matrix $F$ using eight-point algorithm.
    - b. Use $F$ to apply to a new eight-point set and compute the weight of error matches.
    - c. If the weight of error matches is smaller than a threshold $T$, then use $S'$ to develop new $F$.
    - d. Else choose a new set $F$ and repeat the above steps.
    - e. Until trial or no better $F$ is found, stop the process.

### 11.2.3.6 Computing Homography Matrix
In Section 11.2.3.1, we have mentioned that homography matrix $H$ is used for describing the transform of points between two planes. Each point correspondence gives rise to two independent equations in the entries of $H$. Given a set of four point correspondences, we obtain a set of equations $Ah=0$, where $A$ is the matrix of coefficients built from each correspondence, and $h$ is the vector of unknown entries of $H$. We seek a nonzero solution $h$, since the obvious solution $h=0$ is of no interest to us. Since $h$ can only be computed up to scale, we impose the condition $h_1=1$, for example $h_1=1$, which corresponds to $H_1$, and can gain the solution of $h$ as follows:

```
$$\begin{matrix} 0 & 0 & 0 & -x_w & -y_w & x_w & y_w & \hat{E}_w & y_w \end{matrix} \begin{pmatrix} \hat{h}_0 & \hat{h}_1 & \hat{h}_2 & \hat{h}_3 & \hat{h}_4 & \hat{h}_5 & \hat{h}_6 & \hat{h}_7 & \hat{h}_8 & \hat{h}_9 \\ x_w & y_w & 1 & 0 & 0 & 0 & x_w^2 & x_wy_w & y_w^2 \end{pmatrix} = 0 (11.13)$$
```

where:
$\tilde{h}$ is an eight-vector consisting of the first eight components of $h$

Concatenating the equations from four correspondences generates a matrix equation of the form $Mh=b$, where $M$ has eight columns and $b$ is an eight-vector. Such an equation may be solved for $\tilde{h}$ using standard techniques for solving linear equation (such as Gaussian elimination) in the case where $M$ contains just eight rows, or by least-squares techniques in the case of an overdetermined set of equations.

### 11.2.3.7 Automatic Computation of a Homography Using RANSAC
Similar to the procedure of computing $F$, we use RANSAC paradigm to help us select the best matching. The main steps of automatic computing $H$ are listed below:

**Main Steps of Automatic Computing H**

- 1. **Putative correspondences**: Matches fit fundamental matrix $F$.
- 2. **RANSAC robust estimation**: Repeat for $N$ samples, where $N$ is predetermined trial or no better $F$ is found.
    - a. Select a random sample of four correspondences and compute the homography $h$ using inhomogeneous solution of $H$.
    - b. Use $H$ to apply a new four-point set $F$ and compute the weight of error matches.
    - c. If the weight of error matches is smaller than a threshold $T$, then use $S'$ to develop new $F$.
    - d. Choose another new random set $F$ to determine $F$ and repeat the above steps.
    - e. Until trial or no better $F$ is found, stop the step.
