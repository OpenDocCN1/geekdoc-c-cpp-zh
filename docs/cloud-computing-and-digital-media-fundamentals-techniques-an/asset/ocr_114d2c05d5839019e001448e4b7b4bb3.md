In order to study the probability distribution of t_{err}, we calculate the differences between the measured transcoding time and the value from the fitting curve for each segment. We then normalize the time error compared to the calculated value to show the percentage of time error.
```
$prob (x_t) \sim \frac{1}{\hat{\mu}}^k} \frac{\hat{\mu}}^k}{\Gamma(k)} x_t^{k-1} e^{-(x_t/\hat{\mu})}$
```

- \theta = 3
