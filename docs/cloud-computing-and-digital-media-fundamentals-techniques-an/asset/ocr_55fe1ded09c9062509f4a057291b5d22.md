
The event handler is invoked when a user starts a computation of the game tree tasks. The select function is invoked once the worker is available. In the select function, the worker implements the policies of the next node to be evaluated in the game tree. After some node is selected, the pre-update is invoked to perform the necessary preparation for execution. The execute function performs the main functions of the game tree search task. Finally, the update function is invoked when the execute function finishes.

To summarize, developing a game tree search application, developers simply inherit the base, BaseJobLevelAlgorithm, and override the abstract functions as listed in Table 10.2.
