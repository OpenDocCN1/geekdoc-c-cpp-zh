MATLAB® for estimating the video transcoding time. The coefficients of the fitting curve are as follows:

> [0.0003187817297691053, 0.10858758089453366]

The estimated video transcoding time can be represented as

```
$t_{cal} = 0.0003 \times t_{dur} + 0.1086$
```

where:

$t_{dur}$ is the video duration
$t_{cal}$ is the calculated time

Observed from Figure 5.4, given the duration of a segment, the actual transcoding time is biased to the estimated value calculated from the fitting curve, which is referred to as $t_{err}$. The actual video transcoding time (denoted as $t_{est}$) is then

```
$t_{est} = t_{cal} + t_{err}$
```
