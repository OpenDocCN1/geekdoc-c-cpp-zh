# 4.4 METHODS OF QBEE

QBEE (or AFP) is a fast, convenient, and noise robust method for MIR based on an exact but noisy music clip. Figure 4.12 shows the block diagram of a QBEE. In the offline stage, each song in the database is converted into a spectrogram, where peaks are selected. One approach, as proposed by Ellis [9], is to create an energy threshold based on local maxima. Thus, a peak is considered salient if it is equal to the energy threshold, as shown in Figure 4.13, where solid line is the threshold, and dots are local peaks. In the online stage, the same process is applied to the query. If the time difference is≤1 frame, it is called a matched landmark. A song with more matched landmarks will have a higher score since it is more likely to be the desired song. Once the scores of each song are obtained, we could rank the top-k songs and return a ranked list as the final output of the QBEE system.
