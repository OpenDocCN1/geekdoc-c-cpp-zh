# THEOREM 3: P computed with Algorithm 9.4 is optimal.

PROOF: First we prove that Algorithm 9.4 finds the entity eopt with the minimum weight. Lines 5–8 in the algorithm guarantees this property. E contains only entities of minimum weight, which are sufficient to cover all m BQs and n variables. Thus, when k increases to n, the first e in E is the entity with the minimum weight.

Now we prove that the computed P is optimal. Since we already found the optimal entity e_opt, if e_opt's weight is D ∉(e_opt, P) P would only contain 1 Mjoin that joins all BQs in one step (lines 16–19); otherwise, e_opt's weight is derived from his parents, which would have been added to P (line 13–15). Iteratively, P contains all the necessary entities (equivalent to MRJs) to compute eopt, and the longest path of P is just e_opt's weight, which is already the optimal.
