The ensuing MCA analysis is based on the square matrix B=YᵀY, called the Burt matrix, whose dimensions are (|F| + |C|)×(|F| + |C|) and the elements are denoted as bₛij. Let n be the grand total of the Burt matrix, M = B/n the probability matrix derived from B whose elements are zₖ. The M (|F| + |C|)× mass matrix where m₁ⱼ=Sₛij and D the (|F| + |C|)×(|F| + |C|) diagonal mass matrix where d₁₁=m₁₁ and zero otherwise. Since B is symmetric, the solution for the rows and columns is identical, and the analysis stemming from B corresponds to the columns of the indicator matrix.
