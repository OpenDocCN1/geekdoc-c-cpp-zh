## Algorithm 8.3: Model training reduce($mathbf{F}^1_j,\text{list}[\mathbf{F}^j_{\mathcal{C},1,n}])$

1. Allocate Burt matrix $B$ for $\mathbf{F}$ and $\mathbf{C}$, with size $J\times J$, $J=|\mathbf{F}^3|+|\mathbf{C}|$
2. for $[\mathbf{F}^3_{\mathcal{C},1} \in \text{list}[\mathbf{F}^j_{\mathcal{C},1,n}]]$ do // iterate through the list of values
3. let $c=c_j$
4. set $\mathbf{B}[\mathbf{F}^3_{jk}]=\mathbf{B}[\mathbf{F}^3_{jk}]+n$
5. set $\mathbf{B}[\mathbf{C}^3_{jk}]=\mathbf{B}[\mathbf{C}^3_{jk}]+n$
6. set $\mathbf{B}[c_j]=\mathbf{B}[c_j]+n$
7. set $\mathbf{B}[\mathbf{F}^3_{jk}]=\mathbf{B}[\mathbf{F}^3_{jk}]+n$
8. end for
9. Let $n$ be the total of matrix $\mathbf{Z}=\mathbf{B}/n$
10. Compute the probability matrix $\mathbf{Z}$ mass matrix $\mathbf{M}$
11. Compute the $J\times J$ diagonal matrix $\mathbf{D}$
12. Compute the normalized chi-square distance matrix $\mathbf{A}=\mathbf{D}^{-1/2}(\mathbf{Z}-\mathbf{M}^T\mathbf{M})\mathbf{D}^T)^{1/2}$
13. Perform SVD: $\mathbf{A}=\mathbf{P}\hat{\mathbf{Q}}\mathbf{Q}^T$
14. Project $A$ onto two principal components
15. Compute the similarity between every feature value and class label $\mathbf{W}^3=\mathbf{w}_{k,l}^3|k\in|\mathbf{F}^3|,l\in|\mathbf{C}|$, where $\mathbf{w}_{k,l}^3$ is the inner product of $\mathbf{F}^2$ and $\mathbf{C}^2$ in the projected matrix $\mathbf{A}$
16. Output $\mathbf{F}^T_j\mathbf{W}^3$

## 8.5 EXPERIMENTS AND RESULTS

To evaluate the proposed D-MCA classification framework, we conducted experiments that assess scalability of system and compared it to the S-MCA. In this work, we did not evaluate the accuracy of classification as previous works (Chen et al. 2012; Lin and Shyu 2010; Lin et al. 2008, 2009; Zhu et al. 2013) have already proven the usefulness of MCA for CBIR tasks; instead, our concern in this is scaling MCA to build data environments. The scalability is measured separately on model training and classification tasks, comparing D-MCA with S-MCA. The S-MCA code utilized for the experiments is used in the work of Lin et al. (2008), which is written in Java and utilizes the Weka (Witten et al. 2005) and JAMA libraries (NIST 2012). The D-MCA framework was implemented in Java using Hadoop 1.0.4. Except for Burt matrix, steps 9–16 of Algorithm 8.3 were implemented using the S-MCA code.

The dataset utilized in the experiments comes from semantic indexing (SIN) task (Smeaton et al. 2009) of TRECVID 2012 project (Over et al. 2012). We picked one concept that has 262,912 instances and 137,327 test instances. We refer to these datasets as Trainlx and Testlx, respectively. All instances were previously discretized using Weka's minimum description method (MDL) discretization method (Fayyad and Irani 1993). Each instance is represented by a sequential numerical id and 563 low-level features. In addition, the training instances have an extra feature that specifies the class labels. Since a few hundred thousand records do not make up a significantly large dataset, we created the datasets shown in Table 8.4. An increase factor of k means that we repeated each instance k times.

The cluster on which the D-MCA was executed consists of 10 nodes that allow the execution of MR tasks simultaneously, considering the number of CPU cores in each node and available main memory.
