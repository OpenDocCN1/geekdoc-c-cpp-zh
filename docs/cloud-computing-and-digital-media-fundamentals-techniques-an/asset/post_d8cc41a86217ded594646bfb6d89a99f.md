## 10.6 CONCLUSIONS

We develop the desktop grids with the push-mode streaming infrastructure in order to support tightly coupled task control. The push-mode streaming communication can significantly reduce the redundant computations as tree nodes can be generated and pruned in a timely manner. This report depicts the requirements of the dynamic tree search applications and discusses how the JL model can be applied to fit the requirements. The users have reported successful results in rapid development of efficient game tree search applications for the desktop grid platform.
