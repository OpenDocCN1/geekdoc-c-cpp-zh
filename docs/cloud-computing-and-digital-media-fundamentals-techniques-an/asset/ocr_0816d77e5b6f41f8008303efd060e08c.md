FIGURE 11.7 Triangulation from two image points $x$ and $x'$.

```
$\begin{aligned} x^T(P^{TR}x) - (p^{TR}x) = 0 \ y^T(P^{TR}x) - (p^{TR}x) = 0 \ x^T(p^{TR}x) - y(p^{TR}x) = 0 \end{aligned}$ $ (11.16)
```

$P^{TR}$ are the rows of $P$. Only two of the equations are linear independent. Then we combine the two equations derived from $x^T PX=0$; an equation of the form $AX = 0$ can then be composed, with:

```
$\begin{aligned} E p^{TR} - P^{TR} \ yP^{TR} - P^{TR} \ A = xP^{TR} - bp^{TR} \ yP^{TR} - bp^{TR} \end{aligned}$ $ (11.17)
```

This is a redundant set of equations, since the solution is determined only up to scale. Obviously, $A$ has rank 3, and thus has a 1D null space that provides a solution for $X$.
