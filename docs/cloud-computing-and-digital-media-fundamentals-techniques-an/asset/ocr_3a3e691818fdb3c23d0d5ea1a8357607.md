**THEOREM 2:** To partition a hypercube $S$, the Hilbert space-filling curve is achieved a perfect partition function $f$.

PROOF: The minimum value of score function defined in Equation 9.7 is achieved when the following condition holds:

```
$$\bar{A}_{u=1}^{R_i} Cnt(r_{i,u}^j\mathcal{C}) = \bar{A}_{u=1}^{R_j} Cnt(r_{j,u}^i\mathcal{C}) \quad 1 \neq i, j \neq n \quad (9.8)$
```

In other words, in a partition component $c$, assume the number of records relation from $R_i$. The duplication factor of $R_j$ in this component must be $P_{\frac{1}{2},j,R_i}c(R_j)$. Since Hilbert space-filling curve defines a traversing sequence of every cell in the hypercube of $R_i$, $\mathcal{R}_n$, if we use a Hilbert curve $H$ as a partition method, then a partition $c$ is actually a continuous segment of $H$. Considering the construction process of $H$, every dimension is recursively divided by the factor of 2, and such recursive computation occurs the same number of times for all dimensions. Note that $H$ defines a traversing sequence that traverses cells along each dimension fairly, meaning if $H$ has traversed half of $R_i$, then $H$ must also traversed half of $R_j$, where $R_j$ is any other relation. Thus, any partition value (equal to the number of Reduce tasks) $k_r$, a segment of $H$ of length $|H|/k_n$ traverses the same proportion of records from each dimension.
