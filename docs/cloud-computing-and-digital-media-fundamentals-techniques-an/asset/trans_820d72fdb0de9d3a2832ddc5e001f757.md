## 10.6 结论

我们开发了具有流式基础设施的桌面网格以支持耦合的任务控制。流式通信可以显著减少冗余计算。本文描述了动态树搜索应用程序的需求，并讨论了 JL 模型如何适应这些需求。用户在桌面网格平台的高效游戏树应用程序开发方面取得了成功。
