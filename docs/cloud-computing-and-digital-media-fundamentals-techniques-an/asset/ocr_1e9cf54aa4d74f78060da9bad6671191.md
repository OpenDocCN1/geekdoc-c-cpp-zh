# 10.4.4.2 Worker Management

The worker selection commands consist of the instructions used to query the status of a specified worker. The selection conditions can be categorized into two types: the pattern of id/name or the pattern of hardware specification. The conjunction and disjunction of several clauses are also supported.

10.4.4.2.1 WALIVE and WCLOSE A user periodically sends WALIVE message to notify the broker the availability of this user. Also, the user sends a WCLOSE message to the broker upon termination of the user application. Figure 10.6 illustrates the WALIVE message between a worker and the broker.
