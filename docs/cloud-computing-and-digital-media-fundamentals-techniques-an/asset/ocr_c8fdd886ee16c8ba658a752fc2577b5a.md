Compared to these techniques, the significant difference of our study on the execution model of a set of MRJs is that our work takes the number of available processing units into consideration. Therefore, the optimization problem we study is orthogonal to the techniques proposed in the existing literatures we mentioned earlier.

Given $T$ and $k_p$, we concern processing units, the execution plan that guarantees the minimum task execution time order is usually subjected to $k_p$. For instance, the determination of $T$ in Figure 9.5 $M R(e_i)$, $M R(e_j)$, and $M R(e_k)$ can be accomplished in 5, 7, and 9 if units are, 4, and 8 tasks are assigned to them, respectively. Thus, if there are over 16 available processing units, these three MRJs can be scheduled to run in parallel and with no computing competition. On the contrary, if there are not enough processing units, parallel execution of MRJs can lead to very poor time efficiency. It is exactly the classic problem of scheduling independent malleable parallel tasks over bounded parallel processors, which is NP-hard [27]. In this work, we adopt the methodology presented in Reference 27. The method guarantees that for any given $\varepsilon > 0$, it takes linear (in terms of $[T]$, $k_{ps}$ and $\varepsilon^{-1}$) to compute a schedule that promises the evaluation time is at most $(1 + \varepsilon)$ times the scheduling one.
