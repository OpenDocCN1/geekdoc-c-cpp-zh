S-MCA was run in one of the nodes of the cluster. Moreover, in the following experiments, the number of reduce tasks was set to five.
The first experiment compares the training time in seconds between S-MCA and D-MCA as we increase the size of the training set. Figure 8.3 shows the results in a $\log_2$ scale. As expected, the training times increase linearly as we duplicate the size of the training datasets. Two observations can be drawn from Figure 8.3. First, the training times for S-MCA stop at Train16x. This fact supports our claim that S-MCA is not suitable for big data environments as it has to manipulate all the training data in the memory.
