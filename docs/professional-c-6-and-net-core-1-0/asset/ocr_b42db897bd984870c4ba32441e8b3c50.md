The `CommandActions` class defines simple methods `Echo` and `Reverse` that return the action string or return the string reversed (code file `TcpServer/CommandActions.cs`):

```
public class CommandActions
{
    public string Reverse(string action) => string.Join("",
action.Reverse());

    public string Echo(string action) => action;
}
```
