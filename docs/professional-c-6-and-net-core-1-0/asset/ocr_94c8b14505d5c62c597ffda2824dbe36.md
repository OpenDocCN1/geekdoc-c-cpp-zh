In such simple scenarios, just combining some strings with a `MultiBinding` doesn’t require an implementation of `IMultiValueConverter`. Instead, a definition for a format string is adequate, as shown in the following XAML code snippet. The string format defined with the `MultiBinding` first needs a {} prefix. With XAML the curly brackets usually define a markup expression. Using {} as a prefix escapes this and defines that no markup expression, but instead a normal string, follows. The sample specifies that both Binding elements are separated by a comma and a blank (code file `MultiBindingSample/MainWindow.xaml`):

<TextBox>

            <Binding Path="FirstName" />
        </MultiBinding>
    </TextBox.Text>
</TextBox>
