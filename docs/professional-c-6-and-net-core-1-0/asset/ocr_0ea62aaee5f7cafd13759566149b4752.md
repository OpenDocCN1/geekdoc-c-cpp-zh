With this window you can see all the properties of an item and configure it accordingly. You can change some properties by entering text in a text box; others have predefined selections, and some have a custom editor. You can also add event handlers to events with the Properties window.

With UWP and WPF applications, the Properties window looks very different, as you can see in Figure 17.28.
