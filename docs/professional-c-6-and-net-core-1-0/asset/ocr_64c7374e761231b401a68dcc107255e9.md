# Accessing the Content

The previous code snippets have shown you how to access the Content property to retrieve a string. The Content property in the response returns an HttpContent object. In order to get the data from the HttpContent object you need to use one of the methods supplied. In the example, the ReadAsStringAsync method was used. It returns a string representation of the content. As the name implies, this is an async call. Instead of using the async keyword, the Result property could be used as well. Calling the Result property blocks the call until it's finished and then continues on with execution.
