JSON schema file should be generated. The default URL that you can configure with UseSwaggerGen is /swagger/{version}/swagger.json. With the document configured in the previous code snippet, the URL is /swagger/v1/swagger.json. The method UseSwaggerUi defines the URL for the Swagger user interface. Using the method without arguments, the URL is swagger/ui, but of course you can change this URL by using a different overload of the UseSwaggerUi method:

```
public void Configure(IApplicationBuilder app,
IHostingEnvironment env,
    ILoggerFactory loggerFactory)
{
    loggerFactory.AddConsole(Configuration.GetSection("Logging"));
    loggerFactory.AddDebug();

    app.UseIISPlatformHandler();
    app.UseStaticFiles();
    app.UseMvc();

    app.UseSwaggerGen();
    app.UseSwaggerUi();
}
```
