If you select this option, a new project is added, so the ConsoleApp1 solution now contains a console application and a WPF application.

> NOTE In accordance with Visual Studio’s language independence, the new project does not need to be a C# project. It is perfectly acceptable to put a C# project, a Visual Basic project, and a C++ project in the same solution. We will stick with C# here because this is a C# book!

Of course, this means that ConsoleApp1 is not really an appropriate name for the solution anymore.
