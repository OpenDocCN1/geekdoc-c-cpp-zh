Within the view page, the section keyword defines the section. The position where the section is placed is completely independent from the other content. The view doesn’t define the position within the page; this is defined by the layout (code file MVC Sample App/Views/ViewsDemo/LayoutUsingSections.cshtml):

```
{
	ViewBag.Title = "Layout Using Sections";
}
<h2>Layout Using Sections</h2>
Main content here
@section PageNavigation
{
	<div>Navigation defined from the view</div>
	<ul>
		<li>Nav1</li>
		<li>Nav2</li>
	</ul>
}
```
