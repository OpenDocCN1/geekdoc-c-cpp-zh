# Writing Custom Events

You can also define your own telemetry information that should be written to the cloud service. To write custom telemetry data, you need to instantiate a TelemetryClient object. This class is thread safe, so you can use an instance from multiple threads. Here, the method OnAction is changed to write event information that call TrackEvent. You can invoke TrackEvent either by passing an event name, optional properties, and metrics or by passing an object of type EventTelemetry (code file WinAppInsights/MainPage.xaml.cs):

```
private TelemetryClient _telemetry = new TelemetryClient();

private async void OnAction(object sender, RoutedEventArgs e)
{
    _telemetry.TrackEvent("OnAction",
        properties: new Dictionary<string, string>()
        { ["data"] = sampleDataText.Text });
    var dialog = new ContentDialog
    {
        Title ="Sample",
        Content = $"You entered {sampleDataText.Text}",
        PrimaryButtonText ="Ok"
    };
    await dialog.ShowAsync();
}
```

This event information is shown in Figure 20.9. With properties you can pass a dictionary of string objects that is all shown in the cloud portal. Using metrics, you can pass a dictionary of string and double where you can pass any counts that you need to analyze the usage of the app.
