# Sending POST Requests

Let’s send new objects to the service using the HTTP POST request. The HTTP POST request works similarly to the GET request. This request creates a new object server side. The PostAsync method of the HttpClient class requires the object that is added with the second parameter. You use Json.NET’s JsonConvert class to serialize the object to JSON. With a successful return, the Headers.Location property contains a link where the object can be retrieved again from the service.
