The application accepts one command-line argument to pass the name of the server. With this, the method RequestHtmlAsync is invoked to make an HTTP request to the server. It returns a string with the Result property of the Task (code file HttpClientUsingTcp/Program.cs):

```
static void Main(string[] args)
{
    if (args.Length != 1)
    {
        ShowUsage();
    }
    Task<string> t1 = RequestHtmlAsync(args[0]);
    WriteLine(t1.Result);
    ReadLine();
}

private static void ShowUsage()
{
    WriteLine("Usage: HttpClientUsingTcp hostname");
}
```
