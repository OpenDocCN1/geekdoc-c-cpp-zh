# Figure 17.5

In this case, you can see that the drop-down list enables you to target the .NET Frameworks 2.0, 3.0, 3.5, 4, 4.5, 4.5.1, 4.5.2, 4.6, and 4.6.1. You can also install other versions of the .NET Framework by clicking the More Frameworks link. This link opens a website from which you can download other versions of the .NET Framework—for example, 2.0 + 3.5 SP1—but also frameworks for services (Microsoft Azure, OneDrive) and devices (Xamarin).

If you want to change the version of the framework the solution uses, right-click the project and select the properties of the solution. If you are working with a WPF project, you see the dialog shown in Figure 17.6.
