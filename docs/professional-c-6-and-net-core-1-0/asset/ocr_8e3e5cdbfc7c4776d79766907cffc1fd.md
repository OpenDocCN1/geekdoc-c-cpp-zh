For translation, you can also use Microsoft’s translation service. Select the .xlf files in Visual Studio Solution Explorer, and after opening the context menu, select Multilingual App Toolkit ⇨ Generate Machine Translations.

When you open the .xlf files, the Multilingual Editor (see Figure 28.12) is opened. With this tool you can verify the automatic translations and make necessary changes.
