# Figure 44.7

Adding a service reference adds references to the assemblies System.Runtime.Serialization and System.ServiceModel, and it also adds a configuration file containing the binding information and the endpoint address to the service.

From the data contract, the class RoomReservation is generated as a partial class. This class contains all [DataMember] elements of the contract. The class RoomServiceClient is the proxy for the client that contains methods that are defined by the operation contracts. Using this client, you can send a room reservation to the running service.

In the code file
RoomReservation/RoomReservationClient/MainWindow.xaml.cs, the OnReserveRoom method is invoked with the Click event of the button. The ReserveRoomAsync is invoked with the service proxy. The reservation variable receives the data from the UI via data binding.

```
public partial class MainWindow : Window
{
    private RoomReservation _reservation;

    public MainWindow()
    {
        InitializeComponent();
        reservation = new RoomReservation
        {
            StartTime = DateTime.Now,
            EndTime = DateTime.Now.AddHours(1)
        };
        this.DataContext = _reservation;
    }
}
```
