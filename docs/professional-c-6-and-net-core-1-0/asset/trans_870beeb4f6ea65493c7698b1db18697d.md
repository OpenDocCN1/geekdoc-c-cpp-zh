## 地理定位与MapControl

了解用户的位置是应用的一个重要方面，无论是显示地图的应用、显示用户所在区域天气的应用，还是需要决定将用户数据保存到最近的哪个云中心的应用。当应用中使用广告时，用户位置对于显示附近区域的广告（如果有的话）也很重要。

使用UWP应用，你还可以显示地图。在Windows 10中，MapControl作为Windows API的一部分提供，无需使用额外的库（如Bing SDK）即可实现这一点。

示例应用同时使用Geolocator（命名空间Windows.Devices.Geolocation）来提供用户地址信息，以及MapControl（命名空间Windows.UI.Xaml.Controls.Maps）。当然，你可以在应用中独立使用这些类型，而无需相互依赖。

### 使用MapControl

在示例应用中，MainPage中定义了一个MapControl，其不同的属性和事件绑定到通过页面的ViewModel属性访问的MapsViewModel中的值。这样，你可以动态更改应用中的某些设置，并查看MapControl可用的不同功能（代码文件MapSample/MainPage.xaml）：

示例应用在SplitView右侧的Pane中定义了用于配置MapControl的控件，而MapControl定义在SplitView的内容区域中。你可以在第32章中了解更多关于SplitView控件的信息。

在代码隐藏文件中，定义了ViewModel属性，并通过将MapControl传递给构造函数来实例化MapsViewModel。通常最好避免让视图模型直接访问Windows控件，而应仅使用数据绑定来映射。然而，当你使用一些特殊功能（如街景体验）时，直接在MapsViewModel类中使用MapControl会更方便。由于该视图模型类型不做其他事情，而且也只能在Windows设备上使用，因此将MapControl传递给MapsViewModel的构造函数是一种折衷方案（代码文件MapSample/MainPage.xaml.cs）：

			StopStreetView, () => IsStreetView);

			StartStreetViewAsync, () => !IsStreetView);

		{

### 使用Geolocator获取位置信息

接下来，你需要借助Geolocator实例_locator获取用户的实际位置。GetPositionAsync方法通过返回Geoposition实例来返回地理位置。结果被应用到视图模型的CurrentPosition属性，该属性绑定到MapControl的中心（代码文件MapSample/ViewModels/MapsViewModel.cs）：

```
public async void GetCurrentPositionAsync()
{
    try
    {
        Geoposition position = await _locator.GetGeopositionAsync(
            TimeSpan.FromMinutes(5), TimeSpan.FromSeconds(5));
        CurrentPosition = new Geopoint(new BasicGeoposition
        {
            Longitude = position.Coordinate.Point.Position.Longitude,
            Latitude = position.Coordinate.Point.Position.Latitude
        });
    }
    catch (UnauthorizedAccessException ex)
    {
        await new MessageDialog(ex.Message).ShowAsync();
    }
}
```

从`GetGeopositionAsync`返回的`Geoposition`实例列出了`Geolocator`如何得出位置结论的信息：使用手机蜂窝网络、卫星、记录的Wi-Fi网络或IP地址。当你配置`Geolocator`时，可以指定信息的精确度。通过设置`DesiredAccuracyInMeters`属性，你可以定义位置在多少米范围内的精确度。当然，这是你期望的精确度，但可能无法实现。如果需要更精确的位置，可以使用通过访问卫星信息获得的GPS数据。根据所需技术的不同，会消耗更多电量，因此如果不是真正需要，你不应指定这样的精度。如果设备不支持卫星或蜂窝信息，则无法使用这些功能。在这些情况下，你只能使用Wi-Fi网络（如果有）或IP地址。当然，IP地址可能不精确。也许你得到的是IP提供商的定位，而不是用户的。对于我所使用的设备和网络，我获得了64米的精度，位置来源是Wi-Fi，结果非常准确。你可以在图33.14中看到地图。
