# Figure 28.3

To change the current culture, you use the Additional Date, Time, & Regional Settings link in the dialog shown in Figure 28.3. From there, you click the Change Date, Time, or Number Formats option to see the dialog shown in Figure 28.4. The language setting for the format influences the current culture. It is also possible to change the defaults for the number format, the time format, and the date format independent of the culture.
