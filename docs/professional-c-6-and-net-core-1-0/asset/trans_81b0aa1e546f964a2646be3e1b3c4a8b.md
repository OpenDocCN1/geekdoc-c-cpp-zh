## 创建Windows服务程序

本章创建的服务托管一个引文服务器。对于来自客户端的每个请求，引文服务器都会从引文文件中返回一条随机引文。解决方案的第一部分使用三个程序集：一个用于客户端，两个用于服务器。图39.4提供了解决方案的概要。`QuoteServer`程序集承载实际功能。服务将引文文件读入内存缓存，并借助套接字服务器响应引文请求。`QuoteClient`是一个WPF富客户端应用程序。该应用程序创建客户端套接字以与`QuoteServer`通信。第三个程序集是实际的服务。`QuoteService`启动和停止`QuoteServer`；服务控制服务器。

## 创建服务的核心功能

你可以在Windows服务中构建任何功能，例如扫描文件以进行备份或病毒检查，或启动WCF服务器。然而，所有服务程序都有一些相似之处。程序必须能够启动（并返回调用方）、停止和暂停。本节将介绍使用套接字服务器实现此类功能的方式。

在Windows 10中，可将“简单TCP/IP服务”作为Windows组件的一部分进行安装。简单TCP/IP服务中包含一个“每日引文”（qotd）TCP/IP服务器。这个简单的服务监听17号端口，并对每个请求用<windows>\system32\drivers\etc\quotes文件中的一条随机消息作出响应。示例服务将构建一个类似的服务器。与返回ASCII字符串的qotd服务器不同，示例服务器返回Unicode字符串。

首先，创建一个名为QuoteServer的类库，并为服务器实现代码。下面将逐步讲解QuoteServer.cs文件中的QuoteServer类源代码：（代码文件QuoteServer/QuoteServer.cs）：

```
using System;
using System.Collections.Generic;
using System.Diagnostics;
using System.IO;
using System.Linq;
using System.Net;
using System.Net.Sockets;
using System.Text;
using System.Threading.Tasks;
namespace Wrox.ProCSharp.WinServices
{
    public class QuoteServer
    {
        private TcpListener _listener;
        private int _port;
        private string _filename;
        private List<string> _quotes;
        private Random _random;
        private Task _listenerTask;

        public QuoteServer()
            : this ("quotes.txt")
        {
        }
        public QuoteServer(string filename)
            : this (filename, 7890)
        {
        }
        public QuoteServer(string filename, int port)
        {
            if (filename == null) throw new ArgumentNullException(nameof(filename));
            if (port < IPEndPoint.MinPort || port > IPEndPoint.MaxPort)
                throw new ArgumentException("port not valid", nameof(port));

            _filename = filename;
            _port = port;
        }
    }
}
```

ReadQuotes是一个辅助方法，用于从构造函数中指定的文件中读取所有引文。所有引文都被添加到List<string> quotes中。此外，你还要创建一个Random类的实例，用于返回随机引文：

```
protected void ReadQuotes()
{
    try
    {
        _quotes = File.ReadAllLines(_filename).ToList();
        if (_quotes.Count == 0)
        {
            throw new QuoteException("quotes file is empty");
        }
        _random = new Random();
    }
    catch (IOException ex)
    {
        throw new QuoteException("I/O Error", ex);
    }
}
```

另一个辅助方法是GetRandomQuoteOfTheDay。该方法从引文集合中返回一条随机引文：

```
protected string GetRandomQuoteOfTheDay()
{
    int index = _random.Next(0, _quotes.Count);
    return _quotes[index];
}
```

在Start方法中，通过辅助方法ReadQuotes将包含引文的完整文件读入List<string> quotes。之后，启动一个新线程，该线程立即调用Listener方法——这与第25章“网络”中的TcpReceive示例类似。

此处使用任务（task），因为Start方法不能阻塞并等待客户端；它必须立即返回调用方（SCM）。如果方法未能及时（30秒内）返回调用方，SCM将认为启动失败。监听任务是一个长时间运行的后台线程。应用程序可以在不停止该线程的情况下退出：

```
public void Start()
{
    ReadQuotes();
    _listenerTask = Task.Factory.StartNew(Listener, TaskCreationOptions.LongRunning);
}
```

任务函数Listener创建一个TcpListener实例。AcceptSocketAsync方法等待客户端连接。一旦客户端连接，AcceptSocketAsync将返回一个与该客户端关联的套接字。接下来，调用GetRandomQuoteOfTheDay，并使用clientSocket.Send将返回的随机引文发送给客户端：

```
protected async Task ListenerAsync()
{
    try
    {

        IPAddress ipAddress = IPAddress.Any;
        _listener = new TcpListener(ipAddress, _port);
        _listener.Start();
        while (true)
        {
            using (Socket clientSocket = await
        _listener.AcceptSocketAsync())
            {
                string message = GetRandomQuoteOfTheDay();
                var encoder = new UnicodeEncoding();
                byte[] buffer = encoder.GetBytes(message);
                clientSocket.Send(buffer, buffer.Length, 0);
            }
        }
    }
    catch (SocketException ex)
    {
        Trace.TraceError($"QuoteServer {ex.Message}");
        throw new QuoteException("socket error", ex);
    }
}
```

除了Start方法之外，还需要以下方法Stop、Suspend和Resume来控制服务：

```
public void Stop() => _listener.Stop();

public void Suspend() => _listener.Stop();

public void Resume() => Start();
```

另一个公开可用的方法是RefreshQuotes。如果包含引文的文件发生变化，可以使用此方法重新读取该文件：

```
public void RefreshQuotes() => ReadQuotes();
}
}
```

在为服务器构建服务之前，最好先构建一个测试程序，该程序仅创建QuoteServer实例并调用Start。这样，你无需处理与服务相关的问题即可测试功能。你必须手动启动这个测试服务器，并且可以使用调试器轻松地单步执行代码。

测试程序是一个C#控制台应用程序TestQuoteServer。你需要引用QuoteServer类的程序集。创建QuoteServer实例后，将调用QuoteServer实例的Start方法。Start在创建线程后立即返回，因此控制台应用程序会一直运行，直到按下Return键（代码文件TestQuoteServer/Program.cs）：

```
static void Main()
{
    var qs = new QuoteServer("quotes.txt", 4567);
    qs.Start();
    WriteLine("Hit return to exit");
    ReadLine();
    qs.Stop();
}
```

请注意，使用此程序时QuoteServer将在localhost上的4567端口运行——稍后你必须要在客户端中使用这些设置。

## QuoteClient示例

客户端是一个简单的WPF Windows应用程序，你可以在其中向服务器请求引文。该应用程序使用TcpClient类连接到正在运行的服务器，接收返回的消息，并将其显示在文本框中。用户界面包含两个控件：一个Button和一个TextBlock。单击按钮即向服务器请求引文，并显示引文。

对于Button控件，Click事件被分配给方法OnGetQuote，该方法向服务器请求引文；而IsEnabled属性绑定到EnableRequest方法，以便在请求进行期间禁用按钮。对于TextBlock控件，Text属性绑定到Quote属性，以显示所设置的引文（代码文件QuoteClientWPF/MainWindow.xaml）：

```
<Button Margin="3" VerticalAlignment="Stretch" Grid.Row="0" IsEnabled="{Binding EnableRequest, Mode=OneWay}" Click="OnGetQuote"> Get Quote</Button>
<TextBlock Margin="6" Grid.Row="1" TextWrapping="Wrap" Text="{Binding Quote, Mode=OneWay}" />
```
