# UI Testing

For testing the user interface, Visual Studio offers Coded UI Test Project templates for Universal Windows apps, Windows Phone apps, WPF applications, and Windows Forms. When you create a new project, you can find the project template for WPF and Windows Forms in the Test group. However, this template doesn’t work for Windows apps. The project template for Universal Windows apps is in the Universal group. Be aware that automatic recording is not supported for Windows apps.

In this chapter you create a UI test for an MVVM WPF application. This application is part of the downloadable files for this chapter, so you can use it for testing. For the details about this application, read Chapter 31.
