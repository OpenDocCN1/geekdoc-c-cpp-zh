```
class Employee
{
    public Employee(string name, decimal salary)
    {
        Name = name;
        Salary = salary;
    }

    public string Name { get; }
    public decimal Salary { get; private set; }

    public override string ToString() => $"{Name}, {Salary:C}";

    public static bool CompareSalary(Employee e1, Employee e2) =>
        e1.Salary < e2.Salary;
}
```

Note that to match the signature of the Func<T, T, bool> delegate, you have to define CompareSalary in this class as taking two Employee references and returning a Boolean. In the implementation, the comparison based on salary is performed.
