# Creating Tasks

Let’s start with the synchronous method `Greeting`, which takes a while before returning a string (code file `Foundations/Program.cs`):

```
```csharp
static string Greeting(string name)
{
    Task.Delay(3000).Wait();
    return $"Hello, {name}";
}
```
```

To make such a method asynchronously, you define the method `GreetingAsync`. The task-based asynchronous pattern specifies that an asynchronous method is named with the `Async` suffix and returns a task. `GreetingAsync` is defined to have the same input parameters as the `Greeting` method but returns `Task<string>`. `Task<string>`, which defines a task that returns a string in the future. A simple way to return a task is by using the `Task.Run` method. The generic version `Task.Run<string>()` creates a task that returns a string:

```
```csharp
static Task<string> GreetingAsync(string name)
{
    return Task.Run<string>(() =>
    {
        return Greeting(name);
    });
}
```
```
