# Expecting Exceptions with MSTest

When invoking the constructor of the StringSample class and calling the method GetStringDemo with null, an ArgumentNullException is expected. You can easily check exceptions with testing code: apply the ExpectedException attribute to the test method as shown in the following example. This way, the test method succeeds with the exception (code file UnitTestingSamplesTests/StringSampleTests.cs):

```
[TestMethod]
[ExpectedException(typeof(ArgumentNullException))]
public void TestStringSampleNull()
{
    var sample = new StringSample(null);
}
```

You can deal with the exception thrown by the GetStringDemo method in a similar way.
