With the Main method, a Barrier instance is created. In the constructor, you can specify the number of participants. In the example, this number is 3 (numberTasks + 1) because there are two created tasks, and the Main method is a participant as well. Using Task.Run, two tasks are created to fork the iteration through the collection into two parts. After starting the tasks, using SignalAndWait, the main method signals its completion and waits until all remaining participants either signal their completion or remove themselves as participants from the barrier. As soon as all participants are ready with one iteration, the results from the tasks are zipped together with the Zip extension method. Then the next iteration is done to wait for the next results from the tasks:
