With the release of .NET 4.6—and with .NET Core 1.0—the class `EventSource` was extended and simplified to allow instantiating and using it without the need to derive a class. This makes it simpler to use it with small scenarios.

The first example for using `EventSource` shows a simple case. `EventSource` is instantiated as a static member of the `Program` class with a Console Application (Package) project. With the constructor, the name of the event source is specified (code file `SimpleEventSourceSample/Program.cs`):

```
private static EventSource sampleEventSource =
    new EventSource("Wrox-EventSourceSample1");
```

With the `Main` method of the `Program` class, the unique identifier of the event source is retrieved using the `Guid` property. This identifier is created based on the name of the event source. After this, the first event is written to invoke the `Write` method of `EventSource`. The parameter required is the event name that needs to be passed. Other parameters are available with overloads of the object. The second parameter that is passed is an anonymous object defining the `Info` property.
