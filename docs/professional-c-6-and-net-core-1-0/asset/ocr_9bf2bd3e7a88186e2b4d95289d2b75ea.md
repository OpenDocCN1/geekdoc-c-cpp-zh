The heart of the Syntax API is the SyntaxTree class. A SyntaxTree object is created by parsing the C# file content using CSharpSyntaxTree.ParseText. To get the nodes from the tree, the GetRootAsync (or GetRoot) method returns the root node. All the nodes are of a class derived from the base class SyntaxNode.
