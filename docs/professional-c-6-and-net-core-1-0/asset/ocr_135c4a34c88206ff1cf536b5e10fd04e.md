The CommandBar also allows for secondary commands. In case you need more commands that don’t fit into a line—especially with mobile devices—you can use secondary commands. Secondary commands can be defined assigned to the property SecondaryCommands of the CommandBar element.

```
<CommandBar>
    <CommandBar.SecondaryCommands>
        <AppBarButton Label="One" Icon="OneBar" />
        <AppBarButton Label="Two" Icon="TwoBars" />
        <AppBarButton Label="Three" Icon="ThreeBars" />
        <AppBarButton Label="Four" Icon="FourBars" />
    </CommandBar.SecondaryCommands>
    <!-- etc. -->
```

With Windows 10, secondary commands are opened by clicking on the ellipsis button, as shown in Figure 32.25.
