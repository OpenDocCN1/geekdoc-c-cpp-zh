> **NOTE** *For more on regular expressions, please see Andrew Watt’s Beginning Regular Expressions (John Wiley & Sons, 2005).*

Suppose your application needed to convert U.S. phone numbers to an international format. In the United States, the phone numbers have the format 314-123-1234, which is often written as (314) 123-1234. When converting this national format to an international format, you have to include +1 (the country code of the United States) and add parentheses around the area code: +1 (314) 123-1234. As find-and-replace operations go, that is not too complicated. It would still require some coding effort if you were going to use the `String` class for this purpose (meaning you would have to write your code using the methods available from `System.String`). The regular expressions language enables you to construct a short string that achieves the same result.

This section is intended only as a very simple example, so it concentrates on searching strings to identify certain substrings, not on modifying them.
