In many cases you can work with security from higher abstraction levels. For example, using HTTPS to access a web server, keys for encryption are exchanged behind the scenes. Using WCF, you can define what security algorithm to use by changing a configuration file. With the full .NET stack, the File class offers an Encrypt method (using the NTFS file system) to easily encrypt files. Still it’s important to know what happens behind this functionality.
