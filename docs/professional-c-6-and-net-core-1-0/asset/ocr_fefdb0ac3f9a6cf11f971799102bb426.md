# Encoding

Returning data that has been entered by a user can be dangerous. Let’s do this with the `Content` method. The following method directly returns the data that is passed with the query data string (code file `WebSampleApp/RequestAndResponseSample.cs`):

```
public static string Content(HttpRequest request) =>
    request.Query["data"];
```

Invoking this method using the URL http://localhost:5000/content?data=sample, just the string sample is returned. Using the same method, users can also pass HTML content such as http://localhost:5000/content?data=<h1>Heading 1</h1> What’s the result of this?
