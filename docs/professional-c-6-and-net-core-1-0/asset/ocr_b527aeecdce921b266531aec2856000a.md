# Threading and Services

As stated earlier in this chapter, the SCM assumes that the service failed if the initialization takes too long. To deal with this, you need to create a thread.

The OnStart method in your service class must return in time. If you call a blocking method such as AcceptSocket from the TcpListener class, you need to start a thread to do so. With a networking server that deals with multiple clients, a thread pool is also very useful.
AcceptSocket should receive the call and hand the processing off to another thread from the pool. This way, no one waits for the execution of code and the system seems responsive.
