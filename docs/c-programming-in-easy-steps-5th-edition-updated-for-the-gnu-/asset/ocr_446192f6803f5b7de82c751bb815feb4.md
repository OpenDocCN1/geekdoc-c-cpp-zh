With the %= operator, the first operand a is divided by the second operand b, then the remainder of the operation is assigned to the a variable.

3 Next, in the main function block, output the result of assignment operations performed on the variables

```
printf(" Assigned: \n" );
printf(" Variable a = %d \n", a = 8 );
printf(" Variable b = %d \n", b = 4 );
printf(" Added & assigned: \n" );
printf(" Variable a+=b (8+=4) a= %d \n", a += b );
printf(" Subtracted & assigned: \n" );
printf(" Variable a-=b (12-=4) a= %d \n", a -= b );
printf(" Multiplied & assigned: \n" );
printf(" Variable a*=b (8*=4) a= %d \n", a *= b );
printf(" Divided & assigned: \n" );
printf(" Variable a/=b (32/=4) a= %d \n", a /= b );

printf(" Variable a%%=b (8%%=4) a= %d \n", a %= b );
```
