# C Programming Essentials

The 32 words listed in the table below are the keywords of the C programming language. They have special significance in C programs and may not be used for any other purpose.

| auto | break | case | char |
| const | continue | default | do |
| double | else | enum | extern |
| float | for | goto | if |
| int | long | register | return |
| short | signed | sizeof | static |
| struct | switch | typedef | union |
| unsigned | void | volatile | while |

The table below lists the 14 escape sequences that can be used in C programs to incorporate special non-text characters, which have special significance to the C programming code compiler.

| Sequence: | Significance: | Sequence: | Significance: |
| \n | newline | \\ | backslash |
| \t | tab | \? | question mark |
| \v | vertical tab | \' | single quote |
| \b | backspace | \" | double quote |
| \r | carriage return | \xhh | hexadecimal number |
| \f | form feed | \ooo | octal number |
| \a | audible alert | \0 | null character |
