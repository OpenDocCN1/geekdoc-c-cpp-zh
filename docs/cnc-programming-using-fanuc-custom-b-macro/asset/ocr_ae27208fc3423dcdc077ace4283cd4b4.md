# Workpiece Coordinate System Shift Amount

The workpiece coordinate systems, defined by G54 etc. can be shifted by the desired amounts along the X- and / or Z-axis through the *workpiece shift* screen on a lathe. Such a facility is not available on a milling machine. Press the right extension soft key twice on the offset/setting screen, to get the workpiece shift screen.

Such a shift, which applies to all subsequent operations of the machine until the shift value is changed, is useful for shifting the defined workpiece coordinate system (by the shift amount, in the opposite direction) without changing the offset distances.
