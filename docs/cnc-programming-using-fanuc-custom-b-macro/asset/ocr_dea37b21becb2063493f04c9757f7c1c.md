A more complex example is to calculate the sample standard deviation (σₙ₋₁) of, say, 10 given numbers which are stored in #1 through #10. The mathematical formula is

$$\bar{x}=\frac{\sum x_i}{n}$$

$$\sigma_{n-1}=\sqrt{\frac{\sum(x_i-\bar{x})^2}{n-1}}$$
