correctly in cases of both absolute and incremental modes of the calling program. This would be possible only if this information is available while executing the macro. The system variable #4003 stores 90 or 91 depending on whether absolute or incremental mode is currently active. The macro can read this to have information about the active mode. For example, let us assume that variable #1 of the macro represents the absolute X-axis position, and it gets a value through the argument list of the macro call. Then, to take care of the possible incremental mode of the main program at the time of calling the macro, the following statement in the beginning of the macro would require to be inserted (IF_THEN_statement is described in Chap. 5):

```
~~~
IF [#4003 EQ 91] THEN #1 = #5041 + #1;
~~~
```
