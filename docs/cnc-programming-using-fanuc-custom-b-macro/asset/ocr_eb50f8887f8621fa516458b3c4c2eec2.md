# 7.4  Subprogram Call without Using M98/M198

M98 is the usual method of calling a subprogram. (M198 calls a subprogram stored in an external input/output device, such as Fanuc handy file, connected via the RS-232C port of the machine. Set parameter 0020 to 4 and parameter 0102 to 3 to enable such a subprogram call. If parameter 0020 is set to 4, M198 calls a subprogram stored in the PCMCIA flash memory card, which is the simplest method in newer control versions, as a PCMCIA slot has now become a standard feature of the control. Note that, under the M198, the parameter can also be used for subprogram call, by storing the desired number, chosen from 1 and 255, in parameter 6031. If the stored value is 0, M198 is used.) However, if the macro programming feature is enabled on the machine, it is possible to call up to nine subprograms using certain user-defined M-codes. It is also possible to call a subprogram using a T-code. Note that since subprograms are being called, no arguments can be specified for passing on initial data to the local variables of the called program, as in the case of the M98 call. All the rules, which apply to the M98 call, apply to these call methods also.
