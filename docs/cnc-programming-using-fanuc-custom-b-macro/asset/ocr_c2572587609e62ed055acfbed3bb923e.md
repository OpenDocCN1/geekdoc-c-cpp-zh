+   1. Determine the current tool position (X₁, Y₁, Z₁), through appropriate system variable.
+   2. Find out the XY-coordinates (X₀, Y₀) of the helix axis, using the given formulas.
+   3. Use the specified increment in angle, Δθ, and assign θ = Δθ.
+   4. If θ is greater than 360T, go to step 9.
+   5. Calculate R(θ), X(θ), Y(θ), and Z(θ), using the given formulas.
+   6. Move to the calculated coordinates by G01, with the specified feedrate.
+   7. Increment angle (θ = θ + Δθ).
+   8. Go to step 4.
+   9. Return to the calling program.

Program number 8017 is based on this algorithm, which uses the local variables given in Table 8.2.
