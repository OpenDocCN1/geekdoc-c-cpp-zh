If, as a result of calculations, an arithmetic value (final or intermediate) goes beyond this range, an error condition (which is referred to as an alarm) is generated and the execution stops. In fact, a value lying between −10⁻⁴ and +10⁻⁴ (but not equal to 0) also is not permitted. The associated alarm message is “CALCULATED DATA OVERFLOW” (though this is actually a case of mathematical underflow).
