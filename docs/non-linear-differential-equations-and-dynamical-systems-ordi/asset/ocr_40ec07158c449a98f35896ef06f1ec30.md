# 4.4.12 Exact Solution as a Series of Chebyshev Polynomials

The Chebyshev polynomials of the second kind are defined by (II.5.129b) \equiv (4.259a) implying (4.259b, c):

```
$U_N(\cos \phi) = 2^{1-N} \frac{\sin[(N+1)\phi]}{\sin \phi}, \quad (4.259a)$
```

```
$N = 2n-2m-1: \quad \sin[2(n-m)\phi] = 2^{2n-2m-2} U_{2n-2m-1}(\cos \phi). \quad (4.259b, c)$
```

Substitution of (4.259c) in (4.251) specifies the inverse elliptic sine as a series of Chebyshev polynomials of the second kind:

```
$\arg sin(\phi;q) = A\phi + \sum_{n=1}^{m} \frac{q^{2n}}{(2)}(2n-1)! \sum_{m=0}^{n-1} \frac{(-1)^{n-m}}{(2m)!} \frac{n-m}{m} \times 2^{2n-2m-2} \sin \phi U_{2n-2m-1}(\cos \phi). \quad (4.260)$
```

Using (4.246a; 4.259c) in (4.254a) leads to the equivalent result:

```
$\omega_0\sqrt{1+\gamma} = A\arc \left( \frac{x}{a} + \sum_{n=1}^{m} \left( - \frac{\gamma}{\gamma+1} \right)^n \frac{(2n)!}{(n!)^2} 2^{2n} \right) \sum_{m=0}^{n-1} \frac{(-1)^{n-m}}{n-m m!} \frac{2^{2n-2m-2}}{(2n-m)!} U_{2n-2m-1}\left( \sqrt{\frac{x^2}{a^2}} \right), \quad (4.261)$
```

that specifies (problem 111) in inverse the trajectory of the anharmonic oscillator (4.215a) with bquadratic potential (4.215b) in terms of a Chebyshev polynomial of the second kind (4.259a) using the amplitude $A$ in (4.218b), natural frequency (4.221c), and non-linearity parameter (4.244c). In the linear case $\gamma=0$, only the first term on the r.h.s. of (4.261) remains, leaving to the harmonic oscillator (4.223b) since $A=1$ in (4.256b). The lowest order $O(\gamma)$ non-linear perturbation is considered near concerns: (i) the frequency (subsection 4.4.13); (ii) the amplitude (subsection 4.4.14); and (iii) the generation of harmonics (subsection 4.4.15).
