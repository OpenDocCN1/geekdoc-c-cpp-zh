Conversely, multiplying an inexact differential by a suitable integrating factor may render it exact, and hence lead to the general integral. For example the differential:

```

```

```

```

and leads to the general integral (3.170b) of (3.168). This raises the question of the existence of an integrating factor for an inexact differential in two variables that is proved next (subsection 3.8.4).

## 3.8.4 Existence of Integrating Factor for an Inexact Differential

Any explicit differential equation (3.145b), even if it is inexact, can be put into the form:

```
$\frac{\partial y}{\partial x} = \frac{X(x,y)}{Y(x,y)}, \ (3.171)$
```

It has a solution (3.146c) implying (3.146b) and hence:

```
$\frac{\partial y}{\partial x} = \frac{\partial \Phi / \partial x}{\partial \Phi / \partial y}, \quad (3.172)$
```

Equating (3.171) ≡ (3.172) leads to (3.173a):

```
$\frac{X}{Y} \frac{\partial \Phi / \partial x}{\partial \Phi / \partial y} = \frac{1}{X \partial x} \frac{1}{Y \partial y} \equiv \lambda, \quad (3.173a-c)$
```

that is equivalent to (3.173b); the common ratio (3.173c) is called the **integrating factor** it leads from the inexact (3.174a) to the exact (3.174b) differential:

```
$$\frac{\partial Y}{\partial x}-\frac{\partial X}{\partial y} = \lambda(X dx + Y dy) = \frac{\partial \Phi}{\partial x}dx-\frac{\partial \Phi}{\partial y}dy = d\Phi..$ (3.174a, b)$$
```

It follows that the inexact (3.174a) differential (3.145b), has an integrating factor $\lambda$ satisfying (3.173b, c) that leads to multiplication by an exact differential (3.174b), it could be argued that since differential (3.145b) involves two functions (X, Y): (i) a single function $\Phi$ cannot lead to an exact differential, unless the integrating condition (3.148c) is satisfied; and (ii) two functions $(\lambda, \Phi$) could lead to an exact differential (3.174b), as has just been, and in addition there are infinitely many choices of $\lambda$, as shown next (subsections 3.8.5–3.8.6).

## 3.8.6 Infinitely Many Integrating Factors

The integrating factor $\lambda$ for a general inexact differential (3.145b) is a function $\lambda(x,y)$ that is not unique. For example, substituting (3.178a) in (3.176b) leads to (3.178b):

```
$$\lambda = \mu\Phi; \quad \frac{\partial Y}{\partial x}-\frac{\partial X}{\partial y}+\left(Y\frac{\partial}{\partial x}-X\frac{\partial}{\partial y}\right)\log\mu = \left(X\frac{\partial}{\partial x}-Y\frac{\partial}{\partial x}\right)\log\Phi; \quad (3.178a, b)$$
```

from (3.173a) $\mu$ is (3.179a) if the r.h.s. of (3.17b) vanishes, leading to

```
$$\frac{\partial \Phi}{\partial x}=X\frac{\partial \Phi}{\partial y}; \quad \left(Y\frac{\partial}{\partial x}-X\frac{\partial}{\partial y}\right)\log\mu = 0, \quad (3.179a, b)$$
```

that proves that $\mu$ is also an integrating factor that satisfies (3.176b). ```
$G \in D(R); \quad\quad\quad\quad\quad\lambda = \mu G(\Phi). \quad\quad (3.180a, b)$

The latter result follows from one of the statements: (i) if (3.148c) is a solution of the inexact differential (3.145b), then (3.181a) is also a solution:
