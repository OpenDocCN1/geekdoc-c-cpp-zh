# 3.5.2 Solution by Two Quadratures if One Particular Integral Is Known

A first-order non-linear differential equation for which no general solution is the Riccati (1724) – D'Alembert (1763):

```
$y' = Ry^2 + P(x)y + Q(x). \quad (3.58)$
```

For $R=0$ it reduces to the forced linear differential equation (3.27), whose complete integral is (3.20a; 3.31a, b); for $Q=0$ it is a particular quadratic case (3.44a, b) of Bernoulli's equation (3.38), also solvable (3.44c–e). For the example $y'=x^2$ has no elementary solution. The general integral $y$ of the Riccati equation (3.58) can be determined if at least one particular integral $y_1$ is known (3.59a):

```
$Q + Py_1 + Ry_1^2 - y'_1 = 0; \quad y = y_1 + \frac{1}{v},\quad (3.59a, b)$
```
