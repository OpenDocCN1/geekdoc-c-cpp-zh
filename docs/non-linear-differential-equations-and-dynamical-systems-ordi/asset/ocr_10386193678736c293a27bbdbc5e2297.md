# 4.7.14 Periods of the Circulatory and Oscillatory Motions

The period of the circulatory motion is (4.393a) twice the time taken to travel from $\theta=0$ to $	heta = \pi$, or (4.391a) from $\psi = 0$ to $\psi = \pi/2$ leading to (4.399a, b):

```
$\tau_1 = 2f(\pi) = \frac{4}{\dot{	heta}_0} \int_0^{\pi/2} |1 - \frac{1}{q^2} \sin^2 \psi| d\psi $\quad (4.399a-d)$
```

```
$\frac{4}{\dot{	heta}_0^2} \sum_{n=1}^{\infty} (\frac{1}{2q})^n \frac{(2n-1)!!}{(2n)!!}\frac{1}{(n!)^2} = \frac{2\pi}{\dot{	heta}_0} A(\frac{1}{q}),$
```

where (4.392a) [4.252b] were used in (4.399c) [4.399d]. The function $A(q^{-1})$ has power series (4.252b) with coefficients (4.400b):

```
$A(\frac{1}{q}) = 1 + \sum_{n=1}^{\infty} (a_n q^{-n})^2, \quad a_n = \frac{(2n)!}{(n!)^2} 2^{-2n}.$ (4.400b, b)
```

The coefficients are given by (4.400b) = (4.400d) = (4.400e):

```
$a_n = \frac{2n(2n-1)(2n-2)...3.2.1}{[2n(2n-2)(2n-4)...6.4.2]}$ (4.400c-e)
```

```
$\frac{(2n-1)(2n-3)...3.1}{2n(2n-2)...4.2} = \frac{(2n-1)!!}{(2n)!!}$
```

in agreement with (4.400b-e) = (4.248a, b) = (II.66a, b) = (II.657a-d). The oscillatory motion has amplitude (4.382b, 4.392a = 4.401a) corresponding (4.394a) to (4.401b) and hence (4.401c):

```
$\sin\theta_{max} = \frac{|\dot{	heta}_0|}{2\omega_0} q; \sin\varphi_{max} = \frac{1}{q} \sin\theta_{max} = 1, \quad \varphi_{max} = \pi/2.$ (4.401a-c)
```
