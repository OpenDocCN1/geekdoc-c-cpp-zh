# 4.6.7 Amplitude Jumps and Suppression of Oscillations

The amplitude equation (4.324b) with the approximation (4.325a) can be factorized (4.325b):

```
$\varepsilon^2 <<\omega_0^2 b^4 \psi^2; \quad 0 = b^2 \left[\omega_0 b^4 \psi^2 - 2\omega_0 \varepsilon b^2 \psi + \lambda^2 - \left[\frac{\alpha |f_a|}{6\omega_0}\right]^2\right], \quad (4.325a, b)$
```

that has three roots for $b^2$: (i) the zero root (4.326a), the roots (4.326b, c):

```
$b_0 = 0, \quad (b_{\pm})^2 = \frac{1}{\omega_0 \psi} \left[\varepsilon \pm \left[\frac{\alpha |f_a|}{6\omega_0^3}\right]^2 - \lambda^2\right], \quad (4.326a–c)$
```

