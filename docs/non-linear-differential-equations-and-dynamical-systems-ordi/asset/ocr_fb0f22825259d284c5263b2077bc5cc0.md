# 3.1.5 Double Points of Quadratic Differential Equation

A first-order differential equation is explicit if it can be solved for the slope (3.9a), and is of degree M if it is a polynomial of the derivatives (3.9b):

```
$y' = f(x,y), \quad \prod_{m=1}^{M} [y' - f_m(x,y)] = 0. \quad (3.9a, b)
```

A simple case of quadratic differential equation is (3.10a):

```
$0 = y'^2 - [f_+(x) + f_-(x)]y' + f_+(x)f_-(x) = [y' - f_+(x)][y' - f_-(x)], \quad (3.10a)
```
