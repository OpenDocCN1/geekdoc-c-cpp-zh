# 3.5.3 Solution by One Quadrature if Two Particular Integrals Are Known

If a second linearly independent particular integral $y_2$ of the Riccati differential equation is available (3.73a), one quadrature can be dispensed (standard LVI). Knowledge of two particular integrals (3.59a; 3.73a) specifies (3.59b) = (3.73b), a function $v_1$ satisfying (3.61) = (3.73c):

```
$Q+Py_2+Ry_2^2-y_2'=0;\quad y_2-y_1=\frac{1}{v_1}\quad 0=R+(P+2y_1R)v_1+v_1'$.
```

(3.73a-c)

The general integral of the Riccati equation is sought in the form (3.74a):

```
$y=y_1+\frac{1}{v_1}u,\quad\quad v=v_1u$,
```

(3.74a, b)

that is equivalent by (3.59b) to (3.7b). Substituting into (3.61) and using (3.73c) leads to:

```
$0=R+\{(P+2y_1R)v_1+v_1'\}u+v_1u'=R(1-u)+v_1u'$.
```

(3.74c)

The latter, (3.74c), is a separable (3.11b) differential equation:

```
$$\frac{du}{u-1}=\frac{R}{v_1}dx,\quad\log[u(x)-1]=\log C+\int^x\frac{R(\xi)}{v_1(\xi)}d\xi$,
```

(3.75a, b)

```
$u(x)-1=C\exp\left{\int^x\frac{R(\xi)}{v_1(\xi)}d\xi\right\}=CS(x)$;
```

(3.75c)

in (3.75c) the following function (3.73b) appears:

```
$S(x)=\exp\left{\int^xR(\xi)[y_2(\xi)-y_1(\xi)]d\xi\right)$,
```

(3.76)

using (3.73b). Substitution of (3.75c) and (3.74a) gives:

```
$y(x)=y_1(x)+\frac{y_2(x)-y_1(x)}{1+CS(x)}$,
```

(3.77)

as the general integral of Riccati's equation, if two particular integrals (3.59a; 3.73a) of the standard LVI Riccati equation (3.58) are known, the general integral can be obtained from (3.77) by one quadrature (3.76).
