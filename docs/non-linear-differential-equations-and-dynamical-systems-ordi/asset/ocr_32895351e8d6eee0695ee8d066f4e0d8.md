# **NOTE 3.4: Integrating Factor for a Differential in N Variables**

The first-order differential in N variables (3.274a, b) will have a family of integrating hypersurfaces (3.274c) orthogonal to the vector field of coefficients if an an integrating factor (3.274d) exists. If the function has continuous second-order derivatives (3.277a), substitution of (3.274d) in (3.277b) leads to (3.281a):

```
$\frac{\partial}{\partial x_n}(\lambda X_m) = \frac{\partial}{\partial x_m}(\lambda X_n); \quad \lambda \frac{\partial X_m}{\partial x_n} + X_m \frac{\partial \lambda}{\partial x_n} = \lambda \frac{\partial X_n}{\partial x_m} - X_n \frac{\partial \lambda}{\partial x_m}, \quad (3.281a, b)$
```

that is, (3.281a) = (3.281b), the set of equations specifying the integrating factor if it exists. The integrating factor is specified by (3.281b), leading to the integrity condition:

```
$0 = X_s(\frac{\partial X_m}{\partial x_m} - \frac{\partial X_m}{\partial x_s}) + X_m(\frac{\partial X_n}{\partial x_n} - \frac{\partial X_n}{\partial x_m}) + X_n(\frac{\partial X_s}{\partial x_s} - \frac{\partial X_s}{\partial x_n}) = H_{mns}. \quad (3.282)$
```

The conditions (3.282) are skew-symmetric in (m, n, s) and simplify to zero helicity (3.234c) = (3.235) in the three-dimensional case N=3. In N-dimensions the helicity is a vector, with tensor trivector that is skew-symmetric relative to any pair (note 3.8). It has been shown that the first-order differential in N variables (3.278b), with continuously differentiable of coefficients (3.278a) = (3.283a) is exact if the curl is not zero (3.283b):

```
$X_m \in C^1(|\mathbb{R}^N|); \quad \Omega_{mn} = \frac{\partial X_n}{\partial x_m} - \frac{\partial X_m}{\partial x_n} \neq 0, \ \quad (3.283a, b)$
```

but has an integrating factor (3.274d) = (3.284b) specified if the integrity conditions (3.282) = (3.284a) are met stating that the helicity is:

```
$H_{mns} = \sum_{m,n,s} \Omega_{mn} X_s = 0 \iff 0 = \lambda X_n dx_n = d\Phi \iff \Phi(x_n) = C; \quad (3.284a-c)$
```
