# 4.8.1 Physical, Phase, and Parameter Spaces

A second-order dynamical system has several equivalent representations in different spaces, and may include one (more) parameter(s) q. The trajectory in the physical space (x, y) is specified by (4.1a, b) = (4.426a, b) the two components of the velocity of a system of coupled first-order differential equations:

```
$$\frac{dx}{dt}=\dot{x}(x,y;t);$\quad \frac{dy}{dt}=\dot{y}(x,y;t);$\quad (4.426a, b)$
```

choosing an initial position (4.426c, d) at time $t_0$ leads to the trajectory (4.426e, f) for all time:

```
$x_0\equiv x(t_0),y_0\equiv y(t_0);\quad x\equiv x(t_0,y_0;q);\quad y\equiv y(t_0,y_0;q);\quad (4.426c–f)$
```

Solving (4.426a) for $y$ leads to (4.427a) and substitution in (4.426b) leads to a single second-order differential equation (4.427b) for the dependent variable x:

```
$y\equiv y(x,\dot{x};t;q)=\quad F(x,\dot{x};t;q)=0,\quad (4.427a, b)$
```

and likewise for $y$; choosing an initial position (4.427c) and velocity (4.427d) at time $t_0$ leads from (4.427b) to the trajectory (4.427e) for all time:

```
$x_0\equiv x(t_0),\dot{x}_0\equiv\dot{x}(t_0);\quad x\equiv x(t_0,x_0;q);\quad (4.427c–e)$
```

From (4.427e) follows the trajectory (4.428a) and eliminating time with (4.427e) leads to the path in **the phase plane:**

```
$$\dot{x}\equiv\dot{x}(t_0,x_0;q);\quad G(x,x_0;q)=0,\quad (4.428a, b)$
```

whose coordinates are the position and velocity.
