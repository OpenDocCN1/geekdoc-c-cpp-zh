# Differentials and First-Order Equations

# 3.7.3 Change of Variable and Integration by Quadratures

As an example, the solution of the homogeneous non-linear differential equation (3.140a):

```
$y' = \frac{y+x}{y-x'}, \quad C = y^2 - 2xy - x^2, \quad y = x \pm\sqrt{2x^2+C}, \quad (3.140a-c)$
```

is (3.140b) = (3.140c), because (3.140a) corresponds to (3.127) with $f(v)$ specified by (3.141a):

```
$f(v) = \frac{v+1}{v-1} \frac{x}{\sqrt{C}} = \exp\left{\int^{v/x} \left(\rac{v+1}{v-1} - v\right)^{-1} dv\right} = \exp\left{\int^{v/x} \frac{v-1}{v^2-2v-1} dv\right}$
= \exp\left{-\frac{1}{2}\log\left|\frac{y^2}{x^2}-\frac{2y}{x}-1\right|\right) = x\left|\frac{y^2}{x^2}-\frac{2y}{x}-1\right)^{-1/2}$
(3.141a, b)$
```

so that (3.133) becomes (3.141b); the solution (3.141b) is an implicit relation (3.140b) between $x$ and $y$ that may be rendered explicit (3.140c) by solving it as a quadratic in $y$.

Another example is the non-linear first-order homogeneous differential equation (3.142a) corresponding to (3.127) to (3.142b):

```
$y' = \frac{x^2+y^2}{xy-x^2}, \quad f(v) = \frac{v^2+1}{v-1}, \quad f(v)-v = \frac{v+1}{v-1};\quad (3.142a-c)$
```

substituting (3.142c) in the quadrature (3.133) leads to:

```
$\log\left(\frac{x}{C}\right) = \int^{y/x} \frac{v-1}{v+1} dv = \int\left(1-\frac{2}{v+1}\right) dv = -2\log\left(1+\frac{y}{x}\right);\quad (3.143)$
```

corresponding to (3.144a):

```
$\frac{x}{C} = \left(1+\frac{y}{x}\right)^{-2}\exp\left(\frac{y}{x}\right), \quad (x+y)^2 = C\exp\left(\frac{y}{x}\right);\quad (3.144a, b)$
```

that is, the general integral (3.144a) = (3.144b) of (3.142a).
