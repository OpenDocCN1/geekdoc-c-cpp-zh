# Unsteady, Non-Linear, and Chaotic Systems 155

The total energy coincides with the potential energy where the velocity is zero, for
example for the maximum displacement or amplitude (4.237a) of a periodic motion,
and thus the equation of the trajectory (4.212b) becomes (4.237c) for any potential
function:

```
$E = \Phi(a); \quad x(0) = 0; \quad t = \int_{0}^{m} \frac{k}{2} \left[ \Phi(a) - \Phi(\xi) \right]^{-1/2} d\xi, \quad (4.237a-c)$
```

with time at the origin (4.237b). In the case of the biquadratic potential (4.215b)
ext the equation of motion (4.222b) $\equiv$ (4.238):

```
$t = \int_{0}^{k} \frac{1}{\beta} \left[ (a^2 - \xi^2) + \frac{\beta}{a^2} (a^4 - \xi^4) \right]^{-1/2} d\xi, \quad (4.238)$
```

and can be put into a dimensionless form (4.239):

```
$\omega_0 t = \int_{0}^{a} a^2 - \xi^2 + \gamma \left( a^2 - \frac{\xi^4}{a^2} \right)^{-1/2} d\xi, \quad (4.239)$
```

involving only the natural frequency (4.221a) and non-linearity parameter (4.236a).
Since the radical in the integrand in (4.239) is a biquadratic polynomial,
the integral can be evaluated (subsection 4.4.9) as a Jacobian elliptic function
(section I.399).

# 4.4.9 Exact Solution in Terms of the Elliptic Sine

The Jacobian elliptic sine of variable $\xi$ and modulus $q$ is defined by (I.39.114c) $\equiv$
(4.240a, b):

```
$z = sn(\xi;q); \quad \zeta = \arg sn(z;q) = \int_{0}^{\zeta} (1-y^2) (1-q^2y^2)^{-1/2} dy. \quad (4.240a, b)$
```

Rewriting (4.239) in the form (4.241):

```
$\omega_0 t = \int_{0}^{a} a^2 (1+\gamma) - \xi^2 - \gamma \frac{\xi^4}{a^2})^{-1/2} d\xi, \quad (4.241)$
```

suggests the change of variable (4.242a) leading to (4.242b):

```
$y = \frac{\xi}{a}; \quad \omega_0 t = \int_{0}^{a} |1+\gamma y - y^2 - \gamma y^4|^{-1/2} dy. \quad (4.242a, b)$
```
