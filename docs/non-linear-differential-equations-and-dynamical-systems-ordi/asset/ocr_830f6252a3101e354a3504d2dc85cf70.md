```
$R>0: \quad 0 < \iint_{D} \left(\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}\right)dS = \int_{\partial D} (vx-udy); \quad (4.478a, b)$
```

and (ii) the integral 4.478b is zero (4.479) if a limit cycle exists:

```
$\int_{\partial D} (vx-udy) = \oint(vu-uv)dt=0. \quad (4.479)
```

Thus (4.479) is incompatible with (4.478a, b). For example, a compressible flow with velocity $\dot{v}$ corresponding to expansion or contraction at all points (4.480a) cannot have a limit cycle; limit cycle is possible only if there are expansions and contractions at different points:

```
$\dot{D}=V.\dot{v}<0; \quad q/\epsilon=V.\dot{E}<0, \quad (4.480a, b)$
```

likewise, (4.480b) an electrostatic field $\dot{E}$ in a dielectric of permittivity $\epsilon$ with only positive or negative electric charge $q$ cannot have a limit cycle; a limit cycle is possible only in the presence of electric charges with opposite signs. The interpretation is that electric charges with the same (opposite) sign repel (attract) each other, so a limit cycle is not (is) possible. The existence of a limit cycle raises the question of its stability.
