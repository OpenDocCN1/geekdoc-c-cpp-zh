## 4.4.12 Exact Solution as a Series of Chebyshev Polynomials

The Chebyshev polynomials of the second kind are defined by (II.129b) \equiv (4.259a) implying (4.259b, c):

```
$U_N(\cos \phi) = 2^{1-N} \frac{\sin[(N+1)\phi]}{\sin \phi}, \quad (4.259a)$
```

```
$N = 2n-m-1: \quad \sin[2(n-m)\phi] = 2^{2n-m-2} U_{2n-m-1}(\cos \phi). \quad (4.259b, c)$
```

Substitution of (4.259c) in (4.251) specifies the inverse sine as a series of Chebyshev polynomials of the second kind:

```
$\arg(\phi) = A\phi + \sum_{n=1}^{m} \frac{q^{2n}}{(2n-1)!} \sum_{m=0}^{n-1} \frac{(-1)^{n-m}}{(n-m)!} 2^{2n-m-2} U_{2n-m-1}(\cos \phi). \quad (4.260)$
```

Using (4.246a; 4.259c) in (4.254a) leads to the equivalent result:


## 4.4.13 Non-Linear Effects on the Frequency

The lowest order non-linear approximation (4.262a) to (4.246b) is (4.246b):

```
$q^4 \ll 1: \omega_0\sqrt{1+\gamma} = \int_0^{\phi} [1+\frac{q^2}{2}\sin^2 \phi] d\phi$
= \int_0^{\phi} [1+\frac{q^2}{4}(1-\cos(2\phi))] d\phi \quad (4.262a, b)$
= \left(1+\frac{q^2}{4}\right)\phi-\frac{q^2}{8}\sin(2\phi).$
```

The lowest order non-linear approximation (4.262a) corresponds by (4.244c) to (4.263a) and implies (4.263b):

```
$$\gamma^2 \ll 1: q^2 = -\frac{\gamma}{1+\gamma}=-\gamma+O(\gamma^2), \quad 1+\frac{\gamma^2}{4}-\frac{\gamma}{4}. \quad (4.263a–c)$$
```

The second term on the r.h.s. of (4.262b) has an upper bound (4.263d) that is small:

```
$-\frac{q^2}{8}\sin(2\phi) \le \frac{|q^2|}{8}-\frac{\gamma}{8}\frac{\beta a^2}{16}, \quad (4.263d)$
```

it is negligible compared with the r.h.s. of (4.262b) for sufficiently long time (4.264a), leading to the simplification (4.264b):

```
$t \gg \frac{\gamma}{8\omega_0}: \phi = \omega_0\frac{\sqrt{1+\gamma}}{1+q^2/4}=\omega_0\frac{1+\gamma/2}{1-\gamma/4}=\omega_0\left(1+\frac{\gamma}{4}\right)\left(1+\frac{3\gamma}{4}\right). \quad (4.264a, b)$
```

Setting (4.265a) leads to (4.265b):

```
$$\phi = \omega_0 t \left(1+\frac{\gamma}{4}\right)\left(1+\frac{3\gamma}{4}\right) \quad (4.265b)$$
```

that is the oscillation frequency (4.267c). Compared with the undamped oscillator (4.254), the non-linear effect (4.26) is not only on the frequency (4.4.13) but also on the displacement (4.4.14).
