
```

```

```
$C=\frac{\lambda(x)}{\mu(y)}=y\exp\left{-\int P(\xi)d\xi\right},\quad (3.194)$
```

为一般积分 (3.188b) ≡ (3.193a) ≡ (3.194) 与 (3.180b) 相一致。线性无强迫一阶微分方程 (3.19a) 的四种解法已被用来说明积分因子的性质。标准 (LII) 线性强迫一阶微分方程 (3.27) 也可以用仅依赖于 $x$ 的积分因子求解 (EXAMPLE 10.7)。在最简单的依赖于一个变量 ($x$ 或 $y$) 的积分因子 ([subsection 3.8.7]) 与最一般的 ([subsection 3.8.11]) 任意依赖于两个变量 ($x$ 和 $y$) 的积分因子之间，是积分因子：(i/ii) 通过 [subsection 3.8.8(3.8)]) 它们的和 (积) 在两个变量上对称地；和 (iii) 依赖于变量的比值 ([subsection 3.8.10]) 如同齐次方程 (3.7)。

## 3.8.11 非对称非齐次积分因子

作为一个依赖于两个变量的积分因子的例子 (与 subsection 3.8.6 不同) 且既非对称 (subsections 3.8.8–3.8.9) 也非齐次 (subsection 3.8.10)，考虑微分 (3.211a) 当 $a \neq b$ 时是不精确的 且具有积分因子 (3.211b)：

```
$0 = ay \ dx + bx \ dy; \quad \lambda = x^{a-1}y^{b-1}, \quad (3.211a, b)$
```

由它们的乘积 (3.212a) 可得：

```
$0 = \lambda(ay \ dx + bx \ dy) = ax^{a-1}y^{b-1}dx + bx^ay^{b-1}dy = d(x^ay^b); \quad x^ay^b = C, \quad (3.212a, b)$
```

这证明 (3.212b) 是不精确微分 (3.211a) 的一般积分。将 ($a$，由 $b$) 替换为 $(\alpha, \beta)$，可得不精确微分 (3.213a) 具有积分因子 (3.213b) 导致一般积分 (3.213c)：

```
$0 = ay \ dx + bx \ dy, \quad \mu = x^{\alpha-1}y^{\beta-1}, \quad x^\alpha y^\beta = C. \quad (3.213a–c)$
```

积分因子 (3.211b, 3.213b) 的比值为 (3.214a)：

```
$\frac{\mu}{\lambda} = x^{\alpha-a}y^{\beta-b}; \quad 0(ay \ dx + bx \ dy) + x^{\alpha-a}y^{\beta-b}(\alpha \ dx + bx \ dy), \quad (3.214a, b)$
```

暗示不精确微分 (3.211b) 具有积分因子因为其乘积是精确微分：

```
$0 = \lambda[(ay \ dx + bx \ dy) + x^{\alpha-a}y^{\beta-b}(\alpha \ dx + bx \ dy)] \nn = x^{a-1}y^{b-1}(ay \ dx + bx \ dy) + x^ay^{b-1}(ax \ dx + bx \ dy) = d(x^ay^b). \quad (3.215)$
```

已证明不精确微分 (3.214b) 具有积分因子 (3.211b) 导致一般积分：

```
$C = x^a y^b. \quad (3.216)$
```

积分因子 (3.211b) 为：(i) 当 $a=b$ 时对称；(ii) 当 $a-1=1-b$ 或 $a+b=2$ 时齐次；且 (i) 和 (ii) 同时成立当 $a=1$ 时，此时积分因子为单位元，且不需要因为微分是精确的。在情况 (i) 中，包括 (iii)，条件 (3.217a) 导致 (3.211a) 到精确微分 (3.217b)，其解为

```
$a=b; \quad 0 = a(y \ dx + x \ dy) = d(axy), \quad x = C, \quad (3.217a–c)$
```
