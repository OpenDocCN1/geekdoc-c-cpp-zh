# 3.7.2 Linear and Non-Linear Homogeneous Differential Equations

The form of the homogeneous first-order differential equation (3.127) suggests the change of variable (3.131a):

```
$v=\frac{y}{x}; \quad y'=(vx)'=vx'+v;$ (3.131a, b)
```

that transforms (3.131b) to a differential equation (3.132a) that is separable (3.132b):

```
$f(v)-v=x\frac{dv}{dx}, \quad \int\frac{dv}{f(v)-v}+\log C=\int\frac{dx}{x}=\log x;$ (3.132a, b)
```

```
$x=CExp\left{\int^{y/x} \frac{dv}{f(v)-v}\rightright};$ (3.133)
```
