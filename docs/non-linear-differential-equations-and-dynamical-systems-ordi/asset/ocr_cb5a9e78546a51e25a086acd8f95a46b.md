The differential (3.357b) is invariant; that is, it takes the same form (3.360) in each allowable coordinate system (3.359a-c):

```
$0 = X_{i_1...i_m} dx^{i_1}...dx^{i_m}, \quad (3.360)$
```

and only if the coefficients have the transformation law:

```
$X_{i_1...i_m} = X_{j_1...j_m} \frac{\partial x^{j_1}}{\partial x^{i_1}}...\frac{\partial x^{j_m}}{\partial x^{i_m}}, \quad (3.361)$
```

corresponding to a covariant tensor of order M that is symmetric (3.357c) in indices. The invariance properties of differentials in the tensor calculus (notes III.9.1-III.9.52).

# NOTE 3.23: Factorization of Differentials of Degree Two

The consideration of differentials (notes 3.1–3.22) will be concluded with some cases of second degree in two or three variables (notes 3.23–3.24). The second-order differential in two variables (3.353) = (3.362a) can be always factored into the product of two first-order differentials (3.363b):

```
$0 = B(dy-\lambda_+dx)(dy-\lambda_-dx), \quad 2\lambda_{\pm}B=-D \pm\sqrt{D^2-4AB}. \quad (3.362a, b)$
```

This is not the general case (standard XCI) the second-order differential in three variables:

```
$0 = A(dx)^2 + B(dy)^2 + C(dz)^2 + 2Edxdy + 2Edxdz + 2Fdydz. \quad (3.363)$
```

If the condition (3.364a) is, the second-order differential (3.363) can be substituted in the perfect square (3.364b):

```
$C \neq 0: \quad (Cdz+Edx+Fdy)^2\n=E(dx)^2+F(dy)^2+2EFdxdy+C[C(Edx+Fdy)]\n=E(dx)^2+F(dy)^2+2EFdxdy-C[A(dx)^2+B(dy)^2+2Dedxdz]\n=(E^2-CA)(dx)^2+(F^2-BC)(dy)^2+2(EF-CD)dxdz;\n\quad (3.364a, b)$
```

thus the differential (3.363) reduces to a difference of squares if the r.h.s. of (3.364b) is a perfect square (3.365a),

```
$0=(E^2-CA)(F^2-CB)-(EF-CD)^2; \quad ABC+2DEF-AF^2-BE^2-CD^2=0.\n\quad (3.365a, b)$
```
