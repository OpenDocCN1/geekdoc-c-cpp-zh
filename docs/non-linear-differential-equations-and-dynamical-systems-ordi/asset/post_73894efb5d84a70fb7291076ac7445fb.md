# 4.2.1 Coupled First-Order System

The system of two first-order differential equations with constant coefficients (4.4b) = (4.35b, c):

```
$$\dot{z} = \frac{dz}{dt}:\quad \dot{x} = ax + by, \quad \dot{y} = cx + dy, \quad (4.35a–c)$$
```

where dot denotes derivative with regard to time (4.35a) may be considered by two methods: (i) elimination of time leading to the non-homogeneous first-order differential equation (4.5b) specifying the paths (section 4.1); and (ii) direct solution for the trajectory (section 4.2) implying that it is equivalent to a single second-order differential equation with constant coefficients obtained by elimination (4.35b, c):

```
$$\ddot{x} = ax + b\dot{y} = ax + b(cx + dy) = ax + bcx + d(x). \quad (4.36)$$
```

Thus the system of two first-order equations (4.35b, c) is of order two, since it is equivalent to a single differential equation of order two:

```
$P_2 \left( \frac{d}{dt} \right)x,y(t) = \left( \frac{d^2}{dt^2} - (a+d)\frac{d}{dt} + (ad-bc) \right)x,y(t) = 0, \quad (4.37a, b)$
```

which is the same for the two variables; it is sufficient to solve (4.37a) for $x$ (or (4.37b) for $y$), since the other variable $y(x)$ is determined by substitution in (4.35b) [(4.35c)]. An alternative way to obtain the result (4.37a, b) is to seek solutions for $(x, y)$ as exponentials of time (4.38a) with distinct amplitudes:

```
$\{x(t),y(t)\} = e^{\lambda t}\{A,B\}:\quad \begin{bmatrix} -a & -b \\ -c & -d \end{bmatrix} \begin{bmatrix} A \\ B \end{bmatrix} = 0; \quad (4.38a, b)$
```
