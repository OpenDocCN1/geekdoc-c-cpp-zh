# 4.9.7 Singularity at Infinity and Inversion/Stereographic Projection

The singularity at infinity can be obtained via the stereographic projection (sections I.2–I.3) by inversion (4.495a) of a complex (4.489b) = (4.495b) relative to the origin (4.495a), implying (4.495d–g):

```
$$\bar{z} = \frac{1}{z}, \quad z = x+iy = re^{i\phi}, \quad \bar{z} = x-iy = re^{-i\phi} : \quad (4.495a–c)$
```

```
$$\bar{x}+iy = \frac{1}{x+iy} \frac{x-iy}{x^2+y^2} = \frac{x-iy}{r^2}, \quad x+iy = \frac{\bar{x}-\bar{y}}{r^2} : \quad (4.495d, e)$
```

```
$r=|z|=\|\bar{z}|^{-1} = \bar{r}^{-1}, \quad \bar{\phi} = \arg(\bar{z}) =-\arg(z) =-\phi. \quad (4.495f, g)$
```

This leads to the direct (4.496a) inverse (4.497b) coordinate transformations (4.496c, d):

```
${\bar{x},\bar{y}\} = r^{-2}\{x,-y\}, \quad \{x,y\} = r^{-2}\{\bar{x},\bar{y}\}, \quad r\bar{r}=1, \quad \phi+\bar{\phi}=0, \quad (4.496a–d)$
```

and the corresponding direct (4.497a) inverse (4.497b) transformation matrices:

```
$$\frac{\partial(\ar{x},\bar{y})}{\partial(x,y)} = \begin{bmatrix} \frac{\partial\bar{x}}{\partial x} & \frac{\partial\bar{x}}{\partial y} \ \frac{\partial\bar{y}}{\partial x} & \frac{\partial\bar{y}}{\partial y} \end{bmatrix} = r^{-4} \begin{bmatrix} y^2-x^2 & -2xy \ 2xy & x^2-y^2 \end{bmatrix} \quad (4.497a)$
```

```
$$\frac{\partial(x,y)}{\partial(\ar{x},\bar{y})} = \begin{bmatrix} \frac{\partial x}{\partial\bar{x}} & \frac{\partial x}{\partial\bar{y}} \ \frac{\partial y}{\partial\bar{x}} & \frac{\partial y}{\partial\bar{y}} \end{bmatrix} = r^{-4} \begin{bmatrix} y^2-x^2 & -2xy \ 2xy & x^2-y^2 \end{bmatrix} \quad (4.497b)$
```

for example:

```
$$\frac{\partial r}{\partial x} = \frac{\partial}{\partial x}(x^2+y^2)^{1/2} = x|x^2+y^2|^{-1/2} = \frac{x}{r}, \quad \quad (4.497c)$
```

```
$$\frac{\partial x}{\partial r} = \frac{1}{r^2}\frac{2x}{r^3} = \frac{r^2-2x^2}{r^4}, \quad \quad (4.497d)$
```

```
$$\frac{\partial x}{\partial y} = -\frac{2x}{r^3}\frac{2y}{r} = -\frac{2xy}{r^4}. \quad \quad (4.497e)$
```
