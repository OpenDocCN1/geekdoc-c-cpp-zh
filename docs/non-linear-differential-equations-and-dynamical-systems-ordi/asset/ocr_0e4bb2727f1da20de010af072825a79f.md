NOTE 3.15: First-Order Differentials in Any Dimension

A differential of first-order in N variables (3.332a) may have vector of coefficients (3.283a) with non-zero (3.332b) curl (3.283b) and non-zero (3.332c) helicity (3.282);

```
$0 = \sum_{n=1}^{N} X_n dx_n; \quad \Omega_{mn} = \partial_m X_n - \partial_n X_m \neq 0$,$
$$H_{mns} = \sum_{n,s}^{cl} X_s(\partial_m X_n - \partial_n X_m). \quad (3.332a-c)$$
```

Thus there are three cases: (i) an exact differential if the curl is zero (3.333a) implying (3.305b) integrity conditions; (ii) an inex differential with an integrating factor (3.333b) if the curl is not zero but the helicity is zero, implying (3.306b) integrity conditions; and (iii) an exact differential without integrating (3.333c) if the helicity is not zero, in case N – 2 constraints must be imposed:

```
$$d\Phi \quad if \quad \Omega_{mn} = 0, \quad (3.333a)$$
$$\$\lambda^1 d\Phi \quad if \quad \Omega_{mn} \neq 0 = H_{mns}, \quad (3.333b)$$
$$\$\lambda^{-1} d\Phi + \sum_{m=1}^{N-2} d\Phi_m \quad if \quad H_{mns} \neq 0. \quad (3.333c)$$
```

In cases (i, ii) there is (3.333a, a family of hypersurfaces orthogonal to the vector field of coefficients (3.283a) but not in case (iii). In the latter case N–2 functions can be specified that the matrix of partial derivatives (3.292a, b) have maximum rank possible (3.292c); this implies that the N–2 hypersurfaces intersect on a surface, and on that surface exists a curve orthogonal to the vector field. The first-order differentials (sections 3.8–3.9 and notes 3.1–3.15) [sections 3.1–7 and 5.1–5.5]) are integrable in special homogeneous cases [notes 3.16–20 (section 3.7)]. Methods of integration quicker than the preceding apply to special differentials such as the homogeneous type (note 3.16) in two (or more) variables [note 3.17 (3.18)] as shown several examples (notes 3.19–3.20).
