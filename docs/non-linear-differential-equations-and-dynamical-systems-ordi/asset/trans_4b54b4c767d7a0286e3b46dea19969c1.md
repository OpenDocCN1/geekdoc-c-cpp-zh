

# 微分与一阶方程

反过来，通过一个合适的积分因子乘以一个不精确微分，可以使其变为精确，从而得到一般积分。例如微分：

```
$0 = d\Phi = \tan y \ dx + \tan x \ dy$
```

是不精确的，因为系数 (3.169a, b) 不满足可积条件 (3.148c)：

```
${X, Y\} = {\tan y, \tan x\}: \quad \frac{\partial Y}{\partial x} = \sec^2 x \neq \sec^2 y = \frac{\partial X}{\partial y} \quad (3.169a-c)$
```

当乘以积分因子时：

```
$\lambda = \cos x \cos y; \quad \lambda d\Phi = \cos x \sin y \ dx + \cos y \sin x \ dy, \quad (3.169a, b)$
```

不精确微分形式 (3.168) 变为 (3.169b)，它是一个精确微分 (3.170a)：

```
$0 = d\Phi = d(\sin x \sin y), \quad \sin x \sin y = C, \quad (3.170a, b)$
```

并导致 (3.168) 的一般积分 (3.170b)。这就提出了对于两个变量的不精确微分是否存在积分因子的问题，下文将证明该问题（小节 3.8.4）。

## 3.8.4 不精确微分积分因子的存在性

任何显式微分方程 (3.145b)，即使是不精确的，也可以写成形式：

```
$\frac{\partial y}{\partial x} = \frac{X(x,y)}{Y(x,y)}, \ (3.171)$
```

它有一个解 (3.146c) 意味着 (3.146b) 且因此：

```
$\frac{\partial y}{\partial x} = \frac{\partial \Phi / \partial x}{\partial \Phi / \partial y}, \quad (3.172)$
```

令 (3.171) ≡ (3.172) 得到 (3.173a)：

```
$\frac{X}{Y} \frac{\partial \Phi / \partial x}{\partial \Phi / \partial y} = \frac{1}{X \partial x} \frac{1}{Y \partial y} \equiv \lambda, \quad (3.173a-c)$
```

即等价于 (3.173b)；公共比值 (3.173c) 称为**积分因子**，它使不精确 (3.174a) 变为精确 (3.174b) 微分：

```
$$\frac{\partial Y}{\partial x}-\frac{\partial X}{\partial y} = \lambda(X dx + Y dy) = \frac{\partial \Phi}{\partial x}dx-\frac{\partial \Phi}{\partial y}dy = d\Phi..$ (3.174a, b)$$
```

由此可知，不精确 (3.174a) 微分 (3.145b) 具有满足 (3.173b, c) 的积分因子 $\lambda$，它导致乘以精确微分 (3.174b)，可以认为由于微分 (3.145b) 涉及两个函数 (X, Y)：(i) 除非满足可积条件 (3.148c)，否则单个函数 $\Phi$ 不能导致精确微分；并且 (ii) 两个函数 $(\lambda, \Phi$) 可以导致精确微分 (3.174b)，正如刚才所示，并且还有无限多种 $\lambda$ 的选择，如下文所示（小节 3.8.5–3.8.6）。

# 非线性微分方程与动力系统

## 3.8 积分因子的偏微分方程

为了确定**积分因子**满足的方程，将 (3.173b, c) 代入 (3.148a, b) 得到 (3.175c)：

```
$$\Phi \in C^2(\mathbb{R}^2): \quad 0=\frac{\partial^2 \Phi}{\partial x\partial y}-\frac{\partial^2 \Phi}{\partial y\partial x}-\frac{\partial}{\partial x}(\lambda Y)-\frac{\partial}{\partial y}(\lambda X),\$ (3.175a–c)$$
```

即等价于 (3.175c)=(3.176b)：

```
$$\lambda \in C^1(\mathbb{R}^2): \quad \Omega=\frac{\partial Y}{\partial x}-\frac{\partial X}{\partial y}\frac{1}{\lambda}(\frac{\partial \lambda}{\partial x}Y-\Y\frac{\partial \lambda}{\partial y})=(X\frac{\partial \lambda}{\partial y}-Y\frac{\partial \lambda}{\partial x})\log\lambda,\$ (3.176a, b)$$
```

其中积分因子必须连续可微 (3.176a)。因此，不精确 (3.177c) 微分 (3.177a, b)：

```
$$\X,Y \in C^1(\mathbb{R}^2): \quad 0=X(x,y)dx+Y(x,y)dy, \Omega=\frac{\partial Y}{\partial x}-\frac{\partial X}{\partial y}\neq 0,\$ (3.177a–c)$$
```

具有可微 (3.176a) 积分因子 (3.174a, b)，它满足偏微分方程 (3.176b) 通常比不精确微分 (3.145b) 更复杂；然而，只需要 (3.176b) 的一个特解，越简单越好，以得到 (3.145b) 的一般积分。如果 (3.145b) 是一个精确微分 (3.153c)，积分因子 (3.176b) 为任意常数；由此可知积分因子不是唯一的，如下文所示。

# 微分与一阶方程

## 3.8.6 无限多个积分因子

一般不精确微分 (3.145b) 的积分因子 $\lambda$ 是一个函数 $\lambda(x,y)$，不是唯一的。例如，将 (3.178a) 代入 (3.176b) 得到 (3.178b)：

```
$$\lambda = \mu\Phi; \quad \frac{\partial Y}{\partial x}-\frac{\partial X}{\partial y}+\left(Y\frac{\partial}{\partial x}-X\frac{\partial}{\partial y}\right)\log\mu = \left(X\frac{\partial}{\partial x}-Y\frac{\partial}{\partial x}\right)\log\Phi; \quad (3.178a, b)$$
```

由 (3.173a) $\mu$ 为 (3.179a)，如果 (3.17b) 的右端为零，则得到

```
$$\frac{\partial \Phi}{\partial x}=X\frac{\partial \Phi}{\partial y}; \quad \left(Y\frac{\partial}{\partial x}-X\frac{\partial}{\partial y}\right)\log\mu = 0, \quad (3.179a, b)$$
```

这证明了 $\mu$ 也是满足 (3.176b) 的积分因子。该结果可以用两种等价的方式表述：(a) 如果 $\lambda,\mu$ 是 (标准 LXVII) 不精确微分 (3.145b) 的积分因子 (3.176b; 3.179b)，则它们在 (3.148a) 中的比值 $\Phi=\lambda\mu$ 是一个解 (3.146c)；或如果 $\Phi$ 是不精确微分 (3.145b) 的解 (3.146c) 且 $\mu$ 是积分因子 (3.179b)，则 (3.178a) 并且 (3.180b) 也是积分因子 (3.176b)，其中 (3.180a) 是解的微分函数：

```
$G \in D(R); \quad\quad\quad\quad\quad\lambda = \mu G(\Phi). \quad\quad (3.180a, b)$
```

后一结果源于以下陈述之一：(i) 如果 (3.148c) 是不精确微分 (3.145b) 的解，则 (3.181a) 也是解：

```
$G(\Phi(x,y))=G(C_1); \quad\lambda G(dX+dY)=G(\Phi)d\Phi; \quad\quad (3.181a, b)$
```

- ii 如果不精确微分 (3.145b; 3.174a) 通过乘以积分因子 $\lambda$ 变换为精确微分 (3.174b)，则 (3.181b) 也是精确微分，证明 $\lambda G$ 是积分因子。

## 3.8.7 仅依赖于一个变量的积分因子

由于积分因子不是唯一的，可以寻求几种形式，只要它们满足 (3.176a, b)。仅为变量 x 的函数的最简单积分因子由 (3.176b) 给出 (3.182a) [[3.182b]：

```
$$\Omega = \frac{\partial Y}{\partial x}-\frac{\partial X}{\partial y}=-Y\frac{d}{dx}{\log[\lambda(x)]}; \quad\quad X\frac{d}{dy}{\log[\lambda(y)]}; \quad\quad (3.182a, b)$$
```

# 非线性微分方程与动力系统

意味着不精确 (3.177c) 微分 (3.177a, b) 其系数满足 (3.183a) [(3.184a)] 具有标准 LXVIII (LXXIV) 积分因子 (3.174) 仅依赖于 x(y) (3.183b) [(3.184b)]：

```
$$\frac{1}{Y} \left( \frac{\partial X}{\partial y} - \frac{\partial Y}{\partial x} \right) = \Omega f(x); \quad \lambda(x)=\exp\left( \int^x f(\xi)d\xi \right),\quad (3.183a, b)$$
```

```
$$\frac{1}{X} \left( \frac{\partial X}{\partial x} - \frac{\partial Y}{\partial y} \right) = \Omega g(y); \quad \lambda(y)=\exp\left( \int^y g(\eta)d\eta \right),\quad (3.184a, b)$$
```

作为示例，考虑 (标准 LI) 线性强迫一阶微分方程 (3.19a) = (3.185a) 写成两个不同的微分 (3.185b, c)：

```
$y'=Py; \quad Py\ dx-dy=0 \quad P\ dx - \frac{dy}{y} = 0.\quad (3.185a-c)$
```

一个微分 (3.185b) = (3.186a) [(3.185c) = (3.187a)] 是不精确的 (3.186b, c) [精确的 (3.187b, c)] 具有非零 (零) 旋度 (3.186d) [(3.187d)]

```
$Py\ dx-dy=0; \quad \{X, Y\}=\{P^{-1}, Y\}; \quad \Omega=-P,\quad (3.186a-d)$
```

```
$P\ \frac{dy}{y}=0; \quad \{X, Y\}=\{P,-\frac{1}{y}\}; \quad \Omega=0.\quad (3.187a-d)$
```

不精确微分 (3.185c) 可分离并导致 (3.19b) = (3.188a) 一般积分 (3.20a, b) = (3.188b)：

```
$$\int P dx-\log y=-\log C; \quad \lambda(x)=C\exp\left\{ \int^x P(\xi)d\xi \right},\quad (3.188a, b)$$
```

不精确微分 (3.186a-d) 导致 (3.183a) [[3.184a]] 积分因子 (3.183b) [[3.184b]] 仅依赖于 x(y)，即 (3.189a, b) [(3.190a, b)：
