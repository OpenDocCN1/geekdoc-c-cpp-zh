# Non-Linear Differential Equations and Dynamical Systems

It has been shown that if the differential (3.363) of the second order in three variables satisfies (standard XCI) the condition (3.365b), then it can be written as difference of squares (3.366).

```
$(Cdz + Ez + Fdy)^2 -(\sqrt{E^2 - CA}dx + \sqrt{F^2 - CB}dy)^2 = 0, \quad (3.366)$
```

so that it can be split into the product of two differentials of first-degree in three variables:

```
$Cdz + \pm\sqrt{E^2 - CA}dx + {F \pm\sqrt{F^2 - CB}}dy = 0, \quad (3.367)$
```

which can be solved by the methods presented before (section 3.9).

```
$x^2(dx)^2 + y^2(dy)^2 - z^2(dz)^2 + 2xydxdy = 0, \quad (3.368)$
```

```
${A,B,C,D,E,F} = \{x^2,y^2,-z^2,xy,0,0\}, \quad (3.369)$
```
