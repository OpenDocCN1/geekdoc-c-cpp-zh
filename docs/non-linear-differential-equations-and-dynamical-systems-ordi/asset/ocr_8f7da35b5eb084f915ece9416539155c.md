```
$0 = y\,dx + x\,dy + dx(xy) = (1+x)(y\,dx + x\,dy) = (1+x)d(xy) = d\Phi; \quad (3.252)$
```

the integrating factor (3.253a) multiplied by the inexact differential (3.252) leads to the exact differential (3.253b) and the general integral (3.253c:

```
$$\lambda = \frac{1}{1+x}; \quad 0 = \lambda d\Phi = \lambda(1+x)d(xy) = d(xy), \quad xy = C. \quad (3.253a–c)$
```

Thus the curves specified by the intersection of the surfaces (3.251a) and (3.253c) are orthogonal to the vector field (3.249b). Choosing a condition (2.254a) different from (3.251a) leads to (3.254b):

```
$0 = z - x^2 = \Theta(x, y, z); \quad dz = 2x\,dx + x^2\,dy, \quad (3.254a, b)$
```

corresponding to a different surface. Substitution of (3.254a, b) leads from the differential in three (3.249a) to two (3.255) variables:

```
$0 = y\,dx + x\,dy + xd(x^2) = y(1+x^2)dx + x(1+x^2)dy. \quad (3.255)$
```

The latter (3.255) = (3.256a) is a separable first-order differential equation in two variables:

```
$0 = \frac{1+x^2}{1+x^2} x \frac{dy}{y} + (\frac{1}{y} \frac{x}{1+x^2})dx + \frac{1}{y} = d[\log x y\sqrt{1+x^2}]: \quad xy\sqrt{1+x^2} = C, \quad (3.256a, b)$
```

that specifies the general integral (3.256b). Thus the first-order differential in three variables (3.249a) is inexact (3.249c) and has no integrating factor (3.249d), leading to the following equivalent statements: (i) subject to the constraint (3.251a)[[3.254a]] it has general integral (3.253c)[[3.256b]]; and (ii) on the surface (3.251a)[[3.251a]] there exist curves orthogonal to the vector field (3.249b), that is obtained by intersection with the surfaces (3.253c)[[3.256b].
