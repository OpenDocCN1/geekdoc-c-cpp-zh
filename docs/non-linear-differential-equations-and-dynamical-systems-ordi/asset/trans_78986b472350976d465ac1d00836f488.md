## 3.9 积分因子的存在或不存在

除了两个变量的一阶微分中关于积分因子的两种情形 (i, ii)（第 3.8 节）之外，对于三个变量还有第三种情形 (iii)，即积分因子不存在，导致 Pfaff 问题。对于两个变量的一阶微分，积分因子总是存在，这意味着由系数指定的连续向量场存在正交的平面曲线。对于三个变量的一阶微分，存在三种情形 (i-iii)。情形 (i) 是精确微分，如果系数向量的旋度为零（第 3.9.1 节）；在这种情况下积分是直接的，并且满足正交于向量场的曲面族。曲面族正交于向量场也存在（第 3.9.4 节）在情形 (ii) 中，当微分是不精确的并且具有积分因子（第 3.9.2 节）时；可积性的必要且充分条件是 Beltrami 条件，即系数向量场与其旋度正交（第 3.9.3 节），这意味着切线曲线没有挠率或螺旋度为零（第 3.9.5 节）。最简单的 Pfaff 问题出现在情形 (iii) 中，即三个变量的不精确微分，其中系数向量不满足 Beltrami 条件（第 3.9.6 节）；但在任何正则曲面上都存在正交于向量场的曲线族（第 3.9.7 节）。三个变量的一般一阶微分导致由三个标量 Clebsch 势表示的向量场的一般表示（第 3.9.8 节）。存在两种替代表示（第 3.9.9 节）；由另一组标量势表示；以及 (ii) 用向量势代替两个标量势。三维力的功在 (a) 中是不精确的一阶微分，在三个变量中没有积分因子（第 3.9.10 节）；它在保守力场即单标量势的梯度的特殊情形 (b) 中成为精确微分。一般情形 (a) 导致热力学第一定律（第 3.11 节）；即熵、温度和内能的存在。

```

```

如果它与三个变量的函数的微分一致，则为精确的 (3.220a)，这意味着必须满足三个条件 (3.220b)：

```
dΦ = X dx+Y dy+Z dz: {X,Y,Z} = {∂Φ/∂x, ∂Φ/∂y, ∂Φ/∂z}. (3.220a, b)
```


## 3.9.2 积分因子与可积性条件

如果可积性条件 (3.222b--d) 未满足，则三个变量中的微分 (3.219) 不是精确的。如果存在积分因子乘以不精确微分 (3.219) 使其精确 (3.226a)，则仍将存在正交于系数向量的曲面 (图 3.7)，这意味着 (3.226b)：

```
λ(Xdx + Ydy + Zdz) = dΦ: (∂Φ/∂x, ∂Φ/∂y, ∂Φ/∂z) = λ(X,Y,Z). \quad(3.226a, b)
```

存在：i 需要满足的条件，系数向量 (3.226b) 的分量 {X,Y,Z}；ii 只有两个自由函数，即积分 Φ 和积分因子 λ。因此必须对系数向量施加一个约束或可积性条件，以便积分因子存在。该条件是通过将 (3.226b 代入 (3.222b-d) 得到的，假设积分具有连续二阶导数：

```
∂/∂y (λ X) = ∂/∂x (λ Y), \quad ∂/∂z (λ X) = ∂/∂x (λ Z), \quad ∂/∂z (λ Y) = ∂/∂y (λ Z); \quad(3.227a-c)
```
