# 3.5.4 Four-Point Cross-Ratio for the Equation

The preceding results (subsections 3.5.2–3.5.3) suggest that the more particular integrals of the Riccati differential equation are known, the less quadratures are needed to find the general integral (Table 3); it might be extrapolated if three particular integrals of the Riccati differential equation are known, then (standard LVII) the general integral can be found without quadratures. This is proved considering a third linearly independent particular integral (3.81a) of the Riccati equation, besides (3.59a; 3.73a):

```
$0=Q+Py_3+Ry_3^3-y_3^5;\quad y_3-y_1=\frac{1}{v_2}.\quad(3.81a, b)$
```

In addition to the function $v_1$ defined by (3.73b), the function $v_2$ defined by (3.81b) also satisfies a linear differential equation (3.61)=3.73c. Thus, as in (3.57a) the functions $(v, v_1, v_2)$ in (3.59b; 3.73b; 3.81b) have a constant three-point cross-ratio of (3.82):

```
$C=\frac{\frac{v_1-v_2}{1}}{\frac{y_1-y_2}{1}}\cdot\frac{\frac{y_2-y_3}{1}}{\frac{y_1-y_3}{1}}=\frac{(y_1-y_3)(y_3-y_1)}{(y_1-y_2)(y_2-y)}.\quadquad(3.82)$
```
