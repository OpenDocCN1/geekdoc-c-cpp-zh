# Unsteady, Non-Linear, and Chaotic Systems

dynamical systems exhibit bifurcations. The simplest dynamical system is the first-order system (4.435a) with damping q \equiv \lambda;:

```
\dot{x}=\lambda x: \quad x(t)=x(0)e^{\lambda t}; \quad \begin{cases} \lambda < 0 & \text{stable}, \ \lambda=0 & \text{indifferent}, \ \lambda > 0 & \text{unstable}; \end{cases} \quad (4.435a-d)
```

it has a bifurcation for q=\lambda=0 of the eigenvalue \lambda, since it is stable for (4.435b) [[4.435d]] and in between there is indifferent equilibrium (4.43c). A simple second-order dynamical system (section 2.2) is the harmonic oscillator (4.436), for example with initial conditions (4.436a, b):

```
x_0=x(0)\neq 0=\dot{x}(0)=x_0: \quad \ddot{x}+\omega_0^2x=0; \quad (4.436a-c)
```

that has a bifurcation for q=\lambda because:

```
x(t)=\begin{cases} x_0\cos((\omega_0|t|) & \text{if } q=\omega_0^2>0: \text{oscillation}, \ x_0 & \text{if } q=\omega_0^2=0: \text{static}, \ x_0\cosh((\omega_0|t|) & \text{if } q=\omega_0^2<0: \text{monotonic},; \end{cases} \quad (4.436d-f)
```

because it: (i) is oscillatory for q=\omega_0^2>0$ with (4.436d) natural frequency \omega_0|; (ii) growing monotonic (4.436f) if q=\omega_0^2<0$ with growth rate \omega_0|; or (iii) static in the intermediate case \omega_0=0. The bifurcation does not depend on the initial conditions used, for example (4.436a, b). The second-order system (section 2.3) with constant coefficients (4.437b) in the case of damping (4.437a):

```
\lambda>0: \quad \ddot{x}+2\lambda\dot{x}+\omega_0^2x=0: \quad \begin{cases} \text{monotonic} & \text{if } \lambda>\omega_0, \ \text{transition} & \text{if } \lambda=\omega_0, \ \text{oscillatory} & \text{if } \lambda<\omega_0,; \end{cases} \quad (4.437a-f)
```

has a bifurcation for q=\lambda; it is (i) is stable for \lambda<0$ (4.437f) (ii) it grows monotonic (4.437d) for \lambda>\omega_0$ and (iii) in the intermediate case \lambda=\omega_0 it grows with at most a local minimum (4.437e).

The preceding examples 4.435a-d;4.436a-f, 4.437a-f of bifurcation of linear dynamical systems provide a classification of dynamical systems that also applies to non-linear cases (subsections 4.8.4-4.8.9). A dynamical system if it is driven from a potential (4.438a, b):
