# Differentials and First-Order Equations

# 3.8.2 Formal Integration of an Exact Differential

In the case of inability to identify the integral (3.146b, c) on inspection of the (standard LXVI) equation (3.145b), it can be obtained by formally integrating (3.147b, c). The integration of (3.147b) ([3.147c]) leads to (3.156a) ([3.156b]):

```
$\Phi(x,y) = \int X(x,y)dx+u(y) = \int Y(x,y)dy+v(x), \quad (3.156a)$
```

involving the arbitrary function $u(y)$ $[v(x)]$ that is obtained from (3.157a) by substitution in (3.147c) ([3.147b]):

```
$\frac{du}{dy} = \frac{\partial \Phi}{\partial y} - \frac{\partial X}{\partial y} = Y - \frac{\partial X}{\partial y}, \quad \frac{dv}{dx} = \frac{\partial \Phi}{\partial x} - \frac{\partial Y}{\partial x} = X - \frac{\partial Y}{\partial x}.$
```

Thus, if the differential (3.145b) is exact (3.147b, c), its general integral (3.146c) can be obtained from the quadrature (3.156a) ([3.156b]) involving an arbitrary function $u(y)$ $[v(x)]$ satisfying (3.157a) ([3.157b]).

For example, the first-order differential equation or differential in two variables:

```
$y \log ye^x(1+x)dx+xe^x(1+\log y)dy=0, \quad (3.158)$
```

has (3.145b) coefficients:

```
$X = y \log ye^x(1+x), \quad Y = xe^x(1+\log y), \quad (3.159a, b)$
```

showing that it satisfies the integrability condition (3.148c):

```
$\frac{\partial Y}{\partial x} = e^x(1+\log y) = \frac{\partial X}{\partial y}, \quad (3.160)$
```

and hence is an exact differential. The integral (3.156a) is given by:

```
$\Phi(x,y) = y \log ye^x(1+x)dx+u(y) = y \log ye^x+u(y), \quad (3.161)$
```

where the function $u(y)$ satisfies (3.157a) leading to (3.162a):

```
$\frac{du}{dy} = (1+\log y)\{xe^x - \int e^x(1+x)dx\}=0; \rightarrow u=C=0, \quad (3.162a-c)$
```
