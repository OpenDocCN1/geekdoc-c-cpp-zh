## 3 微分和一阶方程

如果微分方程涉及对一个（若干个）变量的导数，则它是常微分（偏微分）方程；常微分方程将在本卷 IV 中讨论，而偏方程将在下一卷 V 中讨论。在具有常数（可变）系数的二阶线性系统的动力学中（第 2(4) 章），自变量仅为时间，导致常微分方程。如果粒子或系统有一个（若干个）自由度，例如其位置由一个（方程组）指定，则常微分方程（N 个同时常微分方程组）的解是一个（N 个函数）关于一个变量的函数。出现在微分方程中的最高阶导数决定了该方程的阶；例如，对于一个自由度的粒子，微分方程是二阶常微分方程，因为位置关于时间的最高阶导数是二阶，指定加速度。并非所有微分方程都易于求解；因此将其分类为 (i) 常微分或偏微分，(ii) 方程或系统，(iii) 一阶或更高阶，以及 (iv) 特定标准或子类型非常重要。目的是识别具有某些性质求解方法的微分方程类。起点是具有次数为 N 的特征多项式的常系数或齐次系数的线性微分方程（第 1 章）；类比其他具有一个特征多项式的方程。考虑 (i) 变系数的线性方程或 (ii) 非线性微分方程，求解一阶方程（第 3 章）更为简单。

在讨论了一阶微分方程的一般性质（第 3.1 节）之后，给出了八类或标准方程的求解方法：(i) 可分离方程（第 3.2 节），其中导数是自变量和因变量的两个独立函数的比值，可通过积分求解；解归结为一次（或两次）积分；(ii) 线性强迫方程，可分离方程的特例，因此总是可解（第 3.2 节）；(iii) 线性强迫方程的解可通过参数变异法从其强迫部分得到（第 3.3 节），此前已使用（注 1.2–1 和第 2.9 节）；(iv) 伯努利方程，非线性但可化为线性类型，因此总是可解（第 3.4 节）；(v) Riccati 方程，虽然尚无已知一般解，

### 3.1 一阶方程的一般性质

一般性质包括解的分类（小节 3.1.1）和一般积分中任意常数的确定（小节 3.1.2）。当微分方程化为积分（小节 3.1.3）或求积（小节 3.1.4）时认为已求解，该积分可能是初等的也可能不是。一阶微分方程的一般积分是一个族（或若干族）积分曲线 [小节 3.1.1 (3.5)]，任意常数的每个值对应于该曲线（每个族）中的一条。

### 3.1.1 一般积分和积分曲线

一阶常微分方程是函数 y(x)、其变量 x 及其一阶导数 y' 之间的关系：

```
y' = \frac{dy}{dx}; \quad F(x,y;y') = 0. \quad (3.1a, b)
```

## 微分和一阶方程

图 3.1
显式一阶微分方程在平面的每个点指定一个斜率，其解是具有相应切线的积分曲线。

函数 y(x) 是因变量，变量 x 是自变量。微分方程的解是满足其（3.1b）的函数 y(x)，将其与一阶导数（3.1a）一起代入。微分方程（3.1a, b）的解可赋予几何解释（图 3.1）；一阶常微分（3.1b）在 (x, y) 平面的每个点指定一个（或多个）斜率 y'。解必须是曲线，其在点 (x, y) 处的切线斜率为 y'，称为积分曲线。由于它在每个点指定一个（或多个）斜率或切线，最一般解是一族曲线（图 3.2）：

```
$f(x, y, C) = 0 \quad\quad (3.2)$
```

涉及参数 C，这是一阶常微分方程（3.1b）的一般积分。给参数 C 一个特定值 C=Cv 指定一条特定曲线，或微分方程的特解。因此一阶常微分将一族曲线（3.2）与在每个点 (x, y) 处的切线斜率（3.1a）联系起来。切线不唯一的情况可能导致多于一个族的积分曲线或具有多重点的曲线，最简单的是重点（图 3.3）。如果积分曲线族具有包络，则为奇异或特殊积分（第 1.1 节）；重点的轨迹或其他轨迹也可能导致特殊积分（第 5.1–5.4 节）。
