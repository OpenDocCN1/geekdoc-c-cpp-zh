```
$$(2x_1 + x_2^2 + 2x_1x_4 - x_3)dx_1 + 2x_1x_2dx_2 - x_1dx_3 + x_1^2dx_4 = 0, \quad (3.319)$$

```

```

the curl bivector (3.278c) of the vector of coefficients (3.320) is zero, and thus (3.319) is an exact first-order differential in four variables. Taking $x_1, x_2$ as parameters (3.321a), the first-order differential (3.319) reduces (3.321c) to two variables $x_3, x_4$:

```
$x_1, x_2 = const; \quad 0 = -x_1dx_3 + x_1^2dx_4 = du, \quad u = -x_1x_3 + x_1^2x_4, \quad (3.321a-d)$
```

and has integral (3.321d). Next $x_1$ to be a variable, leaving $x_2$ constant (3.322a) and leading to (3.322b):

```
$x_2 = const; \quad du = -x_1dx_3 + x_1^2dx_4 + (2x_1x_4 - x_3)dx_3, \quad (3.322a, b)$
```

where the first two terms coincide with two of the first-order differential (3.319) in three variables $x_1, x_3, x_4$:

```
$x_2 = const; \quad 0 = (2x_1 + x_2^2 + 2x_1x_4 - x_3)dx_1 - x_1dx_3 + x_1^2dx_4; \quad (3.323a, b)$
```

substitution of (3.322b) in (3.323b) leads to (3.324a), whose primitive is (3.324b):

```
$0 = (2x_1 + x_2^2)dx_1 + du = dv, \quad v = u + x_1^2 + x_1^2x_2. \quad (3.324a, b)$
```

Taking all $x_1, x_2, x_3, x_4$ in (3.324b) leads to (3.325a):

```
$dv = d(u + x_1^2 + x_1^2x_2) = du + (2x_1 + x_2^2)dx_1 + 2x_1x_2dx_2 = 0, \quad (3.325a, b)$

## NOTE 3.13: Exact Differentials and Integrating Factor

A first-order differential in one variable (3.327a) is always exact for an integrable coefficient (3.327a), and its solution reduces to an integration (3.227c);

```
$X \in E(\mathbb{R}); \quad X(x)dx = d\Phi \quad \Leftrightarrow \quad \Phi(x) = \int^x \Phi(\xi)d\xi; \quad (3.327a–c)$
```

in this there is no curl or helicity. A first-order differential in two variables (3.145b) \equiv (3.328a) may have a vector of coefficients with non-zero curl (3.243b) \equiv (3.328b) and has zero helicity (3.243c) \equiv (3.328c):

```
$X_1 dx_1 + X_2 dx_2 = 0; \quad \Omega = \frac{\partial X_2}{\partial x_1}\frac{\partial X_1}{\partial x_2} \neq 0, \quad H = 0; \quad (3.328a–c)$
```

Thus there are two cases: (i) an exact differential (3.329a) if the curl is zero; and (ii) an integrating factor for an inexact differential (3.329b) if the curl is not zero:

```
$X_1dx_1 + X_2dx_2 = \begin{cases} d\Phi & \text{if} \Omega = 0, \\ \lambda^{-1}d\Phi & \text{if} \Omega \neq 0. \end{cases} \quad (3.329a) \quad (3.329b)$
```

In both cases (Figure 3.6) the plane vector field has a family of orthogonal curves.

## NOTE 3.14: Inexact Differentials without an Integrating Factor

A differential in three variables (3.330a) can have a vector of coefficients with non-zero curl (3.330b) and non-zero helicity (3.330c):

```
$0 = X_1dx_1 + X_2dx_2 + X_3dx_3; \quad \Omega = \nabla \cdot \tilde{X} \neq 0, \quad H = \nabla \times \tilde{X} \neq 0. \quad (3.330a–c)$
```

Thus there are three cases: (i) an exact differential (3.331a) for zero curl; (ii) an inexact differential with an integrating factor (3.331b) for non-zero curl and zero helicity; and (iii) an inexact differential without an integrating factor (3.331c) for non-zero helicity:

```
$X_1dx_1 + X_2dx_2 + X_3dx_3 = \begin{cases} d\Phi & \text{if} \Omega = 0, \\ \lambda^{-1}d\Phi & \text{if} \Omega \neq 0, H = 0; \\ \lambda^{-1}d\Phi + d\Psi & \text{if} H \neq 0. \end{cases} \quad (3.331a) \quad (3.331b) \quad (3.331c)$
```

## NOTE 3.15: First-Order Differentials in Any Dimension

A differential of first-order in $N$ variables (3.332a) may have vector of coefficients (3.332a) with non-zero curl (3.332b) and non-zero helicity (3.332c):

```
$0 = \sum_{n=1}^N X_n dx_n; \quad \Omega_{mn} = \partial_m X_n - \partial_n X_m \neq 0, \quad H_{mn} = \sum_{n,s}^N X_s(\partial_m X_n - \partial_n X_m). \quad (3.332a-c)$
```

Thus there are three cases: (i) an exact differential if the curl is zero (3.333a) implying (3.305b) conditions; (ii) an inexact differential with an integrating factor (3.333b) if the curl is not zero but the helicity is zero, implying (3.306b) conditions; and (iii) an exact differential without integrating (3.333c) if the helicity is not zero, in case $N-2$ constraints must be imposed:

```
$d\Phi \quad \text{if} \Omega_{mn} = 0, \quad (3.333a)$
$\lambda^{-1} d\Phi \quad \text{if} \Omega_{mn} \neq 0 = H_{mn}, \quad (3.333b)$
$\lambda^{-1} d\Phi + \sum_{m=1}^{N-2} d\Phi_m \quad \text{if} H_{mn} \neq 0. \quad (3.333c)$
```

In cases (i, ii) there is (3.333a) a family of hypersurfaces orthogonal to the vector field (3.283a) but not in case (iii). In the latter case $N-2$ functions can be specified that the matrix of partial derivatives (3.292a, b) have maximum rank possible (3.292c); this implies that the $N–2$ hypersurfaces intersect on a surface, and on that surface exists a curve orthogonal to the vector field. ## NOTE 3.16: Homogeneous Functions and Differential

A function $P(x,y)$ is said to be homogeneous of degree $q$ if it satisfies (3.334a):

```
$P(x,y) = x^q P\left(1, \frac{x}{y}\right); \quad P \in D(\mathbb{R}^2); \quad x\frac{\partial P}{\partial x} + y\frac{\partial P}{\partial y} = qP, \quad (3.334a-c)$
```

and if it is differentiable (3.334b) Euler's theorem (3.33c) applies; the latter can be proved from:

```
$x\frac{\partial P}{\partial x} + y\frac{\partial P}{\partial y} = qx^q P\left(1, \frac{x}{y}\right) - \frac{y}{x}x^{q+1} = x\frac{\partial P}{\partial x} + y\frac{\partial P}{\partial y} = qP. \quad (3.335)$
```

If the functions $X, Y$ are homogeneous of the same degree $q$, they satisfy the identity:

```
$Y\left(x\frac{\partial X}{\partial x} + y\frac{\partial X}{\partial y}\right) = YX = X\left(x\frac{\partial Y}{\partial x} + y\frac{\partial Y}{\partial y}\right), \quad (3.336a, b)$
```

that is equivalent to:

```
$\frac{\partial}{\partial y}\left(\frac{X}{XX+YY}\right) - \frac{\partial}{\partial x}\left(\frac{Y}{XX+YY}\right) = \quad (3.336c)$
```

The proof of (3.336c) follows from:

```
$(XX+YY)\left[\frac{\partial}{\partial y}\left(\frac{X}{XX+YY}\right) - \frac{\partial}{\partial x}\left(\frac{Y}{XX+YY}\right)\right]\n=(XX+YY)\left(x\frac{\partial X}{\partial y} + y\frac{\partial X}{\partial y}\right) + Y\left(x\frac{\partial Y}{\partial x} + y\frac{\partial Y}{\partial y}\right) + X\right) \quad (3.337)\n=Y\left(x\frac{\partial Y}{\partial x} + y\frac{\partial Y}{\partial y}\right) - X\left(x\frac{\partial X}{\partial x} + y\frac{\partial X}{\partial y}\right) = 0.$
```

The identities (3.336a, b) = (3.33c) for homogeneous functions (x, y) of the same degree (3.335), are used next (note 3.17) to integrate homogeneous first-order differentials.
