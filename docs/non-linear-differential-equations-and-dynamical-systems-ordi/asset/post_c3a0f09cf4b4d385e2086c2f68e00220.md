## 4.7.14 Periods of the Circulatory and Oscillatory Motions

The period of the circulatory motion is (4.393a) twice the time taken to travel from $\theta=0$ to $\theta = \pi$, or (4.391a) from $\psi = 0$ to $\psi = \pi/2$ leading to (4.399a, b):

```
$$\tau_1 = 2f(\pi) = \frac{4}{\dot{\theta}_0} \int_0^{\pi/2} |1 - \frac{1}{q^2} \sin^2 \psi| d\psi \quad (4.399a-d)$$
```

```
$$\frac{4}{\dot{\theta}_0^2} \sum_{n=1}^{\infty} (\frac{1}{2q})^n \frac{(2n-1)!!}{(2n)!!}\frac{1}{(n!)^2} = \frac{2\pi}{\dot{\theta}_0} A(\frac{1}{q}),$
```

where (4.392a) [4.252b] were used in (4.399c) [4.399d]. The function $A(q^{-1})$ has power series (4.252b) with coefficients (4.400b):

```
$$A(\frac{1}{q}) = 1 + \sum_{n=1}^{\infty} a_n q^{-n}, \quad a_n = \frac{(2n)!}{(n!)^2}. \quad (4.400b, b)$$
```

The coefficients are given by (4.400b) = (4.400d):

```
$$a_n = \frac{2n(2n-1)(2n-2)...3.2}{2n(2n-2)...4.2} \quad (4.400c-e)$$
```

```
$$\frac{(2n-1)(2n-3)...3.1}{2n(2n-2)...4.2} = \frac{(2n-1)!!}{(2n)!!}$$
```

in agreement with (4.400b-e) = (4.248a, b) = (4.66a, d). The oscillatory motion has amplitude (4.382b, 4.392a = 4.401a) corresponding (4.394a) to (4.401b) and hence:

```
$$\sin\theta_{max} = \frac{|\dot{\theta}_0|}{2\omega_0} q; \sin\varphi_{max} = \frac{1}{q} \sin\theta_{max} = 1, \quad \varphi_{max} = \pi/2. \quad (4.401a-c)$$
```

The period of oscillation is four times the time taken to travel from $\theta=0$ to $\theta_{max}$, that is, from $\varphi=0$ to $\varphi=\pi/2$ in (4.395):

```
$$\tau_2 = \frac{\pi}{\omega_0} \int_0^{\pi/2} |1-q^2 \sin^2 \varphi| d\varphi = \frac{4}{\omega_0} A(\frac{\pi}{2}) = \frac{2\pi}{\omega_0} A(q),$quad (4.402a-c)$$
```

in terms of the same function (4.400a).

## 4.7.15 Convergence of the Series Specifying the Exact Period

The periods of the circulatory (4.403b)[oscillatory (4.404b)] pendular motion are specified exactly by series whose convergence is specified by the ratio (4.410) of successive coefficients (4.400e):

```
$$\frac{a_{n+1}}{a_n}=\left[\frac{2n+1}{2n+2}\right]^3=\left[\left(1+\frac{1}{2n}\right)\left(1-\frac{1}{n}\right)\right]^3$$
$$=\left(1-\frac{1}{2n}\right)^2=1-\O\left(\frac{1}{n}\right)^2;\quad (4.410)$$
```

The combined convergence test (subsection I.29.1) specifies convergence of the series (4.403b;4.404b) of the non-linearity parameter (4.392a). The logarithmic series (II.3.48b=4.411a) has coefficients (4.411b) like the arithmetic metrics which have the same ratio (4.411d) to order $n^2$:

```
$$-\log(1-z)=\sum_{n=1}^{\infty}z^n=\sum_{n=1}^{\infty}d_n z^n,\quad d_n=\frac{d_{n+1}}{d_n}=1-\frac{1}{n}+O\left(\frac{1}{n^2}\right)^2;\quad (4.411a-d)$$
```
