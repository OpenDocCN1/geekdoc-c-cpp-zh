# 3.9.6 Inexact Differential without an Integrating Factor

Consider a first-order differential in three variables (3.219) $\equiv$ (3.245b) with (standard-ard LXXVI) continuously differentiable vector of coefficients (3.232a) $\equiv$ (3.245a) with non-zero helicity (3.245d) and hence non-zero curl (3.245c):

```
$$\tilde{X} \in c^1(\mathbb{R}^3): \quad \tilde{X} \cdot d\mathbf{x} = 0, \quad \nabla \times \tilde{X} \neq 0. \tilde{X} \cdot (\nabla \times \tilde{X}) = H. \quad (3.245a-d)$
```

(Then) an arbitrary differentiable function (3.246a) can be imposed (3.246b) specifying the differential of one variable in terms of the others (3.246c):

```
$$\Psi(x,y,z) \in c^1(\mathbb{R}^3): \quad 0 = d\Psi = \frac{\partial \Psi}{\partial x}dx + \frac{\partial \Psi}{\partial y}dy + \frac{\partial \Psi}{\partial z}dz,\n dz = -\frac{\partial \Psi}{\partial z}dx - \frac{\partial \Psi}{\partial y}dy; \quad (3.246a-c)$
```

(ii) substitution of (3.246c) in the inexact non-integrable differential in three variables (3.219) leads to a differential in two variables (3.247a):

```
$$\0 = \left(X-Z\frac{\partial \Psi /\partial x}{\partial \Psi /\partial z}\right)dx+\left(Y-Z\frac{\partial \Psi /\partial y}{\partial \Psi /\partial z}\right)dy = \lambda^{-1}d\Phi, \quad \Phi(x,y,z)=C,\ \quad (3.247a-c)$
```
