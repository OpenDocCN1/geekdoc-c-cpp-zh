# 3.9.5 Plane Curves and Curves with Torsion

A plane vector (3.243a) has curves (3.223a, b) orthogonal to the plane (3.243b) and hence the helicity that is the inner product of the vector is zero (3.243c):

```
$\tilde{X} = \tilde{e}_x A + \tilde{e}_y B, \quad \nabla \cdot \tilde{X} = \nabla (\frac{\partial B}{\partial x} - \frac{\partial A}{\partial y}) = 0, \quad H \equiv \tilde{X}(
abla \times \tilde{X}) = 0. \quad (3.243a–c)$
```

It has been shown that a plane vector (3.243a) has zero helicity (3.243c) and a differential in two variables always has an integrating factor, in agreement with subsection 3.9.1; the geometric interpretation (Figure 3.6) is that a continuously differentiable vector field in the plane has an orthogonal family of curves. The helicity is a measure of the deviation from a plane and corresponds to a curve with *torsion* in space. For example, a cylindrical helix with (Figure 3.8) constant radius $a$ and inclination $\alpha$ has cylindrical coordinates (3.244a):

```
$\tilde{X} = \tilde{e}_r a + \tilde{e}_z \sin \alpha \phi, \quad \nabla \cdot \tilde{X} = \frac{1}{a} \partial_phi \tilde{X}_z = \alpha \sin \alpha, \quad H \equiv \tilde{X}(\nabla \times \tilde{X}) = 0. \n\n(3.244a–c)$
```

corresponding to: (i) the curl (3.241b) in cylindrical (III.6.1) and (ii) constant helicity (3.244c). In three-dimensions: (i) is similar for a vector field with zero curl which the differential is exact (is inexact by having an integrating factor), so that an orthogonal family of surfaces exists (Figure 3.7); and (ii) if the vector of coefficients has non-zero helicity, because an orthogonal family of surfaces does not exist. In the last case the integrability condition of zero helicity is replaced by an integrating function $\Psi$, together with the integrating factor $\lambda$ and general integral $\Phi$ satisfies the three components of the vector of coefficients in three variables (subsection 3.9.6).
