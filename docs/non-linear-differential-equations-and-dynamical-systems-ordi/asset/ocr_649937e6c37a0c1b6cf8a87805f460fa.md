# Differentials and First-Order Equations

Conversely, multiplying an inexact differential by a suitable integrating factor may render it exact, and hence lead to the general integral. For example the differential:

```
$0 = d\Phi = \tan y \ dx + \tan x \ dy
```

is inexact since the coefficients (3.169a, b) do not satisfy (3.169a) the integrability condition (3.148c):

```
${X, Y\} = {\tan y, \tan x\}: \quad \frac{\partial Y}{\partial x} = \sec^2 x \neq \sec^2 y = \frac{\partial X}{\partial y} \quad (3.169a-c)$
```

When multiplied by the integrating factor (3.169a):

```
$\lambda = \cos x \cos y; \quad \lambda d\Phi = \cos x \sin y \ dx + \cos y \sin x \ dx, \quad (3.169a, b)$
```

the inexact differential form (3.168) becomes (3.169b), which is an exact differential (3.170a):

```
$0 = d\Phi = d(\sin x \sin y), \quad \sin x \sin y = C, \quad (3.170a, b)$
```

and leads to the general integral (3.170b) of (3.168). This raises the question of the existence of an integrating factor for an inexact differential in two variables that is proved next (subsection 3.8.4).

# 3.8.4 Existence of Integrating Factor for an Inexact Differential

Any explicit differential equation (3.145b), even if it is inexact, can be put into the form:

```
$\frac{\partial y}{\partial x} = \frac{X(x,y)}{Y(x,y)}, \ (3.171)$
```

It has a solution (3.146c) implying (3.146b) and hence:

```
$\frac{\partial y}{\partial x} = \frac{\partial \Phi / \partial x}{\partial \Phi / \partial y}, \quad (3.172)$
```

Equating (3.171) $\equiv$ (3.172) leads to (3.173a):

```
$\frac{X}{Y} \frac{\partial \Phi / \partial x}{\partial \Phi / \partial y} = \frac{1}{X \ \partial x} \frac{1}{Y \partialpartial y} \equiv \lambda, \quad (3.173a-c)$
```
