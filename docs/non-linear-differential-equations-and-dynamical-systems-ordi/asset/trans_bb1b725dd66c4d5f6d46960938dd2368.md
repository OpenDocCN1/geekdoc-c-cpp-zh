# 微分与一阶方程

## 3.1.2 积分常数与边界条件

前述几何性质可以用解析术语重新表述：第一阶微分方程 (3.1a, b) 的通解 (3.2) 包含一个任意积分常数 C，并包含在 C 的特定取值下所有的特解。严格证明将在第 9.1 节给出，这里给出启发式解释；可能存在未包含在通解中的奇异积分（第 5 章）。若对通解 (3.2) 关于 x 求微分，则得到

$$\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y} = 0, \quad (3.3)$$

其中偏导数可能依赖于积分常数 C。以 C 为参数，并在 (3.2) 与 (3.3) 之间消去，可回到一阶微分方程 (3.1b)。如果通解 (3.2) 包含多于一个积分常数，例如两个 C, C_v，则消去 C 后，剩余常数 C_o 将出现在 (3.1b) 中。如果通解 (3.2) 不包含积分常数，则一般情况下无法通过 (3.3) 消去得到 (3.1b)，除非是奇异或特殊（第 5.1-5.4 节）积分的情况。除特殊情况外，一阶 (3.1a) 微分方程 (3.1b) 的通解 (3.2) 包含一个可由边界条件确定的任意积分常数：

$$f(x_0, y_0, C) = 0, \quad (3.4)$$

选择通过给定点的积分曲线，假定存在且唯一。

## 3.1.3 代数、分析与微分方程

微分方程可以被视为第三层问题，因为当它化为分析问题，如积分时即被认为已求解。因为，最简单的常微分方程一阶方程 (3.5b)：

$$f \in E(|\mathbb{R}|), \quad y' = f(x), \quad y = \int_{0}^{x} f(\xi)d\xi + C, \quad (3.5a–c)$$

其中 f(x) 是可积函数 (3.5a)，其通解 (3.5c) 由一次积分或求积得到，包含一个任意积分常数。无论积分是否初等，进行积分都是分析的第二层问题。问题的求解可能导致隐式通解 (3.2) 或显式形式 (3.6)，涉及代数方程的根，例如具有常数（齐次）系数的线性微分方程的特征多项式 [1.3-1.5 (1.6-1.8)]。求根或得到一个或多个显式解的形式：

y = y(x; C),

是代数的第一层问题。于是存在四层问题层次：(i) 第一层为代数；(ii) 第二层为分析，涉及方程或求积；(iii) 第三层为微分方程，涉及函数与其导数之间的关系；(iv) 第四层为变分问题，其解导致微分方程。

## 3.1.4 求积与不定积分求解

当微分方程的解可由积分表达时，该微分方程可由求积求解，例如 (3.5c) 是微分方程 (3.5b) 的求积解，其中函数 f 可积 (3.5a)。通解 (3.5b) 指定了一族积分曲线，它们彼此仅沿 y 轴平移而不同（图 3.3）；因此每一点 (x0, y0) 仅通过一条曲线：

y - y0 = ∫f(ζ)dζ - ∫x0 f(ζ)dζ = ∫f(ζ)dζ,

因此在通解 (3.5c) 中的不定积分被特定解对应的积分常数中的定积分 (3.7a) 所取代：

C = y0 - ∫f(ζ)dζ,

一阶常微分方程的例子是斜率为线性 (3.8a) 的情形：

y' = 2x, y = x^2 + C,

其通解 (3.8b) 是一族抛物线（图 3.4），在 y 轴 x = 0 处截得 y = C，例如通过原点的抛物线是特解 C = 0。 一阶微分方程的解可能由 N 个函数族组成，如果它是 N 次的（小节 5.4.4）；接下来给出 N = 2 次的例子（小节 3.1.5）。

## 3.1.5 二次微分方程的二重点

一阶微分方程是显式的，如果它可以关于斜率求解 (3.9a)，并且是 M 次的，如果它是导数的多项式 (3.9b)：

$y' = f(x,y), \quad \prod_{m=1}^{M} [y' - f_m(x,y)] = 0. \quad (3.9a, b)$

二次微分方程的一个简单情形是 (3.10a)：

$0 = y'^2 - [f_+(x) + f_-(x)]y' + f_+(x)f_-(x) = [y' - f_+(x)][y' - f_-(x)], \quad (3.10a)$

$f_+(x, y, C_3) = 0$

$f_+(x, y, C_2) = 0$

$f_+(x, y, C_1) = 0$

![](img/6a4cb3b3bd1429197bb791c4b642651c_30_0.png)

**图 3.5** 如果在所有点都有多个斜率，则通解由若干曲线族组成，例如一阶关于斜率为二次的微分方程有两族。

其通解为两个曲线族 (3.10b, c)：

$y_z(x) = C + \int^x f_z(\xi)d\xi. \quad (3.10b, c)$

对于常数 C 的每个取值都有曲线，因此平面中的正则点（图 3.5）是二重点；与图 3.3 中的不同，它们并非由曲线自身相交产生。通解为 (3.10d)：

$0 = \left(y_+(x) - \int^x f_+(\xi)d\xi - C\right)\left(y_-(x) - \int^x f_-(\xi)d\xi - C\right), \quad (3.10d)$

因为它满足 (3.10b, c) 中的任一个；(3.10b, c) ≡ (3.10d) 中只有一个积分常数，因为常微分方程 (3.10a) 为一阶。

# 微分与一阶方程

## 3.2.1 显式与可分离微分方程

一阶显式微分方程 (3.1b) 是显式的 (3.9b) ≡ (3.11a) 如果它可以关于斜率求解：

$$\frac{dy}{dx} = y' = g(x,y) = \frac{X(x)}{Y(y)}, \quad (3.11a, b)$$

如果此外函数 $g(x,y)$ 分裂为两个函数之比，一个关于每个变量，则微分方程 (3.11b) 是可分离的（标准 L）：

$$Y(\eta)d\eta = C - \int^{x} X(\xi)d\xi, \quad (3.11c)$$

并且可以通过求积 (3.11c) 积分。例如，可分离方程 (3.12a)：

$$\frac{dy}{dx} = ye^{x}, \quad y(x) = C\exp(e^{x}), \quad (3.12a, b)$$

具有通解 (3.12b)，因为：

$$\log y = \int_{y} \frac{dy}{y} = \int e^{x} dx + C_1 = \exp(e^{x}) + \log C. \quad (3.13a, b)$$

从 (3.13a) 到 (3.12b) 的过渡中，exp 被 C 取代，因为任意常数的指数（或任何函数）是另一个任意常数；或者，常数在 (3.13b) 中可指定为 $C_1 = \log C$ 以保持一致性 (3.13a) ≡ (3.13b)。对 (3.12b) 关于 x 求微分：

$$y' = Ce^{x}(e^{x}) = e^{y}, \quad (3.14)$$

提供了一个检验，证明它确实是微分方程 (3.12a) 的解。积分曲线 (3.12b) 不会通过原点 $y=0$ 对任何有限的 x 值，并且当 $x \rightarrow -\infty$ 时渐近于水平线 $y \rightarrow C$。边界条件 (3.15a)：

$$1 = y(0) = Ce; \quad y(x) = \frac{\exp(e^{x})}{e} = \exp(e^{x}-1), \quad (3.15a, b)$$

指定常数并导致唯一解 (3.15b)。
