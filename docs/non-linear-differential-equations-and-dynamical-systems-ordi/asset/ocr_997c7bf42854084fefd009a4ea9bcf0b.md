# Unsteady, Non-Linear, and Chaotic Systems 221

A rotationally invariant perturbation (4.444a) does not depend on the angle and is symmetric relative to the origin:

$\Psi(r,t) = \Psi(r,-t) \in C(\mathbb{R}); \quad \Psi(r) = \frac{\mu r^4}{4}, \frac{dr}{dt} = qr + \mu r^3, \quad (4.444a-c)$

if the function (4.444a) has a fourth-order derivative, the leading non-linear term is a cubic in the potential (4.444b), leading to a cubic in the dynamic system (4.444c) and the azimuthal perturbation (4.443a) is unchanged. Thus only the radial perturbation (4.444c) need be considered leading to the super(sub)critical Hopf bifurcation discussed next (subsection 4.8.5) intermediate:

# 4.8.5 Subcritical andcritical Bifurcation (Hopf 1943)

For small radius the second parameter in (4.444c) can be neglected, and the first parameter (4.445a) allows (4.445b) to: (i/ii) stability (instability) for $q<0(q>0)$ in (4.445c)[[4.445e]; or (iii) indifferent equilibrium (4.445d) in the intermediate

```
\mu=0: \frac{dr}{dt}=qr, \quad r(t)=r_0 \times \begin{cases} \exp(-|q|) & \text{if } q<0; \text{stable}, \ & & \text{if } q=0; \text{indifferent}, \ & & \text{if } q>0; \text{unstable}, \end{cases} \quad (4.445a-e)$
```

For large radius the first parameter in (4.444c) can be neglected (4.446a) and the second parameter (4.446b) leads to (4.446c):

```
$q=0: \frac{dr}{dt}=\mu r^3 \quad \mapsto \quad 2\mu t = \int_m^r \frac{dr'}{r'^2} = \frac{1}{m}, \quad (4.446a-c)$
```

that implies (4.446c) = (4.446d) stability (instability) for $\mu<0(\mu>0)$ in (4.446e)[[4.446f]].

```
$[r(t)]^2 = \frac{r_0^2}{1-2\mu t^2} \quad \begin{cases} \text{stable} & \text{for } \mu<0, \ \text{unstable} & \text{for } \mu>0, \end{cases} \quad (4.446d-f)$
```

that is finite for positive time (infinite for $t=1/(2\mu t^2)$). For intermediate radius both parameters should be considered (4.444c) = (4.447a) and affect the existence of a **limit cycle** (4.447b) with constant radius:

```
\frac{dr}{dt}=r(q+\mu r^2)=0, \quad r=\begin{cases} |q|^{1/2} & \text{if } \mu>0; \text{no limit cycle} \ \mu & \text{if } \mu<0; \text{limit cycle}, \end{cases} \quadquad (4.447a-c)$
```
