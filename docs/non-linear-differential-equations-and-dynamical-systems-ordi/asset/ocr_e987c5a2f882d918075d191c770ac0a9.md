# Non-Linear Differential Equations and Dynamical Systems

NOTE 3.18: Extension to Homogeneous Differentials in N Variables

The preceding results extend to first-order differentials in N variables: if the functions (3.344a) are homogeneous of degree q

```
$X_n(x_1,...,x_N) = (x_1)^q X_n\left(\frac{x_2}{x_1}, \frac{x_N}{x_1}\right) \Leftrightarrow \sum_{m=1}^n x_m \frac{\partial X_n}{\partial x_m} = qX_n; \quad (3.344a, b)$
```

from (3.344b) it follows that: (i) (the standard LXXXVIII) first-order differential

```
$d\Psi = \sum_{m=1}^N X_m dx_n; \quad d_n = \frac{1}{\lambda} \sum_{m=1}^N X_n dx_n; \quad (3.345a, b)$
```

has integrating factor (3.345b); and (ii) if the first-order differential (3.345a) is exact (3.346b) and (standard LXXXIX) the vector of coefficients is homogeneous (3.343a) of degree (3.346a):

```
$q \neq -1; \quad d\Phi = \sum_{n=1}^N X_n dx_n \Rightarrow \sum_{n=1}^N X_n x_n = C; \quad (3.346a-c)$
```

then the general integral is (3.346c).

NOTE 3.19: Integration of an Homogeneous First-Order Differential of Degree Two

As an example, consider the first-order differential in two variables (3.347a), that is homogeneous of degree two:

```
$(x^2+y^2)dx-xy=0; \quad \frac{1}{\lambda}=x(x^2+y^2)-xy^2=x^3; \quad (3.347a, b)$
```

its integrating factor (3.347b). Dividing (3.347a) by (3.347b) leads to an exact differential (3.348a):

```
$0 = \frac{dx}{x} + \frac{y^2}{x^3}dx - \frac{y}{x^3}dy = d\left(\log x - \frac{y^2}{2x^2}\right); \quad \log x = C + \frac{y^2}{2z^2}; \quad (3.348a, b)$
```

that specifies the general integral (3.348b) of (3.347a).
