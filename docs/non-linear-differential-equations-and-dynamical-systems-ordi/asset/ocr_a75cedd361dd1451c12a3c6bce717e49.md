Using the identity (II.5.88c) = (4.117b) = (4.291):

$2\cos(2\omega) \sin(\omega) = \sin(3\omega) - \sin(\omega), \quad (4.291)$

in (4.290) leads to:

```
$\tilde{x}_3 + \omega^2 x_3 = \left( 2\omega_2\omega + \omega_0^2\alpha^2 a^2 - \frac{\omega^2\beta a^2}{2} \right) a \sin(\omega)\\n+\frac{\omega_0^2 a^3}{2} \left( \frac{\alpha^2}{3} + \frac{\beta}{2} \right) [\sin(3\omega) - \sin(\omega)], \quad (4.292)$
```

that simplifies to:

```
$\tilde{x}_3 + \omega^2 x_3 = \left[ 2\omega_2\omega + \omega_0^2\alpha^2 \left( \frac{5\alpha^2}{6} - \frac{3\beta}{4} \right) \right] a \sin(\omega) + \frac{\omega_0^3 a^3}{2} \left( \frac{\alpha^2}{3} + \frac{\beta}{2} \right) \sin(3\omega), \quad (4.293)$
```

consisting of a resonant (non-resonant) term, namely the first (second) on the r.h.s. of (4.293).

# 4.5.4 Frequency Change and Generation of Harmonics

The resonant term first on the r.h.s. of (4.293) is eliminated by the secular condition setting the coefficient to zero (4.294a), and the first order (4.283a) approximation $\omega - \omega_0$ can be substituted in the second order leading to (4.294b):

```
$\omega - \omega_0 = \omega_0 \frac{\omega_0^2 a^2}{2\omega} \left( \frac{3\beta}{2} - \frac{5\alpha^2}{6} \right) - \frac{\omega_0^2 a^2}{2} \left( \frac{3\beta}{4} - \frac{5\alpha^2}{6} \right), \quad (4.294a, b)$
```

The solution of the differential equation (4.293) is fixed by the second term on the r.h.s. alone:

```
$x_3(t) = \frac{\omega_0^3 a^3}{16\omega^2} \left( \frac{\alpha^2}{3} + \frac{\beta}{2} \right) \sin(3\omega). \quad (4.295)$
```

The first-order approximation (4.285a) may be used in the second-order approximation (4.294a, b), leading to the frequency:

```
$\omega = \omega_0 \left[ 1 + \frac{a^2}{4} \left( \frac{3\beta}{2} - \frac{5\alpha^2}{3} \right) \right], \quad (4.296)$
```
