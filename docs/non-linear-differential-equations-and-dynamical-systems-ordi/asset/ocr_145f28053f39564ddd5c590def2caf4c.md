# 4.7.13 Two Equivalent Exact Solutions in Term of Elliptic Sines

The change of variable (4.391a) in the general equation of energy for a pendulum (4.384) leads to (4.391b):

```
$$\Psi = \frac{\theta}{2}; = \frac{\dot{\theta}_0}{2} = \int^{1-\left(\frac{2\omega_0}{\dot{\theta}_0}\right)^{-2}}^{-1/2} \sin^2 \psi \ d\psi = \operatorname{arg} \sin\left(\frac{1\Psi}{q}\right), \quad (4.391a, b)$
```

that is (4.246b) an elliptic sine integral (4.392b) with modulus 1/q given by the **non-linearity parameter** (4.392a):

```
$$\q = \frac{\dot{\theta}_0}{2\omega_0} = \sin\left(\frac{\dot{\theta}_0 t}{2} \frac{2\omega_0}{}\right). \quad (4.392a, b)$
```

Thus (4.392b) is an exact solution for the large amplitude pendulum motion. An alternative form of this exact solution can be obtained rewriting (4.391b) $\equiv$(4.393a) as (4.393b):

```
$$\frac{\dot{\theta}_0}{2} = \int_0^{\psi} |1-q^{-2} \sin^2 \psi|^{-1/2} d\psi \longleftrightarrow \omega_0 t = \frac{1}{2q} \int_0^{\psi} |q^2-\sin^2 \psi|^{-1/2} d\psi. \quad (4.393a, b)$
```
