# 4.3.10 Pairs of Mathieu Cosine and Sine Functions

Besides the two pairs of Mathieu cosine and sine functions $(4.137c, d)$, with period $\pi$, and $(4.137e, f)$ with period $2r$, it is possible to obtain pairs with period $p\pi$ for all positive integer $p$. These are incompatible: (i) for different periods; and (ii) between Mathieu cosine and sine functions. The reason is that in each case the set of eigenvalues $(4.137a, b)$ is distinct. Thus none of the preceding solutions can be used as a particular integral of the Mathieu equation.
