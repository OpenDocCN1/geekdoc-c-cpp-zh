# 4.8.4 Non-Linear Perturbation of a Spiral Flow A constant angular velocity (4.442a) and linear radial velocity (4.442b) form a linear dynamical system (4.442c) to a spiral flow (4.442d):

$$\frac{d\theta}{dt} = \Omega = const, \quad \frac{dr}{dt} = \frac{q}{\Omega}r, \quad \Omega\log r - q = const. \quad (4.442a–d)$$

The general non-linear perturbation of (4.43a), corresponding to a gradient dynamical system is:

$$\frac{d\theta}{dt} = \Omega + \frac{\partial\Phi}{\partial t}, \quad \frac{dr}{dt} = qr + \frac{\partial\Phi}{\partial r}. \quad (4.43a, b)$$
