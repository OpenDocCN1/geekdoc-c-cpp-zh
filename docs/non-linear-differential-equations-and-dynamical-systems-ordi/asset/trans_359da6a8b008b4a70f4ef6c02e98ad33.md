## 3.7 非线性一阶齐次微分方程

齐次或非齐次微分方程的称谓有三种不同的含义，其中两种（一者不）相关。第一个含义 (i) 是微分方程 (1.1a, b) 是齐次

（非齐次）如果它具有（不具有）平凡解 $y=0$；例如线性微分方程在受迫 (1.54) [受迫 (1.33)] 时是齐次（非齐次）。受迫（非受迫）线性微分方程的称谓更为可取，因为它与在另外两种含义中的齐次（非齐次）微分方程无关。第二个含义 (ii) 是具有齐次系数的线性微分方程，其可以受迫(1.291a) [受迫 (1.285)] 且阶数任意；它涉及齐次 (1.300b) 而非普通 (1.53) 导数，且在自变量的重新标度 (1.300a, b) 下保持不变。在一阶具有齐次系数的微分方程情形下，导数 $y'$ 是 $y/x$ 的线性函数。这可由 (第 3.7 节) 推广，其中导数 $y'$ 是从属变量与自变量之比 $y/x$ 的任意函数，通常是非线性的。具有齐次系数的线性微分方程 (第 1.6 节) 可通过对应特征多项式的根求解任意阶。非线性情形可通过积分求解一阶微分方程 (小节 3.7.2)。非线性齐次一阶微分方程不受自变量和从属变量同时重新标度的影响 (小节 3.7.1)；在线性微分方程任意阶的情形 (第 1.6 节) 中，不变性也适用于自变量的重新标度 (小节 1.6)。因此齐次微分方程可求解：(i) 线性情形任意阶 (第 1.6–18 节)；(ii) 非线性情形一阶 (小节 3.7.1–3.7.3)。

### 3.7.2 线性与非线性齐次微分方程

齐次一阶微分方程 (3.127) 的形式提示变量替换 (3.131a)：

```
$v=\frac{y}{x}; \quad y'=(vx)'=vx'+v;$ (3.131a, b)
```

该替换将 (3.131b) 转化为可分离的微分方程 (3.132a) (3.132b)：

```
$f(v)-v=x\frac{dv}{dx}, \quad \int\frac{dv}{f(v)-v}+\log C=\int\frac{dx}{x}=\log x;$ (3.132a, b)
```

解可通过积分或二次式求得：

```
$x=CExp\left{\int^{y/x} \frac{dv}{f(v)-v}\rightright};$ (3.133)
```

因此，(标准 LXIV) 齐次非线性一阶微分方程 (3.127) 的一般积分为 (3.133)。

在线性情形 (3.128a) 下，(3.133) 的 (3.134a) 导致 (3.134b)：

```
$f(v)=av+b; x=CExp\left{\int^{y/x} \frac{dv}{(a-1)v+b}\right}=CExp\left{\log\left[(a-1)y/x+b\right]}{a-1}\right,$; (3.134a, b)
```

作为一般积分 (3.135b, c)：

```
$a \neq 1: \quad x=C\left[(a-1)\frac{y}{x}+b\right]^{1/(a-1)}, \quad y(x)=\frac{x}{a-1}\left[\frac{x}{C}\right]^{a-1}-b\right], \quad (3.135a-c)$
```

即线性齐次一阶微分方程 (3.128a, b) 在情形 (3.135a) 下的一般积分；剩余情形 (3.136a) 由 (3.133) 导致 (3.136c)：

```
$a=1: \quad f(x)=v+b, \quad x=C_0\exp\left\\{\frac{1}{b}\int \frac{y}{x}dv\right\}=C_0\exp\left(\frac{y}{bx}\right), \quad (3.136a-c)$
```

表明 (3.136e)：

```
$xy'=y+b, \quad y(x)=bx\log\left(\frac{x}{C_0}\right), \quad (3.136d, e)$
```

是 (3.136d) 的完全积分。
线性齐次微分方程 (3.128b) 也可使用 (1.292a-c) 通过特征多项式 (3.137b) 求解：

```
$a \neq 1: \quad P_1(\delta)=\delta-a: \quad y(x)=C_1x^{\delta}=C_1x^{\frac{bx}{P_1(1)}}{1-a'}}, \quad (3.137a-c)$
```

### 3.7.3 变量替换与积分求值

作为示例，齐次非线性微分方程 (3.140a) 的解：

```
$y' = \frac{y+x}{y-x'}, \quad C = y^2 - 2xy - x^2, \quad y = x \pm\sqrt{2x^2+C}, \quad (3.140a-c)$
```

为 (3.140b) = (3.140c)，因为 (3.140a) 对应于 (3.127) 且 $f(v)$ 由 (3.141a) 指定：

```
$f(v) = \frac{v+1}{v-1} \frac{x}{\sqrt{C}} = \exp\left{\int^{v/x} \left(\frac{v+1}{v-1} - v\right)^{-1} dv\right} = \exp\left{\int^{v/x} \frac{v-1}{v^2-2v-1} dv\right}$
= \exp\left{-\frac{1}{2}\log\left|\frac{y^2}{x^2}-\frac{2y}{x}-1\right|\right) = x\left|\frac{y^2}{x^2}-\frac{2y}{x}-1\right)^{-1/2}$
(3.141a, b)$
```

于是 (3.133) 变为 (3.141b)；解 (3.141b) 是 $x$ 与 $y$ 之间的隐式关系 (3.140b)，可通过将其作为 $y$ 的二次式求解而显式化 (3.140c)。

另一个示例是非线性一阶齐次微分方程 (3.142a)，对应于 (3.127) 到 (3.142b)：

```
$y' = \frac{x^2+y^2}{xy-x^2}, \quad f(v) = \frac{v^2+1}{v-1}, \quad f(v)-v = \frac{v+1}{v-1};\quad (3.142a-c)$
```

将 (3.142c) 代入积分式 (3.133) 得到：

```
$\log\left(\frac{x}{C}\right) = \int^{y/x} \frac{v-1}{v+1} dv = \int\left(1-\frac{2}{v+1}\right) dv = -2\log\left(1+\frac{y}{x}\right);\quad (3.143)$
```

对应于 (3.144a)：

```
$\frac{x}{C} = \left(1+\frac{y}{x}\right)^{-2}\exp\left(\frac{y}{x}\right), \quad (x+y)^2 = C\exp\left(\frac{y}{x}\right);\quad (3.144a, b)$
```

即 (3.142a) 的一般积分 (3.144a) = (3.144b)。
