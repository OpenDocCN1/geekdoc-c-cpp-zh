**NOTE 3.5:** Integrable Differential in N Variables

```
$0 = x_2 dx_1 + x_1 dx_2 + \frac{x_1x_2}{x_4} dx_3 - \frac{x_1x_2x_3}{(x_4)^2} dx_4, \quad (3.285)$
```

