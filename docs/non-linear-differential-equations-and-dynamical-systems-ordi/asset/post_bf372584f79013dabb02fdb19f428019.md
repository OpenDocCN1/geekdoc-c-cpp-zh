## 4.3.18 Parametric Resonance at Sub-multiples of the First Harmonic

The parametric resonance is stronger (weaker) for excitation at twice (at) the natural frequency and the range of frequencies ([4.161d]) ([4.176]) is wider (narrower). Using similar methods ([subsection 4.3.13 to 4.3.14]) it follows that an undamped oscillator (problem 100) with natural frequency excited at any sub-multiple (4.193a) of the first harmonic (4.193b) of the natural frequency ([4.87a]); (i) has parametric resonance (Figure 4.5a) in the frequency range (4.193c) which becomes narrower with increasing order; (ii) one-quarter of the width of the frequency range for parametric resonance specifies the characteristic exponent (4.193d) for the maximum exponential growth of the amplitude with time (4.193e):

```
$n=0,1,2,...dots; \quad \omega_x = \frac{2\omega_0}{n+1} - \frac{2\omega_0}{n+1} < \delta_n - \omega_0 h^{n+1} = 2b_n; \quad x_n(t) = \exp(b_n t);\n(4.193a-e)
```

```
$\omega_x - \frac{2\omega_0}{n+1} < \delta_n - \sqrt{\omega_0^2h^{2n+2}-4\lambda^2} = 2b_n, \quad x_n(t) = \exp[(b_n-\lambda)t];\n(4.194a-c)
```

in the presence (problem 101) of damping: (i) the frequency range (4.194a) of parametric resonance is narrower (Figure 4.5b); (ii) the characteristic exponent is reduced (4.194b) leading to an exponential growth of the amplitude with time (4.194c) that is slower and in addition reduced by damping; (iii) there is a minimum threshold amplitude of excitation (4.195a) that increases (Figure 4.5c) with the order (4.195b) thus (iv) means beyond a certain order k is surpassed (4.195c) by damping:

```
$h_n - O(h_0^{1/n}) - \sqrt{\frac{2\lambda}{\omega_0}} > \frac{2\lambda}{\omega_0} = h_0 < h_1^{1/2} < h_2 < h_0^{1/3} < ... < h_n < h_0^{(1/n)}\n(4.195a, b)
```

```
$h_0 < h_1 < h_2 < ... < h < h < ... < h_n ...\n(4.195c)
```
