
## 4.6.6 Non-Linear Parametric Resonance by Forcing at the First Harmonic

The forcing of a linear oscillator (4.320b) at an applied frequency close (4.302b) to the first harmonic of the natural frequency (4.320a) leads to the response (4.320b).

```
$$\omega_a = 2(\omega_0 + \varepsilon); \quad \ddot{x}_1 + \omega_0^2 x_1 = f_a \cos(\omega_0 t), \quad x_1(t) = -\frac{f_a}{3\omega_0} \cos[2(\omega_0 + \varepsilon)t].$$
```

(4.320a–c)

The first-order approximation for the linearly damped harmonic oscillator (4.303) is (4.321):

```
$$\ddot{x}_2 + 2\lambda\dot{x}_2 + \omega_0^2(x_2 + \alpha x_2^2) = -2\alpha\omega_0\dot{x}_1x_2 + \dots$$
```

where the r.h.s. retained only the term leading to forcing at twice the natural frequency (4.320a). Substitution of (4.320c) in (4.321) leads to:

```
$$\ddot{x}_2 + 2\lambda\dot{x}_2 + \omega_0^2x_2 \left[1 - \frac{2\alpha f_a}{3\omega_0} \cos[2(\omega_0 + \varepsilon)t]\right] + \omega_0^2(\alpha x_2^2 + \beta x_2^3) = 0,\ (4.322a)$$
```

that corresponds to section 4.3 to parametric resonance (4.181) in terms of (4.322b) of the oscillation frequency (4.304a):

```
$$\ddot{x}_2 + 2\lambda\dot{x}_2 + \omega_0^2x_2 = \omega_0^2\frac{2\alpha f_a}{3\omega_0} \cos[2(\omega_0 + \varepsilon)t].$$ \ (4.322b)
```

Substituting (4.323a, b) in the parametric term on the r.h.s. of (4.322b) leads to (4.323c):

$$\omega \sim \omega_0, x_2(t) \sim \cos[(\omega_0 + \varepsilon)t]:$$

```
$$\frac{2\alpha f_b\omega_0^2}{3\omega_0^2}x_2 \cos[2(\omega_0 + \varepsilon)t] \sim \frac{2\alpha f_b}{3\omega_0} \cos[(\omega_0 + \varepsilon)t] \cos[2(\omega_0 + \varepsilon)t]$\\
= \frac{\alpha f_b}{3\omega_0} [\cos[(\omega_0 + \varepsilon)t] + \cos[3(\omega_0 + \varepsilon)t]];$\$\n\quad (4.323a–c)$$
```

the term of frequency $3(\omega_0 + \varepsilon)$ is non-resonant, and is omitted from (4.323c) when substituting in the r.h.s. of (4.322b), leading to (4.323d):

```
$$\ddot{x}_2 + 2\lambda\dot{x}_2 + \omega_0^2x_2 = \frac{\alpha f_b}{3\omega_0} \cos[(\omega_0 + \varepsilon)t].$$ (4.323d)
```

## Unsteady, Non-Linear, and Chaotic Systems

The oscillation (4.323d) is similar to (4.303) = (4.305) with the substitution (4.324a):

```
$f_2 = \frac{\alpha |f_a| b}{3 \omega_0}} \quad b^2 = \left[\omega_0 b^2 \psi - \varepsilon\right]^2 + \lambda^2\right] = \left[\frac{f_2}{2\omega_0}\right]^2, \left[\frac{\alpha |f_a|^2}{6\omega_0^2}\right], \quad (4.324a, b)$
```

the substitution of $|f_a|$ by (4.308a) (4.324a) leads to the relation (4.324b) between the amplitudes of forcing $|f_a|$ and oscillation $b$. This relation can lead to: (i) amplitude jumps as before (subsections 4.6.1–4.6.4); also to (ii) suppression of oscillations as shown next (subsection 4.6.7).

## 4.6.7 Amplitude Jumps and Suppression of Oscillations

The amplitude equation (4.324b) with the approximation (4.325a) can be factorized (4.325b):

```
$\varepsilon^2 <<\omega_0^2 b^4 \psi^2; \quad 0 = b^2 \left[\omega_0 b^4 \psi^2 - 2\omega_0 b^2 \psi + \lambda^2 - \left[\frac{\alpha f_a}{6\omega_0}\right]^2\right], \quad (4.325a, b)$
```

that has three roots for $b^2$: (i) the zero root (4.326a), the roots (4.326b, c):

```
$b_0 = 0, \quad (b_{\pm})^2 = \frac{1}{\omega_0 \psi} \left[\varepsilon \pm \sqrt{\lambda^2 - \left[\frac{\alpha f_a}{6\omega_0}\right]^2}\right], (4.326a–c)$
```

If the damping is not too strong (4.327a), the roots (4.326b, c) are real (4.327b):

```
$\lambda < \frac{\alpha f_a}{6\omega_0^3}: \quad (b_{\pm})^2 = \frac{\varepsilon \pm \varepsilon_0}{\omega_0 \psi}, \quad \varepsilon_0 = \frac{\sqrt{\left[\frac{\alpha f_a}{6\omega_0^3}\right]^{1/2} - \lambda}{1}, (4.327a–c)$
```

The roots (4.327b, c) vanish (4.324a, b) at the points $\varepsilon_0$:

```
$b_{\pm}(-\varepsilon_0) = 0 = b_{\pm}(\varepsilon_0), \quad b_{\pm}(\varepsilon_0) = \frac{2\varepsilon_0}{\omega_0 \psi}, \quad (4.328a–c)$
```

and at $\varepsilon_0$ the second root has the value (4.328c). As shown in Figure 4.14: (i) the root $b_-$ is real beyond the point $-\varepsilon_0$ and is stable.

The motion may be described as follows: (i) starting from high-frequency there is no oscillation up to $+\varepsilon_0$, where there is a jump to $E$, with amplitude (4.328c), followed by an oscillation with decreasing amplitude that is suppressed at $-\varepsilon_0$; and (ii) starting with increasing amplitude smoothly with $B$ at $-\varepsilon_0$. Figure 4.14 applies if $\psi > 0$, and in the opposite case $\psi < 0$ is inverted relative to the $\varepsilon$-axis. Thus a linearly damped anharmonic oscillator (4.303) is forced at applied frequency (4.320a) close (4.302a) to the first harmonic of the natural frequency, nonlinear resonance at the natural frequency (Figure 4.14) with: (i) oscillation in the range $(-\varepsilon_0, +\varepsilon_0)$; (ii) suppression of oscillations at lower frequencies $\varepsilon < -\varepsilon_0$ and (iii) at higher frequencies the oscillations are suppressed if coming from above $\varepsilon > \varepsilon_0$ until $\varepsilon = \varepsilon_0$ where there is an amplitude jump (4.328c), joining the oscillations whose amplitude grows smoothly from below. This corresponds to the Hopf bifurcation (subsection 4.8.5).

## 4.6.8 Non-Linear Parametric Resonance for Forcing at the Second Harmonic

The forcing of a linear oscillator (4.329b) at an applied frequency (4.329a) close (4.302a) to the second harmonic of the natural frequency leads to the response (4.329c):

```
$$\omega_a = 3(\omega_0 + \varepsilon); \quad \dot{x}_1 + \omega_0^2x_1 = f_u \cos(\omega_a t), \quad x_1(t) = \frac{f_u}{8\omega_0^2} \cos[3(\omega_0 + \varepsilon)t].$$
(4.329a-c)$
```

The first-order approximation for the damped, non-linear oscillator (4.303) is (4.330):

```
$$\dot{x}_2 + 2\lambda x_2 + \omega_0^2x_2 + \alpha x_2^2 + \beta x_2^2 = -3\beta x_1x_2^2 + \dots$$
(4.330)$
```

where only the term in the first order and quadratic in the second order was retained. The reason is that for an oscillation (4.331b) close to the natural frequency (4.331a):

```
$$\omega = \omega_0 + \varepsilon; \quad x_2(t) = b \cos[(\omega_0 + \varepsilon)t] = b \cos(\omega).$$$$
(4.331a, b)$
```

the forcing term on the r.h.s. of (4.330):

```
$$-3\beta x_1(t)[x_2(t)]^2 = \frac{3\beta f_u b^2}{8\omega_0^2}\cos^2[(\omega_0 + \varepsilon)t] \cos[3(\omega_0 + \varepsilon)t]$$\\
= \frac{3\beta f_u b^2}{16\omega_0^2}\{1 + \cos[2(\omega_0 + \varepsilon)t]\} \cos[3(\omega_0 + \varepsilon)t]$$\\
= \frac{3\beta f_u b^2}{32\omega_0^2}\{\cos[(\omega_0 + \varepsilon)t] + \dots\},$\n(4.331c)$)$
```

+   (i) contains a triple frequency multiplied by the square of the frequency; (ii) the latter introduces a double frequency; (iii) the product of the double and triple frequency reinces the frequency that causes resonance; (iv) the resonant term on the r.h.s. of (4.330) = (4.331c) and the substitution of the l.h.s. of (4.330) as in (4.303) by the oscillation frequency (4.304a) as in (4.305) leads to:

