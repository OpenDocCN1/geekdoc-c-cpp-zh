The proof uses the Stokes (1875) or curl loop theorem (III.5.210a, b) \equiv (3.150a, b):

```
$\tilde{X} \in C^1 (|D|): \int_D(\nabla \wedge \tilde{X})d\tilde{S} = \int_{\partial D} \tilde{X},d\tilde{x}, \quad (3.150a, b)$
```

that applies to a continuously differentiable vector (3.150a) in a plane domain bounded by a closed regular curve (3.150b). The integrability condition of zero curl (3.149b) \equiv$ (3.151a) implies (3.151b) by the Stokes theorem (3.150a, b):

```
$\nabla \wedge \tilde{X}=0: \quad \int_D(\nabla \wedge \tilde{X})d\tilde{S} = \int_{\partial D} \tilde{X},d\tilde{x}, \quad (3.151a, b)$
```

from (3.151b) it follows that the integrand is an exact differential (3.152) \equiv$ (3.145b):

```
$d\Phi = \tilde{X}.d\tilde{x} = Xdx+Ydy=0, \quad (3.152)$
```

and (3.152) is satisfied by (3.146c). It has been shown that a necessary and sufficient condition that the differential (3.145b) \equiv$ (3.153b) with continuously differentiable vector of coefficients (3.153a) is exact (LXVI) and that the curl is zero (3.149b) \equiv$ (3.153c):

```
$X,Y \in C^1 (|R^2|): \quad 0=Xdx+Ydy=d\Phi \Leftrightarrow \Omega = \frac{\partial Y}{\partial x}-\frac{\partial X}{\partial y}=0 \Leftrightarrow \Phi(x,y)=C; (3.153a-d)$
```

in that case the general integral is specified equating to an arbitrary constant the function (3.153d), that is twice continuously differentiable (3.148a). For example, the equation (3.154a):

```
$0=2y^3dx+3x^2dy=d(x^2y^3), \quad x^2y^3=C, \quad (3.154a, b)$
```

has general integral (3.154b). It can be checked that for the differential (3.154a) \equiv$ (3.155b) with coefficients (3.155a, b):

```
$X=2y^3, \quad Y=3x^2y^2: \quad \frac{\partial Y}{\partial x}=6xy^2=\frac{\partial X}{\partial y}, \quad (3.155a-c)$
```

that the integrability condition (3.148c) \equiv$ (3.155c) is met.
