# Non-Linear Differential Equations and Dynamical Systems

The Einstein summation convention (3.275b), that a repeated index implies summation over its range of values (3.275a), was used in (3.274b):

```
$d\Phi = \sum_{n}^{N} \frac{\partial\Phi}{\partial x_n} dx_n = \frac{\partial\Phi}{\partial x_n} dx_n = \lambda_{X_n} dx_n. \quad (3.275a, b)$
```

All of the preceding are first-order differentials respectively in two (3.145a, b; 3.146c, 3.271; 3.272a–c) and N variables (3.274a–d). Higher-order differentials are considered (notes 3.21–3.24) after completing the analysis of first-order differentials (notes 3.3–3.20).

# NOTE 3.3: Exact Differential in N-Variables

A first-order differential in N-variables (3.274a, b) = (3.276a, b) is standard (LXXXII 3.276c) if it coincides with the differential of a function that satisfies the general integral (3.276d):

```
$n=1,... \quad 0=X_n dx_n=d\Phi, \quad \Phi(x_n)=C; \quad (3.276a–d)$
```

this implies that the vector field $X$ is orthogonal to (3.276b) to the hypersurfaces (3.276d). If the function (3.276d) has continuous second-order derivatives (3.277a), the equality of the second-derivatives (3.277b) leads to the integrability condition (3.277c):

```
$$\Phi \in C^2(\mathbb{R}^N); \quad \frac{\partial^2\Phi}{\partial x_m\partial x_n}=\frac{\partial^2\Phi}{\partial x_n\partial x_m} \quad \frac{\partial X_n}{\partial x_m}=\frac{\partial X_m}{\partial x_n}. \quad (3.277a–c)$
```

The conditions (3.277c) correspond to the vanishing of the curl of the vector of coefficients; in N-dimensions the curl of a vector is a bivector, that is, a skew-symmetric matrix (note 3.8). Thus, a first-order differential in N variables (3.278b) (standard LXXII) continuously differentiable vector of coefficients (3.278a) is exact (3.278c) if the curl is zero (3.278d):

```
$X_n \in C^1(\mathbb{R}^N); \quad 0=X_n dx_n=d\Phi \quad \Omega_{mn}=\frac{\partial X_n}{\partial x_m}-\frac{\partial X_m}{\partial x_n}=0 \quad \Phi(x_n)=C; \quad (3.278a–e)$
```

in this case the general integral (3.278e) specifies a family of hypersurfaces orthogonal to the vector field (3.278a). In two (three) dimensions N=2(N=3) then (3.276a–d) simplify to (3.153a–d) [3.224a–e]). For example, the first-order differential in four variables (3.279a):

```
$0=x_2 dx_1+x_1 dx_2+\frac{dx_3}{x_4}\frac{dx_4}{(x_4^2)}=4=d(x_1\frac{x_3}{x_4}+x_2\frac{x_3}{x_4})=C, \quad (3.279a, b)$
```
