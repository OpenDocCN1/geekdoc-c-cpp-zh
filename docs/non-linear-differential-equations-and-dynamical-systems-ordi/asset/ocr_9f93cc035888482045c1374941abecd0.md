# Unsteady, Non-Linear, and Chaotic Systems

A rigorous approach would require proof existence of the parametric expansions and of their convergence with $n$ terms as $n \rightarrow \infty$. In most problems only the first $O(\varepsilon)$ or second $O(\varepsilon^2)$ terms can be obtained and is considered as an acceptable approximation for small $\varepsilon$. Substituting (4.276a, b) in (4.273a):

```
$$\dot{x}_1 + \varepsilon\dot{x}_2 + \varepsilon^2\dot{x}_3 + (\omega - \omega_1 - \varepsilon^2\omega_1)^2 (x_1 + \varepsilon x_2 + \varepsilon^2 x_3) =\n-\varepsilon\alpha\omega_1(x_1 + \varepsilon x_2 + \varepsilon x_3) - \varepsilon^2\beta\omega_1^2(x_1 + \varepsilon x_2 + \varepsilon^2 x_3),$ (4.277)$
```

valid to $O(\varepsilon^2)$, in the example in the second term of (4.277):

```
$\varepsilon^3 \ll 1: \quad \omega_0^2 = (\omega - \omega_1 - \varepsilon^2\omega_1)^2 = \omega^2 - 2\varepsilon\omega_1\omega + \varepsilon^2(\omega_1^2 - 2\omega_2\omega).$ (4.278a, b)$
```

Equating the coefficients of successive powers of $\varepsilon$ gives (4.279a; 4.280;

```
$\varepsilon^0: \quad \dot{x}_1 + \omega^2 x_1 = 0, \quad x_1(t) = a\sin(\omega t),$ (4.279a, b)$
```

```
$\varepsilon^1: \quad \dot{x}_2 + \omega^2 x_2 = 2\omega\omega_1 x_1 - \varepsilon\alpha x_1^2,\n\\varepsilon^2: \quad \dot{x}_3 + \omega^2 x_3 = 2\omega\omega_1 x_2 + (2\omega - \omega_1)x_1 - \varepsilon\alpha x_1 x_2 - \varepsilon^2\beta x_1^3.$ (4.281)$
```

The method of parametric expansions (4.276a, b) transforms a non-linear problem (4.273) into (problem 114) an infinite recursive sequence of linear problems (4.279a; 4.280; 4.281;...) with each order: (i) satisfying the same differential equation; (ii) forced by linear and non-linear combinations of the preceding orders. In the case of the anharmonic oscillator with restoring force (4.273a); (i) the lowest order (4.279a) is an oscillation (4.279b) for frequency $\omega$ to be determined; (ii) the order $n$ involves terms of lower order $(1, 2, ..., n-1)$ generating harmonics with frequencies up to $n\omega$. This method of parametric expansions is demonstrated with the first (second) order approximation [subsections (4.5.2–4.5.3–4.5.4)].
