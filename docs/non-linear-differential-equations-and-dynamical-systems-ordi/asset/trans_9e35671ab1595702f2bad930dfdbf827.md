## 3.8 恰当与非恰当的一阶微分

一阶微分方程等价于两个变量的微分，根据系数向量是否具有零（非零）旋度而分为两种情况；微分是恰当（非恰当）微分 [章节 3.8.1-3.8.2](3.8.3-3.8.11)]；即，它是否与一个函数的微分相吻合（不相吻合）。因此，微分的积分条件是系数向量具有零旋度 [小节 3.8.1]；或者在这种情况下它是函数的微分，等于任意常数，指定了一般积分。一般积分可以通过观察得到 [小节 3.8.1] 或通过形式积分得到（[小节 3.8.2）。

如果两个变量的微分是非恰当的，它可以被化为恰当 [小节 3.8.3]，从而通过乘以一个积分因子求解 [章节 3.8.4）；积分因子满足一个偏微分方程 [小节 3.8.5）并且任何解都将成立，越简单越好。这些积分因子是无限多的 [小节 3.8.6]，其中两个的比值是非恰当微分的解。为了得到非恰当微分的解，找到一个积分因子就足够了，例如：（i）一个单变量的函数（[小节 3.8.7）；（ii）两个变量的对称函数，如 [小节 3.8.8 (3.8.9)] 和（积）；（iii）两个变量的比值 [小节 3.8.10]；或（iv）两个变量的非对称非齐次函数 [小节 3.8.11）。

### 3.8.2 恰当微分的正式积分

在无法通过观察（标准 LXVI）方程 (3.145b) 识别积分 (3.146b, c) 的情况下，可以通过形式积分 (3.147b, c) 得到。积分 (3.147b)（[3.147c]）导致 (3.156a)（[3.156b]）：

```
$\Phi(x,y) = \int X(x,y)dx+u(y) = \int Y(x,y)dy+v(x), \quad (3.156a)$
```

涉及任意函数 $u(y)$ $[v(x)]$，它由代入 (3.147c)（[3.147b]）中的 (3.157a) 得到：

```
$\frac{du}{dy} = \frac{\partial \Phi}{\partial y} - \frac{\partial X}{\partial y} = Y - \frac{\partial X}{\partial y}, \quad \frac{dv}{dx} = \frac{\partial \Phi}{\partial x} - \frac{\partial Y}{\partial x} = X - \frac{\partial Y}{\partial x}.$
```

因此，如果微分 (3.145b) 是恰当的 (3.147b, c)，其一般积分 (3.146c) 可以由涉及任意函数 $u(y)$ $[v(x)]$ 的积分 (3.156a)（[3.156b]）得到，满足 (3.157a)（[3.157b]）。

### 3.8.3 恰当与非恰当微分之间的转换

微分 (3.145b) 的解在乘以任意函数 λ(x,y) 时保持不变；这种乘法可能将一个恰当微分变为非恰当微分，如果 (X,Y) 不满足可积条件 (3.148c)，则一般 (λX,λY) 也不满足；反之总是可能的，即如果 (X,Y) 不满足可积条件 (3.148c)，可以找到一个函数 λ 使得 (λX,λY) 满足。该函数称为积分因子，在给出其一般性质（小节 3.8.4–3.8.5）和示例（小节 3.8.6–3.8.11）之前，先重新考虑前述恰当微分 (3.154a, b) 和 (3.163)。恰当的 (3.154a) [(3.158]) 在两个变量中等价于一阶微分方程 (3.164a) [(3.165a)：
