```
```c

```

+   2. Define and initialize a global static variable that may only be accessed from within this source code file.

```
```c
static int sum = 100;
```
```

+   3. Add a main function that declares it wants to use the global static variable and output its value.

```
```c
int main()
{
    extern int sum;
    printf("Sum is %d \n", sum);
}
```
```

+   4. Now, insert a declaration to use a second global variable and output its value.

```
```c
extern int num;
printf("Num is %d \n", num);
```
```

+   5. Insert a final statement to return a zero integer value, as required by the function declaration, then save the file.

```
```c

```

+   6. In a separate file define the second global variable, then save that file.
