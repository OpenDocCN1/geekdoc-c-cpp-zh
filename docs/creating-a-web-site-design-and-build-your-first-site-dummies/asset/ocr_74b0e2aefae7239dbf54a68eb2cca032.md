+   3. Click the first color listed in the drop-down list that appears.

ColorHexa takes you to a page containing all the different codes for your Primary Color. The **HEX code** for your **Primary Color** appears at the very top of the screen, below the word ColorHexa.

![](bbox=[0.323, 0.205, 0.68, 0.274])

+   4. Write down the **HEX code** on a piece of paper so that you can use it later. It's also a good idea to write down what your **Primary Color** is.

![](bbox=[0.262, 0.388, 0.746, 0.444])

+   5. Scroll down and you can see all the different ways that your Primary Color can be represented. In **HEX code**, yellow is **ffff00**, but in **Binary code**, yellow is represented as **11111111, 11111111, 00000000**. HEX code is much easier to work with because it's so much shorter!
