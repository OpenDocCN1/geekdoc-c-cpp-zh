# # CREATE THE NAVIGATION MENU

Most web sites put their navigation menu near the top of the wireframe as well. You could place navigation next to the logo or below it.

To create the navigation menu:

+   1. **Draw a smaller rectangle** and place it near the middle of the header.

![](bbox=[0.111, 0.328, 0.948, 0.405])

+   2. **Duplicate this menu item a few times and place these rectangles next to each other.** In the menu bar, click Edit and then click Duplicate.

> > *Using keyboard shortcuts and hotkeys is an essential skill for people who work with computers. If you're interested in programming, try to use keyboard shortcuts whenever possible!*

(You can quickly duplicate this menu item by pressing Ctrl+D in Windows or ⌘-D on a Mac.)

+   3. Add some **placeholder text,** such as Menu Item.

![](bbox=[0.111, 0.737, 0.948, 0.811])

That should do it for the header area.
