### CREATING A CSS FILE FOR STYLE

In this section, you will move all your style code from your HTML files into one CSS file. CSS is another programming language, and it stands for Cascading Style Sheet. You have already written CSS code without even realizing it! All the code inside the head section of your HTML file between the **style tags** is the CSS code.

```html
<!doctype html>
<html>
<head>
  <title>
    <style>
      body {
        font-family: 'Open Sans', sans-serif;
        background-color: #f0f0f0;
      }
      header {
        background-color: #ff0000;
      }
      footer {
        background-color: #0000ff;
      }
      div {
        background-color: #ff0000;
      }
      .left {
        width: 75%;
        float: left;
        background-color: #ffffff;
      }
      .right {
        width: 25%;
        float: left;
        background-color: #000000;
        color: #ffffff;
      }
    </style>
```
