> **WHAT'S A TEMPLATE?**
> 
> A template is an empty guide to give you a head start on creating your style guide. You will see that when you choose to start with a template, the web site will guide you through first adding a logo, and then adding the basic colors If you start with a blank style guide, you can add anything you want in any order. Sometimes it is helpful to use a template because then you don't have to remember everything and can instead just fill in the blanks!
