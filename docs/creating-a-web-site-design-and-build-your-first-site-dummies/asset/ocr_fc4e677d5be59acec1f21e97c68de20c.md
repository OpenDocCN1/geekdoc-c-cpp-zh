# ***A technology book for kids!***

Do you have a favorite topic that you want to share with the world? You can showcase your talents and share your interests through your own web site. You will use planning tools and learn basic HTML to create a web site that can be used to share your interests, artwork, and more.

+   * **Planning Makes Perfect** — Use online tools to help you figure out what you want your site to be about.
+   * **Mapping It Out** — Draw a map for your site using Google Drawings, or even your favorite notebook and a pencil.
+   * **Page One** — Create your site by choosing a template and then customizing it with basic HTML and CSS coding.

# **Technology Requirements:**

**Hardware** – PC or tablet with internet connection running Windows 7 or higher or Mac with internet connection running Mac OS X 10.7 or higher

**Software** – Google Apps, and Frontify.com, all available for free. Sign up instructions inside.

Greg Rickaby has been writing code since the late 90's, when he built simple web pages on Geocities. Since then, Greg has gone on to make a living building web sites for big companies like Microsoft, Discovery Channel, Uber, and Campbell's Soup.
