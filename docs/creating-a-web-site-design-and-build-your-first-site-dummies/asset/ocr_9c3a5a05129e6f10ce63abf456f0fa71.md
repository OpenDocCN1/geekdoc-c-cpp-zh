# CREATE A CSS FILE

First, you need the file to move all your CSS code into.

+   1. Go to http://drive.google.com and double-click your project folder to open it.

+   2. Click New, then More, then CSS Editor.

![](bbox=[0.204, 0.256, 0.795, 0.644])

+   3. Google might tell you that your file will have the same permissions as the folder. This means that your new file will be public, which is good. Click OK.

+   4. Click Untitled.css in the top left of your new file.
