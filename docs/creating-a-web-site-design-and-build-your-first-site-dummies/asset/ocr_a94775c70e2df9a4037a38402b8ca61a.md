# CREATE A BRAND WITH FRONTIFY

After you create an account in Frontify, the next step is to create your style guide. Frontify uses the word *brand* as its name for a style guide.

+   1. Right after you register your account, you should see a small window that asks you to create a brand.
+   2. Type the name of your web site in the **Brand or Company Name** field.
