For now, add the CSS Editey app to Google Drive.

+   1. Go to [http://drive.google.com](http://drive.google.com) and log in to your Google account if you're not logged in already.
+   2. Double-click your project folder to open it.
+   3. Click New, then More, then Connect More Apps.

![](bbox=[0.14, 0.255, 0.844, 0.635])

+   4. Search "CSS" and click Enter. Click Connect next to CSS Editey.
