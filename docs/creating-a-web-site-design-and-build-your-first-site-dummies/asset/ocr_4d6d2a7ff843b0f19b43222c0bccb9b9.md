# ## CREATING A CSS FILE FOR STYLE

In this section, you will move all your style code from your HTML files into one CSS file. CSS is another programming language, and it stands for Cascading Style Sheet. You have already written CSS code without even realizing it! All the code inside the head section of your HTML file between the <mark>style tags</mark> is the CSS code.

        background-color: #ff0000;
