To determine the sensor pixel’s response to the incoming light, we multiply each bit of light $S(x,y)$ by the responsivity $M(x,y)$, and sum up over the entire pixel:

$$\mathit{value}=\int_{-\frac{1}{2}}^{\frac{1}{2}}\int_{-\frac{1}{2}}^{\frac{1}{2}} S(x,y)M(x,y)\,dy\,dx.\tag{18.3}$$

If we extend the definition of $M$ to the whole plane of the sensor by defining $M$ to be 0 outside the unit square corresponding to pixel $(0,0)$, we can rewrite this as

$$\mathit{value}_{0,0}=\int_{-\infty}^{\infty}\int_{-\infty}^{\infty} S(x,y)M(x,y)\,dy\,dx,\tag{18.4}$$

which may appear more complicated, but actually will result in simpler formulas elsewhere.

In a well-designed camera, the sensor responsivity should be the same for each pixel. What does this mean mathematically? It means, for instance, that for sensor pixel $(2,3)$, we’ll want to multiply $S(x,y)M(x-2,y-3)$ and integrate, that is,

$$\mathit{value}_{2,3}=\int_{-\infty}^{\infty}\int_{-\infty}^{\infty} S(x,y)M(x-2,y-3)\,dy\,dx.\tag{18.5}$$

and in general, the formula for sensor pixel $(i,j)$ will be

$$\mathit{value}_{i,j}=\int_{-\infty}^{\infty}\int_{-\infty}^{\infty} S(x,y)M(x-i,y-j)\,dy\,dx.\tag{18.6}$$

This expression has the form of a product of a function $S$ with a shifted function $M$, integrated; the resultant value is a function of the shift amount, $(i,j)$. That is the essence of a convolution, and indeed, Equation 18.6 is almost the definition of the convolution $S * M$ of the two functions. Two small adjustments are needed. First, since $S$ and $M$ are both functions on all of $\mathbb{R}^2$, their convolution is defined to be a function on all of $\mathbb{R}^2$. The values we’ve described above are the restriction of that function to the integer grid. Second, it’s very convenient to have a definition of convolution that makes $f * g = g * f$. For this to work out properly, there needs to be an extra negation; that is, we want Equation 18.6 to have the form

$$\mathit{value}_{i,j}=\int_{-\infty}^{\infty}\int_{-\infty}^{\infty} S(x,y)\widetilde{M}(i-x,j-y)\,dy\,dx.\tag{18.7}$$

We can arrange this by defining $\widetilde{M}(x,y)=M(-x,-y)$. (For a typical sensor, the response function is symmetric, so $\widetilde{M}$ and $M$ are the same.) This final form is just a 2D analog of the 1D convolution. Simplifying to one dimension, we can now define the **convolution** of two functions $f,g : \mathbb{R} \to \mathbb{R}$:

$$(f * g)(t)=\int_{-\infty}^{\infty} f(x)g(t-x)\,dx.\tag{18.8}$$
