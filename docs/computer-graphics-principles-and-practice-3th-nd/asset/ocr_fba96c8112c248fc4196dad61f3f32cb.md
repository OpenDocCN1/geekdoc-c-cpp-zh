public Point AffineCombination(double[] weights, Point[] Points)
{
    Debug.assert(weights.length == Points.length);
    Debug.assert(sum of weights == 1.0);
    Debug.assert(weights.length > 0);

    Point Q = Points[0];
    for (int i = 1; i < weights.length; i++) {
        Q = Q + weights[i] * (Points[i] - Points[0]);
    }
    return Q;
}

public Point AffineCombination(Point P, double wP,
                               Point Q, double wQ)
{
    Debug.assert((wP + wQ) == 1.0);

    Point R = P;
    R = R + wQ * (Q - P);
    return R;
}

# 7.6.5 Matrix Multiplication

The product of two matrices **A** and **B** is defined only when the number of columns of **A** matches the number of rows of **B**. If **A** is an *n × k* and **B** is a *k × p*, then the product **AB** is an *n × p* matrix. If we let the *i*th row of **A** be the transpose of the vector **r**ᵢ, and the *j*th column of **B** be the vector **c**ⱼ, then the *ij*th entry of **AB** is just **r**ᵢ · **c**ⱼ. The following picture may help you remember this:

![](bbox=[0.146, 0.598, 0.66, 0.789])

Thus, we see that the dot product of the vectors **v** and **w** is just the matrix product **v**ᵀ**w**:

**v** · **w** = **v**ᵀ**w** = **w**ᵀ**v**. (7.57)

This leads to an interpretation of the product of the matrix **A** (with rows **a**ᵢ) and a vector **v**: If **w** = **Av**, then the *i*th entry of **w** tells “how much **v** looks like **a**ᵢᵀ” (in the sense described when we discussed Equation 7.38).
