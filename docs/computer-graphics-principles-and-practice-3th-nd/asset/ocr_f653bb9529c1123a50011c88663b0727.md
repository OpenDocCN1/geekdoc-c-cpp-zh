**Exercise 25.2:** If we have a one-dimensional *path mesh* (i.e., each vertex has one or two edges meeting it), we can place it in the plane by assigning random locations to the vertices. In general, the result will not be an embedding: Edges will tend to cross one another. In 3-space, however, there’s plenty of room, and with high probability the use of randomly assigned locations will result in an embedded *path* mesh. In this exercise, you’ll show that for any surface mesh, there’s an embedding in *some* Euclidean space. The idea is simple: For an n-vertex mesh, we’ll place the mesh in R^n by placing vertex 1 at location (1, 0, ..., 0), vertex 2 at location (0, 1, ..., 0), etc. We then place edges and faces in the obvious way, using linear interpolation.

+   - (c) Show that if S1 ∩ S2 = {p, q}, then the associated embedded triangles intersect in the embedded edge associated to {p, q}.
