## 15 光线投射与光栅化 — 387

3D 渲染器确定覆盖图像每个像素的表面，然后执行某种着色例程来计算像素的值。我们介绍一组覆盖算法和一些示例性着色例程，并重新审视图形管线抽象。这些是由几何和处理器架构的一般原理产生的实用设计要点。

对于覆盖，我们推导光线投射和光栅化算法，然后在此基础上构建渲染器的完整源代码。这需要图形学特有的调试技术，例如可视化中间结果。架构感知优化显著提高这些程序的性能，尽管这是以限制抽象为代价。或者，我们可以将抽象上移到管线之上，以启用专用图形硬件。抽象图形处理单元（GPU）的 API 可实现高效的光栅化实现。我们将渲染器移植到此类 API 常见的可编程着色框架。
