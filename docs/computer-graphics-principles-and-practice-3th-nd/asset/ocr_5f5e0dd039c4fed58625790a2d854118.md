In the case of a matrix transformation $T_M$ this being applied only to points of the $w = 1$ plane, the “vectors” lying in that plane all have $w = 0$, and so the matrix used to transform these vectors can have its third column set to be all zeroes (or can be just written as a $2 \times 2$ matrix operating on vectors with two entries), as we have seen earlier. But since

$S = H \circ T_M$. (10.128)

we have (using the multivariable chain rule)

$DS(P) = DH(T_M(P)) \cdot DT_M(P)$. (10.129)

Now, since $H\left(\begin{bmatrix}x\\y\\w\end{bmatrix}\right)=\begin{bmatrix}x/w\\y/w\\1\end{bmatrix}$, we know that

$DH\left(\begin{bmatrix}x\\y\\w\end{bmatrix}\right)=\begin{bmatrix}1/w&0&-x/w^2\\0&1/w&-y/w^2\\0&0&0\end{bmatrix}$ (10.130)

$=\dfrac{1}{w^2}\begin{bmatrix}w&0&-x\\0&w&-y\\0&0&0\end{bmatrix}$. (10.131)

and

$DT_M(P)=M=\begin{bmatrix}2&0&-1\\0&1&0\\1&0&0\end{bmatrix}$. (10.132)

So, if $P=[x,y,1]$ is a point of the $w=1$ plane and $v=\begin{bmatrix}s\\t\\0\end{bmatrix}$ is a vector in that plane, then $S(P)=\begin{bmatrix}2x-1\\y\\x\end{bmatrix}$ and

$DS(P)(v)=DH\left(\begin{bmatrix}2x-1\\y\\x\end{bmatrix}\right)\cdot DT_M(P)v=\begin{bmatrix}s\\t\\0\end{bmatrix}$ (10.133)

$=\dfrac{1}{x^2}\begin{bmatrix}x&0&-(2x+1)\\0&x&-y\\0&0&0\end{bmatrix}\begin{bmatrix}2&0&-1\\0&1&0\\1&0&0\end{bmatrix}\begin{bmatrix}s\\t\\0\end{bmatrix}$ (10.134)

$=\dfrac{1}{x^2}\begin{bmatrix}-1&0&-x\\-y&x&0\\0&0&0\end{bmatrix}\begin{bmatrix}s\\t\\0\end{bmatrix}=\begin{bmatrix}-s/x^2\\(tx-sy)/x^2\\0\end{bmatrix}$. (10.135)

Evidently, the “vector” transformation depends on the point $(x,y,1)$ at which it’s applied. The normal transform, being the inverse transpose of the vector transform, has the same dependence on the point of application.
