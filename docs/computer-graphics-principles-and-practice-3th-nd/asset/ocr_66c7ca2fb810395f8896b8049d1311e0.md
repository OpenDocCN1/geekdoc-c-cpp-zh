in $xyz$-coordinates, are proportional to $1,x,y,z,xy,xz,yz,$ and $x^2-y^2$, with the constant of proportionality chosen so that each integrates to one on the sphere. In spherical polar coordinates, they can be written $1,\cos\theta,\sin\theta\cos\phi,\sin\theta\sin\phi,\cos 2\theta,\sin\theta\cos\phi,$ and $\cos 2\theta$. Like the Fourier basis functions on the circle, they are pairwise orthogonal: The integral of the product of any two distinct harmonics over the sphere is zero. Figure 31.17 shows the first few harmonics, plotted radially. The plot of $h_1$, which is the constant function 1, yields the unit sphere.

To be clear: If you have a continuous function $f:S^2\to\mathbb{R}$, you can write $f$ as a sum of spherical harmonics:

$$f(P)=\sum_{j=1}^{\infty}c_jh_j(P). \tag{31.58}$$

The coefficients $c_j$ depend on $f$, of course, just as when we wrote a function on the unit circle as a sum of sines and cosines, the coefficients of the sines and cosines depended on the function. In fact, they’re determined the same way: by computing integrals.

The cosine-weighted BRDF at a fixed point $P$ is a function of two directions $\omega_i$ and $\omega_o$, that is, the expression

$$\bar f(\omega_i,\omega_o)=f(P,\omega_i,\omega_o)\,\omega_i\cdot n(P) \tag{31.59}$$

defines a map $\bar f:S^2\times S^2\to\mathbb{R}$. So the preceding statement about representing functions on $S^2$ via harmonics does not directly apply. But we can approximate the cosine-weighted BRDF $\bar f$ at $P$ with spherical harmonics in a two-step process. To simplify notation, we’ll omit the argument $P$ for the remainder of this discussion.

First, we fix $\omega_i$ and consider the function $\omega_o\mapsto\bar f(\omega_i,\omega_o)$; this function on $S^2$—let’s call it $F_{\omega_i}$—can be expressed in spherical harmonics:

$$F_{\omega_i}(\omega_o)=\sum_{j=1}^{\infty}c_jh_j(\omega_o). \tag{31.60}$$

If we chose a different $\omega_i$, we could repeat the process; this would get us a different collection of coefficients $\{c_j\}$. Thus we see that the coefficients $c_j$ depend on $\omega_i$, we can think of these as functions of $\omega_i$ and write

$$\bar f(\omega_i,\omega_o)=\sum_j c_j(\omega_i)h_j(\omega_o). \tag{31.61}$$

Now each function $\omega_i\mapsto c_j(\omega_i)$ is itself a function on the sphere, and can be written as a sum of spherical harmonics. We write

$$c_j(\omega_i)=\sum_k w_{jk}h_k(\omega_i). \tag{31.62}$$

Substituting this expression into Equation 31.61, we get

$$\bar f(\omega_i,\omega_o)=\sum_j c_j(\omega_i)h_j(\omega_o); \tag{31.63}$$

$$=\sum_j\sum_k w_{jk}h_k(\omega_i)h_j(\omega_o). \tag{31.64}$$
