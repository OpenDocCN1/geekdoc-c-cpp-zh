Second, it's commutative, which we'll show for the continuous case, answering the inline problem above:

$$ (f * g)(t) = \int_{-\infty}^{\infty} f(x)g(t - x) dx. \tag{18.17} $$

Substituting \(s = t - x, ds = -dx\), and \(x = t - s\), we get

$$
\begin{align*}
(f * g)(t) &= \int_{-\infty}^{\infty} f(x)g(t - x) dx \tag{18.18} \\
&= \int_{x=\infty}^{-\infty} f(t - s)g(s) (-ds) \tag{18.19} \\
&= \int_{s=-\infty}^{\infty} g(s)f(t - s) ds \tag{18.20} \\
&= (g * f)(t). \tag{18.21}
\end{align*}
$$

The proofs for the discrete and mixed cases are very similar.
Third, convolution is associative. The proof, which we omit, involves multiple substitutions.
Finally, continuous-continuous convolution has some special properties involving derivatives, such as \(f' * g = f * g'\) (under some fairly weak assumptions). It also generally increases smoothness: If \(f\) is continuous and \(g\) is piecewise continuous, then \(f * g\) is differentiable; similarly, if \(f\) is once differentiable, then \(f * g\) is twice differentiable. In general, if \(f\) is \(p\)-times differentiable and \(g\) is \(k\)-times differentiable, then \(f * g\) is \((p + k + 1)\)-times differentiable (again under some fairly weak assumptions).
Alas, for a fixed function \(f\), the map \(g \mapsto f * g\) is usually not invertible—you can't usually "unconvolve." We'll see why when we examine the Fourier transform shortly.
