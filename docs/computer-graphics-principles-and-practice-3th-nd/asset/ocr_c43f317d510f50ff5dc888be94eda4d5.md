The rotation matrix we seek is then

**M** = **I** + sin(θ)J_ω + (1 − cos θ)J²_ω. (11.17)

From Inline Exercise 11.4, it’s clear that Mω = ω. And if v is perpendicular to ω, then

**Mv** = **Iv** + sin(θ)J_ωv + (1 − cos θ)J²_ωv = **v** + sin(θ)ω×v + (1 − cos θ)ω×(ω×v) = **v** + sin(θ)ω×v + (1 − cos θ)(−**v**) = sin(θ)ω×v + cos(θ)**v**. (11.18)–(11.21)

which is just the rotation of v in the plane perpendicular to ω by an angle θ. Since M does the right thing to ω and to vectors perpendicular to ω, it must be the right matrix, as per the Transformation Uniqueness principle (see Figure 11.2). In coordinate form, it’s

**M** = sin θ [ [0, −ω_z, ω_y], [ω_z, 0, −ω_x], [−ω_y, ω_x, 0] ] + (1 − cos θ) [ [−ω_y² − ω_z², ω_xω_y, ω_xω_z], [ω_xω_y, −ω_x² − ω_z², ω_yω_z], [ω_xω_z, ω_yω_z, −ω_x² − ω_y²] ] + **I**. (11.22)–(11.23)

# 11.2.4  Finding an Axis and Angle from a Rotation Matrix

As we said earlier, it’s a theorem that every rotation of 3-space has an axis (i.e., a vector that it leaves untouched). We can use Rodrigues’ formula to recover the axis from the matrix. We’ll follow the approach of Palais and Palais [PP07].

We know every rotation matrix has an axis ω and an amount of rotation, θ, about ω; Rodrigues’ formula tells us the matrix must be

**M** = **I** + sin(θ)J_ω + (1 − cos θ)J²_ω. (11.24)

for some unit vector ω and some angle θ.

The trace of this matrix (the sum of the diagonal entries) is

tr(**M**) = tr(**I** + sin(θ)J_ω + (1 − cos θ)J²_ω)
= tr(**I**) + sin(θ)tr(J_ω) + (1 − cos θ)tr(J²_ω)
= 3 + (1 − cos θ)(−2(ω_x² + ω_y² + ω_z²))
= 3 + (1 − cos θ)(−2)
= 1 + 2 cos θ.
