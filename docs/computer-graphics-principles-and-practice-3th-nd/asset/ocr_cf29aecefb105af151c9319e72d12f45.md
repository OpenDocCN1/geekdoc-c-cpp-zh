# 31.8.1 A Note on Notation

We summarize in Table 31.1 the notation we’ll use repeatedly throughout this chapter. Figure 31.7 gives the geometric situation to which items in this table refer.

Notice that the subscript “i” in ωᵢ is set in Roman font rather than italics; that’s to indicate that it’s a “naming-style” subscript (like Vᵢₙ to denote input voltage) rather than an “indexing-style” subscript (like bᵢ, denoting the ith term in a sequence).

When we aggregate over λ, it’s important to decide once and for all whether this aggregate denotes a sum (perhaps an integral from λ = 400 nm to 750 nm), or an average; you can do either one in your code, but you must do it consistently.

*Table 31.1: Notation used in this chapter:*

| Symbol | Meaning |
|---|---|
| 𝓜 | The set of all surfaces in the scene. |
| *P, Q, R* | Points of 𝓜. |
| **n** | The function that takes a surface point *P* and returns the normal at *P*. When the point *P* is easily understood, we sometimes write **n** instead of **n(P)**. |
| ω | A generic unit vector in some direction, also thought of as a point in S² (the endpoint of ω when it’s based at **0**). |
| ωᵢ | A vector from some point *P* toward incoming light, so the light is propagating in direction −ωᵢ. In general, ωᵢ · **n(P)** > 0. |
| ωₒ | A direction in which reflected light travels from a point *P*; in general, ωₒ · **n(P)** > 0. |
| S²₊(*P*) | The set of all directions ω with ω · **n(P)** > 0, that is, the outgoing directions at a point *P* ∈ 𝓜. Defined only for points on surfaces in the scene. |
| S²₊ | Shorthand for S²₊(*P*) in the case where the point *P* is self-evident. |
| *L(P, ω)* | The radiance in a scene at point *P* in direction ω. |
| *Lᵉ(P, ω)* | The emitted radiance from a point *P* on some luminaire in direction ω. *Lᵉ(P, ω)* is zero at any point not on a luminaire. |
| *Lᵈ(P, ω)* | The light arriving at *P* along direction ω that was emitted from an emitter toward *P* along an unobstructed ray between them. This is called the **direct light**. |
| *Lⁱ(P, ω)* | The light arriving at *P* along direction ω that is not a direct light. This is called the **indirect light**. |
| *Lʳ(P, ω)* | The light leaving *P* in direction ω as a result of scattering rather than emission. |
| *fₛ(P, λ, ωᵢ, ωₒ)* | The scattering function (BSDF) at the point *P*, at wavelength λ. |
| *fₜ(P, ωᵢ, ωₒ)* | The nonspectral scattering function (BSDF) at the point *P* (i.e., an aggregate over λ). |
| *fₛ(ωᵢ, ωₒ)* | The nonspectral scattering function (BSDF) at a point that’s clear from context. |
| ρ | The *reflectance* of a Lambertian material. |
