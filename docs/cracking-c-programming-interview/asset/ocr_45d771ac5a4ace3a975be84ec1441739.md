# 23. What is the output of the following program?

```
#include<stdio.h>
struct std
{
  int a;
  union unit
  {
    int a, b;
  } u;
};
int main()
{
  struct std s = {1, 2, 3};
  printf("%d %d %d ", s.a, s.u.a, s.u.b);
  return 0;
}
```
