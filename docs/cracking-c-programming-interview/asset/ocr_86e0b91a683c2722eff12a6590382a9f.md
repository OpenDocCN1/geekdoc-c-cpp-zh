# 56. What is the output of the following program?

```
#include<stdio.h>
int main()
{
    int a1[] = {6, 7, 8, 34, 67};
    int a2[] = {25, 56, 28, 29};
    int a3[] = {-12, 27, -34};
    int *x[] = {a1, a2, a3};
    int **a = x;
    printf("%d ", a[0]);
    printf("%d ", *a[2]);
    printf("%d ", ++a[0]);
    printf("%d", *((a) [0]);
    return 0;
}
```

+   (a) 6 25-12 7
(b) 8-12 7 25
(c) 8-12 27 25
(d) 6 25-12 7
