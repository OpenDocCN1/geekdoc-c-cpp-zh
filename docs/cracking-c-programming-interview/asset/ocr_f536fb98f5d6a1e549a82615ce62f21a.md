# 9. What is the output of the following program?

```
#include<stdio.h>
#include<string.h>
int main()
{
    int i = 1;
    char c[] = "hello";
    char d[] = "India";
    char *b;
    b = i ? c : d; //line 3
    printf("%s",b);
    return 0;
}
```

+   (a) India
(b) hello
(c) error- compile time
(d) garbage
