![](img/192d581e3a01f0e6c194cf1_10_0.png)
Figure 3.1: Representation of 2-D array in stack area

2D array is a collection of 1D arrays. The elements of an array get stored at a continuous location. In the standard C compiler, 2D array gets stored in row-major order (1st row, 2nd row, and so on). a[1][2] can also be written as *(a+1)+2. Here, 1 signifies skipping of one row, and 2 signifies skipping two columns. First *(a+1) means selecting a particular row and second selecting a particular column. The address of a+1 is 1012 (skipping one row), the address of a+2 is 1024 (skipping two rows), and so on. *(a+1)+2 is selecting an element after skipping one row and two elements. It gives a particular a[1][2] that is 9.
