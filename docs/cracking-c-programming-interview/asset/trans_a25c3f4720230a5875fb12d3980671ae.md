# 8. 给定的 foo(x, n) 计算哪个数学函数？

```c

{
    int val = 1;
    if (n > 0)
    {
        if (n % 2 == 1)
            val *= x;
        val *= foo(x, n / 2);
    }
    return val;
}
```

- (a) x^n
- (b) n^x
- (c) n^n
- (d) n * x
