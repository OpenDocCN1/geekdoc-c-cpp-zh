# 47. What is the output of the following program?

```
#include<stdio.h>
int main()
{
    int x = 0;
    while(x < 2)
{
        if(x == 1)
            break;
        x++;
        if(x == 1)
            continue;
        printf("Inside loop ");
    }
    printf("Outside loop\n");
    return 0;
}
```

+   (a) Inside loop Inside loop Outside loop
(b) Inside loop Outside loop
(c) Outside loop
(d) Inside loop
