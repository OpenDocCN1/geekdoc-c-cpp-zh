# Organization of the Book

The chapter-1 "A touch to C" describes conceptual understanding about C programs. It is highly recommend to the readers to go through this chapter before proceeding. After this chapter, the book is divided into 7 groups, each group contains around 60 C programming questions with explanations and other important interview questions. After completing all the groups, there are more than 100 questions given in 5 sample papers with solutions for your practice. The book overall contains more than 600 interview questions.

# Prerequisite

A very basic understanding of theoretical C concepts is required for reading this book.

# Guidelines For Reading the Book

- Try to finish chapter-1 "A Touch to C" in 2 hours.
- The book contains 7 groups of questions, each group has around 60 questions. You can solve 20 questions per day. So, each group takes 3 days to solve. You can solve all the conceptual C programming in 21 days only.
- Give 4 days to sample papers. Overall you need 25 days to solve this book.
