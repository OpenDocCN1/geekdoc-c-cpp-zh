# 9. 关于该函数，以下陈述正确还是错误？

```c
int fun(int p) {
  int i = 50;
  if(i == p) {
    printf("hi\n");
    int k = fun(p);
    return 5;
  } else {
    return 0;
  }
}
```

语句：
(i) 对于 p 的除50以外的所有值，函数都返回零。
(ii) 对于 p 的除50以外的值，函数会无限打印 "hi" 直到栈溢出。
(iii) 当 p = 50 时，函数返回 5。
(iv) 当 p = 50 时，函数会无限打印 "hi" 直到栈溢出。

+ (a) (i), (ii)
(b) (iii), (iv)
(c) (i), (iv)
(d) (iv)
