+   1. What is the output of the following program?

```
#include<stdio.h>
int *fun()
{
    int b = 10;
    return &b;
}
int main()
{
    int *p;
    p = fun();
    printf("%d\n", *p);
    return 0;
}
```

+   (a) 10
(b) Address of variable 'b'
(c) Unexpected Behavior
