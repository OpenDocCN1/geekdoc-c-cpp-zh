# 6. Which of these functions are using pointers correctly?

```
#include <stdio.h>
int *f1()
{
    int x = 10;
    return &x;
}
int *f2()
{
    int *ptr;
    *ptr = 10;
    return ptr;
}
int *f3()
{
    int *ptr;
    ptr = (int*) malloc(sizeof (*ptr));
    return ptr;
}
```

+   (a) f3 only
(b) f1 and f3
(c) f1 and f2
(d) f1, f2, and f3
