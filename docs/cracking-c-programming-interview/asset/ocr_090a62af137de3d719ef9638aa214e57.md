# 40. What is the output of the following program?

```
#include<stdio.h>
int main()
{
  int p = 10;
  int q = 0;
  while(q++ < p) printf("%d, ", q);
  printf("\n");
  q = 0;
  while(++q < p) printf("%d, ", q);
  printf("\n");
  q=0;
  while(p-- > q) printf("%d, ", p);
  printf("\n");
  p=10;
  while(--p > q) printf("%d, ", p);
  return 0;
}
```

+   (a) 0 to 9

+   1 to 9

+   10 to 1

+   9 to 1

+   (b) infinite loop
