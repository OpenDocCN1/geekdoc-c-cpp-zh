We will trace the lifetime of the simple hello program, from the time it is being created by a programmer, until it executes on a system, prints "hello India", and terminates.

+   i. Programmer writes a program in an editor (e.g gedit) and saves a text file called hello.c, also called source program.

+   ii. The source program is a sequence of bits in some meaningful (semantic) order and organized in 8-bit chunks called bytes octets or cells.

+   iii. Modern computers represent each character uniquely using ASCII notation. Each character has a unique 8-bit sized integer value. The ASCII representation of text characters is given in tabular form at the end of this chapter (Table 1.4).
