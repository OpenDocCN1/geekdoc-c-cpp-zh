26. What is the output of the following program?

```
#include<stdio.h>
int x;
int main() 
{
    int * y = &5;
    int *const ptr = &x;
    ptr++;
    (*ptr)++;
    printf("%p %d", ptr, *y);
}
```

+   (a) addr 5
(b) addr addr
(c) 5 5
(d) error- compile time

27. What is the output of the following program?

#include<stdio.h>
