| a[0] | 5 | 6 | 7 |
|---|---|---|---|
| | 1000 | 1004 | 1008 |

![](img/192d581e3a01f0e6c194cfc2ff02d9f1_120_0.png)

假设我们要访问元素 `a[1][1][2]`。在三维数组中，`a[1]` 表示跳过一个二维数组，`a[1]`（或 `*(a+1)`）高亮的 `*` 表示选择所选二维数组中的行，`a[1][1][2]` 表示跳过 2 列。

(i)**(a[i])->*(i+1))` I 表示跳过第一个数组，内部的 `*`（靠近 a）表示选择第二个数组 `a[i]`。第二个 `**`（中间）表示选择数组 `a[i]` 中的特定行。外层的表示在不跳过列的情况下选择特定元素。(iv)**(a[i]*2)->*(i+1)*2)` I 表示跳过二维数组，内部表示一个特定的数组。第二个 `**`（中间）表示在不跳过元素 `a[i][0]` 的情况下选择行：`2` 表示跳过所选行中的特定元素，内部再选择特定元素。这等同于 `a[i][0][2]` 并返回 3。

## 60. c

**解释：** 当用户请求动态分配时，C 程序会请求内存。如果内存可用，内存管理器会将内存分配给程序。如果系统太忙，内存管理器可能会拒绝为程序分配内存。在这里，给定的程序中，内会在无限循环中动态分配内存而不释放（free()）。主内存（RAM）被完全分配给我们的程序，堆溢出并导致 Unix 操作系统系统挂起。如果我们在每次迭代中释放内存，堆就不会溢出，系统也不会挂起，只是无限地打印 hello 10。看以下程序：

```c
#include<stdio.h>
#include<stdlib.h>
int main() {
    while (1) {
        int *p = (int *)malloc(sizeof(int));
        *p=10;
        printf("hello %d", *p);
        free(p);
        p=NULL; // 防止悬空指针（第一组，第7 题解释）
    }
    return 0;
}
```
