# 19. What will be output when you will execute the following c code?

```
#include<stdio.h>
int main()
{
    int a=-7;
    unsigned int b=-7u; //line 2
    if (a==b)
        printf("India");
    else
        printf("Bharat");
    return 0;
}
```

+   (a) India
(b) Bharat
(c) error at line 2
(d) error: signed and unsigned int cannot be compared
