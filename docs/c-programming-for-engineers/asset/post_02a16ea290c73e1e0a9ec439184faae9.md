## Readability Considerations

When using the if-else construct, it's essential to consider which condition enhances readability by two clear choices. For instance, take a look at the following examples:

```c
if( grade >= 50 )
  printf("You pass\n");
else
  printf("You fail\n");
```

```c
if( grade < 50 )
  printf("You fail\n");
else
  printf("You pass\n");
```

In the first example, the condition grade >= 50 focuses on the passing scenario, making it more intuitive and easier to grasp at a glance. Conversely, the second example highlights the scenario with the condition grade < 50.

By structuring your conditions in a way that emphasizes the desired outcome, you can enhance the clarity of your code.

## 7.4 The if-else Ladder

The if-else ladder is a programming construct that allows for handling decisions based on multiple conditions in a structured and organized manner.

In certain scenarios, the outcome of a program depends on evaluating several factors in a sequential manner. The if-else ladder accomplishes this by employing a chain of if-else statements.

Here's how it works:

## 7.4. The if-else ladder

![](img/33fb6b7acbb6df48a3c9564e97117da6_109_0.png)

- 1. The first condition is checked using an if statement.
- 2. If the condition is false, the next condition is checked using an else if statement.
- 3. This chaining of else if statements continues for each additional condition that needs to be evaluated.
- 4. Finally, an else statement is used to handle the last case, which covers all remaining possibilities.

For example:

```c
if (temp > 30) {
  // hot case
} else if (temp > 20) {
  // warm case
} else if (temp > 10) {
  // mild case
} else {
  // cold case
}
```

In this example, an if-else ladder is used to categorize weather conditions based on temperature ranges.

The if-else ladder improves the organization and readability of code when dealing with multistep decision-making processes. The conditions are evaluated one-by-one from top to bottom until a matching condition is found. This construct allows for the logical structuring of complex conditional logic, making the code more understandable and maintainable.

As an additional example, consider the use of an if-else ladder to assign letter grades (A, B, C, and F) based on test scores. This demonstrates how the if-else ladder can handle multistage decision-making scenarios effectively.

```c
#include <stdio.h>

int main() {
    int score;

    // Prompt the user to enter their test score
    printf("Enter your test score: %d", score);
    scanf("%d", &score);

    // Assign letter grades based on the test score
    if (score >= 80) {
        printf("Your grade is: A\n");
    } else if (score >= 65) {
        printf("Your grade is: B\n");
    } else if (score >= 50) {
        printf("Your grade is: C\n");
    } else {
        printf("Your grade is: F\n");
    }

    return 0;
}
```

An if-else ladder is used when outcomes depend on mutually exclusive conditions that must be evaluated sequentially.

## 7.5 Nested if Construct

Nested if-else statements are used when we need to make decisions based on multiple conditions, with each condition depending on the outcome of the previous one. This creates a hierarchical structure where if-else statements are nestled inside each other. Consider the following program:

```c
#include <stdio.h>

int main() {
    int age;

    printf("Enter your age: %d", age);
    scanf("%d", &age);

    if (age >= 18) {
        printf("You are an adult.\n");
        if (age >= 65) {
            printf("You are also a senior citizen.\n");
        }
    } else {
        printf("You are not an adult.\n");
    }

    return 0;
}
```

## 7.5. Nested if Construct

The code has a nested if statement. The outer if statement checks the user's age 18 or older. If it is, then the nested if statement checks if the user's age is 65 or older.

## 7.6 The switch Construct

The switch statement is used to execute one block of code among many possible code blocks. It is often a cleaner alternative to using multiple if-else statements.

```c
switch (expression) {
  case value1:
    // code
    break;
  default:
    // code
    break
}
```

In a switch statement, an expression is evaluated and compared to the values in each case. If a match is found, the corresponding code block runs. If no match is found, the default code block runs (if included).

To avoid running the next case accidentally, each case should end with a break statement. The default case is optional and provides a fallback if no cases match.

Switch statements are especially helpful when there are many possible cases, as they keep the code clear and easy to manage.

Here's a comparison between switch and if-else:

- Switch provides a clear, organized way to handle multiple cases, while if-else can get lengthy with more conditions.
- Switch directly compares an expression to case values, while if-else allows complex conditions.
- Switch works with integers, characters, or enums, while if-else can handle other types.
- Switch jumps to the matching case, while if-else evaluates each by one until a match is found or it reaches else.

```c
#include <stdio.h>

int main() {
    char grade;

    printf("Enter your grade (A, B, C, D, or F): ");
    scanf("%c", &grade);

    switch (grade) {
        case 'A':
            printf("Excellent! You did great!\n");
            break;
        case 'B':
            printf("Very good! Keep up the good work.\n");
            break;
        case 'C':
            printf("Okay, room for improvement.\n");
            break;
        case 'D':
            printf("You need to study more!\n");
            break;
        case 'F':
            printf("Uh oh, better luck next time!\n");
            break;
        default:
            printf("Invalid grade entered.\n");
            break;
    }

    return 0;
}
```
