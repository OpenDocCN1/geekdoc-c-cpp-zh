# 14.3. Macro Substitution

```
#define SQUARE(x) x * x
```

If used in an expression like this:

```
i = 2 + SQUARE(3+3);
```

The macro will expand to:

```
i = 2 + 3+3 * 3+3;
```

This can lead to unexpected results due to the order of operations.
Additionally, macros can introduce side effects when using operators with unintended consequences. For example:

```
int num = 5;
int result = SQUARE(num++);
```

The macro will expand to:

```
int result = num++ * num++;
```

The evaluation of the post-increment operator is undefined, leading to unpredictable results. To avoid this, ensure that macros are used carefully and with proper parentheses. Example:

```
// A macro calculates the maximum of two values
#define MAX(a, b) ((a) > (b) ? (a) : (b))
```

```
int main() {
int a = 4, b = 5, c;
c = MAX(a, b);
printf("MAX(%d, %d) = %d\n", a, b, c);
return 0;
}
```

In the above example, the MAX macro is modified to have parentheses ensuring proper evaluation order. However, using inline functions in C99 or later is a safer and more recommended solution.
