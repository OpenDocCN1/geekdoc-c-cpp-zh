# 15.7. Blink All LEDs in Sequence

Let's break down the code:

+   - The setup() function configures 6 LEDs as outputs.
- The digitalWrite() function is used to control the LEDs, turning them on and off.
  - digitalWrite(i, HIGH); turns on LED i.
  - The delay(500) pauses the program for half a second while the LED remains on.
  - digitalWrite(i, LOW); turns off the LED.
- The first for loop iterates through LEDs 2 to 7, sequentially turning each LED on and off.
- The second for loop iterates from LED 6 to LED 3, creating a backward sequence of turning on and off.
- By continuously both loops, the program creates a visual effect reminiscent of the Knight Rider car from an old TV series.
