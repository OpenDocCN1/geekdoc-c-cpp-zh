## 3.6 Troubleshooting and Common Issues

When learning to program, especially for beginners, encountering errors and facing challenges is common. This section aims to help you troubleshoot issues that arise when using a C compiler.

### 3.6.1 Types of Programming Errors

Understanding the different types of errors in programming is important for identifying and fixing issues in your code. Here are the main types of errors and their causes:

- Syntax Errors: These occur during compilation when the code violates the syntax rules of the programming.
- Semantic Errors: These occur when the code is syntactically correct but does not perform the intended action.
- Runtime Errors: These occur during the execution of the program, such as division by zero or invalid memory access.
- Logical Errors: These occur when the program runs without crashing but produces the wrong result due to a mistake in the logic.
