### 13.1.3 Pointers to Structures

Pointers can also point to structures and unions, allowing dynamic allocation and manipulation of complex data structures. Declaring pointers to structures is straightforward:

```c
struct Person *ptr;
```

To access structure members through a pointer, we can use the arrow operator (->) or by dereferencing:

```c
ptr->age = 26;
(*ptr).age = 26;
```

This arrow operator is especially useful when dealing with structures containing pointers, such as linked lists.

## 13.1.4 Nested Structs

Structs can be nested within other structs to represent complex data structures. For example:

```c
struct Address {
    char street[50];
    char city[30];
};

struct Person {
    char name[10];
    int age;
    float height;
    struct Address address;
};
```

Here, the Person struct contains a nested struct Address to represent the person's address.

## 13.1.5 Passing Structs to Functions

Structs can be passed to functions by value or by reference. For example:

```c
void printPerson(struct Person p) {
    printf("Name: %s, Age: %d, Height: %f\n", p.name, p.age, p.height);
}

// Passing by value
struct Person p = {"Adam", 25, 1.8};
printPerson(p);
```

## 13.1.6 Returning Structs from Functions

Functions can also return structs. For example:

```c
struct Person createPerson(char name[], int age) {
    struct Person p;
    strcpy(p.name, name);
    p.age = age;
    return p;
}
```

This function creates and returns a Person struct with the specified name and age.

## 12.2 Unions: A Special Kind of Struct

In C programming, unions offer a way to create a unique type of structure where all members share the same memory location.

To declare a union, use the union keyword followed by the union's name and a list of member variables enclosed in curly braces. For example:

```c
union myList {
    char c;
    int i;
    double d;
};
```

This defines a union named myList with three member variables: char c, int i and double d.

The main difference between unions and structs is that unions allow only one member to be active at a time, while structs can have multiple active members simultaneously. As a result, modifying one member of a union can affect the values of other members that share the same memory location. In structs, each member has its own separate memory space.

Unions are often used when we want to save memory or work with different types of data that can share the same memory space. They are commonly used in systems programming to make the best use of memory.

In a union, memory is allocated based on the size of the largest member variable so that it can store any type of data in the union. This means that the size of a union is equal to the size of its largest member variable. We can find the size of a struct or union using the sizeof() operator. However, it's important to know that the reported size by the compiler may be larger than expected due to padding used for alignment with the computer's word size.

Below is an example comparing the usages of union and structs:

```c
#include <stdio.h>

// Using a struct to represent different data types
struct myststruct {
    char c;
    int i;
    double d;
};

// Using a union to represent different data types
union myunion {
    char c;
    int i;
    double d;
};

int main() {

    struct myststruct s;

    printf("Memory used by union: %d\n", sizeof(u));

    printf("Value: %c\n", u.c);
}
```

## 13.3 Typedef: Simplifying Type Declarations

The typedef keyword is used to create an alias for existing data types, which can make the code more readable and easier to maintain. It is particularly useful with complex types like structs and unions.

For example, instead of writing `struct Person` every time, you can define a typedef `Person`.

```c
typedef struct {
    int age;
    float height;
} Person;

Person p1; // Now you can use Person instead of struct Person
```

Typedef can also be used with pointers and arrays:

```c
typedef int* intPtr;
typedef int intArray[10];
```

## 13.4 Enums: Improving Program Readability

Enumerations (enums) are a way to define named integer constants. This makes the code much more readable than using magic numbers, as the names provide clear context.

To define an enum, use the `enum` keyword followed by the name:

```c
enum Day {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
};
```

By default, the first constant is 0 and each subsequent constant increases by one. You can also assign specific values:

```c
enum Status {
    LOW = 1,
    MEDIUM = 2,
    HIGH = 10
};
```

Using `typedef` with enums allows you to avoid using the `enum` keyword when declaring variables:

```c
typedef enum { SUNDAY, MONDAY, TUESDAY } Day;

Day today = MONDAY;
```
