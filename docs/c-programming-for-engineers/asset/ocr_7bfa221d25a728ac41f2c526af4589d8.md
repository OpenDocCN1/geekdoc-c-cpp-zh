+   ■ Punctuation, special characters, and C keywords are not allowed.
■ Identifiers are case sensitive (X is not x)
■ The maximum length of an identifier is 31 characters.

Some compilers accept identifiers that are longer than 31 characters. While it is technically possible to have very long identifiers, it is generally considered good practice to keep identifier names short and descriptive to improve readability.

There are no strict rules for naming identifiers, but using descriptive names like makes your code easier to read and understand. Some tips:

+   ■ **Use clear names**: Choose descriptive names like totalScore or calculateArea.
■ **Avoid confusion**: Don't use short, unclear names like x or temp.
■ **Be specific**: Use names like finalExamGrade instead of result if that is what it is.

Variables use camel case convention where compound words or phrases are joined together without spaces, and each word after the first starts with a capital letter.

```
analogInput waterSensor toggleLED reloadPaperTray
```

