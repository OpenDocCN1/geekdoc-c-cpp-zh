# String Object

Constructing a string object has the following syntax:

```
String(val)
String(val, base)
String(val, decimalPlaces)
```

where

+   - val: a variable to format as a String. Allowed data types: string, char, byte, int, long, unsigned int, unsigned long, float, double.
- base: (optional) the base in which to format an integral value.
- decimalPlaces: only if val is float or double. The desired decimal places.

Here are some examples of how to declare and use String objects in Arduino:

```
// using a constant String
String stringOne = "Hello String";n// converting a constant string into a String object
String stringTwo = String("This is a string");
// concatenating two strings
StringThree = String(stringTwo + " with more");
// using a constant integer
StringFour = String(13);
// using an int and a base
String stringFive = String(analogRead(0), DEC);
// using an int and a base (hexadecimal)
String stringSix = String(45, HEX);
// using an int and a base (binary)
String stringSeven = String(255, BIN);
// using a long and a base
String stringEight = String(millis(), DEC);
// using a float and the decimal places
StringNine = String(5.698, 3);
```

You can perform various String manipulations using String methods.

# String Methods

In Arduino programming, they may seem similar, there are some key differences. Functions are standalone pieces of code that perform specific tasks. They have their own scope and can only access their own on. variables. Methods, on the other hand, are associated with objects or instances of a class. They can access and interact with the data and state of the object they belong to. Other differences:

Scope Functions have their own scope and can only access their own variables. Methods can access the data of the object they belong to.
