```
#include <stdio.h>

int main() {
    int i;

    // Loop to print even numbers from 1 to 10
    for (i = 1; i <= 10; i++) {
        if (i % 2 != 0) {
            continue; // Skip odd numbers
        }
        printf("%d\n", i);
    }

    return 0;
}
```

In this example, the continue statement skips iterations where i is even, resulting in the printing of only odd numbers.
While break and continue statements offer powerful control of loops, using them too much can make the code complicated. It's important to use them carefully to keep the code clear. Nested loops with multiple break and continue statements can make it hard to understand how the program works.

# 8.6.3 The goto Statement

The goto statement allows you to jump directly to a specific location in your code, marked by a label. The syntax is as follows:

```
label:
// code to be executed
goto label;
```

The label starts with an alphanumeric character, followed by a colon. You can use the goto statement to jump to any point in your code.
Consider the following example where goto is used to skip ahead in a loop:

```
#include <stdio.h>

int main() {
    int i, j = 10;
    char ch = 'A';

label:
    for (i = 1; i <= 5; i++) {
        for (j = 1; j <= 5; j++) {
            if (i == 3 && j == 3) {
                goto label; // Jump to label, skipping the inner loop
            }
        }
    }
```
