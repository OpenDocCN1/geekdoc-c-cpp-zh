# 15.2 Alternative Arduino Boards

The Maker Uno is not the only board usable to learn Arduino C. There are other
options that are cheaper, more compact, more powerful, or easier to use.

For a budget-friendly way to learn Arduino programming, consider the NodeMCU
ESP8266, which is available online for around RM10. However, unlike the Maker
Uno, it does not come with built-in LEDs and switches, so you'll need to add them
