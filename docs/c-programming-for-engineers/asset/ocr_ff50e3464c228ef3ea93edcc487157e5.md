# # Structured Data

In C, arrays and structures are used to organize multiple related homogeneous data items. suitable for storing heterogeneous data (data of the same type), while structures are used to group heterogeneous data (different data types).

C provides structured data types such as structs, unions, enums, and typedefs, which allow data to be grouped together under meaningful names. The source code is simplified, making programs easier to design, read, and maintain.

+   - Structs: A struct is a composite data type that allows developers to define custom data structures by grouping together different data types under a single name.
- Unions: Unions are similar to structs but have a key difference: they share the same memory location for all members, allowing only one member to be active at a time. This feature is useful when different data types need to be represented using the same memory space.
- Enums: Enums, structs are for enumerations, provide a way to define a set of named integer constants. Enums are useful for representing a fixed set of related values, such as days of the week or error codes, in a more readable and expressive manner.
- Typedefs: Typedefs act as handy shortcuts, allowing you to create new names for existing data types, enhancing code readability and maintainability.

# 13.1 Structs: Defining Custom Data Types

In programming, structs are the basic method to create custom data types by grouping together different variables under a single name.

# 13.1.1 Syntax and Declaration of Structs

The syntax for defining a struct involves the struct keyword followed by the struct's name and a list of member variables enclosed in curly braces. For example:

```
struct Person {
  char name[10];
  int age;
  float height;
};
```

This code defines a struct named person with three member variables: name, age, and height.
