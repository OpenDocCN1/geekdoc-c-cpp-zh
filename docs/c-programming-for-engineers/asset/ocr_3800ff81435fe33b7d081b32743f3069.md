* We prompt the user to enter a string using printf.
* We use scanf with %s format specifier to read the string entered by the user. scanf will read characters until it encounters whitespace (space, tab, newline, etc.) or reaches the end of the input. The string read by scanf is stored in the str array.
* Finally, we print the string using printf.

Using %s with scanf can be unsafe which can lead to buffer overflows if it doesn't limit the number of characters read, the input string exceeds the array size. To reduce this risk, specify a maximum field width in the format string, such as %49, to leave one space for the null terminator.
To avoid potential issues, it's better to avoid scanf to read strings. Instead, you can use a safer approach by combining fgets and scanf functions. Here's a simplified explanation:

+   * fgets: This function reads a whole line of user input into a character buffer, preventing buffer overflows by limiting input size to the buffer capacity.
* scanf: After capturing the input line, scanf parses it according to specified format specifiers, extracting the desired data without directly reading from stdin.

Here's a simple code example:
#include <stdio.h>

```
int main() {
    char input[100]; // Assuming a maximum input length of 99 characters
    char str[50]; // Assuming a maximum string length of 49 characters

    printf("Enter a string: ");
    fgets(input, sizeof(input), stdin); // Read a line of user input

    // Use scanf to parse the str and extract the string
    sscanf(input, "%49[^\n]", str); // %[^\n] reads until newline or EOF,
                                // limit input to 49 characters

    printf("You entered: %s\n", str);

    return 0;
}
```

In this example:
* We declare two character arrays: input to store the user's input line and str to store the extracted string.
