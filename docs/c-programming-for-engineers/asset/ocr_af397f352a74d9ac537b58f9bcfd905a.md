# Exponential Function

The function exp() computes the exponential (e^*) of a given number.

```
#include <stdio.h>
#include <math.h>

int main() {
    double num = 2.0;
    double result = exp(num);
    printf("Exponential of %lf is %lf\n", num, result);
    return 0;
}
```

# Trigonometric Functions

Trigonometric functions like sin(), cos(), and tan() for computing sine, cosine, and tangent values, respectively. The constant for pi is defined in this library as well.

```
#include <stdio.h>
#include <math.h>

int main() {
    double angle = 45.0; // in degrees
    double radian = angle * (M_PI / 180.0); // convert degrees to radians
    printf("Sine of %lf degrees is %lf\n", angle, sin(radian));
    printf("Cosine of %lf degrees is %lf\n", angle, cos(radian));
    printf("Tangent of %lf degrees is %lf\n", angle, tan(radian));
    return 0;
}
```
