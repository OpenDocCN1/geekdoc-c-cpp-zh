# 4.1.7 Comments

In programming, comments are used to explain the code to others. They help make the code clear and easy to understand, which is important for making sure it works correctly. Comments describe what different parts of the code do, and explain how variables are used. Comments don't affect how the program actually runs because the computer ignores them.

Each programming language has its own way of writing comments. In C, one-line comments begin with // through the end of the line.

```
int length = 12; // length in inches
int width = 15; // width in inches
int area; // calculated area
```

```
// Calculate rectangle area
area = length * width;
```

Multi-line comments are enclosed within /* and */ for example: They can span multiple lines.

```
/*
* Here's a multi-line comment *
*/
```

Multi-line comments can also be used as single-line comments

```
int area; // Calculated area */
```

We mostly use one-line comments.

# 4.1.8 The #include Directive

This inserts the contents of another file into the program. It is actually a preprocessor directive, something that is done before the compiler actually sees the program. The directive is not part of the C language.

```
#include <stdio.h>
include <math.h>
```

Notice that there is no semicolon at the end of a directive.
