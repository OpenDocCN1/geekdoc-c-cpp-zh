If an error occurs, the program prints an error message and exits gracefully.

# 11.4  File Positioning

When working with files, you may need to move the file pointer to specific positions or understand the current position within the file. C provides several functions for this purpose:

+   - fseek(): Moves the file pointer to a specific offset from a reference point
  - int result = fseek(file, offset, whence);
  - offset: The number of bytes from whence.
  - whence: A constant that specifies the reference point for the offset.
    - SEEK_SET: Offset from the beginning of the file.
    - SEEK_CUR: Offset from the current file position.
    - SEEK_END: Offset from the end of the file.
  - result: Returns zero on success or a non-zero value on failure.

+   - ftell(): Returns the current file position as a byte offset from the beginning of the file.

```
long position = ftell(file);
```

+   - rewind(): Resets the file position to the beginning of the file.

```
rewind(file);
```

For example, to move the file pointer to a specific position, use the fseek() function. For example, to move the file pointer 100 bytes from the beginning of the file, use:

```
fseek(file, 100, SEEK_SET);
```

Reset the pointer to its initial position can be done two ways.

```
fseek(file, 0, SEEK_SET);   // Longer way
rewind(file);                // Preferred way
```

In the first example, fseek() is used to reset the file position, but it is more verbose. In the second example, rewind() is used to reset the file position to the beginning, which is a more straightforward and recommended approach.
