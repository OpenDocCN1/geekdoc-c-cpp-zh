# 4.1.5 Constants

In C programs, constants are values that remain fixed throughout program execution.
Here are different ways to define constants in C:

+   **Using macros:** The #define directive tells the preprocessor to replace all occurrences of a macro with a literal value:

```
#define PI 3.141593
```

This means every occurrence of PI will be replaced with 3.141593 before compilation. Macros have a major downside which is lack of type checking. However, macros are still commonly used for constants due to their flexibility.

+   **Using const keyword:** The const keyword declares a variable or object as constant. Constants declared with const cannot be changed after initialization.

```
const double PI = 3.141593;
```

Here, PI is a constant variable with a value of 3.141593. Using const ensures that certain values remain constant and are not accidentally changed, promoting code safety.

+   **Using enums:** Enumerations (or enums) define a set of named constants to provide self-documenting code through descriptive identifiers. Their values can be changed in one place rather than scattered literals:

```
enum Days {SUN, MON, TUE, WED, THU, FRI, SAT};
```

Each constant represents a distinct value, with SUN being 0, MON being 1, etc.
When naming constants, choose descriptive names and use the screaming snake case notation for better code comprehension.

# 4.1.6 Operators

Operators in programming are symbols or keywords that are used to manipulate data. Some common types of operators include the following:

+   **Arithmetic Operators:** Perform mathematical operations such as + (addition), - (subtraction), * (multiplication) and / (division).

+   **Assignment Operators:** Assign values to variables. These include the simple assignment operator =, as well as compound assignment operators like +=, -= etc.
