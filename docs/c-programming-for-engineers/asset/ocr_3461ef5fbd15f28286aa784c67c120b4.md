# 12.5 Pointers and Functions

# 12.5.1 Pointer to Functions

Pointers can point to functions, allowing functions to be passed as arguments to other functions, stored in data structures, or dynamically assigned at runtime. This enables powerful programming techniques such as callbacks and implementing polymorphism.

For example:

```
void sayHello() {
    printf("Hello, World!\n");
}
```

```
int main() {
    // Pointer to a function that takes no arguments and returns void
    void (*ptr)() = // // Note syntax
```

```
// Assigning the address of sayHello function to ptr
ptr = sayHello;
```

```
// Calling the function through the pointer
ptr();
```

```
return 0;
```

This will output: Hello, World!, as the function sayHello is called through the function pointer ptr.

# 12.5.2 Exchanging Data with Functions

Pointers allow functions to receive and manipulate data types other than simple scalars.

Pass-by-value

The basic method of a function receiving data in C is pass-by-value. In pass-by-value, a copy of the argument's value is created and passed to the function. Changes made inside the function do not affect the original variable. This method is used for simple data types like integers and characters. For example, consider the incorrect swapping of values without modifying the originals:

```
void swap(int x, int y) { // Incorrect swap function
    int temp = x;
    x = y;
    y = temp;
```
