## 12.9 Hardware Access in Raspberry Pi

The Raspberry Pi, a widely-used single-board computer, offers various hardware capabilities, including general-purpose input/output (GPIO) pins. In C programming for the Raspberry Pi, pointers are crucial for efficiently accessing and manipulating these hardware components.

To demonstrate, let's consider controlling an LED connected to GPIO pin 18. We'll use pointers to directly access GPIO registers and set or read pin values.

```c
#include <bcm2835.h>

// GPIO pin number for LED
#define LED_PIN 18

int main() {
    // Initialize GPIO
    if(!bcm2835_init())
        return 1;

    // Set LED pin as output
    bcm2835_gpio_fsel(LED_PIN, BCM2835_GPIO_FSEL_OUTP);

    // Declare pointer to GPIO register base address
    volatile unsigned *gpio = (volatile unsigned *) BCM2835_GPIO_BASE;

    while(1) {
        // Use pointer to write 1 to GPIO pin, turn LED on
        *gpio |= (1<<LED_PIN);

        // Delay
        delay(1000);

        // Write 0 to GPIO pin to turn LED off
        *gpio &= ~(1<<LED_PIN);

        // Delay
        delay(1000);
    }
    return 0;
}
```

In this example:

- We initialize the GPIO using the bcm2835 library. The bcm2835 library is a C library used for direct, low-level access to the GPIO (general-purpose input/output) on the Raspberry Pi's Broadcom 2835 SOC (system on a chip).
- Set GPIO pin 18 as an output pin.
- Declare a pointer to the GPIO register base address. The volatile keyword tells the compiler that the value in the register can be changed at any time external to the program.
- Inside the loop, we use the pointer to directly write to the GPIO register bitmask, toggling the LED on and off with delays between.

This direct access provides control over hardware components like LEDs. Pointers allow us to interact directly with physical GPIO ports, facilitating real-time interfacing with external devices on the Raspberry Pi.

## 13. Structured Data

In programming, structs are the basic method to create custom data types by grouping together different variables under a single name.

### 13.1 Structs: Syntax Declaration

The syntax for defining a struct involves the struct keyword followed by the struct's name and a list of member variables enclosed in curly braces. For example:

```c
struct Person {
  char name[10];
  int age;
  float height;
};
```

This code defines a struct named person with three member variables: name, age, and height.

### 13.1.2 Accessing Struct Members

Accessing struct members involves the dot (.) operator followed by the member's name. For example:

```c
#include <stdio.h>

struct Person {
    char name[10];
    int age;
    float height;
};

int main() {
    // Declare and initialize struct variables
    struct Person person1 = {"Sarah", 20, 1.65f};
    struct Person person2 = {"Adam", 25, 1.80f};

    // Print first struct data
    printf("Name: %s\n", person1.name);
    printf("Age: %d\n", person1.age);
    printf("Height: %f\n", person1.height);

    // Print second struct data
    printf("Name: %s\n", person2.name);
    printf("Age: %d\n", person2.age);
    printf("Height: %f\n", person2.height);

    return 0;
}
```
