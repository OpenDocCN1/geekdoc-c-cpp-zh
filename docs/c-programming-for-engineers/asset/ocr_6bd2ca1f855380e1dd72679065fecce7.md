```
enum Day today = THURSDAY;
nwitch(today) {
  case MONDAY:
    printf("Oh no, it's Monday\n");
    break;
  case WEDNESDAY:
    printf("It's the Hump Day\n");
    break;
  case FRIDAY:
    printf("TGIF\n");
    break;
  case SUNDAY:
  case SATURDAY:
    printf("It's the weekend\n");
  default:
    printf("Just another day\n");
}
```

return 0;

In summary, enums in C provide a convenient and type-safe way to work with sets of named integer constants. They enhance code readability, safety, and maintainability by replacing "magic numbers" with meaningful names. Using enums with switch statements makes the code more readable and avoids potential issues that may arise from changes to integer values.

# 13.5 Bit Fields

Bit fields in C allow you to specify the number of bits used by each member of a structure, enabling to pack multiple fields into a single byte or word.

When defining a structure, you declare the size in bits of each member using the unsigned int data type. For example:

```
struct {
  unsigned int ready:1;
  unsigned int error_code:9;
  unsigned int command:6;
}
```

Here, ready uses 1 bit, error_code uses 9 bits, and command uses 6 bits..
C packs the bit fields as compactly as possible, aligning storage usage with the integer word length of the computer. For instance, on a 32-bit computer, bit fields from 1 to 32 bits uses one word, while bit fields from 33 to 64 bits uses two words, and so forth.

Using bit fields optimizes memory usage and facilitates working with hardware data layouts, which is crucial for low-memory or hardware interfacing applications.
