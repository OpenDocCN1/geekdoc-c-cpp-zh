# Elementary C

This chapter provides a beginner-friendly overview of essential concepts in programming with the C language. Covers keywords, variables, identifiers, and basic data types, such as integers and characters.

# 4.1 Basic Elements

Programming languages have common elements, such as keywords, programmer-defined identifiers, operators, punctuation, and syntax. These components form the basis of the language structure and allow developers to write code that computers can understand and execute.

# 4.1.1 Keywords

Keywords are words given specific meanings by the C compiler and are reserved exclusively for that use. They are always written in lowercase. Table 4.1 lists all reserved keywords.

Using reserved keywords as identifiers results in compilation errors because the compiler recognizes them as part of the language syntax and functionality. This eliminates ambiguity and ensures the compiler correctly interprets the code.

Table 4.1: C keywords

| auto | break | case | char |
| const | continue | default | do |
| double | else | enum | extern |
| float | | goto | if |
| int | long | register | return |
| short | signed | sizeof | static |
| struct | switch | typedef | union |
| unsigned | void | volatile | while |

# 4.1.2 Identifiers

Identifiers are names given to program elements such as variables and functions. These names are used to identify these elements in the code and refer to them in the code. In C, identifiers follow these guidelines:

+   - Can contain letters ('a' through 'z' and 'A' through 'Z'), digits ('0' through '9') and the underscore character ('_').
- The first character cannot be a digit.
