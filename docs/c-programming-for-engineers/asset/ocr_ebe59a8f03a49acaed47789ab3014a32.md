# Readability Considerations

When using the if-else construct, it's essential to consider which condition enhances readability by two clear choices. For instance, take a look at the following examples:

```
if( grade >= 50 )
  printf("You pass\n");
else
  printf("You fail\n");
```

```
if( grade < 50 )
  printf("You fail\n");
else
  printf("You pass\n");
```

In the first example, the condition grade >= 50 focuses on the passing scenario, making it more intuitive and easier to grasp at a glance. Conversely, the second example highlights the scenario with the condition grade < 50.

By structuring your conditions in a way that emphasizes the desired outcome, you can enhance the clarity of your code.
