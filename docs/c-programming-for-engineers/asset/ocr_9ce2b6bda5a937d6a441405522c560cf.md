Figure 12.3: Array of string pointers

```
#include <stdio.h>
int main() {
    int n;
    const char *day[] = {"Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"};

    do {
        printf("Enter a day from 1 to 7: ");
        scanf("%d", &n);

        if (n < 1 || n > 7) {
            printf("Invalid input. Please try again.\n");
        }
    } while (n < 1 || n > 7);

    puts(day[n-1]);

    return 0;
}
```

The declaration char *day[] = {"Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"}; creates an array named day, where each element of the array is a pointer to a string. This array is initialized with the names of the days of the week.

Each element of the day array points to a string representing a day of the week. For example, day[1] points to the string "Sunday", day[2] points to "Monday", and so on. This setup allows for convenient access to the names of the days of the week using array indexing.
