
## 11.5 Working with Text Files

### 11.5.1 Manipulating Text Files using C

Manipulating text files in C involves more than just reading and writing. You can also modify, filter, and clean data in text files. For example, you can remove unwanted characters, replace text, or perform calculations based on the data. Here is an example of removing all occurrences of the character 'x' from a text file:

```c
FILE in = fopen("input.txt", "r");
FILE out = fopen("output.txt", "w");

while (fgets(line, sizeof(line), in)) {
    fputs(str_replace(line, "x", ""), out);
}
```

```c
fclose(in);
fclose(out);
```

### 11.5.2 Reading and Writing CSV Files

Comma-separated values (CSV) files are commonly used to store tabular data, including sensor data. Here is an example of a CSV file:

| Timestamp | Sensor ID | Temperature | Humidity |
| :--- | :--- | :--- | :--- |
| 2024-03-10 08:00:00 | 001 | 25.5 | 60 |
| 2024-03-10 08:05:00 | 002 | 24.8 | 58 |
| 2024-03-10 08:10:00 | 003 | 26.2 | 63 |
| 2024-03-10 08:15:00 | 001 | 26.8 | 62 |

In this CSV file:
- Each line represents a record.
- Fields within each record are separated by commas.
- The first line contains headers, indicating the meaning of each field (timestamp, sensor ID, temperature, humidity).
- Subsequent lines contain sensor data corresponding to those headers.

In C, you can read and write CSV files using the functions introduced in previous sections. To read a CSV file containing sensor data, as timestamps, sensor IDs, temperatures, and humidity, follow these steps:

1. Open the file for reading:
- `FILE file = fopen("sensor_data.csv", "r");`

2. Declare variables to store sensor data and read the number of records in the file:
```c
char timestamp[20];
char sensor_id[5];
float temperature;
int humidity;
int num_records = 0;
```

3. Read the file, row by row, using `fscanf()`:
```c
while (fscanf(file, "%[^,],%[^,],%f,%f\n", timestamp, sensor_id, &temperature, &humidity) == 4) {
  // Process data here e.g. store in arrays, perform calculations
  num_records++;
}
```

4. Close the file after you are done reading:
- `fclose(file);`

Variables like timestamp, sensor_id, temperature, and humidity are used to store the data from each record. The `fscanf()` function reads the CSV file, parsing each record using the provided format string. `fscanf()` is used to read the CSV file with the format string `"%[^,],%[^,],%f"` to read the first column by the comma, followed by the second column and a newline character.

## 11.6 Working with Binary Files

Binary files are used to store data in a format intended to minimize storage requirements. They are not human-readable. Examples of binary files used in programs on embedded systems include executable files, object files and binary data such as images and sounds.

Use the `fread()` and `fwrite()` functions to read and write binary files, respectively:

- `fread()`: Reads a block of data from a file into a buffer.
  `size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);`
- `fwrite()`: Writes a block of data from a buffer to a file.
  `size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);`

For both functions, the parameters are as follows:
- `ptr`: A pointer to the buffer where the data will be stored or containing the data to be written.
- `size`: The size of each element in bytes.
- `nmemb`: The number of elements to read.
- `stream`: The file stream from which to read the data.

### 11.6. Working with Binary Files

The following C code demonstrates how to store 5 temperature values in a binary file.

```c
#include <stdio.h>

int main() {
    float temperatures[5] = { 25.5, 26.8, 24.2, 27.1, 23.9 };

    FILE* fp = fopen("temperatures.bin", "wb");
    if (fp == NULL) {
        printf("Failed to open the file.\n");
        return 1;
    }

    fwrite(temperatures, sizeof(float), 5, fp);
    fclose(fp);

    printf("Temperatures stored in temperatures.bin successfully.\n");
    return 0;
}
```

Here, we use `fwrite` to write the contents of the temperatures array to the file. The parameters of `fwrite` are the array to write (temperatures), the size of each element (sizeof(float)), the number of elements to write (5), and the file pointer (fp).

Next, we read the temperature values from the `temperatures.bin` file and print them to the console.

```c
#include <stdio.h>

int main() {
    float temperatures[5];

    FILE* fp = fopen("temperatures.bin", "rb");
    if (fp == NULL) {
        printf("Failed to open the file.\n");
        return 1;
    }

    fread(temperatures, sizeof(float), 5, fp);
    fclose(fp);

    printf("Temperatures:\n");
    for (int i = 0; i < 5; i++) {
        printf("%.2f\n", temperatures[i]);
    }
    return 0;
}
```

Here, we use `fread` to read the contents of the temperatures array from the file. The parameters of `fread` are the array to read (temperatures), the size of each element (sizeof(float)), the number of elements to read (5), and the file pointer (fp).
