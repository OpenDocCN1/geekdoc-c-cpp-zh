Example

Consider the following problem statement:

```
Write a program that calculates the average of three numbers.
```

The input requirements for this problem are the set of numbers. The expected output is the average of the numbers. There are no constraints or limitations specified in the problem statement.

Once we have understood the problem, we can move on to the next step of the problem-solving process: designing an algorithm.

# 2.2.3 Algorithm Design

An algorithm is a set of instructions that, when precisely followed, will solve a particular problem or perform a particular task. Algorithmic thinking involves breaking down problems into step-by-step instructions that a computer can follow to solve the problem.

There may be multiple algorithms to solve one problem, each with advantages and disadvantages. Programmers choose the best algorithm based on factors like efficiency.

Instructions are divided into three types:

+   - Input: supplying data to the computer.
- Process: manipulate data such as comparing input or performing complex math.
- Output: delivering the results from the computer.

The aim of algorithm design is to write clear, unambiguous steps that computers can easily follow. Choosing the right algorithm is key to making programs work well.

When creating an algorithm, it's important to think about the data the program will use. Data is anything that a computer program operates on. Data can be numbers, words, or any information the program needs, and it's all stored in the computer's memory.
