Example usage:

```
int var = 10;
int *ptr = &var; // Pointer to var
int **pptr = &ptr; // Pointer to ptr
```

```
// Outputs: Value of var via ptr2: 10
printf("Value of var via pptr: %d\n", **pptr);
```

Here's a program demonstrating the use of double pointers in C:

```
// C program to demonstrate pointer to pointer
#include <stdio.h>

int main() {
    int var = 10;
    int *ptr = &var; // Pointer to var
    int **pptr = &ptr; // Double pointer to ptr

    ptr = &var; // Storing address of var in ptr
    pptr = &ptr; // Storing address of ptr in pptr
```

```
Displaying value of var using both single and double pointers
printf("Value of var: %d\n", var);
printf("Value of var using single pointer = %d\n", *ptr);
printf("Value of var using double pointer = %d\n", **pptr);
```

```
// Displaying value pointers
printf("Address of pptr = %p\n", pptr);
printf("Value of pptr = %p\n", *pptr);
printf("Address of ptr = %p\n", &ptr);
printf("Value of pptr = %p\n", ptr);
printf("Address of val = %p\n", &var);
```
