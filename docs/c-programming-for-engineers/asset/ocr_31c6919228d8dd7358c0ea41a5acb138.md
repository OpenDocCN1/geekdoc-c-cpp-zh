```
#include <stdio.h>

int main() {
    int num = 1;
    while (num <= 5) {
        printf("%d\n", num);
        num++;
    }
    return 0;
}
```

In this example, the program uses a while loop to print numbers from 1 to 5. The num variable is incremented after each iteration, and the loop continues as long as num is less than or equal to 5.
