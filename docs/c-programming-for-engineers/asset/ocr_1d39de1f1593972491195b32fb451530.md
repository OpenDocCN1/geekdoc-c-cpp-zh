# 90 Chapter 6. Standard Input/Output

+   - fgets reads a line of input from the user, limiting input to the size of the input array to prevent buffer overflows.
- scanf parses the string stored in input, extracting the string according to the specified format string %49[^n]. This format specifier reads characters until it encounters a newline character or the end of the input, excluding the newline character itself. We limit the input to 49 characters to ensure space for the null terminator.
- Finally, we print the extracted string using printf.

This approach ensures safer input handling compared to scanc alone, preventing unexpected user inputs.
As final example, we show how to input multiple data items from different data types:

```
#include <stdio.h>

int main() {
    char input[100]; // Assuming a maximum input length of 99 characters
    char name[50]; // Assuming a maximum name length of 49 characters
    int age; // Variable to store the user's age

    printf("Enter your name: ");
    fgets(input, sizeof(input), stdin); // Read a line of user input
    sscanf(input, "%49[^\n]", name); // Extract the name

    printf("Enter your age: ");
    fgets(input, sizeof(input), stdin); // Read a line of user input
    sscanf(input, "%d", &age); // Extract the age

    printf("\nHello %s is %d\n", name, age);

    return 0;
}
```

In this code:

+   - We declare a variable age of type int and name of type character array to store the user's information.
- We prompt the user to enter their name and age.
- We use gets to read a line of input for both the name and the age.
- We use scanf to extract the name from the first input string and the age from the second input string.
- Finally, we print the extracted name and age.

Please note that this approach may be excessive if you never need to input strings.
In such cases, it's more appropriate to use the scanf function instead.
