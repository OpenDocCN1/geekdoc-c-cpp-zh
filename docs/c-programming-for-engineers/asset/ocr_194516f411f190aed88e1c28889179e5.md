In summary, pointers provide a powerful way to access and efficiently manipulate array elements through address arithmetic. Arrays map directly to pointers, and pointers can represent arrays.

# 12.4 Pointers and Strings

Pointers are frequently used for handling strings. The relationship between the "address of" operator and array indexing allows for interchangeable usage, making expressions like &string[0] and something equivalent.

Strings are commonly passed between functions using their character pointer type, char *. For example, the following is a possible implementation of the strlen() library function:

```
int strlen(char*str) {
    int count = 0;
    while(*str++) {
        count++;
    }
    return count;
}
```

The postfix increment *str++ dereferences each character address until the null byte is reached. The idiomatic way to copy a string in C uses pointer arithmetic:

```
void strpy(char *dest, char *src) {
    while ((*dest++ = *src));
}
```

This pointer approach is preferred over indexing as it is simpler and faster by avoiding unnecessary arithmetic. String literals can also have the type char *, demonstrating the fundamental role of pointers in representing strings in C. The following code offers another method of initializing strings:

```
char *str = "Hello";
```

The code sets up a pointer named str to refer to a memory location that stores the first character 'H' of the string. It is important to note that modifying the content of str is not allowed because the memory location where string literals are read-only. Any attempt to modify it can lead to unpredictable results.

To indicate that the string should not be modified, it is recommended to use the const keyword. For example:

```
const char *str = "Hello";
```
