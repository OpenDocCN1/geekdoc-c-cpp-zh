# 7.2.1 Executing a Block of Statements

The code to execute a block of one or more statements enclose them by curly braces { and }. Suppose we want to make sure a is always greater or equal to b. When a is less than b, we want to swap the value. When we get:

```
if ( a < b ) { // swap only if a < b
t = a; // store in a temporary variable t
a = b; // copy b to a
b = t; // update b with temporary variable
```

This is how to write a code block in pseudocode:

```
IF <condition> THEN
<statement1>
<statement2>
ENDIF
```

In writing pseudocode, programmers use the word "endif" for convenience; it is not a C keyword.
