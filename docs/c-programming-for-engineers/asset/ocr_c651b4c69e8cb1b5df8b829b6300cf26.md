# 4.1.3 Variables

Variables are symbolic names used to store and manipulate data. Each variable has a data type that determines the type of data it can hold (such as integers, floating-point numbers, characters, etc.) and a unique identifier known as its name.

Variables in C must be declared before use by specifying its data type and unique name. For example, you can declare an integer variable named age as:

```
int age;
```

After declaring a variable, you can assign a value to it using the assignment operator (=). For example:

```
age = 25;
```

You can also declare and assign a value to a variable in a single statement, known as initialization:

```
int age = 25;
```

Here, int specifies the data type, age is the variable name, = is the assignment operator, and 25 is the initial value.

Variables can be used in expressions to perform calculations or manipulate data. For instance, you can add two variables and store the result in another variable:

```
int x = 5;
y y = 10;
int sum = x + y;
```

# 4.1.4 Literals

Literals provide constant values directly in the code without needing declaration or computation. There are several main types of literals:

+   - Integer Literals: Integer literals represent numeric values like 10 in decimal, 075 in octal (preceded by 0), or 0xa in hexadecimal.
- Floating Point Literals: Values with decimal points, like 3.14159, are floating point. By default, they are treated as double, but they can be explicitly declared as float with an F suffix (e.g.,3.14159F).
- Character Literals: Character literals are written within single quotes, such as 'a' or 'o', and represent a single character value.
- String Literals: String literals, or character arrays, are written within double quotes, such as "Hello". They are terminated by a null character ('\0').
- Boolean Literals: Although C lacks a native Boolean type, Boolean expressions commonly use 0 for false and any nonzero value (usually 1) for true.

Literals provide convenient fixed values directly embedded in code, initializing variables or serving as operands in expressions. This assortment of literal types forms an essential building block for expressing values in C programs.
