The grouping of related steps into blocks improves readability and management. In many programming languages, braces ({}) are used to enclose statements blocks, allowing them to be treated as a single unit during execution. As a result, the statements can be controlled together through such as by regulating their flow, applying conditions to the entire block, or repeating the entire block in a loop.

Example: Calculate area of triangle

The problem can be written in pseudocode as follows:

```
BEGIN
  DECLARE length, width, area
  INPUT length, width
  PROCESS area = 0.5 * length * width
  OUTPUT area
END
```

The flowchart is shown in Fig. 2.5. Finally, the C program is given below:
#include <stdio.h>

```
int main()
{
  int length, width, area; // declare variables

  printf("Enter length: "); // input length
  scanf("%d", &length);
  printf("Enter width: "); // input width
  scanf("%d", &width);

  area = 0.5 * length * width;

  printf("Area : %d\n", area); // output area

  return 0;
}
```
