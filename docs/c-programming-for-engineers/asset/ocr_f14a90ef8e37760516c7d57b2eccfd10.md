# 7.2. The if Construct

![](bbox=[0.045, 0.075, 0.853, 0.413])

Figure 7.1: C decision making structures

The word if and the brackets around condition are required. The condition must evaluate to a Boolean true or false value, typically achieved by comparing values using relational operators like ==, !=, >, <, etc.

If the condition is true, the code block enclosed in curly braces will execute. If the condition is false, the code block is skipped over.

Although it's permissible to omit curly braces when there's only one statement in each block, it is advisable to keep them for better readability and to avoid potential errors.

For example, if a student's test score is 50 or more, they pass. In C, this is written as:

```
#include <stdio.h>

int main() {
    int grade;

    // Prompt the user to enter their latest test grade
    printf("Enter your latest test grade: ");
    scanf("%%d", &grade);

    // Check if the grade is 50 or higher
    if (grade >= 50) {
        printf("Congratulations! You pass.\n");
    }
```
