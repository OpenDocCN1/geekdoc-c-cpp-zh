# 7.4. The if-else ladder

![](bbox=[0.115, 0.075, 0.805, 0.365])

+   1. The first condition is checked using an if statement.
2. If the condition is false, the next condition is checked using an else if statement.
3. This chaining of else if statements continues for each additional condition that needs to be evaluated.
4. Finally, an else statement is used to handle the last case, which covers all remaining possibilities.

For example:

```
if (temp > 30) {
  // hot case
} else if (temp > 20) {
  // warm case
} else if (temp > 10) {
  // mild case
} else {
  // cold case
}
```

In this example, an if-else ladder is used to categorize weather conditions based on temperature ranges.

The if-else ladder improves the organization and readability of code when dealing with multistep decision-making processes. The conditions are evaluated one-by-one from top to bottom until a matching condition is found. This construct allows for the logical structuring of complex conditional logic, making the code more understandable and maintainable.

As an additional example, consider the use of an if-else ladder to assign letter grades (A, B, C, and F) based on test scores. This demonstrates how the if-else ladder can handle multistage decision-making scenarios effectively.
