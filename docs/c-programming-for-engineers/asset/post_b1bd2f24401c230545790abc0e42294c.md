## Key Characteristics

- **Dedicated Functionality**: Embedded systems are designed for specific tasks, such as controlling industrial machinery, managing smart appliances, or operating automotive systems.
- **Resource Constraints**: These systems often operate with limited resources, including memory and processing power, tailored to the specific requirements of the application.
- **Real-Time Operation**: Many embedded systems must respond to inputs and produce outputs within strict time constraints, which require real-time operation.
- **Integration**: Embedded systems are integrated into larger products or systems, playing a crucial role in enhancing functionality.
- **Minimal User Interface**: Many embedded systems have no or minimal direct user interface. Instead, they work behind the scenes to ensure the proper functioning of the larger device.

## Examples of Embedded Systems

- **Consumer Electronics**: Embedded systems control washing machines, refrigerators, coffee makers, smart TVs, digital cameras, and home automation systems.
- **Automotive Control Systems**: Embedded computers in cars manage functions like engine management, airbag deployment, safety features, and entertainment systems.

### Categories of Embedded Computers

Embedded computers can be categorized by how they are programmed.

### System on Chip (SoC)

- A system on chip (SoC) integrates a complete computer system onto a single chip, encompassing a microprocessor and various peripherals and interfaces, but typically excludes main memory.
- SoC-based single-board computers like the Raspberry Pi allow users to run a variety of applications, similar to traditional computers, making them suitable for educational and hobbyist purposes.
- These systems can run GPOS like Linux, which provides a general-purpose computing environment, or real-time operating systems (RTOS) designed to respond quickly to input changes.

## 1.2. Computer Architecture

### Microcontrollers

- A microcontroller (also known as a microcontroller unit or MCU) is a small self-contained computer system that includes a microprocessor, memory, and input/output (I/O) peripherals on a single chip.
- They are also called bare-metal systems because they operate with very minimal resources and without an operating system.
- Bare-metal systems can be extremely compact, consume very little power and cost very little, and buried deep inside devices such as computer mice, USB drives and even certain USB cables.

The choice between SoC and an MCU depends on the specific needs of the application. SoC-based computers offer more flexibility and general-purpose capabilities, while bare-metal systems prioritize efficiency and cost-effectiveness for specific tasks.

## 1.2 Computer Architecture

Computer architecture refers to the design and organization of computer systems, including hardware, firmware, and software components. It organizes computer systems using a layered structure, making it easier to design, develop, and maintain complex systems. Each layer builds upon the one below it, simplifying the design process.

A computer system typically consists of four layers: hardware, firmware, operating system, and application.

### Hardware Layer

Figure 1.5 illustrates the typical hardware layout of a general-purpose computer. The hardware layer is the foundational layer of a computer system and consists of several major components, each serving a specific function:

- **Processor**: The processor, often referred to as the Central Processing Unit (CPU), is the brain of the computer. It fetches instructions from memory, decodes them, and executes them.
- **Memory**: Memory provides storage for data and instructions. It is divided into two types: primary memory and secondary memory (storage devices such as hard drives or solid-state drives). Primary memory holds data the CPU needs to access quickly.
- **Input/Output (I/O) Devices**: I/O devices enable communication and interaction with the external world. Input devices like keyboards and mice provide data or commands to the computer, while output devices like monitors or printers produce results.

### Firmware Layer

The firmware layer sits between hardware and operating system. It consists of software permanently stored in nonvolatile memory, providing hardware and system initialization. Firmware in an embedded system is pre-installed code that is specifically built for its intended functionality and cannot be easily changed by the user. On PCs, this is typically called BIOS (Basic Input/Output System).

### Operating System (OS) Layer

The operating system layer provides a higher level of control over system resources, enabling the management of processes, memory, and devices. It acts as a platform for executing software. General-purpose computers and sophisticated embedded systems typically run an operating system.

### Application Layer

The application layer is the top layer where user-level software resides. It includes various applications, such as word processors, spreadsheets, web browsers, email systems, and other software chosen by the user. These applications run on top of the operating system, utilizing its services and resources.

### 1.3.1 The Need for Programming Skills in Engineering

Programming involves breaking down complex problems into manageable parts, planning a systematic approach to solving them, gradually implementing solutions for each part, and refining those solutions to solve the problem in the best way. Learning to program develops logical and analytical thinking, benefiting the part of the brain responsible for mathematical reasoning. Here is why programming is essential:

- **Problem-Solving**: Programming takes you a logical approach towards solving any problem. This skill helps engineers think of innovative solutions to various engineering problems.
- **Efficiency and Automation**: Automation, possible through programming, streamlines tasks and reduces errors.
- **Versatility**: Programming skills are valuable across different engineering fields, enabling engineers to contribute to diverse projects.
- **Innovation and Adaptability**: Proficient programmers can adapt quickly to new technologies, driving innovation in engineering practices.
