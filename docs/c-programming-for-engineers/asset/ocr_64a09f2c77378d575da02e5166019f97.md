# # File Input/Output

File handling is a crucial aspect of programming, enabling programs to read, write, and manipulate data stored in files, making it critical for various applications, such as data management, software development, and web applications.

File input/output (I/O) in C allows programs to interact with external storage devices like hard drives, USB drives, and memory cards. This capability enables programs to store and retrieve large amounts of data, which is essential for many applications.

In contrast to standard I/O, which handles input and output from the keyboard, screen, and other hardware, file I/O deals specifically with external storage access. Reasons for needing file handling in C include:

+   - **Persistence**: By saving beyond their runtime, programs can maintain preferences, save application state, and archive historical data.
- **Data exchange**: Files facilitate collaboration, data transfer between applications, and compatibility across platforms, as they allow programs to share data in standardized formats.
- **Handling large datasets**: File I/O enables processing massive amounts of data that exceed memory limits, by reading data in chunks, performing operations efficiently, and writing results incrementally.

It is important to note that file handling relies on the operating system, so this chapter may not be relevant for bare-metal embedded systems.

# ## 11.1 Opening and Closing Files

+   - fpen(): which initializes a file stream and returns a pointer to a FILE structure. It takes two arguments:
  - filename: The name of the file to be opened, provided as a null-terminated string.
  - mode: Specifies the file mode:
    - r: Read-only mode. Allows reading data from the file.
    - w: Write-only mode. Erasing existing content or creates a new file if it doesn't exist.
    - a: Append mode. Adds data to the end of the file without overwriting existing content.

```
FILE *fp;
fp = fopen("my_file.txt", "w");
```

+   - fclose(): After opening a file, it's crucial to close it fclose() when done. This function releases system resources associated with the file. It takes the pointer to a FILE structure returned by the previous fopen() call.
