Here, goto skips the inner loop when i and j are both 3. It jumps back to label1, effectively continuing to the next outer loop iteration.
The goto can be used anywhere in your code, not just in loops. Consider the following example:

```
int main() {
int i = 0;

start:
printf("%d\n", i);
i++;

if (i < 10) {
goto start;
}
return 0;
} 
```

In this example, the goto statement is used to create an almost infinite loop. The loop will continue to execute until the value of i becomes greater than or equal to 10.
The goto statement can sometimes be useful to control the flow of your code. However, it is generally considered a bad practice because it can make your code harder to understand. When using loops, it's better to use break to exit the loop early or continue to the next iteration. Ideally, you should try to avoid using break, continue, and goto statements if possible. # 8.7 Infinite Loops

An infinite loop occurs when a loop continues executing indefinitely without a proper termination condition. In simple terms, it is a loop that never ends unless the program is forcibly terminated or interrupted.
Understanding infinite loops is crucial in C programming, as improperly managed loops can lead to high CPU usage, system crashes, and unresponsive programs. However, when used correctly, infinite loops can be a powerful tool in real-time systems and embedded applications.
Infinite loops can be categorized into unintentional and intentional infinite loops.
