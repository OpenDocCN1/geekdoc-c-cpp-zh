This chapter introduces the use of a programming environment. It discusses the differences between Integrated Development Environments (IDEs) and online compilers. The focus is on a hands-on experience, allowing learners to write, execute, and debug C programs.

# ## 3.1 Compilation Process

Compiling a C program involves converting its source code into machine code for execution on a computer. The process consists of four steps:

+   - **Preprocessing**: The preprocessor takes the source code as input, removes comments, and processes preprocessor directives such as including header files (e.g., <stdio.h>). It replaces these directives with the actual content of included files.

+   - **Compiling**: The preprocessed code is then fed into the compiler, which translates it into assembly code.

+   - **Assembling**: The assembly code produced in the previous step is passed to an assembler, which converts it into object code. The object code is represented in a machine-specific low-level language and typically has a file extension such as .o or .obj.
