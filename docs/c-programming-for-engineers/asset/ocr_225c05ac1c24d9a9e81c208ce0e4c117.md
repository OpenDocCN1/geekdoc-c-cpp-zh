# 5.2.4 Unary Arithmetic Expressions

Unary arithmetic expressions in C involve operations performed on a single operand. Here is a breakdown of each unary arithmetic expression:

+   1. **Increment Operator**: The increment operator (++) increases the value of its operand by 1. It can be used as a prefix (++++) or postfix (x++). When used as a prefix, the value of x is incremented before the expression is evaluated. When used as a postfix, the value of x is incremented after the expression is evaluated.
2. **Decrement Operator**: Similar to the increment operator, the decrement operator--) decreases the value of its operand by 1. It can also be used as a prefix (--) or postfix (x--) with the same behavior as the increment operator.
3. **Positive Operator**: The positive operator (+) is used to explicitly indicate the positive sign of a numeric expression. It doesn't change the value of the operand; it returns the operand as positive.
4. **Negative Operator**: Conversely, the negative operator (-) is used to explicitly indicate the negative sign of a numeric expression. Negates the value of the operand, making it negative.
