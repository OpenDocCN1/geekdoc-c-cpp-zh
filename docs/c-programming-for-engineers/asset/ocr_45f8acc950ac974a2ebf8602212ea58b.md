# Table 10.2: Important Libraries for New Programmers

| Library | Description and Key Functions |
|---|---|
| <stdio.h> | Standard Input/Output Library providing functions for console, file, and device I/O operations such as printf(), gets(), and futs(). |
| <stdlib.h> | Standard Library with general-purpose functions for memory allocation, conversion, sorting, and utility operations like malloc(), atoi(), rand(), and qsort(). |
| <ctype.h> | Character Classification Library for classifying characters (alphanumeric, digit, uppercase, etc.) with functions like isalpha(), isdigit(), and isspace(). |
| <time.h> | Time Library for working with dates, times, and intervals, offering functions like time(), localtime(), and difftime(). |
| <string.h> | String manipulation functions like strlen(), strcpy(), and strcmp(). |
| <malloc.h> | Dynamic Memory Allocation Library providing functions for allocating and deallocating memory at runtime with malloc(), calloc(), and free(). |
| <math.h> | Math Library offering mathematical functions like pow(), log(), sinh(), and cos() for advanced mathematical calculations. |
| <stdbool.h> | Utility Library defining the bool, true, and false keywords for Boolean data type support.|

# 10.8 Library Functions

Libraries are collections of precompiled functions and variables that a program can use to perform specific tasks. They provide a convenient way to reuse code and avoid reinventing the wheel for common functionalities. Table 10.2 lists several libraries that are immediately useful for new programmers. Before you use any function from the library, include the associated library file using the #include directive.

# 10.8.1 Math Library

The Math Library in C provides various mathematical functions for performing common mathematical operations. These functions are declared in the <math.h> header file and can be used by including this header in your C program. More details can be found at https://en.wikibooks.org/wiki/C_Programming/math.h.
