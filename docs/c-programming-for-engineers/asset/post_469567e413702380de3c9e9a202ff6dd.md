## 10.5.2 Using First Element as Size Indicator

In this approach, the first element of an array is used to indicate the size information. This is useful when the array size is fixed and known in advance.
Here is an example of using the first element as a size indicator:

```c
#include <stdio.h>

int sumArray(int arr[]) {
    int size = arr[0];
    int sum = 0;
    for (int i = 1; i < size; i++) {
        sum += arr[i];
    }
    return sum;
}

int main() {
    int numbers[] = {5, 1, 2, 3, 4, 5}; // First element indicates the size

    printf("Array elements: ");
    for (int i = 1; i <= numbers[0]; i++) {
        printf("%d ", numbers[i]);
    }
    printf("\n");

    int arraySum = sumArray(numbers);
    printf("Sum of array elements: %d\n", arraySum);

    return 0;
}
```

## 10.5.3 Using Sentinels

Another approach to pass the size of an array is using sentinel values. Sentinels are special values that mark the end of an array. The function iterates over the array until it encounters the sentinel value, which indicates the end of the array.

Here is an example of passing the array size using a sentinel value:

```c
#include <stdio.h>
#define SENTINEL -1

int sumArray(int arr[]) {
    int sum = 0;
    int i = 0;
    while (arr[i] != SENTINEL) {
        sum += arr[i];
        i++;
    }
    return sum;
}

int main() {
    int numbers[] = {1, 2, 3, 4, 5, SENTINEL}; // SENTINEL marks the end of the array
    printf("Array elements: ");
    for (int i = 0; numbers[i] != SENTINEL; i++) {
        printf("%d ", numbers[i]);
    }
}
```

In this example, the function sumArray accepts one parameter: an integer array referred to as arr. Within the function, it iterates over the array until it encounters the specified SENTINEL value, which indicates the end of the array. Subsequently, it calculates the sum of the array elements up to the sentinel value.
