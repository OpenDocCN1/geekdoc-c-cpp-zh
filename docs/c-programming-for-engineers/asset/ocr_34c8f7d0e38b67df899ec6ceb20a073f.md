# 11.6 Working with Binary Files

Binary files are used to store data in a format intended to minimize storage requirements. They are not human-readable. Examples of binary files used in programs on embedded systems include executable files, object files and binary data files such as image and sound.

Use the read() and fwrite() functions to read and write binary files, respectively:

+   - read(): Reads a block of data from a file into a buffer.
size_t read(void *ptr, size_t size, size_t nmemb, FILE *stream);
- fwrite(): Writes a block of data from a buffer to a file.
size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);

For both functions, the parameters are as follows:

```
void ptr : A pointer to the buffer where the data will be stored or containing the data to be written.
size_t size : The size of each element in bytes.
size_t nmemb : The number of elements to read.
FILE stream : The file stream from which to read the data.
```
