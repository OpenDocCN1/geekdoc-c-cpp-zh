# 10.5.3 Using Sentinels

Another approach to pass the size of an array is using sentinel values. Sentinels are special values that mark the end of an array. The function iterates over the array until it encounters the sentinel value, which indicates the end of the array.

Here is an example of passing the array size using a sentinel value:

```
#include <stdio.h>
#define SENTINEL -1

int sumArray(int arr[]) {
    int sum = 0;
    int i = 0;
    while (arr[i] != SENTINEL) {
        sum += arr[i];
        i++;
    }
    return sum;
}
```
