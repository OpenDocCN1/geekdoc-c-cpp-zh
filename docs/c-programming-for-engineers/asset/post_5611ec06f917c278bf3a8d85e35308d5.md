## 15.3 Arduino C vs Regular C

Arduino C is a simplified version of C++ tailored for programming Arduino Boards. To be technically correct, it should be called Arduino C/C++. While it borrows heavily from C and C++, it is distinct in its approach to hardware interaction and ease of use. Below are the key differences between Arduino and Regular C:

- **Hardware-Specific Design**: Arduino C is designed specifically for programming Arduino boards, which use microcontrollers like the ATmega328 or ARM Cortex-M. It simplifies hardware-specific tasks such as reading from sensors or controlling actuators. Regular C, by contrast, is a general-purpose programming language that can be used on a wide range of platforms, from embedded systems to desktop environments.

- **Level of Abstraction**: Arduino provides a higher level of abstraction, hiding many low-level details. For instance, tasks like memory management and register-level operations are handled by inbuilt libraries. This makes Arduino beginner-friendly. Regular C offers more granular control, requiring the programmer to handle low-level details as memory allocation, hardware registers, and timing.

- **Language Features**: Arduino C is essentially a subset of C++ with limited support for object-oriented programming. While it does include features like the String class, it omits more advanced C++ features like inheritance and polymorphism. Regular C is procedural, without object-oriented capabilities, and C++ (on which Arduino C is based) provides the full spectrum of object-oriented features.

- **Additional Data Types**: Arduino introduces some additional data types to suit the microcontroller environment, such as boolean, byte, and word. It also supports binary literals, `0b10001001` for easy representation of binary data. These types and features simplify programming for microcontroller applications.

- **Program Structure**: Arduino C uses a unique program structure centered on two functions: `setup()` and `loop()`. The `setup()` function initializes the program and runs once at the start, the `loop()` function runs continuously. Regular C programs are structured around the `main()` function, which must explicitly manage initialization and repetitive tasks.

- **Built-In Libraries and Tools**: Arduino C includes a wide range of libraries and tools designed for common microcontroller tasks, such as handling digital and analog I/O, communication, and sensor interfaces. These libraries are preconfigured for Arduino hardware, streamlining development. Regular C lacks such libraries and often requires developers to write or include hardware-specific code manually.

- **Ease of Use vs. Flexibility**: Arduino C is designed with simplicity in mind, making it accessible to hobbyists and beginners. Regular C is more versatile and powerful but requires a deeper understanding of hardware and programming concepts.

In summary, Arduino C is a beginner-friendly language designed to simplify programming for Arduino. Its abstraction and built-in libraries make it ideal for learning and rapid prototyping. Regular C, while more complex, offers greater flexibility and control, making it suitable for applications that go beyond the Arduino ecosystem. Advanced users can use regular C with Arduino boards, but this often involves additional setup and manual configuration.

While Arduino C excels in ease of use, its abstraction may limit performance and flexibility for more complex tasks. For highly specialized or resource-intensive applications, regular C or full-featured C++ may be more appropriate.

### 15.3.1 Arduino Data Types

While Arduino data types are mostly similar to those in standard C++, there are a few data types that are unique to Arduino or have specific usage within the Arduino ecosystem. Here are some of the notable data types in Arduino:

- **boolean**: the data type stores logical values of either true or false. It is used for comparisons and decision making in Arduino programming.
- **byte**: the data type stores 8-bit unsigned integers, with a range of 0 to 255. It is a synonym for `unsigned char` in regular C. Not using the 'char' reinforces the idea that the char data type is not only for ASCII characters but can be used for any type of binary data.
- **word**: the data type stores 16-bit unsigned integers, with a range of 0 to 65535.
- **double**: the data type stores double-precision floating-point numbers.
- **String**: a class used to handle text, providing various methods for string manipulation.
