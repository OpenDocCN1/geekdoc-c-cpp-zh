## String Concatenation Function

The function strcat() concatenates (appends) one string to the end of another.

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str1[] = "Hello, ";
    char str2[] = "World!";
    strcat(str1, str2);
    printf("Concatenated string: %s\n", str1);
    return 0;
}
```

### 10.8.3 Standard Library

The stdlib.h library in C provides utility functions for memory management, strings, numbers, and file I/O operations. They include:

- String conversion functions for converting strings to integer and floating-point types and vice versa.
- Random number generation functions for generating pseudo-random integers.
- Sorting and searching functions for efficient data manipulation, sorting, and searching of large arrays.
- Memory management functions for handling dynamic memory allocation.
- Process control functions for managing external processes and program termination.

These functions facilitate the development of efficient, flexible, and secure C programs.

## ASCII to Integer

The atoi() function converts a string to an integer i.e int and returns it. It is equivalent to (strtol(s, (char**)NULL, 10)). If no valid conversions can be made for the string, it returns zero.

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int main () {
  int value;
  char str[20];
  strcpy(str, "81310");
  value = atoi(str);
  printf("String = %s, Int value = %d\n", str, value);
  strncpy(str, "UTM Skudai");
  value = atoi(str);
  printf("String = %s, Int value = %d\n", str, value);
  return 0;
}
```

On compiling the program, we would get this result:

String = 81310, Int value = 81310
String = UTM Skudai, Int value = 0

## Random Number Generation and Sorting

Two function in stdlib.h could be useful for engineers are rand() and qsort().
The rand() function generates pseudo-random integers in C, useful for simulations, randomized algorithms, or creating unpredictable behaviors. It's common to use the random number generator srand() with a seed value based on the current time to ensure different sequences of random numbers each time the program runs.

The qsort is a C implementation of the popular and efficient sorting algorithm. It takes four arguments: a pointer to the array, the number of elements, the size of each element, and a comparison function defining the sorting order. The comparison function compares two elements and returns an integer indicating their relative order Below is an example code demonstrating the use of both function. Note the use of <time.h> to allow the use of the time() function.

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#define ARRAY_SIZE 10

// Comparison function for qsort
int compare(const void *a, const void *b) {
    return (*(int*)a - *(int*)b);
}

int main() {
    // Seed the random number generator
    srand(time(NULL));

    // Initialize an array of ARRAY_SIZE integers
    int array[ARRAY_SIZE];

    // Fill the array with random values
    for (int i = 0; i < ARRAY_SIZE; i++) {
        array[i] = rand() % 101; // Generate random value between 0 and 100
    }

    // Display the original array
    printf("Original array:\n");
    for (int i = 0; i < ARRAY_SIZE; i++) {
        printf("%d ", array[i]);
    }
    printf("\n\n");

    // Sort the array using qsort
    qsort(array, ARRAY_SIZE, sizeof(int), compare);

    // Display the sorted array
    printf("Sorted array:\n");
    for (int i = 0; i < ARRAY_SIZE; i++) {
        printf("%d ", array[i]);
    }
    printf("\n\n");

    return 0;
}
```

A typical run produces this output:

Original array: 68 91 40 20 21 78 47 72
Sorted array: 20 21 24 40 47 68 72 78

This program seeds the random number generator with the current time, initializes an array of 10 integers with random values between 0 and 100, sorts the array using qsort, and prints the original and sorted arrays.
