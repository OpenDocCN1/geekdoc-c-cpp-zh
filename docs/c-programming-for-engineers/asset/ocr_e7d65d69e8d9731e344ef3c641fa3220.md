# 13.6.2 Queues

A queue is a linear data structure that follows the First-In-First-Out (FIFO) principle, where the first element entered into the queue is the first one to be removed. Queues have two main operations: enqueue (inserting an element) and dequeue (removing an element). There are two main types of queues:

+   - Linear Queue: Uses an array to store elements, with a fixed size.
- Dynamic Queue: Uses a linked list to store elements, allowing for dynamic memory allocation and de-allocation.

A queue has a front and rear, with an enqueue adding elements to the rear and a dequeue removing elements from the front.
Common operations on a queue include:

+   - Enqueue: Insert an element into the queue.
- Dequeue: Remove an element from the queue.
- Front: Get the first element in the queue.
- Rear: Get the rear element in the queue.
- IsEmpty: Check if the queue is empty.
- IsFull: Check if the queue is full.

Queues are useful in various applications, such as operating systems, computer networks, and simulation algorithms, where the order of processing elements is important.
