# 4.3 Data Types

Data types are fundamental in programming as they specify the kind of data a variable can hold. They categorize the sorts of values a variable can store. Understanding data types helps prevent errors, optimizes memory usage, and improves code readability.

C provides a range of data types, encompassing numeric types like byte, int, long, float, and double, as well as character types like char and string. Each data type has distinct characteristics and a specific value range. Selecting the appropriate data type based on the expected range of values is crucial for optimizing C programming efficiency.

The size of data in C varies depending on the underlying platform. The ranges outlined in this section hold true for personal computers. However, in scenarios involving embedded systems with smaller processors, the sizes are typically more compact. Table 4.6 lists the major groups of C data types.

| Data Type | What It Stores | Example |
|---|---|---|
| Integer | Whole numbers | int age = 25; |
| Floating-point | Fractional numbers | double pi = 3.14159263589793; |
| Character | Characters | char initial = 'A'; |

# 4.3.1 Integer Data Types

In C, integer data types provide options for storing whole numbers, each with its own size and range.

The Basic Type: int

The most commonly used type is int, which occupies 32 bits (4 bytes) on personal computers, allowing values ranging from -2,147,483,648 to 2,147,483,647 (about ±2 billion). The int data type frequently yields optimal performance because its size corresponds to the native data size in many computer architectures.
