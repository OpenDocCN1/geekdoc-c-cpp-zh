# Chapter 13. Structured Data

+   - We define structures for Node and Stack.
- The createStack() function allocates memory for a new Stack and initializes its top pointer to NULL (empty stack).
- The isEmpty() function checks if the top pointer is NULL, indicating an empty stack.
- The push() function creates a new node, adds the data element, and sets it as the new top by updating the top pointer.
- The pop() function checks for an empty stack and returns an error if so. Otherwise, it stores the data and node to be deleted, updates the top pointer to the next node, and frees the memory of the deleted node.
- The peek() function checks for an empty stack and returns an error if so. Otherwise, it simply returns the data of the top node without removing it.
- The main() function demonstrates creating a stack, pushing elements, peeking the top element, and popping an element.

# Summary

In this chapter, we explored topics related to structured data in C programming. It begins with structs and explains its syntax, accessing members, using pointers to structures, passing structs to functions, and returning structs from functions. The chapter then introduces unions, typedef, enums, and bit fields. Finally, we delve into basic data structures, namely linked lists, queues, and stacks.
