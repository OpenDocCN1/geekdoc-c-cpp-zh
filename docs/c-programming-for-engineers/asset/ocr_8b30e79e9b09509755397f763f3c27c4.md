# 15.3. Arduino C vs Regular C

+   Built-In Libraries and Tools:
Arduino C includes a wide range of libraries and tools designed for common microcontroller tasks, such as handling digital and analog I/O, communication, and sensor interfaces. These libraries are preconfigured for Arduino hardware, streamlining development. Regular C lacks such libraries and often requires developers to write or include hardware-specific code manually.

+   Ease of Use vs. Flexibility:
Arduino C is designed with simplicity in mind, making it accessible to hobbyists and beginners. Regular C is more versatile and powerful but requires a deeper understanding of hardware and programming concepts.

In summary, Arduino C is a beginner-friendly language designed to simplify programming for Arduino. Its abstraction and built-in libraries make it ideal for learning and rapid prototyping. Regular C, while more complex, offers greater flexibility and control, making it suitable for applications that go beyond the Arduino ecosystem. Advanced users can use regular C with Arduino boards, but this often involves additional setup and manual configuration.

While Arduino C excels in ease of use, its abstraction may limit performance and flexibility for more complex tasks. For highly specialized or resource-intensive applications, regular C or full-featured C++ may be more appropriate.

# 15.3.1 Arduino Data Types

While Arduino data types are mostly similar to those in standard C++, there are a few data types that are unique to Arduino or have specific usage within the Arduino ecosystem. Here are some of the notable data types in Arduino:

**boolean** the data type stores logical values of either true or false. It is used for comparisons and decision making in Arduino programming.
**byte** the data type stores 8-bit unsigned integers, with a range of 0 to 255. It is a synonym for unsigned char in regular C. Not using the 'char' reinforces the idea that the char data type is not only for ASCII characters but can be used for any type of binary data.
**word** the data type represents an 16-bit value (0 to 65535). It is a synonym for unsigned int in regular C. It is often used for storing larger numerical values that do not require floating-point precision.
**double** represents double-precision floating-point in regular C but Arduino C on the 8-bit microcontrollers, the range and size are the same as the float data type.

**String** in Arduino C, String is a special data type that is used for handling text or string data. It's a wrapper around the C char array, and Arduino provides some convenient methods for manipulating strings.
