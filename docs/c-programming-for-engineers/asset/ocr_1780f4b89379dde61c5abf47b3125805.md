# CONTROL STATEMENTS

```
if (x == 0) {
  switch (x) {
    case 1:
      break;
    case 2:
      break;
    default:
      break;
  }
}
while (x < 10) {
  for (int i = 0; i < 10; i++) {
    break;
  }
  // exit loop switch immediately
continue; // go to next iteration
```

# ARDINO LIBRARY

```
Serial - communication via UART
Serial.begin(baudrate); Serial.print(data); Serial.println(data); Serial.write(byte);
```

```
Wire - I2C communication
Wire.begin(); Wire.requestFrom(address); Wire.write(byte); Wire.endTransmission();
String.readString(char); String.substring(start, end);
```

```
EEPROM - non-volatile memory
EEPROM.read(address); EEPROM.write(address, value); EEPROM.update(address, value);
```

```
Servo - control motor servo
Servo.attach(pin); Servo.write(angle); Servo.writeMicroseconds();
```

```
SoftwareSerial - UART on any pins
SoftwareSerial.begin(baudrate); SoftwareSerial.print(); SoftwareSerial.available();
```

```
LiquidCrystal - display
lcd.begin(rows, cols); lcd.clear(); lcd.setCursor(col, row); lcd.print(data);
```
