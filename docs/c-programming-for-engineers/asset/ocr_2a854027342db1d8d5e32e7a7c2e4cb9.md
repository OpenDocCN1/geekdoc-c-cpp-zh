# 15.3. Arduino C vs Regular C

Table 15.3: Arduino C Pin Input/Output Functions

| Function | Description |
|---|---|
| pinMode(pin, mode) | Configures a specific pin as either an input (INPUT) or an output (OUTPUT). |
| digitalWrite(pin, value) | Writes a digital value (HIGH or LOW) to a specific output pin |
| digitalRead(pin) | Reads the digital value (HIGH or LOW) from a specific input pin |
| analogWrite(pin, value) | Writes an analog voltage level (between 0 and 255) to a specific PWM (Pulse Width Modulation) capable pin, creating a simulated analog output |
| analogRead(pin) | Reads an analog voltage level (between 0 and 1023) from a specific input pin |

**INPUT:** Requires an external voltage source (HIGH or LOW) on the pin. Leaving it unconnected can lead to unpredictable readings.
**INPUT_PULLUP:** Activates a internal pull-up resistor (~19kΩ) that keeps the pin HIGH by default when nothing is connected. For buttons/switches (connected to ground when pressed) and avoids the need for external resistors.
**OUTPUT:** Allows you to write a digital value (HIGH or LOW) to the pin, controlling external devices or components.

You can change a pin's mode any time in your program, not during setup. This is useful, especially in communication tasks where you send and receive data on the same wire. The default setting for an Arduino pin is INPUT mode.

# Digital Output

The **digitalWrite()** function controls digital components and devices connected to the Arduino. It allows you to set a digital pin to either a HIGH (5V) or LOW (0V) voltage level, enabling precise on/off control.
