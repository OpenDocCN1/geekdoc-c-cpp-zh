# 12.3 Pointers and Arrays

Arrays and pointers are closely related in C. Array elements have addresses, and pointers can be used to access these addresses. 

```
int ar[20], *ip;
```

```
ip = &ar[0]; // point to first element in array
ip = ar; // same as ip = &ar[0]
```

Pointer arithmetic allows efficient manipulation of array elements. Sequential access through pointers is faster than array indexing, eliminating associated arithmetic:

```
sum = 0;
for (ip = ar; ip < &ar[20]; ip++)
sum += *ip;
```

The compiler internally uses pointers to access array elements. With this knowledge, we can utilize pointers to access and modify the elements of a given array. The example below illustrates the use of pointers to access array elements.

```
#include <stdio.h>

int main()
{
    int arr[] = { 100, 200, 300, 400 };
```

```
// Compiler converts below to *(arr + 2)
printf("%d\n", arr[2]);
```

```
// So below also works.
printf("%d\n", *(arr + 2));
```

```
    return 0;
}
```

Pointer arrays store arrays of pointers, where each element is a pointer. For example:

```
int ptrArr[5];

printf("Value of x: %d\n", ptrArr[0]);
```
