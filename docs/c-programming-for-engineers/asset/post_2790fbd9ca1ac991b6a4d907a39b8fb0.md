This chapter focuses on decision making in C programming. We will cover different decision making constructs, their uses, and the evaluation rules, allowing you to create more sophisticated decision-making structures, handle data, and improve program logic.

### 7.1 Boolean Expressions

Boolean expressions (named after the English mathematician George Boole) are used to control program flow. They're often used to check conditions. Programs can test conditions to decide what actions to take. The most basic type of Boolean expression is one that compares two values. Table 7.1 lists the C relational operators.

Table 7.1: C relational operators

| Operator | Example | Meaning |
| :--- | :--- | :--- |
| == | a == b | True if a is equal to b |
| != | a != b | True if a is not equal to b |
| > | a > b | True if a is greater than b |
| < | a < b | True if a is less than b |
| >= | a >= b | True if a is greater than or equal to b |
| <= | a <= b | True if a is less than or equal to b |

It is very important to note that equality uses a double equal sign. A single equal sign is an assignment operation. Don't think "equals", think "same as", with one symbol for each word.

Relational operators help us create basic conditions. However, sometimes we need to check if one thing is true AND another thing is true, or if one of two things is true. For these cases, we use compound and logical operators like AND, OR, and NOT. Table 7.2 lists the C logical operators.

Table 7.2: C logical operators

| Operator | Description | Example | Meaning |
| :--- | :--- | :--- | :--- |
| && | Logical AND | a && b | True if both a and b are true |
| || | Logical OR | a || b | True if either a or b is true |
| ! | Logical NOT | !a | True if a is false (negation) |

C does not have a specific data type for Boolean values, so 1 is used to represent true and 0 to represent false. The logical operators in C treat any non-zero value as true and zero as false.

### 7.2 The if Construct

The if statement is a fundamental control structure that enables programs to make decisions based on specific conditions. It allows a program to execute a block of code only if a specified condition is true. The if construct flowchart, syntax, and pseudocode is summarized in Fig. 7.2. The syntax is as follows:

```c
if (condition) {
    // Code to execute if true
}
```
Figure 7.1: C decision structures

### 7.2. The if Construct

The word if and the brackets around condition are required. The condition must evaluate to a Boolean true or false value, achieved by comparing values using relational operators like ==, !=, >, <, etc. If the condition is true, the code block enclosed in curly braces will execute. If the condition is false, the code block is skipped. Although it's permissible to omit curly braces when there's only one statement in each block, it is advisable to keep them for better readability and to avoid potential errors. For example, if a student's test score is 50 or more, they pass. In C, this is written as:

```c
#include <stdio.h>

int main() {
    int grade;

    // Prompt the user to enter their latest test grade
    printf("Enter your latest test grade: ");
    scanf("%d", &grade);

    // Check if the grade >= 50
    if (grade >= 50) {
        printf("Congratulations! You pass.\n");
    }
    
    return 0;
}
```

### 7.2.1 Executing a Block of Statements

The code to execute a block of one or more statements enclose them by curly braces }. Suppose we want to make sure a is always greater or equal to b. When a is less than b, we want to swap the value. When we get:

```c
if (a < b) { // swap only if a < b
    t = a; // store in a temporary variable
    a = b; // copy b to a
    b = t; // update b with temporary variable
}
```
This is how to write a code block in pseudocode:

```text
IF <condition> THEN
  <statement1>
  <statement2>
ENDIF
```
In writing pseudocode, programmers use the word "endif" for convenience; it is not a C keyword.

### 7.2.2 Compound Conditions

Logical operators, such as && (logical AND), || (logical OR), and ! (logical NOT), are used to create compound conditions by combining simpler conditions. Below are examples demonstrating the usage of logical operators in condition checks:

```c
if (a == 6) && (b != 7) ... // Taken if a is 6 AND b is not 7
if (a == 6) || (b != 7) ... // Taken if a is 6 OR b is not 7
```

### 7.3 The if-else Construct

The if-else construct allows programmers to further conditionally control program flow based on Boolean expressions. It allows alternative code to be executed if the original condition is false.

Often you will want to write code to run if a condition is true, but different code to handle the false case. This is where if-else comes in. The basic syntax of an if-else statement is:

```c
if (condition) {
    // Code to execute if condition is true
} else {
    // Code to execute if condition is false
}
```
If condition is true, code block 1 will execute. If condition is false, the program will skip block 1 and instead execute block 2. This provides a way to have distinct code paths depending on the truth value of the condition checked. For example, if a student's test score is 50 or more, they pass; otherwise, they fail. In C, this is written as:

```c
#include <stdio.h>

int main() {
    int grade;

    // Prompt the user to enter their latest test grade
    printf("Enter your latest test grade: ");
    scanf("%d", &grade);

    // Check if the grade is >= 50
    if (grade >= 50) {
        printf("Congratulations! You pass.\n");
    } else {
        printf("Sorry, you did not pass.\n");
    }

    return 0;
}
```
