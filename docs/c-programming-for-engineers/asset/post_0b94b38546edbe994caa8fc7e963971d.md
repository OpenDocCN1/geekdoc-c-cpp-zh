To find the length of a string you can use either the strlen() function or the length() method. The function works independently, while the method is associated with the String object and can directly access its internal data. Here is an example of Arduino code that demonstrates this functionality.

```
#include <Arduino.h>
#include <String.h>
#include <string.h>

void setup() {
  Serial.begin(9600);

  char cString[] = "Hello, World!";
  String arduinoString = "Hello, World!";

  // Using strlen() function
  int length = strlen(cString);
  Serial.print("String length: ");
  Serial.println(length);

  // Using the String length() method
  length = arduinoString.length();
  Serial.print("String length: ");
  Serial.println(length);
}

```

## 15.4 Hello World in Arduino

"Hello, World!" program has become a tradition and part of programming culture. It is often the first program that programmers write in a new language. In this section, we will write the "Hello, World!" in Arduino C.

In Arduino, a sketch refers to the code written for an Arduino board. A sketch is typically written using the Arduino Integrated Development Environment (IDE) and consists of two essential functions: setup() and loop(). The setup() function is executed once at the beginning, while the loop() function is continuously executed in a loop.

Let us explore Arduino C! When you open the Arduino IDE, you will see a new sketch which is like a blank canvas for your program. This sketch already has functions built-in: setup() and loop(). They are ready for you to use in your code.

```
void setup() {
  // put your setup code here, to run once:
}

void loop() {
  // put your main code here, to run repeatedly:
}
```

Let us analyze what we see. In regular C programming, we typically execute programs on general-purpose computers with operating systems. Here, the program starts by transferring control from the OS to the main() function. When the program finishes, it returns a success code (often "return 0;") back to the operating system. Since this return value is an integer, the main() function itself has an int data type. The key concept is that the program eventually terminates, and control goes back to the OS.

However, things work differently on embedded systems like Arduino boards. Here, the program runs continuously and never terminates. There is no need to return an integer to an operating system. Instead, an embedded application is typically structured with two main parts: initialization and a main loop.

- Initialization (setup()): This part is executed only when the program starts. This can include initializing variables, setting pin modes, configuring communication ports, and other setup tasks.
- Main Loop (loop()): Once the setup is complete, control is transferred to the loop() function. This function runs repeatedly in an endless loop. This section typically contains the core functionality of your program, such as reading sensors, performing calculations, controlling actuators, and responding to external events or inputs.

By separating the initialization and main loop into distinct functions, the Arduino framework simplifies the development process for embedded systems.
Now, we can proceed with the actual "Hello, World!" program below:

```
// Hello, World! Arduino-style
void setup() {
  Serial.begin(9600); // Initialize serial communication at 9600 baud
}
void loop() {
  // "Hello, World!" to the serial monitor
  Serial.println("Hello, World!"); // Print the message
  delay(1000); // Pause for a second
}
```

## 15.5 Blinky Program in Arduino C

The "Blinky" program is the hardware equivalent of "Hello, World!" and is often the first program written when learning to program microcontrollers. It blinks the built-in LED on an Arduino board.

The built-in LED is connected to pin 13. You can refer to it using the number 13 or the constant LED_BUILTIN. To control the LED, use the functions pinMode() and digitalWrite().

```
// Blinky: blinks the built-in LED

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
```
