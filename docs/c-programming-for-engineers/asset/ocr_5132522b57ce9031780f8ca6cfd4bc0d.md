# Computers and Programming

This learning module aims to teach C programming to electrical engineers, focusing on practical programming skills rather than extensive hardware knowledge. Before diving into programming, it is important to have an overview of what a computer is, its components, how software interacts with hardware, and the significance of programming knowledge.

# 1.1 Understanding Computers

We all have an idea of what a computer is: it is the device with a screen, keyboard, and often other things like a mouse, microphone, camera, and speakers. Most computers can store information, connect to the Internet, and use external devices such as USB drives. Even your smartphone is a kind of computer, and we call these general-purpose computers.

But there is another kind of computer embedded systems.

# 1.1.1 General-Purpose Computer Systems

General-purpose computers, such as desktops, laptops, tablets, and smartphones, are versatile and optimized for multitasking. They handle everyday tasks, run various applications, and have a central processing unit (CPU), memory, storage, and input/output interfaces.

Here are some characteristics of general-purpose computers:

+   - Versatility: They can perform a wide range of tasks, running various applications and adapting to different user needs.

+   - User-Interface: These computers use graphical user interfaces (GUIs) and offer voice and finger input, making user-friendly.

+   - Operating Systems: General-purpose computers rely on general-purpose operating systems (GPOS) such as Windows, macOS, Linux, ChromeOS, Android, or iOS to manage resources and facilitate communication between hardware and software.

# 1.1.2 Embedded Systems

Embedded systems are specialized computers designed for specific functions within a larger system. They are often dedicated to performing a single task or a set of closely related tasks. Unlike general-purpose computers, embedded systems are not as visible to users because they are built into other devices or machinery.
