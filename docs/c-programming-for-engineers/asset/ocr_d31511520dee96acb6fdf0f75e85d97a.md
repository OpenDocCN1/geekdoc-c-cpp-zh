For example, consider the following code snippet:

```
int num1 = 7;
float num2 = 2;
float result = num1 / num2;
```

In this example, num1 is automatically converted to a float before performing the division operation. This is because the data types of both operands in a division expression must be the same. Since num2 is a float, num1 is implicitly cast to a float to ensure correct data types.

Automatic type conversion attempts to maintain consistency and accuracy in calculations within C programs. However, it's important for programmers to be aware of these conversions to avoid unintentional data loss.

# 5.4.2 Explicit Type Conversion

Explicit type conversion, also known as type casting, is a way to explicitly convert one data type to another in C. It involves using the casting operator to specify the desired data type for a particular value or expression.
The syntax for explicit type casting is as follows:

(type) value

Here, type represents the target data type to which the value is being cast, and value is the expression or variable that needs to be converted.
Explicit type conversion is useful in situations where you want to enforce a specific type conversion, ensuring the desired behavior in expressions. It allows you to control how values are converted and handle potential data loss or precision issues.

Consider the following code snippet:

```
int num1 = 5, num2 = 2;
float truncated = num1 / num2; // answer 2.000
float result = (float) num1 / num2; // answer 2.500
```

In this example, type division ensures the division is in floating-point. Without the casting operator, integer division would be performed the fraction part to be truncated. For efficiency, C attempts to perform all operations in the lowest data type possible.

A cast is not required when assigning a value from a smaller data type to a larger one. However, using a cast, even in such situations, is still a good idea to make the cast explicit and document the intentional data type change.

In this example, cast is added to clarify the programmer's intention:

```
char ch = 'A';
int ascii_value = (int)ch;
```

Here, we get the ASCII value of the character 'A', which is 65. Adding the cast operator makes it clear that the programmer intentionally converts the 8-bit character data to the integer data type.
