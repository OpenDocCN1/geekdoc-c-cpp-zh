Figure 9.1: Bubble sort

+   - The outer loop (using the variable i) controls how many passes the algorithm makes through the list.
- The inner loop (using the variable j) goes through the list, comparing and swapping elements if needed.

The outer loop runs n-1 times, where n is the number of elements in the array. This is because, after each pass, the largest remaining unsorted number is placed in its correct position, so fewer comparisons are needed each time. In each pass, i increases, and the inner loop runs fewer times (n-i-1) because the largest numbers are already sorted and don't need to be checked again.

For example:

+   - In the first pass (i = 0), the j goes up 6, so the inner loop checks and potentially swaps all elements.
- In the second pass (i = 1), j goes up to only 5, so it checks one less element, and so on.
- This continues until the array is sorted.

After the sorting process is complete, the code prints out the sorted array. Despite its simplicity, bubble sort's efficiency is relatively low, especially for large lists, as it requires multiple passes over the data. However, its straightforward nature makes it an excellent introduction to sorting algorithms and a valuable learning tool in computer programming.
