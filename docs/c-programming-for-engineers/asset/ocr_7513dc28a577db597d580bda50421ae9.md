# 7.6 The switch Construct

The switch construct in C is used to select and execute specific code blocks based on a variable's value (See Fig. 7.6). It provides a concise alternative to multiple if-else-if blocks. Here's the basic syntax:

```
switch (expression) {
  case value1:
    // code to be executed if expression equals value1
    break;
  case value2:
    // code to be executed if expression equals value2
    break;
    // more case statements as needed
  default:
    // code to be executed if none of the above cases is true
  break;
}
```
