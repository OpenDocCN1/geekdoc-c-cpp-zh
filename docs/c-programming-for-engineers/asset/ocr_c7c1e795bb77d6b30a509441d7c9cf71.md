# 6.3.2 Considerations Using scancf

The scanf function is powerful function for getting user input but it can be tricky to use. Here's a list of what to watch for:

+   - **Multiple inputs**: scanf can read multiple inputs separated by whitespace, such as spaces, tabs, and newlines.
- **Whitespace Handling**: By default, scanf skips leading whitespace before attempting to read input, which can sometimes lead to unexpected results, especially with character or string inputs.
- **Buffering Issues**: scanf reads characters from the input stream and stores them in an internal buffer until the entire format is matched. If there's a mismatch, it can leave characters in the input stream, potentially affecting subsequent inputs.
- **Newline Handling**: scanf retains a trailing newline in the buffer after the user presses Enter. Flushing the input stream can ensure smooth operation and prevent disruptions from leftover characters.
- **Return Value**: The scanf function returns number of input items successfully matched and assigned. Validating this value can ensure correct input operations.

While scanf is flexible for interactive input, understanding it well is crucial to avoid problems and keep your program running smoothly. For reduce the risk of program crashes, think about using *fgets* with scanf.

# 6.4 Reading Strings

To read strings in C, you can use scanf with the %s format specifier. However, note that scanf stops reading characters when it encounters whitespace, so it only reads a single word at a time. Here's a simplified example:

```
#include <stdio.h>

int main() {
    char str[50]; // Assuming a maximum string length of 49 characters

    printf("Enter a string: \n");
    scanf("%s", str);

    printf("You entered: %s\n", str);

    return 0;
}
```
