### 2.4.1 Sequential Structure

Sequential structure refers to executing a series of steps or statements in the order they are written in an algorithm. This structure allows us to make decisions, repeat actions, and control the flow of statements. For clarity regarding the sequence of execution, individual steps can be numbered.

```
Begin
Statement_1
Statement_2
Statement_3
...
Statement_n
End
```

In this pseudocode snippet, the statements Statement_1, Statement_2, Statement_3 until Statement_n are grouped within the Begin and End keywords. Even though they are separate statements, they are considered as one statement block in terms of execution.

Example: Calculate area of triangle

The problem can be written in pseudocode as follows:

```
BEGIN
  DECLARE length, width, area
  INPUT length, width
  PROCESS area = 0.5 * length * width
  OUTPUT area
END
```

  printf("Enter width: "); // input width

  printf("Area : %d\n", area); // output area

  return 0;

### 2.4.2 Selection Structure

Selection structure, also known as conditional structure, is a programming construct that allows for decision-making based on certain conditions. It provides the ability to execute different blocks of code depending on whether a condition is evaluated as true or false.

Computers can handle only simple decisions because they only understand "true" or "false". If there's a need for complex decisions, it's up to the programmer to break them down into simpler ones that the computer can handle.

In this structure, the program evaluates the condition, and if it is true, it executes the code block associated with the if statement. If the condition is false, it executes the code block associated with the else statement.

```
IF (condition)
  // Code block to be executed if condition is true
ELSE
  // Code block to be executed if condition is false
ENDIF
```

Selection structures are fundamental for creating programs that can adapt their behavior based on varying inputs or circumstances.

Example: Check if user can vote

Consider the following pseudocode to determine whether a user is eligible to vote based on their age:

![](img/33fb6b7acbb6df48a3c9564e97117da6_38_0.png)

```
BEGIN
DECLARE age
INPUT age
IF age >= 18 THEN
    OUTPUT "OK to vote"
ELSE
    OUTPUT "Not eligible yet"
ENDIF
END
```

This pseudocode checks if the input number is greater than 0, less than 0, or equal to 0, and outputs the corresponding message. The flowchart is shown in Fig. 2.6. Here is the C code:

![](img/33fb6b7acbb6df48a3c9564e97117da6_39_0.png)

Figure 2.6: Flowchart for selection structure

```c
#include <stdio.h>

int main() {
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    if (age >= 18) {
        printf("OK to vote\n");
    } else {
        printf("Not eligible yet\n");
    }

    return 0;
}
```

### 2.4.3 Repetition Structure

Repetition structure, also known as looping or iterative structure, is a fundamental programming construct that allows the execution of a block of code repeatedly as long as a specified condition is true. It enables automation of repetitive tasks, programs more efficient and concise.

There are several types of loops commonly used in programming languages:

- *While Loop*: Executes a block of code repeatedly as long as a specified condition is true.
- *For Loop*: Executes a block of code a specified number of times, typically used for iterating over sequences like arrays.
- *Do-While Loop*: Similar to the while loop, but the block of code is executed at once before the condition is checked.

Loops are essential for tasks such as iterating through arrays, processing lists of data, and implementing algorithms that require repetitive operations. While and for loops are called pre-test loops because the condition is checked before executing the loop. On the other hand, the do-while loop is called a post-test loop because the condition is checked after the statements in the loop are executed.

Example: Print Numbers from 1 to 5

Consider the following pseudocode to print numbers from 1 to 5 using a while loop:

```
BEGIN
  DECLARE num
  SET num to 1
  WHILE num <= 5 DO
    OUTPUT num
    INCREMENT num
ENDWHILE
END
```

This pseudocode initializes a variable num to 1 and then uses a while loop to repeatedly output num until it reaches 5. The num variable is incremented after each iteration. The flowchart is shown in Fig. 2.7.

Here's the corresponding C code:

![](img/33fb6b7acbb6df48a3c9564e97117da6_41_0.png)

```c
#include <stdio.h>

int main() {
    int num = 1;
    while (num <= 5) {
        printf("%d\n", num);
        num++;
    }
    return 0;
}
```

## 2.5. Modularity and Functions

Modularity is a fundamental concept in programming, which involves the decomposition of a complex system into smaller, manageable, and independent units called modules. Each module has a well-defined purpose and interacts with other modules through clearly defined interfaces. The benefits of modularity include the following:

- Reusability: Modules can be reused in different parts of a program or even in different programs, reducing code duplication and development effort.
- **Easier Maintenance**: Modular code is easier to maintain and update, as changes can be made to individual modules without affecting the rest of the system. This facilitates debugging and updating processes.
- **Organization and Readability**: Modular code is more organized and easier to understand, as it breaks down complex functionality into smaller logical units.
- **Improved Scalability**: Modular design allows for easier scaling of a system by adding or removing modules as needed.
- **Team Collaboration**: Modularity facilitates collaboration among multiple programmers, as different team members can work on different modules concurrently.

In C, modularity is achieved by breaking a program into functions. Functions are defined with a return type, a name, optional parameters (also known as arguments), and a body containing the code to be executed. Functions are invoked or called by their name, and they can return a value to the caller if specified.

Let's look at an example of a simple function:

```c
#include <stdio.h>

// Function declaration for a simple function
void greet() {
    printf("Hello, World!\n");
}

int main() {
    greet();      // Function call
    return 0;
}
```

Many functions take inputs, perform calculations, and return results. Let us take a look at a parameterized function:
