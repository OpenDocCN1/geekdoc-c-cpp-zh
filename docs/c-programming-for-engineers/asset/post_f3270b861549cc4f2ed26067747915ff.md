## 8.5 Nested Loops

Nested loops are placed inside other loops. This allows for more complex iterations by using an inner loop to repeatedly execute a set of statements for each iteration of the outer loop.

Nested loops are useful for:

- Iterating over multi-dimensional data structures like matrices or nested arrays.
- Solving problems involving hierarchical structures.
- Creating combinations or permutations.
- Carrying out operations requiring multiple levels of iteration.

The outer loop controls the overall iteration, while the inner loop executes a set of statements for each iteration of the outer loop. This technique is commonly used when working with hierarchical or multi-dimensional data structures, as it allows for nested or sequential iterations over the data.

### Snippet: Printing a Multiplication Table

The following example demonstrates a nested loop to print a multiplication table:

```
#include <stdio.h>

int main() {
    for (int i = 1; i <= 5; ++i) {
        for (int j = 1; j <= 5; ++j) {
            printf("%d * %d = %d\n", i, j, i * j);
        }
    }
    return 0;
}
```

In this example, the outer loop iterates over the values from 1 to 5 for the multiplicand i, while the inner loop iterates over the same range of values for the multiplier j. This results in a complete multiplication table from 1 to 5.

### Snippet: Character Pattern

This snippet prints a row of asterisks of varying lengths.

```c
for(int i=0; i<5; i++) {
    for(int j=0; j<=i; j++) {
        printf("*");
    }
    printf("\n");
}
```

The output is:

*
**
***
****

In this snippet, the inner loop iterates from 0 to the current value of the outer loop variable i, while the outer loop iterates five times (from 0 to 4). An asterisk is printed during each inner loop iteration. After each row of asterisks is printed, the character \n is printed in the outer loop to advance the cursor to the next line.

### Snippet: Bubble Sort

This snippet implements the bubble sort algorithm, which is a simple sorting algorithm that works by repeatedly iterating through a list of elements and swapping adjacent elements if they are in the wrong order

```c
int arr[5] = {3,5,2,1,4};
for(int i=0; i<5; i++) {
  for(int j=i+1; j<5; j++) {
    if(arr[i] > arr[j]) {
      temp = arr[i];
      arr[i] = arr[j];
      arr[j] = temp;
    }
  }
}
```

### Snippet: The first 100 prime numbers

```c
int i, j, isPrime = 1;
while (i <= 100) {
  for (j = 2; j <= i/2; j++) {
    if (i % j == 0) {
      isPrime = 0;
      break;
    }
  }
  if (isPrime) {
    printf("%d ", i);
  }
  i++;
}
```

The outer loop iterates to check up to 100 numbers. The inner loop checks whether a number is prime by checking whether it is divisible by any number between 2 and its square root. If it is not divisible, it is a prime number, and the number is printed.

## 8.6 Loop Control Statements

In C programming, loop control statements are powerful tools that allow one to modify the behavior of loops. Three commonly used loop control statements are break, continue and goto.

### 8.6.1 The break Statement

The break statement (see Fig. 8.4) is used to terminate the loop prematurely. When a break statement is encountered within a loop, the loop is immediately terminated, and program control is transferred to the statement following the loop. This statement is commonly used to exit loops based on certain conditions or implement early termination logic.

```c
while (test expression) {
  if (test expression) {
    break;
  }
}

do {
  if (test expression) {
    break;
  }
} while (test expression);

for (int expression; test expression; update expression) {
  if (test expression) {
    break;
  }
}
```

NOTE: The break statement may also be used inside body of else statement.

Figure 8.4: The break keyword

Consider the following example:

```c
#include <stdio.h>

int main() {
    int i;
    // Loop to print numbers from 1 to 10
    for (i = 1; i <= 10; i++) {
        if (i == 5) {
            break; // Exit loop when i equals 5
        }
        printf("%d\n", i);
    }
}
```

In this example, the loop ends as soon as the value of i becomes 5, skipping the rest of the iterations.

### 8.6.2 The continue Statement

The continue statement (see Fig. 8.5) is used to skip the remaining code inside a loop for the current iteration and proceed to the next iteration. This statement is useful for skipping specific iterations based on certain conditions.

```c
while (test expression) {
  if (test expression) {
    continue;
  }
}

do {
  if (test expression) {
    continue;
  }
} while (test expression);

for (int expression; test expression; update expression) {
  if (test expression) {
    continue;
  }
}
```

NOTE: The continue statement may also be used inside body of else statement.

Figure 8.5: The continue keyword

Consider the following example:

```c
#include <stdio.h>

int main() {
    int i;

    // Loop to print even numbers from 1 to 10
    for (i = 1; i <= 10; i++) {
        if (i % 2 != 0) {
            continue; // Skip odd numbers
        }
        printf("%d\n", i);
    }

    return 0;
}
```

In this example, the continue statement skips iterations where i is even, resulting in the printing of only odd numbers. While break and continue statements offer powerful control of loops, using them too much can make the code complicated. It's important to use them carefully to keep the code clear. Nested loops with multiple break and continue statements can make it hard to understand how the program works.

### 8.6.3 The goto Statement

The goto statement allows you to jump directly to a specific location in your code, marked by a label. The syntax is as follows:

```
label:
// code to be executed
goto label;
```

The label starts with an alphanumeric character, followed by a colon. You can use the goto statement to jump to any point in your code. Consider the following example where goto is used to skip ahead in a loop:

```c
#include <stdio.h>

int main() {
    int i, j = 10;
    char ch = 'A';

label:
    for (i = 1; i <= 5; i++) {
        for (j = 1; j <= 5; j++) {
            if (i == 3 && j == 3) {
                goto label; // Jump to label, skipping the inner loop
            }
        }
        printf("i = %d, j = %d, ch = %c\n", i, j, ch++);
    }
    return 0;
}
```

Here, goto skips the inner loop when i and j are both 3. It jumps back to label, effectively continuing to the next outer loop iteration. The goto can be used anywhere in your code, not just in loops. Consider the following example:

```c
int main() {
int i = 0;

start:
printf("%d\n", i);
i++;

if (i < 10) {
goto start;
}
return 0;
} 
```

In this example, the goto statement is used to create an almost infinite loop. The loop will continue to execute until the value of i becomes greater than or equal to 10.
-wait, the goto statement can sometimes be useful to control the flow of your code. However, it is generally considered a bad practice because it can make your code harder to understand. When using loops, it's better to use break to exit the loop early or continue to the next iteration. Ideally, you should try to avoid using break, continue, and goto statements if possible. ## 8.7 Infinite Loops

An infinite loop occurs when a loop continues executing indefinitely without a proper termination condition. In simple terms, it is a loop that never ends unless the program is forcibly terminated or interrupted.
Understanding infinite loops is crucial in C programming, as improperly managed loops can lead to high CPU usage, system crashes, and unresponsive programs. However, when used correctly, infinite loops can be a powerful tool in real-time systems and embedded applications.
Infinite loops can be categorized into unintentional and intentional infinite loops.
