# 11.3.1 Functions for Writing to Files

C provides several functions for writing data to files:

+   * fprint(): Writes formatted data to a file using a format string and variable arguments.

int num = 10;
float price = 25.6;
fprintf(file, "%d %f\n", num, price);

+   * fputs(): Writes a string to a file. It takes a file pointer and a string as arguments.
fputs("Hello, World!\n", file);

+   * fwrite(): The fwrite() function writes a block of data to a file. It takes a pointer to the data, the size of element in the data block, the number of elements to write, and a file pointer as arguments.
