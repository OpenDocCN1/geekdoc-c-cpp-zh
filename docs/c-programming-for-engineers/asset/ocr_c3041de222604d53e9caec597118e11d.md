Floating-point numbers are stored in memory using the IEEE 754 floating-point
representation, which consists of a sign bit, an exponent, and a fraction (mantissa).
This format allows for a wide range of values but introduces approximation errors.

Common floating point literals are written with a decimal point (1.625) or in
scientific notation (6.022e23 meaning 6.022 × 10²³). To declare initialize
floating-point variables, you can use literals with decimal points or scientific
notation. Example:

```
float c = 2.99e+08; // speed of light
double pi = 3.14159265385973115976346854;
```

When working with floating-point numbers, it is crucial to be aware of rounding
errors and limited precision. In certain cases, they may not yield exact results and
lead to inaccuracies during calculations or comparisons. If high precision or exact
integer values are required, it is recommended to use integer data types instead. It's
portant to exercise caution when comparing floating-point numbers for equality or
performing calculations that demand high precision.
