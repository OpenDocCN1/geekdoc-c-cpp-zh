# 7.6. The switch Construct 103

In a statement, an expression is evaluated and compared to the values in each case. If a match is found, the corresponding code block runs. If no match is found, the default code block runs (if it's included).

To avoid running the next case accidentally, each case should end with a break statement. The default case is optional and provides a fallback action if no cases match.

Switch statements are especially helpful when there are many possible cases, as they keep the code clear and easy to manage.

Here's a comparison between switch and if-else ladders:

+   * Switch provides a clear, organized way to handle multiple cases, while if-else can get lengthy with more conditions.
* Switch directly compares an expression to case values, while if-else allows complex conditions.
* Switch works with integers, characters, or enums, while if-else can handle other types.
* Switch jumps to the matching case, while if-else evaluates each condition by one until a match is found or it reaches else.

In short, use switch for clear, specific comparisons and if-else for complex conditions. Choose based on what the program needs.
