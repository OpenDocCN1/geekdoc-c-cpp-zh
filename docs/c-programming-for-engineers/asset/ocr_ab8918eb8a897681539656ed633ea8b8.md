# 5.2.2 Multiplication and Division

Multiplication (*) is used to calculate the product of two numeric values. It finds application in scenarios such as scaling sensor readings, calculating areas, or determining proportional changes.

```
int length = 5;
int width = 8;
int area = length * width; // Area is 40
```

Division (/) divides the left operand by the right operand. It is used for tasks such as scaling, calculating averages, or determining rates.

```
int total = 100;
int count = 5;
int average = total / count; // Average is 20
```

The (%) operator in C is the modulus operator. It gives the remainder of a division operation between two numbers. For example, 5 % 2 gives '1' because 5 divided by 2 equals 2 with a remainder of 1. It's often used to check if a number is even or odd, find multiples, or cycle through values in algorithms.

```
int number = 73;
int tens = number / 10; // Tens is 7
int ones = number % 10; // Ones is 3
```
