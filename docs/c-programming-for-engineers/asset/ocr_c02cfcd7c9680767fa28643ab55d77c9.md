# Table 10.3: Commonly Used string.h functions

| Function | Description |
| --- | --- |
| strlen() | Calculates the length of a null-terminated string (excluding the null character). |
| strcpy() | Copies the contents of the source string to the destination string. |
| strncpy() | Copies at most n characters from the source string to the destination string. |
| strcat() | Appends (concatenates) the contents of the source string to the destination string. |
| strncat() | Appends at most n characters from the source string to the destination string. |
| strcmp() | Compares two strings and returns an integer indicating their relationship (lexicographically). |
| strncmp() | Compares at most n characters of two strings and returns an integer indicating their relationship. |
| strstr() | Searches for the first occurrence of a substring in a string and returns a pointer to that substring. |
| strchr() | Finds the first occurrence of the character c in the string and returns a pointer to it. |
| strrchr() | Finds the last occurrence of the character c in the string and returns a pointer to it. |
