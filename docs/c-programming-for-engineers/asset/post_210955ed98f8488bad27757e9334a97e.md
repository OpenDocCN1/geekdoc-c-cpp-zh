In this template:

- return_type: This indicates what the function returns after completing its task.
- function_name: It denotes the name of the function.
- parameter_list: These are the inputs required by the function to execute its task, represented as param1, param2, ..., paramn. It’s optional, meaning functions can have no parameters.
- Function body: This section contains the actual code that performs the assigned task to the function. This is also called function definition.

- The empty parenthesis mean it doesn't have any parameters
- The function body is written inside {}

## 10.2.3 Function Parameters

Functions can have parameters, also known as arguments. Here's an example:
#include <stdio.h>

```c
void printMessage(int count) {
    for (i=0; i<count; i++) {
        printf("Hello World\n");
    }
}
int main() {
    int n = 7;
    printMessage(n);
    return 0;
}
```

Here, count is a parameter for the printMessage function. When calling printMessage from main, a value specifying how many times the message should be printed is passed as an argument.

Here's a simple example of calling a function with two parameters:
#include <stdio.h>

```c
// Function declaration with two parameters
void addNumbers(int a, int b) {
    int sum = a + b;
    printf("The sum of %d and %d is: %d\n", a, b, sum);
}

int main() {
    int num1 = 5;
    int num2 = 7;
    // Calling the function with two arguments
    addNumbers(num1, num2);
    return 0;
}
```

In this example, the addNumbers function takes two parameters a and b, which are added together to calculate the sum. Inside the main function, we declare two variables num1 and num2 and initialize them with the values 5 and 7 respectively. Then, we call the addNumbers function with num1 and num2 as arguments. The function adds these two numbers and prints the sum.

In summary, parameters provide functions with input from the calling code in the form of arguments. This example illustrates a clear separation of concern, with main preparing the inputs and addNumbers focusing only on the summation task.

## 10.2.4 The return Statement

So far, we have used void in the function declaration, indicating that these functions do not return any value. However, functions can also return values to the calling code, providing a means to convey results or computed values. To do this, we need to specify the return type in the function declaration.

The return type declared in the function prototype indicates the type of value that the function will return. Consider the following example:

```c
int addNumbers(int a, int b) {
    return (a + b);
}
```

In this function, int is used instead of void as the return type. This means that the addNumbers function returns an integer value. The code `return (a + b);` sends the sum of the two parameters back to the calling code.

It's important to note that the return statement also signifies the end of the function. Any code written after the return statement will not be executed.

In the following example, the main function calls the addNumbers function with values 5 and 7. The function receives the two parameters, a and b, and returns their sum. Then the main function prints the result.

```c
#include <stdio.h>

// Function to add two numbers and return the result
int addNumbers(int a, int b) {
    return a + b;
}

int main() {
    int num1 = 5;
    int num2 = 7;

    // Call the add function and store the result in the sum variable
    int sum = addNumbers(num1, num2);
}
```
