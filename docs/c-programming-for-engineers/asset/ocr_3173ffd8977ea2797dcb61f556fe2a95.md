# Hardware Layer

Figure 1.5 illustrates the typical hardware layout of a general-purpose computer. The hardware layer is the foundational layer of a computer system and consists of several major components, each serving a specific function:

+   **Processor**: The processor, often referred to as the Central Processing Unit (CPU), is the brain of the computer. It performs instructions and calculations. The CPU fetches instructions from memory, decodes them, and executes the necessary operations.
**Memory**: Memory provides storage for data and instructions. It is divided into two main types: primary memory and secondary memory (storage devices such as hard drives or solid-state drives). Primary memory holds data and instructions that the CPU needs to access quickly, while secondary memory stores data for long-term storage even when power is off.
**Input/Output (I/O) Devices**: I/O devices enable communication and interaction between the computer and the external world. These devices include keyboards, mice, monitors, printers, network adapters, and storage devices. Input devices allow users to provide data or commands to the computer, while output devices display or produce results generated by the computer.

# Firmware Layer

The firmware layer sits between the hardware and operating system layers. It consists of software permanently stored in nonvolatile memory, providing essential instructions to control hardware and communicate with the operating system. The firmware handles low-level functions such as power management, input/output control, and system initialization. On PCs, this is typically called the BIOS (Basic Input/Output System).

# Operating System (OS) Layer

The operating system layer provides a higher level of control over system resources, enabling the management of processes, memory, and devices. It acts as a platform for executing software. General-purpose computers and sophisticated embedded systems typically run an operating system, whereas bare metal systems do.

# Application Layer

The application layer is the top layer where user-level software resides. It includes various applications, such as word processors, spreadsheets, web browsers, email systems, and other software chosen by the user. These applications run on top of the operating system, utilizing its services and resources.
