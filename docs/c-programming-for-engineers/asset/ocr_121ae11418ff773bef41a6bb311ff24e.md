# Bitwise AND Operator

# 5.3.1 Bitwise AND operator

The bitwise AND operator (&) performs a bitwise AND operation between two integer types, bit by bit. It returns 1 if both corresponding bits are 1, otherwise 0.

Example: Clear bits 4-7 of the data byte. To clear bits, put 0 in the desired bit positions in the mask and 1 in the unchanged bits.

| unsigned char data = 0xaa; | data | 1 0 1 0 1 0 1 0 | 0xaa |
| unsigned char mask = 0xef; | mask | 0 0 0 0 1 1 1 1 | 0xf |
| unsigned char result; | | | |
| result = a & b; | result | 0 0 0 0 1 0 1 0 | 0xa0 |

# 5.3.2 Bitwise OR operator

The bitwise OR operator (|) performs a bitwise OR operation between two integers, bit by bit. It returns 1 if either of the corresponding bits is 1, otherwise 0.

Example: Set bits 0-3 of the data byte. To set bits, put 1 in the desired bit positions in the mask and 0 in the unchanged bits.

| unsigned char data = 0xaa; | data | 1 0 1 0 1 0 1 0 | 0xaa |
| unsigned char mask = 0xef; | mask | 0 0 0 0 1 1 1 1 | 0xf |
| unsigned char result; | | | |
| result = a | b; | result | 1 0 1 0 1 1 1 1 | 0xaf |

# 5.3.3 Bitwise XOR Operator

The bitwise exclusive-OR (XOR) operator (^) performs a bitwise XOR operation between two integers, bit by bit. It returns 1 if the corresponding bits are different, otherwise 0.

Example: Flip bits 0-3 of the data byte. To flip bits, put 1 in the desired bit positions in the mask and 0 in the unchanged bits.

| unsigned char data = 0xaa; | data | 1 0 1 0 1 0 1 0 | 0xaa |
| unsigned char mask = 0xef; | mask | 0 0 0 0 1 1 1 1 | 0xf |
| unsigned char result; | | | |
| result = a ^ b; | result | 1 0 1 0 0 1 0 1 | 0xa5 |

# 5.3.4 Bitwise Complement Operator

The bitwise complement operator (-) inverts or flips the bits of an integer, changing each 1 to 0 and each 0 to 1. It is also called the bitwise NOT operator.

Example: Flip all bits of the data byte.

| unsigned char data = 0xaa; | data | 1 0 1 0 1 0 1 0 | 0xaa |
| unsigned char result; | | | |
| result = -data; | result | 0 1 0 1 0 1 0 1 | 0x55 |
