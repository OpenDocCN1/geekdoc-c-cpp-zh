# 10.6 Recursive Functions

Recursive functions in C involve a function calling itself during execution. This section covers the principles of recursion, its advantages, and considerations for implementing recursive functions.

# 10.6.1 Principles of Recursion

Recursive functions break down complex problems into smaller subproblems. Each recursive call addresses a subset of the original problem until a base case is reached, preventing infinite recursion. Here's an example to calculate the factorial of a number:

```
// Recursive function to calculate factorial
int factorial(int n) {
  // Base case
  if (n <= 1) {
    return 1;
  }
  // Recursive call
  return n * factorial(n - 1);
}
```

In this snippet, the factorial() function calls itself with a reduced argument (n-1) until reaching the base case (n <= 1), preventing further recursion.
For comparison, here's the equivalent factorial function implemented iteratively:

```
// Iterative function to calculate factorial
int iterativeFactorial(int n) {
  int result = 1;
  for (int i = 2; i <= n; i++) {
    result *= i;
  }
  return result;
}
```

The iterativeFactorial() function calculates the factorial using a loop, providing an alternative approach to the recursive version.

# 10.6.2 Advantages of Recursion

Recursive solutions frequently result in more concise and readable code, particularly for problems that have inherent recursive structures. They mimic the natural flow of certain algorithms and can simplify difficult tasks. However, unnecessary recursion should be avoided, as this can have an impact on performance and excessive stack memory usage.
