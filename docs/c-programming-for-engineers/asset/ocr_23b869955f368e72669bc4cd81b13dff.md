Categories of Embedded Computers

Embedded computers can be categorized by how they are programmed.

# System on Chip (SoC)

+   - A system on chip (SoC) integrates a complete computer system onto a single chip, encompassing a microprocessor and various peripherals and interfaces, but typically excludes main memory.
- SoC-based single-board computers like the Raspberry Pi allow users to run a variety of applications, similar to traditional computers, making them suitable for educational and hobbyist purposes.
- These systems can run GPOS like Linux, which provides a general-purpose computing environment, or real-time operating systems (RTOS) designed to respond quickly to input changes.
