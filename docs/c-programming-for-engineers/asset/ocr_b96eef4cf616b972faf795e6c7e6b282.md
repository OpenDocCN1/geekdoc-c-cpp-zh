# 8.5 Nested Loops

Nested loops are placed inside other loops. This allows for more complex iterations by using an inner loop to repeatedly execute a set of statements for each iteration of the outer loop.

Nested loops are useful for:

+   - Iterating over multi-dimensional data structures like matrices or nested arrays.
- Solving problems involving hierarchical structures.
- Creating combinations or permutations.
- Carrying out operations requiring multiple levels of iteration.

The outer loop controls the overall iteration, while the inner loop executes a set of statements for each iteration of the outer loop. This technique is commonly used when working with hierarchical or multi-dimensional data structures, as it allows for nested or sequential iterations over the data.

# Snippet: Printing a Multiplication Table

The following example demonstrates a nested loop to print a multiplication table:

```
#include <stdio.h>

int main() {
    for (int i = 1; i <= 5; ++i) {
        for (int j = 1; j <= 5; ++j) {
            printf("%d * %d = %d\n", i, j, i * j);
        }
    }
    return 0;
}
```

In this example, the outer loop iterates over the values from 1 to 5 for the multiplicand i, while the inner loop iterates over the same range of values for the multiplier j. This results in a complete multiplication table from 1 to 5.
