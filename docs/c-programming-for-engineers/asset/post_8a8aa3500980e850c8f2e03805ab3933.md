
## 5.5.3 Integer Quirks

Integer division in C differs from floating-point division and can lead to truncation issues. Consider the following example:

```c
int a = 5 / 2;           // Result is 2
float b = 5 / 2;       // Result is 2.0
float c = (float)5 / 2; // Result is 2.5
float d = 5 / 2;       // Result is 2.5
float e = 5 / 2;       // Result is 2.5
```

In the code above, the expression 5 / 2 performs division, resulting in assigning the result to an integer variable like a quotient of 2. This may be expected when assigning the result to a float variable like b. However, it can be surprising when assigning the result...

Truncation occurs when the result of a division is cast to an integer, discarding any decimal part. In the example, the fractional part of the division is discarded because the result is assigned to an integer variable. To obtain a floating-point result, at least one of the operands should be a floating-point type.

To ensure floating-point division, at least one of the operands must be a float. This can be achieved by adding a period at the end of either number or by explicitly casting one of the operands to (float).

It is important to be aware of this behavior to avoid unexpected results when performing divisions in C, especially when working with mixed data types.

## 5.5.4 Overflow and Underflow

Overflow and underflow occur in arithmetic operations where the result exceeds the maximum or minimum value that the data type can represent.

When an underflow occurs, the value becomes too large for the variable to hold, while an underflow occurs when the value becomes too small. In such cases, the variable's value "wraps around" within the range of possible values.

Below is a simplified example demonstrating overflow and underflow in C:

```c
#include <stdio.h>

int main() {
    char c;

    // Overflow example
    c = 127;
    printf("Value before increment: %d\n", c);
    c++;
    printf("Value after increment: %d\n", c);

    // Underflow example
    c = -128;
    printf("Value before decrement: %d\n", c);
    c--;
}
```

### 5.6.1 Integer Data Types and Operations

In embedded systems programming, integer data types are essential, but they come with some challenges. Some of the issues with C integer data types in embedded systems include:

- Limited Memory and Processing Power: Embedded systems often have limited memory and processing power, restricting the size and precision of integer values.
- Hardware-specific Limitations: Some embedded systems have specific limitations, as limited support for supposedly common operations like multiplication and division. For instance, some microcontrollers may not have a hardware multiplier, making multiplication slower.
- Integer Promotions and Conversions: C integer promotions and conversions can sometimes behave unexpectedly in embedded systems. For example, assigning a signed integer to an unsigned integer may result in unexpected values.
