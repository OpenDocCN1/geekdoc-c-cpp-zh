# Chapter 12. pointers

It is good practice to check for a NULL pointer before accessing any pointer variable to avoid run-time errors and crashes.

# Check if the pointer is NULL

Program to avoid segmentation fault while accessing the value of pointer using NULL pointer

```
// C NULL pointer demonstration
#include <stdio.h>

int main() {
    // declaring null pointer
    int *ptr = NULL;

    // dereferencing only if the pointer have any value
    if (ptr == NULL) {
        printf("Pointer does not point to anything");
    } else {
        printf("Value pointed to by pointer: %d", *ptr);
    }
    return 0;
}
```

The C standard specifies the NULL pointer, providing a mechanism for a programmer to determine whether a given pointer is legitimate.

# Dereferencing a NULL Pointer

What's going to happen if we use the following C code:

```
// Trying to dereferencing a null pointer
#include<stdio.h>
int main() {
    int *ptr = NULL;

    printf("%d",*ptr);
    return 0;
}
```

On some machines, the above code compiles successfully, but crashes when run. The program does not behave consistently across all machines. Try the code at your own risk!
