# 6.5 Simple String Output

The puts() function in C is a simple way to print a string and add a newline. The puts() function accepts only a single argument: a pointer to a null-terminated string. It automatically adds a newline (\n) to the end of the string, saving you the trouble of doing it.

```
#include <stdio.h>

int main() {
    const char str[] = "Hello World";

    puts(str);

    return 0;
}
```

In this example, puts() prints "Hello World" followed by a newline. It returns 12, the number of characters printed.

This function is a handy option when you simply need to print a string without any extra formatting or manipulation. In fact, formatting is not possible. Its built-in newline handling makes it preferable to printf() in some cases.

# 6.6 Character Input and Output

The functions getchar() and putchar() allow simple input and output of single characters from standard input and output streams.

The getchar() function retrieves a single character from the standard input stream and returns its ASCII value as an integer. It can be used in a loop to read multiple characters until a predefined condition is met. For example, the code snippet below reads characters from the user until the Enter key is pressed:

```
int ch;
while ((ch = getchar()) != '\n') {
    // Process the character
}
```

In contrast, the putchar() function sends a single character to the standard output stream (usually the console). It accepts an integer argument that specifies the ASCII value of the character to be displayed. For example, the code snippet displays the uppercase alphabet on the console:

```
int ch;
for (ch = 'A'; ch <= 'Z'; ch++) {
    putchar(ch);
}
```
