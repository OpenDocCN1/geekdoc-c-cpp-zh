# 9.3.2 Accessing Array Elements

To access an element in a two-dimensional array, you use two indices. The first index specifies the row, and the second index specifies the column.
For example, to access the element in the second row and third column of the matrix, you can use the following code:

```
int element = matrix[1][2];
```

This code assigns the value of the element in the second row and third column of the array matrix to the variable element.
To modify an element in a multi-dimensional array, you can simply assign a new value to it using the same index syntax. For example, to change the value of the element in the second row and third column of the array matrix to 10, you can use the following code:

```
matrix[1][2] = 10;
```

This code changes the value of the element in the second row and third column of the array matrix to 10.
You can traverse the two-dimensional array using nested loops, such as in the following code, which sums all the elements in a 3x4 matrix:

```
int sum = 0;
for (int i = 0; i < 3; i++) {
  for (int j = 0; j < 4; j++) {
    sum += matrix[i][j];
  }
}
```

Using multidimensional arrays, you can also find the maximum element, transpose the matrix, and perform matrix multiplication.
