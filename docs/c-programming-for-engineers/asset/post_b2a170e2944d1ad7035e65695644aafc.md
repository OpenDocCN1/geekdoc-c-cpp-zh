## 13.6.2 Queues

A queue is a linear data structure that follows the First-In-First-Out (FIFO) principle, where the first element entered into the queue is the first one to be removed. Queues have two main operations: enqueue (inserting an element) and dequeue (removing an element). There are two main types of queues:

- Linear Queue: Uses an array to store elements, with a fixed size.
- Dynamic Queue: Uses a linked list to store elements, allowing for dynamic memory allocation and de-allocation.

A queue has a front and rear, with an enqueue adding elements to the rear and a dequeue removing elements from the front.
Common operations on a queue include:

- Enqueue: Insert an element into the queue.
- Dequeue: Remove an element from the queue.
- Front: Get the first element in the queue.
- Rear: Get the rear element in the queue.
- IsEmpty: Check if the queue is empty.
- IsFull: Check if the queue is full.

Queues are useful in various applications, such as operating systems, computer networks, and simulation algorithms, where the order of processing elements is important.

## 13.6. Data Structures

Example: Here's a simple implementation of a linked-list based queue in C:

```c
#include <stdio.h>
#include <stdlib.h>

// Define a node structure for the linked list
struct Node {
    int data;
    struct Node* next;
};

// Define the queue structure
struct Queue {
    struct Node* front;
    struct Node* rear;
};

// Create a new queue
struct Queue* createQueue() {
    struct Queue* queue = (struct Queue*)malloc(sizeof(struct Queue));
    queue->front = queue->rear = NULL;
    return queue;
}

// Check if the queue is empty
int isEmpty(struct Queue* queue) {
    return queue->front == NULL;
}

// Enqueue (add an element) to the queue
void enqueue(struct Queue* queue, int data) {
    // Create a new node
    struct Node* new_node = (struct Node*)malloc(sizeof(struct Node));
    new_node->data = data;
    new_node->next = NULL;

    // If empty, set both front and rear to the new node
    if (isEmpty(queue)) {
        queue->front = queue->rear = new_node;
    } else {
        // Add the new node at the rear and update the rear pointer
        queue->rear->next = new_node;
        queue->rear = new_node;
    }
}

// Dequeue (remove an element) from the queue
int dequeue(struct Queue* queue) {
    if (isEmpty(queue)) {
        printf("Queue is empty\n");
        return -1; // Or any other indicator for error handling
    }

    // Store the data to be returned and the node to be deleted
    int data = queue->front->data;
    struct Node* temp = queue->front;

    // Update the front pointer
    queue->front = queue->front->next;

    // If after dequeue, the queue becomes empty, set both front and rear
    if (queue->front == NULL) {
        queue->rear = NULL;
    }

    // Free the memory of the deleted node
    free(temp);

    return data;
}

// Print all nodes in the queue
void printQueue(struct Queue* queue) {
    if (isEmpty(queue)) {
        printf("Queue is empty\n");
        return;
    }
    struct Node* temp = queue->front;
    while (temp != NULL) {
        printf("%d ", temp->data);
        temp = temp->next;
    }
    printf("\n");
}

int main() {
    struct Queue* queue = createQueue();

    enqueue(queue, 10);
    enqueue(queue, 20);
    enqueue(queue, 30);

    printf("Queue elements: ");
    printQueue(queue);

    printf("Dequeued: %d\n", dequeue(queue));
    printf("Dequeued: %d\n", dequeue(queue));

    printf("Queue elements: ");
    printQueue(queue);

    return 0;
}
```

This code creates an empty queue, inserts three nodes with integer data, and inserts the data in each node. Then two nodes are dequeued and the final state of the queue is printed again.

- We define structures for Node and Queue.
- The createQueue() allocates memory for a new Queue and initializes its front and rear pointers to NULL.
- The isEmpty() function checks if the front pointer is NULL, indicating an empty queue.
- The enqueue() function creates a new node, adds the data element, and inserts it at the end of the queue by updating the rear pointer.
- The dequeue() function checks for an empty queue and returns an error if so. Otherwise, it stores the data to be deleted, updates the front pointer, and frees the memory of the deleted node.
- The main() function demonstrates creating a queue, enqueuing elements, and dequeuing them.

## 13.6.3 Stacks

A stack is a linear data structure adhering to the Last-In-First-Out(LIFO) principle, meaning that the last element added to the stack is the first one to be removed. - Push: Insert an element onto the top of the stack.
- Pop: Remove an element from the top of the stack.
- Top: Access the element at the top of the stack without removing it.
- IsEmpty: Check if the stack contains no elements.
- IsFull: Check if the stack has reached its maximum capacity (for fixed size).
