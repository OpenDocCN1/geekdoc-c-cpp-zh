# 4.1.9 Punctuation and Special Characters

In C programming, punctuation and special characters are used to represent various elements of the programming language. While the terms are often used interchangeably, they do have subtle differences in meaning and usage.

Punctuation characters are symbols used to organize and structure the code, similar to their usage in written English. Examples of punctuation characters include:

| Character | Name | Description |
| --- | --- | --- |
| ; | Semicolon | Terminates a statement |
| , | Comma sign | Separates elements in a list |
| : | Colon | Introduces a statement label |
| ? | Question mark | Used in ternary conditional operator |
| . | Period | Used to access structure members |
| -> | Arrow | Used to access structure members |

Special characters, however, are non-alphanumeric characters that serve specific purposes in the code. They are used for tasks such as performing arithmetic operations, logical operations, and controlling program flow. Some characters have multiple uses. Examples of special characters include:

| Character | Name | Description |
| --- | --- | --- |
| // | Double slash | Begins a comment |
| # | Pound sign | Begins a preprocessor directive |
| ' | Single quotation marks | Enclose a single character |
| " | Double quotation marks | Enclose a string of characters |
| & | Ampersand | Take the address of a variable; AND operation |
| * | Asterisk | Dereference a pointer; declare pointer variable; multiplication operation |

The main difference between punctuation and special characters lies in their usage and context. Punctuation characters are primarily used to structure and organize the code, while special characters encompass a broader range of symbols and are often used for specific tasks or to represent specific data. In C programming, these two types of characters are often used together.

# 4.2 Number Systems

Numbers can be represented in different bases, which determine valid digits. The most common bases are as follows:

| Number System | Base | Valid Digits |
| --- | --- | --- |
| Decimal | 10 | 0 to 9 |
| Binary | 2 | 0 and 1 |
| Octal | 8 | 0 to 7 |
| Hexadecimal | 16 | 0 to 9 and A to F (or a to f) |
