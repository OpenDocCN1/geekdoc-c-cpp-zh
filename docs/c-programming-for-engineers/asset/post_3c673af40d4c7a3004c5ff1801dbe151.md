
## 10.7.3 Counting Set Bits in Binary Representation

The bitcount() function takes an integer as input and returns the count of ones in its binary representation. The algorithm:

- 1. Initialize variable count to 0.
- 2. In a loop, check if the least significant bit (LSB) of n is 0 or 1 using a bitwise AND with 1.
- 3. If the LSB is 1, increment the count.
- 4. Right-shift n by 1 to move the next bit into the least significant position.
- 5. Repeat steps 2-4 until n becomes 0, indicating that all bits have been counted.
- 6. Return the final count.

```c
int bitcount(int n) {
    count = 0;
    while(n != 0) {
        if (n&1 != 0) // test last bit
            count++;
        n = n >> 1;
    }
    return count;
}
```

Note that the loop may take up to 32 iterations for a 32-bit integer, but it can terminate sooner if all 1 bits have been shifted out.
Instead of incrementing count when the LSB is 1, you can also use count = count + (n&1); but the compiler would probably generate the same machine code.

## 10.7.4 An Improved Approach: Brian Kernighhan's Algorithm

The popcount function takes an integer n as input and returns the count of ones in its binary representation. This uses a technique called Brian Kernighhan's algorithm to count the number of set bits (ones) in the number. The name "popcount" is short for population count, referring to the number of set bits (bits with a value of 1) in a binary representation of a number. The algorithm:

- 1. Initialize variable count to 0.
- 2. In a loop, perform a bitwise AND operation between n and n-1 to clear the least significant bit (set it to 0) and store the result back in n.
- 3. With each iteration, the least significant bit is cleared, and count is incremented.
- 4. The loop continues until n becomes 0, indicating that all bits have been cleared.
- 5. Return the final count.

```c
int popcount(int n) {
    count = 0;
    while(n != 0) {
        n = n&&(n-1); // clear last bit
        count++;
    }
    return count;
}
```

This algorithm is more efficient because it only iterates through the set bits in the binary representation of the number, rather than iterating through all the bits. For example, if the binary representation of n is 1000000000001, it takes only two iterations to finish counting, compared to 16 iterations using the previous algorithm. This shows how the choice of an algorithm greatly impacts the performance of a program.

## 10.7.5 Checking if a Number is a Power of Two

The PowerOfTwo() function takes an integer n as input and returns 1 if the number is a power of two and 0 otherwise. It uses the following conditions to determine whether a number is a power of two:

- The number should not be zero (n != 0).
- The number should have only one bit set to 1. This condition is checked by performing a bitwise AND operation between n and n-1. If the result is 0, it means that n has only one bit set to 1.
- The most significant bit of the number should be 0. This condition is checked by shifting the number 31 bits to the right (n >> 31) and comparing it to 0.

The main program prompts the user to enter an integer, reads the input using scanf("%d"), and then calls the isPowerOfTwo() function to determine if the number is a power of two or not. The appropriate message is printed based on the return value of isPowerOfTwo.

```c
int isPowerOfTwo(int n) {
    return n != 0 && (n & (n-1)) == 0 && (n >> 31) == 0;
}
void main(void) {
    int x;

    printf("enter an integer:\n");
    scanf("%d", &x);
    if(isPowerOfTwo(x)) {
        printf("%d is a power of two\n", x);
    } else {
        printf("%d is not a power of two\n", x);
    }
}
```
