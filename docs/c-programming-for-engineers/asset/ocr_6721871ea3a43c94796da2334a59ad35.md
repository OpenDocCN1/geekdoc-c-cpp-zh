# 9.2. Arrays Operations

The bits array is defined as a constant array with 16 elements, where each element represents the count of set bits for the corresponding decimal number from 0 to 15. By performing a bitwise AND operation bits[nibble & 0xF] to extract the least significant 4 bits of nibble, the code uses the result as an index to access the corresponding count of set bits in the lookup table. For instance, bits[10 & 0xF] corresponds to the number of set bits in the binary representation of 10, which is 2.

These examples illustrate the efficiency and convenience of lookup tables to retrieve information based on specific inputs. They offer a direct approach that minimizes the need for complex calculations.

# 9.2.2 Traversing Arrays

Traversing an array involves visiting each element in sequence. Loops are commonly used for this purpose, ensuring every array element is accessible and can be processed as needed.

To compute the sum of the elements in an array, you can use a loop to iterate the array and add each element to a running total. For example, the following code computes the sum of the elements in an array of integers called arr:

```
int sum = 0;
for(i=0;i<5;i++)
sum += arr[i];
```

```
int arr[5] = {1,2,3,4,5};
```

Once we know how to traverse an array, we can perform various operations to analyze and manipulate the array effectively. Some of these operations include:

+   - **Reducing**: Combining all elements of an array into a single value using an operation such as sum or product.
- **Min, Max, Median, Average, Standard Deviation and Variance**: Many statistical operations can be performed on an array
- **Counting**: Count the number of times each unique element appears in the array.
- **Filtering**: Selecting elements from an array that satisfy a specific condition.
- **Mapping**: Applying a transformation or function to each element of an array.
- **Merging**: Combine two or more arrays into a single array.
- **Deduplicating**: Remove any duplicate elements from the array.
- **Reversing**: Reversing the order of elements in an array.
- **Searching**: Finding a specific element in an array.
- **Sorting**: Arranging the elements of an array in a specific order.
