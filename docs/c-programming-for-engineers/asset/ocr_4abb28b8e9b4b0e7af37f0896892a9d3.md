# String Concatenation Function

The function strcat() concatenates (appends) one string to the end of another.

```
#include <stdio.h>
#include <string.h>

int main() {
    char str1[] = "Hello, ";
    char str2[] = "World!";
    strcat(str1, str2);
    printf("Concatenated string: %s\n", str1);
    return 0;
}
```

# String Comparison Function

The strcmp() function compares two strings and returns an integer indicating its lexicographical relation.

These functions simplify string processing tasks in C programs. More details can be found at https://en.wikibooks.org/wiki/C_Programming/string.h.
