# 3.3.2 Other Features of the Online Compiler

The OneCompiler is simple to use but some options are available.

![](bbox=[0.158, 0.163, 0.963, 0.187])

Figure 3.5: Options on the OneCompiler

As a suggestion, it is a good idea to regularly download your source code while creating your programs to prevent any loss of your work. To do this, click on the three dots, which is the second last item. Then, select "Download" from the list of options that appear. This option not only allows you to download your code but also provides you with the ability to customize some editor settings and clear the output pane.

![](bbox=[0.413, 0.366, 0.663, 0.442])

Figure 3.6: Downloading from OneCompiler

A less apparent option is the ability to rename the source file. Navigate to the label "Main.c" and proceed to rename it to "main.c". It is advisable to use all-lowercase letters for a source file. The compiler likely defaults the filename to "Main.c" to encourage renaming it to a more appropriate format.

![](bbox=[0.283, 0.597, 0.853, 0.683])

Figure 3.7: Renaming a file

The last item on the IDE is the option to go full-screen via the rightmost button. When it comes to sharing your work, rather than downloading the source file and sharing it via email or social media, you can simply share the URL. In most browsers, press Ctrl-L (or Command-L on macOS), followed by Ctrl-C. This action will copy your URL like https://onecompiler.com/c/423mkcfnk to your clipboard.
