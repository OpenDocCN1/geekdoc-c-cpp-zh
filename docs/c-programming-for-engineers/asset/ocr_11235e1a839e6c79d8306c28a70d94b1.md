# Loop Control Statements

```
int i;
// Loop to print numbers from 1 to 10
for (i = 1; i <= 10; i++) {
    if (i == 5) {
        break; // Exit loop when i equals 5
    }
    printf("%d\n", i);
}
```

In this example, the loop ends as soon as the value of i becomes 5, skipping the rest of the iterations.

# 8.6.2 The continue Statement

The continue statement (see Fig. 8.5) is used to skip the remaining code inside a loop for the current iteration and proceed to the next iteration. This statement is useful for skipping specific iterations based on certain conditions.

```

    statement/s
    if (test expression) {
        continue;
```
