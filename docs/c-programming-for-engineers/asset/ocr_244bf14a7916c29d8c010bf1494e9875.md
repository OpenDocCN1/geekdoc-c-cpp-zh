# 13.4 Enums: Improving Program Readability

Enums provide a cleaner and more readable way to define symbolic constants in C. They are commonly used to represent related sets of values like error codes or state values. Enumeratio make code more self-documenting by associating human-readable names with integer values.

To define an enum, list the constant names within curly braces. Each constant automatically gets a unique integer value starting from 0:

```
enum Day { SUNDAY, MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY };
```

Enums can be used like normal types in C. You can assign enum constants to variables and use them in expressions. However, when printing an enum variable, it will display the corresponding integer value rather than the name.

```
enum Day today = WEDNESDAY;
printf("Today is %d", today);
```

This prints the integer value (e.g. 2) Instead of the name.
enums also be defined with explicit integer values instead of auto-incrementing from 0. For example: enum Color RED=1, GREEN=2, BLUE=4. Additionally, the underlying type of enums defaults to int, but you can specify other types like char, int, long or long to accommodate wider or narrower range values.
