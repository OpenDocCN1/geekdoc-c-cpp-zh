# 10.5. Passing Arrays to Functions

Sentinels can be useful when the size of the array is not explicitly known or working with dynamic data series. However, it is important to ensure that the sentinel value does not appear as a valid data value within the array.

# 10.5.4 Processing Strings

In C, strings are represented as arrays of characters, terminated by a null character ('\0'). By using the null character as a sentinel value, functions can iterate over the characters of the string until they encounter the null character.

Here is an example of using sentinel values with strings:

```
#include <stdio.h>

void toUpperCase(char str[]) {
 int i = 0;
 while (str[i] != '\0') { // Keep going until sentinel is found
  if (str[i] >= 'a' && str[i] <= 'z') {
    str[i] -= 32; // Convert lowercase letter to uppercase
  }
  i++;
 }
}

int main() {
 char message[] = "Hello, World!";
printf("String before modification: %s\n", message);

 // Modify the string to uppercase
toUpperCase(message);

printf("String after modification: %s\n", message);
 return 0;
}
```

In this example, the toUpperCase function takes a character array str as a parameter. The function iterates over the characters of the string, converting each lowercase letter to uppercase until it encounters the null character ('\0').

Using sentinel values is a widely accepted method for processing strings in C because it allows functions to handle strings of varying lengths without explicitly passing the size of the string. The null character serves as a natural terminator for string processing operations.
