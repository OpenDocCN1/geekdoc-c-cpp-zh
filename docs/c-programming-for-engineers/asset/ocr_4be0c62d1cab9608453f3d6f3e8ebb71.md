# 11.3.2 Writing Different Data Types to Files

When writing data to a file, handle different data types correctly:

+   - int: Use %d or %i
- float: Use %f or %e
- double: Use %lf or %le
- char: Use %c
- string: Use %s (beware of buffer overflows)

Here's a simple Code snippet that demonstrates writing different data types to a file:

```
#include <stdio.h>

int main() {
    FILE *file = fopen("data.txt", "w");
    if (file == NULL) {
        printf("Error opening file!\n");
        return 1;
    }

    int i = 123;
    float f = 456.789f;
    double d = 789.0123456789;
    char c = 'Z';
    char s[] = "Hello, World!";

    fprintf(file, "int: %d\n",, i);
    fprintf(file, "float: %f\n", f);
    fprintf(file, "double: %lf\n", d);
    fprintf(file, "char: %c\n", c);
    fprintf(file, "string: %s\n", s);

    fclose(file);

    return 0;
}
```
