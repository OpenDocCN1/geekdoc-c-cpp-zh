# 10.8.3 Standard Library

The stdlib.h library in C provides utility functions for memory management, strings, numbers, and file I/O operations. They include:

+   - String conversion functions for converting strings to integer and floating-point types and vice versa.
- Random number generation functions for generating pseudo-random integers.
- Sorting and searching functions for efficient data manipulation, sorting, and searching of large arrays.
- Memory management functions for handling dynamic memory allocation.
- Process control functions for managing external processes and program termination.

These functions facilitate the development of efficient, flexible, and secure C programs.

Table 10.4: Commonly used functions in stdlib.h

| Function | Description |
|---|---|
| malloc() | Allocates a block of memory dynamically on the heap |
| free() | Deallocates previously allocated memory |
| realloc() | Resizes the previously allocated block of memory |
| calloc() | Allocates memory for an array and initializes it with zero |
| exit() | Terminates the program execution immediately with a specified exit status |
| abort() | Aborts the program execution by raising a signal |
| atoi() | Converts a string to an integer |
| atof() | Converts a string to a floating-point number |
| rand() | Generates a pseudo-random number |
| srand() | Seeds the random number generator used by rand() |

More details can be found at https://en.wikibooks.org/wiki/Programming/stdlib.h.
