Explanation
In this example, you have created a function named square that takes an integer (x) as input and returns its square. The main function then calls this custom function to calculate and display the square of the user-entered number.
The program also uses two library functions, scanf and printf. Library functions are highly optimized functions written by the people who wrote the compiler. We should try to use available functions whenever possible, rather than creating our own.
By understanding and implementing functions, you're taking a significant step towards writing modular and maintainable C programs.
