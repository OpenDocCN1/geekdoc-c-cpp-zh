# 4.2. Number Systems

In a base system, the position of each digit determines its value. The base is usually indicated with a subscript after the number. Examples:

+   - Decimal: $92_{10}$ (normally written as just 92)
- Binary: $1011100_2$
- Octal: $134_8$
- Hexadecimal: $5C_{16}$

The binary number is necessary in digital computers due to its binary (base 2) nature, where each bit can be either (1) or off (0). Computers group bits into bytes, and a byte comprises 8 bits, numbered from 0 to 7.

One byte has 8 bits.

Table 4.2 demonstrates how an 8-bit unsigned binary value corresponds to a binary value. Each bit, starting from bit 0, doubles in value as you move left. To form a binary value, you turn on the corresponding bits based on the desired decimal value.

Table 4.2: The interpretation of an unsigned byte containing the pattern 00100001$_2$

| Bit 7 | Bit 6 | Bit 5 | Bit 4 | Bit 3 | Bit 2 | Bit 1 | Bit 0 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Power of 2 | $2^7$ | $2^6$ | $2^5$ | $2^4$ | $2^3$ | $2^2$ | $2^1$ | $2^0$ |
| Decimal value | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
| Binary number | 0 | 0 | 1 | 0 | 0 | 0 | 0 | 1 |
| Decimal value | | | 32 | | | | | |

Example 1: Decimal Value 33
For the value 33, you turn on bits 5 and 0. Because $2^5 = 32$ and $2^0 = 1$, adding these bits yields the bit pattern 00100001$_2$ equal to $32_{10}$. This value can also be written as $21_{16}$ or 418.

In signed numbers, the most significant bit carries a negative weight, commonly known as the sign bit. When this bit is 0, the number is positive, and when it is 1, the number is negative.

Table 4.3: The interpretation of an signed byte containing the pattern 10100001$_2$

| Bit 7 | Bit 6 | Bit 5 | Bit 4 | Bit 3 | Bit 2 | Bit 1 | Bit 0 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Power of 2 | $-2^7$ | $2^6$ | $2^5$ | $2^4$ | $2^3$ | $2^2$ | $2^1$ | $2^0$ |
| Decimal value | -128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
| Binary number | 1 | 0 | 1 | 0 | 0 | 0 | 0 | 1 |
| Decimal value | -128 | | 32 | | | | | |
