# # C on Arduino

This topic covers C programming for Arduino, using the Arduino implementation. It is intended for users with basic knowledge of C. The chapter focuses on the differences between regular C and Arduino C, and explores hardware control without going deep into hardware interfacing.

# ## 15.1 What You Need

To get the most out of this chapter, it is recommended to have a Maker Uno board, which simplifies the learning process for beginners by eliminating the need for extra connections. The Maker Uno board, offered by Cytron Technologies, is an Arduino-compatible board built around the ATmega328P microcontroller.

Unlike the Arduino Uno, which has only one LED, the Maker Uno board features 12 built-in LEDs, a buzzer, and a pushbutton, reducing the need for hardware connections in basic embedded programming experiments. The Maker Uno board has a different input power source and uses a CH340G USB-to-serial chip. The hardware components of the Maker Uno board are displayed in Fig. 15.1.
