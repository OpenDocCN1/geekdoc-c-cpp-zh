# 11.5.1 Manipulating Text Files using C

Manipulating text files in C involves more than just reading and writing. You can also modify, filter, and clean data in text files. For example, you can remove unwanted characters, replace text, or perform calculations based on the data. Here is an example of removing all occurrences of the character 'x' from a text file:

```
FILE in = fopen("input.txt", "r");
FILE out = fopen("output.txt", "w");
```

```
while (fgets(line, sizeof(line), in)) {
    fputs(str_replace("x", "", line), out);
}


```

```
fclose(in);
fclose(out);
```

# 11.5.2 Reading and Writing CSV Files

Comma-separated values (CSV) files are commonly used to store tabular data, including IoT sensor data. Here is an example of a CSV file containing sensor data:

```
Timestamp, Sensor ID, Temperature (C), Humidity (%)
2024-03-10 08:00:00, 001, 25.5, 60
2024-03-10 08:05:00, 002, 24.8, 58
2024-03-10 08:10:00, 003, 26.2, 63
2024-03-10 08:15:00, 001, 26.8, 62
```

In this CSV file:

+   - Each line represents a record containing sensor data.
- Fields within each record are separated by commas.
- The first line typically contains headers, indicating the meaning of each field (timestamp, sensor ID, temperature, humidity).
- Subsequent lines contain sensor data corresponding to those headers.
