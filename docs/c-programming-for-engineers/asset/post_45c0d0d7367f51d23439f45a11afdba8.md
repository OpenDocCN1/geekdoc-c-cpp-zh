## Local Variables

Local variables are limited to a specific function and can only be used within the block of code where they are defined. For example, a local variable declared in the setup function will not be visible or usable in the loop function.

Variables declared within a function or block are considered local to that function or block. Anything enclosed within curly braces {} forms a block. Local variables exist only within the block in which they are declared.

This means they cannot be accessed or outside that block's scope.

```
// Wrong way to use local variables
#include <stdio.h>

void display() {
    int age = 19; // This variable is local to the display function
}

int main() {
    // Compilation error
    printf("Age is: %d\n", age);

    return 0;
}
```

In this code:

- age is a local variable declared within the display function and is accessible only within display.
- Trying to access localVar from main will result in a compilation error because it is out of scope.

## 10.3. Variable Scope and Storage Classes

The following code fixes this error:

```
#include <stdio.h>

void display() {
    int age = 19; // This variable is local to the display function
    printf("Age is %d\n", age);
}

int main() {
    display();
    return 0;
}
```

Variables have scope within any block of code, not just within functions. In the following program, the variable i only exists within the loop. Trying to access i outside the loop will cause a compilation error.

```
#include <stdio.h>

int main() {
    int sum = 0;

    for (int i=0; i<5; i++) {
        sum += i;
    }
    printf("i = %d, sum = %d\n", i, sum); // Compilation error

    return 0;
}
```

In summary, local variables can have block or function scope, meaning that they exist and can be used only within the blocks or functions where they are declared. Attempting to access them outside of these blocks would lead to compilation errors.

## Global Variables

Global variables, as the name suggests, can be accessed from any part of the program. They are declared outside of all functions. They are available throughout the program’s execution.

Excessive use of global variables is generally discouraged as it can lead to name conflicts, tight coupling between code sections, and difficulty maintaining and testing the program.

```
// Global variable declaration
int globalVar = 20;
```

```
void myFunction() {
    printf("%d\n", globalVar);
}
```

```
int main() {
  display();
  globalVar = 23; // changing the value of global variable from main
  → function
  display();
  return 0;
}
```

In this program, the variable globalVar is declared outside of any function, making it accessible from anywhere in the program.

Local variables promote modularity and information hiding, making code easier to understand and maintain. Global variables should be used sparingly as they can introduce dependencies and make your code less flexible and reusable.

In summary, variable scope and storage classes are separate but closely related concepts in C programming. The variable scope determines a variable's visibility, while the storage classes determine its lifetime and behavior across functions and blocks. Understanding these concepts is essential for writing efficient, maintainable, and portable C code.

## Static Variables

Static variables are a special type of variable that combine aspects of local and global variables. Like local variables, they exist throughout the program's execution, not just within a single function. Unlike global variables, they are declared within a function, limiting their visibility to that function (local scope).

Static variables are defined with the 'static' keyword in a function. Static variables can be used to implement counters, maintain historical data, and store persistent values within a function. Here's a simple C code demonstrating static variables:

```
#include <stdio.h>

void incrementCounter() {
  static int counter = 0; // Static variable initialization
  counter++;              // Increment count in each function
  printf("Counter: %d\n", counter);
}

int main() {
  // Calling the function to increment and print the counter
  incrementCounter();
  incrementCounter();
```

## 10.4. Type Conversion During Function Calls

```
incrementCounter();
```

In this example, we define a function named incrementCounter that declares and defines a static local variable counter. The first time the function is called, the counter variable is initialized to 0, and its value is incremented and printed. When the function is called again, the counter retains its previous value, as it is a static variable, and its value is incremented and printed again. The output of this program will be:

```
Counter: 1
Counter: 2
Counter: 3
```

This demonstrates that counter retains its value between function calls to incrementCounter.

In C, type conversion can occur during function calls when the argument types do not exactly match the parameter types of the function. Here are a few examples:

```
void print_value(double value) {
    printf("Value: %f\n", value);
}
```

```
int num = 10;

// Implicit conversion from int to double before passing
print_value(num);
```

In this example, the print_value function expects a double argument, but an int value (num) is passed. This leads to implicit conversion of num to a double being passed to the function.

```
void print_value(int value) {
    printf("Value: %d\n", value);
}
```

```
double another_num = 10.5;

// Implicit conversion from double to int before passing
print_value(another_num);
```

In this example, the print_value function expects an int argument, but a double value (another_num) is passed. This leads to implicit conversion of another_num to an int (likely truncating to 10) before being passed to the function.

```
int calculate_ratio(int a, int b) {
    // Implicit conversion of result back to int
    return (float)a / b;
}
```

```
int ratio = calculate_ratio(10, 3);

printf("Ratio: %d\n", ratio); // Output: 3
```

In this example, the calculate_ratio performs division using float operands. However, the result is implicitly converted to an int, the function has an int return type, discarding the fractional part. As a result, the output is 3 because the fractional part is discarded.

These examples demonstrate how C handles implicit conversion during function calls and returns. Implicit conversions may result in loss of precision or truncation of fractional components. It is important to understand implicit conversions to avoid unexpected behavior. If desired, explicit casts can be used to perform manual type conversions instead of relying on implicit conversions.

## 10.5 Passing Arrays to Functions

In C, arrays are often used to store and manipulate collections of data. When an array is passed to a function, the function only receives a pointer to the first element, the size. There are multiple ways to indicate the size of the array such as passing the size as a separate parameter, using sentinel values, or employing the first element as a size indicator.

### 10.5.1 Passing Array Size as a Separate Parameter

The most common approach to passing the size of an array to a function is to use a separate parameter. This explicitly specifies the size of the array and allows the function to iterate over the elements based on the provided size.

Here is an example of passing the array size as a separate parameter:

```
#include <stdio.h>

int sum(int arr[], int size) {
    int sum = 0;
    for (int i = 0; i < size; i++) {
        sum += arr[i];
    }
    return sum;
}
```

```
int main() {
    int numbers[] = {1, 2, 3, 4, 5};
    int size = sizeof(numbers) / sizeof(numbers[0]);
}
```
