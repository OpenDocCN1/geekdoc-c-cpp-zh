```c
#include <stdio.h>
int main() {
    int n;
    const char *day[] = {"Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"};

    do {
        printf("Enter a day from 1 to 7: ");
        scanf("%d", &n);

        if (n < 1 || n > 7) {
            printf("Invalid input. Please try again.\n");
        }
    } while (n < 1 || n > 7);

    puts(day[n-1]);

    return 0;
}
```

The declaration `const char *day[] = {"Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"};` creates an array named day, where each element is a pointer to a string. For example, day[0] points to "Sunday", day[1] points to "Monday", and so on. This allows for convenient access to the names of the days using array indexing.

## 12.5 Pointers and Functions

### 1.1 Pointer to Functions

Pointers can point to functions, allowing functions to be passed as arguments to other functions, stored in data structures, or dynamically assigned at runtime. This enables powerful techniques such as callbacks and implementing polymorphism. For example:

```c
void sayHello() {
    printf("Hello, World!\n");
}

int main() {
    // Pointer to function that takes no arguments and returns void
    void (*ptr)() = sayHello; // Note syntax

    // Assigning the address of sayHello to ptr
    ptr(); // Calling the function through the pointer

    return 0;
}
```
This will output: Hello, World!

### 1.2 Exchanging Data with Functions

Pointers allow functions to receive and manipulate data types other than simple scalars.

#### Pass-by-value

The basic method of function receiving data in C is pass-by-value. In pass-by-value, a copy of the argument's value is created and passed to the function. Changes made inside the function do not affect the original variable. This method is used for simple types like integers. For example, consider the incorrect swapping of values without modifying the originals:

```c
void swap(int x, int y) { // Incorrect swap function
    int temp = x;
    x = y;
    y = temp;
}

int main() {
    int a = 5, b = 10;
    swap(a, b); // Swapping doesn't work here
    printf("a: %d, b: %d\n", a, b); // Output: 5, 10 (unchanged)
}
```

#### Pass-by-Reference

Pointers allow passing data by reference, enabling functions to modify the original data. In pass-by-reference, the memory address of the original variable is passed to the function. Changes made inside the function affect the original variable. This method is used for large data structures, such as arrays, to avoid copying. For example, consider the correct swapping of values using pointers:

```c
void swap(int *x, int *y) { // Correct swap function, uses pointers
    int temp = *x;
    *x = *y;
    *y = temp;
}

int main() {
    int a = 5, b = 10;
    swap(&a, &b); // Passing addresses to swap function
    printf("a: %d, b: %d\n", a, b); // Output: 10, 5 (swapped)
}
```

When deciding between pass-by-value and pass-by-reference, consider the data type and desired function behavior. Pass-by-value is suitable for simple data types and is safer as it avoids unintended modifications to the original data. In contrast, pass-by-reference is preferable for large data structures to improve efficiency and modify the original data. It avoids copying large amounts of data. Additionally, with pass-by-reference, pointers can be used to indirectly "return" multiple values since C functions can only return a single value.

See Table 12.1 for a summary of the differences between pass-by-value and pass-by-reference.

#### Table 12.1: Comparison of pass-by-value vs pass-by-reference

| Feature | Pass-by-value | Pass-by-reference |
|---|---|---|
| What is passed? | Copy of the value | Memory address of the original variable |
| Changes inside the function: | Only the copy | The original variable |
| Advantages: | Simple data types, efficiency safer, simpler | Complex data types, modifying original variable more efficient for large data structures |

## 12.6 Dynamic Memory Allocation

Dynamic memory allocation allows programs to allocate memory at runtime, opposed to static memory allocation which occurs at compile-time. This is done through pointer usage and memory management functions. The main functions for dynamic allocation are malloc() and free().

- `malloc()`: Requests a chunk of memory from the free storage area called the heap. The number of bytes to allocate is taken as an argument. Returns a void pointer to the starting address of the allocated block.
- `free()`: Returns a previously allocated (deallocates) block back to the free storage for reuse. It takes a pointer to the memory block.

For example:

```c
// Allocate memory for 5 integers
int *ptr = malloc(5 * sizeof(int));

// Use the memory
ptr[0] = 1;

// Free the memory
free(ptr);
```

Here, the malloc() function allocates space for 5 integers. We can then access the memory through ptr. This allows memory needs to be flexible at runtime instead of being fixed at compile time.

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#define ARRAY_SIZE 10

int main() {
    int *array;

    // Dynamically allocate memory for the array
    array = (int*)malloc(ARRAY_SIZE * sizeof(int));

    if (array == NULL) {
        printf("Memory allocation failed!\n");
        return 1;
    }

    // Set the seed for random number generation
    srand(time(NULL));

    // Populate the array with random numbers
    for (int i = 0; i < ARRAY_SIZE; i++) {
        array[i] = rand() % 101; // Generate a random number 0..100
    }

    // Print the elements of the array
    printf("Array elements: ");
    for (int i = 0; i < ARRAY_SIZE; i++) {
        printf("%d ", array[i]);
    }
    printf("\n");

    // Free the dynamically allocated memory
    free(array);

    return 0;
}
```

## 12.7 Null Pointers

Null pointers are those pointers that do not point to any memory location. They can be created by assigning a NULL value to the pointer. A pointer of any type can be assigned the NULL value.

```c
type * pointer_name = NULL;
```

The following are some most common uses of the NULL pointer:

- Uninitialized pointers: The NULL pointer is commonly used to initialize pointers before they are assigned a valid address. This helps prevent wild pointers.
- Function arguments: NULL can be passed as an argument to functions that expect a pointer, especially when there is no meaningful value to pass.
- Dynamic memory allocation: When using function malloc(), NULL is returned if the memory allocation fails.
- Data structures: A NULL pointer indicates the end of data structures such as trees and linked lists.
- Improving readability: Using NULL pointers can improve the readability of code by making it clear when a pointer is not intended to point to a valid memory location.
