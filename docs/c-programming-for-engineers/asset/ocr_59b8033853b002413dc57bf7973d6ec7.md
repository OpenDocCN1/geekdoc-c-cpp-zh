Snippet: Bubble Sort

This snippet implements the bubble sort algorithm, which is a simple sorting algorithm that works by repeatedly iterating through a list of elements and swapping adjacent elements if they are in the wrong order

```
int arr[5] = {3,5,2,1,4};
for(int i=0; i<5; i++) {
for(int j=i+1; j<5; j++) {
  if(arr[i] > arr[j]) {
    temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
  }
}
}
```
