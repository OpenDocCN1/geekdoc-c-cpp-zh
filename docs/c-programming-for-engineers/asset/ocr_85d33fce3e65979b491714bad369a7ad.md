# 12.8.4 Wild Pointers

Wild pointers occur when a pointer is used without initialization. Unlike null pointers which point to a known address (address 0), wild pointers contain random values pointing anywhere in memory.

Dereferencing wild pointers leads to undefined behavior since their targets are unpredictable. Programs may crash or behave unexpectedly. Wild pointers arise from declaring pointers without assignment:

```
#include <stdio.h>

int main() {
    int *ptr; // Wild pointer, not initialized
    int x;

    // Print the value pointed to by ptr (wild pointer)
    printf("Value at wild pointer: %d\n", *ptr);

    // Assign the address of 'x' to the wild pointer
    ptr = &x;

    // Print the value pointed to by ptr (now pointing to 'x')
    printf("Value at 'x': %d\n", *ptr);

    return 0;
}
```

In the beginning of this example, ptr is declared but not initialized, resulting in a wild pointer. When attempting to access the value pointed to by ptr (*ptr) assigning it a valid address, the program behaves unexpectedly because ptr contains a random memory address. Only by assigning the address of variable x to ptr does it become a valid pointer.

To prevent wild pointers, always initialize pointers before use and ensure targets are set. They are a common bug source, so avoid unintended or uninitialized pointer values.
