## Problem Solving

Problem-solving is a fundamental skill in programming. It involves analyzing a given problem, devising a solution, and implementing it in code. Effective problem-solving skills are essential for programmers to create efficient and reliable software applications.

### 2.1 Introduction

Problem solving is the process of finding a solution to a problem. In programming, a problem is typically a task that needs to be accomplished, such as calculating the average of a set of numbers or generating a random password.

### 2.1.1 What is a Problem?

A problem exists when there is a difference between the current situation and desired goal or optimal outcome. For our purposes, a programming problem refers to any task or obstacle that can potentially be addressed through algorithmic solutions and computer programming. Problems can range from personal challenges to complex engineering and scientific computing needs.

Problem-solving skills are essential for programmers for several reasons:

- They enable programmers to create efficient and reliable software applications.
- They help programmers think critically and creatively.
- They allow programmers to work independently and as part of a team.
- They prepare programmers for the challenges of the real world.

Problem-solving skills are crucial for programmers as they develop efficient software, promote critical and creative thinking, support collaborative work, and tackle real-world challenges.

### 2.1.2 A Good Problem Statement

Clearly defining the problem is an essential first step. A well-articulated problem statement should describe:

- The desired objective or intended result of solving the problem
- Any relevant context, assumptions, or constraints
- Specific inputs required to address the problem
- Expected format and computation of the desired outputs
- Any applicable standards, regulations, or best practices

With a good problem statement in hand, programmers understand precisely what is needed to make progress towards a functioning solution. Ambiguous or incomplete problem descriptions can significantly hamper the problem-solving process.

### 2.2 The Problem Solving Process

Fig. 2.1 gives an overview of the most essential steps in problem solving. The problem-solving process typically involves the following steps:

- **Define the Problem**: Clearly understand the problem statement, identify requirements, and determine expected output.
- **Analyze the Problem**: Break down the problem into smaller subproblems, consider alternative solutions, and choose the most appropriate one.
- **Develop an Algorithm**: Design a step-by-step solution using pseudocode or flowcharts.
- **Implement the Solution**: Translate the algorithm into a program using chosen programming language.
- **Test and Debug the Program**: Test the program with various test cases and fix any errors.
- **Evaluate the Solution**: Check if the program solves the original problem, analyze efficiency, and identify areas for improvement.
- **Document the Program**: Write clear documentation explaining the purpose and usage of the program.

### 2.2.1 Define the Problem

The first step in problem-solving is to fully comprehend the problem statement. This includes understanding the input requirements and the desired output. For instance, if we aim to assist a child in calculating square areas, further inquiry might uncover that the child needs a program prompting her to identify the side length of a square, with the program outputting the calculated area.

### 2.2.2 Analyzing the Problem Statement

After defining the problem, it is important to analyze it further to ensure clarity and determine general requirements. This includes the following:

- **Identifying Input Requirements**: Determine the data needed to solve the problem, whether it comes from the user, a file, or a database.
- **Defining Expected Output**: Specify the solution data that the program should produce.

#### Example

Consider the following problem statement:

```
Write a program that calculates the average of three numbers.
```

The input requirements for this problem are the set of numbers. The expected output is the average of the numbers. There are no constraints or limitations specified in the problem statement.

Once we have understood the problem, we can move on to the next step of the problem-solving process: designing an algorithm.

### 2.2.3 Algorithm Design

An algorithm is a set of instructions that, when precisely followed, will solve a particular problem or perform a particular task. Algorithmic thinking involves breaking down problems into step-by-step instructions that a computer can follow to solve the problem.

There may be multiple algorithms to solve one problem, each with advantages and disadvantages. Programmers choose the best algorithm based on factors like efficiency.

Instructions are divided into three types:

- Input: supplying data to the computer.
- Process: manipulate data such as comparing input or performing complex math.
- Output: delivering the results from the computer.

The aim of algorithm design is to write clear, unambiguous steps that computers can easily follow. Choosing the right algorithm is key to making programs work well.

When creating an algorithm, it's important to think about the data the program will use. Data is anything that a computer program operates on. Data can be numbers, words, or any information the program needs, and it's all stored in the computer's memory.

Variables are named storage locations in memory that hold data. Each variable has a name and a data type, specifying the kind of data it can hold. For example, an integer variable stores whole numbers, while a floating-point variable stores numbers with decimals. Variables can only hold one value at a time and we have to give them a value before using them.

#### Example

Let us develop an algorithm for calculating the area of a triangle. The algorithm is the following:

```
Ask the user for the length
Store the first number in the variable length
Ask the user for the width
Store the first number in the variable width
Calculate the area as 0.5 x length x width
Store the area in the variable area
Print the value of the area
```

To verify the correctness of the algorithm, we can perform a dry run. This involves manually executing the instructions using sample data. It helps us identify any logic errors before writing the actual program. Make sure the algorithm is correct before starting the program implementation to avoid wasting time and effort with an incorrect approach.

### 2.2.4 Writing the Program

To develop a computer program from an algorithm, consider user interaction and output design. A program prompts users for input, calculates results, and displays outputs in a specific format.

An algorithm and a program differ in language and rules. Algorithms can be written in an informal language, but programs require adherence to specific programming language's syntax rules.

A high-level language program, like C, is called source code. Compilation transforms source code into an executable program, which is object code found in executable files.
