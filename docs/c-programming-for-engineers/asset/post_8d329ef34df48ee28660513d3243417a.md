# Repetition Logic

Loops are powerful tools that help you repeat tasks automatically, making them essential for efficient programming. This chapter will delve into the fundamental loop structures in C: while, do-while, and for.

## 8.1 Introduction

Loops, also called looping or iteration, allow you to execute a block of code multiple times. This is useful for repetitive tasks and simplifies your code.

Repetition is essential in programming for several reasons:

- * **Efficiency**: Loops automate repetitive tasks, freeing you from writing the code repeatedly.
- * **Flexibility**: Loops can handle changing conditions or data, making your code adaptable.
- * **Cleaner code**: Loops consolidate repeated instructions, improving readability and maintenance.

Loops generally fall into two categories based on when they check the loop condition:

- * **Pre-test Loops**: These loops check the condition before each iteration. If the condition is evaluated to true, the loop is executed. Otherwise, the loop terminates.
- * **Post-test Loops**: These loops execute the code block at least once and check the condition afterward. The loop continues to iterate as long as the condition remains true.

C provides three primary loop structures, each suited for different scenarios:

- * **The while loop (pre-test)**: This loop repeatedly executes a block of code as long as a specified condition is true. The condition is checked before each iteration.
- * **The do-while loop (post-test)**: This loop ensures that the code block executes at least once, and then checks a condition afterward. The loop continues as long as the condition is true.
- * **The for loop (pre-test)**: This loop is often used to iterate a specific number of times or to work with sequences. It combines initialization, condition checking, and increment/decrement steps into a single expression for concise control of the loop.

Choosing the appropriate loop type depends on the specific problem that you are trying to solve. By understanding pre-test and post-test behavior, you can effectively use these loop structures to write efficient C programs.

## 8.2 The while Loop

In C, the while loop is a control structure that repeats a block of code as long as a given condition is true. It's useful when the number of iterations is unknown, and the loop stops when the condition is no longer met.

### 8.2.1 Syntax and Structure

The syntax of the while loop in C is as follows:

```
while (condition) {
// Code to be repeated
// (update condition if needed)
}
```

The condition is a Boolean expression that determines whether the loop should continue to run. If the condition is true, the code block within the loop is executed. If the condition is false, the loop is terminated, and the program control moves to the statement following the loop. The flow chart for the while loop is shown in Fig. 8.1.

### 8.2.2 Examples

The following program uses a while loop to print the first 10 natural numbers:

```c
#include <stdio.h>

int main() {
int i = 1;
while (i <= 10) {
printf("%d\n", i);
i++;
}
return 0;
}
```

The loop continues as long as i is less than or equal to 10. In each iteration, it prints the value of i and increments i by 1. The loop stops when i is greater than 10.

# Snippet: Factorial of a number

```c
int n, i, fact = 1;

while (n > 0) {
    fact *= n;
    n--;
}
printf("%d", fact);
```

This loop calculates the factorial of a number n. The loop continues as long as n is greater than 0. Within each iteration, the current value of fact is multiplied by the current value of n, and the result is stored in fact. Then, n is decremented by 1. After the loop terminates, the calculated factorial value is printed. Note that n should be initialized to a specific value before the loop.

# Snippet: Greatest Common Denominator

The Greatest Common Denominator (GCD) is the largest positive integer that divides two or more numbers without leaving a remainder.

```c
int a = 12;
int b = 15;

while (a != b) {
    if (a > b)
        a -= b;
    else
        b -= a;
}
printf("The GCD of 12 and 15 is %d\n", a);
```

This snippet uses the Euclidean algorithm, which is a well-known method for computing the GCD of two integers. The basic idea is to repeatedly subtract the smaller number from the larger number until the smaller number is 0. The last non-zero remainder is the GCD.

A more efficient version uses modulo:

```c
int a = 12;
int b = 15;

while (a != b) {
    int temp = a;
    a = b % a;
    b = temp;
}
printf("The GCD of 12 and 15 is %d\n", b);
```

Both methods will output the correct.

## 8.3 The do-while Loop

The do-while loop is similar to the while loop, but with one key difference: it's a control structure that executes a block of code at least once before re-evaluating the condition. This is useful in situations where you need to ensure a particular action occurs regardless of the initial condition.

### 8.3.1 Syntax and Structure

The syntax of the do-while loop in C is as follows:

```
do {
  // Code to be repeated
} while (condition);
```

The condition is a Boolean expression that determines whether the loop should continue to run. If the condition is true, the code block is executed again. If the condition is false, the loop is terminated. The flow chart for the do-while loop is shown in Fig. 8.2.

### 8.3.2 Examples

The do-while loop is useful for input validation. For instance, you might want to prompt the user until they enter a positive number:

```c
#include <stdio.h>

int main() {
    int num;
    do {
        printf("Enter a positive number: ");
        scanf("%d", &num);
    } while (num <= 0);
    printf("You entered: %d\n", num);
    return 0;
}
```

In this example, the do-while loop will keep asking the user until they provide a valid number.

# Menu-driven Programs

In programs with menus, a do-while loop can be used to repeatedly display options and process the user's choice until they choose to quit.

```c
#include <stdio.h>

int main() {
    int choice;
    do {
        printf("Menu:\n");
        printf("1. Option 1\n");
        printf("2. Option 2\n");
        printf("3. Exit\n");
        printf("Enter your choice: ");
        scanf("%d", &choice);

        switch (choice) {
            case 1:
                printf("You selected Option 1.\n");
                break;
            case 2:
                printf("You selected Option 2.\n");
                break;
            case 3:
                printf("Exiting the program.\n");
                break;
            default:
                printf("Invalid choice. Please try again.\n");
                break;
        }
    } while (choice != 3);

    return 0;
}
```

## 8.4 The Loop

In C, the for loop is a versatile and compact control structure that can be used to iterate over a range of values or execute a block of code multiple times. It condenses the initialization, condition checking, and iteration steps into a single line, making it ideal for looping tasks with clearly defined start and end conditions.

### 8.4.1 Syntax and Structure

The syntax of the for loop in C is as follows:

```
for (initialization; condition; update) {
  // Code to be executed repeatedly
}
```

- The initialization step initializes loop control variables or performs any necessary setup before entering the loop.
- The condition is evaluated before each iteration. If it evaluates to true, the loop continues; otherwise, the loop terminates.
- The update step updates loop control variables or performs any necessary post-loop processing after each iteration.

### 8.4.2 Examples

Consider the following example that uses a for loop to print numbers from 1 to 5:

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 5; i++) {
        printf("%d\n", i);
    }
    return 0;
}
```
