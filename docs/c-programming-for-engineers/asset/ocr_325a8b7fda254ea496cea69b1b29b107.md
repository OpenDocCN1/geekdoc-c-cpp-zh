# 8.3.2 Examples

Input Validation

Common scenario where a do-while loop is useful for input validation. For instance, you might want to prompt the user to enter a number and continue asking until they provide a valid input:

```
#include <stdio.h>
```

```
int main() {
    int num;
    do {
        printf("Enter a positive number: % ");
        scanf("%d", &num);
    } while (num <= 0);
    printf("You entered: %d\n", num);
    return 0;
}
```

In this example, the do-while loop will keep asking the user to enter a number until they enter a positive number.This approach ensures that the program receives a valid input before proceeding with the rest of the logic. The do-while loop is well suited for this task because it guarantees that the input validation code is executed at least once, even if the initial input is invalid.

Using a do-while loop for input validation, you can create more robust and user-friendly applications that gracefully handle invalid inputs.
