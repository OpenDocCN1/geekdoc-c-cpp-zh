# 7.2.2 Compound Conditions

Logical operators, such as && (logical AND), || (logical OR), and ! (logical NOT), are used to create compound conditions by combining simpler conditions. Below are examples demonstrating the usage of logical operators in condition checks:

```
if ( a == 6) && ( b != 7 ) ... // Taken if a is 6 AND b is not 7
if ( a == 6) || ( b != 7 ) ... // Taken if a is 6 OR b is not 7
```

# 7.3 The if-else Construct

The if-else construct allows programmers to further conditionally control program flow based on Boolean expressions. It allows alternative code to be_executed if the original condition is false.

Often you will want to write code to run if a condition is true, but different code to handle the false case. This is where if-else comes in.
The basic syntax of an if-else statement is:

```
if (condition) {
// Code to execute is condition is true
}\else {
// Code to execute condition is false
}
```

If condition is true, code block 1 will execute.
If condition is false, the program will skip block 1 and instead execute block 2.
This provides a way to have distinct code paths depending on the truth value of the condition checked. For example, if a student's test score is 50 or more, they pass; otherwise, they fail. In C, this is written as:

```
#include <stdio.h>
```

```
int main() {
int grade;

// Prompt the user to enter their latest test grade
printf("Enter your latest test grade: ");
scanf("%d", &grade);

// Check if the grade is >= 50 {
if (grade >= 50) {
printf("Congratulations! You pass.\
");
} else {
printf("Sorry, you did not pass.\
");
}

return 0;
}
```
