Linked lists find applications in various domains such as database management, memory allocation, task scheduling, and file systems, where flexible storage and efficient insertion and deletion operations are necessary. There are two main types of linked lists:

+   1. Singly Linked Lists: Each node points to the next node.
2. Doubly Linked Lists: Each node points to both the next and previous nodes.

Singly linked lists are straightforward, with each node having one successor. Doubly linked lists have nodes that point to both the next and previous nodes, allowing for bidirectional traversal.
Common operations on a singly linked list include:

+   * Insert: Add a new node to the list.
* Delete: Remove a node from the list.
* Search: Find a node with a given value.
* Length: Get the number of nodes in the list.
* Display: Print the data in all the nodes.
* IsEmpty: Check if the list is empty.
* IsFull: Check if the list is full.
