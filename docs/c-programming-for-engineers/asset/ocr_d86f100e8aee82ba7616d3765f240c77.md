# 5.3.5 Bitwise Shift << >>

Bitwise shift operators (<< and >> shift the bits of an integer left or right by a specified number of positions. Fig. 5.2 shows how the operator works for single bit shifts. Shift left inserts 0 from the right. Shift right works differently on signed and unsigned numbers. A right shift inserts a 0 from the left on the unsigned data, but shifts in the sign bit (which could be 0 or 1) on signed data.

```
unsigned char data = 0x93;
unsigned char result;
result = data << 1;
```

```
unsigned char data = 0x93;
unsigned char result;
result = data >> 1;
```

```
char data = 0x93;
char result;
result = data >> 1;
```

Figure 5.2: Shift operations

Shifting a value to the left by n effectively multiplies the operand by 2ⁿ. For example, performing 8 << 1 has the same result as 8 × 2. Conversely, shifting the value to the right by one divides the operand by 8÷2. Hence, 8 >> 1 yields the same outcome. Here are some examples:

```
unsigned char a = 5; // binary: 00000101
unsigned char result1 = a << 2; // binary: 00100100 (20)
unsigned char result2 = a >> 1; // binary: 00000010 (2)
unsigned char b = 164; // binary: 10100100
unsigned char result3 = b << 2; // binary: 10010000 (144)
unsigned char result4 = b >> 1; // binary: 01010010 (82)
char c = 5; // binary: 00000101
char result5 = c << 2; // binary: 00100100 (20)
char result6 = c >> 1; // binary: 00000010 (2)
char d = -92; // binary: 10101100
char result7 = d << 2; // binary: 10001000 (-112)
char result8 = d >> 1; // binary: 11010110 (-46)
```

# 5.3.6 Applications of Bitwise and Shift Operators

Bitwise and shift operators are commonly used to optimize integer arithmetic. They have applications such as replacing multiplications by powers of 2 with shifts and optimizing multiplications by certain constants using a combination of shifts and additions. These optimizations significantly improve integer arithmetic performance, especially in resource-constrained environments such as embedded systems.
