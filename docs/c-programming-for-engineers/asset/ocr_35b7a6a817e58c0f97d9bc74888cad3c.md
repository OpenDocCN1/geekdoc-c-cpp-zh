# 10.2.3 Function Parameters

Functions can have parameters, also known as arguments. Here's an example:
#include <stdio.h>

```
void printMessage(int count) {
    for (i=0; i<count; i++) {
        printf("Hello World\n");
    }
}
int main() {
    int n = 7;
    printMessage(n);
    return 0;
}
```

Here, count is a parameter for the printMessage function. When calling printMessage from main, a value specifying how many times the message should be printed as an argument.
Here's a simple example of calling a function with two parameters:
#include <stdio.h>

```
// Function declaration with two parameters
void addNumbers(int a, int b) {
    int sum = a + b;
    printf("The sum of %d and %d is: %d\n", a, b, sum);
}

int main() {
    int num1 = 5;
    int num2 = 7;
    // Calling the function with two arguments
    addNumbers(num1, num2);
    return 0;
}
```

In this example, the addNumbers function takes two parameters a and b, which are added together to calculate the sum. Inside the main function, we declare two variables num1 and num2 and initialize them with the values 5 and 7 respectively. Then, we call the addNumbers function with num1 and num2 as arguments. The function adds these two numbers and prints the sum.
In summary, parameters provide functions with input from the calling code in the form of arguments. This example illustrates a clear separation of concern, with main preparing the inputs and addNumbers focusing only on the summation task.
