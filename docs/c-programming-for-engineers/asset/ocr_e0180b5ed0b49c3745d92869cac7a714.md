# 3.5. Functions and Modular Programming

```
scanf("%d", &num);

// Check if the number is even or odd
if (num % 2 == 0) {
    printf("%d is even.\n", num);
} else {
    printf("%d is odd.\n", num);
}

return 0;
```

Explanation

In this example, you declare a variable (num) to store an integer input by the user. The program uses the if-else statement to check if the entered number is even or odd. The %operator calculates the remainder when dividing by 2, allowing you to determine the parity of the number.
By completing this example, you can explore other decision-making structures that can make your C programs more interesting.
