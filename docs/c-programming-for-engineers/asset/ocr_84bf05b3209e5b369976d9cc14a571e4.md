# 13.3 Typedef: Simplifying Data Type Declarations

In C programming, typedef is a keyword that allows programmers to create aliases for existing data types. This simplifies the declaration of complex data types and enhances code readability. The main advantage of typedef is that it simplifies complex data type declarations and makes code more readable by providing meaningful names for data types. It also enhances code portability by abstracting away platform-specific data types.

The syntax for using typedef involves specifying the original data type followed by the new name or alias that you want to create for. For example:

```
typedef unsigned long int ULLI;
```

Here, ULLI is created as an alias for unsigned long int.
The typedef statement allows the user to rename a variable type (or define a new type).

```
typedef int weight; //Rename int to weight
weight w1, w2; //Declare w1 and w2 as int
```
