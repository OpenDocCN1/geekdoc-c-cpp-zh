
## 5.3 Bitwise Operators Operator

### 5.3.5 Bitwise Shift << >>

Bitwise shift operators (<< and >> shift the bits of an integer left or right by a specified number of positions. Fig. 5.2 shows how the operator works for single bit shifts. Shift left inserts 0 from the right. Shift right works differently on signed and unsigned numbers. A right shift inserts a 0 from the left on the unsigned data, but shifts in the sign bit (which could be 0 or 1) on signed data.

```
unsigned char data = 0x93;
unsigned char result;
result = data << 1;
```

```
unsigned char data = 0x93;
unsigned char result;
result = data >> 1;
```

```
char data = 0x93;
char result;
result = data >> 1;
```

Figure 5.2: Shift operations

Shifting a value to the left by n effectively multiplies the operand by 2ⁿ. For example, performing 8 << 1 has the same result as 8 × 2. Conversely, shifting the value to the right by one divides the operand by 8÷2. Hence, 8 >> 1 yields the same outcome. Here are some examples:

```
unsigned char a = 5; // binary: 00000101
unsigned char result1 = a << 2; // binary: 00100100 (20)
unsigned char result2 = a >> 1; // binary: 00000010 (2)
unsigned char b = 164; // binary: 10100100
unsigned char result3 = b << 2; // binary: 10010000 (144)
unsigned char result4 = b >> 1; // binary: 01010010 (82)
char c = 5; // binary: 00000101
char result5 = c << 2; // binary: 00100100 (20)
char result6 = c >> 1; // binary: 00000010 (2)
char d = -92; // binary: 10101100
char result7 = d << 2; // binary: 10001000 (-112)
char result8 = d >> 1; // binary: 11010110 (-46)
```

### 5.3.6 Applications of Bitwise and Shift Operators

Bitwise and shift operators are commonly used to optimize integer arithmetic. They have applications such as replacing multiplications by powers of 2 with shifts and optimizing multiplications by certain constants using a combination of shifts and additions. These optimizations significantly improve integer arithmetic performance, especially in resource-constrained environments such as embedded systems.

Example: Multiply a number by 5 using only shift and add operations.

```
unsigned char data = 5;
result = (data << 2) + data;
```

Example: Convert a two-digit packed BCD (Binary Coded Decimal) number in a byte to its binary equivalent. Fig. 5.3 shows the procedure.

```
unsigned char bcd = 0x93;
unsigned char tens, ones, bin;

ones = bcd & 0xf;
tens = (bcd & 0xf0) >> 4;
bin = tens * 10 + ones;
```

## 5.4 Type Conversion

As a program runs, there might be instances where data types need to be converted to perform operations between dissimilar types. This section explores type conversion and casting in C, fundamental concepts that ensure proper handling of data types.
Converting smaller data type into a larger one is called as type promotion. On the other hand, demotion means converting larger data type into a smaller one. Demotion must be done with care as it may cause data loss. Refer to Fig. 5.4 ranking of data types.

### 5.4.1 Automatic Type Conversion

Automatic type conversion, also known as coercion or implicit type conversion, occurs when operands of different types are involved in an operation. This conversion is handled by the compiler, which promotes or demotes one or more operands to a common type before performing the operation. The compiler follows specific rules to determine the resulting data type, typically promoting to a higher precision type when necessary. These rules include:

- 1. Data types like char, short, unsigned short are automatically promoted to int.
- 2. When operating on values of different data types, the lower one is promoted to the type of the higher one.
- 3. When using the assignment operator (=), the type of the expression on the right is converted to the type of the variable on the left.

![](img/33fb6b7acbb6df48a3c9564e97117da6_85_0.png)

For example, consider the following code snippet:

```
int num1 = 7;
float num2 = 2;
float result = num1 / num2;
```

In this example, num1 is automatically converted to a float before performing the division operation. This is because the data types of both operands in a division expression must be the same. Since num2 is a float, num1 is implicitly cast to a float to ensure correct data types.

Automatic type conversion attempts to maintain consistency and accuracy in calculations within C programs. However, it's important for programmers to be aware of these conversions to avoid unintentional.

### 5.4.2 Explicit Type Conversion

Explicit conversion, also known as casting, is a way to convert one type to another. The syntax for explicit casting is as follows:

(type) value

Explicit conversion is useful in situations where you want to specify the target data type. It allows to control how values are converted.

Consider the following code snippet:

```
int num1 = 5, num2 = 2;
float result = num1 / num2; // answer 2.000
float result = (float)num1 / num2; // answer 2.500
```

In this case, the decimal part is truncated during the explicit casting to an integer.
