# # 5.4 Type Conversion

As a program runs, there might be instances where data types need to be converted to perform operations between dissimilar types. This section explores type conversion and casting in C, fundamental concepts that ensure proper handling of data types.
Converting smaller data type into a larger one is called as type promotion. On the other hand, demotion means converting larger data type into a smaller one. Demotion must be done with care as it may cause data loss. Refer to Fig. 5.4 ranking of data types.

#  5.4.1 Automatic Type Conversion

Automatic type conversion, also known as coercion or implicit type conversion, occurs when operands of different types are involved in an operation. This conversion is handled by the compiler, which promotes or demotes one or more operands to a common type before performing the operation. The compiler follows specific rules to determine the resulting data type, typically promoting to a higher precision type when necessary. These rules include:

+   1. Data types like char, short, unsigned short are automatically promoted to int.
2. When operating on values of different data types, the lower one is promoted to the type of the higher one.
3. When using the assignment operator (=), the type of the expression on the right is converted to the type of the variable on the left.
