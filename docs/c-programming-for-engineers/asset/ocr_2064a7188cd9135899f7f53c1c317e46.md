# 10.7.1 Checking if a Number is Even

```
int isEven(int n) {
    return (n & 1) == 0;
}

void main(void) {
    int x;

    printf("enter an integer: ");
    scanf("%d", &x);
    printf("%d is %s\n", isEven(x) ? "even" : "odd");n
```

The isEven() function takes an integer as input and returns 1 if the number is even and 0. It uses the bitwise AND operator (&) with 2 to check the least significant bit of n. If the result is 0, it means the number is even because even numbers have their least significant bit set to 0.

The main program prompts the user to enter an integer, reads the input using scanf, and then calls the isEven function to determine if the number is even or odd. The appropriate message is printed based on the return value of isEven.

# 10.7.2 Printing Binary Representation

The printBinary() function takes an integer as input and prints its binary representation. It uses a loop to iterate over each bit of the number, starting from the most significant bit (MSB) to the least significant bit (LSB).

+   - It calculates the position of the MSB using the formula sizeof(int) * 8 - 1, which assumes that an int is represented using 4 bytes (32 bits).
- The loop iterates from the MSB to the LSB, shifting the bits of x to the right (x >> i) and performing a bitwise AND operation with 1 (& 1) to extract the least significant bit.
- It prints each bit in the specified order, the binary representation of the number is displayed.

```
void printBinary(int x) {
    int i;
    int msb = (sizeof(int) * 8) - 1; // 31 for a 4 byte int

    for(i = msb; i >= 0; i--) {
        printf("%d", (x>>i) & 1);
    }
}
```
