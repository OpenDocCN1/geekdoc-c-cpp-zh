# Random Number Generation and Sorting

Two function in stdlib.h could be useful for engineers are rand() and qsort().
The rand() function generates pseudo-random integers in C, useful for simulations, randomized algorithms, or creating unpredictable behaviors. It's common to use the random number generator srand() with a seed value based on the current time to ensure different sequences of random numbers each time the program runs.

The qsort is a C implementation of the popular and efficient sorting algorithm. It takes four arguments: a pointer to the array, the number of elements, the size of each element, and a comparison function defining the sorting order. The comparison function compares two elements and returns an integer indicating their relative order Below is an example code demonstrating the use of both function. Note the use of <time.h> to allow the use of the time() function.

```
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
```

```
#define ARRAY_SIZE 10
```

```
// Comparison function for qsort
int compare(const void *a, const void *b) {
return (*(int*)a - *(int*)b);
}
```
