# 6.3.1 Basic Syntax

The basic syntax of the printf function is:

```
scanf(format_string, arg1, arg2, ...);
```

where:

+   - format_string is a string that specifies the type of data expected for each variable, similar to placeholders in printf, Common examples include %d for integers, %f for floating-point numbers, and %s for strings.
- arg1, arg2, etc., are the variables where the read data will be stored. The number of variables must match the number of format specifiers in the format_string.

The arguments from the format string tell where to store the values. To store input for a variable, we write &a, which stands for "address of a". Remember, this applies only to scanf to specify the location of individual data items; is not needed for regular variable usage in other parts of the code. The & operator is also not needed for arrays and strings.

Here's an example of calculating the area of a square based on the length of a side:
#include <stdio.h>

```
int main() {
    int side, area;

    printf("Enter the length of a side: ");
    // Read the length of a side entered by the user
    scanf("%d", &side);

    // Calculate the area of the square
    area = side * side;

    // Print the calculated area
    printf("The area of the square with side %d is: %d\n", side, area);

    return 0;
}
```

In this example:

+   - We declare two variables: side to store the length of the side entered by the user, and area to store the calculated area.
- The printf statement prompts the user to enter the length of a side.
- The scanf function reads the integer entered by the user using the %d format specifier and stores it in the side variable.
- We calculate the area of the square using the formula side * side and store the result in the area variable.
- Finally, we print the calculated area along with the length of the side using printf.
