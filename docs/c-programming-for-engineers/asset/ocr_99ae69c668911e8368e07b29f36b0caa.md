Example: Convert a two-digit packed BCD (Binary Coded Decimal) number in a byte to its binary equivalent. Fig. 5.3 shows the procedure.

```
unsigned char bcd = 0x93;
unsigned char tens, ones, bin;

ones = bcd & 0xf;
tens = (bcd & 0xf0) >> 4;
bin = tens * 10 + ones;
```

Figure 5.3: BCD to binary conversion using masking, shift and add

You can further optimize the steps by replacing the multiplication by 10 with shifts and adds. However, the compiler will likely perform this optimization automatically.
For the sake of readability, it's better to leave the steps as separate expressions rather than combining them into one long expression. This makes the code easier to read and understand. Additionally, the compiler will optimize the code regardless of how it is written, so there will be no difference in the generated machine code.
