# 4.3. Data Types

We need to consider the maximum memory value we want to store. Smaller data types, like short int, require less memory but are not always faster. If we choose a type that is too small, we may not have enough space to store our data. If we choose a type that is too large, memory will be wasted.

The size of a computer often plays an important role in software performance. It defines the number of bits the computer can process in a single operation. Common word sizes include 8, 16, 32, and 64 bits. The int data type is typically (but not all the time!) chosen to match the computer's word size. So, in doubt, trust the basic int type.

To help determine the size of the data types on a specific computer, we can use the sizeof() function. It tells us how much memory each type uses and is useful when we work on a computer or system.

```
#include <stdio.h>
int main() {
    printf("Size of char = %d\n", sizeof(char));
    printf("Size of short = %d\n", sizeof(short));
    printf("Size of int = %d\n", sizeof(int));
    printf("Size of long = %d\n", sizeof(long));
    printf("Size of float = %d\n", sizeof(float));
    printf("Size of double = %d\n", sizeof(double));
    printf("Size of long double = %d\n", sizeof(long double));
    return 0;
}
```

When deciding between signed and unsigned data types, we should think about the kind of data we have. If our data can be positive or negative, such as temperature or scores, we can use the int type. But if our data is always nonnegative, such as counters or IDs starting at 0, we can use the unsigned int type.

# 4.3.2 Floating-Point Data Types

C provides floating-point data types to handle numbers with fractional parts. These are crucial for scientific calculations, financial applications, and graphics programming.

The main floating-point types in C are float and double. The float type is single-precision, occupying 32 bits (4 bytes) in memory and offering 6-7 decimal digits of precision. The range of values for a float is approximately from 1.17594351×¹⁻³⁸ to 3.402823466×¹³⁸.

On the other hand, the double type is double-precision, using 64 bits (8 bytes) and providing 15-16 decimal digits of precision. Its range is significantly larger than that of float, with the smallest positive value being 2.22507385807214×¹⁻³⁰⁸ and the largest around 1.797693134862317×¹³⁰⁸.
