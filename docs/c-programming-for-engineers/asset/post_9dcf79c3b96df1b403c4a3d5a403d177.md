Strings in C can be declared and initialized using character arrays. For example:

```c
char str1[10]; // Declaration of a character array
char str2[6] = "Hello"; // Declaration and initialization of a string
char str3[7] = {'H', 'e', 'l', 'l', 'o', '\0'}; // Same as above
```

When strings are initialized using string literals enclosed in double quotes (""), the compiler automatically adds the null character '\0' at the end of the string.

The following example shows the use of a string as a lookup table.

```c
#include <stdio.h>

int main() {
  int num;
  char lookup[] = "0123456789ABCDEF";
  char ascii;

  // enter a number 0-15
  do {
    scanf("%d", &num);
  } while(num>15);
  ascii = lookup[num]; // convert to ASCII
  // print the ASCII of hex
  printf("Hexadecimal number %X in ASCII is '%c (0x%X)\n", 
         num, ascii, ascii);

  return 0;
}
```

This code takes an input number between 0 and 15, converts it to its corresponding hexadecimal ASCII character using a string lookup table, and then prints the ASCII character and its hexadecimal equivalent.

## 9.4. Strings

### 9.4.1 String Input and Output

C provides several functions to input and output strings. The scanf() function can be used to read strings from the standard input, while the printf() function can be used to print strings to the standard output. Additionally, the gets() and puts() functions can also be used for string input and output, respectively.

Here are some code examples demonstrating string input and output:

In this example:

- The scanf() function is used to input a string from the standard input (stdin) and store it in the str array. Note that scanf() stops reading input after whitespace characters.
- The gets() function is used to input a string from stdin and store it in the str array. Unlike scanf(), gets() reads the entire line, including whitespace characters, and terminates the string with a null character.
- The printf() function is used to output the string stored in the str array.
- The puts() function is used to output the string stored in the str array, followed by a newline character.

## 9.5 Common Pitfalls

In this section, we discuss some common mistakes when working with strings:

- Using the wrong index: Accessing an index outside the bounds of an array can lead to undefined behavior.
- Forgetting the null terminator: Strings in C must end with '\0' to be correctly recognized.
- Incorrect buffer size: Allocating an array that is too small for the string can cause buffer overflows.
- Not checking for input length: Failing to validate user input can lead to program crashes.
