# 10.2.4 The return Statement

So far, we have used void in the function declaration, indicating that these functions do not return any value. However, functions can also return values to the calling code, providing a means to convey results or computed values. To do this, we need to specify the return type in the function declaration.

The return type declared in the function prototype indicates the type of value that the function will return. Consider the following example:

```
int addNumbers(int a, int b) {
    return (a + b);
}
```

In this function, int is used instead of void as the return type. This means that the addNumbers function returns an integer value. The code return (a + b); sends the sum of the two parameters back to the calling code.

It's important to note that the return statement also signifies the end of the function. Any code written after the return statement will not be executed.

In the following example, the main function calls the addNumbers function with values 5 and 7. The function receives the two parameters, a and b, and returns their sum. Then the main function prints the result.

```
#include <stdio.h>

// Function to add two numbers and return the result
int addNumbers(int a, int b) {
    return a + b;
}

int main() {
    int num1 = 5;
    int num2 = 7;

    // Call the add function and store the result in the sum variable
    int sum = addNumbers(num1, num2);
}
```
