# 8.3 The do-while Loop

The do-while loop in C is similar to the while loop, but with one key difference: the do-while loop ensures that the loop's body is executed at least once before checking the loop condition. This feature is useful in situations where you want to run the loop at least once, regardless of the initial condition.

# 8.3.1 Syntax and Structure

The syntax of the do-while loop in C is as follows:

```
do {
  // Code to be executed repeatedly
  // This block will execute at least once
} while (condition);
```

In a do-while loop, the code block within the curly braces is executed first, followed by the evaluation of the condition. If the condition is true, the loop continues to run, and the process is repeated. If the condition is false, the loop is terminated, and program control is transferred to the statement following the loop. The flow chart for the do-while loop is shown in Fig. 8.2.
