Another excellent low-cost option is the Blue Pill development board , featuring a compact form factor and based on the ARM Cortex-M3 processor (STM32F103C8T6). This board is ideal for embedded systems projects and aligns well with academic courses like Microprocessor at UTM, where STM32 microcontrollers are used.

For STM32 development, STM32CubeIDE (developed by STMicroelectronics) is the recommended integrated development environment (IDE). It provides built-in support for the STM32 HAL (Hardware Abstraction Layer), enabling higher-level hardware interaction without low-level assembly code. While Keil MDK-ARM remains a popular choice, STM32CubeIDE is the now IDE for STMicroelectronics devices due to its seamless integration and updates. Both tools use C/C++ programming, making them suitable for embedded development.

However, our focus in this chapter is Arduino C, and the Blue Pill can be programmed using the Arduino IDE with the STM32duino core. This makes it easy to use for beginners while still offering the flexibility of a more powerful microcontroller compared to traditional Arduino boards.
