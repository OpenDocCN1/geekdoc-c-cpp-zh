# Snippet: Number Plate Interpreter

```
char state;

printf("Enter first character of vehicle registration: ");
scanf("%c", &state);

switch(state) {
    case 'A': printf("Perak\n"); break;
    case 'B': printf("Selangor\n"); break;
    case 'C': printf("Pahang\n"); break;
    case 'D': printf("Kelantan\n"); break;
    case 'J': printf("Johor\n"); break;
    case 'R': printf("Perlis\n"); break;
    case 'W': // W and V both map to KL
    case 'V': printf("Kuala Lumpur\n"); break;
    default: printf("Invalid character\n");
}
```

# 7.7 Ternary Operator

The ternary operator, also called the conditional operator, is a concise way to write conditional expressions.
The syntax is:

```
condition ? value_if_true : value_if_false
```

The condition is evaluated first. If it's true, the expression returns value_if_true; otherwise, it returns value_if_false.
It's often used for simple assignments or expressions where an if statement would be too verbose.
