# 12.6 Dynamic Memory Allocation

Dynamic memory allocation allows programs to allocate memory at runtime, opposed to static memory allocation which occurs at compile-time. This is done through pointer usage and memory management functions. The main functions for dynamic allocation are malloc() and free().

+   - malloc(): Requests a chunk of unusable memory from the free storage area called the heap. The number of bytes to allocate is taken as an argument. Returns a void pointer to the starting address of the allocated block.
- free(): Returns a previously allocated (deallocates) block back to the free storage for reuse. It takes a pointer to the memory block.

For example:

```
// Allocate memory for 5 integers
int *ptr = malloc(5 * sizeof(int));
```

```
// Use the memory
ptr[0] = 1;
```

```
// Free the memory
free(ptr);
```

Here, the malloc() function allocates space for 5 integers and returns the starting address in ptr. We can then access the memory block through ptr using operators like []. The free() function releases the memory back to the system. This dynamic approach allows memory needs to be flexible at runtime instead of being fixed at compile time.

A longer example:

```
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#define ARRAY_SIZE 10
```

```
int main() {
    int *array;

    // Dynamically allocate memory for the array
    array = (int*)malloc(ARRAY_SIZE * sizeof(int));
```

```
if (array == NULL) {
    printf("Memory allocation failed!\n");
    return 1;
}
```
