return_type function_name (parameter_list) {
// function body
}

In this template:

+   - return_type: This indicates what the function returns after completing its task.
- function_name: It denotes the name of the function.
- parameter_list: These are the inputs required by the function to execute its task, represented as param1, param2, ..., paramn. It’s optional, meaning functions can have no parameters.
- Function body: This section contains the actual code that performs the assigned to the function. This is also called function definition.

Here’s an example:

```
void greet() {
  printf("Hello World");
}
```

In this example:

+   - The name of the function is greet ()
- The return type is void
- The empty parenthesis mean it doesn't have any parameters
- The function body is written inside {}

# 10.2.2 Calling a Function

In the above program, we have declared a function called greet(). To use the greet() function, we need to call it. Here is how the function is called:

```
int main() {
  greet(); // calling a function
}
```
