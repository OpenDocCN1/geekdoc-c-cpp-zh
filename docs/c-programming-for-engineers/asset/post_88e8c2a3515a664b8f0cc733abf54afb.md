## 4.4 Printing Value of Variables

Up to this, we've utilized printf primarily for fixed messages. The first parameter of printf is referred to as the format string. When printf encounters a format specifier in this string, it substitutes it with the corresponding argument from the argument list. In the example below:

```
int num = 5;
int square = num * num;
printf("The square of %d is %d\n", num, square);
```

When printf encounters the % format specifier, it expects an integer argument to replace it during execution. In this instance, num and square are integer variables holding the values 5 and 25 respectively. So, upon execution, printf substitutes the first %d with the value of num, and the second %d with the value of square, resulting in:

The square of 5 is 25

Other commonly used format specifiers include %f for floating-point numbers, %c for characters, %s for strings, and more. You can find more details about the printf function in Chapter 6.

## 5.1 Assignment Operator

Variable assignment and expressions form the backbone of C programming, enabling the storage and manipulation of data.

### 5.1.1 Storing Results in Variables

Variables in C serve as containers for storing data, and they play a crucial role in arithmetic expressions. Storing the result of an expression in a variable allows for reuse and the ability to track changes over time.

```
int a = 10;
int b = 20;
int result = a + b; // Result is stored in the 'result' variable
```

In this example, the variable result holds the value of the addition, providing a named reference for the calculated result.

Variables not only store results but also serve as dynamic containers that can change during program execution. This flexibility is valuable when dealing with evolving data, such as sensor readings or user input.

```
int sensorValue = analogRead(A0); // Storing a sensor reading in a variable
```

Here, sensorValue dynamically captures the output from a sensor connected to analog pin A0.

Variables can be updated with new values on the basis of calculations or changes in the program state. This dynamic update is fundamental for real-time systems and responsive applications.

```
int count = 0;
count = count + 1; // Incrementing the count variable
```

The count variable is incremented, reflecting changes in the program's logic or external input.

Example: Swap the values of integers a and b.
Swapping or exchanging cannot be done without a temporary variable.

```c
int temp = a;
a = b;
b = temp;
```

### 5.1.2 Compound Assignments

Compound assignment operators improve code readability by combining arithmetic operations with assignment. This makes the modification of variables more efficient and easier to understand.

```c
int total = 100;
total += 20; // Using compound assignment
```

Here, the += operator adds 20 to the current value and updates the variable in one step.

### 5.1.3 Multiple Assignments

The operator can be used to assign a value to multiple variables:

```c
x = y = z = 5;
```

The operator associates from right to left, so that z gets the value 5 first, then y gets the value of z, and lastly x gets the value of y.

## 5.2 Arithmetic Operators

Arduino C supports various basic arithmetic operators, each serving a specific purpose:

- Addition (+): Adds two values together.
- Subtraction (-): Subtracts the right operand from the left operand.
- Multiplication (*): Multiplies two values.
- Division (/): Divides the left operand by the right operand.
- Modulus (%): Returns the remainder of the division of the left operand by the right operand.

### 5.2.1 Addition and Subtraction

Addition (+) is a fundamental arithmetic operation that combines two numeric values. In C, this operation is commonly used for tasks such as accumulating sensor readings, calculating offsets, or determining positional changes.

For example:

```c
int a = 10;
int b = 5;
int sum = a + b; // sum is 15
int diff = a - b; // diff is 5
```
