A floating-point number is double by default unless you add 'f' or 'F' to make it float. Therefore, 3.75 is a double, while 3.75f or 3.75F is a float. Double precision is commonly used for most calculations. However, floats save storage if you need to store lots of numbers and tolerate lower precision.

Here is how you can store and print π in both data types:

```
float pi_float = 3.141593;
printf("%.f\n", pi_float); // Output: 3.141593
```

```
double pi_double = 3.141592653589793;
printf("%.15f\n", pi_double); // Output: 3.141592653589793
```

The %f specifies the number as a single-precision floating point number. Since a float has only 6-7 digit precision, providing a more accurate value for π would still yield the same output. Using %E would give you the same precision as the format prints 6 values after the decimal point by default. The %.15f specifies printing the number with 15 digit precision. If you used the specifier for float when printing a double, the output may be unpredictable.

The %e and %E format specifiers are used to print floating-point numbers in scientific notation. It represents the number in the form of mx10^n, where m and n are integer exponent.

```
double num = 1234.56789;
printf("%e", num); // Output: 1.234568e+03
```

In this example, %e is used to print the variable num. The number 1234.56789 is represented in scientific notation as 1.234568e+03, meaning 1.234568 × 10^3.

The %g specifier is used to print floating-point numbers in either %f or %e format, shorter and more precise.

Here's an example:

```
double num = 1234.56789;
printf("%g", num); // Output: 1234.57
```

In this example, %g is used to print the variable num. Since the number is relatively large, it is printed in %f format with 6 significant digits by default, resulting in "1234.57" being printed. If the number were very small or very large, %g might choose to print it in scientific notation.
