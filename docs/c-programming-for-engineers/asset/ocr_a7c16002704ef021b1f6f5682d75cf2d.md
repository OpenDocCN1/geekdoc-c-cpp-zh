```
int sum = 0;
for (int i = 0; i < 5; i++) {
    sum += arr[i];
}
double average = (double) sum / 5;
printf("The average of the elements is: %.2f\n", average);
```

To find the maximum or minimum value in an array, you iterate over the array and keep track of the current maximum or minimum value. For instance, to find the maximum value in an array called arr:

```
int max = arr[0];
for (int i = 1; i < 5; i++) {
    if (arr[i] > max) {
        max = arr[i];
    }
}
```

```
printf("The maximum value in the array is: %d\n", max);
```

In this example, max is initialized with the first element's value, compared against the remaining elements in the array to find the maximum.

When using algorithms that require changes to the contents or updating data stored in the array, array elements are frequently modified.
