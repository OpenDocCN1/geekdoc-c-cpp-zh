The relational and logical operators in C are used in decision-making constructs and produce Boolean results. Although the symbols for logical AND, OR, and NOT may look similar, they produce different outputs. Table 7.3 gives some examples. # 7.2 The if Construct

The if statement is a fundamental control structure that enables programs to make decisions based on specific conditions. It allows a program to execute a block of code only if a specified condition is true. The if construct flowchart, syntax, and pseudocode is summarized in Fig. 7.2.
The syntax of an if statement is as follows:

```
```
if (condition) {
    // Code to execute if condition is true
}
