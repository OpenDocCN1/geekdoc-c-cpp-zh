
## Chapter 12. Pointers

It is good practice to check for a NULL pointer before accessing any pointer variable to avoid run-time errors and crashes.

## Check if the pointer is NULL

Program to avoid segmentation fault while accessing the value of pointer using NULL pointer

```c
// C NULL pointer demonstration
#include <stdio.h>

int main() {
    // declaring null pointer
    int *ptr = NULL;

    // dereferencing only if the pointer have any value
    if (ptr == NULL) {
        printf("Pointer does not point to anything");
    } else {
        printf("Value pointed to by pointer: %d", *ptr);
    }
    return 0;
}
```

The C standard specifies the NULL pointer, providing a mechanism for a programmer to determine whether a given pointer is legitimate.

## Dereferencing a NULL Pointer

What's going to happen if we use the following C code:

```c
// Trying to dereferencing a null pointer
#include<stdio.h>
int main() {
    int *ptr = NULL;

    printf("%d",*ptr);
    return 0;
}
```

On some machines, the above code compiles successfully, but crashes when run. The program does not behave consistently across all machines. Try the code at your own risk!

## Advanced Pointer Concepts

### 2.8 Advanced Pointer Concepts

### 2.8.1 Void Pointers

Void pointers, denoted as `*`, are special pointers in C that can point to objects of any data type. They offer a generic way to work with memory addresses without specifying a specific data type.

A void pointer is like a wildcard pointer that can store the address of any data type. It is defined using the following syntax:

```c
void *pointer_name;
```

With a void pointer, we can store and manipulate memory addresses without concerning ourselves with the actual type of data being pointed to.
Example:

```c
void *ptr;
int x = 10;

ptr = &x; // Assigning the address of x to a void pointer
```

```c
// To dereference a void pointer,
// it needs to be cast to the appropriate type
printf("Value of x: %d", *(int*)ptr); // Outputs: Value of x: 10
```

Void pointers cannot be directly dereferenced because they lack a specific type. Instead, they need to be typecasted before dereferencing. Here's an example:

```c
int x = 4;
float y = 5.5;
void *ptr;

// Assigning the address of x to ptr
ptr = &x;
```

```c
// Dereferencing the void pointer after typecasting it to int
printf("Integer variable is %d", *(int*)ptr);
```

```c
// Now, assigning the address of y to ptr
ptr = &y;
// Dereferencing the void pointer after typecasting it to float
printf("Float variable is %f", ((float*)ptr);
```

Output:

Integer variable = 4
Float variable = 5.500000

Void pointers have various advantages in C programming:

- They are commonly used with memory allocation functions like malloc() and calloc() because these functions return void pointers, allowing them to allocate memory for any data type.
- Void pointers enable the implementation of generic functions, such as the comparison function used in qsort(), which can handle different data types.
- When combined with function pointers of type void (*) (void), they can point to functions that take any arguments and return any value.
- Void pointers are essential in implementing dynamic data structures like lists, trees, and queues, where the data type may vary.
- They are also frequently used for typecasting purposes, enabling flexibility in data manipulation.

### 12.8.2 Pointer Casting

Pointer casting involves converting a pointer from one data type to another. It's often used when working with void pointers or when dealing with incompatible pointer types.

Example:

```c
float pi = 3.14;
void *voidPtr = &pi; // Pointer to pi

// Casting void pointer to float pointer
float *floatPtr = (float*)voidPtr;

printf("Value of pi: %.2f\n", *floatPtr); // Outputs: Value of pi: 3.14
```

### 12.8.3 Dangling Pointers

A dangling pointer occurs when it points to memory that has been deallocated or is no longer valid. This occurs, for example, when memory previously allocated to the pointer is freed, but the pointer still holds that address. Dangling pointers can lead to unpredictable behavior, like accessing memory not owned by the program or causing crashes.

Example:

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *ptr, a = 55;

    ptr = malloc(sizeof(int)); // Allocate memory
    *ptr = 33; // store number in dynamically allocated memory
    printf("Data at ptr: %d\n", *ptr);
    ptr = &a; // Point to 'a'
    printf("Data at ptr: %d\n", *ptr);
    free(ptr); // Free memory
    return 0;
}
```

### 12.8. Advanced Pointer Concepts

The code starts by declaring an integer pointer ptr and an integer variable a. Then, it dynamically allocates memory for an integer using malloc() and assigns the address of the allocated memory to ptr.

After allocating memory, the code stores the value 33 in the dynamically allocated memory and prints it. Then, it points ptr to the address of variable 'a' and prints its value. Finally, it calls free(ptr), which is problematic because 'a' is a stack variable, not heap-allocated memory. This creates a dangling pointer.

To avoid such issues, ensure free is only called on memory allocated with malloc, calloc, or realloc.
