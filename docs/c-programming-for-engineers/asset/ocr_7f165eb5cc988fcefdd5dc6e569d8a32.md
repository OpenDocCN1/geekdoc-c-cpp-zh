# Chapter 3. Programming Environment

The online compiler recommended for this book is OneCompiler, available at https://onecompiler.com/. This is the programming environment we will be using from here on.

The recommended IDE for Windows is Dev-C++ and Code::Blocks. Dev-C++ is accessible at https://www.bloodshed.net. It is a full-featured IDE and code editor for the C/C++ programming language. It uses the Minw port of GCC (GNU Compiler Collection) as its compiler. Code::Blocks is available at https://www.codeblocks.org/downloads/.

If you are using a Mac, install Xcode (https://developer.apple.com/xcode/). You need a stable Internet connection as the latest version is around 8 GB in size, and will use 30 GB on your computer.

# 3.3.1 Running the Hello World Program

The "Hello, World!" program is a simple and traditional introductory program used in various programming languages. Its primary purpose is to output the message "Hello, World" to the user. The program serves as a foundational exercise to familiarize beginners with basic syntax and printing/displaying text in specific programming language.

Running the Hello World program on the OneCompiler is super easy as it is the default program when first launching the website.

+   1. Click the blue button to confirm that the programming language is indeed at C.
2. Click the red button to run the code.
