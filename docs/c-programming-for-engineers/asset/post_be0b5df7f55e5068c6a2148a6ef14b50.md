## 4.3 Data Types

Data types are fundamental in programming as they specify the kind of data a variable can hold. They categorize the sorts of values a variable can store. Understanding data types helps prevent errors, optimizes memory usage, and improves code readability.

C provides a range of data types, encompassing numeric types like byte, int, long, float, and double, as well as character types like char and string. Each data type has distinct characteristics and a specific value range. Selecting the appropriate data type based on the expected range of values is crucial for optimizing C programming efficiency.

The size of data in C varies depending on the underlying platform. The ranges outlined in this section hold true for personal computers. However, in scenarios involving embedded systems with smaller processors, the sizes are typically more compact. Table 4.6 lists the major groups of C data types.

| Data Type | What It Stores | Example |
|---|---|---|
| Integer | Whole numbers | int age = 25; |
| Floating-point | Fractional numbers | double pi = 3.14159263589793; |
| Character | Characters | char initial = 'A'; |

### 4.3.1 Integer Data Types

In C, integer data types provide options for storing whole numbers, each with its own size and range.

#### The Basic Type: int

The most commonly used type is int, which occupies 32 bits (4 bytes) on personal computers, allowing values ranging from -2,147,483,648 to 2,147,483,647 (about ±2 billion). The int data type frequently yields optimal performance because its size corresponds to the native data size in many computer architectures.

#### Table 4.7: C data types with size and range on personal computers

| Data Type | Size (Bits) | Size (Bytes) | Range |
|---|---|---|---|
| char | 8 | 1 | -128 to 127 |
| unsigned char | 8 | 1 | 0 to 255 |
| short int | 16 | 2 | -32768 to 32767 |
| unsigned short int | 16 | 2 | 0 to 65535 |
| int | 32 | 4 | -2 billion to +2 billion |
| unsigned int | 32 | 4 | 0 to 4 billion |
| long int | 64 | 8 | -2⁶³ to +2⁶³ |
| unsigned long int | 64 | 8 | ±3.4 x 10³³ |
| float | 32 | 4 | ±3.4 x 10³⁸ |
| double | 64 | 8 | ±1.8 x 10³⁰⁸⁸ |
| long double | 80 | 10 | ±1.19 x 10⁴⁹³² |

An alternative is unsigned int, which shares the size of int but can only store non-negative values, offering a range from 0 to 4,294,967,295 (about 4 billion). This is useful when negative numbers are not required.

#### The Variants

For smaller ranges, short int can be utilized, occupying half the size of int (16 bits or 2 bytes) and ranging from -32,768 to 32,767. However, caution is needed to prevent overflow when using smaller types. Similarly, unsigned short int is akin to short int but can only store positive numbers, ranging from 0 to 65,535.

In cases where int falls short, you can use long int. The exact size depends on the platform, but it is guaranteed to be at least 32 bit. On PCs, the size is 64 bits, with values up to ±9 quintillion (9 × 10¹⁸). Conversely, unsigned long int provides a larger positive range from 0 to 18 quintillion (1.8 × 10¹⁹).

When declaring variants of int, you can omit the int keyword, which works for short int, unsigned short int, unsigned int, long int, and unsigned long int.

Here is how you declare and initialize integer variables:

```
int temperature = -32;
unsigned age = 25;
short distance = -3;
unsigned short weight = 100;
long mileage = 300000L;
unsigned long messageID = 1234567890;
```

#### Choosing the Right Variant

Choosing the right data type is important to make our programs work well and use memory efficiently.

## 4.3. Data Types

We need to consider the maximum memory value we want to store. Smaller data types, like short int, require less memory but are not always faster. If we choose a type that is too small, we may not have enough space to store our data. If we choose a type that is too large, memory will be wasted.

The size of data often plays an important role in performance. Common word sizes include 8, 16, 32, and 64 bits. The data type is typically chosen to match the computer's word size. To determine the size of data types on a specific computer, we can use the sizeof() function. It tells us how much memory each type uses and is useful when we work on systems.

```c#include <stdio.h>
int main() {
    printf("Size of char = %zu\n", sizeof(char));
    printf("Size of short = %zu\n", sizeof(short));
    printf("Size of int = %zu\n", sizeof(int));
    printf("Size of long = %zu\n", sizeof(long));
    printf("Size of float = %zu\n", sizeof(float));
    printf("Size of double = %zu\n", sizeof(double));
    printf("Size of long double = %zu\n", sizeof(long double));
    return 0;
}
```

When deciding between signed and unsigned types, we should think about the kind of data we have. If our data can be positive or negative, such as temperature, we can use signed types. But if our data is always nonnegative, such as counters, we can use unsigned types.

### 4.3.2 Floating-Point Data Types

C provides floating-point data types to handle numbers with fractional parts. These are crucial for scientific calculations, financial applications, and graphics programming.

The main floating-point types in C are float and double. The float type is single-precision, occupying 32 bits (4 bytes) in memory and offering 6-7 decimal digits of precision. The range of values for a float is approximately 1.⁷⁻³⁸ to 3.⁴³⁸.

On the other hand, the double type is double-precision, using 64 bits (8 bytes) and providing 15-16 decimal digits. Its range is significantly larger than that of float, with the smallest positive value being 2.² × 10⁻³⁰⁸ and the largest around 1.⁸ × 10³⁰⁸. If available, the long double type offers even higher precision, its range varying depending on the compiler and hardware, typically using 10 bytes (80 bits) and providing approximately ±1.¹⁹ × 10⁴⁹³². In some cases, it can be as large as 128 bits.

Floating-point numbers are stored in memory using the IEEE 754 floating-point representation, which consists of a sign bit, an exponent, and a fraction (mantissa). This format allows for a wide range of values but introduces approximation errors.

Common floating-point literals are written with a decimal point (1.625) or in scientific notation (6.022e² meaning 6.022 × 10²). To initialize floating-point variables, you can use literals with decimal points or scientific notation. Example:

```c
float c = 2.99e+08; // speed of light
double pi = 3.1415926538597311597634854;
```

When working with floating-point numbers, it is crucial to be aware of rounding errors and limited precision. In certain cases, they may not yield exact results and lead to inaccuracies during calculations or comparisons. If high precision or exact integer values are required, it is recommended to use integer data types instead. It is important to exercise caution when comparing floating-point numbers for equality or performing calculations that demand high precision.

### 4.3.3 Character Data Type

In C, the char data type is used to represent single characters, such as 'a' or '7', each occupying 1 byte (8 bits) of memory. Characters are encoded using ASCII (American Standard Code for Information Interchange) as shown in Table 4.8. The ASCII standard uses only 7 bits, with the most significant bit typically set to 0. The ASCII code for the character 'A' is in column 100 and row 0001, which corresponds to the binary code 1000001₂ or 0x41 (or 65 in decimal). The following statements are equivalent:

```c
char c = 0x41;
char c = 65;
```

However, for the sake of readability, it is recommended to use the character literal when storing ASCII characters in the variable. The first 32 codes (0000000-0011111) of ASCII are special characters that cause certain actions to be performed. The remaining codes allow all characters to be printed.
