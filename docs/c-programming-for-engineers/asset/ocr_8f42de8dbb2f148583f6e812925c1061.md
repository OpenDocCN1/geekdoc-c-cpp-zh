real-time signal processing, high-speed data acquisition, and multitasking, making
Arduino a viable option even for complex, professional-grade projects.

For a cross-platform development environment, you might explore
PlatformIO, which runs on Windows, macOS, and Linux. It supports over 900+
embedded boards, including STM32, ESP32, AVR (Arduino), and Raspberry Pi Pico.
PlatformIO works with both Arduino C and STM32 HAL, providing a more advanced

# 15.3 Arduino C vs Regular C

Arduino C is a simplified version of C++ tailored for programming Arduino Boards.
be technically correct, it should be called Arduino C/C++. While it borrows heavily
from C and C++, it is distinct in its approach to hardware interaction and ease of use.
Below are the key differences between Arduino and Regular C:

+   - Hardware-Specific Design:
Arduino C is designed specifically for programming Arduino boards, which use
microcontrollers like the ATmega328 or ARM Cortex-M. It simplifies hardware-
specific tasks such as reading from sensors or controlling actuators. Regular C,
by contrast, is a general-purpose programming language that can be used on a
wide range of platforms, from embedded systems to desktop environments.

+   - Level of Abstraction:
Arduino provides a higher level of abstraction, hiding many low-level details.
For instance, tasks like memory management and register-level operations are
handed by inbuilt libraries. This makes Arduino beginner-friendly. Regular C
offers more granular control, requiring the programmer to handle low-level
details as memory allocation, hardware registers, and timing.

+   - Language Features:
Arduino C is essentially a subset of C++ with limited support for object-oriented
programming. While it does include features like the String class, it omits
more advanced C++ features like inheritance and polymorphism. Regular C is
procedural, without object-oriented capabilities, and C++ (on which Arduino C
is based) provides the full spectrum of object-oriented features.

+   - Additional Data Types:
Arduino introduces some additional data types to suit the microcontroller
environment, such as boolean, byte, and word. It also supports binary literals,
0b10001001 for easy representation of binary data. These types and
features simplify programming for microcontroller applications.

+   - Program Structure:
Arduino C uses a unique program structure centered on two functions: setup()
an loop(). The setup() function initializes the program and runs once at
t start, the loop() function runs continuously. Regular C programs
are structured around the main() function, which must explicitly manage
initialization and repetitive tasks.
