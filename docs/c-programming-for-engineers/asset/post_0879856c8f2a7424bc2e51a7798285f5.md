
This code runs the LED on and off with a 1-second delay between each state. Let us break down the code:

## 15.6 Reading from Switch

The Maker Uno has a built-in pushbutton switch connected to pin 2. To use this button, no additional interface components are necessary. However, on other Arduino boards, you may need to connect a pushbutton switch. You can find instructions on how to connect a switch online (e.g., Google).

The following program reads the state of the built-in switch. The built-in LED is turned on when the switch is pressed, and turned off otherwise. Note that the digitalRead() function returns the LOW when the switch is pressed.

// Echo: turns on LED when switch is pressed

```cpp
const byte SWITCH_PIN = 2;
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
  pinMode(SWITCH_PIN, INPUT_PULLUP);
}
void loop() {
  if (digitalRead(SWITCH_PIN) == LOW)
    digitalWrite(LED_BUILTIN, HIGH);
  else
    digitalWrite(LED_BUILTIN, LOW);
}
```

The code demonstrates how to read the state of a switch connected to pin 2 of an Arduino board. In the code set-up, pin 13 is set as an output for the LED, and pin 2 is set as an input. You must use the INPUT PULLUP option to configure the switch. In the loop, the switch state is checked using digitalRead(). If the switch is pressed (LOW state), the LED is turned on. If the switch is released (HIGH state), the LED is turned off.

The following code snippets reuses the LED blinking code from the previous section but require the built in switch to be pressed before the LED blinking can start. The first program uses a polling loop approach which acts as a barrier. It serves as a barrier, preventing further processing until the switch is pressed. Once the switch is pressed, the program proceeds to the loop() function where the LED is blinked.

```cpp
// Blinky2: push the button to start the LED blinking
// Uses the barrier method
const byte SWITCH_PIN = 2;

void setup() {
    pinMode(SWITCH_PIN, INPUT_PULLUP);
    pinMode(LED_BUILTIN, OUTPUT);
    while(digitalRead(SWITCH_PIN) == HIGH);
}

void loop() {
    digitalWrite(LED_BUILTIN, HIGH);
    delay(500);
    digitalWrite(LED_BUILTIN, LOW);
    delay(500);
}
```

In the loop function, the LED is turned on, delayed for 500 milliseconds using delay(500), then turned off, and delayed for another 500 milliseconds.

The second program utilizes a flag variable, PROCEED, to keep track of whether the switch has been pressed. Initially, PROCEED is set to false. In the loop function, the switch input is checked, and if the switch is pressed, PROCEED is changed to true, enabling the LED blinking. Once PROCEED is set to true, it remains true and cannot be changed to false.

```cpp
// Blinky3: push the button to start the LED blinking
// Uses the flag variable method
const byte SWITCH_PIN = 2;
boolean PROCEED = false; // flag variable

void setup() {
    pinMode(SWITCH_PIN, INPUT_PULLUP);
    pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  if(digitalRead(SWITCH_PIN) == LOW)
    PROCEED = true;
  if(PROCEED) {
      digitalWrite(LED_BUILTIN, HIGH);
      delay(500);
      digitalWrite(LED_BUILTIN, LOW);
      delay(500);
  }
}
```

Similarly to the first program, the LED is blinked by turning it on, turning off, and delaying for 500 milliseconds, turning it off and delaying for another 500 milliseconds. However, the blinking only occurs when PROCEED is true, which happens when the switch has been pressed.

In summary, both programs involve checking the state of the switch and blinking the LED accordingly. The first program uses a polling loop as a barrier before proceeding to the LED blinking, while the second program utilizes a flag variable to determine if the switch has been pressed before enabling the LED blinking.

## 15.7 Blink All LEDs in Sequence

In this section, we aim to sequentially turn on LED 2 through 7 in a back and forth pattern, creating an interesting display. Here is the complete code:

```cpp
// KnightRider: Sequentially turns on the built-in LEDs
int delayTime = 100; // Adjust this value to change the speed of the effect
void setup() {
  for (int i = 2; i <= 7; i++) {
    pinMode(i, OUTPUT); // Set pins 2 through 7 as outputs
    digitalWrite(i, LOW); // Turn off all initially
  }
}

void loop() {
  // Scan the LEDs from left to right
  for (int i = 2; i <= 7; i++) {
    digitalWrite(i, HIGH); // Turn on the current LED
    delay(delayTime); // Wait for a while
    digitalWrite(i, LOW); // Turn off the current LED
  }

  // Scan the LEDs from right to left
  for (int i = 6; i > 2; i--) {
    digitalWrite(i, HIGH); // Turn on the current LED
    delay(delayTime); // Wait for a while
    digitalWrite(i, LOW); // Turn off the current LED
  }
}
```

## Blink All LEDs in Sequence

Let's break down the code:

- The setup() function configures 6 LEDs as outputs.
- The digitalWrite() function is used to control the LEDs, turning them on and off.
  - digitalWrite(i, HIGH); turns on i.
  - delay(500) pauses the program for half a second while the LED remains on.
  - digitalWrite(i, LOW); turns off the LED.
- The first loop iterates through LEDs 2 to 7, sequentially turning each on and off.
- The second loop iterates from LED 6 to 3, creating a backward sequence of turning on and off.
- By continuously loops, the program creates a visual effect reminiscent of Knight Rider TV series.
