```
#include <stdio.h>

int main() {
    int score;

    // Prompt the user to enter their test score
    printf("Enter your test score: %d", score);
    scanf("%d", &score);

    // Assign letter grades based on the test score
    if (score >= 80) {
        printf("Your grade is: A\n");
    } else if (score >= 65) {
        printf("Your grade is: B\n");
    } else if (score >= 50) {
        printf("Your grade is: C\n");
    } else {
        printf("Your grade is: F\n");
    }

    return 0;
}
```

An if-else ladder is used when outcomes depend on mutually exclusive conditions that must be evaluated sequentially.

# 7.5 Nested if Construct

Nested if-else statements are used when we need to make decisions based on multiple conditions, with each condition depending on the outcome of the previous one. This creates a hierarchical structure where if-else statements are nestled inside each other. Consider the following program:

```
#include <stdio.h>

int main() {
    int age;

    printf("Enter your age: %d", age);
    scanf("%d", &age);

    if (age >= 18) {
        printf("You are an adult.\n");
        if (age >= 65) {
            printf("You are also a senior citizen.\n");
        }
    } else {
        printf("You are not an adult.\n");
    }
```
