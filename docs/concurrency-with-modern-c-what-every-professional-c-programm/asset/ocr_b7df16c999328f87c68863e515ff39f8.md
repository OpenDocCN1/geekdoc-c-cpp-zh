Each member functions supports an additional memory-ordering argument. The default for the
memory-ordering argument is `std::memory_order_seq_cst` but you can also use `std::memory_order_relaxed`, `std::memory_order_consume`, `std::memory_order_acquire`, `std::memory_order_release`, or `std::memory_order_acq_rel`. The `compare_exchange_strong` and `compare_exchange_weak` member functions can be
parametrized with two memory-orderings. One for the success and one for the failure case. If you
only explicitly provide one memory-ordering, it is used for the success and the failure case. Here are
the details to memory-ordering.
