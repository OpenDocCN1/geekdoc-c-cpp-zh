# ### A small performance test for thread creation

```
~~~cpp
// threadCreationPerformance.cpp

#include <chrono>
#include <iostream>
#include <thread>

static const long long numThreads= 1'000'000;

int main(){

    auto start = std::chrono::system_clock::now();

    for (volatile int i = 0; i < numThreads; ++i) std::thread([]{ }).detach();

    std::chrono::duration<double> dur= std::chrono::system_clock::now() - start;
    std::cout << "time: " << dur.count() << " seconds" << '\n';

}
~~~
```

The program creates 1 million threads that execute the empty lambda function in line 13. These are the numbers for Linux and Windows:
