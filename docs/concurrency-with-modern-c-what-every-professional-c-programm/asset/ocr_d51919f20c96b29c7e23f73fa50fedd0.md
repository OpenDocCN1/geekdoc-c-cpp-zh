# # Locking a non-recursive mutex more than once

Locking a non-recursive `mutex` more than once is undefined behavior.

**Locking more than once**

```
```cpp
// lockTwice.cpp

#include <iostream>
#include <mutex>

int main(){

    std::mutex mut;

    std::cout << '\n';

    std::cout << "first lock call" << '\n';

    mut.lock();

    std::cout << "second lock call" << '\n';

    mut.lock();

    std::cout << "third lock call" << '\n';

}
```
