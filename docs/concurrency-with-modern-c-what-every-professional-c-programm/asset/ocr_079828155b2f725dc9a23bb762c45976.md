+   - All implementation member functions (protected and private) must not use a lock.
+   - The interface member functions call only protected or private member functions but no public member functions.

The thread-safe interface pattern has two nice properties: all public member functions are thread-safe per design and deadlock-free per design. The thread-safe interface is thread-safe because each public member function uses a lock and the thread-safe interface is deadlock-free because a public member function cannot invoke another public member function of the class.
