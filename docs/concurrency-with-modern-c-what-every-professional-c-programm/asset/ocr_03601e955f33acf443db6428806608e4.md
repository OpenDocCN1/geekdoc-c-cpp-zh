Now I use a mutex instead of a spinlock. Let’s see what happens.

# Waiting with a mutex

```
```cpp
// mutex.cpp

#include <mutex>
#include <thread>

std::mutex mut;

void workOnResource(){
  mut.lock();
  std::this_thread::sleep_for(std::chrono::milliseconds(5000));
  mut.unlock();
}
