# ## std::condition_variable_any

std::condition_variable can only wait on an object of type std::unique_lock<mutex> but std::condition_variable_any can wait on a user-supplied lock type that meets the concept of BasicLockable^1. The generalised std::condition_variable_any supports the same interface such as std::condition_variable.
