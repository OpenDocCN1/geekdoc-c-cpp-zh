+   7. **Thread execution mapping guarantees:** Should each execution agent be mapped to a new thread (`execution::new_thread_execution_mapping`) or not (`execution::new_thread_execution_mapping`).
+   8. **Allocators:** Assumes an allocator (`execution::allocator`) with an executor.

You can even define your properties.

# Executors are the Building Blocks

Because the executors are the building blocks for execution, the concurrency and parallelism features of C++ heavily depend on them. This holds for the extended futures, the extensions for networking [N4743](https://wg21.link/n4743), but also the parallel algorithms of the STL, and the new concurrency features in C++20/23 such as latches and barriers, coroutines, transactional memory, and task blocks.
