# 6.1 Calculating the Sum of a Vector

What is the fastest way to add the elements of a `std::vector`? To get the answer, I fill a `std::vector` with one hundred million arbitrary but uniformly distributed¹ numbers between 1 and 10. The task is to calculate the sum of the numbers in various ways. I use the performance of a single-threaded addition as the reference execution time. I discuss atomics, locks, thread-local data and tasks.

Let’s start with the single-threaded scenario.

# 6.1.1 Single Threaded addition of a Vector

The straightforward strategy is to add the numbers in a range-based for loop.
