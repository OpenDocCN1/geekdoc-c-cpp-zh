# 3.2 The Improved Thread std::jthread (C++20)

std::jthread stands for joining thread. In addition to std::thread from C++11, std::jthread automatically joins in its destructor and can cooperatively be interrupted. Consequently, std::jthread extends the interface of std::thread. std::jthread models RAII and, therefore, also joins when an exception occurs.
