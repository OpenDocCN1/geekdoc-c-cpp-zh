The workflow of the DataServer and its DataSession (line 43) is similar. The crucial difference is that the member function `do_read` writes the client data to the output file (line 57).

The following example uses two telnet<sup>42</sup> sessions to invoke the TCP-server. Both TCP clients connect to address 127.0.0.1. They use the port 4711 and 4712 respectively. Due to the EchoServer, data written to the port 4711 is immediately written back. The DataServer writes the client data to the output file more `proactorOutput.txt`.
