The one- and two-argument versions of the ignore member function are used with character arrays instead of an individual character. In the one argument version of the ignore member function, the one is the maximum number of characters to be removed from the input buffer. For example, the statement cin.ignore(80) removes up to the next 80 characters from the input buffer. In the two-argument version, the second argument is a character, if encountered before the number of characters specified in the first argument, cancels the removal from the input buffer to. Thus, the statement cin.ignore(80, '\n') skips the next 80 characters or until a newline is encountered, whichever comes first.

Note

```
*** `cin.ignore();`
*** `cin.get();`
```

This section will use the no-argument version of the ignore member function, but could substitute the no argument version of the get function to do the same effect.

Accordingly, the program modifies the previous one by one following by the call of the get member function with a call to the ignore member function:

```
#include <iostream>
using namespace std;

int main(void)
{
    char ch;
    do {
        cout << "Press Q or q to quit, any other key to continue:";
        cin.get(ch);
        cin.ignore();
        if (ch != 'Q' && ch != 'q')
            cout << "You want to continue\n";
        else
            cout << "You quit\n";
    } while (ch != 'Q' && ch != 'q');
    return 0;
}
```

Now, as the following input and output shows, the program if you press a printable character to continue:

Press Q or q to quit, any other key to continue: x
You want to continue?
Press Q or q to quit, any other key to continue: q
You quit

The reason this works is that the no-argument ignore member function removes the next character from the input buffer. As Figure 12-3 shows, this removes the leftover newline character from the input buffer.
