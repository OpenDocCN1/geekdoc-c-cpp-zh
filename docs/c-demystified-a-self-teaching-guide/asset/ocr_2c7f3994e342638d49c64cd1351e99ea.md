Obviously, -858993460 is not a test score anyone would. Less obvious is the reason why that number is outputted.

The string literal "Jeff" cannot be assigned to an integer variable as testScore. Therefore, the co operator will not assign "Jeff" to that integer variable. Therefore, when the code statement outputs the value of testScore, variable has not yet been a value.

When testScore was declared, there was some value at its memory address left over from programs previously run on the computer. The code statement, when trying to output the value of testScore, the best it can and attempt to interpret this leftover. The result of that interpretation -858993460.

Note Compile time vs. Run-Time Difference When Incompatible Data Types Are Assigned—Error in this chapter, the attempt to assign "Jeff" to testScore testScore = "Jeff" in a compiler error. Here, the attempt to assign "Jeff" to testScore using a cin statement results in an incorrect value. The reason that this time there is no compiler error is because the value the user would not know at compile time, but instead would be known only at run time. Therefore, there would be no compile error, since there was no attempt to assign an incompatible value.

# Inputting Values for Multiple Variables

If you are inputting values for several variables, you could input them one at a time.

```
#include <iostream>
using namespace std;
int main(void)
{
    int myWeight, myHeight;
    string myName;
    cout << "Enter your name: ";
    cin >> myName;
    cout << "Enter your weight in pounds: ";
    cin >> myWeight;
    cout << "Enter your height in inches: ";
    cin >> myHeight;
    cout << "Your score is " << myName << "\n";
    cout << "Your weight in pounds is " << myWeight << "\n";
    cout << "Your height in inches is " << myHeight << "\n";
    return 0;
}
```

The output of the program, with the input of "Jeff" for the name, 200 for the pounds, and 72 for the height,

```
Enter name: Jeff
Enter your weight in pounds: 200
Enter your height in inches: 72
Your name is Jeff
Your weight in pounds is 200
Your height in inches is 72
```
