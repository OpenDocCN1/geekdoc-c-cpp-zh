# The Difference Between Prefix and Postfix

The following program is similar to the previous program that illustrated the increment operator.

```
#include <iostream>
using namespace std;
int main(void)
{
    int num = 2;
    cout << num++;
    return 0;
}
```

However, instead of two statements:

```
num++;
cout << num;
```

This program uses one statement:

```
cout << num++;
```

There are two operators in this statement: the increment operator ++ and the stream insertion operator <<. The issue is of precedence; which operation occurs first.

The output of this program is 2. The reason is when an increment or decrement operator is postfix, that operation is the last to occur. Therefore, the output of num occurs first while the variable's value is 2, and then the value of num is incremented from 2 to 3.

Now, change the line:

```
cout << ++num;
```

to the line:

so the program now reads

```
#include <iostream>
using namespace std;
int main(void)
{
    int num = 2;
    cout << ++num;
    return 0;
}
```

This time, the output of this program is 3 instead of 2. The reason is that an increment or decrement operator is prefix, that operation is the first to occur. Therefore, num first is incremented from 2 to 3 before the value of num is outputted.

The distinction between prefix and postfix also arises frequently with arithmetic operators.
