**Caution** You can also use Notepad or any other editor to write the code. However, do not use Microsoft Word or any other word processing program to write your code. While a word processing program enables you to neatly format your code, it does so using hidden characters that the compiler does not understand and will regard as syntax errors.

Save your work, such as by pressing the Save toolbar. We're now ready to compile.
