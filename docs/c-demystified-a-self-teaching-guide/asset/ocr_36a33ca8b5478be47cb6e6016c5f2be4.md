increasing the possibility of logic errors. That advice also applies to the while loop.
recommended then, and recommend now, as an alternative the use of a logical operator.
The following program modification adopts that alternative.

```
#include <iostream>
using namespace std;
int main(void) {
	int num;
	char choice;
	bool bool = false;
	cout << "Enter a positive number: "
	cin >> num;
	while (num <= 0 && bool == false) {
	cout << "Number must be positive; try again (Y/N): "
	cin >> choice;
	if (choice == 'Y') {
		cout << "Enter number: "
		cin >> num;
	}
	} else
		bool = true;
}
if (bool == false)
	cout << "The number you entered is " << num << " ";
	else
	cout << "You did not enter a positive number";
	return 0;
}
```

Here is some sample input and output when the user eventually enters a positive number:

Enter a positive number: -3
Number must be positive; try again (Y/N): Y
Enter number: 3
The number you entered is 3

Here is some sample input and output when the user does not enter a positive number
but instead decides to quit. The final output is not of number entered, but
rather that the user did not enter a positive number:

Enter a positive number: 0
Number must be positive; try again (Y/N): Y
Enter number: -1
Number must be positive; try again (Y/N): N
Did not enter a positive number

This program modification, in addition to using the && && operator, uses a Boolean
variable named quit. This Boolean variable is used as a flag. A flag is a Boolean
whose value indicates whether a condition exists.

In this program, the while loop continues as long as the data entered is invalid and
the user wants to keep going. Accordingly, the while keyword is followed by two
conditions, joined by the logical && operator.
