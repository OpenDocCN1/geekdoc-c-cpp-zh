Unlike an istream object, an ofstream object that attempts to open a file that does not yet exist is NULL, and its fail member function would return false, because the operating system will create the file if it does not already exist. However, a file for writing is not always successful. For example, before you run the program, create a file named students.dat in the same directory as your program, through its properties check only:

```
#include <fstream>
#include <iostream>
using namespace std;

int main () {
  ofstream outfile;
  outfile.open("students.dat");
  cout << " " << outfile << " " << endl;
  cout << " " << outfile.fail() << " " << outfile.fail() << " " << endl;
  return 0;
}
```

The following output reflects that the ofstream object is NULL, and its fail function returns true, because you cannot open for writing a file that is read only.

```
(outfile) = 00000000
(outfile.fail()) = 1
```

If you cannot open a file for reading or writing, then you do not want to proceed to execute the code that reads from, or to, the file. Instead, you may want to stop execution of the function, in the following code fragment:

```
ifstream infile;
infile.open("students.dat");
if (infile == NULL) {
  cout << "Error in opening file for reading";
  return 0;
}
// code to read from file
```
