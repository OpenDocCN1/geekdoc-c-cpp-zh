# Size

Each of the whole number data types listed in Table 2-2 has a size. Indeed, all C++
types have a size. However, unlike people, the size of a data type is not expressed
in inches or pounds (a subject for most), but in bytes.

Since a byte is the smallest unit of address that a computer can process, no data type
be smaller than one. Most data types are larger than one; the whole
data types listed in Table 2-2 are. However, regardless of the size, the number of
bytes is a whole number. You cannot have a data type size of 3.5 bytes
because .5 bytes, or 4 bytes, is too small for the computer.

Generally, the number of bytes for a data type is the result of 2 since
computers use a binary number system. Thus, typical data sizes are 1 byte (2⁰), 2
bytes (2¹), four bytes (2²), or eight bytes (2³).

The size of a data type matters in two respects: (1) the range of different values
dat the data type may represent and (2) the amount of memory required to store the data
type.
