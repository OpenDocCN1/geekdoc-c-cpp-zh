# Figure 6-2: Flowchart of the movie admission program

The nested if portion of the program is

```
if (age > 12)
    if (age >= 65)
        cout << "Admission is free";
    else
        cout << "You have to pay";
else
    cout << "Admission is free";
```

The inner if/else structure, comparing whether the user is at least 65 years old, is nested within the outer if/else structure, comparing whether the user is at least 12 years old. By this nesting, the comparison of whether the user is at least 65 years old is made only if the user is over 12 years old. This approach is logical, if the user is no more than 12 years old, they would be admitted (and also not possibly 65 years or older).

This program could also have been written using the following if / else if / else structure in place of the nested if statements:

```
if (age <= 12)
    cout << "Admission is free";
else if (age >= 65)
    cout << "Admission is free";
else
    cout << "You have to pay";
```

Each of these alternatives, the nested if statements and the if / else if / else structure, have disadvantages. Nesting one statement inside another by its very nature may be somewhat difficult to write and understand. However, if the if / elseif / if / else structure has the disadvantages of repeating the same cout statement for both the if and else if parts. While this is just one line of repetitive code in this program, in more complex programs the repetitive code could be many lines long.

C++ has a third and perhaps better alternative, the use of logical operators, which we will discuss next.
