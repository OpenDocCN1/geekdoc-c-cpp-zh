One problem is 387 divided by 100 could be 3.87, 3. However, as discussed earlier in this chapter the "Division Operators" section, when an integer is divided by an integer, the result always is an integer unless one of the integer operands is first cast to a float. dollars = total / 100;
```

leftover = total % 100;
```
