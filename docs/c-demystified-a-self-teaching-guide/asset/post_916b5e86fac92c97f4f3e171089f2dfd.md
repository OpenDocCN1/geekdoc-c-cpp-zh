# Structures

Objects are generally too complex to be described by a single variable. An array can store multiple values, but all values must be of the same type. The restriction that all values must be of the same type is not workable for objects. For example, each human being shares characteristics such as name and height. Height may be stored in an integer, but a name would be stored in a C-string.

The name and height variables are related in the sense that they both describe characteristics of the person. However, if you declare them as follows, they do not belong together, but instead simply are independent variables:

```
string name;
int height;
```

C++ enables you to package related variables together into a structure. A structure may contain different types, permitting the program to more faithfully emulate the complexity of a real-world object.

A structure, in reality, is a data type. However, it is not a data type built into C++, such as an int or C-string. It is a programmer-defined data type.

# Declaring a Structure

Since it is a programmer-defined data type, you must declare it so the compiler will understand what it is. The following code fragment declares a structure representing a person with two characteristics, name and height:

```
struct Person {
  string name;
  int height;
};
```

The declaration commences with struct, which is a keyword indicating that a structure is being declared. "Person" is the name I gave for this structure. I could have used another name. As naming variables, you should give the structure a name which indicates what it represents.

The open and close curly braces define the body of the structure. Structures, like functions, have a body enclosed in open and close curly braces. Unlike functions, the close curly brace must be followed by a semicolon.

> Note Forgetting the semicolon after the curly brace is a common rookie mistake. You may not experience a compiler error, but instead a run-time error, particularly on multiple project files, the error message providing little or no clue that the real reason for the error is you forgot the semicolon.

The variables that are related to each other are declared in the body of the structure. Each variable is referred to as a member variable. A structure may have many member variables, as discussed in a later section in this chapter, "Nesting Structures;" where one structure may be a member variable of another.
