# Arithmetic Operators

The program then assigns added the value inputted by the user for the number of students adding the course. Afterward, the program uses the addition operator to add two operands, total and added. The resulting sum is assigned to total, which now reflects the number of all students in the course, both preregistered and added. Then that is outputted.

```
#include <iostream>
using namespace std;
int main() {
    int total, added;
    cout << "Enter number of pre-registered students: ";
    cin >> total;
    cout << "Enter number of students adding the course: ";
    cin >> added;
    total = total + added;
    cout << "Total number of students: " << total;
    return 0;
}
```

The input and output of the program could be
Enter number of registered students: 30
Enter number of students adding the course: 3
Total number of students: 33

# ## Combined Assignment and Arithmetic Operator

New programmers are confused by statements such as total = total + added because, in mathematics, a variable cannot equal plus another. However, this statement is not made in mathematics, but in C++ programming, in which the = operator is not used for equality, instead for assignment.

Nevertheless, there is also another way to express total = total + added:
total += added;

To the compiler, it makes no difference which total = total + added or total += added. However, many programmers prefer total += added, because it looks more elegant, others it seems more readable, and still for the practical reason that it requires less typing.

This compact of combining arithmetic and assignment operators is not limited to the addition operator. In Table 4-2 shows, it can also be used with the other arithmetic operators. In that, it is assumed a is previously declared integer variable.

# ## Table 4-2: Combining Arithmetic and Assignment Operators

| Statement | Combining Operators |
| --- | --- |
| a = a + 2; | a += 2; |
| a = a - 2; | a -= 2; |
| a = a * 2; | a *= 2; |
| a = a / 2; | a /= 2; |
| a = a % 2; | a %= 2; |
