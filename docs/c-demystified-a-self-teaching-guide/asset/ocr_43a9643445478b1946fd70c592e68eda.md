# Opening a File

A file must be opened before you can read from it or write to it. As discussed in the introduction to this section, opening a file establishes a path of communication between the file and a stream object in your program. Opening a file for writing is first discussed.

# Opening a File for Writing

Either the *ofstream* or *iostream* object may be used to open a file for writing. However, the *istream* object cannot be used for this purpose because it may only be used to read from a file.

Both the *ofstream* and *iostream* objects may open a file in two ways. The first is by using a member function, as you might expect, *open*. The second alternative is using a constructor, which is explained in the “The *iostream* or *ofstream* Constructor” section in this chapter, as follows

# The Open Member Function

Both the *ofstream* and *iostream* objects use an *open* member function, whose first argument is the name and location of the file to be opened. However, whether you include a second argument depends on whether the *ofstream* or *iostream* object is calling the member function, or whether you want to access the file in a different “mode” than the default.

# Specifying the File to Be Opened

The file to be opened for writing needs not already exist. If it does not, attempting to open it will automatically create it with the name at the specified location. However, whether or not the file exists, you need to specify a name and location.

Accordingly, whether the *ofstream* or *iostream* object is calling the function, the first argument specifies the name and location of the file to be opened. This information may be provided by using either the *relative path* or *absolute path* of the file. The terms *relative path* and *absolute path* are so, let's discuss them now.

The relative path is the path relative to the location of your program. For example, the following statements for opening a file, *students.dat*, that is in the same directory as the program:

```
ofstream outfile;
outfile.open("students.dat");
```

By contrast, the absolute path is the path starting with the drive letter, and including each directory and subdirectory until the file is reached. For example, if the *students.dat* file is in the *Classes* subdirectory of the Directory of your C drive, it would be opened for writing, using the absolute path, as follows:

```
ofstream outfile;
outfile.open("C:\college\classes\students.dat");
```

Note Two backslashes are necessary because one backslash is an escape sequence. The backslash is the escape sequence for one backslash.
