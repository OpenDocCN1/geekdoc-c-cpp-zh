A better choice is the fail member function, discussed in the earlier section "Checking if the File Was Opened." The following code fragment shows how to use the fail member function in reading a file until the end of the file is reached:

```
ifstream infile;
infile.open("students.dat");
infile >> data;
while(!infile) {
    infile >> data;
    cout << data;
}
infile.close();
```

The preceding code fragment has infile >> data statements, one before the loop begins, the other inside the loop. The reason is that the end of file is not detected until after a read attempt is made. If the file was empty, the count << data statement before the loop was omitted and the count << data statement would execute before an attempt was made to detect if the end of file had been reached.

+   Note
A while loop could be used instead of a if loop. This would dispense with the need to check for file before ending the loop, but add the requirement to check the loop if (using an if statement) end of file reached. This is the usual tradeoff between while and do loops.
