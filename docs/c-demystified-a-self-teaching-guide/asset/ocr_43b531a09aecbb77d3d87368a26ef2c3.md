# Project: Determining the Size of Data Types

As discussed in the Data Types section, the size of each data type depends on the compiler and operating system you are using. In this project, you will find out the size of each data type on your system using the sizeof operator.

# The sizeof operator

The sizeof operator is followed by parentheses, in which you place a data type. It returns the size in bytes of that data type.

For example, on my computer, the expression sizeof(int) returns 4. This means that by my compiler and operating system, the size of an int type is 4 bytes.
