# Ranges of Numbers

Another difference between switch and if/else if statement concerns the handling of ranges of numbers. For example, earlier in this chapter we used an if /else if /else statement to output the user's grade based on the test score that was input by the user. The issued grade was An A if the test score was 90 and 100, a B if the test score was between 80 and 89, and on the if/else if statement in that program was

```
if (testScore > 90)
  cout << "Your grade is an A" << endl;
  else if (testScore >= 80)
  cout << "Your grade is a B" << endl;
  else if (testScore >= 70)
  cout << "Your grade is a C" << endl;
  else if (testScore >= 60)
  cout << "Your grade is a D" << endl;
  else
  cout << "Your grade is an F" << endl;
```
