Similarly, programmers sometimes make the condition of the while loop always true, as while (true) or (1), and break out of the while loop with, you guessed it, the break keyword. Here is an example of a modification of the program we have been using that asks the user to enter a positive number.

```
#include <iostream>
namespace std;
int main(void)
{
    int num;
    char choice;
    bool quit = false;
    while (true)
    {
        cout << "Enter a positive number: ";
        cin >> num;
        if (num > 0)
            break;
        else
        {
            cout << "Number must be positive; try again (Y/N): ";
            cin >> choice;
            if (choice != 'Y')
            {
                quit = true;
                break;
            }
        }
    }
    if (quit == false)
        cout << "The number you entered is " << num << "";
    else
        cout << "You did not enter a positive number";
    return 0;
}
```

The advantage of this modification is that it renders unnecessary to prompt the user before and inside the loop to enter a positive number. However, the use of the while (true) syntax has the disadvantage of making your code less readable because the condition that stops the loop cannot be discerned from the parentheses following the keyword. The do while loop (explained later in this chapter) avoids this disadvantage and would be a preferable choice.
