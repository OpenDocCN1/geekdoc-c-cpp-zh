
## Using an IDE to Create and Run the “Hello World!” Project

You can use any plain-text editor such as Notepad to write the source code. You can also download a free compiler, which usually includes a preprocessor and linker. Then you can compile and run your code from the command line. The command line may be, for example, a DOS prompt at which you type a command that specifies the action you want, such as compiling, followed by the name of the file you want.

While there is nothing wrong with using a plain-text editor and command line tools, many programmers, including me, prefer to create, compile, and run their programs in a C++ Integrated Development Environment, known by the acronym IDE. The term "integrated" in IDE means that the editor, preprocessor, compiler, and linker are all together under one (software) root. Thus, the IDE enables you to create, compile, and run your code using one program rather than separate programs. Additionally, most IDEs have a graphical user interface (GUI) that makes them easier to use than a command line. Finally, many IDEs have added features that ease your task of finding and fixing errors in your code.

The primary disadvantage of using IDEs is that you have to purchase them (though there are some free ones). They also require additional drive space and memory. Nevertheless, obtaining an IDE since it enables you to focus on C++ programming issues without distractions like figuring out the right commands to use on the command line.

There are several IDEs on the market. Microsoft's, called Visual C++, can be obtained separately or as part of Microsoft's Visual Studio subscription. Roland offers C++ Builder, both in free and commercial version. IBM has a VisualAge C++ IDE. There are a number of others as well.

In this book I will use Microsoft C++ .NET 2003 IDE since I have to. However, most IDEs essentially work the same way, and your code will compile and run the same no matter which IDE you use as long as you don't use any libraries custom to a particular IDE. The standard library files will be used, such as iostream, the same in all C++ IDEs.

Additionally, I am running the code on a Windows 2000 operating system. The results should be similar on other operating systems, not just Windows operating systems, but additional types of operating systems as well, as UNIX.

Let's use the IDE to write the source code for the "Hello World!" project, and then compile and run it.

## Setting Up the “Hello World!” Project

Once you have purchased and installed Visual C++ .NET 2003, either as a standalone application or as part of Visual Studio, you are now ready to start your project, which is to create and run the “Hello World” application.

- 1. Start Visual C++.
- 2. Open the New Project dialog box shown in Figure 1-2 using the File | New | Project menu. (The Values in Name and Location will be set in steps 5 and 6.)

![](img/59a3417a6d5906fae6d8000d4c2cff76_23_0.png)
**Figure 1-2:** Creating a New Project

- 3. In the right or left pane of the New Project dialog box, choose Visual C++ Projects from the list of Project Types, and then the Win32 subfolder, as shown in Figure 1-2.
- 4. In the right or contents pane of the New Project dialog box, choose Win32 Console Project from the list of templates. The word console comes from the application running from a console window. Win32 comes from the Windows 32-bit operating system, such as Windows 9x, 2000, or XP.
- 5. In the Location field, using the Browse button, choose an existing folder where you will save your project.
- 6. In the Name field, type the name you've chosen for your project. This will also be the name of the subfolder created to store your project files. I suggest using a name that describes your project so you can locate it more easily.
- 7. Click the OK button. This will display the Win32 Application Wizard, shown in Figure 1-3.

![](img/59a3417a6d5906fae6d8000d4c2cff76_24_0.png)
Click the Application Settings menu item. The appearance of the Win32 Application Wizard then changes to that shown in Figure 1-4.

![](img/59a3417a6d5906fae6d8000d4c2cff76_24_1.png)

Choose, if necessary, Console Application under Application Type (this is the default) and Empty Project under Additional Options. Choosing Empty Project will disable both checkboxes under Add Support For, which should be disabled anyway.

> Caution: Make sure to follow this step carefully, particularly choosing Empty Project, which is not the default. Not configuring Application Settings properly is a common mistake and may require you to start over.

Click the Finish button. Figure 1-5 shows the new subfolder HelloWorld and its parent folder, with the name and location chosen in steps 5 and 6.

![](img/59a3417a6d5906fae6d8000d4c2cff76_25_0.png)
**Figure 1-5:** Windows Explorer showing newly created subfolder and folders

You have created a project for your application. The project is a shell for your application, containing files that will support the creation and running of your application. However, right now the project is empty of any code you have written, so it won't do anything. Accordingly, the next step is to start writing code.

## Writing the Source Code

Visual C++ has a view of a project that is similar to Windows Explorer. That view is called Solution Explorer; if Solution Explorer is not already displayed, you can display it with the menu view | Solution Explorer.

![](img/59a3417a6d5906fae6d8000d4c2cff76_25_1.png)
**Figure 1-6:** Viewing your project with Solution Explorer

Solution Explorer has folders for both source and header files. The file in which the code for the "Hello World!" application will be written is a source file. Source files have a .cpp extension.

## Using an IDE to Create and Run the "Hello World!" Project

We will use Solution Explorer to add a source file to the project, after which we will write code in that source file. You can use the following steps to add a new source file:

- 1. Right-click Source Files in Solution Explorer. This will display a shortcut menu, shown in Figure 1-7.

![](img/59a3417a6d5906fae6d8000d4c2cff76_26_0.png)
**Figure 1-7:** Source Files shortcut menu

- 2. Choose Add | New Item from the shortcut menu to add a new source to the project. This will display the Add New Item dialog box, shown in Figure 1-8.

![](img/59a3417a6d5906fae6d8000d4c2cff76_26_1.png)
**Figure 1-8:** Adding a New Source File to Project

Note If the source file already exists, you can add it to your project using the Add | Existing Item shortcut menu.

- 3. Generally, you will not change the Location field, which is the subfolder in which the projects are stored. Type the name of the new source file in the Name field. You do not need to type the .cpp extension; extension will be appended automatically since it is a source file. By typing **hello**, as shown in Figure 1-8, the new file will be called hello.cpp.
- 4. When you are done, click the Open button. Figure 1-9 shows the new hello.cpp file in Solution Explorer.

![](img/59a3417a6d5906fae6d8000d4c2cff76_27_0.png)

Writing the code is easy. Double-click hello.cpp in Solution Explorer. As shown in Figure 1-10, this will display the hello.cpp file, which at this point is blank.

![](img/59a3417a6d5906fae6d8000d4c2cff76_28_0.png)
Now type your code. When finished, hello.cpp should appear as in Figure 1-11.

![](img/59a3417a6d5906fae6d8000d4c2cff76_28_1.png)
**Figure 1-11:** The source file after typing code

**Caution** You can also use Notepad or any other editor to write the code. However, do not use Microsoft Word or any other word processing program to write your code. While a word processing program enables you to neatly format your code, it does so using hidden characters that the compiler does not understand and will regard as syntax errors.

Save your work, such as by pressing the Save toolbar. We're now ready to compile.
