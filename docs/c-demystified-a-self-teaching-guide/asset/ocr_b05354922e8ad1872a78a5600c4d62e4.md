The following are the contents of the file after the inputted data was written to it:

Programming Demystified
32

The first read of the file did not read the first line of the file, "Programming Demystified." Instead, the first read of the file only read the word "Programming" and stopped. Consequently the second line of the program read the remainder of the first line of the file, "Demystified," instead of number of students.

The istream object with the stream extraction operator reads the file sequentially, starting with the first byte of the file. The first attempt to read the file starts at the beginning of the file and goes to the first whitespace character (a space, tab, or line) or the end of the file, whichever comes first. The second attempt starts at the first printable character and continues to the next whitespace character or the end of the file, whichever comes first.

The first attempt only read "Programming," not "Programming Demystified," because the read stopped at the whitespace between "Programming" and "Demystified." The second attempt read "Demystified." There were no further attempts, so the number of students, 32, was never read.

This should seem like déjà vu. We encountered a similar issue with extraction (>>). As in Chapter 10 using the cin object with the extraction operator (>>), the solution is to use getline.

If you are working with C-strings, then you should use the getline function. The only difference between using the getline function here and in Chapter 10 is that here the getline function is called by an istream or ofstream object instead of a cin object. Accordingly, we need to replace the two calls to infile >> ta data with the following:

```
getline(data, 80);
```

You can also use getline with the C++ string class. The only difference between the getline member function here and in Chapter 10 is that here the first argument of the getline member function is an istream or ofstream object of a cin object. Accordingly, we need to replace the two calls to infile >> data with the following:

```
getline(infile, data);
```
