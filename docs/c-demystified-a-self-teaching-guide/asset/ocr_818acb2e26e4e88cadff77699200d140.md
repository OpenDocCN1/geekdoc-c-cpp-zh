Combining the ios::in and ios::out flags changes expected defaults. The ios::out flag by itself causes an existing file to be overwritten, and the ios::in flag by itself requires that the file already exist. However, the ios::in and ios::out files are used together, the file's existing contents are preserved, and the file will be created if it does not exist.

Note

# Checking if the File Was Opened

You should not assume that a file was successfully opened with the open member function or the constructor. There are several reasons why the file may not have been successfully opened. If the file was not successfully opened, your code casually assumes it and attempts to read, or write to, the file, errors may occur.

The primary difference between opening a file for reading and for writing is that you can write to a file that does not exist—the operating system simply creates it—you cannot read from a file unless it already exists. Therefore, you should check if the file was opened successfully for reading before you attempt to read it.

If the file could not be opened for reading, the value of the istream object that called open is NULL. You may recall from Chapter 11 that NULL is a constant defined in standard library files whose value is zero.

Alternatively, if the file could not be opened for reading, the istream object's fail member function returns true, which is the function's return value if file operation, in this case attempting to open a file, was not successful.

The following code illustrates the use of both checking if the istream object used to call the open function is NULL and the istream object's fail member function returns true:

```
#include <fstream>
#include <iostream>
using namespace std;

int main ()
{
    ifstream infile;
    infile.open("students.dat");
    cout << "" << infile << " << " << endl;
    cout << "" << infile.fail() << " = " << infile.fail() << endl;
    return 0;
}
```

If the students.dat file does not exist, the output would be

```
(infile) = 00000000
(infile.fail()) = 1
```

However, if there was a named students.dat in the same directory as your program, then the output would be

```
(infile) = 0012FE40
(infile.fail()) = 0
```

The value, 0012FE40, is the address of the istream variable, and could be different if you run this program again.
