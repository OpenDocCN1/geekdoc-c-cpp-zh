# The Pointer as a Variable or a Constant

A pointer may be a variable or a constant. Let's examine both possibilities.

# Pointer as a Variable

The preceding program had the pointer pointing to one integer variable. However, a pointer variable, being a variable, can point to different variables at different times in the program. In the following program, the value of the pointer is changed to point to two different integers.

```
#include <iostream>
using namespace std;

int main () {
    int num1 = 5, num2 = 14;
    int* iPtr = &num1;
    cout << "The value of num1 is " << num1 << endl;
    *iPtr *= 2;
    cout << "The value of num1 after " *iPtr *= 2 is "
         << *iPtr << endl;
    iPtr = &num2;
    cout << "The value of num2 is " << num2 << endl;
    *iPtr /= 2;
    cout << "The value of num2 after " *iPtr /= 2 is "
         << *iPtr << endl;
    return 0;
}
```

The resulting output is:
The value of num1 is 5
The value of num1 after *iPtr *= 2 is 10
The value of num2 is 14
The value of num2 after *iPtr /= 2 is 7
