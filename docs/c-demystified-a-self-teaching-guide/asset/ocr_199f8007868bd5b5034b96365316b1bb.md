# Caution

A common mistake is to follow the integer expression not with a colon but a semicolon, which is typically used to terminate statements. This will cause a compiler error.

The default keyword serves the same purpose as an else part in an if /else /else statement, and is therefore not followed by an integer expression.

The integer expression following the switch keyword is evaluated and compared with the integer constant following each keyword, from top to bottom. If there is a match—that is, if two integers are equal—then the statements belonging to that case are executed. Otherwise, they are not. Thus, the statements belonging to a case are conditional, just as statements are in if, else, or else part. However, unlike an if /else statement, multiple conditional statements belonging to a case do not need to be enclosed in curly braces.

# Differences Between switch and if /else /else Statements

While a switch statement is similar to an if /else /else statement, there are important differences.

One difference is that in an if /else /else statement, the comparison following the if part may be independent of the comparison following the else part. While a bit silly, is illustrative of this concept:

```
if (apples == oranges)
  do;
else if (sales >= 5000)
  do;
```

By contrast, in a switch statement, the constant integer expression following a case keyword must be compared with the value following the switch keyword, and nothing else. The next chapter on logical operators discusses other differences between switch and if /else /else statements. However, two differences can be discussed now. One is commonly known as "falling through". Other concerns ranges of numbers.

# Falling Through

In an if /else /else statement, each part is separate from the others. By contrast, a switch statement (once a matching case is found) unless a break statement is executed, "falls through" to the case statements that execute their conditional statements without checking for a match. For example, if you removed the break statements from the switch, you could have the following run:

```
Enter your grade: A
Your average must be between 90 - 100
Your average must be between 80 - 89
Your average must be between 70 - 79
Your average must be between 60 - 69
Your average must be below 60
```

This "falling through" behavior is not necessarily. In the modification of the grade program, the falling-through behavior permits the user to enter a lower grade in addition to an uppercase grade.
