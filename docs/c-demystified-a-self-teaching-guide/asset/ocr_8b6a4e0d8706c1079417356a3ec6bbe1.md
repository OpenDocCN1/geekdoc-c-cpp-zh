# Declaring an Array

An array is a variable. Therefore, the other variables we have covered so far, an array must be declared before it can be used.

The syntax for declaring an array is almost identical to the syntax for declaring integers, characters, or other variables. For example, you would declare an integer variable testScore as follows:

```
int testScore;
```

By contrast, you would declare an array of three test scores this way:

```
int testScore[3];
```

This declaration contains an array of integers. You could instead declare an array of floats, characters, or strings in the following manner:

```
float GPA[5];
char grades[7];
string names[6];
```

While an array can be one of several data types, all the values in the particular array be of the same data type. You cannot have an array in which some elements are floats, others strings, still integers, and so on.

The declaration of a single variable and an array of variables begins with the data type followed by a variable name and ending with a semicolon. The only difference between declaring a variable that holds a single value and an array that is, when declaring an array, the variable name is followed by a number within square brackets. That is the array's size descriptor.

# Note

There is one exception to the necessity of having a size descriptor. As discussed later in this chapter in the section on "Initialization," the square brackets may be empty if you initialize the array when you declare it.

The purpose of the size descriptor is to tell the computer how much memory to reserve. The size descriptor, combined with the data type of the array, determines how much memory to reserve.

As you may recall from Chapter 3, the declaration of a variable reserves memory for the number of bytes required by the data type of that depending on the particular operating system and compiler. For example, an integer variable testScore would reserve 4 bytes. If instead you declared an array of three integer variables, then the amount of memory reserved by that declaration would be 12 bytes, 4*3.
