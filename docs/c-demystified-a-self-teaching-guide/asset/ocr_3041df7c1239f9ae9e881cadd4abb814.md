# # The ! Operator

The ! operator is also known as the logical Not Operator. My daughters have been using the logical Not for years, telling me "Dad, you just look like Tom Cruise ... not!"

The logical Not inverts the value of the Boolean expression, returning false if the Boolean expression is true, Table 6-4 illustrates this.

## Table 6-4: The Logical Not Operator

| Expression | !Expression |
|---|---|
| true | true |
| false | true |

Unlike the logical And and Or, the logical Not is a unary operator; it takes only one expression, not two.

The following program shows the use of the logical Not, combined with the logical And, in determining you get into a movie for free.

```
#include <iostream>
using namespace std;
int main(void){
    int age;
    cout << "Enter your age: ";
    cin >> age;
    if ((age >= 12 && age < 65)) {
        cout << "Admission is free";
    } else {
        cout << "You have to pay";
    }
    return 0;
}
```

This program is almost identical to the one used to illustrate the logical Or. The only difference is that the statement

```
if (age <= 12 || age >= 65)
```

is replaced by the statement

```
if (!(age > 12 || age < 65)
```

**Note** This is an illustration of DeMorgan's law, which is a rule of inference pertaining to the logical And, Or Not operators that are used to distribute a negative to a conjunction or disjunction. In this book, it is only referred to and not covered, in case you hear DeMorgan's mentioned in a programming class or other book, you will hear it first!
