The sample input and output could be
nEnter person's name: Jeff
Enter height in inches: 72
The person's name is Jeff Kent and height is 72

The two-argument constructor is called by the following declaration of a Person instance:
Person pl(strName, inches);

The parentheses are necessary because there are arguments. The arguments must be in the order the constructor is expecting. If the constructor expects the first argument to be a string and the second to be an integer, a compiler error will result if you declare the Person instance with the first argument being an integer and the second string.
