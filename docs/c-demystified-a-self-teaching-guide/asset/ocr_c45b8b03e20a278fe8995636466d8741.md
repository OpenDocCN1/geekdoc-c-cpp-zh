# The switch Statement

The switch statement is similar to an if /else if /else statement. It evaluates the value of an integer expression and then compares it to two or more values to determine which code to execute.

The following program shows a switch statement action in a program that determines your average based on your grade:

```
#include <iostream>
using namespace std;
int main(void)
{
    char grade;
    cout << "Enter your grade: ";
    cin >> grade;
    switch (grade)
    {
        case 'A':
            cout << "Your average must be between 90 - 100"
            << endl;
            break;
        case 'B':
            cout << "Your average must be between 80 - 89"
            << endl;
            break;
        case 'C':
            cout << "Your average must be between 70 - 79"
            << endl;
            break;
        case 'D':
            cout << "Your average must be between 60 - 69"
            << endl;
            break;
        default:
            cout << "Your average must be below 60" << endl;
    }
    return 0;
}
```
