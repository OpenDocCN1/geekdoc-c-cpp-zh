
## Assigning a "Compatible" Data Type

The data types in the cin statement may be different. In this example, the data type of the first variable is a string, whereas the data type of the second and third variables is an integer.

What is important is that the order of the input changes the order of the data types of the variables in the cin statement. The input order "Jeff," 200 is assigned to the variables in the order of their appearance in the cin statement, myName, myWeight, and myHeight. Therefore, "Jeff" is assigned to the string myName, 72 to the integer variable myWeight, and 200 to the integer variable myHeight.

The importance of the order of the input matching the order of the data types in the cin statement is demonstrated by changing the order of the user's input from "Jeff," 200, and 72 to 200, "Jeff," and 72. The program output then would be

```
Enter your name, weight in pounds and height in inches
The three inputs separated by a space
200 Jeff 72
Your name is 200
Your weight in pounds is -858993460
Your height in inches is -858993460
```

While I like to lose weight, -858993460 seems a bit extreme. Also, while it is understandable why "Jeff" cannot be assigned to my 72, nor was 72 assigned to my height.

The one output that is correct is the name. Characters, including digits, can be part of a string. Therefore, 200 may be an unusual name to us, it is perfectly OK for cin, which enforces 200 to the string variable *name*.

Why -858993460 was outputted for myWeight has also been explained earlier in the example where the user entered "Jeff" at the prompt to enter a test score.

However, 72 would be a valid value for cin to assignment to the integer variable *myHeight*. Why wasn't 72 the output for height?

The reason is that the next value for cin is not 72, but instead "Jeff." Since cin was unable to assign "Jeff" to *myWeight*, the value remains in line for assignment, to the variable *myHeight*. Unfortunately, cin was unable to assign "Jeff" to *myHeight* either, so the value of *myHeight*, like *myWeight*, is also outputted as -858993460.

## Summary

A variable serves two purposes. It provides you with a way of referring to particular information, and also reserves the amount of memory necessary to store that information.

You must create a variable before you start using it. You create a variable by declaring it. You may declare multiple variables of the same type in one statement.

You can use the address operator, &, to determine the address of a variable, and the sizeof operator to determine the size of a variable.

The purpose of a variable is to store information. Therefore, after you have created a variable, the next logical step is to specify the information that the variable will store. This is called *assigning* a value to a variable.

A variable can be assigned a value by the programmer in code or by the user, usually via the keyboard, when the program is running. You use the assignment operator to assign a value supplied by code. You use the cin object to assign a value supplied by the user.

In the next chapter, you will learn how to use variables to perform arithmetic.

## Arithmetic Operators

An operator is a symbol that represents a specific action. We have discussed operators in prior chapters, including the assignment operator, = C++ also supports operators for arithmetic, specifically addition, subtraction, multiplication, and division. Table 4-1 summarizes them.

### Table 4-1: Arithmetic Operators

| Operator | Purpose | Example | Result |
| :--- | :--- | :--- | :--- |
| + | Addition | 5 + 2 | 7 |
| - | Subtraction | 5 - 2 | 3 |
| * | Multiplication | 5 * 2 | 10 |
| / | Division (Quotient) | 5 / 2 | 2 |
| % | Division (Remainder) | 5 % 2 | 1 |

The % operator, also called the *modulus* operator, may look unfamiliar. It returns the remainder in division, and will be explained in the "Division" section later in this chapter.

Arithmetic operators are binary operators because they operate on two *operands*, binary being a reference to 2, and operand referring to the two values that in the arithmetic expression. For example, in the expression 5 + 2, the + sign is the operator, and the 5 and 2 each is an operand.

Not all operators are binary. For the expression -3, the negative sign, or negation operator, is a unary operator because it operates on only one operand, which is the integer 3 in this example. There are also ternary operators, which operate on 3 operands. However, all arithmetic operators involve two operands.

The arithmetic operator works with negative as well as positive numbers, and, with the exception of the modulus operator, floating point numbers (numbers with values to the right of the decimal point) as well as whole numbers. The addition operator also works with strings as well as numbers.
