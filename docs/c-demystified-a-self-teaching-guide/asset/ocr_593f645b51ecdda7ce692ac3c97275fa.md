# Useful Character Functions

The C++ standard library ctype contains a number of functions that are useful when working with characters. Two of these functions convert the case of a letter, either from lower to upper or vice versa. The other functions are used to test the value of a character.

# Case Conversion Functions

The toupper and towlower functions each have one argument. If the character represents a letter, A through Z or through z, the toupper function returns the upper case of that. Conversely, the towlower function returns the lower case of that. If the argument is not a letter, both functions return the same character that is the argument.

The toupper and towlower functions can be useful. For example, the following program from a previous section that requires you to check, both in if and a while condition, for an uppercase Q and a lowercase q to determine if the elected to quit:

```
#include <iostream>
using namespace std;

int main(void)
{
    char ch;
    do {
        cout << "Press Q or q to quit, any other key to continue";

        cin.get(ch);
        if (ch != '\n')
            cin.ignore();
        if (ch == 'Q' && ch != 'q')
            cout << "You want to continue?\\n";
        else
            cout << "You quit";
    } while (ch != 'Q' && ch != 'q');
    return 0;
```
