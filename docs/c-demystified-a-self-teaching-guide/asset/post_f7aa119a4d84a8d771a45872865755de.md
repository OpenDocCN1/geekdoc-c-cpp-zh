
The converse of overflow is underflow. Underflow occurs when a variable is assigned a value too small for its range. The output of the following code is "Your test score is 32767." The value assigned, -32769, is 1 too small for the data type. Therefore, the value underflows and wraps around to the data type's highest possible value, 32767.

```cpp
#include <iostream>
namespace std;
int main() {
    short testScore;
    testScore = -32769;
    cout << "Your test score is " << testScore << "\n";
    return 0;
}
```

Additionally, an attempt to assign to testScore -32770, which is 2 too small for the short data type, would result in an output of 32766, and an attempt to assign to testScore -32771, which is 3 too small for the short data type, would result in an output of 32765, and Figure 3-3 illustrates how the underflow is reached.

Floating-point variables, the float or double data type, may also overflow or underflow. However, the result depends on the compiler used, and may be a runtime error occurring during your program, or instead an incorrect result.

# Using the cin Object

Thus far the programmer has supplied the values that are assigned to variables. Most programs are interactive, asking the user to provide information, which the user then inputs, usually by the keyboard.

In Chapter 1, we used the cin object to output information to a standard output, usually the monitor. Now we will use the cin object to obtain information from standard input, which is usually the keyboard. The cin object, like the cout object, is defined in the standard library file <iostream>, which therefore must be included (with an include directive) if you use cin.

The syntax of a cin statement is `cin >> [variable name];`.

The cin object is followed by >>, which is the stream extractor operator. It obtains the input, usually from the keyboard, and assigns that input to the variable to its right.

# Assigning Values to Variables

> Tip Knowing when to >> instead of << can be confusing. It may be helpful to remember that the >> and << operators point in the direction that data is moving. For example in the expression `>> var`, data is moving from standard input into the variable. By contrast, in the expression `<< var`, the << indicates data is moving from the variable to standard output.

When your program reaches a cin statement, its execution halts until the user types something at the keyboard and presses the ENTER key. Try running your program with a blinking cursor until you type a number. Once you type a number and press ENTER, the program will output "Your test score is " followed by the number you inputted. For example, if you input 100, the output will be "Your test score is 100."

```cpp
#include <iostream>
using namespace std;
int main(void) {
    int testScore;
    cin >> testScore;
    cout << "Your test score is " << testScore << "\n";
    return 0;
}
```

This program is not very friendly. Unless the user happened to know what your program did, they would not know what information is being asked of them. Accordingly, a cin statement is preceded by a cout statement telling the user what to do. This is called a prompt.

```cpp
#include <iostream>
using namespace std;
int main(void) {
    int testScore;
    cout << "Enter your test score: ";
    cin >> testScore;
    cout << "Your test score is " << testScore << "\n";
    return 0;
}
```

The program input and output could be:
Enter your test score: 78
Your test score is 78

# Assigning a “Compatible” Data Type

As with the assignment operator, the value assigned by the cin operator need not necessarily be the exact same data type as the variable to which the value is being assigned. In the previous example, a floating-point variable, 77.83, at the prompt for entry of the test score results in the following output: "The test score is 77." Data lost, specifically the part of the number to the right of the decimal point. The cin statement will not read the part to the right of the decimal point because it cannot be stored in a whole variable.

However, the value assigned by the cin operator must be compatible with the type of variable to which the value is being assigned. In programming typing, typing "Jeff" at the prompt for the test score results in the following output: "Your test score is -858993460."

Obviously, -858993460 is not a test score anyone would expect. Less obvious is the reason why that number is outputted.

The string literal "Jeff" cannot be assigned to an integer variable as testScore. Therefore, the cin operator will not assign "Jeff" to that integer variable. Therefore, when the code statement outputs the value of testScore, the variable has not yet been a value.

When testScore was declared, there was some value at its memory address left over from programs previously run on the computer. The code statement, when trying to output the value of testScore, the best it can is attempt to interpret this leftover. The result of that interpretation is -858993460.

Note Compile time vs. Run-Time Difference When Incompatible Data Types Are Assigned—Error in this chapter, the attempt to assign "Jeff" to testScore `testScore = "Jeff"` results in a compiler error. Here, the attempt to assign "Jeff" to testScore using a cin statement results in an incorrect value. The reason that this time there is no compiler error is because the value the user would not know at compile time, but instead would be known only at run time. Therefore, there would be no compile error, since there was no attempt to assign an incompatible value.

# Inputting Values for Multiple Variables

If you are inputting values for several variables, you could input them one at a time.

```cpp
#include <iostream>
using namespace std;
int main(void)

    cout << "Enter your name: ";
    cin >> myName;

    cin >> myWeight;
    cout << "Enter your height in inches: ";

}
```

The output of the program, with:
Enter name: Jeff
Enter weight in pounds: 200
Enter height in inches: 72
Your name is Jeff
Your weight in pounds is 200
Your height in inches is 72

Instead of having separate prompts and cin statements for each variable, you can have one statement to assign values to three variables. The syntax is `cin >> [first variable] >> [second variable] >> [third variable];`.

# Assigning Values to Variables

The same syntax would work when using one cin statement to assign values to four or more variables. The variables are separated by the stream extractor >>. When you use one cin statement to assign values to multiple variables, the user separates each input by one or more spaces. The following program uses one cin statement to assign values to three variables:

```cpp
#include <iostream>
using namespace std;
#include <string>
int main(void) {
    int myWeight, myHeight;
    string name;
    cout << "Enter your name, weight in pounds and height in inches\n";
    cout << "The three inputs should be separated by a space\n";
    cin >> name >> myWeight >> myHeight;
    cout << "Your name is " << name << "\n";
    cout << "Your weight in pounds is " << myWeight << "\n";
    cout << "Your height in inches is " << myHeight << "\n";
    return 0;
}
```

The interaction between user and the cin statement could be as follows:

- The user uses "Jeff", followed by a space. The space tells the cin object that the first input has ended, so the cin object will assign "Jeff" to the first variable in the cin statement, *name*.
- The user uses 200, followed by a space. The space tells the cin object that the second input has ended, so the cin object will assign 200 to the next variable in the cin statement, *myWeight*.
- The user type 72, and then press the ENTER key. The ENTER tells the cin object that the third and final input has ended, so the cin object will assign 72 to the remaining variable in the cin statement, *myHeight*, which completes execution of the cin statement.
