Similarly, you read information from a file into your program using the stream extraction operator (>>) just as you use that operator to input information from the keyboard, except that you use an istream (or fstream) object instead of the cin object.

You read a line of a file using the getline member function if you are working with C-strings or the getline function you use the fail member function to test for the end of the file as you read line by line through a file.

File stream objects may be passed as function arguments. They should be passed by reference rather than by value since the internal state of a file stream object may change with an open operation even if the contents of the file have not changed.
