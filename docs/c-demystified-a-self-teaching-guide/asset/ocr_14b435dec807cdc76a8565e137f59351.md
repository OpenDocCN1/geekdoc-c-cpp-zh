old. This approach is logical, since if the user is not at least 18 years old, they will not be eligible to vote even if they are a citizen.

The if / else structure comparing whether the user is referred to as the "inner" / else structure. The if / else structure comparing whether the user is at least 18 years old is referred to as the "outer" / else structure.

The entire if / else structure (comparing whether the user is a citizen) is nested within the part of the outer / else structure (comparing whether the user is at least 18 years old). You can also nest an if / else structure (or an if structure, or an /else /else structure) within the if / else or part of an outer/else if/else structure.

This program illustrates a use of nested statements. It would be difficult to rewrite this program using if / else / else structure without nested statements. However, later in this chapter we will cover another, equally good alternative: logical operators.

# Testing If Boolean Expression Is True

The following program shows the use of the nested statements in determining if either of Two expressions are true. If the user's input indicates that they are neither more than 12 years old or at least 65 years old, the program outputs that their admission is free.

```
#include <iostream>
using namespace std;
int main(void)
{
    int age;
    cout << "Enter your age: ";
    cin >> age;
    if (age > 12)
        if (age >= 65)
            cout << "Admission is free";
        else
            cout << "You have to pay";
    else
        cout << "Admission is free";
    return 0;
}
```
