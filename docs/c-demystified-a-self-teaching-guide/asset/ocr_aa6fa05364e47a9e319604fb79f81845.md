# The if / else / else Statement

The program we used to illustrate the if/else statement involved two alternatives. Additionally, these alternatives were mutually exclusive; only one could be chosen, not both. A number is either even or odd; it cannot be both and there is no third alternative. There are many other examples of two mutually exclusive. For example, a person is either dead or alive, male or female, child or adult.

However, there are other scenarios where there are more than two, mutually exclusive alternatives. For example, if you take a test, your grade might be one of five types: A, B, C, D, or F. Additionally, these grades are mutually exclusive; you can't get an A and a C on the same test.

Since you can have only one expression and only one else expression in an statement, you need another expression for the third and additional alternatives. That expression is else.

You use the if / else / else statement when there are three or more mutually exclusive alternatives. The if/else statement has an if part and an else part, like an if/else statement. However, it also has one or more else parts.

> Note While the if part is required, the else part is not. Without it, the statement would be named an if / else statement.

The else if works similarly to an if expression. If the else keywords are followed by a relational expression. If the expression is true, the conditional statement or statements "belonging" to the if execute. Otherwise, they don't.

While an else statement may include only one if part and one else part, it may include multiple else parts.

The following program shows the if / else / else statement action in a program that determines your grade based on your test score.

```
#include <iostream>
using namespace std;
int main(void)
{
    int testScore;
    cout << "Enter your test score: ";
    cin >> testScore;
    if (testScore >= 90)
        cout << "Your grade is an A" << endl;
    else if (testScore >= 80)
        cout << "Your grade is a B" << endl;
    else if (testScore >= 70)
        cout << "Your grade is a C" << endl;
    else if (testScore >= 60)
        cout << "Your grade is a D" << endl;
    else
        cout << "Your grade is an F" << endl;
    return 0;
}
```
