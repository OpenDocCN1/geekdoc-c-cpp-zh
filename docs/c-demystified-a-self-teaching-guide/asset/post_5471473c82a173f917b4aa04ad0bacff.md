
## Initialization

As first discussed in Chapter 3, initialization is when you assign a value to a variable in the same statement that you declare that variable. By contrast, assignment is when you assign a value to a variable in a statement after the one in which you declare that.

We will discuss assigning values to an array later in this chapter in the "Assigning and Displaying Array Values." This section covers initialization of an array.

You have two alternative methods of initializing an array. The first alternative is explicit array sizing, in which the brackets contain a numerical constant that specifies the size of the array. The second alternative is implicit array sizing, in which the square brackets are empty and the size of the array is indicated implicitly by the number of elements on the right side of the assignment operator.

## Explicit Array Sizing

The following are examples of explicit array sizing:

```
int testScore[3] = { 74, 87, 91 };
float milesPerGallon[4] = { 44.4, 22.3, 11.6, 33.3 };
char grades[5] = { 'A', 'B', 'C', 'D', 'F' };
string strings[7] = { "Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday" };
```

The syntax of initialization, with explicit and implicit array sizing, is that the declaration, as testScore[3]; is followed by an assignment operator and then, enclosed in curly braces, the values to assign to each array, in order, are separated by commas. For example, in the following statement, the value of the first element of the array (testScore[0]) would be 74, the value of the second element of the array 87, and the value of the third element of the array 91.

```
int testScore[3] = { 74, 87, 91 };
```

The number of elements on the right-hand side of the assignment operator cannot be greater than the number within the square brackets. The following statement will not compile, the error message being "many initializers".

```cpp
float milesPerGallon[4] = { 44.4, 22.3, 11.6, 33.3, 7.4 }; // won't compile
```

You do not have to assign values to each element of the array; the number of elements on the right-hand side of the assignment operator may be less than the number within the square brackets:

```cpp
float milesPerGallon[4] = { 44.4, 22.3, 11.6 };
```

If you do not initialize all the elements of an array, the uninitialized elements have a default value depends on the data type of the array. For example, the default value is 0 for an integer array, 0.0 for a float array, and the null character, '\0', for a character array.

> Note: The null character is discussed later in this chapter in the section "Initializing a Character Array."

Additionally, if you leave an element uninitialized, all elements that follow it must be uninitialized. You can't, for example, alternate initializing and not initializing array elements. For example, the following statement won't compile:
```cpp
float milesPerGallon[4] = { 44.4, , 11.6, 33.3 }; // won't compile
```

## Implicit Array Sizing

The following are examples of array sizing:
```cpp
int testScore[] = { 74, 87, 91 };
float milesPerGallon[] = { 44.4, 22.3, 11.6, 33.3 };
char grades[] = { 'A', 'B', 'C', 'D', 'F' };
string strings[] = {"Sunday","Monday","Tuesday","Wednesday","Thursday","Friday","Saturday"};
```

The first array, *testScore*, allocates memory for three integers. Since the square brackets are blank, the compiler allocates memory based on the number of elements to the right side of the assignment statement.

Similarly, the second array, *milesPerGallon*, allocates memory for four floats, the third array, *grades*, allocates memory for five characters, and the fourth array, *days*, allocates memory for seven strings.

The compiler only allocates memory based on the number of elements to the right side of the assignment statement if square brackets are empty. Otherwise, memory is allocated based on the number in the square brackets. Thus, in the example, the declaration of the array *testScore* would allocate memory for five integers even though only three are in the initialization statement because memory allocation is determined by the number within the square brackets. As discussed in the previous section, the fourth and fifth elements of the array would be initialized to a default value, 0.

```cpp
int testScore[] = { 74, 87, 91 };
```

However, you must tell the compiler how much memory to allocate. Therefore, when declaring an array, you cannot have both empty brackets and no initialization, as in the following example:
```cpp
int testScore[] = {};
```

The compiler error message will be that the array is of unknown size. This is a problem because the computer has no knowing of how much memory to allocate for the array.

## Initializing a Character Array

As showed the previous section, you can initialize a character array using the same syntax as you would initialize an array of any other data type as an integer or a float. As you will see in this chapter, there are some important differences between character arrays and arrays of numeric data. This section will show you your first difference.

The two initializations of a character array to my first name are different in syntax but identical in effect:

```cpp
char name[] = { 'J', 'e', 'f', 'f', '\0' };
char name[] = "Jeff";
```

The latter syntax usually is preferred by programmers simply because it is easier to type.

The character '\0' is the escape sequence for a null character. The 0 in '\0' is a zero, not a big letter o. The zero corresponds to the ASCII value of the null character.

Chapter 2 introduced escape sequences, with '\n', the newline character, which causes the cursor to go to the next line for further printing. The '\n' in a string is displayed literally because the backslash shows that '\n' is an escape sequence.

The null character has a different purpose, which is to signal when to end the output of a character array. For example, the following program outputs, as expected, "Jeff":

```cpp
#include <iostream>
using namespace std;
int main ()
{
    char name[] = {'J', 'e', 'f', 'f', '\0' };
    cout << name;
    return 0;
}
```

```cpp
