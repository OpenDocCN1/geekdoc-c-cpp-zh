
```cpp
cout << "The value of iPtr is " << iPtr << endl;
return 0;
```

Note You could also use initialization instead of declaration followed by assignment, combining the first two statements in int* iPtr = NULL.

The resulting output is
The address of x using iPtr is 00000000

A pointer that is using NULL is called a null pointer.

On most operating systems, programs are not permitted to access memory at address 0 because that memory is reserved by the operating system. You may be thinking: "Wait a minute! He just told me it was to risk having pointers to memory addresses reserved by the operating system. Now he's having us do that on purpose." However, the address has special significance; if the pointer is not intended to point to an accessible location. Thus, if it is too early in your code to know which address to assign to a pointer, you should first assign the pointer to NULL, which makes it safe to access the value of a pointer before it is assigned "real" value such as the address of another variable or constant.

# Assigning a Pointer the Address of a Variable or Constant

Let's assign a "real" value, the address of another variable or constant. To do so, you need to access the address of the variable or constant before you can assign that address to the pointer. You use the address operator, covered in Chapter 3, to accomplish this task.

The following program shows how to use the address operator to assign the address of a variable to a pointer. This program also demonstrates that the value of a pointer is the same as the address to which the pointer points.

```cpp
#include <iostream>
using namespace std;

int main() {

    int num = 5;
    int* iPtr = &num;
    cout << "The address of x using num is " << &num << endl;
    cout << "The address of x using iPtr is " << iPtr << endl;
    return 0;
}
```

The output on your computer (the following addresses likely will be different on yours)
The address of x using num is 0012FED4
The address of x using iPtr is 0012FED4

# Indirection Operator and Dereferencing

The primary use of a pointer is to access and, if appropriate, change the value of the variable that the pointer is pointing to. In the following program, the value of the integer variable `num` is changed twice.

```cpp
#include <iostream>
using namespace std;

int main () {
    int num = 5;
    int* iPtr = &num;
    cout << "The value of num is " << num << endl;
    num = 10;
    cout << "The value of num after num = " << num << endl;
    *iPtr = 15;
    cout << "The value of num after *iPtr is " << *iPtr << endl;
    return 0;
}
```

The resulting output is
The value of num is 5
The value of num after num = 10 is 10
The value of num after *iPtr = 15 is 15

The first change should be familiar, the direct assignment of a value to `num`, such as `num = 10`. However, the second change is accomplished a new way, using the indirection operator:
**iPtr = 15;**

Note As mentioned earlier in chapter, this is an example of a symbol having different meanings in the C++ programming language depending on the context in which it was used.

The placement of the indirection operator before a pointer is to dereference the pointer. The value of a dereferenced pointer is not an address, but rather the value at that address—that is, the value that the pointer points to.

For example, in the preceding program, `iPtr`'s value is the address of `num`. However, the value of `iPtr` dereferenced is the value of `num`. Thus, the following two statements have the same effect, both changing the value of `num`:

```cpp
num = 25;
*iPtr = 25;
```

Similarly, a dereferenced pointer can be used in arithmetic expressions the same as the variable to which it points. Thus, the following two statements have the same effect:

```cpp
num *= 2;
*iPtr *= 2;
```

In these examples, changing a variable's value using the indirection operator rather than through a straightforward assignment seems like an unnecessary complication. However, there are instances covered later in this chapter, such as looping through an array using a pointer, or using dynamic memory allocation, in which the indirection operator is helpful or even necessary.

# The Pointer as a Variable or a Constant

A pointer may be a variable or a constant. Let's examine both possibilities.

# Pointer as a Variable

The preceding program had the pointer pointing to one integer variable. However, a pointer variable, being a variable, can point to different variables at different times. In the following program, the value of the pointer is changed to point to different integers.

```cpp
#include <iostream>
using namespace std;

int main () {
    int num1 = 5, num2 = 14;
    int* iPtr = &num1;
    cout << "The value of num1 is " << num1 << endl;
    *iPtr *= 2;
    cout << "The value of num1 after *iPtr *= 2 is " << *iPtr << endl;
    iPtr = &num2;
    cout << "The value of num2 is " << num2 << endl;
    *iPtr /= 2;
    cout << "The value of num2 after *iPtr /= 2 is " << *iPtr << endl;
    return 0;
}
```

The resulting output is:
The value of num1 is 5
The value of num1 after *iPtr *= 2 is 10
The value of num2 is 14
The value of num2 after *iPtr /= 2 is 7

# The Array Name as a Constant

While the pointer may be a variable, it may also be a constant. Indeed the previous chapter actually discussed a constant pointer: the name of an array. As you may recall from Chapter 10, the value of an array is the base address of the array, which is also the address of the first element of an array. Thus, in the following program, `testScore` and `testScore[0]` have the same value.

```cpp
#include <iostream>
using namespace std;
const int MAX = 3;

int main () {
    int testScore[MAX] = {4, 7, 1};
    cout << "The address of the array is " << testScore << endl;
    cout << "The address of the first element of the array is " << &testScore[0] << endl;
    cout << "The value of the first element of the array is " << *testScore << endl;
    cout << "The value of the first element of the array is " << testScore[0] << endl;
}
```

The resulting output
The address of the array using testScore is 0012FECC
The address of the first element of the array using &testScore[0] is 0012FECC
The value of the first element of the array using *testScore is 4
The value of the first element of the array using testScore[0] is 4

Similarly, if you dereference the name of an array, its value is the same as the value of the first element of the array. Therefore, in the preceding program, both `testScore` and `testScore[0]` have the same value. However, you cannot change the value of the name of the array. For example, a statement such as `testScore++` would result in a compiler error, the error message being "++ needs l-value." As you recall from Chapter 10, the term l-value refers to the value to the left of the assignment operator. This error message is another way of saying you cannot increment a constant because that would be changing the value of a constant after you declare it.

# Pointer Arithmetic

The value of a pointer, even though it is an address, is a numeric value. Therefore, you can perform arithmetic operations on a pointer just as you can a numeric value.

# Using a Variable Pointer to Point to an Array

Pointer arithmetic is done often with arrays. However, since you cannot change the value of the name of an array, being a constant pointer, you should first declare a variable pointer and assign it to the address of an array.

So, we begin with an established point of reference, let's start with the following program, which outputs the address and value of each element of an array using the name of the array:

```cpp
#include <iostream>
using namespace std;
const int MAX = 3;
int main () {
    int testScore[MAX] = {4, 7, 1};
    for (int i = 0; i < MAX; i++) {
        cout << "The address of index " << &testScore[i] << endl;
        cout << "The value at index " << testScore[i] << endl;
    }
    return 0;
}
```

The resulting output is

The address of index 0 of the array is 0012FECC
The value at index 0 of the array is 4
The address of index 1 of the array is 0012FED0
The value at index 1 of the array is 7
The address of index 2 of the array is 0012FED4
The value at index 2 of the array is 1

This program used the name of the array, testScore, to access, by index, each element of the array. The name of array is a constant pointer. The following program modifies the previous program by using a variable pointer, *iPtr, to access by index each element of the array.

```cpp
#include <iostream>
using namespace std;
const int MAX = 3;
int main () {
    int testScore[MAX] = {4, 7, 1};
    int* iPtr = testScore;
    for (int i = 0; i < MAX; i++) {
        cout << "The address of index " << (iPtr + i) << endl;
        cout << "The value at index " << *(iPtr + i) << endl;
    }
    return 0;
}
```
