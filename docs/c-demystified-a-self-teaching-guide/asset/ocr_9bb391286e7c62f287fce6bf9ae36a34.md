# # Summary

Data is persistent when it survives the program is finished or even after the computer is turned off. Data stored in variables does not persist because RAM, where the variables are stored, is cleared when the program (or the computer) starts running. It is necessary to save data to a file on the computer's hard drive or other storage medium so that later can be retrieved when needed.

This chapter showed you how to make data persistent by saving it to a file. Since saving the data accomplishes little unless you can retrieve it, this chapter also showed you how to retrieve data from a file.

A file is a collection of data. It is located on persistent storage, such as a hard drive, CD-ROM, or other storage device.

Files store data in one of two formats, text and binary. Text files store data that has been converted into strings of ASCII characters. By contrast, binary files store data in the same format in which data is stored in RAM, fundamentally and zeroes. Notepad and other plain-text editors use text files. Binary files store more complex data, and are used in more complex programs, such as word processing, spreadsheet, or database programs.

You should include the *fstream* standard library defines when your program reads from, or writes to, files. This standard defines three data types. The *ofstream* data type represents the output stream, the direction of output being from your program out to a file. The *lstream* data type represents the input stream, the direction of input being from a file into your program. The *fstream* data type represents the file stream generally, and has the capabilities of both *ofstream* and *lstream* in that may both write information to files and read information from files.

The process of accessing a file, whether to read it, write to it, or both, goes through the following steps. First, the file must be opened to establish a path of communication between the file and the stream object in your program—*ifstream*, *ofstream*, or *fstream*—used to access the file. Second, your program reads from or writes to the file. Third, and finally, your program closes the file, using the *close* member function, to free system resources that are required to maintain the path of communication between the file and the stream object in your program, and to avoid a “sharing” problem caused by threading in one part of your program to open a file that another part of the program previously opened but not closed.

You use either the *open* member function or a constructor to open a file. A constructor is a function that is automatically called when you attempt to create an *instance* of an object, such as an *ifstream*, *ofstream*, or *fstream* object. Either the open member function or constructor may use two arguments. The first argument is the relative or absolute path to the file. The second argument, which may be optional, is one or more file mode flags, which define how the file should be opened, for input, output, appending, or something else.

You cannot assume that a file was successfully opened for reading or writing. You can check using the *fail* member function to check if a file was successfully opened. You can also check if the file object used is NULL.
