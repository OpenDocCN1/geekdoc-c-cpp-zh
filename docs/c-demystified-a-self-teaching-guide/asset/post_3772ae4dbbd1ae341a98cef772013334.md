# Separating the Constructor Prototype and Implementation

The following code modifies the previous program by separating the prototype of the constructors from the implementation of the constructors. The prototypes are inside the declaration of the structure. However, the implementations are outside of the structure:

```cpp
#include <iostream>
#include <string>
using namespace std;
const int MAX = 3;
struct Person {
    string name;
    int height;
    Person(string s, int h);
};
```

```cpp
Person::Person()
{
    name = "No name assigned";
    height = -1;
}
Person::Person(string s, int h)
{
    name = s;
    height = h;
}
```

```cpp
int main()
{
    int inches;
    string strName;
    cout << "Enter person's name: ";
    getline(cin, strName);
    cout << "Enter height in inches: ";
    cin >> inches;
    cin.ignore();
    Person pl(strName, inches);
    cout << "The person's name is "
    << pl.name << " and height is "
    << pl.height << endl;
    return 0;
}
```

In the function header of each of the constructors, the function name is preceded by the class name and the resolution operator (::):

```cpp
Person::Person(string s, int h)
```

While the preceding discussion could explain how you can separate the prototype and implementation of the constructors, the question thus far unanswered is why. The reason is in OOP—one principle is to separate what a function does from how it does it. This enables programmers to later improve how a function does its job without affecting the function's signature (arguments and return value) on existing programs using the function.

# Passing Structures as Function Arguments

The following program passes a Person structure instance as an argument to two functions. The setValues function assigns values to the member variables of the instance, whereas the getValues function outputs the values of the member variables of the structure:

```cpp
#include <iostream>
#include <string>
using namespace std;
struct Person {
    string name;
    int height;
};
```

```cpp
void setValues(Person&);
void getValues(const Person&);
```

```cpp
int main ()
{
    Person p1;
    setValues(p1);
    cout << "Outputting person data\n";
    cout << "==================\n";
    getValues(p1);
    return 0;
}
```

```cpp
void setValues(Person& pers)
{
    cout << "Enter person's name: ";
    getline(cin, pers.name);
    cout << "Enter height in inches: ";
    cin >> pers.height;
    cin.ignore();
}
```

```cpp
void getValues(const Person& pers)
{
    cout << "Person's name is " << pers.name
         << " and height is " << pers.height << endl;
}
```

The following is some sample input and output:
nEnter person's name: Genghis Khent
Enter height in inches: 78
Outputting person data
==================
Person's name: Genghis Khent
Person's height in inches: 78

Unlike an array, a structure's value is not an address. Therefore, to change the values of its member variables when passing a structure as a function argument, the structure needs to be passed by reference or by address. Therefore, in the setValues function, which changes the member variables of the structure passed to, it is passed by reference.

However, the structure is also passed by reference to the getValues function even though the function does not change the value of its member variables. The reason is that less memory is required to pass the address of an object than the object itself, which may take a lot of bytes. However, here the structure instance in the getValues function's argument list is preceded with the const keyword to prevent the function from inadvertently changing the values inside the structure instance.

# Nested Structures

In previous chapters, we have nested if statements within if statements, and loops within loops. You may also nest a structure within another structure.

Of course, your mother may have told you (or at least tell me) "Just because you can do something doesn't mean you should do it." Here, however, nesting structures is a good idea.

Using our Person structure example, every person has a birthday. A birthday is a date. In turn, may be defined by a structure that contains three members, all integers, which represent the month, day, and year of the particular date. The Date structure could be declared as follows:

```cpp
struct Date
{
    int month;
    int day;
    int year;
};
```

The Person structure declaration would then be modified to add a member variable, of the structure named, bDay, to represent the person's birthday:

```cpp
struct Person {
    string name;
    int height;
    Date bDay;
};
```

The following code modifies the previous one by adding the Date structure and the bDay Date member to the Person structure, as well as modifying the setValues function to assign a value to the bDay member variable and the getValues function to output the value of that member variable:

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Date
{
    int month;
    int day;
    int year;
};

struct Person {
    string name;
    int height;
    Date bDay;
};

void setValues(Person&);
void getValues(const Person&);

int main()
{
    Person p1;
    setValues(p1);
    cout << "Outputting person data\n";
    cout << "==================\n";
    getValues(p1);
    return 0;
}

void setValues(Person& pers)
{
    cout << "Enter person's name: ";
    getline(cin, pers.name);
    cout << "Enter height in inches: ";
    cin >> pers.height;
    cin.ignore();
    cout << "Enter month, day and year of birthday separated by spaces: ";
    cin >> pers.bDay.month >> pers.bDay.day >> pers.bDay.year;
    cin.ignore();
}

void getValues(const Person& pers)
{
    cout << "Person's name is " << pers.name << " " << endl;
    cout << "Person's height in inches is: " << pers.height << endl;
    cout << "Person's birthday in mm/day/yyyy format is: " <<
    << pers.bDay.month << "/" << pers.bDay.day << "/" << pers.bDay.year << endl;
}
```

The following is sample input and output:
nEnter person's name: Genghis Khent
Enter height in inches: 78
Enter month, day and year of birthday separated by spaces: 3 4
1211
Outputting person data
==================
Person's name: Genghis Khent
Person's height in inches is: 78
Person's birthday in mm/day/yyyy format is: 3/4/1211

The Date structure must be declared before the Person structure. Otherwise, the compiler not know what Date was in the declaration of the bDay member variable of the Person structure.

The setValues function sets the value of the person's birthday. It cannot do by:
cin >> pers.bDay

The reason is that bDay is not an integer that can be assigned input of an integer. Instead, itself is also a structure. It is necessary to drill down into the member variables of bDay, month, day, and year, as in the following statement:
cin >> pers.bDay.month >> pers.bDay.day >> pers.bDay.year;

Similarly, the getValues function cannot output the person's birthday with the statement:
cout << pers.bDay;

Instead, it must also drill down into the member variables bDay, month, day, and year, as in the following statement:
cout << "Person's birthday in mm/day/yyyy format is: "
<< pers.bDay.month << "/" << pers.bDay.day << "/" << pers.bDay.year << endl;
