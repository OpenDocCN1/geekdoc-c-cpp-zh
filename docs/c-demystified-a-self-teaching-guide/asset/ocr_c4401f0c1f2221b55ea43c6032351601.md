Note The % (modulus) operator is used if the remainder is 0, 13, or a multiple of 13 items.

While this use of the continue keyword works certainly, as I cautioned in Chapter 7, you should use it (as well the break keyword) sparsely. Each iteration of a for loop has one end point. However, when you use a continue statement, each iteration has multiple points. This makes your code more difficult to understand, and can result in logic errors.
