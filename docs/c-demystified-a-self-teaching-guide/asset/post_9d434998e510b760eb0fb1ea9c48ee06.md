## Combined Assignment and Arithmetic Operator

New programmers are confused by statements such as total = total + added because, in mathematics, a variable cannot equal plus another. However, this statement is not made in mathematics, but in C++ programming, in which the = operator is not used for equality, instead for assignment.

Nevertheless, there is also another way to express total = total + added:
total += added;

To the compiler, it makes no difference which total = total + added or total += added. However, many programmers prefer total += added, because it looks more elegant, others it seems more readable, and still for the practical reason that it requires less typing.

This compact of combining arithmetic and assignment operators is not limited to the addition operator. In Table 4-2 shows, it can also be used with the other arithmetic operators. In that, it is assumed a is previously declared integer variable.

## Table 4-2: Combining Arithmetic and Assignment Operators

| Statement | Combining Operators |
| --- | --- |
| a = a + 2; | a += 2; |
| a = a - 2; | a -= 2; |
| a = a * 2; | a *= 2; |
| a = a / 2; | a /= 2; |
| a = a % 2; | a %= 2; |

# Precedence Between Arithmetic Assignment Operators

The statement total = total + added uses two operators, assignment and arithmetic. The arithmetic operation has precedence over the assignment operation. This means the addition is performed before the assignment. This makes more sense intuitively than the other order. However, as I will explain in detail this chapter, precedence also arises when more than one operator is used in a statement, and there the correct order is less intuitive.

# Adding Strings

While we think of adding numeric operands, the addition operator can also be used with string operands. The output of the following code is: "Your name is JeffKent."

```cpp
#include <iostream>
#include <string>
using namespace std;
int main(void)
{
    string firstName = "Jeff";
    string lastName = "Kent";
    cout << "Your name is " << firstName + lastName;
    return 0;
}
```

Adding two strings has the effect of appending the second string operand to the first string operand. Adding means adding the content of the second string to the end of the first string.

While you can add numbers and numbers, or strings and strings, attempting to add a number and a string will cause a compiler error. The addition operator may perform arithmetic with two numeric operands, or appending with two string operands, but it does not know how to add a numeric operand and a string operand.

# The Subtraction Operator

At the community college where I teach, students leave the class as join it. Some of the prereistered students never show up. Other students who show up later decide to drop the course.

The following program builds on the one we used with the addition operator by adding one integer variable, dropped for students who I dropped because they never showed up, or who dropped themselves from the course. The dropped variable is assigned a value by the user. The program uses the subtraction operator to update total.

```cpp
#include <iostream>
using namespace std;
int main(void)
{
    int total, dropped;
    cout << "Enter number of pre-registered students: ";
    cin >> total;
    cout << "Enter number of students adding the course: ";
    cin >> added;
    total = total + added;
    cout << "How many students dropped? ";
    cin >> dropped;
    total -= dropped;
    cout << "Total number of students: " << total << endl;
    return 0;
}
```

The input and output of the program could be

Enter number of pre-registered students: 30
Enter number of students adding the course: 3
How many students dropped? 5
Total number of students: 28

In this example, we used the combined assignment and arithmetic operator -= in the expression total -= dropped, rather than total = dropped. As explained with the addition operator, either alternative will work the same way.

The effect of overflow and underflow are same with the subtraction operator as with the addition operator. However, unlike the addition operator, the subtraction operator will not work with string operands.

# The Multiplication Operator

Returning to my community college example, all students who enroll in a course owe a tuition of $72, even if they don't show up or later drop the course.

The following program builds on the one we used with the addition operator by adding the following:

```cpp
cout << "Total tuition owed: $" << (total + dropped) * 72;
```

The program now reads

```cpp
#include <iostream>
using namespace std;
int main(void)
{
    int total, added, dropped;

    cin >> total;
    cout << "Enter number of students adding the course: ";

    cout << "How many students dropped? ";
    cin >> dropped;

    cout << "Total number of students: " << total << endl;

```

The input and output of the program could be

Enter number of students adding the course: 3
How many students dropped? 5
Total number of students: 28
Total tuition owed: $2376

The variables **total** and **dropped** are added so that *total* reflects all students ever enrolled, even if they are not in the class, all students owe even if they don't show up or drop the course.

# Precedence Between Arithmetic Operators

The statement we has two arithmetic operators, for addition and multiplication. The order in which the two arithmetic operations are performed makes a difference. If addition is performed first, 28+5, and then the sum, 3, is multiplied by 72, the result is 2376. However, if multiplication is performed first, 5*72, and then the product, 30, is added to 28, the result would be 388.

C++ has rules, called precedence, for determining which operation is first. Precedence was discussed earlier in this chapter in the section on the addition operator over the assignment operator. However, the issue is precedence between arithmetic operators.
