# Note

The condition for both the if and while statements is ch != 'Q' && ch != 'q'. A rookie mistake is to use the || operator when the && operator should be used, and vice versa, as in ch == 'Q' && ch == 'q', the condition would be true. A variable can only have one value at a time, so the value of ch will never equal Q or q, since it cannot be both at the same time. Of course, the expression could be rewritten using the || operator as !(ch == 'Q' || ch == 'q').

# Combining Using of cin, cin.get, and cin.getline()

The problem of a newline character remaining in the input buffer is not limited to the situation in which the ENTER key is pressed in response to a prompt to press any key to continue. This problem also arises when the get or getline member functions are used together in one program, since the ENTER key is used to end input.

The following program is an example of cin and the getline member function used in one program:

```cpp
#include <iostream>
using namespace std;

int main()
{
	char name[80];
	int courseNum;
	cout << "Enter course number: ";
	cin >> courseNum;
	cout << "Enter your name: ";
	cin.getline(name, 80);
	cout << "Course number is: " << courseNum << endl;
	cout << "Your name is: " << name << endl;
	return 0;
}
```

Here is some sample input and output:

Enter course number: 802
Enter your: Course is: 802
Your name is: 

You did not have the opportunity to enter a name. The reason is similar to the situation in the last section in which the user did not have a chance to enter input.

As Figure 12-5 shows, when you typed 802 and pressed the ENTER key to enter input, the input buffer contained not only the 802 but also the newline character resulting from pressing the ENTER key. cin with the stream extractor (>>) removed and assigned to the variable courseNum, but *not including*, the newline character, which remained in the input buffer.

Since the newline character remains in the input buffer, you do not have the opportunity to enter input into the next statement: the call of the getline member function. Instead, Figure-12-5 depicts, the getline member function, which removes whitespaces as well as newline character from the input buffer and assigns newline character to the character array name. While the character array name has assigned value, it is not a printable character, so it appears in the output that name has no value.

The solution, pointed out in the previous section, is to follow use of the cin object and the stream extraction operator (>>) with the no-argument of the ignore (or get) member function. However, unlike with the stream extraction operator (>>) always leaves a newline character in the input buffer. The following modification of the previous program implements this solution by adding a call to the no-argument version of the ignore member function after use of the cin object with the stream extraction operator (>>):

```cpp
#include <iostream>
using namespace std;

int main(void)
{
    char name[80];
    int courseNum;
    cout << "Enter course number: ";
    cin >> courseNum;
    cin.ignore();
    cout << "Enter your name: ";
    cin.getline(name, 80);
    cout << "Course: " << courseNum << endl;
cout << "Your name is: " << name << endl;
    return 0;
}
```

As the following sample input and output show, the program now works properly:

Enter course number: 802
Enter your name: Jeff Kent
Course number is: 802
Your name is: Jeff Kent

# Rules to Live By

Here are three simple rules that will avoid the problem caused by a newline character in the input buffer (assuming, of course, you do not have a programming reason to keep the newline character in the input buffer).

- Rule #1: Always follow cin and the stream extraction operator (>>) with the ignore member function.

Explanation: The cin object with the stream extraction operator (>>) always leaves a newline character in the input buffer. Clear it out with the ignore member function.

```cpp
char ch;
cin >> ch;
cin.ignore();
```

- Rule #2: Don't follow the getline function with the no-argument ignore member function.

Explanation: The getline function removes the newline character that terminated input from the input buffer. Therefore, it should not be followed with the ignore member function.

- Rule #3: After using the get function with one argument, such as cin.get(ch), check to see if you have a newline character in the input buffer. If you do, clear it with the ignore member function.

Explanation: The get function with one argument being a single character will leave a newline character in the input buffer if you type a character and then press ENTER.

```cpp
char ch;
cin >> ch;
cin.ignore();
```

# Case Conversion

The toupper and tolower functions each have one argument. If the argument is a letter, toupper returns the uppercase version; conversely, tolower returns the lower case.

```cpp
#include <iostream>
#include <cctype>
using namespace std;

int main(void)
{
    char ch;
    do {
        cout << "Enter a character: ";
        cin.get(ch);
        if (ch != '\n'){
            cout << "Uppercase: " << toupper(ch) << endl;
            cout << "Lowercase: " << tolower(ch) << endl;
        }
    } while (ch != 'Q' && ch != 'q');
    return 0;
}
```

# Functions that Check the Value of a Character

Table 12-1: Functions that Check the Value of Characters

| Function | Description |
| :--- | :--- |
| isalpha | Returns true if the argument is a letter of the alphabet; false if otherwise. |
| isnum | Returns true if the argument is a letter of the alphabet or a digit; false if otherwise. |
| isdigit | Returns true if the argument is a digit; false if otherwise. |
| islower | Returns true if the argument is a lower case letter of the alphabet, false otherwise. |
