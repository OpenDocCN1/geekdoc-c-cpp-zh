In example of the output between 1 and 10, only one statement

Also, as with the structure, the statement or statements will not execute for the keyword and
parentheses will not execute if the parentheses are followed by a semi-colon that

```cpp
for (int num = 1; num <= 10; num++)
    cout << num << " ";
```

The reason would be 11 if the loop continues, and the empty statement
executes, until the condition fails when num is 11. The statement is not part of the
loop, it executes when the for loop completes, outputting 11, the value of num after the
loop finishes.

The expressions do not need to be inside the parentheses for the loop. In the
program, num is initialized before the loop, and is incremented inside the
body of the loop.

```cpp
#include <iostream>
using namespace std;
int main(void) {
    int num = 1;
    for (; num <= 10;) {
        cout << num << " ";
        num++;
    }
    return 0;
}
```

Even though initialization and incrementing are not done within the parentheses, two semicolons are nevertheless needed to separate the three expressions. While an expression may be empty, the semicolon nevertheless is necessary.

## Beware the Infinite Loop

In the preceding program, if the statement num++ was omitted, the loop would never stop:

```cpp
#include <iostream>
using namespace std;
int main(void) {
    int num = 1;
    for (; num <= 10;)
    {
        cout << num << " ";
    }
    return 0;
}
```

The reason is that the condition num <= 10 would never become false since num would start at 0 and its value would never change because the statement num++ was omitted.

This loop that never stops executing is called an infinite loop. Usually, it identifies itself by a character or characters appearing in rapid succession in your console window, with the application ending never.

You would not intend an infinite loop in your code, but mistakes do happen; I have made this mistake a lot before. If it happens to you, don't panic. You can use the CTRL-BREAK keyboard combination to end the program. Knowing you have encountered an infinite loop, you can correct the error that caused it.

## A Factorial Example

So far, use of the loop has been relatively tricky, counting numbers in ascending or descending order. However, the loop can be used for more sophisticated programs.

The following program calculates the factorial of a number input by the user. A factorial is the product of all the positive integers from 1 to that number. For example, the factorial of 3 is 3*2, which is 6, the factorial of 5 is 5*4*3*2*1, which is 120.

```cpp
#include <iostream>
using namespace std;
int main(void) {
    int num, counter, total = 1;
    cout << "Enter a number: ";
    cin >> num;
    cout << "The factorial of " << num << " is: ";
    for (int counter = 1; counter <= num; counter++)
        total *= counter;
    cout << total;
    return 0;
}
```

## Breaking Out of a Loop

We previously used the break keyword in a switch statement. You can also use the break keyword in a for loop. The break keyword is used within the code of a for loop, commonly within an if / else structure. If the break keyword is reached, the for loop terminates, though the condition is still true.

For example, in the following program, the user is given three tries to guess a number (which happens to be 3) between 1 and 10. However, if the user guesses the number on the first or second try, it would be pointless to ask them again to guess the number. Accordingly, if the user guesses the number, the break statement is used to break out of the loop.

```cpp
#include <iostream>
using namespace std;
int main(void) {
    int num, counter, secret = 3;
    cout << "Guess a number between 1 and 10\n";
    cout << "You have 3 tries\n";
    for (int counter = 1; counter <= 3; counter++) {
        cout << "Enter the number now: ";
        cin >> num;
        if (num == secret) {
            cout << "You guessed the secret number!";
            break;
        }
    }
    cout << "Program over;";
    return 0;
}
```

Here are two sample inputs and outputs. In the first one, the user tried three times without guessing correctly. In the second one, the user guessed correctly on their second try, so there was no third iteration of the loop to the break keyword.

```
Guess a number between 1 and 10
You have 3 tries
Enter the number now: 2
Enter the number now: 4
Enter the number now: 6
Program over
```

Guess a number between 1 and 10
You have 3 tries
Enter the number now: 2
Enter the number now: 3
You guessed the secret number!
```

Without the break keyword, the for loop would be infinite due to the lack of a condition. While the break keyword is part of the C++ language, I recommend you use it sparingly. Normally, each iteration has one exit point. However, when you use multiple break statements, it becomes more difficult to understand, and can result in logic errors.

```cpp
#include <iostream>
using namespace std;
int main(void) {
    int num = 1;
    for (num <= 10) {
        break;
    } else {
        cout << num << " ";
        num++;
    }
}
```

## The Continue Keyword

You can also use the continue keyword in a for loop. The continue keyword, like the break keyword, is used within the code of a for loop, commonly within an if / else structure. If the continue statement is reached, the current iteration of the loop ends, and the next iteration of the loop begins.

For example, in the following program, the user is charged $3 item, but not charged for the 13th item. In other words, every 13th item is free.

```cpp
#include <iostream>
using namespace std;
int main(void) {
    int num, counter, total = 0;
    cout << "How many items you want to buy: ";
    cin >> num;
    for (int counter = 1; counter <= num; counter++) {
        if (counter % 13 == 0)
            continue;
        total += 3;
    }
    cout << "Total for " << num << " items is $" << total;
    return 0;
}
```

Here are three sample inputs and outputs, illustrating the change for the 12 or 13 items is, but on the 14th item the user is charged an additional $3.

How many items you want to buy: 12
Total for 12 items is $36

How many items you want to buy: 13
Total for 13 items is $36

How many items you want to buy: 14
Total for 14 items is $39
