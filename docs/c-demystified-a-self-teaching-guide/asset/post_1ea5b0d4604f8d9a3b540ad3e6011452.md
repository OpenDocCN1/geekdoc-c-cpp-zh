
# The Change Machine Project

My mother was not using a change machine to restrain crafty or mischievous young grandchildren. The youngsters poured hundreds of pennies into the top of the machine, and watched with fascination (fortunately, youngsters are easily fascinated) as the machine sorted the pennies into amounts of change could be taken to the bank and exchanged for dollars, quarters, and bigger loot. The youngsters were motivated as well as fascinated, since guess who got to keep the quarters?

## Program Description

This program will ask the user to input the number of pennies. You may assume the user will input a positive whole number. The code then will output the number of dollars, quarters, nickels, and pennies. The input and output could be:

```
Enter number of pennies to make change: 387
Dollars: 3
Quarters: 3
Dimes: 1
Nickels: 0
Pennies: 2
```

The next section will reproduce the code, and the section following will explain the code. However, as a programming challenge, first try to write the code yourself. If you, great! If not, no problem; you will learn more from the code and the explanation if you first try to write this program.

As a hint (you don't have to look), here are the first three lines of code in main:
```cpp
int total, dollars, quarters, dimes, nickels, leftover;
cout << "Enter number of pennies to make change: ";
cin >> total;
```

The variable total will be assigned the total number of pennies entered by the user. The variable dollar will be assigned the number of pennies in the pennies, 3 in the preceding sample run for 387 pennies. The variables quarters, dimes, and nickels will be assigned the number of quarters, dimes, and nickels in the change, respectively, in the previous sample run for 387 pennies. The variable leftover will ultimately be assigned the number of pennies in the change (2 in the prior sample run for 387 pennies), also will be used for other purposes. Of course, you could write this program with a few more, or a few less, variables.

## The Code

There is more one way to write this program. Here is how I wrote it:

```cpp
#include <iostream>
#include <string>
using namespace std;
int main()
{
    int total, dollars, quarters, dimes, nickels, leftover;
    cout << "Enter number of pennies to make change: ";
    cin >> total;

dollars = total / 100;
leftover = total % 100;
quarters = leftover / 25;
leftover %= 25;
dimes = leftover / 10;
leftover %= 10;
nickels = leftover / 5;
leftover %= 5;
cout << "Dollars: " << dollars << endl;
cout << "Quarters: " << quarters << endl;
cout << "Dimes: " << dimes << endl;
cout << "Nickels: " << nickels << endl;
cout << "Pennies: " << leftover << endl;

    return 0;
}
```

## The Algorithm

You learned in Chapter 1 in a computer program a computer programmer gives instructions to a computer. These instructions are in a programming language such as C++. However, when you write code, you need to formulate the instructions in English or whatever language you think in.

An algorithm, pronounced "Al Gore", is a step-by-step logical procedure for solving a problem. You frequently need to create and implement algorithms. Implementing algorithms in your code is computer programming. Creating algorithms is a skill that can be developed from any field that requires analytical thinking, including but not limited to, mathematics as well as computer programming.

Let's say you are given a number of pennies, like 387, and you have to determine, in your head, how many dollars, quarters, dimes, nickels, and pennies to give as change. How would you do it?

A logical approach is to start with dollars. There are 100 pennies in a dollar. If 387 is divided by 100, the quotient is the number of dollars in the pennies: 3.

One problem is 387 divided by 100 could be 3.87, 3. However, as discussed earlier in this chapter the "Division Operators" section, when an integer is divided by an integer, the result always is an integer unless one of the integer operands is first cast to a float. We want the result of the division to be an integer, or we will not lose any of the integer operands to.

Since the beginning of pennies (387) is stored in the integer variable *total*, if total is divided by 100, also regarded as an integer, the quotient is the number of dollars in the pennies, 3.

```cpp
dollars = total / 100;
```

After you take out 300 pennies (3 dollars) from the pile of 387 pennies, 87 pennies are left over. 87 is the remainder of the division total / 100. We obtain this remainder with the modulus operator, and assign it to the integer variable *leftover*:

```cpp
leftover = total % 100;
```

Next, you follow the same procedure to determine the number of quarters in the 87 pennies left over. The only differences are that the divisor is 25 instead of 100 and the number of pennies is left by *leftover* of *total*.

```cpp
quarters = leftover / 25;
leftover %= 25;
```

The same process is followed for determining the number of dimes and nickels:

```cpp
dimes = leftover / 10;
leftover %= 10;
nickels = leftover / 5;
leftover %= 5;
```

The number of pennies left after division by 5 cannot be converted into higher change. Accordingly, there is no need for further division. There also is no need for a separate variable for pennies because leftover stores the number of pennies left.

All that remains is to output the values of the variables representing the dollars, quarters, dimes, nickels, and pennies.

This method of solving the problem by dividing the total number of pennies by the number of pennies in a dollar, storing the quotient in a variable holding the number of dollars, and dividing the remainder by the number of pennies in a quarter and so on, is an algorithm. We will be discussing many algorithms in this book.
