The Date structure must be declared before the Person structure. Otherwise, the compiler
not know what Date was in the declaration of the bDay member variable of the
Person structure.

The setValues function sets the value of the person's birthday. It cannot do by:
cin >> pers.bday

The reason is that bDay is not an integer that can be assigned input of an integer.
Instead, itself is also a structure. It is necessary to drill down into the
member variables of bDay, month, day, and year, as in the following statement:
cin >> pers.bday.month >> pers.bday.day >> pers.bday.year;

Similarly, the getValues function cannot output the person's birthday with the statement:
cout << pers.bday;

Instead, it must also drill down into the member variables bDay, month, day,
and year, as in the following statement:
cout << "Person's birthday in mm/day/yyyy format is: "
<< pers.bday.month << "/" << pers.bday.day
<< "/" << pers.bday.year << endl;
