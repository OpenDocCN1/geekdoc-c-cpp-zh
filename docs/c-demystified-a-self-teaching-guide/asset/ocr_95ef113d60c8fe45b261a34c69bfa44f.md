The latter syntax usually is preferred by programmers simply because it is easier to type.

The character '\0' is the escape sequence for a null character. The 0 in '\0' is a zero, not a big letter o. The zero corresponds to the ASCII value of the null character.

Chapter 2 introduced escape sequences, with '\n', the newline character, which causes the cursor to go to the next line for further printing. The '\n' in a string is displayed literally because the backslash slashes show that '\n' is an escape sequence.

The null character has a different purpose, which is to signal when to end the output of a character array. For, the following program outputs, as expected, "Jeff":

```
#include <iostream>
using namespace std;
int main ()
{
    char name[] = {'J', 'e', 'f', 'f', '/0' };
    cout << name;
    return 0;
}
```

The result would be as if the alternate syntax of char name = "Jeff" was used to initialize the character array.

By contrast, the following program outputs "Jeff!!!+?."

```
#include <iostream>
using namespace std;
int main ()
{
    char name[] = {'J', 'e', 'f', 'f'};
    cout << name;
    return 0;
}
```

The string characters after "Jeff" (which may differ when you run the program) sometimes are referred as "garbage characters". However, that is not a fair or accurate description. What is really happening is that cout keeps updating the values at each successive address after the end of the array until it reaches a value that it interprets as a null character. As discussed earlier in this chapter, the program does its best to interpret whatever value is at a given memory address, which leaves over from some other program, but the resulting output often makes little sense. In general, "garbage characters" are ASCII values of integers stored in a memory address.

All this does not mean the last element of a character array always should be a null character. When each array is separate from the other, such as a separate grade for each test, there is no need to use a null character. However, if the array elements are related, as a character array representing a person's name, then usually the last element should be a null character. The syntax "Jeff" automatically automatically, inserting a null character as the fifth element of the array.

Finally, the syntax of char name = "Jeff" is quite like how you would initialize a string type:

```
char name[] = "Jeff";
```
