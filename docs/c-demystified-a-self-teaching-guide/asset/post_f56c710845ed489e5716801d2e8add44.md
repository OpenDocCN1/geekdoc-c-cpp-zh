
```
===
Enter first string: chess
Enter second string: check
The first C-string is larger
===

Enter first string: Jeff
Enter second string: Jeffrey
The second C-string is larger
====
```

By contrast, you can use relational operators to compare two variables of the C++ string class. Whether one string is "less than" or "greater than" another works the same way for the C++ string class as does for C-strings. The following code fragment is illustrative:

```cpp
string str1 = "Jeff";
string str2 = "jeff";
string str3 = "Jeffrey";
str1 < str2; // true
str3 > str1; // true
str2 > str3; // true
```

# Conversion Between C-String and a Number

The stdlib library provides several functions for converting the C-string representation of a number to a numeric data type, as well as the reverse.

The atoi function is a name for "ASCII to integer." This function has one argument, a C-string, and returns the integer that the C-string represents. The following code fragment demonstrates how the atoi function works:

```cpp
int num = atoi("7654");
```

The function checks if its argument can be converted to a numeric value. Additionally, the C++ programming language does not define the consequences if the argument cannot be converted to a numeric value. For example, the return value of an expression such as atoi("12Jeff") might be 12, the compiler attempting to perform the conversion from a character array to a number until a non-digit is reached. However, the return value could be 0, indicating the conversion could not be completed successfully.

The atoi function is often used in a program that has the user input number into a character array, then checks if the character array represents a number using the atoi function. This is demonstrated by the following program:

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main(void)
{
    char input[80];
    int num;
    cout << "Enter an integer: ";
    cin >> input;
    for (int x = 0; x < strlen(input); x++)
    {
        if (!isdigit(input[x]) && input[x] != '-')
            return false;
        } else {
            if (!isdigit(input[x]))
                return false;
        }
    }
    int num = atoi(input);
    cout << num;
    return 0;
}
```

The advantage of having the user input into a character array instead of an integer is to avoid a run-time error or garbage data if the input is non-numeric. The character array then is checked to see if its value is the representation of a number. Since the number may be negative, the first character may be a dash as a digit. The value of the character array is confirmed to be the representation of a number, then the atof function is used to assign that value to an integer variable.

The atof function, standing for "ASCII to Float," and the atol function, meaning "ASCII to Long," work the same way as the atof function except their arguments are C-string representations of long and float, respectively, and their return values likewise as a long and float, respectively.

The C++ string class has no member functions that correspond to atoi, atof, or atol. However, a alternative is to first assign the value of a string to a character array using the c_str member function, after which atoi, atof, or atol could be used.

```cpp
string name = "123";
char str1[80];
strcpy(str1, name.c_str());
int num = atoi(str1);
```

The data member of the C++ string class could also be used to the same effect. The call to the strcpy(str, name.data());

Finally, the itoa function is the converse of the atoi function, standing for "Integer to ASCII." It takes three arguments, the integer value to be converted, a pointer to the C-string which the string representation of that integer will be assigned, and the number that represents the base of the converted value. The following code fragment shows how itoa function may be used to assign to the character array intArray the C-string representation of the number 776 in base 10:

```cpp
char intArray[20];
itoa(776, intArray, 10);
```

# Summary

The three subjects of this chapter were the character data type, a C-String (a null-terminated array), and the C++ string class.

We discussed the issues involved in reading a reader when a newline character may be left in the input buffer, and derived the following three rules.

The first rule is to always ignore cin and the string extraction operator (>>) with the no-argument ignore function. The reason is that the cin object with the extraction operator >> leaves a newline in the input buffer, so calling the no-argument ignore function will dispose of leftover newline character.

The second rule is not to use the ignore member function after using the getline function. The reason is that the getline member function removes the newline character that terminated it from the input buffer.

The third rule is that after using the get member function with one argument, as cin.get(ch), to check if you have a newline character in the input buffer, and if you do, call the ignore member function. If you don't, the reason is that the get member function with one argument will leave a newline character in the input buffer if you type a character and then press ENTER, but it won't if you press ENTER.

The C++ standard library cctype contains number of functions that are useful with characters. The toupper and tolower each have one argument, a character. If the character represents a letter, A-Z or z, the toupper function returns the uppercase of it. Conversely, the tolower function returns the lowercase of it. If the argument is not a letter, both functions return the same character that is the argument. A number of other functions in the ctype standard library, including but not limited to isalpha and isdigit, permit you to determine the value of a character, as whether it is a letter, digit, or whitespace.

The cstring standard library provides a number of functions that are useful when working with C-strings. Typically, the string library provides a number of functions that are useful when working with the C++ string class. Use the strlen function to determine the length of a C-string, the length or size member functions to return the length of a C++ string class variable. Use the assignment operator = to assign a value to a C++ string class. Use the strcat function to append a value to a C++ string, and the combined addition and assignment operator += to append a value to a C++ string class variable. Use the strcmp function to compare two C-strings.

The cstdlib standard library provides several functions for converting the C-string representation of a number to a numeric data type, as well as the reverse. These are atoi, or "ASCII to integer," atol, or "ASCII to Long," atof, or "ASCII to float," and itoa, or "Integer to ASCII."
