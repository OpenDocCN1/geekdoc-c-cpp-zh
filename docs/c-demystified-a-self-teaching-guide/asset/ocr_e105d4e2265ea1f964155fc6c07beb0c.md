# Overflow and Underflow

The consequences of an overflow or underflow of number variables is more unpredictable with cin than with the assignment operator. Inputting either 32768, which is 1 more than the highest number in the range of a data type, or –32769, less than the lowest number in that range, results on my computer in the output “Your test score is –13108.”

#include <iostream>
using namespace std;
int main(void)
{
    short testScore;
    testScore = 32768;
    cout << "Your test score is " << testScore << "\n";
    return 0;
}
