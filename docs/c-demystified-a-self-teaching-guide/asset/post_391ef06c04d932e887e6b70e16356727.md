The first time the `printMessage` function is called, the variable `times` is declared, and initialized to zero, by the statement:
`static int times = 0;`

The variable `times` is then incremented and outputted, resulting in the output:
`This function called 1 times`

So far, this is the same as when `times` was an automatic local variable than a static local variable. The difference is that when the `printMessage` function ends, `times`, being a static local, is **not** destroyed. And its value remains in memory.
The next (second) time the `printMessage` function is called, the statement declaring and initializing `times` is not executed because being static, it still exists from the first time the `printMessage` function was called. Further, the value of `times` at the end of the first call of the `printMessage` function, remains in memory. That value is incremented to 2, and outputted, so the output to the second call of the `printMessage` function is:
`This function called 2 times`

Accordingly, we were able to persist the value of the `times` variable between function calls by making that variable either global or static local. The difference was that as a static local the scope of `times` was still limited to the `printMessage` function, as opposed to having scope throughout the program if it were a global variable. This scope would make it easier to fix your program if the value of the `times` variable were incorrect somewhere in your code.

# Sending Information to a Function

The printMessage function in the Hello World program outputs "Hello world!" does not need any further information to do its job.

Let's make the printMessage function more useful so that it not always output "Hello world" but instead outputs whatever we ask it to. Of course, the printMessage function is not a mind reader; we need to tell it the message we want to output.

Let's try to write a program where the user enters in the main to be outputted, that user input is stored in a variable str, and the printMessage function attempts to output the value of that str. One approach is to make the variable global so it can be accessed in both the main and printMessage functions:

```cpp
#include <iostream>
#include <string>
using namespace std;
void printMessage();
string str;

int main ()
{
    cout << "Enter a string: ";
    cin >> str;
    printMessage();
    return 0;
}
void printMessage ()
{
    cout << "You inputted " << str;
}
```

- Note With a string, a statement cin include the <string> standard library. Additionally, the cin object and the stream insertion operator (>>) will only accept the input of a string variable up to the first embedded space. If the user entered "Jeff Kent," the output would be only "Jeff." In Chapter 10, we will cover the getline function, which will work with string that has embedded spaces.

Here is some sample input and output:

Enter a string: Jeff
You inputted Jeff

While this, as discussed in the previous section, global variables can make it more difficult to fix problems with your programs. There is a better alternative here, involving passing arguments.

As discussed earlier in this chapter, the parentheses following the function name in the function header contains the function's arguments. Arguments are information that is provided to a function so that it may perform its task.

As discussed earlier, some functions as the printMessage function in the Hello World program, which simply outputs "Hello world" It does not need any further information to do its job.

However, when we modify the printMessage function so that it does not always output "Hello world! but instead outputs whatever message we ask it to, we need to tell it the message we want to output. We can do so by passing the function an argument that specifies the message.

This chapter will discuss two ways of passing arguments, by value and reference. A third way, passing arguments by address, will be covered after we discuss pointers in Chapter 11.

# Passing Arguments by Value

The following is a modification of the program that uses the printMessage function to output a message. This time, the content of the message to be passed to the printMessage function as an argument:

```cpp
#include <iostream>
#include <string>
using namespace std;
void printMessage(string);

int main () {
    string str;
    cout << "Enter a string: ";
    cin >> str;
    printMessage(str);
    return 0;
}
void printMessage(string s) {
    cout << "You inputted " << s;
}
```

Here is some sample input and output:
nEnter a string: Jeff
You inputted Jeff

# The Function Prototype and Header

Both the function prototype and the function header have one argument, of the string data type. However, the function prototype's argument just has the argument's data type (string), whereas the function header has both a data type and an argument name (string).

The function prototype may include an argument name as well as data type, as in:
void printMessage(string someArg);

However, that argument is called a dummy argument because it serves no purpose.

By contrast, the function header's argument must include an argument name as well as a data type. The purpose of that argument name in the function header's argument is explained next.

# Using the Function Argument

The following code calls the `printMessage` function:

```cpp
printMessage(str);
```

The string variable `str`, whose value previously was assigned by user input, is passed as an argument to the `printMessage` function. The value of `str` then passed to the string variable `s`, which is the argument name in the function header of the `printMessage` function:

```cpp
void printMessage (string s)
```

The string variable `s` is then used in the body of the `printMessage` function to output the message:

```cpp
cout << "You inputted " << s;
```

**Figure 9-2** shows how the value of the argument of the function call is passed to the argument in the function header and then used in the body of the called function.

```cpp
int main()
{
    printMessage(str);
    return 0;

{
```

The function header must include an argument name as well as a data type so the value which is being passed by the function, stored in `str` in `main`, may be stored in a variable that can be used in the `printMessage` function. Otherwise, the value passed would have no place to store for use in the `printMessage` function.

The argument name in the function header can be the same as the name of the variable `printMessage(str)` passed in the function argument:

```cpp
printMessage(str);
void printMessage (string s)
```

Even if so, the `str` in `main` is a separate variable from the `str` in `printMessage`. Nevertheless, I recommend to avoid confusion, using different names in the program.

# Using Multiple Function Arguments

The program we discussed used one argument. However, a function may have two or more function arguments.
The following modification of the `printMessage` function uses two arguments, one for the first name and one for the last:

```cpp
#include <iostream>
#include <string>
using namespace std;
void printMessage(string, string);
```

```cpp
int main() {
  string namel, name2;
  cout << "Enter first name: ";
  cin >> namel;
  cout << "Enter last name: ";
  cin >> name2;
  printMessage(namel, name2);
  return 0;
}

 printMessage(string firstName, string lastName) {
  cout << "Your name is " << firstName << " " << lastName << endl;
}
```

Here is some sample input and output:

Enter first name: Jeff
Enter last name: Kent
Your name is Jeff Kent

The order of arguments in the function call must correspond to the order of arguments in the function header. The function call and the function header here are

```cpp
printMessage(first, last);
vprintMessage(string firstName, string lastName)
```

The variable in the function call is name1. The value of name1 in main is copied into the first variable in the printMessage function header, firstName. Similarly, the second variable in the function call is name2, the value of name2 in main is copied into the second variable in the printMessage function header, lastName.

If the arguments in the function call were reversed, as in:

```cpp
printMessage(last, first);
```

then the sample input and output would be

Enter first name: Jeff
Enter last name: Kent
Your name is Kent Jeff

In this example, paying careful attention to the correspondence between the order of arguments in the function call and the arguments in the function header resulted in my name being outputted backwards. The consequences of a lack of correspondence between the order of arguments in the function call and the order of the arguments in the function header is more drastic when the multiple function arguments have different data types.

In the following program, the first argument, the person's name, is a string, whereas the second argument, the person's age, is a different data type, an integer.
