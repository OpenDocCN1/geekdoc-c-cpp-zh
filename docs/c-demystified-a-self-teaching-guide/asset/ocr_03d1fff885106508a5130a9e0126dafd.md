+   42. With the logical Or operator, both Boolean expressions have to be false for the overall Boolean expression to be false.

+   43. The logical Not operator reverses the "truth" of a Boolean expression, making a true expression false and a false expression true.

+   45. The decrement operator decreases a value by one.

+   48. The purpose of the first expression in the parentheses following the for keyword is to initialize a variable which usually serves as the counter.

+   49. The purpose of the second expression in the parentheses following the for keyword is to set the condition which must be true for the loop to continue execute.

+   50. The purpose of the third expression in the parentheses following the for keyword is to update a value, usually a counter.

+   53. The purpose of the continue keyword in a loop is to prematurely terminate the iteration of a loop.
