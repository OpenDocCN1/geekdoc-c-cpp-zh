# Sending Information to a Function

The printMessage function in the Hello World program outputs "Hello world!" does not need any further information to do its job.

Let's make the printMessage function more useful so that it not always output "Hello world" but instead outputs whatever we ask it to. Of course, the printMessage function is not a mind reader; we need to tell it the message we want to output.

Let's try to write a program where the user enters in the main to be outputted, that user input is stored in a variable str, and the printMessage function attempts to output the value of that str. One approach is to make the variable global so it can be accessed in both the main and printMessage functions:

```
#include <iostream>
#include <string>
using namespace std;
void printMessage();
string str;

int main ()
{
    cout << "Enter a string: ";
    cin >> str;
    printMessage();
    return 0;
}
void printMessage ()
{
    cout << "You inputted " << str;
}
```

+   Note With a string, a statement cin include the <string> standard library. Additionally, the cin object and the stream insertion operator (>>) will only accept the input of a string variable up to the first embedded space. If the user entered "Jeff Kent," the output would be only "Jeff." In Chapter 10, we will cover the getline function, which will work with string that has embedded spaces.

Here is some sample input and output:

Enter a string: Jeff
You inputted Jeff
