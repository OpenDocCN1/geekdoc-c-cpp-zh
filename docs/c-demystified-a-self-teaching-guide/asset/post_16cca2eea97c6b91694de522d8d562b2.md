# The bool Data Type

There is one more data type, bool. This data type has only two possible values, true and false, and its size usually is one byte. The term "bool" is a shortening of Boolean, which is usually used in connection with Boolean Algebra, named after the British mathematician, George Boole.

The bool type is mentioned separately since it does not neatly fit into the number or text categories. It could be regarded as a numeric type in that zero is seen as false, and one (or any other non-zero number) as true. While it may not seem intuitive zero would be false and one would be true, remember that computers essentially store information in switches, where 1 is on, and 0 is off.

# Outputting an Expression

The expression sizeof(int) is separated by the stream insertion operator (<<) from the literal string. If the code were:

```cpp
cout << "Size of int" << sizeof(int) << "\n";
```

then the output would be quite different:

**Size of int4**

The reason is that sizeof(int), being inside the double quotes, would be treated as literal string, not an expression.

# Escape Sequences

The string "\n" following the expression(int) is also a literal string, so it, too, is separated by a string insertion operator from the sizeof(int) expression. However, "n" is a special type of string called escape sequence.

C++ has many escape sequences, though this may be the most common one. This particular escape sequence causes the cursor to go to the next line for further printing. Without it, all the output will be on one line.

The "n" in a string is not displayed literally even though it is encased in double quotes. The reason is that the backslash signals out that this is an escape sequence.

| \' | Single quote | Causes a single quote to be printed |
