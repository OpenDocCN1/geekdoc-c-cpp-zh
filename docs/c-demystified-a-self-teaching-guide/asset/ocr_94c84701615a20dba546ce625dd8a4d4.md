```
string name = "Jeff";
```

Indeed, a character array that ends with a null character often referred to colloquially as a string. a character array that ends with a null character is not thereby converted to a string data type; it is still a character array. Indeed, there is no guarantee that a compiler's implementation of the string data type will result the last character of a true string being a null character.

Thus, while character arrays and strings have many similarities, they are not the same. There are important differences. One cannot safely assume that a string ends with a null character. # Constant Arrays

You can create arrays that are constants. For example, the following array contains the number of days in each month (for February, we use a non-leap year).

```
const int daysInMonth [] = { 31, 28, 31, 30, 31, 30, 31, };
```

Using a constant here is a good choice since the number of days in each month will not change.

You must initialize when creating a constant array, just as you must use initialization when you cannot change the values later, you must specify the values when you create the constant.

# When to Use Initialization

C++ gives you the option of declaring an array, with the values of the array elements unassigned, and initializing it, assigning values to some or all of the array elements.

Initialization usually is the better choice when you know some or all of the array values, but it is not limited to that scenario. Initialization is used to provide each array with an initial default value. For example, we might initialize each of the testScore to -1 as a signal that no test score has been assigned. The -1 is a better choice for this purpose than 0 a student could get a zero on the test, but not a -1.

However, initializing to a default value can be cumbersome when there are many array elements. Additionally, when you don't know in advance the array values, such as for test scores, you decide against initializing for a default value. Furthermore, even if you do initialization, you may want later to change the values of some or all of the array elements. Accordingly, you need to know how to assign values to an array.
