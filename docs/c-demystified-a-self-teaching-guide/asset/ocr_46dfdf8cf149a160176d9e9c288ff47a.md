# Anatomy of a C++ Program

It seems to be a tradition in C++ programming books for the first code example to output to a console window the message "Hello World! (shown in Figure 1-1).

![](bbox=[0.163, 0.215, 0.753, 0.355])

Note The term "console" goes to the days before Windows when the screen did not have menus and toolbars but just text. If you have typed commands using DOS or UNIX, you likely did so in a console window. The text "Press any key to continue" immediately following "Hello World! is not part of the program, but instead is a code for how to close the console window.

Unfortunately, all too often the "Hello World! is followed by many other program examples without the book or teacher explaining how the "Hello World! program works. The result is a confused reader or who's ready to say "Goodbye, Cruel World."

While the "Hello World!" program looks simple, actually there is a lot going behind the scenes of this program. Accordingly, we are going to go through the following code for the "Hello World!" program line by line, though not top-to-bottom order.

```
#include <iostream>
using namespace std;

int main(void)
{
    cout << "Hello World!";
    return 0;
}
```

Note The code programmer is written as source code, which is saved in a file that has a .cpp extension, standing for C++.
