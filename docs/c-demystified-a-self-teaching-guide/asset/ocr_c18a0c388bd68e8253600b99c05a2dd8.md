# Defining and Calling a Function

indicate the beginning and end of the definition of the printMessage function where that function is called.

```
#include <iostream>
using namespace std;

// begins definition of printMessage function
void printMessage(void)
{
    cout << "Hello world";
}
// ends definition of printMessage function
int main()
{
    printMessage(); // calls printMessage function
    return 0;
}
```

The printMessage function is defined first. The void keyword preceding the function name means no return value. The void keyword in parentheses following the function name means this function has no arguments. The parentheses could also be empty, so as main; empty parentheses following the function in a function header is same as placing the void keyword within the parentheses. Which syntax you choose is a matter of taste; it is no better or worse than the other.

The body of the printMessage function has one statement, which outputs "Hello world! The function does not need to contain an explicit return statement because the return type is void, the return statement is implied. You may include an explicit return statement. If you did, then the printMessage function would read

```
void printMessage(void)
{
    cout << "Hello world";
    return;
}
```

# Calling a Function

Unless the printMessage function is called, it is the programming equivalent of the tree that falls in the forest without anyone seeing or hearing it; it is there in the program, but it doesn't do anything. The printMessage function is called in main with line:

```
printMessage();
```

In this example, printMessage is the called function, since it is the function called from main. The empty parentheses indicate that no arguments are passed to this function. I will show you later in this chapter how to pass arguments, as well as how to return values.

The order of execution is as follows:

+   1. Execution starts with the main function.
2. The first statement in main, printMessage(), is executed.
3. Execution shifts to the printMessage function, and begins with the first statement in that function, which outputs "Hello world!"
