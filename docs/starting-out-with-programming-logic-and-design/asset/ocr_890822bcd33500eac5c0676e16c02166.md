If one of the strings in a comparison is shorter than the other, many languages compare only the corresponding characters. If the characters are identical, the shorter string is considered less than the longer string. For example, suppose the strings "High" and "HI" were being compared. The string "HI" would be considered less than "High" because it is shorter.

The pseudocode in Program 4-4 shows a simple demonstration of how two strings can be compared with the < operator. The user is prompted to enter two names and the program displays those two names in alphabetical order.
