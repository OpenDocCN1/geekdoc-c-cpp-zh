### Array Initialization

Most languages allow you to initialize an array with values when you declare it. In this book's pseudocode, we will initialize arrays in the following manner:

```
Constant Integer SIZE = 5
Declare Integer numbers[SIZE] = 10, 20, 30, 40, 50
```

The series of values separated by commas is called an initialization list. These values are stored in the array in the order they appear (The first value, 10, is stored in numbers[0]; the second value, 20, is stored in numbers[1], and so forth.). Here is another example:

```
Constant Integer SIZE = 7
Declare String days[SIZE] = "Sunday", "Monday", "Tuesday", "Thursday", "Friday", "Saturday"
```

This pseudocode declares days as an array of 7 Strings, and initializes days[0] with "Sunday", days[1] with "Monday", and so forth.

### Array Bounds Checking

Most languages perform array bounds checking, which means they do not allow a program to use an invalid array subscript. For example, look at the following pseudocode:

```
// Create an array.
Constant Integer SIZE = 5
Declare Integer numbers[SIZE]

// ERROR! This statement uses an invalid subscript!
Set numbers[5] = 99
```

This pseudocode declares an array with 5 elements. The subscripts for the array's elements are 0 through 4. The last statement will cause an error in most languages because it attempts to assign a value to numbers[5], a nonexistent element.

> NOTE: Array bounds checking typically happens at runtime, which is while the program is running.

### Watch for Off-by-One Errors

Because arrays start at 0 rather than 1, you have to be careful not to perform an off-by-one error. An off-by-one error occurs when a loop iterates too many times or one time too few. For example, look at the following pseudocode:

```
// This code has an off-by-one error.
Constant Integer SIZE = 100
Declare Integer numbers[SIZE]
Declare Integer index
For index = 1 To SIZE - 1
Set numbers[index] = 0
End For
```

The intent of this pseudocode is to create an array of integers with 100 elements, to store the value 0 in each element. However, this code has an off-by-one error. The loop uses its counter variable, index, as a subscript with the numbers array. During the loop's execution, the index variable takes on the values 1 through 99, when it should take on the values 0 through 99. As a result, the first element, which is at subscript 0, is skipped.

Assuming numbers is the same as previously declared, the following loop also performs an off-by-one error. This loop correctly starts with the subscript 0, but it iterates one too many, ending with the subscript 100:

```
// ERROR!
For index = 0 To SIZE
Set numbers[index] = 0
End For
```

The last subscript in this array is 100, which will cause bounds checking.

### Partially Filled Arrays

Sometimes you need to store items in an array, but you do not know the exact number of items. A partially filled array is normally used with an accompanying variable that holds the number of items stored. One solution is to make the array large enough to hold the maximum number of items. This can lead to another problem, however: the array will be only partially filled. Program 8-5 shows a demonstration.

### 8-5

// Declare a constant for array size.
Constant Integer SIZE = 100
// Declare an array to hold integer values.
Declare Integer numbers[SIZE]
// Declare a variable to hold the number of items that are actually stored in the array.
Declare Integer count = 0
// Declare a variable to hold the user's input.
Declare Integer number
// Declare a variable to step through the array.
Declare Integer index
// Prompt the user to enter a number.
Display "Enter a number or -1 to quit"
Input number
// If the input is not -1 and the array is not full, process the input.
While (number != -1 AND count < SIZE)
    // Store the input in the array.
    Set numbers[count] = number
    // Increment count.
    count = count + 1
    // Prompt the user for the next number.
    Display "Enter a number or -1 to quit"
    Input number
End While
// Display the values stored in the array.
Display "Here are the numbers you entered:"
For index = 0 To count - 1
    Display numbers[index]
End For
