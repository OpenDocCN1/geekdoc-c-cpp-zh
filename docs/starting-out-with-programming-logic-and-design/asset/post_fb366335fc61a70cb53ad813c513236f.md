# Finding the Highest Value in an Array

Some programming tasks require you to find the highest value in a set of data. For example, suppose you are designing a program that stores several players' golf scores in an array and you need to find the best score. In golf, the lower the score the better, so you would need an algorithm that finds the highest value in the array.

The algorithm for finding the highest value in an array is very similar to the algorithm for finding the lowest score. It works like this: You create a variable named highest. Then, you assign the value at element 0 to the highest variable. Next, use a loop to step through the rest of the array, beginning at element 1. Each time the loop iterates, it compares an array element to the highest variable. If the element is greater than highest, assign that value to highest. When the loop finishes, the highest variable will contain the highest value. The flowchart in Figure 8-7 illustrates this logic. The pseudocode in Program 8-11 shows this.

```
// Declare a constant for the array size.
Integer SIZE = 5

// Declare an array initialized with values.
Integer numbers[SIZE] = 8, 1, 12, 6, 2

// Declare a counter variable for the array.
Integer index

// Declare a variable to hold the highest value.
Integer highest

// Assign the first element to highest.
Set highest = numbers[0]

// Step through the rest of the array,
// beginning at element 1. When a value
// greater than highest is found, assign
// that value to highest.
For index = 1 To SIZE - 1
If numbers[index] > highest Then
Set highest = numbers[index]
End If
End For

// Display the highest value.
Display "The highest value in the array is ", highest
```
