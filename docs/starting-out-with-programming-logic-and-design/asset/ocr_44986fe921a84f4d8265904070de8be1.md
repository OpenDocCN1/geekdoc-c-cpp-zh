# Review Questions 331

Arrays with more than three dimensions are difficult to visualize, but they can be used in some programming problems. For example, in a factory warehouse cases of widgets are stacked on pallets, an array with four dimensions could be used to store a part number for each widget. The subscripts of element could represent the pallet number, case number, row number, and column number of each widget. Similarly, an array with five dimensions could be used if there were multiple warehouses.
