# Chapter 1 Introduction to Computers and Programming

An *interpreter* is a program that translates and executes the instructions in a high level language. As the interpreter reads each individual instruction in the program, it converts it to a machine language instruction and then executes it. This process repeats for every instruction in the program. This is illustrated in Figure 1-19. Because interpreters combine translation and execution, they typically do not create separate machine language programs.

The interpreter translates each high-level instruction to its equivalent machine language instruction and immediately executes it. This process is repeated for each high-level instruction.

> NOTE: Programs that are compiled execute faster than programs that are interpreted because a compiled program is already translated entirely to language when it is executed. A program that is interpreted must be translated at the time it is executed.

The statements that a programmer writes in a high-level language are called *source code*, or simply *code*. Typically, a programmer saves their program's code in a file on the computer's disk. Next, the programmer uses a compiler to translate the code into a machine language, or an interpreter to translate and execute the code. If the code contains a syntax error, it cannot be translated character, or the incorrect use of an operator. A *syntax error* is a mistake like a misspelled keyword, a missing punctuation mark, When this happens the compiler or interpreter displays an error message indicating that the program contains a syntax error. The programmer corrects the error and attempts again to translate the program.

# Integrated Development Environments

Although you use a simple text editor such as Notepad (which is part of the Windows operating system) to write a program, most programmers use specialized software packages called *integrated development environments* or IDEs. Most IDEs combine the programs into one software package:

+   * A text editor that has specialized features for writing statements in a high-level programming language
* A compiler or interpreter
* Useful tools for testing programs and locating errors
