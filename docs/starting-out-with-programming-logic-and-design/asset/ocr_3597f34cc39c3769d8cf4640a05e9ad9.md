# 3.4 Passing Arguments to Modules

```
4 Declare Integer y = 100
5 Declare Integer z = 101
6
7 // Display the values in those variables.
8 Display "x" is set to ", x
9 Display "y" is set to ", y
10 Display "z" is set to ", z
11
12
13 // Pass each variable to setToZero().
14 Call setToZero(x)
15 Call setToZero(y)
16 Call setToZero(z)
17
18 // Display the values now.
19 Display
20 --------------------
21 Display "x" is set to ", x
22 Display "y" is set to ", y
23 Display "z" is set to ", z
24 End Module
25
26 Module setToZero(Integer Ref value)
27 Set value = 0
28 End Module
```

# Program Output

```
x is set to 99
y is set to 100
z is set to 101
------------------
x is set to 0
y is set to 0
z is set to 0
```

In the main module, the variable x is initialized with 99, the variable y is initialized with 100, and the variable z is initialized with 101. In lines 13 through 15 variables are passed as arguments to the setToZero module. Each time the variable is passed as an argument is set to 0. This is shown when the values of the variables are displayed in lines 19 through 21.

> NOTE: In an actual program you should never use variable names like x, y, and z. This particular program is meant for demonstration purposes, and however these names are adequate.

> NOTE: Normally, only variables may be passed by reference. If you attempt to pass a non-variable argument into a reference variable parameter, an error will result using the setToZero module as an example, the following statement will generate an error:

// This is an error!\setToZero(5);
