```

22 Module format(String Ref str)
23 // First, insert the left paren at position 0.
24
25 insert(str, 0, "(")
26
27 // Next, insert the right paren at position 4.
28 insert(str, 4, ")")
29
30 // Next, insert the hyphen at position 8.
31 insert(str, 8, "-")
32 End Module
```

The module accepts a string argument by reference, passed into the parameter variable str. Line 24 calls the insert library module to insert(" at position 0. All of the characters in the string are automatically shifted right one space to accommodate the inserted character. Line 27 inserts the ")" character at position 4, shifting the characters that previously appeared beginning at position 4 to the right one space. Line 30 inserts the "-" character at position 8, shifting the characters that previously appeared beginning position 8 to the right one space. After this statement executes, the string in str will be formatted as (XXX)XXX-XXXX.
