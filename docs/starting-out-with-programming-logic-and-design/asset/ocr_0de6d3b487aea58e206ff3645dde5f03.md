# Programming Exercises

+   1. Backward String
Design a program that prompts the user to enter a string and then displays the string contents backward. For instance, if the user enters "gravity" the program should display "ytivarg."

+   2. Sentence Capitalizer
Design a program that prompts the user to enter a string containing multiple sentences, and then displays the string with the first character of each sentence capitalized. For, if the user enters "hello. my name is Joe. What is your name?" (Hint: the program should display "Hello. My name is Joe. The Toupper library function can be used to convert a single character to uppercase.)

+   3. Vowels and Consonants
Design a program that prompts the user to enter a string. The program should then display the number of vowels and consonants in the string.

+   4. Sum of Digits in a String
Design a program that asks the user to enter a string containing a series of digit numbers without separating them. The program should display the sum of all the digit numbers in the string. For example, if the user enters 2514, the method should return 12, which is the sum of 2, 5, 1, and 4. (Hint: the stringToInteger library function can be used to convert a single character to an integer.)

+   5. Most Frequent Character
Design a program that prompts the user to enter a string, and displays the character that appears most frequently in the string.
