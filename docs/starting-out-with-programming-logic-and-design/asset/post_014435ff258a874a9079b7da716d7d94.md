### Returning Strings

So you've seen examples of functions that return numbers. Most programming languages allow you to write functions that return strings. For example, the following pseudocode prompts the user to enter their name and then returns the string that the user entered.

```
Function String getName()
// Local variable to hold the user's name.
Declare String name
// Get the user's name.
Display "Enter your name."
Input name
// Return the name.
Return name
End Function
```

### Returning Boolean Values

Most languages allow you to write Boolean functions, which return either True or False. You can use a Boolean function to test a condition, and then return True or False to indicate whether the condition exists. Boolean functions are useful for simplifying complex conditions that are tested in decision and repetition structures.

For example, suppose you are designing a program that will allow the user to enter a number, and then determine whether that number is even or odd. The pseudocode shows how to make that determination:

```
If number MOD 2 == 0 Then
Display "The number is even."
Else
Display "The number is odd."
End If
```

The meaning of the Boolean expression tested by this If-Then statement is not clear, let's take a closer look at it:

```
number MOD 2 ==
```

This expression uses the MOD operator, which was introduced in Chapter 2. Recall the MOD operator divides two integers and returns the remainder of the division. So, this pseudocode is saying: "If the remainder of number divided by 2 is 0, then display a message indicating the number is even, or else display a message indicating the number is odd."

Because dividing an even number by 2 will always give a remainder of 0, this logic will work. The pseudocode would be easier to understand, however, if you could rewrite it to say, "If the number is even, then display a message it is even, or else display a message it is odd." As it turns out, this can be done with a Boolean function. In this example, you could design a function named isEven that accepts a number as an argument and returns True if the number is even, or False otherwise. The following is the pseudocode for such a function.

```
Function Boolean isEven(Integer number)
// Local variable to hold True or False.
Declare Boolean status

// Determine whether number is even. If it is, set
// status to True. Otherwise, set status to False.
If number MOD 2 == 0 Then
Set status = True
Else
Set status = False
End If

// Return the value in the status variable.
Return status
End Function
```

Then you can rewrite the If-statement so it calls the isEven function to determine whether the number is even.

```
If isEven(number) Then
Display "The number is even."
Else
Display "The number is odd."
End If
```

Not only is this easier to understand, but now you have a function that you can program in any time you need to test a number to determine whether it is even.

### Mathematical Functions

Most programming languages provide several mathematical functions. These functions typically accept one or more arguments, perform a mathematical operation, and return the result. For example, sqrt and pow.

### The sqrt Function

The sqrt function accepts an argument and returns its square root. Here is an example of how it is used:

```
Set result = sqrt(16)
```

This statement calls the sqrt function, passing 16 as an argument. The sqrt function returns the square root of the argument, which is then assigned to the result variable.

Program 6-9
```
// Variable declarations
Declare number
Declare Real squareRoot

// Get a number.
Display "Enter a number."
Input number

// Calculate and display its square root.
Set squareRoot = sqrt(number)
Display "The square root of number is ", squareRoot
```

### The pow Function

Another common mathematical function is the pow function. The purpose of the pow function is to raise a number to a power. In a nutshell, it does the same thing that we have been using the ^ operator. In some programming languages, however, do not use an operator that raises a number to a power. Instead, they use a function such as pow. Here is how the pow function is used:

```
Set area = pow(4, 2)
```

This statement calls the pow function, passing 4 and 2 as arguments. The function returns the value of 4 raised to the power of 2, which is assigned to the area variable.
