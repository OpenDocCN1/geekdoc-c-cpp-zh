# Chapter 14: Object-Oriented Programming

This chapter compares procedural and object-oriented programming practices. Fields, methods, access specification, constructors, accessors, and mutators are discussed. The student learns how to model classes with UML and how to find the classes in a particular problem.

# Chapter 15: GUI Applications and Event-Driven Programming

This chapter discusses the basic aspects of designing a GUI application. Building graphical user interfaces with visual tools (such as Visual Studio® or NetBeans™) is discussed. The student learns how work in a GUI application and how to write event handlers.

# Organization of the Text

The text teaches programming logic and design in a step-by-step manner. Each chapter covers a major set of topics and builds knowledge as students progress through the book.
