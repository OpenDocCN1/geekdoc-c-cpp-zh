# 10.5 Control Break Logic 421

```
// Print the total for the last student.
Print "Total donations for student: ",
   currencyFormat(studentTotal)
// Print the total of all donations.
Print "Total of all donations: ",
   currencyFormat(total)
// Close the file.
Close donationsFile
End Module
```

Let's take a closer look at the printDetails module. Here is a summary of the variable declarations:

+   * 20 and 21 declare the studentID and donation variables, which will hold the fields for each record read from the file.
* 24 and 25 declare the studentTotal and total variables. The studentTotal is an accumulator that the program will use to calculate the total donations that each student collects. The total variable is an accumulator that calculates the total of all donations.
* 29 declares the currentID variable. This will store the ID number of the student total is currently being calculated.
* 32 declares donationsFile as an internal name associates with the donations.dat file.

Line 33 opens the donations.dat file, and line 36 reads the first record. The values that are read are stored in the studentID and donation variables.

Line 39 assigns the student ID that was read from the file to the currentID variable. The currentID variable will hold the ID of the student records who are currently being processed.

Line 42 is the beginning of the loop that processes the file. The If statement appears in lines 45 through 57 contains the control break. It tests the control variable, studentID, to determine whether it is not equal to currentID. If the two are not equal, then the program has a record with a student ID that is different from the value stored in currentID. This means it has read the last record for the student whose ID is stored in currentID, so the program momentarily breaks out of the process to display the student's total donations (lines 48 and 49), and set the new student ID in currentID (line 53), and reset the studentTotal accumulator (line 56).

Line 60 prints the contents of the current record. Lines 63 and 64 update the accumulator variables. Line 67 reads the next record from the file. Once all the records have been processed, lines 71 and 72 display the total donations for the last student, lines 75 and 76 display the total of all donations, and line 79 closes the file. The report that is printed by the program will appear similar to the sample report previously shown.
