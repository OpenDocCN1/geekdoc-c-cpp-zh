Figure 1-11 shows how you can picture the number 157 stored in a byte of memory. Each 1 is represented by a bit in the position, and each 0 is represented by a bit in the off position.

# Figure 1-11 The bit pattern for 157

![](bbox=[0.294, 0.417, 0.706, 0.532])

128 + 16 + 8 + 4 + 1 = 157

When all of the bits in a byte are set to 0 (turned off), then the value is 0. When all of the bits in a byte are set to 1 (turned on), the byte holds the largest value that can be stored in it. The largest value that can be stored in a byte is 1 + 2 + 4 + 8 + 16 + 32 + 64 + 128 = 255. This limit exists because there are only eight bits in a byte.

If you need to store a number larger than 255? The answer is simple: use more than one byte. For example, we put two bytes together. This gives us 16 bits. The position values of these 16 bits would be $2^0, 2^1, 2^2, 2^3$, up to $2^{15}$. As shown in Figure 1-12, the maximum value that can be stored in two bytes is 65,535. If you need to store a number larger than that, then more bytes are necessary.
