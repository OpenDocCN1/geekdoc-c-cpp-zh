If clauses are left. If none of the conditions are true, the statements following the Else
clause are executed.

The pseudocode in Program 4-7 shows an example of the If-Then-Else If statement.
This program works the same as Program 4-6. Instead of using a nested decision
structure, this program uses the If-Then-Else If statement in lines 9 through 19.

# Program 4-7

```
// Variable to hold the test score
Declare Real score

// Get the test score.
Display "Enter your test score."
Input score

// Determine the grade.
If score < 60 Then
    Display "Your grade is F."
Else If score < 70 Then
    Display "Your grade is D."
    Else If score < 80 Then
        Display "Your grade is C."
    Else If score < 90 Then
        Display "Your grade is B."
    Else
        Display "Your grade is A."
End If
```

> Notice the alignment and indentation that are used with the If-Then-Else If statement
net: The If, Else If, Else, and End If are all aligned, and the conditionally

> You have to use the If-Then-Else If statement because its logic can be coded
with nested If-Then-Else statements. However, a long series of nested If-Then-Else
statements has two particular disadvantages when you are debugging code:

+   - The code can grow complex and become difficult to understand.
- Because indenting is important in nested statements, a long series of nested If-
henElse statements can become too long to be displayed on the computer
screen without horizontal scrolling. Also, statements tend to "wrap around"
 on paper, making the code even more difficult to read.
