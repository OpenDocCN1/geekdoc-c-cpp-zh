## 10.5 Control Block Logic

The file contains a record for each donation. Each record has two fields: containing the ID number of the student who collected the donation (a Integer), and another containing the amount of the donation (a Real). The records in the file are already sorted in order of student ID numbers.

Here is an example of how the report should appear:

```
Pinebrook Academy Fundraiser Report
| Student ID | Donation Amount |
| :--- | :--- |
| 104 | $250.00 |
| 104 | $100.00 |
| 104 | $500.00 |
| Total donations for student: $850.00 |
| 105 | $100.00 |
| 105 | $800.00 |
| 105 | $400.00 |
| Total donations for student: $1,300.00 |
| 106 | $350.00 |
| 106 | $450.00 |
| 106 | $200.00 |
| Total donations for student: $1,000.00 |
| Total of all donations: $3,150.00 |
```

Program 10-14 shows the pseudocode for the program. Let's first look at the main module and the printHeader module:

### Program 10-14 Fundraiser report program: main and printHeader modules

```
1 Module main()
2 // Print the report header.
3 Call printHeader()
4
5 // Print the details of the report.
6 Call printDetails()
7 End Module
8
9 // The printHeader module prints the report header.
10 Module printHeader()
11 Print "Pinebrook Academy Fundraiser Report"
12 Print
13 Print "Student ID Donation Amount"
14 Print "===================================="
15 End Module
```

In the main module, line 3 calls the printHeader module, which prints the report header. Then, line 6 calls the printDetails module, which prints the body of the report. The pseudocode for the printDetails module follows.

### Fundraiser report program (continued): Program 10-14 printDetails module

```
17 // The PrintDetails module prints the report details.
18 Module printDetails()
19 // Variables for the fields
20 Declare Real studentID
21 Declare Real donation
22
23 // Accumulator variables
24 Declare Real studentTotal = 0
25 Declare Real total = 0
26
27 // A variable to use in the control
28 // break logic.
29 Declare Real currentID
30
31 // Declare an input file and open it.
32 Declare InputFile donationsFile
33 Open donationsFile "donations.dat"
34
35 // Read the first record.
36 Read donationsFile studentID, donation
37
38 // Save the student ID number.
39 Set currentID = studentID
40
41 // Print the report details.
42 While NOT e(donationsFile)
43 // Check the student ID field to see if
44 // it has changed.
45 If studentID != currentID Then
46 // Print the total for the student,
47 // followed by a blank line.
48 // Print "Total donations for student: "
49 currencyFormat(studentTotal)
50
51 Print
52 // Save the next student's ID number.
53 Set currentID = studentID
54 // Reset the accumulator.
55 Set studentTotal = 0
56 End If
57 // Print the data for the donation.
58 Print studentID, Tab, currencyFormat(donation)
59 // Update the accumulators.
60 Set studentTotal = studentTotal + donation
61 Set total = total + donation
62 // Read the next record.
63 Read donationsFile studentID, donation
64 End While
```

### 10.5 Control Break Logic

```
// Print the total for the last student.
Print "Total donations for student: ", currencyFormat(studentTotal)
// Print the total of all donations.
Print "Total of all donations: ", currencyFormat(total)
// Close the file.
Close donationsFile
End Module
```

Let's take a closer look at the printDetails module. Here is a summary of variable declarations:

- 20 and 21 declare studentID and donation, which will hold the fields for each record read from the file.
- 24 and 25 declare studentTotal and total variables. studentTotal is an accumulator that the program will use to calculate the total donations each student collects. total is an accumulator that calculates the total of all donations.
- 29 declares currentID. This will store the ID of the student currently being calculated.
- 32 declares donationsFile as an internal name. Line 33 opens donations.dat file, and line 36 reads the first record. The values are read are stored in studentID and donation variables. Line 39 assigns the student ID that was read to currentID. The currentID variable will hold the ID of the student currently being processed.

Line 42 is the beginning of the loop that processes the file. The If statement appearing in lines 45 through 57 contains the control break. It tests studentID to determine whether it is equal to currentID. If the two are not equal, the program has read the last record for the student whose ID is stored in currentID, so the program momentarily breaks out of the process to display the student's total (lines 48 and 49), sets the new student ID (line 53), and resets the studentTotal accumulator (line 56). Line 60 prints the contents of the record. Lines 63 and 64 update the accumulator. Line 67 reads the next record. Once all the records have been processed, lines 71 and 72 display the total for the last student, lines 75 and 76 display the total of all donations, and line 79 closes the file.

NOTE: The logic of this program assumes that the records in donations.dat are already sorted by student ID. If the records are not sorted by student ID, the report will not list all of donations for each student together.

## Print Charts

When writing programs that report on paper, it is sometimes helpful to use a print spacing chart to design the appearance of the report. A print spacing chart is a sheet of paper that has a grid, similar to graph paper. Figure 10-29 shows an example. Each box in the grid represents a space on the page and can hold one character. Numbers printed along the top and side of the chart allow you to identify any space on the page. You simply fill in the report headers and other text where the desired locations are. Then, when writing code, you can use the chart to determine how many blank spaces are located between items, etc.
