# 470 Chapter 11 Menu-Driven Programs

Figure 11-18 shows the logic for the updateInventory module. First, a module named displayUpdateInventoryMenu is called. The purpose of that module is to display the Update Inventory File menu and get the user's selection. The case structure calls the following modules:

+   - addRecord if the user selected menu item 1
- searchRecord if the user selected menu item 2
- modifyRecord if the user selected menu item 3
- deleteRecord if the user selected menu item 4

If the user selects item 5, Go Back to the Main Menu, the program returns to the main module and the main menu is displayed again.
