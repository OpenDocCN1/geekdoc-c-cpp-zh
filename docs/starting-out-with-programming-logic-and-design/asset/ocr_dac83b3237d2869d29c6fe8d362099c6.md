# The Order of Operations

It is possible to build mathematical expressions with several operators. The follow-ing statement assigns the sum of 17, the variable x, 21, and the variable y to the variable answer.

Set answer = 17 + x + x + 21 + y

Some expressions are not straightforward, however. Consider the following statement:

Set outcome = 12 + 6 / 3
