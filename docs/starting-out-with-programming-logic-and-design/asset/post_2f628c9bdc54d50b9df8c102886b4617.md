The module accepts a string by reference, passed into the parameter variable str. The module assumes that the string is properly formatted as (XXX)XXX-XXXX. All of the remaining characters are automatically shifted left by one position to occupy the space left by the deleted character. Next, line 53 deletes the character at position 3, which is the ")" character. The characters that previously appeared at position 4 are automatically shifted to occupy the space left by the deleted character. Next, line 58 deletes the character at position 6, which is the hyphen. The characters previously appearing to the right of the hyphen are moved left by one position. After this statement executes, the string in str will be unformatted, appearing as a string of digits.
