> TIP: Some object-oriented designers note whether a noun is plural or singular. Sometimes a plural noun will indicate a class and a singular noun will indicate an object.

4. Some of the nouns represent simple values that can be stored in a regular variable and do not require a class.

Remember, a class contains fields and methods. Fields are items that are stored within an object of the class, and define the object's state. Methods are actions or behaviors that may be performed by an object of the class. A noun represents a type of item that would not have any identifiable fields or methods, then it can probably be eliminated from the list.
