3. The intended purpose of the following module is to determine whether the value parameter is within a specified range. The module will not work, however. Find the problem.

```
module checkRange(Integer value, Integer lower, Integer upper)
If value < lower AND value > upper
    Display "The value is outside the range."
Else
    Display "The value is within the range."
End If
End Module
```

+   3. Mass and Weight
Scientists measure an object's mass in kilograms and its weight in Newtons. If you know the amount of an object, you can calculate its weight, in Newtons, with the following formula:

> Weight = Mass × 9.8

Design a program that asks the user to enter an object's mass, and then calculates its weight. If the object weighs more than 1,000 Newtons, display a message indicating that it is too heavy. If the object weighs less than 10 Newtons, display a message indicating that it is too light.

+   4. Magic Dates
The date June 10, 1960, is special because it is written in the following format, the month times the days equals the:

6/10/60
Design a program that asks the user to enter a month (numeric form), a day, and a two-digit year. The program should then determine whether the month times the days equals the year. If so, it should display a message saying the date is magic. Otherwise, it should display a message saying the date is not magic.
