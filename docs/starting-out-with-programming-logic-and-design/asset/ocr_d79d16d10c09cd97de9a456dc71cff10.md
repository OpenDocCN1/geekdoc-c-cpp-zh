The program might work like this: A loop prompts the user to enter a patient's weight, or 0 if there are no more weights. A sentinel value must be enough that it will not be mistaken as a regular value in the list. In the example cited above, the doctor (or her medical assistant) enters 0 to signal the end of the list of weights. Because no patient's weight will be 0, this is a good value to use as a sentinel.
