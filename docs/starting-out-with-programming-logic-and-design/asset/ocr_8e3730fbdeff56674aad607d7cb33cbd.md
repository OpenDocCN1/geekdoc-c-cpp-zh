# 15.2 Designing the User Interface for a GUI Program

> CONCEPT: When creating a GUI program you must design the program's windows and all of the graphical components that appear in them.

A GUI program's user interface consists of one or more windows that appear on the screen when the program is running. While creating a GUI program, one of your tasks is to design the windows and all of the graphical elements that appear in them.
