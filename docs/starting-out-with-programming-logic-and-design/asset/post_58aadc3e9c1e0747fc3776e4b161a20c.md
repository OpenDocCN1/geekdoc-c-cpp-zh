## 5.1 Introduction to Repetition Structures

> **CONCEPT:** A repetition structure causes a statement or set of statements to execute repeatedly.

Programmers commonly have to write code that performs the same task over and over. For example, suppose you have been asked to write a program that calculates a 10 percent sales commission for several salespeople. Although it would not be a good design, one approach would be to write the code to calculate one salesperson's commission, and repeat that code for each salesperson. For example, look at the following pseudocode:

```
// Variables for sales and commission.
Declare Real sales, commission

// Constant for the commission rate.
Constant Real COMMISSION_RATE = 0.10

// Get the amount of sales.
Display "Enter the amount of sales."
Input sales

// Calculate the commission.
Set commission = sales * COMMISSION_RATE

// Display the commission
Display "The commission is $", commission
```

This calculates the first salesperson's commission.

And this goes on and on...

As you can see, this is one long sequence structure containing a lot of duplicated code. There are several disadvantages to this approach, including:

- The duplicated code makes the program large.
- Writing a long sequence of statements can be time-consuming.
- If part of the duplicated code has to be corrected or changed, then the correction or change has to be done many times.

Instead of writing the same sequence of statements over and over, a better way to repeatedly perform an operation is to write the code for the operation once, and then place that in a structure that makes the computer repeat it as many times as necessary. This can be done with a repetition structure, which is more commonly known as a loop.

## Condition-Controlled and Count-Controlled Loops

In this chapter, we will look at two broad categories of loops: condition-controlled and count-controlled. A condition-controlled loop uses a true/false control to control the number of times that it repeats. A count-controlled loop repeats a specific number of times. We will also discuss the specific ways that most programming languages allow you to construct these types of loops.

## Condition-Controlled Loops: While, Do-While, and Do-Until

CONCEPT: Both the While and Do-While loops cause a statement or set of statements to repeat as long as a condition is true. The Do-Until loop causes a statement or set of statements to repeat until a condition is true.

## 5.2 Condition-Controlled Loops: Do-While, and Do-Until

### The While Loop

The While loop gets its name from the way it works: *While condition is true, some task.* The loop has two parts: (1) a condition that is tested for a true or false value, (2) a statement or set of statements that is repeated as long as the condition is true. Figure 5-1 shows the logic of a while loop.

**Figure 5-1** The logic of a while loop

![](img/c939132f78787c7f339c6977b3fc8c85_197_0.png)

The diamond symbol represents the condition that is tested. Notice what happens if the condition is true: one or more statements are executed and the program's execution flows back to the point just above the diamond. The condition is tested again, and if it is true, the process repeats. If the condition is false, the program exits. In a flowchart, you will recognize a loop when you see a line going back to a previous part of the flowchart.

### Writing While Loop in Pseudocode

In pseudocode, we will use the While statement to write a while loop. Here is the general format:

```
While condition
    statement
    statement
    etc.
End While
```

> These statements are the body of the loop. They are repeated while the condition is true.

In the general format, the condition is a Boolean expression, and the statements that appear between While and End While are called the body of loop. When the loop executes, the condition is tested. If it is true, the statements in the body of the loop are executed, and the loop starts over. If the condition is false, the program exits. As shown in the general format, you use the following conventions to write a statement:

- Make sure the While clause and End While clause are aligned.
- Indent the statements in the body.

By indenting the statements in the body, you visually set them apart from the surrounding code. This makes your program easier to read and debug. Also, this is similar to the style that many programmers follow when writing loops in actual code. Program 5-1 shows how we might use a While loop to write the commission calculator that was described at the beginning of this chapter.

### Program 5-1

```
// Variables
Declare Real sales, commission
String KeepGoing = "y"

// Constant for the commission rate.
Constant Real COMMISSION_RATE = 0.10

While KeepGoing == "y"
// Get the amount of sales.
Display "Enter the amount of sales."
Input sales

// Calculate the commission.
Set commission = sales * COMMISSION_RATE

// Display the commission
Display "The commission is $", commission
Display "Do you want to calculate another"
Display "commission? (Enter for yes)."
Input KeepGoing
End While
```

## 5.2 Condition-Controlled Loops: While, Do-While, and Do-Until

In line 2, we declare the sales variable, which will hold the amount of sales, and the commission variable, which will hold the amount of commission. In line 3 we declare a String variable keepGoing. Notice that the variable is initialized with the value "y". This initialization value is important, and in a moment you will see why. In line 6 we declare a constant, COMMISSION_RATE, which is initialized with the value 0.10. This is the commission rate that we will use in our calculation.

Line 8 is the beginning of a While loop, which starts like this:

```
keepGoing == "y"
```

Notice the condition is being tested: keepGoing == "y". The loop tests this condition, and if it is true, the statements in the body of line 8 (lines 9 through 21) are executed. The loop starts over at 8. The expression keepGoing == "y" is executed, and if it is true, the statements in the body of the loop are executed. This repeats until the expression keepGoing == "y" is tested in line 8 and found to be false. When that is false, the program exits the loop. This is illustrated in Figure 5-2.

In order for the loop to stop, something has to happen inside the loop to make the expression keepGoing == "y" false. The statements in lines 19 through 21 take care of this. Lines 19 and 20 display a message "Do you want to calculate another commission? (Enter for y)." Then, the Input statement in line 21 reads the user's input and stores it in keepGoing variable. If the user enters a lowercase y, the expression keepGoing == "y" will be true when the loop starts over. But, if it is false, the body of the loop will execute again. If the user enters anything other than y, the expression will be false when the loop starts over, and the program will exit the loop.
