# Summary

As a beginning student, whenever you have trouble getting started with a program design, determine the program's requirements as follows:

+   1. **Input:** Carefully study the problem and identify the pieces of data that the program needs to read as input. Once you know what data is needed as input, decide the names of the variables for these pieces of data, and their data types.
2. **Process:** What must the program do with the input that it will read? Determine the calculations and/or processes that must be performed. At this time, decide the names and data types of any variables needed to hold the results of calculations.
3. **Output:** What output must program produce? In most cases, it will be the results of the program's calculations and/or processes.

Once you have determined these requirements, you will have an understanding of what the program must do. You will also have a list of variables and their data types. The next step is writing the algorithm in pseudocode, or drawing it as a flowchart.
