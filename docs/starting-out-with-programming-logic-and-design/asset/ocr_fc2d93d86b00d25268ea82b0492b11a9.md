# Chapter 12 Text Processing

| Function | Description |
| --- | --- |
| length(string) | Returns the number of characters in string. For example, the expression length("Test") would return 4, a string that is. |
| append(string1, string2) | Returns a string that is created by appending string2 to the end of string. For example, the expression append("Hello \ "World") would return the string "Hello World". |
| toUpper(string) | Returns a string that is an uppercase copy of string. For example, the expression toUpper("Test") would return the string "TEST". |
| toLower(string) | Returns a string that is a lowercase copy of string. For example, the expression toLower("TEST") would return the string "test". |
| substring(string, start, end) | Returns a substring of string. The substring is the set of characters starting at the position specified by start and ending at the position specified by end.(The first character in string is at position 0). For example, the expression substring("Kevin", 2, 4) would return the string "vin". |
| contains(string1, string2) | Returns True if string1 contains string2. Otherwise it returns False. For example, the expression contains("smiley", "mile") would return True, and the expression contains("Smiley", "xyz") would return False. |
| stringToInt(string) | Converts string to an Integer and returns value. For example, the expression stringToInteger("77") would return the value 77. |
| stringToReal(string) | Converts string to a Real and returns value. For example, the expression stringToReal("1.5") would return the value 1.5. |
| isInteger(string) | Returns True if string can be converted to an Integer, or False otherwise. For example, the expression isInteger("77") would return True, and the expression isInteger("x4yz") would return False. |
| isReal(string) | Returns True if string can be converted to a Real, or False otherwise. For example, the expression isReal("3.2") would return True, and the expression isReal("x4yz") would return False. |
