# ## 11.1 Introduction to Menu-Driven Programs

**CONCEPT:** A menu is a list of operations that are displayed by a program. The user can select one of the operations and the program will perform it.

A menu-driven program displays a list of operations that it can perform on the screen, and allows the user to select the operation that he or she wants the program to perform. The list of operations that is displayed on the screen is called a *menu*. For example, a program that manages a mailing list might display the menu shown in Figure 11-1.
