# 13.3 Examples of Recursive Algorithms

The first parameter, array, is the array to be searched. The next parameter, first, holds the subscript of the first element in the search area (the portion of the array to be searched). The next parameter, last, holds the subscript of the last element in the search area. The last parameter, value, holds the value to be searched. Like the binarySearch function shown in Chapter 9, this function returns the subscript of the value if it is found, or -1 if the value is not found. Program 13-7 demonstrates the function.
