As shown in the hierarchy chart, the main module will call two other modules.
Here are summaries of these modules:

+   - showIntro—This module will display a message on the screen that explains what the program does.
- cupsTounces—This module will accept the number of cups as an argument and calculate and display the equivalent number of fluid ounces.

In addition to calling these modules, the main module will ask the user to enter the number of cups. This value will be passed to the cupsTounces module. Program 3-8 shows the pseudocode for the program, and Figure 3-17 shows a flowchart.
