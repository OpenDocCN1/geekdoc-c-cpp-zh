- 9.4 The sequential search algorithm uses a loop to step through each element of an array, comparing each element's value with the value searched for. The binary search algorithm, which requires the values in the array to be sorted in order, starts at the element in the middle of the array. If the middle element's value is greater than the value searched for, the algorithm tests the element in the first half of the array. If the middle element's value is less than the value searched for, it tests the element in the last half of the array. Each time the array does not find the value searched for, it eliminates half of the remaining portion. This method continues until the value is found, or there are no more elements to test. The binary search is more efficient than the sequential search.
