Variables are "variable" because they can hold different values while a program is running. Once you store a variable to a value, that will remain in the variable until you store a different value in the variable. For example, look at the pseudocode in Program 2-6.

## Program 2-6

```
- Set dollars = 2.75
- Display "I have " , dollars, " in my account."
- Set dollars = 99.95
- Display "But now I have " , dollars, " in my account!"
```

## Program Output

I have 2.75 in my account.
Now I have 99.95 in my account!

Line 1 sets the dollars variable to 2.75, so when the statement in line 2 executes, it displays "I have 2.75 in my account." Then, the statement in line 3 sets the dollars to 99.95. As a result, the value 99.95 replaces the value 2.75 that was previously stored in the variable. When line 4 executes, it displays "But now I have 99.95 in my account!" This program illustrates important characteristics of variables:

- A variable holds only one value at a time.
- When you store a value in a variable, that value replaces the previous value that was in the variable.

## In the Spotlight: Calculating Cell Overage Fees

Suppose your cell plan allows you to use 70 minutes. If you use more than this, you are charged 35 cents for each excess minute. To make sure you understand the steps, first, you want to look closely at the way, using only pencil and paper:

## Manual Algorithm (Using pencil and paper)

- 1. Get the number of minutes that you have.
- 2. Multiply the number of minutes by 0.35.
- 3. The result is your overage fee.

Ask the following questions about this algorithm:

> Question: What do I need to perform?
Answer: I need the number of minutes.

> Question: What must I do with the input?
Answer: I multiply the input (the number of minutes) by 0.35.

> Question: What output must I produce?
Answer: The overage fee.

Now that you have identified the input, the process that must be performed, and the output, you can write the general steps of the program:

## Computer Algorithm

- 1. Get the number of minutes as input.
- 2. Calculate the overage fee by multiplying the number of minutes by 0.35.
- 3. Display the overage fee.

In Step 1 of the computer algorithm, the program gets the number of minutes from the user. Any program needs the user to enter a piece of data, and it does two things: (1) it displays a message prompting the user for the piece of data, and (2) reads the data that the user enters on the keyboard, and stores that data in a variable. In pseudocode, Step 1 of the algorithm will look like this:

```
Display "Enter the number of minutes."
Input excessMinutes
```

Notice that the Input statement stores the value entered by the user in a variable named excessMinutes.
