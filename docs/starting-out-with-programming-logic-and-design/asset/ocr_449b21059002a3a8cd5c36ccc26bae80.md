Let's take a closer look at the first loop, which appears in lines 12 through 16.
Here is the first line of the loop:

```
For index = 0 To SIZE - 1
```

This specifies that the index variable is assigned the values 0 through 2 as the loop executes. Notice we used the expression SIZE – 1 as the ending value for the index variable? Remember, the subscript of the last element in an array is one less than the size of the array. Notice in this case, the subscript of the last element of the array is 2, which is the value of the expression SIZE – 1.

Notice inside the loop, in line 15, the index variable is used as a subscript:

```
Input hours[index]
```

During the first iteration, the index variable is set to 0, so the user's input is stored in hours[0]. During the next iteration, the user's input is stored in hours[1]. Then, during the last iteration the user's input is stored in hours[2]. The loop correctly starts and ends the index variable with valid values (0 through 2).

There is one thing to point out about Program 8-3. This program reads the number of hours worked by three employees referred to as "employee number 1," "employee number 2," and "employee number 3." Here are the Display statements that appear inside the first loop, in lines 13 and 14:

```
Display "Enter the hours worked by"
Display "employee number ", index + 1
```

Notice the second display statement uses the expression index + 1 to display the employee number. What would you think if we left out the + 1 part of the expression, and the statements were written like this?

```
Display "Enter the hours worked by"
Display "employee number ", index
```
