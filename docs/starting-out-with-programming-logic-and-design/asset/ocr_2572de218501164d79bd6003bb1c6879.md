14 End Module

Program 3-4 has three modules: main, showSquare, and showHalf. Notice that the showSquare has a local variable named number (declared in line 7) and the showHalf module also has a local variable number (declared in line 17). It is legal for the two modules to have a local variable with the same name because the variables are not in the same scope. The scope of the two number variables is shown in Figure 3-11.
