# The If-Then-Else If Statement

Even though Program 4-6 is a simple example, the logic of the nested decision structure is fairly complex. Most languages provide a special version of the decision structure known as the If-Then-Else If statement, which makes this type of logic simpler. In pseudocode we will write the If-Then-Else If statement using the following general format:

```
If condition_1 Then
    statement
    etc.
Else condition_2 Then
    statement
    etc.
Insert as many Else If clauses as necessary
Else
    statement
    statement
    etc.
End If
```

When the statement executes, condition_1 is true. If condition_1 is true, the statements that immediately follow are executed, up to the Else If. The rest of the structure is ignored. If condition_1 is false, however, the program jumps to the very next Else If and tests condition_2. If it is, the statements that immediately follow are executed, up to the next Else clause. The rest of the structure is ignored. This process continues until a condition is found to be true, or no more Else
