# 3. Geometry Calculator

Write a program that displays the following menu:

- Geometry Calculator
1. Calculate the Area of a Circle
2. Calculate the Area of a Rectangle
3. Calculate the Area of a Triangle
4. Quit
Enter your choice (1–4).

If the user enters 1, the program should ask for the radius of the circle and then display its area. Use the formula to calculate the circle's area:

```
area = πr^2
```

Use 3.14159 for $\pi$ and the radius of the circle for $r$.

If the user enters 2, the program should ask for the length and width of the rectangle, and then display the rectangle's area. Use the formula to calculate the rectangle's area:

```
area = length × width
```

If the user enters 3, the program should ask for the length of the triangle's base and its height, and then display its area. Use the formula to calculate the area of the triangle:

```
area = base × height × .5
```

If the user enters 4, the program should end.

### 12.2 Character-by-Character Text Processing

Sometimes the data that a program must work with comes in the form of text. Word processors, messaging applications, web browsers, and spellcheckers are just a few examples of. The earlier chapters in this book have demonstrated some text processing techniques, such as case-sensitive and case-insensitive string comparisons, sorting strings in an array, and searching for substrings within a string. In addition, Chapter 6 introduced several standard library functions that perform operations on strings. For your convenience, these functions are summarized in Table 12-1. These functions are useful, but sometimes you need to operate on strings at a more detailed level.

| Function | Description |
| :--- | :--- |
| length(string) | Returns the number of characters in string. For example, the expression length("Test") would return 4. |
| append(string1, string2) | Returns a string that is created by appending string2 to the end of string. For example, the expression append("Hello", "World") would return the string "Hello World". |
| toUpper(string) | Returns a string that is an uppercase copy of string. For example, the expression toUpper("Test") would return the string "TEST". |
| toLower(string) | Returns a string that is a lowercase copy of string. For example, the expression toLower("TEST") would return the string "test". |
| substring(string, start, end) | Returns a substring of string. The substring is the set of characters starting at the position specified by start and ending at the position specified by end. (The first character in string is at position 0). For example, the expression substring("Kevin", 2, 4) would return the string "vin". |
| contains(string1, string2) | Returns True if string1 contains string2. Otherwise it returns False. For example, the expression contains("smiley", "mile") would return True, and the expression contains("Smiley", "xyz") would return False. |
| stringToInt(string) | Converts string to an Integer and returns value. For example, the expression stringToInt("77") would return the value 77. |
| stringToReal(string) | Converts string to a Real and returns value. For example, the expression stringToReal("1.5") would return the value 1.5. |
| isInteger(string) | Returns True if string can be converted to an Integer, or False otherwise. For example, the expression isInteger("77") would return True, and the expression isInteger("x4yz") would return False. |
| isReal(string) | Returns True if string can be converted to a Real, or False otherwise. For example, the expression isReal("3.2") would return True, and the expression isReal("x4yz") would return False. |
