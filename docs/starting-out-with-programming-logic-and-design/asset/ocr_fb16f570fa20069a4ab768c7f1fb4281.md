# 15.2 Designing the User Interface for a GUI Program

# Table 15-1 Common GUI components

| Component | Description |
|---|---|n| Button | A component that causes an action to occur when it is clicked |
| Label | An area that can display text |
| Text box | An area in which the user may type a single line of input from the keyboard |
| Check box | A component that has a box that may be checked or unchecked |
| Radio button | A component that can be selected or deselected; usually appears in groups and allows the user to select several options |
| Combo box | A component (combination of a list and a text box) that displays a drop-list of items from which the user may select; provides a text box in which the user may input |
| List box | A list from which the user may select an item |
| Slider | A component that allows the user to select a value by moving a slider along a track |

> NOTE: GUI components are also known as controls and widgets.

# Component Names

In many IDEs, you must assign unique names to the components that you place in a window. A component's name identifies the component in the program, in the same way that a variable's name identifies the variable. For example, Figure 15-8 shows a window from a program that calculates gross pay. The figure also shows the names that the programmer assigned to each component in the window. Notice that each component's name describes the component's purpose in the program. For example, the text box that the user enters the number of hours worked is named hours, and the button that calculates the gross pay is named calcButton. Additionally, in many programming languages, the rules for naming components are the same as the rules for naming variables.
