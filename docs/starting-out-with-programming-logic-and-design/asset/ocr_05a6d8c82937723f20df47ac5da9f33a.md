# Chapter 14 Object-Oriented Programming

> NOTE: In some languages, such as C++, the act of declaring a class variable creates an object in memory. In these languages, it is not necessary to use the New key to create the object as we did in line 9 of Program 14-1.

The statement, which appears in line 12, is next:

```
CallPhone.setManufacturer("Motorola")
```

This statement calls the phone.setManufacturer method. The expression setManufacturer is written in dot notation. It called dot notation refers to the dot. On the left side of the dot is the name of a class variable that references an object. On the right side of the dot is the name of the method we are calling. When this statement executes, it uses the object referenced by phone to call the setManufacturer method, passing the string "Motorola" as an argument. As a result, the string "Motorola" will be assigned to the object's manufacturer field.

Line 13 calls the phone.setModelNumber method, passing the string "M1000" as an argument. After this statement executes, the string "M1000" will be stored in the object's number field. Line 14 calls the phone.setRetailPrice method, passing 99.99 as an argument. This 99.99 will be assigned to the retailPrice field. The statements in lines 17 through 19 display the values in the object's fields. Here is the statement in line 17:

```
Display "The manufacturer is ", phone.getManufacturer()
```

This statement calls the phone.getManufacturer method, which returns the string "Motorola". The following message is displayed on the screen:

The manufacturer is Motorola
