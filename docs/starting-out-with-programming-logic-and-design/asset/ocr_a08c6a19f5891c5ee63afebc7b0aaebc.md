# Print Spacing Charts

When writing programs that report on paper, it is sometimes helpful to use a print spacing chart to design the appearance of the printed report. A print spacing chart is a sheet of paper that has a grid, similar to graph paper. Figure 10-29 shows an example. Each box in the grid represents a space on the page, and it can hold one character. Numbers that are printed along the top and side of the chart allow you to identify any space on the page. You simply fill in the report headers and other text where the desired locations are. Then, when writing code, you can use the chart to determine how many blank spaces to be located between items, etc.

Figure 10-29 is an example of a print spacing chart for the donations program that you saw in Program 10-14. Notice that the report header and other unchanging text is written in the chart exactly as it is to appear in the report. Where the student ID numbers and donations are to be printed, we write 9s to indicate the positions of numeric digits.

NOTE: You can write Xs instead of 9s to represent variable data in the report; however, it is a common practice to use 9s to represent digits, and Xs to represent characters.
