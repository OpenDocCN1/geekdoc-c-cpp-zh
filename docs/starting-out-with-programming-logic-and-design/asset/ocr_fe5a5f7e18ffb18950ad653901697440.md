# 2.1 Designing a Program

> CONCEPT: Programs must be carefully designed before they are written. During the design process, programmers use tools such as pseudocode and flowcharts to create models of programs.

In Chapter 1 you learned that programmers typically use high-level languages to write programs. However, all professional programmers will tell you that a program should be carefully designed before the code is actually written. When programmers begin a new project, they jump right into start writing code as the first step. They begin by creating a design of the program.

After designing it, the programmer begins writing code in a high-level language. Recall from Chapter 1 that each language has its rules, known as syntax, that must be followed when writing a program. A language's syntax dictates how key words, operators, and punctuation characters can be used. A syntax error occurs if the programmer violates any of these rules.

If the program contains a syntax error, or even a simple mistake like a misspelled keyword, the compiler or interpreter will display an error message indicating what the error is. Virtually all code contains syntax errors when it is written, so the programmer will typically spend some time correcting these. Once all of the syntax errors and simple mistakes have been corrected, the program can be compiled and translated into a language program (or executed by an interpreter, depending on the language being used).
