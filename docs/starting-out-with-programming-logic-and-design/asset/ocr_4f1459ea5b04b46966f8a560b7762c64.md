# Application Software

Programs that make a computer useful for everyday tasks are known as application software. These are the programs that people spend most of their time running on their computers. Figure 1-1, at the beginning of this chapter, shows from two commonly used applications—Microsoft Word, a word processing program, and Microsoft PowerPoint, a presentation program. Some other examples of application software are spreadsheet programs, email programs, Web browsers, and game programs.
