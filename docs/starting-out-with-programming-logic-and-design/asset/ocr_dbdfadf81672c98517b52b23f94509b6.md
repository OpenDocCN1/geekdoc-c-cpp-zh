The determineCommissionRate function accepts the amount of sales as an argument, and it returns the applicable commission rate for that amount of sales. Line 63 declares a local variable named rate that will hold the commission rate. The If-Then-Else If statement in lines 66 through 76 tests the sales parameter and assigns the correct value to the local variable. Line 79 returns the value in the local rate variable.
