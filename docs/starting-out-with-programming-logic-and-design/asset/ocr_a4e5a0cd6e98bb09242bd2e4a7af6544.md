# Designing a Count-Controlled While Loop

In situations, it is best to use the For statement to write a count-controlled loop. Most languages, however, it is possible to use any looping mechanism to create a count-controlled loop. For example, you can create a count-controlled While loop, a count-controlled Do-Until loop, or a count-controlled Do-Until loop. Regardless of the type of mechanism that you use, count-controlled loops perform initialization, test, and increment operation on a counter.

In pseudocode, you can use the following general format to write a count-controlled While loop:

+   Declare counter = startingValue
While counter <= maxValue
  statement
  statement
  Set counter = counter + 1

End While

The ①, ②, and ③ callouts show where the initialization, test, and increment actions are performed.

+   ① shows the declaration of an Integer variable that will be used as the counter. The variable is initialized with the appropriate starting value.
② shows where the While loop tests the expression counter <= maxValue. In this general format, maxValue is the maximum value that the counter can be set to.
③ shows where I is added to the counter variable. In a While loop, the counter variable will not automatically incremented. You have to explicitly write a statement that performs this action. It's important that you understand how this statement works, so let's take a closer look at:
