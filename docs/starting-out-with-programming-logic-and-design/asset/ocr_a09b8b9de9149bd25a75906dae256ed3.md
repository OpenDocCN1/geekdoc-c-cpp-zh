> TIP: Program 5-8 has a constant, MAX_VALUE, that represents the counter variable's maximum value. The first line of the loop could have been written as follows, to achieve the same result:
For counter = 1 To 5
Although creating the named constant is not necessary for this simple program, creating named constants to represent important values is a good habit. Recall from Chapter 2 that named constants make a program easier to read and easier to maintain.
