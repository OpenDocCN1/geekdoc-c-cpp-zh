This is how the statement would be executed by the computer: First, the computer would get the value of the expression on the right side of the = operator, which is counter + 1. Then, that value would be assigned to the counter variable. The effect of the statement is that 1 is added to the counter variable.

> WARNING! If you forget to increment the counter variable in a count-controlled loop, the loop will iterate an infinite number of times.

The pseudocode in Program 5-14 shows an example of a count-controlled while loop. This program follows the same logic that you previously saw in Figure 5-13, and displays "Hello world" five times. Figure 5-17 points out where the counter's initialization, test, and increment occur in the pseudocode.

# Program 5-14

```
// Declare and initialize a counter variable.
Declare Integer counter = 1
// Constant for the maximum value
Constant Integer MAX_VALUE = 5
While counter <= MAX_VALUE
  Display "Hello world"
  Set counter = counter + 1
End While
```
