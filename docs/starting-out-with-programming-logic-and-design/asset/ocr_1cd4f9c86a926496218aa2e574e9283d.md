# 3.2 Defining and Calling a Module

As you can see from the hierarchy chart, the main module will call several other modules. Here are summaries of these modules:

+   - startingMessageThis module will display the starting message that tells the technician what the program does.
- step1—This module will display the instructions for Step 1.
- step2—This module will display the instructions for Step 2.
- step3—This module will display the instructions for Step 3.
- step4—This module will display the instructions for Step 4.

Between calls to these modules, the main module will instruct the user to press a key to see the next step in the instructions. Program 3-2 shows the pseudocode for the program. Figure 3-9 shows the flowchart for the main module, and Figure 3-10 shows the flowcharts for the startingMessage, step1, step2, step3, and step4

# Program 3-2

```
Module main() {
    // Display the starting message.
    Call startingMessage()
    Display "Press a key to see Step 1."

    // Display Step 1.
    Call step1()
    Display "Press a key to see Step 2."

    // Display Step 2.
    Call step2()
    Display "Press a key to see Step 3."

    // Display Step 3.
    Call step3()
    Display "Press a key to see Step 4."

    // Display Step 4.
    Call step4()
End Module

// The startingMessage module displays
// the program's starting message.
Module startingMessage() {
    Display "This program tells you how to"
    Display "disassemble an ACME laundry dryer."
    Display "There are 4 steps in the process."
}
End Module

// The step1 module displays the instructions
// for Step 1.

```
