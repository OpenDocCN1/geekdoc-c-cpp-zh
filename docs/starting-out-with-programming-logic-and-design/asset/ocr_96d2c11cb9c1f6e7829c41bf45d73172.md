# The Do-While Loop

You have learned that the while loop is a pretest loop, which means it tests its condition before performing an iteration. The Do-While loop is a postloop. This means it performs an iteration before testing its condition. As a result, the Do-While loop always performs at least one iteration, even if the condition is false to begin with.
