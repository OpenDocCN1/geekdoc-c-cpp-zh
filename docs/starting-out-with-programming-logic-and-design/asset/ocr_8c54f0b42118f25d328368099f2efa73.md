# Returning Strings

So you've seen examples of functions that return numbers. Most programming lan-
gauges allow you to write functions that return strings. For example, the
seudocode prompt prompts the user to enter his or her name, and then returns the
string that the user.

```
Function String getName()
// Local variable to hold the user's name.
Declare String name
// Get the user's name.
Display "Enter your name."
Input name
// Return the name.
Return name
End Function
```

# Returning Boolean Values

Most languages allow you to write Boolean functions, which return either True or
False. You can use a Boolean function to test a condition, and then return True
or False to indicate whether the condition exists. Boolean functions are useful for
simplifying complex conditions that are tested in decision and repetition structures.

For example, suppose you are designing a program that will allow the user to enter
number, and then determine whether that number is even or odd. The pseudo-
dcode shows how to make that determination. Assume the number is an Integer
variable the number entered by the user.

```
If MOD 2 == 0 Then
Display "The number is even."
Else
Display "The number is odd."
End If
```
