# Chapter 3

+   3.1 A module is a group of statements that exist within a program for the purpose of forming a specific task.

+   3.2 A large task is divided into smaller tasks that are easily performed.

+   3.3 If a specific operation is performed in several places in a program, a module can be written once to perform that operation, and be executed any time it is needed.

+   3.4 Modules can be written for the common tasks that are needed by the different programs. These modules can then be incorporated into each program that needs them.

+   3.5 When a program is developed as a set of modules that each performs an individual task, then different programmers can be assigned the job of writing different modules.
