# Preface

Welcome to Starting Out with Programming Logic and Design, Fourth Edition.
This book uses a language-independent approach to teach programming concepts and problem-solving skills, without assuming any previous experience. By using easy-to-understand pseudocode, flowcharts, and other tools, the student learns to design the logic of programs without the complication of language syntax.

Fundamental topics such as data types, variables, input, output, control structures, modules, functions, arrays, and files are covered as well as object-oriented concepts, GUI development, and event-driven programming. As all the books in the Starting Out . . series, this text is written in clear, easy-to-understand language that students find friendly and inviting.

Each chapter presents a multitude of program design examples. Short examples that highlight specific programming topics are provided, as well as more involved examples that focus on problem solving. Each chapter includes at least one in the Spotlight section provides step-by-step analysis of a specific problem and demonstrates a solution to that problem.

This book is ideal for programming logic course that is taught as a precursor to a language-specific introductory programming course, or for the first part of an introductory programming course in which a specific language is taught.

# Changes in the Fourth Edition

This book's pedagogy, organization, and clear style remain the same as in the previous edition. Many improvements have been made, which are summarized here:

- An explanation of read-only memory, or ROM, has been added to Chapter 1.
- The section on secondary storage in Chapter 1 has been updated to include a discussion on cloud storage.
- IPO charts are now introduced in Chapter 2.
- A discussion about adding parentheses to a math expression to enhance the expression's clarity, even when they are necessary to get the correct result, has been added to Chapter 2.
- Off-page connectors for flowcharts have been introduced in Chapter 2, and added to the flowchart reference in Appendix B.
- A discussion on easier maintenance as an additional benefit of modularization has been added to Chapter 3.
- A cautionary warning about the use of reference variables has been added to Chapter 3.
- The section on local variables in Chapter 3 has been expanded with an additional example and a diagram showing the scope of two variables with the same name in different modules.
- A discussion on how the order of subexpressions in a compound Boolean expression can affect code efficiency in a language that performs short-circuit evaluation has been added to Chapter 4.
- A discussion on how and why statements that call functions are written differently than modules has been added to Chapter 6.
- A discussion on how some of the more popular languages always pass arrays by reference has been added to Chapter 8.
- A new and better example of control-break processing has been added to Chapter 10.
- Appendix D is a new appendix on converting decimal to binary.
- New motivational programming exercises have been added to several chapters.
- The book's Language Reference Guides have been updated. All of the book's Language Reference Guides are available on the book's resource at www.pearsonheired.com/gaddis.
- A new application, Flowgorithm, is available to support the book. Flowgorithm is free software that allows you to create programs using simple flowcharts.

# Brief Overview of Each Chapter

### Chapter 1: Introduction to Computers
This chapter begins by giving how computers work, how data is stored and manipulated, and how we use pseudocode and flowcharts.

### Chapter 2: Input, Processing, and Output
This chapter introduces data types, variables, and sequence. The student learns to input, perform mathematical operations, and produce output.

### Chapter 3: Modules
This chapter introduces the top-down design approach. Student learns to define and call modules, pass arguments to modules, and use variables.

### Chapter 4: Decision Structures and Boolean Logic
In this chapter students explore relational operators and Boolean expressions. The If-Then, If-Then-Else, and Nested decision structures are covered.

### Chapter 5: Repetition Structures
This chapter shows how to use loops. Counters, accumulators, running totals, and sentels are discussed.

### Chapter 6: Functions
This chapter discusses common library functions, such as those for generating random numbers. After learning how to call library functions and how to use values returned by functions...

### Chapter 7: Input Validation
This chapter discusses the importance of validating input. The student learns to write input validation loops that serve as traps.

### Chapter 8: Arrays
In this chapter the student learns to create and work with one- and two-dimensional arrays. Many examples of array processing are provided...

### Chapter 9: Sorting and Searching Arrays
In this chapter the student learns the basics of sorting arrays and searching for data in them. The chapter covers the bubble sort, selection sort, insertion sort, and binary search.

### Chapter 10: Files
This chapter introduces sequential file input and output. The student learns to read and write large sets of data, store data as fields and records, and design programs that work with both files and arrays.

### Chapter 11: Menu-Driven Programs
In this chapter the student learns to design programs that display menus and execute tasks according to the user's menu selection.

### Chapter 12: Text Processing
This chapter discusses text processing at a detailed level. Algorithms that step through the individual characters in a string are discussed, and several common library functions for character and text processing are introduced.

### Chapter 13: Recursion
This chapter discusses recursion and its use in problem solving. A visual trace of recursion is provided, and recursive applications are discussed.
