# 13.3 Examples of Recursive Algorithms

This function's base case is when the start parameter is greater than the end parameter. If this is true, the function returns the value 0. Otherwise, the function executes the following statement:

```
Return array[start] + rangeSum(array, start + 1, end)
```

This statement returns the sum of array[start] plus the return value of a recursive call. Notice that in the recursive call, the starting element in the range is start + 1. In essence, this means “return the value of the first element in the range plus the sum of the elements in the range.” The pseudocode in Program 13-4 demonstrates:

# Program 13-4

```
Module main(){
    // Declare a constant for the array size.
    Constant Integer SIZE = 9

    // Declare an Integer array.
    Declare Integer numbers[SIZE] = 1, 2, 3, 4, 5, 6, 7, 8, 9

    // Declare a variable to hold a sum.
    Declare Integer sum
    Set sum = rangeSum(numbers, 2, 5)

    // Display the sum of elements 2 through 5.
    Display "The sum of elements 2 through 5 is "", sum
End Module

    // The rangeSum function returns the sum of a specified
    // range of elements in array. The start parameter
    // specifies the starting element. The end parameter
    // specifies the ending element.
    Function rangeSum(Integer array[], Integer start, Integer end)
        If start > end
            Return 0
        Else
            Return array[start] + rangeSum(array, start + 1, end)
    End Function
```

# Program Output

The sum of elements 2 through 5 is 18
