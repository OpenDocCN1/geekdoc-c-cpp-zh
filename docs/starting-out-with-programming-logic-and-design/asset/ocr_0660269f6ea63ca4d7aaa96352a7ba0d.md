# # The CPU

When a computer is performing the tasks a program tells it to do, we say that the computer is running or executing the program. The central processing unit, or CPU, is the part of a computer that actually runs programs. (The CPU is often referred to as the processor.) The CPU is the most important component in a computer because without it, computer could not run software.
