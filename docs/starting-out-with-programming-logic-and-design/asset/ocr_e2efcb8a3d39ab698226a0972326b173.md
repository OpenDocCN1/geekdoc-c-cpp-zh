# 15.2 Designing the User Interface for a GUI Program

+   3. Set the components' properties to the desired values.

A component's properties control its visual characteristics, as color, size, position, and any text that is displayed on the component. To get the visual appearance that you want, set each component's properties to the desired values. In most IDEs, you will use a property window to set the starting values for the properties of each component.
