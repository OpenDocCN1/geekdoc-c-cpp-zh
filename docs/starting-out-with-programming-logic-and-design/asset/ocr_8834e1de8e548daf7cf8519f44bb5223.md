The random function returns an integer value, so you can write a call to the function anywhere that you can write an integer value. You have already seen examples where the function's return value is assigned to a variable and where value is sent to the Display statement. To further illustrate the point, there is a state that uses the random function in a math expression:

`Set x = random(10, 1) * 2`

In this statement, a random number in the range of 1 through 10 is generated and multiplied by 2. The result is assigned to the x variable. You can test the return value of the function with an If-Then statement, as demonstrated in the following In Spotlight section.
