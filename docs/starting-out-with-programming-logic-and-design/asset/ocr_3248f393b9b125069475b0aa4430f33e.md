# 5.2 Condition-Controlled Loops: While, Do-While, and Do-Until 175

In line 2, we declare the sales variable, which will hold the amount of sales, and the commission variable, which will hold the amount of commission. In, line 3 we declare a String variable keepgoing. Notice that the variable is initialized with the value "y". This initialization value is important, and in a moment you will see why. In line 6 we declare a constant, COMMISSION RATE, which is initialized with the value 0.10. This is the commission rate that we will use in our calculation.

Line 8 is the beginning of a While loop, which starts like this:

```
keepgoing == "y"
```

Notice the condition is being tested: keepgoing == "y". The loop tests this condition, and if it is true, the statements in the body of line 8 (lines 9 through 21) are executed. The loop starts over at 8. The expression keepgoing == "y" is executed, and if it is true, the statements in the body of the loop are executed. This repeats until the expression keepgoing == "y" is tested in line 8 and found to be false. When that is false, the program exits the loop. This is illustrated in Figure 5-2.

In order for the loop to stop, something has to happen inside the loop to make the expression keepgoing == "y" false. The statements in lines 19 through 21 take care of this. Lines 19 and 20 display a message "Do you want to calculate another commission? (Enter for y)." Then, the Input statement in line 21 reads the user's input and stores it in keepgoing variable. If the user enters a lowercase y), the expression keepgoing == "y" will be true when the loop starts over. But, if it is false, the body of the loop will execute again. If the user enters anything other than y, the expression will be false when the loop starts over, and the program will exit the loop.

![](bbox=[0.125, 0.526, 0.342, 0.542])

This condition is tested.

```
While keepgoing == "y"
// Get the amount of sales.
Display "The amount of sales."
Input sales
// Calculate the commission.
Set commission = sales * COMMISSION_RATE
// Display the commission
Display "The commission is $",, commission
Display "Do you want to calculate another"
Display "commission? (Enter for y)."
Input keepgoing
End While
```

If the condition is true, these statements are executed, and then the loop starts over.

If the condition is false, these statements are skipped and the program exits the loop.

Now that you have the pseudocode, look at the program output in the sample run. First, the program prompted the user to enter the amount of sales. The user entered 10000.0, and then the program displayed the commission for that amount, which is $1000.00. Then, the user is prompted "Do you want to calculate another commission?"
