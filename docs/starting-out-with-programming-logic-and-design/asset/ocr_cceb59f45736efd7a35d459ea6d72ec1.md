# Programming Exercises

+   1. Bug Collector

A bug collects bugs every day for seven days. Design a program that keeps a running total of the number of bugs collected during the seven days. The loop should ask for the number of bugs collected for each day, and when the loop is finished, the program should display the number of bugs collected.

+   2. Calories Burned

Running on a particular treadmill will burn 3.9 calories per minute. Design a program that uses a loop to display the number of calories burned after 10, 15, 20, 25, and 30 minutes.

+   3. Budget Analysis

Design a program that asks the user to enter the amount he or she has budget. A loop should prompt the user to enter each of or her expenses for the month, and keep a running total. When the loop finishes, the program should display the amount that is over or under budget.

+   4. Sum of Numbers

Design a program with a loop that asks the user to enter a set of positive numbers. The user should enter a negative number to signal the end of the series. After all the positive numbers have been entered, the program should display their sum.
