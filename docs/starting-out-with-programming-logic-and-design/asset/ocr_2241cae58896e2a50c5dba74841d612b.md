# Sequentially Searching an Array

CONCEPT: The sequential search algorithm is a simple technique for finding an item in an array. It steps through the array, beginning at the first element, and compares each element to the item being searched. The search stops when the item is found or the end of the array is reached.

Programs need to search for data that is stored in an array. Various techniques known as search algorithms have been developed to locate a specific item in a larger collection of data, such as an array. This section shows you how to use the simplest of all algorithms—the sequential search. The sequential search uses a loop to sequentially step through an array, starting with the first element. It compares each element with the value being searched for and stops when the value is found or the end of the array is reached. If the value is not in the array, the algorithm unsuccessfully searches to the end of the array.
