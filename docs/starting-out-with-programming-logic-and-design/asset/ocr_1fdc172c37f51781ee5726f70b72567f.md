# Programming Style and the If-Then Statement

As shown in Figure 4-6, you should use the following conventions when you write an
If-Then statement:

+   - Make sure the If clause and the End If clause are aligned.
- Indent the conditionally executed statements that appear between the If clause
and the End If clause.

By indenting the conditionally executed statements you make your program easier to read and debug. Mostprogrammers use this style of writing If-Then statements in both pseudocode and
code.
