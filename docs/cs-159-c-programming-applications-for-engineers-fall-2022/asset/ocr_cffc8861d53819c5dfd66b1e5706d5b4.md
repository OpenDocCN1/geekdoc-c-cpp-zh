# Pointer Arithmetic and Arrays (Single Dimension Arrays only)

What takes place when you attempt to add an integer to an address? The result of arithmetic can be used to access and change elements of an array.

```
void changeArray(int *y)
{
   int i;
   temp = *y;

   for(i = 1; i < SIZE; i++)
   {
      *(y + i - 1) = *(y + i);
   }

   *(y + i - 1) = temp;
}
```

```
#define SIZE 5

void printArray(int *);
void changeArray(int *);

int main(void)
{
   int x[SIZE] = {3, 5, 7, 9, 10};

   changeArray(x);
   printArray(x);

   return(0);
}

void printArray(int *y)
{
   int i;

   for(i = 0; i < SIZE; i++)
      printf("%d\n", *(y + i));
}
```

```
Output Generated:
y[0] = 5
Y[1] = 7
Y[2] = 9
Y[3] = 10
Y[4] = 3
```

The application of the indirection operator (*) to the sum of the starting memory address and an integer produces the element at the index of the integer.

```
a[x] == *(a + x)
```
