# Searching

Searching is the process used to find the location of a target in a data set. Perhaps the location, number of occurrences, or presence of the target in the data set provides us with more information about the target.

We will explore two different searching algorithms, the sequential search followed by the binary search. In addition to understanding the logic of each algorithm we will look at issues of efficiency and they compare to each other.

+   • In the sequential search we traverse the array one index at a time until we find the target or search the entire array. Assumptions about our data set include that every element is unique and the data is not sorted.
