# # Complements

Each of the six relational operators is a complement of another relational operator. Whenever one logical expression is true its complement would be false. Whenever one logical expression is false its complement would be true.

+   - For example, x < 3 represents all numbers less than 3, the complement x >= 3 represents all other values.
