# The %s Placeholder

The %s placeholder represents a string and is used in both familiar input and output functions.

# Example of %s placeholder in action:

```
```c
char str1[SIZE];
printf("Enter a string -> ");
scanf("%s", str1); //NOTICE NO &, WHY IS THIS?!
printf("The string you entered was %s.\n", str1);
```
```

# Output of previous code segment

Enter a string -> Purdue
The string you entered was Purdue.

+   * The scanf function only reads in the data up until a new line (\'\n\') or any white space is entered.

Enter a string -> Go Purdue
The string you entered was Go.

# The solution? Find an alternative to scanf!

```
```c
printf("Enter a string -> ");
gets(str1);
printf("The string you entered was %s.\n", str1);
```
```

What happens to the '\n' character entered by the user? The gets function will accept the input, terminated by a new line, and make a delimiter-terminated string out of it.
