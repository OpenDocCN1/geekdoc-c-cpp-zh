# Converted loop:

# Without altering the initialization values, convert the while loop into a for loop:

```
int lov = 1;
int n = 4;
int nFact = 1;
while (lov <= n)
{
    nFact *= lov;
    lov++;
}
```

# Converted loop:

# Without altering the initialization values, convert the while loop into a for loop:

```
int lov;
int n = 4;
int nFact = 1;
lov = n;
while (lov > 0)
{
    nFact *= lov;
    lov--;
}
```
