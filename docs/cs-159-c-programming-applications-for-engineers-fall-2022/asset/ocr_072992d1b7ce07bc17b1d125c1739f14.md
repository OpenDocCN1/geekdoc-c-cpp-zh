# Why are the values being compared with the control expression in single quotes?

The data type of the control expression is character (char) and to compare the results of such an expression with a character literal constant requires that the value be placed inside of single quotes.

If we were comparing integer values then NO single integer quotes would be used.

# Why is it challenging to test two floating-point values for equality?

+   - Representing floating-point data is not exact and is likely to contain round-off errors.
+   - The smallest difference at some seemingly insignificant decimal place will result in the equality operator generating a false value.
+   - Try the following and modify to identify other values that do not work as expected:

float x = 0.1;
x == 0.1 ? printf("True!\n") : printf("False!\n");
