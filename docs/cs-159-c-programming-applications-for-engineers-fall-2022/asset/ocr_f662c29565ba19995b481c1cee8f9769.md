```
void exchangeValues(int, int);

int main(void)
{
    int x = 3;
    int y = 5;
    printf("Before the function: x = %d y = %d\n", x, y);
    exchangeValues(x, y);
    printf("After the function: x = %d\n", x, y);
    return(0);
}
void exchangeValues(int a, int b)
{
    int temp;
    printf("Before the exchange: a = %d\n", a, b);
    temp = a;
    a = b;
    b = temp;
    printf("After the exchange: a = %d b = %d\n", a, b);
}
```

+   - If possibility #1 is true, then changing a will not change x as evidenced by the final print statement in main.
+   - If possibility #2, then upon changing the variable a in the called function we will observe the variable x being changed when control is returned to main.
