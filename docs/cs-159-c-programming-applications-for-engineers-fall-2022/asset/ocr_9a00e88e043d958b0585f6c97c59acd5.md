# Solving the factorial using a recursive function:

```
```c
int factorial (int n)
{
    int nFact = 1;
    if (n > 1)
    {
        nFact = n * factorial (n - 1);
    }
    return (nFact);
}
```

# Solving the factorial with the while loop:

```
```c
int factorial (int n)
{
    int nFact = 1;
    while (n > 0)
    {
        nFact *= n--;
    }
    return (nFact);
}
