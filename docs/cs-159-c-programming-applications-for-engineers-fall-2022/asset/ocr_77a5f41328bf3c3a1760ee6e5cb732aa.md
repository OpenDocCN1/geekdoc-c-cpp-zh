# Use the code segment below for problems 7 – 8

```
int x;
int y;
int z;

int total = 0;

for(x = 1; x < 9; x += 2)
{
    for(y = 1; y < 30; y *= 2)
    {
        for(z = 54545; z != 0; z /= 10)
        {
            total += 1;
        }
    }
}

printf("total: %d\n", total);
printf("sum: %d\n", x + y + z);
```
