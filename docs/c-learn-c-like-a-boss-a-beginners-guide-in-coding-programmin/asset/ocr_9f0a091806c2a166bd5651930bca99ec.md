# ## Variable definitions

A variable definitions instructs the compiler how much and where to store and create the variable. It specifies the data type and lists one or more of the variables of the type. For example

```
~~~
type variable_list;
~~~
```

You have to have a valid data type that is listed above. They may contain one or more identifier names as long as they are separated by commas, such as

```
~~~
int ---- j,k,l;
char----c,ch;
float---- f, salary;
~~~
```
