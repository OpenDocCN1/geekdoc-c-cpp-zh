# Three Important Components of C++

The standard C++ is made up of three very important concepts.

+   - **Core Language:** This is made up of all the variables, data types, literals, and other important aspects of the language, creating building blocks to get to the next level
+   - **C++ Standard Library:** this allows you to manipulate files, and other workings within the language, and bend them to your will.
+   - **STL:** This stands for Standard Template Library, which gives you functions to manipulate data structures and variables and other things of the sort.
