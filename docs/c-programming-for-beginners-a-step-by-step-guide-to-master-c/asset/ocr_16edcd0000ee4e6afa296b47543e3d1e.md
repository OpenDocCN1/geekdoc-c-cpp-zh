# Character Constant

Character constant represented as a single character enclosed within a single quote. These can be single digit, single special symbol or white spaces as '9', 'c', '$', ' ' etc. Every character constant has a unique integer like value in machine's character code as if machine using ASCII (American standard code for information interchange).
