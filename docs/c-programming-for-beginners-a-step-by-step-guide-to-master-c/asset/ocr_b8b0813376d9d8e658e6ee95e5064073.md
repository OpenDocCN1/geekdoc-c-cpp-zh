| Basic data type | Data type with qualifier | Size (byte) | Range |

| | short or signed short int | 2 | -128 to 127 |
| | unsigned short int | 2 | 0 to 65535 |
| | long or signed long int | 4 | -2147483648 to 2147483647 |
| | unsigned long int | 4 | 0 to 4294967295 |
| float | float | 4 | -3.4E-38 to 3.4E+38 |
| double | double | 8 | 1.7E-308 to 1.7E+308 |
