The declaration of an array tells the compiler that, the data type, name of the array, size of the array and for each element it occupies memory space. Like int data type, it occupies 2 bytes for each element and for float it occupies 4 byte for each element etc. The size of the array operates the number of elements that can be stored in an array and it may be a int constant or constant int expression.
