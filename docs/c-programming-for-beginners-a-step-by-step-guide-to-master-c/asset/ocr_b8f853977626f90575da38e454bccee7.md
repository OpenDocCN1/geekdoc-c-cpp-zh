# Environments (IDE)

The process of editing, compiling,
running, and debugging programs is
often managed by a single integrated
application known as an Integrated
Development Environment, or IDE for
short. An IDE is a windows-based
program that allows us to easily manage
large software programs, edit files in
windows, and compile, link, run, and
debug programs.
