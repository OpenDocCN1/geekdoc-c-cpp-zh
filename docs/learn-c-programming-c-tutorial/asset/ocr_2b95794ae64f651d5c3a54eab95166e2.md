You can also use an array of pointers to character to store a list of strings as follows:

```c
#include <stdio.h>

const int MAX = 4;

int main ()
{
    char *names[] = {
                    "Zara Ali",
                    "Hina Ali",
                    "Nuha Ali",
                    "Sara Ali",
                };
    int i = 0;

    for ( i = 0; i < MAX; i++)
    {
        printf("Value of names[%d] = %s\n", i, names[i] );
    }
    return 0;
}
```

Value of names[0] = Zara Ali

Value of names[3] = Sara Ali
