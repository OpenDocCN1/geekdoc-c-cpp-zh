Manipulation of these bits is usually implemented using a set of macros or functions that rely on C's bitwise operators. As shown in Table 4-4, both the bitwise and Boolean operators provide the basic operations of AND, OR, exclusive-OR (XOR), and NOT. However, Boolean operators are used to form conditional expressions (as in an `if` statement) while the corresponding set of bitwise operators are used to manipulate bits.

| Operation | Boolean Operator | Bitwise Operator |
| :--- | :--- | :--- |
| AND | `&&` | `&` |
| OR | `||` | `|` |
| XOR | `unsupported` | `^` |
| NOT | `!` | `~` |

The older C compilers did not provide a Boolean data type, and programmers had to use integer variables to hold Boolean values. The Boolean operators were designed to yield results of type `int`, with true and false represented by 1 and 0, respectively. When interpreting integer values as Boolean values, a value of zero is treated as false, and *any* nonzero value is considered true.

Bitwise operators work on individual bit positions within the operands; that is, the result in any single bit position is entirely independent of all the other bit positions.
