# 2.3.1 Signed Integers

So far, we have only considered how to represent unsigned integers in binary. When signed integers are required, however, we must extend the simple positional representation. Although a single bit could be added to indicate sign, computers do not simply append it to an independently represented magnitude. It turns out that using such a sign-plus-magnitude approach would actually complicate the hardware design of the arithmetic unit, and so another method called 2's complement is used instead.

As is seen in Figure 2-4, the 2's-complement representation of positive values is the same as for unsigned representation. The negative values can be derived by counting backwards from zero. Just as with the odometer on a new car that is driven in reverse, when we back up from zero, the binary count rolls over to all 1's and then decrements from there.
