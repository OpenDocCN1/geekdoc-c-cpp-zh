```
Boolean: (5 || !3) && 6
=> (true OR (NOT true)) AND true
=> (true OR false) AND true
=> (true) AND true
=> true
=> 1

Bitwise: (5 | ~3) & 6
=> (00.0101 OR ~00.0011) AND 00.0110
=> (00.0101 OR 11.1100) AND 00.0110
=> (11.1101) AND 00.0110
=> 00.0100
=> 4
```
