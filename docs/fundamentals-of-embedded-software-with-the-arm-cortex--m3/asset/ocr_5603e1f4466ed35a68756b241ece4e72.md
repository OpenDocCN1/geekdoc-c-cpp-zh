+   (e) Semaphores

+   4. Some processors have two sets of registers: one for integer operations and one for floating-point operations. Under what conditions must the context switch also save and restore the floating-point registers? (Circle all that apply.)
+   (a) The floating-point registers must always be saved and restored.
+   (b) If floating-point operations are used only in a single thread.
+   (c) If floating-point operations are used in more than one thread.
