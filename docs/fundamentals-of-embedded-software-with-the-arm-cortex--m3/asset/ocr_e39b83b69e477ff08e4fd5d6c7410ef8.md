# 4.2 BOOLEAN DATA TYPES

The original C language also did not include a Boolean data type, and it was not added until the 1999 C99 standard. Traditionally, C used integer data types to hold Boolean values. For backward compatibility, C99 created both a new primitive integer data type _Bool that can only hold values of 0 and 1 and a new standard header file called stdbool.h containing the following macro definitions:

```
#define bool    _Bool
#define False   ((_Bool) 0)
#define true    ((_Bool) 1)
```

2 A value of zero is interpreted as Boolean false, and any other value (even a negative value) is interpreted as true. Boolean operators are guaranteed to produce a result of either 0 (false) or 1 (true).
