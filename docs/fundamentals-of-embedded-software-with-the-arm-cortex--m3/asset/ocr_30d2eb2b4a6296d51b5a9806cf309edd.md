# 16. The following function transmits a packet of information over a serial communications line but may transmit corrupted packets when called by more than one thread in a multithreaded application. Describe what changes (if any) are required and why (a) when a preemptive kernel is used and (b) when a non-preemptive kernel is used. [Hint: Do not forget that the function SendByte might yield while waiting for the device to be ready!]
void SendPacket(int type, char *packet, int length)
{
    SendByte(0xFF);
    SendByte(type);
    SendByte(length);
    while (length--) SendByte(*packet++);
}
