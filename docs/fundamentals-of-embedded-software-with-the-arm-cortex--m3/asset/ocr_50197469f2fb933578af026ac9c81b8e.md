Structure members may be used like regular variables are referenced using one of the two member selection operators. With “sue” declared as just shown, “sue.age” and “sue.gender” are used to reference the two member elements of “sue,” as in

```
sue.age = 25 ;
```

By default, function parameters are passed by value, which means that the function is given a copy of the parameter. Rather than taking execution time to copy the structure, we usually prefer to pass only its address. The function prototype might then look like this:

```
void foo(PERSON *p) ;
```

Inside the function, we have only a pointer to the structure. In such a case, we must use different syntax so that a reference to the “age” member of the structure pointed to by “p” becomes

```
p->age = 21 ;
```
