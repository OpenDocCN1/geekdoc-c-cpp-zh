7. The function shown below causes run-time errors when called by more than one thread in a multithreaded application. Explain the cause of the problem, and then modify the function to correct the problem without changing the function's parameter list or its return value.

```
int ExtractWords(char *sentence, char *words[])
{
    char *word;
    int count;
    count = 0;
    word = sentence;
    for (;;) {
        word = strtok(word, ";,:.?!");
        if (!word) break;
        words[count++] = word;
        word = NULL;
    }
    return count;
}
```
