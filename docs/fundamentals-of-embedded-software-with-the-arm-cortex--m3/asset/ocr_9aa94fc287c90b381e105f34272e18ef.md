However, it becomes trivial once you notice that, starting from zero, the least significant bit changes on every count, the next least significant bit changes on every two counts, the one after that changes on every four bits, and so on. No matter how many bits are used in the representation, a value of zero is always represented by all 0's (00 ... 0). This fact, together with the previous observation, makes it trivial to reconstruct a complete binary count sequence for numbers containing an arbitrary number of bits.
