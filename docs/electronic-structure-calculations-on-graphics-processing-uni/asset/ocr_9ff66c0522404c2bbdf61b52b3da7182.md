# Appendix A: Definitions and Conventions

+   - $\hat{H}$ Hamiltonian operator
+   - $\hat{T}$ Kinetic energy operator
+   - $H(k)$ k-Dependent Hamiltonian matrix
+   - $\hat{V}^{loc}$ Local potential
+   - $\hat{V}^{nl}$ Non-local potential
+   - $\hat{\Psi}$ Pseudo-wavefunction (in PAW)
+   - $\tilde{\phi}_n$ Approximate wavefunction in iterative diagonalization
+   - $n_e$ Number of electrons
+   - $N_p$ Number of plane waves
+   - $N_{band}$ Number of bands included in calculation
+   - $N_c$ Bands with non zero occupation. $N_c \ge n_e$
+   - $\Omega$ Unit Cell Volume
+   - $f_{nk}$ Occupancy of monoelectronic wavefunction $\psi_{nk}$
+   - $\Psi_{nk}$ Monoelectronic wavefunction
+   - $u_{nk}$ Periodic part of the monoelectronic function. As the wavefunction $\psi_{nk}$ is closely related to $u_{nk}$ by the Bloch theorem, in the following, we will often use an approximate shortcut and refer to $u_{nk}$ as the wavefunction.

# Appendix B: Example Kernels

We provide here reference implementations of common kernels in plane-wave DFT. These kernels can be found in source form on Github$^2$.

```
static __global__ void proj_forward_k(cuDoubleComplex *phase,
 cuDoubleComplex *u_,
 cuDoubleComplex *u_fp,
 int n_band,
 int p_size,
 int p_size,
 int nband
 {
 const int tdx = threadIdx.x + blockIdx.x * blockDim.x;
 const int nthread = blockDim.x * gridDim.x;
 int idx;
 cuDoubleComplex phase_local;
 for (int i = tdx; i < p_size; i += nthread) {
 idx = perm[i] - 1;
 phase_local = phase[i];
 for (int j = blockIdx.y; j < nband; j += gridDim.y){
 u_rp[i * j*p_size.x - phase_local.x * u_r.fldx - j * u_size.x,
 - phase_local.y * u_r.fldy - j * u_size.y,
 u_rp[i * j*p_size.y - phase_local.x * u_r.fldx - j * u_size.y,
 + phase_local.y * u_r.fldy - j * u_size.x;
 }
 }
 }
```
