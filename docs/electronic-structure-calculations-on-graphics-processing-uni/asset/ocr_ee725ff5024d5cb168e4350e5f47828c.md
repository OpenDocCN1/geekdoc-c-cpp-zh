Among several ways of correcting MRC CCSD energies (for details see Ref. [101] and references therein), the simplest approach is based on adding diagrams accounting for the effect of triples to the diagonal elements of the MRC CCSD effective Hamiltonian matrix ($H^{eff}(CCSD)$) in a way analogous to that of the single reference CCSD(T) approach, that is,

```
$H_{\mu\nu}^{eff}(T) = H_{\mu\nu}^{eff}(CCSD) + \delta_{\mu\nu} s_{\mu}^{T}(T^{\mu}),
\delta_{\mu\nu}(T^{\mu\nu}) = E_{\mu}^{(5)}(\mu) + E_{\nu}^{(5)}(\nu) + E_{SR}^{(5)}(\mu),$
```

where $\delta_{\mu\nu}$ represents Kronecker $\delta$ function. The $E_{\mu}^{(4)}(\mu)$, $E_{SR}^{(5)}(\mu)$, and $E_{SR}^{(4)}(\mu)$ terms represent fourth- and fifth-order contributions, given by the expressions

```
$E_{\mu}^{(4)}(\mu) = \frac{1}{36} \sum_{abijk} \langle \Phi_{\mu}^{ijkab} | V_N | (T_2^i T_2^j) | \Phi_c \rangle c_{jk}^{abk}(\mu),
E_{SR}^{(5)}(\mu) = \sum_{ai} s_i^a(\mu) r^{ai}(\mu),
E_{SR}^{(4)}(\mu) = \frac{1}{4} \sum_{abcdijk} f_{ik}(\mu) t_{ij}^{ab}(\mu) t_{jk}^{abck}(\mu),$
```

where the $s_i^a(\mu)$ intermediate is defined as

```
$s_i^a(\mu) = \frac{1}{4} \sum_{bkj} \langle bc || kj \rangle t_{ik}^{abjc}(\mu).$
```

The form of these corrections is the same for both the BW-MRCCSD and Mk-MRCCSD effective Hamiltonians. Although several forms of the triply excited cluster amplitudes $t_{ijk}^{abc}(\mu)$ have been Discussed [102–106], we will employ the simplest choice defined by the formula

```
$t_{ijk}^{abc}(\mu) = \frac{\langle \Phi_{\mu}^{ijkab} | V_N | (T_2^i T_2^j) | \Phi_c \rangle}{D_{\mu}^{abc}(\mu)},$
```

which is analogous to the form of the $T_2$ operator utilized by the CCSD(T) method. In all our implementations, the $H^{eff}(CCSD)$ operator includes up to two-body terms. The total cost of this procedure (further referred to as the MRCCSD(T) approach) scales as $M \times N^2$, which poses a significant computational challenge.

# 14.3 NWChem Software Architecture

Two main concepts influenced the original design of NWChem conceived in 1993:
