# 7.2.4 Force and Stress

Forces are computed by differentiating the total energy function with respect to ionic positions:

```
F_i^\mu = -\frac{\partial E[\rho]}{\partial R_i^\mu}. \tag{7.15}
```

where \(\mu\) indexes the spatial components and \(i\) indexes the atomic centers.

The total energy is equal to the sum of the electronic energy from the Hamiltonian in Eq. (7.1) and the electrostatic energy due to the ions. This last term will be denoted by \(U[\{R\}]\):

```
E_{tot}(\{f\}, \{u\}, \{R_i\}) = \frac{1}{N_k} \sum_{nk} f_{nk} \langle u_{nk} | T + V^{nl} | u_{nk} \rangle + \frac{1}{2} \iint dr dr' \frac{\rho(r)\rho(r')}{|r - r'|} + E_x[\rho] + \int dr V_{ion}^{loc}(r)\rho(r) + U[\{R\}]. \tag{7.16}
```

where the local potential is separated into its electron-electron Coulombic (Hartree), electron-electron exchange-correlation, and electron-ion Coulombic contributions. Let us introduce \(V_{ext}(r)\), \(D_{ij}^{ion}\), and the onsite density \(\rho_{ij}\):

```
V_{ext}(r) = \frac{\partial E_{tot}}{\partial \rho} = V_{ion}^{loc}(r) + \int dr' \frac{\rho(r')}{|r - r'|} + \frac{\delta E_x[\rho]}{\delta \rho}. \tag{7.17}
```

```
D_{ij}^{ion} = D_{ij} + \int dr V_{ext}(r) Q_{ij}(r). \tag{7.18}
```

```
\rho_{ij} = \sum_{nk} f_{nk} \langle u_{nk} | \beta_i \rangle \langle \beta_j | u_{nk} \rangle. \tag{7.19}
```

Using these definitions, the total energy can be written as

```
E_{tot}(\{f\}, \{u\}, \{R_i\}) = \frac{1}{N_k} \sum_{nk} f_{nk} \langle u_{nk} | T | u_{nk} \rangle + \int dr V_{eff}(r)\rho(r) + \frac{1}{N_k} \sum_{ij} D_{ij} \rho_{ij} + U[\{R\}]. \tag{7.20}
```

leading to the following expression for the forces:

```
F_i^\mu = -\frac{\partial U[\{R\}]}{\partial R_i^\mu} - \int dr \frac{\partial V_{ion}^{loc}(r)}{\partial R_i^\mu} \rho(r) - \int dr V_{ext}(r) \sum_{ij} \frac{\partial Q_{ij}(r)}{\partial R_i^\mu} \rho_{ij} - \sum_{ij} D_{ij}^{ion} \sum_{nk} f_{nk} \left[ \langle u_{nk} | \frac{\partial \hat{\beta}_i}{\partial R_i^\mu} | \beta_i \rangle \langle \beta_i | u_{nk} \rangle + \langle u_{nk} | \beta_i \rangle \langle \beta_i | \frac{\partial \hat{\beta}_i}{\partial R_i^\mu} | u_{nk} \rangle \right]. \tag{7.21}
```

where we have used

```
\frac{\partial \rho(r)}{\partial R_k^\nu} = \sum_{nk} f_{nk} \sum_{ij} \frac{\partial Q_{ij}(r)}{\partial R_k^\nu} \langle \beta_i | u_{nk} \rangle \langle u_{nk} | \beta_j \rangle + Q_{ij}(r) \frac{\partial (\langle \beta_i | u_{nk} \rangle \langle u_{nk} | \beta_j \rangle)}{\partial R_k^\nu}. \tag{7.22}
```
