## 前言

过去十年中，图形处理单元（GPU）在数值模拟中的使用取得了巨大增长，涵盖了所有科学领域。GPU 最初设计用于图形应用和可视化中的协处理器，现已进入主流计算平台和许多最强大的超级计算机。尽管 GPU 硬件设计投入了大量精力，但其在科学计算中的潜力只有在专用编程方法的并行发展以及面向大规模并行处理器重新设计底层数值算法之后才得以实现。

电子结构计算计算密集度高，该领域在高性能计算方面有着长期突破极限的历史。随着 GPU 的兴起，这一传统得以延续。许多研究人员投入了大量精力，开发利用 GPU 计算能力的软件实现。本书通过将这些工作汇编为单一参考资料，向这些发展致敬。

我们编写本书旨在介绍大规模并行 GPU 上电子结构计算这一快速发展的领域。目标读者是理论与计算化学、凝聚态物理和材料科学领域的研究生和资深研究人员，他们希望了解该领域的易懂概述，以及希望进入 GPU 和混合 GPU/CPU 编程以进行电子结构计算的软件开发人员。为此，本书提供了 GPU 计算概述、GPU 编程简介、电子结构理论基本背景，以及最广泛使用的电子结构方法的代码开发和应用最新示例。

我们力求收录所有已开发 GPU 实现的广泛使用的电子结构方法。文本涵盖了所有常用基组，包括局域高斯型和斯莱特型基函数、平面波、小波以及基于实空间网格的方法。若干章节详细介绍了双电子积分计算、交换-相关求积、Fock 矩阵构建、自洽场方程求解、计算核梯度以获取力的策略，以及在密度泛函理论中处理激发态的方法。其他章节则聚焦于半经验方法和关联波函数方法，包括密度拟合的第二阶 Møller-Plesset 扰动理论，以及迭代和扰动性单参考与多参考耦合簇方法。

我们在编辑本书的过程中享受了陡峭的学习曲线，并相信您，读者，会发现它是一本引人入胜且实用的参考书。

## 术语表

以下提供了 GPU 和 GPU 编程相关术语的详细术语表。它偏向于 NVIDIA GPU 和 CUDA 编程模型。然而，AMD GPU 使用类似的概念和硬件实现。例如，NVIDIA 硬件上的 CUDA warp 在 AMD 硬件上称为 wavefront。这并非旨在详尽列出所有术语，而是旨在为读者提供本书中出现的各种 GPU 相关技术术语的简要描述。

**带宽** 传输一个字节数据所需时间的倒数。通常以 GB/s 为单位。

**块** 一组线程，可在 GPU 上执行期间共享数据和通信。块之间的数据无法同步。块在单个 SM 上执行。为优化性能，块大小需要根据问题和硬件（例如，可用共享内存）进行调整。Kepler 架构中，块中的线程数限制为 1024。线程块以 warp 为单位创建和执行；因此，线程数应为 warp 大小（目前为 32）的倍数。线程块在其网格中具有块 ID。

**缓存** 用于降低全局内存访问延迟的快速内存。在具有 Kepler 架构的 NVIDIA GPU 上，SM 共享一个 1.5MB 大小的缓存。这可以被视为 L2 缓存，因为每个 SM 都有一个称为共享内存的 L1 缓存。

**常量内存** 可由主机写入并被所有 SM 访问的快速只读内存。可用的常量内存数量有限。

**设备** 包括处理器和内存的 GPU。设备无法处理位于主机上的数据。

**全局内存** GPU 上可用的内存。可比拟于主机上的主内存。对全局内存的数据访问是缓存的，但由于延迟较高，与 GPU 上的其他内存类别相比较慢。与主机内存相比，全局设备内存支持高数据带宽。在当前具有 Kepler 架构的 NVIDIA 硬件上，数据路径宽度为 512 位；因此，可以在一个周期内获取 16 个连续的 32 位字。因此，步进内存访问会导致带宽显著下降。例如，步长为二的访问将获取 512 位但只使用其中一半。设备内存比主机内存少，目前 NVIDIA Tesla K40 上最高可达 12GB。主机可以访问全局内存，以便在主机和设备之间传输数据。全局内存内核启动之间是持久的。

**网格** 一组映射到 GPU 上流式多处理器并执行内核的块。GPU 上块的执行顺序不是确定性的。在 Kepler 架构中，单个多处理器上可以同时激活 16 个块。
