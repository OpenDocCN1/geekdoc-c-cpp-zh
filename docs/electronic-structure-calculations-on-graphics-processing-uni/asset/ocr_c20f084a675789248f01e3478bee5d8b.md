A stationary solution of the self-consistent equations can be obtained by a simple mixing approach:

```
\( P_{n+1} = \frac{1}{2}(I - \text{sign}(S^{-1}\hat{H}_n - \mu_n I))S^{-1}, \quad \)
\( \hat{H}_{n+1} = (1 - \alpha)\hat{H}_n + \alpha H_{n+1}, \quad \)
```

where \(\alpha\) is a mixing parameter between 0 and 1, and \(\hat{H}_n\) an auxiliary matrix. The fixed point implies that \(\hat{H}_n = H_n\) and \(SP_n H_n - H_n P_n S = 0\). For each iteration, the total electronic energy (\(E_n\)) and Hamiltonian matrix (\(H_n\)) are computed from the density matrix \(P_n\). The value of the chemical potential \(\mu_n\) is determined by bisecting a suitable interval until \(|\text{trace}(P_{n+1}S) - N_e| < \frac{1}{e}\), for a given \(N_e\). Note that the \(\text{trace}(P_{n+1}S)\) is integer-valued unless infinite accuracy is employed in the calculation of the sign function. For a given SCF threshold (\(\epsilon_{\text{SCF}}\)), the convergence criterion employed is \(E_n - E_{n-1} < \epsilon_{\text{SCF}} N_e\).

More advanced algorithms that still use fix point iterations exist. They include the optimization of the chemical potential [8] as part of the density matrix computation, and achieve faster convergence by relaxing absolute trace conservation [9]. These methods represent a significant advance over the sign matrix iteration, if the chemical potential is not known in advance, as the cumbersome bisection can be omitted. Also trace resetting (TRS) purification starts from a normalized Hamiltonian matrix (\(X_n\)) eigenvalues in the interval [0, 1]. The algorithm then calls for iterations where the update depends on the value of the quantity \(\gamma_n = (N - \text{trace}(F(X_n)))/\text{trace}(G(X_n))\).

| \(\gamma_n\) | Update |
| :--- | :--- |
| \(\gamma_n > \gamma_{max}\) | \(X_{n+1} = 2X_n - X_n^2\) |
| \(\gamma_n < \gamma_{min}\) | \(X_{n+1} = X_n^2\) |
| \(\gamma_n \in [\gamma_{min} \gamma_{max}]\) | \(X_{n+1} = F(X_n) + \gamma_n G(X_n)\) |

The choice of the polynomial functions \(F\) and \(G\) is not unique, but an efficient algorithm (TRS4) is achieved by using

```
\( F(x) = x^2(4x - 3x^2), \quad \) (8.5)
```

```
\( G(x) = x^2(1 - x^2). \quad \) (8.6)
```

For this choice of polynomials the values for \(\gamma_{min}\) and \(\gamma_{max}\) are 0 and 6, respectively.

Another class of algorithms aims at a direct minimization of the energy functional, avoiding the self-consistent mixing, and thus adding robustness. To achieve this, the constraints on the density matrix have to be included into the algorithm. In the work of Li _et al._ [10] this was achieved by using an extended energy functional. Helgaker _et al._ [11] proposed a parameterization of the density matrix, that conserves idempotency. Within this curry-step method [12, 13], starting from an idempotent \(P_0\), as obtained for example from the TRS method, one performs updates of the form

```
\( P_{n+1} = e^{-\Delta} P_n e^{\Delta}, \quad \) (8.7)
```

where \(\Delta\) is an anti-Hermitian matrix, \(\Delta^\dagger = -\Delta\). This unitary transformation is evaluated using the Baker-Campbell-Hausdorff expansion

```
\( P_{n+1} = P_n + [P_n, \Delta]_s + \frac{1}{2}([P_n, \Delta]_s, \Delta]_s + \frac{1}{6}([[P_n, \Delta]_s, \Delta]_s, \Delta]_s + \cdots \quad \) (8.8)
```

where the commutator within a nonorthogonal basis is

```
\( [X, \Delta]_s = XS\Delta - \Delta SX. \quad \) (8.9)
```
