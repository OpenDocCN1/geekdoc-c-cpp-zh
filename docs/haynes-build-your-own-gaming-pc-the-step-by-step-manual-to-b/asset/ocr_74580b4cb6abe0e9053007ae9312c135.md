But it is worth noting that Linux does come with some issues: for one thing it won’t be totally familiar to anyone who has used a PC in the last decade – this isn’t Windows and you will need to learn a few things. It also has a number of compatibility issues and while it isn’t quite as major an issue as it used to be, there could be concern that something – whether it’s specific software you want to use or hardware and their

drivers – won’t work. It’s also worth noting that there are a wide range of Linux distributions or distros – a term used to describe the different ‘flavours’ of operating system. For each of these Linux remains the foundation, but the creator (or creators) have provided their own preference or spin on things. This can confuse matters for those looking for a new operating system, but sticking with the more popular distros – such as Ubuntu or Linux Mint – will minimise any of that hassle.
