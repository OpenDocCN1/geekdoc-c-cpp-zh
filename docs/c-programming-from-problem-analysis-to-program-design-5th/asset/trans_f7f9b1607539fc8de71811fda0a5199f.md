在本章前面，我们定义了类`unorderedLinkedList`来创建对象的链表。我们还定义了列表中对视频进行插入和删除等基本操作。然而，有些操作是视频列表特有的，例如借出视频、归还视频、设置视频副本数量等。这些操作在类`unorderedLinkedList`中不可用。因此，我们将从类`unorderedLinkedList`派生一个类`videoListType`，并添加这些操作。
