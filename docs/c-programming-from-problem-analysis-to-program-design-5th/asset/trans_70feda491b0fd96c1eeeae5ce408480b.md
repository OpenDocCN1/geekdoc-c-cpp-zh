- **18.（股市）。** 编写一个程序，帮助一家本地股票交易公司实现其系统自动化。该公司只投资于股票市场。在每个交易日结束时，公司希望生成并发布其股票列表，以便投资者可以看到其持仓当天的表现。我们假设该公司投资于，比如说，10 只不同的股票。期望的输出是生成两个列表，一个按股票代码排序，另一个按涨幅百分比从高到低排序。
