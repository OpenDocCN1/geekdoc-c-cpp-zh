**Function binSearch** This function implements the binary search algorithm on the array candidatesName. It is similar to the function binarySearch discussed earlier in this chapter. Its definition is:

int binSearch(string cNames[], int noOfRows, string name)
{
    int first, last, mid;
    bool found;
    first = 0;
    last = noOfRows - 1;
    found = false;

    while (!found && first <= last)
    {
        mid = (first + last) / 2;

        if (cNames[mid] == name)
            found = true;
        else if (cNames[mid] > name)
            last = mid - 1;
        else
            first = mid + 1;
    }
}
