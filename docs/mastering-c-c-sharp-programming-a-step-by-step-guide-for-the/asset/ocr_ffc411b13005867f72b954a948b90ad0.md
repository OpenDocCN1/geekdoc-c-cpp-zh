# Quick Primer

+   - Creating classes that use generics is done by putting the generic type in a set of angled brackets that follow the class definitions – public class PracticeList<T> {/***/}.
+   - It is common to use one capital letter to indicate the generic types, although it is not a requirement.
+   - You can use several generic types in one class – public class PracticeDictionary<K, V> {/***/}.
