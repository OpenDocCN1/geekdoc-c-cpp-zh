# 跨境数字贸易发展报告（2024）

世界百年未有之大变局下，跨境数字贸易正在成为全球贸易增长的新引擎，全球数字贸易发展显著加速。

+   - 电商平台
+   - 跨境电商平台企业（含服务商）
+   - 企业对企业（B2B）平台

数据要素是数字贸易的关键资源，其开放流动和共享使用是提升全球贸易效率和推动创新增长的重要动力。

数字平台企业更加注重服务能力提升，依托数据要素开发新型服务模式。
