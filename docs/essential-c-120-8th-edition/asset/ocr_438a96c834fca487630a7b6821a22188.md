# Pattern Matching

The operator and switch statement remained relatively static until C# 7.0 where declaration and significant pattern matching capabilities were added. Pattern matching provides a syntax through which criteria can be evaluated and the code executed accordingly. The C# continued pattern matching enhancements all the way to C# 11.
