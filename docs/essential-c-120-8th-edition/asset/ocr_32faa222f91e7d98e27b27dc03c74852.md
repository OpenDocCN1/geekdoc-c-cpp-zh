# 572 Chapter 10: Well-Formed Types

Figure 10.3 demonstrates how an IDE can take advantage of XML comments to assist the developer with a tip about the code he is trying to write. Such coding tips offer significant assistance in large programs, especially when multiple developers share code. For this work, however, the developer obviously must take the time to enter the XML comments within the code and direct the compiler to create the XML file. The next section explains how to accomplish this.

```
// <summary>
/// Display the text specified in the <strong>console</strong>
/// <summary>
/// <param name="text">The text to be displayed in the console.</param>
1 reference
private static void Display(string text)
{
    Console.WriteLine(text);
}
0 references
static void Main(string[] args)
{
    Display("Inigo Montoya");
}
- void Program.Display(string text)
Display the text specified in the console
```

FIGURE 10.3: XML comments as tips in Visual Studio IDE

Starting with Visual Studio 2019, you can also embed simple HTML into a comment, and it will be reflected in the tips. For example, surrounding console with <strong> and </strong> will cause the word “console” to display in bold in Figure 10.3.
