# Expression Lambdas

(items, (first, second) => first < second); //...

Generally, you would read the lambda operator => in an expression lambda the same way as you would a statement lambda: goes to or becomes, although, in those cases where the delegate is a predicate, it is common to read the lambda operator as such or where. Thus, you might read the lambda in Listing 13.16 as “first and second that is less than second.”

Like the null literal, an anonymous function does not have any type associated with it; rather, its type is determined by the type it is being converted to. In other words, the lambda expressions we've seen so far are not intrinsically of the Func<int, bool> (or Compar) type, but they are compatible with the type and may be converted to. As a result, you can use the typeof() operator on an anonymous method, and calling GetType() is possible only after you convert the anonymous method to a particular type.
