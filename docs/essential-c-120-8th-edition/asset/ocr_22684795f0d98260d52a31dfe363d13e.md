The +, -, *, %, &, |, ^, <<, << and >> operators are implemented as binary static methods, where at least one parameter is of the containing type. The method name is the operator symbol prefixed by the keyword operator. As shown in Listing 10.3 with Output 10.1, given the definition of the - + binary operators, you can add and subtract from Arc to and from coordinate. Note that Longitude and Latitude will also require implementations of the + operator because they are called by source.Longitude + arc .LongitudeDifference and source.Latitude + arc .LatitudeDifference.
