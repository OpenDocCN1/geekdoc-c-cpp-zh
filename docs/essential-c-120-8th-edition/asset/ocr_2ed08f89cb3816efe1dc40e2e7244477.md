# String Formatting

Whether you use string.Format() or string interpolation to construct complex formatting strings, a rich and complex set of composite formatting patterns are available to display numbers, dates, times, spans, and so on. For example, if price is a value of type decimal, string.Format("{{0,20:C2}", price) and the equivalent interpolation $\${price,20:C2}" both convert the decimal value to a string using the default currency formatting rules, rounded to two figures after the decimal place and right-justified in a 20-character-wide string. Space does not permit a detailed discussion of all the possible formatting strings; consult the MSDN documentation on composite formatting (http://itl.tc/CompositeFormatting) for a complete listing of possibilities.
