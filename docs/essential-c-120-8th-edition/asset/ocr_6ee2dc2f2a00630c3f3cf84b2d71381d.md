Listing 5.14 uses an entirely new name, CountdownTimer, as the aliases. It is possible, however, to specify the alias as Timer, as shown in Listing 5.15.

LISTING 5.15: Declaring a Type Alias with the Same Name

```
// Declare alias Timer to refer to System.Timers.Timer
// avoid code ambiguity with System.Threading.Timer
using Timer = System.Timers.Timer;

public class HelloWorld
{
    public static void Main()
    {
        Timer timer;

        // ...
    }
}
```

Because of the alias directive, "Timer" is not an ambiguous reference. Furthermore, to refer to the System.Threading.Timer type, you will have to either qualify the type or define a different alias.

Of course, C# 10 and later also support global aliasing directives such as:

```
global using Timer = Timers.Timer;
```

And with all other global directives, a global alias directive can be configured in the csproj file:

```
<Using Include="System.Timers.Timer" Alias="Timer"/>
```
