In Listing 7.3, PdaItem is shown explicitly to derive from object. Although C# allows this syntax, it is unnecessary because all classes that don't have some other derivation will derive from object, regardless of whether it is specified.

> > NOTE
Unless an alternative base class is specified, all classes will derive from object by default.

# Casting between Base and Derived Types

As Listing 7.4 shows, because derivation forms an “is a” relationship, a derived value can always be directly assigned to a base type variable.

LISTING 7.4: Implicit Base Type Casting

```
public class Program {
  public static void Main() {
    // Derived types can be implicitly converted to
    // base types
    Contact contact = new();
    PdaItem item = contact;
    // ...

    // Base types must be cast explicitly to derived types
    contact = (Contact)item;
    // ...
  }
```
