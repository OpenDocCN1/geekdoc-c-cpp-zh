# Task Continuation

We've talked several times about the control flow of a program without ever saying what the most fundamental nature of control flow is: Control flow determines what happens next.* When you have a simple control flow like Console.WriteLine(x.ToString()); the control flow tells you that ToString completes normally, the next thing that will happen is a call to WriteLine with the value returned as the argument. The concept of "what happens next" is called continuation; each point in a control flow has a continuation. In our example, the continuation of ToString is WriteLine (and the continuation of WriteLine is whatever code runs in the next statement). The idea of continuation is so elementary to C# programming that most programmers don't even think about it; it's part of the invisible air that they breathe. The act of C# programming is the act of constructing continuation upon until the control flow of the entire program is complete.
