You cannot have two different threads interacting with a single threaded platform, for example, and async/await addresses this issue. In other words, the async/await syntax tells the compiler to reorganize the code at compile time, even though it is written relatively simply, and to address the myriad of complexities developers would otherwise have to consider explicitly—see Listing 20.3.
