# Type Checking

Since C# 1.0, there have been multiple ways to check an object's type including the operator and the switch statement. In C# 8.0, the switch expression was introduced to enable a value return from the expression.

# Type Checking with the is Operator

Since C# allows casting down the inheritance chain, it is sometimes desirable to determine what the underlying type is before attempting a conversion.
