Although it's possible in C# 7.0 to declare a reference local variable, declaring a field of type ref isn't allowed (see “Instance Fields” (https://essentialcssharp.com/instance-fields) in Chapter 6 for more information on declaring fields):

```
class Thing { ref string _Text; /* Error */ }
```

You can't declare a by-reference-type for an auto-implemented property (see “Properties” (https://essentialcssharp.com/properties) in Chapter 6 for more information on auto-properties):

```
class Thing { ref string Text { get; set; } /* Error */ }
```

Properties that return a reference are allowed (see “Properties” (https://essentialcssharp.com/properties) in Chapter 6 for more information on declaring properties):

```
class Thing { string _Text = "Inigo Montoya";
ref Text { get { return _Text; } }
```

A reference local variable can't be initialized with a value (such as null or a constant). It must be assigned from a by-reference-returning member or a local variable, field, or array element:

```
ref int number = 42; // ERROR
```
