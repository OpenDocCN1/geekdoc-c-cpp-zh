C# 7.0 introduced an improvement to the switch statement that enables—pattern matching so that any data type—not just the few identified earlier—can be used for the switch expression. Pattern matching enables the use of switch statements based on the type of the switch expression and the use of case labels that also declare variables. Lastly, pattern matching switch statements support conditional expressions that not only the type but a Boolean expression at the end of the case label can identify which case should execute. For more information on pattern matching with switch statements and expressions, see Chapter 7.

# Jump Statements

It is possible to alter the execution path of a loop. In fact, with jump statements, it is possible to escape out of the loop or to skip the remaining portion of an iteration and begin with the next iteration, even when the loop condition remains true. This section considers some of the ways to jump the execution path from one location to another.
