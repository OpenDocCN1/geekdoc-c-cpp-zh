这是一个字面字符串，文本将输出两行。然而，你可以通过在字面字符串的大括号内放置换行符，在代码中实现类似的换行而在输出中产生换行（即使在 C# 11 之前也是如此）。但是，对于字面字符串，表达式之外所有行的空白都是显著的。因此，你必须将代码向外缩进，以避免代码中的额外缩进出现在输出中。为了解决这个格式上的特殊问题，C# 11 引入了原始字符串字面量（raw string literals）。

# 原始字符串字面量
