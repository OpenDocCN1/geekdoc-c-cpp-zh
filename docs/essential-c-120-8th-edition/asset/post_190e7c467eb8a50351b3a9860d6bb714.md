Instead of two arrays of players, SelectMany() combines each array selected and produces a single collection of all items.

## TABLE 15.1: Simpler Standard Query Operators

| Comment Type | Description |
| --- | --- |
| OfType<T>() | Forms a query over a collection that returns only the items of a particular type, where the type is identified in the type parameter of the OfType<T>() method. |
| Union() | Combines two collections to form a superset of all the items in both collections. The final collection does not include duplicate items if the same item existed in both collections. |
| Concat() | Combines two collections to form a superset of both collections. Duplicate items are not removed from the resultant collection. Concat() will preserve the ordering. That is, concatenating {A, B} with {C, D} will produce {A, B, C, D}. |

| Distinct() | Filters out duplicate items from a collection so that each item within the resultant collection is unique. |

## ADVANCED TOPIC

### Queryable Extensions for IQueryable&T>

One virtually interface to IEnumerable&lt;T&gt; is IQueryable&lt;T&gt;. Because IQueryable&lt;T&gt; derives from IEnumerable&lt;T&gt;, it has all the members of IEnumerable&lt;T&gt; that are declared directly (e.g., GetEnumerator()). Extension methods are not inherited, however, so IQueryable&lt;T&gt; doesn't have any of the Enumerable extension methods. Nevertheless, it has a similar extending class System.Linq.Queryable that adds to IQueryable&lt;T&gt; almost all of the same methods that Enumerable added to IEnumerable&lt;T&gt;. Therefore, it provides a very similar programming interface.

What makes IQueryable&lt;T&gt; unique is that it enables LINQ providers. A LINQ provider subdivides expressions into their constituent parts. Once divided, the expression can be translated into another language, serialized for remote execution, injected with an asynchronous execution pattern, and much more. Essentially, LINQ providers allow for an interception mechanism into a standard collection API; behavior relating to the queries and collection can be injected via this seemingly limitless functionality.

For example, LINQ providers allow for the translation of a query expression from C# into SQL that is executed on a remote database. In doing so, the C# programmer can remain in their primary object-oriented language and leave the translation to SQL to the underlying LINQ provider.

### Anonymous Types with LINQ

To support LINQ, an advanced API, only eight new language enhancements were made. Two of these enhancements were anonymous types and implicit local variables. Even so, anonymous types have essentially been eclipsed by the introduction of C# tuple syntax. In fact, with the sixth edition of this book, all the LINQ examples that previously leveraged anonymous types were updated to use tuples instead.
