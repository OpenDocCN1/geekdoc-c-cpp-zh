# Guidelines

DO throw an ArgumentException or one of its subtypes bad arguments are passed to a member. Prefer the most derived exception type (e.g., ArgumentNullException), if applicable.

+   DO throw a System.Exception, System.NullReferenceException, or System.ApplicationException.

+   CONSIDER terminating the process by calling System.Environment.FailFast() if the program encounters a scenario where it is unsafe to continue execution.

+   DO use nameof for the paramName argument passed into exception types that take such a parameter. Examples of such exceptions Include ArgumentException, ArgumentOutOfRangeException, and ArgumentNullException.

# Catching Exceptions

Throwing a particular exception enables the catcher to use the exception's type itself to identify the problem. It is not necessary, in other words, to catch the exception and use a switch statement on the exception message to determine which action to take in light of the exception.
