# Automatically Implemented Properties

LISTING 6.18: Defining Properties with Expression Bodied Members

```
public class Employee
{
    // FirstName property
    public string FirstName
    {
        get
        {
            return _FirstName;
        }
        set
        {
            _FirstName = value;
        }
    }
    private string _LastName;
    // LastName property
    public string LastName
    {
        get => _LastName;
        set => _LastName = value;
    }
    private string _LastName;
    // ...
```

Since a property with a single field that is assigned and retrieved by the get and set acceptors is so trivial and common (see the implementations of FirstName and LastName), the compiler allows the declaration of a property without any accessor implementation or backing field declaration.2 Listing 6.19 demonstrates the syntax with the Title and Manager properties, and Output 6.6 shows the results.
