The attribute documents that the enum values can be combined. Furthermore, it changes the behavior of the ToString() and Parse() methods. For example, calling ToString() on an enum that is decorated with FlagsAttribute writes the out strings for each enum flag that is set. In Listing 9.21, file.AttributesToString() returns ReadOnly, Hidden rather than the 3 it would have returned without the FileAttributes flag. If two enum values are the same, ToString() would call the first value. As mentioned earlier, you should use caution when relying on this behavior because it is not localizable.
