One advantage of the is operator over the as operator is that the latter cannot successfully determine the underlying type. The as operator may cast up or down an inheritance chain. Unlike the as operator, the is operator can determine the underlying type. Also, the as operator works mainly with reference types, whereas the is operator works with all types.

More important, as the operator generally requires the additional step of checking the assigned variable for null. Since the pattern matching is operator includes this conditional check automatically, it effectively eliminates the need for the as operator—assuming C# 7.0 or later is available.
