#pragma disable-warning directives are often embedded within the book’s source code to address warnings that crop up because the example code is not fully developed but rather intended for the purpose of elucidation.

Note that C# warning numbers are prefixed with the letters CS in the compiler output, a prefix that is optional in the #pragma directive. Such a number corresponds to the warning error emitted by the compiler when there is no preprocessor command. however, there are other prefixes like “IDE” that are part of the identity. The IDE0059 message is an example. Code analyzers generate IDE-prefixed warnings to suggest code improvements, and removing the prefix will no longer refer to the same warning.

# nowarn:<list> Option

In addition to the #pragma directive, C# compilers generally support the nowarn=<list> option. This achieves the same result as #pragma, except instead of adding it to the source code, you can insert the command as a compiler option. The nowarn option affects the entire compilation, whereas #pragma affects only the file in which it appears. To turn off the CS0219 warning, for example, you would use the command as shown in Output 4.29.

# OUTPUT 4.29

```
> dotnet build /p:NoWarn="0219"
```
