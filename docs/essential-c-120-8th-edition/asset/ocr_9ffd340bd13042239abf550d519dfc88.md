In Listing 14.11, Program can invoke the OnTemperatureChange delegate even though the CurrentTemperature on thermostat did not change. Program, however, triggers a notification to all thermostat subscribers that the temperature changed, even though the thermostat temperature did not change. As before, the problem with the delegate is insufficient encapsulation. Thermostat should prevent any other class from being able to invoke the OnTemperatureChange delegate.

# Declaring an Event

C# provides the event keyword to deal with both problems. Although seemingly like a field modifier, event defines a new type of member (see Listing 14.12).

Listing 14.12: Using the event Keyword with the Event-Coding Pattern

```
public class Thermostat
{
    public class TemperatureArgs : System.EventArgs
    {
        public TemperatureArgs(float newTemperature)
        {
            NewTemperature = newTemperature;
        }

        public float NewTemperature { get; set; }
    }

    // Define the event publisher
    public event EventHandler<TemperatureArgs> OnTemperatureChange =
    delegate { }; };
```
