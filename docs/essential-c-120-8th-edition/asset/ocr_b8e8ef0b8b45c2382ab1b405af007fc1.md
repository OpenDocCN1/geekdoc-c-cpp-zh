# How This Book Is Organized

At a high level, software engineering is about managing complexity, and it is structured toward this end that I have organized Essential C# 12.0. Chapters 1–5 introduced programming, which enable you to start writing simple functioning code immediately. Chapters 6-10 present the object-oriented constructs of C#. Novice readers focus on fully understanding this section before they proceed to the more advanced topics found in the remainder of this book. Chapters 12–14 introduce complexity-reducing constructs, handling common patterns needed by virtually all modern programs. This leads to dynamic programming with reflection and attributes, which is used extensively for threading and interoperability in the chapters that follow.

The book ends with Chapter 24 on the Common Language Infrastructure, which describes C# within the context of the development platform in which it operates. This chapter appears at the end because it is not C# specific and it departs from the syntax and programming style in the rest of the book. However, this chapter is suitable for reading at any time, perhaps most appropriately immediately Chapter 1.
