# Declaring a Record Struct

Fortunately, starting with C# 9.0, a lot of the complexity associated with creating a struct is eliminated with a new contextual keyword—record—that triggers compiler it generating much of the important and complex code related to value type behavior. Learning 9.2 provides an example. With this simple syntax, we have a value type that describes a high-precision angle in terms of degrees, minutes, and seconds. (A *minute* is one-sixtieth of a degree, and a *second* is one-sixteenth of a minute.) This system is used in navigation because it has the nice property that an arc of one minute over the surface of the ocean at the equator is exactly one nautical mile.

# LISTING 9.2: Declaring a struct

```
// Use the record struct constructor to declare a value type
public readonly record struct Angle(
    int Degrees, int Minutes, string? Name = null);
```

The syntax, which uses a primary constructor, is all that is needed to define the entire type. Unlike regular primary constructors explained in Chapter 6 (and not available until C# 12.0), however, a record’s primary constructor also generates an initial set of properties from the properties (the optional¹) positional parameters. As a result, this simple code construct, called a **record struct**, has all the requisites that you need to build a value type including value declaration, data storage with properties, immutability, constructor initialization, deconstruction, equivalence behavior, and

+   1. Both the positional parameters and the parentheses surrounding them (when there are no positional parameters) are optional. Although it would peculiar to declare with only parenthesis, as doing so would be similar to declaring an empty struct or class.
