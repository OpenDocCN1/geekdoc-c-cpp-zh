As previously discussed in this section, there are many different numeric types in C#. Listing 2.2, a literal value is passed to the WriteLine method. Since numbers with a decimal point will default to the double data type, shown in Output 2.2, is 1.618033988749895 (the last two digits, 48, are now 5), corresponding to the expected accuracy of a double.

# LISTING 2.2: Specifying a Literal double

```
Console.WriteLine(1.618033988749898);
```

# OUTPUT 2.2

```
1.618033988749895
```

To view the intended number with its full accuracy, you must declare explicitly the literal value as a decimal type by appending an M (or m) (see Listing 2.3 and Output 2.3).

# LISTING 2.3: Specifying a Literal decimal

```
Console.WriteLine(1.618033988749894M);
```

# OUTPUT 2.3

```
1.618033988749898
```

The output of Listing 2.3 is as expected: 1.618033988749895. Note that d is the abbreviation for double. To remember that "m is for monetary calculations.".
