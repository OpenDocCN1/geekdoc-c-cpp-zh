# LISTING 3.17: Initializing a Three-Dimensional Array

```
bool[,, ] cells;
cells = new bool[2, 3, 3];
{
  // Player 1 moves
  // X | |
  //---++-
  // X | |
  //---++-
  // X | X
  {
    {true, false, false},
    {true, false, false},
    {true, false, true}
  },
  // Player 2 moves
  // | 0 |
  // |--+-
  // | 0 |
  // |--+-
  // | 0 |
  {
    {false, false, true},
    {false, true, false},
    {false, true, true}
  }
};
```
