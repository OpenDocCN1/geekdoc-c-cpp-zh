# Guidelines

AVOID using equality condicionals with binary floating-point types. Either subtract the two values and see if their difference is less than a tolerance or use the decimal type.

You should be aware of some additional unique floating-point characteristics as well. For instance, you would expect that dividing an integer by zero would result in an error—and it does with data types such as int and decimal. The float and double types, however, allow for certain special values. Consider Listing 4.8, and its result output, Output 4.7.
