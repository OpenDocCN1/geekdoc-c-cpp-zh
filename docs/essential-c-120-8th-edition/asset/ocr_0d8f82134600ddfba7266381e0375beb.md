The default operator can provide the default value for any type, including type parameters.

It's possible to use default without specifying a parameter if it is possible to infer the data type.3 For variable initialization or assignment, use Pair<T> pair = default in place of Pair<T> pair = default(Pair<T>). Furthermore, if a method returns an int, it is possible to simply return default and the compiler infer a default(int) from the return of the method. Other scenarios where such inference is possible are default parameter (optional) values and method arguments.

Note that all nullable types have null as their default value, as nullable generic types such as default(T?). Furthermore, the default value for all reference types is null. As a result, if nullable references are enabled by C# 8.0, assigning default to a non-nullable reference type will result in a warning.
