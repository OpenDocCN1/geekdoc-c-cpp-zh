# Strings Are Immutable

All values of type string, whether string literals or otherwise, are immutable (or unmodifiable). For example, it is not possible to change the string Come As You Are, to Come As You Age. A change such requires that you reassign the variable instead of modifying the data to which the variable originally referred.
