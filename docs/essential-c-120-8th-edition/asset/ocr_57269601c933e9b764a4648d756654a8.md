# Filtering with Where()

To filter data from a collection, we need to provide a filter method that returns true or false, indicating whether or not a particular element is included. A delegate expression that takes an argument and returns a Boolean value is called a **predicate**, and a collection's Where() method depends on predicates for identifying filter criteria, as shown in Listing 15.10.
