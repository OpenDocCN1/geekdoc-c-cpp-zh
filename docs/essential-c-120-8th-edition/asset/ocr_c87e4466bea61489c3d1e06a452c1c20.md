Not only string characters can be accessed individually, but it is also possible to retrieve the entire string as an array of characters using the string's ToCharArray() method. Using this approach, you could reverse the string with the System.Array.Reverse() method, as demonstrated in Listing 3.31 which determines whether a string is a palindrome.
