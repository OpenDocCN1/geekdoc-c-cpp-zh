## Understanding a Project

Using dotnet CLI or Visual Studio, there are several files created. The first file is a C# file with the name Program.cs by convention. The name Program is

![](img/ffe0f34eac7523830420733690014d17_44_0.png)

FIGURE 1.4: The Program.cs file

The entry point of a C# program is the Main method. In older versions of C#, this method was explicitly contained within a class, but in modern versions, you can use top-level statements to simplify the code. The project file, ending in .csproj, defines how the project is built and run. It contains information about the target framework, dependencies, and other build settings.

When you build a project, the compiler creates several directories. The most important are the bin and obj directories. The bin (binary) directory contains the compiled executable and libraries, organized by framework and configuration (e.g., Debug or Release). The obj (object) directory contains intermediate files used during the build process.

The project file also allows you to manage NuGet packages, which are libraries you can use in your project. You can add packages using the dotnet CLI or the Visual Studio NuGet Package Manager.
