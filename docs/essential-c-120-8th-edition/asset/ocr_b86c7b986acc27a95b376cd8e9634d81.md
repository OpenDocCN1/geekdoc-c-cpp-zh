# Increment and Decrement Operators (+, --)

C# includes unary operators for incrementing and decrementing counters. The increment operator, ++ increments a variable by one each time it is used. In other words, all of the code lines shown in Listing 4.13 are equivalent.

LISTING 4.13: Increment Operator

```
spaceCount = spaceCount + 1;
spaceCount += 1;
spaceCount++;
```

Similarly, you can decrement a variable by 1 using the decrement operator, --. Therefore, all of the code lines shown in Listing 4.14 are also equivalent.

LISTING 4.14: Decrement Operator

```
lines = lines - 1;
lines-- = 1;
lines--;
```
