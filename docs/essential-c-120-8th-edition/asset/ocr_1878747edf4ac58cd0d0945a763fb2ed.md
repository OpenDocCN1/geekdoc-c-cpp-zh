# Output Parameters (out)

As mentioned earlier, a variable used as a ref parameter must be assigned before it is passed to the called method, because the called method might read from the variable. The "swap" example given previously must read and write from both variables passed to it. However, it is often the case that a method that takes a reference to a variable intends to write to the variable but not read from it. In such cases, clearly it is safe to pass an uninitialized local variable by reference.

To achieve this, code decorate parameters types with the keyword out. This is demonstrated in the TryGetPhoneButton() method in Listing 5.19, which returns the phone button corresponding to a character.
