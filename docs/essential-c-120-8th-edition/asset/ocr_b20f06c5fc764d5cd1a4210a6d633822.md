With Visual Studio, you can activate this feature by checking the Allow Unsafe checkbox from the Build tab of the Project Properties window.

The /unsafe switch enables you to directly manipulate memory and execute instructions that are unmanaged. Requiring /unsafe, therefore, makes explicit exposure to potential security vulnerabilities that such code might introduce. With power comes great responsibility.
