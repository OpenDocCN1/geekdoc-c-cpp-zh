A catch block with no data type, called a general catch block, is equivalent to specifying a catch block that takes an object data type—for instance, catch(object exception){...}. For this reason, a warning is triggered stating that the catch block already exists; hence the #pragma warning disable directive.

Because all classes derive from object, a catch block with no data type must appear last.
General catch blocks are rarely used because there is no to capture any information about the exception. In addition, C# doesn't support the ability to throw an exception of type object. (Only written in languages such as C++ allow exceptions of any type.)
