| Declaration Note that the brackets appear with the data type. Multidimensional arrays are declared using commas, where the comma+1 specifies the number of dimensions. | // 1.

| Assignment The new keyword is optional but only on declaration. If not assigned during declarations, the new keyword is required when instantiating an array. Specifying the data type is optional.* However, without the data type, the size cannot be specified. Both the size and the values do not have to be literals; they can be determined at runtime. If both values and size are specified, the quantities must be consistent. Arrays can be assigned without values. As a result, the value of each item in the array is initialized to its default. The data type and the size are required if no values are specified. | // 2.
