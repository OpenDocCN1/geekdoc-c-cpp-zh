# Programming with null

As described in Chapter 3, while null can be a useful value, it also comes with a few challenges—namely, the need to check a value isn't before invoking the object's member or changing the value from null to something more appropriate to the circumstance.

Although you can check for null using the equality operators, even the relational equality operators, there are several other ways to do so, including C# 7.0's support for null and C# 10.0's support for not null. In addition, several operators are designed exclusively for working with the potential of a null value. These include the null-coalescing operator (and C# 8.0's null-coalescing assignment) and the null-conditional operator. There is an operator to tell the compiler when you believe a value isn't null even if it isn't obvious to the compiler—the null-forgiving operator. Let's start by simply checking whether a value is null or not.
