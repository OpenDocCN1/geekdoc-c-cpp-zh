or some other number very close to 0.1. Similarly, setting a variable to a large number such as Avogadro’s number, $6.02 \times 10^{23}$, could lead to a representation error of approximately $10^8$, which is all a fraction of that number. The accuracy of a floating-point number is in proportion to the magnitude of the number it represents. A floating-point number is precise to a certain number of digits of precision, not by a fixed value such as $\pm0.01$. There are at most 17 significant digits for a double and 9 significant digits for a float$^1$ (assuming the number wasn’t converted from a string in the “Advanced Topic: Floating-Point Types Dissected”).$^2$

```
C# supports two binary floating-point number types listed in Table 2.2. Binary numbers appear as base 10 (denary) numbers for human readability. While there are additional floating-point types beyond the scope of this book (see https://learn.microsoft.com/dotnet/standard/numerics), they are not built-in types with associated keywords.
```
