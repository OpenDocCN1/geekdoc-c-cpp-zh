Note that the items output from a GroupBy() call are of type IGrouping<TKey, TElement>, which has a property for the key that the query is grouping (employee.DepartmentId). However, it does not have a property for the items within the group. Rather, Grouping<TKey, TElement> derives from IEnumerable<T>, for enumeration of the items within the group using a foreach statement or for aggregating the data into something such as a count of items (employeeGroup.Count()).
