# 10.8 Radix Sort

The radix sort is based upon the positional value of the actual digits of the number being stored. This method was earlier performed on a mechanical card sorter. For Ex. The number 245 in decimal notation written with a 2 in the hundredths position, 4 in the ten's position and 5 in the unit position. This three digits will be sorted in maximum three passes. In the first pass, the unit digit will be sorted, in the second pass the tens digit will be sorted and in the third and final pass the hundredths digit will be sorted. Radix sort technique is also used when large lists of names are to be sorted alphabetically.
