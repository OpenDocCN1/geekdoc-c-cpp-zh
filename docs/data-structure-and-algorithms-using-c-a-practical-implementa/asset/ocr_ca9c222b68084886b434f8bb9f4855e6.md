4. Computing for every vertex in graph, a path with the minimum number of edges between start vertex and current vertex or reporting that no such path exists.

Analysis: Total Running time of BFS = O(V + E)

# ALGORITHM BFS(G,S)

+   1. for each vertex u ∈ V[G] - {S}
+   2. do color[u] ← white
+   3. d[u] ← ∞ i.e. distance from S
+   4. P[u] ← NIL i.e. Parent in the BFS tree
+   5. color[S] ← gray
+   6. d[S] ← 0
+   7. Q ← {S}
+   8. while Q ≠ φ do
+   9. u ← head[Q]
+   10. for each v ∈ Adj[u] do
+   11. if color[v] = white then
+   12. color[v] ← gray
+   13. d[v] ← d[u] + 1
+   14. p[v] ← u
+   15. ENQUEUE(Q,v)
+   16. DEQUEUE(Q)
+   17. color[u] ← black
