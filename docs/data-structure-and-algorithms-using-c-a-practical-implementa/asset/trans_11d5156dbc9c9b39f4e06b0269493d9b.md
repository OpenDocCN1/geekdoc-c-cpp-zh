## 7.5 双向链表

双向链表的设计方式是使列表中的每个节点都能存储两个地址部分，一个是其下一个节点，另一个是其前一个节点。

双向链表节点的一般格式如下

```cpp
Struct tagname
{
Data type member1;
Data type member2;
................
................
Data type membern;
Struct link *var1,*var2;
}
```

### 示例：

```cpp
Struct Dlink
{
int info;
struct Dlink *next,*prev ;
};
```

### 图形表示

![](img/1faaa0256577c74e8a61f42967760aa8_217_0.png)

### 创建逻辑

```cpp
Struct link
{
int info;
struct link *next,*prev;
};

Struct link start,*node;
Node=&start;
Allocate a memory to node->next
Node->next ->prev = node
Node = node->next
Node->next = NULL
```

### 创建双向链表的算法
CREATE(START,NODE)
STEP-1 : NEXT[START]:=NULL
PREV[START]:=NULL
STEP-2 : 为 NEXT[NODE] 分配内存
PREV[NEXT][NODE] := NODE
NODE := NEXT[NODE]
NEXT[NODE] := NULL
STEP-3 : 输入 : INFO[NODE]
STEP-4 : 重复步骤-2 和 步骤-3 以创建更多节点
STEP-5 : 返回

### 双向链表遍历算法
TRAVERSE(START,NODE)
STEP-1 : NODE := NEXT[START]
STEP-2 : 输出 : "正向遍历"
STEP-3 : 重复 WHILE (NEXT[NODE] != NULL)
输出 : INFO[NODE]
NODE := NEXT[NODE]
[循环结束]
STEP-4 : 输出 : "逆向遍历"
STEP-5 : 重复 WHILE (PREV[NODE]!=NULL)
输出 : INFO[NODE]
NODE := PREV[NODE]
[循环结束]
STEP-6 : 返回

### 在开头插入节点的算法
INSBEG(START,NODE)
STEP-1 : NODE := NEXT[START]
STEP-2 : 为 NEW 分配内存
STEP-3 : PREV[NEW] := PREV[NODE]
NEXT[NEW] := NODE
PREV[NODE] := NEW
NEXT[PREV[NODE]] := NEW
STEP-4 : 输入 : INFO[NEW]
STEP-5 : 返回

### 在末尾插入节点的算法
INLAST(START,NODE)
STEP-1: NODE. := NEXT[START]
STEP-2: 重复 WHILE (NEXT[NODE]!=NULL)
NODE. = NEXT[NODE]
[循环结束]
STEP-3: 为 NEW 分配内存
STEP-4: PREV[NEW] := PREV[NODE]
NEXT[NEW] := NODE
NEXT[PREV[NODE]] := NEW
PREV[NODE] :=NEW
STEP-5: 输入 : INFO[NEW]
STEP-6: 返回

### 当节点编号已知时插入节点的算法
INSNODE(START,NODE,NO)
STEP-1: NODE. := NEXT[START]
STEP-2: COUNT := 1
STEP-3: 重复 WHILE (NEXT[NODE]!=NULL)
IF(COUNT = NO ) THEN:
为 NEW 分配内存
PREV[NEW] := PREV[NODE]
NEXT[NEW] := NODE
NEXT[PREV[NODE]] := NEW
PREV[NODE] :=NEW
ELSE:
NODE. := NEXT[NODE]
COUNT := COUNT+1
[结束 IF]
[结束循环]
STEP-4: 输入 : INFO[NEW]
STEP-5: 返回

### 当信息已知时插入节点的算法

