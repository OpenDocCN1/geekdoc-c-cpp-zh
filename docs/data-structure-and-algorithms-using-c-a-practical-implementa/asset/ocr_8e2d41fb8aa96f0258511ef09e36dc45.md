# 7.10 Garbage Collection and Compaction

After use of any memory it must be reusable, and its the work of the operating system to find out those memory which are allocated but not used anywhere so the operating system will perform a task as a result these unused memory spaces will added into the free memory space.

The technique which does this collection is called garbage collection.

The garbage collection may take place when there is only some minimum amount of space or no space at all left in the free storage list, or when the CPU is idle and has time to do the collection. The garbage collections invisible to the programmer.

Memory management system uses the concept called compaction, which collects all free memory blocks and places them at one location in a single free block. So the request for memory allocation will be from this free block. Memory management system uses some technique for tis. Different methods for assigning the requested memory from free block such as

+   - FIRST FIT METHOD
+   - BEST FIT METHOD
+   - WORST FIT METHOD

In *first fit* method of memory allocation, the first entry which has free block equal to or more than required one is taken.
