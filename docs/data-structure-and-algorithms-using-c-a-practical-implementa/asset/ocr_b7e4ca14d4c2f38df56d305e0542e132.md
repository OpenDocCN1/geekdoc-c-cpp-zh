# Accessing the members of a class

The members of a class can be accessed with the help of the objects like the structure. That means object_name.member_name;

# Difference between PRIVATE, PUBLIC, AND PROTECTED in programmatically way.

# Example

```
class differ
{
private :
    int x;
public :
    int y;
protected:
    int z;
};

void main()
{
    differ obj;    //Declaration of the object
    cout<<c"Enter a number for x';   //Declaration of the object
    cin>>obj.x;    //Error, because x is private
    cout<<c"Enter a number for y';
    cin>>obj.y;    //No Error, Since Y is public
    cout<<c"Enter a number for z',
    cin>>obj.z;    //Error, because z is protected
}
```
