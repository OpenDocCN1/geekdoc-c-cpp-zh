In this case the nodes with 2-children are called as Internal nodes and the nodes with 0 children are called as External nodes.

# 8.3.1 Array Representation of a Tree

An array can be used to represent the BINARY tree. The total number of elements in the array depends on the total number of nodes in the TREE. The ROOT node is always kept as the FIRST element of the array i.e/ in the 0-Index the root node will be store. Then, in the successive memory locations the left child and right child are stored.
