# 2.3.3 Arithmetic With Pointer

In general the arithmetic operations include Addition, Subtraction, Multiplication, and Division. But in case of pointer we can perform only the addition and subtraction operations. That means when we perform an addition/subtraction operation with the pointer then it shifts the locations because pointer means an address. If we add one to the integer pointer then it will shift two bytes (int occupies two bytes in memory), so for float 4 bytes, char 1 byte, long double 4 bytes and accordingly it will shift the positions.

Ex: Let int *p x;
P=&x;
