# EXAMPLE

WRITE A PROGRAM TO FIND OUT THE FACTORIAL OF A NUMBER

```
#include<iostream.h>
void main ()
{
long int * fact(int *);
int n;
long int *f;
cout<<"Enter a number";
cin>>n;
f=fact(&n);
cout<<"n Factorial Is %ld"<<*f;
}
long int * fact(int *p)
{
int i;
long int f=1;
for(i=1;i<=*p;i++)
f*=i;
return (&f);
}
```
