## 邻接表

使用邻接矩阵表示图由于其实现是静态的，因此不足。解决此问题的方法是使用链表结构，即通过邻接表表示图。如果图不是稠密的，也就是说图是稀疏的，那么更好的解决方案在于邻接表表示。

对于每个顶点，我们保存一个所有相邻顶点的列表。在图的邻接表表示中，我们将维护两个列表。第一个列表用于跟踪图中的所有节点，在第二个列表中，我们为每个节点维护一个相邻节点列表。每个列表都有一个头节点，该头节点将是第一个列表中的对应节点。头节点是顺序排列的，为任何特定顶点的邻接表提供便捷的随机访问。

## 9.3 图的遍历

图的遍历有两种类型，如下

- 广度优先搜索 (BFS)
- 深度优先搜索 (DFS)

### 9.3.1 广度优先搜索 (BFS)

BFS 从给定顶点开始，该顶点位于第 ‘0’ 层。在第一阶段，我们访问第 1 层的所有顶点。在第二阶段，我们访问第 2 层的所有顶点。这些新顶点与第 1 层顶点相邻，以此类推。当每个顶点都被访问时，BFS 终止。BFS 用于解决

- 1. 测试图是否连通。
- 2. 计算图的生成森林。
- 3. 计算图中的环，或报告不存在这样的环。
- 4. 计算图中每个顶点从起始顶点到当前顶点的边数最少的路径，或报告不存在这样的路径。

分析：BFS 的总运行时间 = O(V + E)

### 算法 BFS(G,S)

- 1. 对每个顶点 u ∈ V[G] - {S}
- 2. 令 color[u] ← white
- 3. d[u] ← ∞ 即从 S 的距离
- 4. P[u] ← NIL 即 BFS 树中的父节点
- 5. color[S] ← gray
- 6. d[S] ← 0
- 7. Q ← {S}
- 8. 当 Q ≠ φ 时
- 9. u ← head[Q]
- 10. 对每个 v ∈ Adj[u] 执行
- 11. 如果 color[v] = white 则
- 12. color[v] ← gray
- 13. d[v] ← d[u] + 1
- 14. p[v] ← u
- 15. ENQUEUE(Q,v)
- 16. DEQUEUE(Q)
- 17. color[u] ← black

### 示例

![](img/1faaa0256577c74e8a61f42967760aa8_311_0.png)

```
BFS(G,S)
for each vertex u ∈ V[G] - {S}
    do color[u] ← white
    do color[S] = white
    color[S] = gray
d[S] = 0
Q = {S}
```

## 9.3.2 深度优先搜索

**深度优先搜索** 是遍历图的另一种方式。它使用 STACK 数据结构进行遍历。

### 算法 DFS(G)

- 1. 对每个顶点 u ∈ V[G]
- 2. 令 color[u] ← white
- 3. π (u) ← NIL
- 4. time ← 0
- 5. 对每个顶点 u ∈ V[G]
- 6. 如果 color[u] ← white
- 7. DFS-VISIT(u)

### 算法 DFS-VISIT(u)

- 1. color[u] → gray
- 2. time ← time + 1
- 3. d[u] ← time
- 4. 对每个顶点 v ∈ Adj[u]
- 5. 如果 color[v] ← white
- 6. 则 π (v) ← u
- 7. DFS-VISIT(v)
- 8. color[u] → black
- 9. finish[u] ← time ← time+1

Color[R] = gray, time = 0+1 = 1 d[R] = 1
v ∈ Adj[u] => v = (S,V)
如果 color(S) = white 且 由于 color(S) = white
π (S) = u => π (S) = R
