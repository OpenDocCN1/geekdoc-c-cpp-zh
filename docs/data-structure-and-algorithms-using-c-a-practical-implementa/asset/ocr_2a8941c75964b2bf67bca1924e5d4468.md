# 9.3.2 Depth First Search

**Depth First Search** is another way of traversing of graph. It uses STACK data structure for traversing.

# ALGORITHM DFS(G)

+   1. for each vertex u ∈ V[G]
+   2. do color[u] ← white
+   3. π (u) ← NIL
+   4. time ← 0
+   5. for each vertex u ∈ V[G]
+   6. do if color[u] ← white
+   7. DFS-VISIT(u)

# ALGORITHM DFS-VISIT(u)

+   1. color[u] → gray
+   2. time ← time + 1
+   3. d[u] ← time
+   4. for each vertex v ∈ Adj[u]
+   5. if color[v] ← white
+   6. then π (v) ← u
+   7. DFS-VISIT(v)
+   8. color[u] → black
+   9. finish[u] ← time ← time+1
