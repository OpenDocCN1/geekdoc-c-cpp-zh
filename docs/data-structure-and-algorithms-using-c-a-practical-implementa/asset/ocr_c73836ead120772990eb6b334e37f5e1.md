# 8.16 B+ Tree

In B-TREE we can access records randomly but sequential traversal is not provided by it. B+ TREE is a special tree which provides the random access as well as sequential traversal.

In B+ tree all the non leaf nodes are interconnected i.e/ a leaf node will point to next leaf node.
