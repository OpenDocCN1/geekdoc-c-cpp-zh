# ALGORITHM FOR INSERTION OF A NODE WHEN INFORMATION IS KNOWN

```
INSINFO(START,NODE,VAL)
STEP-1 : NODE := NEXT[START]
STEP-2 : REPEAT WHILE (NEXT[NODE]!=NULL)
IF(INFO[NODE] <=VAL) THEN:
    ALLOCATE A MEMORY TO NEW
    PREV[NEW] := PREV[NODE]
    NEXT[NEW] := NODE
    NEXT[PREV[NODE]] := NEW
    PREV[NODE] :=NEW
ELSE:
    NODE := NEXT[NODE]
[END OF IF]
[END OF LOOP]
STEP-3 : INFO[NEW] :=VAL
STEP-4 : RETURN
```

# ALGORITHM FOR DELETION OF A NODE AT BEGIN

```
DELBEG(START,NODE)
STEP-1 : NODE := NEXT[START]
STEP-2 : WRITE : INFO[NODE]
STEP-3 : NEXT[PREV[NODE]] := NEXT[NODE]
PREV[NEXT[NODE]] := PREV[NODE]
STEP-4: FREE(NODE)
STEP-5 : RETURN
```

# ALGORITHM FOR DELETION OF A NODE AT END

```
DELAST(START,NODE)
STEP-1 : NODE := NEXT[START]
STEP-2 : COUNT := 1
STEP-3: REPEAT WHILE (NEXT[NODE]!=NULL)
    NODE := NEXT[NODE]
    COUNT := COUNT+1
[END OF LOOP]
```
