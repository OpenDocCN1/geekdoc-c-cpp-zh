considers each edge in turn, order by increasing weight. If an edge (u,v) connects two different trees then (u,v) is added to the set of edges of MST , and two trees connected by an edge(u,v) are merged into a single tree. On the other hand if an edge(u,v) connects two vertices in the same tree, then edge(u,v) is discarded. It uses a disjoint set data structure to maintain several disjoint sets of elements. Each set contains the vertices in a tree of current forest.

# ALGORITHM KRUSKAL(G,W)

+   1. A = { φ }
+   2. for each vertex v ∈ V[G]
+   3. do MAKE-SET(v)
+   4. Sort edges E by increasing order of weight W
+   5. for each edge(u,v) ∈ E(G)
+   6. do if FIND-SET(u) ≠ FIND-SET(v)
+   7. then A = A U {(u,v)}
+   8. UNION(u,v)
+   9. return A
