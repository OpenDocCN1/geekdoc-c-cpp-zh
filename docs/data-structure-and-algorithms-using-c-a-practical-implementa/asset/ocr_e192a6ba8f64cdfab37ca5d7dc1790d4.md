# 8.12 Heap Tree

A heap is a complete binary tree and is implemented in an array as sequential representation rather than the linked representation. A heap can be constructed in two different ways such as MAX - HEAP or MIN - HEAP.

A heap is called as Max - Heap or Descending Heap is every node of a heap has a value greater than or equal to the value of every child of that node. In max heap the value of the root will be the biggest number.

A heap is called as min heap or ascending heap if every node of heap has a value less than or equal to the value of every child of that node.
