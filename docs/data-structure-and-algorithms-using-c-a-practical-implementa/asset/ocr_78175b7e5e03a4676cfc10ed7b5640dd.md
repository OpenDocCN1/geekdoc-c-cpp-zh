Step-3 : In the third loop, the 3rd element is compared with the 0th element 52, since 45 is smaller than 52 then 45 is inserted in the 0th place in the array and all the elements from 0th to 2nd are shifted to right by one position.

Step-4 : In the fourth loop the fourth element 33 is compared with the 0th element 45,since 33<45 then 4th element is inserted into the 0th place and all the elements from 0th to 3rd are shifted by one position and as a result we will got the sorted array.
