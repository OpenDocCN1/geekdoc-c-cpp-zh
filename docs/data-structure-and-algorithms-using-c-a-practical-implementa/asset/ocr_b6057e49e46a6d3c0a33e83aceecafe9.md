# If...else

```
If condition, then:
Statements
Else :
Statements
[end of if structure]
```

# If...else ladder

```
If condition1, then:
Statements
Else if condition2, then:
Statements
Else if condition3, then:
Statements
....................
....................
....................
Else If conditionN, then:
Statements
Else:
Statements
[end of if structure]
```

# LOOPING CONSTRUCT

```
Repeat for var = start_value to end_value by
step_value
Statements
[end of loop]
Repeat while condition:
Statements
[end of loop]
Ex : repeat for I = 1 to 10 by 2
Write: i
[end of loop]
```
