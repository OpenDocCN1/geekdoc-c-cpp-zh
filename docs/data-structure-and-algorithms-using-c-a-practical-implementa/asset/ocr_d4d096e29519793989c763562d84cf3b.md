# 9.7 Topological Sorting

In any directed graph which has no cycle, topological sort gives the sequential order of all the nodes x,y and x comes before y in sequential order if a path exists from x to y. So this sequential order will indicate the dependency of one task on another.a

For topological sorting the steps are

+   - Take all the nodes which have zero indegree.
+   - Delete those nodes and edges going from those nodes.
+   - Do the same process again until all the nodes are deleted.
