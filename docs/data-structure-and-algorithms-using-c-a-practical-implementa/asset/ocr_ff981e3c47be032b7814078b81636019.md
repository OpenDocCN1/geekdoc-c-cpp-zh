# Difference between STATIC and AUTO

```
#include<stdio.h>
void main()
{
void change();
change();
change();
change();
}
void change()
{
auto int x=0;
printf("\n X = %d",x);
x++;
}
```

OUTPUT
X=0
X=0
X=0

```
#include<stdio.h>
void main()
{
void change();
change();
change();
change();
}
void change()
{
static int x;
printf("\n X = %d",x);
x++;
}
```

OUTPUT
X=0
X=1
X=2
