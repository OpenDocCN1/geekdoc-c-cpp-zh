# ALGORITHM PRIM(G,W,R)

+   1. for each u ∈ V(G)
+   2. do key[u] ← -∞
+   3. π(u) ← Nil
+   4. Key[R] ← 0
+   5. Q ← V(G)
+   6. While Q ≠ φ
+   7. do u ← EXTRACT-MIN(Q)
+   8. for each v ∈ Q and w(u,v) < key(v)
+   9. then π(v) ← u
+   10. key[v] ← w(u,v)
