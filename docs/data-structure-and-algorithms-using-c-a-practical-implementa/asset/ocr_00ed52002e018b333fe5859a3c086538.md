# 9 Graph

GRAPH is a non linear data structure in which the elements are arranged randomly in side the memory and are interconnected with each other like TREE. The GRAPH having a wide range of application in general life implementation like road map, electrical circuit designs etc...

A graph G is an ordered pair of sets (V,E) where V is the set of vertices and E is the edges which connect the vertices.

A graph can be of two types such as

+   - Directed Graph
+   - Undirected Graph

# DIRECTED GRAPH

A graph in which every edge is directed is called undirected graph.

# UNDIRECTED GRAPH

A graph in which every edge is undirected is called undirected graph.

If in a graph some edges are directed and some are undirected then that graph will be called as mixed graph.
