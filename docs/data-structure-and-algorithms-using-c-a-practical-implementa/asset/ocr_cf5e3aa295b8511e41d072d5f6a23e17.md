# DELETION FROM THE B-TREE

Deletion from a B-Tree is similar to the insertion. Initially we need to find the node from which the value is to be deleted. After the deletion of the value we need to check, whether the tree still maintains the property of B-TREE or not.

Like insertion here also two situations will occur as

+   - Node is leaf node
+   - Node is non leaf node
