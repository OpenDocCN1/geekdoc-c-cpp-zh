# UNDERFLOW

If one can try to delete an element from an empty stack then that situation will be called as the UNDERFLOW.

In general if one can try to DELETE an element from an empty data structure then that will be called as OVERFLOW.

# Condition for UNDERFLOW

+   - Top = -1 (for the STACK starts with 0)
+   - Top = 0 (for the STACK starts with 1)

# EXAMPLES

STACK[5]

[ ] [ ] [ ] [ ] [ ]
0   1   2   3   4

top = -1 (CONDITION FOR EMPTY STACK)

PUSH(5)

[5] [ ] [ ] [ ] [ ]
0   1   2   3   4

top = 0

PUSH(25)

[5] [25] [ ] [ ] [ ]
0   1   2   3   4

top = 1

PUSH(53)

[5] [25] [53] [ ] [ ]
0   1   2   3   4

top = 2

PUSH(78)

0   1   2   3   4
