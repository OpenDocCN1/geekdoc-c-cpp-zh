# ## 2.3 Pointer

The pointer is a variable which can store the address of another variable. Whatever changed with the value of the variable with the help of the pointer that will directly effect to it.

# ### 2.3.1 Declaration of a Pointer

Like other variables the pointer variable should also be declared before its use

```
SYNTAX
Data_type *variable_name;
Example: int *p;
```

# ### 2.3.2 Initialization of a Pointer

Initialization means to assign an initial value, since the pointer can store only the address so during its initialization we have to assign an address of another variable.

```
Ex: int *x,p;
X=&p; /* INITIALIZATION */
```

> NOTE : After declaration of the pointer variable, if we write simply the variables name than it will represent to address and *variable will represent to value. But in C++ always we have to use *variable since it deals with object.

Example : (IN C) WRITE A PROGRAM TO INPUT A NUMBER AND DISPLAY IT.

```
#include<iostream.h>
void main()
{
 int *p,x;
 p=&x;
 printf("\n Enter a number*");
 scanf("%d",&x);
```
