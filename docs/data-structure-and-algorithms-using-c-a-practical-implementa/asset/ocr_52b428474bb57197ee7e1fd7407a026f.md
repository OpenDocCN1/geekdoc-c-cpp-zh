# Example

![](bbox=[0.305, 0.146, 0.656, 0.303])

The path matrix is

```
D⁰ =
7   5   ∞   ∞
7   ∞   ∞   2
∞   3   ∞   ∞
4   ∞   1   ∞
```

According to the algorithm k = 4, i= 4 and j= 4.

So the total number of repetition will be O(4³) = 64

We have to compute D1,D2,D3,D4.

```
For k = 1 & I = 1
J=1 : D'[1][1] = min(D⁰[1][1], D⁰[1][1] + D⁰[1][1]) = (7,7+7) = 7
J=2 : D'[1][2] = min(D⁰[1][2], D⁰[1][1] + D⁰[1][2]) = (5,7+5) = 5
J=3 : D'[1][3] = min(D⁰[1][3], D⁰[1][1] + D⁰[1][3]) = (∞,7+∞) = ∞
J=4 : D'[1][4] = min(D⁰[1][4], D⁰[1][1] + D⁰[1][4]) = (∞,7+∞) = ∞
```

```
For k = 1 & I = 2
J=1 : D'[2][1] = min(D⁰[2][1], D⁰[2][1] + D⁰[1][1]) = (7,7+7) = 7
J=2 : D'[2][2] = min(D⁰[2][2], D⁰[2][1] + D⁰[1][2]) = (∞,7+5) = 12
J=3 : D'[2][3] = min(D⁰[2][3], D⁰[2][1] + D⁰[1][3]) = (∞,7+∞) = ∞
J=4 : D'[2][4] = min(D⁰[2][4], D⁰[2][1] + D⁰[1][4]) = (2,7+∞) = 2
```

```
For k = 1 & I = 3
J=1 : D'[3][1] = min(D⁰[3][1], D⁰[3][1] + D⁰[1][1]) = (∞,∞+7) = ∞
J=2 : D'[3][2] = min(D⁰[3][2], D⁰[3][1] + D⁰[1][2]) = (3, ∞+5) = 3
J=3 : D'[3][3] = min(D⁰[3][3], D⁰[3][1] + D⁰[1][3]) = (∞,∞+∞) = ∞
J=4 : D'[3][4] = min(D⁰[3][4], D⁰[3][1] + D⁰[1][4]) = (∞,∞+∞) = ∞
```
