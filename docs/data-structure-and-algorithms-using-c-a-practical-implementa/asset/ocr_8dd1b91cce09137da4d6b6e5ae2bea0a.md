# ## REGULAR GRAPH

A graph is regular if every node is adjacent to the same number of nodes, Graph-1 is regular since every node is adjacent to other three nodes.

# ## PLANAR GRAPH

A graph is called planar if it can be drawn in a plane without any two edges intersecting. Graph-1 is not a planar graph, while graphs Graph-2, graph-3, and graph-4 are planar graphs.

# ## ARTICULATION POINT

If on removing a node from the graph the graph becomes disconnected then that node is called as the articulation point.

# ## BRIDGE

If on removing an edge from the graph the graph becomes disconnected then that edge is called the bridge.

# ## TREE

An undirected connected graph will be called tree if there is no cycle in it.

# ## BICONNECTED GRAPH

A graph with no articulation points is called as a biconnected graph.
