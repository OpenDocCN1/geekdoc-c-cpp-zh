The external nodes are represented by the square brackets and the internal nodes are represented by the Circles. The path length for any node is the number of minimum nodes traversed from root to that node. In the above figure the total length for internal and external nodes are :-
Path(I) = 0 + 1 + 2 + 1 + 2 + 3 = 9
Path(E) = 2 + 3 + 3 + 2 + 4 + 4 + 4 + 3 = 21
We can also get the total path length of external node as
PATH(E) = PATH(I) + 2N Where N is the number of internal nodes.
Suppose each node having some weights then the weighted path length will be
P = W1P1 + W2P2 + ............ + WNPN
W is the weight and P is the path length of an external node.
