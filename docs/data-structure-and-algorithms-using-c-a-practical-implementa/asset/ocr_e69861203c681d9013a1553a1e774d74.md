# 4.10 Static Data Member and Member Functions

The static is a storage class specifier which is generally used for the declaration of the variable having a specificality compare to other normal variables that it is maintain the consistency of the value of the variable even if it is out of the scope of the function. In C++ we may use static with the members of the class. When we declare a data member as static then the initialized value of the variable is ZERO and it will create a single copy of the variable for all the objects and that will be shared by all the objects. The scope of the static variable is local but it works as like a global variable.
