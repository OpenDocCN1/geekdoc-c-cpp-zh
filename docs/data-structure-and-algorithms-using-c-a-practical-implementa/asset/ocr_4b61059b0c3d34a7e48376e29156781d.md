# Ex: WAP TO INPUT A NUMBER AND DISPLAY IT by using FUNCTION

No doubt that this program is not efficiently used with the structure because the structure is used when there is a requirement to handle more than one element of different type. But in the above program only single variable is to be used but for easy understanding the difference of structure in 'c' and structure in 'c++' this one is better.

```
IN 'C'

#include<stdio.h>
struct print
{
int x;
} ;
void main()
{
struct print p;
void display(struct print);
printf("\n Enter the number");
scanf("%d",&p.x);
display(p);
}
void display(struct print p)
{
printf(" THE ENTERED NUMBER IS %d",p.x);
}
```

OUTPUT

Enter the number 23
THE ENTERED NUMBER IS 23
