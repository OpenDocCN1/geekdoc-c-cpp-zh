# 7.7 Header Linked List

The header link list is a special type of linked list in which a special node will be usd as header node. The purpose of this node is to store the total number of elements present in the linked list. On necessity we can easily access the elements of the linked list.

# Types of Header Linked List

+   - Basically two types of header linked list are used as
+   - Grounded Header Linked List and Circular Header Linked list.
