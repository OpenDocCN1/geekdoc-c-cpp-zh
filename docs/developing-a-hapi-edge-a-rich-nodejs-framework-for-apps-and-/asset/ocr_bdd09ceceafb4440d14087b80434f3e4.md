# Decorating the reply

Similar to server.bind this function lends itself to use reply. Decorate is more narrow
in the scope that it can be used, but it's perfect for canned replies.

```
server.decorate('reply', 'success', function () {
  return this.response({ success: true });
});
```

We have an option to decorate the reply object or the server object and the first argu-\gment where we specify which one. The second argument specifies the name of the meth-
d and the third is the call back.
In our handler, we can simply call:

```
reply.success();
```

This is a very nice shortcut and saves from changing in multiple places if the JSON ob-
jerted changes. It's also a nice means to make sure the replies for success are consist-
ent it eliminates types.

# Tails

Certain actions do not require immediate completion. The type of calls may be a back-\ground of some sort, which is not necessary for the return of the page served to the
client. It may be a database call for some update, or it may be any number of things. When
not necessary to capture this, we are still likely to capture this for logging purpos-
es. When the tails are completed for the request, the server emits a tail event.

```
server.route({
  method: 'GET',
  path: '/',
  handler: function (request, reply) {
    var publishTail = request.tail('publish the book in the
background for download');

    HapiBook.publishForDownload({ format: 'pdf' }, function
(downloadUri) {
      var mail = Mail({ to: user });
      mail.publishNotification(downloadUri, function () {
        publishTail();
      });
    });
```
