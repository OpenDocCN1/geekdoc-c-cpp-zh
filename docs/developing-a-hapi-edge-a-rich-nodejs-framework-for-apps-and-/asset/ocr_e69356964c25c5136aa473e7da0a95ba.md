# Experiments

While lab tests can be made to look like mocha and jasmine behavior driven-BDD style tests, they can also be named something entirely. Whereas BDD styles to use describe and it, lab also offers the options to experiment and test instead. The functions describe and experiment are interchangeable, just as it is and test are. The style you choose is entirely up to you, and there isn't a wrong answer. One of the things is nice about using the experiments style, however, it does reinforce the notion that an engineer is creating the tests and there is some attempt to be scientific about them.

An experiment is useful for wrapping a group of similar tests. For example, if you are testing lab itself, you may write experiment tests that are wrapped in an experiment demonstrated below.

```
// Load modules
var Code = require('code');
var Lab = require('lab');

var lab = exports.lab = Lab.script();
lab.experiment('lab', function () {
  lab.test('exists', function (done) {
    Code.expect(lab).to.exist();
    done();
  });
lab.test('has properties', function (done) {
    Code.expect(Object.keys(lab)).to.not.have.length(0);
    done();
  });
});
```

Then if you run these tests in verbose mode, you will get the following:

```
$ lab -v
lab
1) exists (3 ms)
2) has properties (1 ms)
```
