# Server 2

hapi is a framework used for building applications and services. Behind every service, there is a server; something that serves the client needs. hapi is at its core a superset of an HTTP server. Everything around hapi is tied to this fact, so we kick off this book talking about the main functionality. It's from this everything else is configured and makes a difference. We're going to be talking about lot of concepts that are related to the server, plugins, handlers, testing, and more.

In this chapter we look at how to set up a server and how we've set up the server for our hapi-plugins.com example. We're going to teach you the ins and outs of the server in the hapi framework. You'll know to know how to set up caching. You'll get a first glimpse into plugins and how to add methods that will be available throughout your application. Finally you will learn about the request lifecycle and how to add custom functions for your application.

# Setting up a simple server

Of course we can't start a book without first having a hello world example. Well, yes we can actually, but we're not going to. It's important to know how to set up a server in its simplest configuration before advancing to more complex setups.

```
var Hapi = require('hapi');
var server = new Hapi.Server();
server.connection();
server.route({
    method: 'GET',
    path: '/',
    handler: function (request, reply) {
        return reply('hello hapi');
});
```
