```
var server = new Hapi.Server();
server.views({
  engines: {
    html: require('mu')
  },
  path: __dirname + '/views'
});
```

This is pretty simple. It's going to look in the views directory for 'html' files. When you call the request.view('templateName', { context }) type function previously it will compile and serve this up to the client. Next let's look at Handlebars.js.
