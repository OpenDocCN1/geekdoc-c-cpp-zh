folder by registering good along with the good-console reporter. An example of this registration is found below.

```
var goodOptions = {
  opsInterval: 5000,
  reporters: {
    reporter: 'good-console',
    events: { log: '*', ops: '*' }
  }
};
```

```
var registerHttpPlugins = function (next) {
  server.register([
    Bell,
    Blipp,
    HapiAuth,
    Authentication,
    Controllers,
    Models,
    Routes,
    { register: require('good'), options: goodOptions },
    { select: 'http' },
    function (err) {
      return next(err);
    }
  ]);
};
```

The events that the good-console reporter will send to the console are indicated by the events property. The * value indicates that the reporter will not filter out any events based on specific tags. If you are concerned with only events related to a certain tag, you can indicate that by replacing * with a single string named as the tag you care about or with an array of strings representing the event tags you care about.

The reporting from good is observed after you start the server and look at the output to stdout. Below shows an example output from the ops event after 10 seconds of the server running. As you can see, the memory consumed, uptime, and the loads can be reported.

