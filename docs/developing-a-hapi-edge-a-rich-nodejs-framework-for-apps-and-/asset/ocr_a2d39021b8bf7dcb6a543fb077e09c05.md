# What will this book teach you?

This book will teach you how to build awesome web applications using hapi. It covers many aspects of how and why hapi works the way it does. You will see helpful and ad-v features such as authentication, validation, caching, templating, testing, and de-ging. In this book, you will also walk through the creation of a fully operational hapi web application.
