```
var Hapi = require('hapi');
var ECT = require('ect');
var ectRenderer = ECT({
watch: true,
root: __dirname + '/views'
});
```

```
var server = new Hapi.Server({
server.engines: {
ect: {
  compile: function (tmpl, opts) {
    return function (context, engineOptions) {
      return ectRenderer.render(opts.filename,
context);
    }
  },
  compileMode: 'sync'
},
basePath: __dirname,
path: './views'
});
```

You will see a bit more required. We need to help hapi along with how the
compiling is done by providing a compile function. Additionally, you need to tell hapi
 sync in the compileMode that was discussed previously in this chapter.

tion of the hapis website under Templating. If you don't find what you need, open up
a discussion or considering helping the community to get this templating engine added.
