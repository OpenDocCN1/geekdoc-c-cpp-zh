# Linting

One of the powerful features that lab includes built-in linting support. Out of the box, eslint and jshint are supported linters. The default linting rules enforce a style like the happy style. The original intent of including the linters is to ensure that pull requests to happy projects follow the same style. However, the linting rules can be changed to fit the needs of your project. Any options that need to be passed into the linter can be set using the --lint-options argument. If you want to run the default linting rules with the default eslint, pass -L or --lint to lab. In order to change the linter used, pass -n or --linter to lab. Below demonstrates how to run lab with jshint.

```
$ lab -n jshint
```
