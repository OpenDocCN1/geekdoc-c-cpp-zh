You can have filters setup for the dev prod keywords. To generate a JSON file we can use later for rejoice you can run: confidence -c json --filter.env=dev > rejoice.json. This will result in merging what's in $base with the dev specific entries. In this case, you want blipp and good-console for only the development environment because they are handy for debugging.
