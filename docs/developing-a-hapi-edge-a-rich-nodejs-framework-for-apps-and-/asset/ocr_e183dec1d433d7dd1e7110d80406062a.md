# hapi-auth-cookie

A common authentication scheme of websites is to use cookies to store a security token. Similar to the basic authentication scheme depends on the developer implementing a validate function, the cookie authentication expects the same function. Cookie authentication is provided by the module hapi-auth-cookie. The module options many properties that relate to how cookies are stored, for example to live or secure flag property. One of the main differences between cookie authentication and the basic authentication strategies is that the cookie authentication strategy decorates the request.auth.session object with properties for setting or clearing session properties.
