# hapi-plugins.com

![](bbox=[0.147, 0.25035, 0.852, 0.53035])

In this book, we will walk through how to use hapi to create the backend services for a real (but basic) web application, hapi-plugins. hapi-plugins (hapi-plugins.com) is a search-repository for hapi-related modules available on NPM.

This book will NOT cover how to build the client-side JavaScript portion of the application. However, the complete source code is available on GitHub.

# Style

We will be following hapi style-guidelines throughout this book. To find more about what they are, you can see them at the hapi Style Guide.

We may not agree with everything in the styles, but it's worth noting that just having this style guide to follow prevents time taken up by discussion. It's 99 percent good. Some practices may look odd, but it really helps with the visualization of the code. We recommend choosing this style not for projects related to hapi, but for node development in general.
