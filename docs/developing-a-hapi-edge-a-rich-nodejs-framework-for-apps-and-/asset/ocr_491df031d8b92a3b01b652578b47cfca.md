We created an instance of a hapi server. We don't actually have to do anything at all to configure it. The next step is to get a connection to the server. The connection is the host and port that the server is listening to. By default, the host is set to localhost and the port is generated randomly on ports that don't require system administrator access, and that are available. Since we don't know what the port is, we print the URI out at the end so we can see where our server is listening.

We add a route so that we have somewhere we can actually send a request. We'll go a lot further into routes in Chapter 3, but for now, think of a route as a configured path that the request from the client (browser) can take in order to have a particular response served.

At this point we start the server, and log the server URI so that we know what the server started on.
The next logical steps would be to set a port for our server to start on so that we know it's the same each time. This can be accomplished by using the options for the connection: `server.connection({ port: 8088 });`
