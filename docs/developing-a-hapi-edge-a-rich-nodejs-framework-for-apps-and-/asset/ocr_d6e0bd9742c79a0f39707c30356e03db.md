# ROUTE PREREQUISITES

You may need to initialize a database connection and return it for every single endpoint that you're using. This is a task's perfectly suitable for route prerequisites. There are of course other things you could need to set up, but this is probably the most common. The argument for pre is a mixed array. It can contain either other arrays or other objects. That which is assigned an array will be executed in parallel, while all the other items are executed in series, e:g:

```
server.route({
  method: 'GET',
  path: '/',
  config: {
    handler: function (request, reply) {
      reply.view('index');
    },
    pre: [
      series,
      series,
      [
        parallel,
        parallel
      ],
      series
    ]
  }
});
```
