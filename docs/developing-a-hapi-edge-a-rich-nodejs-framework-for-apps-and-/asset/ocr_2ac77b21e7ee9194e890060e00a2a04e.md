# Using HTTP

Then, we define a JavaScript object that will become our model. In this case, we have an outer object (NpmPackages) and an inner object (Packages). By having an outer object, we can pass instance-specific options to the inner, final object.

Next, before we add our functions, we set aside important configuration variables into defaults.

We know that the shortest is obtainable from the URL "https://skimdb.npmjs.com/registry/_all_docs" without any additional parameters. But the other search APIs do take parameters. We abstract all the URLs into two parts: the base URL and parameterized URI paths. Then, inside the actual request functions, we will concatenate the base URL and URI to generate the final URL. That is why the URIs are functions.

```
var Hoek = require('hoek');
var Wreck = require('wreck');
var Util = require('util');

var internals = {};
internals.defaults = {
  host: 'https://registry.npmjs.org',
  hostList: 'https://skimdb.npmjs.com',
  uris: {
    byShortList: function () { return "/all_docs"; },
    byName: function (name, version) {
      if (version) {
        return Util.format("%s/%s", name, version);
      } else {
        return Util.format("%s", name);
      }
    },
    byKeyword: function (kw) { return Util.format('//-_view/keyword?startkey=%s&endpoint=%s,[}}&group_level=3', kw, kw); },
    byDependentUpon: function (kw) { return Util.format('//-_view/dependentUpon?group_level=3&startkey=%s]&endpoint=%s&skip&limit=1000', kw, kw); }
  }
};
```
