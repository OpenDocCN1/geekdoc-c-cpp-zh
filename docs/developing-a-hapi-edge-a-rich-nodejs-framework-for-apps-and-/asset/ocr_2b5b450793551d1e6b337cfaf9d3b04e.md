# Summary

Setting up a server is rather simple. A server and plugin are much the same thing. The server can consist of several different plugins. A plugin is just a logical separation of smaller more manageable parts, which can get added to your server instance. We can decorate the server with functions and the server can be configured using JSON configuration files.

Using glue can really make our setup a lot simpler, and using configuration files with rejoice and confidence is a good way to go if there are development and production setups.
