# Core Files

One of the more powerful tools to use when debugging an issue with a Node process is to drop a core file of the running process and investigate it with the modular debugging (mdb) tool in SmartOS. Core files are now able to be created on Linux and analyzed in SmartOS. To create a core on Linux you will need to have a newer version of node and the ulimit set to unlimited.
