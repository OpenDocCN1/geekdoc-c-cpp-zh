# CHAPTER 2: Server

Now that we know what we're trying to accomplish, let's see how it's done. registerHttpPlugins and registerApiPlugins are functions to handle registering the plugins for the two separate connections on our server. One function can only apply plugins to one connection at a time. Therefore, we need to distinguish these two functions because we have hapi for two connections.

We're using Async.auto to complete this asynchronously, which we can get away with because it doesn't matter in what order we register plugins. If you're not familiar with the Async library, it's a great tool, and we use it everywhere for cleaner code. It's worth noting here and taking a break to look at the documentation for Async to get familiarized with it. We'll wait.

If there are errors, we print the error to the console and If there are no errors, we go ahead and start the server.

Note that server.register can take an array of plugins. This behavior is similar to [Async].series.in fact, hapi is internally using a lightweight version of Async called items. If you're not finding yourself using all of the features of Async, this may be a good alternative for you.
