# NPM Packages

To start, we configure an instantiable model object NPMackages.

```
var Hoek = require('hapi');
var Wreck = require('wreck');
var Util = require('util');

var internals = {};
internals._defaults = {};
```

```
internals.NMPackages = function (options) {

  var Packages = function (override) {
    this.options = Hoek.applyToDefaults(internals._de-faults, options || {});
    return Packages;
  }
};
```

```
module.exports = internals.NMPackages;
```

For each model, we want to retain our typical require statements on top. hapi style guides dictate the use of a model-specific internals object that is essentially locally-private (cannot be accessed or read from outside this file). Inside, we can set global options (in the _defaults object) that can be overridden later. This snippet has no defaults though.
