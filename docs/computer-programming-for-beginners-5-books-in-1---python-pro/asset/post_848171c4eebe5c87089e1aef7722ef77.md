
For both paths that begin with the current number, the function calls itself twice—one to add and the other to multiply. If the first call returns something valid, good; if not, the result of the second call is returned. It does not matter whether a string or null is returned. Below is an illustration of how functions provide effects. This example searches for a route to the number 13.

## Growing functions

Functions can be introduced into programs in two ways. The first is by writing similar code a lot of times, which invites more mistakes. The second is to find a few functionalities that have not been written and deserve their own function. You can begin by naming the function and then write the body. Below is an example. We will write a program that prints two numbers—the number of cows and chickens available on a farm.

```text
007 Cows
011 Chickens
function printFarmInventory(cows, chickens) {
  let cowString = String(cows);
  while (cowString.length < 3) {
    cowString = "0" + cowString;
  }
  console.log(`${cowString} Cows`);
  let chickenString = String(chickens);
  while (chickenString.length < 3) {
    chickenString = "0" + chickenString;
  }
  console.log(`${chickenString} Chickens`);
}
printFarmInventory(7, 11);
```

Writing `.length` after a string expression determines the length of that string. The loop continues to add zeros at the beginning of the number strings until they consist of three characters.

Here is a better attempt:

```javascript
function printZeroPaddedWithLabel(number, label) {
  let numberString = String(number);
  while (numberString.length < 3) {
    numberString = "0" + numberString;
  }
  console.log(`${numberString} ${label}`);
}
function printFarmInventory(cows, chickens, pigs) {
  printZeroPaddedWithLabel(cows, "Cows");
  printZeroPaddedWithLabel(chickens, "Chickens");
  printZeroPaddedWithLabel(pigs, "Pigs");
}
printFarmInventory(7, 11, 3);
```

Instead of just lifting out the repeated part, try to pick out a single concept:

```javascript
function zeroPad(number, width) {
  let string = String(number);
  while (string.length < width) {
    string = "0" + string;
  }
  return string;
}
function printFarmInventory(cows, chickens, pigs) {
  console.log(`${zeroPad(cows, 3)} Cows`);
  console.log(`${zeroPad(chickens, 3)} Chickens`);
  console.log(`${zeroPad(pigs, 3)} Pigs`);
}
printFarmInventory(7, 16, 3);
```

A function can also be used to print aligned tables of numbers.

## Functions and side effects

Functions can have side effects and return values. Value-producing functions are easier to integrate in new ways than functions that only produce side effects. A pure function is a specific kind of value-producing function that takes some arguments and returns a value based only on those arguments; it does not depend on side effects. For instance, it will not read a global binding with a changeable value. When called with the same arguments, it produces the same value.

## Summary

In this chapter, you learned how to write your own functions. Knowing how to use the function keyword, and when to use it as an expression, allows you to build a function value. When you use a function as a statement, it can set a binding and give that binding a function as its value. You can also use arrow functions to build functions.

```javascript
// Define f to hold a function value
const f = function(a) {
  console.log(a + 2);
};
// Declare g to be a function
function g(a, b) {
  return a * b * 3.5;
}
// A less verbose function value
let h = a => a % 3;
```

The main thing to understand about functions is knowing the scopes. Every block builds a new scope. Parameters and bindings set in a specific scope are local and invisible from the outside. Bindings set with `var` act differently, and they end up in the global scope. Separating the tasks that the program executes into various functions is important. You do not need to repeat yourself often, and functions can arrange a program by categorizing code into bits that perform specific actions.

## Chapter 5: Data Structures: Objects and Arrays

Data structures are built from Booleans, strings, and numbers. Several types of information use more than one chunk. Objects allow the user to combine values together with other objects to build more complex structures. In this chapter, you will understand these concepts by solving a real problem.

### Data sets

If you want to work with a lot of data, you must represent the data in the machine's memory. For instance, you need to represent a group of numbers like 2, 3, 5, 7, and 11. Now let's get creative with our use of strings, as strings can contain quite a lot of data. We will use `"2 3 5 7 11"` as the representation. JavaScript offers a special data type for storing sequences of values, which is called an array. You write an array as a list of values between square brackets, separated by commas.

```javascript
let listOfNumbers = [2, 3, 5, 7, 11];
console.log(listOfNumbers[2]);
// → 5
console.log(listOfNumbers[0]);
// → 2
console.log(listOfNumbers[2 - 1]);
// → 3
```

The notation for getting at the elements inside an array also uses square brackets. A pair of square brackets placed immediately after an expression, with another expression inside, retrieves the element at that position. When counting elements in an array, you begin from zero, not one. Therefore the first element is retrieved with `listOfNumbers[0]`.

### Properties

The previous chapters have contained expressions like `myString.length` (to calculate the length of a string) and `Math.max` (the maximum function). These are properties that access property values. Virtually all JavaScript values contain properties. The few values that do not contain properties are `null` and `undefined`. If you access a property on a nonvalue, the result will be an error.

```javascript
null.length;
// → TypeError: null has no properties
```

In JavaScript, the two main ways to access properties are with a dot and with square brackets. Both `value.x` and `value[x]` access a property on `value`—but not necessarily the same property. The difference is in how `x` is interpreted.

If you use the dot, the text after the dot is the literal name of the property. If you use the square brackets, the expression within the brackets is evaluated to get the property name. `value.x` delivers the property of `value` called "x," while `value[x]` evaluates the expression `x` and uses the result, converted to a string, as the property name. If the property you want is named `color`, you should type `value.color`. If the property you want is named by the binding `i`, type `value[i]`. Property names are strings, but the dot notation works only with valid binding names. Therefore if you want to access a property named `2` or `John Doe`, use the square brackets: `value[2]` or `value["John Doe"]`.

The elements in an array are stored as the properties of the array, using numbers as property names. An array's `length` property determines how many items it contains. The name of that property is a valid binding name. Type `array.length` to determine the length of an array; it is much easier to type than `array["length"]`.

### Methods

String and array objects contain several properties that store function values.

```javascript
let doh = "Doh";
console.log(typeof doh.toUpperCase);
// → function
console.log(doh.toUpperCase());
// → DOH
```

Every string has a `toUpperCase` property. When you call this property, it returns a copy of the string in which all the letters have been converted to uppercase. Even though `toUpperCase` does not take an argument, the function can access the string `"Doh"`—the value of the property on which it was called. Properties that contain functions are known as methods. The example below illustrates two methods that can be used to manipulate arrays.

```javascript
let sequence = [1, 2, 3];
sequence.push(4);
sequence.push(5);
console.log(sequence);
// → [1, 2, 3, 4, 5]
console.log(sequence.pop());
// → 5
console.log(sequence);
// → [1, 2, 3, 4]
```
