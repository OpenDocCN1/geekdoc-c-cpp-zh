# Bindings and scopes

Every binding consists of a scope that enables the visibility of the binding. Whenever you call a function, new illustrations of binding are developed. This creates separation between functions, every function call behaves in its own world and is easy to understand. Functions that were declared with the var keyword in the pre-2015 JavaScript can be seen throughout the global scope. They are absent in a function.

```
```javascript
let x = 10;
if (true) {
  let y = 20;
  var z = 30;
  console.log(x + y + z);
  // → 60
}
// y is not visible here
console.log(x + z);
// → 40
```
