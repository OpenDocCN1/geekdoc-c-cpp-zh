
```js
{
  type: "apply",
  operator: {type: "word", name: ">"},
  args: [
    {type: "word", name: "x"},
    {type: "value", value: 5}
  ]
}
```

We describe a function parseExpression, which takes a string as input and returns an object containing the data structure for the expression at the start of the string, along with the part of the string left after parsing this expression. When you are parsing subexpressions, you can call this function again, passing it the argument expression with the remaining text. This text could consist of more arguments or the closing parenthesis that ends the argument list.

Below is the first part of the parser:

```js
function parseExpression(program) {
  program = skipSpace(program);
  let match, expr;
  if (match = /^"([^"]*)"/.exec(program)) {
    expr = {type: "value", value: match[1]};
  } else if (match = /^\d+\b/.exec(program)) {
    expr = {type: "value", value: Number(match[0])};
  } else if (match = /^[^\s(),#]+/.exec(program)) {
    expr = {type: "word", name: match[0]};
  } else {
    throw new SyntaxError("Unexpected syntax: " + program);
  }
  return parseApply(expr, program.slice(match[0].length));
}

function skipSpace(string) {
  let first = string.search(/\S/);
  if (first == -1) return "";
  return string.slice(first);
}
```

## The evaluator

The evaluator is used to run the syntax tree for a program. Give it a syntax tree and a scope object that associates names with values, and it will evaluate the expression that the tree represents and return the value that this produces.

```js
const specialForms = Object.create(null);
function evaluate(expr, scope) {
  if (expr.type === "value") {
    return expr.value;
  } else if (expr.type === "word") {
    if (expr.name in scope) {
      return scope[expr.name];
    } else {
      throw new ReferenceError(
        `Undefined binding: ${expr.name}`);
    }
  } else if (expr.type === "apply") {
    let {operator, args} = expr;
    if (operator.type === "word" &&
        operator.name in specialForms) {
      return specialForms[operator.name](expr.args, scope);
    } else {
      let op = evaluate(operator, scope);
      if (typeof op === "function") {
        return op(...args.map(arg => evaluate(arg, scope)));
      } else {
        throw new TypeError("Applying a non-function.");
      }
    }
  }
}
```

The evaluator contains code for every expression type. A literal value expression returns its value. For a word, check whether it is defined in the scope and, if so, return the value of the binding. If it is a special form, it does not evaluate anything; instead, it passes the argument expressions, along with the scope, to the function that handles the form. If the call is ordinary, evaluate the operator, determine whether it is a function, and call it with the evaluated arguments. Use plain JavaScript function values to represent Egg’s function values. The recursive structure of evaluating is similar to the structure of the parser, and the two mirror the structure of the language. You could combine the parser with the evaluator and evaluate during parsing, but separating them gives a clearer picture of the program. That is all you need to implement Egg.

## Special forms

The specialForms object describes unique syntax in Egg. It associates words with functions that handle such forms. It is currently empty. Let’s add if.

```js
specialForms.if = (args, scope) => {
  if (args.length != 3) {
    throw new SyntaxError("Wrong number of args to if");
  } else if (evaluate(args[0], scope) !== false) {
    return evaluate(args[1], scope);
  } else {
    return evaluate(args[2], scope);
  }
};
```

Egg’s if construct expects three arguments. It evaluates the first, and if the value is not false, it evaluates the second. If not, it evaluates the third. The if form looks more like JavaScript’s ternary ?: operator than JavaScript’s if. It is an expression, not a statement, and produces a value, which is the result of the second or third argument. Egg is also different from JavaScript in how it treats the condition value. It does not treat things like zero or empty strings as false, only the exact value false. All arguments to functions are evaluated before the function is called.

```js
specialForms.while = (args, scope) => {
  if (args.length != 2) {
    throw new SyntaxError("Wrong number of args to while");
  }
  while (evaluate(args[0], scope) !== false) {
    evaluate(args[1], scope);
  }
  // Since undefined does not exist in Egg, we return false,
  // for lack of a meaningful result.
  return false;
};
```

Another building block is do, which evaluates its arguments from top to bottom. Its value is the value of the last argument.

```js
specialForms.do = (args, scope) => {
  let value = false;
  for (let arg of args) {
    value = evaluate(arg, scope);
  }
  return value;
};
```

To create bindings and assign new values, we need a form called define. It expects a word as its first argument and an expression that produces the value to assign to that word as its second argument. Because define is an expression, it must return a value. We will return the value that was assigned (like JavaScript’s = operator).

```js
specialForms.define = (args, scope) => {
  if (args.length != 2 || args[0].type != "word") {
    throw new SyntaxError("Incorrect use of define");
  }
  let value = evaluate(args[1], scope);
  scope[args[0].name] = value;
  return value;
};
```

## The environment

The scope that evaluate takes is an object with properties whose names correspond to binding names. Their values correspond to the values those bindings are bound to. Below is an example of an object to represent the global scope. To be able to use the previously described if construct, the Boolean values must be accessible. Since there are only two Boolean values, all you need to do is bind two names to the values true and false and use them.

```js
const topScope = Object.create(null);
topScope.true = true;
topScope.false = false;
```

We can now evaluate a simple expression that negates a Boolean value.

```js
let prog = parse(`if(true, false, true)`);
console.log(evaluate(prog, topScope));
// → false
```

To provide basic arithmetic and comparison operators, let’s add function values to the scope. We will use the Function constructor on a few operator functions in a loop rather than writing them out one by one.

```js
for (let op of ["+", "-", "*", "/", "==", "<", ">"]) {
  topScope[op] = Function("a, b", `return a ${op} b;`);
}
```

We will wrap console.log in a function to output values and call it print.

```js
topScope.print = value => {
  console.log(value);
  return value;
};
```

That provides enough elementary tools to write simple programs, parse and run them in a new scope:

```js
function run(program) {
  return evaluate(parse(program), Object.create(topScope));
}
```

The object prototype chain will represent nested scopes, allowing us to add bindings without altering the top-level scope.

```js
run(`
do(define(total, 0),
define(count, 1),
while(<(count, 11),
do(define(total, +(total, count)),
define(count, +(count, 1)))),
print(total))
`);
// → 55
```

This program computes the sum of the numbers from 1 to 10, as shown in Egg.

## Functions

A programming language without functions is a really bad one, although it is easy to add a function that uses its last argument as the function’s body. It also uses every argument before that as the function’s parameter names.

```js
specialForms.fun = (args, scope) => {
  if (!args.length) {
    throw new SyntaxError("Functions need a body");
  }
  let body = args[args.length - 1];
  let params = args.slice(0, args.length - 1).map(expr => {
    if (expr.type != "word") {
      throw new SyntaxError("Parameter names must be words");
    }
    return expr.name;
  });
  return function() {
    if (arguments.length != params.length) {
      throw new TypeError("Wrong number of arguments");
    }
    let localScope = Object.create(scope);
    for (let i = 0; i < arguments.length; i++) {
      localScope[params[i]] = arguments[i];
    }
    return evaluate(body, localScope);
  };
};
```

Egg functions have their own local scope. The function created by the fun form creates this local scope and adds the argument bindings to it. It then evaluates the function body in this scope and returns the result.

```js
run(`
do(define(plusOne, fun(a, +(a, 1))),
print(plusOne(10)))
`);
// → 11

run(`
do(define(pow, fun(base, exp,
  if(==(exp, 0),
    1,
    *(base, pow(base, -(exp, 1))))),
print(pow(2, 10))
`);
// → 1024
```
