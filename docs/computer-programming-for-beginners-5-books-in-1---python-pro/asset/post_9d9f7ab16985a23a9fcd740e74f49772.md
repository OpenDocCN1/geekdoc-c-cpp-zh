
```
// → 8
```

A returned object from exec contains an index property, which determines where in the string the successful match starts. Below is the sequence of digits needed:

```
console.log("one two 100".match(/\d+/));
// → ["100"]
```

When a regular expression contains subexpressions grouped with parentheses, the text that matches those groups will also appear in the array. The whole match is the first element, the next is the part matched by the first group, then the following group, and so on.

```
let quotedText = /'([^']*)'/;
console.log(quotedText.exec("she said 'hello'"));
// → ["'hello'", "hello"]
```

When a group does not end up being matched (for example, if it is followed by a question mark), it outputs undefined. When a group matches several times, only the last match ends up in the array.

```
console.log(/(bad)(ly)?/.exec("bad"));
// → ["bad", "bad", undefined]
console.log(/(\d)+/.exec("123"));
// → ["123", "3"]
```

## The Date class

JavaScript has a standard class that represents dates; it is called Date. If you want to create a date object using new, you can call it without arguments to get the current time and date.

```
console.log(new Date());
// → Mon Nov 11 2018 16:19:11 GMT+0100 (CET)
```

You can also build an object for a particular time.

```
console.log(new Date(2008, 11, 8));
// → Mon Dec 08 2008 00:00:00 GMT+0100 (CET)
console.log(new Date(2008, 11, 1, 9, 12, 59, 59, 999));
// → Mon Dec 01 2008 09:12:59 GMT+0100 (CET)
```

You should follow the JavaScript date naming convention where month numbers begin at zero (therefore, December is 11), and day numbers begin at 1.

The hours, minutes, seconds, and milliseconds arguments are optional and default to zero when not specified. Timestamps are stored as the number of milliseconds in the UTC time zone, following a convention set by “Unix time”.

```
console.log(new Date(2013, 11, 14).getTime());
// → 1386975600000
console.log(new Date(1386975600000));
// → Sat Dec 14 2013 00:00:00 GMT+0100 (CET)
```

When the Date constructor is given a single argument, the argument is treated as a millisecond count. You can determine the current millisecond count by creating a new Date object and calling getTime on it, or by using the Date.now function. Date objects provide methods such as getDate, getHours, getFullYear, getMonth, getMinutes, and getSeconds to retrieve their components.

```
function getDate(string) {
  let [_, month, day, year] =
    /^(\d{1,2})-(\d{1,2})-(\d{4})$/.exec(string);
  return new Date(year, month - 1, day);
}
console.log(getDate("1-30-2003"));
// → Thu Jan 30 2003 00:00:00 GMT+0100 (CET)
```

## Word and string boundaries

You can ensure that the match spans the entire string by adding the markers ^ and $. The caret matches the beginning of the input string, while the dollar sign matches the end. Therefore, /^\d+$/ matches a string consisting entirely of one or more digits, /^!/ matches any string that begins with an exclamation mark, and /x^/ matches no string. If you want the match to begin and end on a word boundary, use the marker \b. A word boundary is the position where a word character (\w) is on one side and a nonword character is on the other.

```
console.log(/cat/.test("concatenate"));
// → true
console.log(/\bcat\b/.test("concatenate"));
// → false
```

## Choice patterns

If you want to know whether a piece of text contains a number followed by one of the words chicken, pig, or cow, you could write three regular expressions and test them. We use the pipe character (|) to denote a choice between the pattern on its left and the pattern on its right:

```
let animalCount = /\b\d+ (pig|cow|chicken)s?\b/;
console.log(animalCount.test("15 pigs"));
// → true
console.log(animalCount.test("15 pigchickens"));
// → false
```

## The replace method

String values have a replace method that can be used to replace part of the string with another string.

```
console.log("papa".replace("p", "m"));
// → mapa
```

The first argument can also be a regular expression, and the first match of the regular expression is replaced. If you add a g option (for global) to the expression, every match in the string will be replaced, not just the first.

```
console.log("Borobudur".replace(/[ou]/, "a"));
// → Barobudur
console.log("Borobudur".replace(/[ou]/g, "a"));
// → Barabadar
```

The real power of using regular expressions with replace is that we can refer to matched groups in the replacement string. For example, you have a large string containing people's names, one per line, in the format Lastname, Firstname. You can swap these names, remove the comma, and get a Firstname Lastname format with the following code:

```
console.log(
"Liskov, Barbara\nMcCarthy, John\nWadler, Philip"
.replace(/(\w+), (\w+)/g, "$2 $1"));
// → Barbara Liskov
// John McCarthy
// Philip Wadler
```

The $1 and $2 in the replacement string refer to the parenthesized groups in the pattern. $1 is replaced by the text that matched against the first group, $2 by the second, and so on up to $9. The whole match can be referred to with $&. You can pass a function instead of a string as the second argument. For each replacement, the function is called with the matched groups as arguments, and its return value is inserted into the new string.

```
let s = "the cia and fbi";
console.log(s.replace(/\b(fbi|cia)\b/g,
str => str.toUpperCase()));
// → the CIA and FBI
```

Here’s a more interesting one:

```
let stock = "1 lemon, 2 cabbages, and 101 eggs";
function minusOne(match, amount, unit) {
  amount = Number(amount) - 1;
  if (amount === 1) { // only one left, remove the 's'
    unit = unit.slice(0, unit.length - 1);
  } else if (amount === 0) {
    amount = "no";
  }
  return amount + " " + unit;
}
console.log(stock.replace(/(\d+) (\w+)/g, minusOne));
// → no lemon, 1 cabbage, and 100 eggs
```

## Greed

You can use replace to write a function that removes all comments from a piece of JavaScript code.

```
function stripComments(code) {
  return code.replace(/\/\/.*|\/\*[^]*\*\//g, "");
}
console.log(stripComments("1 + /* 2 */3"));
// → 1 + 3
console.log(stripComments("x = 10; // ten!"));
// → x = 10;
console.log(stripComments("1 /* a */+/* b */ 1"));
// → 1 1
```

The part before the or operator matches two slash characters followed by any number of non-newline characters. Using [^] matches any character, including newlines. Repetition operators (+, *, and {}) are greedy, meaning they match as much as they can and then backtrack. If a question mark is placed after them (+?, *?, ??, {}?), they become lazy and start matching as little as possible. The lazy star finds the smallest stretch of characters that brings us to a */. It matches a single block comment.

```
function stripComments(code) {
  return code.replace(/\/\*[\s\S]*?\*\/|\/\/.*?/g, "");
}
console.log(stripComments("1 /* a */+/* b */ 1"));
// → 1 + 1
```

## Dynamically creating RegExp objects

There are cases where you might not know the exact pattern you need to match against when writing your code. If you want to find the user's name in a piece of text and wrap it in underscore characters to make it stand out, you can build a string and use the RegExp constructor. For example:

```
let name = "harry";
let text = "Harry is a suspicious character.";
let regexp = new RegExp("\\b(" + name + ")\\b", "gi");
console.log(text.replace(regexp, "_$1_"));
// → _Harry_ is a suspicious character.
```

To build the \b boundary markers, use two backslashes, because you are writing them in a normal string. The second argument to the RegExp constructor contains the options for the regular expression. "gi" means global and case-insensitive.

```
let name = "dea+hl[|]rd";
let text = "This dea+hl[|]rd guy is super annoying.";
let escaped = name.replace(/[\.\[.+*?{}()|^$]/g, "\\$&");
let regexp = new RegExp("\\b" + escaped + "\\b", "gi");
console.log(text.replace(regexp, "_$&_"));
// → This _dea+hl[|]rd_ guy is super annoying.
```

## The search method

You cannot pass a regular expression to the indexOf method on strings. There is another method, search, which does expect a regular expression. Like indexOf, it returns the first index where the expression occurs, or -1 if it does not occur.

```
console.log(" word".search(/\S/));
// → 2
console.log("".search(/\S/));
// → -1
```

## The lastIndex property

The exec method does not provide a convenient way to start searching from a given position in the string. Regular expression objects have properties. One of the properties is called source, and it contains the string that created the expression. lastIndex is another property, and it controls, in some limited circumstances, where the next match will begin. The regular expression must have the global (g) or sticky (y) option enabled, and the match must happen through the exec method. For example:

```
let pattern = /y/g;
pattern.lastIndex = 3;
let match = pattern.exec("xyzzyy");
console.log(match.index);
// → 4
console.log(pattern.lastIndex);
```
