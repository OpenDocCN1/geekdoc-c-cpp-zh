```
function noisy(f) {
```

# Filtering arrays

To search for the script in a data set, use the following function. This function helps to filter out element that failed a test in an array.

```
function filter(array, test) {
  let passed = [];
  for (let element of array) {
    if (test(element)) {
      passed.push(element);
    }
  }
}
```
