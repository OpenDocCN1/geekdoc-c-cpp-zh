## Mutability

We have discussed different values such as Booleans, strings, and numbers whose values are difficult to change, although they can be combined to acquire new values from them. Objects are different from values, and they enable property changing; they can have different content for a single object value at different times. When there are two numbers, 120 and 120, they are considered the same, and there is a similarity between setting two references to one object and possessing two separate objects containing the same properties. Check the code below:

```javascript
let object1 = {value: 10};
let object2 = object1;
let object3 = {value: 10};
console.log(object1 == object2);
// → true
console.log(object1 == object3);
// → false
object1.value = 15;
console.log(object2.value);
// → 15
console.log(object3.value);
// → 10
```

The object1 and object2 bindings hold the same object, and that is why altering object1 influences the value of object2. They are identical by nature. The binding object3 points to a separate object that consists of similar properties as object1 but has a different identity. Bindings can be constant or changeable, but this does not influence their values. A const binding to an object cannot be reassigned and continually points to the same object. It is the object contents that can be changed.

```javascript
const score = {visitors: 0, home: 0};
// This is okay
score.visitors = 1;
// This isn't allowed
score = {visitors: 1, home: 1};
```

When JavaScript’s == operator is used to differentiate objects, it uses the identity to perform that task. It will return true if the objects contain the same value. Comparing several objects will return false, even if their properties are similar.

Correlation is a measure of dependence between statistical variables. They are known as values that span from -1 to 1. An unrelated variable is called a zero correlation. A correlation of 1 signifies that the two are related. Negative means that the variables are related perfectly but opposite to each other; one is true, and the other is false. To calculate the evaluation of the correlation between two Boolean values, utilize the phi coefficient (φ). This formula input is a frequency table holding the number of times it observes several combinations of the variables. The formula's output will be a number between -1 and 1. That is the best definition of a correlation.

Let us use the event of eating pizza as an example and insert it into a frequency table whereby every number signifies the total number of times we used the combination in our measurements. We name the table n, and we calculate φ with the formula below:

```text
φ =
(n11 n00 − n10 n01) / √(n1• n0• n•1 n•0)
```

The notation n01 signifies the number of measurements where the first variable turns false (0), and the second variable becomes true (1). In the pizza table, n01 is 9.

The value n1• indicates the sum of all measurements where the first variable turns true, that is 5 in the table example. Likewise, n•0 suggests the quantity of the measurements where the second variable becomes false. In the pizza table, the top of the division line would be 1×76−4×9 = 40, and the bottom part below would be the square root of 5×85×10×80, or √340000. The result will be φ ≈ 0.069, which is tiny. Therefore, eating pizza had no impact on transformations.

## Computing correlation

JavaScript enables the representation of a two-by-two table with four-element arrays ([76, 9, 4, 1]). Other representations, such as an array holding two two-element arrays ([[76, 9], [4, 1]]) or an object containing property names such as "11" and "01", with the latter representation producing the expression that accesses the table short. We will explain the indices to the array as two-bit binary numbers, where the most significant digit refers to the squirrel variable while the least significant refers to the event table. For instance, the binary number 10 refers to the "Jacques did turn into a squirrel" case but the events didn’t appear. It occurred four times and binary 10 is 2 in decimal, the number is stored at index 2 of the array. This function calculates the φ coefficient from an array:

```javascript
function phi(table) {
  return (table[3] * table[0] - table[2] * table[1]) /
    Math.sqrt((table[2] + table[3]) *
    (table[0] + table[1]) *
    (table[1] + table[3]) *
    (table[0] + table[2]));
}

console.log(phi([76, 9, 4, 1]));
// → 0.068599434
```

The table requires two fields to acquire counts like n1• because the total number of rows and columns are stored indirectly in our data layout. If you want to extract a two-by-two table for a particular event, you must loop across all the entries and calculate the number of times the event happened to the squirrel transformations.

```javascript
function tableFor(event, journal) {
  let table = [0, 0, 0, 0];
  for (let i = 0; i < journal.length; i++) {
    let entry = journal[i], index = 0;
    if (entry.events.includes(event)) index += 1;
    if (entry.squirrel) index += 2;
    table[index] += 1;
  }
  return table;
}
```
