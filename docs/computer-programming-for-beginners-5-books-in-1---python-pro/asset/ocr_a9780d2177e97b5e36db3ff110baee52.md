# SQL UNION Command

Two or more SQL select statements’ result sets can be joined with the ‘UNION’ command. The syntax of usage is as described below:

```
SELECT column-1, column-2… column-n
FROM data_table-1
UNION
SELECT column-1, column-2… column-n
FROM data_table-2
```
