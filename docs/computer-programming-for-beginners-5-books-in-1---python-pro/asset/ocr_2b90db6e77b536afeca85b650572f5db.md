# ***Mega ADK***

This is based on the Mega2560 Arduino board, with incredible memory capacity and a lot of availability for input and output. The difference between the Mega2560 and the Mega ADK is that the Mega ADK is compatible specifically with Android technologies, such as Samsung phones and tablets, Asus technologies, and other non-iOS, non-Windows, mobile devices that use Android.
