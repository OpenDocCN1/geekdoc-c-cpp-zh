Arduino board can be programmed to light or fade a LED etc. The syntax used in Arduino programming is similar to C++. If you are good at C++, then programming in Arduino will be easy for you. The variables in Arduino are initialized in the setup() function. The loop() section has the block to be run repeatedly. When working with Arduino pins, you must specify the pin you need to work with. The pins are normally identified with numbers as each has a unique number. After getting the board, you have to setup Arduino IDE on your computer. This is where you will be writing your Arduino code before uploading it to the board. Arduino code is commonly known as a sketch. You must get a source of power. However, some board types must be configured to allow power to be drawn from a computer. The effect of a sketch on the board will be seen after uploading it to the board, in which one has to click the Upload button.
