# ### Dictionaries

This type of data sequence is similar to the yellow pages. As long as you have a name to search for, you are going to find his phone number and other information. In this example, the name of the person is called a key and the data comes in the form of values. The key itself isn’t mutable, which means it can only be a string, a tuple, or a number, while the values can be any kind of data. Dictionaries, however, are mutable structures. This means that you can edit a number of values. This includes adding and removing them, as well as changing keys.
