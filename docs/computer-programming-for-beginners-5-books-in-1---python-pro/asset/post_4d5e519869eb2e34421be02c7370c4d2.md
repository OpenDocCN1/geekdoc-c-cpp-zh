
```
function noisy(f) {
  return (...args) => {
    console.log("calling with", args);
    let result = f(...args);
    console.log("called with", args, ", returned", result);
    return result;
  };
}
noisy(Math.min)(3, 2, 1);
// → calling with [3, 2, 1]
// → called with [3, 2, 1], returned 1
```

You can also write functions that produce new kinds of control flow.

```
function unless(test, then) {
  if (!test) then();
}
```

```
repeat(3, n => {
  unless(n % 2 == 1, () => {
    console.log(n, "is even");
  });
});
// → 0 is even
// → 2 is even
```

There is a built-in array method, forEach, that produces a loop similar to the for/of loop as a higher-order function.

```
["A", "B"].forEach(l => console.log(l));
// → A
// → B
```

## Filtering arrays

To search for scripts in a data set, use the following function. This function helps to filter out elements that fail a test in an array.

```
function filter(array, test) {
  let passed = [];
  for (let element of array) {
    if (test(element)) {
      passed.push(element);
    }
  }
  return passed;
}
console.log(filter(SCRIPTS, script => script.living));
// → [{name: "Adlam", …}, …]
```

This function uses the argument called test, a function value, to fill a gap in the computation. It determines which elements to keep.

## Transforming with map

The map method changes an array by applying a function to each and every one of its elements and creating a new array from the returned values. The new array has the same length as the input array, but its content is transformed by the function.

```
function map(array, transform) {
  let mapped = [];
  for (let element of array) {
    mapped.push(transform(element));
  }
  return mapped;
}
```

```
let rtlScripts = SCRIPTS.filter(s => s.direction == "rtl");
console.log(map(rtlScripts, s => s.name));
// → ["Adlam", "Arabic", "Imperial Aramaic", …]
```

Like forEach and filter.

## Summarizing with reduce

When you add up numbers, begin with zero and add each element to the sum. The parameters to reduce are a combining function and a start value. This function is a little less straightforward than filter and map. It is shown below:

```
function reduce(array, combine, start) {
  let current = start;
  for (let element of array) {
    current = combine(current, element);
  }
  return current;
}
```

```
console.log(reduce([0, 1, 2, 3, 4], (a, b) => a + b, 0));
// → 10
```

This function is similar to the standard array method reduce and provides more convenience.

```
console.log([1, 2, 3, 4].reduce((a, b) => a + b));
// → 10
```

If you want to use reduce to find the script with the most characters, write it like this:

```
function characterCount(script) {
  return script.ranges.reduce((count, [from, to]) => {
    return count + (to - from);
  }, 0);
}
console.log(SCRIPTS.reduce((a, b) => {
  return characterCount(a) < characterCount(b) ? b : a;
}));
// → {name: "Han", …}
```

## Composability

Take some time to think about how long our code would have been without the higher-order functions.

```
let biggest = null;
for (let script of SCRIPTS) {
  if (biggest == null ||
      characterCount(biggest) < characterCount(script)) {
    biggest = script;
  }
}
console.log(biggest);
// → {name: "Han", …}
```

You can use higher-order functions when you want to compose operations. For instance, here is a line of code that finds the average year of origin for living and dead scripts in the data set.

```
function average(array) {
  return array.reduce((a, b) => a + b) / array.length;
}
console.log(Math.round(average(
  SCRIPTS.filter(s => s.living).map(s => s.year))));
// → 1165
console.log(Math.round(average(
  SCRIPTS.filter(s => !s.living).map(s => s.year))));
// → 204
```

This code shows that the dead scripts are, on average, older than the living ones.

Let's start with all the scripts, filter out the dead (or living), extract their years, average them, and round the result. You can also write these calculations as one big loop:

```
let total = 0, count = 0;
for (let script of SCRIPTS) {
  if (script.living) {
    total += script.year;
    count += 1;
  }
}
console.log(Math.round(total / count));
// → 1165
```

Our two examples are not identical: the first creates new arrays when applying map and filter, while the second calculates numbers only.

## Strings and character codes

One of the significant uses of the data set is to find out what script a block of text is using. Below is a program that performs that task.

Every script contains an array of character code ranges related to it. So, if you are given a character code, use this function to search for the equivalent script (if available):

```
function characterScript(code) {
  for (let script of SCRIPTS) {
    if (script.ranges.some(([from, to]) => {
      return code >= from && code < to;
    })) {
      return script;
    }
  }
  return null;
}
console.log(characterScript(121));
// → {name: "Latin", ...}
```

The some method is another higher-order function. It takes a test function and determines whether that function returns true for any of the elements in the array.

There are some operations on JavaScript strings, such as getting their length using the length property and accessing their contents through square brackets.

```
// Two emoji characters, horse and shoe
let horseShoe = "🐴👞";
console.log(horseShoe.length);
// → 4
console.log(horseShoe[0]);
// → (Invalid half-character)
console.log(horseShoe.charCodeAt(0));
// → 55357 (Code of the half-character)
console.log(horseShoe.codePointAt(0));
// → 128052 (Actual code for horse emoji)
```

JavaScript's charCodeAt method gives you a code unit, not a full character code. The codePointAt method, added later, does give a full Unicode character. It is used to take characters from a string, although the argument sent to codePointAt remains an index into the sequence of code units. If you use a for/of loop to loop across a string, it produces real characters and not code units.

```
let roseDragon = "🌹🐉";
for (let char of roseDragon) {
  console.log(char);
}
// → 🌹
// → 🐉
```

## Recognizing text

You have the characterScript function and a way to loop across characters correctly; now calculate the characters each script owns. The following counting abstraction is used here:

```
function countBy(items, groupName) {
  let counts = [];
  for (let item of items) {
    let name = groupName(item);
    let known = counts.findIndex(c => c.name == name);
    if (known == -1) {
      counts.push({name, count: 1});
    } else {
      counts[known].count++;
    }
  }
  return counts;
}
console.log(countBy([0, 1, 2, 3, 4, 5], n => n > 2));
// → [{name: false, count: 3}, {name: true, count: 3}]
```

The countBy function expects a collection (a group of numbers, elements, or anything that you can loop over with for/of) and a function that calculates a group name for a specified element. It returns a list of objects. Each of the objects names a group and determines the number of elements contained in the group. The findIndex method is similar to indexOf. This method is used to search for the first value for which the stated function returns true and returns -1 when no such element is found. You can use countBy to determine which script is used in a block of text.

```
function textScripts(text) {
  let scripts = countBy(text, char => {
    let script = characterScript(char.codePointAt(0));
    return script ? script.name : "none";
  }).filter(({name}) => name != "none");
  let total = scripts.reduce((n, {count}) => n + count, 0);
  if (total == 0) return "No scripts found";
  return scripts.map(({name, count}) => {
    return `${Math.round(count * 100 / total)}% ${name}`;
  }).join(", ");
}
console.log(textScripts("英国的狗说'woof', 俄罗斯的狗说'тяв'"));
// → 61% Han, 22% Latin, 17% Cyrillic
```

The function counts characters by name through the use of characterScript to attach a name, falling back to the string "none" for characters without any script. If you want to calculate percentages, you need to determine the total amount of characters belonging to a script, which the reduce method can do. If it finds zero characters, the function returns the string "No scripts found".

## Summary

Being able to pass function values to other functions is an essential aspect of JavaScript. It enables writing functions that model computations with “gaps” between them. The code that calls these functions can fill in the gaps by giving function values. Arrays provide several important higher-order methods. Use forEach to loop across elements within an array. Use the filter method to return a new array that contains elements that pass the predicate function. Transform an array by applying a function to each item using map. Use reduce to combine every element of an array into a single value.
