## 示例 4：使用电位器控制光量（编码）

```cpp
// create new file from the Arduino IDE and write the following code:

const int sensorPin = A0;

const int LedPin = 13;

int sensorValue;

void setup()
{
  pinMode(LedPin, OUTPUT);
}

void loop()
{
  sensorValue = analogRead(sensorPin);

  digitalWrite(LedPin, HIGH);
  delay(sensorValue);

  digitalWrite(LedPin, LOW);
  delay(sensorValue);
}
```

*analogRead(pin number).* 此函数将电压作为模拟信号读取（微控制器可以测量从 4.8 毫伏到 5 伏的电压），并且它还会将这些值转换为从 0 到 1,024 的数字值。这种转换称为 *模数转换（ADC）。*

例如：

如果输入到 A0 的电压等于以下值：

| 输入到 A0 的电压 | 数字值 |
| --- | --- |
| 4.8 毫伏 | 1 |
| 48 毫伏 | 10 |
| 480 毫伏 | 100 |
| 1 伏 | 208.33 |
| 2 伏 | 416.66 |
| 5 伏 | 1024 |

```cpp
sensorValue = analogRead(sensorPin);
```

- 在此语句中，微控制器将把传感器读数的值存储在 sensor value 变量中，然后微控制器将根据此变量（sensorValue）的值打开/关闭 LED 一段时间。
- 在此示例中，我们使用了可变电阻器，因此我们可以改变电阻值。

## 示例 6：带 PWM 的 LED（编码）

```cpp
// open the Arduino IDE and select new file then write the following code:

const int ledPin = 11;

int i = 0;

void setup()
{
  pinMode(ledPin, OUTPUT);
}

void loop()
{
  for (i = 0; i < 255; i++) // LED will be lighter
  {
    analogWrite(ledPin, i);
    delay(10);
  }

  for (i = 255; i > 0; i--) // LED will be darker
  {
    analogWrite(ledPin, i);
    delay(10);
  }
}
```

```cpp
for (i = 0; i < 255; i++)
```

- `i = 0` → 初始值
- `i < 255` → 设置你的条件
- `i++` → 是迭代器；在此示例中它将加 1
- `i++` → `i = i + 1`

## 示例 7：带串行接口的温度传感器（编码）

```cpp
const int sensorPin = A0;

int reading;

float voltage;

float temperatureC;

void setup()
{
  Serial.begin(9600);
}

void loop()
{
  reading = analogRead(sensorPin);
  voltage = reading * 5.0 / 1024;
  Serial.print(voltage);
  Serial.println(" volts");

  temperatureC = (voltage - 0.5) * 100;
  Serial.println("Temperature is: ");
  Serial.print(temperatureC);
  Serial.println(" degrees C");

  delay(1000);
}
```
