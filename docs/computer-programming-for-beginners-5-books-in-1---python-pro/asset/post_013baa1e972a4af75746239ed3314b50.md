
For the expression `true || X`, the value will be true and X will not be considered. The same rule applies to `false && X`, where the left side is false and X will be overlooked. You can call this process short-circuit evaluation.

### Bindings

JavaScript uses variable bindings to hold values, for instance:

```javascript

```

`let` is the keyword in that statement, and it means that the statement will specify a binding, with the binding name and value attached using the `=` operator and an expression. Use a defined binding as an expression; the expression contains the binding value. Here is an example below:

```javascript
let ten = 10;
console.log(ten * ten);
// → 100
```

The `=` operator is used on existing bindings to remove the binding from a set value and point it to a new one.

```javascript
let mood = "light";

// → light
mood = "dark";
console.log(mood);

```

Defining a binding without assigning a value will result in nothing to hold. Therefore, asking for the value of a binding produces the `undefined` value. You can define multiple bindings with a single statement separated by commas.

```javascript

```

Use the `var` and `const` words to declare bindings similarly:

```javascript

```

The word `const` means constant. It describes a constant binding, which points to its set value for its lifetime. These words are often used to assign a name to a value to enable easy reference later on.
