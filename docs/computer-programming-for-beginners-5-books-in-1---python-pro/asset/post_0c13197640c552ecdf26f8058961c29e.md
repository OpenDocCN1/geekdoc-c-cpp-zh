## Destructuring

Let’s use the phi function a little bit.

```javascript
function phi(table) {
  return (table[3] * table[0] - table[2] * table[1]) /
    Math.sqrt((table[2] + table[3]) *
              (table[0] + table[1]) *
              (table[1] + table[3]) *
              (table[0] + table[2]));
}
```

One of the reasons this function is hard to read is that there is a binding pointing to the array, but we want bindings for the elements of the array, that is, let n00 = table[0] and so on. Fortunately, there is a better way to do this in JavaScript.

```javascript
function phi([n00, n01, n10, n11]) {
  return (n11 * n00 - n10 * n01) /
    Math.sqrt((n10 + n11) * (n00 + n01) *
              (n01 + n11) * (n00 + n10));
}
```

This also works for bindings created with let, var, or const. If you know the value you are binding is an array, you can use square brackets to look inside the value and bind its contents. Use the same idea for objects, using braces instead of square brackets.

```javascript
let {name} = {name: "Faraji", age: 23};
console.log(name);
// → Faraji
```

## JSON

JSON stands for JavaScript Object Notation and is used as a data storage and communication format on the web. JSON is very similar to JavaScript in the way it writes arrays and objects, although there are restrictions. Its property names must be enclosed in double quotes, and it allows only simple data expressions—no bindings, function calls, or comments.

Here is a sample of a journal entry represented as JSON data:

```json
{
  "squirrel": false,
  "events": ["work", "touched tree", "pizza", "running"]
}
```

JavaScript provides the functions JSON.stringify and JSON.parse to transform data to and from this format. JSON.stringify takes a JavaScript value and returns a JSON-encoded string, while JSON.parse takes a string and converts it back to the value it encodes.

```javascript
let string = JSON.stringify({squirrel: false,
events: ["weekend"]});
console.log(string);
// → {"squirrel":false,"events":["weekend"]}
console.log(JSON.parse(string).events);
// → ["weekend"]
```

### Abstraction

In the context of programming, such vocabularies are usually called abstractions. Abstraction hides details and gives us the ability to talk about problems at a higher level. Let’s compare two recipes for pea soup.

First:

Per person, place 1 cup of dried peas in a container. Add enough water to cover the peas and let them soak for about 12 hours. Remove them from the water and place them in a cooking pot with 4 cups of water per person. Let it boil for about two hours. Half an onion per person, sliced with a knife, is added to the peas and left to cook for 10 minutes.

Then the second recipe:

Per person: half an onion, a stalk of celery, 1 cup dried split peas, and a carrot. Soak the peas in water for about 12 hours. Boil them for about 2 hours in 4 cups of water, then slice the vegetables and add them. Cook for 10 minutes.

The computer performs tasks one by one, in a blind, low-level manner; abstractions let us work with high-level concepts.

### Abstracting repetition

Plain functions are good ways to build abstractions. It is common for a program to repeat a particular action a specific number of times. You can accomplish that with a loop like this:

```javascript
for (let i = 0; i < 10; i++) {
  console.log(i);
}
```

Here we write a function that calls console.log n times.

```javascript
function repeatLog(n) {
  for (let i = 0; i < n; i++) {
    console.log(i);
  }
}
```

If you want to perform a task other than logging numbers, you can pass an action as a function value.

```javascript
function repeat(n, action) {
  for (let i = 0; i < n; i++) {
    action(i);
  }
}

repeat(3, console.log);
// → 0
// → 1
// → 2
```

Sometimes you don’t need to pass in a predefined function to repeat in a loop; create a function value as an alternative:

```javascript
let labels = [];
repeat(5, i => {
  labels.push(`Unit ${i + 1}`);
});
console.log(labels);
// → ["Unit 1", "Unit 2", "Unit 3", "Unit 4", "Unit 5"]
```

This approach looks similar to a loop—it describes the kind of loop and then provides a body. However, the body is written as a function value enclosed in the parentheses of the call to repeat.

### Higher-order functions

Higher-order functions are functions that work on other functions, either by taking them as arguments or by returning them. This type of function enables us to abstract over actions. For instance, you can have a function that produces functions:

```javascript
function greaterThan(n) {
  return m => m > n;
}

let greaterThan10 = greaterThan(10);
console.log(greaterThan10(11));
// → true
```

You can also have functions that transform other functions.
