Create DATABASE store;

If this works, you'll get an outcome like this one:

Query OK, 1 row influenced (0.03 sec)

Database names can't contain any spaces. On Unix servers such as Linux and Mac OS X, database names are case-sensitive as well.

To begin using this database, type:

Use store;

You will get the outcome:

Database changed.

Believing you've done everything accurately, you'll be set up with new information, and it will be chosen for use. Making tables to store information is an imperative idea, so that is the place we're heading!
