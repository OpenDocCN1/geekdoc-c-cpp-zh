### 关联字符串

关联字符串使用这种新安排来连接你在孤立字段中实际提供的登录数据：

dbtype://username:password@host/database

这种结构可能对你来说来说，因为它从根本上与 Windows 记录连接字符串的格式相同。字符串的第一部分是真正让 PEAR 函数区别于原生 PHP 的地方。`phptype` 字段指定了要连接的数据库类型。

支持的数据库包含了 ibase, msql, mssql, mysql, oci8, odbc, pg 和 sybase。你的 PHP 页面要与不同类型的数据库协同工作，只需要更改 `phptype` 即可！

用户名、密钥和数据库对于原生 PHP 接口来说是显然的。只需要指定关联类型即可。尽管如此，你通常需要指定所有字段。

# 第 12 章：处理表单

HTML 结构提供了一种从客户端向服务器发送重要信息的方法，并在那里进行处理。你将利用你在书中第一部分中学的 PHP 语言来处理和验证表单信息。

我们将从构建一个基础表单开始，并弄如何在客户端提交后获取其字段中的数据。我们将检查可以设置表单以及隐藏属性上的基本控件类型。显然，PHP 代码将与这些组件结合。

表单通过两个阶段的过程工作。表单必须展示给客户端。然后用户输入数据并提交表单。每个表单都有一个目标页面，当客户端提交时会将信息转换。通常，这与最初创建表单的是同一个文档。PHP 代码只需检查是否有客户端数据提交页面请求，以确定该文档是被用来生成表单还是处理其信息。

查找数据库在各种应用中至关重要。无论是查找讨论帖子、用户还是网络博客，它都能让客户端的生活变得简单得多。在数据库级别，还有许多方法来处理查询并返回结果。

## 默认值

在对数据库执行查询操作时，你可能需要在表单中确实设置一些默认值。这是非常有用的，例如在查找价格范围时。客户端通常不希望手动输入属性，这在搜索时会变得简单得多。通常，表单元素的默认值位于 `value` 属性中；另一方面，复选框有一个使用 `checked` 关键字的特殊情况。

## 输入类型

有多种类型的数据，你认为哪种好呢？单选框、复选框、内容、按钮……

通常情况下，对于你可能需要一个文本框。`maxlength` 参数决定了客户端可以填入的最大字符数。
