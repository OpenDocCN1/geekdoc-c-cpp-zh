USE mysql;

## 9.2 管理数据库

现在你已经关联到数据库，可以创建用户、数据库和表了。如果你在托管环境中使用 MySQL 服务器，则不需要创建数据库或客户端账户，因为他们已经为你提供了用户名和数据库名称。

### 创建用户

要创建超出默认首选 root 客户端的用户，请执行 grant 命令。grant 命令的语法如下：

```
GRANT PRIVILEGES ON DATABASE.OBJECTS TO 'username'@'hostname' IDENTIFIED BY 'password';
```

例如：

```
GRANT ALL PRIVILEGES ON .* TO "michele"@localhost" IDENTIFIED BY 'secret';
```

这创建了一个名为 michele 的客户端，它可以从本地访问任何内容。要切换到 michele 客户端，在 mysql 命令提示符处输入：

```

exit

```

此时，从命令行使用新的用户名和密码启动 MySQL。启动 MySQL 时用户名和密的的语法符号为：

```
mysql -h hostname -u username -p password
```

注意 `-p` 和密字之间没有空格。如果你只指定了 `-p` 标志而不带密码，MySQL 会提示你输入密码。如果你不需要让客户端访问其表之外的表，请在 *GRANT PRIVILEGES ON ..* TO “michele” 代码中补充客户端数据库的名称，类似于：

```
GRANT ALL PRIVILEGES ON store.* TO "michele"@localhost" IDENTIFIED BY 'mystery'; 
```

你必须以 root 或具有权限的身份运行此行代码。在此代码中，单词 store 关联到分配权限的数据库名称，你将在接下来的部分创建它。

### 创建 MySQL 数据库

你将创建一个名为 store 的数据库。CREATE DATABASE 命令的功能如下：

```
CREATE DATABASE store;
```

如果执行成功，你将得到类似所示的结果：

Query OK, 1 row influenced (0.03 sec)

数据库名不能包含任何空格。在如 Linux 和 Mac OS X 等 Unix 服务器上，数据库名也是区分大小大小的。

要开始使用此数据库，输入：

Use store;

你将得到结果：

Database changed.

在认为你已经准确完成了所有操作后，你已经准备好了新信息，并且它将被选择用于使用。创建表来存储信息是一个必要的想法，所以这正是我们我们要去的地方！

## 9.3 使用 phpMyAdmin

phpMyAdmin 工具可以通过 http://www.phpadmin.net/ 访问，允许你通过你的 Web 程序控制 MySQL 数据库。所只需要一个安装了 PHP 的 Web 服务器和一个用于控制它的 MySQL 数据库。

要引入 phpMyAdmin，请遵循以下步骤：

- 1. 从主页点击 Downloads（下载）。
2. 下载存档文件，例如 all-languages.tar.gz（Unix 存档）或 all-languages.zip（Windows ZIP 设计）。
3. 解压存档（包括子目录）到 PC 上的目录。
4. 将它们发送到可以执行 PHP 记录的 ISP 账户。或者，如果你在本地安装了 Web 服务器，将它们移动到文档根目录下具有一致名称的目录，例如 myadmin。
5. 为了构建 phpMyAdmin，在 myadmin 目录内创建一个名为 config 的目录。在 Linux 上，执行这些命令来创建目录：

```
mkdir config
chmod +w config
cp config.inc.php config/
```

chmod +w config/config

6. 在你的 Web 程序中，访问 http://localhost/myadmin/setup.php。

你将看到一个如图所示的屏幕。

![](img/8e0a31fe30a159a13fdfed13405b5ed7_120_0.png)

7. 在 Servers（服务器）部分，点击 Add（添加）按钮。设置页面所示。
8. 大部分值可以留空。你需要在“password”字段中输入 root 的密码。
9. 从 Authentication（身份验证）选择“cookie”以限制对 MySQL 的访问。
10. 点击“Add”（添加）。
11. 点击 Configuration（配置）部分的“Save”（保存）以保存你的配置。
12. 将 config.inc.php 复制到 myadmin。
13. 删除 config 目录。
14. 在你的 Web 程序中，访问 http://localhost/myadmin/index.php。

登录页面如图所示。

## 9.4 数据库概念

数据库是数据的库。它们用于管理和控制数据。结构化信息是组织相关数据的方法，我们在第 3-6 章中已经讨论过。结构化数据的类型类型（称为数据结构）包括：

- 文件
- 列表
- 数组
- 记录
- 表

这些基本结构都有许多变体并考虑不同的操作。理解这个想法的简单方法是考虑电话录（电话簿）。每个订阅者的记录包含三个字段（也称为属性或列）：姓名、地址以及电话号码。这些记录通过姓名字段标识，该字段被称为键字段。电话录按姓氏字母顺序排列；查看图 9.9，基于电话录类比的数据库中的独特记录和独特字段。虽然 MySQL 数据库中的信息没有以任何特定顺序存储，但可以进行查询。
