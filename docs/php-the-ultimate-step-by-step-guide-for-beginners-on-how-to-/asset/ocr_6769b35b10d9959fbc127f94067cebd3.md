The do ... while loop takes an expression such as a while statement though it puts it at the end. The syntax it is:

```
do {
code to execute;
} while (expression);
```

This circle is helpful when you need to execute a piece of code at any rate once despite of the expression value. E.g. let’s check to 10 with this loop, as indicated in Illustration 6.15.

Illustration 6.15. Numbering to 10 with do ...

```
<?php
$num = 1;
do {
echo "Number is ".$num.\<br/>";
$num++;
} while ($num <= 10);
echo "Done.";
?>
```
