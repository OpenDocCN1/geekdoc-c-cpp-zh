When expanding classes to override functions in your class that are now defined in the superclass, you can still execute the code from the parent class and after include your own particular functionality. To call the parent class technique before your code, use:

parent::method_from_parent

This calls the parent system in the superclass. You can then add it to your code, as shown in Example 7.18.
