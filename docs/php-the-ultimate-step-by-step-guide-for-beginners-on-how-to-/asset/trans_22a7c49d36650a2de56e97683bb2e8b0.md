
在不经意的情况下调整了一个变量而不知道其结果。这种错误可能极难发现。此外，当我们详细检查函数时，你会发现可以在调用函数时可以向它们发送值，并在它们完成后从它们获取返回值。你不需要使用全局变量。

然而，万一你需要在特定函数中使用变量，且不想在每次函数结束时丢失该值，你可能倾向于不使用全局变量，而是使用静态变量。

- 静态变量

静态变量使得变量在函数结束时不会被销毁。每当你调用该函数时，你都可以再次利用该静态值，它的值将与最后一次作为函数一部分使用时相同。考虑此点的最简单方法是将该变量简单地视为全局变量。`$age` 的估值在每次调用 `birthday` 函数时都会被保留。该值将一直保留，直到程序结束。由于它被声明为 `static`，因此值会被保留。通过这种方式，我们讨论了两种变量，但还有一种需要检查，即超全局变量。

- 超全局变量

PHP 使用一种称为“超全局”的奇有变量来提供有关 PHP 脚本运行环境的数据。这些变量不需要声明为全局变量。它们通常是可访问的，并且提供了超出脚本代码本身的重要数据，例如来自用户输入的值。

自 PHP 4.01 以来，超全局变量被称为数组。数组是值的唯一集合，我们将在后面的章节中讨论它们。更早期的全局变量（如以 `$HTTP_*` 开头的但未成组的变量）仍然存在，但明确不建议使用它们，因为它们已经被弃用了。

# 第 6 章：PHP 决策

在最后一部分，你已经开始学习使用 PHP 编程和一些基础知识。现在，是增加你对 PHP 的熟悉程度、学习和知识了。我们将从表达式和语句开始。

## 6.1 表达式

代码中有几个你必须理解的构建模块：语句、表达式和操作符。语句是执行任务的代码。语句由表达式和运算符组成。表达式是评估一个值的代码片段。值可以是数字、内容字符串或布尔值（Boolean）。

运算符是以后某种方式跟在表达式后面的代码组件。例如，一个减号（–）可以用于告诉计算机在减去之前的表达式值后，减少该表达式的值。例如：

```
$account_balance=$credits-$debits;
```

关于表达式最重要的一点是利用运算符将其合并为复合表达式和语句的方法。通过这种方式，我们将查看用于将表达式转换为更复杂的表达式和语句的运算符。

最简单的表达式类型是字面量（literal）或变量。字面量评估为其本身。

字面量的示例包括数字、字符串和常量。变量评估为分配给它的值。

尽管字面量或变量可能是合法的表达式，但它们本身不执行任何操作。你需要通过运算符将它们连接起来让表达式执行操作，例如数学运算或任务。运算符通过在可以评估的基础表达式之间建立连接，将表达式组合成更复杂的表达式。例如，如果你需要建立的连接是两个数值属性的总和，你将编写 `3 + 4`。数字 3 和 4 分别是实质表达式。包含 `3 + 4` 也是一个合法的表达式，在这种情况下，它的值恰好是 7。加号 (+) 是运算符。它两边的数字是它的参数，或操作数（operands）。参数或操作数是运算符作用的对象；例如，一个参数或操作数可能是妻子要求去洗洗碗机的指令，而丈夫执行了洗洗碗机。不同的运算符具有不同类型和数量的操作数。运算符也可以被重载，这意味着它们在不同的语境下执行不同的事情。

你可能会从此推推出通过运算符关联的两个或多个表达式被称为一个表达式。你是的，因为运算符构成了复杂的表达式。你拥有的子表达式和运算符越多，表达式就越详细越复杂。无论如何，只要它的长度可以赋予一个值，它仍然是一个表达式。

当表达式和运算符汇在一起交付一段真正执行操作的代码时，你就有一个语句。

运算符记录在 http://www.php.net/manual/en/language.operators.php 上。我们将讨论一些运算符，以便你尽可能快地开始使用 PHP。目前我们只浅浅地过一下。除了其主要功能外，每个运算符都有四个基本属性：

- 运算符结合性（associativity）
- 操作数数量
- 优先级（Order of precedence）
- 操作数类型

关于表达式，真的没有更多可以看到的，除了如何使用运算符将它们汇成复合表达式和语句。接下来我们将讨论用于将表达式转换为更复杂的表达式和语句的运算符。

## 6.2 运算符概念

PHP 有许多运算符，包括：

- 算术运算符（Arithmetic）
- 数组运算符（Array）
- 赋值运算符（Assignment）
- 位运算符（Bitwise）
- 比较运算符（Comparison）
- 递增递减运算符（Incrementing/decrementing）
- 逻辑运算符（Logical）
- 字符串运算符（String）

运算符记录在 http://www.php.net/manual/en/language.operators.php 上。我们将讨论一些运算符，以便你尽可能快地开始使用 PHP。目前我们只浅浅地过一下。最简单的选择是从操作数开始。

### 1. 操作数数量

运算符具有不同数量的操作数。许多运算符用于将两个表达式连接成更复杂的表达式；这些被称为二元运算符。运算符包括乘法、减法、加法和除法。

某些运算符一个操作数；这些被称为一元运算符。考虑负运算符 (-) 将数值乘以 -1。第 3 章描述的递增和递减运算符也是一元运算符。

三元运算符接受三个操作数。稍后讨论条件判断时的简写语句接受三个操作数。

### 2. 操作数类型

你应该意识到运算符工作时期的操作数类型，因为某些运算符预期其操作数是特定的数据类型。

PHP 试图通过将操作数转换为运算符预期的数据类型来简化你的工作。然而，某些情况下，自动转换是不可能的。

算术运算符是你应该留心类型的一个例子。它们只接受数字作为操作数。例如，当你尝试乘以两个字符串时，PHP 可以将字符串转换为数字。虽然 "Becker" * "Furniture" 不是合法的表达式，但它返回 0。然而，一个没有错误的转换表达式是 "70" * "80"。这导致了 5600。
