# ## 2.1 Testing Page Security

To test page security, try refreshing home.php and click on logout. Now try clicking on the back arrow of your program and see what happens:

![](bbox=[0.318, 0.163, 0.682, 0.193])

As it should be clear, it doesn’t guide you to home.php because you are logged-out. Then for the second test, attempt physically inputting the location localhost/MyFirstWebsite/home.php. The same case ought to happen as well. Since were logged-out, even a manual info of the location doesn’t get to an approved page. What we have done is a simple security component in which we divert unapproved clients to an open page.

Now try signing in again and you should go back to home.php.
