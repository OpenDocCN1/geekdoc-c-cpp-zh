## 参数

参数

在调用函数时，参数提供了一种向函数传递数据的有效方法，而无需过度担心变量的作用域。在 PHP 中，你不需要描述参数持有什么类型的信息——只需要指定参数的名称即可。

接收参数的函数示例是 `strtolower`，它能将你的字符串“Hi world!”转换为小写。它接收一个类型为字符串的参数，该数据类型在第 3 章中描述。此外，还有另一个名为 `strtoupper` 的函数，它能将你字符串中的所有字符转换为大写字母，如示例 7.4 所示。

示例 7.4. 在接收参数的另一个函数内部利用字符串大小写函数

```php
<?php
// 字符串大写函数 underline($str)
{
    // 首先，将所有字符转换为小写
    $str = strtolower($str);
    // 第二，将第一个字符转换为大写
    $str[0] = strtoupper($str[0]);$str[0] 获取字符串中的第一个字符
    echo $str;
}
capitalize("hEllo WoRld!");
?>
```

案例 7.4 产生如下结果：

# Hi world!

在函数内部 `echo` 的 `$str` 值，是因为你没有指定任何从函数获取该值的方法。如上所述，`$str[0]` 获取字符串中的第一个字符。

PHP 不需要你描述一个函数是否真的返回一个值，或者它返回什么类型的数据。

参数同样可以包含得默认值。有了默认值，你实际上不需要为函数传递任何信息，它就会设置默认值。我们将你的大写函数改为一个默认值，允许你将每个单词的首字母大写，或者仅仅将整个句子大写如何？我们将在示例 7.5 中这样做。

图 7.5. 创建一个带有默认参数的大写函数

```php
<?php
// 字符串或仅每个单词首字母大写函数 underline($str,$each=TRUE) {
    // 首先，将所有字符转换为小写或非第一个单词的字母可能会保持大写

    $str = strtolower($str);
    if ($each === TRUE) {
        $str = ucwords ($str);
    } else {
        $str = strtoupper($str);
    }
    echo("$str <br>");
}
capitalize("hEllo WoRld!");
echo("Now do the same with the echo parameter set to FALSE.<br>");
capitalize("hEllo WoRld",FALSE);
?>
```

其结果如下所示：

Hello World!

Now do the same with the echo parameter set to FALSE

HELLO WORLD!

## 参数引用

当你向函数传递一个查询时，函数内部会创建一个本地副本来存储该值。对该值进行的任何更改只会影响函数中的变量本地副本，而不影响参数的源。你可以通过定义引用参数来定义修改源变量的参数。

引用参数在函数定义的参数之前直接放置一个安培符号 (&) 来定义引用。我们应该修改示例 7.5 中的 `capitalize` 函数，使其接收一个用于大写字符串的引用变量，如示例 7.6 所示。

图 7.6 修改 capitalize ( ) 以接收引用参数

```php
<?php
function capitalize ( &$str, $each=TRUE ) {
    // 首先，将所有字符转换为小写
    $str = strtolower($str);
    if ($each === TRUE) {
        $str = ucwords($str);
    } else {
        $str[0] = strtoupper($str[0]);
    }
}
$str = "Hi WoRld!";
underwrite( $str );
echo $str;
?>
```

示例 7.8 产生以下结果：

Hello World!

由于 `capitalize` 将 `$str` 参数定义为引用参数，因此在执行时，到源变量的连接发送到了函数。函数基本上访问并修改了源变量。如果该变量没有声明为引用，则会显示“hEllo World!”的初始估计。

## 包含和引入 PHP 文件

为了让你的代码更易读，你可以将函数放在不同的文件中。

从互联网下载的许多 PHP 扩展都包含了现在已记录的函数，你基本上将它们包含在你的 PHP 程序中。另一方面，PHP 提供了四个函数，允许你从不同的文件中嵌入代码：

- include
- require
- include_once
- require_once

每一个 `include` 和 `require` 函数都接受一个本地文档作为输入。无论处理无法检索资源的方式如何，`require` 和 `include` 函数的功能都非常相似。例如，`include` 和 `include_once` 在资源不可用时会给出提示并尝试继续执行程序。`require` 和 `require_once` 函数在无法恢复资源时会停止特定页面的准备。现在我们将更具体地介绍这些函数。
