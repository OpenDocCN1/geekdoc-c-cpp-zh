```html

<h2>Registration Page</h2>
<a href="index.php">Click here to go back</a><br/><br/>
```

$_SERVER["REQUEST_METHOD"] == "POST" - checks if the submit button was clicked.

$_POST['username'] - gets the username.

mysql_real_escape_string() - ensures the username doesn't contain SQL injection characters.
