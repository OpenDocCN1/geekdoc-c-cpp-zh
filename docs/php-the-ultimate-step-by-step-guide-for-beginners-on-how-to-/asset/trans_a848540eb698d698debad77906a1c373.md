# 引言

你对创建自己的网站的想法感兴趣吗？有没有想过一个拥有登录/注销功能的网站有多酷？需要了解如何在数据库中创建、读取、更新或删除（CRUD）记录吗？你错过了之前的教程吗？考虑了这些问题后，我将向你展示如何在没有任何外部帮助的情况下创建一个网站，并了解 PHP 代码的每一个细微元素。如果你是后端开发的新手，这本书就是适合你的。

我将在点中解释一切，这样你就不需要去研究 PHP 的某些技术。为了保持尽可能简单，我们不会使用任何复杂的系统。此外，我不会专注于我们设计的网站功能。然而，执行设计并不困难。这本书将对 PHP 代码过程进行简单而详尽的分析。

那么，什么是 PHP？如果你需要设计网站，你可能需要知道这个问题的答案。想一下——1995 年估计有超过 10,000 个网站使用 PHP 来建立自己的网站。今天，有超过 1,000,000 个网站在使用 PHP。

PHP 是一种用于网站开发的流行且广泛使用的编程语言。PHP 代表 PHP：超文本预处理器。

在互联网早期，大多数网站都是静态内容页面。随着互联网的发展，人们需要具有更多交互功能的网站，例如留言板和联系表单。PHP 在过去是完美的工具，现在也是。

PHP 是一种非常强大且成熟的编程语言。它最初于于1995 年，已成为网站开发最受欢迎的语言之一。它运行在服务器端，非常安全。现在它已经公开，大多数托管服务都提供 PHP 托管包。

如果你需要一个带有留言板和联系表单等元素的交互式网站，你可以自己学习 PHP 编程、购买网站包，或聘佣专业的 PHP 程序员。许多人没有空间、时间或能力来学习编程语言（如 PHP），并选择购买网站包。最近的一个经历显示出[原文在此处截断/中断]——下一部分似乎是一个过渡。

# 第一章：设置你的服务器

现在我们已经准备好了一切，我们将从设置服务器开始。为了做到，我们需要一个本地服务器。为此最流行的工具是 XAMPP，它包含了 Apache、MySQL、Perl 和 PHP。

一旦安装了 XAMPP，打开 XAMPP 控制面板。你会看到一个模块列表。点击 Apache 和 MySQL 旁的“Start”按钮。如果它们变成了绿色，说明你的服务器正在运行！

现在，打开你的浏览器并在地址栏中输入 `localhost`。你应该看到 XAMPP 仪表板。这确认了你的服务器正常工作。
