# 第 11 章：让 PHP 与 MySQL 通信

现在你已经熟悉使用 MySQL 客户端来控制数据库中的信息，你可以开始使用 PHP 来显示和修改数据库中的信息。

PHP 提供了用于处理数据库的标准函数。

首先，我们将讨论 PHP 内置的数据库函数。我们还将向你演示使用 PHP 扩展与应用程序仓库（PEAR）数据库函数的最有效方法，这些函数让你能够使用相同的函数访问任何支持的数据库。这种灵活性源于一种被称为“抽象”的过程。在编程接口中，反射（reflection）简化了复杂的连接。它不负此，通过消除协作中任何无关紧要的部分，让你能够关注核心部分。PEAR 的 DB 类就是这样一种数据库接口反射。

## 11.1 流程

连接数据库所需的信息被减少到了最低。
这种标准安排允许你与 MySQL 以及其他使用相同函数的数据库进行协作。因此，其他 MySQL 特有的函数被通用的、能够与多个数据库通信的函数所取代。例如，MySQL 特有的接口函数：

```php
mysql_connect($db_host, $db_username, $db_password);
```

相对于 PEAR 的 DB 接口函数：

```php
$connection =
DB::connect("mysql://$db_username:$db_password@$db_host/$db_database");
```

两种方式都提供了核心数据，但 PEAR 函数还额外指定了要连接的数据库类型。相反，你可以连接 MySQL 或其他支持的数据库。我们将介绍这两种关联技术。

在本节中，你将了解如何从 PHP 连接到 MySQL 服务器，如何使用 PHP 获取和恢复信息，以及如何准确地向客户端显示数据。

### 流程

无论使用 mysql 命令行工具还是 PHP，执行查询的本质步骤都是相同的：

- 连接到数据库。
- 选择要使用的数据库。
- 构建 SELECT 语句。
- 执行查询。
- 显示结果。

我们将针对原生 PHP 和 PEAR 函数逐一介绍这些步骤。

### 资源

在连接到 MySQL 数据库时，你将使用两个新资源。一个是连接标识符（connection identifier），它持有与数据库连接相关的大部分重要数据。另一个资源是结果集。它包含了从数据库查询获取结果所需的所有数据。

我们将在本部分创建这两个资源。

### 引入

PEAR 使用一个包管理器（Package Manager）来管理你引入的内容。是否需要引入包管理器取决于你引入的 PHP 版本。如果你运行的是 PHP 4.3.0 或更新版本，它现在已经包含了。如果你运行的是 PHP 5.0，PEAR 已被拆分到不同的包中。你感兴趣的 DB 包是可选的，但作为包管理器的一部分被包含在内。所以，如果你有了包管理器，就可以使用了。

#### Unix

你可以通过在 shell（命令行）中执行以下命令，在 Unix 系统上引入包管理器：

```bash
curl http://go-pear.org/ | php
```

这将获取 go-pear.org 网站的输出（实际上是 PHP 源码）来引入 PEAR 并将其传递给 php 执行。

#### Windows

PHP 5 安装包含了 PEAR 脚本，路径为 `C:\php\go-pear.bat`。如果你没有包含第 2 章中的每个文件，请将所有 PHP 文件复制到 `C:/php` 并执行 `.bat` 文件。如果你是从 MSI 安装程序引入 PHP 的，你可能需要执行以下命令而不是 `go-pear.bat` 文件：

```bash
php go-pear.phar
```

如果 PEAR 目录不存在，你需要重新运行 PHP MSI 安装程序，选择“修改”选项，并在运行 `go-pear.phar` 之前将“扩展和附加项目”设置为“将安装在本地计算机上”。

PEAR 安装程序会会创建一个名为 `C:\php\PEAR_ENV.reg` 的文件。你需要双击它以在注册表中设置 PEAR 路径。此文件取决于你引入的 PEAR 版本。当对话框似乎在验证你的数据时，你将其添加到注册表并点击确定。

在运行此 `.bat` 文件后，你可能需要修改 `php.ini` 文件，将 PEAR 索引添加到包含路径中。`php.ini` 的第 447 行现在记录了这一点：

```ini
include_path = "c:\php\includes;c:\php\PEAR"
```

必须重启 Apache 才能使用 DB 包。
