# Displaying Results with Embedded Links

You may need to give your web browser the capacity to click a hyperlink to launch an activity that relates to the present row in the outcomes from a query. You do this by including URL links to the results of the query when they show on the screen. The links contain a distinctive identifier to the row and the script that handles the activity.

The PHP script that is the target of the link mainly queries the database in light of the distinctive identifier that was passed to it. The types of activity you can do range from formatting or erasing a row to developing details from a related table, for example, writers for book titles.
