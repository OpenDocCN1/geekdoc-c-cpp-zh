首先，选择 localhost/phpmyadmin。这将带你进入 phpmyadmin 落地页：

# Localhost/phpmyadmin

![](img/8e0a31fe30a159a13fdfed13405b5ed7_14_0.png)

从该点开始，点击顶部的“数据库”（Databases）选项卡，然后从中间的内容框中选择 `first_db`，然后点击“创建”（make）。排序规则只需保持如下所示即可：

![](img/8e0a31fe30a159a13fdfed13405b5ed7_14_1.png)

## 0.3 将用户添加到数据库

既然我们已经有了表，我们应该进入有趣的部分，让注册页面可用。从你的 `register.php` 开始包含以下代码：

register.php

![](img/8e0a31fe30a159a13fdfed13405b5ed7_16_0.png)

这里是代码：

```html
<html
<head>
<title>我的第一个 PHP 网站</title>
</head>
<body>
<h2>注册页面</h2>
<a href="index.php">点击此处返回</a><br/><br/>
<form action="checklogin.php" method="POST">
输入用户名：<input type="text" name="username" required="required" /><br>
输入密码：<input type="password" name="password" required="required" /><br>
<input type="submit" value="注册"/>
</form>
</body>
</html>
```

`$_SERVER["REQUEST_METHOD"] == "POST"` 检查是否点击了提交按钮。

`$_POST['username']` 获取用户名。

`mysql_real_escape_string()` 确保用户名不包含 SQL 注入字符。

## 0.4 用户登录：身份验证

我们现在用相应的语言编写 `checklogin.php` 怎么样？

checklogin.php

![](img/8e0a31fe30a159a13fdfed13405b5ed7_20_0.png)

mysql_select_db("first_db") or die("无法连接数据库");

$query = mysql_query("Select * from users WHERE username='$username'");

$exists = mysql_num_rows($query);
