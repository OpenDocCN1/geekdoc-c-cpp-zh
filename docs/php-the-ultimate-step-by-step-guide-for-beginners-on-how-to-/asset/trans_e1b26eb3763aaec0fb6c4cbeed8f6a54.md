## MySQL

MySQL 是一个免费的关系型数据库，但它仍然包含了完整的功能。MySQL 创建于 20 世纪 90 年代，以满足 PC 监控不断发展的的需求。首批核心 MySQL 设计者试图通过利用 mSQL（一种非常小且基础的数据库）来解决他们对数据库的需求。事实证明，mSQL 无法处理它需要的大量问题，因此他们制作了一个更健壮的数据库，并演变成了 MySQL。

MySQL 支持几个不同的数据库引擎。数据库引擎决定了 MySQL 如何处理信息的实际存储和查询。因此，每个存储引擎都有其特定的能力排列和优势配置。随着时间的推移，可用的数据库引擎正变得越来越先进和快速。

MySQL 的最新生产发布版本是 5.0x 版本。MySQL 5.0 提供的执行类似于某些非常昂贵的项目数据库，例如 Oracle、Informix、DB2 (IBM) 和 SQL Server (Microsoft)。开发者通过利用许多开源设计者的才华以及社区测试，实现了这种水平的性能执行。对于一般的 Web 驱动数据库任务，默认的 MyISAM 数据库引擎工作得非常出色。不用担心数据库的最新和最主要的功能，因为你可能需要的大部分功能已经在 MySQL 中整合很久。

## 兼容性

Web 程序（例如 Safari、Firefox、Netscape 和 Internet Explorer）是为处理 HTML 而设计的，因此 Web 服务器运行在何种操作系统上并没有区别。Apache、PHP 和 MySQL 支持广泛的操作系统（OS），因此你所在服务器或客户端上都不局限于特定的操作系统。虽然你不需要过多担心软件兼容性，但文件格式的极其多样化以及所有汇聚的各种语言确实需要一些时间适应。

## 4.4 整合多源信息

在 Web 早期，生活很简单。文件包含 HTML 以及以及二进制文件，例如图片。随后创建了一些进展来改进网页的外观。例如，层叠样式表（CSS）将呈现数据从你的 HTML 中提取出来并放入单一位置，以便你可以同时对整组页面进行格式更改；你不需要物理性地一次更改一个 HTML 标记。

你可能同时拥有引用 CSS 的 HTML 文档、PHP 模板和 MySQL 数据库的数据。PHP 模板使得页面包含由数据库查询填充的字段时，更改页面中的 HTML 变得简单。

为了大致了解你的代码样子，查看一个包含 PHP 代码的示例将很好，该代码从 MySQL 数据库创建 HTML，而该 HTML 本身引用 CSS 样式表。

结果是，虽然你在混合中添加了另一个内容，但你让 HTML 标记更易读，且 PHP 代码没有与偶然的 HTML 混在一起。一个不擅 PHP 的 Web 设计师可以在不用担心破坏 PHP 代码的情况下调整页面的外观。

这里指示的最后一种数据 CSS 也源于分离呈现的愿望，例如将内容和颜色从重要内容分离。

层叠样式表（CSS）补充了 HTML，让 Web 设计师和客户端对网页的显示方式有更多的控制。设计师和客户端可以创建样式表，表描述不同组件（例如页眉和链接）在网站上的显示方式。“层叠”一词源于事实，即不同级别的多个样式表可以同时存在。
