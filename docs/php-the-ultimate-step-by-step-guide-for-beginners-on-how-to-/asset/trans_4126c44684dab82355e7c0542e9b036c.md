
你已经学会了如何定义函数及其参数，以及如何从它们之间传递数据；此外，我们还提供了一些解决潜在问题的优秀示例。

接下来，我们将介绍另一种名为面向对象（OO）的编程风格。PHP 5.0 拥有了 OO 接口。关于哪种编码类型更好，一直存在争议，实际上并没有孰优劣之分；这本质上是一个风格问题。

## 面向对象编程

面向对象编程与我们讨论函数的目标相同，目的是使代码复用。它使用类将函数和变量组合在一起作为一个对象。你可以将对象看作可以工作的“黑盒”。

尽管如此，它们仍然使用函数；不过，在类中定义的这些函数被称为**方法（methods）**。类作为创建对象的蓝图。当创建一个类的对象时，它被称为该类的**实例（instance）**。类中定义的任何变量被称为**属性（properties）**。构造函数可以被来存储信息。

如果你对面向对象编程的概念很陌生，不要担心立即理解它。我们将在第 8 章中处理类，所以你只需要知道如何调用方法。

## 创建类

类通常存储在独立文件中以便复用。让我们创建一个名为 `Cat` 的对象，它拥有三个方法：`meow`、`eat` 和 `purr`。类定义了其名称。类名遵循与变量相同的命名原则。构成类的代码位于大括号之间。创建一个没有任何方法的类，示例 7.10 所示。

示例 7.10. 从类创建对象

```php
<?php
class Cat {
}

$fluffy = new Cat();
echo "Fluffy is a new object.";
?>
```

上面的代码显示：

Fluffy is a new object

## 创建实例

示例 7.10 将类标识为一个实例。`new` 关键字告诉 PHP 返回 `Cat` 类的实例。尽管类本身没有执行任何操作，但你可以将其标识为一个对象。类是创建实例蓝图。类规定了每个实例的内容。

## 方法和构造函数

方法是类在内部定义的函数。它们在类的范围内工作，包括其变量。对于类，有一种特殊的方法被称为**构造函数（constructor）**，在创建类的对象时被调用，用于初始化类并设置变量。构造函数通过创建一个与类同名的方法来定义，示例 7.11 所示。

示例 7.11. 创建 Cat 构造函数

```php
<?php
class Cat {
function Cat() {
}
?>
```

PHP 5.0 支持使用 `__construct` 来创建构造函数，示例 7.12 所示。如果 PHP 5.0 中的类没有此语法，则使用使用类名作为系统的旧样式。

示例 7.12. 使用 PHP 构造函数

```php
<?php
class Cat {
function __construct() {
}
?>
```

构造函数也可以像其他方法一样包含参数。此外，类可以包含自定义方法。对于 `Cat` 类，你可以定义 `meow`、`eat` 和 `purr`，如示例 7.13 所示。

示例 7.13. 为 Cat 定义三个成员函数

```php
<?php
class Cat {
function __construct() {
}
function meow() {
    echo "Meow...";
}
function eat() {
    echo "eats...";
}
function purr() {
    echo "Purr...";
}
}
?>
```

当你声明一个类的实例时，如果存在，构造函数会被可靠地调用。正如你可能知道的，类提供了对象的蓝图。你从类创建一个对象。如果你看到“实例化类（instantiating a class）”这个表达式，它的意思是创建一个对象；因此你可以认为它们是同义的。当创建一个对象时，你正在创建一个类的实例，这意味着你正在实例化类。

`new` 构建通过为该新对象分配内存来实例化类，这意味着它需要一个参数，即对构造函数的调用。构造函数的名称提供了要实例化的类名，构造函数引入了新对象。

`new` 构建返回所创建对象的引用。这个引用通常被赋值给变量。然而，如果引用没有赋值给变量，则在完成 `new` 操作执行的语句之后，该对象将无法访问。示例 7.14 向你展示了有效使用 `new` 的通用方法。

示例 7.14. 创建另一个对象并将其赋值给变量

```php
<?php
class Cat {
function __construct() {
}
function meow() {
    echo "Meow...";
}
function eat() {
    echo "eats...";
}
function purr() {
    echo "Purr...";
}
}

// 将新的 Cat 对象赋值给引用 $myCat
$myCat = new Cat;
?>
```

## 类内部的变量作用域

类可以包含有助于定义结构及其如何使用的变量。类内部的变量使用 `var` 语句声明。`var` 语句声明具有类作用域。类作用域意味着它们在类的任何方法中都可以被识别，并通过特殊构造在类外部引用。示例 7.15 为 `Cat` 添加了 `$age` 变量。

示例 7.15. 为 Cat 添加 $age 变量

```php
<?php
class Cat {
// 猫有多大了
var $age;
// PHP 5 使用:
public $age;
}
?>
```

在类内部引用方法和变量时，你必须使用语法：

$this->变量名 或 方法名

特殊的变量 `$this` 运算符用于修改 `$age` 的值。在示例 7.16 中， `$this->` 运算符用于修改 `$age` 的值。

示例 7.16. 使用 this-> 获取 $age 变量

```php
<?php
class Cat {
// 猫有多大了
var $age;
function __construct($new_age){
// 将这只猫的年龄设置为新年龄
$this->age = $new_age;
}
// birthday 方法增加年龄变量
function Birthday() {
    $this->age++;
}
}
// 创建一个一岁的猫的新实例
$fluffy = new Cat(1);
echo "Age is $fluffy->age <br/>";
echo "Birthday<br/>";
// 增加 fluffy 的年龄
$fluffy->Birthday();
echo "Age is $fluffy->age<br/>";
?>
```
