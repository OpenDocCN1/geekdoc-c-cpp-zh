```
class Domestic_Cat expands Cat {
  /Constructor
  function Domestic_Cat() {
  }
  /Sleep like a domestic cat
  function sleep() {
    echo("Zzzzzz.<br/>");
  }
}
```

```
$fluffy=new Domestic_Cat();
$fluffy->Birthday();
$fluffy->sleep();
echo "Age is $fluffy->age <br/>";
?>
```

Case 7.17 outputs the following:

Zzzzzz.

Age is 1

Notice that you can access the Birthday function from the Cat class and the recently defined sleep method despite of which level in the object defined the method.

# The parent object

A Domestic_Cat is a Cat in all regards. However, it contains the base methods of a Cat. It is likewise feasible to override existing functionality from the superclass to give your own new code. You just reclassify the function in the new class.
