对代码的某些解释：
- `!empty()` - 一个检查值是否为空的方法。如果你想检查它是否为空，可以通过删除感叹号（!）来反转语法，因此其语法将是 `empty()`。
- `$_GET['id']` - 用于从参数中获取值。在我们的用例中，我们将 `id` 作为 URL 参数，因此语法应为 `$_GET['id']`。
- `$id_exists` - 检查给定的 id 是否存在的变量。
- `$_SESSION['id']` - 我们将 `id` 的值放入会话中以便在另一个页面中使用。
