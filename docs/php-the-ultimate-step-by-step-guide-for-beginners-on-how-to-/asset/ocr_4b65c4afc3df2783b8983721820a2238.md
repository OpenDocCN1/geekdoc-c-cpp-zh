# Parameters

Parameters give a helpful approach to pass data to a function when you call it without needing to stress over variable scope. In PHP, you don't need to characterize what kind of information a parameter holds—only the parameters' names need to be specified.

A sample of a function that takes a parameter is strtolower, which changes over your string “Hi world!” to lowercase. It takes a parameter of the sort string, which is a data type depicted in Chapter 3. Additionally, there’s another function called strtoupper which changes over all characters of your string into capitalized letters, as demonstrated in Example 7.4.
