## 父对象

`Domestic_Cat` 在所有方面都是一个 `Cat`。然而，它包含了基类方法。重写父类的现有功能以提供自己的代码是可行的。你只需要在新类中重新定义该函数即可。

在扩展类以重写现在定义在父类中的类函数时，可以在包含自己的功能后，仍然执行来自父类的代码。要在你的代码执行之前调用父类，请使用：

parent::method_from_parent

这会调用父类中的父系统。你可以像示例 7.18 所示将其添加到你的代码中。

### 示例 7.18. 利用 parent

```php
<?php
class Cat {
  // 老猫的属性
  var $age;
  function Cat($new_age){
    //将此处的年龄设置为新年龄
    $this->age = $new_age;
  }
  function Birthday(){
    $this->age++;
  }
  function Eat(){
    echo "chomp.";
  }
  function Meow(){
    echo "meow.";
  }
}
class Domestic_Cat extends Cat {
  //Constructor
  function Domestic_Cat() {
  }
}
```

## 静态方法和变量

如果方法和变量在类中被定义为静态（static），则同样可以被利用和访问。正如第 3 章所述，静态意味着系统或变量不是通过对象实现的。在 PHP 4.0 中，没有真正的方法可以判断一个变量是静态的；尽管如此，在 PHP 5.0 中，你可以使用 `static` 修饰。

`::` 运算符允许你引用没有任何对象的类中的变量和系统。示例 7.20 显示了你如何使用 `::` 调用静态系统，以及即使在创建了实例后，普通的调用语法仍然不起（PHP 不会报告错误）。

### 示例 7.20. 利用 :: 运算符调用催眠

```php
<?php
class Cat {
}
class Domestic_Cat extends Cat {
  //Constructor
  function Domestic_Cat() {
  }
  //此函数必须静态地调用
  public static function hypnotize() {
    echo("The cat was hypnotized.");
    return;
  }
}
// 催眠所有的猫
Domestic_Cat::hypnotize();
```

```php
$domestic_cat = new Domestic_Cat();
// 什么都不做
$domestic_cat->hypnotize();
```

输出如下：

The cat was hypnotized.

当使用范围解析符（::）调用静态方法时，由于不存在对象，你无法利用 `$this` 来引用对象。

## 变量引用

在 PHP 中，变量名指的是内存中存储信息的区域。可以有多个变量名指向内存中的同一个位置。安培符运算符 `&` 用于表示你关注的是变量所引用的内存区域，而不是它的值。

PHP 引用允许让两个变量引用相同的内容。通过这种方式，更改一个变量的值可以改变另一个变量的值。这可能会导致发现代码中的错误变得异常困难，因为改变一个变量会改变另一个。

相同的标点符号也可以用于接收引用的函数。用例 5.21 利用此来引用 `$some` 变量。

### 示例 7.21. 引用 $some_variable

```php
<?php
$some_variable = "Hello World!";
$some_reference = &$some_variable;
$some_reference = "Guten Tag World!";
echo $some_variable;
echo $some_reference;
?>
```

输出如下：

Guten Tag World!
Guten Tag World!

示例 7.21 显示引用是使用 `&` 运算符进行定位的，并且位于当前变量 `$` 之前。变量 `$some_reference` 然后引用了 `$some_variable`（放置 "Hello World!" 的内存区域）。

正如在本部分已经检查过的，变量引用有助于将变量作为引用传递给函数。这允许函数修改你基础代码中的变量，而不是修改一个在函数结束时丢失的本地副本。

在不使用引用运算符的情况下将变量赋值给另一个变量会导致变量的副本被设置在内存的另一个位置。可以更改新变量而不会修改第一个变量。虽然这会占用更多内存，但如果你不想更改第一个变量的值，这是最好的方法。

# 第 8 章：数组

变量对于存储单条数据非常棒，但当你必须存储一整组数据的信息时（例如查询的结果）会发生什么？在这种情况下，请使用数组。数组是存储许多信息的特殊变量类型。数组允许你单独访问存储在其中的任何属性，同时又能复制和控制数组。

## 8.1 数组基础

要处理数组，你需要理解两个术语：索引（index）和元素（element）。索引是访问元素的键，而元素是存储在数组中的值。在 PHP 中，数组默认是从零索引的，这意味着第一个元素位于索引 0，第二个位于索引 1，依此类推。

# 第 9 章：与 MySQL 交互

MySQL 有它自己的客户端界面，允许你移动信息和更改数据库设计。注意你应该使用密码登录。分配数据库客户端可以限制对表的访问。每个 MySQL 服务器可以有多个数据库。

## 9.1 MySQL 数据库

MySQL 数据库是相关联表的集合。要在 PHP 中处理 MySQL，你首先需要建立与数据库的连接。这可以使用 `mysqli` 扩展来实现。

```php
<?php
$mysqli = new mysqli("localhost", "username", "password", "database_name");

// 检查连接
if ($mysqli->connect_error) {
  die("连接失败: " . $mysqli->connect_error);
}
echo "连接成功";
?>
```
