# 第 7 章：函数

为了编写不仅包含几页代码且具有良好体系以发挥价值的 PHP 程序，你必须对函数有深入的理解。函数让你无需在程序中反复编写相同的代码。函数的工作原理是为一组代码分配一个名为“函数名”的名称。随后，你通过调用该名称来执行代码。PHP 中有许多内置函数。例如，`print_r` 是一个函数，它能以易懂的英语而非代码打印变量周围的连贯数据。如果给定字符串、数字或浮点数，`print_r` 函数会打印属性本身。如果给定数组，属性将以键和组件的形式展示出来。对象也使用类似的格式。在 PHP 5.0 中，`print_r` 和 `var_export` 可以显示对象的保护和私有属性。

运行从 `aggregate_info` 到 `imap_ping` 再到 `pdf_open_image` 的数组。由于这类函数有很多，我们在本章中只需涵盖一些基础知识，尽管我们会提供足够的数据，让你在短时间内通过使用函数看起来像个专家。

具体来说，我们将介绍以下内容：

- 如何从函数返回值并在你的代码中应用它们
- 在尝试调用函数之前验证该函数是否存在

在编码时，何时可以将代码拆分为函数，这在很大程度上是一个主观的判断。毫无疑问，如果你发现自己在反复编写某几行代码，那么将这些代码封装成函数是非常明智的。这会让你的代码更易读，并且当你决定对这部分代码进行其他操作时，可以保护你无需进行多处改进，因为代码只需要修改一个处，而不是多个需要替换和更改的地方。

一旦加载 PHP 文档，`echo` 函数基本上就会向程序/浏览器发送 "Welcome world!" 字符串。`echo` 实际上是一个 PHP 语言结构。基本上，这意味着它有能力在不将其参数放在括号内的情况下工作。需要注意的是，在大多数情况下，真正的函数需要括号。

你可以使用 PHP 的众多内置函数之一，也可以定义自己的函数。我们将更多地讨论识别自己的函数。

## 7.1 调用函数

PHP 中有许多内置函数。调用函数最常见的方法是使用其名称后跟括号。如果函数需要参数，这些参数将位于括号内。例如：

```php
function greet($name) {
  echo "Hello, " . $name . "!";
}

greet("Alice"); // 输出: Alice!
```

如果函数使用 `return` 语句返回值，该值可以赋值给变量：

```php
function add($a, $b) {
  return $a + $b;
}

$result = add(5, 3); // $result 现在为 8
```

函数也可以通过引用调用，允许函数修改传递的变量。这是通过使用符号 `&` 实现。

```php
function addToTen(&$value) {
  $value += 10;
}

$number = 5;
addToTen($number); // $number 现在为 15
```

## 7.2 定义函数

要定义函数，使用 `function` 关键字后跟函数名称、括号和代码块。函数内的代码在大括号内。

```php
function myFunction() {
  // 要执行的代码
}
```

函数也可以接收参数，这些是在括号内定义的变量。

```php
function myFunction($param1, $param2) {
  // 使用 $param1 和 $param2
}
```

你可以为参数提供默认值。调用函数时如果没有提供参数，则使用默认值。

```php
function greet($name = "Guest") {
  echo "Hello, $name!";
}

greet(); // 输出: Hello, Guest!
greet("Alice"); // 输出: Hello, Alice!
```

函数也可以使用 `return` 语句返回值。遇到 `return` 语句时，函数停止执行并返回指定的值。

```php
function multiply($a, $b) {
  return $a * $b;
}

$product = multiply(4, 5); // $product 现在为 20
```

## 7.3 作用域

PHP 中的变量具有局部作用域。在函数内部定义的变量是该函数的局部的，无法从外部访问。

```php
$x = 5; // 全局变量

function myFunction() {
  $x = 10; // 局部变量
  echo $x; // 输出 10
}

myFunction();
echo $x; // 输出 5
```

要在函数内部访问全局变量，必须使用 `global` 关键字。

```php
$x = 5;

function myFunction() {
  global $x;
  $x = 10;
  echo $x; // 输出 10
}

myFunction();
```

或者，你可以使用 `$GLOBALS` 数组来访问全局变量。

```php
$x = 5;

function myFunction() {
  echo $GLOBALS['x']; // 输出 5
}

myFunction();
```
