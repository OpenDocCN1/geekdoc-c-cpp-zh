# 模板 (Formats)

模板将描述页面呈现或外观的 HTML 代码与负责处理业务活动信息的 PHP 代码分离开。一旦分离，对于学习过 HTML 或可能学习 CSS 的人来说，修改布局而无需担心地破坏 PHP 代码，这就会变得更加简单。此外，PHP 代码可以专注于信息本身，而不是参与展示的细微元素。

使用模板有许多不同的关注点。例如，如果你在模板中犯了错误，错误将清晰地从模板中返回。模板本身大部分可以导入到 Web 程序或图形化 Web 开发工具中（例如 Dreamweaver），因为它们在处理后看起来就像页面的最终状态。模板支持用于展示的关重要的编程元素，例如，具有判断页面某个区域是否应该可见的能力。

显然，没有什么是完美的；模板也有两三个缺点。模板增加了需要维护的文件数量。它们会包含少量的额外处理时间。它们还强制引入模板引擎并设置注册表。你至少需要运行 PHP 4.0.6 版本才能使用 Smarty，这是一个著名的模板引擎。

# 模板引擎 (Format Engine)

互联网上可以找到几个模板包。每个包都使用自己的模板引擎来准备模板，并在各种情况下使其达到预期效率。无论你使用哪种模板引擎，你通常都会遵循相同的步骤步骤：

- 1. 获取你的数据。
- 2. 对每一个作为模板一部分的属性调用模板函数。
- 3. 使用模板函数显示模板。

# 安装 (Establishment)

虽然引入 Smarty 不像引入和设计 Apache、PHP 以及 MySQL 那样复杂，但它值得某些考虑：

### 应用层级索引 (Application level indexes)

对于你想要使用 Smarty 的每个应用程序，你必须设置一组四个索引。这四个索引分别用于模板、编译后的模板、保留模板和设计记录。尽管你可能不会使用这些功能，但你应该设置这些索引以防万一使用：

- 1. 在你的存档根目录下创建一个名为 `myapp/` 的索引。（你可以根据需要将其重命名，但对于后续内容，我们将统称为 `myapp/`。）
- 2. 在你刚刚创建的目录创建一个名为 `smarty` 的注册表（myapp/smarty）。
- 3. 在你刚刚创建的 smarty 注册表中再创建四个注册表：formats、templates_c、store 和 config。确保 Web 服务器对你之前创建的 `templates_c` 和 `store` 索引具有写入权限。

# 为显示格式化字符串 (Formatting Strings for Display)

在这种情况下，你一直在使用 `echo` 和 `print` 来显示字符串而没有做太大修改。

你会发现两个名为 `sprintf` 和 `printf` 的函数。如果你熟悉其他编程语言（例如 C），你会发现这些函数的工作方式与其他所在的地方相同。如果你以前没有用过它们，不要担心——它们并不很难用。两者之间的主要区别是 `sprintf` 像 `print` 一样向输出显示一个格式化后的字符串，而 `sprintf` 将它生成的字符串保存在你指定的另一个字符串变量中。

# 使用 printf (Using printf)

`printf` 函数通过将其第一个参数作为一个特殊的格式字符串来满足预期。格式字符串使用占位符来描述如何将参数插入字符串中。你可以指定细微元素，例如，在字符串中的数字。每个设置到字符串的参数在格式字符串中都有占位符。例如，输出对齐的数字。
