
交付更稳定的记录。虽然更严格的过期检查听起来像是一种负担，但该提议让程序记录错误而不是试图渲染错误形状的内容，应该通过促使创建者纠正其错误来解决问题。

## 14.2 XHTML 和 XML 命名空间

XML 极具有非排他性。它描述了标点和基本结构，但对查询没有太多规定，例如，元素应该如何命名。这导致了一个问题：一个连接中的 `Title` 含义与另一个连接中的可能完全不同。XML 命名空间规范（可以在 http://www.w3.org/TR/xml-names/ 处找到）提供了一个设计人员可以使用的系统，利用资源标识符（URIs）来识别特定的词汇。URIs 是已知资源定位符（URLs）和资源名称（URNs）的结合。从 XML 命名空间的角度来看，URIs 非常有用，因为它们可以与所有轻松结合。W3C 声称以 `http` 开头的名称非常适合它们作为标识符。在没有混合词汇的纯 XHTML 中，命名空间通过 `XHTML` 属性在 `html` 标签上声明。例如：

```html
<html xmlns="http://www.w3.org/1999/xhtml">
```

命名空间 URI `http://www.w3.org/1999/xhtml` 现在应用于 `html` 组件本身以及任何元素，因为它们没有自己的、以前缀开头的属性或名称。

## 14.3 XHTML 版本

自诞生以来，XHTML 标准直一直在演进。今天有三种关注的形式：

### XHTML 1.0

XHTML 1.0 的内容与 HTML 4.0 相同，但它需要 XML 语法。

### XHTML 1.1

XHTML 1.1 是 1.0 的重新格式版本。它是严格的，因为它使用了更大的元素集合。这是 W3C 的建议，提供了标准属性和需要符合 XHTML 环境的定义。HTML 的任何元素（例如表示性元素和框架）都被移除了。所有的呈现由层叠样式表（CSS）控制。此外，1.1 包含了对 XML 方言的支持。

## 14.4 使用 PHP 创建 XHTML

通过 PHP 生成 XHTML 比创建旧 HTML 困难。

## 15.1 从 PHP 修改数据库对象

SQL 查询字符串是提供数据库命令的基本机制。你可以以执行查询的方式使用标准 SQL 创建和修改数据库对象。有时你需要在 PHP 中创建数据库对象。我们将从创建表开始，这是一个创建对象的示例。

## 15.2 操作表数据

我们之前创建了 `books` 和 `authors` 表，但还没有创建 `buys` 表。我们将使用示例 15.1 显示的 PHP 创建它。

示例 15.1. 在 create_table.php 页面中创建表

```php
<?php
include('db_login.php');
require_once('DB.php');

$connection = DB::connect(
  "mysql://$db_username:$db_password@$db_host/$db_database");
if (!$connection) {
  die("无法连接到数据库: " . DB::error_message());
}

$query = 'CREATE TABLE buys (
  purchase_id int(11) NOT NULL AUTO_INCREMENT,
  firstname varchar(50) NOT NULL,
  lastname varchar(50) NOT NULL,
  amount decimal(10,2) NOT NULL,
  PRIMARY KEY (purchase_id)
) ENGINE=InnoDB';

$result = $connection->query($query);
if (DB::isError($result)) {
  die("无法查询数据库: " . DB::error_message());
}

?>
```
