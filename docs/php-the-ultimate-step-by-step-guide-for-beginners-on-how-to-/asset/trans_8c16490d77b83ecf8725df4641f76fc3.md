

# 4.1 HTTP 与互联网

关于互联网如何运作的一些基础知识，如果你最近没有为 Web 编写过程序，这些可能会有所帮助。超文本传输协议（HTTP）定义了站点页面如何在互联网上进行交换。HTTP 是在万维网上用于交换或传递数据的系统。它存在的独特意义在于提供一种发布、分发和恢复 HTML 页面的方法。万维网联盟（W3C）和互联网工程任务组（IETF）标准化了 HTTP 的开发，它们是连接客户端和服务器的请求-响应协议。起始点的客户端（通常是网络浏览器）被称为用户代理（user agent）。存储或构建资源以及 HTML 文档和图片的目标服务器被称为服务器（server）。在用户代理和服务器之间，可能存在代理（proxies）等中间节点。HTTP 客户端通过在远程主机的特定端口（默认端口 80）建立传输控制协议（TCP）连接来启动请求。监听该端口的 HTTP 服务器会等待客户端发送请求。

在接受请求后，服务器会返回一个状态行（例如“HTTP/1.1 200 OK”）以及自身的响应。根据状态的不同，该响应可以是文件、错误消息或其他数据。HTTP 构建在 TCP 之上，而 TCP 本身又构建在互联网协议（IP）之上。两者通常被称为 TCP/IP。组织化主机上的应用程序可以相互建立关联并在之后交换信息。该协议确保了信息从发送者到收集者的稳健传输。TCP 支撑了互联网许多最著名的应用，包括 Web、电子邮件和 Shell。

# 4.2 PHP 和 MySQL 在 Web 开发中的地位

PHP 是一种编程语言，设计用于在 Web（即服务器）上交互式地创建网页。与 HTML 不同，在 HTML 中 Web 程序使用标签和标记来创建页面，而 PHP 代码则运行在请求的页面和服务器之间，从而改变基础的 HTML 输出。

PHP 让开发变得简单，原因在于你所需的所有代码都包含在 PHP 框架内部。这意味着每当你坐下编写程序时，没有特殊的理由去重新评估代码；因为它自带了 Web 功能。虽然 PHP 对于 Web 应用程序非常出色，但它本身并不存储数据。为此，你需要一个数据库。PHP 工程师使用的数据库是 MySQL，它承担着涉及存储和恢复客户端数据的广泛认可的任务。PHP 可以轻松地访问 MySQL，且它们运行得良好。一个内置优势是 PHP 和 MySQL 运行在不同的 PC 类型和操作系统上，包括 Mac OS、基于 Windows 的 PC 和 Linux。将 PHP 和 MySQL 结合使用的多个元素对许多人来说是自然的：

- PHP 和 MySQL 协作良好：PHP 和 MySQL 在创建时就考虑了对方，因此易于使用。它们之间的编程接口配对合理。设计人员在开发 PHP 和 MySQL 接口时，这两者协作的想法并不是事后才想到的。

- PHP 和 MySQL 拥有开源力量：由于它们都是开源项目，因此 PHP 和 MySQL 都可以免费使用。MySQL 库不再与 PHP 一起打包。高级用户可以对源代码进行改进，并借此更改语言和程序的工作方式。

- PHP 和 MySQL 拥有群体支持：它们在 Web 上都有动态社区，你可以在其中感兴趣，成员们将帮助你回答疑问。如果你有需要，你也可以为 MySQL 购买专业支持。

- PHP 和 MySQL 速度快：它们基础且高效的设计实现了更快的处理速度。

- PHP 和 MySQL 不会用冗余细节阻碍你

# 开源的价值

正如我们在上面说的，PHP 和 MySQL 都是开源项目，因此你不需要担心为办公室或家中的每台 PC 购买用户许可。在任何使用开源项目和技术的时刻，大多数程序员通常都可以访问源代码。这便于个人甚至小组进行分析，以区分复杂代码、进行调试、测试，并对该代码提供更改和新增。

例如，Unix——开源编程社区的先驱——曾向大学编程研究人员开放。Linux 是一种免费源码许可模型。通常，开源许可包含分发经修改代码的特权，但带有一些限制。例如，某些许可证要求衍生代码必须在相同的许可证下发布，或者可能存在他人无法使用你代码的限制。

开源许可起源于保护共享文化的努力，后来促进了人们对这种共享价值的更广泛意识。今天，开源软件工程师通过 http://www.php.net、邮件列表（listservs）和网站在 Web 上分享他们的代码更改。如果你发现自己陷入了了无法逃脱的编码噩梦中，本章中提到的资源可以并且将会帮助你。
