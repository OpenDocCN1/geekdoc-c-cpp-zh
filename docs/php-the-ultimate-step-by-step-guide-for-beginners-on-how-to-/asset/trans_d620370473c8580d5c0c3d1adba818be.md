## 9.5 结构化查询语言

既然你已经定义了表，就可以向其中添加信息了。MySQL 将跟踪所有细节。要管理信息，请使用结构化查询语言 (SQL) 命令。

由于其设计目的是为了轻松地描述行与表之间的关系，数据库使用 SQL 来修改表中的信息。

SQL 是一种用于大多数数据库（例如 MySQL、Oracle 或 Microsoft SQL Server）的标准语言。它被专门设计为用于检索、包含和管理存储在数据库中的信息的语言。我们将在下一章详细介绍 MySQL 的细节，但我们将从一些易于使用的简单命令开始。我们将从创建表开始。

### 创建表

利用表命令来指定新数据库表的结构。当你创建一个数据库表时，每个段都有几个选择，以及数据类型和列名。在向表中添加信息时，必须提供的值通过 `NOT NULL` 关键字指定。`PRIMARY KEY` 关键字告诉 MySQL 使用哪个段作为键字段。随后，你可以使用 `AUTO_INCREMENT` 关键字让 MySQL 自动分配键值。

要创建这些表，请输入并粘贴代码到 MySQL 命令行客户端。如果你忙于运行随附示例中的 SQL 代码，后续章节包含了核心的数据。它解释了如何访问 MySQL 客户端、如何通过 `GRANT` 语句分配安全权限、创建数据库并选择使用它。

示例 9.1. 创建书籍和作者

```sql
CREATE TABLE books (
  title_id INT NOT NULL AUTO_INCREMENT,
  title VARCHAR(150),
  pages INT,
  PRIMARY KEY (title_id));
```

```sql
CREATE TABLE authors (
  author_id INT NOT NULL AUTO_INCREMENT,
  title_id INT NOT NULL,
  author VARCHAR (125),
  PRIMARY KEY (author_id));
```

如果一切顺利，你将看到需要 MySQL 创建名为“books”的表的输出，它看起来将像示例 9.2 所示（查询运行的时间可能不是 0.06 秒）：

### 示例 9.2. 创建示例数据

```sql
mysql> CREATE TABLE books (
  title_id INT NOT NULL AUTO_INCREMENT,
  title VARCHAR (150),
  pages INT,
  PRIMARY KEY (title_id));
```

创建 books 表的代码拆分如下：

- 第一部分称为 `title_id`，是一个数字/整数。`auto_increment` 关键字是一个特殊值，在插入行期间自动分配给此字段。
- `title` 列包含内容多达 150 个字符的内容。
- `pages` 列是一个整数整数。
- `PRIMARY KEY` 属性告诉 MySQL 哪个字段是键值。

核心键必须是唯一的且不为 `NULL`。所有表都应该有一个主键，因为当你在从多个表中检索信息并再次利用键属性访问特定列时，它允许 MySQL 加速访问。MySQL 通过使用一种名为索引的特殊信息结构来实现这一点。索引的作用就像查找记录的快捷路径，类似于图书馆中的分类索引。要验证你的表列，请使用 `DESCRIBE`：

DESCRIBE books;

### 向表中添加数据

`INSERT` 命令用于包含信息。其语法为 `INSERT INTO table columns ([columns]) VALUES ([values]);`。此语法显示了应该将哪些表信息添加到哪些列中，以及值的列表。如果没有指定段，则值必须与创建表时定义的顺序相同在同一个请求中（只要你没有跳过任何段的值）。使用 SQL 命令处理信息以填充数据库时有特定的原则：

- 数字不应被引用。
- 字符串值应当可靠地引用。
- 日期和时间值应当可靠地引用。
- 函数不应被引用。
- `NULL` 永远不应被引用。

最后，如果列没有给出值，它被视为 `NULL`，除非该段存在默认值。如果某个段不能为 `NULL`（它是用 `NOT NULL` 创建的）且你没有指定值，则会发生错误。

例如：

```sql
INSERT INTO books VALUES (1,"Linux in a Nutshell",112);
INSERT INTO authors VALUES (NULL,1,"Ellen Siever");
INSERT INTO authors VALUES (NULL,1,"Aaron Weber");
```

如果没有错误，你将得到：

```sql
mysql> INSERT INTO books VALUES (1,"Linux in a Nutshell",112);
Query OK, 1 row affected (0.00 sec)
mysql> INSERT INTO authors VALUES (NULL,1,"Ellen Siever");
Query OK, 1 row affected (0.00 sec)
mysql> INSERT INTO authors VALUES (NULL,1,"Aaron Weber");
Query OK, 1 row affected (0.00 sec)
```
