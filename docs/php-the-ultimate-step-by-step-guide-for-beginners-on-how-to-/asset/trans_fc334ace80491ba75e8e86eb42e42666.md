某些二元运算符（例如赋值运算符）对左侧操作数有进一步的限制。由于赋值运算符正在给左侧操作数分配值，它必须是一个可以接收值的类型，例如一个变量。

# 示例 6.3. 左值表达式

```php
3 = $locations;/ // 糟糕 - 无法向精确的 3 分配值
$a + $b = $c; // 糟糕 - 左侧的表达式不是一个变量
$c = $a + $b; // OK
```

有一种更简单的方法可以记住这一点。赋值操作中的左侧表达式被称为左值（L-value）。PHP 中的左值是变量、数组组件和对象属性。

## 优先级

运算符的优先级决定了表达式中哪个运算符先被处理。例如，乘法和除法在加法和减法之前被处理。你可以在 http://www.zendend.com/manual/language.operators.php#language.operators.pr 查看一个简化的表格。

如果多个运算符的优先级相同，它们将按照它们在表达式中出现的顺序进行处理。例如，由于乘法和除法的优先级相同，它们按照在表达式中出现的顺序进行准备。相同优先级的运算符可以在任何顺序上出现而不影响结果。

另一方面，大多数表达式没有超过一个相同优先级的运算符，而且它们处理的顺序不会改变结果。如示例 6.4 所示，在对连续的数字进行加减运算时，先加还是先减是没有区别的——结果仍然是 1。

PHP 的优先级级别很少，少到如果不查阅参考资料就很难掌握它们。表 4-2 是按优先级从高到低排序的 PHP 运算符列表。相同级别的运算符优先级完全相同。

# 示例 6.4. 优先级

```php
2 + 4 - 5 == 1;
4 - 5 + 2 == 1;
4 * 5/2 == 10;
5/2 * 4 == 10;
2 + 4 - 5 == 1;
4 - 5 + 2 == 1;
```

当使用包含不同优先级级别运算符的表达式时，顺序可能会改变表达式的值。你可以利用括号 `(` 和 `)` 来覆盖优先级，或者仅仅是为了让表达式更易读。

图 6.5 展示了如何更改默认优先级。

### 图 6.5. 使用括号更改默认优先级

```php
echo 2 * 3 + 4 + 1;
echo 2 * (3 + 4 + 1);
```

结果为：
11
16

在第二个表达式中，由于括号覆盖了默认优先级，乘法最后执行。

# 结合性

所有运算符都按照特定的方向处理其运算符。这种方向被称为结合性（associativity），它依赖于运算符的类型。结合性决定了处理顺序，，取决于运算符的优先级。

如果多个运算符的优先级相同，它们将按照它们在表达式中出现的顺序进行处理。例如，由于它们的优先级相同，乘法和除法按照它们在表达式中出现的顺序进行准备。相同优先级的运算符可以在任何顺序上出现而不影响结果。

大多数表达式没有超过一个相同优先级的运算符，另一方面它们处理的顺序不会改变结果。如示例 6.4 所示，在对连续的数字进行加减运算时，先加还是先减是没有区别的——结果仍然是 1。

PHP 的优先级级别很少，少到如果不查阅参考资料就很难掌握它们。表 4-2 是按优先级从高到低排序的 PHP 运算符列表。相同级别的运算符优先级完全相同。

## 逻辑运算符

逻辑运算符通过逻辑运算符的布尔结果构建更复杂的逻辑表达式；四个逻辑运算符。

## 关系运算符

关系运算符用于比较两个值。我们在上一个章节中讨论过这些运算符。

## 相等

相等运算符，双等号 `==` 经常使用。如果两个操作数相等，则返回 TRUE；否则返回 FALSE。如果你不需要相等运算符自动转换类型，可以使用恒等运算符，三等号 `===`，它会检查类型是否相同。例如，“1” === 1 为假，因为类型不同。

你可能需要验证两个事物是否不同。不等运算符，感叹号等号 `!=` 检查相等的反面。

```
“1” != “A” // 真
“1” != “1” // 假
```

## 比较运算符

比较运算符测试值之间的关系。你可能在中学数学中见过它们。它们包括小于 (`<`)、小于等于 (`<=`)、大于 (`>`) 和大于等于 (`>=`)。

例如，3<4 是真，而3<3 是假，3<=3 是真。

比较运算符经常用于检查是否达到了某个点。例如，如果你购买五个或更多商品，在线商店可能会提供免费配送。因此，代码必须将商品数量与数字五进行比较。

## 逻辑运算符

逻辑运算符通过逻辑运算符的布尔结果构建更复杂的逻辑表达式；四个逻辑运算符。

要测试两个操作数是否为真，使用与运算符，也写为双与符号 `&&`。双与符号和 AND 都是逻辑运算符；主要区别是双与符号在 AND 运算符之前被处理。|| 与 OR 遵循相同的原理。

要测试其中一个操作数是否为真，使用或运算符，它也写为双竖线 `||`。如果一个或两个操作数为真，则返回 TRUE。

使用或运算符可能会导致棘手的程序问题。如果 PHP 发现第一个操作数为真，它就不会评估第二个操作数。虽然这节省了执行时间，但你应该确保第二个运算符中不包含程序正常运行所需的代码。
