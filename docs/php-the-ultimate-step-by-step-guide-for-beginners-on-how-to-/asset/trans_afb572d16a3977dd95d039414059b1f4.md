## 第 5 章：探索 PHP

在引入 PHP、MySQL 和 Apache 之后，你已经准备好开始编写代码了。与许多语言不同，PHP 不需要像编译器和调试器这样复杂的设备。实际上，你会发现可以直接将 PHP 输入到你当前的 HTML 文档中，只需少量更改，你就可以开始运行了。

在本章中，我们将首先向你演示 PHP 如何处理基础文本，然后进入基本的决策处理。你可以做的一些非常酷的事情，包括根据当前客户端的浏览器绘制图形，以及如果客户端使用的操作系统会让你的网站看起来很糟糕，则打印警告信息。通过 PHP，这些以及更多内容都是可以实现的，它让这些陷阱变得易于应对。

为了在 PHP 中编写某些有用的程序，你需要了解可重用的代码块，即函数，以及如何临时存储数据。我们讨论评估，它允许代码根据数学原则做出明智。

### 变量

由于我们预计你还没有过编程，我们得到变量是另一种想法。变量存储值，例如文本字符串“Hello!”或整数 1。变量可以在你的代码中重用，而不需要反复确定整数值。

- PHP 变量可以是字母、数字和下划线；例如 a-z、A-Z、0-9 和 _。
- PHP 变量对大小写敏感。
- 多个单词的变量可以使用下划线隔离；例如 $test_variable。
- 变量可以使用等号 (=) 赋值。
- 赋值后始终以分号 (;) 结束。
