When you achieve the command line, type mysql, and press Enter. The syntax for the mysql command is:

```
mysql -h hostname - u client -p
```

The default username is root if you've installed MySQL all PC. You can overlook the hostname flag and value. Enter your password when MySQL shows the “Enter password” prompt. If the password, username, and hostname are right, you will see a banner monitor like that demonstrated in Figure.

![](bbox=[0.136, 0.463, 0.863, 0.596])

To associate with the mysql database, type the accompanying at the MySQL brief:

USE mysql;

This returns:

Database changed

If your ISP supplied a different database name, use that rather than mysql.
