When the user clicks Go on the keyboard, the URL is loaded, and we tell the text field to dismissFirstResponder to dismiss the keyboard. We also reenable the web view. We put all of this in the delegate method textFieldShouldReturn:.

```objc

    [self loadURLFromTextField];
    [textField resignFirstResponder];
    [self enableWebView];
    return YES;
}
```
