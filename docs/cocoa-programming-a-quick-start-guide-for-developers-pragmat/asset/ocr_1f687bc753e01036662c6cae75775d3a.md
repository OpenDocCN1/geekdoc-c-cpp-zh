# 12.4 Requiring Methods

Remove the `@optional` line from the protocol, and click Build & Run. You’ll get warnings like these:

+   - Incomplete implementation of class `ActivityController`
+   - Method definition for `-applicationDidTerminate:` not found
+   - Method definition for `-applicationDidLaunch:` not found

Now that applicationDidLaunch: and applicationDidTerminate: are required, we’ll need to implement them in ActivityController.m:
