# 10.9  Solution: Adding an Activity Indicator

To start with, add this outlet to your MobileBrowserViewController header file:\n8:

```
Download iPhoneBrowser/MobileBrowser5/Classes/MobileBrowserViewController.h\n\n```objc\n#import <UIKit/UIKit.h>\n\n@interface MobileBrowserViewController : UIViewController\n                                      <UITextFieldDelegate> {\n    UIWebView *webView;\n    UITextField *address;\n    UIBarButtonItem *backButton;\n    UIBarButtonItem *forwardButton;\n    UIActivityIndicatorView *activityView;\n}\n@property(nonatomic,retain) IBOutlet UIWebView *webView;\n@property(nonatomic, retain) IBOutlet UITextField *address;\n@property(nonatomic, retain) IBOutlet UIBarButtonItem *backButton;\n@property(nonatomic, retain) IBOutlet UIBarButtonItem *forwardButton;\n@property(nonatomic, retain) IBOutlet UIActivityIndicatorView *activityView;\n@end\n```
```

Now open up the nib file, and drag an activity indicator view on top of the web view. Connect it to the outlet using the Connections inspector, and then use the Attributes inspector to set its Style to Large White and select the Hide When Stopped checkbox. Save your work, and return to Xcode.

We can make all of the changes we need in the webViewDidStartLoad: and webViewDidFinishLoad: methods. In addition, you can remove the call to enableWebView: in the textFieldShouldReturn: method. Let’s stop and take a look back at the code we’ve written in this chapter. I find it striking that we’ve implemented a web view, text field and its keyboard, Forward and Back buttons, and an activity indicator with so little code.

```
Download iPhoneBrowser/MobileBrowser5/Classes/MobileBrowserViewController.m\n\n```objc\n#import "MobileBrowserViewController.h"\n\n@implementation MobileBrowserViewController\n\n@synthesize address, webView, backButton, forwardButton, activityView;\n```
```
