# # Methods and Parameters

So, you’ve built a working web browser. On one hand, you’re feeling pretty good about yourself. You just dragged and dropped and connected some dots together and had yourself a web browser. That’s power.

On the other hand, it doesn’t feel like real programming. A *real* programmer wouldn’t use a bunch of GUI tools. Real programmers would build the objects with their bare hands. They would say “Arrrr” and make other pirate sounds while they wrestle with memory management. You aren’t going soft on me, are you? Come to think of it, you haven’t even built yourself a “Hello, World!” program yet.

Your “Hello, World!” program will have to wait until the next chapter. Before you start creating your own objects in code and writing your own methods, you need to get comfortable reading the Objective-C that sends a target an action and navigating the API documentation to find out which messages you can send to objects in the Cocoa APIs. This chapter is your introduction to messages in Objective-C and Cocoa.
