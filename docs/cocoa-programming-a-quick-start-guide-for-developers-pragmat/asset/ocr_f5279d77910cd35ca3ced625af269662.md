# 11.7  Solution: Registering for Notifications

Let’s start by registering for and responding to the launch notifications:

```
−(void) registerNotifications {
    NSNotificationCenter *defaultCenter = [[NSNotificationCenter alloc]
                                                    init];
    [defaultCenter addObserver:self
                       selector:@selector(applicationDidLaunch:)
                           name:NSWorkspaceDidLaunchApplicationNotification
                         object:nil];
}
```

The main change was specifying the name of the notification we’re listening for instead of getting all of them by specifying nil. I also changed the name of the callback method to applicationDidLaunch:.
