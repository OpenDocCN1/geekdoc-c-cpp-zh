I hope that you remembered to include the forward declaration for CurrentApp just below the import statement. The property declaration may look a little naked. Without garbage collection, the memory attribute would have to be retain. With garbage collection, this is equivalent to assign, and assign is the default value, so we can leave it out altogether.²

In ActivityController.m, you need to synthesize currentApp and create an instance of it in awakeFromNib. Be sure to import CurrentApp.h.

```
```objc
#import "ActivityController.h"
#import "CurrentApp.h"

@implementation ActivityController

@synthesize currentApp;

-(void)awakeFromNib {
    self.currentApp = [[CurrentApp alloc] init];
}
@end
```
