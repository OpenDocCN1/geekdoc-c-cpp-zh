If you need to wait until a task finishes before executing the next line in your program, then you'll add the block to a queue using the `dispatch_sync()` function. There are other techniques, such as groups, that you can use to coordinate what work gets done when. We won't be covering them in this book. Once you get your head around how to work with these basic options, you'll want to read Apple's *Concurrency Programming Guide* [App09c].
