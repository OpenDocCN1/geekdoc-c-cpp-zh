In this section, we’ll look at the defaults set in the registration domain. You can think of these as the factory settings—these are the values before the user makes any adjustments. Let’s set the value of should-LoadSavedRemovedApps to NO.

The best place to set the registration domain defaults is in an initialize method. The reason is that the initialize method is a class method that is called before any other method is called on HelloApplicationAppDelegate or a subclass. Anything in the initialize method will be done before anything else using our app delegate—even before the applicationDidFinishLaunching: method executes.

Download Persistence/HelloApplication40/HelloApplicationAppDelegate.m

```
```
+(void)initialize {
    NSDictionary *defaults =
        [NSDictionary dictionaryWithObject:[NSNumber numberWithBool:NO]
                                    forKey:@"LoadSavedRemovedApps"];
    [[NSUserDefaults standardUserDefaults] registerDefaults:defaults];
}
