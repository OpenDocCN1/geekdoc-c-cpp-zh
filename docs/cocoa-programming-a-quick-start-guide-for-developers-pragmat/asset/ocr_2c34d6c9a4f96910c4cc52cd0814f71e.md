# 4.9  Initializing Your Objects

When we create a new Greeter object, we allocate memory, and then we call the init method. But you’ve seen the Greeter. It doesn’t have an init method of its own. When you call init on an instance of Greeter, you are really calling init on Greeter’s superclass NSObject.
