Next let’s allow users to pause and resume the spinning:

```
```objective-c
- (IBAction)toggleIsSuspended:(id)sender {
    [queue setSuspended:![queue isSuspended]];
}
```
```

When you send the queue the message setSuspended:YES, the queue will be paused. As with cancel, the progress indicators that are currently spinning will continue to spin until they have finished, but no further indicators will spin until you send the queue the message setSuspended:NO.

Finally, we can create an array of the operations in the queue and ask each one if it is executing or in a ready state. Operations that are executing are also considered to be ready.

```
```objective-c
- (IBAction)queueStatus:(id)sender {
    NSArray *ops = [queue operations];
    int executing = 0;
    int ready = 0;
    for (NSOperation *operation in ops) {
        if ([operation isExecuting]) executing++;
        if ([operation isReady]) ready++;
    }
    NSLog(@"Status for %d operations: executing %d and %d are waiting.",
          [queue operationCount], executing, ready - executing);
}
```
```

This will generate reports like the following in the Console. After nine operations have completed, this is the report that I get:

```
```text
Status for 16 operations: executing 3 and 13 are waiting.
```
