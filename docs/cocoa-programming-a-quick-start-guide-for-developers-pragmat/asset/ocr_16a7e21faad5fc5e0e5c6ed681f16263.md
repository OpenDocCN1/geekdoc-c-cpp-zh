# 2.2 Creating the Appearance with Interface Builder

Double-click MainMenu.xib (English) in the Xcode window. This is your main nib file. A nib file contains all of the work you do in Interface Builder. You create, configure, and connect objects using graphical tools in Interface Builder. Each nib file is essentially a freeze-dried object graph that is reconstituted at runtime. This first application will have a single nib file. Later in the book you’ll build more complicated applications with more than one.
