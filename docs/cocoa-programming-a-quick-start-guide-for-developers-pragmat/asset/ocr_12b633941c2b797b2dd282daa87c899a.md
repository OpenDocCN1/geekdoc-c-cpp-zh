The data source now answers with the information for the application whose index in the array matches the row number.^4 And in each cell the data source responds with the value of the property that matches the cell's column's identifier. Pretty nifty.

Look how this simplifies the code—there are no choices to make. Better yet, we don't have to change this code if we introduce new columns.
