# Connect the Controller to Its Array

You connected the object controller to its object using the content outlet. This time you’ll bind the array controller to the array using the content array. Select the array controller, and open the Bindings inspector.

Under Controller Content, find Content Array. Select the “Bind to” checkbox, and choose Bookshelf in the drop-down list. Set the Model Key Path to bookList.
