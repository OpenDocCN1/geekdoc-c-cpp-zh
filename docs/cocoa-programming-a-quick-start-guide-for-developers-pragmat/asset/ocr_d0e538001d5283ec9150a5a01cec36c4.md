You started Interface Builder when you double-clicked MainMenu.xib. You should see several windows. One has the information for your menu bar, and another is titled MainMenu.xib and contains the File’s Owner and First Responder. The one you care about is empty except for the words *SimpleBrowser* in the title bar. This is the window we’ll use to hold all of our visual elements.

Open the Library using either ⌘ ⇧ L or Tools > Library. The Library is where you’ll find all the objects that Apple provides for you as well as objects that you will create in Xcode. You can navigate to the elements you want, or you can use the search box at the bottom of the window to filter the results. To see the components that Apple provides, check that the Objects tab is selected at the top and that Library is selected in the drop-down list just below the tab. Here I’ve typed *text* to find the text field box I want to use for URL entry.
