The AppControl class provides access to features exported by bada base applications such as dialling, access to the camera, and calendar entries. The AppManager class finds the specified control (the dialling control, for example) and returns it as an object type AppControl for use by the application.

The NotificationManager class includes methods to provide the user with notifications if a new message is received or something requires their attention.
