# 2.5 The App Icon

There is only one more thing to do to complete our app skeleton. Every app needs an icon. As we saw, the icon is displayed in the main menu, and provides the mechanism for the user to launch your app.

The app icon is defined as a property of the app project, and is easy to set. Select your project in Project Explorer, and select Project | Properties from the main menu to launch the Properties dialog.
