The custom drawing for the custom overlay panel is done in the CameraOverlayPanel’s OnDraw() method. The following steps are executed:

+   1. Create the canvas for the overlay panel and clear it.
+   2. Create an Image object and initialise.
+   3. Decode the image file into the decoded bitmap container, passing the local file path of the image file and colour format parameters.
+   4. Scale the bitmap container to the required size.
+   5. Set the masking colour so that any pixels of this colour will be treated as transparent.
+   6. Draw the bitmap on the overlay panel’s canvas.
