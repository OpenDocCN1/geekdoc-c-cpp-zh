The CloseDownloadFile() destroys the reference to the local file so that no further data can be written to it:

```
void
MainForm::CloseDownloadFile(Osp::Io::File* file)
{
    if(file)
    {
        delete file;
        file = null;
    }
}
```

When the file has been successfully downloaded, it can be used by the application as required.
