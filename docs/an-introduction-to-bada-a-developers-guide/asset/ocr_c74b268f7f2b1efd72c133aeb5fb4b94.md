# Privileges Required:

You will need at least the first privilege group in the table below to make use of the features of this namespace:

| Privilege group | Privilege level | Description |
|---|---|---|
| WIFI | NORMAL | Setting up an ad-hoc network, getting information on local WiFi devices |
| WIFI_MANAGER | SYSTEM | Establishing a connection to a specific access point |

# Prerequisites:

Wi-Fi must be activated on the device and you must be connected to a wireless network. Note that it is not possible to test Wifi functionality using the Simulator.
