With the SDK all set up, you’re ready to develop your own applications. We guide you through the bada development process in detail starting in Chapter 2.
Apart from the samples included with the SDK, another useful development resource is the extensive help system. To open the help choose Help | Help Contents in the IDE. Figure A.6 shows the help system. From here you can get more information about all of the bada namespaces and classes, the bada developer guide, and a guide to UI development.
