5. The false argument passed to the StartPreview() method indicates that the OnCameraPreviewed() method associated with the Osp::Media::ICameraEventListener class will not be called. If no processing of the frames created by the camera is required, this ability to not have the OnCameraPreviewed() can reduce the processing requirements of the application.
