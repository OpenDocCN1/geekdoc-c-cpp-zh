# Figure R2.7 Edit field with overlay keypad.

The IScrollPanelEventListener interface must be implemented in order to handle the events generated when the keypad is opened or closed, for example, for retrieval of the edited text string. The ITextEventListener interface must be implemented if the application needs to be aware of when the cursor moves within the Edit field. The IActionEventListener interface must be implemented if the Edit field is created with the optional keypad command button controls to handle the events generated when these buttons are tapped. The following code snippet shows an example of the MainForm class definition:

```
class MainForm :
    public Osp::Ui::Controls::Form,
    public Osp::Ui::IActionEventListener,
    public Osp::Ui::ITextEventListener,
    public Osp::Ui::IScrollPanelEventListener
{

// Construction
public:
    MainForm(void);
    ~MainForm(void);
```
