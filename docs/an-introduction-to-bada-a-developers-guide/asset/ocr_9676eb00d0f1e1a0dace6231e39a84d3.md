That's it. To capture and handle the Softkey event, in MainListForm.cpp we add an appropriate case at the top of the OnActionPerformed() switch statement:

```
switch (actionId)
{
    case ID_LEFT_SOFTKEY:
        ShowOptionMenu();
        break;
    case ID_OPTIONKEY:
        ShowOptionMenu();
        // ... etc

    default:
        break;
}
```
