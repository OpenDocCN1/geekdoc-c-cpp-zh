+     - CAMERA_ERROR_OUT_OF_MEMORY: insufficient memory;
+     - CAMERA_ERROR_DEVICE_FAILED: the camera device failed.

# Hints, Pitfalls, and Related Topics

It is advisable to implement the Osp::Media::ICameraEventListener class, even if you do not wish to process camera frames in the OnCameraPreviewed() method. This is simply because of the OnCameraErrorOccurred() method. At any time the camera could report an error. Implementing the ICameraEventListener interface class will allow to be informed of the error and take appropriate action.

Only subscribe to receive the camera frames in the OnCameraPreviewed() method, if you want to do any post-processing on the camera frames. Such processing could affect the performance of your application.

Currently, working on the target requires that you rotate through 90 degrees the OverlayPanel that will be used to display the camera frames. No such rotation is required when working on the Simulator.
