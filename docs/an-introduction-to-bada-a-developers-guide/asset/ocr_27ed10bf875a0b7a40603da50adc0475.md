In this recipe the facial comparisons are done in the OnCameraPreviewed() callback routine, which is called when a new frame is available. The first task is to call the FaceRecognizer's ExtractFaceInfoFromVideoStreamN() method and get a list of FaceRecognitionInfo objects.
