# 13.8.2 The try-catch-finally Statement

A try-catch-finally statement has this form and is used to catch certain exceptions thrown by trybody.

```
try
    trybody
    catchclause1;
    catchclause2
    ...
    finally
    finallybody
```

where trybody and finallybody are block statements. There may be zero or more catch clauses, and the finally clause may be absent, but at least one catch or finally clause must be present. No return or break or continue or goto can exit the finallybody. A catchclause must have one of these three forms:

```
catch (exceptiontype identifier)
    catchbody

catch (exceptiontype)
    catchbody

catch
    catchbody
```

where exceptiontype is an Exception or subclass (section 20) and identifier is a variable name. A catchbody is a block statement. A catch clause of the third form is equivalent to catch (Exception) and can occur only last. The clause (Ei) catchbody matches exception E if E is Ei or a subclass of Ei. Note that the third form catchbody matches all exception types.

The try-catch-finally statement is executed by trybody. If the execution of trybody terminates normally or by return (when inside a method or constructor) or break or continue (when inside a switch or loop) or by goto, then any catch clause is ignored.

If trybody throws an exception of class E, and one or more catch clauses (with exception types Ei...), the catch clauses are examined in sequence until the first matching clause (Ei), if any, located. If an exception variable x is declared in the first catch clause, then E is bound to x, and the corresponding clause is executed. The catchbody may terminate normally, or by exiting return or break or continue or goto or by throwing an exception. If there is no finally clause, this determines how the entire try-catch-finally terminates. A exception is never null (see 13.8.1), so x cannot be null either. If there is no matching catch clause, the entire try-catch-finally terminates abruptly by throwing exception e.

If there is a finally clause, then finallybody will be executed regardless of whether the execution of trybody terminated normally, whether trybody was exited by executing return or break or continue or goto, whatever exception thrown by trybody was caught by a catch clause, and whether the catchbody was exited by executing return, break, continue or goto or by throwing an exception.

If execution of finallybody terminates normally, then the entire try-catch-finally terminates as determined by trybody (or catchbody), if one was executed). If the execution of finallybody terminates abruptly by throwing an exception e2, then the entire try-catch-finally terminates with exception e2, and any exception thrown by the trybody (or catchbody) will be lost (example 162).
