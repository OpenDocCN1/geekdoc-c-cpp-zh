+   - IEnumerable<T> TakeWhile(Func<T,int,bool> p) returns an enumerable that generates the maximal prefix of the given enumerable consisting of items x for which p(x, i) is true, where x is at position i, counting from zero.

+   - T[] returns a new array that contains the items of the given enumerable.

+   - Dictionary<K,T> ToDictionary(Func<T,K>, Func<T,T> h) returns a new dictionary of type DictionaryKey that contains an entry (h(x), x) for each item x of the given enumerable. Throws ArgumentException if there are two items xi and xj for which h(xi) equals h(xj).

In comprehension notation, the key/value pairs of the new dictionary are ((h(x), x) | x-- xs)

+   - Dictionary<K,E> ToDictionary(Func<T,K>, Func<T,E> h, Func<T,E> f) returns a new dictionary of type DictionaryKey,E that contains an entry (h(x), f(x)) for each item x of the given enumerable. Throws ArgumentException if there are two items xi and xj for which h(xi) equals h(xj). In comprehension notation, the key/value pairs of the new dictionary are ((h(x), f(x)) | x-- xs)

These two methods overload that which take an explicit IComparer<K> as the last argument.

+   - List<T> returns a new List<T> that contains the items of the given enumerable.

+   - IEnumerable<T> ToLookup(Func<T,K>, Func<T,V> h) returns a new lookup structure (section 28.4) that contains an entry (k, vs) for each value k of h, and that vs is an enumerable of all x This is a grouping of the given enumerable items by the value k of h(x), where each group can be accessed by index. In comprehension notation, the key/value pairs of the lookup structure are ((k, x) | x-- xs, where h(x)=k) | h--distinct((h(x)))

+   - IEnumerable<T> ToLookup(Func<T,K>, Func<T,V> h, Func<T,V> f) returns a new lookup structure that contains an entry (k, vs) for each value k of h, and that vs is an enumerable of the values of f(x) for all x for which h(x) equals k. This is a grouping of the transformed values f(x) of the enumerable's items by the value k of h, where each group can be accessed by index k. In comprehension notation, the key/value pairs of the lookup structure are ((k, f(x)) | x-- xs, where h(x)=k) | h--distinct((h(x))))

These two methods overload that take an explicit IComparer<K> as last argument.

+   - IEnumerable<T> Union(IEnumerable<T>) returns an enumerable that generates each item in the given enumerable and each item in ys, without duplicates, comparing items by the default equality comparator. Also overloaded to take an explicit IComparer<T> as last argument.

+   - IEnumerable<T> Where(Func<T,bool> p) returns an enumerable that generates those those items x of the given enumerable for which p(x) is true. In comprehension notation: (x | x-- xs, where p(x)). See example 239. Typically used filter in functional languages.

+   - IEnumerable<T> Where(Func<T,int,bool> p) returns an enumerable that generates those items x of the given enumerable for which p(x,i) is true, where x is at position i, counting from zero. In comprehension notation: (x | (x,i) -> zip2(xs,0..), where p(x,i)).

+   - IEnumerable<T,U,R> Zip(IEnumerable<T>, IEnumerable<U>, Func<T,U,R> f) returns an enumerable whose ith item is the result f(x,y) of applying f to the ith item of xs and the ith item of ys. The length of the result is the shortest of xs and ys. InIn comprehension notation: (f(x,y) | (x,y) -> zip2(xs,ys)).
