# Example 232 Using a Queue in a Worklist Algorithm

Some algorithms use a worklist, represented by a queue, containing subproblems still to be solved. For instance, given a set ss of sets, one can compute its intersection closure: the least set tt that ss is a subset of tt and that for any two s and t in tt, their intersection ∩ t is also in tt. For instance, if ss is {{2,3}, {1,3}}, then tt is {{2,3}, {1}, {1,2}, {2}, {1}, {}}.

The set may be computed by putting all elements of ss in the worklist, repeatedly selecting an element from the worklist, adding it to tt, and for every set t in tt, adding the intersection of s and t to tt if not already in tt. When the worklist is empty, tt is intersection-closed. Sets are represented using class Set<T> (see example 220).

```
static Set<T> IntersectionClose<Set<T>> ss {
    Queue<T> worklist = new Queue<Set<T>>(ss);
    Set<T> tt = new Set<Set<T>>();
    while (worklist.Count != 0) {
        Set<T> s = worklist.Dequeue();
        foreach (Set<T> t in tt) {
            if (!tt.Contains(s))
                worklist.Enqueue(s);
        }
        tt.Add(s);
    }
    return tt;
}
```

# Example 233 Graph Traversal Using a Queue or Stack

A Node<T> is a node in a directed graph with a label of type T; a node has an array of neighbors. The root.VisitBreadthFirst() prints the labels of all nodes reachable from root node in breadth-first order: nodes already visited or in the worklist could be represented by Set<Node<T>> (example 226). Making a Stack instead of Queue would give depth-first traversal.

```
public void VisitBreadthFirst() {
    Dictionary<Node<T>, bool> visited = new Dictionary<Node<T>, bool>();
    Queue<Node<T>> worklist = new Queue<Node<T>>();
    visited.Add(root, false);
    worklist.Enqueue(root);
    while (worklist.Count != 0) {
        Node<T> node = worklist.Dequeue();
        Console.Write(" " + node.label);
        foreach (Node<T> neighbor in node.Neighbors) {
            if (!visited.ContainsKey(neighbor)) {
                visited.Add(neighbor, false);
                worklist.Enqueue(neighbor);
            }
        }
    }
}
```
