Example 145 A Struct for Rational Numbers
A rational number has the form n/d, where n and d are long arithmetic operators + can be represented as a struct of type Frac. Frac defines a constructor, overloaded arithmetic operators and *, an implicit version from long, an explicit conversion to double, comparison operators == and !=, methods Equals
GetHashCode, method CompareTo implements IComparable. Unfortunately the default constructor Frac() initializes n and d to zero, so the desirable invariant d != 0 does not hold.
Fortunately, computing with ill-formed Frac will DivideByZeroException (in auxiliary
method Gcd).
