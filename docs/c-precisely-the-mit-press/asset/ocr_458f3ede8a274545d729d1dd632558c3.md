# Example 107 Type Cases

The cast (long)i succeeds although i is false. In a case such as (C)s that involves a user-defined conversion, the type of s must be exactly the declared argument type of the conversion operator.

```
class B {
class C : B {
private String s;
public C(String s) { this.s = s; }
public static explicit operator C(String s) { return new C(s + s); }
}

int i = 471i;
long ll = (byte)i + (long)i; // Simple type conversions
String s = "ole";
B b1 = new C(""), b2 = new B();
C1 = (C)b1; // Succeeds, b1 has class C
C2 = (C)b2; // Fails, b2 has class B
C3 = (C)s; // User-defined conversion String->C
Object o = (Object)s; // Always succeeds
C4 = (C)(String)o; // Succeeds, Object-->String-->C
C5 = (o); // Fails, no Object-->C conversion
Array arr = (Array)s; // Rejected at compile-time
```
