- int Count() returns the number of items (example 244).
- int Count(Func<T,bool> p) applies to each item x and returns the number of items for which p(x) is true.
- IEnumerable<T> DefaultEmpty() returns an enumerable that generates the same items as the given enumerable, if non-empty; otherwise it generates the singleton-Enumerable containing the single item default(T).
- IEnumerable<T> DefaultEmpty(T x) returns an enumerable that generates the same items as the given enumerable, if non-empty; otherwise it generates the singleton enumerable containing the single item x.

The DefaultEmpty methods can be used to produce a left outer join when combined with the GroupJoin method (example 242).

- IEnumerable<T> Distinct(T x) returns an enumerable that generates each item of the given enumerable exactly once, distinguishing items by the default equality comparer. Also overloaded to take an explicit EqualityComparer<T> as last argument.
- T Element(int i) returns the item at index i, counting from 0. ThrowsOutOfRangeException if i<0 or if i is greater than equal to the number of items in the enumerable.
- T ElementAtDefault(int i) returns the item at index i, counting from 0. Returns default(T) if i<0 or if i is greater than equal to the number of items in the enumerable.
- IEnumerable<T> Except(IEnumerable<T> ys) returns an enumerable that generates those items not equal to any item in ys, comparing items by the default equality comparer. In comparison notation: (x | xs, where y in ys). Also overloaded to take an explicit EqualityComparer<T> as last argument.
- T First() returns the first item of the given enumerable, if non-empty. Returns InvalidOperationException if the enumerable is empty.
- T First(Func<T,bool> p) returns the first item x of the given enumerable for which p(x) is true, if any. Throws InvalidOperationException if there is no such item.
- T FirstDefault() returns the first item of the given enumerable, if non-empty; otherwise returns default(T).
- T FirstDefault(Func<T,bool> p) returns the first item x of the given enumerable for which p(x) is true, if any; otherwise returns default(T).
- IEnumerable<IGrouping<T,K>> GroupBy() returns an enumerable in which items x have been grouped by their value of h(x). Each group in the result is a pair (x, xs) whose members are x that have the same key k, as computed by h(x). In comparison notation: IGrouping<T,K> is described in section 28.A. Interface ((k, x | xs, where h(x)=k)) | k--((h(x)) | x)); the function distinct returns duplicate items.
- IEnumerable<IGrouping<T,K,E>> GroupBy(Func<T,K>, Func<T,E> f) returns an enumerable in which items x have been grouped by their value of h(x) and transformed by f(x). Each group in the result is a pair (k, vs) whose members are the values of f(x) for x that has the same key k, as computed by h(x). In comprehension notation: <(k, (f(x)) | x-xs, where h(x) = k)> | k distinct((h(x)) | x-xs)). See example 235.
- IEnumerable<R> GroupBy<K,R>(Func<T,K> h, Func<T,IEnumerable<R>> g) returns an enumerable that generates items r, each obtained as the value g(k, vs) whose members are the items that have the same key k, as computed by h(x). In comprehension notation: <g(k, (x | x-xs, where h(x) = k)) | k distinct((h(x)) | x-xs))>
- IEnumerable<R> GroupBy<K,R>(Func<T,K> h, Func<T> f, Func<T,IEnumerable<R>> g) returns an enumerable that generates items r, each obtained as the value g(k, vs) of applying g to a group (ks), whose members are the values of f(x) for those items x that have the same key k, computed by h(x). In comprehension notation: <g(k, (f(x) | x-xs, where h(x) = k)) | k distinct((h(x)) | x-xs))>

Each GroupBy also has an overload that takes an explicit EqualityComparer<K> as argument.

- IEnumerable<R> Join<U,K,R>(IEnumerable<T> xs, Func<T,K> fx, Func<U,K> fy, Func<T,U,R> g) returns an enumerable that generates items r, each obtained as the value of g(x,y), where x is drawn from the given enumerable xs, and y is the collection of items from y whose maps to the same key as x. In comprehension notation: <g(x,y) | y-ys, where fx(x) = fy(y)). See example 240.
Also overloaded to take an explicit EqualityComparer<T> as last argument.
- IEnumerable<T> Intersect(IEnumerable<T> ys) returns an enumerable that generates each item in the given enumerable for which there is an equal item in ys, comparing items by the default equality comparer. In comparison notation: <x | x-xs, where x is in ys>
Also overloaded to take an explicit EqualityComparer<T> as last argument.
- IEnumerable<T> Join<U,K,R>(IEnumerable<T> xs, Func<T,K> fx, Func<U,K> fy, Func<T,U,R> g) returns an enumerable that generates the values of g(x,y), where x is drawn from the given enumerable xs, and y is drawn from ys, and for fx(x).Equals(fy(y)). In comprehension notation: <g(x,y) | x-xs, y-ys, where fx(x) = fy(y)). See example 240.
Also overloaded to take an explicit EqualityComparer<T> as last argument.
- T Last() returns the last item of the given enumerable, if non-empty. Throws InvalidOperationException if the enumerable is empty.
- T Last(Func<T,bool> p) returns the last item x of the given enumerable for which p(x) is true, if any. Throws InvalidOperationException if the enumerable is empty.
- T LastDefault(Func<T,bool> p) returns the last item x of the given enumerable for which p(x) is true, if any; otherwise returns default(T).
- int LongCount() returns the number of items in the given enumerable.
- int LongCount(Func<T,bool> p) applies to each item x and returns the number of items for which p(x) is true.

- IEnumerable<R> Select(Func<T, R> f) returns an enumerable whose items are f(x1), f(x2), ... or in comprehension notation: f(x) | x <- xs. Typically called map in functional languages. See examples 235 and 238.
- IEnumerable<R> Select(Func<T, int, R> f) returns an enumerable whose items are f(x1, 0), f(x2, 1), ... or in comprehension notation: f(x, i) | x, i <- zip2(xs, 0) ... where zip2 creates pairs of items from pair of enumerables, and 0 is the enumerable whose items are 0, 1, and so on.
