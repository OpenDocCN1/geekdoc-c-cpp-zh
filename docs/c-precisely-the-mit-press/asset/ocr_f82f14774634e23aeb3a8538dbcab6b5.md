# 13.5 Choice Statements

# 13.5.1 The if Statement

An if statement has the form

```
if (condition)
    truebranch
```

The condition must have type bool, and the truebranch is a statement but not a declaration statement or a labeled statement. If the condition evaluates to true, the truebranch is executed; otherwise not.

# 13.5.2 The if-else Statement

An if-else statement has the form

```
if (condition)
    truebranch
else
    falsebranch
```

The condition must have type bool, and truebranch and falsebranch are statements but not declaration statements or labeled statements. If the condition evaluates to true, then truebranch is executed; otherwise falsebranch is executed.

# 13.5.3 The switch Statement

A switch statement has the form

```
switch (expression) {
    case constant;: branch1
    case constant;: branch2
    ...
    default: branchn
}
```

The expression must have type byte, byte, short, ushort, int, uint, long, char, String, an enum type, or a user-defined type with exactly one implicit conversion to one of these types (except an enum type). This is called the governing type of the switch statement. Each constant must be a compile-time constant. No two constants may have the same value. The type of each constant must be implicitly convertible to the type of expression.

Each branch is preceded by one or more case clauses, which may be terminated by return (if a method or constructor) or continue (if a loop) or goto or break or any other combination of statements that ensures the end of the branch is never reached. This is checked by the compiler. The default clause may be left out. It can appear anywhere among the other clauses, first or last to be the most sensible choices.

The switch statement is executed as follows. The expression evaluates to a value v. If the corresponding branch is executed. If v does not equal any of the constants, then the default is executed; if there is no default clause, nothing is executed. A branch may contain goto and goto default statements (section 13.7.5).
