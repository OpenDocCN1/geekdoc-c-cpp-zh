# Example 111 Lambda Expressions

A lambda expression such as (s => s.Length==3) is a predicate that tests whether the (String) argument has length 3. A typical use is to filter out items of an enumerable that have a particular property. Examples f1 and f2 show that the same expression may be used with two different types. Since a lambda expression has no type in itself (when the parameter is specified), it cannot be assigned to a var-declared variable not of a type of Object or dynamic.

Variables f3 and f4 show the same function add to x and y, but f1 takes both arguments at the same time, whereas f2 returns a function that takes x and y and then returns x+y. The function is associative, so (x+y)+z == x+(y+z).

As shown, a lambda expression can define a recursive function in two steps. These steps may be further hidden in a Recursive class, which has a recursive function.

# Example 112 Anonymous Object Expression

The anonymous object bound to p1 has x and y. The example 112 shows that the field names x and y may be inferred. Even though the types of p1 and p2 cannot be written, the compiler can infer p1.x and p2.have type int. p2.z can be cast to int, and p2.y has a Length property (it has String).

```
double z = 3.14;
var p1 = new { x = 13, y = "foo" }; // Fields: x, y
var p2 = new { x = 42, p1.y, z }; // Fields: x, y, z
int sum = p1.x + p2.x + p2.Length;
```
