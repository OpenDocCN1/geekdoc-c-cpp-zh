# Arrays

# 9 Arrays

An array is an indexed collection of zero or more variables, called elements. An array has a given element type t, which can be any type. The value of an expression of an array type such as t[] is either null or a reference to an array whose element type u is or implicitly converted to t. If it is a value type, u must equal t. Assignment of an array to a variable assigns only the reference; it does not copy the array, as illustrated by arr1 and arr2 in example 71.

# 9.1 One-Dimensional Arrays

In an array with rank l and length l, the elements are indexed by the integers 0, 1,...,l-1. An array of length l with element type t is created (allocated) using an array creation expression, which can take two forms. The first form of array creation expression is

```
t[l]
```

where l is an expression of type int. This creates a new array with rank 1, also called a one-dimensional array, with l elements, all initialized with the default value for type t (section 6.2). The size argument may be zero, or if it is negative OverflowException is thrown.

The second form of array creation expression explicitly lists the elements of the new array

```
t[] = { expression, ..., expression };
```

The type of each expression must be implicitly converted to t. This array creation expression is evaluated by creating a new array of rank 1 whose length equals the number of expressions. Then the expressions are evaluated from left to right, and their values are converted to type t and stored in the array.

A local variable or field of array type may be initialized at declaration, assigning null or an array to it. When an array expression is used to initialize an array at its declaration, new t[] may be left out, so equivalent:

```
t[] = { expression, ..., expression };
```

Note that the declared variable cannot occur in expression: it has not been initialized when the expressions are being evaluated. Also note that there are no array constants: a new distinct array is created every time array creation expression.

Let be an array expression of type t[] whose value is an array of length l with element type u. The array access expression a[i] denotes element number i of a, counting from 0; this has type t. The integer i is the array index. If the value of i is less than 0 or greater than equal to l, then IndexOutOfBoundsException is thrown.

When the element e is a reference type, every array assignment a[i]=e checks the value of e is null or implicitly convertible to the element type u. If this is not the case, an ArrayMismatchException is thrown. This check is made before every array assignment at run-time, but only for reference types. For value types, the type check is performed at compile-time.
