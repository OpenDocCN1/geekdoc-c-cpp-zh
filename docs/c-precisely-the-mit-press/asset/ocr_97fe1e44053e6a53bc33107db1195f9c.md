# 27.10 The Queue<T> Class

An instance of System.Collections.Generic.Queue<T> is a queue, in which elements can be added at the end and removed from the front. This is useful for implementing worklist algorithms and breadth-first traversal. The queue is stored in an underlying array that is automatically extended as needed. Class Queue<T> implements ICollection and has the following additional members:

+   * Constructor Queue() creates a new empty queue.
* Constructor Queue(int capacity) creates a new empty queue with the initial capacity.
* Constructor Queue(IEnumerable<T> enm) creates a new queue, enqueueing the elements produced by enm.
* Dequeue() returns and removes the element at the head of the queue. Throws InvalidOperationException if the queue is empty.
* void Enqueue(T x) adds element x at the end of the queue.
* Peek() returns the element at the head of the queue without removing it. Throws InvalidOperationException if the queue is empty.
* T[]ToArray() returns a new array containing the elements of the queue.
* void TrimSize() trims the underlying array to the actual number of elements in the queue.

# 27.11 The Stack<T> Class

An instance of System.Collections.Generic.Stack<T> is a stack, in which elements can be added and removed only one end, the stack top. This is useful for implementing worklist algorithms and depth-first traversal. The stack is stored in an underlying array that is automatically extended as needed. Class Stack<T> implements ICollection<T> and has the following additional members:

+   * Constructor Stack() creates new empty stack.
* Constructor Stack(int capacity) creates a new empty stack with the initial capacity.
* Constructor Stack(IEnumerable<T> enm) creates a new stack, pushing the elements produced by enm.
* Peek() returns the element at the stack top without removing it. Throws InvalidOperationException if the stack is empty.
* Pop() returns and removes the element at the top of the stack. Throws InvalidOperationException if the stack is empty.
* void Push(T x) adds element x at the top of the stack.
* T[]ToArray() returns a new array containing the stack elements; the stack top is in position 0.
* void TrimSize() trims the underlying array to the actual number of elements in the stack.
