## Example 114 Statement Termination
Execution of a statement may (1) terminate normally, meaning execution will continue with the next statement, if any; or (2) terminate abruptly by throwing an exception; or (3) exit by executing a return statement, if inside a method or constructor; or (4) exit a switch or loop by executing a break statement; or (5) exit the current iteration of a loop and start a new iteration by executing a continue statement; or (6) exit by executing a goto statement; or (7) not terminate at all, for instance, by while (true).

```c
public static void Statement(int choice) {
    boolean again = true;
    while (again) {
        again = false;
        if (choice == 1) // Terminates normally
            Console.WriteLine("Choice 1");
        else if (choice == 2) // Throws exception
            throw new Exception();
        else if (choice == 3) // Returns from method
            return;
        else if (choice == 4) // Breaks out of loop
            break;
        else if (choice == 5) // Continues at loop
            continue;
        else if (choice == 6) // Jumps out of loop
            goto end;
        else // Loops forever
            while (true) {
                Console.WriteLine("At end of loop");
            }
    }
    Console.WriteLine("After loop");
}
Console.WriteLine("At end of method");
```

## Example 115 Common Expressions: Assignment and Method Call
An assignment statement x= is an assignment x= followed by a semicolon. A method call statement M(...); is a method expression M(...). The value returned by the method, if any, is discarded; the method is executed only for its side effect.

# 13.5 Choice Statements

### 13.5.1 The if Statement
An if statement has the form

```c
if (condition)
    truebranch
```

The condition must have type bool, and the truebranch is a statement but not a declaration statement or labeled statement. If the condition evaluates to true, the truebranch is executed; otherwise not.

### 13.5.2 The if-else Statement
An if-else statement has the form

```c
if (condition)
    truebranch
else
    falsebranch
```

The condition must have type bool, and truebranch and falsebranch are statements but not declaration statements or labeled statements. If the condition evaluates to true, then truebranch is executed; otherwise falsebranch is executed.

### 13.5.3 The switch Statement
A switch statement has the form

```c
switch (expression) {
    case constant: branch1;
    case constant: branch2;
    ...
    default: branch;
}
```

The expression must have type byte, byte, short, ushort, int, uint, long, char, String, an enum type, or a user-defined type with exactly one implicit conversion to one of these types (except enum type). This is called the governing type of the switch statement. Each constant must be compile-time constant. No two constants may have the same value. The type of each constant must be convertible to the type of expression. Each branch is preceded by one or more case clauses, which may be terminated by return (if a method or constructor) or continue (if a loop) or goto or any other combination of statements that ensures the end of the branch is never reached. This is checked by the compiler. The default clause may be left out. It can appear among the other clauses, first or last to be the most sensible choices. The switch statement is executed as follows: The expression evaluates to a value v. If the corresponding branch is executed. If v does not equal any of the constants, then the default is executed; if there is no default clause, nothing is executed. A branch may contain goto statements (section 13.7).

## Example 119 Sequence of if-else Statements
A sequence of if-else statements is useful for finding the interval to which a value belongs.

```c
static String AgeGroup(int age) {
  if (age <= 12) return "child";
  else if (age <= 19) return "teenager";
  else if (age <= 45) return "young";
  else if (age <= 60) return "middle-age";
  else
    return "old";
}
```

## Example 120 switch Statement
Method FindCountry finds the corresponding branch to a given phone number prefix. This could be done using a sequence of if-else statements, but a switch is faster and clearer. Note that the default case need not be the last one.

```c
static String FindCountry(int prefix) {
  default: return "Unknown";
  case 1: return "North America";
  case 44: return "Great Britain";
  case 45: return "Denmark";
  case 299: return "Greenland";
  case 46: return "Sweden";
  case 7: return "Russia";
  case 972: return "Israel";
}
```

# 13.6 Loop Statements

### 13.6.1 The for Statement
A statement has the form

```c
for (initialization; condition; step)
body
```

where initialization is a local variable declaration (section 13.4) or a possibly empty comma-separated list of method call expressions, assignment expressions, object creations, increment expressions, and decrement expressions; condition is an expression of bool; step is a possibly comma-separated list of the same kinds of expressions allowed for initialization; and body is a statement but not a declaration statement or a labeled statement. Comma-separated lists of expressions are evaluated from left to right when the list is evaluated. The initialization, condition and step may be empty. An empty condition is equivalent to true. Thus for(;;) body means “forever execute body.”

1. The initialization is executed.
2. The condition is evaluated. If it is false, the loop terminates.
3. If it is true, then:
   (a) the body is executed;
   (b) the step is executed;
   (c) execution continues at 2.

### 13.6.2 The foreach Statement
A foreach statement has the form

```c
foreach (type x in expression)
body
```

where the expression must be enumerable, and its enumerators produce elements that can be explicitly converted to type. The body must be a statement but not a declaration statement or a labeled statement. If the keyword was used instead of type, then the compiler infers the type of x from the element type of the enumerable expression (section 6.3).

First the expression is evaluated to obtain an enumerator. Then the body is evaluated for each element produced by the enumerator, with variable x bound to the result of converting the element to type, possibly by an unboxing conversion. If the element cannot be converted to type, an InvalidCastException is thrown. The scope of local variable x is body, and the body is read-only; it cannot be assigned to or as a ref or out parameter. The body should not modify the enumerator or any data under the enumerator. The expression of type t is enumerable in the following cases:

* In particular, class Array and hence all array types (section 9) implement IEnumerable, and array type T implements IList<U> implement IEnumerable<U> whenever T[] is implicitly convertible to U[].
* It implements a public instance method GetEnumerator() with return type that implement implement a public instance method Next() with return bool and a public instance property Current, as required by interface IEnumerator (section 27.2). See examples 64 and 68.
