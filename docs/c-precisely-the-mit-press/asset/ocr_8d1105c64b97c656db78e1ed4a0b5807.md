# Example 18 Equality of Strings

The comparison operator == applied to string types compares the contents of the strings: the character sequences. When applied to object type, it compares the objects. Two strings that can have the same character sequences may be represented by a single string object (s1 and s2) if they are compile-time constants; otherwise they are not (s2 and s4).

```
String s1 = "abc", s2 = "abc" + "c", s3 = null; // Compile-time constants
String s4 = args[0]; // Value given at run-time
// Assume line argument args[0] is "abc" so s4 is "abc"
Console.WriteLine(s1==s2); // True
Console.WriteLine((Object)s1==(Object)s2); // Probably True
Console.WriteLine(s2==s4); // True
Console.WriteLine((Object)s2==(Object)s4); // Probably False
Console.WriteLine("(0) {1}", s3=s1, s1=s1, s3=s3); // False True
```

# Example 19 Counting the Number of c's in a String Using a String Indexer

```
static int eCount(String s) {
  int count = 0;
  for (int i=0; i<s.Length; i++)
    if (s[i] == 'e')
      count++;
  return count;
}
```

# Example 20 Concatenating All Command Line Arguments

When concatenating strings, do not use ++ but but a string builder (section 8 and example 31).

```
public static void Main(String[] args) {
  String res = ""; // Inefficient
  for (int i=0; i<args.Length; i++) // Inefficient
    res += args[i]; // Inefficient
  Console.WriteLine(res);
}
```

# Example 21 The + Operator Is Associative

```
Console.WriteLine(10 + 25 + "A"); // Same as (10 + 25) + "A", that is, "35A"
Console.WriteLine("A" + 10 + 25); // Same as ("A" + 10) + 25, that is, "A1025"
```
