Example 197 Using non-generic ArrayList: Run-Time Checks and Wrapping of Values
The legacy non-generic ArrayList cool should only contain Person objects, but without generic types, the compiler cannot check that only Person objects are added to cool. Hence at run-time the program must check and cast objects when extracting them from the list. These checks take time, and may fail.

```
SC.ArrayList cool = new SC.ArrayList(); // needs SC = System.Collections;
cool.add(new Person("Kristen"));
cool.add(new Person("Bjarne"));
cool.add(new Exception("Larry"));
cool.add(new Person("Anders"));
Person p = (Person)cool[2]; // Wrong, but no compile-time check
```

Example 198 Using Generic Array List: Compile-Type Checks, Wrapping of Values
With generic types, cool can be declared to have type SC.Collections.List<Person>, the compiler can check that only Person objects are added to the cool.add, and therefore the list can contain only Person objects. At run-time there is no need to check and cast objects when extracting from the list. Generic types improve speed and safety of the program.

```
List<Person> cool = new List<Person>();
cool.add(new Person("Kristen"));
cool.add(new Person("Bjarne"));
cool.add(new Exception("Larry"));
cool.add(new Person("Anders"));
Person p = cool[2]; // Wrong, detected at compile-time needed
```

# Example 199 A Generic Class for Logging

Generic class Log<T> is similar to class Log (example 66), but can log any type of object, not just strings. The use of default(T) instead of null in the Last property; null is not a result of error when Last is initialized with a value type. Compare also the automatically implemented properties (section 10.15) InstanceCount and Count with the one in example 66.

```
public class Log<T> {
    private const SIZE = 5;
    public static int InstanceCount { get; private set; } // Auto-implemented property
    public int Count { get; private set; } // Auto-implemented property
    private T[] log = new T[SIZE];
    public Log() { InstanceCount++; }
    public void Add(T msg) { log[Count % SIZE] = msg; }
    public T Last {
        return Count==0 ? default(T) : log[Count-1]%SIZE];
    }
    set { ... }
}
    public T[] All { ... }
}
```
