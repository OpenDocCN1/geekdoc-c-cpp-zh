# 12 Expressions

An expression is evaluated to obtain a value such as 117 or true. In addition, evaluation of an expression may change the computer's state: the values of variables, fields and array elements, the contents of files, and so on. More precisely, evaluation of an expression

+   * terminates normally, producing a value, or
* terminates abruptly by throwing an exception, or
* does not terminate at all (for instance, it calls a method that does not terminate).

One distinguishes the compile-time type of an expression from the run-time type of its value. An expression has a compile-type inferred by the compiler: when it is a reference type t, and the run-time value of the expression is o, the run-time type of o is a class that is implicitly convertible to t but not necessarily equal to t. For instance, the expression (Object)*"foo" has compile-type t, but its run-time value is an object of String, a subclass of Object.

In the argument and return type columns of the table, integer stands for byte, byte, short, int, uint, long, and numeric stands for float, double, or decimal.

Before the operation is performed, its operands are promoted, and converted to a promotion type by implicit conversion (section 5.3.1).

For the unary operators += the promotion type is if the type of the operand is byte, short, and for the operator - the promotion type is long if the type of the operand is uint. Otherwise the promotion type is the type of the operand type.

For an operator with two numeric operands (the shift operators, section 12.5, and enums, section 16), the promotion is decimal if any operand has decimal (the other cannot be double or float); otherwise it is double if any operand has double; it is float if any operand has float; otherwise it is long if any operand has long type (the other operand cannot have a signed type); otherwise it is long if any operand has long type, or if any operand has uint type and the other has a signed type; otherwise it is uint if any operand has uint type; otherwise it is int.

If the result is given as numeric also, it equals the promotion type. For example, 10 / 3 has type int, whereas 10 / 3.0 has type double, and c + (byte)1 has type int when c has type char.
