Example 245 Query Continuation with Filtering: SQL HAVING
As in 243, the groups are bound to range variable g. Here, in addition, the groups are filtered on size to discard groups that contain one item, the only group with key 2 is output. This is similar to SQL's SELECT ... GROUP BY x#3 HAVING COUNT(*)>1.

```
Show(from x in xs // 2
group x*x by x#3
into g
where g.Key > 1
select g.Key);
Show(xs.GroupBy(x => x#3, x => x*x).Where(g => g.Count()>1).Select(g => g.Key));
```

Example 246 Combining group by. into, and where
This example, from Microsoft Visual Studio Linq samples, groups a stream of products into groups by product category (group by), finds the price of the cheapest product in group (let), and uses the Where extension method on each product g to find all the cheapest products within the group. For efficiency, it is important to compute min outside the Where call; otherwise the minimum would be recomputed for each product in the group, taking time quadratic in the size of the group, which could be very slow.

```
from p in products
group p by p.Category
into g
let min = g.Min(p => p.UnitPrice)
select new (Category = g.Key, Cheapest = g.Where(p => p.Price == min));
```
