Example 177 Parallel Asynchronous Data Retrieval
To retrieve many proteins, one may use asynchronous method NbiProteinAsync (example 176). The from expression creates and starts a task for each protein ID, and WhenAll creates a task that waits for all of them to complete and collects the results and returns them in an array.

```csharp
public static async Task<String[]> NbiProteinParallelAsync(params String[] ids) {
    IEnumerable<Task<String>> tasks = from id in ids select NbiProteinAsync(id);
    return await Task.WhenAll(tasks);
}
```

Example 178 Composite Asynchronous Data Retrieval
A query to the PubMed publication database at NCBI must be done in two steps: first an search query that returns an XML document containing a WebEnv key; then an fetch query that gets the actual results. The asynchronous method performs such a two-step query, calling asynchronous method NbiEntrezAsync(example 176) twice. Because the result is a task, one could further add a timeout (example 179) or use WhenAll to perform many such two-step queries in parallel (example 177).

```csharp
public static async Task<String> NbiPubMedAsync(String term) {
    String search = String.Format("etch.fcgi?db=PubMed&retmode=l&term={0}", term);
    XmlDocument xml = new XmlDocument();
    xml.LoadXml(await NbiEntrezAsync(search));
    XmlNode node = xml["EsearchResult"];
    String fetch = String.Format("retmax=3&db=PubMed&query_key={0}&WebEnv={1}", node["Query"].InnerText, node["WebEnv"].InnerText);
    return await NbiEntrezAsync("etch.fcgi?retype=abstract&retmode=text" + fetch);
}
```

Example 179 Implementing Timeout with async and await
A timeout (example 173) can be implemented using async methods and await.

```csharp
public static async Task<double> SlowTimeout2Task(int n) {
    Task<double> slowFibTask = SlowFibTask(n);
    Task completed = await Task.WhenAny(slowFibTask, Task.Delay(1000));
    return completed == slowFibTask ? slowFibTask.Result : -1;
}
```

## 24 Mathematical Functions

Class Math provides static methods to compute mathematical functions. Floating-point numbers (double and float) conform to IEEE754 include positive and negative infinities as non-numbers, called NaNs. There is also a distinction between positive zero and negative zero, ignored here.

These methods return non-numbers (NaNs) when applied to illegal arguments, called NaNs, and return infinities in case of overflow; do not throw exceptions. They behave sensibly when applied to positive or negative infinities; they return the limit if it exists, or else NaN. The methods round to the nearest even integer in case of a tie. The methods Abs and Sign are overloaded on arguments of type float, int, long, byte, and short; the methods Min and Max are overloaded on the unsigned types.

- * static double E is the e≈2.71828, the base of the natural logarithm.
- * static double PI is the constant π≈3.14159, the circumference of a circle with diameter 1.
- * static double Abs(double x) is the absolute value: if x<0, and -x if x<0.
- * static double Acos(double x) is the arc cosine of x, in the range [0,π], for -1<=x<=1.
- * static double Asin(double x) is the arc sine of x, in the range [-π/2,π/2], for -1<=x<=1.
- * static double Atan(double y, double x) is the arc tangent of y/x in the quadrant of (x, y), in the range [-π,π]. When x is 0, the result is π/2 with the same sign as y.
- * static double Ceil(double x) is the smallest integral value >=x.
- * static double Cos(double x) is the cosine of x, in the range [-1,1].
- * static double Exp(double x) is the exponential of x, that is, e to the power of x.
- * static double Floor(double x) is the largest integral value<=x.
- * static double IEEERemainder(double x, double y) is the remainder of x/y, that is, x-y*, where n is the closest to x/y. May be negative when x is negative and y is positive.
- * static double Log(double x) is the base e logarithm of x, for x>=0.
- * static double Log10(double x) is the base 10 logarithm of x, for x>0.
- * static double Min(double x, double y) is the smallest of x and y.
- * static double Pow(double x, double y) is x to the power of y, that is, x^y. If y is 1, the result is x. If y is 0, then the result is 1.
- * static double Round(double x) is the whole number that is closest to x, rounded to d.
- * static double Sin(double x) is the sine of x.
- * static int Sign(double x) returns +1 or 0 or -1.
- * static double Sqrt(double x) is the square root of x, for x>=0.
- * static double Tan(double x) is the tangent of x.

# Example 180 Floating-Point Factorial
This method computes the factorial $n! = 1 \cdot 2 \cdot 3 \cdots (n-1) \cdot n$ using logarithms.

```csharp
static double Fact(int n) {
    double res = 0.0;
    for (int i=1; i<n; i++)
        res += Math.Log(i);
    return Math.Exp(res);
}
```

# 25 Input and Output

Sequential input and output objects called streams. There are two kinds of streams: character streams and byte streams, also called text streams and binary streams. Character streams are used for input from text files and human-readable output to text files, printers, and so on, using 16-bit Unicode characters. Byte streams are used for compact and efficient input and output of simple data (int, double, ...) as well as objects and arrays, in machine-readable format.

There are separate classes for handling character streams and byte streams. The classes for character input and output are called Readers and Writers. The classes for byte input and output are called Streams. This section describes input and output using the System.IO namespace.

One can create subclasses of the stream classes, inherited methods to obtain specialized stream classes. This is not further discussed here.

The class hierarchies are shown in the following table, with related input and output classes shown on the same line. The table shows, for instance, BufferedStream and FileStream are subclasses of Stream, and that StreamReader is a subclass of TextReader. Abstract classes are in italics.

## 25.1 Creating Streams

An input stream or reader has an underlying source of data to read from, and an output stream or writer has an underlying sink of data to write to. A stream may either be created outright (e.g., a StreamReader may be created and associated with a named file on disk, e.g., for reading from file) or created from an existing stream to provide additional features (e.g., a BufferedStream may be created from a Stream for more efficient input).
