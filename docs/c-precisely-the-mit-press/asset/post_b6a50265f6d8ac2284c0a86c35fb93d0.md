# Example 58 String Concatenation with Extension Method

An extension method may be added to a particular array type as String[] or to a particular instance of a generic type. If ss has type String[], then one can call ss.Concat(", ") to format the array elements comma-separated values.

```csharp
public static class StringArrayExtensions {
    public static StringBuilder Concat(this[] arr, string sep) {
        StringBuilder sb = new StringBuilder();
        if (arr.Length > 0) {
            sb.Append(arr[0]);
            for (int i = 1; i < arr.Length; i++) {
                sb.Append(sep).Append(arr[i]);
            }
        }
        return sb.ToString();
    }
}
```

# Example 59 Extension Method with Type Constraint

An extension method may be added to a particular type instance of a generic type, restricted by a type constraint. This extension method can be called only on type instances IEnumerable<T> which implements IComparable<T>, such as IEnumerable<int> or IList<int> or int[] or List<String>

```csharp
public static bool IsSorted<T>(this IEnumerable<T> xs) where T : IComparable<T> {
    var etor = xs.GetEnumerator();
    if (etor.MoveNext()) {
        T prev = etor.Current;
        while (etor.MoveNext()) {
            if (prev.CompareTo(etor.Current) > 0)
                return false;
            } else {
                prev = etor.Current;
            }
        }
    }
    return true;
}
```

# 10.11 Constructor Declarations

The purpose of an instance constructor in class C is to initialize a new object (instance) of the class. A constructor-declaration in class C has the form

```
constructor-modifier (formal-list)
constructor-body
```

The constructor-modifier is one of the member access modifiers (section 10.3), and the formal-list is as a method (section 10.7). A constructor cannot be abstract or sealed. For the static constructor, see 10.12. A constructor has no return type.

Instance constructors may be overloaded in the same way as methods: the constructor signature (a list of the parameters in formal-list) is used to distinguish constructors in the same class. A constructor may call another overloaded constructor in the same class using the syntax

```
constructor-modifier (formal-list) : this(actual-list)
constructor-body
```

but a constructor may not call itself, directly or indirectly. The argument expressions in actual-list are static code and cannot use the object reference this or any instance member of class C, but can use the parameters from formal-list.

The constructor-body is a block-statement (section 13.2) and may contain statements with declarations of variables. The constructor-body may contain return statements, but no return statement can take an argument expression.

A class that does not explicitly declare a constructor implicitly declares a public, default constructor whose only action is to call the base class constructor (section 10.4):

```csharp
public C() : base() {
```

When new creates a new object in the computer store (section 12.9), a constructor is called to initialize the fields of the class. The first initializers of the object's instance fields are executed, in order of appearance in the class declaration. Then either constructor this(...) in the same class or base class constructor base(...) is called (explicitly or implicitly; see examples 62 and 98). Finally, the body of the constructor is executed (example 63).

The call to a base class constructor will cause a call to a constructor in its base class, and execution of its instance initializers, and so on, until the constructor Object().

# 10.12 Static Field Initialization and the Static Constructor

A static field of an object may be initialized by a static field initializer (section 10.5) or by a parameterless static constructor, declared as follows:

```
static C()
block-statement
```

See example 56. All static initializers are executed, in order of appearance in the class declaration, when the class is loaded. Then the body of the static constructor (if any) is executed. If the execution of a static field initializer or a static constructor throws an exception (section 20), then a TypeInitializationException is thrown instead, and the class is not loaded.

Example 63 The Execution Order of Initializers and Constructor Bodies
Evaluating new C() will execute the instance initializers in class C, execute the instance initializers in class B, execute the body of the B() constructor, execute the body of the C(int) constructor, and finally execute the body of C(). That is, it will print 1 2 3 4 5 6 7.

class C : B {

# 10.13 Member Classes or Nested Classes

A nested class is declared inside another class or struct type. The code of a nested class may refer to all static members, even private ones, of the enclosing class or struct type but cannot refer to its members except through a reference to an instance of the enclosing class or struct type. In contrast to Java, C# has no notion of an inner class, whose instances would contain a reference to an instance of the enclosing class.

A member used in a nested class denotes a member from the innermost enclosing class that declares or inherits a member of that name. That is, if class C has base class B and is declared as a nested class in E, then name resolution in C prefers members declared in C or (non-private) members inherited from base class B over members of the enclosing class E (example 90).

A nested class may have static members as well as instance members.

# 10.14 Class Access Modifiers

The class-modifiers (section 10.1) may include an access modifier to control the accessibility of the class. For a class declared at top level in a compilation unit or at top level a namespace (section 29), the access modifier may be public or absent (which means internal). A public top-level class is accessible in all assemblies; an internal top-level class is accessible only in the assembly (section 1.1) to which it belongs.

For a class declared inside a class or struct type, the access modifier may be one of the member access modifiers (section 10.3).
