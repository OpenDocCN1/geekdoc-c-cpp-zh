# Interfaces

# 15 Interfaces

# 15.1 Interface Declarations

An interface describes methods, properties, indexers, and events but does not implement them. An interface-declaration may contain method descriptions, indexer descriptions, and event descriptions. The descriptions in an interface may appear in any order:

```
interface-modifiers interface I base-interfaces {
  method-descriptions
  property-descriptions
  indexer-descriptions
  event-descriptions
}
```

An interface may be declared at top level or inside a namespace or class or struct. At top level in a namespace, the interface-modifiers may be public or internal (which means internal). Inside a class or struct, the interface-modifiers may be any of the member modifiers (section 10.3). In a class it may also be to hide an interface inherited from a base class.

An interface declaration consists of one or more partial type declarations (section 30). The base-interfaces clause may be absent. Otherwise the interface declaration has this

```
interface-modifiers interface I : I1, I2, ... { }
```

Where I1, I2,... is a non-empty list of interfaces. If the base-interfaces clause is present, then interface I describes all members described by I1, I2,..., and is a subinterface of I1, I2,.... Interface I can describe additional methods, properties, indexers, and events not described by the base interface I1, I2,..., and it may hide inherited members by describing new members. A method-description for method M must have the

```
description-modifier returntype M(format-list);
```

where the description-modifier should be new if the description hides a member inherited from a base interface such as II (otherwise a compiler is given). No access modifiers can be given; all interfaces are implicitly public. A property-description for a property P must have the

```
description-modifier returntype P {
  get;
  set;
}
```

where one of get and set may be left out. An indexer-description must have the

```
description-modifier returntype this[format-list] {
  get;
  set;
}
```

where one of get and set may be left out. An event-description for an event E must have the

```
description-modifier event delegate-type E;
```
