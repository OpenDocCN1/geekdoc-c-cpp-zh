# Example 109 Anonymous Method Compatibility

The anonymous method d11 is compatible with D1 but not D2; the anonymous method d21 is compatible
with D2 but not D1; and d22 is compatible with D2 and D3 but not D1. None of the anonymous methods
are compatible with D4. The foreach loop calls anonymous methods; each of the calls to d21 and
the anonymous method created by M(4) increments the ref parameter y by 1.

```
delegate D1(int x, ref y, int z);
delegate D2(int x, ref y, int z);
delegate D3(int x);
delegate D4(int x, ref y);
class {
    static D1 d1 = delegate(int x, ref y, int z) { z = y++; return x + y; };
    static D2 d21 = delegate(int x, ref y) { y+=2; return x + y; };
    static D2 d22 = delegate { return 5; };
    public static D2 M(int mx) {
        if (mx < 6)
            return delegate (int x, ref y) { y+=2; return x + y; };
        else
            return delegate { return mx; }
    }
    public static void Main(String[] args) {
        D2[] ds = { d21, d22, M(4), M(7), delegate { return 8; } };
        int y = 0;
        foreach (D2 d in ds)
            Console.WriteLine(d, y)); // Prints 4 5 6 7 8
        Console.WriteLine(y); // Prints 4
    }
```

# Example 110 Local Variables Captured in an Anonymous Method

The local variables u and v get captured in the anonymous methods in the loop body. Since u is declared
outside the for loop, only one instance of the variable is created, and all anonymous methods in udlg
to that one instance. Since v is declared, a separate instance of the variable is created
for each iteration of the loop, and each anonymous method in vdlg has its own instance. Thus the\single u is incremented five times, and each v is incremented once.

```
public static void Main(String[] args) {
    D[] udlgs = new D[5], vdlg = new D[5];
    int u = 0;
    for (int i=0; i<5; i++) {
        int v = 0;
        udlgs[i] = delegate () { u++; Console.Write(u); };
        vdlg[i] = delegate () { v++; Console.Write(v); };
    }
    foreach (D lg in udlgs) dlg(); // Prints 12345
    foreach (D lg in vdlg) dlg(); // Prints 11111
}
delegate void D();
```
