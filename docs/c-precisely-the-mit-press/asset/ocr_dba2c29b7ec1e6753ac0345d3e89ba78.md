Example 256 C# Features Not Found in Java
This example uses a generic class LinkedList<T> (example 200) to highlight some non-Java features: a property, an indexer, the yield keyword, explicit interface implementation, exact run-time type test on generic, an explicit conversion, an overloaded operator (+), methods that delegate parameters, and compile-time type inference (var).
