
## 25.7.2 Byte Input and Output from a Byte Array: MemoryStream

A MemoryStream is a Stream that reads from or writes to a byte array in memory. A memory stream has a capacity indicating the maximum number of bytes in the stream, and a length indicating the current number of bytes in the stream. The capacity is set at the creation of the stream and cannot be changed unless the stream is resizable. Class MemoryStream has these constructors:

- MemoryStream() creates a resizable MemoryStream with capacity 0 that supports reading, writing, and seeking.
- MemoryStream(int n) creates a resizable MemoryStream with capacity n that supports reading, writing, and seeking. Throws ArgumentOutOfRangeException if n<0.
- MemoryStream(byte b[]) creates a non-resizable MemoryStream with capacity b.Length that supports reading, writing, and seeking. Throws ArgumentNullException if b is null.
- MemoryStream(byte b, bool wr) works similarly but supports writing if wr is true.
- MemoryStream(byte b, int i, int n) creates a non-resizable MemoryStream based on b[i..i+n-1] with capacity n that supports reading, writing, and seeking. Throws ArgumentNullException if i<0 or n<0, and ArgumentException if i+n>b.Length.
- MemoryStream(byte b, int i, int n, bool wr) works similarly but supports writing if wr is true.

MemoryStream has the same members as class Stream (25.7) and in addition these, where ms is a variable of type MemoryStream:

- SetLength(n), where n has type length, sets the length of ms to n. If n<ms.Length the stream is truncated and the current position is set to that after the last byte of the stream. If n>ms.Capacity, the capacity of ms is increased and the new bytes in the stream are initialized to 0. If ms is non-resizable or ms does not support writing, NotSupportedException is thrown. If n<0, ArgumentOutOfRangeException is thrown.
- Read-write property ms.Capacity of type int of the stream. Setting the capacity to n throws NotSupportedException if ms is non-expandable or closed, and throws ArgumentOutOfRangeException if n!=ms.Length.
- ToArray() of type byte[] writes the contents to a new byte array regardless of the current position of the stream.
- WriteTo(st), where st is an expression of type Stream, writes the contents to the stream st or ms is closed. Throws ArgumentNullException if st is null, and ObjectDisposedException if ms is closed.

## 25.8 Directories

Classes Directory and DirectoryInfo implement methods for manipulating directories. Class Directory provides static methods, and class DirectoryInfo provides similar methods. Every call to a Directory method incurs a security check, whereas DirectoryInfo instance may be null to save some checks.

- Directory.GetCurrentDirectory() of type String returns the string representation of the working directory.
- DirectoryInfo(String path) creates a new DirectoryInfo object with the associated path name. Throws DirectoryNotFoundException if the directory does not exist.

Let d be a variable of type DirectoryInfo:

- d.Name of type String is the name of d.
- d.Parent of type DirectoryInfo is the parent directory of d, or null if d is a root directory.
- d.GetDirectories() of type DirectoryInfo[] returns the subdirectories of d.
- d.GetFiles() of type FileInfo[] returns the files in d.

## 25.9 Files

An object of FileInfo represents a file, which is a file name in the file system. The file name may denote a file or nothing at all (if there is no file or path of that). Even if the file name denote a file, a given program may have the permission to read or write to that, or to read a directory on the path to the file. These are few of the constructors and methods in class FileInfo:

- FileInfo(String name) creates a file name corresponding to the path name, which may be relative or absolute. ArgumentException if name is an empty string or has an invalid format, ArgumentNullException if name is null, PathTooLongException if the name or length is too long, UnauthorizedAccessException or SecurityException if the caller does not have permissions.
- Read-only property Ex is true if a file exists by this file name; otherwise false.
- Read-only property Name and FullName of type String are the file's name and its full path.
- Read-only property Extension of type String is the file's extension including its leading period (.), or the empty string if there is no extension.
- Read-only property Length of type long is the length of the file in bytes.
- FileStream Create() creates a new file and returns a FileStream associated with it.
- void Delete() deletes the file if it exists; otherwise does nothing.
- FileStream OpenRead() creates a FileStream associated with the file for reading.
- FileStream OpenWrite() creates a FileStream associated with the file for writing.
- StreamReader OpenText() creates a StreamReader associated with the file for reading.
- StreamWriter AppendText() creates a StreamWriter for appending text to the file.
- StreamWriter CreateText() creates a new file and returns a StreamWriter for writing to it.

## Example 194 Reading and Printing a Directory Hierarchy

The call ShowDir(0, dir) will print the name of directory dir, call itself recursively to print all subdirectories of dir, and then print the names of all files in dir. Because indent is increased for every recursive call, the layout reflects the directory structure.

```c
using System.IO;
// Directory, DirectoryInfo, FileInfo
public class DirectoryHierarchy {
    public static void ShowDir(int indent, DirectoryInfo dir) {
        Indent(indent); Console.WriteLine(dir.Name);
        DirectoryInfo[] subdirs = dir.GetDirectories();
        foreach (DirectoryInfo d in subdirs) {
            ShowDir(indent + 4, d);
            FileInfo[] files = d.GetFiles();
            foreach (FileInfo file in files) {
                Indent(indent + 4); Console.WriteLine(file.Name);
            }
        }
    }

    public static void Main() {
        DirectoryInfo dir = new DirectoryInfo(Directory.GetCurrentDirectory());
        ShowDir(0, dir);
    }
}
```

## 25.10 Network Communication

A pair of distinct processes may communicate through sockets. The processes may be on the same machine or on different machines connected by a network.

Sockets are often used in client/server architectures, where the server process creates a server socket that listens for connections. When a client connects to the server socket, a fresh socket is created on the server side and is connected to the client. The socket connection is used for bidirectional communication between client and server; both ends can obtain a stream that can be written to and read from.

Here are a constructor and some methods from the Class in namespace System.Net.Sockets:

- Socket(AddressFamily af, SocketType st, ProtocolType pt) creates a server socket of the specified kind.
- void Listen(int queue) transfers the socket to listening mode.
- void Accept(EndPoint ep) listens for a connection, blocking until a connection is made. Creates a new Socket when a connection is made. Throws SocketException if the socket is not in listening mode.
- void Bind(EndPoint ep) binds the socket to a given end point ep (network address and port number) which may be an IPPoint expression (example 196).
- void Close() closes the socket.
- Read-only property RemoteEndPoint returns the remote end point to which this socket is connected.
- int Send(byte[] b) and int Receive(byte[] b) are used to send data to and receive data from the socket.

Although it is possible to communicate using only Sockets, it is usually preferable to wrap a Socket in a NetworkStream and communicate through that either binary or character format.

Class NetworkStream (from namespace System.Net.Sockets) is a subclass of abstract class Stream (section 25.7); it further contains the following constructor and property:

- NetworkStream(Socket s) creates a new stream associated with socket s.
- Read-only property DataAvailable indicates whether data are available to read from the stream.
