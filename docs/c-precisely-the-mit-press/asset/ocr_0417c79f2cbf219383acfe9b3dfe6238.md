**Example 75** Bitwise Operators and Shift Operations
In a shift such as n << 48 or n >> -2 the type of the first argument n determines whether the shift will be performed on a 32-bit or 64-bit value. The least significant bits of 48, 40, and -2 represent the numbers 16, 8, and 30 respectively. The result of 1 << 48 is $2^{16} = 65535$, the result of 1024 >> 40 is $2^{10}/2^{25} = 4$, and the result of 1 << -2 is $2^{30} = 1073741824.

```
public static void Main() {
    int a = 0;              // Bit pattern 0011
    int b = 5;              // Bit pattern 0101
    WriteLine(a);          // Prints 0011
    WriteLine(b);          // Prints 0101
    WriteLine(a+b);       // Prints 1100
    WriteLine(a-b);       // Prints 1010
    WriteLine(a & b);      // Prints 0001
    WriteLine(a ^ b);      // Prints 0110
    WriteLine(a | b);      // Prints 0111
    Console.WriteLine(1 << 48); // Prints 65536
    Console.WriteLine(1L << 48); // Prints 28147496710656
    Console.WriteLine(1024 >> 40); // Prints 4
    Console.WriteLine(1024L >> 40); // Prints 0
    Console.WriteLine(1 << -2); // Prints 1073741824
}

static void WriteLine4(int n) {
    for (int i=3; i>=0; i--)
Console.Write(n >> i & 1);
}
```

**Example 76** Bitwise Operators on Enum Values
Bitwise operators (|) and shifts << can be applied to enum values (section 16) if they were integers. It is useful for combining enum values that represent permissions, such as file access permissions. Bitwise or (|) can be used to combine permissions, and and (&) is used to test for a particular permission. The [Flags] attribute allows enum values to be printed symbolically (section 32).

```
[Flags]
public enum FileAccess { // Prints enum combinations symbolically
    Read = 1 << 0,
    Write = 1 << 1
}
...
public static void Write(FileAccess access) {
    if (0 != (access & FileAccess.Write)) {
        Console.WriteLine("You have write permission");
    }
}
public static void Main(string[] args) {
    FileAccess access = FileAccess.Read | FileAccess.Write;
Console.WriteLine(access); // Prints: Read, Write
Write(access);
}
```
