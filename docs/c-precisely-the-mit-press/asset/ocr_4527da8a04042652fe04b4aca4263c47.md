**Example 94** Pass by Value and Pass by Reference for Simple Types and Arrays
The call M(d1, ref d2, a1, ref a2) passes a double, a reference to the variable d2 holding a double,
reference to an array, and a reference to the variable a2 holding a reference to an array.

```
double d1 = 1.1, d2 = 2.2;
int[] a1 = new int[4], a2 = new int[4];
M(d1, ref d2, a1, ref a2);
...
static void M(double dd1, ref double dd2, int[] aa1, ref int[] aa2) {
  dd1 = 3.3; dd2 = 4.4;
  aa1[0] = 17;
  aa2[0] = 18;
  aa2 = new int[3];
}
```

The solid arrows show the state before the method called; dashed references are caused by parameter passing, and the dotted arrows show the state just after method return.

| In M: | In Main: | Heap: |
|---|---|---||
| d1 | 3.3 | | |
| d2 | 4.4 | | |
| aa1 | | 17 | 0 | 0 | 0 |
| aa2 | | 18 | 0 | 0 | 0 |

After the method returns the parameters dd1, dd2, aa1 and aa2 are discarded. In Main, the ref arguments d2 and a2 have been modified. The by-value arguments d1 and a1 are unmodified, an element in the array pointed to by a1 has been modified.

**Example 95** Calling a Method with a Parameter Array and Overloading
This example shows calls to the three overloads of the Max method (example 54). For one and four arguments, the params overload is called because it is the only possible one. For two arguments Max(int, int) overload is called because its expanded form is better than Max(int, double). For three arguments, Max(int, int, int) overload is called because an explicit overload is preferred to an expanded form of a parameter array.

```
Console.WriteLine(Max(2, 1));
Console.WriteLine(Max(4));
Console.WriteLine(5, 8, 7));
Console.WriteLine(Max(8, 16, 10));
int[] xr = { 13, 32, 15 };
Console.WriteLine(Max(12, xr));
Console.WriteLine(Max(16, ref xr[0]));
```

// Calls Max(int, int, int)
