# 22.2 The Task Classes

Class Task and its subclass Task<T> are used to create concurrently tasks from delegates and lambda expressions, and to implement asynchronous methods (section 23). A Task represents an asynchronous activity that does not produce a result (made from a void delegate), whereas a Task<T> represents a value of type T (made from a delegate with return T).

# 22.2.1 Class Task

Class Task from namespace System.Threading.Tasks has the following members, among others:

+   * Constructor(Action act) creates a task that, when started with Start(), will execute act(act).

+   * ContinueWith(Action<Task> cont) creates and starts a task in which the given task continues with the computation; that, when task completes, cont(task) will be called.

+   * Task<U> ContinueWith(Func<Task, U> cont) is similar, but the continuation produces a result of U.

+   * static Delay(int ms) creates and starts a task that blocks for ms milliseconds.

+   * static Run(Action act) creates and starts a concurrent task that execute act().

+   * static Task<T> Run(Func<T> func) creates and starts a concurrent task that executes func(),

+   * void RunSynchronously() starts the task for synchronous execution on the current task scheduler; blocks the current thread until the task is complete.

+   * void Start() starts the given task for asynchronous execution on the current task scheduler. Throw InvalidOperationException if the task is already started or cancelled (22.2.3).

+   * Read-only property TaskStatus returns the task's state (see on page 141).

+   * void Wait() blocks until the task completes. AggregateException if the task is cancelled or throws an exception (174 and 175).

+   * static Task WhenAll(params Task[] tasks) creates and starts a task that completes when all of the given tasks complete, returning an array of results.

+   * static Task<T[]> WhenAll(params Task<T>[] tasks) creates and starts a task that completes when all of the given tasks complete, returning an array of results.

+   * static Task<T> WhenAny(params Task<T>[] tasks) creates and starts a task that completes when any of the given tasks complete, returning one of the tasks completed. WhenAll and WhenAny have overloads that take as argument an enumerable list of an array (177). Exceptions thrown by the completed tasks will be completed, by the WhenAll and WhenAny tasks, in the InnerExceptions collection of an AggregateException.

The constructor and methods ContinueWith, Delay and Run have further overloads that take an additional CancellationToken argument (section 22.2.3 and 174) for cancellation of the resulting task. The ContinueWith method has overloads that take a task continuation option argument or a task scheduler argument. See the .NET class library documentation.
