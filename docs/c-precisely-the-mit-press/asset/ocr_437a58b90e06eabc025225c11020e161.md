Example 176 Asynchronous Data Retrieval with async and await
Methods NbiEntQueryAsync and NbiProteinAsync behave the same as the task-returning methods in example 170, but the async and await keywords give a neater syntax.

```
public static async Task<String> NbiEntrezAsync(String query) {
    byte[] bytes = await newClient().DownloadDataAsync(new Uri(server + query));
    return ASCIIICode.GetString(bytes);
}
```

```
public static async Task<String> NbiProteinAsync(String id) {
    return await NbiEntrezAsync("etch.fcgi?retype=fasta&retmode=textidb=proteinid=" + id);
}
```

Example 177 Parallel Asynchronous Data Retrieval
To retrieve many proteins, one may use asynchronous method NbiProteinAsync (example 176). The from expression creates and starts a task for each protein ID, and WhenAll creates a task that waits for all of them to complete and collects the results and returns them in an array.

```
public static async Task<String[]> NbiProteinParallelAsync(params String[] ids) {
    IEnumerable<Task<String>> tasks = from id in ids select NbiProteinAsync(id);
    return await Task.WhenAll(tasks);
}
```

Example 178 Composite Asynchronous Data Retrieval
A query to the PubMed publication database at NCBI must be done in two steps: first an search query that returns an XML document containing a WebEnv key; then an fetch query that gets the actual results. The asynchronous method performs such a two-step query, calling asynchronous method NbiEntrezAsync(example 176) twice. Because the result is a task, one could further add a timeout (example 179) or use WhenAll to perform many such two-step queries in parallel (example 177).

```
public static async Task<String> NbiPubMedAsync(String term) {
    String search = String.Format("etch.fcgi?db=PubMed&retmode=l&term={0}", term);
    XmlDocument xml = new XmlDocument();
    xml.LoadXml(await NbiEntrezAsync(search));
    XmlNode node = xml["EsearchResult"];
    String fetch = String.Format("retmax=3&db=PubMed&query_key={0}&WebEnv={1}", node["Query"].InnerText, node["WebEnv"].InnerText);
    return await NbiEntrezAsync("etch.fcgi?retype=abstract&retmode=text" + fetch);
}
```

Example 179 Implementing Timeout with async and await
A timeout (example 173) can be implemented using async methods and await.

```
public static async Task<double> SlowTimeout2Task(int n) {
    Task<double> slowFibTask = SlowFibTask(n);
    Task completed = await Task.WhenAny(slowFibTask, Task.Delay(1000));
    return completed == slowFibTask ? slowFibTask.Result : -1;
}
```
