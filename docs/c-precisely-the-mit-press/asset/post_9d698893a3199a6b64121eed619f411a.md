
# Example 109 Anonymous Method Compatibility

The anonymous method d11 is compatible with D1 but not D2; the anonymous method d21 is compatible with D2 but not D1; and d22 is compatible with D2 and D3 but not D1. None of the anonymous methods are compatible with D4. The foreach loop calls anonymous methods; each of the calls to d21 and the anonymous method created by M(4) increments the ref parameter y by 1.

```csharp
delegate D1(int x, ref int y, int z);
delegate D2(int x, ref int y, int z);
delegate D3(int x);
delegate D4(int x, ref int y);
class {
    static D1 d1 = delegate(int x, ref int y, int z) { z = y++; return x + y; };
    static D2 d21 = delegate(int x, ref int y) { y+=2; return x + y; };
    static D2 d22 = delegate { { return 5; };
    public static D2 M(int mx) {
        if (mx < 6)
            return delegate (int x, ref int y) { y+=2; return x + y; };
        else
            return delegate { return mx; }
    }
    public static void Main(String[] args) {
        D2[] ds = { d21, d22, M(4), M(7), delegate { return 8; } };
        int y = 0;
        foreach (D2 d in ds)
            Console.WriteLine(d, y); // Prints 4 5 6 7 8
        Console.WriteLine(y); // Prints 4
    }
}
```

# Example 110 Local Variables Captured in an Anonymous Method

The local variables u and v get captured in the anonymous methods in the loop body. Since u is declared outside the for loop, only one instance of the variable is created, and all anonymous methods in udlg refer to that one instance. Since v is declared, a separate instance of the variable is created for each iteration of the loop, and each anonymous method in vdlg has its own instance. Thus the single u is incremented five times, and each v is incremented once.

```csharp
public static void Main(String[] args) {
    D[] udlgs = new D[5], vdlg = new D[5];
    int u = 0;
    for (int i=0; i<5; i++) {
        int v = 0;
        udlgs[i] = delegate () { u++; Console.Write(u); };
        vdlg[i] = delegate () { v++; Console.Write(v); };
    }
    foreach (D lg in udlgs) lg(); // Prints 12345
    foreach (D lg in vdlg) lg(); // Prints 11111
}
delegate void D();
```

# 12.23 Lambda Expressions (C# 3.0)

A lambda expression is similar to an anonymous method expression (section 12.22), but the syntax is more compact. Its basic forms are:

```
x => e

(xt, ..., xn) => e

(parameter-modifier t1 x1, ..., parameter-modifier tn xn) => e
```

The x and xi are parameters, the expression is the lambda expression's body, the ti are parameter types, and the parameter-modifier is ref or out. Lambda expressions cannot take parameter arrays (params; see section 10.7) or optional parameters (section 10.10). The e may refer to variables and parameters in the enclosing scope according to the rules as anonymous methods (section 12.22).

The value of a lambda x => e is a delegate object, when applied to a parameter x, it will evaluate expression and return the result. Like an anonymous method, a lambda expression has no type in itself but is convertible to delegate types that agree with the parameter types and the type of e (the return type). When a lambda expression's parameter types are not specified, the compiler attempts to infer them using context information, such as the type of variable or method to which the lambda expression is assigned (example 111).

# 12.24 Anonymous Object Expressions (C# 3.0)

An anonymous object evaluates to an object with read-only fields:

```
new { xi = ei, ..., xn = en }
```

The xi are identifiers and the ei are expressions that are evaluated from left to right to obtain the values of xi. When ei is an identifier x or a field or property access e.f, then xi= be left out, in which case the identifier x or the identifier f will be used for xi.

The resulting anonymous object has read-only properties, returning the values given at creation. The type of the expression is an anonymous type. All anonymous expressions that have the same fields with the same order will have the same anonymous type, at least within the same assembly (section 1.1). The Equals and Get methods are overridden to the anonymous object's field values. The ToString method displays the object's field values. Anonymous object expressions are used in the implementation of LINQ queries (example 242).

# 12.25 Implicit Typed Array Creation Expressions (C# 3.0)

An implicitly typed array creation for a one-dimensional array has this form:

```
new [] { xi = ei, ..., xn = en }
```

The difference from an ordinary array creation (section 9) is that the implicitly typed type format does not specify the type of the newly created array; this would be impossible for an array initialized with anonymous object expressions. The preceding expression creates an array of length n whose element type is the best type of the types of ei. The ei are evaluated from left to right. Rectangular multidimensional arrays new[] { { ... }, ..., { ... } } are created as shown in section 9.2.
