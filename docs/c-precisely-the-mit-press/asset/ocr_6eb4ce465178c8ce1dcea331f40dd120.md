# 10 Classes

# 10.1 Class Declarations and Class Bodies

A class-declaration of class C has the form

```
class-modifiers class C class-base-clause
class-body
```

A declaration of C introduces class C, which is a reference type. The class-modifiers may be at most abstract, sealed, and static (section 10.2) and a class access modifier (section 10.14). Inside an enclosing class D it may be new to hide any member C inherited from the class of D.

The class-base-clause may be used to specify the base class or superclass of class C (section 10.4) and to specify the interfaces implemented by class C (section 15.2).

A declaration may consist of one or more partial declarations (section 30).

The class-body may contain declarations of data members (constants and fields), function members (instance constructors, static constructor, properties, indexers, user-defined overloaded operators, and events), and nested types (classes, struct types, interfaces, enum types, and delegate types):

```
{
constant-declarations
field-declarations
constructor-declarations
static-constructor-declaration
method-declarations
property-declarations
indexer-declarations
operator-declarations
event-declarations
type-declarations
}
```

The declarations in a class-body may appear in any order. A field, method, property, indexer or event may be declared static. Operators must be static, and type members are implicitly static. A non-static member must be an instance member.

There can be no two members with the same name, except methods may have the same name if they have different signatures (method overloading; section 10.7). The scope of the member is the entire class body, except shadowed by a variable or a parameter of method or property or indexer, or by a member of a nested class. However, instance fields and the current object reference cannot be used in initializer expressions of fields, whether static or not.

Static code means expressions and statements in initializers of fields and events, in static constructors, static methods, static indexers, and in operators. Non-static code means expressions and statements in instance constructors, instance methods, instance properties, instance indexers, and instance events. Non-static code is executed using a current object, which can be referred to as this (section 12.16). Static code cannot refer to instance members, only to static members.

Most of what is said about class declarations in this section is true of struct type declarations also, with the modifications listed in section 14.
