# Example 103 Using Properties from the Log Class

This example uses the Log InstanceCount. Last. Count, and All (example 66). Note the use of += on the Last property, which invokes its get-accessor and then its set-accessor.

```
Log log1 = new Log(); log2 = new Log();
Console.WriteLine("Number of logs = " + Log.InstanceCount);
log1.Add("Alarm"); log1.Add("Coffee");
log1.Add("Bus"); log1.Add("Work"); log1.Add("Lunch");
Console.WriteLine(log1.Last);
log1.Last += " nap";
Console.WriteLine(log1.Last);
log1.Add("More work");
Console.WriteLine("Logged entries = " + log1.Count);
foreach (String s in log1.All)
Console.WriteLine(s);
Console.WriteLine();
```

# Example 104 Static, Instance, and Virtual Properties

A class may declare abstract, static, instance, and virtual properties; they behave like the corresponding kinds of methods. A subclass may hide with (new) or override properties inherited from the base class.

```
abstract class A {
    public abstract String Cl { get; }
}
class B : A {
    public static String Name { get { return "B"; } }
    public String Ty { get { return "B"; } }
    public override String Cl { get { return "B"; } }
}
class C : B {
    public new static String Name { get { return "C"; } }
    public new String Ty { get { return "C" + base.Ty; } }
    public override String Cl { get { return "C" + base.Cl; } }
}
B b1 = new B();
C c2 = new C();
B b2 = c2;
Console.WriteLine("B.Name = {0}, C.Name = {1}", B.Name, C.Name); // B C
Console.WriteLine("B1.Ty = {0}, c2.Ty = {1}", b1.Ty, c2.Ty); // B C:B
b1.Ty, b2.Ty, c2.Ty;
Console.WriteLine("b1.Cl = {0}, b2.Cl = {1}, c2.Cl = {2}"); // B C:C:B
b1.Cl, b2.Cl, c2.Cl;);
```
