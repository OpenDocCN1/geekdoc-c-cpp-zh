# Example 210 Generic Comparer as a Delegate

The generic delegate type DComparer<T> describes a method that takes two arguments of type T and compares them, just like method Compare in an object of type IComparer<T> (section 27.3). Note that the method String.Compare (section 7) is compatible with the constructed delegate DComparer-Strings and that the types in method StringReverseCompare (example 153) are avoided.

```
public delegate DComparer<T>(T v1, T v2);
...
DComparer<String> strCmp = String.Compare;
```

# Example 211 Generic QuickSort Using a Delegate to Compare Elements

This generic method is a faster and more typesafe version of the delegate-sorting method in example 153. It sorts an array of type [T] where T is a type parameter, as in example but the element ordering is determined by a delegate of type DComparer<T> (example 210). Note that all type casting, boxing, and unboxing can be avoided, even when sorting of simple type such integers.

```
private static void QSort<T>(T[] arr, DComparer<T> cmp, int a, int b) {
    while (cmp(arr[i], x) < 0) i++;
    while (cmp(x, arr[j]) < 0) j--;
}
```

# Example 212 Generic Delegate Types Functions and Actions

The generic delegate type Func<A1,R>, Action<A1>, and so on (page 122) suffice to describe all methods, except taking ref or out parameters. For instance, method Math.Sign (section 24), which takes a delegate parameter and returns int, can be stored in a variable of type Func<double,int>. The delegate type DoubleToInt is Func<double,int>, and indexed values of the two types can hold the same delegate values, but the types are distinct, and there is no conversion between them, so the assignments dlg1=dlg2 and dlg2=dlg1 would be rejected by the compiler.

```
public delegate int DoubleToInt(double x);
DoubleToInt dlg1 = Math.Sign;
Func<double,int> dlg2 = Math.Sign;
```

# Example 213 Mapping a Method, an Anonymous Method or a Lambda Expression over a Linked List

The generic List<T> method Map<LU>(..), in example 209 takes an argument of generic delegate type Func<T,LU>(page 122). A delegate of that type may be created from an existing method like Math.Sign, or it may be an anonymous expression (section 12.2) or a lambda expression.

```
LinkedList<double> dList = ...;
MyList<int> iList = dList.Map<int>(Math.Sign);
MyList<string> sList1 = dList.Map(delegate(double d) { return "s " + d; });
MyList<string> sList2 = dList.Map(d => "s " + d);
```
