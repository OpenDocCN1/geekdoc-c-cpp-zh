+   * Max() returns the maximal item in the enumeration. If T is a numeric type or nullable numeric type, see section 28.6. +   * Max(Func<T, N> f) applies to each item x of the enumeration and returns the maximum of the values f(x). Defined only when N is a numeric type or a nullable numeric type (section 28.6).

When T is a reference type and there are no non-null items, null is returned. When T is not a reference type and there are no items, InvalidOperationException is thrown. See example 244.

+   * OrderedEnumerable<T> OrderBy(Func<T, K> h) returns an ordered enumerable whose items are ordered by values of h(x). See example 241. Also overloaded to use an IComparer<K> as last argument.

+   * OrderedEnumerable<T> OrderByDescending(Func<T, K> h) returns an ordered enumerable whose items are ordered by descending values of h(x). See example 241. Also overloaded to use an IComparer<K> as last argument.

+   * IEnumerable<R> Reverse() returns an enumerable that generates the items of the enumerable in reverse order.

+   * IEnumerable<R> Select(Func<T, R> f) returns an enumerable whose items are f(x1), f(x2), ... or in comprehension notation: f(x) | x <- xs. Typically called map in functional languages. See examples 235 and 238.

+   * IEnumerable<R> Select(Func<T, int, R> f) returns an enumerable whose items are f(x1, 0), f(x2, 1), ... or in comprehension notation: f(x, i) | x, i <- zip2(xs, 0) ... where zip2 creates pairs of items from pair of enumerables, and 0 is the enumerable whose items are 0, 1, and so on.
