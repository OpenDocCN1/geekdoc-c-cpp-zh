# Example 171 Performing Slow Computation in a Separate Task

A long-running computation, or access to a web server, database or other remote service, may be executed as a separate task to avoid blocking the user interface or to allow other activities to proceed currently. Here SlowFibTask creates and starts a task that performs a long-running computation asynchronously. The result of the task can be obtained as task.Result.

```
public static double SlowFib(int n) { ... computation take 10 seconds for n=43 ... }
public static Task<double> SlowFibTask(int n) {
    return Task.Run(() => SlowFib(n));
}

Task<double> task = SlowFibTask(); // Returns a Running task
Console.Write("[task is running ]");
Console.WriteLine(task.Result);
```

# Example 172 Asynchronous Web Data Retrieval with Task Continuations

Assume one wants to make asynchronous versions of the NbiEntrez and NbiProtein methods in 170, returning a Task<String> instead of a String. Instead of the DownloadData method, an asynchronous version DownloadDataAsync returns a Task<byte[]>. When that task completes, convert the byte array to a String by using ContinueWith from class<T> (section 22.2) to attach a continuation (as a lambda expression) to download the task. Example 176 presents noticeably better but functionally equivalent methods.

```
public static Task<String> NbiEntrezTask(String query) {
    return new WebClient().DownloadAsync(new Uri(server + query))
    .ContinueWith((Task<byte[]> task) =>
        ASCII.Encoding.GetString(task.Result));
}
```

```
public static Task<String> NbiProteinTask(String id) {
    return NbiEntrezTask("effetch.cgi?retry=fasta&retmode=text&db=" + id);
}
```

# Example 173 Implementing Timeout

Task timeout can be implemented using WhenAny to determine whether a given SlowFibTask (example 171) or a certain Delay completes. The WhenAny creates and starts a task, when completes, gets bound to the continuation's parameter task. The result of the task that completed, so one can test whether it is SlowFibTask and if so, return its result, otherwise some dummy value. Example 179 shows how this can be expressed more naturally.

```
public static Task<double> SlowFibTimeout(int n) {
    Task<double> slowFib = SlowFib(n);
    return Task.WhenAny(slowFib, Task.Delay(1000))
    .ContinueWith<double>((Task<double> task) =>
        task.Result == slowFib ? slowFib.Result : -1);
}
```
