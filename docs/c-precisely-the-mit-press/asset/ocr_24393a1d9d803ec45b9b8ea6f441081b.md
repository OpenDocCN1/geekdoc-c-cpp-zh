# Example 68 Operator Overloading

A Seq is a sequence of integers. For instance Seq(1,3) is the sequence 1 2 3. The operator (*) is overloaded so that k*seq is a sequence by multiplying each element of seq by k, and the operator (+) is overloaded so that b+seq is a sequence by adding b to each element of seq, when k and b have type. The unary operator (!) creates a sequence that is the reverse of the one.
Testing ToString uses a foreach statement (13.6.2) to traverse the sequence because Seq has a GetEnumerator method returning an IEnumerator<int> object (example 64).

```
struct Seq {
    private readonly int b, k, n;
    public Seq(int m, int n) { this(m, n-m+1); } // Sequence [m..n]
    public Seq(int b, int k, int n) { this.b = b; this.k = k; this.n = n; }
    public static Seq operator +(int b, Seq seq) {
        return new Seq(seq.b, seq.k, seq.n);
    }
    public static Seq operator +(Seq seq, int b) {
        return new Seq(seq.b+b, seq.k, seq.n);
    }
    public static Seq operator *(int k, Seq seq) {
        return new Seq(seq.b*k, seq.k*k, seq.n);
    }
    public static Seq operator *(Seq seq, int k) {
        return new Seq(seq.b*k, seq.k*k, seq.n);
    }
    public static Seq operator !(Seq seq) {
        return new Seq(seq.b, seq.n-1)*seq.k, -seq.k);
    }
    public static bool operator ==(Seq s1, Seq s2) {
        return s1.n==s2.n && s1.b==s2.b && s1.k==s2.k && s1.n==s2.n;
    }
    public IEnumerator<int> GetEnumerator() { return new SeqEnumerator(this); }
    IEnumerator IEnumerable.GetEnumerator() { return GetEnumerator(); }
    SC.IEnumerator SC.GetEnumerator() { return return GetEnumerator(); }
    private class SeqEnumerator : IEnumerator<int> { ... }
    public override string ToString() {
        StringBuilder sb = new StringBuilder();
        foreach (int i in this) {
            sb.Append(i).Append(" ");
        }
        return sb.ToString();
    }
}

Seq s1 = new Seq(1,3); // 1 2 3
Seq s2 = 2 * s1 + 5; // 7 9 11
Seq s3 = 2 * s3; // 21 27 33
Seq s4 = s3; // 33 27 21
Console.WriteLine(s1==s2); // False
Console.WriteLine(s3==s4); // True
```
