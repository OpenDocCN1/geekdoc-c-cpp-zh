# Example 15 Compile-Time Resolution and Checking of Operators, Assignments, and Field Accesses

```
class Phone {
    public readonly String name;
    public readonly int phone;
    public Phone(String name, int phone) { ... }
}

var dl = 34;                 // Inferred type int
int i1 = (int)dl * 2;
int i2 = (int)dl * 2;        // Cast(int)dl succeeds at compile-time
bool b1 = dl;                // Rejected at compile-time
dl = true;                   // Rejected at compile-time
var pl = new Phone("Kasper", 5170);
String s1 = pl.name;          // Field access checked only at compile-time
int n1 = pl.phone;
var p2 = new {"Kasper", phone = 5170}; // OK: field access rejected at compile-time
String s2 = p2.name;          // Field access checked only at compile-time
int n2 = p2.page;            // Field access rejected at compile-time
```

# Example 16 Run-Time Resolution of Assignments and Field Accesses
Contrast this example with 15. For anonymous objects, see section 12.24.

```
dynamic dl = 34;
int i1 = (int)dl * 2;         // OK: cast(int)(dl*2) at run-time
int i2 = (int)dl * 2;
bool b1 = dl;                // OK: cast(int)dl at run-time
dl = true;                   // Compiles OK; cast(bool)dl throws at run-time
bool b2 = dl;                // OK: cast(bool)dl succeeds at run-time
dynamic pl = new Phone("Kasper", 5170);
String s1 = pl.name;          // Field access checked at run-time
int n1 = pl.phone;            // Compiles OK; field access throws at run-time
dynamic p2 = new {name = "Kasper", phone = 5170};
String s2 = p2.name;          // Field access checked at run-time
int n2 = p2.page;            // Compiles OK; fields throws at run-time
```
