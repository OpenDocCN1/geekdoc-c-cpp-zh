# 13 Statements

The execution of a statement may change the computer’s state: the value of variables, fields, and so on.

# 13.1 Expression Statement

An expression statement is an expression followed by a semicolon:

expression;

It is executed by evaluating the expression and ignoring its value. The only forms of expression that may be legally used in this way are assignment expressions (section 12.7), increment and decrement expressions (section 12.2), and object creation expressions (section 12.9).

# 13.2 Block Statement

A block-statement is a sequence of zero or more statements enclosed in braces:

{ statements }

# 13.3 The Empty Statement

The empty statement (;) consists of a semicolon only, and has no effect at all. If an empty statement is ever needed, it is clearer to use the equivalent block statement { } that contains no statements.

# 13.4 Declaration Statement

The purpose of a declaration is to declare and initialize local variables and constants.

```
var identifier = expression;
type local-variable-declarator, local-variable-declarator, ... ;
```

In the first form type infers the type of the variable identifier being declared (section 6.3). In the second form type is the type of the variables being declared, and local-variable-declarator has one of these:

```
identifier
identifier = local-variable-initializer
```

where identifier is the name of the variable, and the local-variable-initializer must be an expression or array initializer whose value is implicitly converted to type. Thus initialization of a local variable is optional at declaration. A declaration of a variable with an initialization x = 1 is semantically equivalent to a declaration statement without initialization x; followed by an assignment x = 1;

A constant declaration is a local declaration of the second form preceded by const; the local-variable-initializer must be a compile-time constant. A local constant may have simple type (section 5.1), enum type (section 16), or reference type (section 5.2), in which case it must be null.
