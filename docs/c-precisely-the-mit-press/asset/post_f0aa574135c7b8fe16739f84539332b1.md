
# Example 31 Efficiently Concatenating All Command Line Arguments

When there are many (more than 50) command line arguments, this is much faster than example 20.

```c
using System;
using System.Text; // StringBuilder

class StringBuilderConcatenate {
    public static void Main(String[] args) {
        StringBuilder res = new StringBuilder();
        for (int i=0; i<args.Length; i++) {
            res.Append(args[i]);
            Console.WriteLine(res.ToString());
        }
    }
}
```

# Example 32 Replacing Occurrences of a Character by a String

To replace occurrences of character c1 with the string s2 in string s, it is best to use a string builder for the result, since the size of the resulting string is not known in advance. This works well when replacing a character c1 with another character c2, but in case the length of the result is known in advance (equals the length of s), and one can use a character array instead. Solving this problem by repeated concatenation (using res += s2 where res has type String) would be very slow.

```csharp
static String ReplaceCharString(String s, char cl, String s2) {
    StringBuilder res = new StringBuilder();
    for (int i=0; i<s.Length; i++) {
        if (s[i] == cl)
            res.Append(s2);
        else
            res.Append(s[i]);
    }
    return res.ToString();
}
```

# Example 33 An Inefficient Way to Replace Occurrences of a Character by a String

The problem in example 32 can also be solved by destructively modifying a string builder with Remove and Insert. However, repeated use of Remove and Insert is very inefficient: for a string of 200,000 characters this method is approximately 100 times slower than example 32.

```csharp
static void ReplaceCharString(StringBuilder sb, char cl, String s2) {
    int i = 0;
    while (i < sb.Length) { // Inefficient
        if (sb[i] == cl) { // Inefficient
            sb.Remove(i, 1); // Inefficient
            sb.Insert(i, s2); // Inefficient
            i += s2.Length; // Inefficient
        } else // Inefficient
            i += 1; // Inefficient
    }
}
```

# Arrays

An array is an indexed collection of zero or more variables, called elements. An array has a given element type t, which can be any type. The value of an expression of array t[] is either null or a reference to an array whose element type u is implicitly converted to t. Assignment of an array to a variable assigns only the reference; it does not copy the array, as illustrated by arr1 and arr2.

## 9.1 One-Dimensional Arrays

In an array with rank l and length l, the elements are indexed by the integers 0, 1,...,l-1. An array of length l with element type t is created (allocated) using an array expression, which can take two forms. The first form of array creation expression t[l] creates a new array with rank 1, also called a one-dimensional array, with l elements, all initialized with the default value for type t. The size argument may be zero, or if it is negative, an OverflowException is thrown.

The second form of array creation expression explicitly lists the elements of the new array t[] = { expression, ..., expression }; The type of each expression must be implicitly converted to t. Then the expressions are evaluated from left to right, and their values converted to type t and stored in the array. A local variable or field of array type may be initialized at declaration. When an array expression is used to initialize an array at its declaration, new t[] may be left out, so equivalent to t[] = { expression, ..., expression }; Note that the declared variable cannot occur in expression: it has not been initialized when the expressions are being evaluated. Also note that there are no array constants: a new array is created every time array creation expression be an array of type t whose value is an array of length l with element type u. The array access expression a[i] denotes element i of a, counting from 0; this has type t. The integer i is the array index. If the value of i is less than 0 or greater than l, then an IndexOutOfBoundsException is thrown.

When the element e is a reference type, every array assignment a[i]=e checks the value of e is null or implicitly convertible to the element type u. If this is not the case, an ArrayMismatchException is thrown. This check is made before every array assignment at run-time, but only for reference types. For value types, the type check is performed at compile-time.

## Example 34 Creating and One-Dimensional Arrays

This example rolls a thousand times, then prints the frequencies of the outcomes.

```csharp
Random rnd = new Random(); // Random number generator
int[] freq = new int[6]; // All elements initialized to 0
for (int i=0; i<1000; i++) {
    int die = rnd.Next(1, 7); // Roll die
    freq[die-1] += 1; // Increment frequency
}
for (int c=1; c<=6; c++) Console.WriteLine(c + " came up " + freq[c-1] + " times");
```

## Example 35 Using an Initialized Array

Method CheckDate whether a given date is legal in a non-leap year. The array should be created once, outside the method; otherwise a new array is created for every call to the method.

```csharp
static readonly int[] days = { 31, 28, 31, 30, 31, 30, 31, 31, 30, 31 };
static bool CheckDate(int mth, int day)
{ return (mth >= 1) && (mth <= 12) && (day <= days[mth-1]); }
```

This program compiles all, but at-runtime a[2]=p throws ArrayTypeMismatch, since the class Point of the bound p is not implicitly convertible to a's element type RedPoint.

# 9.2 Multidimensional Arrays

There are two ways to form multidimensional arrays: rectangular arrays and jagged arrays.

### 9.2.2 Arrays of Arrays (Jagged Arrays)

In general, an array type has type t[k1][k2]...[kn], where ki is a list of ki-1 elements, ki >= 1, and t is not an array type. This type describes k-dimensional rectangular arrays of k-dimensional rectangular arrays of... kn-dimensional arrays of element t. For example, double[][] is the type of two-dimensional arrays of double

A common case is Java-style "h-dimensional" array types t[][][]... where k1==kn=1. Thus a "two-dimensional" array of t t is a one-dimensional array whose elements are arrays of type t. The array may have different lengths, so the array may be non-rectangular or jagged.

A jagged (Java-style) "h-dimensional" array t[][][]... with h square brackets [,], must be created one at a time.

```csharp
t[l1][...]
```

This creates a one-dimensional array with l1 elements, all initialized to null, and all of type t[...]. where there are h-1 square brackets []. One may subsequently create arrays of type t[...]. and assign them to the elements of the one-dimensional array
