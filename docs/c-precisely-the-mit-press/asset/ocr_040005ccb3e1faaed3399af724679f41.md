# **Example 237** Linq from Clause

Using xs and ys from example 234, these examples show both the Linq source notation and the corresponding extension method calls.
The clause on y select to process all 3·3 = 9 combinations of items, in order, from xs and ys.

```
Show(from x in xs
      from y in ys
      select new { x, y });    // { x=2, y=C } { x=2, y=BB } ... { x=5, y=BA }
Show(xs.SelectMany(x => ys, (x, y) => new { x, y })));
```

# **Example 238** Linq let Clause

The let clause introduces a value of y for each value of x, for use in select. The compiler rewrites this an expression that packages the x and y in an anonymous object expression (section 12.24). Subsequent use of range variables x and y are rewritten to create anonymous xs.x and xy.y.

```
Show(from x in xs
      let y = x*x
      select 100*x + y);    // 204 309 525
Show(xs.Select(x => new { y = x*x }).Select(xy => 100*xy.x + xy.y));
```

# **Example 239** Linq where Clause

The clause on x causes select to process only odd values of x.

```
Show(from x in xs
      where x%2 != 0
      select x*x);    // 9 25
Show(xs.Where(x => x%2 != 0).Select(x => x*x));
```

# **Example 240** Linq join Clause

The first join clause selects to process only those combinations of x and y for x-1 equals y.Length; The second join clause selects for process, for each pair, a (xs,zs), where zs is an *inner join*. This is a stream of y for which x-1 equals y.Length; this is a *group join*.

```
Show(from x in xs
      join y in ys on x-1 equals y.Length
      select new { x, y });    // { x=2, y=C } { x=3, y=BB } { x=3, y=BA }
Show(xs.Join(ys, x => x-1, y => y.Length, (x, y) => new { x, y }));

(from x in xs
      join y in ys on x-1 equals y.Length
      select new { x, y, zs = zs.Count() });    // { x=2, y=1 } { x=3, y=2 } { x=5, y=0 }
Show(xs.GroupJoin(ys, x => x-1, y => y.Length, (x, zs) => new { x, y, zs = zs.Count() })));
```
