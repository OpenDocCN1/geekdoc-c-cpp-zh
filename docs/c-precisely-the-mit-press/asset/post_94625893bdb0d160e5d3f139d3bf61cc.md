- bool SequenceEqual(IEnumerable<T> ys) returns true if each of the given enumerable (by the default equality comparer) the item of the enumerable ys at the same position, and the two enumerables have the same number of items; returns false otherwise. overloaded to take an explicit EqualityComparer<T> as last argument.
- Single<T> returns the only item of the given enumerable. InvalidOperationException if the enumerable is empty or has more than one item.
- Single(Func<T,bool> p) applies p to all items of the given enumerable and returns the first x of the given enumerable for p(x) is true. InvalidOperationException if there is no such item x, or if there is more than one item x.

- SingleOrDefault(Func<T,bool> p) applies p to all items of the given enumerable and returns the first item x of the given enumerable for p(x) is true; otherwise returns default(T). InvalidOperationException if p(x) is true for more than one x in the enumerable.
- IEnumerable<T> Skip(int n) returns an enumerable that generates the items except the first. When n<0, all items are generated; when n is greater than or equal to the number of items, no items are generated.
- IEnumerable<T> SkipWhile(Func<T,bool> p) returns an enumerable that generates the tail of the given enumerable, starting with the first item for which p(x) is false. If p(x) is true for all in the enumerable, no items are generated.
- IEnumerable<T> SkipWhile(Func<T,int,bool> p) returns an enumerable that generates the tail of the given enumerable, starting with the first item for which p(x, i) is false. Where x is i counting from zero.
- N Sum(Func<T,N> f) applies f to each item x of the enumerable and returns the sum of the values f(x). Only when N is a numerical type or a nullable type (section 28.6).
- IEnumerable<T> Take(int n) returns an enumerable that generates the first n items of the given enumerable. when n<0, no items are generated; when n is greater than or equal to the number of items, all items are generated.
- IEnumerable<T> TakeWhile(Func<T,bool> p) returns an enumerable that generates the maximum prefix of the given enumerable consisting of the items x for which p(x) is true.
- IEnumerable<T> TakeWhile(Func<T,int,bool> p) returns an enumerable that generates the maximal prefix of the given enumerable consisting of items x for which p(x, i) is true, where x is at position i, counting from zero.
- T[] returns a new array that contains the items of the given enumerable.
- Dictionary<K,T> ToDictionary(Func<T,K>, Func<T,T> h) returns a new dictionary of type DictionaryKey that contains an entry (h(x), x) for each item x of the given enumerable. Throws ArgumentException if there are two items xi and xj for which h(xi) equals h(xj). In comprehension notation, the key/value pairs of the new dictionary are ((h(x), x) | xs).
- Dictionary<K,E> ToDictionary(Func<T,K>, Func<T,E> h, Func<T,E> f) returns a new dictionary of type DictionaryKey, that contains an entry (h(x), f(x)) for each item x of the given enumerable. - List<T> returns a new List<T> that contains the items of the given enumerable.
- IEnumerable<T> ToLookup(Func<T,K>, Func<T,V> h) returns a new lookup structure that contains an entry (k, vs) for each value k of h, and vs is an enumerable of all x f(x) of the enumerable by the value k, where each group can be accessed by index. In comprehension notation, the key/value pairs of the lookup structure are ((k, x) | xs, where h(x)=k) | h--distinct((h(x))).
- IEnumerable<T> ToLookup(Func<T,K>, Func<T,V> h, Func<T,V> f) returns a new lookup structure that contains an entry (k, vs) for each value k of h, and vs is an enumerable of the values f(x) of the enumerable for which h(x) equals k, where each group can be accessed by index. In comprehension notation, the key/value pairs of the lookup structure are ((k, x) | xs, where h(x)=k) | h--distinct((h(x))).
- IEnumerable<T> Union(IEnumerable<T>) returns an enumerable that generates each item in the given enumerable and each item in ys, without duplicates, comparing items by the default equality comparator. Also overloaded to take an explicit IComparer<T> as last argument.
- IEnumerable<T> Where(Func<T,bool> p) returns an enumerable that generates those items x of the given enumerable for which p(x) is true. In comprehension notation: (x | xs, where p(x)). See example 239. Typically used in functional languages.

The length of the result is the shortest of xs and ys. In comprehension notation: (f(x,y) | (x,y) -> zip2(xs,ys)).

# 28.6 Numeric Extension Methods on IEnumerable<T> (C# 3.0)

Some extension methods on IEnumerable perform aggregation over numerical values and are applicable only when the item type T is a numeric type or a nullable type. More precisely, they are defined on IEnumerable<N> when N is one of the types decimal, decimal?, double?, int?, float?, and float?. The same requirement applies to the result type N of delegate aggregate f of the numeric aggregation methods Average, Min, Sum (section 28.5).

- Average() computes the average of the numbers in the enumeration. The return type R is double if the type N is int or long, and double if N is int or long?; otherwise the return type R. When N is a nullable type, null items are ignored in the computation, and if the enumeration returns null. When N is not a nullable type and the enumeration is empty, InvalidOperation is thrown. See example 244.
- Max() returns the maximum of the numbers in the enumeration. When N is a nullable type, null items are ignored in the computation, and if the enumeration contains non-null items, the method returns null. When N is not a nullable type and the enumeration is empty, InvalidOperationException is thrown. See example 244.
- Min() returns the minimum of the numbers in the enumeration. When N is a nullable type, null items are ignored in the computation, and if the enumeration contains non-null items, the method returns null. When N is not a nullable type and the enumeration is empty, InvalidOperationException is thrown. See example 244.
- Sum() returns the sum of the numbers in the enumeration. When N is a nullable type, null items are ignored in the computation. and if the enumeration contains non-null items (for instance, if N is not nullable and the enumeration is empty), the method returns zero. See example 244.

# 28.7 Extension Methods on IOrderedEnumerable<T> (C# 3.0)

Static class.Linq.Enumerable defines extension methods on interface IOrderedEnumerable<T> (section 28.4) for applying secondary sorting criteria to already ordered enumerable.

- IOrderedEnumerable<T> ThenBy(Func<T,K> h) returns an ordered enumerable whose items x are ordered primarily by the ordering of the given ordered enumerable, and secondly by ascending values of h(x). See example 241. Also overloaded to take an explicit IComparer<K> as last argument.
- IOrderedEnumerable<T> ThenByDescending(Func<T,K> h) returns an ordered enumerable whose items x are ordered primarily by the ordering of the given ordered enumerable, and secondly by descending values of h(x).

Also overloaded to take an explicit IComparer<K> as last argument.
