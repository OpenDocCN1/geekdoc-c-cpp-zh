Example 50 Multiple Fields with the Same Name
ject of class C in this example has two instance fields nf: one is declared in the base class B, and one is declared in C itself. Similarly, object of class D has three instance fields called nf. Class B and class C have each static field sf. Class D does not declare a static sf, so in class D the name sf refers to the static field sf in the base class C. Example 51 and 87 use these cases.

```
class B {
    // One instance nf, one static sf
    public int nf;
    public static int sf;
    public B(int i) { nf = i; sf = i+1; }
}
class C : B {
    // Three instance fields nf
    public int nf;
    public static int sf;
    public C(int i) : base(i+20) { nf = i; sf = i+2; }
}
class D : C {
    public int nf;
    public D(int i) : base(i+40) { nf = i; sf = i+4; }
```
