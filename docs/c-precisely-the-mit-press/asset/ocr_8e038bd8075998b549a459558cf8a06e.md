Example 205 A Generic List Interface

The generic interface MyList<T> extends the interfaces IEnumerable<T> (section 27.2) and IEquatable<T> (section 27.3) with methods to add and remove list elements, an indexer to get and set the element at a particular position, and a generic method Map<U> that takes as an argument a delegate-in generic type Func<T,U> (page 222) and builds a list of MyList<U>. Note that the generic method Map<U> has an additional type parameter U.

```
public interface MyList<T> : IEnumerable<T>, IEquatable<T> {
    int Count { get; } // Number of elements
    T this[int i] { get; set; } // Gets or sets element at index i
    void Add(T item); // Add element at index
    void Insert(int i, T item); // Inserts element at index i
    void Remove(int i); // Removes element at index i
    MyList<U> Map(Func<T, U> f); // Maps f over all elements
}
```

Example 206 A Generic Polyminal Type. Implementing Generic Twice

A value of type AddMul<A,R> supports addition and multiplication with values of type A, giving results of type R. A value of type Polynomial<E> is a polynomial with coefficients of type E; for this to make sense, values of type E must support addition and multiplication with values of type E, and E must have an argumentless constructor E() that creates a zero element of E.

In return, polynomials over E support addition and multiplication with values of type E (thus implementing interface AddMul<E,Polynomial<E>>) and support addition and multiplication with themselves (thus implementing interface AddMul<Polynomial<E>,Polynomial<E>>).

```
interface AddMul<A,R> {
    R(A a); // Addition with A, giving R
    Mul(A a); // Multiplication with A, giving R
}
```
