
# Example 225 Building a Text Index

This example uses generic Dictionary and List collections to build a list of all words in a given text file and the line numbers on which they occur. The file is read using a StreamReader (section 25.4).

```sharp
IDictionary<String, List<int>> IndexFile(String filename) {
    IDictionary<String, List<int>> index = new Dictionary<String, List<int>>();
    Regex delim = new Regex("[^a-zA-Z0-9]*");
    StreamReader rd = new StreamReader(filename);
    int lineno = 0;
    String line;
    while ((line = rd.ReadLine()) != null) {
        String[] res = delim.Split(line);
        lineno++;
        foreach (String s in res) {
            if (s != "") {
                if (!index.ContainsKey(s))
                    index[s] = new List<int>();
                index[s].Add(lineno);
            }
        }
    }
    rd.Close();
    return index;
}
```

# Example 226 Defining a Set with an Element-Based Hash Code

To use a set as key or element in another collection (examples 223 and 232) the set's hash code must be based on its elements. To ensure that, one may define a class Set<T> on HashSet<T> or SortedSet<T> (section 27.9) with an appropriate definition of hash code, caching it for efficiency.

```csharp
    private readonly HashSet<T> inner = new HashSet<T>();
    private int? cachedHash = null; // Cached hash code is valid if non-null
    public void Add(T x) {
        if (!Contains(x)) {
            inner.Add(x);
            cachedHash = null;
        }
    }
    public override int GetHashCode() {
        if (!cachedHash.HasValue) {
            int res = 0;
            foreach (T x in inner) {
                res += x.GetHashCode();
            }
            cachedHash = res;
        }
        return cachedHash.Value;
```

# 27.6 The List<T> Class

The generic class List<T> implements IList<T> and IList. The elements are stored in an array that grows as needed elements are added. Element access is fast, but insertion and deletion are costly except at the list's end. Class List<T> has the members defined by IList<T> and these, among others:

- Constructor List<T>() creates an empty list.
- Constructor List<T>(int capacity) creates an empty list with a given initial capacity.
- Constructor List<T>(IEnumerable<T> enm) creates a list containing enm.elements.
- Read-write property int Capacity gets or sets the current capacity of the list. Throws ArgumentOutOfRangeException if capacity is less than the number of elements.
- void AddRange(IEnumerable<T> enm) adds elements to the end of the list.
- IList<T> AsReadOnly() returns a read-only list that is a wrapper around the given list.
- int BinarySearch(T x) searches for x using binary search. Returns index i>=0 for a[i].CompareTo(x) == 0; otherwise returns i such that -i would be the position for k. The list must be sorted, or call Sort(cmp); else the result is undefined.
- int BinarySearch(T x, IComparer<T> cmp) works similarly, but compares elements using cmp.Compare. The list must be sorted, or call Sort(cmp); else the result is undefined.
- int BinarySearch(int i, int n, IComparer<T> cmp) works similarly, but searches the list with indices i..(n-1).
- void CopyTo(int src, T[] arr, int dat, int n) copies n elements starting at position src to the array arr, starting at position dat. Throws ArgumentOutOfRangeException if src<0 or dat<0 or n<0.
- int IndexOf(T x, int i) returns the least index greater than or equal to i which element equals x; otherwise returns -1. Throws ArgumentOutOfRangeException if i<0 or i>Count.
- int IndexOf(T x) returns the least index greater than 0 and smaller than Count element x; and two other overloads are similar to IndexOf but return the greater index than the least index at an element equals x.
- void RemoveRange(int i, int n) removes the elements in range i..(n-1).
- void Reverse() reverses the order of the list.
- void Reverse(int i, int n) reverses the elements in range i..(n-1).
- void Sort() sorts the list using quicksort, comparing elements using their CompareTo method. The list elements must implement IComparable<T>. The sort is not stable.
- void Sort(IComparer<T> cmp) sorts the list, comparing elements using cmp.Compare.
- void Sort(int i, int n, IComparer<T> cmp) sorts the segment with indices i..(n-1).
- T[] ToArray() returns a new array containing the elements of the list.
- void TrimSize() shrinks the list's capacity to the actual number of elements.

### Example 227 Simple List Operations
This shows the difference between fast element addition at the end of an array-based list and slow element insertion at the head of the list. The two operations take time O(1)a and O(n) respectively (see the table on page 181). For other list operations, see examples 219 and 228.

```sharp
List<int> lst = new List<int>();
lst.Add(7); lst.Add(9); lst.Add(13);
Print(lst);
// 7 9 13 7
int i1 = 2;
int i2 = lst.IndexOf(7);
// 0
int i3 = lst.IndexOf(12);
// -1
lst.Remove(8); Print(lst);
// 7 9 13 7
lst.Remove(7); Print(lst);

lst.Insert(3, 88); Print(lst);
```

### Example 228 Database Query Results in a List and Returning Them in an Array
Sometimes a method must return an array of results where the number of results is not known in advance. In that case, the results could be produced in a list and transferred to an array when the method returns. This method performs a database query, reads each record from the query, and puts it into a List<Record>, then copies the records to an array and returns them. The full example source code shows how to open the database connection.

```csharp
using System.Data.Odbc; // OdbcConnection OdbcDataReader
using System.Collections.Generic; // List<T>
struct Record {
    public string Name, msg;
}
static Record[] GetMessages(OdbcConnection conn) {
    string query = "SELECT name, msg FROM Message ORDER BY name";
    OdbcCommand cmd = new OdbcCommand(query, conn);
    OdbcDataReader reader = cmd.ExecuteReader();
    List<Record> results = new List<Record>();
    while (reader.Read())
        results.Add(new Record(reader.GetString(0), reader.GetString(1)));
    reader.Close();
    return results.ToArray();
}
```

# 27.7 The Dictionary<K,V> and SortedDictionary<K,V> Classes

Classes Dictionary<K,V> and SortedDictionary<K,V> implement IDictionary<K,V> (section 27.5) and are used to represent maps with keys of K and associated values of V. Dictionary<K,V> is implemented as a hash table, so the keys have good GetHashCode but not be ordered. SortedDictionary<K,V> is implemented as an ordered tree, so the keys should be comparable, IComparable<K>.

Objects used as keys should be immutable; if an object is subsequently modified, then the entry may be lost from the dictionary. Dictionary<K,V> and SortedDictionary<K,V> have the methods of Dictionary<K,V>, constructors (among others), and an additional method:

- Constructor Dictionary<K,V>() creates an empty dictionary.
- Constructor Dictionary<K,V>(int capacity) creates an empty dictionary with a given initial capacity.
- Constructor Dictionary<K,V>(IEnumerable<KeyValuePair<K,V>> enm) creates a dictionary containing enm.elements.
- Read-write property int Capacity gets or sets the current capacity of the dictionary. Throws ArgumentOutOfRangeException if capacity is less than the number of elements.
- void AddRange(IEnumerable<KeyValuePair<K,V>> enm) adds elements to the end of the dictionary.
- IList<KeyValuePair<K,V>> AsReadOnly() returns a read-only list that is a wrapper around the given list.
- int BinarySearch(K key) searches for key using binary search. Returns index i>=0 for a[i].CompareTo(x) == 0; otherwise returns i such that -i would be the position for k. The list must be sorted, or call Sort(cmp); else the result is undefined.
- int BinarySearch(K key, IComparer<K> cmp) works similarly, but compares elements using cmp.Compare. The list must be sorted, or call Sort(cmp); else the result is undefined.
- int BinarySearch(int i, int n, IComparer<K> cmp) works similarly, but searches the list with indices i..(n-1).
- void CopyTo(int src, KeyPair<K,V>[] arr, int dat, int n) copies n elements starting at position src to the array arr, starting at position dat. Throws ArgumentOutOfRangeException if src<0 or dat<0 or n<0.
- int IndexOf(K key, int i) returns the least index greater than or equal to i which element equals key; otherwise returns -1. Throws ArgumentOutOfRangeException if i<0 or i>Count.
- int IndexOf(K key) returns the least index greater than 0 and smaller than Count element equals key; and two other overloads are similar to IndexOf but return the greater index than the least index at an element equals key.
- void RemoveRange(int i, int n) removes the elements in range i..(n-1).
- void Reverse() reverses the order of the list.
- void Reverse(int i, int n) reverses the elements in range i..(n-1).
- void Sort() sorts the list using quicksort, comparing elements using their CompareTo method. The list elements must implement IComparable<T>. The sort is not stable.
- void Sort(IComparer<K> cmp) sorts the list, comparing elements using cmp.Compare.
- void Sort(int i, int n, IComparer<K> cmp) sorts the segment with indices i..(n-1).

# 27.9 The IsSet<T> Interface and the HashSet<T> and SortedSet<T> Classes

The generic interface ISet<T> extends IEnumerable<T> and describes collections that do not duplicates, is sets. The interface is implemented by classes HashSet<T> and SortedSet<T>, of which have implementations of the Add, Contains, and Remove methods; see on page 18. Enumeration (section 27.2) of a sorted set produces the elements in increasing order. A hash set produces the elements in some arbitrary order.

Interface ISet<T> supports operations, each taking an argument B of type IEnumerable<T>. The methods that modify set A are ExceptWith(set difference, A\B), IntersectWith(set intersection,A∩B), SymmetricExcept(symmetric difference, (A\B)∪(B\A)), and Union(set union).

The methods that return a bool without modifying the set A are IsProperSubset(A C B), IsProperSuperset(A > B), IsSubsetOf(A ⊆ B), IsSupersetOf(A ≥ B), Overlaps(A∩B ≠ 0), and Equals(A = B).
