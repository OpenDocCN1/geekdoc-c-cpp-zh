Example 141 Enumerating Solutions to the Eight-Queens Problem
A solution to the n-queens problem is a placement of n queens on an n by chessboard so that no queen
can attack any other queen: there can be at most one queen on any row, column, or diagonal. For n = 8 the
solution is on an ordinary chessboard. The iterator method Queens(w, n) enumerates partial n-queens
solutions with w+1 queens placed in the first w+1 columns of the board. It follows that
Queens(n-1, n) enumerates all solutions to the n-queens problem.

```
public static IEnumerable<int[]> Queens(int w, int n) {
    if (w < 0)
        yield return int[n];
    else
        foreach (int[] sol in Queens(w-1, n)) {
            for (int r=0; r<n; r++) {

                        goto fail;
                }
                sol[w] = r;
```
