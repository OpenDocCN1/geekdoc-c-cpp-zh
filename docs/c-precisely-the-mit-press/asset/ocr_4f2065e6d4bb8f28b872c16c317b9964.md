# 8 String Builders

A string builder, which is an object of class System.Text.StringBuilder, is an extensible and modifiable string. Characters can be appended to a string builder without copying those already in the string builder; the string builder is automatically and efficiently extended as needed.

By contrast, a string object s1, cannot be modified. Using s1 + s2, one creates a new object by copying all the characters from s1 and s2; there is no need to extend s1 itself by appending more characters to it. Thus to concatenate strings of each length k by repeated string concatenation (+), one must copy k + 2k + 3k + ... + nk = kn(n+1)/2 characters, and the time required to do this is proportional to n², which grows rapidly as n.

Using a string builder, the concatenation of strings of each length k requires only time proportional to n. To greatly build a string, use a string builder, for repeated concatenation in a loop, as in examples 20 and 31. The expression s1 + ... + sn is efficient; it actually means StringBuilder().Append(s1). ...Append(sn).ToString().nLet sb be a StringBuilder, a String, and an v of any type:

+   * StringBuilder(v) creates a new empty string builder.
* Append(v) appends the string representation of the v to the string builder, converting v to a string by ToString(), see section 7. Extends sb as needed. Returns sb. For possible formatters fmt, v see section 7.2.
* AppendFormat(String fmt, object v) appends the string String.Format(fmt, v) to the string builder. Extends sb as needed. Returns sb.
* Length of type int is the length of sb, that is, the number of characters currently in sb.
* sb[i] is the character at number i in the string builder, counting from zero. Sb[i] = c sets the character at index i to. Throws IndexOutOfRangeException (when getting a character) or ArgumentOutOfRangeException (when setting a character) if i<0 or i>=sb.Length.
* Remove(i, n) deletes the characters at index i..(i+n-1) from the string builder, reducing its length by n characters. Throws ArgumentOutOfRangeException if i<0 or i+n>sb.Length. Returns sb.
* Insert(i, v) inserts the string representation of v by v.ToString() into the string builder, starting at position i, extending sb as needed. Returns sb. Throws ArgumentOutOfRangeException if i<0 or i>sb.Length.
* ToString() of type String is a new string containing the characters currently in sb.

Method Append is fast, but Remove and Insert can be slow when they need to move large parts of the string builder's contents, that is, when both i and i+n are much smaller than Length.

More StringBuilder methods are described in the .Net Framework class library (section 34).
