Example 252 Using Assert to Specify and Check the Result of an Algorithm
The integer square root of x ≥ 0 is an integer y such that y ≤ x and (y+1) > x. The precondition x ≥ 0 is always checked, if an statement. The postcondition on y is specified by a call to Assert and is checked if assertions are enabled at run-time, which is reassuring, that the algorithm's correctness is never obvious. The assertion uses calls to avoid arithmetic overflow.

```
static int Sqrt(int x) { // Algorithm by Borgerding, Hsieh
  if (x < 0)
    throw new ArgumentOutOfRangeException("Sqrt: negative argument");
  int temp, y = 0, b = 0x8000, bshift = 15, v = x;
  do {
    if (v >= (y << bshift))
      y += b; v -= bshift;
  } while ((b >>= 1) > 0);
  Debug.Assert((long)y <= x && (long)(y+1) > x);
  return y;
}
```

Example 253 Using Assert to Specify and Check Invariants
A list of words is to be formatted as a line of text. Its length is the minimum number of characters needed to format the words and the interspace spaces, which are the lengths of the words plus the number of words 1. Those methods change the word list use Assert to specify the invariant of the field length, and check it if assertions are enabled at compile.

```
class WordList {
  private Queue<String> strings = new Queue<String>();
  private int length = -1; // Invariant: equals words length plus interspaces
  public int Length { get { return length; } }
  public void Enqueue(string s) {
    length += 1 + s.Length;
    Debug.Assert(length == computeLength() + strings.Count - 1);
  }
  public string RemoveFirst() {
    String res = strings.Dequeue();
    length -= 1 + res.Length;
    Debug.Assert(length == computeLength() + strings.Count - 1);

}
```
