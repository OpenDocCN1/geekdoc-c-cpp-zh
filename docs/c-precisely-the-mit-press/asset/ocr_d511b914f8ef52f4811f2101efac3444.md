# 28.3 Differences between Linq and SQL

A Linq query select ... is rather similar to a SQL query select from ..., but one cannot use *, and some operations that are expressed as part of an SQL query must be expressed in Linq by calling a method on a result:

+   - Instead of SQL's SELECT COUNT(*) FROM ..., in Linq use (from select ...).Count().nSimilarly, instead of the other SQL aggregation functions AVG, MAX, MIN, and SUM, Linq extension methods Average(), Max(), Min(), and Sum(), described in section 28.6.
- Instead of SQL's DISTINCT(...) FROM ..., in Linq use (from select ...).Distinct().
- Instead of SQL's UNION (SELECT ...) UNION (SELECT ...), in Linq use (from ...).Union(from select ...).
Similarly, instead of SQL's EXCEPT and intersect operators, Linq extension methods Except and Intersect.
- Instead of SQL's HAVING operator, group ... by ... int g where ...

# 28.4 Auxiliary Interfaces That Support Linq (C# 3.0)

Enumerables support Linq queries because the interface IEnumerable<T> implements the query pattern (section 27.2) via its extension methods (methods 28.5). The G<K,T> and O<T> parts of the query expression are implemented by two additional interfaces, IGrouping<K,T> and IOrderedEnumerable<T>.

IGrouping<K,T> in namespace SystemLinq extends IEnumerable<T> and is used to represent a group of items. Extension methods such as GroupBy produce an enumerable of IGrouping<K,T> objects (section 28.5). An Igrouping<K,T> supports enumeration of its items because it derives from IEnumerable<T>, and in addition it can return the group's key:

+   - Read-only property Key returns the group's key.

ILookup<K,T> in namespace SystemLinq extends IEnumerable<IGrouping<K,T>> and represents a collection of groups of items. The interface derives from IGrouping<K,T> and supports all the methods defined on it. In addition an ILookup<K,T> can retrieve a group by well as the number of groups:

+   - Read-only indexer IEnumerable<T> this[K key] returns an enumerable generating the items in the group with key k.
- Read-only property Count returns the number of groups.

IOrderedEnumerable<T> in namespace SystemLinq extends IEnumerable<T> and represents an ordered enumerable: one in which the items have been ordered by one or more criteria. The interface derives from IEnumerable<T> and supports all the extension methods defined on interface. Application of further orderings (via extension methods) ThenBy and ThenDescending; see section 28.7) respects the ordering already applied.
