Choosing an Appropriate Collection Class The running time or time complexity of an operation on a collection is usually given in O notation, as a function of size of the collection. O(1) means constant time, O(log n) means logarithmic time (time at most proportional to the logarithm of n), and O(n) means linear time (time at most proportional to n). For adding, or removing an element, respectively corresponds to very fast, fast slow.
in this case, n is the number of elements in the collection and i is an integer index. Removing an element of a List is fast only near the end of the list, where n-i is small. The average time per operation indicates amortized complexity: over a sequence of operations, O(1) means any single operation could take O(n). HashSet and Dictionary use element hash (and therefore their operations have similar speeds), whereas SortedSet and SortedDictionary use element comparison.
