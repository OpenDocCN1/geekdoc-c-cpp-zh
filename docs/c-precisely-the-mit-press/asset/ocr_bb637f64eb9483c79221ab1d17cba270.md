# Example 81 Object Initializer

An object initializer is used to initialize variable p1 of class Point (example 61). This has the same effect as the three-stage initialization of Point p2. The initialization of p3 first calls the constructor Point (Point) and then changes the value of field y to 17. This has the same effect as the two-stage initialization of Point p4.

```
Point p1 = new Point { x = 10, y = 12 };
Point p2 = new Point(); p2.x = 10; p2.y = 12; // Equivalent to p1 initialization
Point p3 = new Point(p1) { y = 17 };
Point p4 = new Point(p1); p4.y = 17; // Equivalent to p3 initialization
```

# Example 82 Nested Object Initializers

A Rectangle object has an upper left and a lower right corner, declared as automatically implemented properties (section 10.15) called U1 and Lr. A Rectangle r1 can be initialized using these properties. Moreover, by using r2, one can use nested object initializers. This has the same effect as the five-stage initialization of r3. We work only because the Rectangle( ) constructor initializes U1 and Lr with Point objects; otherwise the dereferencing r3.U1 and so on would cause NullReferenceExceptions.

```
public class Rectangle {
    public Point U1 { get; set; } // Upper left corner
    public Point Lr { get; set; } // Lower right corner
    public Rectangle() { U1 = new Point(); }
}
Rectangle r1 = new Rectangle { U1 = new Point { x = 10, y = 12 };
Rectangle r2 = new Rectangle { U1 = { x = 10, y = 12 }, Lr = { x = 14, y = 20 } };
Rectangle r3 = new Rectangle { U1.x = 10; U1.y = 12; Lr.x = 14; Lr.y = 20; };
```

# Example 83 Collection Initializer

Variable list1 is initialized by the collection initializer. This has the same effect as the five-stage initialization of list2. Since each inner group has one member and contains no assignment, the inner braces may be omitted, as for list3. The initialization of list4 shows a case where the inner braces cannot be omitted. Dictionary<K,V> (section 27.7) has a Add(K,V) for adding a key-value pair to the dictionary, so a dictionary can be initialized by a collection initializer.

```
List<int> list1 = new List<int> { { 2 }, { 3 }, { 2+3 }, { 5 + 2 };
List<int> list2 = new List<int>();
list2.Add(2+3); list2.Add(2+3); list2.Add(5+2);
List<int> list3 = new List<int> { 2, 3, 5+ 2 };
int cinq, sept;
List<int> list4 = new List<int> { 2, 3, { cinq = 2 }, { sept = cinq + 2 } };
var numerals = new Dictionary<int,String> { 1, "one" }, { 2, "two" }, { 5, "five" };
```
