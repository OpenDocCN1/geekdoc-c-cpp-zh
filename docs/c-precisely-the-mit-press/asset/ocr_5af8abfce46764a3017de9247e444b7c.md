# Variables, Parameters, Fields, and Scope

Example 2 Scope of Fields, Parameters, and Variables
This program declares five variables or fields, all called x, and shows where each one is in scope.
The field and the variables are labeled #1,...,#5 for reference only.

```
class Scope {
void M1(int x) { // Declaration of parameter x (#1); shadows x (#5)
    x = ?; // x #1 in scope; legal, but no effect outside M1
}
void M3() {
    int x; // Declaration of variable x (#2); shadows x (#5)
    x = ?; // x #2 in scope
}
void M4() {
    int x; // x #5 in scope
    // Would be ILLEGAL, giving a new meaning to x
}
void M5() {
    int x; // Declaration of variable x (#3); shadows x (#5)
    x = ?; // x #3 in scope
{
        int x; // Declaration of variable x (#4); shadows x (#5)
        x = ?; // x #4 in scope
}
    public int x; // Declaration of field x (#5)
}
```

Example 13 Definite Assignment
x is definitely assigned (#1) below because it gets assigned regardless of branch of the
if statement is executed, but y is not, because it gets assigned only in one of the branches. Variable z
is not definitely assigned (#3) because it will be assigned only if the body of the loop gets executed
(and the compiler does not take the value of variables in loop conditions into account when determining
hat).

```
int x, y, z;
if (args.Length == 0)
    x = 10;
else
    x = args.Length;
Console.WriteLine(x); // x definitely assigned, and z not (#1)
y = x;
for (int i=0; i<y; i++) // x and y definitely assigned, z not (#2)
    z = i;
Console.WriteLine(z); // z still not definitely assigned (#3)
```
