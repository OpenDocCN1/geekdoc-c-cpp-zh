# 12.18 Property Access Expression

A property get-access must have one of these three forms:

+   - P
- C.P
- o.P
- base.P

where C is a class and o an expression of reference type. In the first case, P must be a static or instance property declared in an enclosing class. In the second case, P must be a static property declared in C. In the third case, P must be an instance property declared in the type of o, where o is a value. In the fourth case, P must be an instance property declared in the base class. Property declarations are described in 10.15.

In each case, the type of the property get-access expression is the declared type of the property P. A property get-access is evaluated by evaluating o, if present, and then executing the body of the getaccessor. The value is the value returned by the return statement that terminates the execution of the get-accessor's body. Such a return will eventually be executed, provided the get-accessor terminates normally (section 10.15). If o is present but evaluates to null, NullReferenceException.

A property set-access must have one of these three forms:

+   - P = expression
- C.P = expression
- o.P = expression
- base.P = expression

A property cannot be used as a ref or out parameter.
