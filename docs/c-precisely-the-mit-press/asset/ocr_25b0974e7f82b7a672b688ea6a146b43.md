# String Methods

Let s1, s2 and s3 be expressions of String, let cs be an expression of char[], and let v be annexpression of type:

+   - String.Compare(s1, s2) returns a negative integer, zero, or a positive integer, as sl
precedes, equals, or follows s2 in the lexicographical ordering based on the Unicode character
encoding and the culture of the current thread. The null reference precedes any non-null string.
- String.Compare(s1, s2, ignoreCase) works similarly, but does not distinguish lowercase and
uercase if ignoreCase is true.
- s1.CompareTo(s2) has the same meaning as String.Compare(s1, s2) when s1 is not null.
- s1.ToUpper() and s1.ToLower() create a copy of s1 in uppercase and lowercase, respectively.
- s1 + s2 has the same meaning as String.Concat(s1, s2). It constructs the concatenation of s1 and
s2: a new string consisting of the characters of s1 followed by the characters of s2.
- s1 + v are evaluated by converting v to v.ToString() and then con
ating the two strings. If v or v.ToString() is null, the result of the concatenation is s1.
- s1.Substring(i, n) creates a new string containing the n characters from s1 with indices
[i..i+n]. Throws ArgumentOutOfRangeException if i<0 or n or i+n>s1.Length.
- s1.Split(cs of type String[]) is an array of (possibly empty) substrings of s1 that
contains no characters from cs, from left to right. Here cs is either a single argument of type
char[], or zero or more arguments of type char (example 23). Namely, cs is a so-called parameter
array (example 12.17.3).
- s1.StartsWith(s2) and s1.EndsWith(s2), both of type, determines whether s1 starts,
pectively, with the substring s2.
- s1.Remove(i, n) creates a new string from s1 by removing the characters that have indices
[i..i+n-1]. Throws ArgumentOutOfRangeException if i<0 or n or i+n>s1.Length.
- s1.Replace(s2, s3) creates a new string by replacing all non-overlapping occurrences
of the substring s2 with s3 from left to right. If each of s1 and s2 is a single character c1 and c2,
it is much faster than s1.Replace(c1, c2) with String Replace(char, char).
- s1.Trim() creates a new string from s1 by removing all occurrences of char[ ]
from the beginning and end of s1. To remove white characters (including space, newline,
tabor, form feed, and vertical tab) from the beginning and end of s1. If s1
contains only ASCII characters, this is equivalent to s1.Trim("\r\t\f\v").ToCharArray())
- The effect of s1.TrimStart(cs) and s1.TrimEnd(cs) is the same as of s1.Trim(cs), except
characters are only removed at the beginning or end, respectively, of s1.
- s1.ToArray() returns a new character array containing the characters of s1.

More String methods are described in the .NET Framework class library (section 34).
