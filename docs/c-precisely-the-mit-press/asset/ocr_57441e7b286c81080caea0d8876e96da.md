# 10.13 Member Classes or Nested Classes

A nested class is declared inside another class or struct type declaration. The code of a nested class may refer to all static members, even private ones, of the enclosing class or struct type but cannot refer to its members except through a reference to an instance of the enclosing class or struct type. In contrast to Java, C# has no notion of an inner class, whose instances would contain a reference to an instance of the enclosing class.

A member used in a nested class C denotes a member from the innermost enclosing class that declares or inherits a member of that name. That is, if class C has base class B and is declared as a nested class in E, then name resolution in C prefers members declared in C or (non-private) members inherited from base class B over members of the enclosing class E (example 90).

A nested class may have static members as well as instance members.

# 10.14 Class Access Modifiers

The class-modifiers (section 10.1) may include an access modifier to control the accessibility of the class. For a class declared at top level in a compilation unit or at top level a namespace (section 29), the access modifier may be public or absent (which means internal). A public top-level class is accessible in all assemblies; an internal top-level class is accessible only in the assembly (section 1.1) to which it belongs.

For a class declared inside a class or struct type, the access modifier may be one of the member access modifiers (section 10.3).
