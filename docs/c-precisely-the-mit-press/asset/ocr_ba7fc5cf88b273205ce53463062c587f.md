# Example 43 Class Declaration

The Point class is declared to have two instance fields x and y, one constructor, and two instance methods. It is used in examples 24 and 71.

```
public class Point {
    protected internal int x, y;
    public Point(int x, int y) { this.x = x; this.y = y; }
    public void Move(int dx, int dy) { x += dx; dy += dy; }
    public override String toString() { return "(" + x + ", " + y + ")"; }
}
```

# Example 44 Class with Static and Instance Members

The APoint declares a static field allpoints and two instance fields x and y. Each APoint object has its x and y fields, but all objects share the same allpoints field in the APoint class.

The constructor inserts the new object (this) in the array list allpoints. The instance method GetIndex returns the point's index in the list. The static method GetSize returns the number of APoint objects created so far. Instead of the methods GetIndex and GetSize it would be natural to use an instance property and a static property (section 10.15 and example 66). The static method GetPoint returns the ith APoint in the list. The class is used in example 91.

Be aware that every APoint will be reachable from allpoints. This prevents automatic recycling (garbage collection) of APoint objects at run-time; objects should not be kept live unless there is a very good reason to do so.

```
public class APoint {
    private static List<APoint> allpoints = new List<APoint>();
    private int x, y;
    public APoint(int x, int y) { allpoints.Add(this); this.x = x; this.y = y; }
    public void Move(int dx, int dy) { x += dx; dy += dy; }
    public override String toString() { return "(" + x + ", " + y + ")"; }
    public int GetIndex() { return allpoints.IndexOf(this); }
    public static int GetSize() { return allpoints.Count; }
    public static APoint GetPoint(int i) { return allpoints[i]; }
}
```
