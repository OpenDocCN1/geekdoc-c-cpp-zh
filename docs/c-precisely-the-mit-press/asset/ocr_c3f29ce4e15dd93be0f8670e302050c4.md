# Example 192 Organizing a String Array for Random Access

This example shows a way to implement large numbers of texts, such as millions of cached pages or millions of DNA sequences. Define a string array to have three parts: (1) a sequence of strings, each of which is in UTF-8 format; (2) a sequence of integers, representing the start offsets of the strings; and (3) an integer, which is the number of strings in the file.

Put the number of strings and the string offset at the end of the file, so that it is not necessary to know the number of strings or the length of each string before writing the file. The strings can be written to the file incrementally, and the only structure to keep in memory is the table of strings. The table is represented as a List<Long>(27.6) for type safety and performance.

```
static void WriteStrings(String filename, String[] data) {
FileStream raf = new FileStream(filename, FileMode.Create);
BinaryWriter sw = new BinaryWriter(raf);
raf.SetLength(0);                                // Truncates the file
List<Long> offset = new List<Long>();
foreach (string s in data) {
    offset.Add(raf.Position);                    // string offset
    sw.Write(s);                                // Writes string
}
foreach (long v in offset) {\ // Writes string offsets
    Console.WriteLine(v);
}
sw.Write(v);\ // string count
sw.Close();
```

# Example 193 Random Access Reads from a String Array File

The method call ReadString(f, i) reads string number i from string array file f (example 192) in three stages, using three calls to Seek. First, it reads the offset table N from the last 4 bytes of the file. Second, since an int takes 4 bytes and a long takes 8 bytes (section 5.1), the string offset table must begin at position Length-4-8*N, and so the offset of string number i can be read from position Length-4-8*N+i. Third, the string is read from offset.

```
static string ReadString(String filename, int i) {
const int IntSize = 4, LongSize = 8;
FileStream raf = new FileStream(filename, FileMode.Open);
raf.Seek(raf.Length - IntSize, SeekOrigin.Begin);
BinaryReader br = new BinaryReader(raf);
int n = br.ReadInt32();
raf.Seek(raf.Length - IntSize - n * LongSize + i, SeekOrigin.Begin);
long si = br.ReadInt64();
raf.Seek(si, SeekOrigin.Begin);
String s = br.ReadString();
br.Close();
return s;
}
```
