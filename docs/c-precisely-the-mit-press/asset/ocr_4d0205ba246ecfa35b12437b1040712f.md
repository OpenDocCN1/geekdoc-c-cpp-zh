# Example 225 Building a Text Index

This example uses generic Dictionary and List collections to build a list of all words in a given text file and the line numbers on which they occur. The file is read using a StreamReader (section 25.4).

```
IDictionary<String, List<int>> IndexFile(String filename) {
    IDictionary<String, List<int>> index = new Dictionary<String, List<int>>();
    Regex delim = new Regex("[^a-zA-Z0-9]*");
    StreamReader rd = new StreamReader(filename);
    int lineno = 0;
    String line;
    while ((line = rd.ReadLine()) != null) {
        String[] res = delim.Split(line);
        lineno++;
        foreach (String s in res) {
            if (s != "") {
                if (!index.ContainsKey(s))
                    index[s] = new List<int>();
                index[s].Add(lineno);
            }
        }
    }
    rd.Close();
    return index;
}
```

# Example 226 Defining a Set with an Element-Based Hash Code

To use a set as key or element in another collection (examples 223 and 232) the set's hash code must be based on its elements. To ensure that, one may define a class Set<T> on HashSet<T> or SortedSet<T> (section 27.9) with an appropriate definition of hash code, caching it for efficiency.

```
class Set<T> : IEquatable<Set<T>>, ICollection<T> where T : IEquatable<T> {
    private readonly HashSet<T> inner = new HashSet<T>();
    private int? cachedHash = null; // Cached hash code is valid if non-null
    public void Add(T x) {
        if (!Contains(x)) {
            inner.Add(x);
            cachedHash = null;
        }
    }
    public override int GetHashCode() {
        if (!cachedHash.HasValue) {
            int res = 0;
            foreach (T x in inner) {
                res += x.GetHashCode();
            }
            cachedHash = res;
        }
        return cachedHash.Value;
    }
```
