# Example 161 Declaring an Application Exception Class

This is the class of exceptions thrown by method WeekdayNo4 (example 134). The string passed to the constructor of the base class ApplicationException is the string that will be returned by the Message property of the exception.

```
class WeekdayException : ApplicationException {
    public WeekdayException(String wday) : base("Illegal weekday: " + wday) {
}
}
```

# Example 162 Paths through a try-catch-finally statement

To exercise 12 paths through the try-catch-finally statement (section 13.8.2) in method M, run the program with each of the command-line arguments 1yz 102 201 202 301 302 411 421 422 432. The try clause terminates normally on 1yz, exits by return on 2yz, and throws an exception on 3yz and 4yz. However, when z is 2, the finally clause takes over. The catch clause ignores exceptions on 3yz but catches them on 4yz. The catch clause terminates normally on 41, but by return on 421, and throws an exception on 431 and 432. The finally clause terminates normally on xy1 and lets the try or catch clause determine whether terminate normally, by return, or by throwing an exception. The finally clause throws an exception on xy2 (the only exception thrown if the try and catch clauses did not throw an uncaught exception, but if they did an uncaught exception, then finally's exception will be thrown addition)

Exits by break and continue statements are handled similarly to return; a more involved example could be constructed to illustrate their interaction.

```
class TryCatchFinally {
    public static void Main(String[] args) {
        Console.WriteLine(int.Parse(args[0]));
    }

    static void M(int a) {
        try {
            Console.Write("try ... ");
            if (a/100 == 2) return "returned from try";
            if (a/100 == 3) throw new Exception("thrown by try");
            if (a/100 == 4) throw new ApplicationException("thrown by try");
        } catch (ApplicationException) {
            Console.Write("catch ... ");
            if (a%100 == 2) return "returned from catch";
            if (a%100 == 3) throw new Exception("thrown by catch");
        }
        finally {
            Console.WriteLine("finally");
            if (a%10 == 2) throw new Exception("thrown by finally");
        }
        return "terminated normally with " + a;
    }
}
```
