# 27.3 Comparables, Equatables, Comparers, and EqualityComparers

Some values can be compared for ordering (such as less-than), and some values only for equality. A type may implement interfaces that describe methods for order comparison and equality comparison.

An order comparison method as compareTo returns a negative number to indicate less-than, zero to indicate equality, and a positive number to indicate greater-than. The method must define a partial ordering; it be reflexive, antisymmetric, and transitive. Define what is the opposite sign of positive and vice versa, and zero is the opposite sign of zero. The requirements they are:

+   * x.CompareTo(x) must be zero.
* x.CompareTo(y) and y must have opposite signs.
* If one of x.CompareTo(y) and y.CompareTo(z) is zero, x.CompareTo(z) must have the sign of the other one; and if both have the same sign, x.CompareTo(z) must have that sign.

# 27.3.1 IComparable, IComparable<T> and IEquatable<T> Interfaces

The non-generic System.IComparable describes this method:

+   * compareTo(Object object) must return a negative number when the current object (this) is less than that, zero when they are equal, and a positive number when this is greater than that.

The generic system System.IComparable<T> describes this method:

+   * compareTo(T that) must return a negative number when the current object (this) is less than that, zero when they are equal, and a positive number when this is greater than that.

The generic system System.IEquatable<T> describes this method:

+   * equals(T that) must return true if the current object (this) is equal to that; otherwise false.

Type int implements IComparable<int> and IEquatable<int>, and similarly for the other numeric types, for the String class (section 7), and for enum types.

# 27.3.2 The IComparer, IComparer<T>, and EqualityComparer<T> Interfaces

The non-generic System.Collections.Generic describes this method:

+   * compare(Object ol, Object obj2) must return a negative number when ol is less than obj2, zero when they are equal, and a positive number when ol is greater than obj2.

The generic system System.Collections.Generic.IComparer<T> describes these methods:

+   * compare(T v1, T v2) must return a negative number when v1 is less than v2, zero when they are equal, and a positive number when v1 is greater than v2.

The generic system System.Collections.Generic.EqualityComparer<T> describes these methods:

+   * equals(T v1, T v2) must return true if v1 is equal to v2; otherwise false.
* getHashCode(T v) must return a hashcode for v (section 5.2).
