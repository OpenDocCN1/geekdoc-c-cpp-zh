# 25.6 Binary Input and Output: BinaryReader and BinaryWriter

BinaryReader reads values of simple type or String from a binary-format stream. BinaryWriter writes such values to a binary-format stream. The classes have the following constructors:

+   - BinaryReader(Stream s) creates a reader that reads from input s in UTF-8 encoding.
- BinaryReader(Stream s, Encoding enc) creates a reader that reads from s in encoding enc.
- BinaryWriter(Stream s) creates a writer that writes to s using the UTF-8 encoding.
- BinaryWriter(Stream s, Encoding enc) creates a writer that uses encoding enc.

They throw ArgumentException if s is closed or does not support reading (resp. writing), and ArgumentNullException if s or enc is null.
The BinaryReader class has the following methods:

+   - Read() reads the next character and its integer value. Returns -1 on end-of-stream.
- Read(byte[] b, int i, int n) and Read(char[] b, int i, int n) read n bytes (characters) from the stream into b[i..i+n-1]. They throw ArgumentOutOfRangeException if i<0 or n<0, ArgumentException if i+n>b.Length, and ArgumentNullException if b is null. They return 0 on end of stream.
- ReadBoolean(), Read(), ReadChar(), ReadInt16(), ReadUInt16(), ReadInt32(), ReadUInt32(), ReadInt64(), ReadUInt64(), ReadSingle(), ReadDouble(), ReadDecimal() read values from the underlying stream and return a value of type byte, char, short, int, uint, long, float, or decimal. The methods throw EndOfStreamException on end-of-stream.
- ReadBytes(int i) and ReadChars(int i) reads i bytes (or characters) from the stream into a new byte array (or char array) and returns the array.
- ReadString() reads bytes and converts them to a string using the encoding.
- char PeekChar() returns the next character from the stream without advancing the stream.

BinaryWriter has several properties and methods; they throw IOException if the underlying stream is closed:

+   - Read-only property BaseStream is the underlying stream.
- Write(byte[] b, int i, int n) and Write(char[] b, int i, int n) writes n bytes or characters from b[i..i+n-1]. They throw ArgumentOutOfRangeException if i<0 or n<0, ArgumentException if i+n>b.Length, and ArgumentNullException if b is null.
- Write(bool v, short, short, int, uint, long, ulong, float, or decimal) writes write value v in binary format to the underlying stream.
- Write(String s) converts string to bytes using the encoding and writes them to the stream.
- Write(byte[] b) and Write(char[] b) writes the bytes or characters from the array.
- Seek(int i, SeekOrigin so) sets the position to i relative to so and returns the new position of the stream; it can be SeekOrigin.Begin, SeekOrigin.Current, or SeekOrigin.End.
- Flush() writes all data to the underlying stream or file and then clears all buffers.
- Close() flushes and closes the writer.
