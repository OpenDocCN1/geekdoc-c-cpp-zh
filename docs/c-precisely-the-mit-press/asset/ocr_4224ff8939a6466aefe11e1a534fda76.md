# Delegate Types

A declaration of a delegate type introduces a new distinct type, useful for creating a closure (a value that represents a function) from a static or instance method regardless of its declaring class. A delegate-type-declaration has the form

```
delegate-modifiers delegate returntype D(formal-list);
```

The delegate-modifiers control the accessibility of the delegate type D and follow the same rules as class modifiers (section 10.14). The modifiers abstract and sealed cannot be used. A delegate type is a reference type (section 5.2) and is derived from System.Delegate.
Operations on:

+   * To create a delegate D of type D, evaluate D(M), where M is a static or instance method, or new D(o,M); where M is an instance method; or simply assign o. to a variable or parameter of type D. In both cases, the method must be compatible with delegate type D. The invocation list of the resulting delegate calls M only.

If M is an instance method in a reference type, then a reference (the value of this or o) is included with the method. If M is an instance method in a value type, then a boxing conversion (section 5.3.3) occurs, and a reference to a boxed copy of the value is included with the method.

+   * To call a delegate d1, evaluate the call d1(actual-list), where actual-list must be a call to a method (section 12.17) in the delegate's invocation list. A call to the delegate calls all methods in its invocation list; if the invocation list is empty, the call throws NullReferenceException. If the return type is non-void, the result of the delegate is the result of the method called. If the delegate has a ref parameter, that is passed through all the methods. If the delegate has an out parameter, that is set by the method called. If some method in the invocation list throws an exception, then no more methods in the list are called, and the delegate calls the same exception.

+   * Delegates can be combined using the operators + and +=. The invocation list of d1+d2 consists of the invocation list of d1 followed by the invocation list of d2. A method can appear multiple times on the invocation list.

+   * Methods can be removed from a delegate using the operators - and -=. The invocation list of d1-d2 consists of the invocation list of d1, except that methods appearing in the invocation list of d2 are removed by one from the end of d1. If a method appears multiple times in d1, the last occurrence in d1's invocation list is removed first.

A method is compatible with a delegate type if it has the same returntype and the same signature, as is-formal, as the delegate; also ref and out specifications must match.

The Func and Action families of generic delegate allow the description of functions (that return a result) and actions (that do not) up to 16 arguments. See also examples 212, 213, and 218:

```
delegate Func<out R>();
delegate void Action<out R>(Al xl);
delegate Func<in Al, out R>(Al xl);
delegate void Action<in Al, out R>(Al xl);
```
