# Example 214 A Generic Type for Pairs

A pair of two values of type T and U can be represented by a generic type Pair<T,U>. The generic struct type has read-only fields for holding the components, and a constructor for creating pairs.

```
public struct Pair<T,U> {
    public readonly T Fst;
    public readonly U Snd;
    public Pair(T fst, U snd) {
        this.Fst = fst;
        this.Snd = snd;
    }
}
```

# Example 216 A Generic Struct Type to Represent Possibly Missing Values

Struct Option<T> can represent a value of type T that may be missing. Sometimes the null reference is used to mean "missing", but this is impossible for value types. The generic struct Nullable<T> serves a similar purpose but be used only for argument types T that are value types (section 19). Note that the default value of the HasValue field is false, so the struct'sless constructor Option<T>() constructs a missing value.

```
public struct Option<T> {
    public readonly bool HasValue;
    private readonly T value;
    public Option(T value) { this.HasValue = true; this.value = value; }
    public T Value() {
        if (this.HasValue) return value;
        else throw new InvalidOperationException("No value");
    }
    public static operator Option<T>(T value) { return new Option<T>(value); }
    public static explicit operator T(Option<T> option) { return option.Value; }
    public override string ToString() { return HasValue ? value.ToString() : "[No value]"; }
}

public static Option<double> Sqrt(double x) {
    return x >= 0.0 ? new Option<double>(Math.Sqrt(x)) : new Option<double>();
}
```
