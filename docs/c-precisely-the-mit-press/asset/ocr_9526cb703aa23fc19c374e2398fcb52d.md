Example 69 User-Defined Conversions
An implicit conversion of (byte)5 to Frac makes a standard implicit conversion from byte to int
 then an implicit conversion to Frac. An explicit conversion from Frac f2 double first makes an
explicit (possibly lossy) conversion from Frac to float and then a standard implicit conversion to double.

```
struct Frac : Comparable
    public readonly long n, d;
    public Frac(long n, long d) { ... }
    public static implicit operator Frac(int n) { return Frac(n, l); };
    public static implicit operator Frac(long r) { return Frac(n, r); };
    public static explicit operator long(Frac r) { return r.n/d; }
    public static explicit operator float(Frac r) { return (float)r.n/d; };
```

```
Frac f1 = (byte)5;
Frac f2 = 1234567890123L;
int i2 = (int)f2;
double d2 = (double)f2;
// Implicit -->Frac
// Implicit long-->Frac
// Explicit Frac-->long
// Explicit Frac-->float
```

Example 70 Temperature Readings as Events

A thermometer makes (simulated) temperature readings from time to time. Can call handlers of
type Handler) to the thermometer's reading event; when a new (simulated) temperature reading is made,
t thermometer calls these handlers. Only the thermometer can call the event handlers.

```
delegate void Handler(double temperature);
class Thermometer {
    public event Handler HandlerReading;
    private int temperature = 80;
    private static Random rnd = new Random();
    public Thermometer() { new Thread(ThreadStart(Run)).Start(); };
    private void Run() {
        for ({}) { // Forever simulate new readings
            temperature += rnd.Next(-5, 6); // Random number in range -5..5
            if (Reading == null) // If there are any handlers,
                Reading(temperature);
                Thread.Sleep(rnd.Next(2000)); // call them with the new reading
        }
    }
}
```
