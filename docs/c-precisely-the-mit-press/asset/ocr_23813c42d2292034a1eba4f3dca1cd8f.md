Example 64 An Enumerator as a Member Class
The member class SeqEnumerator, declared inside struct Seq (example 68), can enumerate the elements of a sequence. To support the foreach statement (section 13.6.2), the SeqEnumerator class must have a property Current to get the current sequence element and a method Next to move to the next one. If it has methods Dispose and Reset, it can implement interfaces IEnumerator and IEnumerator<T> explicit interface member implementation (section 15.3) of Current with return type Object is needed for the non-generic IEnumerator. The yield return statement provides a radically simpler implementation of enumerators (section 13.12 and example 140).

```
private class SeqEnumerator : IEnumerator {
    private readonly Seq seq;
    private int i;
    public SeqEnumerator(Seq seq) { this.seq = seq; Reset(); }
    public int Current {
        // For IEnumerator<int>
        get {
            if (0 < i && i < seq.n)
                return seq.b + seq.k * i;
            else
                throw new InvalidOperationException();
        }
    }
    object SC.Current { return Current(); } // For IEnumerator
    public bool Next() {
        return ++i < seq.n;
    }
    public void Reset() { i = -1; } // For IEnumerator
    public void Dispose() { } // For IEnumerator<int>
}
```

Example 65 Nested Classes Can Access All Static Members of Enclosing Class
The nested class C.D can access all static members of the enclosing class C, even private ones, as well as non-private static members of the base class B of the enclosing class. The enclosing class cannot access the private members of a nested class C.D.

```
class B {
    protected static int bx = 10;
    private static int bz = 10;
}
class C : B {
    private static int cx = 11;
    public class D {
        private static int dx = bx + cx; // Can access protected bx and private cx
        // public static int dz = bz + 2; // Cannot access private bz in base class
    }
    static void m() {
        int z = D.dx; // Cannot access private dx in nested class
    }
}
```
