# 13.12 The yield Statement and Iterators

The yield statement is used to define enumerators and enumerables (section 27.2) in a convenient way.
The yield statement can be used only inside the body of a method or operator, or the get-accessor of a property or indexer, whose return type is IEnumerator, IEnumerable, IEnumerator<T>, or IEnumerable<T>. The body of this iterator method is then called an iterator block, and the yield type of the iterator block is Object or T, respectively. A yield statement cannot appear in an anonymous method.

A yield statement must have one of these two forms:
yield return;
yield break;

The type of expression must be implicitly convertible to the yield type of the enclosing block.
The statement will return expression a value to a caller, just as a return statement does, but it does not terminate the enclosing block and does not execute any associated finally. Instead, the execution of the iterator block can be resumed after the yield statement, causing the iterator block to execute more yield statements. When the iterator block executes the yield break, or terminates by reaching the end of the iterator block, or throws an exception, it executes any associated classes, and exception cannot be resumed any more. Using the yield statement, an iterator block can produce a sequence of zero or more values.

An iterator method cannot have ref out parameters and cannot contain a return statement.
A yield return statement cannot appear inside a catch clause or inside a statement that has an attached clause. A yield break statement can appear anywhere in the iterator method except in a finally clause or an anonymous method.

The compiler turns the iterator block into a class that implements IEnumerator and IEnumerable<T>, so it has a Current property whose is the yield type, and methods MoveNext() with return type bool and Dispose() with return type. A call to the iterator method creates an instance of this class, an iterator object. It has four states: Before (the initial state), Running, Suspended, and the value of Current is defined only in the Suspended state. If the iterator method has return type IEnumerable or IEnumerable<T>, the compiler also creates another method that implements IEnumerable and IEnumerable<T>, so it has a GetEnumerator() method. A call to the iterator method creates an instance of this, from which independent enumerator objects can be obtained by foreach statements.
