# Example 97 Calling Overridden Methods

Consider the classes A, B, C, D and E (example 55). In a call such as ae.M2() the compile-time target type is A, and the target object's run-time class is E. As seen, if a method is a non-virtual instance method in the compile-time target type, then only the compile-time type matters: ae.M2() calls M2 in A although the target object's run-time class is E. When the method is virtual or abstract in the compile-time target type, the target object's class methods: .M2() calls M2 in class E is marked in the compile-time target type D, and the target object's class is E.

For virtual instance methods, note that method M5 in E is an override M3 in D, but not M3 in C. The reason is the modifier new virtual in class D, which hides the inherited from C.

```
A.M1(); B.M1(); C.M1(); D.M1(); E.M1(); // A.M1 A.M1 C.M1 C.M1
E = new E(); D = de; C = ce; B = be; Ae = ae; ee =;
ae.M2(); be.M2(); ce.M2(); de.M2(); ee.M2(); // A.M2 A.M2 C.M2 E.M2 E.M2
ae.M3(); be.M3(); ce.M3(); de.M3(); ee.M3(); // C.M3 C.M3 E.M3 E.M3
ab = new B(); A = new C();
ab.M2(); ac.M2(); // // A.M2 A.M2 A.M2
ab.M3(); ac.M3(); // // A.M3 C.M3 C.M3
ab.M4(); ac.M4(); // // B.M4 B.M4 E.M4
```

# Example 98 Calling Overridden Methods from a Constructor

If d is an object of class D2, then calling d.M2() will call the method M2 inherited from base class D1.
The call M1() in M2 is equivalent to this.M1(), which this equals d2, so the method M1 declared in class D2 is called. Hence the call d.M2() will print D1.M2 and D2.M1:7. It because field f is initialized to 7 in constructor D2().

Perhaps surprisingly, the creation d = new D2() of an object of class D2 will print D1.M2 and D2.M1:10. Why does it print 0, not 7? The very first constructor of class D2() is to make an implicit call to the base constructor D1(), even before executing the assignment f = 7. Hence f will still have its default value 0 when method M1 in D2 is called from method M2 in D1, which in turn is called from constructor D1().

```
class D1 {
public D1() {}
public virtual void M1() { Console.WriteLine("D1.M1"); }
public virtual void M2() { Console.WriteLine("D1.M2"); }
}
```

```
class D : D1 {
int f;
public D2() { f = 7; }
public override void M1() { Console.WriteLine("D2.M1"); }
}
```
