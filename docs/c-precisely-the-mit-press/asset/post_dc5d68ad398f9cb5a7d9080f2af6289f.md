**Example 26** String Formatting Using the Console.WriteLine Method
This example rolls a die one thousand times and counts frequencies. The frequencies are written to the console (as example 34), but string formatting is used instead of string concatenation.

```c
Random rnd = new Random(); // Random number generator
int[] freq = new int[6]; // All initialized to 0
for (int i=0; i<1000; i++) {
    int die = rnd.Next(1, 7); // Random integer in range 1..
    freq[die-1] += 1;
}
for (int c=0; c<6; c++) {
    Console.WriteLine("{0} came up {1} times", c, freq[c]);
}
```

**Example 27** String Alignment in Text Output
A $3 \times 5$ matrix represented by a two-dimensional array is filled with random numbers from 0 to 999. The matrix is printed with the numbers right-justified in each column.

```c
Random rnd = new Random(); // Random number generator
int[,] m = new int[3,5]; // 3 x 5 matrix
for (int i=0; i<m.GetLength(0); i++) {
    for (int j=0; j<m.GetLength(1); j++) {
        m[i,j] = rnd.Next(1000); // Random integer in range 0..999
    }
}
for (int i=0; i<m.GetLength(0); i++) {
    Console.WriteLine("{0,4} {1,4} {2,4} {3,4} {4,4}", m[i,0], m[i,1], m[i,2], m[i,3], m[i,4]);
}
```

The console output may look like:

```
932 930 417 17 14
993 492 329 828 63
455 721 920 70 520
```

## 7.2.1 Number Formatting

The code part of a format specification for a value of numeric type may be a standard number formatting code, which has the form c or cy or cyyy, where c is a character and y is a digit. The following number formatting codes are predefined for integers (I) or floating-point numbers (F) or both (IF):

| Code | String Format | Precision Specification or yy | Type |
|---|---|---|---|
| Dor | Decimal number (possibly padded with zeros) | Minimum number of digits | I |
| Xor | Hexadecimal (possibly padded with zeros) | Minimum number of digits | |
| Gog | General (default) | Max. number of significant digits | IF |
| Nor | Number with thousands separators | Number of fractional digits | IF |
| Fof | Fixed-point number | Number of fractional digits | F |
| Ror | Lossless value-string conversion | (none) | |
| Eoe | Exponential notation | Number of fractional digits | IF |
| Pop | Percent (value multiplied by 100 %) | Number of fractional digits | IF |
| Coc | Currency amount | Number of fractional digits | IF |

The code part of a format specification for a value of numeric type may also be a custom formatting pattern, which may be a combination of one or more of the predefined custom formatting codes:

```
0 # . , # E0 e0 E+ E-0 e-0 ; 'string' "string"
```

See example 29 and the .Net Framework class documentation for details.

## 7.2.2 DateTime Formatting

The code part of a format specification for an object of DateTime may be one of the predefined standard DateTime formatting codes:

| Code Character | Format |
|---|---|
| For | Full date and time, with (F) or without (f) seconds |
| Gog | General date and time, with (G) or without (g) seconds |
| s | Sortable date and time in ISO8601 format |
| u | Universal local date and time |
| U | Universal local date and time: F converted to UTC |
| R and r | RFC1123 standard full date and time |
| Dor | Full date, long (D) or short (d) format |
| Y and y | Year and month |
| M and m | Month and date |
| T or t | Time, with (t) or without (t) seconds |

The code part of a format specification for an object of DateTime may also be a custom DateTime formatting pattern, which may be a combination of one or more of the predefined custom DateTime formatting codes. See the .Net Framework documentation for details.

# 8 String Builders

A string builder, which is an object of System.Text.StringBuilder, is an extensible and modifiable string. Characters can be appended to a string builder without copying those already in. By contrast, a string object s1, cannot be modified. Using s1 + s2 creates a new object by copying all the characters from s1 and s2; there is no need to extend s1 by appending more. Thus to concatenate strings of length k by repeated string concatenation (+), one must copy k + 2k + 3k + ... + nk = kn(n+1)/2 characters, and the time required to do this grows rapidly as n.

Using a string builder, the concatenation of strings of length k requires only time proportional to n. To greatly build a string, use a string builder, for repeated concatenation in a loop, as in examples 20 and 31. The expression s1 + ... + sn is efficient; it actually means StringBuilder().Append(s1)...Append(sn).ToString().Let sb be a StringBuilder, a String, and an v of any type:

- StringBuilder(v) creates a new empty string builder.
- Append(v) appends the string representation of the v to the string builder, converting v to a string, see section 7. Extends sb as needed. Returns sb.
- AppendFormat(String fmt, object v) appends the string String.Format(fmt, v) to the string builder. Extends sb as needed. Returns sb. For possible formatters fmt, v see section 7.2.
- Length of type int is the length of sb, that is, the number of characters currently in sb.
- sb[i] is the character at number i in the string builder, counting from zero. Sb[i] = c sets the character at index i to. Throws IndexOutOfRangeException (when getting a character) or ArgumentOutOfRangeException (when setting a character) if i<0 or i>=sb.Length.
- Remove(i, n) deletes the characters at index i..(i+n-1) from the string builder, reducing its length by n characters. Throws ArgumentOutOfRangeException if i<0 or i+n>sb.Length. Returns sb.
- Insert(i, v) inserts the string representation of v by v.ToString() into the string builder, starting at position i, extending sb as needed. Returns sb. Throws ArgumentOutOfRangeException if i<0 or i>sb.Length.
- ToString() of type String is a new string containing the characters currently in sb.

Method Append is fast, but Remove and Insert can be slow when they need to move large parts of the string builder's contents, that is, when both i and i+n are much smaller than Length.

More StringBuilder methods are described in the .Net Framework class library (section 34).
