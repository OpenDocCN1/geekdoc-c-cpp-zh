# 14.2 The Reference in a Struct

Inside a struct declaration, this is a variable referring to an instance of the struct type. In methods, properties, and indexers it can be read and assigned to, as if it were a ref parameter (example 144). In the constructors of a struct declaration, this reference can only be assigned to, not read from, as if it were an out parameter. However, unlike an out parameter in a method, it does not have to be defined assigned in the constructors: the struct's fields are all initialized anyway.

# 14.3 Struct Expressions: Value or Variable

An instance method in a class is always invoked on an object reference, explicitly as in o.M(...) or implicitly as in M(...), which means M(...). If method M is assigned to an instance field, then that will affect the field in the object referred to by expression or this.

However, when invoking an instance method in a struct type o.M(...), one must distinguish whether o is a variable or a value. The variable case is when o is a local variable or reference x, a non-readonly field f, or an array element a[i]. The value case is when o is any expression, such as a boxing conversion, a read-only field, or a call to a method, delegate, or indexer. The field of the struct referred to is o. On the other hand, when o is a value, a field assignment performed by M in a call o.M(...) will affect a field of o.M(...) which is an anonymous struct that is not accessible in any other way. In particular, this happens in a field chain as p.Move(5,5).Move(6,6) because p.Move(5,5) is a value, not a variable (example 144). Moreover, it happens when o is a readonly field; then o.Move(5,5) has no effect on the field o.
