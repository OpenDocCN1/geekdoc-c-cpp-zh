# Example 99 Named Arguments

The following calls to method Date.Weekday (example 151) are all equivalent:

```
Date.Weekday(2009, 8, 7)
Date.Weekday(2009, m: 8, d: d)
Date.Weekday(y: 2009, m: 8, d: 7) // ISO order
Date.Weekday(m: 8, d: 7, y: 2009) // US order
Date.Weekday(d: 7, m: 8, y: 2009) // UK order
```

# Example 100 Named Parameters Are Resolved at Compile-Type of Target

The argument names x and y are from interface I, the compile-time type of a, not from the method
A.M actually.

```
interface I { int M(int x, int y); }
class A { public int M(int a, int b) { return a-b; }

/// a = new A();
// a.M(5, y: 3); // Returns +2
/// a.M(5, b: 3); // Illegal: parameter names a and b unknown in type
```

# Example 101 Dynamic Method Receiver: Run-Resolution of Defining Class

Since the receiver of the call v.Length has type dynamic, the choice of which to actually call
postoned to run-time, as v's run-time value is an array, a String, a Stream, or other call
value that has a Length property.

```
dynamic v = ...nres = v.Length;
```

# Example 102 Dynamic Method Arguments: Run-Resolution of Overloading

Consider these overloaded methods:

```
static int Process(int v) { return v * v }
static double Process(double v) { return v * v }
static String Process(String v) { return v + v; }
static Func<int, int> Process(Func<int, int> int) { return x => v(x); };
```

In a call Process(v) which has type dynamic, the overloading resolution is postponed to run-time. The
call will always be accepted but it may fail (RuntimeBinderException) at run-time	if there is no suitable overload, for instance, if the value of v is a bool value. The call Process(v)
will compile-time type dynamic, in all overloads having other types, so further operations
be applied to the result and will be resolved only at run-time. Note that casting a method argument
expression to dynamic can be used for run-time overloading resolution.

```
dynamic v = ...;
dynamic r = Process(v);
Console.WriteLine(Process(v).StartsWith("abca")); // Compiles OK"
```

Because of run-overloading resolution, Enhance(x) and hence Enhance(x).Substring(0,2) have
type dynamic, the call to String and the assignment to s perform tests and checks at run-time.
