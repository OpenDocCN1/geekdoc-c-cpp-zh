# Example 183 A Complete Input-Output Example

```csharp
using System;
using System.IO;

class BasicIOExample {
    public static void Main() {
    TextReader r = Console.In;
    int count = 0;
    String s = r.ReadLine();
    while (s != null && s.Equals("")) {
        count++;
        s = r.ReadLine();
    }
    Console.WriteLine("You entered " + count + " nonempty lines");
}
}
```

## 25.2 Overview of Input and Output Methods

The following table summarizes the naming conventions for methods of the input and output classes as well as their main characteristics, such as their end-of-stream behavior.

| Method Name | Effect |
| --- | --- |
| Read | Inputs characters from a TextReader (section 25.4) or inputs bytes from a Stream (section 25.7) or one character from a BinaryReader (section 25.6). It blocks, that is, does not return, until some input is available; Returns – 1 on end-of-stream, except for the Read(byte[], ...) overloads, which return 0. |
| Readt | Inputs a value of type i from a BinaryReader (section 25.6). Blocks until some input is available; throws EndStream on end-of-stream. |
| Peek | Returns the next character from a TextReader (section 25.4) without advancing the stream. Blocks until some input is available; returns –1 on end-of-stream. |
| PeekChar | Returns the next character from a BinaryReader (section 25.6) without advancing the stream. Blocks until some input is available; returns –1 on end-of-stream. |
| Write | Outputs the text representation of a value (of type int, double, ..., String Object) to a TextWriter which outputs bytes to a Stream (section 25.7) or outputs the representation of a value to a BinaryReader (section 25.6). |
| WriteLine | Same as Write but outputs a newline after each call. |
| Flush | Writes buffered data that has been written to the file system or network. |
| Close | Flushes the stream and releases resources held by the stream. Further operations on the stream, except Close, may throw an ObjectDisException. Writers and output streams should be explicitly closed to make sure that all data have been written to disk or network; otherwise output may be lost. |
| Deserialize | Deserializes objects from a Stream (examples 184 and 254). Defined in System.Runtime.Serialization.Formatters.Binary.BinaryFormatter and System.Runtime.Serialization.Formatters.SoapFormatter. |
| Serialize | Serializes objects to a Stream (examples 184 and 254). Defined in System.Runtime.Serialization.Formatters.Binary.BinaryFormatter and System.Runtime.Serialization.Formatters.SoapFormatter. |

## 25.3 Using Declarations, Exceptions, Thread Safety

A program using the input and output classes must contain the declaration:
```csharp
using System.IO;
```

Most input and output operations can throw an exception of IOException or one of its subclasses (section 20). Hence a method doing input or output should be in a try-catch block (section 13.8.2).

The standard implementation of input-output is not thread-safe; multiple concurrent threads (section 21) cannot read from or write to the stream without corrupting it; so one should not use the same stream from multiple threads. Classes TextReader and TextWriter have a static method Synchronized for creating thread-safe readers and writers.

# Example 184 Input and Output: Eleven in One

This example illustrates human-readable text file: input and output of simple values with binary files; input and output of arrays with binary files; input and output of simple values with random access binary files; input and output using strings and string builders; to standard output and error output; and from standard input.

```csharp
// Write numbers and words on file "f.txt" in human-readable form:
Writer tw = new StreamWriter(FileStream("f.txt", FileMode.Create));
tw.Write(4711); tw.Write(" "); tw.Write("cool"); tw.Close();
// Write simple values to a binary file "p.dat"
BinaryWriter bwr = new BinaryWriter(FileStream("p.dat", FileMode.Create));
bwr.Write(4711); bwr.Write("cool"); bwr.Close();
// Read simple values from a binary file "p.dat"
BinaryReader br = new BinaryReader(FileStream("p.dat", FileMode.Open));
Console.WriteLine(br.ReadInt32() + " + " + br.ReadChar() + " + " + br.ReadString());
// Write an object or array to binary file "o.dat"
FileStream fs = new FileStream("o.dat", FileMode.Create);
BinaryFormatter bf = new BinaryFormatter();
bf.Serialize(fs, new int[] { 1, 2, 5, 11 }); fs.Close();
// Read objects or array from binary file "o.dat" in arbitrary order
FileStream fs = new FileStream("o.dat", FileMode.Open);
int ia = (int[])bf.Deserialize(fs);
Console.WriteLine(ia[0] + " (" + ia[1] + ", " + ia[2] + ", " + ia[3] + ", " + ia[4] + ");\ fs.Close();
// Read and write parts of file "raf.dat" in arbitrary order
FileStream fs = new FileStream("raf.dat", FileMode.OpenCreate, FileAccess.ReadWrite);
BinaryWriter bwr = new BinaryWriter(fs);
bwr.Write(34115); bwr.Write("SeekOrigin.Begin");
```

## 25.4 Sequential Input: TextReaders

The abstract class TextReader and its subclasses StringReader and StreamReader are used for character-oriented input. In addition to the classes shown here, see the corresponding Writer classes (section 25.5). The TextReader class has the following methods:

- Read() reads the reader from the stream and returns it. Returns -1 on end-of-stream.
- Read(char[] b, int i, int n) reads n characters into b[i..i+n-1] and returns the number of characters read. Returns immediately if n is 0. Returns 0 on end-of-stream. Throws ArgumentOutOfRangeException if i<0 or n<0, ArgumentException if i+n>b.length, and ArgumentNullException if b is null.
- ReadBlock(char[], int i, int n) blocks until n characters are read or end-of-stream is reached.
- ReadLine() returns the next line from the stream. Returns null at end-of-stream.
- ReadToEnd() returns the characters from the current position to end-of-stream. Returns -1 on end-of-stream.
- Peek() returns the character without advancing the stream.
- void Close() closes the reader and the underlying stream. Any subsequent operation, except Close, will throw ObjectDisException.

## 25.4.1 Sequential Character Input from a Byte Stream or File: StreamReader

A StreamReader is a character input stream that reads characters from a byte stream or from a file. StreamReader converts bytes from the underlying stream or file into character encoding. The input operations are buffered for efficiency. It has the same methods as TextReader (section 25.4) and also these constructors and property:

- StreamReader(Stream s) creates a character input stream (from a reader) by byte stream s, using UTF-8 encoding.
- StreamReader(Stream s, Encoding enc) works similarly with enc as encoding.
- StreamReader(String filename, Encoding enc) creates a character input stream with the named file on the file system, using UTF-8 encoding. Throws FileNotFoundException if the file cannot be found, DirectoryNotFoundException if filename is null, ArgumentNullException, ArgumentException if it is the empty string, and IOException if it contains invalid path or name characters.
- StreamReader(String filename, Encoding enc) works similarly but uses character encoding enc.
- Read-only property CurrentEncoding.Encoding of Type is the name of the character encoding used by this StreamReader, for instance, "Unicode (UTF-8)".
