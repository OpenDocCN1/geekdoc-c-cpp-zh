# Example 72 Arithmetic Operators

```
public static void Main() {
int max = 2147483647;
int min = -2147483648;
WriteLine(max+1);
WriteLine(min-1);
WriteLine(-min);
Write(10/3); WriteLine(10/(-3));
Write(-10/3); WriteLine(-10)/(-3));
Write(10%3); WriteLine(10%(-3));
Write(-10%3); WriteLine(-10)%(-3));
}
static void Write(int i) { Console.Write(" " + i); }
static void WriteLine(int i) { Console.WriteLine(i); }
```

# Example 73 The checked and unchecked Operators

Overrun of run-time evaluation of type int

```
int max = int.MaxValue;
int j = max+1;
int k = checked(max+1);
int l = checked(Add(max,1));
// j = -2147483648
// Throws OverflowException
// l = -2147483648
```

Overrun of compile-time constant expression of type int

```
int m = int.MaxValue+1;
int n = unchecked(int.MaxValue+1);
int p = checked(int.MaxValue+1);
// Compile-time error!
// n = -2147483648
// Compile-time error!
```

```
char a = char.MaxValue;
char b = (char)(a + 66);
char c = checked((char)(a + 66));
// b = 'A'
// Throws OverflowException
```

# Example 74 Logical Operators

Because of short-evaluation of &&, this expression (example 35) does not evaluate the array days[m-1] unless l <= m; so the index is never out of bounds.

```
(mth >= 1) && (mth <= 12) && (day >= 1) && (day <= days[mth-1]);
```

This method returns true if y is a leap year: if y is a multiple of 4 but not of 100, or is a multiple of 400:

```
static bool LeapYear(int y)
 return y % 4 == 0 && y % 100 != 0 || y % 400 == 0;
```
