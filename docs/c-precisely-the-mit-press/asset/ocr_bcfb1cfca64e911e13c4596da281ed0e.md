# 34 Resources

+   - The C# 4.0 programming language is described in detail by Anders Heielsberg, Mads Torgensen, Scott Wollamuth, Peter Golde, The C# Programming Language, 4th ed. Addison-Wesley, 2010. ISBN 978-0321741769.

+   - The C# 2.0 programming language, including generic types and methods, anonymous methods, nullable types, and so on, was standardized by Ecma International in June 2006. At the time of writing C# 3.0 nor C# 4.0 have been standardized. Download the C# (2.0) Language Specification, adopted as Ecma Standard ECMA-334, 4th ed., from <http://www.ecma-international.com/publications/standards/ECMA-334.htm>.

+   - The Microsoft .Net Framework is available from <http://msdn.microsoft.com/framework/>

+   - Microsoft Visual Studio development environment for C# and many other languages can be bought at <http://msdn.microsoft.com/studio/>.

+   - The Microsoft Visual development environment for C# is sufficient for many programming projects and is available for no charge at <http://msdn.microsoft.com/express/>.

+   - The Microsoft .Net Framework class reference documentation is available at <http://msdn.microsoft.com/library/>

+   - The description of asynchronous programming in section 23 is based on Asynchronous Functions in C# and Asynchronous Programming in C# and Visual Basic, by Mads Torgensen, and on The Task-Based Asynchronous Pattern, Stephen Touches, all published by Microsoft, 2010; as well as the Asynchronous CTP November 2010 software from Microsoft.

+   - The Unicode encoding (<http://www.unicode.org>) corresponds to part of the Universal Character Set (UCS), which is international standard ISO 10646-1:2000. The UTF-8 is a variable-length encoding of UCS, in which 7-bit ASCII characters are encoded as them. It is described in Annex R of the aforementioned standard.

+   - Floating-point arithmetic is described in ANSI/IEEE Standard for Binary Floating-Point Arithmetic (IEEE Std 754-2008). A description is given at <http://en.wikipedia.org/wiki/IEEE_754-2008>

+   - A comprehensive library of collection classes for C# is provided by the library C5, available at <http://www.itu.dk/research/c5/> under a liberal license.

+   - The integer square root algorithm in example 252 is due to Mark Borgerding, Paul Hsieh, and Jim Ulery, see <http://www.azillionmonkeys.com/qsd/sqroot.html>.
