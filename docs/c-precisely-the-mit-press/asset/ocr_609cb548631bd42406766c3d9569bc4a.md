# 2.2.2 Class Task<T>

Class Task<T> from namespace System.Threading.Tasks represents computations that produce a result of T; it is a subclass of Task and has these additional members:

+   * Constructor Task<T>(Func<T> func) creates a task that, when started, will execute func().
* Task ContinueWith(Action<Task<T>> cont) creates and starts a task in which the given task continues with the computation cont; that, when task completes, cont(task) will be called.
* Task<U> ContinueWith<U>(Func<Task<T>, U> cont) is similar, where the continuation produces a result of type U. Overloaded to take as arguments cancellation token, task continuation options, and task schedulers.
* Read-only property Result blocks until the task completes and returns its result. Throws AggregateException if the task throws an exception or is cancelled.

# 2.2.3 Task Cancellation

When creating a task, one can pass it a CallbackContext. The token can subsequently be used to tell the task it may abort. The task may acknowledge the cancellation request (and complete) by throwing an OperationCanceledException that precisely token ct as argument; this moves the task to the cancelled state (page 141). A single cancellation token may be passed to multiple tasks, so that all those tasks may be cancelled by one to call Cancel().

Struct type CallbackContext from namespace System.Threading providing the following operations for use by tasks to which the token has been created:

+   * Read-only property bool IsCancellationRequested returns true if cancellation is requested on the underlying cancellation token source.
* void ThrowIfCancellationRequested() creates an OperationCanceledException with the given token (ct) as argument and throws the exception if IsCancellationRequested is true, acknowledging cancellation; otherwise does nothing.
Class CancellationTokenSource from namespace System.Threading is used to create a cancellation token; it provides the following operations:
* Constructor CancellationTokenSource() creates a new cancellation token source.
* void Cancel() requests cancellation via the associated cancellation token.
* static CancellationTokenSource CreateLinkedTokenSource(params cts) creates a cancellation token source that requests cancellation whenever any of the cancellation token source is given in dtos.
* Read-only property bool IsCancellationRequested returns true if cancellation was requested.
* Read-only property CancellationToken returns the cancellation token.

A number of other cancellation-related types are described in the full .Net class library documentation.
