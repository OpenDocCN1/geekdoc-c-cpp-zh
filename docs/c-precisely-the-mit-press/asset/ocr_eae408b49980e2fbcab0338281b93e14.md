**Example 200** Declaration of a Generic Class
An object of generic class LinkedList<T> is a linked list whose elements have type T; it implements interface MyList<T> (example 205). The generic class declaration has a nested class, an indexer result type method, takes arguments of type T, an Equals(Object) method that checks its argument can be cast to MyList<T>, an Equals(MyList<T>) method, an explicit conversion of Array to LinkedList<T>, an overloaded operator (+) for concatenation, and methods that return enumerators. See also examples 209 and 222.

```
public class LinkedList<T> : MyList<T> {
    protected int size;                // Number of elements in the list
    protected Node first, last;        // Invariant: first=null iff last=null
    protected class Node {
        public Node next;
        public T Item;
    }

    public LinkedList() { first = null; size = 0; }
    public LinkedList(params T[] elements) : this(elements) { ... }
    public int Count { get { return size; }}
    public T this[int i] { get { ... } set { ... }}
    public void Add(T item) { Insert(size, item); }
    public void Insert(int i, T item) { ... }
    public void Remove(int i) { ... }
    public override bool Equals(Object obj) { return Equals(as MyList<T>obj); }
    public bool Equals(MyList<T> other) { ... }
    public override int GetHashCode() { ... }
    public static LinkedList<T> from(T[] arr) { ... }
    public static LinkedList<T> operator +(LinkedList<T> xs1, LinkedList<T> xs2) { ... }
    public IEnumerator GetEnumerator() { return new LinkedListEnumerator<T>(this); }
    IEnumerator GetEnumerator() { return GetEnumerator(); }
```

**Example 201** Subclass Between Generic Classes and Interfaces
The constructed type Point<String> is implicitly convertible to Iovable, and both ColorPoint<String,int> and ColorPoint<String,Color> are implicitly convertible to Point<String> and Iovable.

```
interface Iovable { void Move(int dx, int dy); };
class Point<Label> : Iovable {
    protected internal int x, y;
    private Label lab;
    public Point(int x, int y, Label lab) { this.x=x; this.lab = lab; }
    public void Move(int dx, int dy) { x += dx; y += dy; }
}
class ColorPoint<Label, Color> : Point<Label> {
    private Color c;
    public ColorPoint(int x, int y, Label lab, Color c) : base(x, y, lab) { ... }
}
```
