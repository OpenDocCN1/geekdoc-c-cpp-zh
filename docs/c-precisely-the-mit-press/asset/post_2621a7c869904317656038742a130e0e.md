**Example 220** Traversing a Collection
The prototypical traversal of a collection coll (which implements IEnumerable<T>) uses a foreach statement.

```csharp
public static void Print<T>(ICollection<T> coll) {
  foreach (T x in coll)
    Console.Write("{0} ", x);
    Console.WriteLine();
}
```

**Example 221** Traversing a Dictionary
A dictionary implements IEnumerable<KeyValuePair<K,V>> so its key/value pairs (section 27.8) can be printed like this:

```csharp
public static void Print<K,V>(IDictionary<K,V> dict) {
  foreach (KeyValuePair<K,V> entry in dict)
    Console.WriteLine("{0} --> {1}", entry.key, entry.value);
    Console.WriteLine();
}
```

**Example 222** An Enumerator Class for LinkedList<T>
Class LinkedListEnumerator is a member of class and enumerator for class LinkedList<T> (example 200). The Dispose method releases any data and nodes reachable through the current element. The non-generic Current property and the Reset method are required by interface IEnumerator, which IEnumerator<T> extends. The yield statement (section 13.12) provides a much simpler way to define enumerators.

```csharp
private class LinkedListEnumerator : IEnumerator<T> {
  T curr; // The enumerator's current element
  bool valid; // Is the current element valid?
  Node next; // Node holding the next element, or null
  public LinkedListEnumerator(LinkedList<T> list) {
    next = list.first; valid = false;
  }
  public T Current {
    get { if (valid) return curr; else throw new InvalidOperationException(); }
  }
  public bool MoveNext() {
    if (next != null) {
      curr = next.item; next = next.next; valid = true;
    } else {
      valid = false;
    }
    return valid;
  }
  public void Dispose() { curr = default(T); next = null; valid = false; }
  Object IEnumerator.Current { get { return Current; } }
  void IEnumerator.Reset() { throw new NotSupportedException(); }
}
```

# 27.3 Comparables, Equatables, Comparers, and EqualityComparers

Some values can be compared for ordering (such as less-than), and some values only for equality. A type may implement interfaces that describe methods for order comparison and equality comparison.

An order comparison method as compareTo returns a negative number to indicate less-than, zero to indicate equality, and a positive number to indicate greater-than. The method must define a partial ordering; it be reflexive, antisymmetric, and transitive. Define what is the opposite sign of positive and vice versa, and zero is the opposite sign of zero. The requirements they are:

- x.CompareTo(x) must be zero.
- x.CompareTo(y) and y must have opposite signs.
- If one of x.CompareTo(y) and y.CompareTo(z) is zero, x.CompareTo(z) must have the sign of the other one; and if both have the same sign, x.CompareTo(z) must have that sign.

# 27.3.1 IComparable, IComparable<T> and IEquatable<T> Interfaces

The non-generic System.IComparable describes this method:

- compareTo(Object object) must return a negative number when the current object (this) is less than that, zero when they are equal, and a positive number when this is greater than that.

The generic system System.IComparable<T> describes this method:

- compareTo(T that) must return a negative number when the current object (this) is less than that, zero when they are equal, and a positive number when this is greater than that.

The generic system System.IEquatable<T> describes this method:

- equals(T that) must return true if the current object (this) is equal to that; otherwise false.

Type int implements IComparable<int> and IEquatable<int>, and similarly for the other numeric types, for the String class (section 7), and for enum types.

# 27.3.2 The IComparer, IComparer<T>, and EqualityComparer<T> Interfaces

The non-generic System.Collections.Generic describes this method:

- compare(Object ol, Object obj2) must return a negative number when ol is less than obj2, zero when they are equal, and a positive number when ol is greater than obj2.

The generic system System.Collections.Generic.IComparer<T> describes these methods:

- compare(T v1, T v2) must return a negative number when v1 is less than v2, zero when they are equal, and a positive number when v1 is greater than v2.

The generic system System.Collections.Generic.EqualityComparer<T> describes these methods:

- equals(T v1, T v2) must return true if v1 is equal to v2; otherwise false.
- getHashCode(T v) must return a hashcode for v (section 5.2).

**Example 223** A Class of Comparable Points
A object represents the time of day 00:00-23:59. The method t1.CompareTo(t2) returns a negative number if t1 is before t2, a positive number if t1 is after t2, and zero if they are the same. By defining two overloads of CompareTo, the class implements the non-generic interface and interface IComparable<T>.

```csharp
using System;
public class Time : IComparable<Time>, IEquatable<Time> {
    private int hh, mm; // 24-hour clock
    public Time(int hh, int mm) { this.hh = hh; this.mm = mm; }
    public int CompareTo(Object obj) { // For IComparable
        return CompareTo((Time)obj);
    }
    public int CompareTo(Time that) { // For IComparable<T>
        return hh == that.hh ? mm - that.mm : hh - that.hh;
    }
    public bool Equals(Time that) { // For IEquatable<T>
        return hh == that.hh && mm == that.mm;
    }
    public override string ToString() { return String.Format("{0:00}:{1:00}", hh, mm); }
}
```

**Example 224** A Comparer for Integer Pairs
Integer pairs are ordered lexicographically by this comparer, which has features from example 23.

```csharp
using System.Collections;
using System.Collections.Generic;
public struct IntPair {
    public int fst, snd;
    public IntPair(int fst, int snd) { this.fst = fst; this.snd = snd; }
}
public class IntPairComparer : System.IComparer, IComparer<IntPair>, EqualityComparer<IntPair> {
    public int Compare(Object obj, Object obj) { // For IComparer
        return Compare((IntPair)obj, (IntPair)obj);
    }
    public int Compare(IntPair v1, IntPair v2) { // For IComparer<T>
        return v1.fst != v2.fst ? v1.fst - v2.fst : v1.snd != v2.snd ? v1.snd - v2.snd : 0;
    }
    public bool Equals(IntPair v1, IntPair v2) { // For EqualityComparer<T>
        return v1.fst == v2.fst && v1.snd == v2.snd;
    }
    public int GetHashCode(IntPair v) { // For EqualityComparer<T>
        return v.fst ^ v.snd;
    }
}
```

# 27.4 The IList Interface

The generic interface IList<T> extends IList<T> and describes lists with elements of type T. It has the following members in addition to ICollection<T>:

- Index(int i) returns or sets list i, counting from 0. Throws ArgumentOutOfRangeException if i<0 or i=Count. Throws NotSupportedException if used to set an element on a read-only list.
- Add(T x) adds element x at the end of the list.
- IndexOf(T x) returns the position whose element equals x, if any; otherwise -1.
- Insert(int i, T x) inserts x at position i. Existing elements at position i have their position decremented by 1. Throws ArgumentOutOfRangeException if i<0 or i>Count. Throws NotSupportedException if the list is read-only.
- Remove(T x) removes the first element of the list that equals x, if any. Returns true if an element was removed. All elements at higher positions have moved by 1. Throws NotSupportedException if the list is read-only.
- RemoveAt(int i) removes the element at index i. All elements at higher positions have their position decremented by 1. Throws ArgumentOutOfRangeException if i<0 or i=Count. Throws NotSupportedException if the list is read-only.

IList<T> is implemented by class List<T> which represents a list using an array (27.6).

# 27.5 The Dictionary<K,V> Interface

The generic interface Dictionary<K,V> extends ICollection<KeyValuePair<K,V>>, so it can be seen as a collection of key/value pairs (entries), where the keys have type K and the values have type V. There can be no two entries with the same key, and a key of reference type cannot be null. The interface describes these members in addition to ICollection<KeyValuePair<K,V>>:

- Read-only ICollection<K> returns a collection of the keys in the dictionary.
- Read-only ICollection<V> Returns a collection of values in the dictionary.
- Item[K k] gets or sets the value at dictionary key k. Throws ArgumentException when getting (but not setting) if k is not in the dictionary. Throws NotSupportedException if used to set an element in a read-only dictionary.
- Add(K k, V v) inserts value v key k in the dictionary. Throws ArgumentException if k is already in the dictionary. Throws NotSupportedException if the dictionary is read-only.
- ContainsKey(K k) returns true if the dictionary contains an entry for key k; otherwise false.
- Remove(K k) removes the entry for key k, if any. Returns true if a key was removed.
- TryGetValue(K k, out V v) binds v to the value associated with key k and returns true if the dictionary contains an entry for k; otherwise binds v to default(V) and returns false.
