# 10.4 Subclass, Base, Inheritance, and Hiding

The declaration of a class C may explicitly declare its base B, using a class-base-clause:

: B

where B is a class. Then C is an immediate subclass of B, is said to be derived from B, and is a subclass of any class of which B is a subclass. If class C does not explicitly declare its base class B, then thehe base class is Object. The class-base-clause is used also to list the interfaces implemented by C
(section 15.2).

Class C inherits all non-private members except constructors, and also private fields (although they are not accessible within class C), members

A class can have at most one immediate base class. The predefined class Object is a class of\all other classes; class Object itself has no base class. The classes form a class hierarchy in which
every class object is a descendant of its unique immediate base class (section 5.2).

A constructor (section 10.11) in subclass C may be declared to explicitly call a particular constructor
in base class B, using this syntax:

```
constructor-modifier C(formal-list) : base(actual-list)
constructor-body
```

If a constructor(...) in subclass C does not explicitly declare base(...) this way, then it implicitly calls
the default constructor B() in base class as its first action, as if base(...). In this case B
must have a non-argumentless constructor B(). Conversely, if there is no argumentless constructor
() in B, then a constructor(...) in C must use base(...) to explicitly call another constructor in B.
A method declaration in C may override any non-sealed virtual M inherited from B by declaring-
ing method M with the exact same signature. An overridden method M can be referred to as base.M
inside C's instance constructors and instance methods. The overriding method M in C

+   - must be at least accessible (section 10.3) as the overridden method in B;
- must have the same signature and return type as the overridden method in B.

However, the declaration of a class C cannot redeclare a field f inherited from B, only hide it and declare
an additional field of the same name (section 10.5). The hidden field B can be referred to as base.f inside
's instance constructors and instance methods.

A declaration in C may hide members inherited from the base class B. Example 55 illustrates the
difference between overriding and hiding for methods. The hiding method in C should have the modifier
newther, otherwise a compiler warning is given.

+   - The declaration of a method with signature M(formal-list) hides any inherited method with the same
signature as well as any inherited non-method named M.
- The declaration of a field, property, event, or type named M hides all inherited members M,
including methods.
- The declaration of an indexer this[formal-list] hides inherited indexers with the same signature.
