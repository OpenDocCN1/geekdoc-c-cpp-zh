# 27 Generic Collections: Sets, Lists, and Dictionaries

System.Collections provides efficient, convenient, and type-safe data structures for representing collections of related data. These data structures include sets, lists, stacks, queues, and dictionaries (also called maps). A list is an ordered sequence where elements can be added and removed at any position; a set is a collection without duplicates; a stack is an ordered sequence where elements are added and removed only at one end; a queue is an ordered sequence where elements are added at one end and removed at the other; a dictionary associates values with keys. The collection classes are not thread-safe; using the same collection instance from threads produces unpredictable results.

# 27.1 The ICollection<T> Interface

The generic ICollection<T> extends IEnumerable<T> so that collection elements can be enumerated, and collections support query using the extension methods on IEnumerable<T> (section 28.5) and the LINQ syntax (section 28.1). In addition, ICollection<T> describes the following members:

+   * Read-only property Count returns the number of elements in the collection.
* Read-only bool IsReadOnly returns true if the collection is read-only and cannot be modified; otherwise false.
* void Add(T x) adds element x to the collection. Throws NotSupportedException if read-only.
* void Clear() removes all elements from the collection. Throws NotSupportedException if the collection is read-only.
* bool Contains(T x) returns true if x is in the collection; otherwise false.
* void CopyTo(T[] arr, int i) copies the collection to array arr, starting at array index i. Throws ArgumentOutOfRangeException if i<0 and throws ArgumentException if i+Count>arr.Length. Throws InvalidCastException if some element is not to the array's element
* bool Remove(T x) removes an element of x from the collection. Returns true if an element was removed, else false. Throws NotSupportedException if the collection is read-only.
