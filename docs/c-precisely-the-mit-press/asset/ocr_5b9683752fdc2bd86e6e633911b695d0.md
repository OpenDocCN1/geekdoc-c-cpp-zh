# 28.8 Extension Methods on non-generic Enumerable (C# 3.0)

Static class System.Linq.Enumerable defines extension methods on non-generic interface IEnumerable (section 27.2.2):

+   - IEnumerable<U> Cast<U>() returns an IEnumerable<U> obtained by casting each item of the given non-generic enumerable to type U. This is used to implement explicitly typed range variables in fromcm and join queries (section 28.1.2). Throws InvalidCastException if some item of the given enumerable cannot be cast to type U.
- IEnumerable<U> Of<U>() returns an IEnumerable<U> that produces only those items of the given non-generic enumerable that can be cast to type U. That is, it ignores items that would cause Cast<U> to throw InvalidCastException.

# 28.9 Static Methods to Generate Enumerables (C# 3.0)

Static class System.Linq.Enumerable provides static methods to generate enumerables:

+   - IEnumerable<T> Empty<T>() returns an enumerable that generates no items.
- static IEnumerable<int> Range(int i, int n) returns an enumerable that generates the n integers i, i+1,...,i+n. Throws ArgumentOutOfRangeException if n<0.
- static IEnumerable<T> Repeat(T x, int n) returns an enumeration that generates n times generates x. Throws ArgumentOutOfRangeException if n<0.

In general, enumerables can be conveniently generated using the yield return statement in the iterator block (section 13.12).
