Example 168 Parallel Matrix Multiplication
Matrix multiplication R = AB can be implemented by a tripled nested loop. The usual sequential outermost loop may be replaced by a parallel outermost loop by calling method Parallel.Forwith a lambda expression expressing the inner loops. No synchronization is needed here because each task has a different value of r, so no two write to the same element of array R. On a four-CPU machine this makes matrix multiplication more than three times faster.

```
// for (int r=0; r<rows; r++) { // Old sequential loop
Parallel.For(0, rows, r => {\ // New parallel loop
    for (int c=0; c<cols; c++) {
        double sum = 0.0;
        for (int k=0; k<A; k++)
            sum += A[r,k]*B[k,c];
        R[r,c] = sum;
    }
```

Example 169 Parallel Execution of Illegal Computations
To compute SlowFib(40) = 3 + SlowFib(43) one may compute the two SlowFib in parallel. The speed-up factor will be less than 2 unless computations take equally (which they do not).

```
double fib40 = 0, fib43 = 0; // Define assignment rules require initialization
Parallel.Invoke(delegate { fib40 = SlowFib(40); }, delegate { fib43 = SlowFib(43); });
double result = fib40 + 3 + fib43;
```

Example 170 Parallel Web Data Retrieval
The Entrez serves at the U.S. National Center for Bioinformatics Information (NCBI) can query the center's databases. Given a protein ID, such as P01308 for human, it can search the database and return the protein's amino acid sequence MALW...ENCH. Method NCBIProteinParallel uses Parallel.For to perform multiple queries in parallel. For correctness each iteration of the loop writes a distinct element of the result array. 177 uses asynchronous methods.

```
public static String NCBIEntrez(String query) {
byte[] bytes = new WebClient().DownloadData(new Uri(server + query));
return ASCIIEncoding.ASCII.GetString(bytes);
}
public static String NCBIProteinID(String id) {
    return NCBIEntrez("efetch.fcbi?type=fastretrieval&text=db&proteinid=" + id);
}
public static String[] NCBIProteinParallel(params String[] ids) {
    String[] results = new String[ids.Length];
Parallel.For(0, ids.Length, i => { results[i] = NCBIProtein(ids[i]); });
    return results;
}
```
