# 27.2 Enumerators and Enumerables

# 27.2.1 The Enumerator and IEnumerator<T> Interfaces

An enumerator is an object that enumerates (produces) a stream of elements, such as the elements of a collection. A class or struct that has a method GetEnumerator with return type IEnumerator<T> can be used in a foreach statement (section 13.6.2). System.Collections.IEnumerator describes these members:

+   - Read-only Object Current returns the enumerator's current value. throws InvalidException if the enumerator has not reached the first element or is past the last element.

+   - bool MoveNext() advances the enumerator to the next (or first) element, if possible. Returns true if it succeeded so that Current is valid; false otherwise. throws InvalidOperationException if the underlying collection has been modified since the enumerator was created.

+   - void Reset() resets the enumerator so that the next call to MoveNext() will advance to the first element, if any. throws NotSupportedException if not supported.

The generic interface System.Collections.Generic.IEnumerator<T> interfaces IEnumerator and IDisposable (section 13.10) and describes these members:

+   - Read-only T returns the enumerator's current value, or throws InvalidException if the enumerator has not reached the first element or is past the last element.

+   - bool MoveNext() is just for IEnumerator.

+   - void Dispose() is called by the caller (for instance, a foreach statement) when the enumerator is no longer needed. It should release the resources held by the buffer. Current should throw InvalidOperationException and MoveNext() should return false.

A type that implements IEnumerator<T> must also implement IEnumerator, using explicit interface member implementation (section 15.3) to declare the Current property value, as in example 222.

# 27.2.2 The IEnumerable and IIEnumerable<T> Interfaces

An enumerable is one that implements IEnumerable or IIEnumerable<T>. This means that it has a method GetEnumerator that can produce an enumerator (example 200). System.Collections.IEnumerator describes this method:

+   - IEnumerator GetEnumerator() returns a non-generic enumerator.

The generic interface System.Collections.Generic.IIEnumerable<T> describes this method:

+   - IEnumerator<T> GetEnumerator() returns a generic enumerator.

A collection with element type T implements IEnumerable and IIEnumerable. Array (9.3) implements IEnumerable. For a given t, array type t[] implements IList and therefore IEnumerable<t> and IEnumerable. A user type that implements IEnumerable<T> must also implement IEnumerable, using explicit interface member implementation (section 15.3) to declare the GetEnumerator method twice with different return types, as in example 200.
