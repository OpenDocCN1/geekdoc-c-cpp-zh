# 12.7 Assignment Expression

In the assignment expression x = e, the type of e must be implicitly convertible to the type of x (section 5.3). The type of the expression x = e is the same as the type of x. The assignment is executed by evaluating x, then evaluating e and implicitly converting the value of e to the type of x (if necessary; see section 5.3), and finally storing the result in variable x. The value of the expression x = e is the value that was stored in x.

The left-hand side x may be a local variable or parameter, or a field as o->f, or an array element as a[i], or a pointer or index. See sections 12.18 and 12.19 for the latter case.

When x is an element of an array whose element value is type t, it is checked at run-time there is an implicit reference conversion from the value of e to t (section 9.1).

When e is a compile-time type of int, and x has type byte; short, unsigned; unsigned int or long, conversion is performed automatically, provided the value of e is within the range representable in x (section 5.1), and similarly when e has type long and x has type unsigned.

The assignment operator is right-associative, so the multiple assignment x = y = e has the same meaning as x = (y = e); then evaluate the expression e, assign its value to y, and then to x.

When e has reference type, then only a reference to the object or array is stored in x. When e has value type, the assignment copies the value of e. Example 71 shows that assignment of a struct variable copies the entire struct value.

A compound assignment has the form x += e, and is legal in two cases. x+e must be implicitly convertible to the type of x, in which case the compound assignment x+= is equivalent to x = x+e. Otherwise x+e must be explicitly assignment x+= e is equivalent to x and must be implicitly convertible to t, in which case the compound assignment x+= e is (t)(x+e). In both cases, x is evaluated only once; for instance, in a[i++] the variable i is incremented only once.

The second case occurs when x += e is legal when both x and e are legal (example 77). Since the value of the expression x+= e is that after the assignment, and the assignment operators associate to the result, one can write p[i] += e to increment by e and then store the result in p[i]; see example 56.

# 12.8 Conditional Expression

The conditional expression e1 ? e2 : e3 is legal if e1 has bool type, a type with an implicit conversion to bool, or a type that implements the true operator, and e2 and e3 have the same type or implicit types. The conditional is evaluated by evaluating e1. If e1 evaluates to true, then e2 is evaluated (and not e3); otherwise e3 is evaluated (and not e2). The resulting value is the value of the conditional expression.
