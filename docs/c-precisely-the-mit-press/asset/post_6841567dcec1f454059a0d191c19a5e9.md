
# Compiling, Loading, and Executing C# Programs

### Example 1 Complete Program in File Example001.cs
Almost all programs need the using System directive (section 29.1) but it is omitted in later examples.

```c
using System;
public class Sum {
    static void Main(String[] args) {
        int sum = 0;
        for (int i=0; i<args.Length; i++)
            sum += int.Parse(args[i]);
        Console.WriteLine("The sum is " + sum);
    }
}
```

### Example 2 Compiling and Running a Program from the Command Line
This example shows how to compile the file Example001.cs from the command line under Microsoft .Net (left) or Linux or Windows using the Mono system (right). In both cases the program outputs the text: The sum is 29.

+   csc Example001.cs mcs Example001.cs
Example001 7 9 13 mono Example001.exe 7 9 13

### Example 3 Compiling an Executable with a Reference to a Library
First compile file Mod.cs into a module Mod.netmodule and compile Lib.cs into a library Lib.dll.
Then compile the file Prog.cs and create an executable program in Prog.exe that has an external module Mod and refers to the library Lib. Finally, run the executable.exe:

```
csc /target:module Mod.cs
csc /target:library.dll
csc /addmodule:Mod.netmodule /reference:Lib.dll Prog.cs
```

The resulting assembly consists of two files: the main file Prog.exe, and file Mod.exe which contains the external module. The assembly has a manifest with version number, other metadata, and references to two other assemblies: the Lib, and mscorlib which is included by default.

# 4 Comments and Program Layout

## 2 Names and Reserved Names

A name of a variable, parameter, method, field, indexer, property, class, struct, enum, delegate, interface, or namespace starts with a letter or an underscore (_) and continues with zero or more letters or digits (0-9). Uppercase letters and lowercase letters are distinct. A legal name cannot be one of the keywords, which are reserved names:

```
abstract base bool break byte case char checked class const continue decimal
default default do double else enum event explicit extern finally fixed float
for goto if implicit in int interface is long long namespace ull object object or override private protected public readonly return
byte sealed short size stackalloc static string switch true try
typeof unless unchecked unsafe using virtual void volatile while
```

To use as a name, prefix it with the @ character, as in @while = 17. The pseudo-keywords add, aliases, ascending, by, descending, from, global, group, into, join, let, orderby, partial, remove, select, value, where, and yield are reserved only in certain contexts.

## 3 C Naming Conventions

The following naming conventions are often followed, although not enforced by the C compiler:

- If a name is composed of several words, each word (except possibly the first one) begins with an uppercase letter. Examples: currentLayout, LayoutComponent.
- Names of local variables, parameters, and protected fields begin with a lowercase letter. Examples: vehicle, currentVehicle. Using lowercase l1 or uppercase letter 0 as names.
- Names of public or internal fields, static fields, and named constants begin with an uppercase letter. Examples: Vehicle, MaxValue.
- Names of classes, methods, events, properties, and enum types begin with an uppercase letter. Examples: Cube, ColorCube.
- Names of interfaces begin with the I followed by an uppercase letter. Example: IEnumerable.
- A namespace name is a dot-separated sequence of names, each of which begins with an uppercase letter (System or System.Text or System.RegularExpressions), but could also be a reverse domain name (dk.itu.c5 or ck.cern.mathlib).

## 4 Comments and Program Layout

A comment has no effect on the execution of the program but is used to help humans understand the program. It may be inserted anywhere permitted. There are two forms: one-line comments and delimited comments. Do not insert a delimited comment in the middle of a line, as in example 5.

Program layout has no effect on the computer's execution of the program but is used to help humans understand the structure of the program. For reasons of space the recommended layout style is not always followed in the rest of the book.

### Example 4 Using Keywords as Identifier Names

This feature is provided for interoperability with other programming languages, in which class or public may be a perfectly legal name for a field or method; it should not be used in ordinary C# programming. Note that for non-keywords as i, the identifier @i is the same as the i.

```c
class School {
    const int @class = 2004;
    const bool @public = true;
    String @delegate = "J. Smith ";
    public static int @double(int i) { return @i; }
}

School school = new School();
Console.WriteLine(school.delegate.Trim() + " " + School.class);
```

### Example 6 Program Layout Style

```c
class LayoutExample {
    int j;

    LayoutExample(int j) {
        this.j = j;
    }

    int Sum(int b) {
        if (j > 0) {
            return j + b;
        } else if (j < 0) {
            int res = -j + b;
            return res * 117;
        } else { // j == 0 {
            int sum = 0;
            for (int i=0; i<10; i++) {
                sum += (b - i) * (b - i);
            }
            return sum;
        }
    }
}
```

# 5 Data and Types

A type is a set of data values and operations on them. Every variable, parameter, and field has a declared type, every method has a declared return type, and so on. The compiler will infer a type for every expression based on this information. This compile-time type determines which operations can be performed on the value of the expression.

Types are used in declarations of local variables; in declarations of classes, interfaces, struct types, and their members; delegate type; object and array creation expressions (sections 9 and 12); in type cast expressions (section 12.20); and in instance test expressions (section 12.13).
A type is either a value type (section 5.1) or a reference type (section 5.2).

### 5.1 Value Types and Simple Types

A value type is either simple (this section), a struct type (section 14), or an enum type (section 16). A variable of value type directly contains a value of that, not just a reference to it. Assigning a value of value type to a variable or array element of value type makes a copy of the value.
A simple type is either bool or one of the numeric types. A numeric type is signed or unsigned integer, including the character type, or a floating-point type, or the fixed-point decimal which is useful for exact calculations. The tables below show simple types, some example constants, value range, kind, and size (in bytes). Integer may be written in decimal or hexadecimal notation:

| Notation | Base | Distinction |
|---|---|--- |
| Decimal | 10 | 1234567890, .127, -127 |
| Hexadecimal | 16 | Leading Ox, 01ABCDEF, -07F |

Two's complement representation is used for signed integer types (byte, short, int, and long). The integer types are exact. The floating-point types are inexact and follow the IEEE754 floating-point standard, with number of significant digits indicated.
For each type there is a predefined struct (in the System namespace), also shown. The simple type is alias for the struct and has these members:

-   int.Parse(String a) of type int is the integer by parsing a (example 1). It throws ArgumentNullException if a is null, FormatException if it cannot be parsed as an integer, OverflowException if the parsed number cannot be represented as an int. All simple types have similar Parse methods. The floating-point Parse methods are culture-sensitive (section 7.2).
- The smallest and greatest possible values of each numeric type are represented by constant fields MinValue and MaxValue, such as int.MinValue and int.MaxValue.
- The float and double types define several constants: double.Epsilon is the smallest number of type double greater than zero, double.PositiveInfinity and double.NegativeInfinity positive negative infinity, and double.NaN is a double value that is not a number. These values are determined by the IEEE754 standard.
- The decimal type defines the constants MinusOne, Zero, and One type decimal along with methods for computing with and converting numbers of type decimal.
