190 Generic Collections: Sets, Lists, and Dictionaries

# 27.7 The Dictionary<K,V> and SortedDictionary<K,V> Classes

Classes Dictionary<K,V> and SortedDictionary<K,V> implement Dictionary<K,V> (section 27.5) and are used to represent dictionaries or maps with keys of type K and associated values of type V.

A Dictionary<K,V> is implemented as a hash table, so the keys should have a good GetHashCode method but not be ordered. SortedDictionary<K,V> is implemented as an ordered tree, so the keys should be comparable, for key type K implementing IComparable<K>.

Objects used as dictionary keys should be treated as immutable, or else errors may be encountered. If an object is used as a key in a dictionary, and the object is subsequently modified, then the key and its entry may be lost from the dictionary.

Dictionary<K,V> and SortedDictionary<K,V> have the methods of Dictionary<K,V>, constructors (among others), and an additional method:

+   - Constructors Dictionary<K,V>() create empty dictionaries.

+   - Constructor Dictionary<K,V>(IEqualityComparer<K> cmp) creates an empty dictionary with the generic equality comparer (section 27.3.2).

+   - SortedDictionary<K,V>(IComparer<K> cmp) creates a new empty sorted dictionary with the generic comparator (section 27.3.2).

+   - bool Contains(V v) returns true if the dictionary contains an value v. In contrast to ContainsKey(k), it is slow; it requires a linear search of all key/value pairs.

# 27.8 The KeyValuePair<K,V> Struct

A struct of generic KeyValuePair<K,V> holds a key/value pair, or entry, from a dictionary (sections 27.5 and 27.7). See example 221. The KeyValuePair<K,V> struct has the following methods:

+   - KeyValuePair(K k, V v) creates a pair of k and v.

+   - Read-only property K returns the key in the key/value pair.

+   - Read-only property V returns the value in the key/value pair.

# 27.9 The IsSet<T> Interface and the HashSet<T> and SortedSet<T> Classes

The generic interface ISet<T> extends IEnumerable<T> and describes collections that do not duplicates, is, sets. The interface is implemented by classes HashSet<T> and SortedSet<T>, of of which have implementations of the Add, Contains, and Remove methods; see on page 18. Enumeration (section 27.2) of a sorted set produces the elements in increasing order. A hash set produces the elements in some arbitrary order.

Interface ISet<T> supports operations, each taking an argument B of type IEnumerable<T>. The methods that modify set A are ExceptWith(set difference, A\B), IntersectWith(set intersection,A∩B), SymmetricExcept(symmetric difference, (A\B)∪(B\A)), and Union(set union).

The methods that return a bool without modifying the set A are IsProperSubset(A C B), IsProperSuperset(A > B), IsSubsetOf(A ⊆ B), IsSupersetOf(A ≥ B), Overlaps(A∩B ≠ 0), and Equals(A = B).
