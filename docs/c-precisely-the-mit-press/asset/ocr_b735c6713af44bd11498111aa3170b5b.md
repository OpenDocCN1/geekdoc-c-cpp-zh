# 28.5 Extension Methods on IEnumerable<T> (C# 3.0)

IEnumerable<T> supports many extension methods for processing of data streams, especially useful in queries. These extension methods are defined in static class System.Linq.Enumerable and are available via the directive

```
using System.Linq;
```

Most of these methods are very general, and take type parameters as well as delegate parameters, making heavy use of the generic Func types (section 17). When the result of such a method is itself a stream or collection, the result is described here using the comprehension notation { ... } similar to list comprehension notation from languages such as Haskell, F#, and Scala. It is also similar to set notation in mathematics, with the major difference that it may appear multiple times the result and the order of items matters when the comprehension describes a stream.

For instance, consider Select<R>(Func<T,R> f) on page 205 which returns an IEnumerable<R>. The result of xs.select(f) can be described by the comprehension f(x) | x--xs, that is, the stream of values of f, which is drawn from the stream xs.

In the following descriptions, the enumerable (the argument of the extension method) is assumed to be xs, and its items are assumed to be xl..

+   * Aggregate(Func<T,T> f) returns f(f(x1,x2),x3)... if the enumerable has at least two items x1 and x2; returns true if it has only one; and throws InvalidOperationException if the enumerable is empty. Typically called foldl in functional languages.
* Aggregate<R>(R x0, Func<T,R> f) returns f(f(...f(x0,x1),x2)...xn). Typically called foldl in functional languages.
* Aggregate<R,S>(S x0, Func<T,R> f, Func<R,S> g) returns g(Aggregate<R>(x0, f)).
* bool All(Func<T,bool> p) applies p to each item x of the enumerable and returns false if p(x) is false for any x; otherwise returns true. Typically calledforall in functional languages.
* bool Any() returns true if the enumerable is non-empty;
* bool Any(Func<T,bool> p) applies p to each item x of the enumerable and returns true if p(x) is true for any x; otherwise returns false.
* IEnumerable<T> returns the enumerable unchanged, affecting only its compile type. This can be used to force a cast to, say, the method on IEnumerable<T> in cases where the enumerable implements Where explicitly and as an extension method on IEnumerable<T>. It is similar to a cast (IEnumerable<T>) this will not involve user-defined conversions (section 10.18).
* Average(Func<T,N> f) applies f to each item x of the enumerable and returns the average of f(x). When defined when N is a numerical type or a nullable type (section 28.6).
* IEnumerable<T> Cast<T> returns an enumerable that will generate all the elements of the generic enumerable xs and generate all the elements of ys.
* bool Contains(T x) returns true if the enumerable contains an item equal to x by the default equality comparer. Also overloaded to take an explicit EqualityComparer<T> as last argument.
