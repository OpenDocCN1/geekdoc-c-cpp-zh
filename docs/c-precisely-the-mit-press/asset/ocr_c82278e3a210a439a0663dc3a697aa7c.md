# Example 196 Socket Communication between Processes

This program runs as a server process or as a client machine, depending on the first command line argument. The server and client may run on the same machine, or on machines communicating via a network. Several clients may connect to the same server. The server creates a socket that accepts connections on port 2357. When a client connects, a new socket is created and an integer is received on that socket. If the integer is a prime, the server replies true on that, otherwise others are false. Each client process asks about the primality of numbers 1 through 99 and those that are primes. For simplicity the client creates a new socket for every request to the server, but this is inefficient.

using System.Net;

// BinaryReader, BinaryWriter
// AddressFamily, Dns, IPAddress, ProtocolType, ...
// NetworkStream

        bool server = (args.Length == 1 && args[0] == "server");
        bool client = (args.Length == 2 && args[0] == "client");
        if (server) // Server: accepts queries about primality
            Socket socket = new Socket(AddressFamily.InterNetwork, ProtocolType.Tcp);
            socket.bind(new IPEndPoint(IPAddress.Any, Port));
            socket.listen(10); // Max queue queue = 10 connections.
            for (;;) // Forever, accepts connections
                NetworkStream s = new NetworkStream(socket.Accept());
                BinaryReader reader = new BinaryReader(s);
                BinaryWriter writer = new BinaryWriter(s);
