# 9.2 Multidimensional Arrays

There are two ways to form multidimensional arrays: rectangular arrays and jagged arrays. Here are a rectangular 3 by 2 array and a "two-dimensional" jagged array; example 38 shows how to create them:

```
0.0 0.0
1.0 1.1
2.0 2.1 2.2
```

# 9.2.1 Rectangular Arrays

Rectangular (C-style) arrays have types of form t[,], t[...], and so on, where t is not an array type. The array type t[..., ] with n-1 commas, has rank n and is also called an n-dimensional array type. When n is 1, this is just a one-dimensional array t[]; as in section 9.1. A variable of t[..., ] is either null or holds a reference to an n-dimensional array; assignment of an array does not copy it.

A n-dimensional array may be created in one operation by an array creation:

```
t[l1,...,ln]
```

where l1,...,ln are expressions of type int, for one-dimensional arrays. This creates an array with l1..ln elements, all initialized with the default value for type t (section 6.2). Alternatively, an array creation expression for a rectangular n-dimensional array may have this:

```
t[...,...] { {...expression,...,expression}, {expression,...,expression} }
```

where there are n-1 commas in t[..., ] and the nesting of curly braces is n. The expressions are evaluated from left and implicitly converted to t, as for one-dimensional arrays.
To access an element of an n-dimensional array a, use index a[i1,...,in].

# 9.2.2 Arrays of Arrays (Jagged Arrays)

In general, an array type has type t[k1][k2]...[kn], where ki is a list of ki-1 elements, ki >= 1, and t is not an array type. This type describes k-dimensional rectangular arrays of k-dimensional rectangular arrays of... kn-dimensional arrays of element t. For example, double[][] is the type of two-dimensional arrays of double

A common case is Java-style "h-dimensional" array types t[][][]... where k1==kn=1. Thus a "two-dimensional" array of type t[][] is a one-dimensional array whose elements are arrays of type t. The array may have different lengths, so the array may be non-rectangular or jagged.
A jagged (Java-style) "h-dimensional" array t[][][]... with h square brackets [,], must be created one at a time.

```
t[l1][...]
```

This creates a one-dimensional array with l1 elements, all initialized to null, and all of type t[...]. where there are h-1 square brackets []. One may subsequently create arrays of type t[...]. and assign them to the elements of the one-dimensional array

To access an element of an h-dimensional jagged array a, use h index expressions: a[i1][i2]...[in]. Element access in a jagged array is likely to be less efficient than in a rectangular array.
