# 10.15 Property Declarations

A property is used to get or set a value, using notations C.P and o.P and C.P=e and o.P=e similar to those for accessing or assigning a static instance field (section 12.18). Properties provide controlled access to private fields. A property may be read-only or write-only, as it defines only a get-accessor or a set-accessor or both. A declaration of the property P has the form

```
method-modifiers t P {
    get-body
    set-body
}
```

The get-accessor or set-accessor, but not both, may be left out. The type cannot be void. The method-modifiers are in section 10.7. A get-body is a block-statement that does not return a value of type. A set-body is a block-statement that is executed when an assignment P=e is performed, and can use the variable value of type, which initializes the value of e.

The get-accessor of a property P of type t is a method get_P(), the set-accessor is a method void set_P(t value), and the accessors follow the restrictions imposed on them. For instance, the get-body and set-body of an abstract property must consist of a semicolon; only one class can declare any of properties with different names. Properties cannot be overloaded.

It is common to declare a private field with a corresponding public get-property (such as Count in example 66), so that the field can be read but not written outside the class. An automatically implemented property (C# 3.0) declares a property P by a hidden field (examples 82 and )

```
field-modifiers t P { access-modifier get; access-modifier set; }
```

# 10.16 Indexer Declarations

An indexer is used to get or set a value, using notations C[i] and C[i]=e or similar to those for accessing or assigning an array element (section 12.19). Indexers provide controlled access to elements of collections. An indexer may be read-only or write-only or read-write, as it defines a get-accessor or a set-accessor or both. A declaration of an indexer has the form

```
indexer-modifiers this[formal-list] {
    get-body
    set-body
}
```

The get-accessor or set-accessor, but not both, may be left out. The indexer-modifiers is a list of modifiers abstract, extend, a legal combination of override, sealed, and virtual (section 10.8), and a legal combination of access modifiers (section 10.3). An indexer cannot be static. The type cannot be void. The formal-list is a block-statement that must be non-empty and can include ref or out- parameters. A get-body is a block-statement that must return a value of type t; it can use the parameters in the formal-list. A set-body is a block-statement that must return a value of t. It can use the parameters in the formal-list and the variable value of type t that holds the value passed to the indexer in an assignment.

The accessors of an indexer are get_Item(t value, formal-list) and void set_Item(t value, formal-list). Indexers can be overloaded and may have different return types (example 149).
