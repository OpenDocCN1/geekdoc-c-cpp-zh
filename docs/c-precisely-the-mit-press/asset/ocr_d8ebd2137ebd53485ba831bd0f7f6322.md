# Example 06 Hiding Base Indexer with a New One For Type Safety

ClassList is meant to be a subclass of lists of strings; it is declared as a subclass of non-generic ArrayList(from namespace System.Collections,abstract SC) so that it inherits the Count property, Add method, and so on. It declares an indexer that hides the inherited int-argument indexer but calls it explicitly by base[i] and casts to String. The other indexer(String) calls this class's index using the integer (if any) parsed from the string. It is better to use a generic collection selection (section 27.6) instead, for type safety and efficiency.

Note the use of += on ss[0]; this first calls the indexer's get-accessor and its set-accessor.

```
class StringList : SC.ArrayList {
    public new String(int i) {
        get { return (String)base[i]; }
        set { base[i] = value; }
    }
    public String this[String s] {
        get { return this[int.Parse(s)]; }
    }
}
...
StringList ss = new StringList();
ss.Add("Cop"); ss.Add("en"); ss.Add("cabana");
ss[2] = "hagen";
ss[0] += "en" + ss[2];
Console.WriteLine("A total of {0} strings", ss.Count);
String last = ss[2]; // Correct type
Console.WriteLine(ss["0"] + "/" + last); // Prints: Copenhagen/hagen
```
