# Preface

This second edition of C# Precisely describes the language C# (pronounced "c sharp"), versions 3.0, 4.0, and 5.0. It is a quick reference for readers who have already learned or are learning C# from a standard textbook and who want to know the language in more detail. It should be particularly useful for readers who know the Java programming language and who want to learn C#.

C# is a class-based single-inheritance object-oriented programming language for the Common Language Runtime of .NET platform, a managed execution environment with a type-safe intermediate language and automatic memory management. Thus C# is similar to the Java programming language in many respects, but it differs in almost all matters. In general, C# favors programmer convenience over language simplicity. It was designed by Anders Heijsberg and others from Microsoft Corporation.

C# includes many useful features not found in Java: struct types, operator overloading, reference parameters, multidimensional arrays, user-definable properties, indexers (ers methods), and delegates (as values), but omits Java's inner classes and wildcards in generic types.

C# may appear similar to C++, but its safety is much better and its machine model is very different because of managed and garbage collection. In particular, there is no need to write destructors and finally to aggregate objects used in C or keep track of object ownership.

This book presents C# 4.0 as used in Visual Studio 2010, including lambda expressions, extension methods, anonymous objects, object initializers, collection initializers, language integrated type, dynamic, type covariance and contravariance, and not least, LIN (language integrated query). In addition, it describes asynchronous programming as found in C# 5.0 of Microsoft's .NET Framework, although only generic collection classes, and parts of the Task Library are covered. The book does not cover unsafe code, destructors, finalization, reflection, preprocessing directives (#if.line, #if..), details of IEEE754 floating-point numbers or expression trees.

General rules of the language are given on left-hand pages, and corresponding examples are shown on the right-hand pages for each reference. All examples are fragments of legal C# programs, available at <http://www.itu.dk/sectost/csharprecisely/>. For instance, the code for example 17 is shown in file Example017.cs.
