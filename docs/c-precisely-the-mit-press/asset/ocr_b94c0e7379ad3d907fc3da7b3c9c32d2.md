# Variables, Parameters, Fields, and Scope

A variable is declared inside a method body, constructor body, property body, indexer body, or another block statement (section 13.2). The variable can be used only in that block statement, and only after it has been declared. A parameter is a special kind of variable: it is declared in the parameter list of a method, constructor, or indexer, and can be used only in that method or indexer. A field is declared inside a class, but not inside a method or constructor or initializer block of the class.

A variable, parameter, or field of simple type holds a value of that type, such as the boolean false, the integer 117, the floating-point number 1.7, or a value of struct type (section 14). A variable, parameter, or field of reference type has either null or holds to an object or delegate.

# Scope of Variables, Parameters, and Members (Including Fields)

The scope of a name is that part of the program in which the name can be used. The scope of a variable extends from just after its declaration to the end of the innermost enclosing statement. The scope of a method or constructor or operator or indexer is the entire function body.

The scope of a variable declared in the header of a for statement is the entire statement (header and body). The scope of the variable in a foreach statement is the only body:

```
for (int x = ...; ...; ...) body
foreach (int x in ...) body
```

The scope of a variable or parameter x cannot contain a redeclaration of x. However, the scope of a struct member (such as a field x) may contain a declaration of a variable x that shadows the field, but only if the member has not been used in the same block prior to the declaration (the variable see 83 and 84 in example 12). The scope of a member is the entire class, except where shadowed by a variable or parameter of the same name. The member can be used anywhere in the class, also technically before its declaration. If the member is public or protected, its scope includes subclasses, except where hidden by a subclass of the same name. The scope of a static member also includes every nested class, except where shadowed by a member of a nested class, it excludes subclasses of the nested.

# Default Values and Default Assignment

For every type there is a default value, which can be produced by the expression default(t). For a simple type t default value is shown on page 7. For a struct t default value is a struct whose fields have their default values. A reference type t default value is null. For a nullable type t the default value is null.

A field of object or struct is automatically initialized with the default value for its type t.

Unlike a field, a variable or out parameter is not given an initial value. The compiler requires that variable be definitely assigned wherever it is used. That is, regardless of what conditional statements or loops have been executed before the declaration of a variable and a use of its value, the variable must have been assigned a value before its use.

Like a variable, an out parameter must have been assigned, in the function that declares it, whenever it is used. On the other hand, a by-value parameter or ref parameter is always given a value when the function is called, and so is always definitely assigned.
