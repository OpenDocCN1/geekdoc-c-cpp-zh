Method WriteData demonstrates writing simple data to a BinaryWriter, and method ReadData demonstrates all ways to read simple values from a BinaryReader. The methods complement each other, after writing a stream with WriteData, one can read ReadData. Namely, an integer written using BinaryWriter's method Write(Int) can be read using BinaryReader's method ReadInt32().

```
public static void main() {
    BinaryWriter bw = new BinaryWriter(new FileStream("tmpl.dat", FileMode.Create));
    WriteData(bw); bw.Close();
    BinaryReader br = new BinaryReader(new FileStream("tmpl.dat", FileMode.Open));
    ReadData(br);
}

static void WriteData(BinaryWriter bw) {
    bw.Write(true);
    bw.Write((byte)120);
    bw.Write('A');
    bw.Write("fogg");
    bw.Write("Random");
    bw.Write(300.1);
    bw.Write(300.2F);
    bw.Write(1234);
    bw.Write(12345L);
    bw.Write((short)32000);
    bw.Write((byte)(sbyte-1));
    bw.Write((short)-1);
}

static void ReadData(BinaryReader br) {
    Console.Write(" " + br.ReadBoolean());
    Console.Write(" " + br.ReadByte());
    Console.Write(" " + br.ReadChar());

    Console.Write(" " + br.ReadInt16());
    Console.Write(" " + br.ReadDouble());
    Console.Write(" " + br.ReadSingle());
    Console.Write(" " + br.ReadInt32());
    Console.Write(" " + br.ReadInt64());
    Console.Write(" " + br.ReadInt16());
```

## 25.7 Byte Input and Output: Stream

The abstract class Stream and its subclasses (all of whose names end in Stream) are used for byte-oriented input and output. A stream is associated with some resource to read from or write to, typically a file or an area of memory. A stream may support reading, seeking, writing, or a combination of these. A stream has a current position, indicating which byte to read from or write to. Let s be a variable of type Stream:

- Read-only property s.CanRead is true if the stream is not closed and supports reading; else false.
- Read-only property s.CanSeek is true if the stream is not closed and supports seeking; else false.
- Read-only property s.CanWrite is true if the stream is not closed and supports writing; else false.
- Read-only property s.Length of type long is the number of bytes in the stream, if the stream supports seeking; otherwise throws UnsupportedException.
- Read-write property s.Position of type long returns the current position of the stream. Setting s.Position to v sets the current position of the stream to v.

Variables of class Stream (and any subtype) have the following methods:

- int ReadByte() reads one (0...255) and returns it as an int, blocking until input is available; returns -1 on end-of-stream.
- int Read(byte[] b, int i, int n) reads at most n bytes from the stream and copies them into b[i..i+n-1] and returns the number of bytes actually read as an int and updates the position of the stream. Returns 0 on end-of-stream. Throws Length.OutOfRangeException if i<0 or n<0, ArgumentNullException if b evaluates to null, UnsupportedException if the stream does not support reading, and ObjectDisposedException if the stream has been closed.
- void Seek(long v, SeekOrigin origin) sets the current position of the stream to v; so v must be relative to SeekOrigin. SeekOrigin.Current or SeekOrigin.End or absolute. Throws UnsupportedException if it does not support seeking.
- void WriteByte(byte v) writes v to the stream and updates the current position by v. Throws UnsupportedException if the stream does not support writing, ObjectDisposedException if the stream has been closed.
- void Write(byte[] b, int i, int n) writes at most n bytes from b[i..i+n-1] and updates the current position by n bytes. Throws ArgumentOutOfRangeException if i<0 or n<0, ArgumentNullException if i+n>b.Length, UnsupportedException if the stream does not support writing, ObjectDisposedException if the stream has been closed.
- void SetLength(long v) sets the length of the stream to v. If v>s.Length, the stream is truncated. Throws UnsupportedException if the stream does not support seeking and writing.
- void Flush() writes all data in buffers to the underlying resource and clears all buffers.
- void Close() flushes and closes the stream and releases any underlying resources such as files or network connections.

# Example 192 Organizing a String Array for Random Access

This example shows a way to implement large numbers of texts, such as millions of cached pages or millions of DNA sequences. Define a string array to have three parts: (1) a sequence of strings, each of which is in UTF-8 format; (2) a sequence of integers, representing the start offsets of the strings; and (3) an integer, which is the number of strings in the file.

Put the number of strings and the string offset at the end of the file, so that it is not necessary to know the number of strings or the length of each string before writing the file. The strings can be written to the file incrementally, and the only structure to keep in memory is the table of strings. The table is represented as a List<Long> for type safety and performance.

```
static void WriteStrings(String filename, String[] data) {
    FileStream raf = new FileStream(filename, FileMode.Create);
    BinaryWriter sw = new BinaryWriter(raf);
    raf.SetLength(0);                                // Truncates the file
    List<Long> offset = new List<Long>();
    foreach (string s in data) {
        offset.Add(raf.Position);
        sw.Write(s);
    }
    sw.Write(data.Count);
    foreach (long o in offset) {
        sw.Write(o);
    }
    sw.Close();
    raf.Close();
}
```

# Example 193 Random Access File String

This example shows how to read strings back from the file using random access based on the offset table.

```
static string[] ReadStrings(String filename) {
    FileStream raf = new FileStream(filename, FileMode.Open);
    BinaryReader br = new BinaryReader(raf);
    int count = br.ReadInt32();
    long[] offset = new long[count];
    for (int i = 0; i < count; i++) {
        offset[i] = br.ReadInt64();
    }
    string[] data = new string[count];
    for (int i = 0; i < count; i++) {
        raf.Seek(offset[i], SeekOrigin.Begin);
        data[i] = br.ReadString();
    }
    br.Close();
    raf.Close();
    return data;
}
```
