# Step 6 Test your function.

After implementing a function, you should test it in isolation. Such a test is called a unit test. Work out test cases by hand, and make sure that the function produces the correct results. For example, for a pyramid with height 9 and base length 10, we expect the area to be 1/3 × 9 × 100 = 300. If the height is 0, we expect an area of 0.

```
int main()
{
    cout << "Volume: " << pyramid_volume(9, 10) << endl;
    cout << "Expected: 300";
    cout << "Volume: " << pyramid_volume(0, 10) << endl;
    cout << "Expected: 0";
    return 0;
}
```
