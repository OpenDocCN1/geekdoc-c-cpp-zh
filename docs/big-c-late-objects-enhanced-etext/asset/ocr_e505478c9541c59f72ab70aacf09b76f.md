# R4.1 Given the variables

```
string stars = "*****";
string stripes = "=====";
```

what do these loops print?

```
a. int i = 0;
while (i < 5)
{
  cout << stars.substr(0, i) << endl;
  i++;
}
```

```
b. int i = 0;
while (i < 5)
{
  cout << stars.substr(0, i);
  cout << stripes.substr(i, 5 - i) << endl;
  i++;
}
```

```
c. int i = 0;
while (i < 10)
{
  if (i % 2 == 0) { cout << stars << endl; }
  else { cout << stripes << endl; }
}
```
