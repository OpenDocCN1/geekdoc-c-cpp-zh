# CHARACTER CODES

These escape sequences can occur in strings (for example, "\n") and characters (for example, '\'') However, the \u escape sequences should be used only inside strings that have an encoding prefix, such as

```
string message = u8"San Jos\U000000e9 \U0001f684";
```

A string is a sequence of bytes. In the UTF-8 encoding, bytes between 0 and 127 correspond to the ASCII character range (see Table 2). Other Unicode characters are encoded into multiple bytes, where the first byte is ≥ 192, and subsequent bytes are between 128 and 191. Table 3 shows the encoding.

Table 1 Escape Sequences

| Escape Sequence | Description |
|---|---|
| \n | Newline |
| \r | Carriage return |
| \t | Tab |
| \v | Vertical tab |
| \b | Backspace |
| \f | Form feed |
| \a | Alert |
| \\ | Backslash |
| \" | Double quote |
| \' | Single quote |
| \? | Question mark |
| \Uh1h2h3h4 | A Unicode character, which will be encoded into a sequence of bytes determined by a character encoding |
