# AI Research Resources

+   - **ArXiv** - Preprint server for AI papers: [arxiv.org](https://arxiv.org)

+   - **Google Scholar** - Academic search engine: [scholar.google.com](https://scholar.google.com)

+   - **Papers with Code** - Papers with corresponding code: [paperswithcode.com](https://paperswithcode.com)

+   - **AI Conferences** - NeurIPS, ICML, ACL, CVPR, etc.: [neurips.cc](https://neurips.cc)
