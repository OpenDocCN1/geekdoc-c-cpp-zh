Consider the function call illustrated in Figure 3:
double result = cube_volume();

+   - The parameter variable size_length of the cube_volume function is created.
+   - The parameter variable is initialized with the value of the argument that was passed in the call. In our case, size_length is set to 2.
+   - The function computes the expression size_length * size_length * size_length, which has the value 8. That value is stored in the variable volume.
+   - The function returns. All of its variables are removed. The return value is transferred to the caller, that is, the function calling the cube_volume function.
