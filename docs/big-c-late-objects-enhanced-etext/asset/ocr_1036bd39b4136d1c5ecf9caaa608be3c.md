The book now supports two pathways into object-oriented programming and inheritance. Pointers and structures can be covered before introducing classes. Alternatively, pointers can be deferred until after the implementation of classes.

# Code Walkthrough

Code Walkthrough activities ask students to trace through a segment of code, choosing which line will be executed next and entering the new values of variables changed by the code’s execution. This activity simulates the hand-tracing problem solving technique taught in Chapters 3 and 4—but with immediate feedback.
