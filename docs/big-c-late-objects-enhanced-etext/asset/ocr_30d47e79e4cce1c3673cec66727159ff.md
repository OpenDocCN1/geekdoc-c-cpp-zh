d = the day of the month

w = the weekday (0 = Monday, 1 = Tuesday, ..., 6 = Sunday)

w = ( d + 5 + (26 × (mm + 1))/10 + 5 × (year % 100)/4 + 21 × (year / 100)/4 ) % 7

Here, all / denote integer division and % denotes the remainder operation.
