+   4. If an operator # is found then
+      a) Pop the two top elements of the stack,
+      Where A is the top element and B is the next to top element
+      b) Evaluate R = B # A
+      c) Push R onto the stack
+      [End of If]
+      [End of Loop]
+   5. Set Result equals to the top element on stack
+   6. Return
