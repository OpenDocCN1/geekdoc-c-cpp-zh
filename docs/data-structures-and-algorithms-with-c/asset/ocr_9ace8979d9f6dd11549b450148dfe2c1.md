# o (little omega)-Notation

Little-o notation represents a loose bounding version of Big-Omega; g (n) is a loose lower boundary of the function f(n); it bounds from the bottom, but not from the top. For non-negative functions, f(n) and g(n). f(n) is little omega of g(n) if and only if f(n) = Ω(g(n)), but f(n) ≠ Θ(g(n)). This is denoted as "f(n) = ω(g(n))".

We can write f(n) = ω (g (n)) iff

```
lim
n → ∞
f(n)
───── = ∞
g(n)
```

# Example:

Suppose f(n) = 4n³ + 2n + 3

Now we can write,

```
lim
n → ∞
4n³ + 2n + 3
──────────── = ∞
n²
```

Here g(n) = n²

Hence we can write f(n) = ω (g (n)) = ω (n²)
