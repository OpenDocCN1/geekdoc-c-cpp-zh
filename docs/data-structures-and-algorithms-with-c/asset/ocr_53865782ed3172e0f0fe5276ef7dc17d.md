# Program 3.7: Search a string using strstr() function

```
#include<stdio.h>
#include<string.h>
main()
{
    char string[] = "International";
    char searchstring[] = "nation";
    char substring[30];
    strcpy(substring, strstr(string, searchstring));
    printf("\nSub strings is: %s", substring);
}
Output:
Sub strings is: national
```
