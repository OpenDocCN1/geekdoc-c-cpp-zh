For all the cases total number of comparisons can be calculated recursively

```
T (n) = \begin{cases} c, & \text{when n=1} \\ 2T (n/2) + cn, & \text{otherwise} \end{cases}
```

Where c is a constant

Now,

```
T (n) = 2T (n/2) + cn
= 2. [2. T (n/4) + cn/2] + cn
= 2^2T (n/4) + cn+cn
= 2^2T (n/2^2) + 2cn
:
= 2^i T(n/2^i) + icn
```

Now, let 2^i = n, therefore i = log:n

```
T (n) = nT (n/n) + cnlog:n
= nT (1) + cnlog:n
= c + cnlog:n [hence T (1)=c]
= O (nlogn)
```

| Merge Sort algorithm | Best Case | Average Case | Worst Case |

| | O(nlogn) | O(nlogn) | O(nlogn) |

# Space complexity of MergeSort

The space complexity of the merge sort is O (n + logn), n for the auxiliary array and logn for the stack space.
