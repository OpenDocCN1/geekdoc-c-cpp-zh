# L1 Rotation

The left subtree of node A is AL of height h, right subtree of node B is BR of height h-1, left and right subtree of node C are CL and CR of height h-1 each. Now a node X from AL is deleted, then the height of AL becomes h-1 and A be the nearest ancestor node of X, with balance factor -2. The node B is the root of the right subtree of A with balance factor +1 and node X deleted from the left subtree of A, therefore L1 rotation is used. L1 rotation is similar with R-1 rotation.
