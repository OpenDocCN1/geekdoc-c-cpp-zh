# Binary Tree Traversal

Tree traversal is the operation of visiting each node in the tree exactly once. There are mainly two traversals are:

+   i) Depth First Search (DFS)
+   ii) Breadth First Search (BFS)

# Depth First Search

Depth first search traversal can be implemented easily using a stack, including recursion. Starting from the root of the binary tree, there are three main steps that can be performed. These steps are moving left (L), visiting node (D) and moving right (R), then there are six possible combinations of traversal: LDR, LRD, DLR, DRL, RDL and RLD. Now if we traverse left before right then only three traversal remains: LDR, LRD, DLR. LDR is known as inorder, LRD is postorder and DLR is preorder, these three are only standard binary tree traversals.

# Inorder Traversal

The inorder traversal of a non-empty binary tree is defined as follows, starting from root node:

+   i) Traverse the left subtree of root in inorder.
+   ii) Visit the root node.
+   iii) Traverse the right subtree of the root in inorder.
