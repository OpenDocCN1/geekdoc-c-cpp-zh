
## Complexity of a singly linked list

The cost to insert or delete an element into a known location in the singly linked list is O(1). Whereas for a linear array, the insert or delete operation cost is O(n). This is because, in the case of a linked list, insert or delete operations do not involve any data movement; just by performing pointer exchange among nodes, the insertion or deletion takes place. In the case of an array, both operations involve data replacement by n places.

## Table 5.3: Comparison of Array and Linked List

| Operations | Array | Linked List |
|---|---|---|
| Insert/delete at the beginning | O(n) | O(1) |
| Insert/delete at the end | O(1) | O(1) |
| Insert/delete in the middle | O(n) | O(1) |
| Indexing | O(1) | O(n) |
| Wastage of space | O(1) | O(n) |

## Circular Linked List

A circular linked list is a variation of a singly linked list in which the last node points to the first node of the list. Circular linked lists have neither a beginning nor an end.

In a circular linked list, there are two methods to know if a node is the first node or not.

- i) Either an external pointer, list, points to the first node, or
- ii) A header node is placed as the first node of the circular list.

The header node can be separated from the others by either having a sentinel value as the info part or having a dedicated flag variable to specify if the node is a header node or not.

A linked list can be implemented in either of two ways:

- i) A single pointer is used to point to the header node of the linked list, and the last node of the list points to the header node of the list.
- ii) Two different pointers can be used to point to the first and last nodes of the circular linked list, respectively.

In a linear linked list, once we traverse the list, it is difficult to return to the first node of the list. A circular linked list provides a solution to this problem. In a circular linked list, the last node points to the first node of the linked list, so there is no difficulty in returning to the first node when the list is traversed.

A circular linked list can easily be formed from a linear linked list where the last node of the linear linked list points to the first node of the linked list.

## Create a Circular Linked List

This algorithm creates a node and appends it after the last node (which points to the first node) of the existing list. HEAD is a pointer that holds the address of the first node of the linked list, and DATA is the value of the new node. NEW is a pointer that holds the address of the new node, and temp is a temporary pointer.

### Algorithm to Create a Circular Linked List

```
Algorithm: CIRCULAR_ADD (HEAD, ITEM)
1. [Create the new node]
   a) Allocate memory for the NEW node.
   b) If NEW = NULL, then Print: “Memory not Available” and Return.
   c) Set NEW→DATA = ITEM.
   d) Set NEW→LINK = NEW.
2. [Check whether the list is empty or not]
   If HEAD = NULL, then
       Set HEAD = NEW.
3. Else
   a) Set Temp = HEAD.
   b) Repeat while Temp→LINK ≠ HEAD do
       Set Temp = Temp→LINK.
   [End of loop]
   c) Set Temp→LINK = NEW.
4. [Make the new node point to the first node]
   Set NEW→LINK = HEAD.
5. Return.
```

Initially, HEAD is assigned NULL. When there is no node in a circular linked list, it indicates the first node of the linked list. Initially, it points to NULL.

![](img/723fa3ef35f5102eb67dc45b74bb823d_123_0.png)

After that, a NEW node is created, and the address is assigned to HEAD. The LINK field is assigned to the address of the HEAD node.

![](img/723fa3ef35f5102eb67dc45b74bb823d_124_0.png)

In the next step, another node is created and linked with the first node. The LINK field of the NEW node is linked with the first node.

## Add a New Node at the Beginning of the Circular Linked List

This algorithm creates a node and inserts it at the beginning of the list. HEAD is a pointer that holds the address of the first node of the linked list, and ITEM is the value of the new node. NEW is a pointer that holds the address of the new node, and Temp is a temporary pointer.

### Algorithm to Insert a Node at the Beginning

```
Algorithm: CIRADD_BEG (HEAD, ITEM)
1. [Create the new node]
   a) Allocate memory for the NEW node.
   b) If NEW = NULL, then Print: “Memory not Available” and Return.
   c) Set NEW→DATA = ITEM.
   d) Set NEW→LINK = HEAD.
2. a) Set Temp = HEAD.
   b) Repeat while Temp→LINK ≠ HEAD do
       Set Temp = Temp→LINK.
   [End of loop]
3. [Move HEAD to point to the new node]
   Set HEAD = NEW    // to make the new node the first node
   Set Temp→LINK = HEAD.
4. Return.
```

A NEW node is created and linked with the HEAD node of the circular linked list.

![](img/723fa3ef35f5102eb67dc45b74bb823d_124_2.png)

At last, the address of the NEW node is assigned to the LINK field of the last node of the linked list.

![](img/723fa3ef35f5102eb67dc45b74bb823d_125_0.png)

## Add the New Node after a Specific Location of the Circular Linked List

This algorithm creates a node and inserts it after the node at location loc. HEAD is a pointer that points to the first node, and ITEM is the value of the new node. NEW is a pointer that holds the address of the new node. Temp and PTemp are two temporary pointers used to traverse the list.

### Algorithm to Insert a Node after a Given Node Pointer

```
Algorithm: CIRADD_AFTER (HEAD, ITEM, LOC)
1. [Create the new node]
   a) Allocate memory for the new node.
   b) If NEW = NULL, then Print: “Memory not Available” and Return.
   c) Set NEW→DATA = ITEM.
   d) Set NEW→LINK = Temp.
2. [Make Temp point to the first node]
   Set Temp = HEAD.
3. Repeat for i = 1 to LOC
   a) Set PTemp = Temp and Temp = Temp→LINK.
   b) If Temp = HEAD, then
       Print: “There are less than loc+1 elements” and Return.
4. Set PTemp→LINK = NEW.
5. Return.
```

In the first step, Temp points to the first node of the circular linked list.

![](img/723fa3ef35f5102eb67dc45b74bb823d_125_1.png)

In the next step, Temp is moved until loc is found. Temp points to the node at the loc position. PTemp holds the address of the previous node. A NEW node is created whose LINK field is assigned the address of the HEAD node.

![](img/723fa3ef35f5102eb67dc45b74bb823d_125_2.png)

At last, the NEW node is inserted at the position before loc. For this example, loc is considered to be 2. That means the NEW node is inserted at the 2nd position of the circular linked list.

## Delete a Node from the Beginning of the Circular Linked List

This algorithm deletes a node from the beginning of a circular linked list. HEAD is a pointer that holds the address of the first node of the linked list. Temp is a temporary pointer. ITEM is the variable used to store the value of the deleted item.

### Algorithm to Delete a Node from the Beginning

```
Algorithm: CIRDEL (HEAD)
1. [Make Temp point to the first node]
   Set Temp = HEAD.
2. [Check for empty list]
   If HEAD = NULL, then
       Print: “The linked list is empty”.
3. Else
   a) If HEAD = Temp→LINK, then
       Set HEAD = NULL.
   Else
       P = HEAD.
       Repeat while P→LINK ≠ HEAD do
           Set P = P→LINK.
       [End of loop]
       HEAD = HEAD→LINK.
       P→LINK = HEAD.
4. Set ITEM = Temp→DATA.
5. Deallocate memory for Temp.
6. Return.
```

Firstly, Temp is assigned to the HEAD node of the circular linked list.
