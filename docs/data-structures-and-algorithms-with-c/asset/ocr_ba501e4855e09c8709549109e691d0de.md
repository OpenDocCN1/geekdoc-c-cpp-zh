Path: A path P has written as P = (v0, V1, V2...vn), of length n from a vertex u to v is defined as a sequence of (n+1) vertices. Here, u = v0, V = vn, and v(i-1) is adjacent to vi, for i = 1, 2, 3 ... n.

Closed Path: A path is known as a closed path if the edge has same endpoints. In figure 9.4, V1 V2 V4 V3, V1 is a closed path with same end point V1.
