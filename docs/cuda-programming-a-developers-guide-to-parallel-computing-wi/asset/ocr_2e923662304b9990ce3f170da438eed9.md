Items reported of note are the current driver and runtime version, which should be the same. Compute capability defines what type of device we have for a given device number. Also detailed is the number of cores/SMs per device, speed of the device, along with memory speed and width. Thus, it's possible to calculate the peak bandwidth on a given device. # Bandwidth test
