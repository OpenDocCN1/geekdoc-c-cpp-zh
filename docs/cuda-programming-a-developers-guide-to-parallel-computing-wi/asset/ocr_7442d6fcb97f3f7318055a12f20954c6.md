It's also possible to set up the tool to acquire data from a remote GPU. However, in most cases it's easier to buy a low-end GPU and install it into your PC or workstation. The first step needed to set up Parallel Nsight on Windows is to disable TDR (Figure 4.8). TDR (Timeout Detection and Recovery) is a mechanism in Windows that detects crashes in the driver-level code. If the driver stops responding to events, Windows resets the driver. As the driver will halt when you define a breakpoint, this feature needs to be disabled.
