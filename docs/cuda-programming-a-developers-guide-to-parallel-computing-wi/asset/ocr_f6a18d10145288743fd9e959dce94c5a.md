The code iterates over the dataset from array element 0 to num_elem-1 and then from element 1 to num_elem-2. The two data elements are read into local variables and compared. They are swapped if necessary and a counter num_swaps is used to keep track of the number of swaps done. When no swaps are necessary, the list is sorted.
