# BLOCK SCHEDULING

Suppose you have 1024 blocks to schedule, and eight SMs to schedule these onto. With the Fermi hardware, each SM can accept up to 8 blocks, but only if there is a low thread count per block. With a reasonable thread count, you typically see 6 to 8 blocks per SM.

Now 1024 blocks divided by six SMs is 170 complete blocks each, plus 4 blocks left over. We'll look at the leftover blocks in a minute, because it causes an interesting problem.
