In the process_results function the two conditions for processing a stream are that the stream has completed, that is, that we have met the stop event on the stream, and that the output queue for transmission currently has a free slot. If both of these are not true, the function simply returns and does nothing.

Otherwise, the function collects some timing information and prints it. It then copies the received data to the output queue, thus freeing up the page-locked memory on the host and freeing up a stream slot on the GPU for subsequent use.
