Reduction is an interesting problem in that, as we saw earlier, it's difficult to write a reduction that is faster than an OpenMP version given the transfer time of the data to the GPU. We win considerably because there is only one significant transfer to the device, but this dominates the overall time. However, if the data is already on the GPU, then of course this transfer is not associated with the reduction step.
