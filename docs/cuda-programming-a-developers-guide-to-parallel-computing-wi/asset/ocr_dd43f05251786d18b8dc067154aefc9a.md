Notice that to declare a global variable in the GPU memory space, you simply prefix it by a __device__ specifier. We have finally much the same kernel as before, reading four values from memory N times. However, in this example, I’ve had to reduce KERNEL_LOOP from 64 K down to 4 K as otherwise the kernel takes a very long time to execute. So when comparing the timings, remember we’re doing just one-sixteenth of the work. The results are interesting.
