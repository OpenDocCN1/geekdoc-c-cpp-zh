```
// continuous assignment
module AndOr(AandB, AorB, A, B);
output AandB, AorB,
input A, B;
wire AandB, AorB;
parameter delayO = 10;
assign #delayO AandB = A&B;
assign #delayO AorB = A|B;
endmodule
```

Syntax

# EXAMPLE A.3

The model for the AndOr circuit designed earlier can include all three delays as seen in Figure A.20.

```
// Compute the logical AND and OR of inputs A and B.
module AndOr(AandB, AorB, A, B);
output AandB, AorB;
input A, B;
wire AandB, AorB;
parameter delayO = 10;
parameter rise = 5;
parameter fall = 7;
assign #(rise, fall, delayO) AandB = A&B;
assign #(rise, fall, delayO) AorB = A|B;
endmodule
```
