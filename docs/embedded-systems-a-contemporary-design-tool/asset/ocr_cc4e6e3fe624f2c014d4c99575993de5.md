The Verilog modules in Figure 2.17 model the static-0 and static-1 hazards. We use such models to reflect real-world behavior when testing and verifying a design.

```
// Modeling a Static 0 Hazard
// A static circuit comprised of an and gate and an inverter
module Static0 (o0, i1, i2);
// declare the inputs and outputs
input i1, i2;
output o0;
parameter delay = 6;
// build the logic circuit
not #delay inv0(n1, i1);
and #delay(o0, n1, i2);
endmodule

// Modeling a Static 1 Hazard
// A static circuit comprised of an or gate and an inverter
module Static1 (o0, i1, i2);
// declare the inputs and outputs
input i1, i2;
output o0;
parameter delay = 6;
// build the logic circuit
not #delay inv0(n1, i1);
or #delay(o0, n1, i2);
endmodule
```
