# interarrival time

The invocation of aperiodic tasks is not fixed in time – they are asynchronous to the operation of the core system. Thus, there can be no jitter because there is no expected time for the initiating event. The duration between such tasks is called interarrival time. Such a time is critical when one needs to determine how schedule real-time tasks. Under such circumstances, the lower bound on interarrival time must be identified.
