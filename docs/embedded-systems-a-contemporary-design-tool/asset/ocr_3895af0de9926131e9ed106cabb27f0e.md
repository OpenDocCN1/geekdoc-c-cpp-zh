# ## 20.3.3.1 Computing the Board Level Bypass Capacitor

We compute board level bypass cap as follows:

+   1. Estimate the maximum step change in the supply current \(\Delta I\) due to gate switching as shown in Eq. (20.8). This current will flow through the PSW, returning to the power supply through the ground connection. Since we do not know when or which of the gates will switch, we assume the worst case that all N gates switch simultaneously at a known frequency. The parasitic capacitors for all driven gates on the PCB are in parallel and, thus, add.
+   
+   \(\Delta I_{max} = NC \frac{\Delta V_{signal}}{\Delta t}\)
+   
+   \(\Delta I_{max} = NC \frac{\Delta V_{signal}}{\tau_{rise}}\) (20.8)

+   2. Determine or specify the maximum power supply noise that the logic can handle – \(\Delta V_{noisemax}\).

+   3. Compute the maximum common path impedance, \(X_{max}\), as in Eq. (20.9).
+   
+   \(X_{max} = \frac{\Delta V_{noisemax}}{\Delta I_{max}}\) (20.9)

Remember. \(X_{max}\) is an impedance and, therefore, a function of signal frequency. Typically, we can allocate all of the impedance to one lumped value. If not, we must split the impedance up among the ground connection, the power connection, and the path between power and ground.

+   4. Compute the parasitic inductance, \(L_{psw}\), and the impedance \(X_L\) in the PSW. Combine with \(X_{max}\) as in Eq. (20.10) to find the frequency below which the inductive impedance of the PSW is acceptable, that is – a low enough impedance.
+   
+   \(X_L = j\omega L\)
+   
+   \(|X_L| = \omega L = X_{max} = \frac{\Delta V_{noisemax}}{\Delta I_{max}} = 2\pi F L_{psw}\) (20.10)

We now want to determine the frequency at which we start to get into trouble which gives us a worst case number. Assume that all gates switch together at frequency \(F = F_{psw}\). Substituting \(X_{max}\) from Eq. (20.9) into Eq. (20.10), \(\Delta V_L\) for \(\Delta V_{noisemax}\), and \(\Delta I_L\) for \(\Delta I_{max}\), then solving for \(F_{psw}\) we get Eq. (20.12).

```
\(F_{psw} = \left( \frac{\Delta V_L}{\Delta I_L} \right) \frac{1}{2\pi L_{psw}}\) (20.11)
```
