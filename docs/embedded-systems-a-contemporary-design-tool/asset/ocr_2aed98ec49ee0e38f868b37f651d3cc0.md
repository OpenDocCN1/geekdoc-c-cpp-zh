# 5.12.2 State Machines and State Chart Diagrams

(FSMs) We have studied and used the finite-state machines (FSMs) to model and to implement a system's behavior in time. The term state machine is used to describe:

+   - The states that a system can enter into during its lifetime.
+   - Events to which the system can respond.
+   - Possible responses the system can make to an event.
+   - Transitions between possible states.
