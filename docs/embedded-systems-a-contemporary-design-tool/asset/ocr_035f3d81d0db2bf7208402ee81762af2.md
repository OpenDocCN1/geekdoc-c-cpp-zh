# 3.6.4.1 Two-Stage Johnson Counter

The two-stage or 2-bit Johnson counter executes the state table and has the state diagram given in Figure 3.31.

![](bbox=[0.27, 0.15, 0.48, 0.34])

| Present State t=tn | Next State t=tn+1 |
|---|---|
| A B | A B |
| 0 0 0 | 1 1 0 |
| 1 0 0 | 2 1 1 |
| 2 1 1 | 3 0 1 |
| 3 0 1 | 0 0 0 |

The structural Verilog model for the design is given in the code module in Figure 3.32. Based on the Verilog code, the logic diagram is given in Figure 3.33.

```
module JohnsonCounter(qF1, qF0, clk, por);
input clk, por;
output qF1, qF0;
reg pullUp;
initial pullUp = 1;
// Build the counter
DFF f1(qF1, qBarF1, qF0, clk, pullUp, por);
DFF f0(qF0, qBarF0, qBarF1, clk, pullUp, por);
endmodule
```
