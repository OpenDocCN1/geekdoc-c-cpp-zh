# A.4.3.4 Flow of Control

The behavioral Verilog model supports many of the familiar flow of control constructs, such as branches, switches, and loops. In addition, the language provides support for event-based control.

# A.4.3.4.1 EVENTS

Verilog supports four different types of event-based control. These are given as:

+   - Regular event
+   - Named event
+   - OR event
+   - Level.

event-based control

Each is identified by the event control symbol, @. Verilog interprets an event as a change in the value of either a net or a register. Such a change can be used to invoke the evaluation of either single statement or a block of statements.

The syntax for each is given as follows.

```
Syntax
Regular Event
@(signal = action
variable = @( signal) action
signal may be clock, posedge clock, negedge clock for example
Named Event
event anEvent;
always @(anEvent) action // event is a keyword
OR Event
always @( signal1 or signal2 or signal3..) action
Level
always wait( signal) action // wait is a keyword
```
