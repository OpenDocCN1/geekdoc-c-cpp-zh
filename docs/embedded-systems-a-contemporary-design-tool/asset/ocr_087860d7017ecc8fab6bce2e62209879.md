# Evening with Friends

Set Menu

Parallel Preparation Paths:
- Stock: Prepare Stock -> Add Veggies -> Marriage Seasoning -> Simmer -> Serve Soup
- Meat: Prepare Meat -> Season Meat -> Cook Meat -> Make Sauce (Needs Salt) -> Reduce Sauce -> Serve Meat and Sauce
- Veggies: Clean Veggies -> Steam Veggies / Prepare Sauce -> Serve Veggies
- Fish: Clean Fish -> Season Fish -> Steam Fish / Prepare Garnish -> Serve Fish
- Fruit: Clean Fruit -> Puree Fruit -> Add Sugar -> Adjust Flavoring -> Put Into Freezer ([Lightly Frozen]) -> Remove from Freezer and Serve

Eat -> Enjoy Meal
