7.31 In the C language, the struct cannot hold function members; thus, we include functions by using pointers to functions. Combining data and the functions that operate on that data can be a very powerful tool in developing embedded applications.

(a) Give the class diagrams for three structures. The three structures will share a common data variable called sharedData through pointers to that data. The three functions will be getData(), compute(), and outputData(). The function getData() will bring data into the system, compute() will multiply the data by 2, and outputData() will send the data out of the system.

(b) Give the data and control flow diagrams for such a system.
