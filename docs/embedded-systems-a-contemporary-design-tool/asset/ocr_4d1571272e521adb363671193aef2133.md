# 14.6.2 Big-O Arithmetic

Big-O arithmetic is based on the following simple rules.

+   - Order common functions from smallest to largest.
+     1, log(N), N, Nlog(N), N^2, N^3, ..., 2^N, 3^N, ...

+   - Ignore constant multipliers.
+     300 N + 5N^4 + 6 * 2^N = O(N + N^4 + 2^N)

+   - Ignore everything except the highest order term.
+     N + N^4 + 2^N = O(2^N)
