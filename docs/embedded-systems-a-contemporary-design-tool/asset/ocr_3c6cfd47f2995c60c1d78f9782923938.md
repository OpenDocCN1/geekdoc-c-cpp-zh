The outputs on the decoder are implemented as open collector devices. In addition to the four data inputs, the decoder has three, active low, control inputs. The first, ~LT-Lamp Test, when active, turns all seven segments on. The remaining two support leading zero suppression in multidigit displays. When enabled, the number 00789 would display as 789. When the signal ~BI (Blank Input) is active, all data outputs are OFF independent of the input data. When the signal ~RBI (Ripple Blank Input) is active, all data inputs are low, all data outputs are OFF, and the signal ~RBO (Ripple Blank Output) is active. When implementing a multidigit display, to save power, weight, and the cost of parts, the decoder can be multiplexed among all of the display devices as illustrated in Figure 17.40.
