# 7.6.4 Operations

The only legal operations on a struct are:

+   - Copying.
+   - Assignment to as a unit.
+   - Taking address, using the address of the operator, &.

Structs cannot be compared. Operations such as:

```
Point (...) ;
Point pt1, pt2 ;
if (pt1 == pt2)
{
}
```

are illegal.
