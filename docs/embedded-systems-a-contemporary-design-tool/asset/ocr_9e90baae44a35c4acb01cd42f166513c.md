We now see that three factors dominate impedance between power and ground:
Low frequencies. Inductance of power distribution wiring 0 to F_sw
Middle frequencies. Impedance of board level bypass F_sw to F_boardpass
High frequencies. Impedance of distributed capacitive array F_boardpass to F_knee
We design capacitive array as follows.

+   1. Based upon our discussion above, we want the system to work up to F_knee. Thus, we calculate the total inductance, L_total, we can tolerate at higher frequency.
+   
+   |X_L| ≈ |Lω| ≈ |2πFL|
+   
+   F_knee = 0.5 / t_rise
+   
+   L_total = X_max / (2πF_knee) = X_max * t_rise / π

+   2. Next, from data sheets we find the series inductance of the bypass capacitors (C3) that we will use in the distributed array. A typical value will be around 1–5 nH for a surface mount, through hole device.
+   Since L_equivalent for N parallel inductors of the same value is:
+   
+   L_equivalent = L1 / N
+   
+   We must put N devices in parallel to get the desired value for L_total. Thus, we have:
+   
+   L_total1 = L_C3 / N
+   
+   which is what we want. Such a configuration reduces the total inductance and the total impedance. We now rearrange Eq. (20.22) and compute the number of bypass capacitors as in Eq. (20.23):
+   
+   N = L_C3 / L_total

+   3. The total array capacitance must have impedance less than X_max at frequencies from F_boardpass up to F_knee. Remember that L_C2 is the board level bypass parasitic.
+   From above:
+   
+   F_boardpass = X_max / (2πL_C2)
+   
+   From,
+   
+   X_C = 1 / (jωC)
+   
+   X_C = X_max and = 2πF_boardpass
+   
+   C_array = 1 / (2πF_boardpass X_max)

+   4. Finally, calculate the required capacitance value for the elements that will make up the distributed array.
+   
+   C_element = C_array / N
