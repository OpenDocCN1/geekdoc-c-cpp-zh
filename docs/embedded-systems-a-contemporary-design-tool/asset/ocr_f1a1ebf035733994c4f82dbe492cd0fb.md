Rewriting, we get Eq. (21.35):

```
\( V_0^- = V_0^+ \left( \frac{Z_L - Z_0}{Z_L + Z_0} \right) = \Gamma V_0^+ \) (21.35)
```

which gives a measure of the percentage of the incident signal from the source reflected back, as we see in Figure 21.20.

Let's now examine the boundary limits on Eq. (21.35). If the load impedance at the end of the conducting path appears as a high impedance device, i.e. if the load appears as an open circuit: Open Line \( Z_L = \infty \), then we have:

```
\( \Gamma = \frac{Z_L - Z_0}{Z_L + Z_0} = 1 \) (21.36)
```

which gives:

```
\( V_0^- = V_0^+ \)
```

If the load impedance at the end of the conducting path appears as a low impedance device, then the load appears as a short: Shorted Line \( Z_L = 0 \)

```
\( \Gamma = \frac{Z_L - Z_0}{Z_L + Z_0} = -1 \) (21.37)
```

which gives:

```
\( V_0^- = V_0^+ \)
```

If the load impedance at the end of the conducting path matches the characteristic impedance of the path, we have a matched line: Matched Line \( Z_L = Z_0 \)

```
\( \Gamma = \frac{Z_L - Z_0}{Z_L + Z_0} = 0 \) (21.38)
```

There will be no reflection.

In general, the magnitude of the reflection coefficient will be \(\le 1\), indicating that the reflections will eventually die out.
