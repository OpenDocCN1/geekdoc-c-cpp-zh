7. Build a simulator for a circuit built using logic gates. Consider the gates described in Exercise 15 of Chapter 6. You should allow the user to build the circuit on the graphics window. You should also allow a delay δ to be entered for each gate. A gate takes as input values 1 or 0, and produces output values according to its function. However, the output value is reliably available only after its delay. Specifically, suppose some input value changes at time t. Suppose this will cause the output value to change. Then the new correct value will appear at the output only at time t + δ. During the period from t to t + δ the value at the output will be undefined. For this you should use the value NAN supported as a part of the header file <cmath>. The value NAN represents "undefined value", actually the name is an acronym for "Not A Number". This value behaves as you might expect: do any arithmetic with it and the result is NAN.
