+   2. Here is a “clever” observation about the digit counting problem. Suppose a number $n$ has $d$ digits. Then $\lfloor n/10\rfloor$ has $d-1$ digits. Thus we simply count the number of times we can divide $n$ by 10 till we get zero and that will be the number of digits of the number. So the program is:

```
```cpp
main_program{
    int n, d=0;
    cin >> n;

    while(n>0){
        n = n/10;
        ++d;
    }

    cout << "There are "<<d<<" digits.\\n";
}
