# 16.

Develop a mini drawing program as follows. Your program should have buttons called "Line" and "Circle" which a user can click to draw a line or a circle. After a user clicks on "Line", you should take the next two clicks to mean the endpoints of the line, and so after that a line should be drawn connecting those points. For now, you will have to imprint that line on the canvas. Similarly, after clicking "Circle" the next point should be taken as the center, and the next point as a point on the circumference. You can also have buttons for colours, which can be used to select the colour before clicking on "Line" or "Circle".
