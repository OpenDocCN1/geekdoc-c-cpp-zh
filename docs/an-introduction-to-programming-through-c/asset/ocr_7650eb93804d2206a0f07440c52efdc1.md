# 27.3 Remarks

As you experiment with NRM you might notice that the error norm (as defined in Section 27.1.1) does not necessarily decrease in each iteration. This is understandable, the error norm is guaranteed to decrease only if the equations such as (27.6) hold exactly.

It is possible to show, however, that the vector Δu does indeed give the exact direction in which to move from u_cur for which the rate of reduction of the error norm is the largest possible. Thus there exists an α such that the error norm at u_cur + αΔu will be strictly smaller than that at u_cur. We can try to roughly find this α by starting with α = 1 (which is equivalent to taking the full step, ie. the basic NRM), and successively halving it till we find a point u_cur + αΔu where the error norm is lower than at u_cur.
