16. Consider the points (i, j) where 0 ≤ i, j < n for some constant n, say n = 10. We want to walk from (0,0) to (n − 1, n − 1) taking exactly n − 1 unit steps in the positive x direction, and exactly n − 1 unit steps in the positive y direction. It is acceptable to take order the steps in the x and y direction as we wish, i.e. we may alternate them or take all x steps first and so on. We must take a total of 2n − 2 steps, of which n − 1 must be along the x direction. Thus the total number of ways of choosing, which is also the number of distinct paths that we can follow, is (2n−2 choose n−1). With each path we can associate a 2n − 2 bit number, whose jth least significant bit is 0 if the jth step on the path is in the x direction, and 1 if the jth step is in the y direction.
