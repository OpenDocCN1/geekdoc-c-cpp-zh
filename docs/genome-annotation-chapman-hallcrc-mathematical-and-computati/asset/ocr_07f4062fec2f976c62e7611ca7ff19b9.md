The UCSC browser user interface contains a list of drop-down menus that can be used to initiate the user session. The set of menu options allows users to focus on a particular aspect of an organism's genome that they may wish to examine. There is also a link that allows users to add custom tracks to the displayed data. Upon locating the proper region of interest, the Web site is redirected to a graphical view, displaying the region horizontally, along with a few tracks in region. Menu options located at the bottom of this graphic display allow the user to customize annotations displayed on the screen. Zooming is performed by clicking on the scale buttons (1.5x, 3x, and 10x) that are above the graphic. Additionally, the user can click on a specific position to jump to the base sequence of a specific chromosome. Moving left and right is also done by clicking on the arrow buttons to zoom and also be done at three speeds. The UCSC browser has a variety of functions that can be used for research. These include the display of many different annotations, which are broken into several categories. In addition to these annotations, a homology search can be performed using BLAT, sequence searches using polymerase chain reaction (PCR) primer pairs with in silico PCR, and gene tables containing related genes based on homology, expression, or genomic location can be generated with Gene Sorter (http://genome.usc.edu/cgi-bin/hgNear). Also, users of the UCSC browser can upload their own annotations for display in the browser. Temporary additions can be accomplished in several formats including GFF, GTF, PSL, and BED file formats (http://genome.usc.edu/FAQ/Qformatfor these formats) can be viewed only on the machine from which the data was uploaded, for 8 hours after they were last accessed. Permanent and public additions can be done by uploading the track information into a Web site and linking the Web address (i.e., the URL) to the genome browser.
