This can capture genes that may not be described by the plain text labels or are too general to be captured by a few keywords. For example, capturing all carbohydrate metabolic genes with a few keywords is impossible, but the “carbohydrate metabolism” term is likely assigned to many genes in the genome.

The third way to search is using the automatically generated MAGPIE ID for a gene or a user-generated nametag. These custom nametag can be more memorable and can be set in the functional annotation form (“Seq Alias” in Figure 8.4).

The fourth search, unique to MAGPIE, is by taxonomic distribution of the gene. This search allows the user to find all lineage-specific genes, universal genes, or recent xenologs. The taxonomy names can be from any level of the NCBI database (www.ncbi.nlm.nih.gov/Taxonomy), including common names.
