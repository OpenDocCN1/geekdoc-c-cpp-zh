# 64 Genome Annotation

Complex variants composed of simultaneous insertion deletion events are often referred to as indels. The HGVS syntax is “c.345_347delinsTTTG” for the replacement of three bases in the reference sequence by the four bases TTTG. A special case of an indel is an inversion, where the insertion sequence is of the same length as the deletion, and the two sequences are reverse complement. The HGVS syntax for this case is “c.665_670inv” for a six-base inversion.

Because they span multiple base positions, insertions and deletions can be quite complex in their nomenclature. For example, “c.344_347+2del” is a six-base deletion, removing four coding bases and the (presumable) intron donor GT. The syntax “c.89-7*_89delinsGAA” is a five-base indel, just before the acceptor site of a 3’ UTR exon. A special case of insertions is duplication of short sequences from the reference genome, with the syntax “c.345_348dup.

In addition to the case effects as SNPs, insertions and deletions may cause the insertion or deletion of amino acids in the protein region. If the variant lengths are not multiples of three, translation frameshifts will also occur. For an example, the HGVS syntax is “p.Cys254Trps*” if the frameshift causes an amino acid change from cysteine to tryptophan, and the in-frame stop is 39 residues away. # 4.4.4 Copy Number Variation

In polyploid genomes, variants in the number of copies of a chromosomal segment occur in individuals (Freeman et al., 2006). These copy number variants (CNVs) may affect the genome via gene dosage effects and can lead to disease (Alman and Path, 2012). Methods for high-throughput sequencing of CNV calls are nascent, with most CNV data generated using comparative genomic hybridization (CGH) microglia (Alkan et al., 2011). These methods can be used to generate a relative copy number estimate (e.g., -1 or 1) over a region defined by the density of probes on the microarray.

Where high-resolution sequence data is available, the Wiggle file format (Kent et al., 2010) is suitable for storing and subsequently plotting the data in the UCSC genome browser and others (see Chapter 9). Where CNV data is coarse-grained, the BedGraph file format (Kent et al., 2010) can succinctly represent the information and is accepted by many of the same browsers.
