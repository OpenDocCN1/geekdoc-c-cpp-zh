# 4.4.1.3 Nucleosome Positioning

The position of nucleosomes in a coding region can affect transcription levels via interference with transcription initiators (positions near the start site) and transcription elongation factors (positions downstream) (Pokholok et al., 2005). Large-scale physical elucidation of nucleosome positioning and modification in smaller eukaryotic genomes has been published (Pokholok et al., 2005; Westberger et al., 2009), including changes during organism life cycle. Bioinformatics approaches to nucleosome position prediction (e.g., Segal et al., 2006) generally revolve around the ease with which a given DNA sequence bends, since this correlates with propensity to wrap around a nucleosome. Results are typically stored as GFF3 files.
