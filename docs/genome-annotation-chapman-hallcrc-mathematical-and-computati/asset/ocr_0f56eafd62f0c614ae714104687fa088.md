Examples include the University of California, Santa Cruz (UCSC) Genome Browser (Kent et al., 2002), Ensembl Genome Browser (Flicek et al., 2011), NCBI Map Viewer (ncbi.nlm.nih.gov/mapview), GBrowse (Stein et al., 2002), Bluejay (Soh et al., 2012; Soh et al., 2008), NCBI Genome Workbench (ncbi.nlm.nih.gov/projects/genbench), Integrated Genome Browser (Nicol et al., 2009), and Apollo (Lewis et al., 2002). Some of these are Web-based, whereas others are locally installable tools, as described in Sections 9.2 and 9.3, and respectively.

The annotated data are usually organized into units the form of linear or circular (for viral and microbial genomes) tracks representing genomic locations. A relatively small number of key tracks are shown by default when a genome is initially loaded, with more tracks loadable upon user request. Almost all genome browsers provide the user with the means to adjust the viewing scale, so that a genome can be viewed in its entirety, while specific areas of interest can also be selected from the global view and the display content can be customized to varying degrees. Most tools also have a built-in search capability to allow the user to search for annotations, such as gene names or gene families, with more complex queries of the underlying databases supported in certain genome browsers. As the number of Web-based tools and services for genomic data increases, some tools link to those external resources each time a new external resource needs to be accessed. Some genome browsers can also display multiple genomes simultaneously and show the similarities between annotated features for comparative genomics.

# 9.2 WEB-BASED GENOME ANNOTATION BROWSERS

Most Web-based genome browsers have originally been developed as a front end for accessing and viewing specific genome databases, which were created or maintained by the same group who developed the tool. Naturally, the development of this type of a genome browser is tightly coupled with the expansion of the genome databases that each site hosts. Nevertheless, some of these browsers over time developed into a modularized form that can be downloaded and installed to view locally hosted genome annotation data, which are stored using the same data format standard as the data for which the tool was initially created.
