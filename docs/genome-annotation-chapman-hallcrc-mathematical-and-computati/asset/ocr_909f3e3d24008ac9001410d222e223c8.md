Manual functional annotation is not a requirement, rather provides an opportunity for the user to correct borderline automated calls of function or start stop codon. This is an acknowledgment that no automated system will perfectly capture existing biological knowledge. It also allows new information for particular genes being studied in the lab to be included and shared with colleagues.

# 8.2.4 User Interface

Several MAGPIE web interface pages have been shown so far, which can be browsed from the genome summary image by an annotator. Frequently, a user will want to browse or edit but search the genome annotation. The main search interface for MAGPIE is shown in Figure 8.6.

The first search is a full text search of analysis results, with a filter for the quality of the evidence. This provides a more sensitive way to find sequences than the typical top descriptions indexed by other annotation Web sites.
