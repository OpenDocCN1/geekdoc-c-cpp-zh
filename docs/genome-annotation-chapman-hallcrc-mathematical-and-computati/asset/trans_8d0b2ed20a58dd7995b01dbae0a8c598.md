# 功能注释

## 7.1 引言
对于可以翻译成蛋白质的基因及其周围区域，可以通过分析将建议的信使 RNA (mRNA) 构建体（见第2章）与其预测的生物功能联系起来。由于这些注释大多是一次性的（例如基因组中特定位点的预测基因功能），它们通常使用“静态”注释工具完成（见第8章）。我们将静态注释工具定义为创建特征到基因组区域映射，并以表格、电子表格或基于 HTML 的网页作为最终输出的工具。通常，用户对这些系统的最终输出干预很少或完全不干预，必须按实接受静态注释工具创建的映射。这可能会产生问题，因为公共数据仓库包含大量错误条目，可能导致错误的功能分配。

主要，功能预测是基于对核酸数据的相似性搜索，以及开放阅读框的氨基酸翻译结果与公共数据进行对比，这些数据存储在 EMBL 数据库、GenBank 或本章概述的更专门的数据集合中。

## 7.2 物理和生物化学性质预测

### 7.2.1 物理化学特征
预测蛋白中疏水性（即厌水）氨基酸的分布可以指示蛋白质段是否可能自然位于溶液中，或位于（脂肪）膜旁边或内部。例如，EMBOSS (Rice et al., 2000) Pepwheel 程序计算所谓的“螺旋轮”以检查疏水残基的周期性。具有适当的周期性意味着蛋白质 α 螺旋的一侧是疏水的，另一侧是亲水性的（即喜水的）。这表明该蛋白质可能是跨膜 (TM) 转运体，或其他与脂肪膜和水分子相互作用的某些蛋白质。更广泛地说，跨膜蛋白段的预测是基于已知跨膜基因的氨基酸分布模型进行的。跨跨膜预测的早期成功是使用隐马尔可夫模型 (HMMs) 实现的 (Sonnhammer et al., 1998)。随后开发了改进这种技术的方法。目前的最佳实践是结合多个 TM 预测结果。例如，MetaTM (Klammer et al., 2009) 使用一种称为支持向量机 (Burges, 1998) 的统计方法将六种不同跨膜预测器的结果结合起来。这些方法还可以指示蛋白质的 N 端或 C 端是否预计在膜外。一个蛋白质可能包含多个跨膜结构域，在这种情况下，会对每个非膜段进行内/外预测。

### 7.2.2 序列基序预测
小的氨基酸序列模式被称为基序 (motifs)，它们在细胞中本身可能不具有生化功能，但可能表明该蛋白质是细胞内各种生化或运输过程的目标。

### 7.2.2.1 蛋白质修饰
蛋白质中的氨基酸可能会发生化学修饰，以改变或调节其生物功能。已记录了超过 750 种翻译后修饰 (PTMs) (Montecchi-Palazzi et al., 2008)。最常见的 PTM 包括添加乙酰基 (CH3 乙酰化)、甲酸 (HCOOH，甲酰化)、磷酸基 (PO4^3-，磷酸化)、多糖 (糖基化) 或泛素蛋白 (泛素化) (Parker et al., 2010)。其中，磷酸化对于参与细胞信号传递的蛋白质激活至关重要 (Krebs and Beavo, 1979)。糖基化影响蛋白质的溶解度、稳定性、半衰期和免疫原性 (Dennis et al., 1999)。泛素化有多种作用，包括在真核生物蛋白质回收中发挥关键作用 (Komander, 2009)。

针对如 PROSITE 数据库 (Hulo et al., 2007) 中常见位点的简单氨基酸基序可能会产生许多假阳性和假阴性。另一种方法是为特定类别的 PTM 构建专门工具，例如，激酸磷酸化 (Xue et al., 2006)。PHOSPHIDA (Gnad et al., 2011) 为上述提到的三种修饰提供了全面的数据库和预测工具，因此更具通用性。dbPTM 数据库 (Lee et al., 2006) 使用已实现的 PTM 位点构建了超过 20 种常见 PTM 类的 HMMs。这些 HMM 可以下载供本地使用。AutoMotifServer (Basu and Plewczynski, 2010) 提供了一个集成机器学习的平台，以高置信度预测最常见的修饰，既可以在线使用也可以本地安装。

在将质谱 (MS) 数据映射到注释基因组时，预测 PTM 也对于解释观察到的异常肽非常重要。将每种可能的修饰整合到 MS 搜索中计算开销很大，因此用高置信水平的 PTM 预测进行预注释可以显著加速此类搜索。

### 7.2.2.2 蛋白质定位
氨基酸序列中的基序可以引导蛋白质进入细胞的特定部分。这些基序被称为定位信号。引导蛋白质从细胞分泌的信号肽可以通过 SignalP (Petersen et al., 2011) 识别所有生物，以及仅针对真核生物的 Phobius (Käll et al., 2007)。这些工具可将蛋白质 N 端与序列模型匹配，该模型是使用已知分泌蛋白衍生的，用于预测膜锚蛋白。TargetP (Emanuelsson et al., 2007) 增强了 SignalP，允许预测叶绿体转肽和线粒体靶向肽 N 端基序的存在。

结合多种预测并检查 N 端和 C端的程序为原核生物实现了更全面的定位分析。PSORTb (Yu et al., 2010) 是一个典型的例子，结合了信号肽、靶向基序和跨膜拓扑结构。LocateP (Zhou et al., 2008) 是另一个组合预测器，准确性在90%左右。LOCTree (Nair and Rost, 2005) 基于针对植物、非植物真核生物和原核生物的独立决策树。在原核生物中，它可以分类分泌、周质和细胞质蛋白。在真核生物中，蛋白质被分配到六种定位之一：细胞外、核、细胞质、叶绿体、线粒体或其他细胞器。BaCello (Pierleoni et al., 2006) 为三个真核域（动物、植物和真菌）实现了不同的预测器。

定位信号的注释可以获得关于细胞适应的价值见解。例如，定位信号可能包含在某些剪接变体中缺失的外显子内（第2.6节）。这将指示蛋白质的差异转运。定位也可以为其他功能注释提供支持。例如，真菌基因组中注释为碳水化合物分解酶的基因通常包含信号肽，因为已知这些酶是分泌的 (Braaksma et al., 2010)。

## 7.3 蛋白质结构域
蛋白质的功能主要取决于其三维结构，该结构本身可以分解为功能单元，称为蛋白质结构域。这些蛋白质结构域保护三维结构和电荷分布。蛋白质结构域促进多样化的生化功能，如金属结合或荧光。蛋白质可能包含多个结构域，例如，碳水化合物结合结构域将复合物（配体）与蛋白质相邻，碳水化合物分解结构域随后切割配体。根据 InterProt 目录的大小，已知存在数万个保守结构域 (Hunter et al., 2011)。维持功能对结构和电荷的限制反映在二级（线性氨基酸）序列每个位置的氨基酸替换速率上。位置特异评分模型 (PSSMs) 用于捕捉这些结构域约束，被称为蛋白质结构域模型。最常用的模型是 HMM (Krogh et al., 1994)。如图 7.1 所示，模型代表了对齐输入中所有正样本的总和。这使得查询与模型的匹配比与任何特定正样本匹配更具敏感性。
