Don Gilbert from Indiana University solved this problem through the creation of a tool called Readseq (2003), which can be used to convert many different file formats each other. Readseq was one of the first public domain and open source bioinformatics tools and Gilbert can be credited as one of the early bioinformatics leaders who introduced this policy in the field.

Initially, users could only use local installations of bioinformatics tools, but even before the existence of the World Wide Web, developers began to make their tools accessible over the Internet. E-mail was used as a vehicle for the use of remote bioinformatics tools. The FASTA and BLAST e-mail servers, as well as some "exotic" database search e-mail servers were commonly used.
