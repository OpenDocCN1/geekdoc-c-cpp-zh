These programs also tend to be quite sensitive to the input parameters used, and generally a trade-off between speed and accuracy exists. Established mRNA-to-genome mappers like BLAT (Kent, 2002) can also be used, as long as the data set is small enough or processing time is not a critical factor. Most modern tools that incorporate short-read data into gene predictions and visualizations SAM-formatted files as the input, therefore the need for multigabyte-file-format conversion for these other tools must be taken into consideration as well.

The mapping of reads directly to the genome is relatively straightforward, with a few parameters such as the number of mismatches allowed and whether the quality values of the bases are taken into consideration. The exceptions to this are intron-spanning reads and multicopy genes. Software tools that perform this type of mapping are quite sensitive to the parameters given. The length of the hit “anchor” should be somewhat less than the length of the reads mapped in order to catch spanning introns. One must specify parameters such as minimum and maximum intron size and whether noncanonical splice sites are known to occur. Thorough background knowledge about what is biologically viable for the organism is studied to maximize the accuracy and relevance of the spliced-read predictions.

Read mapping is also highly parallelizable, therefore several short-read alignment tools have been adapted to work on computer clusters, and called cloud clouds, where processor time can be rented by the hour. The growing adoption of cloud computing means that even individual researchers do not own much infrastructure themselves can perform mRNA analysis. Their names suggest, tools such as CloudBurst (Schatz, 2009) for mapping and Contrail (http://contrail-bio.sf.net) for novo assembly have been built specifically to use cloud computing. In some cases, tools that use the OpenMPI parallelization libraries seamlessly transition to the Amazon EC2 cloud, as has been reported for AbySS. Some knowledge of the resource requirements for the types of assemblies being performed is required; several tools can use more than 30GB of RAM, and require the rental of time on suitably equipped machines.
