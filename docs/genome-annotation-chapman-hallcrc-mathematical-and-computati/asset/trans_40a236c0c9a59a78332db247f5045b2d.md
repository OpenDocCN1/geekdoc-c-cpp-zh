

# 动态注释系统
终端用户驱动的注释与可视化

## 9.1 引言

DNA 测序和分析技术的最新进展导致序列和注释数据在极其多样的数据类型和信息粒度上呈现爆炸式增长。基因组注释的核心挑战之一是对从静态注释产生的大量基因组数据进行解释和可视化。为了研究具有科学注释和相关数据的基因组等复杂生物实体，需要一种面向用户的计算工具，帮助用户可视化基因组注释并将数据与他们自己的结果整合。理想情况下，这种视觉丰富的环境允许研究人员以多个视图尺度和自定义方式探索基因组序列，使其能够对其注释数据得出有意义的解释。用于查看和整合基因组数据的图像软件系统需要为用户提供视觉效果，在统一的视觉语境下阐明数据。本质上，这代表了第二代基因组分析和注释系统，与早期静态基因组注释系统相比，特别是在图形界面上灵活得多。

有许多被松散分类为基因组浏览器的软件工具可以使用图形用户界面显示基因组数据和生物学注释。例如加州大学圣克塞亚分校（UCSC）基因组浏览器（Kent 等，2002）、Ensembl 基因组浏览器（Flicek 等，2011）、NCBI Map Viewer（ncbi.nlm.nih.gov/mapview）、GBrowse（Stein 等，2002）、Bluejay（Soh 等，2012；S 等，2008）、NCBI 基因组工作站（ncbi.nlm.nih.gov/projects/genbench）、集成基因组浏览器（Nicol 等，2009）以及 Apollo（Lewis 等，2002）。其中一些是基于 Web 的，另一些是可以在本地安装的工具，分别如 9.2 节和 9.3 节所述。

注释数据通常组织成线性或圆形（用于病毒和微生物基因组）的轨道（tracks）形式，代表基因组位置。当基因组最初加载时，默认显示较少的关键轨道，根据用户请求，可以加载更多轨道。几乎所有的基因组浏览器都为用户提供了调整视图尺度的手段，因此可以查看整个基因组，同时也可以从全局视图中选择特定区域，并可以不同程度地自定义显示内容。大多数工具还具有内置搜索功能，允许用户搜索注释（如基因名称或基因家族），某些基因组浏览器还支持对底层数据库进行更复杂的查询。随着用于基因组数据的 Web 工具和服务的增加，某些工具在每次需要访问新的外部资源时都会链接到这些外部资源。某些基因组浏览器还可以同时显示多个基因组，并显示注释特征之间的相似性以进行比较基因组学研究。

## 9.2 Web基因组注释浏览器

大多数 Web 基因组浏览器最初是作为访问和查看特定基因组数据库的前端开发的，这些数据库是由开发工具的同一小组创建或维护的。这种基因这种浏览器的开发与每个网站托管的基因组数据库的扩张密切耦合。尽管如此，这些浏览器随着时间的推移发展成了模块化形式，可以下载并安装以查看本地托管的基因组注释数据，这些数据使用工具最初创建时相同的数据格式标准存储。

### 9.2.1 加州大学圣克塞亚分校（UCSC）基因组浏览器

加州大学圣克塞亚分校（UCSC）基因组浏览器（Kent 等，2002）最初是为了根据人类基因组计划（www.genome.gov/11006939）向公众提供最新的人类基因组序列版本（国际基因组测序联盟，2001）。UCSC 浏览器利用基于 MySQL 的数据库来编目录基因组信息，但早期只是 C 语言中的一个小脚本，最初用于查看秀线虫（Caenorhabditis elegans）基因预测的剪接图（Kamath 等，2003）。转向使用 MySQL 是为了在查看人类基因组中显著大量数据时保持程序响应时间，人类基因组的最新组装是基因组参考联盟人类构建 37 版（GRCh37，也称为 hg19），于 2009 年 2 月发布。

多年年来，UCSC 基因组浏览器数据库（Dresler 等，2012）一直提供来自许多外部源以及 UCSC 的基因组注释。有关新基因组组装和注释的数据库更新每年通过《核酸研究》（Nucleic Acids Research）杂志的网站（http://nar.oxfordjournals.org）提供。这些序列和注释来自多种来源，包括 UCSC 注释流水线和来自全球研究中心的合作者。UCSC 管理 DNA 元素百科书（ENCODE）联盟（2004，Rosenbloom 等，2012）序列相关数据的官方仓库，并支持数据提交、存储、检索和可视化的协调。ENCODE 起于 2003 年 9 月，目标是识别人类基因组序列中的功能性元件。

UCSC 浏览器的独特功能是核苷酸序列的主图表示，并能够加载和显示各种被称为“轨道”的注释。许多轨道分为八类：比对和测序、表型和疾病关联、基因和基因预测、信使 RNA（mRNA）和表达序列标签（EST）、表达、调控、比较基因组学和重复。UCSC 浏览器允许对数据库上的许多轨道进行可视化。mRNA 和 EST 数据可以从 GenBank 获取，并由 BLAT 进行比对（Kent, 2002）。表达数据可以从合作者处获得，例如 Affymetrix 或基因研究所（GNF）。此外，变异信息通过单核苷酸多态性数据库（dbSNP; nc.nlm.nih.gov/projects/SNP）呈现位点。重复序列来自 RepeatMasker（www.repeatmask.org）和串联重复器（TRF; http://tandem.bu.edu/trf/trf.html）。

UCSC 浏览器用户界面包含下拉菜单列表，用于启动用户会话。菜单选项集允许用户关注他们想要检查的生物基因组的特定方面。还有一个链接允许用户向显示的数据中添加自定义轨道。一旦确定了感兴趣的区域，网站将重定向到图形视图，水平显示该区域，并带有区域内的轨道。位于图形底部的菜单选项允许用户自定义屏幕上显示的注释。缩放通过点击图形上缩放按钮（1.5x、3x 和 10x）执行。此外，用户可以点击特定位置跳转到特定染色体的碱基序列。向左右移动也可以通过点击箭头按钮完成，并有三种速度。图 9.1 显示了 UCSC 浏览器显示人类 21 号染色体基因组区域的截图。
