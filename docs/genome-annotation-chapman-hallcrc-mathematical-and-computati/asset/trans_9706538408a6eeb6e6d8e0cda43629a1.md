多种比对算法依赖于启发式方法来使最佳比对在计算上变得可行，它们并不一定能产生完美的比对。这意味着它们的结果通常包含错误。检测和纠正这些错误需要专门的知识，因此任务通常需要对生成的比对进行手动编辑和整理。许多比对可视化工具也提供了这种编辑功能，并带有序列导航和搜索帮助，帮助用户快速定位感兴趣的区域，以便进行详细分析和后续的比对编辑。允许编辑的代表性工具包括 GeneDoc (www.psc.edu/biomed/genedoc) (Nicholas et al., 1997)、Jalview (Waterhouse et al., 2009)、PFAAT (Caffrey et al., 2007) 和 CINEMA (Lord et al., 2002)。

## 6.4 层级结构的可视化

生物学研究中的许多计数或发现最好被描述为层级结构，通常以树的形式表示。例如，系统发育分析产生发育树，发育树是对所研究生物之间推断出的进化关系的树状表示。另一个例子是基因本体计划（Ashburner et al., 2000），其目标是提供一组受控的词汇，用于描述所有物种的实例基因和基因产物属性以及注释。生物本体可能包含大量术语，这些术语最好组织成表示为树或图的分级结构。聚类是一种应用于广泛生物研究分析方法，例如微阵列实验、序列分析以及有时的系统发育分析，其目标是根据距离或相似性对数据进行分组和划分。常用的聚类算法（例如分层次聚类）经常以树的形式显示簇之间的关系，因为簇是随着生成并合并形成更大的簇而产生的。层级结构是许多生物分析的自然表示方式，目前已经开发了许多用于其可视化的工具（Pavlopoulos et al., 2010）。

### 6.4.1 树的可视化样式

大多数可视化工具都有内置函数，使用欧几里得几何来显示树，通常使用几种不同的样式，特别是在显示系统发育树时。发育树可以可视化为发育图（phylogram）或支系图（cladogram）。在发育图中，分支长度被认为与进化变化的程度成比例；而在支系图中，分支顺序代表了推断的系统发育关系。此外，取决于物种相对于外群序列的位置，每棵树可以是有根或无根的。因此，具有假设共同祖先（即根）的发育图或支系图被认为是有根树，而没有此类祖先的被认为是无根树。

在空间布局方面，树的形状可以是矩形的、倾斜的或圆形的。在矩形树中，节点沿水平或垂直轴布局，分支沿另一轴绘制，以显示层级结构。矩形树中可以可视化数百个节点，通常与其他矩形显示（如热图）结合使用，但用户顺着分支进行视觉导航可能会迅速变得困难。倾斜树的布局与矩形版本本质上相同，只是它使用倾斜线绘制分支以使层级结构更加突出。圆形树的根位于圆形空间的中心，分支从中心向所有方向发射。这种布局比矩形或倾斜布局更节省空间，但比较分支长度可能更有挑战性。图 6.5 展示了使用 Dendrogram (Huson et al., 2007) 生成的六不同的聚类树布局。

对于具有大量节点且每个节点有许多孩子的树，要显示的节点和边呈指数级增长，需要巨大的空间，在使用时会导致严重的视觉混乱。通过在双曲空间中绘制树可以实现更高效的空间利用。这种布局适用于可视化大量的节点。双曲树通常在圆内显示，这提供了双曲平面的鱼眼（即广角）视图。其核心思想是将处于焦点的节点放置在圆心附近以强调它们，而将未焦点的节点放置在远离中心并向圆边界的地方。边长度根据它们距离圆心的距离进行指数级缩放。通过提供平移机制，双曲树查看器允许用户将树的不同分支带到中心聚焦区域进行更仔细的检查，同时保持整棵树的上下文。

### 6.4.2 树的可视化工具

目前没有描述树的标准文件格式。然而，存在一种被大多数树可视化工具支持的广泛使用的格式：Newick 格式。Newick 格式也称为 New Hampshire 格式，它使用字符命名节点，使用成对的括号表示节点的节点，并使用逗号分隔节点。任何节点都可以附加一个数字来指示其与父节点的距离。详细的描述和示例可以从 Felsenstein (1989) 找到，他在推广 Newick 格式方面起了关键作用（http://evolution.genetics.washington.edu/phylip/newicktree.html）。Nexus 格式是另一种常用的格式，它包含了 Newick 格式的树以及对元数据的支持。该格式最初由基于简约约法的系统发育分析 (PAUP) (Swofford, 2002) 引入，这是一个广泛用于推断系统发育树的软件包。

TreeView (Page, 1996) 是一种在 Apple Macintosh 和 Windows PC 上显示系统发育关系的经典程序。它提供了一种查看树文件格式树内容的简单方法，能够读取多达 1000 个分类单元的树。它支持原生图形格式（例如 Macintosh 上的 PICT 和 Windows 上的 Windows 元文件），以便将树图像复制到其他应用程序并将树保存为图像文件。可以在一页上打印多棵树，或跨多页打印单棵树。树也可以进行编辑。TreeView 不再处于活跃开发中，但它是早期用于快速树可视化程序之一。TreeView X (http://darwin.zoology.gl.ac.uk/~rpage/treeview) 是后来开发的 TreeView 的一个版本，支持在 Linux 和其他 Unix 系统上显示系统发育树。
