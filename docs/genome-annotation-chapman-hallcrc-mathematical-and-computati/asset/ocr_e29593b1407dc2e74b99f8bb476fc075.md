# 9.3.4 Apollo

Apollo (Lets et al., 2002) is a genome annotation editing and viewing tool. It was jointly developed by the Berkeley Drosophila Genome Project (http://apollo.berkeley.pop.org), which is part of the FlyBase consortium and the Sanger Institute (http://ensembl.org) of Cambridge, United Kingdom. It was initially used in FlyBase to annotate the Drosophila melanogaster genome (Celniker and Rubin, 2003). Apollo has been incorporated into the GMOD project as the main community annotation and sharing tool through which data providers can share their annotations and let collaborators edit them directly.
