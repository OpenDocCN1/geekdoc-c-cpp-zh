# 5.3.6 GeneSkipper

早期的测序工作需要能够分析较大的连续序列文件（contigs）并提供额外信息和图形化表示的工具，以反映测序进度。EMBL 海德堡是参与酵母基因组计划的地点之一，因此 Christian Schwager 及其团队在 EMBL 创建了基于 Windows 的软件工具 GeneSkipper，它是首批图形化表示已测序 contigs 分析结果（即六个蛋白翻译读框和潜在编码区）的工具之一。

# 5.3.7 Sequencer

Apple Macintosh 电脑一直被认为提供了计算机行业中最易用的界面之一。最终，Howard Cash 创立了一名为 GeneCodes 的公司，为 Macintosh 环境创建了一个序列组装系统，称为 Sequencer（www.sequencer.com）。随着时间的推移，增加了对 Windows 平台的支持。该系统至今仍在销售，并在全球许多实验室中使用。

# 5.4 从 FAST 文件到注释基因组

Staden Package、GeneSkipper 和 Sequencer 对基因组注释任务提供的支持非常有限。本质上，它们接收原始序列文件，并产生 FAST 格式（或其他格式）的组装序列作为输出。因此，随着时间的推移，开发了专门工具，最初用于收集注释信息（这些信息是以手动或半自动方式创建的，例如 ACeDB 工具族），后来是全自动化的工具。

# 5.4.1 ACDeDB

拟南芥（Arabidopsis thaliana）和秀秀线虫（Caenorhabditis elegans）的测序项目产生了 AtDB（一个拟南芥数据库）（Cherry et al., 1992）和 ACDeDB（一个秀秀线虫数据库）（Cherry and Cartinhour, 1994），它们收集了与基因组注释相关的信息并图形化表示了这些信息。与 GeneSkipper 类似，这些系统是在互联网普及初期创建的。使用 ACeDB 系统创建的基因注释可以下载并安装在 UNIX 机器（早期可能也支持其他系统）。该系统的维护非常复杂，因此只有在少数情况下才为其他基因组创建了数据库，例如某些人类染色体和分裂酵母（Schizosomyces pombe）。特别是 ACeDB 处理基因组信息的能力最好，因为工作流中没有建立改变序列状态（从首次组装到完成的基因组）的概念。ACeDB 后来被配备了 Web 功能，但该开发的成功程度有限。尽管如此，这些系统至今仍然存在，英国的 Sanger 中心目前维护着其中一个此类的集合（www.acedb.org）。

# 5.4.2 一个基因组计划，三个基因组注释系统的开始

在全基因组测序的早期，研究人员通常会将 DNA 序列保密直到其发表。这当然阻止了整个科学社区访问这些序列，因此可用的序列信息很少，无法在构建生物信息学以分析和注释大段基因组序列时作为范例。有几个显著的差异，包括支原圆变形虫（Myoplasma capriculum）测序项目（Dolan et al., 1995）。研究人员开放了 draft-mat 版本的早期序列访问。这最终导致了至少三个软件包的创建，它们在自动化基因组分析和注释领域发挥了作用。

直到今天，两个系统 PEDANT（Frishman et al., 2001）和 MAGPIE（Gaaster and Sensen, 1996）仍在使用，而第三个名为 Bioscout 的商业产品随着 LION Biosciences 的终结而消失。PEDANT 现在是德国慕尼黑 Biomatik AG 产品的一部分，而 MAGPIE 是一个开源系统，可以从 Sourceforge 免费下载。所有三个系统最初产生基因区域功能分配的基于 HTML 的表格输出。随着时间的推移，系统不断演进，并添加了分析结果的图形化表示。某些基于 HTML 的方法将在后续章节详细介绍。

# 5.5 结论

生物信息学作为一个研究领域还不到 40 年。在这段时间时间内，开发了许多有用的独立工具，用于表征序列。随着时间的推移，它们被整合到流水线中，用于基因组。最初，注释是以表格形式列出的，但随着时间的推移，证明图形化表示对大多数用户更有用。生物信息学已采用互联网作为共享注释的载体。几乎每种技术方法，从早期的 HTML 方法到最新的 XML 系统都尝试过。今天，我们拥有处理数十万基因组规模的高效工具，将在后续章节讨论。
