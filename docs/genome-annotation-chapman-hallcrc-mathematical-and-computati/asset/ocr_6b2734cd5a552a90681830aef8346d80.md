Profile plots are a common way to visualize high-dimensional data in a two-dimensional space. To plot n-dimensional data points, n vertical and equally spaced lines are drawn. A point in an n-dimensional space is represented as a line graph, connecting n vertices on the n parallel lines, where the vertex positions correspond to the n coordinates of the point. This visualization method enables the user to perceive the expression trends of many genes at the same time, as the vertical positions on the parallel lines can be easily compared. This method facilitates the comparison of expression levels of a set of genes under different experimental conditions (e.g., normal versus diseased tissue) or over a course of time. It is also possible to quickly find a set of genes that are upregulated or downregulated at certain experimental conditions of time points. The biggest limitation of profile plots is that the line graphs tend to severely overlap, creating visual clutter, which may make it hard to visualize expression levels of even a moderate number of genes at the same time. As a solution to this problem, coloring schemes can be adopted to help distinguish graph lines.
