## 9.3.4 Apollo

Apollo (Lets et al., 2002) 是一种基因组注释编辑和查看工具。它由伯克利果蝇基因组项目（http://apollo.berkeley.pop.org，FlyBase 联盟的一部分）和英国剑桥的桑格研究所（http://ensembl.org）联合开发。它最初用于 FlyBase 中对黑腹果蝇基因组进行注释（Celniker and Rubin, 2003）。Apollo 已被纳入 GMOD 项目，作为主要的社区注释和共享工具，数据提供者可以通过该工具共享他们的注释并让合作者直接编辑。Apollo 允许研究人员可视化不同详细程度的基因组注释，并在图形环境中进行注释。Apollo 支持许多数据格式，包括 XML、GenBank、GFF3 和 GMOD 的 Chado 数据库模式。Apollo 是一个 Java 应用程序，可以在 Windows、Mac OS X、Linux、Solaris 以及任何其他能够运行 Java 的 Unix 平台上下载和运行。

## 9.4 基因组比较可视化

一旦基因组被注释，通常需要将其与相似的基因组进行比较。比较多个基因组是研究生物的常用方法，用于阐明同源基因组的功能和进化背景。比较基因组学产生了对能够显示两个或多个基因组之间共线性（synteny）的可视化工具的需求。内置比较基因组功能的基因组浏览器在用户界面和显示外观上与传统的基因组浏览器相似，但通常内置了两个额外的关键能力：在显示区域显示多个基因组的特征，以及视觉上表达显示的基因组或基因组特征之间关系的方法。具有比较功能的基因组浏览器可以根据比较基因组之间关系的视觉表示方式大致分为三类：能够显示图表、线性表示或圆形表示的工具。

### 9.4.1 点图 (Dot Plots)

二维点图传统上被用于可视化两个数据集之间的关系，其中一组沿水平轴表示，另一组沿垂直轴表示。水平轴和垂直轴代表不同的基因组或物种，图中的点代表相似基因组元素。这种显示方案适用于仅显示两个基因组的对齐，这可能是一个严重的局限。它实现在 SyncMap (Lyons et al., 2008)、VISTA (http://pipeline.lbl.gov)、MEDEA (www.broadinstitute.org/annotation/medea) 和 GenomeMatcher (Ohtsubo et al., 2008) 等工具中。通过局部点组可以轻松识别基因重复或重排，每组形成一个特定的聚类模式（如直线）。这些工具都支持缩放和平移，允许用户浏览所显示基因组的不同部分。

### 9.4.2 线性表示

传统的基于 Web 的基因组浏览器通常使用“轨道”（track）的概念来在单个或多个基因组位置显示特定类型的基因组特征。因此，绝大多数比较基因组浏览器也依赖多个线性轨道来表示多个基因组及其特征。基于 GBrowse 的三个基因组浏览器允许所有这些浏览器在线性轨道表示中显示额外的基因组进行比较。GBrowse_syn (http://gmod.org/wiki/GBrowse_syn)，即通用共线性浏览器，可用于结合参考基因组显示多个基因组。参考基因组显示在中心，额外的基因组显示在上下。可以来自其他来源的多序列比对、共线性或共线性数据可以通过 GBrowse 生成的基因组注释进行查看。用户可以更改中心基因组（即参考基因组）以及比较显示的单位大小，这意味着基因组可以在序列级别、基因级别或更大的块级别上进行比较。目前的标准 GBrowse 软件包包含了 GBrowse_syn 工具包。

SynBrowse (Brendel et al., 2007) 是 GBrowse 家族中用于通用序列比较的软件工具。这是通过可视化不同物种之间以及同一物种内部基因组比对来实现的。SynBrowse 的设计目标是帮助生物学家分析基因组共线性、基因同源和其他保守性，这使得它研究基因重复和基因组进化非常有用。SynBrowse 的数据以标准的 GFF2 格式 (http://gmod.org/wiki/GFF2) 创建，其中使用目标标记来表示一个区域与另一个基因组的对应关系。基因组特征之间的关系可以在多个级别显示，包括“共线性块”、“编码基因”和“编码外子”。SynBrowse 运行在 BioPerl (Stajich et al., 2002) 之上，并使用了 GBrowse 的配置和实用程序模块。

SynView (Wang et al., 2006) 是另一个通过标准 GBrowse 配置实现的基因组浏览器。SynView 用于 PlasmoDB (www.parasdb.org)。

## 9.4.3 圆形表示

基因的圆形表示有助于在全基因组视图直观地比较多个微生物或病毒基因。在这种视图模式下，线性轨道被同心圆取代，并用弧表示基因组区域。尽管具有明显的优势，但只有少数基因组浏览器支持这种类型的表示。在 Bluejay 中，用户可以并排可视化多个基因组，并基于基因而非核苷酸进行直接的视觉比较。Bluejay 根据当前加载的基因组数量进入和退出比较模式，并允许同时比较无限数量的基因组。
