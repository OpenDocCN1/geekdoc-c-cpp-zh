# CHAPMAN & HALL/CRC
数学与计算生物学系列

目标与范围：
本系列旨在捕捉整个数学、计算生物学及医学领域的新进展，并总结相关知识。我们致力于通过出版广泛的教科书、参考著作和手册，鼓励将数学、统计和计算方法整合到生物学中。该系列收录的作品旨在吸引数学、统计和计算科学、基础生物学和生物工程领域的学生、研究人员和专业人士，以及该领域的跨学科研究人员。非常鼓励包含具体的案例、应用，以及编程技术和示例。
