## 9.2.4 通用基因组浏览器

通用基因组浏览器 (GBrowse) (Stein et al., 2002) 是源自通用模型组织数据库项目 (GMOD) (http://gmod.org) 开发的最广泛使用的软件工具之一。在本文编写时，根据 GMOD 用户页面（http://gmod.org/wiki/GMOD_Users），有超过一百个数据库或组织以不同形式使用 GBrowse。一些用户示例包括*酿酵母*基因数据库 (SGD; http://yeastgenome.org)、WormBase (http://wormbase.org)、FlyBase (http://flybase.org)、信息学 HapMap 项目 (http://mipmap.org)、小鼠基因组信息学 (MGI; http://informatics.jax.org)。*拟南芥*信息资源 (TAIR; http://arabidopsis.org)、Gramene (http://gramene.org) 以及海胆基因组数据库 (SpBase; http://spbase.org)。

基因组数据以三个不同的级别显示：概述、区域和细节。在每个级别上，注释数据可以水平组织成轨道。可以使用各种预制和可自定义的字形（glyphs）方便地在轨道上表示各种基因组特征，字形是颜色、形状和大小各不同的图形符号，用于表示不同的对象。轨道的垂直排列和外观可以通过用户界面进行自定义。可以通过注释 ID、关键词或注释对特征进行搜索。用户还可以将自定义轨道上传到 GBrowse，其中包含第三方的特征注释。任意 URL 可以附加到注释上，以链接到外部信息资源。GBrowse 还通过浏览器 Cookie 提供了会话管理功能，使得配置设置可以在不同会话之间持续（当然只要 Cookie 不被删除），并且浏览器可以从用户上一次浏览会话离开的地方继续运行。与 UCSC 基因组浏览器、Ensembl 基因组浏览器或 NCBI Map Viewer 不同，GBrowse 不取决于特定的基因组数据库；相反，该系统设计具有可移植性和扩展性。这允许将 GBrowse 部署为自定义基因组浏览器界面，用于模式生物和其他基因组数据库的注释。GBrowse 可以在数据库层、数据模型层和应用层进行修改。它是一个可下载的开源软件包（http://sourceforge.net/gmod/files），具有灵活的插件架构，允许开发者在不修改软件源代码的情况下添加新功能。这是通过插件 API 引入插件来实现的。GBrowse 带有许多标准插件，安装自定义插件只需将 Perl 模块（.pm 文件）复制到单独的目录，并设置 GBrowse 变量来指示所有插件所在的目录。插件使用的某些示例包括运行 BLAST、向许多不同格式导出和从许多不同格式导入、寻找寡核苷酸、设计引物以及创建限制性图谱。

## 9.3 独立式基因组注释浏览器

独立式基因组浏览器与基于 Web 的浏览器不同，它们并不一定与特定的基因组数据库绑定，而是大多数被构建为通用浏览器，可以下载并安装为本地计算机上的应用程序。这些应用程序对用户请求的响应比基于 Web 的浏览器更快，因为一旦所需的基因组注释数据存储在本地磁盘上，就不需要与中央服务器进行通信。此外，这些类型的浏览器通常提供编辑和保存基因组注释的功能。大多数此类浏览器是用 Java 语言编写的，因为这使得程序能够在大多数计算机平台上无需修改即可运行。通过 Java Start，用户可以在无需预先安装程序的情况下，从 Web 浏览器启动这些程序。

## 9.3.1 Bluejay: 基于 XML 的基因组可视化与数据集成

Bluejay 基因组浏览器 (Soh et al., 2008) 是为了应对日益增加的数据类型带来的挑战而开发的，它能够渲染以可扩展标记语言 (XML; www.w3.org/XML) 表示的基因组信息，并提供缩放矢量图形 (SVG; www.w3.org/TR/SVG) 输出 (Turinsky et al., 2004)，支持几乎的语义缩放和出版级图像输出。最近的发展重点是将表达谱分析和比较基因组学整合到浏览器中，以提供功能性见解，这在传统的单基因分析和注释结果显示中是不可能的。

Bluejay 是一种基因组查看器，可以将基因组注释与基因表达信息相结合。它还可以基于基因同源信息辅助基因组分析，并在视图中显示无限数量的基因。它允许生物学家不仅从基因组背景查看基因，还能看到其调控和进化（在基因表达数据的情况下）。Bluejay 提供了丰富的个性化功能，包括许多显示自定义功能和用于标记基因组内多个感兴趣位置的 GPS 式站点。Bluejay 还嵌入了 Seahawk 浏览器 (Gordon and Sens, 2007) 以支持 Moby 协议 (BioMoby Consortium et al., 2008)，使用户无需更改 Bluejay 代码即可无缝调用各种类型基因组数据的 Web 服务。Bluejay 提供了一套独特的自定义基因组浏览功能，目标是让生物学家能够关注、分析、比较和检索与其最感兴趣的基因组数据相关的信息。
