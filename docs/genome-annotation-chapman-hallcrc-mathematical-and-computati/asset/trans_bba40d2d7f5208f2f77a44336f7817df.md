* 病毒—棕色
* 细菌—绿色
* 古菌—黄色
* 真核生物（除以下者外）—粉色
* 真菌—橙色
* 植物—紫色
* 动物—红色

匹配用户输入的自由文本的 GO 术语。这允许在不熟悉 GO 中确切术语的情况下使用这些术语。这可以捕捉可能未通过纯文本标签描述或太泛而无法通过关键词捕捉的基因。例如，通过几个关键词捕获所有碳水化合物代谢基因是不可能的，但“碳水化合物代谢”术语可能分配给基因组中的许多基因。

第三种搜索方法是使用自动生成的基因 MAGPIE ID 或用户标签。这些自定义标签更具记忆点，并且可以在功能注释表中设置（图 8.4 中的“Seq Alias”）。

第四种搜索是 MAGPIE 特有的，根据基因的分类分布进行搜索。这种搜索允许用户找到所有谱系特有基因、通用基因或异源同基因。例如，在搜索人类病原体药物靶点候选时，可能排除与“Homo sapiens”、“human”或“9606”具有强相似性的基因。这些术语中的任何一个都会映射到分类过滤器。该过滤器通过维护 NCBI 分类索引及其到蛋白 ID 的映射得以实现。

第五类搜索是基于序列的。用户可能有来自另一个生物的基因的 DNA 或蛋白序列。序列搜索是寻找新基因组中相关基因的保证方法，无论功能注释结果如何。相反，第六种搜索通过指定与公共数据库的最小或最大相似性，可用于快速筛选新型（或已知）基因。最后，第七种搜索允许用户根据需要关注非常长或非常短的基因。

总之，MAGPIE 为基因组的结构和功能注释提供了所有关键功能，包括来自许多分析工具的数据综合，并具有查询结果的广泛设施。其他系统中对这些功能的实现将被视为针对相同任务采取的不同方法。

## 8.3 通用模型生物数据库

通用模型生物数据库 (GMOD; http://gmod.org) 是一个著名的社区驱动项目，旨在构建用于基因组信息存储、分析和显示的复用组件。在 GMOD 提供的大型软件工具集中，有一个名为 MAKER 的自动化系统（Cantarel 等，2008）。MAKER 可用于原生物和较小真菌基因项目的注释，创建供其他 GMOD 组件使用的基因组数据库。

### 8.3.1 分析管理

MAKER 与 MAGPIE 一样基于命令行，使用内部作业管理系统，用户可以查看其文本日志。数据也存储在平面文件中，除非项目中有超过 1000 条序列。在这种情况下，自定义数据存储包含结果。单机上的作业并行通过连续运行多次分析启动器或配置系统的消息传递接口 (MPI) 实现。
