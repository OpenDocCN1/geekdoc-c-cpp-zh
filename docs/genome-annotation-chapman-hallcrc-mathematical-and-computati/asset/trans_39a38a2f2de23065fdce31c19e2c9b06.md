

## 166 基因注释

比较模式中便于视觉化比较的关键特征是显示基于一致基因分类方案的连接共同基因的连线。例如，Bluejay 具有一个默认书签，连接到已使用 MAGPIE 系统注释的基因组数据，该系统使用 GO (http://www.geneontology.org) 作为主要的基因分类系统。GO 项目提供了一个受控词汇表，用于分层描述任何生物的基因和产物属性。因此，当加载这些基因组进行比较时，每个基因都会连接到在最详细分类水平上与其具有相同 GO 分类的最接近基因（在坐标上接近，而非功能上）。通过使用这一功能，用户可以快速确定所比较基因之间的相似程度，这取决于基因在基因组内的整体分布（即共线性）。需要注意的是，通过 GO 类别进行分类只是 Bluejay 用于基因连接的可能基因分类系统的示例之一。任何符合基因比较目的并能对定义的基因类别提供文本描述的基因分类系统，只要包含在包含基因组注释的 XML 文件中，就可以在不修改 Bluejay 的情况下使用。

在基因水平上对两个或多个相似基因组进行视觉比较比较通常是复杂的，因为由于基因组进化过程中的插入、删除、重复和易位，基因组通常位于基因组的不同部分。Bluejay 中可以自动对基因组进行对齐，以减少基因组位置差异对视觉比较的影响。这在 Bluejay 的比较模式中是可以实现的；所有的基因组显示都以第一个加载的基因组为参考进行缩放。因此，所有圆形基因组的长度都相同。对于圆形基因组，一种减少基因重排对比较影响的最佳对齐是通过最小化所有连接基因对的角度距离之和来定的。通过将外层序列旋转到相对于内部序列的最佳对齐位置，该功能允许用户直观地观察缘基因的最佳全局对齐。用户随后就可以看到两个基因组的功能相似性，并将纯位置差异的影响尽可能降至最低。

另一个辅助基因类别连接的功能是可以通过在连接距离上应用阈值来选择性地显示或隐藏基因之间的连接。对于线性形状基因组，阈值是第一个加载的基因组长度的百分比，而对于圆形基因组，它被设置为 360° 的百分比。通过尝试这个可调节的阈值，用户可以通过观察基因组位置上短于特定距离的连接数量，直观地感知所比较基因组的相似程度。图 9.8 显示了 Bluejay 中基因比较的示例，其中两个圆形细菌基因组显示在一起，相同 GO 分类的基因已连接，并应用了连接距离。

路点（waypoints）可用可以增强 Bluejay 的基因组比较功能。通常需要在特定的基因位置对齐多个基因组，以研究基因周围基因组区域的相似性。Bluejay 中的路点功能允许用户标记多个基因，在多个基因组中为路点赋予相同的名称，随后在相应的标记处对齐基因组，消除了在对齐前估计所需旋转量的需要。

图 9.8 Bluejay 中圆形表示的两个细菌基因组比较。比较*衣原体* (Chlamydia trachatis) 和*鼠嗜衣原体* (Chlamydia muridarum) 可以发现，根据基因本体 (GO) 分类，它们具有许多共同基因，如连接线所示。仅显示角距离小于最大可能距离 (360度) 2% 的连接。**(参见彩色插图。)**

![](img/7da802df4d7c0829a4a41adf9acaf30d_190_0.png)

图 9.9 Bluejay 中通过路点进行基因组对齐。在三个嗜热菌属 (Sulfolobus spp.) 基因组的相应位置设置路点“dpoll”。在选择“在路点处对齐”操作时，通过适当旋转两个离群基因，在 dpoll 基因处对齐基因组。这便于对三个物种的基因结构进行视觉比较。（参见彩色插图）。

如果没有这些 Bluejay 功能，用户将费力地尝试旋转基因组若干角度直到基因对齐。图 9.9 显示了通过路点对齐三个基因组的示例。这种路点的用法大大增加了 Bluejay 的实用性。基因组的视觉外观可以通过圆弧进行自定义以表示这种关系。缺乏图形界面使得学习多个位置的配置变得困难。像 Bluejay 一样，它使用层来表示关系。分布式注释系统更容易整合到数据处理流程中。其他基因组比较工具包括 MEDEA (www.broadinstitute.org/medea) 和 Artemis (Meyer et al., 2009)。
