Each waypoint contains the positional and other descriptive information (such as a potential function of the highlighted region) about that particular point. For example, the user can set a waypoint within a genome to highlight a specific gene or sequence feature, such as a transcriptional promoter or terminator. Figure 9.4 shows a typical use of waypoints, where the user sets two waypoints and then uses the second waypoint to quickly focus on the second region of interest, while he can use the first one to jump back to the first region of interest at any time. This allows the rapid and efficient editing of attributes of these two genomic regions. Setting a waypoint automatically enables a set of operations, such as focusing on it, cutting the genome at it, and aligning several genomes at all waypoints labeled with the identical name, in multiple genomes.

Bluejay also allows the user to view a genome at various levels of detail, from the complete genome to the nucleotide text level. In the view mode, the genome can be set not only on a whole genome but also on any individual base position that is part of the genome. This helps the user to explore a collection of bases, even those that might be separated from each other by a large number of bases. For example, in the "horizontal sequencing" view mode of Bluejay, a genome is displayed as an elongated string of base characters.

Bluejay is written in Java and can be run on any computer with a Java installation (version 1.5 or later). It is a free package downloadable from the Bluejay Web site (http://bluejay.ucgary.ca). There are three options for download: (1) full application (2) Java Web Start can be run from a Web browser with Java plugin without local installation; and (3) Java applet for testing purposes.

# 9.3.2 NCBI Genome Workbench

The NCBI Genome Workbench (www.ncbi.nlm.nih.gov/projects/gbench) is a customizable, integrated application for viewing and analyzing sequence data. It allows the users to organize and view data from publicly available NCBI sequence databases as well as their own sequence data, or a mixture of both. The Genome Workbench offers several different ways of sequencing data, including graphical sequence views, multiple alignment and cross-alignment views, phylogenetic tree views, dot matrix views, and tabular views.
