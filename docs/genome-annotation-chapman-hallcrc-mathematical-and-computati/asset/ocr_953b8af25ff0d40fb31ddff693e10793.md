# 166 ■ Genome Annotation

The key feature of the comparison mode that facilitates the visual comparison is the display of lines that link common genes based on a consistent gene classification scheme. For example, Bluejay has a default bookmark that links to the genome data already annotated using the MAGPIE system, which uses GO (http://www.geneontology.org) as the main gene classification system. The GO project provides a controlled vocabulary to hierarchically describe gene and product attributes in any organism. Thus, when these genomes are loaded for comparison, each gene is linked to the closest with the same GO classification (close in terms of coordinates, not function) at the most detailed classification level. Using this feature, the user can quickly determine the degree of similarity between the genes being compared, in terms of the overall distributions of genes within a genome (i.e., synteny). It is important to note that classification by GO categories is only one example of the possible gene classification systems that might be used in Bluejay for the linking of genes. Any sort of gene classification system that fits the purpose of gene comparison and provides a textual description of the defined gene categories can be used without any modifications to Bluejay, as long as it is included in the XML file that contains the genome annotation.

The visual comparison of two or more similar genomes at the gene level is often complicated, as groups of genes are often located in different parts of the genomes due to insertion, deletion, duplication, translocation during the genome evolution. Genomes can automatically be aligned in Bluejay to minimize the influence of genomic positional differences in the visual comparison. This is possible in the comparison mode of Bluejay; all genome displays are scaled with the first loaded genome as the reference. As a consequence, all circular genomes are of the same length. Thus, an optimal alignment that minimizes the influence of gene rearrangements on comparison is determined by minimizing the sum of the angular distances for all linked gene pairs in the case of circular genomes. By rotating the outer sequence to the best-aligned position with respect to the inner sequence, this feature allows the user to visualize the best global alignment of closely related genes. The user can then see the functional similarity of the two genomes, with the effect of purely positional differences minimized as much as possible.
