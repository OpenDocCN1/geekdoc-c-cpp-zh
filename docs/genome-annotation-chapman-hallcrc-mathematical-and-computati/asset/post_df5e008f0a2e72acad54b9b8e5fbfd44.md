## 6.2 VISUALIZATION OF SEQUENCING DATA

With the emergence of NGS, the primary DNA sequencing data analysis changed considerably. In the case of sequencing data generated by the Illumina Solexa Genome Analyzer (www.illumina.com) and the Applied Biosystems SoliD system (www.appliedbiosystems.com), there are only image data saved and no trace exists. Traditional read alignment viewers cannot be used to display these images, partly due to storage and display speed. Moreover, inspection of a single read trace is less significant for NGS, due to the typically highly redundant sequence coverage of NGS experiments, which means that a base in question can be compared to a large number of other bases at the same position in all of the aligned sequence reads.
