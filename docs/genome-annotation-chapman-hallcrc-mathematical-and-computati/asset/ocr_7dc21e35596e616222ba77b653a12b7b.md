# 7.5.2 Heuristic Methods

Pairwise alignment methods like BLAST are called “heuristic,” because they achieve a speedup in database search through assumptions about what the final alignments will look like. The bias is generally towards moderately well-conserved sequences without shifts and with gaps that do not greatly affect the overall alignment length. When searching for strong homologs, these assumptions are very reasonable, but because many shortcuts are there actually more parameters to BLAST than the canonical Smith–Waterman method. To make the least number of assumptions about what the matches will look like, the Smith-Waterman method searches through a lot more data, being an exhaustive method. Tweaking the parameters of the BLAST tools can increase their sensitivity. This naturally lestens the runtime of the searches.

Key parameters to BLAST for finding weak homologs are the word size, step size, gap score, and X drop-off score. The word size determines the exact match length that must be present to “anchor” the initial alignment. For DNA, the default minimum is 11 base pairs, while amino acid alignments are a “neighborhood score,” which defines how conservative amino acid substitutions should be tried in the anchors as well. The higher the neighborhood score, the more remote matches will be found. The step size parameter determines what fraction of possible anchors are examined.
