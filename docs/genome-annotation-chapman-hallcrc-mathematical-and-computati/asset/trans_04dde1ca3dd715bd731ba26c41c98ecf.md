除了包含基因组注释信息的 XML 文件外，Bluejay 还有其他数据源。这些额外的数据类型可以与基因组注释进行视觉化整合。在显示基因组时，使用 XLink 标准（www.w3.org/tr/xlink）帮助将基因组特征的可视化表示链接到基因组特定组件的外部额外数据源。例如，如果存在 MAGPI 基因注释页面，可以通过点击基因来启动它。事实上，描述基因组的用户创建的自定义 XML 文档可以包含指向任何 Web 页面的 XLinks。XLinks 在被注释的序列在内部表示为文档对象模型（DOM: www.w3.org/dom）树之前插入的。

在使用基因组查看器时，生物学家通常只感兴趣于可视化更大部分基因组中的一小部分。在大型基因组中进行导航以关注感兴趣的小区域，通常涉及多次滚动和缩放操作，直到所需部分以适当的比例比例显示在视图中。这需要用户在相应的查看环境中进行多次操作，以聚焦于目标部分。另一种方法是输入核苷酸位置作为数字，以将焦点集中在该位置上。在这种情况下，用户必须知道或记住目标区域在基因组中的位置。这不符合用户习惯，使得在基因组特定部分之间导航变成了一项枯燥的任务。

Bluejay 通过引入“路点”（waypoint）的概念，使基因组内部的导航变得显著方便，路点大致定义为标识 2D 或 3D 空间中某点的坐标。在定位系统（GPS）应用中，路点对应于地球表面感兴趣位置的坐标。同样，Bluejay 中的路点

Bluejay 用 Java 编写，可以在任何安装了 Java（版本 1.5 或更高版本）的计算机上运行。它是一个可以从 Bluejay 网站（http://bluejay.ucgary.ca）下载的免费软件包。有三种下载选项：（1) 完整应用程序；2) 可以在带有 Java 插件的网络浏览器中运行 Java Web Start，无需本地安装；以及 (3) 用于测试的 Java applet。

## 9.3.3 Integrated Genome Browser

集成基因组浏览器（IGB）（Nicol et al., 2009）是一种用于基因组数据交互可视化的独立应用程序，如基因组注释、微芯片设计和测序芯片数据。IGB 用 Java 语言编写，其当前机制使用 Java Web Start，无需用户显式下载和安装即可自动下载并运行软件（www.bioviz.org/igb）。IGB 在内存需求方面提供三种尺寸（1 GB、2 GB 和 5 GB），以便用户根据其内存容量和数据集选择合适的占用空间。如今，IGB 是一个开源系统，允许开发者将其（及其组件）整合到新的应用程序中，但其最初开发在很大程度上基于微芯片公司 Affymetrix, Inc.在那里被用于分析公司的测序芯片产品。IGB 为探索和分析大规模基因组数据提供了一个早期的定制环境。IGB 让用户可以将实验或计算分析结果与公共领域的基因组序列、注释和数据集一起查看。
