## 9.2.2 Ensembl 基因组浏览器

Ensembl 基因组浏览器 (Flicek et al., 2011) 是 Ensembl 项目的主要可视化工具，该项目为脊椎动物和其他真核生物基因组生成数据库。截至第 59 版本（2010年8月），Ensembl 数据库包含 56 种生物，其中大多数是脊椎动物。

Ensembl 浏览器的单个页面包含统计信息，包括已知的蛋白质编码基因、假基因、微RNA (miRNA) 基因、rRNA、小核 RNA (snRNA)、小分子 RNA (snoRNA) 以及其他 RNA 基因以及单核苷酸多态性 (SNPs)。Ensembl 中的 RNA 基因注释是通过利用其他生物中发现的部分 cDNA 或 EST 以及蛋白质编码基因实现的。非编码 RNA (ncRNA) 的确定是通过与 Wellcome Sanger 研究所的 RNA 家族数据库 (Rfam) 比对合作实现的（<www.sanger.ac.uk/Software/Rfam>）。除了 Ensembl 中释的各种 RNA 序列外，还专门投入资源存储有关调节区域和变异的信息。变异信息不仅限于 SNP，还包括插入和缺失。该系统的开发是为了存储在自然种群和实验室管理菌系中观察到的变异。

Ensembl 利用不同的计算方法来创建程序的各个方面。Ensembl 网站用 Perl 语言编写，这些代码可以安装在本地。编码是模块化且可扩展的，因此系统可以根据研究人员的需求进行定制。数据库使用 MySQL 关系型数据库设计。此外，一套全面的应用程序接口 (APIs) 作为底层数据库方案与更特定应用程序之间的中间层，其目标是通过提供对数据表的高效高层访问来封装数据库布局，并使应用程序与数据布局的变化隔离开。

Ensembl 基因组浏览器还使用嵌入 Web 的程序来促进基因组的可视化说明。在首页上，用户可以选择基因组，这将进入基因组注释数据的“入口点”，例如核型、位置、基因、转录本、变异、表型和调节。例如，核型入口点显示生物体的染色体，并带有有关基因的摘要信息。点击染色体图像为用户提供了链接到位置视图或染色体摘要的选项。图 9.2 显示了位置视图，包含染色体视图和染色体中选定区域的概述。程序还允许在位置字段中输入碱基对位置后跳转到基因组的特定区域。视图的宽度可以通过下拉菜单调整，顶部的下拉菜单允许用户调整各种数据集的显示。

Ensembl 基因组浏览器包含许多可以帮助研究人员的功能。主图形显示中可以显示多种信息，例如限制酶位点。此外，还可以向显示中添加遗传特征、重复序列和装饰。遗传特征包括操纵子、RNA干扰 (RNAi) EST 序列、来自其他数据库的质粒体和基因预测、EST 信息以及同源蛋白。重复序列可能包括末端重复 (LTRs)、RNA 重复、卫星重复、简单重复、串联重复、长散在核元件 (LINE) 和短散在核元件 (SINE) 重复以及 II 型转座子。最后，还可以添加装饰，如序列信息、密码子、起始和终止密码子以及比例尺、G+C 内容、基因图例或 SNP 图例。Ensembl 为用户提供了若干功能来定制程序。用户生成的单个数据集也可以使用并添加到 Ensembl 基因组浏览器中。数据上传可以直接实现到 Ensembl 服务器、到公共服务器并通过 URL 链接，或者通过设置分布式注释服务器 (Dowell et al., 2001; Jenkins et al., 2008)。

## 9.2.3 NCBI Map Viewer

![](img/7da802df4d7c0829a4a41adf9acaf30d_173_0.png)

图 9.2 Ensembl 基因组浏览器的区域概述。顶部部分（染色体视图）指示染色体内当前查看的区域，底部显示多个轨道中的基因组特征。中间的条形允许用户导航到其他区域或更改查看比例。（**参见彩色插图。****）

NCBI Map Viewer (Wolfsberg, 2011) 是一种基因组可视化工具，直接利用 NCBI 的数据和资源，包括 GenBank 和 PubMed。特别是，Map Viewer 为 Entrez Genomes (www.ncbi.nlm.nih.gov/sites/genome) 提供的部分生物提供了特殊的集成地图，该平台提供了 800 多个完整基因。NCBI 基因序列注释包含编码区域、保守域、变异数据、数据库交叉引用、参考文献和名称。这是通过合作与外部输入、自动注释、从 GenBank 传播以及工作人员策划的结合方法实现的。这些序列和注释代表 NCBI 参考 RefSeq (www.ncbi.nlm.nih.gov/refseq) 数据库中，该数据库与 Map Viewer、UniGene (www.ncbi.nlm.nih.gov/unigene)、HomoloGene (www.ncbi.nlm.nih.gov/homolog) 和 UniSTs (Sayers et al., 2009) 相关。除了 RefSeq 数据库外，Repbase (www.girinst.org/repbase) 包含一个真核 DNA 元素数据库，其中包含重复序列和基础信息。

NCBI 利用其专门的软件进行数据提交。RepbaseSubmit (Kohany et al., 2006) 是一个基于 Java 的接口，用于格式化和注释 Repbase 条目，可以消除许多格式错误。此外，Repbase 自动执行诸如序列长度和成分计算等操作，这进一步促进了 Repbase 的策划。该工具还具有预测序列中蛋白质编码区域、数据库搜索、在数据集中包含 PubMed 参考文献以及搜索 NCBI 数据库以正确包含物种特异性信息和分类位置的功能。为了进一步增强此程序，Censor (Kohany et al., 2006) 是一种可以通过与已知重复进行比较来快速识别重复元件的工具。
