### 10.4 TAVERNA

Taverna (Oinn 等人，2004) 是一种流行的工作流编辑和执行环境，专注于编排基于 Web 的资源，而不是 Galaxy 使用固定集合的能力。Taverna 的编程通过显式构建图形图完成的。生物信息学相关服务的注册维护在 BioCatalogue.org。

Taverna 工作流由四种组件类型组成：

- 工作流（Workflows）——这通常是一个列表，例如 Excel 表格或手动记录的值。- 处理器（Processors）——这些是转换数据的函数，例如运行 BLAST、BioMart 查询、BeanShell 脚本（Java 代码）、R 脚本或调用命令行工具。内置处理器显示为紫色，Web 服务为绿色。最近添加到 Taverna 的处理器类型是 REST API (Fielding 和 Taylor，2002)，可以通过调用精心设计的地址来检索数据。例如，特定的 Web 地址模板可以从 UniProt 获取一个格式化的数据库条目，只需将 UNIPROT 替换为真实的 UniProt ID（例如 P6843）。
- 数据链接（Data links）——这些是将数据从一个处理器的输出指向另一个处理器的输入的箭头。
- 工作流输出（Workflow outputs）——这些是用户感兴趣的结果。工作流每个的中间结果也可以列出，但需要更多操作才能访问。
