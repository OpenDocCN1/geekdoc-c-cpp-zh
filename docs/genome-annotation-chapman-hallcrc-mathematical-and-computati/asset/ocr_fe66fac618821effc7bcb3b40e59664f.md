Detecting and correcting these errors requires special knowledge, therefore the task is often necessary to manually edit and curate generated alignments. Many alignment visualization tools also offer this editing capability with sequence navigation and search help to help the user quickly locate the region of interest for detailed analysis and subsequent editing of the alignment.
