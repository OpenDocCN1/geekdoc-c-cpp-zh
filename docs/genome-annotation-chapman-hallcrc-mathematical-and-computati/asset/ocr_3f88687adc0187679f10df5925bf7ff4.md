# 10.6 CONCLUSION

Genome annotation tools tend to produce a fairly fixed set of analysis outputs. Depending on the research question at hand, the available data may be insufficient to properly answer the research question. The custom analysis of genomic scale data by nonprogrammers is becoming viable through the evolution of workflow and workflow-by-example tools. Web-based workflow tools can be used by anyone without requiring a large local informatics infrastructure, though local installation options are available for some tools. This can increase the efficiency (Taverna) and allow for the inclusion of additional tools (Galaxy) that might not be available in the publicly accessible versions of the tools. Workflows provide several advantages over manual analyses: efficiency, research communication, process documentation, reproducibility, keeping results up to date, and the potential reuse and modification of components for related tasks.
