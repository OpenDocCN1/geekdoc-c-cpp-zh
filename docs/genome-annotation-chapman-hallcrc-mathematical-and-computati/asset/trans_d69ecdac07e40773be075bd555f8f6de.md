## 6.5 基因表达数据可视化

高通量基因表达谱分析方法（如 DNA 微阵列）使得获取生物体表达的数百甚至数千个基因的快照成为可能。无论使用基因芯片还是高通量 DNA 测序作为测量方法，可视化技术对于分析和解释基因表达研究产生的海量数据已变得不可或缺。

## 基因组数据可视化技术与工具 ■ 97

基因表达谱分析的总目标是找到一组在某些条件下（例如在疾病模型中或对特定治疗的反应）过表达或低表达的基因。准确检测这些目标基因的困难在于需要同时分析的数据量极其巨大。单个数据集包含超过 10,000 个基因的谱图的情况并不罕见。在不同的实验条件或一段时间内的特定时间间隔下可能会生成相同的数据集，从而进一步增加了数据量。聚类分析和可视化是解决这一数据解释问题的两种关键方法。Quackenbush (2001) 中可以找到基因表达数据分析和可视化的综述。

### 6.5.1 表达数据可视化技术

基因表达研究通常产生多元数据，这需要高效利用二维空间来可视化结果。有很多可视化技术，其中三种在基因表达数据可视化中经常使用：热图、谱图（profile plots）和散点图。在这些方法中，热图生成是最常用的基因表达可视化方法，主要因为它从原始数据生成生成较为简单直接。聚类通常是应用于大多数基因表达数据的首次分析，旨在检测在多种实验条件下表现相似的基因组。Gehlenberg 等人 (2010) 提供了一份多元数据（包括基因表达数据）的可视化工具综合列表。

热图的创建首先定义一个颜色渐变来表示表达水平，随后为每个实验条件或每个时间点下的每个基因绘制一个小型网格。本质上，热图是一个网格矩阵，其中每行对应一个基因，每列对应一个实验观测值（无论是组织、疾病状态还是时间点）。因此，热图的大小会随着同时观察的基因数量增加而迅速增大。热图的行可以重新排序，以反映基因组之间的相似性，例如显示由于层次聚类而聚类在一起的基因。利用矩阵周围的空间添加关于基因名称和实验的注释也是非常简单的。尽管有这些优势，但热图并不是最直观的可视化方法，因为在进行任何观察解释时，网格颜色始终需要对应到调控方向（即上调或下调）和表达水平的大小，而且目前还没有公认的标准配色方案。

谱图（Profile plots）是在二维空间中可视化高维数据的一种常用方法。为了绘制 n 维数据点，会绘制 n 条垂直且等间距线。n 维空间中的一个点表示为折线，连接 n 条平行线上的 n 个顶点，其中顶点的位置对应于 n 个坐标。这种可视化方法使用户能够同时感知许多基因的表达趋势，因为平行线上的垂直位置可以很容易比较。这种方法有助于比较一组基因在不同实验条件（例如正常与疾病组织）或随时间推的表达水平。也可以快速找到在某些实验条件或时间点上调或下调的基因组。谱图最大的局限性是折线往往会严重重叠，产生视觉混乱，这可能使得难以同时可视化中等数量基因的表达水平。为了解决这个问题，可以采用配色方案来帮助区分图线。图 6.7 显示了在 TIGR MultiExpression Viewer (MeV) (Saeed et al., 2003) 中对基因聚类后生成的表达谱图。
