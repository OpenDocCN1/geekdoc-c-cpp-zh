Conditional type 2 filtering is based on the value of a particular member (x.member1) of the data object. This is accomplished by selecting from a document-specific drop-down list at the end of the search phrase (Figure 10.10a, bottom right). Any data member (x.member2) in a document can be selected for further processing, using the hyperlinks in the data display, unless they are gray-out by the filter and are therefore inaccessible.
