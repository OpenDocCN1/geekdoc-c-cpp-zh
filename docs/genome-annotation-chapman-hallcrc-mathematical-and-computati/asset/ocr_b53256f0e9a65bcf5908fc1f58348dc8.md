For a tree with a large number of nodes and many children per node, the nodes and edges to be displayed grow exponentially, requiring an enormous amount of space and causing severe visual clutter when is used. A more efficient use of space can be achieved by drawing trees in a hyperbolic space. This layout is suitable for visualizing a very large number of nodes.
