Specific computational methods for assigning OTUs taxonomy labels are varied, with the popular methods listed roughly from fastest to slowest:

+   - Bayesian classifiers trained on a reference set—The Ribosomal Database Project (RDP) (Wang et al., 2007).

+   - Alignment to reference 16S multiple sequence alignment—Greengenes (DeSantis et al., 2006) or Silva (Prusse et al., 2007) reference, using the ARB taxonomy software (Ludwig et al., 2004).

+   - Parsimonious tree insertion—Also available from ARB (Ludwig et al., 2004).

Reporting of the taxonomy to the user can be useful at different levels, depending on their interest: phylum, class, order, family, or genus. A caveat about such assignments is that different taxonomy databases exist within all of the aforementioned software, and therefore the resulting labels can differ, even when the same sequence data is used. Another caveat is that a growing proportion of the reference 16S RNA sequence data sets possesses (e.g., “uncultured Sulfolobales”), as metagenomic data sets are submitted to the public databases with very little annotation.

Although not accurate, a method applicable to both 16S RNA and whole-genome metagenomic taxonomy assignments is pairwise alignment (e.g., BLAST) to a reference database. Strong alignments can be analyzed for their taxonomic distribution, and a consensus label can be inferred. This method is used for example by the MEGAN software (Huson et al., 2007).

# 3.4.4 Assembly Quality

Whole metagenomic samples pose some additional challenges to genome annotation. In many cases, only genomic fragments can be assembled, ranging from single reads to fragments with a size of a few hundred base pairs. Coding sequence prediction should be done using tools that do not require training sets, since the different OTUs in the sample may not have the same coding sequence model; they belong to a large number of species, possibly belonging to different parts of the phylogenetic tree. Another option is to put the contigs into taxonomic “bins” in a manner akin to OTU assignment.
