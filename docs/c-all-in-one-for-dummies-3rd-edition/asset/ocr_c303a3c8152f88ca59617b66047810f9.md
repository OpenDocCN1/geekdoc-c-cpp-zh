Normally, we use the Next Line button by default and choose the Step Into button only when we specifically want to go into a function. The reason is that some lines of code that may not appear to be functions really are. For example, `cout << "a";` is, in fact, a function, and you might not want to step into that code, because either the source code for it might not be present or you simply might not be interested in the details of the function.
