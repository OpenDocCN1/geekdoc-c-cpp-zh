2. **Clear the Enabled option and click OK.**

Code::Blocks disables the breakpoint so that it no longer stops application execution.

Many debuggers show a disabled breakpoint using a hollow red circle (or sometimes an octagon). Code::Blocks turns the red octagon gray instead. However, you’ll still want to see that disabling the breakpoint actually does work. Set a new breakpoint at the line that reads `return NumberOfPieces;`. Click Debug/Continue and you’ll see that the debugger bypasses the first breakpoint and stops at the second, as shown in Figure 3-4.
