+   - Support multiple options.
+   - Anticipate what could go wrong.

But now, does the user have to press Enter afterward? This message suggests so. But maybe not. So you must be more specific. Maybe one of these examples would work better:

But even these aren't good enough. First, you should generally allow the user to press Enter. Doing something automatically with a single keystroke may surprise the user. Further, you may want to support multiple options. If the user wants to choose option A in the menu, you might support any of the following for input:

+   - A
+   - a
+   - Add
+   - ADD
+   - add
