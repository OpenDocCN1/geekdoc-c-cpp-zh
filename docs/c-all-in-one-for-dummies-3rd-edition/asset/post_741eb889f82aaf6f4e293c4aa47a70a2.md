## Using the auto keyword

The auto keyword is a new feature, added since C++11. What this keyword does is provide a shortcut method for defining the type of a variable, no matter what the variable may ultimately contain. Essentially, you use the auto keyword to save typing time — rather than type the full text of a lambda expression each time you need it, you simply type the name of the variable that contains the lambda expression.

![](img/6ba99460b0feb3585671a4612ff5fabb_622_2.png)

When you use the auto keyword, you’re asking the compiler to determine the type of a variable based on how that variable is used. This means that it must be possible to determine the type of the variable by examining the context in which it is used. When you use the auto keyword, these outcomes are possible:

- The compiler will determine the type automatically and assign it to the variable.
- The variable will receive a correct type, but not the type that you had originally envisioned (such as assigning a long where an int might serve better).
- Two or more types are possible, which means that the compiler will display an error message saying it can't figure out the ambiguous assignment.
- Determination of the variable type is impossible given the context and you must specifically assign a type to the variable.

The `auto` keyword is used in all sorts of situations and you see it pop up several times in the book. The `ReturnType03` example shown in Listing 7-5 demonstrates how you can use the `auto` keyword with lambda expressions to store the associated code and make it easier to access within the application.

### **Listing 7-5: Using the Auto Keyword to Automate the Return Type**

```cpp
#include <iostream>
#include <algorithm>
#include <vector>

using namespace std;

void ProcessVector(vector<int>& vect)
{
    vector<bool> Result;
    Result.resize(vect.size());

    auto Transformer = [](int x){return x > 3;};
    transform(vect.begin(), vect.end(), Result.begin(),
              Transformer);

    cout.setf(ios::boolalpha);
    auto DoPrint = [](bool x){cout << x << endl;};
    for_each(Result.begin(), Result.end(),
             DoPrint);
}

int main()
{
    vector<int> MyVector;
    MyVector.push_back(1);
    MyVector.push_back(2);
    MyVector.push_back(3);
    MyVector.push_back(4);

    ProcessVector(MyVector);
}
```

The overall effect of this application is the same as `ReturnType01` shown in Listing 7-3. The code uses a `transform()` to determine the truth value of whether a value in `vect` is greater than 3. The output is precisely the same as well. The big difference is that the lambda expression is placed within a variable that you can then use as needed. As a result, the `transform()` code is made simpler and easier to read (albeit not quite as short).

## Using the auto keyword with other types

The auto keyword can be used in any situation where you want to define the type of a variable. For example, you could use it in a for loop should you wish to do so, as shown in the AutoKeyword example:

```cpp
for (auto i = 0; i < 8; i++)
    cout << i << endl;
```

Depending on your compiler, when you view i in the debugger, you find that the compiler has made it an int — the same type you would have used when choosing the type manually. Of course, you probably won't use the auto keyword in this manner because typing int is actually shorter than typing auto. Even so, you can use auto anywhere the compiler can determine the type of a variable based on the variable's context. Even something as simple as the following code (also part of the AutoKeyword example) works just fine.

```cpp
auto Greeting = "Hello";
cout << Greeting << endl;
```

In this case, the compiler will create a const char * variable for you. However, there is a problem with this particular bit of code. If you were to assume that the compiler has created a string instead, you might write code like this:

```cpp
auto Greeting = "Hello";
cout << Greeting.length() << endl;
```

Making the wrong assumption means the code won’t compile. You receive an error message stating, error: request for member ‘length’ in ‘Greeting’, which is of non-class type ‘const char*’. To obtain the string that you need, you must specifically declare the variable as type string.

Sometimes you also get the wrong type in situations that aren’t quite so clear. For example, the following code should rely on a long long data type.

```cpp
auto LargeNumber = 15;
LargeNumber += 2147483647;
cout << LargeNumber << endl;
```

When you run the code and get an answer of -2147483634, which is clearly wrong. The problem here is that the compiler assumes you want an int variable. To obtain the long long variable you need, you must specifically declare the variable as type long long. When you run the example using a long long variable, you get the correct output of 2147483662.

## Developing Applications with Lambda Expressions

The previous section of the chapter acquaints you with the essentials of working with lambda expressions. There are a number of ways in which you can expand a lambda expression to meet specific needs. The following sections show how to use some of the more common methods.

### Creating lambda expressions with multiple inputs

Some lambda expressions require that you provide multiple inputs. The two most common examples are checks for equality and sorting algorithms. However, any instance where you must compare one value to another in order to create the desired output will usually require two inputs as a minimum. The MultiInput example in Listing 7-6 performs an equality check between the content of a vector and an array.

### **Listing 7-6: Providing Multiple Input Values**

```cpp
#include <iostream>
#include <algorithm>
#include <vector>

using namespace std;

void CompareRanges(vector<int>& vect, int values[])
{
    auto Result =
        equal(vect.begin(), vect.end(), values,
            [](int x, int y){return x==y;});

    cout.setf(ios::boolalpha);
    cout << "The values are equal: " << Result << endl;
}

int main()
{
    vector<int> MyVector;
    MyVector.push_back(1);
    MyVector.push_back(2);
    MyVector.push_back(3);
    MyVector.push_back(4);

    int MyInts[] = {1, 2, 3, 4};

    CompareRanges(MyVector, MyInts);
}
```

The example begins by creating the vector and array. It then calls CompareRanges() and supplies both items as input.

The CompareRanges() function relies on the equal() algorithm to determine whether the two objects contain the same values. The four inputs determine the beginning and ending of the vector comparison range, the list of values to compare it against, and a lambda expression to define the comparison method.

Notice that the lambda expression takes two parameters in this case, x and y, both of which are int values. The equal() algorithm acts somewhat like a for_each() algorithm in that it checks the values one at a time. The lambda expression must return a Boolean value that expresses whether the two inputs are equal. When you run this example, you see the following output.

```text
The values are equal: true
```
