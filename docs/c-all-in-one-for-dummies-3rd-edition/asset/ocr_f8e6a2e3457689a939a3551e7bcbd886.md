However, the easiest method to build the tools is to build them all at once. A special Jamfile_v2 file is located in the `\CodeBlocks\boost_1_55_0\tools` directory. You use it to create all the tools at once, using the following steps.

+   1. Open a command prompt or terminal window using the technique appropriate for your platform.
+   2. Type `CD \CodeBlocks\boost_1_55_0\tools` and press Enter.
+      The command processor takes you to the main tools directory.
+   3. (Optional) If you haven't already created a path to the CodeBlocks compiler at the command line or terminal, create one.
+      For example, when working with Windows, type `path = C:\CodeBlocks\MinGW\bin;%path%` and press Enter.
+   4. (Optional) If you haven't already created a path to Boost.Build at the command line or terminal, create one.
+      For example, when working with Windows, type `path=C:\Boost.Build\bin;%path%` and press Enter.
+   5. Type `b2 toolset=gcc` and press Enter.
+      Be patient; the build process will take several minutes. BoostBook content appears in the `\CodeBlocks\boost_1_55_0\dist\share\boostbook` directory. Release is the only utility that isn't actually built; it consists of a number of batch files that you find in the `\CodeBlocks\boost_1_55_0\tools\release` directory.
