# ### Opening the sample projects

You obtain the source code for this book from the publisher site described in the Introduction. After you download the .zip file containing the source, you simply extract it to your hard drive.

The source code for this book is divided into books, chapters within books, and examples within chapters. To open the first example found in Chapter 2 of this book, for example, start by locating the \CPP_AIO\BookI\Chapter02\FirstProject folder (or the equivalent on your platform). Within this folder is SayHello.cpp. The Code Blocks Project (.cbp) file extension contains everything that Code::Blocks needs to open the project and present it to you. When you get to this first project, you double-click SayHello.cbp and Code::Blocks automatically opens the project for you, as shown in Figure 1-8.
