
First, note that to create the instances of StoreMe, we used the braces notation. You can do that when you have no constructors. So the line

```
~~~cpp
StoreMe key1 = {10};
~~~
```

creates an instance of StoreMe and puts 10 in the Item member variable.

Also note that we commented out the single line

```
~~~cpp
// map<StoreMe&, StoreMe> pointers;
~~~
```

This is where we attempt to declare a map that holds references. But the line gets a compiler error. When you type this listing, you can try uncommenting the commented line and see the error message. We get several error messages as a result of this line, the main two errors are as follows:

```
~~~
error: conflicting declaration 'std::map<StoreMe, StoreMe> pointers'
error: 'pointers' has a previous declaration as 'std::map<StoreMe,
        StoreMe>* pointers'
~~~
```
