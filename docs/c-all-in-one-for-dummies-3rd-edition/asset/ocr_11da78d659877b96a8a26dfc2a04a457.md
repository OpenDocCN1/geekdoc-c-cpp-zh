When the great founder of the C++ language (Bjarne Stroustrup) created C++, he enhanced structures to the point that classes and structures are *identical*, with one exception. Members of a structure are public by default. Members of a class, however, are private by default.

That's nice. But why would you use a structure? Really, it doesn't matter. Most C++ programmers today never even touch a structure.

![](bbox=[0.081, 0.801, 0.162, 0.859])

However, some C++ programmers use a special convention concerning structures. If a class has only public member variables and no member functions, then make it a structure.
