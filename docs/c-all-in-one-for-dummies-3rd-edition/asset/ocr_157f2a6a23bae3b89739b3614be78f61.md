You can find a step-by-step slideshow that demonstrates how to attach to an existing process at http://www.dummies.com/extras/cplusplusa.io. In some cases, you attach to a process when debugging an application because you need to see how the application works without the debugger in place immediately. A lot of readers write to tell us that slideshows of this sort make their job a lot easier. Even though the slideshow relies on Windows, the process is similar for both Mac and Linux systems.
