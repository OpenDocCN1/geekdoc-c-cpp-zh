When you declare a type (using a `typedef` or an `enum`) inside a class, you do not need an instance of the class present to use the type. But you must fully qualify the name. Thus, you can set up a variable of type `Cheesecake::Flavor` and use it in your application without creating an instance of `Cheesecake`.

![](bbox=[0.145, 0.164, 0.245, 0.229])

Do you have types that you want used only within the class? Make them protected or private. That way you cannot use them outside the class.

Unlike what you can do with nested classes, you can make a type within a class private or protected. If you do so, you can use the type only within the member functions of the class. If you try to use the type outside the class (including setting a member variable, as in `yum.SelectedFlavor = Cheesecake::SquishyStrawberry;`), you get a compiler error.

![](bbox=[0.145, 0.264, 0.245, 0.33])

You can also put a `typedef` inside your class in the same way you'd put an `enum` inside the class, as in the following example:

```
```cpp
class SpongeCake
{
public:
    typedef int SpongeNumber;
    SpongeNumber weight;
    SpongeNumber diameter;
};

int main(int argc, char *argv[])
{
    SpongeCake::SpongeNumber myweight = 30;
    SpongeCake fluff;
    fluff.weight = myweight;
    return 0;
}
