Because `Exclude` appears within the square brackets, the lambda expression can use it to perform the comparison. When you run this example, you see the following output:

+   1. 1
+   2. 2
+   3. 4

![](bbox=[0.142, 0.254, 0.23, 0.326])

Notice that the value of 3 is excluded from the output because this is the value passed as part of the call to `ProcessVector()`. When you provide a different value, a different number is removed from the output. The main purpose of the capture clause is to provide a means of passing additional information to the lambda expression to aid in processing the data it receives.
