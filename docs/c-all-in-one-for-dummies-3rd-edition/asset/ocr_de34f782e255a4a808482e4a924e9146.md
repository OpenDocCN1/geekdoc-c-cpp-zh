line modifies the original integer by dereferencing the pointer. And just to make sure that the process worked, the next line prints the value of `NumberOfPotholes`. When you run the application, you see the following output:

```
6087
```

This is correct; it is the value that the application stored in the original variable by using the pointer variable.

You can also read the value of the original variable through the pointer. Take a look at the ReadPointer example, shown in Listing 7-3. This code accesses the value of NumberOfPotholes through the pointer variable, ptr. When the code gets the value, it saves it in another variable called SaveForLater.

# Listing 7-3: Accessing a Value through a Pointer

```
```cpp
#include <iostream>

using namespace std;

int main()
{
    int NumberOfPotholes;
    int *ptr = &NumberOfPotholes;
    int SaveForLater;
    *ptr = 6087;
    SaveForLater = *ptr;
    cout << SaveForLater << endl;
    *ptr = 7000;
    cout << *ptr << endl;
    cout << SaveForLater << endl;
    return 0;
}
```
```

When you run this application, you see the following output:

```
6087
7000
6087
```

Notice also in this listing that we changed the value through `ptr` again — this time, to 7000. When you run the application, you can see that the value did indeed change, but the value in `SaveForLater` remained the same. That’s because `SaveForLater` is a separate variable and is not connected to the other two. The other two, however, are connected to each other.
