
## Creating More Readable and Concise C++ Code

One of the advantages of using C++ is that you can create concise code that is easy to read. Because you can see more of the code in one glance, C++ is often easier to understand as well because you don't have to scroll the editor page to see the entire solution to a particular problem. However, there are some types of C++ problems that did require a rather verbose solution in earlier versions of C++. Starting with C++ 11, developers have a new technique for solving these problems in ways that bring C++ code back to its concise roots.

You can solve a number of C++ development problems using lambda expressions, but the typical problem is one of making the code more concise and easier to read. There is absolutely nothing wrong with the Problem example shown in Listing 7-1 — it works just fine as shown.

### Listing 7-1: Defining a Problem Solved by Lambda Expressions

```cpp
#include <iostream>
#include <algorithm>
#include <vector>

using namespace std;

class MyFunctor
{
public:
    void operator()(int x)
    {
        cout << x << endl;
    }
};

void ProcessVector(vector<int>& vect)
{
    MyFunctor Func;
    for_each(vect.begin(), vect.end(), Func);
}

int main()
{
    vector<int> MyVector;
    MyVector.push_back(1);
    MyVector.push_back(2);
    MyVector.push_back(3);
    MyVector.push_back(4);

    ProcessVector(MyVector);
}
```

In this case, the example creates a vector, MyVector, and populates it with data. It then calls ProcessVector() to perform a task with the data in the vector.

The call to ProcessVector() creates a functor — a special class of object that acts as if it's a function — named Func. This is an extremely useful kind of a class that you explore further in the “Functors” section of Book VI, Chapter 1. For now, all you need to know is that it's a special kind of a class that acts like a function.

The for_each() algorithm (demonstrated fully in the “Creating Improved Loops Using Foreach” section of Book VI, Chapter 5) is part of the standard library. It processes each element in vect, the vector passed to ProcessVector(), starting at the first element (defined by vect.begin()) and ending with the last element (defined by vect.end()) using Func.

When you look at MyFunctor, you see a definition for an operator that requires a single int input, x. All that the code does is output x to the console. So you see the following output from this example.

```
1
2
3
4
```

## Defining the Essential Lambda Expression

The intent of a lambda expression is to make code shorter and easier to read. It creates a new method for presenting code. However, it doesn't actually create a new C++ capability. What you're doing is using the same techniques, but in a different manner than before. The following sections help you create your first lambda expressions so that you get a better idea of precisely how they work.

### Defining the parts of a lambda expression

The example in the previous section is perfectly usable. However, the functor is only used one time in the example. This situation happens relatively often and it causes confusion for developers who need to work through the resulting code. A lambda expression makes it possible to incorporate the functor as part of the for_each() algorithm, as shown in the Solution example in Listing 7-2.

### Listing 7-2: Defining the Lambda Expression Solution

```cpp
#include <iostream>
#include <algorithm>
#include <vector>

using namespace std;

void ProcessVector(vector<int>& vect)
{
    for_each(vect.begin(), vect.end(), [](int x){cout << x << endl;});
}

int main()
{
    vector<int> MyVector;
    MyVector.push_back(1);
    MyVector.push_back(2);
    MyVector.push_back(3);
    MyVector.push_back(4);

    ProcessVector(MyVector);
}
```

As you can see, using the lambda version of the example is much shorter and easier to understand because you no longer require a separate class to process the data in the `for_each()` algorithm. A lambda expression always appears like this:

```cpp
[](int x){cout << x << endl;}
```

![](img/6ba99460b0feb3585671a4612ff5fabb_619_0.png)

That pair of square brackets (`[]`), followed by any input arguments in parentheses, always needs to be at the beginning of a lambda expression; the code you want to execute — set between a pair of curly braces (`{}`) — always takes up the rear. Like any function, a lambda expression can accept multiple input variables and provide a return value. The beginning square brackets are called the *capture clause* and you see it used later in the chapter. Lambda expressions can include other features — including the ones you see demonstrated in the “Developing with Lambda Expressions” section of the chapter — but every lambda expression includes the following three features:

- Capture clause in square brackets
- Argument list in parentheses
- Executable code in curly braces

### Relying on compiler detection of return type

Lambda expressions can process information and present it directly, or provide the information as part of a return type. Simple lambda expressions can return information without telling the compiler much about it because the compiler can automatically detect the return type. The `ReturnType01` example in Listing 7-3 demonstrates how you would implement a lambda expression that returns data that is automatically detected by the compiler.

### Listing 7-3: Using a Compiler Detected Return Type

```cpp
#include <iostream>
#include <algorithm>
#include <vector>

using namespace std;

void ProcessVector(vector<int>& vect)
{
    vector<bool> Result;
    Result.resize(vect.size());

    transform(vect.begin(), vect.end(), Result.begin(),
              [](int x) { return x > 3; });

    cout.setf(ios::boolalpha);
    for_each(Result.begin(), Result.end(),
             [](bool x) { cout << x << endl; });
}

int main()
{
    vector<int> MyVector;
    MyVector.push_back(1);
    MyVector.push_back(2);
    MyVector.push_back(3);
    MyVector.push_back(4);

    ProcessVector(MyVector);
}
```

As in the previous example, this example (and most of the examples that follow) creates a `vector<int>` named `MyVector`, fills it with information, and passes it to `ProcessVector()`. `ProcessVector()` receives the data as `vect` and processes it one element at a time.

`ProcessVector()` begins by creating a `vector<bool>` named `Result` to receive the results of the data processing. In this case, the processing occurs in a `transform()` function that receives the beginning and ending position of `vect`, along with the beginning position of `Result` and a lambda expression. In order for the `transform()` to work, the lambda expression must return a value that defines precisely how the transformation process works. In this case, the process is a simple comparison of the input value, `x`, with the number 3.

When the transform() is complete, Result contains a list of bool values that indicate whether the individual numbers in vect are greater than 3. To see these values as true or false text output, rather than numbers, you need to call cout.setf(ios::boolalpha). The code then uses a for_each() loop to display the individual values in Result. Here is the output you see when you run this example.

```
false
false
false
true
```

Given that the input values in vect are 1, 2, 3, and 4, it's true that the last element of vect, 4, is greater than the number 3. Using a transform() with a lambda expression, as shown here, is a great way to reduce the code required to perform various kinds of bulk comparisons (among other transformation-specific tasks).

### Using a specific return type

Sometimes a lambda expression is complex enough that the compiler can't figure out what return type to use. Often you see an error message during the compilation process when this occurs. Fortunately, it's easy to fix this problem by simply telling the compiler what sort of return type to expect. The ReturnType02 example shown in Listing 7-4 demonstrates how to perform this task.

### Listing 7-4: Using a Specific Return Type

```cpp
#include <iostream>
#include <algorithm>
#include <vector>

using namespace std;

void ProcessVector(vector<int>& vect)
{
    vector<bool> Result;
    Result.resize(vect.size());

    transform(vect.begin(), vect.end(), Result.begin(),
              [](int x)->bool{return x > 3;});

    cout.setf(ios::boolalpha);
    for_each(Result.begin(), Result.end(),
             [](bool x){cout << x << endl;});
}
```
