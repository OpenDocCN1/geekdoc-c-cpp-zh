# Listing 7-3: Using a Compiler Detected Return Type

```
```cpp
#include <iostream>
#include <algorithm>
#include <vector>

using namespace std;

void ProcessVector(vector<int>& vect)
{
    vector<bool> Result;
    Result.resize(vect.size());

    transform(vect.begin(), vect.end(), Result.begin(),
              [](int x) { return x > 3; });

    cout.setf(ios::boolalpha);
    for_each(Result.begin(), Result.end(),
             [](bool x) { cout << x << endl; });
}

int main()
{
    vector<int> MyVector;
    MyVector.push_back(1);
    MyVector.push_back(2);
    MyVector.push_back(3);
    MyVector.push_back(4);

    ProcessVector(MyVector);
}
```
```

As in the previous example, this example (and most of the examples that follow) creates a `vector<int>` named `MyVector`, fills it with information, and passes it to `ProcessVector()`. `ProcessVector()` receives the data as `vect` and processes it one element at a time.

`ProcessVector()` begins by creating a `vector<bool>` named `Result` to receive the results of the data processing. In this case, the processing occurs in a `transform()` function that receives the beginning and ending position of `vect`, along with the beginning position of `Result` and a lambda expression. In order for the `transform()` to work, the lambda expression must return a value that defines precisely how the transformation process works. In this case, the process is a simple comparison of the input value, `x`, with the number 3.
