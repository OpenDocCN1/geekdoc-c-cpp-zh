# ### Parameterizing classes with templates

UML includes a notation that you can use along with C++ templates. (We discuss templates in Book IV, Chapter 5.) In UML terms, a *template* is a *parameterized class*. If you think about how a template works in C++, you can see that this makes sense because a template takes several parameters that are used by the compiler to build the class.
