```
# ## Ordering the operations

If you want, you can play around with some more complicated problems. For example, you can try something like this:

```
```cpp
cout << 5 + 10 / 2 * 3 + 25 << endl;
```
```

What do you think the answer will be? The answer depends on computer rules for the *order* in which it performs math problems. These are called *orders of operation*. Multiplication and division take precedence over addition and subtraction. Therefore, the computer does all the multiplication and division first from left to right; then it does the addition and subtraction from left to right.
```
