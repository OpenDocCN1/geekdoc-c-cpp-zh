Look at the StandardSort() function first. When an application calls sort(), it places the resulting data in the same object that it received. At first, vect contains unsorted data. However, after the call to sort(), the data is sorted using a generic sorting method. Notice that you don't need a lambda expression to perform a generic sort.

The ProcessVector() function looks almost the same as StandardSort(). The difference is that this function relies on a lambda expression to perform a custom sort. Sorting is a process of comparing one value to another, so the lambda expression receives two inputs, S1 and S2. By knowing which value is greater, sort() can determine where to place the two values in the list.
