# ### Changing values

Sometimes you need to verify that the application works as intended by simulating changes that might occur in the code. In many cases, this means changing a value from its default to the value you want to test. Fortunately, the Watches window provides the means to perform this task. Follow these steps to see how you can change variable values. (We assume that you have already compiled the application with debug information.)

+   1. Set a breakpoint at the `i = i + SpecialMath(i);` line in `main()`.
+   2. Click Debug/Continue.
+   3. When the debugger stops at the breakpoint, choose Debug:Debugging Windows:Watches.
+      You see the Watches window, as shown in Figure 3-6.
+   4. Type `i` in the first column of the Watches window and press Enter.
+      You see the current value of i, which is 10.
+   5. Select the value, 10, in the second column of the Watches window, type 100, and click on the next line of the Watches window.
+      Code:Blocks changes the value of i to 100. The i variable entry used to be black, and now it has turned red because you changed the value.
