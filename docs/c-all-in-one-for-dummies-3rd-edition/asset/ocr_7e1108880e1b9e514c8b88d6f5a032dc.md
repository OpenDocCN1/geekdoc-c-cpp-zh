int CountAntelopes(int original)
{
    int result = original + 10;
    result = result - 2;
    cout << "Calculating " << result << endl;
    return result;
}

int main()
{
    int rabbits = 5;
    int antelopes = 5;
    rabbits = CountRabbits(rabbits);
    cout << "Rabbits now at " << rabbits << endl;
    antelopes = CountAntelopes(antelopes);
    cout << "Antelopes now at " << antelopes << endl;
    //system("PAUSE"); // add this for Windows
    return 0;
}

Now look closely at main() and follow it through, line by line. The first thing main() does is declare a couple of integers. Then main() calls the CountRabbits() function. The CountRabbits() function declares an integer and computes a few lines of calculations. Then the CountRabbits() function prints a message. Finally, it returns. Once back in main(), the application prints another message and then calls the CountAntelopes() function. This function also declares an integer, completes some calculations, prints a message, and then returns. Back in main(), the application prints another message, and, finally, the application finishes.

What we just gave you is a linear description of the entire process of this application. You can see these same steps by using a debugger. With a debugger, you see the computer moving line by line through your code. A debugger performs the first line of your application and then waits for you to tell it to perform the next line — then the next, and the next, and so on, until the end of the application.
