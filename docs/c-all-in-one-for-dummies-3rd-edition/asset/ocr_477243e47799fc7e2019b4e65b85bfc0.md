This edition of the book looks at some new features of C++, including dynamic arrays. You can find an example of how to use a dynamic array with a structure at http://www.dummies.com/extras/cplusplusia. Dynamic arrays make it possible to create extremely flexible data containers that rely on the heap to store information.
