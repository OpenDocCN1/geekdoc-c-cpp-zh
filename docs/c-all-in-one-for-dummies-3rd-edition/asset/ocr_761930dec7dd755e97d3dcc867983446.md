```cpp
#include <iostream>
#include <algorithm>
#include <vector>

using namespace std;

void ProcessVector(vector<int>& vect)
{
    for_each(vect.begin(), vect.end(), [](int x){cout << x << endl;});
}

int main()
{
    vector<int> MyVector;
    MyVector.push_back(1);
    MyVector.push_back(2);
    MyVector.push_back(3);
    MyVector.push_back(4);

    ProcessVector(MyVector);
}
```
```

As you can see, using the lambda version of the example is much shorter and easier to understand because you no longer require a separate class to process the data in the `for_each()` algorithm. A lambda expression always appears like this:

```
```cpp
[](int x){cout << x << endl;}
```
```

![](bbox=[0.145, 0.575, 0.225, 0.645])

That pair of square brackets (`[]`), followed by any input arguments in parenthesis, always needs to be at the beginning of a lambda expression; the code you want to execute — set between a pair of curly braces (`{}`) — always takes up the rear. Like any function, a lambda expression can accept multiple input variables and provide a return value. The beginning square brackets are called the *capture clause* and you see it used later in the chapter. Lambda expressions can include other features — including the ones you see demonstrated in the “Developing with Lambda Expressions” section of the chapter — but every lambda expression includes the following three features:

+   - Capture clause in square brackets
+   - Argument list in parenthesis
+   - Executable code in curly braces
