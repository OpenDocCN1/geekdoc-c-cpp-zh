Directing the Application Flow

```
```cpp
#include <iostream>

using namespace std;

int main()
{
    int x,y,z;

    for (x = 1; x <= 3; x++)
    {
        for (y = 1; y < 3; y++)
        {
            if (y == 2)
                break;
            for (z = 1; z < 3; z++)
            {
                cout << x << " " << y;
                cout << " " << z << endl;
            }
        }
    }

    return 0;
}
```
```

You can see that when y is 2, the for loop with the y in it breaks. But the outer loop continues to run with the next iteration.
