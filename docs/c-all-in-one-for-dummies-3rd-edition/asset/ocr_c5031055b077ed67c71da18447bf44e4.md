# ### Specifying that the lambda expression throws exceptions

An exception is an indicator of an unexpected occurrence within an application. The occurrence could be due to an error, such as someone sending a function an incorrect value. However, the occurrence could just as easily be due to a loss of a network connection or a full disk drive. The important consideration here is that the occurrence is unexpected — that the application couldn’t automatically check for the potential problem and proactively compensate for it.

The process of indicating the unexpected occurrence is called *throwing an exception*. Lambda expressions can throw any sort of exception required to indicate an error condition. However, there are methods of indicating the precise sort of exception that a lambda expression might throw. By indicating the kind of exception, you make it possible for the compiler to optimize the lambda expression and make it faster — more efficient.

![](bbox=[0.14, 0.605, 0.205, 0.655])

In some cases, a lambda expression never throws an exception. Perhaps the functionality it provides is quite simple and there literally isn’t anything that can go wrong in the sense of generating an exceptional condition. When this is the case, you add the `throw()` clause to the lambda expression as shown here.

```
```cpp
auto myLambda = []() throw() {return true;};
```
```

It’s far more likely that your lambda expression will throw a specific exception. For example, the input may be outside the range the lambda expression expects and there isn’t any good way to compensate for this condition. Even in this situation, telling the compiler specifically which exception the lambda expression will throw allows the compiler to better optimize the code — making it faster. The Exceptions example in Listing 7-9 shows just such a situation.
