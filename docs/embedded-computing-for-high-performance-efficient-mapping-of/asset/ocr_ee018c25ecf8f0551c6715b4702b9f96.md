# 2.3.2 FUSED MULTIPLY-ADD UNITS

Fused Multiply-Add (FMA) units perform fused operations such as multiply-add and multiply-subtract. The main idea is to provide a CPU instruction that can perform operations with three input operands and an output result. Fig. 2.12 shows an example of a FMA unit. In this example, we consider the support of instructions D = A*B + C and D = A*B - C.

```
D[3:0] = A[3:0] * B[3:0] + C[3:0];
D[3:0] = A[3:0] * B[3:0] - C[3:0];
```

It is also common for FMA units to support single, double precision floating-point and integer operations, and depending on the data types, to include a rounding stage following the last operation (single rounding step as opposed to two rounding steps) when not using fused operations.
