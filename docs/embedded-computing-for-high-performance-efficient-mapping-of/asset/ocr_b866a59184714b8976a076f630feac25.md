# Table 5.2 Loop transformations and illustrative examples

| Loop transformation | Original source code | Transformed code |
| :--- | :--- | :--- |
| Loop alignment | `for(i=1; i<=N; i++) {`<br>`  b[i]=a[i];`<br>`  d[i]=b[i-1];`<br>`  c[i]=a[i]+i;`<br>`}` | `d[1]=b[0];`<br>`for(i=2; i<=N; i++) {`<br>`  b[i-1]=a[i-1];`<br>`  d[i]=b[i-1];`<br>`  c[i-1]=a[i-1];`<br>`}`<br>`b[N]=a[N];`<br>`c[N]=a[N+1];` |
| Loop coalescing | `for(j=0; j<N; j++)`<br>`  for(i=0; i<N; i++)`<br>`    sum += A[i][j];` | `b[N]=a[N];`<br>`for(t=0; t<N*N; t++) {`<br>`  j = t/N;`<br>`  i = t%N;`<br>`  sum += A[i][j];`<br>`}` |
| Loop collapsing (a special form of loop coalescing) | `for(i=0; j<N; j++)`<br>`  for(i=0; i<N; i++)`<br>`    sum += A[i][j];` | `// p is a pointer to &A[0][0]`<br>`for(i=0; i<N*N; i++)`<br>`  sum += p[i];` |
| Loop flattening | `for(i=0; i<N; i++)`<br>`  ai = A[i];`<br>`  sum = 0;`<br>`  for(j=0; j<M; j++) {`<br>`    sum += B[j][ai];`<br>`  }`<br>`  A[i] = sum/A[i];` | `j=M;`<br>`i=1;`<br>`for(k=0; k<N*M; k++) {`<br>`  if(j==M) {`<br>`    i++;`<br>`    ai = A[i];`<br>`    sum = 0;`<br>`  }`<br>`  sum += B[j][ai];`<br>`  if(j==M-1) {`<br>`    A[i] = sum/A[i];`<br>`  }`<br>`  j++;`<br>`}` |
