# 1.9 EXAMPLES AND BENCHMARKS

While the computing industry uses commercial benchmarks such as the ones provided by EEMBC, there are, however, several benchmark repositories that can be used and have been adopted by many research groups. The most used benchmarks are MiBench [28], MediaBench [29], PolyBench, SNU-RT, HPEC Challenge Benchmark Suite [30], CHStone, UTDS, and SD-VBS [31]. All of them include the source code and input/output data.
