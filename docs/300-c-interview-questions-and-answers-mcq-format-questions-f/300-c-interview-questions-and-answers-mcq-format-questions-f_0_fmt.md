## `while` 和 `do-while` 循环在执行方面有什么区别？

选项 1：`while` 循环至少执行一次其代码块，而 `do-while` 循环可能完全不执行。

选项 2：`do-while` 循环在大多数编程语言中不是有效的循环结构。

选项 3：`while` 循环执行代码块的顺序与 `do-while` 循环相反。

选项 4：`do-while` 循环只能用于对数组进行迭代。

正确答案：1.0

解释：`while` 循环和 `do-while` 循环都用于代码块的重复执行，但它们的区别在于检查条件的时机。在 `while` 循环中，在执行循环体之前检查条件。如果初始条件为假，循环体可能完全不执行。在 `do-while` 循环中，在检查条件之前至少执行一次循环体。这保证了即使条件为假，代码块也会至少执行一次。

选项 2：缓冲 (Buffering)

选项 3：文件格式不匹配

选项 4：磁盘空间不足

正确答案：2.0

解释：`缓冲` 是 C 语言中写入文件数据延迟的常见原因。为了效率，系统可能会在数据写入磁盘之前进行缓冲。这种缓冲会导致数据在磁盘上可见出现延迟。
