# Nesting of for Loop

Nesting of for loop is used most frequently in many programming situations and one of the most important usage in displaying various patterns which we will see in the coming programs.

The syntax for nesting of for loop is given here :

```
for(initialization; condition; increment/decrement)
{
	for(initialization; condition; increment/decrement)
	{
		Statements;
	}
	Statements;
}
```

For each iteration of first for loop (outer for loop) inner for loop runs as it is part of the body of outer for loop. The inner for loop has its own set if statements which executes till the condition for inner for loop is true. See numbers of programs given below :
