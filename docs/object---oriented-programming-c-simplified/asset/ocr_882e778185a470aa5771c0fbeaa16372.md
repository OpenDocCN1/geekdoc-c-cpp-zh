# EXPLANATION :

The declaration void comp_sal (employee temp); tells the compiler that comp_sal is a function which takes an object of class employee type and returns nothing. The function compares the salary of two employee’s. In the main object e1 calls the function comp_sal and passes object e2 as argument. The object e2 is passed call by value and all data members of e2 is copied to object temp. In the function salary is compared and result is displayed.
