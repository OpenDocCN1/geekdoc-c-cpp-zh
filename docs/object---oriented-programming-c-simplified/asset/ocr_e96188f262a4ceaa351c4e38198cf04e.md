```
void show(char*s)
{
    cout << "Explicit function show\n";
    cout << "s=" << s << endl;
}
void main()
{
    show(12);
    show(34.78);
    show("Explicit");
}
```

# EXPLANATION :

When an explicit function is return with the same name as function template for specific data type, explicit function is called first instead of instantiating function template for that specific data type. Here we have function template show which has just one argument of generic data type. And we have a function show which takes a single argument of char* type. When show("Explicit") executes, function template is not instantiated but show(char*) function is called. For all other types of argument function template will be instantiated.
