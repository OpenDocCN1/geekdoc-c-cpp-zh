## 10.5 WORKING OF A VIRTUAL FUNCTION

We have seen how the function is called at run time depending upon the type of object stored in the base class pointer in case of virtual functions. Whatever we have learnt seems quite easy to understand, but how things happen internally is yet to be understood. Here, we will discuss how the actual function is called at run time.

Whenever a virtual function is created in a class, a VTABLE (virtual table) is created for that class and for all classes that inherit this class. Inside the VTABLE, addresses of all virtual functions are stored. If any derived class overrides the virtual functions defined in the base class, the address of the derived class function is written to the VTABLE of the derived class. If the derived class does not override the virtual function, then the address of the virtual function of the base class is put inside the VTABLE.

A special pointer called `vptr` (virtual pointer) points to the first entry of the VTABLE. When a function is called from a base class pointer, the compiler checks the contents of the pointer. The contents will be the address of the base or derived object. From this object address, the address of VPTR is obtained. Once the address of VPTR is known, the appropriate function can be called from VTABLE for that class.

But whatever I have given in the above is totally maintained by the compiler internally. You need not worry about how this is done internally. But you must know VPTR and VTABLE and how a virtual function is called.

```cpp
/*PROG 10.13 DEMO OF VIRTUAL FUNCTION VER 3*/

#include <iostream.h>
#include <conio.h>

class first
{
public:
    virtual void show()
    {
        cout << "Hello from show of first class" << endl;
    }

    virtual void display()
    {
        cout << "Hello from display of first class" << endl;
    }

    void fun()
    {
        cout << "Hello from fun of first" << endl;
    }
};

class second : public first
{
public:
    void show()
    {
        cout << "Hello from show of second class" << endl;
    }

    void fun()
    {
        cout << "Hello from fun of second class" << endl;
    }
};

class third : public first
{
public:
    void display()
    {
        cout << "Hello from display of third class" << endl;
    }

    void fun()
    {
        cout << "Hello from fun of third class" << endl;
    }
};

void main()
{
    clrscr();
    first *ptr;
    first f;
    second s;
    third t;

    ptr = &f;
    ptr->show();
    ptr->display();
    ptr->fun();

    ptr = &s;
    ptr->show();
    ptr->display();
    ptr->fun();

    ptr = &t;
    ptr->show();
    ptr->display();
    ptr->fun();

    getch();
}
```

### OUTPUT

```text

Hello from fun of first
Hello from show of second class

Hello from show of first class

Hello from fun of first
```

### EXPLANATION

The explanation is based on the basis of VPTR and VTABLE. The functions `show` and `display` are virtual in class `first`, and `fun` is not virtual. Class `second` only overrides `fun` and `show`. Class `third` overrides `display` and `fun`. The VTABLE for all three classes is as shown below. Note the addresses of different functions in the VTABLE. The VTABLE for class `first` needs no explanation. Class `second` overrides virtual function `show` but does not override `display`, so in the VTABLE for `second` class, the address of `show` of `second` class and the address of `display` of `first` class are put. Similarly, for the VTABLE of class `third`, the address of `show` of `first` class and the address of `display` of `third` class are put. For all three VTABLEs, a separate VPTR is present.

In the code shown above, when `ptr` contains the address of object `f`, the compiler, from the contents of `ptr`, finds out the address of VPTR of class `first`, and functions of class `first` are called.

![](img/ad5299318df8d4d7c6df5eaa86590ea3_497_0.png)

When `ptr` contains the address of object `s`, the compiler, from the contents of `ptr`, finds out the address of VPTR of class `second`, and functions from VTABLE of `second` get called.

![](img/ad5299318df8d4d7c6df5eaa86590ea3_498_0.png)

When `ptr` contains the address of object `t`, the compiler, from the contents of `ptr`, finds out the address of VPTR of class `third`, and functions from VTABLE of `third` get called.

![](img/ad5299318df8d4d7c6df5eaa86590ea3_498_1.png)

Note `fun` was not virtual in class `first`, so regardless of what the pointer `ptr` contains, `fun` of `first` will be called.
