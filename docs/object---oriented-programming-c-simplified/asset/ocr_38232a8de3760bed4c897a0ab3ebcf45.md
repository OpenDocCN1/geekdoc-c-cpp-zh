Than it does not mean both **A** and **B** are inherited in class **C** in **public** mode. The class **A** is inherited in **public** and class **B** in private which is the **default** mode. Again if you write.

```
class C : A,  B
{
};
```

Than both classes A and B are inherited to C in **private** mode.
