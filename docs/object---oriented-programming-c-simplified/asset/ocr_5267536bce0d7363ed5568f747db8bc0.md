# /*PROG 14.13 RE-THROWING AN EXCEPTION VER 1 */

```
#include <iostream.h>
void main()
{
    try
    {
        try
        {
            throw 20;
        }
        catch(int)
        {
            cout<<"Caught an exception inner catch\n";
            throw;
        }
    }
    catch(int x)
    {
        cout<<"caught an int exception x="<<x<<endl;
    }
}
```

# OUTPUT :

Caught an exception inner catch
caught an int exception x=20

# EXPLANATION :

When exception is thrown it is caught by the inner catch block. The statement thrown in the next lines causes’ exception to be re-thrown exception is passed to the outer catch block which is then executed.
