# EXPLANATION :

The factorial of number say 5 is calculated by multiplying 5*4*3*2*1 or by multiplying 1*2*3*4*5 which will be 120. The class Fact uses function getfact to find factorial of a number which is assigned to data member num through input function. The function getfact works as follows:

Initially f is 1. We run the loop from 1 to num, it may be from num to 1 also. In each iteration value of f is multiplied by i and stored back in f which is used in the next iteration. For better understanding lets take num = 4.

|  | i = | f = | => |
| S1 | 1 | 1 * 1 | 1 |
| S2 | 2 | 1 * 2 | 2 |
| S3 | 3 | 2 * 3 | 6 |
| S4 | 4 | 6 * 4 | 24 |
