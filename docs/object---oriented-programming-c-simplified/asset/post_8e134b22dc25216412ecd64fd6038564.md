## 13.3 CLASS TEMPLATE

Similar to a function template, we can create a class template. The difference is simply that earlier we created a template for a function; now we will be creating it for a class. The class templates are basically used for creating container classes, that is, classes which can contain varieties of objects of any type. For the class templates, the definition method remains the same but the instantiation changes.

Take an example:

```cpp
template<class T>
class demo
{
  T x, y;
  public :
  ............;
  ............;
};
```

The template class can be instantiated when an object of the class will be created. That is:

```cpp
demo<int> d1;
```

creates an instance of class template `demo` for integer data type. Similarly

```cpp
demo<float> d2;
```

will create an instance of class template `demo` for float data type. At this instance, there will be two different `demo` classes residing in memory. One will be using integer data members and the other float data members.
