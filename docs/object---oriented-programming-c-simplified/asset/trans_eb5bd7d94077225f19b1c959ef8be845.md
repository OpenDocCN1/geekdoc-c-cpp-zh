## 11.4 格式化输入/输出操作

在 C++ 中，用于格式化输入和输出的方法有三种：

+   1. 使用 ios 类定义的函数和标志。
+   2. 使用操纵符（内置）
+   3. 用户自定义的操纵符。

## 1. 使用 ios 类定义的函数和标志

## A. ios 函数与标志

ios 类提供了许多用于输入和输出的格式化函数。最常用的函数如下：

## (a) width（ ）函数

该函数用于设置宽度，*即*显示数值或字符串类型数据值时的字段大小。其语法如下：

```
int width (int);
```

它可以与 cout 对象一起使用，如下所示：

```
cout.width (5);
cout << 123;
```

![](img/ad5299318df8d4d7c6df5eaa86590ea3_544_0.png)

图 11.2 width 函数的实现

对于每个要打印的数据值，必须单独使用 width 函数。也就是说，对于下面的代码：

```
cout.width(5);
cout << 123;
cout << 45;
```

width 只对第一个 cout 语句生效，而不对第二个生效。要用宽度 5 打印第二个 cout 语句，我们必须编写：

```
cout.width(5);
cout << 123;
cout.width(5);
cout << 45;
```

## (b) precision 函数

该函数用于设置浮点数小数点后显示的数字位数。其语法如下：

```
int precision (int);
```

它可以这样使用：

```
cout.precision (3);
cout << 123.456789;
```

## (c) fill 函数

fill 函数用于填充由 width 函数设置的字段大小中的空白位置。其语法如下：

它可以这样使用：

```
cout.width (10);
cout.fill ('#');
```
