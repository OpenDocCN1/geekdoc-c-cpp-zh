

- `for` 语句中可以使用多个由逗号分隔的表达式。
- `while` 语句中只有一个表达式字段，该表达式用作指定的条件。
- `while` 语句后面不加分号。
- `while (1)` 语句可以创建 **无限循环**。
- `do-while` 语句将其表达式放在循环的 **底部**。
- `do-while` 语句后面必须加分号。
- 在嵌套循环中，**内层循环必须先完成，外层循环才会继续其迭代**。
