```
class stat_demo
{
    static int s;
    static float f;
    static char *str;
    static char ch;

    public :
    static void show()
    {
        cout << "s=" << s << endl;
        cout << "f=" << f << endl;
        cout << "str=" << str << endl;
        cout << "ch=" << ch << endl;
    }
};

int stat_demo ::s=20;
float stat_demo ::f=234.567;
char* stat_demo ::str="static";
char stat_demo ::ch='S';

void main()
{
    clrscr();
    stat_demo ::show();
    getch();
}

OUTPUT :
s=20
f=234.567001
str=static
ch=S
```

EXPLANATION : In the program there are 4 static variables : s of type int, f of type float, str of type char* and ch of type char. A static variable is declared inside the class but defined outside the class as explained earlier. In the program for example we initialized static int s as :
    int stat_demo :: s = 20
    Where int is the type of static variable, stat_demo is class and s is name of static variable, 20 is the initial value of the static variable s. These are displayed int eh static function show.
