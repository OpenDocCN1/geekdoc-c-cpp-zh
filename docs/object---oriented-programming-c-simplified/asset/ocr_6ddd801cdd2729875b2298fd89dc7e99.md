# 2.5 COUNTING TOKENS

+   1. int a,b,c;
+   
+   (i) int is a keyword (1)
+   (ii) a, b and c variables (3)
+   (iii) comma (,) is operator (2)
+   (iv) ; is delimiter (1)
+   
+   So, total number of tokens (1 + 3 + 2 + 1 = 7)

+   2. c = a + b - 10;
+   
+   (i) a, b and c variables (3)
+   (ii) +, =, - are operators (3)
+   (iii) ; is delimiter (1)
+   (iv) 10 is integer constant (1)
+   
+   So, total number of tokens (3 + 3 + 1 + 1 = 8)
