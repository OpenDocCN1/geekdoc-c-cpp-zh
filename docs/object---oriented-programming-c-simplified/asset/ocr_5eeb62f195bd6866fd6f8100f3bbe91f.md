EXPLANATION : Priority of unary – is higher than binary + so in the expression –d1 + d2, d1 calls operator - which return a temporary object A whose num is -100. Next this A object calls overloaded binary + operator function of class demo and send d2 as argument in the following manner : A.operato + (d2). In the operator + function sum of num of temp and d2 is calculated and assigned to num of temporary object A which is returned.
