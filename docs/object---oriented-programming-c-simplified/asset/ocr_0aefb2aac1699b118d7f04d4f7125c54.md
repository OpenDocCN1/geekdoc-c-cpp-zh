# EXPLANATION :

With the help of containership we can only use public data members/function of the class but not protected or private. In the first class we have returned the reference with the help of getnum function. In the default constructor of class second we assign value of 20 to num of first class by calling the function getnum. Then we show if we call to showf.

```
/* PROG 9.40 DEMO OF CONTAINERSHIP VER 3 */
#include <iostream.h>
#include <conio.h>

class first
{
private :
    int num;
public :
    void showf( )
    {
        cout<< "Hello from first"<<endl;
        cout<< "num="<<num<<endl;
    }
    int &getnum( )
    {
        return num;
    }
};

class second
{
    first f;
public :
    second( )
    {
        f.getnum()=200;
        f.showf( );
    }
};

void main( )
{
    clrscr( );
    second s;
    getch( );
}
```
