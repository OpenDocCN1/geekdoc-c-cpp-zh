# EXPLANATION :

The function peek() returns the next character without extracting it from the stream. In the program it is enclosed it is checked whether next input character is `$`. The function ignore extracts the number of characters n given as first argument (here 1) matching second argument character (here `$`). So whenever next input character in the stream is `$` it is ignored. The ignore function extracts the character and discard it. Here one `$` character and discard. Here one `$` character at a time is discarded.
