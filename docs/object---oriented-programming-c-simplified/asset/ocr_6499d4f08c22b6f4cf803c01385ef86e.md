# Object-Oriented Programming C++ Simplified

```
{
    genExp(x,y);
}
catch(char*E)
{
    cout << "Caught an Exception" << endl;
    cout << <E << endl;
}
cout << "Out of try catch block" << endl;
}
void genExp(int x, int y)
{
    bool m;
    m = x>y ?true :false;
    if(m = true)
        cout << "Subtraction =" << x-y << endl;
    else
        throw("Subtraction not possible");
}
```
