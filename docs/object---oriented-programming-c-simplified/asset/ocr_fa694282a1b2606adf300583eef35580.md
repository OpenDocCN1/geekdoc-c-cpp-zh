# Object-Oriented Programming C++ Simplified

```
y = x;
 x = x++;
```

If we write x = 20; y = ++x;

Then due to pre-increment first x will be incremented by 1 and the same incremented value will be assigned to y. y=++x is equivalent to the following two statement :

![](bbox=[0.15, 0.48, 0.85, 0.58])

> Note : There is only ++ operator which is used to increment the value of the operand by one. There is no such operator as +++ or ++++ which increment the value of 2 or 3.

```
/*PROG 3.14 DEMO OF ++ OPERATOR VER 3*/
#include<iostream.h>
void main()
{
int x,y;
x=10;
y= ++x;
cout<<"x="<<x<<"t"<<"y="<<y<<endl;
--x;
cout<<"x="<<x<<endl;
y--;
cout<<"y="<<y<<endl;
x=y++;
cout<<"x="<<x<<"t"<<"y="<<y<<endl;
y=--x;
cout<<"x="<<x<<"t"<<"y="<<y<<endl;
x=y++;
cout<<"x="<<x<<"t"<<"y="<<y<<endl;
}
```

OUTPUT :

```
x=11 y=11
x=10
y=10
```
