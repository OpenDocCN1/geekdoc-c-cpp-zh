```
#include <iostream.h>
void main()
{
	int line,row,col;
	cout << "Enter the number of lines" << endl;
	cin >> line;
	cout << "The pattern is" << endl;
	for(row=1;row<=line;row++)
	{
		for(col=1;col<=row;col++)
		{
			if(row%2==0)
				cout << !(col%2);
			else
				cout << (col%2);
			cout << "\n";
		}
	}
}
```

# EXPLANATION :

Observe the pattern carefully. On even number of lines we have a different pattern and on odd number of line we have a different pattern. On even number of lines i.e., for row=2, 4, 6,...... if we print the complement of col %2 we get the desired pattern. On row=1, 3, 5,...... we simply print the col%2.
