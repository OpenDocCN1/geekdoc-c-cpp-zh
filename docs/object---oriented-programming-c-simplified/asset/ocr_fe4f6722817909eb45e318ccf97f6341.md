# demo arr[5];

This creates an array of objects of size 5. The first object is referred by arr[0], second by arr[1] and so on. The data members of object arr[0] can be accessed as arr[0].dx and arr[0].dy. As we have just two data members dx and dy of int type inside the class, the size of any object of this demo class will be of 8 bytes. So, size of array will be 8*5=40. Each object will be places at a distance of 8 bytes in the memory as show :
