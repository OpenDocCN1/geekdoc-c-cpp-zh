EXPLANATION : The first character of line entered is scanned in ch using get method. It is checked whether entered character is \n or not. If it is not we display it on to the screen using put and scan the next character again. As soon as next character scanned in equal to '\n' the while loop terminates. Note the whole line is displayed when you press Enter. The entered data is stored in the input before displaying back to screen.
