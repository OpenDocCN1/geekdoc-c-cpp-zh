Its only unusual aspect is the cancellation of self-events on the receipt of a message. This step is required because OMNeT++ places all of its events into a single future event list, from which they are removed only when the event time expires or the event is explicitly deleted. A change in the next event time of the cart and controller invalidates its scheduled next event, and so it must be removed from the future event list and the new, valid time inserted.
