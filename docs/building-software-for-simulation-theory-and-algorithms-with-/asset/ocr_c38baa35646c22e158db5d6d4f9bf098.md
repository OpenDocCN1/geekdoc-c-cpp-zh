$$\delta : S \times X \to S$$

We could write Equation 3.8 without referring to time at all. Given the current state s and an input x the next state s' is

$$s' = \delta(s, x)\tag{3.9}$$

This function gives us a convenient way to define the total state transition by describing how the system responds to any single input. The total state transition function Δ is defined by recursive application of δ to the values in an input trajectory x[t0, tn). The trajectory is decomposed into segments x0, x1, ..., xn−1 of unit length such that

$$x[t_0, t_n) = x_0[t_0, t_1) \cdot x_1[t_1, t_2) \cdots x_{n-1}[t_{n-1}, t_n)$$

Using the semi-group property, we write

$$s_n = \Delta(\Delta(s_0, x_0), x_1 \cdot x_2 \cdots x_{n-1})$$
$$= \Delta(\delta(s_0, x_0(t_0)), x_1 \cdot x_2 \cdots x_{n-1})$$

Repeated application of this formula lets us compute s_n entirely by application of δ. This calculation, carried out in detail, is

$$\Delta(s_0, x) = \Delta(\Delta(s_0, x_0), x_1 \cdot x_2 \cdots x_{n-1})$$
$$= \Delta(\delta(s_0, x_0(t_0)), x_1 \cdot x_2 \cdots x_{n-1})$$
$$= \Delta(s_1, x_1 \cdot x_2 \cdots x_{n-1})$$
$$= \Delta(\Delta(s_1, x_1), x_2 \cdots x_{n-1})$$
$$= \Delta(\delta(s_1, x_1(t_1)), x_2 \cdots x_{n-1})$$
$$= \Delta(s_2, x_2 \cdots x_{n-1})$$
$$= \dots$$
$$= \Delta(\Delta(s_{n-2}, x_{n-2}), x_{n-1})$$
$$= \Delta(\delta(s_{n-2}, x_{n-2}(t_{n-2})), x_{n-1})$$
$$= \Delta(s_{n-1}, x_{n-1})$$
$$= \delta(s_{n-1}, x_{n-1}(t_{n-1}))$$
$$= s_n$$
