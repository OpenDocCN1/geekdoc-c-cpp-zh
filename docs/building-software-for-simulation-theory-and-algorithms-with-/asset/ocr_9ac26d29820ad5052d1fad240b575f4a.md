In this example, all of the code in the parallel block is protected by a lock, and so the threads don't do anything concurrently. The next example eliminates the shared thread_num variable and thereby exhibits real parallelism. Here, each thread obtains its thread ID from OpenMP and stores it in a local (i.e., not shared) variable. A global variable that is read-only holds the total count of threads. Each thread takes turns with cout to print its thread ID. The code is listed below.

# ### Using a Thread-Local Variable in an OpenMP Program

```
```cpp
#include <omp.h> // Include the OpenMP functions
#include <iostream>
using namespace std;

int main()
{
    // Store the number of threads used by OpenMP in a shared variable
    int max_threads = omp_get_max_threads();
    // Create a lock for controlling access to cout
    omp_lock_t lock;
    omp_init_lock(&lock);
    // Start a group of threads. Each will execute the block of code
    #pragma omp parallel
    {
        // Store the thread ID in a local variable. Every thread has its
        // own thread_num variable which is not shared
        int thread_num = omp_get_thread_num();
        omp_set_lock(&lock); // Acquire the lock
        // Print our message
        cout << "Hello from thread " << thread_num <<
            " of " << max_threads << endl;
        cout.flush();
        omp_unset_lock(&lock); // Release the lock
