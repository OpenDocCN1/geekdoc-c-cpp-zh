The *Simulator* class is the most complicated part of the simulation engine. It implements the basic simulation algorithm, implements the interface that makes this algorithm available to clients of the *Simulator*, and assists the *Atomic* model with cleaning up its garbage. The source code for the *Simulator* is listed below. This simulator implementation, an implementation for the *Bag* class, and the abstract *EventListener* and *Atomic* classes constitute a complete library of classes for simulating discrete-time, atomic models. These classes are defined in the file `dtss_atomic.h` that the simulator includes.
