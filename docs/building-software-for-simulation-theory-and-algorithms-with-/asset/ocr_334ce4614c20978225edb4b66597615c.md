```
Input: $x,q,h_{\max},\epsilon_{tol}$  
Output: $x',\tilde{e},e_1,\ldots,e_p$  

1. Tentatively advance $x$ to satisfy the error criteria  
2. $h \leftarrow h_{\max}$  
3. **repeat**  
4. $\quad k_1 \leftarrow h f(x,q),\ k_2 \leftarrow h f(x+\frac{1}{2}k_1,q)$  
5. $\quad x' \leftarrow x+k_2,\ e_k \leftarrow |k_2-k_1|$  
6. $\quad$ **if** $\epsilon_{tol} \leq e_k$ **then** $h \leftarrow 0.8\min\{h,h_{tol}/\epsilon\}$  
7. **until** $e_k \leq \epsilon_{tol}$  
8. Look for events in $[0,h]$  
9. **foreach** $k\in[1,p]$ **do** $g_k \leftarrow g_k(x,q),\ e_k \leftarrow |g_k|\leq\epsilon_{tol}$  
10. Found an event at the start of the interval  
11. **if** $(\exists k)(e_k=true)$ **then** $k\leftarrow0,\ x'\leftarrow x$, return  
12. **repeat**  
13. $\quad$ **foreach** $k\in[1,p]$ **do**  
14. $\qquad g'_k\leftarrow g_k(x',q),\ e_k\leftarrow |g'_k|\leq\epsilon_{tol}$  
15. $\qquad$ **if** $g'_k<0$ **then** $h\leftarrow\min\{h,g_k/(g_k-g'_k)\}$  
16. $\quad$ **end**  
17. $\quad k_1\leftarrow h f(x,q),\ k_2\leftarrow h f(x+\frac{1}{2}k_1,q)$  
18. $\quad x'\leftarrow x+k_2$  
19. **until** $(\forall k)(0<g'_k\lor e_k)$
```

# **Algorithm 5.1** Locate the internal event and tentatively advance $x$ to it.

Integration step $h_{\max}$ are fixed parameters. Let $F$ be a function that applies Algorithm 5.1 to the state; $F(x)$ is equal to $x$ except for $x'$, $\tilde e$, $h$ which the algorithm computes. Define also the function $I((x,q),\tau)=(x',q)$, where $x'$ is $x$ advanced by the step size $\tau$. The discrete-event model is

$$\delta_{int}(((x,q),x',\tilde e,h))=\begin{cases}F((\delta_{int}((x,q)),x',\tilde e,h)) & \text{if }(\exists e_k)(e_k=true)\\ F((x',q),\tilde e,h) & \text{otherwise}\end{cases}$$

$$\delta_{ext}(((x,q),x',\tilde e,h),e,u^b)=F((\delta_{ext}(I((x,q),e),e,u^b),x',\tilde e,h))$$

$$\delta_{con}(((x,q),x',\tilde e,h),u^b)=F((\delta_{con}((x',q),u^b),x',\tilde e,h))$$

$$\lambda(s)=\begin{cases}\tilde{\lambda}((x',q)) & \text{if }(\exists e_k)(e_k=true)\\ \phi & \text{otherwise}\end{cases}$$

To summarize, at each event the continuous variable $x$ is advanced to the present time. If there is an input or if an event threshold is reached, then the discrete transition function of the hybrid system is applied and, in the latter case, an output is also produced. The time advance at each event is the smaller of the integration step size and the time to the next internal event of the hybrid system.
