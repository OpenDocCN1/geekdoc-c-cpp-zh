We have just seen that the performance of a networked control system can be improved by adapting the network to the controller. In this particular case, there is an optimal selection of the MAC's retry limit. In a more complicated network there will be several parameters at each layer of a network protocol stack that can be tuned for performance. For example, the sizes of the send and receive buffers allocated by the operating system can affect queuing delays and packet losses.
