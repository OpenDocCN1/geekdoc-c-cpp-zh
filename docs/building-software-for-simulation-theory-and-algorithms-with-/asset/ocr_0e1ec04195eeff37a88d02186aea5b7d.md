**Algorithm 3.1**  Iterative procedure for computing the total state transition function of a discrete-time system.

This recursive procedure consumes the input trajectory one segment at a time. The state s1, resulting from the input x0(t0) applied to the state s0, is computed first. The state s2 is computed by δ(s1, x1(t1)). The state s3 is computed next by δ(s2, x2(t2)), and this is repeated until we reach sn. This definition of the total state transition function is tail-recursive, and so it can easily be rewritten as the iterative procedure in Algorithm 3.1.

The output function λ describes how the state of the system appears to an observer. It maps the current state s to an output y and has the form

λ : S → Y

The output trajectory y < t0, tn > produced by a state trajectory s < t0, tn > is defined by

y(tk) = λ(s(tk))                    (3.10)

for every tk ∈ < t0, tn >. To accommodate the output function in our simulation, only a small change to Algorithm 3.1 is needed; this gives us Algorithm 3.2.

In summary, the state transition function defines the internal response of the system to input; the output function projects a view of the internal state for an outside observer.
