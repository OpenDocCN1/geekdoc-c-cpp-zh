An interactive simulation of the vending machine described in Section 3.1.3 will illustrate how the simulator is used. The model is implemented by the CoffeeMachine class, which is derived from the Atomic class. The input-output for this model is an enumeration, and so the garbage collection method is not necessary. The state variables of the vending machine model are member variables of the CoffeeMachine class. The state transition function is implemented in the delta method and the output function, in the output_func method. The initial state of the model is set by the constructor.
