# 8. Statements

C# provides a variety of statements. Most of these statements will be familiar to developers who have programmed in C and C++.

+   statement:
+   - labeled-statement
+   - declaration-statement
+   - embedded-statement

+   embedded-statement:
+   - block
+   - empty-statement
+   - expression-statement
+   - selection-statement
+   - iteration-statement
+   - jump-statement
+   - try-statement
+   - checked-statement
+   - unchecked-statement
+   - lock-statement
+   - using-statement
+   - yield-statement
