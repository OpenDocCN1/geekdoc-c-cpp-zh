# XAML Code

As you review the .xaml file, notice Grid controls are used to place items on the page. The top layer Grid named LayoutRoot, has a StackPanel. The StackPanel is named TitlePanel and has a tag Grid.Row="0". Another Grid named ContentPanel is placed at Grid.Row="1". These are added by default when the Windows Phone App template is selected. A review of the file contents in Example 15-20 shows the value for the Text tags for the TextBlock objects on the StackPanel.

# EXAMPLE 15.20

```
```xml
<phone:PhoneApplicationPage
    <!--Tags at the top of the .xaml file and the comments relating to
        localization are not shown here due to space constraints.-->

    <!--LayoutRoot is the root grid where all page content is placed-->
    <Grid x:Name="LayoutRoot" Background="Transparent">
        <Grid.RowDefinitions>
            <RowDefinition Height="Auto"/>
            <RowDefinition Height="*"/>
        </Grid.RowDefinitions>

        <!--TitlePanel contains the name of the application and page title-->
        <StackPanel x:Name="TitlePanel" Grid.Row="0"
                    Margin="12,17,0,28">
            <TextBlock Text="Windows 8 App"
                       Style="{StaticResource PhoneTextNormalStyle}"
                       Margin="12,0,0,0"/>
            <TextBlock Text="Web Browser"
                       Margin="9,-7,0,0"
                       Style="{StaticResource PhoneTextTitle1Style}"/>
        </StackPanel>

        <!--ContentPanel - place additional content here-->
        <Grid x:Name="ContentPanel" Grid.Row="1"
              Margin="12,0,12,0">
            <TextBox x:Name="txtBxURL"
                     TextWrapping="Wrap" Text="http://"
                     Margin="0,0,0,75,530"/>
            <Button x:Name="btnGo" Content="Go"
                    Margin="364,10,0,0" HorizontalAlignment="Left"
                    Width="92" Click="btnGo_Click"/>
            <phone:WebBrowser x:Name="webWindow" Margin="10,82,0,0"
                              Height="515" Width="436"/>
        </Grid>
    </Grid>
</phone:PhoneApplicationPage>
```
