# Silverlight

Silverlight user interfaces are declared in Extensible Application Markup Language (XAML) and programmed using a subset of the .NET Framework. You will be able to use much of the same programming model you have used to develop applications. You still have access to the core methods and classes so that the business logic and data access layer can be used. A Silverlight application starts by invoking the Silverlight control from the HTML page, which then loads up a XAML file. The XAML file contains a Canvas object, which acts as a placeholder for other elements. XAML is a way of describing the user interface using XML. Like Web applications, you have fewer controls to drag and drop and fewer events to program. In the sections that follow, you will create a small application.

# Creating a Smart Device Application for Windows 7.x Phones

You have several options available to create Windows 7.x Phone applications with Visual Studio. They all require that the Windows 7.x Phone SDK be installed. Currently that download is available at http://msdn.microsoft.com/en-us/library/windowsphone/develop/ff402530(v=vs.92).aspx. If you have Visual Studio already loaded on your computer when you install the Windows Phone SDK, an Add-in for Visual Studio is installed instead of a new installation of Visual Studio Express for Windows Phone. The section that follows describes using Visual Studio Express for Windows Phone to create Windows 7.x Phone applications.

You will feel very comfortable when you launch the **Visual Studio Express for Windows Phone** Application. Although there are fewer controls, you still see the same type of user interface that you have been using. You create mobile apps much the same way that you create other types of applications. After selecting **File**, **New Project** and choosing **Visual C#** as the Project type, you will see **Silverlight for Windows Phone** as one of the categories of **Installed Templates**. Selecting this option reveals an option to create a **Windows Phone Application** project. You will name the Project as you have done with previous applications and then you will be asked to **select the Windows Phone Platform to target for the application**.
