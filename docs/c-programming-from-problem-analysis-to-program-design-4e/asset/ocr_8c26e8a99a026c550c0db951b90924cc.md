After using the **TOOLS**, **Options** and **TOOLS**, **Customize** menus, you will want to determine which windows you want open during design. As a minimum you should have available the **Solutions Explorer** and **Properties** windows. During Windows and Web development, the **Class View** window and **Toolbox** should be added. For applications involving data connections, the **Data Sources** and **Server Explorer** should be added. Spend some time customizing the work space to best meet your needs. You will find that it saves you much time during development and makes you more productive.
