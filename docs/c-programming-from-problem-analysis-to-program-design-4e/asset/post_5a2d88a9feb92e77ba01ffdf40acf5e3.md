**unary operator** — An operator that requires a single operand. Examples in C# are the ++ and -- operators that increment and decrement by one.

**Web Service Definition Language (WSDL)** — A language written in XML grammar that describes a Web service. It defines how an XML Web service behaves and details how client applications can interact with the service.

**Web services** — Applications that enable you to exchange data that may be in different formats from one computer to another over the Internet or an intranet.

**Web site** — See Web application.
