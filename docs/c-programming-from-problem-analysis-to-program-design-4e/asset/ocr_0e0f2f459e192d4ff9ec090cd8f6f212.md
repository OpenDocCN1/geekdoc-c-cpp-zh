# Working with Class Diagrams

Class diagrams document the structure of an application by showing data members and behaviors of a class. For multiple class applications, they also show the relationship between the classes. Right-clicking on the project in the **Solution Explorer** window reveals the **View Class Diagram** option. Figure B-9 illustrates the class diagram created for the PresentationGUI application created in Chapter 11.

![](bbox=[0.185, 0.253, 0.912, 0.652])

**FIGURE B-9** PresentationGUI class diagram

The application shown in Figure B-9 consists of three classes. The PresentationGUI class is related to the other classes because it instantiates objects of the Student class. No line connects the PresentationGUI and Student classes. A relationship line connects the Student and Person classes. These two classes are related through the Student class being derived from the Person class.
