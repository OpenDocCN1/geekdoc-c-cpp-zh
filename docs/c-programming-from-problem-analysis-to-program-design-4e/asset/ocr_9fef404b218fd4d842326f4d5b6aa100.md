When you select the Start icon on the toolbar in Visual Studio, you'll notice that you have options for four different emulators and an option labeled Device. You will want to make your selection from this list before launching your application. Documentation indicates the Emulator WVGA 512MB option emulates reduced memory for Windows Phone 7.x devices. Other options include Emulator 720P, Emulator WVGA, and Emulator WXGA. The difference between the emulator options is based on screen resolutions. You can test on each of the options to see how your app will look on phones with different resolutions. It takes a couple of minutes for the emulator to load. When it finishes you get a functioning phone. You can change phone settings on the emulator, move tiles around, resize them, and execute a number of apps. When you swipe from the right to the left, your application is listed as one of the apps available on the phone.
