# VARIABLES

Table 3-3 lists the data items needed for the JoggingDistance problem.

# TABLE 3-3 Variables for the JoggingDistance class

| Data item description | Type | Identifier |
|---|---|---|
| Number of strides during first minute | int | initialStrideCount |
| Number of strides during last minute | int | finalStrideCount |
| Jogging time | int | hrs, mins, totalMinutes |
| Average number of strides per minute | double | numberOfStepsPerMin |
| Total distance traveled | double | distanceTraveled |

# CONSTANTS

The stride (feet per step) is set as a constant value. The identifier and preset constant value will be STRIDE = 2.5.

The number of feet per mile is also set as a constant.

```
FEET_PER_MILE = 5280;
```
