# FIGURE 15-34 Adding controls to the smart device application

![](bbox=[0.18, 0.13, 0.9, 0.67])

Figure 15-34 shows the Properties Window with the TextBox, txtBxInput, control selected. A number of Properties were set. The Font Size was increased for txtBxInput and all controls. The Text property for the TextBlock labels were set. RadioButton objects do not have a Text property, instead the Content property was used to provide identifying information on the form. For the TextBox objects, Text was set to "". The controls that are used in the program statements were named using the Properties Window. Their names were added in the textbox at the top of the Properties Window. The circled item in Figure 15-34, reveals that the name given to the TextBox was txtBxInput.

An Image control was placed on the grid on the phone. The Source property was used to identify a .jpg image. The image was resized and moved. The final design is shown in Figure 15-35. As illustrated in that figure, you have great control over the canvas. You can zoom in/out as you work with controls placed on the form.
