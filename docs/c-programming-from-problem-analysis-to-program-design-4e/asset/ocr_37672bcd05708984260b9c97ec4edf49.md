# TABLE D-1 Operator precedence (continued)

| Category | Example operators |
|---|---|
| Logical OR | \| |
| Conditional AND | && |
| Conditional OR | \|\| |
| Conditional | ?: |
| Assignment | = *= /= %= += -= <<= >>= &= ^= |= |

Operators have equal precedence within the category. Thus, in the expression answer = aNumber + val1 * val2 / 7, the order of operations would be *, /, +, and =.
