# FIGURE 13-16 Values stored in a text file

Figure 13-16 shows the values entered during a single run of the application. If you want to modify the solution so that the next run of the application appends data onto the end of this current data in the text file, only one change is necessary. This change would be made in the FrmWaterDepth_Load() method. Add true as the second argument when you instantiate the StreamWriter() object. It would read:

```
fil = new StreamWriter("WaterData.txt", true);
```

The solution provided in the example did not include a second argument. Thus, by default, a new file is created each time. You get the same effect if you add false as the second argument. If the file exists and append is true, the data is appended or added onto the end to the file. If the file does not exit, a new file is created.
