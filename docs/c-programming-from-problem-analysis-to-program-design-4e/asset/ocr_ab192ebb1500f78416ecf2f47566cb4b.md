Because it is difficult to read a series of binary numbers, two shorthand versions were developed to make viewing the contents of memory locations easier. Base 16, the **hexadecimal numbering system**, works on powers of 16. Base 8, the **octal numbering system**, uses powers of eight. Both are used to express binary numbers more compactly. As with any other positional numbering system, the smallest symbol is 0, the total number of symbols is equal to the base, and our positional notation is used. Hexadecimal has 16 symbols (0-9, A-F).
