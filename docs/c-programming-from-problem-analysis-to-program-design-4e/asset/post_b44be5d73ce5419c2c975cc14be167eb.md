## Windows Phone 8 Apps

The SDK for Windows Phone 8 was released at the end of the year in 2012. Microsoft created a new user interface, featuring its design language called Metro. The user interface of the Zune devices served as the inspiration for the design. Flat colored “live tiles” were used. Like Windows Phone 7.x's SDK, the SDK for Windows Phone 8 provides you with all the tools you need to develop mobile applications. With the SDK, you can use your existing programming skills and code to build applications. Developers creating Windows Phone 7.x applications reported they often used Expression Blend software to enhance the user interface. This is no longer necessary. With Windows Phone 8 development, Visual Studio has integrated much of what you get from Expression Blend into Visual Studio requiring less switching back and forth between applications (Visual Studio and Expression Blend).

There are a number of new features incorporated into the Windows Phone 8 SDK. A number of new classes have been added including the `Wallet`, `MapsTasks`, `PersonalInformation`, and speech synthesis and recognition classes. One of the other big differences between the SDKs is that the core operating systems on all Windows Phones throughout Windows Phone 7 is Windows CE, targeting the .NET Compact Framework. Windows Phone 8 architecture is now based on the Windows NT kernel operating system and shares many components with the Windows 8 operating system. CoreCLR replaces the .NET Compact Framework.

There are several limitations for developing apps for Windows Phone 8, including the requirement that they can only be developed and run under the Windows 8 operating systems on 64-bit machines with 4 GB RAM and 8 GB of free disk space. However, applications are reported to run faster because apps are compiled to ARM code (ARM is the processor that runs on Windows Phone 8 devices) in the Windows Phone Store (cloud) before being downloaded and deployed to the user. Since code generation happens through Microsoft, the CPU is spared the task, resulting in faster loading of apps and less battery power used.

> **NOTE** The SDK download for Windows Phone 8 includes a stand-alone version of Visual Studio Express 2012 for Windows Phone, for developers on earlier versions of Visual Studio; for those with the latest version, it can be installed as an add-in to Visual Studio 2012 Professional, Premium, or Ultimate editions.
