Each separate tab can be clicked to display other options, as shown in Figure 10–21. You can place pictures, buttons, labels, or any control on each tabbed page. Add a TabControl object to the page by dragging the control from the Container section of the Toolbox onto your blank form. You can move the control to the upper-left corner of the form and use the size handles to stretch the control. You can cover the part of the form as shown in Figure 10–21 or all of the form, as is illustrated in Figure 10–22.
