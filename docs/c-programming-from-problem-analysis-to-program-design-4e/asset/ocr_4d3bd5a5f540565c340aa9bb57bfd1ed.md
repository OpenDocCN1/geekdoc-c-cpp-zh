# WEB PAGE

You will recall that two files are created for each page when you build Web applications using the ASP.NET Web Forms Site option. Selecting **FILE**, **New**, **Web Site**, **ASP.NET Web Forms Site** with the File System option selection enables you to specify where the Web site files should be stored on your local machine. The Source code file for the Default.aspx markup file is automatically opened when you first create a Web site as illustrated in Figure 15-5.

In Figure 15-5, notice the three buttons, **Design**, **Split**, and **Source**, shown on the bottom left corner of the figure. Initially the **Default.aspx** file for the **DynamicPage** site is shown in source code; the **Source** button is selected. If you look ahead at Figure 15-6, it illustrates what is shown when the **Design** button is selected for the **Default.aspx** file. Nothing has been added to the file. This is all autogenerated from Visual Studio.

This file (ending in .aspx), shown in Figure 15-5, holds the HTML tags. You can view and directly edit the HTML source code here. The tags automatically generated by Visual Studio are actually XHTML tags. They are referred to as HTML tags for the remainder of the chapter.
