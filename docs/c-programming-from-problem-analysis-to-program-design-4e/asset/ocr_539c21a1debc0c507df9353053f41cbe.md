# # Adding ComboBox Objects

When you place the ComboBox object on the form, it looks like a TextBox object. The top line of the control is left blank for the entry of typed text. The default setting for the property that determines the combo box’s appearance (the DropDownStyle property) is DropDown. If you accept the default setting, the user can either type a new entry into the object or select from the list of items that you assign to the control during design. Another DropDownStyle option, DropDownList, disables new text from being entered into the ComboBox object and offers additional navigational options for viewing the list.
