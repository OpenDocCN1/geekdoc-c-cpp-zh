# Master Pages

When you have more than one page associated with a Web site, you may want to consider beginning with a master page. You can lay out the design you want to see and indicate on the page where content will change from one page to the next. For example, on a master page you might place an HTML table for the layout and include an image element for a logo. You might also include special controls for page navigation for your site. The concept of a master page allows you to create and maintain a consistent theme across several pages for a Web site. As you look back at Figures 15-5 and 15-6, notice one of the nodes listed in the Solution Explorer window is Site.master; this is a master page. It is automatically created when you create a New Web Site in Visual Studio and select the ASP.NET Web Forms Site template. A master page ends with an extension of .master.
