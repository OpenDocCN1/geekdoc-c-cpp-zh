## 按引用传递

回顾一下，数组是引用变量。数组标识符的内存位置实际上并不包含这些值，而是包含一个地址，该地址指示数组中元素的位置。当你将数组传递给方法时，默认情况下传递的是对数组元素地址的引用。此特性的重要性在于：如果方法更改了一个或多个元素，则更改会作用于实际数据。因此，在被调用方法中对数组元素所做的任何更改，都会更改调用方法中创建的同一数组元素。
