> NOTE You will notice that no semicolon is placed at the end of method headings, such as Main( ). Nor do you place semicolons at the end of the class headings (e.g., public class SquareExample) or namespace headings. Semicolons are placed at the end of variable declarations, calls to methods, and assignment statements.

Some programmers refer to the heading for the method as the prototype for the method. The definition of the method includes the heading and the body of the method, which is enclosed in curly braces.

# Modifiers

Modifiers appear in the headings of methods. They also appear in the declaration heading for classes and class members, as shown in Figure 3-1. A modifier is added to a type or a type member's declaration to change or alter it or to indicate how it can be accessed. In Chapter 2, you learned about and used the const modifier. const is added to a declaration to indicate that a value is constant and cannot be changed. You have previously seen two other types of modifiers: static and access modifiers.
