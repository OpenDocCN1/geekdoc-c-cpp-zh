# MODIFYING CONNECTION STRINGS

If you have a problem connecting to a database, it might be necessary to modify the connection string and re-attach the database to your application. You can use several methods to change the connection string. You read earlier about changing the XML App.config file when the connection string is saved with the application. Another approach is to use the Settings page of the Property Designer to modify the project's settings. You access this page through the Solution Explorer window. The Settings.settings file is located inside the Properties folder. Double-clicking on the Settings.settings file opens the application's settings file. From there, you can click on the Value box and Browse to attach the database file. Figure 14-36 shows both the Settings.settings window and the App.config file.
