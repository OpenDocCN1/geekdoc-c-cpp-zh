**FIGURE 9-5**  Properties window

In Figure 9-5, some of the properties have an Expand button to the left of the property name, indicating that the property can be expanded (only one is currently expanded). Groups of properties are collapsed together for easier navigation through the property list. If you click the plus, the group expands. For example, clicking the plus symbol to the left of the Location property expands space where values can be typed for x and y. These values represent the x-coordinate and y-coordinate, respectively, for the location of the upper-left corner of the form.
