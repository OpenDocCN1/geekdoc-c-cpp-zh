# Implicitly Typed Local Variables

With Example 14-28, you will receive an error message, if you declare queryResult as a string data type or even a string array data type. The error message indicates that you cannot implicitly convert from an OrderedEnumerable <string> to a string argument. With Example 14-28, a generic reference was declared, IEnumerable <string>. Another option would be to declare an implicitly typed variable to hold the result. An implicitly typed local variable is strongly typed just as if you had declared the type yourself, but the compiler determines the type. The keyword var is used for this type of declaration. You read about the var data type in Chapter 11 var would replace IEnumerable<string>. This is illustrated in Example 14-29.

```
**EXAMPLE 14.29**

```csharp
var queryResult = from aName in nameArray
                  where aName.Length > 5
                  orderby aName descending
                  select aName;
```
```

Recall the keyword var indicates the type that will be determined from the expression on the right side of the equal symbol. Nothing else was changed in the program. The output from Example 14-29 is the same as from Example 14-28.
