# Using ILDASM to View the Assembly (Optional)

The DLL files cannot be modified or viewed as source code. Visual Studio includes a number of developer tools. One, the Intermediate Language Disassembler (ILDASM) tool, is useful for working with files ending in .dll or .exe. The tool is used to view an assembly. ILDASM can be run from the command line or added as an external tool to Visual Studio and run from within the IDE. The assembly shows the signatures of all methods, data fields, and properties. One of the ILDASM options is to display the source code as a comment in the assembly. Figure 11-14 shows the assembly for Student.dll generated using ILDASM.
