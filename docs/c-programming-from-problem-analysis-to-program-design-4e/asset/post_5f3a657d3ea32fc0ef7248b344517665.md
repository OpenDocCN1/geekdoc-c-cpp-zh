
## APPENDIX B CODE EDITOR TOOLS

![](img/36e48639a06772bcb0fa1ea2525b33a3_1138_0.png)

Neale Cousland / Shutterstock.com

You will write many types of program statements repeatedly. For example, you write while, do, for, if, switch, try...catch...finally, and foreach statements. Every time you use these statements, you type curly braces to show the beginning and end of the block, and you spend time formatting to make sure they are syntactically correct and consistently placed in your program. One of the more exciting Visual Studio features in the Code Editor automates their inclusion. This is done through using code snippets. Code snippets are discussed first in this appendix.

Another time-saving feature is refactoring. If you find that you want to take a segment of code and place it in a method, you can do so using a copy-and-paste approach, or you can use the refactoring tools to restructure your source code. The tools automatically promote local variables to parameters and convert blocks of code into a method. Both of these features are discussed in this appendix.

Class diagrams showing the data members, methods, and relationships between classes can be generated automatically with Visual Studio. You can add blank class diagrams and then add members to the structure or have Visual Studio create diagrams from existing code. This appendix also illustrates the use of class diagrams.

### Code Snippets

**Code snippets** are templates that you can use to insert code. They can help speed up the entry of common code constructs and make you more productive. When you insert a code snippet, a template is inserted into your program that enables you to fill in unique entries. You can use the built-in snippets or create your own. Snippets are stored as XML files that you can edit and customize. Snippets are grouped into the categories of **ASP.NET MVC 3, ASP.NET MVC 4, NetFX30, Office Development, Other, Test,** and **Visual C#**.

Code snippets are named with a short alias. You activate the snippet by either typing the alias and pressing the **Tab** key twice or by using the IntelliSense menu to insert the code snippet. Pressing **Ctrl+K+X** activates the code snippet list, as shown in Figure B-1. In order to see the list of available code snippets that you might want to incorporate into your application, select **Visual C#**.

![](img/36e48639a06772bcb0fa1ea2525b33a3_1139_0.png)

**FIGURE B-1** Code snippet list

When the list is displayed, selecting the name inserts a segment of code at the cursor position. The other option of typing the alias and pressing the **Tab** key twice was used to insert a decrementing `for` statement at the cursor position as shown in Figure B-2. The alias for the decrementing `for` is `forr`.

![](img/36e48639a06772bcb0fa1ea2525b33a3_1139_1.png)

**FIGURE B-2** Decrementing `for` statement code snippet

> **NOTE** Another shortcut for displaying the list of logical code elements that can be inserted in your program is to press **Ctrl+Spacebar**. This pops up a more exhaustive list.

The code snippet aliases are included in the list of available entries. Pressing the Tab key twice after selecting the `forr` alias inserts the code snippet text, as shown in Figure B-3.

```csharp
for (int i = length - 1; i >= 0; i--)
{
}
```

**FIGURE B-3** Code snippet inserted into text

Notice that the code snippet shown in Figure B-3 inserted the text at the cursor position and created an empty for loop. At this point, the editable fields in the code snippet are highlighted and the first editable field is selected automatically. The editable fields for the for statement are the initializer variable (`i` by default) and the Max length expression (`length` by default). You can type a new value for the field or press the Tab key to cycle through the editable fields. Clicking on a field places the cursor in the field, and double-clicking on a field selects it. You can change the fields to reflect the identifiers you use in your program.

Code snippets are simply XML files; you can easily create your own. The file ends with a `.snippet` filename extension. As you find yourself typing the same segment of code for multiple applications, you are encouraged to explore the MSDN documentation to learn more about creating your own shortcuts.

### Refactoring

Refactoring lets you improve on your code by modifying the internal structure without changing the logic or the external behavior of your program. Sometimes methods grow to include more than one major theme. Sometimes you can look at your code and see that a method is doing too much. The Extract Method option provides an easy way to create a new method from a segment of code.

#### Extract Method

The `Main()` method shown in Figure B-4 does both the calculation and displays the results.

```csharp
static void Main(string[] args)
{
    int scoreOne,
        scoreTwo,
        scoreThree;
    double average;

    scoreOne = InputValue("first");
    scoreTwo = InputValue("second");
    scoreThree = InputValue("third");

    average = (scoreOne + scoreTwo + scoreThree) / 3.0;

    Console.Clear();
    Console.WriteLine(" Grading App\n");
    Console.WriteLine("Score #1: {0}\n" +
                    "Score #2: {1}\n" +
                    "Score #3: {2}\n",
                    scoreOne, scoreTwo, scoreThree);
    Console.WriteLine("\nAverage: {0:f2}", average);
    Console.ReadKey();
}
```

**FIGURE B-4** Refactoring a method

Notice that the program statement on Line 22 takes the values entered and performs calculations with them. You can use the Extract Method from the Refactor menu to create a new method to calculate the average. Line 22 was selected prior to choosing the Extract Method from the Refactor menu option. Refactor is available if you right-click on a selection or from the EDIT menu. As shown in Figure B-5, a dialog box prompts you for a new method name.

![](img/36e48639a06772bcb0fa1ea2525b33a3_1142_0.png)

**FIGURE B-5** New method name for the extracted code

The dialog box previews the method signature. When the **OK** button is clicked, a new method is added to the program with a call matching the signature for the method. This is shown in Figure B-6.

![](img/36e48639a06772bcb0fa1ea2525b33a3_1142_1.png)

**FIGURE B-6** `CalculateAverage()` method refactored

The new method containing the selected code is created, and the selected code in the existing member is replaced with a call to the new method. As shown in Figure B-6, Lines 34 through 39 become the body for the new method. Line 22 contains the call to the method.

#### Rename

Another refactoring option is **Rename**. **Rename** is an operation that provides an easy way to change the name of identifiers for data types, local variables, namespaces, methods, and properties. To use this option, position the cursor on the identifier you want to rename and select **Rename** from the EDIT, Refactor menu. It changes the identifier throughout the program. You are prompted to enter a new name, as shown in Figure B-7.

![](img/36e48639a06772bcb0fa1ea2525b33a3_1143_0.png)

**FIGURE B-7** Changing the name for the identifier using Refactor

> **NOTE** An additional menu option of Rename overloads is displayed in the Rename dialog box when you select to rename an identifier that is overloaded.

In addition to changing the identifier in the program statements as illustrated in Figure B-7, you can also search for the identifier in comments and strings. You preview the changes prior to accepting them, as shown in Figure B-8.

![](img/36e48639a06772bcb0fa1ea2525b33a3_1144_0.png)

**FIGURE B-8** Previewing rename changes

As shown in Figure B-8, the proposed changes are shown in the top window. You deselect any changes you do not want made prior to selecting Apply.

#### Other Refactoring Options

The Refactor, Encapsulate Field option lets you create a property from a local variable and then update your code with references to the new property. There are also options to Extract Interface and Remove or Reorder Parameters. Refactoring lets you quickly reorganize your code for better reuse and readability. You are encouraged to explore the MSDN documentation to learn more about refactoring operations that can increase your productivity.
