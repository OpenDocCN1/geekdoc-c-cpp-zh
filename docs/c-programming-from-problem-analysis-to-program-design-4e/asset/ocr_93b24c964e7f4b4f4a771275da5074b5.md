# Two-Dimensional Arrays

Two-dimensional and other multidimensional arrays follow the same guidelines you learned about with one-dimensional arrays. One-dimensional arrays are useful for storing lists of data. Because the data is stored in contiguous memory locations, elements are referenced by an index representing the location relative to the beginning element of the array. Two-dimensional arrays, the most common multidimensional arrays, are used to store information that we normally represent in table form. Two kinds of two-dimensional arrays can be created using C#. Rectangular is the first type, and this type is supported by most languages. The second type is called a jagged or ragged array. Two-dimensional arrays are referenced much like you reference a matrix or table.
