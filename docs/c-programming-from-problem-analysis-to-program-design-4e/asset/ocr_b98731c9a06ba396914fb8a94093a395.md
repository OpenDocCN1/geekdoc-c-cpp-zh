As shown in Figure 15-19, an object of the Uri class is sent as an argument to the Navigate( ) method. URI stands for Universal Resource Identifier. The Uri class in C# represents URIs such as a Web address like "http://WindowsPhone.com". You can manage URI data directly with strings in C#. The Uri class provides a number of properties and an easy way to access parts of the URI. You can manipulate and combine URIs using the Uri class. In Example 15-19, an anonymous, unnamed, Uri object is instantiated by retrieving the string value entered in the txtBxURL textbox. Notice that value was stored in a string variable named site during the first program statement. The string site is the first argument to the constructor. The second argument to the Uri constructor is Absolute. UriKind can take one of three values: Relative, Absolute, or RelativeOrAbsolute. Here since a full URL address is typed into the textbox, Absolute was selected. Once a Uri object is available, it is sent to the webWindow WebBrowser object.

When you launch this app, no page is automatically loaded. Instead http:// appears in the textbox. This enables the user to complete the address for the site they want to visit.

> NOTE
> There is a Loaded( ) event that could be registered. If you wanted a specific Web page to be loaded automatically, you could register a Loaded( ) event and send as the first argument to the Navigate( ) method the address of the Web site you want loaded.

Want an image on your GUI? Put the picture in the Assets folder for your solution. Assets is one of the project folders that is automatically created for you. You'll see the folder displayed in the Solution Explorer window. An easy approach to make it available is to copy and paste it into the Assets folder. To put the picture into the Assets folder, you can use the standard Windows shortcuts for copy (Ctrl+C) and paste (Ctrl+V). Then drag and drop an Image control from the Toolbox onto the phone Designer pane. Move and resize the Image control using the standard Windows resizing handles. To link the Image control to the actual picture, use the Source property listed under the Common Category in the Properties window. A dropdown list shows the images available to the application. If your picture is stored in the Asset folder, you'll see it listed as one of the options under the Source property.
