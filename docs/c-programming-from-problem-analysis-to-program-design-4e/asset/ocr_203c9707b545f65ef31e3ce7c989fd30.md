# ANALYZE THE PROBLEM

You should review the problem specification in Figure 4-8 and make sure you understand the problem definition. Several values must be entered into the program. These values must be entered as string variables and then parsed into numeric fields, so that arithmetic can be performed.

Two separate classes are to be developed. Creating a separate class for the real estate object enables this class to be used by many different applications. One application is to produce a listing showing the cash flow from the investment. Other applications might include determining total investment dollar amounts or locations of investments.
