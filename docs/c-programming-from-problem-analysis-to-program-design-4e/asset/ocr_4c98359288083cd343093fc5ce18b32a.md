# Windows 8 Phone Apps

The SDK for Windows 8 Phone was released at the end of the year in 2012. Microsoft created a new user interface, featuring its design language called Metro. The user interface of the Zune devices served as the inspiration for the design. Flat colored “live tiles” were used. Like Windows 7.x’s SDK, the SDK for Windows 8 Phone provides you with all the tools you need to develop mobile applications. With the SDK, you can use your existing programming skills and code to build applications.
