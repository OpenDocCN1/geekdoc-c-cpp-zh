```csharp
DirectoryInfo dir = new DirectoryInfo(".");
Console.WriteLine("Current Directory: \n{0}\n",
                  Directory.GetCurrentDirectory());
Console.WriteLine("File Name".PadRight(52) +
                  "Size".PadRight(10) + "Creation Time");
foreach (FileInfo fil in dir.GetFiles("*.*"))
{
    string name = fil.Name;
    long size = fil.Length;
    DateTime creationTime = fil.CreationTime;
    Console.WriteLine("{0} {1,12:NO} {2,20:g}", name.PadRight(45),
                      size, creationTime);
}
```
```

After an object of the DirectoryInfo is instantiated in Example 13-2, the GetCurrentDirectory() method is invoked to display the current directory. The GetFiles() method of the FileInfo class is invoked to retrieve a collection of files in the current directory. The Name, Size or Length, and CreationTime properties of the FileInfo class are accessed for the display. The output for the revised example is shown in Figure 13-4.

As you review the code, you will notice that the PadRight() method of the string class was used to format the name of the file returned by the FileInfo Name property.

> > **NOTE**
> > PadRight() in Example 13-2 left aligned the file names and added spaces to the right filling up 45 character positions. The size or Length and CreationTime values were right aligned using the format specifiers. The positive integers (12 and 20) in the format specifiers indicates that the values should be right aligned.
