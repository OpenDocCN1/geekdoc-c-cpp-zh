# Code-Behind File

Up until this point no program statements have been typed in the `MainPage.xaml.cs` file. This is the code-behind file, the file that holds your code for the event-handler methods. You register events, like you saw previously, using the **Events** icon from the **Properties** window. Double-clicking on a control still registers the default event handler.

A Click event is registered for the **Go** button by double-clicking on the button. Doing so opens the `.xaml.cs` file and places a header for the `btnGo_Click()` event-handler method in the file. In this method, the user-supplied text is retrieved from the `txtBoxURL` textbox. That value is sent as an argument to the `Navigate()` method of the `WebBrowser` control. The `btnGo_Click()` event handler is shown in Example 15-19.

private void btnGo_Click(object sender, RoutedEventArgs e)
