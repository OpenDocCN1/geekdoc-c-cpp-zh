If you install Visual Studio 2012 on a Windows 8 machine, whenever you create a Windows Phone application, you are able to select which Windows Phone platform (Windows 8 or Windows 7.5) you want to target. Another option is to download the Windows Phone Software Development Kit (SDK). Microsoft provides an SDK for both platforms. The Windows Phone SDK is a complete development environment for creating Windows Phone applications. The download is free and when this book was written it was available online at http://dev.windowsphone.com/en-us/downloadsdk. In order to extend the 30-day trial period for the download, you have to register the product. There are no costs associated with the registration.

The SDK includes a phone-based design surface, a code editor, Windows Phone project templates, and a Toolbox that contains Windows Phone controls. The SDK enables you to debug your applications on a Windows Phone emulator or an actual Windows Phone device. With an emulator, you do not have to have a Windows Phone in order to create mobile applications targeting this platform. The emulator provides a virtualized environment so when the application is launched a functioning Windows Phone is displayed. Using the emulator you can design and test your application. During development you interact with emulator in the same way that you would interact with a phone device. Once this is installed, you can create mobile applications targeted to the Windows Phone Operating Systems.
