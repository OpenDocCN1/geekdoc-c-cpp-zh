```
private void radBtns_Checked(object sender, RoutedEventArgs e)
{
    if (rdbtnInches.IsChecked == true)
        txtBlkOutput.Text = "Result: "
            + (double.Parse(txtBxInput.Text) * 0.3937008).ToString("F2");
    else
        txtBlkOutput.Text = "Result: "
            + (double.Parse(txtBxInput.Text) * 2.54).ToString("F2");
}
```

The radBtns_Checked() event handler determines which radio button is selected, retrieves the input value from the TextBox objects, converts it to a double, multiplies the values, and then stores the result to the Text property of the txtBlkOutput TextBlock object.

No additional program statements, other than these lines added to the radBtns_Checked() event handler method, were written for the app. Everything else was done through making changes to the properties in the Properties window. Visual Studio autogenerated tags from these property values and placed them in the file ending with the .xaml extension. The tags for this app were added to the MainPage.xaml file.
