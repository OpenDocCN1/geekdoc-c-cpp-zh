In Example 6-12, the loop control variable is declared and initialized at the same time. This is often done with `for` loops when the variable is used only as a loop control variable. Be aware that if you do this, you cannot use the variable that is declared in the `for` statement outside of the `for` statement. The variable counter only exists in the `for` block. The scope of the variable declared in the `for` initializer is the initializer, test expression, increment/update portion, and is inside the loop body. Recall that **scope** refers to the region in the program in which you can use the variable.
