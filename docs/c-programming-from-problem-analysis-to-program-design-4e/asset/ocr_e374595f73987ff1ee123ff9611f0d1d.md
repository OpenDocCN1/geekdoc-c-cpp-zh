# SERVER CONTROL EVENTS

After you select a button from the **Standard** tab on the **Toolbox**, an object is instantiated of the `WebControls.Button` class. You get an object complete with object characteristics. You can register events such as a button click event for the object. Now when you double-click the **Submit** button, you do not get the function `OnClick()` code added to the .aspx markup file. Instead, double-clicking registers the button click event exactly as it was done when you created button click events for Windows applications. An empty button click event-handler method is added. This code is inserted into the code-behind (.aspx.cs) file. Now when the page is requested using HTTP, the Web server has access to all the controls that have `runat="server"` attributes and can retrieve and process the data entered by the user.
