There are a number of new features incorporated into the Windows 8 Phone SDK. A number of new classes have been added including the `Wallet`, `MapsTasks`, `PersonalInformation`, and speech synthesis and recognition classes. One of the other big differences between the SDKs is that the core operating systems on all Windows Phones throughout Windows Phone 7 is Windows CE, targeting the .NET Compact Framework. Windows 8 Phone architecture is now based on the Windows NT kernel operating system and shares many components with the Windows 8 operating system. CoreCLR replaces the .NET Compact Framework.

There are several limitations for developing apps for the Windows 8 Phone, including the requirement that they can only be developed and run under the Windows 8 operating systems on 64-bit machines with 4 GB RAM and 8 GB of free disk space. However, applications are reported to run faster because apps are compiled to ARM code (ARM is the processor that runs on Windows Phone 8 devices) in the Windows Phone Store (cloud) before being downloaded and deployed to the user. Since code generation happens through Microsoft, the CPU is spared the task, resulting in faster loading of apps and less battery power used.

> NOTE The SDK download for Windows 8 Phone includes a stand-alone version of Visual Studio Express 2012 for Windows Phone, for developers on earlier versions of Visual Studio; for those with the latest version, it can be installed as an add-in to Visual Studio 2012 Professional, Premium, or Ultimate editions.

# INSTALLING THE SDK

The first time you attempt to create a Windows Phone project using Visual Studio running Windows 8 OS, you will be prompted to Install Windows Phone SDK, as illustrated in the back image of Figure 15-39. You need to be connected to the Internet when you make this selection because you are directed to the Web site to download the Phone SDK. It downloads both the Windows Phone SDK 8.0, including emulator images and also tools for developing applications for Windows 7.x Phones.
