A second class is created for the user interface. This class allows the user to enter their name, number of dependents, and number of hours worked. Local variables must be declared to hold these values. The employee name can be entered as a single entry. Program statements should be written to separate the first name from last name. You almost always want to have last name separated from first name to facilitate alphabetically ordering records. After values are entered and calculations performed, an area on the form displays the results. Thus, objects that can be used to display gross and net pay along with calculated deductions are needed.
