# FIGURE 15-33 Windows phone application

A blank miniature form (PhoneApplicationPage) that looks like a phone is displayed. It includes a left arrow, the Windows logo, and a search tool at the bottom of the phone. A ContentGrid is placed on the form. As you review Figure 15-33, you will notice that there is a reduced number of options found in the Toolbox and Properties window.

Using the WYSIWYG approach, you can drag and drop controls to the form. To illustrate developing an application for a smart device, a metric calculator is designed. As shown in Figure 15-34, a TextBox, two RadioButtons, and several TextBlock objects are added to the form. The TextBlock object is similar to the Label found previously with Windows Form objects. In Design mode, you have an interactive canvas where you can drag and drop controls from the toolbox and set properties for existing controls on the designer surface. You can zoom in/out during your design using the slide bar beside the emulator. As shown in Figure 15-34, you have great control over sizing and moving the controls.
