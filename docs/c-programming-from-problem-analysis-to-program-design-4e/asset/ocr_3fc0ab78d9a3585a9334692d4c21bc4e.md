> > You can use the PC keyboard to enter text as opposed to the emulator by pressing the **PageDown** key on the PC. Use **PageUp/PageDown** keys to switch between the emulator software keyboard and your PC keyboard for text input.

Your app is automatically launched when you run the application. The emulator is started the first time you deploy it and remains running until you stop it. It maintains its own storage during that time. Pressing the **X** in the top-right corner beside the phone closes the application and terminates the emulator. If you want to just close the app and keep the emulator running, press the Back arrow (←) at the bottom left on the phone. Like a functioning Windows 8 Phone, if you want to relaunch it or open any of the other apps, you can select the app from the list of apps. Swiping from the right displays available apps.
