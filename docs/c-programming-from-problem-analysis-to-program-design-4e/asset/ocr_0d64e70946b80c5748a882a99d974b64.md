# XML

One of the great benefits of using Visual Studio for Windows Phone development is that you can drag and drop controls on the design surface, type property values using the properties windows, and also directly type XML statements into the .xaml file. When you initially create an application, the screen is split so that you not only have access to the Designer pane but also to the .xaml file containing the XML Application Markup Language tags. Each of the items on the screen of an application is a graphical rendering of an object so you will find tags relating to each element that you place on your design surface. These elements contain properties that define how it appears on the screen.
