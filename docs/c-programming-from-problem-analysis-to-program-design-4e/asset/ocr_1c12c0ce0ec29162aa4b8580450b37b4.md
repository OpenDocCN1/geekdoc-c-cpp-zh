# FIGURE 11-22 Setting the StartUp Project

The PresentationGUI is considered by many developers an example of a client application. It is considered a client because it is using the components that you created. Other client applications can make use of these same components. When you build the solution and run the application, Visual Studio copies the DLL from each of the references that were added into the application’s private subdirectory. If you explore the files that are created, you notice you have multiple copies of the DLLs. Actually, each project has its own copy of any referenced DLLs. Figure 11-23 shows the directory listing for the PresentationGUI folder. Notice that it contains copies of all of the .dlls and the PresentationGUI.exe. This makes up the PresentationGUI assembly.
