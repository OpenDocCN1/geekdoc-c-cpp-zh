# DATETIME CLASS

To work with the calendar for the WebControls application programmatically, an object of the DateTime class is instantiated.

The DateTime class has a large number of useful members that can be used with Calendar control objects. Table 15-3 shows some of the more interesting members of this class.

| Compare() - (static member) | Compares two instances of DateTime |
