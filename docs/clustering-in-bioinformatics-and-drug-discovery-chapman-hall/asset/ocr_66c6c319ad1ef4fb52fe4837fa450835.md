# ### 8.1.1 Tversky

The Tversky measure is very much like the Tanimoto measure. Using the conventions in Chapter 2, the Tversky can be stated as follows:

$$s = \frac{c}{\alpha a + \beta b + c}, \tag{8.1}$$

where α and β are continuous valued parameters. In order to get a value range in [0, 1], and to relate the Tversky directly to the Tanimoto, one can constrain α and β so that α = 2 − β. In this way, when α = β = 1, the Tversky becomes the Tanimoto. The asymmetry results from swapping α and β in generating the similarity between (i, j) and (j, i).
