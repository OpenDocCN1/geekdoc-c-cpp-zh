+   • **Dice**  
+     \(s=\sqrt{\frac{2c}{a+b+2c}}\) (2.16)

+   • **Rand**  
+     \(s=\sqrt{\frac{c+d}{a+b+c+d}}\) (2.17)

+   • **Forbes**  
+     \(s=\frac{c}{(c+b)(c+a)}\) (2.18)

+   • **Folkes/Mallows**  
+     \(s=\frac{c}{\sqrt{(c+a)(c+b)}}\) (2.19)

+   • **Fossum**  
+     \(s=\frac{n(c-1/2)^2}{(c+b)(c+a)}\) (2.20)

+   • **Simpson**  
+     \(s=\frac{c}{\min((c+b),(c+a))}\) (2.21)

+   • **Kulczynski-2**  
+     \(s=\frac{c}{n}\frac{2c+b+a}{(c+b)(c+a)}\) (2.22)

Common correlation measures, again loosely in order of their computational complexity, are:

+   • **Yule**  
+     \(r=\frac{cd-ba}{cd+ba}\) (2.23)

+   • **Dennis**  
+     \(r=\frac{cd-ba}{\sqrt{n(c+b)(c+a)}}\) (2.24)

+   • **Pearson**  
+     \(r=\frac{cd-ba}{\sqrt{(c+b)(c+a)(b+d)(a+d)}}\) (2.25)

+   • **Stiles**  
+     \(r=\log\left[\frac{n\left(|cd-ba|-\frac{n}{2}\right)^2}{(c+b)(c+a)(b+d)(a+d)}\right]\) (2.26)
