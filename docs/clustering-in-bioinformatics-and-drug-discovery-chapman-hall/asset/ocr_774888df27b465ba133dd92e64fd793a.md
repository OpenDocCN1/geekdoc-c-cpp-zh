$$\Sigma = \frac{(X-\bar{x})\bullet(X-\bar{x})^T}{n}$$

The numerator is the outer product of the data minus its means, divided by $n$, the number of data elements.

$$A^T\Sigma A = D$$

$D$ is the diagonal matrix of the eigenvalues. The columns of $A$ are their corresponding eigenvectors. The corresponding eigenvectors of the rank ordered eigenvalues are the principal components.

# ### 2.9.1.2  Singular Value Decomposition

Principal components can also be calculated using singular value decomposition.

$$X = UDV^T$$

$X$ is the data matrix. $U$ is the left singular vectors. $D$ is a diagonal singular value matrix. $V^T$ contains the right singular or the orthonormal eigenvectors. The PCA using SVD is utilized in the analysis of gene expression data [142].

# ### 2.9.2  Non-Negative Matrix Factorization

$$X = WH + R$$

$WH + R$ is the *Non-negative Factorization* of the data matrix $X$. It is related to PCA in that it forms a basis of vectors, and also very much like $K$-means clustering where $W$ contains the cluster centroids and $H$ contains the cluster membership vector. $W$ and $H$ are non-negative, but $R$ is a residual matrix which may contain negative values [34, 156].

# ### 2.9.3  Multidimensional Scaling

There are numerous forms of multidimensional scaling [16, 31], often used for visualization, but also on occasion, dimension reduction. *Classical Multidimensional Scaling* is using PCA on the data as above, where we want to use just a small number of the first principal components to project the data relationships into a small dimensional space. Equation 2.48 or Eq. 2.46 covariance eigenvalue/eigenvector methods can be utilized. Alternatively, a dissimilarity or distance matrix can be used in a non-linear fashion with numerous techniques to arrive at a projection into a small number of dimensions. Many of these forms of MDS are based on some form of force directed methods, much like spring embeddings for graph layouts, and are iterative in nature and typically find locally optimal solutions.
