# List of Symbols

+   - **Number**
+     - $N$ — The natural numbers
+     - $\mathbb{Z}$ — The integers
+     - $\mathbb{Q}$ — The rational numbers
+     - $\mathbb{R}$ — The real numbers
+     - $\mathbb{C}$ — The complex numbers

+   - **Algebra**
+     - $\pi$ — pi
+     - $e$ — The natural number
+     - $a,b,c$ — Scalar constants
+     - $x,y,z$ — Scalar variables
+     - $\sum_{i=1}^{N}$ — The sum
+     - $\prod_{i=1}^{N}$ — The product

+   - **Logarithms**
+     - $\lg$ — The logarithm base 2
+     - $\ln$ — The natural logarithm
+     - $\log_i$ — The logarithm base $i$

+   - **Number Theory**
+     - $li(x)$ — The integral logarithm
+     - $F_n$ — The prime sequence or order $n$

+   - **Statistics**
+     - $\sigma$ — The standard deviation
+     - $\sigma^2$ — The variance
+     - $\Sigma$ — The covariance matrix
+     - $\epsilon$ — The error

+   - **Probability**
+     - $P()$ — The probability
+     - $p()$ — The probability density function
+     - $\mathbb{E}[x]$ — The expectation
+     - $\operatorname{Var}[x]$ — The variance

+   - **Linear Algebra**
+     - $x$ — Vectors in bold face
+     - $A$ — Matrices in bold face
+     - $A^{-1}$ — Matrix inverse
+     - $A^\mathsf{T}$ — Matrix transpose
+     - $A \otimes A$ — Hadamard product: the element-wise product of two square matrices
+     - $\operatorname{tr}[A]$ — The sum of the diagonal elements of the matrix $A$, known as the trace of $A$

+   - **Set Theory**
+     - $\mathcal{A}$ — Sets
+     - $\mathcal{C}$ — Clusters
+     - $C_i$ — The $i$th cluster

+   - **Asymptotics**
+     - $\simeq$ — Approximately equal
+     - $O$ — Worst case upper bound
+     - $o$ — Limit bound
+     - $\Theta$ — Tight bound
+     - $\Omega$ — Lower bound
