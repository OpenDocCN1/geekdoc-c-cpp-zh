# APPENDIX D
# CHARACTER CODES

These escape sequences can occur in strings (for example, `"\\n"`) and characters (for example, `'\\0'`).

| Escape Sequence | Description |
|---|---|
| `\\n` | Newline |
| `\\r` | Carriage return |
| `\\t` | Tab |
| `\\v` | Vertical tab |
| `\\b` | Backspace |
| `\\f` | Form feed |
| `\\a` | Alert |
| `\\\\` | Backslash |
| `\\"` | Double quote |
| `\\'` | Single quote |
| `\\?` | Question mark |
| `\\xhh` | Code specified in hexadecimal |
| `\\ooo` | Code specified in octal |
