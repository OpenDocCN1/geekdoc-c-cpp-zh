| Table 2 for Loop Examples |  |  |
|---|---|---|
| **Loop** | **Values of i** | **Comment** |
| `for (i = 0; i <= 5; i++)` | `0 1 2 3 4 5` | Note that the loop is executed 6 times. (See Programming Tip 4.3 on page 147.) |
| `for (i = 5; i >= 0; i--)` | `5 4 3 2 1 0` | Use `i--` for decreasing values. |
| `for (i = 0; i < 9; i = i + 2)` | `0 2 4 6 8` | Use `i = i + 2` for a step size of 2. |
| `for (i = 0; i != 9; i = i + 2)` | `0 2 4 6 8 10 12 14 ...`<br>(infinite loop) | You can use `<` or `<=` instead of `!=` to avoid this problem. |
| `for (i = 1; i <= 20; i = i * 2)` | `1 2 4 8 16` | You can specify any rule for modifying `i`, such as doubling it in every step. |
| `for (i = 0; i < str.length(); i++)` | `0 1 2 ...` until the last valid index of the string `str` | In the loop body, use the expression `str.substr(i, 1)` to get a string containing the i th character. |
