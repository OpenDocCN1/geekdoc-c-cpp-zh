
- 数组元素可以像任何变量一样使用。
- 数组索引必须至少为零且小于数组的大小。
- 边界错误（当你提供无效的数组索引时发生）可能会损坏数据或导致程序终止。
- 对于部分填充的数组，保留一个伴随变量来记录当前大小。

### 能够使用常见的数组算法。

- 要复制数组，请使用循环将其元素复制到新数组。
- 分隔元素时，不要在第一个元素之前放置分隔符。
- 线性搜索按顺序检查元素，直到找到匹配项。
- 插入元素之前，将元素移到数组末尾，*从最后一个元素开始*。
- 交换两个元素时使用临时变量。

### 实现处理数组的函数。

- 将数组传递给函数时，还要传递数组的大小。
- 数组参数始终是引用参数。
- 函数的返回类型不能是数组。
- 当函数修改数组的大小时，需要告知其调用者。
- 向数组添加元素的函数需要知道其容量。

### 能够组合和调整算法以解决编程问题。

- 通过组合基本算法，你可以解决复杂的编程任务。
- 你应该熟悉基本算法的实现，以便能够调整它们。

### 通过操作物理对象来发现算法。

- 使用硬币、扑克牌或玩具的序列来可视化值数组。
- 你可以使用回形针作为位置标记或计数器。

### 将二维数组用于按行和列排列的数据。

- 使用二维数组存储表格数据。
- 二维数组中的单个元素通过使用两个下标 array[i][j] 访问。
- 二维数组参数必须具有固定的列数。

![](img/5e58fb4c840712efd6ed6fa82bb97f57_318_5.png)

### 使用向量管理大小可以改变的集合。

![](img/5e58fb4c840712efd6ed6fa82bb97f57_319_0.png)

- 向量存储大小可以改变的值序列。
- 使用 size 成员函数获取向量的当前大小。
- 使用 push_back 成员函数向向量添加更多元素。使用 pop_back 减小大小。
- 向量可以作为函数参数和返回值出现。
- 使用引用参数修改向量的内容。
- 函数可以返回向量。
