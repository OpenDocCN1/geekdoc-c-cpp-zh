**Figure 5**  The BMP File Format for 24-bit True Color Images

The image is stored as a sequence of pixel rows, starting with the pixels of the bottommost row of the image. Each pixel row contains a sequence of blue/green/red triplets. The end of the row is padded with additional bytes so that the number of bytes in the row is divisible by 4. (See Figure 5.) For example, if a row consisted of merely three pixels, one cyan, one red, and one medium gray, the row would be encoded as

```
255 255 0 0 255 128 128 128 x y z
```

where *x y z* are padding bytes to bring the row length up to 12, a multiple of 4. It is these little twists that make working with real-life file formats such a joyful experience.

The sample program at the end of this section reads every pixel of a BMP file and replaces it with its negative, turning white to black, gray to red, and so on. The result is a negative image of the kind that old-fashioned film cameras used to produce (see Figure 6).
