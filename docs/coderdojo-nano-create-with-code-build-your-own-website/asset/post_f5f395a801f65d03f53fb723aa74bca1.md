
## <ADD A STYLESHEET>

We're now going to change how the page looks. To do this we're going to create a **stylesheet**. A stylesheet tells you how the web page should look. Should the background be white or blue or green? Should the text be large or small? Should the links change color when you roll the mouse over them?

The stylesheet is the place where you keep all this information. The stylesheet is kept separate from the .html file so that you can change the web page's color scheme without having to change the HTML code of the page itself.

- 1. The stylesheet we'll be creating will be in a new file called **my-first-stylesheet.css**. Notice that the file extension of the stylesheet is **.css**, not **.html**. (Stylesheets in this book will be orange, so that you can tell the difference at a glance.) To keep things neat, we'll save our stylesheet in its own folder. We'll name this folder **css** and create it inside the **nanonauts** folder.
- 2. Type in the code from the orange box and save it as **my-first-stylesheet.css** in the **css** folder.
- 3. To link the stylesheet to the web page, you need to add an extra line into your HTML – it's highlighted in the code below.

![](img/52e45ce976f775dd17fd84d91912f770_9_0.png)

```css
body {
font-family: sans-serif;
}
```

- 4. What this line does is link the web page to the stylesheet called **my-first-stylesheet.css**.

This stylesheet is kept in the **css** folder. (That's what the line of code **css/my-first-stylesheet.css** refers to!) In other words, the stylesheet you've just created.

```html
<!DOCTYPE html>
<html>
<head>
<title>About Us</title>
<link type="text/css" rel="stylesheet"
href="css/my-first-stylesheet.css"/>
</head>
<body>
<h1>About Us</h1>
<p>We are the Nanonauts.</p>
<p>Our names are Holly, Dervla, Daniel, and Sam.</p>
</body>
</html>
```

To see the difference the stylesheet makes to the web page, you must reload the page. To reload the page, click on the Reload symbol in the toolbar.

![](img/52e45ce976f775dd17fd84d91912f770_9_1.png)

- 5. After it's reloaded, the page looks a little different. That's because the words are now displaying in a **sans-serif** font — that's what `font-family: sans-serif;` does in the stylesheet.

## WORDS TO REMEMBER

![](img/52e45ce976f775dd17fd84d91912f770_11_0.png)

- **Code editor** – a program that allows you to edit the HTML code for your web page. You don't have to use a special code editor – Notepad will do just fine – but code editors make it easier by color-coding the HTML markup and providing other helpful features.
- **Edit** – when you make changes to a web page, you edit it.
- **File** – whenever you save anything onto your computer or on the web, it's stored as a file. Files can contain any kind of information – they can be web pages, photos, songs, PDF documents, you name it. But programmers refer to all of these things as files.
- **File name** – files always have a file name. So the About Us web page has a file name: `about-us.html`. File names usually end with a period followed by three or four letters (such as `.jpg`, `.pdf`, `.html`). This is known as a **file extension** and it tells the computer what kind of file it is. For example, a file ending `.jpg` is an image file.
- **Folder** – when you save a file, it goes into a folder. A folder is a particular storage location on a computer. Folders can contain other folders. You refer to a folder by giving its **path**. For example, `C:/nanonauts/images` gives the path to the **images** folder inside the **nanonauts** folder on your computer's **C:** drive.
- **Tags** – are special markers used in HTML code. They use angle brackets and look like these examples: `<p>` `</p>` `<h1>` `</h1>` `<br />` You'll be seeing a lot more of them throughout this book!
- **Web browser** – Chrome, Firefox, Internet Explorer, Opera, Safari, and other applications that let you browse the web are called web browsers. To view a web page you need a web browser.

### ADDING A PHOTO TO THE PAGE

The About Us page tells everyone about the band. But wouldn't it be more interesting if it showed a photo as well? To show a photo you've got to tell the web browser where to find it. And to understand where to look, the web browser needs to know **1.** the name of the folder in which the photo is stored and **2.** the title name of the picture. Let's say you have a picture called `nanonauts.jpg`.

You can add the picture to the page by adding the following line of code:

```html
<p><img src="images/nanonauts.jpg" alt="Picture of the Nanonauts"/></p>
```

This is how the modified code looks:

```html
<!DOCTYPE html>
<html>
<head>
<title>About Us</title>
<link type="text/css" rel="stylesheet" href="css/my-first-stylesheet.css"/>
</head>
<body>
<h1>About Us</h1>
<p><img src="images/nanonauts.jpg" alt="Picture of the Nanonauts"/></p>
<p>We are the Nanonauts.</p>
<p>Our names are Holly, Dervla, Daniel, and Sam.</p>
</body>
</html>
```

![](img/52e45ce976f775dd17fd84d91912f770_12_0.png)

After saving the page and reloading it in the browser, it looks like this:

![](img/52e45ce976f775dd17fd84d91912f770_12_1.png)

Let's take a closer look at the code.

```html
<p><img src="images/nanonauts.jpg" alt="Picture of the Nanonauts" /></p>
```

The really important part here is `src="images/nanonauts.jpg"`.

This tells the web browser to look inside the **images** folder for a file named **nanonauts.jpg**. The web browser looks for the **images** folder in the same place that the web page is saved. So, if you look at the files in the **nanonauts** folder, as well as the **about-us.html** file, you'll see an **images** folder. And, if you open this folder, you'll see the **nanonauts.jpg** file.

![](img/52e45ce976f775dd17fd84d91912f770_13_0.png)

### NINJA TIP

If the **nanonauts.jpg** file were missing from the **images** folder, then the browser would show a symbol that indicates that. Something like this:

![](img/52e45ce976f775dd17fd84d91912f770_13_1.png)

The `src="images/nanonauts.jpg"` is an **attribute**. Attributes always follow the same pattern — an attribute name, followed by an equals sign, followed by an attribute value contained within a pair of straight quote marks. Like this:

| attribute name | equals sign | opening straight quote mark | attribute value | closing straight quote mark |
| --- | --- | --- | --- | --- |
| `src` | `=` | `"` | `images/nanonauts.jpg` | `"` |

The **alt** attribute, in the same way, contains text that appears if the picture cannot be shown. This is helpful if the web page is being translated into speech for blind people, for example.

Now that you know how to add a picture, add your own picture into your **about-us.html** page. To do this, copy the picture into the **images** folder and then add the code that will display your picture. So, if your picture came from a digital camera and was called **DSC03730.jpg** you might add the following code:

```html
<p><img src="images/DSC03730.jpg"
alt="Holly playing the guitar" /></p>
```
