# THE RESULT!

You can easily swap the position of the article and aside elements, so that the aside appears on the left. To do this just replace it with `float: right` in the query. Like this:

```
```css
@media all and (min-width: 900px) {
  article {
    float: right;
    width: 65%;
  }
  aside {
    float: right;
    padding-right: 24px;
    width: 34%;
  }
  footer {
    clear: both;
  }
}
