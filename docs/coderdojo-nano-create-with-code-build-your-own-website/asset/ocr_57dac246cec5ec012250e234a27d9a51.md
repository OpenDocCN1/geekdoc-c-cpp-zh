This theory is all very well – but how can you actually get the code of a particular color?

![](bbox=[0.711, 0.032, 0.958, 0.264])

There are two main ways:

+   - If you have an image-editing program such as the GNU Image Manipulation Program (GIMP), Adobe Photoshop, or Corel PaintShop Pro, you can use the color picker or color selector tool. This allows you to hover the cursor over a particular part of an image and get the hex value of the color. Or you can pop open a window and pick a color from a color palette or a color wheel.
+   - If you don't have an image-editing program you can use an online color picker.

Once you have the hex value of a color, you can use it in your stylesheet. For example, if C0C0FF is the code for the exact lavender blue color you want to use as a background color for your h1 main heading, simply add the following rule to your stylesheet:

```
h1 {
  background-color: #C0C0FF;
}
```
