# <ORGANIZING YOUR PAGES>

So far we've looked at HTML elements that are used to mark up our text – to organize it into headings, paragraphs, lists, and tables. But many web pages have lots of different topics on a single page: Let's imagine that the Nanonauts want to make their About Us page more interesting.

![](bbox=[0.667, 0.163, 0.933, 0.322])

They've decided that they want to have:

+   - a short feature about each Nanonaut
+   - an ad for their new CD
+   - an ad for a new Nanonauts T-shirt
+   - details of their next concert

They imagine the page layout might look something like this:

![](bbox=[0.057, 0.341, 0.556, 0.96])

To make it easier for the Nanonauts to organize their page, they can use HTML's structural elements. Structural elements allow you to divide up your page so that it's easy to see where one topic begins and another ends. Some of the most commonly used of these structural elements are **header**, **nav**, **article**, **section**, **aside**, and **footer**.

Using these elements makes it easier to organize your code and also helps to give you more control over how the page appears.
