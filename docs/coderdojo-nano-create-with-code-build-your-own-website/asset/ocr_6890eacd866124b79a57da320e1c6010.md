This is the list of things they want to do:

+   1. Add a header to the page containing the name of the band and the title of the page.
+   2. Add a section called Meet the Nanonauts that contains a short feature about each band member – with their photograph and a few personal details.

+   5. Add a footer to the page containing a copyright statement and a contact email address.

The code for the page is shown on the next few pages, with the structural elements within the body element bracketed in different colors (see the key at the top of page 69 for reference). We also used indentation to show the structure more clearly – more on this in a moment. Notice how the body element contains the nav element followed by a single article (“About Us”). The “Meet the Nanonauts” article is split into four sections (“Daniel – Singer extraordinaire,” “Sam – One-man rhythm section,” “Holly – if it’s got strings, she’ll play it,” and “Dervla – Keyboard maestro”).

Notice that we haven’t given the images a width. Instead we’ve given each image a class – small, medium, or large – and we’ll use the stylesheet to set the image width.
