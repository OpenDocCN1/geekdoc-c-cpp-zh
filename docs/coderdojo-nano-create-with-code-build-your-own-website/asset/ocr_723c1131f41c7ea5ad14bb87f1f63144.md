4. Everything is looking a little squashed up against the side of the boxes. It would be nice if there were a little spacing around the edges. To achieve this we add a margin and some left and right padding to the body and section elements, and small images. Add these rules in one line at a time and see the effects.

![](bbox=[0.029, 0.116, 0.587, 0.871])

```
img.small {
  float: left;
  height: 200px;
  margin-bottom: 24px;
  margin-right: 24px;
}
```

```
section {
  background-color: #88B875;
  margin-bottom: 24px;
  min-height: 320px;
  padding-left: 24px;
  padding-right: 24px;
}
```

```
body {
  background-color: white;
  color: #111111;
  font-family: sans-serif;
  margin-left: auto;
  margin-right: auto;
  max-width: 1024px;
  min-width: 256px;
  padding-left: 24px;
  padding-right: 24px;
}
```
