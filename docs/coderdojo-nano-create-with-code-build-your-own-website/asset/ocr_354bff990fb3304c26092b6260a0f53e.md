**Class attribute** - we've already seen what an attribute is. Most attributes can only be used with particular elements, but the **class** attribute is special because it can be applied to any HTML element. For example:

```
```html
<p class="top-tip">
<h3 class="author">
<table class="football-league-table">
<li class="selected-menu-item">
```
```

You use the **class** attribute to identify the meaning of a particular element and you can then apply a special style only to the element with that particular class.
