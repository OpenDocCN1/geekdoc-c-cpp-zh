Using the CSS you can change every single part of the box separately. For example you can change the appearance of your headings and paragraphs quite dramatically simply by adjusting the padding and spacing properties.

As well as changing the size of the various parts of the box, you can also change the colors of the different parts of the box. Many of the great visual effects you see on a web page are created in this way.

You can also change the overall size of the box by setting its width or height. Elements that are used to contain individual words or short phrases such as **em** or **strong** are called **inline elements**. For inline elements, the box fits around the word or phrase. Elements that are used to contain whole paragraphs are known as **block elements**. For block elements, the box normally stretches across the whole width of the page.
