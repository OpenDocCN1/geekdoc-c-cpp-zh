The purpose of the `onclick` attribute is to contain the name of a function that will be called when the image is clicked. Function is the name we give to some code that performs a useful task. In this case the `swapImage()` function is contained inside the `script` element. The function begins a series of processes that happen like this:

+   1. When the image is clicked the `swapImage()` function runs.

```
```html
<img id="display-image" onclick="swapImage()" src="images/01.png" width="180" height="180">
```
```

+   2. This makes the image (identified by its `id` of `display-image`) available to the script as a variable (`var`) with a name of `imageDisplayed`. (The `id` attribute allows you to give a unique identifying name to an element.)

```
```javascript
var imageDisplayed = document.getElementById('display-image');
```
```

+   3. If the source (`src`) of the `imageDisplayed` variable is currently set to `images/01.png`, then the function changes it to `images/02.png`.

```
```javascript
if (imageDisplayed.src.match("images/01.png")) {
    imageDisplayed.src = "images/02.png";
}
```
```

+   4. However, if the source (`src`) of the `imageDisplayed` variable is currently set to `images/02.png`, it will change it to `images/01.png`.

```
```javascript
else {
    imageDisplayed.src = "images/01.png";
}
```
