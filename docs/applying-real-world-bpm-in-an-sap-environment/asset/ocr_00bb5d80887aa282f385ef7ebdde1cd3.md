The ruleset contains two ruleset variables. Ruleset variables can be used to extend the context of a function, which means adding to the business vocabulary available for the rule definitions. This is very helpful for intermediate values in a sequence of rule steps or when the data provided in the context is not sufficient for the definition of all business rules.
