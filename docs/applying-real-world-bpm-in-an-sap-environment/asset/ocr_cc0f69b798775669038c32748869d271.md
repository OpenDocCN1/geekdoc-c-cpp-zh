# ▸ **3.5.1 Value audits**

Value audits assist with the tracking, monitoring, and controlling of the value drivers and key process changes during each phase of the project. Value audits ensure the project lives up to the initial value expectations as defined in the initial business case. Value audits enhance the capabilities of the project team to manage expectations and focus on key deliverables. They support the transparency of value delivery during the project and assist in tracking key process changes during the project. The key deliverable for a value audit includes the value status (value and cost actuals versus targets and issues) and identifies measures to achieve the value targets and is updated regularly throughout the project phase.
