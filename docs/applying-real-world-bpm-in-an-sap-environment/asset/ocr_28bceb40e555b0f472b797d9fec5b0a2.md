# Flow Rulesets

A flow ruleset is a ruleset providing capabilities to group business rules that need to be executed as in a flow chart. It always has one flow, designated as main flow, and possibly many other rule flows. The execution of the flow ruleset starts with the main flow. A flow ruleset uses aliases and definitions. It also consists of:

+   - If-Then rules
+   - Decision tables
+   - Rule flows
+   - Rule scripts
