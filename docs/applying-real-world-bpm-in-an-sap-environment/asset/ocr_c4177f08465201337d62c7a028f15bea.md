The first dimension focuses on the process model and its provisioning in a form of separate business packages. The second dimension concerns the platform as a carrier for the content packages. Both are equally relevant for Siemens’ solution.

As part of the business concept, the high-level reference process model was defined utilizing the SAP Solution Composer, whereas the detailed process modeling was executed directly in the SAP NetWeaver Developer Studio (NWDS). Besides the process modeling, the different perspectives of the developer studio are also the core component for nearly all development activities, such as the implementation of processes, rules, persistence, Web services, and user interfaces (see Figure 8.10).
