# How Others Can Apply the Danish Armed Forces Automation Value Driver Field

The documentation of any IT system should be linked to the business process model with all of the different process levels, systematically broken down to the lowest level. The synchronization of, for example, SAP Solution Manager with a BPMS such as ARIS only makes sense if the modeling is correct. The prospect of achieving genuine user instructions or automated testing may be a dream in the earlier BPM stages, but is should not be ignored.
