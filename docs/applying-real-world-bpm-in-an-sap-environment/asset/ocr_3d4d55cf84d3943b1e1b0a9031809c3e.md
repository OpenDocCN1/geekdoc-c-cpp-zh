Besides the online demo, each Java-based simple sample can be downloaded as source code (software component archive). The SCA can then be imported to a locally installed SAP NetWeaver Developer Studio (NWDS) system where you can explore and modify process models and screens (see Figure 14.51). If you do so, please keep in mind that simple samples are for educational purposes only and that no maintenance obligation from SAP is associated with them. For simple samples based on ABAP technology you can directly view the sources using the Web Application Builder via WebGUI.
