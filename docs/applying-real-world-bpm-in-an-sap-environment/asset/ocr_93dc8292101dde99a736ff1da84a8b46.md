# Sample Solution Architecture for an SAP Landscape

Figure 8.15 depicts the architecture of the solution. The vendor or supplier sends lead time update files (which can be thousands of records) on a monthly basis via a business-to-business (B2B) hub such as EDI. The file is then picked up by the enterprise application integration (EAI) layer, where the data is transformed into a common format. This data is then passed to the SAP NetWeaver BPM system using a Java Message Service (JMS) queue, where the data is fed into a BPM process. The process executes several rules to check the data and then either processes the update into the SAP system or raises exceptions, which are routed to the responsible product manager for either information or approval.
