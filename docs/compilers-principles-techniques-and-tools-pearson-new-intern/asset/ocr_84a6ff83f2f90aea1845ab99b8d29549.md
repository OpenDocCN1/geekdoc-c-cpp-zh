# 9.3. *FOUNDATIONS OF DATA-FLOW ANALYSIS*

+   1. $x \land x = x$ (meet is *idempotent*).
+   2. $x \land y = y \land x$ (meet is *commutative*).
+   3. $x \land (y \land z) = (x \land y) \land z$ (meet is *associative*).

A semilattice has a *top* element, denoted ⊤, such that

$$\text{for all } x \text{ in } V,\ \top \land x = x.$$

Optionally, a semilattice may have a *bottom* element, denoted ⊥, such that

$$\text{for all } x \text{ in } V,\ \bot \land x = \bot.$$

# Partial Orders

As we shall see, the meet operator of a semilattice defines a partial order on the values of the domain. A relation ≤ is a *partial order* on a set $V$ if for all $x$, $y$, and $z$ in $V$:

+   1. $x \le x$ (the partial order is *reflexive*).
+   2. If $x \le y$ and $y \le x$, then $x = y$ (the partial order is *antisymmetric*).
+   3. If $x \le y$ and $y \le z$, then $x \le z$ (the partial order is *transitive*).

The pair $(V, \le)$ is called a *poset*, or *partially ordered set*. It is also convenient to have a < relation for a poset, defined as

$$x < y \text{ if and only if } (x \le y) \text{ and } (x \ne y).$$

# The Partial Order for a Semilattice

It is useful to define a partial order ≤ for a semilattice $(V, \land)$. For all $x$ and $y$ in $V$, we define

$$x \le y \text{ if and only if } x \land y = x.$$

Because the meet operator is idempotent, commutative, and associative, the ≤ order as defined is reflexive, antisymmetric, and transitive. To see why, observe that:

+   - **Reflexivity:** for all $x$, $x \le x$. The proof is that $x \land x = x$ since meet is idempotent.
+   - **Antisymmetry:** if $x \le y$ and $y \le x$, then $x = y$. In proof, $x \le y$ means $x \land y = x$ and $y \le x$ means $y \land x = y$. By commutativity of $\land$, $x = (x \land y) = (y \land x) = y$.
