The symbolic map at the entry of the program is simply m_NAA. We use the top-down pass to compute the symbolic map to the entry to successively nested regions until we find all the symbolic maps for every basic block. We start by computing the data-flow values for block B₁ in region R₈.

IN[B₁] = m_NAA
OUT[B₁] = f_B₁(IN[B₁])

Descending down to regions R₇ and R₆, we get

INᵢ[B₂] = f_R₇,i,IN[R₆](OUT[B₁])
OUTᵢ[B₂] = f_B₂(INᵢ[B₂])

Finally, in region R₅, we get

INᵢ,ⱼ[B₃] = f_R₅,ⱼ,IN[B₃](OUTᵢ[B₂])
OUTᵢ,ⱼ[B₃] = f_B₃(INᵢ,ⱼ[B₃])
