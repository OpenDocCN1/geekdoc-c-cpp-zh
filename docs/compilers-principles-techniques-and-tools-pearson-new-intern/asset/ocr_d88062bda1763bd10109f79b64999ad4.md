# # 9.5. PARTIAL-REDUNDANCY ELIMINATION

| | (a) Anticipated Expressions | (b) Available Expressions |
|---|---|---|
| Domain | Sets of expressions | Sets of expressions |
| Direction | Backwards | Forwards |
| Transfer function | f_B(x) = e_use_B ∪ (x − e_kill_B) | f_B(x) = (anticipated[B].in ∪ x) − e_kill_B |
| Boundary | IN[EXIT] = ∅ | OUT[ENTRY] = ∅ |
| Meet (∧) | ∩ | ∩ |
| Equations | IN[B] = f_B(OUT[B])<br>OUT[B] = ∧_{S∈succ(B)} IN[S] | OUT[B] = f_B(IN[B])<br>IN[B] = ∧_{P∈pred(B)} OUT[P] |
| Initialization | IN[B] = U | OUT[B] = U |

| | (c) Postponable Expressions | (d) Used Expressions |
|---|---|---|
| Domain | Sets of expressions | Sets of expressions |
| Direction | Forwards | Backwards |
| Transfer function | f_B(x) = (earliest[B] ∪ x) − e_use_B | f_B(x) = (e_use_B ∪ x) − latest[B] |
| Boundary | OUT[ENTRY] = ∅ | IN[EXIT] = ∅ |
| Meet (∧) | ∩ | ∪ |
| Equations | OUT[B] = f_B(IN[B])<br>IN[B] = ∧_{P∈pred(B)} OUT[P] | IN[B] = f_B(OUT[B])<br>OUT[B] = ∧_{S∈succ(B)} IN[S] |
| Initialization | OUT[B] = U | IN[B] = ∅ |

earliest[B] = anticipated[B].in − available[B].in
latest[B] = (earliest[B] ∪ postponable[B].in) ∩
(e_use_B ∪ ¬(⋂_{S∈succ(B)} (earliest[S] ∪ postponable[S].in)))
