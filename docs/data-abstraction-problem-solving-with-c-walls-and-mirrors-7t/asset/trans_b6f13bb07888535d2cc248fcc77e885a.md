## 18.1 ADT 字典

当我们在第 11 章开始讨论对数据集合进行排序时，我们介绍了排序键的概念。例如，你可能希望根据姓名、年龄或邮政编码对关于人员的数据集合进行排序。你选择的标准称为排序键。同样，你可能希望在同一数据集合中搜索姓名、地址或电话号码。你为这次搜索选择的标准称为搜索键。

正如你所想象的，需要值导向操作的应用极其普遍。例如，任务
