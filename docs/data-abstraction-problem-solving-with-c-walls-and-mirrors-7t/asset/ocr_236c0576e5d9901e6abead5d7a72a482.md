The latter operation isPath uses the searchR algorithm to make its determination. If the class Map is the implementation of the ADT flight map, its method isPath has the following C++ definition. Note that NO_CITY is a City object that Map defines as a constant for getNextCity to return in case it cannot find an unvisited adjacent city.
