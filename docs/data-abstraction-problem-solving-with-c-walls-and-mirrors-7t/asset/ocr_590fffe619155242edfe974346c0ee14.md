+   1. You can ignore low-order terms in an algorithm's growth-rate function. For example, if an algorithm is O(n^2 + 4 x n^2 + 3 x n), it is also O(n^2). By examining the table in Figure 10-3a, you can see that the n^2 term is significantly larger than either 4 x n^2 or 3 x n, particularly for large values of n. For large n, the growth rate of n^2 + 4 x n^2 + 3 x n is the same as the growth rate of n^2. It is the growth rate of f(n), not the value of f(n), that is important here. Thus, even if an algorithm is O(n^2 + 4 x n^2 + 3 x n), we say that it is simply O(n^2). In general, you can usually conclude that an algorithm is O(f(n)), where f is a function similar to the ones listed in Figure 10-3.
