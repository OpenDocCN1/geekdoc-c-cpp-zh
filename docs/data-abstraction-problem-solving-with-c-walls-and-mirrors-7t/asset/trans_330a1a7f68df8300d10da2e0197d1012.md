- 7. 动态分配内存的类需要一个显式析构函数。析构函数应使用 delete 释放与对象关联的内存。如果你不定义析构函数，编译器会为你生成一个。编译器生成的析构函数仅适用于使用静态分配内存的类。

- 8. 虽然你可以使用 new 运算符为数组或链式结构动态分配内存，但以每次一个节点的方式增加链式结构的大小，比增加数组的大小更高效。当增加动态分配数组的大小时，必须将原数组的条目复制到新数组中，然后释放原数组。
