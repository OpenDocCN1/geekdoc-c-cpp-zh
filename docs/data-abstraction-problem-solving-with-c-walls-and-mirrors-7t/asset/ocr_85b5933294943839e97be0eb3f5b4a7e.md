| OPERATION | DESCRIPTION |
| :--- | :--- |
| `value_type& top()` | Returns a reference to the front entry in the priority queue. |
| `void push(value_type& item)` | Inserts item into the priority queue. |
| `void pop()` | Removes the front entry in the priority queue. |

#include <iostream>
#include <stack>
using namespace std;
int main()
{
    stack<int> aStack;
    // Right now, the stack is empty
    if (aStack.empty())
        cout << "The stack is empty." << endl;
    for (int j = 0; j < 5; j++)
        aStack.push(j); // Places items on top of stack
    while (!aStack.empty())

# ## C7.1.2 Sequence Containers

The elements in a sequence container are ordered in a linear sequence and can be accessed, inserted, and removed by position. Similar to the arrangement in traditional arrays, the positions in sequence containers are numbered from 0 to size – 1. The front of these containers is at position 0, and the back is at position size – 1.
