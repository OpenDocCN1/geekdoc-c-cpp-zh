

# NGS 数据分析计算方法

## 8.4.2 SVseq2 在一个步骤中同时使用这些特征。

通过仅对到较小的区域（称为焦点区域，focal regions）进行 Read 对特征的拆裂读比对（split-read mapping）。与 SVseq1 相同，由于使用了组合策略，包含读段的插入尺寸不需要显著大于文库大小，且拆裂读比对允许更多的错误。我们将详细讨论焦点区域如何减少错误。注意，当测序覆盖率非常低时，SVseq2 能够仅通过一个跨越读段（spanning read）检测到缺失，而 SVseq1 和其他方法通常需要更高的覆盖率来覆盖精确的断点。

SVseq2 依赖于由拆裂读形成的两种模式来检测缺失：
- Type I 模式：面向锚点的片段被比对（例如图 8.8 中的 Read 1）。
- Type II 模式：远离锚点的片段被比对（例如图 8.9 中的 Read 4）。

对于 I 型模式，基于软剪切（soft-clip）的拆裂读的比对的片段面向锚点。我们将比对片段的位置标记为 $[a, b]$（其中 $a < b$）。为了发现缺失，软剪切片段需要被比对到某些区域 $[c, d]$（其中 $c < d$）。我们将软剪切片段的长度标记为 $l = d - c$。因为真实缺失的长度未知，现有的某些拆裂读比对方法（例如 [1]）有一个关于最大距离的参数。SVseq2 不在大区域内搜索，而是在包含读段（encompassing reads）的引导下仅搜索焦点区域。这里的目标是推断软剪切片段可能从何处开始（包含对的范围）。

## 寻找插入和缺失的计算方法



img/46008551ce3baac2ee69b205.png

图 8.9 缺失检测的 Type II 模式。Read 4 是一个包含对。左端被拆裂。有一对 Read，其两端分别比对到参考基因组上的 $[s_1, e_1]$ 和 $[s_2, e_2]$（$s_1 < e_1 < s_2 < e_2$）。该对是该拆裂读的包含对，其位置由该拆裂读软剪切片段的比对确定。令 $l$ 为期望插入尺寸，$\sigma$ 为插入长度的标准差。注意，$l$ 测量的是两个读段最远点之间的距离。我们将包含对的长度分别标记为 $l_1$ 和 $l_2$。假设 SVseq2 检测的最小缺失为 $m_d$。SVseq2 将 $m_d$ 设置为 0。

**引理 1.** 对于 I 型模式，$s_2 \geq a$，且在高概率下有 $s_2 \leq a - l_1 - l_2 + 3\sigma$。

*证明。* 如果 $s_2 < a$，则 $a$ 不是断点。这与我们的基础假设不符，即比对片段 $[a, b]$ 对应于缺失。为了给 $s_2$ 一个上限，注意 $a$ 是参考序列上的位置 $a = l_{del}$，其中 $l_{del}$ 是缺失的长度。现在高概率下，参考序列上 $s_2$ 与 $e_1$ 之间的距离最多为 $l_1 - l_2 + 3\sigma + l_{del}$。根据如此概率，$s_2 \leq (a - l_{del}) + l_1 - l_2 + 3\sigma + l_{del} = a - l_1 - l_2 + 3\sigma$。

引理 1 表明包含对极有可能被检测到。对于拆裂读，SVseq2 在该区域的反向链上搜索包含对的 Read。现在假设我们为拆裂读 $[s_1, e_1]$ 和 $[s_2, e_2]$ 找到了一个包含对。以下引理规定了 $c$ 的范围（即软剪切片段的起始点）。

**引理 2.** 对于 I 型模式，$e_1 - l_i \leq a - m_d - l_c$。此外，在高概率下有 $c \leq e_1 + l_i - s_1 - l_1 + 3\sigma$。

*证明。* 缺失的最右位置可以是参考序列上 $a$ 左侧 $m_d$ 处，因为最小缺失大小为 $m_d$。因此 $c \leq a - m_d - l_c$。

由于包含对 $([s_1, e_1], [s_2, e_2])$ 包含了缺失，我们知道缺失必须发生在 $[s_1, e_1]$ 区域内。缺失的最左侧位置至少是 $e_1$。由于长度为 $l_i$ 的片段需要从缺失的左端向左进行比对，我们有 $c + l_i \geq e_1$。

我们现在估算 $c$ 可以有多大。在另一染色体（带有缺失的染色体）上，缺失的左右断点变得相同，且缺失的左断点必须位于包含对右端起始位置的左侧。因此，在参考染色体上，高概率下，左断点不会大于 $e_1 - l_i + 3\sigma$。

引理 2 表明，我们只需要在 $[e_1 - l_i + 3\sigma, a - m_d - l_c]$ 区域内搜索软剪切片段。该区域仍然很小。例如，假设 $l_i = 50$（取自长度为 100 的 Read），$l_1 = 100$，$l_2 = 200$，且 $\sigma = 50$。焦点区域的宽度为 200。这远小于原始拆裂读比对将搜索的焦点区域（后者可达 1 Mb）。此外，根据引理 1，包含对的宽度最大为 150。
