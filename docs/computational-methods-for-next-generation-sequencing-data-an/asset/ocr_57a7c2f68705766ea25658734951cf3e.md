solution (step 18) otherwise and forbids for $k_i$ steps of moving the vertex, which leads to
the previous local optimum (step 19). If the current algorithm state has not occurred
viously, the algorithm adds it to the optStates and proceeds to the next
iteration (steps 21–24). Otherwise, the algorithm reduces the current record $(A^*, B^*)
to the solution where $|A^*| \le T$ and stops (steps 25–30).

The default value of $k_i$ is 1. It is still possible that for the solution $(A^*, B^*)$ found by
Algorithm 2, we have $c(A^*, B^*) = 0$. If it happens, we increase $k_i$, by one and repeat
Algorithm 2.
