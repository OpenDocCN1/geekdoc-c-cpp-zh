### 14.3.1.2 Estimating Transcript Frequencies within Each Connected Component

As discussed earlier, in each connected component $C$, we simulate reads with 1000x coverage for each transcript (see Figure 14.2). Thus, for a transcript $T$ with length $|T|$, we generate $N_T=1000l_T$, where $l_T$ is the adjusted length of $T$. Similar we allow only alignments with fragment length less than $4\sigma$ from $\mu$. The reads that belong to the same transcripts are collapsed into a single read class. Let $R=\{R\}$ be all read classes found in the connected component $C$, and $R_T$ be the number of reads simulated from the transcript $T$ that fall in the read class $R$. The first inner loop outputs the set of coefficients $\{D_{R,T}\}$, where $d_{R,T}$ is the portion of reads generated from $T$ belonging to $R$

$$D_{R,T} = \left\{ \frac{|R_T|}{N_T} \right\}$$

$F'_T=\{f'_T\}$ is the crude transcript frequency, that is, the portions of reads emitted by transcripts in the connected component $C$. Then the expected read class frequency $E_R$ can be estimated as:

$$E_R = D_{R}$$

Regression-based estimation of $f'_T$ minimizes squared deviation

$$(D_{R,T} \times F'_T - O_R)^2 = \sum_{R \in \mathcal{R}} (e_R - o_R)^2 \quad (14.3)$$

between expected class frequencies $e_R$'s and observed read class frequencies $o_R$'s. Minimizing (14.3) is equivalent to the following quadratic program that can be solved with any constrained quadratic programming solver.

$$minimize: \sum_{R \in \mathcal{R}} \left( \sum_{T \in \mathcal{T}} d_{R,T} f'_T f_T - o_R \right)^2$$
subject to: $\sum_{T \in \mathcal{T}} f'_T = 1$ and $f'_T \geq 0, \quad \forall T \in C \quad (14.4)$$

### 14.3.1.3 Update Initial Estimates of Transcript Frequencies

The obtained transcript frequency estimation $f'_T$ can vary from the true class frequency since the minimization of deviation is done uniformly. Deed, the deviation in frequency is minimized on the same scale for each read class while different read classes have different size, as well as contribute to different subsets of transcripts. Instead of estimating unknown coefficients, we propose to directly obtain $f'_T$ for which simulated read frequencies $S_R = \{s_R\}$ match the observed frequencies $O_R$ accurately enough as follows.

Until the deviation between simulated and observed read class frequencies is small enough, repeatedly:

- simulate reads according to $F'_R$,
- find deviation between simulated and observed reads, $\Delta_R = S_R - O_R$,
- obtain read frequencies $C_R = O_R - \Delta_R/2$ corrected half-way in the direction opposite to the deviation,
- update estimated transcript frequencies $f'_T$ based on corrected read class frequencies $\{C_R\}$.

Finally, the transcript frequencies $f'_T$s can be obtained from class frequencies $f_T$s as follows:

$$f_T = \frac{f'_T/l_T}{\sum_{T' \in C} f'_{T'}/l_{T'}} \quad (14.5)$$

### 14.3.1.4 Combining Transcript Frequency Estimates from all Connected Components

Finally, we combine individual solutions for each connected component. Let $f_T^{glob}$ and $f_T^{loc}$ be the global frequency of the transcript $T$ and local frequency of the transcript $T$ in its connected component $C$. The global frequency can be computed as:

$$f_T^{glob} = f_T^{loc} \times \frac{|R_C|}{\sum_{T' \in C} f_{T'}^{loc}/l_{T'}} \quad (14.6)$$

where $C$ is the set of all connected components in the graph and $|R_C|$ is the number of reads emitted by the transcripts contained in connected component $C$.

# 14.3.2 Differential Gene Expression Analysis: IsoDE

As differential expression analysis, IsoDE starts with a set $A$ of RNA-Seq alignments for each condition. Bootstrapping can be used in conjunction with any method for estimating gene expression levels from RNA-Seq data, typically expressed in fragment per kilobase of gene length per million reads (FPKM). In IsoDE, we use the IsoEM algorithm, an expectation maximization (EM) algorithm that takes into account isoforms to ensure accurate normalization. Unlike some of the existing methods, IsoEM uniquely maps reads, relying on the distribution of insert sizes and quality scores to probabilistically infer their origin. Previous experiments have shown IsoEM yields highly accurate FPK estimates with lower run-time compared to other commonly used algorithms.

The first step of IsoDE is to generate bootstrap samples by randomly sampling with replacement from the reads represented in A. When a read is selected during resampling, all alignments from $A$ are included in the bootstrap sample. The number of resampled reads in each bootstrap sample equals the total number of reads in the original. However, the total number of alignments may differ between bootstrap samples depending on the number of selected reads and the number of times each is selected. The IsoEM algorithm is then run on each bootstrap sample, resulting in $M$ FPK estimates for each gene. The bootstrap sample generation algorithm is summarized as follows:

1. Sort the alignment file by read ID
2. Compute the number $N$ of reads and generate a list $L$ containing read IDs in the alignment file $A$
3. For $i = 1, \dots, M$:
   a) Randomly select with replacement $N$ read IDs from $L$, sort read IDs, and in $A_i$ all their alignments (if a read is selected $m$ times, its alignments are repeated $m$ times in $A_i$)
   b) Run IsoEM on $A_i$ to get the $i$th FPKM estimate for each gene

### 14.3.2.2 Bootstrap-Testing of Differential Expression

To test for differential expression, IsoDE takes two folders as input, which contain FPK estimates from bootstrap samples generated for the two conditions to be compared. In case of replicates, a list of bootstrap folders is provided for each condition (one folder per replicate, normally with an equal number of bootstrap samples)—IsoDE will automatically merge the folders for the replicates to get a combined folder per condition and then perform the analysis as in the case without replicates.

In the following, we assume that a total of $M$ bootstrap samples is generated for each of the compared conditions. We experimented with two approaches for pairing the FMs estimated from the two sets of bootstrap samples. The “matching” approach, a random one-to-one mapping is created between the $M$ estimates of first condition and the $M$ estimates of the second condition. This results in $M$ pairs of FPKM estimates. In the “all” approach, $M^2$ pairs of FPKM estimates are generated by pairing each FPKM estimate for first condition with each FPKM estimate for second condition. When pairing FPKM estimate $a_i$ for the first condition with FPKM estimate $b_j$ for the second condition, we use $a_i/b_j$ as an estimate for the fold change in the gene expression level between the two conditions. The “matching” approach results in $N=M$ fold change estimates, while the “all” approach results in $N=M^2$ fold change estimates.

The IsoDE for differential expression uses two user-specified parameters, namely the minimum fold change and the minimum bootstrap support $b$. For a given threshold $f$ (typically selected based on biological considerations), we calculate the percentage of fold estimates that are equal to or higher than $f$ when testing for overexpression, respectively lower than $1/f$ when testing for underxp. If this percentage is higher than the minimum bootstrap support $b$, otherwise the gene is classified as nondifferentially expressed (non-DE). The actual bootstrap support for fold threshold $f$ and the minimum fold change with bootstrap support of at least $b$, are included in the IsoDE output to allow the user to easily increase the stringency of the DE test.

As discussed in the results section, varying the bootstrap support $b$ allows us to achieve a smooth trade-off between sensitivity and specificity for a fixed fold change $f$ (see.g., Figure 14.3). Since different trade-offs may be desirable in different biological contexts, no $b$ is universally applicable. In our experiments, we computed $b$ using a simple binomial model for the distribution of fold estimates and a significance level $\alpha=0.05$. Specifically, we assume that under the null the fold changes from bootstrap estimates are likely to be greater or smaller than $f$. We then compute $b$ as $x_{min}/N$, where $x_{min}=\min\{x:P(X\geq x)\leq\alpha\}$ and $X$ is a binomial random variable denoting the number of successes in $N$ independent Bernoulli trials with success probability of $0.5$. For convenience, a calculator for computing the bootstrap support needed to achieve a desired significance level (the possible number) of bootstrap samples for each condition has been made available online.

The number $M$ of bootstrap samples is another parameter that the users of IsoDE must specify. As discussed in the results section, computing the bootstrap support for all genes takes negligible time, and the overall running time of IsoDE is dominated by the time to implement the $2M$ IsoEM runs. Hence, the overall run-times grow linearly with $M$. Experimental results suggest that the “all” pairing approach produces highly accurate results with relatively small values of $M$ (e.g., $M=20$), and thus results in run-times, independent of the number of replicates.
