# 15.3.2 Results and Discussion

We compared performances of clustering-based algorithms SHORAH kGEM, alignment-based algorithm KEC KEC with the alignment-based postprocessing step in “KEC postprocessing using "aligning”. Several modifications of SHORAH clustering hyper-parameter α was tested, and the value α=0.1, which produced the best result, was chosen. For KGEM, the initial value k=1000 was used. For KEC, the k-mers size k=25 was used, and an error threshold was estimated as the end of the first segment of k consecutive zeroes in a k-counts distribution.
