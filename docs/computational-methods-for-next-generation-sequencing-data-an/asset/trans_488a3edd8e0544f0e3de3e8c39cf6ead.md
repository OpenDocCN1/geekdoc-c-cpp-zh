

## 232 NGS 数据分析计算方法

通配符（wildcards）允许读段（reads）和基因组中的某些碱基相互匹配。另一种方法是将参考序列或读段转换以允许 BS 错配（BS-mismatches）。BRAT 引入了基因组和读段的不同位表示；它维护了两个独立的位，即 ta 表示和 cg 表示，每个字母对应一个位。在 ta 表示中，所有的 C 都被转换为 T，所有的 G 都转换为 A，并给 T 分配位 1，给 A 分配位 0。在 cg 表示中，C 和 G 被转换为 1，而 A 被转换为 0。基因组/读段的表示法允许将读段及其反向互补序列比对到正向基因组链上，并区分 BS 错配和非 BS 错配（文中将讨论使用这种表示法进行比对）。

使用 BWT（伯恩·穆瑞勒变换）的方法受限于使用参考序列/读段，且据我们所知，它们没有使用那种将读段中所有 T 的组合转换为 C 的方法：BS-Seeker (23)；Bismark (24)；BRAT-bw (25)。除了参考序列/读段转换外，某些工具还基于这种方法提高由于测序误差导致的比对准确性。这些方法更有效，在某些情况下（对于大基因组，在参考序列上进行哈希处理时），使用于索引的种子（seeds）长度保持固定，且由于空间限制通常保持较短：这导致每个读段及其反向互补序列比对到的基因组位置数量增加。而使用 BWT，种子长度不是固定的：与 BWT 匹配的种子越长，需要检查的基因组位置就越少。

BWT 工具使用了不同的基因组读段。在这里，我们将提供一个由 BRAT-bw 使用的示例。基于参考序列正向链有两个不同的 BWT 索引：在第一种中，所有的 C 都转换为 T；在第二种中，所有的 G 都转换为 A。读段及其反向互补序列也会被转换，导致单个读段产生四个版本：在读段及其反向互补序列中将 C 转换为 T，在读段及其反向互补序列中将 G 转换为 A。将 C 转换为 T 的原始读段及其相同转换的反向互补序列比对到 AG 还原基因组，而将 G 转换为 A 的原始读段版本及其反向互补序列比对到 ACT 还原基因组。

无论使用哈希还是 BWT，一旦确定了潜在的基因组位置，就会进行全长比对，以估计每次比对的准确性。不同的工具选择不同的比对策略。某些工具采用 Smith-Waterman 算法 (24) 的版本，允许读段中核碱酸的插入和删除（Mash, BISS）；另一些使用汉明距离来计算非 BS 错配（RMAP-bs, BRAT-bw, BMap）；使用 Bowtie (25) 作为底层比对工具的工具利用 Bowtie 的输出对比对进行评分（Bismark, BS-Seeker）。如果一个读段以相同的得分比对到两个或多个基因组位置，则认为其是歧义的，通常不被纳入进一步的甲基化分析估计。

为了说明读段到参考序列的全长比对，我们将描述 BRAT 的策略（也用于 BRAT-bw）。读段及其反向互补序列仅比对到正向基因组链 DS+。如前所述，BRAT 对基因组和读段使用了 ta- 和 cg 位表示。

### 10.4 甲基化估计

在亚硫酸盐处理后的读段比对到参考序列、去除拷贝重复并丢弃歧义比对读段后，就可以估计每个胞嘧啶的甲基化状态。每个比对到胞嘧啶的读段代表细胞中的 DNA 甲基化。

不同的工具选择不同的比对策略。某些工具采用允许读段中核碱酸插入和删除的 Smith-Waterman 算法（24）（Mash, BISS）；另一些使用汉明距离计算非 BS 错配（RMAP-bs, BRAT-bw, BMap）；使用 Bowtie (25) 作为底层比对工具的工具使用 Bowtie 的输出对比对评分（Bismark, BS-Seeker）。如果一个读段以相同的得分比对到两个或多个基因组位置，则认为其是歧义的，通常不纳入进一步的甲基化估计。

### 10.5 甲基化估计中的偏差

在科学文献中，有人认为允许 T–C 错配但不允许 C–T 错配的比对可能会引入甲基化水平正确估计的偏差，因为不含 C 的读段更有机会比对到不同的基因组位置 (15)。为了避免这种情况，如果使用还原三字母比对，Bism 将读段视为歧义的。BS-Seeker 使用类似的方法；它忽略某些读段，而对于其余读段，它重新计算非 BS 错配的数量并仅保留得分最高的唯一比对读段。

另一种反方观点认为，允许 C–T 匹配也会导致高估比对到参考序列的读段中未甲基化胞嘧啶的数量。可以通过甲基化比对（仅允许 C–C 和 T–T 匹配）无歧地比对的含 C 读段在允许 T–C 和 C–T 映射时可能会变得歧义并从进一步分析中排除；该读段中 C 对基因组胞嘧啶总数的贡献丢失了，从而影响了甲基化水平的估计。BRAT-bow 提供了在两种方法之间选择的选择：允许或不允许 C–T 错配。在使用方向性亚硫酸盐文库时，甲基化水平估计的另一种偏差如下。考虑图 10.1 中 PCR+ 链上的 5' 伙伴 AACGTCA。当允许 A–G 映射时，它无歧地比对到 DS+ 且零错配，而当允许 T–C 时，它比对到 DS+ 且有一个错配。
