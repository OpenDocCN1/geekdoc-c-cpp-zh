Thus, according to the relations (3.8) and (3.9), any initial solution $(A, B)$ is iteratively improved by moving vertices from one part of the partition until a local optimum is reached, and the obtained solution cannot be further improved. According to (3.8), a local optimum is a clique.
The major general drawback of such search strategies is that the value of the objective function in a local optimum may be far from the globally optimal solution. Another problem, which is specific to our case, is that it is possible that the size of the locally optimal cut in $H$ is 0. In this case, the solution found at the stage (4) of Algorithm GOPDA does not decrease the E(H), and therefore, Algorithm GOPDA will go into an infinite loop. To solve these problems, we use the variation of the tabu strategy (35). The basic idea is that after the move of a vertex $v$ the algorithm arrives at a local optimum, the following actions are taken: the value of the local optimum is compared to the current best solution, $v$ is placed back, and the move of $v$ is prohibited for the next $k_i$ iterations of the algorithm. This is implemented in the following Algorithm OCGBP, which is described in more detail.

Let $tabu^i = \{tabu_1^i, \dots, tabu_j^i\}$ be the tabu state at the iteration $i$, that is, a sequence of integers, where $tabu_j$ is a number of iterations during which it is not allowed to move a vertex $j$. Let $optStates^i$ be a set of optimal states, that is, a set of pairs $((A, B), t_{A,B})$, where $(A, B)$ is a local optimum found by the algorithm at some iteration $j < i$ and $t_{A,B}$ is the tabu state at that iteration, that is, $t_{A,B}=tabu'$. Let $(A^*, B^*)$ be the current record cut, that is, the cut of the best size $c(A^*, B^*)$ found by the algorithm before the $i$th iteration. Let also moveList be the sequence of vertices moved by the algorithm from one part of the cut to another in the order of move. This sequence is easier to implement as a stack, and it allows the algorithm to return to the previous solutions when neighborhoods of solutions are completely explored.
