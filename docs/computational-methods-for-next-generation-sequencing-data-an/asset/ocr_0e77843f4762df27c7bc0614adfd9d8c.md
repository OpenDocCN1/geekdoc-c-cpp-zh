# 9.2.2 Available Approaches

9.2.2.1 Bayesian Tool for Methylation Analysis (Batman) Batman (57) has developed to address the difficulty of estimating absolute methylation levels due to CpG density effects from DNA immunoprecipitation using oligonucleotide arrays (MeDi-chip) or NGS (MeDiP-seq), as explained in methylation quantification. To address this, Batman defines the coupling factor Cpw in the genomic w and CpG density p of DNA molecules being sequenced in the window that contains the CpG, so that local CpG density is in proportion to the coupling factor for a given window. As shown in Figure 9.6, there is an approximately linear relationship between the window and the density of methylated CpGs. This observation leads to a model that defines a set of methylation observations, the probability distribution S for a complete set of independent observations is defined as f(m|S) = Π G(sw|Cpw,mp), ⁻¹ where G(μ, σ²) is a rectified Gaussian probability density function, mp represents the methylation level at position p, and Cpw represents the coupling factor between a w and a CpG p. To calculate f(m|S), the posterior distribution of the methylation state parameters provides the MB-seq data, a standard Bayesian inference approach based on nested sampling, a highly robust Monte Carlo technique has been applied. In other words, for each window of the genome, the approach generates 100 most likely samples from f(m|S), fits distributions to these samples, chooses the most likely methylation state in 100 bp windows, and then chooses the modes of the most likely distributions as the final methylation calls.

To run Batman, we need to (i) filter out low-confidence alignments from BAM files, (ii) generate mapped reads in GFF2 files, (iii) create a database on MySQL, (iv) generate and load a coupling factor using EstimateCouplingProfileApplication and LoadCouplingProfileApplication, (v) generate a Batman array file from a GFF2 file using ReadsToSeqArrayProbes and LoadRatesGFF, (vii) calibrate read counts using coupling factor and (viii) generate methylation states using SampleMethStatesApplication. Batman does not provide a user-friendly interface and requires knowledge of a database management system. It is quite slow and recommends running jobs for each chromosome.
