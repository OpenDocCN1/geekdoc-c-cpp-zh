Alternatively, one can convert the reference or the reads to allow BS-mismatches BRAT introduced different bit representations of a genome and reads; it maintains two separate bits, ta-representation and cg-representation, one bit per letter. In the ta-representation, all Cs are converted to Ts and all Gs are converted to As and bit 1 is assigned to Ts and bit 0 to As. In the cg-representation, Cs and G are converted to 1 and As to 0. Genome/reads representation allows mapping reads and their reverse-complements directly to the positive genomic strand and distinguishes between BS-mismatches and non-BS-mismatches (the alignment using this representation is discussed).

Methods that employ the BWT are restricted to using reference/reads and to the best of our knowledge do not use the approach, in which all combinations of Ts are converted to Cs in a read: BS-Seeker (23); Bismark (24); BRAT-bw (25). In addition to reference/reads conversion, tools used based approach to improve accuracy of mapping due to sequencing errors. These methods are more efficient and in some cases (with large genomes when hashing is done on a reference) also make the length of seeds used for indexing is fixed and usually kept short because of space limitations: this results in a greater number of genomic positions, to which each read and its reverse-complement are aligned. With the BWT, the length of seeds is not fixed in place: the longer the seed matched with the BWT, the fewer are the genomic positions that need to be checked.

There different genomic reads used by the tools of the BWT. Here, we will provide one example used by BRAT-bw. Two different BWT indices are based on a positive strand of the reference: in the first, all Cs are converted to Ts, and in the second all Gs are converted to As. The reads and their reverse-complements are also converted resulting in four versions of a single read; CS are converted to Ts in a read and in the reverse-complement of the read, and Gs are converted to As in a read and in the reverse-complement of the read. Original reads with Cs converted to Ts and their reverse-complements with the same conversion are mapped to the AG-reduced genome, and the versions of original reads and their reverse-complements with Gs converted to As are mapped to the ACT-reduced genome.

Whether one uses hashing or the BWT, once the potential genomic positions are identified, a full-length alignment is performed to estimate the accuracy of each mapping. Different tools choose different alignment strategies. Some tools employ a version of Smith-Waterman algorithm (24) that allows for insertions and deletions of nucleotides in a read (Mash, BISS); others use the Hamming distance to count the non-BS-mismatches (RMAP-bs, BRAT-bw, BMap); the tools used Bowtie (25) as an underlying mapping tool use Bowtie's output to score the alignments (Bismark, BS-Seeker). If a read is mapped to two or more genomic locations with the same score, it is considered ambiguous and usually is not considered for further methylation analysis estimation.
