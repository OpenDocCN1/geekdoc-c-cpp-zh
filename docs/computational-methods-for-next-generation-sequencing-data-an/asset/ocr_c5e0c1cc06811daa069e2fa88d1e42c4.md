Methylation entropy is defined as $ME = 1/b + \Sigma_i(-n_i/N)$ where $b$ is the number of CpGs, $n_i$ is the number of occurrence of methylation pattern $i$ among reads, and $N$ is the total number of reads. Therefore, $ME(A) = 1/3 + (-4/8 * \log_2(4/8)) = 1/3 + -1/2 * -1 = 5/6$ and $ME(B) = 1/3 + (-1/8 * \log_2(1/8)) = 1/3 + -1/8 * -3 = 1$. Interestingly, regions C and D have the same pattern, the same ME score, although their beta scores are 0 and 1. Therefore, ME can distinguish the consistency of single molecule methylation pattern, and that, the higher the ME, the more the random pattern. This can be used to decide whether intermediate methylation of a cell population is either stochastic or allele-specific.

**9.3.2 Quantitatively Methylated Region (QDMR)** QDMR (94) has adopted Shannon entropy to identify DMRs across samples. Shannon entropy represents the uncertainty (unpredictability) of a random variable, that is, the complexity of methylation values across samples, and is defined for a site or region as $H_O =-\Sigma_i p_i \log_2 p_i$, where $p_i$ is the probability of occurrence of the methylation value $m_i$ of sample $s$, $p_i = m_s/\Sigma m_s$. QDMR requires methylation value in a range of [0,1] or [0,100]. If all samples have the same methylation value, $H_O$ is maximized and the uncertainty is minimal. If a fair die is rolled, the outcome is maximally uncertain (unpredicted). If a die is highly biased to side, the outcome is highly predictable and the entropy low. Similarly, if a sample's methylation differs from other samples, the entropy is lower than the maximum. In other words, the higher the difference, the lower the entropy. However, hypermethylation in a sample results in low entropy (Figure 9.12b and d), hypomethylation does not (Figure 9.12c and e). The ROKU (95) has been proposed to solve this problem using a one-step Tukey (a weighted mean), resulting in the processed methylation $m'_s = |m_s - T|$. See Reference 94 for more details. The processed entropy is defined as $H_p =-\Sigma_i p'_i \log_2 p'_i$, where $p'_i = m'_s/\Sigma m'_s$.
