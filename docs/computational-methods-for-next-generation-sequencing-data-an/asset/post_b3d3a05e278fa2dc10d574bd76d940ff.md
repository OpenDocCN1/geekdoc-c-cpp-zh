## 8.4.2 SVseq2 uses the signatures together in one step.

Read pair signature split-read mapping by aligning only to smaller regions (called focal regions). Same as SVseq1, because combined strategy is used, insert size of encompassing read does not need to be significantly longer than library size and split-read mapping can allow more errors. We will discuss in detail how focal regions will reduce errors. Note that SVseq2 is able to catch deletions with only one spanning read when the read coverage is very low, whereas SVseq1 and other methods usually need higher coverage to cover the exact breakpoints.

SVseq2 relies on two types of patterns formed by split reads to detect deletions:
- Type I pattern: the segment facing the anchor is mapped (e.g., Read 1 in Figure 8.8).
- Type II pattern: the segment away from the anchor is mapped (e.g., Read 4 in Figure 8.9).

For type I, the mapped segment of a split read based on soft-clip faces the anchor. We denote the location of the mapped segment as $[a, b]$ (where $a < b$). To discover a deletion, the soft-clipped segment needs to be mapped to some region $[c, d]$ (where $c < d$). We denote the length of the soft-clipped segment as $l = d - c$. Because the length of the true deletion is not known, some existing split-read mapping methods (e.g., [1]) have a parameter on the maximum distance. Instead of searching in a large region, SVseq2 only searches focal region by the guidance of encompassing reads. Our goal is here to infer where the soft-clipped segment is likely to start (the range of encompassing pair).

There is a read pair whose two ends are mapped to $[s_1, e_1]$ and $[s_2, e_2]$, respectively, on the reference genome ($s_1 < e_1 < s_2 < e_2$). This pair is an encompassing pair for the split read whose location is determined by the mapping of the soft-clipped segment of the split read. Let $l$ be the expected insert size and $\sigma$ be the standard deviation of the insert length. Note that $l$ measures the distance between the farthest points of two reads. We denote the length of the encompassing pair as $l_1$ and $l_2$, respectively. Suppose the minimum deletion to be detected by SVseq2 is $m_d$. SVseq2 sets $m_d$ to 0.

**Lemma 1.** For type I pattern, $s_2 \geq a$, and with high probability we have $s_2 \leq a - l_1 - l_2 + 3\sigma$.

*Proof.* If $s_2 < a$, then $a$ is not a breakpoint. This does not agree with our underlying assumption that the mapped segment $[a, b]$ corresponds to a deletion. To give an upper bound on $s_2$, note that $a$ is the position on the reference $a = l_{del}$ where $l_{del}$ is the length of the deletion. Now with high probability, the distance between $s_2$ and $e_1$ is at most $l_1 - l_2 + 3\sigma + l_{del}$ on the reference. With so high probability $s_2 \leq (a - l_{del}) + l_1 - l_2 + 3\sigma + l_{del} = a - l_1 - l_2 + 3\sigma$.

Lemma 1 states that the encompassing pairs are very likely to be detected. For a split read, SVseq2 searches for reads on the reverse strand this region for encompassing pairs. Now suppose we find one encompassing pair for the split read $[s_1, e_1]$ and $[s_2, e_2]$. The following lemma specifies the range of $c$ (i.e., the starting point of the soft-clipped segment).

**Lemma 2.** For type I pattern, $e_1 - l_i \leq a - m_d - l_c$. Moreover, with high probability, we have $c \leq e_1 + l_i - s_1 - l_1 + 3\sigma$.

*Proof.* The rightmost position of a deletion can be $m_d$ to the left of $a$ on the reference because the minimum deletion size is $m_d$. So $c \leq a - m_d - l_c$.

Since the encompassing pair $([s_1, e_1], [s_2, e_2])$ encompasses the deletion, we know the deletion must occur in the region of $[s_1, e_1]$. The leftmost position of the deletion is at least $e_1$. Since length of $l_i$ is to be mapped (to the left) from the left end of the deletion, we have $c + l_i \geq e_1$.

We now estimate how large $c$ can be. That on the alternative chromosome (the chromosome with deletion), the left and right breakpoints of the deletion become the same, and the left breakpoint of the deletion must be to the left of the starting position of the right end of the encompassing pair. Thus, on the reference chromosome, with high probability, the left breakpoint is no bigger than $e_1 - l_i + 3\sigma$.

Lemma 2 states that we only need to search the soft-clipped segment within the region $[e_1 - l_i + 3\sigma, a - m_d - l_c]$. This region is still small. For example, suppose $l_i = 50$ (taken from a read of 100), $l_1 = 100$, $l_2 = 200$, and $\sigma = 50$. The width of the focal region is 200. This is much smaller than the focal region that the original split-read mapping would have searched (which can be as large as 1 Mb). Also, from Lemma 1, the width for the encompassing pairs is at most 150.
