## 9.3.2.5 BSpipe
BSpipe is a comprehensive package to analyze BS-seq for sequence mapping, methylation quantification based on sliding windows or genomic features, DMR identification and annotation, methylation profiling by PCA and unsupervised clustering, and visualization on the UCSC genome browser and IGV.

### Sequence Mapping
BSpipe maps bisulfite-treated reads to reference sequences using in silico conversion. Briefly, reference sequences are converted and indexed by an in-house script and indexing programs for each of the Watson and Crick strands. Similarly, BS-seq reads are converted once or twice, depending on sequencing protocols, and mapped onto two reference indices. Here, each read can be aligned one or four times. BestSam identifies the best map among alignments by realigning the original reads to the original references and recalculating mismatches and indels, except mismatches due to bisulfite conversion. If there are two or more alignments in different locations, the read is reported as a multiple map. BestSam finally generates an augmented SAM (MSAM) file including positions of methylated and unmethylated cytosines. The mapping mode specifies whether C or G in a read is converted by bisulfite treatment and used for measuring methylation. This pipeline summarizes mapping results as number of reads, along with the number of errors and the number of mapping locations and those in each reference. BSpipe can use any mapping program by configuring to specify a parameter setting-indexing program, mapping program, sequence length, and indels, SAM output format, and mapping strands if available. Currently as a default, the program supports Bowie (51), BWA (50); and SOAP2 (52).

### Methylation quantification
A sorted, binary MSAM (MBAM) file is generated and count the number of reads with methylated and unmethylated cytosines for each cytosine in both strands of the genome. This module generates a GFF file in which each line specifies the methylation of a cytosine with the following bases, number of reads, and the sum of base quality scores with methylated and unmethylated cytosines. Finally, the module generates a BED file for a cytosine pattern, for example, CpG, in which line specifies the number of reads (coverage) and methylation fraction (number of reads divided by the read coverage). Users can specify particular patterns of interest, for example, CpH, CpHg, and CpHH. BSpipe supports a sliding window approach to combine the methylation of adjacent CpGs which work together in biological regulation. It outputs the number of CpGs and the mean and standard deviation of methylation for fix-length windows with a step. It can also quantify the methylation of genomic feature such as promoters, exons, introns, CpG islands (CGIs), and repeats for the entire region or fix-length windows.

### Sample comparison
After profiling the methylation of various types of regions, the most important task is to discover outliers or to see the global methylation changes among samples. BSPipe has several modules for this purpose. First, it measures the Pearson or Spearman's correlation coefficient for each pair of samples and generates a heat map to cluster samples based on a matrix of the correlation coefficients. Second, PCA is performed and plotted using the first and second components. Finally, BSPipe conducts hierarchical clustering and k-means to identify differential methylation in an unsupervised manner.

### Differential methylation among groups
BSpipe identifies DMRs in descriptive way by methylation between two samples or groups. It also assesses the significance of DMRs between two groups using statistical tests such as Student t, Wilcoxon, and Kolmogorov–Smirnov tests, and three or more groups using ANOVA. BSPipe generates adjusted p-values for multiple comparisons, and diagnostic plots such as histogram plots of p-values and adjusted p-values, scatter plots between two samples, and a volcano plot heat map for DMRs.

### External programs and parallel execution
BSpipe prepares the input of and runs programs as QDM and BSmooth to enable user's complementary analysis. To take advantage of a multiple computer or a cluster computer, BSPipe coupled with grid engines, for example, sun grid engine, through a configuration file. It splits input files in FASTQ format into many small files and then submits a job for each split file to perform sequence mapping to methylation quantification. The methylation of CpGs is merged. BSPipe also supports annotation and visualization of DMRs as depicted in the next section.

## 9.4 CONCLUSION
Enrichment-based and bisulfite-based approaches described in this chapter have successfully profiled DNA methylation and identified genome-wide methylation, for example, References 18, 97–99. As analysis results, sequence mapping and methylation profile and differential methylation of CpGs, tiling windows, or genomic features are stored in various formats as BAM, Wiggle, GFF, and BED, which can be visualized on the UCSC genome browser (68), gbrowser (69), IGV (70), or IG (71).
