Because orthologous proteins tend to share equivalent functions, this information can be propagated throughout a cluster providing a rapid route for functional annotation of individual genomes or metagenomic data (Figure 2.6a). Interestingly, sequencing projects have generated a large number of hypothetical ORFs that are conserved across taxonomic groups. While incorporating these sequences into COGs has traditionally relied on manual annotation, the sheer number of incoming sequences has driven the development of automated alternatives including the EggNOG database (80). In its second version, EggNOG uses reciprocal BLAST and the "triangle homology" method to build new clusters and append to existing ones (81). While the COG database is included in MetaPathways, the EggNOG database can be added as an unformatted fasta file to the database directory. This file will automatically be formatted to provide the next-and-extend search and results will be combined with other database outputs.

MetaPathways uses BLAST to query predicted protein sequences against reference databases using RefSeq and COG for taxonomic annotation. BLAST scores are calculated and reported as described in the functional annotations section. COG annotations are returned with their declination on the CO functional hierarchy with results exported to the results/annotation_tables/ COG annotations for each read are summarized in a tabular format for the results/annotation_tables/ or directly seen in the MetaPathways v2.0 GUI.

MetaPathways also supports functional gene profiling using MLTreeMap (37). MLTreeMap automatically places marker genes onto a highly resolved phylogeny from a multiple alignment or "supermatrix" of 40 universal COGs (82). Taxonomic assignment proceeds in three steps. First marker genes are identified using nucleotide or protein sequences using BLAST and GeneWise (33). Detected marker genes are added to curated reference alignments using hmmalind and Gblocks (84, 85). These aligned sequences are then placed into annotated reference phylogenies using RAAML (86, 87) (Figure 2.6b). In addition to universal COG reference phylogenies, user-defined trees can be appended to MLTreeMap supporting both phylogenetic and functional anchoring.

# 2.3.3.4 Lowest Ancestor

Taxonomic annotation of environmental sequence information is sensitive to read length and assembly. Although the presence of phylogenetic anchors such as rRNA genes on assembled contigs enables direct annotation of linked ORFs, individual ORF assignments based on BLAST or BLAST can be confounded by shared sequence homology between a number of different taxonomic groups. The LCA algorithm originally incorporated into MEGAN (34) uses BLAST scores to conservatively place sequences into the NCBI taxonomy hierarchy. The LCA represents the lowest node in the NCBI taxonomy to which a sequence can be assigned on the expected taxonomic range of its BLAST hits (Figure 2.6c).
