# DISCOVERING AND GENOTYPING TWILIGHT ZONE DELETIONS

Making use of an ML approach allows to attain an efficient computation scheme. We point out below that a full Bayesian approach is infeasible of being exponential in the number of reads that align with the region of interest – note that we wish to genotype hundreds of thousands of reads of interest, such that run-time considerations are a crucial factor.

We are interested in maximizing

```
$P(G_i \mid R) \propto P(G_i, R) = \sum_{S \in R} P(S) \cdot P(G_i \mid S). \quad (7.3)$
```

By taking probabilities $P(S)$ into account, we would like to appropriately address alignment uncertainty, which can be due to several factors such as multiple mappings and alignment artifacts. Let $K := |R|$ be the number of reads that align to the region to be genotyped. By Bayes’ formula, Equation (7.2) further implies that

```
$P(G_i \mid S) \overset{(7.2)}{\propto} \prod_{S \in R} P(A^+(R) \mid G_i) \cdot \prod_{S \in R} P(A^-(R) \mid G_i)$$\n\overset{(7.2)}{\propto} \prod_{S \in R} P(G_i \mid A^+(R)) \cdot \prod_{S \in R} P(G_i \mid A^-(R)), \quad (7.4)$
```

where the equality is justified by assuming that reads have been generated independently of each other. Note that the computation (7,4) is not possible in the frame of a fully Bayesian approach because only the assumption (7.2) of constant priors is infeasible. This renders such an undertaking infeasible. From (7,4), we conclude that

```
$P(G_i \mid R) \propto \sum_{S \in R} P(S) \cdot \prod_{S \in R} P(G_i \mid S) \cdot \prod_{S \in R} P(G_i \mid A^-(R))$$\n\overset{(7.1)}{\propto} \sum_{S \in R} P(A^+(R))P(G_i \mid A^+(R)) \cdot \prod_{S \in R} (1 - P(A^+(R)))P(G_i \mid A^-(R))$$\n= \sum_{R' \in R} [P(A^+(R'))P(G_i \mid A(R')) + (1 - P(A^+(R')))P(G_i \mid A^-(R'))], \quad (7.5)$
```

where the second row follows from expanding the third row. The last finally, can be computed in linear time in the number of reads $R$, which had been our goal. It remains to compute reasonable $P(G_i \mid A^+)$ and $P(G_i \mid A^-)$ for read alignments A. While

```
$P(G_i \mid A^-) = P(G_i) \quad (7.6)$
```

is obviously reasonable, because the read that underlies A does not stem from the region to be genotyped, computation of $P(G_i \mid A^+)$ requires further reasoning based on the type of evidence that A can provide about $G_i$.
