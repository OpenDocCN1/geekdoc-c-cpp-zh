1.4.3.4 SNP Detection SNP used to scan for single-nucleotide polymorphism (SNP), which is a DNA sequence variation occurring commonly within a population. A single nucleotide in the genome is defined as SNP when it differs between members of a biological species or paired chromosomes. These genetic variations are considered to be associated with many genetic diseases (56, 57).
