## 3.2 大量病毒数据的池设计

测序 $n$ 个样本的重叠策略的基本思想是生成 $m$ 个池（即样本的混合物），其中 $m \ll n$，使得每个样本通过其所属的池被唯一识别 (23)。然后，在对池进行测序后，获得的意见读数可以通过池的集合交集和差集序列分配给样本。这两个示例表明，可以使用较少的池来识别较数量的样本。

**示例 1。** 考虑三个样本 $S_1, S_2, S_3$ 和两个池 $P_1 = S_1 \cup S_2, P_2 = S_2 \cup S_3$（见图 3.2）。这些池满足分离要求，因此每个样本都可以恢复，例如，$S_2 = P_1 \cap P_2, S_1 = P_1 \setminus P_2$ 以及 $S_3 = P_2 \setminus P_1$。因此，对三个样本进行池化需要两次测序运行。

如果两个样本被一个池分离，那么包含样本 $S$ 的所有池的交集减去包含 $C$ 的所有池的并集等于 $S$。相反，如果两个样本 $S_1$ 和 $S_2$ 不被任何池分离，则无法通过集合运算将它们区分。这一事实导致了所述高效池设计方法。

**定理 [23, 32]。** 如果样本的任意子集都可以形成单个池，则可以使用 $m = [\log(n)] + 1$ 个池重构 $n$ 个样本。

**证明。** 为了简单起见，假设 $n$ 是 2 的幂，即 $n = 2^k$（对于任何 $n$，证明是类似的）。然后应用归纳法：如果 $k=1$，则 $P=\{\{S_1\}, \{S_2\}\}$ 显然是一个有效的池设计，$m=2$。假设 $P' = \{S'_1, \dots, S'_{m'}\}$ 是关于样本 $S'$ 的有效池设计；$n'=n/2=2^{k-1}, m' = \log(n') + 1$。构造如下族 $P=\{P_1, \dots, P_{k+1}\}$：

$P_i = \{S_{2j-1}, S_{2j} : S'_j \in P'\}, \quad i=1, \dots, k$;
$P_{k+1} = \{S_1, S_3, \dots, S_{n-1}\}$。

该族 $P$ 是一个有效的池设计。事实上，显然 $\bigcup_{i=1}^{k+1} P_i = S$。由于 $P'$ 是 $n'=n/2$ 的可行池设计，对于每个 $i, j \in \{1, n/2\}, i \neq j$，存在 $l \in \{1, \dots, k\}$ 使得 $P'_l$ 分离 $S'_i$ 和 $S'_j$。
