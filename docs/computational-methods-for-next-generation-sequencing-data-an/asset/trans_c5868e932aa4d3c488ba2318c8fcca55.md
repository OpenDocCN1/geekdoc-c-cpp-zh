RNA-seq技术使得能够在mRNA水平对基因的功能和调控进行全基因组研究，包括表达分析、替代剪接的识别与定量以及基因融合事件的识别。RNA-seq产生的数据允许对单细胞的转录组进行分析，达到了前所未有的分辨率。对于表达分析，RNA-seq也被视为传统微阵技术的替代方案。
