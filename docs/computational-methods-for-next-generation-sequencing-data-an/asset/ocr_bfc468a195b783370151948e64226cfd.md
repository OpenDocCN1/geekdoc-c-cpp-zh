In general, one of the main goals of differential expression (DE) analysis is to identify the differentially expressed genes between two or more conditions. Such genes are selected by combination of expression level threshold and expression score cutoff, which is usually based on p-values generated by statistical modeling. The expression level of RNA unit is measured by the number of sequenced fragments that map to the transcript, which is expected to correlate with its abundance level.

The outcome of DE analysis is influenced by the primary analysis (mapping, mapping parameters, counting) is counted (30). In addition, the overall library preparation protocol and quality is also an important factor of bias (31–33). As described in the following chapters, DE analysis methods differ in how to deal with these pre-analysis phases. Furthermore, RNA Seq experiments tend to be underpowered (too few replicates) and we need methods to perform DE under these circumstances.
