The mapped reads are used to generate a set of all possible exons and thus possible splice junctions between neighboring exons within a distance, which would depend on the genome of interest, and the previously unmappable reads are then aligned to this collection. Transcripts, isforms, and their expression levels can be derived from these two sets of alignments. On the other hand, de novo assembly, the reads are assembled into contigs without any prior assumptions about annotation or splice junctions, these contigs themselves represent transcripts. Expression values for a given data set can then be derived by the coverage of these contigs, de novo assembly is valuable for organisms with well-annotated reference genomes as this can allow either for discovery or for a more accurate assembly of a transcriptome from a nonreference isolate of species, which may be diverted at the sequence level from a sequenced genome and annotation. de novo assembly is essential for the analysis of many nonmodel organisms for which neither exists nor the genome is of poor quality.

Based on alignment methodology, the reference-based assemblers are grouped into two major categories, namely hash-table or prefix/suffix mapping algorithms (24). In the hash-table-based approach, each reads or reference can be indexed. Reads indexed in assemblies such as MAQ (25), RazerS (26), RMAP (27) while BFAST (28), Genomapper (29), Mosik (30), and Novoalign (31) are some examples where the reference is indexed. Linder and Friedel (the Reference 32) have done a comprehensive evaluation of alignment algorithms in the context of RNA-seq and concluded that FM-index (a compressed full-subring index) based algorithms performed the hash-based approach in run-time or in memory requirement. Therefore, we will consider only the RNA-seq assemblers of tools, including bowtie (33) or Bowtie2 (34). The Tuxedo suite (10) is used successfully for reference-based RNA-seq assembly. Tophat2 is the most recent release of Tophat that uses Bowtie2 for alignment, whereas Bowtie was implemented in the older releases of Tophat (35). SpliceMap (36) is another assembler that uses Bowtie for alignment onto reference genome and across splice junctions. In this report, we compare these two widely used reference-based assemblers for their ability to reconstruct the transcripts from the reads while minimizing the discovery of false ones. To compare the efficacy of de novo assembly, we will assemble the same collection of reads with the SOAPnovo (37) and Trinity (38), which are among the few often used and well-cited of de novo assemblers. Importantly, all of the analysis tools we use in our comparisons are freely available, and a list of such tools for NGS analysis along with those we have used in this work is posted at www.cas.louisiana.edu/labs/bioinformatics/ngs_os.html.
