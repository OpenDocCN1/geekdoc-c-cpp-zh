# 38 COMPUTATIONAL METHODS FOR NGS DATA ANALYSIS

# 2.3.4 ePGDB Construction

Pathway-centric approaches that predict metabolic networks using defined rules offer a more robust route for quantitative and predictive metabolic insights. Recently, pathway prediction and metabolic flux algorithms have been developed for microbial communities including the Human Microbiome Project Unified Metabolic Analysis Network (HUMANN) and Predicted Relative Metabolic Turnover (PRMT), respectively. The HumanN combines gene prediction with MinPath (88), a parsimony approach for metabolic reconstruction based on KEGG pathway mapping (http://www.genome.jp/kegg/) (12, 65). PRMT predicts metabolic flux using KEGG pathways across multiple metagenomes (nine). Neither HUMANN nor PRMT scalable data processing steps need to annotate large data sets, and neither offers a coherent data structure for exploring and interpreted metabolic pathways. In addition to HumanN and PRMT, alternative algorithms for metabolic flux modeling within engineered microbial consortia are emerging although their application to environmental sequence information remains to be defined (90, 91).

MetaPathways uses Pathway Tools, a quality-control software environment developed at SRI that supports Pathway/Genome database (PGDB) construction (41, 42). The PGDB contains information on genes, reactions, and pathways that define metabolic and regulatory networks within individuals. The Pathologic algorithm implemented in Pathway Tools allows users to construct new PGDBs from an annotated genome using MetaC (http://metacy.org/) (43, 44), a highly curated, nonredundant, and experimentally validated database of metabolic pathways representing all domains of life. Unlike KEGG or SEED subsystems, MetaC emphasizes smaller, evolutionary conserved or co-regulated units of metabolism and contains the largest collection (over 2000) of experimentally validated metabolic pathways (68). Navigable and extensively commented enzyme properties, pathway descriptions, and literature citations combined within a PGDB provide a coherent structure for exploring and interpreting metabolic networks. Although MetaPathways extends the PGDB concept to environmental sequence information enabling PGDB construction compatible with the editing, search, and navigation features of Pathway Tools (39).

MetaPathways concatenates ORFs into a single "chromosomal" element as input to Pathologic. Gene product descriptions are also harmonized across different protein databases using a scoring system based on keyword and valid EC numbers to improve prediction performance. When constructing PGDBs for cellular organisms, Pathologic uses a process called taxonomic pruning to constrain pathway predictions within a curated range. Thus, inferring a pathway in a bacterium that is constrained to animals is contraindicated. Although this improves prediction accuracy for individual genomes of known origin (92), it severely underestimates the metabolic potential of microbial communities composed of many interacting taxa (3). MetaPathways disables taxonomic pruning by default opening ePGDBs to the structural and functional diversity of microbial communities.
