# 92 COMPUTATIONAL METHODS FOR NGS DATA ANALYSIS

```
Algorithm VGA Assembly Algorithm (5)
**Input:** Set of reads R aligned to the consensus genome
Build conflict graph G = (V, E) from set R
Recursively color G into color classes $C$ using Max-Cut
Initialize the set of viral genomes $\mathcal{V}G \leftarrow \emptyset$
**for** each color class $c_i \in C$ **do**n  Compute maximal independent set in $G = (V, E)$ containing $c_i$
  Assemble $c_i$ into viral genome $g_i$
  **if** $g_i$ covers all positions in the consensus genome **then**
    $\mathcal{V}G \leftarrow \mathcal{V}G \cup \{g_i\}$
  **end**
**end for**
**Output:** Set of complete viral genomes $\mathcal{V}G$
```

In Reference 5, we extend the previous EM and likelihood formulation to incorporate a prior probability for the viral population and compute the maximum a posteriori estimate under the MLE. Let $H$ be a random variable over the set of viral genomes $H = \mathcal{V}G$, and $R$ be a random variable over the set of reads $R$. Let $p[H] \sim \text{Dir}(\alpha_1, \dots, \alpha_{|H|})$ be the prior probability of observing a set of variants and define $p_h = 	ext{Pr}[H=h]$ to be the probability of observing a particular variant $h$. The probability of observing read $r \in R$ is given by marginalizing over all variants

> $$	ext{Pr}[R=r] = \sum_{h \in H} \text{Pr}[R=r|H=h] \cdot p_h$

where

> $$	ext{Pr}[R=r|H=h] = \begin{cases} 1/K_h & \text{if } r \text{ is consistent with } h \ 0 & \text{otherwise} \end{cases}$

and $K_h$ is the number of reads consistent with $h$. We can now define the log-posterior as

> $$\log \text{Pr}[H|R] = \sum_{r \in R} n_r \cdot \log \text{Pr}[R=r] + \sum_{h \in H} (\alpha_h-1) \log p_h - C_R$

where $C_R$ is a constant and $n_r$ is the number of reads $r$. As this function is nonconvex and difficult to optimize, we solve the easier problem of maximizing its lower bound,

> $$\sum_{r \in R, h \in H} n_{rh} \cdot \log (\text{Pr}[R=r|H=h] \cdot p_h) + \sum_{h \in H} (\alpha_h-1) \log p_h$

where $n_{rh}$ is the expected number of reads $r$ generated by variant $h$. The EM algorithm computes this by

> $n_{rh} = n_r \cdot \frac{\text{Pr}[R=r|H=h]}{\text{Pr}[R=r]}$
