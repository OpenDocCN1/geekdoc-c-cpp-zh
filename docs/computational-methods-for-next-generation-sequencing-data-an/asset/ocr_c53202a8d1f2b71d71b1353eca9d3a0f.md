# 3.2.1 Pool Design Optimization Formulation

Sequencing of heterogeneous RNA viral samples imposes the following restrictions on the pool composition: (i) the maximal number of samples that can be pooled without losing detection of minority viral variants; and (ii) undesirability of mixing samples with drastically different viral titers, which may be epidemiologically much harder. Here, we formalize these restrictions and formulate the optimal pool design problem as an optimization problem on graphs.

Let $S=\{S_1, \dots, S_n\}$ be a set of samples and $X \subseteq S$. The set $X$ separates samples $S_i$ and $S_j$, if $X$ contains exactly one of the samples, is, $|X \cap \{S_i, S_j\|=1$. Restrictions on the pool composition can be represented by a sample compatibility graph $G$ with $V(G)=S$ and $S_i, S_j \in E(G)$ if and only the $S_i$ and $S_j$ can be mixed in the same pool. So, every feasible pool is a clique of the graph $G$. Let $T$ be an upper bound for the pool size. The problem of the optimal pool design for sequencing of viral samples can be formulated as follows:

**Viral Sample Pool Design (VSPD) Problem.** Given a sample compatibility graph $G=(V,E)$ and a number $T>0$, find the set of cliques $P=\{P_1, \dots, P_m\}$ of $G$ such that $m$ is minimized

+   (1) $|\cup P_i|=V$;n(2) for every $u,v \in V(G)$ there is a clique $P_i \in P$ separating $u$ and $v$;n(3) $|P_i|\le T$ for every $i=1,\dots,m$.

Unlike the case when subset of samples can be a pool, the general VSPD problem is more challenging.

**Theorem [32].** Viral Sample Pool Design (VSPD) Problem is NP-hard, even for $T=3$.

**Proof.** We will reduce to VSPD with $T=3$, the following special case of the yes/no three-dimensional matching problem.
