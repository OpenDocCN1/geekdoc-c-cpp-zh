Another orthogonal approach is the circularization of ssDNA templates and rolling circle amplifications to long fragments that contain multiple copies of the same template. The individual copies of the same template on each read only differ in PCR and sequencing errors that can be corrected by calling the consensus sequence. # 16.2.4 Data Preprocessing and Read Alignment

Prior to viral haplotype reconstruction, reads must be filtered and aligned. The first step of data processing is the trimming of platform-dependent adapters and amplicon primers. For PacBio reads, this is not trivial, as most primers are degraded due to high error rate and partially clipped by consensus sequence generation. The next step involves qualitying of the reads from both ends, as quality drops at the read ends. Viral quasispecies reconstruction approaches are described the following on a high-quality alignment of the reads. This alignment can be produced with standard alignment methods such as BWA-mem against a well-known reference strain. Alignment artifacts, such as long soft-clipped reads and misaligned bases due to large distance to the reference, can be decreased by a progressive re-alignment strategy. In an iterative procedure, reads are aligned against a reference genome, a consensus sequence is generated, and reads are re-aligned against the consensus sequence.; the software package ConsensusFixer (42) is capable of performing this step. The alignment quality can be increased by pairwise-sensitive Smith-Waterman alignments of the reads with a reference genome. This process can be accelerated by *k-mer* matching of the reads with the reference to first find an approximate alignment region (43). Depending on the sequencing platform, different affine gap costs are required. Such sensitive Smith-Waterman alignment to a reference with ambiguous nucleotides, which tests multiple sets of affine gap costs to find an optimal alignment, is implemented in InDelFixer (44). In general, higher quality baseline alignment leads to better reconstruction results.

# 16.2.5 Spatial Scales of Viral Haplotype Reconstruction

Given the alignment of the reads, diversity estimation can be performed on different spatial scales (Figure 16.6). On the smallest scale, where only a single position of the genome is considered, position-wise diversity estimation detects SNVs; SNP calling assumes detection of co-occurring SNVs. Local reconstruction focuses on a genomic region that can be covered with a single read. For some applications, local reconstruction is sufficient, for example, the protease gene of HIV-1 with length 297 bp can be covered by Illumina reads.
