## 10.2 THE PROBLEM OF MAPPING BS-TREATATED READS

The first step in methylation analysis with BS-seq is mapping bisulfite-treated sequenced reads (hereafter called *reads*) back to the reference genome. In BS-reads mapping, potential matches of T in a read to C in a reference must be allowed in the usual mapping of C in a read to C in a reference. Moreover, BS-mapping must take into account distinct types of bisulfite libraries: the first type, *directional*, produced sequences that are bisulfite-converted versions of two original genomic strands (9) and the second type, *nonirectional*, yields that correspond to four possible strands resulting from PCR steps (5). Figure 10.1 shows the effect of BS conversion and subsequent PCR amplification. There are four strands of PCR: PCR⁺ PCR⁻, PCR*, and PCRᶜ. In directional bisulfite libraries, the addition of special adapters before bisulfite treatment ensures that only PCR⁺ and PCR⁻ corresponding to the original genomic strands are sequenced. The nondirectional libraries result in sequencing all four strands of PCR amplification.

Recalling that sequencing proceeds from the 5′-end toward the 3′-end. For paired-end reads, to produce the 3′-end of a strand with Illumina sequencing instruments, the 5′ end of the reverse-complement of the strand is sequenced. Figure 10.1 shows the paired-end sequenced reads resulting from all PCR strands. In single-end sequencing, only 5′ mates shown on Figure 10.1 are accurate. The order of mates in paired-end reads is essential for correct BS-mapping. We illustrate this by discussing the mapping approaches, in which sequenced reads are mapped directly to the positive strand of the genome, DS⁺ With directional bisulfite libraries, when the 5′ mate maps to DS+, only T-C mismatches are legal (i.e., T in a read is allowed to map onto C in the genome). For paired-end reads, the reverse-complement of the corresponding 3′ mate is mapped onto DS+ with T-C mapping, indicating the unmethylated status of the cytosine. It is important to emphasize that only one kind of BS-mismatches (either T-C or A-G, but not both) must be allowed per single alignment of a read to a reference; moreover, in paired-end alignment, mates must have the same kind of mismatches.

## 10.3 ALGORITHMIC APPROACHES TO THE PROBLEM OF MAPPING BS-TREATED READS

The most time-efficient methods for mapping short reads either use hashing or data structures based on the Burrows-Wheeler transformer or BWT (16) to reduce the search space. As mentioned earlier, BS-mapping introduces additional challenges because BS-treated reads do not match exactly due to conversion of cytosines to thymines. To allow for a T in read to match a C in the genome (hereafter called BS-mismatches), different approaches have been introduced, all of which could be summarized into two categories: (i) all combinations of conversion of Ts to Cs are considered; (ii) reference/read conversions are applied. First, we discuss how these approaches are used with hashing and then consider methods using BWT.

In hashing and BWT, letters A, C, G, and T are converted to the corresponding representations 00, 01, 10, and respectively. For the purpose of reducing search space, it is practical to first identify genomic regions from which each read was oriented. A seed of length k of a read (also a k-mer or q-gram) is hashed from a reference into a table: the binary representation of a seed is used as the hashing index, and the genomic position of the seed is stored in the corresponding bin. For each read, a set of its seeds is hashed into the table and the read is aligned to only those genomic positions that share with the read. To allow for BS-mismatches, some tools use all combinations of Ts to Cs and use both genomic strands; for instance Verjinker (17), BMAP (18), Pash (19), and BISS (20). This method preserves the genomic complexity, but introduces a large number of candidates affecting time efficiency. To reduce search space, some tools (e.g., Pash) use heuristics that verify the distance between the genomic positions, to which different seeds of a read have been used, and keep only those candidate positions that are within appropriate distance from each other.
