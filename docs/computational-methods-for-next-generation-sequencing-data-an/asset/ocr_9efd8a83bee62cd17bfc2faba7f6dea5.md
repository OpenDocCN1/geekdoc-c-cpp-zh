# 8.2.3 Methods for Discovering Long Indels with Exact Breakpoints

To call SVs with exact breakpoints, AS and SR methods could be used. De novo assembly methods may need higher read coverage than SR method, but though of the NGS technologies is increasing constantly. The sequences of long insertions are already known when called with AS methods. AS methods usually require computational resources (especially memory). On the other hand, SR methods could be faster and require less memory if implemented properly. We will not describe particular reads de novo assembly is an interesting problem on its own. We will give more detail about an SV calling tools that use split-read mapping algorithm, called Pindel (16).

8.2.3.1 Pindel is first introduced in Reference 16, which was an SR method that calls long deletions and medium-sized insertions. The SR method of Pindel is implemented as a pattern growth subst method, which can be used to find minimum and maximum unique substrings of a pattern P in a reference sequence S. Suppose the reference is "ATCAATGATGTACT" and the pattern is "ATGCA". First, the locations of all "A" are searched and noted. In this case, they are 1,4,5,8,14. Then T is searched at the base of these locations, then T is the second of the pattern. Keeping searching this way, "ATGC" is unique at location 8, but "ATGCA" is not a substring, "ATG" is the minimum unique substring and "ATGC" is the maximum unique substring.

To call indels, Pindel uses paired-reads that only have one end mapped as whole read, and the unmapped end as split reads using the above method. Instead of mapping split reads to the whole genome, Pindel uses a threshold of maximum event size, that is, mapping 5' of a split read within the threshold of the mapped 3' of a split read. Smaller threshold makes the procedure faster and take less memory. More importantly, using threshold makes the SV calling more accurate, less false positive (FP) hits expected in a smaller region. However, there might be a case that extremely large SVs are lost, although those SVs may be rare. Also, a cutoff value on number of reads supporting the same SV is used by Pindel so that the final list is more.

The signatures of SVs can be found by applying the procedure of split-read mapping using pattern growth. We have shown the SR signature of long deletions. For medium insertion, the sequence reads with a portion in the middle not mapped, but the segments at 5' and 3' are mapped and stitched together. Since its first release, Pindel has been updated: new features include mapping allowing sequencing errors, calling more types of SVs as translocations and so on.
