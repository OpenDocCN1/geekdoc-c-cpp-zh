# 16.3.1.1 Efficient Human Phasing Algorithms

Apart from probabilistic modeling, one approach to human haplotype inference has been formulated with respect to the evolutionary history of a set of haplotypes, the population-genetic concept of coalescent (47). Given a single haplotype site of one individual, its history can be traced back in an acyclic graph to the site of one parent haplotype. This means that the history of two haplotypes at one site merges at one of their most recent ancestor. Under the infinite-sites assumption and without recombination, the coalescent model says that 2n haplotypes of 2n individuals can be displayed as a tree with 2n leaves m edges representing the individual sites. If haplotypes are binary and the root is labeled as a binary sequence, the tree displaying the evolution of the haplotype is called perfect phylogeny. The perfect phylogeny problem is to find the set of explaining haplotypes for a set of genotypes. Various part phylogeny methods have been developed (48–50) and it has been first introduced and solved in Reference 51.

The first probabilistic models in human haplotype belonging to the “gene cutting” models (52–56). These models compute the maximum likelihood estimate of haplotype frequencies from multilocus, unphased genome count data via an expectation maximization (EM) algorithm. This approach provides haplotype frequencies that can be used to compute the most likely pairing of haplotypes for a given genotype.

The maximum likelihood approach can be regarded as a special case of Bayesian inference with a flat prior for the haplotype frequencies, that is, all haplotypes are equally likely. An informative prior for a guided inference process has the potential to solve factors that respect an underlying genealogy and to estimate of the haplotype frequencies in the software PHASE (57), which provides better results than its predecessors, the speed of convergence is slow for whole-genome data. To achieve the run-improvement in Reference 58, the partition–ligation strategy (54) has been adopted. A genomic region is split into multiple smaller regions. Haplotype inference is performed on adjacent regions individually. Using the current parameter estimates, adjacent haplotypes are allowed to merge into a larger haplotype.
