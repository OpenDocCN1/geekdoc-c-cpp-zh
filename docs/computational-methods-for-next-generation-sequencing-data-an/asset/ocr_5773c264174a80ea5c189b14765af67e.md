However, in addition to a possible use of error correction algorithms, such methods can be extremely useful in a pipeline with clustering-based or k-mers-based algorithms as post-processing for data previously cleaned by these algorithms, when the number of unique reads and sequencing errors is greatly reduced, but a significant number of errors still remain.

Two alignment-based methods were proposed in Reference 15. The first of these methods is described in "KEC postprocessing using alignment" algorithm. In Reference 15, it is used as a postprocessing step for KEC algorithm described in the previous section. It corrects errors and performs local haplotypes reconstruction, that identifies haplotypes and their relative frequencies.

The second algorithm (15) uses empirical frequencies for indels and haplotypes obtained from a parameter calibration based on experimental sequencing for artificially created single-clone sets with known clone sequences. An indel is defined as the maximum frequency of erroneous indels in single-clone data sets, and a haplotype frequency threshold is estimated as the weighted average frequency of erroneous haplopes + 9 standard deviations. For instance, for 454/Roche GS FLEX platform and HCV1 region, the indel and haplotype thresholds were estimated as 5.9% and 0.4%, respectively (15). Et work consists of the following steps:

+   (1) External 'references' alignment and length filtering. Each unique read is aligned against a set of external references for the sequenced genomic region. For each read, the best set of reference of the length L is chosen, and reads with lengths less than 0.9L are deleted and reads with lengths greater than L are clipped to the set of the corresponding reference.

+   (2) Internal references' alignment. Internal reference set is constructed by selecting 20 most frequent reads with minimal numbers of indels with regard to the external references. Each read is aligned against the internal reference set and the closest internal reference is chosen.

+   (3) Homopolymer errors' correction. Using alignments to internal references, homopolymers of at least 3 are long and indels in homopolymers are corrected. Multiplicities of reads are recalculated.

+   (4) PCR or sequencing artifacts' removal. Using the internal reference, the number of indels in each read is calculated and reads containing at least T indels are discarded, where T is the weighted average of the number of indels in the data + 4 standard deviations.

+   (5) Indel threshold and NS filtering. Reads that contain frequencies lower than the indel threshold are discarded. After that reads containing NS are also discarded. The latter step is performed at one of the latest stages of the algorithm to take advantage of the nucleotide frequencies at positions other than those with N.

+   (6) Haplotypes frequencies filtering. Haplotypes with frequencies lower than the haplotype frequency threshold are removed.
