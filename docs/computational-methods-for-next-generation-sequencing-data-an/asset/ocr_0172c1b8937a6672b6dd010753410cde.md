# 14.5.1.2 Results on Real Data For the real data set, we assayed sets of human genes using MAQC, Human Brain Reference (HBR) sample (36), and NanoString nCounter amplification-detection system (18).

For MAQC, we correlated (1) results using the Taqman qRT-PCR values for NanoString we used the probe counts provided in Reference 18. Since Taqman data qRT-PCR and NanoString counts only measure the expression levels of genes and probes, respectively, we only compare gene (probe) abundance estimations. The expression level of a gene (probe) is found by summing the frequencies of all counts in the gene (probe). For both data sets, we have used the Ensembl Homo sapiens genome sequence indexes (GRCH37) provided by Illumina.

There are 2 × 50 bp paired-end sets for Human Brain in SRA in MAQC data. The average insert size is 200 bp and the standard deviation about 30 bp. In NanoString data set, we have paired-end reads of length 75 bp and similar characteristics as MAQC (more details can be found in References 18, 42).

In order to compute the 95% confidence interval (CI), we performed bootstrapping by randomly choosing reads from the given set and returning samples to the pool. As a result, our chosen subsample may contain several copies of the same reads, whereas some reads are never chosen. We repeat resampling procedure 200 times. For each sample we computed MPE and r² for Cufflinks (v2.2.0), RSEM (v1.2.19), and SimReg and found how many times our estimates are better than RSEM (since RSEM shows best performance compared to the other tools).

The results presented in Table 14.3 (1) show that SimReg has accuracy comparable to that of RSEM on the MAQC data set but outperforms RSEM in both MPE and r² on the NanoString data set. Mean percentage error of SimReg is less than that of RSEM in 90.5% of cases.

All experiments were conducted on a Dell PowerEdge R815 server with 2.5 GHz, 16-core AMD Opteron 6380 processors and 256 Gb, RAM running under Ubuntu 12.04 LTS.

SimReg is freely available at http://alan.cs.gsu.edu/NGS/?q=adrian/simreg
