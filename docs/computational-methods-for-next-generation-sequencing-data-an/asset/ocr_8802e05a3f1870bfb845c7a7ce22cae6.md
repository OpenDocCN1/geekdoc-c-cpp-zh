IsoDE experiments on the MCF-7 dataset performed as follows. First we generated, for each of the 7 replicates of each condition 20, 10, 6, 5, 3, respectively 2 bootstrap samples. We used subsets of these bootstrap samples as input for IsoDE perform DE analysis with varying number of replicates and a fixed total M = 20 of bootstrap samples per condition. In experiment 1 we used 20 bootstrap samples from first replicate of each condition, in experiment 2 we used 10 bootstrap samples for each of the first 2 replicates of each condition, and so on.
