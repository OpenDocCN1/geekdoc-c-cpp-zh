## 8.2.2 Methods for Discovering Long Indels without Breakpoints

Starting from this section, we will give several examples of SV calling tools that implemented certain signatures discussed in the previous section. In this section, we will cover an RD method CNVator (8), which calls copy number variations (CNV). A long deletion is a loss of copy and a long insertion is a gain of copy. We will cover BreakDancer (9), an RP method. There are more RD methods, for example, References 10–12 and more RP methods, for example, References 13–15.

### 8.2.2. CNVator

CNVator is one of the tools that use RD to discover CNVs from family and population genome sequencing. The main idea of this approach is based on the observation: RD for CNVs is different from that of normal regions, which is also the main observation of all RD-based approaches. One of the techniques CNVator uses is called mean-shift approach. This approach is borrowed from image processing technique, and it presents an elegant way to locate the density maxima without having to estimate the density directly, which is an iterative procedure that shifts each data point to the density maxima along the mean-shift vector. CNVator combines the mean-shift approach with additional refinements to extend the range of discovered CNVs, which are obtained from the initial RD. Detailed implementation of CNVator includes three steps:

First, CNVator calculates the RD for each bin and correct GC-bias. It maps to genome (which is divided into consecutive non-overlapping bins), and if a read (or read pair with concordant mapping distance) can map to more than one position with equal mapping score, it randomly picks one (or a pair) to get unique RD. Then GC-bias is corrected to eliminate the correlation of RD with GC content.

The second step is mean-shift based segment partition and merging, which is the key step of approach. As mentioned earlier, the mean-shift technique is borrowed from image processing to detect edges in computer vision. And using mean-shift approach to participate genome, each bin is viewed as a point, and mean-shift vector of each point is calculated with the direction pointing to bins with the most similar RD signal. Segment breakpoints are determined where two neighboring vectors direct oppositely but do not point to each other. Then, neighboring segments are merged if their RD signal difference is less than one-quarter of the genomic area.

The last step is CNVs calling. At first, segments with a mean RD signal deviating by least a quarter from genomic RD signal are selected, and regions with p-value by a t-test less than 0.05 is called. Then, call additional ones by performing a one-sided test that all RD signal within a segment are smaller than the maximum RD signal within the segment.

Experiment results on data from the 1000 Genomes Project (reads length 36) show that CNator is able to achieve high sensitivity (86-96%) with false-discovery rate 3-20%, and high resolution in breakpoint discovery (< 200 bp in 90% of cases with high sequencing coverage). However, CNator is sensitive to read length, and for constant coverage, as read length increases, less reads will be generated, which will degrade the sensitivity. Also, longer reads are more difficult to be fully mapped around the breakpoints. Thus, it is harder for CNator to call small CNVs. Therefore, RD-based approach is useful for CNVs discovery, but still has its limitations.

### 8.2.2.2 BreakDancer

BreakDancer is one of the first RP-based computational approaches. It is designed for the genome-wide detection of five types of structural variants, including deletions, insertions, inversions, and intachromosomal and interchromosomal translocations. It takes paired-reads as input. If both single-ended and paired-ended reads are given, only the paired-ended ones will be used for further analysis.

First, BreakDancer tallies the anomalous read pairs. Types of structural variations have different anomalous patterns on paired-reads, as explained earlier. According to these different patterns, algorithm tries to locate a set of anomalous regions and identify connected clusters. Different SV types are considered. Each region should have more anomalous read pairs than expected by chance. This allows BreakDancer to filter some false variants due to sequencing and mapping errors.

A structural variant is then considered to derive from a set of regions, each of which connects via another anomalous read pair. For example, BreakDancer uses a preset threshold of at least two anomalous read pairs. Compared to average coverage, the more supporting the region(s), the stronger statistical signals are obtained. BreakDancer applies a statistical test, called confidence score estimation, to quantify the underlying error probabilities of each potential structural variant. This test assumes that the genomic locations of each type structural variant follows a uniform distribution. For each pair of adjacent sites, the probability of harboring a structural variant follows binomial distributions with each component representing one of the insert types. On the scale of genome-wide, the probability of multiple structural variants locating at a particular site follows mixture of Poisson distribution.

In practice, BreakDancer suggests to define three types of inserts: long, medium, and short that are measured according to preset thresholds. The identification process is to find the regions that contain significantly more inserts and insertions from regions that contain significantly short inserts via the Poisson test.
