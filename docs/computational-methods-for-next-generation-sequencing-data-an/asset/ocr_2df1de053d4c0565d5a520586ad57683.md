# 1.4.3 Software as a Service (SaaS)

SaaS provides on-demand software as web services and facilitates remote access to data analyses in various types. The analysis of NGS involves many biological issues, such as sequence mapping, sequence alignment, sequence assembly, expression analysis, sequence analysis, ontology detection, functional annotation of personal genomes, detection of epistatic interactions, and so on (25). SaaS eliminates the complicated of local deployment, simplifies software maintenances, and ensures up-to-date cloud-based services for all possible users with access to the Internet. Since it is impractical to cover all cloud-based NGS data analysis tools available nowadays, four representative categories are carefully selected to elaborate the thinking in the cloud for solving problems that arise from NGS data.
