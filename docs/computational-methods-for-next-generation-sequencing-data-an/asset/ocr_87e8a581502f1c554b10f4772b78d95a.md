# 4.4 PERFORMANCE OF VGA ON SIMULATED DATA

Since the ground truth is unknown for sequenced viral populations, in Reference 5 we used simulations as a standardized way to assess the performance of viral assembly tools. The high-fidelity protocol allows to correct sequencing errors, giving access to highly sequencing data. Post-sequencing error correction techniques are available for reads obtained by regular protocol offering the possibility to partially correct sequencing errors trading off for real biological mutations. Grinder (29) is used to generate reads from both the high fidelity and regular sequencing protocol. Reads are generated from both real and synthetic viral variants with different sequencing parameters and viral expression profiles. Grinder is a state-of-the-art sequencing read simulator to avoid shotgun sequencing data from a viral population. We mapped the simulated paired-end reads to the consensus using Mosaik (30). The consensus was constructed using Vicuna (a de novo assembly assembly tool to produce a linear consensus from deep paired-end sequencing data without errors. See Section 4.3 for details).

In Reference 5, we use sensitivity and positive value (PPV) to evaluate the quality of viral genomes assembled by VGA. We consider fully assembled viral quasispecies that match true quasispecies, is, *Sensitivity = TP/(TP + FN)*, that is, PPV is defined as the proportion of true sequences among assembled quasispecies, that is, PPV = TP/(TP + FP). Additionally, we evaluate the ability of our method to estimate population size (i.e., number of viral genomes in the population). Accuracy of population size prediction is defined as a ratio between estimated and true population sizes. Finally, we use Jensen-Shannon divergence (JSD) to measure the “distance” between them, or in words, the quality of approximation of one probability distribution by the other. It is defined as the Kullback-Leibler divergence from distributions $P$ and $Q$ to their mixture. Formally, the JSD between true distribution $P$ and approximation distribution $Q$ is given by the formula

```
$JSD(P||Q) = \frac{1}{2}D_{KL}(P||M) + \frac{1}{2}D_{KL}(Q||M)$
```

where Kullback–Leibler divergence $D_{KL}$ is

```
$D_{KL}(P||Q) = \sum_{i=1}^n P(i) \log \frac{P(i)}{Q(i)}$
```
