Instead, in Reference 5, we apply an alternative “top-down” approach of recursive graph partitioning along the maximum cut (Max Cut), which has been successfully applied for human haplotyping (26). Given a graph G=(V, E), the Max-Cut problem asks for partitioning of the vertices into two components V₁ and V₂ maximizing the total number of edges, which one endpoint in V₁ and the other in V₂. The Max-Cut problem though NP-hard is well approximated by a 0.5 approximation algorithm, which randomly assigns vertex to one of the two components (27). Our Max-Cut heuristic starts with assigning left-to-right sorted reads to two components and repeatedly moves one vertex at a time from another, improving the solution at each step, until no more improvements of this type can be made.

Our heuristic recursively partitions the graph until each component becomes independent (Figure 4.2c). If reads of a graph completely cover the genome, the resulting sequence is accepted as the next viral genome. Otherwise, if assembled genome contains gaps, we nonconflicting reads from other colors in left-to-right order to fill the gaps (Figure 4.2d). If all SNV positions are covered, then a newly reconstructed viral genome is added to the set VGA. Finally, the genomes whose gaps cannot be filled with the above procedure.

> **Figure 4.2** Overview of VGA (see Reference 5), (a) The algorithm takes as input paired-reads that have been mapped to the population consensus. (b) The first step in the assembly is to determine pairs of conflicting reads that differ SNVs in the overlapping region. Pairs of conflicting reads are connected in the “conflict graph.” Each read has a node in the graph, and an edge is placed between each pair of conflicting reads. (c) The graph is colored into a minimal set of colors to distinguish genome variants in the population. Colors of the graph represent independent sets of nonconflicting reads assembled into genomes. In example, the conflict graph is minimally colored with four colors (red, green, violet, and turquoise), representing individual viral genomes. (d) Reads of the same color are then assembled into individual viral genomes. Fully covered viral genomes are reported. (e) Reads are assigned to assembled viral genomes. Read may be shared across two or more viral genomes. VGA infers relative abundances of viral genomes using the expectation-maximization algorithm. (f) Long conserved regions are detected and phased based on expression profiles. In this example, red and green viral genomes share a long conserved region(colored in black). There is no direct evidence how the subgenomes across the conserved region could be connected. In this example, four possible phasings are valid. VGA uses the expression information of each genome to resolve ambiguous phasing.
