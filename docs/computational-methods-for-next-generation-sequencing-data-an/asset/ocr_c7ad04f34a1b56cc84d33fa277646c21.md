# 4.3.2 Reads Mapping

As with many viral population analyses, the first step is to map the reads to the map (Figure 4.1e). We map reads onto the *novo* consensus using InDelFixer (21) with default parameters. False read alignments were filtered out using fragment length distribution from the mapping data. Assuming that the fragment length follows a normal distribution (22), we only keep reads with fragment length within three standard deviations from the mean. In total, 1.2% of reads have been filtered out versus expected 0.3% due to the three-sigma rule.

# 4.3.3 Viral Genome Assembly (VGA)

In Reference 5, we introduce a viral population assembly method (Figure 4.2) working on highly accurate sequencing data to detect rare variants and tolerate conserved regions across the population. The method includes a postassembly procedure to detect and resolve ambiguity from long conserved regions using expression profiles. After a consensus has been reconstructed directly from the sequence data (Figure 4.2a), our method detects SNVs from aligned sequencing reads. Read overlapping is used to link individual SNVs and distinguish between genome variants in the population. The viral population is condensed in a conflict graph built from aligned sequencing data (Figure 4.2b). Two reads are originated from different genomes if they share SNVs in the overlapping region. Viral variants are identified as independent sets of nonlicting reads. Noncontinuous coverage of rare variants may limit assembly capacities, indicating that increase in coverage is required to increase the assembly accuracy. Frequency of identified variants are estimated using an expectation-maximization algorithm. Comparing with existing approaches, we are able to detect rare population variants while achieving high accuracy.

The viral population starts with determining pairs of mapped reads conflicting with each other in the overlapping region. The combination of deep coverage with high accuracy provides an unprecedented opportunity for estimating genomic diversity in a viral population. Following (23), we construct the conflict graph $G=(V, E)$ with vertices representing paired-end reads, that is, $V=R$, and edges connecting pairs of paired-ends.

Obviously, any true viral genome corresponds to a maximal independent set in the conflict graph (a maximal pair of nonadjacent vertices), although not every maximal independent set necessarily corresponds to a true genome. In Reference 5, we adopt a parsimonious approach requiring to cover the conflict graph with the minimum number of independent sets. This problem is equivalent to MIN-GRAPH-COLORING, which is NP-hard. There exists many heuristics for solving this problem (e.g., References 24, 25) based on greedy selection of a maximal independent set.
