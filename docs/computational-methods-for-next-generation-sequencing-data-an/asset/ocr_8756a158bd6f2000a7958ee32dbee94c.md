EULER-SR (37) corrects errors in a read $r$ of length $|r|$ weak $k$-mers
by solving the following optimization problem: find a sequence $r^*$, which contains
only solid $k$-mers (*solid sequence*) such that the edit distance $d(r, r^*)$ is minimal. This
can be solved using a dynamic programming as follows: Let $S_k$ be a set
of all solid $k$-mers. For any integer $i \leq |r|$ and $a \in S_k$, the score function $score(i, a)$ is
def as the minimum edit distance between a prefix of $r$ of length $i$ and all solid
strings, which has $a$ as a suffix. This function can be computed recursively with
this relation:

```
$score(i, a) = \min_{X \in\{A,C,T,G\}} \begin{cases} score(i-1, X \sqcup a_{k-1}) + 1, & \text{if } s_i \neq a_k; \ 0, & \text{if } s_i = a_k; \end{cases}\nscore(i-1, a) + score(i, X \sqcup a_{k-1}) + 1, (15.15)
```

where $X \sqcup a_{k-1}$ is connected to a character $X$ and the prefix of $a$ of length
k-1$, and the initial condition is $score(0,a) = 0$ for all $a \in S_0$. Solution of the
error correction problem corresponds to the optimal score $\min_{a \in S_r}} score(|r|, a)$.nThe optimal and the corresponding solid string can be calculated by finding a
shortest path between vertices with in-degree 0 and vertices with out-degree 0 in
a relation $G_{rel}$ with vertices connected to pairs $(i, a)$ $(i \in\{0, \dots, |r|\}$),
$a \in S_i)$ and to $(i_1, a)$ and $(i_2, a)$ being connected by an arc, if they belong
to the same recurrence relation with $(i_2, a_2)$ as the left-hand side.
