# 1.3.1 Overview of Cloud Computing

The general notions in cloud computing can be categorized into two types: cloud and cloud technologies. The cloud offers a large pool of easily usable and accessible resources that are scalable to allow optimum utilization (24). A fundamental basis of cloud technologies is virtualization, that, a single physical machine can hold multiple virtual machines (VMs). A VM is a software application that can load a single digital image of resources, often known as a system snapshot, and emulate a physical computing environment. In addition, a VM image can be duplicated, including operating system (OS) and its associated applications. The advent of virtualization, at any time point, a particular element in the cloud can be used by a certain user, while at other times the same element can be employed by other subscribers. There is no fixed-one-to-one relationship between the data or software or physical computing resources. The distinction between traditional computing and virtualization is shown in Figure 1.3. In comparison to the tradition computing, an extra virtualization management layer layer, Hypervisor, is placed between a physical machine layer and resource images layer. Hypervisor acts as a bridge to translate and transport requests from applications running on VMs to manage physical hardware, such as CPU, memory, hard disks, and network connectivity.

Cloud resources for NGS contain various services, including storage data, data transportation, parallelization of tools, and web services of the data analysis. Basically, cloud services for NGS data can be classified into four categories: Hardware as a Service (HaaS), Platform as a Service (PaaS), Software as a Service (SaaS), and Data as a Service (DaaS). More details of these services, including the definitions, cloud-based methods, and NGS applications, will be used in the next section. With the contributions from open source communities, such as Hadoop, cloud computing becomes more and more popular and practical in both fields of industry and academia. In brief, users especially software developers, can pay more attentions on design and arrangement of distributed subtasks for large data sets than for program deployment on the cloud.
