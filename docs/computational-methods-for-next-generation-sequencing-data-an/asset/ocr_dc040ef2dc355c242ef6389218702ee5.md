#  8.2.4 Combined Approaches

We have mentioned previously that there are two types of combined approaches of SV calling. One is combining the results of different tools that use single signature, and the other is combining signatures to all SVs. In this section, we focus on describing computational tools that use combined signatures. We will use a tool SVseq (20, 21) as an example of an SV calling that combine two signatures, namely, split read and read pair. Only the methods of long deletions are covered in detail in this section. The two signatures of long deletions are covered in Section 8.2.1.

Intuitively, calling long deletions (e.g., 1 Mbps) using split-read method is harder than calling shorter deletions. the segments of a split read might hit more locations of the reference genome by we need to search for larger region (e.g., 1 Mbps). At the same time, more FP reads need to be mapped to this. The signal of a split read is relatively weak. Also, mapping split reads in a larger region can be slower. However, if some encompassing reads that are supporting the TP split alignment, situation may improve. On the other hand, shorter deletions using read pair signature is harder, especially when read coverage is lower. For example, if the insert size of an encompassing read of a length of 60bp is 70bp longer than mean library size, this deviation is 50bp; by chance a large portion of reads in a library would have insert size larger than mean library size by it. However, if some spanning reads that support a deletion we are more confident about the deletion.

SVseq implies the ideas above. There are two versions of SVseq(1) and SVseq2 (21). Both versions combine split read and read pair signatures, but the way of combining the signatures. Note that SVseq is able to find the exact breakpoints of SVs since it use the split-read signature.
