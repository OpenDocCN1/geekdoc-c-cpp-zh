9.2.1.6 Saturation Test One of the most important questions in capture-based sequencing such as ChIP-seq, MedDIP-seq, and MBD-seq is whether sequencing is sufficient and if not, how much sequencing is needed. MEDIPS developed the idea that if sequencing is sufficient, a set of reads in the sequencing should be highly correlated to an independent set of reads.
