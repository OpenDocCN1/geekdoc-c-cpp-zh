```
map() :: (key1, value1) -> arraylist(key2, value2) (1.1)
```

The mapper is an initial ingestion and transformation to process input records in parallel. The mapper takes each data record in the form of key/value as input and outputs a collection of key/value. The design of key/value can be customized based on users' demand
The sorting & merging phase sorts the collection of key/value pairs from all mappers in order of the keys. The pairs with the same key are combined and passed to the same reducer.

```
reduce() :: (key2, value3) -> list (value3) (1.2)
```

The reducer acts as the aggregation and summarization that all associated records are processed together if necessary as a single entity.
