# COMPUTATIONAL METHODS FOR NGS DATA ANALYSIS

Regression-based estimation of $f'_T$ minimizes squared deviation

```
$(D_{R,T} \times F'_T - O_R)^2 = \sum_{R \in \mathcal{R}} (e_R - o_R)^2 \quad (14.3)$
```

between expected class frequencies $e_R$'s and observed read class frequencies $o_R$'s. Minimizing (14.3) is equivalent to the following quadratic program that can be solved with any constrained quadratic programming solver.

```
minimize: \sum_{R \in \mathcal{R}} \left( \sum_{T \in \mathcal{T}} d_{R,T} f'_T f_T - o_R \right)^2\nsubject to: \sum_{T \in \mathcal{T}} f'_T = 1$ and $f'_T \geq 0, \quad \forall T \in C \quad (14.4)$
```

14.3.1.3 Update Initial Estimates of Transcript Frequencies The obtained transcript frequency estimation $f'_T$ can vary from the true class frequency since the minimization of deviation is done uniformly. Deed, the deviation in frequency is minimized on the same scale for each read class while different read classes have different size, as well as contribute to different subsets of transcripts. Instead of estimating unknown coefficients, we propose to directly obtain $f'_T$ for which simulated read frequencies $S_R = \{s_R\}$ match the observed frequencies $O_R$ accurately enough as follows.

Until the deviation between simulated and observed read class frequencies is small enough, repeatedly

+   - simulate reads according to $F'_R$,\n- find deviation between simulated and observed reads, $\Delta_R = S_R - O_R$,\n- obtain read frequencies $C_R = O_R - \Delta_R/2$ corrected half-way in the direction opposite to the deviation,\n- update estimated transcript frequencies $f'_T$ based on corrected read class frequencies $\{C_R\}$.

Finally, the transcript frequencies $f'_T$s can be obtained from class frequencies $f_T$s as follows:

```
$f_T = \frac{f'_T/l_T}{\sum_{T' \in C} f'_{T'}/l_{T'}} \quad (14.5)$
```

14.3.1.4 Combining Transcript Frequency Estimates from all Connected Components Finally, we combine individual solutions for each connected component. Let $f_T^{glob}$ and $f_T^{loc}$ be the global frequency of the transcript $T$ and local frequency of the transcript $T$ in its connected component $C$. The global frequency can be computed as:

```
$f_T^{glob} = f_T^{loc} \times \frac{|R_C|}{\|}{\sum_{T' \in C} f_{T'}^{loc}/l_{T'}} \quad (14.6)$
```
