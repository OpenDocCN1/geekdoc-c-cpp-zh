The pseudo-code of the SILP2 NSDP algorithm for processing 3-connected components is given below. SILP2 is different from SILP1 in the else-instead of solving ILP for each of four possible combinations of assignments for $S_i$ and $S_j$ as in SILP1, ILP is solved only two times for combinations $S_i = 0$ & $S_j = 0$ and $ar{S}_i = 0$ & $ar{S}_j = 1$.

# Algorithm The Pseudo-Code of the SILP2 NSDP Algorithm for Processing 3-Connected Components.

```
1: STACK ← root of SPQR-tree
2: VISITED ← $\emptyset$
3: while STACK is not empty
4:   p ← STACK.pop(p)
5:   for each q of p
6:     if p not in VISITED
7:       STACK.push(p)
8:     end if
9:   end for
10: if p is root then
11:   $sol_{final}$ = SOLVE(p.skeleton())
12: else
13:   (i,j) ← getcut(p,parent(p))
14:   $sol_{00}$ = SOLVE(p.skeleton()), $S_i = 0, S_j = 0$
15:   $sol_{01}$ = SOLVE(p.skeleton()), $S_i = 0, S_j = 1$
16:   in parent(p), increase weights $A_{ij}^w$ and $D_{ij}^w$ by $sol_{00}$ and weights $B_{ij}^w, C_{ij}^w$ by $sol_{01}$.
17:   end if
18: end while
```
