When mapped to the reference genome, the alignments of these reads could have some characteristics different from the reads from regions without SVs. We call these characteristics as signatures. The categories of methods we mention utilize signatures. We focus on signatures of long deletions and long insertions in this section. To illustrate the concepts of signatures, we generate some small-scale simulated data. We generate only one type of NGS reads. In Figure 8.2, a paired-end read is generated with two strands from segment of the donor genome. The length is called insert size. Since we do not have the sequences of the entire donor genome, we do not know the insert size of paired-end. When the read is properly mapped, we use the distance of the two ends on the reference genome as insert size. The underlying assumption is that the donor genome has similar structure as reference genome within this region. For sequencing, for most of paired-end reads, the insert sizes calculated from read are reasonably accurate. Usually, the standard deviation of insert sizes is not very large. In our simulation, the reference genome is a random sequence of A, C, G. The donor genome is generated from the reference genome by removing bases from 250,000 to 251,000 and inserting random sequence of length 100 between 750,000 and 750,001. The setting is illustrated in Figure 8.1.

We generate paired-end reads from donor genome with 30x (coverage is average number of reads). In total, 30x coverage of data is also generated from reference genome. The reads are put together to simulate that sample is heterozygous with one copy of genome having SVs and other copy of genome being same as reference genome. The data set is then 60x coverage. Note that in practice, two sequences may have different coverage. We use this simplified simulation to illustrate basic concept. The reads of the data set are generated with tool simulation (https://github.com/lh/wgsim) with insert size, standard deviation, and read length to 500 and 100 respectively. Every reads are chosen to be default. The data set is very ideal compared with real situation, but suffice to show signatures. The reads are mapped by BWA with default parameters. We can view alignments using IGV (6).

## COMPUTATIONAL APPROACHES FOR FINDING INSERTIONS AND DELETIONS

Figure 8.3 shows the region of long deletion and 8.4 shows the region of long insertion. From Figure 8.3, we can see that the coverage at reference:250,001–251,000 (the deletion) is only half of that at other coordinates (without SVs). This is because only one copy of genome of the sample has the sequence from 250,001–251,000 and we sequenced with 30x. The regions without SVs are sequenced with 60x coverage, 30x for each copy. So one signature of long deletion using NGS results is that the coverage of the deletion is smaller compared with regions without SVs. Ideally, for organisms with two copies of genome, if the deletion is heterozygous (in both copies of genome) then the coverage is about 0. This is the read depth (RD) signature. For real data, the RD signature can suffer from several aspects. Reads may be generated not as evenly as simulated data. Coverage at different locations of same copy of genome can fluctuate. Coverage from the two copies of genome at same location can be different. Sequencing and mapping errors may add false-positive reads to the region and remove true-positive reads from the region. Also, not every set has high coverage. Therefore, it may happen that the coverage drop at the location of deletion cannot be reliably detected from background fluctuation of coverage. Moreover, number of copies of genomes is not necessarily two. Some organisms have more.

In 8.3, some reads are marked with colors. The ones with red are very important for the purpose of calling deletions. They are marked with red because the insert size of these reads is significantly longer than expected. As mentioned earlier, we expect the insert size of paired-end read to be similar to the library insert size. The simulated data sets use the mean insert size of 500, but those reads marked with red apparently have much longer insert sizes. The values are larger than 1000, since they are out of the region of 250,001-251,000. Recall that the insert size of these reads is about 1500, which is the size of the deletion plus the mean insert size. The reason for the longer insert sizes is illustrated in Figure 8.5. The read is from a segment of sequence that spans the breakpoint. The length of the segment follows an assumed normal distribution whose mean is the library insert size.
