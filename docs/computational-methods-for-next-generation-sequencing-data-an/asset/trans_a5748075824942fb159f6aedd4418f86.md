**9.3.1 甲基化定量** CpG 位点的甲基化水平被定义为 beta 分（beta score）。对于具有 $m$ 个甲基化（CpG）reads 和 $u$ 个甲基化（TpG 或 CpA）reads 的 CpG 位点，beta 分为 $m/(m+u)$。为了获得高质量的甲基化图谱，会对胞嘧啶碱基质量较低的 reads 应用多种过滤方案，例如质量低于 10；如果 reads 的比对质量较低（例如低于 10）；或者 CpG 的 reads 深度较低（例如低于 6）。在图 9.10 中，由于第三个 CpG 在所有 reads 中都是 Ts，因此其 beta 值为 0，而第四个 beta 值为 3/3 = 1。

由于相邻的 CpG 具有相似的甲基化水平，能够共同调节细胞活动，因此滑动窗口法经常用于甲基化图谱分析。大多数研究使用 100 或 200 bp 的窗口来寻找甲基化变化的热点，并通常使用 1000 或 5000 bp 进行全局甲基化分析。计算滑动窗口的 beta 分有两种方法。在图 9.10 中，一个窗口包含 4 个 CpG。其 beta 分被定义为这些 CpG beta 分的平均值，或者是 reads 中甲基化 CpG 数量占 CpG 总数的比例：0.63 或 0.6。

**9.3.1.3 差异性甲基化** DNA 甲基化研究中最重要的目标之一是识别组间的差异甲基化区域（DMRs）。差异性甲基化通过样本间 beta 分的差异或倍数变化进行定量。由于 beta 值在 0-1 范围内，因此优使用差异（下称 delta 分）。因此，高甲基化和低甲基化分别产生正、负的 delta 分。对于差异性甲基化，统计检验比描述性分析更具相关性。如果每个样本没有重复，或每组只有一个样本，则对每个 CpG 根据两个样本的甲基化和未甲基化 reads 数量建立 2x2 表进行 Fisher 精确检验。如果每个样本都有重复或每组有两个或更多样本，则可以使用 Student $t$ 检验、Wilcoxon 检验、Rao-Scott 检验和 Kolmogorov-Smirnov 检验等统计检验识别每个 CpG 的 DMRs。统计检验会产生每个 CpG 的 p 值，由于基因组包含许多 CpG，应使用 Bonferroni 方法或假发现率（FDR）对 p 值进行多重比较调整。方差分析（ANOVA）可同时比较三个或更多组样本。已开发了多种算法以更好地或替代识别 DMR。DMEAS (87) 使用信息内容测量甲基化熵，代表该区域甲基化模式的复杂性，并检查异质甲基化模式是等位基因特异性的还是细胞特异性的。CpG_MPs (88) 使用扩展搜索差异甲基化热点。BSmooth (89) 采用平滑技术，通过生物学变异总结差异。

# 9.3.1.4 使用亚硫酸盐处理的技术 尽管测序成本大幅下降，但全基因组测序仍然昂贵，RRBS 和 TBS-seq 是亚基因组测序方案。RRBS 使用限制酶，因此 reads 从切位点开始。TBS-seq 定义捕获区域，因此 reads 需要比对到目标区域。

亚硫酸盐转换未甲基化的胞嘧啶（5-mC），但不转换其他碱。换句话说，它不将羟甲基化的胞嘧啶转换为胸腺啶。OxBS-seq 和 TAB-seq 将羟甲基化转换为胸腺啶，而 TAB-seq 将未甲基化和甲基化的胞嘧啶（见表 9.1）。为了分析羟甲基化，OxBS-seq 需要 BS-seq 状态。

# 9.3.1.5 端到端分析流程线 Kit 和 BSpipe 开发。MAP 使用 Bismark 比对 RRBS 和 ERRBS reads 并计算碱基甲基化评分 (90)，methylKit 在预定义区域或覆盖窗口上汇总甲基化，并衡量样本间的相似性、主成分分析（PCA）、无监督聚类以及 DMR 检测和注释。作为一种综合流程，BSpipe 具有与 AMP 和 methylKit 的功能，并支持不同的比对工具、多种可视化方法以及 QDMR 和 BSmooth 等外部程序。BSpipe 通过 GenePattern 提供基于网页的工作流系统，用于微列和 NGS 数据分析。
