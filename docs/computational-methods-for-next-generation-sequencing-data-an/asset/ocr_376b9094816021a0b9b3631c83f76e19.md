# Algorithm kGEEM: Maximum Likelihood k-Clustering Algorithm

+   1: For each genotype $g_i \in G^{(0)}, i = 1, \dots, k$, initialize allele frequencies in the $m$th position $(m = 1, \dots, L)$ as follows:

$$f_{i,m}(e) \leftarrow \begin{cases} 1 - \frac{4\varepsilon}{\varepsilon} & \text{if } r_{i,m} = e \ \text{otherwise}\end{cases}$$

+   2: Initialize $h_{i,r}$ by the probability that $g_i$ emitted read $r$ using formula (3.10): $h_{i,r} \leftarrow Pr(r|g=g_i)$

+   3: repeat
4: $f_i^{(0)} \leftarrow \frac{1}{k}$ for all $i = 1, \dots, k$
5: repeat
6: Compute the expected number of reads $e_{i,r}$ emitted by the $ith$ genotype $g_i$ that match read $r$ as follows:

```
$$e_{i,r} \leftarrow o_r \cdot p_{i,r}$$
$$$p_{i,r} \leftarrow \frac{f_i^{(f^{(r)}} \cdot h_{i,r}}{\sum_{t=1}^k f_t^{(f^{(r)}} \cdot h_{t,r}}$$$
```

$f_i$ is the frequency of $g_i$ and $o_r$ is the observed frequency of $r$.
Estimate the frequency $f_i^{(r+1)}$ of each $G_i^{(t)}$ as the portion of all reads emitted by $g_i^{(t)}$ as follows:

```
$$f_i^{(r+1)} \leftarrow \frac{\sum_{r \in R} e_{i,r}}{\sum_{t=1}^k \sum_{r \in R} e_{t,r}}$$$
```

+   8: until $\sum_{i=1}^k (f_i^{(r)} - f_i^{(r+1)}) \geq 0$
9: Update allele frequencies $f_{i,m}(e)$ for each allele $e \in \{a, c, t, g, d\}$ in the $m$th position of $g_i^{(t+1)}$ as follows:

```
$$f_{i,m}(e) \leftarrow \begin{cases} 1 - \varepsilon & \text{if } e = \arg_{et \in\{a,c,t,g,d\}} \sum_{r \in R:r_m=e} p_{i,r} \ \text{otherwise}\end{cases}$$$
```

+   10: Update $h_{i,r}$ using (3.10): $h_{i,r} \leftarrow Pr(r|g=g_i)$

+   11: until there exists such that $g_i^{(t)} \neq g_i^{(t+1)}$
12: for each read $r \in R$ do
13: $i' \leftarrow \arg \max_i p_{i,r}$
14: Assign read $r$ to $i'$th cluster
15: end for
