# 2.5.3 Statistical Analysis with R

The R statistical environment provides a versatile toolkit for conducting analyses and generating useful data products. R is well adopted by scientists and statisticians alike, having many useful packages for data analysis and quality visualization. However, there is also a significant activation barrier to becoming R proficient. Given that MetaPathways supports export file formats compatible with downstream analyses using R, it is useful to examine specific use cases that lower this activation barrier.
