# 16.3.5.1 Model of **QuasiRecomb** QuasiRecomb is a probabilistic model that generates an estimate of the underlying quasispecies structure by switching between $K$ different generators. It employs an HMM, where different generators are hidden states. Here, the Markov chain is a statistical process that allows transitions on a single state to explain the generation of haplotypes from a set of master sequences and reads from these haplotypes. The different profile sequence generators are denoted by $P_k$ with $k \in [1, \dots, K]$. The number of generators $K$ is unknown and needs to be determined by model selection. Let $Z$ be the hidden random variable with state space $\{P_1, \dots, P_K\}$ and $j$ be the position in the sequence (Figure 16.10). The probability to be read with generator $P_k$ at any sequence position is $P(Z_j)=p_k$. A recombination between two generators with transition probability $P(Z_j=P_k | Z_{j-1}=P_l) = p_{lk}$, for $k \neq l$; if $k=l$ then recombination did not occur. Profile sequence generators indicate the haplotype $H \in \mathcal{A}^L$. The hidden state $H_j$ indicates with emission probability $P(H_j=v | Z_j=P_k) = \mu_{kv}$, for each $v \in \mathcal{V}$. Each observed read $R$, subject to sequencing errors, bases $R_j$ is obtained from an haplotype $H$ with probability $P(R_j=b | H_j=v) =1-(n-1)\epsilon_j$ if $r=v$, and $\epsilon_j$ otherwise. The model parameters are summarized as $\theta = (\pi, \rho, \mu, \epsilon)$.

The likelihood $P(R | \theta)$ of the model factorizes into the product over independent reads, for each read $i$, it can be computed efficiently using the Markov property

```
$P(R | \theta) = \sum_{Z} \prod_{j=1}^{L} P(R_j | H_j) P(H_j | Z_j) P(Z_j | Z_{j-1})$
```
