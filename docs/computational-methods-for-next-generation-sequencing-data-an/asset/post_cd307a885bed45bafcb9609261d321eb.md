## 4.3.2 Reads Mapping

As with many viral population analyses, the first step is to map the reads to the map (Figure 4.1e). We map reads onto the *novo* consensus using InDelFixer (21) with default parameters. False read alignments were filtered out using fragment length distribution from the mapping data. Assuming that the fragment length follows a normal distribution (22), we only keep reads with fragment length within three standard deviations from the mean. In total, 1.2% of reads have been filtered out versus expected 0.3% due to the three-sigma rule.

## 4.3.3 Viral Genome Assembly (VGA)

In Reference 5, we introduce a viral population assembly method (Figure 4.2) working on highly accurate sequencing data to detect rare variants and tolerate conserved regions across the population. The method includes a postassembly procedure to detect and resolve ambiguity from long conserved regions using expression profiles. After a consensus has been reconstructed directly from the sequence data (Figure 4.2a), our method detects SNVs from aligned sequencing reads. Read overlapping is used to link individual SNVs and distinguish between genome variants in the population. The viral population is condensed in a conflict graph built from aligned sequencing data (Figure 4.2b). Two reads are originated from different genomes if they share SNVs in the overlapping region. Viral variants are identified as independent sets of nonlicting reads. Noncontinuous coverage of rare variants may limit assembly capacities, indicating that increase in coverage is required to increase the assembly accuracy. Frequency of identified variants are estimated using an expectation-maximization algorithm. Comparing with existing approaches, we are able to detect rare population variants while achieving high accuracy.

The viral population starts with determining pairs of mapped reads conflicting with each other in the overlapping region. The combination of deep coverage with high accuracy provides an unprecedented opportunity for estimating genomic diversity in a viral population. Following (23), we construct the conflict graph $G=(V, E)$ with vertices representing paired-end reads, that is, $V=R$, and edges connecting pairs of paired-ends.

Obviously, any true viral genome corresponds to a maximal independent set in the conflict graph (a maximal pair of nonadjacent vertices), although not every maximal independent set necessarily corresponds to a true genome. In Reference 5, we adopt a parsimonious approach requiring to cover the conflict graph with the minimum number of independent sets. This problem is equivalent to MIN-GRAPH-COLORING, which is NP-hard. There exists many heuristics for solving this problem (e.g., References 24, 25) based on greedy selection of a maximal independent set. Unfortunately, our attempts to build a single viral genome failed since it is difficult to arrange paired-end reads into a connected single path. Indeed, a greedy algorithm runs out of any possible extension after just a few steps while concatenating paired-read reads from left to right.

Instead, in Reference 5, we apply an alternative “top-down” approach of recursive graph partitioning along the maximum cut (Max Cut), which has been successfully applied for human haplotyping (26). Given a graph G=(V, E), the Max-Cut problem asks for partitioning of the vertices into two components V₁ and V₂ maximizing the total number of edges, which one endpoint in V₁ and the other in V₂. The Max-Cut problem though NP-hard is well approximated by a 0.5 approximation algorithm, which randomly assigns vertex to one of the two components (27). Our Max-Cut heuristic starts with assigning left-to-right sorted reads to two components and repeatedly moves one vertex at a time from another, improving the solution at each step, until no more improvements of this type can be made.

Our heuristic recursively partitions the graph until each component becomes independent (Figure 4.2c). If reads of a graph completely cover the genome, the resulting sequence is accepted as the next viral genome. Otherwise, if assembled genome contains gaps, we use nonconflicting reads from other colors in left-to-right order to fill the gaps (Figure 4.2d). If all SNV positions are covered, then a newly reconstructed viral genome is added to the set VGA. Finally, the genomes whose gaps cannot be filled with the above procedure.

# COMPUTATIONAL METHODS FOR NGS DATA ANALYSIS

```
Algorithm VGA Assembly (5)
**Input:** Set of reads aligned to consensus
Build conflict graph G = (V, E) from set R
Recursively color G into classes C using Max-Cut
Initialize the set of viral genomes VGA $\leftarrow \emptyset$
**for** each color class $c_i \in C$ **do**
  Compute maximal independent set in $G = (V, E)$ containing $c_i$
  Assemble $c_i$ into viral genome $g_i$
  **if** $g_i$ covers all positions in genome **then**
    $\mathcal{VGA} \leftarrow \mathcal{VGA} \cup \{g_i\}$
  **end**
**end for**
**Output:** Set of complete viral genomes
```

In Reference 5, we extend the previous EM formulation to incorporate a prior probability for the viral population and compute the maximum posteriori estimate. Let $H$ be a random variable over the set of viral genomes $H = \mathcal{VGA}$, and $R$ be a random variable over the set of reads $R$. Let $p[H] \sim \text{Dir}(\alpha_1, \dots, \alpha_{|H|})$ be the prior probability of a set of variants and define $p_h = \text{Pr}[H=h]$ to be the probability of a particular variant. The probability of observing read $r \in R$ is given by marginalizing over all variants

> $\text{Pr}[R=r] = \sum_{h \in H} \text{Pr}[R=r|H=h] \cdot p_h$

where

> $\text{Pr}[R=r|H=h] = \begin{cases} 1/K_h & \text{if } r \text{ is consistent with } h \\0 & \text{otherwise} \end{cases}$

and $K_h$ is the number of reads consistent with $h$. We can now define the log-posterior as

> $\log \text{Pr}[H|R] = \sum_{r \in R} n_r \cdot \log \text{Pr}[R=r] + \sum_{h \in H} (\alpha_h-1) \log p_h - C_R$

where $C_R$ is a constant and $n_r$ is the number of reads $r$. As this function is nonconvex and difficult to optimize, we solve the easier problem of maximizing its lower bound,

> $\sum_{r \in R, h \in H} n_{rh} \cdot \log (\text{Pr}[R=r|H=h] \cdot p_h) + \sum_{h \in H} (\alpha_h-1) \log p_h$

where $n_{rh}$ is the expected number of reads $r$ generated by variant $h$. The EM algorithm computes this by

> $n_{rh} = n_r \cdot \frac{\text{Pr}[R=r|H=h]}{\text{Pr}[R=r]}$
