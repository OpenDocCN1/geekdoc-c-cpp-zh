9.2.2.2 MEDIPS Similar to Batan, MEDIPS (65, 72) defining coupling factors as the local CpG density by counting the number of CpGs for a given position. Let $p$ be a given position, and $d$ the size of the library (fragment) chosen for the sequencing (Figure 9.6). The objective is to count the number of CpGs in $[p-d, p+d]$. Several ways have been proposed: count, linear, exp, log, and custom. While count counts the number of CpGs, the other weigh CpGs based on the distance to $p$ using linear, exponential, or logarithmic function. Custom allows user-defined weights, for example, Batan's coupling factors. Coupling factors are precomputed for a genome. Since mammalian genomes are big, fixed-size (say 50 bp) are used for efficiency, where $p$ is the center of a bin. The authors of MEDIPS have tested the different weighting functions and library sizes with 50 bp by measuring the correlation of the methylation to local CpG density using bisulfite sequencing (73). For each of about 300 genomic loci of length 50-500 bp in the bisulfite sequencing, they computed the mean scores and the mean factors, and measured a Pearson correlation coefficient. The best parameter setting is use $l=700$ and count; this gives the best negative correlation as expected in mammalian cells: regions with low CpG density are highly methylated while those with high CpG density are mainly unmethylated.

To make the read count comparable among samples, it is normalized in RPM (Reads Per Million), which is the read count when the read count at position $i$ and $n$ represents the total number of reads mapped. Now we have $rpm = c * 10^6/n$ where $c$ represents the read count. The goal is to adjust the RPM value by the coupling factor, that is, CpG density. To this end, MEDIPS visually inspected a calibration plot where the $x$-and $y$-axis represent coupling factors and read counts, respectively. As shown in Figure 9.6, while the M axis shows no dependency, the grey line called a calibration curve shows a linear relationship for the low range of coupling factor. High range of coupling factor has low read count because regions with high CpG density are mainly unmethylated in mammalian cells. Pelluzzo et al. (75) confirmed the density for the high range of coupling factor in an experiment of fully methylated samples using MedIP-ChIP data. Based on this observation, MEDIPS fits a linear regression model to calculate the methylation score with CpG density. A coupling factor with $n$ genomic bins, $cf = (cf_1, ..., cf_n)$, the algorithm finds the first local maximum of coupling factors, which is denoted as $cf^m$ and performs a linear regression using the least square approach to $cf^m = (cf_1^m, ..., cf_n^m)$ and $rpm^m = (rpm_1, ..., rpm_n) : rpm = \alpha * cf + \beta$ where $\alpha$ and $\beta$ are the theoretical slope and intercept and $\epsilon$ is an error term. The parameters are adjusted, RPM values are calculated using $rms = \log(2rpm/(\alpha+\beta))$. Figure 9.7 shows large changes between RPM and RMS for two samples. To compare any region of interest (ROI), especially for different lengths, MEDIPS calculates a methylation score of ROI by the mean of rms values divided by the mean of coupling factors.

To identify DMRs (Differentially Methylated Regions) between treatment and control samples along an input sample, the initial version of MEDIPS used Student and Wilcoxon tests for each ROI or genomic window of arbitrary length with at least 5 bins. First, it calculated the mean rpm and rms values of all samples for the control and treatment, the ratios of rpm to the control and the ratios of rpm to the control and to treatment. Let $rpm^S$ and $rms^S$ be the rms values at bin $i$, respectively, of a sample $S$, then $Mrpm^S = (\sum rpm^i)/n_i$ and $Mrms^S = (\sum rms^i)/n_i$, where $n_i$ is the number of bins in the ROI. The ratio of rms values of the control to the treatment is, $Rms = Mrms^C/Mrms^T$; and the ratios of rpm values of the control and to treatment is $Rpm = Mrpm^C/Mrpm^T$. Second, for an ROI or genomic window, the Student and Wilcoxon tests are performed using $\{rpm^i\}$ and $\{rms^i\}$ and the $p$-values are computed: $t.val$, and $w.val$. Finally, for the DMR candidate, several filtering schemes are applied to ROIs with $Mrms^C = 0$; $t.val > p$ and $w.val > p$; $Rms < h$; $Mrms^C < t$ or $Mrms^T < t$; and $Rpm^C < h$ or $Rpm^T < h$ are the threshold of the $p$-value, and lower and upper ratios, respectively, and $t$ is a global rank-weighted value estimated by the input.

The latest version 1.2.0 of MEDIPS improved DMR call by using the edgeR package which allows a low number of replicates and uses a linear model for control data, similar to R-seq using binomial distribution. This version also accounts for copy number variants using DNAcopy, for example heterogeneous cells, by computing the log ratio of the mean rpm of all samples in a group to the rpm of the input for each window of a fixed length.

# 9.2.2.3 Bi-Asymmetric-Laplace Model (BALM)

BALM (59) has been developed to accurately estimate the methylation level of each CpG from MBD-seq using a bi-asymmetric-Laplace model, which has been used in recaptulating the 'tags' binomial distribution over target sites in a ChIP-seq experiment (53). The authors observed that tag density from the peaks to borders decreases exponentially in ChIP-seq, and they found that BALM fits better than Gaussian and Student t distributions, that BALM yields a lower value of goodness. 9.8 shows the performance of these models measured by goodness of fit for four samples. BALM uses a tag-shifting model in W-ChiPeaks (77) to measure the enrichment in a sliding window of 50 bp across a genome. Significantly enriched windows are decided by Fisher's test with input data and a predefined threshold weighted by the genome region. For each significantly enriched region, consisting of continuous windows with significant enrichment, a target site is defined as the mean of shifted tag positions in the region. BALM performs the fixed number of iterations for subsequent analysis. It measures parameters of a biasymmetric Laplace model using maximum likelihood estimators. Since an enriched region could have multiple target sites, it builds a mixture model and estimates parameters using expectation-maximization algorithms, and determines the number of target sites using the Bayesian information criterion (Figure 9.9).
