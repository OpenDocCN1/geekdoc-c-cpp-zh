On the other hand, if two samples $S_1$ and $S_2$ are not separated by any pool, then it is impossible to distinguish them from each other by set-theoretical operations. This fact leads to the efficient pool design method described.

**Theorem [23, 32].** If any subset of samples can form a single pool, then $n$ samples can be reconstructed using $m = [\log(n)] + 1$ pools.

**Proof.** As for simplicity $n$ is a power of 2, that is, $n = 2^k$ (the proof is analogous for any $n$). Then apply induction: if $k=1$, then $P=\{\{S_1\}, \{S_2\}\}$ clearly a valid pool design with $m=2$. Suppose that $P' = \{S'_1, \dots, S'_{m'}\}$ is a valid pool design with $S'$; $n'=n/2=2^{k-1}$, $m' = \log(n') + 1$. Construct a family $P=\{P_1, \dots, P_{k+1}\}$ as follows

```

```
