**5.3.2 Read Preprocessing** Each contig has two reverse complement strands and each read from a pair is mapped to one of the strands. We discard aligned (suspected) reads. We first filter read pairs in which at least one read has multiple alignments. Then for each contig we compute its read coverage and filter out contigs with coverage greater than $25n$. Multiple reads connecting the same pair of contigs are bundled according their gap estimation. Since we want to keep only reads that agree with each other, the reads outside of the largest bundle are discarded. This procedure is illustrated in Figure 5.6.

The next step in the construction of the scaffolding graph $G=(V,E)$ is the so-called edge bundling (step 10). Multiple edges that support the same distance, relative ordering and orientation are bundled.

Consider two contigs $A, B \in V(G)$ and let $E_{AB} = \{e_i\}_{i=1,n}$ be the set of edges (paired-read reads) supporting the same relative ordering and orientation of $A$ and $B$. The following steps are performed until no edges in $E_{AB}$ remain unused:

+   1. Choose $e_k \in E_{AB}$ with the median gap estimation $L_{e_k} = L_{median}(E_{AB})$.
2. Determine edges $e_i \in E_{AB}$ whose gap estimation $L_{e_i}$ is within $3\sigma(L_{median}(E_{AB}))$, bundle them into one single edge $e'$.
3. For the bundled edge $e'$ set the gap estimation and its standard deviation $L_{e'} = a/b$ and $\sigma(e') = \sqrt{b}$, where

```
a = \sum_{e_i \in e'} \frac{L_{e_i}}{\sigma(e_i)^2}, b = \sum_{e_i \in e'} \frac{1}{\sigma(e_i)^2},
```

+   4. Set the weight of the bundled edge $W_{e'}$ to $|e'|$.
5. $E_{AB} := E_{AB} \setminus e'$.
