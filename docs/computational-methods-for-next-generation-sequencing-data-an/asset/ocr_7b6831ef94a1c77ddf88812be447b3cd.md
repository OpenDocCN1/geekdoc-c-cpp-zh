# POOLING STRATEGY FOR MASSIVE VIRAL SEQUENCING

The subset $M'$ is called three-dimensional matching. It is known that the problem A is NP-complete (33). Let $X, Y, Z, M, |X| = |Y| = |Z| = q$, be the input of the problem A Construct a graph $G$ as follows:

```
$V(G) = X \cup Y \cup Z \cup A, \quad (3.3)$
```

where $A = \{a_c : v \in X \cup Y \cup Z\}$;

```
$E(G) = \bigcup_{(a,b,c) \in M} \{ab, bc\} \cup \{v_{a_c} : v \in X \cup Y \cup Z\}. \quad (3.4)$
```

We show that $M$ contains three-dimensional matching if and only if the graph $G$ contains a clique test $\mathcal{P} = \{P_1, \dots, P_m\}$ of size $m = 4q$. Let $\mathcal{P} = \{P_1, \dots, P_m\}$ be a clique test of $G, m = 4q$. Let $P' \subseteq P$ be a set of cliques covering the vertices from the set $A$. For every $v \in R$, $P'$ contains either $\{v, a_b\}$ or $\{v, a_c\}$, or both of them. Let $R = R_1 \cup R_2 \cup R_3$, $R_1 = \{v \in R : \{v, a_c\} \in P'\}$, $R_2 = R_1, R_3 = \emptyset$. Consider an arbitrary vertex $v \in R_2$. $P'$ contains either clique $\{v, a_b\}$ or clique $\{v, a_c\}$. If $\{v, a_c\} \in P'$, then $P''$ contains at least one clique, which separates $v$ and $u$. Thus, every $v \in W_u$ is in a clique from the set $P''$. Let $r_1 = |R_1|$. $|P'| = 3q - r_1, |P''| = 3q + r_1, |P'''| = 4q - |P'| = q - r_1$. $3q - r_1$ vertices from the set $R_1$ are covered by $q - r_1$ cliques from set $P'''$. Since sizes of cliques in $P'''$ are at most 3 (by the construction of graph $G$), it is possible only if $r_1 = 0$, all cliques in $P'''$ contain exactly vertices and do not pairwise intersect. The condition ($*$) guarantees that every triangle of the graph $G$ belongs to $M$, and $P'''$ is a three-dimensional matching.

Conversely, if $M' \subseteq M$ is a three-dimensional matching, then $P = M' \cup \{v, a_i\} : v \in R\$ is a clique test of graph $G$. Indeed, for every $v \in R$, a clique $\{v, a_i\}$ separates $V(G)\{v, a_i\}$ and $a_i$ are separated by the clique from $M'$ which contains $v$.

In practice, the pair of vertices should be separated by some clique, and at least one vertex $v \in V(G)$ is not covered by a clique from the set $P$. Thus, any family of cliques satisfying (2) and (3) can be transformed into a family satisfying (1) by adding one additional clique $\{v\}$. Therefore, we consider the problem without the condition (1).
