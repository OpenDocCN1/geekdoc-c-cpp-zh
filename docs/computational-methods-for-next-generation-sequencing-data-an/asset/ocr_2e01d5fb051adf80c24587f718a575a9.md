To this end, we simulated paired-end RNA-seq data based on refSeq transcripts at a coverage level close to mimic mammalian data sets from an Illumina sequencing run. A single lane of the Illumina platform can easily generate ~150 million paired-end reads, which is sufficient for both in-depth quantitation of gene expression in mammalian genomes and deep enough for the identification of novel events. It is thus convenient to use a single line of an Illumina flowcell as a single experimental sample. For simulation, we used some commonly used RNA-seq simulators such as BEER (39) and Flux (40). While BEER provides many desirable parameters to control the simulated reads, it only produces reads with fasta, and hence it was not considered for this study.

We used Flux (40) version 1.2.1 to simulate paired-end reads from ref-seq transcripts of human (hg19). The Flux simulates reads using the control parameters in its input file linking to the sorted GTF file for transcripts and the fast file of the genome using a realistic quality model reflecting the current sequencing technology of. Of the two error models available, we use the quality model for generating 76 bp reads to scale to the longer reads that were generated. The simulator was set to generate a prescribed number of reads of length 100bp, and shorter reads were removed. The paired-end reads are output into a single file and separated into fastq data sets representing the forward and reverse reads as input. In addition to producing the reads, Flux also produces a file with the details of the transcriptome profile (say L), transcript id, number of reads (say N) sequenced from individual transcripts, and their genomic coordinates. If the trimmed length of the reads is 85 bp, then the approximate quality of a transcript will be the number of reads generated by Flux from a transcript times the length of the read divided by the length of the transcript (N * 85/L). Five different data sets were generated, each of which were examined with FastQC and found in fine that the trailing 15 bp had quality score lower than 20, which we used as our quality cutoff threshold. Therefore, 15 bp of the trailing end of each read was trimmed from the data set. Since these data sets were simulated, the leading edges of reads were acceptable and we did not observe any impact of adapters. The details of the reads simulated are given in Table 12.1.
