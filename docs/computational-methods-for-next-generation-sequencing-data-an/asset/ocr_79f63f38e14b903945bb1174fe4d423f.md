# 140	 COMPUTATIONAL METHODS FOR NGS DATA ANALYSIS

The model of (28) assumes independence across sites, errors, and samples. It also assumes that variants are biallelic, which is the case for most of the SNPs in populations of Eukaryotic cells. In this case, genotypes be encoded as integers representing the number of reference alleles in the genotype. For a diploid individual, the homozygous reference genotype is encoded as $g=2$, the heterozygous nonreference genotype is encoded as $g=0$. Given sequencing data from $n$ individuals with ploidies $m_1, m_2, \dots, m_n$, let $ar{G}=\langle G_1, G_2, \dots, G_nangle$ be the vector of genotypes for the $n$ individuals. Then, the random variable $K=\sum_{i=1}^n G_i$ is the number of reference alleles present in the population. Assuming Hardy-Weinberg equilibrium (HWE), the probability of a genotype configuration given a fixed number of reference alleles

```
$P(\bar{G}|K=k)=e\left(k, \sum_{i=1}^n G_i\right)\prod_{i=1}^n \left(\frac{m_i}{G_i}\right)^{G_i}$
```

where $e$ is an indicator function taking the value 1 if the two arguments are equal and 0. The conditional probability of the data $	ilde{d}=\langle d_1, d_2, \dots, d_nangle$ given $K=k$

```
$P(\tilde{d}|K=k)=\frac{1}{\binom{M}{k}}\sum_{g_1=0}^{m_1}\dots\sum_{g_n=0}^{m_n} e\left(k, \sum_{i=1}^n g_i\right)\prod_{i=1}^n \left(\frac{m_i}{g_i}\right)^{g_i} P(d_i|g_i)$
```

Efficient calculation of this likelihood can be performed by dynamic programming defining the following sum:

```
$z_{jl}=\sum_{g_1=0}^{m_1}\dots\sum_{g_j=0}^{m_j} e\left(l, \sum_{i=1}^j g_i\right)\prod_{i=1}^j \left(\frac{m_i}{g_i}\right)^{g_i} P(d_i|g_i)$
```

for $0 \le l \le \sum_{i=1}^j m_i$ ($z_{j'l}=0$ for $l > m_j$). Starting with $z_{00}=1$, the partial sums and the final value of $P(\tilde{d}|K=k)$ are calculated as follows:

```
$z_{jl}=\sum_{g_j=0}^{m_j} z_{j-1,l-g_j} P(d_j|g_j)\binom{m_j}{g_j}\n\n\tP(\tilde{d}|K=k)=\frac{z_{n,k}}{\binom{M}{k}}$
```

The posterior probability $P(K=k|	ilde{d})$ can be calculated using the Bayes rule:

```
$P(K=k|\tilde{d})=\frac{P(K=k)P(\tilde{d}|K=k)}{\sum_{l=1}^k P(K=l)P(\tilde{d}|K=l)}$
```
