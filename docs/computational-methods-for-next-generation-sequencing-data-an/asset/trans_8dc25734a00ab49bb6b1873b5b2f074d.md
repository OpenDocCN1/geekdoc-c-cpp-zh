## NGS 数据分析的计算方法

为患者体内病毒种群的动力学以及可能的进化轨迹提供更深入的见解。随着库制备进展、测序平台敏感性的提高以及更复杂的模型，可能可以在单个个体中检测到所有的病毒株。这些宝贵信息可以通过调整方案来改善治疗效果。
