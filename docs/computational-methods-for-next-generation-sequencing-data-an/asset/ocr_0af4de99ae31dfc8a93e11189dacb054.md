Identical parameters for Cufflinks were originally designed as a tool for the downstream assembly of the output of the Tophat assembler can be used with the output of other algorithms.

Trinity (38) and SOAPdenovo-Trans (37) were used to generate de novo RNA-seq transcriptomes from our simulated data sets. Both are de Bruijn graph-base, de novo transcript assembly algorithms (45). SOAPdenovo-Trans allows testing of k-mer values, with a fixed value of 25. Each was designed with the goal of the assembly of transcripts and quantitation of their transcript abundance. Both attempt to resolve transcripts by resolving de Bruijn subgraphs that potentially contain multiple isoforms. SOAPdenovo-Trans performs transcript quantification as an option, the output of can be used as an algorithm designed for transcript quantification, such as RSEM (46), edgeR (47), or DESeq (48).

The sets of simulated and trimmed paired-reads were analyzed with programs using default values except the option to calculate FPKM values for the SOAPdenovo-Trans analyses. The Trinity assemblies were then analyzed with RSEM for the determination of FPKM values of the assemblies. Assemblies from both programs were then annotated to hg19 using cmap (49). Trinity is a very memory-intensive program, in this study run over 6 hours or an hour. For speeding up Trinity with large data sets, it is very common to increase the memory allocated to the program (or to one or more of the running programs comprising Trinity, inch, chrysalis, and butterfly) by running analyses using multiple processors, all of which can be controlled using command flags. It is also common with large data sets to do an silico normalization step to reduce the run-time. There is a very active listserv discusses current issues in Trinity assemblies (50) and a very detailed tutorial available (51).

For the transcriptome output of all de novo assemblies, when the aligned length of contig spans through the length of a known transcript, we consider a perfect match; otherwise it will be considered a fractional match. We considered 10%, 50%, and 90% fractional matches in annotating contigs to refSeq transcripts.

# 12.6 RESULTS

Different paired-end RNA-seq data were generated with Flux simulator using refSeq transcripts of the human (hg19) as a guide. The specific details and the summary are provided in the Experiment section. Each data set, after trimming, was assembled with the reference-based Tophat2 and SpliceMap and with the de novo assemblers Trinity and the SOAPdenovo-Trans. For evaluation, true positives are considered to be the transcripts generated with coverage over some specified threshold.
