# COMPUTATIONAL METHODS FOR NGS DATA ANALYSIS

Precisely uncover the function of genes regulated by DMRs, functional analysis should be performed with GO terms, pathways, and protein-protein interactions using PANTHER (100), DAVID (101), or IPA (102). The DMRs are segregated on the location to a gene: promoter, downstream, exon, or intron. They are also integrated into epigenomic regions for histone modification, chromatin structure, transcription factors, and nucleosome positioning in ENCODE (103), epigenome ATLS (104), and TCGA (105) by overlapping or distance using BEDTools (106) or FeatureCount (107).
