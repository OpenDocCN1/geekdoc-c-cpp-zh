Lemma 2 states that we only need to search for the second segment of the split read within the region $[e1 - l_i, min(e1 + l_i - l1 - l_2 + 3\sigma, a - m_j)]$. This region is called the “focal” region for the split read being mapped and an encompassing pair. In most current sequence data, the focal region is relatively small. For example, suppose $l_i = 50$ (taken from a read of 100 bps long), $l_i = 100$, $l_i = 200$, and $\sigma = 50$. The width of the focal region is not larger than 200. This is much smaller than the focal region that the original split-read mapping would have searched (which can be as large as 1 Mbps). Also, from Lemma 1, the width for the encompassing pairs is at most 150.

The processing of split reads with type II is similar in many aspects to type I. A main difference between type I and type II patterns is that type II does not need additional encompassing pairs because the paired-end read itself an encompassing pair. This imposes an additional constraint on the focal region. Refer to (21) for more detailed description.

To search for the occurrence of a soft-clipped segment within the inferred focal region, SVseq2 uses a semi-global alignment algorithm. Briefly, we want to map the entire soft-clipped segment within the focal region. Thus, the gaps of the aligned positions for the focal region are without penalty, we set the gap penalty within the read to 3. The similarity score is 1 for matches and -1 for mismatches. Since the focal region and the read are relatively short (e.g., several hundreds at most for the focal region and less than 100 for paired-end reads), split-read mapping with sequence alignment can be performed relatively fast.

In practice, there may be more than one encompassing pairs for candidate deletion (corresponding to a split read). When the deletion is heterozygous in a diploid genome, some encompassing pairs may originate from the copy without the deletion while others are from the copy with the deletion. One possible scheme is to use a “consensus” focal region by combining information provided by multiple encompassing pairs. SVseq2 simply takes the union of all the focal regions from all the possible encompassing pairs. This is because there may be mapping errors in the encompassing pairs, and thus SVseq2 takes a conservative estimate of the focal region. Our experience shows that the overall focal region is still relatively small and searching for split read can be performed relatively effectively.
