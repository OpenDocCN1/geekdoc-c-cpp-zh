The trimmed simulated RNA-seq data sets were assembled by two reference-based assemblers Tophat2 (10) and SpliceMap (36) and two novo assemblers SOAPdenovo-Trans (37) and Trinity (38). Using Bowtie2, the first 500,000 reads from each data set were mapped onto the hg19 refSeq transcripts that were downloaded from Ensembl.org at ftp://ftp.ensembl.org/pub/release-73 to determine the main pair index reference for each data set. This calculation is in terms of properly tuning reference algorithms and is specific to each analysis as the value generated is dependent on both the cDNA fragments used to prepare the sequencing library and the length of the sequence reads (see Figure 12.1a). The output, an aligned BAM file, was sorted by the SortSam module from SamTools (41). Like the fastq sequence, the SAM/BAM formats have been developed for specifically describing the alignments of fastq reads to reference used using second-generation sequencing (11). SAM (sequence alignment/map) is a text description of an alignment to reference, while BAM is the compressed, version of a SAM file, often more manageable than the sheer size of the data sets that resulted from alignments. Most of the used tools to manipulate and analyze these sequence data recognize one or the other of these formats. The CollectInsertSizeMetrics tool from the picard package (42) was used to find the main pair inner distance and deviation for each data set. For each simulated data set, Tophat2 ran with default settings except for the following parameters (inner pair distance, deviation, GTF file from hg19), which were set as appropriate for each data set. Reads were mapped onto the reference and assembled and possible splits between neighboring regions were determined. The unmapped reads are then fragmented and aligned onto the reference and split junctions. A very good tutorial describing the detailed use of Tophat and Cufflinks for RNA-seq analysis is available (43). For the specific case of detecting novel fusion transcripts, a version of Tophat called Top-fusion has been developed (43).

SpliceMap uses a split-read algorithm. Reads that are less than 50 bp were split into overlapping 25 bp-halves while reads are split into overlapping 50 bp reads. These halves were aligned to the reference gene with either Bowtie or BWA (44). These alignments are combined to determine the exons or split junctions. SpliceMap uses an algorithm somewhat similar to Tophat, but generates its analysis without the use of a GTF file describing the transcripts. Each of the five data sets were assembled by Tophat2 and SpliceMap on a cluster computer with over 18 parallel threads. Thread creates an aligned BAM file, and the SpliceMap creates an aligned SAM file. Cufflinks, which provides quantification of RNA-seq from the assembled or aligned BAM file, was the BAM/SAM files of our both Tophat and SpliceMap outputs to generate FPKM tracking files (Fragments Per Kilo base of exons Per Million reads) value is one of several means developed to normalize relative transcript abundance in RNA-seq analyses, taking into account that transcript size varies considerably in many organisms.
