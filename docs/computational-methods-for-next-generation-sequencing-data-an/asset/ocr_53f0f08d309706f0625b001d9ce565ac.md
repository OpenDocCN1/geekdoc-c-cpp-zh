**9.3.1 Methylation Quantification** The methylation level of CpG sites is defined as a beta score. For a CpG site with m methylated (CpG) and u methylated (TpG or CpA) reads, the beta score is m/(m+u). For a high-quality methylation profile, several filtering schemes are applied to reads the base quality of a cytosine is low, for example, ten; if the mapping quality of a read is low, for example, ten; or if the read depth of a CpG is lower, for example, 6.
