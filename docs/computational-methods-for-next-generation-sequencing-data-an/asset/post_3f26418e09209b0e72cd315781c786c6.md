Cuffdiff uses a beta binomial distribution to test the significance of change samples. The model accounts for all uncertainty resulting from read mapping ambiguity and cross-replicate variability. Cuffdiff reports fold change in gene expression level along with statistical significance.

Cufflinks includes a separate program, Cuffdiff, which calculates expression in two or more samples and tests the statistical significance of each observed change in expression between them. The statistical model used to evaluate changes assumes that the number of reads produced by each transcript is proportional to its abundance but fluctuates by technical variability during library preparation and sequencing. Cufflinks a transcript-level count uses an algorithm to model the expression of a gene G. Following this algorithm, it is able to get a distribution for the log-fold change in expression G under the null hypothesis, Cuffdiff computes the average of these distributions and takes their ratio. The process is repeated thousand times across the two conditions. To calculate a p-value of observing the real log-fold change, they counts all the samples and how of them are more extreme than the log-fold change they actually saw in the real data. This number divided by the total number of draws is the estimate for the p-value (9).

edgeR is a statistical method for differential gene expression analysis, which is based on the negative binomial distribution. Although edgeR is primarily designed to work with replicates, it can also be run on data with no replicates. We used edgeR on uniquely mapped reads, as suggested in Reference 34.

edgeR as well as DESeq are downstream count-based analysis tools, both available as R/Bioconductor packages. The edgeR can be used to analyze replicate data sets (highly replicated) and unreplicated.

A particular feature of edgeR functionality is empirical Bayes method that permits the estimation of gene-specific biological variation, can be applied to differential expression for experiments with minimal levels of biological replication, at exon, transcript, or tag level. In fact, read counts can be summarized by any genomic feature. edgeR analyses at the exon level are easily extended to detect differential splicing or isoform-specific differential expression.

DESeq and edgeR are two methods and R packages for quantifying readouts (in form of counts) from high-throughput experiments such as RNA-seq. After alignment, reads are assigned to a feature, where each feature represents a target transcript, in the case of RNA-Seq. An important statistic count is the count of the number of reads in a feature (for RNA-seq), this read is a good approximation of transcript abundance.

Methods used to analyze array-based data assume a normally distributed, continuous response variable. However, response variables for digital methods such as RNA-seq and ChIP-seq are discrete counts. Thus both DESeq and edgeR methods are based on the negative binomial distribution.

## 14.3.1 SimReg: Simulated Regression Method for Transcriptome Quantitation

The proposed method for estimating frequencies of transcripts is based on the novel approach for estimating exact frequencies. First, we describe the essence of our approach and contrast it with Isoasso.

As discussed earlier, it is very difficult (if at all possible) to accurately estimate portions of pair-read edits from subexon. Instead, than distinguishing reads by their gene position, we partition reads into classes consisting of reads with each element of a particular subset of transcripts. In other words, two reads are assigned to the same class if they are consistent with exactly the same transcripts. Our second innovation is to use Monte Carlo simulations instead of attempting counts of each transcript to each read class. For any particular class R, the expected frequency is estimated based on the frequencies of contributing transcripts as well as positions of reads that fall into the class R. Finally, using the standard regression method, we estimate transcript frequencies by minimizing deviation between expected and observed read class frequencies.

The following is the general description of the proposed regression algorithm (SimReg) consisting of four steps and is described in detail.
