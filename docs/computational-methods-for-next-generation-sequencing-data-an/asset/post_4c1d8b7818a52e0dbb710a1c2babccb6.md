
# Algorithm kGEEM: Maximum Likelihood k-Clustering Algorithm

- 1: For each genotype $g_i \in G^{(0)}, i = 1, \dots, k$, initialize allele frequencies in the $m$th position $(m = 1, \dots, L)$ as follows:

$$f_{i,m}(e) \leftarrow \begin{cases} 1 - \frac{4\varepsilon}{\varepsilon} & \text{if } r_{i,m} = e \\ \text{otherwise}\end{cases}$$

- 2: Initialize $h_{i,r}$ by the probability that $g_i$ emitted read $r$ using formula (3.10): $h_{i,r} \leftarrow Pr(r|g=g_i)$

- 3: repeat
- 4: $f_i^{(0)} \leftarrow \frac{1}{k}$ for all $i = 1, \dots, k$
- 5: repeat
- 6: Compute the expected number of reads $e_{i,r}$ emitted by the $i$th genotype $g_i$ that match read $r$ as follows:

```
$$e_{i,r} \leftarrow o_r \cdot p_{i,r}$$
$$p_{i,r} \leftarrow \frac{f_i^{(f^{(r)}} \cdot h_{i,r}}{\sum_{t=1}^k f_t^{(f^{(r)}} \cdot h_{t,r}}}$$
```

$f_i$ is the frequency of $g_i$ and $o_r$ is the observed frequency of $r$.
Estimate the frequency $f_i^{(r+1)}$ of each $G_i^{(t)}$ as the portion of all reads emitted by $g_i^{(t)}$ as follows:

```
$$f_i^{(r+1)} \leftarrow \frac{\sum_{r \in R} e_{i,r}}{\sum_{t=1}^k \sum_{r \in R} e_{t,r}}$$
```

- 8: until $\sum_{i=1}^k (f_i^{(r)} - f_i^{(r+1)}) \geq 0$
- 9: Update allele frequencies $f_{i,m}(e)$ for each allele $e \in \{a, c, t, g, d\}$ in the $m$th position of $g_i^{(t+1)}$ as follows:

```
$$f_{i,m}(e) \leftarrow \begin{cases} 1 - \varepsilon & \text{if } e = \arg_{et \in\{a,c,t,g,d\}} \sum_{r \in R:r_m=e} p_{i,r} \\ \text{otherwise}\end{cases}$$
```

- 10: Update $h_{i,r}$ using (3.10): $h_{i,r} \leftarrow Pr(r|g=g_i)$

- 11: until there exists such that $g_i^{(t)} \neq g_i^{(t+1)}$
- 12: for each read $r \in R$ do
- 13: $i' \leftarrow \arg \max_i p_{i,r}$
- 14: Assign read $r$ to $i'$th cluster
- 15: end for

# 3.4.2 Performance of the Pool Deconvolution Algorithm

Four hundred and fifty test instances with n = 10,..., 150 samples and with threshold of pools' sizes T = 15,25 and 35 were generated. Simulated pools were constructed using 155 HCV V1 pools previously sequenced in Molecular Epidemiology and Bioinformatics Laboratory, Division of Viral Hepatitis, Centers for Disease Control and Prevention using 454 GS System (454 Life Sciences, Branford, CT) (9, 38–40). Reads from each were cleaned from sequencing NGS error correction algorithms KEC and ET (41). Test instances were generated as follows:

- 1. n samples were chosen randomly.
- 2. A random sample's compatibility graph on n vertices was generated based on t titer compatibility model and pools were generated using the VSPD algorithm (Algorithm GOPDA).
- 3. Pools were created by making D randomly selected reads from the samples each pool D was set as D=10,000, which approximately corresponds to the sequencing settings, under which the data used for simulation were obtained (454 Junior System with 8–110 MIDs per sequencing run).

For all test instances, all samples were freed, that is, all n data sets produced by Algorithm is not possible. Some reads are not classified as samples and therefore are lost by the algorithm. However, the number of such was extremely low (Figure 3.5a); in average 99.96% for T = 15, 99.93% for T = 25, and 99.98% for T = 35 were classified. An overwhelming majority of reads were correctly classified (Figure 3.5b); in average 99.98% for T = 15, 99.95% for T = 35 were assigned to the right samples. It should be noted that the accuracy of the classified reads, in general, do not depend on the number of samples if this number is large.

![](img/46aec008551cecb3bbf3aac2ee69b926_96_0.png)

**Figure 3.5** (a) Percentage of samples without silico contamination. (b) Percentage of classified reads. Bars represent a standard error. Source: Skums 2015 (29). Reproduced with permission of Oxford University Press.

We allow an incorrect assignment of reads to the samples *in silico*. The percentage of samples without silico contamination is from 100% for T = 15, 96.13% for T = 25, and 93.8% for T = 35 (Figure 3.6a); In silico contaminants constitute a minority within within samples: an average of 0.163% for T = 15, 0.5545% for T = 25, and 0.892% for T = 35 (Figure 3.6b).

Root square error of the frequency estimates of deconuted haplotypes is in order 0.031–0.107% for T = 15, 0.025–0.139% for T = 25, and 0.028–0.174% for T = 35 (Figure 3.7).

According to all measures considered, the accuracy of the samples deconvolution is affected by the number of allowed samples per pool. The algorithm is more accurate for smaller pools although the accuracy remains high for larger pools.
