Formally, alignment of a given set of unique reads $R = \{r_1, \dots, r_N\}$ with multiplicities $[o_1, \dots, o_N]$ be represented by $N \times L$ matrix $A$, with rows corresponding to reads and columns to alignment positions. For a given set of reads $C' \subseteq R$, a generalized haplotype $G = g(C')$ with a multiplicity $m_j = \sum_{i \in C'} o_i$ is a $5 \times L$ matrix, with columns representing alignment positions and rows representing the bases $\{a, c, t, g, d\}$; the value $G'_{em}$ is the frequency of the base $e$ in $m$th position among all sequences in $C'$. The probability of the read $r_i = (r_i^1, \dots, r_i^f)$ being emitted by a generalized haplotype $G$ can be estimated

> $Pr(r_i|G) = \prod_{j=1}^L G_{ij}^l$ (15.9)

and the probability to observe $r_i$, given the set of $k$ generalized haplotypes $\mathcal{G} = \{G^1, \dots, G^k\}$ with $\{f_1, \dots, f_k\}$, is $Pr(r_i|\mathcal{G}) = \sum_{j=1}^k Pr(r_i|G^j)$.

The objective of kGEM is to find an optimal $G^* = \{G^1, \dots, G^k\}$ of $k$ generalized haplotypes that are most likely emitted $R$,

> $G^* = \arg \max_{|G|=k} \prod_{i=1}^N Pr(r_i|G)^{o_i}$ (15.10)
