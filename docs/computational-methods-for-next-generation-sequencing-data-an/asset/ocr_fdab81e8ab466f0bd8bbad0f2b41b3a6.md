Orhelia is a two-stage algorithm that first extracts relevant features via linear discriminants and then combines these in a neural network to create a gene prediction model (59). MetaGUN environmental sequences into taxonomic bins by k-mer frequencies prior to training a support vector machine (SVM) to identify binned ORFs (60). The Prokaryotic Dynamic Programming Gene-finding Algorithm (Prodigal) provides an efficient heuristic capable of identifying ORFs using alternative genetic codes from anonymous input sequences (61).

MetaProdig (62), an optimized version of Prodigal developed for sequence information, uses 500 training files derived from a pair-wise distance matrix composed of 1415 NCBI RefSeq genes. By calculating the content of each input sequence, MetaProdig uses only those training profiles within a GC range increasing computational efficiency. Moreover, a Bonferroni-correction (63) process reduces false-positive identification on short reads by combining penalties for sequence length, number of training files used, and length of the predicted ORF. When benchmarked against other ORF methods tuned for anonymous and short read sequences, MetaProdig performs exceptionally well with improved site identification (60). Given these outcomes, open source code and widespread use at major sequencing centers Prodigal/MetaProdig was integrated into MetaPathways although alternative prediction algorithms can be readily introduced based on user preference.
