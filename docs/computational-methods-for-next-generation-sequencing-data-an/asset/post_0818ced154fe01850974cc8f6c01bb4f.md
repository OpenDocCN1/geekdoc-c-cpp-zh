## 2.5.1 Large Table Comparisons

MetaPathways supports display and interactive comparison of functional and taxomic annotations from multiple samples. Tabulated annotations can be compared in a supermatrix composed of product descriptions, taxonomic assignments, and predicted pathways, each declined into the KEGG, COG, SEED, NCBI Taxonomy, and MetaCyc hierarchies, using the Knowledge Engine data structure. In addition to supporting standard search, sort, and export functions, the Knowledge Engine data structure allows users to dynamically compare and export subsets of genes or pathways through hierarchical levels even when samples contain millions of annotations.

One of the primary barriers for biologists using code is data formatting. Input files must be delimited correctly and free of noncompliant characters. Fortunately, Pathway Tools allows for ePGDBs to be programmatically accessed via API (https://arabidopsis.org/biocyc/percy/index.jsp) for the and languages. Two common ways tables are formatted for statistical software are the so-called wide and long tables; a part of a collection of data organization concepts that Hadley describes as “tidy data” (http://vita.had.com/papers/tidy-data.pdf). The wide format is intuitive to most users (it is sometimes referred to as “master table”). In wide format, each variable has its own column. While compact and appropriate for some analytical tasks (principal analysis (PCA), Clustering, etc.), for other packages such as ggplot2 a long format is adopted where each row represents one. It is important to understand how to use the melt() and dcast() functions in the reshape2 R package to convert between the two formats.

## 2.5.4 Venn Diagrams

Once a user has loaded a list of pathways into R, it becomes possible to isolate the list of pathways found in each sample and compare differences setdiff(a,b) and intersect(a,b) between sets. The lists generated by these set operations will be useful for selecting and setting up plots and identifying pathways of interest for more-depth exploration.
