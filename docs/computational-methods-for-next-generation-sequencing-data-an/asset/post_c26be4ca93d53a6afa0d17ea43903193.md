The main challenges associated with this approach are the requirement for efficient clustering of a large number of NGS reads and the lack of information on the number of actual clusters (i.e., the number of real haplotypes). Different algorithms handle these challenges differently.

The first clustering-based approach for the NGS error correction in viral samples was proposed in Reference 28, and its basic scheme is summarized in the algorithm for NGS error correction in viral data using k-means clustering. This algorithm estimates the number of haplotypes as follows: given a multiple sequence alignment of reads, the significance of mutations in each alignment column is tested using the null hypothesis of a single haplotype, which implies that the probability to observe at least $l$ mutations in that column follows the binomial distribution and is equal to

```
$P(X \ge l) = \sum_{i=l}^{d} \binom{d}{i} \epsilon^i(1-\epsilon)^{d-i}, \quad (15.1)$
```

where $d$ is the number of reads that overlap the position corresponding to the column under consideration and $\epsilon$ is the sequencing error rate. Under the null hypothesis, the test for pairs of mutations is the probability of having $l$ co-occurrences in two different alignment columns $i$ and $j$, which is given by the formula:

```
$P(Y = l) = \frac{\binom{n_i}{l} \binom{d-n_i}{n-l}}{\binom{d}{n}} (15.2)
```

where $n_i$ and $n_j$ are the number of times the mutations under consideration have been observed in columns $i$ and $j$. Initially, the expected number of haplotypes is defined as the sum of significant mutations and pairs of mutations; however, this number can be an overestimation of the real haplotypes number, and several approaches to reduce this overestimation are proposed (28).

- **Algorithm NGS Error Correction in Viral Data Using k-Means Clustering (28)**
Require: An alignment of reads, which can be constructed, for instance, using a pairwise alignment with a reference genome
1: Partitioned reads into windows over the alignment.
2: for each window do
3: Estimate $k$-the number of haplotypes in the window using a statistical testing to identify significant mutations and pairs of mutations, which can be associated with separate haplotypes. Significant mutations and pairs of mutations are found using the binomial and Fisher's exact tests, respectively.
4: Partition reads into clusters using $k$-means clustering with the Hamming distance defining clusters' membership and correct reads into their clusters' centers.
5: end for

The clustering approach to error correction was further developed in SHOR (23–25). This approach resolves the problem associated with the unknown number of clusters by assigning reads to existing clusters or introducing new clusters using Dirichlet process mixture (DPM).

SORAH is based on the following probabilistic model. It assumes that all $N$ reads are produced from haplotypes via random sequencing errors regulated by the error parameter $\theta$, while all haplotypes originate from a reference genome via an evolutionary process based on random mutations regulated by the mutation probability parameter $\gamma$. Then, the probability of read $r_i$ being erroneously emitted from the haplotype $h_k$ can be estimated as

```
$Pr(r_i|h_k, \theta) = (1-\theta)^{l-d(r_i,h_k)} (\frac{\theta}{3})^{d(r_i,h_k)} (15.3)$
```

and the probability to observe the set of reads $\mathcal{R} = \{r_1, \dots, r_N\}$ given the set of haplotypes $\mathcal{H} = \{h_1, \dots, h_K\}$ and the set of clusters $\mathcal{C} = \{C_1, \dots, C_K\}$ (where the haplotype $h_k$ represents a center of the cluster $C_k$)

```
$Pr(R|C,H,\theta)=\prod_{k=1}^K\prod_{r_i\in C_k}Pr(r_i|h_k),
```

where $L$ is the length of the studied genomic region and $d(r_i, h_k)$ is Hamming distance between sequences $r_i$ and $h_k$ (in Reference 23 the notation is used). Analogously, probability of a haplotype $h_k = (h_{k,1},\dots,h_{k,L})$, given the cluster associated with it, can be estimated as

```
$Pr(h_k|C_k,\theta)=\prod_{j=1}^LPr(h_{k,j}|C_k,\theta).
```

where probability $Pr(h_{k,j}|C_k,\theta)$ of the $j$th base of $h_k$ is calculated as

```
$Pr(h_{k,j}|C_k,\theta)=\frac{(1-\theta)^{m_{h_{k,j}}(h_k)}}{3^{n-m_{h_{k,j}}(h_k)}}\sum_{i=1}^4(1-\theta)^{m_{b_i}(b_u)}}{3^{n-m_{b_i}(b_u)}}
```

where $(b_1,b_2,b_3,b_4)=(a,c,t,g)$ are the bases and $m_{h_k}(b_u)$ is the number of reads from cluster $C_k$ having the base $b_u$ in its position.

Finally, SHORAH requires the calculation of the likelihood $Pr(r_i|ref,\theta,\gamma)$ of the emission of $r_i$ by one of the haplotypes originated from the reference genome, which is estimated as

```
$Pr(r_i|ref,\theta,\gamma)=\sum_{k=1}^KPr(r_i|h_k,\theta)Pr(h_k|ref,\gamma)
```

SHORAH iteratively re-assigns reads to clusters or introduce new clusters using formulas (15.3) and (15.7), sample haplotypes base-by-base from the constructed clusters using formula (15.6), and re-estimated $\theta$ and $\gamma$. Reads are assigned to existing or new clusters according to the probability DPM, which is estimated as follows

```
$Pr(r_i|C_k\setminus\{r_i\},\theta,\gamma)=\frac{|C_k\setminus\{r_i\}|}{|C_k|-1+\alpha}Pr(r_i|h_k,\theta) \text{if } |C_k\setminus\{r_i\}|>0;\frac{\alpha}{|C_k|-1+\alpha}Pr(r_i|ref,\theta,\gamma), \text{ otherwise.
```

Here, $\alpha$ is the parameter, which controls the utilization of existing clusters. The clustering approach to error correction was further developed in kGEM29. Instead of minimizing intruster distances (like in k-means), kGEM maximizes the likelihood of the observed populations.

### Algorithm SHORAH Error Correction

```
1: Initialize the algorithm by randomly assigning reads to clusters
2: while not all reads are assigned
3: $K \leftarrow |C|$
4: for $r_i \in R$ do
5: if $r_i$ has been assigned to the same haplotype more than 80% of iterations then
6: assign $r_i$ to $h_k$
7: end if
8: end for
9: Estimate parameters $\theta$ and $\gamma$ as follows:
$\theta \leftarrow \frac{\sum_{i=1}^N d(r_i, h_k)}{NL}$
$\gamma \leftarrow \frac{\sum_{k=1}^K d(h_k, ref)}{K}$
10: recalculate clusters using (15.8)
11: while
```

Ensure the set of haplotypes. Formally, alignment of a given set of unique reads $R = \{r_1, \dots, r_N\}$ with multiplicities $[o_1, \dots, o_N]$ be represented by $N \times L$ matrix $A$, with rows corresponding to reads and columns to alignment positions. For a given set of reads $C' \subseteq R$, a generalized haplotype $G = g(C')$ with a multiplicity $m_j = \sum_{i \in C'} o_i$ is a $5 \times L$ matrix, with columns representing alignment positions and rows representing the bases $\{a, c, t, g, d\}$; the value $G'_{em}$ is the frequency of the base $e$ in $m$th position among all sequences in $C'$. The probability of the read $r_i = (r_i^1, \dots, r_i^f)$ being emitted by a generalized haplotype $G$ can be estimated

```
$Pr(r_i|G) = \prod_{j=1}^L G_{ij}^l (15.9)$
```

and the probability to observe $r_i$, given the set of $k$ generalized haplotypes $\mathcal{G} = \{G^1, \dots, G^k\}$ with $\{f_1, \dots, f_k\}$, is $Pr(r_i|\mathcal{G}) = \sum_{j=1}^k Pr(r_i|G^j)$.

The objective of kGEM is to find an optimal $G^* = \{G^1, \dots, G^k\}$ of $k$ generalized haplotypes that are most likely $R$,

```
$G^* = \arg \max_{|G|=k} \prod_{i=1}^N Pr(r_i|G)^{o_i} (15.10)$
```
