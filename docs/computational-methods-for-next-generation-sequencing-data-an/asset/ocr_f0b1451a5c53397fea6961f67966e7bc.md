# COMPUTATIONAL METHODS FOR NGS DATA ANALYSIS

$TPR = \frac{TP}{P}$
PPV = \frac{TP}{TP + FP}$
$F_{score} = \frac{2 \cdot TPR \cdot PPV}{TPR + PPV}$

We compare TPR is sensitivity and PPV is positive predictive value.

# 5.4.3 Evaluation and Comparison

We compare ScaffoldMatch and SILP2 with well-established scaffolds SSPACE, OPERA, SOPRA, MIP, SCARPA, as a recently published scaffold, BESST (22). Almost all the scaffolds were run with their default settings using Bowtie2 reader align. OPERA, SSPACE, and BESST were run using Bowtie.
For computing TPR, PPV, and F-score, we used scripts proved in Reference 26. Note that BESST in the last three days failed to produce results due to software exceptions.
