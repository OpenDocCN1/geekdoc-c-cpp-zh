BRAT introduced different bit representations of a genome and reads; it maintains two separate bits, ta-representation and cg-representation, one bit per letter. In the ta-representation, all Cs are converted to Ts and all Gs are converted to As and bit 1 is assigned to Ts and bit 0 to As. In the cg-representation, Cs and G are converted to 1 and As to 0. Whether one uses hashing or the BWT, once the potential genomic positions are identified, a full-length alignment is performed to estimate the accuracy of each mapping. Different tools choose different alignment strategies. Some tools employ a version of Smith-Waterman algorithm (24) that allows for insertions and deletions of nucleotides in a read (Mash, BISS); others use the Hamming distance to count the non-BS-mismatches (RMAP-bs, BRAT-bw, BMap); the tools used Bowtie (25) as an underlying mapping tool use Bowtie's output to score the alignments (Bismark, BS-Seeker). If a read is mapped to two or more genomic locations with the same score, it is considered ambiguous and usually is not considered for further methylation analysis estimation.

### 10.4 METHYLATION ESTIMATION

After bisulfite-treated reads have been mapped to the reference, copy duplicate removed, and ambiguously mapped reads discarded, the methylation state of each cytosine can be estimated. Each read mapped to the cytosine represents DNA methylation in the cell. 

Different tools choose different alignment strategies. Some tools employ a version of Smith-Waterman algorithm (24) that allows for insertions and deletions of nucleotides in a read (Mash, BISS); others use the Hamming distance to count the non-BS-mismatches (RMAP-bs, BRAT-bw, BMap); the tools used Bowtie (25) as an underlying mapping tool use Bowtie's output to score the alignments (Bismark, BS-Seeker). If a read is mapped to two or more genomic locations with the same score, it is considered ambiguous and usually is not considered for further methylation analysis estimation.

### 10.5 POSSIBLE BIASES IN ESTIMATION OF METHYLATION

In the scientific literature, some argue that mapping reads allowing T–C mismatches and not allowing C–T mismatches may introduce a bias in the correct estimation of methylation level because reads not containing C have more chance of mapping to different genomic positions (15). To avoid this, Bism considers a read ambiguous (mapped to multiple locations) if the reads are mapped using reduced three-letter alignments. BS-Seeker use a similar approach; it disregards reads, and for the rest of the reads, it re-calculates the number of non-BS-mismatches and keeps only uniquely mapped reads with the best score.

One counter-argument that allowing C–T matches also introduces a bias toward overestimating the number of unmethylated cytosines in reads mapped to the reference. Read containing cytosines that could have been unambiguously mapped with methylation alignment (allowing C–C and T–T matches only) might become ambiguous and be disregarded from further analysis when T–C and C–T mappings are allowed; the contribution of C from this read to the count of total number of cytosines mapped to the cytosine in the genome is lost, affecting the estimation of methylation level. BRAT-bow offers an option to select between the two approaches: allow C–T mismatches or not.
