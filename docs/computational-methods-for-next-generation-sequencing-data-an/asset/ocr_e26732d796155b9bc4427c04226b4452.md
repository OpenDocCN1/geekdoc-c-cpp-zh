In contrast, the set cover instance solved by IsoInfer merges the solutions obtained for substances of the original isoform reconstruction problem. To cope with the combinatorial complexity of the problem, IsoInfer decomposes the instance into substances and solves them independently. The solution to the set cover instance combines the solutions to the substances in such a way that a small subset of the most frequent transcripts explain (cover) all the reads and all provided transcription start and polyadenylation sites.

When isoforms and their expression levels are obtained through minimizing a loss function that measures the deviation of the estimated number of reads from the observed data (see Section 11.3 for an example), incompleteness (underestimation) is penalized in a global attempt to balance deviations in both directions, by using positive or negative values of $\epsilon$ in (11.2) simultaneously across all observations $b_j$. Despite minimizing (11.3), however, Isolasso sets additional lower bounds for completeness by introducing constraints that require the estimated number of reads on each observed segment to be above a certain threshold.

# 11.3.5 Extensions

In the previous sections, we described the general principles underlying current methods for the transcript assembly problem. In practice, many features play an important role in the applicability of a software tool in a specific context. Clearly, the extent to which a method depends on an existing annotation, from being completely independent of any annotation, as Cufflinks, to incorporating the known transcript start sites and polyadenylation sites, as is the case for iReck, determines the suitability of a method for the problem at hand. Methods also consider gravely in the way they employ read pairing information. Some methods ignore this information completely (TRAPH) or use it in the abundance estimation (Cufflinks), while others apply read mapping signatures for filtering or for additional support (MITIE, CLASS, Script), and other links it to an empirically estimated length distribution (SLIDE).

As an additional design consideration, few in particular MITIE and CLIQ, are to jointly analyze multiple RNA-seq data sets. Lastly, models additionally incorporate solutions to modeling biological phenomena or data artifacts, including unspliced pre-mRNA and intron retention events (32), PCR amplification biases (32) or a GC content bias (33), and reads to multiple locations on the genome.
