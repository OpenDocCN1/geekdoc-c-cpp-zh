Table 10.1 shows the parameters used with each tool and Figure 10.2 shows accuracy (x-axis) with the total number of uniquely mapped reads (y-axis) calculated for the corresponding parameter sets. BRAT-bw has only four user-defined options K, m, C, and F regulate mapping accuracy and the number of mapped reads: The option K sets the number of seeds used with each read, the larger value of K, the more reads are mapped and more accurate the mapping. The option m sets the maximum allowable non-BS-mismatches in reads (mismatches other than BS-mismatches). The larger m, the more reads are mapped, the quality of mapping may be degraded. With the option F set 1, BRAT-bw guarantees to full mapping for the reason; the tool uses 1 with slightly mismatch more reads found and with a slight improvement in accuracy. Finally, option C allows a read to be mapped to T in a genome; with this option, more reads are mapped, but it is questionable whether these matches (C in a read to T in genome) should be allowed.

BS-Seeker is the most powerful tool among the three discussed in flexibility of control it supports all options available with Bowtie2, and Bowtie2 has many different ways to control the quality of the alignment and the number of mapped reads. Using the default parameters is not the best choice for any data as observed on Figure 10.2: BS-Seeker had the smallest mapping efficiency and the lowest mapping accuracy with default parameters.
