11.3.2.1 Two-Stage Optimization Methods in this class follow a two-stage procedure, first determining a set of transcripts and then assigning reads to estimate their expression levels. More formally, in terms of the optimization criteria introduced in the beginning of Section 11.3, these methods treat the minimality of the solution separately from accuracy. Programs in this class include Cufflinks (6), CLASS (35), CLIQ (30), TRAPH (29), and InSofer (34). In the following, we explain the strategies and the underlying mathematical foundations for each of these approaches.

We start with the most prominent example in this class, Cufflinks (6), which aims at finding the minimum number of transcripts or paths in the overlapped graph, which explain all input reads. More formally, Cufflinks models isoform selection problem as a Minimum Path COVER in a directed acyclic graph. Given a directed graph G=(V, E), in this case the algorithm finds a small set of directed paths such that every vertex v belongs to one path. The Minimum Path COVER problem is computationally hard (n.b., NP-hard), it can be efficiently solved for directed acyclic graphs such as the overlap graph. Along with Fulkerson’s proof of Dilworth’s theorem (38), a bipartite graph G' can be constructed from an overlap graph G=(V, E) such that König’s theorem has a matching of size m and only if there exists a cover in G of size n–m. Additionally, Cufflinks assigns a cost to edges in G' such that coverage inhomogeneities along a path are penalized. The minimum path cover in G is obtained in (6) from a min-cost maximum cardinality matching in G', which can be computed in time O(V+E log V).

Similarly, CLASS (35) aims to determine the minimum number of transcripts that collectively satisfy all constraints from spliced and paired-end reads. Formally, it calls the transcript selection process a SET COVER problem, where maximal paths (transcripts) are represented as sets of constraints that can potentially originate from each of the isoforms. A constraint is defined as a class of reads that share the same splicing and exon pattern. In a variation, weights assigned to the sets (isoforms) can incorporate knowledge on gene structure from external databases. Since SET COVER is itself an NP-problem in its general form, CLASS approximates the optimal solution to the set cover instance by a fast greedy algorithm.

In another example, CLIQ (30) formulates an integer program (ILP) that seeks to determine the minimum number of isoforms required to explain the reads well. More precisely, it minimizes the number of expressed transcripts that, for all exons and exon junctions, the estimated number of reads lies within a small factor of (1+ε) of the observed reads, with ε being a user-defined threshold. The solution is subject to the constraints: (i) for every junction, the estimated number of reads is at least the minimum number of reads over all junctions and (ii) the estimated expression level of an isoform is at most a factor of (1+ε) larger than the minimum expression level of its exons and exon junctions.
