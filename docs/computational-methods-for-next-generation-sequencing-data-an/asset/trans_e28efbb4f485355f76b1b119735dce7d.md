### 7.1 引言

尽管二代测序（NGS）实验已成为标准，但对数据的探索仍然面临挑战。NGS 实验通常旨在提供遗传变异目录，用于后续感兴趣的分析。在群体研究中，例如“荷兰基因组”或“1000 人类基因组”等倡议（1, 2），此类目录能够反映群体遗传多样性的全貌。在癌症基因组研究中（全球倡议请参见参考文献 3），需要寻求体变异的全面列表，以帮助理解癌症（亚）类型和疾病进展，并选择合适的治疗方案。

在本章中，我们关注用于二代测序研究的技术，这些技术可以展示*供体基因组*（待研究基因组）与参考基因组之间的差异。重测序研究的通用工作流按以下步骤进行：

- (1) 将目标基因组的 DNA 断裂成片段。
- (2) 对片段进行二代测序，产生*reads*（reads）。一种非常流行且有用的技术是生成*双端序列*（paired-end reads），其片段的两端都与一个内部部分（即*内部段*）一起测序，而该内部段未测序。

### 7.1.1 暮光缺失

在本章中，我们关注由于长度原因难以发现的缺失。如前所述，短缺失以及长缺失不再是主要困难，甚至已成为最佳实践工作流的一部分。中等缺失（我们称之为“NGS 暮光缺失”）在 2009 年后变成了巨大的计算挑战。最近的进展使得它们的发现成为可能。这一证据是，来自群体规模项目（9, 10）的缺失目录包含了大量的暮光缺失，且具有极好的验证率。这与相关项目（特别是 1000 基因组计划）形成了鲜明对比。

### 7.2 符号

我们主要关注重测序研究中最广泛使用的双端序列。令 $\Sigma = \{A, C, G, T\}$ 为碱基酸集合。双端序列由两个序列 $r_1$ 和 $r_2$ 组成，已知它们在参考基因组上的距离为 $L$。当 $r_1$ 和 $r_2$ 比对到参考基因组的位置 $x_1$ 和 $x_2$ 时，它们之间的距离为 $|x_1 - x_2|$。预期距离为 $L$，但由于文库准备的性质，观测到的距离 $|x_1 - x_2|$ 会围绕 $L$ 变化。r_1$ 和 $r_2$ 之间未测序的基因组片段被称为内部段，其长度为 $I(A)$。如果 $x_1 < x_2$，且 $r_1$ 从 $x_1$ 开始且长度为 $length(r_1)$，则内部段跨越从 $x_1 + length(r_1)$ 到 $x_2$ 的区域。如果 $x_2 < x_1$，则其长度为 $I(A) = x_1 - (x_2 + length(r_2))$。

### 7.2.1 比对

比对 $A=(A_1,A_2)$ 可以被比对，其中间隙表示插入或缺失。为了简单起见，我们假设每个比对最多显示一个间隙。用 $u_g$ 表示间隙之前的参考位置，用 $z_g$ 表示紧随间隙的参考位置。相应，我们将 reads 中间隙之前的位置称为 $u_A$，间隙之后的位置称为 $v_A$；因此，参考序列 $\mathcal{G}[u_g]$ 比对 $R[u_A]$，而 $\mathcal{G}[z_g]$ 比对 $R[v_A]$。取决于 $z_g = u_A+1$（参见 7.1 中的比对 D）还是 $u_g = v_A+1$（参见比对 C），间隙表示供体基因组中的插入（插入序列为 $R[u_A+1, v_A-1]$）或供体基因组中的缺失（缺失序列为 $\mathcal{G}[u_A+1, z_g-1]$）。

### 7.2.3 缺失

令 $D_L$ 和 $D_R$ 为缺失 $D$ 的左边界和右边界的参考坐标。也就是说，从位置 $D_L$（包括）到所有位置 $D_R$（包括）的碱基共同构成了序列 $\mathcal{G}[D_L, D_R]$ 在供体基因组中缺失。我们定义 $C(D) := \frac{D_L+D_R}{2}$ 为 $D$ 的中心（不需要是整数），并定义 $L(D) := D_R-D_L+1$ 为缺失的长度。我们通过其中心 $C(D)$ 和长度 $L(D)$ 对缺失 $D=(C(D), L(D))$ 进行参数化。
