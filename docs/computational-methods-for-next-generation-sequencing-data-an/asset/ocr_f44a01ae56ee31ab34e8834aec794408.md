there is a read pair whose two ends are mapped to $[s_1, e_1]$ and $[s_2, e_2]$, respectively, on the reference genome ($s_1 < e_1 < s_2 < e_2$), and this pair is an encompassing pair for the split read, whose location is determined by the mapping of the soft-clipped segment of the split read. Let $l$ be the expected insert size and $\sigma$ be the standard deviation of the insert length. Note that $l$ measures the outlier of the pair (i.e., the distance between the two farthest points of the two reads). We denote the length of the two encompassing pair as $l_1$ and $l_2$, respectively. Suppose the minimum deletion to be detected by SVseq2 is $m_d$. SVseq2 sets $m_d$ to 50.

**Lemma 1.** For type I pattern, $s_2 \geq a$, and with high probability, we have $s_2 \leq a - l_1 - l_2 + l_3 + 3\sigma$.

*Proof.* If $s_2 < a$, then $a$ is not a breakpoint. This does not agree with our underlying assumption that the mapped segment $[a, b]$ corresponds to a deletion. To give an upper bound on $s_2$, note that $a$ is the position on the reference $a = l_{del}$ where $l_{del}$ is the length of the deletion. Now with high probability, the distance between $s_2$ and $e_1$ is at most $l_1 - l_1 - l_2 + 3\sigma + l_{del}$ on the reference. With so high probability $s_2 \leq (a - l_{del}) + l_1 - l_1 - l_2 + 3\sigma + l_{del} = a - l_1 - l_2 + l_3 + 3\sigma$.*

Lemma 1 states that the encompassing pairs are very likely to be detected. For a split read, SVseq2 searches for reads on the reverse strand this region for encompassing pairs. Now suppose we find one encompassing pair for the split read $[s_1, e_1]$ and $[s_2, e_2]$. The following lemma specifies the range of $c$ (i.e., the starting point of the soft-clipped segment).

**Lemma 2.** For type I pattern, $e_1 - l_i, c \leq a - m_d - l_c$. Moreover, with high probability, we have $c \leq e_1 + l_i - s_1 - l_1 + 3\sigma$.

*Proof.* That the rightmost position of a deletion can be $m_d$ to the left of $a$ on the reference because the minimum deletion size is $m_d$. So $c \leq a - m_d - l_c$.
