A short DNA molecule is circularized and sequenced multiple times. The long read contains the single-molecule sequences that differ only in sequencing errors from the same molecule. The single-molecule sequences can be extracted by identifying and cutting the adapters. In a postprocessing step, an algorithm iterates over all alignments of the single-molecule sequences and generates a circular consensus sequence. With this approach, PacBio produces reads of much higher accuracy, as their errors are truly random, compared to all other technologies.
