Hadoop Hadoop (32) is an open source framework for developing data-intensive applications in the cloud. Hadoop natively supports Java, and it can only run on the Linux-based cluster. Hadoop can be extended to support other languages, such as Python, C, and C++. Hadoop has implemented the model of MapReduce: inputs are partitioned into logical records and processed independently by mappers; results from multiple mappers are sorted and merged into distinct groups; and the architecture of Hadoop is shown in Figure 1.6 and the workflow is Input() → Map() → Sort(Merge) → Reduce() → Output. The components of Hadoop are organized as a master-slave structure. When developing Hadoop applications, we only need to specify three items: Java classes defining key/value pairs, mapper, and reducer (32).

The foundation of Hadoop to support the Reduce model is the Hadoop Distributed File System (HDFS). HDFS integrates the shared file system as one file system logically. It also provides a Java-based API to handle file operations. The service of HDFS is functionally based on two processes, NameNode and DataNode. NameNode is in charge of control services, and DataNode is in charge of block storage and retrieval services (32). For the scheduling of jobs on each VMs or operating system, Hadoop uses two processes, TaskTracker and JobTracker. TaskTracker schedules the execution order of each mapper and reducer on slave computing nodes. JobTracker is in charge of job submissions, job monitoring, and distribution of tasks to TaskTrackers (32).
