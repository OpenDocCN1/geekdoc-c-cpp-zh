2. Random graphs, where each vertex $v$ receives a random titer $w_v \in \{1, L\}$, and two vertices $u$ and $v$ are adjacent if and only if $|w_u - w_v| \le R$. This family of tests represents titer compatibility model, that is, in which two pools could be mixed into one pool only if their titers are not sufficiently different.

Twenty-five thousand test instances were generated with $n = 10, \dots, 1000$, with parameters $L = 20, R = 4$, and thresholds of pools' size $T = n$ (i.e., with the threshold), $T = 55, T = 35$, and $T = 25$. For each $n$, the mean size of the set of pools constructed by the VSPD algorithm and the mean reduction coefficient (i.e., the number of pools divided by the number of samples).
