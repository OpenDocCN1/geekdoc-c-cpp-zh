Orhelia is a two-stage algorithm that first extracts relevant features via linear discriminants and then combines these in a neural network to create a gene prediction model (59). MetaGUN environmental sequences into taxonomic bins by k-mer frequencies prior to training a support vector machine (SVM) to identify binned ORFs (60). The Prokaryotic Dynamic Programming Gene-finding Algorithm (Prodigal) provides an efficient heuristic capable of identifying ORFs using alternative genetic codes from anonymous input sequences (61).

MetaProdig (62), an optimized version of Prodigal developed for sequence information, uses 500 training files derived from a pair-wise distance matrix composed of 1415 NCBI RefSeq genes. By calculating the content of each input sequence, MetaProdig uses only those training profiles within a GC range increasing computational efficiency. Moreover, a Bonferroni-correction (63) process reduces false-positive identification on short reads by combining penalties for sequence length, number of training files used, and length of the predicted ORF. When benchmarked against other ORF methods tuned for anonymous and short read sequences, MetaProdig performs exceptionally well with improved site identification (60). ## 2.3.2 Functional Annotation

Following ORF prediction, MetaPathways uses either BLAST or LAST seed-and-extend algorithms (33, 64) to query user defined protein sequence databases for functional annotations. One of the most comprehensive and rapidly expanding public databases for automated functional annotation is the National Center for Biotechnology Information (NCBI) redundant Reference Sequence (RefSeq) database. For example, the RefSeq Version 66 database released in July 2014 contained almost 60 million reference sequences with 20 million entries added in the last 12 months alone (Figure 2.4). ## 2.3 Analysis Modules

The third stage of pipeline operation constructs modules currently focused on transfer RNA (tRNA) and rRNA gene identification as well as taxonomic annotation and functional gene profiling.

2.3.1 tRNA Gene Identification Transfer RNA genes comprise an extensive multicopy gene family termed usage and expression patterns in viral and cellular genomes. MetaPathways implements tRNA scan (version 1.4) using default parameters to identify RNAs from nucleotide sequences (70). Resulting tRNA identifications are exported to the results/tRNA/directory.

2.3.2 rRNA Gene Identification All cellular genomes encode ribosomal RNA genes (Figure 2.5a and b).
