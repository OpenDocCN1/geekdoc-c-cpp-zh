# Algorithm OCBGRP: Optimal Cut Bi-Graph Problem Algorithm

```
1: Find solution (X, Y') of 0.5-approximation algorithm for Maximum Cut [36] applied to the graph H.
2: Apply 2-29 to initial solutions($A^0, B^0$) = (X, Y) and ($A^0, B^0$) = (Y, X)
3: $i \leftarrow 0$; tabu $\leftarrow (0, \dots, 0)$; optStates $\leftarrow \emptyset$; moveList $\leftarrow \emptyset$
4: while true
5: for $u \in V$ calculate $\delta_u$ using relations (3.8),(3.9):
   $\delta_u \leftarrow 1$, if $u \in A'$ and $tabu_u = 0$;n   $\delta_u \leftarrow 2$, if $u \in B'$ and $tabu_u = 0$;n   0, if $tabu_u > 0$;n6: end for
7: $\delta^* \leftarrow \max{\delta_i\}$; $u^* \leftarrow \arg \max_{i=1,\dots,n} \{\delta_i\}$
8: Update the tabu state, that is,
   $tabu \leftarrow tabu-1$, if $tabu>0$;n   0, otherwise;
9: if $\delta^* > 0$ move the vertex $u^*$ to another part of the cut ($A^*, B^*$)
10: Push $u^*$ into the stack moveList
11: end if
12: if $\delta^* = 0$
13: if $c(A^*, B^*) > c(A^*, B^*)$ then $(A^*, B^*) \leftarrow (A^*, B^*)$
14: end if
15: if moveList $
eq \emptyset$ then pop $v$ from moveList and move $v$ back
16: Forbid the vertex $v$ for the next $k$ iterations: $tabu^{i+1} \leftarrow k_r$;n17: end if
18: $s \leftarrow ((A^{i+1}, B^{i+1}), tabu^{i+1})$
19: if $s \in optStates$ then optStates $U[s]$; $i \leftarrow i+1$ continue
20: else
21: while $|A^*| > T$ do $a \leftarrow \argmin[deg_{B^*}^*(a) - deg_{A^*}^*(a), | a \in A^*]$
22: $(A^*, B^*) \leftarrow (A^* \setminus \{a\}, B^* \cup \{a\})$
23: end while
24: return $(A^*, B^*)$
25: end if
26: end while
```

At each iteration, Algorithm OCBGP tries to improve the current solution by moving one vertex from part of the cut to another part (steps 4–7). After the calculations for the cut improvement, the current tabu state is updated (step 8), and if the current solution can be improved, the algorithm does it and proceeds to the next iteration (steps 9–12). If the current $(A', B')$ cannot be improved, it is a local optimum (steps 13–32). According to (3.8), $A'$ is a clique.
