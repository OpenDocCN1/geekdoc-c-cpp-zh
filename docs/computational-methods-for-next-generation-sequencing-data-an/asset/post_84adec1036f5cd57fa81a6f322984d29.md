EULER-SR (37) corrects errors in a read $r$ of length $|r|$ weak $k$-mers by solving the following optimization problem: find a sequence $r^*$, which contains only solid $k$-mers (*solid sequence*) such that the edit distance $d(r, r^*)$ is minimal. This can be solved using a dynamic programming as follows: Let $S_k$ be a set of all solid $k$-mers. For any integer $i \leq |r|$ and $a \in S_k$, the score function $score(i, a)$ is defined as the minimum edit distance between a prefix of $r$ of length $i$ and all solid strings, which has $a$ as a suffix. This function can be computed recursively with this relation:

```
$score(i, a) = \min_{X \in\{A,C,T,G\}} \begin{cases} score(i-1, X \sqcup a_{k-1}) + 1, & \text{if } s_i \neq a_k; \ 0, & \text{if } s_i = a_k; \end{cases}\nscore(i-1, a) + score(i, X \sqcup a_{k-1}) + 1, (15.15)
```

where $X \sqcup a_{k-1}$ is connected to a character $X$ and the prefix of $a$ of length $k-1$, and the initial condition is $score(0,a) = 0$ for all $a \in S_0$. Solution of the error correction problem corresponds to the optimal score $\min_{a \in S_r} score(|r|, a)$. The optimal and the corresponding solid string can be calculated by finding a shortest path between vertices with in-degree 0 and vertices with out-degree 0 in a relation $G_{rel}$ with vertices connected to pairs $(i, a)$ $(i \in\{0, \dots, |r|\}$, $a \in S_i)$ and to $(i_1, a)$ and $(i_2, a)$ being connected by an arc, if they belong to the same recurrence relation with $(i_2, a_2)$ as the left-hand side.

This approach produces what exact solution, but it is highly time- and memory-consuming. In Reference 37, several heuristic approaches were used to improve the algorithm performance; however, none is scalable for longer reads.

KEC (15) uses a different heuristic to error correction, which takes into account a possible nature of errors (such as high prevalence of errors in homopolymers) and utilizes information derived from the structure of previously detected regions. Corrections are based on the analysis of different factors, including the length of an error region, nucleotide sequences at its end, and the frequencies of similar solid $k$-mers. The procedure of error correction is repeated iteratively, after each read containing weak $k$-mers, which were not corrected, is discarded.

Let $h_i(X)$ be a homopolymer consisting of identical bases $X \in\{A,C,T,G\}$ $(i \geq 0$, for convenience we assume that any single base is also a homopolymer of length 1 and a homopolymer of length 0 is deleted). The error correction in KEC is based on the following lemma:

# COMPUTATIONAL METHODS FOR NGS DATA ANALYSIS

**Lemma 1. (15).** *Suppose that a read $r$ contains an error region $[i_e, j_e]$, which has the length $l = j_e - i_e + 1$, with the base $X$, is not a prefix or suffix of $r$ and was caused by a single error $E$. *Then*

- If $E$ is a nucleotide replacement, then $l = k$.
- If $E$ is an insertion creating a homopolymer of the length $p$ ($1 \leq p \leq k$), then $l = k - p + 1$ and the error region is followed by homopolymer $h_{p-1}(X)$.
- If $E$ is a deletion creating a homopolymer of the length $p$ ($0 \leq p \leq k$), then $l = k - p - 1$ and the error region is followed by homopolymer $h_p(Y)$, where $Y \neq X$.

For error regions with length not exceeding $k$, Lemma 1 allows to quickly and reliably detect and correct errors. However, it is not applicable to error regions greater than $k$. “Long” error regions may appear if two or more errors are separated by less than $k$ positions in the read, and prevalence of these regions depends on parameter $k$. The value of $k$ should be carefully chosen, since too small value hampers the reliable separation of $k$-counts of weak and solid k-mers. In different studies, the best results are achieved with $k = 5$ and $k = 3$. For example, the number of long reads was very low at $k = 5$ in samples studied in Reference 15 in comparison to the number of error regions of lengths not exceeding $k$ (Figure 15.5).

The basic scheme of k-mer-based error correction implemented in KEC is summarized in the “k-mer-based error correction implemented in KEC” as follows. It should be noted that at certain stages of this algorithm, several corrections of errors are possible (the algorithm chooses the correction producing k-mers with highest counts), for real data in the overwhelming majority of cases (95.9% on average) the correction producing a solid k-mer is unique. This reduces the impact of heuristic component of this algorithm and makes the results more reliable.

# Algorithm k-Mer-Based Error Correction Implemented in KEC

```
repeat
  for every r = (r_1, ..., r_l) containing error regions do
    for every error region l_i, l_j of r such that l = l_j - l_i + 1 ≤ k do
      if i_i ≠ 1 and l_j ≠ |r| - k + 1 then
        if l < k
          Identify the type and position of error E using Lemma 1. In this case, the identification is unique. For the insertion remove the base r_j; for the deletion r_i, it introduces a solid k-mer.
        end if
      if l ∈ {k-1, k}
        Identify the type and position of error E using Lemma 1. In this case, the error region can be produced by different errors. If l = k-1 and r_i = r_{i+1}, then E could be either insertion of r_i or deletion of the base X ≠ r_i between r_i and r_{i+1}. If l = k, then E can be replacement of one of the possible bases or insertion. In the case of ambiguity choose the correction, which produces a solid k-mer with the highest k-count.
        end if
    else
      Remove the prefix or suffix of r corresponding to the error region.
    end if
end for
Recalculate k-mers and error regions.
until all k-mers are solid or the predefined number of iterations is reached
Discard all reads containing error regions.
```

# 15.2.3 Alignment-Based Algorithms

In this section, we will consider several methods of NGS error correction for viral amplicons, which are based on sequence alignment. The main challenge associated with the application of alignment-based algorithms for viral amplicons is that a high-quality sequence alignment is computationally expensive, and the number of unique NGS reads is usually high due to the extreme heterogeneity of viral populations. Furthermore, viral heterogeneity also leads to the lack of good references, and the quality of alignment may be greatly affected by sequencing errors. However, in addition to a possible use of error correction algorithms, such methods can be extremely useful in a pipeline with clustering-based or k-mers-based algorithms as post-processing for data previously cleaned by these algorithms, when the number of unique reads and sequencing errors is greatly reduced, but a significant number of errors still remain.

Two alignment-based methods were proposed in Reference 15. The first of these methods is described in "KEC postprocessing using alignment" algorithm. In Reference 15, it is used as a postprocessing step for KEC algorithm described in the previous section. It corrects errors and performs local haplotype reconstruction, that identifies haplotypes and their relative frequencies.

The second algorithm (15) uses empirical frequencies for indels and haplotypes obtained from a parameter calibration based on experimental sequencing for artificially created single-clone sets with known clone sequences. An indel is defined as the maximum frequency of indels in single-clone data, and a haplotype frequency threshold is estimated as the weighted average frequency of haplotypes + 9 standard deviations. For instance, for 454/Roche GS platform and HCV region, the indel and haplotype thresholds were estimated as 5.9% and 0.4%, respectively. The work consists of the following steps:

- (1) External 'references' alignment and length filtering. Each unique read is aligned against a set of external references for the sequenced genomic region. For each read, the best set of reference of the length L is chosen, and reads with lengths less than 0.9L are deleted and reads with lengths greater than L are clipped to the set of corresponding reference.
- (2) Internal references' alignment. Internal reference set is constructed by selecting 20 most frequent reads with minimal numbers of indels with regard to the external references. Each read is aligned against the internal reference set and the closest internal reference is chosen.
- (3) Homopolymer errors' correction. Using alignments to internal references, homopolymers of at least 3 are long and indels in homopolymers are corrected. Multiplicities of reads are recalculated.
- (4) PCR or sequencing artifacts' removal. Using the internal reference, the number of indels in each read is calculated and reads containing at least T indels are discarded, where T is the weighted average of the number of indels in the data + 4 standard deviations.
- (5) Indel threshold and NS filtering. Reads that contain frequencies lower than the indel threshold are discarded. After that reads containing NS are also discarded. The latter step is performed at one of the latest stages of the algorithm to take advantage of the nucleotide frequencies at positions other than those with N.
- (6) Haplotypes frequencies filtering. Haplotypes with frequencies lower than the haplotype frequency threshold are removed.
