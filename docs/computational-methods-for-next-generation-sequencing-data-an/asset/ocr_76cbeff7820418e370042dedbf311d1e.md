When mapped to the reference genome, the alignments of these reads could have some characteristics different from the reads from regions without SVs. We call these characteristics as signatures. The categories of methods we mention utilize signatures of SVs. We focus on signatures of long deletions and long insertions in this section. For more signatures on other types of SVs, the reader can refer to reviews in the literature, for example, Reference 4.

To illustrate the concepts of signatures, we generate some small-scale simulated data sets. We generate only one type of NGS reads called paired-end reads. In Figure 8.2, a paired-end read is generated with two strands from a segment of the donor genome. The length of the segment is called insert size. Since we do not have the sequences of the entire set from the donor genome, we do not know the insert size of the paired-end. When the read is properly mapped, we use the distance of the two ends on the reference genome as the insert size. The underlying assumption is that the donor genome has similar structure as the reference genome within this region. For reencing, the donor genome is very similar to the reference genome. So for most of the paired-end reads, the insert sizes calculated from read mapping are reasonably accurate. Usually, paired-end reads from the same library has small library insert size. We assume that the standard deviation of insert sizes is not very large. In our simulation, the reference genome is a random sequence of A, C, G, and Ts. The donor genome is generated from the reference genome by removing the bases from 250,000 to 251,000 and inserting a random sequence of length 100 between bases reference : 750,000 and reference : 750,001. The setting is illustrated in Figure 8.1.

We generate paired-end reads from the donor genome with 30x (coverage is the average number of reads covering one). In total, 30x coverage of data is also generated from the reference genome. The reads are put together to simulate that the sample is heterozygous with one copy of genome having the SVs and the other copy of genome being the same as the reference genome. The data set is then 60x coverage. Note that in practice, the two sequences may have different coverage. We use this simplified simulation to illustrate the basic concept. The reads of the data set are generated with the read simulation tool wgism (https://github.com/lh3/wgism) with insert size, standard deviation, and read length set to 500, 50, and 100 respectively. Every reads are chosen to be the default. The data set is very ideal compared with the real situation, but is suffice to show the signatures. The reads are mapped by BWA (5) with default parameters. We can view the alignments using IGV (6).
