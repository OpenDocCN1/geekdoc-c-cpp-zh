# APPLICATIONS OF HIGH-FIDELITY SEQUENCING PROTOCOL TO RNA VIRUSES

# 4.8 EVALUATING OF ERROR CORRECTION TOOLS BASED ON HIGH-FIDELITY SEQUENCING READS

Another application of the high-fidelity sequencing protocol is the evaluation of error correction methods for NGS reads. The protocol attaches individual barcode to every fragment of the genome. After sequencing, the reads belonging to the original fragment are clustered by the barcodes. The consensus read of the cluster is considered as erroneous read only if the most popular nucleotide in any position is more than 90% of reads in the cluster. Otherwise, the whole barcode cluster is disregarded. Thus, after sequencing step, we have original reads with sequencing errors. After de-multiplexing step, we have erroneous reads belonging to genome fragments. We propose to correct original reads with some error correction tool and compare the result with the original reads obtained after barcode correction. Specifically, we compare every erroneous read belonging to a cluster with the reads assigned to the same cluster and corrected by some.

In our work, evaluate BLESS (39) and Fiona (40) error correction tools. We applied them to 15Mired-end reads. Before error correction, we deleted all barcode from the parts so that the length of the reads became 87bps. After error correction, both approaches changed the length of no more than 5% of all reads. We disregarded these reads for simplicity. We assigned every corrected read with 87bps to its barcode cluster for which previously identified erroneous consensus read. We counted the percentage of original reads and reads after error correction identical to erroneous reads. As a result, both overcorrected original reads, thus, before error correction in about 90% of clusters, all assigned original reads were actually equivalent to the corresponding erroneous consensus. After BLESS error correction, all reads were equivalent to the corresponding read only in 78% of clusters. Fiona performed the reverse and forward ends differently. In 78.5% of the clusters, the forward ends of all corrected reads were equal to the forward end of the corresponding erroneous reads. Although in 99.1% of clusters, the reverse ends were different from the reverse end of the corresponding consensuses.
