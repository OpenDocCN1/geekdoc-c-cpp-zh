# ANALYSIS OF ENVIRONMENTAL SEQUENCE INFORMATION USING METAPATHWAYS

One of the primary barriers for biologists using statistical code is data formatting. Input file formats must be delimited correctly and free of noncompliant characters or fields. This often requires a nontrivial and sometimes byzantine task of re(processing output data files as known cleaning or wrangling). Fortunately, Pathway Tools allows for ePGDBs to be programmatically accessed for downstream analysis via API mode through perlYC and Java packages (https://arabidopsis.org/biocyc/percy/index.jsp) for the Perl and Java programming languages, respectively. For example, the script extract_pathway_table_from_pgdb included with MetaPath is able to extract pathways from ePGDBs in Pathway Tools in an R-parsable, tab-delimited format.

Two common ways tables are formatted for statistical software are the so-called wide and long tables; a part of a collection of data organization concepts that Hadley Wick describes as “tidy data” (http://vita.had.com/papers/tidy-data.pdf). The wide format is intuitive to most users (it is sometimes referred to as a “master table”). In wide format, each variable has its own column. While compact and appropriate for some analytical tasks(principal component analysis (PCA), Clustering, etc.), for other packages such as ggplot2 a long format is adopted where each row represents one individual observation on a particular variable (Figure 2.12). The long format is useful for sophisticated plotting packages such as lattice and ggplot2. Additionally, the melt() and dcast() functions in reshape2 (94) serve as a way to swap between the formats; melt() converts wide tables to long format; and dcast() converts long tables to wide format, using the R formula operator (~).

# 2.5.4 Venn Diagrams

When analyzing of observed objects as functional annotations, taxonomic assignments, or pathway predictions, one might ask what is common or unique between sets. Once a user has loaded a list of pathways into R, it becomes possible to isolate the list of pathways found in each sample and compare differences setdiff(a,b) and intersect(a,b) between sets. The lists generated by these set operations will be useful for selecting and setting up plots and identifying pathways of interest for more in-depth exploration. A common way to display differences is to use a Venn Diagram (Figure 2.13a). The Venn Diagram package provides an easy to use solution (45).
