### 9.2.1.3 Differential Methylation
Differential methylation between two samples can be defined as log2 fold change of read depth of a given window or genomic feature. An alternative method is to use the enriched regions (peaks) that mutually exclusive pairs in two samples are differentially methylated. However, these methods are limited in statistical assessment and sensitivity, respectively. The best solution is to apply statistical models to methylation changes and measure the significance of differentially methylated regions in terms of $p$-values: SICER (54), ChIPDiff (60), DiffBind (61), BChIP (63), edgeR (63), DESSeq (64), MEDIPS, a specialized program for MedIP-seq, used the $t$ and Wilcoxon tests, and the latest versions use edgeR (58, 65).

### 9.2.1.4 Pipelines
Two pipelines have been developed from sequence mapping to methylation profiling and differential methylation including quality assessment of sequencing and affinity efficiency. MEDUSA (Methylated DNA Utility for Sequence Analysis) (66) is a full pipeline for MedIP-seq and sequence mapping using BWA, baseline filtering using SAMTools, quality assessment of sequencing using FastQ, coverage and saturation plots using MEDIPS, identification of DMRs using USeq and R Bioconductor DESSeq in the old version and MEDIPS in the new, and annotation using BEDTools. The output of MedUSA can be visualized on the UCSC genome browser. MeQA (MedIP-seq quality assessment) (67), use FastQ for quality of sequencing; BWA for sequence mapping; SAMTools for sorting and filtering; Samstat for mapping summary quality check; MEDIPS for saturation, coverage, and CpG enrichment estimation; and CEAS for DMR annotation (Figure 9.3).

### 9.2.1.5 Tag Density Plot
Most programs generate sequence mapping results in the wiggle and BED format, be displayed onto the UCSC genome browser (68), gbrowser (69), IGV (70), and IGB (71). Visualization is very useful for interpreting results intuitively and summarizing the overall methylation tendency. A tag density plot is an extended wiggle plot made by drawing the mean read coverage for a group of regions of interest, for example, upregulated genes and all genes.

### 9.2.1.6 Saturation Test
One of the most important questions in capture-based sequencing such as ChIP-seq, MedDIP-seq, and MBD-seq is whether sequencing is sufficient and if not, how much sequencing is needed. MEDIPS developed the idea that if sequencing is sufficient, a set of reads in the sequencing should be highly correlated to an independent set of reads. Therefore, reads are randomly assigned to 2n data sets of equal size, $S_1, \dots, S_n, S_{n+1}, \dots, S_{2n}$. Let $A$ be $(S_1, \dots, S_n)$ and $B$ be $(S_{n+1}, \dots, S_{2n})$. In each iteration $i$, the testing adds data sets $S_i$ and $S_{n+j}$ from $A$ and $B$ to the current data sets $A_i$ and $B_j$, respectively, counts in a window of 50 bp,

## 9.2.2 Available Approaches

### 9.2.2.1 Bayesian Tool for Methylation Analysis (Batman)
Batman (57) has developed to address the difficulty of estimating absolute methylation levels due to CpG density effects from DNA immunoprecipitation using oligonucleotide arrays (MeDi-chip) or NGS (MeDiP-seq), as explained in methylation quantification. To address this, Batman defines the coupling factor Cpw in the genomic $w$ and CpG density $p$ of DNA molecules being sequenced in the window that contains the CpG, so that local CpG density is in proportion to the coupling factor for a given window. As shown in Figure 9.6, there is an approximately linear relationship between the window and the density of methylated CpGs. This observation leads to a model that defines a set of methylation observations, the probability distribution $S$ for a complete set of independent observations is defined as $f(m|S) = \Pi G(sw|Cpw,mp)$, ⁻¹ where $G(\mu, \sigma^2)$ is a rectified Gaussian probability density function, $mp$ represents the methylation level at position $p$, and Cpw represents the coupling factor between a $w$ and a CpG $p$. To calculate $f(m|S)$, the posterior distribution of the methylation state parameters provides the MB-seq data, a standard Bayesian inference approach based on nested sampling, a highly robust Monte Carlo technique has been applied. In other words, for each window of the genome, the approach generates 100 most likely samples from $f(m|S)$, fits distributions to these samples, chooses the most likely methylation state in 100 bp windows, and then chooses the modes of the most likely distributions as the final methylation calls.

To run Batman, we need to:
(i) filter out low-confidence alignments from BAM files,
(ii) generate mapped reads in GFF2 files,
(iii) create a database on MySQL,
(iv) generate and load a coupling factor using EstimateCouplingProfileApplication and LoadCouplingProfileApplication,
(v) generate a Batman array file from a GFF2 file using ReadsToSeqArrayProbes and LoadRatesGFF,
(vii) calibrate read counts using coupling factor and (viii) generate methylation states using SampleMethStatesApplication. Batman does not provide a user-friendly interface and requires knowledge of a database management system. It is quite slow and recommends running jobs for each chromosome.
