All the action takes place in the readFile() function (called from main()), we will look at it in three parts.

```
bool XmlStreamReader::readFile(const QString &fileName)
{
    QFile file(fileName);
    if (!file.open(QFile::ReadOnly | QFile::Text)) {
        std::cerr << "Error: Cannot read file " << qPrintable(fileName)
                  << qPrintable(file.errorString())
                  << std::endl;
        return false;
    }
    reader.setDevice(&file);
```

readFile() function begins by trying to open the file. If it fails, it outputs an error message and returns false. If the file is opened successfully, it is set as the QXmlStreamReader's input device.

```
reader.readNext();
while (!reader.atEnd()) {
    if (reader.isStartElement()) {
        if (reader.name() == "bookindex") {
            readBookIndexElement();
        } else {
            reader.raiseError(QObject::tr("Not a bookindex file"));
        }
    } else {
        reader.readNext();
    }
}
```

QXmlStreamReader's readNext() reads the next token from the input stream. If a token is successfully read and the end of the XML file has not been reached, the function enters the while loop. Because of the structure of the index files, we know that inside this loop there are three possibilities: A <book> start tag has been read, another start tag has been read (in case the file is not a book index), or some other token has been read.

If we have the correct start tag, we can readBookIndexElement() to continue processing. Otherwise, we can call XmlStreamReader::raiseError() with an error message. The next time atEnd() is called (in the while loop), it will return true. This ensures that parsing stops as soon as possible an error has been encountered.
