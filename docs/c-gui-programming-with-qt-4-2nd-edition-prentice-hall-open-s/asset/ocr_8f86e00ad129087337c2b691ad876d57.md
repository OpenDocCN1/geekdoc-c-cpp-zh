For writing XML files, Qt offers three options:

+   - We can use a QXmlStreamWriter.

+   - We can represent the data as a DOM tree in memory and ask the tree to write itself to a file.

+   - We generate the XML by hand.

Using QXmlWriter is by far the easiest approach, and is more reliable than hand-generating XML. Using DOM to produce XML really makes sense only if a DOM tree is already used as the application's primary data structure. All three approaches to reading and writing XML are shown in this chapter.

# Reading XML with QXmlStreamReader

QXmlStreamReader is the fastest and easiest way to read XML in Qt. Because the parser works incrementally, it is particularly useful for finding all occurrences of a tag in an XML document, for reading very large files that may not fit in memory, and for populating custom data structures to reflect an XML document's contents.

The QXmlStreamReader parser works in the tokens listed in Figure 16.1. Each time the read() function is called, the next token is read and becomes the current token. The current token's properties depend on the token's type and are accessible using the getter functions listed in the table.

Figure 16.1. The QXmlStreamReader's tokens

| Token Type | Example | Getter Functions |
|---|---|---|
| StartDocument | N/A | isStandaloneDocument() |
| EndDocument | N/A | isStandaloneDocument() |
| StartElement | <item> | namespaceUri(), name(), attributes(), namespaceDeclarations() |
| EndElement | </item> | namespaceUri(), name() |
| Characters | AT&amp;T | text(), isWhitespace(), isCDATA() |
| Comment | <!-- fix --> | text() |
