Let's create the constructor and look at the timerEvent() function:

```
void PlayerWindow::timerEvent(QTimer *event)
{
    if (event->timerId() == timerId) {
        double curPos = wmp->property("CurrentPosition").toDouble();
        onPositionChange(-1, curPos);
    } else {
        QWidget::timerEvent(event);
    }
}
```

The timerEvent() function is called at regular intervals while a media clip is playing. We use it to advance the slider. This is done by calling property() on the ActiveX control to obtain the value of CurrentPosition property as a QVariant calling toDouble() to convert it to a double. We then call onPositionChange() to perform the update.

One frequent need when dealing with COM objects is to be able to call a COM method directly (as opposed to connecting it to a Qt signal). The easiest way to do this is to invoke QAxBase::dynamicCall() with the name and signature of the method as the first parameter and the arguments to the method as additional parameters. For example:

```
wmp->dynamicCall("TitlePlay(uint)", 6);
```

The dynamicCall() function takes up eight parameters of type QVariant and returns a QVariant. If we need to pass an IDDispatch * or an IUnknown * we can encapsulate the component in a QAxObject and call asVariant() on it to convert it to a QVariant.
