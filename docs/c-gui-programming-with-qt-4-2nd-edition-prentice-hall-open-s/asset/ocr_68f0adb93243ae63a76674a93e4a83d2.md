bool MainWindow::save()
{
    if (curFile.isEmpty()) {
        return saveAs();
    } else {
        return saveFile(curFile);
    }
}

```
bool MainWindow::saveFile(const QString &fileName)
{
    if (!spreadsheet->writeFile(fileName)) {
        statusBar()->showMessage(tr("Saving canceled"), 2000);
        return false;
    }

    setCurrentFile(fileName);
    statusBar()->showMessage(tr("File saved"), 2000);
    return true;
}
```

The save() slot corresponds to File|Save. If the file already has a name because it
opened before or has already been saved, save() calls saveFile() with that
name; otherwise, it simply calls saveAs().

```
bool MainWindow::saveAs()
{
    QString fileName = QFileDialog::getSaveFileName(this,
        tr("Save Spreadsheet"), ".*",
        tr("Spreadsheet files (*.sp"));

    if (fileName.isEmpty())
        return false;
    return saveFile(fileName);
}
```

The saveAs() slot corresponds to File|Save As. We call
QFileDialog::getSaveFileName() to obtain a file name from the user. If the user
licks Cancel, we return false, which is propagated up to its caller (save()) or
okToContinue().
