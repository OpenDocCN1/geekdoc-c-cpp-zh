The bool can take the values true and false. In addition, numeric types can be used where a bool is expected, and the rule that 0 false and any non-zero value means true.

The char type is used for storing ASCII characters and 8-bit integers (bytes). When used as an integer, it can be signed or unsigned, depending on the platform. The type signed char and unsigned char are available as unambiguous alternatives to char. Qt provides QChar type that stores 16-bit Unicode characters.

Instances of built-in types are not initialized by default. When we create an int variable, its value could conceivably be 0, but just as likely be -209486515. Fortunately, most compilers warn us when we attempt to read the contents of an uninitialized variable, and we can use tools like Rational PurifyPlus and Valgrind to detect uninitialized memory accesses and other memory-related problems at run-time.

In memory, the numeric types (except long) have identical sizes on the different platforms supported by the system's byte order. On big-endian architectures (such as PowerPC and SPARC), the 32-bit value 0x12345678 is stored as the four bytes 0x12 0x34 0x56 0x78, whereas on little-endian architectures (such as Intel x86), the sequence is reversed. This makes a difference in programs that copy memory areas onto disk or send binary data over the network. Qt's QDataStream class, presented in Chapter 12, can be used to store binary data in a platform-independent way.
