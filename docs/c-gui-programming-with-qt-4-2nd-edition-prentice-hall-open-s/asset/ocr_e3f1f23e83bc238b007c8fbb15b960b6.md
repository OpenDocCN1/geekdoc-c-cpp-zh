# Figure 8.18. Printing a QImage

![](bbox=[0.012, 0.053, 0.572, 0.642])

We assume that the PrintWindow class has a member variable called printer of type QPrinter. We could simply have created the QPrinter on the stack in printImage(), but then it would not remember the user's settings from one run to another.

We create a QInputDialog and call exec() to show it. It returns true if the user clicked the OK button; otherwise, it returns false. After the call to exec(), the QPrinter object is ready to use. (It is also possible to print without using a QDialog, by directly calling QPrinter member functions to set things up.)

Next, we create QPainter to draw on the QPrinter. We set the window to the image's rectangle and the viewport to a rectangle with the same aspect ratio, and we draw the image at position (0, 0).
