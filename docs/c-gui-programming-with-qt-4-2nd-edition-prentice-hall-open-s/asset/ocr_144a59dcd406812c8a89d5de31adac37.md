```
env = Environment(tools=["default", "qt4"], toolpath=[QT4_PY_PATH])

rccs = [rccs("spreadsheet.qrc", QT4_QRCCFLAGS="-name spreadsheet")]

sources = [
	"cell.cpp",
	"finddialog.cpp",

	"main.cpp",

	"sortdialog.cpp",
	"spreadsheet.cpp"
]
env.Program(target="spreadsheet", source=[rccs, sources])
```

This file is written in Python, we have access to all the features and libraries available in the Python language.

Most of the file is boilerplate, with just a few application-specific items. We begin by setting the paths to qt4.py and to Qt 4's installation directory. We avoid copying qt4.py in every application's directory by putting it in a standard location and setting the path to it accordingly. We must explicitly specify the Qt modules we are using, in case QtCore and QtGui, we must specify the files that need to be processed by rcc and uic. Finally, we list the source files, and set the program's name as well as the .h files; the Qt 4 support is smart enough to run moc correctly as necessary, by inspecting the .cpp files.

Now we can build the application using the scons command:

```
scons
```

This builds the application specified in the SConstruct file in the current directory. We can clean up using scons -c.
