The same dialog could be created visually in Qt Designer by placing the child widgets in their approximate positions; selecting those that need to be laid out together; and clicking Lay Out Horizontally, Form Lay Out Vertically, or Form Lay Out in a Grid. This approach we use in Chapter 2 for the Spreadsheet application's Go to and Sort dialogs.

Using QHBoxLayout and QVBoxLayout is fairly straightforward, but using GridLayout is a bit more involved. GridLayout works on a two-dimensional grid of cells. The QLabel in the top-left cell of the layout is at position (0, 0), and the corresponding QLineEdit is at position (0, 1). The QCheckBox spans two columns; it occupies the cells in positions (2, 0) and (2, 1). The QTreeWidget and the QLabel beneath it also span two columns. The calls to QGridLayout::addWidget() have

```
layout->addWidget(widget, row, column, rowSpan, columnSpan);
```

Here, widget is the child widget to insert into the layout, (row, column) is the top-left cell occupied by the widget, rowSpan is the number of rows occupied by the widget, and columnSpan is the number of columns occupied by the widget. If omitted, rowSpan and columnSpan arguments default to 1.

The addStretch() call tells the vertical layout manager to consume space at that point in the layout. By adding a stretch item, we have told the layout manager to put any excess space between the Close button and the Help button. In Qt Designer, we can achieve the same effect by inserting a spacer. Spacers appear in Qt Designer as blue "springs".
