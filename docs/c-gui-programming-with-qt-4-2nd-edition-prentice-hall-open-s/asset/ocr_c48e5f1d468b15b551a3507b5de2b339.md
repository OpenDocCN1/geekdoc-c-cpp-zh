# Multiple Document Interface

Applications provide multiple documents within the main window's central area are called multiple document interface applications, or MDI applications. In Qt, an MDI application is created using the QMdiArea class as the central widget and by making each document window a QMdiArea subwindow.

It is conventional for MDI applications to provide a Window menu that includes some commands for managing both the windows and the list of windows. The window is identified with a checkmark. The user can make any window active by clicking its entry in the Window menu.
