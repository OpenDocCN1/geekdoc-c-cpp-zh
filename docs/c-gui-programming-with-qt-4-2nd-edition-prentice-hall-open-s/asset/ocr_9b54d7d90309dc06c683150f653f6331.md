```
statusLabel->setText(tcpSocket->errorString());
closeConnection();
}
```

The error() status is connected to TcpSocket's error(QAbstractSocket::SocketError) signal. We ignore the error code and instead use the QIODevice::toString() function, which returns a human-readable error message for the last error that occurred.

Now let's implement the server. The server consists of two classes: TripServer and ClientSocket. The TripServer class is derived from TcpServer, a class that allows us to accept TCP connections. ClientSocket reimplements TcpSocket and handles a single connection. At any time, there are many ClientSocket objects in memory as there are clients being served.

```
class TripServer : public TcpServer
{
    Q_OBJECT

public:
    TripServer(QObject *parent = 0);

private:

};
```

The TripServer class implements the incomingConnection() function from TcpServer. This function is called whenever a client attempts to connect to the server is listening to.
