Providing help files in HTML format and making them available to users via their

application’s resources (such as icons), which cannot easily be customized to

EntryDialog, clicking the browser’s Home or Back button will not have the desired
effect.

## Using QTextBrowser as a Simple Help Engine

Using the user's web browser to show simple help is easy to do, but as we have noted, the approach does a few drawbacks. We can eliminate these problems by providing our own help engine based on the QTextBrowser class.

In this section, we present the simple help browser shown in Figure 17.3 and explain how it can be used within an application. The window uses QTextBrowser to display help pages that are marked up with an HTML-based syntax. QTextBrowser can handle a lot of HTML tags, so it is ideal for this purpose.

We set the Qt::WA_GroupLeader attribute because we want to pop up HelpBrowser from modal dialogs in addition to the main window. Dialog normally prevent the user from interacting with any other window in the application. However, after requesting help, the user must obviously be allowed to interact with both the modal dialog and the help browser. Setting Qt::WA_GroupLeader attribute makes this interaction possible.

We provide two search paths, the first path in the file system that contains the application's documentation, and the second path in the location of the image resources. The HTML can include references to images in the file system in the normal way and references to image resources using a path that begins with :/ (colon slash). the page parameter is the name of the documentation file, with an optional HTML anchor.

It is also possible to use Qt's resource system to embed the help files and their associated images directly into the executable. The only changes required to achieve this are to add entries to the application's .qrc file for each file we embedded and to use the resource path, ::doc/forms.html#editing.

In this example, we used both approaches, embedding the icons (since they are also used by the application itself), but keeping our HTML files in the file system. This has the advantage that the help files can be updated independently of the application, and yet are guaranteed to be able to find the application's icons.

## Using Qt Assistant for Powerful Help

Qt Assistant is a distributable online help supplied by Trolltech. Its main virtues are that it supports indexing and full text search and that it can handle documentation sets for multiple applications. To make use of Qt Assistant, we must incorporate the necessary code in our application, and we must make Qt Assistant aware of our documentation.

[* Qt 4.4 is expected to feature a revamped help system, which will make it easier to integrate our documentation.

Communication between a Qt application and Qt Assistant is handled by the AssistantClient class, which is located in a separate library. To link this library with an application, we must add this line to the application's .pro file:

CONFIG += assistant
