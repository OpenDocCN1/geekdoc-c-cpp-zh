## Supporting Custom Types

In the examples we have relied on QMimeData::setText(). But if we want to drag custom types, we must subclass QMimeData. To show how these approaches work:

- The first approach does not subclass, but has drawbacks: we need to store data several times (once per MIME type).
- The second approach subclasses QMimeData and gives us complete control.
- The third approach subclasses QMimeData to minimize these problems.

The first approach looks like this:

```cpp
void ProjectListWidget::moveEvent(QMouseEvent *event)
{
    if (event->buttons() & Qt::LeftButton) {
        int distance = (event->pos() - startPos).manhattanLength();
        if (distance >= QApplication::startDragDistance()) {
            performDrag();
        }
    }
    QListWidget::moveEvent(event);
}

void ProjectListWidget::performDrag()
{
    QString plainText = selectionAsString();
    if (plainText.isEmpty()) {
        return;
    }

    QMimeData *mimeData = new QMimeData;
    mimeData->setText(plainText);
    mimeData->setHtml(toHtml(plainText));
    mimeData->setData("text/csv", toCsv(plainText).toUtf8());

    QDrag *drag = new QDrag(this);
    drag->setMimeData(mimeData);
    if (drag->exec(Qt::CopyAction | Qt::MoveAction) == Qt::MoveAction) {
        deleteSelection();
    }
}
```
