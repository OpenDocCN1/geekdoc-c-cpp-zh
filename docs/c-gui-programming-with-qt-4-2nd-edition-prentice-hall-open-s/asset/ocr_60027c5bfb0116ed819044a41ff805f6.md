# Global Variables and Functions

C++ lets us declare functions and variables that don't belong to any classes and are accessible from any other function. We have seen several examples of global functions, including main(), the program's entry point. Global variables are rarer, because they compromise modularity and thread reancy. It is still important to understand them because you might encounter them in code written by reformed programmers and other C++ users.
