```
model = new QSqlTableModel(this);

t("Description"));

model->select();
```

Creating the model is similar to what we saw in the preceding section. One difference is that we have provided our column titles. If we had not so, the raw field names would have been used. We have specified a sorting order using setSort(); behind the scenes, this is implemented by an ORDER BY clause.
