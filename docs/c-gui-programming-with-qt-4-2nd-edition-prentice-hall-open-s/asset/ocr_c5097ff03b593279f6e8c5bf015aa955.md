The connectToServer() slot is executed when the user Search to start a server. We call connectHost() on the QtcpSocket object to connect to the server, which we assume is possible at port 6178 on the fictitious host tripserver.zugbahn.de. If you want to try the example on your own machine, replace the host name with HostAddress::LocalHost. The connectToServer() call is asynchronous; it always returns immediately. The connection is typically established. The socket object emits the connected() signal when the connection is up and running, and error(QAbstractSocket::SocketError) if the connection failed.
