We create an Application object. The Application class is derived from QApplication and implements both commitData() and saveState() to support session management.

Next, we create a TicTacToe widget, make the Application object aware of, and we show it. We have called the TicTacToe widget "toe". We must give unique object names to top-level widgets if we want the session manager to restore the windows' sizes and positions.

Here's the definition of the Application class:

    TicTacToe ticTacToe;
