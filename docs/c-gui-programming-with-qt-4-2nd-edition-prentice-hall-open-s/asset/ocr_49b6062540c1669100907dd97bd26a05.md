# Production

The authors wrote the text using NEdit and Vim. They typeset and indexed the text themselves, marking it up with a modified Lout syntax that they converted to pure Lut using a custom preprocessor written in Python. They produced all the diagrams in Lout and used ImageMagick and KView to convert screenshots to PostScript. The monospaced font used for code is derived from a condensed version of DejaVu Mono and was modified using FontForge. The cover was provided by the publisher. The marked-up text was converted to PostScript by Lout, then to PDF by Ghostscript. The authors did all the editing and processing on Kubuntu and Fedora systems under KDE. The example programs were tested on Windows, Linux, and Mac OS X.
