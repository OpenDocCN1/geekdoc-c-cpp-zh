In this example, we don't let script writers instantiate their own PumpSpreadsheet objects; instead, we provide a global singleton object, spreadsheet, that they can use. To allow script writers to instantiate PumpSpreadsheet for themselves, we would need to register a pumpSpreadsheetConstructor() function, which we did for PumpFilter.

In the Gas Pump example, it was sufficient to provide access to the application's widgets (e.g., PumpSpreadsheet) and to the application's custom data classes like PumpFilter. Although not necessary for the Gas Pump example, it is sometimes useful to make functions in C++ available to scripts.
