```
QApplication app(argc, argv);
...
QtTranslator appTranslator;
appTranslator.load("myapp" + QLocale::system().name(), qPath);
app.installTranslator(&appTranslator);

return app.exec();

```

The QLocale::system() function returns a QLocale object that provides the locale name about the user's locale. Conventionally, we use the locale name as part of the .qm file. Names can be more or less precise; for example, fr specifies a French-language locale, fr_CA specifies a French Canadian locale, and fr_CA.ISO8859-15 specifies a French Canadian locale with ISO 8859-15 (an encoding that supports ‘€’, ‘Œ’, ‘æ’ and ‘Ÿ’).

Assuming that the locale is fr_CA.ISO8859-15, the QtTranslator::load() first tries to load the file myapp_fr_CA.ISO8859-15. If this file does not exist, load() next myapp_fr_CA.qm at a time, then myapp_fr.qm and finally myapp.qm, before giving up. Normally, we would only provide myapp_fr.qm, containing a standard French translation, but if we need a different file for French-speaking Canada, we can also provide myapp_fr_CA.qm and it will be for fr locales.

The second argument to QtTranslator::load() is the directory where we want load() for the translation file. In this case, we assume that the translation files are located in the directory given in qPath variable.

The Qt libraries contain a few strings that need to be translated. Trolltech provides French, German, and Simplified Chinese translations in Qt's translations directory. A few other languages are provided as well, but these are contributed by Qt users and are not officially supported. The Qt libraries' translation file should also be loaded:

```
QtTranslator qtTranslator;
qtTranslator.load("qt" + QLocale::system().name(), qPath);
app.installTranslator(&qtTranslator);
```

A Translator object can hold only one translation file at a time, so we use a separate QtTranslator for Qt's translation. Having just one file per translator is not a problem because we can install as many translators as we need. QApplication will use all of them when searching for a translation.
