# # Subclassing QTableWidget

The Spreadsheet class is derived from QTableWidget, as Figure 4.1 shows. The QTableWidget is effectively a grid that represents a two-dimensional sparse array. It displays whichever cells the user scrolls to, within its specified dimensions. When the user enters text into an empty cell, QTableWidget automatically creates a QWidgetItem to store the text.

QTableWidget is derived from QTableView, one of the model/view classes we will look at more closely in Chapter 10. Another table, which has a lot of functionality out of the box, is QTable, available from http://www.ics.com/.

Let's start implementing Spreadsheet, beginning with the header file:

```
#ifndef SPREADSHEET_H
#define SPREADSHEET_H

#include <QTableWidget>

class Cell;
class SpreadsheetCompare;
```

The header starts with forward declarations for the Cell and SpreadsheetCompare classes.
The attributes of a QTableWidget cell, such as its text and its alignment, are stored in a QTableWidgetItem. Unlike QTableWidget, QTableWidgetItem isn't a grid class; it is a pure data class. The Cell class is derived from QTableWidgetItem and will be explained in this chapter's last section.
