# Combining OpenGL and Qainter

In the preceding section, we saw how to use OpenGL commands to draw a 3D scene on a QWidget. It is also possible to use Qainter to draw 2D graphics on which QWidget. The Vowel Cube example we will look at in this section combines OpenGL calls and Qainter, showing how to get the best of both worlds. It also demonstrates the use of the QWidget::renderText() function, which lets us draw transformed textual annotations on top of a 3D scene. The application is shown in Figure 20.2.

void VowelCube::drawCube() {
    glPushAttrib(GL_ALL_ATTRIB_BITS);
    glMatrixMode(GL_PROJECTION);
    glPushMatrix();
    glIdentity();
    float x = glfloat(width()) / height();
    glOrtho(-x, x, -3.0, 3.0, 4.0, 15.0);
    glMatrixMode(GL_MODELVIEW);
    glPushMatrix();
    glIdentity();
    glTranslatef(0.0, 0.0, -10.0);
    glScalef(scaling, scaling, scaling);
    glRotatef(rotationX, 1.0, 0.0, 0.0);
    glRotatef(rotationY, 0.0, 1.0, 0.0);
    glRotatef(rotationZ, 0.0, 0.0, 1.0);

    Enable(GL_MULTISAMPLE);
    glCallList(glObject);
    setFont(QFont("Times", 24));

    renderText(+1.1, +1.1, +1.1, QChar('a'));
