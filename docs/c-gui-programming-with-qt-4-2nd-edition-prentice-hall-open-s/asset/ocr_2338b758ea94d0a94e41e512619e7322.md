In the example, we chose to print an image, but printing graphics views is also very simple. To print the entire scene, we can call QGraphicsScene::render() or QGraphicsView::render(), passing a Printer as the first parameter. Printing items that take up no more than a single page is simple, but many applications need to print multiple pages. There are two approaches to handling multi-page documents with Qt:

+   - We can convert our data to HTML and render it using QTextDocument, Qt's rich text engine.

+   - We can perform the drawing and the page breaking by hand.
