using the data() function. If we were interested in the text, we could retrieve it by calling item->data(Qt::DisplayRole)->toString() or, more conveniently, item->text().

By default, QListWidget is read-only. If we wanted the user to edit the items, we could set the view's editors using QAbstractItem::setEditTriggers(QAbstractItem::AnyKeyPressed); for example, a set of triggers that the user can begin editing an item by starting to type. Alternatively, we could provide an Edit button (and perhaps Add and Delete buttons) or use signal-slot connections that we can handle the editing operations programmatically.

Now that we have seen how to use a convenience view item for viewing and selecting data, we will look at an example in which we can edit data. Again we are using a dialog, this time one that presents a set of (x, y) coordinates that the user can edit.

As the previous example, we will focus on the item view relevant code, starting with the constructor.

The QTableWidget constructor takes the initial number of rows and columns to display. Every item in a QTableWidget is represented by a QTableWidgetItem, including horizontal and vertical header items. setHorizontalHeaderLabels() function sets the text for each table header widget to the corresponding text in the string list it is passed. By default, QTableWidget provides a vertical header with rows labeled from 1, which is exactly what we want, so we don't need to set the vertical header manually.
