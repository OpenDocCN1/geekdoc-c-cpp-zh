The implementation of the Jambi Find application is done in a single file called FindDialog.java. We will review the contents of this file piece by piece, starting with the import declarations.

```
import com.trolltech.qt.core.*;
import com.trolltech.qt.gui.*;
```

Between them, these two import declarations make all of Qt's core and GUI classes available to Java. Additional sets of classes can be made available with import declarations (e.g., import com.trolltech.qt.opengl*).
