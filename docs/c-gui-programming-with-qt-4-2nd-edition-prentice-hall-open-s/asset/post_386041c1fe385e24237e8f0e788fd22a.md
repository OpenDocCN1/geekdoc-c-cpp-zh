By default, QTextStream uses the system's local encoding (e.g., ISO 8859-1 or ISO 8859-15 in America and much of Europe) for reading and writing. This can be changed using setCodec() as follows:

```
stream.setCodec("UTF-8");
```

The UTF-8 encoding used in the example is a ASCII-compatible encoding that can represent the entire Unicode character set. For more information about Unicode and QTextStream's supports for encoding, Chapter 18.

QTextStream has various options modeled after those offered by <iostream>. These can be set by passing special objects, called stream manipulators, on the stream to alter its state, or by calling the functions listed in Figure 12.1. The following example sets the showcase, uppercasedigit, and hex options before it outputs the integer 12345678, producing the text "0xBC614E":

```
out << showcase << uppercasedigit << hex << 12345678;
```

Like QDataStream, QTextStream operates on a QIODevice subclass, which can be a File, a QTemporaryFile, a QBuffer, a QProcess, QTcpSocket, or QUdpSocket, or QSSslSocket. In addition, it can be used directly on a QString. For example:
```cpp
QString str;
QTextStream(&str) << oct << 31 << " " << dec << 25 << endl;
```

This makes the contents of str "37 25\n", since the decimal number 31 is expressed as 37 in octal. In this case, we don't need to set an encoding on the stream, since QString is always Unicode.

Let's look at a simple example of a text-based file format. In the Spreadsheet application described in Part I, we used a binary format for storing Spreadsheet data. The data consisted of a sequence of (row, column, formula) triples, one for very non-empty cell. Writing the data as is straightforward; there is an extract from a revised version of Spreadsheet::writeFile():

```cpp
QTextStream out(&file);
for (int row = 0; row < RowCount; ++row) {
  for (int column = 0; column < ColumnCount; ++column) {
    QString str = formula(row, column);
    if (!str.isEmpty()) {
      out << row << " " << column << " " << endl;
    }
  }
}
```

We have used a simple format, with each line representing one cell with spaces between the row and the column and between the column and the formula. The formula can contain spaces, but we can assume that it contains no '\n' (which we use to terminate lines). Now let's look at the corresponding reading code:

```cpp
QTextStream in(&file);
while (in.atEnd()) {
    QString line = in.readLine();
    QStringList fields = line.split(' ');
    if (fields.size() >= 3) {
        int row = fields.takeFirst().toInt();
        int column = fields.takeFirst().toInt();
        setFormula(row, column, fields.join(' '));
    }
}
```

We read in the Spreadsheet data one line at a time. The readLine() function removes the trailing '\n'. QString::split() returns a list, splitting its string wherever the separator is given. For example, the line 5 19 Total value results in the four-item list ["5", "19", "Total", "value"].

If we have at least three fields, we can extract the data. TheList::takeFirst() function removes the first item in a list and returns the removed item. We extract the row and column numbers. We don't perform any error checking; if we read a non-integer row or column value, QString::toInt() will return 0. When we call setFormula(), we concatenate the remaining fields back into a single string.

In our second QTextStream example, we use a character by character approach to implement a program that reads in a text file and outputs the same text with spaces removed from lines and all tabs replaced by spaces. The tidyFile() function does the program's work:

```cpp
void tidyFile(QIODevice inDevice, QIODevice outDevice)
{
    QTextStream in(inDevice);
    QTextStream out(outDevice);

    const int TabSize = 8;
    int endlCount = 0;
    int spaceCount = 0;
    int column = 0;
    QChar ch;

    while (!in.atEnd()) {
        in >> ch;
        if (ch == '\n') {
            ++endlCount;
            spaceCount = 0;
            column = 0;
        } else if (ch == '\t') {
            int size = TabSize - (column % TabSize);
            spaceCount += size;
            column += size;
        } else if (ch == ' ') {
            ++spaceCount;
            column++;
        } else {
            while (endlCount > 0) {
                out << endl;
                --endlCount;
                column = 0;
            }
            while (spaceCount > 0) {
                out << ' ';
                --spaceCount;
            }
            out << ch;
            column++;
        }
    }
    out << endl;
}
```

```cpp
int main()
{
    QFile inFile;
    QFile outFile;

    inFile.open(stdin, QFile::ReadOnly);
    outFile.open(stdout, QFile::WriteOnly);

    tidyFile(&inFile, &outFile);

    return 0;
}
```

For this example, we don't need a QApplication object, because we are only using Qt's tool classes. See http://doc.qttech.com/4.3/tools.html for the list of all the tool classes. We have assumed that the program is used as a filter, for example:

tidy < cool.cpp > cooler.cpp

It would be easy to extend to be able to handle file names given on the command line if they are given, and to filter cin to cout otherwise.
Since this is a console application, it has a slightly different .pro file from those we have seen for GUI applications:

```
TEMPLATE      = app
QT            = core
CONFIG        += console
CONFIG        -= app_bundle
SOURCES      = tidy.cpp
```

We only link against QtCore since we don't use any GUI functionality. Then we specify that we want to enable console output on Windows and that we don't want the application to live in a bundle on Mac OS X.
