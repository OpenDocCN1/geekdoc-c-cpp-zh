The Project Chooser application presents the user with two list widgets, populated with names. Each list widget represents a project. The user can drag and drop the names in the list widgets to move a person from one project to another.

All of the drag and drop drop code is located in the QListWidget subclass. Here's the class definition:

```
class ProjectListWidget : public QListWidget
{
    Q_OBJECT

public:
    ProjectListWidget(QWidget *parent = 0);

protected:
    void mousePressEvent(MouseEvent event);
    void mouseMoveEvent(MouseEvent event);
    void dragEnter(DragEnterEvent *event);
    void dragMoveEvent(DragMoveEvent event);
    void dropEvent(QDropEvent event);

private:
    void performDrag();

    QPoint startPos;
};
```
