The constructor initializes the offset variable to 0. The x-coordinate at which the text is derived from the offset value. Timer IDs are always non-zero, so we use 0 to indicate that no timer has been started.

```

    myText = newText;
    update();
    updateGeometry();
}
```

The setText() function sets the text to display. It calls update() to request a repaint and updateGeometry() to notify any layout manager responsible for the Ticker widget about a size hint change.
