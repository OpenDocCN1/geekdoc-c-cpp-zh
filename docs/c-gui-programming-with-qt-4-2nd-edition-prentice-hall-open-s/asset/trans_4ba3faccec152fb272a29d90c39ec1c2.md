现在表单已经设计完成，我们准备好通过设置信号与槽连接来使其具有功能。Qt Designer 允许我们在同一个表单的控件之间建立连接。我们需要建立两个连接。

要进入 Qt Designer 的连接模式，连接由表单控件之间的蓝色箭头表示，如图 2.15 所示，它们位于 Qt Designer 的信号/槽窗口。要建立连接，点击发送者控件并将红色线条拖到接收者控件，然后释放。
