```
Spider::Spider(QObject *parent)
  : QObject(parent)
{
  connect(&ftp, SIGNAL(done(bool)), this, SLOT(ftpDone(bool)));
  connect(&ftp, SIGNAL(listInfo(const QUrlInfo&)),
         this, SLOT(ftpListInfo(const QUrlInfo&)));
}
```

In the constructor, we establish two signal-slot connections. listInfo(const QUrlInfo&) is emitted by QFtp when we request a directory listing (getDirectory()) for each file that it retrieves. This signal is connected to a slot called ftpListInfo(), which downloads the file associated with the URL it is given.
