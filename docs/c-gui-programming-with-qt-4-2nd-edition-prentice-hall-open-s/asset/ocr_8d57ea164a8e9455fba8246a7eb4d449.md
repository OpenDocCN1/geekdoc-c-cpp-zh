# The Standard C++ Library

In this section, we will briefly review the Standard C++ library. Figure D.3 lists the core C++ header files. <exception>, <limits>, <new>, and <typeinfo> headers support the C++ language; for example, <limits> allows us to test properties of the compiler's integer and floating-point arithmetic, and <typeinfo> offers basic introspection. The other headers provide useful classes, including a string class and a complex numeric type. The functionality offered by <bitset>, <locale>, <string>, and <typeinfo> loosely overlaps with the QByteArray, QLocale, QString, and QMetaObject classes in Qt.

| Figure D.3. Core C++ library header files |
| Header File | Description |
| <bitset> | Template class for representing fixed-length bit sequences |
| <complex> | Template class for representing complex numbers |
| <exception> | Functions and functions related to exception handling |
| <limits> | Template class that specifies properties of numeric types |
| <locale> | Classes and functions related to localization |
| <new> | Functions that manage dynamic memory allocation |
| <stdexcept> | Predefined types of exceptions for reporting errors |
| <string> | Template string container and character traits |
| <typeinfo> | Class that provides basic meta-information about a type |
| <valarray> | Template classes for representing value arrays |

Standard C++ also includes a set of header files that deal with I/O, listed in Figure D.4. The standard I/O classes' design hacks back to the 1980s is needlessly complex, making them very hard to extend—so difficult, in fact, entire books have been written on the subject. It leaves the programmer with a Pandora's box of unresolved issues related to character encodings and platform-dependent binary representations of primitive data types.

| Figure D.4. C++ I/O library header files |
| Header File | Description |
| <fstream> | Template classes that manipulate external files |
| <iomanip> | I/O stream manipulators that take an argument |
| <ios> | Template base class for I/O streams |
