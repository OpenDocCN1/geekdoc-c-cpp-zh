We call setControl() on the QWidget with the class ID of the Windows Media Player 6.4 control. This will create an instance of the required control. From then on, all the properties, events, and methods of the ActiveX control are available as Qt properties, signals, and slots through the QAx object.

The COM types are automatically converted into the corresponding Qt types
