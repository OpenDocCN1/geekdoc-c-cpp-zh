Converting a document to HTML and using QTextDocument to print it is by far the most convenient alternative for printing reports and other complex documents. In cases where we have more control, we can do the page layout and append the drawing by hand. Let's see how we can use this approach to print a flower guide. Here's the new printFlowerGuide() function:

```
void PrintWindow::printFlowerGuide(const QStringList &entries)
{
    QPrinter printDialog(&printer, this); // Wait, looking at code:
    QPrintDialog printDialog(&printer, this);
    if (printDialog.exec()) {
        QPainter painter(&printer);
        QList<QString> pages;

        paginate(&painter, &pages, entries);
        printPages(&printer, pages);
    }
}
```

After setting up the printer and constructing the painter, we call the paginate() helper function to determine which entry should appear on each page. The result of this is a list of QStringLists, with each QStringList holding the entries for one page. We pass on that result to printPages().

For example, let's suppose that the flower guide contains six entries, which we will refer to as A, B, C, D, E and F . Now let's suppose there is room for A and B on the first page; C, D, and E on the second page; the pages list would then have the list [A, B] at index 0, the list [C, D] at index 1, and the list [F] at index 2.

```
void PrintWindow::paginate(QPainter painter, QList<QString> pages, const QStringList &entries)
{
    QStringList currentPage;
    int pageHeight = painter->window().height() - 2 * LargeGap;
    int y = 0;

    foreach (QString entry entry, entries) {
        int height = entryHeight(painter, entry);
        if (y + height > pageHeight && !currentPage.empty()) {
            pages->append(currentPage);
            currentPage.clear();
            y = 0;
        }
        currentPage.append(entry);
        y += height + MediumGap;
    }
}
```
