The model is constructed and set up in the same way as the QSqlTableModel we saw earlier, but this time we use a QSqlRelationalTableModel and set up a foreign key. The setRelation() function takes the index of a foreign key and a QSqlRelation. The QSqlRelation constructor takes a table name (the foreign key's table), the name of the foreign key field, and the name of the field to display to represent the foreign key's value.

A QComboBox is like a QWidget that it has an internal model to hold its data. We replace that with one of our own, and that is what we do, giving it the relation model that is used by the QSqlRelationalTableModel. The relation has two columns, so we must specify which combobox should show. The relation model created for when we used setRelation(), so we do not know the index of the name column. For this reason, we use the fieldIndex() function with the field name to get the index to make the combobox show the department names. Thanks to QSqlRelationalTableModel, the combobox will display department names rather than department IDs.
