```
void MainWindow::gotoCell()
{
    GotoCellDialog dialog(this);
    if (dialog.exec()) {
        QString str = dialog.lineEdit->text().toUpper();
        spreadsheet->setCurrentCell(str.mid(1).toInt() - 1,
            str[0].unicode() - 'A');
    }
}
```

The QDialog::exec() function returns a true value (QDialog::Accepted), and a false value (QDialog::Rejected) otherwise. Recall that when we created the Go to Cell dialog using Qt Designer in Chapter 2, we connected OK to accept() and Cancel to reject(). If the user chooses OK, we set the current cell to the value in the line editor.

The QTableWidget::setCurrentCell() function expects two arguments:a row and a column index. In the Spreadsheet application, cell A1 is (0, 0) and cell B27 is (26, 1). To obtain the row index from the String returned by QLineEdit::text(), we extract the row number using QString::mid(a substring from the start position to the end of the string), convert it to an int using QString::toInt(), and subtract 1. For the column number, we subtract the numeric value of 'A' from the string's uppercased first character. We know that the string will have the correct format because QRegValidator we created for the dialog allows the OK button to be enabled only if we have a letter followed by up to three digits.

The gotoCell() function differs from all the code seen so far that it creates a widget (a GotoCellDialog) on the stack. At the cost of one extra line, we could just as easily use new and delete

```
void MainWindow::gotoCell()
{
    GotoCellDialog *dialog = new GotoCellDialog(this);
    if (dialog->exec()) {
        QString str = dialog->lineEdit->text().toUpper();
        spreadsheet->setCurrentCell(str.mid(1).toInt() - 1,

    }
    delete dialog;
```
