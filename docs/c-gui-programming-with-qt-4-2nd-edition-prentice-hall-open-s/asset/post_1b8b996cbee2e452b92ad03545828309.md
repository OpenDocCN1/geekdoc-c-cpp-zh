The task of converting a formula into a value is performed by the Cell class. Moment, the thing to bring in mind is that the text shown in the cell is the result of evaluating the formula, not the formula itself.

- If the formula is a number, it is interpreted as such. For example, the formula "1.50" evaluates to double value 1.5, which is rendered right-aligned in the spreadsheet.
- If the formula starts with a single quote, the rest of the formula is interpreted as text. For example, the formula "12345" evaluates to the string "12345".

- If the formula starts with an equal sign ('='), it is interpreted as an arithmetic formula. For example, if Cell A1 contains "12" and cell A2 contains "6", the formula "=A1+A2" evaluates to 18.

# Storing Data as Items

In the Spreadsheet application, every non-empty cell is stored in memory as an individualWidgetItem. Storing data as items is an approach that is also used by ListWidget and QTreeWidget, which operate on ListItems and TreeWidgetItems.

Qt's item classes can be used out of the box as data headers. For example, a TableWidgetItem already stores a few attributes, including a string, font, color, and a pointer back to the Table. The items can also hold data (QVariants), by subclassing the item class we can provide additional functionality.

Older toolkits provide void in their items to store custom data. In Qt, the more natural approach is to use setData() with a QVariant, but if a void is required, it can be trivially achieved by subclassing an item class and adding a void member variable.

For more challenging data handling requirements, such as large data sets, complex data items, database integration, and multiple data views, Qt provides a set of model/view classes that separate the data from their visual representation. These are covered in Chapter 10.

```cpp
void Spreadsheet::setFormula(int row, int column, const QString &formula)
{
    Cell *c = cell(row, column);
    if (!c) {
        c = new Cell;
        setItem(row, column, c);
    }
    c->setFormula(formula);
}
```
