This is done by creating a Qt Assistant profile and writing a .dcf file that provides information about the documentation. All is explained in Qt Assistant's online documentation, we will not duplicate this information here.

An alternative to using a web browser, QTextBrowser, or Qt Assistant is to use platform-specific approaches to providing online help. For Windows applications, it might be desirable to create Windows HTML Help files and to access to them using Microsoft Internet Explorer. You could use Qt's QProcess class or the ActiveQt framework for this. On Mac OS X, Apple Help provides similar functionality to Qt Assistant.
