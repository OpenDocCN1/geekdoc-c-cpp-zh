pixelRect() function returns a QRect suitable for QPainter::fillRect().
i and j parameters are pixel coordinates in the QImage——not in the widget.
The zoom factor is 1, the two coordinate systems coincide exactly.

QRect constructor has the syntax QRect(x, y, width, height), (x, y)
is the position of the top-left corner of the rectangle and width x height is the size
of the rectangle. If the zoom factor is 3 or more, we reduce the size of the rectangle
by one pixel horizontally and vertically so that the fill does not draw over the grid lines.

When the user presses a mouse button, the system generates a "mouse press"
event. By reimplementing QWidget::pressEvent(), we can respond to this
event and set or clear the image pixel under the mouse cursor.

If the user pressed the left mouse button, we call the private function
setImagePixel() with true as the second argument, telling it to set the pixel to
the current pen color. If the user pressed the right mouse button, we also call
setImagePixel(), but pass false to clear the pixel.
