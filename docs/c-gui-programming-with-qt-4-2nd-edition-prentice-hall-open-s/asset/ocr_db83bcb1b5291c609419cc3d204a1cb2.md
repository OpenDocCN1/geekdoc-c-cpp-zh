QVector<QPointF>; in Qt Jambi, we use ArrayList<QPointF> instead, relying on Jambi to transform from one to the other as needed.

With the settings and curve data, we create a new Plotter object with no parent (make it a top-level window). Then we give the plotter settings, and the data for two curves, and call show() to make the plotter visible. Finally, we call QApplication::exec() instead, to start the event loop.

When we compile the application, we must be careful to include not only the normal CLASSPATH, but also the path to the com.softwareinc.plotter package. To run the application, we must also set up a couple of additional environment variables, to ensure that find Qt Jambi and our bindings. On Windows, we must mention PATH as follows:

```
set PATH=%PATH%%;JAMBIPATH\%CD
```

On Unix, we must set LD_LIBRARY_PATH:

```
export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:$JAMBIPATH/lib:$PWD
```

On Mac OS X, the environment variable is called DYLD_LIBRARY_PATH. Also, on all three platforms, we must set QT_PLUGIN_PATH to include Qt Jambi's plugins directory. For example:

```
set QT_PLUGIN_PATH=%QT_PLUGIN_PATH%;%JAMBIPATH\%plugins
```
