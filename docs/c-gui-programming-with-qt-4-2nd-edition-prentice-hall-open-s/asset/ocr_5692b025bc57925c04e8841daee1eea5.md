Any Qt widget has a list of QActions associated with it. To provide a context menu for the application, we add the desired actions to the Spreadsheet and set that widget's context menu to show a context menu with these actions. Context menus are invoked by right-clicking a widget or by pressing a platform-specific key. The Spreadsheet's context menu is shown in Figure 3.6.
