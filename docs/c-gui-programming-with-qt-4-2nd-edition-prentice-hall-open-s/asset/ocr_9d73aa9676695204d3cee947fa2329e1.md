| :on | The widget is "on" |
| :off | The widget is "off" |

Style sheets can also be used together with other techniques to perform more complex customizations. For example, suppose we want to position a tiny "erase" button inside a QLineEdit, to the right of the Qt text. This involves creating an EraseButton class, and placing it on top of the QLineEdit (e.g., using layouts), but also reserving some space for the button, so that the typed-in text cannot collide with the erase button. By subclassing QStyle would be inconvenient, because we would have to subclass every style in Qt that might be used by the application (QWindowsStyle, QPlastiqueStyle, etc.). Using style sheets, the following rule does the trick:

```
QLineEdit {
padding: 0px 15px 0px 0px;
}
```

The padding property lets us specify the top, right, bottom, and left padding of the widget. The padding is inserted between the QLineEdit's text and its frame. For convenience, CSS also defines padding-top, padding-right, padding-left, for when we want to set only one padding value. For example:

```
QLineEdit {
padding-right: 15px;
}
```

Like most Qt widgets are customizable by style sheets, QLineEdit supports the box model depicted in Figure 19.6. This model specifies four rectangles that affect the layout and rendering of a styled widget:

+   1. The contents rectangle is the innermost rectangle. This is where the actual contents of the widget (e.g., the text or image) is painted.

+   2. The padding rectangle encloses the contents rectangle. It takes into account any padding specified using the padding property.

+   3. The border rectangle encloses the padding rectangle. It reserves space for the border.

+   4. The margin rectangle is the outermost rectangle. It encloses the border rectangle and takes into account any specified margin.
