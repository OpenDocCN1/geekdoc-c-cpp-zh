To compile the program, run qmake as usual. Since the FindDialog class contains the Q_OBJECT macro, the Makefile generated by qmake will include rules to run moc, Qt's meta-object compiler. (We Cover Qt's meta-object system in the next section.) For moc to work correctly, we must put the class definition in a header file, separate from the implementation file. The code generated by moc includes this header and adds some C++ boilerplate code of its own.

Classes that use the Q_OBJECT macro must moc run on them. This is a problem because qmake automatically adds the necessary rules to the makefile.
