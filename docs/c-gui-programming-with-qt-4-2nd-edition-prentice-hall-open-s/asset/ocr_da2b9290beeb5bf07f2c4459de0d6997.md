QAction::setShortcutContext() or QShortcut::setContext().

Another common type of event is the timer event. While other event types occur as a regular user action, timer events allow algorithms to perform processing at regular intervals. Timer events can be used to implement blinking cursors or other animations, or to refresh the display.

To demonstrate timer events, we will implement the Ticker widget shown in Figure 7.1. This widget shows a text banner that scrolls left by one pixel every 30 milliseconds. If the widget is wider than the text, the text is repeated as often as necessary to fill the width of the widget.
