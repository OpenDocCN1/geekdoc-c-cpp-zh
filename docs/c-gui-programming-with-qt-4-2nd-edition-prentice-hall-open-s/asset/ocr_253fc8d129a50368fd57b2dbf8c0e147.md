CSV (comma-separated values) or an HTML string. For example, the data

Red Green Blue
Cyan Yellow Magenta

is converted to

"Red", "Green", "Blue"
"Cyan", "Yellow", "Magenta"

or to

```
<table>
<tr><td>Red</td><td>Green</td><td>Blue</td>
<tr><td>Cyan</td><td>Yellow</td><td>Magenta</td>
</table>
```

The conversion is performed in the simplest possible way, using QString::replace(). To escape HTML special characters, we use QString::escape().

```
  if (event->mimeData()->hasFormat("text/csv")) {

    ...
    event->acceptProposedAction();
  } else if (event->mimeData()->hasFormat("text/plain")) {
    QString plainText = event->mimeData()->text();
    ...
    event->acceptProposedAction();
  }
}
```

Although we provide the data in three different formats, we only accept two of them in dropEvent(). If the user drags cells from a QTable to an HTML editor, we also want the cells to be converted into an HTML table. If the user drags arbitrary HTML into a QWidgetItem, we don't want to accept it.

To make this example, we also need to setAcceptDrops(true) and setSelectedMode(ContiguousSelection) in the MyTableWidget constructor.
