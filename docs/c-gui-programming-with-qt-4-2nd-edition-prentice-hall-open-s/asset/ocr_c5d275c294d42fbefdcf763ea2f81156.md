okToContinue(), we check the state of the windowModified property. If it is true, we display the message box shown in Figure 3.9. The message box has a Yes, No, and a Cancel button.

MessageBox provides many standard buttons, and automatically to make one button the default (activated when the user presses Enter), and one escape (activated when the user presses Esc). It is also possible to choose particular buttons as the default and escape buttons, and also to customize the button texts.

The call to warning() may look a bit intimidating at first sight, but the general syntax is straightforward:

```
MessageBox::warning(parent, title, message, buttons);
```
