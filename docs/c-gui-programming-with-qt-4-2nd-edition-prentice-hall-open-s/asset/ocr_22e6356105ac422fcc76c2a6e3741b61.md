QTcpSocket::connectTo(), QUdpSocket::writeDatagram() does not accept name as only host addresses. If we wanted to resolve a name to an IP address host, we have two choices. If we are prepared to block the lookup takes place, we can use the static QHostInfo::fromName() function. Otherwise, we can use QHostInfo::lookupHost() function, which returns immediately and calls the slot it is passed with a QHostInfo object containing the corresponding addresses when the lookup is complete.
