The QStyleOption::initFrom function initializes the fundamental member variables that represent a widget, as rect, state (enabled, focused, etc.), and palette. Member variables specific to QStyleOptionButton must be initialized manner. The MyPushButton example, we initialize features and text and icon iconSize take their default values.

The QWidget::style function returns the appropriate style for drawing the widget. The style is normally set for the entire application using QApplication::setStyle(), but it is also possible to override it for individual widgets using QWidget::setStyle().
