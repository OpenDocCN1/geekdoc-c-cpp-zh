Operators can be implemented either as member functions or as global functions. In our example, we implemented += and -= as member functions, and + - as global functions.

The += and -= operators take a reference to another Point2D object and increment the x- and y-coordinates of the object based on the other. They return *this, which denotes a reference to the current object (this is of type Point2D*). Returning a reference allows us to write exotic code such as a += b += c;
