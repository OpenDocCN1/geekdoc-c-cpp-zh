Macros were popular in the old days, typedefs, enums, constants, inline functions, and templates were introduced. Nowadays, their most important role is to protect header files against multiple inclusions.

+   Macros can be undefined at any point using #undef:

```
#undef PI
```

This is useful if we want to redefine a macro, since the preprocessor doesn't let us define the same macro twice. It is also useful to control conditional compilation.

+   Portions of code can be processed or skipped using #if, #elif, #else, #endif, based on the numeric value of macros. For example:

```
#define NO_OPTIM 0
#define OPTIM_FOR_SPEED 1
#define OPTIM_FOR_MEMORY 2

#define OPTIMIZATION OPTIM_FOR_MEMORY
n...
```

```
#if OPTIMIZATION == OPTIM_FOR_SPEED
typef int MyInt;
#elif OPTIMIZATION == OPTIM_FOR_MEMORY
typef short MyInt;
#else
typef long long MyInt;
#endif
```

In the preceding example, the second typedef declaration would be processed by the compiler, resulting in MyInt defined as a synonym for short. By changing the definition of the OPTIMIZATION macro, we get different programs. If a macro isn't defined, its value is taken to be 0.

Another approach to conditional compilation is to test whether a macro is defined. This can be done by using the defined() operator as follows:

```
#define OPTIM_FOR_MEMORY
...
#if defined(OPTIM_FOR_SPEED)
```
