The XmlStreamReader class provides two public functions: the constructor and parseFile(). The class uses a XmlStreamReader instance to parse the XML file, and populates the QTree to reflect the XML data that is read. The parsing is done recursive descent:

- readBookIndexElement() parses a <bookindex>...</bookindex> element that contains zero or more <entry> elements.


QXmlStreamReader's readNext() reads the next token from the input stream. If a token is successfully read and the end of the XML file has not been reached, the function enters the while loop. Because of the structure of the index files, we know that inside this loop there are three possibilities: A <book> start tag has been read, another start tag has been read (in case the file is not a book index), or some other token has been read.

If we have the correct start tag, we can readBookIndexElement() to continue processing. Otherwise, we can call XmlStreamReader::raiseError() with an error message. The next time atEnd() is called (in the while loop), it will return true. This ensures that parsing stops as soon as possible an error has been encountered. The error can be queried later by calling error() and errorString()) on the QFile. An alternative would have been to return right away when we detect an error in the book index file. using raiseError() is usually more convenient, because it lets us use the same error-reporting mechanism for low-level XML parsing errors, which are raised automatically when QXmlStreamReader runs into invalid XML, and for application-specific errors.

```cpp
void XmlStreamReader::readBookIndexElement()
{
reader.readNext();
while (!reader.atEnd()) {
    if (reader.isEndElement()) {
        reader.readNext();
        break;
    }
    if (reader.isStartElement()) {
        if (reader.name() == "entry") {
            readEntryElement(treeWidget->invisibleRootItem());
        } else {
            skipUnknownElement();
        }
    } else {
        reader.readNext();
    }
}
}
```

readBookindexElement() is responsible for reading the main part of the file. it starts by skipping the current token (at which point this is a <bookindex> start tag) and loops over the input.

If an tag is read, it can only be the </bookindex> tag, since otherwise, QXmlStreamReader would have reported an error (UnexpectedElement). In this, we skip the tag and break out of the loop. Otherwise, we have a top-level index <entry> start tag. This is to process the entry data; if not, we skipUnknownElement(). Using skipUnknownElement() rather than calling raiseError() means that if we extend the book index format in the future to include new tags, this reader will continue to work, since it will simply ignore the tags it does not.

readEntryElement() takes a QTreeWidgetItem * argument that identifies a parent item. We pass QTree::invisibleRootItem() as the parent to make the new items root items. in readEntryElement(), we will call readEntryElement() recursively, with a different parent.

```cpp
void XmlStreamReader::readEntryElement(QTreeWidgetItem *parent)
{
    QTreeWidgetItem *item = new QTreeWidgetItem(parent);
    item->setText(0, reader.attributes().value("term").toString());

    reader.readNext();
    while (!reader.atEnd()) {
        if (reader.isEndElement()) {
            reader.readNext();
            break;
        }
        if (reader.isStartElement()) {
            if (reader.name() == "entry") {
                readEntryElement(item);
            } else if (reader.name() == "page") {
                readPageElement(item);
            } else {
                skipUnknownElement();
            }
        } else {
            reader.readNext();
        }
    }
}
```
