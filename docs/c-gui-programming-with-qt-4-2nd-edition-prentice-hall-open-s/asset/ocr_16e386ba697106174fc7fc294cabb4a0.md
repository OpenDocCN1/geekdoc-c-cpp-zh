# Extending Qt Applications with Scripts

Using the QtScript module, we can write C++ applications that execute ECMAScript. Scripts can be used to extend application functionality without requiring the application to be rebuilt and redeployed. We limit the scripts to a hard-coded set of ECMAScript files that are provided as part of the application and can be replaced with new versions independently of the application, or we can make the application able to use arbitrary ECMAScript files.

Executing a script from a C++ application typically involves the following steps:

+   1. Load the script into a QString.
2. Create a QScriptEngine object and set it up to expose application-specific functionality.
3. Execute the script.

To illustrate this, we will study the Calculator application shown in Figure 22.2. The Calculator application lets the user provide custom buttons by implementing their functionality in scripts. When the application starts up, it traverses the subdirectories, looking for script files, and creates calculator buttons associated with these scripts. By default, Calculator includes the following scripts:

+   - cube.js computes the cube of the current value (x³).
- factorial.js computes the factorial of the current value (x!).
- pi.js overwrites the current value with an approximation of π.
