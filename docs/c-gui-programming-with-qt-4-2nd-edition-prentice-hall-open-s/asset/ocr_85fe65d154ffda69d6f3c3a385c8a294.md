This completes our review of the public functions reimplemented from QStyle. The next four functions are private drawing functions.

```
void BronzeStyle::drawBronzeFrame(const QStyleOption *option,
QPainter *painter) const

    painter->save();
    painter->setRenderHint(QPainter::Antialiasing, true);
    painter->setPen(QPen(option->palette.foreground(), 1.0));
    painter->drawRect(option->rect.adjusted(+1, +1, -1, -1));
    painter->restore();
```

The drawBronzeFrame() function was called from drawPrimitive() to draw a PE_Frame primitive element. This is used to draw the frame around a QFrame (or a subclass, such as QTreeView) when the frame shape is QFrame::StyledPanel. The other frame shapes, such as Box, Panel, and VLine, are drawn directly by QFrame without going through the style.

The frame we draw is an antialased 1-pixel-width outline around the widget, using the palette's foreground brush (available through the QStyleOption's palette member variable). Since the rectangle is antialased and is located on one coordinate, the result is a blurred 2-pixel-width outline, which is precisely what we want for the Bronze style.
