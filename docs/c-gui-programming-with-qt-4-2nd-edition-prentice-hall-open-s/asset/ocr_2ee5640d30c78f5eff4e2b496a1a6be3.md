In the constructor, we set the central widget to be a JournalView, a QWidget subclass. Then we install two QTranslator objects on the QApplication: The translator object stores the current application's translation, and the qtTranslator stores Qt's translation. At the end, we call the createActions() and createMenus() private functions to create the menu system, and we call retranslateUi() (also a private function) to set the user-visible strings for the first time.

```
void MainWindow::createActions()
{
    newAction = new QAction(this);
    newAction->setShortcut(QSequence::New);
    connect(newAction, SIGNAL(triggered()), this, SLOT(newFile()));
    
    exitAction = new QAction(this);
    connect(exitAction, SIGNAL(triggered()), this, SLOT(close()));
    
    aboutQt = new QAction(this);
    connect(aboutQt, SIGNAL(triggered()), qApp, SLOT(aboutQt()));
}
```

The createActions() function creates the QAction objects as usual, but without setting any of the texts. These will be done in retranslateUi(). For actions that have standardized shortcuts, we set the shortcut here using the appropriate enum, and rely on Qt to translate as. For actions that have custom shortcuts, such as the Exit action, we set the shortcut in the retranslateUi() function, along with the text.
