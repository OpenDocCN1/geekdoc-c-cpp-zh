accept() Cancel button to the reject() slot. Both slots close the dialog, accept() sets the result value to QDialog::Accepted (which equals 1), and reject() sets the result to QDialog::Rejected (which equals 0). When we use this dialog, we can use the result to see if the user clicked OK and accordingly.

The on_lineEdit_textChanged() slot enables or disables the OK button, according to which the line editor contains a valid cell location. QLineEdit::hasAcceptableInput() uses the validator we set in the constructor.
