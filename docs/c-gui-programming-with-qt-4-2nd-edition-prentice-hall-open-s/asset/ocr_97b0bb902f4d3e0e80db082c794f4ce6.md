When a link is constructed, it adds itself to the nodes it connects. Graphics items have several flags, but in this case we only want links to be selectable so that the user can select and then delete them.

Every graphics item has an (x, y) position, and a z value that specifies how far forward or back it is in the scene. Since we are going to draw our lines from the center of one node to the center of another node, we give the line a z value so that it will always be drawn underneath the nodes connects. As a result, links will appear as lines between the nearest edges of the nodes they connect.

At the end of the constructor, we set an initial line color and then set the link's endpoints by calling trackNodes().

```
Link::~Link()
{
    myFromNode->removeLink(this);
    myToNode->removeLink(this);
}
```

When a link is destroyed, it removes itself from the nodes it is connecting.

```
void Link::setColor(const QColor &color)
{
    setPen(QPen(color, 1.0));
}
```

When the link's color is set, we simply change its pen, using the given color and a line width of 1. The setPen() function is inherited from QGraphicsLineItem. color() simply returns the pen's color.

```
void Link::trackNodes()
{
    setLine(QLineF(myFromNode->pos(), myToNode->pos()));
}
```

QGraphicsItem::pos() function returns the position of its graphics item relative to the scene (for top-level items) or to the parent item (for child items).

For the Link class, we rely on its base class to handle the painting: QGraphicsLineItem draws a line (using pen()) between two points in the scene.
