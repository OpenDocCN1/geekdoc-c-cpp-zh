The drawCube() function is the heart of the custom widget. We'll review it in two parts:

```
void VowelCube::drawCube()
{
    glPushAttrib(GL_ALL_ATTRIB_BITS);
    glMatrixMode(GL_PROJECTION);
glPushMatrix();
glIdentity();
float x = 3.0 * GLfloat(width()) / height();
glOrtho(-x, +x, -3.0, +3.0, 4.0, 15.0);
nglMatrixMode(GL_MODELVIEW);
glPushMatrix();
glIdentity();
glf(0.0, 0.0, -10.0);
glScalef(scaling, scaling);
glRotatef(rotationX, 1.0, 0.0, 0.0);
glRotatef(rotationY, 0.0, 1.0, 0.0);
glRotatef(rotationZ, 0.0, 0.0, 1.0);

Enable(GL_MULTISAMPLE);
```

Because we have some OpenGL code between two pieces of code that use QPainter, we must be careful—specifically, we must save the OpenGL state that we change in the function and restore it after we are done. We save the OpenGL attributes, the projection matrix, and the model view matrix before we change them. At the end, we save the GL_MULTISAMPLE option to enable antialiasing.
