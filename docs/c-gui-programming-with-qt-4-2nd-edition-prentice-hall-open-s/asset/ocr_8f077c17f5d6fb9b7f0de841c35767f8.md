Next, we call glCallList() to draw the cube object. Then we set the font and color, and call QWidget::renderText() to draw the vowels at the corners of the cube. The Turkish vowels that fall outside the ASCII character range are specified using their Unicode value.

The renderText() function takes an (x, y, z) coordinate triple to position the text in view coordinates. The text itself is not transformed.
