5. Click the form's background to select the form itself. Set the setName property to "GoToCell" and the windowTitle property to "Go to Cell".

All the widgets look fine, except the text label, which shows &Cell Location. Enter a special mode that allows you to set buddies. Click the label and drag the red line to the line editor, release. The label should now appear as Cell Location, as shown in Figure 2.7, and have the line editor as its buddy. Click Edit Buddies to leave buddy mode.
