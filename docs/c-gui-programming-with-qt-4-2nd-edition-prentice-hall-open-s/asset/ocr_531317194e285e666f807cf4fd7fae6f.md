To make the dialog use QDialogQPushButton, we must change both the design and the code of it. In Qt Designer, there are just four steps to take:

+   1. Click the form (not any of the widgets or layouts) and then click Break Layout.

+   2. Click and delete the OK button, the Cancel button, the horizontal spacer, and the (now empty) horizontal layout.

+   3. Drag a "Button Box" onto the form, below the cell location label and line editor.

+   4. Click the form and then click Lay Out Vertically.

If we had just been doing design changes, such as changing the dialog's layouts and widget properties, we would be able to rebuild the application. But here we have removed some widgets and added a new widget, and in these cases we usually change the code too.

In the previous version, we disabled the OK button in Qt Designer. We cannot do that with a QDialogQPushButton, so we do so, immediately after the setupUI() call. QDialogQPushButton has an enum of standard buttons, and we can use this to access particular buttons, in this case the OK button.

Very conveniently, Qt Designer's default name for a QDialogQPushButton is buttonBox. Both connections are from the button box rather than the buttons themselves. The accepted() signal is emitted when a button with the AcceptRole is clicked, and the rejected() signal is emitted by a button with the RejectRole.
