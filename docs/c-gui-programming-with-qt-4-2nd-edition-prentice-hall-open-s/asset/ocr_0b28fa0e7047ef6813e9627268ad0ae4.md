```
QVariant CurrencyModel::headerData(int section, Qt::Orientation /* orientation *//, int role) const
```

```
    if (role != Qt::DisplayRole)
        return QVariant();
```

The headerData() function is called by the view to populate its horizontal and vertical headers. The section parameter is the row or column number (depending on the orientation). Since the rows and columns have the same currency codes, we do not care about the orientation and simply return the currency for the given section number.


```
{
    currencyMap = map;
    reset();
}
```

The caller can change the currency map using setCurrencyMap(). The QAbstractItem::reset() call tells any views that are using the model all their data is invalid; this forces them to request fresh data for the items that are visible.

```
QString CurrencyModel::currencyAt(int offset) const
```

```
{
    return (currencyMap.begin() + offset).key();
}
```

The currencyAt() function returns the key (currency code) at the given offset in the currency map. We use an STL-style iterator to find the item and call key() on it.
