setupUi() call creates and layouts out all the form's widgets, and establishes the signal-slot connection for the on_browseButton_clicked() slot. We give a pointer to the button box's OK button and give it more suitable. We also disable it, since initially there is no image to convert, and we connect to the button box's rejected() signal (emitted by the Close button) to the reject() slot. After that, we connect three signals from QProcess object to three private slots. Whenever the external process has data on its cerr, we will handle it in updateOutputTextEdit.

```
void ConvertDialog::on_browseButton_clicked()
{
    QString initialName = sourceEdit->text();
    if (initialName.isEmpty())
        initialName = QDir::homePath();
    QString fileName =
        QDialog::getFileName(this, tr("Choose File"), initialName);
    fileName = QDir::toNativeSeparators(fileName);
    if (!fileName.isEmpty()) {
        sourceEdit->setText(fileName);
        buttonBox->button(QDialogButton::Ok)->setEnabled(true);
    }
}
```
