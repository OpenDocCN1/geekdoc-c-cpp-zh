We initialize id (the last selected ID) to -1. We construct a QListWidget, a convenience item widget. We iterate over each item in the flowchart map and create a QWidgetItem to represent each one. The QListWidgetItem constructor takes a QString that represents the text to display, followed by the parent QListWidget.

Then we set the item's icon and we call setData() to store our arabic ID in the QListWidgetItem. The iconForSymbol() private function returns a QIcon for a given symbol name.
ListWidgetItems have several roles, each of which has an associated QVariant. The most common roles are Qt::DisplayRole, Qt::EditRole, and Qt::IconRole, and for these convenience setter and getter functions (setText(), setIcon()), there are several other roles. We can also define custom roles by Qt::UserRole or higher. In our example, we use Qt::UserRole to store each item.

The omitted part of the constructor is concerned with creating the buttons, laying out the widgets, and setting the window title.
