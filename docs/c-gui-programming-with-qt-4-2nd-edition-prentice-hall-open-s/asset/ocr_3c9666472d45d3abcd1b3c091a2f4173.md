If a new list of cities is given, we set the private QStringList to the new list, and clear the distances vector, and call QAbstractApiModel::reset() to notify any views that their visible items must be refreshed.

```
int CityModel::offsetof(int row, int column) const
{
    if (row < column)
        qSwap(row, column);
    return (row * (row - 1) / 2) + column;
}
```

The offset() function computes the index of a given city pair in the distances vector. For example, if we had cities A, B, C, and D, and the user updated row 3, column 1 (B to D), the offset would be 3 x (3-1)/2 + 1 = 4. If the user had instead updated row 1, column 3 (D to B), thanks to the qSwap(), exactly the same calculation would be performed and an identical offset would be returned.
