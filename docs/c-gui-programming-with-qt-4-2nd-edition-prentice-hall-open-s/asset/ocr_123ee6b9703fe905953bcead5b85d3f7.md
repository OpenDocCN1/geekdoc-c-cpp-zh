The VowelCube class is derived from QGLWidget. It uses QPainter to draw the background gradient, then it draws the cube using Open GL calls, then it draws the eight vowels at the corners of the cube using renderText(), and finally draws the legend using QPainter and QTextDocument. The user can rotate the cube by pressing a mouse button, dragging, and zoom in or out the mouse wheel.

Unlike the preceding section's Tetrahedron example, where we reimplemented the high-level QGLWidget functions initializeGL(), resizeGL(), and paintGL(), this time we reimplement the traditional QWidget handlers. This gives us more control over how we update the OpenGL framework.
