RC_FILE        = objectsafetyimpl.cpp

The qaxserver.rc and qaxserver.def files referred to in the .pro file are standard files that can be copied from Qt's src\activeqt\control directory.
The makefile or Visual C++ project file generated by make contains rules to register the server in the Windows Registry. To register the server on end-user machines, we can use the regsvr32 tool available on all Windows systems.
We can then include the Bouncer component in an HTML page using the <object> tag:

```
<object id="AxBouncer" classid="clsid:5e2461aa-a3e8-4f7a-8b04-307549a4c08c"><b>The ActiveX control is not available. Make sure you have built and registered the component server.</b></object>
```

We can create buttons that invoke slots:
<input type="button" value="Start" onclick="AxBouncer.start()">
<input type="button" value="Stop" onclick="AxBouncer.stop()">

We can manage the widget using JavaScript or VBScript just like any other ActiveX control. See the demo.html file included with the book's examples for a rudimentary page that uses the ActiveX server.
