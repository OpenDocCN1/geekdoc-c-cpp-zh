the sendRequest() slot is executed when the TcpSocket object emits the connected() signal, indicating that a connection has been established. The slot's task is to generate a request to the server, with all the information entered by the user.

The request is a binary block with the following format:

| quint16 | Block size in bytes (excluding this field) |
|---|-|
| quint8 | Request type (always 'S') |
| QString | Departure city |
| QString | Arrival city |
| QDate | Date of travel |
| QTime | Approximate time of travel |
| quint8 | Time is for departure ('D') or arrival ('A') |

We first write the data to a QByteArray called block. We can't write the data directly to the TcpSocket because we won't know the size of the block, which must be sent first, until after we put all the data into the block.

We initially write 0 as the block size, before the rest of the data. We call seek(0) on the I/O device, a QBuffer created by QDataStream to move back to the beginning of the byte array, and overwrite the initial 0 with the size of the block. The size is calculated by taking the block's size and subtracting sizeof(quint16) (i.e., 2) to exclude the size field from the byte count. After that, we call write() on the TcpSocket to send the block to the server.
