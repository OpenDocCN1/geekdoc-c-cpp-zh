| Red | Green | Blue |

is converted to

"Red", "Green", "Blue"
"Cyan", "Yellow", "Magenta"

or to

```html
<table>
<tr><td>Red</td><td>Green</td><td>Blue</td></tr>
<tr><td>Cyan</td><td>Yellow</td><td>Magenta</td></tr>

```

The conversion is performed in the simplest possible way, using QString::replace(). To escape HTML special characters, we use QString::escape().

Although we provide the data in three different formats, we only accept two of them in dropEvent(). If the user drags cells from a QTable to an HTML editor, we also want the cells to be converted into an HTML table. If the user drags arbitrary HTML into a QWidgetItem, we don't want to accept it.

we redo the example, but this time we will subclass QMimeData to postpone or avoid the (potentially expensive) conversions between QTableItems and QByteArray. Here's the definition of our subclass:

```cpp
class TableMimeData : public QMimeData
{
    Q_OBJECT
public:
    TableMimeData(const QTable *tableWidget,
                  const QTreeWidgetItemSelectionRange &range);

    const QTable *table() const { return myTableWidget; }
    QTreeWidgetItemSelectionRange range() const { return myRange; }
    QStringList formats() const;

protected:
    QVariant retrieveData(const QString &format,
                          QVariant::Type preferredType) const;

private:
    static QString toHtml(const QString &plainText);
    static QString toCsv(const QString &plainText);

    QString text(int row, int column) const;
    QString rangeAsPlainText() const;

    const QTable *myTableWidget;
    QTreeWidgetItemSelectionRange myRange;
    QStringList myFormats;
};
```

Instead of storing actual data, we store a QTableSelectionRange that specifies which cells are dragged and keep a pointer to the QTable. The formats() and retrieveData() functions are reimplemented from QMimeData.

```cpp
TableMimeData::TableMimeData(const QTable *tableWidget,
              const QTableSelectionRange &range)
{
    myTableWidget = tableWidget;
    myRange = range;
    myFormats << "text/csv" << "text/html" << "text/plain";
}
```

In the constructor, we initialize the private variables.

```cpp
QStringList TableMimeData::formats() const
{
    return myFormats;
}
```

The formats() function returns a list of MIME types provided by the MIME data object. The precise order of the formats is usually irrelevant, but it's good practice to put the "best" formats first. Applications that support many formats will sometimes use the first one that matches.

```cpp
QVariant TableMimeData::retrieveData(const QString &format, QVariant::Type preferredType)
{
    if (format == "text/plain") {
        return rangeAsPlainText();
    } else if (format == "text/csv") {
        return toCsv(rangeAsPlainText());
    } else if (format == "text/html") {
        return toHtml(rangeAsPlainText());
    } else {
        return QMimeData::retrieveData(format, preferredType);
    }
}
```

The retrieveData() function returns the data for a given MIME type as a QVariant. The value of the format parameter is normally one of the strings returned by formats(), we cannot assume that, since all applications check the MIME type against formats(). The getter functions text(), html(), urls(), imageData(), colorData(), and data() provided by QMimeData are implemented in retrieveData.

The preferredType parameter gives us a hint about which type we put in the QVariant. Here, we ignore it and trust QMimeData to convert the return value into the desired, if necessary.
