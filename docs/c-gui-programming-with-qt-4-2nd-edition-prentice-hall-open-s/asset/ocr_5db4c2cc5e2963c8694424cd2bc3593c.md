If the Plotter has a focus, a rectangle is drawn by the widget style's drawPrimitive() function with Q::PE_FrameFocusRect as its first argument and a QOptionFocusRect as its second argument. The focus's drawing options are initialized based on the Plotter widget (the call). The background color must be explicitly specified.

When we want to paint using the current style, we can either call a QStyle() function directly, for example

```
style()->drawPrimitive(QStyle::PE_FrameFocusRect, &option, &painter);
```

or use a QStylePainter instead of a QPainter, as we have done in Plotter, and paint more conveniently using this.

The Widget::style() function returns the style that should be used to draw the widget. In Qt, a widget style is a subclass of QStyle. The built-in styles include WindowsStyle, WindowsXPStyle, WindowsVistaStyle, QMotifStyle, QCStyle, QMStyle, QPlasticStyle, and QCleansetStyle. Each style implements the virtual functions in QStyle to perform the drawing in the correct way for the platform style it is emulating. QStylePainter::drawPrimitive() calls the Style function of the same name, which can be used for drawing "primitive elements" such as panels, buttons, and focus rectangles. The widget style is usually the same for all in an application (Application::style()), but it can be overridden on a per-widget basis using Widget::setStyle().

By subclassing QStyle, it is possible to define a custom style. This can be done by giving a distinctive look to an application or a suite of applications, as we see in Chapter 19. While it is generally advisable to use the platform's native look and feel, Qt offers a lot of flexibility if you want to be adventurous.

Qt's built-in widgets rely almost exclusively on QStyle to paint them. This is why they look like native widgets on all platforms supported by Qt. Custom widgets can be made style-aware by using QStyle to paint them or by using built-in Qt widgets as children. For Plotter, we use a combination of both approaches: the focus rectangle is drawn using QStyle (via QStylePainter), and the Zoom In and Out buttons are built-in Qt widgets.
