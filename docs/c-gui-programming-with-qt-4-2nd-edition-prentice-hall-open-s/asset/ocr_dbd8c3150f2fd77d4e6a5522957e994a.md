# Writing XML

Most applications that can read XML files also need to write such files. There are three approaches for generating XML files from Qt applications:

+   - We can use QXmlStreamWriter.
- We can build a DOM tree and save() on it.
- We can generate XML by hand.

The choice between these approaches is mostly independent of whether we use QXmlStreamReader, DOM, SAX for reading XML documents, although if the data is held in a DOM tree it often makes sense to save the tree directly.

Writing XML using QXmlStreamWriter class is particularly easy since the class takes care of escaping special characters for us. If we wanted to output the index data from a QWidget using QXmlStreamWriter, we could do so using two functions. The first function would take a file name and a QWidget *, and iterate over all the top-level items in the tree:

Code View:

```
bool writeXml(const QString &fileName, QWidget *treeWidget)
    QFile file(fileName);
    if (!file.open(QFile::WriteOnly | QFile::Text)) {
        std::cerr << "Error: Cannot write file "
                  << qprintable(fileName) << ":"
                  << qprintable(file.errorString()) << std::endl;
        return false;
    }

    QXmlStreamWriter xmlWriter(&file);
    xmlWriter.setAutoFormatting(true);
    xmlWriter.writeStartElement("bookindex");
    for (int i = 0; i < treeWidget->topLevelItemCount(); ++i)
        writeEntry(&xmlWriter, treeWidget->topLevelItem(i));
    xmlWriter.writeEndDocument();
    file.close();
    if (file.error()) {
        std::cerr << "Error: Cannot write file "
                  << qprintable(fileName) << ":"
                  << qprintable(file.errorString()) << std::endl;
        return false;
    }
    return true;
```
