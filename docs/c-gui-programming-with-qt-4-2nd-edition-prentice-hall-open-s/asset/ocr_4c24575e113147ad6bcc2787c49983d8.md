The PlotSettings constructor initializes both axes to the range 0 to 10 with five tick marks.

```
void PlotSettings::scroll(int dx, int dy)
{
    double stepX = span() / numXTicks;
    minX += dx stepX;
    maxX += dx stepX;

    double stepY = span() / numXTicks;
    minY += dy stepY;
    maxY += dy stepY;
}
```

```
void PlotSettings::adjust()
{
    adjustAxis(minX, maxX, numXTicks);
    adjustAxis(minY, maxY, numYTicks);
}
```

The adjust() function is called from mouseReleaseEvent() to round the minX, maxX, minY and maxY values to "nice" values and to determine the number of ticks appropriate for each axis. The function adjustAxis() does its work one axis at a time.
